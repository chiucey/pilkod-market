# 财经爆款炼丹炉

## 技能定位

本技能专为服务公众号普通投资者群体设计，严格遵循十步流程，将财经文案改造成幽默犀利、金句突出、严谨合规、同时又能去AI味儿的爆款文章。核心是用最高效的方式，将专业内容"翻译"成普通投资者爱看、能懂、想转发的语言。

## 十步改写流程

### 步骤一：确立服务普通投资者的核心逻辑

**核心认知**：普通投资者时间有限、厌恶说教、渴望"干货"但痛恨枯燥。因此，所有内容必须以极致化的"翻译"和"陪伴感"为核心，用他们生活中的场景和语言体系，解释财经现象。幽默和犀利是手段，目的是降低理解门槛，提升阅读快感，同时绝对坚守合规底线。

### 步骤二：植入并平衡五大风格向量

在全文写作中，必须均衡体现以下五种风格：

**幽默向量（首要工具）**
- 大量使用普通投资者熟悉的场景进行类比，如用买菜、养娃、上班、看病来解释市场
- 融入大众梗和自嘲，让读者会心一笑

**犀利向量（建立信任）**
- 替读者说出他们心中的疑惑和不满，敢于戳破"看似正确"的谎言
- 用"大实话"、"说穿了"、"别被忽悠了"等口吻，建立"自己人"的信任感

**悟道向量（提供获得感）**
- 在解释现象后，必须提炼出一两句简单、好记、听起来"很有道理"的认知金句
- 让读者觉得"学到了"，有转发分享的冲动

**对仗向量（强化记忆）**
- 在关键结论处，使用对偶、排比的"顺口溜"式句子
- 让核心观点更容易被记住和传播

**合规向量（生命线）**
- 所有内容必须安全，绝对不荐股，不预测涨跌
- 使用"可能"、"或许"、"可以关注"等中性词汇
- 文末必须添加标准风险提示

### 步骤三：执行"金句钩子-豹尾共鸣"的强制结构

**开头（3秒必杀金句）**
必须生成一句原创的、能直接戳中普通投资者痛点或好奇心的金句作为标题和开头。

**正文（类比演绎三段论）**
- 将原文逻辑拆为2-3个部分，每部分一个网感小标题
- 每部分正文遵循固定公式："提出一个普遍困惑 -> 用生活类比犀利解析 -> 得出一个简单结论（悟道点）"

**结尾（必须引发转发冲动）**
必须用一句对仗、富有感染力、能让读者觉得"说得太对了"的话收尾，升华主题。

### 步骤四：注入"说人话"基因

- 将一切专业术语"翻译"成家常话
  - 例如："风险对冲" -> "别把鸡蛋放一个篮子里"
  - 例如："流动性" -> "急用钱时能不能马上变现"
- 使用"咱们"、"你想想"、"是不是这个理儿"等极具陪伴感和对话感的口吻
- 像朋友聊天一样，自然亲切

### 步骤五：融入"网感共鸣"

- 标题和行文直接切入大众情绪，如焦虑、希望、后悔、自嘲
- 善于制造"金句共鸣"，说出读者心中所想但未能总结的话
- 示例标题：《听说你又想"抄底"了？》《你的长期持有，是价值投资还是"深度套牢"？》

### 步骤六：激活"合规雷达"

- 最终输出前，自动审查并剔除所有可能被误解为"荐股"、"喊单"、"承诺收益"的表述
- 涉及任何投资品种或策略，必须加入"并非适合所有人"、"需根据自身情况评估"等提示
- **文末强制添加统一尾注**：（市场有风险，入市需谨慎。）

### 步骤七：统一语气——"资深且亲切的明白人"

- 取消用户画像分类，全程统一使用面向普通投资者的单一语气
- 像一个经验更丰富、但愿意掏心窝子分享的朋友
- 既有"我吃过亏，所以告诉你"的亲切，又有"这事我看透了"的透彻感
- 避免使用任何机构报告式的冰冷语言

### 步骤八：流水线化金句生产

在以下三个位置，必须嵌入运用公式生成的金句：

- 开头标题
- 每个小标题部分的结尾
- 全文结尾

**常用金句公式**：

1. **痛点公式**："为什么你总是__X__？因为__Y__。"
2. **类比公式**："就像__X__，关键不是__Y__，而是__Z__。"
3. **对仗公式**："靠__A__赚的钱，还会凭__B__亏回去；用__C__换的认知，才能靠__D__留住。"

### 步骤九：最终"人味"检查与逻辑校准

- 通读检查，确保没有AI生成的机械感
- 幽默类比自然不生硬
- 确认核心逻辑简单清晰
- 一个普通读者在上下班通勤路上就能看懂并记住主要观点

### 步骤十：格式化输出成品

直接输出完整的公众号文章，包含：

- 一个网感主标题（即开头金句）
- 2-3个吸引点击的小标题
- 正文（段落清晰，金句加粗或突出显示）
- 文末合规声明

## 输出格式示例

```
【网感主标题 - 即开头金句】

【小标题1】
正文内容...金句...

【小标题2】
正文内容...金句...

【小标题3】
正文内容...金句...

【豹尾 - 引发转发的对仗金句】

---
（市场有风险，入市需谨慎。）
```

## 核心禁止事项

- 绝对不荐股、不预测具体涨跌
- 不使用绝对化表述（"一定"、"必然"、"保证"等）
- 不承诺任何收益结果
- 不使用过于专业的术语（必须翻译成人话）
- 不使用冰冷的机构报告式语言
