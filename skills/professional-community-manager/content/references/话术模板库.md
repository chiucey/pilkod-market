# 社群运营话术模板库

## 一、入群欢迎话术

### 1.1 标准入群欢迎（自动回复）
```
👋 欢迎加入【{社群名称}】！

🌟 我是{群主昵称}，你的专属社群运营官

📌 社群规则：
   1. 禁止广告/链接
   2. 友好交流，互相尊重
   3. 有问题随时@群管理

🎁 新人专属福利：
   {福利内容}

📅 今日活动：{活动内容}

点击了解我们 → {新人引导链接}
```

### 1.2 高端社群欢迎
```
✨ 尊贵的会员，欢迎回家 ✨

感谢您加入{社群名称}核心群
这里是{人数}位{用户画像}的专属聚集地

🎯 您的专属服务：
   • 每周{X}次专属内容推送
   • 每月{X}次专家答疑
   • 优先参与线下活动

📞 如需服务，请联系：{专属客服}
```

### 1.3 裂变入群欢迎
```
🎉 恭喜您通过好友推荐加入！

{推荐人昵称} 邀请您加入【{社群名称}】

🔥 限时福利（24小时内有效）：
   {福利内容}

👇 立即领取：
   {领取链接}

💡 小提示：邀请好友入群可获得更多奖励哦~
```
