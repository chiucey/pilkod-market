# 质量管理体系标准参考

## 1. ISO9001:2015 相关要求

### 7.5.3 文件化信息的控制
作业指导书作为文件化信息应满足：
- 标识和说明（如文件编号、版本）
- 形式（如语言、软件版本、图表）
- 评审和批准是否适宜且充分
- 分发渠道确保需要时可用
- 防止意外使用过期文件
- 清晰标识变更记录

### 作业指导书编制要点
1. 明确文件编号和版本控制
2. 规定编制、审核、批准流程
3. 建立文件分发和回收记录
4. 定期评审文件适用性

## 2. IATF16949 汽车行业标准

### 核心工具要求
| 工具 | 全称 | 应用阶段 |
|------|------|----------|
| APQP | 产品质量先期策划 | 开发阶段 |
| PPAP | 生产件批准程序 | 量产前 |
| FMEA | 失效模式与影响分析 | 设计/过程 |
| SPC | 统计过程控制 | 生产过程 |
| MSA | 测量系统分析 | 检验测量 |

### 作业指导书特殊要求
- 必须与控制计划对应
- 关键特性参数必须明确标识
- 包含防错验证要求
- 满足顾客特定要求

### 追溯性要求
- 批次追溯：原料→过程→成品
- 单件追溯：使用唯一序列号
- 记录保存期限：至少法规要求年限

## 3. ISO13485 医疗器械标准

### 文件控制要求
- 文件审批前应评审适用性
- 确保文件在使用场所可用
- 文件更改应重新审批
- 废止文件应及时回收

### 特殊内容要求
| 要求 | 说明 |
|------|------|
| 洁净室控制 | 环境监测要求 |
| 灭菌参数 | 灭菌工艺参数 |
| 批记录 | 完整生产记录 |
| 追溯要求 | 唯一器械标识(UDI) |

### 培训要求
- 人员能力确认
- 上岗前培训记录
- 持续培训计划

## 4. GMP 食品/药品生产

### 作业指导书要求
| 项目 | 要求 |
|------|------|
| 编写依据 | 工艺规程 |
| 内容覆盖 | 全部操作 |
| 版本控制 | 变更管理 |
| 审核批准 | 质量部门 |

### 卫生控制要求
- 人员卫生规程
- 设备清洁规程
- 环境清洁规程
- 防止交叉污染

## 5. AS9100 航空航天

### 特殊要求
| 项目 | 要求 |
|------|------|
| 关键特性 | 必须标识 |
| 首件检验 | 必须执行 |
| 过程监控 | 记录完整 |
| 可追溯性 | 批次/单件 |

### 顾客特殊要求
- 满足顾客工程规范
- 符合顾客批准程序
- 提交PPAP（适用时）

## 6. 行业标准对照表

| 行业 | 主要标准 | 作业指导书要求 |
|------|----------|----------------|
| 汽车 | IATF16949 | 控制计划关联、FMEA、五大工具 |
| 医疗 | ISO13485 | 批记录、追溯、洁净控制 |
| 食品 | GB14881/GMP | 卫生控制、HACCP |
| 航空 | AS9100 | 首件检验、关键特性 |
| 电子 | ISO9001+客户要求 | 静电防护、ESD控制 |
| 机械 | ISO9001 | 工艺参数、检验标准 |
