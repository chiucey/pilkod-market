# 制造业作业指导书生成器

## 核心功能

### 1. 框架生成
基于行业最佳实践和质量管理体系标准，自动生成符合制造业标准的作业指导书核心框架：
- **基础信息区**：文件标识、版本信息、适用范围
- **作业概述**：目的、范围、引用标准
- **详细作业内容**：工序步骤、质量控制点、安全规范
- **支持性内容**：设备清单、工具清单、异常处理

### 2. 编写方法论
提供四阶段编写流程：
1. **需求锚定**：明确作业目的、法规要求、操作环境
2. **内容开发**：按5W1H原则编写操作步骤
3. **试运行验证**：现场测试、收集反馈、修订完善
4. **持续优化**：定期评审、版本更新

### 3. 内容规范
必须包含的核心要素：
- 作业前准备（人员资质、设备点检、物料确认）
- 核心操作步骤（图文并茂、步骤编号、时限要求）
- 质量控制点（检验标准、判定方法、抽样比例）
- 安全规范（危险源识别、个人防护、应急措施）
- 异常处理（常见问题、原因分析、纠正措施）

### 4. 质量合规
确保文档符合以下标准要求：
- ISO9001:2015 条款7.5.3 文件化信息
- IATF16949 汽车行业质量管理体系
- ISO13485 医疗器械质量管理体系
- GMP 药品/食品生产质量管理规范
- AS9100 航空航天质量管理体系

## 输入参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| industry_type | string | 是 | 行业类型：机械制造/电子装配/汽车零部件/食品加工/化工生产/医疗器械 |
| process_complexity | string | 是 | 复杂度：简单/中等/复杂 |
| quality_standard | array | 否 | 质量标准：ISO9001/IATF16949/ISO13485/GMP/AS9100 |
| include_images | boolean | 否 | 是否包含图文说明（默认true） |
| language | string | 否 | 文档语言：zh-CN/en-US（默认zh-CN） |

## 约束条件

### 内容质量
- **准确性**：技术参数和操作步骤必须准确无误
- **清晰性**：语言简洁明确，避免歧义
- **完整性**：覆盖作业全过程所有关键环节
- **一致性**：术语和格式风格统一

### 实用性
- 文档结构便于现场操作人员快速查阅
- 安全相关内容必须优先标注
- 必须包含版本控制和文档管理机制

### 合规性
- 必须符合用户指定的质量管理体系标准
- 必须符合特定行业的工艺特点和安全要求
- 所有内容必须具有实际可操作性

## 行业特定内容

根据不同行业自动适配：
- **机械制造**：刀具参数、加工余量、精度要求
- **电子装配**：静电防护、焊接温度、检验标准
- **汽车零部件**：过程控制、追溯要求、PPAP提交
- **食品加工**：卫生要求、温度控制、异物防护
- **化工生产**：化学反应安全、个人防护、化学品MSDS
- **医疗器械**：洁净室要求、灭菌参数、批记录
