# 党建公文标题生成技能

## 核心理念

党建公文标题不是文学创作，而是**约束满足问题（CSP）**。成功的标题需要同时满足五大约束：

- **政治约束**：必须嵌入上级文件关键词
- **结构约束**：层级间字数、词性、结构严格对应
- **音韵约束**：尾字押韵或形成节奏
- **逻辑约束**：并列项之间形成"点-线-面"或"过去-现在-未来"的递进
- **创新约束**：90%规范表述 + 10%创新组合

> 生成公式 = 词库 × 骨架 × 校验规则

## 一级标题生成："三段论"骨架

### 标准骨架公式

```
[立场词] + [范围词] + [方向词] —— 通过 + [方法词] + 把 + [定性词+事] + [办/做/落] + [成果词]
```

### 各位置词库

#### 立场词（动词，统一使用）

| 词 | 语义场 | 适用场景 |
|---|--------|---------|
| 坚持 | 定力/一贯性 | 长期工作、原则性问题 |
| 聚焦 | 集中/突破 | 重点攻坚、专项工作 |
| 立足 | 基础/起点 | 基层工作、固本强基 |
| 围绕 | 中心/主线 | 服务中心大局 |
| 紧扣 | 关键/要害 | 问题导向、改革攻坚 |

#### 范围词（双字，形成递进）

| 词 | 维度 | 常见搭配 |
|---|------|---------|
| 全局 | 空间-整体 | 全局出发、全局谋划 |
| 全面 | 空间-覆盖 | 全面覆盖、全面推进 |
| 全力 | 程度-力度 | 全力服务、全力攻坚 |
| 全程 | 时间-过程 | 全程跟进、全程监督 |
| 全员 | 主体-人员 | 全员参与、全员覆盖 |

#### 成果词（单字，尾字，形成递进）

| 词 | 程度 | 语义梯度 |
|---|------|---------|
| 好 | 完成/合格 | 基础层 |
| 实 | 扎实/深入 | 进阶层 |
| 妥 | 稳妥/周全 | 完善层 |
| 细 | 精细/到位 | 质量层 |
| 深 | 深化/拓展 | 发展层 |
| 牢 | 牢固/持久 | 巩固层 |

### 骨架组合示例

```
坚持全局出发 —— 通过完善机制把要事办好
坚持全面覆盖 —— 通过分类施策把难事办实
坚持全力服务 —— 通过助推发展把好事办妥
```

**校验清单**：
- [ ] 立场词统一（坚持×3）
- [ ] 范围词形成递进（全局→全面→全力）
- [ ] 方法词不重复且各有侧重
- [ ] 定性词与"事"搭配合理（要/难/好）
- [ ] 成果词尾字形成递进（好→实→妥）
- [ ] 整体字数一致（±2字以内）

## 一级框架算法

### "以X为Y"+"三力"公式

```
[动词短语A/B/C/D]，[在统一句式中]+[动词]+[X力]
```

**动词短语变体**：
- 以A强B（以信念强信心）
- 于A开B（于变局开新局）
- 化A为B（化有形为有效）
- 用A（在勇当先行中开创发展胜势）

**统一句式**：勇当先行中 / 推进中国式现代化中

**三力词库**：
- 政治定力/思想定力/信念定力
- 韧性活力/创新活力/发展活力
- 共治合力/团结合力/攻坚合力
- 发展胜势/增长胜势/竞争胜势

**生成示例**：

```
基层治理场景：
以信念强信心，在推进基层现代化中淬炼政治定力
于有为变有位，在推进基层现代化中彰显担当活力
化有形为有效，在推进基层现代化中汇聚共治合力
```

### "一流/三不"算法

**格式**：
```
[核心属性]的[维度A] —— 这是我们[动作][主体]的[递进词A]
[核心属性]的[维度B] —— 这是我们[动作][主体]的[递进词B]
[核心属性]的[维度C] —— 这是我们[动作][主体]的[递进词C]
```

**变量说明**：
- 核心属性：一流/高品质/高标准/坚强/过硬
- 维度：环境/服务/平台（吸引→留住→成就）
- 动作：吸引/留住/成就/凝聚/攻坚
- 主体：人才/队伍/组织/群众
- 递进词：不懈追求→不变承诺→不竭动力

**三递进变体**：

| 类型 | 递进词A | 递进词B | 递进词C |
|---------|---------|---------|---------|
| 标准版 | 不懈追求 | 不变承诺 | 不竭动力 |
| 基础版 | 坚实根基 | 核心支撑 | 持续保障 |
| 目标版 | 重要基础 | 关键环节 | 根本保证 |

## 二级标题生成

### 统领字选择矩阵

统领字是一组二级标题的**记忆锚点**：

| 统领字 | 语义场 | 适用场景 | 可搭配数量 |
|--------|--------|---------|-----------|
| 高 | 层级/标准 | 组织建设、顶层设计 | 5+ |
| 用 | 工具/手段 | 方法创新、资源整合 | 5+ |
| 抓 | 力度/重点 | 责任落实、关键少数 | 4+ |
| 强 | 强化/提升 | 能力建设、质量提升 | 4+ |
| 破 | 攻坚/突破 | 问题导向、改革深水区 | 3+ |
| 求 | 目标/成效 | 结果导向、考核评价 | 3+ |
| 以 | 手段/路径 | 方法论、经验总结 | 4+ |
| 服务 | 功能/对象 | 服务型党组织、营商环境 | 3+ |

**选择规则**：
1. 统领字必须能串起3个以上的合理搭配
2. 3个搭配的尾字要形成逻辑闭环
3. 统领字本身必须在党建话语体系内有依据

### "高"字统领词库

| 搭配 | 结构 | 语义 | 使用频次 |
|-----|------|------|---------|
| 高位部署 | 偏正+动宾 | 领导重视、顶层推动 | 高频 |
| 高效运转 | 偏正+动宾 | 机制顺畅、执行有力 | 高频 |
| 高标问效 | 偏正+动宾 | 考核严格、标准提升 | 中频 |
| 高频调度 | 偏正+动宾 | 节奏紧凑、动态管理 | 中频 |
| 高压传导 | 偏正+动宾 | 责任压实、压力到位 | 中频 |

生成规则：`高 + [双字状态词] + [双字动作词]`

### "用"字统领词库

| 搭配 | 结构 | 语义 | 使用频次 |
|-----|------|------|---------|
| 用好 | 动+形 | 质量最优、发挥最大效用 | 高频 |
| 用活 | 动+形 | 状态灵活、机制创新 | 高频 |
| 用准 | 动+形 | 精度到位、靶向施策 | 中频 |
| 用实 | 动+形 | 落地见效、不走过场 | 中频 |
| 用细 | 动+形 | 精细管理、绣花功夫 | 低频 |

生成规则：`用 + [单字形容词] + [名词] + [动词]`

### "三坚"+"XX之X"算法

**格式**：`[动词]+[坚XXX]+[X之X]`

**动词变体**：
- 铸就/锻造/熔铸（精神层面）
- 打牢/夯实/筑牢（基础层面）
- 扛起/担起/肩负（责任层面）

**坚X磐变体**：
- 坚不可摧/坚如磐石/坚不可破（防御性）
- 坚守不渝/坚定不移/坚毅不屈（坚定性）

**XX之X变体**：
- 忠诚之魂/信仰之魂/信念之魂
- 作风之基/能力之基/本领之基
- 担当之责/使命之责/责任之责

**生成示例**：

```
党建场景：
铸就坚不可摧信仰之魂
打牢坚如磐石能力之基
扛起坚守不渝担当之责
```

### 尾字递进矩阵

| 递进类型 | 示例组合 | 逻辑关系 |
|---------|---------|---------|
| 时间维度 | 纾困→集聚→发展 | 救急→蓄能→长远 |
| 空间维度 | 带动建→联建→派驻建 | 辐射→联合→兜底 |
| 程度维度 | 推动→协同→责任 | 动作→协作→约束 |
| 主体维度 | 党委→支部→党员 | 宏观→中观→微观 |
| 过程维度 | 谋划→推进→问效 | 计划→执行→检验 |

## 生成流程

### 标准工作流

```
步骤1：输入解析
    输入：上级文件关键词、本地工作亮点、领导讲话要点
    输出：3个"工作维度"
    工具：关键词提取表、维度映射矩阵

步骤2：一级标题生成
    2.1 选定立场词（根据工作性质：坚持/聚焦/立足）
    2.2 为3个维度匹配范围词（确保递进）
    2.3 匹配方法词（确保不重复、各有侧重）
    2.4 匹配定性词+成果词（确保尾字递进）
    2.5 交叉校验：字数、词性、音韵、逻辑
    输出：3个一级标题

步骤3：二级标题生成（每组3个）
    3.1 选定统领字（根据维度特性）
    3.2 穷举统领字+名词+动词的所有合理组合
    3.3 筛选：字数一致、结构一致、尾字递进
    3.4 校验：至少1个本地创新做法，2个规范表述
    3.5 音韵测试：念一遍，是否顺口
    输出：每组3个二级标题，共9个

步骤4：整体校验
    4.1 竖向校验：统领字是否形成鲜明记忆点
    4.2 横向校验：3个二级标题是否覆盖"点-线-面"
    4.3 层级校验：二级标题是否与一级标题呼应
    4.4 政治校验：是否嵌入足够的上级文件关键词
    4.5 创新校验：是否存在10%的创新组合

步骤5：迭代优化
    5.1 领导修改稿回灌：记录修改点，更新词库
    5.2 上级采用案例归档：纳入"优秀案例库"
    5.3 退稿原因记录：纳入"避坑指南"
```

## 校验规则库

### 硬性校验（一票否决）

| 规则 | 校验方法 | 失败示例 |
|-----|---------|---------|
| 字数一致 | 逐字计数，一级标题±2字，二级标题±1字 | "高位部署强推动"(7字) vs "高效协同运转"(7字) |
| 词性对应 | 标注词性，确保位置一致 | 动宾+动宾+动宾，不可出现动宾+偏正 |
| 结构统一 | 拆解为"修饰语+中心语"，确保层级一致 | "高位部署"(偏正) vs "强推动"(状中) |
| 政治合规 | 检索是否含敏感词、错误表述 | "党建引领一切"（表述不准确） |

### 软性校验（优化项）

| 规则 | 校验方法 | 优化方向 |
|-----|---------|---------|
| 音韵节奏 | 朗读，标注声调 | 避免连续仄声或连续平声 |
| 记忆锚点 | 遮盖测试：能否记住统领字 | 统领字是否足够鲜明 |
| 逻辑闭环 | 画出尾词的逻辑关系图 | 是否存在跳跃或重复 |
| 创新度 | 检索是否为全网首发组合 | 10%创新度是否达标 |

## 常见错误避坑

### "伪对仗"陷阱

| 错误类型 | 示例 | 问题 | 修正 |
|---------|------|------|------|
| 字数伪一致 | "高位推动"(4字) vs "高效协同运转"(6字) | 实际字数不等 | "高位推动" vs "高效运转" |
| 词性错位 | "高位部署"(偏正) vs "强推动"(状中) | 结构不统一 | "高位部署" vs "强力推动" |
| 语义重复 | "全面推进全面覆盖" | "全面"重复 | "全面推进全域覆盖" |
| 逻辑跳跃 | "谋划→执行→总结" | 闭环不完整 | "谋划→推进→问效" |
| 创新过度 | "高能党建" | 无依据、不庄重 | "高质量党建" |

### "打油诗"感来源

- 尾字强行押韵，导致语义扭曲
- 统领字选择过于生僻，无法自然搭配
- 三个二级标题之间缺乏实质差异，仅为凑数
- 过度追求形式，导致内容空洞

**自检**：遮住标题，只看内容，是否还能理解工作逻辑？如果不能，说明形式压倒了内容。
