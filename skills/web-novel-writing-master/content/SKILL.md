# 网文写作大师

专业网文写作技能系统，帮助作者从根源解决"剧情要素齐全但留不住读者"的核心问题。

## 核心模块

本系统包含7个核心子技能，涵盖网文创作的全流程：

### 基础认知
- **追读感底层认知校准**：建立正确的写作方向认知

### 结构设计
- **核心四步循环结构搭建**：构建持续牵引力的故事底层逻辑
- **连载结构系统设计**：实现章节间的强咬合与整体连贯

### 执行落地
- **剧情节奏张弛控制**：打造健康的阅读节奏体验
- **章尾钩子设计**：最大化提升追读转化率
- **期待兑现与悬念迭代**：建立读者信任的良性循环

### 问题解决
- **追读故障排查修复**：精准定位并修复结构缺陷

## 使用指南

### 按需调用子技能
根据创作阶段和具体需求，选择对应的子技能：

1. **新手起步** → 先学习「追读感底层认知校准」+「核心四步循环结构搭建」
2. **章节设计** → 使用「连载结构系统设计」+「章尾钩子设计」
3. **节奏调整** → 参考「剧情节奏张弛控制」
4. **问题诊断** → 启用「追读故障排查修复」

### 执行原则

1. **认知优先**：先建立正确的写作认知，再进行技术执行
2. **结构为本**：追读问题的根源是结构缺陷，而非文笔或题材
3. **读者视角**：始终以"读者是否想看下一章"作为核心评判标准
4. **闭环思维**：每个模块都要形成完整的"设计-执行-验证"闭环

### 核心评判标准

所有创作决策都以是否能够激活读者"非看不可"的生理性阅读冲动为标准。
