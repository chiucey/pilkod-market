# 追读感底层认知校准技能

建立网文写作的核心底层认知，从根源纠正写作方向偏差，解决"剧情要素齐全但留不住读者"的根源性认知问题。

## 核心原理

网文的本质是持续性注意力争夺，追读感的核心是持续激活读者"非看不可"的生理性阅读冲动，而非单章爽点、华丽文笔、宏大设定的零散堆砌。

## 执行流程

### 1. 写作目标锚定

将写作核心导向从「自我内容表达」切换为「读者持续阅读牵引」：
- 每一章动笔前先明确**本章如何推动读者主动点开下一章**
- 将"读者想看什么"置于"我想写什么"之上
- 思考：读者在看完本章后，最想知道什么？

### 2. 追读感标准校验

单章/剧情单元完成后，以**「读者是否会产生'下一章呢？'的强阅读冲动」**为核心评判标准：
- **替代**「这章写得好不好」的自我评价
- **替代**「文笔是否华丽」的表面标准
- **替代**「设定是否宏大」的虚荣指标

### 3. 认知偏差纠偏

摒弃以下错误认知：
- ❌ 追读感 = 节奏快
- ❌ 追读感 = 剧情炸
- ❌ 追读感 = 反转多
- ❌ 追读感 = 冲突强

**正确认知**：追读感的核心是内容间的持续牵引，而非零散爽点的拼接。

## 执行红线

| 禁止行为 | 说明 |
|----------|------|
| 禁止将单章爽点作为核心标准 | 单章爽点只是短期刺激，无法维持持续追读 |
| 禁止将文笔华丽度作为核心标准 | 华丽文笔≠好故事，读者要的是故事吸引力 |
| 禁止脱离读者期待进行内容堆砌 | 自嗨式写作留不住读者 |
| 禁止将追读低迷归咎于外部因素 | 追读问题的根源是结构，不是文笔/题材/平台 |

## 验证清单

完成本章后自检：
- [ ] 本章是否让读者产生了"想知道后续"的冲动？
- [ ] 本章结尾是否停在了"最痒"的位置？
- [ ] 读者的注意力是否被持续牵引而非中断？
- [ ] 是否避免了自嗨式的无效内容输出？
