# 厨房台面石英石和岩板，选哪个？

作者: 西安装修课堂
发布时间: 2022年9月6日

这个问题本身就不成立。石英石和岩板放一块选，前提是钱包决定的，并不是喜好决定的，性能变得次要；资金不允许，了解一下即可。

石英石：成分是石英加树脂等压制的人造石，硬度和耐高温是它做厨房台面的理由，还有重要一点——阻燃、安全，可与食物直接接触。
岩板：要区分陶瓷大板和岩板。过去很多人把陶瓷大板当岩板用，那是一种低级产品；两者工艺和成本天差地别。吸水率、规格、耐磨密度都不同，价格也因设备工艺差异巨大，岩板目前不是寻常百姓能轻松接受的材料。进口岩板价格高到离谱，普通装修使用和国产几乎一样，有钱可以试。

五项对比：
1. 抗划痕：岩板和石英石没太大区别，没人用石英石磨刀，算平手。
2. 抗高温：石英石因抗热才做台面，但和岩板一千多度高温烧制没法比，岩板完胜；石英石内部有树脂，高温会变化，但极少树脂不会燃烧。普通厨房不用防火，可忽略。
3. 抗污：岩板高温压制内部几乎无空隙，任何东西难渗透；石英石再好，酱油倒上24小时也会渗色——勤快人石英石一直新，懒人往往面目全非。
4. 抗磕碰抗摔：石英石完胜，岩板输得彻底。越硬越脆，两者不可兼得，岩板最怕硬物磕碰，剁肉石英石比岩板耐揍。不论用岩板还是石英石，石材下方一定要做垫板，别用各种龙骨，那是人为垫高更容易开裂。
5. 价格：石英石肯定便宜，岩板按薄厚花色不同，是石英石几倍甚至几十倍。

总结：非得二选一，推荐岩板。虽脆，但台面下方做垫板，抗揍能力和石英石区别不大，且永远不渗色。唯一前提是你能承受价格。
