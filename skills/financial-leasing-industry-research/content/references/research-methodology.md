# 金融租赁公司产业研究参考手册

本参考手册提供产业研究方法论的详细补充说明，供研究人员在实际工作中参考使用。

## 附录A：行业分类框架

### A.1 政策导向分类矩阵

| 政策类型 | 典型行业 | 租赁业务建议 |
|---------|---------|-------------|
| 政策鼓励型 | 新能源、算力、芯片、生物医药、高端装备、低空经济 | 积极布局、重点开发 |
| 政策维持型 | 机械制造、精细化工、民生消费、水电气热、公共交通 | 稳健介入、精选客户 |
| 政策收缩型 | 煤炭、钢铁、水泥、房地产、城市建设 | 审慎介入、严控风险 |

### A.2 生命周期分类标准

| 阶段 | 特征 | 典型行业 | 租赁策略 |
|-----|------|---------|---------|
| 导入期 | 高壁垒、爆发式增长 | POE、光刻胶、大硅片 | 精选客户、控制规模 |
| 成长期 | 高壁垒、稳健增长 | 电子化学品、新能源材料 | 积极布局、适度扩张 |
| 成熟期 | 弱周期、一定差异化 | 化肥、氯碱、染料 | 稳健经营、精选客户 |
| 周期行业 | 产品同质化、价格驱动 | 化纤、农药、聚氨酯 | 把握周期、动态调整 |

## 附录B：财务评估指标体系

### B.1 核心财务指标

| 指标 | 计算方式 | 评估要点 |
|-----|---------|---------|
| 毛利率 | （营业收入-营业成本）/营业收入 | 主营业务的利润空间 |
| 净利率 | 净利润/营业收入 | 综合盈利能力 |
| 经营性现金流 | 经营活动现金流入-流出 | 真金白银的偿债能力 |
| 资本开支强度 | 资本支出/营业收入 | 未来投资对现金的占用 |

### B.2 客户分类评估标准

**授信通过标准**：
- 行业：客户群数量较多的景气良好行业
- 市值：30-300亿区间
- 治理结构：专注主业、不搞资本运作
- 股质率：一般不超过30%
- 经营：经营稳健
- 投资：有明确的投资计划
- 负债：债务水平适中、存在腾挪空间

**审慎对待情形**：
- 行业景气度差
- 市值50亿以下审慎对待上市属性
- 资本运作无实际控制人
- 股质率超过50%
- 经营下滑、财务数据异常
- 大额多元化投资、体外投资
- 高负债
- 承租人资质弱、实控人不担保

## 附录C：产业链分析模板

### C.1 产业链分析要素

```
1. 产业链结构
   - 上游：原材料供应
   - 中游：制造加工
   - 下游：终端应用

2. 价值分布
   - 各环节毛利率水平
   - 利润分配格局
   - 价值链瓶颈环节

3. 传导机制
   - 价格传导路径
   - 需求传导路径
   - 周期传导机制

4. 关键节点
   - 核心企业
   - 关键配套
   - 薄弱环节
```

### C.2 产业图谱绘制要素

```
图谱要素：
- 节点：企业/环节
- 边：供应关系、资金关系
- 权重：交易规模、依赖程度
- 属性：企业规模、技术水平、资信状况
```

## 附录D：行业研究信息来源

### D.1 数据来源分类

| 类型 | 来源 | 用途 |
|-----|------|-----|
| 宏观数据 | 国家统计局、海关总署 | 行业整体规模、趋势 |
| 行业数据 | 行业协会、第三方研究机构 | 细分行业分析、竞争格局 |
| 企业数据 | 年报、季报、工商信息 | 客户评估、财务分析 |
| 价格数据 | 大宗商品交易平台、行业网站 | 供需分析、景气判断 |
| 政策数据 | 政府部门官网、公告 | 政策研判、风险预警 |

### D.2 重点跟踪指标

**供给侧指标**：
- 产能规模及变化趋势
- 产能利用率
- 行业集中度
- 环保政策影响
- 重大事件冲击

**需求侧指标**：
- 下游行业景气度
- 出口市场变化
- 替代品/替代成本
- 库存周期

## 附录F：典型案例速查

### F.1 化工行业研究要点

**产业链特点**：强产业链属性，从原材料到终端产品环节清晰

**关键细分领域**：
- 基础化学原料制造（占比约26%）
- 合成材料制造（占比约14%）
- 专用化学产品制造（占比约21%）

**开发策略**：
- 产业链视角：从核心企业向上下游拓展
- 区域视角：以化工园区为载体
- 客户选择：优先进入核心企业供应链的客户

### F.2 电子行业研究要点

**发展趋势**：
- 产业升级：向高附加值领域挺进
- 产业转移：沿海向内陆、境内向境外
- 产业转换：跨界进入新能源等领域

**重点关注**：
- 技术升级带来的设备投资需求
- 产业转移带来的新增产能需求
- 跨界投资带来的融资机会

### F.3 光伏行业研究要点

**技术路线**：
- P型向N型转化
- TOPcon渗透率提升
- HJT、IBC待规模化

**全产业链开发**：
- 组件：年产1GW以上
- 辅材：进入核心组件企业供应链
- 电池片：3GW以上、先进技术
- 硅料硅片：行业前20

**跨界企业评估重点**：
- 股东背景
- 原主业经营及财务状况
- 投资前期进度、技术积累、下游客户资源
