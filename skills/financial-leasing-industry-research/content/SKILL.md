# 金融租赁公司产业研究方法论与体系

本技能为金融租赁公司提供系统化的产业研究框架，涵盖从行业认知到业务赋能的完整链条。

## 核心工作流程

### 阶段一：快速熟悉行业（认知构建）

**政策研判** → **市场空间** → **发展趋势** → **竞争格局**

1. **政策研判**：将行业划分为三类
   - 政策鼓励型：战略性新兴产业（新能源、算力、芯片、生物医药、高端装备、低空经济）、现代服务业
   - 政策维持型：普通制造业（机械制造、精细化工、民生消费）、民生保障行业
   - 政策收缩型：过剩产能（煤炭、钢铁、水泥、矿产）、房地产/基建

2. **市场空间分析**：
   - 存量规模：行业总体规模、二级细分行业占比
   - 增长趋势：历史变化轨迹、未来增长动力

3. **发展趋势研判**：
   - 产业升级：向高附加值领域挺进
   - 产业转移：地理分布变化（如从沿海向内陆）
   - 产业转换：企业主动切换赛道

4. **竞争格局分析**：
   - 集中度水平与形成动因
   - 时点性变化趋势
   - 不同玩家运营模式

### 阶段二：产业链与图谱分析（结构解析）

1. **产业链解析**：
   - 上中下游构成
   - 各环节价值分布
   - 环节间传导机制
   - 利润分配分析

2. **产业图谱绘制**：
   - 关键节点识别
   - 薄弱环节分析
   - 竞合关系梳理

### 阶段三：深度剖析行业（本质挖掘）

**生命周期** → **技术迭代** → **供需格局**

1. **生命周期判断**：
   - 导入期：高壁垒、爆发式增长机会
   - 成长期：高壁垒、稳健快速增长
   - 成熟期：弱周期、一定差异化
   - 周期行业：产品同质化、价格驱动盈利

2. **技术迭代分析**：
   - 主流技术路线及市场份额
   - 新兴技术替代进程
   - 设备投资强度和工艺要求

3. **供需格局分析**：
   - 供给侧：产能、产能利用率、行业集中度
   - 需求侧：行业景气度、出口、替代品
   - 构建供需平衡表，预判景气变化

### 阶段四：财务特征分析（客户评估）

四个关键维度：

| 评估维度 | 核心指标 | 核心问题 |
|---------|---------|---------|
| 盈利空间 | 毛利率 | 是否有足够利润覆盖利息？ |
| 综合效益 | 净利率 | 最终能赚多少钱？ |
| 现金造血 | 经营性现金流 | 是否有真金白银还债？ |
| 未来支出 | 资本开支强度 | 未来投资是否挤占还款？ |

### 阶段五：租赁业务分析（机会识别）

**融资需求分析** → **收益率分析** → **机遇挑战分析**

1. **融资需求类型**：
   - 产能扩张需求（最适合租赁介入）
   - 高息债务置换需求
   - 流动资金补充需求

2. **需求与租赁产品匹配度判断**：
   - 租赁物件充足性
   - 账期需求匹配
   - 价格接受度

## 业务赋能模块

### 行业画像制定

- 行业基础概况（产业链、利润分配、工艺路线、政策）
- 主导因素分析（供需、技术、资金、原材料壁垒）
- 供需格局分析（历史周期、未来展望）
- 景气度展望（1-2年研判）
- 竞争格局分析（空间、梯队、TOP10分析）
- 行业开发策略建议

### 目标客户群梳理

**双视角梳理**：
- 产业链视角：核心企业上下游拓展
- 区域视角：化工园区覆盖、区域禀赋分析

**多维度筛选**：产业园区、上市公司、专精特新、国有客户、注册资本、纳税排名

### 细分行业开发策略

根据产业链驱动核心要素差异化制定策略：
- 上游资源端：偏供给主导、周期性、资源禀赋导向
- 中游制造端：偏技术驱动、差异化、规模效应
- 下游市场端：偏需求主导、成长性、品牌渠道

### 客户分层策略

| 客户层级 | 核心关注点 | 开发策略 |
|---------|-----------|---------|
| 高端客户 | 行业趋势、发展规划 | 行业趋势研读、战略协同 |
| 规模客户 | 经营管理、财务基本面 | 精细分析、长期合作 |
| 一般客户 | 实控人积累、安全生产 | 底线把控、特色产品 |

## 风控赋能模块

### 行业风险管控策略

**动态调整三种态度**：鼓励 / 维持 / 压缩

**景气度分类应用**：
- 高景气（利润增速 > 20%）：加大资产布局
- 弱周期（-20% < 增速 < 20%）：做大基石客群
- 强周期（增速 < -20%）：坚持头部策略

### 预审与调研参与

预审环节：
- 细分行业景气度及特点
- 行业风险提示
- 调研方向和侧重点

调研评审：
- 上市公司动态跟踪（月涨幅超30%预警）
- 年报季报业绩跟踪
- 重大投资动作分析
- 融资环境跟踪

### 风险事件预警

预警内容：
- 行业政策变化
- 重大事件（安全、环保、经营危机）
- 价格异动
- 景气拐点信号
- 同业布局调整

## 输出格式

完成研究后，提供以下产出：

1. **行业研究报告**：涵盖所有分析维度的完整报告
2. **客户名单**：符合租赁准入的目标客户清单
3. **开发策略建议**：具体的业务开发路径和风控要点
4. **风险提示**：行业和重点客户的潜在风险点

## 快速启动提示

当用户提供具体行业名称时，直接进入深度分析流程。
当用户提供客户名单时，结合行业研究进行客户画像分析。
当用户询问行业趋势时，使用发展趋势研判框架进行分析。
