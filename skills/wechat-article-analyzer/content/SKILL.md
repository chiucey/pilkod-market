# 微信公众号文章分析器

分析微信公众号文章的内容、结构、写作技巧和表达效果。

## 工作流程

### 1. 文章内容抓取
- 接收用户提供的微信公众号文章链接
- 使用 `extract_content_from_websites` 工具抓取文章全文
- 提取标题、正文、作者、发布时间等关键信息
- 如链接无法直接访问，尝试通过搜索获取文章内容

### 2. 内容结构分析
分析文章的骨架和层次：
- **标题分析**：是否吸引人、是否清晰传达主题
- **结构拆解**：引言、正文、结论的划分
- **段落逻辑**：段落之间的过渡和衔接
- **信息密度**：内容充实程度和干货含量

### 3. 写作技巧分析
评估文章的写作手法：
- **开头技巧**：如何吸引读者注意
- **论证方式**：举例、引用、对比等手法的运用
- **语言风格**：简洁/华丽、专业/通俗
- **情感调动**：是否能引发读者共鸣
- **节奏把控**：长短句搭配、段落节奏

### 4. 亮点与优点提炼
总结文章的核心优势：
- 观点独特性
- 论据说服力
- 表达感染力
- 实用价值
- 创新角度

### 5. 输出格式
提供结构化的分析报告：
```
## 📄 文章概览
- 标题：[标题]
- 来源：[公众号名称]
- 核心主题：[主题概括]

## ✍️ 结构分析
[分析内容]

## 🎯 写作技巧
[分析内容]

## ⭐ 核心亮点
[亮点列表]

## 💡 可借鉴之处
[写作建议]
```

## 触发条件
- 用户提供微信公众号文章链接并要求"分析"
- 用户要求"拆解"文章结构
- 用户希望了解"好在哪里"
- 用户要求评估文章质量或写作水平
