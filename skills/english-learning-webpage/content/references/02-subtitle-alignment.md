# 字幕对齐与断句

用于把词级 ASR 字幕和可选官方字幕整合为父句与词级高亮数据。

## 作用域

官方字幕只在本步骤使用，用途只有两个：

- 校准 word-level 字幕的识别文本。
- 在同一时间附近辅助校准 word-level 字幕文本；不得把官方字幕中 word-level 没有的内容加入最终学习数据。

本步骤必须输出一个校准后的中间 JSON。后续翻译、固定搭配、连读弱读提示、音频切片、模板注入和页面验证都读取这个中间 JSON，不再直接读取官方字幕。

如果本步骤使用了官方字幕，还必须输出一份可人工查看的 Excel 修改报告，用于汇总实际采用官方文本改动过的词。

## 主轴规则

word-level 字幕永远是学习网页内容主轴：

- 最终学习网页包含哪些句子、哪些词，完全由 word-level 字幕决定。
- word-level 字幕也是默认文本主轴；即使音乐片段或 Whisper 误识别导致局部文本不完美，也优先保留 word-level 内容。
- 官方字幕只按时间戳贴近 word-level 字幕，在相同或相近时间窗口内做文本校准。
- 官方字幕只做低风险校准，例如大小写、明显拼写、标点补全；不要把官方字幕当作绝对正确文本源。
- 官方字幕里多出来的片头歌词、音乐段落、旁白、说话人标签或任何 word-level 没有的词，一律不得插入最终中间 JSON。
- 如果官方字幕缺词，而 word-level 有词，不要删除或覆盖 word-level。
- 如果官方字幕和 word-level 冲突，除非局部匹配置信度很高且属于低风险校准，否则保留 word-level。
- 如果 word-level 是 Whisper Large v3 生成的字幕并跳过音乐片段，这是正常情况；不要用官方 VTT 把被 Whisper 跳过的音乐歌词补回来。

## 推荐路线

如果有官方字幕，需要逐词高亮时，不要做全局官方词序列对齐。应以 word-level 时间轴为主，在每个 word-level 句子或时间窗口内寻找附近官方字幕做局部校准：

```text
word-level 字幕（内容主轴 + 时间准，文本可能错）
        +
官方字幕（只在相近时间窗口内提供校准文本）
        ↓
按时间窗口做局部词序列对齐
        ↓
校准后的 word-level 主轴数据
        ↓
按 word-level 主轴重组父句
```

这样可以同时保留 word-level 的内容范围与逐词时间，并尽量利用官方文本修正识别错误。

如果没有官方字幕，则跳过官方文本校准，直接从 word-level 字幕文本生成父句和词级数据，并在质量说明里标记“文本未经过官方字幕校准”。

## 脚本模板

- 有官方字幕：使用 `scripts/01_align_with_official.py` 作为起点。
- 没有官方字幕：使用 `scripts/02_build_from_wordlevel.py` 作为起点。
- 这两个脚本都应输出同一种中间格式，便于后续流程统一处理。
- 有官方字幕时，`scripts/01_align_with_official.py` 还应输出 `alignment_anomalies.xlsx`，或通过 `--diff-xlsx` 指定报告路径。

## 核心算法

1. 解析 word-level 字幕为 `asr_words`：每个词包含 `word/start/end`。
2. 按 word-level 的句末标点和明显长停顿生成主轴句子或时间窗口。
3. 如果有官方字幕，解析为带 `start/end/tokens` 的官方 cue。
4. 对每个 word-level 时间窗口，只取时间重叠或相近的官方 cue 做局部对齐。
5. 能稳定对应且属于低风险校准的词：可以使用官方词文本 + word-level 时间戳；否则保留 word-level 文本。
6. 官方 cue 中多出来、word-level 时间窗口里没有的词：忽略，不插入。
7. word-level 中找不到官方对应的词：保留 word-level 文本，并计入质量统计。
8. 输出中间 JSON 的词数和内容范围必须与 word-level 主轴一致。

## 断句规则

- 父句按完整句子聚合。
- 只在 `.`, `!`, `?` 或明确标题结尾处分割。
- 不因官方字幕换行、Whisper 行尾、停顿、逗号或短时间间隔切开完整句子。
- 有官方字幕时，先用 word-level 字幕建立粗窗口，再把官方标点校准到词级主轴上；校准后必须重新按句末标点整理父句边界。这样可以修复 word-level 没有句号导致的跨句合并，也可以修复官方标点把一个粗窗口拆成多个完整父句的情况。
- 官方字幕不得插入 word-level 中不存在的词；但当同一时间位置能稳定配对时，应优先采用官方词面文本，保留 word-level 的起止时间。
- 如果没有官方字幕，从 word-level 字幕文本按句末标点合并父句。

## 数字行处理

- SRT/VTT 块中只有第一行纯数字才可视为字幕序号并跳过。
- 时间行后的纯数字内容必须保留为正文词，例如 `50`、`2024`，不能因为 `line.isdigit()` 被误删。
- 百分号属于词面文本的一部分，`50%` 应保留 `%`，但归一化匹配时仍可按 `50` 对齐。

## 时间规则

- 父句 `s/e` 使用该句第一个和最后一个词在原音频中的绝对时间。
- 词级 `w[].s/e` 在最终页面数据里必须改成相对父句切片起点的时间。
- 如果出现 `end <= start` 或时间倒流，先修复词级时间，再进入后续流程。
- 如果大量句子整体错位，优先怀疑字幕不同源，而不是盲目调 padding。

## 质量报告

对齐后至少报告：

```text
官方词总数
正常对齐词数与比例
文本纠错词数与比例
插值词数与比例
丢弃 ASR 多余词数
最长连续插值区间
```

如果插值词超过 10%，提醒用户该素材的逐词高亮可靠性下降。

## 修改词 Excel 报告

当官方字幕参与对齐时，质量报告必须包含一个 Excel 文件，供用户人工检查实际修改过的词。默认文件名建议为 `alignment_anomalies.xlsx`，放在素材目录的 `work` 文件夹中。

模板文件位于 `templates/alignment_anomalies_template.xlsx`。实际生成的报告必须保持同样的列顺序和工作表语义。

Excel 只保留三列：

| 时间戳 | 词级字幕单词 | 官方字幕单词 |
|---|---|---|
| 1:23.45-1:23.70 | whether | weather |

记录规则：

- 只记录最终确实采用官方文本修改了 word-level 的词。
- word-level 和官方字幕冲突但最终保留 word-level：不写入 Excel。
- word-level 多识别或官方字幕缺词但最终保留 word-level：不写入 Excel。
- 官方字幕有词但 word-level 没有：不插入最终数据，也不写入 Excel。
- 时间戳使用 word-level 字幕的词级时间。
- 这份 Excel 是 02 对齐阶段的“实际修改日志”，后续翻译、切片和模板注入不得再直接读取官方字幕。

## 边界情况

- `don't` 与 `do n't`：统一成可匹配形式。
- `I'm` 与 `I am`：可在局部对齐时特殊处理。
- `2024` 与 `twenty twenty-four`：尽量统一数字形式。
- `[Music]`, `[Applause]`, `♪`：作为噪声过滤。
- 口语弱读如 `gonna`, `wanna`：不要强行展开，除非官方文本确实展开且对齐稳定。
