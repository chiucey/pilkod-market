# 交付前验证

用于最终检查页面是否能稳定学习和播放。

## 数据检查

- 每个父句都有 `t/z/s/e/a/w`。
- `z` 不为空，不是占位文本。
- `w` 至少包含一个词。
- 每个词都有 `t/s/e`。
- 词级时间单调递增。
- 父句首词和末词时间落在父句音频切片内。
- `rh` 范围不重叠，且索引没有越界。
- `c` 每句不超过 3 个。

## 字幕检查

- 检查 `02-subtitle-alignment` 产出的中间 JSON：若来源标记为官方校准，最终英文应为校准文本；若来源标记为 word-level only，最终英文来自 word-level 字幕文本，并在交付说明中提示。
- 父句不因逗号、换行或停顿被切断。
- 页面不出现 Azure 或 Whisper 明显错词。
- 插值词比例过高时，在交付说明中提示风险。

## 音频检查

- 第一条父句首词不被切掉。
- 中间随机父句同步正常。
- 最后一条父句结束完整。
- 全句播放能正常停止。
- 选中目标播放能从首词开始，到末词后停止。

## 交互检查

- `全句字幕` 只展开当前父句字幕。
- `全句中文` 只展开当前父句中文。
- `固定搭配` 只展开当前父句固定搭配。
- 完成按钮更新 Header 进度文本和绿色进度条。
- 刷新页面后完成状态仍保留。
- 桌面端可拖选连续词。
- 手机端可点首词和尾词选中范围。
- 复制选中目标可用；失败时有手动复制面板。

## 模板回归

如果修改了模板，先用 `templates/pronunciation_hint_test.html` 或同数据重新生成预览页，确认：

- `rh` 标注贴在对应词或词组上方。
- 换行时提示跟随词组。
- 当前播放词高亮不被选中样式覆盖。
- Header sticky 不遮挡内容。
- 移动端底部操作条不拥挤。

## 技术检查

- 从最终 HTML 提取 `<script>` 后运行 JS 语法检查。
- 输出 HTML 文件名尽量无空格。
- 需要分享时生成 ZIP。
- 保留 `work` 中关键中间文件，方便追查。
