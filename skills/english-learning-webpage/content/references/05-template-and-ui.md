# 模板与交互

用于维护 Daniel 风格学习页的视觉、按钮、移动端交互和模板稳定性。

## 模板优先

- 生成 HTML 时优先使用 `templates/listening_page_template.html`。
- 只替换 `{{TITLE}}`、`{{ID}}`、`{{DATA_JSON}}` 等数据占位符。
- 不要每次重新手写 CSS 和 JS。
- 修改交互或视觉时先改模板，再用参考页回归检查。

## 参考页

`templates/pronunciation_hint_test.html` 是模板回归参考页，覆盖：

- `rh` 词组级连读弱读标注。
- 原字幕上方局部提示。
- 选中目标播放。
- 固定搭配。
- 进度条。
- 移动端底部操作条。

## Daniel 风格

- 背景使用柔和蓝灰渐变。
- 卡片白底，灰蓝细边框。
- 完成状态使用绿色。
- 当前播放词使用明黄色 `#ffe066`。
- 选中目标使用淡绿色。
- 页面应安静、稳定、适合长时间精听，不做营销式 hero 或装饰性卡片堆叠。

## 按钮文案

父句按钮：

- `▶ 全句播放`
- `全句字幕`
- `全句中文`
- `固定搭配`
- `完成`

目标选区按钮：

- `▶ 播放选中目标`
- `复制选中目标`
- `清除`

移动端底部操作条使用短文案：

- `▶ 播放`
- `复制`
- `清除`

## 显示逻辑

- 整句按钮放在父句卡片上方。
- 整句英文字幕和中文翻译显示在按钮下方。
- 父句编号如 `#1` 放在按钮行最左侧，紧挨播放按钮左边。
- 时间戳显示在按钮行右侧，格式为 `3:03–3:05`，无括号、无小数。
- 顶部进度文本靠左，放在 `收起/展开` 按钮右侧。
- `全句字幕` 只切换当前父句自己的 `.wordline`。
- 不显示 `拆分子句`、`播放片段`、`显示字幕`、`显示翻译` 等旧入口。

## 选中目标交互

- 整句字幕必须用词级 span 渲染。
- 桌面端支持拖过一段连续单词选中。
- 手机端支持点第一个词，再点最后一个词选中范围。
- 选中后在当前卡片显示操作条。
- 移动端同时显示底部固定操作条（上下两行结构）。
- 两个操作条都必须包含：复制、播放选中目标按钮、智能底色按钮，以及设置持久化底色高亮的下拉菜单（支持无底色、蓝、橘、绿、红、紫）。
- 智能底色按钮点击后，应读取选中范围左侧相邻单词的持久底色，并自动给选中范围设置一个不同的底色；如果左侧没有单词或没有底色，则从可用底色中随机选择一个。
- 移动端的底色菜单应向上弹出（Drop-up）避免被边缘遮挡。选中底色后立即生效并自动清除选中状态。
- 复制成功后显示短暂的 `已复制` 反馈。
- 如果浏览器拒绝自动复制，显示手动复制面板并自动选中文本。

## Header

- Header 使用 `position: sticky; top: 0`。
- 收起/展开控制 Header 内容。
- 批量完成/重置控制栏与 Header 放在同一个 sticky 容器里。
- sticky 区域底部必须有绿色进度条，随完成比例实时更新。
- 使用 localStorage 保存完成进度。

## JS 注意点

- 单词高亮使用 `requestAnimationFrame`。
- toggle 逻辑写成 `display = (display === 'block') ? 'none' : 'block'`，避免首次点击无效。
- 复制优先使用 `navigator.clipboard.writeText`，并提供隐藏 `textarea` + `document.execCommand('copy')` 兜底。
