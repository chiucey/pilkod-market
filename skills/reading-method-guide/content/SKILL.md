# 阅读方法指导技能

## 核心原则

阅读的核心目标是：**增进理解力**。被动接收信息不是真正的阅读。

## 阅读四层次

### 1. 基础阅读
- 认识字词、理解句意
- 达到"识文断字"的基本能力

### 2. 检视阅读（推荐优先使用）
**在有限时间内快速把握书籍框架**

| 场景 | 方法 |
|------|------|
| 判断是否值得细读 | 书名、序言、目录、索引、出版介绍 |
| 快速了解书籍 | 随意翻阅：重点章节开头结尾 |
| 时间有限时 | 粗读：跳过陌生词汇和难点，保持速度 |

**检视阅读口诀**：看序→翻目→读段→抓核

### 3. 分析阅读
**系统、完整、深入地阅读一本书**

**第一阶段 - 分类与概述**
- 判断书籍类型（虚构/信息/理论/应用）
- 用一句话概括全书主题
- 列出书籍大纲结构
- 找出作者想要解答的核心问题

**第二阶段 - 诠释内容**
- 与作者找到共识（关键词定义）
- 找出作者的主要论述
- 确定作者已解决和未解决的问题

**第三阶段 - 批判性思考**
- 评价之前先确保真正理解
- 区分"不认同"与"不知道"
- 提供有理有据的评价

### 4. 主题阅读
**针对同一主题阅读多本书籍**

1. 收集相关书目，建立书单
2. 初读筛选，锁定核心书籍
3. 多书联动，提炼共同主题
4. 整理分析，形成个人观点

## 阅读四问（必问自己）

| 问题 | 作用 |
|------|------|
| 1. 这本书讲什么？ | 明确主题 |
| 2. 作者细说了什么？ | 理解细节 |
| 3. 这本书有道理吗？ | 批判评价 |
| 4. 这本书跟我有什么关系？ | 实践应用 |

## 指导流程

当用户提供书籍时，按以下步骤提供指导：

```
1. 识别书籍 → 判断类型（虚构/理论/实用/历史等）
2. 匹配层次 → 根据用户目的选择阅读层次
3. 提供方案 → 给出具体阅读步骤和重点
4. 引导提问 → 使用阅读四问引导思考
```

## 书籍类型与阅读策略

| 类型 | 阅读重点 | 推荐层次 |
|------|----------|----------|
| 虚构文学 | 情节、人物、主题、写作技巧 | 检视+赏析 |
| 信息实用 | 问题、解决方案、可操作性 | 检视+分析 |
| 理论学术 | 论证、概念、方法论、证据 | 分析阅读 |
| 历史传记 | 时间线、因果、视角、史料 | 检视+主题 |
| 哲学思辨 | 命题、推理、逻辑、价值观 | 深度分析 |

## 输出模板

为用户提供阅读指导时，按以下格式输出：

```
## 阅读指导：{书名}

### 书籍定位
- 类型：
- 核心主题：
- 适合读者：

### 推荐阅读层次
[选择的阅读层次及理由]

### 阅读路径
1. [具体步骤]
2. [具体步骤]
3. [具体步骤]

### 阅读四问提示
- ❓ 这本书讲什么？
- ❓ 作者细说了什么？
- ❓ 有道理吗？
- ❓ 与我何干？

### 重点关注
[根据书籍类型提醒的阅读重点]
```

## 触发条件

此技能在以下情况被触发：
- 用户询问如何阅读某本书
- 用户想要提升阅读能力
- 用户需要阅读方法指导
- 用户分享书名希望获得阅读建议
