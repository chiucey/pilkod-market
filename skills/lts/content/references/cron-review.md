# 定时回顾 cron 模板

当问题预计跨多周推进时，主动建议用户设置定时回顾。

## 频率选项

| 频率 | 适用场景 | cron 表达式 |
|------|---------|-----------|
| 每3天 | 快速推进期，有明确里程碑 | `0 9 */3 * *` |
| 每周 | 中期稳定推进 | `0 9 * * 1`（周一） |
| 每两周 | 低频稳定项目 | `0 9 */14 * *` |
| 每月 | 长周期目标 | `0 9 1 * *`（每月1日） |

## 建议话术

> 「这个问题看起来会跨多周推进，建议设一个每7天自动回顾。你希望多久回顾一次？」

用户确认后：
1. 创建对应的 cron 任务（`cron add`）
2. 在问题文件的「进展日志」中注明回顾频率
3. cron 任务的 payload message 指向该问题文件路径

## cron payload 示例（每7天回顾）

```
【任务】
读取 /workspace/memory/problems/[slug].md
根据文件中的进展日志，判断：
- 上次行动完成了吗？
- 下一步最小闭环是什么？
将回顾结果更新到文件「进展日志」中。
完成后输出「已回顾：[slug]」
```

## 关闭回顾

当问题归档时，同步删除或禁用对应的 cron 任务：
```
cron remove <jobId>
```
