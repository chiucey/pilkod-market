# 问题记录模板

```markdown
# [问题标题]
状态: 🔴 进行中

## 核心问题
[一句话描述要解决的核心问题]

## 背景
[为什么重要？当前困境是什么？]

## 当前最小闭环
- [ ] [具体行动项]
- [ ] [具体行动项]

## 阻塞与依赖
- [ ] [阻塞项：依赖什么条件才能继续？]

## 进展日志
### YYYY-MM-DD
[记录本次会话的进展、决定和下一步]
```

**使用说明：** 复制此模板，在 `/workspace/memory/problems/` 下创建新文件 `YYYY-MM-DD_slug.md`。
