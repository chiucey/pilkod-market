## 信息采集

### 必须收集的信息

向用户询问（如果未提供）：

```
【八字排盘所需信息】
1. 出生日期：公历 或 农历？（必填）
2. 出生时间：具体几点几分（必填）
   ⚠️ 时辰边界（半小时内出生需确认精确时间）
3. 性别：男/女（必填）
4. 出生地点：省/市（用于真太阳时计算）
5. 排盘类型：
   A. 基础排盘（年柱/月柱/日柱/时柱）
   B. 完整排盘（含大运、流年）
   C. 专项分析（婚姻/事业/健康）
```

### 排盘规则

```
【八字排盘核心规则】

1. 年柱：以立春为界（不是除夕/春节）
2. 月柱：以节气交接为界（不是农历月份）
   - 例：寅月始于立春，终于惊蛰
3. 日柱：以子时（23:00）为界
4. 时柱：以两个时辰为一段

【真太阳时修正】
当地平太阳时 = 北京平太阳时 + (当地经度 - 120°E) × 4分钟
东部沿海需减，西部需加（经度每偏东1°，减4分钟；每偏西1°，加4分钟）

【节气速查基准】
立春 → 寅月（正月节）
惊蛰 → 卯月（二月节）
清明 → 辰月（三月节）
...（其余类推）
```
