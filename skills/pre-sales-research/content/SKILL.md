# 售前企业和行业调研

## 技能定位

本技能帮助售前人员快速完成对目标企业的全面调研，基于**商业模式九宫格（Business Model Canvas）**框架，从9个维度系统性地分析企业，输出结构化的调研报告，为销售提案提供数据支撑。

---

## 商业模式九宫格框架

### 核心9维度

| 序号 | 维度 | 英文名 | 核心问题 |
|------|------|--------|----------|
| 1 | 客户细分 | Customer Segments | 企业在服务谁？有哪些细分客群？ |
| 2 | 价值主张 | Value Propositions | 企业为客户解决什么问题？带来什么价值？ |
| 3 | 渠道通路 | Channels | 企业如何触达客户？销售和交付方式？ |
| 4 | 客户关系 | Customer Relationships | 企业如何维护客户关系？服务模式？ |
| 5 | 收入流 | Revenue Streams | 企业如何赚钱？定价模式和收入结构？ |
| 6 | 核心资源 | Key Resources | 企业有哪些关键资产和核心竞争力？ |
| 7 | 关键业务 | Key Activities | 企业日常核心业务是什么？ |
| 8 | 关键合作 | Key Partnerships | 企业的上下游合作伙伴是谁？生态布局？ |
| 9 | 成本结构 | Cost Structure | 企业的成本结构和主要支出？ |

## 信息采集策略（核心原则）

### 信息源优先级排序

本技能**强制要求**按以下优先级获取信息，确保数据的权威性和时效性：

#### 第一优先级：企业官方信息

| 信息类型 | 获取来源 | 说明 |
|----------|----------|------|
| 企业概况 | 企业官网（About/About Us） | 使命愿景、发展历程 |
| 产品服务 | 企业官网产品页 | 核心产品线、功能特性 |
| 投资者关系 | IR页面、年报、季报 | 财务数据、战略方向 |
| 新闻中心 | 企业官方新闻 | 最新动态、战略发布 |
| 招聘信息 | 招聘页、LinkedIn | 业务布局、人才战略 |

#### 第二优先级：权威行业研究

| 信息来源 | 适用场景 | 权威度 |
|----------|----------|--------|
| 艾瑞咨询 | 中国互联网行业报告 | 最高 |
| 中国信通院 | 互联网行业数据 | 最高 |
| 国家统计局 | 宏观经济数据 | 最高 |
| 麦肯锡 McKinsey | 全球商业洞察 | 最高 |
| BCG 波士顿咨询 | 战略与管理洞察 | 最高 |
| Bain 贝恩 | 行业趋势分析 | 最高 |
| Gartner | 技术与IT领域 | 最高 |
| IDC | 硬件与软件市场 | 高 |

#### 第三优先级：专业媒体与社区

| 信息来源 | 适用场景 | 说明 |
|----------|----------|------|
| 36氪 | 中国科技与创业生态 | 快、准、深 |
| 虎嗅 | 商业分析与评论 | 深度洞察 |
| 钛媒体 | 科技与商业融合 | 前沿趋势 |
| 雪球 | 上市公司分析 | 投资者视角 |
| IT桔子 | 投融资数据 | 融资历史、股东背景 |
| 天眼查/企查查 | 工商信息 | 股权结构、高管团队 |

#### 第四优先级：补充信息源

- 行业展会与峰会资料
- 学术论文与研究报告
- 行业协会发布数据
- 竞品官网与公开资料

### 信息采集规则

1. **时效性要求**：优先获取近12个月内的数据
2. **交叉验证**：关键数据需从2个以上独立来源验证
3. **数据标注**：所有信息需标注来源和时间
4. **排除噪音**：过滤软文、PR稿件、未经证实的小道消息

## 调研流程

### 第一步：确认调研目标

用户需要提供：
- **目标企业名称**
- **调研目的**（初次接触 / 深入合作 / 竞品分析）
- **行业背景**（如已知）

### 第二步：行业背景分析

在分析具体企业前，先构建行业全景：

1. **行业规模与增速**：通过国家统计局、艾瑞等获取市场规模数据
2. **行业生命周期**：判断行业所处阶段（导入/成长/成熟/转型）
3. **政策环境**：通过政府官网、智库了解政策导向
4. **技术趋势**：通过 Gartner、技术博客了解技术演进
5. **行业痛点**：通过行业报告、专家访谈提炼共性挑战

### 第三步：信息采集

按照上述**信息源优先级**执行采集任务，优先使用：
- `batch_web_search` 并指定权威来源
- `extract_content_from_websites` 抓取企业官网和行业报告
- `extract_pdfs_key_info` 提取财报和研报关键信息

### 第四步：九宫格分析

对采集的信息进行结构化分析，填充9个维度，每个维度需体现**行业特点**。

### 第五步：洞察提炼

- 识别企业痛点和行业痛点的交叉点
- 发现基于行业趋势的合作机会
- 评估竞争态势和差异化定位
- 输出与行业背景紧密结合的行动建议

## 行业特点与痛点分析框架

每个行业的调研报告都应包含以下行业层面的分析：

### 行业特征维度

| 分析维度 | 具体内容 |
|----------|----------|
| 行业定位 | 产业链位置、细分赛道、上游供应、下游客户 |
| 市场格局 | 行业集中度、梯队分布、竞争态势 |
| 发展周期 | 导入期、成长期、成熟期、衰退/转型期 |
| 技术驱动 | 核心技术路线、创新方向、技术成熟度 |
| 政策影响 | 监管政策、扶持政策、限制政策 |

### 行业通用痛点

| 痛点类型 | 描述 |
|----------|------|
| 成本压力 | 原材料上涨、人力成本增加、运营费用高企 |
| 竞争加剧 | 同质化竞争、价格战、客户争夺激烈 |
| 技术升级 | 数字化转型、技术迭代、人才短缺 |
| 合规风险 | 监管趋严、合规成本增加、法律风险 |
| 客户变化 | 需求升级、体验期望提高、忠诚度下降 |
| 供应链挑战 | 供应链不稳定、物流成本、库存管理 |

### 行业特定痛点（按行业补充）

在通用痛点基础上，根据具体行业特点补充：
- **制造业**：产能过剩、环保压力、招工难
- **零售业**：流量红利消退、线下门店冲击、电商竞争
- **金融业**：利率下行、不良资产、监管科技
- **互联网**：用户增长见顶、变现压力、数据安全
- **医疗健康**：研发周期长、审批严格、集采降价

## 使用指南

### 典型使用场景

1. **售前初次接触**：了解目标企业的基本情况和痛点
2. **深入合作评估**：全面分析合作机会和风险
3. **竞品分析**：对比目标企业与竞争对手的差异
4. **行业研究**：了解特定行业的发展趋势和投资机会
5. **客户画像构建**：为精准营销提供企业画像

- **结构化报告**：Markdown格式的完整调研报告

- **行动清单**：分优先级的待办事项列表
- **竞品对比表**：多维度对比分析表格

## 常见问题处理

### Q1：用户只提供企业名称怎么办？

**处理方式**：先通过企业名称进行初步信息采集，尝试获取以下信息：
- 企业官网基本信息
- 天眼查/企查查工商信息
- 行业媒体相关报道
- 招聘平台上的业务描述

然后向用户确认以下信息：
- 调研目的（初次接触/深入合作/竞品分析）
- 是否有关注的特定痛点或产品方向
- 是否已有行业背景信息

### Q2：用户要求调研多家企业怎么办？

**处理方式**：
1. 首先确认用户的核心诉求（对比分析/选择最优/全面了解）
2. 如果是对比分析，优先确定对比维度
3. 按照优先级逐家分析，确保每家都达到基本调研深度
4. 最后汇总对比，输出综合结论

### Q3：信息源不足或数据陈旧怎么办？

**处理方式**：
1. 标注信息来源和时间，说明数据局限性
2. 尝试多个替代信息源进行交叉验证
3. 基于现有信息进行合理推断，但需明确标注
4. 建议用户提供内部信息或安排实地访谈

### Q4：用户要求调研非中国企业怎么办？

**处理方式**：
1. 使用英文关键词搜索英文信息源
2. 优先使用英文官方信息源和英文行业报告
3. 参考 Bloomberg、Reuters、华尔街日报等英文媒体
4. 适当调整分析框架，考虑不同市场的商业模式差异
