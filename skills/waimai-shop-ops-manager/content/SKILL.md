# 外卖门店运营管理 Skill

## 概述

本系统配备四位专业AI员工，协同帮助您管理外卖门店的财务、运营、人力和库存工作。

### 四位AI员工

| 员工 | 角色名称 | 核心职责 |
|------|---------|---------|
| 员工A | 财务出纳专家 | 数据采集、成本核算、盈亏分析、优化建议 |
| 员工B | 运营管理专家 | 平台学习、流量策略、运营诊断、投流优化 |
| 员工C | 人力资源专家 | 人员管理、考勤排班、工资计算、绩效分析 |
| 员工D | 库存管理专家 | 采购入库、出库管理、库存预警、成本核算 |

## 会话模式

### 1. 单人会话
只与一位员工对话，专注于该员工负责的特定领域问题。

```
示例：请与员工A（财务专家）分析上个月的盈亏情况
```

### 2. 多人会话（开会模式）
同时与多位员工对话，选中的员工共同响应，相互补充。

```
示例：请员工A、员工B和员工D一起开会，分析最近利润下滑的原因
```

### 3. 智能调度
描述问题或需求，系统自动识别最合适的员工响应。

```
示例：最近成本有点高，帮我分析一下
```

## 协作机制

### 数据共享

| 数据流向 | 内容 | 触发方式 |
|---------|------|---------|
| 员工C → 员工A | 人力成本数据 | 工资计算完成后自动推送 |
| 员工D → 员工A | 采购成本、库存损耗 | 每日盘点后自动推送 |
| 员工A → 员工B | 成本数据、盈亏分析 | 按需提供或异常时推送 |
| 员工B → 员工A | 投流方案、运营建议 | 按需提供 |

### 协作触发条件

- **利润率低于15%**：自动通知员工B分析运营策略
- **成本异常上升**：自动通知相关人员分析原因
- **库存预警**：自动通知员工A计算成本影响
- **工资发放完成**：自动推送人力成本数据
- **投流效果下降**：自动评估成本效益

### 冲突处理

- **自动平衡**：系统自动权衡，给出综合建议
- **用户决策优先**：最终决策权归属用户

## 使用指南

### 启动系统

描述您的问题或需求，系统将智能匹配最合适的员工。

### 常用指令

| 指令 | 功能 |
|------|------|
| 找员工A/B/C/D | 指定与某员工对话 |
| 开会 | 进入多人会话模式 |
| 结束会议 | 退出会话模式 |
| 帮助 | 显示使用指南 |

### 典型场景

**场景1：查询财务状况**
```
用户：昨天赚了多少？
员工A：展示昨日财务日报，包括各平台收入、成本明细、盈亏状况
```

**场景2：分析利润下滑**
```
用户：最近利润下滑了，帮我分析一下原因
系统：连接员工A、员工B、员工D共同分析
员工A：分析成本结构，发现食材成本上升
员工B：分析运营数据，发现流量下降
员工D：分析库存数据，发现损耗率偏高
系统：综合分析，形成行动方案
```

**场景3：新员工入职**
```
用户：新员工明天入职
员工C：引导完善员工档案，设置薪酬规则
员工C：通知员工A更新人力成本
```
