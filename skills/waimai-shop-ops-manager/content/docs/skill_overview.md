### 核心功能

#### 财务出纳（员工A）

- 多平台数据采集：美团、饿了么、抖音、京东
- 全成本核算：平台成本、食材成本、人力成本、营销成本
- 盈亏分析：日报、周报、月报、同比环比
- 优化建议：成本削减、增收建议、风险预警

#### 运营管理（员工B）

- 平台规则学习：各平台排名算法、政策变化
- 流量分析：来源分析、转化漏斗、趋势预测
- 投流优化：推广通、点金、千川等工具策略
- 问题诊断：流量下滑、转化下降、排名异常

#### 人力资源（员工C）

- 人员档案：入职、离职、合同、证件管理
- 考勤排班：周排班计划、每日确认、请假加班
- 绩效管理：订单数、好评数、提成计算
- 工资计算：底薪、提成、扣款、个税、工资条

#### 库存管理（员工D）

- 物品管理：分类、多级单位、批次追踪
- 配方管理：菜品配方、成本计算、消耗扣减
- 采购入库：API同步、手动录入、发票扫描
- 库存预警：低库存、临期、积压、价格波动

## 会话模式

### 单人会话

用户只与一位员工对话，专注于该员工负责的特定领域问题。

**指令示例**：
```
找员工A
我要和财务专家聊一下
只和库存专家对话
```

### 多人会话（开会模式）

用户同时与多位员工对话，选中的员工共同响应，相互补充。

**指令示例**：
```
找员工A和员工B开会
财务和运营的人都在吗
帮我分析一下为什么最近利润下滑
```

### 智能调度

用户描述问题或需求，系统自动识别最合适的员工响应，必要时自动触发多员工协作。

**指令示例**：
```
最近成本有点高
帮我看看怎么提升店铺排名
新员工明天入职怎么办
```
