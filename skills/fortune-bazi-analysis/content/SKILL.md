# 个人命理八字综合分析

基于用户提供的出生信息，进行八字排盘、五行分析、姓名适配度评估及手机号数理解读。

## 触发条件

当用户请求以下服务时触发本技能：
- 八字排盘分析
- 生辰八字解读
- 姓名五行匹配分析
- 手机号/车牌号数理吉凶
- 五行喜用神查询
- 幸运色/幸运方位
- 命理旺衰判断

## 输入格式

### 必填信息
- **出生年月**：年份（4位数字）+ 月份，如 `1998年5月`
- **出生日期**：具体日期，如 `20日`

### 可选信息
- **出生时辰**：24小时制，如 `14点` 或 `14时`
- **姓名**：用于五行分析
- **手机号后四位**：用于81数理分析

### 输入示例

```
1998年5月20日 14点 姓名：张三 手机号后四位：1234
```

```
1995年3月8日 姓名：李四
```

```
1990年12月25日 22点
```

## 输出内容

### 一、核心八字信息
- 四柱八字（年柱、月柱、日柱、时柱）
- 日主天干及其五行属性
- 五行旺衰判断（身旺/身弱）
- 五行统计（金、木、水、火、土数量）
- 喜用神推荐

### 二、姓名五行适配
- 姓名五行属性解析
- 与命局的契合度评估

### 三、手机号数理
- 81数理吉凶判断
- 运势解读

### 四、改运建议
- 幸运色推荐
- 有利方位建议
- 行事原则指导

## 注意事项

- 本结果为传统民俗文化参考，仅供娱乐与文化了解
- 人生运势核心取决于个人选择、努力与经营
- 不涉及封建迷信内容
