# immune translation conventions

Use these conventions when translating immunology content into Chinese. Prefer established clinician-facing wording over literal translation.

## 1. immune pathways and signaling
- signaling pathway -> 信号通路
- pathway activation -> 通路激活
- pathway inhibition/blockade -> 通路抑制 / 阻断
- downstream signaling -> 下游信号传导
- transcriptional program -> 转录程序
- immune dysregulation -> 免疫失调
- immune homeostasis -> 免疫稳态
- inflammatory cascade -> 炎症级联反应
- crosstalk -> 交互作用

Common mappings:
- JAK-STAT signaling -> JAK-STAT 信号通路
- NF-kB signaling -> NF-kB 信号通路
- MAPK pathway -> MAPK 通路
- PI3K-AKT pathway -> PI3K-AKT 通路
- mTOR signaling -> mTOR 信号通路
- type I interferon pathway -> I 型干扰素通路
- complement cascade -> 补体级联反应

## 2. cytokines, chemokines, and receptors
- cytokine -> 细胞因子
- chemokine -> 趋化因子
- receptor occupancy -> 受体占有率
- ligand binding -> 配体结合
- soluble receptor -> 可溶性受体
- shedding -> 脱落
- neutralization -> 中和

Translate classes in Chinese but keep standardized symbols in English when they are the conventional form:
- interleukin-6 (IL-6) -> 白细胞介素-6（IL-6）
- tumor necrosis factor (TNF) -> 肿瘤坏死因子（TNF）
- interferon-gamma (IFN-gamma) -> 干扰素-gamma（IFN-gamma）
- transforming growth factor-beta (TGF-beta) -> 转化生长因子-beta（TGF-beta）

## 3. immune cells and functional states
- T cell -> T 细胞
- B cell -> B 细胞
- plasma cell -> 浆细胞
- dendritic cell -> 树突状细胞
- macrophage -> 巨噬细胞
- neutrophil -> 中性粒细胞
- eosinophil -> 嗜酸性粒细胞
- basophil -> 嗜碱性粒细胞
- natural killer cell -> 自然杀伤细胞
- regulatory T cell (Treg) -> 调节性 T 细胞（Treg）
- helper T cell -> 辅助性 T 细胞
- cytotoxic T cell -> 细胞毒性 T 细胞
- exhausted T cell -> 耗竭 T 细胞
- memory B cell -> 记忆 B 细胞
- plasma blast -> 浆母细胞

Functional verbs:
- recruit -> 招募
- infiltrate -> 浸润
- prime -> 启动致敏 / 启动
- expand -> 扩增
- differentiate -> 分化
- polarize -> 极化
- deplete -> 清除 / 耗竭式清除（按上下文）
- restore function -> 恢复功能

## 4. checkpoints, co-signaling, and therapeutic classes
- immune checkpoint -> 免疫检查点
- checkpoint blockade -> 免疫检查点阻断
- co-stimulatory receptor -> 共刺激受体
- co-inhibitory receptor -> 共抑制受体
- ligand-receptor interaction -> 配体-受体相互作用

Common molecules:
- programmed cell death protein 1 (PD-1) -> 程序性死亡蛋白 1（PD-1）
- programmed death ligand 1 (PD-L1) -> 程序性死亡配体 1（PD-L1）
- cytotoxic T-lymphocyte-associated protein 4 (CTLA-4) -> 细胞毒性 T 淋巴细胞相关蛋白 4（CTLA-4）
- lymphocyte activation gene 3 (LAG-3) -> 淋巴细胞活化基因 3（LAG-3）
- T-cell immunoglobulin and mucin-domain containing-3 (TIM-3) -> T 细胞免疫球蛋白和黏蛋白结构域蛋白 3（TIM-3）
- T-cell immunoreceptor with Ig and ITIM domains (TIGIT) -> 含 Ig 和 ITIM 结构域的 T 细胞免疫受体（TIGIT）

Therapeutic classes:
- monoclonal antibody -> 单克隆抗体
- bispecific antibody -> 双特异性抗体
- fusion protein -> 融合蛋白
- cell therapy -> 细胞治疗
- CAR-T cell therapy -> CAR-T 细胞治疗
- antibody-drug conjugate -> 抗体偶联药物
- small-molecule inhibitor -> 小分子抑制剂

Keep specific agent names in English.

## 5. biomarkers and translational readouts
- biomarker -> 生物标志物
- companion diagnostic -> 伴随诊断
- target engagement -> 靶点结合 / 靶点作用证据
- pharmacodynamic marker -> 药效学标志物
- immune signature -> 免疫特征
- gene expression profile -> 基因表达谱
- single-cell RNA sequencing -> 单细胞 RNA 测序
- flow cytometry -> 流式细胞术
- multiplex assay -> 多重检测
- spatial transcriptomics -> 空间转录组学

## 6. disease-area conventions
Prefer the following disease framing when relevant:
- autoimmune disease -> 自身免疫性疾病
- immune-mediated inflammatory disease -> 免疫介导性炎症性疾病
- inflammatory bowel disease -> 炎症性肠病
- rheumatoid arthritis -> 类风湿关节炎
- systemic lupus erythematosus -> 系统性红斑狼疮
- atopic dermatitis -> 特应性皮炎
- psoriasis -> 银屑病
- multiple sclerosis -> 多发性硬化
- asthma -> 哮喘
- ulcerative colitis -> 溃疡性结肠炎
- Crohn's disease -> 克罗恩病

## 7. trial and efficacy phrasing in immune disease studies
Prefer these renderings when supported by the source:
- met the primary endpoint -> 达到主要终点
- key secondary endpoint -> 关键次要终点
- treatment response -> 治疗应答
- durable response -> 持久应答
- remission -> 缓解
- relapse -> 复发
- flare -> 疾病活动加重 / 急性发作
- steroid-sparing effect -> 激素减量效应
- safety profile -> 安全性特征
- adverse event of special interest -> 特别关注的不良事件

## 8. abbreviation policy
- Expand on first mention when certain.
- Keep canonical abbreviations in English when they are the dominant scientific form.
- Do not invent expansions for rare assay names, exploratory biomarkers, or internal compound codes.

## 9. wording to avoid
Avoid overly literal choices when a conventional clinical phrasing exists.
- “immune attacking itself” -> prefer 自身免疫反应 / 免疫介导损伤 depending on context
- “signal road” -> never; use 信号通路
- “drug worked better” -> prefer 疗效更优 / 显示更佳疗效 / 提高应答率 depending on source

## 10. tie-breaking rule
When more than one Chinese rendering seems possible, choose the option that is:
1. most standard in Chinese medical literature,
2. least likely to distort mechanism,
3. most readable to clinicians.
