## 三、新消费品牌BD实操规律

### 3.1 BD窗口极短，核心在"预测"而非"追击"

| 信号 | 到上市时间 | BD含义 |
|------|-----------|---------|
| 年营收过10亿 | 2-4年 | 🔴 **还有时间，但需立即行动** |
| 线下门店大规模扩张 | 2-4年 | 🔴 **渠道扩张，值得关注** |
| 进入天猫/京东/抖音头部 | 1-3年 | 🟡 **渠道验证，窗口已窄** |
| CFO引入（有IPO经验） | <1-2年 | 🔴 **最后窗口，几乎来不及** |
| 辅导备案公示 | 0 | ⚫️ **窗口已关闭** |

### 3.2 为什么"年营收过10亿"是最强信号

从真实案例看：
- 泡泡玛特：2019年营收过10亿 → 2020年上市（间隔1年）
- 完美日记：2020年营收过50亿 → 2020年上市（间隔1年）
- 奈雪的茶：2019年营收过20亿 → 2021年上市（间隔2年）

**年营收过10亿意味着：1）商业模式验证 2）有规模化能力 3）IPO故事更完整。这是比CFO引入更早、更有价值的信号。**

### 3.3 新消费品牌企业的"盈利能力"

| 企业 | 创立到上市 | 上市时营收 | 上市时利润 | 上市时毛利率 |
|------|-----------|-----------|-----------|-----------|
| 泡泡玛特 | 10年 | 25亿 | 5亿 | 65% |
| 完美日记 | 4年 | 50亿 | -5亿 | 60% |
| 奈雪的茶 | 6年 | 30亿 | -2亿 | 30% |

**新消费品牌企业的特点是：品牌驱动、渠道创新、周期性强。BD时需要关注企业的"品牌力"和"渠道能力"，而不是短期盈利。**

## 五、BD紧迫性评分

```
BD紧迫性 = 预警信号加权之和 − 风险信号扣分

⚠️ 核心变化：CFO引入从权重20降为10！
   因为CFO引入距离上市通常<1-2年，此时BD已几乎无操作空间
   CFO引入的真正价值是"确认该企业会上市"，而不是"还有时间BD"

评级：
  ≥40 → A级（Phase 4，全力推进）
  30-39 → B级（Phase 3，保持接触）
  20-29 → C级（Phase 3，偶尔接触）
  10-19 → D级（Phase 2，建立认知）
  <10 → E级（Phase 1，观察）

⚠️ 确认信号出现 → BD紧迫性=0，标记"窗口已关闭"
```
