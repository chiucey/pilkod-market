## 一、行业定义

动力电池与储能是新能源核心赛道。动力电池为新能源汽车、储能系统提供电能，储能则覆盖电网侧、工商业和户用场景。2026年固态电池/钠离子电池技术加速迭代，大储需求爆发。

## 二、基于真实案例的IPO路径

### 2.1 宁德时代（300750.SZ）— 24天过会，全球第一

| 时间 | 事件 | 信号类型 | 距上市 |
|------|------|---------|---------|
| 2011.12 | 曾毓群从ATL分拆创立，注册资金100万 | — | 7年前 |
| 2012 | **攻克宝马800页德文技术要求**，进入宝马供应链 | 🔔**头部客户突破（权重18）** | **6年前** |
| 2012 | ATL子公司宁德新能源持股15%，提供技术和客户基础 | — | 6年前 |
| 2015 | ATL以8900万转让15%股权给宁波联创（裴振华），彻底切割日资 | — | 政策应对 |
| 2015 | **君联/云峰/深创投/博裕/TCL创投/华西村/七匹狼等数十家机构投资** | 🔔**一级市场密集投资（权重18）** | **3年前** |
| 2017 | 装机量11.84GWh，超越松下全球第一 | 🔔**行业地位确立** | 1年前 |
| **2018.06** | **创业板上市（24天过会）** | 📌**确认信号** | **BD窗口关闭** |

**BD窗口复盘：宁德时代的BD窗口其实在2012年攻克宝马供应链时就已经打开了，但真正密集的产业资本认可在2015年（数十家机构抢份额）。从产业资本认可到上市仅3年——BD窗口极短。二级市场的邓晓峰、李晓星等人2018年还能买入，说明2024年行业共识已形成后，二级市场仍然有活跃度。但一级市场的BD窗口在2015年后已经关闭。**

### 2.2 中创新航（03931.HK）— 从顶峰跌落到重生

| 时间 | 事件 | 信号类型 | BD启示 |
|------|------|---------|--------|
| 2007 | 空空导弹研究院孵化天空能源（洛阳） | — | Phase 1 |
| 2009 | 中航工业集团投资成立中航锂电 | 🔔**产业资本** | 国企启动 |
| 2012 | 装机量全国第一，工信部八家重点支持 | 🔔**行业地位** | 但也是产品单一的风险 |
| 2015.09 | 与金坛区政府签约，金坛建产业园 | 🔔**产能建设/政府批地** | |
| 2015.12 | 补贴政策突变，三元电池崛起 | ⚠️**风险信号（致命）** | 产品路线被市场抛弃 |
| 2016 | 营收14亿顶峰 | — | 顶峰即转折 |
| 2017 | 利润从1.1亿→亏损3.3亿 | ⚠️**风险兑现** | |
| 2018 | 亏损7亿，宇通客车切掉所有订单 | ⚠️**核心客户流失（致命）** | — |
| **2018.08** | **刘静瑜（原天马微电子总经理）空降任董事长** | 🔔**管理层大换血（权重20）** | **极强转折信号** |
| 2019.03 | 成飞集成ST集成，决心甩包袱 | — | 母公司被拖累 |
| 2019 | 金坛区政府成为大股东，股权多元化 | — | 体制激活 |
| 2019-2021 | 连续引入**红杉凯辰、小米长江、领汇基石**等 | 🔔**知名VC入局** | 一级市场重新认可 |
| 2021.11 | 改名中创新航 | — | 品牌重塑 |
| **2022** | **港股IPO** | 📌**确认信号** | **BD窗口关闭** |

**BD窗口复盘：中创新航的案例揭示了动力电池行业的独特风险——**产品路线错误是致命的**（铁锂vs三元）。中航锂电2016年到达顶峰但产品路线没跟上，2018年崩盘。BD在做动力电池企业时，不仅要看营收，更要看技术路线是否匹配行业趋势。刘静瑜2018年空降是转折点，但到2022年才上市，中间4年主要是"修复"。**

## 三、动力电池行业BD实操规律

### 3.1 动力电池BD的独特风险

| 风险 | 说明 | 真实案例 |
|------|------|---------|
| **产品路线被市场抛弃** | 致命风险，技术迭代快 | 中航锂电铁锂→三元，2018年崩盘 |
| **核心客户流失** | 比亏损更可怕 | 宇通2018年切掉中航锂电全部订单 |
| **补贴政策突变** | 政策依赖度极高 | 2016年三元电池崛起补贴倾斜 |
| **母公司拖累** | 子公司独立性差 | 中航锂电拖累成飞集成ST |

### 3.2 BD信号的真实时间线

| 信号 | 到上市时间 | BD含义 |
|------|-----------|---------|
| 攻克头部车企供应链（宝马/大众/特斯拉） | 3-6年 | 🔴 **核心信号** |
| 产业资本+知名VC密集投资 | 2-4年 | 🟡 窗口很窄 |
| 大额融资（单笔≥10亿） | 1-3年 | 🟡 窗口极窄 |
| CFO引入 | <1-2年 | ⚠️ 几乎来不及 |
| GWh级产能投产 | 1-2年 | ⚠️ 几乎来不及 |
| 辅导备案公示 | 0 | ⚫️ 窗口关闭 |
