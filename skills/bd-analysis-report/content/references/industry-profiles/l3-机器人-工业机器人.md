## 一、行业定义

工业机器人是制造业自动化的核心装备，包括多关节机器人、协作机器人、SCARA、Delta机器人等。核心部件包括控制器（大脑）、伺服系统（肌肉）、减速器（关节）。2026年国产替代加速，AI+工业机器人和具身智能是新方向。

| 类型 | 应用场景 | 代表企业 |
|------|---------|---------|
| 六轴机器人 | 焊接、搬运、装配 | 埃斯顿、汇川技术 |
| SCARA | 3C电子、轻负载 | 汇川技术、埃斯顿 |
| 协作机器人 | 人机协作场景 | 优必选、节卡 |
| 焊接机器人 | 汽车制造、重工 | 埃斯顿（收购Cloos） |

## 三、工业机器人BD实操规律

### 3.1 行业特征：长周期，核心部件是关键

| 特征 | 说明 | BD影响 |
|------|------|--------|
| **核心部件决定竞争力** | 控制器、伺服、减速器占成本70% | 有核心部件自研能力的企业更有价值 |
| **客户验证周期长** | 汽车/3C客户验证需1-2年 | 一旦验证通过，订单持续 |
| **并购是快速路径** | 埃斯顿收购Cloos/Trio快速获得技术 | 关注有并购能力的企业 |
| **出海是增长曲线** | 埃斯顿海外收入占比34% | 有海外布局的企业成长性更好 |

### 3.2 BD信号时间线

| 信号 | 到上市时间 | BD含义 |
|------|-----------|---------|
| 核心部件（伺服/控制器）量产 | 5-12年 | 🔴 最早信号 |
| **核心部件市占率突破** | 3-7年 | 🔴 **核心信号** |
| 进军机器人本体制造 | 3-5年 | 🟡 业务转型 |
| 头部客户（汽车/3C）批量订单 | 2-3年 | 🟡 窗口收窄 |
| CFO引入 | 1-2年 | ⚠️ 几乎来不及 |
| 辅导备案 | 0 | ⚫️ 关闭 |

### 3.3 为什么CFO引入权重需要调整

与大分子创新药类似，工业机器人企业的CFO引入通常距离上市<1-2年：
- 埃斯顿：2015年上市，CFO信息未公开披露（可能更早）
- 汇川技术：2010年上市，CFO信息未公开披露

**CFO引入不是"还有时间BD"，而是"企业已经决定上市了"。** 真正有价值的BD信号是**核心部件量产+市占率突破**。
