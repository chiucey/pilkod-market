## 一、行业定义

集成电路是国产替代的核心赛道，是以芯片设计、晶圆制造、封装测试为核心的半导体产业链。其本质是通过技术创新实现芯片自主可控，打破国外垄断。

### 1.1 核心特征

| 特征 | 说明 | 代表企业 |
|------|------|---------|
| 国产替代 | 打破国外垄断，政策驱动 | 中芯国际(国产代工龙头) |
| 资本密集 | 晶圆厂投资超百亿 | 中芯国际(累计投资超千亿) |
| 技术壁垒高 | 先进制程难度大 | 北方华创(刻蚀设备) |
| 周期性强 | 受下游需求影响大 | 所有集成电路企业 |

### 1.2 三级细分赛道

| 三级细分 | 代表产品/应用 | BD优先级 | 上市通道 | 典型IPO案例 |
|---------|------------|---------|---------|-----------|
| **芯片设计-数字** | SoC/CPU/GPU/FPGA | ⭐⭐⭐ | 科创板 | 海光信息(科创板)、寒武纪(科创板) |
| **晶圆制造** | 先进制程/成熟制程 | ⭐⭐⭐ | 科创板/A股 | 中芯国际(科创板/港股) |

## 三、集成电路BD实操规律

### 3.1 BD窗口极短，核心在"预测"而非"追击"

| 信号 | 到上市时间 | BD含义 |
|------|-----------|---------|
| 进入华为/车企/大厂供应链 | 2-5年 | 🔴 **还有时间，但需立即行动** |
| 大基金/国家大基金投资 | 2-4年 | 🔴 **国家认可，值得关注** |
| 流片成功（工程样片） | 1-3年 | 🟡 **技术验证，窗口已窄** |
| CFO引入（有IPO经验） | <1-2年 | 🔴 **最后窗口，几乎来不及** |
| 辅导备案公示 | 0 | ⚫️ **窗口已关闭** |

### 3.2 为什么"进入头部客户供应链"是最强信号

从真实案例看：
- 华大九天：2015年进入华为 → 2022年上市（间隔7年）
- 纳芯微：2018年进入华为 → 2022年上市（间隔4年）

**进入头部客户供应链意味着：1）技术得到验证 2）有稳定收入来源 3）IPO故事更完整。这是比CFO引入更早、更有价值的信号。**

### 3.3 集成电路企业的"国产替代逻辑"

| 企业 | 创立到上市 | 国产替代逻辑 | 市场地位 |
|------|-----------|------------|---------|
| 中芯国际 | 4年(港股) | 晶圆代工国产化 | 国内第一 |
| 北方华创 | 9年 | 半导体设备国产化 | 国内第一 |
| 华大九天 | 13年 | EDA工具国产化 | 国内第一 |
| 纳芯微 | 9年 | 模拟芯片国产化 | 国内头部 |

**集成电路企业的特点是：国产替代逻辑清晰、政策支持力度大、市场空间广阔。BD时需要关注企业的"国产替代位置"和"技术壁垒"，而不是短期盈利。**

## 五、BD紧迫性评分

```
BD紧迫性 = 预警信号加权之和 − 风险信号扣分

⚠️ 核心变化：CFO引入从权重20降为10！
   因为CFO引入距离上市通常<1-2年，此时BD已几乎无操作空间
   CFO引入的真正价值是"确认该企业会上市"，而不是"还有时间BD"

评级：
  ≥40 → A级（Phase 4，全力推进）
  30-39 → B级（Phase 3，保持接触）
  20-29 → C级（Phase 3，偶尔接触）
  10-19 → D级（Phase 2，建立认知）
  <10 → E级（Phase 1，观察）
```
