## 一、行业定义

EDA（电子设计自动化）与半导体IP是集成电路产业链的最上游，包括数字/模拟/封装全流程EDA工具和处理器IP核。被三巨头（Synopsys/Cadence/Siemens EDA）垄断，国产替代空间大但壁垒极高。

### 1.1 核心特征

| 特征 | 说明 | 代表企业 |
|------|------|---------|
| 技术壁垒极高 | 研发难度大 | 华大九天(EDA龙头) |
| 国产替代 | 打破国外垄断 | 概伦电子(EDA) |
| 客户集中 | 芯片设计公司为主 | 所有EDA/IP企业 |
| 研发周期长 | 10年+积累 | 所有EDA/IP企业 |

### 1.2 细分类型

| 类型 | 代表产品/应用 | BD优先级 | 上市通道 | 典型IPO案例 |
|------|------------|---------|---------|-----------|
| **EDA工具** | 数字/模拟/封装EDA | ⭐⭐⭐ | 科创板/创业板 | 华大九天(创业板)、概伦电子(科创板) |
| **半导体IP** | 处理器IP核 | ⭐⭐ | 科创板 | — |

## 三、EDA/IP BD实操规律

### 3.1 BD窗口极短，核心在"预测"而非"追击"

| 信号 | 到上市时间 | BD含义 |
|------|-----------|---------|
| 头部设计公司批量采购 | 2-4年 | 🔴 **还有时间，但需立即行动** |
| 进入华为/台积电供应链 | 2-4年 | 🔴 **客户验证，值得关注** |
| 大基金/国家资本投资 | 1-3年 | 🟡 **国家认可，窗口已窄** |
| CFO引入（有IPO经验） | <1-2年 | 🔴 **最后窗口，几乎来不及** |
| 辅导备案公示 | 0 | ⚫️ **窗口已关闭** |

### 3.2 为什么"头部设计公司批量采购"是最强信号

从真实案例看：
- 华大九天：2015年进入华为 → 2022年上市（间隔7年）
- 概伦电子：2018年进入台积电 → 2021年上市（间隔3年）

**头部设计公司批量采购意味着：1）技术得到验证 2）有稳定收入来源 3）IPO故事更完整。这是比CFO引入更早、更有价值的信号。**

### 3.3 EDA/IP企业的"盈利能力"

| 企业 | 创立到上市 | 上市时营收 | 上市时利润 | 上市时毛利率 |
|------|-----------|-----------|-----------|-----------|
| 华大九天 | 13年 | 5.8亿 | 1.4亿 | 88% |
| 概伦电子 | 11年 | 1.9亿 | 0.5亿 | 70% |

**EDA/IP企业的特点是：技术壁垒极高、毛利率高、研发周期长。BD时需要关注企业的"技术路线"和"客户结构"，而不是短期规模。**

## 五、BD紧迫性评分

```
BD紧迫性 = 预警信号加权之和 − 风险信号扣分

⚠️ 核心变化：CFO引入从权重20降为10！
   因为CFO引入距离上市通常<1-2年，此时BD已几乎无操作空间
   CFO引入的真正价值是"确认该企业会上市"，而不是"还有时间BD"

评级：
  ≥40 → A级（Phase 4，全力推进）
  30-39 → B级（Phase 3，保持接触）
  20-29 → C级（Phase 3，偶尔接触）
  10-19 → D级（Phase 2，建立认知）
  <10 → E级（Phase 1，观察）

⚠️ 确认信号出现 → BD紧迫性=0，标记"窗口已关闭"
```
