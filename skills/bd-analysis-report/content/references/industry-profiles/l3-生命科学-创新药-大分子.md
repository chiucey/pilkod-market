## 一、行业定义

大分子创新药是以蛋白质工程技术为基础的生物制剂，分子量>1000道尔顿。核心类型包括单克隆抗体（mAb）、双特异性抗体（BsAb）、抗体偶联药物（ADC）。

| 类型 | 代表靶点 | 全球代表药 | 中国代表药 |
|------|---------|-----------|-----------|
| 单抗 | PD-1, HER2, CD20 | Keytruda, Herceptin | 达伯舒(信达), 替雷利珠(百济) |
| 双抗 | PD-1xCTLA-4, HER2xHER3 | Opdualag, Zanidatamab | 卡度尼利(康方) |
| ADC | HER2-ADC, TROP2-ADC | Enhertu, Dato-DXd | Trastuzumab deruxtecan(荣昌) |

## 三、大分子行业BD实操规律

### 3.1 BD窗口极短，核心在"预测"而非"追击"

| 信号 | 到上市时间 | BD含义 |
|------|-----------|---------|
| BigPharma/License-out合作 | 3-5年 | 🔴 **还有时间，但需立即行动** |
| NDA递交 | 1-3年 | 🟡 **窗口很窄，争分秒** |
| CFO引入（有IPO经验） | <1-2年 | 🔴 **最后窗口，几乎来不及** |
| 销售团队超500人 | 1-3年 | 🟡 窗口已窄 |
| 辅导备案公示 | 0 | ⚫️ **窗口已关闭** |

### 3.2 为什么CFO引入是"最强但最短"的信号

从真实案例看：
- 信达：2020年CFO → 2020年10月上市（间隔可能<1年）
- 百济：2016年CFO → 2016年11月美股上市（间隔可能<1年）

**CFO引入不是"还有时间BD"，而是"企业已经决定上市了"。** CFO来了说明审计师/券商已经在对接了，审计招标随时可能出现。

### 3.3 真正有价值的BD信号不是"即将上市"，而是"会不会上市"

| 信号 | 说明 | BD价值 |
|------|------|--------|
| 礼来/安进/罗氏等合作讨论 | 证明管线有全球价值 | ⭐⭐⭐ |
| 研发团队有跨国药企背景 | 管线质量有保障 | ⭐⭐⭐ |
| GMP工厂/产能建设启动 | 准备商业化 | ⭐⭐ |
| 引入前跨国药企BD高管 | 开始搭建合作网络 | ⭐⭐⭐ |
| 销售团队从0到1组建 | 准备商业化 | ⭐⭐ |
| CFO引入 | 上市准备启动 | ⭐（已太晚） |
