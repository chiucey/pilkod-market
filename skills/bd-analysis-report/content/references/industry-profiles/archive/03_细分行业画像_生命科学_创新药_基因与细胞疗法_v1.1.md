## 一、行业定义

基因与细胞疗法是生物医药的前沿赛道，包括CAR-T细胞疗法、基因治疗（AAV载体）、基因编辑（CRISPR）、iPSC诱导多能干细胞等。

## 二、成长路径

```
Phase 1          Phase 2            Phase 3             Phase 4            Phase 5
(0-3年)          (3-8年)            (8-12年)            (12-15年)          (15年+)
  │                │                  │                   │                  │
  ├─科学家/医学团队 ├─IND申报          ├─关键临床数据       ├─预警信号≥40      ├─辅导备案
  ├─天使/种子轮    ├─A/B轮融资        ├─NDA递交           ├─CFO引入          ├─审计招标
  │                │                  │                   │                  │
  估值:<5000万USD  估值:5000万-5亿USD 估值:5-30亿USD     估值:30亿+USD      市值:80亿+USD

  ⚠️ Phase 4 = 预警信号≥40且确认信号未出现 = BD唯一窗口
  ⚠️ 基因与细胞疗法周期更长，通常10-15年
```

## 三、信号体系

### 3.1 预警信号（🔔）

| # | 信号 | 权重 | 说明 |
|---|------|------|------|
| E1 | **CFO引入（有IPO经验）** | **20** | 最强预警 |
| E2 | **关键临床数据积极（ORR/生存期）** | **20** | 核心管线验证 |
