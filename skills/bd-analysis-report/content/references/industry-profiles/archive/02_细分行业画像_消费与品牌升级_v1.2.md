## 一、行业概述

### 1.1 行业定义

消费与品牌升级是中国内需市场核心赛道，包括食品饮料、美妆个护、连锁零售、消费科技等细分领域，核心是"国货崛起+消费分级"。

### 1.2 三级细分赛道

| 三级细分 | 代表产品/应用 | BD优先级 | 上市通道 |
|---------|------------|---------|---------|
| **食品饮料** | 新式茶饮/预制菜/健康食品 | ⭐⭐⭐ | A股/港股 |
| **美妆个护** | 国货美妆/功效护肤 | ⭐⭐⭐ | A股/美股 |
| **连锁零售** | 奶茶/咖啡/便利店连锁 | ⭐⭐ | A股/港股 |
| **消费科技** | 智能家电/消费电子 | ⭐⭐ | 科创板/创业板 |
| **潮玩/文创** | 盲盒/IP衍生品 | ⭐⭐ | 港股 |

## 二、基于真实案例的IPO路径

### 2.1 农夫山泉（09633.HK）— 中国包装水龙头

| 时间 | 事件 | 信号类型 | 距上市 |
|------|------|---------|---------|
| 1996 | 钟睒睒在杭州创立 | — | 24年前 |
| 2000 | 发起"天然水vs纯净水"论战，成为行业龙头 | 预警-品牌突破 | 20年前 |
| **2012** | **营收突破100亿，净利润超30亿** | 🔔**规模化验证（权重18）** | **8年前** |
| 2018 | 股权重组，搭建红筹架构 | 预警-架构调整 | 2年前 |
| **2019** | **引入有IPO经验的CFO** | 🔔**CFO引入（权重15）** | **1年前** |
| 2020.06 | 辅导备案公示 | 📌确认信号 | 3个月前 |
| **2020.09** | **港股上市（09633）** | 📌**确认信号** | **BD窗口关闭** |

**BD窗口复盘：农夫山泉成立24年才上市，是慢消费品牌的典型。BD黄金窗口在2018-2019年（架构调整到CFO引入前），此时企业已有绝对的市场地位和盈利，但尚未进入上市冲刺。真正的"黄金窗口"是2019年（架构调整完成后到CFO引入前）。**

### 2.2 逸仙电商（YSG.NYSE）— 国货美妆第一股（完美日记母公司）

| 时间 | 事件 | 信号类型 | 距上市 |
|------|------|---------|---------|
| 2016 | 黄锦峰在广州创立 | — | 4年前 |
| 2017 | 完美日记品牌上线，双11销量破亿 | 预警-品牌爆火 | 3年前 |
| **2018** | **高瓴资本领投A轮融资** | 🔔**知名机构投资（权重18）** | **2年前** |
| 2019 | 营收突破30亿，成为国货美妆Top1 | 🔔**规模化验证（权重15）** | 1年前 |
| **2020** | **完成股改，引入IPO财务团队** | 🔔**上市准备（权重15）** | **同年上市** |
| 2020.09 | 向SEC提交招股书 | 📌确认信号 | 2个月前 |
| **2020.11** | **纳斯达克上市（YSG）** | 📌**确认信号** | **BD窗口关闭** |

**BD窗口复盘：逸仙电商成立仅4年即上市，是新消费品牌的典型"快路径"。BD黄金窗口在2018-2019年（高瓴投资到营收破30亿前），此时企业已有爆品和高增长，但尚未进入上市冲刺。**

## 六、BD紧迫性评分

```
BD紧迫性 = 预警信号加权之和 − 风险信号扣分

⚠️ 确认信号出现时，BD紧迫性=0，标记"窗口已关闭"

评级：
  ≥40 → A级（Phase 4，全力推进）
  30-39 → B级（Phase 3，保持接触）
  20-29 → C级（Phase 3，偶尔接触）
  10-19 → D级（Phase 2，建立认知）
  <10 → E级（Phase 1，观察）
```
