## 一、行业定义

新能源汽车是新能源与双碳的核心赛道，包括整车制造（纯电/插混/增程）和核心零部件（三电系统、热管理、轻量化）。2026年行业进入淘汰赛阶段，头部集中加速。

---

## 二、成长路径

```
Phase 1          Phase 2            Phase 3             Phase 4            Phase 5
(0-3年)          (3-6年)            (6-9年)             (9-12年)           (12年+)
  │                │                  │                   │                  │
  ├─整车/零部件研发 ├─量产/首批交付    ├─年销10万+          ├─预警信号≥40      ├─辅导备案
  ├─天使/种子轮    ├─A/B轮融资        ├─海外市场突破       ├─CFO引入          ├─审计招标
  │                │                  │                   │                  │
  估值:<5亿RMB     估值:5-50亿RMB     估值:50-500亿RMB    估值:500亿+        市值:1000亿+

  ⚠️ Phase 4 = 预警信号≥40且确认信号未出现 = BD唯一窗口
```

## 三、信号体系

| # | 信号 | 权重 | 说明 |
|---|------|------|------|
| E1 | **CFO引入（有IPO经验）** | **20** | 最强预警 |
