## 一、行业概述

新消费品牌2026年进入品牌深耕期，流量红利消退，差异化产品力和私域运营能力成为核心。健康/功能性食品、国货美妆、精品家居为热门赛道。一级市场关注具备产品差异化、稳定复购率和供应链整合能力的新兴品牌。

---

## 二、核心技术与产品方向

| 方向 | 说明 |
|------|------|
| 健康功能食品 | 控糖/减脂/益生菌/运动营养；功能性成分壁垒 |
| 国货美妆 | 成分党/功效党崛起，本土植物成分差异化 |
| 精品家居 | 智能家居、高端定制、跨境家居 |
| IP联名与内容电商 | 抖音/小红书驱动，网红单品逻辑 |

---

## 三、行业特征

| 维度 | 说明 |
|------|------|
| 阶段分布 | 大多数 Phase 1-2，品牌淘汰率高；头部 Phase 3 |
| 资本密度 | 中低——消费品牌轻资产，但营销投放需持续投入 |
| 政策依赖 | 中——食品安全法、广告法监管 |
| 上市通道 | 港股主板（品牌消费）、北交所（专精特新）、创业板 |

| 信号类型 | 内容 |
