## 一、行业定义

具身智能（Embodied AI）是指将大型语言模型/视觉语言模型与物理机器人结合，使机器人具备在真实物理世界中理解语言、视觉感知、推理决策并执行任务的能力。是AI从"数字世界"走向"物理世界"的核心路径，也是人形机器人的"大脑"层。

---

## 二、产业链位置

```
最上层：具身智能算法（大脑）
├─ VLM（视觉语言模型）：视觉感知+语言理解
├─ 行为规划：大模型+强化学习
└─ 实时控制：低延迟控制

中层：机器人整机（身体）
└─ 人形机器人/机械臂/无人车

底层：核心零部件
└─ 减速器/伺服/传感器/灵巧手
```
