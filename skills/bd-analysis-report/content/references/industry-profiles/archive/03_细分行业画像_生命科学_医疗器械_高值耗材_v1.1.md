## 一、行业定义

高值耗材是医疗器械的核心赛道，包括心血管介入耗材（支架/球囊/封堵器）、骨科植入物（关节/脊柱）、眼科耗材（人工晶体/角膜塑形镜）、神经介入等。

## 二、成长路径

```
Phase 1          Phase 2            Phase 3             Phase 4            Phase 5
(0-3年)          (3-6年)            (6-9年)             (9-12年)           (12年+)
  │                │                  │                   │                  │
  ├─医学/工程团队  ├─NMPA注册证申请   ├─集采中标/医院覆盖 ├─预警信号≥40      ├─辅导备案
  ├─天使/种子轮    ├─A轮融资          ├─营收过5亿          ├─CFO引入          ├─审计招标
  │                │                  │                   │                  │
  估值:<5000万     估值:5000万-10亿   估值:10-50亿        估值:50亿+         市值:100亿+

  ⚠️ Phase 4 = 预警信号≥40且确认信号未出现 = BD唯一窗口
```

## 三、信号体系

### 3.1 预警信号（🔔）

| # | 信号 | 权重 | 说明 |
|---|------|------|------|
| E1 | **CFO引入（有IPO经验）** | **20** | 最强预警 |
| E2 | **NMPA注册证获批** | **18** | 产品获批 |
| E3 | 进入集采目录并中标 | 15 | 商业化确认 |
| E4 | 海外注册证（FDA/CE） | 15 | 全球化 |
| E5 | 大额融资（单笔≥3亿） | 12 | 资本押注 |
| E6 | 头部医院覆盖（>100家三甲） | 10 | 客户验证 |

### 3.2 确认信号（📌）— BD窗口关闭

| 信号 | 出现时行动 |
|------|-----------|
| 辅导备案公示 | → Phase 5，窗口关闭 |
| 审计招标公示 | → Phase 5，窗口关闭 |
