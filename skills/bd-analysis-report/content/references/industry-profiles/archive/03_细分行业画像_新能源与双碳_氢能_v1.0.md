## 一、行业概述

氢能2026年处于商业化早期，绿氢制取和氢燃料电池为两大核心方向。地方政府氢能规划密集出台，港口/矿山/重卡为优先落地场景。一级市场以早期投资为主，BD接触重点在具备核心设备和材料能力的企业。

---

## 二、核心技术与产品方向

| 方向 | 说明 |
|------|------|
| 绿氢制取 | 电解水制氢（ALK/PEM/AEC），绿氢项目招标加速 |
| 氢燃料电池系统 | 重卡/港口机械/备用电源，国产化率快速提升 |
| 储氢瓶/运氢 | IV型瓶、液态运氢、有机液体储氢 |
| 氢能应用场景 | 港口集卡、矿山运输、分布式热电联供 |

---

## 三、行业特征

| 维度 | 说明 |
|------|------|
| 阶段分布 | 整体 Phase 1-2，绿氢项目 Phase 1 |
| 资本密度 | 高——电解槽和燃料电池扩产需数十亿 |
| 政策依赖 | 极强——氢能示范城市群补贴政策为核心驱动 |
| 上市通道 | 科创板、港股（特专科技通道待开放） |
