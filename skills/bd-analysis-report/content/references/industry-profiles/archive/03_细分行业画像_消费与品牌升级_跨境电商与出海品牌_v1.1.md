## 一、行业定义

跨境电商与出海品牌是消费赛道的重要方向，包括DTC品牌（独立站）、亚马逊卖家、跨境电商平台等。2026年Temu/SHEIN/TikTok Shop重塑全球电商格局。

## 二、成长路径

```
Phase 1          Phase 2            Phase 3             Phase 4            Phase 5
(0-2年)          (2-4年)            (4-7年)             (7-10年)           (10年+)
  │                │                  │                   │                  │
  ├─选品/供应链    ├─单品爆款         ├─多品类/多渠道      ├─预警信号≥40      ├─辅导备案
  ├─天使/种子轮    ├─A轮融资          ├─年GMV过10亿美元    ├─CFO引入          ├─审计招标
  │                │                  │                   │                  │
  估值:<5000万     估值:5000万-30亿   估值:30-200亿RMB    估值:200亿+        市值:500亿+

  ⚠️ Phase 4 = 预警信号≥40且确认信号未出现 = BD唯一窗口
```

## 三、信号体系

### 3.1 预警信号（🔔）

| # | 信号 | 权重 | 说明 |
|---|------|------|------|
| E1 | **CFO引入（有IPO经验）** | **20** | 最强预警 |
| E2 | **年GMV过10亿美元** | **18** | 规模化验证 |
| E3 | 海外仓/本地化团队建设 | 15 | 深度出海 |
| E4 | 品牌化转型（从卖货到品牌） | 12 | 利润率提升 |
| E5 | 大额融资（单笔≥3亿） | 12 | 资本押注 |
| E6 | 多平台布局（亚马逊+独立站+TikTok） | 10 | 渠道多元化 |
