## 一、行业概述

工业软件是制造业数字化转型的核心，包括研发设计类（CAD/CAE/EDA）、生产执行类（MES/SCADA）和运营管理类（PLM/ERP）。2026年，信创政策和AI大模型双重驱动，国产工业软件进入加速替代期，一级市场关注具备核心IP和头部客户突破能力的标的。

---

## 二、核心技术与产品方向

| 方向 | 说明 |
|------|------|
| EDA | 芯片设计必备，数字/模拟/封装全流程；国产替代空间大 |
| CAD/CAE | 工程设计/仿真，AI+仿真成为新趋势 |
| MES/PLM | 生产执行和产品生命周期管理；SaaS化加速 |
| AI+工业软件 | AI辅助设计/仿真/工艺优化，新兴方向 |

---

## 三、行业特征

| 维度 | 说明 |
|------|------|
| 阶段分布 | EDA Phase 1-2（早期追赶）；MES/PLM Phase 2-3 |
| 资本密度 | 中——软件研发为主，并购为辅 |
| 技术壁垒 | 极高——EDA被三巨头垄断，IP生态为核心 |
| 上市通道 | 科创板（软件属性）、创业板、港股 |

## 四、主要信号

| 信号类型 | 内容 |

| 预警信号 | 进入军工/央国企核心供应商、完成国产EDA全流程单点工具覆盖 |
