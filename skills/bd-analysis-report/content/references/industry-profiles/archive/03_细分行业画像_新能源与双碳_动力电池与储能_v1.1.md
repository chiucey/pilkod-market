## 一、行业定义

动力电池与储能是新能源与双碳的核心赛道。2026年固态电池/钠离子电池技术加速迭代，大储和工商业储能需求爆发，行业进入精细化竞争阶段。

## 二、成长路径

```
Phase 1          Phase 2            Phase 3             Phase 4            Phase 5
(0-3年)          (3-6年)            (6-9年)             (9-12年)           (12年+)
  │                │                  │                   │                  │
  ├─电芯/系统研发  ├─中试线/送样      ├─车企/电网批量导入  ├─预警信号≥40      ├─辅导备案
  ├─天使/种子轮    ├─A轮融资          ├─GWh级产能投产     ├─CFO引入          ├─审计招标
  │                │                  │                   ├─大额融资          ├─上市
  估值:<2亿RMB     估值:2-20亿RMB     估值:20-100亿RMB    估值:100亿+        市值:200亿+

  ⚠️ Phase 4 = 预警信号≥40且确认信号未出现 = BD唯一窗口
```
