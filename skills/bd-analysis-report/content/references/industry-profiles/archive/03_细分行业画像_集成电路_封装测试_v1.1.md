## 一、行业定义

封装测试（OSAT）是集成电路产业链的下游环节，包括传统封装和先进封装（Chiplet/2.5D/3D）。2026年先进封装需求爆发，Chiplet成为新趋势。

---

## 二、成长路径

```
Phase 1          Phase 2            Phase 3             Phase 4            Phase 5
(0-2年)          (2-5年)            (5-8年)             (8-10年)           (10年+)
  │                │                  │                   │                  │
  ├─封测团队组建   ├─产线量产         ├─先进封装突破       ├─预警信号≥40      ├─辅导备案
  ├─天使/种子轮    ├─A轮融资          ├─头部客户批量导入   ├─CFO引入          ├─审计招标
  │                │                  │                   │                  │
  估值:<1亿RMB     估值:1-20亿RMB     估值:20-100亿RMB    估值:100亿+        市值:200亿+

  ⚠️ Phase 4 = 预警信号≥40且确认信号未出现 = BD唯一窗口
```

## 三、信号体系

### 3.1 预警信号（🔔）

| # | 信号 | 权重 | 说明 |
|---|------|------|------|
| E1 | **CFO引入（有IPO经验）** | **20** | 最强预警 |
| E2 | **先进封装量产（Chiplet/2.5D）** | **18** | 技术领先 |
| E3 | 头部设计公司导入 | 15 | 客户验证 |
| E4 | 大额融资（单笔≥5亿） | 15 | 产线建设烧钱 |
| E5 | 环评公示（新产线） | 10 | 产能准备 |

### 3.2 确认信号（📌）— BD窗口关闭

| 信号 | 出现时行动 |
|------|-----------|
| 辅导备案公示 | → Phase 5，窗口关闭 |
| 审计招标公示 | → Phase 5，窗口关闭 |

### 3.3 风险信号（⚠️）

| 信号 | 扣分 |
|------|------|

| 产能利用率低 | -10 |
