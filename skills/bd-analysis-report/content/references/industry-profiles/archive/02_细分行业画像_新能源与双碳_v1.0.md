## 一、行业概述

新能源与双碳是国家战略核心赛道，覆盖动力电池、储能、新能源汽车、光伏、风电、氢能、碳化硅等细分领域。2026年双碳目标驱动下，行业进入规模化成熟期，一级市场关注点从产能扩张转向技术迭代与海外扩张。

---

## 二、三级细分与重点方向

| 三级细分 | 优先级 | 核心要点 |
|---------|--------|---------|
| 动力电池/储能 | ⭐⭐⭐ | 固态电池、钠离子电池、大储/工商业储能 |
| 新能源汽车 | ⭐⭐⭐ | 固态电池上车、800V高压平台、智能驾驶集成 |
| 光伏 | ⭐⭐ | TOPCon/HJT/BC路线竞争；钙钛矿叠层技术 |
| 风电 | ⭐⭐ | 海风是大方向；漂浮式风电开始商业化 |
| 氢能 | ⭐⭐ | 绿氢制取；氢燃料电池重卡/港口机械 |
| 碳化硅/第三代半导体材料 | ⭐⭐ | 800V上车拉动碳化硅需求；国产替代加速 |

## 三、行业特征与BD机会

| 维度 | 说明 |
|------|------|
| 阶段分布 | 动力电池已进入成熟期（Phase 3-4）；氢能仍处早期（Phase 1-2） |
| 资本密度 | 极高——动力电池/光伏扩产需数十亿级资本 |
| 政策依赖 | 强——补贴/消纳政策直接影响企业盈利 |
| 上市通道 | 科创板（新能源+高端制造属性）、创业板、港股 |

## 五、主要企业类型（供企业库填充参考）

- 动力电池：宁德时代供应链企业、固态电池创业企业
- 光伏：HJT/钙钛矿技术路线企业
- 氢能：绿氢制取、燃料电池系统集成商
- 碳化硅：SiC功率器件设计/晶圆制造企业
