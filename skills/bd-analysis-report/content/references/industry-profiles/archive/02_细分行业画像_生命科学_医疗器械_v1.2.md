## 一、行业定义

医疗器械是生物医药的重要组成部分，是以诊断、治疗、监测人体疾病为目的的仪器、设备、器具、材料等。其本质是通过技术创新提升医疗服务的精准性和效率。

### 1.1 核心特征

| 特征 | 说明 | 代表企业 |
|------|------|---------|
| 监管严格 | 需通过NMPA/FDA/CE认证 | 所有医疗器械企业 |
| 渠道为王 | 需要覆盖医院/经销商网络 | 迈瑞医疗(覆盖全球) |
| 集采压力 | 高值耗材面临集采降价 | 微创医疗(集采影响大) |
| 技术壁垒 | 高端设备技术门槛高 | 联影医疗(MRI/CT) |

### 1.2 三级细分赛道

| 三级细分 | 代表产品/应用 | BD优先级 | 上市通道 | 典型IPO案例 |
|---------|------------|---------|---------|-----------|
| **高值耗材** | 心血管/骨科/眼科耗材 | ⭐⭐⭐ | 科创板/港股 | 微创医疗(港股)、心脉医疗(科创板) |
| **影像设备** | CT/MRI/超声 | ⭐⭐⭐ | 科创板/港股 | 联影医疗(科创板)、迈瑞医疗(创业板) |
| **体外诊断（IVD）** | 化学发光/分子诊断 | ⭐⭐ | 科创板/创业板 | 新产业(创业板)、安图生物(主板) |
| **手术机器人** | 腔镜/骨科机器人 | ⭐⭐ | 科创板/港股 | 微创机器人(港股) |

## 三、医疗器械BD实操规律

### 3.1 BD窗口极短，核心在"预测"而非"追击"

| 信号 | 到上市时间 | BD含义 |
|------|-----------|---------|
| 进入三甲医院供应链 | 3-6年 | 🔴 **还有时间，但需立即行动** |
| NMPA注册证获批 | 2-4年 | 🔴 **产品验证，值得关注** |
| 海外注册证获批（FDA/CE） | 2-4年 | 🔴 **全球化能力，值得关注** |
| 进入集采/医保 | 1-3年 | 🟡 **商业化确认，窗口已窄** |
| CFO引入（有IPO经验） | <1-2年 | 🔴 **最后窗口，几乎来不及** |
| 辅导备案公示 | 0 | ⚫️ **窗口已关闭** |

### 3.2 为什么"进入三甲医院供应链"是最强信号

从真实案例看：
- 联影：2016年进入三甲医院 → 2022年上市（间隔6年）
- 新产业：2014年进入三甲医院 → 2020年上市（间隔6年）

**进入三甲医院供应链意味着：1）产品得到临床认可 2）有稳定收入来源 3）IPO故事更完整。这是比CFO引入更早、更有价值的信号。**

### 3.3 医疗器械企业的"盈利能力"

| 企业 | 创立到上市 | 上市时营收 | 上市时利润 | 上市时毛利率 |
|------|-----------|-----------|-----------|-----------|
| 联影医疗 | 11年 | 92亿 | 14亿 | 48% |
| 迈瑞医疗 | 27年 | 137亿 | 37亿 | 67% |
| 微创医疗 | 12年 | - | - | - |
| 新产业 | 25年 | 22亿 | 10亿 | 80% |

**医疗器械企业的特点是：盈利能力强、毛利率高、现金流稳定。BD时需要关注企业的"渠道覆盖"和"集采影响"，而不是短期亏损。**

## 五、BD紧迫性评分

```
BD紧迫性 = 预警信号加权之和 − 风险信号扣分

⚠️ 核心变化：CFO引入从权重20降为10！
   因为CFO引入距离上市通常<1-2年，此时BD已几乎无操作空间
   CFO引入的真正价值是"确认该企业会上市"，而不是"还有时间BD"

评级：
  ≥40 → A级（Phase 4，全力推进）
  30-39 → B级（Phase 3，保持接触）
  20-29 → C级（Phase 3，偶尔接触）
  10-19 → D级（Phase 2，建立认知）
  <10 → E级（Phase 1，观察）
```
