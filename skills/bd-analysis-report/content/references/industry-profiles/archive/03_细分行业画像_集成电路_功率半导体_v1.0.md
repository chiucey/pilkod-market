## 一、行业概述

功率半导体包括硅基MOSFET、IGBT、SiC（碳化硅）和GaN（氮化镓）器件。2026年，800V高压平台和新能源汽车爆发驱动SiC需求高速增长，国产替代从消费级向工业/汽车级快速渗透。

---

## 二、核心技术与产品方向

| 方向 | 说明 |
|------|------|
| SiC MOSFET | 800V新能源车主驱、充电桩；国产替代加速 |
| IGBT | 新能源汽车/光伏/风电；1200V为主 |
| GaN | 快充头、5G射频、激光雷达；新兴方向 |
| 硅基MOSFET | 消费电子、工业电源 |

---

## 三、行业特征

| 维度 | 说明 |
|------|------|
| 阶段分布 | 消费级MOSFET Phase 3-4；SiC Phase 1-2（高速成长期） |
| 资本密度 | 高——SiC衬底成本高，扩产需大量资本 |
| 技术壁垒 | 高——SiC晶体生长工艺难度大，车规认证周期长 |
| 上市通道 | 科创板（半导体+新能源双重属性）、创业板 |
