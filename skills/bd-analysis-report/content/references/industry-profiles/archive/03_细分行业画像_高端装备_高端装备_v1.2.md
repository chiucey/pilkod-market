## 三、高端装备BD实操规律

### 3.1 BD窗口极短，核心在"预测"而非"追击"

| 信号 | 到上市时间 | BD含义 |
|------|-----------|---------|
| 进入军工/央国企供应链 | 3-6年 | 🔴 **还有时间，但需立即行动** |
| 进入头部民企供应链 | 2-4年 | 🔴 **客户验证，值得关注** |
| 海外市场突破 | 2-4年 | 🔴 **全球化能力，值得关注** |
| CFO引入（有IPO经验） | <1-2年 | 🔴 **最后窗口，几乎来不及** |
| 辅导备案公示 | 0 | ⚫️ **窗口已关闭** |

### 3.2 为什么"进入军工/央国企供应链"是最强信号

从真实案例看：
- 汇川技术：2007年进入三一重工 → 2010年上市（间隔3年）
- 科沃斯：2012年进入欧美市场 → 2018年上市（间隔6年）

**进入军工/央国企供应链意味着：1）技术得到验证 2）有稳定收入来源 3）IPO故事更完整。这是比CFO引入更早、更有价值的信号。**

### 3.3 高端装备企业的"盈利能力"

| 企业 | 创立到上市 | 上市时营收 | 上市时利润 | 上市时毛利率 |
|------|-----------|-----------|-----------|-----------|
| 汇川技术 | 7年 | 6亿 | 2亿 | 45% |
| 科沃斯 | 20年 | 40亿 | 5亿 | 25% |

**高端装备企业的特点是：盈利能力强、毛利率稳定、现金流良好。BD时需要关注企业的"客户结构"和"技术壁垒"，而不是短期规模。**

## 五、BD紧迫性评分

```
BD紧迫性 = 预警信号加权之和 − 风险信号扣分

⚠️ 核心变化：CFO引入从权重20降为10！
   因为CFO引入距离上市通常<1-2年，此时BD已几乎无操作空间
   CFO引入的真正价值是"确认该企业会上市"，而不是"还有时间BD"

评级：
  ≥40 → A级（Phase 4，全力推进）
  30-39 → B级（Phase 3，保持接触）
  20-29 → C级（Phase 3，偶尔接触）
  10-19 → D级（Phase 2，建立认知）
  <10 → E级（Phase 1，观察）

⚠️ 确认信号出现 → BD紧迫性=0，标记"窗口已关闭"
```
