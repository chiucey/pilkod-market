## 一、行业定义

晶圆制造是集成电路产业链最重资产的环节，包括先进制程（7nm以下）和成熟制程（28nm以上）。国内以中芯国际为龙头，华虹为成熟制程主力。

---

## 二、成长路径

```
Phase 1          Phase 2            Phase 3             Phase 4            Phase 5
(0-5年)          (5-10年)           (10-15年)           (15-18年)          (18年+)
  │                │                  │                   │                  │
  ├─制造团队组建   ├─产线量产         ├─良率提升/客户导入 ├─预警信号≥40      ├─辅导备案
  ├─大额融资       ├─持续融资         ├─产能满载          ├─CFO引入          ├─审计招标
  │                │                  │                   │                  │
  估值:<50亿RMB    估值:50-200亿RMB   估值:200-1000亿RMB  估值:1000亿+       市值:2000亿+

  ⚠️ Phase 4 = 预警信号≥40且确认信号未出现 = BD唯一窗口
  ⚠️ 晶圆制造周期极长，通常15年以上
```

## 三、信号体系

### 3.1 预警信号（🔔）

| # | 信号 | 权重 | 说明 |
|---|------|------|------|
| E1 | **CFO引入（有IPO经验）** | **20** | 最强预警 |
| E2 | **大基金/国家资本大额投资** | **18** | 国家认可 |
