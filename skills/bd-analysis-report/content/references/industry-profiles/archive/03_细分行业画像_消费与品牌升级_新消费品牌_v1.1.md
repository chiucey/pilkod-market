## 一、行业定义

新消费品牌是消费与品牌升级的核心赛道，包括食品饮料、美妆个护、家居生活等新锐品牌。2026年消费分层加剧，性价比+情绪价值双轮驱动。

## 二、成长路径

```
Phase 1          Phase 2            Phase 3             Phase 4            Phase 5
(0-2年)          (2-4年)            (4-7年)             (7-10年)           (10年+)
  │                │                  │                   │                  │
  ├─品牌创立       ├─线上爆品        ├─全渠道布局         ├─预警信号≥40      ├─辅导备案
  ├─天使/种子轮    ├─A轮融资          ├─年营收过10亿       ├─CFO引入          ├─审计招标
  │                │                  │                   │                  │
  估值:<1亿RMB     估值:1-20亿RMB     估值:20-100亿RMB    估值:100亿+        市值:200亿+

  ⚠️ Phase 4 = 预警信号≥40且确认信号未出现 = BD唯一窗口
```

## 三、信号体系

### 3.1 预警信号（🔔）

| # | 信号 | 权重 | 说明 |
|---|------|------|------|
| E1 | **CFO引入（有IPO经验）** | **20** | 最强预警 |
| E2 | **年营收过10亿** | **18** | 规模化验证 |
| E3 | 线下门店大规模扩张 | 15 | 渠道扩张 |
| E4 | 大额融资（单笔≥3亿） | 12 | 资本押注 |
| E5 | 海外市场突破 | 12 | 出海验证 |
| E6 | 进入天猫/京东/抖音头部 | 10 | 渠道验证 |

### 3.2 确认信号（📌）— BD窗口关闭

| 信号 | 出现时行动 |
|------|-----------|
| 辅导备案公示 | → Phase 5，窗口关闭 |
| 审计招标公示 | → Phase 5，窗口关闭 |

### 3.3 风险信号（⚠️）

| 信号 | 扣分 |
|------|------|
| 品牌口碑危机 | -15 |
| 增长失速/营收下滑 | -12 |
| 渠道依赖过高 | -8 |
