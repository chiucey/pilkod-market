## 一、行业概述

光伏行业2026年进入技术路线深度竞争阶段，TOPCon大规模量产，HJT/BC路线加速降本，钙钛矿叠层开始商业化。行业整体处于Phase 3-4，一级市场BD机会主要为具备差异化技术路线和海外产能布局的标的。

---

## 二、核心技术与产品方向

| 方向 | 说明 |
|------|------|
| TOPCon | 主流路线，量产效率25%+，扩产高峰已过 |
| HJT | 效率优势明确，成本下降关键年 |
| BC（背接触） | 颜值+效率优势，分布式场景受宠 |
| 钙钛矿叠层 | 下一代方向，2028年有望开始商业化 |

---

## 三、行业特征

| 维度 | 说明 |
|------|------|
| 阶段分布 | 整体 Phase 3-4，技术路线迭代期 |
| 资本密度 | 高——一体化产能需数十亿级 |
| 政策依赖 | 中——绿电消纳政策、碳关税影响出口 |
| 上市通道 | 科创板、创业板（组件/逆变器）、港股 |
