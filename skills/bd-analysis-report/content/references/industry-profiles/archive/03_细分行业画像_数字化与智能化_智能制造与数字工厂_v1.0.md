## 一、行业概述

智能制造与数字工厂覆盖MES（生产执行系统）、数字孪生、工业互联网平台和柔性生产系统。2026年，新能源汽车和电子组装行业带动数字工厂建设加速，AI驱动的预测性维护和工艺优化成为新增长点。

---

## 二、核心技术与产品方向

| 方向 | 说明 |
|------|------|
| MES/生产执行系统 | 离散制造/流程工业，SaaS化趋势 |
| 数字孪生 | 工厂级数字孪生、实时仿真、AI工艺优化 |
| 工业互联网平台 | 设备连接、数据采集、边缘计算 |
| 柔性生产系统 | 航空航天/汽车零部件小批量多品种 |

---

## 三、行业特征

| 维度 | 说明 |
|------|------|
| 阶段分布 | 电子/汽车MES Phase 2-3；数字孪生 Phase 1-2 |
| 资本密度 | 中——软件+SaaS模式，项目制与订阅制并存 |
| 政策依赖 | 强——智能制造2025/2026政策驱动 |
| 上市通道 | 科创板（工业软件属性）、创业板、港股 |
