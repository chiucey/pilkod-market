## 一、行业定义

EDA（电子设计自动化）与半导体IP是集成电路产业链的最上游，包括数字/模拟/封装全流程EDA工具和处理器IP核。被三巨头（Synopsys/Cadence/Siemens EDA）垄断，国产替代空间大但壁垒极高。

---

## 二、成长路径

```
Phase 1          Phase 2            Phase 3             Phase 4            Phase 5
(0-3年)          (3-8年)            (8-12年)            (12-15年)          (15年+)
  │                │                  │                   │                  │
  ├─EDA/IP研发团队 ├─工具发布         ├─头部客户导入       ├─预警信号≥40      ├─辅导备案
  ├─大额融资       ├─持续融资          ├─全流程覆盖突破     ├─CFO引入          ├─审计招标
  │                │                  │                   │                  │
  估值:<1亿RMB     估值:1-20亿RMB     估值:20-80亿RMB     估值:80亿+         市值:200亿+

  ⚠️ Phase 4 = 预警信号≥40且确认信号未出现 = BD唯一窗口
  ⚠️ EDA/IP壁垒极高，通常需要10年+积累
```
