## 一、行业概述

消费电子2026年受益于AI大模型落地，AI手机、AI眼镜、智能穿戴设备进入产品创新周期。AR/VR从B端向C端渗透，健康监测功能成为可穿戴标配。一级市场关注具备差异化硬件能力和海外市场突破能力的标的。

---

## 二、核心技术与产品方向

| 方向 | 说明 |
|------|------|
| AI手机/AI PC | 端侧AI芯片、主动服务型操作系统 |
| AI眼镜/AR | Meta Ray-Ban爆款验证方向，国产替代加速 |
| 智能穿戴 | 健康监测（血糖/血压无创）、运动科学 |
| 差异化小家电 | 集成AI的清洁/烹饪/个人护理电器 |

---

## 三、行业特征

| 维度 | 说明 |
|------|------|
| 阶段分布 | AI眼镜 Phase 1-2（高速成长期）；智能穿戴 Phase 2-3 |
| 资本密度 | 中——硬件研发需较大投入，但轻资产运营模式存在 |
| 政策依赖 | 中——3C认证/能效标识 |
| 上市通道 | 港股（消费电子主要通道）、科创板、纳斯达克 |
