## 一、行业定义

消费电子是消费与品牌升级的重要赛道，包括智能硬件、可穿戴设备、智能家居、TWS耳机等。2026年AI+消费电子成为趋势。

## 二、成长路径

```
Phase 1          Phase 2            Phase 3             Phase 4            Phase 5
(0-2年)          (2-4年)            (4-7年)             (7-10年)           (10年+)
  │                │                  │                   │                  │
  ├─硬件+设计团队  ├─产品上市         ├─单品爆款/百万出货  ├─预警信号≥40      ├─辅导备案
  ├─天使/种子轮    ├─A轮融资          ├─全产品线布局       ├─CFO引入          ├─审计招标
  │                │                  │                   │                  │
  估值:<5000万     估值:5000万-20亿   估值:20-100亿RMB    估值:100亿+        市值:200亿+

  ⚠️ Phase 4 = 预警信号≥40且确认信号未出现 = BD唯一窗口
```

## 三、信号体系

### 3.1 预警信号（🔔）

| # | 信号 | 权重 | 说明 |
|---|------|------|------|
| E1 | **CFO引入（有IPO经验）** | **20** | 最强预警 |
| E2 | **单品销量破百万** | **18** | 规模化验证 |
| E3 | 海外市场突破 | 15 | 全球化 |
| E4 | 大额融资（单笔≥3亿） | 12 | 资本押注 |
| E5 | 进入Apple/华为供应链 | 15 | 头部客户 |
| E6 | 年营收过20亿 | 15 | 规模化 |

|------|-----------|

| 审计招标公示 | → Phase 5，窗口关闭 |
