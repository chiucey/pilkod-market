## 一、行业定义

创新药是生物医药的核心赛道，是以新分子实体为基础的药物研发领域。其本质是通过发现和开发全新的治疗靶点、机制或药物形式，为患者提供更有效的治疗方案。

### 1.1 核心特征

| 特征 | 说明 | 代表企业 |
|------|------|---------|
| 研发周期长 | 从靶点到上市10-15年 | 信达生物(9年上市) |
| 投入巨大 | 单药研发成本超10亿美元 | 百济神州(累计亏损超300亿) |
| 成功率低 | 临床I期到上市成功率<10% | 行业平均 |
| 监管严格 | 需通过IND/NDA/BLA审批 | 所有创新药企业 |

### 1.2 三级细分赛道

| 三级细分 | 代表产品/应用 | BD优先级 | 上市通道 | 典型IPO案例 |
|---------|------------|---------|---------|-----------|
| **大分子** | 单抗/双抗/ADC | ⭐⭐⭐ | 港股18A/科创板 | 信达生物(港股)、康方生物(港股) |
| **小分子** | 靶向药/PROTAC | ⭐⭐⭐ | 港股18A/科创板 | 亚盛医药(港股)、诺诚健华(港股) |
| **基因与细胞疗法** | CAR-T/基因治疗 | ⭐⭐ | 港股18A/科创板 | 科济药业(港股) |

## 三、创新药BD实操规律

### 3.1 BD窗口极短，核心在"预测"而非"追击"

| 信号 | 到上市时间 | BD含义 |
|------|-----------|---------|
| BigPharma/License-out合作 | 3-5年 | 🔴 **还有时间，但需立即行动** |
| Phase II/III临床数据积极 | 2-4年 | 🔴 **技术验证，值得关注** |
| NDA递交 | 1-3年 | 🟡 **窗口很窄，争分秒** |
| CFO引入（有IPO经验） | <1-2年 | 🔴 **最后窗口，几乎来不及** |
| 辅导备案公示 | 0 | ⚫️ **窗口已关闭** |

### 3.2 为什么"BigPharma合作"是最强信号

从真实案例看：
- 信达：2015年礼来合作 → 2020年上市（间隔5年）
- 康宁杰瑞：2018年先声合作 → 2019年上市（间隔1年）
- 亚盛：2018年默沙东合作 → 2019年上市（间隔1年）

**BigPharma合作意味着：1）管线得到全球认可 2）有资金支持 3）IPO故事更完整。这是比CFO引入更早、更有价值的信号。**

### 3.3 创新药企业的"烧钱周期"

| 企业 | 创立到上市 | 累计融资 | 上市时营收 | 上市时亏损 |
|------|-----------|---------|-----------|-----------|
| 信达生物 | 9年 | 超50亿人民币 | 10亿+ | - |
| 百济神州 | 6年(美股) | 超10亿美元 | - | - |
| 康宁杰瑞 | 4年 | 超10亿人民币 | 0 | - |
| 亚盛医药 | 10年 | 超20亿人民币 | 0 | - |

**创新药企业的特点是：烧钱周期长、商业化前无收入、IPO时大多亏损。BD时需要关注企业的"管线价值"和"融资能力"，而不是短期盈利。**

## 五、BD紧迫性评分

```
BD紧迫性 = 预警信号加权之和 − 风险信号扣分

⚠️ 核心变化：CFO引入从权重20降为10！
   因为CFO引入距离上市通常<1-2年，此时BD已几乎无操作空间
   CFO引入的真正价值是"确认该企业会上市"，而不是"还有时间BD"

评级：
  ≥40 → A级（Phase 4，全力推进）
  30-39 → B级（Phase 3，保持接触）
  20-29 → C级（Phase 3，偶尔接触）
  10-19 → D级（Phase 2，建立认知）
  <10 → E级（Phase 1，观察）
```
