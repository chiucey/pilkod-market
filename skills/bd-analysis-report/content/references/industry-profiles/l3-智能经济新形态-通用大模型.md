## 三、大模型BD实操规律

### 3.1 BD窗口极短，核心在"预测"而非"追击"

| 信号 | 到上市时间 | BD含义 |
|------|-----------|---------|
| B端付费用户过千/年ARR过亿 | 2-4年 | 🔴 **还有时间，但需立即行动** |
| 大额融资（单笔≥10亿） | 1-3年 | 🟡 **资本押注，窗口已窄** |
| 与头部企业战略合作 | 1-3年 | 🟡 **生态绑定，窗口已窄** |
| CFO引入（有IPO经验） | <1-2年 | 🔴 **最后窗口，几乎来不及** |
| 辅导备案公示 | 0 | ⚫️ **窗口已关闭** |

### 3.2 为什么"B端付费用户过千/年ARR过亿"是最强信号

从真实案例看：
- 商汤科技：2018年进入华为供应链 → 2021年上市（间隔3年）

**B端付费用户过千/年ARR过亿意味着：1）技术得到验证 2）有商业化能力 3）IPO故事更完整。这是比CFO引入更早、更有价值的信号。**

### 3.3 大模型企业的"盈利能力"

| 企业 | 创立到上市 | 上市时营收 | 上市时利润 | 上市时毛利率 |
|------|-----------|-----------|-----------|-----------|
| 商汤科技 | 7年 | 30亿 | -15亿 | 70% |

**大模型企业的特点是：烧钱周期长、技术壁垒高、头部效应明显。BD时需要关注企业的"商业化能力"和"技术壁垒"，而不是短期盈利。**

## 五、BD紧迫性评分

```
BD紧迫性 = 预警信号加权之和 − 风险信号扣分

⚠️ 核心变化：CFO引入从权重20降为10！
   因为CFO引入距离上市通常<1-2年，此时BD已几乎无操作空间
   CFO引入的真正价值是"确认该企业会上市"，而不是"还有时间BD"

评级：
  ≥40 → A级（Phase 4，全力推进）
  30-39 → B级（Phase 3，保持接触）
  20-29 → C级（Phase 3，偶尔接触）
  10-19 → D级（Phase 2，建立认知）
  <10 → E级（Phase 1，观察）

⚠️ 确认信号出现 → BD紧迫性=0，标记"窗口已关闭"
```
