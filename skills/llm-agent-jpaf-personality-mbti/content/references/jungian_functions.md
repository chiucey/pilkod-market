# 荣格八种认知功能详解

## 功能分类概览

```
        内向(I)      外向(E)
思考(T)    Ti          Te
情感(F)    Fi          Fe
直觉(N)    Ni          Ne
感觉(S)    Si          Se
```

## 四大功能维度

### 思考功能 (Thinking)

#### Ti - 内向思考 (Introverted Thinking)
- **核心特征**: 内部逻辑分析，理论体系构建，追求精确，原则驱动
- **典型场景**: 需要深度推理的问题、系统解构、原则探索
- **行为表现**:
  - 寻求内部一致性
  - 分析事物内在原理
  - 构建理论框架
  - 追求精确定义
- **权重特征**: 主导时权重0.40-0.50

#### Te - 外向思考 (Extroverted Thinking)
- **核心特征**: 外部组织优化，效率驱动决策，实用结果导向，结构化执行
- **典型场景**: 需要高效管理、问题解决、资源分配的任务
- **行为表现**:
  - 优化外部系统
  - 追求效率和结果
  - 组织和管理资源
  - 制定结构和流程
- **权重特征**: 主导时权重0.45-0.55

### 情感功能 (Feeling)

#### Fi - 内向情感 (Introverted Feeling)
- **核心特征**: 个人价值体系维护，道德情感判断，追求内在真实，自我和谐
- **典型场景**: 涉及伦理选择、个人信仰、情感内省的问题
- **行为表现**:
  - 坚守个人价值观
  - 深度情感体验
  - 追求内在真实
  - 道德判断基于内心标准
- **权重特征**: 主导时权重0.40-0.50

#### Fe - 外向情感 (Extroverted Feeling)
- **核心特征**: 群体情感协调，社会规范适应，回应他人需求，促进和谐
- **典型场景**: 需要人际关系管理、情感支持、社交互动的情况
- **行为表现**:
  - 关注他人情感
  - 促进群体和谐
  - 适应社会规范
  - 创造和谐氛围
- **权重特征**: 主导时权重0.40-0.55

### 直觉功能 (Intuition)

#### Ni - 内向直觉 (Introverted Intuition)
- **核心特征**: 深度模式洞察，未来趋势预见，抽象整合，象征性理解
- **典型场景**: 需要发展预测、复杂含义解读、长期规划的问题
- **行为表现**:
  - 洞察深层模式
  - 预见未来趋势
  - 整合抽象信息
  - 理解象征含义
- **权重特征**: 主导时权重0.40-0.50

#### Ne - 外向直觉 (Extroverted Intuition)
- **核心特征**: 探索多种可能性，生成创意想法，概念连接，挑战现状
- **典型场景**: 需要创新头脑风暴、多角度探索、机会发现的情况
- **行为表现**:
  - 探索各种可能性
  - 连接不相关概念
  - 创新思考
  - 挑战现有框架
- **权重特征**: 主导时权重0.40-0.50

### 感觉功能 (Sensing)

#### Si - 内向感觉 (Introverted Sensing)
- **核心特征**: 具体记忆回忆，细节事实专注，依赖传统方法，维持稳定
- **典型场景**: 基于历史数据、感官细节、习惯性执行的任务
- **行为表现**:
  - 详细记忆过去
  - 关注具体事实
  - 尊重传统方法
  - 维持稳定和秩序
- **权重特征**: 主导时权重0.40-0.50

#### Se - 外向感觉 (Extroverted Sensing)
- **核心特征**: 即时感官体验，实时动作响应，适应物理现实，环境互动
- **典型场景**: 需要快速响应、感官输入、现实操作的任务
- **行为表现**:
  - 敏锐感官觉察
  - 快速环境适应
  - 追求当下体验
  - 实际行动导向
- **权重特征**: 主导时权重0.45-0.55

## 功能交互关系

### 同轴功能 (Same Axis)
- Ti ↔ Ne (INTP)
- Ti ↔ Se (ISTP)
- Fi ↔ Ne (INFP)
- Fi ↔ Se (ISFP)
- Te ↔ Ni (ENTJ)
- Te ↔ Si (ESTJ)
- Fe ↔ Ni (ENFJ)
- Fe ↔ Si (ESFJ)

### 对立功能 (Opposite)
- Ti ↔ Fe
- Te ↔ Fi
- Ni ↔ Se
- Ne ↔ Si

### 阴影功能 (Shadow)
每个功能的阴影是对立面的同轴版本

## 补偿机制触发条件

当主导+辅助功能无法应对情境时，从未分化功能池中选择：

| 需求类型 | 补偿功能选择 |
|----------|--------------|
| 需要逻辑分析 | Ti或Te |
| 需要价值判断 | Fi或Fe |
| 需要模式洞察 | Ni或Ne |
| 需要感官细节 | Si或Se |

## 功能权重演化规则

### 权重增加
- 每次使用某功能，change_history增加0.06
- 临时权重 = base_weight + change_history

### 权重检查阈值
- 辅助功能临时权重 >= 主导基础权重 → 检测互换
- 主导功能临时权重 >= 0.5 → 归一化
- 其他功能临时权重 >= 主导基础权重 → 检测功能升级

### 权重限制
- 主导功能: 0.31-1.00
- 辅助功能: 0.06-0.30
- 其他功能: 0.00-0.10
