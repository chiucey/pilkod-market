# 咖啡品种详细指南

## 主要咖啡品种

### 阿拉比卡 (Coffea arabica)
- 原产地：埃塞俄比亚高原
- 产量占比：全球约60-70%
- 特征：
  - 豆形：较长、椭圆形、沟纹弯曲
  - 咖啡因含量：约1.2-1.5%
  - 种植海拔：1000-2000米以上
  - 风味：香气复杂、酸度适中、甜味明显

### 罗布斯塔 (Coffea canephora)
- 原产地：中非、西非
- 产量占比：全球约30-40%
- 特征：
  - 豆形：较圆、沟纹直
  - 咖啡因含量：约2.2-2.7%
  - 种植海拔：200-800米
  - 风味：苦味突出、口感浓烈、crema丰富

## 精品咖啡品种

### 波旁 (Bourbon)
- 特点：甜味丰富、酸质柔和
- 产地：巴西、卢旺达、萨尔瓦多

### 瑰夏 (Geisha)
- 特点：花香浓郁、茶感明显、价格昂贵
- 产地：巴拿马（翡翠庄园）、哥伦比亚

### 耶加雪菲 (Yirgacheffe)
- 特点：茉莉花香、柑橘酸质、蜂蜜甜感
- 产地：埃塞俄比亚

### 瑰夏与普通品种对比
| 特征 | 瑰夏 | 普通品种 |
|------|------|---------|
| 干香 | 强烈花香 | 一般 |
| 风味复杂度 | 极佳 | 良好 |
| 价格 | 每磅$50-200+ | 每磅$10-30 |
| 产量 | 低 | 中高 |

## 处理法

### 水洗法 (Washed)
- 过程：去除果皮后发酵清洗
- 风味特点：干净、酸质明亮、纯净
- 适合：喜欢清晰风味的品鉴者

### 日晒法 (Natural)
- 过程：整颗果实干燥后去壳
- 风味特点：果香浓郁、酒香、甜度更高
- 适合：喜欢复杂风味的品鉴者

### 蜜处理 (Honey)
- 过程：去除部分果肉后干燥
- 风味特点：介于水洗与日晒之间
- 分类：白蜜、黄蜜、红蜜、黑蜜（果肉残留量递增）

## 杯测评分标准 (SCA)

| 评分项 | 分值 | 说明 |
|--------|------|------|
| 香气 (Aroma) | 0-10 | 干香与湿香 |
| 风味 (Flavor) | 0-10 | 入口风味 |
| 余韵 (Aftertaste) | 0-10 | 咽下后回味 |
| 酸质 (Acidity) | 0-10 | 酸的质量与强度 |
| 醇厚度 (Body) | 0-10 | 口感质地 |
| 平衡度 (Balance) | 0-10 | 整体协调性 |
| 一致性 (Uniformity) | 0-10 | 杯间一致性 |
| 干净度 (Clean Cup) | 0-10 | 无瑕疵 |
| 甜度 (Sweetness) | 0-10 | 甜感强度 |
| 综合印象 (Overall) | 0-10 | 整体评价 |

**精品等级划分**：
- 80+：精品级 (Specialty)
- 85+：优秀 (Excellent)
- 90+：杰出 (Outstanding)
