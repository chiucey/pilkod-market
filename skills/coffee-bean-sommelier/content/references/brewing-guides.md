# 冲泡指南详解

## 手冲咖啡 (Pour Over)

### 器材
- V60滤杯、Kalita扇形滤杯、蛋糕滤杯
- 手冲壶（温控壶最佳）
- 磨豆机（锥刀或平刀）

### 参数建议
| 参数 | 建议值 |
|------|--------|
| 粉水比 | 1:15-1:17 |
| 水温 | 92-96°C |
| 研磨度 | 中细（食盐粒大小） |
| 总萃取时间 | 2:30-3:30 |

### 冲泡步骤
1. 预热滤杯和分享壶
2. 放入滤纸，倒入热水润湿
3. 倒入咖啡粉，轻拍整平
4. 30秒闷蒸（注入30-50ml水）
5. 第一段注水至总水量1/3
6. 等待30秒
7. 第二段注水至总水量2/3
8. 第三段注水至目标水量
9. 等待滴滤完成

## 意式浓缩 (Espresso)

### 参数建议
| 参数 | 单杯建议值 |
|------|-----------|
| 粉量 | 18-20g |
| 液重 | 36-40g |
| 萃取时间 | 25-35秒 |
| 水温 | 90-96°C |
| 压力 | 9 bar |

### 粉水比参考
- 标准浓缩：1:2（18g→36g）
- ristretto：1:1.5（更浓郁）
- lungo：1:3-1:4（更长萃取）

## 法压壶 (French Press)

### 参数建议
| 参数 | 建议值 |
|------|--------|
| 粉水比 | 1:12-1:15 |
| 水温 | 93-96°C |
| 研磨度 | 粗（面包屑大小） |
| 浸泡时间 | 4分钟 |

### 步骤
1. 预热壶体
2. 倒入咖啡粉和热水
3. 静置4分钟
4. 缓慢下压活塞
5. 立即饮用（避免继续浸泡）

## 爱乐压 (AeroPress)

### 参数建议
| 参数 | 建议值 |
|------|--------|
| 粉水比 | 1:12-1:16 |
| 水温 | 80-85°C（较低温） |
| 研磨度 | 中细 |
| 总时间 | 1:30-2:00 |

### 两种经典方法

**传统法**：
1. 正常倒入水和咖啡粉
2. 搅拌30秒
3. 静置1分钟
4. 缓慢下压

**倒置法**：
1. 倒置爱乐压
2. 加入咖啡粉和热水
3. 静置1:30
4. 翻转放置在杯子上
5. 下压萃取

## 冷萃咖啡 (Cold Brew)

### 参数建议
| 参数 | 建议值 |
|------|--------|
| 粉水比 | 1:5-1:8 |
| 水温 | 冷水/室温 |
| 研磨度 | 粗 |
| 萃取时间 | 12-24小时 |

### 制作要点
- 使用冷水或室温水
- 放入冰箱保持低温
- 过滤后冷藏保存7-14天
- 可稀释浓缩液享用

## 虹吸壶 (Siphon)

### 参数建议
| 参数 | 建议值 |
|------|--------|
| 粉水比 | 1:12-1:15 |
| 水温 | 85-93°C |
| 研磨度 | 中等 |
| 上壶时间 | 45-60秒 |
| 搅拌次数 | 1-2次 |

### 步骤
1. 下壶加入热水
2. 点火热源
3. 水上升至上壶
4. 加入咖啡粉，搅拌
5. 等待萃取
6. 关火，咖啡回流
7. 享用
