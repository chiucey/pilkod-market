# 金蝶 PPT 生成 Skill v3.0

## 概述

基于官方金蝶集团 2026 版 PPT 模板，直接生成完整 `.pptx` 文件。官方背景图和 Logo 内嵌，零配置可用。

> v3.0：品牌色升级 · 29种版式 · Google Canvas 大圆角+阴影系统

## 使用前必读

**按顺序阅读以下参考文件：**
1. `references/style-guide.md` — 品牌色、字体、精确坐标、Logo 规范
2. `references/layout-presets.md` — 12 种标准版式 + 6 种思维模型版式
3. `references/pptx-builder.md` — 技术构建流程、QA 规范

## 完整四阶段工作流

### 第零阶段：思维模型识别

- 0.1 → 扫描用户输入，检测内容结构信号
- 0.2 → 置信度高 → 直接确定模型，写入后续大纲
- 0.3 → 置信度低 → 标记为「标准版式」

### 第一阶段：内容发现

1.1 → 一次性提四个问题（场景/页数/内容状态/素材）
1.2 → 图像评估（如有上传图片）
1.3 → 生成大纲（每页标注版式）→ 用户确认

### 第二阶段：内容脚本

2.1 → 一次输出全部页面内容脚本（含排版指令）
2.2 → 用户审阅反馈 → 确认定稿

### 第三阶段：生成交付

3.1 → 编写 Node.js 构建脚本
3.2 → 执行生成 → 转图 → 视觉 QA → 修复 → 交付 .pptx

## 快速参考

**四个问题**（可跳过如用户已提供完整内容）：
- **场景**：内部汇报 / 伙伴赋能 / 客户大会 / 方案提案
- **页数**：短（5-10页）/ 中（10-20页）/ 长（20页以上）
- **内容状态**：内容已完整 / 有草稿 / 只有主题方向
- **素材**：有图片 / 有图表 / 无额外素材

**核心规范**：
- 字体：Microsoft YaHei（唯一）
- 尺寸：13.3333" × 7.5" (LAYOUT_WIDE)
- 留白：≥30%
- 页脚：右下角页码 + 左侧保密声明

## 常见情况处理

| 情况 | 处理方式 |
|------|---------|
| 用户直接提供完整内容 | 跳过问题，从 Phase 0 + 1.3 开始 |
| 用户明确指定模型 | 跳过 Phase 0，直接采用指定模型 |
| 用户说「直接生成」 | 触发快速模式 |
| 用户只要内容脚本不要文件 | 完成第二阶段后停止 |
