## 5. 页脚规范

```javascript
function addFooter(slide, pageNum, onDark) {
  // 保密声明（浅色背景页）
  slide.addText('④ 内部公开 请勿外传', {
    x: 11.355, y: 7.017, w: 1.327, h: 0.190,
    fontSize: 8, color: 'BFBFBF'
  });
  // 页码
  slide.addText(String(pageNum), {
    x: 12.845, y: 7.051, w: 0.384, h: 0.150,
    fontSize: 10, color: onDark ? 'FFFFFF' : '2971EB',
    align: 'right'
  });
}
```

## 7. Anti-Slop 设计原则

### 间距基准

| 类型 | 数值 |
|------|------|
| 页面最小边距 | 0.5" |
| 内容块之间间距 | 0.3–0.5" |
| 留白目标 | ≥30% |

### 圆角系统

| 卡片类型 | rectRadius |
|---------|-----------|
| 主内容卡片 | 0.15" |
| 小型嵌套元素 | 0.12" |
| 结构性色块 | 0" |

### 阴影三档

| 档位 | blur | offset | opacity |
|------|------|--------|---------|
| elevation-1 | 4 | 1 | 0.05 |
| elevation-2 | 8 | 3 | 0.08 |
| elevation-3 | 14 | 4 | 0.10 |

## 8. 绝对禁止清单

- ❌ 颜色加 `#` 号
- ❌ 复用 shadow 对象（必须用工厂函数）
- ❌ 使用 8 位透明度颜色字符串
- ❌ 错误幻灯片尺寸
- ❌ 封面/结尾页放 Logo
- ❌ 内容页标题加左侧竖线
- ❌ 不同高亮色互相渐变
- ❌ 页面留白 < 30%
