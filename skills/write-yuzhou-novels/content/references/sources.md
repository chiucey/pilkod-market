# 来源与阅读范围

主参考：《从灵气复苏到末法时代》第1—1135章，含书头、附文和完本感言；《正版修仙》第1—1357章，含书头与文件末尾。用户提供的这两部文本已顺序通读完成。连续正文台账合计6,599,151字符，含空白、标点与章名，书头另核，不是净汉字数。

辅助：《万界淘宝商》《许仙志》《魔魂启临》《大周仙吏》《如意小郎君》《世子很凶》《仙子很凶》《问道红尘／仙子请自重》。实际已读开篇、阶段性及结局附近窗口和若干完整关键章，未全本通读。两种问道文本作一部作品版本参考，仙子很凶文案原名太莽。基础十一份文本对应十部独立作品，同名副本不增作品数。

第四版手册替代旧抽样版的主辅定位：两部全本为核心，万界等按功能辅助。事实、技法提炼与原创建议分别判断，不将角色说法、预测和标题当客观已成事实。

证据位置见手册第十四章；完整通读台账保存在用户的《两部叶恨水作品_通读进度与研究笔记.md》。技能不包含整部小说正文，不把索引和摘要冒充全文，不伪造原文引用。需要继续分析辅助作品未读部分时取得原文再判断。

参考是原创写作工具，不是复刻作者独特风格的模板。原作中的称名时间出入、强制控制、羞辱与伦理分歧不自动成为规则。没有量化统计的句长比例和商业结果不作保证。

技能提供可调用的工作指令和参考，不训练模型权重，也不保证跨会话永久记住新故事状态。续写先加载必要前文与连续性表。
