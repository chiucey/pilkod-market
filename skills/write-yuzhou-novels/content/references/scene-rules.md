# 场景设计与审稿规则

## 任务与优势

填写场景卡时用一句话回答每项：谁要什么；为什么现在必须处理；阻力来自何处；优势从何而来；如何验证；付出什么；结果改变谁的选择。允许一章只完成其中一段，跨章跟踪兑现。

优势类型可以是知识、渠道、能力、信誉、关系或组织力。第一次使用给出可理解的效果；重复使用更换约束、对手反应或应用范围，避免同一展示不停重播。使用说明既定能力，不临时增加恰好解决危机的新规则。

## 爽点卡

| 环节 | 检查 |
| --- | --- |
| 期待 | 读者知道困难、限制或被误判的本事吗？ |
| 动作 | 主角做了什么具体判断与实施？ |
| 结果 | 效果可观察，且由此前信息支持吗？ |
| 评价 | 谁懂行？其依据是什么？不同立场是否不同反应？ |
| 收益 | 主角实际得到资源、机会、尊重、自由或关系变化了吗？ |
| 后果 | 对手调整、社会影响、责任或新问题是否合乎比例？ |

不必先羞辱主角再兑现。解决共同困境、救回同伴、获得专业认可、主动选择与兑现承诺均可产生爽感。

## 笑点卡

写清事实、各人理解、各人目的、读者领先的信息、触发动作与落点。幽默要在当事人的逻辑中成立。落点可以是动作或后果，不必是金句。重要人物不能为了凑笑话突然变笨。

原创示例：主角免费教大家修复水泵。村长以为他不求回报；主角其实想统一零件规格，省掉以后逐户维修的麻烦。村长郑重问他想要什么赏赐，他说：“先把你们三十七种螺母换了。”此前应先出现零件混乱和维修成本，落点才有依据。若建立收费服务，继续写投入与村民协商，不把隐藏算盘自动视为高尚。

## 人物与世界

角色卡包含欲望、顾虑、底线、长处、盲点、当前关系证据和可独立采取的行动。通过不同选择区分角色，别只改口头禅。对手的资源、情报与反制有边界，既不全知也不迟钝。

世界规则写成“条件→行动限制→人物选择→结果”。例如恢复资源不足会影响连续作战、旅行距离、组织补给和功法普及；把这些后果写入戏剧，不堆一页百科。

## 去AI味精修

先修逻辑与视角，再修冗余。优先删去空泛结论、读者已经看见的解释、连续同形转折、无意义的动作填充和平均分配的反应。保留能显露欲望、心虚、喜悦、委屈的具体反应。不要把所有长句改短，不要把人物内心全部删光，也不要把每一段都修成同一种克制语气。

训练顺序：观察短片段中的节奏和信息安排→更换目标、人物、冲突与结局写原创片段→比对效果是否成立→脱离原句写独立场景。不要仅替换名词就把原句结构作为正式作品。

## 状态与跨章核验

明确区分已观察事实、人物判断、承诺和未知。后文否定怀孕、死亡或不可中断等说法时更新，不让先前台词变成永久设定。学原理、练成、用出、失去能力各写一条；请求奖励、发货、收到、使用亦分开。遗忘返币后不得继续自动调用遗忘技能。

安排工程时给报告、验收、调整与现场使用。终局核局势、制度、关系与生活，未来方案不当既成成果。角色说“唯一办法”须有其信息条件，不自动变成全知结论。
