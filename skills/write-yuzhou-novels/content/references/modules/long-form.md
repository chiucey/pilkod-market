# 长篇管理：架构、人物、伏笔与状态账

规模按用户要求，单章任务不先制造全书大纲。已有总纲优先修补缺口，不把源文件的 500 章、五卷、三人组或具体案例带入新书。

## 架构与章纲

全书确定核心阅读承诺、主角长期欲望、能力边界、主要冲突与终局结果。每卷有可回答的核心问题、主要对手或阻力、阶段所得和下一选择。场景升级可以是环境、资源、责任、敌人应对或能力运用变化，不要求每卷扩地图或走向群体制度。

单元按“建立期待→试探与推进→关键选择→兑现→后果”安排，长度按故事调整。章纲写场景顺序、谁掌握什么、如何行动、哪里受阻、情绪如何变化、什么实际得到或失去。一个章节可承担多个小动作，不人为限制唯一事件。

## 人物与语音

重要人物建立欲望、顾虑、底线、专业长处、盲点、当前已知信息、独立行动和关系证据。语音卡记说话习惯及其面对不同人的变化。人物成长用新的选择和付出的代价证明，不用旁白宣布完成成长。

配角有主角不在场仍会做的事；是否开独立视角由本书叙述方式决定。对手有资源、情报、同伴和调整策略的能力，也有不知道的事情。不用强制低谷或伤亡配额制造成长。

## 连续性与伏笔

沿用 [yuzhou 连续性模板](../scene-rules.md)，另外按项目需要记录以下账目：

| 记录 | 需要的信息 |
| --- | --- |
| 场景时间线 | 时间、地点、间隔、路程、在场人物 |
| 人物知识 | 内容、来源、获得章节、亲历／转述／猜测／谎言／未知 |
| 能力与伤势 | 发动条件、效果、代价、恢复条件、当前限制 |
| 资源物品 | 原持有人、获取／支出、是否到账／到货、携带或存放地点 |
| 关系承诺 | 当前证据、单方或双方、已完成或未来安排 |
| 伏笔 | 编号、投放、后续暗示、计划回收、当前已揭露范围 |

伏笔编号可以用卷号加序号，沿用已有编号不强制重编。生活细节不必全变成伏笔；已经承诺的关键伏笔不能为求留白漏掉。

跨章加戏或改时间、伤势、装备时，向前核对最近已确认状态，向后查下一次依赖该状态的场景。把影响串起来，不只看新段落本身合理。未提供后文时说明核验边界，不虚称查完全书。

多章工作按需要保存短状态表，区分原文事实和本次新增，供下一次加载。只要正文时，记录不夹进正文；技能不会自动记住跨会话事实。
