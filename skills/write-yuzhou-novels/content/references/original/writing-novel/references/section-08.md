## 阶段三：质量控制（每单元必做）

### 自动化检查清单

每写完一个单元（25章），立即运行：

```
1. CJK字符数统计 → 标记<1800的章
2. "不是X是Y"模式计数 → 标记>3的章  
3. 跨章相似段落检测 → 标记重复模板
4. 段落长度检查 → 标记>300字的段落（手机阅读不友好）
5. 高频词统计 → 标记同词>5次/章的异常
```

### 番茄读者模拟（人工必做）

以番茄老读者视角，对每个单元进行三遍审查：

**第一遍**：快速浏览（模拟真实阅读速度15-30秒/章）→ 直觉打分
- 3秒内能抓住核心事件吗？
- 每章结尾想翻下一章吗？
- 读完后有情绪波动吗？

**第二遍**：仔细阅读 → 逐章找出扣分项
- 哪一章让你想跳过？
- 哪个角色让你觉得"工具人"？
- 哪段对话像AI写的？

**第三遍**：对照问题修改 → 自检确认
- 改完后再快速浏览一遍
- 确认没有引入新问题

### 中段疲劳检测（100-300章专项）

这是完读率的头号杀手。专项检查：
- 连续5章没有新人物/新信息/新冲突？
- 连续10章同一个场景/同一个对抗模式？
- 配角是否在"需要时才出现，不需要时消失"？

**预防**：在100、150、200、250章预设"中期高潮"。这些高潮不必是最大事件，但必须是情绪转折点——让读者感知到"故事在推进"。
