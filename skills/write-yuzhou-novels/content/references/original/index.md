# 来源导航与保留范围

Sepia 两包除入口和界面元数据外的内容逐文件比较相同，合成一份 core、references、research 和 LICENSE；两份不同入口保留为普通 Markdown。其余三个补充来源保留 entry.md、所有参考分节与 LICENSE。原来的 agents 元数据不注册，避免形成多个入口。yuzhou 的图标保留；本包入口和界面元数据统一。

原始材料中的真实案例、日期、统计、研究结论、机器路径和平台收益保持来源身份，不当成当前项目事实。Sepia 研究账本原有的仓库内链接已改成本包路径，内容含义不变。引用研究或回答实时平台信息时，另行核对来源，不能把打包保留等同于验证。

[来源文件清单](../source-manifest.json) 记录本次使用的六个压缩包大小和 SHA-256，以及 Sepia 合并的共同文件，便于校验。
