# 冲突裁决：yuzhou 优先

本文件把六个来源的实际差异转成统一执行规则。用户最新明确指令与本书确认材料仍优先；其他来源不能借“铁律”“硬指标”推翻 yuzhou。所有路径以本技能目录为根；原始参考内的相对链接仍按所在文件解析。

| 冲突点 | 其他来源的倾向或硬要求 | 本包采用的 yuzhou 规则 |
| --- | --- | --- |
| 爽点定义 | 只认打击敌人和造成物理损失，否定理解、和解等 | 判断与行动带来可观察结果、可使用回报；知识、专业认可、救人、资源与自由选择都可成立 |
| 主角主动性 | Sepia 按样本比例让外部人物、机构或偶然决定结局 | 尊重本书主线和主角选择；外部力量须有因果，不为统计比例夺走主角成果 |
| 战斗频率 | 每章物理对抗，前 300 字必有爆炸或攻击 | 一章可只完成场景单元的一段；日常、谈判、失败、告别均可成立，不能强塞战斗 |
| 爽点数量 | 3/5/10 章固定高潮、余韵最多两章 | 用当前单元的期待和兑现安排节奏，不固定每章或每若干章的数量 |
| 正面角色牺牲 | 每约 80 章必须永久牺牲 | 伤亡服从既定剧情和真实后果；不为指标杀人，不把所有代价都改成死亡 |
| 结尾方式 | 只准危机、挑衅、倒计时；或为去 AI 味少结一笔账 | 回应当前场景的选择、情绪和承诺；允许温暖、回报与告别，不能漏掉该交付的结果 |
| 因果链 | Sepia 为结构稀有度强制断开一处因果、留一个不回收细节 | 重要转折要有可追溯因果；环境细节不必全是伏笔，明确承诺的伏笔须有结果 |
| 非线性与反转 | 必加时间跳跃、后置披露、一个稀有结构动作 | 根据本书信息顺序和现场需求选用；清楚优先，不打乱时间账或提前透露真相 |
| 感官与情绪 | 一律动作替代情绪标签；或按感官比例校准 | 允许直接情绪、内心、动作与感官混用；保留肉疼、得意、委屈等温度，避免同质化 |
| 配角与群像 | 强制三人组、固定配角高光配额或全面压缩群像 | 重要角色有独立目标、知识、长处、底线和选择；人数与视角服务当前作品 |
| 全员关系 | Sepia 让人际图趋于中性、减少温暖关系 | 以实际关系证据为准，不为分布指标拆散朋友或强加敌意 |
| 幽默 | 追求固定反转或戏谑动作 | 来自合理认知差与熟人历史，不降智，不打断重大情绪兑现 |
| 新增与删减 | Sepia 固定编辑比例，新增只能补具体性或语法 | 先修逻辑与缺戏，再修爽感、情绪与语言；必要时补场景，允许篇幅增加，按用户字数要求控制 |
| 词与句式禁用 | “不是……而是”、感到、缓缓等发现就删 | 结合重复、语境和功能逐处判断；准确辨别、自然口语和作者惯用表达可保留 |
| 标点和字数 | 按破折号、感叹号、粗口、CJK 密度硬阈值执行 | 用户字数与格式要求执行；统计只作定位提示，不凭标点判 AI，不批量替换 |
| 对白保护 | Sepia 把所有引号内文字视为不可修改 | 用户授权精修对白时可修改；用户明确保护的段落、准确引文和关键情节台词按其边界保留 |
| 固定报告 | 必须先公开缺陷表、模型身份、Voice fit 和每章汇报 | 用户只要正文就直接正文；审稿给定位、依据、影响和改法，不输出无关模板。亲密互动留白的位置告知是用户指定例外，另列于正文之后 |
| 精修权限 | 改良技能鼓励随意砍章、重排和加高能章 | 保剧情精修保留必达事件、伏笔、动机、关系和所得；重大结构重写只按用户授权 |
| 真实引用与虚构 | Sepia 要求至少一个真实品牌、地点或文本 | 原创世界可以虚构，不强塞现实锚点；真实事实与引文准确，不伪造出处 |
| 作者风格 | 固定两位作者比例，或叠加 Hemingway 等 profile | 创作原创语言和人物；用通用技法，不复刻在世作者独特文风。额外风格仅按用户明确选择 |
| 模型归因与评分 | 按指纹推测生成模型，保证 9.0+ 或检测效果 | 不从文风判断作者身份，不把启发式当检测器，不承诺平台评分、收入或检测通过率 |
| 外部技能依赖 | 要求叠加 qidian、智斗等其他技能 | 六个来源已内置，无外部技能依赖；不虚称加载未安装的技能，不自动调用其他模型 |
| 终局社会结果 | 案例把主题升级、制度或共同建设当必然收束 | 核对局势、制度、关系和生活是查账维度，不要求新增制度改革、共同治理、团圆或婚育；用户决定结局 |

原始参考给出新的硬要求时，先问它是否服务本书场景和 yuzhou 的上述原则。没有明显冲突的具体技术可选用；遇到无法裁决的重大剧情分歧才询问用户，普通实现细节自主处理。
