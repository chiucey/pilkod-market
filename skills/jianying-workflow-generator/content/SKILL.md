# 剪映工程工作流生成器

根据提供的素材（视频/图片/音频）和文案脚本，自动生成完整的剪映(CapCut)视频工程工作流程。

## 工作流程

### 1. 素材分析

**输入要求**：
- 视频素材：列出所有视频文件的时长、分辨率、内容描述
- 图片素材：列出所有图片
- 音频素材：列出背景音乐、音效文件
- 文案脚本：完整的故事文本或分镜文本

**分析维度**：
- 时长匹配：素材总时长与目标时长的一致性
- 场景划分：根据文案自动识别场景数量
- 情绪节奏：识别文案中的情绪高点与低点
- 重点标注：识别需要强调的关键信息

### 2. 工作流生成

根据分析结果，自动生成以下工作流程：

#### 2.1 剪辑规划

```json
{
  "timeline": {
    "total_duration": "目标总时长",
    "scenes": [
      {
        "id": 1,
        "name": "场景名称",
        "duration": "时长",
        "source_clips": ["素材列表"],
        "cut_points": [
          {"time": "00:00", "action": "cut_type", "reason": "说明"}
        ]
      }
    ]
  }
}
```

#### 2.2 转场方案

```json
{
  "transitions": [
    {
      "from_scene": 1,
      "to_scene": 2,
      "type": "转场类型",
      "duration": "时长",
      "reason": "使用原因"
    }
  ]
}
```

**转场类型推荐**：
- 场景切换：硬切、淡入淡出、闪白
- 情绪递进：叠化、推移
- 时间过渡：模糊、旋转
- 创意转场：缩放、错位

#### 2.3 特效设计

```json
{
  "effects": [
    {
      "scene_id": 1,
      "type": "特效类型",
      "position": "位置/时间点",
      "parameters": {
        "intensity": "强度",
        "duration": "持续时间"
      }
    }
  ]
}
```

**特效类型**：
- 画面增强：亮度、对比度、饱和度、锐化
- 风格滤镜：复古、电影感、赛博朋克、莫兰迪
- 动态效果：缩放、位移、旋转、抖动
- 创意特效：粒子、光效、遮罩

#### 2.4 字幕设计

```json
{
  "subtitles": [
    {
      "id": 1,
      "text": "字幕文本",
      "start_time": "00:00",
      "end_time": "00:05",
      "style": "字幕样式",
      "animation": "入场/出场动画",
      "position": "位置"
    }
  ]
}
```

**字幕样式**：
- 基础字幕：白色黑边、描边、阴影
- 动感字幕：弹跳、打字机、淡入淡出
- 创意字幕：手势跟随、表情包、装饰框
- 多语言字幕：双语对照

#### 2.5 动画设计

```json
{
  "animations": [
    {
      "element": "元素类型",
      "scene_id": 1,
      "in_animation": "入场动画",
      "out_animation": "出场动画",
      "duration": "时长",
      "easing": "缓动函数"
    }
  ]
}
```

**动画类型**：
- 入场：从左/右/上/下进入，弹跳，缩放，淡入
- 出场：向左/右/上/下退出，消失，缩小
- 强调：脉冲，抖动，呼吸效果
- 路径：沿自定义路径运动

#### 2.6 音频设计

```json
{
  "audio": {
    "background_music": {
      "file": "背景音乐文件",
      "volume": 0.3,
      "fade_in": "00:00",
      "fade_out": "结束前5秒"
    },
    "sound_effects": [
      {
        "type": "音效类型",
        "position": "位置",
        "volume": 0.5
      }
    ],
    "voice_over": {
      "source": "配音文件",
      "sync_with_subtitle": true
    }
  }
}
```

### 3. 输出格式

生成完整的工作流程文档，包含：

1. **项目结构图**：整体时间线可视化
2. **分镜脚本表**：每个场景的详细说明
3. **素材清单**：所有需要的素材及使用位置
4. **操作步骤**：按时间顺序的详细操作指南
5. **参数配置**：所有特效、动画的具体参数值

### 4. 剪映操作指南

为每个工作流步骤提供具体的剪映操作指引：

- 如何添加剪辑点
- 如何应用转场效果
- 如何添加字幕模板
- 如何设置关键帧动画
- 如何调整音频混音

## 示例输入与输出

### 输入示例

**素材**：
- video1.mp4 (0:30) - 产品展示
- video2.mp4 (0:45) - 使用场景
- video3.mp4 (0:20) - 用户评价
- bgm.mp3 - 背景音乐
- logo.png - 品牌logo

**文案**：
```
开场：产品介绍 (0-5秒)
主体：功能展示 (5-25秒)
高潮：核心卖点 (25-35秒)
结尾：品牌呼吁 (35-45秒)
```

### 输出示例

生成完整的工作流程文档，包含45秒视频的全部剪辑方案。

- 品牌宣传片：企业介绍、产品发布

- 活动记录：会议、婚礼、旅行
- 社交媒体：朋友圈、微博、小红书
