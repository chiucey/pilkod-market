# 剪映工作流示例参考

本文档提供常见视频类型的工作流模板和示例，帮助理解如何根据素材和文案生成完整的工作流程。

## 一、短视频类型工作流

### 1.1 种草带货视频 (30-60秒)

**特点**：
- 节奏快，信息密度高
- 前3秒必须有吸引点
- 突出产品卖点和使用效果

**工作流结构**：

```json
{
  "video_type": "种草带货",
  "target_duration": "45秒",
  "structure": {
    "hook": {
      "duration": "0-3秒",
      "content": "痛点引入/惊人数据",
      "style": "快闪/悬念"
    },
    "body": {
      "duration": "3-35秒",
      "segments": [
        {"time": "3-10秒", "content": "产品展示", "cuts": 3},
        {"time": "10-20秒", "content": "功能介绍", "cuts": 4},
        {"time": "20-30秒", "content": "使用效果", "cuts": 3},
        {"time": "30-35秒", "content": "用户证言", "cuts": 2}
      ]
    },
    "cta": {
      "duration": "35-45秒",
      "content": "购买引导",
      "style": "品牌logo+行动号召"
    }
  },
  "effects": ["节奏感强的BGM", "产品特写放大", "文字弹跳入场"],
  "subtitles": "大号字幕，关键卖点高亮"
}
```

### 1.2 知识科普视频 (1-3分钟)

**特点**：
- 信息清晰易懂
- 画面配合文案讲解
- 节奏适中，重点突出

**工作流结构**：

```json
{
  "video_type": "知识科普",
  "target_duration": "90秒",
  "structure": {
    "intro": {
      "duration": "0-5秒",
      "content": "话题引入，设置悬念"
    },
    "main_content": {
      "duration": "5-75秒",
      "segments": [
        {"time": "5-25秒", "content": "背景/问题描述"},
        {"time": "25-50秒", "content": "核心知识点1"},
        {"time": "50-75秒", "content": "核心知识点2"}
      ]
    },
    "summary": {
      "duration": "75-85秒",
      "content": "要点总结"
    },
    "outro": {
      "duration": "85-90秒",
      "content": "互动引导/关注提醒"
    }
  },
  "effects": ["信息图表动画", "时间线展示", "示意图标注"],
  "subtitles": "配合讲解的动态字幕"
}
```

## 二、转场特效参考

### 2.1 场景切换转场

| 转场类型 | 适用场景 | 建议时长 | 剪映操作 |
|---------|---------|---------|---------|
| 硬切 | 节奏感强的切换 | 0秒 | 直接拼接 |
| 淡入淡出 | 情绪过渡 | 0.5-1秒 | 透明度调整 |
| 叠化 | 时间流逝/回忆 | 1-2秒 | 叠加混合 |
| 闪白 | 强调/转场提示 | 0.2秒 | 亮度峰值 |
| 模糊 | 场景转移 | 0.5秒 | 模糊特效 |

### 2.2 创意转场

| 转场类型 | 视觉效果 | 适用场景 |
|---------|---------|---------|
| 缩放转场 | 前后画面缩放衔接 | 焦点转移 |
| 旋转转场 | 画面旋转过渡 | 动感切换 |
| 推移转场 | 镜头推向黑场 | 深入探索 |
| 遮罩转场 | 图形遮挡切换 | 创意视频 |
| 特效转场 | 光效/粒子过渡 | 科技/炫酷 |

## 三、字幕样式参考

### 3.1 常见字幕样式

```json
{
  "styles": {
    "standard": {
      "font": "思源黑体/阿里巴巴普惠体",
      "size": "视频宽度的4-5%",
      "color": "#FFFFFF",
      "stroke": "#000000",
      "stroke_width": "2px",
      "position": "画面底部10-15%位置"
    },
    "highlight": {
      "background": "半透明黑色",
      "padding": "8px 12px",
      "border_radius": "4px"
    },
    "dynamic": {
      "animation_in": "弹跳/打字机/淡入",
      "animation_out": "淡出",
      "duration": "0.3-0.5秒"
    }
  }
}
```

### 3.2 特殊字幕效果

- **打字机效果**：逐字出现，营造紧张感
- **弹跳效果**：活泼俏皮，适合种草视频
- **描边跟随**：文字跟随人物动作
- **手势字幕**：配合手势的创意字幕
- **双语字幕**：上下或左右排列

## 四、动画设计参考

### 4.1 入场动画

| 动画类型 | 特点 | 适用场景 |
|---------|------|---------|
| 淡入 | 平稳柔和 | 正式内容 |
| 滑入 | 方向感强 | 信息展示 |
| 缩放 | 聚焦效果 | 强调重点 |
| 弹跳 | 活泼动感 | 轻松内容 |
| 旋转 | 酷炫吸睛 | 创意视频 |

### 4.2 强调动画

- **脉冲**：强调关键信息
- **抖动**：表现紧张/激动
- **呼吸**：柔和过渡
- **闪烁**：提醒注意

### 4.3 缓动函数

```
ease-in：开始慢，结束时快
ease-out：开始快，结束时慢
ease-in-out：两头慢，中间快
linear：匀速运动
```

## 五、音频设计参考

### 5.1 BGM选择指南

| 视频类型 | 音乐风格 | 节奏 |
|---------|---------|------|
| 种草带货 | 欢快/洗脑 | 快节奏 |
| 知识科普 | 轻快/平静 | 中等节奏 |
| 情感故事 | 抒情/感人 | 慢节奏 |
| 科技数码 | 电子/未来感 | 中快节奏 |
| 美食旅游 | 轻快/惬意 | 中等节奏 |

### 5.2 音效设计

- **转场音效**：短促有力
- **强调音效**：配合关键帧
- **环境音效**：增强沉浸感
- **UI音效**：交互反馈

### 5.3 音量比例

```
人声/配音：100%
背景音乐：20-30%
音效：30-50%
```

## 六、素材管理建议

### 6.1 素材命名规范

```
日期_视频类型_序号
例：20240301_product_show_01.mp4
```

### 6.2 素材分类

```
/project_name
├── /raw_videos      # 原始视频素材
├── /images          # 图片素材
├── /audio           # 音频素材
├── /exports         # 导出文件
└── /backups         # 工程备份
```

### 6.3 素材整理流程

1. 导入所有素材到剪映
2. 创建素材文件夹分类
3. 标记重要素材
4. 删除不需要的素材
5. 备份原始素材
