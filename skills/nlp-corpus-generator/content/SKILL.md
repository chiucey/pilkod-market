# NLP语义语料生成器

根据用户提供的业务场景和客户原始问法，自动扩展高质量的语义语料和关键字，提升NLP模型对客户意图的识别准确率。

## 核心方法论

### 1. 客户长句处理：意图拆分 + 核心语料变体补充

**输入格式**：
```
原始客户问法：[客户输入的一句话]
业务场景：[所属业务类型，如贷款、还款、结清等]
```

**处理流程**：
1. **意图识别**：判断核心意图（提前还款、查询还款、结清证明等）
2. **实体提取**：识别关键实体（贷款类型、金额、日期等）
3. **句式变换**：生成多种表达方式的变体
4. **关键字提取**：生成用于匹配的关键字列表

**输出格式**：
```json
{
  "original_query": "客户原始问法",
  "core_intent": "核心意图",
  "entities": ["实体1", "实体2"],
  "corpus_variants": [
    {"text": "变体语料", "type": "句式类型", "features": ["特征标签"]}
  ],
  "keywords": ["关键字1", "关键字2"],
  "negative_samples": ["负样本语料"]
}
```

### 2. 让每条相似问都"特征鲜明"

#### 2.1 句式特征覆盖

对每个意图，必须覆盖以下句式类型：

| 句式类型 | 示例 | 变换规则 |
|---------|------|---------|
| 肯定句 | "我要提前还款" | 直接表达需求 |
| 否定句 | "能不能不提前还款" | 疑问/否定表达 |
| 祈使句 | "帮我提前还款" | 请求式表达 |
| 疑问句 | "怎么提前还款" | 询问方式 |
| 陈述句 | "我打算提前还款" | 计划性陈述 |

**变换方法**：
- 添加/删除否定词（不、没、未）
- 变换疑问词（怎么、如何、能不能、可不可以）
- 调整语序（我要→我想）
- 添加语气词（啊、呢、吧）

#### 2.2 场景特征扩展

根据不同业务场景的表达习惯进行扩展：

**常见业务场景**：
- 车贷相关：车贷、车辆贷款、按揭车
- 房贷相关：房贷、房屋贷款、按揭房
- 消费贷相关：消费贷、信用贷、花呗、借呗
- 企业贷相关：企业贷、经营贷、商户贷

**场景化表达示例**：
```markdown
场景：贷款结清
- 标准化：贷款已还清
- 车贷场景：车贷还完了、车辆贷款结清了
- 房贷场景：本贷房贷结清了怎么拿证、房子贷款还完了
- 消费贷场景：消费贷还清了要凭证、信用贷结清证明
```

#### 2.3 情绪特征表达

覆盖不同情绪级别的表达方式：

| 情绪级别 | 特征 | 示例 |
|---------|------|------|
| 平和 | 正常询问 | "请问还款流程是什么" |
| 焦虑 | 急切、重复 | "什么时候可以还款、怎么还没还款入口" |
| 愤怒 | 抱怨、质疑 | "你们到底怎么还款的、还不还了到底" |

**情绪变换规则**：
- 平和→焦虑：添加时间敏感词（马上、立刻、赶紧）
- 平和→愤怒：添加质疑词（到底、究竟、怎么还没）
- 焦虑→愤怒：强化语气（加粗、重申、质问）

#### 2.4 口语/方言特征

覆盖不同语言风格的表达：

| 语言类型 | 特征 | 示例 |
|---------|------|------|
| 书面语 | 正式、规范 | "申请提前结清" |
| 口语 | 随意、口语化 | "我想把贷款全还了" |
| 方言习惯 | 地区性表达 | "还清了咋弄"、"提前还贷行不" |

**口语化变换规则**：
- 书面语→口语：添加语气词、简化句式
- 口语→方言：替换常用词（还款→还钱、结清→弄完）

### 3. 负样本生成策略

**重要性**："什么不是"比"什么才是"更重要

#### 3.1 负样本类型

| 类型 | 说明 | 示例 |
|-----|------|------|
| 意图混淆 | 相近意图的错误表达 | "还款计算器"（查询vs操作） |
| 边界模糊 | 边界情况的错误归类 | "还款延期"（展期vs还款） |
| 噪音样本 | 无意义或错误输入 | "asdfgh"、"？？？" |
| 部分匹配 | 包含关键词但意图不同 | "我想贷款"（贷款咨询vs还款） |

#### 3.2 负样本生成规则

每个意图至少生成5-10条负样本：

1. **近义意图负样本**：同一业务域内的其他意图
2. **跨域混淆负样本**：其他业务域的相似表达
3. **部分特征负样本**：只包含部分关键词的错误匹配
4. **噪音负样本**：常见错误输入、测试语句

#### 3.3 边界样本标注

对边界样本进行特殊标注：

```json
{
  "text": "提前还款违约金怎么算",
  "is_boundary": true,
  "boundary_reason": "涉及还款和费用计算两个意图",
  "primary_intent": "还款",
  "secondary_intent": "费用咨询"
}
```

## 使用流程

### 标准输入

```
用户提供：
1. 业务场景描述（如：车贷提前还款）
2. 客户原始问法（1条或多条）
3. 需要扩展的数量（默认每种句式3-5条）
```

### 处理步骤

1. **意图解析**：识别核心意图和实体
2. **语料扩展**：
   - 按句式特征扩展（每种3-5条）
   - 按场景特征扩展（覆盖相关场景）
   - 按情绪特征扩展（平和/焦虑/愤怒）
   - 按语言风格扩展（书面/口语/方言）
3. **关键字提取**：生成匹配关键字
4. **负样本生成**：生成对比负样本
5. **格式输出**：JSON格式导出
