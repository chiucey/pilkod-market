# 情绪表达映射

## 情绪级别定义

### 1. 平和（Neutral）

**特征**：
- 正常语速和音量
- 使用礼貌用语
- 询问式表达
- 不带强烈情感色彩

**语气词**：
- 请问、请教、麻烦、不好意思

**示例对照**：
| 平和表达 | 情绪标记 |
|---------|---------|
| 请问还款流程是什么 | 礼貌询问 |
| 提前还款怎么办理 | 正常咨询 |
| 想了解违约金怎么算 | 平和询问 |
| 还款入口在哪里 | 直接询问 |

### 2. 焦虑（Anxious）

**特征**：
- 使用时间敏感词
- 重复强调
- 急促语气
- 询问紧急处理方式

**时间敏感词**：
- 马上、立刻、赶紧、加急
- 尽快、尽快处理、马上要
- 着急、急、很急

**重复特征**：
- 重复关键词
- 强调重要性
- 追问进度

**示例对照**：
| 平和表达 | 焦虑表达 |
|---------|---------|
| 请问还款流程是什么 | 急死了怎么还款啊 |
| 提前还款怎么办理 | 赶紧帮我提前还款 |
| 想了解违约金怎么算 | 马上要还款了违约金怎么算 |
| 还款入口在哪里 | 还款入口在哪快告诉我 |

### 3. 愤怒（Angry）

**特征**：
- 使用质问语气
- 质疑服务质量
- 表达不满和抱怨
- 要求解释或赔偿

**质疑词**：
- 到底、究竟、怎么还
- 为什么、凭什么、怎么搞的
- 怎么回事、什么情况

**抱怨词**：
- 一直、总是、每次
- 太慢了、太久了
- 不行、没用、不可以

**示例对照**：
| 平和表达 | 愤怒表达 |
|---------|---------|
| 请问还款流程是什么 | 你们到底怎么还款的 |
| 提前还款怎么办理 | 还不还了到底 |
| 想了解违约金怎么算 | 怎么还没人告诉我违约金 |
| 还款入口在哪里 | 还款入口到底在哪 |

## 情绪变换规则

### 平和→焦虑

**规则**：
1. 添加时间敏感词（马上、立刻、赶紧）
2. 添加强调词（急、很急、快）
3. 添加感叹号和重复

**变换示例**：
```
平和: 请问提前还款怎么办理
焦虑: 急！请问提前还款怎么办理！马上要逾期了！

平和: 违约金怎么计算
焦虑: 赶紧告诉我违约金怎么算
```

### 平和→愤怒

**规则**：
1. 替换礼貌词为质疑词
2. 添加质问语气（到底、究竟）
3. 表达不满和抱怨

**变换示例**：
```
平和: 请问还款流程是什么
愤怒: 你们到底怎么还款的

平和: 提前还款怎么办理
愤怒: 还不还了到底，怎么一直办不了
```

### 焦虑→愤怒

**规则**：
1. 强化质问语气
2. 添加抱怨内容
3. 表达对服务的不满

**变换示例**：
```
焦虑: 急死了怎么还没人处理
愤怒: 到底怎么回事！一直没人处理！
```

## 场景化情绪表达

### 还款场景

| 情绪 | 表达示例 |
|------|---------|
| 平和 | "请问怎么还款" |
| 焦虑 | "急！马上还款日了怎么还没入口" |
| 愤怒 | "还款入口到底在哪！等了多久了！" |

### 逾期场景

| 情绪 | 表达示例 |
|------|---------|
| 平和 | "逾期了怎么处理" |
| 焦虑 | "已经逾期了怎么办" |
| 愤怒 | "怎么就逾期了！没人通知我！" |

### 结清场景

| 情绪 | 表达示例 |
|------|---------|
| 平和 | "结清证明怎么获取" |
| 焦虑 | "急要结清证明怎么弄" |
| 愤怒 | "结清证明怎么还没发给我！" |

## 情绪词库

### 平和词库
```
礼貌词: 请问、请、麻烦、请教、打扰、不好意思
询问词: 怎么、如何、什么、多少、能否
中性词: 想、需要、了解、查询、知道
```

### 焦虑词库
```
时间词: 马上、立刻、赶紧、尽快、加急、火速
强调词: 急、很急、着急、紧急、重要
催促词: 快、快点、快点处理、赶紧的
```

### 愤怒词库
```
质疑词: 到底、究竟、怎么、为什么、凭什么
抱怨词: 一直、总是、每次、太、没、没人在
威胁词: 投诉、差评、曝光、举报、反馈
```
