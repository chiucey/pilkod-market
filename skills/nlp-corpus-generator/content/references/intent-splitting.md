# 意图拆分方法论

## 什么是意图拆分

意图拆分是将客户复杂的长句拆解为多个原子意图的过程，每个原子意图代表一个独立的、可被NLP模型识别的语义单元。

## 拆分原则

### 1. 原子性原则
每个原子意图应该：
- 只包含一个核心动作或需求
- 不可再分割
- 有明确的业务含义

### 2. 独立性原则
- 原子意图之间应相互独立
- 可以单独处理和识别
- 组合后形成完整语义

### 3. 覆盖性原则
- 拆分后应覆盖原句所有信息
- 不丢失关键实体和约束
- 保留语义关联

## 拆分方法

### 方法一：基于动宾结构的拆分

**原句**: "我想提前还款但是不知道怎么计算违约金"

| 原子意图 | 动作 | 宾语 | 补充信息 |
|---------|------|------|---------|
| 意图1 | 提前还款 | 提前还款操作 | - |
| 意图2 | 查询 | 违约金计算方式 | 条件：提前还款时 |

### 方法二：基于并列结构的拆分

**原句**: "我要提前还款并开具结清证明"

| 原子意图 | 说明 |
|---------|------|
| 意图1 | 提前还款 |
| 意图2 | 开具结清证明 |

### 方法三：基于转折结构的拆分

**原句**: "我想提前还款但是违约金太高"

| 原子意图 | 说明 |
|---------|------|
| 意图1 | 提前还款（核心意图） |
| 意图2 | 反馈违约金问题（次要意图） |

## 常见意图类型

### 操作类意图
- 提前还款
- 部分还款
- 查询还款金额
- 开具证明
- 修改还款账户

### 咨询类意图
- 还款流程咨询
- 费用计算咨询
- 政策咨询
- 产品咨询

### 投诉类意图
- 还款失败投诉
- 费用过高投诉
- 服务态度投诉

## 实体提取

### 贷款相关实体
```
贷款类型: [车贷, 房贷, 消费贷, 企业贷, 信用贷]
贷款状态: [正常, 逾期, 展期, 结清]
时间相关: [今天, 明天, 本月, 下月, 还款日]
金额相关: [全部, 部分, 最低还款额, 本金, 利息]
```

```
操作类型: [提前, 部分, 全额, 分期]

```
