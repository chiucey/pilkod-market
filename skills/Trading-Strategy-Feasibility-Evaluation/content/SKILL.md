# 交易策略可行性评估与系统构建核心框架

> **核心心法**：交易是系统工程与金融工程，而非算命或纯心理学。你必须像监测火箭飞行一样，用多维量化指标来感知策略运行状态。**“不依赖好运气，坏运气打不败”**是职业交易的终极生存法则。

---

## 一、 交易系统根本认知

1. **必须形成闭环**：完整的交易系统是“买进-卖出-再买进”（开仓-平仓-再开仓）的完整流程。仅关注高胜率买入或卖出是“盲人摸象”，无法以交易为生。
2. **量化评估框架**：不仅要把做法量化形成系统，还要有量化的框架去评估该系统是否具备实盘能力。仅看收益率远远不够，需审查数十个体检指标。
3. **知己重于知彼**：出手前务必“知己”。了解自己的策略问题出在哪，比了解市场更重要。
4. **区分问题属性**：遇到亏损时，必须量化判断是“策略本身有缺陷”（需立即停止/修改），还是“市场短期风格不利”（需坚持）。

---

## 二、 交易者四大基本原则

1. **家国原则**：净头寸持仓方向必须与国家利益一致，财富增长源于国运向上，不与国家博弈。
2. **息价原则**：低利率周期做多股权，高利率周期做多债券。
3. **取舍原则**：主动放弃潜在利润以回避潜在风险。绝不想着赚尽每一分钱，否则终被市场收走。
4. **坐标原则**：建立坐标参照系，对价差（回归）下注，而不是对绝对价格下注。

---

## 三、 策略验证四步严谨流程

绝不用真金白银试验未经验证的方法，从实验到实战必须依次通过：

1. **历史样本回测**：用长期历史数据检验策略基本逻辑的可行性。
2. **蒙特卡罗测试**：用成千上万次随机波动结构挑战策略，测试其韧性，**必须测到策略失控为止**，找到命门（一旦出现此结构即拔电源关机）。注意伪随机数缺陷。
3. **样本外测试**：防止过度拟合。将历史数据分段（如7年优化参数，3年验证），用未参与优化的数据独立跑实况。
4. **实盘测试**：用极小单量（1-2手）验证滑点、手续费、成交效率等真实成本与执行细节。

## 四、 策略评估核心指标体系

### 1. 基础收益与盈利能力
| 指标 | 核心判断标准与解读 |
| :--- | :--- |
| **净利润** | < 0 直接淘汰。优化方向不仅看怎么多赚，更要看怎么控制总亏损。 |
| **盈利因子** | 总盈利/总亏损。**接近1或<1淘汰**；>1.5可进行下去；越大盈利能力越强。 |
| **年化收益率** | **必须显著高于无风险收益率**（国内参考3.5%-7%），否则不如买固收。 |

### 2. 风险与回撤控制
| 指标 | 核心判断标准与解读 |
| :--- | :--- |
| **最大资产回撤(金额/幅度)** | 衡量心理与资金承受力。用于反推需准备的额外保证金（建议≥1手保证金）。 |
| **恢复因子** | 净利润/最大回撤金额。考察风险回报关系，太低说明赚的钱只是在回本。 |
| **年化收益/最大回撤幅度** | **最好>2，>3更优**。衡量承受最大风险换来的年化回报。 |
| **多空交易次数平衡** | **必须保持市场中性**。多空次数严重失衡说明参数优化有问题，未来极易在单边市中持续止损。 |

### 3. 盈利质量与运气成分
| 指标 | 核心判断标准与解读 |
| :--- | :--- |
| **胜率** | **不需要高胜率**！>30%即可，>50%已极难得。90%胜率不切实际。 |
| **盈亏比** | 趋势策略追求高盈亏比（小亏换大盈），短线相对较低。需警惕交易频率过高导致佣金吞噬利润。 |
| **去离群分析** | 剔除3倍标准差外的极端交易。若去离群后盈利大幅锐减，说明策略严重依赖运气而非稳定逻辑。 |
| **最大单赢/总盈利** | 比值过高表明盈利不可复制，高度依赖特定行情。 |
| **最大单亏/总亏损** | 比值过高提示存在未识别的“黑天鹅”风险，若无法归因应弃用策略。 |

### 4. 极端参数与时间维度
| 指标 | 核心判断标准与解读 |
| :--- | :--- |
| **最大连盈/连亏** | 可作为资金曲线投机参考：接近历史最大连盈时减仓防风险，接近最大连亏时逐步加仓。 |
| **平均持仓/盈亏周期** | 判断策略风格。**理想状态**：盈利周期长（耐心持有），亏损周期短（及时止损）。 |
| **月度收益标准差** | 衡量月度收益波动（月乖离风险），是计算风险调整后收益的基础。 |
| **佣金与滑点成本** | 高频策略的生死线。若年佣金达本金50%，策略不可行；极端行情滑点极大，必须实盘验证。 |

### 5. 仓位与组合分析
| 指标 | 核心判断标准与解读 |
| :--- | :--- |
| **持仓时间占比** | 持仓比例需与策略风险暴露面匹配。仓位轻则需拉长持仓时间换取波动；仓位重则需学会空仓。 |
| **最大空仓时间** | “会买是徒弟，会卖是师傅，会空仓是祖师爷”。空仓是为了控制风险暴露。 |
| **获利日占比** | 日常执行中感受到的“盈利日子”比例，影响执行心态，但不直接决定策略优劣。 |
| **平均仓位(净头寸)** | 组合内模型多空对冲可降低风险暴露面（如仅14%），单边行情时则自然集中进攻，实现最优加减仓。 |

### 6. 风险调整后收益（绩效比率）
| 指标 | 核心逻辑 |
| :--- | :--- |
| **夏普比率** | 超额收益 / 总风险标准差。单位总风险换超额收益的度量。 |
| **索提诺/奥瑟比率** | 超额收益 / 下行风险标准差。只对亏损风险惩罚，更符合交易者心理。基准收益率可自设，强调超越自然增长的部分才是真实贡献。 |

## 五、 实战铁律与忠告

1. **本金安全第一**：以交易为生，本金亏完即失业。宁可休息放假，也要回避不确定性，追求财富持续积累而非账户剧烈波动。
2. **绝不盲目实盘**：问出“我能不能实盘”时，说明准备不足。绝不赞成辞职炒股或卖房炒股。
3. **警惕过度拟合**：不主张使用过多参数，推荐非参模型以保持市场中性。
4. **固定手数原则**：模型初学者最好使用固定手数，便于判断异常；通过不同模型的组合来实现加减仓，而非在单一算法中嵌入加减仓逻辑。
