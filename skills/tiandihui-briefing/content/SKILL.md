## Cron 任务设置

使用 `cron` 工具创建定时简报任务，`sessionTarget: "isolated"`, `payload.kind: "agentTurn"`。

示例任务结构（06:00 UTC 美股简报）：
```json
{
  "name": "06:00 UTC 美股+大宗商品简报",
  "schedule": { "kind": "cron", "expr": "0 6 * * *", "tz": "UTC" },
  "payload": { "kind": "agentTurn", "message": "生成今日06:00 UTC简报：美股道琼斯+纳斯达克+标普500行情、黄金价格、石油价格、伊朗战局最新动态。用水浒传江湖气文风作开场白和结尾语。" },
  "sessionTarget": "isolated",
  "delivery": { "mode": "announce", "channel": "feishu", "to": "天地会总舵" }
}
```
