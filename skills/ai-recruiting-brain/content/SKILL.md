# AI招聘大脑 - 智能招聘辅助系统

## 触发短语

当用户要求以下场景时使用：
- 分析岗位需求、拆解任职资格
- 评估简历与岗位的匹配度
- 生成面试问题和考察维度
- 对候选人面试进行评分
- 生成候选人评估报告（含岗位重定位建议）
- 招聘、面试、人才评估、JD分析

---

## 核心能力

端到端智能招聘辅助，涵盖：
1. **岗位分析** - 从JD提取核心任职要素（区分IC岗/管理岗）
2. **简历匹配** - 评估候选人与岗位的匹配程度
3. **面试规划** - 生成岗位类型定制化的面试问题
4. **面试评分** - 结构化评分 + 雷达图可视化
5. **迭代评估** - 多轮面试持续完善候选人画像
6. **评估报告** - 雷达图 + 维度分析 + 轮次总结 + 录用建议

## 工作流程

### 步骤1：岗位需求分析与任职要素拆解

**输入**：用户提供的岗位需求（简短描述或完整JD）

**执行流程**：

1. **识别岗位类型**：根据关键词判断岗位类别

| 岗位大类 | 典型关键词 | 核心考察维度 |
|----------|------------|--------------|
| 技术类 | 研发、工程师、前端、后端、算法、数据 | 技术深度、项目经验、架构能力 |
| 产品类 | 产品经理、BA、需求分析 | 需求洞察、产品思维、数据分析 |
| 运营类 | 运营、策划、增长、用户运营 | 运营能力、创意策划、数据驱动 |
| 销售类 | 销售、客户经理、BD、招商 | 销售能力、客户关系、资源整合 |
| 市场类 | 市场、品牌、公关、营销 | 市场洞察、品牌思维、资源整合 |
| 管理类 | 总监、VP、负责人、经理 | 战略思维、团队管理、跨部门协作 |
| 职能类 | HR、财务、法务、行政 | 专业能力、流程规范、服务意识 |

2. **判断岗位性质**：IC (Individual Contributor) vs 管理岗

```
询问用户：
"请确认该岗位是IC岗还是管理岗？"
- IC岗：聚焦个人贡献，技术/业务专家路线
- 管理岗：带团队，对团队结果负责
```

3. **拆解任职要素**：按以下维度结构化输出

```
## 岗位任职要素表

**岗位名称**：[从输入中提取]

**岗位性质**：[IC岗 / 管理岗]
```

```
### 步骤3：面试规划与问题生成

**输入**：步骤2的匹配度分析结果

**执行**：根据岗位类型生成定制化面试方案

**岗位类型对应的考察维度模板**：

#### 技术类-IC岗
- 技术深度（30%）：原理理解、代码能力、问题分析
- 项目经验（25%）：角色担当、技术选型、问题解决
- 架构设计（20%）：系统思维、技术视野
- 沟通协作（15%）：表达清晰、文档能力
- 潜力成长（10%）：学习能力、技术热情

#### 技术类-管理岗
- 团队管理（30%）：目标设定、绩效辅导、人才梯队
- 技术判断（25%）：技术决策、技术深度保持
- 项目统筹（20%）：跨团队协作、资源调配
- 战略落地（15%）：理解业务、技术规划
- 文化传承（10%）：团队氛围、技术氛围建设

#### 产品类
- 需求洞察（30%）：用户理解、需求挖掘
- 产品设计（25%）：方案设计、原型能力
- 数据分析（20%）：数据驱动、A/B测试
- 跨部门协作（15%）：沟通协调、资源争取
- 商业敏感（10%）：商业模型理解

#### 销售类
- 销售能力（35%）：客户开发、谈判签单
- 客户关系（25%）：客户维护、复购增购
- 资源整合（20%）：内外部资源协调
- 市场洞察（10%）：竞争分析、行业理解
- 自我驱动（10%）：目标达成、抗压能力
```

```
### 步骤4：面试评分

| 分数 | 等级 | 说明 |

| 2 | 较差 | 明显低于要求 |
| 3 | 一般 | 基本达标，有提升空间 |
| 4 | 良好 | 超出预期 |
| 5 | 优秀 | 远超预期，亮点突出 |
```

## 注意事项

1. **岗位类型识别**：在步骤1首先识别岗位类型，选用对应的考察维度模板
2. **IC vs 管理岗**：管理岗需额外考察团队管理能力和战略思维
3. **信息完整性**：提供的信息越详细，输出质量越高
4. **迭代优化**：多轮面试比单轮评估更准确，建议至少2轮
5. **隐私保护**：所有输入内容仅用于本次分析
6. **人工决策**：AI辅助分析，最终决策需结合人工判断
7. **岗位重定位意识**：当发现人选能力与岗位不匹配时，主动建议更适合的方案
8. **职级匹配度监控**：在简历分析和最终评估时，持续关注职级匹配度偏差
