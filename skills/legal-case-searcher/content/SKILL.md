# 类案检索助手

专业的法律案例检索与分析工具，遵循严格五步流程确保输出可核验、有说服力的类案报告。

## 支持的案件类型

- **劳动争议**：劳动合同、社保、工伤、违法解除等
- **合同纠纷**：违约责任、合同效力、表见代理等
- **知识产权**：专利侵权、著作权、商标等
- **不正当竞争**：流量劫持、数据抓取、广告屏蔽等

## 三大检索模式

### 1. 关键词检索
灵活组合争议点、法律领域、地域等关键词进行检索。

### 2. 法条检索
精准定位特定法律条款（如《劳动合同法》第38条）的适用案例。

### 3. 案由检索
按标准案由（如"劳动争议"、"买卖合同纠纷"）筛选案例。

## 五步标准化检索流程

### 步骤1：明确检索目标与核验口径

**关键问题**：
- 用户要找什么类型的案例？
- 如何定义"命中"（法院说理需与用户需求高度一致）？
- 需要覆盖哪些法律领域或地域？

**输出**：清晰的检索目标和核验标准

### 步骤2：预检索

**任务**：
- 理解相关法条的结构和适用范围
- 获取初步案例线索
- 生成候选关键词组

**策略**：
- 如无法条明确指向，先搜索相关法规了解构成要件
- 记录初步发现的案例案号和法院信息

### 步骤3：整理多组关键词

**P类 Prompt 组（精准匹配）**：
- 核心争议点关键词
- 特定法条表述
- 案由标准术语

**W类 Web 线索组（扩大召回）**：
- 相似表述、同义替换
- 地方性规定关键词
- 典型案例名称线索

**输出**：3-5组互补的关键词组合，覆盖不同召回角度

### 步骤4：执行数据库检索

**字段智能分拣**：
- 标题字段：匹配案件名称
- 裁判要旨字段：匹配核心争议焦点
- 正文字段：全文本匹配

**检索策略**：
- 使用 OR 组合多组关键词
- 使用 AND 限定核心约束
- 使用 NOT 排除明显不相关案例

### 步骤5：逐案核验

**核验清单**：
- [ ] 案号与判决内容一致
- [ ] 审理法院与文书信息一致
- [ ] 争议焦点与用户需求相关
- [ ] 本院认为部分包含支持性说理
- [ ] 原文链接可访问验证

**淘汰标准**：
- 法院说理与用户需求方向相反
- 案件事实与用户场景差异过大
- 文书内容无法验证

## 输出报告模板

```markdown
# 类案检索报告

## 检索概要
- 检索目标：[核心需求描述]
- 核验口径：[命中标准]
- 检索时间：[时间戳]

## 关键词矩阵

### P类精准关键词组
| 组号 | 关键词组合 | 检索目的 |
|------|-----------|---------|
| P1 | ... | ... |

### W类容错关键词组
| 组号 | 关键词组合 | 检索目的 |
|------|-----------|---------|
| W1 | ... | ... |

## 命中案例

### 案例1：[案件名称]
- **案号**：[案号]
- **审理法院**：[法院名称]
- **审理程序**：[一审/二审/再审]
- **争议焦点**：[焦点描述]
- **本院认为**：[核心说理摘要]
- **原文链接**：[可验证链接]

### 案例2...

## 裁判趋势分析
[基于命中案例归纳的裁判倾向]

## 风险提示
[可能存在的不利案例或注意事项]
```

## 执行原则

1. **准确性优先**：宁可少而精，不堆砌无关案例
2. **可核验性**：所有案例信息均可通过链接验证
3. **结构化输出**：报告格式统一，便于律师在诉讼中使用
4. **全面性**：使用多组关键词从不同角度召回案例
