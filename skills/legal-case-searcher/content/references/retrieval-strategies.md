# 类案检索策略参考

## 劳动争议类案检索策略

### 常用案由
- 劳动合同纠纷
- 经济补偿金纠纷
- 违法解除劳动合同赔偿金纠纷
- 工伤保险待遇纠纷
- 社会保险纠纷

### 核心法条
- 《劳动合同法》第38条（劳动者单方解除权）
- 《劳动合同法》第39条（用人单位单方解除）
- 《劳动合同法》第40条（无过失性辞退）
- 《劳动合同法》第46条（经济补偿）
- 《工伤保险条例》相关条款

### 关键词组合模板

**P类精准组**：
```
劳动合同解除 + 经济补偿 + 违法解除 + 赔偿金
```

**W类容错组**：
```
劳动关系终止 + 补偿金 + 违法 + 赔偿 + 单位解除
```

## 合同纠纷类案检索策略

### 常用案由
- 买卖合同纠纷
- 借款合同纠纷
- 租赁合同纠纷
- 服务合同纠纷
- 委托合同纠纷

### 核心法条
- 《民法典》第577条（违约责任）
- 《民法典》第584条（损失赔偿）
- 《民法典》第585条（违约金）

### 关键词组合模板

**P类精准组**：
```
合同解除 + 违约责任 + 损失赔偿 + 违约金 + 合同效力
```

**W类容错组**：
```
违约 + 赔偿 + 解除 + 无效 + 不履行 + 迟延履行
```

## 知识产权类案检索策略

### 常用案由
- 著作权侵权纠纷
- 专利权侵权纠纷
- 商标权侵权纠纷
- 技术合同纠纷

### 核心法条
- 《专利法》第64条（侵权判定）
- 《著作权法》第52条
- 《商标法》第57条

### 关键词组合模板

**P类精准组**：
```
专利侵权 + 等同特征 + 全面覆盖 + 侵权赔偿 + 停止侵权
```

**W类容错组**：
```
知识产权 + 侵权 + 赔偿 + 赔偿额 + 损害 + 停止侵害
```
