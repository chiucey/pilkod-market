# 演讲稿生成器

专为中文用户打造的专业演讲稿生成技能，涵盖多种生活与工作场景。

## 核心工作流程

### 第一步：场景识别与信息收集

**识别演讲场景类型：**

| 场景类别 | 关键词 |
|---------|--------|
| 竞选演讲 | 竞选、投票、主席、部长、班长、学生会 |
| 毕业致辞 | 毕业、典礼、校友、毕业感言、离开校园 |
| 婚礼致辞 | 婚礼、结婚、证婚、祝福、新人 |
| 会议发言 | 会议、座谈、报告、汇报、总结 |
| 节日致辞 | 新年、春节、中秋、国庆、劳动节、妇女节 |
| 就职演说 | 就职、任职、履新、上任、就任 |
| 颁奖典礼 | 颁奖、表彰、获奖、荣誉、成就 |
| 追悼会 | 悼词、追悼、缅怀、告别、纪念 |
| 开幕/闭幕 | 开幕、闭幕、启动、结束、圆满 |

**收集关键信息：**

- 演讲者身份（谁在讲）
- 听众群体（讲给谁）
- 核心主题（讲什么）
- 情感基调（温暖感人/振奋人心/庄重严肃/轻松活泼）
- 时间限制（几分钟的演讲）
- 特殊要求（是否需要金句、数据、故事）

### 第二步：结构设计

**标准演讲结构：**

```
【开场】抓注意力（问题/故事/数据/引用）
    ↓
【主体】逻辑递进（2-4个要点）
    ↓
【高潮】情感共鸣（核心金句）
    ↓
【结尾】号召/感谢/展望
```

**各场景适用结构：**

- **竞选演讲**：问题-方案-承诺结构
- **毕业致辞**：回忆-感恩-展望结构
- **婚礼致辞**：相识-相知-相爱-祝福结构
- **会议发言**：情况-问题-对策结构
- **节日致辞**：回顾-成就-祝福结构

### 第三步：内容生成

**开场技巧：**

- 提问开场：「你们有没有想过...」
- 故事开场：「记得十年前...」
- 数据开场：「过去一年，我们...」
- 引用开场：「正如某位伟人所说...」
- 互动开场：「请大家举手示意...」

**金句模板库：**

| 场景 | 金句类型 | 示例 |
|------|---------|------|
| 竞选 | 承诺金句 | 「给我一个机会，还你一个惊喜」 |
| 毕业 | 离别金句 | 「今天你以母校为荣，明天母校以你为荣」 |
| 婚礼 | 爱情金句 | 「执子之手，与子偕老」 |
| 会议 | 目标金句 | 「没有最好，只有更好」 |
| 节日 | 祝福金句 | 「祝大家在新的一年里...」 |

**情感表达技巧：**

- 真诚第一：避免套话，用真实情感打动人
- 具体细节：加入具体故事、数字、例子
- 适当幽默：调节气氛，拉近距离
- 肢体语言提示：标注「（停顿）」「（掌声）」

### 第四步：优化与调整

**检查清单：**

- [ ] 开场是否足够吸引人？
- [ ] 核心信息是否清晰突出？
- [ ] 情感是否真挚动人？
- [ ] 时间长度是否合适？
- [ ] 是否适合目标听众？
- [ ] 是否有记忆点（金句）？

**常见问题修正：**

- 太长 → 删除次要内容，保留核心
- 太空 → 加入具体故事或数据
- 太正式 → 适当口语化，加入幽默
- 太随意 → 加强逻辑结构，增加深度

### 第五步：交付格式

**完整演讲稿包含：**

```markdown
# [演讲标题]

**场景：** [具体场景]
**时长：** [建议时长]
**基调：** [情感风格]

---

## 开场

[开场内容 + 可能的互动提示]

## 正文

### 要点一：[核心观点]

[展开内容]

### 要点二：[核心观点]

[展开内容]

## 高潮

[情感升华的核心段落]

## 结尾

[号召/感谢/展望]

---

**建议金句：**
> [可单独提取的核心金句]

**备注：** [特殊注意事项]
```

## 场景专项指南

### 竞选演讲

**核心要素：**

- 简短有力的自我介绍
- 针对问题的解决方案
- 个人优势与承诺
- 号召投票的请求

**注意事项：**

- 控制时长在3-5分钟
- 避免空洞口号
- 展现自信但不傲慢
- 适当幽默调节气氛

### 毕业致辞

**核心要素：**

- 回忆校园时光
- 感恩师长同学
- 分享人生感悟
- 展望未来前程

**注意事项：**

- 情感真挚，避免过度煽情
- 加入个人真实故事
- 避免说教感
- 留下希望与祝福

### 婚礼致辞

**核心要素：**

- 祝福新人
- 分享新人的美好品质或故事
- 婚姻智慧或建议
- 美好祝愿

**注意事项：**

- 根据身份调整立场（证婚人/长辈/朋友/同事）
- 避免提及前任或其他敏感话题
- 适度而不冗长
- 营造温馨氛围

### 会议发言

**核心要素：**

- 精炼的情况汇报
- 清晰的问题分析
- 可行的解决方案
- 明确的行动计划

**注意事项：**

- 语言专业、逻辑清晰
- 数据支撑观点
- 控制时长，尊重他人
- 准备Q&A应对

### 节日致辞

**核心要素：**

- 节日的意义阐述
- 回顾与展望
- 感谢与祝福
- 凝聚人心

**注意事项：**

- 切合节日主题
- 情感温暖向上
- 避免过度冗长
- 适合公开场合朗读
