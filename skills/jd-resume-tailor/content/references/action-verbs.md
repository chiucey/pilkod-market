## 动词强度等级

### 顶级动词（最强烈）
```
Spearheaded 主导
Pioneered 开创
Transformed 变革
Orchestrated 统筹
Revolutionized 革新
```

### 高级动词
```
Led 领导
Delivered 交付
Achieved 达成
Implemented 实施
Optimized 优化
```

### 中级动词
```
Contributed 贡献
Supported 支持
Assisted 协助
Participated 参与
Maintained 维护
```

### 初级动词（慎用）
```
Did 做
Helped 帮助
Worked on 参与过
Involved in 涉及
Responsible for 负责（但模糊）
```

## 避免使用的动词
```
Tried 尝试
Hopefully 希望
Maybe 也许
Sometimes 有时
Almost 几乎
```

## 组合表达模板

### 数字+动词+结果
```
"Increased sales by 40% YoY through strategic partnerships"
"Reduced system downtime by 60% via automated monitoring"
```

### 团队+动词+成果
```
"Led a team of 8 engineers to deliver 3 major features"
"Collaborated with cross-functional teams of 20+ members"
```

### 项目+动词+影响
```
"Spearheaded the migration project affecting 500k+ users"
"Launched new product line generating $2M ARR in first quarter"
```
