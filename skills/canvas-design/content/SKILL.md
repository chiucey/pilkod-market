# Canvas Design Skill

Create professional canvas-style visual layouts, infographics, posters, and visual compositions.

## Canvas Design Principles

### Layout Fundamentals

**Grid Systems:**
- Establish consistent spacing
- Use alignment for visual harmony
- Apply the rule of thirds

**Visual Hierarchy:**
- Size indicates importance
- Color draws attention
- Position guides the eye

### Typography

**Font Selection:**
- Maximum 2-3 fonts per design
- Pair serif with sans-serif
- Ensure readability at all sizes

**Text Hierarchy:**
- Headlines: Bold, large
- Body: Regular weight
- Captions: Smaller, lighter

### Color Usage

**Palette Creation:**
- Primary color for branding
- Secondary for support
- Accent for highlights

**Contrast:**
- Ensure text readability
- Test on different backgrounds
