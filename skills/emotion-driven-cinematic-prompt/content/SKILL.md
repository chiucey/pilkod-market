# 情绪驱动电影感提示词 · 

## 核心

把情绪意图翻译成电影视觉决策来写生图提示词。每个镜头、焦段、构图、景深、光、色选择都必须服务想要的情绪——绝不把术语当通用提质词堆砌。输出语言跟随用户。除非用户明确要求生成图片，否则只写和优化提示词、不出图。

## 先想：观众应该感受到什么？

依次推断，再写提示词：

1. 观众位置——受害者 / 目击者 / 追逐者 / 上帝视角 / 亲密参与者。
2. 权力关系——谁支配谁、谁渺小、谁控制空间。
3. 空间心理——开放 / 封闭 / 压缩 / 空旷 / 迷宫 / 垂直 / 坍塌。
4. 叙事焦点——人 / 威胁 / 物 / 环境 / 光 / 缺席。
5. 视觉温度——有生命 / 温暖 / 无菌 / 死亡 / 神圣 / 被污染。
6. 真实程度——纪录片 / 神话现实 / 灾难现实 / 梦境逻辑。

## 情绪 → 视觉决策表

| 情绪 | 机位 / 焦段 | 构图 / 空间 | 光 / 色 |
|---|---|---|---|
| 恐惧 / 压迫 / 被支配 | 低机位、轻微仰拍；长焦 / 超长焦压缩 | 威胁占主导体量；人作尺度参照；删逃生路线 | 侧逆光穿尘 / 雾；低饱和冷调 |
| 巨大尺度 / 渺小 | 人眼高度或更低 | 人压底部边缘 / 剪影；减竞争物 | 巨物比人参照更清楚 |
| 敬畏 / 神话 / 宗教 | 低机位、正面对称、仪式调度 | 小人物 + 纪念碑主体；垂直 / 圆形支配 | 真实大气逆光光晕；克制金 / 石 / 骨色 |
| 幽闭 / 无路 | 长焦压平、或紧广角近景畸变 | 删天空地平线；雾 / 墙 / 烟封闭画面；藏出口 | 低亮度；出口方向无光 |
| 孤独 / 遗弃 | 远距、静态、旁观 | 大量负空间；人偏离中心且小 | 冷灰 / 褪蓝 / 弱光；环境压过人 |
| 权力 / 权威 | 仰拍(支配) 或 眼平对称(制度) | 居中、对称、垂直、王座轴；压缩柱列 / 人群 | 硬侧光、受控阴影；深暗限制色盘 |
| 追逐 / 恐慌 | 手持、肩高、跟拍背影、低跑视角 | 倾斜线、局部遮挡、前景虚化、破碎构图 | 实用光、雨中反射、强对比、爆高光 |
| 亲密 / 脆弱 | 近距眼平 / 过肩；标准到短长焦 | 脸、手、呼吸距离、小动作、可触表面 | 浅焦锁眼 / 手；暖肤、柔对比 |
| 冷感 / 无生命 | —— | —— | 低饱和；铁 / 骨 / 灰烬色盘；哑光、矿物、冰冻材质 |
| 纪录片灾难真实 | 物理可信曝光，非 CG 光 | 真实大气：尘捉逆光、雨散街灯、烟吞对比、雪压距离 | 不做 CG 光束；克制颗粒、局部泛光 |

镜头速记：低机位＝权力上移(弱势 / 压迫)；高机位＝脆弱 / 被监视；眼平＝纪实在场；广角＝逼近 / 畸变 / 恐慌；长焦＝压缩纵深 / 不可逃避；浅景深＝锁叙事焦点；深焦＝关系全可读。

## 空间封闭（造恐怖 / 无路）

删：天空、地平线、道路、门、窗、消失点、安全地标、明亮背景。换：沙暴、雾、烟、雪、黑暗、雨幕、尘墙、人群、废墟、黑色虚空、空气吞没。

## 硬规则

1. **确定性**——最终提示词不留未决选项：不写 `or` / `或` / `35mm 或 50mm` / `左或右` / 斜杠选项。每个变量（角度、镜头、画幅、视线、姿态、光向、天气、背景）只选一个。
2. **默认电影机质感**——除非用户要别的介质，写真实电影机拍摄 + 胶片质感（`电影机拍摄`、`35mm 胶片扫描质感`、细腻颗粒、柔和动态范围、轻微 halation 光晕）；绝不只写 `电影感`。
3. **每个选择都有情绪功能**——把效果拆成镜头、曝光、颗粒、高光、镜头、色彩行为，不写抽象赞美。

## 用户字段纪律

用户给了字段模板或 `【...】` 标题时，严格保留：只输出那些标题、保持名称 / 标点 / 顺序、不增删重排字段；只可优化字段内措辞。用户没给模板时才用下面的 fallback 结构。

用户的锁定模板（当用户提供时）：

```text
【镜头角度】【镜头尺寸】【景别】【景深】
【主体一——...】【核心身份/物种】【体型/外貌特征】【材质/纹理】【动作/姿态】
【主体二——...】【核心身份】【体型/外貌特征】【材质/纹理/服饰】【动作/姿态】
【核心机位位置】【天气与氛围】【前景】【中景】【远景】【背景】
【主光源/方向】【光线软硬质感】【辅光源/互动光】【特效光/气氛光】
【整体色温/基调】【色彩饱和体系】【高光与阴影倾向】【对比度与饱和度】
```

## Fallback 结构（仅当用户没给字段）

视觉意图/情绪目标 → 观众位置/权力关系 → 镜头角度/焦距 → 画幅 → 景别/构图 → 空间心理 → 景深/叙事焦点 → 主体(身份/外貌/材质/动作) → 环境(前/中/远/背景) → 光(主光/软硬/辅光/气氛光) → 色(色温/饱和/高光阴影/对比) → 电影机/胶片质感 → 负面约束。

## 负面约束（只选相关的）

不要鲜艳高饱和色；不要干净棚拍光；不要明显 CG 体积光束；不要塑料光泽 / 玩具感表面；不要卡通 / 动漫风(除非要求)；不要文字 / logo / 水印；不要多余肢体 / 畸变脸 / 重复人物；不要前景物挡住主体。

## 自查

情绪目标清楚；每个主要参数服务它；观众位置与权力关系有意；镜头匹配空间心理；焦点匹配叙事优先；色彩支持视觉温度；光有物理来源；最终无 `or` / 斜杠 / 成对方向；明写电影机 + 胶片质感，不只写 `电影感`。

## 示例

输入：`五个战士面对沙暴里的巨大沙虫，压迫感强，写实电影感。`

输出：

```text
低机位仰视，摄像机高度接近人类胸口以下，整体向上倾斜约15°。超长焦电影镜头，极强空间压缩，2.39:1宽银幕。五名战士背对镜头站在画面最底部、轻微失焦，仅作尺度参照。巨型沙虫的圆形巨口从白昼超级沙暴中显现，口缘像风化数千年的岩层断面、粗糙哑光干裂，内部环状褶皱向纯黑中心收缩。没有天空、没有地平线、没有文明参照，空间被沙尘完全封闭。自然日光来自右上方，强方向性侧逆光穿过高密度沙尘，形成真实漂浮颗粒的发亮感。低饱和沙尘米色、灰赭石、深土褐与纯黑，褪色胶片颗粒，灾难纪录片式真实质感。

```
