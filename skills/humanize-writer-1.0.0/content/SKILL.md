## 24种AI写作痕迹清单

### 第一类：过渡词滥用

| # | 痕迹类型 | AI典型特征 | 修复方案 |
|:---:|:---|:---|:---|
| 1 | 因此/所以滥用 | 每句都用"因此"连接 | 删除或替换为：于是、于是乎、接下来、结果 |
| 2 | 然而/但是滥用 | 转折词过度使用 | 适当删减，有些地方不需要转折 |
| 3 | 首先/其次/最后滥用 | 条目必定三段式 | 去掉序号，让句子自然流动 |
| 4 | 总而言之/综上所述 | 结尾必总结 | 删除，让文章自然收尾 |
| 5 | 事实上/实际上 | 强调过于刻意 | 删除或换更自然的说法 |

### 第二类：语气过于确定性

| # | 痕迹类型 | AI典型特征 | 修复方案 |
|:---:|:---|:---|:---|
| 6 | 绝对化表述 | "必须"、"必然"、"一定会" | 改为：通常、往往、一般会 |
| 7 | 过度总结 | "我们应该认识到……" | 删掉评价句，直接陈述事实 |
| 8 | 重复确认 | "值得注意的是……" | 删除，事实自己说话 |
| 9 | 过于笼统 | "各种因素"、"多方面" | 明确指出具体是什么 |
| 10 | 夸大词汇 | "极其"、"非常"、"十分" | 删除或换更克制的词 |

### 第三类：句式结构机械

| # | 痕迹类型 | AI典型特征 | 修复方案 |
|:---:|:---|:---|:---|
| 11 | 排比句过多 | 三句以上结构相同的并列 | 打散句式，长短错落 |
| 12 | 句式单一 | 全篇以"这是因为"开头 | 变换句首词 |
| 13 | 名词化倾向 | "进行实施"、"做出决定" | 改为："实施"、"决定" |
| 14 | 被动语态过多 | "被……"、"被……" | 改回主动语态 |
| 15 | 陈述句堆砌 | 全篇感叹号感叹号 | 适当加入对话/例子/疑问 |

### 第四类：内容空洞泛化

| # | 痕迹类型 | AI典型特征 | 修复方案 |
|:---:|:---|:---|:---|
| 16 | 万能废话句 | "它不仅可以……而且还能……" | 删除或换成具体内容 |
| 17 | 空话套话 | "随着时代的发展" | 直接从具体事实切入 |
| 18 | 重复说同一件事 | 换个说法重复三遍 | 删到只说一遍 |
| 19 | 缺乏具体例子 | 只有观点没有实例 | 补充真实细节或个人经历 |
| 20 | 概念堆砌 | 连续多个专业术语 | 用通俗语言解释一个 |

### 第五类：格式和结构问题

| # | 痕迹类型 | AI典型特征 | 修复方案 |
|:---:|:---|:---|:---|
| 21 | 过度分点 | 每段都是1. 2. 3. | 合并相关内容，减少分点 |
| 22 | 固定开场白 | "让我们一起来看看……" | 删除，直接进正文 |
| 23 | 结尾口号化 | "让我们携手共创……" | 改为具体行动或自然收尾 |
| 24 | 格式化措辞 | "以下是……" | 改为自然导语 |

## 改写技巧速查

### 语气降格表

| AI腔调 | 人类腔调 |
|:---|:---|
| "因此" | "于是"、"结果"、"这导致" |
| "然而" | "但"、"不过"、"只是" |
| "首先" | "一开始""起先" |
| "其次" | "接着"、"随后" |
| "最后" | "到头来"、"最后关头" |
| "总而言之" | （直接删掉） |
| "值得注意的是" | （直接删掉） |
| "我们应该" | "我倾向于"、"一般会" |
| "这表明" | "看起来"、"这说明" |
| "毫无疑问" | "大体上"、"可以说" |
| "必须" | "最好"、"需要" |
| "毫无疑问" | "说白了" |

### 句式变化技巧

```
长短交错：一句长的拆成两句，一句短的可适当合并
句首变化：不要每句都以"这"、"它"开头
主动优先：能用主动语态就不用被动
动词优先：把名词/形容词切换回动词
留白艺术：不要每句话都说满，有些不说完更自然
```

## 特别处理指南

### 场景一：学术/正式文章

```
保留：专业术语、严谨表述
修复：格式化过渡词、空洞套话
原则：去AI味 ≠ 降低专业性
```

### 场景二：自媒体/社交媒体

```
保留：个人风格、有趣表达
修复：过度分点、总结强迫症
原则：越自然越好，接地气
```

### 场景三：商务/职场写作

```
保留：礼貌得体、专业感
修复：绝对化措辞、过度承诺
原则：去除AI腔调，但保持专业
```

### 场景四：创意/故事写作

```
保留：文学性、情感表达
修复：过度解释、作者旁白太多
原则：让读者自己感受，不直接告知
```

## AI检测原理科普（帮助理解）

AI文本容易被检测的原因：

```
1. N-gram 分布异常：AI用词过于"标准"，缺乏真实写作的随机性
2. 困惑度（Perplexity）低：AI文本太"流畅"，真实写作有更多犹豫和跳跃
3. 熵值（Entropy）低：AI不喜欢用罕见词，而人类偶尔会用生僻词
4. 句子结构过于规整：真实写作句子长短差异更大

→ 所以修复核心思路：
增加"不完美"（长短错落、偶尔生僻词）
减少"完美流畅"（过渡词、排比句、绝对化）
```

## 禁止事项

- ❌ 不改变原文的核心信息和意图
- ❌ 不加入原文没有的个人观点
- ❌ 不删除必要的事实和数据
- ❌ 不过度润色导致内容失真
- ❌ 不保证"100%通过AI检测"（无法保证，也不该这样承诺）
