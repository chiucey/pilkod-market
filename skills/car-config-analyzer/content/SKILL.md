# 车型配置分析技能

## 核心工作流程

### 1. 意图识别与信息收集

当用户询问车型配置时，执行以下步骤：

**1.1 识别车型信息**
- 从用户问题中提取车型名称、品牌、年代款
- 常见表述：「小鹏MONA M03怎么样」「比亚迪海豹配置」「某车型值得买吗」

**1.2 搜索最新配置数据**
- 使用 `batch_web_search` 搜索车型最新配置信息
- 关键词格式：「{车型名称} {年份}款 配置参数」
- 备选：「{车型名称} 详细配置表 全系标配」

**1.3 信息提取优先级**
1. 官方配置表/参数配置页面
2. 汽车媒体详细评测
3. 上市新闻稿配置信息

### 2. 配置数据结构化

将收集到的配置信息按以下维度分类整理：

**2.1 基础信息表**
| 维度 | 内容 |
|------|------|
| 车型版本 | 所有在售版本的名称和售价 |
| 车身尺寸 | 长×宽×高、轴距、整备质量 |
| 动力系统 | 电机功率、扭矩、电池容量 |
| 续航里程 | CLTC/NEDC续航、快充时间 |

**2.2 配置对比矩阵**

创建横向对比表，列表示版本，行表示配置项：

```
| 配置项 | Plus版 | Max版 | Ultra SE版 |
|--------|--------|-------|------------|
| 价格 | 11.98万 | 12.98万 | 15.18万 |
| 续航 | 540km | 610km | 610km |
| ... | ... | ... | ... |
```

**2.3 全系标配清单**

提取所有版本均配备的配置，按类别分组：

- **动力系统**：电机、电池、充电等
- **外观配置**：灯光、车窗、轮毂等
- **内饰配置**：座椅、中控、音响等
- **智能配置**：车机系统、辅助驾驶等
- **安全配置**：气囊、刹车、车身稳定等
- **便利配置**：空调、充电接口、无钥匙进入等

### 3. 版本差异化分析

**3.1 识别配置梯度**

分析不同版本间的配置差异，识别配置分层逻辑：

- **入门版**：基础配置，满足基本需求
- **中配版**：舒适配置升级，补齐智能化
- **高配版**：旗舰配置，极致体验

**3.2 差异量化**

对每个版本的增量配置进行量化：

| 版本升级 | 增加配置 | 价格差 | 性价比评估 |
|---------|---------|-------|-----------|
| Plus→Max | 图灵芯片、城市NCA、座椅通风 | +1万 | 智驾刚需必选 |
| Max→Ultra SE | 座椅按摩、20音响、RNC降噪 | +1.2万 | 舒适党首选 |

### 4. 选购建议生成

**4.1 用户画像匹配**

根据不同用户需求提供针对性建议：

| 用户类型 | 需求特征 | 推荐版本 | 推荐理由 |
|---------|---------|---------|---------|
| 性价比用户 | 预算有限、城市通勤 | 入门续航版 | 基础配置齐全，价格最优 |
| 科技用户 | 追求智驾、新鲜体验 | 智驾版 | 城市NOA、车位到车位 |
| 舒适用户 | 注重乘坐体验 | 顶配版 | 按摩座椅、顶级音响 |
| 家庭用户 | 空间实用、安全优先 | 中配版 | 配置均衡、实用性高 |

**4.2 选购建议结构**

生成1000+字的详细选购建议，包含以下模块：

**第一段：市场定位与产品概述**（150字）
- 车型定位、目标人群
- 核心竞争优势
- 价格区间概述

**第二段：版本配置深度解析**（400字）
- 每个版本的配置差异
- 配置背后的价值逻辑
- 各版本适合人群分析

**第三段：竞品对比与选购策略**（200字）
- 与同价位竞品对比
- 选购时机建议
- 权益优惠分析

**第四段：个性化选购推荐**（250字）
- 细分场景推荐（城市通勤/长途出行/家庭用车/年轻潮流）
- 具体配置选择建议
- 选装包评估

### 5. 输出格式规范

**5.1 标题格式**

```
# {品牌}{车型} 配置分析与选购建议
```

**5.2 配置表格式**

使用 Markdown 表格，确保对齐和清晰：

```markdown
| 版本 | 续航(km) | 售价(万元) | 核心亮点 |
|------|---------|-----------|---------|
```

**5.3 差异化表格**

使用对比矩阵展示版本差异：

```markdown
| 配置项 | Plus版 | Max版 | Ultra SE版 |
|--------|:------:|:------:|:---------:|
| 图灵AI芯片 | - | 单颗 | 双颗 |
```

### 6. 质量检查清单

完成输出前检查：

- [ ] 所有版本名称和售价准确无误
- [ ] 全系标配配置完整列出（≥15项）
- [ ] 版本差异化配置清晰对比
- [ ] 选购建议≥1000字
- [ ] 包含限时权益/优惠信息
- [ ] 竞品对比（如有）客观公正

## 注意事项

- **数据时效性**：优先搜索最新上市信息，确保配置数据为最新年份款
- **信息交叉验证**：官方数据与媒体报道交叉核实
- **价格准确性**：售价以官方指导价为准，注明是否为补贴后价格
- **客观中立**：不倾向特定版本，根据用户需求推荐最适合的选择
