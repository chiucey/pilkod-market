# 北京地区组工与支部工作文章撰写技能

本技能以《北京组工通讯》《北京支部生活》《前线》《大学生》为主要参考来源，提供北京地区党建工作专项文体的写作规范。

---

## 一、《北京组工通讯》风格与写法

### 1.1 定位
- **主办**：北京市委组织部
- **读者**：各级组工干部
- **风格**：政策性强、实务指导性强、注重经验总结

### 1.2 常见文章类型
- **经验介绍类**：某单位党建创新做法（结构：背景-做法-成效-启示）
- **调研报告类**：组织工作专题调研（结构：调研背景-基本情况-存在问题-对策建议）
- **领导署名文章**：组织工作重要部署解读
- **动态报道类**：重要会议、活动的纪实性报道

### 1.3 写作规范
- 标题：简明扼要，常用"探索""构建""打造"等动词
- 开头：直接入题，不绕弯子，常用"为深入贯彻落实……"开头
- 主体：经验做法部分要有具体举措，有数据支撑，有典型案例
- 结尾：常用"下一步，将……"引出工作展望
- 字数：经验类 2000-3500字；调研类 3000-5000字

## 二、《北京支部生活》风格与写法

### 2.1 定位
- **主办**：北京市委组织部（面向全市基层党组织和党员）
- **风格**：通俗易懂、贴近基层、注重可读性
- **栏目丰富**：党课参考、经验交流、支部园地、党员心声等

### 2.2 支部建设经验文章写法
**结构模板**：
```
一、基本情况（简要介绍支部概况）
二、主要做法
  （一）抓学习，提升党员政治素养
  （二）抓制度，规范支部组织生活
  （三）抓融合，推动党建业务双提升
三、取得成效（用数据说话）
四、存在不足与下一步打算
```

### 2.3 党员教育类文章
- 善用身边党员故事，以小见大
- 语言生动但不失严肃
- 常用"微党课""主题党日"等具体载体切入
- 注重"学思用贯通、知信行统一"

### 2.4 "三会一课"经验写法
- 突出制度落实的创新性做法
- 体现政治功能和组织力的提升
- 附具体案例和数字成效

## 三、《前线》杂志风格与写法

### 3.1 定位
- **主办**：北京市委宣传部
- **风格**：理论性较强，有思想深度，关注首都发展
- **读者**：机关干部、理论工作者

### 3.2 理论文章特征
- 有明确的理论观点，不是单纯工作汇报
- 论证严密，有学理性
- 善于将中央精神与北京实际结合
- 标题常用判断句或设问句

### 3.3 写法要点
- 开头：提出一个理论问题或现实命题
- 主体：逐层展开，有理论深度，有首都实践支撑
- 结尾：提出思考性、前瞻性观点
- 篇幅：3000-6000字

## 四、《大学生》杂志相关写作

### 4.1 定位
- **主办**：北京市委教育工委
- **读者**：高校师生
- **风格**：青春气息 + 思想性

### 4.2 高校党建工作文章要点
- 突出高校特色（思政课、课程思政、立德树人）
- 关注青年教师和学生党员发展
- 体现首都高校的引领示范作用

## 五、民主生活会 / 组织生活会对照检查材料专项

### 5.1 材料结构（通用模板）
```
一、上年度整改措施落实情况
二、存在的问题
  （一）思想政治方面
  （二）精神状态方面
  （三）工作作风方面
三、原因剖析
  （一）理论学习不够深入
  （二）宗旨意识有所淡化
  （三）党性锻炼不够自觉
四、今后整改措施
  （一）加强理论学习
  （二）强化宗旨意识
  （三）严格自我要求
```

### 5.2 写作要求
- 问题部分：开门见山，不穿靴戴帽，用具体事例说明
- 原因剖析：深挖思想根源，不就事论事
- 整改措施：具体可操作，有时间节点
- 语言：严肃认真，实事求是，不夸大不缩小
- 字数：通常 3000-5000字

## 六、述学述职述廉述法材料专项

### 6.1 述职报告结构
```
一、基本情况
二、主要工作及成效（分条列项，每项工作有做法有成效）
三、存在的不足
四、下一步工作思路
```

### 6.2 写作要点
- 每项工作"做法+成效"配对出现，成效用数据佐证
- 不足部分要实事求是，不回避
- 语言朴实，不唱高调
- 篇幅：通常 2000-3000字

### 6.3 述廉部分要点
- 如实报告个人重大事项
- 落实"一岗双责"情况
- 廉洁自律情况
