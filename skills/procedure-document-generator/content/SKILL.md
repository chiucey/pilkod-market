# 检验检测机构程序文件生成器

## 功能说明

本技能为第三方检验检测机构质量负责人提供符合国家标准的程序文件模板，支持一键生成符合以下法规要求的《标准物质及菌（毒）种管理程序》文件：

### 适用法规标准

- 《检测和校准实验室能力认可准则（CNAS-CL01：2018）》（等同ISO/IEC 17025:2017）
- 《检验检测机构资质认定评审准则（总局令〔2023〕21号）》
- 《放射卫生技术服务机构管理办法（卫监督发〔2012〕25号）》
- 《检验检测机构资质认定生态环境监测机构评审补充要求（国市监检测〔2018〕245号）》
- 《职业卫生技术服务机构管理办法（国家卫生健康委员会令第11号）》

## 适用机构类型

本技能适用于以下类型的检验检测机构：

- 放射卫生技术服务机构
- 职业卫生技术服务机构（工业放射类）
- 环境监测机构（电离辐射类）
- 医疗机构消毒效果监测机构
- 综合类第三方检验检测机构

## 组织架构适配

生成的程序文件适用于以下组织架构的机构：

| 部门 | 说明 |
|------|------|
| 行政部 | 采购执行、供应商管理 |
| 财务部 | 费用审核与支付 |
| 市场部 | 市场拓展 |
| 检验检测部 | 检测执行、样品管理 |
| 评价部 | 技术评价与评估 |
| 质量管理部 | 质量管理、文件控制 |

|------|------|
| 1 | 目的和适用范围 |
| 2 | 引用文件 |

| 9 | 期间核查 |
| 10 | 记录管理 |
| 11 | 附则 |

## 程序文件特点

- **符合标准**：完全符合CNAS-CL01:2018和资质认定评审准则要求
- **内容完整**：涵盖标准物质和标准菌（毒）种两大类管理要求
- **职责清晰**：明确各部门的职责分工
- **记录齐全**：提供完整的记录表格样式（附录A）
- **操作性强**：提供详细的操作流程和检查要求

## 使用方法

### 基础使用

1. 明确机构基本信息（名称、部门架构）
2. 确定业务领域范围
3. 指定程序文件编号和版本号
4. 生成完整的程序文件

### 定制化需求

- 可指定具体的标准物质类型
- 可调整储存条件要求
- 可添加机构特定的表单
- 可修改职责分工

## 质量负责人操作提示

- 确保程序文件与机构质量手册保持一致
- 程序文件需经质量负责人审核批准后发布
- 定期评审程序文件的适用性
- 及时更新以反映法规变化
