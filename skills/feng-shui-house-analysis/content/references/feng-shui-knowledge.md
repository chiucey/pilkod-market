## 二、户型吉凶判断标准

### 吉格户型
1. **方正户型**：最理想的户型，四平八稳，聚气藏风
2. **长方形户型**：东南或南北朝向为佳
3. **正方形户型**：四面均衡，运势平稳
4. **明堂开阔：入门处有适当空间
5. **动线流畅：各区域连接自然

### 凶格户型
1. **刀形房**：前端尖锐，财运受损
2. **锯齿房**：边缘不整，健康不佳
3. **三角形房**：棱角分明，矛盾是非
4. **缺角房**：某方位缺失，影响对应家庭成员
5. **手枪房**：异形突出口，运势外流

## 三、常见煞气与化解

### 3.1 穿堂煞
- **形成**：入户门正对窗户或后门
- **影响**：财来财去，难以聚财
- **化解**：
  - 设置屏风或隔断
  - 放置阔叶植物
  - 悬挂珠帘
  - 门前放置脚垫

### 3.2 门对门煞
- **形成**：相邻房门相对
- **影响**：口舌是非，隐私泄露
- **化解**：
  - 常关门
  - 门上挂珠帘
  - 放置水生植物

### 3.3 横梁压顶
- **形成**：床上或沙发上正上方有横梁
- **影响**：压力感重，头痛失眠
- **化解**：
  - 用吊顶遮盖
  - 挂五帝钱
  - 摆放高大绿植

### 3.4 厨卫对冲
- **形成**：厨房门与卫生间门相对
- **影响**：健康受损，财运破耗
- **化解**：
  - 常关厨卫门
  - 两者之间放绿植
  - 门上挂长明灯

### 3.5 开门见灶
- **形成**：入户门直接看到厨房
- **影响**：钱财外露，家人健康
- **化解**：
  - 设置玄关
  - 摆放屏风
  - 放置阔叶植物

### 3.6 床头靠窗
- **形成**：床头紧邻窗户
- **影响**：睡眠不安，容易疲劳
- **化解**：
  - 床头靠墙
  - 窗户加厚窗帘
  - 床头柜放化解物品

### 3.7 楼梯冲门
- **形成**：楼梯正对入户门
- **影响**：财气外泄，是非不断
- **化解**：
  - 设置屏风
  - 悬挂凸镜
  - 放置屏风绿植

## 四、各功能区域风水

### 4.1 客厅
- **财位**：大门对角线位置，忌空置
- **沙发**：背实面空，忌横梁压顶
- **电视背景墙**：宜有靠山图案

### 4.2 卧室
- **床位**：头顶忌横梁，床头靠墙
- **镜子**：忌对床
- **颜色**：宜柔和，忌大红大紫
- **窗户**：保持空气流通

### 4.3 厨房
- **灶台**：忌正对门或窗户
- **水槽**：与灶台宜分开放置
- **颜色**：宜浅色系，忌纯黑

### 4.4 卫生间
- **位置**：忌正对入户门或厨房
- **光线**：保持明亮干燥
- **通风**：保持空气流通

### 4.5 书房/儿童房
- **文昌位**：东南或正东最佳
- **书桌**：背后有靠，忌对门或窗
- **光线**：柔和自然光
