# 分镜脚本生成器

将叙事文本（故事本、剧本）转换为专业的分镜脚本，包含完整的镜头描述、画面构图、景别、角度、运动、时长、对白和音效信息。

## 核心输出格式

每个分镜包含以下标准化字段：

| 字段 | 说明 | 示例 |
|------|------|------|
| `shot_no` | 镜头编号 | SH001, SH002 |
| `shot_type` | 镜头类型 | 定场/全景/中景/近景/特写/大特写 |
| `camera_angle` | 拍摄角度 | 平视/俯视/仰视/斜角/鸟瞰 |
| `camera_movement` | 镜头运动 | 固定/推/拉/摇/移/跟/升降/手持 |
| `duration` | 预计时长 | 3-5秒, 8-10秒 |
| `visual_description` | 画面描述 | 具体场景、人物动作、环境细节 |
| `dialogue` | 对白/旁白 | 角色台词或叙述 |
| `sound_effect` | 音效/音乐 | 环境音、背景音乐、特效音 |
| `mood` | 氛围基调 | 紧张/温馨/悬疑/欢快/沉重 |

## 输入处理流程

### 1. 文本解析
- 识别场景标记（场景编号、地点、时间）
- 提取角色对话和动作描述
- 识别情绪转折点和节奏变化
- 标记关键视觉元素

### 2. 镜头拆分原则
- **动作连贯性**: 每个镜头聚焦一个动作单元
- **情感峰值**: 情绪高潮点单独成镜
- **视觉对比**: 远-中-近景交替使用
- **节奏控制**: 紧张场景短镜，快节奏；抒情场景长镜，慢节奏
- **视角转换**: 每3-5个镜头变换视角或景别

### 3. 分镜增强
- 添加画面构图建议
- 推荐镜头时长
- 标注转场建议
- 添加视觉参考描述

## 输出模板

```markdown
# 分镜脚本

**项目名称**: [项目名]
**总镜头数**: [数量]
**预计时长**: [总时长]

---

## 场景 [X]: [场景名称]
**地点**: [位置] | **时间**: [时间] | **氛围**: [氛围]

| 镜头 | 类型 | 角度 | 运动 | 时长 | 画面描述 |
|------|------|------|------|------|----------|
| SH001 | [景别] | [角度] | [运动] | [秒] | [描述] |

**对话**: [对白内容]
**音效**: [音效描述]
**备注**: [补充说明]
```

## 示例转换

### 输入（剧本片段）
```
场景3：咖啡馆内 日

林悦走进咖啡馆，环顾四周。她看到窗边的空位，
走过去坐下。服务员走过来递上菜单。

林悦（对服务员）：请给我一杯拿铁。
```

### 输出（分镜脚本）
```
## 场景 3: 咖啡馆

| 镜头 | 类型 | 角度 | 运动 | 时长 | 画面描述 |
|------|------|------|------|------|----------|
| SH301 | 定场 | 平视 | 固定 | 4s | 咖啡馆全景，午后阳光透过窗户洒入 |
| SH302 | 中景 | 平视 | 跟拍 | 5s | 林悦推门进入，走向窗边座位 |
| SH303 | 近景 | 俯视 | 固定 | 3s | 林悦坐下，放下包，望向窗外 |
| SH304 | 中景 | 平视 | 推进 | 4s | 服务员走近，递上菜单 |
| SH305 | 特写 | 平视 | 固定 | 3s | 林悦翻看菜单，微笑回应 |
```

**对话**: 林悦："请给我一杯拿铁。"
**音效**: 咖啡机声、背景爵士乐、门铃声
**氛围**: 温馨、轻松

## 视觉叙事指南

### 景别使用规则
- **定场/全景**: 场景介绍、情绪建立、时间过渡
- **中景**: 对话交流、日常动作、关系展示
- **近景**: 情感表达、关键互动
- **特写**: 情绪高潮、细节强调、象征意义

### 节奏映射
| 叙事节奏 | 镜头时长 | 景别倾向 | 运动频率 |
|----------|----------|----------|----------|
| 紧张/动作 | 2-4秒 | 近景/特写为主 | 高频率 |
| 对话/交流 | 4-8秒 | 中景/近景交替 | 适度 |
| 抒情/思考 | 6-12秒 | 全景/近景 | 低/固定 |
| 过渡/转场 | 3-5秒 | 全景/定场 | 缓慢 |

### 转场建议
- **场景内**: 叠化或硬切
- **时间跳转**: 淡入淡出
- **情绪转折**: 快速剪辑或定格
- **平行叙事**: 交叉剪辑

## 质量检查清单

生成后确认：
- [ ] 每个场景有开场定场镜头
- [ ] 景别有节奏变化，不过于单调
- [ ] 对话场景包含正反打或群像
- [ ] 动作场景有动态镜头运动
- [ ] 情绪节点有适当特写
- [ ] 时长分布符合叙事节奏
- [ ] 音效描述支持画面氛围
