# 高清视频生成器

## 技能概述

本技能使用先进的视频生成模型，通过文字描述、图片或热门社交平台URL快速生成高质量、高清视频内容。用户可以根据不同需求选择合适的视频生成方式。

## 核心能力

### 1. 文本到视频生成
- 接收简短、自然语言描述作为输入
- 生成与之匹配的动态视频内容
- 支持多种视频风格和主题

### 2. 图片到视频生成
- 将静态图片转换为动态视频
- 支持指定运动方向和效果
- 可添加镜头运动和转场效果

### 3. 热门视频素材获取
- 支持抖音视频URL解析
- 支持B站视频URL解析
- 获取高频热门视频素材

### 4. 支持的功能
- 视频分辨率：768P、1080P
- 视频时长：6秒、10秒
- 多种宽高比支持
- 运动效果控制

## 输入源类型

### 类型一：文字描述
通过自然语言描述生成视频场景

**示例**：
```
prompt: "日落时分的海边，浪花轻轻拍打沙滩"
```

### 类型二：图片素材
将图片转换为动态视频

**参数**：
- image_file: 参考图片路径
- prompt: 运动描述（可选）
- reference_type: first_frame（默认）/ subject

**示例**：
```
image_file: "/workspace/imgs/landscape.png"
prompt: "云朵缓缓飘动，光线逐渐变化"
reference_type: "first_frame"
```

### 类型三：社交平台URL
从抖音、B站获取热门视频素材

**支持的URL类型**：
- 抖音：https://www.douyin.com/video/xxx
- B站：https://www.bilibili.com/video/xxx

**注意**：URL获取功能需要有效链接，可能受平台限制

## 技术实现

### 使用的工具

1. **mcp__matrix__gen_videos**
   - 主要视频生成工具
   - 支持文本到视频
   - 支持图片到视频
   - 支持多种分辨率和时长

2. **mcp__matrix__batch_text_to_video**
   - 批量文本到视频生成
   - 一次生成多个视频

3. **mcp__matrix__batch_image_to_video**
   - 批量图片到视频生成
   - 支持参考类型选择

4. **mcp__matrix__social-commerce-scraper**
   - 抖音热门视频抓取
   - B站热门视频抓取
   - 小红书热门内容获取

## 使用方法

### 基础语法

**文本生成视频**：
```
生成视频 [描述内容]
```

**图片生成视频**：
```
将图片转换为视频：[图片路径]
描述运动：[运动描述]
```

**获取热门素材**：
```
获取抖音热门视频
获取B站热门视频
```

### 参数说明

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| prompt | string | 必需 | 视频描述文字 |
| duration | int | 6 | 视频时长（6/10秒） |
| resolution | string | 768P | 分辨率（768P/1080P） |
| image_file | string | 可选 | 参考图片路径 |
| reference_type | string | first_frame | 参考类型 |

## 使用示例

### 示例 1：文字生成风景视频
```
prompt: "日落时分的海边小镇，渔船归港，夕阳余晖"
duration: 6
resolution: 768P
```

### 示例 2：图片生成动态视频
```
image_file: "/workspace/imgs/cat.png"
prompt: "猫咪开始走动，环顾四周"
reference_type: "subject"
duration: 6
resolution: 1080P
```

### 示例 3：批量生成对比视频
```
image_file_list: ["image1.png", "image2.png", "image3.png"]
prompt_list: ["清晨的森林", "午后的花园", "黄昏的海边"]
duration_list: [6, 6, 6]
```

### 示例 4：获取热门素材
```
平台：抖音
类型：热门带货视频
数量：10
```

## 输出格式

- 默认输出为 MP4 格式
- 视频保存在 workspace 目录
- 返回视频的完整路径供下载和使用

## 最佳实践

### 1. 文字描述优化
- 具体明确的动作描述
- 包含环境氛围和光线
- 使用稳定的镜头语言

**推荐**：
```
一只橘猫在阳光下慵懒地伸展身体，周围飘落着樱花花瓣
```

**避免**：
```
一只猫在动
```

### 2. 图片质量要求
- 使用高清无水印图片
- 避免过度压缩的图片
- 主体清晰、背景简洁

### 3. 运动效果控制
- 选择 first_frame：保持原图主体
- 选择 subject：主体作为主角移动

## 技术规格

| 规格 | 支持范围 |
|------|----------|
| 视频时长 | 6秒 / 10秒 |
| 分辨率 | 768P / 1080P |
| 输出格式 | MP4 |
| 并发生成 | 最多5个/次 |
| 支持平台 | 抖音、B站、小红书 |

## 限制说明

- 单次生成最多5个视频
- 1080P + 10秒组合会降级为768P
- URL解析受平台接口限制
- 某些敏感内容会被过滤

## 错误处理

常见错误及解决方案：

| 错误类型 | 可能原因 | 解决方案 |
|----------|----------|----------|
| 生成失败 | 描述过于抽象 | 简化描述，增加具体细节 |
| 图片解析失败 | 图片格式不支持 | 转换为PNG/JPG格式 |
| URL解析失败 | 链接无效或已失效 | 更换新的视频链接 |
| 分辨率不支持 | 超高分辨率请求 | 降低分辨率要求 |
