## 1. 三大内容主线详解

### 1.1 情绪爆款类（30%）

#### 核心定位
引发强情绪共鸣、促进传播扩散，适合宠物离世、生病、陪伴回忆等情感强烈的场景。

#### 内容公式
```
爆款公式：不会说话的它 + 用一生陪你 + 某一天突然明白
```

#### 标杆内容方向

| 方向 | 关键词 | 情感触发点 |
|------|--------|------------|
| 宠物临终前的故事 | 最后时刻、告别、陪伴 | 生死感悟、珍惜当下 |
| 主人最后一次抱它 | 拥抱、离别、不舍 | 情感宣泄、深度共鸣 |
| 它每天都在等你回家 | 等待、忠诚、陪伴 | 感动、日常共鸣 |
| 养宠物后才懂的道理 | 成长、领悟、责任 | 反思、代入感 |

#### 时长配比建议
- 30秒版：聚焦1个核心瞬间，情感爆发点单一
- 40秒版：增加回忆铺垫，情感层次更丰富
- 45秒版：完整叙事弧线，起承转合俱全

#### 情绪爆款内容 Checklist
- [ ] 开头3秒抓住注意力（有画面冲击力或悬念）
- [ ] 中段有明确的情感线索
- [ ] 结尾有情感升华或金句
- [ ] 背景音乐与情感节奏匹配
- [ ] 字幕设计强化情绪（关键文案放大）

---

### 1.2 案例展示类（20%）

#### 核心定位
建立信任、促进转化，通过真实案例展示专业能力和服务价值。

#### 内容公式
```
展示公式：真实故事 + 专业制作 + 情感价值
```

#### 转化设计要点

| 环节 | 设计要点 | 目的 |
|------|----------|------|
| 评论区 | 引导私信咨询 | 获取潜在客户 |
| 主页 | 链接小红书店铺 | 直接转化 |
| 内容 | 软性植入服务介绍 | 建立认知 |

#### 案例展示内容 Checklist
- [ ] 有真实的客户故事（宠物名字、品种、背景）
- [ ] 展示成品精华片段（视觉质量高）
- [ ] 有客户反馈/评价（增强可信度）
- [ ] 服务流程/亮点清晰展示
- [ ] 结尾有明确的行动引导

---

### 1.3 轻知识类（50%）

#### 核心定位
稳定更新频率、积累粉丝、测试爆款，门槛低、受众广。

#### 内容公式
```
知识公式：实用价值 + 情感关联 + 轻松表达
```

#### 核心内容类型

| 类型 | 内容方向 | 更新频率建议 |
|------|----------|--------------|
| 拍摄技巧 | 宠物摄影技巧、手机拍摄教程 | 高频 |
| 宠物护理 | 健康知识、日常护理、疾病预防 | 中频 |
| 温暖瞬间 | 日常治愈内容、主人与宠物互动 | 高频 |
| 养宠知识 | 新手指南、品种科普、行为解读 | 中频 |

#### 轻知识内容 Checklist
- [ ] 开头有痛点或共鸣点（用户能代入）
- [ ] 知识内容实用、可操作
- [ ] 有具体的技巧/方法/步骤
- [ ] 情感升华结尾（不是纯干货，有温度）
- [ ] 更新频率稳定（建议每周4-5条）

## 2. Seedance 2.0 Prompt模板

### 2.1 Prompt七维度规范

每个视频片段的Prompt必须完整包含以下7个维度：

| 维度 | 说明 | 示例 |
|------|------|------|
| 画面风格 | 视觉调性、色彩基调、构图风格 | 暖色调、胶片质感、柔和光线 |
| 主体动作 | 宠物/人物的主要动作、表情、状态 | 金毛犬在草地上奔跑、回头看主人 |
| 情绪氛围 | 画面传达的情感、氛围 | 快乐、自由、青春活力 |
| 对白/旁白 | 人物对话或叙述性旁白内容 | 旁白："那时候它每天都这样跑" |
| 镜头运动 | 运镜方式、景别变化、角度 | 横移跟随拍摄，中景到近景 |
| 音效设计 | 环境音、BGM风格、音效 | 轻快钢琴BGM，自然风声 |
| 特效设计 | 视觉特效、转场、后期调色 | 轻微胶片颗粒感，暖色色调 |

## 4. 常见问题与解决方案

### Q1: 如何处理宠物不配合拍摄的情况？
**方案**：
- 使用零食引导注意力
- 从远处拍摄减少干扰
- 利用宠物自然行为（打哈欠、伸懒腰）抓拍
- 分段拍摄，后期剪辑整合

### Q2: 如何在没有真实素材时创作内容？
**方案**：
- 使用AI生成宠物形象（参考品种特征）
- 构建虚拟但符合现实的场景
- 侧重旁白和情绪表达，弱化具体画面
- 注明"创意示意"避免误导

### Q3: 如何平衡情感深度和平台传播性？
**方案**：
- 开头强冲击（视觉或情感）
- 中段保持节奏，避免拖沓
- 结尾留悬念或引导互动
- 适配不同平台时长要求

### Q4: 如何让AI生成更符合预期的视频？
**方案**：
- Prompt详细描述主体特征（品种、颜色、大小）
- 指定光线方向和质量（上午阳光、傍晚暖光）
- 明确情绪氛围词汇
- 提供参考画面描述（"类似XX风格"）
- 标注镜头运动和景别

### Q5: 30秒/40秒/45秒版本如何选择？
**方案**：
| 时长 | 适用场景 | 内容特点 |
|------|----------|----------|
| 30秒 | 情绪爆款、快速传播 | 单点突破，情感聚焦 |
| 40秒 | 轻知识、技巧分享 | 有空间展开讲解 |
| 45秒 | 完整故事、深度叙事 | 叙事弧线完整 |

### Q6: B站是否需要运营？
**建议**：根据项目报告，B站目前暂未列入优先运营平台。但从长远看：
- B站用户年龄偏年轻，对宠物内容接受度高
- B站适合深度内容（1-3分钟），可作为案例深度展示渠道
- 如果内容产能充足，可考虑将45秒/完整版内容分发B站（横屏16:9适配）

**建议策略**：
- 当前阶段：暂不单独运营B站
