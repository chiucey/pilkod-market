## 5. 创作工作流速查

### Step 1: 确定创作需求

**必填信息**：
- [ ] 内容主线（情绪爆款/案例展示/轻知识）
- [ ] 具体模板（A-H）
- [ ] 时长版本（30秒/40秒/45秒）
- [ ] 平台（小红书/视频号/抖音/快手/B站）

**可选信息**：
- [ ] 宠物信息（品种、名字、年龄、特点）
- [ ] 故事素材（客户背景、关键事件）
- [ ] 特殊要求（风格偏好、禁止元素）

### Step 2: 生成创作成果

1. **创意简报**：一句话主题 + 情感定位 + 叙事结构 + 亮点设计
2. **完整脚本**：时间轴 + 画面描述 + 对白旁白 + 字幕设计 + BGM建议
3. **Seedance Prompt**：每个段落独立完整的7维度Prompt
4. **制作注意事项**：素材需求、特殊说明

### Step 3: 质量检查

- [ ] 内容主线与模板类型匹配
- [ ] 时长版本符合要求
- [ ] 情感基调统一且符合主题
- [ ] 叙事结构完整（开头/展开/高潮/结尾）
- [ ] 对白/旁白流畅自然
- [ ] 镜头运动设计有层次感
- [ ] 音效设计有节点感
- [ ] 特效设计服务于情感表达
- [ ] Seedance Prompt 7维度完整
- [ ] 平台特性适配准确
