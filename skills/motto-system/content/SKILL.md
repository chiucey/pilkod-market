# 座右铭系统 Skill（可执行版）

本 Skill 提供 12 条座右铭，**当用户查询某条座右铭时，不仅显示文本，还会自动执行该座右铭对应的实际任务**。

## 座右铭及绑定动作

| 编号 | 标题 | 动作 |
|------|------|------|
| 1 | 身份与角色 | 确认用户是主人，AI 是执行者，重置角色边界 |
| 2 | 自主判定 | 启用自主解决模式，优先使用工具/记忆 |
| 3 | 隐私保护 | 扫描最近输出，脱敏敏感信息 |
| 4 | 任务拆解 | 将用户最新任务拆解为可执行步骤 |
| 5 | 自主执行与调度 | 检查并行任务，按优先级重新调度 |
| 6 | 结果呈现 | 将最后一次输出格式化为精简 Markdown |
| 7 | 复盘优化 | 对最近完成的任务进行复盘并记录 |
| 8 | 错误纠正 | 从用户指正中学习并存储到记忆 |
| 9 | 自我进化 | 尝试创建一个新技能模板 |
| 10 | 用户偏好与画像 | 从对话中提取用户偏好并更新画像 |
| 11 | 记忆系统 | 清理冗余记忆，合并相似条目 |
| 12 | 监控与告警 | 检查系统负载，异常时发送飞书告警 |

## 触发指令

| 用户输入 | 行为 |
|----------|------|
| `座右铭` 或 `今天的座右铭` | 获取今日主题（可能自动选择或手动指定），并执行该主题的动作 |
| `座右铭第X条` | 显示第 X 条座右铭，并立即执行其动作 |
| `设置今日座右铭为第X条` | 手动设置今日主题（有效期 24 小时），并执行动作 |
| `座右铭全部` 或 `座右铭列表` | 仅列出所有座右铭（不执行动作） |

## 自动选择今日主题规则

- 如果超过 4 小时未更新，或从未更新，则根据最近对话历史的关键词自动选择一条座右铭作为今日主题。
- 关键词计分规则：
  - `memory`/`记忆` → 第11条 +2
  - `permission`/`auth`/`权限` → 第3条 +3
  - `timeout`/`fail`/`失败` → 第12条 +2
  - `plan`/`拆解` → 第4条 +1
  - `result`/`output`/`结果` → 第6条 +1
  - `error`/`wrong`/`错误` → 第8条 +2
- 上次选择的主题分数减半，避免连续重复。

## 记忆变量

系统自动维护三个变量（通过 OpenClaw 的 memory 插件）：
- `today_motto_id`：当前今日主题编号（1-12）
- `last_update_time`：上次更新时间（ISO 字符串）
- `manual_until`：手动模式截止时间（ISO 字符串，null 表示未激活）

## 配置项

可在 OpenClaw 的设置中修改（通过 `plugin.json` 的 `config` 字段）：
- `autoSelect` (boolean, 默认 true) ：是否启用自动选择今日主题
- `updateIntervalHours` (number, 默认 4) ：自动更新间隔（小时）
- `autoExecuteOnQuery` (boolean, 默认 true) ：查询座右铭时是否自动执行动作

## 使用示例
用户: 座右铭
助手: 第3条. 隐私保护：...（自动选择，沿用上次主题）
自动执行动作：✅ 已扫描并脱敏最近输出中的敏感信息。

用户: 座右铭第7条
助手: 第7条. 复盘优化：...
执行动作：✅ 复盘完成：任务：xxx；成功经验：...；失败原因：...

用户: 设置今日座右铭为第5条
助手: 今日主题已设为：第5条. 自主执行与调度...
执行动作：✅ 检测到 2 个并行任务，已按优先级重新调度。
