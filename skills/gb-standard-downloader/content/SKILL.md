# 标准文件下载器

自动下载中国各类标准PDF全文文档的技能。

## 支持的标准类型

### 国家标准（GB系列）
- **GB**：强制性国家标准
- **GB/T**：推荐性国家标准
- **GB/Z**：国家标准指导性技术文件

### 行业标准
- QB（轻工）、JB（机械）、HG（化工）
- FZ（纺织）、YS（有色金属）、NY（农业）
- 以及其他行业标准

### 企业标准
- 以Q/开头的企业标准

## 工作流程

### 第一步：识别标准信息

用户提供标准号或关键词：
- 标准号示例：`GB 5009.3`、`GB/T 19238-2010`
- 行业标准：`QB/T 1803`、`JB/T 12345`
- 关键词示例：`食品中水分的测定`

### 第二步：搜索标准

访问以下数据源：
1. 国家标准全文公开系统 (openstd.gov.cn)
2. 中国标准服务网 (cssn.net.cn)
3. 工标网 (csres.com)
4. 全国标准信息公共服务平台 (samr.gov.cn)

### 第三步：处理验证码

部分平台下载需要验证码，可选方案：
- **超级鹰**：付费验证码服务
- **ddddocr**：免费中文OCR工具
- **OCR.space**：免费在线OCR API

### 第四步：获取PDF

- 直接下载公开的PDF
- 处理验证码后下载
- 提供在线阅读地址
- 说明购买途径

## 数据源说明

| 平台 | 网址 | 说明 |
