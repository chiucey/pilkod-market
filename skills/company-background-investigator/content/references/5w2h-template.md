# 5W2H分析框架详解

## 各维度深度分析要点

### What（定性分析）

**核心问题**：这家公司是做什么的？

**分析维度**：
```
1. 主营产品/服务
   - 核心产品线
   - 产品差异化特征
   - 定价策略

2. 行业归属
   - 国民经济行业分类
   - 细分赛道定位
   - 行业生命周期阶段

3. 商业模式
   - 收入来源结构
   - 价值创造方式
   - 盈利模式

4. 目标市场
   - B端/C端/G端
   - 客户画像
   - 市场覆盖
```

### Who（人物分析）

**核心问题**：谁在运营这家公司？

**分析维度**：
```
1. 法人代表
   - 身份背景
   - 任职资格
   - 关联企业

2. 股东结构
   - 控股股东
   - 股权比例
   - 实际控制人

3. 高管团队
   - 核心管理层
   - 专业背景
   - 稳定性

4. 关联企业
   - 母公司/子公司
   - 兄弟公司
   - 投资关系
```

### When（时间分析）

**核心问题**：这家公司的发展历程？

**分析维度**：
```
1. 成立时间
   - 工商注册日期
   - 经营期限
   - 存续状态

2. 重要时间节点
   - 融资/上市
   - 重大战略调整
   - 资质获取

3. 资质有效期
   - 许可证期限
   - 认证有效周期
   - 年报披露周期

4. 发展趋势
   - 人员规模变化
   - 业务扩张轨迹
```

### Where（地理分析）

**核心问题**：这家公司在哪里运营？

**分析维度**：
```
1. 注册地址
   - 工商注册地
   - 园区/楼宇

2. 实际经营地
   - 总部位置
   - 分支机构
   - 办公环境

3. 业务覆盖
   - 区域分布
   - 重点市场
   - 物流网络

4. 地理战略
   - 选址逻辑
   - 区位优势
```

### Why（战略分析）

**核心问题**：为什么这家公司存在并发展？

**分析维度**：
```
1. 使命愿景
   - 企业定位
   - 发展目标
   - 价值主张

2. 竞争优势
   - 核心壁垒
   - 差异化能力
   - 资源禀赋

3. 行业地位
   - 市场份额
   - 竞争排名
   - 品牌影响力

4. 潜在风险
   - 行业风险
   - 经营风险
   - 合规风险
```

### How（运营分析）

**核心问题**：这家公司如何运作？

**分析维度**：
```
1. 商业模式
   - 价值链位置
   - 运营流程
   - 关键环节

2. 获客渠道
   - 营销策略
   - 渠道网络
   - 客户来源

3. 合作伙伴
   - 供应商关系
   - 渠道伙伴
   - 生态布局

4. 核心能力
   - 技术能力
   - 运营能力
   - 组织能力
```

### How Much（量化分析）

**核心问题**：这家公司的规模如何？

**分析维度**：
```
1. 资本实力
   - 注册资本
   - 实缴资本
   - 融资历史

2. 人员规模
   - 参保人数
   - 团队结构
   - 人才密度

3. 经营规模
   - 营收规模
   - 利润水平
   - 增长率

4. 资质等级
   - 资质类型
   - 认证级别
   - 荣誉资质
```
