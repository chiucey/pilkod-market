## 信息推导逻辑

### 从公司名称推导
```
公司名称结构 = [区域]+[字号]+[行业]+[组织形式]
例：深圳市腾讯计算机系统有限公司
- 区域：深圳市
- 字号：腾讯
- 行业：计算机系统
- 形式：有限公司
```

### 从域名推导
```
域名格式 = [品牌名].[后缀]
常见后缀对应：
- .com/.cn: 商业公司
- .org: 非营利组织
- .edu: 教育机构
- .gov: 政府机构
```

### 从邮箱域名推导
```
邮箱格式 = [用户名]@[域名]
域名部分 = 企业官网域名
常见企业邮箱后缀：
- @163.com / @qq.com: 个人/小微企业
- @企业域名.com: 有自建邮箱的企业
```

## 交叉验证矩阵

| 信息类型 | 验证项 | 辅助验证源 |
|---------|-------|-----------|
| 公司名称 | 是否真实注册 | 工商数据 |
| 法人代表 | 任职资格 | 失信名单 |
| 注册地址 | 实际经营地 | 地图+电话 |
| 注册资本 | 实缴情况 | 年报数据 |
| 经营范围 | 实际业务 | 产品/新闻 |
| 联系方式 | 有效性 | 直接联系 |

## 风险信号清单

### 高风险指标
- [ ] 被列入经营异常名录
- [ ] 严重违法失信名单
- [ ] 正在进行清算
- [ ] 行政处罚记录
- [ ] 法律诉讼集中

### 中风险指标
- [ ] 频繁变更工商信息
- [ ] 注册资本异常
- [ ] 地址无法核验
- [ ] 联系方式失效

### 低风险指标
- [ ] 成立时间较短
- [ ] 信息公开度低
- [ ] 舆情信息有限
