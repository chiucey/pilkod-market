# 背景调查技能 (Company Background Investigator)

## 核心能力

将任意零散的客户信息碎片，通过系统性搜索和交叉验证，还原完整的商业画像，并以5W2H框架结构化输出。

## 输入处理

### 信息提取
接收用户提供的任意信息，提取以下实体：
- **公司名称**（全称/简称）
- **联系方式**（电话、邮箱、地址）
- **网络痕迹**（网址、社交媒体、ICP备案）
- **其他线索**（法人、高管、关联公司）

### 信息分组策略
```
优先级1：公司名称 → 核心锚点
优先级2：网址/邮箱 → 数字身份
优先级3：电话号码 → 直接联系
优先级4：地址信息 → 地理定位
```

## 5W2H调查框架

### What（是什么）
- 公司主营业务/产品
- 行业分类（国民经济行业分类）
- 商业模式（ToB/ToC/ToG）
- 主要客户群体

### Who（是谁）
- 法人代表/实际控制人
- 核心高管团队
- 股权结构（穿透分析）
- 关联公司/集团成员

### When（何时）
- 成立时间/经营期限
- 注册资本实缴情况
- 重要里程碑时间线
- 资质许可有效期

### Where（何地）
- 注册地址
- 实际经营地址
- 分支机构分布
- 业务覆盖区域

### Why（为何）
- 企业愿景/使命
- 竞争优势/差异化
- 行业地位分析
- 潜在风险信号

### How（如何）
- 商业模式实现路径
- 营销渠道策略
- 合作伙伴网络
- 技术/运营能力

### How Much（多少）
- 注册资本/实缴资本
- 参保人数（人员规模）
- 年报营收估算
- 资质等级/认证范围

## 调查执行流程

### 步骤1：信息解析与补全
```
1. 解析用户输入，识别实体类型
2. 利用已知信息推导未知信息
3. 构建初步查询策略
```

### 步骤2：多源信息获取
并行执行以下搜索：

| 信息类型 | 数据来源 |
|---------|---------|
| 工商信息 | 企业信用信息公示系统 |
| 联系方式 | 官网、黄页、地图数据 |
| 经营状态 | 新闻、年报、招聘数据 |
| 舆情分析 | 新闻媒体、社交媒体 |
| 资质认证 | 官方许可数据库 |
| 关联关系 | 股权穿透、任职穿透 |

### 步骤3：交叉验证
- 三重验证原则：同一信息需3个独立来源确认
- 时间线一致性检查
- 逻辑矛盾识别与标记

### 步骤4：框架填充与报告生成
按5W2H七维度组织信息，未确认项标注"待核实"

## 输出格式

### 报告结构
```markdown
# [公司名称] 背景调查报告

## 执行摘要
- 调查时间
- 信息完整度评分
- 关键发现

## 5W2H分析
### What - 企业定性
### Who - 关键人物
### When - 时间线
### Where - 地理分布
### Why - 战略分析
### How - 运营模式
### How Much - 规模量化

## 风险提示
## 信息来源清单
```

### 可信度标注
- ✅ 已验证（多重来源确认）
- ⚠️ 待核实（单一来源）
- ❓ 存疑（信息矛盾）

## 调查原则

1. **最小信息启动**：仅凭一个碎片即可启动调查
2. **信息自我补全**：从已知推导未知
3. **来源透明可查**：所有信息标注来源
4. **不确定性表达**：不臆测，明确标注置信度
5. **合规边界**：仅使用公开可获取信息

## 触发条件

当用户提供以下任意信息时触发：
- 公司名称（含疑似名称）
- 电话号码
- 电子邮箱
- 网站URL
- 办公地址
- 法人/高管姓名
- 营业执照编号
- 任何其他商业实体标识
