# A股每日复盘与次日交易计划

## 核心定位

**本skill的核心价值**：通过每日复盘诊断交易问题，结合大盘和板块情绪，为次日交易计划提供决策依据。

## 两大核心模块

```
skill输出
├── 模块A：每日复盘诊断
│   ├── 当日市场情绪分析
│   ├── 持仓个股分析
│   ├── 仓位合理性评估
│   └── 买卖对错归因
│
└── 模块B：次日交易计划（最重要输出）
    ├── 大盘预判与仓位决策
    ├── 重点关注板块
    ├── 潜在机会标的
    ├── 操作节奏与应对预案
    └── 风险提示
```

## 模块A：每日复盘诊断

### A1. 市场情绪分析

获取当日数据：

```
- 涨跌停统计（过滤ST股）
- 涨跌幅分布（各区间家数）
- 指数涨跌（上证、深证、创业板、科创板）
- 成交量与成交额
- 涨跌家数比（上涨/下跌/平盘）
```

情绪判定标准：

| 情绪等级 | 特征表现 | 涨停家数 | 操作建议 |
|---------|---------|---------|---------|
| 极度亢奋 | 龙头大面积加速、指数放量大涨 | ≥100家 | 谨慎追高，控制仓位 |
| 情绪高涨 | 板块涨停潮、赚钱效应明显 | 60-100家 | 可适当参与，优选龙头 |
| 情绪平稳 | 涨跌互现、结构性机会 | 40-60家 | 控制仓位，精选个股 |
| 情绪谨慎 | 热点散乱、轮动快 | 20-40家 | 轻仓试错，不追高 |
| 情绪低迷 | 跌停增多、亏钱效应扩散 | 10-20家 | 极低仓位或空仓 |
| 情绪恐慌 | 恐慌性杀跌、市场普跌 | <10家 | 空仓休息 |

### A2. 仓位合理性评估

**核心评估维度：**

```
仓位评估checklist
├── 买入时大盘状态
│   ├─ 指数位置（高位/中位/低位）
│   ├─ 趋势方向（上升/震荡/下降）
│   └─ 成交量（放量/缩量）
│
├── 买入时板块情绪
│   ├─ 板块所处阶段（启动/高潮/退潮）
│   ├─ 资金流向（净流入/净流出）
│   └─ 板块联动性（共振/背离）
│
├── 仓位与情绪匹配度
│   ├─ 大盘下跌时个股仓位是否过高？
│   ├─ 板块退潮时是否重仓持有？
│   └─ 情绪高点时仓位是否过于激进？
│
└── 持仓应对是否得当
    ├─ 大盘出现风险信号时是否减仓？
    ├─ 板块退潮时是否果断止损？
    └─ 个股独立逻辑是否足以穿越板块？
```

### A3. 买卖对错归因分析

**买点分类：**

```
买点类型评估
├── 突破型买点（最优）
│   ├─ 特征：放量突破关键位置
│   ├─ 质量：★★★★★
│   └─ 要求：必须配合大盘共振
│
├── 回踩确认型买点（良好）
│   ├─ 特征：回调至支撑位企稳
│   ├─ 质量：★★★★☆
│   └─ 要求：支撑位必须有效
│
├── 消息催化型买点（一般）
│   ├─ 特征：突发消息刺激
│   ├─ 质量：★★★☆☆
│   └─ 要求：消息级别和资金认可度
│
├── 跟风型买点（较差）
│   ├─ 特征：看到别人涨了才买
│   ├─ 质量：★★☆☆☆
│   └─ 风险：容易买在日内高点
│
└─ 盲目型买点（最差）
    ├─ 特征：无明确理由
    ├─ 质量：★☆☆☆☆
    └─ 问题：情绪化交易
```

**卖点分类：**

```
卖点类型评估
├── 主动止盈（优秀）
│   ├─ 信号：到达目标价/板块高潮
│   ├─ 时机：卖在日内高点区域
│   └─ 质量：★★★★★
│
├── 被动止盈（良好）
│   ├─ 信号：分时背离/冲高回落
│   ├─ 时机：次高点附近
│   └─ 质量：★★★★☆
│
├── 被动止损（及格）
│   ├─ 信号：跌破止损位
│   ├─ 时机：及时执行
│   └─ 质量：★★★☆☆
│
├── 情绪化止损（不及格）
│   ├─ 信号：恐慌卖出
│   ├─ 问题：卖在低位
│   └─ 质量：★★☆☆☆
│
└─ 犹豫不决（最差）
    ├─ 信号：不止损，死扛
    ├─ 问题：亏损扩大
    └─ 质量：★☆☆☆☆
```

**亏损归因分类：**

```
亏损归因框架
├── 系统性亏损（可接受）
│   ├─ 定义：正常波动范围内亏损
│   └─ 处理：接受并记录
│
├── 执行性亏损（需改进）
│   ├─ 原因：未遵守止损纪律
│   ├─ 原因：未执行计划
│   └─ 原因：犹豫导致亏损扩大
│
├── 判断性亏损（需提升）
│   ├─ 原因：选股错误
│   ├─ 原因：买点时机错误
│   ├─ 原因：大盘板块判断失误
│   └─ 原因：对情绪周期把握不准
│
└─ 纪律性亏损（必须杜绝）
    ├─ 原因：追高买入
    ├─ 原因：重仓单一票
    ├─ 原因：情绪化交易
    └─ 原因：无计划交易
```

### B2. 仓位决策

**仓位决策规则：**

```
仓位决策矩阵

                    大盘上升    大盘震荡    大盘下降
板块上升            50-70%     40-50%     20-30%
板块震荡            40-50%     30-40%     10-20%
板块下降            20-30%     10-20%      0-10%
```

**仓位决策要点：**

```
仓位决策checklist
├── 情绪高涨时仓位上限
│   └─ 单只个股仓位不超过20%
│
├── 情绪低迷时仓位下限
│   └─ 总仓位不超过30%
│
├── 大盘风险信号触发条件
│   ├─ 跌破10日均线 → 减仓至50%
│   ├─ 跌破20日均线 → 减仓至30%
│   └─ 放量破位 → 减仓至10%或空仓
│
└─ 板块退潮信号识别
    ├─ 龙头股炸板 → 减仓同类个股
    ├─ 主力资金净流出 → 控制仓位
    └─ 板块内部分化 → 汰弱留强
```

## 注意事项

1. **仓位优先原则**：大盘下跌时，任何个股都要控制仓位
2. **止损纪律**：亏损达到预设止损位必须执行，不幻想
3. **情绪跟随**：不做与市场情绪对抗的操作
4. **计划执行**：交易计划一旦制定，必须严格执行
