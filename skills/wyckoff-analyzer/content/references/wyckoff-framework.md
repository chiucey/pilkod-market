# 维克夫（Wyckoff）量价分析框架

> 基于 Richard Wyckoff 经典理论，1990年代至今跨越美股、A股验证
> 核心："供求关系主导价格，人性情绪驱动交易"

---

## 三大核心法则

### 1. 供求法则（股价涨跌唯一本质）
- 买盘（需求）＞卖盘（供应）→ 股价必涨
- 卖盘＞买盘 → 股价必跌
- 主力拉升核心：提前吃光市场所有抛压（散户手里无筹码可卖），少量买盘推高股价
- 主力出货核心：制造买盘（让散户疯狂接盘），大量卖盘也不让股价暴跌
- A股实操：只看"放量上涨时抛压是否减少"（缩量新高是强信号）

### 2. 因果法则（暴涨必有因，暴跌必有根）
- 拉升的"因"= 底部长期吸筹，吸筹越久，拉升空间越大
- 无吸筹的突然暴涨（突发利好一字板）= 假突破，主力无筹码支撑，必然回落
- A股实操：重点关注"下跌后横盘震荡3个月以上"的标的

### 3. 努力与结果法则（量价匹配才是真趋势）
- 成交量 = 主力的"努力"，价格变动 = 努力的"结果"
- 背离 = 主力暗中做反向操作

**核心背离信号（A股最实用）：**
- 放量上涨，但股价涨不动（长上影、十字星）→ 主力假装拉升，暗中派发
- 缩量下跌，但股价快速大跌 → 主力刻意砸盘，暗中吸筹
- 放量下跌，股价却不创新低 → 买盘承接力强，主力砸盘失败，大概率反转

## 主力操盘四阶段

### 阶段1：吸筹（Accumulation）— "忍"，切勿抄底

**市场背景：** 股价经历大幅下跌，散户被套严重，市场情绪绝望

**主力行为：**
- 悄悄进场，小单分批买入，股价维持低位横盘
- 刻意震仓，制造"还要跌"假象，骗取带血筹码
- 压制股价在固定区间，不让涨（防散户抢筹）也不让跌太多（防其他机构捡漏）

**量价特征：**
- 成交量缩量震荡，整体量能低迷
- 价格波动幅度小，K线小阴小阳
- 偶尔大阴线（震仓），但快速收回

**散户正确操作：** 只观察，不抄底，不补仓

---

### 阶段2：拉升（Markup）— "跟"，最佳进场点

**启动前提：** 主力吸筹完毕，市场抛压基本耗尽

**主力行为：**
- 突破试盘：用少量资金突破横盘压力位，观察是否有散户抛盘
- 温和抬价：成交量温和放大，不爆巨量，股价沿5/10日均线向上
- 洗盘整理：拉升一段后小幅回调（5%-10%），洗掉跟风散户

**量价特征：**
- 股价突破长期横盘区间，收盘价站稳
- 成交量逐步放大，量价同步上涨
- 回调时缩量，无明显抛压

**散户正确操作：** 突破压力位时果断进场（右侧交易）

---

### 阶段3：派发（Distribution）— "逃"，最危险阶段

**市场背景：** 股价大幅上涨（通常50%以上），利好满天飞，散户贪婪进场

**主力行为：**
- 高位震荡，小单分批派发，把筹码转移给散户
- 制造假突破，拉升创小幅新高，在新高位置大量出货
- 高位成交量持续放大，但股价不再创新高

**量价特征：**
- 成交量巨量但股价滞涨（长上影、十字星、阴包阳）
- 股价在高位宽幅震荡，上下影线多
- 假突破新高，但次日快速回落，放量大阴线

**散户正确操作：** 果断卖出，不贪心，不侥幸

---

### 阶段4：回落（Markdown）— "空"，切勿抄底

**主力行为：** 完全离场，不再干预股价，让股价自由落体

**量价特征：**
- 成交量从巨量逐步缩量
- 下跌初期放量（散户恐慌割肉），后期缩量阴跌
- 股价沿5/10日均线向下，反弹时成交量小，涨不动
- 不断创出新低，无明显支撑位

**散户正确操作：** 空仓观望，不抄底，不补仓

## 两大实操工具

### 工具1：竹线图+量价行为分析

3个核心分析点：
1. **收盘价位置**：收盘价在K线上方 = 多头强势；下方 = 空头强势；中间 = 多空平衡
2. **波动幅度+成交量**：量大波动幅度小 = 多空僵持（主力暗中操作）；量大波动幅度大 = 一方完胜
3. **跟随确认**：单根K线不作数，必须等次日K线确认

### 工具2：点数图（Point and Figure）

**绘制逻辑：**
- 设定格值（如1元/格）：涨1元画红叉，跌1元画绿圈
- 小幅波动（<1格）不画点，只记录有效变动
- 横盘区间 = 吸筹/派发区间，震荡的格数就是"因"

**核心用法（A股最实用）：**
- **计算拉升目标位：** 吸筹区间格数 = 拉升涨幅格数
  - 例：吸筹区间5格（5-10元，每格1元）→ 拉升目标位 = 10+5 = 15元
- **计算下跌目标位：** 派发区间格数 = 下跌跌幅格数
- **判断趋势：** 连续红叉 = 上升趋势；连续绿圈 = 下跌趋势

## 三条交易铁律

### 铁律1：拒绝预测，只做右侧交易
- 市场永远是对的， 不要猜"股价会跌到多少、涨到多少"
- 下跌趋势：不抄底，直到"不再创新低 + 连续3根阳线 + 成交量放大"确认反转
- 上升趋势：不逃顶，直到"不再创新高 + 量价背离 + 大阴线"确认反转

### 铁律2：像狙击手一样，只打"关键点"
- 市场90%时间是无序波动，只有10%时间趋势明确
- 三个核心关键点（其余时间空仓）：
  1. 吸筹后的**突破点**（最佳进场点）
  2. 拉升中的**缩量回踩点**（加仓点）
  3. 派发初期的**跌破点**（最佳卖出点）

### 铁律3：看不懂就离场，只做"看得懂的股"
- 账户只留1-3只看得懂的标的，集中资金做
- 若看不清阶段（吸筹or派发），直接卖出或不买

## A股实操落地总结

> 吸筹期忍得住不抄底，拉升期跟得上不犹豫，派发期逃得掉不贪心，回落期空得住不侥幸，只打关键点，看不懂就离场，量价为根，跟随为魂。
