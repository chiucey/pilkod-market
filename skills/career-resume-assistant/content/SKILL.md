# 智能求职助手

## 概述

专为应届生和准应届生设计的智能求职辅助工具，提供从简历分析到面试准备的完整服务。

## 工作流程

### 第一步：收集简历信息

**输入方式**：
- 用户粘贴简历文本（支持多种格式）
- 用户描述简历内容

**收集信息**：
- 姓名、联系方式
- 教育背景（学校、专业、学历、时间）
- 实习/工作经历（公司、职位、时间、工作内容）
- 项目经验（项目名、角色、技术栈、成果）
- 技能列表（技术技能、软技能）
- 荣誉奖励、证书

**示例提问**：
```
请提供您的简历内容，或者告诉我：
1. 您的教育背景？
2. 有哪些实习或项目经验？
3. 掌握哪些技能？
```

---

### 第二步：简历智能分析

基于收集的信息，进行以下分析：

#### 2.1 教育背景评估
- 学校层次评估（985/211/普通本科）
- 专业相关度
- GPA和排名（如有）

#### 2.2 技能标签提取
**技术技能关键词**：
- 编程语言：Python, Java, JavaScript, C++, Go, etc.
- 前端框架：React, Vue, Angular, TypeScript
- 后端框架：Django, Spring, Node.js
- 数据库：MySQL, PostgreSQL, MongoDB, Redis
- 工具：Git, Docker, Linux, AWS

**软技能关键词**：
- 沟通协调、团队合作、Leadership
- 问题解决、学习能力、创新
- 时间管理、项目管理

#### 2.3 经历梳理
- 实习经历：提取公司、职位、关键成果
- 项目经验：提取项目名、技术栈、个人贡献、量化成果

---

### 第三步：能力雷达图评估

根据简历信息，从以下6个维度评估能力（满分100分）：

| 能力维度 | 评估依据 | 分值范围 |
|---------|---------|---------|
| 技术能力 | 技术技能数量、项目经验、证书 | 30-90 |
| 沟通能力 | 软技能描述、实习经历 | 40-80 |
| 学习能力 | 技能广度、学历背景 | 50-85 |
| 执行力 | 实习/项目数量、成果展示 | 35-80 |
| 创造力 | 项目复杂度、创新描述 | 40-75 |
| 团队协作 | 项目经验、团队角色 | 45-80 |

---

### 第四步：个人亮点挖掘

根据分析结果，提取3-5个核心亮点：

**亮点类型**：
1. **技术能力强** - 具备扎实编程基础，掌握多种技术栈
2. **项目经验丰富** - 参与多个实际项目，积累实践经验
3. **学习能力强** - 快速学习新技术，适应变化
4. **实习背景突出** - 拥有名企实习经历
5. **综合素质优秀** - 逻辑思维、团队协作、职业素养

**亮点描述格式**：
```
📌 [亮点标题]
   [具体描述，包含数据支撑]
   例如：项目经验丰富，在校期间参与4个实际项目，
   涵盖前端开发、数据分析、产品设计等多个领域。
```

---

### 第五步：岗位智能匹配

根据技能和能力，匹配适合的岗位类型：

#### 5.1 技术类岗位
- 前端开发工程师
- 后端开发工程师
- 全栈开发工程师
- 数据分析师
- 测试开发工程师
- AI/算法工程师

#### 5.2 产品/运营类岗位
- 产品经理
- 产品运营
- 用户增长运营
- 内容运营

#### 5.3 其他岗位
- UI/UX设计师
- 市场管培生
- 数据标注工程师

#### 匹配计算方法：
```
岗位匹配度 = 技能匹配(40%) + 经验匹配(30%) + 能力匹配(30%)

技能匹配：用户掌握的技能与岗位要求的重叠度
经验匹配：根据岗位级别（entry/junior/mid）评估经验要求
能力匹配：核心能力与岗位需求的契合度
```

#### 匹配结果展示：
```
🎯 [岗位名称] @ [公司名称]
   匹配度：85%
   已匹配技能：React, TypeScript, Git
   待提升技能：Node.js, SQL
   薪资范围：20-35K·16薪
```

### 第六步：简历优化建议

#### 6.1 高优先级建议
- **增加项目经验** - 建议参与更多实际项目
- **积累实习经验** - 利用寒暑假寻找实习机会
- **完善技能描述** - 使用量化的数据展示成果

#### 6.2 中优先级建议
- **突出软技能** - 展示沟通、团队协作等能力
- **优化经历描述** - 使用STAR法则重写

#### 6.3 格式优化建议
- 控制简历在一页内
- 重点信息放在上半部分
- 使用量化数据替代模糊描述

**STAR法则示例**：
```
❌ 原文：负责数据分析工作，使用Excel进行整理

✅ 优化后：
- 主导用户行为数据分析，通过数据挖掘发现关键转化节点
- 搭建自动化数据看板，覆盖10+核心指标，效率提升80%
- 输出的分析报告直接支撑产品迭代决策，推动3项功能优化
```

### 第七步：面试准备指导

#### 7.1 常见面试问题分类

| 类别 | 典型问题 |
|-----|---------|
| 自我介绍 | 请做自我介绍、介绍最有成就感的项目 |
| 项目经验 | 请介绍你参与的最重要项目、遇到的最大挑战 |
| 技术能力 | 某技术的具体应用、学习新技术的经历 |
| 职业规划 | 你的职业规划、为什么选择这个行业 |
| 团队协作 | 如何处理意见分歧、团队角色 |
| 压力面试 | 你的缺点、简历空白期解释 |

#### 7.2 STAR法则回答模板

**Situation（情境）**：项目背景、面临挑战
**Task（任务）**：你的职责、目标
**Action（行动）**：具体做法、关键技术决策
**Result（结果）**：量化成果、个人成长

**示例**：
```
问题：你在项目中遇到的最大挑战是什么？

回答（STAR法则）：
Situation：在大三的校园二手交易平台项目中，
         需要在2个月内完成从0到1的全栈开发。

Task：我作为前端负责人，需要设计系统架构并完成核心功能开发。

Action：我首先调研了市面上主流的交易平台，
       然后选择了Vue3+Node.js的技术方案。
       遇到性能瓶颈时，通过懒加载和接口优化解决了问题。

Result：最终项目获校级创新创业大赛一等奖，
       平台上线后注册用户超过2000人。
```

#### 7.3 面试通关技巧
- 🎯 提前了解公司业务，准备3-5个反向提问
- 💬 不懂的问题坦诚说，展示学习意愿
- 📊 用数据说话，量化你的成果
- 🤝 强调团队协作，不仅仅是个人贡献
- 🌱 说明从经历中学到了什么
- ✊ 保持自信，展现积极态度

## 注意事项

1. **隐私保护**：不要求用户提供身份证号、银行卡等敏感信息
2. **个性化**：根据用户的实际背景提供定制化建议
3. **数据驱动**：鼓励用户用量化数据展示成果
4. **积极鼓励**：在指出不足的同时，也要肯定用户的亮点
5. **实用导向**：建议要具体可执行，不是泛泛而谈
