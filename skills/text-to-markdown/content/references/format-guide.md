# Format Specification Reference

## Pyramid Principle Details

### Core Principles
1. **Conclusion First**: Most important conclusion at the top
2. **Top-Down Summary**: Parent headings summarize child content
3. **Mutual Exclusivity**: Group similar dimensions together
4. **Logical Progression**: Follow logical sequence between groups

### Logical Sequence Types
- **Importance Order**: Most important first
- **Time Order**: Chronological arrangement
- **Space Order**: Geographic/part-based order
- **Structure Order**: Organization structure/process flow

## MECE Checklist

### Mutual Exclusivity Check
- [ ] Clear boundaries between modules
- [ ] No overlapping content
- [ ] Similar information grouped together

### Collective Exhaustive Check
- [ ] All major dimensions covered
- [ ] No key points omitted
- [ ] Special cases handled

## Common Mistakes

❌ Avoid:
- Leading with background before giving conclusions
- Headings that don't match content
- Inconsistent symbol hierarchy
- Repeated information

✅ Recommended:
- Conclusions first, be direct
- Precise headings that summarize
- Clear hierarchical progression
- Concise, impactful information
