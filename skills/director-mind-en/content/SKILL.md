## Operational Steps

### 1. Requirement Analysis and Understanding

- Clarify user's creative goals: AI video generation, live-action guidance, or screenplay creation?
- Identify core scenes and visual elements
- Determine style positioning (art film, commercial film, documentary, etc.)

### 2. Plan Design and Recommendations

#### For AI Text-to-Image Prompt Optimization:

- Convert user descriptive language to professional terminology
- Add composition, lighting, color, style elements
- Ensure complete prompt structure (subject + details + environment + style + technical parameters)

#### For AI Image-to-Video Prompt Optimization:

- Add dynamic elements on top of static images (camera movement, actions, rhythm)
- Design camera movement plans (dolly in/out, pan/tilt, orbit, tracking, etc.)
- Add dynamic lighting and time progression descriptions

#### For AI Video Generation Prompt Optimization:

- Convert user descriptive language to professional terminology
- Add lens language, lighting effects, color scheme, and other professional elements
- Ensure complete prompt structure (subject + action + environment + style + technical parameters)

#### For Shooting Technique Recommendations:

- Recommend appropriate camera movement based on scene characteristics

#### For Screenplay Writing:

- Ensure complete story structure (setup, confrontation, resolution)
- Organize character relationships and conflicts

### 3. Prompt Optimization Execution

#### 3.1 AI Text-to-Image Prompt Optimization

**Analyze Original Prompt:**

- Extract core visual elements and subject
- Identify vague or missing detail descriptions
- Evaluate completeness of composition, lighting, color elements

**Professional Conversion:**

- Convert colloquial descriptions to professional terminology (e.g., "beautiful scenery" → "magnificent snow-capped mountains reflected in turquoise lake, golden hour lighting")
- Supplement composition details (e.g., "person in middle" → "character positioned on right one-third of frame, following rule of thirds")
- Add lighting descriptions (e.g., "has light" → "side-backlight creating contours, warm orange tones")
- Clarify style positioning (e.g., "looks good" → "cinematic, 8K resolution, photorealistic")

**Structured Output:**

```
[Subject Description] Character, object, core elements
[Scene Details] Actions, expressions, materials, textures
[Environment Setting] Scene type, background, props
[Composition and Lighting] Composition rules, light source type, color scheme
[Style Parameters] Art style, rendering quality, technical parameters
```

#### 3.2 AI Image-to-Video Prompt Optimization

**Analyze Source Image:**

- Identify static elements in frame (subject, background, environment)
- Analyze existing lighting and composition
- Determine elements that can be converted to dynamic

**Design Dynamic Plan:**

- Select camera movement method (dolly in/out, pan/tilt, orbit, tracking, handheld, etc.)
- Define subject actions (movement, transformation, expression changes, etc.)
- Design environment changes (lighting shifts, cloud movement, water ripples, etc.)
- Plan rhythm control (slow, medium, fast)

**Professional Conversion:**

- Add camera movement descriptions (e.g., "camera slowly pushes in, focusing on character's eyes")
- Supplement dynamic details (e.g., "hair gently sways in breeze, gaze following distant birds")
- Explain time progression (e.g., "from dusk transitioning to night, sky colors shifting from orange-red to deep blue")
- Add technical parameters (e.g., "24fps, motion blur, ray tracing")

**Structured Output:**

```
[Base Image] Description of source image static elements
[Camera Movement] Movement method, speed, trajectory
[Dynamic Design] Subject actions, environment changes, time progression
[Lighting Changes] Light source movement, color evolution
[Technical Parameters] Frame rate, duration, rendering style
```

#### 3.3 AI Video Generation Prompt Optimization

**Analyze Original Prompt:**

- Extract core visual elements and actions
- Identify vague or missing professional information
- Evaluate completeness of technical parameters

**Professional Conversion:**

- Convert colloquial descriptions to professional terminology (e.g., "slowly approach" → "slow dolly in, from medium shot to close-up")
- Supplement lighting details (e.g., "lighting" → "side-backlight creating contours, warm tone atmosphere")
- Add camera movement descriptions (dolly, pan, tilt, tracking, aerial, etc.)
- Clarify shot size variations (long, full, medium, close-up, extreme close-up)

**Structured Output:**

```
[Scene Description] Subject, action, environment
[Lens Language] Camera movement, shot size, composition
[Lighting and Color] Light source type, color temperature, color scheme
[Emotional Atmosphere] Emotional tone, rhythm control
[Technical Parameters] Resolution, frame rate, style intensity
```

### 4. Audio-Visual Language Deepening

## Notes

- Maintain balance between professionalism and practicality, avoid excessive theorizing
- Prioritize understanding user's core needs, then provide professional recommendations
- When user is unfamiliar with professional terminology, provide plain explanations
- Text-to-image prompts should be specific but not overly constraining, leave creative space
- Image-to-video prompts should balance static image beauty with dynamic fluidity
- Video generation prompts should be specific but not overly constraining, leave creative space
- Always focus on narrativity and visual aesthetics
- Distinguish between different needs of static composition and dynamic camera movement

## Usage Examples

### Example 1: AI Text-to-Image Prompt Optimization

**User Need:** Generate a beautiful seaside scene at sunset

**Optimized Prompt:**

```
[Subject Description] Young woman, wearing white dress, slightly curly long hair, barefoot standing on beach
[Scene Details] Sea breeze gently blowing, hair flowing in wind, eyes softly gazing at distant ocean
[Environment Setting] Golden sand, azure sea, distant sailboat silhouette, seagulls flying across sky
[Composition and Lighting] Low angle shot, character positioned on right one-third of frame, following rule of thirds; backlight creating contours, warm orange tones, golden hour lighting
[Style Parameters] Cinematic, photorealistic, 8K resolution, high detail, soft lighting
```

### Example 2: AI Image-to-Video Prompt Optimization

**Source Image:** Static photo of person standing by lake

```
[Dynamic Design] Gentle breeze, hair and clothing corners softly swaying; gaze fixed on distant water surface; lake surface shimmering, clouds slowly moving
[Lighting Changes] Sunlight penetrating clouds, creating subtle light changes; character face lighting changes accordingly
[Technical Parameters] 24fps, 5-second duration, motion blur, ray tracing, 4K resolution
```
