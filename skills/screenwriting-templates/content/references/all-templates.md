### 模板1：悉德·菲尔德 经典三幕式结构

**来源：** 《电影剧本写作基础》（Syd Field），全球400+电影学院核心教材

**地位：** 好莱坞编剧教父，所有编剧模板的底层基础

#### 核心框架

```
第一幕：建置（0-25%）
├── 世界观建立
├── 主角日常呈现
├── 激励事件打破平静
├── 主角接受任务
└── 正式踏上旅程

第二幕：对抗（25-75%）
├── 持续遭遇挑战
├── 反派施压升级
├── 中点重大转折（伪胜利/伪失败）
└── 主角陷入人生最低谷

第三幕：结局（75-100%）
├── 绝地反击
├── 终极对决
├── 冲突解决
└── 人物弧光完成
```

#### 两个关键情节点

| 情节点 | 位置 | 功能 |
|--------|------|------|
| 第一情节点（Inciting Incident） | 第25页/25% | 主角正式行动，踏上旅程 |
| 第二情节点（Second Plot Point） | 第75-85页/75-85% | 最低谷后的转机，获得新方案 |

#### ATU 301功能簇对照

| 幕 | 占比 | 核心功能 | 对应ATU功能簇 |
|----|------|----------|---------------|
| 第一幕 | 25% | 铺垫主角、设定，通过激励事件打破平静 | 任务簇(A) → 旅程簇(B) |
| 第二幕 | 50% | 主角持续遭遇挑战、反派施压，中点转折 | 战斗簇(D) / 身份簇(E) / 背叛簇(F) / 黑暗簇(G) |
| 第三幕 | 25% | 主角绝地反击、终极对决、冲突解决 | 战斗簇(H) / 变形簇(I) / 牺牲簇(J) / 宝藏簇(K) |

#### 典型适用

- 院线电影（90-120分钟）
- 长篇小说（10万字以上）
- 游戏主线剧情
- **容错率最高，新手首选模板**

### 模板2：丹·哈蒙 故事圈

**来源：** 《瑞克和莫蒂》主创 Dan Harmon，基于英雄之旅简化的闭环模型

**地位：** 单元剧/连载网文神器

#### 核心八步

```
        A（你/舒适区）
           ╱ ╲
          ╱   ╲
    D（选择）  B（需求）
        ↓       ↗
  C（探索新  F（代价）
    世界）
          ↘     ↙
           G（回归）
              ↓
           H（改变）
```

| 步骤 | 名称 | 内容 | ATU对照 |
|------|------|------|---------|
| 1 | You（你） | 主角处于舒适区，初始状态铺垫 | 身份簇-初始状态 |
| 2 | Need（需求） | 主角有了明确的欲望/核心目标 | 任务簇-发现问题 |
| 3 | Go（出发） | 主角进入陌生环境 | 旅程簇-出发 |
| 4 | Search（探索） | 主角适应新环境，遭遇考验与对抗 | 战斗簇-试炼 |
| 5 | Find（获得） | 主角得到了想要的东西 | 宝藏簇-获得奖赏 |
| 6 | Take（代价） | 主角为收获付出沉重代价 | 背叛簇/黑暗簇 |
| 7 | Return（回归） | 主角回到熟悉的环境 | 旅程簇-归途 |
| 8 | Change（改变） | 主角发生根本性蜕变 | 变形簇-蜕变 |

#### 典型适用

- 单元剧（每集独立故事）
- 连载网文（日更节奏）
- 番剧支线剧情
- 游戏支线任务
- **优点：每章/每集都有完整起承转合，不写流水账**

### 模板3：弗兰克·丹尼尔 八序列结构

**来源：** 南加州大学电影学院，Frank Daniel，好莱坞顶级剧本医生

**地位：** 解决"第二幕拖沓"问题的终极方案

#### 八序列框架

```
╔════════════════════════════════════════════════════════════════╗
║  第一幕（序列1-2）                                              ║
╠════════════════════════════════════════════════════════════════╣
║  序列1（0-12%）：铺垫 + 日常建立                                ║
║  序列2（12-25%）：激励事件，主角正式接受任务                      ║
╠════════════════════════════════════════════════════════════════╣
║  第二幕上半（序列3-4）                                          ║
╠════════════════════════════════════════════════════════════════╣
║  序列3（25-37%）：初入险境，遭遇挑战                            ║
║  序列4（37-50%）：中点重大反转（伪胜利/伪失败）                  ║
╠════════════════════════════════════════════════════════════════╣
║  第二幕下半（序列5-6）                                          ║
╠════════════════════════════════════════════════════════════════╣
║  序列5（50-62%）：压力升级，危机加剧                            ║
║  序列6（62-75%）：主角陷入绝境，人生最低谷                      ║
╠════════════════════════════════════════════════════════════════╣
║  第三幕（序列7-8）                                              ║
╠════════════════════════════════════════════════════════════════╣
║  序列7（75-88%）：终极对决，绝地反击                            ║
║  序列8（88-100%）：结局闭环 + 主题升华                          ║
╚════════════════════════════════════════════════════════════════╝
```

#### 核心特点

> 每个序列都是一个微型三幕式，有自己的"建置-对抗-结局"

- **序列1-2** = 第一幕（建立世界）
- **序列3-6** = 第二幕（四个阶段，每阶段都是小高潮）
- **序列7-8** = 第三幕（终局）

#### 典型适用

- 院线电影（120分钟+）
- 12-24集网剧
- 长篇小说分卷（每卷约8-10万字）
- **完美适配"小爽点不断，大爽点集中"的网文需求**

### 模板4：罗伯特·麦基 价值反转体系

**来源：** Robert McKee《故事：材质、结构、风格和银幕剧作的原理》

**地位：** 全球编剧必读圣经，"叙事学的终极教科书"

#### 核心逻辑

> **故事的本质是价值反转**
> 每一个场景都必须完成一次价值正负反转

#### 五层结构

```
┌─────────────────────────────────────────┐
│  终极故事（Complete Story）              │ ← 主角从头到尾的根本性价值改变
│    ├─ 多幕（Acts）                      │
│    │     ├─ 序列（Sequences）           │
│    │     │     ├─ 场景（Scenes）        │
│    │     │     │     └─ 节拍（Beats）   │ ← 最小单元：动作+反应
│    │     │     └─ ...                   │
│    │     └─ ...                         │
│    └─ ...                               │
└─────────────────────────────────────────┘
```

#### 场景价值反转示例

| 场景类型 | 反转方向 | 情绪效果 |
|----------|----------|----------|
| 希望建立 | 希望→绝望 | 悲伤/震惊 |
| 信任建立 | 信任→背叛 | 愤怒/心碎 |
| 爱情升温 | 爱→恨/失去 | 心碎/恐惧 |
| 胜利在望 | 信心→失败 | 沮丧/绝望 |

#### 典型适用

- 高口碑电影/剧集
- 强情绪冲击的故事
- 深度角色扮演游戏的主线剧情
- **与ATU的黑暗簇(G)、牺牲簇(I)、变形簇(J)完美适配**

### 模板5：约翰·特鲁比 22步故事结构

**来源：** John Truby《故事写作大师班》，迪士尼/华纳御用编剧导师

**地位：** 业内公认的"人物+剧情双在线"模板

#### 22步框架

```
┌──────────────────────────────────────────────────────────────────┐
│  第一部分：前提与设计（第1-4步）                                    │
├──────────────────────────────────────────────────────────────────┤
│  ① 弱点与需求：主角的内在致命弱点 + 必须解决的人生需求             │
│  ② 欲望：主角的外在核心目标                                       │
│  ③ 对手：与主角有相同欲望的强力对手（核心冲突来源）               │
│  ④ 计划：主角为达成目标制定的行动方案                              │
├──────────────────────────────────────────────────────────────────┤
│  第二部分：对抗升级（第5-12步）                                    │
├──────────────────────────────────────────────────────────────────┤
│  ⑤ 第一幕对抗                                                     │
│  ⑥ 盟友出现                                                      │
│  ⑦ 考验与选择                                                     │
│  ⑧ 对手加大压力                                                   │
│  ⑨ 伪装自我揭露（主角对自己撒的谎）                                │
│  ⑩ 第二幕中点：真正自我揭露                                       │
│  ⑪ 考验升级                                                      │
│  ⑫ 主角的选择（道德层面的抉择）                                    │
├──────────────────────────────────────────────────────────────────┤
│  第三部分：终极对决与蜕变（第13-22步）                             │
├──────────────────────────────────────────────────────────────────┤
│  ⑬ 对决准备                                                      │
│  ⑭ 终极对决：主角和对手的最终对抗                                  │
│  ⑮ 真实自我揭露：主角在对决中认清真实的自己                        │
│  ⑯ 过渡：进入新世界                                               │
│  ⑰ 新的平衡点：主角完成蜕变，进入全新人生状态                      │
│  ⑱ 结局：所有故事线收束                                          │
│  ⑲ 主题表达：故事的核心观点                                       │
│  ⑳ 形象画面压韵：结尾画面与开头形成对照                           │
│  ㉑ 复合主题                                                     │
│  ㉒ 故事高潮：主人公的终极选择                                    │
└──────────────────────────────────────────────────────────────────┘
```

#### 核心特点

> 每一步同时推进**剧情**和**人物成长**，彻底解决"剧情和人物脱节"的问题

#### 典型适用

- 长篇小说（尤其是人物驱动型）
- IP主线剧情
- 需要角色深度的游戏叙事
- **与ATU的变形簇(J)、宝藏簇(K)、黑暗簇(G)完美适配**

### 模板6：拉约什·埃格里 冲突三要素

**来源：** Lajos Egri《编剧的艺术》（百老汇戏剧圣经）

**地位：** 强冲突故事的底层法则

#### 三维角色模型

```
┌─────────────────────────────────────────┐
│              三维角色                    │
├─────────────────────────────────────────┤
│  生理维度                                │
│  └─ 外在：外貌、年龄、健康状况           │
├─────────────────────────────────────────┤
│  社会维度                                │
│  └─ 关系：家庭、朋友、职业、社会地位      │
├─────────────────────────────────────────┤
│  心理维度  ←─ 核心矛盾所在               │
│  └─ 内在：恐惧、欲望、执念、未愈合创伤   │
└─────────────────────────────────────────┘
```

#### 冲突升级路径

```
静态冲突（表面矛盾）
    ↓
跳跃冲突（间歇性爆发）
    ↓
持续升级冲突（不断加码）
    ↓
指向故事前提的核心冲突
```

#### 典型适用

- 戏剧/话剧
- 权谋文/宫斗文
- 家庭伦理故事
- 强人物冲突的影视剧本
- **与ATU的身份簇(E)、背叛簇(F)完美适配**

### 模板7：布莱克·斯奈德 救猫咪15节拍表

**来源：** Blake Snyder《救猫咪：电影编剧指南》

**地位：** 全球商业创作最通用模板，90%商业院线片都在用

#### 15节拍详解

| # | 节拍 | 位置 | ATU对照 | 内容说明 |
|----|------|------|---------|----------|
| 1 | 开场画面 | 0-1% | 初始状态 | 定调画面，确立情绪基色 |
| 2 | 主题呈现 | 5% | 主题伏笔 | 有人说出或暗示主题 |
| 3 | 铺垫建置 | 1-10% | 身份簇 | 展示主角日常生活与世界 |
| 4 | 激励事件 | 12% | 任务簇 | 打破平静，触发主线 |
| 5 | 争执辩论 | 12-25% | 身份簇 | 主角内心挣扎，决定是否行动 |
| 6 | 第二幕衔接点 | 25% | 旅程簇 | 正式出发，进入"第二幕" |
| 7 | B故事 | 30% | 身份簇 | 情感线/伙伴线（通常是爱情） |
| 8 | 趣味游戏 | 30-50% | 战斗簇 | 展示卖点与核心场景，爽点输出 |
| 9 | 中点 | 50% | 战斗簇 | 重大转折：伪胜利或伪失败 |
| 10 | 反派逼近 | 50-75% | 背叛簇 | 反派加大压力，内外交困 |
| 11 | 一无所有 | 75% | 黑暗簇 | 重大打击，几乎失去一切 |
| 12 | 灵魂黑夜 | 75-80% | 牺牲簇 | 最低谷，反思与顿悟 |
| 13 | 第三幕衔接点 | 80% | 变形簇 | 找到破局方案，准备绝地反击 |
| 14 | 终极对决 | 80-99% | 战斗簇 | 最终战斗/关键抉择 |
| 15 | 终场画面 | 99-100% | 变形簇 | 与开头呼应，终幕画面 |

#### ATU 301功能簇完整映射

```
开场画面(1) + 主题呈现(2) + 铺垫建置(3)
    → ATU 身份簇(E) / 世界观铺垫

激励事件(4) + 争执辩论(5)
    → ATU 任务簇(A) / 旅程簇(B)

第二幕衔接点(6) + B故事(7)
    → ATU 旅程簇(B) / 身份簇(E)情感线

趣味游戏(8)
    → ATU 战斗簇(D) / 宝藏簇(K)

中点(9) + 反派逼近(10)
    → ATU 背叛簇(F) / 战斗簇(D)

一无所有(11) + 灵魂黑夜(12)
    → ATU 黑暗簇(G) / 牺牲簇(I)

第三幕衔接点(13) + 终极对决(14)
    → ATU 变形簇(J) / 战斗簇(D)

终场画面(15)
    → ATU 归来簇(H) / 变形簇(J)
```

#### 典型适用

- 商业电影（90-120分钟）
- 新媒体文/爽文
- 短剧/短视频剧情
- **精准控制节奏，爽点密集不拖沓**

### 模板8：林赛·多兰 七要点结构

**来源：** Lindsay Doran，《傲慢与偏见》《理智与情感》金牌制片人

**地位：** 情感向故事的终极模板

#### 七要点框架

```
┌─────────────────────────────────────────────────────────────┐
│  七要点情感弧线                                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│     高 ──╮                                    ╭─ 高         │
│         │ ＼                                ╱│ 圆满          │
│    情感  │    ＼    希望时刻(4)           ╱  │ 情感          │
│    期望  │      ＼_____________________╱    │ 重归于好      │
│         │       ╱  ＼               ╱  ＼   │              │
│     低 ──╯      吸引(3)  重大挫折(5)  自我  ╰─ 低            │
│                 吸引力     因为缺陷破裂  转变(6) 绝望         │
│                    ↗                                    ↘   │
│              意外相遇(2)                             情感圆满  │
│                  ↗                                  (7)     │
│            情感缺陷(1) ←────────────────────→ 新的平衡       │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

#### 各要点详解

| # | 要点 | ATU对照 | 内容 |
|----|------|---------|------|
| 1 | 主角的情感缺陷 | 身份簇(E) | 主角无法幸福的内在核心原因 |
| 2 | 意外相遇 | 任务簇(A) | 命中注定的人出现，打破日常 |
| 3 | 吸引力 | 身份簇(E) | 两人情感拉扯，产生羁绊 |
| 4 | 希望时刻 | 宝藏簇(K) | 情感达到顶峰，以为能圆满 |
| 5 | 重大挫折 | 黑暗簇(G) | 因情感缺陷，两人关系破裂 |
| 6 | 自我转变 | 变形簇(J) | 主角认清缺陷，完成内在成长 |
| 7 | 情感圆满 | 变形簇(J) | 带着全新自己，获得真正幸福 |

#### 典型适用

- 言情小说（现言/古言）
- 情感向短剧
- 女性向IP开发
- **解决"工业糖精、没CP感、情感转折生硬"的问题**

### 模板9：三宅隆太 日式悬疑12步

**来源：** 三宅隆太 Ryuta Miyake，《午夜凶铃》《咒怨》系列核心编剧

**地位：** 日式悬疑/灵异/推理的黄金模板

#### 12步框架

```
┌─────────────────────────────────────────────────────────────┐
│  日式悬疑叙事节奏                                            │
├─────────────────────────────────────────────────────────────┤
```
