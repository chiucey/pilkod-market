```
新手入门      → 救猫咪15节拍 → 三幕式 → 故事圈
```

## 模板核心要素

### 三幕式（通用基础）
```
第一幕(25%) → 建置：世界观+激励事件+主角出发
第二幕(50%) → 对抗：中点转折+压力升级+最低谷
第三幕(25%) → 结局：绝地反击+终极对决+人物蜕变
```

### 救猫咪15节拍（商业最常用）
```
开场画面 → 主题呈现 → 铺垫建置 → 激励事件
争执辩论 → 第二幕衔接点 → B故事 → 趣味游戏
中点反转 → 反派逼近 → 一无所有 → 灵魂黑夜
第三幕衔接点 → 终极对决 → 终场画面
```

### 故事圈（单元剧/网文）
```
You(舒适区) → Need(需求) → Go(出发) → Search(探索)
Find(获得) → Take(代价) → Return(回归) → Change(改变)
```

## 工作流程

当用户提供以下信息时，给予精准推荐：

1. **题材类型** → 推荐主模板 + 辅助模板
2. **篇幅长度** → 筛选适合的模板
3. **核心需求**（节奏/人物/冲突）→ 强调对应模板优势
4. **新手/进阶** → 给出学习路径

详细模板内容请查看 `references/` 目录。
