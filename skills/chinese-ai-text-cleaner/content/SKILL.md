# 中文AI文本排版清洗

## 功能概述

将AI生成的中文文本清洗为符合中文排版规范的标准化格式。

## 清洗规则

### 1. 标点符号规范化

| 问题 | 修复 |
|------|------|
| 半角逗号 `,` | 改为全角 `，` |
| 半角句号 `.` | 改为全角 `。` |
| 半角分号 `;` | 改为全角 `；` |
| 半角冒号 `:` | 改为全角 `：` |
| 半角引号 `"` `"` | 改为全角 `「」` 或 `“”` |
| 半角括号 `()` | 改为全角 `（）` |
| 半角问号 `?` | 改为全角 `？` |
| 半角感叹号 `!` | 改为全角 `！` |

### 2. 连接符处理

- **删除** 句中的多余 `——`，除非是真正的对话中断或转折强调
- 连续出现 `......` 或 `…` 改为标准省略号 `……`
- 破折号 `——` 保留用于需要强调的转折句

### 3. 空格清理

- 删除英文词与中文之间的多余空格
- 删除句首/句尾的多余空格
- 保留中文与全角标点之间的自然间距

### 4. AI表达清洗

常见AI冗余表达需要清理：

| AI常用表达 | 建议修改 |
|-----------|----------|
| "首先"、"其次"、"最后"（机械列表） | 根据语境保留或改为自然过渡 |
| "值得注意的是"、"需要注意的是" | 删除或简化 |
| "一般来说"、"通常情况下" | 删除 |
| 重复的修饰语 | 精简 |
| 过于完美的过渡句 | 删除 |

### 5. 数字处理

- 纯数字 123 改为中文一二三 或保持阿拉伯数字（根据上下文）
- 年份如 2024年 保持阿拉伯数字

## 使用方式

1. **读取待清洗的文本文件**
2. **逐条应用上述规则**
3. **输出清洗后的文本**

## 示例

**清洗前：**
```
首先，我需要说明的是——这本书的主人公叫小明。他生活在一个小镇上， 
每天的生活很简单。"你好啊！"有一天，小明对自己的朋友说。 
然后，他们一起去上学......他们去了学校，学校的老师很好。
```

**清洗后：**
```
这本书的主人公叫小明。他生活在一个小镇上，每天的生活很简单。
“你好啊！”有一天，小明对自己的朋友说。
然后，他们一起去上学……他们去了学校，学校的老师很好。
```

## 注意事项

- 保留原文的语气和语义，仅做格式和表达清洗
- 省略号 `……` 居中显示，不同于英文省略号
- 对话中的引号优先使用 `「」` 或 `“”`，保持一致
- 保留必要的英文术语（如人名、地名可保留原文）
