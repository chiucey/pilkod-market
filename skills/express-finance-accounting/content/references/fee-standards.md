# 快递财务 - 计费规则配置参考

## 派费计费规则

### 按重量段计费（标准配置）

| 重量段 | 首重费用 | 续重费用(元/kg) | 最低收费 |
|--------|----------|-----------------|----------|
| 0-1kg | 1.5元 | - | 1.5元 |
| 1-3kg | 1.5元 | 0.5 | 2.0元 |
| 3-10kg | 2.5元 | 0.8 | 4.0元 |
| 10-30kg | 5.0元 | 1.0 | 10.0元 |
| 30kg+ | 25.0元 | 1.5 | 40.0元 |

### 按区域计费

| 区域类型 | 基础派费 | 超区附加费 |
|----------|----------|------------|
| 城市核心区 | 1.2元/票 | 0元 |
| 城市郊区 | 1.5元/票 | 0元 |
| 乡镇区域 | 2.0元/票 | 1.0元 |
| 偏远地区 | 3.0元/票 | 2.0元 |

## 其他费用标准

| 费用项目 | 计费方式 | 标准 |
|----------|----------|------|
| 上楼费 | 按重量+楼层 | 1-3kg: 1元, 3kg+: 2元 |
| 偏远附加费 | 固定 | 2-5元/票 |
| 保价费 | 按声明价值 | 1‰ (最低1元) |
| 签收回执费 | 固定 | 1元/票 |
| 代收货款服务费 | 按金额比例 | 1%, 最低5元 |
| 拒收件处理费 | 固定 | 3元/票 |
