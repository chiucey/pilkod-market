# 快递财务 - 数据导入模板说明

## 收支流水导入模板

### 标准CSV格式

```csv
日期,单号,客户名称,业务类型,金额,收/支,备注
2024-03-01,SF123456789,张三,派件,15.00,收,派送费
2024-03-01,SF123456790,李四,派件,12.00,收,派送费
2024-03-01,ZD987654321,网点A,中转,85.50,支,中转费
2024-03-02,SF123456791,王五,运费,45.00,收,运费收入
2024-03-02,MD555555555,系统,面单,500.00,支,购买面单
```

### 业务类型代码对照

| 代码 | 业务类型 | 收/支 | 会计处理 |
|------|----------|-------|----------|
| 01 | 派件 | 收 | 应收账款+ |
| 02 | 运费 | 收 | 应收账款+ |
| 03 | 中转 | 支 | 主营业务成本+ |
| 04 | 面单 | 支 | 主营业务成本+ |
| 05 | 上楼费 | 收 | 主营业务收入+ |
| 06 | 保价费 | 收 | 其他业务收入+ |
| 07 | 代收货款 | 收 | 往来款 |
| 08 | 偏远附加 | 收 | 主营业务收入+ |
| 99 | 其他 | - | 根据实际 |

## Excel模板结构

### Sheet1: 收支流水

| 列号 | 字段名 | 数据类型 | 必填 | 说明 |
|------|--------|----------|------|------|
| A | 日期 | 日期 | 是 | YYYY-MM-DD |
| B | 单号 | 文本 | 否 | 快递单号 |
| C | 客户名称 | 文本 | 是 | 客户/员工名称 |
| D | 业务类型 | 下拉 | 是 | 见类型对照表 |
| E | 金额 | 数值 | 是 | 精确到分 |
| F | 收/支 | 下拉 | 是 | 收/支 |
| G | 对方科目 | 文本 | 否 | 银行账号等 |
| H | 备注 | 文本 | 否 | 补充说明 |

### Sheet2: 客户资料

| 列号 | 字段名 | 说明 |
|------|--------|------|
| A | 客户编号 | 自动生成 |
| B | 客户名称 | 必填 |
| C | 客户类型 | 客户/员工/网点 |
| D | 联系电话 | - |
| E | 地址 | - |
| F | 结算方式 | 月结/现结 |
| G | 信用额度 | 月结客户用 |
| H | 备注 | - |

### Sheet3: 费用标准

| 列号 | 字段名 | 说明 |
|------|--------|------|
| A | 费用类型 | 派费/中转费/... |
| B | 计费方式 | 按重量/按件数/固定 |
| C | 起始值 | 范围起始 |
| D | 结束值 | 范围结束 |
| E | 单价 | 元/票 或 元/kg |
| F | 最低收费 | - |
| G | 生效日期 | - |
| H | 失效日期 | - |

## 数据校验规则

### 日期校验
- 格式：YYYY-MM-DD
- 范围：2020-01-01 至 当前日期+7天
- 异常：红色标注

### 金额校验
- 正数
- 精确到小数点后2位
- 不能为0
- 异常：红色标注

### 业务类型校验
- 必须在下拉列表中选择
- 自由输入会提示选择
- 异常：弹窗提示

### 必填校验
- 日期、客户名称、金额、收/支不能为空
- 异常：整行红色高亮
