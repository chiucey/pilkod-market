# 快递财务自动核算与报表生成

## 技能概述

本技能为快递物流行业提供全面的财务自动化解决方案，支持费用查询、自动核算、报表生成、会计做账和月结对账等功能。

## 核心功能模块

### 1. 费用查询模块

支持查询以下费用类型：
- **运费查询**：按单号、客户、日期范围查询应收运费
- **中转费查询**：各中转中心之间的转运费用
- **派费查询**：末端派件员的派送费用
- **面单费查询**：电子面单使用成本
- **其他费用**：上楼费、偏远附加费、保价费等

**触发指令示例**：
- "查询张三3月份的派费"
- "这个月的中转费是多少"
- "本周面单费明细"

### 2. 报表自动生成模块

#### 现金报表
- 现金收入明细表
- 现金支出明细表
- 现金流水账
- 银行对账表

#### 现金台账
- 按客户分类的台账
- 按业务类型分类的台账
- 按时间周期汇总的台账

#### 利润表
- 营业收入明细
- 营业成本明细
- 期间费用明细
- 净利润计算

**触发指令示例**：
- "生成3月份现金报表"
- "打印现金台账"
- "导出本月利润表"

### 3. 财务核算模块

#### 中转费核算
- 按重量段计费规则自动计算
- 按目的地中转费标准表匹配
- 中转费汇总统计

#### 会计做账
- 收入类凭证生成
- 成本类凭证生成
- 费用类凭证生成
- 银行转账凭证

#### 凭证分录
| 业务类型 | 借方科目 | 贷方科目 |
|---------|---------|---------|
| 收到运费 | 银行存款/现金 | 应收账款 |
| 支付中转费 | 营业成本-中转费 | 银行存款/现金 |
| 计提派费 | 营业成本-派送费 | 应付账款 |
| 购买面单 | 营业成本-面单费 | 银行存款/现金 |

**触发指令示例**：
- "自动生成本月凭证"
- "做中转费会计分录"
- "生成计提派费凭证"

### 4. 月结对账模块

自动完成月度结账流程：
- 应收应付款项核对
- 现金银行余额核对
- 收支汇总核对
- 生成对账差异表
- 结账凭证生成

**触发指令示例**：
- "完成3月份对账"
- "月结处理"
- "生成对账差异表"

## 数据输入格式

支持以下数据导入方式：

### 标准表格模板（推荐）
```csv
日期,单号,客户名称,业务类型,金额,收/支,备注
2024-03-01,SF123456,张三,派件,15.00,收,派送费
2024-03-01,ZD789012,李四,运费,85.00,收,运费
2024-03-02,ZZ654321,王五,中转,12.00,支,中转费
```

### 字段说明
| 字段 | 必填 | 说明 |
|-----|-----|-----|
| 日期 | 是 | 格式：YYYY-MM-DD |
| 单号 | 否 | 快递单号 |
| 客户名称 | 是 | 客户/员工姓名 |
| 业务类型 | 是 | 运费/派件/中转/面单/其他 |
| 金额 | 是 | 数字，精确到分 |
| 收/支 | 是 | 收：收入；支：支出 |
| 备注 | 否 | 补充说明 |

| 指令 | 功能 |
|-----|-----|
| `/财务查询 [类型] [条件]` | 按条件查询费用 |
| `/生成报表 [报表类型] [月份]` | 生成指定报表 |

## 使用流程

### 首次使用
1. 导入基础数据（客户资料、费用标准表）
2. 配置中转费计费规则
3. 设置会计科目模板
4. 验证初始化数据

### 日常使用
1. 每日导入收支流水
2. 执行自动核算
3. 生成所需报表
4. 审核并导出

### 月结流程
1. 核对所有应收应付款
2. 运行月结对账
3. 生成结账凭证
4. 输出月度财务报表

## 计费规则配置

支持自定义计费规则模板：

### 派费标准（示例）
```yaml
派费规则:
  标准派件:
    重量范围: 0-3kg
    费用: 1.5元/票
  超重派件:
    超出部分: +0.5元/kg
  偏远地区:
    附加费: +1.0元/票
```

### 中转费标准（示例）
```yaml
中转费规则:
  按目的地区域:
    一区: 1.0元/kg
    二区: 1.5元/kg
    三区: 2.0元/kg
    偏远区: 3.0元/kg
  最低收费: 5元/票
```

## 注意事项

1. **数据备份**：定期导出备份重要财务数据
2. **权限控制**：敏感财务操作建议设置审核流程
3. **数据核对**：生成报表后需人工核对确认
4. **标准更新**：费用标准变更时及时更新配置
