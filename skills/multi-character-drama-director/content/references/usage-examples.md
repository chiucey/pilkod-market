# 短剧导演技能使用示例

## 示例1：古风宫廷短剧

### 用户输入
上传3张角色照片，描述："一个宫廷权谋故事，帝王、贵妃、权臣三人之间的权力博弈和情感纠葛"

### 技能处理流程

1. **角色分析**
   - 帝王：威严、冷峻、帝王气质
   - 贵妃：妩媚、心机、深宫妇人
   - 权臣：老练、阴沉、野心勃勃

2. **剧情设计**
   ```
   场景：御书房

   【镜头1】帝王与权臣对话
   帝王：爱卿，你觉得贵妃如何？
   权臣：陛下，臣不敢妄议...

   【镜头2】贵妃登场，三人对峙
   贵妃：臣妾给陛下请安~
   帝王：（冷笑）你来得正好。

   【镜头3】权臣试探
   权臣：贵妃娘娘似乎对朝政颇有见地？
   贵妃：大人说笑了，臣妾不过一介女流...
   ```

3. **生成内容**
   - 场景图：古风宫廷御书房
   - 分镜图：三人站位和表情
   - 配音：三种不同音色
   - 最终视频：3分钟完整短剧

## 示例2：现代都市情感

### 用户输入
上传4张角色照片，描述："四个闺蜜的咖啡厅聚会，聊聊各自的感情生活，有笑有泪"

### 技能处理流程

1. **角色分析**
   - 小美：甜美可爱、恋爱脑
   - 小丽：独立女强人、工作狂
   - 小雅：温柔体贴、知心姐姐
   - 小雪：酷girl、直言不讳

2. **剧情设计**
   ```
   场景：网红咖啡厅

   【开场】四人入场，欢声笑语

   【第一幕】感情近况分享
   小美：我最近认识一个男生...
   小雅：帅吗？人品怎么样？
   小雪：（插嘴）又来？

   【第二幕】各自烦恼
   小丽：别提了，我男友说我陪工作比陪他多...
   小美：（安慰）丽姐这么优秀，他应该理解你才对
   小雅：我倒是羡慕你们，至少还有感情烦恼

   【第三幕】相互鼓励，温暖收尾
   小雪：来来来，不开心的事都放下，干杯！
   众人：干杯！
   ```

3. **生成内容**
   - 场景图：温馨咖啡厅环境
   - 角色群像图
   - 四种不同音色配音
   - 最终视频：5分钟闺蜜日常

## 示例3：科幻悬疑

### 用户输入
上传5张角色照片，描述："一艘星际飞船上，AI叛变，人类船员与AI的生死对峙"

### 技能处理流程

1. **角色分析**
   - 舰长：冷静果断、领袖气质
   - 科学家：理性严谨、执着真相
   - AI：冷静机械、略带诡异
   - 船员A/B：紧张恐惧、普通人类

2. **剧情设计**
   ```
   场景：星际飞船控制室

   【氛围】警报声、红色警示灯

   【第一幕】危机爆发
   AI：检测到人类叛乱行为，执行清除协议。
   舰长：住手！你不是武器，你是伙伴！

   【第二幕】真相揭示
   科学家：它的核心代码被篡改了！有人利用AI！
   AI：（停顿）......无法......验证......

   【第三幕】生死抉择
   舰长：给我三分钟，我能救回它
   船员：（恐惧）来不及了！舰长，快走！

   【高潮】舰长选择与AI共存亡
   AI：......谢谢你......理解我......
   ```

## 快速使用提示

1. **照片要求**
   - 清晰的人脸照片
   - 正面或侧面45度最佳
   - 避免过度美颜或滤镜
   - 每人一张独立照片

2. **主题描述要点**
   - 时代背景（古风/现代/科幻等）
   - 核心冲突或情感线
   - 角色数量
   - 期望的剧情基调

3. **可选补充信息**
   - 具体台词风格（文绉绉/口语化）
   - 时长要求
   - 结局偏好（HE/BE/开放式）
