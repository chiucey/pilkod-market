# 多人短剧剧情模板库

## 一、古风题材模板

### 1.1 宫廷权谋

**角色配置**：3-5人
- 帝王/帝王妃
- 权臣/谋士
- 忠仆/暗卫
- 反派/奸妃

**剧情结构**：
```
第一幕：朝堂暗涌
- 权臣试探帝王态度
- 帝王与忠臣密谋
- 伏笔埋设

第二幕：后宫风云
- 嫔妃争宠暗斗
- 真相浮出水面
- 情感纠葛

第三幕：破局反击
- 忠臣献策
- 帝王决断
- 大结局
```

### 1.2 仙侠情缘

**角色配置**：3-4人
- 男女主角
- 师尊/长老
- 反派/魔君
- 配角（师兄妹）

**经典台词模板**：
- "三生三世，初心不改"
- "纵使魂飞魄散，我亦不悔"
- "这天下苍生，与我何干？我只想要你活着"

## 二、现代题材模板

### 2.1 都市情感

**角色配置**：2-4人
- 男女主角
- 闺蜜/兄弟
- 前任/情敌
- 父母/长辈

**剧情结构**：
```
第一幕：相遇/重逢
- 意外邂逅
- 身份揭示
- 情感萌芽

第二幕：磨合/冲突
- 误会产生
- 外部阻力
- 内心挣扎

第三幕：抉择/圆满
- 真情告白
- 解决问题
- 幸福结局
```

### 2.2 职场风云

**角色配置**：3-5人
- 老板/上司
- 同事/下属
- 竞争对手
- 客户/合作伙伴

**经典场景**：
- 会议battle
- 团队协作
- 商业谈判
- 职场潜规则

## 四、悬疑题材模板

### 4.1 推理探案

**角色配置**：4-6人
- 侦探/警察
- 受害者
- 嫌疑人
- 证人

**叙事结构**：
```
1. 案发：神秘死亡/失踪
2. 调查：逐一排查嫌疑
3. 推理：关键证据浮现
4. 逆转：意想不到的真相
5. 结案：正义伸张
```

## 五、角色对话技巧

### 5.1 对话节奏

| 场景 | 语速 | 情感 | 留白 |
|------|------|------|------|
| 激烈争吵 | 快 | 愤怒/激动 | 短 |
| 深情告白 | 慢 | 温柔/真挚 | 长 |
| 紧张对峙 | 中快 | 冷静/压迫 | 中 |
| 日常闲聊 | 正常 | 轻松/自然 | 短 |

## 六、分镜脚本模板

```markdown
## 场景1：咖啡厅相遇

### 镜头1
- 画面：女主角推门进入咖啡厅
- 角度：跟拍女主角
- 台词：女主角内心独白
- 时长：5秒

### 镜头2
- 画面：男主角抬头，四目相对
- 角度：双人正反打
- 台词：男主角（惊讶）"是你？"
- 时长：3秒

### 镜头3
- 画面：女主角走近
- 角度：中景推进
- 台词：女主角"好久不见..."
- 时长：4秒
```

## 七、质量评估标准

| 维度 | 优秀 | 合格 | 待改进 |
|------|------|------|--------|
| 剧情完整 | 起承转合完整 | 基本完整 | 虎头蛇尾 |
| 角色鲜明 | 性格立体 | 性格清晰 | 脸谱化 |
| 对话自然 | 流畅有张力 | 通顺 | 生硬刻意 |
| 情感共鸣 | 引人入胜 | 有所触动 | 平淡无奇 |
| 画面质量 | 精美专业 | 清晰正常 | 模糊粗糙 |
