# Audio Typo Checker - 音频错别字检测

检测音频读音与文案不一致的问题，帮助配音质检和字幕校对。

## 核心能力

1. **音频读音检测**
   - 配音读错字（如"鳌鱼"读成"鲨鱼"）
   - 漏读（音频中少了某些字）
   - 多读（音频中多了某些字）

2. **文案错别字检测**
   - 同音字错误
   - 形近字错误

3. **多音字读音提醒**
   - 自动检测文案中的多音字
   - 提醒配音师注意正确读音
   - 示例：镇北堡的"堡"应读bǔ（地名），而非bǎo（堡垒）
   - 内置80+常见易错多音字词库

## 执行流程

### 1. 音频语音识别

使用 `audios_understand` 工具获取音频内容：
- 调用 audios_understand，prompt 设置为"请完整转录这段音频的全部内容"

### 2. 对比分析

调用 `scripts/check_typo.py` 中的函数进行对比：
```python
from check_typo import check_and_generate_marked_doc

report, output_path = check_and_generate_marked_doc(
    script_text=文案文本,
    asr_text=ASR识别结果,
    output_dir='./output',
    original_filename='原始文件名.docx'
)
```

### 3. 输出结果

- **检测报告**：Markdown 格式，详细列出各类问题
- **标红 Word 文档**：错误文字用红色加粗显示，保留原文标点和段落格式

## 输出示例

```

============================================================
配音错误：2 处
发音差异：1 处

❌ "鳌鱼" 读成了 "鲨鱼"（语义变化大）

【多音字读音提醒】
🔔 "镇北堡"中的"堡"应读bǔ，易误读为bǎo
============================================================
```
