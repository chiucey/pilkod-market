# IT之家新闻聚合与报道生成

## 功能概述

本技能从IT之家热榜和滚动新闻页面抓取数据，提取热度最高的新闻，并自动生成结构化的新闻报道文章。

## 工作流程

### 步骤 1：数据采集

使用 `mcp__matrix__batch_web_search` 工具搜索IT之家热门新闻：

```
搜索关键词：IT之家 热度最高 新闻 + 当前日期
备用关键词：ithome.com 热门新闻 排行
```

### 步骤 2：页面内容提取

并行访问以下页面获取详细数据：

1. **热榜日榜**：`https://m.ithome.com/rankm/`
2. **最新滚动新闻**：`https://www.ithome.com/list/`

使用 `mcp__matrix__extract_content_from_websites` 工具提取：
- 热度排名数据
- 新闻标题和链接
- 评论数和热度指数
- 发布时间

### 步骤 3：数据筛选

按照以下规则筛选热度最高的10条新闻：

| 筛选条件 | 说明 |
|---------|------|
| 时间范围 | 最近12-24小时内的新闻 |
| 热度排序 | 按IT之家热度指数从高到低排列 |
| 内容去重 | 合并同一事件的多篇报道 |
| 质量过滤 | 排除广告、软文类内容 |

### 步骤 4：新闻报道生成

基于提取的新闻数据，按以下结构生成报道：

```
1. 标题：使用事件核心内容 + 日期
2. 导语：概括今日最重要新闻事件（50-100字）
3. 主体内容：
   - 每条新闻独立成段
   - 按热度从高到低排列
   - 添加背景说明和行业影响分析
4. 结语：总结要点 + 来源说明
```

### 步骤 5：输出格式

最终输出包含：

1. **热榜汇总表**：Markdown格式的排名表格
2. **热点分析**：3-5句话的趋势总结
3. **完整报道文章**：可直接发布的长文
4. **数据来源标注**：IT之家链接和时间戳

## 注意事项

1. **时效性**：新闻数据必须使用当天最新抓取的结果
2. **准确性**：热度数据直接引用IT之家官方排名，不自行计算
3. **完整性**：对于重大新闻，可以补充相关的行业背景信息
4. **版权合规**：报道仅用于信息整理，不复制原文超过必要范围
