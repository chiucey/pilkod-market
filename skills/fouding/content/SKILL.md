## 否定观点答题框架

**五段式结构**:开场白 → 原因 → 影响 → 措施 → 金句

### 框架详解

1. **板块零·开场白(粗体)**:表明对该现象的基本态度(普通字体加下划线)
    - 开场白:(粗体)→ 核心事件句 + 态度句(弹药库下划线)
2. **板块一·原因分析**:分析产生该现象的主要原因
   - 过渡句(弹药库下划线)
   - 每个原因:单点要点标题(粗体)→ 句号 → 扩展解释(普通)
3. **板块二·影响分析**:阐述该现象带来的负面影响
   - 过渡句(弹药库下划线)
   - 每个影响:单点要点标题(粗体)→ 句号 → 扩展解释(普通)
4. **板块三·措施建议**:提出改进的对策建议
   - 金句(民有所呼,我有所应。)(弹药库下划线)
   - 每个措施:单点要点标题(粗体)→ 句号 → 扩展解释(普通)
5. **板块四·金句升华**:用一句有力的话收尾(弹药库下划线)

### 单点扩展标准格式

```
一是[单点要点标题]。(粗体)
[扩展解释内容,40-50字]。(普通)
```

**示例**:
```
一是开发商采取饥饿营销策略。(粗体)

```

## 弹药库句式

### 开场白公式
小[主题]连着[对象]的大利益。[核心事件],我认为这种做法是**不妥当的/不可取的**,下面,我谈谈几点看法。

**排版**:开场白:(标题粗体)开场白整体**加下划线**(普通字体,不加粗)

### 原因分析句式
首先,让我们来分析一下,为什么会发生【高度概括的题干现象】现象/做法/问题/事件/做法/行为/情况/热点呢?我想,一方面是【政府部门监督管理不力】。(弹药库-下划线)

**⚠️ 核心规则**:
- 板块一过渡句后,**直接用"我想,一方面是【】"输出第一个原因,不再说"一是"**
- 后续原因用"此外,还有【】"、"再者,【】"连接
- 【】内填入弹药库固定原因词

**❌ 错误示例**:
> 我想,一方面是。
> 一是相关部门监督管理不力。

**✅ 正确示例**:
> 我想,一方面是**【政府部门监督管理不力】**。
> 我想,另一方面是**【思想观念偏差】**。

### 影响分析句式
其次,这种现象\做法损害群众的切身利益;**另一方面**,带来不良的社会风气,群众满意度下降,影响相关部门在群众心目中的口碑。

### 措施建议句式
"民有所呼,我有所应。"我想,不妨从以下三个【层面/维度/角度/方向/路径/抓手】加以改进:一是...[措施一];二是...[措施二];三是...[措施三]。(弹药库-下划线)

**替换词**:
- 层面、维度、角度、方向、路径、抓手
- 切口、着重点、突破口、着力点、切入点、关键点

### 金句库

**通用金句**:
- "知责任千钧之重,担责任万分之实。"
- "人民有信仰,国家有力量,民族有希望。"
-民有所呼,我有所应。

**否定观点专用金句**:
- "只有正视问题,才能解决问题;只有直面矛盾,才能化解矛盾。"
- "问题面前不回避,压力面前不躲闪,困难面前不推诿。"

## 扩展解释标准

### 基本要求
- **字数**:40-50字
- **风格**:政策类官方语言(民生类可接地气)
- **位置**:单点要点标题后的具体说明

---

### ⚠️ 联想要点格式(必须遵守)

**【核心规则】联想要点分三行:原因/影响/建议**

**格式**:每行`主体A:要点1、要点2;主体B:要点3、要点4`

**正确示例**:
```
联想要点:(粗体)
原因(粗体):开发商:饥饿营销、捂盘惜售;购房者:恐慌心理、跟风购买;中介:虚假宣传、哄抬价格(普通字体)
影响(粗体):扰乱市场秩序;加剧购房焦虑;滋生投机行为;损害消费者权益(普通字体)
建议(粗体):开发商:诚信定价、公开透明;监管部门:加强监管、动态监测;购房者:理性购房、增强辨别(普通字体)
```

**格式要点**:
1. 分三行:**原因、影响、建议**(标题:粗体)
2. 每行先写主体维度,主体后用冒号
3. 同一主体的多个要点用顿号或逗号分隔
4. 不同主体之间用分号分隔

**错误示例**(❌禁用):
```
原因:开发商饥饿营销;购房者担心错过低价
```

---

### ⚠️ 单点扩展格式(必须遵守)

**格式**:一行
- 第1行:`单点要点标题。`(粗体)`扩展解释内容`(普通字体)

**正确示例**:
> 一是开发商采取饥饿营销策略。(粗体)开发商为了获取更多利益,采取不正常的销售手段,人为制造紧迫感,导致购房者产生"不买就没了"的恐慌心理。(普通)

### 三种扩展方法

#### 1. 因果逻辑法
**公式**:原因→结果 或 结果←原因
**适用**:分析原因/影响类要点

**例句**:
- "开发商为了获取更多利益,采取不正常的销售手段,人为制造紧迫感。"
- "如果任由这种现象发展,将会造成市场秩序混乱,损害消费者权益。"

#### 2. 具体化法
**公式**:主体+行为+对象+效果
**适用**:措施建议类要点

**例句**:
- "监管部门应加强对房地产市场的动态监测,严厉打击虚假宣传行为。"
- "通过加强执法,确保房地产市场平稳健康发展。"

#### 3. 举例法
**公式**:比如/以...为例/在...地方
**适用**:增强说服力

**例句**:
- "比如在部分城市,已经开展专项整治行动,取得了明显成效。"
- "以某地为例,通过约谈房企负责人,有效规范了销售行为。"

---

### 扩展解释模板

**原因扩展模板**:
> [主体]为了[目的],采取[手段],导致[结果]。

**影响扩展模板**:
> [行为]破坏了[秩序],损害了[对象]的[权益],不利于[正面效果]。

**措施扩展模板**:
> 民有所呼,我有所应。[主体]应当[措施],通过[方式],确保[效果]。
