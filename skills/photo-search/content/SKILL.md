# Photo Search Agent - 照片查询智能体

## 1. 技能概述

照片查询智能体通过自然语言描述（包括语音转文字）解析用户想要查找的照片特征，利用AI视觉理解能力在本地设备照片库中精准定位匹配照片。

## 2. 核心能力

### 2.1 输入方式
- **语音输入**：支持语音描述转文字
- **手动输入**：键盘输入自然语言描述

### 2.2 特征解析
智能解析照片特征的多个维度：
- **时间特征**：年份、月份、季节、特殊日期
- **地点特征**：城市、国家、具体场所（如"大都会博物馆"）
- **人物特征**：人数、外貌描述、关系（如"和朋友"、"全家福"）
- **物品特征**：具体物品、艺术作品（如"梵高自画像"）
- **事件特征**：活动类型、节日庆典

### 2.3 搜索策略
1. **语义理解**：使用自然语言处理理解用户描述意图
2. **多维匹配**：组合时间+地点+人物+物品多维度匹配
3. **模糊搜索**：支持语义相似的关键词扩展
4. **结果排序**：按相关性得分排序返回

### 2.4 输出格式
返回匹配照片的：
- 文件路径/引用
- 缩略图预览
- 匹配度评分
- 匹配特征说明

## 3. 工作流程

### 3.1 接收输入
```
用户输入 → 语音转文字（可选）→ 原始描述文本
```

### 3.2 特征提取
```
描述文本 → AI解析 → 结构化特征
{
  "time": ["2025"],
  "location": ["美国", "大都会博物馆"],
  "people": [],
  "objects": ["梵高自画像"],
  "event": "合影"
}
```

### 3.3 搜索执行
```
结构化特征 → 搜索引擎 → 候选照片列表
```

### 3.4 结果展示
```
候选照片 → 相关性排序 → 格式化输出 → 用户确认
```

## 4. 使用示例

### 示例1：语音输入
```
用户（语音）："帮我找去年夏天在海边拍的照片"
系统处理：
  1. 语音转文字 → "去年夏天在海边拍的照片"
  2. 特征提取 → time=["去年夏天"], location=["海边"]
  3. 搜索匹配 → 返回海边夏季度假照片
```

### 示例2：详细描述
```
用户："2025年在美国大都会博物馆与梵高自画像的合影"
特征解析：
  - time: 2025年
  - location: 美国大都会博物馆
  - object: 梵高自画像
  - event: 合影
搜索结果：
  - 照片1 (匹配度92%): /photos/2025_met_trip.jpg
  - 照片2 (匹配度78%): /photos/vacation/museum_visit.png
```

### 示例3：模糊搜索
```
用户："找个有猫的照片"
特征解析：
  - object: 猫
  - context: 包含猫的任何照片
搜索结果：返回所有包含猫科动物的照片
```

## 5. 技术实现

### 5.1 核心模块
- **InputHandler**：处理语音/文本输入
- **FeatureExtractor**：使用NLP/LLM解析照片特征
- **PhotoMatcher**：多维特征匹配引擎
- **ResultFormatter**：结果格式化和展示

### 5.2 数据流
```
用户输入 → InputHandler → FeatureExtractor → PhotoMatcher → ResultFormatter → 输出
                              ↓
                        照片库（元数据+缩略图）
```

### 5.3 兼容性
- 支持 iOS 照片库元数据
- 支持 Android 照片库
- 支持本地文件系统照片
- 支持云端照片服务

## 6. 错误处理

| 场景 | 处理方式 |
|------|----------|
| 无匹配照片 | "未找到符合条件的照片，尝试放宽搜索条件？"|
| 输入描述不清 | "请提供更多细节，如时间、地点或照片中的主要物体" |
| 照片库不可访问 | "无法访问照片库，请检查权限设置" |
| 语音识别失败 | "语音识别失败，请手动输入描述" |

## 7. 扩展能力

### 7.1 高级搜索
- 以图搜图：上传参考图片搜索相似照片
- 时间轴浏览：按时间线展示照片
- 人脸聚类：基于人物分组照片

### 7.2 智能推荐
- 回忆功能：智能推荐同地点/同人物的历史照片
- 精彩时刻：自动识别高质量照片
- 相似照片：发现构图相似的照片组

## 8. 限制与注意事项

1. **隐私保护**：本地处理，照片不上传云端
2. **权限要求**：需要照片库读取权限
3. **搜索精度**：依赖照片元数据完整性
4. **处理速度**：首次搜索需建立索引，后续加速
