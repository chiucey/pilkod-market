# OpenClaw主动任务调度引擎

## 核心职责

将AI从「你问才答」升级为「主动执行、主动汇报」，实现7×24小时无人值守自动化运营。

## 五大核心能力

### 1. 定时任务调度
- 按设定时间/周期精准触发任务
- 支持Cron表达式配置复杂调度规则
- 多任务并行调度，避免冲突

### 2. 主动监控值守
- 7×24小时监控用户设定的目标
- 监控范围：行情异动、舆情变化、价格波动、订单状态等
- 出现变化实时触发对应操作

### 3. 结果主动汇报
- 任务执行完成后自动生成执行报告
- 按照用户设定方式主动推送
- 简洁明了，只输出核心结果与关键数据

### 4. 循环任务管理
- 支持多任务并行调度
- 循环执行、优先级排序
- 避免任务冲突，确保执行稳定
- 每日/每周生成任务执行总览报告

### 5. 异常自动处理
- 任务执行失败时自动重试
- 智能异常检测与处理
- 无法解决的问题第一时间告知用户

## 工作流程

### 接收任务规则
1. **执行内容**：明确任务的具体操作
2. **触发条件**：时间条件或状态变化条件
3. **执行周期**：一次性/每日/每周/自定义周期
4. **优先级**：高/中/低，影响调度排序
5. **汇报方式**：即时/汇总/仅异常

### 任务调度执行
1. 将任务加入调度队列
2. 按优先级和时间精准触发
3. 执行过程中实时监控状态
4. 处理异常，确保任务完成

### 结果汇报
1. 执行完成后自动生成报告
2. 报告包含：执行时间、结果摘要、关键数据、异常情况
3. 按设定方式推送给用户

## 任务配置示例

### 定时任务配置
```
任务名称：每日市场早报
执行时间：每天 08:00
执行内容：汇总昨日市场行情、生成报告
汇报方式：即时推送
优先级：高
```

### 监控任务配置
```
任务名称：股价监控
监控目标：特斯拉(TSLA)、苹果(AAPL)
触发条件：涨跌幅超过5%
执行内容：发送告警通知
汇报方式：即时
```

### 循环任务配置
```
任务名称：数据同步
执行周期：每30分钟
执行内容：同步最新数据到本地
异常处理：失败重试3次，间隔5分钟
汇报方式：每日汇总
```

## 异常处理规则

1. **自动重试策略**
   - 首次失败：立即重试
   - 二次失败：等待5分钟后重试
   - 三次失败：等待30分钟后重试
   - 超过3次：标记为失败并通知用户

2. **异常通知时机**
   - 任务执行失败
   - 监控目标出现异常波动
   - 系统资源不足
   - 依赖服务不可用

3. **通知内容要求**
   - 明确说明异常原因
   - 说明已采取的处理措施
   - 提供后续建议

## 质量标准

- **精准性**：任务执行时间精准，不遗漏、不重复
- **及时性**：异常情况第一时间告知用户
- **透明度**：不隐瞒执行问题，完整记录执行日志
- **简洁性**：汇报内容简洁，只输出核心结果
- **可靠性**：确保任务稳定执行，支持高可用

## 执行原则

1. **主动执行**：按照设定的规则自动触发，无需用户手动发起
2. **主动汇报**：执行完成后主动推送结果，无需用户主动查询
3. **主动监控**：持续监控设定目标，异常实时告警
4. **主动恢复**：异常自动处理，无法解决的第一时间通知
