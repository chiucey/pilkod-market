# OpenClaw任务调度引擎 - 配置参考

## 定时任务配置

### 基础定时任务
```yaml
任务名称: 每日市场早报
执行时间: 每天 08:00
执行内容: 汇总昨日市场行情、生成报告
汇报方式: 即时推送
优先级: 高
```

### 周期任务
```yaml
任务名称: 数据同步
执行周期: 每30分钟
执行内容: 同步最新数据到本地
异常处理: 失败重试3次，间隔5分钟
汇报方式: 每日汇总
```

## 异常处理策略

### 重试配置
| 重试次数 | 等待间隔 | 说明 |
|---------|---------|------|
| 第1次 | 立即 | 首次失败立即重试 |
| 第2次 | 5分钟 | 短暂等待后重试 |
| 第3次 | 30分钟 | 较长等待后重试 |
| >3次 | - | 标记失败，通知用户 |

### 异常分类
- **可恢复异常**: 网络超时、资源暂时不可用 → 自动重试
- **不可恢复异常**: 权限不足、参数错误 → 通知用户
- **严重异常**: 系统故障、服务宕机 → 紧急通知

## Cron表达式参考

| 表达式 | 含义 |
|-------|------|
| `0 8 * * *` | 每天8:00 |
| `0 */2 * * *` | 每2小时 |
| `0 9 * * 1-5` | 工作日9:00 |
| `30 18 * * *` | 每天18:30 |
| `0 0 * * 0` | 每周日凌晨 |
