# AI知识库管理技能

## 能力概述

本技能为MaxClaw提供私有化AI知识库全生命周期管理能力，支持知识入库、语义检索、知识管理、关联分析和智能问答。所有知识加密存储，仅用户本人可访问。

## 核心功能模块

### 1. 知识入库

**支持格式：**
- 纯文本内容
- PDF/Word/Excel文档
- 图片（OCR文字识别）
- 音频文件（语音转文字）
- 网页链接内容抓取

**入库流程：**
1. 接收用户提交的知识内容（支持多格式）
2. 内容预处理：格式转换、编码统一、噪声去除
3. 核心知识点提取：自动识别标题、关键段落、核心概念
4. 分类标注：按用户设定的分类规则归类（如"科研/工作/学习/生活"）
5. 元数据标记：入库时间、来源URL、作者、关键词标签
6. 加密存储：AES-256加密后存入私有知识库
7. 返回入库结果：成功/失败条数、分配的知识ID

**触发指令示例：**
- "将这段文本入库到科研分类"
- "上传这份PDF到工作知识库"
- "扫描这张图片提取文字"
- "转录这段音频内容"

---

### 2. 语义检索

**检索模式：**

**模式一：关键词检索**
- 用户输入关键词，系统匹配标题/正文/标签
- 支持布尔逻辑（AND/OR/NOT）
- 支持通配符模糊匹配

**模式二：自然语言检索**
- 用户使用自然语言提问
- 示例："告诉我关于新能源电池的知识点"
- 系统理解语义意图，返回相关知识

**模式三：相似性检索**
- 用户上传文档或粘贴文本片段
- 系统在大模型编码空间计算语义相似度
- 返回最相似的已有知识条目

**检索结果排序：**
- 相关性得分（默认优先）
- 时效性（较新知识优先）
- 重要性评分（访问频率/引用次数）
- 支持按分类/时间/来源筛选

**触发指令示例：**
- "检索新能源相关的知识"
- "找找关于项目管理的资料"
- "上传文档找相似知识"
- "最近入库的人工智能知识有哪些"

---

### 3. 知识管理

**知识更新：**
- 修改知识内容、标题、分类、标签
- 版本记录：保留历史版本，支持回滚
- 批量更新：按条件筛选后统一修改分类

**知识删除：**
- 单条删除：指定知识ID删除
- 批量删除：按条件筛选后批量移除
- 回收站机制：删除内容保留30天，可恢复
- 彻底删除：清空回收站后永久移除

**知识归档：**
- 将低频访问/过期知识移入归档库
- 归档知识仍可检索，但降低索引权重
- 支持批量归档（如"归档3个月前未访问的知识"）

**触发指令示例：**
- "更新知识ID-123的内容"
- "删除这条过期的政策文件"
- "批量将科研分类的知识归档"
- "恢复上周删除的那条知识"

---

### 4. 关联分析（知识图谱）

**自动关联识别：**
- 基于语义相似度识别知识点之间的关联
- 实体识别：自动标注人名/机构名/概念名
- 关系抽取：识别"属于"、"包含"、"对立"、"因果"等关系

**图谱可视化：**
- 生成可拖拽调整的知识图谱
- 节点代表知识点，边代表关联关系
- 支持按分类/时间/重要性筛选显示
- 支持导出为PNG/SVG图片

**典型关联路径示例：**
- "新能源电池 → 锂电池 → 正极材料 → 钴酸锂"
- "机器学习 → 深度学习 → CNN → 图像识别"

**触发指令示例：**
- "构建人工智能领域的知识图谱"
- "显示知识A的所有关联知识"
- "找出与这个概念相关的知识点"
- "导出知识图谱为图片"

### 5. 智能问答

**基于知识库的精准问答：**
- 理解用户自然语言问题
- 在知识库中检索相关知识点
- 综合多个知识点生成完整答案
- 标注答案来源（对应的知识ID）

**追问式问答：**
- 支持多轮对话上下文理解
- 示例对话：
  - 用户："什么是神经网络？"
  - AI回答后，用户追问："这个知识点的应用场景有哪些？"
  - AI结合"神经网络的应用场景"相关知识继续回答

**知识缺口提示：**
- 当知识库无法完全回答时，提示用户补充相关知识
- 记录高频但无答案的问题，供用户后续补充

**触发指令示例：**
- "基于我的知识库回答：如何提升团队协作效率"
- "知识库里有关于XXX的内容吗"
- "我之前存储的关于YYY的知识讲了什么"

---

### 6. 知识库备份与恢复

**自动备份：**
- 每日凌晨自动全量备份
- 增量备份：每次操作后记录变更日志
- 备份文件AES-256加密压缩

**手动备份：**
- 用户可手动触发即时备份
- 支持导出为加密压缩包下载

**版本恢复：**
- 支持恢复到指定日期的备份版本
- 恢复前预览备份内容
- 支持选择性恢复（只恢复某分类/时间段）

**触发指令示例：**
- "立即备份我的知识库"
- "恢复到昨天的版本"
- "查看可用的备份历史"

---

### 7. 权限管理与安全

**访问控制：**
- 知识库默认为用户私有
- 可设置共享权限给指定人员（输入邮箱/ID）
- 共享级别：只读/可添加/可编辑

**操作审计：**
- 记录所有知识库操作日志
- 日志包含：操作人/时间/操作类型/目标内容
- 支持导出操作审计报告

**敏感内容过滤：**
- 入库时自动检测敏感词
- 包含敏感内容的知识需用户确认后才入库
- 支持自定义敏感词库

**触发指令示例：**
- "查看我的知识库操作日志"
- "设置知识ID-456为共享给张三"
- "添加新的敏感词"

## 健康度评分体系

系统自动评估知识库健康状态，评分维度：

| 维度 | 权重 | 评分标准 |
|------|------|----------|
| 更新频率 | 20% | 30天内有更新得满分 |
| 内容完整性 | 25% | 知识点信息完整度高 |
| 检索命中率 | 25% | 高频检索词有对应答案 |
| 图谱密度 | 15% | 知识间关联丰富度 |
| 存储效率 | 15% | 无冗余/重复内容 |

**触发指令示例：**
- "知识库健康度评分是多少"
- "哪些方面需要改进"
- "提示我补充高频检索但缺失的知识"

## 安全规则

| 规则 | 说明 |
|------|------|
| 数据隔离 | 用户数据严格隔离，不同用户数据物理分离 |
| 禁止外部调用 | 知识库操作不调用外部API，数据不出本地 |
| 加密存储 | 所有知识内容AES-256加密存储 |
| 访问控制 | 严格的身份验证和权限校验 |
| 操作追溯 | 所有操作记录完整日志，支持审计 |
| 敏感过滤 | 入库前敏感内容自动过滤 |

## 错误处理

| 错误类型 | 处理方式 |
|----------|----------|
| 入库失败 | 提示具体原因（格式不支持/内容违规），提供修改建议 |
| 检索无结果 | 建议调整关键词，或引导用户入库相关知识 |
| 权限不足 | 提示需要更高权限，列出可执行的操作 |
| 存储满 | 提示清理低频知识或归档旧内容 |
| 加密解密失败 | 记录日志，提示联系技术支持 |
