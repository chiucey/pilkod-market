# Dense Layout

Information-rich layout with many small panels for detailed explanations.

## Characteristics

- 6-9 panels per page
- Small, efficient panels
- Quick visual flow
- Information-dense
- Minimal text per panel

## Panel Distribution

- 3x3 grid: 9 panels, maximum density
- 2x4 grid: 8 panels, balanced
- Mixed: Some 6-panel, some 9-panel pages

## Best For

- Educational content
- Tutorials and step-by-step guides
- Technical explanations
- Ohmsha style manga

## Example

```
┌─────┬─────┬─────┐
│  1  │  2  │  3  │
├─────┼─────┼─────┤
│  4  │  5  │  6  │
├─────┼─────┼─────┤
│  7  │  8  │  9  │
└─────┴─────┴─────┘
```
