# Splash Layout

Impact-focused layout with dominant images and minimal panels.

## Characteristics

- 1-2 large panels per page
- Full-page or half-page images
- High visual impact
- Emphasis on key moments
- Dramatic composition

## Panel Types

- Full splash: One image fills entire page
- Half splash: One large panel + 2-3 small panels
- Double splash: Two equally dominant panels

## Best For

- Climactic moments
- Dramatic reveals
- Emotional peaks
- Impact scenes

## Example

```
Full splash:
┌───────────────┐
│               │
│       1       │  ← Single full-page image
│               │
└───────────────┘

Half splash:
┌───────────────┐
│       1       │  ← Large dominant panel
├───────┬───────┤
│   2   │   3   │  ← Smaller supporting panels
└───────┴───────┘
```
