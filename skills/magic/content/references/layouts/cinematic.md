# Cinematic Layout

Film-inspired layout with emphasis on atmosphere and visual impact.

## Characteristics

- 2-4 panels per page
- Variable panel sizes (some wide, some tall)
- Wide horizontal panels for establishing shots
- Full-bleed panels for impact
- Emphasis on mood and composition

## Panel Types

- Splash panels: Full or half-page dramatic images
- Wide panels: Cinematic horizontal framing
- Vertical panels: Emphasizing height/distance
-Inset panels: Overlapping for depth

## Best For

- Dramatic narratives
- Emotional moments
- Atmospheric storytelling
- Film-like pacing

## Example

```
┌───────────────┐  ← Wide panel (establishing shot)
│       1       │
├───────┬───────┤
│   2   │   3   │
└───────┴───────┘
┌───────────────┐  ← Wide panel (climactic moment)
│       4       │
└───────────────┘
```
