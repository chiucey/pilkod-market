# Webtoon Layout

Vertical scrolling format optimized for digital reading.

## Characteristics

- Vertical canvas (scrolling)
- Variable panel heights
- Consistent panel width
- No fixed page breaks
- Optimized for mobile reading

## Panel Structure

- Panels stack vertically
- Height varies by content needs
- Some panels span full width (emphasis)
- Some panels are narrow (quick beats)
- Gutter space for reading flow

## Best For

- Digital-first content
- Mobile reading
- Tutorials (Ohmsha style)
- Step-by-step explanations
- Vertical narrative flow

## Example

```
┌──────────────┐
│      1       │  ← Tall establishing panel
├──────────────┤
│      2       │  ← Medium panel
├──────────────┤
│   3a │   3b  │  ← Split panel (side-by-side)
├──────────────┤
│      4       │  ← Wide emphasis panel
├──────────────┤
│      5       │  ← Short panel (quick beat)
└──────────────┘
```

## Special Considerations

- **Scroll pace**: Vary panel height for pacing
- **Breaks**: Use wider gaps for scene/time changes
- **Reveal**: Tall panels can hide information below the fold
- **Text**: Keep text minimal and readable on small screens
- **Gestures**: Swipe up for next panel (natural flow)
