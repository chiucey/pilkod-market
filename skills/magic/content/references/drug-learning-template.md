# Drug Learning Template (药物学习通用模板)

Standardized 5-section framework for pharmacology comics. Every drug follows the same structure, ensuring systematic and complete learning.

## Core Principle

**One drug, one comic, five steps — never miss a dimension.**

每种药物漫画都严格遵循五步结构，读者形成固定学习节奏，先知道"这是什么药"，再知道"怎么起效"，然后"治什么病"，最后"怕什么、忌什么"。

## Five-Section Structure

| Section | Chinese | Core Question | Page Count | Wuxia Metaphor |
|---------|---------|---------------|------------|----------------|
| 1. Classification | 分类 | 这味药属于哪个门派？ | 1-2 pages | 门派归属 |
| 2. Mechanism of Action | 作用机制 | 这味药如何制敌？ | 2-4 pages | 武功招式与内功心法 |
| 3. Indications | 适应症 | 这味药克哪些敌？ | 1-2 pages | 对阵的敌人与战场 |
| 4. Adverse Reactions | 不良反应 | 这味药有何反噬？ | 1-2 pages | 走火入魔与反噬之险 |
| 5. Contraindications | 禁忌症 | 谁绝不可用此药？ | 1-2 pages | 禁地与不可触碰之人 |

**Total: 8-12 pages** (adjustable based on drug complexity)

## Per-Section Design Guide

### Section 1: 分类 (Classification)

**Narrative Purpose**: Establish the drug's identity and lineage in the pharmacology world.

**Must Cover**:
- Drug class and subclass (e.g., 青蒿素 → 倍半萜内酯类 → 抗疟药)
- Related drugs in the same class (兄弟姐妹)
- Key distinguishing features of this class
- Position in the therapeutic landscape

**Visual Design (Wuxia)**:
- **Scene**: 门派大殿 or 宗门卷轴
- **Action**: 主角踏入某门派，展示门派旗帜与座次
- **Metaphor**: 药物分类 = 江湖门派谱系
- **Key Visual**: 分类树/门派图，标注本药所在位置

**Example Panel Flow**:
1. 侠客问路："此药归属何门何派？"
2. 展开门派谱系卷轴
3. 聚焦到本药的门派位置，标出同类药物
4. 旁白点出本门派的共同特征

---

### Section 2: 作用机制 (Mechanism of Action)

**Narrative Purpose**: The most critical section — show HOW the drug works at molecular/cellular level.

**Must Cover**:
- Molecular target (受体、酶、离子通道等)
- Binding/interaction process
- Signal cascade or downstream effects
- Why this mechanism produces the therapeutic effect
- Key structure-activity relationship (e.g., 过氧桥键 for 青蒿素)

**Visual Design (Wuxia)**:
- **Scene**: 细胞江湖 / 分子战场
- **Action**: 药侠施展招式，与靶点过招
- **Metaphor**: 
  - 作用靶点 = 敌方命门
  - 药物-受体结合 = 招式锁喉
  - 信号通路 = 内功运行路线
  - 结构-活性关系 = 招式精髓所在
- **Key Visual**: 机制示意图（可抽象为武功路线图）

**Example Panel Flow**:
1. 药侠深入敌营（进入体内/细胞）
2. 发现命门（识别靶点）
3. 施展绝技（药物与靶点结合/反应）
4. 内力奔涌（信号传导/级联反应）
5. 敌人溃败（产生药理效应）
6. 旁白：关键结构是制胜核心

**Important**: This section gets the most pages (2-4) because mechanism is the hardest to memorize and most important to understand.

---

### Section 3: 适应症 (Indications)

**Narrative Purpose**: Show what diseases/conditions this drug treats — where it wins.

**Must Cover**:
- Primary indications (首选/主要适应症)
- Secondary/off-label uses
- Special populations or situations where it excels
- Comparison with alternatives if relevant (为什么选它不选别的)

**Visual Design (Wuxia)**:
- **Scene**: 战场 / 对决擂台
- **Action**: 药侠对阵各类敌人（疾病），展示胜绩
- **Metaphor**:
  - 疾病 = 各路魔头/敌将
  - 适应症 = 药侠能击败的敌人名单
  - 首选适应症 = 药侠的成名之战
- **Key Visual**: 战绩榜/克敌图

**Example Panel Flow**:
1. 药侠来到战场，面对不同敌人
2. 对A敌：一招制胜（首选适应症）
3. 对B敌：也可取胜但非最佳（次选适应症）
4. 旁白：什么战场该派此药侠出战

---

### Section 4: 不良反应 (Adverse Reactions)

**Narrative Purpose**: Show what harm the drug can cause — every sword has two edges.

**Must Cover**:
- Common adverse reactions (常见)
- Serious/rare adverse reactions (严重/罕见)
- Mechanism of key adverse reactions (why they happen)
- Dose-dependency relationship if applicable
- Management strategies if notable

**Visual Design (Wuxia)**:
- **Scene**: 修炼密室 / 走火入魔
- **Action**: 药侠用力过猛或招式反噬，自身受伤
- **Metaphor**:
  - 不良反应 = 走火入魔/内力反噬
  - 常见不良反应 = 轻微岔气
  - 严重不良反应 = 走火入魔
  - 机制相关不良反应 = 招式双刃剑（治敌原理同时伤己）
- **Key Visual**: 反噬图谱，标注常见vs严重

**Example Panel Flow**:
1. 药侠施展绝技后，察觉体内异样
2. 轻则：手抖、气乱（常见不良反应）
3. 重则：经脉逆行、吐血（严重不良反应）
4. 旁白解释：为何会产生这些反噬（机制联系）
5. 提示：如何化解或减轻反噬

---

### Section 5: 禁忌症 (Contraindications)

**Narrative Purpose**: Show who must NEVER use this drug — the forbidden zones.

**Must Cover**:
- Absolute contraindications (绝对禁忌)
- Relative contraindications (相对禁忌)
- Drug interactions that are contraindicated (药物相互作用禁忌)
- Why these are contraindicated (brief mechanistic explanation)
- Special populations (pregnancy, pediatric, renal/hepatic impairment)

**Visual Design (Wuxia)**:
- **Scene**: 禁地 / 封印之门
- **Action**: 药侠面对禁地警示，不可踏入
- **Metaphor**:
  - 绝对禁忌 = 生死禁地，踏入必亡
  - 相对禁忌 = 险地，需高手护持方可尝试
  - 药物相互作用 = 两股内力冲突，走火入魔
  - 特殊人群 = 体质特殊者不可修炼此功
- **Key Visual**: 禁忌之门/封印阵法，标注各禁忌项

**Example Panel Flow**:
1. 药侠行至一处，前方竖起"禁地"牌
2. 绝对禁忌：此门绝不可入（说明原因）
3. 相对禁忌：此路极险，慎入（说明条件）
4. 药物冲突：若同时修炼他功，内力冲突（药物相互作用）
5. 特殊体质者：孕者、幼者、体虚者不可尝试
6. 总结：牢记禁忌，方能安全用药

---

## Cover Page Design

**Must include**:
- 药物名称（中英文）
- 五步结构预告（分类→机制→适应症→不良反应→禁忌症）
- 核心视觉意象（药物的武侠形象）

**Title Format**: `[药物名]：[一句话武侠化定位]`

Example: `青蒿素：疟疾克星的过氧绝杀`

## Memory Mnemonic System (记忆口诀)

Each drug comic should include a 5-line mnemonic that maps to the 5 sections:

```
[分类句] - 门派归宗
[机制句] - 制敌心法
[适应句] - 克敌战绩
[反噬句] - 走火之险
[禁忌句] - 禁地之门
```

Example for 青蒿素:
```
倍半萜内酯抗疟派 → 过氧断桥自由基 → 红内期疟原虫灭 → 罕见神经毒耳毒 → 孕初忌用防致畸
```

## Style Recommendation for Drug Content

**Default: wuxia + splash**

| Drug Content Signal | Style | Layout | Reason |
|--------------------|-------|--------|--------|
| 药物/药理/药名 | wuxia | splash | 武侠隐喻天然适配药理叙事 |
| 特殊要求 | 可覆盖 | 可覆盖 | 用户指定优先 |

**Why Wuxia**:
- 药物分类 → 门派归属（天然映射）
- 作用机制 → 武功招式（动作感强）
- 适应症 → 克敌战绩（战斗场景）
- 不良反应 → 走火入魔（戏剧冲突）
- 禁忌症 → 禁地封印（悬念感）

## Cross-Drug Comparison

When generating multiple drug comics in the same class, maintain:
- Same visual style across the series
- Consistent metaphor system (same 门派 uses similar visual language)
- Comparable page structure for easy cross-reference
- Character design: same-class drugs share visual motifs but have distinct identities

## Usage in Workflow

When the skill detects pharmacology/drug content:
1. Auto-apply this template in Step 1 (Analysis)
2. Pre-structure storyboard around the 5 sections
3. Generate mnemonic for the summary page
4. Default to wuxia + splash style recommendation
