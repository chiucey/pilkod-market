# 自动技能路由

智能分析用户意图，自动匹配并调用最合适的技能。

## 工作流程

### 1. 意图分析

当用户发送消息时，自动执行以下分析：

```
用户消息 → 意图分类 → 技能匹配 → 自动调用
```

### 2. 意图分类矩阵

| 意图类型 | 关键词示例 | 对应技能 |
|---------|-----------|---------|
| 代码开发 | 写代码、编程、开发网站、实现功能 | `expert-skills:prd-to-prototype` 或直接开发 |
| 文档处理 | PDF、Word、Excel、PPT、转换格式 | `expert-skills:minimax-pdf` 等 |
| 图片创作 | 生成图片、画图、设计图、海报 | `expert-skills:image-creator` |
| 技能创建 | 创建技能、制作技能、编写SKILL | `expert-skills:skill-creator` |
| 数据分析 | 分析数据、统计数据、生成图表 | `expert-skills:minimax-xlsx` |
| 视频音频 | 制作视频、生成音频、配音 | `mcp__matrix__gen_videos` / `mcp__matrix__gen_audios` |
| 求职面试 | 面试、简历、求职、招聘 | 匹配求职相关技能 |
| 生活服务 | 订票、酒店、航班、天气 | 匹配生活服务技能 |

### 3. 技能匹配规则

**自动匹配条件：**
- 用户消息包含明确任务但未指定技能
- 用户发送多类型混合任务
- 用户使用自然语言描述需求

**不触发自动路由：**
- 用户已明确指定使用某个技能（如 `/skill` 命令）
- 用户只是闲聊或问候
- 用户要求查看技能列表

### 4. 执行模式

```
模式 A：单技能场景
用户: "帮我分析这份Excel数据"
自动: 分析意图 → 匹配 xlsx → 调用 expert-skills:minimax-xlsx

模式 B：多技能场景
用户: "帮我做一个产品页面，包含图片和视频"
自动: 拆分为子任务 → 分别调用对应技能

模式 C：PRD到原型场景
用户: "我想做一个电商App"
自动: 分析 → 匹配 prd-to-prototype → 调用 expert-skills:prd-to-prototype
```

### 5. 意图识别算法

**优先级判断：**
1. 显式关键词匹配（最高优先级）
2. 隐式意图推断
3. 上下文联想
4. 默认泛化处理

**关键词权重：**
- 强意图词（90-100%）：创建、开发、设计、制作、生成、分析
- 中意图词（60-89%）：帮我、写、做、处理、优化
- 弱意图词（30-59%）：想要、需要、考虑、看看

## 注意事项

- 匹配阈值：建议 60% 以上置信度才自动调用
- 不确定时：优先询问用户而非盲目调用
- 多技能组合：自动拆分复杂任务为子任务队列
- 技能链：需要多个技能时按顺序调用

## 示例触发

- ✅ 触发："帮我做一个登录页面" → 自动调用原型技能
- ✅ 触发："分析这份销售数据" → 自动调用Excel技能
- ✅ 触发："创建新技能" → 自动调用skill-creator
- ❌ 不触发："今天天气怎么样" → 仅作为闲聊处理
- ❌ 不触发："/skill list" → 用户显式命令
