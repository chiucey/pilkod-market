# 剧本拆解与分镜制作规范 (Storyboard Creator)

本 Skill 提供了将解说类剧本拆解为标准化分镜表格的完整工作流与规范。适用于历史解说、纪录片、剧情解说等需要将长段旁白转化为具体画面指令的场景。同时内置了唐、宋、元、明四朝的核心历史设定知识，以及历史剧资产可视化生成SOP，用于指导历史题材的资产卡与提示词生成。

## 核心工作流

当接收到剧本拆解与分镜制作任务时，请严格按照以下步骤执行：

1. **通读剧本与需求**：完整读取剧本内容，理解叙事结构、核心冲突与视觉基调。
2. **提取资产卡**：从剧本中提取所有需要重复使用的角色、场景、道具，建立资产库。**注意人物资产卡必须采用三视图设计。**
3. **精细拆解音频文案**：将长段旁白拆分为短句，确保画面时长能支撑解说。
4. **编写七维提示词**：为每条分镜编写结构化的视频提示词，并调取对应资产。结合历史设定知识确保服化道准确。
5. **生成分镜表格**：将数据写入标准化的 Excel 模板中（包含「分镜数据」和「资产卡」两个工作表）。

## 规范详解

### 1. 音频文案拆分规则（关键！）

**痛点**：音频文案过长会导致生成的画面时长不足以支撑解说旁白的时长。

**规则**：
- **字数限制**：每条分镜的音频文案必须控制在 **20-40字** 之间（约对应 3-6 秒的画面）。
- **长段拆分**：遇到长段旁白，必须将其拆分为多条独立的分镜。例如："三天。从断粮到崩溃，只需要三天。这就是繁华的真相。" 应当拆分为至少两条分镜，每条对应一个单一的画面动作或意象。
- **宁碎勿长**：宁可分镜条数多，绝不可单条音频过长。
- **无遗漏**：拆分后必须与原剧本逐字核对，确保解说词 **100% 无遗漏、无篡改**。

### 2. 资产卡提取与设计规范

资产卡是保证画面连贯性的核心。分为三类：角色资产、场景资产、道具资产。

**命名规范**：`资产名称-资产类型/特征`（例如：`解说员阿正-历史解说员`、`州桥夜市-夜戏`）

**人物资产卡特殊要求（强制！）**：
- **三视图排版设计**：所有人物（角色）资产卡的提示词中，**必须明确要求生成人物的三视图（正面、侧面、背面），不要单图**。
- **画风与排版描述**：必须包含以下描述："电影级写实画风，好莱坞真人影视定妆照，8k分辨率，极致细节。采用角色设计排版（Character design sheet），画面均分为三个部分：包含一张极高清晰度的面部特写照，一张全身正面站立视图，一张全身侧面站立视图。"
- **纯色/灰色影棚背景**：所有人物资产卡的提示词中，**必须明确要求使用纯色或灰色影棚背景**（例如："纯色灰色影棚背景，无杂物"）。
- **不可简化**：人物资产的描述必须详尽，包含服饰、发型、气质等细节，**严禁简化资产卡描述**。
- **示例**："男性，30-35岁，书卷气，身着深色简约中式棉麻衬衫；面容清俊，眼神深邃；**电影级写实画风，好莱坞真人影视定妆照，8k分辨率，极致细节。采用角色设计排版（Character design sheet），画面均分为三个部分：包含一张极高清晰度的面部特写照，一张全身正面站立视图，一张全身侧面站立视图。纯色灰色影棚背景，无杂物**"

**场景/道具资产卡要求**：
- 场景资产需明确时间（日戏/夜戏/黄昏）和核心光影氛围。
- 道具资产需明确材质、体量和关键细节。

### 3. 历史剧资产可视化生成SOP

在生成历史题材的人物、场景、道具提示词时，必须严格按照以下SOP执行，并参考历史设定知识库。

#### 第一步：需求确认
明确以下四个核心要素：
1. **目标朝代**（唐 / 宋 / 元 / 明）
2. **人物身份**（例如：唐朝皇帝、宋代平民男子、元代蒙古贵族女性、明代大臣）
3. **具体场合**（例如：日常燕居、大朝会、宫廷宴会、市井劳作）
4. **（可选）搜索特征/名称**

#### 第二步：定制化Prompt生成
严格依据以下格式构建提示词：

**[正向指令]**
1. **基础画质与风格**：杰作，极高分辨率，写实风格，电影级光影，准确的[朝代]中国古典美学。
2. **主体人物视觉锚点**：
   - **发型与头饰**：(例：皇帝戴黑色软脚幞头；宋代官员戴展脚幞头；元代皇后戴罟罟冠；明代男子戴网巾)
   - **服装与配饰**：(例：唐代穿圆领袍+乌皮六合靴；宋代穿直裰/褙子；元代穿纳石失金锦质孙服；明代穿有补子的官服)
   - **气质与动作**：(例：唐代叉手礼、宋代拱手作揖、明代跪拜或揖礼)
3. **场景与环境细节**：
   - **建筑特征**：(例：唐代为朱白配色、鸱尾、直棂窗；宋代为格子门窗、斗拱秀丽；明代为黄色琉璃瓦、规整院落)
   - **室内陈设与道具**：(例：唐代坐床榻、用卷轴；宋代用高桌椅、蝴蝶装书籍、建盏；明代用圈椅、青花瓷、线装书)

**[反向指令]**
**重要避坑指南（负向提示词）：**
绝对不要出现任何与本朝代不符的元素，尤其是：
- **跨朝代错误**：根据目标朝代，将严重历史错误转化为反向Prompt。(例：生成唐代画面时，写明：No 黄色琉璃瓦, No 线装书, No 高背椅, No 抱拳礼, No 程朱理学服饰。)
- **通用禁忌**：No 现代装束，No 旗袍，No 玉米辣椒等外来作物，No 超短裙，No 解剖学错误，No 手指/脚趾变形。

### 4. 七维视频提示词编写标准

每条分镜的视频提示词必须严格按照以下结构编写：

1. **调取资产**：在提示词最前方，使用 `@资产名称` 调取相关资产（可调取多个）。
2. **七维描述**：
   - `【构图运镜】`：景别（特写/近景/中景/全景/远景）与镜头运动（固定/推/拉/摇/移/叠化）。
   - `【人物/物件】`：画面主体是什么。
   - `【动作/状态】`：主体在做什么，或处于什么状态。
   - `【位置关系】`：主体在画面中的位置，以及与其他元素的空间关系。
   - `【背景环境】`：所处的具体环境。
   - `【光影氛围】`：光源方向、色调（冷/暖）、整体氛围感。
   - `【时间】`：白天/夜晚/黄昏/清晨等。
3. **画质后缀**：在最后加上英文画质后缀，如 `(Professional Shot, best quality, highres, masterpiece:1.2, ultra-detailed, [核心意境词])`。

### 5. 历史设定知识库（用于指导提示词生成）

#### 唐代
- **人物服饰**：
  - **皇帝/官员**：常服为圆领右衽袍衫（皇帝赭黄，官员按品色紫、绯、绿、青），戴黑色幞头（软裹巾子），穿乌皮六合靴。
  - **女性**：高髻（半翻髻、倭堕髻等），穿衫/襦与高腰长裙（系带在胸下，非腋下），必配披帛。妆容繁复（花钿、面靥等）。
  - **平民**：交领/圆领粗布短衣，麻布幞头或椎髻，草鞋/麻鞋。
- **场景建筑**：庑殿顶/歇山顶，出檐深远，斗拱宏大。屋脊有鸱尾。直棂窗。朱白配色（红柱白墙）。室内多铺方砖/木地板，家具以壶门榻、矮案为主。
- **生活习惯**：主流行礼为**叉手礼**（非抱拳礼）。主流坐姿为**席地跪坐或盘腿坐**（高桌椅未普及）。书籍主流为**卷轴装**（无线装书）。

#### 宋代
- **人物服饰**：
  - **皇帝/官员**：标志性首服为**展脚幞头**（两脚平直细长）。常服为圆领大袖袍衫/襕衫。官员佩鱼袋。
  - **女性**：服饰趋于修长含蓄。外罩**褙子**（对襟长外套，两侧开衩）是绝对主流。戴高冠/花钗冠。
  - **文人/乡绅**：流行各种巾子（东坡巾、纶巾），穿交领/圆领襕衫或直裰。
- **场景建筑**：歇山顶为主，屋脊饰鸱吻。斗拱变小变密。**格子门窗**普及。市井突破坊市制，临街开店，出现酒旗招牌。室内**高足桌椅完全普及**。
- **生活习惯**：主流行礼为**拱手作揖礼**。主流坐姿为**完全垂足高坐**（坐椅子/凳子）。**合餐制**确立。书籍主流为**册页装帧（蝴蝶装）**。流行斗茶。

#### 元代
- **人物服饰**：
  - **蒙古贵族/官员**：标志性发型为**“婆焦”发式**（三搭头）。戴钹笠冠或暖帽。穿“质孙袍”或“辫线袄”（腰部密褶），束“答忽”带。
  - **汉族官员**：公服需戴展脚幞头（将头发藏起），穿紫/绯/绿袍。
  - **女性**：蒙古贵族妇女戴高耸的**罟罟冠**（顾姑冠），穿宽大交领长袍。汉族妇女多穿交领短襦与长裙/长裤。
- **场景建筑**：宫殿大量使用彩色琉璃瓦剪边。室内高低家具并存，普遍设暖炕与壁炉，铺地毯/挂壁毯。
- **生活习惯**：宫廷盛行“质孙宴”（统一着装颜色）。

#### 明代
- **人物服饰**：
  - **皇帝/官员**：恢复汉族衣冠。官员戴**乌纱帽**（两角椭圆），穿圆领大袖衫。核心标志为胸前背后的**“补子”**（文禽武兽）。
  - **平民（男）**：必须**束发戴网巾**，外罩四方平定巾或瓜皮帽。穿直裰或短衣，严禁使用官定颜色（黄、紫、大红）和纹样。
  - **女性**：穿袄、衫、裙，外罩**比甲**（无袖长马甲）。平民妇女严禁戴凤冠、穿霞帔。缠足风气盛行（弓鞋）。
- **场景建筑**：硬山顶/悬山顶普及。砖墙（清水墙/混水墙）普遍。门窗多为菱花格扇窗或方格窗。室内家具工艺达高峰（明式家具：圈椅、官帽椅、架子床）。
- **生活习惯**：官场行叩拜礼，常礼为揖礼（抱拳）。完全垂足高坐。阅读线装书。

### 6. 质检标准

在交付分镜表格前，必须进行自我质检：
1. **音频长度**：是否所有音频文案都在 20-40 字左右？
2. **文本完整性**：是否覆盖了剧本的 100% 内容，无任何遗漏？
3. **人物资产**：所有角色资产卡的提示词中，是否都包含了**"电影级写实画风...采用角色设计排版...面部特写照，全身正面站立视图，全身侧面站立视图"**以及**"纯色/灰色影棚背景"**的要求？描述是否详尽无简化？
4. **提示词格式**：是否每条提示词都包含了 `@资产` 和完整的七维描述？
5. **历史准确性**：提示词中的服化道描述是否符合对应朝代的历史设定（如唐代叉手礼、宋代展脚幞头、明代网巾与补子等）？是否包含了必要的正向和反向指令？
