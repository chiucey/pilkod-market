# 语文试卷分析技能

## 功能概述

本技能从语文试卷图片中提取信息，生成标准化的试卷分析报告。适用于初三语文期中测试、月考、期末考试等各类测试的试卷分析工作。

## 输入要求

- **支持格式**: JPG、PNG、JPEG、BMP 等常见图片格式
- **图片要求**: 尽量清晰，避免严重倾斜或模糊
- **输入方式**: 提供试卷图片文件路径或上传图片

## 输出结构

生成的试卷分析报告包含以下模块：

### 1. 基本信息区
| 字段 | 说明 |
|------|------|
| 学生姓名 | 从试卷中提取 |
| 学科 | 固定为"语文" |
| 年级 | 如"九年级"等 |
| 考试日期 | 提取或留空待填写 |
| 满分 | 如"70分（无作文）" |
| 得分 | 学生实际得分 |
| 考试时长 | 如"120分钟" |

### 2. 试卷评估区
| 评估维度 | 可选值 |
|---------|--------|
| 题量大小 | 适中 / 偏大 / 偏小 |
| 难易程度 | 适中 / 偏难 / 偏易 |
| 命题覆盖范围 | 具体列出考查内容 |

### 3. 题型分布表

| 大题类型 | 分值 | 说明 |
|---------|------|------|
| 积累与运用 | XX分 | 字音字形、病句修改等 |
| 阅读与鉴赏 | XX分 | 古诗文阅读、现代文阅读 |
| 写作 | XX分 | 作文（可选，如无作文则标注） |

### 4. 知识点梳理
根据试卷内容，梳理考查的知识点：
- 字音字形
- 病句修改
- 句子仿写
- 诗词手法赏析
- 现代文文章主旨分析
- 开放拓展

### 5. 易错点分析
识别学生容易出错的题型：
- 理解性默写
- 夸张手法的赏析
- 句子赏析
- 名著写作特色的分析
- 论证方法的作用

### 6. 试题分析表（核心模块）

按题号逐一分析，每道题包含：

| 分析项 | 示例内容 |
|-------|---------|
| 题号 | 第1题 |
| 考查内容 | 考查书法字体识别 |
| 总分 | 共2分 |
| 得分 | 得2分 |
| 失分原因 | 考生能准确识别书法字体 |

**分析格式示例**：
```
第1题：考查书法字体识别，共2分，得2分。
考生能准确识别书法字体。

第2题：考查楷书简体字书写，共2分，得2分。
考生书写无误。

第3题：考查语段综合，共9分，得3分，扣6分。
考生在字音和成语辨析上回答正确，在病句、句子仿写、语言表达上扣分。
```

## 处理流程

### 第一步：图片识别

使用 OCR 工具从试卷图片中提取文本内容：

```
使用 images_understand 工具读取试卷图片
提取以下信息：
- 学生姓名（如有）
- 试卷标题（如"初三语文期中测试"）
- 各题题目和答案内容
- 分值标注
```

### 第二步：内容解析

解析提取的文本，识别：
- 试卷结构（大题、小题）
- 每道题的考查知识点
- 分值设置
- 学生作答情况（如果图片中包含答卷）

### 第三步：结构化输出

按照上述输出结构，生成标准化的试卷分析报告。

## 输出格式

生成的分析报告以 Markdown 格式输出，包含：
1. 结构化的表格数据
2. 详细的试题分析
3. 知识点和易错点总结

## 注意事项

1. **图片质量**: 如果图片模糊或倾斜严重，OCR 识别可能不准确
2. **信息补全**: 报告中标记 `[待填写]` 的字段需要用户手动补充
3. **适用范围**: 主要适用于初中语文试卷，小学试卷可适当调整分析维度
