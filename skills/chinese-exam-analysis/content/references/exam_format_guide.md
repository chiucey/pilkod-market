# 语文试卷分析技能 - 参考资料

## 试卷分析报告标准格式

基于魏山智语文试卷分析文档，本技能生成的分析报告应遵循以下格式规范。

### 基本信息表结构

试卷分析报告的基本信息区域采用以下字段结构：

| 字段 | 类型 | 说明 |
|------|------|------|
| 学生姓名 | 文本 | 从试卷中提取或标注 `[待填写]` |
| 分析老师 | 文本 | 标注 `[待填写]` |
| 学科 | 固定值 | 固定为"语文" |
| 日期 | 文本 | 如"2025年12月29日" |
| 校区 | 文本 | 标注 `[待填写]` |
| 学校 | 文本 | 标注 `[待填写]` |
| 年级 | 文本 | 如"九年级" |
| 满分 | 文本 | 如"70（无作文）" |
| 得分 | 数值 | 学生实际得分 |
| 考试时长 | 文本 | 如"120分钟" |

### 试卷评估标准

#### 题量评估
- **适中**: 大部分学生能在规定时间内完成
- **偏大**: 多数学生反映时间紧张
- **偏小**: 考试时间充裕

#### 难度评估
- **适中**: 基础题、中等题、难题比例合理
- **偏难**: 难题占比过高
- **偏易**: 基础题占比过高

#### 命题覆盖范围示例

九年级上学期语文试卷常见的命题覆盖范围：

```
书法与书写，语段综合，九年级上学期古诗文默写，九年级上学期古诗词鉴赏，九年级上学期文言文对比阅读，文学类文本，实用类文本
```

### 题型分布标准

初中语文试卷典型的题型分布：

| 题型 | 典型分值 | 包含内容 |
|------|---------|---------|
| 积累与运用 | 25-30分 | 字音字形、病句修改、句子仿写、活动设计、应用文 |
| 阅读与鉴赏 | 40-50分 | 古诗词鉴赏、文言文阅读、现代文阅读（文学类/实用类） |
| 写作 | 50分 | 作文（部分考试可能无作文） |

### 知识点分类体系

#### 积累与运用类知识点
- 字音字形
- 病句修改
- 句子仿写
- 诗词手法赏析
- 语言表达

#### 阅读鉴赏类知识点
- 古诗文默写（理解性默写）
- 诗词手法赏析（夸张、比喻、拟人等）
- 句子赏析
- 文章主旨分析
- 名著写作特色分析
- 论证方法的作用

#### 常见易错点
- 理解性默写（不能准确背诵）
- 夸张手法的赏析（手法判断错误）
- 句子赏析（答题角度不准确）
- 名著写作特色的分析（缺乏方法）
- 论证方法的作用（概念混淆）

### 试题分析格式

每道题的试题分析应包含以下要素：

1. **题号标识**: "第X题"
2. **考查内容**: 简明描述考查的知识点
3. **分值信息**: "共X分"
4. **得分情况**: "得X分"或"得X分，扣X分"
5. **详细分析**: 说明得分或失分原因

#### 示例

```
第4题：考查九年级上学期古诗词默写，共8分，得5分，扣3分。
考生对《岳阳楼记》和《水调歌头》的内容还不够熟悉。
```

### 图片识别注意事项

#### 试卷图片质量要求
- 分辨率建议: 最低 800x600 像素
- 光照均匀，避免阴影
- 无严重倾斜（倾斜角度不超过 15 度）
- 文字清晰可辨

#### 常见识别问题
1. **手写文字**: 潦草的手写体可能识别错误
2. **表格内容**: 复杂表格可能解析不准确
3. **特殊符号**: 数学符号或化学式可能被误读
4. **图片插入**: 试卷中的图片需要额外处理

#### 识别后校验
- 检查学生姓名是否正确
- 核对总分是否与各题分值之和匹配
- 验证日期格式是否规范
