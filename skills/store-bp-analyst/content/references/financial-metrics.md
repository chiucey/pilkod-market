# 财务指标计算公式

## 一、收入类指标

### 1.1 营业收入
```
营业收入 = Σ(各商品销量 × 单价)
```

### 1.2 客单价 (Average Transaction Value, ATV)
```
客单价 = 营业收入 / 客单数
```

### 1.3 同比增长率
```
同比增长率 = (本期值 - 去年同期值) / 去年同期值 × 100%
```

### 1.4 环比增长率
```
环比增长率 = (本期值 - 上期值) / 上期值 × 100%
```

## 二、成本类指标

### 2.1 营业成本
```
营业成本 = Σ(各商品销售成本 × 销量)
销售成本 = 采购成本 + 直接人工 + 直接费用
```

### 2.2 成本率
```
成本率 = 营业成本 / 营业收入 × 100%
```

### 2.3 变动成本率
```
变动成本率 = 变动成本 / 营业收入 × 100%
```

## 三、利润类指标

### 3.1 毛利润
```
毛利润 = 营业收入 - 营业成本
```

### 3.2 毛利率
```
毛利率 = (营业收入 - 营业成本) / 营业收入 × 100%
```

### 3.3 营业利润
```
营业利润 = 毛利润 - 营业费用
营业费用 = 销售费用 + 管理费用 + 财务费用
```

### 3.4 净利率
```
净利率 = 净利润 / 营业收入 × 100%
```

## 四、效率类指标

### 4.1 存货周转率
```
存货周转率 = 营业成本 / 平均存货
平均存货 = (期初存货 + 期末存货) / 2
```

### 4.2 存货周转天数
```
存货周转天数 = 365 / 存货周转率
```

### 4.3 人效 (Sales per Employee)
```
人效 = 营业收入 / 员工人数
```

### 4.4 坪效 (Sales per Area)
```
坪效 = 营业收入 / 营业面积(m²)
```

## 五、客户类指标

### 5.1 转化率
```
转化率 = 成交客单数 / 到店客流量 × 100%
```

### 5.2 复购率
```
复购率 = 重复购买客户数 / 总购买客户数 × 100%
```

### 5.3 客户终身价值 (CLV)
```
CLV = 平均客单价 × 平均年购买频次 × 客户平均生命周期
```

### 5.4 客户获取成本 (CAC)
```
CAC = 营销总费用 / 新增客户数
```

## 六、预警指标

### 6.1 盈亏平衡点
```
盈亏平衡点(销售额) = 固定成本 / 边际贡献率
边际贡献率 = (销售额 - 变动成本) / 销售额 × 100%
```

### 6.2 流动比率
```
流动比率 = 流动资产 / 流动负债
```

### 6.3 库存预警线
```
安全库存 = 平均日销量 × 补货周期 + 保险库存
库存预警 = 库存量 < 安全库存
```

## 七、零售专项指标

### 7.1 连带率
```
连带率 = 销售件数 / 成交笔数
```

### 7.2 折扣率
```
折扣率 = 实际销售额 / 标价销售额 × 100%
```

### 7.3 销销比
```
销销比 = 本期销售 / 上期销售
```

### 7.4 品类贡献率
```
品类贡献率 = 品类销售额 / 总销售额 × 100%
```
