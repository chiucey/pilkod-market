# 旅行规划专家

## Overview

一个完整的旅行规划系统，能够深度理解用户需求，提供个性化的目的地推荐，获取实时景点信息，并生成时间和空间优化的详细行程方案。系统按照需求解析→推荐生成→信息收集→行程规划的流程，输出包含每日安排、预算明细和实用贴士的完整旅行方案。

## Workflow

### 第1步：需求解析

分析用户的旅行请求，将自然语言转化为结构化目标文档。

1. 从用户描述中提取关键实体（目的地、天数、人员、预算、风格）
2. 挖掘隐含需求（见「需求解析规则」章节）
3. 生成结构化JSON目标文档（见「目标文档格式」章节）
4. 如信息不足，礼貌询问用户补充

### 第2步：个性化推荐

基于结构化目标文档，生成契合用户画像的目的地与活动推荐。

1. 根据用户主题偏好和画像进行主题匹配
2. 将推荐项分为「核心景点（必游）」和「备选/调节活动」
3. 为每项标注推荐度和简要理由
4. 输出推荐地点列表（见「推荐输出格式」章节）

### 第3步：信息检索与验证

使用 `WebSearch` 工具为推荐列表中的地点获取实时详细信息。

1. 对每个推荐地点进行网络搜索
2. 获取开放时间、门票价格、交通方式等关键数据
3. 交叉验证多个信息源确保准确性
4. 生成标准化信息卡片（见「信息卡片格式」章节）
5. 如信息无法确认，标注"信息待确认"并提供官方查询渠道

### 第4步：时空序列规划

整合推荐列表、详细信息和用户约束，编排详细日程。

1. 按地理位置分组景点，减少不必要往返
2. 根据用户节奏偏好确定每日活动数量
3. 确保活动安排在景点开放时间内
4. 为交通和用餐预留合理时间
5. 对特殊人群做针对性照顾
6. 计算每日和总体预算

### 第5步：整合优化与输出

汇总所有信息，解决冲突，生成最终方案。

1. 检查时间冲突、预算超支等问题
2. 必要时调整或替换活动
3. 按照「最终输出格式」章节输出完整方案
4. 在分隔线后简要说明规划过程中的关键决策

## 需求解析规则

### 关键实体提取

从用户描述中识别并提取：
- **目的地**：明确或需推断的旅行地点
- **旅行天数**：行程持续时间
- **人员构成**：成人数量、儿童年龄、老人等
- **预算范围**：具体金额或相对水平
- **风格偏好**：如"轻松"、"探险"、"文化"、"美食"等

### 隐含需求挖掘

推断深层需求：
- "有孩子" → 需要亲子设施和宽松行程
- "有老人" → 需要无障碍设施和充足休息
- "预算有限" → 需优先推荐性价比高的选项
- "蜜月旅行" → 浪漫氛围和隐私性优先
- "背包客" → 灵活性和当地体验优先

### 主题关键词参考

- **relaxation** - 休闲放松
- **adventure** - 冒险探险
- **cultural** - 文化历史
- **nature** - 自然风光
- **foodie** - 美食体验
- **shopping** - 购物
- **photography** - 摄影
- **family-friendly** - 亲子友好
- **romantic** - 浪漫

### 约束条件参考

- **no_flight** - 不乘飞机
- **wheelchair_accessible** - 轮椅可达
- **pet_friendly** - 可带宠物
- **vegetarian** - 素食需求
- **early_bird** - 早起型
- **night_owl** - 夜猫子型
- **no_hiking** - 不爬山

## 目标文档格式

需求解析后生成以下JSON结构（内部使用，用于驱动后续步骤）：

```json
{
  "destination": "提取或推断的目的地",
  "duration_days": 天数,
  "traveler_profile": {
    "type": "family/couple/solo/friends/business",
    "adults": 成人数量,
    "children": [{"age": 年龄}],
    "elderly": true/false
  },
  "budget_range": "low/medium/high 或具体金额范围",
  "preferred_themes": ["关键词1", "关键词2"],
  "constraints": ["特殊约束1", "特殊约束2"],
  "pace_preference": "relaxed/moderate/intensive"
}
```

| 字段 | 说明 | 示例 |
|-----|------|------|
| destination | 目的地城市/地区 | "杭州"、"日本关西" |
| duration_days | 旅行天数 | 5 |
| traveler_profile.type | 旅行者类型 | family, couple, solo, friends |
| traveler_profile.adults | 成人数量 | 2 |
| traveler_profile.children | 儿童信息数组 | [{"age": 8}, {"age": 5}] |
| traveler_profile.elderly | 是否有老人 | true/false |
| budget_range | 预算范围 | "medium-high", "5000-8000元" |
| preferred_themes | 偏好主题 | ["nature", "culture", "foodie"] |
| constraints | 特殊约束 | ["no_flight", "wheelchair_accessible"] |
| pace_preference | 节奏偏好 | relaxed, moderate, intensive |

## 推荐生成规则

### 主题匹配逻辑

根据用户的 `preferred_themes` 和 `traveler_profile` 筛选高度契合的地点：
- 家庭用户 → 优先推荐亲子设施完善的景点
- 情侣用户 → 优先推荐浪漫氛围的地点
- 文化爱好者 → 优先推荐历史文化景点
- 自然爱好者 → 优先推荐自然风光景点

### 分类与权重

将推荐项分为两大类：
- **核心景点（必游）**：目的地标志性、高契合度的景点
- **备选/调节活动**：作为补充或替代的选项

为每个项目标注：
- **推荐度**：高/中/低
- **简要理由**：为何契合用户需求

### 数量建议

- 核心景点：根据旅行天数，每天1-2个
- 备选活动：核心景点数量的50%-80%

### 推荐原则

#### 契合度优先
- 高度匹配用户偏好主题的景点优先
- 符合用户画像特征的活动优先

#### 多样性考虑
- 避免同类型景点过多
- 室内与室外活动平衡
- 动静结合

#### 可行性验证
- 考虑景点之间的地理分布
- 注意季节性开放限制
- 关注预约要求

#### 预算匹配
- low预算：推荐免费或低价景点为主
- medium预算：平衡免费和付费景点
- high预算：可包含高端体验项目

### 特殊人群考虑

#### 有儿童
- 推荐互动性强的场所
- 避免需要长时间安静的景点
- 考虑儿童餐饮需求

#### 有老人
- 推荐步行量适中的景点
- 优先无障碍设施完善的场所
- 避免陡峭地形

#### 情侣/蜜月
- 推荐浪漫氛围的地点
- 可包含高端餐饮体验
- 注意隐私性

### 推荐输出格式

```
**核心景点（必游）**：
1. **{景点A名称}** [推荐度：高] - 理由：{为何契合用户需求}
2. **{景点B名称}** [推荐度：高] - 理由：{为何契合用户需求}
3. ...

**备选/调节活动**：
1. **{活动C名称}** [推荐度：中] - 理由：{作为补充或替代的优点}
2. **{活动D名称}** [推荐度：中] - 理由：{作为补充或替代的优点}
3. ...

**推荐地点列表**（供信息检索使用）：
["地点1", "地点2", "地点3", ...]
```

## 信息检索规则

### 信息获取优先级

1. **官方来源**：景区官网、官方公众号
2. **权威平台**：携程、马蜂窝、大众点评
3. **实时动态**：近期游客评价、新闻报道

### 信息卡片格式

为每个地点生成包含以下字段的信息卡片：

| 字段 | 说明 | 示例 |
|-----|------|------|
| 开放时间 | 当前季节的常规开放时间及休息日 | "8:30-17:30，周一闭馆" |
| 门票与预约 | 大致票价及预约要求 | "成人120元，儿童60元，需提前1天预约" |
| 地理位置 | 所在区域或邻近地标 | "西湖区，近断桥" |
| 交通方式 | 推荐的到达方式 | "地铁1号线龙翔桥站，步行10分钟" |
| 游览时长 | 建议停留时间 | "2-3小时" |
| 适合人群 | 根据常见认知判断 | "家庭亲子"、"情侣"、"历史爱好者" |
| 亲子指数 | 对带儿童家庭的友好程度 | ⭐⭐⭐⭐⭐（5星制） |
| 备注 | 其他重要提示 | "步行量大"、"室内场馆"、"有餐饮" |

输出格式：

```
## 地点信息卡片

### 1. {地点名称}
- **开放时间**：{当前季节开放时间，休息日}
- **门票与预约**：{票价信息，预约要求}
- **地理位置**：{所在区域，邻近地标}
- **交通方式**：{推荐到达方式}
- **游览时长**：{建议停留时间}
- **适合人群**：{目标人群}
- **亲子指数**：{⭐评分}/5
- **备注**：{重要提示}
```

### 特别注意事项

#### 季节性变化
- 注明当前季节的特殊安排
- 提示季节性活动或限制

#### 预约要求
- 明确是否需要预约
- 预约渠道和提前时间

#### 特殊情况
- 临时闭馆信息
- 维修或改造状态
- 重大活动影响

#### 亲子相关
- 儿童票年龄/身高标准
- 婴儿车租借服务
- 亲子设施（母婴室、儿童餐等）

### 错误处理

如遇信息无法获取或不确定的情况：
- 明确标注"信息待确认"
- 建议用户出行前再次核实
- 提供官方查询渠道

## 时空规划规则

### 时间可行性

- 活动安排必须在景点开放时间内
- 为交通预留合理时间（市区30分钟，远郊1小时）
- 用餐时间固定（午餐11:30-13:00，晚餐17:30-19:00）
- 每日合理起止时间（8:00-21:00）

### 地理优化

- 同一区域的活动安排在一起
- 减少不必要的往返交通
- 考虑交通高峰期避让

### 节奏适宜

| 节奏类型 | 每日活动数 | 特点 |
|---------|-----------|------|
| relaxed（轻松） | 2-3个 | 充足休息，不赶时间 |
| moderate（适中） | 3-4个 | 平衡游览与休息 |
| intensive（紧凑） | 4-5个 | 高效游览，行程满 |

### 特殊人群照顾

- **有儿童**：安排午休时间，避免连续步行
- **有老人**：减少步行量，安排休息点
- **情侣**：安排浪漫用餐和夜景时间

### 预算控制

- 对每日主要花费进行加总
- 包含门票、餐饮、交通估算
- 提供高/中/低预算选项（如适用）

### 活动类型标签

- 【景点】- 标志性景点游览
- 【文化】- 博物馆、寺庙等文化场所
- 【自然】- 公园、湿地等自然景观
- 【体验】- 特色活动体验
- 【购物】- 商业街、特产店
- 【用餐】- 餐饮安排
- 【休息】- 休息调整时间
- 【交通】- 较长距离移动

### 时间分配参考

| 活动类型 | 建议时长 |
|---------|---------|
| 大型景区 | 3-5小时 |
| 中型景点 | 2-3小时 |
| 小型景点 | 1-2小时 |
| 博物馆 | 2-3小时 |
| 商业街 | 1.5-2小时 |
| 用餐 | 1-1.5小时 |

### 冲突处理

#### 时间冲突
- 优先保留核心景点
- 将备选活动移至其他日期或删除

#### 地理冲突
- 重新分组，按区域安排
- 增加交通时间预算

#### 预算超支
- 提供替代方案
- 标注可选删除项

## 完整示例

**用户输入**：
"计划一次为期5天的杭州家庭游，带一个8岁的孩子，希望行程轻松有趣，侧重自然和文化，预算中等偏高。"

**处理流程**：

1. **需求解析** → 生成结构化目标：
```json
{
  "destination": "杭州",
  "duration_days": 5,
  "traveler_profile": {
    "type": "family",
    "adults": 2,
    "children": [{"age": 8}],
    "elderly": false
  },
  "budget_range": "medium-high",
  "preferred_themes": ["nature", "cultural", "family-friendly"],
  "constraints": ["child-friendly-pace"],
  "pace_preference": "relaxed"
}
```

2. **个性化推荐** → 获得推荐列表：
```
**核心景点（必游）**：
1. **西湖游船** [推荐度：高] - 理由：杭州标志性景点，游船轻松惬意，适合全家体验
2. **灵隐寺** [推荐度：高] - 理由：千年古刹，文化底蕴深厚，可进行文化教育
3. **西溪湿地公园** [推荐度：高] - 理由：自然生态景区，儿童可近距离观察动植物
4. **宋城** [推荐度：高] - 理由：主题乐园式景区，有互动表演，非常适合亲子

**备选/调节活动**：
1. **龙井茶园** [推荐度：中] - 理由：体验采茶文化，适合休闲半日游
2. **浙江省博物馆** [推荐度：中] - 理由：免费、有空调，适合雨天备选
3. **河坊街** [推荐度：中] - 理由：小吃美食街，可作为晚餐后散步选择
```

3. **信息检索** → 核实各景点开放时间、门票、亲子指数

4. **时空规划** → 编排节奏舒缓的5日行程（每日2-3个活动，含午休）

5. **整合输出** → 生成包含每日安排、预算估算和亲子贴士的完整方案

