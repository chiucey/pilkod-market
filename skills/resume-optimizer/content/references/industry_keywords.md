## 简历常用数字表达

### 增长/提升
```
增长：提升了30%、同比增长50%
增长到：从10万增长到50万
翻了X倍：业绩翻了3倍
```

### 效率/速度
```
缩短：交付周期缩短40%
提升：处理速度提升2倍
节省：时间节省50%
```

### 规模/范围
```
涉及：涉及金额1000万
覆盖：覆盖用户100万+
管理：管理团队20人+
```

### 比例/占比
```
占比：市场份额达到30%
贡献：贡献营收50万
负责：负责项目预算的60%
```
