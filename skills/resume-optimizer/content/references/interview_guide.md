# 简历优化技能参考指南

## 深度访谈技巧库

### STAR法则深度追问模板

#### 情境（Situation）追问
```
• 这个项目/任务的背景是什么？
• 当时面临的主要挑战是什么？
• 有哪些限制条件（时间、资源、人力）？
• 为什么这个任务很重要/紧急？
• 之前有人尝试过吗？结果如何？
```

#### 任务（Task）追问
```
• 您在这个项目中的具体角色是什么？
• 您的职责范围有多大？
• 您需要达成什么具体目标？
• 成功的标准是什么？
• 有哪些关键绩效指标（KPI）？
```

#### 行动（Action）追问
```
• 您采取了哪些具体步骤？
• 为什么选择这种方法？
• 您使用了哪些工具/技术/方法？
• 您如何协调团队/资源？
• 遇到了什么困难？如何解决的？
• 有什么创新或改进？
```

#### 结果（Result）追问
```
• 最终取得了什么成果？
• 如何量化这些成果？（百分比、具体数字）
• 与之前相比提升了多少？
• 为公司/团队带来了什么价值？
• 您个人的贡献是什么？
```

### 量化数据挖掘问题

当用户陈述不够具体时，使用以下追问：

#### 效率提升类
- 「完成这件事通常需要多久？您优化后缩短了多少？」
- 「以前的方法是什么？您改进后效率提升了多少？」
- 「每月/每周能处理多少任务？」

#### 成本节约类
- 「这个方案帮助公司节约了多少成本？」
- 「与之前相比，降低了多少比例？」
- 「资源利用率提升了多少？」

#### 业绩增长类
- 「您的贡献对营收增长有多大影响？」
- 「用户增长了多少？增长比例是多少？」
- 「市场份额有什么变化？」

#### 用户增长类
- 「您负责的产品/服务有多少用户？」
- 「用户活跃度/留存率是多少？」
- 「新增用户的主要来源是什么？」

#### 团队管理类
- 「您管理的团队有多少人？」
- 「团队流失率是多少？」
- 「团队整体绩效提升了多少？」

### 置信度快速提升问题

以下是5个能快速提升综合置信度的黄金问题：

1. **目标明确性问题**
   「您的KPI/OKR是什么？完成情况如何？」
   → 快速确认工作职责和成就水平

2. **成就验证性问题**
   「您负责过最有成就感的一个项目是什么？取得了什么成果？」
   → 挖掘最具代表性的成就案例

3. **能力证明问题**
   「您的直属上级如何评价您的工作？」
   → 获取第三方能力背书

4. **个人定位问题**
   「如果给您的职业生涯写一个标题，会是什么？」
   → 快速把握用户的职业定位和核心价值

5. **差异化认知问题**
   「您最想被雇主记住的一个特点是什么？为什么？」
   → 明确用户的差异化竞争优势

## 简历排版最佳实践

### 结构优先级（从高到低）

1. **联系信息**
   - 姓名（突出显示）
   - 电话、邮箱、LinkedIn
   - 城市（不需要完整地址）

2. **简历摘要**（强烈推荐）
   - 2-3句话概括核心价值
   - 突出最相关的经验和成就
   - 针对目标岗位定制

3. **工作经历**
   - 倒序排列（最近优先）
   - 每条包含：职位、公司、时间
   - 使用STAR法则描述成就

4. **教育背景**
   - 硕士/本科以上才需要详细
   - 包含GPA（如果>3.5）、荣誉
   - 相关课程（初入职场可写）

5. **技能模块**
   - 分类呈现：技术技能、业务技能
   - 避免"精通Word"等无价值项
   - 按熟练度分组

### 格式规范

| 项目 | 建议 |
|------|------|
| 页数 | 1-2页（5年以下1页，5年以上2页） |
| 字体 | 建议使用专业字体，如Arial、Calibri |
| 字号 | 姓名24-28pt，标题12-14pt，正文10-11pt |
| 边距 | 0.5-1英寸 |
| 行距 | 1.0-1.5倍 |
| 颜色 | 黑白或深蓝/深灰，专业简洁 |

### ATS友好建议

- 使用标准标题（如"工作经历"而非"我的战绩"）
- 避免表格、图片、复杂格式
- 关键词与JD匹配
- 纯文本保存一份备份

## 置信度评估细则

### 各维度评分标准

#### 求职目标维度（权重30%，目标95%）

| 置信度 | 标准 |
|--------|------|
| 0-30% | 仅表达"想找工作"或"换个方向" |
| 31-50% | 有大致方向但不明确（如"互联网方向"） |
| 51-70% | 知道想做什么但具体公司/岗位未定 |
| 71-85% | 明确目标岗位，行业方向清晰 |
| 86-94% | 了解目标薪资范围和工作地点 |
| 95%+ | 完全明确：岗位、行业、薪资、地点、职级、时间 |

#### 核心竞争力维度（权重20%，目标90%）

| 置信度 | 标准 |
|--------|------|
| 0-30% | 仅能说出笼统描述（如"我很勤奋"） |
| 31-50% | 有具体技能但不熟悉应用场景 |
| 51-70% | 能举出1-2个应用案例 |
| 71-85% | 能量化描述1-2个成就 |
| 86-89% | 能清晰描述3个核心能力及具体案例 |
| 90%+ | 差异化定位明确，可与同龄人比较 |

#### 工作经历亮点维度（权重20%，目标90%）

| 置信度 | 标准 |
|--------|------|
| 0-30% | 简历中有工作描述但无量化数据 |
| 31-50% | 有部分量化但数据来源不明 |
| 51-70% | 有具体量化数据但未经追问确认 |
| 71-85% | 所有核心项目都有STAR描述 |
| 86-89% | 有1-2个亮点案例经过深度追问验证 |
| 90%+ | 主要成就均已验证，真实性有保障 |

### 置信度计算示例

假设各维度当前状态：
- 求职目标：95%（完全达标）
- 行业定位：90%（略低于目标）
- 核心竞争力：88%
- 工作经历亮点：85%
- 技能匹配度：90%

综合置信度 = (95×0.3 + 90×0.2 + 88×0.2 + 85×0.2 + 90×0.1) / 1.0
           = (28.5 + 18 + 17.6 + 17 + 9) / 1.0
           = 90.1%

结论：综合置信度90.1%，距离95%还差4.9个百分点，需要补充核心竞争力或工作经历亮点的细节。
