# 涟漪投资决策Skill

## 文件结构

```
investment-decision/
├── SKILL.md              # Skill定义（触发条件 + 执行流程）
├── README.md             # 本文件
└── scripts/
    ├── market_scan.py     # 市场扫描（情绪罗盘）
    ├── position_check.py  # 持仓检查（止损预警）
    └── daily_review.py    # 收盘复盘
```

## 触发时机

1. **每日开盘前**（建议7:30-8:30）：运行市场扫描 + 仓位建议
2. **盘中选股时**：V问"今天有什么机会"触发选股信号
3. **持仓检查时**：V提到持仓股票时自动检查
4. **收盘后**：运行复盘记录

## 快速使用

```bash
# 开盘前市场扫描
python3 scripts/market_scan.py

# 持仓检查
python3 scripts/position_check.py

# 收盘复盘
python3 scripts/daily_review.py
```

## 情绪罗盘 v7.1（固化参数）

| 评分 | 仓位 | 操作 |
|------|------|------|
| >70分 | 50-70% | 重仓，积极操作 |
| 55-70分 | 30-50% | 轻仓，严格止损 |
| 40-55分 | 20-30% | 中性，短线为主 |
| <40分 | ≤20% | 观望，不开新仓 |
| <20分 | 空仓 | 全面休息 |

## 止损铁律

- 单一标的止损：-5%
- 回撤止损：-8%
- 最大仓位：单标的≤25%，单一板块≤40%
- 保持现金：永远≥20%

## 三类买点

- **买点A**（最强）：主题日 + 情绪≥45 + 放量>1.2倍 → 仓位25%
- **买点B**（次强）：非主题日 + 情绪≥50 → 仓位20%
- **买点C**（辅助）：情绪≥45 + 放量>1.4倍 → 仓位15%
