# 开运建议参考

## 五行补救方法

### 木弱者
- 颜色：青、绿色系
- 方位：东方
- 职业：木材、教育、设计
- 数字：3、8
- 吉祥物：绿植、竹制品、翡翠
- 食物：蔬菜、水果、绿茶
- 避免：金属饰品、金色

### 火弱者
- 颜色：红、紫色系
- 方位：南方
- 职业：电子、照明、能源
- 数字：2、7
- 吉祥物：红玛瑙、紫水晶、蜡烛
- 食物：辛辣食物、红肉、荔枝
- 避免：大量黑色、深色

### 土弱者
- 颜色：黄、棕色系
- 方位：中央、西南、东北
- 职业：建筑、农业、矿产
- 数字：5、10
- 吉祥物：黄玉、陶瓷、紫砂
- 食物：地瓜、南瓜、小米
- 避免：过多绿色

### 金弱者
- 颜色：白、金色系
- 方位：西方
- 职业：金融、冶金、珠宝
- 数字：4、9
- 吉祥物：金饰、白玉、金属摆件
- 食物：鸡胸肉、白萝卜、梨
- 避免：红色过多

### 水弱者
- 颜色：黑、蓝、灰色系
- 方位：北方
- 职业：航海、物流、金融
- 数字：1、6
- 吉祥物：黑曜石、水晶球、鱼缸
- 食物：海带、黑豆、黑色食品
- 避免：过多火属性物品
