# 投标标书解析 Skill

> 用于解析招标文件，获取标书写作要求

## 触发条件

当用户需要解析投标文件、获取标书写作要求时调用此 skill。

## 重要原则

### ⚠️ 信息摘录原则（必须遵守）

**【强制要求】原文摘录，禁止简化：**
- 所有从文本中获取的信息必须**逐字原文摘录**
- 不得对表格内容进行归纳总结或精简
- 不得对条款进行概括性描述
- 不得省略任何内容，即使看似重复
- 所有格式要求、条款编号必须完整保留

### 文件查找原则

- 严格按照给定的文件路径定位文件
- 如果文件路径包含"货物清单"或"一览表"，优先定位该文件
- 如果文件路径包含其他特定文件，按路径指示定位

---

## 工作流程

### 阶段一：定位招标文件包

```
输入：用户指定的文件夹路径
目标：找到【包X_完整招标文件_XXXXXXXXX】压缩包
```

**操作步骤：**

| 步骤 | 操作 | 判断条件 |
|------|------|----------|
| 1.1 | 审查文件夹 | 如果有多个文件夹，寻找名称类似【（投标公司）（年份）服务类（第几次）公开采购】的文件夹 |
| 1.2 | 定位招标文件包 | 寻找包含【XXX_招标文件包】字样的压缩包 |
| 1.3 | 解压操作 | 解压后判断：如果是文件夹则继续打开，如果是压缩包则继续解压 |
| 1.4 | 确认完整包 | 找到【包X_完整招标文件_XXXXXXXXX】字样的压缩包 |

### 阶段二：解压并获取核心文件

```
输入：【包X_完整招标文件_XXXXXXXXX】压缩包
目标：获取招标文件、招标公告、技术规范书
```

**操作步骤：**

| 步骤 | 操作 | 说明 |
|------|------|------|
| 2.1 | 解压压缩包 | 遍历解压后的文件 |
| 2.2 | 识别文件类型 | 通常招标文件单独列出，招标公告、技术规范书需要解压相应压缩包 |
| 2.3 | 多压缩包处理 | 若有多个压缩包，解压每个压缩包获取对应内容 |
| 2.4 | 阅读核心文档 | 阅读带【招标公告】、【招标文件】、【技术规范书】字样的 doc 文档 |

### 阶段三：提取关键信息

#### 3.1 提取招标公告信息

| 字段名 | 原文摘录 |
|--------|----------|
| 项目建设单位 | （原文填写） |
| 招标人 | （原文填写） |
| 招标代理机构 | （原文填写） |
| 招标文件（电子文件）获取时间 | （原文填写） |
| 投标文件提交的截止时间 | （原文填写） |
| 投标文件的方式 | （原文填写） |

#### 3.2 提取招标文件信息

**3.2.1 投标保证金（见 3.4.1）**
- 若无需递交：标注"无需递交"
- 若需要递交：记录递交方式（原文摘录）

**3.2.2 财务状况年份要求（见 3.5.2）**
- （原文摘录财务状况年份要求）

**3.2.3 投标文件效力（见 3.7.4）**
- 判断是否支持网盘上传
- （原文填写）

**3.2.4 投标文件上传方式（见 4.2.2）**
- （原文摘录上传方式，通常为"通过电子招标投标交易平台递交"）

**3.2.5 开标时间（见 5.1）**
- 判断是否与投标时间一致或具体日期
- 判断价格文件不足几家不予开标
- （原文摘录）

**3.2.6 电子投标文件编制要求（见 10）**
- （原文摘录电子投标文件的编制要求以及上传要求）

**3.2.7 投标文件格式（见第六章）**
- 抄录所有投标文件格式表格
- 抄录所有商业文件、技术文件的写作内容
- 整理标题以及相应的书写要求
- **【重要】此处必须逐条原文摘录，不得省略**

#### 3.3 提取技术规范书信息

**（原文摘录，不同标书要求的技术规范书写作规范可能包含）：**

| 内容类型 | 摘录要求 |
|----------|----------|
| 项目基础情况介绍 | 原文摘录 |
| 技术规范和标准 | 原文摘录 |
| 项目人员要求 | 原文摘录 |
| 服务内容要求 | 原文摘录 |
| 其它对投标人的要求 | 原文摘录 |

#### 3.4 提取【货物清单】或【一览表】

**定位规则：**
- 用户会给定路径
- 阅读名字为【货物清单】或【一览表】字样的 excel 表
- 该文件涉及的项目已用黄色高亮标出

**摘录内容：**

| 字段 | 填写说明 |
|------|----------|
| 招标编号 | （原文填写） |
| 分标编号 | （原文填写） |
| 分标名称 | （原文填写） |
| 包号 | （原文填写） |
| 包名称 | （原文填写） |
| 专用资质业绩要求 | （原文填写，逐条摘录黄色高亮项目内容） |

#### 3.5 提取用户指定的第四份文件

**定位规则：**
- 用户会给定路径
- 阅读该路径指向的文件
- 该文件涉及的项目已用黄色或红色高亮标出

**摘录内容：**

| 字段 | 填写说明 |
|------|----------|
| 商务部分得分要求 | （原文填写） |
| 技术部分得分要求 | （原文填写） |
| 其它高亮内容 | （原文逐条摘录） |

## 注意事项

1. **【强制】原文摘录**：所有信息必须逐字原文摘录，不得简化、归纳或省略
2. **表格完整性**：所有表格内容必须完整抄录，包括所有行列
3. **条款编号保留**：保留所有章节编号和条款编号
4. **高亮标注**：黄色/红色高亮内容必须逐条摘录
5. **格式要求原文**：投标文件格式要求必须完整原文抄录
