匀变速直线运动：从加速度到位移

已知：a = dv/dt（加速度定义）

由 a = dv/dt 得 dv = a·dt

∫dv = ∫a·dt → v = at + C

t=0 时 v=v₀，C=v₀ → v = v₀ + at

由 v = dx/dt（速度定义）得 dx = v·dt

∫dx = ∫(v₀+at)·dt → x = v₀t + ½at² + C'

t=0 时 x=0，C'=0 → x = v₀t + ½at²

当 v₀=0 时：v = at, x = ½at²
