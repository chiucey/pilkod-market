# 自主进化系统 (Evolution System)

让 HTML Content Creator 技能从用户反馈中持续学习和改进。

## 工作原理

```
用户反馈 → 归档至 feedback/ → 分析是否为重复反馈
                              ├─ 2+ 次同类反馈 → 提炼为 learnings.md 规则
                              └─ 首次 → 仅记录，待积累后转化
```

## 目录结构

| 路径 | 用途 |
|------|------|
| `SKILL.md` | 进化子技能定义，反馈处理工作流 |
| `feedback/` | 原始反馈存档，按日期命名 `YYYY-MM-DD_NNN.md` |
| `learnings.md` | 提炼后的可执行规则（核心产出） |
| `changelog.md` | 技能演化版本日志 |

## 使用方式

用户给出反馈后，主 SKILL.md 路由表检测到关键词（反馈/改进/调整/重做/不好/修改），触发本模块的反馈处理流程。
