# 咖啡店会计记账凭证自动生成工具

## 功能说明

本工具用于根据银行流水和营收数据，自动生成符合咖啡店业务特点的月度记账分录。

## 主要功能

* 自动识别银行流水中的各类交易（收入、支出、手续费等）
* 根据营收数据自动计算增值税和主营业务收入
* 自动生成采购、工资、报销、消耗等分录
* 按交易时间顺序排列凭证
* 输出标准格式的Excel文件

## 使用方法

### 命令行使用

```bash
python accounting\\\\\\\\\\\\\\\_voucher.py <月份> \\\\\\\\\\\\\\\[银行流水文件] \\\\\\\\\\\\\\\[营收文件]

# 示例
python accounting\\\\\\\\\\\\\\\_voucher.py 2026-05
python accounting\\\\\\\\\\\\\\\_voucher.py 2026-05 data/银行流水.xlsx data/营收.xlsx
```

### 参数说明

|参数|必需|说明|默认值|
|-|-|-|-|
|月份|是|目标月份，格式YYYY-MM|-|
|银行流水文件|否|Excel文件路径|user\_input\_files/2026银行流水.xlsx|
|营收文件|否|Excel文件路径|user\_input\_files/2026营收.xlsx|

## 输入文件格式

### 银行流水Excel要求

必须包含以下列：

* `统计日期`: 月份标识（如 "2026-04"）
* `交易日`: 交易日期
* `交易类型`: 交易类型（如 "网联付款申请收款"）
* `借方金额（支出）`: 支出金额
* `贷方金额（收入）`: 收入金额
* `摘要`: 交易摘要

### 营收Excel要求

必须包含以下列：

* `日期`: 营收日期
* `月份`: 月份标识（如 "2026-04"）
* `POS机财务费用`: 支付手续费
* `现金收入`: 现金收入
* `1%增值税`: 增值税金额
* `银行到账收入`: 银行到账金额

## 生成的凭证类型

|凭证类型|描述|科目|
|-|-|-|
|咖啡馆收入|每日营收入账|主营业务收入、应交增值税、扫码手续费、银行存款|
|银行手续费|跨行转账手续费|财务费用-银行手续费|
|员工社保公积金|社保、公积金、个税|应付职工薪酬-社保/公积金/个税|
|采购分录|原材料采购|原材料-咖啡豆/牛奶、周转材料-耗材|
|员工报销|各类报销|管理费用-其他|
|兼职工资|兼职人员费用|管理费用-兼职人员费用|
|归还借款|股东借款归还|短期借款|
|理财赎回|理财产品赎回|银行存款、理财产品|
|工资计提|月末工资计提|管理费用-管理人员职工薪酬|
|月末消耗|原材料消耗结转|主营业务成本、原材料|

## 输出格式

生成Excel文件包含以下列：

* 交易日期、日期、凭证号、行号、摘要
* 科目编码、科目名称
* 借方本币、贷方本币
* 以及其他标准财务字段

## 注意事项

1. **借贷平衡**: 所有生成的凭证借贷金额相等
2. **日期处理**: 凭证日期统一设为月末（YYYY-MM-30）
3. **消耗数据**: 月末原材料消耗为估算值，需根据实际盘点调整
4. **工资数据**: 工资计提参考历史数据，需根据实际情况调整
