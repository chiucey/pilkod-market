## 配图生成注意事项

1. **比例要求**
   - 封面图：推荐 900x383（2.35:1）或 900x500（16:9）
   - 文中配图：推荐 800x600 或 600x400

2. **文字避免**
   - 不要在配图中添加中文文字
   - 让文字在公众号编辑器中添加

3. **版权注意**
   - 使用 AI 生成图片可规避版权问题
   - 避免使用品牌 logo 或名人照片

4. **风格统一**
   - 同一篇文章的配图风格应保持一致
   - 颜色搭配要协调

5. **适配性**
   - 考虑手机端阅读体验
   - 重要内容不要放在图片边缘
