# 账号基础设置指南

完成平台注册后，需要对账号进行统一、专业的设置。本指南提供各平台的账号设置模板和注意事项。

---

## 一、头像统一设置

### 头像制作标准

**推荐头像类型**：
```
类型1：真人商务照（推荐）
├── 穿正装或商务休闲装
├── 表情自然、微笑
├── 白色或浅色纯色背景
└── 头部居中，留白适当

类型2：品牌Logo
├── 简洁明了的设计
├── 颜色不超过2-3种
└── 便于识别和记忆

类型3：专业插画头像
├── 委托设计师定制
├── 体现专业领域特色
└── 风格统一、独特
```

**技术规格要求**：

| 平台 | 推荐尺寸 | 最小尺寸 | 格式 |
|------|---------|---------|------|
| 微信公众号 | 400×400px | 200×200px | PNG/JPG |
| 知乎 | 400×400px | 200×200px | PNG/JPG |
| 头条号 | 400×400px | 200×200px | PNG/JPG |
| 小红书 | 400×400px | 200×200px | PNG/JPG |
| 领英 | 400×400px | 200×200px | PNG/JPG |
| 百家号 | 400×400px | 200×200px | PNG/JPG |

**头像制作建议**：
```
✅ 一次性制作多个尺寸备用
✅ 保留PSD源文件方便修改
✅ 定期更新头像保持新鲜感
✅ 所有平台使用同一张头像
```

- 精益供应链讲堂
- 供应链管理内参

## 五、新账号养号期设置

### 养号期（注册后7-14天）

**目标**：建立账号初始权重，避免被判定为营销号

**每日操作**：
```
1. 浏览：每天浏览30分钟相关内容
2. 点赞：每天点赞10-20篇优质内容
3. 评论：每天评论3-5条（字数≥20字）
4. 关注：关注30-50个同领域账号
5. 收藏：收藏优质内容
```

**禁止行为**：
```
❌ 大量发布营销内容
❌ 频繁添加外链/联系方式
❌ 使用违规词汇
❌ 短时间内大量操作
❌ 发布低质量/搬运内容
```

### 养号期内容发布建议

```
第1周：发布1-2篇测试内容
├── 观察内容显示是否正常
├── 了解平台推荐机制
└── 收集用户反馈

第2周：根据反馈调整
├── 优化标题和封面
├── 调整发布时间
└── 开始建立互动
```

## 八、常见问题处理

### 问题1：账号名称被占用怎么办

```
解决方案：
1. 优先保证公众号、知乎等核心平台名称一致
2. 其他平台可使用微小差异化（如加"讲堂"）
3. 如有商标权可申诉
4. 等待对方注销后抢注
```

### 问题2：简介被平台限制怎么办

```
解决方案：
1. 删除敏感词汇（"最"、"第一"等极限词）
2. 避免直接留联系方式（放到评论区或私信）
3. 精简简介长度
4. 参考各平台合规简介模板
```

### 问题3：头像审核不通过怎么办

```
解决方案：
1. 确保头像不包含二维码、联系方式
2. 避免使用卡通人物/动漫形象（部分平台）
3. 避免过度美颜/PS
4. 使用正式着装
5. 确保面部清晰可见
```

## 九、下一步操作

完成账号基础设置后，您需要：

1. **统一设置所有平台账号**
   - 按照上述模板设置每个平台
   - 确保核心信息一致

2. **完成实名认证**
   - 实名认证是发布内容的前提
   - 部分平台原创标签需实名后申请

3. **申请原创保护**
   - 各平台申请原创标签
   - 保护内容版权

4. **开始养号期运营**
   - 每天保持活跃
   - 发布测试内容

5. **对接下来的运营进行规划**
   - 确定发布节奏
   - 规划内容选题
