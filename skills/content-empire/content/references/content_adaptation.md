# 内容分级适配方法论

基于公众号原创母版，制作3个版本的内容适配，10分钟即可完成，无需重写内容。

## 三大内容版本

### 1. 私域完整版

**适用平台**：微信公众号、视频号、钉钉公众号、飞书公众号、钉钉圈子、飞书知识库

**核心特点**：
- 保留完整长文内容
- 保留完整排版格式
- 可包含课程信息、联系方式
- 可设置私域引流钩子
- 无内容限制

**发布要点**：
- 标注原创声明
- 可直接留微信号、二维码
- 可添加课程购买链接
- 适合深度干货、体系化课程内容

---

### 2. 公域引流版

**适用平台**：今日头条、百家号、知乎、搜狐号、网易号、企鹅号、一点资讯、小红书

**核心特点**：
- 保留90%核心干货内容
- 硬广改为软引导
- 禁止直接留联系方式
- 注重算法推荐优化

**引流合规化改造**：

❌ 禁止做法：
```
"加微信领全套工具包"
"扫码添加老师微信"
"手机号：138xxxxxxx"
"私聊获取更多资料"
```

✅ 正确做法：
```
"需要工具模板的朋友，评论区留言【工具】即可领取"
"点击头像私信回复【课程】获取详情"
"更多实战案例，可关注后在主页获取联系方式"
```

**内容调整策略**：

| 原内容 | 调整后 |
|-------|-------|
| "我们的课程包括..." | "优秀的供应链课程通常包含以下模块..." |
| "立即联系顾问报名" | "建议先收藏本文，评论区交流学习心得" |
| "报名请加微信" | "相关培训信息可关注行业权威平台获取" |
| 硬性联系方式 | 评论区软引导 + 个人简介合规留联系方式 |

---

### 3. 垂直专业版

**适用平台**：领英、亿欧网、36氪、物流技术与应用官网、中国采购与供应链管理网、哈佛商业评论、盖世汽车网、中华工控网、商界评论

**核心特点**：
- 保留深度行业洞察
- 保留案例、方法论
- 弱化营销内容
- 强化专业度
- 提升行业认可度

**内容调整策略**：

| 调整方向 | 具体做法 |
|---------|---------|
| 弱化营销 | 删除"立即报名""咨询课程"等硬广 |
| 强化专业 | 增加行业术语引用、权威数据支撑 |
| 提升深度 | 扩展行业趋势分析、战略层面解读 |
| 精选案例 | 保留1-2个标杆案例深入拆解 |
| 去掉引流 | 删除所有私域引流元素 |

## 内容快速适配流程

### Step 1: 识别平台类型

根据目标平台的属性，判断属于哪一类：

```
私域平台 → 使用完整版
公域平台 → 使用引流版
垂直专业平台 → 使用专业版
```

### Step 2: 内容改造检查清单

**引流版改造检查**：
- [ ] 删除所有微信号、手机号、二维码
- [ ] 删除"立即联系""扫码"等硬广表达
- [ ] 添加评论区软引导话术
- [ ] 检查个人简介是否合规留联系方式
- [ ] 标题添加关键词利于推荐

**专业版改造检查**：
- [ ] 删除所有营销推广内容
- [ ] 增加行业术语和专业引用
- [ ] 扩展深度分析和趋势洞察
- [ ] 精选1-2个案例深入展开
- [ ] 保持内容专业严谨风格

### Step 3: 快速改造技巧

**段落精简法**（适用小红书等）：
```
原文：段落1（5行） + 段落2（4行） + 段落3（6行）
改造后：段落1（2行） + 段落2（2行） + 段落3（2行） + 段落4（2行）
```

**干货清单法**（适用小红书等）：
```
原文：一段200字的详细说明
改造后：
1. 要点1
2. 要点2
3. 要点3
4. 要点4
```

**问答结构法**（适用知乎等）：
```
原文：直接陈述观点
改造后：
问题：为什么XXX？
解决方案：XXX
案例：XXX
总结：XXX
```

|-----|------|------|---------|---------|
