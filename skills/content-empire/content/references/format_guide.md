## 各平台排版规范

### 微信公众号排版规范

**段落格式**：
- 段落长度：2-4句话/段
- 行间距：1.75或2倍行距
- 字间距：默认或1px
- 正文字号：15-16px
- 标题字号：18-22px（根据层级递减）

**排版建议**：
```
✅ 段落控制在3行以内
✅ 多用空行分隔大段落
✅ 重要内容加粗突出
✅ 适当使用emoji增加活力
✅ 配图宽度控制在640px以内
✅ 文末添加互动引导
```

### 今日头条排版规范

**段落格式**：
- 段落长度：2-3句话/段
- 行间距：1.5倍
- 正文字号：16-18px

**排版建议**：
```
✅ 标题关键词前置（前20字包含核心词）
✅ 正文开头100字内出现核心关键词
✅ 段落简洁，每段聚焦一个观点
✅ 适当分段，3-5段为宜
✅ 配图居中，与内容相关
```

### 小红书排版规范

**段落格式**：
- 段落长度：1-2句话/段
- 行间距：1.5倍
- 正文字号：14-16px

**排版建议**：
```
✅ 每段最多2行，多用换行
✅ 干货清单用数字标注
✅ 大量使用emoji（10-20个）
✅ 重点内容用符号标记：⚠️、✅、❌、💡
✅ 文末添加互动话题标签
✅ 配图用多图拼接展示
```

### 知乎排版规范

**段落格式**：
- 段落长度：3-5句话/段

## 标题字数与格式规范

### 核心平台标题规范

| 平台 | 标题字数 | 最佳字数 | 格式建议 |
|------|---------|---------|---------|
| 微信公众号 | ≤30字 | 20-26字 | 可用感叹句、疑问句 |
| 今日头条 | ≤30字 | 20-26字 | 关键词前置，可用符号 |
| 百家号 | ≤30字 | 20-26字 | 关键词前置，SEO友好 |
| 知乎 | ≤40字 | 25-35字 | 疑问句、对比句效果好 |
| 小红书 | ≤20字 | 12-18字 | 必须用emoji，可用符号 |
| 微博 | ≤48字 | 20-30字 | 可带话题标签 |
| 领英 | ≤100字 | 40-70字 | 专业正式，避免夸张 |

### 标题公式模板

**数字型标题**：
```
[数字]个[核心价值点]，快速掌握[主题]
例：5个关键步骤，快速搭建供应商评估体系
```

**疑问型标题**：
```
[痛点问题]？[解决方案]告诉你
例：供应商交期总延误？5步教你建立预警机制
```

**对比型标题**：
```
[旧方法]vs[新方法]，差距竟然这么大
例：传统采购vs战略采购，差距竟然这么大
```

**清单型标题**：
```
[核心主题]：[数字]个[要点]盘点
例：供应链降本：8个关键指标盘点
```

**悬念型标题**：
```
为什么[结果]？[行业/人群]必须知道
例：为什么你的供应商管理总是失败？采购总监必须知道这5点
```

## 标签话题使用规范

### 各平台标签数量

| 平台 | 推荐标签数 | 最大标签数 | 格式 |
|------|-----------|-----------|------|
| 微信公众号 | 3-5个 | 无限制 | #标签# |

| 百家号 | 3-5个 | 10个 | 系统推荐 |

| 小红书 | 5-10个 | 10个 | #标签# |
| 微博 | 1-3个 | 20个 | #话题# |
| 领英 | 3-5个 | 5个 | 选择行业话题 |

### 高效标签选择策略

**选标签原则**：
1. 与内容核心主题强相关
2. 有一定搜索量和讨论度
3. 目标受众常用的标签
4. 结合热度标签和长尾标签

**标签组合建议**：
```
核心标签（1-2个）：直接描述内容主题
行业标签（1-2个）：精准触达行业人群
热点标签（0-1个）：借势热度话题
长尾标签（1-2个）：覆盖细分搜索需求
```

**示例**：
```
内容主题：制造业供应链降本
标签组合：
#供应链管理 #制造业 #采购降本 #精益生产 #供应链优化
```
