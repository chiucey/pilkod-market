# Document Pro - 专业文档处理技能

## 概述

Document Pro 是一款专为 MiniMax Agent 设计的多格式文档智能处理技能，支持 PDF、DOCX、PPT、TXT、Markdown 等常见文档格式的读取、解析、内容提取与智能总结。采用纯本地处理架构，无需网络请求，保护用户隐私。

## 核心能力

- **多格式支持**：PDF、DOCX、PPT/TXT、Markdown
- **智能解析**：自动识别文档结构，提取标题、正文、表格
- **内容总结**：生成精准摘要，保留核心信息
- **关键词提取**：自动识别高频词汇与关键概念
- **结构化输出**：JSON 格式输出，便于后续处理
- **隐私保护**：全程本地计算，不上传不存储

## 支持格式

| 格式 | 扩展名 | 解析能力 |
|------|--------|----------|
| PDF | .pdf | 文本提取、页面分析 |
| Word | .docx | 段落、表格、标题 |
| PowerPoint | .pptx | 幻灯片、文本框 |
| 纯文本 | .txt | 直接读取 |
| Markdown | .md | 结构化解析 |

## 使用场景

1. **合同审查**：快速提取关键条款
2. **报告总结**：生成会议报告摘要
3. **论文解析**：提取研究要点与结论
4. **资料整理**：批量处理文档信息

## 触发词

- 解析文档、文档处理、读取文档
- 文档总结、内容总结
- 提取关键信息、关键词提取
- 格式转换、Document Pro

## 工作流程

1. 接收用户文档（上传或路径）
2. 识别文档格式
3. 调用对应解析器提取内容
4. 执行文本清洗与分段
5. 生成摘要与关键词
6. 输出结构化结果

## 配置参数

- `min_paragraph_length`: 最小段落长度（默认100字符）
- `max_summary_length`: 最大摘要长度（默认1000字符）
- `keyword_count`: 关键词数量（默认10个）
- `language`: 输出语言（zh-CN/en）
- `output_format`: 输出格式（summary/extract/full）

## 注意事项

- PDF 加密文档需要解密权限
- DOCX 需要 python-docx 库支持
- PPTX 需要 python-pptx 库支持
- 大文件处理可能需要更长时间
