# 小红书文字笔记生图

为小红书/朋友圈生成有质感的**文字笔记配图**。文字用**黑色秀丽笔手写风格**，带**飞黑（笔画尾端飞白）**、**起笔粗重收笔细尖**、**错落有致**、**上紧下松**的艺术效果。

## 适用场景

- 小红书图文笔记（3:4 竖图）
- 朋友圈 / 公众号配图
- 心情语录、励志短句、文艺短句
- 想要"有书法感、有人文味"的文字配图

## 输入格式

用户给我：

1. **1 个或多个句子**（每行一句，或用 `|` / 中文逗号 `，` 分隔）
2. **可选：背景选择**（`auto` / `随机` / 指定编号 `01-05`；默认 `auto`，即每个句子从 5 张背景中随机抽）

示例：
```
请帮我做这3句话：
- 落在你肩上的光 也正悄悄温暖着整个岁月
- 人生不是等暴风雨过去 而是学会在雨中跳舞
- 岁月不声不响 却让你懂得什么是值得
```

## 输出规格

- 尺寸：**1242 × 1660 像素**（小红书 3:4 竖图）
- 格式：PNG / JPEG
- 文字：黑色秀丽笔手写，带飞黑、起笔粗重收笔细尖
- 文字颜色：按背景自动适配
  - 浅色背景（樱花/雪原）→ **黑色字**
  - 深色背景（竹林/红枫/星空）→ **白色字**
- 蚂蚁 + 石头 + 光线/花瓣/枫叶/雪花/星空 元素保留

## 字体规范

- 字体：**Noto Serif CJK SC Bold**（系统自带，用于 PIL 精确渲染阶段）
- 字号：**160 px**（5 张统一）
- 行间距：184 px（1.15 倍字号）
- 布局：3 行布局（7+7+4 或按标点/字数分行）
- 排版：居中、整体略上移（避开蚂蚁）

## 文字分行规则

- 默认按**标点 + 字数**分行，让每行 5-8 个字、行宽不超过图宽 80%
- 短句（≤10 字）：1 行
- 中句（10-15 字）：2 行
- 长句（>15 字）：3 行
- 用户指定分行（`/` 或换行）时优先按用户来

## 工作流（两阶段流水线）

### 阶段 1：PIL 精确渲染（保文字 100% 准确）

1. 加载背景图
2. 加载字体（Noto Serif CJK Bold）
3. 按分行规则拆分句子
4. 居中渲染（颜色按背景适配：浅→黑 / 深→白）
5. 输出 1792×2400 中间产物

### 阶段 2：AI 改写（加飞黑手写质感）

调用 `image_synthesize` 工具，参数：
- `input_file`：阶段 1 输出图
- `prompt`：明确指令"只改笔触不改字，文字内容必须完全一致，黑色（白色）墨水，飞黑、起笔粗重收笔细尖、错落有致、上紧下松"
- `aspect_ratio: 3:4`
- `resolution: 2K`

### 阶段 3：Resize

AI 输出 1792×2400，resize 到 1242×1660 输出。

## 复用方式

调用此技能时，直接说"做 5 张小红书文字笔记"或"用这套背景生成文字图"，并附上句子列表即可。

## 已知限制

- 中文字数 > 25 时会拆成 4-5 行，文字会偏小（仍能看清但不够突出）
- 每张图耗时约 30-60 秒（AI 改写阶段）
- 蚂蚁是固定元素，**不能**换其他形象（除非用户提供新参考图）
- 字体风格是"飞黑手写"质感，不是真手写（基于图像模型改写）

## 扩展

- 想要新背景：把新图放到 `backgrounds/` 目录，命名为 `bg_06_xxx.png`，在 SKILL.md 表格里加一行即可
- 想要不同字体风格：改阶段 1 的字体路径，或改阶段 2 的 prompt 关键词
- 想要不同输出尺寸：改 `scripts/generate.py` 里的 `TARGET_SIZE` 变量
