## 多入口协同策略

### 引流逻辑图

```
┌─────────────────────────────────────────┐
│            人才需求池                    │
├─────────────────────────────────────────┤
│  心理人才 │ 公考人才 │ AI人才 │ 其他    │
└─────────────────────────────────────────┘
         │          │          │
    ┌────┴────┐ ┌───┴───┐ ┌────┴────┐
    │ 4个入口 │ │ 3个入口│ │ 3个入口 │
    └────┬────┘ └───┬───┘ └────┬────┘
         │          │          │
    ┌────┴──────────┴──────────┴────┐
    │       简历/沟通汇总           │
    └────┬──────────┬──────────┬────┘
         │          │          │
    ┌────┴────┐ ┌───┴───┐ ┌────┴────┐
    │ 心理岗位 │ │公考岗位│ │ AI岗位  │
    │ 转化区   │ │ 转化区 │ │  转化区  │
    └─────────┘ └───────┘ └─────────┘
```

### 岗位组合建议

**最小配置（3个岗位）**
- 1个引流岗 + 1个转化岗 + 1个储备岗

**标准配置（5个岗位）**
- 2个引流岗 + 2个转化岗 + 1个储备岗

**豪华配置（8+个岗位）**
- 3个引流岗 + 3个转化岗 + 2个储备岗

## 岗位更新频率建议

| 岗位类型 | 更新频率 | 原因 |
|---------|---------|-----|
| 引流岗 | 每周微调 | 保持曝光 |
| 转化岗 | 每两周优化 | 测试效果 |
| 储备岗 | 每月审视 | 调整方向 |
