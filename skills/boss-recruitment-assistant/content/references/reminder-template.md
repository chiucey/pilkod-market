# WorkBuddy提醒消息模板

## 紧急度标识

```
🔴 紧急：立即需要决策的人才
🟡 重要：建议当天处理的人才
🟢 普通：储备待观察的人才
```

---

## 标准提醒模板

### 模板A：高质量人才发现

```
🔴 【发现高质量人才】

类型：{人才类型}
来源：{发现渠道/岗位}

📋 基本情况
- 姓名：{姓名}
- 背景：{学历}+{经验}
- 期望薪资：{金额}/月

✨ 核心优势
1. {优势1}
2. {优势2}
3. {优势3}

⚠️ 潜在风险
- {风险描述}

💡 建议动作
- 是否建议立即跟进：是/否
- 是否建议交换微信：是/否
- 跟进优先级：{高/中/低}

回复"1"立即跟进 | 回复"0"暂不处理
```

### 模板B：可培养人才发现

```
🟡 【发现潜力人才】

类型：{人才类型}
来源：{发现渠道/岗位}

📋 基本情况
- 姓名：{姓名}
- 背景：{简要描述}
- 亮点：{核心特点}

✅ 符合条件
- 成本可控：{是/否}
- 沟通顺畅：{是/否}
- 发展意愿：{是/否}

📝 建议
建议纳入B类培养，观察1-2周后重新评估

回复"确认"加入人才库 | 回复"跳过"忽略
```

### 模板C：储备人才提醒

```
🟢 【人才库更新】

{简要描述}

此类人才将进入C类观察库，暂不主动提醒

回复"详情"查看完整信息
```

## 自定义提醒设置

### 触发条件配置

```yaml
提醒触发条件:
  能力达标:
    - 经验年限 >= 1年
    - 或有相关证书

  成本匹配:
    - 期望薪资 <= 4000元
    - 或可协商

  沟通质量:
    - 响应时间 < 30分钟
    - 表达清晰度 >= 80%

  意愿确认:
    - 明确表示愿意面试
    - 或主动询问详情
```

### 免打扰设置

```yaml
免打扰时段:
  - 23:00 - 08:00 (夜间)
  - 可设置例外：紧急人才不受限

批量提醒:
  - 非紧急人才可累积，午间/晚间统一提醒
```

## 提醒交互指令

| 用户回复 | 系统动作 |
|---------|---------|
| "1" | 立即跟进该候选人 |
| "0" | 暂不处理，标记为"待定" |
| "详情" | 发送完整人才分析报告 |
| "跳过" | 从提醒列表移除 |
| "收藏" | 加入A类优先跟进 |
| "取消" | 关闭该类提醒 |

## 消息示例：完整对话流

**系统发送：**
```

类型：公考人才
背景：某211大学法学本科，2年律所助理经验

- 法学背景扎实

风险：
- 薪资期望略高(4500)，需谈判

建议：建议立即跟进，可考虑交换微信

回复"1"立即跟进
```

**用户回复：1**

**系统响应：**
```
✅ 已记录您的选择

正在准备：
- 候选人联系方式
- 交换微信话术建议
- 面试安排备选时间

Boss直聘对话窗口已为您置顶
```
