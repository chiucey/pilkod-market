# 背景提升规划指南

## 科研提升路径

### 大学阶段科研时间轴

```
大一：打基础
├── 加入实验室/课题组
├── 学习基础科研方法
├── 参与学长学姐项目
└── 争取大创项目立项

大二：积累经验
├── 独立承担小课题
├── 参加学术竞赛（挑战杯/大创）
├── 撰写研究报告/论文
└── 争取核心期刊/会议发表

大三：产出成果
├── 主导重要科研项目
├── 发表高质量论文（SCI/核心）
├── 参加国际学术会议
└── 获取知名导师推荐信

大四：深化拓展
├── 继续深耕研究方向
├── 准备graduate school申请
└── 总结科研成果
```

## 实习规划指南

### 实习时间轴建议

```
大一暑假：认知期
├── 基础实习（家乡/线上）
├── 行业调研/职业探索
└── 培养基础职场能力

大二暑假：积累期
├── 专业相关实习（中型企业）
├── 补充行业认知
└── 准备申请材料素材

大三暑假：冲刺期
├── 名企实习（目标行业头部）
├── 获取推荐信/项目成果
└── 为秋招/留学申请加分

大四：收获期
├── 研究生申请/秋招
└── 延续实习积累

研究生：深化期
├── 暑期实习（return offer）
└── 行业深耕
```

## 语言考试规划

### 雅思/托福备考建议

**备考周期**：2-3个月集中备考为佳

| 模块 | 目标分数 | 备考重点 |
|------|----------|----------|
| 听力 | 7.0-7.5+ | 精听+场景词汇 |
| 阅读 | 7.5-8.0+ | 同义替换+速度 |
| 口语 | 6.5-7.0+ | 题库准备+流利度 |
| 写作 | 6.5-7.0+ | 逻辑结构+词汇多样 |

**考试时间建议**：
- 雅思：有效期2年，建议大二下/大三上考出理想成绩
- 托福：有效期2年，可与雅思交替备考增加机会

### GRE/GMAT规划

| 考试 | 适用范围 | 目标分数 | 备考周期 |
|------|----------|----------|----------|
| GRE | 理工/文商科硕博 | 320-330+ | 3-4个月 |
| GMAT | 商科硕士/MBA | 700+ | 3-4个月 |

**时间安排**：
- GRE：建议大三上学期完成
- GMAT：建议大三上学期完成
- 有效期内可多次考试取最优成绩

## 背景提升优先级矩阵

### 学术类学生（理工/基础学科）

```
优先级排序：
1. 科研经历 + 论文发表（核心）
2. 学科竞赛（省级/国家级）
3. GPA保持/提升（基础）
4. 实习经历（补充）
5. 海外交换/暑校（加分项）
```

### 商科类学生

```
优先级排序：
1. 名企实习（核心）
2. 商赛/案例比赛（重要）
3. 领导力活动（学生会社团）
4. 海外交换/交流项目（加分）
5. GPA + 语言成绩（门槛）
```

### 文科/艺术类学生

```
优先级排序：
1. 作品集/Writing Sample（核心）
2. 相关实习（专业领域）
3. 调研项目/社会活动
4. 海外交流/暑校
5. GPA + 语言成绩
```

## 长期规划检查清单

### 大一阶段
- [ ] 适应大学学习节奏，找到学习方法
- [ ] 了解专业方向，规划四年目标
- [ ] 参加社团/学生组织，培养软实力
- [ ] 开始英语学习，准备四六级
- [ ] 了解留学/保研/就业基本信息

### 大二阶段
- [ ] 保持高GPA（3.5+/4.0）
- [ ] 开始准备雅思/托福
- [ ] 寻找科研机会，加入实验室
- [ ] 参加1-2个学科竞赛
- [ ] 了解暑期交换/暑校项目

### 大三阶段
- [ ] 考出语言成绩（雅思7+/托福100+）
- [ ] 如需GRE/GMAT，完成考试
- [ ] 积累科研/实习成果
- [ ] 准备文书素材和推荐信
- [ ] 关注申请季信息，准备材料

### 大四阶段
- [ ] 提交申请，跟踪进度
- [ ] 准备笔面试
- [ ] 确认offer，缴纳 deposit
- [ ] 补齐条件，换取无条件offer
- [ ] 准备签证、住宿、行前准备
