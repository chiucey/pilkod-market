# 深圳图书馆图书查询与豆瓣评论技能

## 技能用途
整合深圳图书馆OPAC查询和豆瓣书评查询，帮助用户快速判断一本书是否值得借阅。

## 核心功能
1. 在深圳图书馆OPAC查询图书
2. 显示馆藏地、复本数量、在馆状态
3. 在豆瓣网站查询该书网络评论和评分

## 工作流程

### 步骤1：获取图书信息
1. 向用户询问**书名**（或ISBN）
2. 用户可选择提供作者名以缩小范围

### 步骤2：查询深圳图书馆OPAC
访问深圳图书馆OPAC系统：`https://opac.szlib.org.cn/`
- 使用 `/workspace/temp-skills/sz-library-book-checker/scripts/szlib_search.py` 脚本进行搜索
- 提取结果中的索书号、馆藏地、可借状态

**馆藏地说明：**
| 馆藏地代码 | 位置 |
|------------|------|
| SZUL-主馆-基藏 | 深圳图书馆主馆五楼基藏库 |
| SZUL-主馆-开架 | 深圳图书馆主馆三楼开架书库 |
| SZUL-主馆-少儿 | 深圳图书馆主馆二楼少儿服务区 |
| SZUL-南山分馆 | 南山图书馆分馆 |
| SZUL-福田分馆 | 福田图书馆分馆 |

### 步骤3：查询豆瓣评论
访问豆瓣读书频道：`https://book.douban.com/`
- 使用 `/workspace/temp-skills/sz-library-book-checker/scripts/douban_search.py` 脚本查询
- 提取评分、评论数量、热门短评

**评分参考标准：**
| 评分 | 推荐度 |
|------|--------|
| 9.0+ | 强烈推荐 |
| 8.0-8.9 | 推荐 |
| 7.0-7.9 | 可参考 |
| 6.0-6.9 | 谨慎选择 |
| <6.0 | 不推荐 |

### 步骤4：输出综合报告

```
📚 图书信息报告
================

书名：《xxx》
作者：xxx
ISBN：xxx

【深圳图书馆馆藏情况】
- 馆藏地：xxx
- 索书号：xxx
- 复本数：x本
- 在馆数量：x本
- 可借状态：✅可借 / ❌已借出

【豆瓣书评参考】
- 豆瓣评分：x.x/10
- 评价人数：xxx人
- 热门评论摘要：xxx

【综合建议】
xxx
```

## 脚本说明

### szlib_search.py
- 输入：书名/ISBN/作者
- 输出：馆藏信息JSON
- 使用网络请求获取OPAC数据

### douban_search.py
- 输入：书名/ISBN
- 输出：评分和评论JSON
- 使用网络请求获取豆瓣数据

## 触发条件
- 用户说"查一下xx书"
- 用户说"看看xx书在图书馆有没有"
- 用户说"这本书怎么样"并提供书名
- 用户说"帮我找xx书的馆藏情况"
