## 置信度评估标准

### 置信度评分计算

```
置信度总分 = 数据质量分(0-4) + 逻辑严密分(0-3) + 历史验证分(0-3)
```

| 总分 | 等级 | 系数 | 说明 |
|------|------|------|------|
| 9-10 | 高置信 | 1.0 | 数据完整、逻辑严密、历史验证充分 |
| 6-8 | 中置信 | 0.8 | 数据较完整、逻辑合理、部分假设 |
| <6 | 低置信 | 0.6 | 数据有限、逻辑复杂、假设较多 |

### 数据质量评分标准

| 分数 | 条件 |
|------|------|
| 4分 | 交易所官方数据100%覆盖，财报完整，无数据缺失 |
| 3分 | 交易所数据≥80%，财报完整，缺失<10% |
| 2分 | 交易所数据≥60%，财报基本完整，缺失<20% |
| 1分 | 数据来源混杂，财报存在重大缺失 |
| 0分 | 数据严重缺失，来源不可靠 |

### 逻辑严密性评分标准

| 分数 | 条件 |
|------|------|
| 3分 | 每步推理有明确依据，假设合理，无逻辑跳跃 |
| 2分 | 主要逻辑完整，少数假设需要验证 |
| 1分 | 逻辑链条存在断裂，部分假设存疑 |
| 0分 | 逻辑混乱，无法形成有效结论 |

### 历史验证评分标准

| 分数 | 条件 |
|------|------|
| 3分 | 相似案例验证成功率高(>80%)，策略历史表现优秀 |
| 2分 | 部分案例验证成功，策略历史表现中等 |
| 1分 | 历史验证案例有限，策略表现不稳定 |
| 0分 | 无历史验证数据，策略为全新设计 |

## 风险评估指标

| 风险类型 | 评估指标 | 高风险阈值 | 中风险阈值 |
|----------|----------|------------|------------|
| 财务风险 | 资产负债率 | >70% | >50% |
| 财务风险 | 流动比率 | <1 | <1.5 |
| 财务风险 | 经营现金流 | 连续2年负 | 1年负 |
| 运营风险 | 毛利率波动 | >30% | >20% |
| 运营风险 | 大客户集中度 | >50% | >30% |
| 市场风险 | 质押比例 | >50% | >30% |
| 市场风险 | 日均成交 | <1000万 | <3000万 |
| 市场风险 | 波动率 | >50% | >35% |
| 治理风险 | 商誉占比 | >30% | >20% |
| 治理风险 | 关联交易异常 | 是 | - |

### 风险系数计算

```
风险系数 = 1 - Σ(风险项权重 × 风险值) / 100
```

| 风险等级 | 风险系数 | 操作建议 |
|----------|----------|----------|
| 低风险 | 1.0 | 正常操作 |
| 中低风险 | 0.95 | 仓位降低10% |
| 中风险 | 0.85 | 仓位降低25% |
| 中高风险 | 0.70 | 仓位降低50% |
| 高风险 | 0.50 | 仓位降低80% |
| 极高风险 | 0 | 禁止持仓 |

## 回测评估指标

### 核心指标

| 指标 | 计算公式 | 合格标准 |
|------|----------|----------|
| 年化收益率 | (期末净值/期初净值)^(1/年数)-1 | >8% |
| 最大回撤 | max(峰值-谷值)/峰值 | <25% |
| 夏普比率 | (收益率-无风险利率)/波动率 | >0.8 |
| 卡玛比率 | 年化收益率/最大回撤 | >0.5 |
| 胜率 | 盈利交易数/总交易数 | >50% |
| 盈亏比 | 平均盈利/平均亏损 | >1.2 |

### 样本内外一致性

| 指标 | 要求 |
|------|------|
| 样本内/外收益差异 | <30% |
| 样本内/外最大回撤差异 | <50% |
| 样本内/外夏普比率差异 | <40% |
