# 系统化交易参数指南 v3.0

## 概述

系统化交易是指基于预先定义的量化规则进行投资决策的方法，可以减少情绪干扰，提高决策一致性。v3.0版本提供了完整的系统化交易参数体系。

## 入场规则体系

### 1. 价值入场规则

| 规则编号 | 规则名称 | 参数 | 说明 |
|----------|----------|------|------|
| V001 | PE相对低估 | PE < 行业均值 × 0.8 | 估值低于行业 |
| V002 | PB历史低位 | PB < 历史20分位 | 相对历史低估 |
| V003 | 股息率高 | 股息率 > 3% | 现金流回报 |
| V004 | PEG低估 | PEG < 1.0 | 成长与估值匹配 |

### 2. 质量入场规则

| 规则编号 | 规则名称 | 参数 | 说明 |
|----------|----------|------|------|
| Q001 | 盈利能力 | ROE > 15% | 高于盈利门槛 |
| Q002 | 盈利稳定 | ROE标准差 < 5% | 盈利稳定性 |

### 3. 趋势入场规则

| 规则编号 | 规则名称 | 参数 | 说明 |
|----------|----------|------|------|

### 4. 量价入场规则

| 规则编号 | 规则名称 | 参数 | 说明 |
|----------|----------|------|------|
| P001 | 放量突破 | 成交量 > MA20 × 1.5 | 量价配合 |

### 5. 复合入场条件


### 2. 动态仓位调整

| 市场环境 | 仓位调整 | 说明 |
|----------|----------|------|
| 牛市确认 | +10% | 顺势加仓 |
| 震荡市 | ±0% | 维持中性 |
| 熊市信号 | -20% | 防御减仓 |
| 极度悲观 | 最低20% | 极端防御 |

### 3. 仓位计算公式

```python
# 仓位计算公式
目标仓位 = (
    基础仓位 ×
    评分系数(评分/100) ×
    风险系数 ×
    市场环境系数
)

# 评分系数
评分系数 = {
    90-100: 1.2,  # A+级
    80-89: 1.0,   # A级
    70-79: 0.8,   # B+级
    60-69: 0.6,   # B级
    40-59: 0.3,   # C级
    <40: 0.0      # D级
}

# 风险系数
风险系数 = 1.0 - Σ(风险项 × 风险权重)

# 市场环境系数
市场环境系数 = {
    牛市: 1.1,
    震荡: 1.0,
    熊市: 0.7,
    极端: 0.5
}
```
