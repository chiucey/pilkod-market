# A股每日情绪分析和热点追踪

## 概述

本技能提供完整的A股盘后复盘分析，涵盖市场情绪、热点追踪、资金动向等多维度分析，输出专业级复盘报告。

## 数据获取流程

### 1. 获取当日市场数据

使用AKShare或东方财富API获取以下数据：

```
- 沪深两市涨跌停统计（过滤ST股）
- 涨跌幅分布数据（各区间家数）
- 沪深两市成交量和成交额
- 指数涨跌情况（上证、深证、创业板、科创板）
```

### 2. 获取涨停个股数据

```
- 当日涨停个股列表（含股票代码、名称、连板数）
- 涨停原因分类（公告涨停、题材涨停等）
- 跌停个股列表
```

### 3. 获取板块资金流向

```
- 行业板块涨跌排名
- 概念板块资金净流入TOP10
- 沪深港通资金流向
```

### 4. 获取龙虎榜数据

```
- 机构席位买卖统计
- 知名游资席位动向
- 当日上榜个股
```

## 注意事项

1. 所有涨停统计需过滤ST股
2. 连板高度计算需验证前一交易日是否涨停
3. 机构席位数据需标注是否为三日累计
4. 游资席位名称可能变动，数据仅供参考
