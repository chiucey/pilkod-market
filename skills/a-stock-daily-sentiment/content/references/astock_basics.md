# A股市场基础知识参考

## A股市场概述

### 交易时间
- **上午**：9:30 - 11:30
- **下午**：13:00 - 15:00
- **集合竞价**：9:15-9:25（开盘），14:57-15:00（收盘）

### 涨跌幅限制
- **主板**（沪深主板）：±10%
- **创业板/科创板**：±20%
- **ST股**：±5%
- **新股上市首日**：±44%（主板）、±无限制（创业板/科创板）

### 交易单位
- 最小买卖单位：100股（1手）
- 申报价格最小变动单位：0.01元

## 涨停板分析体系

### 核心指标
1. **涨停家数**：反映市场赚钱效应
2. **跌停家数**：反映市场亏钱效应
3. **连板高度**：反映市场风险偏好
4. **涨停封单**：反映资金攻击力度

### 连板晋级逻辑
- **首板**：当日首次涨停
- **2连板**：连续2日涨停
- **3连板**：连续3日涨停（高标股）
- **4连板+**：妖股/龙头股

### 梯队完整性评估
| 梯队状态 | 特征 | 市场含义 |
|----------|------|----------|
| 完整 | 首板多 → 中位股 → 龙头 | 健康的题材炒作 |
| 断层 | 只有龙头，无跟风 | 孤军深入，风险高 |
| 衰退 | 高位股炸板，低位补涨 | 情绪退潮信号 |

## 数据源

### AKShare 常用接口

```python
import akshare as ak

# 1. 实时行情
ak.stock_zh_a_spot_em()  # 个股实时行情

# 2. 涨停板池
ak.stock_zt_pool_em(date="20240101")  # 涨停板详情
ak.stock_zt_pool_dt_em(date="20240101")  # 跌停板详情

# 3. 板块数据
ak.stock_sector_fund_flow_rank(indicator="今日")  # 行业资金流向
ak.stock_board_concept_name_em()  # 概念板块列表

# 4. 龙虎榜
ak.stock_lhb_detail_em(date="20240101")  # 龙虎榜详情
ak.stock_lhb_yyb_ph_em(date="20240101")  # 营业部排行

# 5. 指数数据
ak.stock_zh_index_spot_em(symbol="000001")  # 指数实时行情
```

### 东方财富接口

```python
# 东财Choice数据（需要账号）
ak.stock_zt_pool_em()  # 涨停板池

# 资金流向
ak.stock_individual_fund_flow(stock="000001")
```

## 涨停原因分类

### 1. 公告驱动
- 业绩预增/扭亏
- 资产重组/收购
- 签订大合同
- 高管增持
- 股权激励

### 2. 题材驱动
- 政策利好
- 行业景气
- 技术突破
- 产品发布
- 订单落地

### 3. 资金驱动
- 龙头股连板
- 情绪回暖
- 轮动补涨

### 4. 风险修复
- 退市风险消除（摘帽）
- 债务重组完成
- 诉讼终结

## 机构席位分析

### 机构类型
- **公募基金**：长线配置
- **私募基金**：灵活操作
- **QFII/RQFII**：价值投资
- **社保基金**：稳健风格

### 机构行为信号
| 信号 | 含义 |
|------|------|
| 机构大额净买入 | 看好后市 |
| 机构席位出现在跌停 | 可能出货 |
| 多家机构分歧买入 | 存在争议 |

## 情绪指标体系

### 1. 涨跌停比
```
情绪指数 = 涨停家数 / (涨停家数 + 跌停家数)
```
- >0.8：极度乐观
- 0.6-0.8：乐观
- 0.4-0.6：中性
- 0.2-0.4：悲观
- <0.2：极度悲观

### 2. 量能趋势
- 放量上涨：健康
- 缩量上涨：谨慎
- 放量下跌：可能见底
- 缩量下跌：观望

### 3. 涨跌家数比
- 上涨家数 > 下跌家数：市场偏强
- 上涨家数 < 下跌家数：市场偏弱
