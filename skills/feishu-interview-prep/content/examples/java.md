## Java 第二面：系统设计与架构

### 设计题示例

**题目：设计一个秒杀系统**

考察维度：
1. 高并发处理（线程池、异步化）
2. 库存扣减（数据库事务、分布式锁）
3. 缓存策略（Redis、热点数据）
4. 限流熔断（Sentinel、Hystrix）
5. 防刷机制（验证码、接口幂等）
