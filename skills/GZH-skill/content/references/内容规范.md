# 职场万事通 — 内容规范参考手册

## 一、爆款标题公式库

### 8 大核心公式

| 编号 | 公式名称 | 模板 | 示例 |
|:---:|---------|------|------|
| 1 | 数字+痛点+悬念 | 在{场景}{N年}才明白的{N}个真相，第{N}个太扎心 | 在公司干了8年才明白的5个真相，第3个太扎心 |
| 2 | 反常识/颠覆认知 | 你以为{常识}？{反转} | 你以为努力就能升职？醒醒吧 |
| 3 | 对比反转 | {A}和{B}的人，差距根本不在{看似原因} | 月薪5千和月薪5万的人，差距根本不在能力 |
| 4 | 身份代入+情绪 | {年龄/身份}{事件}那天，我{行为} | 35岁被裁那天，我删掉了所有同事的微信 |
| 5 | 紧迫感/利益驱动 | {年份}{政策}，不知道这{N}条你就亏大了 | 2026年社保新规，不知道这3条你就亏大了 |
| 6 | 争议/站队 | {行为}的人，凭什么不能{期望}？ | 准时下班的人，凭什么不能升职？ |
| 7 | 清单/合集 | {身份}必须知道的{N}条{知识} | 打工人必须知道的10条劳动法常识 |
| 8 | 恐惧/避坑 | {场景}千万别做这{N}件事，做了一件就后悔 | 离职千万别做这3件事，做了一件就后悔 |

### 标题情绪钩子类型

| 情绪类型 | 触发词 | 适用选题 |
|---------|-------|---------|
| **好奇** | 真相、秘密、没人告诉你、99%的人不知道 | 职场潜规则、行业内幕 |
| **共鸣** | 扎心、说的就是我、太真实了 | 打工人日常、职场感悟 |
| **清醒** | 终于想通了、早该明白、看清了 | 职场认知升级、成长感悟 |
| **实用** | 再不知道就晚了、一定要学会、建议收藏 | 政策变化、职场技巧 |

**情绪红线：不使用愤怒、仇恨、消极、暴力类触发词（如"杀""死""毁""废""忍不了"等）**

## 二、内容形式规范

### A. 小绿书短图文（主力格式 — 70%）

**适用选题**：情绪共鸣类、实用技巧类

**结构模板：**
```
卡片1（钩子）：一句反常识或扎心的话
卡片2（痛点1）：排比金句
卡片3（痛点2）：排比金句
卡片4（痛点3）：排比金句
卡片5（升华）：总结性金句
卡片6（引导）：关注「万事通」，带你看透职场那些事
```

**风格关键词**：口语化、排比句、短句、情绪浓、像朋友聊天

**字数限制**：每张卡片 15-40 字，总字数 100-250 字

**配文（正文区）**：100-200 字，补充说明 + 引导互动

### B. 中等干货图文（辅助格式 — 20%）

**适用选题**：实用技巧类（面试、跳槽、谈薪等）

**结构模板**：
```
开头：场景代入（100字）
正文：3-5 个要点，每个要点 2-3 句（500-800字）
结尾：总结 + 引导关注（100字）
```

**字数限制**：800-1200 字

### C. 长图文（偶尔发布 — 10%）

**适用选题**：社保/劳动法科普类

**结构模板**：
```
开头：真实案例引入（100字）
正文：大白话解释 + 案例 + 可操作建议（500-800字）
结尾：金句 + 引导转发 + 引导关注（100-200字）
```

**字数限制**：800-1200 字

## 三、文字卡片图设计规范

### 尺寸
- **公众号+小红书通用**：1242 × 1660 px（3:4 竖版）
- **公众号封面图**：900 × 383 px（2.35:1 横版）

### 背景色池（莫兰迪色系）

| 色名 | 色值 | 适用情绪 |
|------|------|---------|
| 雾霾蓝 | #B0C4DE | 理性、清醒、吐槽 |
| 奶茶色 | #D2B48C | 温暖、共鸣、治愈 |
| 浅灰绿 | #C1CDCD | 清新、干货、实用 |
| 烟灰粉 | #D4A5A5 | 柔和、情感、女性向 |
| 淡鸢尾紫 | #C8BFE7 | 独特、反思、深度 |
| 暖米白 | #F5F0EB | 高级、简约、百搭 |
| 深藏蓝 | #2F4F6F | 深色系、配白字、冲击力强 |
| 碳灰 | #4A4A4A | 深色系、配白字、专业感 |

### 排版规范

- **字体**：思源黑体（标题加粗） / 站酷快乐体（正文常规）
- **文字颜色**：浅色背景用深灰 #333333，深色背景用纯白 #FFFFFF
- **文字位置**：水平居中，垂直居中偏上
- **行间距**：1.8-2.0 倍
- **上下留白**：至少占图片高度的 20%
- **每张图文字量**：不超过 40 个字

### 整套卡片的一致性要求

- 同一选题的所有卡片使用同一背景色
- 字体、字号、排版方式保持统一
- 最后一张引导关注卡片可以换一个同色系的深/浅变体

## 五、评论区互动话术模板

### 共鸣型
- "有同感的扣 1，看看有多少打工人跟我一样"
- "你们公司也这样吗？评论区说说"
- "工作几年后你最大的感悟是什么？"

### 讨论型
- "遇到这种情况你会怎么选？评论区聊聊"
- "你觉得这件事该怎么处理比较好？"
- "这种情况你会选择留下还是离开？说说你的理由"

### 求助型
- "遇到过类似情况的朋友，你们最后怎么处理的？"
- "有没有HR朋友帮忙看看，这种情况怎么办？"
- "有经验的朋友帮忙支支招"

### 引导关注型
- "关注我，每天陪你聊聊职场那些事"
- "点个关注，一起做清醒的打工人"
- "关注「万事通」，职场路上不孤单"
