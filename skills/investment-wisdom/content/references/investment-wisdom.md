# 世界顶级投资家智慧全集

## 一、巴菲特（Warren Buffett）- 价值投资之父

### 核心理念

1. **护城河理论（Economic Moat）**
   - 品牌护城河：可口可乐、苹果
   - 成本护城河：低成本制造商
   - 转换成本护城河：企业软件、医疗器械
   - 网络效应护城河：信用卡、交易所

2. **内在价值评估**
   - DCF（现金流折现）是核心方法
   - 安全边际至少20-30%
   - 模糊的正确胜过精确的错误

3. **能力圈原则**
   > "风险来自于你不知道自己在做什么"
   - 只投资你深入理解的行业
   - 承认无知是智慧的开始

### 投资戒律

```
1. 永远不要亏损
2. 永远记住第一条
3. 别人贪婪时恐惧，别人恐惧时贪婪
4. 找到足够湿的雪和长长的坡
5. 好公司应该能用合理价格买到
```

### 经典语录

- "如果你不愿意持有一个股票十年，那就不要考虑持有十分钟"
- "好公司的标准：业务清晰、护城河宽、管理层诚信有能力"
- "投资简单但不容易：找到好公司，以合理价格买入，长期持有"

## 二、芒格（Charlie Munger）- 多元思维模型

### 核心框架

1. **逆向思维**
   > "我只想知道我会死在哪里，然后永远不去那里"
   - 先排除明显错误，再寻找机会

2. **多元思维模型**
   - 心理学：理解人类认知偏差
   - 工程学：冗余、安全边际
   - 经济学：供需、激励机制
   - 生物学：适应与演化

3. **误判心理学**
   - 过度自信偏差
   - 社会认同
   - 损失厌恶
   - 锚定效应

### 投资原则

- **等待合理价格**：耐心的价值
- **极度挑剔**：宁可错过不要做错
- **跨学科学习**：构建多元知识框架
- **长期主义**：复利的力量

## 三、达利欧（Ray Dalio）- 全天候策略

### 风险平价理论

1. **全天候投资组合**
   ```
   30% 股票
   40% 长期国债
   15% 中期国债
   7.5% 黄金
   7.5% 大宗商品
   ```

2. **经济机器框架**
   - 短期债务周期：5-8年
   - 长期债务周期：75-100年
   - 生产率增长驱动长期回报

3. **分散化原则**
   - 不同资产在不同时期表现良好
   - 寻找低相关性资产
   - 避免集中风险

### 风险管理

> "不要把能生蛋的鹅杀掉"

- 首要原则：**保护本金**
- 第二原则：**记住第一条**
- 第三原则：**保持流动性**

## 四、索罗斯（George Soros）- 反身性理论

### 核心理论

1. **反身性原理**
   - 认知与现实相互影响
   - 市场不是有效的，而是有偏差的
   - 偏差会导致泡沫或崩盘

2. **开放社会理念**
   - 承认人类认知的局限性
   - 避免极端确定性和教条
   - 批判性思维

3. **大机会理论**
   > "当你犯错时，减少损失；当你正确时，增加头寸"
   - 在高不确定处下大注
   - 边缘投资（Asymmetric bets）

### 操作策略

- 识别趋势和拐点
- 快速止损，保护资本
- 敢于持有重仓

## 五、彼得·林奇（Peter Lynch）- 成长投资

### 投资分类

1. **六种股票类型**
   - 缓慢增长股：大型成熟公司
   - 稳定增长股：稳健的快速消费品
   - 快速增长股：高成长科技/零售
   - 周期股：航空、汽车、银行
   - 资产股：含大量隐藏资产
   - 困境股：转机的公司

2. **十倍股寻找**
   - 从日常生活中发现投资机会
   - 关注小型、有成长空间的公司
   - 理解公司的增长逻辑

### 投资原则

> "投资你所了解的东西"
- 日常生活中发现牛股
- 小公司比大公司更有潜力
- 关注分红和回购

## 六、邓普顿（John Templeton）- 逆向投资

### 核心策略

1. **极度悲观买入**
   > "街头溅血时是买入的最佳时机"
   - 在市场最悲观时寻找机会
   - 低估是最大的安全边际

2. **全球化配置**
   - 寻找全球价值洼地
   - 分散单一市场风险

3. **估值纪律**
   - 关注市盈率、市净率
   - 等待极端低估机会

## 七、瑞·达利欧（桥水基金）

### 风险平价详解

```
核心原则：
1. 风险平衡而非资金平衡
2. 分散到不同经济环境
3. 避免过度集中
```

### 债务危机框架

- 短期去杠杆：货币宽松
- 长期去杠杆：财政紧缩+货币贬值
- 关注债务/GDP比率

## 八、丹·皮埃尔（Dan Peirce）- 趋势跟踪

### 量化策略原则

1. **趋势跟踪**
   - 顺势而为，避免预测
   - 机械执行纪律

2. **风险管理**
   - 固定比例止损
   - 分散多策略

3. **长期视角**
   - 接受短期回撤
   - 等待长期趋势

## 九、威廉·桑代克（William O'Neil）- CANSLIM

### 选股系统

```
C = 当季每股收益（A）增长
A = 年增长率：25%+最好
N = 新产品/新管理层/新高
S = 供给需求：大成交量的上涨
L = 领导地位：相对强度排名
I = 机构认同：至少有机构买入
M = 市场方向：跟随大盘
```

### 技术分析

- 柄状形态（Cup with handle）
- 突破时买入
- 止损纪律

## 十、霍华德·马克斯（Howard Marks）- 第二层次思维

### 核心观点

1. **第二层次思维**
   > "你必须想一些别人想不到的东西"
   - 第一层：这是一个好公司
   - 第二层：所有人都知道这是好公司，定价太高

2. **周期理论**
   - 市场永远在周期中
   - 过度乐观导致风险
   - 过度悲观创造机会

3. **风险与回报**
   - 高风险不等于高回报
   - 真正的风险是永久损失
   - 好的投资往往是买入了风险资产却获得了低风险回报

### 钟摆理论

```
市场情绪的钟摆：
过度乐观 → 风险溢价低 → 危险
过度悲观 → 风险溢价高 → 机会
```
