# 每日市场复盘技能

## 核心功能

自动化执行A股、港股、美股的每日收盘复盘，生成结构化复盘报告。

## 触发条件

- 用户请求"今日复盘"
- 用户请求"复盘A股/港股/美股"
- 用户请求"市场复盘"
- 用户请求"收盘总结"
- 用户请求"每日市场总结"
- 用户请求大盘/指数分析

## 数据获取流程

### 1. A股数据获取

```python
import akshare as ak

# 当日大盘指数
index_spot = ak.stock_zh_index_spot_em()  # 沪深指数实时行情

# A股实时行情
stock_spot = ak.stock_zh_a_spot_em()  # 全部A股实时行情

# 行业板块涨跌
sector_spot = ak.stock_sector_spot(indicator="实时")  # 行业板块实时行情

# 概念板块涨跌
concept_spot = ak.stock_board_concept_spot_em()  # 概念板块实时行情

# 资金流向
money_flow = ak.stock_market_day_zj_EM()  # 市场资金流向

# 龙虎榜
top_list = ak.stock_lhb_detail_em()  # 龙虎榜详情

# 涨停跌停统计
limit_up = ak.stock_zt_pool_em(date=current_date)  # 涨停股池
limit_down = ak.stock_zt_pool_em(date=current_date, zt_limit="down")  # 跌停股池
```

### 2. 港股数据获取

```python
# 港股主要指数
hk_index = ak.stock_hk_spot_em()  # 港股实时行情

# 港股个股走势
hk_stock = ak.stock_hk_hist(symbol="00700", period="daily", adjust="qfq")

# 南向资金（港股通）
southern_flow = ak.stock_hk_south_trade统计(date=current_date)
```

## 工作流程

### 步骤1：确认复盘日期
- 优先使用用户指定的日期
- 默认使用最近交易日（A股/港股15:00后，美股04:00后）

### 步骤2：并行获取数据
- 同时获取A股、港股、美股数据
- 使用异步/并行请求提升效率

### 步骤3：数据整理与分析
- 计算涨跌幅、成交额变化
- 识别板块轮动规律
- 统计涨跌停家数
- 分析资金流向

### 步骤4：生成报告
- 按标准格式输出复盘报告
- 包含数据表格和文字分析
- 给出客观的市场研判

## 输出规范

1. **数据时效性**：明确标注数据截止时间
2. **格式统一**：使用标准Markdown表格
3. **客观描述**：避免主观臆断，用数据说话
4. **风险提示**：包含必要的免责声明
