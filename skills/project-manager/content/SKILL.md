# Project Manager - 专业项目管理技能

## 项目全流程管理框架

项目生命周期五大阶段：

```
启动 → 规划 → 执行 → 监控 → 收尾
  ↑                                ↓
  ←←←←←←← 持续改进 ←←←←←←←←←←←
```

---

## 阶段一：项目启动（Initiation）

### 立项报告生成

收到立项需求时，生成标准化立项报告，包含：

- 项目背景与问题定义
- 项目目标（SMART原则）
- 初步范围定义
- 干系人初步识别
- 风险初步评估
- 资源与预算估算
- 预期收益
- 建议与结论

### 干系人识别

生成干系人登记册：
```
| 干系人 | 角色 | 影响力 | 利益程度 | 管理策略 |
|--------|------|---------|---------|---------|
|        |      |         |         |         |
```

---

## 阶段二：项目规划（Planning）

### 项目计划结构

标准项目计划应包含：

1. **项目章程** - 项目授权文件
2. **项目管理计划** - 整体计划
   - 范围管理计划
   - 进度管理计划
   - 成本管理计划
   - 质量管理计划
   - 风险管理计划
   - 沟通管理计划
3. **基准文件**
   - 范围基准
   - 进度基准
   - 成本基准

### WBS 工作分解结构

将项目分解为可管理的工作包：

```
项目
├── 子项目1
│   ├── 工作包1.1
│   │   └── 任务1.1.1
│   └── 工作包1.2
├── 子项目2
│   └── ...
└── 项目管理活动
```

### 里程碑计划

定义关键里程碑：
```
M1: 项目启动 - [日期]
M2: 方案确认 - [日期]
M3: 开发完成 - [日期]
M4: 测试通过 - [日期]
M5: 上线交付 - [日期]
M6: 项目收尾 - [日期]
```

### 风险管理

**风险登记册格式：**
```
| ID | 风险描述 | 影响 | 概率 | 风险值 | 应对策略 | 责任人 |
|----|----------|------|------|-------|---------|--------|
| R1 |          |      |      |       |         |        |
```

## 阶段三：项目执行（Execution）

### 任务管理

日常任务跟踪，格式：
```
当前执行任务：[任务名称]
负责人：[姓名]
截止日期：[日期]
完成度：[XX%]
阻塞问题：[有/无]
```

自动生成项目周报格式：
```

### 📊 本周进展
| 任务 | 负责人 | 状态 | 完成度 |
|------|--------|------|--------|
|      |        |      |        |

### 📅 下周计划
| 任务 | 负责人 | 计划完成度 |
```

## 阶段四：项目监控（Monitoring & Controlling）

### 项目仪表盘

定期生成项目状态快照：
```
项目健康状态：[🟢绿 / 🟡黄 / 🔴红]

进度指标：
  - 计划完成：XX%
  - 实际完成：XX%
  - 偏差：±XX%

质量指标：
  - 测试通过率：XX%
  - 缺陷修复率：XX%

成本指标：
  - 预算：XX万元
  - 实际支出：XX万元
  - 偏差：±XX%
```

### 进度偏差分析

当项目进度偏差超过阈值（默认10%）时，生成偏差分析报告：
- 偏差原因分析
- 影响评估
- 纠正措施建议
- 预防措施

## 阶段五：项目收尾（Closing）

### 项目总结报告

项目结束时生成完整项目总结：
```

### 一、项目概况
- 项目名称：
- 项目经理：
- 项目周期：
- 项目状态：[已完成/提前终止/暂停]

### 二、目标达成情况
| 目标 | 预期结果 | 实际结果 | 达成率 |
|------|---------|---------|--------|
|      |         |         |        |

### 三、关键成果
- 交付物清单
- 里程碑达成情况
- 质量评估

### 四、经验教训
**成功因素：**
1. ...
**改进机会：**
1. ...

### 五、资产归档
- 文档归档状态：[已完成/待归档]
- 知识沉淀：[内容清单]
```

## 常用文档模板

当用户需要投标准备时，生成投标文件框架。

1. 文档概述
2. 用户画像
3. 功能需求
4. 非功能需求
5. 验收标准
6. 风险与假设
