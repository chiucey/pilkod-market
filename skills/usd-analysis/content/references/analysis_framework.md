# USD Analysis Framework

## 技术分析框架

### 1. 趋势判断标准

**上升趋势：**
- 价格高于均线系统
- 均线多头排列（MA5 > MA20 > MA60）
- 高点不断抬高，低点不断抬高

**下降趋势：**
- 价格低于均线系统
- 均线空头排列（MA5 < MA20 < MA60）
- 高点不断降低，低点不断降低

**盘整/震荡：**
- 价格围绕均线上下波动
- 无明显方向性趋势

### 2. 关键支撑阻力位识别

1. **历史高低点**：前期重要高低点
2. **整数关口**：如 100、105、110 等
3. **斐波那契回撤位**：38.2%、50%、61.8%
4. **成交密集区**：价格多次停留的区域

## 基本面分析框架

### 1. 美联储政策评估

**鹰派信号：**
- 加息预期升温
- 缩表加速
- 官员讲话偏紧缩
- 点阵图显示更高利率路径

**鸽派信号：**
- 降息预期升温
- 扩表或放缓缩表
- 官员讲话偏宽松
- 点阵图显示更低利率路径

## 评分体系

### 综合评分计算

```
技术面得分 = (趋势得分 × 0.4) + (动量得分 × 0.3) + (波动性得分 × 0.3)
基本面得分 = (货币政策得分 × 0.4) + (经济数据得分 × 0.4) + (财政状况 × 0.2)
市场情绪得分 = (机构持仓 × 0.4) + (投机仓位 × 0.3) + (波动率 × 0.3)
综合评分 = (技术面得分 × 0.35) + (基本面得分 × 0.45) + (市场情绪 × 0.2)
```

### 评分解读

- **8-10分**：强烈看多
- **6-8分**：轻度看多
- **4-6分**：中性
- **2-4分**：轻度看空
- **0-2分**：强烈看空

## 风险因素清单

1. **政策意外风险**：美联储政策突然转向
2. **数据黑天鹅**：重大经济数据大幅偏离预期
3. **地缘政治风险**：重大国际事件冲击
4. **流动性风险**：市场流动性急剧下降
5. **趋势反转风险**：长期趋势突然反转
