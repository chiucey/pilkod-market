# 毕业论文智能修改与终审系统（增强版）

## 核心功能概览

本技能提供四大模块的毕业论文修改与审核服务：

| 模块 | 功能数 | 核心能力 |
|------|--------|----------|
| 模块一：智能分割与协同处理 | 5项 | 自动分章、逐段处理、全局合并、断点续传 |
| 模块二：内容修改与深度优化 | 22项 | 润色/降重/摘要/结论/引言/标题优化等 |
| 模块三：最终稿审核与修正 | 12项 | 封面检查/目录核对/文献终审/盲审处理等 |
| 模块四：自我审查与迭代修正 | 3项 | 修改并自查/循环优化/全局质量诊断 |

## 模块一：智能分割与协同处理

### 1. 智能分割

**触发指令**：
- "分割论文"、"分章处理"、"按章节处理"
- 粘贴含多级标题的长文档时自动识别

**执行流程**：
1. 自动识别标题层级：
   - 一级标题：`第X章`、`第X部分`
   - 二级标题：`一、`、`（一）`、阿拉伯数字编号
   - 三级标题：`1.`、`(1)`、小写字母编号
2. 按章→节→小节拆分文档结构
3. 超长段落（>1500字）以自然段切分
4. 为每个分块生成上下文摘要

**输出**：
- 分割大纲（章节目录+字数统计）
- 处理计划确认表单

---

### 2. 处理计划确认

**触发指令**：
- "确认计划"、"按此处理"、"开始处理"

**执行流程**：
用户确认前展示：
```
论文分割结构：
├── 第1章 绪论 [约3000字]
├── 第2章 文献综述 [约4500字]
│   ├── 2.1 国外研究现状
│   └── 2.2 国内研究现状
├── 第3章 研究方法 [约5000字]
│   ├── 3.1 研究框架
│   └── 3.2 数据收集
...
总章节数：8章 | 总字数：约50,000字
```

用户可指定：
- "优先处理第3-5章"
- "跳过第2章"
- "只处理结论部分"
- "针对第4章进行深度优化"

---

### 3. 逐段处理与进度播报

**触发指令**：
- "逐段润色"、"处理全部"、"继续处理"

**执行流程**：
1. 按序处理每个章节
2. 维护上下文状态：
   - **前文术语表**：记录已处理的专有术语
   - **核心论点摘要**：记录主要论点位置
3. 逐段输出结果并显示进度
4. 术语统一检查（与前文术语表对比）

**进度格式**：
```
[进度] 已完成 第2章 的润色 [3/12]
[进度] 正在处理 第3章 3.2节...
[进度] 已完成 第4章 的降重 [7/12]
```

---

### 4. 全局一致性合并

**触发指令**：
- "合并全文"、"输出定稿"、"合并检查"

**执行流程**：
1. **结构核查**：
   - 章节、节、小节编号连续性检查
   - 补充缺失的小节标题
2. **编号校验**：
   - 图、表、公式编号连续性
   - 正文引用与编号匹配
3. **指代替换**：
   - 将"本章""下图""上述"等替换为具体引用
   - 示例：`"如图3-2所示" ← "如下图所示"`
4. **过渡优化**：
   - 检测拼接处
   - 自动生成或优化过渡句
5. **输出**：
   - 合并后全文
   - 《合并处理说明》文档

---

### 5. 智能断点续传

**触发指令**：
- "继续处理"、"断点续传"、"恢复任务"

**执行流程**：
1. 自动定位未完成段落（基于处理标记）
2. 显示已完成的章节列表
3. 提供选项：
   - "继续处理剩余部分"
   - "处理全部"（含已完成部分重新处理）

## 模块二：内容修改与深度优化（22项）

### 原有15项功能

#### 2.1 润色/学术润色

**触发指令**：
- "润色"、"学术润色"、"改通顺"、"改口语"

**执行标准**：
- 口语化表达 → 学术语言
- 修正病句、搭配不当、标点错误
- 保持原意不变

**输出格式**：
```markdown
【润色结果】

原文：[原段落]
改后：[润色后段落]

修改说明：
- "我觉得" → "本文认为"（口语→学术）
- "差不多" → "基本一致"（模糊→精确）
```

---

#### 2.2 降重/改写

**触发指令**：
- "降重"、"改写"、"降低查重"、"降低重复率"

**执行标准**：
- 深度改写，句式重组
- 同义替换，语态转换
- 保留原意，核心关键词除外

**输出格式**：
```markdown
【降重结果】

原文：[原段落]
改后：[改写后段落]

改写策略：
- 主动句 → 被动句
- 拆句合并
- 顺序调整
查重预估：下降约15-20%
```

---

#### 2.3 摘要优化

**触发指令**：
- "摘要"、"优化摘要"、"生成摘要"

**执行标准**：
- 控制在300字以内
- 包含四要素：
  1. **研究背景**：问题/缺口
  2. **研究方法**：手段/框架
  3. **研究结果**：主要发现
  4. **研究结论**：价值/意义

**输出格式**：
```markdown
【摘要（300字）】

[摘要正文]

关键词：关键词1；关键词2；关键词3；关键词4；关键词5
```

---

#### 2.4 英文摘要

**触发指令**：
- "英文摘要"、"中译英"、"翻译摘要"

**执行标准**：
- 150-250词
- 学术英语表达
- 时态正确（背景过去时，方法现在时，结果现在时）

**输出格式**：
```markdown
【Abstract】

[英文摘要正文]

Keywords: keyword1; keyword2; keyword3; keyword4; keyword5
```

---

#### 2.5 结论/提炼结论

**触发指令**：
- "结论"、"提炼结论"、"写结论"

**执行标准**：
- 500-800字
- 分点概括研究结论
- 局限性与展望

**输出格式**：
```markdown
【结论】

一、主要结论
1. ...
2. ...

二、研究局限
...

三、未来展望
...
```

---

#### 2.6 引言/优化引言

**触发指令**：
- "引言"、"优化引言"、"写引言"

**执行标准**：
- 漏斗式结构
- 研究背景 → 研究缺口 → 本文贡献

**输出格式**：
```markdown
【优化后引言】

1. 研究背景（宽泛）
2. 国内外研究现状（聚焦）
3. 研究缺口（精准定位）
```

## 错误处理

### 文档结构识别失败
- 提示用户手动指定章节划分
- 询问："请用【第X章】标记章节起始位置"

### 处理中断
- 保存当前进度
- 提供断点续传功能
- 显示已完成的章节列表

### 格式识别错误
- 使用保守策略（不自动修正不确定项）
- 提示用户确认
- 在报告中列出存疑项
