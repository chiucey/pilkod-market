## 功能详细说明

### 润色标准

**口语化表达识别**：
- "我觉得" → "本文认为"
- "差不多" → "基本一致"
- "这个东西" → "该方法"
- "非常" → 根据语境选择精确词汇

**学术表达特征**：
- 使用学科术语
- 被动语态
- 客观陈述
- 逻辑连接词

### 降重策略

1. **句式重组**：主动句↔被动句、长句拆短
2. **同义替换**：使用近义词、专业术语替换
3. **语序调整**：重新排列句子成分
4. **表达转换**：描述性→定义性、具体→抽象

**查重预估**：深度改写后重复率下降15-25%

### 摘要四要素

```
1. 研究背景（2-3句）
   - 研究领域概述
   - 存在的问题

2. 研究方法（1-2句）
   - 采用的研究方法
   - 研究框架

3. 研究结果（2-3句）
   - 主要发现
   - 关键数据

4. 研究结论（1-2句）
   - 研究价值
   - 应用前景
```

### 结论结构

```
一、主要结论（500-600字）
   1. 结论一
   2. 结论二
   3. 结论三

二、研究局限（100-150字）
   - 数据局限
   - 方法局限

三、未来展望（100-150字）
   - 研究方向
   - 应用拓展
```

### 引言漏斗式结构

```
广泛背景 → 聚焦研究 → 精准缺口 → 本文贡献

第1段：研究领域宏观背景（宽）
第2段：国内外研究现状（收窄）
第3段：现有研究的不足与缺口（精准）
第4段：本文的研究目的与内容（本文）
```
