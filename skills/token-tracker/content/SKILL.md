# Token 消耗追踪器

实时监控并记录 AI 对话中的 token 消耗，帮助你了解资源使用情况。

## 🎯 功能

| 功能 | 说明 |
|------|------|
| **实时消耗** | 查看当前会话的 token 消耗 |
| **分步记录** | 记录每次工具调用的消耗 |
| **统计分析** | 分析消耗分布，找出耗能大户 |
| **报告生成** | 导出消耗报告 |

## ⚡ 快速使用

```
"查看当前消耗"
"生成消耗报告"
"哪些操作最耗 token?"
"分析这次对话的 token 消耗"
```

## 🔧 使用方式

### 1. 实时查看
在对话中直接询问：
```
"现在用了多少 token?"
```

### 2. 深度分析
```
"分析这次对话的 token 消耗"
"哪些工具最耗 token?"
```

## 📊 信息来源

通过 `session_status` 工具获取：

| 字段 | 说明 |
|------|------|
| `Tokens in` | 输入 token 数量 |
| `Tokens out` | 输出 token 数量 |
| `Cost` | 花费金额 |
| `Context` | 上下文使用量 |

## 📁 记录存储

消耗记录保存在：
- `/workspace/memory/token-usage/` - 每日消耗日志

## 🔄 典型消耗场景

| 操作 | 预估消耗 |
|------|----------|
| 读取文件 | 低 (1-5KB) |
| 搜索网页 | 中 (10-50KB) |
| 浏览器操作 | 高 (50-200KB) |
| 生成图片 | 很高 (500KB+) |
| 长对话累积 | 随轮次增加 |

## ⚠️ 注意事项

- Token 消耗与输出长度、上下文复杂度正相关
- 建议定期查看消耗报告，优化使用方式
- 可设置阈值提醒（待开发）
