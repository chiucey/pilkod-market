## 一、数据源与更新频率

### 1. 气候模式数据

| 模式 | 数据来源 | 更新频率 |
|------|----------|----------|
| ENSO | NOAA、IRI | 每周 ENSO 周报 |
| IOD | BOM、IRI | 每月模式分析更新 |
| AO/NAO | NOAA CPC | 每周更新 |
| MJO | NOAA、ECMWF | 每日更新 |

### 2. 核心产区天气数据

**监测指标：**
- 温度（均值、极值、距平）
- 湿度
- 降雨（累计、强度）
- 土壤墒情
- 极端事件（热浪、寒潮、霜冻、洪涝、干旱）

**数据来源：**
- USDA Crop Progress
- Weekly Weather Bulletin
- 中国农业部门周报
- WMO 全球气候监测报告

**更新频率：** 每周更新，包含最近 14 天实况 + 未来 1–3 个月展望

### 3. 农作物生长阶段

**数据源：** 官方作物周报、卫星遥感（NDVI）

**四个关键阶段：**
1. 播种/出苗期
2. 营养生长期
3. 关键产量形成期（开花/结荚/灌浆/糖油分积累）
4. 成熟/收获期

### 4. 历史均值参考与异常阈值

**气象指标：** 与历史同期（30年气候均值）对比，显著偏离标记异常

**阶段异常量化阈值：**

| 生长阶段 | 异常指标 | 阈值 |
|----------|----------|------|
| 播种/出苗期 | 播种进度落后 | ≥ 3 天 |
| 营养生长期 | 长势指数偏差 | ≥ 10% |
| 关键产量形成期 | 开花/结荚/灌浆偏差 | ≥ 10% |
| 成熟/收获期 | 成熟百分比偏差 | ≥ 10% |

## 二、分析模块

### 模块1：气候模式判断

**监测模式：** ENSO、IOD、AO/NAO、MJO

**输出要素：**
- 当前状态：弱 / 中等 / 强
- 趋势判断：增强 / 减弱 / 维持
- 强度数值：ONI 指数（ENSO）、DMI 指数（IOD）等

**模式叠加评分计算：**
```
风险指数 = 异常幅度 × 模式强度系数
```

| 模式强度 | 系数 |
|----------|------|
| 弱 | 0.3 |
| 中等 | 0.6 |
| 强 | 1.0 |

### 模块2：农业气象异常识别

**监测指标体系：**

| 指标类别 | 具体指标 |
|----------|----------|
| 温度 | 均温距平、高温日数、低温日数 |
| 降水 | 累计降雨、降雨距平百分比、强降水日数 |
| 土壤 | 土壤湿度、土壤温度、墒情指数 |
| 极端 | 干旱天数、过湿天数、热浪、寒潮、霜冻、洪涝 |

**异常识别三要素：**
1. 偏离历史均值幅度与持续时间
2. 是否落在核心产区
3. 是否落在关键生长阶段窗口

**极端事件权重矩阵：**

| 极端事件 | 关键阶段 | 权重等级 |
|----------|----------|----------|
| 洪涝 | 播种/出苗期、关键产量形成期 | 高 |
| 高温热浪 | 营养生长期、关键产量形成期 | 增加不利 |
| 霜冻 | 播种/出苗期 | 高风险 |
| 冰雹/台风 | 特定作物阶段 | 极高 |
| 干旱 | 全阶段 | 中-高 |
| 寒潮 | 越冬期、播种期 | 中 |

### 模块3：生长阶段监控

**四阶段定义：**

| 阶段 | 主要影响 | 关键参数 |
|------|----------|----------|
| 播种/出苗期 | 出苗推进速度、墒情条件 | 土壤温度、水分 |
| 营养生长期 | 植株长势、营养积累 | 水热条件、光照 |
| 关键产量形成期 | 开花/结荚/灌浆、糖油分形成 | 温差、降水 |
| 成熟/收获期 | 收获进度、品质、损失率 | 晴雨比例、干燥度 |

**阶段判断逻辑：**
- 当前阶段落地状态与历史同期对比
- 阶段异常 → 提升该阶段作物影响权重
- 跨阶段异常累积效应评估

### 模块4：产区权重系统

**产区分类与权重：**

| 产区角色 | 权重系数 | 说明 |
|----------|----------|------|
| 核心主产区 | 1.0 | 全球最大产区，影响价格走势 |
| 次主产区 | 0.5 | 重要补充，影响区域供需 |
| 非产区 | 0 | 忽略 |

**跨产区同向异常组合：**

| 组合类型 | 信号强度 |
|----------|----------|
| 核心产区 + 次主产区同向异常 | 极高权重 |
| 多核心产区同向异常 | 极强信号 |
| 单核心产区异常 | 高信号 |
| 仅次主产区异常 | 中信号 |
| 核心产区方向不一致 | 降低置信度 |

### 模块5：阶段化影响映射

**作物-阶段-影响对应表：**

| 品种 | 播种/出苗期 | 营养生长期 | 关键产量形成期 | 成熟/收获期 |
|------|-------------|------------|----------------|-------------|
| 白糖 | 出苗率、苗期长势 | 分蘖、茎伸长 | 糖分积累、茎粗 | 含糖量、收获损耗 |
| 大豆 | 出苗率、苗齐度 | 株高、叶面积 | 结荚数、粒重 | 蛋白质含量 |
| 棕榈油 | 定植成活率 | 果穗发育 | 果串重量、油分 | 产量、品质 |
| 菜籽 | 出苗、苗期抗性 | 开盘度、抽薹 | 角果发育、灌浆 | 含油量 |
| 棉花 | 出苗、保苗率 | 株高、果枝数 | 开花、结铃 | 纤维品质 |

**影响方向判断：**
- 异常强度超过正常区间 → 提高不利判断权重
- 过湿/过干 → 可能方向反转
- 适度有利情况需说明阈值范围

### 模块6：假设分析框架

**三种假设情景：**

| 假设类型 | 触发条件 | 输出描述 |
|----------|----------|----------|
| 基准假设 | 当前异常 + 气候模式最可能路径 | 基本维持现状判断 |
| 偏风险假设 | 异常强度升级或模式异常加强 | 产量前景承压 |
| 偏改善假设 | 异常修复或未继续升级 | 产量前景改善 |

**产出前景评级：**
- 偏改善
- 基本稳定
- 小幅承压
- 明显承压
- 暂不明确

### 模块7：风险评估

**方向反转风险：** 高 / 中 / 低

**置信度评估：** 高 / 中 / 低

## 五、执行风格指南

### 核心原则
1. **先结论后逻辑** — 开门见山给出判断，再展开分析依据
2. **用词明确** — 避免模糊表述，使用具体数值和明确结论
3. **适度有利说明** — 解释有利影响的阈值范围，过量可能反转

### 判断标准
- **有利：** 气象条件落在作物适宜区间内
- **中性：** 无显著异常或异常不落在关键产区/阶段
- **不利：** 异常超出容忍阈值且落在核心产区关键阶段

### 分析优先级
1. 首先识别当前异常是否落在**核心产区**
2. 其次判断是否落在**关键生长阶段窗口**
3. 最后综合评估**异常强度和持续时间**

### 假设分析要求
- 基准假设必须基于当前异常 + 最可能气候路径
- 偏风险和偏改善假设需明确触发条件
- 三种假设的产出前景需保持逻辑一致性

## 六、分析执行示例

### 示例：ENSO 背景下大豆产区分析

**背景信息：**
- ENSO 状态：中等强度拉尼娜（ONI = -1.2°C）
- 监测时间：2024年3月
- 美国大豆：处于播种准备期
- 巴西大豆：关键产量形成期末期

**分析流程：**

1. **气候模式判断**
   - ENSO：中等拉尼娜，维持
   - 对大豆影响：阿根廷产区偏干，巴西产区接近正常

2. **产区权重计算**
   - 美国核心产区（权重1.0）
   - 巴西核心产区（权重1.0）
   - 阿根廷次主产区（权重0.5）

3. **阶段判断**
   - 美国：播种/出苗前期，土壤温度偏低
   - 巴西：灌浆完成期，即将进入收获

4. **综合判断**
   - 美国产区：低温延迟播种 → 小幅承压
   - 巴西产区：天气接近正常 → 基本稳定
   - 阿根廷产区：偏干但处于收获末期 → 影响有限

5. **假设分析**
   - 基准：拉尼娜维持 → 美国播种可能延迟1-2周
   - 偏风险：拉尼娜增强 → 干旱风险上升
   - 偏改善：ENSO转向中性 → 天气条件改善
