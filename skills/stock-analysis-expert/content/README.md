# A股超短线打板复盘专家

## 📋 简介

这是一个专为 A 股超短线交易者设计的专业复盘专家 Skill，基于 MiniMax Agent 平台开发。本 Skill 封装了完整的短线交易分析体系，包括情绪周期判断、龙头股识别、涨停板深度分析、次日策略建议等核心功能。

## ✨ 核心功能

### 1. 情绪周期分析
- 七阶段情绪周期识别（冰点期 → 退潮期）
- 量化情绪温度计算
- 仓位动态调整建议

### 2. 涨停板分析
- 涨停家数统计与时间分布
- 板块分布热力图
- 封板质量评估（封成比、换手率）
- 连板股追踪

### 3. 龙头股识别
- 空间龙、板块龙、日内龙识别
- 龙头股走势分析
- 资金流向追踪
- 弱转强信号捕捉

### 4. 次日策略建议
- 竞价预期设定
- 关键价位预警
- 仓位管理方案
- 风险提示

## 📊 核心指标解读

### 封成比

```
封成比 = 封单金额 / 成交金额 × 100%
```

| 封成比 | 次日预期 | 操作建议 |
|--------|----------|----------|
| >50% | 高开5%+，连板预期强 | 积极持有 |
| 30%-50% | 高开3%-5% | 持有观察 |
| 10%-30% | 开盘强度一般 | 考虑减仓 |
| <10% | 大概率低开 | 及时止损 |

### 情绪温度

```
情绪温度 = (涨停家数 × 2 - 跌停家数 × 1.5) / 100
```

| 温度区间 | 市场状态 | 操作建议 |
|----------|----------|----------|
| <20 | 冰点 | 空仓等待 |
| 20-40 | 偏冷 | 轻仓试错 |
| 40-60 | 中性 | 正常操作 |
| 60-80 | 偏热 | 重仓参与 |
| >80 | 亢奋 | 边打边退 |

## ⚠️ 风险提示

1. **超短线风险高**：本 Skill 仅供参考，不构成投资建议
2. **严格执行止损**：单票亏损超过7%必须止损
3. **仓位管理**：根据情绪周期动态调整仓位
4. **只做主升**：不参与调整，只做主升段行情

## 🔧 故障排除

### 数据获取失败
- 检查网络连接
- 尝试切换数据源
- 使用 batch_web_search 作为备用

### 分析结果异常
- 核实输入的日期是否正确
- 确认市场类型设置
- 检查股票代码是否有效
