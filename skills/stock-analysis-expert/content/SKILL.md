# A股超短线打板复盘专家 Skill

## 概述

本 Skill 封装了专业的 A 股超短线打板复盘能力，集成了情绪周期分析、龙头股识别、涨停板深度分析、次日交易策略建议等核心功能。适用于短线交易者、涨停板敢死队成员以及专业投研人员。

## 核心能力

### 1. 情绪周期判断

通过量化指标综合评估市场情绪所处阶段：

| 阶段 | 特征 | 仓位建议 | 核心指标 |
|------|------|----------|-----------|
| ❄️ 冰点期 | 龙头杀跌20-30%，跌停>涨停 | 0-2层 | 涨停<50家，跌停>50家 |
| 🌱 混沌期 | 板块无序轮动，无主线 | 1-3层 | 连板高度<4板 |
| 🔥 启动期 | 打破4板空间，有板块效应 | 3-5层 | 出现3板+个股 |
| 🚀 发酵期 | 连板增多，赚钱效应 | 5-8层 | 连板家数>15家 |
| ⭐ 主升期 | 龙头加速，6-7板 | 8-10层 | 成交额>1.2万亿 |
| 🎉 高潮期 | 亢奋，风险来临 | <5层 | 龙头缩量加速 |
| 🍂 退潮期 | 中位股跳水，亏钱效应 | 0-1层 | 炸板率>40% |

### 2. 涨停板深度分析

- **时间分布统计**：早盘（9:30-10:00）、上午（10:00-11:30）、下午（13:00-14:00）、尾盘（14:00-15:00）
- **板块分布追踪**：按行业、概念、地区三维分类统计
- **封板质量评估**：基于封成比、封单金额、换手率等指标

### 3. 龙头股识别标准

| 龙头类型 | 定义 | 识别特征 |
|----------|------|----------|
| 空间龙 | 市场最高板 | 连板高度最高 |
| 板块龙 | 单一题材领涨 | 率先涨停、封单最大 |
| 日内龙 | 当日涨幅最高 | 带动板块集体涨停 |
| 容量龙 | 板块中军 | 成交额大、走势稳健 |

### 4. 次日交易策略

- 竞价预期设定
- 关键价位预警
- 仓位动态调整方案
- 止损止盈纪律

## 技术指标计算公式

### 封成比
```
封成比 = 封单金额 / 成交金额 × 100%
```

| 封成比 | 次日预期 | 操作参考 |
|--------|----------|----------|
| >50% | 高开5%+，连板预期强 | 积极持有 |
| 30%-50% | 高开3%-5% | 持有观察 |
| 10%-30% | 开盘强度一般 | 考虑减仓 |
| <10% | 大概率低开 | 及时止损 |

### 情绪温度
```
情绪温度 = (涨停家数 × 2 - 跌停家数 × 1.5 - 中位股跌幅 × 0.5) / 100
```

## 注意事项

1. **风险控制**：超短线打板是高风险高收益策略，所有分析仅供参考
2. **止损纪律**：单票亏损超过7%必须止损
3. **仓位管理**：根据情绪周期阶段动态调整仓位
4. **只做主升**：不参与调整，只做主升段
