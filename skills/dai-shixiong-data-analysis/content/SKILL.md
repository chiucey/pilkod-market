## 五、知识库核心内容

### 5.1 职业发展问答（连麦逐字稿精华）

#### 5.1.1 转正与职场适应

**Q: 如何才能百分百转正？**
A: 转正的核心不是完成合同上的绩效，而是成为公司离不开的人。公司觉得你"能用"是最基础的要求，领导想要保你，你怎么都能活；领导想让你走，你怎么都会出局。最重要的是让领导离不开你——当他在这家公司被裁时，还愿意把你带走。

**Q: 试用期被裁的核心原因是什么？**
A: 只有两种可能性：
- 第一种是能力问题，基础能力跟不上
- 第二种是意识问题，自我意识过剩，不愿意配合和迁就别人

**Q: 如何成为一个公司一定会需要的人？**
A: 做好三件事：
1. 做需要人做但大家不愿意做的事
2. 做需要人做但很难的事，做到你肯定能留任
3. 做脏活、累活和杂活，主动承担

**Q: 职场中如何处理与领导的关系？**
A: 记录领导和同事的所有需求，观察他们情绪什么时候爆发，区分哪些是：
- 你能做且愿意做的事
- 能做但不愿意做的事
- 做不到但愿意做的事

精髓是：你不需要为领导做成什么，你只要愿意为他做就行。遇到难的事情第一个冲上去最关键。

**Q: 遇到不好的领导怎么办？**
A: 如果你觉得一个领导不值得你付出，应该早点做好觉悟。为不值得的人付出，对双方都是折磨。你要果断决定是走还是留，不要在中间状态自我折磨。实在要走时，应该少干一些事，等公司裁你而不是自己离职，争取一个月赔偿即可。

#### 5.1.2 简历与面试

**Q: 简历上如何体现多层价值？**
A: 一件事在商业化过程中有多层价值：
- **执行层**：把事情做完
- **拆分层**：课题分离，分清楚一件事还是两件事
- **梳理层**：对方需要什么、逻辑清晰
- **决策层**：做还是不做、为什么做
- **探索层**：接触新信息、成长迭代

**Q: 简历怎么写才能被面试官认可？**
A: 简历上要写的是公司想让你干的事，不是你已经干的事。没写就等于不会。关键是按照新岗位的需求，重新理解和梳理旧岗位的工作内容，掌握新技能后模拟做一遍，最后输出一份符合新岗位要求的工作经历。

**Q: 如何回答空窗期的问题？**
A:
- 短期空窗（1-6个月）：强调主动规划、技能提升或目标调整
- 中长期空窗（6个月以上）：突出有价值的经历

关键是把这段时间转化为"增值期"，强调能力成长而非时间消耗，关联应聘岗位。

**Q: 面试中如何讲好项目经历？**
A: 使用STAR法则但不要生硬套用。
- 背景要精准描述业务问题
- 目标要定性和定量
- 过程要系统展开（尤其是"问题与解决"部分）
- 结果要有具体数据

更重要的是能讲出自己从项目中学到的经验规律和人生感悟。

#### 5.1.3 业务分析能力

**Q: 如何提升数据分析能力？**
A: 把手头的事做好已经是非常高的要求。问自己几个问题：
- 有没有完成这件事？
- 做这件事有没有收获到经验？
- 能不能做得更好？
- 最后的结果回报有没有拿出来？

只要你把项目文档、PPT汇报过程、SOP数据等输出留下来，面试和简历就都有内容可写。

**Q: 如何进行课题分离？**
A: 任何时候问一个原问题：这到底是一件事还是两件事？比如"不要谈恋爱"和"谈恋爱"是两件事。在职场上，领导要你做一件事，同时他也在看你的忠诚度和认可度。这两件事是可以分开做的。

**Q: 如何提升决策力？**
A: 决策力缺失是大多数人的问题。好的策略需要迭代，但每一次迭代的决策速度都要快。如果慢的话，就证明你没想明白，人生没活明白，没有目标不自洽。训练决策力的方法是做课题分离，做自我剥离，把自己当做朋友帮他做决策。

#### 5.1.4 薪资与福利

**Q: 试用期被裁要不要劳动仲裁？**
A: 就算试用期裁掉你，企业或HR部门默认接受的就是N+1。走劳动仲裁绕一圈后也只拿到N+1。对于企业来说，这是故意折磨打工人。建议直接走，争取拿到该拿的。如果试用期才一两个月，N+1可能才千把块钱，不值得折腾。

### 5.2 大厂面试真题库（核心考点）

#### 5.2.1 指标体系类题目

**题目类型**：涵盖今日头条、微信状态功能、货拉拉、B站商业化、抖音电商、微信视频号、淘特、Shein、网易云课堂、滴滴出行、支付宝、知乎、Keep、淘宝直播、王者荣耀等平台。

**解题思路：指标体系构建五步法**

**第一步「建立联系」**
没有认知就无法开始分析。接到陌生业务问题时，第一反应是寻找一个相似的、熟悉的APP进行体验和类比。如果毫无认知完全陌生，就立刻去体验。

**第二步「明确目标」**
清晰定义业务核心目的、所处业务环节、环节核心目的。例如提升用户规模、提升用户粘性、变现等。

**第三步「还原体验并环节拆解」**
模拟用户关键路径，拆解出行为环节。

**第四步「指标映射」**
为每个环节定义指标（原子指标）。指标分类包括绝对值、转化率、活跃度、客单价等。

**第五步「产出指标流水线」**
按照用户从接触到流失的全链路，梳理出一系列指标。例如拉新→转化→活跃→留存→流失。

**高手进阶：抓核心指标、洞察核心指标**
关键洞察是：【核心用户】的【核心动作】提升的就是【核心指标（北极星指标）】

以今日头条为例：粘性不仅看日活，更关键的是次日乃至连续登录的用户，这代表了习惯的养成。

以淘宝特卖/拼多多为例：核心用户不是看LTV，客单价可能很低，而是看深度参与砍价、分享、平台特色活动的用户，他们是对比用户和活动驱动型用户。

**指标细化（衍生指标）：** 结合具体业务情景、产品机制细化指标。衍生指标 = 原子指标 + 时间周期 + 业务修饰词（维度）。例如7日活跃度。

**答题模板**：
```
1. 建立联系：类比XX产品（熟悉的业务场景）
2. 明确目标：该业务的北极星指标是XXX
3. 还原体验：用户关键路径是 曝光→点击→XXX→转化→留存
4. 指标映射：
   - 拉新：曝光量、点击率、新用户数
   - 转化：转化率、GMV、客单价
   - 留存：次日留存、7日留存
5. 产出流水线：整体指标体系串起来
```

**指标体系答题要点总结**：
- 指标是业务的仪表盘，源于对**用户体验**与**业务流程**的深度理解
- 指标体系的灵魂，不在于指标本身（无非用户数、转化率、LTV等），而在于通过指标**反映了哪种核心动作的提升**

#### 5.2.2 用户画像类题目

**题目类型**：涵盖淘宝用户生命周期分群、B站UP主画像、网易云音乐听歌用户画像、携程高价值用户分层、小红书广告投放用户画像、拼多多下沉市场用户画像、抖音广告兴趣标签、招商银行信用卡客户画像、企业微信核心用户角色、网易严选家居品类用户画像、腾讯课堂付费转化用户分群、得物潮玩兴趣用户画像、BOSS直聘用户画像、盒马会员用户画像、蔚来汽车用户画像等。

**RFM模型核心维度**：
- **R（Recency）**：用户最近一次消费时间
- **F（Frequency）**：用户在一定周期内的消费次数
- **M（Monetary）**：用户的平均订单成交金额

**用户生命周期分群维度**：
- 浏览用户（潜在用户）：最近一次浏览时间小于7天，无历史购买记录
- 新购买用户：最近一次消费时间小于15天，且为首单
- 成长用户（低频或低价值用户）：消费频率大于M次/周，小于N次/周，或平均订单成交金额小于YY元
- 高频忠实用户（成熟用户）：消费频率大于N次/周，大促购买次数占比不高于S%，且平均订单成交金额大于XX元
- 预警流失用户：最近一次消费时间超过15天，购买频率较上月环比下降显著
- 流失用户：最近一次消费时间超过30天

**用户画像分析维度**：
- 基础属性：人口统计学特征（年龄、性别、地域等）
- 行为数据：浏览、搜索、收藏、加购、下单等
- 消费能力：客单价、购买频次、LTV等
- 生命周期阶段：新用户、成长用户、成熟用户、流失用户
- 兴趣偏好：品类偏好、内容偏好、功能偏好

**答题模板**：
```
1. 确定分群维度：基于RFM模型，结合业务特点
2. 定义分群标准：
   - 高价值用户：R低、F高、M高
   - 潜力用户：R低、F低、M高
   - 流失风险用户：R高、F下降
3. 运营策略：
   - 高价值用户：专属服务、VIP权益
   - 潜力用户：提升频次
   - 流失用户：召回活动
```

#### 5.2.3 SQL类题目核心考点

**常见SQL题型**：
- 窗口函数类：排名问题、累计计算、分组聚合
- 多表关联：JOIN操作、UNION合并
- 条件筛选：WHERE、HAVING、CASE WHEN
- 聚合统计：COUNT、SUM、AVG、GROUP BY
- 日期处理：日期计算、日期格式转换
- 排名问题：TOP N、分组TOP N

**必须掌握的窗口函数**：
- `ROW_NUMBER()`：排序（无并列）
- `RANK()`：排序（有并列，跳跃）
- `DENSE_RANK()`：排序（有并列，不跳跃）
- `LAG() / LEAD()`：前后行数据
- `SUM() OVER`：累计计算
- `AVG() OVER`：移动平均

**答题要点**：
- 理解业务需求，明确输出目标
- 善用窗口函数处理排名和累计问题
- 注意NULL值处理和边界条件
- 优化查询效率，避免全表扫描
- 结果验证，确保逻辑正确

#### 5.2.4 业务分析类题目

**题目类型**：
- 指标异动分析：如美团外卖订单量异常波动分析
- 业务归因分析：收入下降/用户流失原因定位
- 策略效果评估：新功能上线效果评估
- AB测试分析：实验组与对照组对比分析

**指标异动分析五步法**：
1. 确认数据准确性，排除数据问题
2. 确定时间范围，确认异常开始时间点
3. 维度拆解，从产品、用户、渠道等维度拆分
4. 找到关键影响因素，定位核心原因
5. 提出业务建议，制定优化策略

**"向前看"归因法**：
- 从最靠近异常的时刻开始排查
- 一直向前找到第一个有波动的指标
- 核心是找到核心问题，问题解决后指标能提升即可

### 5.3 开品报告六维自检法

**课程特色**：
戴师兄数据分析实战课采用「实战导向」教学，每个模块的习题均配套答案文档，支持【抄作业】式学习。课程教授可复用的分析「流水线」和「八股文」，确保基础题目不丢分。

#### 维度一：看竞对
- 你的假设还有谁在做？做的如何？是否有机会点？你和他们的区别是什么？
- 有效研究竞品需要明确：竞品的核心卖点是什么？他们的市场表现如何？是否存在可进入的差异化机会点？

**竞品分析三步法**：
- **直接竞品**：与产品形态和使用场景最相似的产品
- **跨品类竞品**：同形态但不同品类的产品
- **传统竞品**：非创新形态的产品（作为创新对照，突出优势）

#### 维度二：看规模
- 你的洞察市场量级有多大？
- 当说到"大"或者"小"的时候，你的参照系是什么？参照系可以是什么？比如行业爆品关键词指数。

#### 维度三：看产品力
- 你预设的痛点，有没有针对性？
- 你所设想的痛点，来自于哪个关键洞察？这个洞察是被市面品牌忽视或忽略的吗？

#### 维度四：看自然流量潜力
- 在"内容"上，你看到了什么机会？
- 有没有内容机会，你将如何借力这些内容机会？

#### 维度五：成分分析
- 你的成分是怎么来的？你是否了解成分的价值和特点？
- 你借助搜索和AI，深度理解成分了吗？成分选择需要说明理由，而非简单罗列。

#### 维度六：价值汇流
- 每个板块，你有没有找到它的价值和意义？
- 你的数据洞察，是否可以"汇流"？最终所有的分析，都可以指向你的结论。

### 5.4 开品报告常见扣分点与加分项

#### 常见扣分点

**扣分点一：把用户主观诉求当成产品客观能力**
- 问题表现：把"用户主观诉求"当成了"产品客观能力"，未区分事实和假设
- 示例："一瓶搞定所有玻璃"——用户希望一瓶搞定，但产品是否真能一瓶搞定所有场景？需要论证配方如何通过复配实现多重能力

**扣分点二：超大市场通常是风险命题**
- 问题表现：体量巨大但高度碎片化的市场，渠道、定价、用户需求完全不同
- 正确做法：选择一个细分赛道深耕，而非试图覆盖所有市场

**扣分点三：跨界开品跳步**
- 问题表现：完全跳过了"找原因-解问题"的核心环节
- 正确做法：重点研究"为什么这个成分很好，但目前没有普及"

**扣分点四：核心差异化卖点价值挖掘不足**
- 问题表现：把行业基础门槛当成核心卖点反复论述
- 示例：把"可视化"等同于"瓦解污渍的视觉效果"，没意识到"精准定位隐形污渍"才是核心价值

**扣分点五：不舍得砍内容**
- 问题表现：报告内容冗余，很多板块与核心价值点关联不大
- 正确做法：每个板块都需要能够"汇流"到最终结论

**扣分点六：最大价值点未作为底层逻辑**
- 问题表现：把"一次性/便捷"当成了"附属卖点"，未将最大的价值点作为「底层逻辑」渗透到报告所有板块

#### 加分项

**加分项一：品类定义清晰**
创新品类虽然没有直接数据支撑，但分析方式正确，能有效归类需求和产品

**加分项二：核心价值点贯穿全报告**
所有板块的设计都围绕核心价值点展开

**加分项三：隐性痛点挖掘**
挖掘用户隐性痛点作为核心卖点

**加分项四：品类再创新**
核心价值是创新了产品形态

**加分项五：AI验证精准**
AI问的问题精准，能验证核心假设（市场需求验证、竞品空白验证、场景适配验证、技术落地验证）

### 5.5 求职技巧（求职冲刺表精华）

#### 简历撰写核心原理
**简历的本质**：简历上要写的是公司想让你干的事，不是你已经干的事。没写就等于不会。

**简历撰写模板**：
```
负责XXX目的，使用XXX工具，通过XXX技能，完成了/实现了XXX具体出来的结果是什么，提升了XXX效果（绝对值和百分比，哪个高填哪个）
```

#### 空窗期修复策略
**空窗期解释原则**：不是修复简历，而是找回理想的人生。

**常用解释方向**：
- 个人成长：探索职业目标和方向
- 寻求挑战：寻找新机会和挑战
- 家庭原因：照顾家人或处理个人事务
- 职业转变：转向不同行业或职业
- 环境不适：寻找更匹配的工作环境
- 追求平衡：重视工作生活平衡
- 自我探索：挖掘个人潜力
- 专业发展：提升专业技能

#### 移花接木技巧
**核心原理**：
- 信息差：世界上没有人知道你自己到底是如何完成工作的
- 结果论：面试中能把结果和过程描述清楚，不管做没做过，都会视为做过
- 背调无效化：只要你逻辑闭环，在信息差里发挥

**具体操作**：
1. 按新岗位需求重新理解旧岗位工作内容
2. 掌握新技能后模拟做一遍
3. 输出符合新岗位要求的工作经历

#### 简历内容优先级
1. 简历一定要对照JD，认真匹配自己的内容
2. 作品集要看对应JD的需求，重点突出岗位核心能力
3. 校招/2年以下：突出"能干活、会学习、会思考、会沉淀"
4. 3年以上：核心竞争力往策略、规划、优质看板、工具全面方向打

#### 投递策略
**投递阶段**：
- 第一阶段（乱投）：非意向岗位随便投，一天100个，两天后看反馈
- 第二阶段（海投）：意向岗位+非意向城市+中小厂，一天100个
- 第三阶段（定投）：意向岗位+意向城市+匹配行业+大中小厂，质量>数量

**投递复盘**：
- 有1%面试邀约基本没问题
- 1%不到必须继续迭代简历
- 至少3次面试+复盘后开启定投
