# 党政机关公文排版助手

本技能为机关单位办公室工作人员提供符合国家标准的公文排版服务，确保文档格式规范、统一。

## 排版核心规范

### 页面设置

| 参数 | 标准值 |
|------|--------|
| 上边距 | 37mm |
| 下边距 | 35mm |
| 左边距 | 28mm |
| 右边距 | 26mm |

### 字体规范

| 用途 | 字体 | 字号 |
|------|------|------|
| 公文标题 | 方正小标宋简体 | 二号 |
| 正文 | 仿宋_GB2312 | 三号 |
| 一级标题 | 黑体 | 三号 |
| 二级标题 | 楷体_GB2312（加粗） | 三号 |
| 三级标题 | 仿宋_GB2312（加粗） | 三号 |
| 数字/英文 | Times New Roman | 对应正文字号 |

### 段落规范

- **行距**: 28磅
- **首行缩进**: 2字符
- **段落间距**: 按照标准公文格式设置

## 排版执行流程

### 步骤1：设置页面布局

在文档编辑器中设置以下页边距：
```
上: 3.7cm
下: 3.5cm
左: 2.8cm
右: 2.6cm
```

### 步骤2：设置正文字体

正文样式配置：
```
字体: 仿宋_GB2312
字号: 三号（16pt）
行距: 固定值 28磅
首行缩进: 2字符
```

### 步骤3：设置标题样式

**一级标题**（黑体）:
```
字体: 黑体
字号: 三号（16pt）
加粗: 是
```

**二级标题**（楷体加粗）:
```
字体: 楷体_GB2312
字号: 三号（16pt）
加粗: 是
```

**三级标题**（仿宋加粗）:
```
字体: 仿宋_GB2312
字号: 三号（16pt）
加粗: 是
```

### 步骤4：标题排版

公文标题应使用：
```
字体: 方正小标宋简体
字号: 二号（22pt）
居中排列
不加粗
```

### 步骤5：数字与英文处理

文档中的阿拉伯数字和英文统一使用 Times New Roman 字体。

## 排版检查清单

完成排版后，请核对以下要点：

- [ ] 页边距符合标准（上3.7cm，下3.5cm，左2.8cm，右2.6cm）
- [ ] 正文使用三号仿宋_GB2312
- [ ] 行距设置为28磅
- [ ] 首行缩进2字符
- [ ] 标题使用对应字体和字号
- [ ] 数字和英文使用Times New Roman
- [ ] 整体排版整洁、规范

## 适用场景

- 党政机关公文撰写
- 政府通知、决定、报告
- 机关单位请示、批复
- 办公会议纪要
- 各类正式行政文书

## 注意事项

1. 严格按照GB/T 9704-2012标准执行
2. 字体名称需与操作系统已安装字体匹配
3. WPS Office和Microsoft Office的字体列表可能略有差异
4. 重要文件建议打印预览后确认格式
