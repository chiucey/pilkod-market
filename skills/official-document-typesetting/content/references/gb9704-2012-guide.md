# 《党政机关公文格式》（GB/T 9704-2012）排版指南

## 一、页面设置参数

### 精确数值

| 项目 | 数值 | 说明 |
|------|------|------|
| 页面上边距 | 37mm | 成品尺寸：210mm×297mm |
| 页面下边距 | 35mm | 留出页码空间 |
| 页面左边距 | 28mm | 装订位置 |
| 页面右边距 | 26mm | 视觉平衡 |

### 计算说明

- A4纸尺寸：210mm × 297mm
- 版心尺寸：156mm × 225mm（宽×高）
- 可写字区域：210 - 28 - 26 = 156mm（宽）

## 二、字体与字号详解

### 2.1 标题字体

**公文标题（二号方正小标宋简体）**

- 字号：二号 ≈ 22pt ≈ 16号
- 字体名称：方正小标宋简体、FZXiaoBiaoSong-B05
- 特殊要求：居中排列，不加粗

### 2.2 正文字体

**正文主体（三号仿宋_GB2312）**

- 字号：三号 ≈ 16pt ≈ 14号
- 字体名称：仿宋_GB2312、FangSong_GB2312
- 行距：28磅（固定值）
- 首行缩进：2字符（约32.4pt）

### 2.3 标题分级

| 级别 | 字体 | 字号 | 加粗 | 示例 |
|------|------|------|------|------|
| 一级 | 黑体 | 三号(16pt) | 是 | 一、基本要求 |
| 二级 | 楷体_GB2312 | 三号(16pt) | 是 | （一）组织领导 |
| 三级 | 仿宋_GB2312 | 三号(16pt) | 是 | 1. 工作目标 |

### 2.4 数字与外文

**阿拉伯数字**

- 字体：Times New Roman
- 字号：跟随上下文（三号正文则用三号）
- 使用场景：日期、编号、统计数据

**英文和外文字母**

- 字体：Times New Roman
- 字号：跟随上下文
- 注意大小写规范

## 三、段落排版规范

### 3.1 行距设置

```
推荐设置：固定值 28磅

计算依据：
- 三号字约16pt
- 28磅行距约为字号的1.75倍
- 确保上下行文字不重叠
```

### 3.2 首行缩进

```
缩进量：2字符
字符宽度：16.2pt（以三号字计算）
总缩进：约32.4pt
```

### 3.3 段落间距

- 段前间距：0pt
- 段后间距：0pt
- 与标题间距：段前12pt，段后12pt

## 五、软件操作指南

### 5.1 WPS Office 设置步骤

1. **页面布局**
   - 布局 → 页面设置
   - 页边距：上3.7cm，下3.5cm，左2.8cm，右2.6cm

2. **新建样式**
   - 格式 → 样式与格式
   - 新建"公文标题"样式
   - 字体：方正小标宋简体，二号
   - 段落：居中，行距28磅

3. **应用样式**
   - 选中文字 → 应用对应样式
   - 使用格式刷快速复制格式

### 5.2 Microsoft Word 设置步骤

1. **页面设置**
   - 布局 → 页边距
   - 自定义边距 → 设置数值

2. **样式窗格**
   - 视图 → 样式窗格
   - 创建新样式
   - 设置字体和段落格式

3. **快捷键设置**
   - 为常用样式设置快捷键
   - 提高排版效率

## 六、常见问题解答

### Q1: 系统没有方正小标宋简体怎么办？

A: 可以使用以下替代方案：
- 方正小标宋（简化版本）
- 华文细黑（视觉效果接近）
- 或联系信息技术部门安装字体

### Q2: 行距28磅在软件中如何设置？

A: 在段落设置中选择"固定值"，输入28磅。

### Q3: 首行缩进2字符如何精确设置？

A: 在段落缩进中设置"特殊格式"为"首行缩进"，"磅值"为"2字符"。

### Q4: 数字必须用Times New Roman吗？

A: 是的，按照GB/T 9704-2012标准，公文中的阿拉伯数字应使用Times New Roman字体。
