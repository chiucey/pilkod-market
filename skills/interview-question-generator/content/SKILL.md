# 智能面试题生成器

服务于HR和面试官的专业面试题生成工具，基于岗位信息生成深度考察题目。

## 核心能力

- **岗位智能解析**：从岗位名称、职责描述、任职资格中提取核心能力要求
- **多维题目生成**：行为面试题、情景模拟题、专业知识题、文化匹配题、压力面试题
- **专业评分体系**：基于BARS的5级评分标准 + 参考答案要点
- **STAR法则贯穿**：引导候选人用STAR框架回答行为问题

## 输入要求

用户至少提供以下之一：
- 岗位名称（如：高级Java工程师、运营专员、产品经理）
- 岗位职责描述（核心工作内容）
- 任职资格（学历、经验、技能要求）
- 候选人简历（可自动提取关键信息）

> **提示**：提供的信息越详细，题目越精准匹配岗位需求。

## 输出结构

每个岗位生成以下五大模块：

### 1. 行为面试题（STAR法则）
**考察要点**：通过追问具体经历评估真实能力
- 每题附带【考察要素】【STAR提示】【评分标准（5/3/1分）】
- 自动根据岗位职责定制（如检测到管理职责则追加领导力题）

### 2. 情景模拟题
**考察要点**：模拟真实工作场景评估应变与决策能力
- 每题附带【考察维度】【参考答案要点】【评分标准】
- 场景与岗位实际工作高度相关

### 3. 专业知识题
**考察要点**：验证岗位核心技能与知识储备
- 根据识别的技能关键词自动生成进阶题
- 每题附带【标准答案要点】【深入追问提示】

### 4. 文化匹配题
**考察要点**：评估价值观、团队协作、职业稳定性
- 考察动机、适应性、抗挫能力

### 5. 压力面试题（慎用）
**考察要点**：评估抗压能力与应变能力
- ⚠️ 使用前建议标注，避免让候选人感到被审问

## 评分维度体系

基于**行为锚定等级量表（BARS）**，每个维度采用5分制：

| 分数 | 等级 | 行为描述 |
|------|------|----------|
| 5分 | 卓越 | 远超岗位要求，有量化成果支撑 |
| 4分 | 优秀 | 达到并部分超越岗位要求 |
| 3分 | 胜任 | 满足岗位基本要求 |
| 2分 | 待提升 | 部分能力有欠缺 |
| 1分 | 不胜任 | 明显不符合岗位要求 |

## 使用方式

### 直接调用
```
用户: "为高级前端工程师生成面试题"
用户: "准备React开发岗的面试问题"
用户: "产品经理任职资格面试评估"
```

### 必要信息提取
- 从用户输入中识别**岗位类型**（技术/产品/运营/销售/管理）
- 提取**核心技能关键词**（编程语言、工具、方法论）
- 判断**职级层次**（初级/中级/高级/专家/管理岗）

## 注意事项

1. **行为题必问**：STAR法则题能最真实反映候选人能力
2. **追问原则**：不满足于初始回答，追问"S具体情境中T你的任务A你做了什么R结果如何"
3. **警惕信号**：回答泛泛而谈、回避具体细节、"我们团队"代替"我"
4. **压力题慎用**：仅在必要情况下使用，提前告知候选人
