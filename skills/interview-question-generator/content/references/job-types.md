# 各类岗位面试侧重点

## 1. 技术/研发岗

### 核心考察维度
- 专业知识深度
- 项目经验真实性
- 问题解决能力
- 技术学习能力
- 代码规范意识

### 推荐题型分布
```
技术深挖题（40%）> 项目经历追问（30%）> 系统设计题（20%）> 基础概念题（10%）
```

### 追问方向
- 技术选型原因（为什么用A不用B）
- 性能优化实践（具体数据指标）
- 团队协作模式（代码评审、敏捷流程）
- 技术债务处理
- 持续学习方式

### 必问题库

**行为面试类**
1. 请描述一个你解决过的最复杂的技术问题，你是如何排查和解决的？
2. 你在项目中有没有推动过技术改进？请详细说明。

**技术深挖类**
1. 你在这个项目中遇到的最大技术挑战是什么？如何攻克的？
2. 如果重新做一次这个项目，你会做哪些不同的技术决策？

---

## 2. 产品/运营岗

### 核心考察维度
- 业务理解深度
- 逻辑思维严密性
- 数据分析能力
- 跨部门协作能力
- 用户洞察力

### 推荐题型分布
```
场景模拟题（35%）> 数据分析题（25%）> 产品感觉题（20%）> 行业认知（20%）
```

### 追问方向
- 需求优先级判断方法
- 数据驱动决策的案例
- 与开发/设计团队的协作经验
- 竞品分析能力
- 产品迭代思维

### 必问题库

**行为面试类**
1. 请描述一个你主导的产品功能，从需求分析到上线全流程。
2. 你是如何处理来自不同部门的冲突需求的？

**情景模拟类**
1. 如果你发现一个产品指标突然下降，你会如何排查问题？
2. 假设开发资源有限，你会如何与开发团队沟通确定需求优先级？

---

## 3. 销售/商务岗

### 核心考察维度
- 沟通表达能力
- 客户关系管理能力
- 谈判能力
- 抗压与韧性
- 业绩导向意识

### 推荐题型分布
```
情景模拟（35%）> 过往业绩深挖（30%）> 行业理解（20%）> 产品知识（15%）
```

### 追问方向
- 最大单笔成交经历
- 最难谈判的经历
- 客户维护方法
- 失败案例复盘
- 行业趋势理解

### 必问题库

**行为面试类**
1. 请描述你完成的最大一笔订单，你是如何做到的？
2. 讲述一次你丢失重要客户的经历，你从中学到了什么？

**情景模拟类**
1. 假设客户提出降价30%的要求，你会如何应对？
2. 如果一个客户对你的产品表示不感兴趣，你会怎么做？

---

## 4. 市场/营销岗

### 核心考察维度
- 市场洞察能力
- 创意策划能力
- 数据分析能力
- 项目执行能力
- 资源整合能力

### 推荐题型分布
```
营销策划案（30%）> 数据分析题（25%）> 行业洞察（25%）> 过往案例（20%）
```

### 追问方向
- 成功营销案例拆解
- 预算管理与ROI优化
- 渠道选择逻辑
- 竞品营销策略分析
- 团队协作模式

### 必问题库

**行为面试类**
1. 请描述一个你认为最成功的营销活动，你是如何策划和执行的？
2. 你有没有做过效果不达预期的营销活动？如何复盘？

**情景模拟类**
1. 如果给你有限的预算，你会如何规划一场产品发布？
2. 假设竞品推出了比你更好的产品，你会如何应对？

---

## 5. 管理岗（团队负责人/经理）

### 核心考察维度
- 团队领导力
- 战略思维
- 人才培养能力
- 绩效管理能力
- 变革推动能力

### 推荐题型分布
```
管理场景模拟（35%）> 人才梯队建设（25%）> 绩效管理（20%）> 过往成果数据（20%）
```

### 追问方向
- 团队规模与管理幅度
- 绩效面谈经验
- 处理低绩效员工的方法
- 人才培养机制
- 战略规划能力

### 必问题库

**行为面试类**
1. 请描述你管理团队的最大规模，你是如何进行日常管理的？
2. 讲述一次你不得不辞退员工的情况，你是如何处理的？

**情景模拟类**
1. 假设你新接手一个绩效较低的团队，你会如何快速提升团队表现？
2. 如果核心成员提出离职，你会如何挽留？

---

## 6. 管培生/校招生

### 核心考察维度
- 学习能力
- 成长潜力
- 价值观匹配
- 逻辑思维能力
- 主动性

### 推荐题型分布
```
STAR行为题（30%）> 价值观判断（25%）> 逻辑思维（25%）> 行业认知（20%）
```

### 追问方向
- 实习经历收获
- 社团活动经验
- 抗压与成长经历
- 学习方法论
- 职业规划

### 必问题库

**行为面试类**
1. 请描述你在实习/兼职中遇到的最大挑战，你是如何解决的？
2. 你在大学期间最有成就感的一件事是什么？

**情景模拟类**
1. 如果入职后发现工作与预期不符，你会怎么办？
2. 假设你需要同时完成学业和实习，你会如何平衡？

---

## 7. 财务/金融岗

### 核心考察维度
- 专业知识深度
- 数据敏感性
- 风险意识
- 合规意识
- 细致严谨

### 推荐题型分布
```
专业问题（35%）> 案例分析（30%）> 风险判断（20%）> 合规意识（15%）
```

### 追问方向
- 财务报表分析能力
- 风险识别经验
- 合规流程理解
- 行业法规认知
- 数据处理能力

### 必问题库

**专业类**
1. 请分析一家你熟悉的公司财务报表，识别潜在风险点。
2. 如果你发现一笔账目存在合规问题，你会如何处理？

**情景模拟类**
1. 假设公司面临一项重大投资决策，你会如何进行财务评估？
2. 如果审计发现历史数据存在错误，你会如何应对？

---

## 8. 行政/支持岗

### 核心考察维度
- 细节把控能力
- 多任务管理能力
- 服务意识
- 沟通协调能力
- 应急处理能力

### 推荐题型分布
```
情景处理（35%）> 过往经验（30%）> 服务意识（20%）> 职业稳定性（15%）
```

### 追问方向
- 行政事务处理经验
- 突发情况应对
- 服务意识体现
- 跨部门协调
- 职业规划

### 必问题库

**行为面试类**
1. 请描述一次你同时处理多项紧急任务的情况。
2. 讲述一次你主动发现并解决的问题。

**情景模拟类**
1. 如果领导临时需要一个重要资料，但相关同事不配合，你会怎么做？
2. 假设公司举办大型活动，你需要协调哪些资源？
