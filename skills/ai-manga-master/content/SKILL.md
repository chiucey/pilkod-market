# AI漫剧大师

## Overview

AI漫剧大师是一个专业的AI动漫剧制作技能，擅长将小说、故事转化为精彩的AI动漫短剧。涵盖小说分析与剧本改编、角色设计、分镜规划、AI图像生成、AI视频制作的全流程能力。制作过程循序渐进，每完成一个阶段与用户确认后再继续。

## Workflow

### 第一阶段：内容分析（剧本分析）

1. 接收用户提供的小说内容或文件
2. 深度阅读分析，完整理解小说的情节、人物、主题
3. 按以下框架进行结构化分析：
   - **核心冲突**：故事的主要矛盾是什么？
   - **情感主线**：贯穿全篇的情感是什么？
   - **高潮时刻**：哪些场景最具张力？
   - **视觉亮点**：哪些场景最适合动漫视觉表现？
4. 分析角色信息：
   - **主角特征**：外貌、性格、标志性特点
   - **配角关系**：与主角的关系和互动
   - **角色弧光**：角色在故事中的成长变化
5. 提取适合动漫化的精华片段（建议3-10个关键场景），按优先级排序
6. 输出结构化的分析报告（格式见下方"剧本分析报告格式"）
7. **与用户确认**选取的情节和改编方向

### 第二阶段：剧本创作

1. 将选取的情节改编为分镜剧本
2. 为每个场景设计：
   - 场景描述（背景、氛围、光线）
   - 角色动作和表情
   - 对话或旁白文字
   - 镜头运动建议
3. 注意动漫特有的叙事节奏
4. **与用户确认**剧本内容

### 第三阶段：角色设计

1. 为每个主要角色收集设计信息：
   - 角色基本信息（姓名、年龄、身份）
   - 外貌描述（发型、发色、眼睛、体型）
   - 服装风格（日常服、特殊服装）
   - 性格特点（影响表情和姿态设计）
   - 标志性物品或特征
2. 确定角色的视觉关键词和色彩方案
3. 使用图像生成工具创建角色设定图：
   - 全身立绘（正面）
   - 面部特写
   - 表情变化（可选）
4. 确保所有角色在同一视觉风格下协调统一
5. 角色设定图保存在 `output/characters/` 目录
6. **与用户确认**角色设计

### 第四阶段：分镜设计与场景图像生成

1. 为每个场景设计分镜构图（格式见下方"分镜脚本格式"）
2. 选择合适的景别、角度、构图
3. 构建场景图像生成提示词
4. 按照分镜顺序逐场景生成画面
5. 保持角色形象和风格一致性
6. 场景图保存在 `output/scenes/` 目录

### 第五阶段：视频制作

1. 为重点场景制作动态视频
2. 描述角色的具体动作和镜头运动方向
3. 保持与静态图的一致性
4. 视频保存在 `output/videos/` 目录

### 第六阶段：整合输出

1. 整理所有素材
2. 提供完整的剧本文档（保存至 `output/script/storyboard.md`）
3. 输出场景图和视频文件列表
4. 给出后期制作建议（配音、配乐、字幕）

## 镜头语言参考

### 景别
- **特写（CU）** - 面部表情、重要物品
- **近景（MS）** - 胸部以上，适合对话
- **中景（FS）** - 全身，展示动作
- **远景（LS）** - 展示环境和人物关系
- **大远景（ELS）** - 壮观场景，建立氛围

### 角度
- **平视** - 平等、客观
- **仰视** - 威严、压迫感
- **俯视** - 弱小、全局视角
- **斜角** - 不安、紧张感

### 运动（视频用）
- **推进** - 聚焦、强调
- **拉远** - 揭示、展开
- **平移** - 跟随、展示
- **环绕** - 全方位展示

## 角色设计指南

### 设计原则

#### 辨识度
- 每个角色需要独特的视觉特征
- 发型、发色是最重要的识别元素
- 服装和配饰强化角色个性

#### 一致性
- 所有角色使用相同的绘画风格
- 比例和线条粗细保持统一
- 色彩饱和度和明度协调

#### 表现力
- 设计要能体现角色性格
- 预留足够的动态表现空间
- 考虑角色在不同情绪下的表现

### 角色立绘提示词结构
```
[角色描述], [服装描述], [姿势], anime style, character design,
full body shot, clean background, high quality, detailed,
[风格关键词]
```

### 角色立绘示例提示词
```
young female warrior with long silver hair and blue eyes,
wearing elegant white armor with gold accents,
confident standing pose with sword,
anime style, character design, full body shot,
clean white background, high quality, detailed illustration,
```

### 角色设定图文件命名
- `character_[角色名]_fullbody.png` - 全身立绘
- `character_[角色名]_portrait.png` - 面部特写

### 角色设定图规格
- 全身立绘：3:4 比例
- 面部特写：1:1 比例
- 背景：纯色或简洁渐变

## 场景图像生成指南

### 场景图提示词结构
```
[场景描述], [角色描述和动作], [光线和氛围],
[构图指示], anime style, [风格关键词],
high quality, detailed background, cinematic composition
```

### 场景图规格
- 比例：16:9 宽屏比例
- 分辨率：默认2K
- 保持角色形象一致
- 背景细节要与故事设定匹配

### 视频规格
- 时长：每个场景6-10秒
- 分辨率：768P 或 1080P
- 动作要流畅自然

## 漫画风格指南

本节提供各种动漫风格的详细参考和AI提示词模板，确保生成的图像和视频保持风格一致性。

## 风格一致性技巧

### 角色一致性
1. **固定关键特征描述**：在每个提示词中使用相同的角色描述
2. **使用参考词**：如 "same character as before"
3. **保持配色方案**：记录并重复使用角色的颜色代码

### 场景一致性
1. **统一光线风格**：选定后保持一致
2. **背景风格词固定**：使用相同的背景描述词
3. **色调一致**：确定整体色调后坚持使用

### 提示词结构标准
```
[主体描述], [动作/姿势], [服装], [表情],
[场景/背景], [光线], [风格关键词],
[质量词], [比例/构图]
```

## 常见问题解决

### 角色不一致
- 增加更详细的特征描述
- 使用具体的颜色名称
- 添加 "consistent character design" 关键词

### 风格混乱
- 减少风格关键词数量
- 使用负面提示词排除不想要的风格
- 保持核心风格词在前

### 质量不足
- 添加 "masterpiece, best quality"
- 增加分辨率相关词
- 使用 "highly detailed"

## 互动原则

1. **循序渐进** - 每完成一个阶段，与用户确认后再继续
2. **灵活调整** - 根据用户反馈随时调整方向
3. **专业建议** - 主动提供专业的动漫制作建议
4. **质量优先** - 宁可减少场景数量，也要保证每个画面的质量
5. **尊重原著** - 保留原作的精髓和情感内核
6. **视觉思维** - 始终考虑场景的视觉表现力
