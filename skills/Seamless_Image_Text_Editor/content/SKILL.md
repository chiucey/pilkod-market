## 1. 触发条件 (Triggered When)
- 用户上传包含文本的图像，并要求替换、修改或抹除其中的文字内容。
- 用户要求进行无痕 P 图、去除水印或替换特定的背景元素。

## 2. 预期输入 (Inputs)
- `source_image`: 用户提供的原始图像。
- `target_text`: 需要替换或新加入的文字内容（若为擦除则为空）。
- `target_area`: 用户指定的修改区域（可选）。

## 3. 执行逻辑 (Execution Protocol)

### 阶段一：深度环境侦测 (Analyze_Source)
在执行任何图像编辑或生成建议前，必须优先调用视觉分析能力，输出原图的拆解报告：
- **Font_Profile**: 识别/推测原字体风格、字重、确切颜色代码 (HEX)、字距与行距。
- **Perspective**: 计算 3D 透视网格、表面倾斜度或介质物理形变（如纸张弯曲）。
- **Lighting_&_Texture**: 提取阴影角度及柔和度、高光位置、环境反射率。
- **Background_Noise**: 分析图像底噪（ISO 噪点、JPEG 压缩伪影、失焦模糊度）。

### 阶段二：无痕擦除策略 (Erase_Protocol)
制定背景修复方案：
- 锁定需要擦除的文本区域。
- 如果通过 Stable Diffusion 接口执行，生成用于修复背景的精准 Prompt，并锁定 `Denoising strength` 和 `Mask blur` 阈值，确保背景纹理连续。
- 如果是指导用户操作，给出精确的 Photoshop 工具路径（如：内容识别填充 -> 仿制图章修补纹理边缘）。

### 阶段三：像素级融合 (Reconstruct_Protocol)
在插入新文字或元素时，强制执行“缺陷还原”检查清单：
- [ ] **透视对齐**: 新元素必须严格贴合阶段一提取的透视网格。
- [ ] **光影重建**: 叠加正确的图层混合模式（如正片叠底/滤色），匹配环境色温。
- [ ] **物理劣化 (关键)**: 严禁贴入清晰锐利的新文字。必须根据阶段一的底噪分析，为其添加对应的高斯模糊、单色噪点或镜头畸变效果，以匹配原图画质。

## 4. 输出规范 (Output Format)
若智能体具备直接出图权限：直接返回最终图像，并附带简短的《融合参数日志》。

若智能体运行在纯文本/代码指导模式，必须严格按照以下模板输出：
```text
🔍 **环境侦测报告**
- 字体特征：[推测字体与颜色]
- 透视与光影：[透视角度及光源方向]
- 底图劣化特征：[噪点与模糊度分析]

🛠️ **执行参数建议 (SD/PS)**
- 擦除方案：[Inpainting 提示词或 PS 操作步骤]
- 融合滤镜：[需添加的模糊、噪点等具体数值]
