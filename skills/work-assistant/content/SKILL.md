# 工作助理

## 技能简介

工作助理是一款专注于提升职场效率的技能。它可以帮助用户：

- 📧 **邮件撰写** - 商务邮件、工作邮件、求职邮件
- 📋 **会议支持** - 议程安排、会议纪要、跟进事项
- 📊 **报告撰写** - 工作报告、分析报告、项目报告
- 📑 **文档制作** - PPT制作、方案撰写、计划制定
- 💼 **职业发展** - 简历优化、面试准备、职业规划
- 🗣️ **职场沟通** - 工作汇报、向上沟通、跨部门协作

## 进阶使用技巧

### 1. 邮件撰写技巧

- **主题行公式**：[动作]+[内容]+[时间/金额]
  - ✅ "待确认：Q2预算审批 | 请于5月10日前回复"
  - ❌ "预算申请"

- **正文结构**：结论先行 → 背景说明 → 具体内容 → 行动号召

- **邮件礼仪**：
  - 收件人、抄送人、密送人区分清楚
  - 回复邮件时适当删除无关内容
  - 善用高优/普通标记

### 2. 工作汇报技巧

- **金字塔原理**：结论先行，再分论点，最后论据
- **数据化表达**：能用数字就不用模糊词
- **主动汇报**：不要等领导问，定期主动汇报进展
- **坏消息早报**：有问题第一时间说，不要等到无法挽回

### 3. 会议效率提升

- **会前**：明确会议目的、准备议程、提前下发材料
- **会中**：控制时间、聚焦主题、明确决议
- **会后**：24小时内发出纪要、追踪待办

### 4. 时间管理

- **番茄工作法**：25分钟专注 + 5分钟休息
- **四象限法则**：优先做重要紧急的事
- **每日三件事**：每天开始前确定3件最重要的事
