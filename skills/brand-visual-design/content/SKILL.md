# 品牌视觉设计 (Brand Visual Design)

## 核心理念

**Max-De$ign 主张：要么设计，要么被设计。**

品牌视觉设计不仅是创造美观的图形，更是通过视觉语言传递品牌价值、建立情感连接、形成差异化认知的系统性工程。

## 2. 品牌视觉设计流程

### 阶段一：品牌策略 (Strategy)

| 步骤 | 内容 | 产出 |
|------|------|------|
| 品牌调研 | 行业分析、竞品视觉研究、目标用户洞察 | 调研报告 |
| 品牌定位 | 核心价值、品牌个性、差异化主张 | 品牌定位陈述 |
| 品牌架构 | 母品牌与子品牌关系 | 品牌架构图 |
| 品牌命名 | 名称创意、域名检查、法律检索 | 备选名称清单 |

### 阶段二：视觉探索 (Exploration)

| 步骤 | 内容 | 产出 |
|------|------|------|
| 视觉方向 | 探索 3-5 个设计方向 | 方向概念板 |
| Logo 设计 | 草图、手稿、数字化 | Logo 方案 |
| 色彩系统 | 主色、辅色、渐变 | 品牌色板 |
| 字体系统 | 标题字、正文字、数字体 | 字体规范 |

### 阶段三：系统构建 (Development)

| 步骤 | 内容 | 产出 |
|------|------|------|
| Logo 精修 | 比例优化、栅格建立 | 标准化 Logo |
| VI 手册 | 规范文档、示例图 | VI 手册初稿 |
| 物料设计 | 名片、信封、工牌等 | 应用模板 |

### 阶段四：交付落地 (Delivery)

| 步骤 | 内容 | 产出 |
|------|------|------|
| 品牌手册 | 完整使用规范 | 品牌手册 |
| 源文件包 | AI/EPS/PSD/SVG/PDF | 设计源文件 |
| 资产库 | 规范图标、图形元素 | 品牌资产 |

## 3. Logo 设计系统

### Logo 类型

| 类型 | 说明 | 适用场景 | 示例 |
|------|------|----------|------|
| 文字标 (Wordmark) | 品牌名称文字设计 | 已有强认知的品牌 | Coca-Cola, Google |
| 图形标 (Symbol) | 抽象或具象图形 | 需图形记忆点 | Apple, Nike |
| 图文组合 (Combination) | 图形+文字的组合 | 初期品牌建设 | 大多数品牌 |
| 动态标 (Animated) | 可动态变化的 Logo | 数字媒体环境 | Instagram, Gmail |

### Logo 设计原则

1. **独特性**：可识别，与竞品差异化
2. **简洁性**：小尺寸可辨识，记忆成本低
3. **适应性**：黑白/彩色/单色均可用
4. **永恒性**：不过时，能承载品牌发展
5. **功能性**：适合各种应用场景


### Logo 禁用与使用规范

| 禁用场景 | 规范 |
|----------|------|
| 拉伸变形 | 保持固定宽高比 |
| 颜色随意 | 仅使用规范中的颜色 |
| 添加效果 | 禁止添加阴影/投影/渐变 |
| 遮挡裁切 | 完整展示 logo |
| 低对比度 | 确保与背景有足够对比 |

## 4. 色彩系统

### 色彩层级

| 层级 | 说明 | 使用比例 | 数量 |
|------|------|----------|------|
| 品牌主色 | 品牌核心识别色 | 60% | 1-2 色 |
| 品牌辅色 | 辅助表达、扩展色 | 30% | 2-3 色 |
| 功能色 | 状态、提示、功能指示 | 10% | 3-5 色 |
| 中性色 | 背景、文字、边框 | 背景比例 | 5-9 色 |

### 色彩命名规范

```
主色 (Primary)
├── 品牌红 (Brand Red) - #E63946
├── 品牌蓝 (Brand Blue) - #1D3557
└── 品牌金 (Brand Gold) - #F4A261

辅色 (Secondary)
├── 浅蓝 (Light Blue) - #A8DADC
├── 深绿 (Deep Green) - #2A9D8F
└── 橙色 (Orange) - #E9C46A

中性色 (Neutral)
├── 深灰 (Dark Gray) - #333333
├── 中灰 (Medium Gray) - #666666
├── 浅灰 (Light Gray) - #CCCCCC
└── 背景白 (Background) - #FAFAFA
```

### 色彩应用规则

| 应用场景 | 建议 |
|----------|------|
| 大面积背景 | 使用浅色或白色 |
| 主要按钮 | 使用主色 |
| 辅助元素 | 使用辅色 |
| 正文文字 | 使用深灰 (#333 或更深) |
| 辅助文字 | 使用中灰 (#666) |
| 边框分隔 | 使用浅灰 (#EEE 或 #CCC) |

## 5. 字体系统

### 字体层级

| 层级 | 用途 | 字号范围 | 行高比例 |
|------|------|----------|----------|
| H1 - 主标题 | 页面主标题 | 48-72px | 1.1-1.2 |
| H2 - 副标题 | 章节标题 | 32-40px | 1.2-1.3 |
| H3 - 小标题 | 内容小节 | 24-28px | 1.3-1.4 |
| Body - 正文 | 主要内容 | 16-18px | 1.5-1.6 |
| Caption - 说明 | 辅助说明 | 12-14px | 1.4-1.5 |

### 字体选择原则

1. **可读性优先**：正文选择无衬线字体
2. **品牌契合**：字体性格与品牌调性一致
3. **系统支持**：确保各平台可用性
4. **层级清晰**：通过字重/字号区分层级
5. **避免混用**：同一项目不超过 2 种字体族

### 推荐字体组合

| 场景 | 标题字体 | 正文字体 |
|------|----------|----------|
| 现代科技 | Montserrat | Open Sans |
| 高端奢华 | Playfair Display | Lato |
| 简约专业 | 思源黑体 | 思源黑体 |
| 活力创意 | Poppins | Inter |
| 传统稳重 | 思源宋体 | 思源黑体 |

## 7. VI 应用系统

### 办公应用

| 应用项 | 尺寸规范 | 输出格式 |
|--------|----------|----------|
| 名片 | 90×54mm / 3.5×2.1in | AI, PDF |
| 信封 | DL (220×110mm) / C4 (324×229mm) | AI, PDF |
| 信纸 | A4 (210×297mm) | AI, PDF |
| PPT 模板 | 16:9, 4:3 | PPTX |
| 邮件签名 | HTML | PNG + HTML |
| 工牌/胸卡 | 85.6×54mm | AI, PDF |

### 数字应用

| 应用项 | 规范 |
|--------|------|
| 网站 Logo | SVG, PNG (1x, 2x) |
| 社交媒体头像 | 圆形, 400×400px |
| 社交媒体封面 | Facebook: 820×312px, Twitter: 1500×500px |
| App Icon | iOS: 1024×1024px, Android: 512×512px |
| 微信头像 | 200×200px (服务器), 132×132px (展示) |

### 环境应用

| 应用项 | 规范 |
|--------|------|
| 门牌 | 亚克力/金属, 尺寸根据门体 |
| 背景墙 | 高清图, 需考虑照明 |
| 导视系统 | 统一风格, 符合人体工学 |
| 灯箱 | 考虑光源均匀性 |

## 9. 品牌设计质量检查清单

### Logo 检验

- [ ] 不同尺寸下清晰可辨
- [ ] 黑白版本可用
- [ ] 单色版本可用
- [ ] 反白版本可用
- [ ] 最小使用尺寸测试
- [ ] 与竞品有明显差异

### 色彩检验

- [ ] 主色符合品牌调性
- [ ] 辅色与主色协调
- [ ] 色彩对比度符合 WCAG 标准
- [ ] 色彩在不同材质上呈现一致
- [ ] 色彩应用场景已穷举

### 字体检验

- [ ] 字体可商用或有授权
- [ ] 各层级字号清晰区分
- [ ] 中英文搭配协调
- [ ] 不同平台显示一致

### 整体检验

- [ ] 品牌识别度高
- [ ] 视觉风格统一
- [ ] 应用场景覆盖完整
- [ ] 规范说明清晰可执行
- [ ] 源文件规范命名

| 应用场景 | 颜色模式 | 分辨率 |

| 社交媒体 | RGB | 72dpi |
