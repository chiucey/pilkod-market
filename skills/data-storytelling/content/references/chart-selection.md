# 图表选择参考指南

## 图表选择决策树

```
开始
  │
  ▼
需要展示什么？
  │
  ├─ 单一数值 ──────────────────────────► 简单文本（数字+单位）
  │
  ├─ 类别比较 ──────────────────────────► 条形图
  │     │
  │     └─ 类别多且名称长 ────────────► 水平条形图
  │     └─ 类别少且关注排名 ─────────► 垂直条形图
  │
  ├─ 时间趋势 ──────────────────────────► 折线图
  │     │
  │     └─ 多条线比较 ───────────────► 折线图（控制线条数 ≤ 5）
  │     └─ 显示区间范围 ─────────────► 面积图
  │
  ├─ 变量关系 ──────────────────────────► 散点图
  │     │
  │     └─ 展示分布密度 ──────────────► 带透明度的散点图
  │
  ├─ 前后变化 ──────────────────────────► 斜率图
  │
  ├─ 矩阵关系 ──────────────────────────► 热力图
  │
  └─ 部分与整体 ────────────────────────► 堆叠条形图
        │
        └─ 避免使用 ──────────────────► 饼图
```

## 各图表适用场景

### 简单文本

**适用场景**
- KPI 卡片
- 核心指标展示
- 对比数字展示

**示例**
```
离职率
  15.8%
  较上季度 ↓ 2.3%
```

**禁忌**
- 展示趋势变化（用折线图）
- 展示多个相关指标

### 条形图

**水平条形图适用场景**
- 类别名称较长（如城市名、人名）
- 类别数量较多（> 7 个）
- 关注排名顺序

**垂直条形图适用场景**
- 时间序列（但通常用折线图更佳）
- 类别数量较少（≤ 7 个）
- 强调单个高值

**制作要点**
- 排序应有逻辑（时间/数值/字母）
- 保持条形宽度一致
- 数值标签放在条形末端
- 网格线仅保留参考线

### 折线图

**适用场景**
- 时间序列趋势
- 连续数据变化
- 多指标对比

**制作要点**
- 线条数量 ≤ 5 条
- 避免使用标记点（除非关键点）
- Y 轴从 0 开始（或明确标注截断
- 适当使用面积填充增强效果

**禁忌**
- X 轴为非连续数据
- 时间点不均匀

### 散点图

**适用场景**
- 两个变量的相关性
- 识别异常值
- 分组展示

**制作要点**
- 添加趋势线
- 用颜色/形状区分分组
- 标注异常点
- 添加参考线（如平均线）

### 斜率图

**适用场景**
- 两个时间点间的变化
- 强调变化幅度
- 简单对比

**制作要点**
- 仅限两个时间点
- 线条粗细表示数值大小
- 高亮最大/最小变化项
- 按变化幅度排序

### 热力图

**适用场景**
- 矩阵数据（如部门 × 月份）
- 密度/强度展示
- 相关性矩阵

**制作要点**
- 使用渐变色（避免红绿搭配）
- 标注数值
- 行列有明确标签
- 色块大小一致

### 堆叠条形图

**适用场景**
- 部分与整体关系
- 多类别组成结构
- 累积效果展示

**制作要点**
- 控制在 5 个以内组成部分
- 使用单一色调渐变
- 从大到小排序
- 避免过多堆叠层次

## 配色参考

### 单色渐变（推荐）

```css
/* 蓝渐变 */
#EFF6FF → #3B82F6 → #1E40AF

/* 绿渐变 */
#F0FDF4 → #22C55E → #166534

/* 橙渐变 */
#FFF7ED → #F97316 → #9A3412
```

### 双色对比（用于强调）

```css
/* 蓝橙对比 */
#3B82F6 + #F97316

/* 绿红对比（慎用） */
#22C55E + #EF4444
```

### 色盲友好配色

避免使用：红-绿、黄-蓝
推荐使用：蓝-橙、蓝-灰

## 常见错误

1. **饼图滥用**：人眼不擅长判断角度和面积差异
2. **3D 图表**：扭曲数据比例，增加认知负荷
3. **双 Y 轴**：容易误导关联性判断
4. **过度装饰**：分散注意力，降低信噪比
5. **截断坐标轴**：不从 0 开始的 Y 轴会夸大差异
6. **网格线过密**：干扰数据读取
7. **图例远离数据**：增加认知负担
