# Slide Types Guide - 5种页面类型详解

本指南详细说明5种页面类型的用途、布局和生成方法。

---

## 1. 封面页 (Cover)

**用途**：开场、主题引入、给观众第一印象

**必需元素**：主标题（大字号，醒目）、副标题/描述（可选）、日期/机构/演讲者信息

**布局选项**：居中布局、左对齐布局、全屏色块型、左侧色块型

详见代码示例和完整指南。

---

## 2. 目录页 (Table of Contents)

**用途**：内容导航、帮助观众了解整体结构

**必需元素**：页面标题、章节列表（带编号）、页码指引（可选）

**布局选项**：垂直列表、网格卡片

详见代码示例和完整指南。

---

## 3. 分隔页 (Section Divider)

**用途**：章节过渡、视觉停顿、帮助观众消化内容

**必需元素**：章节编号（大字号）、章节标题、简介文字（可选）

**布局选项**：居中大号、左对齐色块

详见代码示例和完整指南。

---

## 4. 内容页 (Content)

**用途**：展示核心信息、详细阐述观点

**必需元素**：页面标题、内容要点/图表/数据、页码徽章

**内容子类型**：
- 文本型：概念解释、要点说明
- 数据型：统计展示、指标呈现
- 对比型：方案对比、利弊分析
- 流程型：步骤说明、流程展示
- 图片型：案例展示、产品介绍

详见代码示例和完整指南。

---

## 5. 总结页 (Summary)

**用途**：收尾，强化记忆、呼吁行动

**必需元素**：总结标题、关键要点（3-5条）、CTA/联系方式（可选）

**布局选项**：要点回顾型、CTA型、关键词云型、三点总结型

详见代码示例和完整指南。

---

## 页码徽章

除封面外，所有页面必须包含页码徽章：

```javascript
function addPageBadge(slide, pres, theme, pageNum) {
  slide.addShape(pres.shapes.OVAL, {
    x: 9.3, y: 5.1, w: 0.4, h: 0.4,
    fill: { color: theme.accent }
  });
  slide.addText(String(pageNum), {
    x: 9.3, y: 5.1, w: 0.4, h: 0.4,
    fontSize: 12, fontFace: "Arial",
    color: "FFFFFF", bold: true,
    align: "center", valign: "middle"
  });
}
```

## 页面类型选择决策树

```
内容类型是什么？
│
├─ 开场/主题引入 → 封面 (Cover)
├─ 章节导航/总览 → 目录 (TOC)
├─ 章节过渡/停顿 → 分隔页 (Divider)
├─ 核心信息展示 → 内容页 (Content)
│   ├─ 数据/指标 → 数据卡片布局
│   ├─ 流程/步骤 → 时间线布局
│   ├─ 对比分析 → 双列布局
│   └─ 概念解释 → 要点列表布局
└─ 收尾/回顾 → 总结页 (Summary)
```
