# Creative Layouts Guide - 创意布局设计指南

本指南提供高阶布局技巧和创意模板，让生成的PPT更具视觉冲击力和设计感。

---

## 核心设计原则

### 1. 视觉层次
- **大小对比**：标题 > 副标题 > 正文 > 注释
- **色彩对比**：主色用于重要元素，浅色用于次要
- **留白节奏**：重要内容周围留白，密集内容紧凑排列

### 2. 动态平衡
- **对称平衡**：左右/上下镜像排列
- **不对称平衡**：通过大小、颜色、形状实现视觉平衡
- **对角线布局**：引导视觉流动

### 3. 创意技巧
- **负空间**：利用空白区域创造呼吸感
- **层叠效果**：卡片叠加制造深度
- **几何装饰**：浮动元素增加动感

---

## 封面页创意布局

### 1. 全屏色块型
背景全用主色，标题居中，大字号。

### 2. 左侧色块型
左侧色块占30%，右侧放标题和内容。

### 3. 几何装饰型
右上角/左下角浮动圆形，斜线装饰。

---

## 内容页创意布局

### 1. 卡片瀑布流
适用于多项目展示、特性介绍。高度不一的卡片错落排列。

### 2. 数字强调型
适用于数据展示。主数据超大字号，下方4个指标卡片。

### 3. 时间线流程型
适用于流程说明。横线+节点圆圈+下方内容卡片。

```javascript
function createTimelineLayout(pres, theme) {
  const steps = [
    { num: "01", title: "步骤1", desc: "描述1" },
    { num: "02", title: "步骤2", desc: "描述2" },
    { num: "03", title: "步骤3", desc: "描述3" }
  ];

  const lineY = 2.4;
  slide.addShape(pres.shapes.LINE, {
    x: 1.2, y: lineY, w: 7.0, h: 0,
    line: { color: theme.accent, width: 4 }
  });
  // 节点和卡片...
}
```

### 4. 双栏对比型
适用于方案对比。左右两列卡片，优缺点对比。

### 5. 网格画廊型
适用于案例展示。不同大小的图片网格排列。

## 总结页创意布局

### 1. 关键词云型
大字号的关键词散落排列，底部CTA按钮。

### 2. 三点总结型
三个大数字+标题+描述的卡片布局。

## 装饰元素库

### 浮动气泡
```javascript
function addFloatingBubbles(slide, pres, theme) {
  const bubbles = [
    { x: 8.5, y: 0.5, size: 1.2, t: 60 },
    { x: 7.8, y: 1.8, size: 0.6, t: 40 }
  ];
  bubbles.forEach(b => {
    slide.addShape(pres.shapes.OVAL, {
      x: b.x, y: b.y, w: b.size, h: b.size,
      fill: { color: theme.accent, transparency: b.t }
    });
  });
}
```

## 布局选择决策表

| 内容类型 | 推荐布局 | 视觉效果 |
|---------|---------|---------|
| 多项目/特性 | 卡片瀑布流、网格画廊 | 信息丰富、层次分明 |
| 数据指标 | 数字强调型、数据卡片 | 重点突出、数字醒目 |
| 流程步骤 | 时间线流程型 | 清晰有序、逻辑连贯 |
| 方案对比 | 双栏对比型 | 公平客观、一目了然 |
| 总结回顾 | 三点总结型、关键词云 | 强化记忆、呼吁行动 |
| 品牌展示 | 几何装饰型、全屏色块 | 高端大气、视觉冲击 |
