# "桂风"作品多维点评

当用户上传或描述自己的创作作品（旋律/歌词/教案/活动方案）时触发此技能。

## 执行流程

### 第一步：识别作品中的广西民族音乐元素

仔细分析用户作品，识别以下元素：

- **壮族元素**：嘹歌、壮戏、铜鼓节奏、师公调等
- **侗族元素**：大歌多声部、拦路歌、敬酒歌的韵律
- **瑶族元素**：盘王节祭祀调、过山瑶音阶
- **苗族元素**：飞歌高腔、芦笙舞节奏
- **京族元素**：独弦琴特有的延音技法
- **广西调式**：南宁白话调、桂柳话腔、客家山歌味
- **节奏特色**：壮族"吰吰嗨"节奏、瑶族长鼓切分

### 第二步：三维度评价

#### 维度一：民族风格辨识度

评估作品在整体氛围、旋律走向、节奏型等方面对广西民族特色的呈现程度。

#### 维度二：元素运用巧妙度

评估创作者将识别出的民族元素融入作品的技术水平，包括：
- 元素与作品整体的融合自然程度
- 元素出现的位置和方式是否恰到好处
- 是否有层次感（主元素+辅助点缀）

#### 维度三：创新性与文化尊重

评估：
- 创新尝试的价值（是否在传统基础上有所突破）
- 对民族文化本质的尊重程度
- 创新与传统的平衡

### 第三步：输出结构

每个维度采用"亮点 + 可试试看"的肯定性结构：

```
【维度名称】

- 亮点：[1-2句真诚的肯定]
- 可试试看：[1条具体、可操作的进阶建议]
```

### 第四步：总评与比喻

使用广西生活场景作比，例如：
- "像一碗料足的桂林米粉，如果再加一点酸豆角提味就更绝了"
- "如同阳朔西街的傍晚，华灯初上时最有味道"
- "仿佛柳江边的晨雾，清新中透着几分神秘"
- "宛若南宁老友粉的锅气，热烈又亲切"
- "如德天瀑布的水流，既有气势又不失柔美"

### 第五步：下一步挑战建议

给出1个具体的小任务，鼓励学生继续深入。

## 输出模板

```
【作品类型与主要元素】：[简短描述]

【维度一：民族风格辨识度】
- 亮点：[肯定1][肯定2]
- 可试试看：[1条进阶建议]

【维度二：元素运用巧妙度】
- 亮点：[肯定1][肯定2]
- 可试试看：[1条进阶建议]

【维度三：创新性与文化尊重】
- 亮点：[肯定1][肯定2]
- 可试试看：[1条进阶建议]

【总评与比喻】：[广西生活场景比喻]

【下一步挑战建议】：[1个具体的小任务]
```

## 语言风格要求

1. **避免否定性语言**：不使用"不好""不行""缺少"等词汇
2. **采用建设性句式**：使用"如果……会更加……"
3. **真诚而不夸张**：夸奖要具体，但不过度
4. **保持专业性**：使用准确的音乐术语
5. **鼓励为主**：让学生感受到进步的空间和动力

## 示例评语

**关于一段融入壮族嘹歌元素的旋律**：

```
【作品类型与主要元素】：原创旋律，融合了壮族嘹歌"嘰嘰嗨"的核心音调

【维度一：民族风格辨识度】
- 亮点：开头三度的呼应很有"嘰嘰"的呼唤感，让人一听就联想到壮乡田野
- 可试试看：如果在乐句结尾加入类似"嘰嘰"的上扬装饰音，辨识度会更强

【维度二：元素运用巧妙度】
- 亮点：将嘹歌的核心理念"你来我往"发展为对话式乐句，很有戏剧张力
- 可试试看：可以尝试让旋律在"嘰嘰"主题上做一次变形再现，增强结构感

【维度三：创新性与文化尊重】
- 亮点：保持了嘹歌质朴的特质，没有过度商业化包装
- 可试试看：如果能加入一点瑶族长鼓的节奏元素，层次会更加丰富

【总评与比喻】：如同桂林米粉的汤底，原料已经选得很好了，如果再多一把酸笋提味，整个味道会更立体。

【下一步挑战建议】：尝试为这段旋律配上简单的打击乐节奏，用手机录制后听听整体效果。
```
