## 阶段一：系统构建与材料分析

### 步骤1：全局设计系统构建

**执行内容：**
1. 确立五色限定规范
   - 深海蓝 #0B528D（主色）
   - 天空蓝 #5A97CA（辅色）
   - 薰衣草蓝 #7CA5E8（点缀）
   - 雾灰白 #CFD1DE（背景）
   - 珊瑚橙 #F18765（强调）

2. 建立字体层级
   - H1 主标题：深海蓝，28-32pt，Bold
   - H2 副标题：珊瑚橙 = H1×0.74（强制），Semibold
   - H3 正文：深海蓝，14-16pt，Regular
   - H4 注释：天空蓝，10-12pt，Regular

3. 构建渐变系统
   - 品牌渐变：深海蓝→天空蓝→薰衣草蓝
   - 强调渐变：珊瑚橙→雾灰白

4. 确认章节控制数量
   - <30页：≤3章
   - 30-60页：≤5章
   - >60页：≤7章

**输出：** 完整设计规范文档

---

### 步骤2：系统性图像提取

**执行内容：**
1. 100%提取所有图像资产
   - 扫描上传文件中的每一张图片
   - 记录原始分辨率和格式
   - 建立提取清单

2. 建立图像元数据库
   ```
   字段：
   - 文件名
   - 来源页码
   - 图像类型（实景/截图/流程图/图表）
   - 原始分辨率
   - 质量评级（1-5）
   - 叙事权重评估
   - 章节分隔页候选标记
   ```

3. 标记章节分隔页候选意象
   - 筛选适合章节分隔页的全景/氛围图像
   - 记录推荐理由

**输出：** 图像元数据库表

---

### 步骤3：强制评估矩阵

**执行内容：**
每张图像必须通过五类决策之一：

| 决策类别 | 说明 | 处理方式 |
|----------|------|----------|
| 保留优化 | 高质量、叙事相关 | 直接使用 + 专业后期 |
| 艺术裁切 | 构图可优化 | 智能裁切 + 后期 |
| 章节意象 | 适合章节分隔页 | 特殊处理 + 遮罩 |
| 信息重绘 | 图表/流程图 | 矢量转化 |
| 辅助参考 | 参考价值低 | 仅作参考 |

**评估矩阵示例：**
```
图像001: 工厂航拍全景.jpg
- 来源: 原始文件 P.1
- 质量: 5/5
- 叙事相关性: 高
- 情感冲击力: 高
- 决策: 章节意象 → 封面候选

图像007: 竞争对手工厂实拍.jpg
- 来源: 原始文件 P.7
- 质量: 4/5
- 叙事相关性: 高
- 情感冲击力: 中
- 决策: 保留优化 → 内容页形式A

图像012: 流程图.jpg
- 来源: 原始文件 P.12
- 质量: 3/5
- 叙事相关性: 中
- 决策: 信息重绘 → 矢量图表
```

## 阶段二：架构规划与页面设计

### 步骤4：章节架构规划

**执行内容：**
1. 按控制数量拆分材料
   - 根据预估总页数确定章节数
   - 划分每章节主题范围

2. 分配主题与页数
   - 平衡各章节内容量
   - 确保一页一主题

3. 规划章节分隔页意象
   - 每章分配1张核心意象
   - 设计渐变遮罩方案

**章节结构示例（3章）：**
```
CH.01 市场格局与竞争态势
├─ 分隔页
├─ P.1 行业宏观分析
├─ P.2 竞争对手全景
├─ P.3 竞争态势诊断
└─ P.4 SWOT分析

CH.02 运营效率与数字化转型
├─ 分隔页
├─ P.5 数字化现状评估
├─ P.6 转型路径规划
├─ P.7 实施成效展示
└─ P.8 关键指标达成

CH.03 战略建议与实施路径
├─ 分隔页
├─ P.9 战略目标设定
├─ P.10 实施路线图
├─ P.11 风险管控措施
└─ P.12 致谢与展望
```

---

### 步骤5：战略框架植入

**执行内容：**
识别并应用适合的战略分析模型：

| 模型 | 适用场景 | 植入时机 |
|------|----------|----------|
| SWOT | 综合分析 | 竞争格局章节 |
| 波特五力 | 行业分析 | 市场分析章节 |
| BCG矩阵 | 业务组合 | 能力评估章节 |
| 价值链 | 流程优化 | 运营效率章节 |
| 趋势预测 | 未来展望 | 战略建议章节 |
| 情景规划 | 不确定性 | 风险管控章节 |

**植入要求：**
- 模型与内容高度匹配
- 视觉呈现统一风格
- 融入五色渐变元素

---

### 步骤6：副标题体系生成

**执行内容：**
为每页生成加粗一句话核心洞察：

**规则：**
- 置于主标题下方
- 字号 = H1 × 0.74（强制）
- 色彩 = 珊瑚橙 #F18765（强制）
- 字重 = Semibold
- 内容 = 完整句子的核心洞察
- 衬底 = 无色块（强制）

**生成流程：**
1. 提炼本页核心论点
2. 转化为行动导向的洞察表述
3. 控制在20-30字
4. 确保与主标题逻辑关联

**示例：**
```
主标题：核心竞争对手战略动向与应对矩阵
副标题：三巨头技术投入年增35%形成压制，我方需以差异化场景突破避免正面消耗
字数：28字 ✓
语气：洞察性 ✓
行动导向：✓
```

### 步骤7：数据标注筛选

**执行内容：**
1. 识别须标注的专业/官方数据
   - 研究机构报告数据
   - 政府/官方统计数据
   - 行业协会数据
   - 第三方研究数据

2. 格式规范
   ```
   数据来源：[机构名称/年份/报告名称]
   ```

3. 其他数据处理
   - 内部数据：标注但不强制
   - 估算数据：标注但不强制

## 阶段三：视觉设计与整合

### 步骤8：艺术裁切方案

**执行内容：**
1. 智能计算裁切区域
   - 分析图像核心内容区域
   - 计算最优构图比例
   - 确定裁切边界

2. 保护核心表达
   - 识别图像叙事主体
   - 避免裁切破坏主体
   - 强化视觉焦点

3. 锁定宽高比
   - 常用比例：16:9, 4:3, 1:1, 2.35:1
   - 禁止拉伸变形
   - 基于目标页面布局选择

**裁切决策矩阵：**
```
图像类型          推荐比例    裁切策略
─────────────────────────────────────
人物场景          4:3         保留全身/半身
产品特写          1:1         中心构图
建筑/厂区          2.35:1      全景横幅
数据图表          16:9        保持完整
流程示意          16:9/4:3    横向展开
```

---

### 步骤9：多图组合设计

**触发条件：** ≥3张关联图像

**执行内容：**
1. 选择形式M（多图组合冲击）
2. 大小对比编排
   - 主图：40-50%
   - 辅图：错落排列
3. 位置错落
   - 间距：8-16pt
   - 高低错落
4. 色彩呼应
   - 统一后期风格
   - 低饱和冷色调
5. 叙事序列
   - 按逻辑/时间排列
   - 形成视觉故事线

**布局示例（6图）：**
```
┌──────────────────────────────────┐
│   ┌─────┐      ┌───────────┐    │
│   │     │      │           │    │
│   │ 主图│      │   辅图2    │    │
│   │ 40% │      │   25%     │    │
│   └─────┘      └───────────┘    │
│      ┌─────┐ ┌─────┐ ┌─────┐   │
│      │辅图3│ │辅图4│ │辅图5│   │
│      └─────┘ └─────┘ └─────┘   │
│            ┌─────┐              │
│            │辅图6│              │
│            └─────┘              │
└──────────────────────────────────┘
```

### 步骤10：形式适配与视觉平衡

**执行内容：**
1. 最优形式分配
   - 根据图像数量选择13种形式之一
   - 考虑内容关联性
   - 匹配叙事节奏

2. 重心计算
   - 图像区域重心
   - 文字区域重心
   - 整体页面重心
   - 目标：偏差 ≤5%

3. 留白控制
   - 目标：15-25%
   - 确保视觉呼吸
   - 避免拥挤

---

### 步骤11：矢量图表转化

**执行内容：**
1. 统一风格规格
   - 线条：2pt（品牌渐变描边）
   - 圆角：4pt
   - 数据标签：H4，无色块衬底

2. 填充规范
   - 薰衣草蓝低透明度
   - 或雾灰白低透明度
   - 仅图表内部

3. 强调处理
   - 珊瑚橙 #F18765
   - 用于关键数据高亮
   - 禁止色块衬底

**矢量图表模板：**
```
SWOT矩阵：
┌─────────────────────────────┐
│     │   有利      │   不利  │
├─────┼─────────────┼─────────┤
│内部 │   S优势     │   W劣势 │
│     │   (珊瑚橙)  │         │
├─────┼─────────────┼─────────┤
│外部 │   O机会     │   T威胁 │
│     │             │  (珊瑚橙)│
└─────────────────────────────┘
线条: 2pt 品牌渐变
圆角: 4pt
填充: 薰衣草蓝20%
```

## 阶段四：质量保证与终审

### 步骤12：边界安全预审

**执行内容：**
1. 40pt安全边距确认
   - 上边距 ≥40pt
   - 下边距 ≥40pt
   - 左右边距 ≥40pt

2. 预演元素位置
   - 模拟每页元素布局
   - 计算精确坐标
   - 确保无重叠

3. 溢出风险检测
   - 文字溢出检测
   - 图像边界检测
   - 图表边界检测

---

**强制规则：**
1. 纯白背景 #FFFFFF
2. 无色块衬底
3. 副标题珊瑚橙74%
4. 每页至少一张原生图像

**编排检查清单：**
- [ ] 背景色为纯白
- [ ] 无色块衬底
- [ ] 副标题色彩正确
- [ ] 副标题字号正确
- [ ] 原生图像已嵌入

### 步骤14：内容边界终审

**执行内容：**
1. 逐页精确校验

   - 验证所有边界
   - 确认无溢出

2. 零溢出保证
   - 文字框边界
   - 图像边界
   - 图表边界

### 步骤15：视觉节奏审查

2. 节奏控制
   - 内容页密度变化
   - 章节分隔页呼吸
   - 整体阅读节奏
