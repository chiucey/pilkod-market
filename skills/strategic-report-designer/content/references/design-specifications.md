# 战略报告设计师 - 设计规范参考

## 五色色值详解

### 深海蓝 #0B528D
**主色 Primary Color**
- 主标题文字（H1）
- 章节分隔页背景
- 图表主线条
- 正文内容
- 矢量图表主色

### 天空蓝 #5A97CA
**辅色 Secondary Color**
- 页眉页脚
- 装饰渐变节点
- 图表辅助元素
- 注释文字（H4）
- 装饰元素

### 薰衣草蓝 #7CA5E8
**点缀色 Accent Color**
- 渐变终点
- 轻填充
- 柔和强调
- 图表内部填充

### 雾灰白 #CFD1DE
**背景/分隔色 Background/Separator**
- 装饰渐变淡出
- 副标题文字（封面）
- 章节分隔页副标题
- 强调渐变终点

### 珊瑚橙 #F18765
**强调色 Accent/Highlight**
- 副标题（强制）
- 数据高亮
- 关键数据标注
- 警示信息
- 章节分隔页强调装饰

## 渐变系统详解

### 品牌渐变 (Brand Gradient)
```
深海蓝 #0B528D → 天空蓝 #5A97CA → 薰衣草蓝 #7CA5E8
```
**用途：**
- 章节分隔页装饰线
- 图表线条渐变描边
- 品牌视觉元素

### 强调渐变 (Accent Gradient)
```
珊瑚橙 #F18765 → 雾灰白 #CFD1DE
```
**用途：**
- 章节分隔页变化
- 强调装饰元素
- 数据高亮渐变

### 遮罩渐变 (Mask Gradient)
- 章节分隔页：深海蓝 25-50% 透明度
- 内容页遮罩：雾灰白 80-90% 透明度
- 图像半透明处理

## 字体层级规范

### 字号计算示例

假设主标题 H1 = 30pt：

| 层级 | 计算公式 | 字号 | 色彩 | 字重 |
|------|----------|------|------|------|
| CH | H1 × 1.3-1.4 | 36-42pt | 纸白/深海蓝 | Bold |
| H1 | 基准 | 30pt | 深海蓝 #0B528D | Bold |
| H2 | H1 × 0.74 | 22.2pt | 珊瑚橙 #F18765 | Semibold |
| H3 | H1 × 0.47-0.53 | 14-16pt | 深海蓝 #0B528D | Regular |
| H4 | H1 × 0.33-0.4 | 10-12pt | 天空蓝 #5A97CA | Regular |

### 副标题（H2）规范

**强制要求：**
- 色彩：珊瑚橙 #F18765
- 字号：主标题 × 0.74
- 字重：Semibold
- 内容：完整句子的核心洞察
- 衬底：禁止色块衬底

**正确示例：**
```
主标题：三巨头技术投入年增35%形成压制
副标题（珊瑚橙，22.2pt）：我方需以差异化场景突破避免正面消耗
```

**错误示例：**
```
副标题：关键发现一  ← 非完整句子
副标题：[关键数据]  ← 非洞察性表述
```

## 13种原生图像形式详解

### A - 单图主导
**特征：** 单张大幅图像占50-70%，文字图表环绕
**适用：** 核心场景展示、关键产品/技术图示
**布局：**
```
┌─────────────────────────────┐
│  图像 (55%)    │   SWOT    │
│                │   矩阵    │
│                │   (45%)   │
└─────────────────────────────┘
```

### B - 双图对话
**特征：** 两张图像并置，对比或呼应
**适用：** Before/After、前后对比、方案A/B对比

### C - 三图序列
**特征：** 三张图像排列，时间或逻辑递进
**适用：** 发展阶段、演进历程、流程步骤

### D - 四图网格
**特征：** 2×2矩阵，多维度场景
**适用：** 四象限分析、多维度对比

### E - 全景横幅
**特征：** 2.35:1超宽幅，贯穿页面
**适用：** 鸟瞰图、全景图、航空摄影

### F - 对比并置
**特征：** Before/After，中央渐变分隔线
**适用：** 转型前后、改造成果

### G - 时间轴串联
**特征：** 图像沿时间轴，渐变线条节点
**适用：** 时间线展示、历史演进

### H - 环形环绕
**特征：** 中央图表，周边环形图像
**适用：** 生态系统、业务布局

### I - 层叠透视
**特征：** 透明度渐变层叠
**适用：** 战略层次、多维度分析

### J - 蒙太奇拼贴
**特征：** 不规则网格，视觉张力
**适用：** 多场景组合、视觉冲击

### K - 出血沉浸
**特征：** 图像延伸至边缘，渐变遮罩
**适用：** 沉浸式场景、视觉强调

### L - 画中画嵌套
**特征：** 主图像含小图窗口
**适用：** 细节放大、关联展示

### M - 多图组合冲击
**特征：** 3-8张有机组合，大小对比/位置错落
**适用：** 关键节点展示、综合成果
**触发条件：** ≥3张关联图像

## 页面结构规范

### 封面页模板

```html
背景: 深海蓝 #0B528D

主标题: "智能制造转型战略咨询报告"
- 字体: 纸白 #FAFAFA
- 字号: 48-56pt
- 字重: Bold
- 位置: 距顶 80pt

副标题: "从传统制造到智能工厂的72小时蜕变全景"
- 字体: 雾灰白 #CFD1DE
- 字号: 28-32pt
- 位置: 距主标题 24pt

核心意象: 原始文件工厂全景航拍
- 全出血
- 深海蓝 30%→50% 渐变遮罩

渐变装饰线: 品牌渐变
- 长度: 60%
- 高度: 2pt
- 位置: 居中，距副标题 32pt

边界校验: 所有元素距边缘 ≥50pt
```

### 章节分隔页模板

```html
背景: 深海蓝 #0B528D 至 75% 深度渐变

章节编号: "CH.01"
- 字体: H4, 12pt
- 配色: 品牌渐变
- 位置: 距顶 60pt

章节主标题: "市场格局与竞争态势"
- 字体: 纸白 #FAFAFA
- 字号: 36-42pt
- 字重: Bold
- 位置: 距编号 24pt
- 衬底: 无色块

渐变装饰线: 品牌渐变
- 配色: 深海蓝→天空蓝→薰衣草蓝
- 长度: 50%
- 高度: 2pt
- 位置: 居中，距标题 16pt

核心意象: 原始文件行业峰会航拍
- 比例: 2.35:1 超宽幅
- 高度: 90%
- 出血: 全出血
- 遮罩: 深海蓝 25%→45%（底部重顶部轻）

章节洞察短语: "从分散竞争向头部集中过渡的关键窗口期"
- 字体: 雾灰白 #CFD1DE
- 字号: H3, 16pt
- 位置: 距装饰线 20pt

边界校验: 所有元素距边缘 ≥50pt
```

### 内容页模板

```html
背景: 纯白 #FFFFFF (强制)

页眉: "03 | 竞争态势诊断"
- 字体: H4, 天空蓝 #5A97CA
- 位置: 距顶 40pt

主标题: "核心竞争对手战略动向与应对矩阵"
- 字体: H1, 深海蓝 #0B528D
- 字号: 28-32pt
- 字重: Bold
- 位置: 距页眉 16pt

副标题: "三巨头技术投入年增35%形成压制，我方需以差异化场景突破避免正面消耗"
- 字体: H2, 珊瑚橙 #F18765 (强制)
- 字号: H1×0.74 (约 20.7-23.7pt)
- 字重: Semibold
- 位置: 距主标题 8pt
- 衬底: 无色块 (强制)

布局示例: 单图主导(左55%) + SWOT矩阵(右45%)

原生图像: 竞争对手工厂实拍
- 裁切: 智能16:9
- 后期: 饱和度-25%，色温5800K

SWOT矩阵:
- 线条: 2pt 品牌渐变
- 圆角: 4pt
- 填充: 薰衣草蓝低透明度
- 强调: 珊瑚橙 #F18765

数据标注: "技术投入对比：巨头￥48亿 vs 我方￥9.6亿 | 数据来源：年报拆解2024"

页脚: 距底 40pt
- 专业数据来源标注 (H4, 天空蓝)

边界校验:
- 图像右边缘距矩阵左边缘: 20pt
- 矩阵右边缘距页面右边缘: 40pt
- 所有元素距边缘: ≥40pt
- 零溢出 (强制)
```

## 数据标注规范

### 必须标注的数据
- 专业研究机构数据
- 严谨研究数据
- 官方机构数据
- 科学数据
- 行业协会数据

### 标注格式
```html
数据来源：[机构名称/年份/报告名称]
```

### 示例
```
数据来源：年报拆解2024
数据来源：IDC中国研究部2024Q3
数据来源：国家统计局2024
```

### 不强制标注的数据
- 内部数据（标注但不强制）
- 估算数据
- 经验数据

## 质量红线清单

### 绝对禁止
1. 任何第六色、高饱和度色、荧光色
2. 色块衬底（副标题、数据标签等）
3. 内容溢出页面边界
4. 图像扭曲变形
5. 过度裁切
6. 非珊瑚橙副标题
7. 副标题字号 ≠ 74%
8. 章节数量超控
9. 非纯白内容页背景
10. 连续三页同形式

### 强制执行
1. 五色限定合规
2. 无色块衬底
3. 专业数据标注
4. 零溢出
5. 纯白背景
6. 副标题珊瑚橙74%
7. 渐变规范
8. 每页至少一张原生图像

## 视觉平衡规范

### 重心控制
- 重心偏差：≤5%
- 留白比例：15-25%

### 黄金分割应用
- 图像区域可采用黄金分割（1:1.618）
- 文字与图像比例可参考黄金分割

### 三分法则
- 重要元素放置在三分线交点
- 视线引导沿三分线

## 渐变装饰线规范

### 品牌渐变装饰线
```
起点: 深海蓝 #0B528D
中点: 天空蓝 #5A97CA
终点: 薰衣草蓝 #7CA5E8
```
- 长度: 40-60% 页面宽度
- 高度: 1.5-2pt
- 位置: 居中或左对齐

### 强调渐变装饰线
```
起点: 珊瑚橙 #F18765
终点: 雾灰白 #CFD1DE
```
- 用途: 章节分隔页变化、强调元素

### 渐变透明度
- 章节分隔页遮罩: 深海蓝 25-50%
- 内容页遮罩: 雾灰白 80-90%
