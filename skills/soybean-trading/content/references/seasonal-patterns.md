## 二、年度季节周期四阶段

### 阶段1️⃣：北美播种与出苗期（4月下旬 - 6月中旬）

**核心逻辑：**
- USDA 种植面积报告（3月底/6月底）→ 确定种植面积
- 作物出苗率 + 土壤湿度 → 市场定价单产潜力
- 天气的任何异常（干旱/过湿/低温）→ 价格快速反应

**历史规律：**
- 4月做多胜率72%，平均收益+1.8% → 季节性最强做多月之一
- 5月高波动（ATR 22¢）→ 方向不明确，适合期权买入
- 6月胜率68%，+2.4%平均收益 → 第二强做多月

**典型行情：**
```
2012年：6月干旱预警 → 月涨幅+28.5%（历史最大6月涨幅）
2020年：5月播种进度延迟 → 月涨幅+18.6%
2022年：6月干旱 → 月涨幅+14.3%
```

### 阶段2️⃣：北美关键生长期（6月下旬 - 8月中旬）

**核心逻辑：**
- 授粉期（7月）对产量最敏感——"都说7月是关键"
- 干旱指数（Palmer Drought Index）→ 直接关联单产损失
- 天气预报是主要价格驱动因子

**历史规律：**
- 7月是年度最强做多月（胜率74%，平均+3.1%）
- 8月高波动（ATR 30¢）——天气炒作峰值
- 8月后半段：早收压力开始显现

**典型行情：**
```
1988年：7月热浪 + 干旱 → 大豆+48%（年内最高）
2012年：7-8月极端干旱 → 6-8月累计涨幅+52%
2023年：8月干旱（爱荷华/伊利诺伊） → 月涨幅+12.4%
```

### 阶段3️⃣：北美收割压力期（9月 - 11月中旬）

**核心逻辑：**
- 收割进度推进 → 现货季节性供应压力
- 农户销售节奏 → 商业持仓变化
- 单产数据逐步确认 → USDA修正

**历史规律：**
- 9月胜率仅45%（35年仅16次上涨）
- 10月是最强做空月（胜率35%，平均-2.1%）
- 11月前半段仍有收割压力，后半段转向南美播种

**典型行情：**
```
2018年：创纪录丰收 → 9-11月累计跌幅-18.3%
2020年：9月良好收割天气 → 月跌幅-9.2%
2016年：丰产确认 → 10月跌幅-12.8%
```

### 阶段4️⃣：南美种植与北美消费期（11月下旬 - 次年3月）

**核心逻辑：**
- 南美播种进度（巴西/阿根廷）→ 新季产量预期
- 美国出口销售进度 vs USDA年度目标
- 中国需求节奏（进口商采购窗口）

**历史规律：**
- 12月-2月：方向不明，震荡为主
- 3月：南美产量预估确认 + 北美新季播种展望

## 四、天气对季节性的非线性影响

### 4.1 NINO 3.4 指数与大豆单产

厄尔尼诺/拉尼娜对全球大豆主产区的影响：

```
强厄尔尼诺（NINO > +0.8）：
  ✓ 巴西中南部：降雨偏多 → 单产↑（正常或偏高）
  ✗ 阿根廷：干旱风险 → 单产↓（减产30-40%概率）
  → 净效果：CBOT方向不确定（阿根廷减产vs巴西丰产）

强拉尼娜（NINO < -0.8）：
  ✗ 巴西中南部：干旱 → 单产↓
  ✓ 阿根廷：降雨正常 → 单产↑
  ✗ 美国（6-8月）：高温干旱风险↑
  → 净效果：CBOT 大豆价格通常上涨（美国风险溢价）
```

### 4.2 美国干旱监测指数（Drought Monitor）

```
D0（异常干燥）→ 单产影响：0-5%
D1（中度干旱）→ 单产影响：5-10%
D2（严重干旱）→ 单产影响：10-15%
D3（极端干旱）→ 单产影响：15-25%
D4（异常干旱）→ 单产影响：>25%（历史极值）
```
