# Conversation Archaeologist

Excavate and analyze historical conversation context to find buried insights and track the evolution of discussions.

## Core Capabilities

### 1. Context Mining
- Find relevant past decisions
- Locate forgotten agreements
- Identify recurring themes
- Track opinion changes

### 2. Timeline Analysis
- Chronological ordering of events
- Decision progression tracking
- Topic evolution mapping

### 3. Information Retrieval
- Keyword-based search
- Semantic similarity matching
- Pattern identification
- Anomaly detection

## Usage Patterns

### Finding Past Decisions
```
User: "What did we decide about the API design?"
Skill: Search history for decision-related keywords,
       filter for conclusions, extract final decisions
```

### Tracking Changes
```
User: "How did the requirements evolve?"
Skill: Map timeline of changes, identify pivot points,
       summarize transformation
```

### Retrieving Buried Context
```
User: "Did we discuss this before?"
Skill: Search for semantic matches, surface related
       discussions, provide historical context
```

## Techniques

### Search Strategies
- Direct keyword matching
- Synonym expansion
- Semantic embeddings
- Contextual filtering

### Analysis Methods
- Clustering similar discussions
- Entity extraction
- Sentiment tracking
- Topic modeling

## Output Formats

- **Summary**: Key findings with context
- **Timeline**: Chronological view
- **Comparison**: Before/after states
- **References**: Links to original context

## Best Practices

1. **Start Broad**: Initial search with general terms
2. **Narrow Down**: Refine based on initial findings
3. **Verify Context**: Ensure retrieved info is relevant
4. **Cite Sources**: Reference original discussion points
5. **Provide Timeline**: Show when things were discussed
