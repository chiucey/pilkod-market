# 去AI味写作检查清单

## 撰写前检查

- [ ] 确认目标平台（腾讯云/掘金/InfoQ等）
- [ ] 确认文章类型（A/B/C/D型）
- [ ] 确认目标读者画像
- [ ] 确认预期篇幅（短篇1500字/中篇3000字/长篇5000字）
- [ ] 完成素材溯源分类
- [ ] 用户确认知识边界

## 撰写中检查

### 词汇层面
- [ ] 无"首先/其次/最后"连接词
- [ ] 无"总而言之/综上所述"总结癖
- [ ] 无"赋能/助力/致力于"等AI腔
- [ ] 无"无缝衔接/不言而喻"翻译腔
- [ ] 无"该方案/上述问题"公文腔
- [ ] 用"得/要/能"替代"需要/应当/可以"

### 节奏层面
- [ ] 有短句打破节奏（如"就这么简单。""没戏。"）
- [ ] 段落长度不一致
- [ ] 无对称列表（1. 2. 3.）
- [ ] 避免每个点都是"主标题+三行解释"

### 结构层面
- [ ] Trade-offs 章节存在（倒数第二章节）
- [ ] Pitfalls 章节存在（最后章节）
- [ ] Pitfalls 至少包含2个实战误区
- [ ] 配图备注符合平台要求

### 技术锚点
- [ ] 每个概念有具体技术载体
- [ ] 代码示例标注语言和来源
- [ ] 数据有出处（官方文档优先）

### 态度层面
- [ ] 有明确技术立场
- [ ] 非中立腔（允许批评/推荐）
- [ ] 允许情绪词汇
- [ ] 无过度"端水"

## 撰写后检查

- [ ] 全文朗读检查流畅度
- [ ] 无遗漏的AI腔词汇
- [ ] 章节逻辑通顺
- [ ] 结尾自然收束（无强行升华）
- [ ] 格式符合目标平台规范
