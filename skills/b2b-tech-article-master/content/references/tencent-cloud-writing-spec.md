# 腾讯云技术社区写作规范

> 适用于腾讯云技术社区 FinClip、小程序容器等技术相关文章

---

## 一、平台文章结构

### 必须使用的 A/B/C/D 型结构

当目标平台为腾讯云时，**必须从以下4种结构中选择1种**：

| 类型 | 名称 | 适用场景 |
|------|------|----------|
| A型 | 技术实践型 | 有明确案例的技术实践分享 |
| B型 | 原理解析型 | 技术原理深度剖析 |
| C型 | 架构设计型 | 系统架构设计分享 |
| D型 | 见解思考型 | 行业洞察与方法论沉淀 |

### 结构规则

- **倒数第二章节**：必须是 Trade-offs（技术局限性与边界条件）
- **最后章节**：必须是 Pitfalls（已知问题与规避方案）
- **配图备注**：必须备注"背景干净、无水印、图文强相关"

### 通用平台章节结构（5章模板）

1. **背景与动机**（约500字）
   - 技术演进脉络
   - 核心问题

2. **方案拆解**（约600字）
   - 核心实现原理
   - 技术载体（代码/配置）

3. **性能验证**（约500字）
   - 压测数据
   - 量化收益

4. **Trade-offs**（约500字）← 独立章节
   - 边界条件
   - 实施成本

5. **Pitfalls**（约400字）← 独立章节
   - 实战误区（至少2个）
   - 决策边界

## 三、配图规范

### 腾讯云配图要求

- 背景干净
- 无水印
- 图文强相关
- 建议尺寸：800x450（16:9）
- 格式：PNG/JPG

### 性能图表示例

如需生成性能对比图表，可参考以下Python脚本结构：

```python
import matplotlib.pyplot as plt
import numpy as np

# 包体积对比示例数据
platforms = ['iOS', 'Android', 'HarmonyOS']
before = [18.2, 22.4, 19.1]  # 集成前
after = [20.5, 24.8, 21.4]    # 集成后
```

## 四、SEO关键词融入

### 关键词位置

1. **标题**：必须包含核心关键词
2. **前两段**：自然融入长尾关键词
3. **小标题**：可包含次级关键词
4. **结论**：可重复核心关键词

### 关键词密度

- 核心关键词：出现2-3次
- 长尾关键词：出现1-2次
- 避免关键词堆砌

---

## 五、获客钩子设计

### 常用钩子类型

1. **痛点共鸣**：指出读者面临的共同问题
2. **数据冲击**：用具体数字吸引眼球
3. **对比反差**：Before/After 鲜明对比
4. **技术揭秘**：揭示"不为人知"的细节

### 钩子位置

- 标题
- 引言开头
- 每个章节开头

## 六、知识边界确认

在正式生成前，必须：

1. **溯源分类**：哪些来自用户素材，哪些是AI推演补充
2. **用户确认**：未经确认，AI补充内容不得进入正文

**暂停询问**：`"材料解析完成。请确认架构逻辑和案例数据？确认后启动大纲构建。"`
