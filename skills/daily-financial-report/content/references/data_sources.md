## 时区说明

- A股：北京时间（UTC+8）9:30-15:00
- 港股：北京时间（UTC+8）9:30-16:00
- 日股：东京时间（UTC+9）9:00-15:00
- 美股：美东时间（UTC-5）9:30-16:00，对应北京时间22:30-04:00（冬令时）或21:30-03:00（夏令时）
- 报告中日期使用交易日日期

- 国家统计局发布的煤炭市场价格
