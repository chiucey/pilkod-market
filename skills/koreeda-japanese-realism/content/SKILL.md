# 是枝裕和日系写实风格技能

> **Author**: 起始终下
> **Copyright**: © 2025 起始终下. All Rights Reserved.

---

## 技能定位

本技能将用户的图像需求转化为是枝裕和电影美学风格的Prompt，专门适配千问系列图像生成模型。

**核心价值**：捕捉日常生活中细腻情感，用写实摄影手法呈现家庭与人物的微妙关系。

---

## 适用场景

### 主要适用场景

| 场景类型 | 具体示例 | 输出特点 |
|---------|---------|---------|
| **家庭场景** | 一家人在餐桌吃饭、孩子玩耍、老人独坐 | 温暖自然，生活气息浓厚 |
| **日常瞬间** | 通勤路上、雨天窗边、午后庭院 | 安静内省，氛围感强 |
| **人物肖像** | 老人特写、女性侧脸、儿童表情 | 情感细腻，皱纹/肌肤质感真实 |
| **风景静物** | 日本老宅、海边小镇、季节植物 | 借景抒情，季节感明确 |
| **情感氛围** | 离别、团聚、独处、回忆 | 内敛克制，意在言外 |

### 不适用场景

| 不适用场景 | 原因说明 |
|-----------|---------|
| **激烈动作场面** | 是枝风格强调静态观察，不适合动作大片 |
| **强烈戏剧冲突** | 追求平淡中的深意，避免狗血剧情 |
| **科幻/奇幻元素** | 写实根基，不适合幻想题材 |
| **商业广告感** | 拒绝过度包装，追求真实自然 |
| **极端情绪表达** | 克制内敛，避免过度煽情 |

## 输入要求

### 必填信息

| 信息类型 | 说明 | 示例 |
|---------|------|------|
| **主体** | 主要人物或场景 | "一位老奶奶"、"日式庭院" |
| **情感基调** | 整体情绪氛围 | "安静"、"温暖"、"淡淡的忧伤" |
| **时间/季节** | 增强季节感 | "夏日午后"、"初冬清晨" |

### 选填信息

| 信息类型 | 说明 | 缺失时处理 |
|---------|------|-----------|
| **服饰细节** | 人物穿着描述 | 使用典型日常服饰 |
| **环境细节** | 场景具体描述 | 用通用日式场景 |
| **光线描述** | 特殊光影需求 | 使用标准自然光 |
| **构图偏好** | 景别/角度要求 | 使用中景平视 |

### 模糊需求处理

当用户只说"是枝裕和风格"而无具体描述时，**必须先确认**：

```
了解您需要是枝裕和电影感的图像。为了更精准生成，请告诉我：

1. 【主体】画面主要内容是什么？
   - 人物（老人/女性/儿童/家庭）？
   - 场景（室内/海边/街道/庭院）？

2. 【情感基调】希望传达什么感受？
   - 温暖治愈 / 安静内省 / 淡淡忧伤 / 日常平淡 / 亲人羁绊？

3. 【时间设定】有特定时间/季节吗？
   - 春夏秋冬 / 晨昏 / 无所谓

4. 【重要细节】有什么必须保留的元素？（可选）
   - 特定服饰/道具/环境元素？

如需快速开始，我可以按默认方案生成：
【日本女性、中景、窗边自然光、安静内省、夏日午后】
```

## 处理方法

### 核心美学原则

#### 1. 色调系统

| 季节 | 主色调 | 色彩关键词 |
|------|--------|----------|
| **春** | 柔和粉白 | 樱粉、浅绿、暖白、淡粉 |
| **夏** | 青绿水润 | 翠绿、蔚蓝、海水色、草木绿 |
| **秋** | 暖黄橙红 | 金黄、橙红、枯叶、暖棕 |
| **冬** | 冷灰暖调 | 暖灰、米白、暗蓝、暖橙灯光 |

#### 2. 光线系统

| 光线类型 | 描述 | Prompt关键词 |
|---------|------|-------------|
| **窗边光** | 柔和侧光，温暖穿透 | 自然窗光, 斜射入室, 温暖光斑 |
| **阴天柔光** | 散射均匀，无强烈阴影 | 阴天, 柔和散射, 低对比 |
| **黄金时刻** | 傍晚暖光，斜长影子 | 夕阳余晖, 金色时刻, 长影 |
| **室内暖灯** | 灯笼/台灯光晕 | 暖黄灯光, 光晕, 温馨 |

#### 3. 质感系统

| 质感类型 | 描述 | Prompt关键词 |
|---------|------|-------------|
| **胶片颗粒** | 模拟电影胶片 | 胶片颗粒, Kodak Portra, 细腻颗粒 |
| **自然纹理** | 木材/布料/肌肤 | 自然纹理, 真实肌肤, 木纹质感 |
| **生活痕迹** | 岁月使用感 | 旧物感, 日常痕迹, 生活气息 |

#### 4. 构图系统

| 构图类型 | 描述 | Prompt关键词 |
|---------|------|-------------|
| **深焦环境** | 前后景都清晰 | 深焦, 环境入镜, 空间感 |
| **2/3构图** | 人物偏离中心 | 三分构图, 侧身, 留白 |
| **窗框切割** | 门窗框住主体 | 窗框构图, 框架构图 |
| **平行视线** | 平视自然视角 | 平视角度, 观察视角 |

- 风格：是枝裕和日系电影美学，写实摄影风格
- 色调：[季节色调，如"春夏青绿"或"秋冬暖黄"]

【主体描述】
- 人物：[性别、年龄、服饰、姿态、表情描述]
- 视线：[目光方向，如"望向窗外"或"低头沉思"]

【场景设定】

- 时间：[季节+时段，如"夏日午后"或"初冬黄昏"]
- 环境细节：[生活气息的细节描写]

【光影氛围】
- 光源：[具体光线描述，如"窗口斜射的自然光"]
- 氛围：[情感基调，如"安静内省"或"温暖治愈"]
- 质感：[胶片颗粒/自然纹理描述]

【构图规则】
- 景别：[全景/中景/近景/特写]
- 视角：[平视/俯视/仰视]
- 构图：[深焦/留白/框架]

- 包含：[必须出现的元素]

## 应用示例

### 示例1：窗边女性

**用户需求**："一位日本女性在窗边望向外面，夏日午后"

**生成Prompt（框架A）**：

```
【整体定调】
- 画幅：竖幅，3:4比例
- 风格：是枝裕和日系电影美学，写实摄影风格
- 色调：夏日青绿与白色为主

【主体描述】
- 人物：一位30岁左右的日本女性，穿着白色棉麻衬衫，
  长发自然垂落，侧身站在窗边，目光望向窗外
- 表情：平静、若有所思，唇角微微放松

【场景设定】
- 地点：日式现代公寓，简洁木质窗框
- 时间：夏日午后3点左右，阳光斜射
- 细节：窗外可见绿树，光线在地板投下影子

【光影氛围】
- 光源：窗口斜射的自然光，温暖但柔和
- 氛围：安静内省，夏日的慵懒与期待
- 质感：胶片颗粒，细腻肌肤纹理

【构图规则】
- 景别：中景，膝盖以上
- 视角：平视，窗框作为框架
- 构图：2/3构图，女性位于画面右侧

【约束条件】
- 包含：窗边光影、夏日氛围、自然姿态
- 禁止：浓烈色彩、夸张表情、戏剧性打光
```

运动/状态：静态画面，捕捉用餐的日常温馨，
　　　　　　碗筷轻触声仿佛可闻
美学控制：侧逆光勾勒人物轮廓，深焦背景，

风格化：是枝裕和电影感，胶片颗粒质感，

　　　家庭温情，克制内敛的情感表达
