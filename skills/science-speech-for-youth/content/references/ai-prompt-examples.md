# AI辅助科普演讲稿创作提示词示例

## 提示词编写原则

1. **明确角色**：设定AI为"科普演讲稿写作专家"或"青少年科技教育专家"
2. **说明背景**：提供演讲的目的、场景、受众等基本信息
3. **指定风格**：明确语言风格、互动方式、篇幅要求
4. **提供素材**：给出核心知识点、案例偏好、参考案例

---

## 阶段一：选题与策划

### 提示词模板：选题生成

```markdown
# 角色设定
你是一位专业的科普演讲稿写作专家，擅长为青少年创作引人入胜的科普演讲稿。

# 任务说明
我需要为一个[年龄段]的科普演讲活动征集选题。请根据以下信息，推荐5个有吸引力的演讲选题。

# 基本信息
- 主题领域：[如：人工智能、生物技术、新能源等]
- 演讲时长：[X]分钟
- 活动类型：[如：科技节、科普讲座、课堂延伸等]
- 特别要求：[如有]

# 输出要求
请为每个选题提供：
1. 标题（吸引眼球，能激发好奇心）
2. 核心角度（从什么切入主题）
3. 目标受众可能感兴趣的点
4. 简要大纲（3-5个要点）

# 语言风格
输出使用中文，语言生动有趣，适合科技教育专家参考。
```

### 提示词模板：标题优化

```markdown
# 角色设定
你是一位擅长为科普内容起标题的创意专家。

# 任务说明
请为以下演讲主题提供10个有吸引力的标题选项。

# 主题信息
- 核心主题：[具体主题]
- 目标受众：[年龄段]
- 演讲风格：[严谨有趣/轻松活泼/探索冒险等]

# 输出要求
- 标题要能激发好奇心
- 避免过于学术化
- 可以使用问句、比喻、数字等技巧
- 简短有力，建议8-15个字

# 输出格式
请按创意程度排序，标注每个标题的创意亮点。
```

## 阶段二：框架搭建

### 提示词模板：结构设计

```markdown
# 角色设定
你是一位专业的科普演讲结构设计师。

# 任务说明
请为以下演讲内容设计详细的结构框架。

# 基本信息
- 演讲主题：[主题名称]
- 目标受众：[年龄段+认知特点简述]
- 演讲时长：[X]分钟（约[Y]字）
- 核心知识点：[列出3-5个核心知识点]

# 设计要求
1. 设计开篇引入方式（要求：能激发好奇心，吸引注意力）
2. 规划主体内容的逻辑线索（要求：符合青少年认知规律）
3. 设计互动环节（要求：至少2处，能巩固学习、激发思考）
4. 设计结尾升华（要求：有情感共鸣，传递科学精神）

# 输出格式
请提供：
1. 整体结构图（文字版）
2. 各部分字数分配
3. 各部分核心内容要点
4. 段落之间的过渡语建议
```

### 提示词模板：知识点分解

```markdown
# 角色设定
你是一位擅长将复杂科学知识分解为易于理解内容的教育专家。

# 任务说明
请将以下科学主题分解为适合[年龄段]青少年理解的内容模块。

# 主题信息
- 主题：[具体主题]
- 核心原理：[简要说明]
- 受众基础：[受众可能已知的相关知识]

# 分解要求
1. 将核心内容分解为3-4个模块
2. 每个模块用"比喻"或"生活案例"来解释
3. 说明各模块之间的逻辑关系
4. 标注每个模块适合的呈现方式（如：讲故事、做实验、展示图片等）

# 输出格式
请用表格形式呈现每个模块，包含：模块名称、核心内容、比喻/案例、呈现方式
```

## 阶段三：初稿生成

### 提示词模板：完整初稿

```markdown
# 角色设定
你是一位经验丰富的科普演讲稿撰写专家，擅长为青少年创作生动有趣的演讲稿。

# 任务说明
请根据以下信息撰写一篇完整的科普演讲稿。

# 基本信息
- 标题：[演讲标题]
- 目标受众：[具体年龄段]，约[Y]人
- 演讲时长：[X]分钟（约[Z]字）
- 场景：[如：学校礼堂、教室、科技馆等]
- 目的：[科普知识/激发兴趣/传递科学精神等]

# 内容要求
核心知识点：
1. [知识点1]
2. [知识点2]
3. [知识点3]

请在演讲稿中：
- 自然融入以上知识点
- 使用至少3个生动的比喻
- 包含1-2个真实案例或故事
- 设计2处互动环节

# 语言风格要求
- 亲切自然，像和朋友聊天
- 避免说教口吻
- 使用短句，节奏明快
- 适当使用感叹句增强感染力
- 可适当使用网络流行语，但要适度

# 输出格式
请按以下结构输出：
1. 演讲稿正文（完整段落）
2. 标注每段适合的语速和停顿
3. 标注适合配合手势或表情的地方
```

### 提示词模板：分段落生成

```markdown
# 角色设定
你是一位专业的科普演讲稿撰写专家。

# 任务说明
请撰写以下演讲稿的开篇部分。

# 演讲信息
- 标题：[标题]
- 受众：[年龄段]
- 字数要求：约[200]字

# 开篇要求
设计一个引人入胜的开篇，要求：
1. 用一个惊人的事实、一张图片描述、或一个有趣的问题开场
2. 能立即抓住听众注意力
3. 与演讲主题直接相关
4. 引发听众好奇心，让他们想继续听下去

# 输出格式
请直接输出开篇文本，并在结尾标注[此处可停顿X秒]
```

请重点优化以下方面：
- [ ] 语言更加生动有趣
- [ ] 比喻更加贴近青少年生活
- [ ] 节奏更加明快

## 阶段五：审核检查

### 提示词模板：全面审核

```markdown
# 角色设定
你是一位专业的科普演讲稿审核专家。

# 任务说明
请对以下演讲稿进行全面审核并提出修改建议。

# 演讲稿全文
[粘贴全文]

# 审核维度

请从以下维度进行审核：

1. **科学性审核**
   - 核心概念是否准确
   - 数据引用是否可靠
   - 逻辑推理是否严密
   - 是否存在科学性错误

2. **可读性审核**
   - 语言是否流畅易懂
   - 比喻是否恰当准确
   - 节奏是否合适
   - 是否存在冗余内容

3. **适龄性审核**
   - 是否符合[年龄段]的认知水平
   - 语言风格是否适当
   - 内容是否有吸引力
   - 知识点密度是否合适

4. **互动性审核**
   - 开篇是否吸引人
   - 是否有互动设计
   - 互动是否自然有效
   - 结尾是否有升华

5. **完整性审核**
   - 结构是否完整
   - 各部分衔接是否自然
   - 时间安排是否合理

# 输出格式
请提供：
1. 总体评分（1-10分）及简要评价
2. 各维度具体评价
3. 需要修改的具体位置和建议
4. 修改优先级排序
```

## 高级技巧

### 技巧一：角色扮演法

在提示词中加入角色扮演元素：

```markdown
# 角色扮演设定
请扮演一位充满激情的青年科学家，刚刚完成了某项研究，你要用5分钟向一群好奇的中学生介绍你的发现。
语气要充满热情，像是在分享一个激动人心的故事，而不是在上课。
```

### 技巧二：案例参考法

提供优秀案例让AI学习风格：

```markdown
# 参考案例
以下是一篇优秀的小学高年级科普演讲稿开篇，请学习这种风格：
[粘贴案例]

请用这种风格撰写[你的主题]的开篇。
```

### 技巧三：迭代优化法

分步骤迭代优化：

1. 第一轮：生成初稿
2. 第二轮：针对薄弱环节单独优化
3. 第三轮：整体润色
4. 第四轮：最终审核

### 技巧四：人机协同法

AI生成后，人类专家重点关注：

1. **必须人工审核**：科学准确性
2. **AI+人工调整**：比喻和案例
3. **AI为主**：结构和语言
4. **人工把控**：整体风格和情感
