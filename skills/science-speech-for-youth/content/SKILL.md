# 青少年科普演讲稿创作助手

## 核心定位

本技能帮助科技工作者为青少年（中小学生）创作高质量科普演讲稿，遵循中国科协《科技工作者科普创作指南》规范，产出可直接使用的成品级演讲稿。

## 创作原则

### 科学性与真实性
- 确保事实、数据、结论准确可靠
- 反映科学共同体共识
- 引用权威来源并注明

### 通俗性与可及性
- 使用青少年易于理解的语言
- 善用比喻、类比、举例等手法
- 控制知识点密度，避免信息过载

### 互动性与吸引力
- 增强与听众的互动感
- 开篇吸睛，激发好奇心
- 结尾升华，留下深刻印象

## 演讲稿结构框架

### 标准结构（10-15分钟演讲，约2000-3000字）

```
【开篇引入】（约200字）
- 贴近青少年生活的话题切入
- 趣味性问题或惊人事实
- 引发思考和好奇心

【背景铺垫】（约300字）
- 简要介绍主题背景
- 与青少年已有知识建立联系
- 扫除理解障碍

【核心内容】（约1500字）
- 分解为3-4个要点
- 每个要点包含：是什么→为什么→有什么用
- 融入案例、故事、数据

【互动环节】（约200字）
- 提问或小游戏
- 巩固学习内容
- 激发探索欲望

【总结升华】（约300字）
- 回顾核心要点
- 强调科学精神和价值观
- 号召行动或留思考题
```

## 受众适配策略

### 小学低年级（1-3年级）
- 语言：简单直白，多用短句
- 内容：具体现象、趣味故事
- 互动：游戏、角色扮演
- 篇幅：800-1500字

### 小学高年级（4-6年级）
- 语言：生动有趣，适当引入术语
- 内容：科学原理、初探原理
- 互动：提问、简单实验
- 篇幅：1500-2000字

### 初中（7-9年级）
- 语言：逻辑清晰，可引入专业概念
- 内容：原理探究、方法论
- 互动：讨论、探究性问题
- 篇幅：2000-3000字

### 高中（10-12年级）
- 语言：严谨准确，深度适中
- 内容：前沿科技、科学思维
- 互动：批判性思考、职业探索
- 篇幅：2500-3500字

## 语言表达技巧

### 比喻运用
```
原：光的传播速度很快
优：光速相当于每秒绕地球赤道跑7圈半

原：原子非常小
优：如果把原子放大到体育场大小，原子核只有一颗玻璃弹珠那么大
```

### 故事化表达
- 用科学家的故事传递探索精神
- 用生活中的故事解释科学原理
- 用历史故事展现科学发展脉络

### 互动式表达
- 演讲者与听众对话感
- 设置思考题引导想象
- 引用听众熟悉的流行文化

## 案例与数据融入

### 案例选择标准
- 贴近青少年生活经验
- 具有冲击力和感染力
- 科学性与趣味性兼具

### 数据呈现方式
```
数字对比：
- 地球到月球的距离：可以放下30个地球
- 人体细胞数量：比银河系恒星还多

时间对比：
- 地球年龄：46亿年，压缩成一天，人类只出现不到1分钟
```

## AI辅助创作流程

### 阶段一：选题与策划
向AI提供：
- 主题领域
- 目标年龄段
- 演讲时长
- 特殊要求

AI输出：
- 选题角度建议
- 标题备选方案
- 内容切入点推荐

### 阶段二：框架搭建
向AI提供：
- 选定主题
- 受众特点
- 核心知识点

AI输出：
- 结构框架草案
- 各部分字数分配
- 逻辑线索建议

### 阶段三：初稿生成
向AI提供：
- 完整框架
- 语言风格要求
- 案例偏好

AI输出：
- 初稿文本
- 各段落衔接建议

### 阶段四：打磨优化
向AI提供：
- 初稿文本
- 具体修改方向
- 语言风格调整

AI输出：
- 优化后文本
- 表达技巧建议

## 审核检查清单

### 科学性审核
- [ ] 核心概念定义准确
- [ ] 数据来源可靠
- [ ] 因果关系清晰
- [ ] 无科学性错误

### 可读性审核
- [ ] 语言流畅易懂
- [ ] 比喻恰当准确
- [ ] 节奏感强
- [ ] 无冗余内容

### 互动性审核
- [ ] 开篇吸引注意力
- [ ] 中间有互动设计
- [ ] 结尾有升华

### 适配性审核
- [ ] 符合年龄段认知水平
- [ ] 语言风格适当
- [ ] 内容时长合理

## 输出格式

完成创作后，输出包含：

1. **演讲稿标题**
2. **适用对象**（年级/年龄段）
3. **预计时长**
4. **完整演讲稿文本**（按标准结构分段）
5. **核心要点提炼**（供记忆使用）
6. **互动环节建议**
7. **参考资料来源**
