# 分析框架详细说明

**作者：BlueJudy**

## 1. PESTEL分析框架

### 定义
PESTEL分析是一种宏观环境分析工具，用于评估影响行业的六大外部因素。

### 六要素详解

| 要素 | 分析内容 | 示例问题 |
|------|----------|----------|
| **政治(Political)** | 政府政策、稳定性、贸易法规 | 行业政策是否支持？监管趋势如何？ |
| **经济(Economic)** | 经济增长、利率、汇率、通胀 | 经济周期位置？消费能力变化？ |
| **社会(Social)** | 人口统计、文化、生活方式 | 人口老龄化？消费习惯变化？ |
| **技术(Technological)** | 创新、研发、自动化 | 技术颠覆风险？研发投入趋势？ |
| **环境(Environmental)** | 气候、可持续性、ESG | 碳中和要求？环保法规趋严？ |
| **法律(Legal)** | 劳动法、竞争法、消费者保护 | 合规成本？法律变化风险？ |

### 应用场景
- 识别外部机会与威胁
- 评估行业整体吸引力
- 预测政策变化影响

## 2. SWOT分析框架

### 定义
SWOT分析是一种战略规划工具，用于评估组织的内外部环境。

### 四要素矩阵

| | **积极** | **消极** |
|---|---|---|
| **内部** | 优势(Strengths) | 劣势(Weaknesses) |
| **外部** | 机会(Opportunities) | 威胁(Threats) |

### 分析要点

**优势（Strengths）**
- 核心竞争力是什么？
- 资源禀赋有哪些？
- 市场地位如何？

**劣势（Weaknesses）**
- 短板在哪里？
- 资源缺口是什么？
- 运营效率问题？

**机会（Opportunities）**
- 市场增长点？
- 技术突破带来的机会？
- 政策红利？

**威胁（Threats）**
- 竞争对手动向？
- 替代品威胁？
- 宏观风险因素？

### 战略匹配
- **SO策略**：利用优势抓住机会
- **WO策略**：克服劣势抓住机会
- **ST策略**：利用优势规避威胁
- **WT策略**：减少劣势规避威胁

## 3. 波特五力模型

### 定义
迈克尔·波特提出的行业竞争结构分析框架。

### 五力详解

#### 3.1 供应商议价能力
**影响因素：**
- 供应商集中度
- 替代供应商可得性
- 供应商产品差异化程度
- 转换成本
- 纵向一体化程度

**评估问题：**
- 核心供应商是否集中？
- 是否存在卡脖子环节？
- 国产替代可行性？

#### 3.2 买方议价能力
**影响因素：**
- 买方集中度
- 产品标准化程度
- 买方转换成本
- 买方盈利能力
- 信息透明度

**评估问题：**
- 大客户占比？
- 客户议价能力？
- 产品差异化程度？

#### 3.3 潜在进入者威胁
**进入壁垒：**
- 规模经济
- 网络效应
- 品牌忠诚度
- 资本需求
- 渠道控制
- 政府政策

**进入者类型：**
- 产业新进入者
- 横向扩张者
- 纵向一体化者

#### 3.4 替代品威胁
**评估维度：**
- 替代品性价比
- 用户转换成本
- 替代品盈利能力
- 技术演进趋势

#### 3.5 行业内竞争程度
**竞争驱动因素：**
- 竞争对手数量
- 行业集中度
- 产品差异化
- 行业增长阶段
- 退出壁垒

## 4. 市场规模测算框架

### TAM-SAM-SOM三层模型

```
┌─────────────────────────────────────────┐
│            TAM (总潜在市场)              │
│  ┌───────────────────────────────────┐  │
│  │         SAM (可服务市场)          │  │
│  │  ┌─────────────────────────────┐  │  │
│  │  │      SOM (可获得市场)       │  │  │
│  │  └─────────────────────────────┘  │  │
│  └───────────────────────────────────┘  │
└─────────────────────────────────────────┘
```

### 定义

| 层级 | 定义 | 测算方法 |
|------|------|----------|
| **TAM** | 全球/全市场总需求 | 顶层宏观经济法/需求加总法 |
| **SAM** | 目标细分市场总需求 | 基于TAM乘以目标市场占比 |
| **SOM** | 可实际获得的市场份额 | 基于SAM乘以渗透率假设 |

### 测算方法

#### 1. 自上而下法（Top-Down）
```
TAM = 目标用户群体 × 单用户年均消费
SAM = TAM × 目标市场占比
SOM = SAM × 预期市场份额
```

#### 2. 自下而上法（Bottom-Up）
```
市场规模 = 用户数量 × 客单价 × 购买频次
```

#### 3. 需求端测算
```
市场规模 = 潜在用户 × 渗透率 × ARPU
```

### 增速预测方法

| 方法 | 适用场景 | 注意事项 |
|------|----------|----------|
| 历史增速外推 | 成熟行业 | 注意基数效应 |
| 渗透率提升逻辑 | 新兴行业 | 需验证渗透率假设 |
| 复合增长率(CAGR) | 长周期预测 | 需说明预测期 |
| 情景分析 | 高不确定性 | 设置乐观/基准/保守情景 |

## 5. 财务分析框架

### 5.1 盈利能力分析

**核心指标：**
| 指标 | 计算公式 | 参考标准 |
|------|----------|----------|
| 毛利率 | (收入-成本)/收入 | >30%为优质 |
| 净利率 | 净利润/收入 | >15%为优质 |
| ROE | 净利润/股东权益 | >15%为优质 |
| ROA | 净利润/总资产 | >5%为优质 |

### 5.2 成长性分析

**核心指标：**
| 指标 | 说明 | 关注点 |
|------|------|--------|
| 营收增速 | 收入同比增长 | 是否可持续 |
| 净利润增速 | 利润同比增长 | 是否与营收匹配 |
| 复合增长率 | CAGR 3-5年 | 长期成长性 |

### 5.3 偿债能力分析

**核心指标：**
| 指标 | 计算公式 | 参考标准 |
|------|----------|----------|
| 资产负债率 | 总负债/总资产 | <60%为稳健 |
| 流动比率 | 流动资产/流动负债 | >1.5为稳健 |
| 速动比率 | (流动资产-存货)/流动负债 | >1.0为稳健 |

### 5.4 运营效率分析

**核心指标：**
| 指标 | 计算公式 | 关注点 |
|------|----------|--------|
| 存货周转天数 | 365/存货周转率 | 趋势变化 |
| 应收账款周转天数 | 365/应收账款周转率 | 回款能力 |
| 总资产周转率 | 收入/总资产 | 利用效率 |

### 5.5 估值方法

| 方法 | 适用场景 | 核心参数 |
|------|----------|----------|
| PE估值 | 成熟稳定盈利企业 | 行业平均PE |
| PB估值 | 重资产企业 | 净资产质量 |
| PS估值 | 高增长未盈利企业 | 营收质量 |
| DCF估值 | 所有企业（核心方法） | 现金流预测、折现率 |

### 5.6 风险信号识别

**红旗警示清单：**
- [ ] 应收账款增速远高于营收增速
- [ ] 存货积压严重，周转天数持续上升
- [ ] 经营现金流长期为负
- [ ] 商誉占净资产比重过高（>50%）
- [ ] 关联交易频繁且金额较大
- [ ] 毛利率异常高于行业平均
- [ ] 应收账款/存货/商誉突然大幅增加
- [ ] 审计意见非标准无保留

## 6. 投资回报测算框架

### 情景分析

| 情景 | 假设条件 | 概率 | 预期收益率 |
|------|----------|------|------------|
| 乐观 | 核心假设全部兑现 | 25% | +50%以上 |
| 基准 | 中性假设条件 | 50% | +20%~30% |
| 保守 | 部分假设不兑现 | 20% | 0%~10% |
| 悲观 | 核心假设落空 | 5% | -20%以上 |

### 风险收益评估

```
风险收益比 = 预期收益 / 潜在损失

- 风险收益比 > 2:1：值得投资
- 风险收益比 1:1 ~ 2:1：谨慎考虑
- 风险收益比 < 1:1：不建议投资
```
