# 质量标准规范

**作者：BlueJudy**

## 一、质量审核清单

### 1.1 事实核查清单

在报告最终输出前，必须逐一核实以下要素：

#### 公司信息核查

- [ ] **公司名称**：确认全称和简称正确
- [ ] **股票代码**：A股（XXXXXX.SZ/XXXXXX.SH）、港股（XXXX.HK）、美股（XXXX.NASDAQ）
- [ ] **市值数据**：核实最新市值和日期
- [ ] **财务数据**：交叉验证不同来源的数据一致性

#### 行业数据核查

- [ ] **市场规模**：核实数据来源和时间节点
- [ ] **增速数据**：确认同比/环比计算正确
- [ ] **市场份额**：核实数据口径（收入/销量/产能）
- [ ] **排名数据**：确认排名依据和时间

#### 政策文件核查

- [ ] **文件名称**：核实官方全称
- [ ] **发布部门**：确认发文机构
- [ ] **发布时间**：核实发布日期
- [ ] **核心内容**：摘要准确反映文件精神

### 1.2 数据准确性核查

#### 数值类数据

| 检查项 | 核查方法 | 容错标准 |
|--------|----------|----------|
| 百分比 | 反推验证 | ±0.1pp |
| 金额 | 单位换算验证 | ±1% |
| 增长率 | 原始数据验证 | ±0.5pp |
| 市场份额 | 多源交叉验证 | ±1% |

#### 趋势类判断

| 检查项 | 核查方法 | 标准 |
|--------|----------|------|
| "快速增长" | 增速>20% | 需数据支撑 |
| "稳步增长" | 增速10-20% | 需数据支撑 |
| "基本持平" | 增速±5% | 需数据支撑 |
| "小幅下降" | 增速-5%~-15% | 需数据支撑 |
| "大幅下降" | 增速<-15% | 需数据支撑 |

### 1.3 逻辑一致性核查

#### 内部一致性

- [ ] 目录结构与正文内容一致
- [ ] 各章节引用数据相互印证
- [ ] 核心观点与支撑数据匹配
- [ ] 结论与前文分析逻辑连贯

#### 数据一致性

- [ ] 图表数据与正文数据一致
- [ ] 表格数据横向纵向加总正确
- [ ] 不同章节引用同一数据一致

### 1.4 格式规范性核查

#### 数值格式

| 要素 | 规范 | 示例 |
|------|------|------|
| 金额 | 亿元为单位 | 100亿元 |
| 百分比 | 保留1位小数 | 12.5% |
| 增长倍数 | 保留1位小数 | 2.3倍 |
| 人数 | 万为单位 | 100万人 |

#### 时间格式

| 场景 | 规范 | 示例 |
|------|------|------|
| 年度数据 | YYYY年 | 2024年 |
| 季度数据 | YYYY年QN | 2024年Q3 |
| 月度数据 | YYYY年MM月 | 2024年3月 |
| 截止时间 | YYYY年末/中 | 2024年末 |

#### 股票代码格式

| 市场 | 格式 | 示例 |
|------|------|------|
| A股深交所 | XXXXXX.SZ | 300750.SZ |
| A股上交所 | XXXXXX.SH | 600519.SH |
| 港股 | XXXX.HK | 0700.HK |
| 美股 | XXXX.NASDAQ | AAPL.NASDAQ |

## 二、信息来源可靠性评估

### 2.1 来源分级标准

| 等级 | 来源类型 | 可信度 | 适用场景 |
|------|----------|--------|----------|
| **A级** | 官方统计数据、监管文件、公司公告 | 极高 | 核心论点支撑 |
| **B级** | 权威机构报告、专业媒体 | 高 | 重要论点支撑 |
| **C级** | 行业专家观点、企业宣传 | 中 | 补充参考 |
| **D级** | 网络信息、匿名来源 | 低 | 仅作提示 |

### 2.2 优先引用来源

**中国市场数据优先来源：**

| 数据类型 | 优先来源 |
|----------|----------|
| 宏观数据 | 国家统计局、海关总署 |
| 行业数据 | 行业协会、主管部门 |
| 上市公司数据 | 公司公告、交易所公开信息 |
| 政策法规 | 国务院、发改委、工信部等官方网站 |
| 市场数据 | Wind、Bloomberg、FactSet |

### 2.3 来源标注规范

#### 新闻报道

```
格式：「[媒体名称] [报道标题] [发布日期]」
示例：「新华社《新能源汽车产销两旺》 2024年12月15日」
```

#### 研究报告

```
格式：「[研究机构] [报告标题] [发布日期]」
示例：「中金公司《中国新能源汽车行业展望》 2024年11月」
```

#### 财务数据

```
格式：「[公司名称] [股票代码] [报告类型]（如2024年年报）」
示例：「宁德时代 300750.SZ 2024年半年报」
```

#### 政策文件

```
格式：「[发布部门] [文件名称] [文号] [发布日期]」
示例：「国务院《新能源汽车产业发展规划（2021-2035年）》 国办发〔2020〕39号 2020年11月」
```

## 三、风险评估规范

### 3.1 风险识别标准

#### 技术风险

| 风险等级 | 判断标准 | 标注方式 |
|----------|----------|----------|
| 低 | 技术成熟，替代风险小 | ○ |
| 中 | 存在技术迭代可能 | ● |
| 高 | 技术路线存在不确定性 | ◎ |
| 极高 | 面临颠覆性技术威胁 | ★ |

#### 市场风险

| 风险等级 | 判断标准 | 标注方式 |
|----------|----------|----------|
| 低 | 市场需求稳定增长 | ○ |
| 中 | 需求增速存在波动 | ● |
| 高 | 面临需求萎缩风险 | ◎ |
| 极高 | 核心市场面临萎缩 | ★ |

#### 政策风险

| 风险等级 | 判断标准 | 标注方式 |
|----------|----------|----------|
| 低 | 政策持续支持 | ○ |
| 中 | 政策存在调整可能 | ● |
| 高 | 面临政策收紧风险 | ◎ |
| 极高 | 政策转向负面 | ★ |

### 3.2 风险综合评级

| 评级 | 定义 | 投资建议 |
|------|------|----------|
| **R1** | 风险低，可积极关注 | 可作为核心配置 |
| **R2** | 风险中低，需关注 | 可作为卫星配置 |
| **R3** | 风险中高，需谨慎 | 控制仓位 |
| **R4** | 风险高，建议回避 | 不建议投资 |

## 四、报告质量评分标准

### 4.1 评分维度

| 维度 | 权重 | 评分标准 |
|------|------|----------|
| **数据准确性** | 30% | 数据核实完整、计算正确 |
| **逻辑严密性** | 25% | 分析逻辑清晰、结论有据 |
| **信息来源可靠性** | 20% | 引用权威来源、标注规范 |
| **实用价值** | 15% | 投资建议具体可操作 |
| **可读性** | 10% | 结构清晰、表达专业 |

### 4.2 质量等级

| 等级 | 分数 | 标准 |
|------|------|------|
| **优秀** | 90-100分 | 全面达到各项标准 |
| **良好** | 75-89分 | 大部分达标，少量改进空间 |
| **合格** | 60-74分 | 达到基本标准，需优化 |
| **不合格** | <60分 | 存在重大问题，需返工 |

## 五、常见错误清单

### 5.1 数据类错误

| 错误类型 | 示例 | 正确做法 |
|----------|------|----------|
| 数值错位 | "1000亿元"写成"100亿元" | 核对数量级 |
| 单位混淆 | 亿元/万美元混用 | 统一换算 |
| 时间错误 | 引用过期数据未标注 | 注明数据时效 |
| 数据矛盾 | 正文与图表数据不一致 | 交叉核对 |

### 5.2 表述类错误

| 错误类型 | 示例 | 正确做法 |
|----------|------|----------|
| 绝对化表述 | "一定会增长" | 使用概率表述 |
| 模糊表述 | "业绩大幅增长" | 给出具体数字 |
| 逻辑跳跃 | 无数据支撑的结论 | 补充论证 |
| 过度推论 | 基于单一因素预测 | 多因素综合 |

### 5.3 格式类错误

| 错误类型 | 示例 | 正确做法 |
|----------|------|----------|
| 引用缺失 | 关键数据无来源 | 补充引用 |
| 格式不一 | 数字格式混用 | 统一格式 |
| 图表无标注 | 图表无标题说明 | 完善图表信息 |

## 六、质量保障流程

### 6.1 自查流程

1. **初步检查**：撰写完成后通读全文
2. **数据核实**：逐一核实关键数据
3. **逻辑检查**：验证分析逻辑连贯性
4. **格式检查**：统一全文格式
5. **引用检查**：补充完整引用标注

### 6.2 审核流程

1. **内容审核**：由质量审核师进行
2. **数据核实**：交叉验证关键数据
3. **逻辑审核**：评估分析严谨性
4. **格式审核**：检查规范性
5. **反馈修正**：根据审核意见修改

### 6.3 发布前检查

- [ ] 所有数据已核实
- [ ] 所有引用已标注
- [ ] 图表完整清晰
- [ ] 格式统一规范
- [ ] 结论有数据支撑
- [ ] 风险提示完整
