# 电影级表演动作与微表情参考指南

## 一、眼部微表情系统

### 眼神变化
| 类型 | 描述关键词 | 适用场景 |
|------|----------|---------|
| 凝视 | 目光如炬、定睛凝视、眼眶微湿 | 深情、悲痛、决心 |
| 闪烁 | 眼眶微红、泪光闪烁、睫毛轻颤 | 隐忍、感动、委屈 |
| 闪躲 | 目光游移、不敢对视、眼神飘忽 | 心虚、紧张、羞涩 |
| 空洞 | 双目失神、眼眸空洞、目光涣散 | 震惊、绝望、麻木 |
| 锐利 | 目光如刀、眼神凌厉、杀气外露 | 愤怒、威胁、决绝 |

### 视线方向
- **上挑**：若有所思、回忆、不屑
- **下垂**：愧疚、沉思、疲惫
- **平视**：坦诚、坚定、从容
- **斜瞥**：轻蔑、怀疑、警觉

## 十、综合情绪表演模板

### 悲伤/哀痛
```
眼眶泛红 → 泪光闪烁 → 双眉微蹙 → 嘴角下垂 → 唇瓣轻颤
→ 肩膀微微耸动 → 双臂无力垂落 → 步伐沉重 → 身体微微颤抖
```

### 愤怒/暴怒
```
眉头紧锁 → 眼神凌厉 → 目光如刀 → 咬紧牙关 → 下颌紧绷
→ 拳头紧握 → 指节泛白 → 双臂颤抖 → 胸膛剧烈起伏 → 呼吸急促
```

### 惊喜/震惊
```
瞳孔微缩 → 眼眸睁大 → 双眉上扬 → 嘴唇微张 → 倒吸一口凉气
→ 身体僵住 → 双手微张 → 不自觉后退一步
```

### 恐惧/惊吓
```
脸色骤变 → 面如土色 → 瞳孔放大 → 眼神惊惧 → 身体僵直
→ 双腿发软 → 双手颤抖 → 不自觉后退 → 呼吸急促
```

### 喜悦/开心
```
眉眼弯弯 → 眼含笑意 → 嘴角上扬 → 梨涡浅现 → 面若桃花
→ 步伐轻快 → 衣袂翩翩 → 喜上眉梢 → 神采飞扬
```

### 紧张/不安
```
坐立不安 → 搓手顿足 → 眼神游移 → 吞咽口水 → 喉头滚动
→ 呼吸急促 → 双手攥紧 → 双肩紧绷 → 目光闪烁
```

### 沉思/回忆
```
目光凝滞 → 眼神空洞 → 眉心微蹙 → 手指轻叩 → 下意识摩挲
→ 身体微微后仰 → 呼吸放缓 → 渐入沉思
```

### 冷漠/疏离
```
面色平静 → 眼神淡漠 → 目光冰冷 → 嘴角平直 → 纹丝不动
→ 呼吸平稳 → 气场冷淡 → 置身事外
```
