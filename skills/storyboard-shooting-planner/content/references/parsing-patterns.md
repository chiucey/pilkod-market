# 分镜脚本解析参考模式

本文档提供分镜脚本的解析模式和标准参考。

## 支持的输入格式

### 1. 简单文本格式

```
场景1：[描述]
场景2：[描述]
场景3：[描述]
```

### 2. 编号场景格式

```
Scene 01: [场景描述]
Scene 02: [场景描述]
```

### 3. 详细场景格式

```
场景编号: SC01
场景类型: 内景/外景
时间: 日景/夜景/黄昏/清晨
地点: [具体地点]
内容: [场景内容描述]
镜头: [镜头类型]
角色: [出现角色]
道具: [关键道具]
备注: [其他说明]
```

### 4. 表格格式

| 场景 | 类型 | 时间 | 描述 |
|-----|-----|-----|-----|
| 01 | 内景 | 日景 | ... |

## 关键词识别

### 场景类型识别

| 关键词 | 判定 |
|-------|-----|
| 内景、室内 | 内景 |
| 外景、户外、室外 | 外景 |

### 时间识别

| 关键词 | 判定 |
|-------|-----|
| 日景、日间、白天 | 日景 |
| 夜景、夜间、晚上 | 夜景 |
| 黄昏、傍晚 | 黄昏 |
| 清晨、早晨 | 清晨 |

### 难度等级评估

| 判定条件 | 难度 |
|---------|-----|
| 静态对话场景 | 低 |
| 含一般特效 | 中 |
| 复杂动作、大规模特效、夜景复杂布光 | 高 |

## 设备配置标准

### 基本配置（单机组）

- 主机 1 台
- 脚架 1 套
- 基础灯光套装 1 套
- 枪式麦克风 1 套

### 中等配置（双机组）

- 主机 2 台
- 脚架 2 套
- 滑轨或稳定器 1 套
- 灯光套装 2 套
- 无线麦克风 2 套

### 高级配置（三机组+）

- 主机 3 台以上
- 完整灯光配置
- 专业音频套装
- 航拍设备（如需要）

## 人员配置参考

### 基础剧组（低成本制作）

| 岗位 | 人数 |
|-----|-----|
| 导演 | 1 |
| 摄影师 | 1 |
| 灯光/场务 | 1-2 |
| 录音 | 1 |

### 标准剧组（中等制作）

| 岗位 | 人数 |
|-----|-----|
| 导演 | 1 |
| 副导演 | 1 |
| 摄影师 | 2 |
| 摄影助理 | 1-2 |
| 灯光师 | 2 |
| 灯光助理 | 1-2 |
| 录音师 | 1 |
| 场务 | 2-3 |

### 专业剧组（高成本制作）

按标准剧组配置加倍，并根据需要添加：
- 特效师
- 美术指导
- 化妆师
- 服装师
- 制片主任

## 时间估算标准

### 单场景拍摄时间

| 场景复杂度 | 预估时间 |
|-----------|---------|
| 简单对话 | 30-60 分钟 |
| 一般场景 | 1-2 小时 |
| 复杂场景 | 2-4 小时 |
| 高难度场景 | 4 小时以上 |

### 前期准备时间

| 项目 | 时间 |
|-----|-----|
| 设备检查 | 0.5 天 |
| 场地堪景 | 1-2 天 |
| 场景布置 | 根据复杂度 |

### 后期制作时间

| 项目 | 时间 |
|-----|-----|
| 素材整理 | 拍摄天数 × 0.5 |
| 粗剪 | 拍摄天数 × 1 |
| 精剪 | 2-5 天 |
| 调色 | 1-3 天 |
| 音效/配乐 | 2-4 天 |
