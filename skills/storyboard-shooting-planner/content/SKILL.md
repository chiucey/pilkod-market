# 分镜拍摄规划技能

根据导入的分镜脚本，自动分析并生成完整的拍摄需求清单，包括场景分解、设备清单、人员配置、场地要求和时间规划。

## 触发条件

当用户发送以下内容时激活本技能：
- 分镜脚本（文字描述或结构化格式）
- 故事板描述
- 镜头清单
- 要求生成拍摄计划、制作清单或制作时间表

## 工作流程

### 步骤 1：解析分镜脚本

解析用户输入的分镜内容，提取以下关键元素：

- **场景数量**：统计总场景数
- **场景描述**：每场的内容概要
- **镜头类型**：特写、中景、全景等
- **角色数量**：出现的角色/演员数
- **道具需求**：关键道具清单
- **特效需求**：视觉特效或特殊效果
- **音效/音乐提示**：需要的声音元素

### 步骤 2：生成拍摄需求分析

基于解析结果，生成以下输出：

#### 2.1 场景分解表

| 场景编号 | 场景描述 | 镜头数 | 时长估算 | 难度等级 |
|---------|---------|-------|---------|---------|
| Scene 01 | [描述] | X | X min | 低/中/高 |

#### 2.2 设备需求清单

**摄影设备**：
- 主机位数量
- 辅助设备（稳定器、脚架等）
- 特殊镜头需求

**灯光设备**：
- 基本灯光套装数量
- 特殊灯光需求

**音频设备**：
- 收音设备配置
- 现场录音需求

**特效设备**（如有需要）

#### 2.3 人员配置建议

| 岗位 | 人数 | 备注 |
|-----|-----|------|
| 导演 | 1 | |
| 摄影师 | X | 根据机位数量 |
| 灯光师 | X | |
| 录音师 | X | |
| 场务 | X | |

#### 2.4 场地需求

- 内景需求及数量
- 外景需求及数量
- 特殊场地要求
- 场地布置时间需求

#### 2.5 时间规划建议

- 前期准备时间
- 单场景拍摄时间估算
- 后期制作时间估算
- 总制作周期

#### 2.6 制作预算参考（可选）

根据场景复杂度和设备需求，提供预算范围参考。

## 输出格式

以结构化的 Markdown 表格和清单形式输出，确保信息清晰易读。使用适当的 emoji 增强可读性。

## 示例输入

```
场景1：室内办公室，日景，男女主角对话
场景2：户外街道，黄昏，男女主角行走
场景3：室内咖啡厅，夜景，反派登场
```

## 注意事项

1. **输入兼容性**：支持多种分镜脚本格式，优先解析结构化格式
2. **复杂度评估**：根据场景描述中的关键词（特效、夜景、动作等）评估难度
3. **灵活调整**：输出为建议性质，可根据实际项目情况调整
4. **中文优先**：默认使用中文输出，确保术语准确
