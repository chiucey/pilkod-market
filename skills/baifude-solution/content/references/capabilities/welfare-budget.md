# 福利预算发放管理

- **能力 ID**：BFD-005
- **所属模块**：商城交付 / 预算与发放
- **适用场景**：
  - HR 月度/季度/年度向员工发放福利（典型：节日福利、生日福利、周年福利）
  - 基于员工考勤表现自动发放奖励（全勤奖、出勤达标奖）
  - 加班餐补/加班福利的自动核算与发放
  - 通过客户自有系统（HRIS/OA）触发福利发放，需要对接而非 HR 手动操作
- **核心功能**：
  支持 **4 种发放方式**：
  1. **后台发放福豆** — HR 在百福得企业运营管理后台手动向员工账户充值福豆（BFD-004 资金形式）
  2. **系统对接发放** — 通过 API/对接由客户自有系统自动触发发放（适合大批量、与业务系统联动）
  3. **考勤规则发放** — 基于考勤规则自动核算并发放（如全勤奖、迟到/请假对应的福利调整）
  4. **加班餐领取规则** — 基于员工加班情况，自动生成加班餐补领取资格与额度
- **客户价值**：
  - 业务价值：把福利发放从"一次性集中操作"变成"持续可配置的业务规则"，HR 工作量大幅下降
  - 数字化价值：发放记录全链路留痕，可对账、可复盘、可对接客户 BI 系统
- **对接要求**：
  - 单点登录：与 BFD-002 组织管理选定的方案联动
  - 数据接口：考勤数据源（系统对接发放时）、加班记录、员工花名册
  - 实施周期：后台发放 1 周内；系统对接 2-3 周；考勤/加班规则 2-4 周（取决于规则复杂度）
- **典型客户场景**：
  - 场景 1：某 1000 人制造企业，每月按全勤情况发放餐补奖励 → 推荐**考勤规则发放**
  - 场景 2：某互联网公司，HR 希望员工加班后自动收到加班餐补 → 推荐**加班餐领取规则**
  - 场景 3：某集团型企业，福利发放由总部 HRIS 统一调度，需要把数据推送到百福得 → 推荐**系统对接发放**
- **注意事项 / 限制**：
  - 4 种发放方式**可叠加使用**（同一员工账户可由多种规则共同充值）
  - 考勤/加班规则的"规则定义"在百福得后台配置，**不能直接读取客户考勤系统**；需客户提供规则说明，百福得实施时配置
  - 福利发放涉税（现金福利 vs 实物福利），建议提前与财务确认
  - 大批量发放（>1000 人/次）建议用**系统对接发放**而非后台手动，避免操作失误
- **关联能力**：
  - 强关联：BFD-004 资金形式（发放的资产是福豆 / 三方积分 / 三方收银台）
  - 强关联：BFD-002 组织管理（发放对象依赖组织/用户数据）
  - 强关联：BFD-010 费控管理（发放后的消费环节需要配合费控规则）
