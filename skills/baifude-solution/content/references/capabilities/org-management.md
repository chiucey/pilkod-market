# 组织管理

- **能力 ID**：BFD-002
- **所属模块**：商城交付 / 基础支撑
- **适用场景**：
  - 客户需要把自有员工花名册、组织架构同步进百福得平台，以确定"谁能享受福利"
  - 客户对员工入离调转有实时性要求（如离职当天停发福利）
  - 客户已有 IM（钉钉/飞书/企微）或 HRIS，希望复用既有账号体系
- **核心功能**：
  百福得提供 **4 种接入方案**，按"客户投入度从低到高"排列：
  1. **标准方案 1：人工入离调转** — HR 在百福得企业运营管理后台手动维护员工档案；适合 100 人以下小客户、试水期客户
  2. **标准方案 2：三方 IM 平台 SSO 对接** — 与钉钉、飞书、企微、北森等三方 IM/HRIS 打通，员工用工作账号一键登录百福得，组织架构自动同步；适合主流中大型客户
  3. **标准方案 3：BFD-OpenAPI 对接** — 客户通过调用百福得 OpenAPI 自行推送组织/用户数据；轻量投入研发，联调即可上线
  4. **客制化入会** — 客户有自研 HR/账号系统，需要深度集成；百福得配合做定制开发，把客户生态的组织/用户数据无缝接入
- **客户价值**：
  - 业务价值：员工档案与组织架构实时一致，避免"离职员工继续领福利"的合规风险
  - 数字化价值：减少人工维护工作量，组织变动后福利权益自动跟随
- **对接要求**：
  - 单点登录：取决于所选方案
    - 方案 1：无需 SSO，HR 维护账号
    - 方案 2：需要客户在 IM 后台配置 OAuth / 应用授权
    - 方案 3：需要客户研发联调 OpenAPI
    - 客制化：需评估定制范围
  - 数据接口：员工花名册（姓名、手机号、工号、所属组织、入离职日期）、组织架构
  - 实施周期：方案 1 当天可用；方案 2 约 1 周；方案 3 约 2-3 周；客制化 4 周+
- **典型客户场景**：
  - 场景 1：某 300 人公司，已用飞书作为办公 IM，希望员工在飞书工作台一键进入福利商城 → 推荐**标准方案 2**（飞书 SSO）
  - 场景 2：某 5000 人集团，已有自研 HR 系统，希望组织变动实时同步到福利平台 → 推荐**标准方案 3**（OpenAPI）或**客制化**
  - 场景 3：某 50 人初创公司，无任何 IM/HRIS 需求简单 → 推荐**标准方案 1**（人工维护）
- **注意事项 / 限制**：
  - 4 种方案**互斥选择**，但部分场景可组合（如 SSO + OpenAPI 联合使用）
  - 北森对接：作为 HRIS 厂商，SSO 时需要客户确认北森侧的应用授权能力
  - 客制化方案涉及研发投入，需走商务评估流程
  - 客户组织数据涉及个保法敏感信息，建议明确数据存储位置与使用范围
- **关联能力**：
  - 强关联：BFD-001 商城交付（组织管理是商城的前置条件）
  - 依赖：本能力的选择直接决定 SSO 方案
