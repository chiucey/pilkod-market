# 结算开票

- **能力 ID**：BFD-009
- **所属模块**：商城交付 / 财务结算
- **适用场景**：
  - 客户需要按**企业主体**、**成本中心**等维度拆分账单（如多子公司、多事业部、成本归集到不同部门）
  - 客户需要百福得开具**增值税专用发票**（专票），用于进项抵扣
  - 客户财务需要在月末/年终结账时按特定维度汇总福利支出
- **核心功能**：
  通过两个机制支持结算开票：
  1. **对客清结算**：按企业主体/成本中心维度拆分账单与开票
  2. **开专票合规支持**：通过对接客户收银台满足专票开票的合规要求
- **对客清结算**（用户信息扩展 + 交易快照）：
  - **用户信息扩展**：客户对接百福得时（BFD-002 组织管理阶段），用户数据需要包含：
    - **企业主体**：员工所属的法人主体/公司（如"北京 XX 信息技术有限公司"）
    - **成本中心**：员工的成本归集部门（如"研发部-后端组"、"市场部-品牌组"）
    - （其他字段按需扩展，如项目代码、员工职级等）
  - **交易快照**：用户下单时，百福得在交易快照中**固化记录**上述字段
    - 即便后续用户调岗/调部门，**已发生的订单仍以"下单时点"的数据为准**
    - 避免事后争议和回溯成本
  - **账单出具**：百福得根据交易快照中的企业主体/成本中心维度出具账单
- **开专票的合规要求**（硬性约束）：
  - 客户如需百福得开具**增值税专用发票**（专票），**一般要求对接客户收银台**（BFD-012）
  - 合规原因：满足"**交易域属于客户**"这一条开专票合规要求
    - 专票的开票方必须是**交易的实际收款方**（即资金流的最终收款主体）
    - 在百福得自营福豆/三方积分体系下，资金流是"客户→百福得→商家"，交易域在百福得 → 只能开**普通发票**
    - 对接客户收银台后，资金流是"客户→客户收银台→百福得"，交易域在客户 → 客户可开**专票**
- **对接要求**：
  - 单点登录：与 BFD-002 组织管理联动
  - 数据接口：
    - **BFD-002 组织管理**：用户数据需扩展企业主体、成本中心等字段
    - **BFD-012 三方收银台对接**：开专票的客户必须叠加对接
  - 实施周期：
    - 仅启用"对客清结算"（用户数据扩展 + 账单出具）：1-2 周
    - 叠加"开专票支持"：需叠加 BFD-012 的 3-4 周实施周期
- **典型客户场景**：
  - 场景 1：某集团客户有 10 个子公司，每个子公司独立财务核算，需要按子公司拆分福利账单 → 启用"对客清结算"
  - 场景 2：某制造业客户按事业部核算成本，福利支出需分摊到不同事业部的成本中心 → 启用"对客清结算"
  - 场景 3：某金融客户需要百福得开专票用于增值税进项抵扣 → **必须对接客户收银台** + 启用"对客清结算"
  - 场景 4：某国企客户有"按项目代码归集成本"的财务要求 → 扩展用户数据字段（项目代码）+ 启用"对客清结算"
- **注意事项 / 限制**：
  - **专票 vs 普票**：
    - **普通发票**（普票）：开给个人或对发票无要求的客户；任何模式都支持
    - **增值税专用发票**（专票）：开给一般纳税人客户，用于进项抵扣；**必须对接客户收银台**（BFD-012）
  - **用户数据扩展的时点**：
    - 必须在 BFD-002 组织管理对接阶段就规划好企业主体、成本中心等字段
    - 后期补加字段，已发生的订单**无法回填**（需重新导入数据或做特殊处理）
  - **多企业主体开票**：
    - 不同子公司可能需要分别开票给各自的法人主体
    - 百福得根据交易快照中的"企业主体"字段拆分发票
  - **成本中心变动处理**：
    - 员工调岗/调部门时，建议按"**下单时点**"的成本中心为准
    - 避免回溯调账（成本高、易出错）
  - **跨境场景**：
    - 跨境交易涉及外汇、税务、关税等复杂问题，需单独评估
    - 跨境专票需符合"出口退税"等专项合规要求
- **关联能力**：
  - 强关联：BFD-002 组织管理（用户数据扩展是前置条件）
  - 强关联：BFD-012 三方收银台对接规范（开专票的合规路径）
  - 关联：BFD-004 资金形式（资金形式选择影响开票模式，福豆/三方积分下只能开普票）
  - 联动：BFD-104 基础数据管理（待补充，商品输出模式下的结算开票与对账）
  - 联动：BFD-011 三方积分对接规范（若客户用三方积分且需专票，仍需对接收银台）
