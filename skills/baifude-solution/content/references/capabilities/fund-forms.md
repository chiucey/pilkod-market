# 资金形式

- **能力 ID**：BFD-004
- **所属模块**：商城交付 / 支付与资产
- **适用场景**：
  - 客户希望明确"员工用什么钱在百福得商城里下单"
  - 客户已有自有积分体系（如游戏币、会员积分、银行积分），希望员工直接用现有积分消费
  - 客户已有自建收银台/电商系统，希望百福得商城嵌入到客户自有收银体系内
- **核心功能**：
  百福得支持 **4 种资金形式**，对应不同资金归属与支付路径：
  1. **福豆**（百福得自有资产）
     - 百福得平台内部通用资产，由百福得收银台完成下单支付
     - 适用：客户没有自有积分体系，HR 向员工福豆账户充值，员工在商城用福豆消费
  2. **三方积分**（对接客户既有积分）
     - 把客户系统的积分余额对接进百福得，员工直接使用客户积分余额下单
     - 支付路径：仍在百福得收银台内完成
     - 适用：客户已有成熟积分体系（游戏公司、银行的会员积分、零售会员积分等），希望复用
  3. **三方收银台**（对接客户收银体系）
     - 把客户的收银台对接进来，订单支付完全在客户收银台完成
     - 与百福得收银台**无关**；一般情况下所有资产由客户管理
     - 部分客户会给百福得开通收款商户，用于收取订单中的现金部分
     - 适用：客户有自建电商/支付体系，希望完全自有闭环
  4. **三方积分转福豆**（BFD-013 简化版，BFD-011 的轻量变体）
     - 员工把客户的三方积分**单向兑换**为百福得福豆，福豆充值到员工百福得账户
     - **兑换不可逆**：福豆不能再退回客户的三方积分
     - 适用：客户希望规避退款接口对接复杂度、福利场景简单、不涉及复杂多次退款
     - 复用 BFD-011 的 3 个 API（余额查询 / 余额扣减 / 支付结果查询），**省略退款接口**
     - 实施周期更短（1-2 周）
- **客户价值**：
  - 业务价值：尊重客户既有的资金/资产体系，避免重复建设；客户可根据合规要求和资金管理诉求灵活选择
  - 数字化价值：财务对账、税务处理按客户既有的资金路径走，无需切换体系
- **对接要求**：
  - 单点登录：与 BFD-002 组织管理联动
  - 数据接口：
    - 福豆：百福得后台充值，HR 自助操作
    - 三方积分：客户提供 4 个 API（余额查询 / 余额扣减 / 退款 / 支付结果查询），**完整对接规范见 BFD-011**
    - 三方积分转福豆：客户提供 3 个 API（省略退款接口），**简化版规范见 BFD-013**
    - 三方收银台：客户提供 3 必备 + 1 可选 API（预下单 / 退款 / 支付结果查询 / 余额查询可选），**完整对接规范见 BFD-012**
  - 实施周期：福豆 1 周内；三方积分 2-3 周（取决于客户 API 成熟度，详见 BFD-011）；三方积分转福豆 1-2 周（详见 BFD-013）；三方收银台 3-4 周（详见 BFD-012）
- **典型客户场景**：
  - 场景 1：某互联网公司希望员工福利以"积分制"发放，HR 月初给每人充值福豆，员工自选兑换 → **福豆**
  - 场景 2：某游戏公司已有游戏币积分，希望员工福利也能用游戏币兑换福利商品 → **三方积分**
  - 场景 3：某大型零售集团已有自己的会员电商和收银台，希望百福得商城商品嵌入到自家 APP 收银流程 → **三方收银台**
  - 场景 4：某零售客户希望员工用会员积分兑换福豆后消费，担心会员积分体系对接退款接口的复杂度 → **三方积分转福豆**
- **注意事项 / 限制**：
  - **4 种形式互斥**（同一笔订单只能用一种资金），但可按员工/场景配置不同员工用不同资金形式
  - **三方积分**与**三方收银台**的关键区别：前者仍在百福得收银台内（百福得主导支付流程），后者完全脱离百福得收银台（客户主导支付流程）
  - **三方积分转福豆**与**三方积分**的关键区别：前者兑换单向不可逆（福豆不能退回三方积分），退款走福豆账户内部路径；后者积分始终在客户体系内，可双向流转
  - 涉及**现金收款**的场景（如三方收银台中的现金部分）需要走**百福得收款商户号**开通流程，涉及 KYC 与税务合规
  - 福豆有有效期/使用范围限制时，需在 HR 后台提前配置（避免员工投诉）
  - 跨境资金（如外籍员工）需要单独评估币种与合规
- **关联能力**：
  - 强关联：BFD-001 商城交付、BFD-002 组织管理
  - 详细规范：
    - BFD-011 三方积分对接规范（百福得主导支付，4 个 API 详细时序与幂等约定）
    - BFD-013 三方积分转福豆（简化版，3 个 API，省略退款接口，详见 BFD-013）
    - BFD-012 三方收银台对接规范（客户主导支付，3 必备 + 1 可选 API + 异步通知机制）
  - 决策联动：资金形式的选择与 BFD-009 结算开票（开专票必须对接收银台）紧密相关
