## 怎么新增一条能力

详细规范见 `../capability-schema.md`。一句话流程：
1. 复制 schema 模板到 `references/capabilities/<kebab-name>.md`
2. 填字段 + 分配能力 ID（看本表最大编号 +1，注意：跳过"待补充"表格中已暂占的 ID）
3. 在本表"已收录能力"区追加一行
4. 完成 ✅

## 维护备注

- 建议按"补充一个能力就跑一次"的方式累积，不要一次堆很多条质量不齐的
- 能力 ID 一旦分配不要改动（即使能力下线也要标"已下线"而不是删 ID）
- 能力有重大更新时（功能、限制变化），在对应 .md 文件顶部加一行 `> 更新于 YYYY-MM-DD：XXX`
- "待补充"列表中暂定的 ID 不要直接发放给客户，等用户补充详细定义后正式落库再使用
- BFD-010（费控管理）是用户后续追加的"非原 8 模块"项，体现了"商城交付核心内容"可继续扩展
