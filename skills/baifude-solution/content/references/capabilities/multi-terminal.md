# 多终端交付

- **能力 ID**：BFD-003
- **所属模块**：商城交付 / 用户触达
- **适用场景**：
  - 客户希望员工可以在不同终端（App / 小程序 / H5）灵活访问福利商城
  - 客户有自研小程序，希望在自家生态内嵌百福得商城内容
  - 客户有多个业务线 / 子品牌，需要给不同人群定向呈现不同商城页面
- **核心功能**：
  1. 支持 **百福得 App**、**百福得小程序**、**百福得 H5** 等多终端，员工可按习惯选择
  2. H5 嵌入到客户小程序环境时，支持按交付频道/品牌配置授权域名（解决跨域访问与白名单问题）
  3. 支持按客户需求场景，配置"不同场景入口 → 定向 H5 页面"的多场景交付登录（如从钉钉工作台进的是一个页面、从企微进的是另一个）
- **客户价值**：
  - 业务价值：员工在常用办公入口就能进入福利商城，无需额外下载/跳转，触达效率高
  - 数字化价值：可根据入口来源做数据归因（哪个入口转化率高）
- **对接要求**：
  - 单点登录：与 BFD-002 组织管理选定的 SSO 方案联动
  - 数据接口：场景入口与定向页面的映射配置（客户提供场景清单）
  - 实施周期：标准终端 1-2 周；嵌入到客户小程序需评估域名授权情况
- **典型客户场景**：
  - 场景 1：客户企业有自研办公 App，希望员工在工作台内直接打开福利商城 → **H5 嵌入方案**，需客户提供小程序环境的授权域名
  - 场景 2：客户有 3 条业务线（总部、子公司、海外），希望员工进入时看到不同商品池 → **多场景定向 H5**，按入口配置不同页面
  - 场景 3：客户希望员工"零摩擦"领福利（不下载任何 App） → 推荐 **H5 或百福得小程序**
- **注意事项 / 限制**：
  - **域名授权**：H5 嵌入到客户小程序环境时，每个交付频道/品牌需要单独配置可访问的页面域名，**不是一次配置全量生效**；实施前要明确客户的频道清单
  - 海外员工：H5 需考虑访问速度与合规
  - 终端切换的体验一致性：App / 小程序 / H5 的功能范围可能略有差异（以产品最新能力为准）
  - 多场景定向 H5：场景数量越多配置工作量越大，建议早期聚焦 2-3 个核心场景
- **关联能力**：
  - 强关联：BFD-002 组织管理（终端访问的账号体系依赖组织管理）
  - 强关联：BFD-001 商城交付
