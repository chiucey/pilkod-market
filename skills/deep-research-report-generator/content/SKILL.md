# 深度调研报告生成器

## 核心能力

- 多类型报告：行业研究、市场分析、竞品分析、投资研究
- 专业分析框架：PEST、波特五力、SWOT、波特价值链
- 数据驱动：整合权威数据源，支持图表可视化
- 多格式输出：Markdown、DOCX、PDF、HTML

## 触发条件

当用户需要以下类型的报告时触发：
- 行业研究报告
- 市场分析报告
- 竞品分析报告
- 投资可行性报告
- 商业调研报告
- 任何需要数据支撑的专业研究报告

## 分析框架

### 1. PEST宏观分析
- 政治（Political）：政策环境、法规影响
- 经济（Economic）：市场规模、增长趋势
- 社会（Social）：人口特征、消费习惯
- 技术（Technological）：技术变革、创新趋势

### 2. 波特五力模型
- 现有竞争者的竞争程度
- 新进入者的威胁
- 替代品的威胁
- 供应商的议价能力
- 购买者的议价能力

### 3. SWOT分析
- 优势（Strengths）
- 劣势（Weaknesses）
- 机会（Opportunities）
- 威胁（Threats）

### 4. 财务分析模型
- DCF现金流折现
- LTV/CAC分析
- 盈亏平衡分析
- 投资回报率测算

## 执行流程

### 阶段1：需求确认

当技能被触发时，通过交互式表单收集以下信息：

1. **报告类型**：行业研究 / 市场分析 / 竞品分析 / 投资研究 / 其他
2. **研究主题**：目标行业/企业/产品
3. **目标受众**：投资机构 / 企业决策层 / 学术研究 / 个人参考
4. **详细程度**：简要概述 / 标准报告 / 深度报告
5. **数据要求**：是否需要最新数据 / 图表可视化 / 预测分析

### 阶段2：信息收集与数据获取

1. **网络搜索**：使用 `batch_web_search` 收集权威数据
   - 搜索行业报告、统计数据、政策文件
   - 收集竞品信息、市场规模数据
   - 获取最新行业动态和趋势

2. **数据整理**：将收集的数据分类整理
   - 定量数据：市场规模、增长率、份额
   - 定性分析：竞争格局、技术趋势、政策影响
   - 财务数据：营收、利润、投资动态

### 阶段3：框架分析与报告撰写

根据报告类型选择适当框架组合：

**行业研究报告必备章节**：
1. 执行摘要
2. 研究背景与方法
3. 行业概况与市场现状
4. 市场分析与规模估算
5. 竞争格局分析
6. 行业发展趋势
7. 投资分析/建议
8. 风险提示与应对
9. 结论与建议

**竞品分析报告必备章节**：
1. 竞品概览
2. 产品对比分析
3. 商业模式对比
4. 市场表现分析
5. 竞争优势/劣势
6. 市场策略分析
7. 发展潜力评估
8. 启示与建议

### 阶段4：报告生成与格式化

1. **内容生成**：按结构撰写各章节
2. **数据可视化**：生成图表（Mermaid、Matplotlib）
3. **格式排版**：
   - Markdown格式（默认）
   - 可选：DOCX、PDF、HTML

### 图表规范

- 使用Mermaid格式生成流程图、架构图
- 使用Matplotlib生成数据图表（柱状图、折线图、饼图）
- 所有图表必须包含清晰的标题和注释

## 质量标准

1. **数据准确性**：所有数据必须标注来源
2. **分析深度**：运用至少2种专业分析框架
3. **时效性**：优先使用最新数据和趋势
4. **可操作性**：结论和建议必须具体可执行
5. **格式规范**：结构清晰、逻辑连贯

## 交付物

- 主报告文档（Markdown格式）
- 数据图表文件（如需要）
