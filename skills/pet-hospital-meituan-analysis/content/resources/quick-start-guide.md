## 美团经营宝时间筛选三种方法（必读！）

> ⚠️ **之前踩过的坑**：
> 1. ❌ 只用了"日"模式 → 以为系统不能选3月，其实是没切到"月"
> 2. ❌ 没发现"日|月"切换 → 页面上这个切换按钮不起眼，容易被忽略
> 3. ❌ 首页小组件没有月视图 → 首页经营参谋只有"实时/昨天"，不是完整的数据页面

### 三种方法对比表

| | 方法一：日 | 方法二：月 | 方法三：自定义 |
|---|---|---|---|
| **位置** | 筛选栏"日\|月"中选"日" | 筛选栏"日\|月"中选"月" | 在"日"模式下点击"自定义" |
| **统计粒度** | 按天 | 按月 | 按天 |
| **可选历史月份** | ❌ 不能（约30天内） | ✅ **可以**（关键差异！） | ❌ 受限（约30天内） |
| **环比功能** | 较上7天/30天 | 较前1月 | 无 |
| **适用场景** | 日常监控 | **月报/历史月份数据** | 灵活时间段 |

### 方法二：月（按月统计）【⭐ 获取历史月份数据的正确方式】

- **位置**：经营参谋子页面顶部筛选栏，"日 | 月"切换中选"月"
- **特点**：
  - ✅ **不受30天限制**：可自由选择历史月份（如2026年3月）
  - ✅ **环比功能**：可勾选"较前1月表现"，自动显示环比变化
- ⭐ **这是获取历史月份数据的唯一正确方式！**

### ⚡ 采集历史月份数据时的标准操作

```
1. 必须先切到"月"模式，再选目标月份
2. 每个页面切换后截图确认时间范围文字（如"2026-03-2026-03"）
3. 勾选"较前1月表现"可同时获取环比数据
4. 首页和推广中心没有月视图，这些页面的数据只能用"日"或"自定义"获取
```

## 🚀 10分钟快速上手

### 第一步：采集前准备（2分钟）

```
□ 打开美团商家后台（e.dianping.com）
□ 登录账号
□ 确认门店名称正确
□ 检查系统时间是否正确
□ 准备截图工具（PNG格式+2倍DPI设置）
```

### 第二步：时间验证（2分钟）

```
⚠️ 重要：每个页面采集前必须执行7步时间验证

步骤1：进入页面后查看系统时间
步骤2：截取包含时间的截图
步骤3：OCR识别时间文字
步骤4：核对与目标时间是否一致
步骤5：不一致则刷新重试
步骤6：3次失败则终止采集
步骤7：记录time_before+time_after截图
```

### 第三步：数据采集（5分钟/页面）

```
1. 经营评分页面 → 10个数据点
2. 竞对洞察页面 → 6个数据点
3. 本店分析页面 → 17个数据点
4. 评价管理页面 → 10个数据点
5. 市场洞察页面 → 10个数据点

每个页面截图命名规范：
- time_before_XXX.png（时间验证前）
- data_XXX_01.png（数据截图）
- time_after_XXX.png（时间验证后）
```

### 第四步：数据录入（3分钟）

```
1. 打开采集模板
2. 将53个数据点填入对应表格
3. 每个数据点标注截图编号
4. 模糊数据标注【截图模糊无法准确识别】
5. 填写时间验证日志
```

### 第五步：质量检查（2分钟）

```
□ 时间验证日志已填写
□ 所有截图PNG格式确认
□ 所有截图2倍DPI确认
□ 每个数据点有截图编号
□ 模糊数据有标注
□ 执行交付前抽查（≥10%）
```

### 第六步：生成报告（10分钟）

```
1. 打开报告模板
2. 填入53个数据点
3. 按10大模块填充分析内容
4. 每个✅附带截图编号+验证方式
5. 制定90天行动计划
```

## 常见问题FAQ

### Q1：数据采集需要多久？
**A：** 熟练后约30-60分钟，包含时间验证和质量检查。

### Q2：报告生成需要多久？
**A：** 基于完整数据，约15-30分钟。

### Q3：没有某些数据怎么办？
**A：** 统一标注【截图模糊无法准确识别】，不要臆测或估算。

### Q4：时间验证失败怎么办？
**A：** 刷新页面重试，3次失败则终止该页面采集，记录问题后继续其他页面。

### Q5：截图模糊怎么办？
**A：** 删除截图，重新截取同一页面，再次检测。3次失败则标注【截图模糊无法准确识别】。
