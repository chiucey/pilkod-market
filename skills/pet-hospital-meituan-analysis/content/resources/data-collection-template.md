## 【第0阶段】采集前强制验证（必须完成）

### 阶段0.1：门店验证（4步）

| 步骤 | 操作 | 输出 | 质量要求 |
|------|------|------|---------|
| 1 | 截图门店名称 | `store_verify_01.png` | 必须包含完整门店名称 |
| 2 | OCR识别门店名称 | 识别文本A | - |
| 3 | 与目标门店比对 | 比对A vs 目标B | 必须100%一致 |
| 4 | 验证结果记录 | store_verify_log | - |

### 阶段0.2：时间验证7步流程（核心红线）

> ⚠️ **时间准确性是红线1的核心**，每进入一个数据页面必须执行7步时间验证：

```
步骤1：进入目标页面
步骤2：点击时间选择器，等待2秒
步骤3：确认时间选项可见（选择"日/月/自定义"）
步骤4：点击目标时间
步骤5：等待3秒（数据加载）
步骤6：OCR验证时间戳
步骤7：截图存档（time_before + time_after）
```

## 美团经营宝时间筛选三种方法

| | 方法一：日 | 方法二：月 | 方法三：自定义 |
|---|---|---|---|
| **位置** | 筛选栏"日\|月"中选"日" | 筛选栏"日\|月"中选"月" | 在"日"模式下点击"自定义" |
| **统计粒度** | 按天 | 按月 | 按天 |
| **可选历史月份** | ❌ 不能（约30天内） | ✅ **可以**（关键差异！） | ❌ 受限（约30天内） |
| **环比功能** | 较上7天/30天 | 较前1月 | 无 |
| **适用场景** | 日常监控 | **月报/历史月份数据** | 灵活时间段 |

### ⚡ V2.3标准建议：采集历史月份数据时

```
1. 必须先切到"月"模式，再选目标月份
2. 每个页面切换后截图确认时间范围文字（如"2026-03-2026-03"）
3. 勾选"较前1月表现"可同时获取环比数据
4. 首页和推广中心没有月视图，这些页面的数据只能用"日"或"自定义"获取
```
