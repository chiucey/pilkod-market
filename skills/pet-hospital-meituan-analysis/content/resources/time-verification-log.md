## 美团经营宝时间筛选三种方法（必读！）

> ⚠️ **重要提示**：获取历史月份数据必须使用"月"模式！以下三种方法必须严格区分。

### 三种方法总览

| | 方法一：日 | 方法二：月 | 方法三：自定义 |
|---|---|---|---|
| **位置** | 筛选栏"日\|月"中选"日" | 筛选栏"日\|月"中选"月" | 在"日"模式下点击"自定义" |
| **历史月份支持** | ❌ 不能（约30天内） | ✅ **可以**（关键差异！） | ❌ 受限（约30天内） |
| **环比功能** | 较上7天/30天 | 较前1月 | 无 |

### ⚡ V2.3标准：采集历史月份数据时

```
1. 必须先切到"月"模式，再选目标月份
2. 每个页面切换后截图确认时间范围文字（如"2026-03-2026-03"）
3. 勾选"较前1月表现"可同时获取环比数据
```

## 7步时间验证流程

> ⚠️ **V2.3升级**：增加"月"模式切换验证步骤，确保历史月份数据采集正确。

```
步骤1：进入页面后查看系统时间
步骤2：确认时间筛选模式（"日"或"月"）- 采集历史月份必须选"月"
步骤3：截取包含时间的页面截图（time_before_XXX.png）
步骤4：OCR识别截图中的时间文字
步骤5：核对OCR识别时间与目标时间是否一致
步骤6：若不一致，刷新页面重新获取
步骤7：离开页面前截取时间截图（time_after_XXX.png）
```

**模式切换验证（V2.3新增）：**
```
采集历史月份时：
□ 确认已切换到"月"模式
□ 截图确认月份选择器显示正确月份（如"2026-03"）
□ 勾选"较前1月表现"选项（可选）
□ 等待数据加载后截图
```
