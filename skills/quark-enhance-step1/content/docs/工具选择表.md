> 入参统一：`dataBase64`（图片 base64）或 `dataUrl`（https 公网 URL）二选一。
> 计费：除 `scan_general_ocr` 实测 0 计费外，其余按**每图每次 1 计费**。

## 一、我们的默认选择（先看这张）

| 输入 | 选用 | 理由 |
|---|---|---|

## 三、组合用法（常见两段式）

```
拍摄件（含阴影/屏幕纹）
  └ scan_remove_shadow 或 scan_remove_screen_pattern   （1 次）
      └ scan_certificate_invoice_enhance                （1 次）
          └ 本地：零重编码落版（0 计费）
```

> 注意：每一段都是一次独立计费。**能一段解决就不要两段**——先在本地把方向、载荷、边界处理好，再上传。
> 复合图（一页含多件）**不拆分**，一次调用处理整页。

## 四、复印效果与红章保色（如需白底黑字）

原理：`scan_remove_background_color` 去底色 → 本地灰度强化（autocontrast + 阶调压缩）→ A4 合成。

**红章保色**（要保留红色印章时）：

- 红色蒙版：`red_diff = R - max(G, B)`，`alpha = clip(red_diff / 35, 0, 1)`（**零模糊**）
- 重着色保笔画：`out = (V, V·(1−S′), V·(1−S′))`，V = 原明度（笔画浓淡 → 红深浅），`S′ = clip(S × 1.9, 0, 0.95)`
- **禁用**高斯模糊蒙版 + 单色平涂——会把章内文字抹成一团（实测翻车点）

## 五、失败与替代

| 现象 | 判断 | 替代 |
|---|---|---|
| 返回图丢失人像/国徽 | 误用了 `scan_image_to_pdf` | 改 `scan_certificate_invoice_enhance` |
| 返回图整体躺倒 | 源件方向未摆正 / 按 EXIF 误旋 | 用存储像素重新摆正 |
| HTTP 413 | 载荷超限 | 回到 `prepare.py` 压缩（长边 ≤800px） |
| 输出是碎片图 | 图像被裁切 | 检查是否被 `scan_crop_rectify` 误裁；改用增强类工具 |
| 结果不满意但已计费 | — | 原始响应与图像**已落盘**，可本地继续处理，**不要重调** |
