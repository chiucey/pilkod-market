# 操作手册（分步命令）

> 一站式用法见 README；本文件给的是**可单独调用的分步命令**，便于排障与精细控制。

---

## 0. 环境

```bash
node -v                        # >= 18
python -c "import PIL, numpy"  # 图像处理
python -c "import pypdf"       # 可选，读 PDF 用

export QUARK_AI_API_KEY=<你的 aiApiKey>     # Linux/macOS
set QUARK_AI_API_KEY=<你的 aiApiKey>        # Windows CMD
$env:QUARK_AI_API_KEY="<你的 aiApiKey>"     # Windows PowerShell
```

自检调用链（首次部署必做）：

```bash
node scripts/call_mcp.js --list      # 应列出 36 个工具
```

---

## 1. ⓪ 体检（免费）

```bash
python scripts/probe.py --input "图.jpg" --pretty
python scripts/probe.py --input "目录/" -o probe.json       # 批量
python scripts/probe.py --input "扫描件.pdf" --pretty
```

关键输出：`kind`（拍摄件/文档类图像/扫描PDF）、`dpi_est`、`edge.all_white`、`std_paper`、
`dark_band.flagged`、`exif.orientation`、`cloud_suggest` + `cloud_reason`。

---

## 2. ① 预处理（免费）

```bash
# 一般上云前
python scripts/prepare.py --input "图.jpg" --outdir "./_out" --max-long-edge 800 --quality 85

# 源件方向不对（逆时针旋正 90 度；以存储像素为准，不要看 EXIF）
python scripts/prepare.py --input "图.jpg" --outdir "./_out" --rotate 90

# 含防伪底纹的 PNG（不转 JPEG，保住网纹）
python scripts/prepare.py --input "图.png" --outdir "./_out" --keep-format
```

产出：`_out/<name>_prep.jpg`（或 `.png`）＋ `_out/<name>_prep.args.json`（内含 `dataBase64`）。

---

## 3. ② 上云（计费，每图 1 次）

```bash
node scripts/call_mcp.js scan_certificate_invoice_enhance \
     @"_out/图_prep.args.json" --outdir "./_out" --name 图
```

产出：

```
_out/enhanced/图.jpg        增强结果
_out/mcp_raw/图.json        原始响应（留档，可复用，绝不重调）
stdout: 一行 JSON（含 elapsed_ms / dimensions / 计费次数）
```

其他常用工具：

```bash
node scripts/call_mcp.js scan_general_ocr @"...args.json" --outdir ./_out --name ocr   # 免费
node scripts/call_mcp.js scan_remove_screen_pattern @"...args.json" --outdir ./_out   # 去屏幕纹
node scripts/call_mcp.js scan_image_hd_enhance @"...args.json" --outdir ./_out        # 超分
```

---

## 4. ③ 核验（免费）

```bash
python scripts/verify.py --src "_out/图_prep.jpg" --out "_out/enhanced/图.jpg" -o verify.json
```

输出：`geometry_change_pct`（几何变化率）、`geometry_level`、`sharpness_ratio`、`verdict.level`（A/B/C）与 `todo`。

判定口径：

| 几何变化率 | 级别 | 处置 |
|---|---|---|
| ≤ 2% | 良好 | 直接可用 |
| 2–5% | 可接受 | 落版须按主导边锚定、另一边等比推算 |
| > 5% | 超限 | 人工确认；**禁止拉伸修正** |

## 5. ④ 一站式

```bash
python scripts/run_step1.py --input "图.jpg" --outdir "./_out" --purpose 证件卡
python scripts/run_step1.py --input "图.jpg" --outdir "./_out" --cloud no        # 只体检不调用
python scripts/run_step1.py --input "扫描件.pdf" --outdir "./_out"               # PDF → 本地路径
```

产出：`_out/result.json`（标准化报告）＋ `_out/run.log`。

## 6. 参数速查

| 脚本 | 参数 | 说明 |
|---|---|---|
| probe.py | `--input` `-o` `--pretty` | 体检 |
| prepare.py | `--rotate {0,90,180,270}` | 逆时针旋正（以存储像素为准） |
| | `--max-long-edge`（默认 800） | 缩放上限 |
| | `--max-mb`（默认 1.4） | 载荷上限 |
| | `--quality`（默认 85） | JPEG 质量 |
| | `--keep-format` | 含底纹的 PNG 用它 |
| call_mcp.js | `@args.json` | 大 base64 必须走文件 |
| | `--outdir` `--name` | 落盘位置与命名 |
| verify.py | `--change-warn`（2.0）`--change-fail`（5.0） | 几何变化率阈值 |
| run_step1.py | `--purpose {auto,证件卡,文档,票据,图片}` | 决定默认工具 |
| | `--cloud {auto,yes,no}` | 强制/自动决定是否上云 |
| | `--tool` | 覆盖工具选择 |
| | `--allow-ocr` | 允许对纯文字文档用 `scan_image_to_pdf`（**确认无要素再用**） |

## 7. 常见问题

**Q：为什么不上云却也有输出？**
本地路径会把源件原样复制到 `_out/enhanced/`，并在 `verdict.todo` 里给出落版建议（提示下游必须零重编码）。这是刻意的——**很多件本来就不该上云**。

**Q：调用返回了结果但我不满意，能重调吗？**
不能，先看 `_out/mcp_raw/*.json` 与增强图。**结果已落盘，本地继续处理即可**，重调只会再花一次计费。

**Q：`scan_image_to_pdf` 报了"拒绝"？**
这是保护机制。该工具是 OCR 重建，会丢人像/国徽/防伪底纹/手写签名。
确认这份件**确实没有**这些要素后，加 `--allow-ocr` 才会执行。

**Q：PDF 输入走什么路径？**
本地路径。`probe.py` 会读页数、每页图像编码、`/Rotate`、文字层是否可用，并在报告里给出落版建议
（页面级克隆 / 字节复制 / 只改 MediaBox）。**不要转成图片再拼回去。**

**Q：处理完的 `_out` 目录要保留吗？**
整目录交回调用方（`result.json` 是下游归档的依据）。本包自身不保留任何长期副本。
