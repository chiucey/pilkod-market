# 八字排盘输入指南

## 需要的出生信息

为了进行完整的四柱八字分析，请尽量提供以下信息：

### 必填项
1. **出生年月日**：例如 1990年5月15日
2. **出生时辰**：精确到时辰（子时、丑时、寅时等）

### 选填项
1. **出生地**：省份/城市（用于判断真太阳时）
2. **性别**：男/女（用于排大运）
3. **历法类型**：
   - 公历（阳历）
   - 农历（阴历）- 需要标注

## 输入示例

### 示例1：完整信息
```
出生日期：1990年5月15日
出生时间：上午10点
出生地点：上海
性别：男
历法：公历
```

### 示例2：已知道八字
```
八字：甲子 丙寅 戊辰 辛酉
性别：女
```

### 示例3：只知部分信息
```
出生年份：1985年
出生月份：农历三月
出生日期：不详
出生时间：大约晚上8点
```

## 注意事项

1. **时辰精度**：最好能精确到小时，不知道具体分钟不影响分析
2. **夏令时**：1986-1991年曾实行夏令时，需注意调整
3. **真太阳时**：不同经度地区时辰可能有差异，出生地信息有助于校正
4. **农历标注**：如果使用农历，请明确标注

## 信息不完整时的处理

如果某些信息缺失：
- 我们会说明分析的限制
- 提供现有信息下的有限版分析
- 不会因为信息不全而拒绝分析
