# 梅花易数占卜技能

## 核心原理

梅花易数以"心易"为宗，通过特定算法将用户信息转化为卦象，再根据体用生克关系进行解读。

### 先天卦数对应

| 卦象 | 数字 | 五行 | 象意 |
|------|------|------|------|
| 乾 | 1 | 金 | 天、圆、健、刚 |
| 兑 | 2 | 金 | 泽、毁、悦、决 |
| 离 | 3 | 火 | 火、日、电、丽 |
| 震 | 4 | 木 | 雷、动、震、惧 |
| 巽 | 5 | 木 | 风、入、散、谦 |
| 坎 | 6 | 水 | 水、下、陷、劳 |
| 艮 | 7 | 土 | 山、止、静、笃 |
| 坤 | 8 | 土 | 地、顺、柔、吝 |

### 五行生克

- **相生**：木 → 火 → 土 → 金 → 水 → 木
- **相克**：木 克 土 克 水 克 火 克 金 克 木

## 起卦算法

### 数字起卦

用户需要提供**两个数字**（可以是任意数字，如电话号码、日期、随机想一个数等）：

```
上卦 = (数字1 % 8)，若结果为0则取8
下卦 = (数字2 % 8)，若结果为0则取8
动爻 = ((数字1 + 数字2) % 6)，若结果为0则取6
```

### 时间起卦

基于年月日时起卦：

```
年支数 = 地支对应的数字（子1丑2...亥12）
月数 = 月份（1-12）
日数 = 日期（1-31）

上卦 = (年支数 + 月数) % 8，若为0则取8
下卦 = (上卦 + 日数) % 8，若为0则取8
动爻 = (年支数 + 月数 + 日数) % 6，若为0则取6
```

时间取农历时间的地支数。

## 解卦流程

### 第一步：确定体用

- **体**：代表问卦者本人或主方
- **用**：代表所问之事或对方

动爻所在的卦为"用卦"，另一个为"体卦"。若动爻在上卦，则上卦为用，下卦为体；若动爻在下卦，则下卦为用，上卦为体。

### 第二步：分析主卦

| 卦象组合 | 吉凶 | 说明 |
|----------|------|------|
| 用生体 | 大吉 | 所求之事顺利，有贵人相助 |
| 体用比和 | 中吉 | 所求之事平稳，可得 |
| 体克用 | 小吉 | 需努力付出方可得 |
| 用克体 | 大凶 | 阻碍重重，难以成功 |
| 体生用 | 耗泄 | 付出较多，需防破耗 |

### 第三步：分析变卦

动爻变化后形成变卦，对应事情发展的最终结果或变化趋势。

### 第四步：判断应期

根据卦中五行生克和旺相休囚，判断事情发生的时间：
- **旺相**：事情将在近期（当天~数日内）发生
- **休囚**：事情较慢，需更长时间
- **入库**：事情暂缓，需等待时机

### 详细解析部分（口语化娓娓道来）

#### 一、卦象基础
- 卦象符号（五行符号）
- 卦象象意
- 核心含义

#### 二、体用分析
- 体卦的象征含义
- 用卦的象征含义
- 两者关系解读

#### 三、五行生克
- 体用五行属性
- 生克关系详解
- 对问事的影响

#### 四、卦象详解
- 主卦解读
- 变卦解读
- 事情发展脉络

#### 五、应期判断
- 事情发生的时间判断
- 需要注意的时机

#### 六、外应参考
- 起卦时的兆头提示
- 需要留意的细节

## 注意事项

1. 问卦态度：保持诚心，起卦时心无杂念
2. 心态调整：卦象仅供参考，命运掌握在自己手中
3. 解读灵活：结合实际情况灵活理解卦意
4. 积极面对：无论卦象如何，都应积极行动
