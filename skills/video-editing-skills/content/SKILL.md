# 视频剪辑与编辑技能

## 目标

提供从**素材分析 → 剪辑制作 → 特效添加 → 成品输出**的完整视频编辑工作流程，涵盖短视频、宣传片、教学视频、Vlog 等常见场景。

## 快速工作流

```
需求理解 → 素材分析 → 剪辑方案 → 编辑制作 → 特效与调色 → 导出交付
```

### 1. 需求理解（使用表单）

> **先问清关键信息，避免返工**

| 表单字段 | 说明 | 示例 |
|---------|------|------|
| 视频类型 | 短视频/宣传片/教学/电商 | "产品宣传" |
| 时长要求 | 目标时长 | "60-90秒" |
| 画面风格 | 清新/电影感/科技感/复古 | "科技感" |
| 音效要求 | BGM/配音/字幕 | "需要背景音乐+字幕" |
| 品牌元素 | Logo/配色/字体 | "用公司Logo" |

**表单示例**：
```markdown
请确认视频需求：

1. 视频类型：①短视频 ②宣传片 ③教学视频 ④电商带货 ⑤Vlog ⑥其他
2. 目标时长：①15-30秒 ②30-60秒 ③1-3分钟 ④3分钟以上
3. 画面风格：①清新自然 ②电影感 ③科技感 ④复古 ⑤其他
4. 音效：①纯音乐BGM ②配音+字幕 ③两者都要
5. 品牌要求：___（如Logo位置、配色等）
```

### 2. 素材分析

#### 素材类型检查

| 素材类型 | 处理要点 |
|---------|---------|
| 用户上传视频 | 检查时长、分辨率、格式 |
| 用户提供文案 | 提取关键信息点 |
| 用户提供图片 | 检查数量和质量 |
| 纯文字需求 | 需要生成对应视觉内容 |

#### 素材质量评估

```
检查项：
- 视频分辨率（建议1080P以上）
- 音频清晰度
- 光线条件
- 画面稳定度
- 内容完整性
```

---

### 3. 剪辑方案制定

#### 常见视频结构

**短视频（15-60秒）**：
```
开场（3秒）：吸引注意力
主题（5-10秒/个）：核心内容展示
结尾（3-5秒）：CTA或总结
```

**宣传片（1-3分钟）**：
```
片头（5秒）：Logo+主题
背景介绍（10-20秒）
核心内容（分章节，每节15-30秒）
成果展示（10-20秒）
结尾（5秒）：联系信息
```

**教学视频**：
```
导入（30秒）：问题/目标
步骤讲解（每步1-2分钟）
总结回顾（30秒）
作业/练习（可选）
```

#### 转场建议

| 场景 | 推荐转场 |
|-----|---------|
| 同一场景多镜头 | 硬切/Cut |
| 不同场景切换 | 淡入淡出/Fade |
| 节奏感强的内容 | 快速切换/Swipe |
| 情感过渡 | 叠化/Dissolve |

### 4. 编辑制作

#### 基础剪辑操作

| 操作 | 工具/方法 | 说明 |
|-----|----------|------|
| 剪切 | `trim_video` | 去除不需要的片段 |
| 拼接 | `concatenate_videos` | 合并多个片段 |
| 变速 | `speed_up` / `slow_down` | 调整节奏 |
| 旋转 | `rotate_video` | 修正画面角度 |
| 裁剪 | `crop_video` | 调整构图 |

#### 音频处理

| 操作 | 说明 |
|-----|------|
| 添加BGM | 选择节奏匹配的背景音乐 |
| 音量调整 | 人声与BGM平衡（人声为主BGM降低） |
| 降噪 | 去除背景噪音 |
| 配音 | 添加解说/旁白 |

#### 字幕制作

```
字幕要求：
- 字体大小：屏幕高度的1/15-1/20
- 位置：画面底部，留出安全边距
- 样式：白字黑边或带背景色
- 时间轴：与语音同步
```

---

### 5. 特效与调色

#### 常用特效

| 特效类型 | 使用场景 |
|---------|---------|
| 文字动画 | 标题/强调 |
| 贴纸/GIF | 趣味元素 |
| 马赛克 | 遮盖敏感信息 |
| 画中画 | 对比/讲解 |
| 绿幕抠像 | 更换背景 |

#### 调色方案

| 风格 | 参数特点 |
|-----|---------|
| 清新自然 | 高亮度、低对比、偏冷色调 |
| 电影感 | 低亮度、高对比、暖色调、暗角 |
| 科技感 | 高饱和、蓝青色调、锐化 |
| 复古 | 降低饱和、添加噪点、色偏 |

---

### 6. 导出与交付

#### 输出格式建议

| 用途 | 推荐格式 | 分辨率 | 码率 |
|-----|---------|-------|------|
| 抖音/快手 | MP4(H.264) | 1080x1920 | 8-15 Mbps |
| B站/YouTube | MP4(H.264/H.265) | 1920x1080 | 10-20 Mbps |
| 微信视频号 | MP4(H.264) | 1080x1920 | 5-10 Mbps |
| 内部存档 | MP4/MOV | 原始分辨率 | 20+ Mbps |

#### 交付检查清单

| 检查项 | 标准 |
|-------|------|
| 时长 | 符合目标时长±5% |
| 画面 | 无花屏/黑屏/卡顿 |
| 音频 | 声音清晰、音量一致 |
| 字幕 | 无错别字、时间轴准确 |
| 转场 | 流畅自然 |
| 文件 | 格式正确、命名规范 |

## 典型用法示例

### 示例 1：产品宣传视频

```
用户：帮我做一个30秒的产品宣传视频

1. 需求确认：
   - 类型：电商宣传
   - 时长：30秒
   - 风格：科技感
   - 内容：产品3个卖点

2. 素材准备：
   - 产品视频素材（拍摄或用户提供）
   - 背景音乐（节奏轻快）
   - Logo文件

3. 剪辑流程：
   - 0-3秒：开场动画+产品名称
   - 4-10秒：卖点1展示
   - 11-17秒：卖点2展示
   - 18-24秒：卖点3展示
   - 25-30秒：结尾CTA+Logo

4. 添加效果：
   - 转场：快速切换
   - 调色：科技感蓝青色调
   - 字幕：卖点文字动画

5. 导出交付
```

### 示例 2：会议/活动回顾视频

```
用户：把我们公司年会的视频剪辑成3分钟的回顾片

1. 需求确认：
   - 类型：活动回顾
   - 时长：3分钟
   - 风格：喜庆、团队氛围
   - 内容：领导致辞+节目表演+颁奖+合影

2. 素材整理：
   - 识别各节目/环节的开始和结束时间点
   - 标记精彩瞬间
   - 选择背景音乐

3. 结构规划：
   - 开场：签到/花絮（15秒）
   - 第一章：领导致辞（40秒）
   - 第二章：精彩节目（80秒）
   - 第三章：颁奖典礼（50秒）
   - 第四章：合影留念（15秒）
   - 结尾：展望来年（20秒）

4. 制作要点：
   - 关键发言保留完整
   - 节目选取高潮片段
   - 添加字幕标注节目名称
   - 统一调色风格
```

### 示例 3：教学视频剪辑

```
用户：帮我剪辑一段Python教程视频

1. 需求确认：
   - 类型：教学视频
   - 时长：单集10-15分钟
   - 风格：清晰、专业
   - 平台：B站/YouTube

2. 素材处理：
   - 去除口头禅和停顿
   - 加速重复操作片段
   - 保留关键代码讲解

3. 后期制作：
   - 添加章节标记
   - 关键代码高亮
   - 添加进度条/时间提示
   - 开头结尾统一模板

4. 字幕制作：
   - 自动生成+人工校对
   - 关键词汇标注
```

### 示例 4：视频素材拼接

```
用户：有5段视频素材，帮我拼接成一个完整的视频

1. 素材检查：
   - 分辨率是否一致
   - 方向是否统一（横屏/竖屏）
   - 音频是否正常

2. 方案制定：
   - 统一格式和分辨率
   - 设计转场位置
   - 选择背景音乐

3. 执行拼接：
   - 按逻辑顺序排列
   - 适当剪切冗余内容
   - 添加转场效果

4. 导出成品
```
