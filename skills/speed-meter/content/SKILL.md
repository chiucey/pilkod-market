# 实时时速表技能

## 技能概述

创建一个手机端全屏实时时速表应用，提供10种样式选择、自定义大小和背景颜色，实时显示GPS速度。

## 执行流程

### 1. 需求确认

快速确认用户需求（可在执行中自然完成）：
- 确认需要的速度单位（km/h 或 mph）
- 确认是否需要震动/声音提醒功能

### 2. 创建项目结构

```
speed-meter/
├── index.html          # 主应用页面
├── styles.css          # 样式表
├── app.js              # 核心逻辑
└── assets/
    └── icon.svg        # 应用图标
```

### 3. 功能实现

#### 3.1 速度获取
- 使用 Geolocation API 获取 GPS 数据
- 计算实时速度（m/s 转 km/h 或 mph）
- 处理定位失败和无权访问情况

#### 3.2 10种样式设计

| 序号 | 样式名称 | 特点描述 |
|------|----------|----------|
| 1 | 经典指针 | 传统汽车仪表盘指针样式 |
| 2 | 数字霓虹 | 发光数字显示，赛博朋克风格 |
| 3 | 简约数字 | 极简主义，纯数字显示 |
| 4 | 机械仪表 | 金属质感圆形表盘 |
| 5 | 渐变数字 | 颜色随速度变化的数字 |
| 6 | 科技全息 | 全息投影效果显示 |
| 7 | 复古指针 | 老式汽车仪表风格 |
| 8 | 未来科幻 | 科幻飞船风格 |
| 9 | 运动风格 | 赛车仪表风格 |
| 10 | 水墨风格 | 中国风水墨晕染效果 |

#### 3.3 设置选项
- **速度单位**: km/h 或 mph
- **字体大小**: 小/中/大/特大
- **背景颜色**: 预设色板 + 自定义颜色选择器
- **全屏锁定**: 防止误触退出

#### 3.4 权限处理
- 定位权限请求与错误处理
- 网络连接状态提示
- 降级方案（无GPS时显示说明）

### 4. 验证检查点

- [ ] 10种样式可正常切换
- [ ] 字体大小调整生效
- [ ] 背景颜色自定义功能正常
- [ ] GPS定位获取速度数据
- [ ] 全屏显示正常
- [ ] 响应式适配手机屏幕
- [ ] 权限请求逻辑完整

### 5. 部署

使用 `deploy` 工具部署到服务器，提供访问链接。

## 技术规范

### 前端技术
- HTML5 + CSS3 + Vanilla JavaScript
- Geolocation API
- Fullscreen API
- LocalStorage 存储用户偏好

### 兼容性
- iOS Safari 14+
- Android Chrome 90+
- 需 HTTPS 环境获取GPS数据

### 性能要求
- 首屏加载 < 2秒
- 速度更新频率 1Hz
- 60fps 动画渲染

## 交付物

1. 完整可运行的时速表应用
2. 10种可选样式
3. 可调节的显示参数
4. 部署后的访问链接
