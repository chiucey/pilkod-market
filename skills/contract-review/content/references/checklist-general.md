# 通用合同条款审查清单

> 这份清单是合同审查 skill 的工作底稿：审查时按这个顺序逐条对位。每条给"审查要点 + 关键风险信号"，审查者按当前立场判断风险等级。
>
> 不是法律意见清单 —— 真碰到强制性规定 / 行业强监管领域，标"⚠️ 建议专业律师确认"。

## 1. 合同主体

- **审查要点**：双方主体名称是否与营业执照 / 主体资格证明一致；自然人需身份证号 / 法人需统一社会信用代码；签约代表人是否有授权。
- **关键风险信号**：
  - 主体名称错字、简称、曾用名
  - 签约代表无授权 / 无委托书
  - 主体资格存疑（已注销、吊销、列入异常经营）
  - 自然人签约但缺少身份证号

## 2. 标的物 / 服务内容

- **审查要点**：标的描述是否清晰、可量化、可验收。货物类要规格型号 / 数量 / 质量标准；服务类要服务范围 / 服务标准 / 交付物清单。
- **关键风险信号**：
  - 描述模糊（"等"、"相关"、"若干"）
  - 数量 / 规格空白待填
  - 缺乏质量标准或引用了不存在的标准
  - 服务范围用"协助"、"支持"等弱动词，无明确交付物

## 3. 价款 / 付款方式

- **审查要点**：金额大小写一致；币种明确；付款节点清晰；发票与付款义务关系。
- **关键风险信号**：
  - 大小写不一致
  - 付款节点缺失（只写"合同生效后付款"但无明确日期 / 里程碑）
  - 付款前置条件过严或过松
  - 未约定逾期付款违约金
  - 税费承担方不明确
  - 付款方式（电汇 / 票据 / 现金 / 数字货币）模糊

## 4. 履约期限

- **审查要点**：起止时间明确；交付 / 服务里程碑具体；宽限期 / 异议期合理。
- **关键风险信号**：
  - 起止时间用"自合同签订之日起"但无签订日
  - 期限空白或仅写"约 X 个月"
  - 缺乏分阶段时间点
  - 缺乏己方异议 / 通知期限

## 5. 验收 / 交付

- **审查要点**：验收标准、验收方式、验收期限、异议处理、不合格后果。
- **关键风险信号**：
  - 验收标准缺失或无法量化
  - 验收期限空白（无期限 = 无限期拖延风险）
  - 异议期过短（< 7 天）
  - 未约定不合格处理（退货 / 换货 / 折价 / 解除）

## 6. 质量保证 / 售后

- **审查要点**：质保期、质保范围、保修响应时间、售后责任。
- **关键风险信号**：
  - 货物类合同无质保条款
  - 质保期过短或过长（行业惯例不一致）
  - 售后响应时间未量化

## 7. 知识产权

- **审查要点**：背景 IP 归属；履行过程中产生的 IP 归属；许可范围；侵权责任承担。
- **关键风险信号**：
  - 研发 / 设计 / 创作类合同无 IP 归属条款
  - 一方"全部"转让 IP，未保留任何使用 / 改进权
  - 缺乏侵权责任承担（谁负责抗辩、谁负责赔偿）
  - 第三方 IP 许可关系未约定
  - 源代码 / 数据所有权未约定

## 8. 保密

- **审查要点**：保密信息范围、保密期限、保密义务人、例外情形、违约责任。
- **关键风险信号**：
  - 保密范围过窄或过宽
  - 保密期缺失或约定永久保密（部分法律不支持永久）
  - 缺乏已有信息 / 公开信息 / 独立开发等例外
  - 保密义务主体不包括员工 / 关联公司 / 合作方
  - 无保密违约责任或责任过轻

## 9. 违约责任

- **审查要点**：违约情形、违约金计算、赔偿范围（直接损失 / 间接损失 / 预期利益）、责任上限、免责事由。
- **关键风险信号**：
  - 违约情形列举不全
  - 违约金过高（> 实际损失 30% 显著比例）或过低
  - 责任上限缺失或不对等（一方有上限一方无）
  - 间接损失约定排除（但要看立场：己方排除对方间接损失是优势，己方放弃主张己方间接损失是劣势）
  - 逾期违约金与法定利率差异显著

## 10. 不可抗力

- **审查要点**：不可抗力定义 / 列举；通知期限；证明文件；法律后果（免责 + 解除权 + 期限顺延）。
- **关键风险信号**：
  - 不可抗力定义过窄（如仅限"自然灾害"）
  - 通知期限过短（< 3 天）或缺失
  - 未约定后果（是免责、还是可解除）
  - 缺乏疫情 / 政策变化 / 网络安全事件等现代事由

## 11. 解除 / 终止

- **审查要点**：解除条件、解除程序、解除后果（已履行部分处理、款项结算、资料返还）、单方解除权。
- **关键风险信号**：
  - 解除条件严苛失衡（一方有单方权、另一方无）
  - 解除程序缺失（通知形式、通知期）
  - 解除后责任划分不清
  - 缺乏"期满不续约自动终止"条款（长期合同尤其重要）

## 12. 转让 / 分包 / 委托

- **审查要点**：是否需要对方同意；同意的合理拒绝情形；关联方转让是否豁免。
- **关键风险信号**：
  - 完全禁止转让（过严，可能影响企业重组 / 上市）
  - 完全允许对方自由分包（导致质量失控）
  - 关联方转让需同意（正常应豁免）

## 13. 通知送达

- **审查要点**：送达地址、送达方式（书面 / 邮件 / 短信 / 微信）、送达生效时点、地址变更通知义务。
- **关键风险信号**：
  - 送达地址空白（争议时无法送达）
  - 仅约定"书面通知"但未明确具体形式
  - 缺乏地址变更通知义务（对方改地址不通知 = 实际上规避了通知义务）
  - 送达生效时点不明（发出 vs 收到 vs 视为收到）

## 14. 争议解决

- **审查要点**：管辖机构（法院 / 仲裁）、具体管辖地、适用法律、仲裁机构选择、仲裁语言、律师费承担。
- **关键风险信号**：
  - 管辖地对自己明显不利（远、成本高）
  - 同时约定仲裁 + 法院（效力冲突）
  - 仲裁机构不明确（"某地仲裁委员会"指代不清）
  - 未约定适用法律（涉外合同重大风险）
  - 律师费 / 差旅费承担未约定

## 15. 适用法律

- **审查要点**：准据法选择；强制性规定 vs 任意性规定的差异；涉外合同的特殊处理。
- **关键风险信号**：
  - 涉外合同未约定适用法律
  - 选择对己方不熟悉的法域（执行难、解释难）
  - 选择外国法但未约定冲突规范

## 16. 合同生效

- **审查要点**：生效条件（签字盖章 / 审批 / 登记）；生效日期；份数；附件清单。
- **关键风险信号**：
  - 需登记 / 备案的合同未提及（不动产 / 股权 / 商标等）
  - 缺乏附件清单（容易遗漏重要文件）
  - 份数不足（双方各执份数 = 总份数不清）
  - 签字人未签字、盖章未盖

## 17. 其他常见条款（视合同类型）

- **不可竞争**：服务期内的同业竞争限制（注意劳动法上限）
- **排他合作**：是否双向、范围、期限
- **保险责任**：大型项目 / 货物运输 / 工程类合同必备
- **安全 / 环保 / 职业健康**：EHS 条款
- **反贿赂 / 反腐败**：跨境合作 + 大型采购必备
- **数据保护 / 个人信息**：涉及个人信息处理必备
- **关联方交易**：上市公司必备
- **陈述与保证**：并购 / 投融资必备
- **兜底条款**：变更、补充、权利放弃、可分割性

## 18. 缺失条款提示模板

审查完成后如果发现 checklist 中应当有但合同中缺失的，按以下模板提示：

```
⚠️ 缺失条款：[条款名]
风险：[缺失会导致什么问题]
建议：补充 [标准条款框架 / 关键点]
```

## 19. 特殊合同类型关注点（按需展开）

- **服务类**：服务水平协议 SLA、变更管理、过渡期支持
- **租赁类**：维修责任、装修约定、退还条件、押金返还
- **劳动类**：工作时间、薪酬结构、保密与竞业限制（注意上限）、解除补偿（注意法定下限）
- **股权类**：估值、对赌、回购、优先权、估值调整、反稀释
- **技术开发类**：需求变更、源代码交付、缺陷修复期、知识产权（重点）
- **保密协议 NDA**：单向 vs 双向、保密期、例外、衍生信息
