# 条款释义参考

> 合同审查时常用术语的简明释义 + 关键法律 / 商业含义。仅供审查者参考，不构成法律意见。
>
> 涉及具体法律条款的强制规定 / 数额 / 程序，标 ⚠️ 的必须以现行法律法规为准，本表可能滞后。

## 不可抗力 (Force Majeure)

- **概念**：不能预见、不能避免、不能克服的客观情况。
- **典型列举**：自然灾害（地震、台风、洪水）、战争、暴乱、政府行为、政策变化、疫情（视情形）。
- **法律后果**：部分或全部免除责任 + 合同可解除（视严重程度）。
- **审查要点**：
  - 定义不要过窄（仅"自然灾害"会让政府行为、政策变化漏掉）
  - 通知期限 + 证明文件（公证 / 政府公告 / 第三方证明）
  - 持续超过一定期限（如 30 / 60 / 90 天）应允许解除
- **立场差异**：
  - 甲方：列举要全、通知期短、持续期限要短（方便己方免责）
  - 乙方：列举要宽、通知期长、持续期限要长（避免被轻易解除）

## 违约金 (Liquidated Damages) vs 赔偿金 (Compensation)

- **违约金**：合同预先约定，违约时按约定金额支付。
- **赔偿金**：实际损失 + 合理费用，按实际计算。
- **关键差异**：
  - 违约金过高可请求法院 / 仲裁调减（实务中 > 实际损失 30% 显著比例易被调）
  - 违约金过低不能请求调增（除非显失公平）
  - 多数合同会约定"违约金 + 赔偿金"叠加，但需明确二者关系
- **审查要点**：
  - 计算基数（合同总额？本期款项？损失额？）
  - 计算方式（固定金额 / 比例 / 公式）
  - 上限（有 / 无 / 比例）
  - 与法定利息的关系（逾期付款时常同时主张）

## 责任上限 (Liability Cap)

- **概念**：违约方对守约方的总赔偿上限。
- **常见形式**：
  - 不超过合同总金额的 X 倍
  - 不超过已支付金额
  - 不超过最近 X 个月的服务费
- **关键风险**：
  - 多数合同会设例外（故意 / 重大过失 / 人身损害 / 知识产权侵权 / 保密违约等不适用上限）
  - 例外列举不全 = 实质缩小了己方保护
- **审查要点**：
  - 上限数额是否合理
  - 例外条款的完整性和倾向性

## 知识产权归属 (IP Ownership)

- **三种主要模式**：
  - **全部归甲方**：甲方获得全部 IP，包括乙方背景 IP 的衍生部分
  - **共有**：双方共有，各方有权独立使用（注意：可能稀释商业价值）
  - **各自所有**：乙方保留背景 IP，甲方获得履行过程产生的 IP
- **背景 IP (Background IP)**：合同签订前一方已拥有的 IP。
- **前景 IP (Foreground IP)**：合同履行过程中产生的 IP。
- **衍生 IP**：基于背景 IP 改进产生的 IP。
- **审查要点**：
  - 转让 vs 许可（独占 / 非独占 / 排他）
  - 地域范围
  - 改进成果归属
  - 源代码 / 数据所有权
  - 第三方 IP 依赖

## 保密义务 (Confidentiality)

- **保密信息范围**：
  - 列举式（具体列明）+ 兜底（"其他保密信息"）
  - 标记要求（书面标记"保密"才受保护 — 增加对方义务但加重己方提示责任）
- **保密期**：
  - 合同期内 + 合同结束后 X 年（通常 2-5 年）
  - 商业秘密适用至公开为止（无期限）
- **典型例外**：
  - 已知信息（披露前已合法持有）
  - 公开信息（非因接收方过错公开）
  - 独立开发
  - 法律 / 政府强制披露
- **审查要点**：
  - 单向 vs 双向（一般应双向，避免单方保护失衡）
  - 保密义务主体（应包括关联方、员工、顾问、合作方）
  - 违约责任（部分与违约金竞合）

## 争议解决：法院 vs 仲裁

- **法院**：
  - 优势：可上诉（二审 + 再审）、程序严格
  - 劣势：周期长（普通程序 6 个月以上）、公开审理、管辖受限
- **仲裁**：
  - 优势：周期短、一裁终局、不公开、专业（行业仲裁规则）
  - 劣势：不可上诉（除非程序违法）、费用高、无法缺席执行
- **管辖地选择**：
  - 法院：原告就被告 + 合同签订地 / 履行地 / 标的物所在地
  - 仲裁：仲裁机构所在地
- **审查要点**：
  - 同时约定仲裁 + 法院（仲裁条款可能无效）
  - 涉外合同选择国际仲裁（ICC / SIAC / HKIAC）
  - 律师费 / 差旅费承担

## 转让 (Assignment) vs 委托 (Delegation)

- **转让**：合同权利 / 义务整体转移给第三方（合同主体变更）
- **委托**：合同义务由第三方代为履行（合同主体不变）
- **分包**：履行过程中部分工作由第三方完成（不影响合同主体）
- **审查要点**：
  - 完全禁止 = 影响企业重组、上市、并购，需豁免关联方
  - 自由转让 = 履约风险升高
  - 一般惯例：经对方书面同意 + 关联方豁免

## 通知送达 (Notice)

- **送达方式**：书面（线下快递 + 签收）、电子邮件、短信、传真、即时通讯
- **送达生效时点**：
  - **发出主义**：发出即生效（对己方有利，对方承担收不到风险）
  - **到达主义**：对方实际收到生效（对方有利）
  - **视为到达**：寄出后 X 天视为到达（折中）
- **审查要点**：
  - 送达地址明确（含邮政编码）
  - 多渠道送达（管道 / / 邮件 / 短信）
  - 地址变更通知义务（对方改地址未通知 = 实际规避了送达义务）

## 合同生效条件

- **生效时点**：
  - **签字盖章时**：合同载明签字盖章生效
  - **条件成就时**：如"自 X 审批通过之日起生效"
  - **登记 / 备案时**：不动产 / 股权 / 商标转让合同（要式合同）
- **审查要点**：
  - 是否需要审批 / 备案（不履行 = 合同不生效 / 不对抗第三人）
  - 份数（双方各执 + 备案份数）
  - 附件清单（漏列 = 漏掉重要文件）

## 兜底条款 (Boilerplate Clauses)

- **完整协议 (Entire Agreement)**：合同 + 列明附件构成完整协议，排除此前谈判纪要、邮件
- **修改 (Amendment)**：必须书面 + 双方签字
- **权利放弃 (Waiver)**：单方放弃权利不影响后续主张
- **可分割性 (Severability)**：某条款无效不影响其他条款
- **转让 (Assignment)**：见上
- **副本 (Counterparts)**：可分多个副本签署，每份等同正本
- **审查要点**：兜底条款一般不必修改，但要注意"完整协议"是否排除了一些原本对己方有利的谈判承诺

## 反稀释 / 优先权（股权类合同专用）

- **反稀释**：后续融资估值下调时，已投资方获得额外股权
- **优先购买权 (ROFR)**：老股东优先购买新发行股份
- **共同出售权 (Co-sale)**：大股东出售时老股东可按比例搭售
- **回购权 (Redemption)**：触发条件满足时投资人可要求公司回购
- **对赌 (VAM/Adjustment)**：业绩 / 上市未达成时估值调整或现金 / 股权补偿

## 关键合规术语

- **陈述与保证 (Representations & Warranties)**：一方对特定事实的陈述，不实 = 违约 + 赔偿
- **补偿 (Indemnification)**：一方对另一方因特定事由产生的损失承担补偿
- **持续承诺 (Continuing Covenants)**：合同期内持续履行的义务（如月度报告、合规审计）
- **条件先决 (Conditions Precedent)**：合同义务生效的前提条件
