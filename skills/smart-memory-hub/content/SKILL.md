# Smart Memory Hub - 智能记忆管家

## 核心目标

为 AI 提供**持久化记忆能力**，同时**严格防止记忆膨胀**导致上下文溢出、存储堵塞或响应超时。

## 两大核心能力

### 1. 可靠的长期记忆

- **自动记忆**：用户重要信息（名称、偏好、未完成任务等）自动捕获
- **手动记忆**：`/remember <内容>` 强制保存
- **回忆查询**：`/recall <关键词>` 检索相关记忆
- **跨会话持久化**：启动时自动加载相关记忆

### 2. 防止记忆膨胀死机

| 约束项 | 限制值 |
|--------|--------|
| 记忆库总量 | ≤ 200 条 |
| 单条记忆长度 | ≤ 200 字符 |
| 每次注入记忆 | ≤ 5 条 |
| 淘汰阈值 | ≥ 180 条时触发 |
| 强制合并阈值 | = 200 条时 |
| 降级响应时间 | > 1 秒则跳过 |

## 记忆存储格式

**文件路径**：`~/.openclaw/smart_memory/memory.json`

```json
{
  "max_entries": 200,
  "version": "1.0.0",
  "last_cleanup": "2025-01-01T00:00:00Z",
  "degraded_mode": false,
  "entries": [
    {
      "id": "mem_001",
      "content": "用户叫张三，喜欢简洁的回答",
      "keywords": ["姓名", "偏好", "简洁"],
      "last_used": "2025-07-14T10:00:00Z",
      "importance": 85,
      "created_at": "2025-07-01T08:00:00Z"
    }
  ],
  "compressed_cache": "用户早期讨论内容摘要..."
}
```

## 执行流程

### 启动时

```
1. 读取 memory.json
2. 加载记忆索引（不直接全量放入上下文）
3. 检查 degraded_mode 状态
4. 清理过期记忆（如有）
```

### 用户输入后

```
1. 提取关键词（或简单向量匹配）
2. 检索最多 5 条相关记忆
3. 验证检索时间 < 1 秒
4. 将记忆以 [记忆] 内容 格式注入上下文
5. 更新 last_used 时间戳
```

### 自动维护（每 10 轮对话后）

```
1. 检查条目数是否 ≥ 180
2. 若是，触发淘汰逻辑：
   - 删除 last_used 最早的 20 条
   - 但 importance > 90 的保留
3. 若条目数 = 200：
   - 强制合并最旧 10 条为 1 条摘要
```

## 淘汰策略

| 场景 | 策略 |
|------|------|
| 条目 ≥ 180 | 删除 last_used 最早的 20 条（importance > 90 除外） |
| 条目 = 200 | 强制合并最旧 10 条为压缩摘要 |
| 单条 > 200 字符 | 截断并标记已压缩 |

## 降级机制

**触发条件**：
- I/O 错误
- 超时 > 1 秒
- 文件大小 > 5MB

**降级行为**：
```
1. 设置 degraded_mode = true
2. 本次会话不再读写记忆
3. 返回提示："[记忆系统暂不可用，请稍后 /clear_memory 重试]"
```

## 手动指令

| 指令 | 功能 | 示例 |
|------|------|------|
| `/remember <内容>` | 强制保存记忆 | `/remember 用户喜欢深色主题` |
| `/recall <关键词>` | 检索匹配记忆 | `/recall 项目名称` |
| `/memory_stats` | 显示统计信息 | `/memory_stats` |
| `/clear_memory` | 清空所有记忆 | `/clear_memory` (二次确认) |
| `/compact_memory` | 手动压缩记忆 | `/compact_memory` |

## 注入格式

当使用记忆回答时：

```
[记忆] 用户叫张三 (importance: 85)
[记忆] 用户项目代号是"天鹰" (importance: 90)
```

**可选前缀**：`根据记忆中你曾说过 …，因此我 …`

**未找到时**：正常回答，不刻意提示。

## 关键参数

| 参数 | 值 | 说明 |
|------|-----|------|
| `MAX_ENTRIES` | 200 | 最大条目数 |
| `MAX_CHARS` | 200 | 单条最大字符数 |
| `INJECT_LIMIT` | 5 | 每次最多注入条数 |
| `CLEANUP_THRESHOLD` | 180 | 自动清理阈值 |
| `TIMEOUT_MS` | 1000 | 检索超时（毫秒） |
| `CLEANUP_INTERVAL` | 10 | 清理检查间隔（轮次） |

## 重要性评分规则

| 来源 | 基础分数 |
|------|----------|
| 用户明确说"记住" | +30 |
| 信息出现 ≥2 次 | +20 |
| 包含关键信息（姓名、项目） | +25 |
| 待办事项 | +20 |
| 手动 /remember | +50 |

## 初始化

- 检测 `memory.json` 是否存在
- 若不存在，自动创建空库：
```json
{
  "max_entries": 200,
  "version": "1.0.0",
  "last_cleanup": "<current_time>",
  "degraded_mode": false,
  "entries": [],
  "compressed_cache": ""
}
```

## 存储路径

```
~/.openclaw/smart_memory/
├── memory.json        # 主存储文件
├── memory_backup.json # 备份文件（压缩前）
└── memory.log        # 操作日志
```

## 性能约束

- 检索延迟：< 200ms（正常模式）
- 降级阈值：> 1000ms
- 文件大小：建议 < 5MB
- 启动时间：< 500ms
