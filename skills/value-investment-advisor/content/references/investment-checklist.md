# 价值投资决策检查清单

## 格雷厄姆投资检查清单

### 第一部分：投资 vs 投机的区分

**格雷厄姆定义**：
> "投资是基于详尽的分析，本金的安全和满意回报有保证的操作。不符合这一标准的操作就是投机。"

**检查问题**：
- [ ] 投资决策是否基于详尽的分析？
- [ ] 是否有本金安全的保障？
- [ ] 是否有满意的预期回报？
- [ ] 是否能够承受本金亏损的可能？

---

### 第二部分：防御型投资者选股标准

格雷厄姆为防御型投资者提出的选股标准：

#### 1. 企业规模
- [ ] 工业公司年销售额 ≥ 1亿美元（现代标准应更高）
- [ ] 公用事业公司总资产 ≥ 5000万美元
- [ ] 避免微型股（规模过小难以深入分析）

#### 2. 财务稳健
- [ ] 流动比率（流动资产/流动负债）≥ 2
- [ ] 长期负债 ≤ 净流动资产（营运资本）
- [ ] 负债比例合理（行业平均负债率参考）

#### 3. 盈利稳定
- [ ] 过去10年每年均有盈利
- [ ] 过去10年没有削减股息
- [ ] 盈利不是依赖非经常性损益

#### 4. 股息记录
- [ ] 连续20年支付股息（格雷厄姆严格标准）
- [ ] 股息支付稳定或增长
- [ ] 股息率具有吸引力

#### 5. 盈利增长
- [ ] 过去10年每股收益增长超过33%
- [ ] 或使用公式：PE ≤ 0.5 × ROE × 100

#### 6. 合理价格
- [ ] PE（市盈率）≤ 15倍
- [ ] 或 PB（市净率）≤ 1.5倍
- [ ] 或股息率 ≥ 债券利率的2/3
- [ ] 股价大幅低于内在价值

---

### 第三部分：格雷厄姆估值检查

#### 格雷厄姆估值公式
```
内在价值 = EPS × (8.5 + 2 × 预期年增长率)
```
- [ ] EPS是否使用TTM或预期值？
- [ ] 预期增长率是否合理（7-10年）？
- [ ] 现代应用：基数可调整为7-8

#### 简化安全边际
- [ ] 安全价格 = 0.9 × 每股净资产（PB = 0.9）
- [ ] 理想买价 = EPS × 7（PE = 7）

#### Net-Net法（深度价值）
```
净-Net价值 = 流动资产 - 全部负债 - 优先股
买入标准：股价 < 净-Net价值的2/3（0.67）
```
- [ ] 仅适用于小型公司
- [ ] 需要分散投资（10-30只）
- [ ] 寻找催化剂：清算、管理变革

---

### 第四部分：格雷厄姆投资戒律

1. **不亏损原则**
   - [ ] 本金安全永远是第一优先
   - [ ] 不投资无法承受损失的资金

2. **安全边际原则**
   - [ ] 股价显著低于内在价值
   - [ ] 为错误和意外留出缓冲空间

3. **分散投资原则**
   - [ ] 持有10-30只以上股票
   - [ ] 避免集中单一标的

4. **长期持有原则**
   - [ ] 至少3-5年的投资周期
   - [ ] 不为短期波动改变决策

5. **逆向思维原则**
   - [ ] 大众恐惧时买入
   - [ ] 贪婪时卖出

6. **独立思考原则**
   - [ ] 不依赖他人建议
   - [ ] 独立进行深入分析

7. **程序化原则**
   - [ ] 制定明确的投资规则
   - [ ] 严格执行，不感情用事

8. **能力圈原则**
   - [ ] 只投资了解的领域
   - [ ] 坦诚承认无知

## 巴菲特投资检查清单

### 第五部分：巴菲特八大投资标准

巴菲特1992年精简版选股标准：

#### 1. 能够了解
- [ ] 我能够理解这家公司的业务吗？
- [ ] 商业模式是否简单易懂？
- [ ] 5-10年后这家公司的样子能预见吗？

#### 2. 良好前景
- [ ] 公司是否有长期稳定的需求？
- [ ] 行业是否具有长期成长性？
- [ ] 竞争优势是否可持续？

#### 3. 诚实正直管理层
- [ ] 管理层是否诚实、有能力？
- [ ] 是否始终以股东利益为先？
- [ ] 是否有糟糕的决策历史？

#### 4. 有吸引力的价格
- [ ] 当前价格是否低于内在价值？
- [ ] 是否有足够的安全边际？
- [ ] 价格是否提供了"用大桶接"的机会？

---

### 第六部分：巴菲特1982年详细标准

#### 1. 规模要求
- [ ] 至少有500万美元的税后利润
- [ ] 避免微型公司

#### 2. 持续盈利
- [ ] 显示出持续稳定的盈利能力
- [ ] 不投资"由亏转盈"的反转型公司
- [ ] 不依赖一次性收益

#### 3. 净资产收益率
- [ ] 少量或零负债下获得良好ROE
- [ ] ROE > 15%是优质信号
- [ ] 避免高负债低ROE的公司

#### 4. 管理层
- [ ] 管理层理性、忠诚
- [ ] 以股东利益为先
- [ ] 有资本配置能力

#### 5. 业务简单
- [ ] 业务简单、易了解
- [ ] 即使"傻瓜"也能经营好
- [ ] 避免复杂技术型公司

#### 6. 出售价格
- [ ] 清楚知道买入价格
- [ ] 不在价格不明朗时谈判
- [ ] 耐心等待合理价格

---

### 第七部分：巴菲特企业评估四问

#### 1. 企业质量（Business）
- [ ] 业务是否简单且可理解？
- [ ] 是否有持续的长期前景？
- [ ] 是否具有经济护城河？
- [ ] 管理层是否德才兼备？

#### 2. 管理层（Management）
- [ ] 管理层是否理性？
- [ ] 是否对股东坦诚？
- [ ] 能否抵制"机构惯性"？
- [ ] 是否合理配置资本？

#### 3. 财务（Financial）
- [ ] ROE是否持续 > 15%？
- [ ] 负债水平是否合理？
- [ ] 现金流是否健康？
- [ ] 利润率是否稳定？

#### 4. 价值（Value）
- [ ] 价格是否具有安全边际？
- [ ] 是否在能力圈内？
- [ ] 是否能用合理价格买到？

---

### 第八部分：巴菲特年度检查清单

每年检查持有股票的关键指标：

- [ ] **初始权益报酬率**：是否保持稳定？
- [ ] **经营毛利**：是否保持或改善？
- [ ] **负债水平**：是否可控？
- [ ] **资本支出**：是否合理？
- [ ] **现金流量**：是否充裕？

## 芒格投资检查清单

### 第九部分：芒格决策检查清单

来自《穷查理宝典》的系统检查清单：

#### 1. 风险评估
- [ ] 测算合适的安全边际
- [ ] 避免和道德品质有问题的人交易
- [ ] 坚持为预定的风险要求合适的补偿
- [ ] 永远警惕通货膨胀和利率风险
- [ ] 避免犯下大错，避免资本金持续亏损

#### 2. 独立思考
- [ ] 客观和理性的态度需要独立思考
- [ ] 你是对是错，不取决于别人同意还是反对你
- [ ] 随大流只能让你往平均值靠近

#### 3. 准备
- [ ] 通过广泛的阅读把自己培养成终生自学者
- [ ] 培养好奇心，每天努力使自己聪明一点点
- [ ] 熟练掌握各大学科的思维模型

#### 4. 谦虚
- [ ] 承认自己的无知是智慧的开端
- [ ] 只在自己明确界定的能力圈内行事
- [ ] 辨认和核查否定性的证据
- [ ] 别愚弄自己

#### 5. 严格分析
- [ ] 区分价值和价格、过程和行动
- [ ] 记住浅显的，好过掌握深奥的
- [ ] 成为商业分析家，而非市场分析师
- [ ] 考虑总体的风险和效益
- [ ] 朝前想、往后看——反过来想

#### 6. 配置资本
- [ ] 记住最好的用途由次好的用途衡量出来
- [ ] 好主意特别少——狠狠下赌注
- [ ] 别"爱上"投资项目

#### 7. 耐心
- [ ] 克制人类天生爱行动的偏好
- [ ] 复利是世界第八大奇迹
- [ ] 不到必要的时候，别去打断它

#### 8. 决断
- [ ] 当合适的机会出现时，狠狠下注
- [ ] 不要平庸地分散投资
- [ ] 机会只给有准备的头脑

---

### 第十部分：芒格投资前问题

#### 基础问题
- [ ] 目前的价格和成交量是多少？
- [ ] 交易行情如何？
- [ ] 经营年报何时披露？
- [ ] 是否存在其他敏感因素？

#### 资本配置
- [ ] 用来买股票的钱，现在或将来有更好的用途吗？
- [ ] 手上有足够的流动资金吗？
- [ ] 这笔资金的机会成本是多少？

---

## 综合决策流程

### 第十一部分：投资决策七步法

#### 第一步：排除阶段
- [ ] 是否在能力圈内？
- [ ] 是否能理解商业模式？
- [ ] 是否有持续的竞争优势？
- [ ] 管理层是否德才兼备？

#### 第二步：财务分析
- [ ] ROE > 15%且稳定
- [ ] 负债率合理（< 50%）
- [ ] 现金流为正且稳定
- [ ] 利润率稳定或改善

#### 第三步：估值评估
- [ ] PE/PB处于历史低位？
- [ ] 股息率有吸引力？
- [ ] 有足够的安全边际？

#### 第四步：定性分析
- [ ] 护城河的来源和持续性？
- [ ] 行业竞争格局？
- [ ] 管理层质量？

#### 第五步：价格与价值比较
- [ ] 当前价格 vs 内在价值
- [ ] 安全边际是否足够（> 20-30%）？
- [ ] 是否值得大举投资？

#### 第六步：仓位决策
- [ ] 单只股票仓位不超过10-20%
- [ ] 总体风险是否可控？
- [ ] 是否有更好的替代机会？

#### 第七步：持有和监控
- [ ] 建立定期检查机制
- [ ] 监控关键指标变化
- [ ] 评估是否需要调整

---

### 第十二部分：卖出决策检查

**格雷厄姆/巴菲特卖出原则**：

- [ ] 股价是否已经大幅高于内在价值？
- [ ] 是否有更好的投资机会（机会成本）？
- [ ] 基本面是否发生根本性恶化？
- [ ] 是否发现了更好的公司？
- [ ] 是否需要现金进行再平衡？

**不卖出的理由**：
- [ ] 仅仅因为股价短期下跌？
- [ ] 仅仅因为其他人恐惧？
- [ ] 仅仅因为需要"落袋为安"？

---

### 第十三部分：常见投资陷阱检查

#### 格雷厄姆警告的陷阱
- [ ] 不投资不了解的领域
- [ ] 不被"成长股"故事迷惑
- [ ] 警惕高增长预期背后的风险
- [ ] 避免"热门"股票

#### 巴菲特警告的陷阱
- [ ] 不预测宏观经济走势
- [ ] 不相信任何预测
- [ ] 不理会股市短期涨跌
- [ ] 不被市场情绪左右

#### 芒格警告的陷阱
- [ ] 避免"锤子综合症"（单一思维框架）
- [ ] 避免过度自信
- [ ] 避免嫉妒和攀比
- [ ] 避免"损失厌恶"偏差

---

## 快速检查清单（实用版）

### 投资前必问

1. **我能理解这个业务吗？**（巴菲特第一问）
2. **这个公司有护城河吗？**（竞争优势）
3. **管理层值得信任吗？**（诚信与能力）
4. **价格有安全边际吗？**（估值）
5. **我能承受这笔投资可能的损失吗？**（风险承受）
6. **这笔钱有更好的用途吗？**（机会成本）
7. **我是在独立思考还是随大流？**（独立判断）

### 每日/每周提醒

- 市场先生是仆人，不是主人
- 短期波动是噪音，不是信号
- 复利需要时间，不要频繁交易
- 不知道的东西比知道的重要
- 等待是投资者最好的朋友

---

## 检查清单使用指南

### 使用频率建议

| 检查类型 | 频率 |
|---------|------|
| 快速检查（7问） | 每次投资决策前 |
| 完整检查（13部分） | 重大投资决策前 |
| 持有检查 | 每季度/年度 |
| 卖出检查 | 考虑卖出时 |

### 注意事项

1. **不要求完美**：不需要所有问题都"是"，关键是权衡
2. **安全边际优先**：如果安全边际足够，其他标准可适当放宽
3. **能力圈第一**：如果不懂，再好的机会也要放弃
4. **独立思考**：清单是辅助，不是替代思考
5. **定期更新**：根据市场变化调整检查标准
