# 巴菲特与格雷厄姆投资案例集

## 巴菲特十大经典投资案例

### 案例1：政府雇员保险公司（GEICO）

**投资时间**：1951年首次买入，1976年危机抄底

**投资背景**：
- GEICO由利奥·古德温于1936年创立
- 采用直销模式，无代理商，成本比竞争对手低30-40%
- 专门服务政府雇员群体，风险低

**格雷厄姆的早期投资**：
- 1948年，格雷厄姆-纽曼公司收购GEICO一半股份
- 因SEC规定限制被迫分配给合伙人
- 格雷厄姆担任GEICO董事会主席

**巴菲特的投资决策**：
- 1950年作为格雷厄姆学生拜访GEICO，副总裁戴维森讲解4小时
- 1951年以约29美元/股买入350股（当时市价40美元）
- 1976年GEICO因盲目扩张濒临破产，股价从61美元跌至2美元
- 巴菲特以3.18美元/股抄底买入130万股

**投资成果**：
- 1995年，巴菲特用4500万美元投资赚了23亿美元
- 20年增长50倍，年均收益1.1亿美元
- 1996年GEICO成为伯克希尔全资子公司

**投资启示**：
1. **深入了解企业**——巴菲特花了4小时研究商业模式
2. **危机中寻找机会**——市场恐惧时的大胆买入
3. **关注核心竞争力**——直销模式的低成本优势
4. **识别管理层质量**——杰克·伯恩的扭亏能力

---

### 案例2：可口可乐（Coca-Cola）

**投资时间**：1988-1994年

**投资背景**：
- 1987年"黑色星期一"股市崩盘
- 可口可乐市盈率约15倍
- 巴菲特观察可口可乐长达50年

**投资决策因素**：
- **品牌护城河**：120年的品牌价值，无人能击败
- **商业模式**：卖的是品牌而非饮料
- **管理层**：罗伯托·戈伊苏埃塔的出色领导
- **资本配置**：12年回购25%股份
- **稳定现金流**：一罐只赚半美分但一天销售十亿罐

**投资规模**：
- 1988年：投入5.93亿美元
- 1989年：增持近一倍，总投资10.24亿美元
- 1994年：继续增持，总投资达13亿美元

**投资成果**：
- 1991年市值达37.43亿美元，两年涨2.66倍
- 1997年底市值133亿美元，10年赚10倍
- 22年间年化复合收益率22.3%（标普500同期7.4%）
- 1美元留存收益创造9.51美元市值

**投资启示**：
1. **长期观察，果断出手**——等待50年的机会
2. **品牌是最深的护城河**——无法复制和模仿
3. **合理价格买优秀企业**——不要求极度低估
4. **信任优秀管理层**——与罗伯托的深度交流

### 案例3：华盛顿邮报（Washington Post）

**投资时间**：1973-1975年

**投资背景**：
- 当时美国股市低迷
- 尼克松"水门事件"报道期间
- 报纸行业具有天然垄断性

**投资决策因素**：
- **行业护城河**：日报的天然垄断地位
- **管理层**：凯瑟琳·格雷厄姆的卓越领导
- **财务稳健**：每股收益长期稳定增长
- **资本效率**：低负债，高ROE

**投资规模**：
- 投资约0.11亿美元

**投资成果**：
- 1975-1991年：每股收益增长10倍
- 30年间盈利160倍（从1000万美元到17亿美元）
- 为巴菲特创造了传媒业投资的经典案例

**投资启示**：
1. **行业结构决定竞争格局**——媒体的地方垄断特性
2. **信任优秀管理层**——凯瑟琳·格雷厄姆的能力
3. **关注资本配置能力**——管理层的理性决策
4. **长期陪伴成长**——30年的耐心持有

### 案例5：喜诗糖果（See's Candies）

- 证明了"合理价格买优秀企业"的可行性

1. **品牌黏性**——客户愿意为品牌支付溢价
2. **定价权**——抗通胀的核心能力

### 案例6：美国运通（American Express）

**投资时间**：1960年代沙拉油丑闻后

**投资背景**：
- 1963年运通遭遇沙拉油丑闻
- 股价大幅下跌
- 投资者恐慌抛售

**投资决策过程**：
1. **分析事件影响**：判断这只是短期声誉受损
2. **评估核心业务**：旅行支票和信用卡业务稳健
3. **理解商业模式**：运通本质上经营的是什么
4. **大举买入**：在别人恐惧时贪婪

**投资成果**：
- 巴菲特投入巨大，获得丰厚回报
- 持有至今，成为长期核心持仓
- 证明了"好公司+危机=绝佳机会"

**投资启示**：
1. **区分核心与非核心**——丑闻不影响长期价值
2. **理解商业模式**——运通是"货币"而非"商品"
3. **逆向投资**——危机创造买入机会
4. **大机会来了要下重注**——充分把握危机

### 案例7：中石油（PetroChina）

**投资时间**：2003-2007年

**投资背景**：
- 2000年香港上市
- 2002-2003年油价上涨
- 市盈率仅6倍，国际平均24倍

**投资决策因素**：
- **估值极低**：市盈率6倍，严重低估
- **石油资源**：中国最大石油公司
- **现金流**：高股息率，现金奶牛
- **市场偏见**：对中国的价值评估存在偏见

**投资规模**：
- 最多持有23.48亿股，持股比例13.5%
- 平均成本1.65港元

**投资成果**：
- 2007年以均价13.47港元全部卖出
- 5亿美元投入变成40亿美元
- 教科书式的"价值实现后卖出"

**投资启示**：
1. **估值是硬道理**——极端低估提供安全边际
2. **克服市场偏见**——别人恐惧时发现机会
3. **知道何时卖出**——价值实现后不贪
4. **不懂不买**——巴菲特承认这是少数他"懂"的外国公司

### 案例9：伯克希尔·哈撒韦（Berkshire Hathaway）

**投资时间**：1965年

**投资背景**：
- 新英格兰地区的纺织厂
- 巴菲特早期的"糟糕"投资
- 转变为投资帝国的起点

**投资决策因素**：
- **价格便宜**——典型的格雷厄姆式捡烟蒂
- **净流动资产**——股价低于清算价值
- **管理层改善空间**：可以更换管理层

**投资教训**：
1. **避免"糟糕"行业**——纺织业是夕阳产业
2. **价格便宜不等于好投资**——要关注行业前景
3. **资本配置能力**——将资金重新配置到保险业
4. **从失败中学习**——这次教训塑造了后续投资理念

**投资成果**：
- 虽然纺织业最终关闭
- 但保险业务发展成为伯克希尔的基石
- 证明了"好公司+差行业≠好投资"的反面教训

**投资启示**：
1. **行业选择很重要**——避免夕阳产业
2. **买入价格不是唯一**——成长性和护城河更重要
3. **资本配置是核心**——管理层重新配置资本的能力
4. **从错误中学习**——这次教训价值连城

## 格雷厄姆十大经典投资案例

### 案例1：政府雇员保险公司（GEICO）

**投资时间**：1948年

**投资背景**：
- GEICO创始人利奥·古德温急需资金
- 格雷厄姆-纽曼公司寻找投资机会
- 保险业的新兴商业模式

**投资决策因素**：
- **商业模式创新**：直销模式，无代理商
- **成本优势**：比竞争对手低30-40%
- **细分市场**：政府雇员风险低
- **创始人的诚信**：古德温的专业背景

**投资过程**：
- 决定收购一半股份（约37.5%）
- SEC介入：投资基金持有超过10%违法
- 格雷厄姆将股份分配给合伙人
- 格雷厄姆担任董事会主席

**投资成果**：
- 成为格雷厄姆最成功的投资之一
- 奠定了巴菲特后续投资的基础
- 证明了"好商业模式"的价值

**投资启示**：
1. **创新商业模式**——直销颠覆传统保险
2. **成本优势**——可持续的竞争优势
3. **深入调查**——格雷厄姆亲任董事长的原因
4. **价值发现**——被低估的新兴企业

### 案例10：格雷厄姆-纽曼公司（Graham-Newman）

- 格雷厄姆创立的investment partnership
- 美国最早的共同基金形式
- 价值投资的实践平台

- **价值导向**：寻找被低估的证券
- **安全边际**：只买有安全边际的标的

- 培养了巴菲特等一批投资家

**投资启示**：
1. **系统方法**——价值投资是系统工程
2. **长期验证**——30年的成功实践
3. **人才培养**——培养下一代投资者
4. **原则坚守**——30年如一日的原则
