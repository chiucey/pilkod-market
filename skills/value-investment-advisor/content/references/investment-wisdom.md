## 价值投资核心框架

### 内在价值评估

**现金流折现法（DCF）**：
```
内在价值 = Σ [CFt / (1+r)^t] + 终值 / (1+r)^n
其中：CFt = 第t年现金流，r = 折现率，n = 预测年限
```

**简化估值指标**：
- 市盈率（PE）：适合稳定增长企业
- 市净率（PB）：适合金融、重资产企业
- 股息率：适合价值型投资
- PEG：成长性评估

### 护城河类型

1. **无形资产**：品牌、专利、特许经营权
2. **成本优势**：规模经济、独特地理位置
3. **转换成本**：客户粘性、网络效应
4. **网络效应**：平台型企业
5. **效率优势**：精益管理、技术壁垒

### 优质企业特征

| 指标 | 标准 | 说明 |
|-----|-----|-----|
| ROE | >15% | 持续稳定的股东回报 |
| 毛利率 | >30% | 定价权和竞争优势 |
| 净利率 | >10% | 真正的盈利能力 |
| 负债率 | <50% | 财务稳健性 |
| 现金流 | 正且稳定 | 真实利润质量 |
| 分红率 | 稳定或增长 | 管理层回馈股东意愿 |

## 格雷厄姆估值方法与实践工具

### 格雷厄姆选股标准（防御型投资者）

格雷厄姆在《聪明的投资者》中为防御型投资者提出了具体的选股标准：

**标准一：规模适当**
- 工业公司：年销售额不低于1亿美元（格雷厄姆时代标准，需根据通胀调整）
- 公用事业公司：总资产不低于5000万美元

**标准二：财务稳健**
- 流动比率（流动资产/流动负债）≥ 2
- 长期负债不超过净流动资产（营运资本）

**标准三：盈利稳定**
- 过去10年每年均有盈利
- 过去10年没有削减股息

**标准四：股息记录**
- 连续20年支付股息

**标准五：盈利增长**
- 过去10年每股收益增长超过33%
- 或使用格雷厄姆偏爱公式：PE ≤ 0.5 × ROE × 100

**标准六：合理价格**
- PE ≤ 15倍
- 或股价 ≤ 1.5 × 每股净资产（PB ≤ 1.5）
- 或股息率 ≥ 债券利率的2/3

### 格雷厄姆估值公式

**格雷厄姆估值公式（Graham Formula）**：
```
价值 = EPS × (8.5 + 2 × 预期年增长率)
```
- EPS = 每股收益（TTM或预期）
- 8.5 = 当时合理PE基数（现代可调整为7-8）
- 预期年增长率 = 未来7-10年的预期增长率

**简化版安全边际估值**：
```
安全价格 = 0.9 × 每股净资产（PB = 0.9）
理想买价 = EPS × 7（PE = 7）
```

### 格雷厄姆股债平衡策略

**50:50再平衡策略**：
1. 将资产分为两半：50%股票，50%债券
2. 当股票上涨使比例变为55:45时，卖掉5%股票买入债券
3. 当股票下跌使比例变为45:55时，卖掉5%债券买入股票
4. 每年至少检视一次，根据年龄调整股债比例

**年龄调整法则**：
- 股票比例 = 100 - 年龄（或110/120 - 年龄）
- 剩余配置债券和现金
- 年龄越大，债券比例越高

### 格雷厄姆"捡烟蒂"策略

适用于深度价值的投资方法：

**Net-Net（净流动资产）法**：
```
净营运资本 = 流动资产 - 全部负债
净-Net价值 = 流动资产 - 全部负债 - 优先股
买入标准：股价 < 净-Net价值的2/3（0.67）
```

**关注要点**：
- 只适用于小型/中型公司
- 需要分散投资（至少10-30只）
- 催化剂：清算、管理变革、市场重新定价
- 现代市场较少出现此机会

### 格雷厄姆投资者类型匹配

| 类型 | 特点 | 适合策略 |
|-----|-----|---------|
| 防御型 | 缺乏时间/兴趣深入研究 | 指数基金 + 50:50股债平衡 |
| 进取型 | 愿意投入时间研究 | 个股精选 + 更大安全边际 |
| 积极型 | 专业分析能力 | 深度价值 + 困境反转 |

### 格雷厄姆投资戒律

1. **不亏损** - 永远将本金安全放在第一位
2. **安全边际** - 只在价格显著低于价值时买入
3. **分散投资** - 持有10-30只以上股票
4. **长期持有** - 至少3-5年，避免短期波动
5. **逆向思维** - 在大众恐惧时买入，贪婪时卖出
6. **独立思考** - 不依赖他人建议，独立分析
7. **程序化** - 制定投资规则并严格执行
8. **承认无知** - 不投资不了解的领域
