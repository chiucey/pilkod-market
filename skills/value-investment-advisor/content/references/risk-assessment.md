# 风险偏好评估问卷

## 格雷厄姆投资者分类法

格雷厄姆在《聪明的投资者》中将投资者分为两类，这是价值投资的基础分类：

### 防御型投资者（Passive/Defensive Investor）

**定义**：追求稳健回报，不愿或没有时间深入研究市场的投资者。

**格雷厄姆建议特征**：
- 投入较少时间和精力在投资上
- 追求程序化、系统化的投资方式
- 主要目标是避免重大错误和损失

**格雷厄姆建议配置**（50:50股债平衡）：
- 50% 优质债券/固定收益产品
- 50% 多元化股票组合（可选择指数基金）
- 每年进行一次再平衡

### 进取型投资者（Active/Enterprising Investor）

**定义**：愿意投入更多时间和精力，愿意承担更高风险以追求更高收益的投资者。

**格雷厄姆建议特征**：
- 有兴趣和能力深入分析企业和证券
- 有耐心等待合适的买入时机
- 能够承受短期波动

**格雷厄姆建议配置**：
- 更大的灵活性
- 可以寻找被低估的特殊机会
- 需要更严格的安全边际

## 不同风险偏好的投资建议特征

### 保守型投资者
- **特征**：本金安全优先，无法接受任何损失
- **适合**：国债、大额存单、纯债基金、货币基金
- **价值投资适配**：高股息、低估值蓝筹股
- **持有周期**：视具体品种而定
- **关键指标**：本金保障、流动性

### 稳健型投资者
- **特征**：追求稳健收益，可接受小幅波动
- **适合**：二级债基、偏债混合、固收+
- **价值投资适配**：优质白马股 + 债券组合
- **持有周期**：3-5年
- **关键指标**：最大回撤控制、波动率

### 平衡型投资者
- **特征**：寻求收益与风险的平衡
- **适合**：股债平衡基金、灵活配置基金
- **价值投资适配**：低估优质股 + 行业龙头
- **持有周期**：3-7年
- **关键指标**：风险调整后收益

### 进取型投资者
- **特征**：追求高收益，可接受较大波动
- **适合**：股票型基金、主动管理基金、优质个股
- **价值投资适配**：成长股 + 周期股 + 海外资产
- **持有周期**：5-10年
- **关键指标**：长期复合收益率

### 激进型投资者
- **特征**：愿意承受高波动，追求超额回报
- **适合**：股票、期货、期权、另类投资
- **价值投资适配**：深度价值 + 困境反转
- **持有周期**：7-10年+
- **关键指标**：绝对收益、相对排名
