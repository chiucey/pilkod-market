# Adobe Premiere Pro 快捷键速查表

## 文件操作

| 功能 | Windows | macOS |
|------|---------|-------|
| 新建项目 | Ctrl+Alt+N | Cmd+Opt+N |
| 打开项目 | Ctrl+O | Cmd+O |
| 保存项目 | Ctrl+S | Cmd+S |
| 另存为 | Ctrl+Shift+S | Cmd+Shift+S |
| 导入媒体 | Ctrl+I | Cmd+I |
| 导出媒体 | Ctrl+M | Cmd+M |
| 关闭项目 | Ctrl+W | Cmd+W |
| 退出 | Ctrl+Q | Cmd+Q |

| 功能 | Windows | macOS |
|------|---------|-------|
| 撤销 | Ctrl+Z | Cmd+Z |

| 剪切 | Ctrl+X | Cmd+X |
| 复制 | Ctrl+C | Cmd+C |
| 粘贴 | Ctrl+V | Cmd+V |
| 粘贴插入 | Ctrl+Shift+V | Cmd+Shift+V |
| 删除/清除 | Delete | Delete |
| 波纹删除 | Shift+Delete | Shift+Delete |
| 全选 | Ctrl+A | Cmd+A |
| 取消选择 | Shift+Ctrl+A | Shift+Cmd+A |
| 查找 | Ctrl+F | Cmd+F |
