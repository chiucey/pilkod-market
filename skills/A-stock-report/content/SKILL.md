## 量化情绪打分规则（6维，满分100）

| 维度 | 满分 | 区间得分 |
|------|------|---------|
| ①涨停数量 | 15 | ≥150→15, ≥100→12, ≥60→9, ≥30→5, ≥10→2, <10→0 |
| ②涨跌停比 | 15 | ≥8→15, ≥5→12, ≥3→9, ≥1.5→5, ≥0.5→2, <0.5→0；跌停=0时直接15分 |
| ③北向资金 | 20 | ≥100亿→20, ≥50→15, ≥20→10, ≥0→6; 流出≥-50→3, <-50→0 |
| ④主力资金（全市场） | 20 | ≥500亿→20, ≥200→16, ≥50→12, ≥0→8; -200→5, -500→2, <-500→0 |
| ⑤炸板率（炸板数/涨停数） | 15 | <15%→15（强封板）, <25%→12, <35%→8, <45%→5, ≥45%→3；无数据→⚠️暂缺 |
| ⑥沪深300 | 10 | ≥+2%→10, ≥+1%→8, ≥0%→6; -1%→4, <-1%→0 |

**综合评级**：≥85→🟢极强多头 | ≥68→🟡多头偏强 | ≥52→⚪中性震荡 | ≥36→🟠偏空谨慎 | <36→🔴极弱空头

**⚠️ 评分保护**：任意一项数据暂缺 → 整体等级显示"⚠️数据暂缺，无法评分"（不是0分，不计入）。

**市场风险偏好**（晚报专用，独立于情绪，纯分类）：
`两融比例 = 融资买入额 / 全市场成交额 × 100%`
<7% → 偏保守 | 7~11% → 中性 | >11% → 投机偏好

## 数据源（Python脚本实现，SKILL.md只描述逻辑）

> ⚠️ **核心原则**：今日数据暂缺时，脚本返回 `None`，由 AI 第三步搜索补全；**禁止取昨日数据凑数**（数据不可比，违反可比性原则）。

| 数据项 | 正确来源 | 注意事项 |
|--------|----------|-----------|
| 六大指数 | 腾讯 qt.gtimg.cn field[32] | URL格式 `qt.gtimg.cn/q=sh000001,sz399001...`；腾讯返回纯数字代码（如"000001"非"sh000001"） |
| 涨停家数 | akshare `stock_zt_pool_em(date=今天)` | ⚠️ 跌停用 `stock_zt_pool_dtgc_em`，不是 `stock_dt_pool_em` |
| 北向资金 | akshare `stock_hsgt_fund_flow_summary_em` | 列名 `成交净买额`（万元），筛选 `资金方向=='北向'`；**今日数据18:00后才更新**，暂缺时返回 `None`，AI 搜索补全 |
| 两融余额 | akshare `stock_margin_account_info` | 列名 `融资余额`（已是**亿元**，无需除1e8）；今日未更新时返回 `None`，AI 搜索补全 |
| 融资买入额 | akshare `stock_margin_account_info` | 列名 `融资买入额`（已是**亿元**）；今日为0时**不要**取昨日数据，由 AI 搜索补全 |
| 两融比例 | 融资买入额 / 全市场成交额 | **不是**融资余额/全市场成交额（概念错误） |
| 全市场成交额 | 腾讯 qt.gtimg.cn 沪深各一个指数加总 | 沪市上证指数 field[37]（万元） + 深市深证成指 field[37]（万元），除1e4→亿；akshare 深市数据偏小，**不要用** |
| 申万行业涨跌 | akshare `stock_sector_spot()`（无参数） | 东财概念板块 API 在沙盒中被封 |
| 全市场主力净流入 | ①妙想 MX API → ②akshare个股加总后备 | 妙想每日50次限额；妙想可用时显示"妙想数据"，不可用时返回 `None`，AI 搜索补全 |
| 行业主力资金流向 | 妙想 MX API（分两批，每批10行业） | 妙想不可用时返回空 |
