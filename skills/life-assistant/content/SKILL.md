# 生活小助手

## 技能简介

生活小助手是一款专注于解决日常生活问题的技能。它可以帮助用户：

- 🧑‍🍳 **食谱推荐** - 根据食材或场景推荐菜谱

- 💡 **生活妙招** - 提供实用的生活技巧和建议
- 🧮 **快速计算** - 计算花费、分摊金额、单位换算

## 使用示例

### 示例1：食谱推荐 - 番茄炒蛋

**用户**: "我想做一道番茄炒蛋，需要什么配料和步骤？"

**助手**:

```
🍳 番茄炒蛋（家常经典）

📋 所需配料：
- 番茄 2个
- 鸡蛋 3个
- 葱花 适量
- 盐 1小勺
- 糖 半小勺
- 食用油 2汤匙

📝 烹饪步骤：
1. 番茄洗净切块，鸡蛋打散加少许盐搅匀
2. 热锅凉油，倒入蛋液炒至凝固盛出备用
3. 锅中再加少许油，放入番茄块翻炒出汁
4. 加入炒好的鸡蛋，调入盐和糖翻炒均匀
5. 撒上葱花即可出锅

⏱️ 烹饪时间：约10分钟
🔢 难易程度：⭐（入门级）

💡 小贴士：
   - 番茄切块时可以去皮，口感更好
   - 炒鸡蛋时火不要太大，以免变老
   - 加一点糖可以中和番茄的酸味

还想学其他简单菜吗？
```

### 示例4：生活妙招 - 抽油烟机清洁

**用户**: "厨房的抽油烟机很难清洁，有什么好办法吗？"

**助手**:

```
💡 抽油烟机清洁小妙招

🧹 方法一：苏打粉+白醋（推荐）
1. 将苏打粉调成糊状，涂抹在油污处
2. 静置15-20分钟
3. 用喷壶喷白醋，产生泡沫
4. 用刷子轻轻刷洗，最后用清水擦净

🧹 方法二：温水+洗洁精
1. 将洗洁精加入温水中
2. 用抹布浸泡后敷在油污处
3. 静置10分钟后擦拭

🧹 方法三：蒸汽清洁
1. 用蒸汽清洁机的热气软化油污
2. 配合刷子快速清洁

🧹 方法四：专用清洁剂
1. 购买厨房专用油污清洁剂
2. 喷洒后静置5分钟
3. 用刷子刷洗后清水冲净

⚠️ 注意事项：
• 避免使用钢丝球，以免刮伤表面涂层
• 每周清洁一次，油污不易堆积
• 清洁前可以先烧一锅热水，让蒸汽软化油污
• 清洁时记得戴手套，保护双手

🛡️ 预防建议：
• 每次烹饪后用湿布擦拭表面
• 定期清理油杯（建议每月一次）
• 在油杯里放一张纸巾，方便清理
• 烹饪时开窗通风，减少油烟附着

还想知道其他清洁妙招吗？比如：
• 微波炉清洁
• 冰箱除异味
• 浴室清洁
• 窗户清洁
```

### 示例7：生活妙招 - 衣服去污

**用户**: "我的白T恤不小心沾到咖啡渍了，怎么洗掉？"

**助手**:

```
🧺 咖啡渍去除妙招

⏰ 黄金时间：污渍越新鲜越容易清除

🧹 方法一：立即处理（推荐）
1. 用冷水冲洗污渍背面（从内向外）
2. 在污渍处涂抹洗洁精或洗衣液
3. 轻轻揉搓，静置5-10分钟
4. 用冷水冲洗后正常洗涤

🧹 方法二：苏打粉
1. 将苏打粉加水调成糊状
2. 涂抹在污渍处
3. 静置15-30分钟
4. 用刷子轻刷后洗涤

🧹 方法三：白醋
1. 将白醋和水1:1混合
2. 用棉球蘸取溶液涂抹污渍
3. 静置5分钟后用冷水冲洗
4. 正常洗涤

🧹 方法四：双氧水（用于顽固污渍）
1. 将3%双氧水滴在污渍上
2. 静置10-15分钟
3. 用清水冲洗后洗涤

⚠️ 注意事项：
• 不要用热水，会让咖啡渍固定
• 不要摩擦，会扩大污渍范围
• 丝绸和羊毛衣物建议送专业干洗

🛡️ 预防建议：
• 随身携带去污笔
• 喝咖啡时注意慢饮
• 穿着浅色衣服时格外小心

还有其他衣物问题吗？
```

## 进阶使用技巧

### 1. 组合使用

可以同时提出多个需求：

- "帮我列一个3天的健康饮食清单，并且计算每天的热量摄入"
- "我下周要搬家，列一个购物清单，再帮我算一下大概要花多少钱"
- "推荐几道简单菜谱，同时告诉我需要买什么食材"

### 2. 场景化提问

越具体的场景描述，获得的回答越实用：

- ❌ "怎么做饭？"
- ✅ "我是一个做饭新手，想要在30分钟内做出营养均衡的晚餐，请推荐几道菜"

- ❌ "帮我算费用"
- ✅ "我们6个人去日本玩7天，机票已买，现在要算酒店、餐饮、交通、门票的预算"

### 3. 持续对话

可以追问或补充信息：

- "刚才那个食谱里的盐能换成酱油吗？"
- "清单里的饮料我想换成果汁，可以吗？"
- "那个计算结果能帮我导出成表格吗？"
- "如果8个人改成10个人，费用怎么变？"

### 4. 自定义偏好

告诉我你的特殊需求：

- "我正在减肥，帮我推荐低热量的菜谱"
- "我对海鲜过敏，请推荐不含海鲜的菜单"
- "我们家有小孩，帮我列一个适合全家人的购物清单"
- "我住在北方，冬天有什么暖身食谱推荐？"
- "预算有限，帮我规划一个500元的派对"

### 5. 限制条件提问

可以加入具体的限制：

- "给我介绍5道不超过15分钟的快手菜"
- "我不吃辣，有什么川菜推荐？"
- "预算1000元，帮我列一个搬家购物清单"
- "家里只有电磁炉，能做什么菜？"
