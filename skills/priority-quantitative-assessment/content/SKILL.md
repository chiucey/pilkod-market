# 需求优先级量化评估与排期管控技能

## 技能定义

通过科学的量化评估方法，对需求进行优先级排序，结合资源约束制定合理的排期计划，确保产品迭代效率最大化。

## 核心SOP

### 方法一：RICE评估法

**公式**：RICE Score = (Reach × Impact × Confidence) / Effort

| 因素 | 说明 | 打分范围 |
|------|------|---------|
| Reach（触达） | 影响用户数量/周期 | 1-1000 |
| Impact（影响） | 对北极星指标的影响 | 3=massive, 2=high, 1=medium, 0.5=low, 0.25=minimal |
| Confidence（置信度） | 预估的置信程度 | 100%=high, 80%=medium, 50%=low |
| Effort（工作量） | 团队工作量（人天） | 正整数 |

### 方法二：价值-复杂度矩阵

```
高价值
    ↑
    │
    │  ★ 紧急重要  │  ◆ 战略优先
    │   (立即做)   │   (规划做)
    ├────────────┼─────────────→
    │  ○ 低价值   │  ● 核心价值
    │   (可不做)   │   (重点做)
    │   高复杂度   │   低复杂度
低价值              高价值
```

### 方法三：MoSCoW法则

| 分类 | 含义 | 占比建议 |
|------|------|---------|
| Must have | 必须有 | 60% |
| Should have | 应该有 | 20% |
| Could have | 可以有 | 15% |
| Won't have | 这次不会有 | 5% |

### 排期规划

**敏捷估算扑克**：
- XS: 0.5天
- S: 1-2天
- M: 3-5天
- L: 8-13天
- XL: 21+天（需拆分）

**迭代容量计算**：

```
可用工时 = 团队人数 × 迭代天数 × 每日工时 × 效率系数(0.7-0.8)
预估容量 = 可用工时 × 验证缓冲(0.7)
```
