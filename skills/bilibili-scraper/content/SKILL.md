# B站数据抓取技能

## 核心能力

1. **视频信息抓取** - 获取标题、UP主、播放量、点赞、投币、收藏、弹幕数等
2. **排行榜数据** - 全站、分类、分区排行榜
3. **UP主信息** - 粉丝数、作品列表、播放量统计
4. **评论数据** - 楼层评论、回复评论
5. **搜索结果** - 关键词搜索、多条件筛选

## 使用场景

- 分析B站视频热度趋势
- 批量采集UP主数据
- 竞品分析/行业研究
- 内容创作参考

## 输出格式

所有数据以JSON格式返回，包含：
- 基础元数据（标题、作者、发布时间等）
- 互动数据（播放、点赞、投币、收藏、弹幕）
- 关联数据（标签、分类、合集等）

## 注意事项

- 遵守B站robots.txt和服务条款
- 合理控制请求频率，避免对服务器造成压力
- 数据仅供个人学习研究使用
