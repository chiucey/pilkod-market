# Quality Gates & Standards

> **Author**: 起始终下
> **Copyright**: © 2025 起始终下. All Rights Reserved.

---

## A. Direction & Rhythm

- [ ] Direction covers IMAGE, CAMERA/SPACE, INFORMATION/EMOTION, ACTION/WORLD four axes
- [ ] First viewing chart indicates audience already knows, questions, predictions, evidence, reassessment, payback
- [ ] Direction includes composition, blocking, camera positions, lighting, editing, sound, perspective, visual motifs
- [ ] Each direction's difference comes from visual language, not genre labels
- [ ] Each shot can explain what new understanding, feeling, relationship, or rhythm function it provides audience
- [ ] Scene timecodes are continuous start-to-end, sum precisely equals target duration
- [ ] Shot density matches plot intensity

### Style Fusion

- [ ] Primary/secondary/accent method weights, scope, owned craft knobs are clear
- [ ] User locks, format, genre, primary method, secondary style priority not inverted
- [ ] Fixed/handheld, deep/shallow, long-take/quick-cut, natural/expressive lighting conflicts resolved per item
- [ ] Do not substitute director names for specific shot decisions, do not replicate specific film shots

### Cinematic Visual Grammar

- [ ] Core scenes specify unresolvable state, character action, visible consequence
- [ ] Composition can trace to who looks at whom, who knows more, who is spatially constrained, audience position
- [ ] Key shots have repeatable gaze flow: entry, block/accelerate, landing point, unresolved edge info, lingering impression
- [ ] Camera area, height, distance, axis, subject proportion, focus layer, main light source can be executed in real space
- [ ] Each sequence has only one primary visual engine and maximum two auxiliary engines
- [ ] Colors come from clothing, walls, weather, practical lights, reflections—not unmotivated global filters
- [ ] One continuous visual group selects one capture base and one primary imperfection family
- [ ] Each shot follows density budget: 2-3 scene details, 1 primary action, 1 secondary clue, 1 main light source, 1 composition mechanism
- [ ] Shot groups do not mechanically repeat wide-medium-close, do not default to establishing shot endings
- [ ] Each reference preserves only one primary dimension; character relationships, actions, props, spatial skeleton, iconic combinations redesigned

---

## B. Storyboard

- [ ] Shot numbers continuous, no duplicates or gaps
- [ ] Start-end timecodes continuous, no overlaps or gaps
- [ ] Camera angle, shot size, notes simultaneously executable
- [ ] Each shot specifies start state, movement, end state; blocking before camera
- [ ] Character motivation, action, position, prop state continuous
- [ ] 180-degree line, gaze, movement direction with clear basis
- [ ] No psychological interpretation or author conclusions in visual content
- [ ] Modification notes consistent with actual table

---

## C. Visual Assets

- [ ] Character/scene/prop IDs complete; scene-prop mapping complete
- [ ] Same character's appearance, clothing, insignia consistent item by item
- [ ] Asset lock includes identity, geography, light direction, state fields reused by prompts or for review
- [ ] Each image prompt includes task, identity lock, action end state, scene geography, camera, light direction, material, risk constraints, parameters
- [ ] Chinese-English semantic alignment
- [ ] UI/signage accurate text changed to post overlay, not directly generated by model

---

## D. Video Prompts

- [ ] Target tool control surface identified; when unknown, use platform-neutral contract, do not invent capabilities
- [ ] Each generation duration 4-15 seconds; try to pack to 12-15 seconds when same scene and continuity established, scene purity prioritized over filling duration
- [ ] Each main video prompt contains only one scene ID; cross-scene switches must be segmented
- [ ] Storyboard coverage 100%; each shot appears in only one main video prompt
- [ ] Each cut point in multi-shot prompts marked with time, shot size, camera position, spatial anchor
- [ ] Opening frame, blocking, per-second actions, explicit end state filmable
- [ ] Dialogue and lip-sync periods match; unlabeled if no dialogue
- [ ] Diegetic, non-diegetic, music/narration/subtitle layers correctly classified
- [ ] At least one verifiable connection logic with previous/next shots
- [ ] Chinese-English versions correspond item by item
- [ ] Constraints only for real risks in this segment, no overly long generic prohibition lists

---

## E. Forbidden Terms

**Chinese empty words**: 令人叹为观止、令人惊叹、视觉盛宴、完美呈现、震撼人心、美轮美奂、无与伦比、惊艳、绝美

**English empty words**: breathtaking, stunning, captivating, mesmerizing, cinematic masterpiece, visual feast, seamlessly, flawlessly, cutting-edge, next-level

**Psychological words in prompts**: 感到、意识到、内心、仿佛、似乎、悲伤、恐惧、愤怒 (unless as diagnostic label)

---

## F. Problem Handling

1. Mark shot/asset ID and conflict field
2. Modify only minimum scope
3. Recalculate all affected timecodes
4. Check previous/next shot states and connections
5. Re-scan forbidden terms
6. Actual files or tables as standard, do not accept "already fixed" text declarations instead of verification
