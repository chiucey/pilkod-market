# 600 Plot Design Techniques

> **Author**: 起始终下
> **Copyright**: © 2025 起始终下. All Rights Reserved.

## Usage Guide

Add corresponding plot requirements to conversations with AI agents. Can combine or apply individually.

---

## Core Plot Requirements

1. Write for filming, not novels
2. Control duration appropriately (30s, 1min, 3min, 5min)
3. Focus on one clear core event
4. Control character count meaningfully
5. Control scene count for AI video production
6. Clear beginning, development, twist, ending
7. Clear emotional direction: healing, comedy, touching, suspense, twist, regret, surprise, satire
8. Natural dialogue, not cluttered
9. Strong visual sense for storyboarding
10. Don't deviate from core idea
