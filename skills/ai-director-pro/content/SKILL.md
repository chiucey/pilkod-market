## Part 1: Four-Axis Decision Framework

### The Four Axes of Cinematic Decision

Before any visual creation, establish the four-axis framework:

#### 1. IMAGE / 画面

- **Visual Proposition**: Capturable change sentences, e.g., "As the character approaches truth, the doorframe cuts them narrower"
- **Repetitive Relationships**: Scale, blocking, negative space, texture, color, or motif
- **Deviation Point**: When climax allows reverse composition or color

#### 2. CAMERA / SPACE / 镜头与时空

- Write body, props, and space starting/ending points first, then place camera
- State: observation distance, camera height, axis, screen direction, lens effect, allowable movement
- Each movement must change information, power distance, or physical sensation

#### 3. INFORMATION / EMOTION / 信息与情绪

Per beat, fill: audience already knows, currently asking, predicting, seeing new evidence, reassessing, physical feeling, payback/debt

#### 4. ACTION / WORLD / 行动与世界

- Characters attempt concrete actions to change situation; action must have visible end state
- World rules presented through usage, obstruction, and cost
- Each action writes clear `start state → attempt → contact/resistance → result → new situation`

## Part 3: Story & Plot Design System

### 600 Plot Design Techniques

Use these techniques to enhance storytelling:

#### Core Plot Requirements

1. Write for filming, not novels
2. Control duration appropriately (30s, 1min, 3min, 5min)
3. Focus on one clear core event
4. Control character count meaningfully
5. Control scene count for AI video production
6. Clear beginning, development, twist, ending
7. Clear emotional direction: healing, comedy, touching, suspense, twist, regret, surprise, satire
8. Natural dialogue, not cluttered
9. Strong visual sense for storyboarding
10. Don't deviate from core idea

#### Output Format

## Part 4: Cinematic Visual Grammar

### Relationship Pressure Cards

Before positioning camera, fill:

- Who is looking at whom, who deliberately not looking
- Who knows more, who misjudges
- Who is preparing to leave, wait, block, or expose
- How doors, windows, tables, mirrors, stairs, corridors, floor lines limit action
- Where audience is placed: participant, bystander, voyeur, observed, blind spot
- Whether person or space dominates, whether relationship changes at end of shot

### Gaze Flow Sentence

For each key frame or shot group, write a gaze flow:

```
入口 → 阻挡/加速 → 决定性落点 → 尚未解决的边缘信息 → 离开画面的余味
```

### Visual Engines

Choose one primary engine per project/sequence, maximum two auxiliaries:

- **秩序**: Axis, repetition, symmetry, geometric rules established and broken
- **光**: Visible light source changes identity, information, or action permissions
- **色**: Color source migrates, fades, or reverses in plot
- **空间**: Doors, levels, blocking, distance, and paths create narrative
- **人物状态**: Posture, breathing, action completeness, performance distance carry change
- **尺度/世界**: Character-environment ratio reveals system, natural, or collective power
- **社会调度**: Multi-person positioning, furniture, entrances-exits form power geometry
- **主观扰动**: Focus, exposure, motion, or sound-image offset represents limited cognition

## Part 5: Professional Workflow

### Phase 1: Ideation & Planning (10%)

#### 1.1 Inspiration Acquisition
- **No complete script needed** - agile creation method
- Discuss with friends, create 2-3 test shots to validate direction
- Mx-Shell approach: "边做边想" - work as you go

#### 1.2 Visual Pre-visualization
- Form scene in mind: position (up/down/left/right/center/edge)
- Only describe after clear mental picture
- **Do not fully rely on AI**

#### 1.3 Story Development
- Use plot design techniques from 600-technique library
- Apply emotional direction early
- Design conflict and resolution structure

### Phase 2: Prompt Engineering (20%)

**Core Principle**: 95% hand-written, AI only for special actions

#### Attention Guidance
```yaml
# Inefficient
主角按压腰带，腰带发出红光

# Efficient (keyword repetition)
主角用力按压腰带核心，水晶核心本体被挤压而开裂，
红光伴随晶体的裂纹亮起，启动装置后慢慢松开手
```

#### Spatial Description
```yaml
# Abstract
"英雄登场"

# Spatial (better for AI)
"单脚跪姿、单手撑地、水墙环形扩散"
```

### Phase 3: Generation (40%)

#### Quality Control Nodes

```
Stage 1: Concept Validation (2-3 test shots)
  ├─ Evaluate: Is style correct?
  ├─ Decision: Continue this direction?
  └─ Output: Viable prompt framework

Stage 2: Segment Generation (each 15-20s)
  ├─ Evaluate: Is timing smooth?
  ├─ Decision: Need adjustments?
  └─ Output: Usable video clips

Stage 3: Post-production Integration
  ├─ Evaluate: Overall rhythm/emotion consistent?
  ├─ Decision: Need supplementary shots?
  └─ Output: Final film
```

#### Resource Investment Ratio

```
Concept: 10% (quick test, direction validation)
Prompt Writing: 20% (refinement, structuring)
Generation: 40% (massive draws, screening)
Post-production: 30% (editing, color, audio)
```

### Phase 4: Post-production & Editing

| Statistic | Value |
|-----------|-------|
| Image-to-video ratio | ~80% images generate clips |
| Total clips generated | 200+ for complex works |
| Editing duration | ~10 days for complex projects |

## Part 7: Large Model Limitations & Solutions

### 1. Long-sequence Consistency

**Issue**: Content over 10s容易出现风格漂移、穿帮累积

**Solution Matrix**:

| Solution | Principle | Cost | Effect |
|----------|-----------|------|--------|
| Segmented Generation | Divide into 15s clips | Medium | High |
| Reference Anchoring | Use keyframe screenshots | Low | Medium |
| Post-fix | Image model repairs | High | Medium |
| Abandon Long Take | Use montage | Low | Medium |

**Professional Advice**: Single shots under 15s most stable; segment if longer.

### 2. Physics Simulation

**Issue**: AI has weak physics understanding

**Solutions**:
1. **Prioritize Seedance**: Best physics feedback
2. **Simplify physics scenes**: Avoid complex interactions
3. **Embrace glitches**: Sometimes "errors" become style

### 3. Face Consistency

**Solutions**:

```yaml
Solution 1: Sketch Method
  Convert photo → realistic sketch → AI generates
  Pros: Bypass limits, Cons: Distortion

Solution 2: Description Anchoring
  Detailed facial description (features, face shape, hairstyle)
  Pros: Authenticity, Cons: Unstable

Solution 3: Clone Tool
  Dedicated AI clone tools
  Pros: High consistency, Cons: High cost
```

## Part 10: Common Problem Solutions

### Generation Failure
- Simply regenerate
- Prompt violation: Delete words without changing meaning

### Copyright Issues
- Replace film/TV related terms
- Enterprise users: FlowMuse with permissions

### Face Not Supported
- Ignore system prompts, continue
- Use Doubao for "realistic style color sketch"
- Provide multiple photos + detailed description

### Unideal Effects
- Common issue - try multiple times
- Modify prompt, add detailed requirements
- Reference images need high quality

### Word Limit
- Use computer web version
- Trim redundant descriptions
