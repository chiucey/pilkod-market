# PPT模版生成器 - 详细使用指南

本参考资料提供PPT模版生成技能的详细使用说明、参数配置和最佳实践。

## 内置模版详解

### 企业商务风格 (corporate)

**适用场景**：年度汇报、商务提案、工作总结、项目汇报

**设计特点**：
- 主色调：深蓝色 (#1E3A5F)
- 辅助色：浅灰色 (#F5F7FA)
- 强调色：金色 (#D4AF37)
- 字体：思源黑体、微软雅黑
- 布局：左对齐、清晰的层级结构

**典型结构**：
1. 封面页 - 公司LOGO、标题、日期
2. 目录页 - 内容概览
3. 内容页 - 图表+文字说明
4. 结尾页 - 感谢语

### 创意活泼风格 (creative)

**适用场景**：教育培训、市场推广、创意展示、团队活动

**设计特点**：
- 主色调：多彩渐变 (橙红到金黄)
- 辅助色：白色、浅粉
- 强调色：明亮绿色 (#2ECC71)
- 字体：圆润可爱的无衬线字体
- 布局：居中、大量图形元素

**典型结构**：
1. 封面页 - 大标题、装饰图形
2. 目录页 - 可视化图标列表
3. 内容页 - 卡片式布局
4. 结尾页 - 互动号召

### 简约清晰风格 (minimal)

**适用场景**：学术报告、技术文档、发布会演讲、个人简历

**设计特点**：
- 主色调：纯白背景、黑色文字
- 辅助色：单色点缀
- 强调色：品牌主色
- 字体：苹方、Helvetica
- 布局：大量留白、极简线条

**典型结构**：
1. 封面页 - 极简标题
2. 内容页 - 一句话一页
3. 数据页 - 简洁图表
4. 结尾页 - 联系方式

### 科技感风格 (tech)

**适用场景**：科技产品发布、AI/技术介绍、创新方案展示

**设计特点**：
- 主色调：深色背景 (#0D1B2A)、霓虹蓝 (#00D9FF)
- 辅助色：暗紫色 (#7B2CBF)
- 强调色：电光绿 (#39FF14)
- 字体：等宽字体、未来感字体
- 布局：不对称、大胆留白

**典型结构**：
1. 封面页 - 全屏视觉冲击
2. 技术架构页 - 流程图、示意图
3. 数据展示页 - 动态图表
4. 未来展望页 - 概念图

### 优雅典雅风格 (elegant)

**适用场景**：高端品牌、婚礼策划、艺术展示、奢侈品介绍

**设计特点**：
- 主色调：暖米色 (#FAF8F5)、咖啡色 (#5D4037)
- 辅助色：玫瑰金、香槟色
- 强调色：深酒红 (#722F37)
- 字体：衬线字体、优雅字体
- 布局：对称、精致边框

**典型结构**：
1. 封面页 - 精致纹理背景
2. 故事页 - 叙事性排版
3. 产品页 - 细节展示
4. 结尾页 - 高端感谢

## 常见问题处理

### 问题1：内容过长如何处理

**解决方案**：
- 自动拆分长段落
- 启用智能摘要功能
- 建议用户精简内容
- 增加页面数量

### 问题2：图片如何处理

**解决方案**：
- 使用用户提供的图片URL
- 调用图片搜索下载功能
- 提供占位符供后续替换
- 使用内置图标库

### 问题3：多语言支持

**解决方案**：
- 标题可使用中英文混合
- 内置多语言模版变体
- 支持RTL布局（阿拉伯语等）

## 输出文件规格

- 格式：PPTX (Microsoft PowerPoint 2007+)
- 尺寸：16:9 宽屏 (1920x1080)
- 字体嵌入：是的
- 图片处理：自动压缩优化
- 最大页数：建议不超过100页

## 调用示例

### 示例1：简单PPT生成

```
用户输入：创建一个关于"新能源汽车发展趋势"的PPT
技能处理：
1. 分析主题 → 选择"科技感"风格
2. 生成结构：封面、目录、5页内容、结尾
3. 填充内容：行业数据、政策分析、市场前景等
4. 输出PPTX文件
```

### 示例2：使用内置模版

```
用户输入：选择"创意活泼"风格，主题是"团队建设活动"
技能处理：
1. 调用creative模版
2. 生成活动介绍、流程安排、游戏规则、总结
3. 添加趣味图形和图标
4. 输出活泼风格的PPT
```

### 示例3：批量生成

```
用户输入：需要生成10份不同产品的介绍PPT
技能处理：
1. 加载产品列表
2. 批量生成每份PPT
3. 保持风格一致，内容各异
4. 打包下载
```
