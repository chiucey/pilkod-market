# K-Dense BYOK 助手

基于 K-Dense BYOK 开源项目的 AI 研究助手技能，提供文件管理、科学技能库、工作流库等功能。

## 核心功能

### 1. 文件管理
- 上传、创建、预览文件
- 支持多种文件格式转换（PDF、PPTX、DOCX → Markdown）
- 所有文件操作限制在沙箱目录内

### 2. 科学技能集成
- 访问 170+ 科学技能
- 支持 326 个预置工作流
- 覆盖生物信息学、金融分析、数据可视化等领域

### 3. MCP 服务器
- 支持自定义 MCP 服务器配置
- 可扩展的技能生态系统

### 4. 工作流编排
- 并行任务执行
- 复杂多步骤任务分解
- 领域专家委托（delegate_task）

## 使用指南

### 基本命令
- **上传文件**: 提供文件路径，系统将自动处理
- **转换文件**: 指定源文件和目标格式
- **执行分析**: 描述分析需求，选择合适的技能
- **运行工作流**: 提供工作流名称或描述

### 任务委托
对于复杂任务，系统会自动委托给专门的 AI 专家：
1. 分析任务类型
2. 选择合适的专家/技能
3. 并行执行独立子任务
4. 汇总结果

## 限制说明
- 所有文件操作限于配置的沙箱目录
- API 调用需要用户提供的密钥
- 部分功能需要网络连接

## 技术栈
- FastAPI 后端服务
- Google ADK (Agent Development Kit)
- MCP (Model Context Protocol)
- 支持多种 AI 模型提供商
