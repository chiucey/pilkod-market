# AI合规审查技能

## 技能概述

本技能提供全面的AI系统合规审查能力，涵盖数据安全、模型安全、贸易合规、内容安全、知识产权和道德伦理六大核心领域。

## 适用场景

当用户需要：
- 对AI系统进行全面的合规性审查
- 检查特定要点是否符合监管要求
- 生成合规审查报告和数据
- 评估AI系统的安全性和伦理合规性

## 核心审核要点

### 1. 数据安全与隐私保护

| 审核要点 | 描述 | 合规标准 |
|---------|------|----------|
| 数据来源合规 | 确保数据收集合法合规 | 需提供数据来源证明和授权文件 |
| 数据跨境合规 | 跨境数据传输符合法规 | 需符合当地数据跨境传输规定 |
| 个人信息保护 | 保护个人隐私和数据权益 | 需符合GDPR/个人信息保护法 |
| 训练数据合规 | 训练数据的合法性和合规性 | 需有数据使用授权和合规声明 |
| 数据安全保护 | 防止数据泄露和未授权访问 | 需有安全保护机制和审计日志 |

### 2. 模型、算法安全

| 审核要点 | 描述 | 合规标准 |
|---------|------|----------|
| 模型鲁棒性 | 模型在不同条件下的稳定性 | 需进行鲁棒性测试并记录结果 |
| 网络基础设施安全 | 底层网络和硬件的安全性 | 需有安全防护措施和定期审计 |
| 网络攻击防护 | 防御网络威胁的能力 | 需有防护机制和应急预案 |

### 3. 贸易合规

| 审核要点 | 描述 | 合规标准 |
|---------|------|----------|
| 技术进出口管制 | 国际技术转移的合规性 | 需符合出口管制法规 |
| 芯片管制 | 硬件采购和使用的合规性 | 需有芯片采购合规证明 |
| 供应链安全 | 供应链完整性和安全性 | 需有供应链安全管理体系 |

### 4. 内容安全

| 审核要点 | 描述 | 合规标准 |
|---------|------|----------|
| 生成合成内容标识 | AI生成内容的标记和溯源 | 需有内容标识和溯源机制 |
| 虚假伪造信息治理 | 防止虚假信息和深度伪造 | 需有检测和治理机制 |
| 违法不良信息审核 | 不良内容的审核和过滤 | 需有审核过滤系统和处置流程 |

### 5. 知识产权

| 审核要点 | 描述 | 合规标准 |
|---------|------|----------|
| 训练数据知识产权合规 | 训练数据的版权合规 | 需有版权声明和合规证明 |
| 生成物知识产权归属 | AI生成内容的版权归属 | 需明确版权归属协议 |
| 开源合规 | 开源软件使用的合规性 | 需有开源许可合规声明 |

### 6. 道德伦理

| 审核要点 | 描述 | 合规标准 |
|---------|------|----------|
| 算法透明度 | 算法决策的可解释性 | 需有可解释性文档和说明 |
| 公平反偏见 | 防止算法偏见和歧视 | 需有偏见检测和缓解措施 |
| 避免信息茧房 | 防止信息隔离和回音室效应 | 需有推荐多样性保障机制 |
| 高风险应用场景限制 | 对敏感应用的控制和限制 | 需有风险评估和限制措施 |
| 特定领域伦理要求 | 医疗、教育等领域的伦理要求 | 需符合领域特定伦理规范 |

## 使用方法

1. **输入**: 提供需要审核的AI系统或相关文档
2. **分析**: 根据六大领域逐一进行合规性检查
3. **输出**: 生成完整的审核数据和报告

## 注意事项

- 每个审核要点都需要独立评估和记录
- 所有发现都需要有对应的证据或文档支持
- 改进建议应具体、可操作且符合当前法规要求
