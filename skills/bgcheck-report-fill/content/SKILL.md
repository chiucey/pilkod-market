# 背调信息自动填写 Skill

## 功能
将候选人回复的背调信息收集邮件中的关键信息，自动提取并填写至飞书背书报告模版。

## 触发词
**"背调填写"** + 提供邮件内容（粘贴邮件全文）

## 背调报告模版
- 文档ID：`F5hqdOXVOol2gQx3xrscsOKRnjb`
- 链接：https://feishu.cn/docx/F5hqdOXVOol2gQx3xrscsOKRnjb

## 工作流程

### 第一步：理解邮件内容
解读邮件，识别以下关键信息：

**候选人基本信息：**
- 姓名
- 应聘岗位（推测或明确）
- 任职公司

**证明人信息（最近一家 + 上一家，每家最多3类）：**
- 直属上司：姓名、联系方式（电话/邮箱）、共事时间
- 同事：姓名、联系方式（电话/邮箱）、共事时间
- HR：姓名、联系方式（电话/邮箱）、共事时间

### 第二步：识别邮件结构
常见背调邮件回复结构：
- 表格形式（HTML table / 文本表格）
- 纯文本分段
- 键值对形式

### 第三步：调用 feishu_doc 填写模版
使用 `feishu_doc` action=`list_blocks` 先列出所有 block，找到各区块 block_id，再使用 `update_block` 填写各区块。

**各区块填写方式：**

#### 候选人基本信息（Text blocks）
- 姓名 → 查找"姓名"对应的 Text block
- 访谈日期 → 填写当天日期
- 访谈方式 → 默认☐ 电话

#### 被访人信息（每个证明人填一条记录）
- 使用 `feishu_doc` action=`update_block` 填写被访人信息

#### 候选人履历核实（Table blocks）
- Table 1：候选人履历核实 - 任职时间
- Table 2：候选人履历核实 - 职位/职级

#### 工作表现评估（Table blocks）
- Table 3：工作表现评估 - 综合评分（维度评分表）

#### 风险点核查（Table blocks）
- Table 4：风险点核查

### 第四步：向恒宇汇报
- 填写了哪些内容
- 哪些信息未找到（邮件中缺失）
- 建议补充的内容

## 邮件信息提取参考

### 常见邮件格式 A（表格形式）
```
候选人姓名：张三
应聘岗位：算法工程师
任职公司：XX科技

证明人信息：
| 证明人类型 | 姓名 | 联系方式 | 共事时间 |
|-----------|------|---------|---------|
| 直属上司 | 李四 | 138xxxx | 2021-2023 |
| 同事 | 王五 | 139xxxx | 2022-2023 |
```

### 常见邮件格式 B（文本形式）
```
直属上司：李四，电话：138xxxx，任职时间：2021年-2023年
同事：王五，邮箱：wangwu@xx.com，共事时间：2022年-2023年
HR：赵六，电话：137xxxx
```

### 常见邮件格式 C（背调授权邮件回复）
候选人填写了背调授权书，确认了任职信息，通常包含：
- 任职时间段
- 职位名称
- 离职原因
- 证明人联系方式

## 注意事项
- 没有的信息**不填写**，留空即可
- 日期格式统一为 YYYY-MM-DD
- 电话号码去除空格和横线
- 邮箱原样填写
- 填写后用 `feishu_doc` action=`read` 验证
