# Web Info Research

网络信息搜索与整合技能，能够从多个来源收集信息、智能整合、并进行事实核查。

## 核心能力

1. **多源搜索**：使用批量网络搜索从多个角度收集信息
2. **内容提取**：从相关网页提取关键信息
3. **智能整合**：将多个来源的信息整合为连贯的报告
4. **事实核查**：验证关键声明的准确性，区分事实与观点

## 工作流程

### 步骤 1：理解查询

分析用户的信息需求：
- 确定搜索主题和范围
- 识别关键问题或子主题
- 判断是否需要事实核查

### 步骤 2：执行搜索

使用 `batch_web_search` 工具进行搜索：
- 每次查询最多10个结果
- 使用相关关键词组合
- 对于复杂主题，进行多角度搜索

### 步骤 3：提取内容

使用 `extract_content_from_websites` 工具：
- 从高相关性网页提取详细信息
- 优先选择权威来源（政府、教育、知名媒体）
- 提取事实、数据、日期等具体信息

### 步骤 4：信息整合

整合搜索结果：
- 按主题或时间线组织信息
- 标注信息来源（必须包含引用）
- 识别信息共识和争议点

### 步骤 5：事实核查

对关键声明进行核查：
- 交叉验证多个来源
- 标注信息来源的可靠性
- 明确区分：已证实事实 / 专家观点 / 存疑信息
- 如有矛盾，说明不同来源的差异

## 输出格式

### 标准信息报告

```
## [主题] 信息汇总

### 核心发现
- 要点1 [来源1]
- 要点2 [来源2]

### 详细信息
...

### 来源列表
1. [来源标题](URL)
2. ...

---

## 事实核查报告

### 已证实信息 ✓
- 事实1
- 事实2

### 存疑/待核实信息 ⚠
- 声明1（来源A称...，来源B称...）

### 信息空白
- 暂无权威来源证实...
```

## 引用规范

**必须**：所有从搜索结果提取的信息必须包含 `<citation>{{index}}</citation>` 标签，其中 index 是搜索结果的序号。

示例：
```
根据最新数据显示[...] <citation>1</citation>，同时[...] <citation>3</citation>。
```

## 质量标准

- **全面性**：覆盖主题的主要方面
- **准确性**：忠实于原来源，不曲解
- **透明性**：清晰标注信息来源和不确定性
- **时效性**：注意信息的发布时间

## 注意事项

1. 优先选择权威来源（政府网站、学术期刊、知名媒体）
2. 对于存疑信息，明确标注并提供不同来源
3. 如果搜索结果不理想，尝试不同的关键词组合
4. 尊重版权，提取信息但不过度引用
5. 对于专业领域（如医疗、法律），建议咨询专业人士
