# 信息搜索与整合示例

## 示例 1：简单信息查询

**用户请求**："搜索一下2024年诺贝尔物理学奖得主的信息"

**执行流程**：
1. 搜索 "2024 Nobel Prize Physics winner"
2. 提取相关网页内容
3. 整合获奖者信息、贡献领域、获奖原因

**输出示例**：
```
## 2024年诺贝尔物理学奖得主

根据诺贝尔奖官方网站的公告[...] <citation>1</citation>。

### 获奖者
- **[获奖者姓名]**（所属机构）
- **[获奖者姓名]**（所属机构）

### 获奖贡献
[简述获奖原因]

### 来源
1. [Nobel Prize Official](URL)
```

## 示例 2：多角度信息整合

**用户请求**："帮我调查一下电动汽车的市场发展趋势"

**执行流程**：
1. 搜索市场规模数据

3. 搜索主要厂商动态
4. 搜索政策环境变化
5. 整合为综合报告

## 示例 3：事实核查场景

**用户请求**："网上有人说电动汽车比燃油车更污染，这是真的吗？帮我核实"

**执行流程**：
1. 搜索"电动汽车 vs 燃油车 碳排放"
2. 搜索"电动汽车电池污染"
3. 搜索权威机构研究报告
4. 交叉验证各方说法

**输出示例**：
```
## 事实核查报告：电动汽车 vs 燃油车环保性

### 结论摘要
电动汽车的环保优势取决于[条件]。

### 已证实事实 ✓
- 电动汽车在使用阶段零尾气排放 [来源1]
- 电动汽车全生命周期碳排放平均比燃油车低[XX]% [来源2]

### 需要考虑的因素
- 电力来源：如果电网主要使用煤电，优势减小 [来源3]
- 电池生产阶段的碳排放较高 [来源4]
- 电池回收问题仍在发展中 [来源5]

### 来源可信度评估
- [来源1]: 权威机构 ✓
- [来源2]: 学术研究 ✓
- [来源3]: 行业报告 △（需多源验证）
```

## 搜索优化技巧

### 关键词组合
- 使用引号精确匹配："exact phrase"
- 使用减号排除：electric car -toyota
- 使用OR扩大范围：battery OR lithium
- 使用site:限定来源：site:gov OR site:edu

### 来源优先级
1. **最高**：政府网站 (.gov)、学术机构 (.edu)
2. **高**：知名媒体、权威研究机构
3. **中**：专业媒体、行业报告
4. **参考**：博客、论坛、社交媒体（需交叉验证）

## 常见陷阱

1. **确认偏误**：只搜索符合预期观点的信息
2. **过时信息**：未注意信息发布的时间
3. **单一来源**：依赖单一信息源
4. **权威谬误**：认为来自权威网站的信息必然正确
5. **数据误读**：曲解原始数据的含义
