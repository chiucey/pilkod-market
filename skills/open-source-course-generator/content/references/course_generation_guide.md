# 开源项目教程生成详细指南

## 1. 项目分析方法论

### 1.1 初步扫描阶段

**必须执行的操作**：
1. 使用 `Glob` 获取项目文件树
2. 识别 `package.json`、`setup.py`、`Cargo.toml` 等配置文件
3. 确定项目根目录和源码目录结构
4. 识别入口文件（`index.js`、`main.py`、`main.go` 等）

**输出模板**：

```
项目名称: [从 package.json 或目录名获取]
项目类型: [Web应用/库/CLI工具/SDK/框架]
主要语言: [JavaScript/Python/Go/etc]
源码目录: [src/ 或 lib/ 或项目根目录]

目录结构:
[使用树形结构展示关键目录]

主要依赖:
[从配置文件提取的关键依赖]
```

### 1.2 深度分析阶段

**分析维度**：

1. **架构设计**
   - 采用的设计模式（MVVM/MVC/组件化/函数式等）
   - 模块划分和职责分配
   - 数据流向

2. **核心模块**
   - 按重要性排序的核心模块列表
   - 每个模块的功能说明
   - 模块间的依赖关系

3. **关键代码路径**
   - 主执行流程
   - 核心算法和数据结构
   - 重要配置项

### 1.3 代码理解技巧

**理解陌生代码的步骤**：
1. 从入口文件开始
2. 追踪关键函数调用链
3. 理解数据结构和转换
4. 识别外部依赖的使用方式
5. 总结模块职责

## 2. 课程设计原则

### 2.1 课程结构设计

**通用课程模板**：

```
第一部分：环境与准备（1-2节）
├── 第1节：项目介绍与环境搭建
└── 第2节：项目结构与源码概览

第二部分：核心概念（按模块数量决定节数）
├── 第3节：[模块A]基础使用
├── 第4节：[模块A]实现原理
├── 第5节：[模块B]基础使用
└── ...

第三部分：实战与扩展
├── 进阶用法
├── 扩展开发
└── 最佳实践

第四部分：总结
└── 知识回顾与学习路径
```

**节数确定规则**：
- 小型项目（< 10个核心文件）：5-8节
- 中型项目（10-50个核心文件）：8-15节
- 大型项目（> 50个核心文件）：15-25节

### 2.2 单节课内容模板

```markdown
## 第X节：[精确的课程标题]

### 学习目标
- 预期学习成果1
- 预期学习成果2
- 预期学习成果3

### 前置知识
- 需要了解的概念或技能

### 理论知识（500-1000字）
[包含以下元素]：
- 问题背景：为什么需要这个知识
- 核心概念：清晰的定义和解释
- 原理说明：如何工作的
- 示例说明：通过例子加深理解

### 源码解析

#### 源码文件：[相对路径/文件名]

```[语言]
[完整可运行的代码片段]
```

**代码说明**：
- 第X行：[功能说明]
- 第Y行：[关键逻辑解释]

### 实践练习

**练习1：基础练习**
- 任务描述
- 实现提示
- 预期结果

**练习2：进阶练习**
- 任务描述
- 实现提示

### 本节小结
- 关键点1
- 关键点2
- 关键点3

### 延伸学习
- 相关资源链接
- 深入阅读建议
```

## 3. 代码准确性保证

### 3.1 代码引用规则

**必须遵守**：
1. 每个代码片段必须标注来源文件
2. 代码必须与源码完全一致
3. 禁止简化或省略关键逻辑
4. 对于过长的代码，可以分段展示，但必须说明是源码的哪一部分

**代码块标记**：
```markdown
```[语言] filename="src/xxx/yyy.js"
// 代码内容
```
```

### 3.2 代码验证清单

- [ ] 代码与源码完全一致
- [ ] 缩进格式正确
- [ ] 注释与代码对应
- [ ] 导入路径正确
- [ ] 语法正确可运行

### 3.3 常见问题处理

**问题1：代码过长**
- 拆分为多个代码块
- 每个块有独立的说明
- 保持代码逻辑连贯

**问题2：多处引用的代码**
- 首次出现完整展示
- 后续引用标注"接上"
- 说明复用位置

**问题3：复杂的依赖关系**
- 使用图表辅助说明
- 分步骤展示调用链
- 提供简化示例

## 4. 分块输出策略

### 4.1 分块触发条件

当单次输出预估超过以下限制时启用分块：
- 预估token数 > 8000
- 包含超过3个代码块
- 章节内容预计超过2000字

### 4.2 分块格式规范

**标准分块格式**：

```
[BLOCK_START:章节编号/总章节数]
# 课程标题

## 第一部分标题

### 第1节标题
[内容...]

### 第2节标题
[内容...]

[BLOCK_END:章节编号/总章节数]

---
**请回复"继续"或"next"查看下一部分内容**
---
```

### 4.3 分块执行流程

1. 首次输出：课程大纲 + 第一部分内容
2. 用户确认后继续
3. 循环直到完成所有内容
4. 最终输出汇总说明

### 4.4 上下文保持

每块开始时：
- 简要回顾进度
- 说明即将学习的内容
- 提示前置知识

## 5. 初级开发者友好原则

### 5.1 术语处理

- 首次出现专业术语时提供解释
- 使用类比帮助理解抽象概念
- 提供术语中英文对照

### 5.2 代码可读性

- 避免过于简洁的代码
- 添加详细的中文注释
- 解释每一行的作用
- 突出关键逻辑

### 5.3 学习曲线控制

- 从简单到复杂
- 每个概念都有足够的铺垫
- 提供足够的实践机会
- 及时总结和回顾
