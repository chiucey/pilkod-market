# 开源项目教程生成器

## 核心功能

分析开源项目代码结构，生成完整、准确的教程课程大纲和详细内容。

## 工作流程

### 阶段1：项目分析与理解

1. **扫描项目结构**
   - 使用 Glob 工具获取项目文件结构
   - 识别主要编程语言和框架
   - 确定项目类型（Web应用、库/SDK、CLI工具等）

2. **分析核心代码**
   - 阅读关键入口文件和配置文件
   - 理解项目架构和模块划分
   - 识别核心功能和模块依赖关系

3. **生成项目分析报告**
   - 项目概述（名称、用途、技术栈）
   - 目录结构说明
   - 核心模块分析
   - 依赖关系图

### 阶段2：课程大纲设计

1. **确定课程目标**
   - 目标受众：初级入门开发人员
   - 学习成果预期
   - 课程难度梯度

2. **设计课程结构**
   - 基础入门篇（环境搭建、项目运行）
   - 核心概念篇（主要模块和功能）
   - 进阶实践篇（高级用法、扩展开发）
   - 总结回顾篇

3. **输出课程大纲**
   - 章节数量：根据项目复杂度决定（5-20节）
   - 每节包含：标题、目标、内容概要

### 阶段3：详细内容编写

**重要约束**：
- 所有代码示例必须来自实际源码
- 禁止编造或简化代码
- 保持代码与源码100%一致
- 确保初级开发者能够理解

**分块输出策略**：
当内容超过上下文限制时，采用以下策略：
1. 按章节分块输出
2. 每块包含完整的单节课内容
3. 使用明确的块标记：`[BLOCK_START:n]` 和 `[BLOCK_END:n]`
4. 用户确认后继续下一块

### 阶段4：内容验证

1. **代码验证**
   - 确保所有代码片段与源码一致
   - 标记代码来源文件路径
   - 验证代码可运行性

2. **内容完整性检查**
   - 课程覆盖所有核心功能
   - 无遗漏重要模块
   - 逻辑顺序合理

## 输出格式

### 课程大纲格式

```markdown
# [项目名称] 完整教程

## 课程概述
- 目标受众：初级开发人员
- 前置知识：...
- 学习时长：...

## 课程大纲

### 第一篇：基础入门
1. [第1节] 课程标题 - 简短描述
2. [第2节] 课程标题 - 简短描述
...

### 第二篇：核心概念
...
```

### 单节课格式

```markdown
## 第X节：[课程标题]

### 学习目标
- 目标1
- 目标2

### 理论知识
[详细的概念解释]

### 代码实现
[完整的、可运行的代码，标注来源文件]

### 实践练习
[巩固学习的练习题]

### 本节小结
[关键知识点回顾]
```

## 分块输出机制

当检测到输出将超过合理长度时，自动启用分块：

```
[BLOCK_START:1/10]
# 第一篇 基础入门

## 第1节：...
[内容...]
[BLOCK_END:1/10]

---

**请确认继续下一节内容，输入"继续"或"next"**

[BLOCK_START:2/10]
## 第2节：...
[内容...]
[BLOCK_END:2/10]
```
