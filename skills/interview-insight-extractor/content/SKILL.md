# 用户访谈洞察提取器

## 技能概述

将用户访谈原始记录转化为结构化、可行动的洞察报告。支持单份访谈独立分析和多份访谈合并综合洞察，自动融合知识库背景信息。

## 输入要求

### 必需输入
- **原始逐字稿**：访谈的完整文字记录
- **研究员整理纪要**：结构化的访谈摘要
- **飞书文档连接**：通过飞书 API 读取源文档和写入输出

### 知识库输入（自动获取）
- 项目背景资料
- 产品策略文档
- 历史研究报告
- 相关历史访谈洞察

## 执行流程

### 阶段 1：输入解析
1. 读取飞书文档获取原始逐字稿
2. 读取研究员整理的纪要
3. 识别受访者编号和基本信息

### 阶段 2：知识库预检索
1. 自动查询有权限的知识库文档
2. 提取项目背景、产品策略、历史研究相关内容
3. 建立"已知假设/结论"清单

### 阶段 3：单份洞察提取
1. **用户目标提取**
   - 识别受访者表达的核心目标
   - 区分显性目标和隐性目标
   - 标注置信度和出现频次

2. **痛点分析**
   - 分类：功能痛点、体验痛点、流程痛点、情绪痛点
   - 标注严重程度和频次
   - 关联到具体目标和场景

3. **行为模式识别**
   - 识别典型使用路径
   - 标注习惯性行为和例外行为
   - 发现潜在需求模式

4. **机会点发现**
   - 基于痛点推导
   - 基于未满足需求识别
   - 基于行为模式洞察

5. **建议动作生成**
   - 对应每个机会点
   - 标注优先级和预期影响
   - 保持可执行性

### 阶段 4：知识库融合
1. **背景关联**
   - 将访谈内容与知识库背景关联
   - 标注关联强度

2. **一致性/冲突分析**
   - 比对访谈信号与历史结论
   - 判定关系：一致、冲突、补充、矛盾
   - 给出差异判断说明

3. **融合机会点**
   - 结合知识库支撑和访谈验证
   - 生成综合评级

4. **验证问题清单**
   - 识别需要深挖的冲突点
   - 提供验证建议

### 阶段 5：合并综合洞察
1. **跨访谈聚合**
   - 统计各洞察的出现频次
   - 识别共识和分歧
   - 汇总痛点图谱和机会点优先级

2. **综合判断**
   - 给出整体置信度评估
   - 识别数据缺口

### 阶段 6：输出生成
1. 生成 X 份单份洞察文档
2. 生成 1 份合并综合洞察文档
3. 输出到飞书指定文件夹

## 置信度评估标准

| 评级 | 标准 | 说明 |
|------|------|------|
| 高 | 单点确认 + 多处佐证 + 行为观察 | 置信度高，建议直接行动 |
| 中 | 单点确认 + 部分佐证 | 需补充验证，建议进一步访谈 |
| 低 | 单一来源 + 无行为佐证 | 建议谨慎对待，需扩大样本 |

## 冲突处理规则

1. **自动查询**：每次执行自动查询有权限的知识库
2. **并列展示**：将访谈信号与知识库结论并列展示
3. **差异判断**：明确标注"一致/冲突/补充/矛盾"
4. **建议处理**：针对冲突点给出验证或深入建议

## 飞书集成说明

### 输入文档格式
- 飞书文档（支持 Markdown 格式）
- 逐字稿：纯文本或带时间戳格式
- 纪要：结构化文档

### 输出位置
- 在输入文档同目录下创建 `洞察输出` 文件夹
- 单份洞察：`洞察报告-[受访者编号].md`
- 合并洞察：`综合洞察报告-YYYYMMDD.md`

## 质量保障

- 每条洞察必须附带原话摘录
- 出现频次统计基于关键词和语义双重识别
- 知识库融合采用相关性阈值过滤（>0.3）
- 冲突判定需要明确证据支撑
