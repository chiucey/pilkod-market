# 设计案例对比

## 封面设计对比

### ❌ 错误示范：白色背景 + 多元素堆砌
```
标题（14pt灰色）+ 副标题 + 多个图标 + 装饰线条 + 公司logo + 背景图
```

### ✅ 正确示范：深色背景 + 单一焦点
```
┌─────────────────────────┐
│                         │
│    大标题（36pt白色）    │
│                         │
│    副标题（18pt灰色）    │
│                         │
└─────────────────────────┘
```

## 数据页对比

### ❌ 错误示范：饼图 + 密集数据
- 饼图显示5个以上分类
- 每个扇区标注小字号百分比
- 图例在底部，字号10pt
- 背景五颜六色

## 排版对比

### ❌ 错误示范：缺乏层次
```
标题：年度报告总结（16pt）
正文：2023年我们取得了优异的成绩...（12pt灰色）
      在各个方面都有显著提升...（12pt灰色）
图表：图1.1 （10pt）
```

### ✅ 正确示范：层次分明
```
【主标题】年度业绩亮点（32pt粗体）

【数据卡片】数字突出显示（48-72pt）

【正文】简洁描述（16pt）

【来源】脚注小字（12pt灰色）
```
