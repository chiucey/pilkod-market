# 期货走势分析技能

## 核心能力

本技能提供全面的期货市场分析服务，包括：
- 多品种走势技术分析
- 市场环境综合研判
- 趋势预测与情景分析
- 风险提示与交易建议

## 工作流程

### 第一步：品种与时间范围确认

当用户提供分析需求时，首先明确：
- 分析的期货品种（如螺纹钢、铜、原油、黄金等）
- 分析的时间范围（短期/中期/长期）
- 是否有特定的技术指标偏好

**数据获取**：
1. 使用股票工具获取期货品种相关数据
2. 搜索最新期货市场新闻和分析报告
3. 提取权威机构的研报内容

### 第二步：技术分析

执行以下技术分析：

```
1. 趋势分析
   - 价格走势（上涨/下跌/震荡）
   - 均线系统（MA5/MA20/MA60）
   - 趋势线与通道分析

2. 动能指标
   - RSI相对强弱指标
   - MACD指标（快线/慢线/柱状图）
   - 随机指标KDJ

3. 支撑阻力
   - 历史支撑/阻力位
   - 布林带轨道分析
   - 斐波那契回撤位

4. 成交量分析
   - 成交量与价格背离
   - 持仓量变化
   - 资金流向
```

### 第三步：市场环境分析

结合当下宏观环境进行分析：

```
1. 宏观因素
   - 货币政策走向
   - 经济增长预期
   - 通货膨胀水平

2. 产业因素
   - 供需格局变化
   - 库存周期
   - 产能利用率

3. 政策因素
   - 行业政策调整
   - 进出口政策
   - 环保政策影响

4. 外部市场
   - 国际市场联动
   - 汇率波动影响
   - 地缘政治因素
```

### 第四步：趋势预测

基于以上分析，给出预测：

```
1. 情景分析
   - 乐观情景：突破关键阻力后的目标位
   - 中性情景：震荡区间内的运行区间
   - 悲观情景：跌破支撑后的下行空间

2. 时间窗口
   - 短期（1-4周）走势预判
   - 中期（1-3月）趋势判断
   - 关键转折点提示

3. 概率评估
   - 各情景发生的概率分布
   - 核心驱动因素识别
```

### 第五步：风险提示与建议

```
1. 风险因素
   - 主要风险点识别
   - 风险等级评估（高/中/低）

2. 操作建议
   - 入场点位建议
   - 止损点位设置
   - 持仓管理策略

3. 注意事项
   - 需关注的重要数据/事件
   - 止损/止盈建议
```

## 输出格式

### 完整分析报告结构

```
## 一、品种概述
- 基本信息（代码、交易所、合约乘数）
- 近期行情回顾

## 二、技术面分析
### 2.1 趋势判断
### 2.2 关键支撑阻力位
### 2.3 技术指标解读

## 三、市场环境分析
### 3.1 宏观面影响
### 3.2 产业供需分析
### 3.3 政策面对比

## 四、趋势预测
### 4.1 短期预测（1-4周）
### 4.2 中期预测（1-3月）
### 4.3 情景概率分布

## 五、风险提示与操作建议
### 5.1 主要风险点
### 5.2 交易建议
### 5.3 关注事项
```

## 数据来源

- 实时行情数据：通过股票数据工具获取
- 市场新闻：网络搜索最新期货资讯
- 分析研报：权威机构研究报告
- 宏观数据：经济指标数据库

## 注意事项

1. **免责声明**：分析仅供参考，不构成投资建议
2. **时效性**：市场变化快，需结合实时信息判断
3. **风险控制**：始终强调止损和仓位管理
4. **多空思维**：同时提供多空双方的逻辑分析
