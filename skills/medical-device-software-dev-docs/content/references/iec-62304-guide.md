# IEC 62304 医疗器械软件生命周期过程指南

## 概述

IEC 62304:2006+AMD1:2015 是医疗器械软件生命周期过程的标准，定义了软件开发、维护和风险管理的要求。

## 核心章节

### 第4章 - 过程概述
- 软件开发过程
- 软件维护过程
- 软件风险管理过程

### 第5章 - 软件开发过程

#### 5.1 软件开发策划
**要求**:
- 制定软件开发计划
- 建立软件安全分类
- 确定软件开发过程

#### 5.2 软件需求分析
**要求**:
- 分析软件需求
- 建立软件需求规格
- 建立需求追溯性

#### 5.3 软件架构设计
**要求**:
- 定义软件系统结构
- 定义软件项
- 建立软件项之间的接口
- 支持软件安全要求

#### 5.4 软件详细设计
**要求**:
- 为每个软件项设计详细规格
- 定义软件单元

#### 5.5 软件单元实现与验证
**要求**:
- 实现软件单元设计
- 验证软件单元

#### 5.6 软件集成与集成测试
**要求**:
- 集成软件项
- 验证集成软件

#### 5.7 软件系统测试
**要求**:
- 执行系统测试
- 验证软件与系统需求一致

#### 5.8 软件发布
**要求**:
- 确认软件准备就绪
- 发布软件

## 软件安全分类

| 分类 | 定义 | 过程要求 |
|------|------|----------|
| A类 | 不会导致伤害 | 基础过程 |
| B类 | 可能导致非严重伤害 | 基础过程 + 标准过程 |
| C类 | 可能导致严重伤害或死亡 | 基础过程 + 标准过程 + 增强过程 |

## 与其他标准的关系

```
IEC 62304
    ├── ISO 14971 (风险管理)
    ├── IEC 62304 AMD1 (网络安全补充)
    ├── ISO 13485 (质量管理体系)
    └── 区域法规
        ├── FDA 21 CFR Part 820
        ├── EU MDR 2017/745
        └── NMPA 医疗器械法规
```

## 关键术语

| 术语 | 定义 |
|------|------|
| Software Item (软件项) | 可独立配置的软件的集合 |
| Software System (软件系统) | 由一个或多个软件项组成 |
| SOUP (含未知来源的软件项) | 商业现货软件、开源软件 |
| Unit (软件单元) | 软件项的最小可测试元素 |
