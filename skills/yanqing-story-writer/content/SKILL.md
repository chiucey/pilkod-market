# 言情小说创作技能

本技能用于创作符合知乎盐选小说风格的言情短篇小说，具备逻辑自洽的情节和爽文特性。

## 核心原则

### 1. 盐选小说风格特点
- **开篇即爆点**：前三句话必须制造冲突或悬念，直接抓住读者
- **节奏紧凑**：每800-1200字一个小高潮，每章至少一个爽点
- **情绪共鸣**：精准把控读者情感，在虐与甜之间制造张力
- **反转设计**：意料之外又在情理之中的情节反转

### 2. 情节逻辑要求
- 人物行为动机必须合理
- 事件发展符合因果关系
- 背景设定自洽统一
- 伏笔要有回收

### 3. 爽文特性
- **逆袭感**：主角从困境中翻盘
- **打脸**：打脸反派或看不起主角的人
- **甜宠**：主角之间的甜蜜互动
- **复仇**：正义得到伸张
- **金手指**：主角拥有独特优势

## 小说类型与模板

### 现代言情

**适用场景**：都市背景、职场生活、校园恋爱、现代婚姻

**结构模板**：
```
开篇(冲突/悬念) → 背景交代 → 矛盾升级 → 真相揭露 → 甜蜜结局/虐后甜
```

**常用元素**：
- 豪门总裁/落魄千金
- 青梅竹马/久别重逢
- 合约恋爱/先婚后爱
- 破镜重圆/追妻火葬场
- 复仇虐渣/逆袭打脸

### 古代言情

**适用场景**：宫斗宅斗、江湖武侠、穿越重生、仙侠奇缘

**结构模板**：
```
穿越/重生开场 → 身份揭露 → 权谋斗争 → 真相大白 → 圆满结局
```

**常用元素**：
- 穿越女/重生女手撕白莲花
- 王爷/将军追妻
- 宫斗宅斗
- 医毒双绝/全能嫡女
- 冷面阎王化为情深

### 未来幻想言情

**适用场景**：星际/末世/赛博朋克、AI/机器人、异世界、异能

**结构模板**：
```
异世界设定 → 危机/相遇 → 能力觉醒 → 逆袭翻盘 → 双宿双飞
```

**常用元素**：
- 末世生存/丧尸危机
- 星际联邦/机甲战士
- 异能觉醒/天赋异禀
- 人机恋/AI伴侣
- 异世界冒险/异族之恋

## 创作流程

### 步骤1：确认创作类型与核心设定

**必问信息**：
- 小说类型（现代/古代/未来幻想）
- 主角身份设定
- 主线冲突类型（爱情/复仇/职场/逆袭）
- 结局偏好（甜/虐/虐后甜）

### 步骤2：构建人物设定

| 角色 | 设定要素 |
|------|----------|
| 女主 | 身份背景、性格特点、独特能力/金手指、成长弧线 |
| 男主 | 身份背景、性格特点、与女主的羁绊、前期误解 |
| 配角 | 功能定位（助攻/反派/炮灰）、与主角的关系 |

### 步骤3：设计情节结构

**爽文节奏设计**：
1. **起**：开篇即冲突，主角陷入困境或遭遇不公
2. **承**：矛盾升级，遭遇打压但暗中积蓄力量
3. **转**：真相揭露/能力展示，反转开始
4. **合**：逆袭成功，收获爱情与尊严

**每章必备要素**：
- 至少一个期待点（读者想知道后续的内容）
- 至少一个爽点（让读者感到满足的内容）
- 至少一个钩子（引导读者继续读下去）

### 步骤4：撰写正文

**开篇公式**：
```
"如果+身份+遭遇+极端情境"
示例："如果一个被全家嫌弃的落魄千金，突然发现自己是首富唯一的继承人……"
```

**打脸公式**：
```
轻视 → 嘲讽 → 隐藏实力 → 关键时刻出手 → 众人震惊 → 打脸完成
```

**甜宠公式**：
```
暗中关心 → 欲言又止 → 细节展示 → 误会被动触发 → 真相大白 → 甜蜜告白
```

### 步骤5：审核与优化

**自检清单**：
- [ ] 开篇是否在3句话内制造冲突？
- [ ] 每800-1200字是否有小高潮？
- [ ] 反派是否有足够的戏份来衬托主角？
- [ ] 爽点是否足够密集？
- [ ] 伏笔是否有回收？
- [ ] 结局是否符合读者期待？
