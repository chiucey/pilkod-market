# 现代言情模板与案例

## 豪门总裁类

### 经典开局模板
```
"如果一个被净身出户的落魄千金，突然被告知自己是首富唯一的继承人……"
或者
"如果一个被迫签下卖身契的穷学生，发现自己的新婚妻子是全球首富……"
```

### 情节要素
1. **身份反差**：落魄身份 vs 隐藏显贵身份
2. **男主初始态度**：冷漠/厌恶 → 好奇/关注 → 心动
3. **打脸场景设计**：
   - 亲戚嘲讽 → 身份揭露 → 众人震惊
   - 前男友炫耀 → 女主逆袭 → 前男友后悔
   - 婆家轻视 → 女主展现实力 → 婆婆态度转变

### 甜蜜互动桥段
- 霸总暗中保护但不说明
- 被迫同住产生的暧昧
- 公开场合霸气护妻
- 误会解除后的深情告白

## 青梅竹马/久别重逢类

### 经典开局模板
```
"如果那个十年前不告而别的初恋，突然出现在自己的婚礼上……"
或者
"如果从小一起长大的邻家哥哥，成了自己的上司……"
```

### 情节要素
1. **分离原因**：误会/被迫/家庭变故
2. **重逢场景**：尴尬/敌对 → 回忆涌现 → 情感挣扎
3. **虐心设计**：
   - 一方有对象，一方单身
   - 家人反对
   - 误以为对方无情

### 甜宠桥段
- 小时候的回忆杀
- 重逢后的暗中照顾
- 追妻火葬场
- 双向奔赴的告白

## 合约恋爱/先婚后爱类

### 经典开局模板
```
"如果被迫和一个陌生人领证结婚，婚后才发现对方是商业帝王……"
或者
"如果为了还债不得不假装成别人的女朋友，结果假戏真做……"
```

### 情节要素
1. **合约设定**：时间限制/附加条件/隐藏条款
2. **日常暧昧**：被迫同住/亲密接触/假装恩爱
3. **转折点**：一方先动心 → 另一方后知后觉 → 追妻

### 爽点设计
- 合约期间的心动瞬间
- 第三方出现引发的醋意
- 合约结束时的挽留
- 公开关系时的霸气宣言

## 破镜重圆/追妻火葬场类

### 经典开局模板
```
"如果那个曾经抛弃我的男人，五年后跪在我面前求我回头……"
或者
"如果离婚后的我，突然发现前夫是隐藏的超级富豪……"
```

### 情节要素
1. **分手/离婚原因**：误会/背叛/被迫/看不清真心
2. **重逢状态**：女主已经逆袭/男主追悔莫及
3. **虐点设计**：
   - 男主试图挽回但女主冷淡
   - 男主发现女主有了追求者
   - 回忆对比造成的心理冲击

### 逆袭设计
- 女主事业有成
- 女主身边出现优质追求者
- 女主掌握了男主的把柄/秘密
- 男主发现自己仍爱女主

## 复仇虐渣类

### 经典开局模板
```
"如果前世被绿茶婊害得家破人亡，重生后我该如何复仇……"
或者
"如果那个抢走我一切的继妹，知道她的一切都是偷来的吗……"
```

### 情节要素
1. **前世/被陷害的冤屈**：必须足够惨才能激发爽感
2. **复仇计划**：步步为营/借力打力/暗中布局
3. **打脸节奏**：小打脸 → 中打脸 → 大打脸 → 完美收官

### 金手指设计
- 重生带来的先知优势
- 隐藏身份/实力
- 神秘盟友/后台
- 特殊技能/才华

### 反派智商分级
- **青铜反派**：低级陷害，容易被揭穿
- **白银反派**：有一定心机，需要主角智取
- **王者反派**：伪装完美，最终靠男主联手击败

## 快速创作检查清单

### 开篇必检（3句话内）
- [ ] 第一句制造冲突或悬念
- [ ] 主角困境明确
- [ ] 读者想知道后续

### 节奏必检（每800字）
- [ ] 有小高潮或爽点
- [ ] 有期待点（钩子）
- [ ] 情节有推进

### 打脸必检
- [ ] 反派嘲讽在前
- [ ] 主角隐忍/暗中准备
- [ ] 关键时刻逆袭
- [ ] 围观群众震惊

### 甜宠必检
- [ ] 有暧昧互动
- [ ] 有宠溺细节
- [ ] 有真情流露

### 结尾必检
- [ ] 核心冲突解决
- [ ] 感情线圆满
- [ ] 有彩蛋或番外钩子
