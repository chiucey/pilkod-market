# 古代言情模板与案例

## 穿越重生类

### 经典开局模板
```
"如果穿越成古代不受宠的嫡女，面对继母和继妹的陷害，我该如何绝地反击……"
或者
"如果重生到一切悲剧发生之前，这一次我一定要改变命运……"
```

### 穿越女逆袭要素
1. **原身困境**：被欺负/被轻视/被陷害
2. **穿越金手指**：现代知识/医毒技能/商业头脑/上帝视角
3. **打脸节奏**：小试牛刀 → 崭露头角 → 一鸣惊人

### 重生复仇设计
- **前世惨状**：被害死/家破人亡/被辜负
- **今生优势**：知道未来/识破阴谋/提前布局
- **复仇对象**：继母/继妹/渣男/恶婆婆
- **复仇方式**：以其人之道还治其人之身

## 宫斗宅斗类

### 经典开局模板
```
"如果一个不受宠的庶女，被迫嫁入皇宫成为最不起眼的答应……"
或者
"如果嫁入侯府第一天就被婆婆立规矩，面对一群虎狼亲戚，我该如何自保……"
```

### 宫斗核心要素
1. **生存法则**：隐忍/借力/站队/留后手
2. **晋升路线**：答应 → 美人 → 嫔妃 → 贵妃 → 皇后
3. **必备技能**：察言观色/借刀杀人/化险为夷

### 宅斗核心要素
1. **家族势力**：公婆/叔伯/姑嫂关系
2. **嫁妆争夺**：嫡庶之争/聘礼风波
3. **子嗣问题**：生儿子/养孩子/嫡庶之别

### 打脸设计
- 白莲花假面被揭穿
- 陷害反噬自身
- 皇上/王爷霸气护妻
- 最终母仪天下

## 王爷将军追妻类

### 经典开局模板
```
"如果那个冷面阎王般的战神王爷，为了追妻甘愿放弃兵权……"
或者
"如果逃婚被抓回，被告知我只是他的冲喜新娘，现在要变成他的心头好……"
```

### 男主类型设定
- **冷面王爷**：外冷内热，只对女主温柔
- **战神将军**：杀伐果断，唯独对女主束手无策
- **腹黑帝王**：城府深沉，却为女主一再破例

### 追妻火葬场要素
1. **虐点设计**：误会/伤害/错过/被迫分离
2. **追妻方式**：卑微挽回/霸气抢人/默默守护
3. **反转时刻**：女主发现男主真心/男主追到追妻现场

### 甜宠桥段
- 王爷亲手喂药/梳发
- 将军战场传思念
- 霸总为她放弃一切
- 竹马变夫君的日常甜蜜

## 医毒双绝/全能设定

### 经典开局模板
```
"如果我不仅是相府真千金，还是神医谷传人，医毒双绝……"
或者
"如果穿越女不仅会现代医学，还带着一个随身的灵泉空间……"
```

### 技能展示设计
1. **医术展示**：救人/解毒/针灸/外科手术
2. **毒术展示**：揭穿阴谋/以其人之道/反杀反派
3. **其他技能**：做饭/制香/琴棋书画/武功

### 打脸场景
- 被质疑是废物 → 当众救人/解毒
- 被嘲笑没有嫁妆 → 拿出绝世珍宝
- 被陷害下毒 → 反手揭穿下毒者
- 医术比御医还强 → 皇帝刮目相看

## 仙侠奇缘类

### 经典开局模板
```
"如果一个废柴修仙者，不仅契约了上古神兽，还被三个大佬争着收徒……"
或者
"如果跌落悬崖不仅没死，还获得了上古传承，开启逆天修仙路……"
```

### 修炼设定
- **等级体系**：炼气 → 筑基 → 金丹 → 元婴 → 化神
- **金手指**：上古传承/逆天资质/神秘师父/神兽契约
- **必备元素**：天才流/废柴逆袭/师门争斗/资源争夺

### 仙侠甜宠
- 高冷师父为我破例
- 天才师兄暗中守护
- 魔尊为我不惜叛出魔道
- 几世轮回终相遇
