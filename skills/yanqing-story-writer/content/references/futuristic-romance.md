# 未来幻想言情模板与案例

## 末世生存类

### 经典开局模板
```
"如果丧尸爆发，我不仅觉醒了治愈系异能，还意外获得了随身空间……"
或者
"如果末世降临，我带着前世的记忆重生，这一次我要活下去，还要保护那个人……"
```

### 末世设定要素
1. **末世背景**：丧尸爆发/病毒侵袭/资源枯竭/文明崩塌
2. **异能体系**：力量/速度/治愈/空间/精神/预知
3. **生存法则**：资源争夺/团队协作/人性考验

### 女主机甲设定
- **治愈系异能**：稀缺珍贵，被各方势力争夺
- **随身空间**：物资储备/种植养殖/秘密基地
- **特殊血脉**：上古传承/神兽血脉/外星基因

### 爽点设计
- 在丧尸群中救出高冷男主
- 物资丰富让众人羡慕
- 治愈能力被追捧
- 异能进阶秒杀众人

### 甜宠桥段
- 末世中的相互依靠
- 危机时刻的舍命相护
- 高冷男主为她破例
- 一起建立末世家园

## 星际联邦类

### 经典开局模板
```
"如果我是流落民间的皇室血脉，不仅被接入皇宫，还被指定嫁给最年轻的星将……"
或者
"如果穿越到星际时代，不仅成了废物召唤师，还意外契约了sss级神兽……"
```

### 星际设定要素
1. **世界观**：星际联邦/帝国/共和国多足鼎立
2. **战斗体系**：机甲/战舰/异能/精神力
3. **等级制度**：平民/贵族/皇室/贵族分等

### 女主逆袭设计
- **隐藏身份**：皇室血脉/古老传承/特殊体质
- **逆天能力**：sss级召唤/逆天精神力/全系异能
- **打脸节奏**：被嘲笑 → 能力觉醒 → 震惊全场

### 男主设定
- **星将/元帅**：冷酷霸道，战功赫赫
- **皇子/王储**：身份尊贵，只对女主例外
- **星际海盗/神秘强者**：亦正亦邪，深情专一

### 星际甜宠
- 机甲里的私密空间
- 星战中的守护
- 皇宫中的霸气护妻
- 宇宙级别的心意表达

## 赛博朋克类

### 经典开局模板
```
"如果在这个被财团控制的赛博城市，我不仅是一名黑客，还是唯一能破解主脑的人……"
或者
"如果在这个记忆可以买卖的时代，我的记忆被偷走，却发现偷走我记忆的人是我的雇主……"
```

### 赛博设定要素
1. **科技元素**：人工智能/神经网络/义体改造/虚拟现实
2. **社会问题**：贫富差距/财团控制/数据隐私/意识上传
3. **视觉风格**：霓虹灯光/高楼林立/雨夜氛围

### 女主设定
- **黑客身份**：自由黑客/地下组织成员
- **特殊能力**：神经入侵/数据操控/记忆提取
- **隐藏背景**：财团叛逃者/失落AI的创造者

### 甜宠元素
- 赛博空间的二人世界
- 义体改造中的亲密接触
- 虚拟现实中的告白
- 霓虹灯下的浪漫

## 人机恋/AI伴侣类

### 经典开局模板
```
"如果我买回家的智能管家突然觉醒了自我意识，还说他已经爱我十年……"
或者
"如果那个被设定为完美男友的AI，实际是一个被封印意识的人类灵魂……"
```

### 人机设定要素
1. **AI设定**：家务型/陪伴型/战斗型/情感型
2. **意识觉醒**：渐进觉醒/突然觉醒/被迫觉醒
3. **情感纠葛**：程序设定 vs 真实感情

### 冲突设计
- 人类与AI的感情是否正当
- AI的自我意识归属问题
- 财团对AI的追捕
- 人类身体的限制/突破

### 甜宠桥段
- AI的程序性宠溺 vs 真实感情
- 跨维度的爱情
- 意识数据的备份与保存
- 打破人与AI的界限

## 异世界冒险类

### 经典开局模板
```
"如果穿越到剑与魔法的异世界，我不仅召唤出了sss级精灵王，还被他追求……"
或者
"如果误入异世界，被魔兽掳走，结果成了魔兽王的王后……"
```

### 异世界设定要素
1. **世界观**：剑与魔法/异族林立/古老预言
2. **种族体系**：人类/精灵/兽人/龙族/魔族
3. **冒险元素**：魔法学院/公会任务/勇者选拔/魔王战争

### 女主设定
- **穿越者优势**：现代知识/特殊魔法/召唤能力
- **隐藏身份**：古老家族/神族血脉/预言中的勇者
- **逆天技能**：全系魔法/SSS召唤兽/神级炼金

### 男主类型
- **精灵王/精灵族长**：高冷长寿，只对女主心动
- **魔兽王/龙族首领**：霸道强大，占有欲强
- **勇者/骑士团长**：正义热血，光明属性

### 异世界甜宠
- 不同种族间的文化冲突与融合
- 跨越种族的爱情
- 异世界的冒险中加深感情
- 共同对抗魔王/拯救世界
