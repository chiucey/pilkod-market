# 粤语翻译技能

## 核心能力

将普通话句子翻译成粤语（广东话），并标注标准粤语拼音读音。

## 工作流程

### 1. 接收用户输入
- 获取普通话句子
- 识别需要翻译的内容

### 2. 粤语翻译转换
应用以下翻译规则：

| 普通话 | 粤语 | 读音（粤拼） |
|--------|------|-------------|
| 你好 | 你好 / 早晨 | nei5 hou2 / zou2 san4 |
| 谢谢 | 多谢 | do1 ze6 |
| 对不起 | 唔好意思 | m4 hou2 yi3 si3 |
| 不知道 | 唔知 | m4 zi1 |
| 什么 | 咩 | me1 |
| 为什么 | 點解 | dim2 gaai2 |
| 吃饭了吗 | 食咗饭未 | sik6 zo2 faan6 mei6 |
| 我不知道 | 我唔知 | ngo5 m4 zi1 |
| 今天 | 今日 | gam1 yaat6 |
| 明天 | 聽日 | ting1 yaat6 |
| 昨天 | 琴日 | kam4 yaat6 |

### 3. 常用词汇映射

**人称代词：**
- 我 → 我 ngo5
- 你 → 你 nei5
- 他/她 → 佢 keoi5
- 我们 → 我哋 ngo5 dei6
- 你们 → 你哋 nei5 dei6
- 他们 → 佢哋 keoi5 dei6

**常用动词：**
- 是 → 係 hai6
- 有 → 有 yau5
- 没有 → 冇 mou5
- 做 → 做 zou6
- 吃 → 食 sik6
- 喝 → 飲 yam1
- 看 → 睇 tai2
- 说 → 話 wa6 / 講 gong2
- 知道 → 知 zi1 / 識 sik1

**语气词：**
- 吗 → 嗎 maa1 / 呀 aa1
- 吧 → 啦 laa1
- 啊 → 呀 aa1 / 啊 aa3

### 4. 声调标注规则

粤语有9个声调，使用粤拼（Jyutping）标注：

| 声调 | 数字 | 例字 |
|------|------|------|
| 高平 | 1 | 夫 fu1 |
| 高升 | 2 | 扶 fu2 |
| 高降 | 3 | 苦 fu3 |
| 中平 | 4 | 科 fo1 |
| 低升 | 5 | 扶 fu5 |
| 低降 | 6 | 裤 fu6 |
| 高入 | 7 | 福 fuk1 |
| 中入 | 8 | 服 fuk6 |
| 低入 | 9 | 缚 fuk6 |

### 5. 输出格式

```
【普通话】
用户输入的原句

【粤语翻译】
翻译后的粤语文字

【读音标注】
每个字的粤拼读音，数字表示声调
```

## 示例

**输入：** "你好，谢谢你"

**输出：**
```
【普通话】
你好，谢谢你

【粤语翻译】
你好，多謝你

【读音标注】
你(nei5) 好(hou2) ， 多(do1) 謝(ze6) 你(nei5)
```

**输入：** "你吃饭了吗？"

**输出：**
```
【普通话】
你吃饭了吗？

【粤语翻译】
你食咗饭未呀？

【读音标注】
你(nei5) 食(sik6) 咗(zo2) 饭(faan6) 未(mei6) 呀(aa1)
```

**输入：** "我不知道他在哪里"

**输出：**
```
【普通话】
我不知道他在哪里

【粤语翻译】
我唔知佢喺邊度

【读音标注】
我(ngo5) 唔(m4) 知(zi1) 佢(keoi5) 喺(hai2) 邊(bin1) 度(dou6)
```

## 注意事项

1. **口语优先**：粤语翻译以口语为主，不必拘泥于书面语形式
2. **语气自然**：适当添加语气词使表达更自然
3. **声调准确**：严格按照粤拼标注声调
4. **无法翻译时**：对于没有固定粤语对应的词汇，使用近似表达或注明"无对应粤语"

## 质量标准

- 翻译准确性：确保核心意思传达正确
- 读音标准性：使用标准粤拼标注
- 表达自然性：符合粤语口语习惯
- 格式规范性：清晰分开展示原文、译文和读音
