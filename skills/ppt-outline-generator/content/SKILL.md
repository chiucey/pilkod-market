# PPT Outline Generator

## Core Capabilities

Generate professional PowerPoint presentation outlines with clear structure from topic, audience, and time constraints.

## Key Features

- **Outline Generation**: Topic + Audience + Duration → Cover + TOC + Content + Conclusion
- **Structure Planning**: Logical flow and narrative arc
- **Content Organization**: Key points, supporting details, examples
- **Time Management**: Appropriate slide count based on duration

## Workflow

### 1. Receive Requirements

**Required Information**:
- Topic: What is the presentation about?
- Audience: Who will view it? (e.g., executives, clients, students)
- Duration: How long is the presentation? (e.g., "15 minutes", "30 slides")

**Ask clarifying questions when needed**:
- "What's the main message you want to convey?"
- "Any specific sections or points to include?"
- "Is this for internal or external presentation?"

### 2. Output Structure

```
# [Topic] Presentation Outline

## Overview
- **Topic**: ...
- **Audience**: ...
- **Duration**: ...
- **Total Slides**: ...

---

## Slide 1: Cover
**Title**: [Main Title]
**Subtitle**: [Subtitle if needed]
**Visual**: [Suggested cover image/concept]

---

## Slide 2: Table of Contents
1. Introduction
2. Section A
3. Section B
4. Conclusion

---

## Slide 3: Introduction
- Hook/Opening statement
- Why this topic matters
- What audience will learn

---

## [Content Section 1]

### Slide X: Section Title
- Key point 1
- Key point 2

### Slide X+1: Details
- Supporting data/example
- Supporting data/example

---

## [Content Section 2]
...

## Slide N-1: Summary
- Recap of key points
- Main takeaways

## Slide N: Conclusion/CTA
- Call to action
- Contact/Next steps
- Q&A prompt
```

## Slide Count Guidelines

| Duration | Slides | Content/Slide |
|----------|--------|---------------|
| 5-10 min | 5-10 | 1-2 main points |
| 15-20 min | 10-15 | 2-3 main points |
| 30 min | 20-30 | 3-4 main points |
| 45-60 min | 30-40 | 4-5 main points |

## Audience Adaptation

| Audience | Style | Focus |
|----------|-------|-------|
| Executives | Data-driven, concise | ROI, outcomes |
| Clients | Benefit-oriented | Value proposition |
| Students | Educational, clear | Learning outcomes |
| Technical | Detailed, thorough | Specifications |
| General | Accessible, engaging | Common understanding |

## Structure Patterns

### The "What-Why-How" Pattern
1. What: Problem/Opportunity
2. Why: Significance/Impact
3. How: Solution/Steps

### The "Problem-Solution" Pattern
1. Current situation
2. Challenge/Gap
3. Proposed solution
4. Expected results

### The "Storytelling" Pattern
1. Hook (attention)
2. Journey (development)
3. Climax (key insight)
4. Resolution (takeaway)

### The "Comparison" Pattern
1. Option A analysis
2. Option B analysis
3. Option C analysis
4. Recommendation

## Quality Standards

1. **Logical Flow**: Clear progression from one point to next
2. **Audience-Focused**: Content relevant to viewers
3. **Balanced**: Not too dense or too sparse
4. **Actionable**: Ends with clear next steps
5. **Professional**: Suitable for business/educational use

## Slide Type Guidelines

| Slide Type | Purpose | Elements |
|------------|---------|----------|
| Cover | First impression | Title, subtitle, visual |
| TOC | Navigation | Numbered list |
| Content | Information delivery | Bullet points, images |
| Data | Evidence | Charts, statistics |
| Quote | Credibility | Large quote, attribution |
| Transition | Flow | Section title only |
| Summary | Reinforcement | Key takeaways |
| CTA | Action | Clear next step |
