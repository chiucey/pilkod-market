# 音乐提示词模板库

## 通用模板

### 模板1: 基础流行
```
[Adjective] [Genre] music, [Mood], [Tempo], featuring [Main Instrument], [Supporting Instruments], [Special Elements]
```

示例:
```
Upbeat pop music, happy and energetic, 120 BPM, featuring piano melody, with light drums, synth pads, perfect for summer vibes
```

### 模板2: 情绪驱动
```
[Emotion] [Genre] track, expressing [Specific Feeling], [Tempo], [Instrument Description], [Production Style]
```

示例:
```
Melancholic indie folk, expressing longing and nostalgia, slow tempo, fingerpicking guitar, reverb-drenched vocals, intimate bedroom production
```

### 模板3: 场景应用
```
[Scene/Use Case] music, [Genre], [Atmosphere], [Tempo], [Instrumentation], [Duration]
```

示例:
```
Coffee shop background music, jazz bossa nova, relaxed and warm, moderate tempo, nylon guitar, soft percussion, 3 minutes loop
```
