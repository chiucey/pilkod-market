# 上下文交接文档模板

按实际对话删减或扩展，不要保留没有信息量的空章节。凡是没有核验到的内容，必须标为“未核验”“不可恢复”或“不在交接范围内”。

```markdown
# {项目或任务名称}：{时间范围}对话上下文交接

> 生成日期：{YYYY-MM-DD}
> 用途：{例如交给新的 AI 继续开发、复核或恢复会话}
> 范围：收录第 {起始轮} 轮至第 {结束轮} 轮；不包含 {明确排除的元请求、当前整理请求或内部过程}。
