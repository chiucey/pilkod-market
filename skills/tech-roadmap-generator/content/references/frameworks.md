# Technical Roadmap Framework Details

## NSFC Framework Details

### NSFC-01: Basic Research

**Applicable Disciplines**: Math, Physics, Chemistry, Biology

**Framework Structure**:
```
Problem Identification → Literature Review → Theoretical Hypothesis → Experimental Design → Data Collection → Analysis & Verification → Conclusion Summary
```

**Core Characteristics**:
- Emphasizes theoretical exploration from phenomenon to essence
- Focuses on scientific rigor and reproducibility of experimental design
- Results require multi-angle verification

### NSFC-03: Technical Breakthrough

**Applicable Disciplines**: Information Technology, Automation

**Framework Structure**:
```
Research Goal → Technical Route → Scheme Design → System Implementation → Performance Testing → Outcome Application
```

**Core Characteristics**:
- Clear goals and explicit technical routes
- Emphasizes system implementation
- Focuses on performance metric verification

---

### NSFC-04: Interdisciplinary Innovation

**Applicable Disciplines**: Biomedical Engineering, Nanoscience

**Framework Structure**:
```
Method A from Discipline → ┐
                           ├→ Intersection Innovation Point → Integrated Method → Innovative Application
Method B from Discipline → ┘
```

**Core Characteristics**:
- Convergence of multi-disciplinary methods
- Emphasizes identification of innovation points
- Explores cross-border applications

---

### NSFC-05: Equipment R&D

**Applicable Disciplines**: Mechanical Engineering, Aerospace

**Framework Structure**:
```
Requirement Analysis → Scheme Design → Detailed Design → Manufacturing → Assembly & Debugging → Testing & Verification
```

**Core Characteristics**:

### NSFC-06: Method Innovation

**Applicable Disciplines**: Chemistry, Biology

### NSFC-08: Theoretical Modeling

**Applicable Disciplines**: Medicine, Pharmacy

## NSSFC Framework Details

### NSSFC-01: Empirical Research

**Applicable Disciplines**: Economics, Management

**Framework Structure**:
```
Theory Selection → Research Hypothesis → Research Design → Data Collection → Data Analysis → Hypothesis Testing → Conclusion
```

**Core Characteristics**:
- Hypothesis-testing oriented
- Primarily quantitative analysis
- Emphasizes causal relationships

---

### NSSFC-02: Case Study

**Applicable Disciplines**: Law, Education

**Framework Structure**:
```
Case Selection → Case Description → Problem Analysis → Comparative Analysis → Experience Summary → Policy Recommendations
```

**Core Characteristics**:
- In-depth analysis of single or multiple cases
- Focuses on situational analysis
- Emphasizes implications and significance

---

### NSSFC-03: Historical Research

**Applicable Disciplines**: History, Philosophy

**Framework Structure**:
```
Historical Source Collection → Historical Source Analysis → Historical Narrative → Historical Interpretation → Integration of History and Theory
```

**Core Characteristics**:
- Based on historical sources
- Emphasizes historical context
- Combination of objective narrative and subjective interpretation

---

### NSSFC-04: Policy Research

**Applicable Disciplines**: Public Administration, Sociology

**Framework Structure**:
```
Policy Problem → Policy Analysis → Policy Recommendation → Implementation Path → Effect Evaluation
```

**Core Characteristics**:
- Problem-oriented
- Emphasizes operability
- Focuses on feasibility of policy recommendations

---

### NSSFC-05: Field Survey

**Applicable Disciplines**: Anthropology, Ethnology

**Framework Structure**:
```
Field Site Selection → Field Entry → Participant Observation → In-depth Interview → Field Notes → Data Organization → Analysis & Writing
```

**Core Characteristics**:
- Long-cycle field work
- Emphasizes combination of emic and etic perspectives
- In-depth description and interpretation

---

### NSSFC-06: Comparative Study

**Applicable Disciplines**: Political Science, Literature

**Framework Structure**:
```
Comparison Object → Comparison Dimension → Descriptive Analysis → Comparative Analysis → Causal Explanation → Implications & Reference
```

**Core Characteristics**:
- Multi-case comparison
- Emphasizes comparability
- Focuses on interpretation of differences

---

### NSSFC-07: Quantitative Research

**Applicable Disciplines**: Psychology, Sociology

**Framework Structure**:
```
Literature Review → Research Hypothesis → Questionnaire Design → Pilot Survey → Formal Survey → Data Analysis → Model Testing
```

**Core Characteristics**:
- Questionnaire/scale as primary tools
- Statistical model analysis
- Emphasizes scale reliability and validity

---

### NSSFC-08: Qualitative Research

**Applicable Disciplines**: Education, Nursing

**Framework Structure**:
```
Research Problem → Research Subject → Data Collection → Open Coding → Axial Coding → Selective Coding → Theory Construction
```

**Core Characteristics**:
- Grounded theory oriented
- Emphasizes theoretical saturation
- Inductive theory generation

---

### NSSFC-09: Action Research

**Applicable Disciplines**: Education, Management

**Framework Structure**:
```
Problem Identification → Action Planning → Action Implementation → Effect Observation → Reflection & Improvement → (Cyclical Iteration)
```

**Core Characteristics**:
- Practice-oriented
- Emphasizes reflection and improvement
- Spiral upward progression

---

### NSSFC-10: Literature Review

**Applicable Disciplines**: Library Science, Information Science

**Framework Structure**:
```
Literature Search → Literature Screening → Bibliometric Analysis → Thematic Analysis → Comprehensive Review → Research Prospect
```

**Core Characteristics**:
- Systematic literature review
- Combination of bibliometric and content analysis
- Emphasizes identification of research gaps

---

## General Design Principles

### Color Coding Standards
- **Start Node**: Green (#d5e8d4)
- **End Node**: Green (#82b366)
- **Main Process**: Blue (#dae8fc)
- **Decision/Branch**: Yellow (#fff2cc)
- **Key Outcomes**: Orange (#f8cecc)
- **Background**: White (#ffffff)

### Shape Usage Standards
- **Ellipse**: Start/End nodes
- **Rectangle**: General process/task
- **Rounded Rectangle**: Processing/Operation
- **Diamond**: Decision/Decision point
- **Hexagon**: Preparation/Input

### Connection Line Standards
- **Solid Arrow**: Main process flow
- **Dashed Arrow**: Information flow
- **Dotted Line**: Feedback/Iteration
- **Straight Line without Arrow**: Parallel relationship
