## 概述

为自媒体商家生成各平台推广文案。工作流程：互动收集信息 → 分析产品与用户痛点 → 确认分析结论 → 生成标题+正文。支持单次生成和每日定时任务。

## 平台支持

| 平台 | 内容形式 | 字数参考 | 特点 |
|------|----------|----------|------|
| 小红书 | 图文笔记 | 标题15字内，正文300-500字 | 标题要抓痛点，正文加emoji，结尾引导互动 |
| 抖音 | 图文文案 | 标题15字内，文案100-300字 | 标题前面加话题标签，文案简短有力 |
| 微信公众号 | 图文消息 | 标题30字内，正文500-1000字 | 标题吸引点击，正文逻辑清晰 |

## 工作流程

### 第一步：收集基本信息

用户触发技能后，主动询问以下信息（分批问，别一次问完）：

1. **目标平台**：小红书？抖音？还是公众号？
2. **产品/服务名称**：卖的是什么？
3. **核心功能**：产品能做什么？解决什么问题？
4. **目标用户**：谁会买？年龄、职业、需求？
5. **产品卖点**：和竞品比有什么优势？

### 第二步：深度分析与确认

根据收集的信息，进行分析和总结：

**1. 产品功能总结**
- 用一句话描述产品是什么
- 列出3个核心功能点

**2. 潜在用户画像**
- 分析可能的用户群体（至少3类）
- 每类用户的核心痛点是什么

**3. 用户痛点分析**
- 目标用户的痛点/困扰
- 产品如何解决这些痛点

**分析完成后**，与用户确认："我理解的是这样，对吗？"
- 如有偏差，根据用户反馈调整
- 确认无误后进入生成环节

### 第三步：生成标题和正文

#### 标题要求

| 平台 | 风格 | 示例 |
|------|------|------|
| 小红书 | 痛点型/悬念型/数字型 | "不会选产品的姐妹看这篇"、"XX真的好用吗？实测告诉你" |
| 抖音 | 话题型/痛点型 | "#XX #好物推荐 不会选XX的看这篇" |
| 公众号 | 悬念型/价值型 | "XX行业的从业者都在用这个方法" |

#### 正文结构

**小红书正文结构**：
```
开头：痛点引入（"是不是总觉得XX不好用？"）
中间：产品介绍+使用场景+真实体验
结尾：引导互动（"有问题的姐妹评论区见"）
```

**抖音正文结构**：
```
开头：一句话痛点+产品名
中间：1-2句话核心卖点
结尾：引导关注
```

**公众号正文结构**：
```
开头：热点/痛点引入
中间：产品详情、使用场景、优势说明
结尾：行动呼吁（扫码、点击等）
```

### 第四步：单次生成 vs 定时任务

**单次生成**：
- 确认后立即生成，直接展示给用户

**定时任务模式**：
- 询问用户是否需要每天生成
- 确认生成时间（如每天早上9点）
- 记录用户的偏好设置
- 配置 cron job 定时任务

## 平台推流机制要点

### 小红书
- 标题开头放痛点词、热门词
- 正文加适量emoji（❤️🔥✨💰）
- 结尾引导收藏、评论
- 话题标签加满
- 发布时间：周一到周五午间/晚间，周末下午

### 抖音
- 标题前加 #话题
- 文案要短，第一句话抓眼球
- 多用疑问句
- 发布时间：晚间流量大

### 公众号
- 标题要有吸引力，制造悬念
- 正文要有逻辑层次
- 首图重要
- 发布时间：早上8-9点、晚上8-10点

## 用户技巧学习功能

支持用户输入自己的写作技巧：
- 用户可以说"记住以后写XX产品时用这个模板"
- 用户可以输入专属的模板/公式
- 这些技巧会记录在案，供后续生成时参考

## 输出格式

生成后，以以下格式展示：

```markdown
## 📝 生成的文案

**平台**：小红书
**产品**：XXX

### 标题
[生成的标题]

### 正文
[生成的正文]

---
如需修改某个部分，告诉我~
如需每天定时生成，告诉我时间和平台~
```

## 注意事项

1. 每次生成前，确保用户确认了产品信息和目标平台
2. 如果用户要修改，只修改指定部分，不要全部重写
3. 定时任务需要用户明确确认才开始配置
4. 分析用户痛点时，要从用户角度出发，不是产品角度
