# 公文格式生成器

标准公文格式生成工具，基于《党政机关公文格式》国家标准（GB/T 9704-2012），适用于工作汇报、进展报告、情况说明等正式公文。

## 功能特点

- **标准字体配置**：方正小标宋简体（标题）、黑体（一级标题）、楷体_GB2312（二级标题）、仿宋_GB2312（正文）
- **规范页面设置**：标准页边距（上3.6cm、下3.5cm、左2.8cm、右2.6cm）
- **智能标点转换**：自动将半角标点转换为全角
- **混合字体处理**：中文使用中文字体，英文/数字使用Times New Roman

## 使用方法

### 方式一：提供完整信息

请提供以下信息，我会帮您生成标准公文格式文档：

```
标题：关于XXX的汇报
汇报单位：XXX公司/部门
日期：XXXX年XX月XX日（可选，默认今天）
正文内容：支持多级标题结构
```

### 方式二：提供已有文章

直接粘贴您的文章内容，我会自动识别标题结构并调整为标准公文格式。

## 标题层级说明

| 层级 | 格式示例 | 字体 | 说明 |
|------|----------|------|------|
| 一级标题 | 一、二、三... | 黑体，3号（16pt） | 主要章节 |
| 二级标题 | （一）（二）... | 楷体_GB2312，3号（16pt） | 子章节 |
| 三级标题 | 1. 2. 3... | 仿宋_GB2312加粗，3号（16pt） | 详细条目 |
| 正文 | 标准段落文字 | 仿宋_GB2312，3号（16pt） | 首行缩进2字符 |

## 格式规范

### 页面设置
- 纸张：A4
- 页边距：上3.6cm，下3.5cm，左2.8cm，右2.6cm
- 行距：固定值28磅

### 字体规范
- 标题：2号方正小标宋简体（22pt），居中
- 汇报单位/日期：3号楷体_GB2312（16pt），居中
- 正文：一级标题黑体，二级标题楷体，三级标题仿宋加粗，正文仿宋
- 英文/数字：Times New Roman

### 标点符号
自动转换半角标点为全角标点，符合公文规范。

## 示例

**输入示例**：
```
标题：关于近期工作进展的汇报
单位：江苏金服

一、工作进展
已完成各项准备工作...

（一）组织架构
设立四个职能部门...

二、下一步计划
加快推进项目实施...
```

**输出**：符合国家标准的Word公文格式文档

## 输出格式

生成的文档为`.docx`格式，可直接用Microsoft Word、WPS等软件打开编辑。
