# 公文格式规范参考

## 依据标准

本工具依据《党政机关公文格式》（GB/T 9704-2012）国家标准设计。

## 页面设置

| 项目 | 数值 |
|------|------|
| 纸张 | A4 (210mm × 297mm) |
| 上边距 | 3.6 cm |
| 下边距 | 3.5 cm |
| 左边距 | 2.8 cm |
| 右边距 | 2.6 cm |

## 字体与字号

### 正文字体

| 要素 | 字体 | 字号 | 说明 |
|------|------|------|------|
| 公文标题 | 方正小标宋简体 | 2号（22pt） | 居中，不加粗 |
| 秘密等级 | 黑体 | 4号（14pt） | 右上角 |
| 紧急程度 | 黑体 | 4号（14pt） | 左上角 |
| 发文机关标志 | 华文行楷/小标宋 | 红色，居中 | 上白边处 |
| 签发人 | 仿宋 | 3号（16pt） | 右对齐 |

### 正文字体

| 层级 | 字体 | 字号 | 特殊格式 |
|------|------|------|----------|
| 一级标题 | 黑体 | 3号（16pt） | 不加粗，如"一、" |
| 二级标题 | 楷体_GB2312 | 3号（16pt） | 不加粗，如"（一）" |
| 三级标题 | 仿宋_GB2312 | 3号（16pt） | 加粗，如"1." |
| 正文 | 仿宋_GB2312 | 3号（16pt） | 首行缩进2字符 |

### 数字与外文

- 数字：使用Times New Roman字体
- 英文：使用Times New Roman字体
- 外国人名、地名、机关名称等可用对应外文字体

## 段落格式

| 项目 | 数值 |
|------|------|
| 行间距 | 固定值28磅 |
| 段前间距 | 0 |
| 段后间距 | 0 |
| 首行缩进 | 2字符 |
| 正文字符间距 | 标准 |

## 标点符号

公文应使用**全角标点符号**：

- 句号：。
- 逗号：，
- 顿号：、
- 分号：；
- 冒号：：
- 引号：「」或""
- 括号：（）
- 书名号：《》
- 破折号：——
- 省略号：……
