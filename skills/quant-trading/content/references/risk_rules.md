# 风险控制规则设计指南

## 一、止损止盈规则

### 1.1 止损规则

#### 固定止损
**规则**：入场后设定固定百分比止损

| 交易品种 | 止损比例 | 说明 |
|---------|---------|-----|
| 股票 | 5-10% | 根据波动性调整 |
| 期货 | 2-5% | 高杠杆需严格 |
| 外汇 | 0.5-2% | 日内交易 |
| 加密货币 | 10-20% | 波动剧烈 |

#### ATR止损
**规则**：以ATR倍数设置止损

```
止损价位 = 入场价 - N × ATR

示例：
- 入场价：100元
- ATR(14)：2元
- ATR倍数：2
- 止损价：100 - 2 × 2 = 96元
```

**ATR倍数选择**：
| 市场特征 | ATR倍数 | 适用场景 |
|---------|---------|---------|
| 低波动 | 1.5-2.0 | 紧密止损 |
| 中波动 | 2.0-3.0 | 标准止损 |
| 高波动 | 3.0-5.0 | 宽松止损 |

#### 追踪止损
**规则**：随价格变动调整止损位置

| 类型 | 规则 | 特点 |
|-----|-----|-----|
| 固定比例追踪 | 最高价 × (1 - 固定比例) | 简单 |
| 移动ATR追踪 | 最高价 - N × ATR | 动态 |
| 阶梯追踪 | 价格每上涨X%调高止损 | 稳健 |

**追踪止损示例**：
```
初始止损：入场价 - 3%
追踪启动：盈利达到 5% 后启动追踪
追踪比例：锁定盈利的 50%

入场价：100元
盈利5%触发：价格涨至 105 元
后续最高价：115 元
追踪止损：115 × (1 - 50%) = 57.5元（无效）
→ 正确计算：105 + (115-105) × 50% = 110元
```

### 1.2 止盈规则

#### 固定止盈
**规则**：设定目标价位或比例

| 止盈类型 | 规则 | 适用场景 |
|---------|-----|---------|
| 固定比例 | 盈利达到 X% 止盈 | 短线交易 |
| 固定价位 | 价格达到目标位止盈 | 支撑阻力 |
| R比止盈 | 止盈 = 止损 × R倍数 | 盈亏比固定 |

#### 移动止盈
**规则**：随价格上涨逐步提高止盈

| 方法 | 规则 | 特点 |
|-----|-----|-----|
| 阶梯止盈 | 每涨X%调高目标Y% | 稳健 |
| 回撤止盈 | 从高点回撤Z%触发 | 锁定利润 |
| ATR止盈 | 价格 - N × ATR | 动态适应 |

## 二、仓位管理规则

### 2.1 固定仓位法

**规则**：每次交易使用固定仓位比例

```
仓位 = 总资金 × 固定比例

示例：
- 总资金：100,000元
- 固定比例：10%
- 单笔交易金额：10,000元
```

**优点**：风险可控
**缺点**：无法利用盈利机会

### 2.2 波动率仓位法

**规则**：根据ATR计算仓位

```
仓位 = 账户风险额 ÷ (入场价 - 止损价)
     = 总资金 × 风险比例 ÷ ATR倍数

示例：
- 总资金：100,000元
- 风险比例：2%
- ATR：2元
- ATR倍数：2
- 最大亏损：100,000 × 2% = 2,000元
- 止损距离：2 × 2 = 4元
- 仓位：2,000 ÷ 4 = 500股
```

### 2.3 金字塔加仓法

**规则**：盈利后逐步加仓

| 加仓次数 | 仓位递减 | 建议 |
|---------|---------|-----|
| 第1次加仓 | 100% | 原仓位 |
| 第2次加仓 | 50% | 减半 |
| 第3次加仓 | 25% | 再减半 |
| 第4次加仓 | 12.5% | 最小化 |

**规则**：
- 仅在盈利时加仓
- 每次加仓后调整整体止损
- 限制最大加仓次数（建议≤3次）

### 2.4 倒金字塔减仓法

**规则**：亏损时逐步减仓

```
首次减仓：亏损X%时减仓50%
二次减仓：再亏损X%时清仓
```

## 三、总风险控制规则

### 3.1 单品种仓位限制

| 风险偏好 | 单品种仓位上限 | 适用人群 |
|---------|--------------|---------|
| 保守 | 5-10% | 稳健型 |
| 平衡 | 10-20% | 平衡型 |
| 激进 | 20-30% | 激进型 |

### 3.2 总仓位限制

```
最大总仓位 = 总资金 × 仓位上限比例

示例：
- 总资金：100,000元
- 最大仓位：80%
- 最大持仓金额：80,000元
```

### 3.3 日内交易限制

| 规则 | 参数 | 说明 |
|-----|-----|-----|
| 日内最大亏损 | 总资金2% | 触发停止交易 |
| 日内最大交易次数 | 5-10次 | 控制频率 |
| 日内最大回撤 | 总资金3% | 熔断机制 |

### 3.4 连续亏损控制

| 连续亏损次数 | 仓位调整 |
|------------|---------|
| 2次 | 仓位减半 |
| 3次 | 仓位降至25% |
| 4次 | 暂停交易复盘 |
| 5次 | 策略暂停 |

## 四、风险预警指标

### 4.1 核心监控指标

| 指标 | 预警值 | 处理措施 |
|-----|-------|---------|
| 当日最大回撤 | > 3% | 停止开新仓 |
| 当周最大回撤 | > 5% | 仓位减半 |
| 月度回撤 | > 10% | 策略复盘 |
| 夏普比率 | < 1.0 | 优化或暂停 |

### 4.2 杠杆使用限制

| 市场 | 最大杠杆 | 说明 |
|-----|---------|-----|
| 股票 | 1-2倍 | 融资融券 |
| 期货 | 5-10倍 | 保证金制度 |
| 外汇 | 10-50倍 | 高杠杆 |
| 加密货币 | 2-5倍 | 建议低杠杆 |

### 4.3 相关性控制

**规则**：高相关品种不重复建仓

```
相关性阈值：> 0.7（高度相关）
处理方式：选择其中一个品种建仓
```

## 五、应急预案

### 5.1 极端行情应对

| 场景 | 应对措施 |
|-----|---------|
| 流动性枯竭 | 缩小止损、降低仓位 |
| 价格跳空 | 使用FOK/IOC订单 |
| 系统故障 | 设置手动止损线 |
| 市场中断 | 保持仓位不追加 |

### 5.2 回撤熔断机制

```
触发条件：回撤达到设定值
执行动作：
1. 停止开新仓
2. 平掉部分仓位
3. 等待市场稳定
4. 复盘后决定是否继续
```

### 5.3 定期检查清单

| 频率 | 检查内容 |
|-----|---------|
| 每日 | 持仓风险、当日盈亏 |
| 每周 | 回撤情况、胜率变化 |
| 每月 | 策略表现、综合评估 |
| 每季 | 策略优化、参数调整 |

## 六、合规与风控建议

### 6.1 核心原则

1. **永远设置止损**：每一笔交易都必须有止损
2. **单笔风险控制**：单笔亏损不超过总资金2%
3. **分散投资**：不把所有资金压在单一策略
4. **定期复盘**：每月评估策略有效性
5. **留有余地**：永远不要满仓操作

### 6.2 风控检查表

```
交易前检查：
□ 止损价位是否设定
□ 仓位是否符合规则
□ 单日亏损是否超限
□ 相关品种是否重复建仓

交易后检查：
□ 是否记录交易日志
□ 盈亏是否在预期内
□ 是否需要调整仓位
□ 策略是否需要复盘
```
