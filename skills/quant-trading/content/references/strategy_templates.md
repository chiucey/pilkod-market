# 量化策略模板库

## 1. 趋势跟踪策略

### 1.1 均线交叉策略

**策略逻辑**：
- 金叉买入（短期MA上穿长期MA）
- 死叉卖出（短期MA下穿长期MA）

**参数配置**：
| 参数 | 建议值 | 调优范围 |
|-----|-------|---------|
| 短期MA周期 | 20 | 5-30 |
| 长期MA周期 | 60 | 40-200 |
| 品种选择 | 高流动性 | - |

**示例规则**：
```
入场：MA20 上穿 MA60，且 ADX > 25
出场：MA20 下穿 MA60，或 追踪止损 3%
仓位：固定 10% 仓位
```

### 1.2 动量策略

**策略逻辑**：
- 价格上涨动量强劲时买入
- 价格下跌动量转弱时卖出

**参数配置**：
| 参数 | 建议值 | 调优范围 |
|-----|-------|---------|
| ROC周期 | 12 | 5-30 |
| 入场阈值 | > 5% | 3%-10% |
| 持仓周期 | 5-20天 | - |

### 1.3 海龟交易策略

**策略逻辑**：
- 价格突破20日高低点入场
- 价格反向突破10日高低点出场
- ATR计算仓位

**参数配置**：
| 参数 | 标准值 | 可调范围 |
|-----|-------|---------|
| 入场周期 | 20 | 15-30 |
| 出场周期 | 10 | 8-20 |
| 仓位单位 | 1 ATR | 0.5-2 ATR |

## 2. 均值回归策略

### 2.1 RSI均值回归

**策略逻辑**：
- RSI < 30 视为超卖，买入
- RSI > 70 视为超买，卖出

**参数配置**：
| 参数 | 建议值 | 调优范围 |
|-----|-------|---------|
| RSI周期 | 14 | 7-21 |
| 超卖阈值 | 30 | 20-35 |
| 超买阈值 | 70 | 65-80 |
| 持仓时长 | 5-10天 | - |

### 2.2 Bollinger Bands均值回归

**策略逻辑**：
- 价格触及下轨买入
- 价格触及上轨卖出
- 中轨作为目标位

**参数配置**：
| 参数 | 建议值 | 调优范围 |
|-----|-------|---------|
| 周期 | 20 | 10-30 |
| 标准差倍数 | 2.0 | 1.5-3.0 |
| 止损 | 2% | 1%-3% |

### 2.3 乖离率策略

**策略逻辑**：
- 价格偏离均线过大时回归
- 计算N日乖离率

**参数配置**：
| 参数 | 建议值 | 调优范围 |
|-----|-------|---------|
| MA周期 | 20 | 10-60 |
| 乖离率阈值 | ±5% | ±3%-±10% |
| 回归目标 | 0 | - |

## 3. 套利策略

### 3.1 配对交易策略

**策略逻辑**：
- 选择高度相关的两个品种
- 当价差偏离均值时，做空高估、做多低估
- 价差回归时平仓获利

**参数配置**：
| 参数 | 建议值 | 说明 |
|-----|-------|-----|
| 相关性阈值 | > 0.8 | 高度相关 |
| 协整周期 | 60 | 统计周期 |
| 入场Z-score | > 2.0 | 标准差倍数 |
| 止损Z-score | > 3.0 | 强制平仓 |

**示例规则**：
```
标的：A股票 和 B股票（行业相同）
协整检验：p值 < 0.05
入场：Z-score > 2.0（价差扩大）
出场：Z-score < 0 或 Z-score < 0.5
仓位：市场中性和对冲
```

### 3.2 跨期套利策略

**策略逻辑**：
- 同一品种不同到期月的价差交易
- 适用于期货、期权

**参数配置**：
| 参数 | 建议值 |
|-----|-------|
| 月差阈值 | 合理价差 ± 5% |
| 持仓周期 | 价差收敛 |
| 止损 | 20% |

## 4. 突破策略

### 4.1 区间突破策略

**策略逻辑**：
- 价格突破N日区间高点买入
- 价格跌破N日区间低点卖出

**参数配置**：
| 参数 | 建议值 | 调优范围 |
|-----|-------|---------|
| 区间周期 | 20 | 10-60 |
| 确认K线 | 1-2根 | - |
| 止损 | 2% ATR | 1%-3% |

### 4.2 趋势线突破策略

**策略逻辑**：
- 价格有效突破趋势线入场
- 回踩趋势线不破加仓

## 5. 复合策略

### 5.1 多周期共振策略

**策略逻辑**：
- 日线、4小时、1小时同向信号
- 多周期确认提高胜率

**参数配置**：
| 周期 | 指标 | 作用 |
|-----|-----|-----|
| 日线 | MA60趋势 | 方向确认 |
| 4小时 | MA20交叉 | 入场信号 |
| 1小时 | RSI超买超卖 | 精准入场 |

### 5.2 多指标共振策略

**策略逻辑**：
- 多个指标同时发出信号
- 避免单一指标假信号

**示例**：
```
买入信号：
- MA20 > MA60（趋势确认）
- MACD > 0（动量确认）
- ADX > 25（趋势强度）
- RSI 40-60（不超买）
```

## 策略选择指南

| 市场环境 | 推荐策略 | 原因 |
|---------|---------|-----|
| 趋势明确 | 趋势跟踪/突破 | 顺势获利 |
| 震荡整理 | 均值回归 | 高卖低买 |
| 相关品种分化 | 配对交易 | 价差收敛 |
| 波动率放大 | 突破/趋势 | 波动中趋势 |
