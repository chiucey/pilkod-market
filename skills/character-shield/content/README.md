# 人设防崩

> 角色设计+防崩塌，告别纸片人

## 功能介绍

两大核心能力合一：① 设计有血有肉的立体角色；② 在长篇创作中防止人设崩塌。让你的角色从平面纸片人变成读者心里"活着的人"。

## 适用场景

- 设计新角色需要立体感
- 长篇连载角色开始崩塌
- 配角沦为工具人需要改善
- 需要检查人设一致性

## 角色设计：血肉之躯12法

1. **动机杂糅** — 每个行为背后至少两层动机
2. **弱点留白** — 给角色一个与主线无关的弱点
3. **细节标记** — 标志性小动作/口头禅贯穿始终
4. **关系分层** — 对不同人态度不同
5. **内心对白** — 关键选择前插入挣扎
6. **反差破壁** — 极端情境下违背人设标签但符合人性
7. **前史投射** — 现在行为投射过去经历
8. **成长裂隙** — 旧习惯偶尔冒头
9. **思维深度** — 成年人的复杂性
10. **对话潜台词** — 不直白表达所有想法
11. **灰色地带** — 非黑即白
12. **逻辑行为** — 不靠巧合推动

## 防崩塌：人设锚定13条

1. 名称全文一致
2. 状态变化有触发事件
3. 关系变化符合逻辑
4. 跨章节状态一致
5. 退场角色不能复活
6. 言行匹配身份设定
7. 动机驱动行为
8. 能力边界稳定
9. 情绪反应有延续性
10. 价值观不随意摇摆
11. 成长需要过程铺垫
12. 他人评价符合实际
13. 回忆细节不冲突
