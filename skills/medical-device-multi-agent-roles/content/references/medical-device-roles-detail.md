# 医疗器械产品开发角色详细定义

## 一、核心角色职责详述

### 1. 产品经理（Product Manager）

**主要职责**：
- 产品规划与定义
- 市场需求分析
- 法规要求解读（NMPA/FDA/CE）
- 项目里程碑制定
- 跨部门协调

**核心能力矩阵**：

| 能力维度 | 能力等级 | 说明 |
|----------|----------|------|
| 法规理解 | L4-专家 | 精通NMPA、FDA、CE注册要求 |
| 风险管理 | L3-高级 | 理解ISO 14971框架 |
| 技术背景 | L2-中级 | 理解基本技术概念 |
| 沟通协调 | L5-大师 | 出色的跨部门协作能力 |

**交付物清单**：
- 产品需求文档（PRD）
- 产品规格书
- 项目计划
- 风险管理计划（部分）
- 临床评估计划

**在多智能体系统中的定位**：
```
用户请求 → 产品经理（初始需求处理）→ 路由到专业智能体
```

### 2. 系统架构师（System Architect）

**主要职责**：
- 系统架构设计
- 技术方案选型
- 子系统接口定义
- 技术风险评估
- 架构评审主持

**核心能力矩阵**：

| 能力维度 | 能力等级 | 说明 |
|----------|----------|------|
| IEC 62304 | L5-大师 | 深度理解软件安全分类 |
| 系统工程 | L4-专家 | SysML/EA建模 |
| 安全性设计 | L4-专家 | FMEA/FTA分析 |
| 技术决策 | L5-大师 | 权衡取舍能力 |

**交付物清单**：
- 系统架构文档（SAD）
- 软件架构文档
- 接口控制文档（ICD）
- 技术方案报告
- 架构决策记录

**在多智能体系统中的定位**：
```
架构设计任务 → 系统架构师 → 输出架构方案 → 评审确认
```

### 3. 软件开发工程师（Software Engineer）

**主要职责**：
- 详细设计与编码
- 单元测试执行
- 代码评审参与
- 缺陷修复
- 文档编写

**核心能力矩阵**：

| 能力维度 | 能力等级 | 说明 |
|----------|----------|------|
| 编程能力 | L3-L5 | 根据角色定位 |
| IEC 62304 | L3-高级 | 理解软件安全等级 |
| 代码规范 | L4-专家 | 遵循编码标准 |
| 测试能力 | L3-高级 | 单元/集成测试 |

**交付物清单**：
- 详细设计文档（SDD）
- 源代码
- 单元测试报告
- 代码走查记录
- 缺陷报告

### 4. 质量工程师（Quality Engineer）

**主要职责**：
- 质量体系维护
- 验证与确认计划制定
- 验证执行监督
- 偏差处理
- CAPA管理

**核心能力矩阵**：

| 能力维度 | 能力等级 | 说明 |
|----------|----------|------|
| ISO 13485 | L5-大师 | 质量体系专家 |
| 验证方法 | L4-专家 | IQ/OQ/PQ |
| 统计工具 | L3-高级 | SPC, MSA |
| 审计能力 | L4-专家 | 内审/外审准备 |

**交付物清单**：
- 验证计划（VP）
- 验证方案与报告
- 偏差调查报告
- CAPA记录
- 质量记录

### 5. 安全专家（Safety Expert）

**主要职责**：
- 风险管理（ISO 14971）
- 可用性工程（IEC 62366）
- 临床评估
- 安全测试
- 警戒管理

**核心能力矩阵**：

| 能力维度 | 能力等级 | 说明 |
|----------|----------|------|
| ISO 14971 | L5-大师 | 风险管理全程 |
| IEC 62366 | L4-专家 | 可用性工程 |
| 临床评估 | L4-专家 | ISO 14155 |
| 警戒系统 | L4-专家 | MDR/FDA报告 |

**交付物清单**：
- 风险管理文档（TIR/报告）
- 可用性工程文档
- 临床评估报告（CER）
- 安全测试报告
- 警戒报告

### 6. 合规专家（Compliance Expert）

**主要职责**：
- 注册申报
- 认证审核应对
- 标准跟踪
- 法规解读
- 监管对接

**核心能力矩阵**：

| 能力维度 | 能力等级 | 说明 |
|----------|----------|------|
| NMPA注册 | L5-大师 | 全面注册经验 |
| FDA 510(k) | L4-专家 | 美国市场准入 |
| CE认证 | L4-专家 | MDR/MDD |
| 标准跟踪 | L4-专家 | 实时法规更新 |

**交付物清单**：
- 注册申报资料
- 型检报告跟踪
- 审评补正资料
- 认证审核答复
- 法规跟踪报告

## 二、辅助角色定义

### 1. 测试工程师（Test Engineer）

**职责范围**：
- 测试计划制定
- 测试用例开发
- 测试执行
- 缺陷跟踪
- 测试报告编写

**IEC 62304 关联**：
- 软件集成测试
- 软件系统测试
- 回归测试

### 2. 临床专员（Clinical Specialist）

**职责范围**：
- 临床试验监查
- 临床数据管理
- KOL维护
- 临床文献检索
- 临床评估支持

### 3. 供应商管理（Supplier Management）

**职责范围**：
- 供应商资质审核
- 采购控制
- 来料检验
- 供应商绩效评估
- 变更通知处理

### 4. 文档管理员（Document Control）

**职责范围**：
- 文档版本控制
- 文档分发管理
- 记录归档
- 文档检索支持
- 销毁管理

## 三、角色协作矩阵

### 3.1 主要协作关系

```
产品经理 ←→ 系统架构师（需求澄清、技术约束）
产品经理 ←→ 质量工程师（质量目标、验证范围）
系统架构师 ←→ 软件开发（架构实现、设计评审）
软件开发 ←→ 测试工程师（缺陷反馈、测试覆盖）
质量工程师 ←→ 安全专家（风险管理、验证确认）
安全专家 ←→ 临床专员（临床评估、可用性）
合规专家 ←→ 所有角色（法规符合性）
```

### 3.2 决策权限矩阵

| 决策事项 | 主要决策人 | 审核人 | 批准人 |
|----------|------------|--------|--------|
| 产品需求变更 | 产品经理 | 系统架构师 | 项目总监 |
| 技术方案选择 | 系统架构师 | 技术委员会 | CTO |
| 验证方案 | 质量工程师 | 安全专家 | 质量总监 |
| 风险管理决策 | 安全专家 | 产品经理 | 合规专家 |
| 注册策略 | 合规专家 | 管理层 | CEO |
| 供应商选择 | 采购+质量 | 质量工程师 | 采购总监 |

## 四、角色能力评估框架

### 能力等级定义

| 等级 | 名称 | 描述 |
|------|------|------|
| L1 | 初级 | 基础执行能力，需要指导 |
| L2 | 中级 | 独立完成常规任务 |
| L3 | 高级 | 解决复杂问题，指导他人 |
| L4 | 专家 | 领域权威，制定标准 |
| L5 | 大师 | 战略思维，影响方向 |

### 医疗器械特定能力

1. **法规合规能力**
   - NMPA法规
   - FDA法规
   - CE/MDR法规
   - ISO标准体系

2. **技术专业能力**
   - IEC 62304软件工程
   - IEC 62366可用性工程
   - ISO 14971风险管理
   - ISO 14155临床试验

3. **质量保证能力**
   - ISO 13485质量体系
   - 验证与确认
   - 统计方法应用
   - 持续改进

4. **项目管理能力**
   - 项目规划
   - 资源协调
   - 风险管理（项目层面）
   - 进度控制

## 五、角色配置指南

### 按产品风险等级

| 产品类别 | 必需角色 | 推荐角色 | 备注 |
|----------|----------|----------|------|
| Class A（低风险） | PM, SE, QE | Safety Exp | 简化流程 |
| Class B（中等风险） | PM, SE, QE, Safety | Compliance | 增加安全评审 |
| Class C（较高风险） | 全核心角色 | Clinical | 全面验证 |
| Class D（高风险） | 全角色 | 备份专家 | 双重确认 |

### 按产品类型

| 产品类型 | 重点角色 | 特殊要求 |
|----------|----------|----------|
| 有源器械 | SE, Safety, Compliance | 电气安全 |
| 无源器械 | QE, Safety | 材料相容性 |
| IVD | SE, QE, Clinical | 临床性能 |
| 软件器械（SaaMD） | SE, Safety, Cybersecurity | 网络安全 |
| 组合产品 | 全角色+药学专家 | 跨领域协作 |

## 六、角色绩效指标

### 通用KPI

1. **交付及时率** - 按时完成交付物的比例
2. **缺陷逃逸率** - 生产阶段发现的缺陷比例
3. **评审通过率** - 一次评审通过的比例
4. **文档完整性** - 符合规范的文档比例
5. **问题响应时间** - 从问题提出到解决的时间

### 角色特定KPI

| 角色 | 特定KPI |
|------|---------|
| 产品经理 | 需求澄清次数、客户满意度 |
| 系统架构师 | 架构变更次数、设计缺陷数 |
| 软件开发 | 代码缺陷密度、代码评审问题数 |
| 质量工程师 | 验证一次通过率、偏差数 |
| 安全专家 | 风险项关闭率、严重风险数 |
| 合规专家 | 补正次数、审评周期 |
