# 领域匹配参考手册

## 关键词 → 领域映射表

### STEM（理工科）

**物理学**
- 关键词：量子、相对论、力学、电磁、热力学、光学、粒子、弦理论、暗物质、能量守恒
- 核心问题类型：自然现象解释、技术原理分析、材料特性

**化学**
- 关键词：分子、反应、催化剂、有机合成、酸碱、电化学、元素周期表、键能
- 核心问题类型：反应机理、物质转化、工艺优化

**生物学**
- 关键词：细胞、基因、进化、生态、蛋白质、DNA、RNA、代谢、光合作用
- 核心问题类型：生命现象、疾病机制、生态系统

**计算机科学**
- 关键词：算法、数据结构、机器学习、深度学习、神经网络、编程语言、操作系统、网络协议、数据库
- 核心问题类型：技术选型、性能优化、系统设计、AI原理

**数学**
- 关键词：代数、几何、概率、统计、微积分、拓扑、数论、优化
- 核心问题类型：模型构建、统计分析、逻辑推理

### HUM（人文社科）

**经济学**
- 关键词：供需、GDP、通货膨胀、货币政策、财政政策、博弈论、市场失灵
- 核心问题类型：经济现象分析、政策效果评估、投资决策

**心理学**
- 关键词：认知、情感、行为、动机、人格、发展心理学、社会心理学、心理咨询
- 核心问题类型：行为解释、情绪管理、人际关系

**社会学**
- 关键词：社会结构、文化、阶层、全球化、社会流动、群体行为、社会问题
- 核心问题类型：社会现象分析、群体行为预测

**哲学**
- 关键词：存在、意识、伦理学、形而上学、认识论、逻辑、价值论
- 核心问题类型：根本性问题探讨、伦理判断框架

**历史学**
- 关键词：朝代、文明、革命、现代化、全球化进程、历史事件、历史人物
- 核心问题类型：历史因果分析、当代问题溯源

### BUS（商学管理）

**战略管理**
- 关键词：竞争优势、SWOT分析、五力模型、战略定位、商业模式创新
- 核心问题类型：企业战略制定、竞争分析

**市场营销**
- 关键词：品牌、消费者行为、市场细分、4P、渠道、营销策略、数字营销
- 核心问题类型：市场进入、品牌建设、用户增长

**运营管理**
- 关键词：供应链、流程优化、质量管理、精益生产、库存管理
- 核心问题类型：效率提升、成本控制

**人力资源**
- 关键词：招聘、培训、绩效管理、领导力、组织发展、企业文化
- 核心问题类型：人才管理、组织建设

### TECH（科技互联网）

## 第一性原理拆解模板

### 问题分类框架

```
描述性（是什么）→ 解释性（为什么）→ 处方性（怎么办）
```

### 拆解问题层级

**第一层：现象描述**
- 观察到的是什么？
- 表面特征是什么？

**第二层：机制解释**
- 背后原理是什么？
- 关键变量有哪些？
- 因果链条如何？

**第三层：本质追问**
- 最基本的事实是什么？
- 不可简化的假设是什么？
- 核心矛盾是什么？

### 数据验证清单

- [ ] 数据来源是否权威？（政府统计、学术期刊、知名机构）
- [ ] 数据时效性如何？（近5年数据优先）
- [ ] 样本是否具有代表性？
- [ ] 是否存在数据偏差？
- [ ] 相关性 vs 因果性是否混淆？
- [ ] 是否遗漏关键变量？
