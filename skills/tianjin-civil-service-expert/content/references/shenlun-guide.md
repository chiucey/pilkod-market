# 申论备考指南

## 一、申论概述

### 考试形式
- 考试时间：150分钟
- 总分：100分
- 材料数量：5-6则材料，约6000-8000字

### 考试题型
1. 归纳概括题
2. 综合分析题
3. 提出对策题
4. 贯彻执行题
5. 文章写作题

## 二、各题型答题框架

### 1. 归纳概括题

**题型识别**
- 概括、总结、归纳、简述
- 原因、问题、影响、措施

**答题结构**
```
一、总括句（材料核心主题）
二、要点1：[核心词]+具体表述
三、要点2：[核心词]+具体表述
四、要点3：[核心词]+具体表述
```

**字数控制**
- 要求200字以内：写4-5个要点
- 要求300字以内：写5-6个要点
- 宁多勿少，踩点给分

### 2. 综合分析题

**题型分类**
- 解释型分析：谈理解、含义
- 评价型分析：评析、认识
- 启示型分析：启示、教益

**答题结构**
```
【亮明观点】材料中...，我认为...
【具体分析】
  1. 原因/背景：...
  2. 影响：...（积极/消极）
  3. 对策：因此/所以应...
【总结/升华】综上所述/总而言之...
```

### 3. 提出对策题

**识别词**
- 建议、措施、解决办法
- 如何做、怎样解决

**答题结构**
```
问题1+对策1
问题2+对策2
问题3+对策3
```

**对策来源**
1. 材料直接提取（权威观点、领导人讲话）
2. 经验推演（材料中的成功案例）
3. 问题反推（有这些问题就要解决）
4. 常识补充（普适性对策）

**常用对策领域**
- 制度建设
- 宣传教育
- 资金保障
- 人才队伍
- 科技支撑
- 监督执法

### 4. 贯彻执行题

**常见文种**
- 调研报告
- 汇报材料
- 倡议书
- 宣传稿
- 通知公告
- 发言稿

**通用结构**
```
【标题】
【称谓】（视文种而定）
【正文】
  一/（一）背景/目的
  二/（二）具体内容
  三/（三）倡议/号召（视文种）
【落款】
  单位
  日期
```

**宣传类特殊结构**
```
一、活动主题/背景
二、活动意义
三、具体内容安排
四、注意事项
```

### 5. 文章写作题

**题目类型**
- 命题作文：给定标题
- 半命题作文：给定主题词
- 话题作文：围绕话题自拟标题

**五段三分结构（推荐）**
```
第一段：引出主题+亮明观点
第二段：分论点1+论证
第三段：分论点2+论证
第四段：分论点3+论证
第五段：总结升华
```

**分论点设计**
- 并列式：意义/做法并列
- 递进式：由浅入深、由小到大
- 对比式：正反对比

**论证方法**
1. 举例论证：材料内+材料外
2. 道理论证：名言、政策、原理
3. 对比论证：正反对比
4. 比喻论证：生动形象

**开头写法**
- 转折式：好现象+问题+观点
- 引言式：名言+材料+观点
- 排比式：排比句+观点

**结尾写法**
- 总结回扣式
- 发出号召式
- 展望未来式

## 三、天津申论特色

### 热门考点
1. 京津冀协同发展
2. 滨海新区创新实践
3. 基层社会治理
4. 乡村振兴战略
5. 优化营商环境
6. 生态文明建设

### 材料特点
- 注重本地案例
- 紧跟国家政策
- 关注民生热点
- 强调务实导向

## 四、高分技巧

### 1. 审题技巧
- 问什么答什么
- 明确作答范围
- 注意字数限制
- 看清特殊要求（条理清晰、有逻辑等）

### 2. 材料阅读技巧
- 第一遍：通读，了解大意
- 第二遍：精读，标注要点
- 提炼关键词
- 合并同类项

### 3. 语言表达技巧
- 使用政府规范用语
- 多用动词和名词
- 避免口语化
- 善用关联词

### 4. 卷面要求
- 字迹工整清晰
- 格式规范
- 段落分明
- 不涂改或少涂改

## 五、常见问题与解决

### 问题1：要点找不到
**解决**：多练真题，培养敏感度；学会提取关键词

### 问题2：字数超限
**解决**：合并同类项；删除修饰词；精简表述

### 问题3：大作文跑题
**解决**：紧扣材料和题干；首段亮明总论点；每段扣题

### 问题4：时间不够
**解决**：控制每题时间；先做会的；留足作文时间（60分钟）

## 六、备考计划

### 基础阶段
- 学习基础理论
- 了解五大题型
- 每天精读1篇范文

### 强化阶段
- 真题精做精析
- 整理万能模板
- 积累高频规范词

### 冲刺阶段
- 全真模拟
- 背诵开头结尾模板
- 关注时政热点
