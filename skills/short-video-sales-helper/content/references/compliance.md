# 合规护栏（Compliance Guard）

> 带货脚本的**生命线**。带错字 = 限流/下架/账号封禁。
> 本文件是 Self-check 的**硬门**，不通过不能输出。
> 覆盖 4 平台：抖音 / 快手 / **视频号** / **小红书**。

---

## 一、广告法红线（4 平台通用，必须 0 命中）

### 极限词禁用（任何平台都查）
- **程度类**：最、第一、唯一、首个、首个、首个、No.1、TOP、极致、巅峰、顶级、国家级、顶级
- **范围类**：100%、绝对、万能、全网最低、全网最 XX、独家
- **夸张类**：碾压、吊打、完爆、秒杀、彻底、永远、永久
- **虚假承诺**：保证、承诺、立竿见影、一次就 X、轻松 X

**自检方法**：脚本输出后，Ctrl+F 搜以上关键词。**任何命中 → 改写或删除**。

### 功效宣称禁用（按品类差异化）
| 品类 | 禁用词 |
|---|---|
| 普通食品 | 治、防、消炎、杀菌、抗癌、抗病毒、增强免疫力、药用价值 |
| 普通化妆品 | 治、防、消炎、杀菌、生发、祛疤、医学美容、特效 |
| 服装/家居 | 抗菌、抗病毒、防辐射、治百病 |
| 3C/家电 | 节能 XX%、省电 XX%、延寿 XX 年（无检测报告） |
| 课程/服务 | 学会 XX、保过、保证收益、月入 XX 万 |

### 虚假对比禁用
- "碾压竞品"/"吊打 XX" → 改"我对比了 X 款，XX 这点更好"
- "比 XX 便宜 50%" → 改"官方价 199，限时 99"
- 无依据的"全网最低" → 改"目前看到的最低价"
- 自家产品 vs 同品类的具体型号 → **不指名道姓**

### 数据可证
| 数据类型 | 必须有来源 |
|---|---|
| 销量 "10万+" | 平台后台截图 / 第三方数据 |
| 好评率 "99%" | 真实统计 / 抽样 |
| 改善 "7 天" | 真实测试 / 报告 |
| 实验室数据 | 检测报告编号 |

**无来源数据 → 弱化为**：
- "据说 / 听说"（带不确定性）
- "实测 1 个月"（个人样本）
- "多数用户反馈"（群体主观）
- 直接删除

## 二、4 平台审核红线

### 平台 1：抖音 🔴（审核最严）
**易限流品类**：医疗 / 金融 / 减肥 / 丰胸 / 壮阳 / 增高 / 美容手术
**易限流行为**：
- 极限词（最、第一、100%）→ 限流甚至下架
- 站外引流（"加微信"、二维码）→ 立即限流
- 价格异常（"1 元秒杀"虚假宣传）→ 限流
- 医疗/金融承诺 → 高危
**字幕规则**：不要压在品牌 logo 上；不要全屏遮挡画面
**Bgm**：不要用未授权的流行歌曲（会下架）
**特殊提示**：抖音对"嘘"等小手势也会限流，需前置铺垫

### 平台 2：快手 🟡（接地气，禁忌略少）
**易限流品类**：医疗 / 金融 / 减肥 / 壮阳
**易限流行为**：
- 站外引流（"加微信"）→ 限流
- 未成年人相关 → 严禁
- 民族 / 宗教 / 政治 → 严禁
**风格特点**：老铁文化，方言 / 接地气更受欢迎
**字幕规则**：方言字幕 + 普通话字幕同时出现，转化更高

### 平台 3：视频号 🟢（微信生态，最严政治）
**易限流品类**：医疗 / 金融 / 减肥 / 增高 / 美容手术
**易限流行为**：
- 涉政 / 涉领导人 → 零容忍
- 涉黄 / 涉暴 / 涉毒 → 零容忍
- 谣言 / 阴谋论 → 严打
- 站外引流（诱导加微信）→ 限流
- 虚假养生 / 医疗 → 严打
**特殊规则**：
- 微信生态需遵守《微信外部链接内容管理规范》
- 视频号助手绑定需实名
- **不要诱导"加微信领取 XX"**（会被判定为站外引流）
**字幕规则**：字幕严禁压住品牌 logo 或右上角分享按钮

### 平台 4：小红书 🟡（软广标识最严）
**易限流品类**：医美 / 减肥药 / 丰胸 / 增高 / 金融
**易限流行为**：
- 软广**必须标识**：#广告 / #赞助 / 品牌合作 / 利益相关
- 医疗/金融承诺 → 严打
- 极限词 → 限流
- 站外引流（"加微信"）→ 限流
**软广标识规则**：
- 标题前加 `#广告` 或 `#赞助`
- 正文明确写"本笔记含商业推广"
- 否则被举报 → 下架笔记 + 扣信用分
**风格特点**：封面党 + 标题党 + 标签党，缺一不可
**封面要求**：第一眼要"颜值即正义"，产品露出要"高级感"

## 三、跨平台通用禁忌（任何平台都查）

### 严重违规（直接下架/封号）
- 涉政 / 涉领导人 / 涉国旗国徽
- 涉黄 / 涉暴 / 涉毒
- 民族分裂 / 宗教极端
- 未成年人不当内容
- 谣言 / 阴谋论
- 危险行为（未成年人模仿）

### 中度违规（限流）
- 极限词 / 虚假对比
- 医疗/金融承诺
- 站外引流
- 价格异常

### 轻度违规（流量受影响）
- 字幕压 logo
- 画质不清晰
- BGM 版权问题
- 标题党但内容不符

## 四、Self-check 新增 2 项硬门（必跑）

```
[ ] ⭐ 无广告法极限词（搜:最/第一/100%/碾压/吊打/秒杀/唯一/国家级/万能/绝对）
[ ] ⭐ 数据/对比有依据或已弱化为"据说/实测"（不允许无来源的"99%/10万+/7天改善"）
[ ] ⭐ 平台特定禁忌已检查（4 平台切换时分别跑一遍）
[ ] ⭐ 软广已标识（小红书必须 #广告 / #赞助）
```

**这 2-4 项不过 → 直接重做，不能用"其他项过了"来抵分**。

## 六、违规应急（如脚本已发但被限流）

1. **立即删除** 违规视频
2. **自查**：哪条规则触雷（用本文件 + 平台审核规则）
3. **改写**：按规则改写后重发
4. **记录**：进 `references/diagnosis-archive.md` 当案例归档（避免再犯）
