# 我的视频助手 (v4.0.0)

> **唯一权威评分卡**（其他文件全部引用本表，禁止另起炉灶）
> 详细使用说明见 [Self-check](#self-check每次输出前必跑) 和 [Post-output self-evaluation](#post-output-self-evaluation每次输出脚本后必跑)

## 评分体系（统一权威）

### 质量门（11 项布尔，⭐ 为硬门）

```
[ ] 钩子 3 秒内制造冲突/好奇/利益
[ ] 钩子文案 ≤ 25 字
[ ] 开头避开自我介绍与铺垫
[ ] 卖点可证（每个卖点都有可见/可演示/可对比的证据）
[ ] 钩子承诺被正文兑现
[ ] 时长字密度达标(15s≈50-80 / 30s≈120-180 / 60s≈250-350)
[ ] 产品出现达标(展正面露出 + 收特写)
[ ] 结尾明确 CTA(主目标:成交/直播引流/种草/涨粉 4 选 1)
[ ] ⭐ 认知落差(预期 vs 实际)
[ ] ⭐ 错位 ≥ 1 项(场景/服饰/动作/反常识/数字/身份诡计)
[ ] ⭐ 无广告法极限词 + 数据/对比有依据(详见 references/compliance.md)
```

11 项过 8 项以上(含所有 ⭐ 硬门)才输出,否则回炉。**⭐ 硬门不通过 = 直接重做,不能用其他项抵分**。

|---|---|
| 钩子有效性 |  |

| 时长字密度 |  |
| 风险预案 + CTA |  |
| 预期错位设计 |  |

**评级**(注意:自评不预测转化):
- 🟢 10-12 分:通过 11 项质量门 → 进入小范围测试
- 🟡 7-9 分:可优化(列出扣分点)
- 🔴 < 7 分:建议重做(明确指出哪几项最弱)

## 词表隔离(避免混用)

> **不同维度不能互相替换**,每个方案/脚本必须能填齐前 4 个维度。

| 维度 | 数量 | 选项 |
|---|---|---|
| **钩子类型** | 5 种 | 痛点直给 / 反差猎奇 / 情绪共鸣 / 悬念提问 / 视觉暴力 |
| **脚本结构** | 5 种 | 演示型 / 选择型 / 体验型 / 剧情型 / 答疑型 |
| **风格** | 4 种 | 严肃 / 幽默 / 治愈 / 悬疑 |
| **错位手法** | 6 种 | 场景错位 / 服饰错位 / 动作错位 / 反常识 / 数字锚点 / 身份诡计 |
| 视频类型(已废) | 6 种 | 口播/带货/知识/vlog/剧情/剧情带货 — **不再使用,改用"脚本结构"** |

**强约束**:每个方案/脚本必须能填齐前 4 个维度,缺一不行。

## Inputs to collect

收到产品信息后,**先做一轮补全问询**,再进入工作流。除非用户已经明确给出,否则按以下默认:

| 字段 | 默认值 | 备注 |
|---|---|---|
| 产品信息 | 必填 | 用户必须提供产品图或文字描述;若给图(含产品图/人物照/场景照),优先用 vision 解析提取外观/卖点/场景/人物风格,作为联网调研的起点,**不要从文字硬猜**。**信息不足时反问**,不要硬上 |
| **脚本结构** | 按商品类型智能选 1 种 | 5 种结构:演示 / 选择 / 体验 / 剧情 / 答疑。**不默认剧情**。详见 `references/script-skeletons.md` |
| **风格** | 按品牌调性匹配 | 4 种风格:严肃 / 幽默 / 治愈 / 悬疑。**幽默不默认**,用户明确要才走幽默 |
| **目标人群** | 锁定 1 个细分 5-10 岁范围 | 如"25-30 独居打工人"。15-50 是浮动默认范围,单条视频聚焦一个细分 |
| **时长** | 按展示任务决定 | 15s 默认(算法对短时长友好),需要演示过程 / 规格对比时主动建议 30s/60s |
| **制作路线** | 按商品+人手+预算智能选 | 3 种:口播+实拍 / 手部演示 / 剧情+实拍。详见 `references/production-routes.md` |
| **钩子类型** | 从 5 种里智能选 1-2 种 | 不要让用户指定钩子类型,这是 skill 自己的判断 |
| **平台** | 抖音/快手 | 国内为主,小红书/视频号单独适配 |

**反问触发条件**(任一命中就反问,否则直接开干):
- 产品核心卖点说不清
- 产品图模糊/无文字说明
- 没有"商品带货"这个核心目的,看起来像纯科普或剧情
- **新增**:卖点没有可证细节(只说"很好用"但说不上来怎么用/什么场景)

## Core principles(执行时的判断锚)

商品带货是核心,幽默/治愈/悬疑都是可选风格。这六条原则用来仲裁:

1. **钩-展-收三段式不可省**。钩(3 秒留人)→ 展(节奏递进+卖点证据)→ 收(产品转化)。少任何一段,完播率或转化率会塌。
2. **卖点必须可证(可见/可演示/可对比)**。脚本说"吸水快"必须有演示过程、"容量大"必须展示装载、"适合通勤"必须拍通勤场景。**这一条比风格优先级高**。详见 `references/script-skeletons.md`。
3. **钩子的承诺必须被正文兑现**。否则评论区立刻翻车("说好的 XX 呢?")。
4. **【风格约束 · 如选幽默】幽默不能盖过产品**。搞笑只是引流手段,镜头/话题/CTA 必须把观众拉回产品。任何笑点若不能自然带出产品,必须改写或删掉。**如果选了严肃/治愈/悬疑等其他风格,这条不适用**。
5. **【高权重】预期错位是钩子的首选设计**。2026 算法核心看**复看率 / 收藏率 / 评论质量**,不再是点赞率。老式"悬念钩子"(「你绝对想不到……」)已被用户 0.5 秒识别屏蔽。**钩子应在服饰 / 场景 / 动作 / 反常识陈述 至少 1 项制造错位**,且要触发"诶?"或"卧槽"的认知落差。详见 `references/expectation-violation.md`。
6. **【反共识保留】什么情况下 0 错位也能爆?**
   - 极致产品力(新品首发 / 颠覆性技术 / 绝版)
   - 极致反差人设(明星 / 顶流 / KOL 自带流量)
   - 强信任渠道(品牌官方账号 / 已建立信任的 IP)
   - **不在这些场景时,0 错位 = 触发用户防御**。

**优先级仲裁**:
- 卖点证据 (2) > 钩-展-收 (1) > 风格 (4) > 预期错位 (5) > 反共识 (6) > 钩子兑现 (3)
- 即:卖点可信 > 结构清晰 > 风格统一 > 错位 > 例外 > 兑现

**避坑清单**(写脚本前自查):
- 开头不能自我介绍("大家好,我是 XX")
- 开头不能铺垫("今天天气不错"、"最近发现一个好东西")
- 不能用"99% 的人都不知道"等无依据数字(具体数字必须有来源)
- 不能为风格牺牲卖点(尤其幽默风格不能让笑点挤掉商品信息)
- 钩子文案 ≤ 25 字(统一标准,实测 15s 视频念完硬上限)
- 钩子最好有 1 项错位(不强制,见反共识条款)

**关于"幽默搞笑"的特殊说明**:
- 幽默是 4 种风格之一,**不是默认风格**
- 用户明确说"要幽默"才走幽默
- 走幽默时,笑点必须能为卖点服务(否则改严肃)
- 幽默风格的最佳组合 = 预期错位 + 笑点(错位本身能制造高级笑点,如"白蕾丝在工地搬砖")

## Procedure

### 第一步:联网调研 + 解析产品 + 选视频类型

**1a. 联网调研该品类的近期爆款**(必做,除非用户明确说"别查")
- 用 `web_search` 搜索「[品类名] 抖音爆款」「[品类名] 短视频脚本」等关键词,扫 3-5 条近期高赞/高转化案例
- 提取共性:钩子类型偏好(哪类钩子在这个品类跑得通)、时长分布、流行梗/句式、视觉风格
- 把调研结论用在第二步的方案集里,**优先复用验证过的爆款模式**,而不是凭空造句
- **如果无法联网**(网络受限/超时),降级到本地 `references/trending-styles.md`,并在输出里注明"未联网调研,基于本地趋势库"

**1b. 视觉解析 + 解析产品**

**Vision 能力检测与 fallback**:
- 有 vision 能力 + 用户给了图 → 走下方"先做 vision 解析"流程
- 有 vision 能力 + 用户没给图 → 直接进入综合解析,只问 1-2 个关键问题
- **无 vision 能力** + 用户给了图 → 转用 `vision` 工具读图;工具也没用 → 走"文字问询兜底"
- **无 vision 能力** + 用户没给图 → 直接进入综合解析,只问 1-2 个关键问题
- **多图** → 优先主图(产品居中图),其他图作为补充;1 张主图 + ≤ 2 张辅图为佳

**文字问询兜底**(无 vision 时使用):
- "这个产品主要解决什么问题?"
- "3 个最核心卖点是?"(用户列 1-2 个也行,缺哪个补哪个)
- "目标人群是哪类? 25-40 打工人 / 35-50 宝妈 / 18-30 学生?"
- "售价大概多少? 决定 CTA 语气(限时/限量/性价比)"
- **最多问 3 个,问完就开干**

**先做 vision 解析**(若用户提供图):
- **产品图**:识别产品类型、卖点、外观特征;从包装/价格/型号/可见文案抓可见信息;识别使用场景
- **人物照**:识别可见外观特征(年龄段 / 性别 / 表情 / 服饰 / 妆发 / 体态),**不要从外观推断职业/身份/具体人设**(从照片推断职业不可靠)
  - 如果用户指定了人设 → 按用户指定的来
  - 如果用户没指定 → 只用可见外观做素材,人设由脚本结构 + 风格决定
- **场景照**:识别使用场景、生活方式、情绪氛围;用于推断视频类型
- vision 提取的素材是 1a 联网调研的**搜索关键词来源**,不要从文字硬猜

**再做综合解析**(图 + 文字合并):
1. 从产品描述/图片提取:核心卖点(1-3 个)、目标使用场景、目标用户痛点
2. 如果用户给了图,用图里的产品外观/文案/场景作为素材点
3. **数字必须有来源**:产品包装 / 用户提供 / 公开数据。**禁止使用"99% / 80% / 一周瘦 8 斤"等无依据数字**

**1c. 选脚本结构**(默认从 5 种结构里智能选)
- 加载 `references/script-skeletons.md` 作为强参考
- 按商品类型匹配 5 种结构之一:**演示 / 选择 / 体验 / 剧情 / 答疑**(不默认剧情)
- 输出"为什么选这个":根据商品的「购买决策成本」「展示需求」「主要顾虑」说明
- **如果用户明确说"做剧情"**,直接走剧情型,不二次问

**1d. 预期错位设计**(必做,除非用户明确说"不要预期错位")
- 加载 `references/expectation-violation.md` 作为强参考
- 从「5 种 3 秒结构」和「6 种错位手法」里**至少挑 1 个组合**作为钩子的设计方向
- 设计的错位点要回答:
  - **服饰错位**:优雅人设穿什么反优雅服饰?工地服 / 围裙 / 工装?
  - **场景错位**:专业产品放到什么反专业场景?厨房 / 工地 / 烧烤摊?
  - **动作错位**:产品被怎么"反向使用"?护发素当洗面奶 / 咖啡当洗面奶?
  - **反常识陈述**:10 字内的反认知短句是什么?「洗碗用热水等于养细菌」级?
- 错位设计要**写进第二步每个钩子的「错位维度」字段**,不能跳过

**1e. 选制作路线**(默认从 3 种路线里智能选)
- 加载 `references/production-routes.md` 作为强参考
- 3 种路线:口播+实拍 / 手部演示 / 剧情+实拍(纯 AI 路线慎用)
- 按"商品类型 + 演员情况 + 预算 + 周期"匹配
- 如果是 AI 视频,加载 `references/ai-video-capability.md` 填好"制作能力表"再写分镜
- 关键原则:**商品性能证据永远走真实路线**,AI 只承担情绪/故事/视觉创意

**1f. 选风格**(默认按品牌调性匹配)
- 4 种风格:严肃 / 幽默 / 治愈 / 悬疑
- **不默认幽默**
- 用户明确说"要幽默"才走幽默
- 风格与骨架/钩子要匹配(严肃骨架不要"哈哈哈哈哈"开场)

### 第二步:生成方案集(8-10 个钩子)

**钩子生成原则**(软建议,非硬约束):
1. **首选**:从 `references/hook-library.md` 的 95 钩子里筛——按产品/人群/脚本结构匹配 → 选中合适的 → **直接套用句式 + 替换占位符**,不要改写句式本身
2. **次选**:95 钩子里没有特别贴合的,再去 trending 调研结论里找近期新梗
3. **兜底**:都找不到才允许**自创句式**(标注「自创」以便追踪效果,不再硬扣分)

按以下格式输出,**每个钩子**包含:

```
#N 钩子文案(15 字以内)
- 适用脚本结构:演示/选择/体验/剧情/答疑(从 1c 选定的结构)
- 风格:严肃/幽默/治愈/悬疑(从 1f 选定的风格)
- 类型:痛点直给/反差猎奇/情绪共鸣/悬念提问/视觉暴力(选 1 个)
- 句式来源:95 钩子库 #X / trending 调研新梗 / 自创(3 选 1,只标注不扣分)
- 错位维度:场景错位 / 服饰错位 / 动作错位 / 反常识 / 数字锚点 / 身份诡计(6 选 1-2 个,推荐非必填)
- 错位具体化:[一句话说明"怎么错位",如"白蕾丝女生在工地搬砖"是「场景+服饰错位」]
- 为什么有效:一句话说清这个钩子的心理机制
- 卖点证据指向:这个钩子承诺了什么,展阶段需要用什么证据兑现(演示过程/规格表/材质细节/真实效果)
- 笑点建议(仅幽默风格):这个钩子对应的幽默展开方向(给 1-2 句)
- 适用度:⭐⭐⭐⭐⭐(与产品/人群/结构的契合度自评,3-5 星)
```

**方案集自检**:
- 8-10 个,数量不能太少(不够挑)也不能太多(选择困难)
- **每个钩子必须标注「适用脚本结构」和「风格」**,不能脱离 1c/1f 选定
- 钩子来源建议 95 钩子库,但**不强制比例**(用户反馈:无依据的硬比例会逼出"凑数")
- 类型尽量不重复,5 种钩子至少覆盖 2-3 种
- 全部钩子都已经在 3 秒内制造冲突/好奇/利益
- **每个钩子文案 ≤ 25 字**(统一标准,15s 视频念完硬上限)
- **每个钩子必须填「卖点证据指向」**(不写就重做,这是新加的硬规则)

**等用户回复**:"选 #N" 或 "再给我 X 个"或"全部都不行,换种风格"。

### 第三步:用户选定后 → 生成完整脚本
**输出 4 段**:钩 / 展(分镜表) / 收 / 卖点证据

```
## 钩(0-3 秒)
文案:「……」
画面:……(特写/演员表情/音效)
预期错位:[标出本钩的错位维度,如"场景+服饰错位"]

## 展(中间节奏) — 分镜表
| 时间 | 镜头目的 | 景别/机位 | 动作 | 商品信息 | 声音/字幕 | 时长/素材 | 来源 |
|---|---|---|---|---|---|---|---|
| 3-5s | [本镜证明哪个卖点/回答哪个顾虑] | [全景/近景/特写/俯拍] | [演员或手部具体做什么] | [哪个包装/规格/细节必须看清] | [口播/字幕/操作原声] | [本镜成片时长,生成素材时长] | [真人实拍/AI 生成/后期合成] |
| 5-8s | ... | | | | | | |
| 8-11s | ... | | | | | | |
| 11-13s | ... | | | | | | |

节奏提示:按内容需要决定切镜(不强制每 2-3 秒切一次)

## 收(13-15 秒)
文案:「……」(金句升华 + 互动引导)
画面:产品特写 + 引导手势

## 卖点证据(必填)
列出本脚本中"为什么可信"的全部证据:
- 证据 1:[演示过程/规格表/材质细节/真实效果/对比测试]
- 证据 2:[同上]
- 证据 3:[同上]
- 谁适合 / 谁不适合:[明确]
```

**完整脚本自检**:
- 总字数符合时长(15s ≈ 50-80 字,30s ≈ 120-180 字,60s ≈ 250-350 字)
- 钩-展-收 三段清晰可拆
- **分镜表 7 字段全填**(镜头目的/景别/动作/商品/声音/时长素材/来源)
- **卖点证据至少 2 条**(演示/规格/材质/效果/对比 任一)
- 产品出现次数:钩子里能暗含最好;展里必须正面露出;收里必须有特写
- 结尾有明确 CTA(目标明确:成交/直播引流/种草/涨粉 4 选 1)
- 风格统一(严肃骨架不要"哈哈哈哈哈";幽默骨架要有笑点但不能挤掉卖点)

### 第四步:可执行的拍摄清单(选做,但带货场景强烈建议)
- **演员 / 模特 / 手部演示**:谁出镜,什么状态
- **场景**:具体场地(家/办公室/户外/桌面/...)
- **道具清单**:商品 + 辅助道具 + 赠品
- **设备**:手机/相机 + 收音 + 灯光
- **BGM 风格建议**:按风格选(严肃/治愈/轻快/反差/悬疑)
- **字幕重点**:钩子必须上字幕,产品名/价格/规格必须上字幕
- **关键演员时刻**:哪个分镜必须演到位(对应卖点证据)
- **制作路线确认**:口播+实拍 / 手部演示 / 剧情+实拍(选定后不再变)
- **AI 视频片段检查表**(如用 AI):见 `references/ai-video-capability.md` 第九节
- **成片验收清单**:商品一致性 5 项 + 动作验收 4 项(见 production-routes)

### 第五步:可附带的发布配套建议(选做,但带货场景强烈建议)
- **本条内容主目标(必填,4 选 1)**:成交 / 直播引流 / 种草 / 涨粉
- **风险预案**:1-2 条最可能出问题的情况(演员表情不到位/APP 数字不清/15s 装不下),对应备选方案
- **备用钩子**:从方案集挑 1-2 个作为"拍摄撞档期可快速切换"的备份
- **发布话题**:3-5 个相关话题标签(#打工人日常 #办公好物 类)
- **发布时间**:**起点建议**工作日 12:00-13:30 或 21:00-22:30,**用 A/B 测试找自己账号的最佳时间**(不绝对)
- **一镜到底配音稿**(给演员直接念的版本,无分镜)
- **AI 内容标识**(如用 AI):发布时勾选"AI 生成"标签

## Output contract

**三轮交付**(按用户需求触发对应轮次):

- **Round 1**:8-10 个钩子方案(用上面的"#N 钩子文案"模板,含错位维度 + 卖点证据指向)
- **Round 2**:用户选定后,完整脚本(用上面的"钩/分镜表/收/卖点证据"模板)+ 拍摄清单 + 发布配套
- **Round 3**(可选,用户给视频时触发):用预期错位 + 5 钩子 + 钩-展-收框架,**诊断用户提供的既有视频**,输出 3 个问题 + 3 个改进方案 + 1 个重做版钩-展-收

**用户灵活处理**:
- 用户明确说"直接出脚本" → 跳过选钩环节,直接出 Round 2 完整脚本(仍含分镜表 + 卖点证据)
- 用户说"我就要幽默" → 风格锁定幽默,骨架仍按商品类型选
- 用户给视频/脚本要求"诊断" → 直接走 Round 3

### Round 3 诊断既有视频(可选,能力扩展)

**触发条件**:用户提供了已发布的视频(链接/文件)或既有脚本,要求"分析问题"。

**诊断流程(7 步,带查重 + 归档循环)**:
1. **拆解 5 镜分镜**:把视频拆成 0-3s / 3-8s / 8-13s / 13-15s(或对应时长)5 个段落
2. **查重历史案例**:先读 `references/diagnosis-archive.md` 的"模式问题追踪"表,看是否已有类似问题。如果命中已有模式,可以直接引用模式 #X 作为诊断依据
3. **三框架对照诊断**:
   - **钩-展-收结构**:每段功能是否清晰?缺哪段?
   - **5 钩子类型覆盖**:钩子属于哪一类?是否有效?
   - **预期错位硬规则**:每个分镜的服饰/场景/动作/反常识是否错位?错了几项?
4. **输出三件套**:
   - **3 个具体问题**(用"问题+证据+影响"格式,不空喊)
   - **3 个改进方案**(每个方案能直接拿来改 1 个分镜)
   - **1 个重做版钩-展-收**(3 段重写,展示"如果我来改会是什么样")
5. **提炼新模式**:从这次诊断里抽象出至少 1 个"通用问题模式"(不针对这个视频,而是针对一类视频)
6. **归档到 `references/diagnosis-archive.md`**:用文件里的"诊断案例标准格式"完整填一次,**不允许只诊断不归档**
7. **更新模式追踪表**:如果发现了新模式 → 加到追踪表,标记"待观察"。如果已有模式被命中 → 命中次数 +1,**命中 3 次自动升级为 SKILL.md Self-check 项**

**叠层升级的逻辑**:
- 第 1 次诊断某个问题 → 归档 + 标记"待观察"
- 第 2 次诊断同样问题 → 命中次数 +1
- 第 3 次诊断同样问题 → 升级为 Self-check 硬规则,SKILL.md 自动加 1 项
- 第 4+ 次诊断 → 已经是 Self-check 一部分,直接引用即可

**诊断自检**:
- 问题不能空喊("开头不好"),要具体到"0-0.3s 钩子 0 错位,产品居中,触发用户防御"
- 改进方案不能模糊("改开头"),要具体到"改成白蕾丝女生在工地搬砖的场景错位"
- 重做版要真的能直接拿去拍,不是"假大空重做"
- **必须提炼至少 1 个新模式**,不允许"只是个例"
- **必须归档**,不允许只输出不写进知识库

## Failure handling

- **产品信息不够** → 问 1-2 个关键问题(核心卖点?目标人群?售价区间?),不要超过 3 个问题
- **方案都不满意** → 让用户说"哪里不满意"(太严肃/太夸张/不切产品),针对性重做
- **首选钩子拍摄撞档期** → 走第五步给出的"备用钩子",结构一致、文案已就绪
- **用户卡顿不知道选哪个** → 给一个推荐("如果只能选一个,我推荐 #3,理由是……"),不要让用户决策疲劳
- **脚本太长/太短** → 先看时长约束,再回头压缩/扩写
- **完全不知道从哪下手** → 默认走"模板填充"路线:从 `references/hook-library.md` 按产品类型筛 3 个最贴的钩子,替换占位符直接成句(不再降级到自创)
