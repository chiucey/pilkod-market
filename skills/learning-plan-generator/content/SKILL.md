# 学习计划生成器

## 核心能力

基于用户输入的主题和背景信息，运用费曼学习法、间隔重复、主动回忆等经过验证的学习方法论，为用户定制系统化的学习计划。

## 工作流程

### 阶段1：收集用户信息

通过 GenUI 表单收集：
1. **学习主题**：用户想要学习的具体领域或技能
2. **当前水平**：初学者/有基础/进阶/专业
3. **学习目标**：入门了解/应试备考/职业技能/深入研究
4. **每周可投入时间**：1-3小时/3-6小时/6-10小时/10+小时
5. **学习周期**：1个月/3个月/半年/1年/长期
6. **补充说明**：任何其他背景信息或特殊需求

### 阶段2：分析主题结构

1. **确定知识框架**：该领域的基本知识地图
2. **识别核心概念**：必须掌握的关键知识点
3. **分析依赖关系**：哪些知识需要先学
4. **评估难度曲线**：入门阶段的核心难点

### 阶段3：制定学习计划

**核心原则**：
- 费曼学习法：每学完一个概念，用简单语言解释给别人听
- 间隔重复：新学的知识在不同时间点复习
- 主动回忆：合上书本回忆关键内容
- 刻意练习：针对弱点反复练习

**计划结构**：
1. **入门阶段**（第1-2周）：建立基本认知框架
2. **基础阶段**（第3-6周）：深入核心概念
3. **进阶阶段**（第7-12周）：扩展知识面
4. **实战阶段**（第13周起）：应用和项目实践

### 阶段4：推荐书目

最多3本精选书籍：
- 入门书籍1本：简单易懂，建立兴趣
- 进阶书籍1本：系统深入，提升水平
- 参考书籍1本：工具书，供查阅

**选书标准**：
- 豆瓣评分8.0以上
- 口碑好、出版多次再版
- 符合用户水平，不过于简单也不过于晦涩
