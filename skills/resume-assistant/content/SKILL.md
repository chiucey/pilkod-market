# 简历助手

## 核心功能

### 1. 简历撰写
从零开始构建专业简历，包含以下模块：

- **个人信息**：姓名、联系方式、职位目标
- **教育背景**：学校、专业、学位、在校时间
- **工作经历**：公司、职位、工作时间、工作内容与成就
- **项目经验**：项目名称、项目描述、个人角色、技术栈、成果展示
- **技能清单**：技术技能、软技能、语言能力
- **其他信息**：证书、奖项、兴趣爱好、培训经历

### 2. 简历优化
针对现有简历进行专业优化：

- **内容优化**：突出成就、量化成果、强化个人品牌
- **结构优化**：改善布局、提升可读性、增强逻辑性
- **关键词优化**：针对目标岗位调整关键词，提升简历通过率
- **语言优化**：使用专业动词、改善表达方式、提升专业度

### 3. 面试准备
全方位面试准备支持：

- **岗位研究**：分析目标岗位要求，制定应答策略
- **常见问题**：准备高频面试问题及参考答案
- **STAR法则**：使用STAR框架组织行为面试答案
- **模拟练习**：模拟真实面试场景，提供反馈建议
- **注意事项**：面试礼仪、肢体语言、常见陷阱

## 使用场景

### 场景一：撰写新简历

```
用户：我想申请产品经理岗位，请帮我撰写一份专业的简历。

助手将：
1. 收集必要信息（教育背景、工作经历、技能等）
2. 根据产品经理岗位特点优化内容
3. 生成结构清晰、专业度高的简历
```

### 场景二：优化现有简历

```
用户：我有一份简历想请您优化，目标是字节跳动的后端开发岗位。

助手将：
1. 分析现有简历内容
2. 针对目标岗位调整关键词和重点
3. 提供优化建议并生成改进版本
```

### 场景三：面试准备

```
用户：我下周要去面试算法工程师，请帮我准备面试。

助手将：
1. 分析算法工程师常见面试问题
2. 提供技术问题答题思路
3. 准备行为面试问题的STAR格式答案
```

## 简历结构建议

### 基础信息模块

| 模块 | 必填 | 说明 |
|------|------|------|
| 姓名 | 是 | 中文简历用中文名，英文简历用英文名 |
| 联系方式 | 是 | 电话、邮箱、LinkedIn（可选） |
| 求职意向 | 是 | 明确目标岗位和期望薪资 |

### 教育背景模块

| 模块 | 必填 | 说明 |
|------|------|------|
| 学校名称 | 是 | 注明211/985或排名情况 |
| 专业学位 | 是 | 本科/硕士/博士，专业名称 |
| 在校时间 | 是 | 精确到月份 |
| GPA/排名 | 建议 | GPA≥3.5或排名前20%时填写 |
| 相关课程 | 建议 | 填写与岗位相关的核心课程 |

### 工作经历模块

| 模块 | 必填 | 说明 |
|------|------|------|
| 公司名称 | 是 | 公司全称，可添加一句话简介 |
| 职位名称 | 是 | 实际职位名称 |
| 工作时间 | 是 | 精确到月份 |
| 工作内容 | 是 | 使用动词开头，描述具体工作 |
| 工作成果 | 是 | 量化成果，使用数据支撑 |

### 项目经验模块

| 模块 | 必填 | 说明 |
|------|------|------|
| 项目名称 | 是 | 清晰、有辨识度的名称 |
| 项目时间 | 是 | 项目持续时间 |
| 项目描述 | 是 | 一句话概括项目背景 |
| 个人职责 | 是 | 本人在项目中的角色 |
| 技术栈 | 是 | 使用的技术和工具 |
| 项目成果 | 是 | 项目取得的成绩和贡献 |

## 简历优化技巧

### 成就量化方法

```
❌ 原始描述：
负责用户增长工作，用户活跃度提升

✓ 优化后：
主导用户增长策略，DAU提升150%，MAU从500万增长至1250万
```

### 动词使用建议

| 类别 | 推荐动词 |
|------|----------|
| 领导力 | 主导、带领、管理、负责、统筹 |
| 协作 | 协调、推动、参与、配合、支持 |
| 成果 | 提升、优化、改善、实现、建立 |
| 分析 | 分析、研究、评估、调研、洞察 |

### 关键词优化

根据目标岗位JD调整简历关键词：

1. **提取关键词**：分析目标岗位的技能要求
2. **匹配度检查**：确保简历包含相关关键词
3. **权重调整**：将重要关键词放在显眼位置
4. **自然融入**：避免堆砌关键词

### 行为面试准备

#### STAR法则应用

```
情境（Situation）：描述背景和挑战
任务（Task）：明确你的职责和目标
行动（Action）：你采取的具体行动
结果（Result）：取得的成果和影响

示例：
 Situation：在创业公司期间，公司面临用户留存率低的问题
 Task：我作为增长负责人，需要在3个月内将留存率提升30%
 Action：我主导了数据埋点体系建设，通过A/B测试优化核心流程
 Result：次月留存率从25%提升至42%，超预期完成任务
```

#### 高频行为问题

| 问题类型 | 问题示例 |
|----------|----------|
| 自我介绍 | 请做一个简短的自我介绍 |
| 优势劣势 | 你的最大优点和缺点是什么 |
| 成功经历 | 分享一个让你最有成就感的工作经历 |
| 失败教训 | 分享一次失败的经历及从中得到的教训 |
| 团队协作 | 描述一次你与团队成员产生分歧的经历 |
| 抗压能力 | 描述一次在高压下完成任务的经历 |
| 职业规划 | 你未来3-5年的职业规划是什么 |

### 面试注意事项

#### 面试前准备

```
✓ 准备内容：
├─ 深入研究目标公司和岗位
├─ 复习简历中的每个细节
├─ 准备3-5个针对公司的问题
├─ 确认面试时间、地点、形式
└─ 准备职业装（视公司文化调整）

✗ 避免事项：
├─ 对公司或岗位一无所知
├─ 简历内容记不清细节
├─ 没有问题要问面试官
└─ 迟到或着装不得体
```

#### 面试中表现

```
✓ 优秀表现：
├─ 逻辑清晰，表达有条理
├─ 眼神交流，保持微笑
├─ 积极倾听，理解问题意图
├─ 不懂的问题坦诚承认
└─ 展示学习能力和潜力

✗ 避免表现：
├─ 回答过于冗长或跑题
├─ 过度紧张或过于放松
├─ 贬低前公司或同事
├─ 争论或反驳面试官
└─ 急于表现，忽视团队协作
```

#### 面试后跟进

```
✓ 正确做法：
├─ 发送感谢邮件（24小时内）
├─ 简要回顾面试亮点
├─ 表达对岗位的热情
└─ 保持平和心态

✗ 避免做法：
├─ 追问面试结果
├─ 抱怨或负面反馈
├─ 同时接受多家offer不告知
└─ 忽视后续跟进邮件
```
