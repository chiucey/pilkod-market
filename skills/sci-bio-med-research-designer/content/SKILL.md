# SCI生物医学文章解读与技术方案生成

## 核心功能

本技能帮助研究人员快速解读SCI生物医学文献，并生成可视化的实验设计技术方案和研究结果示意图。

## 工作流程

### 步骤1：文章内容提取

使用 `extract_pdfs_full_content` 工具提取PDF全文内容：
```
- 提取研究背景与目的
- 识别关键研究方法
- 提取实验结果与结论
```

### 步骤2：文章结构化解读

从提取的内容中提取以下关键信息：

**研究概述：**
- 研究领域与疾病类型
- 科学假设或研究问题
- 主要研究目标

**实验设计要素：**
- 研究类型（体内/体外/临床）
- 样本来源与数量
- 干预措施或处理因素
- 检测指标与方法
- 数据分析策略

**核心结果：**
- 主要发现
- 统计显著性
- 关键图表数据

### 步骤3：技术方案生成

基于解读内容，生成结构化的实验设计方案：

```
研究类型 → 样本设计 → 实验方法 → 检测指标 → 分析策略
```

### 步骤4：示意图生成（使用nano-banana）

调用 `image_synthesize` 工具生成以下类型示意图：

1. **实验设计流程图**：展示整体研究框架
2. **技术路线图**：详细实验步骤与流程
3. **结果示意图**：关键数据可视化展示
4. **机制示意图**：分子/细胞层面机制展示

生成提示词模板：
- 实验设计图：`[研究类型] research design flow chart, [具体领域] study, scientific illustration, clean white background, professional biomedical style`
- 技术路线图：`[实验方法] technical workflow diagram, [研究内容], step-by-step protocol, scientific diagram, clear labels`
- 结果示意图：`[研究结果类型] data visualization, [具体数据], scientific figure style, publication quality`
- 机制示意图：`[分子/通路名称] mechanism diagram, [生物过程], cellular/molecular level, detailed annotation`

## 输出格式

### 1. 文章摘要卡片

```
| 项目 | 内容 |
|------|------|
| 研究领域 | [领域] |
| 研究类型 | [类型] |
| 样本规模 | [数量] |
| 核心技术 | [方法] |
| 主要结论 | [结论] |
```

### 2. 实验设计方案

```
## 研究概述
[简要描述]

## 实验设计框架
[结构化方案]

## 技术路线
[流程说明]
```

### 3. 生成的示意图

提供可直接使用的PNG格式示意图。

## 适用领域

- 疾病机制研究
- 药物研发与药理学
- 分子生物学实验设计
- 临床医学研究

## 使用示例

用户上传PDF文件并说："请解读这篇SCI文章并生成实验设计技术方案"

→ 系统自动提取文章内容
→ 生成结构化解读
→ 创建技术方案路线图
→ 生成可视化示意图

## 注意事项

1. **PDF格式**：优先使用PDF文件以获得最佳提取效果
2. **图片清晰度**：生成示意图时建议使用高分辨率设置
3. **内容核实**：自动解读结果需用户核实准确性
4. **版权合规**：仅用于研究辅助，不用于抄袭或不当使用
