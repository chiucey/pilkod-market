### 2.3 特征工程（17维）

#### 技术指标特征
| 特征名 | 描述 |
|--------|------|
| Log_Return | 对数收益率 |
| MA_5, MA_10, MA_20, MA_60 | 移动平均线 |
| Volatility_5, Volatility_20 | 历史波动率 |
| RSI | 相对强弱指数 |
| Momentum_5, Momentum_20 | 动量指标 |
| Price_Position_20, Price_Position_60 | 价格相对位置 |

#### 季节性特征
| 特征名 | 描述 |
|--------|------|
| Month_Sin, Month_Cos | 月份周期编码 |

#### 滞后特征
| 特征名 | 描述 |
|--------|------|
| Log_Return_Lag_1/2/3 | 滞后收益率 |

#### 目标变量
| 变量 | 描述 |
|------|------|
| Future_Return | 未来22天对数收益率 |
| Future_Direction | 未来22天方向 (1=涨, 0=跌) |

### 2.4 数据预处理流程

1. **缺失值处理**：删除含有NaN的行
2. **异常值处理**：使用3σ原则，过滤超出均值±3倍标准差的数据
3. **特征计算**：滚动窗口计算技术指标
4. **目标变量**：计算未来22天收益率和方向

### 3.1 Ridge回归模型（收益率预测）

```python
Ridge(alpha=1.0)
输入: 17维特征向量
输出: 连续收益率值
```

### 3.2 Logistic回归模型（方向分类）

```python
LogisticRegression(max_iter=1000, C=1.0)
输入: 17维特征向量
输出: 方向概率 [0, 1]
```

### 3.3 预测策略

#### 历史中位数锚定 + 方向修正

```python
# 1. 计算训练集历史收益率中位数
median_return = median(historical_returns)

# 2. 混合模型预测和历史中位数
model_weight = 0.3
final_pred = model_weight * model_pred + (1 - model_weight) * median_return

# 3. 方向一致性修正
if direction_prob > 0.5:
    final_pred = max(0, final_pred)  # 强制为正
else:
    final_pred = min(0, final_pred)  # 强制为负
```
