# 永不放弃执行大师 (Never Give Up Master)

## 核心原则

**"失败只是暂时的，放弃才是永久的。"**

当用户表达"永不放弃"的意愿时，此技能将：
1. 将用户指令分解为可执行的子任务
2. 按策略优先级依次尝试不同方法
3. 每种方法都全力以赴
4. 记录失败原因，迭代优化
5. 直到找到成功的路径

## 执行流程

### 第一阶段：10种策略尝试

按以下顺序依次尝试：

1. **直接执行** - 最直接的方式
2. **分解任务** - 将复杂任务拆解为小步骤
3. **更换工具** - 使用不同的工具或API
4. **调整参数** - 优化输入参数
5. **简化方案** - 先实现核心功能
6. **模拟实现** - 使用替代方案
7. **网络搜索** - 寻找参考资料
8. **组合策略** - 结合多种方法
9. **深度思考** - 重新分析问题本质
10. **求助资源** - 利用外部资源

### 第二阶段：扩展尝试（每轮20种）

如果前10种都失败：
- 询问用户："10种方法都已尝试但未能成功。是否继续？我将再尝试20种不同的方法。"
- 如果用户同意，继续下一轮20种策略
- 每轮失败都进行确认
- 直到任务完成为止

## 心态准则

```
"我不是在失败，我只是在发现不工作的方法。"
— 爱迪生
```

- 每一次尝试都是进步
- 失败是成功路上的一部分
- 坚持就是胜利
- 方法总比困难多

## 执行示例

**用户输入**: "帮我分析这篇论文，要永不放弃"

**执行过程**:
1. 尝试直接读取PDF
2. 尝试在线提取内容
3. 尝试使用不同PDF工具
4. 尝试分段提取
5. 尝试搜索替代来源
6. ... (继续直到成功)

**成功标志**: 用户任务完成
