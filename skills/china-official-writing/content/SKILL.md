# 中国官方媒体理论评论写作技能

本技能提供人民日报、解放军报、科技日报的理论评论文章撰写规范，用于支撑科研机构公文写作。

## 一、人民日报（理论版 / 评论版）撰写规范

### 1.1 理论文章特征
- **主题**：重大理论问题、党的创新理论阐释、政策解读
- **篇幅**：通常 2000-4000 字
- **结构**："总分总"三层结构为主
  - 开篇：点明主题，引用重要论述或重大部署
  - 主体：分论点展开，每个分论点配一个典型案例或数据
  - 结尾：升华主题，呼应开头，常用"让我们更加紧密地团结在……"等句式
- **语言风格**：庄重、凝练、有理论深度，善用排比、对仗

### 1.2 评论员文章（任仲平/本评论员）特征
- **时效性**：紧跟重大事件、重大会议、重大部署
- **标题**：常用祈使句或判断句，如"坚定信心 共克时艰"
- **开头**：从具体事件切入，逐步上升到理论高度
- **论证**：事实论证+理论论证，常引用领导人重要论述作为论据
- **结尾**：发出号召，具有动员性质

### 1.3 写作常用框架
```
第一部分：时代背景 / 重大意义（为什么要做）
第二部分：核心内涵 / 主要精神（是什么）
第三部分：实践要求 / 落实举措（怎么做）
```

### 1.4 高频金句模板
- "深入学习贯彻习近平新时代中国特色社会主义思想"
- "增强'四个意识'、坚定'四个自信'、做到'两个维护'"
- "统筹推进'五位一体'总体布局，协调推进'四个全面'战略布局"
- "以钉钉子精神抓好落实"
- "知行合一、学以致用"

## 二、解放军报（理论版）撰写规范

### 2.1 军队理论文章特点
- **政治立场**：党对军队的绝对领导，强军目标，听党指挥
- **语言特色**：军事化表达，战斗化语言
- **常用词汇**：听党指挥、能打胜仗、作风优良；练兵备战；能打仗、打胜仗
- **结构**：观点鲜明、逻辑严密、语言精练

### 2.2 常见栏目
- **理论专版**：阐释强军思想、军魂意识
- **闻思录**：以思考性短文为主，500-1000字
- **兵眼看两会/兵眼看全会**：结合军队实际解读会议精神

### 2.3 写作要求
- 坚持军魂意识，突出"两个维护"
- 理论与实践结合，融入部队实际训练、工作
- 善用军队典型、英雄模范事迹
- 避免过于学术化，追求简洁有力

## 三、科技日报（理论评论）撰写规范

### 3.1 科技评论特征
- **关注点**：科技创新、科普工作、科技政策、国际科技竞争
- **语言风格**：严谨而不失活泼，专业性与可读性并重
- **常用结构**：问题导向型（现状-问题-对策）

### 3.2 科技评论写作框架
```
开头：用一个科技事件或数据切入，引出主题
第二段：分析现状，点明科技发展的意义或面临的问题
第三段：从政策、资金、人才、机制等多维度分析
结尾：提出期望或呼吁，强调科技自立自强
```

### 3.3 常用表述
- "科技自立自强是国家强盛之基、安全之要"
- "把科技的命脉牢牢掌握在自己手中"
- "创新驱动发展"
- "深化科技体制改革"

## 四、通用公文写作核心原则

### 4.1 政治话语体系
- 善用"政治话语+专业话语+群众话语"三结合
- 重大表述须与中央精神一致（可引用二十大报告、总书记重要讲话原文）
- 使用规范的政治术语，不生造词汇

### 4.2 写作自检清单
- [ ] 开篇是否有明确的主题句或核心观点
- [ ] 每个段落是否有明确的分论点
- [ ] 是否有用典型案例或数据支撑论点
- [ ] 结尾是否有升华或发出号召
- [ ] 语言是否庄重凝练，无语病错字
- [ ] 是否符合该媒体/文体的特定格式

### 4.3 常用连接词
- 开头：闻言、长期以来、党的十八大以来
- 递进：更重要的是、尤其是、特别是
- 转折：然而、与此同时、但也应看到
- 结尾：总之、综上所述、让我们

### 5.7 综合运用提示

**写作搭配建议**
- 写对照检查/述职材料 → 侧重「作风纪律类」+「军魂意识类」表述
- 写经验交流/汇报材料 → 侧重「备战打仗类」+「基层组织类」表述，配合具体数据
- 写理论文章/研讨发言 → 侧重「核心要义类」+「人才建设类」，体现理论深度
- 写动员讲话/誓师发言 → 侧重「备战打仗类」+「作风纪律类」，语言要有力有力

**常见错误警示**
- ❌ 使用"军事化管理"替代"依法治军"（不规范表述）
- ❌ 混用"武装力量"与"人民军队"（须明确主体）
- ❌ 将"听党指挥"写成"服从命令"（政治定位不够准确）
- ❌ 使用"首长指示"替代"上级部署"（制度表述要规范）
