# 分布式光伏发电自消纳比例测算模型

## 技能概述

本技能用于根据企业的历史用电数据（电费核查联和用电负荷曲线），建立分布式光伏发电自消纳比例测算模型，帮助企业评估光伏项目的经济性和投资回报。

## 核心概念

### 自消纳比例定义

```
自消纳比例 = 光伏发电自我消纳电量 / 光伏总发电量 × 100%
```

- **自我消纳电量**：光伏发电在企业用电时段内被直接消费的电量
- **光伏总发电量**：光伏电站设计装机容量 × 年等效发电小时数 × 系统效率
- **余电上网电量**：光伏发电超出企业用电负荷的部分输送至电网

### 关键参数

| 参数 | 说明 | 数据来源 |
|------|------|----------|
| 装机容量 (kWp) | 光伏电站设计装机规模 | 用户输入/项目规划 |
| 年等效发电小时数 | 考虑辐照、效率等因素的年有效发电小时 | 当地气象数据/行业标准 |
| 系统效率 | 光伏组件、逆变器、线损等的综合效率 | 默认 0.80-0.85 |
| 企业用电负荷曲线 | 24小时或分时段用电功率分布 | 负荷曲线监测数据 |
| 年用电量 | 企业年度总用电量 | 电费核查联 |
| 峰谷时段分布 | 用电高峰和低谷时段 | 电费核查联 |

## 工作流程

### 步骤 1：数据采集与标准化

**输入数据清单：**

1. **电费核查联数据**
   - 年度用电量（kWh）
   - 峰谷时段用电量分布
   - 基本电费与电度电费结构
   - 电压等级与计费方式

2. **用电负荷曲线数据**
   - 典型日负荷曲线（工作日/休息日）
   - 负荷率与最大需量
   - 季节性负荷变化特征

3. **光伏项目参数**
   - 拟建/已建设计装机容量 (kWp)
   - 安装位置与朝向
   - 组件类型与效率

**数据标准化处理：**

```
1. 将年度用电量按月/日分解
2. 将负荷曲线归一化为 0-24 小时功率分布
3. 计算各时段平均负荷率
```

### 步骤 2：光伏发电量模拟

**日发电量计算：**

```
日发电量 = 装机容量 × 日峰值日照小时数 × 系统效率
```

**年发电量计算：**

```
年发电量 = 装机容量 × 年等效发电小时数 × 系统效率
```

**各月发电量分布（基于辐照季节性）：**

| 月份 | 发电量占比 |
|------|----------|
| 1-2月 | 8% |
| 3-4月 | 18% |
| 5-6月 | 22% |
| 7-8月 | 24% |
| 9-10月 | 18% |
| 11-12月 | 10% |

### 步骤 3：负荷-发电匹配分析

**分时段消纳计算模型：**

```
对于每个时段 t：
  光伏发电量_t = 装机容量 × 时段t发电系数
  企业用电量_t = 负荷曲线_t × 最大需量
  自我消纳_t = min(光伏发电量_t, 企业用电量_t)
  余电上网_t = max(0, 光伏发电量_t - 企业用电量_t)
```

**典型日匹配分析：**

1. **光伏发电曲线特征**
   - 发电时段：通常 06:00-18:00
   - 发电高峰：10:00-14:00
   - 峰谷系数：约 0.3-0.8

2. **企业用电曲线特征**
   - 生产时段高负荷
   - 非生产时段低负荷
   - 峰谷差率指标

### 步骤 4：自消纳比例计算

**年度综合自消纳比例：**

```
年自消纳总量 = Σ(各时段自我消纳电量)
年余电上网总量 = Σ(各时段余电上网电量)
年光伏发电总量 = 年自消纳总量 + 年余电上网总量

年自消纳比例 = 年自消纳总量 / 年光伏发电总量 × 100%
```

**季节性自消纳分析：**

| 季节 | 发电量占比 | 自消纳难点 |
|------|-----------|-----------|
| 夏季 | 高 | 光伏发电高峰与负荷高峰重叠较好 |
| 冬季 | 低 | 光伏发电不足，可能需要网购电 |
| 春秋季 | 中等 | 发电与负荷匹配较好 |

### 步骤 5：经济性测算

**自消纳收益计算：**

```
自消纳收益 = 自消纳电量 × (电网电价 - 光伏发电成本)
余电上网收益 = 余电上网电量 × 余电上网电价
年综合收益 = 自消纳收益 + 余电上网收益 + 补贴收益
```

**敏感性分析：**

- 不同装机容量下的自消纳比例变化
- 不同用电负荷变化对自消纳比例的影响
- 电价变化对项目收益的影响

## 常见场景与适配

### 场景 1：制造业企业

**负荷特征：** 生产时段稳定，有明显的峰谷差异

**测算重点：**
- 生产班次与光伏发电时段的匹配度
- 午休时段负荷变化
- 节假日生产安排

### 场景 2：商业综合体

**负荷特征：** 用电高峰集中在白天，与光伏发电高度吻合

**测算重点：**
- 空调负荷与光伏发电的相关性
- 周末与工作日负荷差异
- 商业营业时间与光伏时段的匹配

### 场景 3：工业园区

**负荷特征：** 多企业叠加，负荷曲线较为平滑

**测算重点：**
- 园区整体负荷与光伏发电的匹配
- 不同入驻企业的负荷叠加效应
- 园区自备变压器的承载能力

## 数据质量要求

### 电费核查联数据要求

| 字段 | 必填 | 格式要求 |
|------|------|----------|
| 结算周期 | 是 | YYYY-MM |
| 峰时段电量 | 是 | kWh |
| 谷时段电量 | 是 | kWh |
| 平时段电量 | 是 | kWh |
| 最大需量 | 是 | kW |
| 电压等级 | 是 | kV |
| 电价 | 是 | 元/kWh |

### 负荷曲线数据要求

| 字段 | 必填 | 格式要求 |
|------|------|----------|
| 时间戳 | 是 | YYYY-MM-DD HH:mm |
| 有功功率 | 是 | kW |
| 无功功率 | 否 | kVar |
| 电压 | 否 | V |
| 采集周期 | 是 | 分钟 |

### 数据完整性标准

- 电费核查联：至少覆盖 12 个月
- 负荷曲线：至少包含 7 天完整数据（工作日+休息日）
- 数据缺失率：不超过 5%

## 误差与不确定性

### 模型假设

1. 光伏发电曲线假设为标准正态分布
2. 企业负荷假设在测算周期内保持稳定
3. 未考虑储能系统对自消纳比例的提升作用
4. 电价假设在测算周期内保持不变

### 不确定性来源

| 来源 | 影响 | 处理方式 |
|------|------|----------|
| 辐照量年际变化 | ±10% | 采用多年平均值 |
| 组件衰减 | -0.5%/年 | 分年测算 |
| 负荷变化 | ±15% | 敏感性分析 |
| 电价调整 | 影响收益 | 分情景测算 |
