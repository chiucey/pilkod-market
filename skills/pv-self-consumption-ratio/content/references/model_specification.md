# 分布式光伏自消纳比例测算模型技术规格

## 1. 模型概述

本模型用于测算企业投资建设分布式光伏电站后，光伏发电量的自我消纳比例。该比例是评估光伏项目经济性的关键指标，直接影响项目投资回报。

## 2. 数学模型

### 2.1 光伏发电量计算

```
年发电量 = 装机容量 × 年等效发电小时数 × 系统效率
日发电量 = 装机容量 × 日峰值日照小时数 × 系统效率
```

**参数说明：**
- 装机容量 (kWp)：光伏组件标称功率之和
- 年等效发电小时数：根据当地辐照条件确定，中国东部地区约1000-1400小时
- 系统效率：考虑组件效率、逆变器效率、线损等，综合效率约0.80-0.85

### 2.2 分时段发电曲线

光伏发电曲线近似服从正态分布，高峰时段为10:00-14:00。

```
f(t) = A × exp(-(t-12)² / (2σ²))
```

典型日光伏发电系数：

| 时段 | 发电系数 |
|------|----------|
| 06:00-07:00 | 0.02-0.08 |
| 08:00-09:00 | 0.15-0.22 |
| 10:00-11:00 | 0.28-0.33 |
| 12:00-13:00 | 0.32-0.33 |
| 14:00-15:00 | 0.24-0.28 |
| 16:00-17:00 | 0.12-0.18 |
| 18:00 | <0.02 |

### 2.3 自消纳计算

对于每个时段t：

```
光伏发电量_t = 装机容量 × 时段t发电系数
企业用电量_t = 负荷曲线_t × 最大需量
自我消纳_t = min(光伏发电量_t, 企业用电量_t)
余电上网_t = max(0, 光伏发电量_t - 企业用电量_t)
```

### 2.4 综合自消纳比例

```
年自消纳总量 = Σ(各时段自我消纳电量)
年光伏发电总量 = Σ(各时段光伏发电量)
年自消纳比例 = 年自消纳总量 / 年光伏发电总量 × 100%
```

## 4. 敏感性分析

### 4.1 自消纳比例敏感性因素

| 因素 | 变化范围 | 对自消纳比例的影响 |
|------|----------|-------------------|
| 装机容量 | ±20% | ±5-8% |
| 用电负荷 | ±15% | ±8-12% |
| 系统效率 | ±3% | ±2-3% |
| 季节性 | 夏/冬季 | ±10-15% |

### 4.2 经济性敏感性

| 参数 | 变化 | 对回收期的影响 |
|------|------|---------------|
| 电价 | +10% | 缩短0.5-1年 |
| 发电量 | -10% | 延长0.8-1.5年 |
| 投资成本 | +15% | 延长1-2年 |

## 5. 优化策略

### 5.1 提升自消纳比例的方法

1. **容量匹配优化**
   - 根据企业用电负荷曲线确定最优装机容量
   - 避免装机容量过大导致余电过多

2. **生产计划优化**
   - 调整生产班次，使其与光伏发电时段匹配
   - 将高耗能生产安排在白天进行

3. **储能配置**
   - 配置储能系统存储多余光伏电力
   - 在光伏发电不足时释放储能电力

4. **需求侧响应**
   - 利用光伏发电时段的价格信号引导用电
   - 实施错峰生产策略

### 5.2 典型优化案例

**案例：制造业企业**
- 原方案装机：500kWp
- 原自消纳比例：65%
- 优化后自消纳比例：82%

**优化措施：**
1. 将部分夜班生产调整为白班
2. 配置100kWh储能系统
3. 安装光伏后配置智控系统自动调节

## 6. 数据质量要求

### 6.1 电费核查联数据

- 时间跨度：至少12个月
- 数据完整性：缺失率<5%
- 包含字段：结算周期、峰谷平时段电量、最大需量、电压等级、电价

### 6.2 负荷曲线数据

- 采集周期：15分钟或1小时
- 时间跨度：至少7天完整数据
- 包含工作日和休息日数据
- 数据完整性：缺失率<3%

## 7. 模型局限性

1. **假设条件**
   - 假设光伏发电曲线为标准正态分布
   - 假设企业负荷在测算周期内保持稳定
   - 未考虑储能系统对自消纳比例的提升作用

2. **不确定性来源**
   - 辐照量年际变化：±10%
   - 组件衰减：首年2%，后续0.5%/年
   - 电价调整：影响收益测算

3. **适用范围**
   - 适用于低压或高压并网分布式光伏项目
   - 不适用于全额上网项目
   - 不适用于配置大规模储能的项目
