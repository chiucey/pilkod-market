# 学术文献深度检索技能

本技能提供全面的学术文献检索服务，涵盖学术论文、技术文档、行业报告和学位论文四大类型。

## 核心能力

1. **学术论文检索**：期刊文章、会议论文、arXiv预印本
2. **技术文档检索**：专利、标准规范、技术白皮书
3. **行业报告检索**：市场分析、行业趋势、投资研究
4. **学位论文检索**：硕士论文、博士论文

## 工作流程

### 步骤1：理解检索需求

用户输入后，提取以下关键信息：

| 信息项 | 说明 |
|-------|------|
| **检索主题** | 用户的研究领域或关键词 |
| **文献类型** | 学术论文/技术文档/行业报告/学位论文（可多选）|
| **时间范围** | 近1年/近2年/近5年/不限 |
| **语言偏好** | 中文/英文/不限 |
| **其他要求** | 特定机构、开放获取等 |

### 步骤2：构建检索策略

根据文献类型选择对应的检索策略：

#### 学术论文检索策略
- 中文核心：知网、万方、维普
- 英文核心：Semantic Scholar、Google Scholar、arXiv、DBLP
- 会议论文：IEEE Xplore、ACM Digital Library、NeurIPS/ICML/ACL官方会议

#### 技术文档检索策略
- 专利：国家知识产权局、WO/EP/US专利库
- 标准：中国标准服务网、全国标准信息公共服务平台
- 白皮书：权威机构官网、行业协会发布

#### 行业报告检索策略
- 国内：艾瑞咨询、艾媒咨询、中商产业研究院
- 国际：Gartner、McKinsey、IDC、Forrester
- 政府：工信部、发改委、科技部政策文件

#### 学位论文检索策略
- 中国：知网、万方
- 国际：ProQuest、WorldCat

### 步骤3：执行检索

使用 `batch_web_search` 工具执行多维度并行检索：

```
检索维度分配示例（最多10个查询）：
1. 主题 + 学术论文 + 年份
2. 主题 + 技术专利 + 年份
3. 主题 + 行业报告 + 年份
4. 主题 + 学位论文 + 年份
5. 主题 + 英文论文 + 年份
6. 主题 + 综述/survey
7. 主题 + 顶级会议
8. 主题 + 发展趋势
9. 主题 + 市场分析
10. 主题 + 最新进展
```

### 步骤4：整理与呈现

将检索结果按以下结构整理：

1. **学术论文**：论文标题、来源期刊/会议、作者、关键词、核心发现
2. **技术文档**：文档名称、发布机构、文档类型、关键内容摘要
3. **行业报告**：报告名称、发布机构、发布时间、核心数据/结论
4. **学位论文**：论文题目、学位层次、院校、研究方向

## 输出格式

### 文献清单表格

```
| 类型 | 标题/名称 | 来源/机构 | 年份 | 关键词/摘要 |
|------|----------|-----------|------|------------|
```

### 研究趋势摘要

提供检索主题的：
- 当前研究热点
- 技术演进路线
- 关键里程碑论文/报告
- 权威数据来源汇总

### 推荐阅读清单

按优先级分类：
- ⭐⭐⭐ 必读经典
- ⭐⭐ 重要参考
- ⭐ 扩展阅读

## 质量控制

- 确保检索结果覆盖所有用户指定的文献类型
- 优先返回权威机构和知名期刊/会议的内容
- 标注可获取的PDF/链接资源
- 提供中英文双语检索能力

## 常用检索词模板

| 文献类型 | 中文检索词 | 英文检索词 |
|---------|-----------|-----------|
| 学术论文 | 学术论文/期刊/会议 | academic paper/journal/conference |
| 技术专利 | 专利/技术规范 | patent/technical standard |
| 行业报告 | 行业报告/市场分析 | industry report/market analysis |
| 学位论文 | 学位论文/硕士/博士 | thesis/dissertation |

## 触发检查

本技能仅在以下情况触发：
- 用户明确要求检索文献资源
- 用户提供研究主题并要求搜索相关资料
- 用户查询特定报告、论文或标准文档

不适用于：普通问答、闲聊、写作辅助等非文献检索场景。
