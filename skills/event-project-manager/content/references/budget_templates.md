## 四、预算审批流程

### 预算分级审批
| 预算金额 | 审批人 | 审批周期 |
|---------|--------|---------|
| < 5,000元 | 部门经理 | 1个工作日 |
| 5,000-20,000元 | 部门经理+财务 | 2-3个工作日 |
| 20,000-50,000元 | 部门经理+财务+VP | 3-5个工作日 |
| > 50,000元 | 部门经理+财务+VP+CEO | 5-7个工作日 |

### 预算调整规则
- 单项超支10%以内：部门经理审批
- 单项超支10-20%：需说明原因，财务审批
- 单项超支20%以上：需重新走预算审批流程
