## 三、应急预案模板

### 预案A：主讲嘉宾临时缺席

**触发条件**：活动前24小时内嘉宾确认无法出席

**应急措施**：
1. 立即联系备用嘉宾（名单提前准备）
2. 如无法找到替代嘉宾，改为：
   - 播放嘉宾预录视频
   - 改为圆桌讨论形式
   - 缩短该环节，增加互动时间
3. 通知参会者议程变更
4. 准备相应补偿方案（如延长茶歇、增加礼品）

**责任人**：PMM（主）+ PR（配合）

---

### 预案B：直播技术故障

**触发条件**：直播中断超过3分钟

**应急措施**：
1. 技术人员立即排查问题
2. 同时启动备用直播平台
3. 主持人引导观众转移至新链接
4. 通过社群/短信通知观众新链接
5. 记录故障时间，事后补偿观众

**责任人**：技术（主）+ 运营（配合）

---

### 预案C：场地临时不可用

**触发条件**：活动当天场地无法使用

**应急措施**：
1. 立即启用备选场地（需提前签约）
2. 通知所有参会者新地址
3. 安排接驳车接送（如距离远）
4. 简化现场布置，确保核心流程

**责任人**：PMM（主）+ 行政（配合）

---

### 预案D：参会人数远超预期

**触发条件**：现场人数超过场地容量120%

**应急措施**：
1. 立即限制入场，引导至等候区
2. 开启线上直播，让场外人员参与
3. 安排工作人员维持秩序
4. 增加茶歇批次，避免拥挤

**责任人**：PMM（主）+ 运营（配合）
