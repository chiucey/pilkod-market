## 五、物料验收标准

### 设计类验收
- [ ] 品牌Logo使用正确
- [ ] 色彩符合品牌规范
- [ ] 文字无错别字
- [ ] 分辨率满足使用要求
- [ ] 出血位设置正确（印刷品）

### 印刷类验收
- [ ] 颜色还原度达标
- [ ] 裁切整齐无毛边
- [ ] 纸张/材质符合要求
- [ ] 数量准确
- [ ] 包装完好

### 礼品类验收
- [ ] 外观无瑕疵
- [ ] 品牌标识清晰
- [ ] 包装完整
- [ ] 数量准确
- [ ] 附赠品齐全

### 设备类验收
- [ ] 功能正常
- [ ] 配件齐全
- [ ] 电池满电/备用电池
- [ ] 存储卡清空/格式化
- [ ] 提前测试运行

### 内容类验收
- [ ] PPT内容审核通过
- [ ] 格式统一规范
- [ ] 视频/音频可正常播放
- [ ] 链接/二维码可正常访问
- [ ] 备份文件已准备
