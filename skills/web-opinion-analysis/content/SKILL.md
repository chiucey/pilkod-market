# 舆情监测自动化流水线 Skill v1.1.0

> 升级版：使用 OpenClaw 内置工具（batch_web_search + extract_content_from_websites + LLM）
> 无需pip安装NLP依赖，兼容所有OpenClaw环境

---

## 功能概述

自动完成以下工作：
1. **主题搜索** — 用 batch_web_search 搜索相关最新内容
2. **深度抓取** — 用 extract_content_from_websites 抓取重点URL正文
3. **LLM分析** — 用内置LLM进行情感/实体/趋势分析
4. **报告生成** — 输出结构化Markdown报告

---

## 标准化执行流程

### Step 1：接收主题输入

用户说"舆情监控 + 主题词"，提取主题。

### Step 2：批量搜索

使用 `batch_web_search` 搜索：
- `[主题] 最新动态 2026`
- `[主题] 行业新闻`
- `[主题] 政策 监管`

每个查询取前5-8条结果。

### Step 3：抓取重点URL

从搜索结果中筛选3-5个重点URL，用 `extract_content_from_websites` 抓取正文。

### Step 4：LLM综合分析

将正文内容交给LLM，要求输出：
- 情感分析（正面/中性/负面 + 置信度）
- 关键事件提炼（3-5条）
- 涉及机构/人名/地点
- 热点关键词TOP5
- 趋势判断
- 投行点评

### Step 5：生成报告

输出文件：`/workspace/opinion_reports/{日期}/{主题}_舆情报告_{时间}.md`

同时在对话中输出摘要。

## 异常处理

| 情况 | 处理 |
|------|------|
| 搜索0结果 | 换关键词重试，或告知用户"该主题暂无足够数据" |
| URL抓取失败 | 跳过该URL，标记"[抓取失败]"，不影响其他内容 |
| 正文过短（<200字） | 标记"[内容不足]"，不进行深度分析 |
| 用户无具体主题 | 默认监控：宏观经济 + AI科技 + A股市场 |
