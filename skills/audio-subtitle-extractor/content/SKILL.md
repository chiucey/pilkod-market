# 音频字幕提取器

提取用户提供的音频文件中的字幕内容，并生成可下载的字幕文件。

## 工作流程

### 1. 接收音频文件
- 接收用户上传的音频文件
- 支持格式：MP3、WAV、M4A、FLAC、OGG、WMA、AAC
- 使用 `audios_understand` 工具进行音频转写

### 2. 处理音频
- 将音频文件路径传递给 `audios_understand` 工具
- 请求详细的转写结果，包括时间戳信息
- 如果音频过长（超过10分钟），提示用户分段处理

### 3. 生成字幕文件
根据用户选择的格式生成字幕：

**SRT格式（推荐）：**
```
1
00:00:00,000 --> 00:00:02,500
第一段字幕文本

2
00:00:02,500 --> 00:00:05,000
第二段字幕文本
```

**VTT格式：**
```
WEBVTT

00:00:00.000 --> 00:00:02.500
第一段字幕文本

00:00:02.500 --> 00:00:05.000
第二段字幕文本
```

**TXT格式：**
纯文本逐行输出，无时间戳

### 4. 保存字幕文件
- 将字幕内容保存到 `extract/` 目录
- 文件命名：`原文件名_字幕.格式`
- 返回下载链接给用户

### 5. 显示结果
- 在对话中展示提取的字幕内容
- 提供下载链接
- 显示音频总时长和字幕段数

## 错误处理
- 音频无法识别：提示用户音频质量问题或语言问题
- 格式不支持：列出支持的格式列表
- 转写失败：建议用户尝试其他工具或检查音频质量
