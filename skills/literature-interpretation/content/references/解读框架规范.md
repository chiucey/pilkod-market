# 解读框架规范

本文档为 literature-interpretation 技能提供标准化解读框架，所有深度解读必须严格遵循本文档的要求。

---

## 一、科研故事大白话版写作规范

### 核心逻辑（五步叙事法）

按以下逻辑展开，不得打乱顺序：

```
① 他们想解决什么问题
② 以前的方法哪里不行
③ 他们用了什么新招
④ 结果怎么样
⑤ 这项研究牛在哪
```

### 写作要求

- **用词**：选择日常用语，避免专业术语堆砌
- **比喻**：能用比喻的地方就用比喻，让非专业人士也能理解
- **数据**：关键数据要具象化（如"提高了3倍"改为"从10%提升到30%"）
- **篇幅**：300–500字，简洁有力
- **语气**：客观中性，不夸大，发现局限性时也要如实指出

### 示例框架

> 这群科学家想解决的问题是：**（一句话说清楚研究目标）**。此前，虽然有人尝试过用**（前人方法）**来解决，但效果有限——主要是因为**（前人方法的问题）**。这次，研究团队采用了**（本文新方法/思路）**，在一系列精心设计的实验后，他们发现**（核心发现，用数据说话）**。这个发现牛在**（创新点概括）**，为**（应用场景/领域）**提供了全新思路。

## 二、题目解读范式

### 题目结构三段式

```
前置定语（核心创新点）+ 中心词（研究对象）+ 后置定语（应用领域/条件）
```

### 解析步骤

1. **找中心词**：题目中代表研究对象的词（如"mechanism"、"framework"、"model"）
2. **找前置定语**：中心词前面描述核心创新点的词（如"novel"、"dual-target"、"lightweight"）
3. **找后置定语**：中心词后面描述应用场景或限制条件的词（如"in pest management"）
4. **提炼创新点**：从前置定语判断本文最核心的创新点

### 示例

题目："A lightweight deep learning framework for real-time pest detection in agricultural fields"

| 成分 | 内容 |
|------|------|
| 前置定语（创新点） | lightweight deep learning |
| 中心词（研究对象） | framework |
| 后置定语（应用领域） | for real-time pest detection in agricultural fields |
| 核心创新点 | 轻量化深度学习框架（又快又轻，适合田间实时检测） |

## 三、摘要五步法详解

| 步骤 | 标题 | 内容要求 | 篇幅 |
|------|------|---------|------|
| 1 | 背景 | 交代该问题的科学/现实重要性，为什么值得研究 | 1–2句 |
| 2 | 问题 | 前人工作的关键局限性 + 本文要解决的科学假设 | 1–2句 |
| 3 | 方法 | 核心实验/模型/分析手段，突出创新方法 | 2–3句 |
| 4 | 结果 | **关键数据加粗**，最重要的1–3个发现 | 2–3句 |
| 5 | 意义 | 理论贡献或应用价值，对领域的推动作用 | 1–2句 |

> 顺序不可颠倒。"结果"部分必须包含具体数值。若某步骤原文未明确说明，解读时注明"原文未明确提及"。

## 四、引言起承转合解析

| 部分 | 英文对应 | 内容 | 段落位置 |
|------|---------|------|---------|
| **起** | Background | 研究的大背景是什么，领域现状 | 引言第1段 |
| **承** | Literature Review | 前人做了什么，关键研究有哪些 | 引言前1/2 |
| **转** | Gap Identification | 前人工作的局限性是什么，存在哪些知识缺口 | 引言中段 |
| **合** | Paper Objectives | 本文如何切入，有什么创新和贡献 | 引言最后1–2段 |

**解读要点：**
- **起**：关注作者如何定义大背景——社会需求还是科学前沿？
- **承**：关注引用文献的时间分布——是否涵盖最新进展？
- **转**：关注作者如何描述前人不足——是否客观、有依据？
- **合**：关注作者如何定位本文创新——方法创新还是理论创新？
