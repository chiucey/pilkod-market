# 术语规范

本文档为 literature-interpretation 技能提供标准化的术语分类与中文表达规范，确保解读内容的一致性和专业性。

---

## 一、创新点类型分类

解读时，须判断论文的核心创新属于以下哪种类型（或多种组合）：

| 类型 | 定义 | 常见表达 |
|------|------|---------|
| **结构创新** | 提出新的物质结构、体系或组织形式 | "首次揭示了…三维结构"、"构建了…网络架构" |
| **材料创新** | 发现或合成新型功能材料 | "合成了一种新型…材料"、"开发了…复合材料" |
| **性能创新** | 在某项性能指标上取得突破性提升 | "将灵敏度提高了…倍"、"在…条件下实现了…" |
| **机制创新** | 揭示了新的因果关系或作用机理 | "首次阐明了…机制"、"揭示了…信号通路" |
| **方法创新** | 创建了新的研究工具、分析方法或算法 | "建立了…分析方法"、"开发了…算法/模型" |
| **体系创新** | 整合多项技术形成完整系统或方案 | "构建了…一体化平台"、"建立了…标准流程" |

### 判断方法

根据论文题目的前置定语判断：
- 含"novel"、"new"→ 重点关注材料/结构/方法创新
- 含"efficient"、"high-performance"→ 重点关注性能创新
- 含"mechanism"、"reveal"→ 重点关注机制创新
- 含"framework"、"system"、"integrated"→ 重点关注体系创新

## 二、图表类型分类

解读时，须判断每张图表支撑了哪种功能，并说明其与创新点的关联：

| 类型 | 功能描述 | 常见图表形式 |
|------|---------|------------|
| **结构表征图** | 展示物质的微观/宏观结构形态 | SEM、TEM、XRD、AFM、模式图 |
| **性能测试图** | 呈现实验数据或性能指标 | 折线图、柱状图、热图、ROC曲线 |
| **机理分析图** | 解释因果关系或工作原理 | 流程图、示意图、信号通路图 |
| **理论计算图** | 展示模型预测或仿真结果 | 散点图、等高线图、能量图 |
| **对比验证图** | 新方法/材料与现有方法的对照 | 对比柱状图、误差分析图 |

### 图表解读要求

每张图表解读必须包含：
1. **这张图展示了什么**（一句话概括）
2. **关键数据**（用加粗标注具体数值）
3. **支撑哪个创新点**（说明图的结论如何支持核心/分创新点）

## 四、术语使用注意事项

- **首次出现**：关键术语首次出现时附英文原文
- **避免堆砌**：图表解读和结果描述中不要堆砌术语，保持可读性
- **具象化数据**：百分比、倍率等数据要给出具体对比值
- **中性表达**：客观描述结果，避免"首次"、"第一"等绝对化表述（除非原文明确说明）
