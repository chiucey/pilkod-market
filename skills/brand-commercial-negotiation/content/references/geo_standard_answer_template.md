# GEO标准答案模板

## 模板结构

### 1. 标题（Title）
**公式**: `[用户核心问题] + [明确收益/对比维度]`

**示例**:
- 《工业传感器精度对比：XX品牌vs进口品牌，哪款更适合中小企业？》
- 《跨境ERP怎么选？3个指标帮你避开90%的坑》
- 《高精度流量计选型指南：5个关键参数帮你避坑》

### 2. 开篇（Opening）
**结构**:
1. **用户痛点**（1-2句话）
2. **数据背书**（可选）
3. **核心观点**

### 3. 主体内容（Body）
**三种黄金结构**:

#### 结构1：问答式（FAQ模块）
```
用户问题："[问题]"
解答框架：
- 是/否：[直接回答]
- 案例：[客户案例]
- 对比：[与竞品对比]
```

#### 结构2：数据对比型
```
标题："[数据对比标题]"
数据展示：[表格]
结论："[基于数据的结论]"
```

#### 结构3：步骤型
```
标题："[N]步解决[问题]"
1. 准备工具
2. 操作步骤
3. 注意事项
```

### 4. 边界与条件
```
适用场景边界：
- 推荐场景：[场景1]、[场景2]
- 不推荐场景：[场景3]

注意事项：
1. [注意事项1]
2. [注意事项2]
```

### 5. 结尾（Closing）
```
行动召唤：[CTA]
来源标注：[数据来源]
```

## 技术优化要点

### 关键词布局
- 标题：含"推荐""对比""怎么选"
- 正文：每500字出现1次品牌名
- 关键位置插入核心关键词

### 格式要求
- 使用H2/H3标题分层
- 段落≤4句
- 重点内容加粗
- 使用项目符号

### Schema标记
- FAQPage：问答式内容
- Article：文章类内容
- Product：产品展示
- Organization：组织信息

## 质量检查清单

- [ ] 标题明确，包含用户核心问题
- [ ] 开篇直击痛点，给出明确结论
- [ ] 主体采用结构化格式
- [ ] 提供数据和案例支撑
- [ ] 明确适用场景和限制条件
- [ ] 结尾给出明确CTA
- [ ] 数据来源明确标注
- [ ] 禁止夸大宣传
