# AI 内容生成提示词模板

## 一、文章标题生成

### 基础模板
```
你是一位资深的新媒体内容策划专家。请根据以下选题，生成5个吸引人的微信公众号文章标题。

选题：{topic}
目标读者：{target_audience}
文章风格：{style}

要求：
1. 每个标题控制在20-30字
2. 具有吸引力，能引发好奇心
3. 体现文章核心价值
4. 避免标题党，保持内容相关性

请以列表形式输出：
```

### 爆款标题模板
```
请为以下主题生成10个爆款标题，涵盖不同类型：

选题：{topic}

标题类型要求：
1. 数字型（3-5个）：如"5个技巧让你..."
2. 悬念型（2-3个）：制造好奇和期待
3. 情感型（2-3个）：引发情感共鸣
4. 利益型（2-3个）：直接点明好处

输出格式：
【数字型】
1. ...

【悬念型】
1. ...

【情感型】
1. ...

【利益型】
1. ...
```

## 二、文章正文生成

### 完整文章模板
```
请为微信公众号撰写一篇优质文章。

## 基本信息
- 主题：{topic}
- 目标读者：{target_audience}
- 文章类型：{article_type}（知识科普/经验分享/产品介绍/热点评论）
- 风格调性：{tone}（专业严谨/轻松活泼/亲切温暖/犀利直接）
- 字数要求：{word_count}字左右

## 结构要求
请采用以下结构：
1. 开头：引发兴趣（150-200字）
   - 场景描述/痛点切入/数据引入
2. 核心内容：分{chapter_count}个章节
   - 每个章节：300-500字
   - 包含小标题、案例/数据、要点总结
3. 结尾：总结升华+互动引导（100-150字）
   - 核心观点回顾
   - 情感共鸣
   - 开放性问题引导留言

## 特殊要求
- 在适当位置添加"📌"、"💡"、"⚠️"等emoji标记重点
- 引用他人观点时使用引用块样式
- 复杂概念用简短案例解释
- 避免过长段落，单段不超过150字

## 排版标记
使用以下Markdown标记（用于后续转HTML）：
- # 一级标题
- ## 二级标题
- ### 三级标题
- > 引用块
- **加粗** 重点强调
- {image-placeholder:X} 图片占位符（X为图片描述）
- --- 分割线

请开始撰写：
```

### 分章节生成模板
```
请为"第{chapter}章：{chapter_title}"撰写300-500字的正文内容。

章节主题：{chapter_theme}
目标：{chapter_goal}
已有内容摘要：{context}

要求：
1. 语言风格：{style}
2. 包含1-2个相关案例或数据
3. 结尾有本章节要点总结
4. 使用{image-placeholder:X}标记需要配图的位置

输出：
```

## 三、配图描述生成

### 封面图描述
```
请为微信公众号文章生成封面图的AI绘图提示词。

文章标题：{title}
文章主题：{topic}
目标读者：{audience}
品牌调性：{brand_style}

要求：
1. 描述应为英文
2. 风格：现代简洁、专业大气
3. 突出主题核心元素
4. 避免文字（封面图不宜有太多文字）
5. 适合竖版（900 x 383像素）
6. 颜色：明亮、对比度适中

示例格式：
"A modern minimalist illustration featuring [核心元素], with clean lines and soft gradients, professional tone, vertical composition, bright and inviting colors"

请生成3个不同风格的封面图提示词：
```

### 章节配图描述
```
请为以下章节内容生成配图描述。

章节标题：{chapter_title}
章节内容摘要：{summary}

要求：
1. 英文描述，50-100词
2. 风格与文章整体调性一致
3. 与章节内容高度相关
4. 可包含人物、场景、概念图等

请生成2个配图方案：
```

## 四、摘要/引导语生成

### 文章摘要
```
请为以下微信公众号文章生成摘要（digest）。

文章标题：{title}
文章正文：{content}

要求：
1. 长度：40-60字
2. 概括文章核心观点
3. 引发读者阅读兴趣
4. 避免泄露全部内容

输出：
```

### 关注引导语
```
请为文章结尾生成关注引导语。

公众号名称：{account_name}
文章主题：{topic}

要求：
1. 简洁有力，10-20字
2. 表达账号价值
3. 引导关注动作
4. 符合公众号风格

输出格式：
"如果你觉得这篇文章有帮助，欢迎关注【{account_name}】，获取更多{related_topic}干货。"
```

2. 与文章内容紧密相关
3. 能引发读者思考和讨论
4. 10-30字

输出：
```

要求：
1. 自然过渡，不生硬
2. 突出推荐文章价值
3. 引导点击阅读
4. 50字左右

输出：
```
