# 微信公众号自动发布工作流

全自动一站式解决方案：从选题 → 内容生成 → 配图 → 排版 → 发布草稿箱

## 工作流程

### 第一步：选题确认
- 解析用户提供的选题信息
- 提取核心主题、目标受众、文章风格
- 如信息不足，使用引导表单补充关键信息

### 第二步：内容生成
使用 AI 生成高质量公众号文章：
- 标题：吸引点击、符合平台调性
- 导语：引发兴趣、建立期待
- 正文：结构清晰、逻辑通顺、图文并茂
- 结语：总结要点、引导互动

**内容要求**：
- 字数建议 1500-3000 字
- 多级标题划分章节
- 每个章节配有引导语
- 适度使用表情符号增加生动性

### 第三步：配图生成
为文章生成配套图片：
- 封面图：1张，吸引眼球、概括主题
- 章节配图：3-5张，配合章节内容
- 图片风格：现代简洁、符合公众号阅读习惯
- 统一视觉风格

### 第四步：自动排版
应用专业排版模板：
- 标题样式：突出醒目
- 正文字体：舒适易读
- 段落间距：留白合理
- 重点标注：加粗、引用块
- 引导关注：底部二维码占位

### 第五步：草稿发布
导出为微信公众号支持的格式：
- HTML 富文本格式
- Markdown 格式（可选）
- 附带完整配图下载链接
- 生成操作指引文档

## 输出产物

1. **article.html** - 排版好的完整文章（可直接复制到公众号编辑器）
2. **article.md** - Markdown 源文件
3. **cover.jpg** - 封面图
4. **images/** - 章节配图文件夹
5. **publish-guide.md** - 发布操作指引

## 快速开始

用户提供选题后，直接执行完整工作流：
```
选题：{用户描述的主题}
```

## 错误处理

- 内容生成失败：提供草稿版本供用户修改
- 配图生成失败：使用占位图并提示用户补充
- 排版异常：回退到基础模板确保可用性
