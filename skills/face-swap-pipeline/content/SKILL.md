# 单次精确AI换脸 Skill

版本：2.1.0（在2.0.0基础上强化面部特征还原：脸型胖瘦逐项精确匹配参考图、底图眼镜原样保留）

## 定位与目标

复刻本地 ComfyUI 工作流「EpicrealismXL+Flux换脸」的核心逻辑，但**压缩为单次 image_edit 调用**，把所有节点的意图（InstantID身份迁移 + inpaint局部重绘 + adain肤色匹配 + Flux细节修复）全部翻译成自然语言约束，让 seedream 一次就理解该做什么、不该做什么。

**核心原则**：底图的一切（姿势、服装、发型、背景、构图、光照）都不动，只换脸，且一次到位。

## 1. 使用边界

### 1.1 应使用

- 用户发来两张图：一张底图（被换脸）+ 一张脸参考图（要换成谁）
- 用户说"把这张脸换到那张图上""帮我换脸""人脸替换"
- 用户有一张人物图，想把里面的人换成另一个人的脸
- 医疗新媒体场景：需要把医生形象合成到不同场景/服装/姿势的素材图中

### 1.2 不应使用

- 没有脸部参考图，只想生成新人物（用 image_gen）
- 需要换身体/服装/背景（那是整体图生图，不是换脸）
- 视频换脸（本技能只处理静态图片）
- 多人合影中只换某一个人的脸（需用户先裁切出单人）

### 1.3 输入要求

必须提供：
- **目标底图**：被换脸的图（人物身体/姿势/背景都保留这张）
- **脸部参考图**：要换成谁的脸（正面清晰照最佳）

**最佳实践**：脸部参考图的角度尽量接近底图人脸角度（都是正面就最好），角度差越大效果越差。

## 2. 执行流程（单次调用，不抽奖）

### 准备：图片上传

用户上传的是本地文件时，先用 `FileBatchUpload` 把两张图都上传获取 URL。
- `image_reference_url_list[0]` = 目标底图
- `image_reference_url_list[1]` = 脸部参考图

**尺寸规则**：保持底图原始比例。根据底图实际像素设置 width/height（长边不超过2048）。
- 竖图底图 → width:height ≈ 3:4 或 9:16
- 横图底图 → width:height ≈ 4:3 或 16:9
- 不确定时按底图方向选最接近的比例

### 单次换脸调用

**工具**：`image_edit`
**model_version**：`seedream_5.0_pro`（必须用最强模型，不能用flash）
**image_reference_url_list**：`[底图URL, 脸参考图URL]`

**Prompt 模板（完整复制，不要删减任何一行）**：

```
你是一个专业的人脸替换工程师。现在有两张参考图：
- 参考图1：目标底图，保留这张图的一切
- 参考图2：面部人物参考，只取这张图的面部身份特征

执行精确换脸操作：将参考图1中人物的面部，替换为参考图2中人物的面部身份特征。

【严格保持参考图1完全不变的内容——以下每一项都不能动】
1. 人物头部的角度、朝向、姿势、表情状态
2. 身体姿态、服装、发型、手部位置、配饰
3. 眼镜：底图人物若戴眼镜，镜框样式、镜片颜色与反光、佩戴位置与角度必须原样保留，不得摘除、更换或改变
4. 背景场景、构图、所有物体的位置和大小
5. 光照方向、阴影位置、色温、画面整体色调
6. 画面中除面部区域以外的所有像素

【只修改面部区域——以下是面部要达到的效果】
1. 脸型与胖瘦严格匹配参考图2：脸宽与脸长比例、下颌线形状（圆脸/方脸/瓜子脸/长脸）、颧骨位置与宽度、咬肌大小都必须与参考图2一致，不得保留参考图1的脸型与胖瘦特征
2. 五官形状严格匹配参考图2：眼睛大小与形状、眉毛粗细与形状、鼻型、嘴唇厚薄、耳型
3. 面部骨骼结构匹配参考图2：额头宽度、眉骨、下颌骨
4. 面部肤色、光影、色温必须完全融入参考图1的光照环境——不能出现参考图2的光源方向，面部看起来就是在参考图1的环境里被照亮的
5. 面部皮肤纹理自然真实，有真实皮肤质感，不要过度磨皮
6. 面部与头发、耳朵、颈部、衣领的边缘过渡柔和自然，无任何拼接痕迹
7. 五官细节清晰，眼睛有神，嘴唇质感真实
8. 相似度优先级：当参考图1的脸型/胖瘦与参考图2冲突时，一律以参考图2为准，不要为了贴合底图而保留底图的面部特征

【禁止事项】
- 不要改变参考图1中除面部以外的任何内容
- 不要美化、美颜、瘦脸，保持真实感
- 不要改变面部表情，保持参考图1的表情状态
- 不要移除、新增或更换参考图1中的眼镜：底图戴眼镜必须保留，底图不戴眼镜则不要添加
- 不要添加或移除任何物体
```

## 3. 第一次结果出来后怎么办

### 3.1 一次成功（理想情况）

直接通过 `RichMediaCard` 交付，任务完成。

### 3.2 不够像（脸不像参考图2的人）

**不要重新生成整张图**，用微调指令第二次调用：

**工具**：`image_edit`
**image_reference_url_list**：`[第一次结果图URL, 脸参考图URL]`

**Prompt**：
```
这张图的面部身份特征还不够像参考图2的人物。请加强面部与参考图2的相似度：
- 重点修正脸型与胖瘦：脸宽、下颌线形状（圆脸/方脸/瓜子脸/长脸）、颧骨位置、咬肌大小必须与参考图2完全一致，参考图2是圆脸就不能是尖脸，是瘦脸就不能是胖脸
- 调整五官形状、眼睛眉毛形状、鼻型、嘴唇厚薄，使其更接近参考图2的人物
- 保持参考图1的姿势、表情、服装、背景、光照完全不变
- 保持面部肤色与环境光匹配
- 其他所有内容不要动
```

### 3.3 边缘有痕迹 / 肤色不匀

**不要重新生成整张图**，用微调指令第二次调用：

**工具**：`image_edit`
**image_reference_url_list**：`[第一次结果图URL]`

**Prompt**：
```
这张图的面部边缘有拼接痕迹，肤色不均匀。请修复：
- 面部与头发、耳朵、颈部的边缘过渡柔和自然
- 面部肤色与颈部、耳朵的肤色统一
- 保持面部五官形状和身份特征完全不变
- 其他所有内容不要动
```

### 3.4 底图其他部分被改了

**不要重新生成**，用微调指令第二次调用：

**工具**：`image_edit`
**image_reference_url_list**：`[原始底图URL, 第一次结果图URL]`

**Prompt**：
```
参考图1是原始底图，参考图2是换脸后的图。请把参考图2中被错误修改的非面部区域恢复成参考图1的样子：
- 身体、服装、背景、构图全部恢复成参考图1
- 只保留参考图2中已经换好的面部
- 不要重新换脸，不要改变面部
```

### 3.5 眼镜丢失 / 眼镜被换掉

**不要重新生成整张图**，用微调指令第二次调用：

**工具**：`image_edit`
**image_reference_url_list**：`[第一次结果图URL, 原始底图URL]`

**Prompt**：
```
参考图2是原始底图，参考图1是换脸后的图。参考图1中人物的眼镜丢失了（或镜框样式被改变了），请恢复：
- 严格按照参考图2中眼镜的样式（镜框形状、颜色、粗细、镜片反光）、佩戴位置与角度，把眼镜原样加回到参考图1人物脸上
- 眼镜贴合面部，镜片透明可以透出眼睛，光影与参考图2一致
- 面部五官、脸型、身份特征完全保持不变
- 其他所有内容不要动
```

注：以上默认保留"底图人物佩戴的眼镜"。如果用户明确要求换成参考图2人物戴的眼镜样式，须在换脸指令中单独说明，否则一律保留底图眼镜。

## 4. 单次成功率最大化技巧

| 技巧 | 做法 | 为什么 |
|---|---|---|
| 用最强模型 | seedream_5.0_pro | 身份保持能力最强，一次成功率最高 |
| 参考图顺序 | 底图在前，脸参考在后 | 模型优先理解第一张图是"要保留的底图" |
| prompt结构化 | 分【保持不变】【只修改面部】【禁止事项】三段 | 模型对结构化指令执行更精确 |
| 表情保持 | prompt明确写"保持参考图1的表情" | 防止模型把表情也改成参考图2的 |
| 不要过度要求 | 不要写"完美""极致"等模糊词 | 精确指令比形容词更有效 |
| 参考图角度匹配 | 脸参考图角度尽量接近底图人脸角度 | 角度差越大，一次成功率越低 |
| 脸型胖瘦还原 | prompt写明"脸宽、下颌线、颧骨、咬肌与参考图2一致，脸型冲突以参考图2为准" | 模型默认倾向保留底图脸型导致不像，必须显式声明优先级 |
| 保留底图眼镜 | prompt明确"底图戴眼镜必须原样保留，不得摘除或更换" | 模型会把眼镜当作面部内容重绘，显式声明才能保住 |

## 5. ComfyUI 参数 → 自然语言 对照

| ComfyUI 节点/参数 | 在豆包prompt中的对应表达 |
|---|---|
| InstantID（身份迁移） | "脸型胖瘦（脸宽、下颌线、颧骨、咬肌）与五官形状、面部骨骼结构严格匹配参考图2，冲突时以参考图2为准" |
| InpaintModelConditioning（局部重绘） | "只修改面部区域，其他所有像素保持不变" |
| denoise=0.8（换脸强度） | "严格保持底图一切不变，只换面部身份特征" |
| MaskFastGrow + MaskComposite（边缘过渡） | "面部与头发、耳朵、颈部边缘过渡柔和自然，无拼接痕迹" |
| easy imageColorMatch adain（肤色匹配） | "面部肤色、光影、色温完全融入参考图1的光照环境" |
| Flux denoise=0.5（细节修复） | "皮肤纹理自然真实，五官细节清晰，不要过度磨皮" |
| KSampler euler/simple（采样器） | 不适用（seedream自动决定） |
| 眼镜保留 | "底图眼镜原样保留，不得摘除或更换" |

## 6. 使用示例

**用户说**："帮我把这张医生的脸换到那张白大褂肖像图上"

**执行**：
1. 用户上传两张图：医生正面照 + 白大褂底图
2. FileBatchUpload 上传获取URL
3. 单次 image_edit：参考图=[底图, 医生脸]，用完整prompt模板
4. 检查结果：
   - 满意 → RichMediaCard 交付，完成
   - 不够像（脸型/胖瘦/五官不像）→ 按3.2微调
   - 眼镜丢失或镜框被改 → 按3.5恢复
   - 边缘有痕 → 按3.3微调
   - 底图被改 → 按3.4恢复

**目标**：最多2次调用出最终结果（第1次主换脸 + 最多1次微调），不抽奖。
