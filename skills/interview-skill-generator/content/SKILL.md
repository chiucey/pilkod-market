# 访谈式技能生成器

通过引导式问答了解用户需求，自动生成完整的技能文件。

## 核心工作流程

### 阶段 1：需求发现（访谈）

使用 GenUI 表单向用户收集基本信息：

1. **技能基本信息**
   - 技能名称（英文，连字符格式）
   - 技能描述（中文，详细说明功能）
   - 触发短语（何时应该触发这个技能）

2. **功能需求**
   - 技能的主要功能是什么？
   - 有哪些具体的使用场景？
   - 需要哪些输入参数？
   - 期望的输出格式是什么？

3. **技术细节**
   - 是否需要外部工具或API？
   - 是否有特殊的执行环境要求？
   - 是否有依赖项或前置条件？

### 阶段 2：技能生成

根据访谈结果生成完整的技能结构：

```
skill-name/
├── SKILL.md              # 技能定义文件
├── _meta.json            # 元数据（id + version）
├── scripts/              # 可选：自动化脚本
├── references/           # 可选：参考资料
└── assets/               # 可选：资源文件
```

### 阶段 3：生成 SKILL.md

生成的 SKILL.md 必须包含：

1. **Frontmatter（必填）**
   ```yaml
   ---
   name: skill-name
   description: 技能描述，包含触发短语
   ---
   ```

2. **技能内容**
   - 清晰的执行流程
   - 具体的使用示例
   - 错误处理和边界情况

### 阶段 4：验证与交付

1. 调用 path-checker 验证路径和名称
2. 生成技能 ID（使用 generate_skill_id）
3. 创建 _meta.json
4. 打包交付

## 访谈问题模板

### 问题集 A：基础信息
- 技能叫什么名字？（英文，用连字符分隔）
- 用一句话描述这个技能是做什么的？
- 用户在什么情况下应该使用这个技能？

### 问题集 B：功能细节
- 这个技能的主要功能是什么？
- 能举个例子说明如何使用吗？
- 有没有特定的使用限制或注意事项？

### 问题集 C：技术要求
- 需要调用外部工具或API吗？
- 有特殊的依赖或环境要求吗？

## 技能生成示例

当用户说"我想创建一个定时提醒的技能"时：

1. 启动访谈表单
2. 收集：名称（schedule-reminder）、描述、触发条件
3. 生成完整 SKILL.md
4. 创建 _meta.json
5. 验证并交付

## 质量标准

生成的技能必须：
- [ ] Frontmatter 格式正确（name + description）
- [ ] 描述包含明确的触发短语
- [ ] 内容结构清晰、流程明确
- [ ] 包含实际可用的示例
- [ ] 路径和名称均为英文

## 快速启动

当用户请求创建技能时，立即启动访谈流程：

```
1. 显示欢迎信息
2. 启动访谈表单（GenUI）
3. 收集所有必要信息
4. 生成技能文件
5. 验证并交付
```
