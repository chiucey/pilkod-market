# 涟漪可视化 Skill

## 核心功能
使用内置 `image_synthesize` 工具，将投资分析内容转化为直观的可视化图表，服务于V的投资决策和报告。

## 适用场景

### 1. 市场情绪仪表盘
将当前市场情绪（VIX/资金流/趋势评分）生成一张综合仪表盘图
```
Prompt要求：专业金融风格，深色背景，VIX/恐惧贪婪指数/资金流向 三联仪表盘
风格：Bloomberg Terminal风格，专业数据可视化
```

### 2. 仓位结构图
将V的当前持仓比例（A股/美股/港股/币/现金）生成饼图
```
Prompt要求：简洁专业的持仓饼图，显示各资产类别占比，标注仓位比例和止损位
风格：资产管理报告风格
```

### 3. 情景分析矩阵
将A/B/C三种情景（乐观/基准/悲观）生成对比图
```
Prompt要求：三栏对比布局，乐观/基准/悲观三个情景的价格区间和概率
风格：投资银行研报风格
```

### 4. 每日市场简报封面
生成当日市场简报的封面图
```
Prompt要求：当日日期，沪深300/纳指/BTC收盘价，主要新闻标题摘要
风格：财经杂志封面风格，专业简洁
```

### 5. 标的分析雷达图
将七问评分的7个维度生成为雷达图
```
Prompt要求：七边形雷达图，七个维度（机会/评分/反向证据/理解度/体系匹配/时机/防误导）
风格：咨询公司PPT风格
```

### 6. 投资复盘记录配图
配合每日/每周复盘报告生成的图表
```
Prompt要求：收益率曲线图，标注建仓/止损/止盈点
风格：TradingView截图风格
```

## 图像生成标准规范

### 涟漪图像Prompt模板

**标准开头（始终包含）：**
```
[资产类别] [标的] [分析类型] 
数据：[实际数据]
风格：Bloomberg/Reuters/专业投行研报
配色：深色主题（#0a0a0a底色，#00D4AA绿色，#FF6B6B红色，#FFFFFF白色文字）
```

**必须包含的信息：**
- 数据来源和时间戳
- 关键价格/比例数字
- 涟漪评分（如有）

**禁止包含的内容：**
- 虚假或未经核实的数据
- 未来价格预测（只展示情景分析）
- 个人隐私信息

## 输出规范

生成后的图像说明：
```
## 🖼️ 图像：[标题]
- 用途：
- 包含数据：
- 数据来源：
- 生成时间：
```
