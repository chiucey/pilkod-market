# 小鸡性别预测分析

## 工作流程

### 1. 图像采集与分析

使用 `images_understand` 工具分析鸡蛋照片，关注以下特征：

**形状指标**
- 长宽比：记录鸡蛋长度和宽度
- 钝端与尖端的比例
- 整体对称性

**颜色特征**
- 蛋壳主色调
- 颜色均匀度
- 是否有斑点或花纹

**表面纹理**
- 光滑程度
- 是否有粗糙区域
- 钙化点分布

### 2. 传统孵化性别预测方法

根据以下经验法则进行预测（准确率约60-70%供参考）：

| 特征 | 预测母鸡 | 预测公鸡 |
|------|----------|----------|
| 形状 | 较短圆、对称 | 较长、略微不对称 |
| 尖端 | 较钝 | 较尖 |
| 颜色 | 浅色系（白/米色） | 深色系（棕色/褐色） |
| 重量 | 较轻（相对） | 较重（相对） |

### 3. 输出格式

提供以下格式的分析报告：

```json
{
  "prediction": "母鸡 | 公鸡",
  "confidence": "低 | 中 | 高",
  "factors": {

    "color_analysis": "描述",
    "texture_analysis": "描述"
  },
  "traditional_method_score": {
    "hen_indicators": ["列表..."],
    "rooster_indicators": ["列表..."]
  },
  "disclaimer": "传统方法预测，仅供参考"
}
```

### 4. 注意事项

- 强调这只是基于外观的传统经验方法
- 实际性别由遗传基因决定（鸡蛋无法决定性别）
- 建议用户咨询专业孵化人员获取更准确的信息
- 预测结果仅供参考娱乐

### 5. 适用场景

- 用户上传鸡蛋照片
- 用户询问"这个鸡蛋会孵出公鸡还是母鸡"
- 用户对孵化小鸡性别好奇
- 用户需要根据性别预测进行孵化规划
