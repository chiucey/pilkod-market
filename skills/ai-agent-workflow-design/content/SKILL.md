# AI产品Agent工作流与场景化落地设计技能

## 技能定义

设计基于AI Agent的智能化工作流程，将大模型能力封装为可落地的产品功能，实现人机协作的效率提升和体验优化。

## 核心SOP

### 步骤1：场景识别与价值评估

**AI适用场景矩阵**：

| 场景类型 | 适用度 | 典型场景 | 核心价值 |
|---------|-------|---------|---------|
| 内容生成 | ★★★★★ | 文案/代码/图片生成 | 效率提升10x |
| 信息抽取 | ★★★★★ | 文档解析/结构化 | 降本80% |
| 对话交互 | ★★★★★ | 客服/助手/问答 | 7x24服务 |
| 决策支持 | ★★★★☆ | 推荐/匹配/排序 | 精准度提升 |
| 自动化执行 | ★★★★☆ | 任务编排/工具调用 | 人工替代 |
| 创意探索 | ★★★☆☆ | 头脑风暴/方案建议 | 拓展思路 |

**价值评估模板**：

| 维度 | 评估项 | 评分(1-5) |
|------|-------|----------|
| 效率价值 | 时间节省 | [1-5] |
| 质量价值 | 效果提升 | [1-5] |
| 成本价值 | 成本降低 | [1-5] |
| 体验价值 | 用户满意度 | [1-5] |
| 可行性 | 技术成熟度 | [1-5] |

```
└─────────────────────────────────────────────────────────────┘
```

**Agent类型选择**：

| 类型 | 自主程度 | 适用场景 | 实现复杂度 |
|------|---------|---------|-----------|
| ReAct Agent | 中 | 问答、简单任务 | ★★☆☆☆ |
| Plan-and-Execute | 高 | 复杂多步骤任务 | ★★★☆☆ |
| AutoGPT-style | 极高 | 开放式任务 | ★★★★☆ |
| Human-in-the-loop | 需确认 | 高风险操作 | ★★★☆☆ |

### 步骤3：人机协作设计

**交互模式选择**：

| 模式 | 适用场景 | 用户控制度 | 自动化程度 |
|------|---------|-----------|-----------|
| Fully Auto | 低风险、高频 | 最低 | 最高 |
| Auto + Review | 中风险 | 中 | 高 |
| Human-in-loop | 高风险 | 高 | 中 |
| Human-on-loop | 合规要求 | 最高 | 低 |

**Copilot设计模式**：

```
┌────────────────────────────────────────────────────────────┐
│                  Copilot 用户体验设计                       │
├────────────────────────────────────────────────────────────┤
│                                                             │
│  1️⃣ 输入阶段                                                │
│     ├─ 意图理解：「用户想要什么」                            │
│     ├─ 上下文收集：「需要什么信息」                          │
│     └─ 建议补全：「还有什么可以补充」                        │
│                                                             │
│  2️⃣ 执行阶段                                                │
│     ├─ 透明过程：「正在做什么」                              │
│     ├─ 进度反馈：「完成度如何」                              │
│     └─ 可中断：「用户可以随时干预」                          │
│                                                             │
│  3️⃣ 输出阶段                                                │
│     ├─ 多方案选项：「A/B/C方案」                            │
│     ├─ 解释说明：「为什么这样」                              │
│     └─ 接受修改：「可以这样调整」                           │
│                                                             │
└────────────────────────────────────────────────────────────┘
```

### 步骤5：效果评估与迭代

| 指标类型 | 具体指标 | 评估方法 |
