# 法律文书模板说明

## 一、文书模板清单

本技能提供以下法律文书模板：

### 1. 决议类模板

| 模板名称 | 用途 | 关键要素 |
|----------|------|----------|
| 股东出资确认决议 | 确认股东出资情况 | 认缴/实缴对比表 |
| 章程修改决议 | 修改公司章程 | 2/3以上表决权 |
| 债转股股东会决议 | 债权转为出资 | 关联股东回避 |

### 2. 协议类模板

| 模板名称 | 用途 | 关键要素 |
|----------|------|----------|
| 出资确认协议 | 确认欠缴出资及补缴 | 金额+期限+违约 |
| 往来款项确认协议 | 确认款项性质 | 出资/借款/代付 |
| 借款合同 | 股东与公司借款 | 金额+期限+利率 |
| 债转股协议 | 代垫款转出资 | 债权确认+转股条件 |

### 3. 对账函类模板

| 模板名称 | 用途 | 关键要素 |
|----------|------|----------|
| 股东出资对账函 | 与股东核对出资 | 认缴/实缴对比 |
| 出资实缴确认书 | 确认实缴情况 | 股东签字 |
| 往来款项性质确认书 | 确认款项性质 | 双方签字 |

### 4. 律师函类模板

| 模板名称 | 用途 | 关键要素 |
|----------|------|----------|
| 催缴出资律师函 | 催促足额缴纳出资 | 15日期限+法律后果 |
| 返还抽逃出资律师函 | 要求返还抽逃出资 | 利息计算+诉讼风险 |

## 二、模板使用流程

### 催缴出资流程

```
1. 核查出资情况
   └─ 编制欠缴明细表
2. 起草律师函
   └─ 使用"催缴出资律师函"模板
3. 发出催缴函
   └─ 保留送达凭证
4. 等待回复（15日）
5. 如未回复
   └─ 启动诉讼程序
```

### 债转股流程

```
1. 债权确认
   └─ 使用"往来款项确认协议"
2. 股东会决议
   └─ 使用"债转股股东会决议"模板
3. 签订协议
   └─ 使用"债转股协议"模板
4. 变更登记
   └─ 更新名册+工商登记
```

## 三、模板填充要点

### 出资确认协议填充要点

```
【必填项】
- 甲方（公司）信息
- 乙方（股东）信息
- 认缴出资额
- 实缴出资额
- 欠缴金额
- 补缴期限（建议15-30日）
- 违约金比例（建议0.05%/日）
- 违约责任条款

【可选项】
- 利息计算方式
- 分期缴纳安排
- 担保条款
```

### 律师函填充要点

```
【必填项】
- 收件人信息
- 欠缴/抽逃事实描述
- 具体金额
- 限期要求
- 法律依据（具体条款）
- 法律后果提示
- 律师事务所盖章
- 经办律师签字

【格式要求】
- 使用律师事务所抬头纸
- 挂号信或快递邮寄
- 保留邮寄凭证
```

## 四、质量检查清单

使用模板前请确认：

- [ ] 文件格式正确（.md/.docx）
- [ ] 必填项已全部填充
- [ ] 法律依据准确无误
- [ ] 金额计算正确
- [ ] 日期格式规范
- [ ] 签字盖章位置正确
- [ ] 副本份数充足
- [ ] 送达凭证已保留

## 五、输出格式

模板输出为两种格式：

1. **Markdown格式**（.md）
   - 便于编辑和审阅
   - 可直接复制到文档

2. **DOCX格式**（.docx）
   - 便于打印使用
   - 符合正式文书格式

---

**注意**：模板为标准格式，实际使用时请根据具体情况进行调整，建议在专业律师指导下使用。
