## 三、操作流程要点

### 章程修订流程

```
1. 提议（5个工作日）
   └─ 董事会/监事会/代表1/10以上表决权股东
2. 论证（10个工作日）
   └─ 律师法律论证 + 会计师财务论证
3. 通知（提前15日）
   └─ 书面通知载明议题
4. 决议（2/3以上表决权）
   └─ 制作会议记录、全体股东签字
5. 文件制作（5个工作日）
   └─ 章程修正案 + 股东会决议
6. 备案（30日内）
   └─ 向登记机关提交变更申请
```

### 债转股操作流程

```
1. 债权确认
   └─ 核查金额、性质、凭证
2. 价值评估
   └─ 编制评估报告
3. 股东会决议
   └─ 关联股东回避表决
4. 签订协议
   └─ 债转股协议
5. 修改章程
   └─ 载明出资方式变更
6. 变更登记
   └─ 更新名册 + 工商登记
7. 缴纳印花税
   └─ 实收资本×0.025%
```

### 抽逃出资识别标准

根据《公司法司法解释三》第12条，以下情形构成抽逃出资：

1. **制作虚假财务报表虚增利润进行分配**
   - 识别要点：利润分配与实际经营不符

2. **通过虚构债权债务关系将其出资转出**
   - 识别要点：无基础法律关系的资金往来

3. **利用关联交易将出资转出**
   - 识别要点：关联交易价格不公允

4. **其他未经法定程序将出资抽回的行为**
   - 识别要点：出资后短期内无正当理由转出等额资金

**举证要点**：银行流水是关键证据，需与工商登记、章程规定交叉比对。
