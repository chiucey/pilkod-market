# 鲸鱼行为分析方法

## 一、鲸鱼定义与分类

| 类型 | BTC持有量 | 信号权重 |
|------|----------|----------|
| 虾米 | < 1 BTC | 散户行为 |
| 螃蟹 | 1-10 BTC | 小户 |
| 鱼 | 10-100 BTC | 中户 |
| 鲸鱼 | 100-1000 BTC | 大户 |
| 超级鲸鱼 | 1000+ BTC | 机构级 |

## 二、关键监控指标

### 1. 鲸鱼余额变化

```
积累信号（看涨）：
- 鲸鱼地址余额增加
- 鲸鱼数量增加
- 长期持有币龄上升

抛售信号（看跌）：
- 鲸鱼余额减少
- 大额转至交易所
- 币龄下降
```

### 2. 大额转账监控

```
高风险信号（转至交易所）：
- 单笔 > 1000 BTC
- 多个鲸鱼同步转出
- 转入交易所热钱包

正常信号（钱包间转移）：
- 转至冷钱包
- 机构托管转账
- 交易所内部调拨
```

### 3. 历史准确率

```
鲸鱼买入信号 → 价格上涨：
准确率 ≈ 70%

鲸鱼卖出信号 → 价格下跌：
准确率 ≈ 65%

延迟性：
- 信号发出到价格反应：1-7天
- 部分信号可能是噪音
```

## 四、实战信号组合

### 强买入信号

```
同时满足：
✅ 鲸鱼余额增加
✅ 交易所余额下降
✅ MVRV < 2.0
✅ 价格不跌反涨

结论：主力暗中吸筹 → 买入信号强
```

### 强卖出信号

```
同时满足：
❌ 鲸鱼余额减少
❌ 大量转入交易所
❌ MVRV > 3.7
❌ 社交媒体热度极高

结论：主力高位派发 → 卖出信号强
```

## 五、注意事项

⚠️ 鲸鱼信号有延迟，不是实时价格预测
⚠️ 部分转账可能是正常运营（非抛售）
⚠️ 结合多个指标综合判断
⚠️ 仓位管理比选时更重要
