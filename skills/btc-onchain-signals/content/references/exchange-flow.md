# 交易所流量分析框架

## 一、核心概念

```
交易所净流入 = 转入交易所的BTC - 转出交易所的BTC

流入增加 → 抛压增加 → 看跌信号
流出增加 → 抛压减少 → 看涨信号
```

## 二、历史规律

| 时期 | 流量变化 | 价格走势 |
|------|----------|----------|
| 2022年熊市 | 大量流入交易所 | 持续下跌 |
| 2023年初 | 流出为主 | 筑底反弹 |
| 2024年初 | 持续流出 | 牛市启动 |

## 三、关键阈值

```
🟢 看涨信号：
- 交易所BTC余额创年度新低
- 连续净流出 > 30天
- 流出速度加快

🔴 看跌信号：
- 交易所BTC余额创年度新高
- 连续净流入 > 7天
- 大量BTC转入交易所
```

## 四、实战应用

### 信号1：交易所余额持续下降

```
观察：
- 交易所BTC余额减少
- 用户提币至个人钱包
- 持有意愿增强

信号强度：🟢 中等偏强
持续时间：通常预示中期趋势
```

### 信号2：大额BTC转入交易所

```
观察：
- 单笔1000+ BTC转入
- 多个地址同步转入
- 转入后价格承压

信号强度：🔴 警示信号
操作建议：减仓观望
```

### 信号3：稳定币入金能力

```
观察：
- 交易所稳定币余额
- 稳定币净流入
- 购买力储备

信号含义：
- 稳定币增加 = 潜在购买力
- 特别关注 USDT、USDC 余额变化
```

## 六、综合判断

⚠️ 交易所流量是滞后指标
⚠️ 需结合其他信号综合判断
⚠️ 短期波动可能有噪音
⚠️ 中期趋势更可靠
