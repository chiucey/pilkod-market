# MVRV指标深度解读

## 一、MVRV基础

```
MVRV = Market Value / Realized Value
     = 市值 / 实现市值

实现市值 = Σ(每枚BTC最后转移时的价格 × 数量)
```

## 三、交易信号阈值

```
🟢 买入区间：
- MVRV < 2.0 → 低估（+30分）
- MVRV < 1.75 → 极度低估（+50分）
- MVRV 跌破365日均线 → 局部底部信号

🟡 持有区间：
- MVRV = 2.0-3.7 → 正常估值
- 价格围绕已实现价格波动

🔴 卖出区间：
- MVRV > 3.7 → 高估（+30分）
- MVRV > 5.0 → 极度高估（+50分）
- MVRV > 7.0 → 历史泡沫区域
```

## 四、MVRV Z-Score

```
计算：Z = (MVRV - 均值) / 标准差

信号解读：
- Z < 0 → 市值低于平均成本
- Z = 0-3 → 正常区域
- Z > 3 → 超买区域
- Z > 7 → 历史顶部区域

当前数据（2025年）：
- MVRV Z-Score ≈ 2.84
- 历史标准：>3.7为高估
- 结论：仍有上涨空间
```
