# BTC 链上信号分析器

## 核心指标体系

### 1. MVRV 指标（市场价值/实现价值比率）

```
定义：市值与实现市值的比值
- MVRV = 1.0 → 市场均价 = 持有者平均成本
- MVRV > 3.7 → 高估区域 → 卖出信号
- MVRV < 2.0 → 低估区域 → 买入信号
- MVRV < 1.75 → 极度低估 → 强力买入信号

历史验证：
- 2021年1月 MVRV=7 → 市场顶部
- 2022年6月 MVRV=1.0 → 熊市底部
- 2024年1月 MVRV=1.7 → 买入机会，之后涨幅196%
- 当前（2025年）MVRV≈2.84 → 仍处于低估区域
```

### 2. 已实现价格（Realized Price）

```
定义：全网BTC的平均持有成本
计算：每枚BTC最后一次转移时的价格加权平均

交易信号：
- 当前价格 < 已实现价格 → 整体亏损状态 → 底部信号
- 当前价格 > 已实现价格 → 整体盈利状态 → 正常/偏高
- 当前价格 >> 已实现价格 → 泡沫区域 → 顶部信号

历史数据：
- 已实现价格通常为周期低点的2-3倍
- 2022年熊市底部：已实现价格约$16,000
- 2024年当前位置：已实现价格约$40,000-$50,000
```

### 3. SOPR 指标（支出产出比）

```
定义：已花费输出利润率
- SOPR > 1 → 整体盈利卖出
- SOPR < 1 → 整体亏损卖出
- SOPR 极端值 → 反转信号

交易信号：
🔴 SOPR > 3.5 → 极度贪婪 → 卖出信号
🟡 SOPR = 1.5-3.0 → 正常盈利 → 持有
🟢 SOPR < 1.1 → 恐慌抛售 → 买入机会
```

### 4. 交易所流量分析

```
关键指标：
- 交易所净流入↑ → 抛压增加 → 看跌
- 交易所净流出↑ → 抛压减少 → 看涨

交易信号：
🟢 交易所余额持续下降 → 长期持有趋势 → 买入信号
🔴 交易所余额大幅增加 → 抛压来袭 → 谨慎
🟡 大量BTC转入交易所 → 短期抛售准备 → 警示
```

### 5. 鲸鱼行为监控

```
鲸鱼定义：持有1000+ BTC的地址
监控指标：
- 鲸鱼积累信号：鲸鱼地址持续增持
- 鲸鱼抛售信号：大额转账至交易所
- 历史准确率：70%+的短期信号

交易信号：
🟢 鲸鱼余额增加 + 价格不涨 → 积累中 → 买入机会
🔴 鲸鱼余额减少 + 价格不跌 → 抛售中 → 卖出信号
```
