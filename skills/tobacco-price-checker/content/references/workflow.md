# 烟草价格核查工作流详解

## 网站信息

**目标网站**: 烟悦网 (https://www.yanyue.cn/)
- 国内知名的烟草信息网站
- 提供香烟品牌、价格、评测等信息

## 数据获取流程

### Step 1: 搜索品类
1. 打开烟悦网首页
2. 使用搜索框输入完整品类名称
3. 等待搜索结果加载

### Step 2: 提取价格
从搜索结果页面提取：
- 产品名称
- 规格/包装
- 价格信息
- 产品图片URL

### Step 3: 截图保存
- 截取价格展示区域的完整截图
- 保存为PNG格式
- 命名格式：`{品类名}_价格截图.png`

## Excel报告规范

### 文件命名
```
烟草价格核查_{日期}.xlsx
例：烟草价格核查_20260326.xlsx
```

### 列定义
| 列名 | 类型 | 说明 |
|------|------|------|
| 序号 | INTEGER | 从1开始的序号 |
| 品类名 | TEXT | 完整的烟草品类名称 |
| 价格信息 | TEXT | 价格文本，格式：¥XX.XX |
| 价格截图 | IMAGE | 本地PNG图片路径 |

### 输出路径
```
/workspace/downloads/烟草价格核查_{日期}.xlsx
```

## 注意事项

1. **网络稳定性**: 确保网络连接正常
2. **截图质量**: 确保截图清晰可读
3. **文件编码**: 使用UTF-8编码处理中文
4. **图片路径**: Excel中嵌入相对路径便于分享
