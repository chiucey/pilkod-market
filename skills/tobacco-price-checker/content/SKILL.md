# 烟草价格核查技能

## 工作流程

### 1. 接收核查品类

接收用户提供的待核查烟草品类名称列表（如"钻石（荷花）烤烟型"）。

### 2. 搜索价格信息

对每个品类执行以下操作：

1. 访问烟悦网 (https://www.yanyue.cn/)
2. 在搜索框输入品类名称
3. 获取搜索结果中的价格信息
4. 截取价格展示区域的截图

### 3. 生成Excel报告

创建Excel文件，包含以下4列：

| 序号 | 品类名 | 价格信息 | 价格截图 |
|------|--------|----------|----------|
| 1 | 钻石（荷花）烤烟型 | ¥XX.XX | [图片路径] |

### 4. 输出最终结果

将生成的Excel文件路径返回给用户。

## 技术实现

### 网页提取
- 使用 `extract_content_from_websites` 工具提取烟悦网搜索结果
- 使用 `look_picture` 工具截取价格截图

### Excel生成
- 使用 `minimax-xlsx` 技能生成Excel报告
- 图片以相对路径形式插入Excel

## 示例

**输入**：钻石（荷花）烤烟型

**输出**：
- Excel文件：/workspace/downloads/烟草价格核查_20260326.xlsx
- 包含完整的品类、价格、截图信息
