# 5AI超短线选股分析系统

## 支持的报告类型

### 类型一：5AI选股分析报告（多股横向对比）
5个AI对用户指定的股票池独立评分，三种方法综合排名，输出最优推荐。

### 类型二：个股深度分析报告（单股全面分析）
覆盖：基本面一览表 / 全年财报 / 单季财报 / 业务亮点 / 资金面 / 核心风险 / 机构观点 / 投资建议（短期/中期/长期/已持有）

## 核心评分逻辑（类型一）

5个AI（DeepSeek/Kimi/豆包AI/千问/MiniMax）对每只股票6个维度独立评分（1-10分）：

| 维度 | 权重 | 评分要点 |
|------|------|---------|
| 基本面 | 10% | 年报净利润增速、营收增长、股东情况 |
| 趋势强度 | 20% | 均线多头/空头、MACD方向、趋势持续性 |
| 资金动能 | 20% | 主力净流入/流出、量比、换手率 |
| 交易情绪 | 30% | 当日涨跌幅、市场情绪、板块热度 |
| 技术指标 | 10% | KDJ金叉/死叉、RSI超买超卖 |
| 风险 | 10% | 高位追涨风险、流动性风险、基本面恶化 |

## 三种排名方法

- **方法一（平均分法）**：5个AI加权得分取均值，高分优先
- **方法二（积分法）**：每AI对5股排名，第1名=1分，第2名=2分，汇总后总分最低最优
- **方法三（投票法）**：每AI前2名各1票，票数高优先

综合排名 = 三项排名之和最小者最优。

## 执行流程

1. **搜集数据**：用 `batch_web_search` 并行搜集每只股票最新行情和年报数据（使用最新公开数据）
2. **AI评分**：模拟5个AI独立评分，不同AI分值要有差异（体现不同风格）
3. **排名计算**：三种方法分别排名，加权汇总
4. **生成报告**：调用 `scripts/generate_report.py` 生成 .docx
5. **发送微信**：用 `upload_to_cdn` 上传，用 `message` 工具发微信
6. **保存文件**：保存至 `/workspace/股票分析/`

## 脚本用法

```bash
# 测试模式
python3 scripts/generate_report.py --test

# 个股深度报告
python3 scripts/generate_report.py --type single --date 20260427 \
    --stock "朗姿股份" --code "002612"

# 5AI选股报告
python3 scripts/generate_report.py --type 5ai --date 20260427 \
    --stocks "朗姿股份,和而泰,国林科技,汉邦科技,长春一东"
```

## 数据要求

- **时效性**：必须使用最新公开数据（搜索当日或近日行情）
- **基本面**：以最新年报/季报为准，注明数据日期
- **股价**：注明具体日期
- **风险提示**：必须包含"本报告仅供参考，不构成投资建议"

## 注意事项

- 5个AI评分必须各自独立，不同AI分值要有差异
- 停牌超过1周的股票标注"暂不纳入"
- 超短线止损不超过4%，止盈不超过7%，持仓1-3天
- 生成Word文档后自动发微信，无需用户手动操作
