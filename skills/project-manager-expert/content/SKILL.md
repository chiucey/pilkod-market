# 项目管理专家技能

## 核心能力

### 1. 文件审阅

**支持的格式：**
- PDF文档（项目计划、需求文档、会议纪要）
- Microsoft Project文件（.mpp）
- 其他Office文档（Word、Excel）

**审阅流程：**
1. 接收用户上传的文件
2. 提取关键信息：
   - 项目名称和描述
   - 阶段和里程碑
   - 任务列表和负责人
   - 时间线和截止日期
   - 资源分配
3. 生成结构化项目摘要

### 2. 项目跟踪

**跟踪维度：**
- **里程碑跟踪**：重点关注关键阶段完成情况
- **任务状态**：待处理、进行中、已完成、已逾期
- **关键时间点**：阶段截止日期、交付物日期
- **进度百分比**：整体进度和各阶段进度

**跟踪视图：**
```
项目进度总览
├── 整体完成度: XX%
├── 当前阶段: 阶段名称
├── 里程碑状态
│   ├── ✓ 已完成: N个
│   ├── → 进行中: N个
│   └── ⚠ 待开始: N个
└── 风险提示
    └── 逾期任务: N个
```

### 3. 提醒机制

**提醒类型：**

| 类型 | 频率 | 内容 |
|------|------|------|
| 每日提醒 | 每天固定时间 | 当日任务、即将到期任务 |
| 每周提醒 | 每周固定时间 | 周报、里程碑状态、风险预警 |
| 关键提醒 | 实时 | 任务逾期、里程碑到期 |

**提醒内容：**
- 今日待办任务
- 本周里程碑
- 即将到期（3天内）
- 已逾期任务
- 进度更新

### 4. 里程碑反馈

**反馈维度：**
1. **完成度评估**：已完成 vs 计划完成
2. **进度趋势**：提前/按时/延期
3. **风险等级**：高/中/低
4. **建议措施**：下一步行动

## 工作流程

### 流程1：项目初始化

```
用户上传文件
    ↓
解析文件内容
    ↓
提取项目信息
    ↓
生成项目摘要
    ↓
建立跟踪模板
```

### 流程2：日常跟踪

```
每日/每周检查
    ↓
更新任务状态
    ↓
检查里程碑进度
    ↓
识别风险项
    ↓
生成提醒报告
```

### 流程3：提醒设置

```
用户指定提醒时间
    ↓
配置提醒频率
    ↓
设置提醒内容
    ↓
激活提醒任务
```

## 使用示例

### 示例1：上传PDF项目计划

用户：
> "请审阅这个项目计划PDF，提取里程碑和关键时间点"

执行：
1. 使用extract_pdfs_full_content提取PDF内容
2. 识别里程碑节点
3. 提取关键日期
4. 生成项目摘要
5. 建立跟踪任务

### 示例2：设置提醒

用户：
> "每天上午9点提醒我检查项目进度，每周一出周报"

执行：
1. 使用create_cron_job创建每日提醒任务
2. 配置每周一提醒生成周报
3. 确认提醒配置

### 示例3：项目状态查询

用户：
> "当前项目进展如何？有哪些里程碑需要关注？"

执行：
1. 读取项目跟踪文件
2. 计算完成度
3. 识别进行中和待开始里程碑
4. 生成状态报告
