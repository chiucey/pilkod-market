> 适配普通账号（无资质认证）| 参考风格：彩色水彩手绘插画风 | 版本：v6.0

---

## ⚠️ 绝对优先：合规红线（任何情况下都不能突破）

### 🚫 绝对禁止的表达

| 违规类型 | 违规表达 | 违规原因 |
|---------|---------|---------|
| 承诺收益 | "保证赚钱"、"稳赚不赔"、"一定涨" | 违反《证券法》 |
| 保本承诺 | "本金安全"、"不会亏损"、"零风险" | 虚假承诺 |
| 具体荐股 | "XX股票必买"、"XX股票赶紧卖" | 无资质荐股 |
| 收益预测 | "持有X年翻倍"、"年化XX%" | 违规预测 |

### 🚫 绝对禁止的视觉元素

```
❌ 不要画任何具体的股票代码或K线图
❌ 不要画任何带收益数字的收益曲线
❌ 不要画任何"赚钱"相关的人民币/美元图案
❌ 不要画任何暗示"稳赚"的元素
❌ 不要画任何金融机构的logo或名称
```

## 图片风格（生成时必须严格遵循）

### 整体风格：彩色水彩手绘插画

与 story-book-generator 绘本风格保持一致，核心特征：

- **主要技法**：水彩手绘风格（Watercolor）+ 稚拙美（Naive Art）
- **表现手法**：拟人化动物角色 或 可爱 Q 版人物 + 符号化图标
- **质感**：透明晕染，自然笔触，手绘感
- **背景**：纯白极简，大量留白
- **线条**：非闭合轮廓，轻微颤抖感，圆润符号化图标

### 配色方案（严格按此执行）

```
背景色：纯白色 #FFFFFF（大量留白）

步骤/功能配色（莫兰迪水彩色系）：
- 砖红色系 #E8A598 / #F4B8B0（警示/紧急/第一步）
- 草绿色系 #A8D5A2 / #C5E8C0（成长/分配/第二步）
- 雾霾蓝色系 #B8D4E3 / #D0E8F0（稳健/配置/第三步）
- 香芋紫色系 #D4C5E8 / #E0D6F0（进阶/智慧/第四步）
- 金黄色系 #FFF3C4（金句引用框背景）
- 深灰色系 #4A4A4A / #666666（正文文字）

注意：所有颜色均为水彩手绘调色盘上的柔和莫兰迪色，严禁黑白线条图！
```

### 关键视觉元素（全部保留）

1. **胶囊型边框**：步骤标题用圆角矩形包裹，`[ STEP 1 ]` 白色字体放在彩色胶囊内
2. **虚线分割**：内容模块用虚线框包裹
3. **"人话"翻译**：专业术语旁括号标注大白话
4. **打勾打叉符号**：✅ 正确做法 / ❌ 错误做法
5. **金句引用框**：浅黄底色 #FFF3C4 + 双引号，右下角放置
6. **小灯泡图标**：Tips 或重点提示
7. **星星/闪光点装饰**：图标周围点缀
8. **手绘感线条**：边框和箭头不完美直线

### 构图比例

```
- 竖屏长图（3:4，1080×1440px）
- 主体角色占 60-70%
- 文字留白区域占 20-30%（左下角或右下角）
- 背景纯白，无复杂环境
```

## 工作流程

### 第一步：理解文案与合规检查

- 检查是否有承诺收益、保本、具体荐股等违规表达
- 识别核心主题、关键词数量
- 判断适用图片类型（封面图 / 步骤指南图 / 概念解释图 / 总结图）

### 第二步：确定账号定位

> "我是投资理财知识的学习者和分享者，不是专业人士。内容定位是：个人经验 + 知识科普，不构成投资建议。"

### 第三步：规划图片结构

**多图模式（推荐，2-5张）：**
- 每张标注序号（如 ①、② 或 上篇/下篇）
- 保持风格高度一致

### 第四步：生成图片 Prompt

**标准提示词模板（彩色水彩版）：**

```
彩色水彩手绘插画风格，小红书治愈系理财知识笔记。
纯白背景 #FFFFFF，大量留白。
莫兰迪水彩色系（砖红/草绿/雾霾蓝/香芋紫/金黄）。
画面包含：[具体内容描述]
视觉元素：[胶囊边框/虚线分割/人话翻译/打勾打叉/金句框/小灯泡/星星装饰] 全都要体现。
水彩晕染效果，透明笔触，手绘稚拙美感。
比例 3:4，无水印无违规内容。
```

**参考图必须传入（使用 `input_files` 参数）：**
```
/workspace/xhs_ref_01.jpg  — 参考图1（理财信息图：米白/米色背景+信息图网格布局+Q版卡通人物+红绿糖果色系）
/workspace/xhs_ref_01.jpg  — 参考图2（理财信息图：扁平化手绘+黑色闭合描边+符号化图标）
/workspace/xhs_ref_03.jpg  — 参考图3（理财三卡片：手绘笔记风+胶囊色块+黑色描边）
```

### 第五步：生成图片

使用 `image_synthesize` 工具：
- `input_files`：传入参考图（最多 3 张）
- `prompt`：第四步生成的 prompt
- `aspect_ratio`：**必须设为 `"3:4"`**
- `resolution`：设为 `"2K"`

### 第六步：输出配套文案

Markdown 格式，包含：
- **封面标题**：`一张图看懂 [核心主题]`
- **正文内容**：每个概念用 emoji + 简短解释
- **金句框文字**：提炼核心金句
- **结尾声明**：
  ```
  以上是我的学习笔记～
  投资有风险，入市需谨慎～
  一起学习，一起进步！✨
  ```
- **话题标签**：5-8个相关话题

### 第七步：合规复查

```
□ 没有"稳赚"、"保本"、"一定涨"等表达
□ 没有具体的股票/基金代码
□ 没有具体收益数字
□ 添加了"仅供参考"和"投资有风险"声明
□ 视觉元素没有违规内容
```

## 注意事项

- 风格必须为**彩色水彩手绘插画风**，严禁黑白线条图

- 一次最多生成 5 张图，超出则分批
- 所有理财内容必须附带"投资有风险，入市需谨慎"声明
