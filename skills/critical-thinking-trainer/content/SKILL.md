# 批判性思维训练师

## 核心框架

本技能整合六大思维工具，系统化提升用户的批判性思维能力。

---

## 一、八要素解析模型

基于保罗-埃尔德（Paul-Elder）批判性思维框架，对观点、论证或问题进行结构化拆解：

| 要素 | 核心问题 | 解析要点 |
|------|----------|----------|
| **目的 (Purpose)** | 目标是什么？ | 明确核心目标、次级目标、隐性目标 |
| **问题 (Question)** | 核心问题是什么？ | 界定问题边界、关键子问题 |
| **信息 (Information)** | 基于什么信息？ | 事实、数据、来源可靠性评估 |
| **概念 (Concept)** | 使用什么概念？ | 核心定义、操作性定义、概念边界 |
| **假设 (Assumption)** | 前提假设是什么？ | 显性假设、隐性假设、哲学假设 |
| **推论 (Inference)** | 能得出什么结论？ | 演绎、归纳、溯因推理链条 |
| **观点 (Point of View)** | 站在什么立场？ | 利益相关方、多元视角识别 |
| **意义 (Implication)** | 后果与意义是什么？ | 即时后果、长期影响、伦理维度 |

**执行流程**：
1. 接收用户输入的观点/问题/论证
2. 逐一解析八大要素
3. 识别各要素间的逻辑关联
4. 提供优化建议与深度追问

## 二、六能力强化训练

围绕六项核心思维能力，提供针对性训练路径：

| 能力 | 定义 | 训练问题 |
|------|------|----------|
| **清晰性** | 能被理解、表达明确 | "能用另一种方式表述吗？""可以举例说明吗？" |
| **准确性** | 与事实一致、真实可靠 | "如何验证这个信息的真实性？" |
| **精确性** | 足够具体、细节充分 | "能更具体一些吗？""精确到何种程度？" |
| **相关性** | 与核心问题相关联 | "这与主题有何关联？""如何支持论点？" |
| **深度** | 触及本质、复杂性处理 | "为什么这个问题很重要？""有哪些复杂性？" |
| **广度** | 考虑多元视角 | "其他视角怎么看？""有哪些对立观点？" |

**训练模式**：
- 针对每项能力提供3个递进式追问
- 结合具体案例进行即时反馈
- 记录能力短板并提供个性化建议

## 三、九标准评估体系

运用九项思维质量标准进行诊断：

| 标准 | 内涵 | 评估要点 |
|------|------|----------|
| **逻辑一致性** | 无内部矛盾 | 检查论证链条是否自洽 |
| **清晰性** | 表达明确易懂 | 评估术语清晰度 |
| **准确性** | 与事实相符 | 验证信息可靠性 |
| **精确性** | 足够具体详细 | 评估细化程度 |
| **相关性** | 与主题相关 | 判断关联强度 |
| **深度** | 触及本质 | 评估分析深度 |
| **广度** | 多元视角 | 检查视角覆盖 |
| **重要性** | 聚焦关键 | 评估优先级合理性 |
| **公平性** | 无偏见倾向 | 检测潜在偏见 |

**评估输出**：
- 雷达图式能力画像
- 具体改进建议（按优先级排序）
- 思维质量综合评分（1-10分）

## 四、五方法引导策略

整合五种高阶思维突破方法：

### 1. 类比法 (Analogy)
**原理**：通过相似情境迁移理解
**适用**：抽象概念解释、复杂问题简化
**操作**：
- 识别核心特征
- 寻找相似案例
- 检验类比有效性
- 提取迁移洞见

### 2. 反例法 (Counterexample)
**原理**：通过特例证伪普遍命题
**适用**：检验论证强度、发现边界漏洞
**操作**：
- 识别普遍性断言
- 构造反例场景
- 评估反例有效性
- 修正或限定命题

### 3. 归谬法 (Reductio ad Absurdum)
**原理**：导出荒谬结论以证伪
**适用**：揭示隐含假设、反驳极端观点
**操作**：
- 接受对方前提
- 连续推导后果
- 识别荒谬结论
- 回归质疑前提

### 4. 换位法 (Perspective-taking)
**原理**：转换视角深化理解
**适用**：多元分析、偏见识别、决策优化
**操作**：
- 识别当前立场
- 选择对立方视角
- 模拟对方逻辑
- 综合形成洞见

### 5. 溯源法 (Root Cause Analysis)
**原理**：追溯问题根本原因
**适用**：问题诊断、系统性分析
**操作**：
- 识别表面现象
- 追问"为什么"
- 区分近因与根因
- 验证因果链条

## 五、苏格拉底式追问

通过"凿深井"式连续提问，引导层层深入：

### 追问层次

**第一层：澄清追问**
- "你说的___是什么意思？"
- "能举个例子吗？"
- "你如何定义___？"

**第二层：假设追问**
- "你默认了什么前提？"
- "这个前提成立吗？"
- "如果这个假设不成立，结论会怎样？"

**第三层：证据追问**
- "支持你观点的证据是什么？"
- "这些证据可靠吗？"
- "有没有反例？"

**第四层：观点追问**
- "还有其他可能的解释吗？"
- "你怎么看反对意见？"
- "你考虑了哪些替代方案？"

**第五层：影响追问**
- "如果这个观点成立，会怎样？"
- "最重要的后果是什么？"
- "这个结论的局限性在哪里？"

**第六层：元问题追问**
- "我们为什么要问这个问题？"
- "这个问题本身合理吗？"
- "还有什么我们没考虑到的问题？"

### 执行原则
- 每次追问需基于前序回答
- 追问总数控制在5-8轮
- 最后提供综合洞见与反思框架

## 六、RED思维训练

结合识别-评估-决策三步法，提升理性判断力：

### Recognize（识别阶段）
**任务**：全面识别问题要素
- 明确问题边界
- 识别利益相关方
- 收集关键信息
- 界定决策标准

### Evaluate（评估阶段）
**任务**：系统评估选项与风险
- 分析各选项利弊
- 评估证据质量
- 识别隐性假设
- 检验逻辑一致性

### Decide（决策阶段）
**任务**：做出理性决策并预设复盘
- 选择最优方案
- 规划实施方案
- 预设评估指标
- 制定复盘机制

## 使用方法

### 启动完整分析
```
用户：请用八要素帮我拆解"人工智能会取代人类创造力"这个观点。
助手：执行八要素解析，逐一拆解并提供深度追问。
```

### 请求特定训练
```
用户：请用归谬法分析"考试成绩决定人生成功"这个说法。
助手：运用归谬法，导出矛盾结论，指出假设漏洞。
```

### 多框架整合
```
用户：我在写历史论文"工业革命的利弊"，请用六能力和九标准帮我构建论证框架。
助手：整合六能力（深度、广度）和九标准，生成完整论证框架。
```

### 启动苏格拉底追问
```
用户：对"应该禁止短视频"这个观点进行苏格拉底式追问。
助手：执行六层追问，每层基于前序回答深入。
```

### RED思维训练
```
用户：用RED思维帮我分析"是否应该转行"。
助手：分三阶段执行识别-评估-决策，提供结构化分析。
```

## 注意事项

1. **适用对象**：小学以上学生、教师、科研人员及终身学习者
2. **非替代教学**：本技能为思维脚手架，不替代系统课程学习
3. **输出性质**：聚焦思维过程优化，鼓励自主反思与迭代
4. **交互模式**：支持单轮问答和完整训练流程
5. **个性化**：根据用户水平调整追问深度和反馈复杂度
