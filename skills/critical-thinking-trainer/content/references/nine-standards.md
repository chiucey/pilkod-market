# 九标准评估体系详解

## 评估维度概览

九标准体系是评估思维质量的综合性工具，帮助识别论证的强项与弱项。

## 评分指南

| 评分 | 等级 | 描述 |
|------|------|------|
| 9-10 | 优秀 | 完美呈现，几乎无改进空间 |
| 7-8 | 良好 | 达到标准，有小幅度改进空间 |
| 5-6 | 一般 | 满足基本要求，需显著改进 |
| 3-4 | 不足 | 存在明显问题 |
| 1-2 | 严重不足 | 几乎无法接受 |

## 逐项详解

### 1. 逻辑一致性 (Logical Consistency)
**定义**：论证内部各部分无矛盾

**检查清单**：
- [ ] 论点之间不矛盾
- [ ] 结论与前提一致
- [ ] 整体论证结构合理
- [ ] 无循环论证

**典型问题**：
- 自相矛盾的声明
- 偷换概念
- 双重标准

### 2. 清晰性 (Clarity)
**定义**：表达能被理解，不含糊

**检查清单**：
- [ ] 术语定义明确
- [ ] 语句无歧义
- [ ] 结构层次清晰
- [ ] 关键概念可识别

**典型问题**：
- 模糊表达
- 术语未定义
- 隐喻使用不当

### 3. 准确性 (Accuracy)
**定义**：与事实和真相相符

**检查清单**：
- [ ] 事实陈述可验证
- [ ] 数据来源可靠
- [ ] 无虚假信息
- [ ] 无夸大或缩小

**典型问题**：
- 事实错误
- 数据造假
- 来源不可靠

### 4. 精确性 (Precision)
**定义**：足够具体和细化

**检查清单**：
- [ ] 提供具体细节
- [ ] 数量化表达
- [ ] 时间范围明确
- [ ] 边界条件清晰

**典型问题**：
- 过于笼统
- "大约"、"可能"过多
- 缺乏具体例子

### 5. 相关性 (Relevance)
**定义**：与核心问题直接相关

**检查清单**：
- [ ] 论据直接支持论点
- [ ] 无无关信息
- [ ] 关注核心问题
- [ ] 避免红鲱鱼策略

**典型问题**：
- 转移话题
- 无关论据
- 人身攻击

### 6. 深度 (Depth)
**定义**：触及问题复杂性

**检查清单**：
- [ ] 考虑多重因果
- [ ] 识别隐藏复杂性
- [ ] 处理困难问题
- [ ] 区分表面与本质

**典型问题**：
- 过于简单化
- 忽视复杂性
- 回避困难问题

### 7. 广度 (Breadth)
**定义**：考虑多元视角

**检查清单**：
- [ ] 识别对立观点
- [ ] 考虑替代解释
- [ ] 多元化思考
- [ ] 跨文化视角

**典型问题**：
- 单一视角
- 忽视对立观点
- 文化中心主义

### 8. 重要性 (Significance)
**定义**：聚焦关键问题

**检查清单**：
- [ ] 关注核心议题
- [ ] 优先级合理
- [ ] 不纠缠次要问题
- [ ] 权衡得当

**典型问题**：
- 次要问题占用大量篇幅
- 核心问题被边缘化
- 重要性判断失误

### 9. 公平性 (Fairness)
**定义**：无偏见、客观公正

**检查清单**：
- [ ] 公平对待各观点
- [ ] 无隐藏动机
- [ ] 利益冲突披露
- [ ] 承认局限性

**典型问题**：
- 偏见明显
- 动机不纯
- 不公平对待对立观点
