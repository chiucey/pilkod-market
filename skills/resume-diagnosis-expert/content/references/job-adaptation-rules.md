# 岗位适配规则

根据用户目标岗位类型，调整简历内容的表达重点和结构。

## 大厂岗位（阿里、腾讯、字节、美团等）

### 表达重点
- **标准化能力**：流程建设、SOP 设计、规范化管理
- **数据能力**：数据指标体系、AB 测试、数据驱动决策
- **项目管理**：跨团队协作、项目推进、复杂项目管理
- **规模化经验**：大规模团队、大流量平台、大促运营
- **方法论沉淀**：方法论输出、团队赋能、知识传承

### 表达风格
- 克制、专业、结构化
- 避免过度创业化和过度夸张
- 强调体系和流程，而非个人英雄主义

### 常用表达结构
- "搭建 [体系/机制]，支撑 [规模] 业务稳定运行"
- "主导 [项目]，协调 [X] 个部门，实现 [量化结果]"
- "沉淀 [方法论]，推广至 [X] 个团队/业务线"

### 需要弱化的内容
- 过强的个人英雄主义叙事
- 过于灵活的灰色地带操作
- 模糊的"灵活应变"能力

---

## 创业公司（A轮/B轮）

### 表达重点
- **从 0 到 1**：从无到有搭建业务/团队/体系
- **资源受限下拿结果**：有限资源下的创新和突破
- **多模块协同**：多业务线、多角色、多任务的协调能力
- **组织搭建**：团队组建、文化建设、人才培养
- **经营意识**：成本意识、效率意识、商业化意识

### 表达风格
- 有战斗感，能看到攻坚能力
- 务实，不虚，数字说话
- 体现灵活性和适应性

### 常用表达结构
- "从 0 到 1 搭建 [业务/团队]，在 [资源限制] 下实现 [结果]"
- "在 [行业/市场] 变化中，快速调整 [策略/方向]，实现 [结果]"
- "一人承担 [X] 角色，完成 [跨领域任务]"

### 需要弱化的内容
- 过于成熟的体系化表达（创业公司更需要灵活）
- 大厂背景下的螺丝钉心态
- 明确的流程依赖

---

## 销售管理岗

### 表达重点
- **团队规模**：直接管理人数、团队年度业绩
- **业绩达成**：个人/团队业绩完成率、增长幅度
- **客户转化**：客户开发成功率、转化率提升
- **拜访管理**：客户拜访量、拜访覆盖率、CRM 管理
- **销售 SOP**：销售流程、话术体系、客户分级管理
- **业绩复盘**：数据分析、问题诊断、策略调整

### 常用表达结构
- "管理 [X] 人销售团队，年业绩 [X] 万，完成率 [X]%"
- "搭建销售过程管理机制，围绕 [客户分层、拜访节奏、转化跟进]，提升团队 [指标]"
- "开拓 [行业/区域] 市场，从 0 到 1 建立 [客户开发体系]，年新增客户 [X] 家"

### 常用量化指标
- 业绩：年销售额、季度完成率、同比增长
- 客户：客户数量、客户质量、客户流失率
- 团队：团队规模、人效、月均产出

---

## 运营负责人岗

### 表达重点
- **用户/商户分层**：用户生命周期管理、分层运营策略
- **活动机制**：活动策划、运营活动设计、效果追踪
- **转化提升**：转化率、GMV、留存率
- **数据分析**：数据指标体系、数据驱动决策
- **运营策略**：策略制定、策略执行、效果迭代

### 常用表达结构
- "搭建用户分层运营体系，围绕 [用户分层维度]，设计 [运营策略]，实现 [量化结果]"
- "主导运营活动 [X] 场，结合 [用户生命周期] 和 [业务目标]，提升 [核心指标]"
- "从 0 到 1 搭建运营体系，完成 [指标追踪、活动机制、用户分层] 建设"

### 常用量化指标
- 用户：DAU/MAU、新增用户、留存率、转化率
- 交易：GMV、客单价、订单量、复购率
- 效率：活动转化率、运营人效、内容产出

---

## 业务负责人/总经理岗

### 表达重点
- **经营闭环**：收入增长、利润改善、成本控制
- **组织搭建**：团队规模、组织架构、人才梯队
- **战略判断**：行业洞察、市场判断、战略规划
- **跨部门协同**：多部门协作、资源整合、系统推进
- **业务模型设计**：商业模式、业务逻辑、增长模型

### 常用表达结构
- "统筹 [业务/部门] 整体运营，实现年收入 [X] 万，同比增长 [X]%"
- "从经营视角拆解 [获客、转化、激活、复购、履约、毛利] 链路，推动 [多部门] 协同"
- "主导 [战略级项目]，协调 [X] 个部门，推动业务从 [现状] 向 [目标] 演进"

### 常用量化指标
- 经营：收入、利润、增长率、成本控制
- 组织：团队规模、人员流失率、人效
- 业务：市场占有率、用户规模、GMV

---

## 供应链管理岗

### 表达重点
- **采购成本**：成本优化、供应商议价、品类管理
- **履约效率**：配送时效、履约成本、仓储周转
- **库存周转**：库存管理、滞销处理、库存周转率
- **供应商管理**：供应商开发、评估、淘汰机制
- **前后端协同**：采购与销售协同、仓储与配送协同

### 常用表达结构
- "优化供应链结构，将采购成本降低 [X]%，履约效率提升 [X]%"
- "搭建供应商评估体系，[供应商数量] 家供应商纳入管理，淘汰率 [X]%"
- "从经营视角推动 [采购、仓储、配送] 协同，提高供应链对前端增长的支撑能力"

### 常用量化指标
- 成本：采购成本、履约成本、成本降低率
- 效率：配送时效、履约周期、库存周转天数
- 质量：缺货率、损耗率、供应商质量评分

---

## 战略运营岗

### 表达重点
- **业务分析**：行业分析、竞品分析、数据洞察
- **经营诊断**：问题诊断、机会识别、策略建议
- **指标体系**：指标设计、数据追踪、效果评估
- **项目推进**：跨部门项目、项目管理、进度管控
- **管理机制**：流程建设、制度设计、运营规范

### 常用表达结构
- "搭建业务分析体系，定期输出 [行业洞察、竞品分析、经营诊断] 报告，支持 [决策]"
- "主导 [跨部门项目]，协调 [X] 个部门，推动 [复杂任务] 按期完成"
- "设计并落地 [管理制度/运营规范]，提升组织运营效率 [X]%"

### 常用量化指标
- 分析：报告产出数量、决策支持次数
- 项目：项目完成率、进度偏差、跨部门协作满意度
- 效率：流程审批效率、决策周期、管理半径

---

## 高管岗位（VP、总监及以上）

### 表达重点
- **经营结果**：收入、利润、市场份额、增长速度
- **组织能力**：组织规模、组织变革、人才梯队
- **业务模型**：商业模式创新、业务模式升级
- **战略判断**：长期规划、趋势预判、风险管控
- **复杂问题解决**：历史遗留问题、跨领域复杂问题
- **资源整合**：资本运作、政府关系、战略合作

### 常用表达结构
- "负责 [X] 亿规模业务，实现年收入 [X] 亿，同比增长 [X]%，利润 [X]%"
- "带领 [X] 人团队，完成 [组织变革/业务转型]，支撑公司 [战略目标]"
- "主导 [战略级项目]，整合 [内外部资源]，实现 [重大突破]"

### 常用量化指标
- 经营：收入规模、利润贡献、增长率、市场份额
- 组织：团队规模、管理幅度、人才密度
- 战略：战略项目数量、重大突破、创新成果

---

## 岗位适配决策流程

```
用户提供目标岗位？
├── 是 → 确定岗位类型 → 应用对应适配规则
├── 否 → 按通用求职竞争力处理
└── 不确定 → 询问用户或提供通用版本 + 定制建议
```

## 适配检查清单

- [ ] 是否针对目标岗位调整了表达重点？
- [ ] 是否使用了目标岗位常用的量化指标？
- [ ] 是否避免了与目标岗位不匹配的表达？
- [ ] 是否体现了目标岗位需要的关键能力？
- [ ] 整体风格是否与目标岗位文化相符？
