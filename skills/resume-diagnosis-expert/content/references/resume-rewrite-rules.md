# 简历重写规则

## 核心表达结构

### 1. 背景问题 + 关键动作 + 业务结果 + 经营价值

**格式**：
面对 [具体问题]，通过 [关键动作]，实现 [业务结果]，最终 [经营价值]。

**示例**：
面对门店复购不足、销售与运营协同成本高的问题，重构门店分层运营机制，围绕客户激活、优惠券触达、销售跟进和复购召回建立标准动作，提升商户运营效率和销售转化稳定性。

### 2. 动作动词 + 业务场景 + 规模/难度 + 结果

**格式**：
[动作动词] + [业务场景] + （围绕 [规模/难度]）+ ，实现 [结果]。

**示例**：
搭建销售过程管理机制，围绕客户分层、拜访节奏、转化跟进和复盘机制，提升团队打法标准化程度。

### 3. 从 0 到 1 + 机制搭建 + 结果验证

**格式**：
从 0 到 1 搭建 [体系/机制]，完成 [具体建设内容]，推动业务从 [旧状态] 转向 [新状态]。

**示例**：
从0到1搭建商户运营体系，完成门店分层、活动机制、复购召回、数据追踪和销售协同流程建设，推动业务从经验驱动转向流程化管理。

### 4. 经营视角 + 协同对象 + 业务闭环

**格式**：
从经营视角拆解 [价值链各环节]，推动 [多方协同]，形成 [业务闭环]。

**示例**：
从经营视角拆解获客、转化、激活、复购、履约和毛利链路，推动销售、运营、供应链、产品之间形成协同机制。

## 常用动作动词库

### 战略与规划
搭建、制定、重构、规划、设计、推动、统筹

### 团队与管理
组建、带领、管理、培养、激励、考核、优化

### 业务与运营
开拓、运营、维护、优化、提升、增长、转化、分析

### 流程与机制
建立、完善、规范、标准化、简化、自动化

### 数据与指标
搭建、构建、建立、追踪、监控、分析、优化

## 弱表达 vs 强表达对照

### 团队管理

| 弱表达 | 强表达 |
|-------|-------|
| 负责销售团队管理 | 搭建销售过程管理机制，围绕客户分层、拜访节奏、转化跟进和复盘机制，提升团队打法标准化程度 |
| 管理 10 人团队 | 从0到1搭建并管理 10 人业务团队，完成岗位分工、目标拆解、过程管理和绩效复盘体系建设 |

### 运营活动

| 弱表达 | 强表达 |
|-------|-------|
| 负责运营活动 | 基于用户分层、消费频次和转化节点，设计运营活动机制，提升活动转化效率和客户复购表现 |
| 参与活动策划 | 主导策划并落地 [X] 场运营活动，结合用户生命周期和业务目标，提升 [具体指标] |

### 战略决策

| 弱表达 | 强表达 |
|-------|-------|
| 参与公司战略制定 | 结合业务增长、供应链能力、客户结构和利润模型，参与制定阶段性业务策略，并推动销售、运营、供应链协同落地 |
| 协助制定计划 | 基于数据分析和市场洞察，协助制定季度业务目标，并拆解为可执行的行动计划 |

### 供应链

| 弱表达 | 强表达 |
|-------|-------|
| 优化供应链 | 围绕采购成本、履约效率、库存周转和商户需求，推动供应链品类与业务场景匹配，提高供应链对前端增长的支撑能力 |
| 负责采购 | 建立供应商评估和采购流程标准化体系，在保证质量的前提下降低采购成本 [X]% |

### 组织搭建

| 弱表达 | 强表达 |
|-------|-------|
| 负责团队搭建 | 从0到1搭建业务团队，完成岗位分工、目标拆解、培训机制和绩效复盘体系建设 |
| 招聘团队成员 | 主导核心岗位招聘，建立人才画像和面试评估标准，入职 [X] 个月内实现团队稳定产出 |

## 量化结果表达规范

### 可量化的维度

- **规模**：X 万用户、X 家商户、X 家门店、X 人团队
- **增长**：提升 X%、增长 X 倍、环比提升 X
- **效率**：效率提升 X%、成本降低 X%、周期缩短 X 天
- **质量**：满意度提升 X、投诉率降低 X%、留存提升 X%

### 量化表达示例

| 原表达 | 量化后表达 |
|-------|-----------|
| 用户增长显著 | 用户从 50 万增长至 120 万，增幅 140% |
| 提升转化率 | 将页面转化率从 2.3% 提升至 4.1%，提升 78% |
| 降低成本 | 优化供应链结构，将采购成本降低 12% |
| 提高效率 | 搭建标准化流程，将新人上手周期从 30 天缩短至 14 天 |

## 禁用表达

以下表达在重写时需要避免或替换：

1. **空洞动词**：参与、负责、协助、完成、支持
2. **模糊描述**：显著提升、大幅增长、明显改善、效果良好
3. **被动表达**：被安排、被要求、被指派
4. **模糊时间**：一段时间、近期、最近
5. **模糊数量**：一些、多个、不少

## 重写检查清单

- [ ] 是否使用了强动作动词开头？
- [ ] 是否包含了业务背景或问题？
- [ ] 是否量化了业务结果？
- [ ] 是否体现了经营价值或规模？
- [ ] 是否避免了空洞描述？
- [ ] 是否可以自圆其说（面试时能解释）？
