# 教材审校技能

## 核心能力

对教材、教科书、学术文档进行全面的多维度审校，涵盖以下内容类型：

| 内容类型 | 审查要点 |
|---------|---------|
| **文字内容** | 语法错误、拼写错误、标点符号、用词准确性、表述一致性 |
| **数学公式** | 公式正确性、符号规范、编号引用、格式统一 |
| **图形图像** | 清晰度、版权声明、分辨率、标注准确性 |
| **数据表格** | 数据一致性、表头规范、跨页处理、单位统一 |
| **参考文献** | 格式规范、完整性、可追溯性、DOI/URL有效性 |

## 审校工作流

### 阶段 1：内容接收与预处理

1. **接收审校材料**
   - 用户上传教材文件（支持格式：PDF、DOCX、MD、TXT）
   - 确认审校范围（全稿审校/章节审校/指定内容审校）
   - 记录用户特殊要求或关注点

2. **内容结构化**
   - 识别文档结构（章节、页码、图表编号）
   - 提取可审查的内容元素（文字段落、公式、图片、表格、参考文献）
   - 建立内容清单供逐一审查

### 阶段 2：分项审校

#### 2.1 文字内容审校

**审查项目**：
- 错别字检测（中英文）
- 语法错误识别
- 标点符号规范（中文顿号、书名号、引号等）
- 术语一致性检查
- 数字用法规范（阿拉伯数字vs汉字数字）
- 计量单位规范

**处理方式**：
- 逐段阅读，发现问题即时标记
- 记录问题位置（章节+段落/页码）
- 区分"必须修改"与"建议修改"

#### 2.2 公式审校

**审查项目**：
- 数学符号书写规范
- 上下标、正斜体/反斜体使用
- 公式编号连续性
- 公式前后文引用一致性
- 变量定义与使用一致性
- 公式计算逻辑验证

**示例问题记录格式**：
```
[公式审校-第3章]
位置：3.2节，公式(3-15)
问题：下标i应为斜体
建议修改：x_i → x_i (保持斜体)
严重程度：中等
```

#### 2.3 图形图像审校

**审查项目**：
- 图片清晰度与分辨率（建议≥300dpi）
- 图形标注文字可读性
- 坐标轴标签、单位规范性
- 图例完整性
- 版权信息（图片来源声明）
- 与正文内容的对应关系

#### 2.4 表格审校

**审查项目**：
- 表头设计与内容对应
- 数据一致性与准确性
- 跨页表格续表标识
- 计量单位一致性
- 边框、对齐格式规范
- 与正文引用的一致性

#### 2.5 参考文献审校

**审查项目**：
- 格式规范性（GB/T 7714、APA、MLA等）
- 必填字段完整性
- 作者、题名、出版年等关键信息准确性
- DOI/URL有效性验证
- 序号连续性
- 正文中引用与参考文献列表对应

**常见参考文献格式**：
| 类型 | 核心要素 |
|-----|---------|
| 期刊论文 | 作者. 题名[J]. 期刊名, 年, 卷(期): 页码. |
| 专著 | 作者. 题名[M]. 出版地: 出版社, 年. |
| 电子资源 | 作者. 题名[EB/OL]. 获取日期. URL |

### 阶段 3：问题汇总与报告

#### 3.1 问题分类汇总

按内容类型和问题严重程度汇总：

| 分类 | 说明 |
|-----|------|
| 致命错误 | 事实错误、数据错误、严重逻辑问题 |
| 严重错误 | 格式错误、内容不一致、关键信息缺失 |
| 一般问题 | 标点、用词、次要格式问题 |
| 优化建议 | 表述优化、布局改进建议 |

#### 3.2 审校报告结构

```
# 教材审校报告

## 基本信息
- 文档名称：[文件名]
- 审校范围：[全稿/章节/指定内容]
- 审校日期：[YYYY-MM-DD]
- 审校类型：[全面审校/专项审校]

- 公式问题：X处
- 图形图像问题：X处
- 表格问题：X处
- 参考文献问题：X处
- **总计**：X处

## 详细问题清单

| 序号 | 位置 | 问题描述 | 建议修改 | 严重程度 |
|-----|-----|---------|---------|---------|

...

...
```

## 审校输出规范

### 输出文件格式

用户可选择以下输出格式：

1. **Markdown报告** - 便于查看和版本控制
2. **JSON格式** - 便于程序处理和后续集成
3. **修订标记文档** - 使用Word Track Changes或PDF批注

## 质量控制

### 审校准确性保障

1. **双重核查**：对关键问题进行二次确认
2. **标准参考**：依据相关出版规范和国家标准
3. **一致性检查**：确保全书/全文风格统一
4. **可追溯性**：所有问题均可定位到具体位置

### 时效性要求

- 单章节审校：通常1-2小时内完成
- 全稿审校：根据篇幅，通常1-3个工作日
- 加急服务：可协商缩短周期

## 使用示例

### 场景1：全稿审校

```
用户：请帮我审校这份教材PDF，需要全面检查
助手：我将对该教材进行全面的多维度审校，包括文字、公式、图形、表格和参考文献。请上传您的教材文件，并确认审校范围（全稿还是指定章节）。
```

### 场景2：专项审校

```
用户：帮我重点检查这本教材的参考文献格式
助手：我将对该教材的参考文献进行专项审校，检查格式规范性、字段完整性和引用对应关系。
```

### 场景3：即时问题查询

```
用户：这段话的表达有问题吗？"由于实验方法的局限性，使得结果存在一定误差"
助手：这句话存在主语残缺的问题。"由于...使得..."是典型的无主语句式。建议修改为："由于实验方法的局限性，结果存在一定误差"或"实验方法的局限性使得结果存在一定误差"。
```
