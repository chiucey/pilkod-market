# 教材审校标准参考

本文档提供教材审校过程中使用的标准规范和参考指南。

## 一、文字内容审校标准

### 1.1 错别字常见类型

| 错误类型 | 示例 | 正确写法 |
|---------|------|---------|
| 形近误用 | 人口繁殖 | 人口繁衍 |
| 音近误用 | 想像力 | 想象力 |
| 义近误用 | 度高重视 | 高度重视 |
| 笔画错误 | 电视 | 电视 |

### 1.2 标点符号规范要点

- 顿号使用：并列的词或词组之间用顿号
- 引号使用：完整引用用双引号，嵌套用单引号
- 书名号使用：《》用于书名、篇名、报刊名
- 省略号：六个点，居中，占两格
- 破折号：两个横线，占两格

### 1.3 数字用法规范

**应使用阿拉伯数字**：
- 物理量值：5g、10cm、38℃
- 编号和代码：第1章、表2-3
- 公元纪年：2024年

**应使用汉字数字**：
- 固定搭配：星期三、四书五经
- 概数：七八天、二十几岁
- 庄重场合：中华人民共和国

## 二、数学公式审校标准

### 2.1 常用符号规范

| 符号类型 | 正确用法 | 常见错误 |
|---------|---------|---------|
| 变量 | x, y, z (斜体) | x（正体） |
| 数字 | 1, 2, 3 (正体) | 1, 2, 3 (斜体) |
| 函数名 | sin, cos, log (正体) | sin（斜体） |
| 单位 | m, kg, s (正体) | m（斜体） |

### 2.2 公式格式检查清单

- [ ] 公式居中，编号右对齐
- [ ] 公式中变量全部定义
- [ ] 上下标清晰可辨
- [ ] 分数使用分数线或斜杠格式正确
- [ ] 公式与上下文编号一致

## 三、图形图像审校标准

### 3.1 分辨率要求

| 图像类型 | 最低分辨率 | 推荐分辨率 |
|---------|-----------|-----------|
| 印刷品 | 300 dpi | 600 dpi |
| 数字出版 | 150 dpi | 300 dpi |
| 屏幕显示 | 72 dpi | 150 dpi |

### 3.2 图形标注规范

- 坐标轴名称和单位完整
- 图例清晰可辨
- 图表编号连续
- 图片来源标注（如适用）

## 四、表格审校标准

### 4.1 表格结构规范

- 表头居中加粗
- 数据左对齐或居中（统一）
- 计量单位统一
- 跨页表格有续表标识

### 4.2 常见表格问题

- 表头与数据列不对应
- 数据精度不一致
- 缺失合计行/列
- 表格与正文引用不一致

## 五、参考文献审校标准

### 5.1 GB/T 7714-2015 核心格式

**期刊论文**：
```
[序号] 作者. 题名[J]. 刊名, 年, 卷(期): 起止页码.
```

**专著**：
```
[序号] 作者. 题名[M]. 版本. 出版地: 出版者, 年.
```

**电子资源**：
```
[序号] 作者. 题名[EB/OL]. (更新日期)[引用日期]. URL.
```

### 5.2 必填字段检查

| 文献类型 | 必填字段 |
|---------|---------|
| 期刊 | 作者, 题名, 刊名, 年, 卷, 期, 页码 |
| 专著 | 作者, 题名, 出版地, 出版社, 年 |
| 学位论文 | 作者, 题名, 学位, 授予单位, 年 |

### 5.3 DOI/URL 格式

- DOI格式：`https://doi.org/10.xxxx/xxxxx`
- URL需完整，包含协议头
- 引用日期对电子资源必需
