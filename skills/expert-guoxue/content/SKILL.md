# 国学传统文化专家

## 核心能力

将中国传统文化元素（周易、阴阳五行、中医经络、神话、历史典故）有机融入故事设定，避免文化元素显得生硬或堆砌。

## 阴阳五行体系融合

### 基础框架

```
五行：木 火 土 金 水
相生：木→火→土→金→水→木
相克：木克土→土克水→水克火→火克金→金克木
```

### 修炼体系示例（金木水火土对应境界）

- **金之道**：锐利、杀伐，对应剑修，主白色/金色调
- **木之道**：生机、韧性，对应丹道/治愈，主绿色调
- **水之道**：柔韧、包容，对应刺客/幻术，主蓝色调
- **火之道**：爆烈、阳刚，对应战斗，主红色调
- **土之道**：厚重、守御，对应防御，主黄色调

### 阴阳应用场景

- 功法分阴阳（阳性刚猛、阴性柔韧，双修可互补）
- 武器分阴阳（阳性主攻击、阴性主控制）
- 突破分阴阳劫（阴劫考验心性、阳劫考验肉身）

## 周易八卦在命名中的运用

### 常见吉利卦象

| 卦象 | 含义 | 适用于 |
|------|------|--------|
| 乾卦 | 刚健不息 | 主角姓名、宗门名 |
| 坤卦 | 厚德载物 | 女主姓名、大派名称 |
| 震卦 | 震动、觉醒 | 主角觉醒情节 |
| 巽卦 | 风、渗透 | 刺客/情报组织 |
| 坎卦 | 险、成长 | 主角初期困境 |
| 离卦 | 光明、火焰 | 火系功法/角色 |
| 艮卦 | 停止、守护 | 守护型角色/封印 |
| 兑卦 | 喜悦、口舌 | 嘴炮型角色、商会 |

### 八卦阵设计

八卦阵可用于：宗门大阵、封印、遗迹入口、战斗阵法
按卦象排列乾→坤→震→巽→坎→离→艮→兑，每卦对应一种能量属性。

## 中医经络融入战斗/修炼体系

```
十二正经 + 任督二脉
修炼即"通脉"：通一条经脉 = 突破一个小境界
任脉（阴脉之海）→ 主内伤恢复、柔韧
督脉（阳脉之海）→ 主外功防御、刚猛
```

- 走火入魔：经脉岔气，需用特定草药/针灸救治
- 顿悟：某条经脉突然通透，境界飞跃
- 暗伤积累：过度使用禁忌招式导致经脉受损

## 古代神话元素融入

### 神兽/凶兽体系

- 青龙、白虎、朱雀、玄武（四圣兽）
- 麒麟、凤凰、金翅大鹏（祥瑞）
- 饕餮、穷奇、梼杌、混沌（四大凶兽）
- 烛龙、应龙、鲲鹏、九尾狐（强力神兽）

### 神兵利器命名法

```
主人名+神器特性：
赤霄（赤=火红，霄=高远）→ 火属性帝王剑
青冥（青=木，冥=幽深）→ 风属性暗杀剑
玄冰（玄=黑/水，冰=寒冷）→ 冰属性防御剑
```

## 避坑指南

- 不要堆砌术语：每章最多引入1-2个传统文化概念并解释
- 不要让角色"背诵典故"：用行为和场景自然展示文化内涵
- 中西合璧要谨慎：玄幻/仙侠尽量保持东方美学体系完整
