# Excel 排版优化专家

智能优化 Excel 表格的视觉呈现和打印布局，使数据表格美观、专业、易读。

## 核心能力

### 1. 视觉美学优化

| 优化维度 | 具体操作 |
|---------|---------|
| **对齐策略** | 数值右对齐，文本左对齐，表头居中 |
| **字体层次** | 标题加粗放大(14-16pt)，正文适中(11-12pt)，注释缩小(9-10pt) |
| **列宽自适应** | 根据内容长度智能调整，避免文字挤压或过宽留白 |
| **行高优化** | 表头行高增加(30-40pt)，数据行舒适(20-25pt) |
| **边框系统** | 外框加粗(1.5pt)，内框细线(0.5pt)，形成清晰网格 |

### 2. 配色方案

```
标准商务配色：
- 表头背景：#4472C4 (深蓝) + 白色文字
- 交替行：#F2F2F2 (浅灰) / #FFFFFF (白色)
- 边框线：#BFBFBF (中性灰)
- 重点强调：#FFC000 (金黄) 或 #E74C3C (警示红)

医疗/科研配色：
- 表头背景：#2E86AB (青蓝) + 白色文字
- 数据交替：#E8F4F8 (淡蓝) / 白色

教育/儿童配色：
- 柔和色系，避免过于刺眼
- 使用 #7ED3B2, #FFB347 等温和配色
```

### 3. 打印优化

| 打印需求 | 优化设置 |
|---------|---------|
| **纸张适配** | A4 自适应列宽，分页预览设置 |
| **页边距** | 上下2.54cm，左右1.91cm（窄边距） |
| **页眉页脚** | 自动添加工作表名、页码、打印日期 |
| **重复标题行** | 跨页时自动重复表头 |
| **缩放打印** | 智能缩放避免截断最后一列 |
| **网格线** | 打印时保留网格线或仅边框 |

### 4. 数据可读性增强

```
条件格式规则：
- 正负数：红色负数、绿色正数
- 阈值提醒：超过/低于阈值自动变色
- 数据条/色阶：直观展示数据分布
- 重复值高亮：标记重复数据

合并单元格策略：
- 仅表头横向合并，避免数据区合并
- 跨列居中时考虑阅读方向
```

### 标准执行步骤

1. **上传/输入文件**
   - 支持 .xlsx, .xls, .csv 格式
   - 读取第一个工作表作为处理对象

2. **结构分析**
   - 识别数据范围（连续区域）
   - 检测表头行位置
   - 统计行列数量

3. **应用优化方案**
   - 根据用户选择的应用预设或自定义配置
   - 逐项执行格式化操作

4. **预览确认**
   - 生成预览图像
   - 显示关键变更摘要

5. **保存交付**
   - 输出优化后的 Excel 文件

## 预设模板

### 模板 A：商务报告

```
适用场景：商务报告、季度总结、项目汇报
特点：专业严谨、层次分明、可直接打印
```

### 模板 B：数据看板

```
适用场景：数据分析、统计报表、财务报表
特点：信息密度高、颜色区分、便于快速阅读
```

### 模板 C：简洁清单

```
适用场景：清单列表、任务分配、日程安排
特点：简洁大方、留白充足、便于手写备注
```

## 注意事项

- 合并单元格可能影响某些操作的精确性
- 超大表格（>10000行）可能需要分批处理
- 彩色打印时注意色彩饱和度
- 密码保护的工作表无法修改格式
- 公式单元格保留公式逻辑不变
