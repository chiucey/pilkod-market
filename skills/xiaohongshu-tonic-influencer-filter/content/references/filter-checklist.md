# 滋补达人筛选检查清单

## 一、账号基础信息核查

### 1.1 粉丝数据真实性
- [ ] 近30天粉丝增长曲线平滑，无异常暴涨
- [ ] 粉丝互动数据与粉丝量级匹配
- [ ] 评论区IP分布合理（非单一地区刷量）

### 1.2 内容垂直度
- [ ] 滋补/养生类内容占比 ≥ 70%
- [ ] 无大量美妆、穿搭、低价零食内容
- [ ] 账号人设与滋补定位一致

### 1.3 商业合作记录
- [ ] 品牌合作数量适中（非刷屏型）
- [ ] 合作品牌调性与本品牌匹配
- [ ] 无负面品牌合作舆情

## 二、数据质量评估

### 2.1 互动率计算
```
互动率 = (点赞 + 收藏 + 评论) / 粉丝数 × 100%
```

**滋补赛道参考标准**：
| 层级 | 平均互动率 | 优质账号标准 |
|------|------------|--------------|
| 素人 1k-1w | 2%-4% | ≥ 3% |
| 腰部 1w-10w | 1.5%-3% | ≥ 2.5% |
| 中头部 10w-100w | 1%-2% | ≥ 1.5% |
| 头部 100w+ | 0.5%-1.5% | ≥ 1% |

### 2.2 数据稳定性
- [ ] 笔记数据波动在正常范围内
- [ ] 无单篇爆款后持续低迷的异常曲线
- [ ] 爆款笔记符合内容规律

### 2.3 评论区质量
- [ ] 评论内容与滋补话题相关
- [ ] 有真实用户咨询功效、吃法、选购
- [ ] 无大量水军式好评

## 三、风险账号识别

### 3.1 绝对排除条件
- [ ] 有平台违规限流记录
- [ ] 数据波动严重异常
- [ ] 频繁硬广刷屏（每月 > 10条）
- [ ] 跨品类混乱接单

### 3.2 相对排除条件（需评估）
- [ ] 近期才开始做滋补内容
- [ ] 合作品牌调性偏低
- [ ] 评论区负面舆情
- [ ] 粉丝画像偏离目标人群

## 四、达人分层配比建议

### 4.1 预算分配参考

| 总预算 | 素人 | 腰部 | 中头部 | 头部 |
|--------|------|------|--------|------|
| 1万以下 | 70% | 30% | 0% | 0% |
| 1-5万 | 40% | 50% | 10% | 0% |
| 5-15万 | 20% | 45% | 25% | 10% |
| 15万+ | 15% | 35% | 30% | 20% |

### 4.2 投放节奏建议
- **预热期（1-2周）**：腰部达人为主，积累口碑
- **爆发期（3-4周）**：中头部达人加入，加大曝光
- **长尾期（5周+）**：素人铺量，口碑沉淀
