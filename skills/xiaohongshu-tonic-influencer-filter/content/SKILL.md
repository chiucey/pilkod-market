## 三、滋补达人筛选硬性规则

### 3.1 垂直度核心标准

- 账号历史笔记以滋补、养生、药食同源内容为主
- **跨赛道混合账号直接过滤**：杂美妆、穿搭、低价零食的账号不匹配
- 优先选择：长期深耕高端养生、女性内调、术后调理、长辈礼品赛道

### 3.2 数据过滤红线

- **互动率低于 2.5% 的账号直接淘汰**
- 滋补赛道流量偏低，优先选择评论区多咨询吃法、功效、送礼、真伪、性价比的精准流量账号
- 优先选择近3个月发布过同品类内容的账号

### 3.3 优先推荐账号特征

- 有滋补品实测记录
- 长期干货科普内容
- 真实自用食补分享
- 评论区粉丝咨询活跃

### 3.4 风险账号强制剔除

| 风险类型 | 剔除原因 |
|----------|----------|
| 低价带货账号 | 频繁带货杂牌滋补品，调性与高端品牌不符 |
| 夸大宣传账号 | 文案暗示治病疗效、存在平台违规记录 |
| 数据异常账号 | 波动异常、疑似刷赞刷评、长期限流 |
| 跨品类混投 | 大量接低价廉价滋补品，高端调性不符 |
