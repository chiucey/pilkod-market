# ASCII 艺术图表生成器

## 核心能力

生成多种类型的 ASCII 艺术图表，支持实时自定义样式和颜色。

## 支持的图表类型

| 类型 | 触发词 | 描述 |
|------|--------|------|
| bar | 柱状图、bar chart | 垂直柱状图 |
| hbar | 水平条形图、horizontal bar | 水平条形图 |
| line | 折线图、line chart | 数据趋势线 |
| pie | 饼图、pie chart | 比例分布圆图 |
| stacked | 堆叠图、stacked bar | 多数据堆叠柱状图 |
| area | 面积图、area chart | 填充区域折线图 |

## 使用流程

### 1. 解析用户需求

接收用户的数据和图表要求：
- **数据**：数值数组、对象列表、CSV 格式
- **类型**：图表类型（默认柱状图）
- **样式**：simple / elegant / compact（默认 elegant）
- **颜色**：是否使用 ANSI 颜色（默认否）
- **尺寸**：宽度（默认 60 字符）、高度（自动计算）

### 2. 生成图表

使用 `scripts/generate_chart.py` 核心生成器：

```python
from generate_chart import ASCIIChartGenerator

generator = ASCIIChartGenerator(
    width=60,      # 图表宽度（字符数）
    style='elegant',  # simple | elegant | compact
    use_colors=False  # 是否使用 ANSI 颜色
)

# 生成柱状图
chart = generator.bar(data=[10, 25, 30, 45], labels=['Q1', 'Q2', 'Q3', 'Q4'])

# 生成折线图
chart = generator.line(data=[3.2, 3.5, 4.1, 3.8, 4.5], labels=['Jan', 'Feb', 'Mar', 'Apr', 'May'])

# 生成饼图
chart = generator.pie(data={'A': 30, 'B': 25, 'C': 25, 'D': 20})

# 生成水平条形图
chart = generator.hbar(data=[100, 75, 50, 25], labels=['Apple', 'Banana', 'Orange', 'Grape'])

# 生成堆叠柱状图
chart = generator.stacked(data=[
    {'label': 'P1', 'values': [10, 20, 15]},
    {'label': 'P2', 'values': [15, 10, 20]}
], series=['Red', 'Green', 'Blue'])
```

### 3. 应用样式

根据用户选择的样式应用不同字符集：

| 样式 | 特点 | 适用场景 |
|------|------|----------|
| simple | `+-|*#` 基础字符 | 极简终端、邮件 |
| elegant | `│─┌┐└┘├┤┼ #■●` 精致边框 | 演示、文档 |
| compact | `┃━╋ ▓▒░` 紧凑高效 | 长数据、窄终端 |

### 4. 应用颜色（可选）

使用 ANSI 颜色代码增强可视化：

```
颜色代码映射：
- 红色系：\033[91m (明亮红) / \033[31m (标准红)
- 绿色系：\033[92m (明亮绿) / \033[33m (黄色)
- 蓝色系：\033[94m (明亮蓝) / \033[34m (标准蓝)
- 紫色系：\033[95m (亮紫) / \033[35m (标准紫)
- 重置：\033[0m
```

## 快捷命令

- `生成柱状图 data=[10,20,30] labels=[A,B,C]`
- `生成折线图 3.2,3.5,4.1,3.8`
- `生成饼图 A:30% B:25% C:25% D:20%`
- `ASCII图表 数据显示 样式=elegant 颜色=true`

## 错误处理

| 错误情况 | 处理方式 |
|----------|----------|
| 无数据 | 提示用户输入数据 |
| 数据格式错误 | 显示正确的输入格式示例 |
| 数据类型不匹配 | 尝试转换或提示修正 |
| 值全部为0或负数 | 特殊处理或提示数据无效 |
