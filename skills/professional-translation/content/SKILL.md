# 专业翻译技能

## 核心能力

本技能专注于高质量专业内容翻译，确保术语准确、格式规范、语言流畅。

## 翻译工作流程

### 1. 内容识别与分析

**输入类型判断：**
- 纯文本：直接进入翻译流程
- 多段落长文：分段处理，保持上下文连贯
- 专业术语密集内容：启用术语一致性模式

**专业领域识别：**
- 学术/科研：保持学术规范，使用正式表达
- 技术/IT：正确翻译技术术语，可保留原文缩写
- 法律：严谨措辞，必要时添加译注
- 医学：使用标准医学术语译法
- 商业/金融：商务语言风格

### 2. 翻译执行

**翻译原则：**
- 准确性第一：忠实传达原意
- 专业性第二：使用目标领域标准术语
- 可读性第三：符合目标语言表达习惯
- 一致性原则：同一术语全文保持一致

**术语处理：**
- 常见专业术语使用标准译法
- 首次出现的重要术语可附注原文
- 缩写首次出现时给出全称

### 3. 输出格式

**标准输出结构：**
```
【原文语言】→【目标语言】

【译文正文】
```

**特殊标注（如需要）：**
- 术语说明：[术语原文] = 标准译法
- 歧义说明：【注】原文中...可能指...
- 原文保留：技术术语、专有名词可保留原文

## 适用场景

- 学术论文摘要翻译
- 技术文档本地化
- 法律合同翻译
- 商业提案翻译
- 专业书籍章节翻译
- 研究报告翻译

## 示例

**输入：**
```
The efficacy of this novel therapeutic approach was evaluated through randomized controlled trials conducted across multiple institutions.
```

**输出：**
```
【英文】→【中文】

通过在多家机构开展的随机对照试验对该新型治疗方案的有效性进行了评估。
```

## 质量保证

1. 检查数字、人名、地名等专有名词准确性
2. 确保专业术语使用规范译法
3. 验证句子结构符合目标语言习惯
4. 保持原文格式（标题、列表、引用等）
