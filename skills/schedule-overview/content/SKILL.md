# 日程快速一览表生成器

根据用户输入的文字内容，智能提取日程关键信息并生成交互式网页表格。

## 工作流程

1. **接收用户输入**：获取用户提供的日程文字描述
2. **信息提取**：使用AI能力从文字中提取以下关键信息：
   - 日期（年月日）
   - 具体时间（开始时间、结束时间）
   - 地点
   - 活动主题
   - 参与人员
3. **数据处理**：按照规则处理和格式化数据
4. **生成网页**：创建包含日程表格的HTML页面
5. **提供链接**：返回可访问的网页链接

## 信息提取规则

### 必需提取字段
| 字段 | 说明 | 默认值 |
|------|------|--------|
| 日期 | 年-月-日格式 | 未知 |
| 时间 | 24小时制，开始时间~结束时间 | 仅开始时间 |
| 地点 | 会议室、教室等，#连接的字段为地点 | 未知 |
| 活动主题 | 活动名称，**加粗显示** | 未知 |
| 参与人员 | 全体成员、特定群体等 | 未知 |

### 特殊规则

**培训相关**：
- 提及"培训"但未说明参与人员 → 填写"报名培训人员"
- 提及"线上培训" → 地点列填写"线上"
- 活动主题包含培训 → 显示为"培训：活动名称"

**地点识别**：
- 格式如"2#307"表示地点为"2#307"
- "#会议室"、"#教室"等#连接字段属于地点

## 周数计算规则（2026年）

- 2026年1月1日-1月4日为第1周
- 每周从周一到周日
- 计算公式：给定日期所在的周数 = 日期距离1月1日的周数 + 1

### 周数参考
| 日期范围 | 周数 |
|---------|------|
| 2026.1.1 - 2026.1.4 | 第1周 |
| 2026.6.1 - 2026.6.7 | 第23周 |
| 2026.6.8 - 2026.6.14 | 第24周 |
| 2026.7.6 - 2026.7.12 | 第28周 |

## 表格格式规范

### 列结构
1. **自然周数** - 通过日期计算，白/灰交替底色
2. **日期和星期** - 格式：YYYY-MM-DD (周X)
3. **具体时间** - HH:MM-HH:MM，无结束时间则仅显示开始时间
4. **地点** - 活动场所
5. **活动主题** - **加粗显示**
6. **参与人员** - 活动参与者

### 样式规则
- 所有列文字内容居中显示
- 活动主题加粗
- 未识别信息标注"未知"
- 时间列不标注未知，无结束时间仅填开始时间

## 单元格合并规则

- 当相邻行的自然周数相同时，合并这些单元格
- 合并单元格垂直居中显示

## 底色交替规则

- 奇数周（第1、3、5...周）：白色底色
- 偶数周（第2、4、6...周）：灰色底色
- 同周数的单元格合并后显示单一底色

## 搜索功能要求

### 顶部搜索框
- 位于表格上方
- 支持关键词快速搜索
- 输入关键词后：
  - 包含关键词的单元格高亮显示（黄色背景）
  - 其他行保持显示，仅非匹配内容淡化
  - 实时过滤，无需提交

### 高亮显示
- 使用黄色背景（#FFFF00 或类似）突出匹配内容
- 搜索框支持清除操作

## 输出格式

### 生成内容
1. 完整的HTML页面文件
2. 包含内联CSS样式的日程表格
3. 顶部搜索框
4. 所有交互功能

### 交付方式
- 保存HTML文件到工作目录
- 提供可访问的网页链接
- 链接在新标签页打开表格页面

## 示例输入

```
6月10日 14:00-16:00 2#307 科室例会 全体科室成员参加
6月12日 9:00 3#201 青年培训 全体青年同事
6月15日 10:00-12:00 会议室A 党支部会议 所有党员
6月20日 线上培训 新人入职培训
```

## 技术实现

生成的HTML页面必须包含：
- UTF-8编码
- 响应式设计
- 内联JavaScript实现搜索功能
- 内联CSS样式
- 表格使用semantic HTML标签
