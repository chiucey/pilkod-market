# 涟漪竞品分析 Skill

## 核心功能
对任意投资标的进行系统性竞品分析，遵循涟漪七问评分体系的第四问"真的理解吗？"——通过竞品对比，真正理解标的在市场中的位置。

## 标准竞品分析流程

### Step 1：确定分析标的 & 主要竞品

输入：目标公司/项目
输出：主要竞品列表（3-5个）

选择标准：
- 直接竞争对手（同赛道）
- 规模相近（可对比）
- 数据可获取

### Step 2：多维度数据收集

使用 `batch_web_search` 收集以下维度：

| 维度 | 指标 | 用途 |
|------|------|------|
| 市值/估值 | FDV、MCAP | 规模对比 |
| 收入/毛利 | Revenue、GP | 盈利能力 |
| 用户数/TVL | MAU、TVL | 增长性 |
| 技术积累 | 代码提交、开发活跃度 | 技术护城河 |
| 团队背景 | 创始人经验 | 团队评估 |
| 资金来源 | 融资历史、机构持有 | 资本认可 |
| 社区规模 | 开发者/用户 | 网络效应 |

### Step 3：竞品对比矩阵

```
| 指标 | 目标标的 | 竞品A | 竞品B | 竞品C |
|------|---------|-------|-------|-------|
| 市值 | $X | $X | $X | $X |
| 收入 | $X | $X | $X | $X |
| 增速 | X% | X% | X% | X% |
| ... | ... | ... | ... | ... |
```

### Step 4：综合评估

输出格式：
```
## 🏆 涟漪竞品分析：<标的>

### 📌 一句话定位
（目标标的的核心竞争优势，≤20字）

### 📊 关键指标对比
（最重要的3个指标，为什么重要）

### ✅ 优势
- 相对于竞品的绝对优势

### ⚠️ 劣势
- 相对于竞品的明显短板

### 🔍 估值判断
（结合当前价格，相对贵还是便宜）

### 📋 涟漪理解度
- 1-5分，这个标的真的理解了吗？
- （能解释清楚逻辑 = 4-5分）

---
分析时间：YYYY-MM-DD | 数据来源：xxx
```

## 适用场景

| V说 | 涟漪执行 |
|------|---------|
| "分析一下BTC的竞争对手" | BTC vs ETH/SOL/XRP全面竞品分析 |

| "这个DeFi项目靠谱吗" | 项目+竞品分析 |
| "山寨季来了买什么" | 主流山寨竞品对比+打分 |
