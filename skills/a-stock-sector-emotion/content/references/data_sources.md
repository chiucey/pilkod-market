## 二、情绪分析方法

### 2.1 β值（贝塔系数）

衡量板块相对于大盘的波动性：

```
β = 板块涨跌幅 / 大盘涨跌幅
```

**解读**：
| β值范围 | 含义 |
|---------|------|
| β > 1.5 | 高弹性板块，波动大于大盘 |
| 1.0 < β ≤ 1.5 | 略高于大盘波动 |
| 0.8 ≤ β ≤ 1.0 | 与大盘同步 |
| 0.5 ≤ β < 0.8 | 低弹性板块 |
| β < 0 | 负相关，逆势板块 |

### 2.2 领先滞后分析

通过时间序列相关性判断：

1. **Pearson相关系数**：衡量线性相关程度
2. **Granger因果检验**：检验板块是否领先/滞后于大盘
3. **滚动窗口**：使用5日/10日滚动窗口分析

### 2.3 资金流向指标

```
主力净流入 = 超大单净流入 + 大单净流入
中单净流入 = 中单净流入
小单净流入 = 小单净流出
```

**情绪判断**：
| 主力净流入 | 市场解读 |
|-----------|---------|
| > 50亿 | 主力积极布局，情绪乐观 |
| 10-50亿 | 温和流入 |
| -10-10亿 | 基本平衡 |
| < -30亿 | 主力撤退，情绪谨慎 |

### 2.4 量价配合分析

| 指数 | 成交量 | 市场含义 |
|------|--------|---------|
| 上涨 | 放量 > 10% | 强势，做多力量充足 |
| 上涨 | 缩量 > 10% | 虚涨，可能回落 |
| 下跌 | 放量 > 10% | 弱势，做空力量大 |
| 下跌 | 缩量 < 10% | 惜售，可能见底 |
| 震荡 | 缩量 | 观望，等待突破 |

## 四、注意事项

1. **数据时效性**：
   - 实时数据在交易时间内更新
   - 午盘数据（11:30）可能有5-10分钟延迟
   - 尾盘数据（15:00）为当日最终数据

2. **复权处理**：
   - 涨跌幅数据需做前复权处理
   - 避免因分红送股导致的数据失真

3. **停牌股处理**：
   - 停牌股不纳入涨跌幅计算
   - 需过滤ST股和退市股

4. **异常值处理**：
   - 新股上市首日涨跌幅可能超过10%
   - 科创板、创业板涨跌幅限制为20%
   - 北交所为30%

5. **数据验证**：
   - 对比多个数据源验证准确性
   - 设置合理的数据范围检查
   - 记录数据采集时间戳
