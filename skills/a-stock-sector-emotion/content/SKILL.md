# A股板块情绪分析与大盘联动识别

## 技能目标

识别A股各板块与大盘情绪的联动关系，通过爬取实时市场数据，分析板块涨跌与大盘的同步性、领先滞后关系、资金流向，为投资决策提供情绪参考。

## 核心能力

### 1. 数据爬取
- **执行时间**：每天 12:30（午盘休市后）和 18:00（尾盘收盘后）
- **数据源**：
  - 东方财富（板块资金流向、涨跌幅排名）
  - 同花顺（板块详细数据、龙头股表现）
  - 新浪财经（大盘指数数据）
- **爬取内容**：
  - 大盘指数（上证、深证、创业板）
  - 行业板块涨跌排名
  - 概念板块涨跌排名
  - 板块资金净流入/流出
  - 涨停股/跌停股数量

### 2. 情绪分析维度

#### 2.1 涨跌幅相关性（β值/相关系数）
- 计算公式：`相关性 = 板块涨跌幅 / 大盘涨跌幅`
- 分类：
  - **高联动**（β > 1.2）：板块波动大于大盘
  - **同步**（0.8 ≤ β ≤ 1.2）：与大盘基本同步
  - **低联动**（β < 0.8）：与大盘走势独立
  - **逆势**（β < 0）：与大盘负相关

#### 2.2 时间领先/滞后分析
- **领先板块**：在大盘上涨前1-3个周期已有明显涨幅
- **滞后板块**：在大盘上涨后才开始跟涨
- **独立板块**：无论大盘涨跌都有独立走势

#### 2.3 资金流向分析
- 资金净流入 = 主力净流入 - 主力净流出
- 情绪判断：
  - **资金涌入**：净流入 > 50亿，情绪积极
  - **资金流出**：净流出 > 30亿，情绪谨慎
  - **资金平衡**：区间震荡为主

#### 2.4 龙头股带动分析
- 识别板块内涨停龙头股
- 分析龙头股对板块的带动效应
- 判断板块情绪的真实性（真联动 vs 少数个股行情）

### 3. 大盘情绪判断标准

基于**量价结合**原则：

| 情绪状态 | 上涨条件 | 下跌条件 | 震荡条件 |
|---------|---------|---------|---------|
| **指数涨跌** | 沪深300涨跌幅 > 0.5% | 沪深300涨跌幅 < -0.5% | -0.5% ≤ 涨跌 ≤ 0.5% |
| **成交量** | 较前一日放量 > 10% | 较前一日缩量 > 15% | 成交量基本持平 |
| **综合判断** | 上涨 + 放量 = **强势** | 下跌 + 放量 = **弱势** | 震荡 + 缩量 = **观望** |

```

- 大盘指数实时数据

- 板块资金流向

```
- 计算板块与大盘的相关系数

```
- 判断大盘情绪状态
- 分类板块联动类型
- 生成情绪指数
```

### Step 4: 报告生成
```
- 组装复盘报告
- 输出结构化分析结果
```

## 技术实现

### 依赖工具
- `mcp__matrix__batch_web_search`：搜索数据源URL
- `mcp__matrix__extract_content_from_websites`：提取网页数据
- `mcp__matrix__stocks_*`：获取股票相关数据

### 数据缓存
- 每次分析后保存数据到 `data/cache/` 目录
- 用于历史对比和趋势分析

## 注意事项

1. **数据时效性**：仅分析最近交易日数据，不做历史回测
2. **风险提示**：分析结果仅供参考，不构成投资建议
3. **异常处理**：数据源不可用时，使用备用数据源
4. **合规要求**：不涉及内幕信息，仅使用公开市场数据
