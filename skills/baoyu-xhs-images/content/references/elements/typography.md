# 字体与文字装饰

## 花字风格（适合小红书）

| 效果 | 描述 | 适用风格 |
|------|------|---------|
| 描边+阴影 | 白色字+粗黑描边+投影 | cute, pop |
| 渐变字 | 粉橙渐变/彩虹渐变 | cute, fresh |
| 白色手写体 | Brush字体白色，手写感 | notion, minimal |
| 黑色楷体 | 传统正式感 | retro, chalkboard |
| 黄色荧光笔 | 手写笔记荧光笔效果 | study-notes |

## 标签样式

```
🏷️ 标签1  🏷️ 标签2  🏷️ 标签3
```

## 常用文字方向

- **左对齐**：阅读习惯，通用
- **居中**：封面、金句、标题
- **右对齐**：补充说明、引用

## 信息层次

```
大标题（主标题）  → 最大，最醒目
副标题（分段）    → 中等，分隔内容
正文（详情）      → 较小，说明文字
注释（补充）      → 最小，灰色
```
