# 画布与布局

## 小红书图片规格

| 规格 | 尺寸 |
|------|------|
| 标准竖图（推荐） | 1080×1350px（3:4） |
| 宽图 | 1080×1260px（6:7） |
| 正方形 | 1080×1080px（1:1） |

## 安全区域

- 顶部 120px：系统 UI 遮挡区
- 底部 200px：标题、互动按钮区域
- 左右边距：每侧留 ≥60px

## 布局类型

| 布局 | 描述 | 适用内容 |
|------|------|---------|
| `sparse` | 大留白，1-2个要点 | 封面、情感类 |
| `balanced` | 标准内容密度，3-4点 | 日常分享、种草 |
| `dense` | 高信息密度，5-8点 | 知识卡、干货 |
| `list` | 枚举/排名格式 | 清单、好物推荐 |
| `comparison` | 左右对比 | 前后对比、产品对比 |
| `flow` | 时间线/流程 | 步骤教程、成长变化 |
| `mindmap` | 中心放射思维导图 | 知识梳理、概念解释 |
| `quadrant` | 四象限/圆环分割 | 分类、矩阵分析 |
