# 偏好设置 schema (EXTEND.md)

```yaml
# 偏好语言
language: zh  # zh / en

# 默认风格和布局
default_style: notion
default_layout: balanced

# 水印设置
watermark:
  enabled: false  # true / false
  text: ""        # 水印文字
  position: bottom-right  # top-left / top-right / bottom-left / bottom-right

# 自定义风格定义
custom_styles: {}
  # 可在此覆盖预设中的风格定义

# 图像数量偏好
preferred_image_count: 5  # 1-10
```
