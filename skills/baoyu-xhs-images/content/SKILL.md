# 小红书图片生成技能

将内容拆分为适合小红书传播的系列信息图，提供 10 种视觉风格和 8 种信息布局。

## 使用方式

直接描述需求即可，技能会自动分析内容并生成：

**提供文章/内容**：粘贴文章或提供文件路径，技能分析后生成系列图
**直接描述主题**：如"帮我生成小红书图片，主题是AI工具推荐"

## 核心参数（可直接指定，也可不指定让技能自动选择）

| 参数 | 选项 |
|------|------|
| `--style` | cute / fresh / warm / bold / minimal / retro / pop / notion / chalkboard / study-notes |
| `--layout` | sparse / balanced / dense / list / comparison / flow / mindmap / quadrant |
| 图片数量 | 1-10 张（默认根据内容自动推荐）|

## 风格选择指引

| 内容类型 | 推荐风格 |
|---------|---------|
| 美妆、时尚、少女、粉嫩 | `cute` |
| 健康、自然、清新、有机 | `fresh` |
| 生活、故事、情感、温暖 | `warm` |
| 干货、教程、知识、概念 | `notion` |
| 专业、商务、简洁 | `minimal` |
| 经典、复古、传统 | `retro` |
| 有趣、惊艳、创意 | `pop` |
| 教育、课堂、学习 | `chalkboard` |
| 笔记、手写、学习指南 | `study-notes` |
| 醒目、必看、警告 | `bold` |

## 输出结构

每轮生成的内容保存在 `xhs-images/{主题slug}/` 目录：

```
xhs-images/{topic-slug}/
├── analysis.md              # 内容分析
├── outline.md               # 最终大纲
├── prompts/                 # 各图生成提示词
│   ├── 01-cover-[slug].md
│   ├── 02-content-[slug].md
│   └── ...
├── 01-cover-[slug].png      # 封面
├── 02-content-[slug].png    # 内容图
└── ...
```

## 生成流程

1. **分析内容** → 理解主题、类型、目标受众
2. **确认理解** → 展示分析结果，补充卖点/风格偏好
3. **生成3种大纲方案** → 故事驱动型 / 信息密集型 / 视觉优先型
4. **确认大纲和风格** → 选择方案、指定风格和视觉元素
5. **依次生成图片** → 封面→内容→结尾，第一张图作为后续图的风格锚点
6. **完成报告** → 展示所有图片路径

## 视觉一致性

生成多张图时，**第一张（封面）作为风格参考**，后续图片通过引用第一张来保持角色、配色和画风一致。

## 详细参考

- **视觉元素**：`references/elements/` — 画布比例、安全区、网格布局、字体装饰、特效
- **风格预设**：`references/presets/` — 各风格的元素组合定义（cute/notion/warm 等）
- **工作流**：`references/workflows/` — 内容分析框架、大纲模板、提示词组装指南
- **配置**：`references/config/` — 偏好设置、水印配置

## 内容拆分原则

- **封面（第1张）**：钩子 + 视觉冲击，`sparse` 布局
- **内容（中间）**：核心价值点，`balanced` / `dense` / `list` / `comparison` / `flow`
- **结尾（最后）**：CTA / 总结，`sparse` 或 `balanced`
