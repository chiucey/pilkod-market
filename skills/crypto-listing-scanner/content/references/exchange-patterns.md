# 交易所上币规律详解

## 一、交易所分类与上币风格

| 交易所 | 定位 | 上币速度 | 合规程度 | 合约特点 |
|--------|------|---------|---------|---------|
| Binance | 综合龙头 | 中等 | 高 | 合约上线加速中 |
| Coinbase | 合规典范 | 最慢 | 最高 | 谨慎上线 |
| OKX | 衍生品强 | 快 | 中高 | 衍生品领先 |
| Bybit | 衍生品专精 | 很快 | 中 | 小币种合约多 |
| HTX | 亚洲市场 | 极快 | 中 | "潜力币摇篮" |
| MEXC | 新兴项目 | 极快 | 低中 | 快速上新 |

## 二、关键规律

### 规律1：小所先行，大所跟进

```
现象：新币通常先在 HTX、MEXC 上线
     1-4周后，币安/OKX才上线

机会：
- 监控小所新币 → 发现潜力币
- 大所上线预警 → 埋伏预期行情
```

### 规律2：币安合约加速上线

```
现象：2024年后币安加快合约上线
原因：争夺Bybit的衍生品市场份额

机会：
- 币安合约上线 = 确定性流动性增加
- 合约上线前可能是埋伏时机
```

### 规律3：期现不同步模式

| 模式 | 说明 | 风险 |
|------|------|------|
| 现货先上 | 常见，合约延迟1-4周 | 中低 |
| 合约先上 | 高波动性币种 | 高 |
| 期现同步 | 主流大币种 | 低 |

## 三、数据采集清单

```markdown
每日监控：
□ 币安/OKX/HTX/MEXC 新币上线
□ CoinMarketCap 新上市列表
□ 合约即将上线公告
□ 社交媒体热度变化

周度分析：
□ 本周新币表现汇总
□ 合约上线后的价格走势
□ 识别有规律的币种
```

## 四、风险提示

⚠️ 小所流动性差，滑点高
⚠️ 上小所≠项目优质
⚠️ 严格止损，控制仓位
