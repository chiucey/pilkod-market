# Pump & Dump 预警指标体系

## 一、Pump & Dump 运作机制

### 什么是 Pump & Dump

```
Pump & Dump（拉升出货）是加密货币市场中最常见的操纵手法：

Phase 1 - 建仓阶段：
- 庄家/项目方提前买入大量低价筹码
- 筹码集中在少数地址（可通过链上分析识别）

Phase 2 - 拉升阶段（Pump）：
- 通过社交媒体、付费喊单群等造势
- 制造虚假热度（FOMO 效应）
- 配合新闻/公告等利好消息
- 价格快速拉升（可能1小时涨100%+）

Phase 3 - 出货阶段（Dump）：
- 价格达到目标位后，大量抛售
- 庄家/项目方高位套现
- 价格快速回落（可能回到原点甚至更低）
- 散户接盘后被套牢

总时长：通常 1小时 - 3天
```

### 学术研究结论

根据多篇学术论文的研究发现：

1. **Li et al. (2021)** - 分析了价格、成交量和波动率在 Pump & Dump 期间的行为
2. **Hamrick & Rouah (2020)** - 研究发现 Pump & Dump 多发生在小型交易所
3. **Mirtaheri et al. (2021)** - 通过 Twitter 行为识别 Pump 信号
4. **机器学习模型** - 可实现 75%+ 的准确率预测成功的 Pump 事件

## 二、高风险预警指标

### 指标 1：上币模式异常

#### 高风险特征

| 特征 | 风险等级 | 说明 |
|------|---------|------|
| 仅在小交易所上线 | 🔴 高 | 缺乏大所背书，流动性差 |
| 合约先于现货上线 | 🔴 高 | 可能用于操纵定价 |
| 上线即暴涨（>100%）| 🔴 高 | 典型的 Pump 信号 |
| 合约持仓量极低 | 🔴 高 | 缺乏对冲盘，价格易被操纵 |

#### 中等风险特征

| 特征 | 风险等级 | 说明 |
|------|---------|------|
| 大所上线但合约慢 | 🟡 中 | 可能等待操纵时机 |
| 上线交易所数量少 | 🟡 中 | 流动性集中 |
| 社区热度与上线时间不匹配 | 🟡 中 | 可能是付费推广 |

#### 低风险特征

| 特征 | 风险等级 | 说明 |
|------|---------|------|
| Coinbase/币安上线 | 🟢 低 | 合规背书较强 |
| 期现同步上线 | 🟢 低 | 市场定价效率高 |
| 机构参与/持有 | 🟢 低 | 筹码分散 |
| 公链生态集成 | 🟢 低 | 有实际应用支撑 |

### 指标 2：链上异常信号

#### 地址集中度分析

```
风险评估：
- 前10地址持有 > 50% 供应量 → 🔴 极高风险
- 前10地址持有 > 30% 供应量 → 🔴 高风险
- 前10地址持有 > 20% 供应量 → 🟡 中等风险
- 前10地址持有 < 20% 供应量 → 🟢 相对安全

工具推荐：
- Etherscan/BscScan Token Tracker
- Nansen（付费）
- Arkham Intelligence
- DeBank
```

#### 代币解锁日程

```
高风险信号：
- 代币即将大批量解锁
- 团队/投资人锁仓即将到期
- 私募/公募代币释放

风险逻辑：
解锁 = 抛压 = 价格下行压力

监控资源：
- Token Unlocks 网站
- 项目官方 Tokenomics 文档
- Dune Analytics 解锁追踪
```

### 指标 3：社交媒体热度

#### Twitter/X 信号

```
🔴 红色信号：
- 突然大量新账号转发（买粉迹象）
- 与币圈 KOL 合作的付费推广
- "今天涨10倍"等夸张话术
- 同一个 KOL 频繁推同一币

🟡 黄色信号：
- 项目方密集发布推文
- "Coming Soon"暗示类公告
- 与热点事件强行关联

🟢 绿色信号：
- 持续的有机社区讨论
- 开发者活跃度提升
- 真实的技术讨论（非喊单）
```

#### Telegram/Discord 信号

```
风险群特征：
- 名为"XX 币官方社区"但发言被管控
- 群里只有喊单，没有讨论
- 禁止讨论项目缺点
- 频繁发购买链接

正常社区特征：
- 开放讨论（可质疑项目）
- 开发者定期 AMA
- 技术讨论占主导
- 社区自发组织活动
```

### 指标 4：交易数据异常

#### 成交量分析

```
正常模式：
- 成交量与价格走势匹配
- 买卖盘深度均衡
- 盘口价差合理（<1%）

Pump 信号：
- 成交量暴增但价格涨幅不成比例
- 短时间内成交量远超日均
- 出现"一柱擎天"式K线
```

#### 盘口分析

```
🔴 高风险盘口：
- 买一/卖一深度极不对称
- 卖盘挂单量远大于买盘
- 大额卖单压制价格
- 卖单被吃掉后立即有新卖单

🟢 健康盘口：
- 买卖盘相对均衡
- 大单被吃掉后价格跟进上涨
- 没有明显的单边压制
```

## 三、Pump & Dump 识别公式

### 综合风险评分

```markdown
总分 = A + B + C + D + E + F

A. 上币模式（满分 25分）
  - 🔴 仅小所: +25分
  - 🟡 大所待定: +15分
  - 🟢 大所已上: +0分

B. 合约持仓量（满分 20分）
  - 🔴 极低/无: +20分
  - 🟡 中等: +10分
  - 🟢 充足: +0分

C. 地址集中度（满分 20分）
  - 🔴 前10 > 50%: +20分
  - 🔴 前10 > 30%: +15分
  - 🟡 前10 > 20%: +10分
  - 🟢 前10 < 20%: +0分

D. 代币解锁（满分 15分）
  - 🔴 近期大额解锁: +15分
  - 🟡 未来几个月解锁: +8分
  - 🟢 无近期解锁: +0分

E. 社交媒体（满分 10分）
  - 🔴 异常热度: +10分
  - 🟡 热度上升: +5分
  - 🟢 正常讨论: +0分

F. 交易量异常（满分 10分）
  - 🔴 明显 Pump 量: +10分
  - 🟡 成交量放大: +5分
  - 🟢 正常: +0分
```

### 风险等级划分

| 分数 | 风险等级 | 建议 |
|------|---------|------|
| 70-100 | 🔴 极高风险 | 强烈建议回避 |
| 50-69 | 🔴 高风险 | 仅做短线，严格止损 |
| 30-49 | 🟡 中等风险 | 谨慎参与，控制仓位 |
| 0-29 | 🟢 低风险 | 可考虑趋势交易 |

## 四、实战应对策略

### 如果你已经持有

```markdown
□ 设置移动止损（不要让利润变亏损）
□ 分批止盈（不要一次全出）
□ 关注盘口大单变化
□ 发现异常立即减仓
□ 不要追涨加仓
```

### 如果你想参与 Pump

```markdown
□ 只用你能承受损失的资金
□ 设置硬止损（如 -30%）
□ 严格控制仓位（<5% 组合）
□ 提前设置好买卖价
□ Pump 开始后果断执行纪律
□ 不要 FOMO 追高
□ 记住：P&D 庄家永远比你先跑
```

### 识别 Pump 的早期信号

```
预警清单（出现3个以上 = 可能 Pump）：
☐ 突然的社交媒体热度
☐ 成交量开始放大
☐ 价格开始突破关键技术位
☐ 出现 KOL 推荐
☐ 合约持仓量开始增加
☐ 小所开始上线该币
☐ 项目方发布"大新闻"
```

## 六、案例分析

### 案例：典型的 Pump & Dump 模式

```
币种：XXX（虚构示例）

时间线：
Day 1: 在 HTX、MEXC 上线，定价 $0.001
Day 2-3: 社区开始讨论，但无大所上线
Day 4: Twitter KOL 开始推荐
Day 5: 成交量暴增，价格涨至 $0.01（+900%）
Day 6: 价格回落至 $0.002
Day 7: 项目方宣布"合作失败"，价格跌回 $0.0008

庄家行为分析：
- Day 1-3: 暗中建仓
- Day 4-5: 配合 KOL 喊单，高位出货
- Day 6-7: 剩余仓位不计成本抛出

教训：
- 不要追涨刚上线的小币
- KOL 推荐是危险信号
- 没有大所上线的币流动性差
- 涨 900% 后必有大幅回落
```

### 案例：相对健康的币种

```
币种：YYY（虚构示例）

时间线：
Day 1: 币安、OKX 同步上线
Day 1: 合约同步开放
Day 2-7: 价格稳步上涨 +30%
Day 14: Coinbase 宣布上线
Day 14: 价格再涨 +50%
Day 30: 代币解锁，但解锁量小且有锁仓

健康特征：
- 大所背书（币安 + Coinbase）

- 机构投资者参与（地址分散）
- 代币解锁有序，抛压可控
```

## 七、总结

### Pump & Dump 核心识别要点

```
三不碰：
1. 不碰只有小所上线的币
2. 不碰 KOL 刚推荐的币
3. 不碰合约持仓极低的币

三观察：
1. 观察合约持仓量变化（增加 = 健康）
2. 观察地址集中度（分散 = 健康）
3. 观察代币解锁日程（有计划 = 健康）
```
