# Pump & Dump 预警指标

## 高风险特征

| 特征 | 风险 | 说明 |
|------|------|------|
| 仅在小交易所上线 | 🔴高 | 流动性差 |
| 合约先于现货 | 🔴高 | 可能操纵定价 |
| 上线即暴涨>100% | 🔴高 | 典型Pump信号 |
| KOL突然推荐 | 🔴高 | 危险信号 |

## 低风险特征

| 特征 | 风险 | 说明 |
|------|------|------|
| Coinbase/币安上线 | 🟢低 | 合规背书 |
| 期现同步 | 🟢低 | 市场效率高 |
| 机构参与 | 🟢低 | 筹码分散 |

## 综合风险评分

```
总分 = A + B + C + D

A. 上币模式（25分）
   - 仅小所: +25
   - 大所已上: +0

B. 合约持仓量（20分）
   - 极低: +20
   - 充足: +0

C. 地址集中度（20分）
   - 前10>50%: +20
   - 前10<20%: +0

D. 代币解锁（15分）
   - 近期大额解锁: +15
   - 无近期解锁: +0

风险等级：
- 70-100分 → 🔴极高风险
- 50-69分 → 🔴高风险
- 30-49分 → 🟡中等风险
- 0-29分 → 🟢低风险
```

## 三不碰原则

1. 不碰只有小所上线的币
2. 不碰KOL刚推荐的币
3. 不碰合约持仓极低的币

⚠️ 本指南仅供教育目的，不构成投资建议
