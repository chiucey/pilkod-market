# 加密货币上币模式扫描器

## 技能目标

分析加密货币在不同交易所的上币规律，识别：
1. **现货 vs 合约上线时差** - 发现合约上线前的潜伏机会
2. **跨交易所价差** - 现货与合约市场的价格差异
3. **交易所特性分析** - 各交易所的上币风格和速度差异
4. **Pump & Dump 信号** - 低流动性币种的操纵预警

## 工作流程

### 1. 确定目标币种

```
用户输入或自动检测：
- 用户指定币种（如 SOL, PEPE, ARKM）
- 或扫描新上线币种
- 或监控特定交易所的新币动态
```

### 2. 收集交易所数据

#### 主要监控交易所
| 交易所 | 特性 | 合约上线速度 | 信号含义 |
|--------|------|-------------|----------|
| Binance | 现货龙头 | 中等偏慢 | 合约上线通常伴随大行情 |
| Bybit | 衍生品强势 | 快速 | 小币种合约上线多，波动大 |
| OKX | 衍生品领先 | 快速 | 与Bybit竞争 |
| HTX (火币) | "潜力币摇篮" | 极快 | 新币上线频繁，但风险高 |
| MEXC | 快速上新 | 极快 | 常首批上线小币种 |
| Gate.io | 资产品种全 | 中等 | 价值发现平台 |
| Coinbase | 合规优先 | 慢 | 合规背书信号 |

#### 数据采集点
```markdown
现货市场：
- 币安、OKX、HTX、Coinbase、Kucoin 各币种的上市时间
- 现货上线日期和初始价格

合约市场：
- 永续合约上线日期
- 合约与现货上线的时间差
- 合约持仓量/未平仓合约变化
```

### 3. 核心分析维度

#### 维度 A：合约-现货时间差分析

```
信号类型：
🔴 高机会信号（时间差 > 30天）
   - 币种已上现货但未上合约
   - 合约上线预期 = 潜在波动预告

🟡 中等机会信号（时间差 7-30天）
   - 刚上合约，流动性建立期
   - 可能出现合约溢价

🟢 低机会信号（时间差 < 7天）
   - 市场已充分定价
   - 信息优势减弱
```

#### 维度 B：交易所特性规律

```
规律 1：HTX/MEXC 首发规律
- 现象：很多币先在 HTX/MEXC 上线，1-4周后币安/OKX才上线
- 原因：小交易所抢上项目方推广币
- 机会：观察小所上线币的社区热度

规律 2：币安合约加速上线
- 现象：2024年后币安加快合约上线，对标Bybit
- 原因：争夺衍生品市场份额
- 影响：部分币合约上线后波动性降低

规律 3：永续合约先于现货
- 现象：某些币先上合约，后上现货
- 风险：操纵可能性更高
- 机会：期现价差套利

规律 4：主流币 vs 小币节奏
- 主流币：币安先行，合规考量
- 小币：HTX/MEXC先行，热度驱动
```

#### 维度 C：Pump & Dump 预警指标

```
高风险特征：
- 只上小交易所，不上主流所
- 合约持仓量极低
- 社交媒体突然集中推广
- 上线后立即出现巨大涨幅（>100%）
- 团队/项目方代币解锁在即

低风险特征：
- Coinbase/币安上线
- 合约与现货同步上线
- 机构投资者参与
- 公链生态集成
```
