# CEO核心能力模型

## 系统性视角

CEO不是一个职位标签，而是一个功能角色。任何组织，无论大小，都需要有人承担这四个功能：

```
┌─────────────────────────────────────────────────────────┐
│                      CEO 核心功能                         │
├─────────────────┬─────────────────┬────────────────────┤
│   方向定义       │   资源配置       │   组织校准          │
│   Direction     │   Allocation    │   Calibration      │
├─────────────────┴─────────────────┴────────────────────┤
│                      结果承担                             │
│                   Accountability                          │
└─────────────────────────────────────────────────────────┘
```

## 四力模型

### 1. 洞察力 (Insight)
- 穿透表象看到本质矛盾
- 识别真正的机会与威胁
- 判断什么是关键问题

### 2. 决策力 (Decision)
- 在不确定性中做选择
- 知道什么时候该放弃
- 承担决策的后果

### 3. 组织力 (Organization)
- 建立高效运转的团队
- 降低系统熵增
- 维持组织清晰度

### 4. 稳定力 (Stabilization)
- 在压力下保持冷静
- 稳定团队信心
- 维护系统连续性

## CEO的四个转变

| 阶段 | 关注点 | 关键词 |
|------|--------|--------|
| 从员工到管理者 | 做自己的事 | 执行 |
| 从管理者到总监 | 让别人做事 | 效率 |
| 从总监到VP | 做对的事 | 方向 |
| 从VP到CEO | 定义什么事是对的 | 系统 |

## 常见CEO陷阱

1. **英雄主义陷阱** — 觉得自己必须解决所有问题
2. **完美主义陷阱** — 等待完美决策时机而错失行动窗口
3. **授权不足陷阱** — 不敢放权导致团队无法成长
4. **授权过度陷阱** — 放弃监督导致失控
5. **沟通错位陷阱** — 不同时期用同一种沟通方式

## 评估框架

### 短期评估（季度）
- 关键指标是否改善
- 重大决策质量如何
- 团队状态如何

### 中期评估（年度）
- 战略是否有效执行
- 组织能力是否提升
- 资源是否正确配置

### 长期评估（3-5年）
- 企业是否更健康
- 是否积累起竞争优势
- 是否建立可传承的组织

## 第一性原理追问清单

面对任何商业问题，用第一性原理追问：

1. **这个问题最底层的因是什么？**
2. **如果不解决这个问题，后果是什么？**
3. **解决这个问题的最小路径是什么？**
4. **谁最适合解决这个问题？**
5. **我们有没有在解决真正的问题？**
