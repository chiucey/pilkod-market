# 小说创作助手 - 混合模式工作流

## 核心工作流程

### 第一阶段：主题与概念构建

1. **收集创作素材**
   - 询问用户：小说主题/核心概念、类型（都市/玄幻/悬疑/言情等）
   - 收集用户已有素材：人物设定、情节片段、世界观描述
   - 记录用户偏好：写作风格、目标字数、章节长度

2. **生成故事核心**
   - 提炼3-5个核心主题词
   - 确定主线冲突与核心悬念
   - 设定故事基调（虐恋/热血/治愈/黑暗等）
   - 明确目标读者群体

### 第二阶段：结构规划

3. **构建故事大纲**
   - 选择叙事结构：三幕式 / 英雄之旅 / 五幕式 / 章节驱动
   - 划分故事阶段：
     - 铺垫期（1-3章）
     - 冲突升级期（4-8章）
     - 高潮转折期（9-12章）
     - 解决与尾声（13-15章）
   - 生成章节目录（含章节名称和核心事件）

4. **人物体系设计**
   - 主要角色：姓名、背景、性格特征、外貌描写、核心动机
   - 配角设计：功能性角色及其在剧情中的作用
   - 角色关系图：爱恨纠葛、利益冲突、成长弧线
   - 创建角色卡片（参考 `/references/character_template.md`）

### 第三阶段：章节创作（迭代模式）

5. **章节内容生成**
   对每个章节执行：

   a. **章节规划**
      - 明确本章核心事件
      - 确定出场人物
      - 设置本章小高潮或转折点
      - 规划字数目标（建议3000-5000字/章）

   b. **内容撰写**
      - 开篇：场景设定与氛围营造
      - 发展：情节推进与冲突展开
      - 高潮：本章核心事件
      - 结尾：悬念设置或情节闭环
      - 对白：符合人物性格和当前情境

   c. **一致性检查**
      - 时间线一致性：事件先后顺序
      - 人物状态一致性：情感、伤势、能力变化
      - 细节一致性：物品、环境、称呼
      - 伏笔呼应：前面埋下的线索是否回收

6. **章节审核**
   - 检查逻辑漏洞
   - 优化文笔表达
   - 强化情感张力
   - 确保与前后章节衔接自然

### 第四阶段：全局整合

7. **全稿一致性审查**
   - 构建故事事实数据库：
     - 时间线表（年月日、重要事件）
     - 人物状态记录（每个角色的关键状态变化）
     - 物品流转记录（重要道具的位置和归属）
     - 伏笔清单（埋下的线索与回收情况）
   - 检测矛盾点并提出修正建议
   - 优化章节之间的过渡

8. **输出成品**
   - 按用户要求格式输出：单章节/全稿
   - 生成目录索引
   - 可选：导出为TXT/Markdown/JSON格式

## 输出格式规范

章节输出格式：
```
【第X章】章节标题
字数：XXXX字
核心事件：[一句话描述]
出场人物：角色1、角色2...

[正文内容]
```

## 质量标准

- 每个章节应有明确的目标和完成度
- 人物行为应符合已建立的性格特征
- 情节推进应有逻辑支撑
- 伏笔应有合理的回收
- 全局不应出现明显的时间线矛盾
