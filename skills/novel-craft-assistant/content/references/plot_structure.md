# 经典叙事结构参考

## 三幕式结构

```
第一幕 (25%)          第二幕 (50%)              第三幕 (25%)
   │                      │                         │
   ▼                      ▼                         ▼
┌──────┐            ┌──────────────┐           ┌──────┐
│ 铺垫  │──────────▶│    冲突升级   │────────▶│ 解决  │
└──────┘            └──────────────┘           └──────┘
   │                      │                         │
   │                      │                         │
┌──────┐            ┌──────────────┐           ┌──────┐
│ 建立  │            │   中点转折    │           │ 高潮  │
│ 设定  │            │   伪胜利/     │           │ 终极  │
│ 日常  │            │   伪失败      │           │ 对决  │
└──────┘            └──────────────┘           └──────┘
```

### 第一幕：铺垫与建立
- 展示主角的日常生活/正常世界
- 引入主要角色
- 建立故事基调
- 触发事件（B群事件）
- 第一幕转折点：进入新世界

### 第二幕：冲突与成长
- 主角面对新挑战
- 建立盟友与敌人
- 多次尝试与失败
- 中点转折：揭示新信息
- 主角接近目标
- 第二幕转折点：危机降临

### 第三幕：高潮与解决
- 终极决战/核心冲突
- 高潮时刻
- 结局展示
- 收尾与反思

## 章节结构模板

### 单章结构（建议）

```
【开头】
- 场景切入（时间、地点、环境）
- 情绪基调建立
- 角色出场

【发展】
- 事件推进
- 对话/冲突
- 内心活动

【高潮】
- 本章核心事件
- 情感张力顶点

【结尾】
- 悬念设置/情节闭环
- 钩子吸引继续阅读
```
