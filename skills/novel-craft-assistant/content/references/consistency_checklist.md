# 一致性检查清单

## 1. 时间线检查

### 日期与时间
- [ ] 每日日期是否前后一致
- [ ] 季节、天气描写是否与时间线匹配
- [ ] 昼夜更替是否合理
- [ ] 节日/特殊日期是否被正确使用

### 事件顺序
- [ ] 事件因果关系是否合理
- [ ] 回忆/闪回时间点是否准确
- [ ] 准备时间与行动是否匹配（如：说"三天后"，实际天数）
- [ ] 旅行时间、距离是否一致

---

## 2. 人物状态检查

### 外貌特征
- [ ] 头发颜色/长度变化是否追踪
- [ ] 伤病恢复过程是否记录
- [ ] 服装穿着是否前后一致
- [ ] 标志性特征（疤痕、配饰）是否保持

### 性格与能力
- [ ] 人物性格是否保持稳定
- [ ] 能力/技能是否前后一致
- [ ] 知识储备是否合理（不会突然知道不该知道的事）
- [ ] 说话方式/口头禅是否保持

### 情感状态
- [ ] 情感变化是否有铺垫
- [ ] 人物关系发展是否合理
- [ ] 记忆是否准确（不会忘记重要事件）
- [ ] 态度转变是否有合理原因

---

## 3. 物品与道具检查

### 重要物品
- [ ] 物品位置追踪（谁拿着、在哪里）
- [ ] 物品外观描述是否一致
- [ ] 物品能力/功能是否保持
- [ ] 物品所有权变更是否记录

### 文件/信息
- [ ] 证件信息是否一致
- [ ] 联系方式是否正确
- [ ] 秘密/情报传递是否闭环

---

## 4. 世界观设定检查

### 地理环境
- [ ] 地点描述是否一致
- [ ] 建筑布局是否保持
- [ ] 距离/方向是否合理
- [ ] 地名是否统一

### 社会规则
- [ ] 货币系统是否一致
- [ ] 等级制度/权力结构是否保持
- [ ] 技术水平/魔法规则是否一致
- [ ] 法律/习俗是否前后一致

---

## 5. 伏笔与呼应检查

### 伏笔管理表

### 伏笔检查
- [ ] 埋下的线索是否有回收
- [ ] 回收是否自然合理
- [ ] 细节呼应是否准确
- [ ] 人物反应是否符合之前的铺垫

---

## 6. 逻辑漏洞检查

### 行动逻辑
- [ ] 人物动机是否充分
- [ ] 决策是否符合性格
- [ ] 行动结果是否合理
- [ ] 巧合是否过多

### 因果关系
- [ ] 事件触发是否合理
- [ ] 后果是否与原因匹配
- [ ] 是否有遗漏的中间步骤

---

## 7. 格式与风格检查

### 语言风格
- [ ] 叙事视角是否统一
- [ ] 人称是否一致
- [ ] 语气/文风是否统一

### 细节格式
- [ ] 人名/地名写法统一
- [ ] 数字格式统一（中文/阿拉伯数字）
- [ ] 标点使用规范
- [ ] 章节格式统一
