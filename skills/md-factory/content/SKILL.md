# MD Factory - 内容结构化与Markdown生成引擎

> 将输入内容转化为「可直接使用的成品内容」

---

## 核心能力

### 它能做什么

- **格式转换**：PDF、DOCX、XLSX、PPTX、HTML、图片(OCR)、音频(转写) → Markdown
- **智能结构化**：自动识别内容类型，匹配最佳输出模板
- **成品输出**：生成可直接粘贴到 Notion、Obsidian、小红书、GitHub 的内容

### 它与众不同的地方

| 普通转换工具 | MD Factory |
|-------------|-----------|
| 保留原文结构 | 重建优化结构 |
| 输出生硬难读 | 适合人类阅读 |
| 需要手动整理 | 自动提炼要点 |
| 仅格式转换 | 输出可直接使用 |

## 使用方法

### 安装

```bash
pip install -r requirements.txt
```

### 命令行使用

```bash
# 自动识别模板
python convert.py document.pdf -o output.md

# 指定模板
python convert.py document.pdf -o output.md --template knowledge-card

# 批量处理 + 指定模板
python convert.py ./docs/ -d ./output/ --template tech-doc
```

### Python API

```python
from convert import MDConverter

# 创建转换器
converter = MDConverter()

# 转换并结构化（自动选择模板）
result = converter.convert_and_structure("document.pdf")

# 指定模板
result = converter.convert_and_structure(
    "document.pdf",
    template="knowledge-card"
)
print(result)
```

## 处理流程

```
┌─────────────────────────────────────────────────────┐
│                    处理流程                          │
├─────────────────────────────────────────────────────┤
│  1. 理解主题 → 识别内容类型和核心信息                │
│  2. 提取要点 → 从原文中筛选关键内容                 │
│  3. 删除噪音 → 移除广告、导航、无意义内容           │
│  4. 重建结构 → 按模板要求重组内容                   │
│  5. 输出成品 → 生成可直接使用的结果                 │
└─────────────────────────────────────────────────────┘
```

---

## 结构修复规则

自动执行以下修复：

| 问题 | 修复方式 |
|------|----------|
| 标题层级混乱 | 重建 H1→H2→H3 层级 |
| 段落过长 | 自动拆分为短段落 |
| 重复信息 | 合并去重 |
| 噪音内容 | 删除广告/导航/无关内容 |
| 缺失总结 | 补全 TL;DR |
| 缺少标签 | 自动生成相关标签 |

## 命令行参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `input` | 输入文件或目录 | - |

## 故障排除

### 转换结果为空

可能是扫描件PDF，需要OCR支持：
```bash
pip install 'markitdown[all]'
```

### 模板选择不准确

使用 `--template` 手动指定模板类型

### 内容结构混乱

工具会自动重建结构，如需保留原结构使用 `--no-restructure`
