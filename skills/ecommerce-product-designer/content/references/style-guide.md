# 电商美工图片风格指南

## 主图风格规范

### 1. 简约白底风格
**适用场景**: 淘宝、天猫、京东等国内电商平台

**特点**:
- 纯白背景 (RGB: 255, 255, 255)
- 产品居中，占画面 60-80%
- 无阴影或柔和投影
- 简洁明了

**提示词模板**:
```
Clean white background e-commerce product photo, [产品名称] centered,
professional studio lighting, minimalist composition, [颜色] finish,
high-end product photography style, no distracting elements,
sharp focus, commercial quality, 4K resolution
```

### 2. 渐变背景风格
**适用场景**: 跨境电商、独立站、APP展示

**特点**:
- 渐变色背景 (如粉色系、蓝色系渐变)
- 产品立体感强
- 时尚感强

**提示词模板**:
```
E-commerce product showcase, [产品名称] on elegant gradient background
([颜色1] to [颜色2]), professional lighting with soft shadows,
modern minimalist style, [风格描述], vibrant commercial photography,
centered composition, studio setting, ultra detailed, 8K
```

### 3. 场景化风格
**适用场景**: 家具、家居、户外用品

**特点**:
- 产品在实际场景中展示
- 生活方式感强
- 情感连接度高

**提示词模板**:
```
Lifestyle product photography, [产品名称] in realistic [场景描述] setting,
warm natural lighting, [颜色] color palette, cozy atmosphere,
professional interior photography style, soft focus background,
commercial e-commerce quality, [情绪描述] mood
```

## 详情页设计规范

### 布局结构
1. **顶部Banner** - 品牌标识 + 主推广语
2. **产品卖点** - 3-5个核心优势
3. **细节展示** - 产品特写 + 材质说明
4. **使用场景** - 真实场景应用
5. **规格参数** - 尺寸、材质、配件
6. **用户评价** - 口碑展示
7. **购买引导** - CTA按钮 + 售后保障

### 图片尺寸
- 宽度: 750px (手机端标准)
- 高度: 视内容而定，建议单张不超过 2000px
- 宽高比: 3:4 或 9:16 竖版

### 排版原则
- 留白充足，呼吸感强
- 文字精炼，突出重点
- 色彩统一，不超过3种主色

## 营销文案优化技巧

### 主标题公式
```
[人群] + [场景] + [核心利益点] + [产品名称]
示例: "都市白领首选 | 轻便降噪 | [品牌]无线耳机"
```

### 卖点挖掘维度
1. **功能价值** - 产品能做什么
2. **情感价值** - 带给用户什么感受
3. **社交价值** - 展示能带来什么身份认同
4. **经济价值** - 性价比、耐用性

### 差异化表达
- 对比法: "比普通XX更XX"
- 数字法: "XX项黑科技，XX%提升"
- 场景法: "无论XX还是XX，都能XX"
- 溯源法: "来自XX的XX，XX年匠心"
