# 微信公众号科技资讯生成器

端到端自动化创作科技/AI/机器人领域每日资讯文章。

## 核心能力

- **选题智能解析**：理解用户提供的领域方向，提取核心资讯点
- **内容结构化生成**：标题 + 导语 + 正文 + 结语，适配公众号阅读习惯
- **专业配图生成**：封面图 + 章节配图，统一科技风格
- **自动排版输出**：输出可直接粘贴到公众号编辑器的 HTML

## 工作流程

### 阶段一：选题与信息收集

1. **解析用户选题**
   - 提取领域关键词：科技/AI/机器人/大模型/智能体/具身智能
   - 确定文章定位：资讯快讯/深度解读/行业分析
   - 识别目标受众：从业者/爱好者/投资人/大众

2. **信息补全（如需）**
   - 使用引导表单收集：文章风格、字数要求、重点方向
   - 推荐默认参数确保内容质量

### 阶段二：内容生成

1. **网络搜索最新动态**
   - 搜索关键词：`[领域] 最新进展 2026`
   - 搜索来源：科技媒体、行业报告、官方发布
   - 筛选高价值资讯：重大突破、产品发布、行业合作

2. **文章结构设计**
   ```
   - 标题：数字量化 + 悬念悬念（20字内）
   - 导语：今日核心动态一句话概括
   - 正文：3-5个资讯点，每点含标题 + 简述 + 解读
   - 结语：明日关注点 + 互动引导
   ```

3. **内容生成要求**
   - 字数：1500-2500字
   - 风格：专业但不晦涩，技术词汇适度解释
   - 结构：多级标题划分，使用 emoji 增加可读性
   - 配图提示：为每个主要章节标注配图需求

### 阶段三：配图生成

1. **封面图**
   - 主题：当日核心领域代表性画面
   - 风格：科技感强、色彩鲜明
   - 尺寸：900x383（公众号封面标准）

2. **章节配图**
   - 每个主要资讯点配图 1 张
   - 风格统一：扁平化科技风或写实渲染
   - 尺寸：600x400（横版）或 400x600（竖版）

### 阶段四：排版与输出

1. **排版规范**
   - 标题：24px 加粗，#1a1a1a
   - 正文：16px，#333333，行高 1.8
   - 引用：左侧 3px 边框，#f5f5f5 背景
   - 重点：加粗 + #e74c3c 红色
   - 段落间距：16px

2. **输出文件**
   - `article.html` - 排版好的完整文章
   - `article.md` - Markdown 源文件
   - `cover.jpg` - 封面图
   - `images/` - 章节配图文件夹
   - `publish-guide.md` - 发布操作指引

## 输出产物

| 文件 | 说明 |
|------|------|
| article.html | 排版好的 HTML，可直接复制到公众号 |
| article.md | Markdown 源文件备份 |
| cover.jpg | 封面图 |
| images/*.jpg | 章节配图（3-5张） |
| publish-guide.md | 复制粘贴操作指引 |
