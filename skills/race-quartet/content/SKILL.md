# 香港赛马三重彩/四重彩预测系统

本技能提供完整的赛马预测工作流，从数据采集到投注建议生成。

## 核心功能

### 1. 数据采集

从香港赛马会（HKGRI）公开数据源采集历史赛事数据：

- **赛事基本信息**：日期、场次、赛道类型、途程、场地状况
- **马匹数据**：马名、编号、负磅、档位、血统
- **骑师与练马师**：胜率、历史搭档记录
- **赛果数据**：完成时间、排名、赔率、派彩

**数据源优先级**：
1. HKJC 官方网站公开数据
2. 赛马数据聚合平台（需配置）
3. 用户提供的自定义数据

### 2. 特征工程

自动计算以下特征类别：

| 特征类别 | 具体指标 |
|---------|---------|
| 时序衰减特征 | 最近3/5/10场加权胜率、指数衰减平均排名 |
| 对比特征 | 历史交锋胜负记录、相对排名差异 |
| 状态特征 | 近期表现趋势、状态波动系数 |
| 赛道适配特征 | 特定赛道/途程历史胜率 |
| 组合特征 | 骑师×马匹协同效应、负磅适应度 |

### 3. 排序模型

支持多种排序预测模型：

#### Bradley-Terry 模型
- **原理**：基于成对比较的强度参数估计
- **适用场景**：数据稀疏的新马、数据有限的赛季分析
- **输出**：每匹马的相对强度参数、Top-K 排列概率分布

#### Elo/TrueSkill 评分系统
- **Elo**：经典单维评分，适合简单场景
- **TrueSkill**：多维评分+不确定性估计，适合复杂场景
- **输出**：马匹评分、胜率预测、置信区间

#### 模型选择建议
- 初赛马或数据有限 → Bradley-Terry
- 稳定参赛马匹分析 → Elo/TrueSkill
- 综合预测 → 多模型集成

### 4. 投注建议

基于预测结果生成投注组合：

**三重彩预测**
- 计算所有可能排列的概率分布
- 输出 Top-10 高概率三重彩组合及期望值
- 标注推荐等级（高/中/低优先级）

**四重彩预测**
- 计算前四名排列概率
- 输出 Top-10 组合及期望值
- 提供覆盖策略建议

## 使用方法

### 基础预测分析

```
请分析 [日期/场次] 的香港赛马三重彩预测
```

### 完整工作流

```
对 [日期] 的 [场次] 进行完整预测分析，包括：
1. 数据采集和特征工程
2. Bradley-Terry 模型训练
3. 生成三重彩/四重彩投注建议
```

### 自定义参数

支持以下参数自定义：
- `model_type`: 模型类型选择（bt/elo/trueskill）
- `top_k`: 返回的 Top-K 组合数量
- `min_ev_threshold`: 最小期望值阈值
- `feature_window`: 特征计算的时序窗口大小

### 数据导入

如需使用自定义数据进行分析，请提供：
- CSV 格式的马匹历史表现数据
- 或 Excel 格式的赛事记录

## 注意事项

1. **数据时效性**：建议使用最近 2-3 个马季的数据进行训练
2. **模型局限性**：预测结果仅供参考，马赛存在固有不确定性
3. **投注风险**：请理性投注，设置止损线
4. **税费说明**：香港赛马返奖率约 82%，计算期望值时需扣除 18% 税费

## 技术架构

```
用户输入 → 数据采集 → 特征工程 → 模型训练 → 预测输出 → 投注建议
     ↓          ↓           ↓           ↓           ↓
  参数配置    HKJC API    时序计算   BT/Elo/TS   期望值优化
```
