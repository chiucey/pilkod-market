# 阿里国际站TM聊天自动回复助手

## 技能概述

本技能帮助用户实现阿里国际站TM聊天的自动回复功能。通过在本地Windows电脑部署代理程序，配合AI智能分析，为外贸卖家提供7x24小时的智能客服支持。

## 工作流程

### 步骤1：环境检测
- 检测TM安装位置和版本
- 确认操作系统类型
- 检测代理程序运行状态

### 步骤2：消息监控
- 实时监控TM聊天窗口
- 抓取买家发送的新消息
- 识别消息发送时间/买家ID/产品咨询

### 步骤3：智能分析
- 分析买家意图（询价/议价/售后/样品等）
- 匹配知识库中的标准回复
- 调用AI生成个性化回复

### 步骤4：自动回复
- 支持人工审核后发送
- 支持全自动直接发送
- 支持定时延迟发送

## 回复策略

### 关键词模板匹配
```
询价 → 价格表/目录
样品 → 样品政策/运费说明
MOQ  → 最小起订量说明
价格 → 阶梯报价/优惠信息
交期 → 生产周期/发货时间
```

### AI智能回复
- 支持多语言（中/英/西/法/德等）
- 语气可调（专业/友好/正式）
- 自动学习用户回复习惯

## 配置参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `auto_mode` | 自动发送模式 | `review` |
| `delay_seconds` | 回复延迟(秒) | `30` |
| `language` | 回复语言 | `en` |
| `keyword_rules` | 关键词规则 | `[]` |

## 注意事项

1. **账号安全**：避免频繁自动回复触发风控
2. **业务差异**：B2B场景复杂，AI回复需人工审核
3. **数据隐私**：聊天数据仅本地处理，不上传云端
