# 龙头股识别与操作手册

## 龙头股的定义

### 什么是龙头股

龙头股是指在某个板块或概念中，具有领导地位、率先启动、涨幅领先、同板块中影响最大的股票。

### 龙头股特征

```
龙头股 = 板块涨幅第一 + 涨停质量高 + 资金认可 + 题材纯正
```

## 龙头股识别模型

### 评分体系

| 评分维度 | 权重 | 评分标准 |
|---------|-----|---------|
| 身位领先 | 25% | 板块内涨停时间最早 |
| 封板力度 | 25% | 封单金额/成交额 > 0.5 |
| 题材纯正 | 20% | 主业与热点契合度高 |
| 形态突破 | 15% | 涨停突破重要压力位 |
| 资金实力 | 15% | 主力资金净流入大 |

### 龙头股分类

#### 1. 总龙头（情绪龙头）

- 全市场最高连板
- 不分板块，带动整体情绪
- 介入方式：打板、竞价
- 仓位建议：20-30%

#### 2. 板块龙头

- 板块内涨幅最大
- 带动同板块个股
- 介入方式：打板、回调低吸
- 仓位建议：10-20%

#### 3. 补涨龙

- 跟随龙头上涨
- 题材正宗但身位落后
- 介入方式：低吸
- 仓位建议：5-10%

### 加分项（满足越多越好）

1. **身位领先** - 板块内第一个涨停
2. **题材正宗** - 主业直接受益
3. **历史股性** - 之前有过涨停记录
4. **形态突破** - 涨停突破前高/均线
5. **消息刺激** - 有明确利好公告

## 龙头股操作策略

### 1. 竞价买入

**适用场景**：龙头一字板打开
```
条件：
- 竞价成交量 > 昨日成交 10%
- 股价低开 < 5%
- 板块情绪延续
```

**买入方法**：
- 9:25前准备
- 9:25-9:30观察竞价
- 符合条件立即下单

### 2. 打板买入

**适用场景**：早盘强势涨停
```
条件：
- 涨幅 > 5% 后涨停
- 封板时量 > 昨日全天 50%
- 封单 > 5000万
```

**买入方法**：
- 涨停瞬间下单
- 部分成交即可
- 预留仓位防撤单

### 3. 回调低吸

**适用场景**：龙头股首次分歧
```
条件：
- 涨停次日低开/回调
- 回调幅度 < 5%
- 承接有力
```

**买入方法**：
- 分批买入
- 设定止损位
- 严格控制仓位

## 龙头股风险控制

### 止损位设置

| 买入方式 | 止损位 | 说明 |
|---------|-------|-----|
| 竞价买入 | -5% | 开盘即亏5%需止损 |
| 打板买入 | -7% | 涨停价计算 |
| 低吸买入 | -3% | 买入价计算 |

### 仓位管理

```
单票仓位 = 风险度系数 / 止损幅度

示例：
- 风险度系数：1
- 止损幅度：5%
- 单票仓位：1/5 = 20%
```

### 卖出时机

1. **次日冲高卖出** - 开盘/冲高即卖
2. **破板即卖** - 涨停打开第一时间卖出
3. **高位放量卖出** - 换手率 > 25% 谨慎
4. **达到目标卖出** - 设定止盈位

## 龙头股情绪周期

```
情绪周期：
冷淡期 → 升温期 → 狂热期 → 高潮期 → 退潮期 → 冷淡期

龙头股机会：
冷淡期：不追高，等待
升温期：布局龙头
狂热期：持股待涨
高潮期：高位减仓
退潮期：空仓观望
```

## 常见问题

### Q1：如何判断龙头？
1. 板块内第一个涨停
2. 封板力度最强
3. 题材最正宗
4. 资金净流入最大

### Q2：龙头股买入后不连板怎么办？
- 次日冲高卖出
- 不恋战
- 严格止损

### Q3：跟风股能不能买？
- 跟风股：可以轻仓做短线
- 杂毛股：不建议买
- 区分方法：看板块内涨停数量和时间

### Q4：大盘环境对龙头股影响？
- 大盘好：龙头股更容易连板
- 大盘差：龙头股独立走强
- 大盘暴跌：所有股票都危险
