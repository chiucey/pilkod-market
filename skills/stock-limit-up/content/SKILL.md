# 涨停板筛选与龙头股分析技能

## 核心能力

1. **涨停板识别** - 识别当日涨停股票，分析涨停质量
2. **龙头股筛选** - 从涨停股中筛选真正的龙头标的
3. **连板股追踪** - 追踪连续涨停股票，判断连板逻辑
4. **板块联动分析** - 分析涨停股所属板块，找出板块龙头
5. **打板策略评估** - 评估涨停板介入机会与风险

## 涨停板质量评估体系

### 涨停质量评分维度

| 维度 | 指标 | 权重 | 说明 |
|-----|------|-----|------|
| 封板力度 | 封单金额/成交额比 | 20% | 封单越大越强势 |
| 换手率 | 当日换手率 | 15% | 适中为佳，过高有出货嫌疑 |
| 流通市值 | 流通盘大小 | 15% | 过大难连续，过小流动性差 |
| 板块效应 | 所属板块涨停数量 | 20% | 板块联动强更有持续性 |
| 封板时间 | 涨停时间早晚 | 15% | 越早封板越强势 |
| 昨日表现 | 昨日K线形态 | 15% | 缩量涨停更健康 |

### 涨停板分类

1. **一字板** - 开盘即涨停，全天未打开
   - 特点：极度强势，但难以介入
   - 风险：次日可能高开低走

2. **早盘板** - 上午10:30前涨停
   - 特点：强势信号，市场认可度高
   - 机会：可考虑打板介入

3. **午盘板** - 10:30-14:00涨停
   - 特点：一般强势
   - 风险：需结合板块判断

4. **尾盘板** - 14:00后涨停
   - 特点：弱势信号，可能被砸
   - 风险：谨慎对待

## 龙头股识别模型

### 龙头股核心特征

```
龙头股 = 板块涨幅领先 × 涨停质量高 × 流通性适中 × 资金认可度高
```

### 筛选条件

#### 必须满足
- [ ] 所属板块涨停数量 ≥ 2只
- [ ] 流通市值 10-500亿
- [ ] 换手率 3%-20%
- [ ] 封板金额 > 5000万

#### 加分项
- [ ] 题材新颖、想象空间大
- [ ] 身位领先（率先涨停）
- [ ] 形态突破（突破重要压力位）
- [ ] 消息面刺激（政策、业绩、事件）

### 龙头股评级

| 等级 | 描述 | 介入建议 |
|-----|------|---------|
| S级 | 绝对龙头，板块灵魂 | 竞价/打板介入 |
| A级 | 强势跟风龙，身位靠前 | 打板介入，轻仓 |
| B级 | 跟风股，板块联动 | 谨慎，次日观察 |
| C级 | 杂毛股，无板块效应 | 不建议介入 |

## 工作流程

### 涨停板分析流程

```
用户输入 → 股票/板块识别 → 数据获取 → 质量评分 → 龙头判断 → 输出报告
```

### 步骤1：获取涨停数据

获取当日涨停股票列表：
- 涨跌幅 = 9.9%~10.1%（A股涨停）
- 按涨停时间、封单金额排序

### 步骤2：板块分类

对涨停股进行板块归类：
- 行业分类（按申万行业）
- 概念分类（按题材概念）
- 地域分类（按上市公司地域）

### 步骤3：龙头筛选

按以下标准打分：
1. **身位领先**：板块内最早涨停
2. **封板力度**：封单金额/成交额 > 0.5
3. **换手健康**：换手率 3%-15%
4. **形态突破**：涨停突破重要均线/平台
5. **题材纯正**：主营与热点契合度

### 步骤4：风险评估

- 大盘环境评估（市场情绪）
- 解禁压力分析
- 减持风险提示
- 前期涨幅评估

## 涨停板操作策略

### 竞价买入策略

适用场景：龙头股一字板打开后
- 竞价成交量 > 昨日成交10%
- 股价低开 < 3%
- 板块情绪延续

### 打板买入策略

适用场景：早盘强势涨停
- 涨停前股价在5%以上涨幅
- 封板时成交量 > 昨日全天50%
- 封单金额 > 5000万

### 仓位管理

| 股票评级 | 建议仓位 | 止损位 |
|---------|---------|-------|
| S级龙头 | 10-20% | -5% |
| A级跟风 | 5-10% | -7% |
| B级杂毛 | 3-5% | -10% |

## 注意事项

1. **涨停板有风险** - 追板是高风险操作
2. **止损必备** - 必须设置止损点
3. **仓位控制** - 单票不超过20%仓位
4. **情绪管理** - 不要盲目追高
5. **数据分析** - 仅供参考，不构成投资建议
