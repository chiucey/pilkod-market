# 洞察工作组织与方法

## 一、洞察工作形式

### 1.1 三种洞察形式

| 形式 | 特征 | 适用场景 | 周期 |
|-----|------|---------|------|
| 例行洞察 | 周期性、持续性 | 日常监控 | 月度/季度 |
| 热点洞察 | 快速响应 | 突发事件 | 按需 |
| 深度洞察 | 深入研究 | 重大课题 | 项目周期 |

### 1.2 例行化洞察信息收集

#### 信息来源
```
项目与合同信息
品牌活动信息
客户接触记录
创新与产品解决方案
财务表现数据
```

#### 信息分类
| 信息类别 | 具体内容 |
|---------|---------|
| 项目与合同 | 重大项目进展、合同签订情况 |
| 品牌活动 | 行业大会、展示活动 |
| 客户接触 | 客户拜访、交流记录 |
| 创新方案 | 新产品、新技术、新方案 |
| 财务数据 | 业绩报告、财务指标 |

## 二、洞察信息来源体系

### 2.1 一手信息获取
| 方法 | 说明 |
|-----|------|
| 一线调研 | 与行销、市场代表深入交流 |
| 明白人互动 | 与客户内部明白人深度访谈 |
| 联合创新 | 与客户共同开展创新项目 |
| 项目深入 | 深度参与关键项目运作 |

### 2.2 二手信息收集
| 方法 | 说明 |
|-----|------|
| 调查问卷 | 结构化问卷调研 |
| 咨询报告 | 行业分析报告 |
| 网络数据 | 公开数据挖掘 |
| 公开信息 | 新闻、年报、行业分析 |

### 2.3 数据分析方法
```
真实数据采集
    ↓
建立分析模型
    ↓
量化分析
    ↓
得出洞察结论
```

## 三、洞察项目运作

### 3.1 洞察项目组织架构
```
专题总目标
     ↓
┌─────┴─────┐
↓     ↓     ↓
区域  研发  其他
洞察  互锁  协同
     ↓
一线调研
```

### 3.2 区域洞察策略
| 市场类型 | 特征 | 洞察重点 |
|---------|------|---------|
| 第一波市场 | 行业领导者，技术领先 | 创新趋势 |
| 第二波市场 | 产粮区，性价比优 | 主流需求 |
| 第三波市场 | 人口红利，低成本ROI | 规模效益 |

### 3.3 洞察目标定制
- **区域目标定制化**：根据区域特点或关键大T项目制定洞察目标
- **研发目标对齐**：与研发技术项目沟通，确定研究方向
- **周边沟通**：利用一切资源获取客户真实信息

## 四、洞察工作流程

### 4.1 四步洞察流程
```
第一步：深入场景
    ↓
第二步：痛点识别
    ↓
第三步：需求提炼
    ↓
第四步：方案构想
```

### 4.2 深入场景要点
| 动作 | 说明 |
|-----|------|
| 协同洞察 | 成立洞察项目，一线调研 |
| 关键项目深入 | 深耕重大项目，牵引需求 |
| 明白人互动 | 与客户明白人深度交流 |
| 联合创新 | 与客户共同定义产品 |

### 4.3 痛点识别要点
| 动作 | 说明 |
|-----|------|
| 数据挖掘 | 从网络数据中发现本质 |
| 根因分析 | 刨根问底，找出真正问题 |
| 模型建立 | 建立量化分析模型 |

### 4.4 需求提炼要点
| 动作 | 说明 |
|-----|------|
| 聚焦重点 | 抓住主要矛盾 |
| 敢于取舍 | 去伪存真 |
| 优先级排序 | 十六字方针指导 |

### 4.5 方案构想要点
| 动作 | 说明 |
|-----|------|
| 双轮驱动 | 市场+研发共同驱动 |
| 目标牵引 | 以目标网牵引 |
| 极简设计 | 外部极简，内部复杂 |

| 传播能力 | 洞察成果有效传递 |
