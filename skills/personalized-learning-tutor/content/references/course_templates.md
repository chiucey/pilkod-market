## 知识图片生成指南

### 流程图（Mermaid）
适用于：步骤过程、工作流程、算法流程

```
graph TD
    A[开始] --> B[步骤1]
    B --> C[步骤2]
    C --> D{判断条件}
    D -->|是| E[结果A]
    D -->|否| F[结果B]
    E --> G[结束]
    F --> G
```

### 架构图（Mermaid）
适用于：系统架构、层级结构、组织结构

```
graph TB
    A[顶层概念] --> B[分支1]
    A --> C[分支2]
    A --> D[分支3]
    B --> B1[子概念1]
    B --> B2[子概念2]
    C --> C1[子概念3]
    D --> D1[子概念4]
```

适用于：方案对比、特性比较、优缺点分析

|------|-------|-------|------|

## 案例搜索模板

### 搜索关键词组合
```
# 基础搜索
[核心概念] + 应用案例
[核心概念] + 实战
[核心概念] + 成功案例
[核心概念] + 行业案例

# 扩展搜索
[核心概念] + 2024/2025 + 案例
[核心概念] + 企业/公司 + 应用
[核心概念] + 数据/统计 + 报告
```

### 案例格式要求
1. **真实可信**：来源于可靠渠道
2. **具体数据**：包含可量化的结果
3. **清晰背景**：说明应用场景
4. **关联所学**：紧扣课程知识点

## 课程分解策略

### 按难度分配
- **简单概念**（理解级）：可每天2-3个概念
- **中等难度**（应用级）：每天1-2个概念
- **复杂内容**（精通级）：每2天1个核心主题

### 按内容结构分配
- **独立章节**：可单独成课
- **系列概念**：保持连续性，分配在同一周
- **总结复习**：每5-7天安排一次复习

### 时间缓冲
- 总天数的90%用于新内容
- 10%用于总结和缓冲
- 考虑周末/休息日设置

## 难度等级定义

### 入门级
- 基础概念解释
- 简单案例
- 无专业术语或有限解释
- 快速上手为目标

### 进阶级
- 深入原理讲解
- 实际应用案例
- 包含最佳实践
- 独立应用为目标

### 精通级
- 深度原理剖析
- 复杂案例分析
- 前沿趋势探讨
- 系统掌握为目标
