## 二、成长性分析

### 2.1 收入端
- 量的增长（销量、市场份额）
- 价的增长（产品结构升级、提价能力）
- 新业务拓展
- 并表因素

### 2.2 利润端
- 毛利率变化及原因
- 费用率控制（销售/管理/研发/财务）
- 营业利润率趋势
- 净利润率趋势

### 2.3 成长质量
```
收入含金量 = 经营现金流/净利润
盈利质量指数 = 经营现金流/归母净利润
```

## 三、盈利能力分析

### 3.1 杜邦分析
```
ROE = 净利率 × 资产周转率 × 权益乘数
    = (净利润/收入) × (收入/资产) × (资产/净资产)

分解：
- 净利率：体现产品竞争力
- 周转率：体现资产效率
- 杠杆率：体现负债经营程度
```

## 四、偿债能力分析

### 4.1 短期偿债
- 流动比率 = 流动资产/流动负债（>1.5稳健）
- 速动比率 = (流动资产-存货)/流动负债（>1理想）
- 现金比率 = 货币资金/流动负债

### 4.2 长期偿债
- 资产负债率（>70%警戒线）
- 产权比率
- 利息保障倍数

### 4.3 债务结构
- 有息负债/总负债
- 短期债务/长期债务
- 债务到期分布

## 五、运营效率分析

### 5.1 资产周转
- 总资产周转率
- 存货周转天数
- 应收账款周转天数
- 应付账款周转天数

### 5.2 现金循环周期
```
现金循环周期 = 存货周转天数 + 应收账款周转天数 - 应付账款周转天数
```

### 5.3 营运资本分析
- 应收账款高企风险
- 存货跌价风险
- 供应商占款能力

## 六、现金流分析

### 6.1 现金流肖像
```
经营现金流 + 正：表明"奶牛型"企业
          - 负：表明"赌徒型"企业
投资现金流 + 正：表明收缩战略
          - 负：表明扩张战略
融资现金流 + 正：表明输血维持
          - 负：表明还债或分红
```

### 6.2 现金流质量
- 经营现金流/净利润 > 1 优质
- 资本支出/折旧摊销合理性
- 自由现金流 = 经营现金流 - 资本支出

## 八、财务风险识别

### 8.1 预警信号
- 应收账款异常增长
- 存货周转显著放缓
- 毛利率持续下滑
- 关联交易频繁
- 会计政策变更
- 审计非标意见

### 8.2 财务造假特征
- 收入虚增（虚增合同、提前确认）
- 利润操纵（变更会计估计、少计费用）
- 资产泡沫（虚增资产、在建工程延迟转固）
- 现金流造假（虚增经营现金流）
