# 公募基金研究报告技能

## 核心能力

### 1. 报告类型覆盖

| 报告类型 | 触发关键词 | 标准结构 |
|---------|-----------|---------|
| 宏观策略报告 | 宏观、策略、大类资产 | 宏观经济→政策展望→资产配置→行业机会 |
| 行业深度报告 | 行业研究、行业深度、赛道 | 行业概况→竞争格局→产业链→核心标的 |
| 公司深度报告 | 公司深度、公司研究、个股 | 公司概况→业务分析→财务解读→估值分析→投资建议 |
| 基金产品分析 | 基金产品、基金分析、业绩归因 | 产品概况→业绩分析→持仓分析→风险收益特征 |
| 定期跟踪报告 | 季报、年报、跟踪、点评 | 数据概览→重点变化→投资展望 |

### 2. 标准分析框架

#### 宏观分析框架
```
1. 经济周期判断
   - GDP增长与结构
   - 通胀与货币政策
   - 流动性环境

2. 政策环境评估
   - 财政政策方向
   - 货币政策取向
   - 监管政策变化

3. 资产配置建议
   - 权益/固收/商品权重
   - 行业轮动策略
   - 风格配置建议
```

#### 行业分析框架
```
1. 行业空间测算
   - 市场规模(TAM)
   - 增速与驱动力
   - 渗透率分析

2. 竞争格局研判
   - 波特五力分析
   - 竞争壁垒识别
   - 格局演变趋势

3. 产业链价值分布
   - 上游原材料
   - 中游制造/服务
   - 下游渠道/终端

4. 核心标的筛选
   - 龙头公司
   - 成长黑马
   - 估值性价比
```

#### 公司分析框架
```
1. 商业模式拆解
   - 收入结构
   - 利润来源
   - 现金流特征

2. 核心竞争力评估
   - 产品/技术壁垒
   - 渠道/品牌优势
   - 管理层能力

3. 财务分析
   - 成长性(收入/利润增速)
   - 盈利能力(毛利率/净利率/ROE)
   - 偿债能力(负债率/流动性)
   - 运营效率(周转率)

4. 估值方法选择
   - PE/PB/PS估值
   - DCF现金流折现
   - PEG成长估值
   - EV/EBITDA
```

### 3. 报告格式规范

#### 标题结构
```
[公司/行业简称]深度报告：[主标题]
[副标题：核心观点概括，20字以内]

示例：
宁德时代深度报告：全球锂电龙头，成长空间广阔
```

#### 正文结构
```
一、投资要点（3-5条核心逻辑）
二、行业/公司基本情况
三、核心分析
四、财务预测与估值
五、风险提示
六、投资建议
```

#### 数据引用规范
- 财务数据必须标注来源（公司公告、Wind、彭博等）
- 预测数据需明确假设前提
- 图表需标注数据来源和截止日期
- 估值基准日必须明确

### 4. 专业术语规范

| 英文缩写 | 中文含义 | 使用场景 |
|---------|---------|---------|
| TAM | 潜在市场总量 | 行业空间测算 |
| CAGR | 复合年均增长率 | 成长性分析 |
| ROE | 净资产收益率 | 盈利能力分析 |
| DCF | 现金流折现 | 绝对估值法 |
| PEG | 市盈率相对增长比率 | 成长股估值 |
| EV | 企业价值 | 并购估值 |
| Beta | 系统性风险 | 波动性分析 |
| Alpha | 超额收益 | 主动管理能力 |

### 5. 风险提示模板

```markdown
风险提示：
1. 政策风险：监管政策变化超预期
2. 市场风险：系统性下跌风险
3. 经营风险：原材料价格波动/产品需求不及预期
4. 财务风险：应收账款/存货周转恶化
5. 估值风险：市场情绪导致估值中枢下移
```

### 6. 输出格式

生成报告时遵循以下格式：

```
# [标题]

## 报告信息
- 报告日期：[YYYY-MM-DD]
- 分析师：[姓名]
- 评级：[买入/增持/中性/减持]

## 一、投资要点
[3-5条核心逻辑]

## 二、XX分析
[详细分析内容]

## 三、财务预测
[关键假设与预测数据]

## 四、估值与投资建议
[估值方法与结论]

## 五、风险提示
[风险因素列表]
```

## 触发检测规则

当用户输入包含以下模式时，激活此技能：
- "写/撰写/生成 + 报告"
- "基金研究/行业研究/公司研究"
- "投资价值/深度分析"
- "评级/目标价"
- "业绩预测/财务预测"
- 具体的公司/行业名称 + "分析/报告/研究"

## 质量门槛

1. **完整性检查**：包含标准报告结构的所有必要章节
2. **数据支撑**：关键结论有数据或逻辑支撑
3. **逻辑一致性**：各部分分析逻辑连贯，相互印证
4. **风险揭示**：不回避风险因素
5. **时效性意识**：明确标注数据截止日期
