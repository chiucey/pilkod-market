# 用药安全检查技能

## 核心功能

本技能帮助用户检查药物之间的相互作用，确保用药安全。

## 工作流程

### 步骤1：识别用户输入的药物

1. 解析用户输入，提取所有药物名称
2. 标准化药物名称（别名→标准名称）
3. 去重并确认药物列表

### 步骤2：查询药物相互作用

1. 加载 `references/drug_interactions.json` 数据库
2. 对每对药物进行相互作用检查
3. 查询每种药物的禁忌食物和行为

### 步骤3：生成分析报告

根据检查结果，生成结构化报告：

```
## 用药安全分析报告

### 1. 药物相互作用检查

| 药物组合 | 是否安全 | 风险等级 | 说明 |
|---------|---------|---------|------|
| 药物A + 药物B | ⚠️ 谨慎 | 中 | 可能导致... |

### 2. 禁忌药物清单

以下药物**禁止**与您当前服用的药物同时服用：
- [药物名称] - 原因：...

### 3. 禁忌食物清单

用药期间**禁止**食用以下食物：
- [食物名称] - 原因：...

### 4. 禁忌行为清单

用药期间**应避免**以下行为：
- [行为名称] - 原因：...

### 5. 安全建议

- 建议用药时间
- 饮食注意事项
- 何时就医
```

## 风险等级定义

- **严重（🚨）**: 可能危及生命，必须立即停药或就医
- **高危（⚠️）**: 可能导致严重不良反应，需密切监测
- **中危（⚡）**: 可能影响药效或导致轻微不适
- **低危（ℹ️）**: 影响较小，但仍需注意

## 重要提醒

1. 本技能提供的信息仅供参考，不能替代医生诊断
2. 如有疑问，请立即咨询医生或药师
3. 遇到严重反应应立即就医
