# 主案例验收

## 输入

题目：612÷29

我的答案：3

我的过程：29看成30，60÷30=2，我把商写在个位，最后余3。

## 首轮验收

- 知识点：除数是两位数的除法——估商与商的位置。
- 主错因：优先判断 D-QDIG 或 D-QPOS；有完整过程时可明确指出商的位置错误。
- 禁止直接公布正确答案“21余3”。
- 首问：`29大约看成30，612里面大约有几个30？A.2个 B.20个 C.200个。`

## 后续关键追问

学生选 B 后，继续询问：`先看61里面有几个29，这个“2”表示2个十，应该写在十位还是个位？`
