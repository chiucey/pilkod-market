# Token Cost Controller

OpenClaw Token cost control skill - Smart caching, dynamic routing, real-time monitoring.

## Installation

```bash
npm install
node install.js
```

## Usage

```bash
node cli.js report       # View report
node cli.js top-skills   # Top consuming skills
node cli.js alerts       # View alerts
```

## Features

- Smart Cache - Save 30-50%
- Dynamic Routing - Auto-select optimal model
- Real-time Monitoring - Detect anomalies within 5 seconds
- One-click Control - Disable skills, set budget
