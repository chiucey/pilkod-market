# 场景类型与提示词模板

## 电商/广告

### 核心特点
- 产品360度旋转展示、爆炸分解、3D渲染特效
- 第一人称沉浸式手作体验
- 模仿参考视频的广告创意，替换产品主体
- 配合广告词和品牌logo

### 提示词模板
```
[产品]@图片N + [展示动作] + [特效] + [音效描述]
```

### 示例

**产品360度展示**
```
图1中的可口可乐饮料,360度高速旋转2圈后,突然停住蓄力分裂成了3个部分进行展示。随后分解后的可口可乐饮料罐的上中下三部分快速向内旋转合成，一罐完整的可口可乐饮料，3D渲染产品展示特效,动感产品特效展示
```

**第一人称体验**
```
第一人称视角，手持咖啡杯缓缓举起，透过蒸汽看到清晨的城市天际线，阳光从建筑间洒落，背景虚化城市灯光，温暖色调，广告级画质
```

**产品替换创意**
```
参考@视频1的广告创意和运镜方式，将产品替换为@图片1的护肤品，保持原视频的慢动作质感和水花飞溅特效，背景音乐参考@音频1
```

## AI漫剧/仙侠

### 核心特点
- 使用首尾帧控制变身/变装效果
- 时间戳分镜法控制每段画面
- 详细的特效描述（法阵、能量波、粒子效果）
- 台词用引号标注，指定语气

### 提示词模板
```
变身/变装首尾帧 + 时间戳分镜 + 特效描述 + 台词标注
```

### 示例

**变身效果**
```
0-3秒：@图片1为首帧，普通少女站在古风房间内，月光透过窗棂
4-8秒：低角度仰拍，法阵在脚下亮起金色光芒，能量波向外扩散，少女衣袂飘动
9-12秒：快速旋转镜头环绕，特效粒子包裹全身，光芒大盛
13-15秒：@图片2为尾帧，少女已变为白狐形态，威严站立，特写面部，眼神冷冽
音效：法阵启动的嗡鸣声，能量爆发声，背景古风配乐
```

**仙侠战斗**
```
仙侠战斗场景，金红暖色调，0-5秒：低角度特写主角拔剑出鞘，剑刃雷光闪烁；6-10秒：环绕快切，主角旋身斩出剑气，敌人被击飞；11-15秒：仰拍慢放，主角收剑伫立，身后敌人碎裂消散
台词（主角，冷峻）："此剑一出，尔等皆灰飞烟灭"
```

## 短剧/对白

### 核心特点
- 画面+台词分开描述，台词标注角色和情绪
- 音效单独描述
- 精准时长控制
- 可指定旁白

### 提示词模板
```
画面（X-X秒）：[画面描述]
台词N（角色，情绪）：[台词内容]
音效：[音效描述]
```

### 示例

```
画面（0-5秒）：特写女主撕契约镜头，纸屑飘落，总裁单膝跪地伸手阻拦，眼神慌乱，女主侧身躲开，嘴角挂着冷漠笑意
台词1（总裁，卑微慌乱）：苏晚！契约还没结束，你不能走！我给你钱，给你地位！
画面（6-10秒）：女主抬脚避开他的手，将撕碎的契约纸扔在他脸上，镜头扫过周围宾客的窃窃私语
台词2（女主，冷漠反杀）：契约？顾总，当初是你说，我连给你提鞋都不配，现在求我？晚了！
画面（11-15秒）：总裁僵在原地，脸上沾着纸屑，女主转身昂首离开，红裙裙摆飘动
音效：华丽又带张力的背景音，契约撕碎的声响，宾客轻微的窃窃私语声
```

## MV/音乐卡点

### 核心特点
- 指定画幅比（2.35:1）和帧率（24fps）
- 分镜头描述每个镜头的场景、动作、音效
- 强调声音设计与节拍同步
- 多图卡点参考视频节奏

### 提示词模板
```
画幅比 + 帧率 + @图片N + 参考@音频1节奏 + 分镜描述
```

### 示例

```
2.35:1宽银幕，24fps，15秒MV，@图片1@图片2@图片3@图片4@图片5@图片6@图片7根据@音频1的画面关键帧位置和整体节奏进行卡点，画面中的人物更有动感，整体画面风格更梦幻，画面张力强，可根据音乐及画面需求自行改变参考图的景别，及补充画面的光影变化
```

**分镜版**
```
15秒音乐MV，2.35:1，24fps，赛博朋克霓虹风格
0-3秒：@图片1为主角开场，固定镜头特写，雨夜霓虹灯闪烁，鼓点落下时切入
4-7秒：@图片2切换，环绕推镜头跟随主角走进酒吧，节拍同步
8-11秒：@图片3@图片4交叉快切，主角在舞池中起舞，灯光变幻
12-15秒：@图片5结尾，缓推特写主角侧脸，灯光渐暗定格
背景音乐参考@音频1
```

## 通用时长建议

| 场景类型 | 推荐时长 | 分镜数量 |
|----------|----------|----------|
| 产品展示 | 4-8秒 | 1-2个镜头 |
| 简短特效 | 6-10秒 | 2-3个镜头 |
| 完整短场景 | 9-12秒 | 3个镜头 |
| 有对白的剧情 | 12-15秒 | 4-5个镜头 |
| 完整MV片段 | 15秒 | 4-6个镜头 |
