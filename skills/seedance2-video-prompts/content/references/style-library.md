## 组合示例

### 电影级广告
```
2.35:1宽银幕，24fps，高饱和暖色调，商业广告大片质感，自然光+侧逆光
```

### 赛博朋克MV
```
赛博朋克霓虹，低饱和冷色调，霓虹灯光斑斓，电影感，慢动作，升格拍摄
```

### 中国风仙侠
```
中国风水墨，暖色调，烟雾缭绕，体积光，电影质感，胶片颗粒
```

### 美食纪录片
```
4K高清晰度，自然采光，浅景深，微距特写，慢动作，暖色调
```

### 科技产品展示
```
HDR，精细CGI，蓝白冷色调，高对比度，浅景深，环绕拍摄
```
