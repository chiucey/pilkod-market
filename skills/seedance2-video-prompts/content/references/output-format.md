# 完整输出格式规范

## 简单模式

直接输出可复制使用的提示词，附带简要的素材准备建议。

适用场景：用户目标明确，≤15秒

```
## 视频提示词

**主题**：[一句话概括]
**时长**：[X秒]
**比例**：[16:9 / 9:16 / 1:1]

### 提示词

[完整提示词，直接包含@图片、@视频、@音频引用]

### 素材建议

- @图片1：[用途说明]
- @图片2：[用途说明]
- @视频1：[用途说明]
```

---

## 完整模式

生成2-3个不同风格版本供选择。

适用场景：需要探索创意方向，≤15秒

```
## 视频提示词

**主题**：[一句话概括]
**时长**：[X秒]
**比例**：[16:9 / 9:16 / 1:1]

### 公共参考素材（如有）

- @图片编号 用途说明
  - 图片生成提示词：[中文描述]

---

### 版本一：[版本标题]

#### 提示词

[完整提示词，直接包含@图片、@视频、@音频引用]

#### 参考素材

**首帧图片 @图片N**
- 画面描述：[与提示词开头画面一致]
- 图片生成提示词：[中文，风格与主题匹配]

**尾帧图片 @图片N**（如需要）
- 画面描述：[与提示词结尾画面一致]
- 图片生成提示词：[中文]

---

### 版本二：[版本标题]

[结构同版本一，所有内容独立匹配本版本]

---

### 提示词解析

[各版本设计意图差异]
```

---

## @引用编号分配规则

1. **公共素材**使用固定编号：角色参考图从 @图片1 开始依次编号，参考视频用 @视频1，参考音频用 @音频1
2. **版本独立素材**（首帧、尾帧、场景参考）每个版本使用独立编号，在公共素材编号之后依次递增
3. 在每个素材标题后标注对应的 @图片编号，方便用户对照上传

## 超长模式（>15秒）

使用「超长视频分段拼接策略」的输出格式，每段包含独立提示词和衔接点描述。

详见 [long-video-strategy.md](./long-video-strategy.md)

## 首帧/尾帧图片生成提示词规范

每个首帧/尾帧图片必须提供：
1. **画面描述**：与视频提示词中的对应画面一致
2. **图片生成提示词**：中文描述，包含风格设定

### 图片风格自动匹配

| 主题类型 | 推荐图片风格 |
|----------|-------------|
| 仙侠/修真 | 3D国漫渲染风格、中国仙侠概念设计风格 |
| 古风/历史 | 中国风工笔画、水墨画、古典绘画风格 |
| 赛博朋克/科幻 | 未来科幻写实CG风格、概念设计风格 |
| 现实/人物 | 电影摄影写实风格、人像摄影风格 |
| 美食 | 美食广告摄影风格、商业摄影风格 |
| 自然风光 | 风光摄影风格、航拍纪录片风格 |
| 动漫 | 对应动漫的美术风格（如日漫赛璐璐、国漫3D渲染等） |

## 微调优化指引

用户选定版本后，可要求：

| 微调类型 | 操作示例 |
|----------|----------|
| 调整画面内容 | "第3秒的动作改成挥拳，不要抬腿" |
| 更换风格 | "整体改成赛博朋克风格，冷色调" |
| 更换镜头 | "把环绕镜头改成推拉镜头" |
| 增减台词 | "加入一句男主的台词：'你终于来了'" |
| 增减音效 | "加入风声和远处的狼嚎" |
| 调整时长 | "把时长改成10秒，重点保留战斗高潮" |
