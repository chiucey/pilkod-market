# 镜头语言词汇库

## 景别

| 类别 | 关键词 | 说明 |
|------|--------|------|
| 极远景 | 大远景 | 用于展示宏大场景、交代环境 |
| 远景 | 远景 | 人物全身，展现人与环境关系 |
| 全景 | 全景 | 人物全身，保留一定环境空间 |
| 中景 | 中景、中近景 | 膝盖以上，利于表现动作 |
| 近景 | 近景 | 腰部以上，利于表现神态 |
| 特写 | 特写、大特写 | 面部或局部细节，强调情绪 |
| 极端特写 | 局部特写 | 眼睛、手、道具等细节 |

---

## 运镜方式

| 类别 | 关键词 | 说明 |
|------|--------|------|
| 推进 | 推镜头、推进 | 从远到近，强化注意 |
| 拉远 | 拉镜头、拉远 | 从近到远，交代环境 |
| 水平转动 | 摇镜头、摇 | 镜头固定，水平转动 |
| 垂直转动 | 俯仰 | 镜头固定，上下转动 |
| 水平移动 | 移镜头、横移 | 摄像机移动拍摄 |
| 跟随移动 | 跟拍、跟镜头 | 跟随主体移动 |
| 环绕 | 环绕拍摄、环绕镜头 | 围绕主体旋转 |
| 航拍 | 航拍、航拍镜头 | 从上方俯拍大场景 |
| 手持 | 手持跟拍 | 晃动效果，增加真实感 |
| 特殊 | 希区柯克变焦 | 推进同时拉远，制造恐惧感 |

---

## 拍摄角度

| 类别 | 关键词 | 说明 |
|------|--------|------|
| 水平视角 | 平视 | 与主体视线齐平 |
| 俯视 | 俯拍、鸟瞰视角、俯视 | 从上往下 |
| 仰视 | 仰拍、仰视 | 从下往上，强化威严 |
| 低角度 | 低角度 | 地面视角 |
| 倾斜 | 倾斜镜头 | 制造紧张感 |
| 特殊 | 鱼眼镜头 | 扭曲透视效果 |
| 主观 | 第一人称视角、主观视角 | 以角色视角呈现 |

---

## 节奏控制

| 类别 | 关键词 | 说明 |
|------|--------|------|
| 升格 | 升格拍摄、慢动作 | 慢镜头，强化情绪 |
| 快切 | 快切、快速剪辑 | 节奏紧张 |
| 延时 | 延时摄影 | 时间压缩 |
| 长镜头 | 一镜到底、长镜头 | 连续不间断 |
| 硬切 | 硬切 | 直接切换镜头 |
| 卡点 | 卡点 | 与音乐节拍同步 |

---

## 焦点控制

| 类别 | 关键词 | 说明 |
|------|--------|------|
| 浅焦 | 浅景深、虚化背景 | 突出主体 |
| 深焦 | 深景深 | 前后都清晰 |
| 焦点转移 | 焦点转移 | 焦点从A移到B |
| 选择性对焦 | 选择性对焦 | 特定区域清晰 |

---

## 转场与特效

| 类别 | 关键词 | 说明 |
|------|--------|------|
| 遮挡转场 | 遮挡擦镜转场 | 主体遮挡时切换 |
| 渐变转场 | 无缝渐变转场 | 柔和过渡 |
| 环绕快切 | 环绕摇镜快切 | 动感切换 |
| 定格 | 定格、定格慢放 | 静止画面 |
| 分屏 | 分屏 | 多画面同时呈现 |

---

## 组合示例

### 电影感镜头
```
低角度仰拍，浅景深，环绕摇镜慢放
```

### 紧张追逐
```
手持跟拍，快切，希区柯克变焦
```

### 唯美转场
```
遮挡擦镜转场，焦点转移，浅景深
```

### 动作捕捉
```
升格拍摄，环绕拍摄，选择性对焦
```
