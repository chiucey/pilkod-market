# Prompt 模板库

## 核心模板

### 🎬 视频片段 Prompt 基础模板

```
[Visual Description], flat medical illustration, clean white background,
modern healthcare style, soft pastel colors,
[Animation instruction: smooth zoom in / gentle fade in / subtle transition],
no text, no people, high educational clarity, professional medical design
```

**占位符说明：**
- `[Visual Description]` — 具体场景画面描述，必填
- `[Animation instruction]` — 动画动作指令，见风格指南

## TTS 解说词模板

### 通用开场句

| 场景 | 中文模板 |
|------|---------|
| Hook | "你知道吗？[惊人数据/事实]，这关系到你我的健康。" |
| 引出话题 | "今天我们来聊聊[主题]，它影响着很多人。" |
| 引入问题 | "如果出现这几个症状，你可能需要注意了。" |

### 通用过渡句

| 场景 | 中文模板 |
|------|---------|
| 进入核心 | "那么，它到底是怎么发生的呢？" |
| 解释机制 | "让我们把复杂的过程，简单说清楚。" |
| 展示数据 | "这几个数字，关键时刻能救命。" |
| 转折 | "但好消息是，它完全可防可治。" |

### 通用收尾句

| 场景 | 中文模板 |
|------|---------|
| 总结 | "总结一下：记住这三点，健康由你掌控。" |
| 行动号召 | "从今天开始，做这一件事就够了。" |
| 感谢 | "感谢观看，记得关注我们，了解更多医学科普！" |

## 字数与时长对照

| 时长 | 解说词字数 | 示例 |
|------|-----------|------|
| 6 秒 | 28~42 字 | "你知道吗？全球每3秒就新增一位老年痴呆患者。"（30字） |
| 10 秒 | 48~72 字 | "根据最新研究，只要每天坚持快走三十分钟，就能显著降低认知衰退风险超过40%。"（42字） |

> **Tip**：中文TTS正常语速约 4~5 字/秒。6秒片段建议30~35字，留意不要超过40字。
