# 多平台内容适配指南

## 平台特性速查表

### 抖音平台规范

#### 用户画像
- **核心用户**：18-35岁，Z世代占比高
- **内容偏好**：娱乐化、节奏快、反转强、新奇有趣
- **使用场景**：碎片时间、通勤、睡前
- **互动特点**：点赞即认可，评论多玩梗

#### 内容规范
| 维度 | 规范要求 |
|------|----------|
| 时长 | 15秒-3分钟，1分钟以内最佳 |
| 比例 | 9:16竖版，1080x1920 |
| 封面 | 高对比度，人物居中，文字3-5字 |
| BGM | 必须使用热门BGM或原创音乐 |
| 字幕 | 必须有，增强完播率 |
| 水印 | 平台自动添加，无需手动处理 |

#### 爆款要素
```
完播率 > 点赞 > 评论 > 转发 > 收藏
```

- 前3秒必须有"钩子"
- 15秒视频至少2个内容峰值
- 60秒视频至少3个内容峰值
- 结尾必须有互动引导

#### 敏感内容
- 医疗/金融类需资质
- 竞品对比需谨慎
- 未成年人出镜限制
- 酒类/烟草禁止

---

### 视频号平台规范

#### 用户画像
- **核心用户**：30-50岁，社会中坚层
- **内容偏好**：正能量、知识型、情感共鸣、时事热点
- **使用场景**：朋友圈转发、家庭群分享
- **互动特点**：转发即认可，点赞即支持

#### 内容规范
| 维度 | 规范要求 |
|------|----------|
| 时长 | 30秒-10分钟，1-3分钟最佳 |
| 比例 | 16:9横版 或 9:16竖版 |
| 封面 | 温暖色调，场景感强，文字10字内 |
| BGM | 正能量/怀旧/经典为主 |
| 字幕 | 建议添加，便于中老年观看 |
| 信任背书 | 可添加官方/专业认证标识 |

#### 爆款要素
```
情感共鸣 > 转发 > 点赞 > 评论
```

- 情感触动是核心
- 叙事完整性很重要
- 需要"值得转发"的理由
- 结尾强化主题/价值观

#### 传播路径
- 私域（朋友圈/微信群）为主
- 公域（推荐）辅助
- 社交关系链传播
- 适合中老年群体触达

---

### 小红书平台规范

#### 用户画像
- **核心用户**：18-35岁都市女性
- **内容偏好**：精致生活、真实分享、干货教程、种草拔草
- **使用场景**：主动搜索、有目的浏览
- **互动特点**：收藏=有用，评论=想交流

#### 内容规范
| 维度 | 规范要求 |
|------|----------|
| 笔记字数 | 500-1500字为佳 |
| 图片数量 | 3-9张，必需首图吸睛 |
| 封面 | 精致文艺、留白、emoji点缀 |
| 标题 | 20字内，关键词前置，emoji可加分 |
| 正文结构 | 开头Hook→正文→结尾CTA |
| 标签 | 1个主话题+3-5个细分话题 |

#### 爆款要素
```
收藏率 > 评论率 > 点赞率
```

- 封面美学是流量密码
- "真实感"是核心竞争力
- 利他价值必须明确
- 评论区运营很重要

#### 封面设计指南
| 类型 | 风格特点 | 适用场景 |
|------|----------|----------|
| 对比型 | Before/After | 护肤/减肥/装修 |
| 清单型 | 数字+利他 | 干货/教程/合集 |
| 氛围型 | 高颜值/场景感 | 探店/好物/旅行 |
| 人物型 | 真人出镜/表情夸张 | Vlog/穿搭/美妆 |
| 文字型 | 简洁大字+背景 | 观点/金句/干货 |

## 跨平台内容矩阵

### 一稿多发策略

#### 素材一次采集
```
原始素材采集清单：
├── 主演示视频（多角度）
├── 产品/场景特写镜头
├── 幕后花絮素材
├── 原声配音素材
└── 相关图文资料
```

#### 差异化加工

| 平台 | 时长 | 结构重点 | BGM风格 | 封面风格 |
|------|------|----------|----------|----------|
| 抖音 | 15-60秒 | 前3秒钩子+节奏感 | 热门BGM+卡点 | 冲击感+大字 |
| 视频号 | 60-180秒 | 情感铺垫+完整叙事 | 温情/励志 | 场景感+温暖 |
| 小红书 | 图文/视频 | 干货价值+真实感 | 轻音乐 | 精致+留白 |

## 违规风险防范

### 通用敏感词库
```
极限词：第一/最好/最佳/顶级/极致
绝对词：100%/必须/一定/保证
虚假词：免费/立即/马上（无限制）
违禁词：详见各平台规则
```

### 各平台特殊规则
- **抖音**：医疗/金融需资质；未成年人保护；版权音乐
- **视频号**：微信生态规则；诱导分享限制；外部链接规范
- **小红书**：医疗/美妆功效词；虚假种草；软广标注
