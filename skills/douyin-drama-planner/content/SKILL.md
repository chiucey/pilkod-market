# 🎬 抖音故事演绎 · 短视频策划包

> 从热点 → 选题 → 钩子 → 脚本 → 分镜 → 角色图 → 视频 → BGM，一站式完成。

---

## 何时激活

用户说以下任何一句时激活：
- "出内容" / "做一期视频" / "策划一下"
- "帮我选个题" / "今天发什么" / "有什么热点"
- "写个脚本" / "出分镜" / "短视频全套"
- "热点选题" / "做这期内容"

---

## 核心原则

1. **每期内容都必须有热点来源** — 不能凭空创作
2. **每步完成后必须展示给用户确认** — 再进入下一步
3. **视频提示词必须包含光线和场景亮度说明** — 防止衣服前面发黑
4. **先确认角色风格再出图** — 避免返工

## 工作流程（标准7步）

---

### 第1步：热点搜索 & 选题判断

**执行方式：**
```bash
# 抓抖音热榜
node skills/douyin-hot-trend/scripts/douyin.js hot 20

# 补充搜索（可选）
batch_web_search 搜索当天热搜话题
```

**选题判断框架（我填写）：**

```markdown
## 热点洞察报告

### 热榜TOP3分析

**热点A：[标题]**
- 热度：XXX
- 为什么爆：情绪共鸣/视觉冲击/名人效应/季节因素
- 适合内容形式：剧情/变装/舞蹈/口播/故事演绎
- 蹭的角度：你的古风美女角色 × 这个热点 = [具体切入角度]
- 风险评估：有无版权/IP问题

**推荐选题（给出我的选择及理由）：**
```

**判断标准（可蹭的热点）：**
- ✅ 情绪共鸣强（委屈/逆袭/被冤枉）
- ✅ 有视觉呈现空间（古风美人能演绎）
- ✅ 无版权/IP风险
- ❌ 已爆剧改编（白日提灯类）— 已被抖音扣分，禁止
- ❌ 政治/社会敏感话题

---

### 第2步：开场钩子设计（3条）

**爆款开场公式（三种类型，根据热点选择）：**

**公式A — 悬念留白型：**
```
“她等了三年，终于等到了这一天..."
画面：第一帧，大表情 or 视觉冲击
```

**公式B — 反差冲击型：**
```
"你以为我只是一个普通的宫女？"
画面：转身后华服/身份出现
```

**公式C — 情绪爆发型：**
```
配乐前3秒无声 → 第4秒高潮音乐起
画面：大表情 or 动作爆发
```

**输出格式：**
```markdown
## 开场钩子（3条）

1. 【悬念型】「她等了三年...」
2. 【反差型】「你以为我只是...」
3. 【情绪型」前3秒无声，第4秒爆发

推荐：选第X条，理由：XXXX
```

```markdown
## 视频脚本

**时长：** 30秒
**形式：** 古风美女故事演绎

### 镜头语言说明

- 中间：情绪铺垫，动作描写简洁

### 时间轴

| 时间 | 画面 | 旁白/台词 | 音乐/音效 |

| 0-3s | [开场画面描述] | [台词或无声] | 前奏/留白 |
| 3-15s | [核心画面] | [台词] | BGM高潮段 |
| 15-30s | [结尾画面] | [收尾句/无台词] | 音乐渐弱 |

### 台词示例（供参考）
[开场钩子引用]

```

### 第4步：分镜设计（必须3段式）

```markdown
## 分镜设计

### 分镜1：出场（0-3秒）
- **画面描述**：[具体描述角色出现的第一个镜头]
- **运镜**：[正面/侧面/背影] [推/拉/摇/固定]
- **光线**：[正面柔和光/侧光/逆光] — **必须写明正面光，避免衣服正面发黑**
- **场景亮度**：[明亮/中等/暗调但有光斑点缀]
- **面部保护**：面部清晰，不被遮挡

### 分镜2：核心动作（3-15秒）
- **动作**：每次只写1个动作
- **运镜**：[全身镜头/面部特写/跟踪拍摄]
- **光线**：正面柔和光补充
- **面部保护**：全程面部清晰可见

### 分镜3：结尾（15-30秒）
- **画面**：定格pose / 回眸 / 微笑
- **运镜**：缓慢拉远 or 固定特写
- **情绪留白**：留出评论空间

---

### 视频提示词要素确认单（必须逐项确认）

| # | 要素 | 说明 | 状态 |
|---|------|------|------|
| 1 | 人物位置 | 正面/侧面/背影 |  |
| 2 | 服装色调 | 深色还是浅色？浅色服装必须正面补光 |  |
| 3 | 背景亮度 | 不能太暗，否则浅色服装会发黑 |  |
| 4 | 光线方向 | 正面柔和光 = 衣服保持明亮的关键 |  |
| 5 | 动作描写 | 每次只写1个动作 |  |
| 6 | 面部保护 | 全程"面部清晰，不被遮挡" |  |
| 7 | 环境点缀 | 金色光斑/灯笼光斑，避免全黑压抑 |  |
| 8 | 色调倾向 | 冷/暖/黑白对比？ |  |

**⚠️ 重要提醒（每次必读）：**
- 浅色/白色服装 + 暗夜背景 = AI自动压暗衣服正面
- 解决方法：提示词必须写"正面柔和光"或"soft front lighting"
- 背景点缀金色光斑，避免全黑压抑
```

### 第5步：角色图生成

**执行前必须确认：**
- 用户是否已有角色图？
- 没有 → 按用户审美画像生成新图
- 有 → 确认图片是否需要调整

**用户审美画像（从历史图片分析中提取）：**
```markdown
## 用户审美画像

### 面部（最核心）
- 脸型：古典东方鹅蛋脸，柔和下颌线
- 眼睛：浅色瞳孔（浅褐/浅蓝绿/琥珀色）→ 空灵仙气感
- 眼神：内敛沉静，微微低头，若有所思
- 表情：克制，微微淡笑或不笑，有"非人间"距离感
- 皮肤：瓷感/玉感，肤如凝脂，白皙通透

### 气质
- 清冷仙气，大家闺秀，不食人间烟火

### 服装
- 国风汉服/仙侠风，轻盈薄纱，精致刺绣
- ❌ 不要：现代OL风/日常穿搭

### 配色
- 清新淡雅，莫兰迪/国风色系，冷色调为主

### 光影
- 柔和月光/轮廓光，逆光打造发丝光晕

### 渲染
- 3D国风CG，虚幻引擎/Ocane Render，电影级质感

### 负面清单
- 深色瞳孔、过于日常表情、浓妆、欧式审美
- 肤色偏深/偏黑（必须白皙通透）
- 西式脸/混血脸（必须典型东方鹅蛋脸）
```

**生成后：**
- 展示角色图给用户
- 用户确认满意 → 进入下一步
- 不满意 → 记录反馈，重新生成

---

### 第6步：生成视频片段

**视频生成规则：**
- 每段视频只含 **1个动作 + 1种运镜**
- 复杂内容分段出 → 剪映拼接

**提示词模板：**
```
[分镜描述]，面部始终清晰，不被遮挡，
正面柔和光打亮全身，正面soft front lighting，
[动作描写，单一简洁]，
[光线/光斑描写]，
[渲染风格]，
[时长]秒
```

**生成后：**
- 检查是否有以下问题：
  - 衣服正面发黑 → 加"正面柔和光"重新出
  - 面部被遮挡 → 加"面部清晰不被遮挡"重新出
  - 动作断/手糊 → 简化动作词，重新出

---

### 第7步：后期合成 & BGM

**BGM生成提示词模板：**
```
[风格]古风[情绪]音乐，[乐器]为主旋律，[情绪描述]，
适合[场景类型]，[节奏描述]，[其他描述]
```

**字幕：**
- 用 ffmpeg 生成SRT字幕文件
- 字幕样式：居中，白色字体，黑色描边

## 抖音内容策划手册（内置知识）

### 爆款底层逻辑（2026年4月更新）

```
关键指标权重：完播率 > 转发率 > 点赞率 > 评论率 > 转粉率

冷启动原理：
视频发布 → 先推500人
前3秒完播率高 → 进入3000人流量池

结论：前3秒 = 生死线
```

### 爆款视频结构

```
开场1秒：强冲突/悬念/视觉冲击 → 留住人
中间：情绪铺垫，动作描写 → 提高完播
结尾：情绪爆发/反转 → 引发评论
```

### 2026年抖音规则红线

| 雷区 | 后果 |
|------|------|
| AI内容不打标 | 限流 |

| 违禁词（最/一/级/绝对化） | 限流 |
| 品牌logo/未授权BGM | 侵权封号 |

### 选题判断标准

```
热点能不能蹭 =
```

## 进度管理

每个阶段完成后：
1. 展示成果给用户
2. 等待用户确认
3. 用户确认后进入下一阶段
4. 用户不满意 → 记录反馈，修订后重新展示

**6个必须确认节点：**
1. ✅ 热点选题方向
2. ✅ 开场钩子方案
3. ✅ 脚本内容
4. ✅ 分镜提示词（含光线确认）
5. ✅ 角色参考图
6. ✅ 最终视频预览

## 注意事项

1. **每次出视频提示词前**，必须先出"视频提示词要素确认单"，用户逐项确认后再生成
2. **浅色服装 + 暗夜场景**：必须加"正面柔和光"描写，这是最高频的翻车原因
3. **动作要单一**：每次只写1个动作，AI无法处理复杂多动作
4. **面部保护**：全程"面部清晰，不被遮挡"必须写入每条提示词
5. **避免IP蹭热点**：已爆剧改编一律禁止（白日提灯类已有真实扣分案例）
