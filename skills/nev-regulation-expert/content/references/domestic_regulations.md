# 国内乘用车新能源三电及动总法规标准详解

## 一、新能源乘用车产品技术要求

### 1.1 纯电动乘用车技术要求

| 指标 | 要求 | 说明 |
|------|------|------|
| 30分钟最高车速 | ≥100km/h | 确保高速续航能力 |
| 续驶里程 | ≥200km | 工况法续驶里程 |
| 动力电池能量密度 | ≥125Wh/kg | 质量能量密度 |
| 百公里电耗 | 按整备质量分档 | 见下表 |

**百公里电能消耗量目标值（Y）计算公式：**

| 整备质量(m, kg) | 目标值(Y)公式 |
|-----------------|---------------|
| m ≤ 1000 | Y ≤ 0.0112×m + 0.4 |
| 1000 < m ≤ 1600 | Y ≤ 0.0078×m + 3.8 |
| m > 1600 | Y ≤ 0.0048×m + 8.60 |

### 1.2 插电式混合动力乘用车技术要求

| 指标 | 要求 | 说明 |
|------|------|------|
| 纯电动续驶里程 | ≥43km | 等效全电里程 |
| 电量保持模式燃料消耗量 | <限值的60%-65% | 根据整备质量分档 |
| 电量消耗模式电耗 | <纯电目标的125%-130% | 根据整备质量分档 |

**燃料消耗量限值比例：**
- 整备质量 < 2510kg：应小于60%
- 整备质量 ≥ 2510kg：应小于65%

### 1.3 低温性能要求

对按照GB/T 18386.1-2021附录A进行检测的纯电动乘用车：
- 低温里程衰减率 ≤ 35%
- 电池系统能量密度 ≥ 95Wh/kg
- 续驶里程 ≥ 120km

## 二、动力电池安全标准（GB 38031-2020）

### 2.1 适用范围
- 电动汽车用动力蓄电池
- 单体、模块、电池包/系统

### 2.2 核心安全要求

#### 机械安全
- 振动试验
- 机械冲击试验
- 碰撞试验

#### 环境安全
- 温度循环试验
- 盐雾试验
- 湿热循环试验

#### 电气安全
- 绝缘电阻试验
- 耐电压试验
- 外部短路试验

#### 热安全
- 加热试验
- 热失控试验
- 热扩散试验

### 2.3 热失控防护要求（2026年起强制）

根据工业和信息化部要求：
- 电池包或系统发生热失控时，应通过预警装置向乘客发出警告
- 电池单体发生热失控后5分钟内，电池系统不起火、不爆炸
- 需通过热失控触发试验验证

## 三、驱动电机系统标准

### 3.1 效率要求（GB/T 36988-2018）

| 工作点 | 永磁同步电机效率 | 异步电机效率 |
|--------|------------------|--------------|
| 峰值效率 | ≥96% | ≥94% |
| 高效区（≥80%） | 功率占比≥85% | 功率占比≥80% |

### 3.2 功率密度要求

| 类型 | 峰值功率密度 | 连续功率密度 |
|------|--------------|--------------|
| 乘用车驱动电机 | ≥2.5kW/kg | ≥1.0kW/kg |

### 3.3 可靠性要求
- 工作温度范围：-40℃ ~ +125℃（绕组）
- 防护等级：不低于IP67
- 寿命要求：≥15年或30万公里

## 五、双积分管理办法

### 5.1 乘用车企业平均燃料消耗量积分（CAFC）

**计算公式：**
```
CAFC积分 = (目标燃料消耗量 - 实际燃料消耗量) × 年度生产/进口量
```

**正积分：** 可结转、关联企业转让
**负积分：** 必须抵偿（关联企业转让、新能源正积分购买）

### 5.2 新能源汽车积分（NEV）

**积分计算：**
```
NEV积分 = 标准车型积分 × 车型数量 × 核算系数
```

| 纯电动续驶里程R | 标准积分 |
|-----------------|----------|
| 100km ≤ R < 150km | 1.0 |
| 150km ≤ R < 200km | 2.0 |
| 200km ≤ R < 300km | 3.0 |
| 300km ≤ R < 400km | 4.0 |
| R ≥ 400km | 5.0 |

**插电式混合动力车型：** 固定1.6分（2024年起）
**燃料电池车型：** 固定4.0分

### 5.3 比例要求

| 年度 | NEV积分比例要求 |
|------|-----------------|
| 2021年 | 14% |
| 2022年 | 16% |
| 2023年 | 18% |
| 2024年 | 22% |
| 2025年 | 28% |
| 2026年及以后 | 38%（预计） |

## 七、新能源汽车安全监管

### 7.1 远程监控要求

依据GB/T 32960：
- 需接入新能源汽车国家监测平台
- 实时上传数据：电池、电机、温度、位置等
- 数据保存期限：不少于3年

### 7.2 缺陷产品召回

依据《缺陷汽车产品召回管理条例》：
- 动力电池、电机等关键部件纳入召回范围
- 存在安全风险时应主动召回
- 监管部门可责令召回

### 7.3 三电系统纳入年检（2025年3月起）

根据《新能源汽车运行安全性能检验规程》（GB/T 43220-2023）：
- 动力电池：充放电温度、SOC、容量保持率
- 驱动电机：温度、旋变信号
- 电气安全：绝缘电阻

## 八、动力电池回收利用

### 8.1 溯源管理

依据《新能源汽车动力蓄电池回收利用管理暂行办法》：
- 实行"新能源汽车国家监测与动力蓄电池回收利用溯源综合管理平台"管理
- 编码要求：单体、模块、电池包编码
- 全生命周期追溯

### 8.2 回收责任

| 企业类型 | 责任 |
|----------|------|
| 汽车生产企业 | 回收主体责任 |
| 动力电池生产企业 | 按规定提供拆解技术信息 |
| 梯次利用企业 | 符合相关技术规范 |
| 再生利用企业 | 符合环保要求 |

### 8.3 回收率要求

| 类型 | 要求 |
|------|------|
| 梯次利用 | 优先梯次利用 |
| 再生利用 | 锂回收率 ≥ 90% |
| 镍、钴、锰回收率 | ≥ 98% |

## 九、轻量化要求

### 9.1 与能耗的关联

车辆整备质量直接影响：
- 百公里电耗/油耗目标值
- 实际电耗/油耗
- 积分核算

### 9.2 轻量化技术路线

| 技术方向 | 应用部位 | 减重效果 |
|----------|----------|----------|
| 高强度钢 | 车身结构 | 10-20% |
| 铝合金 | 电池壳体、悬挂 | 15-30% |
| 碳纤维 | 车身覆盖件 | 30-50% |
| 复合材料 | 结构件 | 20-40% |
