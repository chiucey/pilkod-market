# 国际乘用车新能源及动总法规标准详解

## 一、欧盟法规体系

### 1.1 欧盟碳排放法规（EU 2023/851）

#### 核心目标

| 年度 | CO₂排放目标 | 说明 |
|------|-------------|------|
| 2021-2024年 | 95g/km | 第一阶段目标 |
| 2025-2029年 | 93.6g/km | 较2021年下降15% |
| 2030-2034年 | 49.5g/km | 较2021年下降55% |
| 2035年起 | 0g/km | 零排放目标 |

#### WLTP工况要求
- 测试工况：全球统一轻型汽车测试规程（WLTP）
- CO₂排放目标值基于WLTP循环测试
- 2025年目标：93.6g/km（WLTP工况）

#### 罚款机制
```
罚款 = (实际排放 - 目标排放) × 95欧元/克/辆 × 销量
```

#### 零排放和低排放车辆（ZLEV）激励机制
- ZLEV定义：CO₂排放 < 50g/km
- 超过基准比例（25%）的销量可获额外积分
- 积分可用于平滑达标

### 1.2 欧盟2035年禁燃令

#### 主要内容
- 2035年起，新注册的乘用车和轻型商用车CO₂排放必须为0
- 等同于禁售传统燃油车
- 允许混合动力车型（排放<50g/km）过渡

#### 政策调整（2024年）
- 允许2025-2027年平均排放达标
- 非单一年度考核
- 2030年起继续收紧至49.5g/km

### 1.3 欧盟REPowerEU计划

#### 目标
- 2030年实现减排55%（较1990年）
- 2050年实现气候中和

#### 电动汽车相关
- 充电基础设施部署目标
- 可再生能源电力要求
- 电池可持续性要求

## 二、美国法规体系

### 2.1 EPA排放标准

#### 乘用车温室气体（GHG）排放标准

| 车型年份 | 车队平均CO₂排放目标 (g/mi) |
|----------|---------------------------|
| 2024年 | 161-179 |
| 2025年 | 144-161 |
| 2026年 | 124-145 |

注：1英里(约1.6km)，数据为轿车标准

#### 州级标准——加州ZEV法规

加州空气资源委员会（CARB）ZEV法规：
- ZEV销售比例要求逐步提升
- 2035年实现100%零排放
- 已被其他14个州采纳

### 2.2 CAFE（企业平均燃油经济性）标准

#### 联邦CAFE标准（特朗普政府调整）

| 类型 | 调整内容 |
|------|----------|
| 轻型卡车 | 2026-2032年增速放缓至2%/年 |
| 轿车 | 保持1.5%/年增速 |
| 撤销奥巴马政府严格标准 | 2021年SAFE规则 |

#### 政策特点
- CAFE积分可跨年度使用
- 罚则：每0.1MPG不足罚款约14美元/辆
- 电动化车型积分优惠

### 2.3 FMVSS安全标准

#### FMVSS 305a（电动汽车安全）

2025年2月发布的新标准：
- 碰撞后电池电解液泄漏要求
- 电气安全保护要求
- 推进电池性能要求

| 要求 | 生效日期 |
|------|----------|
| 应急响应文件 | 2025年12月22日 |
| 轻型车辆合规 | 2027年9月1日 |
| 重型车辆合规 | 2028年9月1日 |

## 三、日本法规体系

### 3.1 燃料消耗量标准

#### 测试工况
- JC08工况（部分替代10-15工况）
- WLTP工况逐步引入

#### 2025年目标

| 车型 | 燃料消耗量目标 |
|------|---------------|
| 汽油车 | ≤5.0L/100km |
| 混合动力 | ≤3.9L/100km |
| 电动汽车 | 耗电≤12.9kWh/100km |

#### 2030年目标
- 平均CO₂排放较2020年减少32%
- 2035年实现新车销售100%电动化

### 3.2 日本车辆排放标准

#### 碳排放目标值

| 年度 | 目标 |
|------|------|
| 2020年 | 122g/km |
| 2030年 | 73.7g/km（较2020年减39.5%） |

## 五、全球技术法规（GTR）

### 5.1 UN R136（电动汽车安全）

全球统一的安全技术法规：
- 电动汽车碰撞后电气安全
- 电池热失控防护
- 充电安全

### 5.2 UN R154/WLTP

统一测试规程：
- 全球统一轻型汽车测试程序
- 消除NEDC与实际行驶差异
- 提高排放测试准确性

### 5.3 GTR 13（氢燃料电池车辆）

氢燃料电池汽车全球技术法规：
- 氢安全
- 碰撞安全
- 储氢系统
