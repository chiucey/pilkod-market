# 新能源三电及动总技术方案合规性检查清单

## 一、动力电池系统合规检查

### 1.1 产品技术要求符合性

| 检查项 | 标准要求 | 检查方法 | 判定 |
|--------|----------|----------|------|
| 能量密度 | ≥125Wh/kg | 型式认证报告 | 必须满足 |
| 低温性能 | 衰减率≤35% | GB/T 18386.1附录A | 可选满足 |
| 安全性 | GB 38031 | 型式试验 | 必须通过 |
| 溯源编码 | 符合GB/T 34014 | 编码规则核查 | 必须满足 |

### 1.2 安全标准符合性（GB 38031-2020）

| 试验项目 | 要求 | 合格判定 |
|----------|------|----------|
| 振动试验 | 加速振动后无泄漏、起火 | 通过/不通过 |
| 机械冲击 | 冲击后无泄漏、起火 | 通过/不通过 |
| 碰撞试验 | 碰撞后无泄漏、起火 | 通过/不通过 |
| 温度循环 | 循环后无泄漏、起火 | 通过/不通过 |
| 盐雾试验 | 试验后绝缘正常 | 通过/不通过 |
| 外部短路 | 短路后无起火、爆炸 | 通过/不通过 |
| 加热试验 | 加热至热失控 | 无起火爆炸 | 通过/不通过 |
| 热失控 | 5分钟内不起火爆炸 | 强制要求 | 通过/不通过 |

### 1.3 热失控防护检查（2026年起强制）

| 检查项 | 要求 | 验证方式 |
|--------|------|----------|
| 热失控预警 | 提前发出警告信号 | 功能测试 |
| 5分钟不起火 | 热失控后5分钟内不起火不爆炸 | 试验验证 |
| 乘员保护 | 提供逃生时间 | 设计评估 |

### 1.4 电池管理系统（BMS）检查

| 功能项 | 要求 | 检查内容 |
|--------|------|----------|
| SOC估算 | 精度±10% | 工况测试 |
| 温度管理 | 过温保护 | 功能验证 |
| 电压管理 | 均衡功能 | 功能验证 |
| 通信功能 | 与整车通信正常 | 通信测试 |
| 故障诊断 | 故障码存储 | 功能验证 |

## 三、整车性能合规检查

### 3.1 纯电动乘用车

| 检查项 | 标准要求 | 典型值检查 |
|--------|----------|-----------|
| 最高车速 | ≥100km/h（30分钟） | 型式试验 |
| 续驶里程 | ≥200km | 工况法测试 |
| 电池能量密度 | ≥125Wh/kg | 型式试验 |
| 百公里电耗 | 满足公式限值 | 工况测试 |

**百公里电耗限值公式：**
```
m ≤ 1000: Y ≤ 0.0112×m + 0.4
1000 < m ≤ 1600: Y ≤ 0.0078×m + 3.8
m > 1600: Y ≤ 0.0048×m + 8.60
```

### 3.2 插电式混合动力乘用车

| 检查项 | 标准要求 | 检查方式 |
|--------|----------|----------|
| 纯电续驶里程 | ≥43km | 工况法测试 |
| 燃料消耗量 | <限值60%/65% | B状态测试 |
| 电耗 | <纯电目标125%/130% | A状态测试 |

### 3.3 动力性检查

| 指标 | 要求 | 说明 |
|------|------|------|
| 0-100km/h加速 | 设计目标 | 型式试验 |
| 最高车速 | ≥120km/h | 型式试验 |
| 爬坡能力 | ≥20%坡度 | 试验验证 |

| ... | ... | ... |
| 2510~2660 | 7.42 | 必须达标 |
| >2660 | 7.72 | 必须达标 |

### 4.2 双积分合规检查

**CAFC积分核算：**
```
CAFC正积分 = (目标值 - 实际值) × 产量
负积分必须当年抵偿
```

**NEV积分核算：**
```
NEV积分 = 标准积分 × 产量 × 核算系数
年度NEV积分比例 ≥ 要求比例
```
