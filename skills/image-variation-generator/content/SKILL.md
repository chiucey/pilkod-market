# 图片关联生成器

根据用户提供的参考图片，使用 AI 生成多张风格、主题或场景相关的关联图片。

## 工作流程

### 步骤 1：分析参考图片

使用 `images_understand` 工具分析参考图片的：
- 主题和内容
- 艺术风格
- 颜色色调
- 主要元素和场景
- 情绪氛围

### 步骤 2：生成关联图片

基于分析结果，使用 `image_synthesize` 工具批量生成5张关联图片：

**重要**：必须先将参考图片下载到本地（`/workspace/reference_image.png`），然后使用本地路径作为 `input_files`。

生成策略示例：
- **场景变换**：同一主题的不同视角/场景
- **元素特写**：图片中某个元素的细节放大
- **氛围延伸**：保持风格但变化光线/天气/时间
- **叙事扩展**：展现故事的前因后果场景

### 步骤 3：输出展示

以卡片形式展示生成的图片，每个卡片包含：
- 图片预览
- 图片描述
- 直接可用的下载链接

## 生成提示词模板

```
[原始风格描述], [新场景/视角/元素], [细节强化], cinematic quality, high detail
```

## 注意事项

- 每次最多生成5张图片（batch 限制）
- 参考图片必须下载到本地后再使用
- 使用中文描述生成偏向中文审美，使用英文描述偏向国际审美
- 保持风格一致性的关键：提取核心视觉元素并在提示词中强调
