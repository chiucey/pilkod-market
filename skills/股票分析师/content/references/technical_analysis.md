# 技术分析参考指南

## K线形态分析

### 底部反转形态

#### 锤子线（Hammer）
- **形态特征**：下影线长度为实体的2-3倍，上影线短或无，下影线越长反转信号越强
- **确认条件**：出现于下降趋势末端，第二天需确认上涨
- **信号强度**：中等偏强
- **应用场景**：短线的潜在买入信号

#### 吞没形态（Engulfing）
- **看涨吞没**：第二根阳线实体完全覆盖第一根阴线实体
- **确认条件**：两实体颜色相反，第二实体量能放大
- **信号强度**：强
- **应用场景**：重要的趋势反转信号

#### 晨星（Morning Star）
- **形态特征**：三根K线组合，第一根大阴，第二根十字星，第三根大阳
- **确认条件**：第三根阳线收盘需深入第一根阴线实体一半以上
- **信号强度**：强
- **应用场景**：中线底部确认

### 顶部反转形态

#### 射击之星（Shooting Star）
- **形态特征**：上影线长（至少为实体2倍），下影线短，实体小
- **确认条件**：出现于上升趋势末端，第二天确认下跌
- **信号强度**：中等
- **应用场景**：短线的潜在卖出信号

#### 乌云盖顶（Dark Cloud Cover）
- **形态特征**：第一根大阳后出现高开低走的阴线
- **确认条件**：第二根阴线收盘需深入第一根阳线实体一半以上
- **信号强度**：强
- **应用场景**：重要的顶部反转信号

#### 黄昏星（Evening Star）
- **形态特征**：三根K线组合，与晨星相反
- **确认条件**：第三根阴线收盘需深入第一根阳线实体一半以上
- **信号强度**：强

### 持续形态

#### 三角形整理
- **对称三角形**：高点和低点逐渐收敛
- **上升三角形**：水平上轨+上升下轨，向上突破概率大
- **下降三角形**：水平下轨+下降上轨，向下突破概率大

#### 旗形整理
- **上升旗形**：短暂回调后继续上涨
- **下降旗形**：短暂反弹后继续下跌

## 技术指标分析

### MACD指标

#### 参数设置
- 默认参数：12, 26, 9

#### 信号判断
- **金叉**：DIF线上穿DEA线，看涨信号
- **死叉**：DIF线下穿DEA线，看跌信号
- **零轴**：DIF在零轴上方为多头市场，下方为空头市场
- **背离**：
  - 顶背离：价格创新高但MACD未创新高，看跌
  - 底背离：价格创新低但MACD未创新低，看涨

#### 应用技巧
- 金叉在零轴上方出现，信号更强
- 死叉在零轴下方出现，信号更强
- MACD柱状线收缩往往意味着趋势暂停

### KDJ指标

#### 参数设置
- 默认参数：9, 3, 3

#### 信号判断
- **超买区域**：K、D、J值超过80，市场可能过热
- **超卖区域**：K、D、J值低于20，市场可能超卖
- **金叉**：K线上穿D线
- **死叉**：K线下穿D线

#### 应用技巧
- KD在高位形成死叉且三线发散向下，风险较大
- KD在低位形成金叉且三线发散向上，机会较大
- J值大于100为超买信号，J值小于0为超卖信号

### RSI指标

#### 参数设置
- 常用参数：14

#### 信号判断
- **超买**：RSI超过70，价格可能调整
- **超卖**：RSI低于30，价格可能反弹
- **背离**：与价格走势相反的RSI走势
- **趋势线**：RSI突破趋势线可能预示反转

#### 应用技巧
- 单边市中RSI可能长时间处于超买/超卖区域
- 震荡市中RSI信号更可靠
- 配合成交量使用效果更好

### 布林带（Bollinger Bands）

#### 参数设置
- 默认参数：20, 2（周期，中轨倍数）

#### 信号判断
- **上轨突破**：价格触及上轨，可能继续上涨或回调
- **下轨支撑**：价格触及下轨，可能反弹
- **收口**：布林带收口，酝酿突破
- **开口**：布林带开口，趋势加速

#### 应用技巧
- 配合MACD使用效果更好
- 布林带收口后向上突破概率较高时，往往伴随放量
- 连续触及上轨后回落概率增大

### 均线系统

#### 常用均线
- 短期：5日、10日均线
- 中期：20日、30日均线
- 长期：60日、120日、250日均线

#### 信号判断
- **多头排列**：短期均线在长期均线上方，趋势向上
- **空头排列**：短期均线在长期均线下方，趋势向下
- **均线金叉**：短期均线上穿长期均线，看涨
- **均线死叉**：短期均线下穿长期均线，看跌
- **回踩确认**：均线支撑/压力位确认

## 量价关系

### 放量与缩量标准
- **温和放量**：量能较前期放大30%-50%
- **明显放量**：量能较前期放大1倍以上
- **天量**：历史高位量能水平
- **地量**：历史低位量能水平

### 量价配合
- **量增价涨**：积极信号，需求推动价格上涨
- **量增价跌**：警示信号，可能继续下跌
- **量缩价涨**：需要警惕，可能是虚涨
- **量缩价跌**：可能见底，抛压减少
- **天量天价**：顶部信号概率大
- **地量地价**：底部信号概率大

### 异常量能识别
- **突发放量**：量能异常放大需关注
- **连续放量**：持续量能变化趋势
- **量能背离**：价格与量能走势不一致

## 短线交易信号体系

### 买入信号（满足3项以上可考虑买入）

1. **技术指标信号**
   - [ ] MACD在零轴上方形成金叉
   - [ ] KDJ在20附近形成金叉
   - [ ] RSI低于30后反弹
   - [ ] 股价站上5日均线

2. **K线形态信号**
   - [ ] 出现锤子线、吞没等底部形态
   - [ ] 出现早晨之星形态
   - [ ] 跳空高开且回补缺口后企稳

3. **量价信号**
   - [ ] 放量上涨，量能持续
   - [ ] 突破关键位置时放量
   - [ ] 缩量回调至支撑位

4. **趋势信号**
   - [ ] 均线多头排列
   - [ ] 布林带中轨支撑
   - [ ] 突破下降趋势线

### 卖出信号（满足3项以上需警惕）

1. **技术指标信号**
   - [ ] MACD在零轴下方形成死叉
   - [ ] KDJ在80附近形成死叉
   - [ ] RSI高于70后回落
   - [ ] 股价跌破5日均线

2. **K线形态信号**
   - [ ] 出现射击之星、乌云盖顶形态
   - [ ] 出现黄昏之星形态
   - [ ] 跳空低开

3. **量价信号**
   - [ ] 放量下跌
   - [ ] 天量见天价
   - [ ] 缩量上涨

4. **趋势信号**
   - [ ] 均线空头排列
   - [ ] 跌破布林带中轨
   - [ ] 跌破上升趋势线

## 支撑位与压力位

### 支撑位判断
- **前期低点**：价格回调的低点位置
- **均线支撑**：20日、60日均线附近
- **整数关口**：心理整数价位
- **成交量密集区**：前期成交放量区
- **布林带下轨**：价格波动的下边界

### 压力位判断
- **前期高点**：价格反弹的高点位置
- **均线压力**：20日、60日均线附近
- **整数关口**：心理整数价位
- **历史密集区**：前期成交放量区
- **布林带上轨**：价格波动的上边界

### 支撑压力转换
- 支撑位被跌破后可能变为压力位
- 压力位被突破后可能变为支撑位
- 突破时量能放大可提高突破有效性

## 短线交易纪律

### 止损原则
- **固定止损**：亏损达到5%-8%必须止损
- **技术止损**：跌破关键支撑位即止损
- **时间止损**：持有超过一定时间未达预期即离场

### 止盈原则
- **分批止盈**：高位出现卖出信号时先止盈一半
- **移动止损**：盈利后不断提高止损位
- **目标位止盈**：达到预期涨幅后了结

### 仓位管理
- **单票仓位**：不超过总仓位20%
- **分散持仓**：持有3-5只不同板块股票
- **加仓原则**：盈利加仓，不轻易补仓亏损仓位
- **总仓位**：根据市场环境控制在30%-70%
