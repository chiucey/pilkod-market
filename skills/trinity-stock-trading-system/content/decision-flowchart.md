## 一、选股决策流程

```
[市场环境判断]
        │
        ▼
┌───────────────────────────────┐
│  当前趋势是什么？              │
│  □ 上升趋势 → 进入买点筛选    │
│  □ 震荡市 → 寻找突破个股      │
│  □ 下降趋势 → 观望等待        │
└───────────────────────────────┘
        │
        ▼
[板块热点筛选]
        │
        ▼
┌───────────────────────────────┐
│  热点板块是否明确？            │
│  □ 是 → 进入个股筛选          │
│  □ 否 → 等待热点形成          │
└───────────────────────────────┘
        │
        ▼
[技术形态筛选]
        │
        ▼
┌───────────────────────────────┐
│  出现以下哪种突破形态？        │
│  □ 下降楔形突破               │
│  □ 旗形向上突破               │
│  □ 杯柄形态突破               │
│  □ 上升三角形突破             │
│  □ 箱体向上突破               │
│  □ 无明确形态 → 不操作        │
└───────────────────────────────┘
        │
        ▼
[资金确认]
        │
        ▼
┌───────────────────────────────┐
│  资金信号是否确认？           │
│  □ 主力净流入？               │
│  □ 成交量放大？               │
│  □ 两者皆有 → 准备买入         │
│  □ 只有其一 → 谨慎观望        │
│  □ 两者皆无 → 不操作          │
└───────────────────────────────┘
        │
        ▼
[买入决策]
```

## 二、买入决策流程

```
[买点出现]
        │
        ▼
┌───────────────────────────────┐
│  第一买点（首选）              │
│  突破当日收盘前15分钟          │
│  条件：突破确认+量能配合       │
│  仓位：10%-15%                 │
│  状态：□ 满足 → 执行买入       │
│        □ 不满足 → 进入第二买点 │
└───────────────────────────────┘
        │
        ▼
┌───────────────────────────────┐
│  第二买点（次选）              │
│  回踩确认后买入                │
│  条件：回踩不破支撑+缩量止跌   │
│  仓位：5%加仓                  │
│  状态：□ 满足 → 执行买入       │
│        □ 不满足 → 观望        │
└───────────────────────────────┘
        │
        ▼
┌───────────────────────────────┐
│  第三买点（备选）              │
│  再次突破时买入                │
│  条件：盘整缩量+突破放量       │
│  仓位：5%加仓                  │
│  状态：□ 满足 → 执行买入       │
│        □ 不满足 → 不操作      │
└───────────────────────────────┘
        │
        ▼
[执行买入]
        │
        ▼
┌───────────────────────────────┐
│  同时确认以下条件：            │
│  □ 大盘环境支持                │
│  □ 板块效应存在               │
│  □ 止损位明确                 │
│  □ 仓位控制合理               │
└───────────────────────────────┘
```

        ▼

        │
        ▼

│  □ 跌破买入价8%               │
│  → 考虑清仓                  │
└───────────────────────────────┘

        ▼

## 六、市场环境切换流程

```
[当前市场环境]
        │
        ▼
┌───────────────────────────────┐
│  市场环境判断标准：            │
│                                │
│  【上升趋势】                  │
│  □ 股价站稳20日均线            │
│  □ 均线多头排列               │
│  □ 成交量放大                 │
│  → 仓位：80%-100%             │
│                                │
│  【震荡市】                    │
│  □ 股价在均线间波动           │
│  □ 均线纠缠                   │
│  □ 成交量萎缩                 │
│  → 仓位：40%-60%              │
│                                │
│  【下降趋势】                  │
│  □ 股价跌破20日均线            │
│  □ 均线空头排列               │
│  □ 成交量萎缩                 │
│  → 仓位：0%-20%               │
└───────────────────────────────┘
        │
        ▼
[仓位调整]
        │
        ▼
┌───────────────────────────────┐
│  环境变化时的操作：            │
│                                │
│  上升→震荡：                  │
│  → 逐步降低仓位               │
│  → 锁定部分利润               │
│                                │
│  震荡→下降：                  │
│  → 快速降低仓位               │
│  → 保留充足现金               │
│                                │
│  下降→震荡：                  │
│  → 保持轻仓                   │
│  → 等待明确信号               │
│                                │
│  震荡→上升：                  │
│  → 逐步加仓                   │
│  → 布局热点板块               │
└───────────────────────────────┘
```

## 八、交易检查清单

### 买入前检查（必须全部满足）

```
□ 大盘处于上升或震荡趋势
□ 板块处于热点之中
□ 出现明确的突破形态
□ 成交量配合放大
□ 主力资金净流入
□ 止损位明确且合理
□ 仓位控制在计划范围内
□ 基本面无重大利空
```

### 持仓中检查（每日执行）

```
□ 走势是否符合预期
□ 是否触及止损位
□ 是否达到止盈目标
□ 基本面是否有变化
□ 板块是否仍为热点
□ 大盘环境是否变化
```

### 卖出前检查（任一满足即执行）

```
□ 触及止损位
□ 涨幅达到目标位
□ 出现头部形态
□ 放量滞涨
□ 跌破重要均线
□ 基本面出现利空
□ 板块整体退潮
```
