## 二、五大突破形态快速识别

### 形态1：下降楔形突破

```
【识别要点】
✓ 高点不断下降
✓ 低点也不断下降，但速度更慢
✓ 形成收敛的楔形

【买入条件】
□ 价格突破上边趋势线
□ 成交量放大
□ 突破后3日站稳

【止损设置】
- 跌破楔形下沿下方3%

【目标计算】
- 楔形高度 × 1.5～2倍
```

### 形态2：旗形向上突破

```
【识别要点】
✓ 有明显的"旗杆"（急促上涨）
✓ 有平行的"旗面"（小幅回调）

【买入条件】
□ 价格突破旗面上沿
□ 成交量重新放大

【止损设置】
- 跌破旗面下沿下方2%

【目标计算】
- 旗杆高度 = 预期涨幅
```

### 形态3：杯柄形态

```
【识别要点】
✓ U型底部（杯身）
✓ 小幅回撤（杯柄）
✓ 突破在前期高点附近

【买入条件】
□ 价格突破杯柄阻力位
□ 成交量配合放大

【止损设置】
- 跌破杯柄最低点下方5%

【目标计算】
- 杯深度 × 1.5倍涨幅
```

### 形态4：上升三角形突破

```
【识别要点】
✓ 上方水平阻力线
✓ 下方向上倾斜支撑线
✓ 低点不断抬高

【买入条件】
□ 价格突破水平阻力线
□ 成交量放大至近期最高

【止损设置】
- 跌破三角形下沿下方3%

【目标计算】
- 三角形垂直高度
```

### 形态5：箱体向上突破

```
【识别要点】
✓ 上下平行的支撑阻力线
✓ 多次来回震荡
✓ 整理时间较长

【买入条件】
□ 价格站上箱体顶部
□ 成交量 > 平均量能1.5倍
□ 3日内不重回箱体

【止损设置】
- 跌破箱体下沿下方4%

【目标计算】
- 箱体宽度 = 预期涨幅
```

## 三、均线操作速查表

### 葛兰维尔八大法则

```
【买入法则】
法则1：均线走平，股价从下方突破均线 → 买入 ✓
法则2：股价在均线上，回调不破均线 → 买入 ✓
法则3：股价在均线上，回调未触及均线即涨 → 买入 ✓
法则4：股价在均线下方，突然暴跌远离均线 → 买入（抢反弹）✓

【卖出法则】
法则5：股价在均线上方，突然暴涨远离均线 → 卖出 ✓
法则6：均线走平，股价从上方跌破均线 → 卖出 ✓
法则7：股价在均线下方，反弹未能突破均线 → 卖出 ✓
法则8：股价在均线上方，均线下降，股价接近均线 → 卖出 ✓
```

## 四、资金流向判断标准

### KDJ指标应用

```
【J值信号】
J值 > 100：超买，短期回调风险
J值 < 0：超卖，反弹机会

【金叉死叉】
KDJ金叉（K上穿D）：买入信号
KDJ死叉（K下穿D）：卖出信号

【背离信号】
顶背离：价格创新高，KDJ未创新高 → 卖出信号
底背离：价格创新低，KDJ未创新低 → 买入信号
```

### 资金监控指标

```
【净流入标准】
□ 主力净流入 > 1亿元：强势信号
□ 连续3日净流入：持续关注
□ 板块净流入排名前三：热点确认

【量能标准】
□ 成交量较前5日均量放大30%以上：有效放量
□ 突破时量能为前期高量1.5倍以上：强势突破
```

## 五、止损止盈速查

### 止损原则

```
【绝对止损】（必须执行）
□ 单只股票亏损超过15%→ 必须清仓
□ 总资金亏损超过8%→ 必须减仓
□ 跌破重要支撑3日未能收复→ 必须离场

【相对止损】
□ 跌破买入价5%→ 考虑减仓
□ 跌破买入价8%→ 必须清仓
□ 跌破均线支撑有效确认→ 离场
```

### 止盈原则

```
【目标位止盈】
□ 涨幅达到10%→ 可考虑部分止盈
□ 涨幅达到20%→ 建议止盈一半
□ 涨幅达到30%→ 建议清仓

【技术面止盈】
□ 出现明显头部形态（M头、乌云盖顶）
□ 放量滞涨
□ 跌破5日均线
□ 板块整体退潮
```

### 不同市场环境操作

```
【上升趋势】
□ 仓位：80%-100%
□ 操作：以持股为主，回调买入
□ 选股：强势板块龙头
□ 止损：放宽至8%-10%

【震荡市】
□ 仓位：40%-60%
□ 操作：高抛低吸，控制频率
□ 选股：热点轮动个股，快进快出
□ 止损：严格执行5%-8%

【下降趋势】
□ 仓位：0%-20%
□ 操作：以持币为主，空仓等待
□ 选股：不追涨，不抄底
□ 止损：随时准备离场
```

## 七、仓位管理标准

### 总仓位控制

```
【单次最大仓位】
首次建仓：不超过总资金15%
加仓次数：最多2次，每次5%
单只股票最大仓位：总资金20%

【加仓条件】
□ 首次买入后上涨
□ 回踩确认支撑有效
□ 量能再次放大
```

### 分批买入策略

```
【策略1：金字塔买入】
第1次：10%仓位（突破买入）
第2次：5%仓位（回踩确认）
第3次：5%仓位（再次突破）

【策略2：等额买入】
第1次：7%仓位
第2次：7%仓位
第3次：6%仓位
```

## 八、常见错误及避免方法

### 散户常见错误

```
【错误1：追涨杀跌】
表现：股价涨了就追，跌了就卖
后果：反复亏损，割肉不断

【错误2：不止损】
表现：亏损了死扛，不愿认错
后果：小亏变大亏，深套

【错误3：频繁交易】
表现：每天都在买卖，不空仓
后果：交易成本高，收益被侵蚀

【错误4：从众心理】
表现：别人买什么我买什么
后果：接盘在高位，利润有限

【错误5：情绪化交易】
表现：凭感觉操作，不执行计划
后果：计划形同虚设，亏损难免
```

### 避免方法

```
□ 制定交易计划并严格执行
□ 设定止损位并坚决执行
□ 控制交易频率，减少无效操作
□ 独立思考，不盲目跟随
□ 每日复盘，持续改进
```
