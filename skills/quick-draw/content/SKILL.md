# 快速绘画技能

## 触发条件

当用户在对话中：
- 说出一个物品/动物/人物的名称，要求"画出来"、"生成图片"、"画一个"
- 直接要求"画 [任意主题]"
- 使用类似"帮我画这个"、"生成图像"的表达

## 执行流程

### 1. 解析用户意图

识别用户想要绘画的主题：
- 从用户输入中提取核心绘画对象
- 处理中英文混合输入
- 识别复合主题（如"一只可爱的猫咪在花园里"）

### 2. 生成绘画提示词

将用户输入转换为适合图像生成的英文描述：
- 保持主题核心特征
- 添加适当的风格描述（写实、卡通、水彩等）
- 如用户未指定风格，默认使用"插画风格，细节丰富"

### 3. 调用图像生成

使用 `image_synthesize` 工具生成图像：
- 输出文件保存到 `/workspace/imgs/draw_{timestamp}.png`
- 确保图像质量清晰

### 4. 返回结果

向用户展示生成的图像并提供下载链接。

## 示例

| 用户输入 | 生成结果 |
|---------|---------|
| "画一只猫" | 生成猫咪插画 |
| "画埃菲尔铁塔" | 生成埃菲尔铁塔图像 |
| "画一个苹果" | 生成苹果图像 |
| "Draw a dragon" | 生成龙图像 |

## 错误处理

- 如果用户输入过于模糊，询问具体想要画什么
- 如果图像生成失败，提示用户重试或换一种描述方式
