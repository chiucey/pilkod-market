# AI写作去痕工具 (AI Writing Dehumanizer)

## 概述

这是一个强大的AI写作去痕工具，能够识别并消除文本中的AI生成痕迹，将内容改写为更自然、更像人类书写的风格。

## 核心功能

- 识别并修复文本中的 **24种AI写作痕迹**
- 将AI生成的文本改写为自然的人类写作风格
- 提供检测清单和质量评分标准
- 保留原文核心含义，仅消除AI特征

## AI写作模式检测清单

### 📝 内容模式 (6种)

1. **过度强调意义、遗产和更广泛的趋势**
   - 特征：频繁使用"深远意义"、"历史遗产"、"发展趋势"等宏大词汇
   - 示例："这一举措具有深远的历史意义和重要的时代价值"

2. **过度强调知名度和媒体报道**
   - 特征：依赖"众所周知"、"据报道"、"媒体广泛关注"等表述
   - 示例："众所周知，人工智能正在引领新一轮科技革命"

3. **以-ing结尾的肤浅分析**
   - 特征：使用动名词形式进行浅层分析
   - 示例："探讨数字化转型的重要性，深入探讨行业发展趋势"

4. **宣传和广告式语言**
   - 特征：使用夸张的营销语言
   - 示例："突破性创新、革命性解决方案、颠覆性技术"

5. **模糊归因和含糊措辞**
   - 特征：缺乏具体来源或数据的泛泛而谈
   - 示例："研究表明"、"数据显示"、"专家普遍认为"

6. **提纲式的"挑战与未来展望"部分**
   - 特征：机械套用"挑战-机遇-展望"结构
   - 示例："首先...其次...最后...综上所述..."

### 🔤 语言和语法模式 (6种)

7. **过度使用的"AI词汇"**
   - 警示词：此外、至关重要、深入探讨、强调、持久的、增强、培养、获得、突出、相互作用、复杂性、关键性的、展示、宝贵的、充满活力的
   - 示例："此外，这一发现具有至关重要的科学价值"

8. **避免使用"是"(系动词回避)**
   - 特征：刻意使用冗长表达替代简单系动词
   - 示例："该技术可以被描述为具有革命性特征"

9. **否定式排比**
   - 特征：连续使用"不是...而是..."结构
   - 示例："这不是简单的技术迭代，而是深层次的范式转变"

10. **三段式法则过度使用**
    - 特征：滥用"首先...其次...最后..."结构
    - 示例："第一...第二...第三..."

11. **刻意换词(同义词循环)**
    - 特征：同一概念反复使用不同表达
    - 示例："创新/革新/突破/变革" 反复出现

12. **虚假范围**
    - 特征：使用"所有"、"每个"、"全部"等绝对化表述
    - 示例："所有企业都必须拥抱数字化转型"

### 🎨 风格模式 (6种)

13. **破折号过度使用**
    - 特征：一个句子中使用多个破折号
    - 示例："这是一个——从技术层面看——非常重要的——突破"

14. **粗体过度使用**
    - 特征：大量使用加粗文本来强调
    - 格式：`**这是重点**`、`**核心观点**`

15. **内联标题垂直列表**
    - 特征：使用编号列表或项目符号罗列观点
    - 示例：
      ```
      1. 创新性
      2. 实用性
      3. 可扩展性
      ```

16. **标题中的标题大写**
    - 特征：副标题或小标题使用Title Case
    - 示例：`## 研究方法 ## 研究结果 ## 结论`

17. **表情符号**
    - 特征：在正式文本中使用表情符号
    - 示例："这个方案非常棒！👍 让我们开始吧！✨"

18. **弯引号**
    - 特征：使用""代替标准的""

### 💬 交流模式和填充词 (6种)

19. **协作交流痕迹**
    - 特征：AI辅导式的语气
    - 示例："很好！让我们一起探索这个问题"、"你做得很好！"

20. **知识截止日期免责声明**
    - 特征：提及训练数据的时间限制
    - 示例："根据我的训练数据（截止到XX年）..."

21. **谄媚/卑躬屈膝的语气**
    - 特征：过度讨好用户
    - 示例："您提出了一个非常精彩的问题！"

22. **填充短语**
    - 警示短语：值得注意的是、换句话说、本质上、实际上、简而言之、毫无疑问、值得注意的是
    - 示例："值得注意的是，这一发现具有重要意义"

23. **过度限定**
    - 特征：使用过多限定词
    - 示例："在某种程度上、相对而言、可以说、大体上"

24. **通用积极结论**
    - 特征：结尾使用千篇一律的积极语句
    - 示例："让我们携手共创美好未来！"

## 去痕改写规则

### 核心原则

1. **保留核心信息** - 确保原文的主要观点和数据不变
2. **消除AI特征** - 移除所有24种AI写作模式
3. **使用自然表达** - 采用人类日常写作风格
4. **具体而非抽象** - 用具体细节替代泛泛而谈
5. **简洁明了** - 删除冗余的填充词和过渡句

### 改写技巧

| AI写作特征 | 改写方法 |
|-----------|---------|
| 宏大叙事词 | 用具体事实和数据替代 |
| 绝对化表述 | 改为更谨慎的表达 |
| 机械结构 | 采用自然流畅的叙述 |
| 填充短语 | 直接表达核心意思 |
| 过度强调 | 降低语调，平和叙述 |
| 同义循环 | 统一使用最准确的表达 |

## 使用方法

### 基本命令

```
/ai-writing-dehumanizer [需要去痕的文本]
```

### 使用示例

**示例1 - 直接改写：**
```
/ai-writing-dehumanizer 请帮我人性化以下文本：
这个项目作为我们团队致力于创新的证明。此外，它展示了我们在不断演变的技术格局中的关键作用。
```

**改写后：**
> 我们做了这个项目，是团队创新的尝试。项目用了半年时间开发，现在已经上线运行。

**示例2 - 批量处理：**
```
/ai-writing-dehumanizer 请检查并改写这段文章，使其更自然：
[粘贴AI生成的文本内容]
```

**示例3 - 针对性改写：**
```
/ai-writing-dehumanizer 这段话太像AI写的了，帮我改得自然一些：
[粘贴文本]
```

## 评分标准

### AI痕迹指数 (0-100)

| 分数 | 等级 | 描述 |
|-----|------|------|
| 0-20 | 人类写作 | 完全没有AI特征 |
| 21-40 | 轻微AI特征 | 偶尔有不自然的表达 |
| 41-60 | 中度AI特征 | 有明显AI写作模式 |
| 61-80 | 高度AI特征 | 大部分内容有明显AI痕迹 |
| 81-100 | 典型AI生成 | 充满AI写作特征 |

### 评分维度

1. **词汇特征** - 是否使用了AI警示词汇
2. **句式结构** - 是否过度使用机械结构
3. **内容模式** - 是否有宏大叙事和空泛表达
4. **风格元素** - 是否使用了AI特有的格式
5. **语气语调** - 是否过于讨好或机械

## 场景应用

### 场景1：改写营销文案

**原始文本：**
> 坐落在风景如画的杭州市中心，这家咖啡馆拥有丰富的文化底蕴和令人叹为观止的装饰。它作为城市咖啡文化的焦点，为顾客提供无缝、直观和充满活力的体验。

**去痕后：**
> 这家咖啡馆在杭州市中心开了三年，以手冲咖啡和老建筑改造的空间出名。

### 场景2：改写学术摘要

**原始文本：**
> 本研究深入探讨了机器学习在医疗诊断中的关键作用，突出了其在不断演变的医疗格局中的重要性。此外，它为该领域的未来发展奠定了坚实的基础。

**去痕后：**
> 本研究分析了机器学习在医疗诊断中的应用，重点是肺癌早期筛查。研究使用了2019-2023年间5000例病历数据。

### 场景3：改写商务邮件

**原始文本：**
> 非常感谢您抽出宝贵时间阅读我的邮件。我谨代表我们的团队，向您致以最诚挚的问候和最深切的感谢！

**去痕后：**
> 您好！想和您沟通一下项目进展。

## 技术原理

### 处理流程

1. **输入分析** - 接收原始文本
2. **模式扫描** - 对照24种AI模式检测文本
3. **问题标记** - 标识发现的AI特征
4. **智能改写** - 按规则重写问题片段
5. **质量评估** - 计算AI痕迹指数
6. **输出结果** - 返回去痕后的文本

### 核心原则

- 保持原文核心含义不变
- 仅消除AI写作特征
- 采用自然人类表达方式
- 维持适当的语体风格
- 让文字有"人味"

---

## 注意事项

1. **不是作弊工具** - 本工具旨在帮助改进写作风格，不是用于学术造假
2. **保留必要信息** - 原文的核心数据和关键信息应保留
3. **风格适配** - 根据文本类型调整改写程度
4. **人工审核** - 建议对重要文本进行人工校对
