# 品牌商广BRIEF标准模板（大家电行业）

## 技能职责

接收项目基本信息，自动生成标准化的品牌商业广告合作BRIEF文档，用于品牌方与内容创作者/代理之间的合作执行。

## 使用场景

1. **初次对接**：向品牌方索取合作所需信息
2. **项目立项**：生成标准BRIEF作为执行依据
3. **合同附件**：BRIEF作为商务合同的技术附件
4. **项目交接**：确保多方协作信息一致

## 输入格式（可选）

```
品牌名称：[填写]
产品名称：[填写]
合作平台：[抖音/小红书/京东等]
预算区间：[填写]
档期要求：[填写]
```

如无输入，将直接输出完整BRIEF模板供手动填写。

### 文档结构

1. 品牌信息
