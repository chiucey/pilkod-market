# 订单汇总模板规格说明

## 概述

本模板用于汇总采购订单和委外订单的未到货情况，便于供应商跟单管理。

## 数据来源要求

### 采购订单列表
- 文件格式：Excel (.xlsx)
- 必需字段：
  - 供应商名称
  - 订单编号（PO开头）
  - 存货编码
  - 存货名称
  - 规格型号
  - 数量
  - 计划到货日期
  - 承诺到货日期（如有）
  - 要求到货日期
  - 累计到货数量
  - 累计入库数量
  - 预计货期

### 委外订单列表
- 文件格式：Excel (.xlsx)
- 必需字段：
  - 供应商名称
  - 订单编号（纯数字）
  - 存货编码
  - 存货名称
  - 规格型号
  - 数量
  - 计划到货日期
  - 承诺到货日期（如有）
  - 要求到货日期
  - 累计到货数量
  - 累计入库数量
  - 预计货期

## 字段说明

| 字段名 | 说明 | 计算规则 |
|--------|------|----------|
| 订单类型 | 区分采购/委外 | 直接来源于原始数据 |
| 供应商 | 供应商全称 | 原始数据 |
| 订单编号 | 唯一标识 | 原始数据 |
| 存货编码 | 物料编码 | 原始数据 |
| 存货名称 | 物料名称 | 原始数据 |
| 规格型号 | 物料规格 | 原始数据 |
| 数量 | 订购数量 | 原始数据 |
| 累计到货数量 | 已到货数量 | 原始数据 |
| 累计入库数量 | 已入库数量 | 原始数据 |
| 计划到货日期 | 计划交货日 | 原始数据 |
| 承诺到货日期 | 承诺交货日 | 原始数据 |
| 要求到货日期 | 要求交货日 | 优先使用承诺日期，无承诺用计划日期 |
| 到货状态判断 | 当前状态 | 根据要求日期与当前日期计算 |
| 预计货期 | 预计到货时间 | 原始数据或空 |

## 状态计算规则

```
当前日期 = 今日
要求到货日期 = 承诺到货日期(如有) 否则 计划到货日期
天数差 = 要求到货日期 - 当前日期

判断逻辑：
- 天数差 < 0  → 已超期N天
- 天数差 = 0  → 临期(0天)
- 天数差 1-3  → 临期(N天)
- 天数差 4-7  → 近期(N天)
- 天数差 > 7  → 正常(N天)
```

## 工作表结构

### 1. 📖使用说明
- 说明文档和颜色图例
- 静态内容

### 2. ⚠️超期临期需跟进
- 筛选条件：days_diff <= 3
- 列：订单类型、供应商、订单编号、存货编码、存货名称、规格型号、数量、累计到货数量、累计入库数量、计划到货日期、承诺到货日期、要求到货日期、到货状态判断

### 3. 📋全部未到货汇总
- 包含所有未完成订单
- 按days_diff和供应商排序
- 完整列：订单类型、供应商、订单编号、存货编码、存货名称、规格型号、数量、累计到货数量、累计入库数量、计划到货日期、承诺到货日期、要求到货日期、到货状态判断、预计货期

### 4. [供应商名称]工作表
- 每个供应商一个独立工作表
- 工作表名称取供应商名称前10个字符
- 包含该供应商所有订单
- 完整列：订单类型、供应商、订单编号、存货编码、存货名称、规格型号、数量、累计到货数量、累计入库数量、计划到货日期、承诺到货日期、要求到货日期、到货状态判断、预计货期

## 颜色规范

| 状态类型 | 颜色代码 | 填充色 | 说明 |
|----------|----------|--------|------|
| 已超期 | #FF6B6B | 红色 | 需立即处理 |
| 临期 | #FFA94D | 橙色 | 3天内需关注 |
| 近期 | #FFE066 | 黄色 | 7天内需关注 |
| 正常 | #69DB7C | 绿色 | 正常状态 |

## 输出文件命名

```
供应商未到货订单汇总_YYYYMMDD.xlsx
```

例如：`供应商未到货订单汇总_20260414.xlsx`
