# 财报效应分析

## 触发后：解析用户意图

从用户消息提取：

| 信息 | 示例 | 处理方式 |
|------|------|---------|
| 股票代码 | TSLA、小鹏、700.HK | 转换为标准格式（如 XPEV.US、700.HK） |
| 财报日期 | 用户提供 | 用 `--dates` 传入 |
| 无日期 | 用户未提供 | 使用脚本内置历史日期 |

**内置历史财报数据的股票**：XPEV.US, TSLA.US, NVDA.US, AAPL.US, MSFT.US, META.US, GOOGL.US, AMZN.US, UNH.US, 700.HK, 9988.HK, 1810.HK, 1211.HK

**非内置股票**：脚本自动按以下顺序获取财报日期，无需人工干预：
1. Longbridge `finance-calendar report` 拉取近900日历史财报日期
2. 若 Longbridge 无数据，回落到 **yfinance** 网页源（需 `pip install yfinance`）
3. 两者均失败时提示用户用 `--dates` 手动传入日期

报告会自动显示相应提示：
- 使用 yfinance 时：顶部出现**橙黄色数据来源提示条**，说明数据来自 Yahoo Finance
- 有效财报样本 < 5 次时：顶部出现**黄色样本量提示条**，提醒统计参考价值有限

## 执行步骤

### Step 1：运行分析脚本

```bash
python3 "<skill_dir>/scripts/analyzer.py" \
  --symbol XPEV.US \
  --output /tmp/earnings_XPEV_$(date +%Y%m%d_%H%M%S).html
```

如用户提供了财报日期：
```bash
python3 "<skill_dir>/scripts/analyzer.py" \
  --symbol TSLA.US \
  --dates "2025-01-29,2025-04-22,2025-07-22" \
  --output /tmp/earnings_TSLA.html
```

脚本自动完成：
- `longbridge kline history` 获取近900日 K 线
- 对每个财报日计算 T-5、T、T+5、T+10 价格
- 统计涨跌次数、平均幅度、分布
- `longbridge positions` 读取用户当前持仓
- 生成含 Chart.js 图表的 HTML 报告
- 根据历史胜率 + 持仓情况生成3条持仓情景参考（含合规声明）

### Step 2：数据复查（必须执行，不可跳过）

**HTML 生成后，必须立即用 Longbridge CLI 对关键数据进行复查，确保报告数据准确。** 脚本内部的计算逻辑可能因日期偏移、数据缺失等原因产生误差，AI 不得仅凭脚本输出直接向用户汇报，必须先核实。

复查项目：

```bash
# 1. 核实最近一次财报日前后5日价格
longbridge kline history {SYMBOL} --start {T-10日} --end {T+15日} --period day

# 2. 核实当前持仓
longbridge positions
```

逐项检查 HTML 中「财报事件明细」表格的**所有记录**：
- 每一条的前5日价、发布日价、后5日价是否与 K 线数据一致
- 每一条涨跌幅计算是否正确（后5日价 / 前5日价 - 1）
- 持仓数量、成本价是否与 `longbridge positions` 返回一致

**不得只抽查部分记录，必须全量核实。** K 线数据在早期日期更容易因交易日偏移产生误差，越早的数据越需要仔细核对。

发现不一致时，应告知用户数据存在偏差，并说明原因（如财报日恰为非交易日、数据截止日期等）。

### Step 3：打开报告

```bash
open /tmp/earnings_*.html
```

### Step 4：向用户汇报摘要

```
📊 {股票名} 财报效应分析完成

历史样本：{N}次财报
上涨概率：{X}%（{up}次上涨 / {dn}次下跌）
前5→后5日平均：{avg5:+.1f}%
前5→后10日平均：{avg10:+.1f}%

持仓：{有/无} → 已生成持仓情景参考

报告已在浏览器打开。⚠️ 历史数据不构成投资建议，请谨慎决策。
```

## 合规要求（必须遵守）

1. **三条情景参考必须标注风险等级**（低/中/高）
2. **HTML 底部必须有完整合规声明**，明确注明"不构成投资建议"
3. **禁止使用"一定会涨/跌"等确定性表述**，统计结论均用"历史上...""平均...""概率..."表达
4. **期权操作（情景3）必须注明适合有一定经验的投资者**
5. 若用户追问"应该买吗"，回复：「本工具仅提供历史统计参考，不提供投资建议，请结合自身情况和专业顾问意见决策。」
