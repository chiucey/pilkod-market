## 指令集

### 1. 分析报告

**触发条件**：用户发送"分析报告"指令

**执行流程**：
1. 获取当前实时大盘数据（使用AKShare/Tushare）
2. 获取前日/当日收盘数据
3. 调用实时分析预测模型
4. 生成全面详细的分析报告

**报告必含内容**：
- 分析标的股票代码
- 买卖和持有建议（买入/卖出/持有）
- 建仓或减仓合适价格区间
- 压力位和支撑位
- 未来趋势预测
- 分析依据说明

### 2. 报告优化

**触发条件**：用户发送"报告优化"指令

**执行流程**：
1. 分析当前报告的完整性
2. 根据实时行情补充新的分析维度
3. 增加基本面因子分析
4. 完善市场情绪解读
5. 补充行业对比分析

### 3. 模型报告

**触发条件**：用户发送"模型报告"指令

**报告内容**：
- 模型详情（算法、参数、输入特征）
- 优化详情（历史优化记录）
- 回测详情（准确率、收益率、最大回撤）
- 数据模块详情（数据源、数据质量）
- 下一步优化计划

### 4. 系统报告

**触发条件**：用户发送"系统报告"指令

**报告内容**：
- 系统全部模块概览
- 所有功能详情
- 模块间交互逻辑
- 后续完善计划

### 5. 数据更新

**触发条件**：用户发送"数据更新"指令

**执行流程**：
1. 查找和集成更多有效数据源
2. 更新历史数据
3. 更新实时数据
4. 执行数据检核（横向/纵向一致性）
5. 处理虚拟数据（标记、补充）

### 6. 模型优化

**触发条件**：用户发送"模型优化"指令

**执行流程**：
1. 分析是否需要新增分析标的
2. 分析是否需要新增特征维度
3. 分析是否需要调整模型算法
4. 获取新增标的的历史数据
5. 执行数据更新操作
6. 进行模型训练和对比
7. 多轮回测迭代优化
8. 同步更新分析报告生成逻辑

### 7. 系统优化

**触发条件**：用户发送"系统优化"指令

**执行流程**：
1. 执行"模型优化"指令
2. 执行"报告优化"指令
3. 检查全系统功能完整性
4. 检查模块联动更新
5. 优化功能不合理处

### 8. 提交反馈

**触发条件**：用户发送"提交反馈"指令

**执行流程**：
1. 收集用户反馈内容
2. 登记反馈信息
3. 分析反馈价值
4. 纳入优化建议

## 错误处理

1. 数据获取失败：切换备用数据源
2. 模型预测异常：回退到基准模型
3. 报告生成失败：返回简化版本
4. 数据检核失败：标记异常数据，待手动确认
