# A股分析预测系统 - 分析维度参考文档

## 一、技术分析维度

### 1. 均线系统

| 指标 | 周期 | 说明 |
|------|------|------|
| MA5 | 5日 | 短期趋势 |
| MA10 | 10日 | 短期趋势 |
| MA20 | 20日 | 中期趋势 |
| MA60 | 60日 | 中期趋势 |
| MA120 | 120日 | 长期趋势 |
| MA250 | 250日 | 年线 |

**分析逻辑**:
- 多头排列：短期 > 长期 → 强势
- 空头排列：短期 < 长期 → 弱势
- 金叉：短期上穿长期 → 买入信号
- 死叉：短期下穿长期 → 卖出信号

### 2. MACD指标

```python
MACD = {
    "快线EMA": 12日指数移动平均,
    "慢线EMA": 26日指数移动平均,
    "DIF": 快线EMA - 慢线EMA,
    "DEA": DIF的9日移动平均,
    "MACD柱": (DIF - DEA) * 2
}
```

**信号**:
- DIF上穿DEA → 金叉买入
- DIF下穿DEA → 死叉卖出
- MACD柱转红 → 多头信号
- MACD柱转绿 → 空头信号

### 3. KDJ指标

```python
KDJ = {
    "RSV": (收盘价 - N日最低) / (N日最高 - N日最低) * 100,
    "K": RSV的3日移动平均,
    "D": K的3日移动平均,
    "J": 3*K - 2*D
}
```

**信号**:
- K值 > 80 → 超买区域
- K值 < 20 → 超卖区域
- J值 > 100 → 极端超买
- J值 < 0 → 极端超卖

### 4. RSI指标

| 周期 | 应用 |
|------|------|
| RSI6 | 短期超买超卖 |
| RSI12 | 中期趋势 |
| RSI24 | 长期趋势 |

**信号**:
- RSI > 70 → 超买
- RSI < 30 → 超卖
- RSI突破前高 → 确认趋势
- RSI与价格背离 → 反转信号

### 5. 布林带（BOLL）

```python
BOLL = {
    "中轨": MA20,
    "上轨": MA20 + 2*STD20,
    "下轨": MA20 - 2*STD20
}
```

**信号**:
- 价格触及上轨 → 强势但警惕回调
- 价格触及下轨 → 弱势但警惕反弹
- 布林带收窄 → 酝酿突破
- 布林带开口 → 趋势加速

## 二、基本面分析维度

### 1. 估值指标

| 指标 | 计算 | 含义 |
|------|------|------|
| PE | 市价/每股收益 | 市盈率，越低越便宜 |
| PB | 市价/每股净资产 | 市净率，破净可能价值重估 |
| PS | 市价/每股营收 | 市销率，适合成长股 |
| PCF | 市价/每股现金流 | 市现率 |

### 2. 盈利指标

| 指标 | 计算 | 含义 |
|------|------|------|
| ROE | 净利润/净资产 | 净资产收益率 |
| ROA | 净利润/总资产 | 总资产收益率 |
| 毛利率 | (营收-成本)/营收 | 定价能力 |
| 净利率 | 净利润/营收 | 盈利能力 |

### 3. 成长指标

| 指标 | 计算 | 含义 |
|------|------|------|
| 营收增速 | (本期营收-上期营收)/上期营收 | 增长能力 |
| 净利润增速 | (本期净利-上期净利)/上期净利 | 盈利增长 |
| PEG | PE/净利润增速 | 成长估值匹配 |

## 三、市场情绪维度

### 1. 资金流向

```python
FUND_FLOW = {
    "北向资金": 沪深港通北向净流入,
    "主力净流入": 大单净流入,
    "超大单净流入": 机构资金,
    "散户资金": 小单净流入
}
```

**信号**:
- 北向资金持续净流入 → 外资看多
- 主力净流入放大 → 机构建仓
- 散户资金大幅流入 → 警惕见顶

### 2. 融资融券

```python
MARGIN = {
    "融资余额": 投资者融资买入金额,
    "融券余额": 投资者融券卖出金额,
    "融资净买入": 本日融资买入-归还,
    "融券净卖出": 本日融券卖出-买还
}
```

**信号**:
- 融资余额持续上升 → 杠杆资金看多
- 融资余额快速下降 → 警惕踩踏
- 融券余额异常升高 → 做空力量聚集

### 3. 市场情绪指数

| 指标 | 数值 | 信号 |
|------|------|------|
| 恐慌指数(VIX) | >30 | 市场恐慌加剧 |
| 换手率 | 异常放大 | 多空分歧 |
| 涨跌停家数比 | 上涨家数/下跌家数 | 市场热度 |
