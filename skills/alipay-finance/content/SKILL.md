# 支付宝理财信息查询 Skill

## 功能说明

通过 web_search 和 extract_content_from_websites 工具，获取支付宝/蚂蚁集团公开的金融产品信息，包括：
- 余额宝收益率及近期动态
- 支付宝热门基金行情
- 支付宝稳健理财专区信息
- 蚂蚁集团/支付宝最新资讯

## 数据来源

- 支付宝官网公开数据
- 蚂蚁集团官方公告
- 主流财经网站（天天基金网、同花顺、东方财富等）支付宝相关数据

## 查询方式

### 1. 余额宝/货币基金信息
使用 `batch_web_search` 搜索：
- `余额宝收益率 2026`
- `支付宝货币基金 年化收益`

### 2. 支付宝基金行情
使用 `batch_web_search` 搜索：
- `支付宝金选基金 2026`
- `支付宝基金排行 热门`

### 3. 支付宝理财资讯
使用 `batch_web_search` 搜索：
- `支付宝理财 最新产品 2026`
- `蚂蚁集团 理财 动态`

### 4. 页面详情抓取
对搜索到的可靠链接使用 `extract_content_from_websites` 提取具体内容。

## 输出格式

收到查询请求后，返回结构化信息：

```
## 支付宝理财概览 [日期]

### 💰 余额宝/货币基金
- 7日年化收益率：X.XX%
- 万份收益：X.XX元
- 状态：[上升/下降/持平]

### 📊 支付宝金选基金（示例）
| 基金名称 | 代码 | 最新净值 | 日涨跌 |
|----------|------|----------|--------|

### 🏧 稳健理财专区
- 产品类型：短债/纯债/银行理财
- 参考年化：X.X% - X.X%

### 📰 最新动态
- [资讯标题1](链接) - 日期
- [资讯标题2](链接) - 日期

---
⚠️ 仅供参考，非实时数据，购买前请以支付宝官方为准。
```

## 注意事项

- 所有数据均来自公开网络，不涉及用户账户信息
- 返回结果会注明数据来源日期
- 不提供具体投资建议
