# 北京16+1区融媒体中心宣传情况报告撰写技能

## 技能概述

本技能用于撰写北京16+1区融媒体中心宣传情况的阶段性总结报告。框架基于示例文档，涵盖协同发展、民生服务、城市更新三大主题板块。

## 输入要求

用户提供的内容来源：
- 公众号文章链接及标题
- 抖音号/视频号标题
- 其他新媒体平台内容标题

## 输出框架

### 文档标题格式
```
[日期]16+1区融媒体中心宣传情况
```

### 正文结构

**第一段：总述**
- 简述当日宣传的整体情况
- 提及平台数量（频道频率、新媒体平台数量）
- 点明宣传主题方向

**第二段：聚焦协同发展**
- 开头一句概括本板块主题
- 围绕"京津冀协同发展国家战略"展开
- 包含具体区名、媒体平台账号、内容标题
- 用原文引述或概括方式描述报道内容
- 每条内容突出该区的特色亮点

**第三段：关注民生实事**
- 开头一句概括本板块主题
- 聚焦"七有""五性"需求
- 展示为民服务举措、基层治理成效
- 同样包含具体区名、平台账号、内容标题

**第四段：呈现城市更新**
- 开头一句概括本板块主题
- 围绕老城保护、城市治理、风貌提升
- 展现城市有机更新实践

## 内容要求

1. **真实性原则**：所有内容必须来自用户提供的原始信息，不得自行编造
2. **完整性原则**：每个区的宣传内容都要提及
3. **准确性原则**：区名、平台名称、内容标题需准确
4. **格式规范**：使用"一是/二是/三是"结构化表述

## 撰写流程

1. **信息提取**：从用户提供的链接/标题中提取关键信息
2. **分类整理**：按三大板块（协同发展、民生实事、城市更新）分类
3. **内容撰写**：按照框架格式撰写
4. **检查核实**：确保所有提及内容均有来源依据

## 注意事项

- 不要添加用户未提供的细节或数据
- 保持语言简洁、正式
- 善用"报道"、"介绍"、"展现"等动词
- 突出各区宣传的特色和亮点
