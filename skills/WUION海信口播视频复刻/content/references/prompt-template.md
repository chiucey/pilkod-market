## 四、[视频文件名]直贴版提示词（直接复制使用）

> 以下提示词用于 AI 视频生成工具，**全部时序精确到 0.01 秒**，**全程无任何文字**。

### 基础引用

```
@Image1：人物参考（全程唯一）
@Image2：场景参考（全程唯一）
参考音频：从参考视频单独提取的口播音频（X.XX 秒，N 段中文口播，全程唯一口播时序基准）
```

### 核心参数

```
画幅：2K，9:16 竖屏（1080×1920）
帧率：60fps
总时长：X.XX 秒（精确到 0.01 秒）
风格：写实摄影，产品广告质感，明亮客厅
文字：全程无字幕、无标题、无水印、无叠字、无贴纸、无动画特效；电视屏幕内无任何文字、Logo、广告牌、字幕、赛事标志
声音：口播由参考音频驱动，不在画面内渲染
```

### 完整提示词

