# PRD评审检查清单

本文档提供PRD文档的自检标准，确保文档质量。

## 一、完整性检查

### 1.1 产品概述
- [ ] 是否有清晰的产品背景描述？
- [ ] 产品定位是否明确（一句话描述）？
- [ ] 目标用户是否有画像描述？
- [ ] 成功指标是否可量化？

### 1.2 功能需求
- [ ] 功能清单是否覆盖核心功能？
- [ ] 每个功能是否有明确的优先级？
- [ ] 是否包含用户故事？
- [ ] 是否包含验收标准？
- [ ] 验收标准是否可测试？

### 1.3 非功能需求
- [ ] 性能要求是否明确？
- [ ] 安全要求是否覆盖？
- [ ] 兼容性要求是否说明？
- [ ] 可用性要求是否定义？

### 1.4 发布标准
- [ ] 测试标准是否可执行？
- [ ] 发布条件是否明确？
- [ ] 是否有明确的负责人？

## 二、可测试性检查

### 2.1 验收标准格式
每个功能点应有以下格式的验收标准：

```
Given [前置条件]
When [操作步骤]
Then [预期结果]
```

### 2.2 验收标准示例

**好的验收标准：**
```markdown
Given 用户已登录且有收货地址
When 用户提交订单（订单金额≥99元）
Then 订单创建成功，显示优惠券抵扣后金额
     发送短信通知到用户手机
     库存扣减相应数量
```

**不好的验收标准：**
```markdown
- 订单支付流程正常
- 用户体验良好
- 系统稳定可靠
```

### 2.3 量化指标检查
- [ ] 性能指标是否有具体数值？
- [ ] 转化率指标是否有目标值？
- [ ] 错误率指标是否有阈值？

## 三、一致性检查

### 3.1 内部一致性
- [ ] 功能清单与详细描述是否一致？
- [ ] 优先级标注是否统一？
- [ ] 术语使用是否统一？
- [ ] 格式风格是否统一？

### 3.2 外部一致性
- [ ] 与产品 roadmap 是否一致？
- [ ] 与技术架构是否匹配？
- [ ] 与其他产品是否有关联说明？
- [ ] 与依赖方是否确认？

## 四、风险评估检查

### 4.1 技术风险
- [ ] 是否有技术可行性存疑的功能？
- [ ] 是否有性能瓶颈风险？
- [ ] 是否有技术依赖？

### 4.2 资源风险
- [ ] 人力投入是否评估？
- [ ] 时间节点是否合理？
- [ ] 是否有外部依赖？

### 4.3 业务风险
- [ ] 是否有合规风险？
- [ ] 是否有竞品风险？
- [ ] 是否有政策风险？

## 六、MVP拆分建议

### 6.1 MVP定义
MVP（最小可行产品）应包含：
1. 解决核心问题的必备功能
2. 基础的用户体验
3. 可验证产品假设的最小范围

### 6.2 拆分原则
```
P0: 必须有 → MVP必须包含
P1: 应该有 → 第一版迭代
P2: 可以有 → 后续版本
```

### 6.3 拆分示例

**原始需求：**
```markdown
功能1（P0）：用户注册登录
功能2（P0）：商品浏览
功能3（P0）：下单支付
功能4（P1）：优惠券
功能5（P1）：积分体系
功能6（P2）：社交分享
功能7（P2）：评价系统
```

**MVP版本：**
```markdown
MVP 1.0（发布标准版）：
├── 功能1：用户注册登录
├── 功能2：商品浏览
└── 功能3：下单支付

迭代 1.1：
├── 功能4：优惠券
└── 功能5：积分体系

迭代 1.2：
├── 功能6：社交分享
└── 功能7：评价系统
```

## 七、数据支撑建议

### 7.1 需求数据化
每个功能需求应回答：
1. 这个功能解决什么问题？
2. 有多少用户会遇到这个问题？
3. 解决这个问题能带来什么价值？
4. 如何量化这个价值？

### 7.2 常用数据指标
| 指标类型 | 指标名称 | 计算方式 |
|---------|---------|---------|
| 转化 | 点击率 | 点击/曝光 |
| 转化 | 下单率 | 下单UV/访问UV |
| 留存 | 次日留存 | 次日回访/新增 |
| 留存 | 7日留存 | 7日回访/新增 |
| 活跃 | DAU | 日活跃用户数 |
| 活跃 | MAU | 月活跃用户数 |
| 收入 | ARPU | 收入/活跃用户 |
| 口碑 | NPS | 推荐者%-贬损者% |
