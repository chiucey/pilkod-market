# PRD模板参考

本文档提供四种产品的PRD模板详细参考。

## 模板一：互联网C端产品

### 特点
- 面向消费者，用户量大，交互体验优先
- 强调用户增长、留存、转化
- 功能迭代快，需要快速验证

### 核心章节
```markdown
# [产品名称] PRD

## 1. 产品概述
### 1.1 产品背景
[市场规模、用户痛点、市场机会]

### 1.2 产品定位
[产品是什么，解决什么人在什么场景下的什么问题]

### 1.3 目标用户
- **目标用户群体**：[用户画像描述]
- **用户规模**：预计[X]万用户
- **核心场景**：
  - 场景1：[描述]
  - 场景2：[描述]

### 1.4 成功指标
| 指标 | 定义 | 目标值 |
|-----|------|-------|
| DAU | 日活跃用户数 | [X]万 |
| 次日留存 | 次日回访比例 | ≥[X]% |
| 转化率 | 完成目标行为用户/访问用户 | ≥[X]% |
| NPS | 用户净推荐值 | ≥[X]分 |

## 2. 功能需求

### 2.1 功能总览
| 模块 | 功能点 | 优先级 | 状态 |
|-----|-------|-------|------|
| 首页 | Banner展示 | P1 | 待开发 |
| 搜索 | 关键词搜索 | P0 | 待开发 |
| ... | ... | ... | ... |

### 2.2 详细功能

#### 首页模块
**功能描述：** 用户打开APP首先看到的页面

**页面结构：**
| 区域 | 内容 | 交互 |
|-----|------|------|
| 顶部 | 状态栏+搜索入口 | 点击进入搜索页 |
| 中部 | 内容展示区 | 列表/瀑布流 |
| 底部 | 底部导航 | Tab切换 |

**用户故事：**
- 作为[新用户]，我想要[快速了解产品核心价值]，以便[决定是否继续使用]
- 作为[老用户]，我想要[快速找到我感兴趣的内容]，以便[提升使用效率]

**验收标准：**
- Given [用户首次打开APP]，When [等待加载完成]，Then [首页显示时间≤2秒，内容完整]
- Given [用户下拉刷新]，When [网络正常]，Then [5秒内更新内容，显示刷新结果]

## 模板二：B端SaaS产品

### 特点
- 面向企业用户，决策链长
- 强调效率提升、流程规范、数据安全
- 需支持多租户、权限管理、定制化

### 核心章节
```markdown
# [产品名称] PRD

## 1. 产品概述

### 1.1 产品背景
- **行业背景**：[行业现状和趋势]
- **客户痛点**：
  - 痛点1：[具体描述]
  - 痛点2：[具体描述]
- **解决方案**：[产品如何解决痛点]

### 1.2 产品定位
- **产品形态**：B端SaaS / 私有部署
- **目标客群**：中小型企业 / 大型企业 / 特定行业
- **核心价值**：提升[X]%效率，降低[X]%成本

### 1.3 商业模式
- **定价模式**：订阅制 / 按用量 / 一次性买断
- **价格区间**：[X]-[X]元/年
- **目标客户规模**：[X]家企业

### 1.4 成功指标
| 指标 | 定义 | 目标值 |
|-----|------|-------|
| ARR | 年度经常性收入 | [X]万元 |
| 客户数 | 付费企业数 | [X]家 |
| 续费率 | 到期续费比例 | ≥[X]% |
| NRR | 净收入留存率 | ≥[X]% |

## 2. 功能需求

### 2.1 功能总览
| 模块 | 功能点 | 优先级 | 用户角色 |
|-----|-------|-------|---------|
| 组织管理 | 部门管理 | P0 | 管理员 |
| 权限管理 | 角色权限 | P0 | 管理员 |
| 业务模块 | 核心功能 | P0 | 普通用户 |
| ... | ... | ... | ... |

### 2.2 权限体系

#### 角色定义
| 角色 | 描述 | 权限范围 |
|-----|------|---------|
| 超级管理员 | 企业所有者 | 全部功能 |
| 管理员 | IT/HR负责人 | 部分管理功能 |
| 普通用户 | 业务人员 | 业务功能 |
| 访客 | 外部人员 | 只读功能 |

#### 权限矩阵（示例）
| 功能 | 超级管理员 | 管理员 | 普通用户 |
|-----|-----------|-------|---------|
| 组织设置 | ✓ | ✓ | ✗ |
| 成员管理 | ✓ | ✓ | ✗ |
| 业务操作 | ✓ | ✓ | ✓ |
| 数据导出 | ✓ | ✓ | ✗ |

### 2.3 多租户设计
- **租户隔离**：数据层逻辑隔离
- **定制化**：支持Logo、主题色、字段定制
- **数据迁移**：支持租户间数据迁移

## 模板四：数据产品

### 特点
- 面向数据分析师、业务人员
- 强调数据准确性、分析能力、可视化
- 需考虑数据治理、权限控制、性能

### 核心章节
```markdown
# [产品名称] PRD

## 1. 产品概述

### 1.1 产品定位
- **产品类型**：数据平台 / BI工具 / 数据服务
- **核心能力**：一站式数据采集、存储、分析、可视化
- **目标用户**：数据分析师、业务人员、管理层

### 1.2 数据架构
```
[数据源] → [数据采集] → [数据存储] → [数据处理] → [数据应用]
                              ↓
                         [数据治理]
```

### 1.3 目标场景
| 场景 | 用户 | 核心需求 |
|-----|------|---------|
| 数据接入 | 数据工程师 | 快速接入多数据源 |
| 数据建模 | 数据分析师 | 低代码建模 |
| 数据分析 | 业务人员 | 自助分析 |
| 数据可视化 | 管理层 | 决策支持 |

### 1.4 成功指标
| 指标 | 定义 | 目标值 |
|-----|------|-------|
| 数据规模 | 日处理数据量 | [X]TB |
| 查询性能 | P99查询耗时 | ≤[X]秒 |
| 可用性 | 系统可用时间 | ≥99.9% |
| 用户活跃 | 月活用户数 | [X]人 |

## 2. 功能需求

### 2.1 功能总览
| 模块 | 功能点 | 优先级 | 说明 |
|-----|-------|-------|------|
| 数据接入 | 数据源连接 | P0 | 支持[X]种数据源 |
| 数据开发 | SQL开发 | P0 | 在线IDE |
| 数据治理 | 数据质量 | P1 | 规则配置 |
| 数据应用 | 可视化 | P0 | 图表组件 |
| ... | ... | ... | ... |

### 2.2 数据模型

#### 主题域划分
| 主题域 | 描述 | 核心实体 |
|-------|------|---------|
| 用户域 | 用户相关数据 | 用户、账户、会员 |
| 交易域 | 交易相关数据 | 订单、支付、物流 |
| 行为域 | 用户行为数据 | 埋点、会话、事件 |

#### 指标体系
| 指标分类 | 示例指标 | 计算口径 |
|---------|---------|---------|
| 流量指标 | DAU/MAU | 去重计数 |
| 转化指标 | 转化率 | 转化用户/曝光用户 |
| 营收指标 | GMV | SUM(订单金额) |

### 2.3 数据安全
- **数据分级**：
  - L1 公开：可对外展示
  - L2 内部：仅内部使用
  - L3 敏感：需脱敏处理
  - L4 机密：严格访问控制
- **脱敏规则**：手机号、身份证等敏感字段脱敏
- **权限控制**：行列级权限、数据权限、列权限
