# PRD输出格式转换指南

本文档提供不同平台的PRD文档格式转换参考。

## 1. Markdown格式（原生）

```markdown
# 产品名称 PRD

## 1. 产品概述
### 1.1 产品背景
...

## 2. 功能需求
...

## 3. 非功能需求
...

## 4. 发布标准
...
```

**特点：** 通用格式，代码友好，易于版本控制

---

## 2. 飞书文档格式

飞书原生支持Markdown，导入时：
1. 直接粘贴Markdown内容
2. 或使用飞书开放平台API导入

```markdown
# 产品名称 PRD

> 文档信息
> - 版本：v1.0.0
> - 更新日期：2024-01-01
> - 负责人：产品经理

## 1. 产品概述

### 1.1 产品背景
<!-- 使用高亮标注重点 -->
==产品定位：一款XXX产品==

### 1.2 目标用户
| 用户类型 | 核心需求 | 痛点 |
|---------|---------|------|
| 年轻女性 | 时尚穿搭 | 搭配困难 |

!!! tip "提示"
    目标用户规模预计XX万
```

**飞书特有功能映射：**
| 功能 | Markdown写法 | 飞书效果 |
|-----|-------------|---------|
| 高亮 | `==文字==` | 黄色高亮 |
| 提示框 | `!!! tip` | 提示卡片 |
| 嵌入文档 | `@文档链接` | 自动关联 |
| 任务 | `- [ ] 任务` | 复选框 |

## 3. Notion格式

Notion使用类似的Markdown变体：

```markdown
# 产品名称 PRD

## 产品概述

**产品定位：** ==一句话描述==

## 功能需求

- [ ] P0 功能1
- [ ] P1 功能2
- [x] 已完成功能

### 用户故事
> "作为一个[用户角色]，我想要[功能]，以便[收益]。"

### 验收标准
```
Given [前置条件]
When [操作]
Then [结果]
```
```

**Notion特有功能映射：**
| 功能 | 实现方式 |
|-----|---------|
| 数据库 | 使用Notion Database |
| 看板 | 使用Board视图 |
| 标签 | 使用Multi-select属性 |
| 关系 | 使用Relation属性 |

## 4. Axure原型格式

### PRD与Axure映射

| PRD内容 | Axure对应 |
|-------|----------|
| 产品概述 | 说明页面/首页 |
| 功能清单 | 站点地图 |
| 详细功能 | 页面流程图 |
| 流程图 | 流程连接线 |
| 交互说明 | 链接+交互注释 |
| 验收标准 | 标注在元件上 |

### PRD标注格式

```markdown
## [页面名称]

**页面URL：** /path/page

**功能描述：** [一句话描述]

**页面结构：**
| 元件 | 类型 | 交互 | 说明 |
|-----|------|------|------|
| 搜索框 | Text Field | OnFocus → 显示历史 | 最多显示10条 |

**交互流程：**
1. 用户点击搜索框 → 显示历史记录
2. 用户输入关键词 → 触发搜索建议
3. 用户点击建议 → 跳转搜索结果页

**验收标准：**
- [ ] 页面加载时间 ≤ 2秒
- [ ] 搜索建议延迟 ≤ 200ms
- [ ] 历史记录正确展示

**原型链接：** [Axure原型地址]
```

## 5. 墨刀格式

### PRD与墨刀映射

| PRD内容 | 墨刀对应 |
|-------|----------|
| 功能清单 | 项目结构 |
| 页面说明 | 画板注释 |
| 流程说明 | 流程连线 |
| 验收标准 | 检查清单 |

### PRD标注格式

```markdown
## [页面名称]

**ID：** MD-XXX-001

**描述：** [页面描述]

**注释：**
- 搜索框：支持关键词联想
- 结果列表：支持下拉刷新
- 筛选器：支持多选

**状态：**
- [ ] 设计稿完成
- [ ] 交互评审通过
- [ ] 开发已实现

**链接：** [墨刀原型链接]
```

## 7. 通用格式转换检查清单

### 导出前检查
- [ ] 所有链接是否有效
- [ ] 图片是否已上传到目标平台
- [ ] 表格格式是否正确
- [ ] 代码块是否保留
- [ ] 特殊符号是否转义

### 格式兼容性
| 格式 | Markdown兼容 | 飞书兼容 | Notion兼容 |
|-----|-------------|---------|-----------|
| 标题 `#` | ✓ | ✓ | ✓ |
| 列表 `-` | ✓ | ✓ | ✓ |
| 表格 `|` | ✓ | ✓ | ✓ |
| 代码块 ``` | ✓ | ✓ | ✓ |
| 任务 `- [ ]` | ✓ | ✓ | ✓ |
| 高亮 `==` | ✗ | ✓ | ✗ |
| 提示 `!!!` | ✗ | 部分 | ✗ |

## 8. 快速导出脚本参考

### Markdown to 飞书（Python示例）

```python
def md_to_feishu(md_content):
    # 替换高亮标记
    content = md_content.replace('==', '<mark>')
    content = content.replace('==', '</mark>')

    # 替换提示框
    content = content.replace('!!! tip', '<blockquote>')

    return content
```

### Markdown to Word（Pandoc）

```bash
pandoc prd.md -o prd.docx \
  --reference-doc=template.docx \
  --toc \
  --number-sections
```
