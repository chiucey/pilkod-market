# 股票监控技能 (Stock Watcher)

## 概述

股票监控技能提供多市场股票实时行情监控服务，支持自定义阈值告警、持仓组合跟踪、行情异动识别及定时报告推送。

## 触发词

- 股票监控
- 实时股价
- 价格告警
- 持仓跟踪
- 行情异动
- 涨停提醒
- 监控日报
- 股票异动
- 持仓收益
- 走势对比

## 功能模块

### 1. 实时行情采集

**功能说明**：按配置的频率获取标的最新行情数据

**数据项**：
- 当前价格
- 涨跌幅
- 成交量/成交额
- 最高价/最低价
- 开盘价/昨收价
- 市值/流通市值
- 市盈率/市净率

**支持市场**：
- A股（上交所/深交所）
- 港股（港交所）
- 美股（纽交所/纳斯达克）

### 2. 阈值告警

**告警类型**：

| 类型 | 说明 | 触发条件 |
|------|------|----------|
| 价格告警 | 标的价格触及指定值 | 价格 ≥ 或 ≤ 阈值 |
| 涨幅告警 | 标的价格波动超过阈值 | 涨跌幅 ≥ 阈值 |
| 成交量告警 | 成交量异常放大 | 成交量 ≥ 均量的N倍 |
| 跌破告警 | 价格跌破持仓成本 | 价格 < 成本价 |
| 止盈告警 | 浮盈达到目标 | 收益率 ≥ 目标值 |

**告警内容**：
```
【股票告警】
标的：{股票名称}({代码})
当前价：{价格} {涨跌幅}
阈值：{告警类型} {阈值}
触发时间：{时间}
异动原因：{自动分析原因}
```

### 3. 持仓跟踪

**功能说明**：管理用户持仓组合，计算浮盈浮亏

**数据管理**：
- 持仓标的（代码/名称）
- 持仓数量
- 成本价
- 持仓成本
- 当前市值
- 浮盈金额
- 浮盈收益率

**计算公式**：
- 当前市值 = 当前价 × 持仓数量
- 浮盈金额 = 当前市值 - 持仓成本
- 浮盈收益率 = (当前价 - 成本价) / 成本价 × 100%

### 4. 异动识别

**异动类型**：

| 类型 | 识别条件 | 影响说明 |
|------|----------|----------|
| 涨停 | 股价达到涨幅限制 | 交易活跃度极高 |
| 跌停 | 股价达到跌幅限制 | 交易流动性风险 |
| 大宗交易 | 成交额/成交量异常 | 大资金动向 |
| 龙虎榜 | 上榜交易所公开名单 | 机构博弈信号 |
| 停牌 | 交易暂停 | 重大事项待公布 |
| 复牌 | 恢复交易 | 关注复牌公告 |

### 5. 定时报告

**日报**：每个交易日收盘后推送

**周报**：每周最后一个交易日推送

**报告内容**：
```
【股票监控{日报/周报}】
📅 报告期：{日期范围}
📊 持仓概况：
   总市值：{金额}
   浮盈总额：{金额}({收益率})

🔥 异动回顾：
   {异动标的} {异动类型} {详情}

⚠️ 告警记录：
   {告警时间} {标的} {告警类型} {触发值}

📈 走势回顾：
   {本周/本月涨跌幅TOP5}

📉 走势回顾：
   {本周/本月跌幅TOP5}
```

### 6. 走势对比

**支持周期**：1日、1周、1月、3月、1年、自定义

**对比维度**：
- 涨跌幅对比
- 波动率对比
- 成交量对比
- 相对强弱分析

## 配置项

### 监控标的

```yaml
symbols:
  - market: A
    code: "600519"
    name: "贵州茅台"
  - market: HK
    code: "0700"
    name: "腾讯控股"
  - market: US
    code: "AAPL"
    name: "Apple Inc."
```

### 告警阈值

```yaml
alerts:
  - symbol: "600519"
    type: "price"
    condition: "gte"
    threshold: 2000
    enabled: true
  - symbol: "600519"
    type: "change_percent"
    condition: "gte"
    threshold: 5
    enabled: true
```

### 持仓配置

```yaml
positions:
  - symbol: "600519"
    shares: 100
    cost: 1800.00
```

### 监控频率

```yaml
monitor:
  real_time_interval: 300  # 秒，默认5分钟
  report_schedule:
    daily: "16:00"  # 日报推送时间
    weekly: "friday 16:00"  # 周报推送时间
```

## 执行流程

### 初始化 (pre_execution)

1. 解析用户配置的监控标的列表
2. 加载用户持仓组合数据（本地存储）
3. 校验标的合规性（仅公开上市标的）
4. 初始化定时任务规则
5. 配置通知渠道

### 主执行 (main_execution)

1. **行情采集**：按频率获取标的最新行情
2. **阈值检测**：逐条检查告警规则
3. **持仓计算**：实时更新持仓状态
4. **异动识别**：扫描所有标的异常波动
5. **报告生成**：定时生成监控报告
6. **走势分析**：执行用户请求的对比分析

### 收尾 (post_execution)

1. 持久化监控数据与告警记录
2. 清理过期数据（30天+分钟级数据）
3. 推送告警/报告到指定渠道
4. 更新监控配置（实时生效）

## 数据存储

**保留周期**：
- 告警记录：90天
- 持仓快照：90天
- 分钟级行情：30天
- 日线行情：无限期
- 异动记录：90天

**存储位置**：本地加密存储

## 安全规则

| 规则 | 说明 |
|------|------|
| 数据隔离 | 所有数据本地存储，不上传外部 |
| 无交易权限 | 仅监控功能，不支持实际交易 |
| 凭证加密 | 告警配置加密存储 |
| 访问限制 | 仅可访问公开行情数据 |
| 频率限制 | 监控频率≥1分钟/次 |
| 市场限制 | 仅支持已上市公开标的 |

## 使用示例

### 启动监控

```
用户：启动股票监控，监控贵州茅台和腾讯控股
系统：已添加监控标的：贵州茅台(600519)、腾讯控股(0700.HK)
      监控频率：5分钟/次
      告警渠道：智能体会话
```

### 设置告警

```
用户：茅台跌破1800块时提醒我
系统：已设置告警
      标的：贵州茅台(600519)
      条件：价格 < 1800.00
      触发后通知
```

### 查看持仓

```
用户：查看我的持仓情况
系统：【持仓概况】
      贵州茅台(600519)：100股
      成本价：1800.00
      当前价：1850.00
      浮盈：+5000.00 (+2.78%)
```

### 异动提醒

```
系统：【行情异动】
      标的：{股票名称}({代码})
      类型：涨停
      时间：{触发时间}
      当前价：{价格}
      说明：{影响分析}
```

## 注意事项

1. **行情延迟**：免费行情可能有15分钟延迟
2. **成本计算**：浮盈基于用户输入的成本价
3. **数据准确性**：以实际行情为准，不承担投资建议
4. **频率限制**：免费版本监控间隔不少于1分钟
5. **数据保留**：历史数据超过保留期限自动清理
