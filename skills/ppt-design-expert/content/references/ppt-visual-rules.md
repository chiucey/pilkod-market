# 《演说之禅》+ 高桥流 视觉执行手册

---

## 核心理念：少即是多

> "Your slide design is successful if you can cover the main point in 3 seconds."
> — Garr Reynolds, 《演说之禅》

**三大原则：**
1. **少即是多** — 每页不超过6行，每行不超过6词
2. **视觉留白** — 页面元素不超过40%，留足呼吸空间
3. **三重构成** — 图形 + 标题 + 简述，三者缺一不可

---

## 页面类型执行标准

### 1. 封面页（Cover）
```
视觉元素：
- 主标题：大字号，一行，极简（≤10字）
- 副标题：功能说明（可选）
- 视觉锤：一图/一色/一图形，直击主题

❌ 禁忌：
- 多个字体大小竞争
- 装饰线条过多
- 「关于」「介绍」「汇报」开头

✅ 公式：
主标题 = 核心结论（一句话）
副标题 = 受众/时间/场景
```

### 2. 目录页（TOC）
```
视觉元素：
- 章节标题 ≤ 3个
- 每个章节：一行标题 + 一行简述
- 可用数字/图标区分

✅ 公式：
章节数 = 受众需要知道的「路」的数量
不要告诉受众你做了什么，告诉他们能得到什么
```

### 3. 内容页（Content）— 高桥流执行标准
```
标题标准：
- 字号：≥ 40pt（大标题）
- 只写一行
- 结论前置
- 不用「关于」「分析」「说明」

内容标准：
- 每页 ≤ 3个要点
- 每点一行文字
- 要点 = 主语 + 动词 + 对象（无拖沓句式）
- 30秒内读完（每页演讲时间上限）

视觉布局：
┌─────────────────────────────────┐
│  大标题（40pt+）                  │
│                                  │
│  ● 要点1                         │
│  ● 要点2                         │
│  ● 要点3                         │
│                              ○页码│
└─────────────────────────────────┘

留白规则：
- 上下边距 ≥ 10%
- 左右边距 ≥ 5%
- 内容区 ≤ 页面60%
```

### 4. 数据页（Data）
```
核心原则：让数字「讲故事」，不「展示数字」

❌ 错误：
- 满屏数据表格
- 大量数字无解读
- 混乱的图表

✅ 正确：
- 一个核心数字 + 一个解读
- 用类比让数字有感知
  例：「相当于从北京到上海往返3次」
  例：「如果一天一个，一年可以读完一座小型图书馆」

图表选择：
- 1个数据点 → 大字号数字 + 解读文字
- 2-3个对比 → 柱状图或条形图
- 时间序列 → 折线图
- 占比关系 → 饼图（≤3个分类）
```

### 5. 总结页（Summary）
```
核心原则：重申核心结论 + 具体CTA

必备元素：
□ 核心结论（一句话，重复封面）
□ 具体行动（1-2件，第一步是什么）
□ 联系信息（如何跟进）

❌ 禁忌：
- 「以上就是全部内容，谢谢」
- 没有CTA的总结页
- 与封面不一致的结论
```

## 配色执行标准

### 配色方案（5套）

| 方案 | 主色 | 辅色 | 强调色 | 背景 | 适用场景 |
|------|------|------|--------|------|---------|
| **商务专业** | #1e3a5f | #2563eb | #f59e0b | #ffffff | 国企/政府 |
| **学术严谨** | #1e293b | #475569 | #0891b2 | #f1f5f9 | 学校/教研 |
| **活泼教学** | #7c3aed | #2563eb | #f59e0b | #f5f3ff | 小学/培训 |
| **中国古典** | #7c3aed | #dc2626 | #f59e0b | #faf4ed | 文化/语文 |
| **简约现代** | #0f172a | #64748b | #e11d48 | #ffffff | 商业/创意 |

### 配色执行规则

```
1. 同一PPT不超过3种主色（不含黑白色）
2. 主色占40%面积，辅色占30%，强调色占10%
3. 色块+白字 > 白底+彩字（更易读）
4. 深色背景用于：封面/总结；浅色背景用于：内容页
```

| 副文本 | 14-16pt | Microsoft YaHei | 颜色淡 |

| 页码 | 12pt | Arial | 圆圈装饰 |

## 参考案例：山海经课研PPT的视觉设计分析

### 整体结构
```
I   定位（为什么是山海经）     → 解决「为什么学」问题
II  演绎（戏剧创作）           → 解决「怎么体验」问题
III 穿越（创意写作）           → 解决「怎么创造」问题
IV  积淀（分级阅读+金句）      → 解决「怎么内化」问题
V   评价（评价量规）          → 解决「怎么检验」问题
```

### 每页视觉模式
```
内容页标准模式：
┌─────────────────────────────────────┐
│  [章节序号]  [页面标题]              │  ← 大标题行
│  [核心内容]                         │
│  ┌──────────────────┐ ┌─────────┐ │
│  │ 具体案例/数据     │ │ 高亮框  │ │  ← 双栏布局
│  │                  │ │ 金句/评语│ │
│  └──────────────────┘ └─────────┘ │
│  《框架》对应：XXX指标          ○N │  ← 底部框架标注
└─────────────────────────────────────┘
```

### 视觉亮点（可复用）

| 亮点 | 视觉表现 | 复用场景 |
|------|---------|---------|
| **金句卡片** | 紫色底+白字+引号 | 台词/下水文/名言 |
| **神兽卡片** | 卡片组+原文+描述 | 人物/概念解释 |
| **评价量规表** | 3星表格+维度 | 评估/评分页 |
