# 八大方法论工具详解

## 1. 苏格拉底追问法（Socratic Questioning）

### 核心理念
不直接给答案，而是通过连续追问让人自己发现问题的本质。

### 追问分类

| 类型 | 示例 | 用途 |
|------|------|------|
| 澄清追问 | 「你说的X，具体指什么？」 | 消除歧义，找到真实含义 |
| 假设追问 | 「这个假设成立的前提是什么？」 | 检验前提是否稳固 |
| 证据追问 | 「有什么证据支持这个观点？」 | 区分事实与感觉 |
| 原因追问 | 「为什么会这样？」 | 追溯深层原因 |
| 影响追问 | 「如果这样做，后果是什么？」 | 评估行动结果 |
| 观点追问 | 「其他人会怎么看这件事？」 | 多元视角 |

### 在PPT设计中的应用

**用于开始前的需求澄清：**
```
用户：我想要一个介绍我们公司产品的PPT。
追问1：「最怕领导听完产生什么误解？」
追问2：「如果只给你30秒，你会说什么？」
追问3：「他们的痛点是什么？我们解决了哪个？」
追问4：「他们现在用什么替代方案？」
追问5：「听完这个PPT，他们应该做什么决定？」
```

## 2. 麦肯锡金字塔原理（Pyramid Principle）

### 核心理念
- **结论先行**：先告诉听众你要说什么
- **以上统下**：每个论点下面有支撑论据
- **MECE分组**：相互独立，完全穷尽

### 结构图示

```
        ┌─────────────────┐
        │   核心结论（1句）│
        └────────┬────────┘
         ┌───────┴───────┐
         ↓               ↓
    ┌────────┐       ┌────────┐
    │ 论点1  │       │ 论点2  │（如果需要3个论点）
    └────┬───┘       └────┬───┘
    ┌────┴───┐       ┌────┴───┐
    ↓       ↓       ↓       ↓
  数据    案例    数据    案例
```

### MECE法则执行检查

```
□ 论点之间是否有重叠？（如果有 → 合并）
□ 是否遗漏了重要论点？（如果有 → 补充）
□ 每个论点是否有2-3个支撑证据？
□ 证据是数据/案例/故事，而不是Opinion？
```

## 3. 特劳特定位理论（Positioning）

### 核心理念
在潜在客户的心智中建立差异化定位。

### 三问定位法

```
1.「我们是什么？」（品类定位）
2.「我们与竞争对手有什么不同？」（差异化）
3.「为什么客户应该相信我们？」（信任状）
```

### 在PPT中的应用

**用于封面设计：**
```
❌ 错误：「关于XX公司产品介绍」
✅ 正确：「[品类]专家：解决[核心问题]的[差异化方案]」
```

**用于结论设计：**
```
❌ 模糊：「我们提供优质服务」
✅ 定位：「连续3年[细分领域]市场份额第一」
```

## 4. 叶茂中冲突营销理论

### 核心理念
没有冲突就没有注意力。好的营销 = 制造/利用心理冲突。

### 冲突类型

| 类型 | 示例 | PPT应用 |
|------|------|--------|
| 供需冲突 | 「你想要X，但Y限制了你」 | 痛点放大 |
| 认知冲突 | 「你以为X，但实际上Y」 | 反转设计 |
| 竞争冲突 | 「你应该选我们而不是对手」 | 对比呈现 |
| 自我冲突 | 「你想要A，但内心觉得B」 | 情感共鸣 |

### 在PPT中的应用

**用于设计开场钩子：**
```
❌ 平淡开场：「今天向大家汇报我们的工作」
✅ 冲突开场：「为什么你的团队学了很多方法论，却还是做不出好PPT？」
```

**用于设计核心论点：**
```
❌ 平铺直叙：「我们的产品有三大优势」
✅ 冲突切入：「别买我们的产品——除非你真的需要解决这5个问题」
```

## 5. 实证研究方法（Empirical Research）

### 核心理念
PPT中的每一个论点必须有数据/证据支撑，而不是opinion。

### 证据等级（从强到弱）

| 等级 | 类型 | 可信度 |
|------|------|--------|
| 1 | 随机对照实验（RCT） | ⭐⭐⭐⭐⭐ |
| 2 | 准实验/纵向追踪 | ⭐⭐⭐⭐ |
| 3 | 大样本数据 | ⭐⭐⭐⭐ |
| 4 | 小样本案例 | ⭐⭐⭐ |
| 5 | 定性访谈/专家意见 | ⭐⭐ |
| 6 | 个人经验/opinion | ⭐ |

### PPT中的实证检验

```
检查每个论点：
- 有数据吗？（等级1-4 → OK）
- 无数据有案例吗？（等级5 → 标注「案例」）
- 无数据无案例吗？（等级6 → 删除或改为问题呈现）
```

## 6. 元方法论（Meta-Methodology）

### 核心理念
在使用方法之前，先问「我用什么方法来选择这些方法？」

### 在PPT设计中的应用

```
当用户提出多个框架时（麦肯锡+特劳特+叶茂中）：
→ 元方法论问：
  「这些框架各自解决什么问题？」
  「麦肯锡 → 解决结构问题（怎么组织内容）」
  「特劳特 → 解决定位问题（在心智中占什么位置）」
  「叶茂中 → 解决注意力问题（怎么让人想听）」
  → 根据PPT目标选择主导框架，其他做辅助
```

## 7. SCQA框架（Situation-Complication-Question-Answer）

### 核心理念
用讲故事的方式设计PPT的逻辑流。

### 四步结构

| 阶段 | 任务 | 示例 |
|------|------|------|
| **S（背景）** | 建立共同认知 | 「众所周知，中国的K12教育市场竞争激烈」 |
| **C（冲突）** | 引入问题/冲突 | 「但90%的培训机构不知道自己的真正定位」 |
| **Q（问题）** | 提出核心疑问 | 「那么，如何找到你独特的市场位置？」 |
| **A（答案）** | 给出解决方案 | 「特劳特定位法——让你的品牌在心智中占据第一」 |

### 在PPT中的应用顺序

```
第1页：封面 = 核心结论（Q+A合一，省掉前奏）
第2页：S（背景铺垫，如果需要的话）
第3页：C（核心冲突）
第4页：Q（我们面临的问题）
第5页：A（解决方案 = 核心论点1）
第6页：论据/案例
第7页：A（核心论点2）
...
最后：总结 + CTA
```

## 8. 麦肯锡情境分析（7S Framework）

### 核心理念
系统性诊断一个组织/项目的关键要素。

### 7S要素

| 要素 | 含义 | PPT设计应用 |
|------|------|-----------|
| Strategy | 战略 | 我们的解决方案是什么？ |
| Structure | 组织结构 | 谁来做？汇报关系？ |
| Systems | 系统/流程 | 怎么执行？ |
| Shared Values | 核心价值观 | 为什么这样做？ |
| Style | 风格/文化 | 以什么方式呈现？ |
| Staff | 人才/能力 | 团队配置？ |
| Skills | 能力/优势 | 我们的核心竞争力？ |

### 在PPT设计中的应用

**用于诊断和发现：**
```
问题诊断清单：
□ 战略清晰吗？（听众知道你要去哪吗？）
□ 结构合理吗？（逻辑顺序对吗？）
□ 有 Shared Values 吗？（有故事/情怀吗？）
□ 风格一致吗？（视觉统一吗？）
□ Skills 体现了吗？（你和别人有什么不同？）
```
