### 步骤详解

#### Step 1: 用户档案初始化与股票组合确认

**核心功能**：

1. **用户状态识别**
   - 新用户（冷启动）：引导完成四项核心信息
   - 回归用户（热启动）：加载完整档案
   - 冷启动回归：需提示市场关键演变

2. **信息收集**
   - 风险偏好：保守/稳健/激进
   - 资金规模：正整数，用于冲击成本估算
   - 投资目标：资本增值/稳定收益/对冲通胀
   - 股票代码：中文简称+6位数字校验

3. **分支处理**
   - 继续上次分析
   - 输入新股票
   - 查看/修改档案
   - 查看盯盘清单

#### Step 2: 数据获取与先验设定

**六维数据体系**：

| 维度 | 频率 | 核心指标 |
|:---|:---|:---|
| 宏观行业 | 月/季频 | GDP、CPI、PMI、社融 |
| 基本面 | 季/年频 | 三表、营收、净利润 |
| 估值预期 | 日/实时 | PE-TTM、PB、一致预期 |
| 技术面 | 实时/分钟 | 价、量、盘口、逐笔 |
| 情绪资金 | 实时/日 | 北向、融资、舆情 |
| 另类数据 | 不定频 | 卫星、电商、招聘 |

**数据源优先级**：

```
财务三表：巨潮资讯 > Wind > 东方财富 > 腾讯
实时行情：腾讯财经API > 东方财富 > 雪球 > 新浪
北向资金：港交所披露易 > Wind > 东方财富
舆情情感：自建NLP > 财联社 > 微博 > 腾讯财经
```

#### Step 3: 数据复核与清洗

**多源交叉验证**：

```
差异率 < 1%  → 【高可信】权重1.0
差异率 1-5%  → 【存疑-已仲裁】权重0.9
差异率 ≥ 5%  → 【严重存疑】权重0.5 + 黄色预警
```

**财务粉饰七项检测**：
1. 应收与营收增速剪刀差
2. 存货周转与毛利率背离
3. 经营现金流与净利润匹配度
4. 关联交易依赖度
5. 审计意见一票否决
6. 商誉与净资产比例
7. 其他应收款性质突检

#### Step 6: 智能仓位与交易方案

**凯利公式**：

```
f* = (p × b - (1-p)) / b

修正：f_safe = f* × 风险偏好系数
     f_final = min(修正后仓位, 用户上限)
```

**仓位修正系数**：

```
保守型：f_safe = f* × 0.3（单票上限15%）
稳健型：f_safe = f* × 0.5（单票上限25%）
激进型：f_safe = f* × 0.7（单票上限35%）
```

**组合优化**：

```
w_target = λ × w_sharpe + (1-λ) × w_riskparity

λ动态调整：
- 趋势明显：λ=0.7
- 震荡市：λ=0.3
- 中性：λ=0.5

再平衡触发：|w_current - w_target| > 5%
```

**交易指令单**：

```
【交易指令详情】标的：股票名称（代码）

方向：买入（加仓）
委托类型：限价委托
限价价格：XX.XX元
委托数量：XX股
有效期：今日有效，14:55自动撤单

备选方案：[如撤单后的备选策略]
预估冲击成本：约XX个基点
风险控制：[触发止损的具体条件]
```

|:---|:---|:---|

**综合信号强度**：

```
[-2, +2]区间 → 执行等级映射
≥ +1.5：强烈积极信号 → 立即加仓
+0.8~+1.5：温和积极 → 考虑加仓
-0.8~+0.8：中性震荡 → 无操作
-1.5~-0.8：温和消极 → 考虑减仓
≤ -1.5：强烈消极 → 止损执行

自适应阈值：GARCH模型动态调整
```

#### Step 8: 每日深度复盘与机会挖掘

**五层归因法**：

1. 宏观与政策层
2. 指数与风格层
3. 情绪与资金层
4. 持仓个股异动归因
5. 自选股扫描与点评

**持仓逻辑重检**：

```
强制反事实提问：
「如果今天空仓，只有现金，
这个价位还愿意买吗？」

判定：
- 愿意 → 逻辑加强
- 条件性愿意 → 逻辑不变
- 不愿意 → 逻辑弱化
- 完全不愿意 → 逻辑破坏
```

**新机会挖掘**：

```
初筛条件：涨幅前30/跌幅前20/放量突破/创60日新高
二次筛选：至少满足3条
  - 基本面：营收净利增速>15%
  - 估值：PE/PB分位数<60%
  - 技术：均线多头+MACD金叉
  - 资金：北向连续净流入/机构席位买入
  - AI预判：5日上涨概率>60%
  - 事件：明确催化剂
```

#### Step 9: 行为偏差校准与干预

**十二维偏差监控**：

| 偏差类型 | 检测指标 | 阈值 |
|:---|:---|:---|
| 过度交易 | 日均交易次数/历史均值 | >2.0 |
| 追涨 | (买入价-均线)/均线 | >4% |
| 杀跌 | (卖出价-均线)/均线 | <-4% |
| 损失厌恶 | 亏损超10%持仓自然日 | >40天 |
| 处置效应 | 止盈持仓期/亏损持仓期 | <0.5 |
| 过度自信 | 当前仓位/平均仓位 | >1.3 |
| 确认偏误 | 忽略利空次数/总利空 | >70% |
| 羊群效应 | 热门股持仓占比 | >1.5 |
| 锚定效应 | |当前价-锚定价|/锚定价 | >15% |
| 后见之明 | 声称"早知道"次数 | >3次/月 |
| 心理账户 | 分账户管理资金占比 | >30% |
| 模糊厌恶 | 熟悉行业持仓占比 | >80% |

```
原始素材 → 数据质量审查 → 多源验证 → 15专家智能体深度分析
→ 逻辑链构建 → 不确定性量化 → 替代假设 → 合规确认
→ 洞察性结论

【禁止行为】
❌ 直接引用第三方报告作为最终结论
❌ 不验证就使用高风险数据
❌ 忽视数据冲突继续分析
❌ 将预测结果作为确定性结论
```

### 4.3 安全审核

**预审清单**：

```
1. 权限审核：是否请求敏感权限
2. 数据来源：是否可信、是否有隐私风险
3. 输出质量：历史准确率、已知缺陷
4. 合规性：是否符合数据保护法规
```

**风险分类**：

```
LOW → 直接集成
MEDIUM → 复核后集成
HIGH → 深度审核后集成
EXTREME → 禁止集成
```
