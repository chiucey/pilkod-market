# 爆款写作公式参考

## 一、标题公式库

### 1. 好奇心驱动类
| 公式 | 示例 |
|------|------|
| 数字+反差 | "月入3万和月入3000的人，差距到底在哪里？" |
| 问句+悬念 | "为什么同样努力，你却总是差一步？" |
| 揭秘/揭秘 | "揭秘：那些年入百万的人，都在偷偷用这个方法" |
| 限定词+悬念 | "全网都在找的答案，今天终于说清楚了" |

### 2. 干货合集类
| 公式 | 示例 |
|------|------|
| 数字+领域+大全 | "2024年最值得收藏的30个职场技巧" |
| 人群+痛点+方案 | "给所有职场人的10条生存法则" |
| 方法+效果 | "学会这3步，让你的效率提升300%" |
| 清单体 | "清单：入职第一周必须搞清楚的5件事" |

### 3. 情绪对立类
| 公式 | 示例 |
|------|------|
| 颠覆常识 | "别再努力了，这才是成功的真相" |
| 对比冲击 | "年薪50万和年薪500万的人，差的不只是钱" |
| 戳痛点 | "你那么努力，为什么还是过不好这一生？" |
| 情绪宣泄 | "受够了！这就是我不想上班的理由" |

### 4. 利益驱动类
| 公式 | 示例 |
|------|------|
| 免费+价值 | "免费送你一套价值9999的写作模板" |
| 秒懂+技能 | "一文搞懂什么是真正的用户思维" |
| 收藏+实用性 | "建议收藏：2024年最全避坑指南" |
| 限时+紧迫感 | "今晚删！内部流出的职场晋升攻略" |

## 二、正文结构模板

### SCQA模型示例
```
S（情境）： 最近，很多读者问我...
C（冲突）： 但现实是，大多数人做的方法都是错的...
Q（问题）： 到底应该怎么做？
A（答案）： 今天我来告诉你真正的答案...
```

### 剥洋葱结构示例
```
第一层（表象）：表面上看，xxx
第二层（原因）：但实际上，这是因为...
第三层（本质）：更深一层，你会明白...
第四层（行动）：所以，你应该...
```

### 故事+观点结构示例
```
【场景引入】
上周遇到一件事...

【冲突展开】
本来以为...结果却...

【观点抛出】
这件事让我意识到...

【延伸讨论】
其实，职场/生活/感情中...

【行动号召】
如果你也...不妨试试...
```

## 三、金句模板

### 触动型
- "xxx，才是真正的 xxx"
- "不是 xxx 太难，是你 xxx 太容易"
- "真正 xxx 的人，从来不 xxx"

### 共鸣型
- "我们都曾 xxx，只是后来..."
- "有时候，xxx 不是因为 xxx，而是因为..."
- "你以为自己 xxx，其实你只是在 xxx"

### 点睛型
- "xxx，不是 xxx，而是 xxx"
- " xxx 的背后，是 xxx"
- " xxx，恰恰是 xxx 的开始"

## 四、排版建议

### 引用块使用场景
- 重要数据出处
- 名人名言
- 读者留言/评论
- 核心观点强调

### 图片位置建议
- 开头：情绪引导图
- 中间：数据可视化图/对比图
- 结尾：总结金句图/互动图

### 段落节奏
- 痛点段落：短句+留白
- 分析段落：适当长句+逻辑连接
- 高潮段落：金句+视觉化表达
