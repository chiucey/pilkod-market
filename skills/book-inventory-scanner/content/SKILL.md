# 图书批量盘点技能

## 功能概述

本技能能够从书脊图片中自动识别并提取图书信息，支持批量处理多张图片，输出结构化的盘点报告。

## 核心能力

- **图像识别**：识别书脊上的文字信息
- **信息提取**：自动提取书名、作者、出版社、ISBN等元数据
- **批量处理**：支持一次处理多张书脊图片
- **盘点报告**：生成包含统计信息的汇总报告

## 使用流程

### 1. 图片输入

接收用户上传的书脊图片，支持以下格式：
- JPG / JPEG
- PNG
- WEBP

### 2. 图像预处理

- 自动调整图片方向
- 增强文字对比度
- 降噪处理

### 3. OCR识别

使用光学字符识别技术提取书脊上的文字，包括：
- 书名（通常最大、最醒目的文字）
- 作者姓名
- 出版社名称
- ISBN号码
- 其他可识别的出版信息

### 4. 信息结构化

将识别的文字信息解析为结构化数据：

```json
{
  "books": [
    {
      "index": 1,
      "title": "书名",
      "author": "作者",
      "publisher": "出版社",
      "isbn": "ISBN号码",
      "confidence": 0.95
    }
  ],
  "total_count": 数量,
  "summary": {
    "unique_titles": 0,
    "unique_authors": 0,
    "unique_publishers": 0
  }
}
```

### 5. 盘点报告生成

生成完整的盘点报告，包含：
- 图书总数统计
- 按出版社分布
- 按作者统计
- 未识别/模糊图片标记

## 输出格式

### 终端输出

```
📚 图书盘点报告
═══════════════════════════════

📖 总计清点：X 本图书

📋 详细信息：
1. 《书名1》- 作者：XXX | 出版社：XXX
2. 《书名2》- 作者：XXX | 出版社：XXX
...

📊 统计摘要：
• 涉及 X 家出版社
• 涉及 X 位作者
• 识别置信度：XX%

⚠️ 需要复核的图片：X 张
```

### 文件输出

可选导出为：
- JSON格式（机器可读）
- CSV格式（表格兼容）
- Markdown格式（文档友好）

## 适用场景

- 图书馆藏书盘点
- 书店库存管理
- 个人图书收藏管理
- 档案馆图书清点
- 企业图书角管理

## 注意事项

1. **图片质量**：书脊文字越清晰，识别准确率越高
2. **拍摄角度**：尽量垂直拍摄，避免严重倾斜
3. **光线条件**：避免强烈反光，确保文字可读
4. **批量限制**：建议单次不超过50张图片
5. **特殊书籍**：古籍、艺术画册等特殊装帧可能影响识别

## 错误处理

- 无法识别的图片将标记为"待复核"
- 提供每本书的识别置信度供参考
- 识别模糊时会提示具体需要人工确认的信息
