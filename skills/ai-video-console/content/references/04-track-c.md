## C1 装配

### 装配前准备

核对每镜编号、版本、时长、画幅、帧率、音频状态；识别可用入点出点、动作接点、
视线接点、声音锚点；口型素材标记不可变速区间；建立对白、环境声、拟音、音乐、
旁白的独立音轨逻辑。

### 顺序

1. 按剧本与已确认镜头结构建粗剪，先保证**叙事可懂**
2. 以人物表演、信息揭示、情绪变化定镜头长短
3. 用动作匹配、视线匹配、构图关系、声音桥或合理省略完成衔接
4. 加入环境声、拟音、对白与静默，建立空间连续性
5. 音乐最后服从叙事，不用音乐掩盖节奏问题
6. 完成画面连续性、声音、字幕与输出规格终检

### 节奏

切点优先级：人物决定或反应 → 动作完成点 → 信息出现点 → 声音重音 → 构图张力变化。
不平均分配时长，不为"快节奏"机械碎切。情绪镜头允许停留，但必须有表演或声音变化支撑。
动作场面保持方向、速度与力量连续，必要时压缩重复过程。悬念场面控制信息先后，
不用随机黑场或故障特效制造廉价悬疑。蒙太奇必须有统一概念、节奏或动作母题。

### 转场

默认优先：直切 → 动作切 → 视线切 → 声音桥 → 图形匹配 → 遮挡 → 自然光变。
只有故事世界和风格允许时才用显性特效转场。不得滥用溶解、闪白、故障、旋转、缩放。

### 声音

对白清晰度优先，环境底噪保持空间统一；J-cut / L-cut 与声音桥服务叙事预告、延续或反差；
拟音对应可见动作与材质；音乐不持续满铺，保留呼吸与静默；口型素材不得变速
（变速即破坏唇音同步）；仅保留指定音乐的项目，按规格静音其他视频自带音轨。

## C2 终检（逐镜）

- 故事信息是否完整、顺序是否清楚
- 人物身份、服装、道具、场景是否漂移
- 轴线、视线、运动方向、动作相位是否连续
- 光向、昼夜、天气、曝光、色彩是否突变
- 对白、口型、环境声与空间是否匹配
- 有无重复镜头、无功能镜头、过早切断或拖沓停留
- 有无生成错误：闪烁、融化、穿插、跳变或不可接受的物理问题
- 字幕、音乐、素材、品牌元素是否符合授权与平台规范

### 修复优先级

1. 剧情缺失、错序、台词错误
2. 身份漂移、空间跳轴、动作断裂
3. 口型与声音同步
4. 生成瑕疵与光色突变
5. 节奏、转场、声音精修

能靠换切点、插反应镜、声音桥或局部重生成修复的，不重做整段。
修复会改变重大创作方向的，先请求确认。

## C3 交付

严格按台账输出分辨率、比例、帧率、语言、字幕、安全区、音频与文件规格。

输出前给出简洁终检结论：**已通过项 / 仍存风险 / 是否满足交付标准**。
不得虚报完成或掩盖失败镜头。

交付后回写台账：最终时间线版本、所用镜头版本、声音版本、输出规格、剩余风险、
交付状态。只有全部强制项通过才可宣布项目完成；否则停在 C2 并列出最小修复任务。
