## A1 立项

### 素材盘点（用户提供剧本、图、视频、音频时）

先判断媒介（真人实拍 / 动画 / 混合媒介），**不明则暂停询问**，不得默认。

**剧本与文档**：保持原剧情、事件顺序、台词和节奏，提取场次、时空、人物关系与目标阻力、
核心事件与情绪转折、必须保留的原话旁白字幕品牌数据、造型与场景与道具的状态变化、
生成难点与连续性风险。区分三类信息——**可观察事实 / 专业判断 / 无法确认**，
不得把推断写成事实。

**图片与参考**：按证据提取主体外观、服装妆发材质与时代地域、场景结构与前中后景、
道具形态与持有方式、构图景别机位焦段、主光方向光比色温、表演瞬间与可延续状态、
媒介质感与 AI 味风险。

**视频与参考片**：**按镜头而非固定秒数**拆解——时码、切点、景别、相机运动轨迹与速度、
动作接点、轴线与空间重建、焦点转移、表演节拍、声音桥。不得把 zoom 写成 dolly，
不得把人物移动误判为相机移动，无法确认标"待验证"。

**音频**：总时长、节拍、重音、人声特征、可作切点的同步锚点，以及**是否允许变速、
裁切、重新配音**（这一项直接约束交轨）。

### 立项单必含

媒介、题材与核心情绪、目标时长、**四维决策**（时长档 × 画幅 × 风格 × 画质）、
语言、发布平台、交付范围（全流程或指定工位）、不可修改限制（剧本/台词/人物/品牌/
地域/时代/平台）。

四维决策在立项时一次锁死；中途变更任一维会引发全链路回退，属确认关卡事项。
涉及已有 IP 时，品牌名与主色调在立项即标记为硬锁。

### 竖屏短剧/参赛项目：开场钩子（条件分支）

仅当项目为竖屏短剧、信息流短视频或参赛作品时启用：

- **前 3 秒**：视听强打断——冲突、悬念或反常画面直接呈现
- **前 10 秒**：强化矛盾或刻意误导，抬高预期偏差
- **前 30 秒**：底牌揭晓或第一次反转兑现，锚定追看理由

**原创性红线**：结构方法可以学，人物、关系、职业、场景、反转、关键道具、核心台词、
反转顺序、结尾悬念——换名字换时代照搬也算抄袭。参赛项目须先过平台与赛事原创合规。

## A2 定调

建立全片视觉圣经，输出至少八项：

1. 媒介工艺与真实度边界
2. 摄影系统与焦段使用原则
3. 曝光、对比、高光过渡、暗部信息、动态范围
4. 主色、辅色、强调色、肤色与综合色彩关系
5. 光线动机、光质、色温关系、昼夜继承规则
6. 美术材质、年代、地域、去 AI 味约束
7. 可变的场景规则与不可跨镜锁死的内容
8. 负向视觉禁忌

先确认各参考对象**各自负责的维度**，不用一部片子包办全部审美。按三域模型分离后
（见 `01-ledger.md` 第二节），**只把全域写进 @FILM_SEAL**，经用户确认后生效。

未确认影调封印，闸一不开。

## A3 排镜

### key_element 契约（编剧层与生产层的交接契约）

```
契约（随锁定剧本交付，写入台账资产索引区）
├── 角色：名称 → 所需视图（三视图/表情/动作）→ 首次出场场次 → 造型变化点
├── 场景：名称 → 所需视图（空镜/四视图/俯视布局）→ 出场场次 → 昼夜天气状态数
├── 道具：名称 → 所需图 → 归属角色 → 状态变化链
├── 服装：角色 × 场次 → 造型版本 → 切换点
└── 声音：对白/旁白清单 → 音色要求 → 可否重新配音
```

契约是硬约束：造料按契约逐项交付打钩，契约外不造，契约缺项先补齐再排镜。
剧本修订时先做契约 diff，再按回退矩阵执行。

### 主要分镜 @MK

只提取**真正承担叙事、视觉或情绪功能**的主要分镜，不做全片镜头总表。每个 @MK 必须：
对应剧本原句或事件｜说明镜头功能与观众此刻获得的信息｜引用资产编号｜
明确景别机位构图人物位置视线动作相位与空间关系｜给出声音锚点与前后衔接条件｜
仅在叙事需要时使用特殊机位或复杂运动。

重大镜头先出导演级方案供确认，不直接生成。

### 连续镜头 @SH

仅从已确认 @MK 向前后扩展，按叙事需要安排主机位、副机位、反应、插入、环境与动作细节，
**不套固定数量或机械九宫格**。每次切镜必须至少完成一项功能：
提供新信息 / 改变情绪距离 / 强化人物选择或反应 / 完成空间重建 / 遮蔽生成难点 / 建立剪辑点。

**连续性必检**：180 度轴线、视线匹配、运动与出入画方向；动作接点、手势、身体朝向、
姿态与表情相位；人物道具服装场景位置；时间天气光向色温曝光；景别差异是否足够
（避免无意义跳切）；声音桥与底噪衔接。

### 镜头描述固定字段

```
镜号与版本 ｜ 对应剧本原文 ｜ 镜头功能 ｜ 建议时长 ｜ 资产引用
景别、机位、焦段倾向、构图
相机运动：起点、路径、速度变化、终点
人物表演：意图、动作节拍、视线、微表情
环境与物理变化
对白、环境声、拟音、音乐
入镜状态、出镜状态、剪辑点
连续性与生成风险
```

"推进、环绕、摇镜、跟拍"必须写清运动主体、方向、路径、速度与结束构图，
**禁止只写"电影感运镜"**。

### 表演与声音预案

动作来自人物目标与场景压力，不用"震惊/悲伤/开心"这类空泛词；优先可观察行为——
停顿、呼吸、视线落点、重心变化；对白标注对象、潜台词、节奏、重音与动作支点；
明确主反应与次反应，不让所有人同时做大动作。

分镜阶段预埋：对白起止、动作重音、环境声桥、音乐进出、静默、转场声。
口型镜头必须给出原句、说话人、可见口型范围与不可变速约束。

### 输出纪律

先交主要分镜供确认，再扩展连续镜头；每次只提交一个层级（视觉方向 → 资产方案 →
主要分镜 → 连续镜头）；分镜、提示词、剪辑清单不得混成一份模糊文档。
