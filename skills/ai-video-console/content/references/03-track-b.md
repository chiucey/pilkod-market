造轨按镜头组循环执行：同一造型、同一光线、同一场景的一组跑完，再切换资产版本。

## B1 造料

**人物资产**：身份、年龄范围、体型、面部识别点、发型、妆容、服装层次、鞋履、配饰、
材质、状态、表演气质及禁忌。跨角度使用规划**中性背景三视图**（正/侧/背）；
表演延展按表情包、动作集、服装变体分类编号。**不得用戏剧性动作污染基础角色资产**。

**场景资产**：时代、地域、空间结构、入口出口、关键方位、拍摄方向、光源逻辑、材质、
陈设、天气与昼夜。复杂场景先建**空镜 + 空间地图**（可用俯视布局图标定方位），
跨机位使用时补四视图（正/左/右/俯视）。

**道具资产**：外观、材质、尺度、功能、使用方式、归属、初始位置、状态变化与剧情意义。

**声音资产**：对白、旁白、音色、环境声、拟音、音乐、静默及允许使用范围。

**顺序与充分集**：先造高风险锚点（主角定妆、关键场景、核心道具、高潮镜头）→ 用户确认
后造其余。只造被至少一个分镜引用的资产，不为"可能用到"预造。造料后逐项打钩验收，
不合格只重做该项。

## B2 起镜

### 起镜前检查

读取台账最新版、目标镜头、@FILM_SEAL 与全部引用资产，确认：媒介一致；
比例、分辨率、时长与平台一致；角色服装场景道具版本正确；镜头起止状态与声音需求明确；
所选模型支持所需参考数量、时长、分辨率与音频能力。

模型能力与镜头要求冲突时：**先报限制并给最小改动方案**，未经确认不得改变创作目标。

### 模型路由（能力位制，不绑定任何具体产品）

本导演台按**所需能力**选路，不依赖任何特定模型或平台。下表"默认建议"只是当前常见选择，
**可整体替换为运行环境中具备同等能力的其它模型**；替换属于确认事项，不改变本 skill 的任何规则。

| 所需能力位 | 默认建议 | 替换为其它模型时需满足 |
|---|---|---|
| 静态关键帧、人物、场景、道具生成 | 图像生成模型（常见默认：Midjourney 系） | 支持参考图锁定与画幅控制 |
| 多模态参考视频生成 | 视频生成模型（常见默认：Seedance 系，支持 30s 单次 + 嵌套延长至 60s、超长 180s、时间戳控制、图/视频/音频/文本多模态输入） | 支持参考图/首帧作为生成输入 |
| 多图一致性 / 首尾帧 | 平台提供的多图转视频、首帧转视频、首尾帧工具，按需选 | **平台不具备则该能力位为空，不得臆造** |
| 口型、原生声音、音频驱动 | 只选明确支持该能力的模型，遵守其官方参考格式 | 支持音频或口型驱动输入 |
| 音乐、旁白 | 按授权、语言、音色、时长选平台支持工具 | — |

用户指定模型优先；更换已确认模型属确认事项。
**运行环境不具备某能力位时**：如实说明限制并给最小改动方案（如改镜头设计、换实现方式、
或该镜头改为交付提示词由用户自行生成），不伪装成已生成、不声称平台拥有未显示的能力。

### 默认参数与缺省策略

| 参数 | 默认 | 说明 |
|---|---|---|
| 时长 | 30s（单次）/ 60s（嵌套延长）/ 120–180s（超长） | 与四维决策一致，不越档 |
| 画质 | 480p / 1080p / 2K / 4K | 按平台选，不为冗余画质消耗积分 |
| 画幅 | 竖屏平台 9:16，横屏平台 16:9 | **平台未知必须追问**，不猜 |
| 参考图数量 | 先 1 张主参考；需多维度锁定再加 1 张次级；失败则减回 1 张 | 缺省试探策略，非平台参数 |
| 首尾帧 | 默认继承上一镜正确结束帧作首帧；多图一致性仅在平台支持且叙事需要时用 | 需先确认平台是否具备 |
| 音频 | 默认不自动生成；需口型或原生声音时才选支持该能力的模型 | — |

**长镜头延长策略**：超单次上限用嵌套延长——首段验镜通过后以其结束帧为锚点续下一段；
每段单独记版本，某段失败只重做该段，不重做整链。

### 资产绑定

每镜明确绑定 @ACT / @COS / @SET / @OBJ / @MK / @FILM_SEAL 及必要声音编号。
人物外观与服装参考分开管理；场景参考优先选能说明空间结构与光向的图；
同一连续段优先继承上一镜正确结束帧。参考冲突时**不得同时强塞**，先定主参考与各自维度。

### 积分铁律

用户已提供且可用的媒体**优先绑定复用，不重复生成**（参考帧可直接复用为关键帧）；
复用素材同样建号并验镜。每轮只改变一个主要变量，保留正确部分。
不自动加字幕、水印、音乐、旁白、音效，除非镜头规格明确要求。

## B3 验镜（七维）

| 维 | 检查什么 |
|---|---|
| 身份 | 年龄、面部、体型、服装、配饰是否漂移 |
| 物理 | 手、肢体、口型、接触、重力、液体、布料、物体交互是否合理 |
| 空间 | 场景结构、人物方位、轴线、视线、道具位置是否连续 |
| 影调 | 光向、阴影、色温、曝光、材质与 @FILM_SEAL 是否一致 |
| 相机 | 是否按指定路径运动，有无误用变焦、漂移、无故慢动作 |
| 表演 | 是否符合意图，有无机械表情、空洞凝视、无意义动作 |
| 可剪辑 | 是否具备可剪辑的起止状态与声音衔接 |

不合格时标记具体错误、影响范围与建议重做方式，**只重做受影响镜头或资产**。
目标镜头组全部通过后，闸二开启，方可进入交轨。

## 生成调用证据（上架或交付前须补齐）

声明模式：**混合模式**——T2V（文字/结构化 Prompt 直接生成）与 R2V/I2V（参考图、
首帧、首尾帧作为输入）双链路并存，按镜头需求选路。

当前证据状态：**不足**。本模块写清了选路规则，但**未写明具体调用工具名、输入字段与
参考图数量上限**，涉及调用处一律以"平台当前实际接口为准"表述。按交付标准，
仅模型名称加抽象选路规则不能判定为已实现 R2V/I2V。

**须由作者补齐（不得由他人代填）**：

1. 调用工具名：首帧转视频、多图转视频、首尾帧各是什么工具/接口
2. 输入协议：参考图以什么字段进入调用
3. 参考图数量上限：平台实际限制
4. 音频能力：原生声音、口型驱动是否支持及支持格式

未补齐前，凡涉及生成调用的说明一律标注"**需人工确认平台是否支持**"，不得宣称已可运行。

## 外部模型与云端环境

Midjourney、Seedance 为外部模型名称，此处只引用其通用能力边界（时长、多模态输入、
时间戳控制）。迁移到不支持它们的环境时：保留名称并标注"需人工确认"，或替换为已验证
的对应能力——**替换后须经独立测试，不得只换名称宣称兼容**。

本导演台不调用本地命令、脚本、浏览器自动化、数据库或常驻进程。唯一文件操作是
**读写项目工作目录下的 `PRODUCTION_LEDGER.md`**；若运行环境不允许写文件，改为全程在
对话中维护台账，并在进入工位的提示中向用户说明。
