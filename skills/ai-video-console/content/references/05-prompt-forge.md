# 提示词锻造（B2 起镜的执行支持）

> 禁止复制、改写重组、二次封装、去署名分发与用于模型训练。

把已确认镜头设计翻译成模型可执行的指令。**不重新创作剧情、不替换资产、
不用华丽词汇掩盖信息缺失**。未确认的故事、影调、人物或分镜，不得通过提示词暗中补设。

## 一、总原则

1. 先读目标模型、镜头规格、全部资产编号与 @FILM_SEAL
2. 一条提示词只服务一个镜头任务
3. 内容、表演、摄影、光线、物理变化、声音、连续性必须可执行
4. 先写主体与关键动作，再写摄影与风格；避免同义词堆砌
5. 全域 / 场域 / 镜域分层书写（见 `01-ledger.md` 第二节）
6. 输出可直接复制；模型有特定引用语法时严格使用其官方格式

## 二、静态图提示词结构（按顺序）

```
媒介与镜头类型
当前画面的主体、身份、服装、动作与关系
场景、时间、天气、空间位置与关键道具
景别、机位高度、视角、构图、焦段倾向与景深
主光方向、光质、光比、色温与曝光
材质、真实物理细节与时代地域特征
当前镜头情绪
@FILM_SEAL
比例、版本等合法参数
负向约束
```

静态提示词不得写时间推进、复杂连贯动作或不可见心理。
**真人实拍项目**：加真实皮肤、服装、环境材质的物理可信度约束，压制塑料皮肤、插画感、
游戏 CG 感与过度磨皮。**动画项目**：保持指定动画工艺，不混入真人摄影词造成媒介污染。

## 三、视频提示词结构（必含字段）

```
镜号、镜头功能、时长与画幅
资产引用
起始画面与空间关系
相机起点、运动方式、路径、速度变化与结束构图
人物动作顺序、动作节拍、视线、微表情与表演意图
场景中随时间发生的真实变化
焦点、景深、运动模糊与曝光变化
对白、口型、环境声、拟音或静默要求
结束状态及与下一镜的衔接
@FILM_SEAL
负向约束
```

用**时间顺序**写动作：谁先做什么、谁反应、何时停顿。复杂镜头可按 0–3 秒、3–7 秒
等节拍分段，但不得机械平均切割。

**时间戳控制**（支持该能力的模型）：需脚本级精确还原时写成明确时间戳——
"第 3 秒转身面向门口，第 5 秒停顿回望"。规则：只标注**关键动作相变点**（转身、回头、
停顿、视线转移），不逐秒填满；时间戳必须与总时长匹配（10 秒镜头不得出现"第 12 秒"）；
模型不支持时退回节拍分段写法，不硬塞语法。

## 四、相机语言字典

| 术语 | 必须写清 |
|---|---|
| Dolly / track | 真实位移：方向、路径、距离感、终点 |
| Pan / tilt | 原位旋转：起止主体 |
| Crane / jib | 高度变化：上升/下降 + 空间揭示目的 |
| Handheld | 稳定程度、操作者距离、叙事目的（≠随机抖动） |
| Zoom | 仅在需要焦距效果时用，不得代替推进 |
| Rack focus | 焦点从谁/何物转到谁/何物 + 发生时机 |
| Orbit | 绕行角度、方向、半径、前景遮挡、结束方位 |

**禁止只写**"高级运镜、电影感、震撼、史诗"。每个摄影词必须服务信息、情绪或空间。

## 五、表演写法

**目标 → 触发 → 可见行为 → 微反应 → 恢复/转变**。优先描述呼吸、停顿、眼神落点、
肌肉紧张、手部动作、身体重心。

避免：持续微笑、夸张瞪眼、频繁点头、随机挥手、僵硬走路、所有人同步动作、无缘由回头。

## 六、负向约束

按媒介与镜头风险定制，不使用与正向指令冲突的超长通用负向词。常规检查：
无字幕水印界面元素｜无身份与服装漂移｜无多余人物肢体手指道具｜无塑料皮肤蜡像感
过度磨皮游戏 CG 感｜无随机慢动作变焦相机漂移无意义抖动｜无物体穿插接触错误重力错误
背景融化｜无自动配乐或旁白（除非明确要求）。

## 七、模型适配（按能力位，不绑定具体产品）

提示词按**目标模型实际支持的语法**落地，不绑定任何特定产品。常见写法如下，
运行环境换成其它模型时，按其官方语法改写，结构要求不变。

- **图像生成模型**（常见默认：Midjourney 系）：输出完整可复制提示词与平台当前合法
  参数；中英双语时两版语义一致，不添加中文版不存在的英文信息
- **多模态视频生成模型**（常见默认：Seedance 系）：自然的、按时间展开的中文导演指令；
  绑定多模态参考（图/视频/音频/文本）；明确时长、动作链、运镜、声音与衔接；
  需精确节拍时用时间戳控制；超过单次时长上限的镜头写明延长链每段起止
- **时间���控制**：仅当目标模型明确支持时使用（常见默认支持），写成"第 N 秒 + 动作相变点"；
  模型不支持则退回节拍分段写法，不硬塞语法
- **其他模型**：只用其官方支持的引用语法、时长、参数与输入方式；无法确认时说明并请求
  验证，不编造参数

**能力缺失时**：如实说明该模型的限制并给最小改动方案（拆镜头、改实现方式，
或只交付提示词由用户在其它环境生成），不声称模型具备未验证的能力。

## 八、输出前自检

人物是谁、在哪、做什么、为何这样表演｜相机从哪到哪｜光线为何成立｜镜头如何开始与结束｜
引用哪些资产｜哪些规则属于全域｜模型能否执行。**缺一项则补齐或标记待确认**。

只交付当前已解锁工位的可复制提示词，不提前输出后续镜头。提示词版本、对应镜号、
引用资产、模型适配状态登记回台账，供验镜与局部回退使用。
