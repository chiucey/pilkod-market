# 金价日报技能 (Gold Price Daily Report)

## 技能概述

本技能用于每日自动生成金价日报，帮助用户了解黄金市场动态并做出投资决策。

## 核心功能

### 1. 数据采集
- **国际金价**：从 CME-COMEX、LBMA、金投网 等获取
- **国内金价**：从 上海黄金交易所(SGE)、上海期货交易所 获取
- **宏观指标**：美元指数、美债收益率、人民币汇率
- **资金流向**：SPDR黄金ETF持仓、CFTC持仓报告
- **央行动态**：全球央行购金数据（来源：世界黄金协会WGC）

### 2. 日报生成
按照【金价日报提纲.md】的结构生成完整报告，包含：
- 核心摘要（简洁明了）
- 市场数据复盘
- 驱动因素分析
- 分周期走势预测
- 投资建议

### 3. 数据存储
- **JSON数据文件**：`{日期}-金价数据.JSON`
- **日报文件**：`{日期}-金价日报.MD`

## 使用方法

### 基本命令
```
/gold-price-daily
```

### 首次运行
首次运行时，技能会：
1. 生成当日金价日报
2. 等待用户确认效果
3. 如满意，设置每日定时任务（早上9点推送）

### 定时任务
设置成功后，每天早上9点自动：
1. 采集最新金价数据
2. 生成金价日报
3. 推送至用户

## 数据来源优先级

| 优先级 | 数据类型 | 来源 |
|--------|----------|------|
| ★★★★★ | 国内金价 | 上海黄金交易所(SGE) |
| ★★★★★ | 国际金价 | CME-COMEX, LBMA |
| ★★★★★ | 央行购金 | 世界黄金协会(WGC) |
| ★★★★★ | ETF持仓 | SPDR Gold Trust |
| ★★★★☆ | 财经数据 | 金投网、汇通网 |

1. **数据延迟**：部分实时行情存在15分钟延迟
2. **数据核实**：核心数据通过多源交叉验证
3. **风险提示**：本报告仅供参考，不构成投资建议
4. **定时任务**：首次运行后需用户确认再设置
