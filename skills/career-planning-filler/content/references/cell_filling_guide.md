# Cell Filling Guide

This reference describes what to fill in each red-font cell of the career planning Excel template. Extract information from the student's resume and combine with industry knowledge.

## Cell Mapping

| Cell | Section | What to Fill |
|------|---------|-------------|
| B3 | 背景挖掘 | Student location, education (school/major/GPA/courses), internships, skills, language proficiency, career intent |
| B4 | 归国时间及求职时间线 | Graduation date, return date, applicable recruitment seasons (autumn/spring), which season is primary |
| B5 | 可行性就业方向 | Recommended target industries based on background, skills, and experience |
| B6 | 求职方向与企业 | Specific companies and matching positions per direction |
| D12 | 实习留用 | Whether target companies offer internships, intern-to-full-time conversion rates |
| D13 | 校招/社招 | Campus recruitment scale, whether social recruitment exists |
| D14 | 专业知识或技能提升 | Skills gaps to address, specific improvement recommendations |
| D15 | 项目科研经历 | Existing resources (school, projects), recommended additions (competitions, open-source, research) |
| D16 | 实习申请建议 | Timeline, target companies, application channels, preparation tips |
| D17 | 证书考试 | Recommended certifications with priority ranking |
| D18 | 其他注意事项 | GitHub, blog, interview prep, networking, visa planning, resume versioning |

## Direction-Specific Guidance

Read the relevant section below based on the student's target role.

### Algorithm / ML Engineer Direction

- Emphasize: LeetCode (300+ problems), Kaggle competitions, PyTorch/TensorFlow projects, system design
- Companies: ByteDance, Tencent, Alibaba, Baidu, SenseTime, Megvii, iFlytek
- Certifications: Low priority (practical experience > certificates); optionally recommend cloud ML certs
- Skills to develop: Deep learning frameworks, distributed computing, MLOps, LLM/RAG

### Quantitative Finance Direction

- Emphasize: Probability/statistics, stochastic calculus, strategy backtesting, factor models
- Companies: CICC, CITIC Securities, Huatai Securities, Nine Chapters, High-Flyer, Two Sigma, Citadel
- Certifications: CFA Level 1, FRM
- Skills to develop: High-frequency trading, options pricing, alternative data, C++ optimization

### Data Analysis / Data Science Direction

- Emphasize: SQL proficiency, A/B testing, statistical modeling, visualization (Tableau/PowerBI)
- Companies: ByteDance, Meituan, Didi, JD, PDD, banks' fintech departments
- Certifications: Google Data Analytics, AWS Data Analytics
- Skills to develop: Causal inference, experimentation platforms, business acumen

### General Software Engineering Direction

- Emphasize: System design, distributed systems, algorithms, project experience
- Companies: Major tech companies, unicorn startups
- Certifications: Low priority
- Skills to develop: Cloud platforms, CI/CD, microservices architecture
