## 分析内容

### 宏观经济分析要点

1. **增长趋势分析**：分析各项指标的月度/季度变化趋势
2. **结构分析**：分析经济结构变化（如三产结构、投资消费结构）
3. **对比分析**：与上年同期数据进行同比分析
4. **关联解读**：分析各指标之间的关联性和经济含义

### 能源行业分析要点

1. **生产供应**：分析能源生产总量和结构变化
2. **消费需求**：分析能源消费趋势和季节性特征
3. **价格走势**：分析国际油价波动及影响因素
4. **安全评估**：评估能源供应保障能力

## 输出要求

### 1. 结构化分析报告

报告应包含：
- 报告日期和数据更新时间
- 各指标最新数值和同比变化
- 趋势分析和对比解读
- 数据来源标注
- 主要发现和展望

### 2. 交互式可视化仪表板（可选）

使用 React + ECharts 构建双页签仪表板：

**页签一：宏观经济数据**
- 核心指标卡片（GDP、固定资产投资、消费、工业增加值、进出口、CPI、PPI、PMI）
- GDP季度趋势柱状图
- 投资与消费折线图
- 工业与进出口组合图
- CPI/PPI走势对比图
- PMI走势图（含荣枯线）
- 详细数据表格

**页签二：能源行业数据**
- 核心指标卡片（用电量、天然气、煤炭、原油产量、油价）
- 用电量月度趋势图
- 能源生产趋势图
- 电力消费结构饼图
- 天然气消费量柱状图
- 国际油价走势图
- 详细数据表格

**设计规范**：
- 背景色采用浅色系（白底+蓝色渐变）
- 图表使用 ECharts 实现交互
- 支持悬停显示详细数据
- 响应式布局适配各种屏幕

## 快速执行模板

当用户请求分析时，按以下步骤执行：

1. **并行数据采集** - 使用 `batch_web_search` 同时搜索宏观和能源数据
2. **数据整理** - 汇总各指标最新值和同比变化
3. **分析解读** - 分析趋势、对比上年同期、解读经济含义
4. **报告生成** - 生成结构化分析报告（Markdown）
5. **可视化开发**（可选）- 创建交互式仪表板
6. **部署发布** - 部署可视化应用并提供访问链接

## 数据来源参考

- **国家统计局** (stats.gov.cn) - 经济普查、GPD、工业、投资、消费、价格指数
- **国家能源局** (nea.gov.cn) - 电力、煤炭、新能源
- **国家发展和改革委员会** (ndrc.gov.cn) - 天然气运行快报
- **海关总署** (customs.gov.cn) - 进出口数据
- **NYMEX/ICE** - 国际原油期货价格
