# 第3章 商业分析 — 生成指引

> 此章节因产品定型不同而差异最大，请先确认产品定型。

## 章节目标

从商业视角分析产品的市场空间、竞争格局和差异化定位。

> 💡 方法论基础：商业化产品：STP市场细分 + 竞品分析框架；企业自研：三层业务调研

## 质量标准

- [ ] 商业化产品：客户画像具体到行业+规模+阶段

- [ ] SaaS产品：有SaaS关键指标预估
