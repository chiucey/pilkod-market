# Capability Self-Assessment（能力自评技能）

## 核心职责

在执行任何任务前，实时评估智能体的置信度与完成概率，据此做出明智的行动决策。

## 评估维度

### 1. 技能匹配度 (Skill Match)
- 所需技能是否已加载
- 技能熟练度等级（基础/熟练/专家）
- 技能版本是否为最新

### 2. 知识覆盖度 (Knowledge Coverage)
- 任务领域是否在训练知识范围内
- 所需专业知识是否具备
- 是否有知识盲区

### 3. 工具可用性 (Tool Availability)
- 完成任务所需的工具是否可用
- 工具权限是否充足
- 工具调用是否稳定

### 4. 任务复杂度 (Task Complexity)
- 任务步骤数量
- 任务之间的依赖关系
- 潜在错误点数量
- 时间/资源需求

### 5. 历史成功率 (Historical Success)
- 类似任务的历史表现
- 失败模式分析
- 改进空间评估

## 置信度计算公式

```
置信度 = Σ(维度权重 × 维度得分) / Σ权重

默认权重配置:
- 技能匹配度: 30%
- 知识覆盖度: 25%
- 工具可用性: 20%
- 任务复杂度: 15%
- 历史成功率: 10%
```

## 决策矩阵

| 置信度范围 | 决策 | 行动 |
|-----------|------|------|
| 90%-100% | 高置信度 | 直接执行，保持用户更新 |
| 70%-89% | 中高置信度 | 执行，必要时主动确认 |
| 50%-69% | 中低置信度 | 执行前向用户确认方案 |
| 30%-49% | 低置信度 | 触发 SISE 技能补全，或向用户寻求澄清 |
| 0%-29% | 极低置信度 | 拒绝执行，详细说明原因 |

## 执行流程

### Step 1: 任务解析
- 提取任务核心需求
- 识别所需技能清单
- 识别所需工具清单
- 评估任务边界

### Step 2: 多维度评估
```
对每个维度进行 0-100 评分:
- 技能匹配度: 检查技能库，评估匹配程度
- 知识覆盖度: 评估知识边界
- 工具可用性: 验证工具可用性
- 任务复杂度: 分析任务结构
- 历史成功率: 查询历史案例
```

### Step 3: 置信度计算
- 应用加权公式计算总体置信度
- 识别关键风险点
- 标记需要澄清的模糊点

### Step 4: 决策输出
- 输出置信度分数
- 输出关键发现
- 输出行动建议
- 如需澄清，生成具体问题列表

## 输出格式

```

[任务的核心描述]

### 置信度评分
**总体置信度**: XX%
**评估时间**: [时间戳]

### 维度得分
| 维度 | 得分 | 说明 |
|-----|------|------|
| 技能匹配度 | XX/100 | [简要说明] |
| 知识覆盖度 | XX/100 | [简要说明] |
| 工具可用性 | XX/100 | [简要说明] |
| 任务复杂度 | XX/100 | [简要说明] |

```

## 触发条件

自动触发于以下场景：
1. 用户提出新任务时
2. 用户询问"能做吗"时
3. 任务涉及未知领域时
4. 连续失败后的新尝试时
5. 执行前需要决策时

## 注意事项

1. **保守原则**：在不确定时，倾向于给出较低的置信度
2. **透明原则**：如实报告能力边界，不夸大不隐瞒
3. **主动原则**：主动识别风险并提出澄清需求
4. **学习原则**：根据执行结果更新评估模型

## 集成指南

此技能可被主代理在以下时机调用：
- 任务接收时（前置检查）
- 任务规划时（风险评估）
- 任务执行中（实时调整）
- 任务完成后（结果复盘）
