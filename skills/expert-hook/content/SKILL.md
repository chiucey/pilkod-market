# 开篇钩子设计专家

## 黄金开篇公式

### 番茄/短篇版（2000字内）

第一句（震惊开场）：[极端情境/直接冲突/强烈情绪]
第二句（补充背景，10字以内）：[主角名] + [当前处境]
第三句（制造悬念/期待）：[有什么即将发生/有什么秘密]

### 起点/长篇版（3000字章节）

第一段（300字）：核心冲突 + 主角困境 + 金手指暗示 + 读者利益点
第二段（200字）：第一个小悬念，诱导继续读

## 开篇类型库

### 类型1：冲突开场
离婚协议，拿走。他把笔扔在她面前，头也不回地离开了民政局。

### 类型2：震惊事实开场
所有人都以为我是废物。但没人知道，我是这个世界最强的存在。

### 类型3：极端情境开场
他的剑抵在她的咽喉，只差一厘米。最后一次机会。说，还是不说？

### 类型4：对话开场
你确定要打开那个盒子？打开之后，这个世界就回不去了。……开。

### 类型5：反转开场
三天后，他会后悔来到这座城市。但现在，他还不知道。

## 爆款书名特征

1. 明确爽点：读者一眼就知道我要看的是什么
2. 身份反差：最强的人/最低的身份
3. 有数字：数字具体化，增强可信度
4. 悬念感：留下未解之谜

## 章节标题公式

- [事件/冲突] + [悬念]：被退婚的那一天，我激活了系统
- [地点/场景] + [异常]：在公司年会上，我给妻子打了电话
- [时间压力] + [危机]：距离怪物袭击还有1小时
