# 债务还款分析技能 - 使用指南

## 功能概述

本技能帮助用户分析个人或家庭的债务情况，生成详细的还款报表，并提供还款策略优化建议。

## 输入格式

### 标准表格格式
```
债务名称 | 类型 | 本金 | 年利率(%) | 期限(月) | 已还月数 | 月还款额
信用卡1  | 信用卡| 50000 | 18     | 12      | 3        | 4500
信用贷1  | 信用贷| 100000| 12     | 24      | 6        | 5000
```

### 自然语言格式
```
"我欠了信用卡5万，年利率18%，已经还了3个月，每月还4500；
另外还有信用贷10万，年利率12%，24期，还了6个月，每月5000；
房贷200万，年利率4.9%，360期，还了12个月，每月10600"
```

## 支持的债务类型

| 类型标识 | 说明 |
|---------|------|
| 信用卡 | 信用卡透支消费 |
| 信用贷 | 无抵押信用贷款 |
| 房贷 | 房屋按揭贷款 |
| 车贷 | 汽车消费贷款 |
| 消费贷 | 消费分期贷款 |
| 网贷 | 网络借贷 |
| 其他 | 其他类型债务 |

## 输出报表内容

### 1. 负债概况
- 总债务笔数和本金
- 月还款压力
- 加权平均利率
- 期限分析

### 2. 债务明细表
- 各债务完整信息
- 利率对比
- 进度对比

### 3. 还款进度可视化
- ASCII进度条
- 已还本金/利息
- 剩余情况

### 4. 利息分析
- 已付利息统计
- 预估剩余利息
- 利息成本占比

### 5. 还款策略对比
- **雪球法**：优先还清余额最小的债务
  - 优点：快速获得成就感，心理激励强
  - 缺点：整体利息支出可能较高

- **雪崩法**：优先偿还利率最高的债务
  - 优点：数学最优，整体利息最少
  - 缺点：前期进度可能不明显

### 6. 优化建议
- 基于利率分析的建议
- 额外还款效果估算
- 债务置换建议

## 常用计算公式

### 等额本息月供计算
```
月供 = 本金 × 月利率 × (1+月利率)^期数 / [(1+月利率)^期数 - 1]
```

### 已付利息计算
```
已付利息 = 月供 × 已还月数 - 已还本金
```

### 剩余本金估算
```
剩余本金 = 原本金 × (1 - 已还月数/总期数)
```

## 策略选择建议

| 用户情况 | 推荐策略 |
|---------|---------|
| 自律性较弱，需要激励 | 雪球法 |
| 追求利息最小化 | 雪崩法 |
| 高利率债务占比高 | 雪崩法 |
| 多笔小债务心理压力大 | 雪球法 |
| 收入稳定且有额外还款能力 | 雪崩法 |

## 注意事项

1. **数据精度**：报表基于用户输入数据计算，假设数据准确
2. **利息估算**：总利息为预估，实际可能因还款日提前等因素略有差异
3. **提前还款**：未考虑提前还款违约金，如有请自行调整
4. **多币种**：如有外币债务，请统一换算为人民币
5. **复利计算**：部分计算采用简化估算，精确值请以银行账单为准
