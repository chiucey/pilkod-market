# Agent 角色管理技能

## 1. 功能概述

本技能为 MaxClaw 提供完整的 Agent 角色生命周期管理能力，涵盖角色定义、权限绑定、技能挂载、角色切换、审计追踪等核心功能。所有角色操作均遵循最小权限原则，确保系统安全合规。

## 2. 核心功能模块

### 2.1 角色定义

#### 2.1.1 基本信息配置
| 配置项 | 说明 | 示例 |
|--------|------|------|
| 角色名称 | 自定义的Agent角色标识 | "财务分析师Agent" |
| 核心定位 | 角色的主要职责和用途 | "企业财务报表分析与成本核算专家" |
| 擅长领域 | 角色专注的技术/业务范围 | "财务报表分析/成本核算/预算编制" |
| 行为准则 | 角色的操作规范和约束 | "仅基于合规数据输出分析结果，避免主观判断" |

#### 2.1.2 预设模板库
提供多种场景化角色模板，支持快速创建：

| 模板类型 | 适用场景 | 预置技能 |
|----------|----------|----------|
| 科研助手 | 学术研究、数据分析 | 文献检索、实验设计、数据分析 |
| 客服代表 | 客户咨询、问题解答 | 智能问答、情绪分析、话术生成 |
| 营销专家 | 市场推广、内容创作 | 文案生成、用户画像分析、竞品分析 |
| 财务分析师 | 报表分析、风险评估 | 财报解析、数据可视化、趋势预测 |
| 法务顾问 | 合同审核、合规审查 | 文档解析、风险识别、条款比对 |

### 2.2 权限绑定

#### 2.2.1 权限类型
| 权限类别 | 权限级别 | 说明 |
|----------|----------|------|
| 技能访问权限 | 无/只读/可调用 | 控制角色可使用的技能范围 |
| 数据访问权限 | 无/只读/可编辑 | 控制角色可访问的数据源/知识库 |
| 操作权限 | 只读/编辑/管理 | 控制角色的系统操作级别 |

#### 2.2.2 最小权限原则
- **默认拒绝**：新角色默认无任何权限，需显式授权
- **最小范围**：权限授予仅限于完成任务所需的最小范围
- **临时权限**：支持设置有效期（如"临时开放24小时"），到期自动回收

#### 2.2.3 权限配置示例
```
角色: 财务分析师
├── 技能访问权限
│   ├── ✅ 财报解析 (可调用)
│   ├── ✅ 数据可视化 (可调用)
│   ├── ✅ 趋势预测 (可调用)
│   └── ❌ 代码执行 (无权限)
├── 数据访问权限
│   ├── ✅ 财务知识库 (只读)
│   ├── ✅ 市场数据库 (只读)
│   └── ❌ 客户隐私数据 (无权限)
└── 操作权限
    ├── ✅ 查看分析报告 (只读)
    └── ❌ 系统配置 (无权限)
```

### 2.3 技能挂载与卸载

#### 2.3.1 智能推荐
根据角色定位自动推荐适配技能，并标注匹配度：

```
角色: 客服代表
推荐技能:
├── 智能问答系统 (匹配度: 95%)
├── 情绪分析 (匹配度: 88%)
├── 话术生成 (匹配度: 82%)
└── 知识库检索 (匹配度: 75%)
```

#### 2.3.2 批量操作
- **批量挂载**：支持一次性挂载多个技能
- **批量卸载**：支持批量移除技能（保留配置备份）
- **技能组合**：支持保存常用技能组合为"技能集"

### 2.4 角色切换

#### 2.4.1 快速切换机制
- 支持通过指令快速切换到预设角色
- 切换时自动加载对应权限与技能配置
- 支持快捷指令如 `/switch 角色名`

#### 2.4.2 配置保护
- 切换前自动保存当前角色配置
- 切换回原角色时可完整恢复配置
- 支持配置对比，确认切换前后差异

### 2.5 角色克隆与删除

#### 2.5.1 角色克隆
- 复制已有角色的完整配置
- 支持修改差异化配置（名称/权限/技能）
- 适用于创建相似角色变体

#### 2.5.2 角色删除
- 删除前自动创建配置备份
- 支持设置删除延迟（如24小时内可撤销）
- 清理关联的临时权限和会话数据

### 2.6 角色审计

#### 2.6.1 操作日志
记录所有角色相关操作：

| 日志类型 | 记录内容 | 保留期限 |
|----------|----------|----------|
| 权限变更 | 权限调整人、时间、变更前后对比 | 1年 |
| 技能挂载 | 技能挂载/卸载记录、操作人 | 1年 |
| 角色切换 | 切换时间、切换前后角色、操作人 | 6个月 |
| 登录日志 | 角色登录时间、IP地址、操作 | 1年 |

#### 2.6.2 审计报告
- 生成角色权限合规性评分
- 检测权限过度授予情况
- 提供优化建议

### 2.7 场景适配

#### 2.7.1 场景化配置
针对特定业务场景自动调整角色配置：

```
场景: 客户投诉处理
自动配置:
├── 挂载技能
│   ├── 情绪分析 (优先级: 高)
│   ├── 话术生成 (优先级: 高)
│   └── 知识库检索 (优先级: 中)
├── 临时权限
│   └── 客户历史记录 (有效期: 2小时)
└── 行为准则
    └── 增加"安抚客户情绪"优先级
```

## 3. 执行流程

### 3.1 执行前检查
1. 初始化 Agent 角色体系（角色模板库、权限矩阵、技能适配规则、行为准则库）
2. 加载已创建的 Agent 角色列表及权限配置
3. 解析用户指令（角色创建/编辑/权限调整/技能挂载+参数）
4. 校验角色操作权限（仅管理员/所有者可修改角色权限）

### 3.2 执行中处理
1. **角色定义**：自定义Agent角色名称、核心定位、擅长领域、行为准则
2. **权限绑定**：按最小权限原则分配技能/数据/操作权限
3. **技能挂载**：根据角色定位推荐并挂载适配技能
4. **角色切换**：支持快速切换并保留原配置
5. **审计记录**：实时记录所有操作日志

### 3.3 执行后处理
1. 保存角色配置与操作日志（加密存储）
2. 返回角色操作结果
3. 生成权限合规性评分
4. 提醒清理长期未使用的角色（超过30天）

## 4. 指令示例

### 4.1 创建角色
```
/create-role 名称=财务分析师 定位=企业财务报表分析专家 擅长领域=财报分析/成本核算/预算编制
```

### 4.2 绑定权限
```
/bind-permission 角色=财务分析师 技能权限=财报解析:可调用,数据可视化:可调用 数据权限=财务知识库:只读
```

### 4.3 挂载技能
```
/mount-skill 角色=财务分析师 技能=财报解析,数据可视化,趋势预测
```

### 4.4 切换角色
```
/switch 角色=客服代表
```

### 4.5 克隆角色
```
/clone-role 源角色=客服代表 新角色=高级客服 调整=增加情绪分析技能
```

### 4.6 查看审计日志
```
/audit-logs 角色=财务分析师 时间范围=近30天
```

## 5. 安全规则

| 规则 | 说明 |
|------|------|
| 数据隔离 | 不同角色的数据访问严格隔离 |
| 禁止外部调用 | 角色操作不涉及外部系统调用 |
| 最小权限 | 默认拒绝，仅授予必要权限 |
| 权限审计 | 所有权限变更均需记录和审计 |
| 角色隔离 | 角色间配置互不影响 |

## 6. 依赖模块

- `role_definition`: 角色定义与模板管理
- `permission_binding`: 权限绑定与最小权限原则
- `skill_mounting`: 技能挂载与智能推荐
- `role_switching`: 角色切换与配置保护
- `audit_log`: 操作日志与审计报告
