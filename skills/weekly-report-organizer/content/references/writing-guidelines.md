# 周报填写详细规范

## 基础信息规范

### 填报人
- 填写本人姓名
- 无需填写岗位/工号等额外信息

### 填报周期
- 固定填写本周周一至周日的日期
- 格式：`YYYY.MM.DD-YYYY.MM.DD`
- 示例：`2026.03.10-2026.03.14`

### 工时名称
- 统一使用部门规范的工时全称
- 禁止使用简称/别称
- 确保项目名称统一，便于统计

---

## 任务描述规范

### 写作原则
- 统一使用「动词+核心事项+补充说明」的简洁写法
- 避免模糊表述
- 无需冗余修饰

### 正确写法
- 分析青岛联通308局风冷机房节能率下降原因并调整参数。
- 总结云南昭通算法调参经验，纳入《算法调参经验工程化》。
- 整理OASIS现有功能及缺失项，输出《NewLand/OASIS需求表》表格。

### 错误写法
- 调参、处理机房问题。
- 做文档。
- 项目对接。

## 进度状态规范

### 状态类型与适用场景

| 状态标识 | 适用场景 | 填写示例 |
|---------|---------|---------|
| `--100%` | 本周内该任务部分已完成，是最常用的状态 | 水冷末端算法代码完善。--100% |
| `--XX%` | 有明确量化进度、跨周推进的开发/调参/文档类任务 | 完成NorthLand节能算法引擎核心模块开发。--60% |
| `--跟进中` | 无明确量化进度、需持续对接/等待反馈/等待前置条件的沟通、参会、项目对接类任务 | 确认山东移动开发区机房现场情况，待封网结束后调参。--跟进中 |
| `--阻塞待协调（原因）` | 任务出现卡点，无法正常推进，需团队/领导协调资源解决 | XX项目算法部署受阻。--阻塞待协调（客户机房暂未开放权限，需现场对接开通） |

### 进度状态选择判断

```
任务已完成?
├── 是 → --100%
└── 否 → 有明确百分比?
    ├── 是 → --XX%（填写实际数字）
    └── 否 → 是否在等待外部条件?
        ├── 是 → --跟进中
        └── 否 → 是否遇到卡点需要协调?
            ├── 是 → --阻塞待协调（必须写明原因）
            └── 否 → --跟进中
```

## 飞书发送注意事项

### 格式适配
- 飞书对话框内，使用 **Tab 键**进行列表缩进
- 发送后电脑/手机端格式会自动对齐，不会出现错乱
- **禁止使用空格缩进**，避免格式混乱

### 填写效率
- 可将模板固定到飞书输入框快捷短语
- 无需重复调整格式

### 快速复制模板

```
【部门周报】填报人：XXX | 填报周期：YYYY.MM.DD-YYYY.MM.DD
- 工时名称
	- 具体任务描述。--100%
	- 具体任务描述。--XX%
	- 具体任务描述。--跟进中
	- 具体任务描述。--阻塞待协调（写明具体原因）
```
