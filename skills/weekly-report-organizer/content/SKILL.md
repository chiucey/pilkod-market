# 周报整理技能

根据部门统一的飞书周报模板，帮助整理和生成规范的周报内容。

## 工作流程

### 1. 收集信息

请提供以下信息：

- **填报人**：李建东（固定）
- **填报周期**：本周一至周日日期，格式 `YYYY.MM.DD-YYYY.MM.DD`
- **工时项目**：您参与的项目/工时名称（使用规范全称）
- **任务内容**：每项任务的描述和完成进度

### 2. 进度状态标识

根据任务情况选择对应状态：

| 状态 | 适用场景 | 示例 |
|------|---------|------|
| `--100%` | 本周已完成的任务 | 水冷末端算法代码完善 |
| `--XX%` | 有明确量化进度的任务 | 节能算法引擎开发 --60% |
| `--跟进中` | 持续对接/等待反馈的任务 | 待封网结束后调参 |
| `--阻塞待协调（原因）` | 出现卡点需协调 | 客户机房暂未开放权限 |

### 3. 任务描述规范

使用「动词+核心事项+补充说明」的简洁写法：

**正确**：`分析青岛联通308局风冷机房节能率下降原因并调整参数`

**错误**：`调参、处理机房问题`

### 4. 输出格式

按以下模板生成周报：

```
【部门周报】填报人：李建东 | 填报周期：YYYY.MM.DD-YYYY.MM.DD
- 工时名称
    - 任务描述。--100%
    - 任务描述。--60%
    - 任务描述。--跟进中
    - 任务描述。--阻塞待协调（具体原因）
```

## 快速参考

### 基础格式规范

- 使用 Tab 键缩进（飞书会自动对齐）
- 禁止使用空格缩进
- 填报周期固定为周一至周日

### 进度状态选择指南

- **100%**：本周完全结束的任务
- **XX%**：有明确百分比进展的开发/调参任务
- **跟进中**：等待外部响应、持续对接类任务
- **阻塞待协调**：必须附带括号说明具体原因

### 填写示例

```
【部门周报】填报人：李建东 | 填报周期：2026.03.02-2026.03.06
- NorthLand节能算法引擎
    - 梳理水冷末端算法代码，完善流程图、算法描述文档。--100%
    - 优化氟泵空调算法参数JSON文件格式。--100%
- 空调AI群控网关项目
    - 整理OASIS现有功能及缺失项。--100%
    - 确认山东移动开发区机房现场情况。--跟进中
- XX项目
    - 算法部署受阻。--阻塞待协调（客户机房暂未开放权限）
```
