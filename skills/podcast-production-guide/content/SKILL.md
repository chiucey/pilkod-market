# 播客制作入门指南

## 核心功能概述

本Skill帮助内容创作者从零开始创建高质量播客节目，踏入音频内容赛道。

## 设备选择

### 入门级设备

| 设备 | 推荐型号 | 预算 |
|------|----------|------|
| 麦克风 | 舒尔MV7 | 1000-1500元 |
| 声卡 | 雅马哈AG03 | 800-1200元 |
| 耳机 | 索尼7506 | 500-800元 |
| 监听音箱 | JBL 305P | 1500-2000元 |

### 录音软件

- **Audacity**：免费开源
- **Adobe Audition**：专业强大
- **GarageBand**：Mac免费

## 录制技巧

### 环境布置

- 选择小空间（衣柜、书房）
- 使用吸音棉减少回声
- 远离窗户和电器
- 保持安静无干扰

### 录制要点

| 要点 | 说明 |
|------|------|
| 距离 | 麦克风15-30cm |
| 音量 | 保持稳定适中 |
| 语速 | 比日常稍慢 |
| 停顿 | 给听众思考时间 |

## 剪辑流程

### 标准剪辑步骤

1. 降噪处理
2. 删除语气词（嗯、啊）
3. 调整音量平衡
4. 添加背景音乐
5. 导出MP3格式

### 常用BGM资源

- Epidemic Sound
- Artlist
- 爱给网（国内免费）

## 内容策划

### 节目结构

```
开场（1-2分钟）
├── 主持人自我介绍
├── 本期内容预告

主体（20-40分钟）
├── 话题1
├── 话题2
└── 话题3

结尾（2-5分钟）
├── 内容总结
├── 下期预告
└── 互动引导
```

### 选题策略

- 垂直领域深耕
- 热点话题结合
- 系列化策划
- 听众问题征集
