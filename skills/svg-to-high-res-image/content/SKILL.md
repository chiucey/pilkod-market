# SVG 转高清图片技能

## 功能概述

将SVG矢量图形文件转换为高分辨率位图图片，支持多种输出格式和分辨率设置。

## 使用方法

当用户请求以下操作时自动触发：
- "将SVG转换为PNG/JPG"
- "SVG转高清图片"
- "导出SVG为图片"
- "svg2png" / "svg to image"
- "矢量图转位图"
- "高清SVG导出"

## 执行步骤

### 步骤1：读取SVG文件
使用 Read 工具读取用户提供的SVG文件内容。

### 步骤2：确定输出参数
根据用户需求确定：
- **输出格式**：PNG（默认，透明背景）或 JPG（白色背景）
- **分辨率**：1K (1024px)、2K (2048px)、4K (4096px)，默认2K
- **缩放比例**：1x、2x、3x、4x

### 步骤3：创建HTML渲染文件
生成临时HTML文件用于SVG渲染：
```html
<!DOCTYPE html>
<html>
<head>
<style>
body { margin: 0; background: transparent; }
img, svg { width: {width}px; height: auto; }
</style>
</head>
<body>
<!-- SVG内容 -->
</body>
</html>
```

### 步骤4：使用 html-to-image 工具转换
使用 `html_to_image` 或 `html_to_pdf` 工具将HTML渲染为图片。

### 步骤5：保存输出
将生成的图片保存到用户指定位置或 `imgs/` 目录。

## 支持的输出格式

| 格式 | 背景 | 适用场景 |
|------|------|----------|
| PNG | 透明/自定义 | 图标、设计稿、UI元素 |
| JPG | 白色/自定义 | 照片、文档、预览图 |

## 分辨率规格

| 规格 | 尺寸 | 适用场景 |
|------|------|----------|
| 1K | 1024px | 缩略图、社交媒体 |
| 2K | 2048px | 一般用途（默认） |
| 4K | 4096px | 打印、高清展示 |

## 示例使用

**用户输入**：
```
将这个SVG图标转换为4K分辨率的PNG图片
```

**执行流程**：
1. 读取SVG文件
2. 设置输出参数：格式=PNG，分辨率=4K
3. 创建HTML渲染文件
4. 使用渲染工具生成PNG图片
5. 保存到 `imgs/` 目录

**用户输入**：
```
SVG转JPG，2倍缩放
```

**执行流程**：
1. 读取SVG文件
2. 设置输出参数：格式=JPG，缩放=2x
3. 创建HTML渲染文件
4. 使用渲染工具生成JPG图片
5. 保存到 `imgs/` 目录

## 注意事项

- SVG必须为有效的XML格式
- 包含外部资源的SVG（图片引用、字体等）需要先内联处理
- 复杂SVG可能需要较长渲染时间
- 建议在转换前验证SVG显示效果
