# 数据格式规范参考

## 推荐的表格格式

### 基础数据表

| 字段名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| 客户名称 | 文本 | 客户公司/个人名称 | ABC科技有限公司 |
| 行业分类 | 文本 | 所属行业领域 | 互联网、金融、制造 |
| 收入类型 | 文本 | 产品/服务类型 | 产品销售、技术服务、广告 |
| 运营方式 | 文本 | 销售渠道/模式 | 直销、代理、电商平台 |
| 收入金额 | 数值 | 当期收入（元） | 100000 |
| 成本金额 | 数值 | 当期成本（元） | 60000 |
| 毛利 | 数值 | 收入-成本 | 40000 |
| 日期/月份 | 日期 | 数据所属期间 | 2024-01 |

### 多表格组合方式

**方案A：单一综合表**
- 所有字段放在一个表格中
- 适合数据量较小的情况

**方案B：多表格分离**
- 表1：客户基础信息（客户名称、行业、规模等）
- 表2：收入数据（客户名称、收入类型、金额）
- 表3：成本数据（客户名称、运营方式、成本）
- 适合数据量大、结构复杂的情况

## 数据校验规则

1. **必填字段**：客户名称、收入金额、日期
2. **数值字段**：必须为正数
3. **日期格式**：YYYY-MM 或 YYYY/MM
4. **文本字段**：避免特殊字符污染
