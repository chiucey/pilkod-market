# 财务经营数据分析技能

## 核心能力

本技能提供完整的财务经营数据分析解决方案，支持多表格上传、四维度深度分析和周期性报告生成。

## 工作流程

### 第一步：数据收集与上传

1. **接收用户上传的Excel/CSV表格**
   - 支持多个表格同时上传（每个表格代表不同数据维度）
   - 自动识别表格列名和数据类型
   - 提取数据：客户信息、行业分类、收入类型、运营方式

2. **数据解析与验证**
   - 解析上传的文件格式（支持xlsx、csv）
   - 校验数据完整性和格式正确性
   - 存储解析后的结构化数据

### 第二步：四维度深度分析

#### 维度一：客户分析
- 客户分类统计（按规模、行业、地区）
- 客户贡献度排名（收入占比、毛利贡献）
- 客户变化趋势（新增、流失、复购）
- 改善建议：客户结构优化方案、交叉销售策略

#### 维度二：行业分析
- 各行业收入占比与毛利对比
- 行业增长趋势分析
- 行业竞争态势评估
- 改善建议：行业布局优化、重点行业突破策略

#### 维度三：收入类型分析
- 收入结构分析（产品类型、服务类型）
- 各收入类型的毛利率对比
- 收入稳定性评估
- 改善建议：高毛利业务拓展、低毛利业务优化

#### 维度四：运营方式分析
- 不同运营渠道的效果对比
- 运营成本与收益分析
- 运营效率评估
- 改善建议：渠道整合优化、运营模式创新

### 第三步：报告生成

#### 月度报告
- 月度经营数据总览
- 四维度详细分析
- 月度改善建议汇总
- 环比/同比分析

#### 季度报告
- 季度经营数据汇总
- 四维度趋势分析
- 季度亮点与问题识别
- 下季度预测与建议

#### 年度报告
- 年度经营数据汇总
- 全年四维度深度分析
- 年度目标达成评估
- 年度改善建议与下年规划

## 输出格式

### 数据看板展示
- 月度数据卡片（支持12个月切换）
- 四维度分析图表（柱状图、饼图、折线图）
- 趋势分析面板
- 改善建议面板

### 分析报告
- 结构化分析报告（Markdown/PDF格式）
- 数据表格导出
- 图表可视化输出

## 触发指令

用户可通过以下方式触发：
- "上传财务数据进行分析"
- "生成月度经营分析报告"
- "季度经营分析"
- "年度总结报告"
- "分析客户/行业/收入类型/运营方式"
- "财务看板"

## 注意事项

1. 上传时请确保表格格式规范（列名清晰、数据完整）
2. 首次分析需要提供至少一个月的数据
3. 季度/年度报告需要至少一个完整季度的数据
4. 所有分析结果自动保存并支持历史查看
