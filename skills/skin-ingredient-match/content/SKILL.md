# Skin Ingredient Match · 成分定制推荐

## 技能定位

本技能是"成分诊断 + 精准推荐"服务，核心逻辑：

**用户肤质现状 + 用户主动诉求 → 推荐有效成分 → 给出成分选购建议**

可联动使用：
- `eye-wrinkle-scan`（眼周皱纹问题 → 成分推荐）
- `dark-circle-id`（黑眼圈类型 → 成分推荐）
- `eye-hydration-check`（眼周缺水 → 成分推荐）
- `t-oil-analysis`（T区出油 → 成分推荐）
- `chin-mouth-dark-spot-check`（下巴暗沉 → 成分推荐）

---

## 输入处理

### 必填输入：用户肤质画像

新用户先收集肤质画像：

```
请告诉我：
1. 你的肤质类型？（油皮/干皮/混干/混油/中性/敏感肌）
2. 你最想解决的皮肤问题？（1~3个，按优先级排序）
3. 有没有对某些成分过敏或不耐受的经历？
4. 平时护肤最在意什么？（保湿/抗衰/美白/祛痘/维稳）
```

### 可选输入

- 已有肤质档案（来自其他 Skills 的诊断结果）
- 正在使用的产品（判断成分是否有重叠或冲突）

## 推荐逻辑

### 第一步：分析肤质画像

根据用户肤质，划定"能用成分"和"不能用/慎用成分"：

```
干皮/混干 → 优先保湿+屏障修护成分
           → 慎用：高浓度酸类、A醇（从低浓度开始）
油皮/混油 → 优先控油+疏通+抗氧化成分
           → 慎用：过度保湿的封闭性成分
敏感肌 → 优先屏障修护+抗炎成分
        → 禁用：酒精、精油、A醇、酸类（高浓度）
油敏皮 → 控油+修护同时进行，避免封闭性保湿
```

### 第二步：结合用户诉求

| 用户诉求 | 优先级成分 | 协同成分 |
|---------|---------|---------|
| 美白淡斑 | VC、烟酰胺、377、传明酸 | 保湿+防晒是基础 |
| 抗衰紧致 | 视黄醇、胜肽、玻色因 | 保湿+防晒 |
| 保湿锁水 | 神经酰胺、透明质酸、泛醇 | — |
| 控油祛痘 | 水杨酸、壬二酸、烟酰胺 | 抗炎+屏障修护 |
| 敏感修护 | 泛醇、神经酰胺、燕麦、积雪草 | 避免刺激 |
| 毛孔粗大 | 水杨酸、烟酰胺、壬二酸 | 控油+抗老 |
| 抗氧化 | VC、绿茶多酚、白藜芦醇 | 防晒是核心 |

### 第三步：成分搭配原则

```
✅ 黄金搭档：
VC + VE → 抗氧化效果倍增
VC + 烟酰胺 → 美白+修护双管齐下
神经酰胺 + 泛醇 + 胆固醇 → 屏障修护三剑客
水杨酸 + 保湿精华 → 控油不伤屏障
胜肽 + 玻色因 → 多维度抗衰

❌ 不能混用的成分：
A醇（Retinol）+ 酸类 → 刺激性太强
A醇 + VC → pH值冲突，功效抵消
壬二酸 + 酸类 → 刺激加倍
377 + 高浓度VC → 刺激，pH冲突
```

## 注意事项

- 只推荐成分和功效类型，不推荐具体品牌
- 敏感肌先修护屏障再上功效成分
- 美白和抗衰诉求叠加时，先建立耐受再叠加
- 孕期/哺乳期：提前告知，需排除禁用成分（A醇、酸类、壬二酸）
- 成分浓度遵循"从低到高"原则，给出使用频率建议
