# 短剧配乐风格参考指南

## 一、短剧类型与音乐风格匹配

### 1. 都市爱情剧
**风格关键词**：现代、时尚、情感细腻
**推荐风格**：
- **主旋律**：钢琴+弦乐抒情
- **副旋律**：电子流行、City Pop
- **转场**：轻爵士、蓝调
**参考剧集**：《何以笙箫默》《微微一笑很倾城》

**配乐特点**：
- 钢琴作为主旋律，承载情感表达
- 弦乐铺底增加厚重感
- 电子音色点缀，增添现代感
- 节奏多为中慢速，贴合人物内心

### 2. 古风仙侠剧
**风格关键词**：飘逸、古典、神秘
**推荐风格**：
- **主旋律**：古筝、笛箫、琵琶
- **氛围**：民族管弦乐、水墨意境
- **打斗**：鼓点+电子音效
**参考剧集**：《陈情令》《长月烬明》

**配乐特点**：
- 大量使用民族乐器
- 五声音阶为主，典雅悠远
- 笛箫营造飘逸感
- 古筝/琵琶增加节奏张力

### 3. 悬疑推理剧
**风格关键词**：紧张、神秘、层层递进
**推荐风格**：
- **主旋律**：钢琴+电子合成音
- **氛围**：环境音、低频脉冲
- **高潮**：管弦乐+电子结合
**参考剧集**：《隐秘的角落》《白夜追凶》

**配乐特点**：
- 大量使用不协和音程制造紧张感
- 节奏型复杂，变化多端
- 低频元素营造压迫感
- 留白与突然爆发形成对比

### 4. 喜剧搞笑剧
**风格关键词**：轻松、活泼、跳跃
**推荐风格**：
- **主旋律**：卡通音乐、木琴、口哨
- **转场**：爵士摇摆、民族特色
- **表情音效**：短促有趣的音效
**参考剧集**：《武林外传》《爱情公寓》

**配乐特点**：
- 节奏轻快跳跃
- 大量使用不规则节拍
- 滑稽音效点缀
- 乐器编配活泼多变

### 5. 家庭伦理剧
**风格关键词**：温情、现实、接地气
**推荐风格**：
- **主旋律**：钢琴、吉他弹唱
- **氛围**：原声吉他、口琴
- **高潮**：弦乐温情铺底
**参考剧集**：《都挺好》《以家人之名》

**配乐特点**：
- 温馨而不煽情
- 贴近日常生活
- 钢琴/吉他为主，亲切感强
- 情感表达克制而真挚

## 二、情绪强度与配乐密度对照

### 情绪强度分级

| 强度等级 | 情绪状态 | 配乐密度 | 音乐元素 |
|---------|---------|---------|---------|
| 1级（极低） | 平静、空灵、虚无 | 极简 | 单音/单旋律线、长时间留白 |
| 2级（低） | 舒缓、放松、日常 | 稀疏 | 简单和声、缓慢节奏 |
| 3级（中等） | 温和、愉悦、轻松 | 适中 | 完整编曲、中等节奏 |
| 4级（较高） | 紧张、期待、激动 | 密集 | 复杂编曲、快速节奏 |
| 5级（极高） | 高潮、爆发、冲击 | 极密 | 多层叠加、音效强化 |

## 三、常见配乐场景模板

### 场景1：雨中告白
**场景描述**：男主在雨中等待女主，终于见面后表白
**情绪曲线**：紧张期待 → 深情表白 → 甜蜜接受
**配乐建议**：
- 前奏：钢琴独奏，营造孤独等待感
- 主歌：钢琴+弦乐，旋律逐渐升温
- 副歌：弦乐全开，电子音效点缀雨声
- 结尾：甜蜜钢琴收尾

**SUNO提示词**：
```
Style: Emotional Cinematic Pop
Mood: Romantic, hopeful, deeply moving
Instrumentation: Piano, strings, electronic pads
Tempo: 65 BPM, building to 80 BPM
Duration: 2:30
```

### 场景2：车祸/意外
**场景描述**：女主目睹男主出车祸，情绪崩溃
**情绪曲线**：震惊 → 恐惧 → 崩溃 → 绝望
**配乐建议**：
- 瞬间：音效+低频噪音，突然的静默
- 崩溃：钢琴急促低音弦乐紧绷
- 绝望：人声哼鸣+环境音，极度压抑

**SUNO提示词**：
```
Style: Dark Cinematic, Trauma Soundtrack
Mood: Devastating, heart-wrenching, dramatic
Instrumentation: Piano, low strings, distorted bass
Tempo: 50 BPM, arrhythmic pulses
Duration: 1:30
```

### 场景3：职场逆袭
**场景描述**：主角在职场受到打压后反击成功
**情绪曲线**：压抑 → 反击 → 爆发 → 胜利
**配乐建议**：
- 压抑段：低音铜管，沉重缓慢
- 反击点：鼓点进入，节奏增强
- 爆发段：交响金属+电子，力量感爆发
- 胜利段：明亮弦乐+铜管，辉煌结尾

**SUNO提示词**：
```
Style: Epic Orchestral Rock
Mood: Powerful, triumphant, victorious
Instrumentation: Full orchestra, electric guitar, drums
Tempo: 120 BPM, driving rhythm
Duration: 2:00
```

### 场景4：闺蜜深夜谈心
**场景描述**：两个女孩在深夜天台聊天，互相倾诉心事
**情绪曲线**：轻松 → 倾诉 → 感动 → 坚定友情
**配乐建议**：
- 轻松段：轻爵士吉他，夜晚氛围
- 倾诉段：钢琴+弦乐，情感流露
- 感动段：音乐渐强，人声哼鸣
- 坚定段：温暖弦乐收尾

**SUNO提示词**：
```
Style: Warm Acoustic Pop
Mood: Intimate, heartfelt, supportive
Instrumentation: Acoustic guitar, piano, soft strings
Tempo: 75 BPM, gentle feel
Duration: 2:00
```

### 场景5：古风离别
**场景描述**：将军远征，爱人在城门送别
**情绪曲线**：不舍 → 誓言 → 决绝 → 孤独
**配乐建议**：
- 不舍段：笛声悠远，二胡低沉
- 誓言段：鼓点加入，情绪递进
- 决绝段：琵琶急促，马蹄音效
- 孤独段：箫声独奏，空旷苍凉

**SUNO提示词**：
```
Style: Traditional Chinese Orchestral
Mood: Bittersweet farewell, patriotic, epic
Instrumentation: Dizi, erhu, guzheng, guqin
Tempo: 70 BPM, emotional dynamics
Duration: 2:30
```

## 四、配乐术语速查表

| 术语 | 含义 | 应用场景 |
|-----|------|---------|
| OST | Original Soundtrack，影视原声 | 整体风格定位 |
| BGM | Background Music，背景音乐 | 日常场景铺垫 |
| Incidental Music | 附属音乐/情景音乐 | 特定情景配乐 |
| Leitmotif | 主导动机/主题音乐 | 角色/地点专属旋律 |
| Stinger | 音效式音乐片段 | 转场、突发事件 |
| Riser | 上升音效 | 情绪递进、转场 |
| Drop | 爆发点 | 节奏/情绪高潮 |
| Swell | 渐强/弦乐涌动 | 情感爆发前的蓄力 |
| Pulse | 脉冲/心跳节奏 | 紧张、期待场景 |
| Drone | 持续低音/氛围音 | 神秘、悬疑、恐怖场景 |
