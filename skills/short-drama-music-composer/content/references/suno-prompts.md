# SUNO音乐创作提示词模板

## 一、SUNO平台基础认知

### SUNO简介
Suno是一款AI音乐生成工具，可以通过文本提示词创作完整的音乐作品（包含人声和器乐）。

### 提示词核心要素

| 要素 | 说明 | 示例 |
|-----|------|------|
| Style | 音乐风格 | Cinematic Pop, Lo-fi, Orchestral |
| Mood | 情绪基调 | Romantic, Melancholic, Uplifting |
| Instruments | 乐器配置 | Piano, Strings, Guitar |
| Tempo | 节奏速度 | 60 BPM, Mid-tempo, Fast |
| Reference | 参考元素 | Korean Pop, 90s R&B, Anime Soundtrack |

### 基础提示词公式

```
Style: [音乐风格]
Mood: [情绪关键词]
Instrumentation: [主要乐器]
Tempo: [节奏描述]
Duration: [时长要求]
```

## 五、常见问题与解决

### Q1：如何控制音乐的时长？
**解决**：
- 直接在提示词中指定Duration
- 短场景（1-2分钟）：简化编曲
- 长场景（3分钟+）：需要更丰富的结构

### Q2：如何避免风格过于统一？
**解决**：
- 使用渐进式提示词分段生成
- 在Instrumentation中指定变化
- 使用"building"、"transformation"等动态词

### Q3：中文歌词如何在SUNO实现？
**解决**：
- SUNO对中文支持有限，建议分段尝试
- 可以先用英文提示词生成纯音乐
- 单独生成中文歌曲时使用中文开头

### Q4：如何生成更情绪化的音乐？
**解决**：
- 使用强烈的情绪词（devastating, euphoric）
- 指定动态范围（pp to ff）
- 使用情感化的乐器（solo violin, breathy vocals）
