# 短剧AI配乐家技能

## 技能概述

本技能为短剧创作者提供完整的配乐解决方案，从剧本解读到最终的音乐创作提示词，覆盖短剧配乐的完整工作流程。

## 核心工作流程

### 阶段一：剧本接收与结构解析

**输入要求**：
- 用户提供的短剧剧本（可以是完整剧本或单集内容）
- 支持格式：纯文本、Markdown、JSON格式的分集脚本

**解析内容**：
1. **剧情类型识别**：都市爱情、古风仙侠、悬疑惊悚、喜剧搞笑、家庭伦理等
2. **集数结构拆分**：识别剧本中的场景切换点，按集/场景进行拆分
3. **人物关系分析**：梳理主要人物及其情感线索
4. **情感曲线绘制**：追踪整体剧情的情感起伏

### 阶段二：场景级配乐分析

对每个场景进行深度分析，输出以下要素：

```
场景编号 | 场景描述 | 时长估算 | 情绪基调 | 紧张度 | 配乐类型建议
```

**情绪分类矩阵**：

| 情绪类别 | 适用场景 | 推荐风格 |
|---------|---------|---------|
| 甜蜜温馨 | 恋人相处、亲情时刻 | 轻爵士、流行情歌、弦乐小品 |
| 悲伤虐心 | 离别、误解、失去 | 钢琴独奏、弦乐悲歌、民谣 |
| 紧张悬疑 | 危机时刻、推理过程 | 电子合成音、悬疑管弦乐 |
| 热血燃情 | 高潮时刻、励志场景 | 摇滚、交响金属、电子舞曲 |
| 搞笑轻松 | 喜剧场景、日常互动 | 轻喜剧音乐、卡通风格、民族乐器 |
| 古风雅韵 | 古装场景、历史背景 | 古筝、笛箫、二胡、民乐合奏 |
| 神秘诡异 | 灵异事件、心理恐惧 | 环境音、电子特效、低频氛围 |

**紧张度评级**：1-10分制
- 1-3：低紧张，背景铺垫
- 4-6：中紧张，情绪推进
- 7-10：高紧张，冲突高潮

### 阶段三：配乐思路与建议

**分场景配乐策略**：

1. **开场配乐**：建立剧集调性，吸引观众
2. **转场配乐**：平滑过渡，制造节奏感
3. **情绪配乐**：强化场景情绪，引导观众情感
4. **高潮配乐**：配合关键剧情节点
5. **结尾配乐**：收束情绪，埋下伏笔

**音乐元素建议**：
- 主旋律乐器选择
- 和声进行建议
- 节奏型建议
- 特殊音效建议（如需要）

### 阶段四：借鉴曲目推荐

**推荐维度**：
1. **情绪匹配度**：与目标场景情绪相似度
2. **风格参考度**：可借鉴的音乐风格元素
3. **版权合规性**：推荐公开版权或原创参考曲目
4. **歌词参考**（如需要）：提供可借鉴的歌词方向

**推荐曲目格式**：

```markdown
## 场景X推荐曲目

### 参考曲目A
- **曲目名**：[歌曲名称]
- **艺术家**：[艺术家名]
- **情绪匹配度**：★★★★☆
- **可借鉴元素**：主旋律走向、副歌编排
- **适用提示**：适合作为[具体场景]的情绪参考

### 纯音乐参考B
- **曲目名**：[纯音乐名称]
- **来源**：[影视原声/游戏音乐/版权状态]
- **配器参考**：弦乐为主，搭配钢琴
- **节奏参考**：60-70BPM，渐进式递增
```

### 阶段五：歌词创作（如需要）

**触发条件**：
- 用户明确要求为特定场景创作歌词
- 场景需要原创歌曲（如角色主题曲、片尾曲、插曲）

**歌词创作流程**：

1. **场景理解**：深入理解场景的剧情、人物情感、叙事目的
2. **风格定位**：确定歌词风格（深情款款、热血激昂、清新文艺等）
3. **结构设计**：规划主歌、副歌、桥段布局
4. **意象提炼**：提取关键情感意象和视觉元素
5. **歌词生成**：创作完整歌词
6. **韵脚优化**：调整韵脚使歌词朗朗上口

**歌词输出格式**：

```markdown
## 原创歌词：[歌曲名称]

**创作背景**：[场景简述]

**歌词风格**：深情款款 / 热血燃情 / 清新文艺 / 虐心情歌

**[Verse 1 主歌]**
[歌词内容...]

**[Pre-Chorus 前副歌]**
[过渡性内容...]

**[Chorus 副歌]**
[核心Hook，情感高潮...]

**[Verse 2 主歌2]**
[推进剧情...]

**[Chorus 副歌]**
[重复+变化...]

**[Bridge 桥段]**
[情绪转折或升华...]

**[Final Chorus 最终副歌]**
[最强情绪输出...]

**[Outro 尾声]**
[余韵收束...]
```

### 阶段六：SUNO音乐创作提示词生成

**SUNO提示词格式**：

```
[音乐风格], [情绪基调], [主要乐器], [节奏速度], [音色描述], [参考元素], [时长要求]
```

**提示词生成模板**：

```markdown
## SUNO音乐提示词

### 场景X配乐提示词
**基础提示词**：
```
[Style]: [如Cinematic Pop, Emotional Ballad, Epic Orchestral等]
[Mood]: [如Romantic, Melancholic, Suspenseful, Uplifting等]
[Instrumentation]: [如Piano, Strings, Guitar, Chinese Traditional等]
[Tempo]: [如60-70 BPM, Mid-tempo, Fast-paced等]
[Additional]: [如Softdynamics, Building intensity, Minimal等]
```

**中文友好版提示词**：
```
[风格描述]，[情绪关键词]，[主要乐器]，[节奏特征]，[音色描述]，[时长要求]
```

**完整示例**：

输入场景：第5集 男主雨中告白，情绪从悲伤转向希望

生成的SUNO提示词：
```
Style: Emotional Cinematic Pop with orchestral elements
Mood: Melancholic yet hopeful, deeply romantic
Instrumentation: Piano-led, strings swells, subtle electronic pads
Tempo: 70 BPM, building to 85 BPM in chorus
Additional: Rain sound effects, gentle dynamics, cinematic feel
Duration: 2:30-3:00

中文版：
电影感流行抒情，钢琴主导配以弦乐，情绪从忧郁转向希望，70-85BPM，雨声音效，电影级动态，时长2分30秒至3分钟
```
```

## 输出交付物清单

完成配乐分析后，输出完整的配乐方案：

1. **剧本分析报告**：剧情类型、人物关系、情感曲线
2. **分集配乐表**：每集/每个场景的配乐建议
3. **音乐风格指南**：整体风格定位和参考
4. **借鉴曲目清单**：含情绪匹配度和参考说明
5. **原创歌词**（如需要）：完整歌词内容
6. **SUNO提示词库**：每个配乐点的SUNO创作提示词

## 技能使用示例

### 示例1：完整剧本配乐分析

**用户输入**：
```
请帮我分析这个短剧的配乐方案：[粘贴完整剧本或上传文件]

需求：
1. 按每集进行场景配乐分析
2. 提供可配乐的思路和建议
3. 推荐借鉴曲目
4. 第3集结尾需要一首虐心情歌，请生成歌词
5. 提供SUNO音乐提示词
```

**技能输出**：
[完整的剧本分析、场景配乐表、曲目推荐、歌词创作、SUNO提示词]

### 示例2：单场景配乐

**用户输入**：
```
场景：女主在咖啡厅等待男主，这是他们分手后的第一次见面。她既紧张又期待，看着窗外的雨，想起了曾经的美好时光。
情绪：从期待→回忆的温暖→现实的苦涩→重新燃起希望
时长：约2分钟

请提供：
1. 配乐思路
2. 借鉴曲目（最好有歌词）
3. 如果有歌词版本，请生成歌词
4. SUNO提示词
```

**技能输出**：
[场景分析、配乐思路、曲目推荐、歌词创作、SUNO提示词]

## 注意事项

1. **版权意识**：推荐曲目时优先选择公开版权或原创参考，避免直接推荐需要版权授权的商业曲目
2. **风格一致性**：确保同一集/同一情感线内的配乐风格保持连贯
3. **时长匹配**：配乐建议需与场景时长匹配，注意前奏、主歌、副歌的时间分配
4. **情感真实性**：歌词创作需贴合角色性格和剧情走向，避免词不达意
5. **SUNO限制**：SUNO对中文支持有限，如需中文歌词建议分开生成或使用英文提示词

## 技能边界

**本技能可以**：
- 解读分析各类短剧剧本
- 提供专业的配乐建议和思路
- 推荐参考曲目和音乐风格
- 创作原创歌词
- 生成SUNO等AI音乐工具的提示词

**本技能不能**：
- 直接生成音频文件（可生成提示词供用户在SUNO等平台生成）
- 保证SUNO生成的音频质量
- 提供版权音乐文件下载
- 替代专业音乐制作人
