# 黄金核心宏观指标解读

## 1. 美联储利率（Federal Reserve）

**重要性：** ⭐⭐⭐（最高）

- 美联储加息 → 美元走强 → 黄金承压（黄金以美元计价）
- 美联储降息 → 持有黄金的机会成本降低 → 金价上涨
- **关键工具：** FOMC会议声明、点阵图、CME FedWatch利率期货

**如何解读：**
- 关注"higher for longer"叙事是否转向
- 实际利率 = 名义利率 - 通胀率；**实际利率下行 → 金价上行**
- 10年期美债收益率与金价呈强负相关（~ -0.85）

---

## 2. 美元指数（DXY）

**重要性：** ⭐⭐⭐

- DXY = 美元相对六大货币的加权指数（EUR占比最大）
- DXY与黄金历史负相关性：**约 -0.7**
- 美元升值1% ≈ 黄金下跌0.5-0.8%

**大致对应关系：**
| DXY 区间 | 黄金相对强弱 |
|---------|------------|
| > 105 | 金价承压 |
| 98-105 | 中性/震荡 |
| < 98 | 金价相对受益 |

---

## 3. 地缘政治风险

**重要性：** ⭐⭐（高）

- 黄金是传统避险资产
- 重大事件驱动金价：战争、制裁、金融危机、大选动荡
- 典型案例：2022年俄乌战争爆发 → 黄金单日涨超3%

**观察指标：**
- VIX恐慌指数 > 20：避险情绪升温
- 黄金ETF持仓量（GLD / SPDR Gold Trust）增加 = 资金流入

---

## 4. 通胀数据

**重要性：** ⭐⭐

- 黄金传统上是通胀对冲工具
- 但高通胀 + **强加息** 并存时，金价仍可能下跌（2022年就是例证）
- 关键指标：**CPI同比、PCE核心通胀、10年期盈亏平衡通胀率**

**逻辑链：**
```
高通胀 → 美联储加息预期 → 实际利率上升 → 黄金机会成本上升 → 金价承压
高通胀 → 货币信用担忧 → 黄金避险需求 → 金价上涨
（两条逻辑博弈，结果取决于谁的力道更强）
```

---

## 5. 央行购金（Central Bank Gold Buying）

**重要性：** ⭐⭐（逐年上升）

- 全球央行净购金量是近年金价的重要支撑因素
- 2022/2023年央行年均净购金超过1000吨
- 中国、印度、土耳其、波兰是主要购金国
- **数据来源：** 世界黄金协会（WGC）季度报告

**为何重要：** 央行购金是"刚性需求"，与投机资金不同，具有长期锁仓特征

---

## 6. 黄金ETF持仓（SPDR Gold Trust, GLD）

**重要性：** ⭐

- GLD持仓量下降 = 机构投资者撤离 → 金价压力
- GLD持仓量上升 = 机构买入 → 金价支撑
- 持仓量单周变化超过20吨需重点关注

---

## 7. 实际利率（Real Interest Rates）

**重要性：** ⭐⭐⭐

- 实际利率 = 10年期美债收益率 - 通胀预期（CPI或PCE）
- **实际利率为负** = 持有黄金的机会成本极低 → 极度利好金价
- 2020年疫情期间实际利率深度为负 → 黄金历史新高

**10年期TIPS（通胀保护债券）收益率** 是观察实际利率的最佳窗口

---

## 关键经济数据发布日历

这些数据发布日常常引发黄金剧烈波动：

| 数据 | 发布频率 | 对黄金影响 |
|------|---------|----------|
| 美国CPI | 每月 | 直接影响美联储加息预期 |
| 美国非农就业/失业率 | 每月 | 影响美联储政策预期 |
| FOMC会议利率决定 | 每6-8周 | 最重要宏观事件 |
| 美国GDP | 每季度 | 经济预期影响利率路径 |
| PCE核心通胀 | 每月 | 美联储最关注的通胀指标 |
| ISM制造业/服务业PMI | 每月 | 经济健康度，影响利率预期 |
