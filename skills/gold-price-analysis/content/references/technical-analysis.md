# 黄金技术分析指南

## 常用时间周期

| 周期 | 用途 | 适用对象 |
|------|------|---------|
| 日线（H4） | 短期交易（1天-1周） | 日内交易者、短线投资者 |
| 周线（D1） | 中期趋势（1周-3月） | 波段交易者 |
| 月线（Monthly） | 长期趋势判断 | 定投投资者 |

---

## 1. 移动平均线（MA）

**核心用法：**
- **MA50**：识别中期趋势（收于MA50上方 = 中期偏多）
- **MA200**：识别长期趋势（"生命线"，收于下方 = 熊市信号）

**黄金常用均线组合：**
```
多头排列（上涨趋势）：MA20 > MA50 > MA200（均线从上到下）
空头排列（下跌趋势）：MA20 < MA50 < MA200
金叉（买入信号）：MA50从下向上穿越MA200
死叉（卖出信号）：MA50从上向下穿越MA200
```

---

## 2. RSI（相对强弱指数）

**参数：** 14日（标准）

| RSI区间 | 信号 | 含义 |
|--------|------|------|
| > 70 | 超买 | 可能回调，谨慎追高 |
| 50-70 | 偏强 | 多头趋势中 |
| 40-60 | 中性 | 震荡整理 |
| 30-50 | 偏弱 | 空头趋势中 |
| < 30 | 超卖 | 可能反弹，低位吸筹机会 |

**黄金特殊用法：**
- 月线RSI > 80：历史极值，往往对应重要顶部
- 月线RSI < 30：历史极值，关注长期布局机会

---

## 3. MACD（移动平均收敛发散）

**参数：** 12, 26, 9（日线标准）

**核心信号：**
```
MACD > 信号线（9日EMA）：多头信号
MACD < 信号线：空头信号
MACD 从负转正（金叉在零轴下方）：潜在上涨动能积累
MACD 从正转负（死叉在零轴上方）：潜在下跌动能积累
```

**黄金市场特点：**
- MACD在零轴上方持续时间长（趋势性强，做空需谨慎）
- 周线MACD金叉往往是中级行情起点

---

## 4. 布林带（Bollinger Bands）

**参数：** 20日MA ± 2倍标准差

| 价格位置 | 信号 |
|---------|------|
| 触及上轨 | 可能短线回调（超买） |
| 触及中轨（20日均线） | 动态支撑/阻力 |
| 触及下轨 | 可能反弹（超卖） |
| 布林带收窄 | 酝酿突破（大波动在即） |
| 布林带开口放大 | 趋势延续 |

---

## 5. 支撑位与阻力位

**如何识别关键位：**
1. **前期高低点**：历史价格拐点
2. **整数关口**：2000、2500、3000（心理大关）
3. **斐波那契回撤**：38.2%、50%、61.8%回撤位
4. **成交量堆积区**：机构建仓密集区

**黄金关键心理关口（2024-2026）：**
```
支撑位：2500、2600、2700
阻力位：2800、3000
历史新高：~3000（2025年）
```

---

## 6. 趋势线与通道

**画线规则：**
- 连接两个或更多明显低点 = 上升趋势线（支撑）
- 连接两个或更多明显高点 = 下降趋势线（阻力）
- 趋势线被有效突破（收盘价穿越）= 趋势反转信号

**黄金长期趋势线（供参考）：**
- 2018年低点（1160）至2020年高点（2075）连线：构成2022年回调支撑
- 2020年高点（2075）延伸：构成2024-2025年主要阻力区

---

## 7. 机构订单流（订单簿）

**概念：** 黄金期货市场（COMEX）中，大型机构在特定价格设置大量限价单

**观察方式：**
- CME期货持仓报告（COT）：区分商业持仓 vs 非商业投机持仓
- 非商业多头持仓创历史新高 = 机构过度看多 = 反转风险
- 商业机构（黄金生产商）净空头 = 对冲风险，常作为反向指标

---

## 技术面分析检查清单

分析黄金时，按顺序检查：

1. ✅ 当前价格 vs MA50、MA200（趋势方向）
2. ✅ RSI 是否超买/超卖
3. ✅ MACD 动能方向与零轴位置
4. ✅ 布林带是否触及上下轨或收窄酝酿突破
5. ✅ 支撑位与阻力位（最近2-3个重要高低点）
6. ✅ 成交量是否配合（突破时量能放大 = 有效）
7. ✅ 斐波那契回撤位（38.2%、50%、61.8%）

---

## 时间周期共振原则

多个周期出现同一方向信号时，信号最强：

```
✅ 周线MACD金叉 + 日线RSI < 30 = 强买入信号
✅ 月线趋势向上 + 周线回调至MA50支撑 = 布局多单位
⚠️ 月线空头 + 日线超卖反弹 = 短线反弹对待，谨慎追多
```
