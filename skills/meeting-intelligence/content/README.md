# 智能会议助手（Meeting Intelligence）

## 技能简介

智能会议助手是一款专业的会议效率工具，旨在帮助职场人士高效管理会议全流程。从会前准备到会后追踪，一站式解决会议相关的所有痛点。

## 核心功能

- **智能解析**：支持语音转文字、聊天记录、文档等多格式输入
- **待办提取**：自动识别责任人、时间节点、完成标准，确保任务不遗漏
- **决策标记**：完整记录决策依据和执行标准，便于追溯
- **多格式输出**：支持 Word、PDF、Markdown、CSV、JSON 等格式
- **任务追踪**：自动关联责任人，支持导出到任务管理工具
- **模板复用**：提供多种专业会议模板，快速生成规范纪要
- **历史检索**：建立会议知识库，支持按项目、人员、时间检索

## 适用场景

- 周会复盘与周报生成
- 项目评审会完整记录
- 商务谈判与客户会议
- 团队头脑风暴
- 一对一绩效面谈
- 跨部门协调会议

|---------|---------|-----------|
| 周例会 | 30-60 分钟 | 低 |

## 支持的输入格式

- 语音转文字（Otter.ai、讯飞听见、飞书妙记、腾讯会议等）
- 文字聊天记录
- 文档（PDF、Word、Markdown）
- PPT 演示文稿
- 即时通讯内容

## 支持的输出格式

- Markdown
- Word（.docx）
- PDF
- CSV（任务清单）
- JSON（数据交换）

## 使用示例

### 示例一：周会纪要快速生成

上传一周的会议聊天记录或语音转文字内容，5 分钟内生成结构化周会纪要，包含本周进展、下周计划和待办任务。

### 示例二：项目评审会完整记录

处理复杂项目评审会，自动识别评审意见、决策结论和后续行动，确保每个评审点都有明确的跟进责任人。

### 示例三：待办任务自动追踪

从会议内容中提取所有待办任务，自动关联责任人，支持导出到任务管理工具，持续追踪直到完成。

### 示例四：决策历史追溯

建立决策知识库，可以按项目、人员、时间检索历史决策，了解决策背景和执行情况。
