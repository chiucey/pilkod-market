# Mosaic Diary · 碎片拼日记

把零散的句子按你选的方式（情绪 / 主题）整理成彩色卡片，再生成一篇有温度的日记 HTML。

## 怎么用

把你想记录的句子扔给我，可以一次扔、可以分多次扔，攒够了说一声"用情绪整理"或"用主题整理"，我就会给你生成一份带卡片的 HTML 日记。

**示例对话：**

> 你：今天加班到 10 点，累死了。同事送了杯奶茶，感动。
>
> 我：加进去 ✓ 现在 2 条。要继续加还是开始整理？
>
> 你：再补：和妈妈打电话聊了半小时。
>
> 我：加了 ✓ 现在 3 条。这次想用情绪分还是主题分？
>
> 你：情绪
>
> 我：[生成 HTML + 散文日记] 搞定！今天的情绪地图长这样 →

## 触发关键词

| 你说 | 我做什么 |
|------|---------|
| `加 / 追加` + 句子 | 写入句子池 |
| `看看 / 列出` | 显示已累积的所有句子 |
| `生成 / 整理` + 日记/卡片 | **先问"还要补点啥吗"**，再生成 |
| `够了 / 开整 / 就这样` | 确认生成 |
| `整理，别问了` | 跳过提问直接生成 |
| `改 / 调 / 换` + 内容 | 微调生成结果（改句子、换金句、换模式、删条目……）|
| `用情绪` / `mood` | 情绪模式 |
| `用主题` / `topic` | 主题模式 |
| `撤销` / `删最后` | 移除最近一条 |
| `重置` / `清空` | 清空句子池（需二次确认）|

## 分类模式

**🌈 情绪模式** — 开心、平静、感动、焦虑、低落、期待、怀旧……

**📂 主题模式** — 工作、学习、社交、家庭、爱好、健康、琐事、想法……

每张卡片会带：
- 类目名 + 图标
- 该类目专属颜色（左侧色条 + 项目符号）
- 句子的条数小标签
- 原始句子（不会被润色）

## 日记正文

卡片墙之外，会附一篇**约 200 字的散文**（克制、具体、不无病呻吟）：
- 第一人称，短句为主
- 1-2 处引用原话，**不堆砌**
- 结尾留白，不升华、不说教
- 避免"对自己好点""明天会更好"这种鸡汤腔

## 今日一句 💭

日记正文之后、卡片墙之前，会插入一句**真实名言**：
- 默认真实名人名言（汪曾祺、苏轼、老子、木心、王尔德…）
- 选句原则：与当天内容有呼应，不选烂大街的
- 30-80 字，引言式排版（上下装饰线 + 大引号 + 居中）
- 你也可以说"换一句 / 用某名言 / 今天想原创"

## 我的书单 📚

金句优先从你存的书单里选：
- `加书：汪曾祺` / `加作者：毛姆` / `加书：《人间草木》`
- `加书单：汪曾祺、毛姆、老子`（批量）
- `看书单` / `清空书单`
- 选中时 HTML 顶部会显示 "📚 引自：xxx"
- 书单为空时，从默认名言库里选

## 输出

HTML 是自包含的（CSS 内联、无外部依赖），双击就能用浏览器打开。
支持打印、转发、长期保存。
