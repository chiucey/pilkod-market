# AI提示词生成规范指南

## 文案类AI提示词模板

### 1. 品牌Slogan生成

```
【AI平台】：ChatGPT / 豆包 / Kimi
【适用岗位】：文案岗
【应用场景】：品牌定位期，生成核心口号

提示词模板：
请为[品牌名]生成[X]个品牌slogan，要求：
- 风格：[商务正式/创意活泼/互联网年轻化]
- 品牌调性：[描述品牌调性]
- 目标人群：[年龄段+特征]
- 核心卖点：[1-3个核心卖点]
- 字数限制：[X-Y]字
- 避免使用：[绝对化用语/行业禁忌词]
- 格式要求：直接输出slogan，附带简短释义
```

### 2. 产品卖点文案生成

```
【AI平台】：ChatGPT / 豆包
【适用岗位】：文案岗
【应用场景】：产品推广期

提示词模板：
请为[产品名]撰写产品卖点文案，要求：
- 产品类型：[品类]
- 目标人群：[精准描述]
- 核心卖点：[USP列表]
- 文案风格：[种草风/卖点罗列/情感共鸣/...]
- 适用渠道：[小红书/抖音/微博/详情页]
- 字数限制：[X-Y]字
- 必须包含元素：[明星成分/专利技术/用户证言/...]
- 规避要点：[夸大表述/违规用语]
```

### 3. 直播口播脚本

```
【AI平台】：ChatGPT
【适用岗位】：文案岗 / 策划岗
【应用场景】：直播带货

提示词模板：
请为[品牌/产品]撰写[X]分钟直播口播脚本，要求：
- 直播场景：[品牌自播/达人带货/专场直播]
- 目标GMV：[X万]
- 产品数量：[X款]
- 风格：[专业严谨/活泼亲切/粉丝福利向]
- 必须包含：开场话术、产品介绍、促单话术、结束话术
- 时长分配：开场[X]分钟/产品讲解每款[X]分钟/促单[X]分钟/结束[X]分钟
- 规避要点：虚假承诺、绝对化表述、竞品对比
```

## 图片类AI提示词模板

### 1. 品牌主视觉（Midjourney）

```
【AI平台】：Midjourney / Stable Diffusion
【适用岗位】：设计岗
【应用场景】：品牌主KV、户外大屏、官网banner

提示词模板：
[品牌名] brand visual poster, [风格描述],
[key visual元素描述], [光线描述],
[色彩方案], [构图方式], [画面比例],
[画质要求], [避免元素]
```

**示例**：
```
美妆品牌主视觉：
"SK-II brand visual poster, elegant Asian woman face close-up,
glassy skin texture, soft pink lighting, pastel color palette,
center composition, 16:9 aspect ratio, ultra high quality,
no text, no logo, no unnecessary elements"
```

## 视频类AI提示词模板

```
【适用岗位】：策划岗 / 设计岗
【应用场景】：15s-30s信息流广告、短视频种草
```

```
  1. 开场[X]秒：[场景+内容]
  2. 核心[X]秒：[场景+内容]

- 配乐建议：[风格描述]
```

## 行业定制AI提示词

### 美妆护肤行业

```
风格关键词：通透肌肤、光泽感、精致、品质感、高级感
规避要素：过度磨皮、虚假对比、夸大功效
标准表达：肌肤问题改善、帮助改善、温和配方
```

### 食品快消行业

```
风格关键词：食欲感、新鲜、活力、场景化、生活方式
规避要素：过度PS食材、虚假宣传、绝对化表述
标准表达：以实物为准、精选原料、真材实料
```

### 金融行业

```
风格关键词：稳健、专业、可信赖、安全、品质
规避要素：夸大收益、承诺保本、对比银行利率
标准表达：历史业绩仅供参考、风险提示、稳健增值
```

### 医疗健康行业

```
风格关键词：专业、权威、温和、安心、科学
规避要素：治愈率、保证疗效、患者推荐
标准表达：帮助改善、辅助治疗、仅供参考
```
