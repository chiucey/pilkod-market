# 游戏测试用例生成技能 - 使用说明

## 快速开始

### 第一步：准备需求文档
上传游戏活动需求文档，支持以下格式：
- Excel (.xlsx, .xlsm)
- Word (.docx)
- PDF (.pdf)

### 第二步：触发技能
在对话中描述您的需求，例如：
> "请根据xxx活动需求文档生成测试用例"

### 第三步：获取输出
技能将自动生成：
1. Markdown格式测试用例表格
2. Excel格式测试用例文档（奖励相关用例已标识）

## 测试用例模板说明

### Excel模板字段

| 字段 | 说明 | 示例 |
|------|------|------|
| 序号 | 用例ID（模块_序号） | 红包雨_001 |
| 模块 | 功能模块名称 | 红包雨 |
| 子模块 | 子功能模块 | 活动基础规则 |
| 测试类型 | 测试分类 | 功能验收 |
| 测试点 | 测试详细描述 | 验证活动开启时间为3天 |
| 测试结果 | 测试结果（预留） | p/f/f-p |
| 备注 | 补充说明（预留） | - |

### 颜色标识

- **奖励相关**用例行使用 `#FBE5D6` 橙色背景色填充
- 便于在大量用例中快速识别奖励相关测试点

## 测试类型说明

| 测试类型 | 适用场景 | 示例 |
|---------|----------|------|
| 功能验收 | 功能逻辑验证 | 按钮点击、界面跳转 |
| 界面验收 | UI展示验证 | 文本显示、图标位置 |

## 常见问题

### Q: 如何增加边界测试用例？
A: 技能会根据业务场景自动补充边界测试用例，覆盖按钮状态、数量边界、时间边界、奖励概率等。

### Q: 需求文档不完整怎么办？
A: 技能会识别并列出需求中的不明确之处，作为风险提示输出。

### Q: 如何验证概率测试？
A: 建议使用100+样本进行概率验证，技能会生成对应的边界测试用例。
