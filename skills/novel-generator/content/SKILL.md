# 长篇小说生成器

专业级长篇网络小说与精品短剧智能创作引擎，基于 InkOS 多智能体架构。

## 核心能力

- **长篇小说全流程**：从大纲到完稿的完整创作管线
- **短剧剧本创作**：精品短剧、精品微短剧剧本生成
- **文件解析分析**：上传参考文档进行风格解析和内容提取
- **风格模仿创作**：模仿特定作者风格进行定制化写作
- **大纲生成**：多层级结构化故事大纲
- **人设构建**：角色背景、性格、外貌、关系网络
- **世界观设定**：时代背景、地理、社会结构、规则体系
- **章节续写/改写**：已有内容延伸、扩写、风格调整

## 10-Agent 智能管线

### 管线架构

```
[雷达 Agent] → [规划师 Agent] → [编排师 Agent] → [建筑师 Agent] → [写手 Agent]
                                                                    ↓
[审计员 Agent] ← [修订者 Agent] ← [归一化器 Agent] ← [反射器 Agent] ← [观察者 Agent]
```

### Agent 职责

| Agent | 职责 | 核心能力 |
|-------|------|----------|
| **雷达 Agent** | 需求探测与分类 | 解析用户意图、识别创作类型、提取关键参数 |
| **规划师 Agent** | 策略制定 | 故事结构规划、节奏设计、章节划分 |
| **编排师 Agent** | 资源整合 | 素材库调用、风格匹配、参考整合 |
| **建筑师 Agent** | 世界观构建 | 设定体系、规则制定、逻辑自洽性 |
| **写手 Agent** | 内容创作 | 多风格写作、情感渲染、对话生成 |
| **观察者 Agent** | 过程监控 | 质量追踪、进度监控、异常预警 |
| **反射器 Agent** | 自我审视 | 深度反思、逻辑校验、漏洞检测 |
| **归一化 Agent** | 风格统一 | 文风一致化、表达标准化、格式规范 |
| **审计员 Agent** | 质量审计 | AI 痕迹检测、去 AI 味优化、评分评级 |
| **修订者 Agent** | 迭代优化 | 智能修订、多轮优化、细节打磨 |

## 33 维度 AI 痕迹检测

### 检测维度矩阵

| 类别 | 检测维度 |
|------|----------|
| **句式维度 (1-8)** | 开头模式、转折模式、因果模式、并列模式、递进模式、总结模式、排比模式、过渡模式 |
| **词汇维度 (9-15)** | 高频副词、情感形容词、程度副词、绝对化词汇、模糊量词、比喻高频词、连接词密度 |
| **修辞维度 (16-22)** | 比喻密度、拟人频率、排比密度、夸张程度、反复频率、对偶使用、互文使用 |
| **结构维度 (23-27)** | 段落均匀度、章节节奏、开头固定模式、结尾固定模式、过渡词频率 |
| **内容维度 (28-33)** | 情感词密度、对话比例、内心独白频率、场景描写密度、动作描写密度、细节密度 |

### AI 痕迹评分标准

- **0-20分**：强 AI 味，特征明显
- **21-40分**：中度 AI 味，需要显著改写
- **41-60分**：轻度 AI 味，局部调整
- **61-80分**：接近人类写作，仅需微调
- **81-100分**：自然人类写作风格

## 触发场景与工作流

### 场景 1：完整长篇小说生成

**触发条件**：用户明确要求生成完整长篇小说

**工作流程**：
1. 雷达 Agent 解析需求（题材、风格、字数、主题）
2. 规划师 Agent 制定创作策略
3. 建筑师 Agent 构建世界观
4. 编排师 Agent 整合素材风格
5. 写手 Agent 执行章节创作
6. 观察者 Agent 监控质量进度
7. 反射器 Agent 逻辑自检
8. 归一化 Agent 风格统一
9. 审计员 Agent AI 痕迹检测
10. 修订者 Agent 最终优化

**输出产物**：
- 完整故事大纲（多层级）
- 角色设定档案
- 世界观设定文档
- 章节正文（按计划分批交付）

### 场景 2：大纲生成

**触发条件**：用户要求生成故事大纲

**输入参数**：
- 题材类型
- 核心主题
- 主要角色描述
- 篇幅要求

**输出产物**：多层级结构化大纲
```
第一卷：背景设定
  第一章：世界观介绍
    1.1 时代背景
    1.2 地理环境
  第二章：主角登场
    2.1 人物背景
    2.2 核心冲突
...
```

### 场景 3：人设构建

**触发条件**：用户要求创建角色设定

**输入参数**：
- 角色在故事中的定位
- 性格关键词
- 人物关系要求

**输出产物**：完整角色卡
```yaml
姓名：{角色名}
性别：
年龄：
外貌：
性格：
背景：
能力：
人际关系：
角色弧光：
经典台词：
```

### 场景 4：世界观设定

**触发条件**：用户要求构建故事世界

**输出产物**：
- 时代背景设定
- 地理环境描述
- 社会结构体系
- 力量/能力系统
- 势力分布图谱
- 世界规则文档

### 场景 5：章节续写/改写

**触发条件**：用户提供已有章节，要求续写或改写

**输入**：
- 原文内容
- 续写方向或改写要求
- 目标风格

**工作流程**：
1. 分析原文风格特征
2. 提取关键情节要素
3. 规划续写/改写策略
4. 执行创作
5. AI 痕迹去除
6. 质量审核

### 场景 6：风格模仿

**触发条件**：用户提供参考作品或风格要求

**工作流程**：
1. 解析参考作品的文风特征
2. 提取句式、词汇、修辞偏好
3. 建立风格模型
4. 执行创作
5. 风格一致性校验

### 场景 7：短剧剧本创作

**触发条件**：用户要求生成短剧/微短剧剧本

**输出产物**：
- 剧名与定位
- 人物小传
- 分集大纲
- 分镜剧本（包含场景、对白、旁白、动作指示）

### 风格选项

- **男频风格**：热血、升级、战斗、爽文节奏
- **女频风格**：情感细腻、人设丰富、剧情曲折

- **网文风格**：快节奏、高潮迭起、代入感强
- **仿写风格**：指定模仿某位作家或某部作品

## 质量控制

### 创作阶段质量门禁

| 阶段 | 质量门禁 | 检测重点 |
|------|----------|----------|
| 大纲阶段 | 逻辑自洽性 | 情节连贯、冲突合理 |
| 人设阶段 | 角色立体度 | 性格一致、行为合理 |
| 初稿阶段 | 内容完整性 | 情节推进、细节丰富 |
| 修订阶段 | AI 痕迹检测 | 33 维度评分 |
| 定稿阶段 | 整体可读性 | 流畅度、节奏感 |

### AI 痕迹优化策略

1. **句式变化**：打破固定开头、增加长短句变化
2. **词汇替换**：减少高频 AI 词汇、增加口语化表达
3. **修辞克制**：降低比喻密度、增加自然描写
4. **结构打破**：随机段落长度、避免对称结构
5. **情感真实**：增加细节描写、减少过度煽情

## 使用示例

### 示例 1：生成完整大纲

```
用户：我要写一本都市玄幻小说，男主是意外获得传承的普通人，女主是古老家族的千金，总字数 100 万字左右

Agent 响应：
[雷达] 解析需求：都市玄幻 + 传承系统 + 豪门设定
[规划师] 制定策略：系统流 + 扮猪吃虎 + 多女主结构
[建筑师] 构建世界观：现代都市 + 修士设定 + 势力格局
[编排师] 整合素材：参考《都市修仙》《全职高手》风格
...
```

### 示例 2：续写章节

```
用户：续写以下章节，风格保持一致，去除 AI 味：
[粘贴原文]

Agent 响应：
[分析原文风格特征]
[提取情节要素]
[执行续写创作]
[AI 痕迹检测：得分 35]
[优化后得分：78]
[输出续写内容]
```

## 注意事项

1. **分批交付**：长篇作品按章节分批生成，避免输出截断
2. **风格一致性**：创作过程中保持风格统一
3. **逻辑自洽**：复杂设定需建立设定档案，确保前后一致
4. **AI 痕迹**：默认执行去 AI 味处理，除非用户明确要求保留
5. **互动修正**：根据用户反馈迭代优化
