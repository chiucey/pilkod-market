# 世界观构建指南

## 世界观构建流程

### 第一步：核心设定确定

```
[确定主题] → [选定基调] → [构建核心规则] → [设计主线冲突]
```

**核心问题清单**：

1. 这个世界的核心魅力是什么？
2. 主角在这个世界中追求什么？
3. 世界规则如何服务于故事？
4. 这个世界有什么独特之处？

### 第二步：多层构建框架

```
┌─────────────────────────────────────┐
│          宏观层面（世界格局）          │
├─────────────────────────────────────┤
│          中观层面（势力/组织）          │
├─────────────────────────────────────┤
│          微观层面（人物/日常）          │
└─────────────────────────────────────┘
```

## 力量/能力体系

### 体系设计原则

| 原则 | 说明 | 示例 |
|------|------|------|
| 层级清晰 | 能力等级分明 | 青铜/白银/黄金 |
| 代价平衡 | 能力有代价 | 燃烧寿命/使用限制 |
| 独特性 | 避免同质化 | 独特修炼方式 |
| 可视化 | 能力表现具象 | 颜色/形态/特效 |

## 势力架构设计

### 势力类型库

| 势力类型 | 特点 | 典型代表 |
|----------|------|----------|
| 宗门/门派 | 传承性、系统化 | 少林、武当、各大玄幻宗门 |
| 家族/世家 | 血脉传承、利益纠葛 | 古武世家、修真家族 |
| 国家/帝国 | 政治实体、军队力量 | 皇权体系、帝国统治 |
| 商会/财团 | 经济控制、暗中操纵 | 经济寡头、商业帝国 |
| 神秘组织 | 目的不明、高度隐秘 | 杀手组织、情报网络 |
| 宗教/教会 | 信仰力量、精神控制 | 圣殿骑士团、光明教廷 |
| 独立势力 | 强者个人、超然物外 | 散修联盟、游侠团体 |

| 要素 | 说明 | 创作要点 |
|------|------|----------|
| 地形分布 | 山脉、平原、沙漠等 | 影响势力划分 |
| 气候特征 | 四季分明/常年冰雪 | 特色文化 |

## 世界观一致性检查

### 逻辑自洽检查清单

- [ ] 力量体系是否前后一致
- [ ] 势力分布是否合理
- [ ] 社会结构是否符合逻辑
- [ ] 地理环境是否影响剧情
- [ ] 规则设定是否产生预期冲突
- [ ] 设定细节是否为主线服务

### 设定优先级

| 优先级 | 设定类型 | 详细程度 |
|--------|----------|----------|
| 核心设定 | 力量体系、核心冲突 | 极其详细 |
| 重要设定 | 主要势力、重要地点 | 详细 |
| 一般设定 | 配角背景、次要势力 | 概要 |
| 背景设定 | 历史文化、风土人情 | 可后续补充 |

## 世界观服务于故事

### 设定取材原则

1. **有用性**：设定要服务于剧情
2. **选择性**：不要面面俱到
3. **渐进式**：随着剧情展开设定
4. **记忆点**：每个设定要有独特记忆点

### 常见世界观陷阱

| 陷阱 | 问题 | 解决方案 |
|------|------|----------|
| 设定堆砌 | 大量设定但与剧情无关 | 删减不必要设定 |
| 前后矛盾 | 不同章节设定冲突 | 建立设定档案 |
| 力量崩坏 | 战力随剧情忽高忽低 | 严格等级划分 |
| 细节缺失 | 世界观空洞不立体 | 补充生活细节 |
