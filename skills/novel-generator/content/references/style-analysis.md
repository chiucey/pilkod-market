# 文风分析手册

## 网文风格分类

### 男频主流风格

#### 1. 热血爽文风

**特征**：

```yaml
节奏特点：
  - 语速：快节奏，短句为主
  - 段落：短小精悍，段落密集
  - 高潮：高频出现，平均3章一个小高潮

句式特征：
  - 短句多："他一拳轰出！"
  - 感叹句多："太强了！"
  - 疑问句多："这怎么可能？"

词汇偏好：
  - 战斗类：碾压、秒杀、轰、爆
  - 升级类：突破、暴涨、飙升
  - 情感类：霸气、王者、无敌

修辞特点：
  - 夸张手法大量使用
  - 数字强调："一拳，足足十万斤！"
  - 对比强调："蝼蚁与巨龙"
```

**代表作品**：《全职高手》《斗破苍穹》《完美世界》

#### 2. 腹黑谋略风

**特征**：

```yaml
节奏特点：
  - 语速：稳健，信息量大
  - 段落：中等长度，逻辑严密
  - 高潮：较少但质量高

句式特征：
  - 复合句多："既然...那么..."
  - 推理句多："因为...所以..."
  - 反问句多："你以为...？"

词汇偏好：
  - 谋略类：算计、布局、洞察
  - 心理类：阴沉、深邃、莫测
  - 冷静类：淡然、从容、不屑

修辞特点：
  - 伏笔密集
  - 心理描写细腻
  - 对话暗藏机锋
```

**代表作品**：《庆余年》《琅琊榜》《雪中悍刀行》

#### 3. 轻松幽默风

**特征**：

```yaml
节奏特点：
  - 语速：明快，不压抑
  - 段落：长短交错
  - 高潮：张弛有度，笑点与燃点并存

句式特征：
  - 吐槽句多："这就很尴尬了"
  - 口语化："我去""绝了"
  - 自嘲句多

词汇偏好：
  - 吐槽类：扎心、泪目、真香
  - 幽默类：搞笑、神转折
  - 网络流行词

修辞特点：
  - 大量玩梗
  - 轻松对话
  - 适度自嘲
```

**代表作品**：《大王饶命》《我欲封天》

### 女频主流风格

#### 1. 甜宠文风

**特征**：

```yaml
情感基调：
  - 主色：甜蜜、温馨
  - 甜度：中高糖，虐也是为了甜
  - 情感：细腻、缠绵

句式特征：
  - 短句与长句交替
  - 感叹句："心跳加速""脸红"
  - 省略号多："他...他怎么..."

词汇偏好：
  - 甜词：宠溺、心动、沦陷
  - 描写：耳尖泛红、眸光温柔
  - 男主称呼：霸道、温柔、腹黑

修辞特点：
  - 细节描写丰富
  - 心理描写占比较大
  - 肢体接触细节
```

**代表作品**：《何以笙箫默》《微微一笑很倾城》

#### 2. 虐恋情深风

**特征**：

```yaml
情感基调：
  - 主色：虐心、虐身
  - 甜虐比例：3:7 或 2:8
  - 情感：撕心裂肺、刻骨铭心

句式特征：
  - 长句多："她以为...却不曾想..."
  - 悲情词多：心碎、眼泪、绝望
  - 反问多："为什么...？"

词汇偏好：
  - 虐词：背叛、误会、虐心
  - 身体描写：苍白、虚弱、伤痕
  - 隐忍词：沉默、苦笑、倔强

修辞特点：
  - 场景渲染强烈
  - 对比反差大
  - 误会与错过
```

**代表作品**：《东宫》《十年三月七日》

#### 3. 大女主风

**特征**：

```yaml
情感基调：
  - 主色：独立、自主、成长
  - 平衡：事业与感情并重
  - 情感：理性、自主选择

句式特征：
  - 干脆利落
  - 独立句多
  - 决定句："我要..."、"我不会..."

词汇偏好：
  - 成长词：蜕变、崛起、逆袭
  - 能力词：实力、格局、智慧
  - 自主词：选择、掌控、主宰

修辞特点：
  - 内心独白多
  - 决策过程详细
  - 强调自我价值
```

**代表作品**：《扶摇》《知否知否应是绿肥红瘦》

## 风格分析维度

### 句式分析矩阵

| 维度 | AI典型特征 | 人类写作特征 |
|------|------------|--------------|
| 开头句式 | 固定模式（如"只见..."、"就在这时..."） | 变化多样 |
| 段落长度 | 过于均匀 | 长短交错 |
| 连接词 | 过度使用连接词 | 自然过渡 |
| 句式结构 | 高度相似 | 多样化 |

### 词汇密度分析

```yaml
AI高风险词汇：
  - 高频副词："突然"、"竟然"、"居然"
  - 程度副词："非常"、"极其"、"相当"
  - 情感词："高兴地说"、"悲伤地"
  - 固定搭配："与此同时"、"因此"

人类写作特征：
  - 口语化表达
  - 地域特色词
  - 个人习惯词
  - 时代流行语
```

## 风格模仿指南

### 分析步骤

1. **采样分析**
   - 提取至少 3 万字的样本
   - 统计句式分布
   - 识别高频词汇

2. **特征提取**
   ```yaml
   句式特征：
     - 平均句长：[字数]
     - 短句比例：[百分比]
     - 感叹句频率：[百分比]

   词汇特征：
     - 高频形容词
     - 高频副词
     - 特色名词
     - 口头禅/金句

   修辞特征：
     - 比喻类型偏好
     - 描写详略偏好
     - 情感表达方式
   ```

3. **建立风格模型**
   - 创建风格字典
   - 制定句式规则
   - 定义情感基调

### 模仿执行

```yaml
写作时注意：
  - 句式长度变化
  - 词汇替换
  - 节奏把控
  - 风格一致性

质量检查：
  - AI痕迹扫描
  - 风格匹配度
  - 可读性评估
```

## 网文风格与平台适配

### 主流平台风格偏好

| 平台 | 风格偏好 | 节奏要求 | 字数要求 |
|------|----------|----------|----------|
| 起点中文网 | 爽文、系统流 | 极快 | 日更3000+ |
| 晋江文学城 | 感情细腻 | 中等 | 日更2000+ |
| 飞卢小说网 | 快节奏 | 极快 | 日更5000+ |
| 番茄小说 | 轻松小白文 | 快 | 日更4000+ |
| 七猫小说 | 免费爽文 | 快 | 日更3000+ |

### 平台禁忌

```yaml
起点禁忌：
  - 开局女主太多
  - 节奏太慢
  - 三观不正

晋江禁忌：
  - 男主不洁
  - 过度种马
  - 文笔粗糙

飞卢禁忌：
  - 节奏慢
  - 废话多
  - 不够爽

番茄禁忌：
  - 内容低俗
  - 过度敏感
  - 更新不稳定
```
