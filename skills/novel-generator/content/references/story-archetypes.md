# 故事原型与叙事结构

## 经典故事原型

### 1. 英雄之旅（The Hero's Journey）

**适用类型**：玄幻、奇幻、修仙、成长类小说

**12 阶段结构**：

| 阶段 | 描述 | 小说中的应用 |
|------|------|--------------|
| 普通世界 | 主角的日常生活 | 平凡的开端 |
| 冒险召唤 | 命运的转折点 | 奇遇、传承获得 |
| 拒绝召唤 | 主角的犹豫 | 初期的不安 |
| 遇见导师 | 引导者出现 | 师父、神秘人 |
| 跨越门槛 | 进入冒险世界 | 离开家乡/踏入修炼 |
| 试炼与盟友 | 挑战与伙伴 | 升级打怪、结交朋友 |
| 接近深穴 | 接近最大挑战 | 核心冲突逼近 |
| 最大考验 | 生死关头 | 决战、突破 |
| 获得奖赏 | 胜利的果实 | 获得神器/能力 |
| 返回之路 | 回归的旅程 | 回归日常/新的开始 |
| 复活重生 | 脱胎换骨 | 重大转折/觉醒 |
| 带回万能药 | 改变的世界 | 结局与传承 |

### 2. 三幕结构（Three-Act Structure）

**适用类型**：都市言情、职场、悬疑

**结构划分**：

```
第一幕（25%）：建置
├── 设定世界观
├── 引出主角
├── 展示日常生活
├── 触发事件打破平衡
└── 第一转折点

第二幕（50%）：对抗
├── 主角的挣扎
├── 新的挑战出现
├── 中点转折
├── 反派逼近
└── 第二转折点（最低点）

第三幕（25%）：解决
├── 高潮对决
├── 解决冲突
├── 结局收束
└── 新平衡建立
```

### 3. 起承转合（经典四段式）

**适用类型**：短篇故事、章节结构

| 阶段 | 功能 | 字数占比 |
|------|------|----------|
| 起 | 交代背景，引出人物 | 10-15% |
| 承 | 发展情节，埋下伏笔 | 25-30% |
| 转 | 冲突升级，高潮来临 | 35-40% |
| 合 | 解决问题，收束结尾 | 15-20% |

## 网文节奏模型

### 快节奏爽文结构

**核心原则**：
- 3 章一个小高潮
- 10 章一个中等高潮
- 30 章一个大高潮
- 每章结尾留钩子

**节奏公式**：
```
冲突 → 压抑 → 爆发 → 反转 → 收获
```

### 慢热型结构

**核心原则**：
- 前 10 章铺垫世界观
- 人物关系层层递进
- 30 章后渐入高潮
- 情感渲染为主

## 常见叙事视角

| 视角 | 优势 | 劣势 | 适用类型 |
|------|------|------|----------|
| 第一人称（我） | 代入感强 | 视野受限 | 都市、校园、悬疑 |
| 第三人称全知 | 信息量大 | 代入感弱 | 史诗、群像、宏观叙事 |
| 第三人称限知 | 平衡适中 | 切换复杂 | 大多数类型 |
| 多视角交叉 | 立体丰富 | 难度高 | 权谋、战争、复杂剧情 |

## 章节结构模板

### 黄金三章模板

```markdown
## 第一章：开篇钩子

### 开头（100-300字）
- 场景描写或冲突画面
- 直接进入核心事件
- 制造悬念

### 发展（1000-2000字）
- 展开核心冲突
- 展示主角能力/性格
- 埋下伏笔

### 结尾（200-500字）
- 留下钩子
- 反转或悬念
- 引发读者期待
```

### 章末钩子技巧

1. **冲突未决**：正当紧张时刻戛然而止
2. **意外发生**：突然的反转或惊喜
3. **信息透露**：关键信息即将揭晓
4. **情绪高点**：情感最浓烈时收尾
5. **悬念提问**：留下疑问引发好奇

## 情节类型库

### 冲突类型

- **外在冲突**：与敌人、环境、社会的对抗
- **内在冲突**：内心的挣扎与成长
- **人际冲突**：与亲友、爱人、伙伴的矛盾
- **命运冲突**：与宿命、预言的抗争

### 经典情节模式

1. **复仇型**：正义或黑暗的复仇之路
2. **成长型**：从弱小到强大的蜕变
3. **追寻型**：寻找某人/某物/真相
4. **救赎型**：弥补过去的错误
5. **三角恋**：情感纠葛与抉择
6. **逆袭型**：从低谷走向巅峰
7. **守护型**：保护某人或某物
8. **阴谋型**：揭露真相与对抗幕后黑手

## 伏笔与呼应技巧

### 伏笔类型

1. **人物伏笔**：身份、性格、能力的后续揭示
2. **物件伏笔**：重要道具的提前出现
3. **话语伏笔**：日后应验的言语
4. **环境伏笔**：场景细节的后续关联
5. **情感伏笔**：感情发展的前期铺垫

### 呼应技巧

- **首尾呼应**：开头与结尾的主题呼应
- **前后呼应**：前文细节在后续重现
- **人物呼应**：相似场景中人物的对比
- **情节呼应**：相似困境中不同选择的结果
