# AI 痕迹检测详解

## 33 维度检测矩阵

### 句式维度 (1-8)

#### 维度1：开头模式检测

```yaml
AI典型开头：
  - "只见..." （70%的AI写作使用）
  - "就在这时..."
  - "令人惊讶的是..."
  - "不料..."
  - "然而..."

人类写作开头：
  - 直接进入场景
  - 变化多样
  - 有个人特色

检测方法：
  1. 统计"只见"出现频率
  2. 检测固定句式开头比例
  3. 分析开头多样性指数
```

#### 维度2：转折模式检测

```yaml
AI典型转折：
  - "却不料..." → 意外转折
  - "没想到..." → 认知反差
  - "但是..." → 简单转折
  - "然而..." → 预期违背

人类写作转折：
  - 埋线式转折
  - 渐进式揭示
  - 自然因果
  - 意料之外情理之中

检测阈值：
  - AI味道阈值：转折句中固定模式 > 40%
  - 正常范围：< 20%
```

#### 维度3：因果模式检测

```yaml
AI典型因果：
  - 过度解释因果关系
  - 因果连接词密集
  - 逻辑链条过于清晰

常见问题句式：
  - "因为A，所以B，于是C，结果D"
  - "这使得..."
  - "从而导致..."

人类写作特点：
  - 省略因果解释
  - 让读者自己推理
  - 自然流畅
```

#### 维度4-8：其他句式维度

| 维度 | AI典型特征 | 检测指标 |
|------|------------|----------|
| 并列模式 | "一方面...另一方面..."过度使用 | 并列连接词密度 |
| 递进模式 | "甚至...更...最为..."固定递进 | 递进词频率 |
| 总结模式 | "综上所述...总之..."频繁出现 | 总结句比例 |
| 排比模式 | 多项并列过于整齐 | 排比结构密度 |
| 过渡模式 | 过渡词使用规律化 | 过渡模式规律性 |

### 词汇维度 (9-15)

#### 维度9：高频副词检测

```yaml
AI高频副词黑名单：
  高风险：
    - 突然（> 3次/千字）
    - 竟然
    - 居然
    - 十分
    - 非常
    - 极其
    - 相当

  中风险：
    - 微微
    - 缓缓
    - 轻轻
    - 渐渐
    - 明显

检测标准：
  - 千字高频副词 > 8次 → 高AI味
  - 千字高频副词 4-8次 → 中AI味
  - 千字高频副词 < 4次 → 低AI味
```

#### 维度10-15：其他词汇维度

| 维度 | AI典型特征 | 检测方法 |
|------|------------|----------|
| 情感形容词 | "美丽的"、"善良的"过度使用 | 形容词密度 |
| 程度副词 | "很"、"非常"、"极其"堆砌 | 程度副词比例 |
| 绝对化词汇 | "所有"、"全部"、"永远" | 绝对词频率 |
| 模糊量词 | "许多"、"一些"、"大量" | 量化词精确度 |
| 比喻高频词 | 固定比喻词反复使用 | 比喻多样性 |
| 连接词密度 | "但是"、"而且"、"因此"过密 | 连接词占比 |

### 修辞维度 (16-22)

#### 维度16：比喻密度检测

```yaml
AI比喻问题：
  - 比喻过于直白
  - 比喻类型单一
  - 重复使用相似比喻

问题示例：
  - "如同一把利剑"出现5次+
  - "像...一样"句式反复
  - 隐喻使用不当

人类写作特点：
  - 比喻有新意
  - 多种比喻交替
  - 留白与含蓄

检测阈值：
  - 比喻密度 > 15%/千字 → 高AI味
  - 比喻类型 < 5种 → 异常
```

#### 维度17-22：其他修辞维度

| 维度 | AI典型特征 | 问题程度 |
|------|------------|----------|
| 拟人频率 | 过度拟人化 | 中 |
| 排比密度 | 排比过于工整 | 高 |
| 夸张程度 | 不切实际的夸张 | 中 |
| 反复频率 | 词句重复使用 | 高 |
| 对偶使用 | 刻意对仗 | 中 |
| 互文使用 | 模式化互文 | 低 |

### 结构维度 (23-27)

#### 维度23：段落均匀度检测

```yaml
AI段落问题：
  - 段落长度过于均匀
  - 理想值：150-200字
  - 变化指数 < 0.3

人类写作特点：
  - 段落长短交错
  - 根据内容灵活调整
  - 变化指数 > 0.5

检测方法：
  1. 统计段落长度标准差
  2. 计算变化指数
  3. 分析分布曲线
```

#### 维度24-27：其他结构维度

| 维度 | AI典型特征 | 检测重点 |
|------|------------|----------|
| 章节节奏 | 过于规律 | 节奏变化分析 |
| 开头固定 | 固定模式开头 | 开头多样性 |
| 结尾固定 | 固定模式结尾 | 结尾多样性 |
| 过渡词频率 | 过渡词使用规律 | 过渡自然度 |

### 内容维度 (28-33)

#### 维度28：情感词密度检测

## AI 痕迹评分系统

### 综合评分计算

```yaml
评分公式：
  总分 = Σ(维度权重 × 维度得分) / Σ维度权重

权重分配：
  - 句式维度（1-8）：权重 1.0
  - 词汇维度（9-15）：权重 1.2
  - 修辞维度（16-22）：权重 0.8
  - 结构维度（23-27）：权重 0.9
  - 内容维度（28-33）：权重 1.5（最重要）
```

### 评分等级

| 等级 | 分数范围 | 含义 | 处理建议 |
|------|----------|------|----------|
| A | 81-100 | 自然人类写作 | 仅需微调 |
| B | 61-80 | 接近人类写作 | 局部优化 |
| C | 41-60 | 轻度AI味 | 需要改写 |
| D | 21-40 | 中度AI味 | 显著改写 |
| F | 0-20 | 强AI味 | 大量重写 |

## 去 AI 味优化指南

### 优化策略清单

#### 句式优化

```yaml
1. 打破固定开头
   - 减少"只见..."、"就在这时..."
   - 使用多样化开头

2. 增加长短句变化
   - 目标：句子长度变化 > 50%
   - 短句增加张力
   - 长句增加信息量

3. 减少因果解释
   - 删除"这使得..."、"从而..."
   - 让逻辑自己呈现

4. 增加自然过渡
   - 减少连接词
   - 使用场景转换而非词语过渡
```

#### 词汇优化

```yaml
1. 替换高频副词
   - "突然" → "猛地"、"瞬间"
   - "非常" → 删除或具体化

2. 减少程度副词
   - "极其" → 删除
   - "十分" → 改为具体描写

3. 增加口语化
   - 加入方言
   - 加入口头禅
   - 加入语气词

4. 丰富词汇
   - 同义词替换
   - 避免重复
```

#### 修辞优化

```yaml
1. 比喻优化
   - 减少明喻
   - 增加暗喻/借代
   - 减少"像...一样"

2. 情感描写优化
   - 减少直接情感标注
   - 增加动作暗示
   - 留白给读者

3. 排比优化
   - 打破工整
   - 减少排比频率
```

#### 内容优化

```yaml
1. 增加细节真实感
   - 加入具体数字
   - 加入真实细节
   - 加入个人特色

2. 平衡描写
   - 不要过度描写
   - 不要描写不足
   - 根据情节需要调整

3. 增强代入感
   - 使用第二人称"你"
   - 增加互动感
   - 减少说教感
```

## AI 痕迹检测流程

```yaml
检测流程：

Step 1: 文本预处理
  - 去除格式标记
  - 统一编码
  - 分句分词

Step 2: 维度检测
  - 逐维度分析
  - 统计各维度指标
  - 标记异常点

Step 3: 综合评分
  - 加权计算总分
  - 确定等级
  - 生成报告

Step 4: 优化建议
  - 针对每个问题点
  - 提供修改建议
  - 生成优化后版本

Step 5: 最终验证
  - 再次检测
  - 确认达标
  - 输出定稿
```

## 实战案例

### 案例一：高AI味段落

```yaml
原文（得分：28分，D级）：
  "只见他突然站了起来，眼中闪过一丝惊讶，
  然后缓缓地说道：'这真是太不可思议了！'
  他感到心中充满了喜悦，因为这意味着..."

问题点：
  - "只见"开头
  - "突然"高频
  - 情感直接标注
  - 因果连接词过多

优化后（得分：76分，B级）：
  "他猛地从椅子上弹起。
  "这...怎么可能？"他听到自己的声音在发抖。
  成了。"

得分提升：48分
```

### 案例二：中等AI味段落

```yaml
原文（得分：52分，C级）：
  "她轻轻地推开了门，映入眼帘的是...
  房间里面非常安静，只能听到...
  她的心中微微有些紧张..."

问题点：
  - "轻轻地"过度使用
  - "非常"副词
  - 情感描写直白

优化后（得分：71分，B级）：
  "门把手冰凉。
  屋内漆黑，只有窗帘缝隙漏进一线光。
  她站在门口，脚却迈不进去。"

得分提升：19分
```
