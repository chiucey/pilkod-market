## 角色关系设定

### 常见关系类型

| 关系类型 | 特点 | 戏剧张力 |
|----------|------|----------|
| 师徒 | 传承、教导、超越 | 徒弟成长后的抉择 |
| 兄弟/闺蜜 | 陪伴、支持、背叛 | 利益面前的考验 |
| 欢喜冤家 | 互怼、日久生情 | 从对立到认可 |
| 青梅竹马 | 了解、默契、暗恋 | 迟来的告白 |
| 契约关系 | 交易、假结婚、假男友 | 假戏真做 |
| 宿敌/竞争 | 对抗、追赶、相互成就 | 既是敌人也是动力 |
| 救命恩人 | 报恩、依赖、愧疚 | 情感的复杂纠葛 |
| 身份差距 | 豪门/穷小子、千金/普通人 | 阶层冲突 |

### CP 组合公式

#### 男频 CP

- **标配组合**：废柴男主 + 白富美/大小姐
- **热血组合**：草根男主 + 战斗系女主
- **智谋组合**：腹黑男主 + 聪明女主
- **治愈组合**：受伤男主 + 温暖女主

#### 女频 CP

- **霸道总裁**：多金、霸道、专情
- **阳光暖男**：温暖、守护、无条件支持
- **腹黑竹马**：腹黑、深情、等她多年
- **禁欲系**：高冷、克制、后期爆发
- **狼狗型**：奶狗外表、狼性内核
- **小狼狗**：年下、撒娇、占有欲强

## 角色塑造技巧

### 立体角色三要素

1. **核心欲望**：角色最想要什么
2. **行为动机**：为什么想要
3. **行动方式**：如何追求

### 人设一致性检查

- [ ] 性格与行为是否一致
- [ ] 语言风格是否符合身份
- [ ] 做决定的方式是否一致
- [ ] 成长变化是否有迹可循
- [ ] 弱点是否影响核心能力

### 角色记忆点设计

| 类型 | 示例 |
|------|------|
| 外貌记忆点 | 眼角泪痣、酒窝、虎牙 |

| 口头禅记忆点 | 标志性的口头禅 |
| 技能记忆点 | 招牌技能/绝招 |
| 物件记忆点 | 随身携带的物品 |
