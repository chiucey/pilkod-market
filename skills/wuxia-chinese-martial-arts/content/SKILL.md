# 胡金铨国风武侠风格技能

> **Author**: 起始终下
> **Copyright**: © 2025 起始终下. All Rights Reserved.

---

## 技能定位

本技能将用户的图像需求转化为胡金铨武侠美学风格的Prompt，专门适配千问系列图像生成模型。

**核心价值**：传承中国水墨画美学，以写意手法呈现武侠世界的侠骨柔情与江湖意境。

---

## 适用场景

### 主要适用场景

| 场景类型 | 具体示例 | 输出特点 |
|---------|---------|---------|
| **武侠人物** | 剑客、侠女、僧道、江湖人物 | 侠骨铮铮，意态潇洒 |
| **动作场面** | 竹林对战、飞檐走壁、拔剑对峙 | 动中有静，静中有动 |
| **江湖环境** | 客栈、山崖、寺庙、竹林、古道 | 山水入画，意境深远 |
| **夜景氛围** | 月下剑影、烛火摇曳、夜色深沉 | 明暗对比，意蕴悠长 |
| **群像场面** | 客栈百态、江湖群像、对峙双方 | 社会缩影，众生百态 |

### 不适用场景

| 不适用场景 | 原因说明 |
|-----------|---------|
| **现代都市** | 武侠古风与现代场景不兼容 |
| **玄幻仙侠** | 传统武侠讲究写实，非魔幻 |
| **CG特效感** | 水墨写意风格反对过度渲染 |
| **西方奇幻** | 中国传统武侠，非剑与魔法 |
| **过于暴力** | 胡金铨风格节制有度，意在言外 |

## 处理方法

### 核心美学原则

#### 1. 色调系统

| 色系 | 描述 | Prompt关键词 |
|------|------|-------------|
| **水墨黑白** | 浓淡墨色为主 | 水墨黑白, 浓淡墨色, 焦浓重淡清 |
| **朱红点缀** | 中国红作为强调 | 朱红, 印章红, 点缀, 鲜血 |
| **传统五色** | 青绿/土黄/素白 | 青绿山水, 土黄, 素白, 黛 |
| **夜色蓝灰** | 夜间冷色调 | 深蓝, 灰黑, 冷月, 夜色 |

#### 2. 光线系统

| 光线类型 | 描述 | Prompt关键词 |
|---------|------|-------------|
| **月光** | 冷白清冽 | 月光, 冷月, 银白, 月华如水 |
| **烛火** | 温暖摇曳 | 烛光, 摇曳, 昏黄, 油灯 |
| **日光** | 白日明亮 | 阳光, 日光, 天光 |
| **剪影** | 逆光轮廓 | 剪影, 逆光, 轮廓分明 |

#### 3. 明暗对比

| 对比类型 | 描述 | Prompt关键词 |
|---------|------|-------------|
| **高对比** | 明暗分明 | 高对比, 强烈明暗, chiaroscuro |
| **中间调** | 灰阶过渡 | 灰阶, 柔和过渡, 水墨晕染 |
| **低点光** | 少量光源 | 少量光, 点光源, 局部照明 |

#### 4. 质感系统

| 质感类型 | 描述 | Prompt关键词 |
|---------|------|-------------|
| **水墨晕染** | 墨色自然晕开 | 水墨晕染, 墨迹, 笔触 |
| **宣纸质感** | 传统材质 | 宣纸, 纸质, 素雅 |
| **丝绸光泽** | 武侠服饰 | 丝绸, 光泽, 绸缎 |
| **古典木构** | 建筑材质 | 木构, 木质, 柱梁 |

#### 5. 构图系统

| 构图类型 | 描述 | Prompt关键词 |
|---------|------|-------------|
| **留白** | 大量空白 | 大量留白, 负空间, 空灵 |
| **对角线** | 动感构图 | 对角线, 斜线, 动感 |
| **框架** | 门窗框景 | 门窗框架, 框景 |
| **远近** | 纵深透视 | 纵深, 近大远小, 层次 |

## 应用示例

### 示例1：月下剑客

**用户需求**："一位白衣剑客站在竹林中望月"

**生成Prompt（框架A）**：

```
【整体定调】
- 画幅：横幅，2.35:1宽银幕
- 风格：胡金铨武侠美学，中国水墨画风
- 色调：水墨黑白为主，月光银白，朱红印章点缀

【主体描述】
- 人物：一位30岁左右的男性剑客，身着白色长袍，
  腰系长剑，发髻高束，身形修长挺拔
- 姿态：静立于竹林空地，仰望夜空
- 表情：神情冷峻，目光深邃，似在沉思

【场景设定】
- 地点：竹林深处，月光穿透竹叶洒落
- 时间：深夜，满月高悬
- 环境：万竹环绕，地上竹影斑驳，薄雾轻笼

【光影氛围】
- 光源：月光从上方洒落，银白清冷
- 氛围：孤寂肃杀，侠客独行的意境
- 明暗：高对比，月光处明亮，竹影处漆黑

【构图规则】
- 景别：全景，人物与竹林融为一体
- 视角：微微仰视，突出剑客气度
- 构图：人物位于画面左侧1/3处，大量留白于右侧

【质感描述】
- 质感：水墨晕染，笔触洒脱，宣纸质感
- 服饰：丝绸长袍，月光下微微反光

【约束条件】
- 包含：月下竹林、白衣剑客、水墨质感
- 禁止：CG渲染感、过于鲜艳的色彩、过多人物
```
