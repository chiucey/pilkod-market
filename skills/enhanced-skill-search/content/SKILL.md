# MaxClaw 增强版技能搜索技能

## 概述

此技能为大型Agent团队（≥10个Agent）提供企业级的精细化技能管理能力，支持复杂场景下的技能发现、组合与协调。

## 核心能力

### 1. 多维度技能分类筛选

#### 按类型分类
| 类型 | 说明 | 筛选标签 |
|------|------|---------|
| 功能型 | 执行特定任务的技能 | `functional` |
| 协调型 | 管理多Agent协作的技能 | `orchestration` |
| 分析型 | 数据处理和分析技能 | `analytics` |
| 集成型 | 连接外部系统的技能 | `integration` |

#### 按场景分类
- **开发场景**: 代码生成、调试、测试、部署
- **研究场景**: 信息检索、数据分析、报告生成
- **运营场景**: 监控、日志、告警、自动化运维
- **协作场景**: 多Agent协调、知识共享、任务分配

#### 按版本筛选
- 稳定版本（GA）
- 测试版本（Beta）
- 实验版本（Alpha）

### 2. 多维度匹配系统

#### 能力维度
- **功能覆盖度**: 技能能力与需求的匹配程度
- **精度等级**: 技能输出的精确度要求
- **响应速度**: 技能执行的时间效率

#### 性能维度
- **资源消耗**: CPU/内存使用预期
- **并发能力**: 支持的并行任务数
- **可靠性**: SLA和错误率指标

#### 权限维度
- **数据访问级别**: 读取/写入/管理权限
- **系统访问范围**: 本地/网络/云端
- **敏感操作**: 需要确认的危险操作标记

### 3. 技能组合推荐引擎

#### 复杂任务分解
```
复杂任务 → 子任务识别 → 技能映射 → 依赖分析 → 最优组合
```

#### 组合优化策略
- **最小集合**: 用最少的技能完成任务
- **最强组合**: 使用性能最优的技能组合
- **负载均衡**: 避免单技能过载的任务分配

#### 组合评估指标
- 组合覆盖率（所有需求的满足程度）
- 组合效率（任务完成时间）
- 组合成本（资源消耗总和）
- 冲突风险（技能间干扰程度）

### 4. 技能冲突自动解决

#### 冲突类型
| 冲突类型 | 描述 | 解决方案 |
|---------|------|---------|
| 功能重叠 | 多技能提供相同功能 | 保留最优，标记冗余 |
| 资源竞争 | 技能争用相同资源 | 优先级排序，串行执行 |
| 依赖冲突 | 技能依赖版本不兼容 | 寻找兼容版本或替代品 |
| 权限冲突 | 权限要求相互矛盾 | 分阶段执行或权限升级 |

#### 冲突解决策略
1. **自动解决**: 系统自动选择最优解
2. **用户确认**: 高影响冲突需用户确认
3. **降级方案**: 提供功能降级但可用的替代组合

### 5. 团队技能库同步

#### 同步机制
- **中心辐射型**: 中央技能库，分支同步
- **分布式**: 各Agent维护本地技能库，定期合并
- **实时同步**: 变更即时传播到所有节点

#### 同步策略
- 版本兼容性检查
- 冲突检测与合并
- 增量更新优化
- 断线续传支持

## 执行工作流

### 阶段1：需求解析
1. 解析用户查询的意图和约束
2. 提取筛选条件（类型/场景/版本/性能/权限）
3. 识别是否为复杂任务需要技能组合

### 阶段2：多维度搜索
1. 并行执行分类筛选
2. 应用多维度匹配算法
3. 计算综合评分

### 阶段3：组合优化（如适用）
1. 任务分解为原子需求
2. 为每个子任务选择最优技能
3. 分析技能间依赖和冲突
4. 生成最优组合方案

### 阶段4：冲突处理
1. 检测技能间冲突
2. 应用冲突解决策略
3. 生成冲突报告和解决方案

### 阶段5：同步管理（如适用）
1. 检查团队技能库状态
2. 执行增量同步
3. 验证同步结果

## 决策矩阵

### 匹配度计算
```
综合得分 = 功能匹配 × 0.4 + 性能匹配 × 0.3 + 权限匹配 × 0.2 + 版本稳定性 × 0.1
```

### 组合推荐优先级
1. 无冲突方案优先于有冲突方案
2. 高覆盖率方案优先于低覆盖率
3. 资源消耗低的方案优先于高的
4. 稳定版本优先于实验版本

### 同步冲突处理
- **版本差异**: 保留最新稳定版本
- **功能差异**: 保留功能完整版本
- **无法合并**: 标记冲突，等待人工介入
