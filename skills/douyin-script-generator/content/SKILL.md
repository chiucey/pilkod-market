# 抖音优质脚本生成器

一键生成抖音优质脚本，让视频创作更轻松。

## 支持的脚本类型

| 类型 | 适用场景 | 核心要素 |
|------|----------|----------|
| 剧情类 | 情感故事、搞笑段子 | 冲突设计、情绪反转、人物弧线 |
| 带货类 | 商品推荐、种草安利 | 痛点挖掘、价值塑造、限时紧迫感 |
| 口播类 | 知识分享、干货输出 | 开头吸引、逻辑清晰、结尾引导 |
| Vlog类 | 日常生活记录 | 场景切换、情绪节奏、个人风格 |
| 热点类 | 时事评论、话题解读 | 快速切入、独特视角、互动引导 |

## 工作流程

### 1. 收集用户需求

询问以下信息（如用户未明确提供）：
- **脚本主题**：视频要表达什么？
- **脚本类型**：剧情/带货/口播/Vlog/热点？
- **目标受众**：给谁看的？
- **视频时长**：15秒/30秒/60秒/3分钟？
- **风格偏好**：搞笑/感人/专业/日常？

### 2. 生成脚本结构

每个脚本必须包含以下要素：

```
【开场钩子】(0-3秒)
- 抓住注意力的开场
- 悬念/冲突/共鸣

【主体内容】(中间部分)
- 核心信息传递
- 情绪递进
- 转折点设计

【高潮/亮点】(中后段)
- 最精彩的瞬间
- 金句/名场面

【结尾引导】(最后3-5秒)
- 行动号召(CTA)
- 互动引导
- 关注引导
```

### 3. 输出完整脚本

按照以下格式输出：

```
==========================================
📱 抖音脚本：[主题名称]
⏱️ 时长：[建议时长]
🎯 受众：[目标人群]
==========================================

【开场钩子】
[具体台词/动作描述]

【镜头1】
- 画面：[具体描述]
- 台词：[对白/旁白]
- 音效：[背景音乐/音效提示]

【镜头2】
- 画面：[具体描述]
- 台词：[对白/旁白]
- 音效：[背景音乐/音效提示]

... (根据时长调整镜头数量)

【高潮片段】
[最精彩的片段设计]

【结尾引导】
- 行动号召：[具体文案]
- 互动话题：[引导评论的提问]
- 关注引导：[关注理由]

==========================================
💡 拍摄建议：
1. [补充说明1]
2. [补充说明2]
3. [补充说明3]
==========================================
```

## 脚本优化技巧

### 开场5秒法则
- 使用疑问句引发好奇
- 展示惊人数据或画面
- 直接喊出目标受众

### 情绪节奏把控
- 每30秒设置一个小高潮
- 利用停顿创造张力
- 音乐卡点增强节奏感

### 提升完播率
- 前3秒必须留住观众
- 避免冗长铺垫
- 设置中途钩子防止跳出

**用户输入**："生成一个带货口红的脚本，目标受众是20-30岁女性，时长60秒"

**输出脚本示例**：

```

📱 抖音脚本：女生必入的显白口红

🎯 受众：20-30岁追求精致的女性

"姐妹们！这支口红让我白了一个度！"

- 画面：素颜状态展示
- 台词："我以前的肤色暗沉，黄气很重..."

【镜头2】
- 画面：涂抹口红过程（特写）
- 台词："轻轻一抹，立成立马显白3个度"
- 音效：口红盖开合声

【高潮片段】
- 画面：前后对比（素颜 vs 妆后）
- 台词："同一个光源，这差异你们自己看！"
- 音效：惊叹音效 + 背景音乐高潮

【结尾引导】
- 行动号召："点击左下角立即购买"

1. 使用自然光或环形补光灯，保证肤色准确
2. 口红特写镜头要多角度展示
3. 对比照务必在同一光源下拍摄
4. 背景音乐选择节奏欢快的电商BGM

```

## 快速生成模板

对于简单需求，可直接套用以下模板快速生成：

**信息流广告模板**：
```
问题引入 → 产品展示 → 效果证明 → 限时优惠 → 行动号召
```

**剧情反转模板**：
```
铺垫日常 → 冲突升级 → 反转时刻 → 情感升华 → 主题升华
```

**知识干货模板**：
```
痛点提出 → 原因分析 → 解决方案 → 效果展示 → 总结回顾
```

## 注意事项

1. **时长控制**：严格按照用户要求的时长分配镜头
2. **版权合规**：避免提及具体品牌（除非用户指定）
3. **语言风格**：口语化、接地气，符合抖音平台调性
4. **敏感词规避**：避免使用绝对化用语（"最好"、"第一"等）
5. **互动设计**：结尾必须有明确的互动引导

## 质量检查清单

生成脚本后，检查是否包含：
- [ ] 吸引人的开场（3秒内抓住注意力）
- [ ] 清晰的信息传递
- [ ] 至少1个情绪高潮点
- [ ] 明确的行动号召(CTA)
- [ ] 互动话题引导
- [ ] 具体的拍摄建议
- [ ] 时长分配合理
