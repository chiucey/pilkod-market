# 常用分层模板

以下模板用于快速把安全方案文档抽象为稳定的分层结构。

## 1. 总体安全服务架构图

适用场景：
- 安全服务总体设计
- 总体架构设计
- 多平台协同的安全体系方案

建议分层：
1. 应用场景 / 服务对象层
2. 平台建设 / 统一管理层
3. 核心能力层
4. 智能分析与运营支撑层
5. 数据与基础底座层

可选补充：
- 在顶部单独加“统一管理与联动平面”
- 在底部单独加“开放联动”层

## 2. 平台逻辑架构图

适用场景：
- 综合安全平台
- 监测审计平台
- 统一管理平台
- 态势感知平台

建议分层：
1. 应用场景
2. 展示交互层
3. 业务应用层
4. 分析计算层
5. 数据汇聚层
6. 设备接入层
7. 开放联动与平台底座

常见模块：
- 展示交互层：Web界面、大屏、报表、推送
- 业务应用层：策略管理、状态监控、告警管理、事件处置、调度中心
- 分析计算层：关联分析、聚合降噪、异常检测、趋势分析
- 数据汇聚层：格式转换、映射、清洗、归一化、消息队列、存储检索
- 设备接入层：WAF、主机安全、防火墙、日志设备、标准协议

## 3. 组件 / 产品架构图

适用场景：
- WAF 产品架构
- NGFW 产品架构
- 主机安全产品架构
- 单一组件服务架构

建议分层：
1. 部署/接入层
2. 核心引擎层
3. 策略执行/控制层
4. 管理控制层
5. 开放接口/联动层

可选补充：
- 部署模式层
- 集群高可用层
- 运维支撑层

## 4. 信息不足时的保守模板

当文档内容较少，但用户仍要求出图时，使用以下保守结构：
1. 应用场景
2. 核心能力
3. 管理控制
4. 数据支撑
5. 基础底座

命名优先中性、稳妥、可复用。
