# Fast Summarize 快速总结技能

## 技能说明

本技能帮助用户快速从各类内容中提炼核心要点，适合处理文档、长文、网页、视频等材料的快速阅读和要点获取。

## 触发方式

当用户发送以下类型的内容或指令时自动触发：

- 上传文件（PDF、图片、视频、音频）并要求总结
- 发送网页链接并要求总结内容
- 直接粘贴长文本并要求提炼要点
- 使用触发词：总结、整理、提炼要点、说重点、核心内容、主要观点

## 处理流程

### Step 1: 内容识别

自动识别用户输入的内容类型：

| 内容类型 | 识别方式 | 处理工具 |
|---------|---------|---------|
| PDF文档 | 文件扩展名 .pdf | `extract_pdfs_full_content` / `extract_pdfs_key_info` |
| 网页/长文 | URL链接 | `extract_content_from_websites` |
| 视频 | 视频文件或URL | `videos_understand` |
| 音频 | 音频文件 | `audios_understand` |
| 图片 | 图片文件 | `images_understand` |
| 纯文本 | 直接粘贴的文字 | 直接分析 |

### Step 2: 内容提取

根据识别的类型，使用对应工具提取内容：

```
IF 内容是文件:
  - PDF → extract_pdfs_key_info(prompt="提取核心要点和关键信息")
  - 图片 → images_understand(prompt="识别并总结图片中的文字内容")
  - 视频 → videos_understand(prompt="总结视频的主要内容")
  - 音频 → audios_understand(prompt="转录并总结音频内容")

ELIF 内容是URL:
  - 调用 extract_content_from_websites 提取网页内容

ELSE:
  - 直接对纯文本进行结构化分析
```

### Step 3: 要点提炼

对提取的内容进行结构化总结，输出格式：

```
【主题/标题】
[一句话概括核心内容]

【关键要点】
1. [要点1]
2. [要点2]
3. [要点3]
... (根据内容长度自动调整数量)

【补充信息】(可选)
- 背景/上下文
- 相关数据或事实
- 重要结论或建议
```

### Step 4: 特殊处理规则

| 场景 | 处理方式 |
|------|---------|
| 内容过长 | 分段处理后合并精华 |
| 内容涉密/受限 | 提示用户内容无法访问，建议手动复制可公开部分 |
| 格式不支持 | 告知用户当前不支持该格式，提供替代方案 |
| 多语言内容 | 自动识别语言，用同语言输出总结 |

## 不支持的场景

以下情况应主动告知用户原因和解决方案：

| 场景 | 原因 | 解决方案 |
|------|------|---------|
| 受限网站 | 该网站需要登录或限制访问 | 请手动复制可公开的部分文字内容 |
| 加密PDF | PDF已加密保护 | 请提供解密后的版本 |
| 损坏文件 | 文件格式损坏无法读取 | 请重新上传清晰完整的文件 |
| 实时内容 | 内容需要实时交互 | 建议使用网页交互工具处理 |

## 输出规范

1. **简洁性**: 总结应简洁明了，避免冗余
2. **完整性**: 涵盖原文的主要观点和信息
3. **结构性**: 使用清晰的层次和格式
4. **准确性**: 忠实于原文，不添加无关推测

## 快速使用示例

```
用户: 帮我总结一下这个PDF [上传文件]
助手: [自动识别PDF，提取内容，输出结构化总结]

用户: https://example.com/article [这是链接]
助手: [自动提取网页内容，输出总结]

用户: 帮我整理下这段文字的主要观点 [粘贴长文]
助手: [直接分析文本，输出要点]
```
