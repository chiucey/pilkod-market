# Fast Summarize 参考文档

## 工具使用指南

### 内容提取工具矩阵

| 内容类型 | 推荐工具 | 适用场景 |
|---------|---------|---------|
| PDF文档 | `extract_pdfs_key_info` | 快速提取关键信息 |
| PDF文档 | `extract_pdfs_full_content` | 需要完整内容时 |
| 网页 | `extract_content_from_websites` | 公开可访问的网页 |
| 视频 | `videos_understand` | 本地视频文件或URL |
| 音频 | `audios_understand` | 音频文件转录和总结 |
| 图片文字 | `images_understand` | OCR识别和内容提取 |

### 提示词模板

#### PDF总结提示词
```
请提取并总结这份PDF文档的核心要点，包括：
1. 文档主题/标题
2. 3-5个关键要点
3. 重要结论或建议
保持简洁，用列表格式输出。
```

#### 网页总结提示词
```
请总结这个网页的主要内容：
1. 页面主题
2. 主要观点（3-5点）
3. 关键信息
输出简洁明了的要点列表。
```

#### 视频总结提示词
```
请总结这个视频的核心内容：
1. 视频主题
2. 主要讨论的问题
3. 关键结论或要点
请用简洁的要点格式输出。
```

#### 音频总结提示词
```
请转录并总结这段音频的内容：
1. 音频主题
2. 主要讨论的内容
3. 关键信息点
使用要点列表格式。
```

## 常见问题处理

### Q: 内容太长怎么办？
A: 分段处理，每段提取要点后合并精华。

### Q: 内容无法访问怎么办？
A: 告知用户原因（登录限制、加密等），建议手动复制内容。

### Q: 格式不支持怎么办？
A: 明确告知不支持该格式，提供替代方案（如复制文字内容）。

## 最佳实践

1. **快速响应**: 用户发送内容后立即识别类型并开始处理
2. **结构化输出**: 使用统一的要点格式，便于阅读
3. **适度精简**: 总结长度控制在原文的10-20%
4. **保留关键**: 不遗漏重要数据和结论
5. **诚实告知**: 无法处理时明确说明原因
