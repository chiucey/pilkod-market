# 薪酬科目对比分析器

## 一、技能简介

这是一个专业的薪酬数据分析工具，通过对比两份不同时间段的薪酬科目明细，自动计算各科目的增减变动，智能归类分析，并生成完整的薪酬变动分析报告。无论是月度薪资对比、年度薪酬调整分析，还是部门薪酬结构分析，都能快速给出专业的数据洞察。

### 核心价值

- 快速对比两份薪酬数据，找出薪资变化原因
- 智能识别薪酬科目类别，自动归类统计
- 多维度分析薪酬变动，量化每个因素的影响
- 生成专业分析报告，支持PPT和Excel导出
- 可视化展示薪酬结构变化

## 二、核心功能

### 2.1 薪酬数据智能读取

**支持文件格式**
- Microsoft Excel：.xlsx、.xls
- CSV文件：.csv
- 支持格式：工资条（每行一人）、工资表（按列汇总）

**智能识别能力**
- 自动识别薪酬科目列（基本工资、绩效、补贴、社保等）
- 智能匹配两期数据的人员和科目
- 自动处理人员变动（新增、离职）
- 识别异常数据并标记

**数据字段识别**
```
标准薪酬科目：
├── 基本工资
├── 岗位工资
├── 绩效工资
├── 全勤奖
├── 交通补贴
├── 餐补/饭补
├── 住房补贴
├── 通讯补贴
├── 高温补贴
├── 加班费
├── 年终奖
├── 社会保险（养老、医疗、失业）
├── 住房公积金
├── 个人所得税
├── 其他扣款
└── 实发工资
```

### 2.2 科目对比分析

**对比维度**
- 同比对比（本月vs上月、本季度vs上季度、本年vs去年）
- 环比对比（连续月份对比）
- 同期对比（今年某月vs去年同月）
- 部门对比（不同部门间薪酬结构对比）

**分析方法**
| 分析类型 | 说明 | 适用场景 |
|---------|------|---------|
| 科目维度 | 分析每个薪酬科目的变化 | 了解具体增减项 |
| 人员维度 | 分析每个人员的薪酬变化 | 关注个体差异 |
| 部门维度 | 分析部门的薪酬结构变化 | 部门整体分析 |
| 结构维度 | 分析薪酬各部分占比变化 | 结构优化分析 |

### 2.3 智能归类统计

**科目大类归类**

```
一、应发工资类
├── 固定工资：基本工资、岗位工资、工龄工资
├── 绩效工资：绩效奖金、提成、业绩奖金
├── 各类补贴：交通补贴、餐补、住房补贴、通讯补贴
├── 奖励工资：全勤奖、年终奖、专项奖励
└── 其他应发：加班费、高温补贴、其他

二、代扣代缴类
├── 社保个人部分：养老、医疗、失业保险
├── 公积金：住房公积金个人缴存
└── 税费：个人所得税

三、实发工资
└── 应发合计 - 代扣合计 = 实发工资
```

**统计指标**
- 本期金额
- 上期金额
- 变动金额（本期 - 上期）
- 变动幅度（变动金额 / 上期 × 100%）
- 占比变化
- 贡献度（该科目变动对总变动的影响比例）

## 四、分析示例

### 4.1 月度薪酬对比

**场景**：比较2024年2月与2024年1月薪酬数据

**输入数据**
- 上期（1月）：50人薪酬明细，15个薪酬科目
- 本期（2月）：52人薪酬明细，15个薪酬科目

**分析输出**
```
【总体变动】
应发工资合计：+8.5万元（+5.2%）
代扣合计：+1.2万元（+4.8%）
实发工资合计：+7.3万元（+5.4%）

【变动原因分析】
1. 绩效工资增加 +6.0万元（+15%）
   原因：季度绩效奖金发放

2. 社会保险增加 +0.8万元（+3.2%）
   原因：社保基数年度调整

3. 加班费减少 -1.5万元（-25%）
   原因：春节假期加班减少

4. 新增2人，薪酬增加 +3.2万元
```

### 4.2 年度薪酬调整分析

**场景**：对比2023年度与2024年度薪酬

**输入数据**
- 2023年度薪酬汇总表
- 2024年度薪酬汇总表
- 包含12个月明细

**分析输出**
```
【年度薪酬变动总览】
人均薪酬：8.2万 → 9.1万（+11%）

【薪酬结构调整】
基本工资占比：55% → 52%（-3%）
绩效工资占比：25% → 28%（+3%）
福利补贴占比：20% → 20%（持平）

【变化趋势】
Q1-Q4各季度薪酬增长率：3%、2.5%、2.8%、2.7%

【优化建议】
1. 绩效工资占比提升，激励效果显现
2. 建议适度提高固定工资比例以稳定团队
3. 福利补贴结构可进一步优化
```

## 九、注意事项

### 9.1 数据准备
- 确保两期数据格式一致
- 人员姓名/工号保持唯一性
- 金额字段格式统一
- 避免合并单元格

### 9.2 数据匹配
- 人员匹配优先使用工号
- 科目匹配支持模糊识别
- 异常匹配需要人工确认
- 新增/离职人员单独标记

### 9.3 分析建议
- 变动超过10%需要重点关注
- 异常数据需要人工核实
- 报告数据需要保密处理
- 建议结合业务背景分析
