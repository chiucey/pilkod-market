# 竞争对手分析参考

## 分析维度

1. **竞品菜单结构**：有哪些产品？价格带在哪个区间？
2. **竞品活动力度**：满减门槛是多少？折扣力度多大？
3. **竞品评分和评价**：好评说什么，差评说什么？（复购吸引力在哪里？）
4. **竞品曝光和单量**：用多少曝光，转化率多少？（推测）

## 操作方法

**直接观察法（最简单）：**
1. 打开美团/饿了么，定位到你的店铺
2. 搜索同一品类/关键词
3. 看排名靠前的竞对，逐一记录：菜单、价格、活动、评分
4. 重点关注：和自己在同一价格区间的商家

**差异化定位原则：**
- 避免正面价格战（你低我更低）
- 找到自己的优势空间（品质/口味/服务/特色）
- 用差异化建立护城河（例：你是"最新鲜的抄手"，别人没有）

## 竞对分析的常见发现

| 发现 | 应对策略 |
|---|---|
| 竞品价格比你低很多 | 不打价格战，突出品质和新鲜优势 |
| 竞品活动力度很大 | 突出"真实惠"而非"看起来便宜" |
| 竞品评分比你高 | 提升服务，优化差评处理 |
| 竞品菜单比你丰富 | 精简菜单，突出招牌，不比数量比质量 |

## 竞对监控频率

- 每周：看一次主要竞品动态
- 每月：做一次全面竞品分析
- 有重大变化时（如竞品突然大促）：及时调整应对
