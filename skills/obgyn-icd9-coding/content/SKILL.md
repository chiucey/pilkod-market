# 妇产科手术ICD-9-CM-3编码原则收集与整理

## 技能目标

收集和整理妇产科手术的ICD-9-CM-3编码规则知识，输出一份结构完整、内容专业的编码知识文档（.docx 格式）。

## 适用场景

- 医疗产品经理构建ICD-9编码质控系统
- 病案编码员学习妇产科手术编码规范
- DRG/DIP付费体系下的编码质控建设
- 妇产科手术编码知识库构建

## 妇产科手术编码收集范围

### 一、产科手术（ICD-9-CM-3 第11章 产科操作 72-75）

#### 1. 助产手术操作（72-73）

| 手术类别 | ICD-9-CM-3编码范围 | 核心编码要点 |
|----------|-------------------|-------------|
| 产钳术 | 72.0-72.6, 73.3 | 低位72.0/72.1、中位72.21、高位72.31、头后出72.6；分清是否伴外阴切开；若产钳失败转剖宫产需附加编码73.3 |
| 臀位牵引术 | 72.51-72.54 | 部分臀位牵引72.51-72.52 vs 全部臀位牵引72.53-72.54；伴产钳用于头后出需合并编码 |
| 胎头吸引术 | 72.7 | 真空吸引术，注意区分是否伴外阴切开(72.71) |
| 转胎术 | 73.21-73.22, 73.91 | 外倒转术73.91（腹壁外操作）vs 内倒转术73.21-73.22（手入宫腔） |
| 人工破膜术 | 73.01, 73.09 | 区分引产(73.01) vs 分娩时(73.09) |

#### 2. 剖宫产术（74）

| 手术类别 | ICD-9-CM-3编码 | 核心编码要点 |
|----------|---------------|-------------|
| 古典式剖宫产 | 74.0 | 子宫上段/体部剖宫产，适用范围有限 |
| 子宫下段剖宫产 | 74.1 | 最常用：下段横切口74.1x01、下段直切口74.1x02 |
| 腹膜外剖宫产 | 74.2 | 经腹膜外途径，适用于疑有宫腔感染 |
| 剖宫取胎（终止妊娠） | 74.91 | 治疗性流产，不能用于分娩 |

> **分类要点**：剖宫产同时伴子宫其他手术需另编码；74.91为终止妊娠的剖宫产，不可与分娩剖宫产混淆。

#### 3. 产伤修复手术（71, 75）

| 手术类别 | ICD-9-CM-3编码 | 核心编码要点 |
|----------|---------------|-------------|
| 会阴侧切缝合术 | 73.6 | 伴产钳/吸引术时合并编码 |
| 近期产科会阴裂伤修补 | 75.69 | 本次生产过程中撕裂修补 |
| 陈旧性产科会阴裂伤修补 | 71.79 | 既往生产遗留裂伤修补 |
| 非产科会阴裂伤修补 | 71.71 | 非产伤导致 |

### 二、妇科手术（ICD-9-CM-3 第12章 女性生殖器官手术 65-71）

#### 1. 子宫手术（68-69）

**子宫切除术编码指引表**：

| 手术方式 | 经腹 | 腹腔镜 | 经阴道 |
|---------|------|--------|--------|
| 次全子宫切除术 | 68.3 | 68.31 | — |
| 全子宫切除术 | 68.4 | 68.41 | 68.5 |
| 广泛性/根治性子宫切除术 | 68.6 | 68.61 | 68.7 |
| 根治性子宫+盆腔淋巴结清扫 | 68.6 + 40.59 | 68.61 + 40.59 | 68.7 + 40.59 |

> 编码核心要点：区分手术范围（次全/全切/广泛/根治）+ 入路（经腹/腹腔镜/经阴道）+ 是否保留附件/卵巢 + 是否清扫淋巴结。

| 其他子宫手术 | ICD-9-CM-3编码 | 核心编码要点 |
|-------------|---------------|-------------|
| 子宫肌瘤切除术 | 68.29 | 区分经腹、腹腔镜、宫腔镜入路 |
| 子宫切开术 | 68.0 | 子宫中隔切除术等 |
| 子宫颈锥形切除术 | 67.2 | LEEP刀锥切、冷刀锥切 |
| 子宫颈切除术 | 67.3-67.4 | 区分部分/全部切除 |

|----------|---------------|-------------|

| 单侧卵巢切除术 | 65.3/65.4 | 区分是否同时切除输卵管 |
| 双侧卵巢切除术 | 65.5/65.6 | 区分是否同时切除输卵管 |
| 卵巢粘连松解术 | 65.8 | 区分卵巢/输卵管同时松解 vs 单纯卵巢 |

## 内容模块详细要求

### 模块一：手术内涵

- 说明手术的定义、目的、临床分类
- 产科手术：区分不同手术方式的临床意义
- 妇科手术：按范围/入路/术式的分类体系
- 注明各类手术的异同点及适用范围

### 模块二：主要适应症

- 列出各类手术的主要临床适应症
- 产科：产程异常、胎儿窘迫、胎位异常、瘢痕子宫等
- 妇科：按疾病类别（子宫肌瘤、卵巢囊肿、恶性肿瘤、子宫内膜异位症等）分别说明

### 模块三：ICD9编码（核心模块）

#### 编码索引路径

- 给出主要手术的主导词查询路径
- 格式：主导词 → 修饰词 → 编码
- 范例：
  - 主导词：切开-子宫 → 剖宫产 74
  - 主导词：切除术-子宫 → 子宫切除术 68.3-68.7
  - 主导词：修复术-会阴 → 会阴裂伤修补术

#### 手术操作编码表

- 以表格呈现各类手术与对应编码
- 包含编码、手术操作名称、备注
- 标注易混淆编码的区分要点
- 覆盖7位编码细目

### 模块四：临床与编码核心原则

#### 编码核心逻辑（步骤化）

```
1. 阅读并理解手术记录
   提取关键信息：
   - 手术类型与范围
   - 手术入路（经腹/经阴道/腹腔镜/宫腔镜）
   - 术中所见及并发症
   - 是否初次手术/再次手术

2. 识别适用的手术类型编码
   根据手术名称和记录选择对应编码

3. 考虑组合编码
   - 主要手术+辅助手术
   - 另编码特殊情况（如粘连松解、淋巴结清扫）
   - 双侧手术编码处理

4. 避免常见编码错误
   详见常见错误清单
```

#### 编码要点

**产科手术编码要点**：
① 区分经阴道分娩助产 vs 剖宫产
② 助产手术若失败转剖宫产，需附加失败编码
③ 会阴切开术伴助产时合并编码，不单独编码
④ 剖宫产同时行子宫肌瘤剔除等需另编码
⑤ 区分分娩剖宫产(74.0-74.2) vs 终止妊娠的剖宫取胎(74.91)
⑥ 近期产科裂伤 vs 陈旧性产科裂伤，编码完全不同

**妇科手术编码要点**：
① **子宫切除术**：区分范围（次全/全/广泛/根治）+ 入路
② **卵巢手术**：单侧 vs 双侧、保留 vs 切除输卵管、开腹 vs 腹腔镜
③ **异位妊娠手术**：切开取胚保留输卵管66.01 vs 输卵管切除66.62
④ **肌瘤剔除**：单纯剔除68.29 vs 伴子宫切除按子宫切除术编码
⑤ **恶性肿瘤手术**：根治性手术需另编码淋巴结清扫(40.59)
⑥ **粘连松解**：主要手术目标作主要编码，附带操作作附加编码

#### 常见编码错误清单

| 常见错误 | 错误原因 | 正确做法 |
|---------|---------|---------|
| 剖宫产笼统编码为74.1 | 未区分古典式/子宫下段/腹膜外 | 根据手术记录选择74.0/74.1/74.2 |
| 子宫切除笼统编码为68.4 | 未区分次全/全切/根治及入路 | 明确范围+入路选择对应编码 |
| 产钳失败未附加编码 | 失败后转剖宫产仅编剖宫产 | 加编73.3作为附加编码 |
| 会阴切开重复编码 | 伴产钳时分别编72.x+73.6 | 合并为72.1/72.21/72.31等 |
| 异位妊娠手术误编 | 保留vs切除输卵管混淆 | 切开取胚66.01 vs 切除66.62 |
| 卵巢手术忽略双侧 | 双侧卵巢切除仅编单侧 | 使用65.5/65.6双侧编码 |
| 腹腔镜入路未区分 | 开放和腔镜使用同一编码 | 查找含"腹腔镜下"细目编码 |
| 终止妊娠剖宫产误编为分娩剖宫产 | 74.91与74.x混淆 | 根据临床目的选择正确编码 |

## 关键注意事项

1. ICD-9-CM-3 是手术操作分类编码，区别于 ICD-10 疾病分类编码
2. 编码需要 7 位细目精度（如 74.1x01 而非 74.1）
3. 关注 DRG/DIP 下的编码影响：同类手术不同编码可能导致不同 DRG 分组
4. 腹腔镜入路通常有独立编码细目，不可笼统编码为开放手术
5. 产科与妇科手术编码分属不同章节（第11章 vs 第12章）
6. 会阴切开术伴助产时合并编码，产科会阴裂伤单独编码
7. 终止妊娠的剖宫产(74.91) ≠ 分娩剖宫产(74.0-74.2)，是最常见的混淆点
8. 双侧器官手术需使用双侧编码或重复编码
