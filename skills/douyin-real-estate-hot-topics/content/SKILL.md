# 抖音房产热门话题分析技能

## 功能概述

自动搜索并分析抖音平台当日房产领域热门话题，提取话题浏览量、类型分类和出处来源信息。

## 触发条件

- 用户询问"抖音房产热门话题"
- 用户要求"搜索房产热点"
- 用户请求"分析房产话题趋势"
- 用户需要"房产话题日报"
- 任何涉及抖音/抖音房产热门话题的查询

## 执行流程

### 步骤1：搜索热门话题

使用批量搜索工具搜索抖音房产热门话题：

```
搜索词建议：
- "抖音房产热门话题 今日"
- "抖音房产热点 2024"
- "房产热门 抖音"
- "房地产热门话题"
```

### 步骤2：数据提取

从搜索结果中提取以下信息：

| 字段 | 说明 | 示例 |
|------|------|------|
| 话题名称 | 话题标题/关键词 | "#北京房价走势#" |
| 浏览量 | 话题热度指标 | 2.5亿 |
| 类型 | 话题分类 | 政策解读/市场分析/买房攻略/维权曝光 |
| 出处/来源 | 内容来源平台或账号 | 抖音官方/房产大V/中介公司 |
| 话题链接 | 抖音话题页URL | https://www.douyin.com/topic/xxx |

### 步骤3：数据整理与排名

- 按浏览量降序排列
- 筛选前10个热门话题
- 补充话题类型标签
- 标注信息来源可靠性

### 步骤4：格式化输出

生成结构化报告，包含：

1. **概览**：总话题数、热度最高话题、热度区间
2. **TOP10热门话题排行榜**：详细数据表格
3. **话题类型分布**：饼图或条形图
4. **信息来源分析**：主要来源占比

## 输出格式

```markdown
# 抖音房产热门话题日报
**日期**: YYYY-MM-DD

## 概览
- 热门话题总数：XX个
- 热度峰值话题：XXX（浏览量XX）
- 热度区间：XX万 ~ XX亿

## TOP10热门话题排行榜

| 排名 | 话题名称 | 浏览量 | 类型 | 出处/来源 |
|------|----------|--------|------|----------|
| 1 | #XXX话题# | XX亿 | 政策解读 | 抖音官方 |
| ... | ... | ... | ... | ... |

## 话题类型分布
- 政策解读：X个 (XX%)
- 市场分析：X个 (XX%)
- 买房攻略：X个 (XX%)
- 维权曝光：X个 (XX%)

## 主要信息来源
- 抖音官方账号：X%
- 房产大V：X%
- 中介/开发商：X%
- 其他：X%
```

## 定时任务配置

如需每日自动执行，配置cron任务：

```json
{
  "job_title": "抖音房产热门话题日报",
  "cron_expression": "0 9 * * *",
  "job_instruction": "执行douyin-real-estate-hot-topics技能，搜索当日抖音房产热门话题前10名，提取浏览量、类型、出处信息，生成日报并保存到data/daily_report_{date}.md"
}
```

## 注意事项

1. 搜索结果应尽量获取最新的实时数据
2. 浏览量数据尽可能精确，保留原始格式
3. 类型分类需根据话题内容判断归类
4. 来源信息标注账号类型（官方/VIP/普通）
5. 如搜索结果不足10个，按实际数量返回

## 质量标准

- 数据来源：至少3个不同搜索渠道验证
- 数据时效：获取最近7天内的热门话题
- 信息完整度：每个话题需包含至少4个核心字段
- 报告可读性：格式清晰，数据直观
