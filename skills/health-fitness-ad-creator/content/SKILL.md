## 输出形式一：口播文案

### 口播文案结构模板

```
[HOOK - 3秒] 引发共鸣痛点或欲望
[PROBLEM - 5秒] 描述用户面临的问题
[SOLUTION - 10秒] 介绍产品如何解决
[BENEFITS - 10秒] 强调使用后的效果（包括减脂功效）
[CTA - 5秒] 明确行动号召
```

### 口播文案风格指南

**目标受众**：30-50岁欧美用户，追求健康生活和体形改善

**语言风格**：
- 直接、简洁、有活力
- 使用第二人称 "you" 增加代入感
- 避免过度夸张，使用实际数据增强可信度
- 强调减脂和各自产品的独特卖点

**通用开场句式**：
```
"Are you tired of..."
"Imagine waking up feeling..."
"What if you could..."
"It's time to..."
"Ready to transform..."
```

**效果承诺句式**：
```
"Burn up to [X] calories"
"Lose [X] pounds in [X] weeks"
"Build muscle, burn fat"
"Transform your body"
"Feel stronger, look leaner"
```

### 口播文案变体规则

1. **时长变体**：
   - 15秒版本：压缩核心信息，强调CTA和减脂效果
   - 30秒版本：完整结构，情感铺垫充分
   - 60秒版本：添加社会证明、用户证言、详细功效

2. **平台适配**：
   - **Meta (Instagram/Facebook)**：更直接、情感化、前3秒抓眼球，强调视觉效果
   - **Google**：更信息性、强调效果和可信度

3. **A/B测试变体**：
   - 疑问句开场 vs 陈述句开场
   - 问题导向 vs 结果导向
   - 社群证明 vs 个人收益

### 信息元素规范

#### 时间显示格式
```
⏱ MM:SS    # 例如 05:30
⏱ X分钟    # 例如 "5分钟"
⏱ X组 × Y次 # 例如 "3组 × 12次"
```

#### 消耗显示格式
```
🔥 X cal    # 例如 "150 cal"
🔥 X kcal   # 欧规
📊 每分钟消耗 # 可选补充信息
```

#### 动作名称
```
主动作: 全大写
        例如 "SQUATS" (深蹲)
子动作: 首字母大写
        例如 "Left Leg Forward"
```

#### 难度等级
```
🟢 初级 (Beginner)
🟡 中级 (Intermediate)
🔴 高级 (Advanced)
⚡ 所有等级 (All Levels)
```
