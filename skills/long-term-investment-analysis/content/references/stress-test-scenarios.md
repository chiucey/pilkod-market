**情景**：同业风险传染

| 参数 | 值 |
|------|------|
| 核心假设 | 融资成本上升200bps |
| 净利润冲击幅度 | [分析师填入] |
| 估值调整后安全边际 | [分析师填入] |

**同业风险传染利息支出冲击计算规则**：

```python
# 步骤1：获取有息负债总额和原融资成本
interest_bearing_debt = [有息负债总额]
original_cost = [原融资成本]  # 若不可得，使用报表附注"利息支出/有息负债"近似

# 步骤2：冲击后利息支出
shocked_interest = interest_bearing_debt * (original_cost + 0.02)  # 200bps=0.02

# 步骤3：利息支出增幅
interest_increase_pct = (shocked_interest - original_interest) / abs(original_interest)
```

**单一依赖降级路径**：

| 数据可得性 | 判断方法 | 触发条件 |
|------------|----------|----------|
| 年报明确披露第一大客户销售收入及占比 | 直接取值 | 占比>30% → 触发 |
| 仅披露前五大客户合计占比，且合计>50% | 取max(合计÷5, 合计×0.4)作为估算值 | 估算值>30% → 触发，标注"基于前五大合计推算" |
| 未披露客户集中度数据 | 年报中"客户依赖风险"文字描述 | 出现"重大依赖""单一客户" → 触发，标注"基于文本风险提示触发" |
| 以上均不可得 | 默认为"不触发" | 标注"单一依赖数据不可得，已跳过该情景" |

## 流动性风险压力测试

### 流动性折扣情景

| 情景 | 假设条件 | 测算方法 |
|------|----------|----------|
| **流动性折扣情景** | 日均成交额萎缩至当前30% | 变现天数 = 持仓市值 ÷ (日均成交额 × 30% × 0.2)。若 > 10个交易日，DCF估值应折价10%-20% |
| **流动性枯竭情景**（北交所/新三板强制） | 连续3日日均成交额 < 100万元（北交所）/< 50万元（新三板） | 估值应折价20%-30% |
