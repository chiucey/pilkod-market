# 财务计算公式与指标说明

## 杜邦分析法（ROE分解）

**核心公式**：
```
ROE = 销售净利率 × 资产周转率 × 权益乘数

销售净利率 = 净利润 ÷ 营业收入（盈利能力）
资产周转率 = 营业收入 ÷ 总资产（运营效率）
权益乘数 = 总资产 ÷ 股东权益（财务杠杆）
```

**行业适配说明**：
- 消费/医药：重点关注净利率变动（品牌溢价/定价权）
- 零售/制造：重点关注周转率变动（运营效率）
- 银行/地产：重点关注权益乘数变动（杠杆运用），高杠杆驱动须标红

---

## CFOR分解法（经营资产现金回报率）

**核心公式**：
```
CFOR = 现金利润率 × 经营资产周转率

现金利润率 = 经营活动现金流净额 ÷ 营业收入（销售收现能力）
经营资产周转率 = 营业收入 ÷ 经营资产（经营资产含固定资产、存货、应收账款等）
```

**分析要点**：
- 高 CFOR 表明资产现金回报丰厚
- 低现金利润率提示回款慢或垫资多
- 低周转率提示资产占用现金严重

**适用行业**：工程建筑、ToB软件、房地产、重型制造

---

## 自由现金流转化率与FCF-ROE协同框架

**计算公式**：
```
FCFF ≈ 经营活动现金流净额 – 资本支出
FCF转化率 = FCFF ÷ 净利润
```

**行业标准**：
| 行业类型 | 优质标准 | 极佳标准 |
|----------|----------|----------|
| 重资产（制造、航运、化工、钢铁、电力） | > 0.8 | > 1.0 |
| 轻资产（SaaS、互联网、品牌消费轻模式） | > 1.2 | > 1.5 |
| 混合/资本中等 | 使用重资产标准 | — |

**商业真相组合分析**：
| 组合 | ROE 水平 | FCF 转化率 | 判断 |
|------|----------|------------|------|
| 高质量增长 | >15% | 重资产>0.8/轻资产>1.2 | 理想标的 |
| 纸面富贵 | >15% | 重资产≤0.8/轻资产≤1.2 | 利润沉淀于应收/存货 |
| 现金牛 | <8% | 重资产>0.8/轻资产>1.2 | 成熟期企业，往往高分红 |
| 双重困境 | <8% | 低于行业相对优线 | 谨慎 |
| 防御资产 | 8%–15% | 重资产>0.8/轻资产>1.2 | 稳健 |
| 成长伪装 | 8%–15% | 低于行业相对优线 | 警惕 |

## ROIC与WACC对比分析

### ROIC计算
```
ROIC = NOPAT ÷ 投入资本

NOPAT = 息税前利润 × (1 – 所得税率)
投入资本 = 股东权益 + 有息负债 – 现金等价物
```

### WACC计算
```
WACC = Ke × 股权占比 + Kd × (1 – 税率) × 债务占比

债务占比 = 有息负债 ÷ 投入资本
股权占比 = 1 – 债务占比
```

### 股权成本Ke的机构级计算

**第一步：获取基础β（β_raw）**
- 优先：个股近3年周收益率对市场指数的OLS回归斜率
- A股：沪深300；港股：恒生指数
- 若上市不足3年：使用同行业可比公司β中位数，注明"β取行业替代值"
- 记录回归R²，若R² < 0.2，须标注"β解释力极低"

**第二步：Blume调整（均值回归修正）**
```
β_adjusted = 0.33 + 0.67 × β_raw
```

**第三步：去杠杆/再杠杆（若使用行业替代β时必须执行）**
```
β_unlevered = β_levered ÷ [1 + (1 - t) × D/E]
β_re-levered = β_unlevered × [1 + (1 - t) × D_target/E_target]
```

**无风险利率Rf的期限结构匹配**：
- 预测期5年取5年期国债；预测期10年取10年期国债
- A股、北交所/新三板：中国国债收益率
- 港股：若内地收入占比≥70%且以人民币计价≥80%，使用中国国债收益率；否则默认美国国债收益率

**ERP（股权风险溢价）取值参考**：
| 市场 | 建议取值 | 备注 |
|------|----------|------|
| A股 | 5%–7% | 建议取6%作为中性假设 |
| 港股 | 5%–6.5% | 建议取5.5% |
| 北交所/新三板 | 6%–7% | 参考A股标准上浮0.5-1% |

**最终Ke计算**：
```
K_e = R_f + β_adjusted × ERP
```

**债务成本Kd**：
- 优先：公司近一年实际利息支出 ÷ 平均有息负债
- 备选：同评级债券收益率或LPR加信用利差

### 流动性调整WACC

| 市场/条件 | 调整项 | 调整方法 |
|-----------|--------|----------|
| 港股小市值 | 日均成交额 < 500万HKD | Kd上浮100-200bps，Ke上浮50-100bps |
| 北交所 | 日均成交额 < 1000万元 | ERP上浮1-2% |
| 新三板 | 所有标的 | DCF不适用 |
| A股小市值 | 日均成交额 < 3000万元 | ERP上浮0.5-1% |

### Amihud非流动性指标
```
Illiquidity = (1/D) × Σ(|R_d| / V_d)
```
其中 R_d 为日收益率，V_d 为日成交金额（亿元）。

若 Illiquidity > 0.1，须上调WACC至少1%。

### 行业WACC参考区间

| 行业 | WACC参考区间 | 备注 |
|------|-------------|------|
| 能源/地产/公用事业 | 6%–7% | 重资产、低β、高债务占比 |
| 医疗/消费 | 7%–8.5% | 稳定现金流、中等β |
| 科技/工业/制造 | 9%以上 | 高β、轻资产、不确定性大 |

### 周期股ROIC通用处理原则

- 周期顶部/底部的单年ROIC无意义，必须使用**完整周期平均ROIC**（通常取5-10年）
- 估值时须结合周期时钟的当前阶段判断
- **周期股WACC特殊处理**：须同时计算当期WACC和周期中位WACC，若偏差>20%，使用周期中位WACC

### ROIC-WACC利差判断的"持续"定义

- "持续"定义为：过去5年中≥4年ROIC > WACC，且最后一年必须满足
- 若数据不足5年（如上市不足5年），则要求有数据的全部年份内最多1年不满足

### 价值判断规则

- **ROIC > WACC**：创造价值。若持续且ROE合理（12%–20%）、杠杆适度（负债率<50%），可视为高质量公司
- **ROIC < WACC**：毁灭价值。若此时ROE尚可，通常依赖高杠杆，风险较大

## PB-ROE矩阵

### 阈值定义

- **高PB**：高于历史70%分位，或 PB / 行业平均PB > 1.25
- **低PB**：低于历史30%分位，或 PB / 行业平均PB < 0.75
- **高ROE**：ROE > 15%
- **低ROE**：ROE < 8%

### 四象限定义

| 象限 | 匹配性 | 投资逻辑 | 动态质量检查 |
|------|--------|----------|--------------|
| 高PB + 高ROE（明星股） | 高度匹配 | 核心资产，关键看ROE可持续性 | 杜邦拆解，高杠杆须标红 |
| 低PB + 低ROE（价值陷阱） | 高度匹配 | 关注困境反转 | 排查净资产水分：商誉、存货、应收 |
| 高PB + 低ROE（泡沫股） | 严重不匹配 | 不建议价值投资者参与 | 关注市场预期与基本面鸿沟 |
| 低PB + 高ROE（隐形冠军） | 明显不匹配 | 框架"甜点区" | 高ROE能否维持？低PB是否隐藏风险？ |

## 市赚率（PR）

**核心公式**：
```
PR = N × PE(TTM) / ROE(TTM)
```

⚠️ **ROE代入格式（严格执行）**：ROE必须代入百分比数值（如ROE=15%则代入15，而非0.15）

**错误示范警示**：
- ✅ 正确：PR = 1.0 × 10 ÷ 15 = 0.67
- ❌ 错误：PR = 1.0 × 10 ÷ 0.15 = 66.7

**模型自查**：计算完成后检查PR值是否在0.1~5.0区间。若PR>10，大概率误用0.15替代15。

### N系数确定规则

*当近三年合计每股收益为正时：*
| 股利支付率区间 | N值 |
|----------------|------|
| ≥ 50% | 1.0 |
| 30%–50% | 1.5 |
| 10%–30% | 1.8 |
| < 10% | 2.0 |

**使用规则**：PR不作为独立买入条件，仅在PB-ROE矩阵分析后作为补充参考。"PR ≤ 0.5且股息率 ≥ 5%"可作为"低PB+高ROE"象限的强化信号。

## 安全边际计算方法库

| 方法 | 核心原理 | 首选适用行业 | 不适用场景及原因 |
|------|----------|-------------|---------------------|
| 格雷厄姆净流动资产法（NCAV） | 基于清算价值 | 破产边缘的制造业/贸易公司 | 轻资产/无形资产占比>30%的公司 |
| 现金流折现法（DCF） | 基于未来自由现金流预测 | 消费、公用事业、SaaS等 | 周期股/项目制公司/初创期 |
| 市盈率相对法（P/E） | 对比历史PE、行业PE | 盈利稳定的非周期行业 | 亏损/微利/利润波动极大 |
| 市净率法（P/B） | 基于账面价值 | 银行、保险、房地产、重资产制造 | 轻资产/商誉占净资产>30% |
| 收益率比较法 | 盈利收益率 vs 无风险利率 | 大类资产配置视角下的成熟公司 | 亏损/高增长但低利润 |
| 股利贴现模型（DDM） | 基于股利分配 | 分红稳定、股息政策透明的公司 | 不分红/分红波动大 |

### 安全边际率计算

```
安全边际率 = (内在价值 – 当前市值) / 内在价值
```

**四种口径**：
| 口径 | 说明 |
|------|------|
| ①近五年平均 | 取过去5个财年末的市值，分别计算每年的安全边际率后取算术平均 |
| ②近五年最小 | 过去5年安全边际率的最小值 |
| ③近五年最大 | 过去5年安全边际率的最大值 |
| ④当前 | 以最新收盘价对应市值计算的安全边际率 |

> 注意：内在价值使用统一估值方法在各年末重新计算，而非用当前内在价值回溯历史。
