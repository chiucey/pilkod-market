# 护城河七步法检查表·融合版

> 长线分析核心模块，必须逐项执行并输出检查结果。
> **终止规则**：若第一步"硬性门槛筛选"判定为"不通过"，则立即终止护城河分析，输出"不满足价值创造要求，放弃"。

## 第一步：硬性门槛筛选（财务过滤器）

| 测试项 | 通过标准 | 结果 |
|--------|----------|------|
| **1.1 传统成熟期测试** | 过去5年 ROIC 持续 **> 15%**（5年中≥4年满足，且最近一年必须满足）且 **> WACC**；ROE 持续 **> 15%**（非高杠杆驱动）。**周期股使用周期平均ROIC**。 | ☐ 通过 / ☐ 不通过 |
| **1.2 新经济豁免测试** | *仅限 SaaS/平台型*：NDR 连续多年 **> 110%**；LTV/CAC **> 3**。 | ☐ 通过 / ☐ 不适用 |
| **1.3 周期性排雷** | 过去5年中，ROIC 低于 WACC 的年份 **≤ 1年**（最近一年必须 > WACC 才算通过）。**周期股：此条不适用，直接跳过。** | ☐ 通过 / ☐ 不通过 / ☐ 免检（周期股） |
| **1.4 研发驱动豁免** | *仅限研发密集型*：研发费用率连续2年>15%且资本化率<20%，且满足：① 核心品种处于临床III期/量产导入期；② 近2年新增专利>10件；③ 与高校/科研院所合作项目>2个。②③置信度较低，须标注。 | ☐ 通过 / ☐ 不适用 |

**判定**：以上四项至少满足一项且通过1.3（或豁免），否则直接淘汰。

> **行业校准说明**：若行业类型为"成熟重资产/类固收"（银行、港口、高速公路、公用事业），且该行业过去5年ROIC中位数 < 10%，则"ROIC > 15%"的门槛调整为"ROIC > 当前 WACC + 5%"。

**若判定为"不通过"，立即输出"不满足价值创造要求，放弃"，本分析终止。**

## 第二步：行业利润池扫描（土壤双核测试）

| 测试项 | 核心问题 | 结论 |
|--------|----------|------|
| **2.1 进入威胁** | 超额利润是否引来产业资本/跨界巨头？进入门槛是物理限制、网络锁定还是巨额沉没成本？ | ☐ 强壁垒 ☐ 弱壁垒 |
| **2.2 下游议价权** | 客户是分散的 C 端，还是具备集采能力或扶持二供能力的 B 端/G 端？ | ☐ 强势 ☐ 弱势 |

**判定**：若两力均恶劣，标记为"脆弱护城河"，需极苛刻的安全边际。

## 第三步：护城河来源定性

### 3.1 护城河来源分级定位

> 下表中的数值为经验参考范围，但不可孤立使用。若指标落在阈值边缘（±2个百分点或±15%相对偏差），必须叠加至少一个定性信号才能下结论。

| 梯队 | 类型 | 可观测量化验证指标 | **参考范围（强→弱）** | **警示信号** |
|------|------|-------------------|----------------------|------------|
| 第一梯队 | 网络效应 | 用户年流失率、交叉网络弹性系数 | 流失率<10%（强），>20%（弱） | 流失率连续两年上升 |
| | 极端转换成本 | NDR、客户上线时长 | NDR>110%（强），<90%（弱） | NDR下降超5个百分点 |
| 第二梯队 | 供给侧成本优势 | 单位成本 vs 行业均值差距 | 持续5年低于行业均值>15%（强） | 差距收窄 |
| | 有效规模 | 市场空间 ÷ 最小有效产能 | >3倍（强），<1.5倍（弱） | 新进入者宣布扩产 |
| 第三梯队 | 品牌溢价 | 提价次数及提价后销量变化 | 成功提价≥3次且销量不降（强） | 提价能力丧失 |
| | 专利封锁 | 核心专利剩余年限、胜诉率 | 剩余>8年且胜诉率>80%（强） | 竞品已推出仿制药 |
| | 反向定位 | 模仿者财务表现 | 有2个以上案例证明模仿者失败（强） | 模仿者成功 |
| | 数据飞轮 | 数据独占性、模型效果曲线 | 数据独占且效果持续提升（强） | 数据可公开获取 |

### 3.2 护城河真伪鉴别

**格林沃尔德"暴力破解"实验**：
> 手握 100 亿美元，挖走高管，给足补贴，5 年内能否摧毁？
> 回答须具体到"哪个环节无法被资本复制"，禁止笼统回答。

**伪护城河排雷检查**（逐项勾选）：
- ☐ 单纯高市占率（无定价权）
- ☐ 优秀产品（非生态锁定）
- ☐ 先发优势（已被后来者追赶）
- ☐ 依赖政策补贴

**判定**：真护城河需满足暴力破解答案为具体到不可复制环节且无伪护城河特征。

### 3.3 输出格式

对每个识别到的护城河来源，须输出：
1. **来源类型与状态**：[类型]（[拓宽/稳定/侵蚀]）
2. **不可复制性论证**：具体描述竞争对手为何无法复制（200字内）
3. **半衰期预估**：[>10年/5-10年/<5年/不可预估]
4. **关键警示信号**：列举对应警示信号是否出现

**综合判断**格式：
"护城河来源A（状态），护城河来源B（状态）。[一句话综合判断]"

> ⚠️ 禁止输出"综合评分：X分"、"宽/中/窄护城河"等打分式结论。

## 第六步：估值与安全边际映射

| 护城河趋势评级 | 估值方法 | 买入触发条件 |
|----------------|------------------------|--------------|
| **宽+正向** | EPV + **保守**成长溢价 | 仅在市场恐慌时介入 |
| **宽+稳定** | **纯 EPV 估值，零成长溢价** | 当前利润即价值全部 |
| **宽+负向 / 中等** | 资产重置成本（甚至清算价值） | 极度低估才考虑 |
| **窄** | 不建议长期持有 | 低于清算价值 |
| 🎯 **绝佳击球区** | 基本面"宽+稳定"，市场因系统性恐慌给出"无护城河"级报价 | **扣动扳机** |

## 第七步：持有期监控清单（退出红线）

### 7.1 季度常规体检
- ☐ ROIC 是否跌破 15%（或行业对标值的合理水平）？
- ☐ 毛利率是否异常下滑且无合理解释？
- ☐ 第三步中任何一项量化指标是否从"强"跌至"弱"区间？

### 7.2 年度深度体检
- ☐ 重做第三步"暴力破解实验"，答案是否从"否"变为"是"或"不确定"？

### 7.3 三条不可逆退出红线（触碰任意一条，无论盈亏坚决离场）
- ☐ **护城河来源降级**（如：网络效应 → 转换成本）
- ☐ **监管逻辑颠覆**（如教培、强监管平台）
- ☐ **技术替代进入早期大众阶段**
