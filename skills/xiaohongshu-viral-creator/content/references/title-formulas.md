# 爆款标题公式库

## 一、情绪共鸣型

### 1. 痛点戳中型
```
模板：「[痛点/焦虑]？[解决方案]！」
适用：护肤、穿搭、职场

变体：
- 脸大显土？这样穿秒变小脸！
- 头发贴头皮？3招拯救细软塌！
- 手残党？教你5分钟搞定日常妆！
- 社恐变社牛？我只做了这三件事
- 腿粗胯宽？这条裤子绝了！
```

### 2. 身份代入型
```
模板：「[身份人群]必看！/ 适合[人群]的XX」
适用：精准受众触达

变体：
- 学生党平价好物分享｜均价20+
- 打工人早餐合集｜5分钟搞定
- 微胖女生显瘦穿搭｜这套绝了
- 敏感肌护肤避坑｜干货分享
- 租房改造｜500块焕然一新
```

### 3. 情绪爆发型
```
模板：「[情绪词]！[反差事件/惊喜]」
适用：引发强烈情绪反应

变体：
- 救命！这个真的绝绝子！
- 哭死！终于找到平替了！
- 我天！这也太好看了吧！
- 真香警告！用了三年的宝藏！
- 破防了！颜值与实力并存！
```

### 4. 逆袭爽感型
```
模板：「从XX到XX，我只做了XX」
适用：引发好奇和期待

变体：
- 从路人到焦点，我只换了发型！
- 从小白到月入过万，我经历了什么？
- 从土气到高级感，换了这些就够了！
- 从自卑到自信，她做了什么？
- 从微胖到好身材，方法公开！
```

## 标题优化检查清单

```
✓ 字数：18-25字为佳
✓ 结构：悬念/情绪词 + 核心价值 + 引导词
✓ 关键词：包含目标人群/核心痛点/解决利益
✓ emoji：1-3个，适量点缀
✓ 测试：准备3-5个备选标题

自检问题：
□ 是否让人产生好奇？
□ 是否知道点进去能得到什么？
□ 是否引发情绪共鸣？
□ 是否适合目标人群？
□ 是否优于同行标题？
```
