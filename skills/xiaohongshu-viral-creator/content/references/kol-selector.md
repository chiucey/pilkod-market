# KOL/KOC 筛选评估工具

## 筛选维度详解

### 一、基础数据指标

#### 1. 粉丝量级划分

| 等级 | 粉丝范围 | 适用场景 | 价格区间 |
|------|----------|----------|----------|
| 头部KOL | 50万+ | 品牌曝光、事件营销 | 5万+/条 |
| 腰部KOL | 10-50万 | 产品种草、口碑沉淀 | 1-5万/条 |
| 初级KOL | 1-10万 | 垂直渗透、口碑铺设 | 1000-1万/条 |
| KOC素人 | <1万 | 真实口碑、UGC裂变 | 免费-500/条 |

#### 2. 核心数据指标计算

```
互动率 = (点赞+收藏+评论+分享) / 粉丝数 × 100%

细分指标：
- 点赞率 = 点赞数 / 粉丝数 × 100%
- 收藏率 = 收藏数 / 粉丝数 × 100%
- 评论率 = 评论数 / 粉丝数 × 100%
- 分享率 = 分享数 / 粉丝数 × 100%

基准参考值：
✓ 优秀：互动率 > 5%
✓ 良好：互动率 3%-5%
⚠️ 一般：互动率 1%-3%
✗ 异常：互动率 < 1% 或异常高
```

#### 3. 数据质量评估

```python
# 粉丝质量评估模型
def evaluate_fan_quality(account):
    """评估账号粉丝质量"""

    # 1. 异常波动检测
    if account.growth_rate > 50:  # 短期异常增长
        return "高风险：疑似刷粉"

    # 2. 互动真实性
    real_interaction = account.comments / (account.likes * 0.1)
    if real_interaction < 0.05:  # 评论异常少
        return "警告：可能存在水军"

    # 3. 内容匹配度
    content_relevance = calculate_topic_overlap(
```

### 二、内容质量评估

#### 1. 垂直度评分

```
垂直度 = 核心领域笔记数 / 总笔记数 × 100%

评分标准：
★★★★★ (90%+)：非常垂直，领域专家
★★★★☆ (70%-90%)：较垂直，有明确人设
★★★☆☆ (50%-70%)：一般垂直，涉猎较广
★★☆☆☆ (<50%)：泛娱乐，垂直度低

加分项：
+ 人设鲜明（美妆博主/职场博主/母婴博主）
+ 风格统一（色调/排版/语言风格）
+ 内容深度（专业度/系统性）
```

#### 2. 人设感评估

```
人设强度指标：
- 头像/昵称辨识度
- 内容风格一致性
- 语言表达个人特色
- 账号人格化程度

人设类型：
📌 专业型：专家/导师/顾问形象
📌 闺蜜型：朋友/陪伴/分享形象
📌 励志型：逆袭/成长/蜕变形象
📌 真实型：素人/接地气/真实感
```

#### 3. 爆款率分析

```
爆款率 = 点赞>10000的笔记数 / 总笔记数 × 100%

爆款等级：
🔥 超爆款：点赞 > 10万
🔥 大爆款：点赞 5-10万
🔥 爆款：点赞 1-5万
📌 普通：点赞 1000-1万
📌 低效：点赞 < 1000

爆款规律分析：
- 爆款内容类型是什么？
- 爆款发布的时间规律？
- 爆款内容的共性特征？
```

### 三、商业价值评估

#### 1. 带货能力评估

```
核心指标：
- 带货笔记占比
- 带货GMV/销售额
- 带货转化率
- 复购推荐率

评估维度：
✓ 真实使用体验（自用推荐）
✓ 专业产品讲解（成分/功效）
✓ 对比测评维度（横向测评）
✓ 购物攻略信息（价格/渠道）
✓ 售后使用反馈（长期跟踪）
```

#### 2. 合作性价比

```
性价比公式：
ROI = 带来的GMV / 合作成本

合作价值评估：
A类账号（高ROI）：
- 互动率高 (>5%)
- 带货历史好
- 粉丝信任度高
- 价格合理

B类账号（中等ROI）：
- 互动率中等 (3%-5%)
- 有带货经验
- 内容质量稳定

C类账号（低ROI）：
- 互动率低 (<3%)
- 无带货数据
- 价格偏高
```

#### 3. 风险评估清单

```
⚠️ 高风险指标：
□ 近期粉丝异常增长
□ 互动数据波动大
□ 有抄袭/仿牌投诉记录
□ 内容同质化严重
□ 人设前后不一致
□ 负面舆论记录

✓ 低风险指标：
□ 长期稳定输出
□ 粉丝粘性高
□ 内容原创度高
□ 商业笔记口碑好
□ 积极配合度高
```

### 四、筛选决策模型

#### 1. 评分体系

```
综合评分 = Σ(指标得分 × 权重)

权重分配示例（种草场景）：
- 互动率：30%（核心指标）
- 垂直度：25%（内容匹配）
- 带货力：20%（商业价值）
- 配合度：15%（执行效率）
- 性价比：10%（成本控制）

评分等级：
★★★★★ (90+)：强烈推荐
★★★★☆ (75-90)：推荐
★★★☆☆ (60-75)：可考虑
★★☆☆☆ (45-60)：谨慎选择
★☆☆☆☆ (<45)：不建议
```

#### 2. 筛选流程

```
Step 1: 需求确认
├─ 品牌/产品类型
├─ 目标人群画像
├─ 预算范围
├─ 合作目标（曝光/种草/转化）
└─ 时间节点

Step 2: 初筛过滤
├─ 粉丝量级过滤
├─ 内容领域匹配
├─ 数据基准线过滤
└→ 输出候选名单（20-50人）

Step 3: 深度评估
├─ 详细数据查看
├─ 内容质量审核
├─ 商业历史调
└→ 输出精选名单（5-10人）

Step 4: 确认合作
├─ 档期和报价确认
├─ 合作形式确定
└→ 签订合作协议

Step 5: 执行监控
├─ 内容审核
├─ 数据追踪
└→ 效果评估
```

#### 3. 场景化推荐

| 合作场景 | 推荐类型 | 优先指标 | 预算建议 |
|----------|----------|----------|----------|
| 新品上市 | 腰部KOL+初级KOL | 垂直度、带货力 | 5-20万 |
| 大促种草 | 头部KOL+素人铺量 | 影响力、性价比 | 10-50万 |
| 口碑沉淀 | KOC素人矩阵 | 真实感、垂直度 | 1-5万 |
| 品牌升级 | 头部KOL+腰部KOL | 调性匹配、人设感 | 20-100万 |
| 事件营销 | 头部KOL | 影响力、破圈力 | 50万+ |
