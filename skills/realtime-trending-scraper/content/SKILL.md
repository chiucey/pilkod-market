# Realtime Trending Scraper

实时网络热点信息抓取技能，聚合多平台热门话题与趋势事件。

## 核心能力

### 1. 热点信息源
- **微博热搜**：实时热搜榜单及热度指数
- **知乎热榜**：热门问答与讨论话题
- **百度热搜**：搜索热度排行榜
- **抖音/小红书热点**：短视频平台热门内容
- **今日头条/腾讯新闻**：新闻资讯热点

### 2. 信息抓取方式

#### 批量搜索模式
```python
# 使用 batch_web_search 并行抓取多个平台的热点
queries = [
    {"query": "微博热搜 今日", "num_results": 10},
    {"query": "知乎热榜", "num_results": 10},
    {"query": "百度热搜实时", "num_results": 10},
    {"query": "抖音热点", "num_results": 10},
    {"query": "今日头条热点新闻", "num_results": 10}
]
```

#### 内容提取模式
```python
# 从特定热点页面提取详细信息
tasks = [
    {"url": "https://weibo.com/hot/search", "prompt": "提取热搜榜单前20条"},
    {"url": "https://www.zhihu.com/hot", "prompt": "提取热榜话题"}
]
```

```
1. [内容] - ❤️ xxx万点赞
2. [内容] - ❤️ xxx万点赞
...

[按时间排序的重大事件]
```

### 4. 高级功能

#### 热点追踪
- 设定关键词持续监控
- 追踪话题热度变化趋势
- 预警异常热度波动

#### 热点分析
- 话题热度趋势图
- 热度来源分布统计
- 关联话题聚类分析

#### 自定义筛选
- 按平台筛选
- 按时间范围筛选
- 按热度阈值筛选
- 按类别筛选（娱乐/科技/社会/体育等）

## 使用示例

### 基础热点查询
用户："帮我看看今天有什么热点新闻"

处理流程：
1. 并行调用 batch_web_search 抓取各平台热点
2. 汇总提取关键信息
3. 按热度排序格式化输出

### 特定话题追踪
用户："追踪一下关于 [话题] 的最新动态"

处理流程：
1. 搜索该话题的最新信息
2. 提取相关讨论和观点
3. 提供话题发展时间线

### 热点报告生成
用户："生成一份今日热点报告"

处理流程：
1. 抓取全平台热点数据
2. 按类别聚合整理
3. 生成结构化报告

## 注意事项

1. **时效性**：热点信息具有强时效性，优先使用最新数据
2. **多源验证**：重要信息需多平台交叉验证
3. **去重合并**：相同话题在不同平台的表达需合并处理
4. **隐私保护**：不抓取个人隐私信息
5. **频率控制**：避免短时间内大量请求同一平台

## 技术实现

使用工具：
- `batch_web_search`：并行搜索多平台热点
- `extract_content_from_websites`：深度提取页面内容
- `interact_with_website`：动态页面交互（如需要）

## 输出质量标准

- 信息完整：覆盖主要热点平台
- 格式清晰：结构化呈现便于阅读
- 时效优先：确保信息为最新
- 分类合理：按类型/平台清晰分组
