# BLM 业务领先模型完整框架（v3.0 参考文档）

## 模型总览

BLM 由两大核心闭环构成：

1. **战略制定层**：市场洞察 → 战略意图 → 创新焦点 → 业务设计
2. **战略执行层**：关键任务 → 正式组织 → 人才 → 氛围与文化

两大闭环由 **领导力（Leadership）** 与 **价值观（Core Values）** 贯穿，由 **业绩差距 / 机会差距** 驱动启动。

```
        ┌──────────────────────────────────────────┐
        │             领  导  力                    │
        ├──────────────────────────────────────────┤
        │  战略意图 → 市场洞察 → 创新焦点 → 业务设计   │  ← 战略制定
        │                                          │
        │              ↕ 战略解码 ↕                  │
        │                                          │
        │  关键任务 → 正式组织 → 人  才 → 氛围文化     │  ← 战略执行
        ├──────────────────────────────────────────┤
        │             价  值  观                    │
        └──────────────────────────────────────────┘
                       ↑
              业绩差距 / 机会差距（驱动起点）
```

## 模块释义

### 一、战略制定层

#### 1. 战略意图（Strategic Intent）
- **愿景（Vision）**：3-5 年终极图景，可量化
- **使命（Mission）**：为谁解决什么问题，创造什么独特价值
- **战略目标（Objectives）**：财务、市场、能力三类
- **作用**：作为整个 BLM 闭环的"北极星"，指引市场洞察的方向

#### 2. 市场洞察（Market Insight）
- 决定战略思考的深度
- 通过华为"五看"工具确保对未来的预判基于事实而非假设：
  - 看趋势（Trends）
  - 看市场（Market）
  - 看客户（Customer）
  - 看对手（Competitor）
  - 看机会（Opportunity）
- 产出：差距分析（业绩差距 + 机会差距）

#### 3. 创新焦点（Innovation Focus）
- 通过非对称手段捕获战略机会
- 四大方向：
  - 产品/服务创新
  - 商业模式创新
  - 技术创新
  - 运营创新
- **原则**：聚焦 1-2 个主方向，避免全面铺开

#### 4. 业务设计（Business Design）
- 战略思考的落脚点
- 五大要素：
  - 客户选择（Customer Selection）
  - 价值主张（Value Proposition）
  - 盈利模式（Profit Model）
  - **战略控制点（Strategic Control Point）**——护城河
  - 活动范围（Scope）

### 二、战略执行层

#### 5. 关键任务（Key Tasks）
- 支撑业务设计落地的重点工作清单
- 通过 **BEM（Business Execution Model）** 战略解码工具分解至各级组织
- 必须包含：责任人（Who）+ 截止日期（When）+ 产出物（What）

#### 6. 正式组织（Formal Organization）
- 组织架构（Structure）
- 管控模式（Governance）
- 流程体系（Process）
- 是战略实施的保障政策

#### 7. 人才（Talent）
- 战略的执行载体
- 关注：人才引进、评价、激励、能力提升
- 2026 年新维度：AI 流利度（AI Fluency）、双元性能力

#### 8. 氛围与文化（Atmosphere & Culture）
- 激发人才动能的关键
- 强调"以客户为中心"和"自我批判"
- **新项目高频失败原因**：母体组织文化对新业务的"排异反应"

### 三、贯穿要素

#### 领导力（Leadership）
- BLM 的引擎
- 必须由高层亲自领导战略洞察与设计
- 核心能力：战略洞察力、决断力、执行记录、资源整合力、自我批判能力

#### 价值观（Core Values）
- 直接影响决策取舍的行为准则
- 3-5 条，必须可操作

## 模型演进历史

| 阶段 | 时期 | 核心特征 | 关键工具 |
|---|---|---|---|
| **IBM 原始版** | 1990s-2003 | 关注组织一致性、战略与执行的匹配 | Congruence Model（一致性模型） |
| **华为优化版** | 2008-至今 | 强化市场洞察、战略解码与经营闭环 | 五看三定、BEM、DSTE 年度流程 |
| **现代扩展版** | 2020s | 整合数字智能化、生态协同、风险治理 | AI Native 架构、ESG、地缘政治审视 |

## 与 DSTE 流程的关系

华为将 BLM 嵌入更宏大的 **DSTE（Develop Strategy to Execute）** 流程：

```
战略洞察 → 战略制定（BLM 上半）→ 战略解码（BEM）→ 战略执行（BLM 下半）→ 战略评估 → 复盘迭代
   ↑                                                                            ↓
   └─────────────────────────── 年度滚动 ──────────────────────────────┘
```

DSTE 强调战略不是一次性事件，而是**年度滚动 + 季度评审 + 月度跟踪**的持续闭环。

## 常见误用

1. **把 BLM 当成填空模板**：没有真正的"工程化社会对话"，BLM 模块沦为 PPT 堆砌。
2. **跳过差距分析**：直接进入战略意图，导致战略与现状脱节。
3. **忽略战略执行层**：只做战略制定，不做组织、人才、文化的匹配设计。
4. **领导力缺位**：高层不亲自参与，由幕僚代笔，失去战略共识。
5. **静态使用**：一次性输出战略报告后束之高阁，未形成 DSTE 滚动闭环。
