# 五看三定：华为战略洞察与决策工具集（v3.0 参考文档）

"五看三定" 是华为在 BLM 框架内开发的市场洞察与战略选择标准化工具，解决传统 SWOT/PEST 颗粒度过粗、深度不足的问题。

## 一、五看（Look at Five）：多维度深度扫描

### 1. 看趋势（Look at Trends）

**核心问题**：长期演进规律是什么？

| 审视维度 | 必答内容 |
|---|---|
| 技术趋势 | 关键技术成熟度曲线、拐点时机、颠覆性技术信号 |
| 宏观经济 | GDP/利率/汇率走势对行业的影响 |
| 监管政策 | 国内外政策方向（含 EU AI Act、数据安全法等） |
| 社会人口 | 老龄化、消费分级、Z 世代偏好 |
| 数字化/AI | AI 对本行业的重塑路径与时间表 |

### 2. 看市场（Look at Market）

**核心问题**：市场结构与价值分布如何？

- **TAM**（Total Addressable Market）：理论总市场
- **SAM**（Serviceable Addressable Market）：可服务市场
- **SOM**（Serviceable Obtainable Market）：可获得市场
- 市场成熟度：导入期 / 成长期 / 成熟期 / 衰退期
- 集中度：HHI 指数 或 CR4/CR8
- **价值池迁移分析**：未来 3 年利润池将向哪些环节集中？

### 3. 看客户（Look at Customer）

**核心问题**：客户为什么买？

- 目标客群画像（人口/职业/收入/行为）
- 核心痛点与未被满足的需求
- 购买决策路径与关键触点
- TCO（Total Cost of Ownership）视角：客户付出的不仅是价格，还有时间、学习成本、切换成本
- 客户生命周期阶段（认知/兴趣/决策/复购/推荐）

### 4. 看对手（Look at Competitors）

**核心问题**：我们如何活下来？

| 审视项 | 必答内容 |
|---|---|
| 主要玩家盘点 | 产品 / 价格 / 渠道 / 服务对比 |
| 头部对手最强护城河 | 是什么？为什么难复制？可持续多久？ |
| 我们 vs 头部能力差距 | 在哪些维度？差距倍数？需要多久追平？ |
| 切入缝隙 | 对手的盲区、弱点、无法快速跟进的领域 |
| **生存压力测试** | 如果对手全力反击（降价 / 锁渠道 / 挖团队），我们如何活下来？ |
| 对手底层假设 | 他们为什么这么做？假设可能何时失效？ |

### 5. 看机会（Look at Opportunities）

**核心问题**：爆发点在哪里？

- 行业痛点未被满足的部分
- 商业模式转变中的爆发点（订阅制 / 平台化 / 智能化）
- 技术拐点（成本下降 10x、性能提升 10x）
- 政策窗口（牌照放开 / 补贴启动）
- 人口结构变化（银发经济 / Z 世代消费）
- 跨界整合机会

## 二、三定（Define Three）：战略决策的定力与控制

### 1. 定战略控制点（Define Strategic Control Points）

**核心命题**：核心竞争力只是生存基础，**战略控制点** 才是获取高利润的护城河。

#### 战略控制点完整清单（按强度从弱到强）

| 等级 | 控制点类型 | 特征 | 典型案例 |
|---|---|---|---|
| 弱 | 价格优势 | 易被复制 | 早期电商 |
| 弱 | 单一产品功能 | 易被复制 | 工具类 App |
| 中 | 品牌信任资产 | 需长期投入 | 茅台 / 奢侈品 |
| 中 | 规模效应 | 规模越大边际成本越低 | 亚马逊 AWS |
| 中 | 客户关系 | 高接触/高定制 | 咨询公司 |
| 强 | 客户转换成本 | 迁移成本极高 | SAP / Salesforce |
| 强 | 网络效应 | 用户越多价值越大 | 微信 / Uber |
| 强 | 关键稀缺资源 | 牌照 / 数据 / 矿权 | 银行牌照 / 卫星轨道 |
| 强 | 专利/知识产权 | 法律保护 | 高通 / 制药 |
| 极强 | 系统记录地位（SoR） | 业务流程中最后被放弃的工具 | 银行核心系统 / 核心 ERP |
| 极强 | 垂直整合栈 | 软硬件 / 数据 / 算力深度打通 | 特斯拉 / 苹果 |
| 极强 | 专有数据资产（AI 时代） | 极难迁移的垂直数据集群 | 医疗影像数据 / 工业数据 |

**审视规则**：
- 必须从清单中明确标注 [√/×]，至少识别 1-2 个具体控制点
- 全部为 × → 立项风险极高，等同于"为行业探路"

### 2. 定目标（Define Objectives）

**核心命题**：建立明确、可度量的近期及长期经营指标。

- **财务目标**：年份 + 营收 / 利润 / 现金流的具体数字
- **市场目标**：市场份额 / 排名 / 用户规模
- **能力目标**：需要建立的核心能力（团队 / 技术 / 渠道）
- **时间目标**：Phase 1/2/3 的里程碑

### 3. 定策略（Define Strategy）

**核心命题**：制定实现目标的路径与资源配置方案。

- 进入策略（自建 / 收购 / 合作）
- 增长策略（产品扩展 / 市场扩展 / 客群扩展）
- 防御策略（壁垒强化 / 替代品阻击 / 上下游整合）
- 资源配置（资金 / 人力 / 时间的优先级）

## 三、五看三定与 BLM 的关系

```
五看（市场洞察）→ 差距分析 → 战略意图 → 创新焦点 → 业务设计
                                                     ↓
                                              三定（战略选择）
                                                     ↓
                                              战略解码（BEM）
                                                     ↓
                                              战略执行（BLM 下半）
```

五看完成的是"看清楚"，三定完成的是"想明白"，BLM 下半完成的是"做出来"。

## 四、常见误用

1. **五看流于形式**：每个维度只写 1-2 句话，没有数据支撑，沦为表面文章。
2. **跳过看对手的"生存压力测试"**：只盘点对手现状，不思考对手反击场景。
3. **战略控制点不真实**：自我安慰式标注，没有客观证据支撑。
4. **三定缺乏数字**：定目标不写具体数字，定策略不写优先级，沦为口号。
