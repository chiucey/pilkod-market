# 数据存储格式规范

## 存储结构

数据存储在 `./.weekly-report-data/` 目录下，按年月分文件存储。

## 文件命名

```
YYYY-MM.json
```

示例：
- `2024-01.json` - 2024年1月数据
- `2024-02.json` - 2024年2月数据

## 数据结构

```json
{
  "YYYY-MM-DD": [
    {
      "id": "时间戳字符串",
      "content": "工作内容",
      "status": "状态",
      "remark": "备注",
      "createdAt": "YYYY-MM-DD HH:mm:ss"
    }
  ]
}
```

## 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | string | 是 | 唯一标识，使用时间戳 |
| content | string | 是 | 工作内容描述 |
| status | string | 是 | 任务状态：已完成/进行中/待开始/已延期 |
| remark | string | 否 | 备注信息 |
| createdAt | string | 是 | 创建时间 |
