# 小红书笔记文案模板库

## 一、标题公式

### 痛点型（最高点击率）
```
[人群标签] + [痛点场景] + [解决方案暗示]
例：皮肤暗沉的姐妹看过来！这3步真的亮了
```

### 数字型（信任感强）
```
[数字] + [类目] + [结果/方法]
例：28天素人逆袭！靠这5个动作瘦了15斤
```

### 好奇型（悬念钩子）
```
[颠覆认知] + [结果展示]
例：我花300块买的，比1000块的好用太多了…
```

### 价值型（收藏转化高）
```
[合集/清单] + [价值承诺]
例：建议收藏｜2026年最值得入手的10款平价护肤
```

### 情绪共鸣型（分享率高）
```
[场景/情绪] + [共鸣点]
例：29岁，第一次在租房里布置了一个真正属于自己的角落
```

## 二、正文结构模板

### 模板A：干货攻略型（收藏率高）
```
【开头钩子 - 前3行必须吸引人】
✨ [痛点/场景引入，引发共鸣]

【主体内容】
📍 方法一：[标题]
[具体操作步骤，2-3句]

📍 方法二：[标题]
[具体操作步骤，2-3句]

📍 方法三：[标题]
[具体操作步骤，2-3句]

【结尾CTA】
💬 你们有没有试过这个方法？评论区告诉我～
❤️ 觉得有用的话记得收藏！下次找不到就麻烦了～
```

### 模板B：种草测评型（转化率高）
```
【开头 - 场景化引入】
[产品使用前的状态/问题，制造代入感]

【产品介绍】
🏷️ 产品：[名称]
💰 价格：[价格区间]
🎯 适合人群：[目标用户]

【使用体验】
📌 第一印象：[外观/包装感受]
📌 实际效果：[使用过程中的感受]
📌 惊喜点：[超预期的地方]
📌 不足点：[真实缺点，增加可信度]

【总结】
⭐ 推荐指数：[X/5星]
✅ 适合购买的情况：[具体场景]
❌ 不建议入手的情况：[诚实建议]

【CTA】
💌 有问题直接问我，都会回！
```

### 模板C：生活记录型（互动率高）
```
【情绪开场】
[一句话描述当下状态/心情，贴近生活]

【内容主体 - 故事化叙述】
[用第一人称讲述，细节要具体，让人有画面感]
[可以分几个场景/时间点展开]

【感悟/收获】
[从经历中提炼的insight，引发共鸣]

【互动引导】
你们有没有类似的经历呢？
```

### 模板D：教程类型（专业感强）
```
【一句话说清楚能学到什么】
今天教大家[具体技能]，[X]分钟学会！

【准备工作】
🛠️ 工具/材料：[清单]
⏱️ 耗时：[时间预估]
💪 难度：[新手/进阶]

【步骤详解】
Step 1：[操作] → [效果]
Step 2：[操作] → [效果]
Step 3：[操作] → [效果]

【注意事项】
⚠️ [常见误区1]
⚠️ [常见误区2]

【成品展示 + CTA】
按照以上步骤，你也能做出[成品]！
学会了记得@我看看效果～
```

## 三、评论区互动话术

### 回复咨询类评论
```
"宝子好问题！[简要回答] 你可以[具体建议]，我自己用下来[个人体验]～有其他问题继续问我！"
```

### 回复赞美类评论
```
"谢谢宝子！[真诚感谢] 你[发现的细节]，我[相关补充]，希望对你有帮助❤️"
```

### 引导关注
```
"这类内容我经常分享，关注我不迷路～"
```

### 引发讨论
```
"你们觉得[选项A]还是[选项B]更好用？评论区投票！"
```

## 四、封面文案规范

| 要素 | 规范 |
|------|------|
| 字数 | 主标题≤8字，副标题≤12字 |
| 字体 | 粗体、有对比度，确保手机小屏可读 |
| 关键词 | 必须包含品类核心词 |
| 情绪词 | 加入"绝了""OMG""救命"等网感词 |
| 数字 | 有数字比无数字点击率高40% |
