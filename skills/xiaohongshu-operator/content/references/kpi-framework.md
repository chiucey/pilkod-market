# 小红书数据分析与KPI追踪框架

## 一、核心KPI基准值

| 指标 | 定义 | 及格线 | 优秀线 | 计算公式 |
|------|------|--------|--------|---------|
| **互动率** | 综合互动/曝光 | 3% | 5%+ | (点赞+收藏+评论+分享)/浏览量 |
| **收藏率** | 收藏/浏览 | 5% | 8%+ | 收藏数/浏览量 |
| **评论率** | 评论/浏览 | 1% | 2%+ | 评论数/浏览量 |
| **分享率** | 分享/浏览 | 1% | 2%+ | 分享数/浏览量 |
| **粉丝增长率** | 月新增/总粉丝 | 10% | 15-25%+ | 月新增粉丝/月初总粉丝 |
| **点击率(CTR)** | 外链点击/浏览 | 1% | 3%+ | 外链点击/浏览量 |

## 三、内容归因分析矩阵

| 问题现象 | 可能原因 | 解决方向 |
|---------|---------|---------|
| 浏览量低 | 标题吸引力不足/话题标签选错/发布时间不对 | 优化标题公式，检查话题热度，调整发布时间 |
| 浏览高但互动低 | 内容价值不足/CTA太弱/评论门槛高 | 增加干货密度，强化CTA引导，提问式结尾 |
| 互动高但不增粉 | 内容与账号定位偏差 | 强化账号人设，统一内容方向 |
| 收藏高但评论少 | 内容信息密度高，读者沉默消费 | 在评论区主动发起话题，引导讨论 |
| 粉丝增长停滞 | 内容缺乏新鲜感/更新频率降低 | 引入新话题，增加发布频次，蹭热点 |

## 四、内容分级评估标准

| 级别 | 浏览量(新账号) | 浏览量(成熟账号) | 行动 |
|------|-------------|----------------|------|
| A级爆款 | 1万+ | 10万+ | 立即追更同类内容，做成系列 |
| B级优质 | 3000-1万 | 3万-10万 | 分析优点，复制方法论 |
| C级及格 | 1000-3000 | 1万-3万 | 小幅优化，继续发布 |
| D级需改进 | <1000 | <1万 | 深度归因，停止同类型 |

## 五、账号健康度诊断

每月检查以下指标，评估账号整体状态：

**基础健康**
- [ ] 完播率（视频）≥30%
- [ ] 账号互动率维持在3%以上
- [ ] 每月粉丝净增长为正

**内容健康**
- [ ] 爆款率（A/B级内容占比）≥20%
- [ ] 内容定位一致性（是否跑偏）
- [ ] 是否定期产出收藏率高的硬干货

**社区健康**
- [ ] 评论正面情绪占比≥85%
- [ ] 是否有粉丝自发二创或@账号
- [ ] 是否有回头互动的忠实粉丝

## 六、算法友好度检查清单

发布前：
- [ ] 标题含核心关键词
- [ ] 正文前3行涵盖搜索词
- [ ] 话题标签数量5-10个，层级合理
- [ ] 图片/视频质量达标（非搬运内容）
- [ ] 发布时间在高峰时段（7-9点 / 12-13点 / 20-22点）

发布后：
- [ ] 发布后30分钟内回复前5条评论
- [ ] 在相关话题下的热门帖子留言引流
- [ ] 检查系统是否正常收录（搜索验证）
