# 小红书视觉美学与滤镜选择指南

## 一、主流美学风格分类

### 1. 奶油白/INS极简风
- **核心色调**：米白、燕麦色、浅灰、哑光白
- **适合品类**：家居、护肤、轻奢品牌、咖啡
- **构图原则**：留白≥40%，中心构图，物品整齐排列
- **光线要求**：柔和自然光，避免强硬阴影
- **滤镜关键词**：VSCO A4/A6，Lightroom白色系预设，低饱和高亮度

### 2. 多巴胺撞色风
- **核心色调**：亮黄+粉红、橙+紫、蓝+橙等对比色
- **适合品类**：服装、配饰、美妆、零食
- **构图原则**：色块明确，主体突出，背景单色
- **光线要求**：充足光线，避免偏色
- **滤镜关键词**：提高饱和度+20，增加对比度，暖色调

### 3. 复古胶片风
- **核心色调**：暖黄、棕褐、淡绿、做旧色
- **适合品类**：旅行、咖啡、文艺生活、复古服装
- **构图原则**：随意自然，有生活感，可有轻微虚焦
- **光线要求**：黄金时段光线，逆光/侧光效果佳
- **滤镜关键词**：VSCO HB1/HB2，胶片颗粒感+20，褪色效果

### 4. 清新日系风
- **核心色调**：浅粉、薄荷绿、淡蓝、纯白
- **适合品类**：美食、花艺、小清新生活、文具
- **构图原则**：对角线构图，细节特写，自然散乱美
- **光线要求**：窗边柔光，轻微过曝（+0.3EV）
- **滤镜关键词**：日系感、低对比度、高明度

### 5. 高级暗调风
- **核心色调**：深棕、炭灰、酒红、金色点缀
- **适合品类**：奢侈品、高端餐饮、精品酒店
- **构图原则**：戏剧性用光，阴影利用，精致细节
- **光线要求**：低调侧光，强调质感
- **滤镜关键词**：降低高光，提高阴影，增加暖调

## 二、图片规格规范

| 参数 | 推荐规格 |
|------|---------|
| 比例 | **9:16（竖版）**为首选，3:4次之 |
| 分辨率 | 最低1080x1920px |
| 文件大小 | <10MB，JPEG格式 |
| 封面图 | 第1张必须最抓眼球，建议有文字叠加 |
| 图片数量 | 1张（极简风）/ 3-9张（图文并茂）/ 视频优先 |

## 三、视频规格规范

| 参数 | 推荐规格 |
|------|---------|
| 时长 | **15-60秒最优**（算法推荐权重最高） |
| 比例 | 9:16竖版 |
| 分辨率 | 1080x1920px |
| 帧率 | 30fps |
| 封面 | 第一帧务必精心设计，直接影响点击率 |
| 字幕 | 必加，增加20%完播率 |

## 四、色彩心理学快速参考

| 颜色 | 心理联想 | 适合场景 |
|------|---------|---------|
| 红/粉 | 活力、热情、女性 | 美妆、服装、节日营销 |
| 蓝 | 信任、冷静、专业 | 科技、金融、健康 |
| 绿 | 自然、健康、清新 | 有机食品、护肤、环保 |
| 黄/橙 | 快乐、活泼、食欲 | 美食、运动、儿童 |
| 紫 | 神秘、高贵、创意 | 美容、香氛、奢华 |
| 白/米 | 简约、纯粹、高级 | 家居、轻奢、极简品牌 |
| 黑/深色 | 权威、优雅、奢侈 | 高端品牌、成熟市场 |

## 五、封面设计检查清单

- [ ] 主视觉清晰，焦点明确
- [ ] 文字覆盖建议区域（左上/中间/右下）
- [ ] 字体大小在手机小屏可读
- [ ] 色彩与品牌美学一致
- [ ] 第一眼3秒能看懂主题
- [ ] 避免大量纯文字，图文比例适当
- [ ] 避免过度滤镜导致失真
