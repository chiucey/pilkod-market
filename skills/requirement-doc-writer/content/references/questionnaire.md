# Requirement Clarification Questionnaire

## 需求澄清问题清单

在撰写需求文档前，使用此清单确认所有关键信息已收集。

---

## 核心问题（必问）

### 关于需求本身

1. **您希望通过这个需求实现什么目标？**
   - [ ] 解决什么问题？
   - [ ] 带来什么价值？
   - [ ] 有具体的成功指标吗？

2. **这个需求的核心范围是什么？**
   - [ ] 必须包含的核心功能？
   - [ ] 明确排除的内容？
   - [ ] 是否有相似功能需要整合？

3. **这个需求的优先级如何？**
   - [ ] P0 - 必须本期完成
   - [ ] P1 - 重要，本期尽量完成
   - [ ] P2 - 可以放在后续迭代

### 关于用户

4. **谁是这个功能的主要用户？**
   - [ ] 用户角色描述
   - [ ] 用户数量估算
   - [ ] 用户技术水平

5. **用户的主要使用场景是什么？**
   - [ ] 日常使用场景
   - [ ] 极端使用场景
   - [ ] 使用频率

6. **用户当前是如何解决这个问题的？**
   - [ ] 现有解决方案
   - [ ] 痛点
   - [ ] 改进期望

---

## 扩展问题（按需询问）

### 时间与资源

## 快速澄清模板

对于时间紧迫的场景，使用以下快速模板：

```
需求：[一句话描述]
目标：[要解决的问题]
用户：[目标用户群体]
核心功能：[3-5个关键功能]
优先级：P[0/1/2]
截止日期：[如有]
```
