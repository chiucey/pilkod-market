# BareK_Trading_Skill – 裸K线个股买卖点判断技能

## 功能概述

基于纯K线价格行为（无技术指标），通过识别市场结构（趋势/震荡）、关键支撑阻力位、反转K线形态（锤子线、吞没、Pinbar等），输出个股的买卖点判断及风控建议。

**核心原则**：本技能严格遵循纯价格行为分析，不使用任何滞后指标（MACD、KDJ、RSI等），仅依靠K线形态、价格结构和成交量进行判断。

---

## 适用场景

- 个股日线或小时级别的技术分析
- 辅助交易者识别高概率入场/出场时机
- 制定止损、止盈、仓位管理计划
- 识别关键支撑阻力位及汇合区域

---

用户需提供：

| 信息类型 | 要求 | 说明 |
|---------|------|------|
| 个股代码/名称 | 可选 | 用于输出报告标识 |

| 当前持仓状态 | 可选 | 空仓/持有多仓/持有空仓 |
| 账户资金 | 可选 | 用于仓位计算 |

- 下跌：近期高点依次降低（H1<H2<H3），低点依次降低（L1<L2<L3）

### 3. K线信号识别

#### 信号判定标准

| 形态 | 判定条件 | 有效位置 |
|------|---------|---------|
| **锤子线** | 实体短，下影线≥实体2倍，无上影线或极短 | 下跌趋势末端/关键支撑位 |
| **射击之星** | 实体短，上影线≥实体2倍，无下影线或极短 | 上涨趋势末端/关键阻力位 |
| **阳包阴** | 第二根阳线实体完全覆盖前一根阴线实体 | 关键支撑位附近 |
| **阴包阳** | 第二根阴线实体完全覆盖前一根阳线实体 | 关键阻力位附近 |
| **上升Pinbar** | 小实体+长下影线拒绝更低价格 | 支撑区 |
| **下降Pinbar** | 小实体+长上影线拒绝更高价格 | 阻力区 |
| **双针探底** | 两根K线均有长下影线，最低价相近 | 下跌低位 |

#### 最近信号汇总

| K线序号 | 形态 | 质量评级 | 位置评估 | 成交量 |
|--------|------|---------|---------|-------|
| 第X根 | 锤子线 | 高/中/低 | 支撑区/阻力区/中间位 | 放大/正常/萎缩 |

**信号有效性排序**：
1. 关键位置 + 形态清晰 + 成交量配合 → 高概率
2. 关键位置 + 形态 → 中概率
3. 仅形态 → 低概率

- 出现看跌反转K线形态

### 5. 持仓管理建议（如有持仓）

#### 持仓状态评估

| 项目 | 当前状态 |
|------|---------|
| 持仓方向 | 多仓/空仓 |
| 持仓均价 | XX.XX |
| 当前盈亏 | +X.X% / -X.X% |
| 是否符合趋势 | 是/否 |

#### 止损管理建议

- **盈利<1R**：保持初始止损不动
- **盈利1R-2R**：将止损移至保本
- **盈利>2R**：上移止损至1R利润锁定

#### 反转信号应对

若出现反向反转信号：
- 高概率反向信号 → 考虑全部平仓
- 中概率反向信号 → 考虑减仓50%
- 低概率反向信号 → 保持仓位观望

---

### 6. 风控提醒

| 风控项目 | 建议值 |
|---------|-------|
| 单笔最大亏损 | ≤总资金2% |
| 建议风险比例 | 1%~1.5% |
| R值（风险单位） | 入场价与止损价之差 |
| 连续亏损暂停 | 连续3笔亏损后停止交易并复盘 |

#### 仓位计算公式

```
建议仓位 = 账户总资金 × 风险比例（默认1.5%） ÷ （入场价 − 止损价）
```

## 分析规则（内置逻辑）

### 规则1：趋势定义

```
上涨趋势：HHV(20) > HHV(20)_1 AND LLV(20) > LLV(20)_1
下跌趋势：HHV(20) < HHV(20)_1 AND LLV(20) < LLV(20)_1
震荡趋势：以上皆不满足
```

### 规则2：关键位置识别优先级

1. **波段高/低点**：明显的转折点，优先级最高
2. **整数关口**：心理价位（10.00、20.00、100.00等）
3. **斐波那契回撤**：50%和61.8%回撤位
4. **水平支撑阻力**：多次测试的位置
5. **汇合区**：多个条件重叠的位置优先级最高

### 规则3：有效反转K线判定

**形态完整性检查**：
- 实体大小：应小于整根K线的20%
- 影线长度：应大于实体的2倍
- 影线方向：与预期反转方向一致
- 影线顶点：应明显突破近期价格范围

**位置验证**：
- 必须位于关键支撑/阻力位附近
- 必须与当前趋势方向一致（底部形态在下跌中，顶部形态在上涨中）

**成交量确认**（可选）：
- 反转K线当天成交量应高于近期平均水平
- 缩量反转需降低信号评级

### 规则4：买卖点触发逻辑

#### 做多入场的完整条件

```
1. 趋势条件：上涨趋势 OR 下跌趋势末端
2. 位置条件：价格触及关键支撑位
3. 形态条件：出现看涨反转K线
4. 止损设置：设于该K线最低价下方1-2个最小报价单位
```

#### 做空/止盈的完整条件

```
1. 趋势条件：下跌趋势 OR 上涨趋势末端
2. 位置条件：价格触及关键阻力位
3. 形态条件：出现看跌反转K线
4. 止损设置：设于该K线最高价上方1-2个最小报价单位
```

### 规则5：风控计算标准

| 参数 | 默认值 | 可调整 |
|------|-------|-------|
| 单笔风险比例 | 1.5% | 1%~2% |
| R值计算 | 入场价-止损价 | - |
| 止盈倍数 | 1R/2R/3R | - |
| 保本止损 | 盈利达2R后 | - |

## 注意事项

1. **仅供参考**：本技能仅提供技术分析参考，不构成投资建议
2. **风险自担**：用户需自行承担交易风险
3. **止损纪律**：必须严格执行预设止损，不得临时更改
4. **连续亏损**：当连续3笔交易亏损时，建议停止使用并复盘
5. **心态管理**：避免情绪化交易，保持交易计划一致性
6. **数据质量**：K线数据应保证完整性和准确性
