# AI漫剧生成器

## 任务目标
- 本Skill用于：根据用户提供的主题或简单想法，一键生成完整的AI漫画剧集
- 能力包含：剧情创作、角色设计、分镜脚本编写、图像生成、漫剧排版
- 触发条件：用户需要创作漫画故事、连环画、图文剧本、视觉化叙事内容

## 前置准备
- 依赖说明：scripts脚本所需的依赖包及版本
  ```
  Pillow>=9.0.0
  ```

## 操作步骤

### 标准流程

#### 步骤1：需求采集
- 向用户询问以下信息（如用户未提供则使用默认值）：
  - **主题/题材**：故事核心主题（如"科幻冒险"、"校园恋爱"、"悬疑推理"）
  - **风格**：画面风格（如"日式漫画"、"美式卡通"、"水墨风格"、"像素风"）
  - **格数**：每页画格数量（建议4-8格）
  - **页数**：漫剧总页数（建议1-3页）
  - **角色**：主要角色信息（可选，如未提供则自动设计）

#### 步骤2：剧情创作
- 根据用户提供的主题，智能体创作完整的故事内容：
  - 生成故事大纲（起承转合结构）
  - 编写详细剧本（包含场景描述、角色对白、动作指导）
  - 控制故事节奏以适配指定格数和页数
- 参考 [references/story_template.md](references/story_template.md) 中的故事结构模板

#### 步骤3：角色设计
- 为故事中的主要角色设计视觉形象：
  - **外貌特征**：年龄、性别、身高、体型、发型、发色、瞳色
  - **服装造型**：主要服装、配饰、标志性元素
  - **性格特征**：通过表情、姿态体现的性格特点
  - **视觉关键词**：用于图像生成的英文描述词
- 将角色描述整理为结构化文档，确保后续图像生成的一致性

#### 步骤4：分镜脚本生成
- 将剧本拆解为具体的分镜脚本，每格包含：
  - **镜头编号**：如"第1页第1格"
  - **场景描述**：环境、时间、天气、氛围
  - **角色信息**：出场角色、位置、动作、表情
  - **对白/旁白**：角色对白、内心独白、叙事文字
  - **图像生成提示词**：英文格式的详细画面描述
- 参考 [references/story_template.md](references/story_template.md) 中的分镜脚本格式

#### 步骤5：图像生成
- 逐格生成分镜脚本中描述的漫画图像：
  - 使用智能体的图像生成能力
  - 基于分镜脚本中的提示词生成画面
  - 保持画风一致性（通过在提示词中包含风格关键词）
  - 保持角色一致性（通过在提示词中重复角色视觉关键词）
- 将生成的图像按顺序命名保存（如`01.png`, `02.png`...）到临时目录
- 注意：图像生成时使用统一的风格描述前缀，确保画面风格一致

#### 步骤6：漫剧排版
- 调用 `scripts/comic_layout.py` 脚本进行图像拼接：
  ```bash
  python scripts/comic_layout.py --input-dir <图像目录> --output <输出路径> --layout <布局> [--title <标题>]
  ```
- 参数说明：
  - `--input-dir`：包含生成图像的目录路径
  - `--output`：输出漫剧图片的完整路径
  - `--layout`：排版布局（支持：`2x1`、`2x2`、`3x2`、`4x2`）
  - `--title`：漫剧标题（可选，将添加标题栏）
- 脚本将自动：
  - 读取并排序输入目录中的图像
  - 统一图像尺寸并拼接成完整页面
  - 添加画格分隔线和边距
  - 输出最终的漫剧图片

#### 步骤7：输出与交付
- 向用户展示生成的漫剧图片
- 提供完整的创作资料：
  - 故事大纲和完整剧本
  - 角色设计文档
  - 分镜脚本
  - 漫剧成品图片

### 可选分支
- **快速模式**：用户只提供主题关键词，其余全部自动生成
- **精细模式**：用户参与每个环节的确认和调整（剧情、角色、分镜）
- **多页模式**：生成多页漫剧时，重复步骤4-6并最终合并为PDF

## 资源索引
- 必要脚本：见 [scripts/comic_layout.py](scripts/comic_layout.py)（用途：图像拼接与排版；参数：输入目录、输出路径、布局格式、标题）
- 领域参考：见 [references/story_template.md](references/story_template.md)（何时读取：创作剧情和编写分镜脚本时参考格式规范）

## 注意事项
- 图像生成时务必保持画风一致：在每个提示词开头添加统一的风格描述
- 角色一致性：在不同画格中重复使用相同的角色视觉关键词
- 分镜节奏：控制每格的信息量，避免单格过于复杂
- 图像数量：确保生成的图像数量与排版布局匹配（如`2x2`布局需要4张图）
- 如需调整某格画面，可单独重新生成该格图像后再拼接

## 使用示例

### 示例1：快速生成科幻漫剧
- 用户输入："生成一个科幻题材的4格漫剧，风格是日式漫画"
- 执行方式：
  1. 智能体创作科幻主题短故事（4格容量）
  2. 设计主要角色形象
  3. 生成4格分镜脚本和对应提示词
  4. 生成4张漫画图像
  5. 调用脚本以`2x2`布局拼接
- 输出：完整的4格漫剧图片

### 示例2：自定义剧情的恋爱漫剧
- 用户输入：提供完整剧情大纲
- 执行方式：
  1. 智能体根据大纲细化剧本
  2. 按用户要求设计角色
  3. 拆解分镜并生成图像
  4. 排版输出
- 输出：符合用户剧情要求的漫剧

### 示例3：多页悬疑漫剧
- 用户输入："创作一个3页的悬疑推理漫剧"
- 执行方式：
  1. 创作完整悬疑故事（3页容量，约12-18格）
  2. 设计侦探、嫌疑人等角色
  3. 逐页生成分镜和图像
  4. 分别排版每页后合并
- 输出：3页完整漫剧
