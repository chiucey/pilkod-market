# 投资行业分析报告技能

## 技能概述

本技能帮助用户基于专业的行业分析框架，生成结构化的投资研究报告。技能遵循工程化工作流程，强调数据驱动、交叉验证和客观中立。

## 核心分析框架

技能内置以下分析维度，完整覆盖投资研究的全部关键要素：

### 一、行业界定与分类
- **行业定义**：根据国家标准或市场惯例明确行业归属及边界
- **细分领域**：按产品类型、技术路线、应用场景、客户层级等维度划分
- **产业链位置**：明确本行业在产业链中的位置，梳理上下游关系

### 二、宏观环境分析（PEST）
- **政治（Policy）**：产业政策、税收优惠、进出口管制、环保要求
- **经济（Economy）**：GDP增速、利率汇率、居民收入、固定资产投资
- **社会（Society）**：人口结构、消费习惯、健康意识、文化观念
- **技术（Technology）**：技术革新速度、研发投入趋势、专利布局

### 三、行业发展阶段与生命周期
- **阶段判断**：导入期、成长期、成熟期、衰退期特征分析
- **历史沿革**：回顾行业过去5-10年发展历程
- **未来展望**：技术趋势、政策趋势、需求趋势、供给趋势

### 四、市场分析与规模测算
- **市场规模**：全球/中国整体市场规模及细分领域
- **市场结构**：区域分布、客户类型分布、产品档次分布
- **增长驱动因素**：渗透率提升、替代需求、政策强制要求等
- **潜在空间**：理论天花板测算

### 五、行业结构分析（五力模型）
- **上游议价能力**：供应商集中度、原材料稀缺性
- **下游议价能力**：客户集中度、价格敏感度
- **潜在进入者威胁**：行业门槛、进入周期
- **业内竞争程度**：竞争对手数量、产品同质化程度
- **替代品威胁**：功能替代、技术替代可能性

### 六、战略群组分析
- **划分维度**：按产品价格带、地域覆盖、客户类型等划分
- **识别直接对手**：同一群组内的企业构成最直接竞争
- **移动壁垒**：跨越不同群组的难度分析

### 七、关键成功因素（KSF）
- **技术能力**：核心技术、专利壁垒、研发迭代速度
- **成本控制**：规模效应、供应链管理
- **品牌渠道**：品牌认知度、渠道覆盖密度
- **资源禀赋**：稀缺资源获取、政府关系

### 八、行业风险分析
- **宏观风险**：经济周期波动、贸易摩擦、汇率波动
- **政策风险**：行业监管收紧、税收优惠取消
- **技术风险**：技术路线被颠覆、研发失败
- **竞争风险**：恶性价格战、新巨头进入

### 九、行业盈利性与投资价值
- **盈利水平**：毛利率、净利率、ROE水平
- **资本回报**：ROIC、投资回收期
- **投资吸引力**：机会与威胁的综合评估

### 十、标的关联分析（如适用）
- **定位匹配**：标的在行业细分领域的卡位
- **竞争优势**：标的相对行业平均水平的差异化优势
- **风险传导**：行业风险对标的经营的影响路径
- **成长空间**：行业增长红利中标的能获取的份额

## 工作流程

### 阶段1：需求确认

在开始分析前，确认以下关键信息：

1. **行业范围**：用户关注的特定行业或领域
2. **投资标的**（可选）：
   - 有明确的拟投资标的公司
   - 仅进行行业层面分析
   - 多家可比公司对比分析
3. **报告格式**：Word（.docx）、PDF（.pdf）、Markdown（.md）
4. **特殊要求**：用户关注的特定分析重点

### 阶段2：信息搜集

按照优先级进行多源信息搜集：

**优先级1（权威官方）**：
- 政府类官方数据（统计局、海关、证监会等）
- 国家级产业政策文件
- 上市公司正式公告和年报

**优先级2（专业机构）**：
- 机构撰写的行业研报（中金、招商、国泰君安等）
- 金融数据端信息（Wind、ifind、Choice等）
- 专业咨询机构报告（艾瑞、前瞻、BCG等）

**优先级3（企业信息）**：
- 上市企业的定期报告/公告
- 招股说明书、增发募集书
- 企业官方网站和投资者关系材料

**优先级4（新闻媒体）**：
- 权威财经媒体（财新、21世纪、经济观察等）
- 行业专业媒体和公众号
- 公开新闻资讯

### 阶段3：信息整合与交叉验证

**数据交叉验证原则**：
- 关键数据需从2个以上独立来源验证
- 存在冲突时，优先采信权威来源数据
- 无法验证的数据需明确标注
- 区分事实陈述与合理推测

**信息分类处理**：
- 可量化数据：精确数值、百分比、增长率
- 定性分析：趋势判断、竞争格局描述
- 专家观点：需标注来源和置信度
- 预测估算：需标注方法和假设条件

### 阶段4：报告撰写

按照分析框架输出结构化报告：

**报告核心章节**：
1. **行业摘要**：一句话概括行业核心特征及投资吸引力
2. **行业现状**：生命周期阶段、市场规模、竞争格局、主要参与者
3. **行业展望**：未来3-5年发展趋势、关键驱动因素、市场预测
4. **投资机会与风险**：行业层面的机会和风险点
5. **对标的公司的启示**（如适用）：对具体公司的战略和估值影响
6. **结论**：明确行业投资价值，建议重点关注方向

**撰写要点**：
- 用数据图表支撑观点
- 交叉验证输入资料的一致性
- 突出独到见解，而非简单罗列数据
- 保持客观中立，给出明确投资判断
- 说人话，避免过度专业化术语堆砌

### 阶段5：可视化呈现

**图表生成**：
- 市场趋势图（柱状图/折线图）
- 产业链结构图
- 竞争格局图（饼图/堆叠图）
- 可比公司对比图
- 五力分析雷达图
- 企业发展时间线

**图表规范**：
- 中文字体优先使用：Microsoft YaHei、SimHei
- 颜色主题：专业商务风格
- 数据标注清晰，避免歧义

### 阶段6：多格式输出

根据用户需求，输出以下格式：
- **Markdown格式**：适合纯文本阅读和进一步编辑
- **Word格式（.docx）**：适合打印和正式交付
- **PDF格式（.pdf）**：适合分享和存档

## 数据来源标注

报告末尾必须包含完整的数据来源列表，格式如下：

```
[编号] 来源名称 - 可靠性评级 - 数据描述
    URL: 实际链接
```

**可靠性评级标准**：
- Tier 1：政府官方数据、国际组织报告
- Tier 2：权威金融机构研报、专业咨询机构
- Tier 3：上市公司公告、行业媒体
- Tier 4：一般媒体报道、公开资讯

## 质量门槛

报告必须满足以下质量标准：

1. **信息来源可追溯**：所有关键数据均有来源标注
2. **数据交叉验证**：关键数据经过多源验证
3. **逻辑推理清晰**：结论有数据支撑
4. **客观中立表述**：避免夸大或误导性陈述
5. **格式规范统一**：符合专业研究报告标准

## 注意事项

1. **分析深度适配**：根据用户提供的资料完整度调整分析深度
2. **数据时效性**：优先使用近12个月内的数据
3. **客观呈现**：即使结论可能与用户预期不符，也应如实呈现
4. **风险提示**：明确标注数据的局限性和分析的假设条件
