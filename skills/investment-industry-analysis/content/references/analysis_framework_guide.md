# 行业分析框架参考指南

本参考文档详细说明了行业分析框架的每个模块及其使用方法。

## 模块详解

### 一、行业界定与分类

**目的**：明确分析的行业边界和细分领域

**分析要点**：
- 行业定义：根据国家标准或市场惯例明确归属
- 细分领域：按产品类型、技术路线、应用场景、客户层级等划分
- 产业链位置：明确在上游/中游/下游的位置

**产出**：
- 行业定义描述
- 细分市场清单
- 产业链结构图

### 二、宏观环境分析（PEST）

**目的**：评估外部宏观因素对行业的影响

| 维度 | 分析内容 | 数据来源 |
|------|---------|---------|
| 政治(Policy) | 产业政策、税收优惠、进出口管制 | 国务院、发改委、商务部 |
| 经济(Economy) | GDP增速、利率汇率、居民收入 | 统计局、央行 |
| 社会(Society) | 人口结构、消费习惯、健康意识 | 统计局、民政部 |
| 技术(Technology) | 技术革新速度、研发投入、专利布局 | 专利局、科技部 |

**注意**：可根据具体行业选择性侧重，如半导体行业重点分析政策与技术。

### 三、行业发展阶段与生命周期

**阶段特征**：

| 阶段 | 技术成熟度 | 销量增速 | 竞争焦点 | 战略目标 |
|------|-----------|---------|---------|---------|
| 导入期 | 低 | 缓慢 | 产品研发 | 技术突破 |
| 成长期 | 提高 | 快速增长 | 市场开拓 | 扩大份额 |
| 成熟期 | 高 | 稳定 | 成本控制 | 维持利润 |
| 衰退期 | 下降 | 负增长 | 收缩退出 | 资产回收 |

**趋势展望维度**：
- 技术趋势：新一代技术渗透、产品迭代方向
- 政策趋势：未来法规、补贴退坡、标准升级
- 需求趋势：下游变化、消费升级/降级、新兴场景
- 供给趋势：产能扩张/出清、全球化重构
- 宏观驱动：人口、经济、社会文化影响

### 四、市场分析与规模测算

**市场规模分析**：
- 全球/中国整体市场规模（历史3-5年、当前、未来3-5年预测）
- 细分领域市场规模

**市场结构分析**：
- 区域分布
- 客户类型分布
- 产品档次分布
- 市场集中度（CRn、赫芬达尔指数）

**增长驱动因素**（需量化）：
- 渗透率提升空间
- 替代需求规模
- 政策强制要求
- 下游应用扩张
- 技术突破带来的新场景

**潜在空间测算**：
```
理论天花板 = 目标客户总数 × 单价 × 理论渗透率
```

### 五、行业结构分析（五力模型）

**五力详解**：

1. **上游议价能力**
   - 供应商集中度
   - 原材料稀缺性
   - 价格波动传导机制

2. **下游议价能力**
   - 客户集中度
   - 价格敏感度
   - 转换成本
   - 后向整合可能性

3. **潜在进入者威胁**
   - 行业门槛（技术/资本/渠道/资质）
   - 新进入者来源及实力
   - 实现盈利周期

4. **业内竞争程度**
   - 竞争对手数量及实力
   - 产品同质化程度
   - 价格战频率
   - 市场退出壁垒

5. **替代品威胁**
   - 功能替代可能性
   - 技术替代可能性
   - 替代品性价比

**综合评估**：
- 行业当前盈利水平
- 未来竞争演变趋势
- 标的公司在博弈中的相对地位

### 六、战略群组分析

**划分维度**：
- 产品价格带（高端/中端/低端）
- 地域覆盖广度（全球/区域/本土）
- 客户类型（高端/大众）
- 技术路线（不同技术派系）

**分析框架**：
- 识别直接对手（同群组企业）
- 分析移动壁垒（跨群组难度）
- 评估机会与威胁

### 七、关键成功因素（KSF）

| 因素类别 | 分析内容 |
|---------|---------|
| 技术能力 | 核心技术、专利壁垒、研发迭代速度 |
| 成本控制 | 规模效应、供应链管理、生产工艺优化 |
| 品牌渠道 | 品牌认知度、渠道覆盖密度、客户粘性 |
| 资源禀赋 | 稀缺资源获取、政府关系、特许经营权 |
| 组织能力 | 管理团队、激励机制、人才储备 |

**与标的对照**：
- 分析标的在各KSF上的表现
- 识别差距和改进空间

### 八、行业风险分析

| 风险类型 | 主要内容 | 分析要点 |
|---------|---------|---------|
| 宏观风险 | 经济周期、贸易摩擦、汇率波动 | 关联度分析 |
| 政策风险 | 监管收紧、优惠取消、标准提高 | 政策敏感性 |
| 技术风险 | 技术颠覆、研发失败、专利诉讼 | 技术路线评估 |
| 竞争风险 | 价格战、跨界进入、行业整合 | 竞争强度 |
| 供应链风险 | 断供、物流中断、成本飙升 | 供应链弹性 |
| 替代风险 | 跨行业替代、商业模式颠覆 | 替代可能性 |

### 九、行业盈利性与投资价值

**盈利水平指标**：
- 毛利率
- 净利率
- ROE（净资产收益率）

**资本回报指标**：
- ROIC（投资资本回报率）
- 投资回收期

**投资吸引力评估**：

| 机会因素 | 威胁因素 |
|---------|---------|
| 高增长 | 红海竞争 |
| 低渗透 | 替代临近 |
| 政策红利 | 成本上升 |
| 技术突破 | 需求萎缩 |

**行业吸引力评分**（可选）：
综合市场规模、增速、盈利性、竞争格局等维度打分。

### 十、对拟投资标的的关联分析

| 分析维度 | 分析内容 |
|---------|---------|
| 定位匹配 | 标的在细分领域的卡位与KSF的契合度 |
| 竞争优势 | 相对行业平均的差异化优势 |
| 风险传导 | 行业风险对标的经营的具体影响路径 |
| 成长空间 | 行业增长红利中标的能获取的份额及逻辑 |

## 数据来源优先级

| 优先级 | 来源类型 | 可靠性 | 说明 |
|-------|---------|--------|------|
| 1 | 政府官方数据 | 高 | 统计局、海关、证监会等 |
| 2 | 权威机构研报 | 高 | 中金、国泰君安等 |
| 3 | 金融数据端 | 中高 | Wind、ifind、Choice |
| 4 | 上市公司公告 | 高 | 年报、招股书 |
| 5 | 专业媒体 | 中 | 财新、21世纪经济报道 |
| 6 | 企业官网 | 中低 | 需交叉验证 |

## 报告撰写规范

### 结构要求

1. **行业摘要**：一句话概括核心特征和投资吸引力
2. **行业现状**：生命周期、市场规模、竞争格局、主要参与者
3. **行业展望**：3-5年趋势、驱动因素、市场预测
4. **投资机会与风险**：行业层面机会和风险点
5. **对标的公司的启示**：对战略、财务及估值的影响
6. **结论**：投资价值判断，建议关注方向

### 撰写要点

- 用数据图表支撑观点
- 交叉验证信息一致性
- 突出独到见解
- 保持客观中立
- 说人话，避免过度术语

### 数据标注

所有数据必须标注：
- 来源名称
- 数据时间
- 可靠性评级
- 获取URL（如有）
