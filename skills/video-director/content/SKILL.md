# 视频导演 (Video Director)

智能视频制作导演，将复杂视频脚本分解为可执行的专业任务，协调多agent协作完成端到端视频制作。

## 核心能力

- **剧本解析**：自动识别脚本中的人物设定、场景描写、镜头语言、视觉提示、声音提示
- **任务分解**：将视频制作分解为美术、剪辑、配乐、合成等独立任务
- **多agent协调**：并行调度专业agent，确保视觉风格一致性
- **质量把控**：在关键节点进行质量检查，确保最终输出精美

## 工作流程

### 第一步：剧本结构解析

接收用户脚本后，系统自动识别以下核心元素：

| 元素类型 | 提取内容 | 示例 |
|---------|---------|------|
| 人物设定卡 | 角色外貌、服装、道具、一致性提示 | 商鞅：冷峻威严、鹰钩鼻、法尺 |
| 分镜时间轴 | 画面描述、时间码、特效建议 | 00:00-00:12 刑场特写 |
| 视觉提示 | 色调、构图、动画风格 | 画面色调转为血红 |
| 声音提示 | 音效类型、音乐氛围 | 慢镜头血液飞溅 |
| 转场设计 | 过渡动画、叠化效果 | 文字裂变特效 |

### 第二步：任务分解与agent分配

根据解析结果，自动生成以下专业任务：

```
graph TD
    A[剧本解析] --> B[人物资产生成]
    A --> C[场景背景生成]
    A --> D[分镜画面生成]
    A --> E[配乐音效设计]
    B --> F[剪辑合成]
    C --> F
    D --> F
    E --> F
    F --> G[最终视频输出]
```

| 任务类型 | 负责agent | 核心输入 |
|---------|----------|---------|
| 人物资产 | art-director | 人物设定卡、一致性要求 |
| 场景背景 | art-director | 场景描写、时代背景 |
| 分镜画面 | image-gen | 时间轴脚本、视觉提示 |
| 动态效果 | video-gen | 分镜、视觉提示 |
| 配乐音效 | audio-director | 声音提示、情感节奏 |
| 剪辑合成 | editor | 所有素材、时间轴 |
| 字幕包装 | subtitle-gen | 旁白字幕、特效文字 |

### 第三步：多agent并行执行

**阶段1：美术资产生成（并行）**
- 生成所有人物设定形象
- 生成场景背景素材
- 生成特效元素

**阶段2：分镜画面生成（并行）**
- 按时间轴生成各镜头画面
- 生成转场特效素材
- 生成字幕包装元素

**阶段3：音视频合成**
- 生成配乐和音效
- 合成动态视频
- 添加字幕和特效

### 第四步：质量把控节点

| 检查点 | 检查内容 | 通过标准 |
|-------|---------|---------|
| 人物一致性 | 同一角色在不同镜头的形象 | 面部特征、服装、道具一致 |
| 色调统一 | 全片色彩风格 | 符合预设色调指引 |
| 叙事连贯 | 画面衔接流畅 | 时间轴逻辑清晰 |
| 音画同步 | 声音与画面配合 | 节奏匹配、无延迟 |
| 格式规范 | 输出规格 | 符合目标平台要求 |

## 触发条件

此skill在以下情况自动激活：

1. **直接触发**：用户提到"导演"、"视频制作"、"视频生成"
2. **脚本上传**：用户上传包含以下内容的文档：
   - 人物设定/角色卡
   - 分集/分镜脚本
   - 画面描述与时间轴
   - 视觉/声音提示
3. **任务类型**：涉及image-gen、video-gen、audio-gen的复合任务

## 输出标准

最终交付物包含：

- **视频文件**：mp4格式，分辨率1080P+
- **素材包**：分镜图片、配乐、音效
- **制作报告**：任务分解与执行记录
