# 视频脚本解析模板

本模板用于系统化解析用户提供的视频脚本，自动提取制作所需的关键元素。

---

## 一、人物设定卡解析

### 识别模式

```
身份/关系：[角色身份和关系描述]
出现集数：[出现的集数]
外貌识别点：[面部特征、体型、眼神等]
穿戴/服饰：[服装、冠饰、佩饰等]
打扮/仪态：[发型、胡须、姿态等]
一致性提示：[保持一致的关键要素]
```

### 提取字段

| 字段名 | 类型 | 描述 | 示例 |
|-------|------|------|------|
| role_name | string | 角色名称 | 商鞅 |
| role_type | enum | 角色类型 | monarch/minister/general/civilian |
| appearance | object | 外貌特征 | {face, eyes, body, features} |
| costume | object | 服饰配置 | {main, accessory, color} |
| props | string[] | 标志性道具 | [法尺, 竹简] |
| consistency | string | 一致性要求 | 冷峻威严的法律化身形象 |
| episodes | number[] | 出现集数 | [2, 3] |
| mood | string | 角色气质 | 冷酷决绝 |

### 解析示例

```json
{
  "role_name": "商鞅",
  "role_type": "minister",
  "appearance": {
    "face": "瘦高身形，面容冷峻，鹰钩鼻",
    "eyes": "眼神锐利如刀",
    "body": "身形瘦高"
  },
  "costume": {
    "main": "深色法家深衣（黑/深灰）",
    "accessory": "法尺（象征度量与法律）",
    "color": "黑色/深灰"
  },
  "props": ["法尺", "竹简", "法冠（獬豸冠）"],
  "consistency": "必须保持冷峻威严的法律化身形象",
  "episodes": [2],
  "mood": "冷酷决绝"
}
```

## 二、分镜时间轴解析

### 识别模式

```
时间码：[开始时间-结束时间]
画面描述：[场景、人物、动作、构图]
旁白/字幕：[配音台词、字幕文字]
特效/转场建议：[视觉效果、转场动画]
```

### 提取字段

| 字段名 | 类型 | 描述 | 示例 |
|-------|------|------|------|
| time_start | string | 开始时间码 | 00:00:00 |
| time_end | string | 结束时间码 | 00:00:12 |
| duration | number | 镜头时长(秒) | 12 |
| scene_type | enum | 场景类型 | dialogue/action/exposition |
| visual_elements | object | 视觉元素 | {characters, setting, composition} |
| narration | string | 旁白内容 | 太子犯法，师傅受刑 |
| subtitle | string | 字幕文字 | 法不阿贵 |
| effects | string[] | 特效列表 | [慢镜头, 血液飞溅] |
| transition | object | 转场设计 | {type, animation} |

### 解析示例

```json
{
  "time_start": "00:00:00",
  "time_end": "00:00:12",
  "duration": 12,
  "scene_type": "action",
  "visual_elements": {
    "characters": ["商鞅", "公子虔"],
    "setting": "刑场",
    "composition": "特写"
  },
  "narration": "太子犯法，师傅受刑。",
  "subtitle": "法不阿贵",
  "effects": ["慢镜头", "血液飞溅", "镜头震动"],
  "transition": {
    "type": "fade_in",
    "animation": "法牌特写"
  }
}
```

## 三、视觉提示解析

### 色调指引

| 色调类型 | 情绪/氛围 | 适用场景 | 示例 |
|---------|-----------|---------|------|
| 血红 | 紧张、残酷 | 刑场、战争 | 画面色调转为血红 |
| 玄黑 | 庄严、威严 | 王权、帝王 | 色调玄黑 |
| 昏黄 | 苍凉、历史 | 西陲荒原 | 色调昏黄苍凉 |
| 冷青 | 悬疑、神秘 | 密室、阴影 | 色调转为冷峻的青色 |
| 金色 | 辉煌、胜利 | 加冕、统一 | 金色色调 |

### 构图风格

| 构图类型 | 视觉效果 | 使用场景 |
|---------|---------|---------|
| 俯视拉远 | 史诗感、宏大 | 系列开场 |
| 仰视 | 威严、压迫 | 君王镜头 |
| 特写 | 强调、紧张 | 关键道具、表情 |
| 分屏对比 | 冲突、对立 | 变革前后对比 |
| 剪影 | 神秘、暗示 | 暗示性场景 |

### 动画风格

| 动画类型 | 效果 | 示例 |
|---------|------|------|
| 地图动画 | 领土变化、战略 | 地图推进动画 |
| 速度线 | 动感、冲击 | 冲锋、战斗 |
| 粒子特效 | 氛围、情绪 | 风雪、火花 |
| 裂纹特效 | 破裂、变革 | 规则重写 |

## 八、质量检查清单

### 人物一致性检查

- [ ] 同一角色在不同集的外貌一致
- [ ] 服装配色保持统一
- [ ] 标志性道具始终出现
- [ ] 角色气质符合设定

### 视觉统一检查

- [ ] 全片色调风格一致
- [ ] 构图风格符合场景类型
- [ ] 特效风格统一
- [ ] 转场自然流畅

### 音画配合检查

- [ ] 音乐情绪与画面匹配
- [ ] 音效与动作同步
- [ ] 节奏与剪辑速度一致
- [ ] 旁白与画面内容对应

### 技术规范检查

- [ ] 分辨率达到目标规格
- [ ] 帧率稳定
- [ ] 音视频同步
- [ ] 字幕位置正确
