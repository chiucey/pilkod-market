# 写作助手

将任何输入源转化为符合主流社交平台算法的二创作品的专业技能。

## 核心工作流

### 第一阶段：情报解析

**输入拆解维度：**
- 热点要素提取（话题热度、情感共鸣点、传播势能）
- PRD核心诉求识别（品牌调性、目标人群、转化目标）
- 竞品内容审计（差异化空间识别）

**情报输出模板：**
```
热点DNA：[情绪标签] + [话题切角] + [可延展场景]
内容定位：[差异化切角] vs [竞品占位]
平台适配：[平台算法偏好] → [内容形态建议]
```

### 第二阶段：平台差异化策略

#### 抖音策略
- **算法逻辑**：完播率 → 互动率 → 转粉率
- **内容公式**：[前置钩子3秒] + [反转/爆点] + [行动号召]
- **视觉特征**：竖屏9:16、快节奏剪辑、信息密度高
- **文案要点**：强钩子标题（疑问/数字/冲突）+ 热词埋设

#### 小红书策略
- **算法逻辑**：收藏率 → 评论率 → 分享率
- **内容公式**：[利他价值] + [个人体验] + [实用干货]
- **视觉特征**：3:4竖图、封面字体突出、精致感
- **文案要点**：真实感第一人称、标签体系完善、情感共鸣句

#### 视频号策略
- **算法逻辑**：好友互动 → 朋友圈裂变 → 推荐流量
- **内容公式**：[情感共鸣] + [社交货币] + [价值输出]
- **视觉特征**：横竖兼容、更接近电视语言
- **文案要点**：朋友圈分享属性强、话题性标题

### 第三阶段：内容资产输出

**生产级交付物清单：**

| 交付物 | 抖音版 | 小红书版 | 视频号版 |
|--------|--------|----------|----------|
| 标题/封面文案 | ✅ | ✅ | ✅ |
| 脚本/正文 | ✅ | ✅ | ✅ |
| 分镜建议 | ✅ | - | ✅ |
| 标签方案 | ✅ | ✅ | ✅ |
| 发布时间建议 | ✅ | ✅ | ✅ |
| 互动话术库 | ✅ | ✅ | ✅ |

### 第四阶段：合规性检查

**必检项：**
1. 平台违禁词过滤
2. 版权风险提示（配乐/素材来源）
3. 医疗/金融/食品等行业特殊规定
4. 绝对化用语排查

## 质量标准

**就绪定义：**
- 每个平台至少产出1套可直接使用的完整内容方案
- 标题通过"3秒测试"（扫读即被吸引）
- 正文包含至少3个平台算法鼓励的互动触发点
- 提供至少3个备选标题供选择

## 快速执行模式

对于简单需求（单平台单条内容）：
1. 输入 → 提取热点DNA
2. 选择平台模板
3. 输出可直接发布的终稿

对于复杂需求（多平台多内容矩阵）：
1. 输入 → 情报解析报告
2. 制定差异化策略矩阵
3. 按平台批量输出内容资产包
