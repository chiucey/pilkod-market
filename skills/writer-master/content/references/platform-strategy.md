# 平台策略参考文档

## 抖音内容公式库

### 高转化脚本模板

#### 模板A：问题解决型
```
[0-3秒] 开场钩子："你是不是也...？"
[3-8秒] 痛点放大："99%的人都踩过这个坑"
[8-20秒] 解决方案：具体步骤演示
[20-25秒] 反转/彩蛋："但是..."
[25-30秒] 行动号召："关注我，每天分享..."
```

#### 模板B：成果展示型
```
[0-3秒] 成果冲击："看这个对比"
[3-10秒] 过程揭秘：快速展示方法
[10-20秒] 细节放大：关键点讲解
[20-25秒] 情绪升华："真的改变了我..."
[25-30秒] CTA："想学的扣1"
```

### 爆款标题公式
- 数字型："5个技巧，让你..."
- 疑问型："为什么你总是...？"
- 对比型："从XX到XX，我只用了..."
- 悬念型："最后一个绝了..."
- 冲突型："月薪3000和30000的区别"

### 抖音违禁词清单
- 最强、第一、顶级、绝对
- 永久、彻底治愈
- 暗示高收益/稳赚
- 未经授权的品牌对比

## 小红书内容公式库

### 爆款笔记模板

#### 模板A：PLOG（图片日记型）
```
[封面] 高颜值封面 + 吸引眼球的文字叠加
[标题] 情绪词 + 数字 + 关键词
[正文结构]
1. 开场：情境代入（"我终于..."）
2. 主体：干货输出（分段、有层次）
3. 结尾：互动引导（"你们觉得呢？"）
[标签] 3-5个热门标签 + 1-2个精准标签
```

#### 模板B：干货教程型
```
[封面] Before/After对比 or 成果展示
[标题] 受众定位 + 解决方案 + 效果承诺
[正文结构]
1. 问题背景
2. 方法论/步骤（图文并茂）
3. 常见误区
4. 真实体验总结
[互动] 评论区置顶互动问题
```

### 小红书爆款标题公式
- "救命！这个也太..."
- "姐妹们，真的绝了！"
- "手把手教你..."
- "坦白局 | ..."
- "被问800遍的..."

### 小红书敏感词/话题
- 医疗效果夸大
- 金融投资暗示收益
- 绝对化功效承诺
- 未经证实的测评对比

## 视频号内容公式库

### 朋友圈裂变型内容

#### 模板A：情感共鸣型
```
[开头] 情境设置（"你有没有遇到过..."）
[发展] 故事推进（代入感强）
[高潮] 情感爆发点
[结尾] 金句收尾（适合截图分享）
```

#### 模板B：知识价值型
```
[开头] 抛出问题/误区
[主体] 系统性解答（电视讲座风格）
[结尾] 总结金句 + 关注引导
```

### 视频号标题特点
- 更长（15-20字）
- 话题感强
- 适合中老年群体理解
- 悬念+价值并重

### 视频号审核重点
- 外部链接限制
- 诱导关注/分享限制
- 医疗/金融内容严格审核
