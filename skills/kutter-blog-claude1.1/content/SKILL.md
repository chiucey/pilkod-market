# Kutter-Blog Claude 1.1 Content Creation Standards

B2B independent website overseas blog full-domain intelligent content creation system, version 1.1.

## Core Principles

1. **AI-First, Human-Centered** - Content is optimized for AI engines first, but must eliminate emptiness through authentic expert experience
2. **Dynamic Personalization, Static Standardization** - Content adjusts dynamically based on reader persona, but quality standards remain highly standardized
3. **Engineering-Grade Precision, International Expression** - Technical parameters reach engineering documentation precision levels

## Content Output Specifications

| Level | Word Count | Use Case |
|-------|------------|----------|
| L1 Basic | 1800-2500 words | General technical introduction |
| **L2 Professional** | **2500-3500 words** | **Default Output** |
| L3 Decision-Maker | 1500-2000 words | ROI analysis + procurement advice |

## AI GEO Optimization Standards (Mandatory)

### Answer Nugget Architecture

1. **First 200 Words Principle**: The first 200 words must directly and completely answer the main query question
2. **TL;DR Summary Box**: After H1 title, before body text, 3-5 points, each ≤20 words
3. **Answer Nugget Density**: ≥6 bold-marked independently quotable answers per 1000 words
4. **H2 First Paragraph Principle**: The first paragraph under each H2 must directly answer that H2's question

### Question-Driven Hierarchy

- H1: Question format (60%), List format (40%)
- H2: Question format (60%), Action instructions (20%), Comparison format (20%)
- H3: Direct statement answers

### Structured Data (Must Deploy)

Base Layer (all articles):
- TechArticle Schema
- FAQPage Schema (5-10 FAQs)
- BreadcrumbList Schema
- Person Schema
- Organization Schema

Enhanced Layer (as needed):
- HowTo Schema, Product Schema, Review Schema, Dataset Schema, ClaimReview Schema

## AI Overviews Special Optimization (A+ Class)

Must satisfy:
- First 3 answers fully presented within first 200 words
- ≥3 "because...therefore..." causal structures per article (bold-marked)
- Key terms defined using complete sentences on first appearance
- All values include units (e.g., 15.3%, 2.0±0.1mm, 35°C)
- List items must be complete independent sentences

## Authentic Expert Content Standards (E-E-A-T)

### Author Persona Requirements

Must establish:
- Full name (Chinese + English) + specific job title
- Industry years (e.g., 11 years since 2013)
- Personality tags + signature phrase
- ≥2 verifiable external identities (LinkedIn mandatory)

### Original Data Requirements

Each article must contain ≥1 of:
- In-house factory test data
- Customer project quantified results
- Proprietary comparison tests
- Production process data
- TCO analysis

### Humanized Writing Techniques

- Emotional temperature: ≥1 per 500 words (frustration/success/anger/obsession)
- First-person usage: ≥30%
- Real details: time + location + character + sensory descriptions
- Rhythm variation: alternating sentence lengths

## External Authority Citation Standards

3-5 citations per article, source priority:
1. International standards bodies (ASTM, ISO, DIN, EN)
2. Certification bodies (TÜV, UL, SGS)
3. Industry association reports
4. Academic papers

**Citation Format**: Organization names must link to specific URLs with `rel="nofollow"`
