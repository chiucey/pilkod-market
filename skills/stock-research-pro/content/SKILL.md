## 工作流程

### 触发方式

```
用户："分析一下我的持仓"
用户："诊断持仓"
用户："帮我看看现在仓位怎么样"
用户："换仓有什么建议"
用户："分析示例股票A"
用户："600176估值怎么样"
```

### 持仓诊断模式执行步骤

**Step 1：获取持仓信息**

优先从用户输入获取持仓明细，格式：
```
股票名 | 代码 | 持股数 | 成本价
```

若用户未提供持仓信息，使用技能内置示例持仓数据演示（不包含任何真实用户数据）。

**Step 2：批量获取实时行情**

```bash
python3 scripts/stock_research.py --portfolio
```

内部调用腾讯API批量接口：
`http://qt.gtimg.cn/q={code1},{code2},...`

**Step 3：计算持仓指标**

对每只持仓计算：
- 浮动盈亏 = (现价 - 成本价) × 持股数
- 盈亏率 = (现价 - 成本价) / 成本价 × 100%
- 当日盈亏 = (现价 - 昨收) × 持股数
- 仓位占比 = 市值 / 总市值 × 100%

**Step 4：四维风险评估**

| 维度 | 权重 | 评估内容 |
|------|------|---------|
| 集中度风险 | 25分 | 单只股票仓位占比是否过高 |
| 波动性风险 | 25分 | 持仓整体振幅（反映稳定性）|
| 流动性风险 | 25分 | 成交活跃度 |
| 趋势风险 | 25分 | 整体浮盈/浮亏方向 |

**Step 5：（可选）同步飞书Bitable**

当用户提供飞书Bitable URL时，执行以下MCP操作：
1. `feishu_bitable_get_meta` → 解析 app_token / table_id
2. `feishu_bitable_list_fields` → 确认字段名
3. `feishu_bitable_list_records` → 获取 record_id 列表
4. `feishu_bitable_update_record` → 批量更新"当前价(元)"、"盈亏额(元)"、"盈亏率(%)"

**Step 6：输出诊断报告**

```
【一、持仓概览】总市值/总成本/浮盈亏/当日盈亏/仓位
【二、个股明细】每只股票的市价/盈亏/占比
【三、四维风险评估】综合评级 + 四维条形图
【四、操作建议】综合仓位管理 + 每只股票具体建议
【五、研究声明】
```

### 个股研究模式执行步骤

**Step 1：解析股票代码**

**Step 2：获取实时行情 + 生成报告**

```bash
python3 scripts/stock_research.py 600176 sh
```

## 四维风险评级标准

| 综合分 | 风险等级 | 说明 |
|--------|---------|------|
| 85-100分 | 🟢 低风险 | 分散配置，趋势向上 |
| 65-84分 | 🟡 中低风险 | 稳健持有 |
| 45-64分 | 🟡 中风险 | 控制仓位，高位考虑减仓 |
| 25-44分 | 🟠 中高风险 | 降仓为主，减少暴露 |
| 0-24分 | 🔴 高风险 | 清仓或止损 |

### 操作建议规则

| 情况 | 建议 |
|------|------|
| 浮盈≥30% | ⚠️ 分批止盈，先出一半 |
| 浮盈≥15% + 今日涨≥2% | 🟢 可加仓 |
| 浮亏≥-10% | 🔴 建议止损 |
| 浮亏≥-3% + 今日反弹 | 🟢 逢低可小仓补入摊低成本 |
| 其他 | ✅ 继续持有 |

## 飞书同步说明

当用户说"同步飞书"、"更新持仓表格"时：

**Step 1：解析URL**
```
https://my.feishu.cn/base/xxx?table=yyy
```
提取 app_token 和 table_id。

**Step 2：获取记录**
- `feishu_bitable_list_records` → 获取所有 record_id

**Step 3：计算并更新**
- 计算盈亏额、盈亏率
- `feishu_bitable_update_record` 更新以下字段：
  - `当前价(元)`
  - `盈亏额(元)`
  - `盈亏率(%)`

**注意**：更新时不包含任何硬编码用户数据，record_id 从飞书实时获取。

## 数据来源与限制

- **实时行情**：腾讯财经 `qt.gtimg.cn`（3-5秒延迟）
- **财务数据**：估算值（静态参考表），建议用 akshare 补充
- **港股/美股**：当前版本仅支持A股
- **字数**：诊断报告建议300-800字，个股研报500-1500字
