# stock-research-pro · A股个股深度研究技能

> 🎯 **核心卖点：持仓诊断 + 个股深度研究**，一键生成专业投研报告

---

## 功能概览

| 功能 | 说明 |
|------|------|
| 📊 **实时行情** | 腾讯财经API，毫秒级响应，支持批量多股 |
| 📈 **四维估值评分** | PE/PB/ROE/趋势，0-100分量化评级 |
| 🎯 **操作建议区间** | 支撑位 / 合理建仓区间 / 压力位 |
| 📋 **持仓诊断模式** | 批量分析持仓，计算浮盈亏、四维风险评估 |
| 📲 **飞书同步** | 可选：自动更新飞书Bitable持仓记录 |
| 🖥️ **结构化研报** | 标准投研格式，可直接使用 |

## 快速开始

### 触发词

```
分析股票 / 研究一下 / 帮我看看 / 个股诊断 /
估值评分 / 投资研究 / 股票研报 / [代码]怎么样 /
分析我的持仓 / 帮我诊断持仓
```

### 输入格式

支持三种输入方式：

```
600176          ← 纯代码（自动识别市场）
000657          ← 同上
sh600519        ← 带市场前缀
```

**自动识别规则：**
- `6`、`9` 开头 → 上交所 `sh`
- `0`、`3` 开头 → 深交所 `sz`

### 示例对话

```
用户：分析一下贵州茅台
→ 自动识别 sh600519，生成完整研报

用户：帮我看看000858
→ 自动识别 sz000858，生成完整研报

用户：分析我的持仓
→ 进入持仓诊断模式，批量分析持仓股
```

## 持仓诊断模式

输入"分析我的持仓"时，脚本进入批量诊断模式，输出：

- **持仓概览**：总市值、总成本、浮动盈亏、当日盈亏、仓位比例
- **个股明细**：每只股票的市价/成本/盈亏/占比
- **四维风险评估**：集中度/波动性/流动性/趋势 各25分
- **操作建议**：每只股票具体操作（加仓/减仓/止损/持有）
- **飞书同步**：可选自动更新Bitable持仓表格

## 估值评分系统

评分维度（满分100分）：

| 维度 | 权重 | 优秀(满分) | 良好 | 一般 | 较差 | 差 |
|------|------|-----------|------|------|------|-----|
| PE估值 | 30分 | <10倍 | <20倍 | <30倍 | <50倍 | ≥50倍 |
| PB估值 | 20分 | <2倍 | <4倍 | <6倍 | <8倍 | ≥8倍 |
| ROE质量 | 25分 | ≥20% | ≥15% | ≥10% | ≥5% | <5% |
| 趋势动量 | 25分 | +10%+ | +5% | 平盘 | -5% | <-5% |

**综合评级：**
- 80+ 分：⭐⭐⭐⭐⭐ 极具投资价值
- 65-79 分：⭐⭐⭐⭐ 较好投资价值
- 50-64 分：⭐⭐⭐ 一般投资价值
- 35-49 分：⭐⭐ 投资价值偏低
- <35 分：⭐ 投资价值低

## 使用限制

- **A股专用**：不支持港股、美股
- **数据延迟**：腾讯财经约3-5秒延迟，盘中数据仅供参考
- **财务数据**：PE/ROE等指标为估算值，建议安装 akshare 获取精确数据
- **投资风险**：本报告仅供参考，不构成投资建议
