# 估值方法论详解

## 一、PE（市盈率）估值

### 公式
```
PE = 当前股价 / 每股收益(EPS)
```

### 参考标准（A股惯例）

| PE区间 | 解读 | 适用场景 |
|--------|------|---------|
| < 10倍 | 明显低估 | 传统行业龙头，稳定增长 |
| 10-20倍 | 合理偏低 | 大多数优质公司 |
| 20-30倍 | 合理偏高 | 成长型公司 |
| 30-50倍 | 偏高 | 热门成长股，预期高增长 |
| > 50倍 | 泡沫区间 | 投机性很强，风险大 |

### 注意事项
- PE<0（亏损）时PE指标失效，看PB更可靠
- 周期性行业（钢铁/煤炭/化工）PE失真，用PB更准
- 券商一致预期PE参考意义更大

---

## 二、PB（市净率）估值

### 公式
```
PB = 当前股价 / 每股净资产(BPS)
```

### 参考标准

| PB区间 | 解读 |
|--------|------|
| < 1倍 | 破净，价值重估机会 |
| 1-2倍 | 正常偏低 |
| 2-4倍 | 合理区间 |
| 4-6倍 | 偏高，成长预期强 |
| > 6倍 | 高溢价，行业龙头专享 |

### 适用场景
- **券商**强烈依赖PB（资产业重）
- **银行**用PB最准（资产透明）
- **周期股**用PB胜于PE

---

## 三、ROE（净资产收益率）

### 公式
```
ROE = 净利润 / 净资产 × 100%
```

### 杜邦拆解
```
ROE = 净利率 × 资产周转率 × 权益乘数
```

### 评价标准

| ROE区间 | 评价 |
|---------|------|
| ≥ 20% | 优秀，龙头标志 |
| 15-20% | 良好，优质公司 |
| 10-15% | 中等，健康水平 |
| 5-10% | 较弱，竞争加剧 |
| < 5% | 差，需改善 |

---

## 四、PS（市销率）

### 公式
```
PS = 总市值 / 营业收入
```

适用于收入稳定但利润波动大的成长期公司（尤其是互联网/软件）。

---

## 五、综合评分模型（stock-research-pro 采用）

```
总分 = PE得分(30) + PB得分(20) + ROE得分(25) + 趋势得分(25)
```

### 为什么这样设计？

- **PE(30)**：最通用的估值指标，直接反映市场预期
- **PB(20)**：补充PE失真场景（周期股、亏损股）
- **ROE(25)**：衡量公司真实盈利能力，护城河的核心体现
- **趋势(25)**：动量因子，A股情绪驱动明显，趋势强则短期胜率更高

---

## 六、PEG估值（成长性）

```
PEG = PE / (年度净利润增速 × 100)
```

| PEG区间 | 解读 |
|---------|------|
| < 0.8 | 潜在低估，增长被低估 |
| 0.8-1.2 | 合理，成长与估值匹配 |
| > 1.2 | 偏高，增长预期已部分price-in |
| > 2 | 明显高估 |

---

## 七、实战注意事项

1. **多指标交叉验证**：PE/PB/ROE三者方向一致时信号最强
2. **行业对比**：必须和同业比，跨行业比较无意义
3. **历史分位**：当前估值处于历史哪个分位？<20%分位=低估
4. **机构预期**：券商一致预测EPS是动态的，比静态PE更有价值
5. **周期调整**：强周期行业用席勒PE（剔除通胀）更准
