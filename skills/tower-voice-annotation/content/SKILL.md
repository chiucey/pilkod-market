# 塔台语音标注助手

## 技能介绍

本技能用于整理和标注塔台语音转写内容，将原始语音文本转换为符合规范的Excel标注数据。

## 核心功能

1. **数字转换**：将小写汉字数字转换为阿拉伯数字并加括号标注
2. **航班号标准化**：统一航空公司名称和四位数字格式
3. **术语规范化**：统一民航专业术语
4. **Excel输出**：生成符合标注规范的表格数据

---

## 十二、常见问题处理

- **渤海(Bohai) vs 白海**：需结合语境判断
- **脱波(动词) vs 通播(名词)**
- **请抄 vs 启程**（启程非民航词汇）
- **进近 vs 渐近/渐进**（只能使用"进近"）
- **"自0起飞"可能是误听**：正确应为"四洞(40)起飞"

## 使用方法

当用户提供语音转写文本时，按照以下步骤处理：

1. 读取原始文本内容
2. 识别并转换所有小写汉字数字为阿拉伯数字括号
3. 标准化航班号格式
4. 规范化术语表达
5. 根据对话内容判断role（管制员1/飞行员2）
6. 生成符合字段规范的Excel文件
