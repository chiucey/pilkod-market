# 股票市场代码参考

## A股市场

### 上交所（沪市）
- **代码格式**: 6位数字，通常以 `6`、`5`、`11` 开头
- **后缀**: `.SS`（Shanghai Stock Exchange）
- **示例**:
  - `600519.SS` - 贵州茅台
  - `600036.SS` - 招商银行
  - `601318.SS` - 中国平安
  - `600276.SS` - 恒瑞医药

### 深交所（深市）
- **代码格式**: 6位数字，通常以 `0`、`1`、`2`、`3` 开头
- **后缀**: `.SZ`（Shenzhen Stock Exchange）
- **示例**:
  - `000858.SZ` - 五粮液
  - `000333.SZ` - 美的集团
  - `300750.SZ` - 宁德时代
  - `002475.SZ` - 立讯精密

### 创业板
- **代码格式**: 6位数字，以 `3` 开头
- **后缀**: `.SZ`
- **示例**:
  - `300059.SZ` - 东方财富
  - `300015.SZ` - 爱尔眼科

### 科创板
- **代码格式**: 6位数字，以 `688` 开头
- **后缀**: `.SS`
- **示例**:
  - `688981.SS` - 中芯国际
  - `688111.SS` - 金山办公

## 港股市场

### 主板
- **代码格式**: 4-5位数字
- **后缀**: `.HK`
- **示例**:
  - `0700.HK` - 腾讯控股
  - `9988.HK` - 阿里巴巴

## 代码识别规则

### 自动识别逻辑
```
1. 如果是纯数字（6位）:
   - 6/5/11 开头 → A股沪市 (.SS)
   - 0/1/2/3 开头 → A股深市 (.SZ)
   - 3 开头且较短 → 创业板 (.SZ)

2. 如果包含 .HK → 港股

3. 如果是英文字母 → 美股

4. 默认 A股沪市处理无法识别的6位数字
```

### 输入转换示例
| 用户输入 | 识别结果 | 市场 |
|----------|----------|------|
| 贵州茅台 | 600519.SS | A股沪市 |
| 腾讯 | 0700.HK | 港股 |
| 苹果 | AAPL | 美股 |
| 阿里巴巴 | 9988.HK | 港股 |
| 特斯拉 | TSLA | 美股 |
