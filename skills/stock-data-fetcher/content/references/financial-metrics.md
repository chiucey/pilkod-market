# 财务指标参考指南

## 估值指标

### 市盈率 (P/E Ratio)
- **定义**: 股价与每股收益的比值
- **公式**: `P/E = 股价 / 每股收益(EPS)`
- **解读**:
  - PE 低 → 可能被低估
  - PE 高 → 成长预期高或被高估
- **注意**: 亏损公司无法计算PE

### 市净率 (P/B Ratio)
- **定义**: 股价与每股净资产的比值
- **公式**: `P/B = 股价 / 每股净资产`
- **解读**:
  - PB < 1 → 股价低于净资产
  - PB > 3 → 成长型公司
- **适用**: 金融、资产密集型行业

### 市销率 (P/S Ratio)
- **定义**: 股价与每股销售额的比值
- **公式**: `P/S = 市值 / 总营收`
- **适用**: 营收稳定但利润波动大的公司

## 盈利能力指标

### 毛利率 (Gross Margin)
- **定义**: 营收减去直接成本后的比例
- **公式**: `毛利率 = (营收 - 成本) / 营收 × 100%`
- **解读**:
  - 高毛利率 → 定价能力强或成本控制好
  - 科技公司通常毛利率较高

### 净利率 (Net Margin)
- **定义**: 净利润占营收的比例
- **公式**: `净利率 = 净利润 / 营收 × 100%`
- **解读**: 反映最终盈利能力

### 每股收益 (EPS)
- **定义**: 归属于每股的净利润
- **公式**: `EPS = 净利润 / 总股本`
- **用途**: 计算PE、成长率分析

### 净资产收益率 (ROE)
- **定义**: 股东权益的回报率
- **公式**: `ROE = 净利润 / 股东权益 × 100%`
- **解读**:
  - ROE > 15% → 优质公司
  - 持续高ROE → 竞争优势明显

### 资产回报率 (ROA)
- **定义**: 资产的回报率
- **公式**: `ROA = 净利润 / 总资产 × 100%`
- **解读**: 衡量资产使用效率

## 成长指标

### 营收增长率
- **定义**: 营收同比变化
- **公式**: `(本期营收 - 上期营收) / 上期营收 × 100%`

### 净利润增长率
- **定义**: 净利润同比变化
- **公式**: `(本期净利润 - 上期净利润) / 上期净利润 × 100%`

### EPS增长率
- **定义**: 每股收益同比变化
- **用途**: 评估盈利成长性

## 财务健康指标

### 资产负债率
- **定义**: 总负债占总资产的比例
- **公式**: `资产负债率 = 总负债 / 总资产 × 100%`
- **解读**:
  - < 50% → 财务稳健
  - > 70% → 负债较高

### 流动比率
- **定义**: 流动资产与流动负债的比值
- **公式**: `流动比率 = 流动资产 / 流动负债`
- **解读**: > 1.5 通常被认为是健康的

### 速动比率
- **定义**: 排除存货后的流动比率
- **公式**: `速动比率 = (流动资产 - 存货) / 流动负债`

## 分红指标

### 股息率
- **定义**: 年度分红与股价的比值
- **公式**: `股息率 = 年度每股分红 / 股价 × 100%`
- **用途**: 价值投资参考

### 分红比例 (Payout Ratio)
- **定义**: 分红占净利润的比例
- **公式**: `分红比例 = 每股分红 / EPS × 100%`
- **解读**:
  - 20-40% → 成长型公司
  - 50-70% → 成熟稳健型
  - > 80% → 关注分红可持续性

## 股票筛选参考

### 价值型股票特征
- PE < 15
- PB < 1.5
- 股息率 > 3%
- ROE > 15%

### 成长型股票特征
- 营收增长率 > 20%
- 净利润增长率 > 25%
- 毛利率 > 40%
- 研发投入高

### 蓝筹股特征
- 市值 > 1000亿
- PE 在 10-25 之间
- 连续多年分红
- 行业龙头地位
