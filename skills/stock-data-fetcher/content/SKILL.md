# 股票数据抓取技能

实时获取股票价格和财务数据，支持多市场查询。

## 触发条件

当用户请求以下类型的数据时激活：
- 查询股票实时价格或行情
- 获取财务报表数据（营收、利润、资产负债表）
- 分析财务指标（市盈率、市净率、ROE、毛利率等）
- 股票对比分析
- 历史价格数据查询

## 执行流程

### 1. 解析股票代码

**输入处理**：
- 中文股票名称 → 自动转换为股票代码
- 支持格式：
  - A股：`600519`（上证）、`000858`（深证）
  - 港股：`0700.HK`、`9988.HK`
  - 美股：`AAPL`、`TSLA`

**代码识别规则**：
- 6位数字 → A股（上证以6/5/11开头，深证以0/1/2/3开头）
- 以.HK结尾 → 港股
- 英文字母组合 → 美股

### 2. 数据抓取

根据用户需求，使用以下工具组合：

**股价数据**：
```python
使用 stocks_price 工具
参数：symbol, start_date, end_date, interval="1d"
```

**股票基本信息**：
```python
使用 stocks_info 工具
参数：symbol
```

**财务数据**：
```python
使用 stocks_financial_data 工具
参数：symbol
```

**股票统计指标**：
```python
使用 stocks_statistics 工具
参数：symbol
```

**市场新闻**：
```python
使用 stocks_news 工具
参数：symbol, snippet_count
```

### 3. 数据格式化

**股价数据格式**：
```
股票代码: [SYMBOL]
股票名称: [NAME]
当前价格: [PRICE] [CURRENCY]
涨跌幅: [CHANGE%]
最高价: [HIGH]
最低价: [LOW]
成交量: [VOLUME]
市值: [MARKET_CAP]
```

**财务数据格式**：
```
=== 财务概览 ===
营收(TTM): [REVENUE]
净利润(TTM): [NET_INCOME]
毛利率: [GROSS_MARGIN]%
ROE: [ROE]%
每股收益(EPS): [EPS]
市盈率(PE): [PE_RATIO]
市净率(PB): [PB_RATIO]
```

### 4. 市场支持

| 市场 | 代码格式 | 示例 | 工具前缀 |
|------|----------|------|----------|
| A股-上证 | 6位数字 | 600519 | - |
| A股-深证 | 6位数字 | 000858 | - |
| 港股 | XXXX.HK | 0700.HK | - |
| 美股 | 英文代码 | AAPL | - |

## 输出要求

1. **数据时效性**：明确标注数据获取时间
2. **数据完整性**：提供完整的财务指标
3. **格式清晰**：使用表格或结构化格式
4. **数据来源**：标注数据来源

## 错误处理

- **无效股票代码**：返回"未找到该股票，请检查代码是否正确"
- **API调用失败**：尝试备用数据源或返回友好错误
- **市场不支持**：说明支持的市场类型
