# 序列帧生成器

## 技能定位

专为需要生成**连贯序列帧图片**的创作者设计。无论是动画制作、游戏开发、短视频分镜还是故事板创作，都能轻松应对。

## 核心能力

### 1. 智能序列生成
- 根据描述批量生成风格统一的连续帧
- 自动保持角色/场景一致性
- 支持多种宽高比和分辨率

### 2. 丰富的使用场景
| 场景 | 说明 |
|------|------|
| 动画制作 | 关键帧、中间帧、动作序列 |
| 游戏开发 | 角色动作、场景过渡、特效序列 |
| 故事板/分镜 | 短视频创作、影视分镜、漫画草图 |
| GIF素材 | 动态表情、循环动画、微动效 |
| 插画序列 | 连环画、教程图解、步骤演示 |

### 3. 输出格式支持
- 单张图片（PNG/JPG/WebP）
- ZIP打包（批量下载）
- 编号命名（frame_001, frame_002...）

## 使用指南

### 基础用法

直接描述你想要的序列帧：

```
生成一段角色行走的序列帧，10帧，动作连贯
```

```
创建3个不同表情的角色特写序列：开心、惊讶、愤怒
```

### 进阶用法

指定更详细的参数：

| 参数 | 说明 | 示例 |
|------|------|------|
| 数量 | 生成帧数 | 8帧、12帧、24帧 |
| 风格 | 美术风格 | 写实、卡通、水墨、像素 |
| 动作 | 运动描述 | 跳跃、转身、跑步、飞行 |
| 视角 | 镜头角度 | 正脸、侧脸、特写、全景 |

### 组合示例

```
生成一个角色从站立到跳跃的12帧动画序列，卡通风格，白底透明背景
```

```
创建5个连续的城市夜景画面，赛博朋克风格，展示从黄昏到夜晚的时间变化
```

## 工作流程

1. **接收需求** - 理解用户的序列帧描述
2. **参数解析** - 提取帧数、风格、动作等关键信息
3. **智能拆分** - 将复杂序列分解为可生成的独立帧
4. **批量生成** - 使用图像生成工具创建每一帧
5. **质量检查** - 确保帧间连贯性和风格一致性
6. **整理输出** - 编号排序，提供下载

## 输出交付

生成的序列帧将包含：
- 所有帧图片（按编号命名）
- 可选的ZIP压缩包
- 建议的帧率/播放速度提示

## 适用人群

- **动画师**：快速生成关键帧和动作测试
- **游戏开发者**：制作角色动画和特效素材
- **内容创作者**：制作分镜和故事板
- **自媒体博主**：生成短视频素材和GIF动图
- **设计师**：创作连环画和插画序列
- **教师/讲师**：制作教程图解和步骤演示

## 温馨提示

- 帧数越多，单次生成时间越长
- 复杂动作建议分段生成以保证质量
- 如需高度一致的序列，可先生成参考图
- 支持指定输出尺寸以适配不同平台
