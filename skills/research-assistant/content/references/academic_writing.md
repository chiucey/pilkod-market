# 学术写作规范与技巧

## 1. 标题撰写规范

### 基本要求
- **简洁性**：中文标题不超过20个字，英文标题不超过12个词
- **准确性**：准确反映研究内容，避免夸大或缩小
- **特异性**：使用具体术语而非泛泛之词
- **可检索性**：包含关键词，便于文献检索

### 标题结构
```
[研究方法] + [研究对象] + [研究问题/结论]
```

---

## 2. 摘要撰写规范

### 结构要素（300字左右）
1. **研究背景**（1-2句）：研究领域现状与存在的问题
2. **研究目的**（1句）：本研究的核心目标
3. **研究方法**（1-2句）：采用的主要方法或技术
4. **主要发现**（2-3句）：最具创新性的研究结果
5. **研究意义**（1句）：理论和实践价值

### 避免事项
- ❌ 不使用"本文研究了..."、"本文探讨了..."等套话
- ❌ 不引用参考文献
- ❌ 不使用缩写或简称（除非是公认术语）
- ❌ 不使用主观评价词汇（如"首次"、"填补空白"等）

---

## 3. 关键词选取

### 原则
- **数量**：3-8个关键词
- **选择**：优先使用专业术语和主题词
- **覆盖**：涵盖研究对象、方法、理论、领域
- **规范**：参考《汉语主题词表》或学科专业词表

### 常见错误
- 使用过于宽泛的词汇（如"研究"、"分析"）
- 使用过于具体的口语词汇
- 中英文关键词不对应

---

## 4. 引言撰写规范

### 经典结构（Funnel Structure）
```
宽泛背景 → 领域现状 → 研究空白 → 研究价值 → 本文贡献
```

### 各部分内容
1. **研究背景**（1-2段）：领域重要性、研究趋势
2. **文献综述**（2-3段）：
   - 经典研究
   - 近期进展
   - 研究流派
3. **研究空白**（1段）：现有研究的不足
4. **研究目的与意义**（1段）：本文要解决的问题
5. **本文结构**（可选）：各部分安排

### 常见错误
- 文献堆砌，缺乏批判性分析
- 与文献综述重复
- 夸大研究意义

---

## 5. 方法论描述

### 必备要素
1. **研究设计**：实验/调查/案例研究的类型
2. **样本/数据**：来源、数量、选择标准
3. **材料/工具**：设备、仪器、软件、量表
4. **程序/步骤**：操作流程、时间顺序
5. **分析方法**：统计方法、软件、参数设置

### 写作技巧
- 使用过去时态
- 提供足够细节供重复验证
- 明确控制变量
- 引用已建立的方法

---

## 6. 结果呈现

### 图表规范
| 类型 | 适用场景 |
|------|----------|
| 表格 | 精确数据、分类比较 |
| 柱状图 | 离散变量比较 |
| 折线图 | 趋势变化 |
| 散点图 | 相关关系 |
| 流程图 | 方法步骤 |
| 技术图 | 结构原理 |

### 文字描述
- 先描述主要发现
- 再描述次要发现
- 引用图表时注明编号
- 客观描述，不做解释

---

## 7. 讨论撰写

### 标准结构
```
1. 核心发现总结（1段）
2. 与已有研究对比（2-3段）
3. 理论贡献（1段）
4. 实践意义（1段）
5. 研究局限（1段）
6. 未来方向（1段）
```

### 批判性思维
- 承认研究的局限性
- 讨论结果的不确定性
- 提出替代解释
- 避免过度推论

---

## 8. 常用学术表达

### 表示"认为/相信"
- 本文认为...
- 本研究支持...
- 证据表明...

### 表示"发现/结果显示"
- 研究发现...
- 结果显示...
- 数据表明...

### 表示"对比/差异"
- 与...相比...
- 显著高于/低于...
- 无显著差异

### 表示"因果"
- 导致...
- 产生影响...
- 证实了...的关系
