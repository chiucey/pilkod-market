# 文献引用格式规范参考

## 1. GB/T 7714-2015（国标）

### 专著
```
[序号] 主要责任者. 题名: 其他题名信息[M]. 其他责任者. 版本项. 出版地: 出版者, 出版年.
```
示例：
```
[1] 刘国钧, 郑昌陶, 江乃武. 图书馆目录[M]. 北京: 高等教育出版社, 1957.
```

### 期刊文章
```
[序号] 主要责任者. 题名[J]. 刊名, 出版年, 卷(期): 起止页码.
```
示例：
```
[2] 何龄修. 读顾城《南明史》[J]. 中国史研究, 1998(3): 167-173.
```

### 学位论文
```
[序号] 主要责任者. 题名[D]. 出版地: 出版者, 出版年.
```
示例：
```
[3] 张筑生. 微分半动力系统的不变集[D]. 北京: 北京大学数学系数学研究所, 1983.
```

## 2. APA格式（第7版）

### 期刊文章
```
Author, A. A., & Author, B. B. (Year). Title of article. Title of Periodical, volume number(issue number), page numbers. https://doi.org/xxxxx
```
示例：
```
Smith, J. A., & Jones, M. B. (2019). The effects of climate change on biodiversity. Nature, 543(7647), 123-130. https://doi.org/10.1038/s41586-019-1234-5
```

### 书籍
```
Author, A. A. (Year). Title of work: Capital letter also for subtitle. Publisher.
```
示例：
```
Brown, L. S. (2018). Critical thinking skills: Developing effective analysis and argument (2nd ed.). Routledge.
```

## 3. MLA格式（第9版）

### 期刊文章
```
Author Last Name, First Name. "Article Title." Journal Name, vol. #, no. #, Year, pp. #-#.
```
示例：
```
Garcia, Maria. "Digital Humanities and Modern Libraries." Library Quarterly, vol. 89, no. 2, 2019, pp. 112-128.
```

### 书籍
```
Author Last Name, First Name. Title of Book. Publisher, Year.
```
示例：
```
Foucault, Michel. Discipline and Punish: The Birth of the Prison. Vintage Books, 1977.
```

## 4. 常见错误与规避

| 错误类型 | 正确做法 |
|---------|---------|
| 缺少DOI | 优先添加DOI，无DOI则提供URL |
| 作者姓名颠倒 | 外文名：名-姓；中文名：姓-名 |
| 刊名缩写错误 | 使用标准缩写，不可自创 |
| 年份错误 | 核对原文，确保与出版年份一致 |
| 页码遗漏 | 期刊必须标注起止页码 |
| 格式不一致 | 同一文献类型保持统一格式 |
