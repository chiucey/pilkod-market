# 论文复现技能使用指南

## 快速开始

### 触发技能

当您需要理解或复现一篇论文时，可以这样开始对话：

```
请帮我复现这篇论文：https://arxiv.org/abs/2301.12345
```

或：

```
我想要理解这篇论文的核心创新点：[论文链接或上传PDF]
```

## 输入格式

技能支持以下输入格式：

| 类型 | 示例 | 处理方式 |
|------|------|----------|
| arXiv链接 | `https://arxiv.org/abs/2301.12345` | 自动提取并下载PDF |
| PDF链接 | `https://arxiv.org/pdf/2301.12345.pdf` | 直接下载并解析 |
| 本地PDF | `/workspace/papers/paper.pdf` | 读取本地文件 |
| DOI | `10.1145/3442188.3445922` | 解析并获取论文 |

## 输出内容

技能将返回完整的论文分析报告，包括：

### 1. 基本信息
- 论文标题、作者、发表 venue
- 论文链接和发布日期

### 2. 核心创新点
- 主要贡献的清晰描述
- 技术细节和实现机制
- 与现有方法的对比优势

### 3. 方法论详解
- 算法架构和流程图
- 核心数学公式
- 实现细节和注意事项

### 4. 代码复现
- **有开源代码**：详细的代码学习笔记和关键部分解读
- **无开源代码**：基于论文实现的完整可运行代码

## 使用技巧

### 获取更详细的分析
```
请详细分析这篇论文，包括：
1. 所有创新点的具体技术细节
2. 实验设置的完整描述
3. 代码实现的核心逻辑
```

### 获取特定部分
```
请重点解释这篇论文中的[具体部分，如：注意力机制]
```

### 获取对比分析
```
这篇论文相比[其他论文]有什么改进？
```

## 常见问题

### Q: 支持中文论文吗？
A: 支持，但部分PDF提取可能存在中文OCR限制。

### Q: 代码可以用什么语言？
A: 优先使用论文官方实现的语言，其次为Python。

### Q: 生成的代码可以直接运行吗？
A: 是的，核心算法代码可直接运行，非核心部分（如数据加载）可能需要适配。

### Q: 如何验证代码正确性？
A: 可对比论文中的示例输出，或运行提供的测试用例。

## 最佳实践

1. **提供完整链接** - 包含完整URL以便自动获取PDF
2. **明确分析重点** - 说明需要重点关注的部分
3. **验证实现结果** - 使用论文提供的示例数据进行验证
4. **记录疑问点** - 对不明确的地方标注以便后续研究

## 注意事项

- 部分付费论文可能无法获取完整内容
- 复杂数学公式可能需要人工确认
- 代码实现为复现性质，使用时请注明来源
