# Pre-Writing Checklist

## Before Starting Any Task

### 1. Outline Confirmation
- [ ] User has provided complete outline
- [ ] Outline is locked and saved
- [ ] Target section is identified
- [ ] Context from previous sections is noted

### 2. Glossary Verification
- [ ] Glossary provided by user OR
- [ ] Will generate after first writing segment
- [ ] All key terms identified
- [ ] Abbreviations defined

### 3. Reference Check
- [ ] Required references identified
- [ ] All sources verified in English databases only:
  - [ ] Web of Science
  - [ ] Scopus
  - [ ] PubMed
  - [ ] Google Scholar
- [ ] NO Chinese databases used
- [ ] DOIs confirmed

### 4. Style Confirmation
- [ ] Default style confirmed with user OR
- [ ] Custom style requirements noted
- [ ] Citation format selected:
  - [ ] APA 7th (default)
  - [ ] MLA
  - [ ] Chicago
  - [ ] Harvard
  - [ ] IEEE
  - [ ] Other: ________

### 5. Writing Constraints
- [ ] Word count target known
- [ ] Target journal (if any)
- [ ] Deadline noted
- [ ] Any special requirements noted

# Post-Writing Checklist

## Before Delivering Content

### 1. Outline Compliance
- [ ] Content matches target section
- [ ] All required subsections included
- [ ] Logical flow maintained
- [ ] Connects to previous sections

### 2. Style Compliance
- [ ] Formal academic tone
- [ ] Passive voice dominant
- [ ] No first-person pronouns
- [ ] No prohibited AI phrases
- [ ] Sentences ≤30 words
- [ ] No 3+ level nested clauses
- [ ] Topic sentences present

### 3. Glossary Compliance
- [ ] All terms match glossary
- [ ] New terms added to glossary
- [ ] Abbreviations properly introduced
- [ ] Consistent terminology throughout

### 4. Citation Compliance
- [ ] All sources in English databases
- [ ] Proper APA 7th format
- [ ] DOIs included
- [ ] Reference list accurate

### 5. Quality Check
- [ ] Clear argumentation
- [ ] Evidence supports claims
- [ ] Logical transitions
- [ ] No redundancy
- [ ] Grammar and spelling correct
