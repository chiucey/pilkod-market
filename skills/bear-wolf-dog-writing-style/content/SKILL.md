# 熊狼狗写作风格蒸馏

本技能基于网络小说《没钱修什么仙》全文分析，蒸馏作者熊狼狗的写作风格与创作技法。

## 核心风格特征

### 1. 赛博修仙世界观融合
**核心公式**: 传统修仙 + 现代科技 + 社会批判 = 赛博修仙

**特征元素**:
- **羽书系统**: 类似游戏面板的属性展示界面，显示"法力"、"道心"、"肉体强度"等数值
- **灵根经济**: 灵根可租可买，天灵根价格6000万，映射现实中的房产经济
- **仙道技术产业链**: 功法、丹药、法器形成完整商业生态
- **科技修仙融合**: 霓虹广告、修仙贷、互联网金融等现代元素

**创作要点**:
```
世界观设定公式:
[传统修仙要素] + [现代科技/商业元素] = 新奇感
例: "绝育手术防早恋" + "修仙" = 荒诞讽刺
     "灵根租赁" + "分期付款" = 消费主义批判
```

### 2. 社会现实讽刺
**映射层次**:
- **教育内卷**: 学生每天只睡两小时，绝育保持专注，映射衡水模式
- **借贷陷阱**: 70万巨债、利滚利、催债电话，映射校园贷
- **职场剥削**: 荒牛镇魂心诀(牛马心法)、996工作制
- **贫富分化**: 昆墟分层，有钱人在上层享受，穷人在底层挣扎

**讽刺手法**:
- 用正常语气描述荒谬设定（冷幽默）
- 将现实问题通过修仙世界的"合理规则"呈现
- 对话中角色用理所当然的态度讨论残酷规则

### 3. 反套路主角塑造
**主角张羽特征**:
- **穿越者**: 带着上一世记忆穿越到修仙世界
- **背负债务**: 原身欠债70万，利滚利
- **被迫内卷**: 仪式力量(诅咒)逼迫他不断修炼
- **"够颠"**: 不按常理出牌，敢挑战权威

**反套路清单**:
```
传统主角 → 反套路版本
天才少年 → 借贷狗伪装的天才
神兵利器 → 租来的天灵根
师傅庇护 → 被学生会压迫
正派宗门 → 法务部比宗门更牛
```

### 4. 黑色幽默表达
**典型案例**:
- "一人跳楼，全家赔钱"（月考横幅）
- "我们学校虽是女校，但不歧视男性，只要你完成性别转换手术"
- "绝育是为了专心修行"
- "跳楼要赔钱"（救人后还要赔偿）

**幽默公式**:
```
[残酷现实] + [轻描淡写语气] + [荒诞逻辑自洽] = 黑色幽默
```

### 5. 游戏化系统设定
**羽书(属性面板)特征**:
- 技能分级显示经验值: "健体三十六式3级(6/30)"
- 可切换专精
- 等级提升触发技能/属性突破
- 数值精确到小数点后一位

**升级系统**:
```
升级收益:
1级 → 解锁基础技能
3级 → 引动法力辅助
5级 → 获得特殊效果
10级 → 质的飞跃 + 隐藏收益
```

### 6. 叙事节奏把控
**章节结构**:
- 每章聚焦一个核心冲突/事件
- 章内包含: 事件发展 → 转折 → 主角应对 → 新的伏笔
- 结尾留悬念或反转

**节奏类型**:
| 类型 | 特征 | 案例 |
|------|------|------|
| 升级爽文 | 快速提升、数值膨胀 | 一夜练成10级心法 |
| 社会批判 | 压抑、讽刺 | 学生会被打压 |
| 搞笑日常 | 黑色幽默 | 白真真的吐槽 |
| 紧张战斗 | 压迫感 | 法赛、实战考试 |

## 创作框架

### 赛博修仙世界观构建清单
```
□ 基础设定
  - 修仙与科技融合方式
  - 社会阶层划分依据(学分/法力/财富)
  - 宗门与企业关系

□ 经济系统
  - 灵根/功法/丹药价格体系
  - 借贷与分期机制
  - 穷人与富人资源差距

□ 教育体系
  - 修仙学习的残酷规则
  - 考试与竞争机制
  - 学校与社会的关系

□ 讽刺映射
  - 现实问题的修仙化改编
  - 荒诞设定背后的真实逻辑
```

### 主角塑造模板
```
姓名: 张羽型主角
□ 身份背景
  - 穿越者/重生者
  - 原身有债务/困境
  - 有明确的目标(考大学/还债/往上爬)

□ 核心特质
  - "够颠": 不按套路出牌
  - 被迫努力(系统/仪式/债务)
  - 有底线有原则

□ 人物关系
  - 一个挚友(白真真型)
  - 一个敌人/压迫者(学生会型)
  - 若干工具人/反派

□ 成长轨迹
  - 前期: 被压迫、求生存
  - 中期: 反击、获取资源
  - 后期: 挑战规则/上位
```

### 章节结构模板
```
【章节模板】
1. 开头钩子 (场景/事件/冲突)
2. 事件发展 (主角行动)
3. 遭遇困难/反转
4. 主角应对 (发挥主观能动性)
5. 获得收益/新的困境
6. 结尾悬念

【爽点节奏】
- 每3-5章安排一次升级/爽点
- 重要考试/竞赛作为阶段性高潮
- 反派打压 → 主角反击 → 打脸爽文
```

## 典型场景模板

### 场景1: 讽刺设定展示
```
场景: 面试/招生
目的: 展示修仙世界的残酷规则
结构:
1. 正常流程开始
2. 揭露荒谬规则(绝育/变性/卖身)
3. 角色用理所当然态度讨论
4. 主角内心吐槽/无奈接受
```

### 场景2: 升级爽点
```
结构:
1. 修炼积累 (经验值接近满)
2. 突破瞬间 (感官描写)
3. 能力提升 (具体数值变化)
4. 周围人反应 (惊讶/嫉妒)
5. 主角低调/装逼
```

### 场景3: 社会讽刺
```
公式:
[现代问题] → [修仙世界对应物]
校园贷 → 修仙贷/灵根分期
996 → 荒牛镇魂心诀
学区房 → 昆墟分层

表达方式:
- 用角色对话自然带出
- 用"正常"语气描述荒谬
- 对比穷富角色处境
```

### 场景4: 黑色幽默时刻
```
公式:
[严肃/残酷场景] + [荒诞细节] = 黑色幽默

案例:
- 跳楼救人后要求赔偿场地费
- 法赛上死人被视为"意外事故"
- 学生会施压后说"为你好"

写作要点:
- 保持冷静叙事语气
- 让角色用正常态度讨论
- 在笑声中揭示残酷
```

## 文风特征

### 语气语调
- **总体**: 轻松幽默，但有深度
- **叙事**: 冷静客观，偶有主角内心吐槽
- **对话**: 生活化，贴合角色身份
- **解说**: 简洁带过，不拖沓

### 文字风格
```markdown
【优点学习】
- 描述精准具体 (数值、细节)
- 节奏明快不拖沓
- 对话自然流畅
- 信息密度高

【避免问题】
- 不要过度解释设定
- 不要长篇大论心理描写
- 不要重复相似场景
```

### 人物对话特征
```
穷学生语气:
- 自嘲、无奈、带点丧
- "这破地方"、"TMD"
- 抱怨但不失希望

富学生语气:
- 理所当然的优越感
- 轻描淡写谈论剥削
- "你们穷人"类表述

工具人反派:
- 执行规则，不问对错
- 用官方话术回应质疑
- "公司规定"、"合同条款"
```

## 创作检查清单

### 开篇检查
- [ ] 有没有明确的冲突/困境
- [ ] 主角有没有明确的目标
- [ ] 世界观设定是否新奇且自洽
- [ ] 是否有讽刺现实的元素

### 章节检查
- [ ] 是否有明确的核心事件
- [ ] 节奏是否明快
- [ ] 有没有爽点/反转
- [ ] 结尾是否留悬念

### 人物检查
- [ ] 主角是否"够颠"
- [ ] 配角是否有辨识度
- [ ] 反派是否可恶但真实
- [ ] 人物关系是否清晰

### 世界观检查
- [ ] 规则是否自洽
- [ ] 是否有社会讽刺元素
- [ ] 游戏化系统是否有趣
- [ ] 经济/阶层设定是否合理
