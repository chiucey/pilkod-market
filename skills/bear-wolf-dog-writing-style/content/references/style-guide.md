|------|----------|----------|

| 民用级儿童飞剑 | 2000-8000元 | 电子产品 |

### 1.2 社会阶层
```
昆墟结构:
├── 地上36层 (上层=高社会阶层)
│   ├── 空气清新
│   ├── 摩天大楼
│   └── 精英阶层
└── 地下18层 (下层=底层人民)
    ├── 污水横流
    ├── 破旧公寓
    └── 贫民窟

学校鄙视链:
重点高中学生 → 普通高中学生 → 职校学生
  (高种姓)     (正常人)      (低种姓)
```

### 1.3 教育体系残酷规则
```
睡眠剥夺:
- 优秀毕业生: 不睡觉
- 普通学生: 每天2小时睡眠
- 主角张羽: 5小时(被认为不努力)

绝育手术:
- 学校要求: 入学前完成绝育
- 理由: "防止早恋，专心修行"
- 延伸: 调节激素水平提高学习效率

借贷体系:
- 平台借贷: 无门槛，利率高
- 贷款逾期: 暴力催收
- 父母兜底: 卖房卖器官
```

## 二、经典场景拆解

### 2.1 面试场景(第1章)

**目的**: 展示修仙世界的残酷门槛

**结构**:
```
1. 正常流程开始(面试)
2. 揭露荒谬规则
3. 用"正常"语气讨论
4. 主角被拒绝(表面原因)
5. 暗示真实原因(穷)
```

**原文摘录**:
> "本校为了提升学习效率，防止早恋，要求所有学生在入学前要完成把相关器官摘除的绝育手术，从此专心修行。"

**讽刺点**: 用科学/健康理由包装对穷人的剥削

### 2.2 试药场景(第11章)

**目的**: 展示底层人的生存困境

**结构**:
```
1. 高薪诱惑(1万元/次)
2. 隐藏风险揭露(合同条款)
3. 主角被迫接受
4. 实际危险(法力失控/内伤)
5. 资本家冷酷态度
```

**原文摘录**:
> "只要你们练成这门功法完成试验，我们就会按完成度给你们酬劳。"
> "我们这次要测试的东西，还有与113相匹配的辅助运功设备……"

**讽刺点**: 合法外衣下的剥削

### 2.3 法赛场景(第49章)

**目的**: 主角逆袭爽点

**结构**:
```
1. 竞赛开始(高压力)
2. 遭遇强敌(三大名校)
3. 绝境/危机
4. 突破(领悟新技能)
5. 逆袭成功
6. 打脸/装逼
```

**原文摘录**:
> "第四名，嵩阳高中，张羽，总分273"

**爽点设计**:
- 穷学生逆袭富二代
- 打破名校垄断
- 引起各方关注

## 三、人物塑造模式

### 3.1 主角张羽模板

**身份公式**:
```
穿越者 + 原身困境 + 明确目标 + 被迫努力 = 张羽型主角
```

**性格特征**:
| 特征 | 表现 | 效果 |
|------|------|------|
| 自嘲 | "这破地方" | 接地气 |
| 不屈 | "打死我也不签" | 有骨气 |
| 务实 | "形势逼人强" | 识时务 |
| 义气 | "能不能多带一个人" | 有朋友 |
| 吐槽 | "TMD" | 有趣 |

**口头禅/习惯**:
- "靠"
- "这破……"
- "难道是……"
- 内心疯狂吐槽
- 表面冷静接受

### 3.2 白真真模板(挚友)

**定位**: 主角的朋友，同为穷人，有自己的困境

**特征**:
- 同为借贷狗
- 性格直爽，敢骂敢言
- 偶尔靠谱
- 关键时刻挺兄弟

**对话风格**:
```
"畜生啊！张羽你这个畜生！快给我停下！"
"一群虫豸连食堂都搞不好"
"我白真真一生不弱于人！"
```

### 3.3 学生会模板(反派)

**定位**: 有钱人阶层代理，压迫者

**特征**:
- 以"双赢"包装剥削
- 用合同/规则合法化压迫
- 表面客气，实则傲慢
- 必要时撕破脸

**经典台词**:
```
"已经给他们开到我能开到的最好条件了吧？"
"这些穷鬼啊，你对他们太凶，他们心里怨你骂你"
"我已经足够给他们脸了吧？"
```

## 五、升级爽点节奏指南

### 5.1 升级触发模式
```
积累期 → 接近临界 → 突破瞬间 → 能力跃升 → 验证爽点
```

### 5.2 数值设计
```
基础属性:
- 法力: 0-100+ (持续增长)
- 道心: 1级起
- 肉体强度: 0.84级起

技能等级:
- 1级: 解锁
- 3级: 质变(法力辅助)
- 5级: 稳定输出
- 10级: 极限突破+隐藏效果

经验格式:
[技能名][等级](当前/升级需求)
例: 健体三十六式3级(6/30)
```

### 5.3 爽点类型
| 类型 | 触发条件 | 情绪效果 |
|------|----------|----------|
| 数值碾压 | 超过同学/对手 | 爽 |
| 逆袭打脸 | 以弱胜强 | 爽 |
| 装逼成功 | 低调装逼被打脸 | 爆爽 |
| 体系认可 | 获得资源/职位 | 爽 |
| 敌人服软 | 反派低头 | 最爽 |

### 5.4 节奏安排
```
【日常章】: 铺垫、发展
【冲突章】: 矛盾、升级
【爽点章】: 突破、碾压
【悬念章】: 反转、伏笔

典型节奏:
第1章: 困境展示
第2-3章: 第一次尝试
第4-5章: 失败/被打压
第6-7章: 转折/获得机遇
第8章: 爽点爆发
```

## 六、文风模仿要点

### 6.1 叙事节奏
```markdown
快节奏要素:
- 每段不超过3-4句
- 对话自然插入
- 心理描写简短
- 动作用短句

案例(原文节奏):
"张羽微微一愣。" (简短)
"这又是他所不知道的情报，本以为的优势转眼成了劣势。" (一个转折)
```

### 6.2 对话设计
```markdown
对话公式:
[角色定位] + [当前处境] + [性格特征] = 角色台词

穷学生:
- 口语化
- 带点自嘲
- 偶尔爆粗

富学生:
- 书面化
- 傲慢语气
- 冷漠自私

工具人:
- 公事公办
- 规则至上
- 推卸责任
```

### 6.3 内心OS模式
```markdown
主角内心吐槽公式:
[观察现象] + [内心吐槽] + [无奈接受]

案例:
"张羽原本不想理会，但在手机足足震动了一分多钟后，
他终于忍不住地将之拿了起来，却发现对方已经挂了电话。
'小贷广告吗？'" (先吐槽)
"'哼。' 张羽心想自己的面试资料恐怕是被哪个学校给卖了。" (解释)
"但放下手机片刻之后，他又拿了起来，重新点开了那条消息。" (无奈接受)
```

### 6.4 世界观展现场景
```markdown
展示公式:
[具体场景] + [规则揭露] + [角色反应] + [讽刺点]

案例(借贷):
"母亲：儿子，你不要担心，不论你选绝育还是变性，
手术的钱妈妈一定会帮你凑齐的。"
(母亲关心→实为无奈)
```

## 八、实用写作模板
