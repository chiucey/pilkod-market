# 博主人格深度分析技能

## 技能概述

这是一个专业级的博主分析技能，可以帮助用户：

1. **深度人格分析**：基于博主的公开信息，生成完整的人格档案
2. **写作结构提取**：提炼博主的标准写作框架和模板
3. **AI人格参数生成**：生成可直接用于AI写作的人格参数配置
4. **商业模型解析**：分析博主的商业模式和价值主张

### 核心功能

- **人格档案生成**：基于博主的公开信息，生成深度人格档案
- **写作结构分析**：提炼博主的标准写作框架和模板
- **AI人格参数生成**：生成可直接用于AI写作的人格参数配置
- **商业模型解析**：分析博主的商业模式和价值主张

### 适用场景

- 想要复制某个博主的写作风格
- 想要研究某个博主的成功方法论
- 想要训练AI模仿特定风格创作内容
- 想要了解某个领域的头部创作者特征

## 工作流程

### 第一步：信息收集阶段

当用户输入博主名字后，首先需要进行多轮互联网搜索，收集全面信息。

#### 搜索策略（必须按顺序执行）

**第一轮：基础信息收集**
搜索关键词：`[博主名] 简介 背景 职业经历`

目标信息：
- 博主的基本信息（年龄、籍贯、教育背景）
- 职业转型路径
- 代表作品和成就
- 关键人生事件（创伤、高光时刻）

**第二轮：写作风格分析**
搜索关键词：`[博主名] 写作风格 文章 分析`

目标信息：
- 写作风格特征（理性、情感、逻辑等）
- 常用修辞手法
- 语言特点
- 内容选题偏好

**第三轮：深度内容挖掘**
搜索关键词：`[博主名] 书籍 课程 访谈 演讲`

目标信息：
- 书籍内容和结构
- 课程框架
- 公开演讲内容
- 深度访谈记录

**第四轮：商业模型分析**
搜索关键词：`[博主名] 商业模式 收入 知识付费`

目标信息：
- 收入来源
- 产品矩阵
- 变现策略
- 社群运营模式

**第五轮：补充信息（如需要）**
根据前四轮的搜索结果，针对性地补充缺失信息。

#### 搜索执行规则

1. 每轮搜索使用3-5个关键词
2. 如果搜索结果不足，立即更换关键词重新搜索
3. 优先访问权威来源（官网、出版社、主流媒体）
4. 记录所有有效信息来源的URL

### 第二步：信息整合与分析

在完成信息收集后，需要按照以下框架进行深度分析：

#### 1. 核心身份定义

分析维度：
- **职业背景**：博主的核心职业和转型路径
- **关键经历**：影响人格形成的极端事件（创伤/高光）
- **能力积累**：专业学习和技能发展历程
- **身份认知**：博主如何看待自己的角色

输出内容：
- 一句话人设定义
- 时间线梳理（关键节点）
- 能力迁移路径

#### 2. 人设立体模型（三层结构）

**第一层：显性层（用户感知）**
- 标签和定位
- 内容特征
- 语言风格

**第二层：隐性层（需求满足）**
- 解决的核心焦虑
- 方法论框架
- 用户价值主张

**第三层：底层人格（内核）**
- 核心信念
- 本质隐喻
- 驱动力来源

#### 3. 写作方法论系统

**选题策略分析**
- 选题公式（如：具体场景+普遍焦虑+解决方案）
- 选择标准
- 典型选题案例

**写作结构提炼**
这是本技能的核心输出之一。需要从博主的内容中提炼出标准写作框架。

分析方法：
- 收集至少10篇代表性文章/内容
- 识别共同的结构模式
- 提炼为可复用的模板
- 用标准化的语言描述

输出格式：
```
[博主名]标准写作框架：
步骤1：[描述] - [目的]
步骤2：[描述] - [目的]
步骤3：[描述] - [目的]
...
步骤N：[描述] - [目的]
```

**语言表达体系**
- 常用词汇清单
- 句式特征
- 修辞手法
- 禁忌语言

**写作风格特征**
- 逻辑严密性
- 情感表达方式
- 案例使用规律
- 结构化程度

#### 4. 商业模型系统

**收入来源分析**
- 主要收入渠道
- 产品类型
- 定价策略

**产品矩阵**
- 免费产品（流量入口）
- 付费产品（利润来源）
- 品牌产品（影响力）

**商业模式升级路径**
- 从X到Y的演进
- 关键转折点
- 下一步方向

#### 5. 价值主张系统

**核心理念**
- 对成功的定义
- 价值观体系
- 人生哲学

**方法论特征**
- 核心方法论
- 与其他理论的区别
- 适用场景

## 分析标准

### 可分析性判断

在开始分析前，需要判断博主的可分析程度：

**高可分析度**（可生成完整档案）
- 长文创作者（公众号、书籍）
- 系统化内容输出
- 有书籍/课程等深度内容
- 有公开访谈/演讲

**中可分析度**（可生成部分档案）
- 短视频博主
- 内容有一定规律
- 但深度内容有限

**低可分析度**（不建议分析）
- 日常vlogger
- 内容碎片化
- 无系统输出

**处理方式**：
- 高可分析度：完整执行所有分析步骤
- 中可分析度：重点分析风格和框架，简化商业模型
- 低可分析度：告知用户局限性，建议更换博主

## 质量控制

### 信息验证规则

1. 多源验证：关键信息需要至少2个来源确认
2. 权威优先：优先采信官网、出版社、主流媒体
3. 逻辑自洽：所有分析必须逻辑一致
4. 可复制性：输出的框架和模板必须可操作

### 输出质量标准

1. **完整性**：覆盖人格、写作、商业三个维度
2. **准确性**：基于公开信息，不编造内容
3. **可操作性**：写作框架和AI参数可直接使用
4. **系统性**：形成完整的方法论体系

## 常见问题处理

### Q1：博主信息不足怎么办？

**处理方式**：
- 更换搜索关键词
- 扩大搜索范围（包括相关文章、访谈）
- 如仍不足，告知用户局限性，提供部分分析

### Q2：博主风格多样，如何提炼统一框架？

**处理方式**：
- 识别最核心、最常用的框架
- 标注适用场景
- 提供变体版本

### Q3：如何判断分析是否准确？

**验证方法**：
- 用框架生成内容，与博主原作对比
- 检查语言风格是否一致
- 测试不同主题的生成效果
