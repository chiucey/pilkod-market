## 二、完播率设计技巧

### 时间节点设计
| 时长 | 爆点位置 | 设计要点 |
|------|----------|----------|
| 15秒 | 3秒 | 强钩子必须在前3秒 |
| 30秒 | 3秒、15秒、25秒 | 每15秒一个情绪爆点 |
| 60秒 | 3秒、15秒、30秒、45秒 | 每15秒信息增量 |
| 90秒 | 3秒、15秒、30秒、45秒、60秒、75秒 | 高密度信息输出 |

### 情绪节奏设计
```
[0-3秒] 强刺激 → [3-15秒] 建立期待 → [15-30秒] 信息释放 → [30-45秒] 情绪高潮 → [45-60秒] 价值沉淀 → [结尾] 互动引导
```

## 四、内容类型详解

### 口播文案结构
```
[开场] 黄金3秒钩子 - 引发好奇/共鸣
[主体] 痛点分析 - 精准戳中用户需求
[高潮] 解决方案 - 给出干货价值
[收尾] 金句升华 - 强化记忆点
[CTA] 互动引导 - 引导点赞关注评论
```

### 带货文案结构
```
[开场] 福利/痛点钩子 - 吸引停留
[痛点] 问题放大 - 共情需求
[产品] 卖点呈现 - 场景化展示
[信任] 背书加持 - 增强说服力
[逼单] 限时福利 - 促成转化
[行动] 明确指令 - 点击购买
```

### 探店文案结构
```
[开场] 猎奇/福利钩子 - 引发兴趣
[环境] 门店定位 - 位置/特色介绍
[产品] 招牌体验 - 沉浸式描述
[价格] 性价比 - 透明公开
[建议] 避坑提示 - 真诚分享
[引导] 同城打卡 - 引导到店
```

## 六、禁忌词汇与表达

### 抖音禁用词
- 绝对化词汇：第一、顶级、极致
- 医疗效果：治疗、治愈、根除
- 虚假承诺：100%有效、无效退款（夸大）
- 违规引导：加我微信、点击链接

### 小红书敏感词
- 过度营销：必买、无限回购
- 虚假宣传：最好用、最值得
- 违禁内容：医疗效果类需资质

### 广告法禁用
- 虚假数据：100%、90%
- 绝对用语：国家级、最高级
- 误导内容：混淆概念、夸大功效
