# 转化路径分析 Skill

## 适用场景
用户上传电商/广告投放的转化路径数据文件（CSV 或 Excel），系统按照预设的标准分析框架，自动完成数据处理与多维度分析，输出处理后的数据文件、Markdown 格式的分析表格、以及附带问题诊断与策略建议的分析报告。

## 数据文件规范

### 支持格式
- CSV
- Excel（.xlsx / .xls）

### 上传方式
用户在对话中直接上传文件，每次分析一个文件。

### 原始字段说明

| 字段名 | 数据类型 | 含义 |
|--------|----------|------|
| `转化路径` | 字符串 | 用户从进入到最后购买的完整转化路径，由逗号分隔的节点标签组成（如 "DVAI,DVAO,DVAI"） |
| `路径人数（用户）` | 数值 | 走过该转化路径的总用户数 |
| `购买人数（用户）` | 数值 | 在该路径上完成购买的用户数 |
| `新客购买人数（用户）` | 数值 | 在该路径上首次购买的新客户数 |
| `销售额` | 数值 | 该转化路径产生的总销售额 |
| `广告花费` | 数值 | 该转化路径对应的广告总花费 |

### 新增计算字段

| 字段名 | 计算方式 |
|--------|----------|
| `路径步数` | 转化路径中逗号分隔的节点数量 |
| `路径首位` | 转化路径的第一个节点 |
| `路径末位` | 转化路径的最后一个节点 |

## 指标计算公式

| 指标 | 公式 |
|------|------|
| **转化率** | 购买人数 / 路径人数 |
| **ROAS** | 销售额 / 广告花费 |
| **客单价** | 销售额 / 购买人数 |
| **新客比例** | 新客购买人数 / 购买人数 |

## 分析方向清单

### 一、可选分析板块

所有分析板块（1-8）均为**可选**，用户可根据需求自由组合选择。

#### 1. 整体数据概览
- 统计数据总行数
- 各字段汇总值（路径人数、购买人数、新客购买人数、销售额、广告花费）
- 汇总指标：整体转化率、整体ROAS、整体客单价、整体新客比例

#### 2. 路径步数分组分析
按路径步数分组，统计：
- 路径数量
- 路径人数（&占比）
- 广告花费（&占比）
- 销售额（&占比）
- 转化率、ROAS、客单价、新客比例

#### 3. 首位/末位分组分析

**前置条件**：仅统计步数 > 1 的组合路径

**按路径首位分组：**
- 路径数量
- 路径人数（&占比）
- 广告花费（&占比）
- 销售额（&占比）
- 转化率、ROAS、客单价、新客比例

**按路径末位分组：**
- 路径数量
- 路径人数（&占比）
- 广告花费（&占比）
- 销售额（&占比）
- 转化率、ROAS、客单价、新客比例

#### 4. 热门路径 TOP N
**前置条件**：仅统计步数 > 1 的组合路径

- 列出购买人数最高的前 N 条路径（TOP 10）
- 包含完整路径、路径步数、路径人数、购买人数、新客购买人数、销售额、广告花费、转化率、ROAS、客单价、新客比例

#### 5. 组合路径效率分析
**分析1：组合路径 vs 非组合路径对比**
- 定义：路径步数 > 1 为组合路径，路径步数 = 1 为非组合路径
- 分别统计组合路径与非组合路径的：
  - 路径人数（&占比）
  - 广告花费（&占比）
  - 销售额（&占比）
  - 转化率、ROAS、客单价、新客比例
- 对比两者效率差异

**分析2：步数=1 的非组合路径明细**
- 列举所有步数 = 1 的路径数据
- 包含完整路径、路径人数、购买人数、新客购买人数、销售额、广告花费、转化率、ROAS、客单价、新客比例
- 按购买人数降序排列

#### 6. 节点贡献分析
**需询问参数：** "请输入要分析的节点名称（如 DVAI、DVAO）"

**分析1：包含该节点的所有路径**
- 筛选包含指定节点的行
- 统计：路径人数（&占比）、广告花费（&占比）、销售额（&占比）、转化率、ROAS、客单价、新客比例

**分析2：包含该节点的组合路径**
- 在组合路径（步数 > 1）基础上，筛选包含指定节点的行
- 统计：路径人数（&占比）、广告花费（&占比）、销售额（&占比）、转化率、ROAS、客单价、新客比例

#### 7. 特定路径模式识别
**前置条件**：仅统计步数 > 1 的组合路径

**需询问参数：** "请输入路径模式条件，格式为「开头节点-结尾节点」（如 DVAI-DVAO，表示首位是DVAI且末位是DVAO的路径）"

- 筛选符合指定模式的组合路径
- 统计：路径数量、路径人数（&占比）、广告花费（&占比）、销售额（&占比）、转化率、ROAS、客单价、新客比例

#### 8. 辅助归因分析
**前置条件**：仅统计步数 > 1 的组合路径

**需询问参数：** "请输入要分析的节点名称"

**分析1：辅助触达统计**
- 定义：首触与末触均不是该节点，但路径中含该节点的路径
- 筛选符合条件的组合路径
- 统计：路径数量、路径人数（&占比）、广告花费（&占比）、销售额（&占比）、转化率、ROAS、客单价、新客比例

**分析2：三维对比**
- 将该节点作为**首触**、**末触**、**辅助触达**三种角色的数据进行横向对比
- 展示同一节点在不同触达位置时的效率差异
- 包含指标：路径数量、路径人数、广告花费、销售额、转化率、ROAS、客单价、新客比例

---

### 二、分析前询问（必须执行）

在执行任何分析前，**必须**询问用户以下问题：

1. **是否有特定条件下的数据筛选需求？**
   - 如：只分析某段时间的数据、排除某些特定路径等
   - 记录用户的筛选条件，如有补充则应用

2. **是否有业务特定的分析逻辑或特殊情况说明？**
   - 如：某次分析的背景说明、特殊参数定义等
   - 记录用户的补充说明，如有则一并纳入分析

**注意**：即使用户表示无补充，仍需确认"无补充"后继续执行。

## 输出格式规范

### 输出1：处理后的原文件（CSV）
- 在原始字段基础上，增加计算字段：`路径步数`、`路径首位`、`路径末位`
- 输出可下载的 CSV 文件

### 输出2：分析数据表格
- **对话中展示**：使用 Markdown 表格格式
- **可复制格式**：提供以 Tab 分隔的文本，便于复制到 Excel
- **可下载**：提供 CSV 格式下载

### 输出3：分析报告结构

**各模块报告结构**：

```
## [分析模块名称]

### 数据表格
[Markdown 表格]

### 问题诊断
[基于该模块数据分析识别的问题点，如转化率异常、某类路径效率低等]
```

**全盘策略建议**：
在所有模块分析完成后，输出综合性的策略建议：
```
## 全盘策略建议

### 问题总结
[汇总各模块发现的主要问题]

### 优化建议
[针对汇总问题的综合优化建议，按优先级排序]

### 注意事项
[执行建议时需关注的风险点或前提条件]
```

## 执行流程

1. **接收文件**：用户上传 CSV 或 Excel 文件
2. **数据处理**：
   - 读取文件
   - 解析「转化路径」字段，计算新增字段（路径步数、路径首位、路径末位）
   - 保存处理后的数据文件
3. **展示可选分析板块**：向用户展示所有可选分析板块（1-8），使用 `genui-checkbox-group` 让用户多选
4. **补充询问参数**：
   - 如果用户选择了板块6，询问节点名称
   - 如果用户选择了板块7，询问路径模式条件
   - 如果用户选择了板块8，询问辅助节点名称
5. **分析前询问（必须执行）**：
   - 询问是否有数据筛选需求
   - 询问是否有特殊情况说明
   - 等待用户回复后继续
6. **执行分析**：按用户选择的顺序执行对应的分析
7. **生成输出**：
   - 输出处理后的 CSV 文件
   - 输出用户所选模块的 Markdown 表格
   - 输出各模块的问题诊断
   - 输出全盘的策略建议
8. **询问可视化**：询问是否需要生成数据图表

---

## 注意事项

1. **计算字段为空的情况**：如果某行数据为空或无法解析，设置相应字段为空值
2. **除零错误**：计算指标时注意分母为0的情况，设置合理默认值
3. **占比计算**：占比 = 该分组值 / 全量值，保留2位小数
4. **ROAS计算**：如果广告花费为0，ROAS 显示为空或"-"
