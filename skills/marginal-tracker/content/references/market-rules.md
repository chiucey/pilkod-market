# A股 / 港股 / 美股市场规则

## 市场识别

- 先判市场,再选主体类型:A股 → `a_stock`,港股 → `hk_stock`,美股 → `us_stock`。
- 保留原始交易代码、交易所、币种、本地时区、交易日历。
- 做跨市场比较时,统一币种、会计期间、财务口径、复权方式、估值日期。
- 解释用中文,但公司、证券、指标、公告名称可保留原文。

## A股

- 适用中国企业会计准则、人民币、中国交易日历。
- 处理 T+1、涨跌停、ST / *ST、停复牌、退市风险、流动性约束。
- 区分累计报告期、单季度推导值与 TTM;关注归母净利润、扣非净利润、经营现金流。
- 股本结构需明确:总股本、流通股本、限售股、解禁、增减持、回购、分红与再融资影响。
- 行业比较优先标注分类口径(申万 / 中信 / 中证 / 证监会)。

## 港股

- 适用港交所交易日历、港币、相应上市规则。
- 区分主板 / GEM、同股不同权、红筹 / H股、双重主要上市、二次上市。
- 处理每手股数、停牌、配售、供股、可换股证券、控股股东持股变化。
- 明确财报采用的准则(IFRS / HKFRS / 其他)与报告币种。
- A/H 比较时考虑股份类别、汇率、自由流通、公司行动差异。

## 美股

- 适用 NYSE / Nasdaq 等交易所日历、美元、美东时区。
- 以 SEC 文件、公司 IR、GAAP / 非 GAAP 口径、季度财报为主要事实基础。
- 处理盘前 / 盘后发布、拆股、回购、股权激励、稀释股数、ADR、双重上市。
- 事件分析要区分常规交易时段、盘前、盘后的价格反应。
- 财报分析可用电话会文字稿,但文字稿不得替代正式申报文件中的会计数字。

## 跨市场通用

- 明确价格是否复权,以及分红、拆股、配股、送转或其他公司行动的处理方式。
- 股价、估值、事件、宏观数据都要记录截至时间。
- 区分:正式披露、MCP 结构化数据、用户材料、分析师推导、假设、判断。
- 数据冲突时以交易所 / 监管 / 公司正式披露为准,并披露差异来源。
- 输出研究分析,**不输出面向个人的交易指令**。
