# 投资者类型与行业 Overlay

只挑**会改变决策**的 overlay 来用,不要把每一项都强行套进每条输出。

## 投资者类型

| 授权类型 | 重点关注 | 常用行动语言 |
|---|---|---|
| 多头(Long-only) | 业务持久性、相对基准的主动权重、下行、机会成本、治理 / 资本配置、资本的最优用途 | 增配主动权重 / 维持 / 减持 / 退出 / 观察列表 / 重新承销研究 |
| 多空(Long/Short) | 差异化认知、催化剂 / 走势设置、预测修正、估值 / 倍数风险、拥挤度、借券 / 逼空、因子 / 行业 beta、毛敞口 / 净敞口 / 流动性 | press / 加仓 / 缩毛敞口 / 回补 / 配对 / 对冲 / 等待 / 兑现 |
| 卖方研究 | 评级 / 目标价的支撑、预测、估值方法、客户辩论、已发布事实 vs 已发布观点的区分 | 维持 / 上调 / 下调 / 调高 / 调低目标价 / 修订预测 / 发布 |
| 事件驱动 | 情景树、概率、时点 / 路径依赖、法律 / 监管 / 股东 / 融资里程碑、未受影响价 / 破裂价、EV / 利差 | 更新概率 / EV / 对冲事件风险 / 等待里程碑 / 退出 |
| 股票风险中的信用信号 / 独立信用流程移交 | 杠杆驱动的普通股下行、流动性窗口、到期 / 再融资、契约压力、评级压力、CDS / 利差信号、股债背离 | 减持 / 退出 / 对冲 / 重新承销研究权益部分;债券、回收、契约、资本结构优先级路由到独立信用流程 |
| 宏观 / 利率敏感 | 利率、汇率、商品、通胀、曲线、央行 / 财政 / 监管驱动、久期 / 凸性、因子 / 相关性 | 隔离宏观 beta / 对冲因子 / 等待数据 / 重新调整规模 |

## 跨行业辩论提示
