# 核心工作流契约

用于完整的论点跟踪器搭建或更新。

## 步骤序列

1. **上下文锁定**。收齐发行人 / 证券、方向、授权、期限、敞口、用户给的成本基础 / 评级 / 目标价、基准 / 同业、输出格式。缺失项以**带标签的占位符**补全。
2. **来源与时效性**。盘点每条来源的名称、类型、截至时间 / 报告期、可靠性、覆盖范围、局限。优先顺序:用户 / 已连接材料 → 官方公告 / 公告函 / 电话会文字稿 → 供应商市场 / 一致预期数据 → 研究 / 新闻 → 假设。重大证券论点更新尽量取当前公开价与基本市场背景,记录来源与时间戳;缺失的一致预期、模型、仓位、基准、风险输入要**单独**点出。
3. **原始承销研究**。独立保留:一句话论点、差异化认知、市场框架、估值锚、情景、预期回报、催化剂、KPI、终止标准、仓位含义、待解尽调。
4. **支柱拆分**。把论点转化为有优先级、可检验的主张,每个支柱要有:基准、预期路径、确认 / 警告 / 失效阈值、节奏、模型关联、行动关联、下一个验证点。数值权重 / 评分仅在继承自前期跟踪器或用户明确要求时保留;否则用定性优先级,不出汇总评分图。
5. **证据台账追加**。每条新事实带:来源 / 日期、所属支柱、先验内部预期、一致预期 / 市场预期、解读、信号、幅度、质量、模型 / 估值 / 确信度 / 行动影响、后续事项或下一个验证点。
6. **KPI / 修正 / 催化剂**。把实际值与上一期、内部模型、指引、一致预期、用户提供的买方预期、阈值、同业对照。不可得数据**明示标注**。
7. **模型 / 估值**。声明被改动的模型项;判断该变化属于时点 / 周期 / 结构性中的哪一类;说明预测含义、公允值 / 目标价 / 下行 / 利差 / 回收的影响,以及风险回报是否仍然过门槛。缺当前价或关键估值输入时,**把证券论点就绪度标为 not decision-grade**,而不是硬给一个估值驱动的行动建议。
8. **状态 / 行动**。
   - 公司论点状态从 strengthening / intact / watch / impaired / broken / changed / untested / retired 中选,与证券论点就绪度(ready / conditional / re-underwrite / not decision-grade)**分别**判定。
   - 汇总状态须与核心支柱对齐:继承的核心支柱 `Impaired` 时,汇总停留在 `Watch` 需有证据支撑的覆盖理由;多个核心支柱 `Impaired` 时,汇总默认 `Impaired`。
   - 行动建议从 add / press、hold、trim、exit / cover、upgrade / downgrade、hedge / pair、wait、re-underwrite、update model、diligence、escalation 中选。
   - 每个阈值打 `Inherited threshold` / `Draft threshold for PM confirmation` / `Approved monitoring rule` 之一。
9. **红队 / 日志**。最有力的反方观点、其证据、什么会改变结论、待解问题、下次审查日期、仅追加变更日志。
10. **GUI / 工作簿 QA**。默认先整理 `visual-page brief` 并调用 `visual-page` 生成 GUI/HTML 审查页。用户明确要求 XLSX 时,工作簿输出要以紧凑、面向决策的封面起头,审计轨迹放进细表;首屏不重复字段;冻结关键列;每个工作表交付前可视化检查。完整行动规则矩阵、完整尽调 / 缺口登记表放在专属选项卡;封面只显示行动立场、主要阻碍、下一道关口。需要大量横向滚动的表要缩减或拆分;评分图除非继承或被要求,否则不出。

## 运行模式与节奏

每份完整跟踪器都要写出运行模式:

- 决策权限
- 审查节奏
- 催化剂后更新 SLA
- 升级触发条件
- 下一审查关口
- 用户提供时:组合角色与主动权重
- 仅追加决策日志变更流程

每次更新的结尾**必须**落在以下之一:`add` / `press` / `hold` / `trim` / `exit` / `cover` / `hedge` / `wait for proof` / `re-underwrite` / `update model` / `escalate`。

新提出的监控阈值是**辅助决策的草案**,不是已批准的授权规则。继承的阈值与已批准的监控规则要**分别保留**,带上来源与批准状态。

## 解读规则

- 证据方向:strongly confirming、mildly confirming、neutral、mixed、mildly weakening、strongly weakening、invalidating、untested。
- 论点可以"变强"而股票"变得不那么吸引人"——当估值 / 预期跑得比证据快时。
- 头条 beat 也可以削弱论点——当先行 KPI、质量、现金转化、指引令人失望时。
- 股价走势是**信号**,要拆解,不是论点状态的证明。
- 任何"持续监控"的结论必须配上:指标、来源、阈值、日期、行动。
