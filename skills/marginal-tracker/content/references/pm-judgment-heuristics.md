# 公开股票 PM 判断启发式

本文件给多市场股票研究类技能共用,适用场景:用户在尽调一只上市股票、公开公司催化剂、公开公司模型、多空推介、卖方笔记、ETF / 指数成分股、组合持仓。

## 受众模式

- `long_only_pm`:论点持久性、下行捕获、相对基准的风险、流动性、加减仓纪律、组合角色。
- `long_short_hf`:差异化认知、催化剂路径、情景偏斜、借券 / 拥挤、对冲 / 平仓规则、毛 / 净敞口、时点风险。
- `sell_side_research`:评级与目标价纪律、预测修正、市场辩论框架、评级的风险、客户可读性、合规口径。
- `etf_index_diligence`:指数方法、成分权重、流通 / 流动性、ETF 持有、被动资金流相关性、因子 / 行业敞口、再平衡风险、跟踪误差含义。
- `public_equity_diligence`:有来源支撑的发行人尽调、业务质量、管理层可信度、治理、会计质量、资本配置、估值风险、下一项需要的尽调来源。

## 老 PM 必问

任何实质性输出在添加背景之前,先回答这七问:

1. **被错定价的是什么(如果有)?**
2. **市场已经计入了什么?**
3. **什么会证明这个论点?**
4. **什么会杀掉这个论点?**
5. **为什么是现在?**
6. **什么会改变仓位 / 评级 / 目标价 / 对冲 / 减持 / 退出 / 平仓 / 观察列表?**
7. **缺哪些证据?**

## 核心启发式

- **差异化楔子**:把"已知事实"和"被错定价的洞察"分开。没有差异化楔子,就把它定性为监控项或 pass。
- **市场已计入什么**:在建议任何行动前,先讲当前股价 / 一致预期 / 仓位 / 基准持有似乎已经折现了什么。
- **预测路径**:指出收入 / 利润率 / EPS / FCF / KPI / 倍数中哪条路径必须移动股票才能赚。
- **估值偏斜**:展示基础 / 乐观 / 悲观,并说明当前股价是否已经为乐观情形买单。
- **下行机制**:先解释怎么亏钱,再解释怎么赚钱。
- **催化剂质量**:区分硬日期、证据窗口、软叙事催化剂、以及"无催化剂"配置。
- **持仓与定位**:在相关时,标记流动性、容量、被动持有、ETF / 指数敞口、空头利息、借券、拥挤度、因子 / 行业敞口。
- **基准与因子敞口**:声明该证券是绝对回报、相对基准主动下注、对冲、因子表达,还是成分股尽调项。
- **反证条件**:每一条论点检验都要可观测、可日期化,并与某个来源 / KPI / 模型项 / 事件挂钩。
- **行动纪律**:把下一步动作归类为 `add`、`press`、`hold`、`trim`、`exit`、`cover`、`hedge`、`watchlist`、`pass`、`wait for proof` 或 `re-underwrite`。

## 品味规则

- 没有泛泛的"好公司 / 便宜股票"结论。要点名具体的错定价,否则就说没有。
- **公司论点与股票论点必须分开**。好公司可以是糟股票;糟糕业绩也可以创造更好的入场点。
- 每条重要主张都打标签:事实、管理层说法、一致预期、市场数据、模型输出、假设、PM 判断。
- 一致预期、价格、持仓、流动性、借券、期权、指数、ETF、空头利息这些数据,都要记录截至时间。
- 惩罚:无引用催化剂、陈旧市场数据、虚假精确度、对"市场怎么想"的无根据断言。
- 不要把缺失数据糊弄过去。**把缺失证据放进决策里**,而不是只放在附录。

## PM / 风险工作流视角

本视角与 `portfolio-risk-management` 共用,涉及为公开股票仓位调仓 / 对冲时启用:

- **Alpha 与意外敞口的分离**:把 PM 有意持有的特异性 / 催化剂 / 因子 / 基准 / 指数敞口,与意外背上的 beta / 因子 / 行业 / 流动性 / 借券 / 期权 / 汇率 / 商品 / 利率 / 拥挤 / 跳空风险分开。
- **保留敞口**:声明在仓位调整 / 对冲建议之后**还剩什么风险**。一个把股票论点也一并消去的对冲,通常比缩小仓位更差。
- **绑定约束**:点名最紧的可信限制(下行损失、流动性、借券、毛 / 净 / beta / 因子敞口、主动权重、期权权利金 / 希腊字母、授权、催化剂时点、确信度中的哪一项)。
- **对冲失败情形**:写一个对冲 / 配对 / ETF / 期权 / 宏观替代物在标的承压时**失效**的场景。
- **缩规模 / 不对冲的对照**:把对冲方案与"缩毛敞口、用更小的初始仓位、或干脆什么都不做"做对照——基差风险、成本、alpha 损耗有时比敞口本身更糟。
- **行动规则**:加 / 减 / 退出 / 平仓 / 调规模 / 滚仓 / 取消的规则要绑定到可观测的价格、论点证据、流动性、借券、期权到期、催化剂路径、因子敞口或对冲基差。
- **信用信号边界**:CDS、信用利差、评级、再融资压力、到期墙、契约头条可以为公开股票的下行或偿付能力提供信息;但 CDS、债券、贷款、利差 DV01 / CS01、资本结构、困境、回收、契约层面的交易**不要在多市场股票研究里建议或定规模**——路由到独立信用分析流程。
