# 辽宁电力市场电价预测技能

## 核心约束规则

### 1. 预测必须基于七大核心因素
- **煤价**：火电边际成本决定电价底线
- **火电开机容量**：以热定电刚性约束
- **新能源出力**：风电/光伏实时+预测出力
- **全网负荷**：实时负荷+预测曲线
- **跨省外送**：蒙东/吉黑省间交易
- **机组检修**：停机容量影响供需
- **历史成交价**：近7日同时段参考

### 2. 辽宁市场底层逻辑
| 场景 | 价格影响 |
|------|---------|
| 火电主导 | 边际成本定价，电价有底 |
| 风光大发 | 压制时段电价，易现负电价 |
| 负荷高峰 | 推高晚峰价格至0.30+ |
| 外送增加 | 改变供需平衡，抬升底部 |

### 3. 禁止行为
- ❌ 脱离行业规则自由预测
- ❌ 输出无依据极端数值
- ❌ 缺少关键影响因素说明
- ❌ 输出格式混乱

## 分时段预测规则

### 时段1：早高峰（07:00–11:00）
**特征**：负荷攀升，光伏介入，火电逐步顶出力
**预测要点**：
- 风光若弱出力 → 电价易冲高
- 光伏逐步出力 → 抑制涨幅
- 煤价支撑底部价格

### 时段2：午间平段（11:00–17:00）
**特征**：光伏峰值，新能源占比最高
**预测要点**：
- 光伏满发（峰值420万kW）→ 电价大概率走低
- 煤价上涨或外送增加 → 抬升底部价格
- 午间常现低价区间

### 时段3：晚高峰（17:00–22:00）
**特征**：光伏归零，负荷高位，全靠火电
**预测要点**：
- 全天价格峰值区间
- 风电夜间启动可平抑高价
- 典型峰值：0.30~0.45元/kWh

### 时段4：夜间低谷（22:00–次日07:00）
**特征**：负荷最低，火电深度调峰
**预测要点**：
- 风电大发时段（超1200万kW）
- 易现负电价（-0.05~-0.15元/kWh）
- 储能充电最优窗口

## 输出格式规范

### 1. 分时段预测表
```
| 时段 | 预测电价 | 合理区间 | 驱动因素 |
```

### 2. 逐15分钟预测值
```
时间（MM-DD HH:MM）  预测电价（元/kWh）  时段标注
```

### 3. 核心影响因素说明
列出本次预测的3-5个关键驱动因素及影响方向

### 4. 关键预警
- ⚠️ 负电价极值时段及预测值
- 📈 价格冲高时段
- 📉 日内价格最低点

## 预测值生成流程

1. **数据接收**：解析用户提供的7类数据
2. **时段分析**：识别当前所处预测时段
3. **供需测算**：计算火电/新能源/负荷平衡
4. **区间预测**：确定合理价格区间
5. **逐点输出**：生成96个15分钟预测值
6. **关键标注**：标记极值时段和预警信息

持续优化核心因素权重，降低预测误差。
