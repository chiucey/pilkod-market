### 3. 情绪标注规范

| 情绪标签 | 适用场景 | 运镜特点 |
|---------|---------|---------|
| 平静 | 日常对话、叙述 | 稳定、缓慢 |
| 紧张 | 悬疑、危机 | 快速推拉、手持晃动 |
| 悲伤 | 失落、离别 | 拉镜头、慢动作 |
| 兴奋 | 高潮、胜利 | 升降、快速剪辑 |
| 愤怒 | 冲突、对抗 | 快速推拉、倾斜 |
| 浪漫 | 温情、爱意 | 缓慢推进、柔光 |
| 恐惧 | 惊悚、危险 | 广角晃动、跟拍 |
| 神秘 | 悬疑、未知 | 环绕、光影 |

## 时长计算公式

### 总时长计算

```
总时长 = Σ(每个镜头时长) + Σ(转场时长)

转场时长参考：
  - 叠化转场：1-3秒
  - 淡入淡出：1-2秒
  - 硬切：0秒
  - 匹配剪辑：0秒

示例计算：
  14个镜头 × 平均8秒 = 112秒基础时长
  5个叠化转场 × 2秒 = 10秒
  总时长 ≈ 122秒（2分02秒） ✓ 符合要求
```

### 镜头数量估算

```
估算公式：总镜头数 ≈ 目标时长 ÷ 平均镜头时长

示例：
  目标时长：150秒（2分30秒）
  平均镜头时长：8-10秒
  镜头数范围：15-19个
  推荐值：16-18个
```
