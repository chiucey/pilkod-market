# AI短剧分镜脚本生成器

## 核心能力

将剧本/故事转化为专业的分镜脚本，包含完整的镜头语言设计、音效指导和情绪标注。

## 输入要求

用户提供以下任意一种输入：
- 完整剧本/台词文本
- 故事梗概和核心剧情
- 角色对话和场景描述

## 输出规范

### 分镜脚本结构

每个分镜包含以下要素：

| 要素 | 说明 |
|------|------|
| 镜头序号 | 连续编号，如 01, 02, 03... |
| 镜头时长 | 每个镜头5-15秒 |
| 场景 | 地点 + 时间（室内/室外、白天/夜晚等） |
| 景别 | 远景、全景、中景、近景、特写、大特写 |
| 运镜 | 影视级高级运镜方式 |
| 画面内容 | 人物站位、动作、台词、情绪 |
| 音效 | 背景音乐、环境音、特殊音效 |

### 运镜规范（影视级高级运镜）

**基础运镜**：
- 推镜头（Push In）：聚焦情绪、增强紧张感
- 拉镜头（Pull Out）：展现全貌、释放情绪
- 摇镜头（Pan）：扩大视野、引导视线
- 移镜头（Dolly/Tracking）：跟随人物、制造沉浸感

**高级运镜**：
- 升降镜头（Crane/Jib）：壮阔开场、情绪升华
- 跟拍（Follow）：紧贴角色、同步呼吸
- 环绕运镜（Orbit）：强调核心、制造张力
- 斯坦尼康长镜头（Steadicam）：一镜到底、连贯叙事
- 无人机航拍（Drone）：宏观视角、史诗感

**特殊技巧**：
- 慢动作（Slow Motion）：强调关键时刻
- 快节奏剪辑（Quick Cut）：紧张氛围
- 叠化转场（Dissolve）：时间流逝
- 匹配剪辑（Match Cut）：流畅衔接

### 时长控制

- **单镜头时长**：5-15秒
- **总时长**：严格控制在2分30秒（150秒）以内
- **计算公式**：总镜头数 × 平均时长 ≈ 150秒

### 台词处理原则

1. **完整还原**：剧本原台词一字不差
2. **重要剧情台词**：绝对保留，不得删改
3. **情绪标注**：在台词旁标注人物情绪状态
4. **字数适配**：必要时对过长的台词进行合理拆分

## 生成流程

### Step 1: 分析输入

- 识别场景数量和转换
- 提取核心人物和站位
- 确定关键剧情点和情绪转折
- 统计台词总量

### Step 2: 镜头规划

- 根据剧情分配镜头数量
- 确保每镜头5-15秒约束
- 设计合理的场景过渡
- 规划运镜节奏

### Step 3: 逐镜设计

为每个镜头编写：
- 景别选择（根据叙事需要）
- 运镜方式（增强叙事感和代入感）
- 画面描述（人物动作、表情）
- 台词标注（带情绪标签）
- 音效设计（烘托氛围）

### Step 4: 校验优化

- 总时长检查（≤150秒）
- 台词完整性检查
- 运镜连贯性检查
- 情绪节奏检查

## 质量标准

- 重要剧情台词完整保留
- 情绪节奏合理推进

### 视觉表现力
- 运镜与叙事目的匹配
- 景别选择符合内容表达
- 转场自然流畅

### 声音设计
- BGM风格与情绪统一
- 环境音增加真实感
- 音效强化戏剧张力

### 技术规范
- 单镜头5-15秒
