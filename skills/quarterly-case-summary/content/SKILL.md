# 季度工作案例撰写技能

## 使用场景

帮助产品经理或员工围绕公司核心价值观，总结最新季度的工作案例。重点在于描述工作细节内容，并适当结合价值观进行升华。

## 公司四大核心价值观

### 第一：用户为根
- 从用户中来，满足用户需求
- 到用户中去，摸产品听声音
- 敬畏用户，优先维护用户利益

### 第二：价值为本
- 落地实干，拿到实际结果
- 关注细节，把握机会
- 开拓新方法，创造新价值

### 第三：追求卓越
- 勇于自省，持续学习
- 主动担责，锲而不舍
- 渴望成功，树立高标准

### 第四：协作共赢
- 敢于寻求帮助，乐于提供帮助
- 遇事不推诿，凡事有回应
- 着眼大局，换位思考共赢

## 工作流程

### 步骤1：收集案例信息

通过GenUI表单向用户询问每个价值观的工作案例：

1. **用户为根** - 询问具体如何满足用户需求、维护用户利益
2. **价值为本** - 询问实际成果、细节创新、方法突破
3. **追求卓越** - 询问自我突破、攻坚克难、高标准达成
4. **协作共赢** - 询问跨部门协作、帮助支持、集体利益

### 步骤2：撰写案例内容

撰写规范：
- 每个案例不超过100个字
- 重点描述工作细节和具体行动
- 适当结合价值观关键词进行升华
- 案例应具有可读性和感染力

### 步骤3：整理输出

按价值观分类整理，形成完整的季度案例总结文档。

## 案例撰写示例

**用户为根案例示例：**
"针对用户反馈的页面加载缓慢问题，我连续三天蹲点用户使用场景，通过埋点数据和用户访谈，发现根本原因是接口冗余请求。主动协调开发团队优化接口，将加载时间从3秒降至0.8秒，用户满意度提升40%。"

**价值为本案例示例：**
"在XX项目中，我注意到订单确认页的转化率在周末明显下降。通过细致分析发现是物流时效显示不清晰导致用户决策犹豫。我创新性引入实时物流动态展示功能，该功能现已推广至全站，带动整体转化率提升5%。"

**追求卓越案例示例：**
"接手遗留项目时代码质量堪忧，我主动申请延期一周进行全面重构。期间自学领域驱动设计，最终不仅交付高质量代码，还建立了团队的代码评审规范，后续迭代效率提升60%。"

**协作共赢案例示例：**
"跨部门项目涉及5个团队，我主动建立每日站会机制，协调资源冲突12次。面对技术方案分歧，我组织多方协商会议，最终找到兼顾各方利益的解决方案，项目提前3天上线。"
