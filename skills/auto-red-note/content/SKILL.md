# Auto-RedNote 小红书图文笔记创建

## 使用场景

- 用户需要创建小红书图文笔记
- 用户需要生成精美的笔记发布配图素材
- 用户想要快速创建专业级图文笔记
- 用户需要多种风格主题的图文素材

## 核心能力

### 图文笔记生成

- **封面图**：AI自动根据主题生成吸睛标题、副标题、装饰Emoji
- **内容图**：支持标题、段落、列表、引用、代码块等多种内容格式
- **HD输出**：1080×1440像素，3:4黄金比例，完美适配小红书平台
- **实时预览**：生成后立即在对话中显示图片预览

### 主题风格（8种）

| 风格ID | 名称 | 说明 |
|--------|------|------|
| `default` | 默认简约 | 浅灰渐变背景 |
| `playful-geometric` | 趣味几何 | 孟菲斯风格 |
| `neo-brutalism` | 新丑风格 | 粗犷现代 |
| `botanical` | 植物园风 | 自然清新 |
| `professional` | 专业商务 | 商务精英 |
| `retro` | 复古怀旧 | 怀旧质感 |
| `terminal` | 终端命令行 | 极客风格 |
| `sketch` | 手绘素描 | 手绘风格 |

### 分页模式（4种）

| 模式ID | 说明 | 适用场景 |
|--------|------|----------|
| `separator` | 手动分页（---分隔符） | 内容可控 |
| `auto-fit` | 固定尺寸自动缩放 | 封面+单图 |
| `auto-split` | 按高度自动分割 | 多要点内容 |
| `dynamic` | 按内容动态高度 | 长内容（最大4320px）|

### 色彩系统（9种）

- `red` | `orange` | `yellow` | `green` | `blue` | `purple` | `pink` | `brown` | `gray`

详细配色规则见 `references/color-systems.md`

## 工作流程

### 步骤1：收集用户需求（分步引导）

**第一步：询问主题**

```
请告诉我您想要创作什么主题的图文笔记？
例如："5个效率神器"、"春季穿搭指南"、"健康饮食建议"
```

处理规则：
- 用户仅提供主题 → 直接进入下一步
- 用户提供标题+副标题 → 跳过封面信息询问

---

**第二步：询问布局主题**

```
请选择布局主题，或输入"AI推荐"让我为您选择：
- default：默认简约
- playful-geometric：趣味几何
- neo-brutalism：新丑风格
- botanical：植物园风
- professional：专业商务
- retro：复古怀旧
- terminal：终端命令行
- sketch：手绘素描
```

处理规则：
- 用户选择具体主题 → 使用用户选择
- 用户选择"AI推荐" → AI根据主题自动推荐
- 默认使用 `default`

---

**第三步：询问内容风格**

```
请选择内容风格，或输入"AI推荐"让我为您选择：
- Playful：使用丰富Emoji和生动语言
- Professional：正式严谨的表达
- Concise：精简直白的风格
- Detailed：全面详尽的阐述
```

处理规则：
- 用户选择具体风格 → 使用用户选择
- 用户选择"AI推荐" → AI根据主题自动推荐
- 默认使用 `Playful`

---

**第四步：询问色彩系统**

```
请选择色彩系统，或输入"AI推荐"让我为您选择：
- red：红色系（热情活力）
- orange：橙色系（阳光活力）
- yellow：黄色系（明亮欢快）
- green：绿色系（自然清新）
- blue：蓝色系（专业信赖）
- purple：紫色系（优雅神秘）
- pink：粉色系（温暖甜蜜）
- brown：棕色系（温暖自然）
- gray：灰色系（简约高级）
```

处理规则：
- 用户选择具体色彩 → 使用用户选择
- 用户选择"AI推荐" → AI根据主题自动推荐
- 默认使用 `blue`
- **禁止在非紫色系中使用紫色作为主题色**（除非用户明确要求）

---

**关键规则**

- 必须分步询问，不能一次性显示所有问题
- 必须询问布局主题、内容风格、色彩系统
- 主题色和边框色必须符合所选色彩系统规则
- 不询问分页模式，AI自动根据内容选择
- 不询问封面装饰Emoji，AI自动生成
- 每步等待用户响应后再进行下一步

---

**封面标题和副标题生成规则**

AI根据用户提供的主题自动生成：

**标题**：简洁有力，不超过15字，击中主题核心
- 示例："5个效率神器" → "效率神器"
- 示例："春季穿搭指南" → "春季穿搭"
- 示例："健康饮食建议" → "健康饮食"

**副标题**：补充说明或价值主张，不超过15字
- 示例："提升工作效率" 或 "让工作更轻松"
- 示例："打造最美造型" 或 "时尚穿搭灵感"
- 示例："吃出健康生活" 或 "营养均衡指南"

**Emoji选择指南**

根据主题自动选择最合适的装饰Emoji：

| 主题类型 | 推荐Emoji |
|----------|-----------|
| 效率/速度 | ⚡、🚀、💨、⏱️ |
| 科技/创新 | 💡、🔮、📱、💻 |
| 生活/健康 | 🌿、🍃、❤️、✨ |
| 美食/分享 | 🍜、🍰、📸、🎉 |
| 学习/成长 | 📚、🎓、📝、🌟 |
| 商务/职场 | 💼、📊、📈、💰 |

---

**确认收集的信息**

```
已收到！我将为您创建"【主题】"的图文笔记：
- 封面标题：【标题】
- 封面副标题：【副标题】
- 封面装饰：【Emoji】
- 布局主题：【主题名称】
- 内容风格：【风格名称】
- 色彩系统：【色彩名称】

请提供相关素材，或让我根据主题自动生成内容？
```

---

### 步骤2：准备图文内容

#### 2.1 确定分页模式（AI自动选择）

| 内容长度 | 推荐模式 | 说明 |
|----------|----------|------|
| 短内容（封面+1-2图） | `auto-fit` | 固定尺寸自动缩放 |
| 中等内容（3-6图） | `auto-split` | 按高度自动分割 |
| 长内容（7+图） | `dynamic` | 动态高度（最大4320px）|
| 有明确分页要求 | `separator` | 手动分隔符 |

#### 2.2 创建Markdown文件

创建用于渲染图文的Markdown文件，包含：

```yaml
---
emoji: "🚀"           # 封面装饰Emoji
title: "大标题"        # 封面主标题（不超过15字）
subtitle: "副标题文案"  # 封面副标题（不超过15字）
---

# 📝 神器一：Notion

> 全能型笔记工具，支持数据库、看板、日历等多种视图...

## 特色功能

- 特色一
- 特色二

---

# ⚡ 神器二：Raycast

强大的启动器和搜索工具
```

规则：
- 根据用户提供的主题和素材生成内容
- 支持标题、段落、列表、引用、代码块等格式
- 符合用户选择的内容风格（Playful/Professional/Concise/Detailed）
- 遵守色彩系统的配色规则
- **禁止使用紫色作为主题色**（除非用户明确要求）

---

### 步骤3：渲染图文笔记

使用渲染脚本将Markdown文档转换为HD图片：

```bash
python scripts/render_xhs.py <markdown_file> [options]
```

**渲染参数**

| 参数 | 短 | 说明 | 默认值 |
|------|-----|------|--------|
| `--output-dir` | `-o` | 输出目录 | 当前目录 |
| `--theme` | `-t` | 布局主题 | default |
| `--mode` | `-m` | 分页模式 | separator |
| `--width` | `-w` | 图片宽度 | 1080 |
| `--height` | | 图片高度 | 1440 |
| `--max-height` | | dynamic最大高度 | 4320 |
| `--dpr` | | 设备像素比 | 2 |

**生成图片**

- 封面图：`cover.png`
- 内容图：`card_1.png`、`card_2.png`、...
- 尺寸：1080×1440像素，3:4比例

---

### 步骤4：交付图片（必须执行）

使用finish工具直接交付图片文件：

```json
{
  "success": true,
  "files": [
    {"type": "image", "path": "./cover.png", "name": "封面"},
    {"type": "image", "path": "./card_1.png", "name": "正文1"},
    {"type": "image", "path": "./card_2.png", "name": "正文2"}
  ],
  "message": "图文已生成完成！"
}
```

**关键要求**

- 必须使用finish工具交付图片
- 所有生成的图片文件必须添加到files列表
- 使用相对路径（./文件名）
- 图片会自动在对话中显示
- 用户可直接查看和下载

---

### 步骤5：询问是否打包（可选）

生成图片后，主动询问用户：

```
是否需要将生成的图文打包为 .zip 压缩包下载？
- 回复"是"或"打包"：生成压缩包
- 回复"否"或"不需要"：使用在线图片即可
```

**处理用户响应**

用户回复"是"或"打包"：
```bash
zip -r xhs_images.zip cover.png card_*.png
```

使用finish工具交付压缩包：
```json
{
  "success": true,
  "files": [
    {"type": "file", "path": "./xhs_images.zip", "name": "图文素材包"}
  ],
  "message": "打包完成！"
}
```

用户回复"否"或"不需要"：
- 确认用户选择，任务完成

## 图片规格

### 封面图

- 尺寸：1080×1440像素（3:4黄金比例）
- 元素：Emoji装饰、主标题、副标题
- 设计风格：渐变背景 + 圆角内容区

### 内容图

- 尺寸：1080×1440像素（3:4比例）
- 支持格式：标题、段落、列表、引用、代码块、图片
- 设计风格：白色卡片 + 渐变背景边框

## 技能资源

### 脚本文件

- `scripts/render_xhs.py` - Python渲染脚本
- `scripts/render_xhs.js` - Node.js渲染脚本
- `scripts/publish_xhs.py` - 小红书发布脚本

### 资产文件

- `assets/cover.html` - 封面HTML模板
- `assets/card.html` - 内容卡片HTML模板
- `assets/styles.css` - 共享样式表

### 参考文档

- `references/color-systems.md` - 完整色彩系统参考

## 注意事项

- Markdown文件保存在工作目录，渲染图片也保存在工作目录
- 技能目录仅存储脚本和模板，不存储用户数据
- 图片尺寸根据内容自动调整，保持3:4比例
- Cookie有有效期限制，过期后需重新获取
- 发布功能依赖xhs库，需安装：`pip install xhs`
- **禁止使用紫色作为主题色**（除非用户明确要求）
- AI自动生成封面标题、副标题、装饰Emoji，无需用户指定
- 封面标题和副标题不超过15字，简洁有力
