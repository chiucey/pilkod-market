# 小红书图文笔记色彩系统参考

本文档详细说明9种色彩系统的配色规则和使用指南。

## 色彩系统总览

| 色彩ID | 名称 | 情绪 | 适用场景 |
|--------|------|------|----------|
| `red` | 红色系 | 热情活力 | 节日、促销、励志 |
| `orange` | 橙色系 | 阳光活力 | 美食、旅行、生活 |
| `yellow` | 黄色系 | 明亮欢快 | 儿童、教育、轻松 |
| `green` | 绿色系 | 自然清新 | 环保、健康、植物 |
| `blue` | 蓝色系 | 专业信赖 | 科技、商业、专业 |
| `purple` | 紫色系 | 优雅神秘 | 时尚、艺术、高端 |
| `pink` | 粉色系 | 温暖甜蜜 | 美妆、情感、生活 |
| `brown` | 棕色系 | 温暖自然 | 复古、手工、咖啡 |
| `gray` | 灰色系 | 简约高级 | 极简、商务、时尚 |

## 红色系 (red)

### 情绪特征
温暖、热情、充满活力、引人注目

### 配色方案

```
Primary:     #E53935 (主红色)
Light:       #FF6B6B (浅红)
Dark:        #C62828 (深红)
Accent:      #FFCDD2 (粉红点缀)
Background:  #FFEBEE (浅红背景)
Text:        #B71C1C (深红文字)
Border:      #EF9A9A (边框红)
```

### 使用规则
- 主题色：使用 `#E53935` 或 `#C62828`
- 边框色：使用 `#EF9A9A` 或 `#FFCDD2`
- 背景色：使用 `#FFEBEE` 或 `#FFF5F5`
- 文字色：使用 `#B71C1C` 作为强调色
- 适用主题：节日庆典、限时促销、励志鸡汤

## 使用指南

### 配色选择决策树

```
1. 用户是否明确指定色彩系统？
   ├── 是 → 使用用户选择的色彩系统
   └── 否 → 进入下一步

2. 根据主题类型推荐：
   ├── 节日/促销/励志 → 推荐 red
   ├── 美食/旅行/生活 → 推荐 orange
   ├── 儿童/教育/轻松 → 推荐 yellow
   ├── 环保/健康/植物 → 推荐 green
   ├── 科技/商业/专业 → 推荐 blue
   ├── 时尚/艺术/高端 → 推荐 purple
   ├── 美妆/情感/少女 → 推荐 pink
   ├── 复古/手工/咖啡 → 推荐 brown
   └── 极简/商务/时尚 → 推荐 gray

3. 默认推荐：blue（专业信赖）
```

### 配色应用比例

建议在一个设计中使用以下比例：

- **主色 (Primary)**: 60% - 用于主要元素和背景
- **浅色 (Light)**: 25% - 用于辅助元素和过渡
- **深色 (Dark)**: 10% - 用于强调和标题
- **点缀色 (Accent)**: 5% - 用于小元素和高亮

### 禁忌规则

1. **禁止在非紫色系中使用深紫色作为强调色**
2. **避免在同一设计中混合使用超过3种色彩系统**
3. **确保文字与背景有足够的对比度（至少4.5:1）**
4. **禁止使用过亮的颜色作为大面背景**
