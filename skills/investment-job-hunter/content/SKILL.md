# 投资岗位搜集技能

## 核心原则

**宁缺毋滥**：只推荐真正与投资、战略、行业研究相关的高质量职位。不收录纯行政、纯秘书、纯销售类岗位。

## 目标区域

上海、江苏、浙江、安徽

## 信息源优先级

| 来源类型 | 用途 | 优先级 |
|---------|------|--------|
| 主招聘平台 | 规模化发现岗位 | 1 |
| 官方来源 | 验证真实性 | 2 |
| 半公开来源 | 补充隐性岗位 | 3 |
| 辅助验证 | 判断公司质量 | 4 |

## 岗位分类

| 类别 | 包含岗位 |
|------|---------|
| 一级市场投资 | VC/PE/股权投资/产业投资/并购投资 |
| 一级半市场投资 | Pre-IPO/定增/配售/资本市场投资 |
| 二级市场投资 | 股票研究/行业研究/公司研究/投资分析 |
| 战略研究 | 战略规划/战略研究/行业研究 |
| 资本运作 | 并购整合/投资者关系/资本运作 |
| 董事长助理-投资导向 | 需JD明确涉及投资分析/战略规划/资本运作 |

## 采集流程

### 第一步：广泛收集
从主招聘平台（BOSS直聘、猎聘、智联、51job、脉脉、LinkedIn）和半公开来源（猎头、脉脉职言、行业公众号）收集岗位线索。

### 第二步：初步过滤
- 地点：上海/江苏/浙江/安徽
- 标题可能属于投资/研究/战略/资本运作/董事长助理-投资导向
- 排除明显纯行政/纯销售/纯运营岗位

### 第三步：职责复核
必须验证 JD 是否涉及以下核心职责：
- 投资分析或决策支持
- 行业/公司研究
- 战略规划
- 资本运作或并购
- 投资相关的董事长/总裁助理职责

### 第四步：来源验证与交叉验证
- 官方来源优先于招聘平台
- 优先进行交叉验证（招聘平台+官方来源）

## 输出格式

每条岗位输出：
1. **职位名称** + **公司名称**
2. **工作地点** + **岗位类别**
3. **来源类型** + **具体来源**
4. **可信度**：高/中/低
5. **匹配度**：1-5分
6. **匹配原因**（必须说明为何纳入）
7. **关键职责摘要**
8. **任职要求摘要**
9. **投递优先级**：高/中/低
10. **风险提示**（如适用）

## 筛选规则

### 必须排除
- 纯行政助理
- 纯秘书
- 纯会务接待
- 纯日程协调
- 纯商务/销售支持
- 纯运营执行
- 与投资研究无明显关联的泛管理岗

### 特别说明
- 董事长助理/总裁助理：必须结合JD判断，只有明确涉及投资/战略/资本运作才纳入
- 标题党识别：有些岗位标题是"投资经理"但实际是销售，需仔细核对JD
- 信息不足时：标记"信息不足，需进一步验证"

## 时效性处理

- 优先近期发布的岗位
- 无更新时间时标记"时效性未知"
- 发布时间较早且无更新信号时降低优先级

## 去重规则

以下情况视为同一岗位：
- 同一公司 + 相同/近似岗位名称 + 相同城市
- 核心职责高度相似

保留：信息最完整、发布时间最新、来源可信度最高
