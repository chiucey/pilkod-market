# 投资岗位分类参考标准

## 一、一级市场投资

### 核心特征
- 投资于未上市企业股权
- 参与企业早期/成长期投资
- 涉及尽职调查、交易结构设计、投后管理

### 典型岗位
| 岗位名称 | 纳入标准 | 排除标准 |
|---------|---------|---------|
| VCAssociate/Analyst | 早期投资、支持创新行业 | - |
| PE投资经理/分析师 | 成长期/成熟期股权投资 | - |
| 产业投资经理 | 上市公司/集团产业投资 | 纯采购/供应商管理 |
| 并购投资经理 | 并购交易执行、交易结构 | 仅做尽调的咨询岗 |
| 投资总监/VP | 独立判断项目、带领团队 | - |
| 投资部负责人 | 搭建投资团队、制定策略 | - |

### 判断要点
- 看JD是否涉及"投资决策"、"项目判断"、"股权投资的完整流程"
- 看是否有"退出策略"、"IRR"、"DPI"等投资指标

---

## 二、一级半市场投资

### 核心特征
- 投资于上市前后阶段
- 定增、配售、大宗交易
- Pre-IPO投资、战略配售

### 典型岗位
| 岗位名称 | 纳入标准 | 排除标准 |
|---------|---------|---------|
| 定增投资经理 | 参与上市公司定增项目 | 仅做承销的销售 |
| Pre-IPO投资经理 | 上市前股权投资、锁定期理解 | 纯财务顾问 |
| 战略配售投资 | 参与科创板/港股战略配售 | - |
| 资本市场部投资岗 | 权益类投资、二级增减持 | 纯IR维护 |

### 判断要点
- 必须看JD是否涉及"定增"、"配售"、"锁定期"、"Pre-IPO"
- 纯"IPO承销"、"上市辅导"应排除

---

## 三、二级市场投资

### 核心特征
- 股票投资组合管理
- 行业/公司研究支持投资决策
- 公开市场权益投资

### 典型岗位
| 岗位名称 | 纳入标准 | 排除标准 |
|---------|---------|---------|
| 行业研究员 | 覆盖特定行业、提供投资建议 | 资讯编辑、新闻采编 |
| 股票分析师 | 二级市场分析报告 | 纯销售分析师 |
| 基金经理助理 | 支持基金投资决策 | 渠道销售、客服 |
| 权益投资经理 | 管理股票组合 | 仅做固收 |
| 研究部负责人 | 带领研究团队 | - |

### 判断要点
- 必须是"支持投资决策"的研报撰写
- 排除：财经编辑、证券销售、客户服务、产品运营

---

## 四、战略研究与战略规划

### 核心特征
- 公司战略规划与执行
- 行业研究与竞争分析
- 战略项目推动

### 典型岗位
| 岗位名称 | 纳入标准 | 排除标准 |
|---------|---------|---------|
| 战略规划经理 | 公司战略制定与落地 | 纯运营执行 |
| 战略研究员 | 行业研究、战略建议 | 仅做战略文档撰写 |
| 战略发展经理 | BD战略、合作伙伴战略 | 纯BD执行 |
| 首席战略官/CSO | 全面负责战略 | - |

### 判断要点
- "经营分析"和"运营分析"偏向执行，保留但降低优先级
- 必须有"战略"、"行业研究"或"竞争分析"元素

---

## 五、资本运作与并购

### 核心特征
- 并购交易全流程
- 融资与资本结构优化
- 投资者关系

### 典型岗位
| 岗位名称 | 纳入标准 | 排除标准 |
|---------|---------|---------|
| 并购经理 | 并购交易执行、M&A | 仅做尽调的FA |
| 资本运作经理 | 融资、上市、并购 | 纯财务会计 |
| 投资者关系IR | 资本市场沟通、股东管理 | 纯公关、媒体 |
| CFO/财务总监 | 资本运作主导 | 纯记账会计 |

### 判断要点
- IR岗位必须有"资本市场"、"股东"、"投资者"关键词
- 排除：纯公关、纯媒体、纯财经编辑

---

## 六、董事长助理/总裁助理

### 核心原则
**必须结合JD判断**，不能仅凭岗位名称纳入。

### 高相关特征（纳入）
- 参与投资决策支持
- 行业研究/公司研究
- 战略规划支持
- 资本运作/并购支持
- 经营分析/经营研究

### 低相关特征（排除）
- 纯会议安排/行程管理
- 纯接待/对外联络
- 纯文书/文档撰写
- 纯日程协调/事务跟进
- 纯行政支持

### 判断示例

**应纳入**：某科技公司"董事长助理"，JD描述"协助董事长进行行业研究、投资项目判断、战略规划推进"

**应排除**：某地产公司"总裁助理"，JD描述"负责总裁日程安排、来访接待、会议纪要、行程协调"

## 七、特殊说明

### 易混淆岗位识别

| 岗位类型 | 真实属性 | 伪装识别 |
|---------|---------|---------|
| 投资顾问 | 可能是销售 | 看是否涉及产品销售KPI |
| 投资经理（FA） | 财务顾问 | 看是否独立判断项目价值 |
| 行业研究（咨询） | 管理咨询 | 看是否服务于投资决策 |
| 战略合作 | 商务拓展 | 看是否有战略高度 |

### 标题党识别方法
1. JD全文是否与"投资"强相关
2. 是否有明确的"投资决策"、"项目判断"职责
3. 公司是否有真实的投资业务（查公开资料）
4. 薪资结构是否与销售挂钩
