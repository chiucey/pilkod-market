# Excel 多源数据合并与转换技能

## 功能概述

本技能用于处理多源Excel数据，支持：
- 读取并解析多个Excel文件
- 基于关键字/字段匹配数据行
- 提取指定列或计算新字段
- 数据类型转换和格式标准化
- 生成整合后的Excel输出

## 工作流程

### 步骤1：收集用户需求

向用户确认以下信息（使用GenUI表单）：
- **源文件**: 要处理的所有Excel文件路径
- **匹配规则**: 如何在文件间匹配数据（基于哪些列/字段）
- **提取字段**: 从源文件中提取哪些列
- **转换规则**: 是否需要计算新字段或数据类型转换
- **输出格式**: 输出文件的格式和结构要求

### 步骤2：分析源文件

读取所有Excel文件，分析：
- 列名和数据类型
- 数据行数
- 潜在的关键匹配字段
- 数据质量（空值、格式问题）

### 步骤3：执行数据匹配与提取

根据用户指定的规则执行：
1. **匹配逻辑**: 使用 pandas merge/join 基于指定字段匹配
2. **字段提取**: 选择需要的列
3. **数据转换**: 应用转换规则（类型转换、计算新字段等）

### 步骤4：生成输出文件

创建最终Excel文件：
- 包含提取和转换后的数据
- 保持良好的格式和可读性
- 可选：添加数据透视或汇总

## 常用匹配模式

| 模式 | 说明 | 示例 |
|------|------|------|
| 一对一 | 两文件按同一关键字段匹配 | 客户ID、订单号 |
| 一对多 | 主表记录匹配附表多条记录 | 订单匹配订单明细 |
| 多对多 | 两个文件按多个字段联合匹配 | 姓名+日期+金额 |
| 条件提取 | 根据条件从单个文件提取 | 金额>1000的记录 |

## 常用转换操作

- **列重命名**: 统一列名格式
- **类型转换**: 字符串→数字、日期格式统一
- **计算字段**: 金额合计、百分比计算
- **数据清洗**: 去除空值、标准化文本
- **数据过滤**: 按条件筛选记录

## 使用示例

**示例1：合并客户和订单数据**
```
用户提供：
- customers.xlsx (客户ID, 姓名, 电话)
- orders.xlsx (订单号, 客户ID, 金额)

输出：
- merged.xlsx (订单号, 客户ID, 姓名, 电话, 金额)
```

**示例2：跨文件提取产品信息**
```
用户提供：
- sales.xlsx (产品编码, 销售数量, 销售日期)
- products.xlsx (产品编码, 产品名称, 单价)

输出：
- report.xlsx (销售日期, 产品名称, 数量, 单价, 销售额)
```

## 技术实现

使用 Python pandas 库处理Excel数据：
- `pandas.read_excel()`: 读取Excel文件
- `pd.merge()`: 数据表关联
- `pandas.DataFrame`: 数据操作
- `to_excel()`: 导出Excel

## 注意事项

1. **文件格式**: 支持 .xlsx 和 .xls 格式
2. **编码**: 默认使用UTF-8编码
3. **空值处理**: 明确空值的处理方式（保留/删除/填充）
4. **数据量**: 注意大文件的处理性能
5. **列名冲突**: 多文件合并时注意重名列的处理
