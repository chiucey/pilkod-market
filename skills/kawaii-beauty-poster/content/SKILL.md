# 少女风格美妆营销海报生成器

## 技能定位

生成日系Kawaii插画风格的垂直美妆产品营销海报，适用于移动端传播场景。

## 核心设计要素

### 1. 风格定位
- **主风格**：日系插画风（Kawaii/Cute Illustration）
- **视觉特征**：线条圆润柔和、厚涂描边效果、手绘治愈感
- **目标受众**：年轻女性、Gen Z、少女心用户

### 2. 配色方案
- **主色调**：樱花粉（Sakura Pink）
- **辅助色**：蜜桃粉、奶油白、淡金色
- **光效色**：柔和渐变、金色散景光斑
- **色彩原则**：饱和度适中、梦幻温暖、通透明亮

### 3. 布局结构
- **构图形式**：垂直对称的中心构图（9:16比例）
- **视觉层级**：
  - 顶部：核心Slogan艺术字体
  - 中部：产品套装陈列（展示台/丝带装饰）
  - 底部：行动呼吁按钮（CTA）
- **平衡处理**：对角线呼应（樱花树枝/装饰元素）

### 4. 装饰元素库
| 元素类型 | 适用场景 | 情感联想 |
|---------|---------|---------|
| 樱花花瓣/树枝 | 春季限定、樱花季 | 浪漫、绽放 |
| 爱心 | 少女心、礼盒、节日 | 可爱、甜蜜 |
| 星星/光斑 | 提亮功效、产品光泽 | 闪耀、梦幻 |
| 缎带/蝴蝶结 | 礼盒包装、仪式感 | 精致、用心 |
| 散景光斑 | 背景氛围 | 梦幻、通透 |

### 5. 适合展示的产品卖点

| 卖点类型 | 海报设计语言 | 推荐场景 |
|---------|-------------|---------|
| 樱花成分/春季限定 | 樱花装饰元素 | 春日新品发布 |
| 水光肌/提亮功效 | 发光星星/光泽特效 | 功效宣传 |
| 温和配方/敏感肌可用 | 柔和配色/无攻击性视觉 | 成分党种草 |
| 限定礼盒/节日套装 | 缎带/仪式感构图 | 礼盒推广 |
| 少女肌/粉嫩通透 | 整体少女风设计 | 品牌调性传达 |

## 执行流程

### 步骤1：需求收集
收集以下信息（如用户未指定则使用默认值）：
- 产品类型（护肤品/彩妆/礼盒）
- 核心卖点（成分/功效/限定）
- 目标节日/季节（如有）
- 文案内容（Slogan/副标题/CTA）
- 尺寸偏好（默认9:16垂直）

### 步骤2：Prompt构建
构建图像生成Prompt，包含：
1. **基础设定**：产品类型 + 垂直海报 + Kawaii风格
2. **配色方案**：具体颜色描述
3. **装饰元素**：根据卖点选择
4. **布局结构**：中心对称构图描述
5. **文案位置**：Slogan + 副标题 + CTA
6. **氛围描述**：梦幻、甜美、少女感

### 步骤3：生成与优化
- 使用 `image_synthesize` 工具生成海报
- 评估效果并根据需要调整Prompt
- 交付最终海报文件

## Prompt模板

```
A beautiful vertical marketing poster for {product_type}, designed in cute kawaii style for young women. Features: soft pastel {primary_color} and {secondary_color} color palette, {decorative_elements}, elegant product showcase in center, soft gradient background, dreamy bokeh lights, stylized text placeholders, feminine and romantic atmosphere, high quality graphic design, advertisement poster style, vertical portrait orientation, {aspect_ratio} aspect ratio.
```

## 输出规范

- **文件格式**：PNG
- **尺寸比例**：9:16（垂直海报标准）
- **保存路径**：`/workspace/{产品名}_poster.png`
- **质量标准**：高分辨率、清晰文字、色彩协调

## 质量检查清单

- [ ] 垂直海报比例正确（9:16）
- [ ] 配色协调统一，无突兀色彩
- [ ] 产品展示位置醒目
- [ ] 装饰元素与卖点契合
- [ ] 文案层次清晰可读
- [ ] 整体风格少女感、甜美度达标
- [ ] 适合移动端传播
