# 工作总结整理技能 - 使用说明

## 功能概述

本技能用于将多份周工作总结整理成结构化的月度或年度工作总结Word文档。

## 使用场景

1. **整理月度工作总结**：用户提供当月的周工作总结（4-5份），自动合并生成月度总结
2. **整理年度工作总结**：用户提供当年的月度工作总结（12份），自动合并生成年度总结

## 使用方法

当用户提供周工作总结文档并要求整理时：
1. 读取所有文档内容
2. 按业务模块分类
3. 合并重复工作
4. 生成Word文档

## 技术细节

### 依赖工具
- `python-docx`: Python文档处理库
- `LibreOffice (soffice)`: 文档格式转换

### 文件结构
```
work-summary-compiler/
├── SKILL.md              # 技能定义文件
├── scripts/
│   ├── read_docs.py      # 读取文档脚本
│   └── create_summary.py # 生成文档脚本
└── docs/
    └── usage_guide.md    # 使用指南（本文件）
```

## 注意事项

1. **原始格式**：源文件为`.doc`格式，需要先转换为`.docx`
2. **内容保真**：合并时保持原文语义，不随意删改
3. **去重策略**：例行工作保留一次，重点工作详细展开
4. **分类逻辑**：按业务模块（考勤、薪酬、招聘等）分类
