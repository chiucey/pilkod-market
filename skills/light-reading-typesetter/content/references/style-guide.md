# 轻阅读·收账风格设计指南

## 设计理念

**轻阅读**强调的是让阅读变得轻松愉悦，降低认知负担。**收账风格**则源于日本传统美学，追求简约、留白、自然的视觉体验。两者的结合，创造出一种宁静雅致、易于沉浸的阅读氛围。

## 字体选择

### 推荐字体组合

**网页/电子阅读：**
- 标题：思源黑体 Medium / Noto Sans SC
- 正文：思源宋体 Regular / Noto Serif SC
- 英文辅助：EB Garamond

**印刷出版：**
- 标题：方正字体
- 正文：宋体 / 明朗体

### 字体大小规范

```
标题 H1：28pt / 1.75rem
标题 H2：22pt / 1.375rem
标题 H3：18pt / 1.125rem
正文：14pt / 1rem
注释：12pt / 0.875rem
```

## 插图设计规范

### 风格要求

1. **水墨风格**：意境悠远，线条流畅
2. **极简线条**：去繁就简，点到即止
3. **扁平插画**：色块柔和，轮廓清晰
4. **噪点纹理**：增添质感，柔和过渡

### 尺寸规格

| 类型 | 宽度 | 高度 | 位置 |
|------|------|------|------|
| 全页插图 | 100% | auto | 章节首页 |
| 半页插图 | 60% | auto | 段落间 |
| 小型装饰 | 30% | auto | 引用块 |
| 微型图标 | 24px | 24px | 列表项 |

## 占位符设计

### 设计原则

1. **视觉协调**：与整体风格一致
2. **信息清晰**：明确标注为占位符
3. **易于替换**：便于后续填充真实图片

### 推荐样式

```html
<!-- 样式一：简约文字占位符 -->
<div class="img-placeholder">
  <span class="placeholder-icon">✦</span>
  <span class="placeholder-text">[意境插图]</span>
</div>

<!-- 样式二：虚线边框占位符 -->
<div class="img-placeholder bordered">
  <span class="placeholder-text">此处应有装饰插图</span>
</div>

<!-- 样式三：渐变背景占位符 -->
<div class="img-placeholder gradient">
  <span class="placeholder-text">等待插画师创作</span>
</div>
```

## 质量检验标准

### 可读性检查

- [ ] 文字与背景对比度 ≥ 4.5:1
- [ ] 正文字号 ≥ 14pt
- [ ] 行高 ≥ 1.6 倍
- [ ] 段落间距合理，不拥挤

### 视觉一致性

- [ ] 全书色彩体系统一
- [ ] 字体使用规范一致
- [ ] 插图风格协调
- [ ] 留白比例适当

### 响应式适配（如电子版）

- [ ] 桌面端阅读体验佳
- [ ] 平板端排版正常
- [ ] 移动端可读性强
