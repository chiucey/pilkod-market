# 公文写作培训技能

## 核心分析框架

### 一、结构拆解（宏观）

分析文章整体框架，识别以下结构类型：

| 结构类型 | 特征 | 适用场景 |
|---------|------|---------|
| 总分总 | 意义引入→主体分析→对策→总结 | 策论文、评论文章 |
| 并列式 | 各段落平行排列分论点 | 部署类通知、意见 |
| 递进式 | 层层深入（背景→现状→对策） | 调研报告、请示 |
| 纵贯式 | 时间/逻辑顺序贯穿 | 工作总结、汇报 |
| 交叉式 | 纵横结合 | 综合性报告 |

**重点学**：
- 标题与中心论点的关系
- 段落之间的逻辑链条
- 开头引入方式（背景/数据/问题/政策）
- 结尾如何首尾呼应

### 二、论证逻辑（中观）

**整体论证**：
- 各分论点如何服务中心论点
- 政治逻辑与文章逻辑的统一
- 引用最新权威论断的使用方式

**段落展开模式**：
- 主旨句 + 论证展开 + 结论
- 主旨句 + 理论/现状阐述 + 案例 + 结论
- 分点陈述对策（链条式写法）

**常见逻辑连接词**：
- 表因果：`因此、为此、由此可见`
- 表递进：`更重要的是、甚至、更值得关注`
- 表转折：`然而、但与此同时、值得注意的是`
- 表对策：`必须、应当、亟需、亟须`

### 三、语言表达（微观）

**经典句式积累**：
- `只有……才能……`
- `以……为抓手/突破口/着力点`
- `推动……向纵深发展`
- `坚持……导向/目标/原则`
- `把……作为……的重中之重`
- `实现……全覆盖/零突破/新跨越`

**修辞手法**：
- 八字短句开头（增强气势）
- 排比（增强说服力）
- 设问（引发思考）
- 比喻（形象生动）

**政策热词积累**：
政治表态类、改革部署类、民生关切类、生态文明类、党建引领类

### 四、金句与标题

**小标题特征**：
- 对仗工整
- 字数一致
- 体现工作领域关键词
- 体现成效/方向

**常见标题句式**：
- 动宾结构：以X为Y
- 主谓结构：X是Y的Z
- 对联结构：字数相同、词性相对

## 工作流程

### 步骤1：获取当日文章列表

从以下来源获取当日《人民日报》文章列表：

```
https://paper.people.com.cn/rmrb/pc/layout/<YYYYMMDD>/node_01.html
```

（替换 YYYYMMDD 为目标日期，如 20260423）

使用 extract_content_from_websites 工具提取当日所有文章链接。

### 步骤2：筛选5篇最有价值的文章

优先选择标准：
1. 第五版"评论"版（人民时评）文章（★★★★★）
2. 头版要闻中政策导向明确的文章（★★★★）
3. 理论版有深度的解读文章（★★★★）
4. 涉及改革、民生、党建等通用主题（★★★★★）

选择结果须涵盖不同主题，优先选择：
- 结构新颖的文章（总分总以外的结构）
- 论证技巧独特的文章
- 语言表达有亮点的文章
