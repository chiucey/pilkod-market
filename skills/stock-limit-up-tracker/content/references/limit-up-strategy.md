# 涨停板打板策略参考指南

## 一、涨停板基础概念

### 1.1 什么是涨停板
- A股市场实行涨跌停制度，普通股票日涨跌幅限制为10%
- ST股票涨跌幅限制为5%
- 科创板、创业板实行20%涨跌幅限制
- 新股上市首日无涨跌幅限制

### 1.2 涨停板类型

#### 按封板时间分类
| 类型 | 特征 | 含义 |
|------|------|------|
| 一字板 | 开盘即涨停全天未打开 | 极强，但次日可能无参与机会 |
| 早盘板 | 上午10:30前封板 | 强势，市场认可度高 |
| 午盘板 | 10:30-14:00封板 | 中等强度 |
| 尾盘板 | 14:00后封板 | 较弱，可能存在资金诱多 |

#### 按封板质量分类
| 类型 | 特征 | 风险 |
|------|------|------|
| 硬板/缩量板 | 封板后成交稀少 | 较稳健，次日溢价率高 |
| 烂板 | 反复打开封上 | 风险较高，需观察次日 |
| 排板 | 涨停价大量排队 | 能否成交不确定 |
| 扫板 | 主动吃货涨停 | 主力意图明显 |

## 二、打板策略体系

### 2.1 首板策略（首涨停）

**适用条件：**
- 板块出现政策或消息利好
- 个股处于低位启动
- 成交量温和放大
- 封板时间早、封单量大

**选股标准：**
1. 流通市值50亿以下为佳
2. 所属板块是当日热点
3. 封板前有明显的拉升吸筹迹象
4. 封板后抛压小

### 2.2 连板策略

**二板定龙头：**
- 市场中真正有价值的连板股往往从二板开始确认
- 二板放量检验个股股性和市场认可度
- 强势股二板往往是最佳介入点

**连板股特征：**
- 每日高开或一字开盘
- 封板时间越来越早
- 成交量持续萎缩（缩量加速）
- 所属板块持续发酵

### 2.3 龙头战法

**龙头股特征：**
- 板块内涨幅最大、封板最早
- 具有带动板块整体上涨的影响力
- 拥有独特题材或稀缺性
- 资金参与度高、流动性好

**操作要点：**
- 只做板块最强的那只
- 错过龙头不做跟风
- 龙头首阴可博弈反包

## 三、风险控制

### 3.1 止损原则
- 买入后次日走势不及预期，果断离场
- 亏损控制在-7%以内
- 炸板当日不能回封必须出局

### 3.2 仓位管理
- 单只股票仓位不超过总资金的20%
- 打板仓位控制在30%-50%
- 保留足够子弹应对突发情况

### 3.3 禁止事项
- ❌ 不抄底跌停股
- ❌ 不在尾盘封板时追入
- ❌ 不买ST股和问题股
- ❌ 不重仓单只股票
- ❌ 不逆势操作

## 四、市场情绪判断

### 4.1 情绪指标
| 指标 | 良好 | 恶劣 |
|------|------|------|
| 涨停家数 | >50家 | <20家 |
| 跌停家数 | <10家 | >30家 |
| 昨日涨停今表现 | >3% | <-2% |
| 炸板率 | <30% | >50% |

### 4.2 情绪周期
1. **启动期**：龙头股出现，板块开始发酵
2. **高潮期**：板块全面爆发，涨停家数激增
3. **退潮期**：龙头股炸板，跟风股大跌
4. **冰点期**：涨停家数骤降，跌停增加

## 五、数据分析方法

### 5.1 封板率计算
```
封板率 = 封住涨停的时间 / 交易时间 × 100%
```

### 5.2 相对强度指标
```
RS = 个股涨幅 / 大盘涨幅
RS > 1.5 为强势股
```

### 5.3 主力资金净流入
监控大单净流入，判断主力参与程度。
