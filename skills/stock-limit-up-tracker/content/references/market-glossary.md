# 股票打板术语词典

## A-C

| 术语 | 解释 |
|------|------|
| **打板** | 在股票涨停的瞬间买入 |
| **排板** | 在涨停价挂单排队等待成交 |
| **扫板** | 主动在涨停价买入，吃掉所有卖单 |
| **封板** | 股价涨停并封住涨停板 |
| **破板/炸板** | 涨停板被打开，股价回落 |
| **硬板** | 封板后成交稀少，极为强势 |
| **烂板** | 涨停板多次被打开 |
| **缩量板** | 成交量小于昨日，强势信号 |
| **放量板** | 成交量大于昨日，需分析 |
| **一字板** | 开盘即涨停，全天未打开 |
| **T字板** | 开盘涨停，中间打开又封上 |
| **首板** | 股票近期第一次涨停 |
| **二板** | 连续第二个涨停 |
| **连板/几连板** | 连续多个涨停 |
| **妖股** | 走势异常强劲的股票 |
| **龙头** | 板块中涨幅最大、带动性最强的股票 |
| **跟风** | 跟随龙头上涨的股票 |
| **卡位** | 在龙头停牌期间顶替龙头位置的股票 |

## D-F

| 术语 | 解释 |
|------|------|
| **地板** | 跌停板 |
| **翘板** | 从跌停板拉起 |
| **反包** | 吃掉昨日上影线或阴线 |
| **弱转强** | 从烂板转为硬板 |
| **强转弱** | 从硬板转为烂板 |
| **助攻** | 跟风股封板帮助龙头稳固 |
| **砸盘** | 大额卖出导致股价下跌 |
| **点火** | 启动拉升的第一笔大单 |
| **拉升** | 股价快速上涨 |
| **洗盘** | 主力洗掉浮筹的动作 |
| **吸筹** | 主力收集筹码 |
| **出货** | 主力卖出筹码 |

## G-I

| 术语 | 解释 |
|------|------|
| **换手** | 成交量/流通股本 |
| **高换手** | 换手率超过20% |
| **低换手** | 换手率低于5% |
| **量比** | 当日每分钟平均成交量/过去5日每分钟平均成交量 |
| **量能** | 成交量的俗称 |
| **倍量** | 成交量是昨日的一倍以上 |
| **堆量** | 成交量逐步放大 |
| **缩量** | 成交量逐步缩小 |
| **分歧** | 多空双方力量相当 |
| **一致** | 市场预期高度统一 |

## J-L

| 术语 | 解释 |
|------|------|
| **竞价** | 开盘前/收盘前的集合竞价 |
| **高开** | 开盘价高于昨日收盘价 |
| **低开** | 开盘价低于昨日收盘价 |
| **平开** | 开盘价等于昨日收盘价 |
| **溢价** | 次日开盘涨幅超过昨日涨停价 |
| **溢价率** | (次日开盘价-昨日涨停价)/昨日涨停价 |
| **核按钮** | 跌停价挂单卖出 |
| **天地板** | 从涨停到跌停 |
| **地天板** | 从跌停到涨停 |
| **龙虎榜** | 当日涨跌幅偏离值达7%的股票名单 |

## M-O

| 术语 | 解释 |
|------|------|
| **市值** | 股价×总股本 |
| **流通值** | 股价×流通股本 |
| **小市值** | 流通市值较小，通常更具弹性 |
| **大盘** | 上证指数 |
| **创业板** | 300开头，20%涨跌幅 |
| **科创板** | 688开头，20%涨跌幅 |
| **主板** | 600/000开头，10%涨跌幅 |
| **北交所** | 8开头，30%涨跌幅 |

## P-R

| 术语 | 解释 |
|------|------|
| **PE** | 市盈率 |
| **PB** | 市净率 |
| **MACD** | 指数平滑异同移动平均线 |
| **KDJ** | 随机指标 |
| **RSI** | 相对强弱指标 |
| **MA** | 移动平均线 |
| **K线** | 蜡烛图 |
| **上影线** | 最高价与收盘价的差 |
| **下影线** | 开盘价与最低价的差 |

## S-U

| 术语 | 解释 |
|------|------|
| **情绪** | 市场整体做多或做空氛围 |
| **高潮** | 市场情绪达到顶峰 |
| **退潮** | 市场情绪开始回落 |
| **冰点** | 市场情绪极度低迷 |
| **修复** | 从冰点恢复 |
| **主线** | 当期市场最强热点 |
| **支线** | 次要热点 |
| **一日游** | 热点持续一天即消退 |
| **板块** | 具有相同属性的股票集合 |
| **联动** | 板块内股票同涨同跌 |

## V-X

| 术语 | 解释 |
|------|------|
| **庄股** | 有主力高度控盘的股票 |
| **庄家** | 运作股票的主力资金 |
| **散户** | 中小投资者 |
| **游资** | 短线操作的热钱 |
| **机构** | 基金公司、券商等 |
| **主力** | 主导股价运行的大资金 |

## Y-Z

| 术语 | 解释 |
|------|------|
| **溢价** | 超出正常价值的部分 |
| **预期** | 市场对股票的上涨预期 |
| **兑现** | 预期变成现实 |
| **落袋** | 获利了结 |
| **割肉** | 亏损卖出 |
| **踏空** | 错过上涨行情 |
| **套牢** | 买入后亏损无法卖出 |
| **解套** | 从亏损回到成本价 |
| **回本** | 回到买入成本 |
| **止损** | 亏损到一定程度卖出 |
| **止盈** | 获利到一定程度卖出 |
| **锁仓** | 持有不动 |
| **加仓** | 增加持仓 |
| **建仓** | 初次买入 |
| **清仓** | 全部卖出 |
