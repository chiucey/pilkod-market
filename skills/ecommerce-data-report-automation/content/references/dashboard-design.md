## 二、图表设计规范

### 2.1 KPI 卡片

| 指标 | 计算方式 | 展示格式 | 颜色规则 |
|------|----------|----------|----------|
| 总完成量 | Σ实际/Σ目标×100% | 百分比，1位小数 | >=100%绿色，>=80%黄色，<80%红色 |
| 控比 | Σ实际花费/Σ预算×100% | 百分比，1位小数 | <100%绿色，100-105%黄色，>105%红色 |
| 同比增长 | (本期-上期)/上期×100% | 百分比，1位小数 | 正值绿色，负值红色 |
| 发布进度 | 已发布/计划发布×100% | 百分比，1位小数 | >=80%绿色，>=50%黄色，<50%红色 |

## 三、工具选型建议

### 3.1 Tableau

**优点：**
- 交互性强
- 连接数据源丰富
- 可视化效果好

**适用场景：**
- 数据分析师使用
- 需要复杂交互的仪表盘
- 连接数据库实时数据

### 3.2 Power BI

**优点：**
- 与 Microsoft 生态集成好
- DAX 公式强大
- 免费版本功能完整

**适用场景：**
- 企业内部使用
- 需要与 Excel/Teams 集成
- 中小型数据集

### 3.3 Excel 图表

**优点：**
- 无需额外工具
- 制作快速
- 输出格式通用

**适用场景：**
- 快速原型制作
- 简单日报
- 非技术人员使用

### 3.4 Python (Plotly/Altair)

**优点：**
- 可自动化生成
- 支持自定义程度高
- 可嵌入网页

**适用场景：**
- 需要自动化更新
- 与数据处理脚本集成
- Web 应用内嵌

## 四、交互功能设计

### 4.1 筛选器

| 筛选类型 | 选项 | 默认值 | 联动 |
|----------|------|--------|------|
| 日期范围 | 今日/本周/本月/自定义 | 本周 | 更新所有图表 |
| 产品系 | 全部/A7/A8/A10 | 全部 | 更新所有图表 |
| 平台 | 全部/京东/天猫/抖音/小红书/B站 | 全部 | 更新所有图表 |

### 4.2 导出功能

- **导出 Excel**：导出当前筛选后的数据
- **导出 PDF**：导出当前视图的 PDF 快照
- **导出图片**：导出单个图表为 PNG

### 4.3 订阅功能

- 设置定时刷新（每小时/每天）
- 设置定时邮件发送
- 支持只发送异常数据
