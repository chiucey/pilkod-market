# v6 评分模型详解

## 评分公式

```
综合评分 = (vp_score × 0.55 + f4_score × 0.45)

vp_score = (今日vp + 3) / 6 × 10
         取值范围：0~10

f4_score = 均线多空 × 0.30
          + 潜在动能 × 0.25
          + 动能强度 × 0.25
          + 趋势位置 × 0.20
```

---

## 今日强弱（vp）

| 今日涨跌 | vp值 | 标签 |
|---------|------|------|
| ≥ +9.5% | +2.0 | 涨停 |
| +7% ~ +9.5% | +1.5 | 大涨 |
| +4% ~ +7% | +1.0 | 上涨 |
| 0% ~ +4% | +0.5 | 微涨 |
| -3% ~ 0% | -0.5 | 震荡 |
| < -3% | -1.5 | 下跌 |

---

## 四力指标

### ① 均线多空（ma）
反映当前位置相对均线的强弱，取值0~70：

| 10日涨幅 | ma |
|---------|-----|
| < 15% | max(20, 30 + c10/15×20) |
| 15% ~ 50% | 70 |
| 50% ~ 80% | max(30, 70-(c10-50)/30×40) |
| > 80% | 25 |

### ② 潜在动能（pot）
```pot = min(40, c10 / 5 × 8)```
- 低位启动 → 潜在动能大
- 高位滞涨 → 潜在动能耗尽

### ③ 动能强度（kin）
```python
if 今日涨跌 > 0: kin = min(45, 今日涨跌% × 3 + 10)
else:            kin = max(-15, 今日涨跌% × 2)
```

### ④ 趋势位置（f4综合分）
f4 = ma×0.3 + 80×0.25 + kin×0.25 + pot×0.2

## 位置判断

| 10日涨幅 | 位置 |
|---------|------|
| < 30% | 低位 |
| 30% ~ 80% | 中位 |
| > 80% | 高位 |

## 位置 × 节奏联合判断（核心经验）

### 低位（10日涨幅 < 30%）
| 节奏 | 判断 | 操作 |
|------|------|------|
| 连续放量 | 主力建仓 | ✅ 买入 |
| 连续缩量 | 锁定筹码 | ✅ 买入 |
| 放缩交替 | 最健康形态 | ✅ 买入 |

### 中位（10日涨幅 30%~80%）
| 节奏 | 判断 | 操作 |
|------|------|------|
| 涨停/大涨 + 缩量 | 主升浪 | ✅ 买入 |
| 放缩交替 | 健康慢牛 | ✅ 买入 |
| 连续放量 | ⚠️ 警惕派发 | ⚠️ 观望 |
| 高位连续缩量 | 临界爆发 | ⚠️ 观望 |

### 高位（10日涨幅 > 80%）
| 节奏 | 判断 | 操作 |
|------|------|------|
| 放缩交替 | 高位震荡 | ⚠️ 观望 |
| 连续放量 | 🔴 主力派发 | 🔴 离场 |
| 连续缩量 | 🔴 撑不住 | 🔴 离场 |

## 10日换手率风险阈值

| 换手率 | 含义 | 风险 |
|--------|------|------|
| < 30% | 极度低换，主力锁仓 | ✅ 优质 |
| 30% ~ 80% | 正常换手 | ✅ 健康 |
| 80% ~ 150% | 偏高 | ⚠️ 警惕 |
| > 150% | 高位派发风险 | ⚠️ 危险 |
| > 200% | 超高换手 | 🔴 离场 |

---

## 风险标志优先级

1. **🔴 高位派发**：10日涨幅>80% + 换手>150%
2. **🔴 超活跃换手**：10日换手>200%
3. **🔴 离场**：综合评分<4.0
4. **⚠️ 高位警戒**：10日涨幅>80%
5. **⚠️ 超活跃**：10日换手>200%
