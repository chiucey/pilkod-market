# v7 评分模型详解

## 综合评分公式

```
综合 = v6_score × 0.65 + dragon_score × 0.35

v6_score（0~10）= 今日量价vp × 0.55 + 四力f4 × 0.45
dragon_score（0~10）= 资金活性 + 板块引领 + 情绪锚定
```

---

## v6：今日量价 + 四力

### 今日强弱（vp）

| 今日涨跌 | vp |
|---------|-----|
| ≥ +9.5% | +2.0 |
| +7%~+9.5% | +1.5 |
| +4%~+7% | +1.0 |
| 0%~+4% | +0.5 |
| < 0% | -1.5 |

### 四力（f4）

| 维度 | 权重 | 说明 |
|------|------|------|
| 均线多空 | 30% | 15%~50%区间最强 |
| 潜在动能 | 25% | 10日涨幅映射 |
| 动能强度 | 25% | 今日涨跌驱动 |
| 趋势位置 | 20% | 综合估值 |

---

## 龙头地位（dragon_score）

### 资金活性（5分）— 最关键

| 今日换手率 | 得分 | 说明 |
|-----------|------|------|
| 15%~40% | **5.0** | 黄金换手，主力主导 |
| 8%~15% | 4.0 | 正常 |
| 40%~60% | 3.5 | 偏高但健康 |
| 3%~8% | 2.5 | 偏低 |
| >60% | 2.0 | 接力过度 |
| <3% | 1.0 | 不活跃 |

### 板块引领（3分）

| 今日涨跌 | 得分 |
|---------|------|
| ≥+9.5% | 3.0 |
| +7%~+9.5% | 2.5 |
| +5%~+7% | 2.0 |
| +3%~+5% | 1.5 |
| 0%~+3% | 1.0 |
| <0% | 0.0 |

### 情绪锚定（2分）

振幅稳健（5%~20%）= 1.5分；中小盘（流通<30亿）= 1.5分
