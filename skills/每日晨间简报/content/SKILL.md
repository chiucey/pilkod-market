# 每日晨报助手

## 技能定位

综合性每日资讯汇总工具，为用户提供全面、及时的晨间信息概览。

## 触发条件

以下任一场景触发本技能：
- 用户请求"晨报"、"日报"、"早报"、"今日简报"、"今日摘要"
- 询问今日天气、热点新闻、或综合资讯
- 需要每日资讯汇总和整理
- 任何与每日信息汇总相关的问题

## 晨报板块结构

| 板块 | 说明 |
|------|------|
| 天气 | 用户指定地点天气及未来3天预报（默认泉州） |
| 热点资讯 | 微博/小红书/知乎/国际热点各3条，每条附带简评 |
| 财经行情 | A股/美股/港股/大宗商品 |
| 加密货币 | BTC/ETH 等主流币种（币安数据） |
| 热点板块 | A股当日热门行业板块 |

## 执行工作流

### 阶段1：数据获取

#### 天气数据（wttr.in）
- **地点获取**：用户未指定地点时，默认使用"泉州"
- **API调用**：`https://wttr.in/{地点}?format=j1`
- **默认地址**：`https://wttr.in/Quanzhou?format=j1`

#### 热点资讯
```
微博热搜: "s.weibo.com 微博热搜榜 今日"
小红书: "新榜 小红书话题榜 今日" 或 "tophub.today 小红书"
知乎: "tophub.today 知乎热榜" 或 "zhihu.com 知乎热榜"
国际热点: "Google Trends world trending" 或 "CNN Reuters top news"
```

#### 财经行情（权威数据源）
```
新浪财经: "site:finance.sina.com.cn 上证指数 今日收盘"
东方财富: "site:eastmoney.com 创业板指 今日"
同花顺: "site:10jqka.com.cn 道琼斯 纳斯达克"
雪球: "xueqiu.com 美股三大指数"
Yahoo财经: "site:finance.yahoo.com Dow Jones Nasdaq S&P500"
```

#### 加密货币（币安数据）
```
搜索: "binance.com BTC ETH 价格 今日"
备用: "coinmarketcap.com crypto price today"
```

### 阶段2：数据解析与验证

1. 提取关键数据点
2. 验证数据时效性
3. 如某项数据缺失，使用 stocks_price 工具补充

## 数据源约束

### 权威财经数据源（按优先级）
1. **Yahoo Finance** - 国际市场首选
2. **新浪财经** - A股数据权威
3. **东方财富** - 板块数据详尽
4. **同花顺** - 技术分析工具
5. **雪球** - 社区数据分析

### 加密货币数据源
1. **Binance 币安** - 首选
2. **CoinMarketCap** - 备用

### 天气数据源
1. **wttr.in** - 唯一数据源
   - API：`https://wttr.in/{地点}?format=j1`
   - 默认地点：泉州（`https://wttr.in/Quanzhou?format=j1`）

### 热点数据源
1. **微博** - s.weibo.com 或 tophub.today 聚合
2. **小红书** - 新榜（newrank.cn）或千瓜数据
3. **知乎** - tophub.today 聚合
4. **国际** - Google Trends / CNN / Reuters / BBC / Twitter

## 数据精度规范

| 类型 | 规范 |
|------|------|
| 价格 | 保留1-2位小数 |
| 涨跌幅 | 保留2位小数（如 +1.23%） |
| 成交量 | 使用亿/万单位 |
| 时间戳 | YYYY-MM-DD 格式 |

## 错误处理

1. **数据获取失败**：尝试替代搜索词或 API
2. **数据过期**：明确标注数据日期
3. **部分数据缺失**：标注"获取中"，不影响其他板块
