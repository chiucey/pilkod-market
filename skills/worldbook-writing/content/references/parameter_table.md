# 参数速查表

## 完整参数对照

| 参数字段 | 作用 | 可选值/范围 | MMD 平台约束 |
|---------|------|------------|------------|
| `comment` | 条目中文名称（AI不可见） | 任意中文字符串 | 建议格式：【类型-内容】 |
| `disable` | 启用/停用开关 | `false`（启用）/ `true`（停用） | 无特殊约束 |
| `constant` | 常量条目（常驻内存） | `true` / `false` | `true` 时每次打包必检 |
| `position` | 同一 depth 下的优先级 | 整数，数字越小越优先 | 1-10=核心规则，11-30=重要NPC，51+=物品/Lore |
| `role` | 角色类型（决定插入帮派） | `0`=默认 / `system`=`插入system` / `user`=`插入user` / `assistant`=`插入assistant` | 见"角色帮派约束" |
| `depth` | 电梯帮插入楼层（仅电梯帮有效） | 0-99整数 | 天台帮无 depth；0~3⚠️过强；4~6✅推荐；≥21⚠️无效 |
| `order` | 末位淘汰优先级（数字越大越优先上车） | 0-9999整数 | 角色人设默认10000，为最高优先级 |
| `probability` | 触发概率（仅绿灯有效） | 0-100整数 | 蓝灯下此参数无效 |
| `key` | 主要关键词数组（繁简双版本必填） | 字符串数组，最多5个 | 必须包含简体+繁体；无递归扫描 |
| `keysecondary` | 次要关键词数组（AND附加条件） | 字符串数组 | 必须与主要关键词同时出现才触发 |
| `content` | 叙事主体（AI实际读取的内容） | 字符串，最多3000字 | 必须含主语；禁止游戏系统语言 |
| `uid` | 条目唯一标识符 | 字符串，建议与order对应 | 推荐三位数字，如"001" |

## 触发条件详解（蓝灯 vs 绿灯）

| 维度 | 🔵 蓝灯（常驻） | 🟢 绿灯（关键词） |
|------|--------------|----------------|
| 触发方式 | 无条件塞入 | 满足关键词+概率才触发 |
| 概率参数 | ❌ 无效（忽略） | ✅ 有效（0~100） |
| 适用场景 | 核心规则、必须生效的设定 | 条件性设定、随机事件 |
| 排序优先性 | 与绿灯同等排队 | 与蓝灯同等排队 |

## 深度建议值

| 深度值 | 效果 | 推荐场景 |
|-------|------|---------|
| 0 | 比最新输入还靠下，极强干预 | ⚠️ 慎用，可能扭曲正常推演 |
| 1-3 | 极强印象，如"贴着耳朵喊" | 仅用于紧急覆盖或紧急修正 |
| **4-6** | **最佳区间，前几分钟回忆感** | ✅ **默认推荐值** |
| 7-20 | 中等印象 | 可用于次要剧情设定 |
| 21-99 | 位于聊天深处 | ⚠️ 基本无效，建议检查设计 |
| 无（天台帮） | 固定在顶端，无深度概念 | 核心规则、角色设定 |

## 顺序（Order）分配建议

| 设定类型 | 推荐顺序值 | 淘汰风险 |
|---------|----------|---------|
| 角色人设（默认） | 10000 | 永不淘汰（最高优先） |
| 核心NPC设定 | 9000-9998 | 极低 |
| 世界观背景 | 5000-8999 | 低 |
| 重要场景 | 1000-4999 | 中 |
| 支线场景 | 500-999 | 中高 |
| 物品/道具 | 100-499 | 高 |
| Lore/背景知识 | 10-99 | 极高 |
| 测试/临时条目 | 1-9 | 首批淘汰 |

## 关键词设计规范

### 扫描规则
- 扫描范围：最新4条消息（固定，不可改）
- 匹配方式：字符串精确匹配（区分简繁）

### 推荐关键词格式
```json
"key": ["关键词", "關鍵詞"]
```

### 触发条件速查
| 条件组合 | 是否触发 |
|---------|---------|
| 主要关键词出现 + 无次要关键词 | ✅ 触发（按概率） |
| 主要关键词出现 + 次要关键词也出现 | ✅ 触发（按概率） |
| 仅次要关键词出现 | ❌ 不触发 |
| 主要关键词出现多次 | 仅首次计一次 |
| AI 输出繁体，关键词仅填简体 | ❌ 不触发（常见bug） |
