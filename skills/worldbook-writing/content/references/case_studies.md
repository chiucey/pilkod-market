# 惨案现场与正确写法对照

## 惨案一：角色当场变性（最常见致命错误）

### 错误示范：全绿灯导致角色登场时信息缺失

**设定：**
```
蓝灯（角色卡主栏）：小美，小红，小岚是光明小学的学生
绿灯世界书（关键词：小美）：小美是男的，三年级，光头
```

**实际发生：**
```
回合1 用户：去光明小学看看
回合1 AI回复：小美穿着超短裙在跳皮筋，双马尾在脑后飞扬
  （绿灯未触发，AI根据默认数据库猜测"小美=女孩"）

回合2 用户：推倒她
回合2 AI回复：小美说："对不起，其实我是光头男"
  （绿灯触发，但已与回合1的描述矛盾——当场变性）
```

### 正确示范：显隐分离

```
✅ 蓝灯（显性锚点，无妥协余地）：
   小美，女，三年级学生，总是扎着双马尾，性格开朗

✅ 绿灯（隐性触发，保护秘密）：
   关键词：小美，脱衣服，检查光头
   仅{{user}}主动触发时才告知——
   小美剃了光头，这是她与某种地下仪式的秘密契约
```

## 惨案二：省略主语导致 AI 自我混淆

### 错误示范

```json
{
  "comment": "【NPC-小明】",
  "key": ["小明"],
  "content": "男，18岁，高中生，父母在海外"
}
```
**AI 实际理解为：**
> "小明"只是一个激活暗号，content里完全没有提到"小明"是谁。
> AI可能这样理解：哦？content里说"他是男的"——等等，谁是"他"？

### 正确示范

```json
{
  "comment": "【NPC-小明】",
  "key": ["小明", "小明"],
  "content": "小明，男，18岁，高中生，父母在海外，从小由外婆抚养"
}
```

## 惨案三：关键词无繁简导致失效

### 错误示范

```json
"key": ["张总", "陈老板"]
```
**实际情况：**
AI 在某次回复中生成了"張總"（繁体），但关键词只有简体"张总" → 关键词失效，世界书不触发。

### 正确示范

```json
"key": ["张总", "張總", "陈老板", "陳老闆"]
```

## 惨案四：递归套娃失败

### 错误示范

```
世界书A（关键词：水果）
  内容：……香蕉……（香蕉两个字的出现试图触发世界书B的关键词"香蕉"）

世界书B（关键词：香蕉）
  内容：香蕉是一种水果……
```

**平台预判：** 关键词只在聊天记录中扫描，不在世界书内容中扫描。香蕉这两个字在世界书A的内容里出现，**不会**触发世界书B。

## 惨案五：深度过大导致"无效条目"

### 错误示范

```json
{
  "depth": 50,
  "content": "关于蓉城地下排水系统的秘密……"
}
```

**实际情况：** depth=50 意味着这条设定被插入到聊天记录第50层楼之下，在实际对话中基本不会被 AI 的专注力覆盖，等于石沉大海。

### 正确示范

```json
{
  "depth": 5,
  "content": "蓉城地下排水系统的历史可追溯到三百年前……"
}
```

## 惨案六：顺序分配无层次导致核心设定被淘汰

### 错误示范

```
所有世界书顺序都设为100
  → 每次触发末位淘汰时，所有条目按字数排
  → 核心NPC设定（300字）被边缘物品（50字）挤出
```

### 正确示范

```
核心NPC设定：        顺序 9000
世界观背景：         顺序 5000
蓉城人文地理（次要）：顺序 500
测试用物品（可淘汰）：顺序 10
```

## 惨案七：绿灯概率50%用于关键剧情

### 错误示范

```json
{
  "key": ["地下室"],
  "probability": 50,
  "content": "地下室有一条通往归墟教祭坛的暗道"
}
```

**实际问题：** 50% 概率意味着玩家进入地下室时，有一半的概率完全看不到暗道存在，关键剧情随机丢失。

### 正确示范

```json
{
  "key": ["地下室"],
  "probability": 100,
  "content": "地下室潮湿阴暗，墙角的旧木箱后面，隐约可见一道通往更深处的暗道"
}
```

> 随机性抽奖适合用于"奖励"类场景（宝物/稀有道具），**不适合**用于关键剧情线索和地图结构。
