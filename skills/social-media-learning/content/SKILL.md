# 跨平台学习助手

## Overview

专业的一站式学习内容采集与转化技能，整合抖音、小红书、YouTube 等主流社交平台的内容采集与知识消化功能。从平台采集原始学习内容，自动提取知识点，生成多种格式的学习材料（笔记、测验、幻灯片、思维导图、音频课程）。

---

## 核心工作原则

### 1. 原文优先
- 采集内容以原文形式记录，不做过度改写
- 保留原平台的表达风格和特色内容
- 整合归纳部分不超过总内容的15%

### 2. 多平台协同
- 支持抖音、小红书、YouTube 三大主流平台
- 自动识别内容来源并标注
- 支持跨平台内容关联和整合

### 3. 学习导向
- 以知识消化为目标，不止步于信息收集
- 自动提取核心概念和关键知识点
- 生成符合学习规律的系统化材料

### 4. 质量优先
- 确保内容准确性和完整性
- 根据目标受众调整输出深度
- 输出可直接使用的学习材料

## 完整工作流程

### 阶段1：需求确认

收到用户的跨平台学习需求后：

1. **确认学习主题**：明确用户想要学习的具体领域
2. **确认目标平台**：了解用户指定的具体平台（抖音/小红书/YouTube/全部）
3. **确认输出格式**：用户期望的学习材料类型
4. **确认受众水平**：学习内容的深度要求（入门/进阶/精通）

### 阶段2：平台内容采集

根据目标平台执行采集任务：

#### 抖音平台
- 访问抖音搜索页面，使用关键词搜索
- 收集搜索结果中的视频信息（标题、作者、点赞数）
- 深度采集：视频描述、评论区内容、字幕内容（如有）
- 提取话题标签和相关推荐

#### 小红书平台
- 访问小红书搜索页面，使用关键词搜索
- 收集笔记信息（标题、作者、收藏数）
- 深度采集：笔记正文、所有图片内容、完整评论区
- 提取话题标签和关联笔记

#### YouTube平台
- 访问YouTube搜索页面，使用关键词搜索
- 收集视频信息（标题、频道、观看量）
- 深度采集：视频描述、字幕内容（如有）、评论区
- 提取章节信息、播放列表、相关视频

#### 采集原则
- **禁止使用外部搜索引擎**搜索平台内容
- **必须通过浏览器工具直接访问**各平台完成操作
- 对每个平台执行穷尽式搜索（多组关键词）
- 完整浏览内容，不遗漏关键信息

### 阶段3：系列内容识别与关联分析

这是本技能的核心增强功能，专门处理博主系列内容的学习场景：

#### 3.1 系列内容识别

在采集过程中，**主动识别并标记系列内容**：

**识别信号**：
- **标题模式**：视频/笔记标题包含序号（如"第1集"、"Part 1"、"01"、"入门教程(1)"等）
- **合集标识**：平台提供的官方合集/播放列表功能（YouTube Playlist、小红书合集、抖音合集）
- **博主主页**：同一博主发布的多个相关主题内容
- **评论区提示**：评论中提到的"还有第X集"、"建议看下一个"等信息
- **关联推荐**：平台算法推荐的相关内容

**识别流程**：
1. 采集每个内容时，检查标题是否包含序号模式
2. 检查是否有官方合集/播放列表
3. 检查博主主页是否有其他相关内容
4. 查看评论区是否有系列提示
5. 检查平台关联推荐内容

**识别输出**：
```markdown
## 系列识别记录

### 系列A：[系列名称]
- **系列标识**：[合集名称/序号模式]
- **博主**：[博主名称]
- **已发现集数**：共X集，已采集X集
- **序号列表**：[01, 02, 03, ...]
- **集数状态**：
  - ✅ 已采集：01, 02, 03
  - ❌ 未采集：04, 05, 06
- **发现来源**：[标题序号/合集/博主主页/评论/关联推荐]
```

#### 3.2 系列内容完整采集

发现系列内容后，执行**系统性完整采集**：

**采集策略**：
1. **识别系列边界**：确定系列的开始和结束
2. **按顺序采集**：按照序号顺序逐一采集（01 → 02 → 03 → ...）
3. **跨集知识点标记**：记录每个知识点属于第几集
4. **依赖关系追踪**：记录哪些知识点需要前置知识

**采集检查清单**：
- [ ] 发现系列后，立即识别该系列的全部集数
- [ ] 采集前检查是否已有集数被采集过
- [ ] 优先采集序号靠前的基础集数
- [ ] 采集每集时，同时检查是否有新增的集数
- [ ] 直到系列完整或明确无更新后再进入下一阶段

**穷尽式采集原则**：
- 如果只采集了系列的前3集就说"完成"，这是**严重错误**
- 必须检查并尝试访问所有已知集数
- 对于长篇系列（如50集），优先确保有代表性的完整覆盖
- 采集完成后，**必须汇报**：本次采集覆盖了系列的全部/部分集数

#### 3.3 跨集知识关联分析

系列内容采集完成后，进行**系统性关联分析**：

**关联分析维度**：

| 分析维度 | 说明 | 分析示例 |
|----------|------|----------|
| **递进关系** | 知识点之间的前后依赖 | 第3集需要第1-2集的基础 |
| **扩展关系** | 同一知识点的不同角度 | 第1集讲原理，第2集讲实践 |
| **深化关系** | 从入门到精通的递进 | 第1集入门，第5集进阶 |
| **并列关系** | 同一层级的不同主题 | 摄影系列的不同题材 |

**关联分析输出**：
```markdown
## 系列知识关联图

### 知识体系结构

**前置知识**（必须先学）：
- [基础知识模块]

**核心内容**（按学习顺序）：
1. [第1集] → 基础知识入门
2. [第2集] → 核心概念讲解
3. [第3集] → 进阶技巧
4. [第4集] → 综合应用
5. [第5集] → 实战案例

**知识点依赖关系**：
- 集3 的 [知识点A] 依赖 集1 的 [知识点X]
- 集4 的 [知识点B] 依赖 集2-3 的 [知识点Y、Z]
- 集5 的 [实战项目] 需要 集1-4 的全部知识

**未覆盖集数**：
- [序号列表]，原因：[某平台访问限制/内容已删除/其他]
```

#### 3.4 整体理解与整合

在系列内容分析完成后，进行**整体性理解**：

**整体理解检查**：
1. **知识完整性**：该系列是否覆盖了主题的完整知识体系？
2. **学习路径**：按照什么顺序学习最高效？
3. **遗漏补充**：系列中是否有明显的内容缺口？是否需要其他来源补充？
4. **实际价值**：该系列相比其他系列，有什么独特价值？

**整合输出**：
```markdown
## 系列整体评估

### 知识覆盖度
- 核心概念：X/X 已覆盖
- 进阶内容：X/X 已覆盖
- 实战应用：X/X 已覆盖

### 学习建议
- 推荐学习顺序：[按序号/按主题]
- 必看集数：[列出最重要的集数]
- 可跳过集数：[如有]
- 需要补充的内容：[系列未覆盖的知识点]

### 与其他来源的整合
- 适合作为：[主要学习来源/补充材料/入门引导]
- 需要补充的知识点：[建议的其他学习来源]
```

### 阶段4：内容整理与分析

将采集到的内容进行系统化整理：

1. **去重与筛选**：移除重复内容，保留高质量相关资源
2. **主题分类**：按知识点或主题对内容进行分类
3. **核心提取**：识别每个内容片段的核心知识点
4. **关系梳理**：建立知识点之间的关联关系
5. **结构设计**：设计适合学习的知识结构

### 阶段4：学习材料生成

根据用户选择的格式生成学习材料：

1. **笔记生成**：将整理的内容转化为结构化笔记
2. **测验设计**：基于关键知识点设计交互式测验
3. **幻灯片制作**：制作适合讲解的视觉幻灯片
4. **思维导图构建**：绘制知识框架的视觉导图
5. **音频课程录制**：生成师生对话形式的音频课程

### 阶段5：交付与反馈

- 提交完整的学习材料包
- 询问是否需要补充或调整
- 根据反馈进行迭代优化

## 各平台操作指南

### 抖音

**网页版入口**：
- 抖音搜索：`https://www.douyin.com/search/关键词`

**搜索流程**：
1. 访问抖音搜索页面
2. 输入学习主题关键词
3. 切换排序方式（综合/最新/最热）
4. 记录搜索结果

**内容采集**：
1. 点击进入视频详情页
2. 记录视频描述和话题标签
3. 滚动查看评论区内容
4. 如有字幕，记录字幕内容

### 小红书

**网页版入口**：
- 小红书官网：`https://www.xiaohongshu.com`
- 搜索页面：`https://www.xiaohongshu.com/search_result?keyword=关键词`

**搜索流程**：
1. 访问小红书搜索页面
2. 输入学习主题关键词
3. 切换排序方式
4. 记录笔记列表

**内容采集**：
1. 点击进入笔记详情
2. 右划浏览所有图片，记录图片文字
3. 滚动查看完整正文
4. 下拉加载所有评论并记录

### YouTube

**网页版入口**：
- YouTube：`https://www.youtube.com`
- 搜索页面：`https://www.youtube.com/results?search_query=关键词`

**搜索流程**：
1. 访问YouTube搜索页面
2. 输入学习主题关键词
3. 切换排序和筛选条件
4. 记录视频列表信息

**内容采集**：
1. 点击进入视频页面
2. 记录视频标题、频道、发布时间
3. 复制视频描述内容
4. 滚动查看评论区
5. 如有字幕，使用字幕功能获取完整文本

## 常见错误避免

### 基础错误
1. **使用外部搜索引擎**：绝对禁止使用Google/Bing/百度等搜索平台内容
2. **采集不完整**：未浏览完整内容就结束采集
3. **忽略评论价值**：评论中常有重要的补充知识和真实反馈
4. **过度归纳**：整合总结内容超过15%
5. **来源缺失**：记录信息时未标注内容来源平台
6. **平台遗漏**：多平台任务只完成部分平台
7. **受众不匹配**：输出内容的深度与受众水平不符

### 系列内容相关错误（重点避免）

8. **系列识别遗漏** ❌❌❌
   - **错误**：发现一个视频就立即分析，没有检查该博主是否有其他相关系列内容
   - **正确**：采集每个内容时，必须检查博主主页、标题序号、合集标识

9. **系列采集不完整** ❌❌❌
   - **错误**：采集了系列的前3集就说"完成"，没有继续检查后续集数
   - **正确**：必须穷尽式检查所有已知集数，直到明确系列边界

10. **系列孤立分析** ❌❌
    - **错误**：把第5集当成独立内容分析，没有标注它依赖第1-4集的知识
    - **正确**：系列内容必须标注集数之间的依赖关系和递进关系

11. **系列更新未追踪** ❌❌
    - **错误**：采集时系列只有5集，一周后用户想学习才发现有第6-10集
    - **正确**：记录系列的当前状态和更新时间，后续可补充采集

12. **跨系列关系忽视** ❌❌
    - **错误**：只看单个系列内部的关联，没有发现不同系列的互补关系
    - **正确**：分析不同系列之间的知识互补性，提供整合学习路径

13. **系列完整性误报** ❌
    - **错误**：系列有10集，只采集了5集却报告"系列完整采集"
    - **正确**：必须诚实报告采集覆盖范围，如"已采集5/10集，缺5集"

## 与用户沟通规范

1. **开始前**：确认学习主题、目标平台、输出格式
2. **执行中**：每完成一个平台采集后简要汇报进度
3. **遇到问题**：如某平台内容过少，及时与用户沟通调整策略
4. **完成后**：提交完整的学习材料包，询问是否需要补充

## 工具使用优先级

1. **平台浏览器访问**：通过 `extract_content_from_websites` 直接访问各平台
2. **视频内容理解**：使用 `videos_understand` 分析视频关键内容
3. **图像内容识别**：使用 `images_understand` 提取图片文字信息
4. **音频内容处理**：使用 `listen_audio` 分析音频内容
5. **内容深度理解**：使用 `extract_content_from_websites` 提取完整网页内容
