# YouTube平台采集指南

## 平台概述

YouTube是全球最大的视频分享平台，月活跃用户超过20亿。内容特点：
- 内容深度和专业性强
- 长视频为主，信息密度高
- 自动字幕支持多语言
- 章节功能便于定位

## 访问方式

### 网页版入口
```
YouTube主页：https://www.youtube.com
搜索页面：https://www.youtube.com/results?search_query={关键词}
视频页面：https://www.youtube.com/watch?v={视频ID}
频道页面：https://www.youtube.com/@{频道名}
```

### 视频字幕获取
1. 点击视频下方的"更多"按钮
2. 选择"打开转录"
3. 复制完整字幕文本

## 搜索策略

### 关键词设计原则
1. **语言选择**：根据学习主题选择搜索语言
   - 英文内容通常更丰富
   - 中文内容更易理解
2. **关键词组合**：使用多个相关词
   - 示例：tutorial、guide、how to、tips
3. **内容类型**：明确想学的内容形式
   - tutorial：教程类
   - documentary：纪录片
   - lecture：讲座

### 搜索示例
| 学习主题 | 中文搜索 | 英文搜索 |
|----------|----------|----------|
| 机器学习 | 机器学习教程 | machine learning tutorial |
| 摄影 | 摄影教程 | photography tutorial |
| 烹饪 | 家常菜教程 | cooking tutorial |

## 内容采集规范

### 必采集信息
1. **视频基础信息**
   - 标题（完整记录）
   - 频道名称和链接
   - 发布时间
   - 观看次数、点赞数、评论数
   - 视频时长

2. **视频描述**（重点！）
   - 完整复制描述文字
   - 提取视频章节（如有）
   - 记录相关链接和资源
   - 提取时间戳标记

3. **字幕内容**（如有）
   - 使用转录功能获取完整字幕
   - 保留时间戳信息
   - 记录关键段落

4. **评论区内容**
   - 热门评论（高赞评论）
   - 有价值的问答内容
   - 资源推荐类评论
   - 补充说明类评论

## 特殊功能使用

### 章节功能
许多教育类视频会使用章节功能：
- 按时间戳定位内容
- 了解视频结构
- 快速跳转到想学的部分
- 记录章节间的知识关联

### 播放列表（系列内容识别）
**播放列表是YouTube识别系列内容最重要的方式！**

**识别方法**：
1. 视频描述中常包含播放列表链接（"Watch the full playlist: ..."）
2. 视频下方会显示所属播放列表
3. 频道主页有专门的"播放列表"标签页

**采集流程**：
```
1. 发现一个视频有播放列表 → 点击进入播放列表
2. 查看播放列表中的所有视频
3. 记录播放列表名称和总集数
4. 按顺序采集所有视频
5. 分析视频之间的关联关系
```

**播放列表采集记录格式**：
```
## 播放列表：[列表名称]
- 频道：@[频道名]
- 视频总数：X个
- 列表链接：https://www.youtube.com/playlist?list=xxx

### 视频清单
| 序号 | 标题 | 时长 | 状态 |
|------|------|------|------|
| 01 | 标题1 | 45:30 | ✅ |
| 02 | 标题2 | 38:15 | ✅ |
| 03 | 标题3 | 52:00 | ⚠️ |

### 集数关系
- 本系列为系统性教程
- 第3集需要第1-2集的基础
- 第5集为实战综合演练
```

### 频道系列识别
**进入频道主页查找系列内容**：
1. 点击视频下方的频道名称
2. 进入频道主页
3. 查看"视频"标签页
4. 筛选相同主题的系列视频
5. 检查是否有"播放列表"标签页

### YouTube Shorts
短视频内容：
- 适合快速了解某个知识点
- 可作为补充学习资源
- 质量参差不齐，注意筛选
- 通常不是系列内容的主力

## 学习内容识别

### 高质量内容特征
- 频道有专业背景或认证
- 视频有清晰的章节结构
- 描述中有相关资源链接
- 评论区反馈积极
- 有完整的知识体系

### 常见优质教育频道类型
- 大学课程（MIT OpenCourseWare等）
- 专业教程（各类技能教程）
- 科普频道（知识讲解类）
- 行业分析（深度解读类）

## 字幕处理

### 获取字幕的方法
1. **自动字幕**
   - 点击视频下方的"更多"
   - 选择"打开转录"
   - 复制即可

2. **手动字幕**
   - 部分视频有创作者上传的准确字幕
   - 质量更高，优先使用

3. **无字幕处理**
   - 使用视频理解工具分析内容
   - 记录视频中的关键画面
   - 根据画面推断内容

## 内容过滤

### 需要筛选的内容
- 点击诱饵标题
- 过度商业化内容
- 信息不完整的内容
- 评论区争议大的内容

### 优先选择
- 观看量高且观看/点赞比合理的
- 频道有持续更新历史
- 视频有章节标记
- 有配套资源或链接
