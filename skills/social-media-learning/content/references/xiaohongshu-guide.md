# 小红书平台采集指南

## 平台概述

小红书是中国领先的生活方式分享平台，月活跃用户超过2.6亿。用户群体以年轻人为主，内容特点：
- 图文并茂，视觉呈现丰富
- 真实用户分享，实用性强
- 种草属性强，方法步骤详细
- 适合教程类、攻略类、测评类内容

## 访问方式

### 网页版入口
```
小红书官网：https://www.xiaohongshu.com
搜索页面：https://www.xiaohongshu.com/search_result?keyword={关键词}
笔记详情：https://www.xiaohongshu.com/explore/{笔记ID}
```

### 移动端特点
- 瀑布流内容展示
-  swipe left 进入详情
- 图片以轮播形式展示
- 评论需点击展开

## 搜索策略

### 关键词设计原则
1. **场景关键词**：具体使用场景
   - 示例：护肤→早C晚A、美白、抗老
2. **人群关键词**：目标用户群体
   - 示例：学生党、宝妈、打工人
3. **效果关键词**：期望达成的效果
   - 示例：祛痘、去黑眼圈、显白
4. **对比关键词**：产品对比选择
   - 示例：测评、对比、红黑榜

## 内容采集规范

### 必采集信息
1. **笔记基础信息**
   - 标题（完整记录）
   - 作者昵称和主页链接
   - 发布时间
   - 点赞数、收藏数、评论数

2. **正文内容**
   - 完整复制正文文字
   - 保留原文排版和格式
   - 提取所有话题标签（#xxx）

3. **图片内容**（重点！）
   - 右划浏览所有图片
   - 记录每张图片的文字内容
   - 记录图片中的步骤流程
   - 记录图片中的产品/工具信息

4. **评论区内容**
   - 热门评论（点赞>50）
   - 有价值的问答内容
   - 作者回复
   - 补充信息类评论

- 最新：最新发布
- 最热：互动量最高

### 笔记合集（系列内容识别）
**小红书的系列内容识别需要结合多种方式！**

**识别方法**：
1. 笔记详情页下方有"专辑"入口
2. 标题包含序号模式（第1篇/Part 1等）
3. 评论区常有"还有续集"等提示
4. 博主主页有"专辑"标签页
5. 同一话题标签下的系列内容

**小红书系列识别信号**：
| 信号类型 | 示例 | 说明 |
|----------|------|------|
| 序号标题 | "护肤教程①"、"保姆级教程·入门篇" | 直接标明序号 |
| 专辑标识 | 笔记下方的专辑入口 | 官方系列组织 |
| 话题连续 | 同一#话题#下的多篇内容 | 隐性系列 |
| 评论区提示 | "求续集！"、"蹲后续" | 用户期待更多 |
| 关联推荐 | "相关阅读"推荐 | 系统识别关联 |

**专辑识别流程**：
```
1. 发现一篇笔记 → 检查是否有专辑标识
2. 点击进入专辑 → 查看所有笔记列表
3. 记录专辑名称和笔记数量
4. 检查笔记的发布顺序
5. 进入博主主页，查找更多专辑
```

**专辑采集记录格式**：
```
## 专辑：[专辑名称]
- 博主：@用户名
- 笔记总数：X篇
- 专辑链接：https://www.xiaohongshu.com/collection/xxx

### 笔记清单
| 序号 | 标题 | 发布时间 | 收藏 | 状态 |
|------|------|----------|------|------|
| ① | 标题1 | 2024-01 | 5.2万 | ✅ |
| ② | 标题2 | 2024-01 | 4.8万 | ✅ |
| ③ | 标题3 | 2024-02 | 3.1万 | ✅ |

### 系列结构分析
- 本专辑为系统性教程，共3篇
- 建议学习顺序：① → ② → ③
- 第②篇需要第①篇的基础
```

**博主主页查找系列**：
1. 点击博主名称进入主页
2. 查看是否有"专辑"标签
3. 滚动查看笔记列表，识别序号模式
4. 记录所有发现的专辑内容

**隐性系列识别**：
小红书很多系列没有官方专辑，需要通过：
1. 同一话题标签下的多篇内容
2. 标题的序号模式（如①、②或第一、第二）
3. 评论区的"求更新"提示
4. 作者回复中的"会持续更新"承诺

## 学习内容识别

### 高质量内容特征
- 有清晰的步骤流程
- 有实际效果对比图
- 评论区反馈积极
- 有详细的成分/方法说明

### 需要警惕的内容
- 软广告植入
- 夸大效果宣传
- 缺乏可操作性
- 评论区负面反馈多

## 注意事项

### 图片文字提取
小红书内容很多以图片为主，必须：
- 完整浏览所有图片
- 提取图片中的关键文字
- 识别步骤图中的流程顺序
- 记录产品图中的名称和规格

### 评论价值挖掘
评论区常包含：
- 用户的实际使用反馈
- 不同肤质/体质的适用情况
- 补充的使用技巧
- 替代产品推荐
