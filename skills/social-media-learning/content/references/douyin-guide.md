# 抖音平台采集指南

## 平台概述

抖音是中国领先的短视频平台，日活跃用户超过7亿。用户群体广泛，内容类型多样，特别适合以下学习场景：
- 技能教程（烹饪、手工、办公软件等）
- 知识科普（科学、历史、文化等）
- 行业动态（科技、财经、时尚等）
- 语言学习（英语、日语等）

## 访问方式

### 网页版入口
```
抖音搜索: https://www.douyin.com/search/{关键词}
```

### 移动端特点
- 视频以竖屏形式呈现
-  swipe up 切换下一个视频
- 评论折叠显示，需点击展开

## 搜索策略

### 关键词设计原则
1. **核心关键词**：直接表达学习主题
   - 示例：学习摄影 → 摄影教程、摄影技巧
2. **场景关键词**：具体应用场景
   - 示例：手机摄影、夜景拍摄、人像摄影
3. **问题关键词**：用户常问的问题
   - 示例：怎么拍、如何学、教程
4. **专业术语**：行业专业词汇
   - 示例：构图、曝光、景深

### 搜索示例
| 学习主题 | 核心词 | 扩展词 | 长尾词 |
|----------|--------|--------|--------|
| Python编程 | Python教程 | Python入门 | Python爬虫实战 |
| 英语口语 | 英语口语 | 英语学习 | 日常英语对话 |
| 健身 | 健身教程 | 家庭健身 | 腹肌训练计划 |

## 内容采集规范

### 必采集信息
1. **视频基础信息**
   - 标题（完整记录）
   - 作者昵称和主页链接
   - 发布时间
   - 点赞数、评论数、收藏数

2. **视频描述内容**
   - 完整复制视频描述文字
   - 提取所有话题标签（#xxx）
   - 记录 @提及 的其他用户

3. **评论区内容**
   - 热门评论（点赞>100）
   - 有价值的问答内容
   - 作者回复
   - 实用技巧类评论

4. **字幕内容**（如有）
   - 视频内嵌字幕
   - 自动字幕
   - 评论区的补充说明

### 采集示例格式

```
## 视频：[视频标题]
- 链接：https://www.douyin.com/video/xxx
- 作者：@用户名
- 发布时间：2024-01-01
- 互动数据：👍 1.2万 | 💬 856 | ⭐ 3.4万

### 视频描述
[完整描述内容]
#话题1 #话题2 #话题3

### 核心知识点
[从视频内容提取的关键信息]

### 评论区精选
**用户A**：评论内容 (👍 234)
**作者回复**：回复内容

**用户B**：评论内容 (👍 156)
```

## 特殊功能使用

### 话题广场
访问抖音话题页面，发现该主题下的热门内容：
```
https://www.douyin.com/tag/关键词
```

### 搜索结果筛选
- 综合排序：默认推荐
- 最新发布：最新内容
- 最多点赞：热门内容
- 最多收藏：高质量内容

### 合集功能（系列内容识别）
**抖音合集是识别系列内容的重要方式！**

**识别方法**：
1. 视频详情页下方有"合集"入口
2. 标题包含序号模式（第1集/第01集/01等）
3. 评论区常有"还有下一集"等提示
4. 博主主页有"合集"标签页

**合集识别流程**：
```
1. 发现一个视频 → 检查是否有合集标识
2. 点击进入合集 → 查看所有视频列表
3. 记录合集名称和视频数量
4. 检查视频是否按顺序发布
5. 进入博主主页，查找更多合集
```

**抖音系列识别信号**：
| 信号类型 | 示例 | 说明 |
|----------|------|------|
| 序号标题 | "摄影教程第1集"、"01摄影入门" | 直接标明集数 |
| 连续话题 | "#手机摄影教程#"系列 | 同一话题下的系列 |
| 合集标识 | 视频下方的合集入口 | 官方系列组织 |
| 评论区提示 | "建议先看第X集" | 用户推荐顺序 |
| 作者回复 | "@用户 先看入门篇" | 作者指定顺序 |

**合集采集记录格式**：
```
## 合集：[合集名称]
- 博主：@用户名
- 视频总数：X个
- 合集链接：https://www.douyin.com/collection/xxx

### 视频清单
| 序号 | 标题 | 发布时间 | 点赞 | 状态 |
|------|------|----------|------|------|
| 01 | 标题1 | 2024-01 | 5.2万 | ✅ |
| 02 | 标题2 | 2024-01 | 4.8万 | ✅ |
| 03 | 标题3 | 2024-02 | 3.1万 | ✅ |

### 系列结构分析
- 本合集为系统性教程，共3集
- 建议学习顺序：01 → 02 → 03
- 第2集需要第1集的基础
```

**博主主页查找系列**：
1. 点击博主名称进入主页
2. 查看是否有"合集"标签
3. 滚动查看视频列表，识别序号模式
4. 记录所有发现的系列内容

## 学习内容识别

### 高质量内容特征
- 创作者有专业背景或认证
- 内容有明确的知识框架
- 评论区有积极的互动
- 有系列化内容产出

### 需要警惕的内容
- 夸大宣传效果
- 缺乏实际可操作性
- 评论区负面反馈多
- 内容同质化严重

## 常见问题处理

### 视频无法访问
- 检查链接是否正确
- 尝试刷新页面
- 记录无法访问，后续补充

### 内容不完整
- 视频被删除或隐藏
- 描述被编辑修改
- 评论区关闭

### 搜索结果稀少
- 尝试更多关键词组合
- 使用同义词替换
- 扩大搜索范围（如摄影→拍照→影像）
