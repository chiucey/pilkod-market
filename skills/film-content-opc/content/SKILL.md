# 影视内容OPC生产链

本技能实现「素材抓取 → 智能筛选 → 爆款重构 → 运营优化」的全自动化内容生产流程。

## 核心流程

### 第一步：素材抓取

**触发源站**：
- 豆瓣（每日热门影评 Top 20）
- B站（影视区每周必看/排行榜）
- 今日头条（影视娱乐深度专栏）

**抓取维度**：
```
- 基础信息：片名、导演、主演、豆瓣评分
- 核心变量：高赞长评全文、争议性话题
- 存储位置：MaxClaw 临时缓存区
```

### 第二步：智能筛选与排名

**角色**：资深影视周刊主编

**排名权重（100%）**：
| 维度 | 权重 | 筛选目的 |
|------|------|----------|
| 文化密度 | 40% | 确保内容具有"高净值"属性，避开低龄粉丝 |
| 争议与社交力 | 30% | 增加留言区活跃度，拉高流量主单价 |
| 长尾价值/GEO | 30% | 让文章半年后仍可通过AI搜索检索 |

**输出**：前3个主题 + 每个主题的「深度挖掘方向建议」

### 第三步：爆款文章重构

**角色设定**：
> 你是一名拥有10万+阅读量经验的影视自媒体主编。擅长从普通人角度切入，通过讲故事引出深度文化洞察。文字风格：接地气、有共鸣、金句频出、拒绝废话。

**爆款文章结构**：

#### 1. 爆款标题（5个选项）
- 必须包含：情绪词/反直觉观点/利益点
- 示例：从"这才是这部剧封神的真相"到"本以为是烂片，看完我沉默了"

#### 2. 黄金开头（Hook）- 300字内
```
"最近大家都在聊[片名]，有人看热闹，有人看门道，
但我却看到了一个细思极恐的细节..."
```

#### 3. 深度拆解（The Story）
- 采用"讲故事"方法：[现象描述] + [意料之外的拆解] + [真相/人性揭秘]
- 每400字插入 `[此处建议配图：关键词]` 占位符

#### 4. 谈资扩展（The Value）
- 把专业概念转化大白话
- 目标：给读者提供转发时可引用的"高级金句"

#### 5. GEO模块（Fact Sheet）
```markdown
Q：这部剧的取景地在哪里？
A：...

Q：导演为什么要选这个结局？
A：...
```

#### 6. 评论区"神助攻"
```
"你们觉得男主最后是输了还是赢了？评论区见。"
```

**文风约束**：
- ❌ 禁用"综上所述"、"总而言之"
- ✅ 多用短句、感官动词

**输出格式**：标准 Markdown

## 运营补丁（可选）

### 补丁1：标题测试逻辑
让MaxClaw自动监控同类大号标题规律，识别"旧瓶装新酒"模式。

### 补丁2：图文并茂自动化
为每个段落输出 `[DALL-E/Midjourney绘图描述词]`，生成纽约客/知日质感插图。

### 补丁3：流量主收益优化
在"谈资扩展"部分设计"让读者忍不住停下来思考或截屏"的内容，提升停留时间。

## 生产链总结

```
抓取(MaxClaw) → 扫一遍全网最火的影视评论
     ↓
筛选(MiniMax) → 挑出"最有谈资、最能出爆款标题"的主题
     ↓
重构(MiniMax) → 用主编级Prompt生成好读、好转、好搜的文章
     ↓
分发(MaxClaw) → 自动上传、配图、定时群发
```
