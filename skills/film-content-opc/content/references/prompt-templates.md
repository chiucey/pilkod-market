# 爆款文章Prompt模板库

## 模板1：角色设定Prompt

```
【角色设定】
你是一名拥有10万+阅读量经验的影视自媒体主编。

你的专长：
- 从普通人都能看懂的角度切入
- 通过讲故事的方式引出深度文化洞察
- 文字风格：接地气、有共鸣、金句频出、拒绝废话

你的限制：
- 不用"综上所述"、"总而言之"这种学生腔
- 多用短句，多用感官动词
- 每400字插入一个配图建议占位符
```

## 模板2：爆款标题生成Prompt

```
请为这篇影评生成5个爆款标题选项：

要求：
1. 必须包含以下元素之一（情绪词/反直觉观点/利益点）
2. 符合公众号调性，有传播力
3. 能引发点击欲望

原始素材：[粘贴影评摘要/电影名称]

输出格式：
1. [标题1]
2. [标题2]
3. [标题3]
4. [标题4]
5. [标题5]
```

**标题库参考**：

| 类型 | 示例 |
|------|------|
| 反直觉型 | "本以为是烂片，看完我沉默了..." |
| 揭秘型 | "这才是这部剧封神的真相" |
| 争议型 | "10年后重看，我才看懂了这个细节" |
| 情绪型 | "终于有人敢拍出来了" |
| 利益型 | "看懂这3点，你就明白为什么全网吹爆" |

## 模板3：黄金开头(Hook)生成Prompt

```
请为以下电影/剧集生成3个"黄金开头"：

电影：[片名]
核心主题：[主题]
目标读者：[普通影迷/资深影迷/大众]

要求：
- 300字内
- 用一句话引起共鸣或抛出大家都在好奇的问题
- 开头要"抓人"，让人忍不住想读下去

风格参考：
"最近大家都在聊[片名]，有人看热闹，有人看门道，
但我却看到了一个细思极恐的细节..."
```

## 模板4：深度拆解段落Prompt

```
请基于以下素材，写一段"深度拆解"：

原始长评精华：
[粘贴影评核心观点]

请采用"讲故事"结构：
1. [现象描述] - 读者能产生共鸣的场景/细节
2. [意料之外的拆解] - 反常识的解读
3. [真相/人性揭秘] - 深层洞察

要求：
- 600-800字
- 每400字插入"[此处建议配图：关键词]"占位符
- 金句用**加粗**
```

## 模板5：谈资扩展(GEO转化)Prompt

```
请将以下专业概念转化为"大白话"，生成"高级金句"：

原始概念：[如"萨特的存在主义"——既然改变不了世界，就先放过自己]

请完成以下转化：
1. 专业概念：[原文]
2. 大白话版本：[一句话说清楚]
3. 高级金句：[可转发朋友圈的引用句]
4. 应用场景：[适合在文章哪个位置插入]
```

## 模板6：Fact Sheet(GEO模块)Prompt

```
请为这篇影评生成【冷知识/背景卡片】：

电影：[片名]
导演：[导演名]

请生成5组Q&A：

Q1：[关于取景地/幕后/彩蛋]
A1：[答案]

Q2：[关于导演意图/结局解读]
A2：[答案]

...（共5组）

目的：让AI搜索直接抓取你的回答作为推荐答案
```

## 模板7：评论区"神助攻"Prompt

```
请生成3个"神助攻"评论区引导问题：

电影：[片名]
争议焦点：[如"开放式结局的解读"]

要求：
1. 问题要能引发不同观点碰撞
2. 让读者忍不住想留言
3. 简短有力，不超过30字

示例：
"你们觉得男主最后是输了还是赢了？评论区见。"
```

## 模板8：完整文章生成Prompt

```
【任务】
请基于以下素材，撰写1篇深度影视推文。

【素材】
- 电影：[片名]
- 豆瓣评分：[X分]
- 导演：[导演名]
- 核心争议：[争议点]
- 高赞长评摘要：[摘要内容]

【结构要求】
1. 爆款标题（5个选项）
2. 黄金开头（Hook）- 300字内
3. 深度拆解（The Story）- 600-800字，每400字配图建议
4. 谈资扩展（The Value）- 专业概念大白话化
5. GEO模块（Fact Sheet）- 5组Q&A
6. 评论区神助攻 - 1个引导问题

【文风】
- 接地气、有共鸣、金句频出
- 不用"综上所述"
- 多用短句和感官动词

【输出格式】
标准Markdown
```
