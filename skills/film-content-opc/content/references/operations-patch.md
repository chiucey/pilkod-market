# 运营补丁指南

## 补丁1：标题测试逻辑

### 核心策略："旧瓶装新酒"

爆款标题往往不是全新创造，而是：
- 经典框架 + 新角度
- 情绪共鸣 + 信息增量
- 反常识 + 有据可依

### 标题监控Prompt

```python
TITLE_ANALYSIS_PROMPT = """
分析以下标题的爆款基因：

标题：[待分析标题]

请输出：
1. 情绪词/反直觉点/利益点（用颜色标注）
2. 标题类型：[揭秘型/争议型/情绪型/利益型/...]
3. 可复用的框架结构
4. 如果套用到[新电影]，可以怎么改写
"""
```

### "10年后重看"系列模板

| 原版 | 变体 |
|------|------|
| 10年后重看《大话西游》 | 刷了5遍后，我发现了一个秘密 |
| 这部剧20年后依然是神作 | 凭什么它能火20年？ |
| 当年没看懂《肖申克》 | 现在才明白，这部电影在说我们自己 |

### 自动标题生成流程

```
1. 抓取同类大号近30天爆款标题
2. 提取高频情绪词/结构模板
3. 结合新电影元素，自动生成5个变体
4. A/B测试选择最优
```

## 补丁2：图文并茂自动化

### 流程

```
文章段落 → AI绘图Prompt生成 → Midjourney/DALL-E → 配图
```

### 配图质量标准

| 维度 | 要求 |
|------|------|
| 风格统一 | 整篇文章使用同一视觉风格 |
| 版权安全 | 100% AI原创，无侵权风险 |
| 品牌调性 | 对标《纽约客》《知日》质感 |
| 尺寸适配 | 公众号内文配图：900x600最佳 |

### 质感提升技巧

```
# 统一在文章开头声明风格指南
【本文视觉规范】
- 主色调：暖黄+深蓝（电影感）
- 光线：自然光+局部暖调（王家卫风格）
- 构图：三分法，大量留白
- 参考：Wong Kar-wai《花样年华》

# 这样生成的图片会形成系列感
```

### 高净值广告主吸引力

- **《纽约客》风格**：简洁、高端、有品味
- **《知日》风格**：日系排版、留白、文艺感
- AI原创插图 = 品牌调性背书

## 补丁3：流量主收益优化

### 核心指标

| 指标 | 优化目标 |
|------|----------|
| 点击率 | 提升留言区/广告点击 |
| 停留时间 | 增加"忍不住截屏"的内容 |
| 完播率 | 优化文章节奏，减少跳出 |

### "截屏冲动"内容设计

```
【技巧1：制造"认知冲突"】
不是告诉他答案，而是让他自己顿悟
示例："看到第三遍，我才明白这场戏在说什么..."

【技巧2：制造"转发资本"】
给读者"我可以分享这个"的社交货币
示例："原来这才是《繁花》最值钱的地方..."

【技巧3：制造"思考停顿"】
让人停下来想一想的"留白"
示例："有时候，不说话比说一千句话更有力量"
```

### 评论区引导技巧

```
【好问题特征】
1. 有明确立场但留争议空间
2. 能引发不同人群共鸣
3. 简短有力，不超过30字

【优质问题示例】
❌ "你们觉得这部电影怎么样？"（太泛）
✓ "高启强是坏人吗？"（有立场，可辩论）
✓ "如果你是安欣，你会怎么选？"（代入感强）
✓ "这3个细节，你看懂了几个？"（好奇心驱动）
```

## 被动收益布局

### GEO长尾策略

