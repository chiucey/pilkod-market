# 组件库与使用场景

## 通用组件分类

### 基础组件（Basic）
构成界面的最小单元。

#### Button 按钮
- **类型**：主按钮(Primary)、次按钮(Default)、虚线按钮(Dashed)、文字按钮(Text)、链接按钮(Link)
- **尺寸**：大(Large)、中(Medium/Default)、小(Small)
- **状态**：默认、悬停、点击、加载中、禁用
- **决策规则**：
  - 一个页面只应有一个主按钮（视觉焦点）
  - 删除/危险操作用红色警示按钮
  - 次要操作用次按钮或文字按钮
  - 成组操作使用按钮组或下拉菜单

#### Input 输入框
- **类型**：文本、密码、数字、文本域、搜索
- **状态**：默认、聚焦、错误、禁用、只读
- **变体**：前置/后置标签、带图标、带清除按钮
- **规范**：
  - 高度：32px(sm) / 40px(md) / 48px(lg)
  - 错误状态需配合红色边框和错误提示文字
  - 搜索框需有放大镜图标和placeholder提示

#### Select 选择器
- **类型**：单选、多选、级联、树选择
- **交互**：点击展开、搜索过滤、键盘导航
- **规范**：
  - 下拉列表最大高度 256px，超出滚动
  - 多选标签需有清除按钮
  - 空状态显示"暂无数据"

### 展示组件（Data Display）

#### Table 表格
- **元素**：表头、表体、行、单元格、排序图标、分页
- **功能**：排序、筛选、分页、行选择、行展开
- **规范**：
  - 表头文字加粗，背景色区别于表体
  - 行 hover 效果 #FAFAFA
  - 固定列/固定表头需有阴影区分
  - 分页器在表格底部右对齐
  - 每页条数默认 10/20/50

#### Card 卡片
- **结构**：标题区、内容区、操作区（可选）
- **尺寸**：自适应宽度，最小高度由内容决定
- **规范**：
  - 内边距 16-20px
  - 标题 16px Medium，内容 14px Regular
  - 操作区按钮右对齐
  - hover 可提升阴影层级

#### Tag 标签
- **类型**：默认、成功、警告、错误、处理中
- **样式**：填充/描边/可关闭/可选择
- **规范**：
  - 圆角 999px（胶囊形）或 2px（方形）
  - 高度 20-24px，水平内边距 8-12px
  - 文字 12px

#### Badge 徽标
- **类型**：数字、小红点、状态点
- **位置**：右上角偏移
- **规范**：
  - 数字超过 99 显示 99+
  - 状态点用于在线/离线/忙碌

### 反馈组件（Feedback）

#### Modal 对话框
- **类型**：确认框、信息框、表单框、自定义
- **结构**：标题、内容、操作按钮（确定/取消）
- **规范**：
  - 宽度 400-560px（小）/ 600-720px（中）/ 800-960px（大）
  - 遮罩层 rgba(0,0,0,0.45)
  - 点击遮罩可关闭（可配置）
  - 动画：从中心缩放淡入 200ms
  - 最多同时展示一个 Modal

#### Message 全局提示
- **类型**：成功、错误、警告、加载中、信息
- **规范**：
  - 顶部居中显示
  - 自动消失 3s（成功）/ 不消失（错误可手动关闭）
  - 最多同时显示一条
  - 动画：从顶部滑入 200ms

#### Notification 通知提醒
- **类型**：成功、错误、警告、信息
- **规范**：
  - 右上角堆叠显示，最多 5 条
  - 每条有标题和描述
  - 手动关闭或 4.5s 自动关闭

#### Form 表单
- **布局**：水平（标签在左）、垂直（标签在上）、行内
- **元素**：标签、输入控件、校验提示、帮助文字
- **规范**：
  - 标签右对齐（水平）或左对齐（垂直）
  - 必填项标记红色星号 *
  - 校验错误显示红色文字和边框
  - 提交按钮在表单底部左对齐或右对齐
  - 表单间距 16-24px

### 导航组件（Navigation）

#### Menu 导航菜单
- **类型**：侧栏菜单、顶部菜单、内嵌菜单
- **规范**：
  - 侧栏宽度 200-256px
  - 一级菜单 14px，二级 14px
  - 选中项高亮背景 + 左侧竖线指示
  - 折叠后图标宽度 64-80px

#### Breadcrumb 面包屑
- **规范**：
  - 首页显示"首页"或 Home 图标
  - 当前页不可点击
  - 分隔符使用 ">" 或 "/"

#### Tabs 标签页
- **类型**：线条型、卡片型、胶囊型
- **规范**：
  - 标签页高度 40-48px
  - 选中项下划线或背景高亮
  - 支持关闭、新增、拖拽排序

#### Pagination 分页
- **规范**：
  - 默认显示 10 条/页
  - 页码范围 1-5 + 省略号 + 末页
  - 简洁模式：上一页/下一页 + 页码输入

### 其他常用组件

#### DatePicker 日期选择器
- **类型**：日期、日期范围、日期时间、月份、年份
- **规范**：
  - 面板宽度 280px
  - 选中日期主色背景白色文字
  - 范围选择首尾圆角相连

#### Upload 上传
- **类型**：点击上传、拖拽上传、图片列表、图片卡片
- **规范**：
  - 拖拽区域虚线边框，hover 变实线
  - 上传中显示进度条
  - 上传失败显示红色错误提示和重试按钮

#### Tooltip 文字提示 / Popover 气泡卡片
- **规范**：
  - 触发方式：hover / click / focus
  - 方向：上/下/左/右
  - 最大宽度 250px，超出换行
  - 箭头 4px 三角形

#### Drawer 抽屉
- **规范**：
  - 从右侧滑入（默认），可配置方向
  - 宽度 256-480px
  - 遮罩层可点击关闭
  - 动画 300ms ease-out

## 组件选型决策树

遇到场景 → 选择组件：

- **数据录入**：
  - 少量文本 → Input
  - 多行文本 → Input.TextArea
  - 选项 ≤5 个 → Radio / Checkbox
  - 选项 >5 个 → Select
  - 日期/时间 → DatePicker / TimePicker
  - 文件 → Upload

- **数据展示**：
  - 结构化列表 → Table
  - 卡片式 → Card / List
  - 时间线 → Timeline
  - 统计数字 → Statistic
  - 树形结构 → Tree

- **操作反馈**：
  - 需要确认 → Modal.confirm
  - 轻提示 → Message
  - 详细通知 → Notification
  - 加载中 → Spin / Skeleton

- **导航**：
  - 一级导航 → Menu
  - 二级/页面内 → Tabs
  - 路径回溯 → Breadcrumb
  - 步骤流程 → Steps
