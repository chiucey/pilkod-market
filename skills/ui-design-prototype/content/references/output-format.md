# 设计稿输出格式与模板

## 设计稿交付物结构

### 1. 设计概览（Design Overview）
```markdown

## 项目信息
- 产品名称：[名称]
- 目标平台：[Web/iOS/Android/小程序]

- 页面数量：[N] 页
- 适配范围：[PC + 移动端 / PC 端 / 移动端]

## 设计原则

|---------|---------|--------|------|
| [名称] | [列表/表单/详情/仪表盘] | P0/P1 | [说明] |
```

## 图片输出规范

当生成设计稿图片时，遵循以下规范：

### 画布设置
- 分辨率：1440px 宽度（PC 基准）/ 375px 宽度（移动端基准）
- 背景色：#F5F5F5（默认灰色画布）
- 内容区最大宽度：1200px（PC）/ 343px（移动端，左右各 16px margin）

### 元素绘制规范
- 使用纯色填充，不使用渐变（除非设计系统定义）
- 文字使用对应字号和颜色
- 组件严格按照设计 Token 绘制
- 间距严格按 8px 基数系统
- 截图区域包含完整页面，不截断内容

### 标注规范
- 关键尺寸用红色标注线和数字
- 颜色值用色块 + 十六进制标注
- 字体用字号 + 字重标注
- 间距用双向箭头 + 数值标注
