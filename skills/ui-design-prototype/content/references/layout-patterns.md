# 布局模式与栅格系统

## 栅格系统

### 屏幕断点
| 名称 | 宽度 | 适用设备 |
|------|------|---------|
| xs | < 576px | 手机竖屏 |
| sm | ≥ 576px | 手机横屏/小平板 |
| md | ≥ 768px | 平板 |
| lg | ≥ 992px | 笔记本 |
| xl | ≥ 1200px | 桌面显示器 |
| xxl | ≥ 1600px | 大屏显示器 |

### 列数与间距
- 总列数：24 列（Ant Design）/ 12 列（Bootstrap/Material）
- 列间距（Gutter）：16px（默认）/ 24px（宽松）/ 8px（紧凑）
- 外边距（Margin）：24px（默认）/ 自动居中（max-width 1200px）

### 布局计算
- 列宽 = (容器宽度 - (列数 - 1) * Gutter) / 列数
- 跨 N 列 = N * 列宽 + (N - 1) * Gutter
- 响应式：同一元素在不同断点指定不同 span 值

## 常见页面布局

### 1. 侧栏导航布局（Admin Dashboard）
```
+----------------------------+
|  Logo    |  Header         |
|----------+----------------|
|          |                 |
|  Side    |   Content       |
|  Menu    |   Area          |
|  200px   |   (flex: 1)     |
|          |                 |
+----------------------------+
```
- 侧栏固定宽度 200-256px，内容区自适应
- 顶部 Header 高度 64px
- 内容区最小宽度 768px（防止过度挤压）
- 侧栏可折叠为图标模式 64-80px
- 适用：管理后台、数据中台、SaaS 应用

### 2. 顶部导航布局（Landing / Corporate）
```
+----------------------------+
|  Logo    Nav      Actions  |
+----------------------------+
|                            |
|       Hero / Banner        |
|                            |
+----------------------------+
|    Feature Cards x3        |
+----------------------------+
|         Footer             |
+----------------------------+
```
- 顶部导航高度 64px，滚动可固定
- 内容区 max-width 1200px 居中
- 区块间距 64-80px
- 适用：官网、营销页、产品展示

### 3. 双栏布局（List + Detail）
```
+----------------+-----------+
|                |           |
|    List        |  Detail   |
|    30-40%      |  60-70%   |
|                |           |
+----------------+-----------+
```
- 左侧列表固定宽度 320-400px 或 30-40%
- 右侧详情自适应
- 列表项有选中态，与右侧联动
- 适用：邮件客户端、IM 聊天、商品管理

### 4. 三栏布局（Sidebar + Main + Aside）
```
+--------+------------+------+
|        |            |      |
| Filter |   Main     | Help |
| 240px  |   Content  | 200px|
|        |            |      |
+--------+------------+------+
```
- 左右两侧固定，中间自适应
- 右侧可折叠
- 适用：电商筛选、文档站点、设置页

### 5. 卡片网格布局（Dashboard / Gallery）
```
+------+------+------+------+
| Card | Card | Card | Card |
+------+------+------+------+
| Card | Card | Card | Card |
+------+------+------+------+
```
- 等宽卡片，Gutter 16-24px
- 响应式：xl 4列 → lg 3列 → md 2列 → sm 1列
- 卡片高度可统一或不统一（瀑布流）
- 适用：数据面板、图片库、商品列表

### 6. 步骤/流程布局（Wizard / Checkout）
```
+----------------------------+
|  Step 1 → Step 2 → Step 3 |
+----------------------------+
|                            |
|      Step Content          |
|                            |
+----------------------------+
|  [Back]          [Next]    |
+----------------------------+
```
- 步骤条在顶部或左侧
- 内容区随步骤切换
- 底部有导航按钮
- 适用：表单向导、注册流程、结账

## 模式层（Pattern）定义

### 列表页模式（List Page）
- 搜索栏（顶部）
- 筛选区（可展开/收起）
- 操作按钮区（新建/导出/批量操作）
- 数据表格（主体）
- 分页器（底部）

### 表单页模式（Form Page）
- 页面标题 + 返回按钮
- 分组卡片（基础信息、详细信息、高级设置）
- 表单项按逻辑分组
- 底部固定操作栏（保存/取消）

### 详情页模式（Detail Page）
- 页面标题 + 操作按钮（编辑/删除/返回）
- 信息卡片（只读数据展示）
- 关联数据列表/Tab
- 操作日志/时间线

### 弹窗编辑模式（Modal Edit）
- 触发按钮打开 Modal
- 表单在 Modal 内
- 提交后刷新列表
- 适用：轻量编辑、快速添加

### 批量操作模式（Batch Operation）
- 表格行选择 Checkbox
- 选中后底部浮出操作栏
- 操作：删除/导出/修改状态/分配
- 显示已选数量

### 空状态模式（Empty State）
- 空状态插画（SVG 或图标）
- 描述文字
- 引导操作按钮
- 适用：首次使用、无搜索结果、无数据

### 错误处理模式（Error Handling）
- 全局错误：错误页面（403/404/500）
- 局部错误：内联错误提示
- 网络错误：重试按钮 + 离线提示
- 权限不足：降级展示 + 申请权限入口

## 间距布局原则

### 8px 基数系统
所有间距为 8 的倍数：8, 16, 24, 32, 40, 48, 64

### 亲密性原则
- 相关元素间距小（8-16px）
- 不相关元素间距大（24-48px）
- 同一层级保持一致

### 视觉层次
- 通过间距大小暗示信息层级
- 重要模块上下留白更大
- 次级模块间距紧凑

### 对齐原则
- 左对齐为主（中文阅读习惯）
- 表单标签右对齐或顶对齐
- 数字/金额右对齐
- 操作按钮右下对齐
