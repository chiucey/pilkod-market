# LOF基金套利分析技能 (lof-fund-analyzer)

## 产品简介

本技能是专为 Minimax Agent 打造的国内LOF基金套利专业分析工具，无任何第三方平台依赖，可自动拉取全市场300+可套利LOF基金的实时场内外数据，精准计算溢价/折价率，通过多维度筛选规则锁定高安全边际的双向套利机会，是个人投资者进行LOF套利的高效辅助工具。

## 核心功能

1. **全市场数据自动拉取**：对接天天基金网+东方财富网公开合规数据源，自动获取LOF基金场外净值、场内实时价格、申赎状态、成交额等核心数据
2. **双向套利全场景支持**：同时覆盖「溢价套利（场外申购->场内卖出）」和「折价套利（场内买入->场外赎回）」两大核心套利场景
3. **多维度安全边际筛选**：内置流动性、申赎状态、风险缓冲、成本覆盖等6大硬门槛，有效过滤低质量机会，降低套利风险
4. **T+2风险缓冲机制**：针对LOF套利的核心时间差风险，内置专属风险缓冲参数，提升套利胜率
5. **自动化分析报告**：自动生成标准化分析报告，结果支持Excel导出，方便二次查看与分析
6. **自定义参数支持**：支持用户自定义溢价率阈值、成交额门槛、分析范围等参数，适配不同风险偏好

## 安装与使用

### 1. 技能导入

将本JSON文件直接导入Minimax Agent的技能管理界面，系统会自动创建完整的项目目录结构与代码文件。

### 2. 配置调整

根据个人实际情况，修改 `config/settings.yaml` 中的核心配置：

- 套利成本参数：根据自己的券商佣金、基金申购费率调整
- 筛选规则：根据自己的风险偏好，调整溢价率阈值、成交额门槛等
- 风险缓冲：根据市场波动情况，调整T+2风险缓冲比例

### 3. 触发使用

在 Minimax Agent 对话中，通过以下方式触发技能：

- 关键词触发：输入「LOF分析」「LOF套利机会盘点」「溢价率分析」等关键词
- 自定义参数触发：传入JSON参数，例如 `{"min_premium_rate": 2.0, "max_analyze_funds": 300}`

## 权限声明

- `read:file`：读取配置文件 `config/settings.yaml`
- `write:file`：将分析结果写入 `output` 目录
- `network:true`：访问天天基金网、东方财富网公开接口获取基金行情数据

## 核心风险提示

1. **市场波动风险**：LOF套利存在T+2的时间差，期间市场大幅波动可能导致溢价率消失，甚至产生亏损
2. **流动性风险**：场内成交额过低的基金，可能出现无法按预期价格成交、滑点过大的问题
3. **申赎风险**：基金可能临时暂停申购或赎回，导致套利流程无法完成
4. **合规提示**：本工具所有数据源均为公开免费接口，仅供个人学习研究使用，请勿高频请求，遵守相关网站的使用规则
5. **免责声明**：本工具提供的所有分析结果仅供参考，不构成任何投资建议，投资有风险，入市需谨慎
