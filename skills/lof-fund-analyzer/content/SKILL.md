# LOF基金套利分析技能 (lof-fund-analyzer)

## 产品简介

本技能是专为 Minimax Agent 打造的国内LOF基金套利专业分析工具，无任何第三方平台依赖，可自动拉取全市场300+可套利LOF基金的实时场内外数据，精准计算溢价/折价率，通过多维度筛选规则锁定高安全边际的双向套利机会。

## 核心功能

### 1. 全市场数据自动拉取
- 对接天天基金网 + 东方财富网公开合规数据源
- 自动获取LOF基金场外净值、场内实时价格、申赎状态、成交额等核心数据
- 无需API密钥，个人学习使用完全合规

### 2. 双向套利全场景支持
| 套利类型 | 条件 | 操作策略 |
|---------|------|---------|
| **溢价套利** | 场内价格 > 场外净值 | 场外按净值申购 → T+2转场内 → 高价卖出 |
| **折价套利** | 场内价格 < 场外净值 | 场内低价买入 → T+2转场外 → 按净值赎回 |

### 3. 多维度安全边际筛选
- **流动性门槛**：日均成交额≥500万，避免无法成交
- **申赎状态校验**：自动过滤暂停申赎的基金
- **T+2风险缓冲**：覆盖2天时间差的市场波动风险
- **成本精细化计算**：覆盖申购/赎回/佣金/转托管全成本

### 4. 自定义参数支持
```json
{
  "min_premium_rate": 2.0,
  "min_discount_rate": 1.5,
  "max_analyze_funds": 300,
  "min_daily_amount": 1000
}
```

## 核心概念

### 溢价率计算
```
溢价率 = (场内价格 - 场外净值) / 场外净值 × 100%
```

### 安全边际计算
```
溢价安全边际 = 溢价率 - 申购费 - 卖出佣金 - 转托管费 - 风险缓冲
折价安全边际 = 折价率 - 买入佣金 - 赎回费 - 风险缓冲
```

## 数据来源

### 场内数据（东方财富）
- `https://push2.eastmoney.com/api/qt/stock/details/get`
- 字段：最新价(f43)、昨收价(f60)、成交额(f8)

### 场外数据（天天基金网）
- `http://fund.eastmoney.com/data/rankhandler.aspx` - LOF基金列表
- `http://api.fund.eastmoney.com/f10/lsjz` - 基金净值数据
- `http://fund.eastmoney.com/pingzhongdata/{code}.js` - 申赎状态

## 风险提示

⚠️ **重要声明**：

1. **市场波动风险**：LOF套利存在T+2时间差，期间市场大幅波动可能导致溢价率消失
2. **流动性风险**：场内成交额过低的基金，可能无法按预期价格成交
3. **申赎风险**：基金可能临时暂停申购或赎回
4. **数据时效性**：15:00前分析时，场外净值为前一交易日数据
5. **免责声明**：本工具仅供学习研究，不构成任何投资建议
