# 游戏开发团队汇报清单

## 目标
为用户组建一个具备多职能分工协作能力的游戏开发团队，并给出每个岗位的技能说明与适用范围。

## 已落地内容

### 1. 已创建本地团队编排 Skill
- `game-dev-team`

用途：
- 定义游戏开发团队岗位
- 规定岗位协作关系
- 规定标准交接格式
- 提供岗位与技能映射清单
- 提供不同规模团队预设

### 2. 已纳入团队的岗位命名
1. 游戏制作人 / Producer Agent
2. 游戏策划 / Game Design Agent
3. 叙事设计师 / Narrative Agent
4. UI/UX 设计师 / Game UI Agent
5. 游戏美术 / Art Agent
6. 技术开发 / Gameplay Programmer Agent
7. 音频设计 / Audio Agent
8. QA 测试 / QA Agent

扩展岗位：
9. 技术美术 / Technical Art Agent
10. 关卡设计师 / Level Design Agent
11. 运营与数据 / LiveOps & Analytics Agent

## 每个岗位当前可用 Skill 说明

### Producer Agent
当前可用：
- `doc-coauthoring`
- `internal-comms`
- `game-dev-team`

适合处理：
- 里程碑规划
- 任务拆解
- 汇报文档
- 跨角色协作节奏管理

### Game Design Agent
当前可用：
- `doc-coauthoring`
- `game-dev-team`

适合处理：
- 核心玩法循环设计
- 系统规则设计
- GDD 结构化撰写
- 数值与机制假设整理

### Narrative Agent
当前可用：
- `doc-coauthoring`
- `internal-comms`
- `game-dev-team`

适合处理：
- 世界观设定
- 角色设定
- 任务剧情
- 对白草稿

### Game UI Agent
当前可用：
- `frontend-design`
- `canvas-design`
- `theme-factory`
- `game-dev-team`

适合处理：
- HUD 结构设计
- 菜单流程设计
- 视觉层级设计
- 界面展示稿

### Art Agent
当前可用：
- `4399-image-generate`
- `canvas-design`
- `algorithmic-art`
- `game-dev-team`

适合处理：
- 概念图
- 风格探索
- 插画与静态视觉草案

### Gameplay Programmer Agent
当前可用：
- `frontend-design`
- `webapp-testing`
- `playwright-browser-automation`
- `game-dev-team`

适合处理：
- 交互原型
- 游戏前端界面逻辑
- 浏览器试玩原型
- 自动化验证

### Audio Agent
当前可用：
- `4399-voice-clone`
- `4399-video-generate`
- `game-dev-team`

适合处理：
- 语音参考实验
- 视听概念样片辅助
- 音频事件规划文档

说明：
- 当前更偏“音频方案设计”和“参考生成”，并非完整 DAW 音频制作链

### QA Agent
当前可用：
- `webapp-testing`
- `playwright-browser-automation`
- `game-dev-team`

适合处理：
