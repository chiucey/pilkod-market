# 游戏开发团队

## 概述

使用此技能将游戏开发团队结构化为具有不同职位名称、清晰职责范围和明确协作边界的专用智能体。

目标不是让每个智能体都做所有事情。目标是让交接清晰、职责明确、输出可组合。

## 核心团队结构

除非用户要求更小或更大的团队配置，否则围绕以下默认角色创建团队。

### 1. 游戏制作人 / Producer Agent

**角色职责**

- 负责范围、里程碑、优先级和交付节奏
- 将大目标分解为阶段性工作包
- 协调所有其他角色之间的依赖关系

**主要输出**

- 里程碑计划
- Sprint 目标
- 任务板结构
- 风险清单
- 交付总结

**擅长**

- 将模糊的游戏想法转化为阶段性执行计划
- 在设计、美术、代码、QA 和发布之间安排工作顺序

### 2. 游戏策划 / Game Design Agent

**角色职责**

- 负责核心循环、系统、进度、平衡假设和功能规格
- 定义游戏应该带来的感受以及玩家重复执行的操作

**主要输出**

- 游戏概念简报
- GDD（游戏设计文档）章节
- 核心循环定义
- 系统规格
- 平衡假设

**擅长**

- 将产品目标转化为可玩机制
- 定义规则、玩家目标、资源、奖励和节奏

### 3. 叙事设计师 / Narrative Agent

**角色职责**

- 负责世界观构建、故事线、任务节点、对话基调和角色塑造
- 为策划提供叙事钩子和进度上下文支持

**主要输出**

- 世界观设定笔记
- 任务大纲
- 角色传记
- 对话草稿
- 叙事结构文档

### 4. UI/UX 设计师 / Game UI Agent

**角色职责**

- 负责玩家端流程、菜单结构、HUD、线框图和无可用性
- 确保在游戏压力下的信息层次可读性

**主要输出**

- 屏幕流程
- HUD 布局方案
- 菜单架构
- 交互说明
- UI 文案建议

### 5. 游戏美术 / Art Agent

**角色职责**

- 负责视觉方向、资源清单、风格一致性、图标设计和 2D 视觉制作规划
- 可按需拆分为概念美术、像素美术或场景美术

**主要输出**

- 美术方向简报
- 风格指南
- 资源清单
- 图标/精灵简报
- 场景构图说明

### 6. 技术开发 / Gameplay Programmer Agent

**角色职责**

- 实现机制、玩家控制、摄像机、AI 钩子、UI 集成、存档/读档和技术架构
- 将设计转化为可运行的系统

**主要输出**

- 实施计划
- 游戏玩法脚本/模块
- 技术决策
- 集成说明
- 优化待办事项

### 7. 音频设计 / Audio Agent

**角色职责**

- 负责 BGM 方向、音效分类、情绪参考和事件到声音的映射
- 与设计及叙事协调情感时机

**主要输出**

- 音频方向简报
- 事件音效清单
- 环境音计划
- 音乐提示计划

### 8. QA 测试 / QA Agent

**角色职责**

- 负责测试策略、Bug 复现、验收标准验证、边缘情况发现和回归覆盖
- 保护可玩性和发布质量

**主要输出**

- 测试计划
- 测试用例
- Bug 报告格式
- 回归检查清单
- 发布就绪总结

## 推荐扩展角色

当项目规模扩大时添加这些角色。

### 9. 技术美术 / Technical Art Agent

- 连接美术管线和引擎集成
- 负责导入规则、着色器/材质设置、优化和渲染一致性

### 10. 关卡设计师 / Level Design Agent

- 负责遭遇流程、空间节奏、挑战曲线和内容放置

### 11. 运营与数据 / LiveOps & Analytics Agent

- 负责留存假设、活动规划、遥测框架和经济调优反馈

## 协作规则

### 规则 1：制作人拥有优先级决定权

如果角色在时间或范围上发生冲突，由制作人决定顺序。

### 规则 2：策划拥有玩法意图决定权

如果实现不明确，返回给游戏策划智能体进行机制澄清。

### 规则 3：程序员拥有技术可行性说明

如果某个功能成本高或有风险，程序员应提出带有权衡的替代方案。

### 规则 4：UI 和美术必须在共享视觉语言上保持一致

UI 不应在没有明确理由的情况下偏离游戏的视觉风格。

### 规则 5：QA 根据书面验收标准进行验证

如果没有验收标准，QA 应在签字前请求提供。

## 交接标准

每个角色应以下列格式将工作交接给下一个角色：

- **上下文：** 这项工作是为了什么
- **决策：** 决定了什么
- **约束：** 引擎、风格、范围、时间线、性能、平台
- **未解决问题：** 未解决的要点
- **下一负责人：** 哪个角色接下来行动

## 工作流

### 阶段 1：团队组建

1. 确定项目所需的角色
2. 确定引擎和美术风格
3. 确定目标平台
4. 设置里程碑切片

### 阶段 2：预生产

1. 制作人定义范围和里程碑框架
2. 策划智能体起草核心循环和主要系统
3. 叙事智能体起草设定和动机（如相关）
4. UI 智能体定义玩家端流程
5. 美术智能体定义风格和资源需求
6. 程序员智能体选择架构方案
7. QA 智能体尽早起草验收标准和测试策略

### 阶段 3：生产

1. 程序员首先实现最高风险的机制
2. UI 和美术针对可玩构建进行迭代
3. 音频填充事件反馈和情绪缺口
4. QA 持续验证功能和回归

### 阶段 4：打磨

1. QA 识别摩擦点和缺陷
2. 策划调优平衡和节奏
3. UI 提高清晰度
4. 音频增强反馈质量
5. 制作人决定削减/保留/修复的优先级

## 角色-技能映射

优先使用本地已安装的技能（如果可用）。然后如果环境支持安装，再推荐外部技能。

### 制作人智能体

**强本地技能**

- internal-comms（内部沟通）
- doc-coauthoring（文档协作）

**可用时推荐添加的外部技能**

- project-session-management（项目会话管理）
- project-management（项目管理）
- senior-pm（高级项目经理）

### 游戏策划智能体

**强本地技能**

- doc-coauthoring（文档协作）
- wechat-mp-writer（微信公众号撰写器，用于长篇想法探索时）

**可用时推荐添加的外部技能**

- game-design-theory（游戏设计理论）
- game-design-document（游戏设计文档）
- game-designer（游戏设计师）

### 叙事设计师智能体

**强本地技能**

- doc-coauthoring（文档协作）
- internal-comms（内部沟通）

**可用时推荐添加的外部技能**

- storytelling（故事讲述）
- hum-narrative（人文叙事）
- visual-storytelling-design（视觉叙事设计）

### 游戏 UI 智能体

**强本地技能**

- frontend-design（前端设计）
- canvas-design（画布设计）
- theme-factory（主题工厂）

**可用时推荐添加的外部技能**

- game-ui-design（游戏 UI 设计）
- godot-ui（Godot UI）

### 美术智能体

**强本地技能**

- 4399-image-generate（图像生成）
- canvas-design（画布设计）
- algorithmic-art（算法艺术）

**可用时推荐添加的外部技能**

- pixel-art-sprites（像素艺术精灵）
- pixel-art（像素艺术）
- godot-asset-generator（Godot 资源生成器）

### 游戏玩法程序员智能体

**强本地技能**

- frontend-design（前端设计）
- webapp-testing（Web 应用测试）
- playwright-browser-automation（Playwright 浏览器自动化）

**可用时推荐添加的外部技能**

- unity-developer（Unity 开发者）
- unity-ecs-patterns（Unity ECS 模式）
- godot-gdscript-patterns（Godot GDScript 模式）
- godot-development（Godot 开发）
- godot-optimization（Godot 优化）

### 音频智能体

**强本地技能**

- 4399-video-generate（仅用于临时 AV 概念制作）
- 4399-voice-clone（仅用于参考语音实验）

**可用时推荐添加的外部技能**

- game-audio（游戏音频）
- add-audio（添加音频）
- audio-systems（音频系统）

### QA 智能体

**强本地技能**

- webapp-testing（Web 应用测试）
- playwright-browser-automation（Playwright 浏览器自动化）

**可用时推荐添加的外部技能**

- qa-testing-strategy（QA 测试策略）
- qa-testing-playwright（QA Playwright 测试）
- qa-agent-testing（QA 智能体测试）

- QA 智能体

- 制作人智能体
- 游戏策划智能体

- UI 智能体
- 美术智能体
- 程序员智能体
- 音频智能体
- QA 智能体

## 输出模板

当要求组建团队时，返回：

1. 团队名单
2. 角色职责
3. 角色-技能映射
4. 协作工作流
5. 当前差距和推荐额外技能
