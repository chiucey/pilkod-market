组件样式库

STYLE KIT / 可删除

下列是本电子版用到的全部排版组件，按实际章节挑选使用。类名即组件名，复制区块后替换文字即可。

.prose / .prose.no-indent — 正文段落，首行缩进两字

这是标准正文段落，缩进两字符，中文两端对齐，行高两倍。

加 no-indent 后取消缩进，用于卡片内、列表后的补充说明。

.h--3 / .h--4 — 小标题（深色，h3 前带橙色方点）

三级小标题

紧跟在小标题后的正文会自动取消首行缩进。

四级小标题

更轻的一级，用于分组或次级说明。

.pull — 引文，橙色竖线
适合放书中金句或作者的核心判断。—— 出处
.list / .list--dot / .list--check — 三种列表
  1. 有序列表：自动编号，编号为橙色两位数。
  • 圆点列表：并列要点，不强调顺序。
  • 勾选列表：该做 / 不该做、优势 / 劣势。
.cards — 要点卡片网格，自动换列
01

要点标题

40–80 字说明。

02

要点标题

卡片之间用 1px 线分隔，不用阴影。

03

要点标题

适合放"三点结论""四个误区"。
