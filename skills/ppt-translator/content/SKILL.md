# PPT Translator Skill

## 概述

此技能可将PPT文件从一种语言翻译成另一种语言，同时：
- 保留原始幻灯片布局和排版
- 保持背景主题和设计元素
- 智能调整字体大小以适应翻译后的文本
- 保留图片、图表和其他非文本元素

## 使用场景

- 将英文PPT翻译成中文或其他语言
- 制作多语言版本的演示文稿
- 翻译商业提案、培训材料或教育课件

## 工作流程

### 步骤 1：读取原始PPT

使用 `python-pptx` 库读取原始PowerPoint文件：
- 遍历所有幻灯片
- 识别文本框、标题、段落
- 记录每个文本元素的位置和格式属性

### 步骤 2：提取并翻译文本

对于每个文本元素：
1. 提取原始文本内容
2. 调用翻译API（如Google Translate API或Azure Translator）
3. 获取翻译后的文本

### 步骤 3：智能排版调整

翻译后文本通常比原文长或短，需要：
1. 计算原文与译文的字符长度比
2. 智能调整字体大小（保持可读性）
3. 如果文本过长，启用文本自动换行
4. 保留原始字体样式（粗体、斜体、颜色等）

### 步骤 4：重建幻灯片

1. 保持原有背景主题
2. 保持原有图片、形状、图表
3. 仅更新文本内容
4. 应用调整后的字体大小
5. 保存为新的PPTX文件

## 关键技术

- **python-pptx**: Python库用于读取和操作PowerPoint文件
- **AI翻译模型**: 支持多种翻译引擎，用户可自行选择
- **智能字体调整算法**: 根据文本长度比例自动调整字体大小

## 支持的翻译模型

用户可自行选择以下翻译模型：

| 模型 | 说明 | API配置 |
|------|------|--------|
| DeepSeek | DeepSeek最新翻译模型，推荐使用 | 需要配置 `DEEPSEEK_API_KEY` |
| OpenAI (GPT) | GPT系列翻译模型 | 需要配置 `OPENAI_API_KEY` |
| Google Translate | 传统翻译服务 | 需要配置 `GOOGLE_TRANSLATE_API_KEY` |
| 百度翻译 | 百度翻译API | 需要配置 `BAIDU_TRANSLATE_APPID` 和 `BAIDU_TRANSLATE_KEY` |
| 腾讯翻译 | 腾讯翻译君API | 需要配置 `TENCENT_SECRET_ID` 和 `TENCENT_SECRET_KEY` |

### 模型选择说明

1. **DeepSeek（推荐）**: 翻译质量高，支持中文语境，适合商业文档
2. **OpenAI**: GPT系列模型，翻译流畅自然
3. **Google Translate**: 传统翻译服务，覆盖语言广
4. **百度/腾讯翻译**: 国内服务，访问稳定

用户可通过设置对应的环境变量或API密钥来启用相应模型。

## 输出

### 文件格式
- 输出文件格式为 **PPTX**（PowerPoint演示文稿）
- 保持与原文件相同的视觉风格和主题

### 文件位置
- **输出位置与原文件位置保持一致**
- 输出文件保存在原文件所在目录

### 文件命名规则
输出文件名遵循以下规则：
- **原文件名 + 目标语言名称**
- 例如：
  - 原文件：`/path/to/上海复动医疗公司介绍.pptx` → 翻译为英文：`/path/to/上海复动医疗公司介绍英文.pptx`
  - 原文件：`/path/to/产品手册.pptx` → 翻译为日文：`/path/to/产品手册日文.pptx`
  - 原文件：`/path/to/Company_Profile.pptx` → 翻译为中文：`/path/to/Company_Profile中文.pptx`
