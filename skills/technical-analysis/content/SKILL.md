# 技术分析 SKILL

## 概述

基于"规则计算在前，模型解读在后"的设计理念，对单一标的执行结构化技术分析。Python 负责行情获取、指标计算和形态扫描，LLM 通过五维交叉验证框架进行归纳解读，输出可复核的技术分析报告。

定位：研究辅助工具，提供客观技术面底稿。不给出买卖指令、仓位建议或收益预测。

## 使用场景

- 日常复盘任意标的的技术面状态
- 判断标的短期处于趋势延续、震荡、动量过热还是低波压缩
- 辅助交易节奏研判和风险识别
- 为研究报告提供技术面底稿
- 多标的技术面快速扫描和对比

## 执行步骤

### 第一步：标的识别与数据获取

1. **确认分析标的**：
   - 国债期货：`T0`（十年）、`TF0`（五年）、`TS0`（二年）；用户只说"国债期货"默认 T0
   - A股个股：如 `600519.SH`、`000001.SZ`
   - 股票指数：如"上证指数"、"沪深300"、"创业板指"
   - ETF：如 `510300`、`159915`
   - 商品期货：如"螺纹钢主力"、"原油主力"
   - 用户输入模糊时，先确认具体标的再继续

2. **获取数据**：用 Python 脚本获取至少 250 个交易日的日线 OHLCV 数据
   - 数据源优先级：AKShare > Tushare > 腾讯财经 > 新浪财经 > BaoStock
   - 字段标准化为：date, open, high, low, close, volume
   - 数据获取失败时按优先级切换数据源

### 第二步：核心技术指标计算

使用 TA-Lib（或 pandas_ta / 纯 numpy 替代）计算五类指标：

**趋势模块**：
- MA5, MA10, MA20, MA60（均线系统）
- MACD：DIF, DEA, MACD柱体（参数 12/26/9）
- 均线排列状态：多头排列 / 空头排列 / 均线纠缠

**动量模块**：
- RSI(6), RSI(12), RSI(14), RSI(24)
- KDJ：K, D, J（参数 9/3/3）

**波动模块**：
- BOLL(20,2)：上轨、中轨、下轨、%B、带宽
- ATR(14)

**量价模块**：
- 成交量及其 5日/20日均量
- 量比 = 当日成交量 / 过去5日平均成交量

**扩展指标**（用于异常扫描，不逐项写入正文）：
- 趋势类：ADX(14), ADXR(14), DX(14), PLUS_DI, MINUS_DI, AROON, AROONOSC
- 动量类：WILLR, CCI(14/20), MOM(10), ROC(10), ROCP(10), TRIX(15), ULTOSC, CMO(14), APO(12), PPO(12)
- 波动类：ATR(7), NATR(14), STDDEV(20), BOLL %B, BOLL带宽
- 量价类：OBV, AD, ADOSC, MFI(14)

### 第三步：K线形态识别

调用 TA-Lib 的 CDL 系列函数，批量识别 61 种经典 K 线形态：

```python
cdl_functions = [f for f in dir(talib) if f.startswith('CDL')]
patterns_found = []
for func_name in cdl_functions:
    func = getattr(talib, func_name)
    result = func(open_arr, high, low, close)
    recent = result[-30:]  # 最近30个交易日
    hits = np.where(recent != 0)[0]
    for idx in hits:
        patterns_found.append({
            'date': df['date'].iloc[-30+idx],
            'pattern': func_name.replace('CDL', ''),
            'direction': 'bullish' if recent[idx] > 0 else 'bearish',
            'strength': abs(recent[idx])
        })
```

对最近 3 个交易日出现的形态，统计过去 3 年的历史胜率、盈亏比和 5 日期望收益。

形态分三类：
- 单K线：十字星、锤子线、上吊线、蜻蜓十字、墓碑十字、纺锤线、光头光脚线
- 双K线：吞没、乌云盖顶、刺透、孕线、十字孕线
- 多K线：早晨之星、黄昏之星、三只乌鸦、三白兵

### 第四步：历史分位数扫描

以过去 3 年（约 750 个交易日）为窗口，计算所有指标的历史分位数：

```python
def percentile_rank(series, current_value, window=750):
    historical = series[-window:]
    historical = historical[~np.isnan(historical)]
    if len(historical) == 0:
        return 50.0
    return (historical < current_value).sum() / len(historical) * 100

# 对每个指标计算分位数
indicators_pct = {}
for name, series, current in indicator_list:
    indicators_pct[name] = percentile_rank(series, current)
```

**异常判定规则**：
- 分位数 > 90% → 历史高位（可能过热/波动放大）
- 分位数 < 10% → 历史低位（可能超卖/波动压缩）
- 同类 3 个以上指标同步极端 → 技术共振

### 第六步：五维交叉验证（LLM 解读核心）

Python 计算完成后，LLM 按以下框架对信号进行归纳解读。这是整个分析最核心的环节。

#### 6.1 五维归类

| 维度 | 核心问题 | 主要指标 |
|------|----------|----------|
| 趋势 | 价格方向是否成立？ | 均线排列、价格vs关键MA、MACD方向 |
| 动量 | 边际强弱是否改善/过热？ | RSI、KDJ、扩展动量指标 |
| 波动 | 风险环境扩张还是收敛？ | BOLL通道位置、ATR、波动分位 |
| 量价 | 价格变化有成交配合吗？ | 成交量变化、量比、OBV/MFI方向 |
| 位置风险 | 当前状态偏离历史常态吗？ | 多指标历史分位数、同类共振 |

各维度功能不同：趋势和动量主要服务于方向判断，波动和位置风险主要服务于风险识别，量价主要服务于信号质量验证。

#### 6.2 维度内部一致性判断（第一层过滤）

每个维度内部检查信号是否方向一致。内部一致 → 该维度可信度高；内部分歧 → 降低解释强度。

- **趋势**：均线结构 + 价格位置 + MACD DIF/DEA 是否同向。若价格位置偏强但 MACD 转弱，说明趋势与动能分歧。
- **动量**：RSI + KDJ + 扩展动量是否共同修复/转弱/过热。若短周期与中周期背离，说明情绪未形成一致。
- **波动**：ATR + BOLL带宽 + 通道位置是否共同指向扩张或收敛。若价格触通道边界但 ATR 未确认，波动支持不足。
- **量价**：价格方向与成交量、量比是否同向。缺乏成交支持或成交异常放大但方向不清，需警惕噪声。
- **位置风险**：是否多个同类指标同步极端分位。单一极端只是局部异常，多指标共振才说明偏离常态。

#### 6.3 跨维度验证（第二层过滤）

| 验证关系 | 组合 | 回答问题 | 组合含义 |
|----------|------|----------|----------|
| 方向确认 | 趋势 x 动量 | 方向信号是否成立 | 同向：相互验证，可信度高；分歧：降低方向强度 |
| 质量确认 | 趋势 x 量价 | 价格信号是否可靠 | 同向：突破获成交配合；分歧：警惕假突破 |
| 风险确认 | 动量 x 波动 x 位置风险 | 当前风险是否累积 | 同向：识别过热/过冷/压缩；分歧：约束结论强度 |
| 形态验证 | K线形态 x 核心维度 | 形态是否增强主判断 | 同向：增权；反向或样本不足：降权 |

**跨维度验证细则**：

1. **趋势 x 动量（方向确认）**：
   - 价格站上关键均线 + 动量同步修复 → 方向可信度高
   - 价格弱势 + 动量继续回落 → 下行延续性强
   - 趋势与动量背离 → 降低方向判断强度

2. **趋势 x 量价（质量确认）**：
   - 价格突破 + 成交放大、量比抬升 → 突破有效性高
   - 价格上涨但成交萎缩 → 信号质量不足
   - 放量但方向不清 → 理解为交易分歧，不直接推导方向

3. **动量 x 波动 x 位置风险（风险确认）**：
   - 动量高位 + ATR/BOLL扩张 + 多指标历史高分位 → 高波动强动量高拥挤，提示追涨风险
   - 动量低位 + 价格接近通道下沿 + 多指标低分位 → 超卖/低迷，但非反转信号
   - ATR低分位 + BOLL收窄 + 成交低迷 → 低波压缩，后续突破时波动放大概率上升

4. **K线形态 x 核心维度（形态验证）**：
   - 看涨形态 + 趋势修复 + 动量回升 + 成交配合 → 增强信号
   - 看涨形态出现在下跌趋势中且量价未确认 → 只视为短期反弹线索
   - 看跌形态 + 高位钝化 + 动量回落 + 波动放大 → 风险提示更强
   - 形态样本不足或与核心指标方向相反 → 主动降权

#### 6.4 信号确认度评级

- **强确认**：趋势+动量+量价同向，波动配合，位置风险不极端
- **中等确认**：方向信号成立但量价或波动未完全配合
- **弱确认/分歧**：维度间存在明显矛盾，需条件化表达

## 注意事项

### 定位边界
- 研究辅助工具，不是交易系统
- 不承担收益预测、买卖指令、仓位建议功能
- 技术信号不能替代基本面判断

### 解读原则
- 趋势偏强 ≠ 可以追涨（需动量、量价、位置风险交叉验证）
- RSI/KDJ高位 ≠ 必然下跌（强趋势中可高位钝化）
- 单一K线形态 ≠ 反转信号（需与核心维度方向一致才增权）
- 历史胜率 ≠ 本次必然兑现（受样本量和市场环境约束）
- 低分位 ≠ 反转成立（需趋势结构修复和量价改善后才表述为"低位修复"）

### 资产特殊性
- **国债期货**：低波动资产，ATR和BOLL带宽的边际变化比绝对水平更重要；期货量价关系反映交易活跃度和多空博弈程度；利率债定价受货币政策和资金面主导
- **A股个股**：关注涨跌停对指标的影响；量价关系更直接反映资金进出
- **指数/ETF**：波动相对平滑，均线和趋势指标参考价值更高
- **商品期货**：注意合约换月对连续数据的影响；持仓量可作为量价补充
