# 进销存业务规则详解

## 一、核心业务概念

### 1.1 仓库管理
- 支持多仓库管理（仓库1、仓库2...）
- 每个仓库独立核算库存
- 支持仓库间的库存调拨

### 1.2 商品管理
- 商品分类：原材料、半成品、成品、辅助材料等
- 计量单位：件、个、箱、千克、升等
- 价格管理：采购价、销售价、参考价

### 1.3 供应商与客户
- 供应商档案：编码、名称、联系人、电话、地址
- 客户档案：编码、名称、联系人、电话、地址、信用额度

## 二、单据类型定义

### 2.1 采购模块
| 单据类型 | 代码 | 说明 |
|----------|------|------|
| 采购订单 | PO | 采购意向，尚未执行 |
| 采购入库 | PI | 实际入库完成 |
| 采购退货 | PR | 退给供应商 |

### 2.2 销售模块
| 单据类型 | 代码 | 说明 |
|----------|------|------|
| 销售订单 | SO | 销售意向，尚未执行 |
| 销售出库 | SI | 实际出库完成 |
| 销售退货 | SR | 客户退货 |

### 2.3 库存模块
| 单据类型 | 代码 | 说明 |
|----------|------|------|
| 库存调拨 | IT | 仓库间调拨 |
| 库存调整 | IA | 盘盈盘亏调整 |
| 库存盘点 | IC | 盘点作业 |

## 三、业务流程

### 3.1 采购入库流程
```
1. 创建采购订单（可选）
      ↓
2. 供应商发货
      ↓
3. 仓库接收商品
      ↓
4. 质量检验（可选）
      ↓
5. 确认入库
      ↓
6. 更新库存
      ↓
7. 生成付款计划
```

### 3.2 销售出库流程
```
1. 创建销售订单（可选）
      ↓
2. 检查库存是否充足
      ↓
3. 仓库备货
      ↓
4. 质量检验（可选）
      ↓
5. 确认出库
      ↓
6. 更新库存
      ↓
7. 生成应收款
```

### 3.3 库存调拨流程
```
1. 发起调拨申请
      ↓
2. 源仓库确认出库
      ↓
3. 在途运输
      ↓
4. 目标仓库确认入库
      ↓
5. 完成调拨
```

### 3.4 盘点作业流程
```
1. 创建盘点单
      ↓
2. 打印盘点表
      ↓
3. 实地盘点
      ↓
4. 录入实盘数量
      ↓
5. 系统计算差异
      ↓
6. 复核差异
      ↓
7. 确认调整
      ↓
8. 生成调整单据
```

## 四、库存计算规则

### 4.1 库存数量计算
```
当前库存 = 期初库存 + 本期入库 - 本期出库
```

### 4.2 库存金额计算（加权平均法）
```
加权平均价 = (期初金额 + 本期入库金额) / (期初数量 + 本期入库数量)
当前金额 = 当前库存 × 加权平均价
```

### 4.3 库存预警判断
```
IF 当前库存 <= 最低库存 THEN 触发预警
```

## 五、权限控制

### 5.1 角色定义
| 角色 | 权限 |
|------|------|
| 管理员 | 全部功能 |
| 采购员 | 采购相关 |
| 销售员 | 销售相关 |
| 仓管员 | 库存相关、盘点 |
| 财务 | 报表查看 |

### 5.2 操作权限
- 新增：需要有对应模块的新增权限
- 修改：单据未审核时可修改
- 删除：仅草稿状态可删除
- 审核：需要有审核权限

## 六、异常处理

### 6.1 库存不足处理
1. 提示库存不足数量
2. 建议采购数量
3. 支持分批出库

### 6.2 单据冲销
- 错误单据需要红冲
- 红冲后生成相反单据
- 保持账目完整可追溯

### 6.3 数据一致性
- 所有操作需要事务支持
- 操作失败自动回滚
- 记录操作日志

## 七、报表规范

### 7.1 报表周期
- 日报表：当日业务汇总
- 周报表：本周业务汇总
- 月报表：本月业务汇总
- 年报表：本年业务汇总

### 7.2 报表格式
- 支持导出Excel
- 支持打印
- 支持自定义列
