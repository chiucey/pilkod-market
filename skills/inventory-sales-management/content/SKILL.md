# 进销存管理系统

## 功能概览

本技能提供完整的进销存管理功能，包括以下核心模块：

### 1. 进货管理（采购）
- **采购入库**：记录商品采购入库，支持多商品同时入库
- **采购退货**：处理供应商退货业务
- **采购查询**：查看采购历史记录

### 2. 销售管理
- **销售出库**：记录商品销售出库，生成销售单
- **销售退货**：处理客户退货业务
- **销售查询**：查看销售历史和统计数据

### 3. 库存管理
- **库存查询**：实时查询各商品库存数量
- **库存预警**：设置库存下限提醒
- **库存调拨**：仓库间商品调拨
- **库存流水**：查看库存变动明细

### 4. 盘点管理
- **创建盘点单**：发起库存盘点任务
- **盘点录入**：录入实际盘点数据
- **盈亏处理**：系统自动计算差异并调整库存

## 工作流程

### 标准业务流程

```
进货流程：供应商 → 采购订单 → 入库检验 → 入库确认 → 库存增加
销售流程：客户 → 销售订单 → 出库检验 → 出库确认 → 库存减少
盘点流程：发起盘点 → 实地盘点 → 数据录入 → 差异分析 → 盈亏调整
```

## 交互流程

### 采购入库流程
1. 用户发起采购入库请求
2. 系统要求提供：供应商、商品明细（编码/名称、数量、单价）
3. 系统生成采购单号，更新库存
4. 返回入库确认信息

### 销售出库流程
1. 用户发起销售出库请求
2. 系统检查库存是否充足
3. 若库存不足，提示警告
4. 若充足，要求确认：客户、商品明细、数量
5. 系统生成销售单号，更新库存
6. 返回出库确认信息

### 盘点流程
1. 用户发起盘点请求
2. 系统创建盘点单，显示应盘商品列表
3. 用户逐一录入实盘数量
4. 系统计算差异（账面 - 实盘）
5. 用户确认处理方式（调整库存/待查）
6. 系统执行库存调整

## 业务规则

### 库存预警规则
- 当库存 <= 最低库存时，触发预警提醒
- 支持多仓库分别设置预警

### 价格控制
- 采购价格不能为空，需填写
- 销售价格不能低于采购价格（需配置允许亏损）

### 单据状态
- 采购/销售单：草稿 → 已确认 → 已完成
- 盘点单：进行中 → 已确认 → 已归档

## 报表功能

### 库存报表
- 库存汇总表：按商品/仓库汇总
- 库存明细表：库存流水明细
- 库存预警表：低于预警线的商品

### 经营报表
- 采购汇总表：按时间/供应商统计
- 销售汇总表：按时间/客户统计
- 毛利分析表：销售毛利统计

## 错误处理

| 错误码 | 说明 | 处理方式 |
|--------|------|----------|
| E001 | 库存不足 | 检查库存或建议采购 |
| E002 | 商品不存在 | 新增商品或检查编码 |
| E003 | 单据已审核 | 无法修改，请先反审核 |
| E004 | 参数不完整 | 补充缺失参数 |
| E005 | 金额不平 | 检查单价和数量 |
