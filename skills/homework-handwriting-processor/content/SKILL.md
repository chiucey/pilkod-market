# 作业题目与笔迹处理器

## 功能概述

1. **题目识别** - 检测并提取图片中的所有题目
2. **多题目分离** - 将多道题目分别处理
3. **手写笔记提取** - 识别手写内容
4. **思维分析** - 判断是思维过程还是简单计算/划线
5. **流程图生成** - 若为思维过程，生成100字内流程图（箭头链接）
6. **笔迹去除** - 生成干净的无笔迹图片
7. **题目输出** - 用文字形式呈现题目

## 处理流程

### 步骤1：题目检测与分离

1. 使用 `images_understand` 工具分析图片
2. 识别图片中的所有题目数量和位置
3. 若有多道题目，按位置/区域分离

### 步骤2：手写笔记提取

1. 提取图片中的所有手写内容
2. 分析手写内容的性质：
   - **思维过程**：包含解题思路、分析步骤、逻辑推导
   - **简单计算**：仅数字、运算符、划线标记
   - **划线标记**：下划线、波浪线、叉号等

### 步骤3：思维判断与流程图生成

**判断标准**：
- 思维过程：包含因果关系、推理步骤、分析说明
- 非思维过程：纯计算结果、涂改标记、简单划线

**若为思维过程**：
1. 用 100 字以内描述思维流程
2. 使用箭头 `→` 连接各步骤
3. 格式：`步骤1 → 步骤2 → 步骤3`
4. 仅包含关键思维节点，不含计算细节

### 步骤4：笔迹处理

根据用户需求提供：
- **仅题目文字**：提取题目文本
- **无笔迹卷子**：生成去除手写的干净图片

## 输出格式

### 题目输出

```
题目1：[题目内容]
├── 提取的手写内容：[手写文字]
├── 笔迹类型：[思维过程/简单计算/划线标记]
├── 思维流程图：[如有]
└── 无笔迹图片：[如需要]

题目2：...
```

### 流程图格式示例

```
理解题意 → 分析已知条件 → 确定解题方向 → 验证结果
```

## 使用工具

- `images_understand`：图片内容分析、题目识别、手写提取
- `image_synthesize`：笔迹去除处理
- `render_mermaid`：生成可视化流程图（如需要）

## 注意事项

1. 计算过程不生成流程图，只提取最终答案
2. 流程图严格控制在 100 字以内
3. 多题目时按逻辑顺序排列
4. 用户明确要求时才生成无笔迹卷子图片
