# Excel深度分析技能

## 技能概述

本技能提供对Excel表格的全面深度分析，自动完成以下工作：

1. **数据读取与解析** - 读取Excel文件，分析数据结构
2. **数据质量检查** - 检测缺失值、重复行、格式错误、数据类型异常
3. **统计分析** - 描述性统计、分布分析、相关性分析、趋势检测
4. **异常检测** - 使用统计方法和业务规则识别异常值
5. **问题诊断** - 识别数据中的矛盾、不一致和潜在问题
6. **根因分析** - 深入分析问题根源，定位关键因素
7. **报告生成** - 生成结构化的分析报告

## 工作流程

### 步骤1：数据读取与结构分析

```
1. 读取Excel文件（支持.xlsx、.xls、.csv格式）
2. 识别工作表结构（表头、数据区域、格式）
3. 分析字段类型（数值、文本、日期、布尔等）
4. 统计记录数和字段数
5. 检测数据稀疏性
```

### 步骤2：数据质量检查

**必检项目**：
- 缺失值检测（各字段缺失率、缺失模式）
- 重复行检测（完全重复、部分关键字段重复）
- 格式异常（日期格式不一致、数值格式混乱）
- 数据类型不匹配
- 边界值检测（超出合理范围的值）

**输出**：数据质量评分（0-100分）和问题清单

### 步骤3：统计分析

**描述性统计**：
- 数值型：均值、中位数、标准差、最小/最大值、四分位数、偏度、峰度
- 分类型：唯一值数量、众数、频率分布
- 日期型：时间跨度、时间分布

**高级分析**：
- 相关性分析（Pearson/Spearman相关系数矩阵）
- 分布检验（正态性检验）
- 趋势分析（时间序列特征）
- 分组对比分析

### 步骤4：异常检测

**统计方法**：
- Z-score方法（检测偏离均值超过3σ的值）
- IQR方法（检测超出1.5倍四分位距的值）
- 孤立森林算法
- 基于业务规则的异常检测

**异常分类**：
- 数值异常（极端值）
- 格式异常（不符合预期格式）
- 逻辑异常（违反业务规则的组合）
- 模式异常（不符合整体分布模式）

### 步骤5：问题诊断与根因分析

**问题识别框架**：

```
问题类型          识别方法              分析深度
────────────────────────────────────────────────────
数据完整性问题    缺失值/重复分析        基础
数据一致性问题    跨字段/跨表验证        中级
数据准确性问题    业务规则校验          深入
数据时效性问题    时间戳分析            基础
数据合理性异常    统计+业务规则         深入
```

**根因分析技术**：
- 帕累托分析（80/20法则）
- 鱼骨图分析（人机料法环测）
- 关联规则挖掘
- 对比分析（不同维度切片对比）
- 假设检验

### 步骤6：报告生成

**报告结构**：

```markdown
# Excel数据分析报告

## 1. 执行摘要
   - 分析概述
   - 关键发现
   - 风险等级

## 2. 数据概况
   - 数据基本信息
   - 字段清单及类型
   - 数据规模统计

## 3. 数据质量评估
   - 整体质量评分
   - 问题清单及严重程度
   - 质量问题分布图

## 4. 统计分析结果
   - 描述性统计摘要
   - 关键指标分析
   - 分布特征描述

## 5. 异常检测报告
   - 异常记录清单
   - 异常类型分布
   - 异常模式分析

## 6. 问题诊断与根因分析
   - 发现的问题列表
   - 问题严重程度排序
   - 根因分析结果

   - 优先级排序的问题处理建议
   - 数据改进建议
   - 预防措施
```

## 执行指南

### 基本分析命令

用户只需提供Excel文件路径，即可启动完整分析：

```
请分析这个Excel文件：data.xlsx
```

### 自定义分析选项

用户可以通过以下方式指定分析重点：

```
分析要点：
- 重点字段：销售额、客户数、日期
- 分析维度：按月份、按地区、按产品线
- 异常检测灵敏度：高/中/低
- 是否包含预测分析：是/否
```

### 分析结果展示

分析完成后，结果包含：
1. **结构化报告**：Markdown格式的完整分析报告
2. **数据表格**：异常记录、问题清单等以表格形式呈现
3. **可视化图表**：分布图、相关性热力图、异常点标注图等
4. **修复建议**：针对每个问题的具体修复方案

## 技术实现

**依赖工具**：
- Python 3.x
- pandas（数据处理）
- openpyxl（Excel读取）
- scipy（统计分析）
- matplotlib/seaborn（可视化）

**执行方式**：
使用 minimax-xlsx 技能中的Python执行环境或直接调用分析脚本

## 常见场景处理

| 场景 | 分析重点 | 报告侧重点 |
|------|----------|------------|
| 销售数据 | 趋势、异常波动、区域对比 | 业务增长机会与风险 |
| 财务数据 | 数据准确性、完整性、一致性 | 财务风险点 |
| 用户数据 | 缺失率、分布特征、异常行为 | 用户体验问题 |
| 生产数据 | 产能异常、质量波动、设备故障 | 生产效率优化 |
| 库存数据 | 合理性、周转率、呆滞料 | 库存优化建议 |

## 限制与注意事项

1. **文件大小限制**：建议单个文件不超过100MB
2. **密码保护**：加密的Excel文件需要提供密码
3. **多工作表**：默认分析第一个工作表，可指定工作表名
4. **宏和公式**：VBA宏不会执行，公式结果会被读取而非公式本身
5. **中文支持**：完整支持中文列名和数据

## 质量标准

本技能保证：
- 所有分析基于数据事实，不添加虚构内容
- 异常检测结合统计方法与业务理解
- 根因分析提供证据支持，避免主观臆断
- 报告结构清晰，便于决策参考
