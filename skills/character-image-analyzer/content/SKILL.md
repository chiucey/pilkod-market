# 人物图片角色分析器

## 功能说明

本技能用于分析用户提供的人物参考图片,提取关键视觉特征,生成结构化、详细的女性角色描述文档,供视频制作使用。

## 分析维度

分析上传的人物图片时,需要从以下维度提取信息:

### 1. 基础外貌特征

- **年龄范围**: 估计年龄段(如:20-25岁、30岁左右等)
- **脸型**: 圆脸、瓜子脸、方脸、鹅蛋脸等
- **肤色**: 白皙、自然、小麦色等
- **身高体型**: 高挑、中等、娇小;苗条、匀称、丰满等

### 2. 面部特征

- **眼睛**: 形状(杏眼、桃花眼、丹凤眼等)、大小、眼神特点
- **眉毛**: 眉形(柳叶眉、平眉、拱形眉等)、颜色
- **鼻子**: 鼻梁高低、鼻型特点
- **嘴唇**: 厚薄、唇形、常见表情
- **发型**: 长度、颜色、卷直、刘海样式

### 3. 服装风格

- **整体风格**: 商务、休闲、甜美、优雅、运动、复古等
- **色彩偏好**: 常用色系、色彩搭配特点
- **服装类型**: 常见穿着(裙装、裤装、职业装等)
- **配饰**: 眼镜、首饰、包包等标志性配饰

### 4. 气质与个性

- **气质类型**: 温柔、干练、活泼、知性、冷艳等
- **表情特点**: 微笑频率、严肃程度、亲和力
- **姿态特征**: 站姿、坐姿、行走风格

### 5. 场景适配建议

- **适合的视频场景**: 职场、生活、旅行、运动等
- **角色定位建议**: 主角、配角、旁白等
- **情感表达范围**: 适合表现的情绪类型

## 使用说明

1. **接收图片**: 用户上传人物参考图片
2. **图片分析**: 使用 images_understand 工具分析图片内容
3. **信息提取**: 按照分析维度提取关键特征
4. **生成描述**: 按照输出模板生成结构化角色描述
5. **补充建议**: 提供场景适配和制作建议

## 注意事项

- 分析时注意尊重用户隐私,不要泄露任何个人信息
- 确保描述客观准确,避免主观臆断
- 对于无法准确判断的特征,标注为"无法确定"
- 生成的角色描述应具有视频制作实用性
