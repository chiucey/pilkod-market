# 营养素补充剂协议标准

## 一、基础补充原则

### 1.1 个体化评估框架

**补充前必评要素**
```
① 饮食摄入评估（食物频率问卷、24小时膳食回顾）
② 生活方式因素（压力水平、运动量、日晒时间）
③ 生理状态（年龄、性别、孕期/哺乳期）
④ 健康状况（消化吸收能力、慢性疾病、用药情况）
⑤ 检测数据（实验室检测结果的客观依据）
⑥ 经济承受力（长期坚持的可能性）
```

**补充优先级判定**
```
P0（紧急补充）：已有明显缺乏症状或检测确认严重不足
P1（优先补充）：功能医学优化范围以下，有相关症状
P2（常规补充）：维持最佳功能状态
P3（可选补充）：特定需求或进一步优化
```

### 1.2 补充剂质量识别

**优质补充剂特征**
- 活性形式：甲基叶酸而非叶酸；甲基钴胺素而非氰钴胺
- 可利用形态：镁甘氨酸盐/苏糖酸盐而非氧化物
- 第三方认证：NSF、USP、ConsumerLab、CL
- 配方清洁：无不必要的填充剂、颜色、粘合剂
- 生物利用度：考虑吸收率和利用形式

**避免的成分**
- 人工色素和香料
- 氢化油或部分氢化油
- 过多糖分或不必要甜味剂
- 常见过敏原（未标注）

## 二、核心营养素协议

### 2.1 维生素D3

**检测基础**
- 检测25-OH维生素D水平
- 基线评估后开始补充
- 3个月后复查调整剂量

**补充方案**

| 人群 | 起始剂量 | 目标剂量 | 说明 |
|-----|---------|---------|-----|
| 一般成人 | 2000-4000 IU/日 | 维持2000 IU/日 | 维持目标水平 |
| 缺乏者（<20 ng/mL） | 5000-10000 IU/日 | 4-8周后降至维持量 | 纠正缺乏 |
| 肥胖/吸收不良 | 6000-10000 IU/日 | 维持4000-6000 IU/日 | 增加剂量 |
| 骨质疏松风险 | 4000-8000 IU/日 | 维持3000-4000 IU/日 | 结合K2 |

**协同配伍**
- 维生素K2（MK-7）：100-200 mcg/日（促进钙沉积入骨）
- 镁：400-800 mg/日（参与维生素D代谢）
- 钙：仅在饮食摄入不足时额外补充

**服用建议**
- 随含脂肪的餐食服用以提高吸收
- 避免与矿物油、泻药同时服用
- 分次服用比单次大剂量更好

**注意事项**
- 某些药物相互作用（类固醇、抗惊厥药）
- 定期监测血钙水平（高剂量时）
- 肾功能不全者慎用

---

### 2.2 Omega-3不饱和脂肪酸

**检测基础**
- Omega-3指数（红细胞EPA+DHA）：最佳8-12%
- AA/EPA比值：理想<3

**补充方案**

| 情况 | EPA+DHA剂量 | 服用周期 | 说明 |
|-----|-------------|---------|-----|
| 一般抗炎维护 | 1000-2000 mg | 持续 | 心脑健康 |
| 慢性炎症/自身免疫 | 2000-4000 mg | 3-6个月后评估 | 抗炎效果 |
| 高甘油三酯 | 3000-4000 mg | 持续 | 医疗监督下 |
| 心理/认知健康 | 2000-3000 mg | 持续 | EPA优先 |

**EPA与DHA配比**
- 抗炎/情绪：EPA优先（EPA>DHA）
- 脑功能/认知：DHA可较高
- 通用抗炎：1:1或2:1（EPA:DHA）

**协同配伍**
- 抗氧化剂（维生素E、辅酶Q10）：防止氧化
- 磷脂：促进DHA整合入细胞膜
- 维生素D：协同抗炎

**服用建议**
- 随餐服用，减少胃肠不适
- 冰箱冷藏保持新鲜度
- 选择肠溶或乳化制剂减少鱼腥嗝

**质量标准**
- IFOS（国际鱼油标准）认证
- 重金属检测（汞、铅、砷、镉）
- 氧化指标（过氧化物<5 mEq/kg）
- PCBs和Dioxins检测

### 2.3 镁

**检测基础**
- 血清镁：参考范围0.75-0.95 mmol/L
- 红细胞镁：更准确的组织镁状态
- 临床症状评估（肌肉痉挛、失眠等）

**补充方案**

| 镁形态 | 剂量范围 | 特点 | 适用场景 |
|-------|---------|------|---------|
| 甘氨酸镁 | 200-400 mg | 高吸收率，温和 | 睡眠、焦虑、一般补充 |
| 苏糖酸镁 | 200-400 mg | 高生物利用度 | 脑功能、认知 |
| 柠檬酸镁 | 200-400 mg | 适中吸收，轻度通便 | 一般补充、便秘倾向 |
| 牛磺酸镁 | 200-400 mg | 心血管亲和性 | 心脏健康、高血压 |
| 氧化镁 | 400-800 mg | 吸收率低，仅大剂量时用 | 经济型，但不推荐 |

**协同配伍**
- 维生素B6：促进镁进入细胞
- 维生素D：代谢需要镁
- 牛磺酸：协同神经系统支持

**服用建议**
- 分次服用，减少腹泻风险
- 晚餐时或睡前服用
- 肾脏功能异常者慎用

### 2.4 维生素B族复合物

**检测基础**
- 血清B12：应>400 pg/mL（功能医学）
- 叶酸：血清叶酸>7 ng/mL
- 同型半胱氨酸：<8 μmol/L（B族利用指标）
- MMA（甲基丙二酸）：B12功能指标

**B12补充方案**

| B12形态 | 剂量 | 适用人群 | 说明 |
|--------|-----|---------|-----|
| 甲基钴胺素 | 1000-5000 mcg | 一般人群 | 活性形式，直接利用 |
| 羟钴胺素 | 1000-5000 mcg | 肾脏问题者 | 储存形式 |
| 腺苷钴胺素 | 1000-3000 mcg | 能量/代谢支持 | 参与能量产生 |

| 补充方式 | 频率 | 适用情况 |
|---------|------|---------|
| 口服舌下含服 | 每日 | 一般吸收功能正常 |
| 舌下喷剂 | 每日 | 吞咽困难或胃酸问题 |
| 注射 | 每周-每月 | 严重缺乏或吸收障碍 |

**叶酸补充方案**

| 情况 | 剂量 | 形态 |
|-----|-----|-----|
| 一般维护 | 400-800 mcg | 甲基叶酸（5-MTHF） |
| MTHFR变异 | 800-1600 mcg | 甲基叶酸必须 |
| 高同型半胱氨酸 | 800-1200 mcg | 配合B6、B12 |

**B族复合物服用建议**
- 早晨随餐服用
- 避免晚间服用（可能影响睡眠）
- B3（烟酸）避免与他汀类药物同服
- B6长期大剂量需监测神经症状

### 2.5 益生菌

**菌株选择指南**

| 适应症 | 推荐菌株 | 剂量范围 |
|-------|---------|---------|
| 肠易激综合征 | 婴儿双歧杆菌35624 | 1×10⁹-1×10¹⁰ CFU |
| 抗生素相关腹泻 | 布拉氏酵母菌 | 250-500 mg/日 |
| 免疫调节 | 嗜酸乳杆菌NCFM + 双歧杆菌Bi-07 | 1-2×10¹⁰ CFU |
| 抑郁/焦虑支持 | 瑞士乳杆菌R0052 + 长双歧杆菌R0175 | 3×10⁹ CFU |
| 儿童湿疹 | 鼠李糖乳杆菌GG | 1×10¹⁰ CFU |
| 女性私密健康 | 卷曲乳杆菌、格氏乳杆菌 | 1-5×10⁹ CFU |
| 一般肠道健康 | 多菌株复合制剂 | 5-10×10⁹ CFU |

**服用指南**
- 活菌数：选择至少50亿CFU
- 储存：多数需冷藏
- 服用时间：晨起空腹或睡前（避开胃酸高峰）
- 与抗生素：间隔2小时以上

### 2.6 谷胱甘肽与抗氧化剂

**谷胱甘肽补充策略**

| 形式 | 剂量 | 生物利用度 | 说明 |
|-----|-----|-----------|-----|
| 还原型GSH | 250-500 mg | 直接补充 | 效果好但易氧化 |
| N-乙酰半胱氨酸（NAC） | 600-1800 mg | 前体，体内合成 | 经济实用 |
| S-乙酰谷胱甘肽（SAG） | 50-100 mg | 吸收率高 | 较新型式 |
| α-硫辛酸 | 300-600 mg | 再生GSH | 多效抗氧化 |

**协同抗氧化方案**
- 维生素C：500-2000 mg/日（再生谷胱甘肽）
- 维生素E：400 IU/日（混合生育酚）
- 辅酶Q10：100-300 mg/日（线粒体保护）
- 硒：200 mcg/日（谷胱甘肽过氧化物酶）

## 三、特殊人群协议

### 3.1 女性生殖健康

**经前综合征支持**
```
方案周期：月经前14天开始

核心组合：
- 钙：1200 mg/日（分2次）
- 镁：400 mg/日
- 维生素B6：50-100 mg/日（仅经前）
- 月见草油：1000-2000 mg/日
- DHA：1000 mg/日

疗程：3个月经周期后评估
```

**围绝经期/更年期支持**
```
核心组合：
- 大豆异黄酮：50-100 mg/日（非转基因）
- 黑升麻提取物：40-80 mg/日
- 红三叶草：40-80 mg/日
- 亚麻籽：2汤匙/日
- Omega-3：2000 mg/日

辅助：益生菌、肝脏支持
```

### 3.2 男性健康

**睾酮支持**
```
基础方案：
- 锌：30 mg/日
- 维生素D：3000-4000 IU/日
- 镁：400 mg/日
- Omega-3：2000 mg/日

增强方案（视情况添加）：
- D-天冬氨酸：2-3g/日
- 刺蒺藜提取物：250-500 mg/日
- 玛咖：1500-3000 mg/日
- Fenugreek葫芦巴：500-600 mg/日

评估周期：3个月后复查总睾酮/游离睾酮
```

### 3.3 儿童补充（4岁以上）

**基本原则**
- 剂量按体重调整（成人剂量的1/4-1/2）
- 优先选择食物来源
- 避免不必要的添加剂
- 咀嚼制剂更适宜

**常见补充建议**

| 营养素 | 剂量（4-12岁） | 说明 |
|-------|---------------|-----|
| 维生素D | 1000-2000 IU/日 | 缺乏时加倍 |
| Omega-3 | 500-1000 mg EPA+DHA | 认知/行为支持 |
| 益生菌 | 5-10×10⁹ CFU | 肠道/免疫 |
| 锌 | 10-15 mg/日 | 免疫/生长发育 |
| 镁 | 100-200 mg/日 | 多动/睡眠 |

## 四、常见症状方案

### 4.1 慢性疲劳方案

**评估优先项**
- 甲状腺功能（TSH、FT3、FT4）
- 肾上腺功能（皮质醇曲线）
- 铁蛋白、维生素B12、叶酸
- 维生素D
- 血糖/胰岛素

**核心支持方案**
```
第一阶段（第1-4周）：
- 辅酶Q10：200 mg/日
- 镁：400 mg/日
- B族复合物：含B12和叶酸
- 铁（如缺乏）：复合铁剂

第二阶段（第5-12周）：
- 添加NADH：20 mg/日
- 乙酰左旋肉碱：500-1000 mg/日
- 红景天提取物：400 mg/日

支持措施：
- 规律作息
- 间歇性运动
- 压力管理
```

### 4.2 肠道修复方案

**肠漏/肠易激支持**
```
修复期（第1-8周）：
- 谷氨酰胺：5-10 g/日（空腹）
- 锌（鳌合形式）：30 mg/日
- 益生菌：10-50×10⁹ CFU/日
- 维生素A：3000 IU/日
- Omega-3：2000 mg/日

抗炎期（持续）：
- 槲皮素：500 mg/日
- 姜黄素：500 mg/日
- 消化酶：随大餐服用

菌群重建（8周后）：
- 益生元：FOS/GOS 3-5 g/日
- 发酵食品引入
```

### 4.3 情绪/心理健康支持

**焦虑/抑郁辅助方案**
```
炎症相关：
- Omega-3（EPA优先）：2000-3000 mg/日
- 维生素D：3000-4000 IU/日
- 锌：25-30 mg/日
- 益生菌（心理益生菌株）：10×10⁹ CFU

神经递质支持：
- 镁（甘氨酸镁）：400 mg/日
- 维生素B6（P5P）：25-50 mg/日
- SAMe：400-800 mg/日
- 5-HTP：50-150 mg/日（与SSRI同用需谨慎）

适应原支持：
- 南非醉茄：300-600 mg/日
- L-茶氨酸：200-400 mg/日
```

## 五、补充剂相互作用警示

### 5.1 常见禁忌配对

| 营养素组合 | 相互作用 | 处理方式 |
|----------|---------|---------|
| 钙 + 铁 | 吸收竞争 | 分开服用（间隔2小时） |
| 钙 + 锌/镁（高剂量） | 吸收竞争 | 分开或选择复合制剂 |
| 维生素E + 维生素K | 抗凝协同 | 监测INR/凝血功能 |
| Omega-3 + 华法林 | 抗凝协同 | 监测凝血参数 |
| 圣约翰草 + 5-HTP | 血清素综合征风险 | 避免联用 |
| 褪黑素 + 处方安眠药 | 镇静叠加 | 谨慎或避免 |

### 5.2 药物-营养素相互作用

| 药物类别 | 营养素影响 | 建议 |
|---------|----------|-----|
| 他汀类药物 | 辅酶Q10消耗 | 补充CoQ10 100-200 mg |
| SSRI抗抑郁药 | 5-HTP需谨慎 | 避免同时高剂量 |
| 利尿剂 | 镁、钾流失 | 监测电解质 |
| 二甲双胍 | B12吸收↓ | 监测B12水平 |
| 质子泵抑制剂 | B12、镁吸收↓ | 监测相关营养素 |
| 甲状腺药物 | 钙铁影响吸收 | 分开4小时服用 |

### 5.3 时间分服原则

**建议分开的补充剂**
```
【早晨】
- 甲状腺药物（空腹）
- 复合维生素B（供能）
- 辅酶Q10（能量）
- 空腹服用：谷氨酰胺、消化酶

【随早餐】
- 维生素D（配脂肪）
- Omega-3（配脂肪）
- 脂溶性营养素
- 益生菌（部分）

【午餐】
- 锌
- 铁（如需要，分开两次）
- 消化酶（随大餐）

【下午】
- 镁（肌肉/能量支持）

【晚餐】
- 消化酶（随大餐）
- 钙（睡前，如不分两次）

【睡前】
- 镁
- 褪黑素
- 甘氨酸镁
- 益生菌（特定菌株）
```
