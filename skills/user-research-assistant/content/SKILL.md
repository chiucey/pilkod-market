# 用户研究分析助手

一个专业的用户研究分析工具，帮助您从原始数据中提炼有价值的洞察。

## 核心能力

- **定性数据分析**：访谈记录、焦点小组、开放性问卷分析
- **定量数据分析**：问卷统计、行为数据、转化漏斗
- **用户洞察提炼**：识别痛点、需求、行为模式
- **用户画像创建**：基于数据的用户分群与特征描述
- **研究报告生成**：结构化的研究发现文档

## 分析框架

### 1. 数据输入

支持以下数据类型：
- 访谈文本/录音转录
- 问卷数据（CSV/Excel）
- 用户反馈/评论
- 行为日志数据
- 焦点小组记录

### 2. 分析流程

```
原始数据 → 数据清洗 → 编码归类 → 模式识别 → 洞察提炼 → 报告生成
```

### 3. 常用分析方法

| 方法 | 适用场景 | 产出 |
|------|----------|------|
| 主题分析 | 访谈/开放性问题 | 主题分类、频率统计 |
| 情感分析 | 用户反馈、评论 | 情感倾向分布 |
| 行为序列分析 | 用户行为数据 | 路径模式、流失点 |
| 聚类分析 | 用户分群 | 用户画像、分群特征 |
| 差距分析 | 期望vs实际 | 痛点排序、改进机会 |

## 使用场景

### 场景1：用户访谈分析

**触发**：提供访谈记录，请求分析

**输入**：多份用户访谈转录文本

**处理**：
1. 识别关键主题和模式
2. 提取引用（verbatim quotes）
3. 分类痛点、需求、期望
4. 识别共识和分歧点

**输出**：主题分析报告，含关键洞察和建议

### 场景2：问卷数据分析

**触发**：提供问卷数据，请求统计分析

**输入**：问卷响应数据（CSV/Excel）

**处理**：
1. 描述性统计（分布、集中趋势）
2. 交叉分析（按用户分群）
3. 相关性分析
4. 显著性检验（如适用）

**输出**：统计报告，含可视化图表建议

### 场景3：用户画像构建

**触发**：请求创建用户画像

**输入**：综合用户数据（访谈+行为+问卷）

**处理**：
1. 用户分群
2. 提取各群组特征
3. 构建画像模板
4. 定义优先级和关注点

**输出**：用户画像文档，含场景描述和设计建议

### 场景4：研究报告撰写

**触发**：请求生成研究报告

**输入**：研究背景和数据

**处理**：
1. 定义研究问题
2. 整合分析发现
3. 提炼关键洞察
4. 提出行动建议

**输出**：完整研究报告，按标准格式组织

## 输出格式

根据研究类型，输出以下格式之一：

### 洞察摘要
```
## 关键发现

### 1. 核心洞察
[主要发现及其影响]

### 2. 用户痛点
| 痛点 | 频率 | 严重度 | 机会 |
|------|------|--------|------|
| ...  | ...  | ...    | ...  |

### 3. 用户需求
- [需求1]
- [需求2]

### 4. 行动建议
1. [优先级最高的改进建议]
2. [次要建议]
```

### 用户画像
```
## 用户画像：[画像名称]

### 基本信息
- 人口特征
- 使用场景

### 目标与动机
- 主要目标
- 深层动机

### 痛点与挫折
- 当前痛点
- 未满足需求

### 行为特征
- 使用习惯
- 决策因素

### 引用/证言
[代表性子弹]
```

## 数据处理原则

1. **隐私保护**：处理时匿名化个人标识信息
2. **引用标注**：关键发现附带原始引用
3. **置信度标注**：区分观察结果与推断
4. **多元视角**：呈现用户多样性，避免过度概括

## 最佳实践

- 提供更多上下文信息可获得更准确的分析
- 定性分析建议提供3-5份以上样本
- 定量分析建议说明样本量和收集方法
- 如有特定分析框架需求，请明确说明

## 局限性说明

- 深度访谈分析需要足够的数据量支持
- 自动分析可能存在理解偏差，需人工复核
- 复杂统计模型需要明确的假设和足够的样本量
