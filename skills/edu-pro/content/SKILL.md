## 技能描述

EduPro 智能教育助手是一款**一站式教育解决方案**，整合备课、出题、诊断、练习四大核心功能：

**核心能力**：
- 📖 **备课模块**：教案、大纲、学期计划一键生成
- 📝 **出题模块**：15学科全覆盖，智能组卷
- 🎯 **诊断模块**：AI精准定位知识薄弱点
- 📈 **练习模块**：自适应难度，精准提升

**差异化价值**：
- 诊断→出题联动：基于薄弱点自动生成针对性练习
- 全流程覆盖：从备课到学习追踪完整闭环
- 15学科支持：语文/数学/英语/物理/化学/生物/历史/地理/政治/音乐/美术/体育/信息技术/科学

## 功能模块

### 模块1：备课系统

#### 1.1 教学大纲生成
**输入**：学科、年级、课时数、知识点列表
**输出**：
- 课程总体目标
- 课时分配表
- 每课时教学目标、重难点、教学方法

#### 1.2 教案模板生成
**输入**：课程主题、教学时长、年级、学科
**输出**：
- 三维目标（知识与技能/过程与方法/情感态度价值观）
- 教学重点与难点
- 完整教学过程（导入/新课/练习/总结/作业）
- 板书设计模板

#### 1.3 学期教学计划
**输入**：年级、学科、每周课时数、学期周数
**输出**：
- 16-20周详细教学进度表
- 期中/期末复习计划
- 时间节点规划

#### 2.1 章节练习题
**输入**：学科、年级、章节、难度、题型、数量

#### 2.4 变式练习卷

### 模块3：诊断系统

#### 3.1 错题诊断分析
**输入**：学生错题/答题记录
**输出**：深度诊断报告

**诊断维度**：

| 维度 | 说明 | 示例 |
|------|------|------|
| 知识漏洞 | 知识点未掌握 | 判别式Δ应用不熟 |
| 理解偏差 | 概念理解有误 | 函数符号理解错误 |
| 方法缺失 | 解题方法不熟 | 不知道用求根公式 |
| 粗心失误 | 会但做错 | 计算步骤出错 |
| 综合应用 | 多知识点综合 | 跨章节应用题 |

**诊断报告示例**：
```
┌─────────────────────────────────────────────────┐
│ 【错题】x²-5x+6=0，求解                          │
│ 【学生答案】x=1, x=6 ❌                          │
│ 【正确答案】x=2, x=3 ✓                          │
├─────────────────────────────────────────────────┤
│ 错误类型：方法缺失                               │
│ 涉及知识点：                                     │
│ ① 因式分解法 (cross method)                    │
│ ② 积为常数、和为系数                           │
│ 薄弱程度：                                       │
│ 因式分解 ████░░░░░░ 40% ← 主要问题              │
├─────────────────────────────────────────────────┤
│ 根因分析：                                       │
│ 不熟悉"和乘积"法——凑出-5=-2-3，6=-2×3          │
│ 推荐：先从简单二次项系数为1的方程开始练          │
└─────────────────────────────────────────────────┘
```

#### 3.2 全科综合诊断
**输入**：多科成绩/多题错题
**输出**：
- 各科薄弱点排序
- 共同根因分析
- 优先级提升建议

#### 3.3 学习问题诊断
超越单科，分析整体学习问题：

| 问题类型 | 表现 | 建议 |
|----------|------|------|
| 注意力问题 | 做题慢、粗心 | 专注力训练 |
| 方法问题 | 刷题多进步慢 | 错题本使用 |
| 习惯问题 | 不爱检查 | 正向激励 |
| 心理问题 | 考试焦虑 | 目标拆分 |
| 基础问题 | 听不懂 | 从头补基础 |

### 模块4：自适应练习系统

#### 4.1 自适应出题
根据诊断结果动态调整难度：

```
初始测评 → 确定基线难度
    ↓
答对 → 提升难度（+1级）
    ↓
答错 → 分析原因 → 降低难度或切换知识点
    ↓
持续循环 → 直到稳定在"最近发展区"
```

**难度分级**：

| 级别 | 名称 | 说明 |
|------|------|------|
| L1 | 基础巩固 | 概念识别、简单应用 |
| L2 | 进阶提升 | 变式练习、多步骤 |
| L3 | 综合应用 | 跨知识点、综合问题 |
| L4 | 挑战拓展 | 难题、竞赛级别 |

**智能调整**：
- 连续答对3题 → 提升难度
- 连续答错2题 → 降低难度
- 正确率70-80% → 最优学习区间

#### 4.2 精准提升计划
根据诊断结果生成个性化方案：

**方案结构**：
```
【个人提升计划】
姓名：___ 日期：___

一、当前水平评估
   数学综合能力：65/100
   需要重点突破：几何证明

二、每日练习计划（建议）
   Day1-3：几何基础证明（每天15分钟）
   Day4-6：复杂证明专项（每天15分钟）
   Day7：综合测试

三、针对性练习题
   几何证明练习（20题，含解析）
```

### 模块8：学科专项诊断

#### 8.1 数学诊断专项
- 初中：代数、几何、函数、概率
- 高中：三角函数、导数、积分、数列、向量

#### 8.2 英语诊断专项
- 时态：一般现在/过去/将来/完成时

#### 8.3 物理诊断专项
- 力学：速度、加速度、牛顿定律、功和能
- 电磁学：电场、电路、磁场、电磁感应

#### 8.4 化学诊断专项
- 溶液：溶解度、浓度计算
- 反应类型：氧化还原、酸碱反应
