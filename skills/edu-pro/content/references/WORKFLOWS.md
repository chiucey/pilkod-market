## 场景1：备课到出题完整流程

### Step 1: 生成教学大纲

```
输入：
- 学科：数学
- 年级：初二
- 课时：每周4课时，共16周
- 知识点：三角形、全等三角形、轴对称、整式的乘法与因式分解、分式

输出：
- 16周课程安排表
- 每周教学目标
- 重难点标注
```

### Step 2: 生成教案

```
输入：
- 课程：全等三角形的判定（SAS）
- 课时：45分钟
- 年级：初二

输出：
- 三维教学目标
- 教学重点（SSS/SAS/ASA/AAS判定定理）
- 教学难点（判定定理的选择）
- 教学过程（导入→探索→总结→练习→作业）
```

### Step 3: 生成配套练习

```
输入：
- 学科：数学
- 章节：全等三角形
- 难度：中等（易:中:难 = 7:2:1）
- 数量：20题

输出：
- 选择题（10题）
- 填空题（5题）
- 解答题（5题）
- 参考答案
```

## 场景2：错题诊断与精准练习

### Step 1: 错题诊断

```
输入：
题目：如图，△ABC中，AB=AC，AD是角平分线
求证：BD=CD

学生答案：无法证明

诊断结果：
┌─────────────────────────────────────────────┐
│ 错误类型：方法缺失                           │
│ 涉及知识点：                                 │
│ ① 等腰三角形三线合一性质                    │
│ ② 证明线段相等的策略                        │
├─────────────────────────────────────────────┤
│ 根因分析：                                   │
│ 不了解等腰三角形"三线合一"定理               │
│ AD是角平分线+中线+高线，应利用此性质         │
├─────────────────────────────────────────────┤
│ 推荐路径：                                   │
│ Step1: 复习等腰三角形性质                    │
│ Step2: 理解"三线合一"定理                    │
│ Step3: 练习等腰三角形证明题                   │
└─────────────────────────────────────────────┘
```

### Step 2: 自适应练习生成

```
基于诊断结果，自动生成：

【练习计划】
主题：等腰三角形证明
难度：L2（进阶）
数量：10题

题目列表：
1. 等腰三角形性质基础题（3题）
2. 三线合一应用题（4题）
3. 综合证明题（3题）

每题包含：题目、分析、答案、变式题链接
```

## 场景3：全科综合诊断

### 输入

```
学生：小明，初二
问题：最近数学和物理都考差了

需要诊断：
- 数学：最近3次考试卷
- 物理：最近2次考试卷
- 课堂表现：上课听讲但不记笔记
- 作业情况：做题不检查
```

### 输出：全科诊断报告

```
═══════════════════════════════════════════════════════
                    【全科综合诊断报告】
                        学生：小明  初二
═══════════════════════════════════════════════════════

│ 科目   │ 最近成绩   │ 班级排名 │ 趋势      │ 状态      │
├────────┼────────────┼───────────┼───────────┼──────────┤
│ 数学   │ 72→68→65   │ 25→30→32 │ ↓下降    │ ⚠ 警示   │
│ 物理   │ 78→70→65   │ 15→20→25 │ ↓下降    │ ⚠ 警示   │
└────────────────────────────────────────────────────────┘

二、学科问题诊断

【数学】综合掌握度：62%
├── 问题1：一次函数（薄弱度75%）
│   ├── 表现：函数图像分析题错误率高
│   ├── 根因：图像与解析式转换不熟练
│   └── 建议：每天5分钟图像练习
│
├── 问题2：几何证明（薄弱度55%）
│   ├── 表现：证明题思路混乱
│   ├── 根因：缺乏逻辑训练
│   └── 建议：从简单题开始，训练"因为-所以"
│
└── 问题3：计算失误（粗心型）
    ├── 表现：会做的题算错
    ├── 根因：做题不检查
    └── 建议：养成验算习惯

【物理】综合掌握度：65%
├── 问题1：力学分析（薄弱度60%）
│   ├── 表现：受力分析错误
│   ├── 根因：力的合成与分解不熟
│   └── 建议：画图法训练
│
└── 问题2：公式应用（薄弱度70%）
    ├── 表现：知道公式但不会用
    ├── 根因：审题不清、条件提取弱
    └── 建议：练习画已知条件标注

│ 【共同根因】数学基础影响物理学习                        │
├────────────────────────────────────────────────────────┤
│ • 数学函数→物理公式理解                                │
│ • 数学几何→物理力学分析                                │
│ • 数学计算→物理数值运算                                │
└────────────────────────────────────────────────────────┘

四、学习行为问题

| 问题     | 表现            | 影响  | 建议                |
|----------|----------------|-------|---------------------|
| 笔记缺失 | 上课不记笔记    | 复习难 | 使用康奈尔笔记法    |

| 错题闲置 | 错题不复盘      | 重复错 | 建立错题本          |

五、提升计划（4周）

┌────────────────────────────────────────────────────────┐
│ 第1-2周：补基础                                         │
│ • 数学：一次函数专项（每天20分钟）                      │
│ • 物理：力学基础（每天20分钟）                         │
│ • 习惯：开始使用错题本                                 │
├────────────────────────────────────────────────────────┤
│ 第3-4周：提能力                                         │
│ • 数学：几何证明入门（每天25分钟）                      │
│ • 物理：综合应用题（每天25分钟）                       │
│ • 习惯：做题后必须检查                                 │
```

### 自适应调整规则

| 条件 | 动作 | 结果 |
|------|------|------|
| 连续答对3题 | 提升难度+1级 | 进入更高挑战 |
| 连续答错2题 | 降低难度-1级 | 回到基础巩固 |
| 连续答错2题（同一知识点）| 切换知识点 | 换个角度学习 |
| 正确率70-80% | 维持当前难度 | 最优学习区间 |
| 完成20题 | 生成报告 | 结束本轮练习 |

## 场景5：试卷生成与变式练习

### Step 1: 生成标准试卷

```
输入：
- 学科：初三化学
- 单元：第八单元 金属和金属材料
- 总分：100分
- 难度：易:中:难 = 7:2:1
- 题型：选择、填空、简答、计算

输出：
- 完整试卷（含密封线格式）
- 答题卡模板
- 标准答案+评分细则
- 双向细目表
```

### Step 2: 基于错题生成变式练习

```
学生错误记录：
1. 金属与酸反应生成气体判断错误
2. 置换反应条件判断不清
3. 金属活动性顺序应用不熟

生成变式练习：
┌─────────────────────────────────────────────┐
│ 【变式1】金属与酸反应                        │
│ 基础题：Zn+HCl→?                            │
│ 变式1-1：Mg+HCl→?（金属活动性）             │
│ 变式1-2：Cu+HCl→?（为何不反应？）           │
├─────────────────────────────────────────────┤
│ 【变式2】置换反应                           │
│ 基础题：Fe+CuSO₄→?                          │
│ 变式2-1：Cu+FeSO₄→?（为何不行？）           │
│ 变式2-2：Zn+FeSO₄→?（多步置换）             │
├─────────────────────────────────────────────┤
│ 【变式3】金属活动性顺序                     │
│ 基础题：Mg>Zn>Fe>Cu>Ag                      │
│ 变式3-1：设计实验验证Fe>Cu                 │
│ 变式3-2：混合盐溶液中的置换顺序             │
└─────────────────────────────────────────────┘
```

## 快速参考卡片

### 备课流程

```
1. 确定目标 → 2. 规划课时 → 3. 设计教案 → 4. 生成练习
```

### 诊断流程

```
1. 输入错题 → 2. AI诊断 → 3. 生成报告 → 4. 推荐练习
```

### 自适应练习流程

```
1. 初始测评 → 2. 确定难度 → 3. 循环练习 → 4. 生成报告
```

### 联动流程（诊断+出题）

```
1. 错题输入 → 2. 诊断分析 → 3. 生成练习 → 4. 进度追踪
```

## 常见问题处理

| 场景 | 问题 | 处理方式 |
|------|------|----------|
| 备课 | 课时不够 | 压缩非重点，保留核心 |
| 出题 | 难度失衡 | 调整易:中:难比例 |
| 诊断 | 根因不明 | 追问学生解题过程 |
| 练习 | 抵触练习 | 从简单题开始，建立信心 |
| 报告 | 数据不足 | 收集更多样本后再诊断 |
