## 知识点关联图谱

### 数学-物理关联

```
数学知识 → 物理应用
├── 三角函数 → 力分解、振动
├── 向量 → 力、速度合成
├── 二次函数 → 抛体运动
├── 导数 → 瞬时速度、加速度
└── 积分 → 功、冲量
```

### 化学-生物关联

```
化学知识 → 生物应用
├── 有机化学 → 生物大分子
├── 反应速率 → 代谢反应
├── 酸碱平衡 → 体液pH
└── 化学键 → 分子结构
```

## 难度等级定义

| 等级 | 名称 | 说明 | 举例 |
|------|------|------|------|
| L1 | 基础 | 概念识别、简单计算 | 1+1=2 |
| L2 | 进阶 | 公式应用、多步骤 | 解方程x²-5x+6=0 |
| L3 | 综合 | 跨知识点、变式 | 应用题、证明题 |
| L4 | 拓展 | 难题、竞赛级别 | 奥数题、压轴题 |
