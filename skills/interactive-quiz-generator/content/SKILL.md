# 交互式测验生成器

将知识内容转化为个性化交互式网页测验应用。

## 核心能力

1. **智能考点提取**：从提供的内容中自动识别关键知识点，生成多样化题型
2. **三种专业风格**：童趣探索版 / 优雅极简版 / 活力游戏版
3. **即时可部署**：生成完整的单文件 HTML，可直接部署

## 工作流程

### 步骤 1：收集信息

收集以下信息（按需获取，可部分提供）：

| 信息项 | 说明 | 必需 |
|--------|------|------|
| 测验主题 | 测验的标题/主题 | 是 |
| 内容来源 | 原始文本内容或文件路径 | 是 |
| 题型偏好 | 单选/多选/判断/简答 | 否 |
| 题目数量 | 期望的题目数量 | 否（默认8-12题） |
| 风格选择 | study/elegant/game | 否（默认elegant） |

### 步骤 2：内容分析与考点提取

对提供的内容进行结构化分析：

```
内容 → 关键概念提取 → 知识点梳理 → 题型设计 → 题目生成
```

**考点提取规则**：
- 名词定义 → 判断题/单选题
- 特征描述 → 多选题
- 过程步骤 → 排序题/填空题
- 因果关系 → 应用题

### 步骤 3：选择模板风格

根据场景选择最合适的设计风格：

| 风格 | 适用场景 | 设计特点 |
|------|----------|----------|
| **study** | 儿童教育、亲子学习 | 圆角卡片、趣味图标、鼓励动画 |
| **elegant** | 正式考试、知识考核 | 极简布局、清晰层级、专业配色 |
| **game** | 年轻用户、培训活动 | 进度条、积分系统、动态反馈 |

### 步骤 4：生成测验 HTML

使用对应模板生成完整的单文件 HTML 测验应用：

- 自动注入提取的题目
- 包含完整的答题逻辑
- 支持即时反馈与结果统计
- 响应式设计，适配各种设备

### Game（活力游戏版）

## 输出交付

生成的 HTML 文件包含：

- 完整的 HTML/CSS/JS 代码
- 内置题目数据（JSON 格式）
- 无外部依赖
- 可直接在浏览器打开
- 部署后可通过 URL 分享

## 使用示例

**触发示例**：
- "将这篇科普文章转化为测验"
- "制作一个关于 Python 基础的选择题测试"
- "为我的培训材料生成互动问答网页"
- "创建儿童安全知识小游戏"

**典型工作流**：
1. 用户提供内容或文件路径
2. 分析内容并提取考点
3. 确认风格选择（如需要）
4. 生成并提供 HTML 文件
5. 可选：协助部署到线上
