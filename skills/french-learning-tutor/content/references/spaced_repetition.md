# Spaced Repetition and the Forgetting Curve

## 📚 Ebbinghaus Forgetting Curve Principle

German psychologist Hermann Ebbinghaus (1885) discovered that human memory retention follows a predictable decay pattern.

> **The brain forgets new information exponentially over time.**

### Memory Retention Curve

```
Retention (%)   100 |          ●
                80 |       ●
                60 |     ●
                40 |   ●
                20 |
                    0 +---+---+---+---+---+---+--> Time (days)
                      1   3   7   14  30  60
```

### Key Time Points

| Time | Retention | Note |
|------|-----------|------|
| 20 min | 58% | Rapid forgetting zone |
| 1 hour | 44% | |
| 8 hours | 36% | |
| 1 day | 33% | |
| **Day 3** | **27%** | 🔥 Key review point |
| **Day 7** | **25%** | 🔥 Critical review point |
| **Day 14** | **21%** | 🔥 Reinforcement point |
| **Day 30** | **18%** | 🔥 Long-term memory point |
| **Day 60** | **14%** | 🔥 Ultra long-term point |

## 🔄 Spaced Repetition Principle

### Core Concept

> **Reviewing just before forgetting dramatically improves retention.**

### Review Interval Calculation

```
First learning
    ↓ +1 day → Review 1
           ↓ +3 days → Review 2
                  ↓ +7 days → Review 3
                         ↓ +14 days → Review 4
                                ↓ +30 days → Review 5
                                       ↓ +60 days → Final consolidation
```

### Why This Works

1. **Reduced Cognitive Load**: Each review is incremental
2. **Active Retrieval**: Each recall strengthens memory
3. **Adaptable**: Adjusts to personal forgetting rhythm
4. **High Long-term Retention**: 80%+ after 60 days

## 🧠 Brain Science Support

### Memory Formation Process

1. **Encoding**: Information enters short-term memory
2. **Consolidation**: Short-term → long-term conversion
3. **Retrieval**: Information pulled from long-term memory

### Why Spaced Repetition Works

| Traditional Learning | Spaced Repetition |
|---------------------|-------------------|
| Cramming | Distributed practice |
| Passive repetition | Active retrieval |
| Rapid forgetting | Long-term retention |
| Inefficient | Efficient |

**Key**: Each retrieval (recall) strengthens the memory pathway.

## ⚠️ Common Mistakes

### ❌ Wrong Approaches

1. **Passive reading**: No active recall
2. **No usage**: Words not used in sentences
3. **Cramming**: Last-minute review
4. **Ignoring listening**: Only memorize words, not pronunciation

### ✅ Correct Approaches

1. **Active recall**: Try to remember before checking
2. **Speak and listen**: Use words immediately
3. **Consistency**: 30 min/day > 6 hours on weekends
4. **Combine reading and listening**: Words + audio + context
