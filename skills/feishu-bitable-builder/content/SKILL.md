# feishu-bitable-builder

创建并管理飞书多维表格电商ERP系统。

## 触发条件
用户说「创建飞书ERP」「帮我搭飞书表格」「建多维表格」「飞书ERP」或类似表达时激活。

## 前置要求
1. 用户需安装 OpenClaw Browser Relay Chrome 扩展
2. 用户在飞书页面点击扩展图标（badge ON）连接标签页
3. 飞书账号已登录，且持有目标多维表格所在文件夹的编辑权限
4. 飞书需为专业版（自动化规则/公式/关联字段依赖专业版）

## 工作流程

### 阶段一：准备工作
1. 检查是否有已连接的浏览器标签页（Browser Relay）
2. 若无，引导用户点击扩展图标连接飞书标签页
3. 截图确认当前页面为飞书主界面

### 阶段二：创建多维表格
1. 导航至目标文件夹（用户指定或根目录）
2. 新建多维表格，命名为「电商ERP系统-XXX」
3. 重命名默认数据表为「产品主数据」
4. 依次创建以下数据表（按顺序）：
   - 产品主数据
   - 车型字典（汽车内饰用）
   - 入库记录
   - 出库记录
   - 订单主表
   - 订单明细
   - 供应商管理

### 阶段三：配置字段
每个表的字段按以下规范创建，字段类型严格按设计来：

#### 产品主数据表
- 文本：商品名称、商品条码、规格/型号
- 数字：安全库存量
- 货币：进价、指导售价
- 图片：商品图片
- 单选：类目（汽车内饰/食品）、品牌、是否定制款
- 级联选择：商品类目
- 关联：供应商（关联至供应商管理表）
- 关联（多选）：适配车型（关联至车型字典表）
- 数字：定制备货周期（天）
- 公式：当前库存量（Lookup汇总）
- 公式：库存状态（IF判断）

#### 车型字典表
- 单选：品牌
- 文本：厂商、车系、年款范围
- 单选：适用状态

#### 入库记录表
- 文本：入库单号、批次号、经手人
- 关联：关联商品（→产品主数据）
- 数字：入库数量
- 日期：入库时间、生产日期、保质期至
- 关联：关联供应商（→供应商管理表）
- 单选：入库类型
- 文本：备注

#### 出库记录表
- 文本：出库单号、物流单号
- 关联：关联订单编号（→订单主表）
- 关联：关联商品（→产品主数据）
- 数字：出库数量
- 日期：出库时间
- 单选：出库类型
- 文本：备注

#### 订单主表
- 文本：订单编号、客户名称、联系方式、收货地址、客服备注、录入人
- 单选：平台来源（淘宝/拼多多/抖音/小红书）、订单状态、是否有定制
- 货币：订单金额
- 日期：下单时间、预计发货日期、实际发货日期

#### 订单明细表
- 关联：关联订单（→订单主表）
- 关联：关联商品（→产品主数据）
- 文本：车型信息、备注
- 数字：数量
- 货币：单价
- 公式：小计（数量×单价）

#### 供应商管理表
- 文本：供应商名称、联系人、主供类目、付款方式
- 电话：联系电话
- 数字：评分（1-5）
- 单选：合作状态
- 文本：备注

### 阶段四：配置自动化规则
按以下规则配置自动化（使用飞书内置自动化）：

| 规则名称 | 触发 | 动作 |
|---------|------|------|
| 入库库存增加 | 入库记录表新增记录 | 产品主数据对应记录库存+N |
| 出库库存减少 | 出库记录表新增记录 | 产品主数据对应记录库存-N |
| 库存不足预警 | 产品主数据库存<安全库存 | 发送消息给负责人 |
| 定制款待确认提醒 | 订单状态=已确认且车型信息为空 | 发送消息提醒 |

### 阶段五：创建仪表盘
- 经营日报看板（各平台订单数/销售额）
- 库存预警看板（不足库存商品列表）
- 多平台销售对比（柱状图/饼图）

## 关键约束
- 严格按字段类型创建，货币用货币字段，日期用日期字段，公式用公式字段
- 关联字段需先创建被关联表，再建关联字段
- 权限设置：录入人仅可编辑自己创建的记录，管理员可全部查看

## 输出
完成后截图确认所有表创建完毕，并告知用户后续操作步骤（录入商品、录入订单等）
