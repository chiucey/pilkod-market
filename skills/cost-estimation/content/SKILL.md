# 造价成本测算工作流程

## 一、工作流程总览

```
[接收文件] → [确定地区] → [解析CAD图纸] → [匹配定额] → [查找单价] → [计算总价] → [偏差检查] → [输出Excel]
```

## 二、详细执行步骤

### 步骤1：接收用户文件

**接收以下文件**：
- CAD图纸文件（.dwg, .dxf, .pdf等格式）
- 清单文件（Excel、PDF或Word格式）
- 投标文件（如有）
- 其他相关资料

**确认清单包含**：
- 清单编号
- 清单名称/描述
- 单位
- 工程量

### 步骤2：询问并确定地区

**必须询问用户**：
> "请告诉我项目所在地区（省/市），以便我使用当地的预算定额进行报价。"

**常用地区选项**：
- 华东地区：上海、江苏、浙江、安徽、福建、江西、山东
- 华北地区：北京、天津、河北、山西、内蒙古
- 华南地区：广东、广西、海南
- 华中地区：河南、湖北、湖南
- 西南地区：四川、贵州、云南、重庆、西藏
- 西北地区：陕西、甘肃、青海、宁夏、新疆
- 东北地区：辽宁、吉林、黑龙江

### 步骤3：解析CAD图纸

**使用图像理解工具**读取CAD图纸：

1. **识别图纸类型**：
   - 建筑平面图（长度、面积）
   - 结构配筋图（钢筋用量）
   - 水电安装图（管线长度）
   - 装修详图（面积、材料）

2. **提取关键尺寸**：
   - 标注的尺寸数据
   - 线段长度
   - 面积计算（多边形区域）
   - 体积计算（长×宽×高）

3. **记录识别信息**：
   ```
   识别的构件 | 图纸尺寸 | 计算工程量 | 备注
   ```

### 步骤4：定额匹配

**对于每一条清单项**：

1. **分析清单描述关键词**
2. **在定额库中搜索最匹配项**：
   - 定额编号
   - 定额名称
   - 工作内容
   - 计量单位
   - 基价（人工费+材料费+机械费）
3. **套用依据说明**：说明为什么选择此定额

**定额匹配原则**：
- 工作内容最接近优先
- 计量单位一致优先
- 工艺做法匹配优先

### 步骤5：查找市场单价

**信息来源**：
- 当地造价信息网
- 建材市场价格指数
- 近期中标项目价格参考

**查找内容**：
- 主材市场价
- 人工费单价
- 机械台班单价
- 租赁价格

### 步骤6：计算各项价格

**单价计算公式**：
```
综合单价 = 定额基价 + 材料价差 + 风险费用
```

**总价计算公式**：
```
清单合价 = 综合单价 × 清单工程量
```

### 步骤7：工程量偏差检查

**比对图纸算量与清单工程量**：

| 偏差判断 | 处理方式 |
|---------|---------|
| 偏差 ≤ 20% | 正常使用清单工程量 |
| 偏差 > 20% | 用**红色/橙色标注**，提示复核 |

**标注示例**：
- 背景色：橙色 (#FFA500) 表示偏高
- 背景色：浅红色 (#FF6B6B) 表示偏低
- 添加批注说明偏差比例

### 步骤8：汇总计算

**计算内容**：
- 分部分项工程费
- 措施项目费
- 其他项目费
- 规费
- 税金
- **含税总价**

## 三、输出Excel格式要求

### 工作表结构

```
工作表1：成本测算汇总表
├── 项目名称
├── 建筑规模
├── 测算日期
├── 地区
└── 总造价

工作表2：分部分项清单
├── 清单编号
├── 清单名称
├── 定额编号
├── 定额名称
├── 单位
├── 清单工程量
├── 图纸算量
├── 综合单价
├── 合价
├── 备注/标注
└── 偏差率

工作表3：材料价格明细
├── 材料名称
├── 规格型号
├── 单位
├── 市场单价
├── 产地/供应商
└── 备注

工作表4：人材机汇总
├── 费用类别
├── 金额
├── 占比
└── 说明
```

### Excel样式要求

- 表头：深蓝色背景，白色字体
- 偏差标注行：橙色背景
- 公式单元格：浅灰色背景
- 金额格式：人民币符号，保留2位小数
- 列宽自适应

## 四、定额参考格式

```
| 定额编号 | 定额名称 | 工作内容 | 单位 | 人工费 | 材料费 | 机械费 | 基价 |
|---------|---------|---------|------|--------|--------|--------|-----|
| 10101001 | xxx | xxx | m³ | xx元 | xx元 | xx元 | xx元 |
```

## 五、市场单价参考格式

```
| 材料/设备名称 | 规格型号 | 单位 | 市场单价 | 来源 | 日期 |
|-------------|---------|------|---------|-----|-----|
| xxx | xxx | xxx | xxx元 | xxx | 2026-xx-xx |
```

## 六、注意事项

1. **严格依据**：所有定额套用必须有明确依据
2. **实事求是**：市场价应反映当前真实行情
3. **偏差提醒**：任何>20%偏差必须标注
4. **可追溯**：保留计算过程和依据来源
5. **复核提示**：最终结果建议人工复核

## 七、工具使用策略

1. **图纸识别**：使用 `images_understand` 分析CAD图纸
2. **文件读取**：使用 `extract_pdfs_key_info` 读取PDF清单
3. **市场调研**：使用 `batch_web_search` 查询地区定额和市场价
4. **Excel生成**：使用 `minimax-xlsx` 生成Excel表格
5. **内容提取**：使用 `extract_content_from_websites` 查找定额网站
