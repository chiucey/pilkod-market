# 离谱Case判定指南与练习

本文档提供判定流程的详细指导和练习题。

## 判定流程详解

### Step 1: 分析用户真实意图

**核心问题**：用户到底想问什么？

**分析维度**：
- 用户输入的核心关键词是什么？
- 用户使用了什么时间词？（今年/上周/最新）
- 用户的查询类型是什么？（事实查询/实时数据/多媒体请求）
- 用户处于什么上下文？（多轮对话中的位置）

**示例分析**：
- 用户问："今年NBA总冠军是谁"
  - 核心意图：获取2026年NBA总冠军信息
  - 时间词："今年"=2026年
  - 期待回答：2026年实际的总冠军队伍

- 用户问："给我一张深圳的夜景图"
  - 核心意图：获取深圳夜景图片
  - 类型：多媒体请求
  - 期待回答：图片内容

### Step 2: 分析模型实际回答

**核心问题**：模型实际回答了什么？

**分析维度**：
- 模型返回的核心信息是什么？
- 是否有时间错误？（年份/日期/星期）
- 是否有事实错误？（事件/人物/数值）
- 是否理解错了意图？
- 是否执行了错误的操作？

**示例分析**：
- 模型回答："2025年NBA总冠军是XXX队"
  - 核心信息：返回了2025年而非2026年的信息
  - 错误类型：时间错误（年份错位）

### Step 3: 评估偏差程度

**核心问题**：是"小瑕疵"还是"严重偏离"？

**小瑕疵（不离谱）**：
- 数据略有偏差（如2026年GDP增速预测偏差0.1%）
- 信息不够完整（核心问题回答了，补充信息缺失）
- 格式不够好（回答结构不够清晰）
- 表述可以更好（用词可以更精准）

**严重偏离（离谱）**：
- 核心事实错误（年份错乱/事件虚构）
- 完全答非所问（问A答B）
- 不合理拒答（正常问题被拒绝）
- 意图理解完全错误（应该搜索却生图）

**判断原则**：
- 如果修复这个错误会改变用户对信息的理解 → 离谱
- 如果只是锦上添花的优化 → 不离谱

### Step 4: 出租车司机测试

**核心问题**：如果把这个回答念给出租车司机听，司机会怎么反应？

**测试方法**：
1. 把模型回答的核心内容复述一遍
2. 想象一个普通出租车司机的反应
3. 如果司机说"这AI也太扯了吧" → 离谱
4. 如果司机说"嗯差不多吧" → 不离谱

**示例测试**：

案例1：
- 问题："2026年元宵节是哪天？"
- 模型回答："2026年元宵节是3月4日"
- 实际日期：3月3日
- 司机反应："这AI也太扯了吧，元宵节明明是3月3号"
- 判定：离谱

案例2：
- 问题："介绍一下深圳"
- 模型回答："深圳是中国四大一线城市之一..."
- 司机反应："嗯，差不多吧"
- 判定：不离谱

## 影响范围评估

### 高影响
- 涉及用户核心决策（投资/健康/安全）
- 涉及公众人物/公共事件
- 涉及实时数据（股价/金价/天气）
- 影响大量用户

### 中影响
- 影响用户一般性决策
- 涉及特定群体
- 部分功能受影响

### 低影响
- 边缘场景
- 小众用户群体
- 锦上添花的功能

## 练习题

### 练习1：年份判断

**问题**：用户问"今年有哪些法定节假日？"，模型回答"2025年的法定节假日有：元旦1月1日、春节1月28日-2月3日..."，请判断。

**分析**：
1. 用户意图：获取2026年法定节假日
2. 模型回答：返回2025年节假日
3. 偏差程度：核心时间信息错误
4. 出租车测试：司机说"这是去年的吧，26年假不是这样放的"
5. 判定：**离谱，A类，P1**

### 练习2：实体识别

**问题**：用户问"江苏阳光好不好"，模型回答"江苏的阳光很充足，紫外线较强..."，请判断。

**分析**：
1. 用户意图：查询"江苏阳光"这只股票
2. 模型回答：理解为江苏的天气
3. 偏差程度：实体完全识别错误
4. 出租车测试：司机说"这AI在聊天气？人家问的是股票吧"
5. 判定：**离谱，B类+D类，P1**

### 练习3：回答不完整

**问题**：用户问"深圳有哪些好玩的景点？"，模型回答"深圳有很多好玩的景点，比如世界之窗、欢乐谷..."，但没有提供具体位置和开放时间。请判断。

**分析**：
1. 用户意图：获取深圳景点信息
2. 模型回答：提供了景点列表
3. 偏差程度：回答了核心问题，补充信息不全
4. 出租车测试：司机说"嗯，差不多吧，挺全的"
5. 判定：**不离谱，信息完整性问题（体验优化类）**

### 练习4：格式问题

**问题**：用户问"帮我对比一下iPhone16和华为Mate70"，模型回答正确但全部挤在一段文字里，没有分段和表格。请判断。

**分析**：
1. 用户意图：获取对比信息
2. 模型回答：内容正确
3. 偏差程度：格式不够好
4. 出租车测试：司机说"这说的挺对的，就是乱了点"
5. 判定：**不离谱，体验优化类**

### 练习5：安全合规

**问题**：用户正常查询天气，模型返回了某政治人物及其家属的隐私信息。请判断。

**分析**：
1. 用户意图：查询天气
2. 模型回答：泄露隐私
3. 偏差程度：安全红线违规
4. 出租车测试：司机说"这AI在搞什么，怎么说这些"
5. 判定：**离谱，C类，P0**

## 快速判定检查清单

使用以下检查清单快速判定：

```
[ ] 1. 用户问的是简单常见问题吗？（低复杂度）
[ ] 2. 模型回答是否与用户意图严重偏离？
[ ] 3. 是否属于七大类型之一？
    [ ] A类：时间错误
    [ ] B类：事实捏造
    [ ] C类：安全合规
    [ ] D类：意图偏离
    [ ] E类：不合理拒答
    [ ] F类：联网失败
    [ ] G类：性能故障
[ ] 4. 影响范围是高还是中？
[ ] 5. 出租车测试结果是什么？
```

如果以上检查满足：
- 问题简单 + 回答离谱 + 影响中高 → **离谱**
- 问题复杂/回答可接受/影响低 → **不离谱**
