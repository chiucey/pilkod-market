# 水闸工程分段算量 Skill

根据用户输入的一套水闸工程图纸（通常 4–10 张），自动识别图纸中的水闸分段，逐段估算土建工程量，按材料/分段分类汇总，导出 Excel 工作簿。本 skill 定位为**粗略估算**，非施工图精算，重点关注分段的完整性和数量级合理性。

## 一、核心原则

- **不编造尺寸**。只能使用图纸中可见的尺寸、标高、材料标注、特性表；无法确定的值写 `未知`。
- **统一换算为米**。中国水利图纸结构尺寸常以 `cm` 标注，标高以 `m` 标注，计算前全部换算为 m。
- **可追溯**。每条工程量写明来源图片、视图/剖面号、参数来源和公式。
- **分段独立**。不得把一个分段的尺寸套用到另一个分段，除非图纸明确说明相同。
- **无法闭合则不计算**。必要参数缺失的构件不强行算，放入缺失信息表。
- **防止重复计量**。墙、墩已按实体计入时，胸墙/顶板只补算未被墙墩体积包含的增量。
- **必须输出 .xlsx**。优先使用 `scripts/export_quantities.py`。

## 二、图纸解读流程

### 2.1 图纸清点

列出所有图片/PDF 页，逐页判定角色：

| 角色 | 特征 | 提供的关键信息 |
|---|---|---|
| 平面图 | 俯视布置、孔口数量、轴线 | 总长、总宽、墩墙布置、分段分界 |
| 纵剖图 | 沿水流方向剖面 | 各分段长度、标高、底板/垫层厚度、材料分层 |
| 横剖图 | 垂直水流方向剖面 | 断面几何、墩墙尺寸、底板宽度 |
| 编号剖面 | 标注剖面号（1-1、2-2 等） | 断面面积最权威的来源 |
| 局部详图 | 放大比例 | 细部尺寸、止水、排水管 |
| 材料说明/特性表 | 表格或文字 | 混凝土强度等级、砌石标号、钢筋量 |
| 金属结构/闸门布置图 | 闸门、启闭机 | 孔口尺寸、门槽二期砼范围 |
| 工程量表 | 已列工程量 | 仅作校验参考，不能直接引用 |

记录每页的图名、剖面号、比例、可见说明。

### 2.2 确定水流方向

在平面图和纵剖图中确定水流方向（上游 → 下游），以此为基准排列分段。

## 三、分段识别与逐段计算

沿水流方向依次识别以下分段。图纸中出现哪些分段取决于工程规模，**不是每套图纸都包含全部分段**。

### 通用计算逻辑

对每个分段，核心思路一致：

```
工程量 ≈ 断面面积 × 顺水流方向长度
```

- **断面面积**优先取编号剖面标注尺寸计算（最权威），其次从横剖图提取。
- **长度**优先取纵剖图标注（最权威），其次从平面图提取。
- 断面沿水流方向不变 → 棱柱法：`V = A × L`。
- 断面沿水流方向渐变 → 棱台法或分段平均法。

### 体积估算方法

#### 方法一：断面面积法（首选）

```
V = A × L
```

`A` 为断面面积，从编号剖面几何计算得到；`L` 为沿水流方向的分段长度。

#### 方法二：规则矩形棱柱法

```
板/层：V = L × W × T
墙体：V = L × T × H × N
```

#### 方法三：梯形棱柱法（断面渐变）

当断面沿水流方向由 `A₁` 渐变到 `A₂`：

```
V = L × (A₁ + A₂) / 2
```

当宽度由 `W_start` 渐变到 `W_end`（厚度不变）：

```
V = L × (W_start + W_end) / 2 × T
```

使用平均宽法时必须在假设条件中说明。

#### 方法四：组合断面拆分

台阶、斜坡、齿坎等复杂断面拆成矩形、三角形、梯形分别计算后求和：

```
矩形：A = 宽 × 高
三角形：A = 底 × 高 / 2
梯形：A = (上底 + 下底) × 高 / 2
组合断面：A = Σ各子面积 - 孔洞/扣除
```

### 3.1 上游连接段 `upstream_connection`

| 常见标注 | 上游翼墙、上游护底、连接段、渠道衔接、进口渐变段 |
|---|---|
| 典型构件 | 混凝土/浆砌石护底、翼墙（八字墙/扭曲墙）、砂砾垫层、排水管 |
| 参数提取 | 护底长度 × 宽度 × 厚度；翼墙长度、起止高度、平均厚度 |
| 计算方法 | 护底用棱柱法；翼墙优先断面面积法，或起止断面平均法 |
| 注意事项 | 翼墙通常为渐变断面，注意区分左右两侧 |

```
V_护底 = L × W × T
V_翼墙 = L_wall × A_avg（断面面积法） 或 L × (H_start + H_end) / 2 × T（平均高法）
```

### 3.2 铺盖段 `apron`

| 常见标注 | 铺盖、防渗铺盖、上游铺盖、钢筋混凝土铺盖 |
|---|---|
| 典型构件 | 铺盖混凝土底板、C20 垫层、挡墙（悬臂式/扶壁式）、护坡、排水管 |
| 参数提取 | 铺盖长度、宽度、底板厚度、垫层厚度；挡墙高度、厚度、长度 |
| 计算方法 | 底板/垫层用棱柱法：`L × W × T`；挡墙优先横剖图断面面积 × 长度 |
| 注意事项 | 铺盖宽度可能含两侧挡墙基础，注意区分净宽和总宽 |

### 3.3 闸室段 `chamber`

最复杂分段，详见 **第四节闸室段详细规则**。

核心构件：底板、垫层、闸墩（中墩+边墩）、边墙、胸墙/顶板、门槽二期砼、交通桥/启闭平台。

### 3.4 消力池段 `stilling_basin`

| 常见标注 | 消力池、消力池底板、尾坎、消力坎、池墙 |
|---|---|
| 典型构件 | 消力池底板、池墙（边墙）、尾坎、C20 垫层、砂砾垫层、土工布、排水管 |
| 参数提取 | 池长、池宽、底板厚度、池墙高度/厚度、尾坎高度/宽度 |
| 计算方法 | 底板/垫层用棱柱法；池墙用断面面积法或 `L × T × H`；尾坎按梯形/矩形断面 × 宽度 |
| 注意事项 | 消力池底板通常下卧，底板低于上下游高程；尾坎是高出底板的小型坎墙 |

```
V_池底板 = L × W × T_floor
V_池墙 = T_wall × H_wall × L_wall × N_wall
V_尾坎 = A_尾坎断面 × W（或按梯形断面估算）
```

### 3.5 下游连接段 `downstream_connection`

| 常见标注 | 下游护坦、下游连接段、出口渐变段、下游翼墙 |
|---|---|
| 典型构件 | 混凝土/浆砌石护底、挡墙（悬臂式）、护坡、垫层、排水管、栏杆 |
| 参数提取 | 连接段长度、护底宽度/厚度、挡墙高度/厚度/长度 |
| 计算方法 | 与上游连接段类似；护底用棱柱法，挡墙用断面面积法 |
| 注意事项 | 下游侧通常有扩散渐变段，宽度可能逐渐增大 |

### 3.6 浆砌石海漫段 `mortared_riprap_apron`

| 常见标注 | 浆砌石海漫、M7.5/M10 浆砌石 |
|---|---|
| 典型构件 | 浆砌石护底、浆砌石护坡、砂砾垫层、排水管 |
| 参数提取 | 海漫长度、宽度、砌石厚度、垫层厚度 |
| 计算方法 | 棱柱法：`V = L × W × T`（护底+护坡分别计算） |
| 注意事项 | 护坡为两侧斜坡，按斜面积 × 厚度计算；坡度从横剖图读取 |

```
V_护底 = L × W_bottom × T
V_护坡 = L × S_slope × T × 2（S_slope 为斜坡斜长）
```

### 3.7 干砌石海漫段 `dry_riprap_apron`

| 常见标注 | 干砌石海漫 |
|---|---|
| 典型构件 | 干砌石护底、干砌石护坡、砂砾垫层、排水管 |
| 参数提取 | 同上，材料换为干砌石 |
| 计算方法 | 同浆砌石海漫段 |
| 注意事项 | 干砌石通常在下游侧浆砌石之后 |

### 3.8 抛石槽段 `dumped_stone_trench`

| 常见标注 | 抛石槽、抛石防冲槽、散抛石 |
|---|---|
| 典型构件 | 散抛石 |
| 参数提取 | 槽长、槽宽（顶宽/底宽）、槽深 |
| 计算方法 | 梯形断面面积 × 长度：`A = (W_top + W_bottom) / 2 × D × L` |
| 注意事项 | 通常位于最下游，断面为梯形槽 |

```
V = L × (W_top + W_bottom) / 2 × D
```

## 四、闸室段详细规则

闸室段是水闸核心也是最复杂的分段，需独立逐构件计算。

### 4.1 参数提取优先级

| 参数 | 优先来源 | 备注 |
|---|---|---|
| 闸室长度 `L_chamber` | 平面图或纵剖图 | 顺水流方向 |
| 总宽 `W_total` | 横剖图或平面图 | 底板/垫层计算使用，含边墙 |
| 底板厚度 `T_floor` | 纵剖图/横剖图 | 结构厚度 ≥ 0.1m |
| 垫层厚度 `T_cushion` | 纵剖图/横剖图 | 通常 C20，≥ 0.05m |
| 孔口数量 `N_opening` | 平面图/表格 | 过水孔数 |
| 孔口宽/高 | 平面图/表格/横剖图 | 校验闸墩布置 |
| 闸墩数量/厚度/高度/长度 | 平面图 + 剖面图 | 中墩 + 边墩，分别提取 |
| 边墙厚度/高度/长度 | 剖面图 + 平面图 | 通常左右各一道 |
| 胸墙/顶板尺寸 | 编号剖面/横剖图 | 注意扣除墩墙重叠 |

### 4.2 核心公式

```
V_floor      = L_chamber × W_total × T_floor       # 底板
V_cushion    = L_chamber × W_total × T_cushion       # 垫层
V_pier       = T_pier × L_pier × H_pier × N_pier     # 闸墩
V_wall       = T_wall × L_wall × H_wall × N_wall     # 边墙
V_chest_wall = L_chest × H_or_T_chest × W_effective  # 胸墙/顶板
V_pier2nd    = 门槽二期砼（按门槽尺寸估算）
```

### 4.3 胸墙/顶板扣除规则

胸墙/顶板的 `W_effective` 取值：
- 如果墩墙实体已计入 → 胸墙只补算孔口**净宽**范围内的体积（扣除墩墙重叠）。
- 如果墩墙计算未包含胸墙所在高程范围 → 可按完整结构宽度计算。
- **必须在假设条件中说明是否扣除了墩墙重叠。**

### 4.4 其他闸室构件

启闭平台、交通桥、排架柱、启闭机房等按图纸可见尺寸单独提取。若图纸信息不足以计算，记录到缺失信息表。

## 五、证据优先级

同一参数在多张图纸中出现时，采用优先级：

1. **编号剖面**（断面几何、断面面积最权威）
2. **纵剖图**（分段长度、标高、层厚、材料变化最权威）
3. **平面图**（平面宽度、总长、孔口数量、墩墙布置最权威）
4. **详图/材料表**（局部尺寸、材料等级、补充信息）

当不同来源数据冲突时，采用高优先级来源，并在假设条件中记录差异。

## 六、材料分类

- **C35/C30/C25 钢筋混凝土**：按图纸强度等级分别统计。只标注 `钢筋混凝土` 时写 `钢筋混凝土（强度等级未标注）`。
- **C20 混凝土**：通常为垫层或素混凝土层，按图纸标注归类。
- **M10/M7.5 浆砌石**：护坡、护底、挡墙等。
- **干砌石**：单独分类。
- **散抛石**：抛石槽等。
- **砂砾垫层 / 碎石垫层**：单独分类。
- **土工布**：按面积（m²）统计。
- **钢筋制安**：若图纸给出了配筋率或钢筋表，按 t 估算；否则记为 `未知`。
- 不同强度等级混凝土**不得合并**。

## 七、Excel 导出

### 7.1 使用脚本导出（首选）

整理 JSON 数据后运行：

```bash
python scripts/export_quantities.py takeoff.json output.xlsx
```

### 7.2 JSON 结构

```json
{
  "drawings": [],
  "parameters": [],
  "details": [],
  "assumptions": [],
  "missing": []
}
```

**drawings** — 图纸清点记录：

```json
{
  "file": "提取自3.4天门张角闸图册_01.png",
  "role": "纵剖图",
  "title": "水闸纵剖面图",
  "section": "全闸",
  "notes": "含各分段长度和底板标高"
}
```

**parameters** — 提取的参数（按分段归类）：

```json
{
  "segment": "chamber",
  "parameter": "L_chamber",
  "value": "16.30",
  "unit": "m",
  "source": "图01 纵剖图",
  "notes": ""
}
```

**details** — 工程量明细（每条一个构件）：

```json
{
  "segment": "chamber",
  "component": "底板",
  "material": "C30W4F150混凝土",
  "quantity_m3": 261.30,
  "formula": "16.30 × 10.68 × 1.50",
  "confidence": "较高",
  "source": "图01 + 图03 1-1剖面",
  "notes": ""
}
```

`confidence` 取值：`较高`（尺寸明确）/ `中等`（部分估算）/ `较低`（关键尺寸不确定）。

**assumptions** — 假设条件（每条一个字符串或对象）：

```json
"消力池段池墙高度取纵剖图标高差，未取得编号剖面验证。"
```

**missing** — 缺失信息：

```json
{
  "segment": "chamber",
  "item": "门槽二期砼",
  "impact": "影响闸室段混凝土总量约 2-5%",
  "needed": "门槽详图或门槽尺寸",
  "source": "图03 平面图有门槽位置但无尺寸"
}
```

### 7.3 输出工作簿结构

| 工作表 | 内容 |
|---|---|
| `图纸识别` | 每张图纸的角色、图名、剖面号、备注 |
| `参数提取` | 按分段列出所有提取的参数及来源 |
| `工程量明细` | 逐构件列出 segment/component/material/quantity/formula/confidence/source |
| `材料汇总` | 按材料类型汇总总方量（用 SUMIF 公式） |
| `分段汇总` | 按分段汇总总方量（用 SUMIF 公式） |
| `假设条件` | 所有假设和简化处理说明 |
| `缺失信息` | 无法计算的构件及影响评估 |

> 汇总表格式参考常见水闸工程量表（如白杨庄闸设计工程量表），按分段→构件→材料的层级组织。

### 7.4 脚本不可用时的回退

手工创建同样工作表和列结构的 Excel（使用 minimax-xlsx skill 或 openpyxl）。

## 八、最终回复要求

完成算量后，向用户报告：

- **输出文件**：`.xlsx` 文件路径。
- **总量概要**：按材料汇总和按分段汇总的主要方量。
- **关键假设**：列出对总量影响较大的假设（如平均宽法适用范围、墩墙重叠扣除方式等）。
- **缺失项**：列出影响较大的缺失尺寸及对应构件。
- **图纸覆盖**：使用了哪些图纸/页面，哪些页面未被使用。
