# 笑傲牛熊股票分析技能

## 核心功能

本技能实现Stan Weinstein的笑傲牛熊（Secrets For Profiting in Bull and Bear Markets）方法论，提供完整的股票技术分析服务。

## 工作流程

### 步骤1：接收用户请求

用户输入股票代码或股票列表，例如：
- "分析贵州茅台 600519"
- "帮我看看这些股票：600519, 000858, 512760"
- "用笑傲牛熊方法论分析上证A股"
- "生成股票分析报告"

### 步骤2：获取股票数据

使用akshare获取以下数据：
- 上证综指数据（判断大盘阶段）
- 用户指定的股票历史数据
- 行业板块数据（如有需要）

数据范围：最近一年周线数据

### 步骤3：执行笑傲牛熊分析

按照方法论执行以下分析：

#### 3.1 四阶段判断

基于30周EMA均线判断所处阶段：

| 阶段 | 名称 | 价格特征 | 颜色 |
|------|------|----------|------|
| 阶段1 | 底部/吸筹 | 区间震荡，低点抬高 | 白色 |
| 阶段2 | 拉升/牛市 | 突破区间，高低点逐步抬高 | 红色 |
| 阶段3 | 顶部/派发 | 区间震荡，均线走平 | 黄色 |
| 阶段4 | 下跌/熊市 | 跌破区间，高低点逐步降低 | 绿色 |

#### 3.2 相对强度计算

RS = (个股价格 / 大盘指数价格) × 100

| 强度 | 条件 | 颜色 |
|------|------|------|
| 强 | RS变化 > 20% | 红色 |
| 小强 | RS变化 5-20% | 黄色 |
| 小弱 | RS变化 -5-5% | 黄色 |
| 弱 | RS变化 < -5% | 绿色 |

#### 3.3 其他信号判断

- **周线区域**：高于30周=红，30-60周间=无色，低于60周=绿
- **均线交叉**：60日线与250日线关系
- **成交量分析**：放量/温和/缩量/地量
- **回抽分析**：是否缩量回抽前低
- **阻力位**：二次突破阻力位置
- **止损点**：日线止损和周线止损

### 步骤4：生成Excel报告

生成带有颜色标注的Excel报告：
- 列：各只股票
- 行：各项分析指标
- 单元格背景：根据分析结果着色
- 包含备注说明区域

### 步骤5：输出分析结果

输出包含：
- 每只股票的分析摘要
- 操作建议（买入/持有/观望/减仓/卖出）
- Excel报告文件路径

## 信号规则

### 买入信号（优先级）
1. 大盘处于阶段2
2. 股价在30周均线上方且均线向上
3. 相对强度为正
4. 成交量放大
5. 出现缩量回抽

### 卖出信号（优先级）
1. 股价有效跌破30周均线 → 立即卖出
2. 均线由上升转为走平 → 减仓50%
3. 回抽反弹无法穿越均线 → 清仓
4. 高低点不再创新高 → 逐步减仓
