# 笑傲牛熊（Stan Weinstein）方法论详解

## 一、核心原则（三条铁律）

### 1. 趋势是你的朋友
永远不要逆势操作。在下降趋势中买入就像接飞刀，风险极高。

### 2. 让利润奔跑，截断亏损
- 亏损股及时止损（控制在7-8%以内）
- 强势股持有至转弱再卖出
- 不要过早止盈

### 3. 相对强度优先
只交易强于大盘的股票。弱势股可能继续跑输大盘。

## 二、四阶段分析法

### 阶段详解

#### 第一阶段：底部/吸筹（Base/Accumulation）
```
特征：
- 价格在区间内震荡
- 波动幅度收窄
- 成交量逐渐减少
- 低点逐步抬高

均线状态：
- 30周均线走平或向下
- 价格围绕均线反复穿越

操作建议：
- 观望，不买入
- 耐心等待突破信号
```

#### 第二阶段：拉升/牛市（Advancing/Uptrend）
```
特征：
- 向上突破区间
- 高点、低点逐步抬高
- 趋势向上

均线状态：
- 30周均线向上运行
- 价格在均线上方

操作建议：
- 买入并持有
- 回调不破均线是加仓机会
```

#### 第三阶段：顶部/派发（Top/Distribution）
```
特征：
- 进入区间震荡
- 高点难以再创新高
- 均线走平

均线状态：
- 30周均线走平
- 价格反复穿越均线

操作建议：
- 逐步卖出
- 不再追高
```

#### 第四阶段：下跌/熊市（Declining/Downtrend）
```
特征：
- 向下突破区间
- 高点、低点逐步降低
- 趋势向下

均线状态：
- 30周均线向下运行
- 价格在均线下方

操作建议：
- 清仓或卖空
- 耐心等待下一个底部
```

## 三、核心公式

### 公式1：相对强度（RS）

```
RS = (个股收盘价 / 大盘收盘价) × 100

然后计算RS的变化率：
RS变化率 = (当前RS / 基准RS - 1) × 100%

判断标准：
- RS变化 > 20%：强（红色）
- RS变化 5-20%：小强（黄色）
- RS变化 -5-5%：小弱（黄色）
- RS变化 < -5%：弱（绿色）
```

### 公式2：买入价与止损价

```
买入价 = 前期高点 + 0.125元（最小价格单位）

止损位 = max(前期支撑低点, 30周均线位置) - 0.125元

硬止损 = 买入价 - 7%~8%
```

## 四、买入规则（第二阶段初期）

必须同时满足以下条件：

| 条件 | 说明 | 优先级 |
|------|------|--------|
| 大盘多头 | 整体市场处于上升趋势 | 必须 |
| 行业强势 | 目标股所在行业强于大盘 | 必须 |
| 股价在均线上方 | 价格站稳30周均线上方 | 必须 |
| 均线向上 | 30周均线已掉头向上 | 必须 |
| 突破阻力区 | 向上突破第一阶段横盘区间 | 必须 |
| 成交量放大 | 突破时成交量放大50%以上 | 必须 |
| 相对强度为正 | RS > 0 | 必须 |

### 金字塔式建仓

```
突破买点  →  买入 50% 仓位
回调不破  →  买入 30% 仓位
再次启动  →  买入 20% 仓位
```

---

## 五、卖出规则

### 卖出信号（按优先级）

1. **股价有效跌破30周均线** → 立即卖出
2. **均线由上升转为走平** → 减仓50%
3. **回抽反弹无法穿越均线** → 清仓
4. **高低点不再创新高** → 逐步减仓

### 止损规则

```
硬止损 = 买入价 - 7%~8%（个股）或 -3%~5%（大盘弱时）

移动止损 = 跟随30周均线向上移动
```

## 六、选股流程

### 标准流程（8步）

```
Step 1 → 判断大盘所处阶段（只用第二阶段操作）
Step 2 → 筛选强于大盘的行业（RS排名前三）
Step 3 → 在强势行业中找处于第一/二阶段的个股
Step 4 → 记录每只个股的突破价位
Step 5 → 优先选择：突破上方无阻力、创历史新高的个股
Step 6 → 检查RS线，必须在零轴上方
Step 7 → 等突破 + 成交量确认
Step 8 → 分批建仓，设置止损
```

### 仓位管理

| 资金规模 | 持仓数量 |
|----------|----------|
| 1万～2.5万美元 | 5～6只 |
| 10万美元以上 | 10～20只 |

- 单只股票不超过总仓位的 15%～20%
- 动态再平衡：每上涨 25%，检查是否需要调仓

## 七、常见问题

### Q: 如何判断是真正的突破而非假突破？
A: 观察成交量。真正的突破需要成交量放大确认（至少50%以上）。

### Q: 已经在第四阶段的股票可以买吗？
A: 不建议。第四阶段是下跌趋势，逆势操作风险极大。

### Q: 相对强度有什么作用？
A: 相对强度帮助筛选强势股。弱势股可能随大盘下跌，而强势股可能逆势上涨。

### Q: 止损位如何设置？
A: 日线止损=max(支撑低点, 30周均线)-0.125；长期止损=30周均线。

---

## 八、注意事项

1. **不要预测顶部和底部**
2. **跟随趋势，让利润奔跑**
3. **严格执行止损**
4. **只交易处于第二阶段的股票**
5. **相对强度必须是正的**
