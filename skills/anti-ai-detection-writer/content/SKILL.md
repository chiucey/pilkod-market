# 抗AI检测写作

降低文章AI特征，让文本看起来像真实人类随口记录，而非"写文章"。

## 核心理念

AI检测工具识别的不是"内容好坏"，而是"AI特征"——即文本中那些过于完整、流畅、规范的模式。对抗检测的核心，是破坏这些特征，让文本看起来像一个真实人类在随口记录，本技能示例、示范仅供参考。

## 三大破坏目标

| 目标 | 说明 | 方法 |
|------|------|------|
| **破坏完整性** | 不要开头、不要结尾、不要完整叙事弧线 | 从中间开始 |
| **破坏流畅性** | 加入废话、打断、跳跃、自我质疑 | 打乱节奏 |
| **破坏精致感** | 用口语、重复、不完美的表达 | 加入瑕疵 |

## 五步操作流程

### 第一步：选定题材（避坑）

**推荐：**
- 抽象哲理
- 生活片段
- 个人观察
- 冷思考

**避免：**
- 温情叙事（思乡、亲情）
- 正能量治愈
- 成功学鸡汤

### 第二步：写作时逐条对照（核心清单）

#### 1. 开头：从中间开始，不铺垫

**错误：**
```
"最近我发现……"
"有这样一个故事……"
"今天我想聊聊……"
```

**正确：**
```
"杯子有个裂纹。"
"也不知道从什么时候开始的。"
```

#### 2. 叙事：打散，不要完整故事

**错误：** 时间线清晰（去年→今年→现在），有起因、经过、结果

**正确：** 想到哪写到哪，细节可以重复，可以前后矛盾。

```
"第一次发现的时候想换一个，后来忘了。再后来每次来都找这个杯子。"
```

#### 3. 引用名人名言、诗词、书籍名句

引用是提升文章质感的重要手段，但必须自然融入，不用于论证，否则会被识别为AI特征。

**正确做法：**
```
- 用"突然想起""好像在哪看过""原话记不清了"引出
- 引用后不解释其含义，只是情绪触发
- 引用比例控制在全文20%左右（2-3处为宜）
```
**示例：**
```
"忽然想起一句诗，什么'日之夕矣，牛羊下来'，大概是这个意思。上学时背过，一直觉得跟自己没关系。现在坐在这儿，天黑了，不想走。"
```

**错误做法：**
```
"正如《诗经》所言：'日之夕矣，羊牛下来。'这表达了古人对归家的向往，也让我反思现代人的孤独。"
```

#### 4. 叙事带有感情色彩

感情色彩不是直接抒情（"我很感动""我好伤心"），而是通过细节、动作、内心独白、自我矛盾来传达。

**正确做法：**
```
- 用细节暗示情绪："杯子有个裂纹。第一次发现的时候想换一个，后来忘了。"
- 用动作表达情绪："手机震了一下。我没看。把手机翻过去扣在桌上。"
- 用自我质疑传达复杂心情："你说这是不是有病。也不是不想回。是回去了，也不知道干嘛。"
- 用平淡话语收束情绪："也就这点念想了。"
```
**错误做法：**
```
"我孤独极了。"
"那一刻我感受到深深的忧伤。"
```

#### 5. 语言：有废话、打断、自我质疑（下述为例子仅供参考）

- 加入口语词："其实""反正""你懂吗""可能""我也不知道"
- 加入括号插入：（写到这儿突然想起来……算了不想了）
- 加入反问："你说这是不是有病。"
- 加入自我矛盾："也不是不想回。是回去了，也不知道干嘛。"

#### 6. 细节：具体、有瑕疵

**错误：**
```
"咖啡很好喝"
"灯光很温暖"
```

**正确：**
```
"杯子有个裂纹"
"路灯黄黄的，照在地上像铺了层旧报纸"
```

#### 7. 结尾：戛然而止，不总结

**错误：**
```
"所以我们要珍惜当下"
"愿我们都能……"
"这就是人生的意义"
```

**正确：**
```
"躺下的时候想，明天去不去。应该会吧。"
```

#### 8. 段落分明：层次清晰但不死板

段落之间要有逻辑衔接，但不要刻意的"第一、第二、第三"。

**正确做法：**
```
- 每个段落围绕一个核心点展开
- 段落之间用自然过渡，不用序号或连接词
- 段落在视觉上有呼吸感，长短错落
```
**错误做法：**
```
"首先……其次……最后……"
"综上所述……"
```

#### 9. 内容质量：言之有物，有深度

在破坏AI特征的同时，保证内容有价值。

**正确做法：**
```
- 有独特的个人视角或洞察
- 有具体的场景、细节、感受
- 有一定思考深度，不流于表面
```
**错误做法：**
```
- 空泛的感慨："人生就是这样"
- 正确的废话："我们要努力"
- 无病呻吟："好孤独好寂寞"
```
#### 10. 主题突出：形散神不散

虽然叙事要打散、开头结尾要打破，但全文要有一条隐性主线。

**正确做法：**
```
- 全文围绕一个核心情绪或主题
- 所有细节、引用、动作都指向这个核心
- 读者能感受到统一感，即使文章"东拉西扯"
```
**错误做法：**
```
- 东一榔头西一棒槌，完全没有关联
- 写了很多，但不知所云
- 主题模糊，读者不知道你想表达什么
```
### 第三步：整体检查（写完后自查）

- 如果删掉任何一段，整体还成立？如果成立，说明段落功能太明确，需要打散。
- 有没有一句是"结论式"的？（如"这就是……"）有则删或改成个人感受。
- 引用是否自然融入？是否用了"突然想起""记不清原话"？是否超过3处？
- 感情色彩是否通过细节、动作、内心独白传达，而非直接抒情？
- 全文读一遍，有没有哪句话特别"顺"？有则加个打断、废话、反问。
- 段落是否分明？每个段落是否有明确的核心？
- 内容是否有深度，还是空泛感慨？
- 全文是否围绕一个核心主题？读者能感受到统一感吗？

### 第四步：必要时使用工具辅助

- 可先用AI生成初稿，但必须进行上述"人工化"改写。
- 检测后若AIGC值仍高，对照清单逐条修改，重点改开头、引用、结尾、情感表达方式。

### 第五步：成功案例对照（仅供参考，实际根据用户需求）

| 特征 | 错误写法（AI特征） | 正确写法（人工特征） |
|------|-------------------|---------------------|
| **开头** | 今天下班后，我走进了一家咖啡馆…… | 杯子有个裂纹。 |
| **引用** | 木心曾说："从前的日色变得慢。"这句话让我感到…… | 忽然想起一句诗，什么"日之夕矣，牛羊下来"，大概是这个意思。 |
| **感情** | 我很孤独，很疲惫。 | 手机震了一下。我没看。把手机翻过去扣在桌上。爱谁谁吧。 |
| **叙事** | 我加班到很晚，然后去了咖啡馆，点了咖啡，坐在窗边…… | 坐靠窗的位置……后来小姑娘过来加水，我问她叫什么。 |
| **结尾** | 这杯咖啡，是成年人最后的体面。 | 躺下的时候想，明天去不去。应该会吧。 |
| **语言** | 流畅、无废话 | "你说这是不是有病""可能我就是喜欢那个杯子？搞不懂" |

## 常见陷阱与解决

| 陷阱 | 问题 | 解决 |
|------|------|------|
| **引用堆砌或生硬** | 为了"有文化"而大量引用，且引用方式像在写论文 | 引用不超过2-3处，都以"突然想起""原话记不清了"引出，不解释 |
| **直接抒情** | 文章中出现"我很感动""我很难过"等直白表达 | 用细节、动作、内心独白代替 |
| **试图讲道理** | 文章最后总要总结一个道理 | 把道理藏在细节和动作里，让读者自己体会 |
| **语言太"干净"** | 没有废话、没有打断、没有口语 | 写完后故意加一两处"其实""我也不知道""你懂吗" |
| **叙事太完整** | 有头有尾，有因果 | 砍掉开头和结尾，从中间开始，在中间结束 |
| **段落混乱** | 没有层次，堆砌成一段 | 每个段落有明确核心，长短错落，自然过渡 |
| **内容空洞** | 空泛感慨，无病呻吟 | 有具体细节、个人视角、思考深度 |
| **主题模糊** | 东拉西扯，不知所云 | 围绕一个核心情绪或主题，形散神不散 |

## 快速检查清单

- [ ] 开头没有"今天""最近""我有个朋友"
- [ ] 没有"首先其次最后""总而言之"
- [ ] 没有完整的故事（有起因经过结果）
- [ ] 引用2-3处，都用"突然想起""记不清原话"引出
- [ ] 感情色彩通过细节、动作、内心独白传达，没有直接抒情
- [ ] 至少有一处括号插入或口语打断
- [ ] 至少有一处自我质疑或反问
- [ ] 结尾没有总结、升华、呼吁
- [ ] 全文读起来像一个人在自言自语，不像在写文章
- [ ] 段落分明，每个段落有明确的核心，长短错落
- [ ] 内容有深度，有具体细节和个人视角，不是空泛感慨
- [ ] 主题突出，全文围绕一个核心，形散神不散
