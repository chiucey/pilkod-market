## 🧱 万能公式（核心框架）

### 7段式标准公式

```
主体（Subject）
  ↓
主体细节（Subject Details）
  ↓
场景环境（Environment）
  ↓
艺术风格（Art Style）
  ↓
光影氛围（Lighting & Atmosphere）
  ↓
画面构图（Composition）
  ↓
技术参数（Technical Parameters）
```

### 速查模板

**人像摄影：**
```
[人物] + [表情/姿态] + [服装] + [场景] + [光影] + [风格] + [参数]
```
→ 示例：一个时尚女孩，街拍，卫衣+短裙，上海老洋房, golden hour, film photography, f/1.8 bokeh, 35mm film

**风景摄影：**
```
[地理环境] + [季节/时间] + [天气] + [光影] + [风格] + [参数]
```
→ 示例：西藏高原，夏季黄昏，雨后彩虹，volumetric light rays, landscape photography, ultra detailed, 8K

**概念设计：**
```
[世界观/风格] + [主体] + [环境] + [情绪] + [色调] + [参数]
```
→ 示例：赛博朋克风格，科技废土城市，霓虹雨夜，反乌托邦，teal and orange, cinematic, unreal engine 5

## 📌 提示词写作原则

1. **具体 > 抽象**：写"金色长发女孩"比只写"女孩"好得多
2. **风格明确**：指定艺术家或风格关键词，效果翻倍
3. **善用光影**：光影词是氛围感的关键，少了会平淡
4. **构图参数**：不说构图，AI 可能给你随意构图
5. **层层递进**：主体→场景→风格→光影→参数，逻辑清晰
6. **英语更准**：英文提示词效果普遍更好（平台对英文理解更深）
