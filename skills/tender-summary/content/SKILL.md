# Tender Summary

## Inputs to collect

- 用户只说触发词但**没附 Excel** → 先问"请把今天的招投标 Excel 发我"，不要凭空跑
- 多个 Excel → 处理最新上传那一个，歧义时问"哪个是今天的"
- 触发词 + Excel 都到位 → 直接开始，不用再问"是否开始"
- **「今日/今天」口径**：标题日期用**当前 session 日期**（YYYY-MM-DD），**不按 Excel 数据发布日期过滤**——即使用户发的是 7-24 的数据，标题也写 7-28
- **数据处理范围**：处理 Excel 全部通过过滤的数据（不按发布日期过滤 Excel 内容）——因为用户已经选择把这份 Excel 发给"今日"任务，全表都算"今日输入"

## Procedure

按以下顺序执行，**每一步都不跳**：

### 1. 读 Excel 并定位固定列

按以下列号取出原始数据（列号从 1 开始）：

| 列号 | 列名 | 取出的字段 |
|---|---|---|
| E | 区/县 | 所在区县 |
| F | 公告标题 | 公告标题 |
| G | 公告类别 | 信息类型判断 |
| H | 公告内容 | 公告内容（核心，要深入理解） |
| J | 公告地址 | 公告链接 |
| L | 项目名称 | 项目名称 |
| V | 单位名称 | 采购单位 |

如果实际 Excel 列顺序不匹配 → **停下来报错**，问用户提供正确的表，不要硬猜。

### 2. 异常过滤（先过滤，再做内容理解）

按以下规则**丢弃**不符合的记录：

| 规则 | 适用类型 | 判断依据 |
|---|---|---|
| 采购单位为「中国移动/中国联通/中国电信」系 | 全部 | V 列精确匹配（含全称/简称/大小写不敏感），需覆盖**系内子公司**（如"联通数字科技有限公司""中国移动通信集团北京有限公司"）|
| 标题包含「中标候选人公示」 | 仅中标公告 | F 列子串匹配 |
| 中标单位不在白名单 | 仅中标公告 | 见 `references/content-dictionary.md` 第 3 节 |

**运营商白名单**（仅中标公告用）：歌华有线、中国广电、中国移动、中国联通、中国电信（含上述各家系内子公司简称/全称/分公司）。
即：中标公告只收集中标单位属于上述五家之一；其他中标公告全部丢弃。

### 3. 类型识别（G 列判断）

| G 列取值 | 信息类型 |
|---|---|
| 招标、询价、竞谈、竞价 | 招标公告 |
| 采购意向 | 采购意向 |
| 中标、成交 | 中标公告 |
| 其他 | 丢弃（不收集） |

注意：G 列是"公告类别"，不是公告正文里出现的"采购意向/中标"等字眼；按 G 列原值取。

完整关键词列表与匹配规则见 `references/content-dictionary.md` 第 4 节。

### 4. 项目需求提炼 + 关键产品服务过滤（核心）

**核心原则：LLM 做正经理解，不靠关键词硬匹配**。

**关键产品服务列表**（26 类关键词）：详见 `references/content-dictionary.md` 第 1 节。**这 26 个关键词是 LLM 的辅助锚点，不是判定标准**——LLM 应该用自己的语义理解力去读 H 列内容。

**如果 Excel 自带"匹配关键词"列**（如剑鱼标讯的 B 列）：
- 优先用 Excel 自带关键词做初筛，**不必再自己做关键词匹配**
- 但 LLM 仍要**逐条**读 H 列内容做语义理解

**判定流程**（LLM 思维）：

1. **LLM 读 H 列内容 + F 列标题 + L 列项目名**，理解这个项目**实质在采购什么**
2. **判断项目实质**是否属于以下类型之一：
   - 通信类（专线/线路/带宽/物联网卡/手机卡/网络接入等）
   - 云计算/云服务/政务云/IDC 机房等
   - 视频会议/专网/应急广播等
   - 信息化集成（平台/系统建设/集成项目）
   - 大数据/数据协同等
   - 弱电/智能化（明确以通信/网络/云为主语）
3. **如果是以下情况，丢弃**：
   - **硬件就丢（无条件）**：项目名/标题/H列中只要**出现**以下硬件词之一（服务器/存储/交换机/路由器/终端/打印机/磁盘阵列/光纤环机/光纤设备/机柜/摄像机/摄像头/防火墙/负载均衡/网关/台式机/笔记本/扫描仪/复印机/碎纸机/投影仪/一体机/显示器/硬件/基站等），**无条件丢弃**——不论是主导、附属、混合其他服务，全部丢。不存在"硬件+服务"混合保留的灰色地带。
   - **安全测评/咨询服务就丢**：项目名/标题/H列含"等保测评/等级保护测评/网络安全等级保护测评/商用密码应用安全性评估/安全咨询/安全审计/风险评估/安全检查/安全运维"等服务类关键词 → 丢。这类是**第三方安全咨询服务**，不是采购网络/通信/云资源。例：
     - "电子政务外网等保测评和商用密码评估" → 丢
     - "XX 系统信息安全风险评估" → 丢
     - **例外**：保留"渗透测试/拨测/监控/巡检"——这些是**持续运营服务**而非一次性咨询。
   - **能力建设/科研项目/创新工程就丢**：项目名/标题含"运营管理能力/能力建设/创新发展工程/科研项目/示范工程/试点项目/专项"等服务类关键词 → 丢。这类是**咨询服务/科研/示范项目**，不是采购具体网络/通信/云资源。例：
     - "eSIM 业务管理平台-**运营管理能力**" → 丢
     - "工业互联网**创新发展工程**-标识解析体系" → 丢
     - "XX 平台**能力建设**项目" → 丢
     - "XX **示范工程**" → 丢
     - **例外**：保留"运营/运营服务"等真正的运营服务（如"专线运营""平台运营"）——这些是**持续运营**而非"运营管理能力建设"。
   - **企业内部信息化项目就丢**：项目主语是"建设/开发/优化一个**系统/平台**"（不是采购运营商/云服务商提供的网络/通信/云资源）→ 丢。判断：**项目实质是采购外部网络/通信/云资源**（专线租赁、政务云租赁、宽带接入、互联网接入、语音迁移、IDC 机房等）才保留；项目实质是**自建/自用系统**（财务/HR/办公/医疗等内部系统、SaaS 订阅、网管软件、SDK 开发、涉密监管系统、给已建系统配套的 CDN 等）→ 丢。例：
     - "XX 财务系统功能优化项目" → 丢
     - "XX 医学研究登记备案信息系统建设" → 丢
     - "XX 大数据分析通用系统建设" → 丢
     - "XX 移动办公平台订阅服务" → 丢
     - "XX 即时通讯 SDK 软件鸿蒙适配" → 丢
     - "XX 涉密计算机网络保密自监管系统" → 丢
     - "XX 网络基础设施一体化管控（网管软件）" → 丢
     - "12306 网内容分发网络（CDN）服务" → 丢（给已建系统配套，非对外 CDN）
     - "XX 网络综合布线及维修服务框架协议" → 丢（布线+维修是网络维护类，不是采购外部网络资源）
     - **保留**：
       - "专线租赁"（采购运营商专线）
       - "政务云租赁"（采购云服务商云资源）
       - "宽带网络服务"（采购运营商宽带）
       - "互联网接入服务"（采购运营商接入）
       - "语音迁移服务"（采购运营商语音迁移）
       - "网络通信服务"（采购外部网络通信）
       - "链路租赁"（采购外部链路）
- **纯软件采购就丢**：项目主语是"采购**软件**/SaaS/云端应用软件"（不是采购云**资源**）→ 丢。判断：项目采购的是**云基础设施资源**（云服务器/云存储/云网络/政务云租赁/公有云租赁等）→ 保留；项目采购的是**应用软件**（云诊室软件、办公 SaaS、管理软件、行业应用软件等）→ 丢。例：
  - "互联网诊疗云诊室业务**所需的软件**" → 丢（采购云端应用软件）
  - "XX 办公自动化系统软件" → 丢
  - "XX 行业应用软件开发服务" → 丢
  - **保留**：
    - "政务云租赁"（采购的是云资源 CPU/存储/网络）
    - "公有云资源租赁"（同上）
    - "专线租赁/裸光纤租赁"（采购的是网络资源）
   - **AI 算力就丢**：项目**主要**是采购 GPU 智算/大模型/AI 训练算力/智能算力等 AI 算力服务
   - **运维/升级就丢**（仅招标/采购意向；中标公告保留）：项目是运行维护/运维/升级改造/改造/升级/保障/维护性质的服务
   - **不相关**：项目不是网络/通信/云/信息化类（如客用品采购/办公室装修/电梯维保/环卫场所/森林防火/地接服务等）
   - **运营商黑名单**：采购方是移动/联通/电信系（含系内子公司"联通数字科技有限公司""联通数科"等）
   - **中标白名单不过**（仅中标公告）：中标方不属于移动/联通/电信/歌华有线/中国广电
   - **项目名/标题含"中标候选人公示"**（仅中标公告）
4. **判断采购的"产品类型"**（用于项目需求提炼）：
   - 主语是什么（专线/云/物联网卡/平台/系统/视频会议/专网……）
   - 数量/规模/带宽/时延等技术参数
   - 服务期限/区域/对接对象

**项目需求提炼格式**（3-5 个核心关键词 + 一句话总结）：
```
<关键词1>/<关键词2>/<关键词3>/<关键词4>：<一句话总结，含核心产品+规模参数+服务期限/对象>
```
- **关键词**：从 26 类关键词中选 3-5 个最相关的，或基于 H 列内容提炼具体技术词（如"50M 专网"、"政务外网出口"、"1G 专线"）
- **一句话总结**：完整描述项目采购内容，至少包括"采购什么+给谁+多大量+多长时间"
- **不要在项目需求里写预算金额**——预算有独立的"预算金额"字段，项目需求里只写采购内容、规模参数、期限、对象
- 例：
  - "专线/数据中心/1G 专线/租赁：公安部机房至亦庄数据中心 1G 备用专线 3 年租赁"
  - "数据专网/数据传输/带宽/50M：顺义水务局与下属 10 个分支机构 50M 数据专网建设"
  - "政务云/云服务商/西城区：西城区 2026 年政务云服务商采购"
  - "互联网接入/政务外网/流量清洗/密云：密云区数据中心互联网接入服务（含 7×24 流量清洗）"
  - "无线互联网/访问服务/5 年/光大银行：光大银行北京分行 2026-2030 年支行网点无线互联网访问服务"

**提炼的边界**：
- 提炼结果不是简单"项目名重复"——必须包含**新的信息**（规模/期限/对接对象/技术参数）
- 如果 H 列没有足够信息，关键词可以只列产品类型（如"信息化集成/系统"），一句话用项目名补充
- **不要**虚构数字或参数——H 列没有就标"具体规模见公告"

### 5. 按类型深度提炼（H 列）

通过 4 后，根据类型从 H 列进一步提取：

| 信息类型 | 额外提取字段 |
|---|---|
| 招标公告 | 预算金额、获取招标文件时间/报名截止日期（**精确到分**） |
| 采购意向 | 预算金额、预计采购时间（格式 YYYY-MM） |
| 中标公告 | 中标单位、中标金额 |

**招标公告时间字段优先级**（二选一，优先"获取招标文件时间"）：
- **优先提炼"获取招标文件时间"**：找 H 列里"获取招标文件时间/采购文件获取时间/磋商文件获取时间/获取采购文件时间/招标文件获取时间/采购文件购买时间"等关键词，输出时间段 `YYYY-MM-DD HH:MM ~ YYYY-MM-DD HH:MM`（精确到分）
- **找不到"获取招标文件时间"** → 提炼"报名截止日期"：找"报名截止/投标截止/响应文件递交截止/响应截止"等关键词，输出单点时间 `YYYY-MM-DD HH:MM`（精确到分）
- **特殊格式**："可在截止时间前：2026年7月27日10时00分止" → 提炼为"截止 2026-07-27 10:00"
- **都找不到** → 用 Excel 自带字段（只能到日）：
  - 优先用第 18 列「报名截止日期」；如空再试用第 19 列「开标日期」；如空再试用第 20 列「投标截止日期」
- H 列有内容时必须**精确到分钟**；只到日时填“未披露”不填具体时间

**"获取招标文件时间"段的提取与归一**（重要）：
"获取招标文件时间"段常见多种格式，**不能只匹配标准 `YYYY-MM-DD HH:MM`**。提炼步骤：
1. **找关键词段**（按优先级）：`获取招标文件时间` / `磋商文件获取时间` / `采购文件获取时间` / `获取采购文件时间` / `招标文件获取时间` / `采购文件购买时间` / `文件获取时间` / `文件发售时间` / `获取时间` / `购买时间` / `领取时间`
2. **抓取该段到段落结束**（可能是句子末尾、或者下一个大段标题如 "2." "3."，或者"地点："/"方式："/"招标文件领取地点"/"递交投标文件地点"等后续信息标记）。注意：原文常见"获取时间：...获取地点：..."，段尾"获取地点"中的"获取"字眼会被程序误抓，**段尾正则要包含"获取地点"/"领取地点"/"购买地点"等完整词组**（先于"获取"/"地点"单独匹配）
3. **去掉尾部括号说明**（如"（北京时间，下同，法定节假日除外）"、"（含）"等）
4. **去掉尾部编号杂质**（如"。" "、"、"5."等）
5. **归一化**：
   - 日期：`2026年7月24日` → `2026-07-24`（`YYYY年M月D日` → `YYYY-MM-DD`）
   - 时间：`9:00` → `09:00`（补零）
   - "至" 加空格（"`至`" → "` 至 `"，让时间段更清晰）
   - 合并多余空白
6. **保留详细描述**（如"每天上午09:00至12:00，下午13:00至17:00" 这种上下午时间描述原样保留）

示例：
- H 列原文：`磋商文件获取时间：2026年7月24日至2026年7月31日，每天上午9:00至12:00，下午13:00至17:00（北京时间，下同，法定节假日除外）`
- 归一输出：`2026-07-24 至 2026-07-31，每天上午09:00 至 12:00，下午13:00 至 17:00`

**H 列时间解析规则**（支持以下格式，全部归一为 `YYYY-MM-DD HH:MM`）：
- `2026-07-23 00:00:00` → `2026-07-23 00:00`
- `2026-07-28 10:00` → `2026-07-28 10:00`
- `2026年8月13日9时00分` → `2026-08-13 09:00`
- `2026年8月12日上午9:00` → `2026-08-12 09:00`
- `2026-08-17 09:30（北京时间）` → `2026-08-17 09:30`
- 范围格式 `2026-07-23 00:00:00～2026-07-27 23:59:59` → `2026-07-23 00:00 ~ 2026-07-27 23:59`

**H 列（公告内容）为空时的回退策略**：
- **项目需求**：用 F 列标题或 L 列项目名补（取更具体的那条）
- **预算金额**：用 Excel 自带结构化字段（第 16 列「预算金额（万元）」）
- **报名截止日期**：用第 18 列；**开标日期**：用第 19 列；**投标截止日期**：用第 20 列（按 F 列标题决定取哪一个）—— **这些字段只有日期，没有时间，输出时只能精确到日**
- **预计采购时间**：用 H 列「备注」段提到的月份；如没有 → "未披露"
- **中标单位**：用第 28 列「中标单位信息（来源:招标公告网站）」下的「单位名称」子列；如空再尝试 H 列文本里"中标供应商名称"附近的实体名
- **中标金额**：用第 17 列「中标金额（万元）」

**「所在区县」三段式回退**（注意不是 H 列空了才走，是 E 列空了才走）：
1. **第一优先**：E 列「区县」原值（如有）→ 直接用
2. **第二优先**：从 H 列内容 / F 列标题里搜 "XX省XX市XX区" / "北京市XX区" 这种地址模式 → 找到就用
3. **第三优先**：LLM 知识库推断——根据预算单位名称推断其**现实办公地址**所在区县
   - 优先用 **最新办公地址**（不是注册地；如有公司迁址公告则用最新）
   - 找不到明确最新办公地址时，用 **注册地**（注册地更稳定）
   - 推断结果**加"（推断）"后缀**，让用户知道这是推算的
   - 完全无可靠信息时 → 标"未披露"

如果某些字段在 H 列和结构化字段都找不到 → 输出"未披露"，**不要编造**。

**格式硬约束**：
- 标题：`YYYY-MM-DD招标--意向-中标信息汇总（共X条）:` —— **日期后紧跟"招标"，无空格；末尾是冒号**
- X = 通过全部过滤后留下的总记录数（招标 + 意向 + 中标三类合计）
- 三类分节顺序固定：招标公告 → 采购意向 → 中标公告
- 空类别**不省略分节标题**（如某天无中标，仍输出"中标公告\n（无）"）
- 每条记录从 1 开始重新编号（不跨类别累加）
- 字段顺序**严格按模板**，不要调换、不要遗漏、不要多加
- 字段值缺失时填"未披露"，**不要写 N/A、空、空字符串**
- 中标公告里"项目需求"和"采购单位"之间**没有空行**（按用户模板）
- 招标公告"获取招标文件时间/报名截止日期"和"公告链接"之间**没有空行**（按用户模板）
- **其他字段之间也都没有空行**（按用户最新模板）
- **空行规则汇总**：单条记录内字段间无空行；同一类别多条记录之间有 1 个空行；不同类别分节之间有 1 个空行；标题和首个分节之间有 1 个空行
- 紧急标记：招标公告里"获取招标文件时间/报名截止日期"是当日 → 在条目最前面加 `🔥`（不是项目名前）
- **不要再加任何"以下是..."之类的解释性前言**

## Failure handling

| 情况 | 处理 |
|---|---|
| Excel 读不出 / 列结构不对 | 报错 + 让用户确认列号，**不要**继续编 |
| G 列取值不在三类里 | 静默丢弃（不报错） |
| 关键产品服务列表**全无命中** | 静默丢弃该条（不报错） |
| 关键产品服务**有命中**但语义判断不相关（只出现在资格要求/能力描述/邮箱） | 静默丢弃（不报错） |
| H 列内容**为空** | 用 F 列标题 / L 列项目名补项目需求；预算/截止时间/中标单位/中标金额回退到 Excel 自带结构化字段 |
| H 列内容理解不出预算金额/时间/中标单位等 | 字段填"未披露"，不丢弃整条 |
| 采购单位是运营商 → 全条丢弃（不留行） | |
| 中标单位不在白名单 → 整条丢弃 | |
| 标题含"中标候选人公示" | 中标公告里整条丢弃 |
| 最终 0 条 | 仍输出标题"YYYY-MM-DD招标--意向-中标信息汇总（共0条）:"，正文三类都标"（无）" |
| 标题日期 | 用**当前 session 日期**（如 2026-07-28），**不**用 Excel 里数据的发布日期（即使 Excel 是 7-24 的，标题仍写 7-28） |

## Notes

- H 列公告内容是**自由文本**，项目需求提炼依赖模型语义理解。提炼时先识别"采购方要买什么"，再判断是否命中 26 类关键词之一
- 关键产品服务列表要**按子串匹配**（如 H 列出现"云计算平台"也命中"云计算"），不要做整词匹配
- 26 类关键词大小写不敏感（中文不涉及，但英文缩写如 IDC/5G/wifi 不区分大小写）
- "运营商黑名单"（中国移动/联通/电信）做精确包含匹配即可，"中国移动通信集团 XX 公司"应识别为"中国移动"

## 输出规范：处理统计各阶段必须配项目名

每轮处理后给用户讲结果时，**必须**用一句话讲清每条数据被丢在哪个阶段。trace 数据可以现跑（不用每次保留在最终输出文件里），但**向用户汇报时要按阶段列出项目名**，让用户能一眼看出哪些项目被丢在哪个规则下。

阶段名按程序运行顺序：运营商黑(buyer) → 运营商黑(名称) → 长城网 → 变更/更正公告 → 中标候选 → 中标白名单不过 → 无B列关键词 → 硬件 → 硬件(PC) → AI算力 → 运维 → 安全测评/咨询 → 能力建设/创新工程 → 企业内部信息化。最终保留条数 = 总条数 - 全部丢弃条数。
