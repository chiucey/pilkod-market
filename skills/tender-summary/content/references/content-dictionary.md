## 1. 关键产品服务列表（26 类）

**用途**：判断 H 列提炼出的「项目需求」是否属于本技能关心的范围。命中任一即保留该公告。

匹配规则：
- 中文关键词：子串匹配（"云计算平台"也命中"云计算"）
- 英文/数字缩写（IDC/5G/wifi）：大小写不敏感、子串匹配
- 一条公告中只要出现任一关键词就保留

```
# 基础设施类
数据中心
IDC
云计算
云服务
云租赁

# 通信类
固话语音
IP电话         # VoIP / IP PBX（避免误命中普通电话）
互联网接入
光纤接入
网络链路租用
网络通信服务
专网专线
专网           # 应急专网 / 行业专网 / 政府专网
宽带           # 校园宽带/家庭宽带/专线宽带
物联网卡       # 5G 物联网的子集
线路租用       # 运营商通信线路租用（如"运营商通信线路租用"）
通信线路       # 通信线路 / 数据线路 / 传输线路
通信专线       # 通信专线（与"专网专线"互补，区别于金融/医疗专线）
政务云         # 政务专属云平台
电子政务       # 电子政务外网 / 电子政务专网
视频会议       # 视频会议系统

# 算力/AI 类（AI 算力不在本技能关心范围，已去掉 GPU/智算/算力）
大数据         # 大数据平台

# 行业专网/集成类
信息化集成
wifi无线网          # 也匹配 WiFi、WIFI
5G物联网
应急广播
```

**示例匹配**：
| H 列文本 | 命中 | 原因 |
|---|---|---|
| "采购云计算平台服务" | ✅ | 命中"云计算" |
| "建设 IDC 机房" | ✅ | 命中"IDC" |
| "专线网络租用" | ✅ | 命中"专网专线"、"网络链路租用" |
| "采购办公电脑" | ❌ | 未命中 |
| "购买空调设备" | ❌ | 未命中 |
| "5G 专网建设" | ✅ | 命中"5G物联网"、"专网专线" |

## 2. 运营商黑名单（采购方）

**用途**：当 V 列（采购单位）属于本表任一项时，**整条公告丢弃**（无论类型）。

匹配规则：
- 子串包含即命中
- 简称 + 全称都识别（中国联通 / 中国联合网络通信 都视为同一运营商）

```
中国移动
中国移动通信
中国联通
中国联合网络通信
中国电信
中国电信股份
```

## 3. 中标公告运营商白名单

**用途**：仅对**中标公告**生效。从 H 列提炼出的「中标单位」必须命中本表任一项，否则整条丢弃。

匹配规则同黑名单（简称 + 全称都识别）：

```
歌华有线
中国广电
中国移动
中国移动通信
中国联通
中国联合网络通信
中国电信
中国电信股份
```

注意：与「运营商黑名单」的关系——
- 黑名单作用于**采购方**（V 列）
- 白名单作用于**中标方**（H 列提炼）
- 同一公告里两个角色可能都是运营商，正常保留

## 4. 公告类别 → 信息类型映射（G 列）

G 列（公告类别）文本按如下归类，子串包含即命中（取第一个命中的类型）：

| 关键词 | 信息类型 |
|---|---|
| 招标 | 招标公告 |
| 询价 | 招标公告 |
| 竞谈 | 招标公告 |
| 竞价 | 招标公告 |
| 采购意向 | 采购意向 |
| 中标 | 中标公告 |
| 成交 | 中标公告 |

未命中上述任一关键词 → 整条丢弃（不收集）。

## 5. 中标候选人公示识别（F 列）

**用途**：F 列（公告标题）包含「中标候选人公示」→ 中标公告里整条丢弃。

匹配关键词：

```
中标候选人公示
中标候选人
候选人公示
```

注：仅匹配标题，**不匹配** H 列内容里的相同文本。

## 6. 字段缺失处理

如果以下字段在源数据中提取不到，统一填 `未披露`：

- 预算金额
- 获取招标文件时间 / 报名截止日期
- 预计采购时间
- 中标单位
- 中标金额
- 所在区县（E 列空）
- 公告链接（J 列空）

`项目需求` 缺失 → 整条丢弃（视为 H 列内容无法理解）。
