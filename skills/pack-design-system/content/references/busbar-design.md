# 家用储能电池包汇流排设计方案

## 1. 设计概述

### 1.1 基础参数

| 参数 | 数值 | 说明 |
|------|------|------|
| 电芯配置 | 15S7P | 15串7并 |
| 标称电压 | 48V (15×3.2V) | |
| 标称电流 | 35A | 350Ah/10h放电率 |
| 峰值电流 | 100A | 短时放电 |
| 最大充电电流 | 35A | 0.1C充电 |

### 1.2 设计目标

- 汇流排种类最少化（降低模具成本）
- 对称设计原则（均衡电流分布）
- 低内阻设计（降低温升）
- 工艺可行（激光焊/电阻焊）

---

## 2. 汇流排结构设计

### 2.1 串并联连接逻辑

```
电芯排布示意（7并×15串简化图）:

并联组1 → P1: [C1][C2][C3][C4][C5][C6][C7]
并联组2 → P2: [C8][C9][C10][C11][C12][C13][C14]
...
并联组7 → P7: [C99][C100][C101][C102][C103][C104][C105]

串联连接: P1+ → P2+ → P3+ → ... → P7+ →  Pack+
        ↓       ↓       ↓              ↓
       P1-     P2-     P3-            P7-
        ↓       ↓       ↓              ↓
       (内部连接形成串联)
```

### 2.2 汇流排类型定义

| 类型 | 数量 | 用途 |
|------|------|------|
| **A型汇流排** | 1 | 主正极输出 |
| **B型汇流排** | 1 | 主负极输出 |
| **C型汇流排** | 13 | 串联连接排 |
| **D型汇流排** | 15 | 并联汇流排（横向连接） |

**总计：30个汇流排 → 设计优化为2种通用型号**

## 3. 优化方案：模块化汇流排设计

### 3.1 设计原则

采用"积木式"设计，通过少量标准化零件实现完整连接：

| 零件类型 | 数量 | 说明 |
|---------|------|------|
| **串联连接排 (Series Bar)** | 13个 | 跨并联组连接 |
| **并联汇流排 (Parallel Bar)** | 2个 | 并联组内部连接 |
| **主极输出排 (Terminal Bar)** | 2个 | 正负极端子 |

## 4. 材料选择

### 4.1 铜排材料对比

| 材料 | 导电率 | 焊接性 | 成本 | 推荐用途 |
|------|--------|--------|------|---------|
| T2紫铜 | 100% IACS | 一般 | 中 | 普通汇流排 |
| 镀锡紫铜 | 98% IACS | 好 | 中高 | 激光焊首选 |
| 镍铜合金 | 85% IACS | 好 | 高 | 耐腐蚀要求 |
| 铝合金 | 60% IACS | 差 | 低 | 不推荐 |

**推荐：T2紫铜镀锡**

### 4.2 材料规格

| 项目 | 规格 |
|------|------|
| 材质 | T2 (铜含量≥99.9%) |
| 状态 | 软态 (R) 或半硬 (Y2) |
| 表面处理 | 镀锡 (Sn 5-15μm) |
| 镀层附着力 | 无起皮、脱落 |
| 硬度 | 50-90 HB |

## 5. 内阻计算与温升分析

### 5.1 电流路径分析

```
Pack+ ──────────────────────────────────→ Pack-
       │                                    ↑
       │  (假设电流从最远电芯流入)              │
       ↓                                    │
  [C1]─[C2]─[C3]─[C4]─[C5]─[C6]─[C7]      │
       │                                    │
       └────────────────────────────────────┘

最远路径: 7个焊点 + 7段汇流排
```

### 5.2 内阻估算

| 组件 | 阻值 | 说明 |
|------|------|------|
| 焊点电阻 | 0.1mΩ | 每个约0.015mΩ |
| 铜排电阻 | 0.2mΩ | 280mm×10mm×1.5mm |
| 接触电阻 | 0.05mΩ | 端子连接 |
| **单路径总阻** | **≈0.35mΩ** | |
| **Pack等效内阻** | **≈0.05mΩ** | 7路并联 |

### 5.3 温升计算

| 工况 | 电流 | 内阻 | 功耗 | 温升(自然散热) |
|------|------|------|------|---------------|
| 持续放电 | 35A | 0.05mΩ | 0.06W | <1°C |
| 峰值放电 | 100A | 0.05mΩ | 0.5W | <5°C |
| 快充 | 35A | 0.05mΩ | 0.06W | <1°C |

**结论：汇流排内阻引起的温升可忽略**

## 6. 连接工艺

### 6.1 激光焊接 (推荐)

| 参数 | 规格 |
|------|------|
| 焊接方式 | 光纤激光焊接 |
| 激光功率 | 800-1500W |
| 焊接速度 | 50-100mm/s |
| 焊点直径 | φ3-5mm |
| 焊接深度 | ≥1.0mm (熔透) |
| 气保护 | 氩气 (Ar 99.99%) |

**优点**：
- 焊点美观，热影响区小
- 自动化程度高
- 焊接强度高

**缺点**：
- 设备投资大
- 对工件配合精度要求高

### 6.2 电阻焊接

| 参数 | 规格 |
|------|------|
| 焊接方式 | 中频电阻焊 |
| 焊接电流 | 3000-8000A |
| 焊接时间 | 20-100ms |
| 电极压力 | 30-100N |
| 焊点直径 | φ4-6mm |

**优点**：
- 设备成本低
- 对镀层适应性好

**缺点**：
- 热影响区较大
- 自动化程度一般

### 6.3 焊接质量检验

| 检验项目 | 方法 | 标准 |
|---------|------|------|
| 外观检查 | 目视 | 无虚焊、裂纹 |
| 拉拔力测试 | 拉力计 | ≥50N/焊点 |
| 接触电阻 | 四线法 | <0.1mΩ/焊点 |

## 7. 绝缘与防护

### 7.1 绝缘方案

| 方案 | 材料 | 厚度 | 特点 |
|------|------|------|------|
| **热缩管** | 聚烯烃 | 0.5-1.0mm | 包裹美观 |
| **PCB板** | FR4 | 1.6mm | 集成度高 |
| **注塑** | PA66 | 2.0mm | 防护最好 |

**推荐：热缩管 + 硅胶板组合**

### 7.2 绝缘步骤

1. 焊接完成后进行外观检验
2. 清洁汇流排表面
3. 套入热缩管 (φ10/15mm规格)
4. 热风枪加热收缩
5. 关键部位贴硅胶垫
6. 耐压测试 (500VDC/1min)
