## 电芯选型指南

### 按应用场景选型

| 应用场景 | 推荐电芯 | 理由 |
|---------|---------|------|
| 储能电站(削峰填谷) | C46-100Ah / C50系列 | 大容量、低成本 |
| 家用储能 | C33-40Ah / C46-50Ah | 适中容量、易于集成 |
| 通信备电 | C33-25Ah / C33-40Ah | 小体积、高可靠性 |
| 轻型动力(AGV/叉车) | C46-75Ah / C50-100Ah | 高功率、中大容量 |
| 换电/重卡 | C50-180Ah | 超大容量、高能量密度 |

### 按空间约束选型

| 空间限制 | 推荐方案 |
|---------|---------|
| 高度受限(<100mm) | C33系列 |
| 直径受限(圆形截面) | C46系列 |
| 重量受限 | C33系列(轻量化) |
| 体积能量密度优先 | C50系列 |
