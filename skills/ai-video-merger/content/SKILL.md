# AI视频合成助手

## 核心能力

将AI生成的多个短视频片段（AI短剧、AI漫剧等）一键合并为完整的视频作品。

## 工作流程

### 步骤1：收集视频信息

当用户提供多个视频片段时，询问以下信息：

1. **视频片段列表**：用户提供需要合并的视频URL或文件
2. **视频顺序**：确认视频的排列顺序（按1,2,3...顺序合并）
3. **旁白/配音**（可选）：是否有单独的旁白文件需要嵌入
4. **背景音乐**（可选）：是否需要添加背景音乐

### 步骤2：生成合并方案

根据用户提供的素材，生成FFmpeg.wasm合并命令或完整的React网页应用。

**合并逻辑**：
```
输入文件 → 视频片段（5个）
         → 旁白文件（可选，5个）
         → 背景音乐（可选，1个）

处理流程：
1. 按顺序拼接所有视频片段
2. 将旁白对齐到对应视频段的时间点
3. 混入背景音乐（音量降低，不盖过旁白）
4. 输出完整视频
```

### 步骤3：构建网页应用

使用React + FFmpeg.wasm构建单页面应用：

```tsx
// 核心功能
- 视频片段上传/URL输入
- 旁白文件关联
- 背景音乐添加
- 一键合成按钮
- 进度显示
- 自动下载
```

**技术栈**：
- React + TypeScript
- FFmpeg.wasm（浏览器端FFmpeg）
- Tailwind CSS（样式）
- 单HTML文件部署

### 步骤4：部署与交付

1. 将生成的网页部署到可访问的URL
2. 将链接发送给用户
3. 用户打开链接，点击"开始合成"即可

## 技术原理

### 什么是FFmpeg.wasm？

FFmpeg是音视频处理领域的"瑞士军刀"，但传统FFmpeg需要安装在服务器上。

FFmpeg.wasm让FFmpeg可以在浏览器中运行：
- 不需要服务器安装
- 不消耗服务器算力
- 文件直接从CDN下载
- 纯本地处理，保护隐私

### 处理流程

```
用户请求合并
    ↓
AI生成React+FFmpeg.wasm网页
    ↓
部署网页，发送链接给用户
    ↓
用户打开网页
    ↓
浏览器自动处理：
  - 下载视频片段
  - 下载音频文件
  - FFmpeg.wasm执行合并
  - 生成最终视频
    ↓
自动弹出下载
```

- 视频越大，合成时间越长（约3-5分钟）
- 建议使用Chrome/Edge浏览器
