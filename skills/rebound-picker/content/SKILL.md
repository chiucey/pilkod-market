# 超跌反弹选股系统

## 功能
每日14:30自动扫描A股全市场，筛选超跌反弹候选股，尾盘买入次日冲高卖。

## 选股条件
- 今日跌幅：-3% ~ -8%
- 距60日高点跌幅：25% ~ 45%
- 量比：> 1.5
- 标的范围：主板（沪6开头、深0开头）
- 排除：创业板、科创板、北交所、ST

## 操作流程
1. 14:30运行脚本，查看候选列表
2. 人工结合大盘氛围筛选
3. 尾盘14:50~14:55买入
4. 次日冲高3~5%卖出
5. 止损：成本-5%

## 使用方式
```bash
cd /workspace && python3 scripts/chenxiaoqun_rebound.py
```

## 数据源
- 腾讯行情（主）：qt.gtimg.cn
- 新浪行情（备）：hq.sinajs.cn
- 东方财富（专线备）：push2.eastmoney.com

## 注意事项
- 本工具仅供参考，不构成投资建议
- 选股后需结合大盘氛围判断
- 止损纪律必须执行
