# SiNSE 温度验证报告 版式规范

> 本规范来自对原始 15 页 PDF 的复刻要求：除数据变化外，版式、模块、字体、颜色、页眉页脚保持一致；原件没有的模块一律不加。

## 1. 页面基础

- 纸张：A4 横向（PDF 用 landscape(A4)，HTML 用 `297mm × 210mm` 固定页）。
- 页边距：左右 12mm，上 18mm，下 12mm。
- 字体：微软雅黑（PDF 注册 `msyh.ttc` / `msyhbd.ttc`，HTML 用 `"Microsoft YaHei"`）。
- 灰底：统一 `#E7E6E6`（RGB ≈ 231/230/230）。
- 表格边框：0.5pt/1px 灰色实线。

## 2. 页眉（每页）

从左到右：

```
SiNSE        验证报告        [验证对象]        [编号]        [装载类型]                      页码：x / y
```

- 字号 9pt，黑色。
- 下方一条灰色分隔线。

## 3. 页脚

仅首页（P1）底部有签字行：

```
验证人： [空白]  签字日期： [空白]  审核人： [空白]  签字日期： [空白]
```

- 8 列结构，标签列灰底，空白列白底。

## 4. 模块详情

### P1 验证报告首页

1. **标题条**：灰底黑字，居中，14pt，「验证报告」。
2. **8 列信息表**：行标签灰底，值白底，按以下字段排列：
   - 装载类型 / 公司名称
   - 验证报告编号
   - 校准报告编号
   - 验证对象 / 型号 / 编号 / 备注
   - 验证仪器 / 型号 / 编号 / 简称
   - SOP / 扫描间隔(秒) / 记录间隔(秒)
   - 探头数量 / 压力探头 / 验证类型
   - 工艺时间段（标:上:下） / 压力要求 / 时长要求(分钟)
3. **注释条**：灰底，「注释：」。
4. **结论一：工艺时间段**：左侧灰底竖条 + 右侧白底正文。
   - 包含工艺要求、实际时长判定、温度范围、最冷/最热点、整体均匀度、同刻均匀性、单探头波动度。
5. **底部签字行**（同页脚）。

### P2 探头定义

- 标题条「探头定义」。
- 副标题条 `INFO["简称"]`。
- 2 列表：通道、标签。
- 通道名格式：`{简称}_{序号:02d}`；标签格式：`T1, T2, ...`。

### P3 布点图

- 标题「布点图」，居中。
- 灭菌柜腔体矩形示意图，内部标注 T1/T2/... 探头位置。

### P4 温度阶段统计

- 标题「温度阶段统计 工艺时间段:开始~~结束」，居中 12pt 加粗。
- 一个表格包含：
  - 表头行：探头 / J01_01 / J01_02 / ...
  - 数据行：最小值、最大值、大减小、平均值、平减标
  - 5 组排序行（每组 2 行）：
    - 灰底标签行（整行合并）：如「每个探头的最小值排序(由小到大):」
    - 白底表达式行（整行合并）：如 `(J01_01=121.20℃)<(J01_02=121.20℃)<(...)`

### P5 同一时刻的温度均匀性

- 一个大表格：
  - 表头跨列：同一时刻的温度均匀性：
  - 跨列公式行：Max(最大-最小)、Max(最大-平均)、Max(平均-最小)，后附发生时间。
  - 6 列数据行：全均℃、最大均-全均℃、全均-最小均℃。

### P6 温度数据

- 标题「温度数据」。
- 明细表：时间 / J01_01 / J01_02 / ...，每行一条原始记录。

### P7 签字页

- 验证人 / 签字日期 / 审核人 / 签字日期 8 列签字行。

## 5. 禁止添加的内容

- 判定规则说明表。
- 判定算法文字解释。
- 页眉页脚以外的装饰性元素。
- 未在原 PDF 中出现的统计指标或图表。

## 6. 输出文件命名

- PDF：`温度验证报告_{YYYYMMDD}.pdf`
- HTML：`温度验证报告_{YYYYMMDD}.html`
