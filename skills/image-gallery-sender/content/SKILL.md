# Image Gallery Sender - 图片集发送技能

批量发图时，将多张图片打包成一个精美的在线画廊，一句话生成链接发给用户微信。

## 技能简介（发布到技能市场的描述）

> **批量发图神器**：将任意数量图片自动打包成在线画廊，发送一条链接即可，用户点击即看，长按即存。完美解决微信批量发图被拦截的痛点，支持自动降级逐张发送。

## 核心优势
- ✅ 一条链接包含所有图片，用户自行保存
- ✅ 绕过微信批量发图限制（超过5张必被拦截）
- ✅ 支持任意数量图片
- ✅ 画廊发不出去时自动改为逐张间隔发送

## 触发场景
- 用户说"把xxx图片发给我" + 图片≥3张
- 用户说"批量发图" / "发图集" / "生成图集"
- 用户提供了多张图片路径并要求发送

## 使用示例

**示例1（批量发送画廊链接）：**
> "把 /workspace/xiaohongshu/ 01~10 号图片生成图集发给我"

**示例2（指定图片发画廊）：**
> "发送 image1.png、image2.png、image3.png 这三张图的图集链接"

**示例3（直接逐张发送）：**
> "把 image1.png 和 image2.png 直接发给我"

## 技术流程
1. 接收图片路径列表（绝对路径）
2. 生成精美HTML画廊（深色主题，网格布局）
3. 部署为公开网页
4. 发送链接到用户微信
5. 若部署失败 → 自动降级为逐张间隔发送

## 依赖
- `message` 工具（OpenClaw）— 用于发送微信消息
- `deploy` 工具（OpenClaw）— 用于部署画廊网页
- Python 3 — 用于生成HTML画廊文件

## 参数
| 参数 | 说明 | 默认值 |
|------|------|--------|
| --title | 相册标题 | 图片集 |
| --desc | 描述 | 长按图片即可保存 |
| --name | 部署项目名 | gallery-{时间戳} |
| --no-gallery | 跳过画廊，直接逐张发送 | false |
