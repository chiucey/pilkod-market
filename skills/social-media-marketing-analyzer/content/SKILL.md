# 社交媒体营销分析与策略制定

## 工作流程

### 步骤 1：收集产品/服务信息

向用户收集以下信息：
- 产品/服务名称和核心卖点
- 目标市场或行业
- 竞争对手信息（可选）
- 希望重点分析的平台（小红书/抖音/其他）

**如信息不完整，使用确认表单收集：**

```xml
<genui-form-wizard title="社交媒体营销分析" action-id="product_info">
<genui-form-page title="步骤1：产品/服务信息">
<genui-input name="productName" placeholder="请输入产品/服务名称"></genui-input>
<genui-input selection-mode="checkbox" name="platforms" placeholder="请选择分析平台（可多选）"></genui-input>
</genui-form-page>
<genui-form-page title="步骤2：补充信息（可选）">
<genui-input name="targetMarket" placeholder="目标市场或行业（可选）"></genui-input>
<genui-input name="competitors" placeholder="主要竞争对手（可选）"></genui-input>
</genui-form-page>
</genui-form-wizard>
```

### 步骤 2：社交媒体数据抓取

使用 `batch_web_search` 和 `extract_content_from_websites` 工具进行多维度数据采集：

**热度分析维度：**
- 搜索产品/服务相关关键词的热度趋势
- 收集帖子/视频的点赞、评论、转发数据
- 分析话题标签使用频率

**内容分析维度：**
- 抓取热门帖子/视频的标题、内容和标签
- 分析内容形式（图文、短视频、直播等）
- 识别高互动内容的共同特征

**人群分析维度：**
- 分析评论者和观看者的画像特征
- 识别主要讨论群体（年龄、兴趣、职业等）
- 发现潜在目标客户群体

**方式分析维度：**
- 识别成功的推广方式和内容形式
- 分析KOL/KOC合作效果
- 总结平台特有的内容玩法

### 步骤 3：数据分析与客户细分

基于抓取的数据进行结构化分析：

**目标客户细分框架：**
1. **人口统计特征**：年龄、性别、地域分布
2. **行为特征**：购买频次、互动偏好、内容消费习惯
3. **需求特征**：核心痛点、搜索意图、使用场景
4. **价值分层**：潜在客户、高价值客户、忠诚客户

### 步骤 4：营销策略制定

基于分析结果，制定以下策略：

**内容策略：**
- 推荐的内容形式和风格
- 关键词和话题标签建议
- 内容发布频率和时间

**渠道策略：**
- 平台选择和权重分配
- KOL/KOC合作建议
- 付费推广预算分配

**目标人群策略：**
- 核心目标人群定位
- 拓展人群方向
- 个性化触达方案

## 输出格式

生成结构化的分析报告：

```
# 社交媒体营销分析报告

## 1. 热度分析
[热度数据概览、趋势分析]

## 2. 内容分析
[热门内容特征、内容形式建议]

## 3. 人群分析
[目标客户画像、细分人群描述]

## 4. 方式分析
[成功推广方式、内容玩法总结]

## 5. 目标客户细分
[客户细分矩阵、各细分群体特征]

## 6. 营销策略建议
### 6.1 内容策略
### 6.2 渠道策略
### 6.3 人群策略

## 7. 执行建议
[具体可落地的行动项]
```

## 注意事项

- 数据来源应标注平台和时间
- 分析应基于真实抓取数据，避免主观臆断
- 策略建议应具有可操作性
- 如遇到平台访问限制，及时调整搜索策略
