### VBA 宏
```vba
Sub 一键排版()
    ' 全选文档
    ActiveDocument.Select

    ' 设置正文字体
    With Selection.Font
        .Name = "宋体"
        .Size = 12
    End With

    ' 设置行距
    Selection.ParagraphFormat.LineSpacing = 28

    ' 清除格式后应用正文样式
    Selection.ClearFormatting
    Selection.Style = ActiveDocument.Styles("正文")
End Sub
```

### Python-docx
```python
from docx import Document
from docx.shared import Pt, Cm
from docx.enum.text import WD_ALIGN_PARAGRAPH

doc = Document()
# 设置页边距
for section in doc.sections:
    section.top_margin = Cm(3.7)
    section.bottom_margin = Cm(3.5)
    section.left_margin = Cm(2.8)
    section.right_margin = Cm(2.6)
```

### 2. 方案匹配

根据需求复杂度选择方案：

#### 简单排版（1-5分钟）
**方案：键盘快捷键 + 格式刷**
```
步骤1：全选内容（Ctrl+A）
步骤2：设置正文字体（Ctrl+D → 选择字体）
步骤3：清除格式（Ctrl+Space）
步骤4：应用样式（Alt+H+L+N → 选择样式）
步骤5：格式刷统一（选中样本 → 双击格式刷 → 刷其他）
```

#### 中等排版（5-15分钟）
**方案：样式定义 + 批量应用**
```
步骤1：创建样式（视图 → 样式窗格 → 新建样式）
步骤2：定义标题1样式（字体、字号、行距、段落）
步骤3：定义标题2/3样式（层级关系）
步骤4：批量应用（Ctrl+H → 高级替换）
步骤5：插入目录（引用 → 目录）
```

#### 批量生成（15-60分钟）
**方案：VBA 宏 / Python-docx**
```
步骤1：准备数据源（Excel 表格）
步骤2：编写宏代码（邮件合并逻辑）
步骤3：运行测试（生成5份测试文档）
步骤4：批量执行（生成全部1000份）
步骤5：格式检查（抽查文档排版）
```

### 3. 执行与交付

#### 代码方案交付
```vba
' ================== 使用说明 ==================
' 1. 按 Alt+F11 打开 VBA 编辑器
' 2. 插入 → 模块
' 3. 粘贴以下代码
' 4. 关闭编辑器
' 5. 按 Alt+F8，选择"一键排版"运行
' ================== 代码开始 ==================

Sub 一键排版()
    Dim para As Paragraph
    For Each para In ActiveDocument.Paragraphs
        ' 检测标题关键词
        If Left(para.Range.Text, 2) = "第" And Right(Left(para.Range.Text, 4), 1) = "章" Then
            para.Style = ActiveDocument.Styles("标题 1")
        End If
    Next
    ' 生成目录
    ActiveDocument.TablesOfContents.Add Range:= _
        ActiveDocument.Paragraphs(1).Range
End Sub
```

#### 手动方案交付
```
分步操作指南：

步骤1：设置页边距
- 点击「布局」选项卡
- 点击「页边距」→「自定义边距」
- 设置：上3.7cm，下3.5cm，左2.8cm，右2.6cm
- 点击「确定」

步骤2：创建样式
- 点击「样式」窗格（视图 → 勾选「样式窗格」）
- 点击「新建样式」
- 命名：标题1
- 字体：黑体，小三
- 段落：居中，段前0.5行，段后0.5行

步骤3：批量应用样式
- 按 Ctrl+H 打开查找替换
- 高级选项 → 勾选「使用通配符」
- 查找内容：^13[一二三四五六]
- 替换为：[留空]
- 点击「更多」→「格式」→「样式」→ 选择「标题1」
- 点击「全部替换」
```
