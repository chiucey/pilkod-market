# 全学科标准化教案生成工具

## 技能概述

本技能通过引导用户完善备课信息，按固定六步流程生成结构完整、格式规范且适配各学科课程标准的教案文档。

## 触发条件

- 用户要求生成教案文档
- 用户需要各学科标准教案模板
- 用户要求创建备课文档或教学设计方案
- 用户请求生成课件大纲或课程计划

## 工作流程

### 步骤 1：收集备课信息

使用 GenUI 表单向用户收集以下核心信息：

| 字段 | 说明 | 必填 |
|------|------|------|
| 学科 | 语文/数学/英语/物理/化学/历史/地理/生物/政治/音乐/美术/体育等 | 是 |
| 学段/年级 | 小学/初中/高中 + 具体年级 | 是 |
| 课题名称 | 具体的课程章节或课时名称 | 是 |
| 课时安排 | 第几课时（如：第1课时） | 是 |
| 教学时长 | 标准时长（分钟），默认45分钟 | 否 |

**学科差异化说明：**
- 语文：侧重语言理解、阅读鉴赏、写作训练
- 数学：侧重概念理解、例题讲解、练习巩固
- 英语：侧重词汇语法、阅读理解、口语表达
- 物理/化学：侧重实验探究、原理讲解、计算应用
- 历史/政治：侧重史实记忆、观点分析、材料解读
- 音体美：侧重技能训练、作品创作、实践体验

### 步骤 2：生成课前部分

基于学科特点和学情，构建以下内容：

```markdown
### ✨ 教材分析
[基于学科特点的教材内容分析]

### 👥 学情分析
[目标学生群体的认知特点和已有知识基础]

### 🎯 教学目标
- **知识与技能：** [具体知识点和技能要求]
- **过程与方法：** [学习过程和采用的方法]
- **情感态度与价值观：** [情感教育和价值引导]

### ⭐ 教学重难点
- **重点：** [核心知识点]
- **难点：** [学生不易理解的内容]
- **突破策略：** [具体教学方法]

### 🛠️ 教学方法
[根据学科特点选择：讲授法/讨论法/探究法/演示法/实验法等]

### 📦 教学准备
- 教师准备：[教师所需教具、课件等]
- 学生准备：[学生预习内容、前置知识等]
```

### 步骤 3：生成课中部分

设计符合教学逻辑的课堂实施流程：

```markdown
### 🚀 导入新课（X分钟）
[具体导入方式：故事/问题/情境/复习等]

### 📖 新课讲授（X分钟）
[分步骤详细讲解，体现教学逻辑]

### 📝 课堂小结（X分钟）
[知识梳理和重点回顾]

### ✍️ 课堂练习（X分钟）
[随堂巩固题目]
```

### 步骤 4：生成课后部分

规划课后巩固与拓展任务：

```markdown
### 📚 作业布置
- **基础题：** [巩固性题目 2-3道]
- **拓展题：** [提升性题目 1-2道]

### 🌟 拓展延伸
[相关知识链接、兴趣探索方向]

### 🎯 实践活动
[动手实践、探究活动或项目学习任务]
```

### 步骤 5：生成课后评价

提供教学反思方向：

```markdown
### 💭 教学反思
- **教学效果评估：** [预期达成情况]
- **改进方向：** [可能的调整措施]
- **关注点：** [学困生辅导、分层教学等]
```

### 步骤 6：输出完整教案

将所有内容整合为规范的 Markdown 文档：

```markdown
# 【学科】第X课时：《课题名称》教学设计

| 项目 | 内容 |
|------|------|
| 学科 | XXX |
| 年级/学段 | XXX |
| 课题 | XXX |
| 课时 | 第X课时 |
| 时长 | XX分钟 |

---（各模块内容）---
```

文件输出路径：`./user-data/lesson-plans/[学科]_[课题]_[日期].md`

### 排版规范

## 学科适配说明

### 语文科目

- 增加阅读鉴赏、写作训练环节
- 重视文本解读和语言品味
- 融入中华优秀传统文化元素

### 数学科目

- 强调概念形成和定理推导
- 注重例题示范和变式训练
- 培养数学思想和逻辑推理能力

### 英语科目

- 融入听说读写技能训练
- 重视语境理解和交际能力
- 增加跨文化交际意识培养

### 理科科目（物理/化学/生物）

- 增加实验探究环节设计
- 注重原理讲解和科学方法
- 培养观察、假设、验证的科学思维

### 文科科目（历史/地理/政治）

- 强调史料分析和观点论证
- 融入时政热点和生活实例
- 培养家国情怀和社会责任感

### 艺体科目（音乐/美术/体育）

- 突出技能训练和实践体验
- 重视作品创作和展示评价
- 培养审美能力和健康意识

## 质量检查清单

生成教案后，自检以下要点：

- [ ] 备课信息完整（学科、年级、课题、课时）
- [ ] 教学目标符合学科核心素养要求
- [ ] 教学重难点突出，突破策略可行
- [ ] 课中流程逻辑清晰，时间分配合理
- [ ] 作业布置体现分层（基础+拓展）
- [ ] 格式规范，emoji 使用准确
- [ ] 内容符合对应学段和学科特点
