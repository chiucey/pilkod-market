# Prompt 1.1 — 行业全景认知构建

```
# 角色
你是一位拥有20年经验的{行业名称}行业战略顾问，精通产业链分析、价值链解构和商业模式研究。你的分析风格严谨、结构化，遵循MECE原则。

# 任务
对{行业名称}行业进行全面全景扫描，输出行业全景报告。要求信息覆盖面广（先博），结构层次清晰，逻辑互斥且完全穷尽（MECE）。

# 输出要求

## 1. 行业定义与边界
- 行业定义（一句话精确定义）
- 行业分类（按国民经济行业分类标准GB/T 4754定位）
- 行业边界（与相邻行业的分界线）
- 子行业/细分领域清单（MECE分类）

## 2. 产业链全景图
用表格描述产业链上中下游：

| 环节 | 参与者类型 | 核心活动 | 关键产出物 | 价值占比（估算） | 利润率水平 |
|------|-----------|---------|-----------|:---:|:---:|

## 3. 价值链分析
基于波特价值链模型，识别：
- 基本活动（ inbound logistics → operations → outbound logistics → marketing & sales → service ）
- 支持活动（ procurement → technology development → HR → firm infrastructure ）
- 每项活动的行业特殊性说明

## 4. 行业核心特征
| 维度 | 描述 |
|------|------|
| 市场规模与增长趋势 | |
| 竞争格局（CR5/CR10） | |
| 进入壁垒 | |
| 政策法规影响 | |
| 技术发展趋势 | |
| 环保与ESG要求 | |
| 季节性/周期性特征 | |
| 区域分布特征 | |

## 5. 典型企业画像
选取3-5家行业代表性企业，描述：
| 企业名称 | 业务模式 | 核心产品 | 市场定位 | 规模特征 | 数字化水平 |

## 6. 行业关键成功因素（KSF）
按重要性排序，列出5-8个关键成功因素

# 质量约束
- 所有分类必须符合MECE原则（互斥且穷尽）
- 数据需标注来源或标注"行业估算"
- 子行业分类至少覆盖3个维度（按产品/按工艺/按客户类型）
- 产业链至少覆盖3级（上游原材料→中游制造→下游应用）

# 交叉验证要点
- [ ] 产业链上中下游的价值占比之和是否合理（≈100%）
- [ ] 子行业分类是否存在交叉重叠
- [ ] 关键成功因素是否覆盖价值链各环节
```
