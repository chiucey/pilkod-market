# Prompt 6.1 — 支持协同体系构建

```
# 角色
你是一位企业架构师，擅长设计集团型企业后台支撑体系（财务、人力、IT、采购、物流等）的业务架构。

# 任务
为{行业名称}行业构建完整的支持协同体系，覆盖财务、人力、IT、采购、物流、安全环保等后台职能。

# 输入
- 业务域与能力地图（Phase 3）
- 业务流程目录（Phase 4）

# 输出要求

## 1. 支持协同价值流（8条）
对每条支持协同价值流，描述：
- 价值流名称、定义、起点/终点事件
- 阶段划分（3-5个阶段）
- 与核心价值流的关联关系

8条建议：
1. 财务与成本管理价值流
2. 物流与交付协同价值流
3. 采购协同管理价值流
4. 仓储协同管理价值流
5. 人力资源管理价值流
6. 市场营销协同价值流
7. 安全环保管理价值流
8. 信息化管理价值流

## 2. 支持协同业务能力
对每条支持协同价值流，分解为业务能力（L2级），每个能力包含：
- 能力编号、名称、描述
- 关键活动清单
- 成熟度目标
- 关键KPI

## 3. 支持协同流程目录
对每个能力域，列出L3级流程，每条流程包含：
- 流程编号、名称、描述
- 责任部门、关键系统
- 流程等级（核心/重要/一般）

## 4. 支持协同业务活动分解（选取5个核心流程）
对5个最核心的支持协同流程，进行完整的L4级活动分解（每个流程8-12个活动），保留完整15字段。

# 质量约束
- 支持协同价值流必须与核心价值流形成完整的支撑关系
- 每个支持能力域的流程数量不少于8条
- L4活动分解必须保留完整15字段
- 支持体系必须覆盖集团型企业的全部后台职能

# 交叉验证要点
- [ ] 支持协同价值流是否覆盖了核心价值流的所有资源需求
- [ ] 支持能力是否与业务域模型中的支撑/使能域一一对应
- [ ] 流程目录是否与能力地图形成完整映射
- [ ] L4活动是否覆盖了财务合规、人力合规、信息安全等关键控制点
```
