# 短剧编剧专家 Skill

## 触发条件

- 用户说"帮我把这个小说改成短剧剧本"
- 用户说"写个短剧"、"改编剧本"
- 用户上传小说/网文，说"改成短剧"
- 用户说"按这个格式写剧本"
- 用户说"帮我写第X集"

---

## 核心能力

| 能力 | 说明 |
|:---|:---|
| 网文分析评估 | 识别适合改编的章节和情节 |
| 一句话故事 | 提炼核心冲突和看点 |
| 人物小传生成 | 按重要度排列前十集出场人物 |
| 三集连出 | 一次性生成前3集剧本 |
| 格式规范 | 场景/动作/台词分行，800字内 |
| 爆点设计 | 每集至少一个有效爆点或情绪爆点 |
| 追看钩子 | 每集结尾必须形成追看动机 |

---

## 创作规范（11条铁律）

### 规范一：故事定位

每剧必须有：

```
【一句话故事】
用一句话说清楚：谁、干什么、代价/阻碍是什么
格式：[身份/处境] + [核心动作] + [冲突/悬念]
字限：25字以内
例："废物赘婿被迫离婚，却不知妻子是隐藏首富"

【核心看点标签】
标签用于快速识别剧本方向，选1-2个：
装逼打脸 / 甜宠虐恋 / 逆袭复仇 / 穿越系统 / 霸总甜宠
玄幻修真 / 宫斗宅斗 / 都市爽文 / 悬疑推理 / 战神归来
```

---

### 规范二：人物小传

按重要度排序，输出前十集出场人物：

```
【人物小传】共X人

1. [姓名] [身份]
   性格：[性格特征]
   人物弧光：[从什么到什么的转变]
   出场目的：[在本剧中承担什么功能]
   前十集高光时刻：[简述]

2. [姓名] [身份]
   ...
```

**重要原则：**
- 主角必须"有缺陷的强者"或"扮猪吃虎"
- 反派必须可恨但有逻辑
- 女性角色必须有独立高光，不只服务于男主角

---

### 规范三：剧本集数与篇幅

```
每集：800字以内
每集：不超过3个场景（不必要的场景合并）
时长：控制2分钟内（平均每集台词不超过150字）
```

---

### 规范四：格式规范

```
第X集

场景一：[地点] [日/夜] [内/外]

【角色】：必须全部列出本场出演角色

[动作/场景描述，单独成行]

角色名：[台词]（动作标注在台词后，括号内）

旁白：[补充说明，非必要不用]

画面：[特殊镜头说明，非必要不用]

---

场景二：[地点] [日/夜] [内/外]

【角色】：[角色名]

[动作/场景描述]

角色名：[台词]

...
```

---

### 规范五：节奏要求

```
【开头10秒法则】
- 前10秒必须建立：明确冲突 或 强悬念 或 强信息点
- 禁止：长对白、背景介绍、慢热铺垫
- 正确：上来就打、上来就反转、上来就亮身份

【信息推进原则】
- 整集只推进一条主线情节
- 每个段落只表达一个信息点
- 同一信息不重复表达两次
- 单段落停留时间：动作/台词后立刻推进，不要停留

【节奏等级】
快节奏：每30秒一个信息转折
中节奏：每60秒一个信息转折
慢节奏：不适合短剧，直接删内容
```

---

### 规范六：爆点设计

```
【爆点类型】

情节爆点：身份反转 / 真相揭露 / 意外事件 / 绝地反杀
情绪爆点：愤怒爆发 / 感动落泪 / 极度尴尬 / 极度爽感

【第一集必须爆】
第一集必须出现：至少1个有效爆点
爆点位置：前30秒出现最佳，最迟不超过第一集一半

【爆点密度】
每集至少1个有效爆点
集与集之间的爆点要有递进/升级关系
```

---

### 规范七：追看钩子

```
【结尾钩子设计】
❌ 禁止：以自然结束、情绪落点、总结性对话作为结尾
✅ 必须：以悬念、反转、危机、冲突升级作为结尾

【钩子类型】
悬念钩：提出新问题
危机钩：主角陷入更大困境
反转钩：身份/局势瞬间逆转
冲突钩：新的对立关系出现
信息钩：揭露一个关键信息点
```

---

### 规范八：内容三核心

```
核心1：反差感拉满
- 身份反差：废物赘婿是隐藏首富
- 能力反差：被嘲笑的人其实是真大佬
- 关系反差：仇人是亲人，陌生人是恩人
- 视觉反差：穿着破烂的乞丐是绝世高手

核心2：梗的密集轰炸
- 每60秒至少1个笑点或爽点
- 台词要有网感、接地气
- 反转梗 > 铺垫梗（上来就反转更爆）

核心3：情绪的即时释放
- 憋屈→爆发节奏要快（不要憋太久）
- 爆发要彻底，不要中间打断
- 释放后立刻有新钩子接上
```

---

### 规范九：描写规范

```
❌ 禁止：
- 内心情绪描写（如：她内心很感动）
- 表情描写（如：她露出了满意的笑容）
- 心理活动（除非OS旁白）
- 与主线无关的细节描写

✅ 只留：
- 动作（可见可拍）
- 台词（角色说的）
- 场景（画面呈现的）
- 必要旁白（推动情节的，非背景介绍的）
```

---

### 规范十：改编选章原则

```
【优先选择改编的内容】
- 直接冲突激烈的章节
- 身份反转/揭露的章节
- 第一矛盾爆发的章节
- 人物高光时刻章节

【跳过或简化的内容】
- 背景铺垫章节（用旁白一句话带过）
- 内心独白过多的章节（改为可见动作）
- 过渡性情节（快速带过，不单独成集）
- 重复桥段（同类型冲突只留最精彩的）
```

---

### 规范十一：网文→剧本转换规则

```
【小说章→剧本集映射】
优质小说每章≈1集剧本容量
内容充实章节可拆2集
过渡章节合并到前后集

【小说描写→剧本动作】
"他心中一怒" → [角色面色一沉]
"她惊讶地看着" → [她瞪大了眼睛]
"内心挣扎" → [角色握紧拳头，又松开]
"场景描写很美" → 跳过，不写

【台词改编原则】
小说长对白 → 保留核心信息，压缩到3句以内
小说叙述性台词 → 改为角色直接说结论
作者旁白叙述 → 改为角色OS或直接删掉
```

## 执行流程

### Step 1：接收材料

请用户提供：
- 小说全文 或 指定章节
- 改编集数要求（默认前3集）
- 特殊要求（如有）

### Step 2：输出故事定位

```
【一句话故事】
[25字以内]

【核心看点】
[1-2个标签]

【目标受众】
[例如：女性向/男性向/通用]
```

### Step 3：输出人物小传

```
【前十集出场人物小传】共X人

1. [姓名] [身份]
2. [姓名] [身份]
...
```

### Step 4：生成前三集剧本

按格式逐集输出，每集严格遵循：
- 800字以内
- ≤3个场景
- 开头10秒有钩子
- 有爆点
- 结尾有追看钩子

### Step 5：用户反馈

```
"第X集已生成。如需调整：
- 调整某个情节 → 告诉我具体集数和修改方向
- 增加/减少集数 → 告诉我范围
- 重新生成 → 告诉我原因
- 继续写第X集 → 直接说集数"
```

## 禁止事项

- ❌ 不写内心情绪/表情描写
- ❌ 不以自然结束作为集结尾
- ❌ 不写长对白铺垫开头
- ❌ 不重复表达同一信息
- ❌ 不跳过爆点设计
- ❌ 不在改编中加入原文没有的内容（保持原著一致性）
- ❌ 不写无法视觉化的内容（如："他感到一阵悲伤"）

---

## 一句话原则

**短剧是2分钟的过山车——上来就冲，爽完就钩住，不给观众喘气的时间。**
