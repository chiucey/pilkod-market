# 专业科普知识写作

将复杂的专业知识转化为通俗易懂、生动有趣的文章。

## 核心原则

### 1. 准确为本
- 事实准确，数据可靠
- 引用权威来源
- 区分已确认事实与假说/争议

### 2. 通俗易懂
- 用类比解释抽象概念
- 化繁为简，降低理解门槛
- 避免不必要的专业术语
- 必须使用的术语需提供解释

### 3. 生动有趣
- 善用故事、案例、场景
- 制造悬念和好奇心
- 语言流畅，节奏感强
- 适当幽默，但不失严谨

## 写作流程

### 第一步：受众分析
明确文章面向的读者群体：
- **大众读者**：无需背景知识，侧重趣味性和实用性
- **学生群体**：兼顾知识性与教育意义
- **专业人士**：可在部分章节深入探讨

### 第二步：主题聚焦
- 确定核心信息（1-3个关键点）
- 梳理知识结构，确定讲解顺序
- 设计吸引读者的切入点

### 第三步：结构设计

**推荐结构：**

```
1. 悬念导入（吸引注意力）
   └─ 提出有趣问题/现象/故事

2. 核心概念讲解
   └─ 从已知到未知，循序渐进

3. 原理/机制阐释
   └─ 结合案例和类比说明

4. 应用与意义
   └─ 联系实际，体现价值

5. 总结升华
   └─ 回顾要点，留下思考
```

### 第四步：内容撰写

**开头技巧：**
- 抛出问题引发思考
- 讲述生活中的现象
- 引用惊人数据或事实
- 讲述相关历史故事

**正文技巧：**
- 每段一个核心观点
- 段首亮出结论
- 善用"比如"、"打个比方"等引导词
- 控制段落长度（3-5句为佳）

**结尾技巧：**
- 呼应开头，形成闭环
- 展望未来，激发兴趣
- 提炼金句，加深印象

## 语言规范

### 推荐句式
- 主动句优先
- 短句为主，长短交错
- 具体名词替代抽象概念
- 动词具体有力

### 禁用/慎用
- 空洞的套话
- 未经核实的绝对化表述
- 过度渲染或夸大
- 生造词汇或谐音梗

## 专业术语处理

| 场景 | 处理方式 |
|------|----------|
| 高频核心术语 | 首次出现时加括号注英文原词 |
| 专业术语 | 提供通俗解释或类比 |
| 数据/公式 | 转化为可视化或生活类比 |
| 复杂机制 | 拆解为多步骤流程说明 |

## 质量检查清单

完成初稿后逐项核对：

- [ ] 核心信息是否清晰传达？
- [ ] 是否有足够的案例/类比辅助理解？
- [ ] 专业术语是否都有解释？
- [ ] 段落是否过长需要拆分？
- [ ] 开头是否足够吸引人？
- [ ] 结尾是否有力？
- [ ] 事实和数据是否核实？
- [ ] 是否有错别字或语病？

## 输出格式

请提供以下格式的科普文章：

```
【标题】
（副标题）

【开篇引导】
（吸引读者的开场，100-200字）

【正文内容】
（分3-5个章节，每章有小标题）

【总结升华】
（收尾段落，50-100字）

【写作说明】（可选）
（解释关键决策，如数据来源、类比逻辑等）
```

## 注意事项

1. **平衡深度与广度**：科普不是学术论文，但也不能过于浅薄
2. **保持科学精神**：承认未知和不确定性，避免绝对化
3. **本土化适配**：适当使用本土文化背景的类比
4. **时效性意识**：确保引用的数据和事实为最新
5. **版权意识**：引用他人内容需注明来源
