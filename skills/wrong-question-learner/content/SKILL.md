# 错题学习与分析技能

## 核心工作流程

### 阶段 1：接收与判断

当用户发送题目（图片/文字）+ "加入错题"时：

1. **检查是否有做题过程**
   - 有过程 → 进入阶段2（错误分析）
   - 无过程 → 进入阶段3（逻辑讲解）

### 阶段 2：错误分析（仅当有做题过程时执行）

1. **分析错误原因**
   - 识别计算错误、逻辑错误、概念混淆、步骤遗漏等
   - 标注错误位置和类型

2. **给出补救措施建议**（≤20字）
   - 简洁明了
   - 直接指出改进方向

3. **进入阶段3**：讲解底层逻辑

### 阶段 3：底层逻辑与思路讲解

1. **题目归类**
   - 判断题目类型（几何、代数、概率等）

2. **讲解核心知识点**
   - 一级公式/定理
   - 二级结论和推导
   - 关键解题思路

3. **规范解题步骤**
   - 完整、规范的解题流程

### 阶段 4：出相似题练习

1. **生成相似题**
   - 保留原题核心考点
   - 适当变化条件/数据/问法
   - 融入之前出现过的易错点（如果有）

2. **等待用户回应**

### 阶段 5：分流处理

**分支A - 用户要求"直接加入错题本"：**
- 将原题 + 相似题 + 所有分析内容写入错题本
- 若对话中未创建错题本，则新建 `/workspace/temp-skills/wrong-question-learner/wrong-notebook.json`
- 记录：题目、错误分析、补救建议、底层逻辑、公式二级结论、相似题、完整解题过程

**分支B - 用户给出解答过程：**
- 回到阶段2重新分析用户的新解答
- 在后续出题时融入之前遇到的问题
- 继续练习直到满足阶段6条件

### 阶段 6：总结与归档

**触发条件（满足其一）：**
- 出题数量达到3道
- 用户连续2-3道题几乎无错答对（错误包括步骤不严谨）

**总结内容：**
- 本次学习的知识点
- 常见错误类型回顾
- 核心公式/二级结论
- 学习建议

**执行阶段5的分支A**：将总结一并写入错题本

## 错题本格式

```json
{
  "wrong_questions": [
    {
      "id": "uuid",
      "original_question": "原题内容/图片路径",
      "user_solution": "用户的解题过程",
      "error_analysis": "错误分析",
      "remedy_suggestion": "补救建议（≤20字）",
      "core_logic": {
        "knowledge_type": "知识点分类",
        "level1_formula": "一级公式",
        "level2_conclusion": "二级结论",
        "solution_steps": ["步骤1", "步骤2"]
      },
      "similar_questions": [
        {
          "question": "相似题内容",
          "answer": "答案"
        }
      ],
      "learning_summary": "学习总结",
      "created_at": "时间戳"
    }
  ]
}
```

## 注意事项

1. **题目格式支持**：同时支持图片和文字形式的题目
2. **补救建议限制**：必须控制在20字以内
3. **步骤严谨性**：解题步骤不完整或不严谨也算错误
4. **易错点融入**：后续出题时要体现之前出现过的易错点
5. **错题本路径**：统一保存在 `/workspace/temp-skills/wrong-question-learner/wrong-notebook.json`
