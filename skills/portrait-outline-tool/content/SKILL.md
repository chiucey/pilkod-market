# 人像轮廓描绘工具

## 功能特性

- **智能人像识别**：自动检测图片中的人物区域
- **轮廓描绘**：使用曲线精确描绘头部和身体轮廓
- **参数调节**：
  - 线条粗细：1-20px 可调节
  - 线条颜色：多种预设颜色 + 自定义颜色
- **实时预览**：即时查看描绘效果
- **一键下载**：保存处理后的图片到本地

## 技术实现

### 核心算法
1. **人像分割**：使用 MediaPipe Selfie Segmentation 进行人像检测
2. **边缘检测**：采用 Canny 算法提取人像边界
3. **曲线拟合**：使用贝塞尔曲线平滑轮廓线条
4. **Canvas 渲染**：HTML5 Canvas 实现绘制和预览

### 依赖库
- MediaPipe Tasks Vision（人像分割）
- HTML5 Canvas API（图像处理）
- File API（文件上传下载）

## 使用流程

1. 上传图片（支持 JPG、PNG、WebP）
2. 系统自动识别人像区域
3. 调整线条粗细和颜色
4. 预览效果
5. 下载最终图片

## 输出格式

支持下载为 PNG 格式，保留透明背景（如有）
