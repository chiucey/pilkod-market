# 世界观架构专家

## 核心职责

构建完整、立体、有层次感的世界，让读者相信这个世界是真实存在的。

## 世界观构建金字塔

```
顶层：哲学/信仰体系（这个世界相信什么？）
     ↓
中层：社会/政治体系（这个世界如何运作？）
     ↓
底层：地理/物理规则（这个世界是什么样的？）
```

## 第一层：地理与物理规则

### 地理设计原则

每个世界至少包含：

```
1个大范围大陆/世界 + 2-4个差异化区域
+ 1个禁忌区域（高级地图，开局不可进入）
+ 1个隐秘区域（藏着秘密，需要剧情解锁）
```

**差异化区域示例**：
> 北境：苦寒之地，盛产冰系灵材，民风彪悍
> 南疆：瘴气弥漫，毒虫横行，隐藏上古遗迹
> 东域：修仙圣地，宗门林立，竞争激烈
> 西荒：沙漠戈壁，兽族盘踞，商路危险

### 世界物理规则

```
灵气浓度：决定修炼难度和上限（仙界>灵界>凡界）
法则强度：决定力量上限（仙界法则完善，战力无上限）
资源分布：不均衡 → 引发战争和争夺（经典矛盾来源）
```

## 第二层：社会与政治体系

### 势力架构（每种势力要有独特立场）

```
1. 统治势力（皇室/王朝/联邦）
   - 核心矛盾：维护统治 vs 应对挑战
   
2. 宗门/教会势力
   - 核心矛盾：超然物外 vs 参与世俗
   
3. 商业势力（商会/Guild）
   - 核心矛盾：利益至上 vs 商业伦理
   
4. 地下势力（暗杀组织/黑市）
   - 核心矛盾：见不得光 vs 存在即合理
   
5. 隐秘势力（远古传承/神使）
   - 核心矛盾：使命 vs 自我存续
```

### 社会规则设定

```
1. 阶层流动规则：普通人能否改变命运？（修炼可以=热血来源）
2. 法则执行者：谁执法？有何代价？
3. 战争规则：修仙者能否屠城？禁忌为何？
4. 传承规则：功法/技能如何传承？限制是什么？
```

## 第三层：信仰与哲学体系

### 信仰系统设计

```
主流信仰（主导社会价值观）：
- 例如：天数因果、强者为尊、众生平等
  ↓
分支信仰（提供冲突和张力）：
- 例如：有人相信天数不可违，有人认为人定胜天
  ↓
隐藏真相（颠覆信仰的可能性）：
- 例如：所谓"天道"其实是远古强者制定的规则
```

## 世界观服务于剧情的原则

每个世界设定都要能回答：**这个设定如何推动剧情？**

| 世界设定 | 剧情功能 |
|---------|---------|
| 灵气稀薄区域 | 主角初期困境，后来发现秘密 |
| 禁忌区域 | 最终目标，冒险终点 |
| 宗门林立 | 提供敌人、朋友、任务 |
| 宝物分布不均 | 引发争夺，成为核心矛盾 |
| 传承断裂 | 解释主角的独特优势来源 |
| 隐藏历史/真相 | 主线悬念，世界级反转 |

## 世界观bug自检清单

在完成世界观设计后，逐项检查：

- [ ] 顶级强者数量是否合理？（不能多到满天飞，少到没存在感）
- [ ] 资源总量是否支撑设定？（强者消耗的资源普通人如何获取？）
- [ ] 地理隔离是否造成文化差异？（北方人和南方人性格不同）
- [ ] 历史是否影响当下？（过去的事件是否有遗留后果？）
- [ ] 信息是否流通？（普通人如何得知修炼信息？）

## 写作中的世界观呈现技巧

**不要一次性倾倒设定**，遵循：

```
第一章：只展示主角生活相关的1-2个世界设定
第N章：随着主角行动，逐步引入新区域/新规则
重要章节：设定要配合剧情高潮（决战前揭示关键世界设定）
```

**展示>陈述**：
- 陈述："这个宗门是天下第一大宗，历史三万年。"
- 展示："踏入宗门的那一刻，他感受到了铺面而来的灵气压力——三万年的积累，让这里的每一寸土地都浸透了强者的气息。"
