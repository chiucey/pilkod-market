# 播客摘要整理

将用户发来的播客逐字稿，按照标准指令生成结构化 HTML 摘要，发布到公开网页，并推送微信通知。

## 工作流程

### Step 1：识别与读取
- 用户发来文件或链接 → 识别为播客逐字稿
- 读取文件完整内容（`.txt` 文件，直接当 TXT 处理，不转 MD）

### Step 2：生成摘要
- 参考 `references/播客处理指令.md` 进行内容提炼
- 参考 `references/文章页模板.html` 生成 HTML
- 文件命名规则：`播客标题.html`（去掉特殊字符，保留核心关键词）

### Step 3：更新索引页
- 读取现有 `index.html`
- 在顶部插入新的摘要卡片（时间倒序，最新在前）
- 卡片格式：
  - 标题 + 日期
  - 一句话摘要（核心主题）
  - 3-5个要点列表
  - "点击阅读全文 →" 链接

### Step 4：部署
- 用 `deploy` 工具部署 `dist_dir=/workspace/podcast-archive`
- 获取返回的 public URL

### Step 5：推送微信
- 用 `message` 工具发送链接到用户微信：
  - `channel=openclaw-weixin`
  - `accountId=403adf54f8b9-im-bot`
  - 消息格式：`🎙️ 播客摘要已更新 👇\n\n👉 {url}\n\n{文章标题}\n{一句话摘要}\n共 {N} 篇，点击上方链接查看全部。`

## 设计规范（已在模板中固化）

| 元素 | 规范 |
|------|------|
| 背景色 | #f5f5f5（浅灰） |
| 正文文字 | #333，15px |
| 主标题 | #1a1a1a，22px，加粗 |
| 章节标题 | 白底黑字，18px，加粗 |
| 三级标题 | 金色 #c89a00，15px，加粗 |
| 要点符号 | 金色 #c89a00 圆点 |
| 卡片背景 | #ffffff，圆角12px |
| 引用块 | #f0f0f0，左边框4px金色 |

## 关键约束

- **纯 TXT 处理**：不将 txt 文件转为 md 处理，直接读取内容
- **不遗漏案例**：每个案例必须包含背景/主体/情节/证据/结果/关联
- **不删细节**：宁可详细，不可遗漏
- **无来源痕迹**：正文不出现任何引用标记或"根据xxx"字样
- **先更新记忆**：每次处理完成后，将新文章标题+URL 追加到 MEMORY.md 的「播客摘要库」章节
