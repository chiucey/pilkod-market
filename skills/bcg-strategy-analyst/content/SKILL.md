# BCG 战略分析专家

您身边的波士顿咨询集团战略顾问，让复杂的战略分析变得简单直观。

## 核心能力

### 📊 BCG 矩阵分析

**纵轴**：市场增长率（高/低）
**横轴**：相对市场份额（高/低）

| 象限 | 特征 | 策略 |
|------|------|------|
| ⭐ 明星业务 | 高增长 + 高份额 | 投资扩张，争取更大份额 |
| 💰 现金牛 | 低增长 + 高份额 | 榨取利润，输出现金流 |
| ❓ 问题业务 | 高增长 + 低份额 | 选择性投资，择优培养 |
| 🐕 瘦狗业务 | 低增长 + 低份额 | 收割或放弃 |

### 🔍 战略分析框架

**SWOT 分析**
- 优势（Strengths）
- 劣势（Weaknesses）
- 机会（Opportunities）
- 威胁（Threats）

**波特五力模型**
1. 现有竞争激烈程度
2. 新进入者威胁
3. 替代品威胁
4. 供应商议价能力
5. 买家议价能力

**价值链分析**
研发 → 采购 → 生产 → 营销 → 销售 → 服务

### 📈 增长战略模型

**SBU 战略**：战略业务单元规划

**三条增长曲线**
- 第一曲线：核心成熟业务（守护现金流）
- 第二曲线：新锐增长业务（战略投入）
- 第三曲线：未来布局业务（种子投资）

**四大增长路径**
1. 渗透：抢市场
2. 延伸：拓品类
3. 合作：找盟友
4. 全球化：走出去

### ⚔️ 竞争战略选择

| 战略类型 | 核心逻辑 | 关键成功因素 |
|----------|----------|--------------|
| 成本领先 | 规模效应 + 成本优化 | 效率提升 |
| 差异化 | 产品/服务/品牌差异化 | 创新与独特价值 |
| 集中化 | 聚焦特定细分市场 | 深耕细分领域 |
| 蓝海战略 | 创造新市场空间 | 规避正面竞争 |

### 📋 客户战略分析

- **客户分层**：核心客户 / 战略客户 / 机会客户
- **LTV 计算**：客单价 × 购买频次 × 生命周期
- **CAC 计算**：营销费用 / 新增客户数
