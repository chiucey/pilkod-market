# 润色提示词技能

将任意自然语言描述转化为专业 AI Agent Prompt。

## 核心原则

**角色设定（Role）** → 告诉 AI"你是谁"
**任务目标（Task）** → 告诉 AI"要做什么"
**约束条件（Constraint）** → 告诉 AI"注意什么"
**输出格式（Output）** → 告诉 AI"怎么回答"

## 润色公式

```
# 角色设定
你是一个[专业身份]，擅长[核心能力]。

# 任务目标
请帮我[动词+具体任务]。

# 约束条件
- 要求1（必须做到）
- 要求2（避免踩坑）
- 要求3（提升质量）

# 输出格式
请按以下格式回答：
1. [格式要求1]
2. [格式要求2]
```

## 润色示例

**用户输入（大白话）：**
> 帮我写一个介绍无人机的文案

**润色后（AI规范句式）：**
```
# 角色设定
你是一个专业的无人机行业营销文案撰写专家，擅长将技术参数转化为客户价值主张。

# 任务目标
请帮我撰写一段面向政企客户的无人机产品介绍文案，突出产品在智慧城市、公安巡检、应急救援场景下的应用优势。

# 约束条件
- 语言风格：专业严谨，适度使用行业术语，避免过于技术化
- 受众：政府招标采购负责人、企业IT部门
- 字数：200-300字
- 必须包含：产品名称、核心功能、差异化优势各1项
- 禁止：夸大宣传、虚假承诺

# 输出格式
请直接输出文案正文，无需额外解释。
```

## 自动识别逻辑

用户输入后，自动判断：

| 输入类型 | 处理方式 |
|---------|---------|
| 纯大白话（无结构） | 套用四段式公式完整润色 |
| 半结构化（有部分逻辑） | 保留已有结构，补全缺失部分 |
| 已有Prompt（但格式混乱） | 整理归并，去除冗余，补全四要素 |

## 快速润色模式

当用户只需要小改动时，直接输出润色结果，无需解释过程。

## 注意事项

- 润色结果必须是**纯Prompt内容**，不包含"下面是润色后的Prompt"这类引导语
- 如果用户输入已具备良好结构，直接给出优化建议而非重写
- 中文输入输出中文Prompt
- 润色时优先保留原意，只优化表达方式和结构
