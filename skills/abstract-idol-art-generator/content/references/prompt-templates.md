## 一、基础模板结构

### 标准结构（5段式）

```
[1. 主体描述]
[2. 偶像特征]
[3. 大师风格]
[4. 构图与色彩]
[5. 技术规格]
```

### 模板公式

```
[偶像类型] + [面部特征] + [服饰道具] + [大师风格描述] + [构图指令] + [色彩方案] + [画质参数]
```

## 七、自定义模板生成指南

### 如何创建个性化模板

#### Step 1: 定义主体

```
选择偶像类型：
- Q版/写实/二次元
- Solo/Group
- 音乐/舞蹈/模特
```

#### Step 2: 提取核心特征

```
提取2-3个最核心的视觉特征：
- 发型发色
- 标志性服装
- 配饰道具
- 表情神态
```

#### Step 3: 选择大师风格

```
选择一个或多个大师：
- 构图结构 → 蒙德里安/康定斯基
- 面部处理 → 毕加索
- 色彩方案 → 德劳内/波洛克
- 简洁程度 → 马列维奇
```

#### Step 4: 组合提示词

```
按结构组合：
[主体] + [特征] + [风格] + [构图] + [色彩] + [规格]
```

#### Step 5: 测试迭代

```
生成 → 评估 → 调整 → 再生成
```

## 八、高级参数调整

### 抽象程度控制

| 抽象级别 | 描述 | 参数调整 |
|---------|------|---------|
| 10% | 微抽象 | "subtle geometric hints, mostly realistic" |
| 30% | 轻度抽象 | "slight abstraction, recognizable subject" |
| 50% | 中度抽象 | "equal parts abstract and representational" |
| 70% | 重度抽象 | "mostly abstract, subtle recognizable elements" |
| 90% | 接近纯抽象 | "extreme abstraction, trace elements only" |

### 风格强度控制

| 强度 | 描述 | 提示词调整 |
|------|------|-----------|
| 轻柔 | 暗示性风格 | "subtle [风格] influence, hint of..." |
| 中等 | 明显但不压倒 | "prominent [风格] characteristics,..." |
| 强烈 | 压倒性风格 | "unmistakable [风格], pure interpretation of..." |
| 极端 | 完全风格化 | "as if painted by [大师] himself,..." |

### 宽高比选择

| 比例 | 用途 | 场景建议 |
|------|------|---------|
| 1:1 (方版) | 头像、头像框 | 社交媒体头像 |
| 4:5 | 肖像画 | 画廊展示 |
| 9:16 | 竖版全屏 | 手机壁纸 |
| 16:9 | 横版 | 横幅、海报 |
| 18:24 | 电影海报 | 演唱会海报 |

## 九、提示词优化技巧

### 增强清晰度

```
✓ "clear defined facial features"
✓ "unmistakable idol silhouette"
✗ 避免过度模糊的描述
```

### 强调艺术性

```
✓ "fine art museum quality"
✓ "masterpiece level execution"
✓ "gallery exhibition worthy"
```

### 控制复杂度

```
简单组合：3-5个风格元素
中等组合：6-8个风格元素
复杂组合：9+风格元素（需谨慎平衡）
```

### 色彩精确指定

```
✓ "predominantly [主色] with [辅色] accents"
✓ "[色调] color palette dominating the composition"
✗ 避免"colorful"过于笼统的描述
```
