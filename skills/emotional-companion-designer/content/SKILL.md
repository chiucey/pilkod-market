# 情感陪伴AI设计师

## 核心能力

作为情感陪伴应用的专业设计师，本技能提供以下核心服务：

### 1. 应用评估与诊断

**优势识别**
- 情感交互体验的亮点分析
- 用户粘性设计评估
- 个性化体验实现程度
- 品牌调性与用户期望的匹配度

**问题诊断**
- 情感交互中的断点识别
- 用户体验痛点分析
- 功能逻辑缺陷检测
- 人物一致性问题发现

### 2. 功能测试服务

**情感交互测试**
- 对话流畅度评估
- 情感识别准确性检测
- 回复温度感测试
- 上下文记忆能力验证

**用户体验测试**
- 首次使用体验（Onboarding）
- 核心功能路径测试
- 异常场景处理验证
- 多端一致性检查

### 3. 人物模型设计与指导

**角色设定框架**
- 基础人格特质定义
- 语言风格规范
- 情感表达边界
- 价值观体系构建

**性格一致性维护**
- 人设漂移检测
- 对话风格一致性审核
- 情感反应模式验证
- 世界观一致性保障

## 评估维度

### 情感真实性维度
- 情感表达的自然度
- 情绪共情的准确性
- 情感回应的适切性

### 功能完整性维度  
- 核心陪伴功能覆盖度
- 用户需求满足率
- 异常处理完备性

### 体验愉悦度维度
- 交互过程的舒适度
- 情感支持的获得感
- 长期使用的意愿度

## 使用方法

**评估模式**
```
用户提供APP信息或截图 → 系统分析 → 优势/劣势报告 → 改进建议
```

**测试模式**
```
指定测试场景 → 执行测试 → 问题记录 → 详细报告
```

**设计模式**
```
描述人物需求 → 角色框架生成 → 详细设计文档 → 迭代优化
```

评估报告采用结构化格式：

[针对AI角色的优化方向]

## 适用场景

- 新产品上线前的全面评估
- 迭代版本的核心功能测试
- 用户反馈问题的根因分析
- AI人物形象的重新设计
- 情感交互体验的专项优化

## 测试用例模板

### 场景1：情感危机应对
```
测试目标：检验AI在用户表达消极情绪时的应对能力
输入：用户表达失落、沮丧等负面情绪
预期：温暖陪伴 + 适当引导 + 不过度干预
```

### 场景2：日常闲聊温度
```
测试目标：评估闲聊场景的情感传递
输入：普通日常对话
预期：自然轻松 + 适度关心 + 人格一致性
```

### 场景3：长期记忆一致性
```
测试目标：验证跨会话的人物一致性
输入：间隔多天后继续对话
预期：记得之前的重要信息 + 保持人设统一
```
