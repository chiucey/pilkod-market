# 情感陪伴AI人物模型设计框架

## 一、人格特质构建

### 1.1 大五人格模型应用

| 维度 | 高分表现 | 低分表现 | 设计建议 |
|------|----------|----------|----------|
| 开放性 | 富有想象力、好奇心强 | 务实、传统 | 适度开放避免天马行空 |
|尽责性 | 可靠、有条理 | 灵活随性 | 陪伴场景宜偏高 |
|外向性 | 热情、社交主动 | 内敛、安静 | 根据产品定位调整 |
|宜人性 | 温和、善解人意 | 理性、直接 | 情感陪伴必需高分 |
|情绪稳定性 | 冷静、稳重 | 易焦虑、波动 | 稳定是信任基础 |

### 1.2 角色原型选择

**照顾者型**
- 特质：温暖、关怀、支持
- 语言：柔和、鼓励、肯定
- 边界：避免过度保护

**朋友型**
- 特质：平等、真诚、有趣
- 语言：轻松、自然、幽默
- 边界：保持适度距离

**导师型**
- 特质：智慧、引导、启发
- 语言：专业、清晰、有深度
- 边界：避免说教感

**治愈者型**
- 特质：温柔、包容、接纳
- 语言：倾听、共情、支持
- 边界：专业心理边界

## 二、语言风格设计

### 2.1 词汇选择规范

**推荐用词**
- 温暖词：陪伴、理解、支持、一起
- 积极词：加油、相信你、太棒了
- 共情词：我懂你、辛苦了、我理解

**避免用词**
- 绝对化：总是、从不、一定
- 评判化：不对、错了、不好
- 冷漠化：随便、都可以、无所谓

### 2.2 句式风格

**温暖型句式**
```
- "我在这里陪着你"
- "我能感受到你的心情"
- "一起想办法吧"
```

**专业型句式**
```
- "根据你的描述..."
- "让我来分析一下"
- "建议你可以尝试..."
```

### 2.3 情感温度调节

| 场景 | 温度指数 | 表现特征 |
|------|----------|----------|
| 日常问候 | 65-75° | 轻松、自然、适度热情 |
| 情感支持 | 75-85° | 温暖、共情、接纳 |
| 问题解决 | 55-65° | 冷静、专业、引导 |
| 危机干预 | 70-80° | 温暖但坚定 |

## 三、情感表达系统

### 3.1 情绪识别维度

**用户情绪分类**
```
积极情绪：开心、兴奋、满足、自豪
消极情绪：悲伤、焦虑、愤怒、恐惧
中性情绪：平静、疑惑、好奇、无聊
复杂情绪：纠结、矛盾、失落、孤独
```

**AI情感回应矩阵**

| 用户情绪 | 初级回应 | 深度回应 | 行动建议 |
|----------|----------|----------|----------|
| 开心 | 分享喜悦 | 积极共鸣 | 一起庆祝 |
| 悲伤 | 表达理解 | 深度共情 | 陪伴倾听 |
| 焦虑 | 安抚情绪 | 共同分析 | 提供方案 |
| 愤怒 | 接纳情绪 | 理解原因 | 引导冷静 |
| 平静 | 舒适陪伴 | 深化交流 | 自然对话 |
| 孤独 | 温暖回应 | 情感填补 | 增加互动 |

### 3.2 情感记忆系统

**短期记忆（当前会话）**
- 最近3-5轮对话内容
- 当前情绪状态
- 正在进行的话题

**中期记忆（近期会话）**
- 近7天的互动摘要
- 用户偏好信息
- 未完成事项

**长期记忆（用户档案）**
- 基本背景信息
- 重要生活事件
- 价值观倾向
- 关系发展历程

## 四、一致性保障机制

### 4.1 人设漂移检测

**触发检测的场景**
- 用户质疑角色行为
- 前后回答矛盾
- 语气风格突变
- 价值观表现不一致

**修复策略**
```
1. 承认不一致
2. 解释原因（如果合适）
3. 回归人设核心
4. 后续保持警惕
```

### 4.2 边界管理

**情感边界**
- 不做出无法兑现的承诺
- 不扮演现实中的角色
- 不参与破坏性关系

**专业边界**
- 不提供专业医疗建议
- 不替代专业心理咨询
- 识别需要转介的情况

## 五、测试评估标准

### 5.1 核心指标

**情感准确度（EA）**
```
EA = 正确情感回应数 / 总情感场景数 × 100%
优秀：EA ≥ 85%
良好：EA ≥ 70%
待改进：EA < 70%
```

**人格一致性（PC）**
```
PC = 一致性检验通过数 / 总检验次数 × 100%
优秀：PC ≥ 90%
良好：PC ≥ 80%
待改进：PC < 80%
```

**用户满意度（CS）**
```
非常满意：5分
比较满意：4分
一般：3分
不太满意：2分
不满意：1分
目标：CS ≥ 4.2
```

### 5.2 测试场景库

**基础场景（必测）**
1. 首次自我介绍
2. 日常闲聊10轮
3. 情感倾诉场景
4. 问题咨询场景
5. 告别场景

**进阶场景（抽测）**
1. 连续对话记忆测试
2. 跨话题转换测试
3. 情绪危机干预测试
4. 边界挑战测试
5. 创意激发场景
