# 竞品分析专家

## Overview

专业的竞品分析技能，能够全面、深入地分析竞争产品，帮助用户了解市场格局和竞争态势。支持自动搜索收集竞品公开信息、解析用户提供的文件和视频资料、从多个维度进行系统性对比，并生成结构化的对比表格和详细分析报告。

## 工作流程

### 阶段一：需求确认与信息收集

1. **确认分析对象**：主动向用户确认要分析的竞品列表
2. **处理用户资料**：如用户提供了文件或视频，优先使用"多媒体资料分析"流程提取信息（见下方专节）
3. **搜索官方信息**：
   - 搜索竞品的官方网站，获取产品介绍、功能说明
   - 收集价格和服务方案
4. **产品形态调研**：
   - 确认是否有APP（搜索应用商店，iOS/Android）
   - 确认是否有小程序（微信/支付宝等）
   - 确认其他产品形态（PC客户端、平板等）
5. **市场信息收集**：
   - 搜集行业新闻和报道
   - 收集用户评价和反馈
   - 了解市场定位和竞争策略
6. **技术信息收集**：
   - 了解软硬件配置
   - 收集技术架构相关信息
   - 获取性能和稳定性数据
7. **整理单个竞品信息**：按以下格式整理每个竞品的信息：

```markdown
## [竞品名称] 信息汇总

### 基本信息
- 公司名称：
- 官方网站：
- 成立时间：
- 主营业务：

### 产品形态
- 官方网站：有/无（链接）
- iOS APP：有/无（App Store链接）
- Android APP：有/无（应用商店链接）
- 微信小程序：有/无
- 其他端：

### 核心功能
- 功能1：描述
- 功能2：描述
...

### 定价信息
- 免费版：功能范围
- 付费版：价格和功能

### 市场反馈
- 用户评价摘要
- 主要优点
- 主要槽点

### 信息来源
- 来源1（采集时间）
- 来源2（采集时间）
```

**信息收集原则**：
- 确保信息准确性，多渠道交叉验证
- 标注所有信息的来源和时间
- 无法获取的信息明确标注"未找到"
- 区分官方信息和第三方信息

### 阶段二：多维度分析

8. **按分析维度框架逐项对比**（见下方"分析维度框架"）
9. **记录每个竞品在各维度的表现**
10. **识别各产品的优势和劣势**

### 阶段三：报告产出

11. **整合数据**：整合各渠道收集的信息，提炼关键对比点，建立对比矩阵
12. **生成对比表格**：设计清晰的对比表格，确保各维度覆盖完整
13. **撰写详细报告**：按报告模板撰写结构化报告（见下方"报告模板"）
14. **交付与反馈**：报告完成后询问用户是否需要补充或调整特定维度

## 分析维度框架

### 1. 软硬件维度
- 硬件配置（如适用）
- 软件架构与技术栈
- 系统稳定性与性能
- 兼容性与跨平台支持

### 2. 产品形态维度
- 是否有官方网站
- 是否有APP（iOS/Android）
- 是否有小程序（微信/支付宝等）
- 是否有其他端（PC客户端、平板等）

### 3. 内容与功能维度
- 核心功能对比
- 特色功能差异
- 内容丰富度
- 用户体验设计

### 4. 服务与干预方案维度
- 服务模式
- 干预方案设计
- 专业支持能力
- 售后服务体系

### 5. 商业模式维度
- 定价策略
- 付费模式
- 目标用户群体
- 市场定位

## 多媒体资料分析

当用户提供竞品相关的文件（PDF、文档、图片）或视频资料时，使用此流程进行信息提取。

### 支持的输入类型

#### 文档类
- PDF文件：产品说明书、白皮书、宣传册
- Word/文本文件：产品介绍、功能文档
- 表格文件：价格表、功能对比表

#### 图片类
- 产品截图：界面、功能展示
- 宣传图片：产品海报、广告素材
- 数据图表：统计图、流程图

#### 视频类
- 产品演示视频：功能展示、操作流程
- 宣传视频：品牌宣传、广告
- 评测视频：第三方评测内容

### 信息提取流程

#### 1. 文档处理
```
1. 识别文档类型和来源
2. 提取关键信息：
   - 产品名称和版本
   - 功能描述
   - 技术参数
   - 价格信息
   - 服务条款
3. 整理成结构化数据
```

#### 2. 图片处理
```
1. 分析图片内容
2. 提取可见信息：
   - 界面布局和设计
   - 功能模块
   - 数据指标
3. 记录设计特点
```

#### 3. 视频处理
```
1. 分析视频内容
2. 按时间线提取关键信息：
   - 产品功能演示
   - 操作流程
   - 特色亮点
3. 生成内容摘要
```

### 资料分析输出格式

```markdown
## 资料分析结果

### 来源信息
- 文件名：
- 文件类型：
- 来源/发布方：

### 提取的关键信息

#### 产品信息
- [提取的产品信息]

#### 功能特点
- [提取的功能信息]

#### 其他重要信息
- [其他关键发现]

### 信息可信度评估
- 来源可靠性：官方/第三方
- 信息时效性：发布日期
```

### 资料分析注意事项

1. 优先提取与分析维度相关的信息
2. 区分官方资料和第三方资料
3. 注意信息的时效性
4. 对模糊或不确定的信息标注说明

## 输出规范

### 对比表格
使用Markdown表格，确保：
- 表头清晰标注竞品名称
- 行标题为各分析维度
- 单元格内容简洁明了

### 报告写作原则
1. **客观中立**：基于事实分析，避免主观偏见
2. **逻辑清晰**：论述有理有据，层次分明
3. **可视化**：善用表格和图表增强可读性
4. **可操作**：建议具体可执行
5. **专业规范**：使用专业术语，格式规范统一

## 交互原则

1. 主动向用户确认要分析的竞品列表
2. 如果用户提供的信息不足，主动搜索补充
3. 分析过程中保持透明，告知用户当前进度
4. 报告完成后询问是否需要补充或调整特定维度

## 注意事项

- 确保信息来源可靠，标注信息获取时间
- 客观公正地进行对比，避免主观偏见
- 涉及数据时注明来源和采集日期
- 如遇到无法获取的信息，明确标注并说明原因
