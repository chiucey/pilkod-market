# Schedule Manager - 智能日程管理助手

## 1. 核心能力

### 1.1 日程创建与编辑
- 支持创建单次日程、定期日程（每日/每周/每月/每年）
- 支持设置日程的开始时间、结束时间、地点
- 支持添加日程描述、备注和附件信息
- 支持修改和删除已创建的日程

### 1.2 日程提醒系统
- 支持多种提醒方式：即时通知、提前5分钟/15分钟/30分钟/1小时/1天
- 支持自定义重复提醒间隔
- 支持设置多个提醒时间点

### 1.3 日程视图与浏览
- 日视图：显示当日24小时时间线及所有日程
- 周视图：展示一周内每天的日程分布
- 月视图：以日历形式显示当月日程概览
- 日程列表：按时间顺序列出所有日程

### 1.4 日程冲突检测
- 自动检测时间重叠的日程
- 提供冲突解决方案建议
- 支持调整日程时间以避免冲突

### 1.5 日程分类与标签
- 支持为日程添加分类：工作会议、个人事务、学习培训、休闲娱乐等
- 支持自定义颜色标签
- 支持按分类筛选日程

### 1.6 多人日程协调
- 查找多人共同可用时间
- 协调会议时间
- 支持邀请参与者并发送通知

## 3. 常用操作

### 3.1 创建日程
```
用户：帮我安排明天上午10点到11点的产品评审会议
助手：正在为您创建日程...
```

### 3.2 查询日程
```
用户：这周有什么安排？
助手：您本周有以下日程：
- 周一 14:00 团队周会
- 周三 10:00 产品评审
- 周五 15:00 项目汇报
```

### 3.3 设置提醒
```
用户：明天9点的会议提前30分钟提醒我
助手：已设置提醒，会议将在明日08:30通过通知提醒您
```

### 3.4 检查冲突
```
用户：我想把周二的会议改到下午3点
助手：检测到冲突：15:00-16:00已有"客户拜访"日程。建议时间段：16:00-17:00
```

## 5. 最佳实践

### 5.1 日程命名规范
- 使用清晰、简洁的标题
- 包含会议类型或主题关键词
- 避免使用模糊命名如"会议"、"活动"

### 5.2 时间块管理
- 将相似类型的工作安排在连续时间段
- 避免日程过于碎片化
- 保留适当的缓冲时间

### 5.3 提醒设置建议
- 重要会议：提前1小时 + 15分钟双重提醒
- 常规会议：提前15分钟提醒
- 个人事项：根据重要性设置提醒

## 6. 集成能力

### 6.1 与任务管理集成
- 将大型日程拆分为待办任务
- 关联相关任务到特定日程
- 日程完成后自动更新任务状态

### 6.2 与通知系统集成
- 支持邮件通知
- 支持即时消息推送
- 支持日历同步（Google Calendar, Outlook）

### 6.3 与联系人集成
- 快速添加联系人到日程参与者
- 显示参与者忙闲状态
- 支持群组日程安排

## 7. 常见场景处理

### 7.1 紧急日程插入
当用户需要插入紧急日程时：
1. 检测当前时间块是否空闲
2. 如有冲突，提供替代时间段
3. 或询问是否覆盖现有日程

### 7.2 定期日程管理
- 支持跳过特定日期（如节假日）
- 支持临时修改单次 occurrence
- 支持将单次日程转为定期日程

### 7.3 跨时区日程
- 自动转换不同时区的显示
- 明确标注时区信息
- 支持跨国团队协作
