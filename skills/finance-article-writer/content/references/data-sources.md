# 财经写作数据来源指南

## 一、权威数据来源

### 1. 国内宏观数据

| 数据类型 | 来源 | 发布频率 | 关注时间点 |
|---------|------|---------|-----------|
| GDP | 国家统计局 | 季度 | 1/4/7/10月中下旬 |
| CPI/PPI | 国家统计局 | 月度 | 每月9日左右 |
| 社融/M2 | 央行 | 月度 | 每月10-15日 |
| 进出口 | 海关总署 | 月度 | 每月8日左右 |
| 制造业PMI | 国家统计局 | 月度 | 每月最后一天 |
| 工业企业利润 | 国家统计局 | 月度 | 月底 |

**官方渠道**：
- 国家统计局官网：www.stats.gov.cn
- 央行官网：www.pbc.gov.cn
- 海关总署官网：www.customs.gov.cn

### 2. 金融市场数据

| 数据类型 | 来源 | 说明 |
|---------|------|------|
| 股市数据 | 交易所/Wind | 实时+历史 |
| 基金数据 | 天天基金/晨星 | 净值+持仓 |
| 债券数据 | 中债登/外汇交易中心 | 收益率曲线 |
| 期货数据 | 期货交易所 | 主力合约 |

**常用工具**：
- Wind金融终端（机构）
- 东方财富Choice（个人版可用）
- 天天基金网（基金数据）
- iFinD（同花顺）

### 3. 上市公司数据

| 数据类型 | 来源 |

| 财报 | 巨潮资讯网/交易所 |
| 公告 | 交易所官网/公司官网 |

## 六、数据使用规范

### 引用规范

```
✅ 正确格式：
"据国家统计局数据，2024年一季度GDP同比增长5.3%"

"中金公司研报显示，预计2024年A股净利润增长10%"

"Wind数据显示，截至2024年Q1，北向资金净流入XX亿元"
```

### 数据核实清单

- [ ] 数据来源是否权威？
- [ ] 数据是否为最新？
- [ ] 数据口径是否一致？
- [ ] 是否有明显异常值？
- [ ] 是否需要调整（季调、年化等）？

### 数据呈现原则

1. **来源明确**：注明数据出处
2. **口径清晰**：说明数据定义
3. **时间标注**：注明数据时点
4. **对比说明**：同比/环比/预期对比
5. **图表辅助**：关键数据可视化

## 七、常用经济指标速查

### 宏观经济指标

| 指标 | 正常区间 | 偏高含义 | 偏低含义 |
|------|---------|---------|---------|
| CPI | 2-3% | 通胀压力 | 通缩风险 |
| PPI | - | 上游价格 | 需求疲软 |
| GDP增速 | 5-6% | 经济过热 | 经济下行 |
| 失业率 | 4-5% | 劳动力紧张 | 就业不足 |
| 社融增速 | 10-12% | 信用扩张 | 信用收缩 |

### 市场情绪指标

| 指标 | 含义 | 参考区间 |
|------|------|---------|
| 换手率 | 市场活跃度 | 牛市>3%，熊市<1% |
| 融资融券 | 杠杆资金 | 变化趋势更重要 |
| 北向资金 | 外资流向 | 持续净流入/流出 |
| 涨跌停数 | 市场热度 | 涨停多=热度高 |

### 估值指标

| 指标 | 说明 | 参考标准 |
|------|------|---------|
| PE | 市盈率 | 沪深300历史均值约13倍 |
| PB | 市净率 | 沪深300历史均值约1.5倍 |
| 股息率 | 分红收益率 | 与无风险利率对比 |
| PEG | 成长性估值 | <1=相对便宜 |
