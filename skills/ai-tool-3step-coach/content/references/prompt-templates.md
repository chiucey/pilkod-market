# AI工具3步教练 - 场景指令模板库

## 写文案场景

### 公众号文案模板

**模板1：开头吸引人**
```
请帮我写一个公众号开头，要求：
1. 前3句话要让人想继续看下去
2. 结尾留个钩子，让人想留言
3. 总字数控制在200字以内
4. 语气像朋友聊天，不要太正式
```

**模板2：结构化长文**
```
请帮我写一篇公众号文章，结构如下：
- 开头：1句话引入主题
- 观点1：[主题相关]
- 观点2：[主题相关]
- 观点3：[主题相关]
- 结尾：总结+行动号召
总字数：800-1000字
```

### 朋友圈文案模板

**模板1：生活分享**
```
请帮我写一条朋友圈，内容是[你的经历/感受]，要求：
1. 真实自然，像朋友聊天
2. 带上emoji增加温度
3. 可以有互动引导（问句）
4. 字数50-100字
```

**模板2：产品推广**
```
请帮我写一条推广朋友圈，内容是[产品/服务]，要求：
1. 不像广告，像推荐
2. 包含个人使用体验
3. 有购买理由但不强制
4. 字数100-150字
```

## 做脚本场景

### 短视频脚本模板

**模板1：口播脚本**
```
请帮我写一个口播脚本，主题是[你的话题]，
时长：1分钟（约200字）
结构：
- 开头3秒：抛出痛点/吸引点
- 中间50秒：分享干货/观点
- 结尾10秒：总结+引导互动
语气：亲切、自然、像朋友聊天
```

**模板2：vlog旁白**
```
请帮我写一段vlog旁白，时长约[2-3]分钟
场景：[你的一天/一个经历/一次体验]
风格：[轻松随意/治愈系/干货分享]
要求：
- 画面感强，能看到画面
- 有细节，不空洞
- 适当留白，不要太满
```

## 整理信息场景

### 会议纪要模板

```
请帮我整理以下会议内容，提取：
1. 会议主题
2. 关键决策（3-5条）
3. 待办事项（带负责人）
4. 下次会议时间

[粘贴会议记录/录音转文字]
```

### 读书笔记模板

```
请帮我整理《[书名]》的读书笔记，结构如下：
1. 一句话总结本书
2. 3个核心观点（每个100字）
3. 最有启发的1个点
4. 行动计划（看完后我要做什么）

---

[粘贴书摘/章节内容]
```

### 数据汇总模板

```
请帮我整理以下数据/信息，结构如下：
1. 关键发现（3-5条）
2. 数据对比（如有）
3. 结论/建议
4. 下一步行动

[粘贴原始数据]
```

## 优化技巧

### 让AI更懂你的技巧

1. **给例子**：说"像这样写"比"写好一点"更有效
2. **说身份**：加"作为一个[职业/角色]"效果更好
3. **定风格**：说"像朋友聊天"或"像专家讲解"
4. **限字数**："200字以内"比"简短"更准确
5. **分步骤**："先列提纲再写正文"比分段写更好

### 避开常见坑

1. **不要**：笼统说"写好一点"
2. **不要**：不给背景信息直接要结果
3. **不要**：让AI一次做太多事
4. **可以**：分步骤让AI做，每次一个任务
5. **可以**：不满意就说"再改一下xxx"
