# 工程报价智能对比与合同条款合理性审查

## 一、核心能力概览

### 1.1 工程报价对比
- **数据标准化**：提取不同报价单中的清单编码、项目名称、特征、单位、工程量、单价、合价等，统一格式
- **横向对比**：相同清单项单价差异率、总价组成分析、主要材料价格对比
- **不平衡报价识别**：前期项目单价异常偏高、后期项目单价偏低、工程量可能增加项单价偏高
- **报价完整性检查**：漏项、重复项、计算错误、综合单价组成异常

### 1.2 合同条款审查
基于国家标准合同范本（如GF-2017-0201）、行业惯例、清单计价规范（GB50500）进行审查。

**重点审查条款类型**：

| 条款类别 | 常见不合理表现 | 建议方向 |
|---------|---------------|---------|
| 计价方式 | 固定总价但范围不清；综合单价不做任何调整 | 明确范围边界，约定可调价情形 |
| 工程量确认 | 以甲方单方确认为准，无复核机制 | 增加双方共同计量、异议复核期限 |
| 变更与签证 | 仅计成本不含利润；签证时限极短 | 按合同单价或市场价合理计价，含合理利润 |
| 付款条件 | 节点设置不合理；质保金比例过高 | 付款节点与工程关键路径匹配，质保金≤3% |
| 价格调整 | 不调价或仅单方承担降价风险 | 引用权威价格指数，约定对称调价机制 |
| 违约责任 | 仅约定乙方违约，无甲方责任 | 明确双方对等责任与违约金计算方式 |
| 结算与审计 | 以审计结果为唯一依据，审计时限无约束 | 约定结算审核期限，避免无限期拖延 |
| 不可抗力 | 排除政策变化、异常气候等 | 按示范文本分担损失，工期顺延 |

### 1.3 交叉分析
- 报价与合同矛盾检测
- 风险叠加识别（如低价报价+固定单价合同）
- 用户偏好适配（可设定风险底线）

## 二、工作流程

### 2.1 用户输入
- **报价文件**：至少2份，支持Excel、PDF或文本粘贴，需包含清单项、工作量、单价等
- **合同文本**：WORD、PDF或扫描件，或直接输入关键条款段落
- **自定义要求**（可选）：重点关注的条款方向、商务底线、特殊施工条件

### 2.2 处理流程

```
用户上传报价与合同
       ↓
   数据解析与标准化
       ↓
   报价横向对比计算
       ↓
   不平衡报价检测
       ↓
   合同条款NLP提取
       ↓
   规则引擎风险检测
       ↓
   交叉分析（报价×合同）
       ↓
   生成报告与修改建议
```

## 三、输出格式

### 3.1 报价对比输出
```
1. 总体对比摘要
   - 各投标人总价、排序
   - 主要偏差项（标明可能的不平衡报价项）

2. 详细对比表
   项目编码 | 项目名称 | 单位 | 工程量 | 投标A单价 | 投标B单价 | ... | 偏差率 | 风险标记

3. 风险项分析
   - 异常高价项（理由及可能影响）
   - 异常低价项（后期变更风险）
   - 缺漏项建议

4. 评审建议
   - 推荐顺序或需要澄清的问题列表
```

### 3.2 合同审查输出
```
1. 整体风险评级（低/中/高）

2. 不合理条款清单（按重要性排序）
   - 条款位置 | 原文摘录 | 不合理性分析 | 修改建议 | 谈判优先级

3. 交叉风险（报价与合同矛盾项）

4. 谈判策略建议
```

## 四、核心算法说明

### 4.1 单价偏差率计算
```
偏差率 = (某供应商单价 - 平均单价) / 平均单价 × 100%
```

### 4.2 不平衡报价检测维度
- **时间价值偏差**：前期项目单价高的方案导致业主早付款
- **工程量变更敏感性**：单价偏高且工程量可能增加的项目
- **投标人策略聚类**：识别一致异常模式（可能围标）

### 4.3 风险评分公式
```
风险指数 = 严重度 × (w₁×金额影响 + w₂×工期影响 + w₃×变更概率)
```
阈值：≥3.0 必须修改，2.0-3.0 建议修改，<2.0 可保留

## 五、示例用户指令

- "对比这三家幕墙工程报价，重点看出入口大门的单价差异和不平衡报价。"
- "检查这份施工合同中，关于设计变更的计价条款是否公平。"
- "我是酒店项目甲方，帮我审查这份总包合同，挖出对我不利的隐性成本条款。"

## 六、注意事项

1. **数据完整性**：提供完整的报价清单和合同文本可提高分析准确性
2. **用户偏好**：可设置风险底线（如不接受垫资比例超30%），系统据此过滤警报
3. **交叉验证**：建议同时提供招标清单作为基准，以提高匹配准确性
