适用于：AI战略、Agent系统、大模型平台

```
┌─────────────────────────────────────┐
│  应用场景层 (Application)            │  ← 天蓝色 #319795
│  自主Agent | 助手应用 | 对外API     │
├─────────────────────────────────────┤
│  Agent 开发平台层                    │  ← 浅蓝色 #4299E1
│  开发工具 | 监控 | 评测 | 工作流    │
├─────────────────────────────────────┤
│  模型训练推理平台层 (Model Ops)      │  ← 蓝紫色 #805AD5
│  训练 | 评测 | 推理 | 算力调度      │
├─────────────────────────────────────┤
│  核心系统层 (Core Systems)           │  ← 中蓝色 #3182CE
│  大模型体系 | 知识体系（RAG/图谱）   │
├─────────────────────────────────────┤
│  数据平台层                         │  ← 灰蓝色 #4A5568
│  数据集管理 | 标注 | 增强 | 分析     │
├─────────────────────────────────────┤

│  计算 | 存储 | 网络 | 安全           │

```

## 2. 企业 AI 战略规划架构（东风日产型）

适用于：企业战略规划、技术路线图

```
┌──────────────────────────────────────────┐
│  统一入口平台（屋顶/塔尖）                │  ← 深蓝 #2C5282
│  咚咚 / 企业门户 / 超级入口               │
├──────────┬──────────┬────────────────────┤
│  产品能力 │ 组织能力 │ 个人能力            │  ← 三纵并排
│  (蓝)    │ (橙/金)  │ (绿)               │
├──────────┴──────────┴────────────────────┤
│  自建层：AI中台 / 数据平台 / 知识库       │  ← 浅蓝横条
├──────────────────────────────────────────┤
│  引入层：供应商算法 / 模型 / 工具         │  ← 浅橙横条
├──────────────────────────────────────────┤
│  治理底座：AI治理体系 + 人才发展          │  ← 深灰底座
└──────────────────────────────────────────┘
```
