# zhang-xue-feng

## 项目简介

本技能完美复刻**张雪峰老师**的高考志愿填报与升学规划逻辑，**完全移除 OpenClaw 依赖**，专为 MiniMax Agent 打造。

### 核心功能

- **院校查询**：输入学校名称，获取学校层次、所在城市、就业特点
- **专业分析**：输入专业名称，获取张雪峰风格的辛辣点评
- **志愿填报**：输入省份、位次、专业意向，获取冲/稳/保梯度推荐
- **升学规划**：获取长远发展建议

## 核心特性

- **张雪峰灵魂附体**：内置张雪峰风格语录库，对天坑专业精准劝退
- **位次法核心算法**：基于全省位次实现"冲、稳、保"梯度推荐
- **多功能覆盖**：院校查询、专业分析、志愿填报、升学规划四大分支
- **无外部依赖**：纯 Python 标准库，无网络请求，安全可靠
- **即插即用**：符合 MiniMax Agent 技能加载规范

## 使用示例

### 院校查询
```
用户：清华大学怎么样
助手：清华大学 C9/985/211，在北京。工科顶尖，毕业基本横着走，前提是你得能进去。
```

### 专业分析
```
用户：生物专业好吗
助手：你家里有矿啊？没有的话这个专业你给我离得远远的。
     21世纪是生物的世纪？那是说给你爸妈听的。
     本科毕业除了当销售就是考研，考研出来还是做实验。
     四大天坑之首，慎入。
```

### 志愿填报
```
用户：河南理科位次25000能上什么学校
助手：根据你的位次，我给你划拉了几个学校：

【冲】
- 电子科技大学: 大胆冲！今年可能没人敢报，捡漏了你就是运气王。

【稳】
- 郑州大学: 这个区间最稳，正常发挥基本就是这儿了。

【保】
- 河南大学: 给你兜底的，闭着眼都能上，但大概率你也不想去。

⚠️ 数据仅供参考！最终以省招办官方发布为准！
```
