# 技术指标参考手册

本文档为短线潜力股筛选提供详细的技术指标计算方法和应用指南。

## 一、动量指标

### 1. RSI (Relative Strength Index)

**计算公式：**
```
RSI(14) = 100 - (100 / (1 + RS))
其中 RS = 14日内上涨幅度均值 / 14日内下跌幅度均值
```

**应用场景：**
| RSI 区间 | 信号 | 操作建议 |
|----------|------|----------|
| 0-30 | 超卖 | 谨慎买入，等待反弹 |
| 30-50 | 偏弱 | 观望或轻仓试探 |
| 50-75 | 强势 | 重点关注，趋势延续 |
| 75-85 | 超买 | 谨慎追高，注意回调 |
| 85-100 | 极度过买 | 及时止盈，考虑离场 |

### 2. MACD (Moving Average Convergence Divergence)

**计算公式：**
```
EMA(12) = 12日指数移动平均
EMA(26) = 26日指数移动平均
DIF = EMA(12) - EMA(26)
DEA = DIF的9日移动平均
MACD柱 = (DIF - DEA) × 2
```

**应用场景：**
- **金叉买入**：DIF 上穿 DEA，且柱由负转正
- **死叉卖出**：DIF 下穿 DEA，且柱由正转负
- **底背离**：价格创新低，但 MACD 未创新低 → 潜在反弹信号
- **顶背离**：价格创新高，但 MACD 未创新高 → 警惕回调

### 3. KDJ 随机指标

**计算公式：**
```
RSV = (收盘价 - N日内最低价) / (N日内最高价 - N日内最低价) × 100
K = 2/3 × 前一日K值 + 1/3 × 当日RSV
D = 2/3 × 前一日D值 + 1/3 × 当日K值
J = 3 × K - 2 × D
```

**应用场景：**
- KDJ 金叉（K 上穿 D）且在 20 以下：低位买入信号
- KDJ 死叉（K 下穿 D）且在 80 以上：高位卖出信号
- J 值 > 100：超买警戒
- J 值 < 0：超卖警戒

## 二、趋势指标

### 1. 移动平均线 (MA)

**常用周期：**
| 周期 | 用途 |
|------|------|
| 5 日线 | 短线操作参考，快速响应 |
| 10 日线 | 短期趋势判断 |
| 20 日线 | 中短期支撑/阻力 |
| 60 日线 | 中期趋势生命线 |
| 120 日线 | 半年线，长期趋势 |

**均线多头排列：**
- 短期 > 中期 > 长期
- 价格在所有均线之上
- 均线向上发散

**均线空头排列：**
- 短期 < 中期 < 长期
- 价格在所有均线之下
- 均线向下发散

### 2. 布林带 (Bollinger Bands)

**计算公式：**
```
中轨 = MA(20)
上轨 = 中轨 + 2 × 标准差
下轨 = 中轨 - 2 × 标准差
```

**应用场景：**
- 价格触及下轨：超卖，可能反弹
- 价格触及上轨：超买，可能回调
- 布林带收窄：酝酿突破，关注方向选择
- 布林带开口：趋势加速，延续性强

## 三、量价指标

### 1. 成交量 (VOL)

**量价配合分析：**
| 价格走势 | 成交量 | 信号含义 |
|----------|--------|----------|
| 上涨 | 放量 | 资金积极入场，趋势健康 |
| 上涨 | 缩量 | 上涨动能减弱，警惕回调 |
| 下跌 | 放量 | 抛压沉重，加速探底 |
| 下跌 | 缩量 | 卖方衰竭，可能见底 |
| 震荡 | 缩量 | 多空平衡，酝酿突破 |

**均量线：**
- 5 日均量 > 10 日均量：短期资金活跃
- 量能突破前期高点：确认趋势

### 2. 换手率

**换手率参考：**
| 换手率 | 市场含义 |
|--------|----------|
| < 3% | 交易冷清，观望 |
| 3-7% | 正常波动 |
| 7-15% | 活跃，需关注位置 |
| > 15% | 高度活跃，警惕风险 |
| > 25% | 异常活跃，主力可能出货 |

## 四、支撑阻力

### 1. 支撑位识别

**常见支撑位：**
- 前期低点
- 重要均线（20 日、60 日线）
- 整数关口
- 前期成交密集区上沿

### 2. 阻力位识别

**常见阻力位：**
- 前期高点
- 均线压力位
- 整数关口
- 前期成交密集区下沿

### 3. 筹码分布

**分析要点：**
- 底部筹码集中：主力建仓，等待拉升
- 顶部筹码集中：主力出货，风险聚集
- 单峰密集：方向即将选择
- 双峰填谷：震荡格局，突破在即

## 五、综合评分标准

### 热点评分 (40%)

| 评分 | 条件 |
|------|------|
| 90-100 | 板块涨停 ≥ 5 只，消息面重大利好 |
| 70-89 | 板块涨幅 ≥ 3%，涨停 3-5 只 |
| 50-69 | 板块涨幅 1-3%，涨停 1-2 只 |
| 30-49 | 板块小涨，联动性一般 |
| < 30 | 板块走弱，无明显催化 |

### 强势评分 (35%)

| 评分 | 条件 |
|------|------|
| 90-100 | 5日涨幅超大盘 10%+，RSI 在 60-70，量能充足 |
| 70-89 | 5日涨幅超大盘 5-10%，均线多头 |
| 50-69 | 跑赢大盘，趋势完整 |
| 30-49 | 跟随大盘，无明显优势 |
| < 30 | 弱于大盘，走势疲软 |

### 分歧评分 (25%)

| 评分 | 条件 |
|------|------|
| 90-100 | 关键支撑/阻力位有效，筹码配合良好 |
| 70-89 | 分歧信号明确，入场时机好 |
| 50-69 | 有一定分歧价值 |
| 30-49 | 分歧信号模糊 |
| < 30 | 无明显分歧点 |

## 六、K线形态识别

### 买入形态

1. **锤子线**：下影线是实体的 2-3 倍，收盘接近高点
2. **启明星**：下跌趋势中出现，看涨反转
3. **吞没形态**：阳包阴，看涨信号
4. **早晨之星**：三K线组合，看涨反转

### 卖出形态

1. **射击之星**：上影线长，顶部反转信号
2. **黄昏之星**：上涨后出现，看跌反转
3. **吞没形态**：阴包阳，看跌信号
4. **乌云盖顶**：第二日高开低走，顶部预警
