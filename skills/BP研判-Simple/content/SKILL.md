## BP 研判 4 段框架（30 分钟内出）

### 1. 赛道 + 切入点

**回答**：什么赛道、用什么技术切、卡在产业链哪一环？

**输出字段**：
- **产业链位置**：上游 / 中游 / 下游
- **技术路线**：3 条主流路线对比
- **商业本质**：卖什么（器件/模组/整机/平台/数据）
- **目标客户**：B 端 / C 端 / 双边
- **可触达 TAM**：用真实可触达 × 5% 市占率上限

### 2. 壁垒识别

**回答**：真壁垒还是假壁垒？和国际 Tier 1 的具体参数差异？

**输出字段**：
- **对标 3 家**：国际 Tier 1 + 国内跟随者 + 价格战玩家
- **真壁垒类型**（按强度排序）：
  1. 客户验证壁垒（已签 Tier 1 独家协议）⭐⭐⭐⭐⭐
  2. 认证壁垒（UL/IEC/AEC-Q/医疗 FDA）⭐⭐⭐⭐
  3. 技术参数壁垒（像素/精度/响应时间/寿命）⭐⭐⭐
  4. 规模/产能壁垒（Fab 锁定）⭐⭐⭐
  5. 专利/IP 壁垒 ⭐⭐
  6. 创始人/团队壁垒 ⭐⭐
- **护城河宽度**：18-24 个月 / 3-5 年 / 5-10 年

### 3. 业绩三角

**回答**：人/技术/钱闭环了吗？订单可验证吗？

**输出字段**：
- **客户验证**：是否签了 Top 3 客户？样品/POC/小批量/独家？
- **收入质量**：分产品线占比、毛利率结构、ASP 趋势
- **业绩兑现**：收入 CAGR、净利率趋势、亏损收窄
- **产业方股东**：美的/海尔/比亚迪/宁德/京东方是否在股东列表？
- **历史融资**：融了几轮、估值变化
- **本轮估值锚点**：按可比公司 PS/PE 测算

### 4. 雷点扫描

**回答**：缺什么？能不能补？值不值得为这个雷点买单？

**输出字段**：
- **信息缺失清单**（按重要性排序）：收入/订单/客户名单/创始团队履历/上一轮估值/分产品线收入/财务三表
- **结构性雷点**：创始人控制权、关联交易、国际 Tier 1 中国本地化反扑、政策窗口期
- **执行性雷点**：Fabless 产能、团队完整度（CFO/CSO/销售 VP 缺失）、海外业务合规
