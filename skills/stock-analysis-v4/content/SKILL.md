# 股票深度分析 SKILL v4.0.5

## ⚠️ 强制触发机制（100%执行）

### 触发条件检测

**当用户输入满足以下任一条件时，必须调用本SKILL：**

1. **【触发1】包含股票代码**
   ```
   匹配模式：6位数字、4位/8位数字（北交所）
   示例：601456、002532、600519、430001
   ```

2. **【触发2】包含股票名称关键词**
   ```
   匹配词：股票、股份、公司
   示例：国联民生、天山铝业、贵州茅台
   ```

3. **【触发3】包含分析意图词**
   ```
   匹配词：分析、查看、查询、对比、走势、持仓、成本、财报、行情、股价
   ```

4. **【触发4】明确请求分析**
   ```
   匹配词：帮我看看、分析下、查一下、对比一下
   ```

### 触发执行流程

```
用户输入 → 触发检测 → 【强制调用】本SKILL → 执行分析流程
                ↓
         【禁止】跳过SKILL直接网页搜索
         【禁止】自行判断不使用API
```

## 股票代码识别转换系统（内置规则）

### 代码格式说明

腾讯财经API需要的股票代码格式：

| 市场 | 代码前缀 | 示例 | 转换规则 |
|------|----------|------|----------|
| 上海主板 | sh | sh601456 | 6开头的6位码 → sh + 代码 |
| 深圳主板 | sz | sz002532 | 0开头的6位码 → sz + 代码 |
| 创业板 | sz | sz300750 | 3开头的6位码 → sz + 代码 |
| 北交所 | bj | bj430001 | 4/8开头的6位码 → bj + 代码 |

### 内置股票名称映射表

```
天山铝业 → 002532 → sz002532
```

### 识别转换流程

```
用户输入
   ↓
【Step 1】提取股票标识（代码或名称）
   ↓
【Step 2】识别市场类型
   - 6开头 → 上海(sh)
   - 0/3开头 → 深圳(sz)
   - 4/8开头 → 北交所(bj)
   ↓
【Step 3】如果输入是名称，查表转换为代码
   ↓
【Step 4】拼接腾讯API格式
   - sh/sz/bj + 代码
   ↓
【Step 5】调用API: https://qt.gtimg.cn/q=sh601456
```
