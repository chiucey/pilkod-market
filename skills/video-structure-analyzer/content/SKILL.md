# 视频结构分析器

## 核心能力

1. **镜头语言解析**
   - 全景（Establishing Shot）
   - 近景（Close-up）
   - 中景（Medium Shot）
   - 缓慢推镜（Slow Push-in）

2. **角色替换**
   - 识别脚本中的角色名称
   - 执行批量替换
   - 保持角色动作描述的一致性

3. **场景调整**
   - 交通工具变更（小船→木筏）
   - 环境细节添加（摊档桌子、物品摆放）
   - 地理位置描述修改

4. **道具替换**
   - 核心道具交换
   - 相关动作调整
   - 结局对白关联修改

## 工作流程

### 输入处理

接收用户提供的视频脚本/分镜头描述，识别以下结构元素：

```
[镜头类型] [场景描述], [角色动作], [对白/台词]
```

### 替换规则

| 替换类型 | 处理方式 |
|---------|---------|
| 角色名称 | 全文替换，保持语法一致性 |
| 场景描述 | 整体替换，保留镜头类型 |
| 道具物品 | 替换并调整相关动作描写 |
| 结局对白 | 关联替换，逻辑自洽 |

### 输出格式

保持输入的格式结构，仅替换指定元素：

```
[镜头类型] [新场景描述], [新角色动作], [新对白]
```

## 示例

### 输入
```
全景 女记者+男中年 在小船上采访，男中年仰头喝水，女问："海上末日，你选择尿液过滤器，还是五个女幸存者"
近景 男中年低头喝杯中液体
结尾：男中年大喊："因为生存来源就只有尿液过滤器啊"
```

### 角色替换输出
```
全景 九尾狐+臭脚猪 在小船上采访，臭脚猪仰头喝水，九尾狐问："海上末日，你选择尿液过滤器，还是五个女幸存者"
近景 臭脚猪低头喝杯中液体
结尾：臭脚猪大喊："因为生存来源就只有尿液过滤器啊"
```

### 完整替换输出
```
全景 九尾狐+臭脚猪 在木筏售卖摊档旁采访，臭脚猪闻鲱鱼毒草鞋，九尾狐问："海上末日，你选择鲱鱼毒草鞋，还是五个女幸存者"
近景 臭脚猪手里拿着鲱鱼毒草鞋，在闻来闻去
结尾：臭脚猪大喊："因为鲱鱼毒草鞋是唯一的生存物资啊"
```

## 使用方式

1. **纯角色替换**：提供原始脚本 + 角色对照表
2. **场景调整**：提供原始脚本 + 新场景描述
3. **道具替换**：提供原始脚本 + 道具对照表 + 关联对白调整
4. **完整转换**：提供原始脚本 + 完整替换要求（角色+场景+道具）

## 注意事项

- 保持镜头类型的准确性
- 角色替换时注意动作描写的一致性
- 道具替换后确保相关对白逻辑自洽
- 场景变更时保留原有的空间关系描述
