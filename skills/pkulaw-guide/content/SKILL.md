# 北大法宝数据库使用指南助手

一款面向法学研究人员的专业数据库使用指南工具，提供简单检索、高级检索、出版物检索、核心期刊检索和作者检索五大核心功能。

## 核心功能

### 1. 简单检索
- 分类筛选：法律法规、司法案例、学术论文、司法解释
- 快捷检索标签：民法典、劳动合同法、知识产权、公司法、刑法修正案等
- 检索技巧提示与法学论文常用主题推荐

### 2. 高级检索
- 多条件自由组合（AND/OR逻辑关系）
- 支持字段：标题、全文、作者、关键词、摘要、机构
- 时间范围限定与文献类型筛选
- 检索策略示例参考

### 3. 出版物检索
- CLSCI/CSSCI等法学核心期刊分类浏览
- 期刊信息展示：ISSN、影响因子、级别标识
- 投稿指南：选刊建议、注意事项

### 4. 核心期刊检索
- 按年份、期数筛选核心期刊论文
- 排序功能：相关度、引用次数、发表时间
- 论文摘要预览与写作建议

### 5. 作者检索
- 知名法学家信息卡片展示
- 机构、研究领域筛选
- 学术指标：论文数、被引次数、H指数
- 学术合作与文献追踪建议

## 适用场景

- 科研工作者进行法学研究
- 研究生撰写法学毕业论文
- 法律从业者查找法规和案例
- 学术作者追踪研究动态
- 期刊投稿选刊参考

## 技术栈

- React 18 + TypeScript
- Tailwind CSS
- Lucide React Icons
- Vite 构建工具
