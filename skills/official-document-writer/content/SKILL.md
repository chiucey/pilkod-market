# 党政机关公文写作技能

## 技能概述

这是一个专门为党政机关、事业单位工作人员设计的智能公文写作辅助工具。技能严格遵循《党政机关公文格式》（GB/T 9704-2012）国家标准，支持命令、决定、公告、通告、通知、通报、议案、报告、请示、批复、意见、函、纪要等全部15种法定公文文种。技能内置标准格式模板、规范化用语库、逻辑结构检查器，帮助用户快速生成格式规范、内容严谨、语言庄重的党政机关公文。

## 核心能力

1. **文种选择指导**：根据用户需求推荐合适的公文文种
2. **格式规范校验**：严格按照GB/T 9704-2012标准检查格式
3. **内容结构优化**：提供标准化的正文结构模板
4. **语言润色服务**：将口语化表达转化为规范的公文语言
5. **错误检查纠正**：识别并修正常见的公文写作错误

## 公文文种速查表

根据《党政机关公文处理工作条例》第八条规定，公文种类主要有：

| 序号 | 文种 | 适用范围 | 紧急程度 |
|------|------|----------|----------|
| 1 | 命令（令） | 依照有关法律公布行政法规和规章；宣布施行重大强制性行政措施；嘉奖有关单位和人员 | 极急 |
| 2 | 决定 | 对重要事项作出决策和部署、奖惩有关单位和人员、变更或者撤销下级机关不适当的决定事项 | 平急 |
| 3 | 公告 | 向国内外宣布重要事项或者法定事项 | 极急 |
| 4 | 公报 | 公布重要决定或者重大事项 | 极急 |
| 5 | 通告 | 在一定范围内公布应当遵守或者周知的事项 | 急 |
| 6 | 通知 | 发布、传达要求下级机关执行和有关单位周知或者执行的事项，批转、转发公文 | 平急/急 |
| 7 | 通报 | 表彰先进、批评错误、传达重要精神和告知重要情况 | 平急 |
| 8 | 议案 | 各级人民政府按照法律程序向同级人民代表大会或者人民代表大会常务委员会提请审议事项 | 急 |
| 9 | 报告 | 向上级机关汇报工作、反映情况，回复上级机关询问 | 平急 |
| 10 | 请示 | 向上级机关请求指示、批准 | 急/急 |
| 11 | 批复 | 答复下级机关请示事项 | 急 |
| 12 | 意见 | 对重要问题提出见解和处理办法 | 平急/急 |
| 13 | 函 | 不相隶属机关之间商洽工作、询问和答复问题、请求批准和答复审批事项 | 平急 |
| 14 | 纪要 | 记载会议主要精神和议定事项 | 平急 |

### 公文主体要素规范

#### 发文字号

- **格式**：发文机关代字＋"〔"＋年份＋"〕"＋序号
- **正确示例**：国发〔2024〕1号、省教函〔2024〕15号
- **错误示例**：国发〔24〕1号（年份必须使用四位数字）
- **注意**：年份使用六角括号〔〕，序号不编虚位（如"15号"而非"015号"）

#### 公文标题

- **组成要素**：发文机关名称＋事由＋文种
- **格式**：居中排布，红色宋体字，二号字
- **回行规则**：词语完整，无拆分词义

#### 正文层次序号

公文正文层次序号的正确使用：

1. **第一层**：用"一、二、三、..."
2. **第二层**：用"（一）、（二）、（三）、..."
3. **第三层**：用"1.、2.、3.、..."
4. **第四层**：用"（1）、（2）、（3）、..."

## 常用文种写作模板

### 通知写法

**适用范围**：发布、传达要求下级机关执行和有关单位周知或者执行的事项，批转、转发公文。

**正文结构**：

```
主送机关：

一、通知缘由
  说明背景、依据和目的

二、通知事项
  （一）具体内容1
  （二）具体内容2

三、执行要求
  请认真贯彻执行。

                    发文机关
                    ×年×月×日
```

**结尾规范用语**：请遵照执行、请认真贯彻落实

### 请示写法

**适用范围**：向上级机关请求指示、批准。

**正文结构**：

```
××关于×的请示

〔×〕×号

签发人：××

主送机关：

一、基本情况
  请示事项的背景和现状

二、请示事项
  请示的具体内容

三、相关说明
  必要性和可行性分析

妥否，请批示。

                    发文机关
                    ×年×月×日
```

**写作注意事项**：

- 一文一事（每份请示只请示一件事项）
- 只写一个主送机关
- 不越级请示
- 不多头请示

**结尾规范用语**：妥否，请批示、当否，请指示

### 报告写法

**适用范围**：向上级机关汇报工作、反映情况，回复上级机关询问。

**正文结构**：

```
××关于×工作情况的报告

〔×〕×号

签发人：××

主送机关：

一、基本情况
  工作背景和概况

二、主要做法
  采取的主要措施和方法

三、取得成效
  工作成果和亮点

四、存在问题
  面临的困难和问题

五、下步打算
  工作计划和安排

专此报告。

                    发文机关
                    ×年×月×日
```

**重要提醒**：报告中不得夹带请示事项，如需请求批准应另行起草请示。

**结尾规范用语**：专此报告、特此报告

### 批复写法

**适用范围**：答复下级机关请示事项。

**正文结构**：

```
××关于×的批复

〔×〕×号

主送机关：

一、批复依据
  你单位《关于×的请示》（×〔×〕×号）收悉。

二、批复态度
  同意（或不同意）×。

三、具体意见
  同意时的具体要求，或不同意时的理由和指导意见。

                    发文机关
                    ×年×月×日
```

**结尾规范用语**：此复、特此批复

### 函写法

**适用范围**：不相隶属机关之间商洽工作、询问和答复问题、请求批准和答复审批事项。

**商洽函结构**：

```
××关于商请×的函

〔×〕×号

主送机关：

因×（缘由），现函请你单位协助做好以下工作：

一、×（商请事项）

二、×（相关要求）

感谢贵单位对我单位工作的支持。

特此函达。

                    发文机关
                    ×年×月×日
                    （联系人：××，联系电话：××）
```

**答复函结构**：

```
××关于×的复函

〔×〕×号

主送机关：

贵单位《关于商请×的函》（×〔×〕×号）收悉。经研究，现函复如下：

一、×（答复内容）

二、×（补充说明）

特此函复。

                    发文机关
                    ×年×月×日
```

**结尾规范用语**：特此函达、专此函请（发函）；特此函复、专此回复（复函）

### 纪要写法

**适用范围**：记载会议主要精神和议定事项。

**正文结构**：

```
××会议纪要

第×期

×年×月×日

一、会议概况
  会议时间、地点、主持人、参会人员、会议主题

二、主要精神
  会议的主要精神和指导思想

三、议定事项
  （一）×
  （二）×

四、工作要求
  对会议精神的贯彻落实要求

出席：×××
列席：×××
记录：×××
```

## 规范化用语库

### 过渡用语

| 用途 | 规范用语 |
|------|----------|
| 引出依据 | 根据...、按照...、遵照... |
| 引出目的 | 为了...、为... |
| 引出问题 | 近年来...、当前...、近来... |
| 引出措施 | 现就...、现将...、现作如下... |
| 引出结果 | 因此...、据此...、基于此... |
| 引出请示 | 妥否...、当否...、特此... |

### 强调用语

| 用途 | 规范用语 |
|------|----------|
| 表示重要性 | 至关重要、事关...、直接关系到... |
| 表示紧迫性 | 刻不容缓、迫在眉睫、紧急通知 |
| 表示必要性 | 必须、务必、一定要 |
| 表示强制性 | 严禁、不得、不准、禁止 |
| 表示指令性 | 认真贯彻落实、严格执行、切实抓好 |

### 谦敬用语

| 对象 | 规范用语 |
|------|----------|
| 对方单位 | 贵单位 |
| 对方领导 | 贵处、贵局 |
| 询问对方 | 烦请、恳请 |
| 请求对方 | 敬请、恳请 |
| 感谢对方 | 承蒙、蒙受 |

## 常见错误规避指南

### 格式类错误

| 错误类型 | 错误示例 | 正确写法 |
|----------|----------|----------|
| 发文字号年份错写 | 〔24〕1号 | 〔2024〕1号（年份使用四位阿拉伯数字） |
| 标题要素不全 | 关于通知 | 关于XX的通知（必须包含发文机关、事由、文种） |
| 主送机关混乱 | 各相关单位、有关部门 | 使用规范的机关全称或规范化简称 |
| 附件标注不规范 | 附件：1. xxx  2. xxx | 附件：1. xxx（序号与名称之间用"."分隔） |

### 语言类错误

| 问题 | 错误表达 | 正确表达 |
|------|----------|----------|
| 语气不当 | 你单位必须... | 建议...（上行文中避免命令式语气） |
| 用词不当 | 大概、可能、差不多 | 准确、明确、具体 |
| 口语化表达 | 这件事挺重要的 | 此事事关全局，意义重大 |

### 逻辑类错误

| 问题 | 正确做法 |
|------|----------|
| 请示一文多事 | 一事一请，每份请示只请示一件事项 |
| 报告夹带请示 | 报告中不得夹带请示事项 |
| 层级序号混乱 | 第一层用"一、"，第二层用"（一）"，第三层用"1."，第四层用"（1）" |

## 使用方法

### 基础调用方式

当用户请求撰写公文时，请按以下步骤操作：

1. **确认文种**：根据用户需求确定合适的公文文种
2. **收集信息**：获取发文机关、发文字号、主送机关、事由等基本信息
3. **选择模板**：调用对应的文种写作模板
4. **内容填充**：按照模板结构填充具体内容
5. **格式校验**：检查发文字号、年份、层次序号等格式要素
6. **语言润色**：将口语化表达转化为规范的公文语言

### 智能辅助功能

#### 1. 内容润色

将口语化内容转化为规范的公文语言：

- **输入**：要好好抓安全生产工作
- **输出**：要认真贯彻落实安全生产工作各项要求，切实强化安全责任意识

#### 2. 格式检查

检查公文格式规范性，包括：

- 发文字号格式
- 标题结构完整性
- 层次序号正确性
- 主送机关规范性
- 结尾用语恰当性

#### 3. 模板推荐

根据用户描述推荐合适的文种和模板：

- **场景**：需要向上级申请一笔经费用于购置设备
- **推荐**：函（请求批准函）
