# 十维知识拆解框架 · 参考说明

## 设计背景

普通人掌握知识往往是零散的。知道一点概念、几个术语，但没有整体感。讲清楚的人少，是因为没掌握框架。

这套十维框架的目标是：**让任意学科都能在短时间内建立起完整的认知骨架。**

---

## 十维详解

### 1. 名称/概念
- 学科的正式名称（中/英）
- 民间别名、简称
- 核心定义（3 种以上的经典表述）
- 核心概念的边界与模糊地带

### 2. 类别/种属
- 主流分类体系（2～3 种）
- 主要流派/分支
- 各类之间的关系（包含？并列？交叉？）
- 分类的依据是什么（方法论？研究对象？）

### 3. 含义/定义
- 这个学科试图回答的**核心问题**是什么
- 与相近学科的**核心区别**在哪
- 在人类知识体系中的**定位**（位于哪个层次？）

### 4. 特征/属性
- 这个学科**最独特**的思维方式是什么
- 研究对象的**根本特性**是什么
- 它使用什么**语言和工具**来描述世界

### 5. 组成/结构
- 主要子学科/分支模块（列出 5～8 个）
- 模块之间的**逻辑关系**和**依赖关系**
- 有哪些**核心概念/定律/原理**支撑整个学科

### 6. 作用/功能
- 它能**解决什么问题**（具体场景）
- 对个人/社会/学术界有什么**价值**
- 与哪些**现实问题**直接相关

### 7. 条件/环境
- 这个学科在什么**历史背景**下诞生
- 它的存在依赖于哪些**社会/技术/经济条件**
- 为什么这个时代它变得**重要了**

### 8. 历程/演变
- **关键时间节点**（创始、突破、分化）
- 代表人物及其贡献（3～5 位）
- 范式转变（2～3 次重大转折）
- 现在的学术生态是什么样的

### 9. 前景/趋势
- 学科内部有什么**新方向**正在兴起
- 与哪些**新兴领域**交叉
- 未来 5～10 年可能有什么**重大突破**
- 产业应用层面有什么新动态

### 10. 风险/挑战
- 这个学科的**根本局限**在哪里
- 内部有什么**争议/未解决的问题**
- 面临哪些**外部挑战**（资金、社会信任等）
- 有什么**被颠覆**的风险

## 使用提示

**面对用户的学科时，遵循以下顺序：**

1. 先问用户是否有基础（完全零基础 vs 有一定了解）
2. 先问用户的目标（建立认知框架 vs 深度研究 vs 应用实践）
3. 根据回答决定展开深度（维度 1-5 优先，6-10 按需展开）
4. 用户提供的参考资料/图，优先融入"阶段 1：建骨架"

**输出弹性：**
- 时间有限 → 只输出骨架 + 1、2、3、5、6 维度的核心内容
- 想要深入 → 完整十维展开 + 推荐学习路径
- 有具体材料 → 按材料整合，融合用户提供的框架

---

## 与用户图的关系

用户提供的图（如"任一知识都包括10个知识点"那类框架图）是一个很好的起点。把它作为"阶段 1 建骨架"的参考，结合十维框架，生成更完整的学科骨架图。

例子：用户提供"个体心理学"+一张参考图
→ 先解读参考图的结构
→ 再用十维框架补充图中没有的维度
→ 输出完整骨架 + 精简摘要
