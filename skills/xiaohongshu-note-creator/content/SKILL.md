# 小红书笔记素材创作技能

根据用户需求和提供的资料，创作完整的小红书笔记内容并生成图片卡片。

## 核心能力

1. **内容撰写**：标题 + 正文（emoji风格、段落格式）
2. **图片卡片生成**：封面卡片 + 正文卡片
3. **直接发布**：使用Cookies可直接发布到小红书

## 排版主题

| 主题名称 | 描述 | 适用场景 |
|---------|------|---------|
| `default` | 默认简约浅灰渐变背景（`#f3f3f3 -> #f9f9f9`） | 通用场景 |
| `playful-geometric` | 活泼几何（Memphis风格） | 时尚/生活类 |
| `neo-brutalism` | 新粗野主义 | 个性/创意类 |
| `botanical` | 植物园自然风格 | 生活方式/美妆 |
| `professional` | 专业商务风格 | 职场/知识类 |
| `retro` | 复古怀旧风格 | 怀旧/文艺类 |
| `terminal` | 终端命令行风格 | 科技/程序员类 |
| `sketch` | 手绘素描风格 | 艺术/教程类 |

## 分页模式

| 模式 | 描述 | 适用场景 |
|------|------|---------|
| `separator` | 按 `---` 分隔符分页 | 内容已手动控量 |
| `auto-fit` | 固定尺寸下自动缩放文字 | 封面+单张图片但尺寸固定 |
| `auto-split` | 按渲染后高度自动切分 | 长文内容切分不影响阅读 |
| `dynamic` | 根据内容动态调整图片高度 | 短内容（≤550字） |

## 执行流程

### 步骤1：收集需求

收集以下信息：
- **笔记主题/核心内容**：用户想要分享什么
- **参考资料**（如有）：产品介绍、数据、素材链接等
- **排版主题**：指定主题或由AI推荐
- **分页模式**：指定模式或由AI判断
- **Cookies**（可选）：如需直接发布

### 步骤2：内容创作

生成内容必须包含：
- **标题**：吸引眼球，含emoji，含关键词
- **正文**：小红书风格（emoji表情、分段落、互动引导）

### 步骤3：图片卡片生成

1. **封面卡片**：吸引眼球，含核心信息
2. **正文卡片**：按分页模式生成

卡片尺寸：
- 封面：3:4（1125x1500px）
- 正文：保持统一比例

### 步骤4：发布（如适用）

使用用户提供的Cookies调用发布API。
