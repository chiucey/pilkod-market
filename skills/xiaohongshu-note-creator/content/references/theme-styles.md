# 小红书排版主题详细样式

## 1. default（默认简约）

```css
background: linear-gradient(180deg, #f3f3f3 0%, #f9f9f9 100%);
font-family: "PingFang SC", "Helvetica Neue", sans-serif;
border-radius: 12px;
```

特点：干净、简洁、通用

## 2. playful-geometric（活泼几何）

```css
background: #FFF5E6;
border: 3px solid #FF6B6B;
box-shadow: 6px 6px 0 #FFD93D;
```

元素：
- 几何形状装饰（圆形、三角形、波浪线）
- 明亮的Memphis配色
- 活泼的排版布局

## 3. neo-brutalism（新粗野主义）

```css
background: #FFFFFF;
border: 4px solid #000000;
box-shadow: 8px 8px 0 #000000;
```

特点：
- 粗黑边框
- 强烈阴影
- 大胆的撞色
- 无衬线字体

## 4. botanical（植物园自然）

```css
background: linear-gradient(180deg, #F5F7F0 0%, #E8EFE0 100%);
color: #3D5A3D;
```

元素：
- 植物插画/叶子图案
- 自然色调（绿色、米色、棕色）
- 手写体或衬线字体
- 留白充足

## 5. professional（专业商务）

```css
background: linear-gradient(180deg, #1A1A2E 0%, #16213E 100%);
color: #FFFFFF;
```

特点：
- 深蓝色调
- 简洁的线条装饰
- 专业字体
- 数据可视化友好

## 6. retro（复古怀旧）

```css
background: #FDF6E3;
border: 2px solid #C4A77D;
color: #5D4E37;
```

元素：
- 旧报纸纹理
- 暖色调
- 衬线字体
- 边框装饰

## 7. terminal（终端命令行）

```css
background: #1E1E1E;
color: #00FF00;
font-family: "Courier New", monospace;
```

特点：
- 黑色背景+绿色文字
- 代码块风格
- 伪终端界面
- 闪烁光标效果

## 8. sketch（手绘素描）

```css
background: #FEFEFA;
filter: url(#sketch-filter);
```

特点：
- 手绘线条
- 不规则边框
- 铅笔纹理
- 随意但温暖的风格

## 卡片尺寸规范

| 类型 | 尺寸比例 | 像素尺寸 | 用途 |
|------|---------|---------|------|
| 封面 | 3:4 | 1125x1500 | 吸引眼球 |
| 正文 | 3:4 | 1125x1500 | 展示内容 |

## 字体建议

- 标题：粗体，24-32px
- 正文：常规，16-18px
- 标签：中等，14-16px
