# exam-maker

老师制作试卷的核心技能，支持**试卷生成**和**Markdown 转 Word** 两大功能，输出**试卷**和**答案**两份独立文件。

## 工作流程

### 模式一：生成试卷

当用户要求"生成试卷"、"出试卷"、"制作试卷"时：

1. **收集考试信息**（如未提供，按默认值处理）：
   - 考试科目、年级、满分、考试时长
   - 题型范围：选择题、填空题、解答题、多选题、判断题
   - 知识点范围（用户提供教材文本或描述）

2. **生成 Markdown 试卷**（`/workspace/exams/` 目录）

3. **转换为 Word**（调用 `scripts/md2exam.js`，Node.js 环境）
   - 自动生成**两份文件**：试卷（不含答案）和答案（仅含答案）
   - **文件名固定为英文**：避免 Unicode 字符导致 CDN 上传失败
   - `exam-questions.docx` → 学生用试卷
   - `exam-answers.docx` → 教师用答案册

4. **上传并返回下载链接**给用户

### 模式二：Markdown → Word 转换

当用户要求"转成 Word"、"导出 docx"、"Markdown 转 Word"时：

1. 读取用户提供的 Markdown 内容（文件上传或直接粘贴）
2. 调用 `scripts/md2exam.js` 生成试卷 + 答案两份 docx
3. 返回下载链接

## 输出文件规范

### 文件命名规则

| 文件 | 命名 | 用途 |
|------|------|------|
| 试卷 | `exam-questions.docx` | 分发给学生，含题目和答题区域 |
| 答案 | `exam-answers.docx` | 教师保留，含完整参考答案 |

> ⚠️ 统一使用英文文件名，避免中文字符导致 CDN/下载失败。

### 试卷（exam-questions.docx）内容

- 试卷标题（居中，黑体大字）
- 考生信息答题纸（姓名、班级、学号、得分栏）
- 所有题目（题号 + 分值 + 题干 + 选项/填空区域）
- **不包含答案**

### 答案（exam-answers.docx）内容

- 与试卷相同的题号 + 分值 + 题干
- 每题附**完整参考答案**（解答题含推导过程）
- 用紫色斜体标注，清晰区分

## 格式规范

### Markdown 试卷格式

使用特殊标记区分题型和分值：

```markdown
# 试卷标题
- 科目：数学 | 年级：高二 | 满分：150分 | 时间：120分钟

## 选择题（共 10 题，每题 5 分）

1. （5分）题干文字 $E=mc^2$ 这里有公式
   - A. 选项一
   - B. 选项二
   - C. 选项三
   - D. 选项四
   **答案：A**

2. （5分）题目文字
   - A. 选项一
   - B. 选项二
   - C. 选项三
   - D. 选项四
   **答案：B**

## 填空题（共 5 题，每题 4 分）

3. （4分）求 $\int_0^1 x^2 dx$ 的值。
   **答案：** $\dfrac{1}{3}$

## 解答题（共 5 题，每题 12 分）

6. （12分）证明：当 $n$ 为正整数时，有 $\sum_{k=1}^n k = \dfrac{n(n+1)}{2}$。
   **答案：** [教师参考答案]

## 多选题（共 2 题，每题 6 分）

8. （6分）下列正确的是（）
   - A. 选项一
   - B. 选项二
   - C. 选项三
   - D. 选项四
   **答案：ABD**
```

### LaTeX 公式规范

- 行内公式：使用 `$...$`（标准 LaTeX）
- 独立公式：使用 `$$...$$` 或 `\[...\]`
- 支持：分式、根号、矩阵、积分、极限、求和符号、向量、希腊字母等

## 转换脚本用法

### Node.js 环境（推荐，已预装）

```bash
node scripts/md2exam.js <输入.md>
```

输出两份英文命名的 docx：
- `exam-questions.docx`（试卷）
- `exam-answers.docx`（答案）

### Python 环境（需手动安装依赖）

```bash
pip install python-docx markdown lxml
python scripts/md2exam.py <输入.md> [--output <输出名>]
```

## 试卷模板结构（exam-template.docx）

模板包含以下预定义样式：

| 样式名 | 用途 |
|--------|------|
| 试卷标题 | 大标题（居中，黑体，二号） |
| 试卷信息栏 | 科目、年级、满分、时间（居中，小五号） |
| 题头 | 题型标题（黑体，四号，左对齐） |
| 题干 | 题目文字（宋体，五号） |
| 选项 | ABCD 选项（宋体，五号，左缩进） |
| 答案 | 答案行（楷体，五号，紫色斜体） |
| 得分栏 | 考生答题信息表（边框表格） |
| 页眉页脚 | 密封线、页码 |

## 依赖

### Node.js（推荐，预装）
- `docx`（`cd scripts && npm install docx`）

### Python（备选）
- `python-docx` ≥ 1.0.0
- `lxml` ≥ 4.9.0
- `markdown` ≥ 3.4.0
- `pandoc` ≥ 2.0（用于 LaTeX → OMML 转换）
