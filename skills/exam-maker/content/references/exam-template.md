## 一、选择题（共 10 题，每题 5 分）

1. （5分）已知集合 $A = \{x \mid x^2 - 4x + 3 < 0\}$，$B = \{1, 2, 3\}$，则 $A \cap B$ 为（    ）
   - A. $\{1, 2\}$
   - B. $\{1, 3\}$
   - C. $\{2, 3\}$

   **答案：B**

2. （5分）函数 $f(x) = \dfrac{1}{\sqrt{x-2}}$ 的定义域为（    ）

   - B. $[2, +\infty)$
   - C. $(-\infty, 2)$
   - D. $(-\infty, 2]$
   **答案：A**

3. （5分）若 $\vec{a} = (1, -2)$，$\vec{b} = (3, k)$，且 $\vec{a} \perp \vec{b}$，则 $k = $（    ）

   - B. $-\dfrac{3}{2}$

   - D. $-6$
   **答案：B**

4. （5分）已知 $\sin x = \dfrac{3}{5}$，$x \in \left(\dfrac{\pi}{2}, \pi\right)$，则 $\cos 2x = $（    ）
   - A. $\dfrac{7}{25}$

   - C. $\dfrac{24}{25}$
   - D. $-\dfrac{24}{25}$

5. （5分）等差数列 $\{a_n\}$ 中，$a_1 = 3$，$a_5 = 11$，则 $S_{10} = $（    ）

## 三、解答题（共 5 题，每题 12 分）

11. （12分）已知函数 $f(x) = ax^2 + bx + c$（$a \neq 0$），且 $f(1) = 0$，$f(-1) = 4$，$f(0) = 2$。
    （1）求 $a, b, c$ 的值；
    （2）求 $f(x)$ 的顶点坐标和对称轴方程。

    **答案：**
    （1）由条件得：$\begin{cases} a + b + c = 0 \\ a - b + c = 4 \\ c = 2 \end{cases}$，解得 $a = -1$，$b = -2$，$c = 2$。
    （2）$f(x) = -x^2 - 2x + 2 = -(x+1)^2 + 3$，顶点 $(-1, 3)$，对称轴 $x = -1$。

12. （12分）证明：当 $n$ 为正整数时，有
    $$\sum_{k=1}^n k^2 = \frac{n(n+1)(2n+1)}{6}$$

    **答案：**【数学归纳法】略。

13. （12分）求椭圆 $\dfrac{x^2}{25} + \dfrac{y^2}{16} = 1$ 上任意一点 $P(x_0, y_0)$ 到直线 $l: 3x + 4y - 12 = 0$ 的距离的最大值与最小值。

    **答案：** 最大值 $\dfrac{13}{5}$，最小值 $\dfrac{7}{5}$。

## 五、判断题（共 5 题，每题 2 分）

16. （2分）"所有素数都是奇数"是真命题。  （    ）
    **答案：✗**（2是偶素数）

17. （2分）若 $f'(x_0) = 0$，则 $x_0$ 一定是 $f(x)$ 的极值点。  （    ）
    **答案：✗**（还需二阶导数或单调性判断，如 $f(x)=x^3$ 在 $x=0$ 处）

18. （2分）$\displaystyle \frac{d}{dx}(\sin^2 x) = 2\sin x \cos x = \sin 2x$。  （    ）
    **答案：✓**

19. （2分）$\log_a (MN) = \log_a M + \log_a N$（$a>0$ 且 $a \neq 1$，$M>0, N>0$）。  （    ）
    **答案：✓**

20. （2分）直线的点斜式方程 $y - y_0 = k(x - x_0)$ 可以表示平面上所有直线。  （    ）
    **答案：✗**（竖直直线 $x = x_0$ 不能用点斜式表示）
