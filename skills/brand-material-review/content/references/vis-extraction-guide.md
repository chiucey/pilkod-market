# VIS规范文档解析指南

## 支持的文件格式

### 文档类
- PDF (.pdf)
- Word文档 (.docx, .doc)
- PowerPoint (.pptx, .ppt)
- Excel表格 (.xlsx, .xls)

### 图片类
- 品牌LOGO原文件 (PNG, SVG, AI, EPS)
- 色彩规范参考图
- 字体规范示例图

## 关键信息提取

### 1. LOGO规范信息

需要提取：
```
- 主LOGO源文件
- LOGO最小使用尺寸
- 净空区比例要求
- LOGO标准色值（HEX/RGB/CMYK）
- LOGO反白/反黑版本
- LOGO错误使用示例
```

### 2. 色彩规范信息

需要提取：
```
- 品牌主色及色值
- 品牌辅助色及色值
- 禁止使用颜色
- 渐变规范（如果适用）
- 色彩使用场景说明
```

### 3. 字体规范信息

需要提取：
```
- 中文字体列表
- 西文字体列表
- 数字字体规范
- 各层级字号规范
- 字重使用规范
```

### 4. 辅助图形规范

需要提取：
```
- 辅助图形源文件
- 图形使用场景
- 组合使用规则
- 禁用组合说明
```

## 规范完整性评估

### 高完整性（推荐）
包含以上所有关键信息，可进行完整审核

### 中等完整性
缺少部分信息，仅能进行有限审核

### 低完整性
信息严重不足，审核结果可能不够准确

## 常见问题处理

### 问题1：扫描版PDF无法提取文字
- 解决方案：使用OCR技术识别
- 或要求提供可编辑版本

### 问题2：色彩值格式不统一
- 统一转换为HEX格式进行比对
- 列出原始格式供参考

### 问题3：缺少明确的尺寸规范
- 根据行业标准推断最小尺寸
- 在报告中标注"建议确认"

### 问题4：多个版本规范共存
- 以最新版本为准
- 在报告中标注版本信息
