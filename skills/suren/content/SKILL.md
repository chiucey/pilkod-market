# V4.1 游资交易策略系统

## 核心原则

**只做主线、只做主升阶段**

## ⚠️ 核心操作规则（必须遵守！）

1. **优先使用米筐RQData接口**
   - 米筐license需要用户自行配置
   - akshare作为备用

2. **数据二次校验机制**
   - 连板股票、人气股的数据必须用接口二次校验
   - 不能相信未经校验的数据
   - 发现数据与K线不符时，以K线为准

3. **时间逻辑严格遵守**
   - **T日数据 → 生成T+1日预案**
   - 今天是4月23日 → 用4.23数据生成4月24日预案
   - 4月24日的行情还未发生，绝不能说"今日"

4. **遇到问题直接说**
   - 不要猜数据
   - 不要假设数据
   - 直接告诉用户需要什么数据
   - 先从米筐查，查不到再问用户要

---

## ⚠️ 强制工作流程

每次生成交易预案必须按以下顺序执行：

---

### 第一步：确认当前日期和目标日期

**关键问题**：
- 今天是几号？（T日）
- 生成哪一天的预案？（T+1日）

**示例**：
- 今天是4月22日 → 用4.22数据生成**4月23日**预案
- 今天是4月23日 → 用4.23数据生成**4月24日**预案

---

### 第二步：从米筐获取T日数据

**米筐初始化**：
```python
import rqdatac as rq
rq.init(username="license", password="YOUR_LICENSE_KEY")
```

**必须用米筐获取的数据**：
- T日涨停股票列表（含收盘价）
- T-1日收盘价（计算涨幅）
- T日跌停股票列表
- 重点股票的近期K线（校验连板数）

**连板检测方法（必须执行）**：
```python
hist = rq.get_price(code, start_date="T-5日", end_date="T日", frequency='1d')
逐日计算涨幅，统计连续涨停天数 = 连板数
```

---

### 第三步：二次校验连板数据

**判断首板的方法**：
- T日涨停
- T-1日未涨停 → T日是**首板**

**判断连板的方法**：
- T日涨停
- T-1日也涨停 → T日是**N连板**（N=连续涨停天数）

**示例（云南锗业）**：
| 日期 | 收盘 | 涨幅 | 判断 |
|:----:|:----:|:----:|:-----|
| 4.17 | 涨停 | +10% | 首板 |
| 4.18 | 涨停 | +10% | 2连板 |
| 4.21 | 未涨停 | +0.29% | 断板 |
| 4.22 | 涨停 | +10% | **首板**（不是2连板！）|

⚠️ **错误识别**：4.22是首板，T+1不能买！

---

### 第四步：七维情绪指标打分（连续体系）

#### 4.1 收集近4日数据

获取T-3、T-2、T-1、T日的以下数据：
- 涨停数量
- 跌停数量
- 最高连板数
- 连板数量
- 首板溢价
- 连板晋级率

#### 4.2 情绪动量表（必须生成）

| 指标 | T-3 | T-2 | T-1 | T日 | 趋势 |
|:-----|:---:|:---:|:---:|:---:|:----:|
| 涨停数 | X只 | X只 | X只 | X只 | ↑/→/↓ |
| 跌停数 | X只 | X只 | X只 | X只 | ↑/→/↓ |
| 最高连板 | X板 | X板 | X板 | X板 | ↑/→/↓ |
| 当日得分 | A | B | C | D | - |
| 4日均分 | - | - | - | E=(A+B+C+D)/4 | - |

#### 4.3 当日打分（权重60%）

| 维度 | 数据 | 变化 | 打分 | 说明 |
|:----:|:--------:|:----:|:----:|:-----|
| 涨停数量 | X只 | +X% | +1/2 | 15-30%增长+1，>30%增长+2 |
| 跌停数量 | X只 | -X% | -1/2 | >20%减少+1，>40%减少+2 |
| 炸板率 | X% | - | +1/2/-2 | <20%+1，<15%+2，>30%-1，>40%-2 |
| 最高连板 | X板 | - | +1/2 | >=5板+1，>=7板+2 |
| 连板数量 | X家 | - | +1/2 | >=15家+1，>=25家+2 |
| 涨停溢价 | X% | - | +1/2 | >3%+1，>5%+2 |
| 连板晋级率 | X% | - | +1/2 | 50-70%+1，>70%+2 |

#### 4.4 趋势分计算（权重15%）

| 趋势 | 条件 | 加分 |
|:----:|:-----|:----:|
| 连续升温 | 连续3天得分上升 | +2 |
| 稳定上升 | 连续2天上升 | +1 |
| 震荡 | 无明显趋势 | 0 |
| 降温 | 连续2天下降 | -1 |
| 连续降温 | 连续3天下降 | -2 |

#### 4.5 最终情绪得分

```
最终得分 = 当日得分 × 60% + 4日均分 × 25% + 趋势分 × 15%
```

**修正规则**：
- 主升期 + 连续降温 → 降为发酵期
- 冰点期 + 连续升温 → 升级为分歧期
- 趋势分 ±2 时，再修正±1档

#### 4.6 综合得分→情绪周期

| 最终得分 | 周期 | 仓位 |
|:--------:|:----:|:----:|
| >=+8 | 主升期 | 5成 |
| +4~+7 | 发酵期 | 3成 |
| 0~+3 | 分歧期 | 1-2成 |
| -4~-1 | 退潮期 | 0-1成 |
| <=-5 | 冰点期 | 0成 |

#### 4.7 情绪惯性判断

| 连续状态 | 判断 | 操作 |
|:---------|:----:|:-----|
| 连续3天高位(>=+4) | 情绪稳定 | 持仓为主 |
| 连续3天低位(<=+2) | 情绪低迷 | 观望为主 |
| 高位突然下滑 | 注意转折 | 降低仓位 |
| 低位突然上升 | 可能是拐点 | 试探性建仓 |

#### 4.8 情绪转折核心锚点

| 特征 | 判定 | 操作 |
|:-----|:----:|:-----|
| **龙头股高位跌停** | 退潮开始 | 立即降仓至1成 |
| 中位股批量掉队 | 高位震荡期 | 降低仓位 |
| 连板晋级率明显下降 | 高位震荡期 | 降低仓位 |
| 只剩龙头孤军奋战 | 高位震荡期 | 谨慎 |

**核心逻辑**：
- **龙头股涨跌是情绪周期的"锚"**
- **连板晋级率和炸板率是辅助验证**
- 数值是参考，特征才是判断依据

---

### 第五步：首板/连板指数分析

| 情况 | 信号 | 操作建议 |
|------|------|----------|
| 连板涨幅 > 首板涨幅 | 高位股强势 | 往龙头核心切 |
| 首板涨幅 > 连板涨幅 | 低位补涨 | 情绪末期信号，降低仓位 |
| 两个指标都>3% | 高潮确认 | "今天短线看分歧" |
| 两个指标都低 | 退潮期 | 空仓 |

---

### 第六步：主线判断表

| 板块 | 人气 | 涨停池 | 连板股 | 扩散度 | 梯队 | 板块K线 | 等级 |
|:----:|:---:|:------:|:------:|:------:|:---:|:-------:|:---:|
| 商业航天 | 3/4 | 10+只 | 博云6板 | >30% | 完整 | 连续上涨 | **A级** |

**判断标准**：
- **扩散度**：主线涨停/全市场涨停 >50%明确，>30%有主线，<30%散乱
- **连板梯队**：完整 / 断层 / 薄弱
- **板块K线**：连续2日+上涨 = 确认主线持续性

**总分>=4：强主线，可参与**
**总分2-3：主线，谨慎参与**
**总分0-1：观察，不参与**
**总分<0：一日游，回避**

---

### 第七步：仓位指导

| 情绪周期 | 仓位 | 股票数量 |
|----------|------|----------|
| 主升期 | 5成 | 3只 |
| 上升期 | 4成 | 2-3只 |
| 发酵期 | 3成 | 1-2只 |
| 分歧期 | 1-2成 | 最多1只 |
| 退潮/高位震荡 | 0-1成 | 0只 |
| 冰点/主跌 | 0成 | 0只 |

### 第八步：规则自检（核心！每次必须执行）

**自检顺序（用T日数据判断T+1日操作）**：
```
□ 1. T日是否首板？  → 是则排除（T+1不能买首板）
□ 2. 是否7板以上？  → 是则排除
□ 3. 量比是否>3倍？ → 是则排除
□ 4. 是否被重点监控？ → 是则排除
□ 5. 是否在选股域？ → 否则排除
□ 6. 主线是否明确？ → 否则谨慎
```

**量比规则**：
- >3倍：绝对回避
- 2-3倍：回避
- 1.5-2倍：谨慎
- <1.5倍：正常

**连板高度规则**：
- 2-4板：优先
- 5-6板：谨慎
- **7板以上：绝对回避**

---

### 第九步：选股推荐

**选股域**：
1. T日3连板及以上
2. T日人气榜前10（开盘啦、雪球、淘股吧、同花顺）

**龙头股的核心定义（必须理解！）**：

> 龙头股不只是"连板最高的股票"，核心是**带动性与主动性**。
>
> - **高度领先**：板块内连板数最高或涨幅最大
> - **带动板块**：其表现能对板块内其他个股产生明显影响（跟涨/跟跌）
> - **主动表态**：不是被动跟涨，而是自身主动拉升，带动板块情绪
>
> 简单判断方法：看该股分时拉升时，板块内是否有其他个股跟随响应。若独自上涨不带板块，则带动性不足，不一定是龙头。

**推荐输出格式**：
```
## 推荐股票（X只）

### 股票1：[名称]（[代码]）
- **昨日连板**：X板
- **量比**：X.XX倍
- **题材**：[所属题材]
- **所属板块**：[所属板块]
- **主线匹配**：高度匹配 / 中度匹配 / 不匹配
- **风险点**：[如有]
- **操作建议**：[买入/观望/回避]
```
