# 林肯周报生成技能

## 功能说明

自动从Excel数据文件生成林肯舆情周报Word文档，严格按照林肯品牌交付版周报格式。

## 使用方法

在对话中发送指令：
```
请生成林肯周报，数据文件是：[Excel文件路径]
```

## 数据要求

Excel文件需包含以下列：
- 发布时间
- 标题
- 摘要
- 媒体名称（渠道）
- 情感（正面/中性/负面）

## 数据处理逻辑

### 1. 相似度聚合
- **相似度阈值**：80%（标题相似度超过80%的内容视为同一话题）
- **聚合目的**：避免重复话题，统计真实传播规模

### 2. 内容质量分类（仅针对正面信息）

#### 高质量品牌传播内容
- 标题长度≥15字符
- 包含具体产品信息、配置、技术描述
- 包含质量信号词：全新、新一代、配置、动力、油耗、空间、舒适、豪华、智能、科技、安全等

#### 营销互动内容
- 包含品牌标签话题、互动话题
- 主要用于品牌话题传播和用户互动

### 3. 话题选择策略

#### 正面话题选择
- 从高质量品牌传播内容的聚类中选择
- 确保覆盖不同主题（产品展示、智能科技、试驾体验、配置解析等）
- 选择4个代表性话题

#### 负面话题选择
- 从负面信息的聚类中选择
- 覆盖不同问题类型（销量、配置、价格、品牌舆论等）
- 选择5个代表性话题

## 计算规则

- **总传播量**：数据总条数
- **日均扩散量**：总传播量 ÷ 7（四舍五入取整）
- **占比计算**：各类别数量 ÷ 总传播量 × 100%（保留1位小数）

## 输出格式

### 文件命名
- 文件名：`林肯舆情周报（MMDD-MMDD）.docx`

### 文档格式
- **字体**：全部宋体，11号字（标题13号字）
- **对齐**：标题左对齐，无下划线
