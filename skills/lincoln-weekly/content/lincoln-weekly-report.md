# 林肯舆情周报生成器

## 功能说明

自动从Excel数据文件生成林肯舆情周报Word文档，严格按照林肯品牌交付版周报格式。

## 使用方法

在对话中发送指令：
```
请生成林肯周报，数据文件是：[Excel文件路径]
```

## 数据要求

Excel文件需包含以下列：
- 发布时间
- 标题
- 摘要
- 媒体名称（渠道）
- 情感（正面/中性/负面）

## 数据处理逻辑

### 1. 相似度聚合
- **相似度阈值**：80%（标题相似度超过80%的内容视为同一话题）
- **聚合目的**：避免重复话题，统计真实传播规模
- **聚合方法**：使用difflib.SequenceMatcher计算文本相似度

### 2. 内容质量分类（仅针对正面信息）

#### 高质量品牌传播内容
**特征**：
- 标题长度≥15字符
- 包含具体产品信息、配置、技术描述
- 包含质量信号词：全新、新一代、配置、动力、油耗、空间、舒适、豪华、智能、科技、安全、性能、体验、优势、特点、亮点、试驾、评测、解析、详解、介绍、推荐、导购
- 纯标签内容≤2个（#标签数量不超过2个）
- 排除明显的营销充数模式

**排除的营销充数模式**：
- 品牌标签话题：#好事来林肯定舒服、#林肯舒奢瞬间、#林肯的N种躺平姿势
- 互动话题：#买车那些事儿、想听听大家、朋友们最近、这个假期大家
- 通用场景：#清明、#下雨、#花是春游出片关键词、#我的春日搭子
- 简单表态：论安全感这一块、我还是很放心的、实力不必多说
- KOL合作：#张雪机车相关内容

#### 营销互动内容
- 包含上述营销充数模式的内容
- 主要用于品牌话题传播和用户互动
- 在周报中作为整体趋势提及，不作为主要话题

### 3. 内容主体识别

#### 判断标准：是否真正讨论林肯
**正面内容识别**：
- 包含多个林肯关键词（≥2个）
- 林肯关键词数量多于竞品关键词
- 竞品关键词：奔驰、宝马、奥迪、雷克萨斯、凯迪拉克、沃尔沃、理想、蔚来、小鹏、特斯拉、问界、比亚迪

**负面内容识别**：
- 应用相同标准，但需注意负面信息中仅提及林肯的比例较高（约60%）
- 优先选择主要讨论林肯而非仅提及的内容

### 4. 话题选择策略

#### 正面话题选择
1. **数据源**：从高质量品牌传播内容的聚类中选择
2. **聚类筛选**：优先选择主要讨论林肯的聚类
3. **多样性保证**：确保覆盖不同主题（产品展示、智能科技、试驾体验、配置解析等）
4. **避免重复**：同一聚类只选择一个代表话题
5. **数量**：选择4个代表性话题

#### 负面话题选择
1. **数据源**：从负面信息的聚类中选择
2. **聚类筛选**：优先选择主要讨论林肯的聚类
3. **多样性保证**：覆盖不同问题类型（销量、配置、价格、品牌舆论等）
4. **避免重复**：同一聚类只选择一个代表话题
5. **数量**：选择5个代表性话题

#### 车型关键词
- 飞行家、航海家、冒险家、领航员、林肯Z、林肯ZEPHYR

## 话题筛选标准

### 正面话题（高质量品牌传播）
- **内容类型**：产品展示介绍、技术配置解析、试驾评测体验、购车指南推荐、品牌活动促销
- **质量要求**：
  - 有具体的产品信息、配置、优势描述
  - 有明确的正面宣传内容
  - 不是简单的标签话题或互动话题
- **主题覆盖**：产品展示、智能科技、试驾体验、配置解析、品牌传播等

### 敏感话题
- **内容类型**：销量困境、品牌舆论、产品配置问题、价格争议、产品投诉
- **相关性**：优先选择主要讨论林肯的内容，排除仅提及林肯的行业文章
- **真实性**：反映林肯品牌真实面临的问题和舆论

## 计算规则

- **总传播量**：数据总条数
- **日均扩散量**：总传播量 ÷ 7（四舍五入取整）
- **占比计算**：各类别数量 ÷ 总传播量 × 100%（保留1位小数）
- **平台统计**：按媒体名称统计数量并排序，取TOP5

## 输出格式

### 文件命名
- 文件名：`林肯舆情周报（MMDD-MMDD）.docx`
- 日期格式：月日-月日（如 0329-0405）

### 文档格式
- **字体**：全部宋体，11号字（标题13号字）
- **对齐**：标题左对齐，无下划线
- **缩进**：
  - 一级标题（1. 2. 3.）：不空格
  - 二级标题（1.1 1.2等）：空2格
  - 三级标题（2.1.1等）：空3格
- **段间距**：一级标题之间空一行

  2.1 主要围绕"产品展示""智能科技""试驾体验""品牌传播"等内容展开

### 话题展示格式
- **标题长度**：控制在50-60字符，超出部分用"..."省略
- **相似度标注**：每个话题后标注聚合数量（X条相似内容）
- **主题概括**：2.1和3.1的开头概括主要传播点，用引号分隔

## 数据质量提示

### 典型数据特征
- **正面内容**：高质量品牌传播约占45-50%，营销互动内容约占50-55%
- **负面内容**：主要讨论林肯的内容约占35-40%，仅提及林肯的行业文章约占60-65%
- **相似度聚合**：正面信息通常有1500-2000个聚类，负面信息通常有200-400个聚类

### 车型关注度排序
典型排序（按提及量）：航海家 > 冒险家 > 飞行家 > 林肯Z > 领航员

## 使用建议

1. **数据验证**：生成周报前，先查看数据统计，确认正面/负面比例合理
2. **质量检查**：检查正面话题是否为高质量品牌传播内容，而非营销充数内容
3. **相关性确认**：确认负面话题主要讨论林肯，而非仅提及的行业文章
4. **主题覆盖**：确认选择的话题覆盖不同主题，避免重复
