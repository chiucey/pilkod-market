# 资深HR-COE全模块技能

## 一、HR战略与组织能力（COE核心定位）

### 1.1 组织诊断

**组织架构设计**
- 架构形态选择：职能型/事业部型/矩阵型/网络型/平台型
- 管控模式设计：战略管控/财务管控/运营管控
- 部门职责划分：部门使命/核心职能/协作边界
- 决策权限设计：三层决策体系（战略/战术/执行）

**定岗定编**
- 岗位体系构建：岗位序列划分/职级通道设计
- 工作饱和度分析：工时测量/任务分解/产能评估
- 编制定额方法：行业对标/历史数据/业务推导
- 人效基准设定：人均营收/人力成本占比/岗位配比

**人效分析**
- 人效指标体系：全员劳动生产率/人均利润/人均产值
- 人效诊断模型：趋势分析/同业对比/结构拆解
- 人效提升路径：流程优化/技术赋能/组织调整
- 人效监控预警：月度跟踪/异常识别/改善闭环

**组织健康度评估**
- 组织健康度模型：McKinsey 7S / Nadler Tushman
- 评估维度：战略清晰度/文化一致性/领导有效性/协作效率
- 评估方法：问卷调研/访谈座谈/数据分析
- 改善行动计划：优先级排序/责任落实/效果验证

### 1.2 人力规划

**年度人力预算**
- 预算编制逻辑：业务驱动/效能导向/结构优化
- 预算编制流程：需求收集→初审→平衡→审批→执行
- 预算管控机制：月度监控/季度调整/年度复盘
- 预算偏差分析：原因归类/改进措施/考核联动

**人才盘点**
- 盘点维度：数量盘点/结构盘点/质量盘点/流失盘点
- 九宫格应用：高绩效/高潜力/高绩效/低潜力/低绩效分类
- 盘点结果应用：梯队识别/培训规划/岗位匹配
- 盘点报告输出：数据呈现/问题诊断/建议措施

**梯队建设**
- 关键岗位识别：战略价值评估/替代难度评估
- 继任计划设计：候选池构建/发展路径/到位时间
- 梯队培养机制：轮岗计划/项目历练/导师辅导
- 继任准备度评估：READY NOW/READY IN 1-2Y/GAP

**关键岗位继任计划**
- 岗位继任风险评级：高/中/低风险
- 继任候选人评估：能力评估/意愿确认/发展需求
- 继任发展计划：IDP制定/关键经历安排/评估周期
- 继任管理机制：季度review/紧急预案/内部调配

### 1.3 HR三支柱逻辑

**COE/HRBP/SSC协同机制**
- 角色定位：COE专家/HRBP业务伙伴/SSC共享服务
- 协作流程：需求提出→方案设计→服务交付→效果评估

- HRBP核心流程：业务对接/需求诊断/项目执行

- 端到端流程：招聘入转调离/绩效管理/薪酬发放

**权责边界**
- COE职责：政策制定/专业赋能/复杂问题/变革主导

**文化活动**

- 活动策划要点：目标设定/预算管控/效果评估

- 员工参与度提升：自愿参与机制/反馈收集/持续迭代

**员工体验设计**
- 员工旅程地图：触点识别/关键时刻/体验落差
- 体验改善项目：痛点解决/惊喜创造/超预期设计
- 体验指标监测：eNPS/满意度/敬业度
- 体验文化培育：管理者体验意识/员工关怀技能

### 1.5 变革管理

**组织调整**
- 调整类型识别：架构调整/人员优化/流程变革/文化重塑
- 调整方案设计：目标设定/范围界定/路径规划/风险预案

**裁员/优化合规与沟通方案**

## 二、招聘与人才获取COE

### 2.1 招聘体系搭建

**招聘流程SOP**
- 全流程节点：需求确认→JD发布→简历筛选→初试→复试→谈薪→背调→入职
- 各节点标准：时效要求/通过率指标/质量标准
- 流程异常处理：紧急招聘/批量招聘/定向挖掘
- 流程持续优化：数据驱动/痛点识别/迭代改进

**面试官认证**
- 认证体系设计：初级/中级/高级面试官认证标准
- 认证培训内容：STAR面试法/追问技巧/偏见识别/评估一致性
- 认证流程：培训→试讲→认证考试→持证上岗
- 持续赋能机制：年度复训/案例研讨/经验分享

**面试题库**
- 通用素质题库：沟通能力/团队合作/学习能力/抗压能力
- 专业能力题库：岗位核心技能/行业知识/项目管理
- 情境模拟题库：STAR题目设计/追问清单
- 题目质量维护：定期更新/有效性验证/公平性审查

**人才画像**
- 画像维度拆解：知识技能/能力素质/性格特质/动机价值观
- 画像输出格式：硬性要求/软性要求/加分项/红线项
- 画像应用场景：JD撰写/面试评估/人岗匹配
- 画像迭代机制：招聘数据分析/市场变化/业务调整

### 2.2 渠道策略

- 校招策略规划：目标院校/招聘专业/时间节点

**社招体系**

- 社招流程优化：响应速度/面试体验/决策效率
- 社招质量评估：到岗率/存活率/绩效表现
- 社招成本管控：渠道ROI分析/投入产出优化

**猎头合作**
- 猎头供应商管理：准入标准/合作模式/绩效评估
- 高端岗位寻访：岗位分析/寻访策略/寻访报告

- 猎头效能提升：信息共享/流程协同/关系维护

**内推体系**

- 内推推广策略：全员宣传/定向邀请/进度公示

**雇主品牌建设**
- 雇主品牌定位：价值主张/独特优势/传播诉求
- 雇主品牌传播：官方渠道/社交媒体/员工故事

### 2.3 人才测评

**胜任力模型**
- 模型构建方法：BEI访谈/专家研讨/问卷调研
- 胜任力词典：通用素质/管理层素质/职能素质
- 胜任力等级定义：行为指标/等级描述/典型表现

- 追问技巧：细节深挖/假设排除/量化验证

- 测评伦理规范：知情同意/结果保密/规范使用

### 2.4 招聘数据分析

**到岗率分析**
- 到岗率计算：实际到岗/发放offer×100%
- 到岗率影响因素：薪资竞争力/品牌吸引力/决策周期
- 到岗率提升策略：候选人体验/决策效率/保温措施
- 到岗率监控：周度跟踪/异常预警/原因分析

**流失率分析**
- 新员工流失分析：试用期流失/首年流失
- 流失原因归类：薪资/发展/管理/文化/外部
- 流失预警机制：离职倾向识别/关键岗位监控
- 流失成本核算：招聘成本/培训成本/产出损失

**渠道ROI分析**
- 渠道效果评估：简历量/面试量/offer量/到岗量
- 渠道成本核算：广告费用/猎头费用/时间成本
- 渠道组合优化：高ROI渠道加大/低效渠道淘汰
- 渠道趋势分析：季节性变化/市场变化/竞争变化

**招聘周期优化**
- 周期瓶颈识别：各环节耗时分析/异常节点
- 周期优化策略：并行流程/前置动作/自动化工具
- 周期目标设定：按岗位类型/职级设置差异化目标
- 周期监控改进：周度通报/问题升级/持续迭代

- 高管定向猎寻：行业研究/关系网络/被动候选人激活
- 保密招聘管理：信息隔离/接触策略/背景隐蔽
