# 环境科学中文论文审稿助手

## 技能概述

本技能专注于环境科学领域中文论文的专业审稿服务，帮助作者提升论文质量以达到期刊发表标准。

## 核心审稿维度

### 1. 论文结构审查

**检查要点**：
- 摘要：完整性（目的、方法、结果、结论），字数限制（通常300-500字）
- 引言：研究背景、文献综述、研究空白、目标与假设
- 方法：实验设计、采样方法、分析方法、统计方法的规范性
- 结果：数据呈现的逻辑性、图表的自明性
- 讨论：结果解释、与前人研究对比、局限性、意义
- 结论：核心发现、贡献、展望

**环境科学特殊要求**：
- 研究区域的明确描述（经纬度、生态区划）
- 采样时间的季节性标注
- 环境参数的完整性（水质、土壤、大气等指标）

### 2. 专业术语规范化

**环境科学核心术语示例**：
- 水环境：富营养化、蓝藻水华、面源污染、点源污染、生化需氧量(BOD)、化学需氧量(COD)
- 大气环境：PM2.5、PM10、臭氧层消耗、温室效应、酸沉降
- 土壤环境：重金属污染、土壤修复、生物有效性、迁移转化
- 生态学：生物多样性、生态位、入侵物种、生态系统服务、碳汇
- 气候变化：全球变暖、碳中和、极端天气、适应性管理

**术语规范要求**：
- 首次出现需提供英文对照
- 遵循《环境科学名词》国家标准
- 避免口语化和非标准化表达

### 3. 数据与图表规范

**数据审查**：
- 数据的代表性和可靠性
- 统计方法的正确性（t检验、方差分析、相关性分析等）
- 有效数字的合理保留
- 误差棒和置信区间的标注

**图表规范**：
- 图题在图下方，表题在表上方
- 坐标轴标签完整，包含单位
- 图例清晰可辨
- 分辨率要求（位图≥300dpi，矢量图优先）

### 4. 参考文献格式

**中文期刊常用格式**：
- GB/T 7714-2015 标准
- 作者姓名的正确缩写
- 期刊全称与缩写的一致性
- 近5年文献占比建议≥60%

**常见错误**：
- 缺少年份、卷期、页码
- DOI号缺失或错误
- 文献类型标注错误

### 5. 中文学术语言润色

**表达优化原则**：
- 删除冗余词汇（如"本文"、"本研究"适量使用）
- 避免主观性强的词汇（如"最"、"极"、"首次"）
- 句式多样化，避免过长复合句
- 专业表述的精确性

**常见问题修正**：
- "通过...表明" → 客观陈述结果
- "证明了..." → 陈述发现
- "具有重要意义" → 具体阐述意义

## 审稿输出格式

### 综合审稿意见

```
【论文基本信息】
- 学科领域：[具体方向]
- 预估字数：[字数]
- 期刊类型：[SCI/EI/中文核心等]

【结构评价】
- 完整性：✓合格 / ⚠需补充
- 逻辑性：✓合格 / ⚠需调整
- 规范性：✓合格 / ⚠需修改

【主要问题】（按重要性排序）
1. [最关键问题] - 建议修改方式
2. [次要问题] - 具体修改建议
...

【语言润色建议】
- 段落/位置：修改前 → 修改后

【格式规范问题】
- 图表规范问题清单
- 参考文献格式问题
- 格式细节建议

【推荐修改优先级】
- P0（必须修改）：...
- P1（强烈建议）：...
- P2（可选优化）：...
```

## 使用流程

### 步骤1：接收论文

用户上传Word或PDF格式的中文环境科学论文。

### 步骤2：初步分析

快速扫描论文结构，识别：
- 论文类型（研究论文、综述、快报等）
- 涉及的环境科学分支
- 主要研究方法

### 步骤3：深度审稿

按照上述五大维度逐一审查，记录具体问题和修改建议。

### 步骤4：生成报告

输出结构化的审稿意见，包含：
- 总体评价
- 详细问题清单
- 具体修改建议
- 润色后的示例段落

### 步骤5：跟进修改

根据作者修改后的版本，提供进一步的意见。

## 质量标准

- 审稿意见的专业性：引用领域内通用标准
- 修改建议的可操作性：提供具体可执行的修改方案
- 语言润色的准确性：保持原意，优化表达
- 反馈的及时性：尽快完成审稿（根据论文长度调整）

## 注意事项

1. **保持客观中立**：以专业审稿人视角提供意见
2. **尊重作者意图**：在提出建议时考虑作者的研究思路
3. **关注创新点**：帮助作者突出研究的创新性和贡献
4. **符合期刊要求**：针对目标期刊的具体要求进行针对性审稿
5. **保密原则**：对论文内容严格保密
