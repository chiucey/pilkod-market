# 资产负债表分析技能

## 概述

这是一个专业的股票资产负债表分析技能，可以自动获取并分析股票最近5年的财务数据，生成标准格式的资产负债表分析表格。

## 功能特点

- 自动获取最近5年年度财务数据
- 自动获取最近一期季度/半年报数据
- 计算19项关键财务指标
- 自动生成数据趋势分析备注
- 支持标准表格格式输出

## 使用方法

### 触发条件

当用户提出以下请求时触发此技能：
- "分析XXX股票的资产负债表"
- "查询XXX的财务数据"
- "帮我分析XXX的偿债能力"
- "生成XXX的资产负债表表格"

### 输入要求

- 股票代码（如：601001、000001、600519等）
- 中国A股或港股代码

### 输出内容

1. **19项核心财务指标**：
   - 资产类：类现金、应收账款、存货、固定资产、流动资产、非流动资产
   - 负债类：有息负债、应付账款、负债总额、资产负债率
   - 现金流类：经营性净现金流、资本开支、自由现金流
   - 衍生指标：营运资金、净现金、可清算资产、每股净资产

2. **数据时间跨度**：
   - 最近5个完整财年
   - 最近一期季度/半年报

3. **分析备注**：
   - 现金储备评估
   - 负债率趋势分析
   - 现金流质量评估

## 技术实现

### 数据获取
- 使用 `stocks_financial_data` 工具获取完整财务数据
- 使用 `stocks_info` 工具确认股票信息

### 数据处理
- Python脚本处理原始财务数据
- 自动计算衍生指标
- 生成标准格式表格

### 输出格式
- Markdown表格格式
- 支持复制到Excel或其他工具
- 包含单位标注（亿元、%等）

## 注意事项

1. **数据来源**：使用股票行情API获取数据，可能存在数据延迟
2. **数据单位**：表格统一使用"亿元"，百分比使用"%"
3. **数据缺失**：某些特殊情况可能导致部分数据缺失，会在备注中说明
4. **时效性**：最近一期数据可能为估算值，最终以年报为准

## 常见问题

**Q: 支持港股吗？**
A: 支持，港股代码格式为如 0700.HK

**Q: 数据更新频率？**
A: 年度报告在财年结束后约3-4个月更新，季报约1-2个月

**Q: 如何解读表格？**
A: 参考表格最后一列"重要备注"，以及相关财务指标的行业对比
