# 资产负债表分析技能

## 功能概述

输入股票代码，自动查询该股票最近5年的年报财务数据和最近一期财务报表，按照标准格式生成资产负债表分析表格。

## 输入要求

- **股票代码**：用户提供的股票代码（如：601001、000001等）
- **数据范围**：最近5个财年 + 最近一期季报/半年报

## 数据获取流程

### 步骤1：获取股票基本信息

使用 `stocks_info` 工具获取股票基本信息，确认股票代码有效。

### 步骤2：获取财务数据

使用 `stocks_financial_data` 工具获取以下财务数据：
- 资产负债表 (Balance Sheet)
- 现金流量表 (Cash Flow)
- 利润表 (Income Statement)

### 步骤3：计算衍生指标

根据获取的原始财务数据，计算以下衍生指标：

1. **净现金** = 类现金 - 有息负债
2. **营运资金** = 应收账款 + 合同资产及存货 - 应付账款
3. **自由现金流** = 经营性净现金流 - 资本开支
4. **自由现金流占利润比重** = 自由现金流 / 全口径利润
5. **可清算资产** = 流动资产 - 负债总额

### 步骤4：生成分析备注

根据数据特征自动生成简要分析备注：
- 现金储备充裕/紧张
- 负债率变化趋势（上升/下降/稳定）
- 现金流质量评估
- 偿债能力评估

## 执行命令

### 数据获取

```python
# 获取股票信息
stocks_info(symbol="股票代码")

# 获取财务数据
stocks_financial_data(symbol="股票代码")
```

### 数据处理

从API返回的财务数据中提取并计算以下关键科目：

**资产负债表科目：**
- 货币资金/类现金 (Cash and Cash Equivalents)
- 应收账款 (Accounts Receivable)
- 存货/合同资产 (Inventories/Contract Assets)
- 应付账款 (Accounts Payable)
- 固定资产 (Fixed Assets)
- 短期借款/长期借款/有息负债 (Debt)
- 流动资产 (Current Assets)
- 非流动资产 (Non-current Assets)
- 总负债 (Total Liabilities)

**现金流量表科目：**
- 经营性现金流 (Operating Cash Flow)
- 资本开支 (Capital Expenditure)

**利润表科目：**
- 净利润 (Net Income)

**所有者权益：**
- 每股净资产 (Book Value per Share)

## 注意事项

1. **单位统一**：所有数值统一使用"亿元"或"百万元"，保持一致性
2. **百分比格式**：资产负债率和现金流占利润比重使用百分比显示
3. **负数处理**：用负号表示支出大于收入的情况
4. **数据缺失**：如果某年数据缺失，在备注中说明
5. **季度数据标注**：最近一期数据需标注是季度还是半年报

## 错误处理

- 股票代码无效：提示用户检查股票代码格式
- 数据获取失败：说明原因并提供手动查询建议
- 部分数据缺失：仅标注缺失部分，保留可用数据
