# 每日股票证券新闻分析与行业风险评估

## 核心功能

### 1. 新闻采集与汇总

**采集范围：**
- A股主板市场（上交所、深交所）
- 科创板（STAR Market）
- 创业板（ChiNext）
- 港股（H股、红筹股、民企股）
- 北向/南向资金动态

**采集内容：**
- 重要政策公告与监管动态
- 上市公司重大事项（并购重组、业绩预告）
- 行业政策与市场热点
- 机构研报摘要与评级变动
- 资金流向与市场情绪

### 2. 行业风险分析框架

**分析维度：**

| 分析维度 | 指标 | 数据来源 |
|---------|------|---------|
| 政策风险 | 行业政策变化、监管收紧程度 | 证监会、交易所公告 |
| 市场风险 | 行业估值分位、波动率 | 行情数据 |
| 流动性风险 | 成交额变化、资金流向 | 资金流向数据 |
| 基本面风险 | 盈利预期、行业景气度 | 财报、PMI数据 |
| 外部风险 | 国际市场传导、地缘政治 | 海外市场联动 |

**风险评级标准：**
- 🟢 低风险：政策支持、流动性充裕、基本面稳健
- 🟡 中风险：存在不确定性，需关注后续发展
- 🔴 高风险：负面因素集中释放，建议谨慎

### 3. 市场分类分析

#### A股主板分析
- 上证指数、深证成指成分动态
- 沪深300、中证500行业权重变化
- 蓝筹股与白马股动态

#### 科创板专项
- 科创50成分股动态
- 科创板IPO与再融资动态
- 硬科技行业（半导体、生物医药、新能源）专项分析

#### 港股专项
- 恒生指数、恒生科技指数成分动态
- 南向资金偏好变化
- 港股特有风险（汇率、海外流动性）

### 4. 输出报告模板

**每日新闻简报结构：**
```
📊 [日期] 每日股市新闻与行业分析

【市场概览】
- 主要指数表现
- 成交额与资金流向
- 市场情绪指标

【重要新闻摘要】
1. [新闻标题]
   - 来源：[媒体/官媒]
   - 影响：[行业/板块]
   - 点评：[简短分析]

【行业动态】
- [行业名称]
  - 风险等级：🟢/🟡/🔴
  - 主要驱动因素
  - 投资建议

【重点关注】
- 机会提示
- 风险预警

【北向/南向资金】
- 资金流向统计
- 重点加仓/减仓个股
```

## 执行工作流

### Step 1: 确定分析范围
用户指定或默认全市场覆盖：
- 明确是否包含A股/科创板/港股
- 指定重点关注行业（如有）
- 确定时间范围（今日/本周）

### Step 2: 新闻采集
使用 `batch_web_search` 采集：
```
搜索策略：
- 关键词组合：市场类型 + "今日新闻" + "行业动态"
- 政策新闻：证监会 + 交易所 + 最新公告
- 港股：恒生指数 + 港股 + 最新
```

### Step 3: 数据处理与分析
1. 提取关键信息：标题、来源、时间、影响范围
2. 分类整理：按市场板块、行业分类
3. 风险评估：应用风险分析框架评级

### Step 4: 生成报告
按报告模板结构化输出，包含：
- 量化数据（如涨跌幅、资金流入）
- 定性分析（趋势判断、风险提示）
- 可操作建议

## 数据源优先级

1. **官方渠道**（首选）：
   - 证监会官网
   - 上交所/深交所公告
   - 港交所披露易

2. **权威财经媒体**：
   - 东方财富网
   - 同花顺
   - 雪球
   - 华尔街见闻

3. **数据平台**：
   - Wind（如有）
   - Choice金融终端
   - 免费行情数据API

## 注意事项

- **时效性**：优先采集当日或前日新闻
- **来源验证**：重要政策信息需核实官方来源
- **风险提示**：分析内容仅供参考，不构成投资建议
- **差异化分析**：区分A股、科创板、港股特有风险因素

## 常见使用场景

1. **早盘准备**：「帮我汇总今日A股重要新闻」
2. **行业研究**：「分析最近一周新能源行业动态与风险」
3. **港股专项**：「港股今日有什么值得关注的新闻？」
4. **科创板研究**：「科创板最近有哪些政策利好？」
5. **风险预警**：「提示近期市场主要风险点」
