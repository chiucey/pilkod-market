## 数据接口

### 免费行情API
- **AKShare**: Python金融数据库，支持股票、基金、期货
- **Tushare**: A股数据接口，需要积分
- **BAOSTOCK**: 免费A股数据

### 示例查询
```python
# 使用AKShare获取A股数据
import akshare as ak
ak.stock_zh_a_spot_em()  # 获取实时行情
ak.stock_news_em(symbol="A股")  # 获取新闻
```

## 风险指标计算

### 市场风险指标
```
1. 波动率 = STD(日收益率) × √252
2. Beta = COV(个股, 市场) / VAR(市场)
3. VaR(95%) = 均值 - 1.65 × STD
```

### 流动性指标
```
1. 换手率 = 成交股数/流通股本 × 100%
2. 成交额变化率 = (当日 - 前日) / 前日 × 100%
3. 资金流向 = 主动买入 - 主动卖出
```

### 估值指标
```
1. PE = 股价 / 每股收益
2. PB = 股价 / 每股净资产
3. 股息率 = 股息 / 股价 × 100%
```
