# 行业风险评估框架

## 风险评分体系

### 综合风险评分（0-100）

| 分数 | 等级 | 颜色 | 含义 |
|-----|------|-----|------|
| 0-30 | 低风险 | 🟢 | 积极因素占主导，可适当参与 |
| 31-60 | 中风险 | 🟡 | 需关注不确定性，谨慎操作 |
| 61-100 | 高风险 | 🔴 | 风险因素集中，建议回避 |

## 各维度评估标准

### 1. 政策风险维度（权重25%）

| 指标 | 低风险 | 中风险 | 高风险 |
|-----|-------|-------|-------|
| 政策态度 | 明确支持 | 支持但有调整 | 收紧或限制 |
| 监管强度 | 正常监管 | 加强监管 | 严格限制 |
| 政策预期 | 可预期 | 存在不确定性 | 高度不确定 |

**评分标准：**
- 政策明确利好行业：+10分
- 政策中性：0分
- 政策收紧行业：+20分
- 政策禁止/严控：+30分

### 2. 市场风险维度（权重25%）

**估值风险评估：**
```
估值偏离度 = (当前PE - 历史均值PE) / 历史均值PE × 100%

- 偏离度 < -20%：低估（-5分）
- 偏离度 -20%~+20%：合理（0分）
- 偏离度 +20%~+50%：偏高（+10分）
- 偏离度 > +50%：泡沫（+20分）
```

**波动率风险：**
```
当前波动率 vs 历史波动率分位

- 分位数 < 30%：低波动（-5分）
- 分位数 30%~70%：正常（0分）
- 分位数 > 70%：高波动（+10分）
- 分位数 > 90%：极端波动（+20分）
```

### 3. 流动性风险维度（权重20%）

**成交活跃度：**
- 日均成交额 > 行业平均：充裕（0分）
- 日均成交额 50%~100%行业平均：一般（+5分）
- 日均成交额 < 50%行业平均：萎缩（+10分）

**资金流向：**
- 连续净流入：积极（-5分）
- 资金基本平衡：中性（0分）
- 连续净流出：消极（+10分）

### 4. 基本面风险维度（权重20%）

**盈利预期：**
- 行业净利润增速 > 10%：向好（-5分）
- 行业净利润增速 0%~10%：平稳（0分）
- 行业净利润增速 -10%~0%：下滑（+10分）
- 行业净利润增速 < -10%：恶化（+20分）

**行业景气度（PMI）：**
- PMI > 50 且环比上升：扩张（-5分）
- PMI > 50 且环比下降：趋缓（+5分）
- PMI < 50：收缩（+15分）

### 5. 外部风险维度（权重10%）

**国际市场联动：**
- 与美股相关性 < 0.3：低联动（0分）
- 与美股相关性 0.3~0.6：中等联动（+5分）
- 与美股相关性 > 0.6：高联动（+10分）

**汇率敏感性：**
- 出口占比 < 10%：低敏感（0分）
- 出口占比 10%~30%：中等敏感（+5分）
- 出口占比 > 30%：高敏感（+10分）

## 行业风险示例

### 半导体行业（示例）

**当前风险评分：45分（🟡中风险）**

| 维度 | 评分 | 说明 |
|-----|------|-----|
| 政策风险 | +5 | 国家政策支持半导体自主可控 |
| 市场风险 | +15 | 估值偏高，波动率较大 |
| 流动性风险 | +10 | 成交活跃但近期有所萎缩 |
| 基本面风险 | +10 | 国产替代逻辑持续，盈利改善 |
| 外部风险 | +5 | 存在出口管制风险 |

**结论**：行业长期逻辑清晰，但短期估值和外部风险需关注，建议定投方式参与。

### 银行业（示例）

**当前风险评分：25分（🟢低风险）**

| 维度 | 评分 | 说明 |
|-----|------|-----|
| 政策风险 | 0 | 监管稳定 |
| 市场风险 | 0 | 估值合理，波动低 |
| 流动性风险 | +10 | 成交活跃度一般 |
| 基本面风险 | +10 | 净息差承压 |
| 外部风险 | +5 | 资产质量需关注 |

**结论**：防御性行业，适合保守型投资者，关注资产质量变化。

### 房地产行业（示例）

**当前风险评分：70分（🔴高风险）**

| 维度 | 评分 | 说明 |
|-----|------|-----|
| 政策风险 | +20 | 房住不炒总基调 |
| 市场风险 | +15 | 销售下行，库存高企 |
| 流动性风险 | +15 | 资金紧张，违约频发 |
| 基本面风险 | +15 | 盈利大幅下滑 |
| 外部风险 | +5 | 需求端疲弱 |

**结论**：风险集中释放期，建议回避，等待行业出清信号。

## 风险预警信号

### 红色预警（需立即关注）
- 🔴 政策突变（突然出台限制性政策）
- 🔴 龙头企业违约/暴雷
- 🔴 大规模资金外逃（单日净流出 > 行业流通市值5%）
- 🔴 行业PMI跌破45

### 黄色预警（需密切关注）
- 🟡 监管风声趋紧
- 🟡 主要客户流失
- 🟡 库存异常积累
- 🟡 重要高管变动

### 绿色信号（积极关注）
- 🟢 政策明确支持
- 🟢 技术突破/订单爆发
- 🟢 龙头公司回购
- 🟢 行业并购整合

## 更新频率建议

| 市场状态 | 建议更新频率 |
|---------|------------|
| 正常市场 | 每日收盘后更新 |
| 市场波动加大 | 每4小时更新 |
| 重大政策出台 | 事件驱动即时更新 |
| 财报季 | 周频增加业绩追踪 |
