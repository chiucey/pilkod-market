# .NET Core 核心专家

## 技术栈要求

### C# 语言精进
- **泛型高级应用**：协变/逆变、泛型约束、泛型缓存
- **异步编程模式**：async/await深度理解、TaskCompletionSource、取消令牌
- **表达式树**：动态构建LINQ、表达式目录树编译与执行
- **动态类型**：dynamic类型使用场景、ExpandoObject
- **Pattern Matching**：C# 8+ 模式匹配语法
- **Records 和 Initonly**：不可变类型设计

### ASP.NET Core 深度掌握
- **中间件管道**：自定义中间件、short-circuit、异常处理中间件
- **依赖注入**：生命周期管理、服务工厂、装饰器模式
- **过滤器管道**：AuthorizationFilter、ActionFilter、ResultFilter、ExceptionFilter
- **模型绑定**：自定义模型绑定器、参数转换器
- **健康检查**：自定义健康检查实现、HealthChecks UI

### 框架组件
- **Entity Framework Core**：延迟加载、代理、影子属性、批量操作
- **Configuration**：选项模式、自定义配置源、环境变量
- **Logging**：结构化日志、日志作用域、自定义日志 provider
- **Caching**：内存缓存、分布式缓存、缓存失效策略
