# 热点资讯分析框架

## 一、热点筛选标准

### 热度指标
| 指标 | 权重 | 说明 |
|------|------|------|
| 时效性 | 30% | 事件发生时间，越近越有价值 |
| 关注度 | 25% | 搜索量、讨论量、转发量 |
| 争议性 | 20% | 观点分歧越大，讨论越充分 |
| 相关性 | 15% | 与目标受众的关联程度 |
| 延展性 | 10% | 可深挖、可系列化的空间 |

### 热点分类
1. **突发新闻**：重大事件，需要快速反应
2. **持续热点**：多日发酵，可深度分析
3. **周期性热点**：节日、节点、季节性话题
4. **长期话题**：经典议题，常做常新

## 二、内容角度选择

### 常见角度类型
- **是什么**：科普解读型
- **为什么**：原因分析型
- **怎么看**：观点评论型
- **怎么办**：实用建议型
- **谁在做**：人物故事型

### 角度选择决策树
```
热点事件
├── 如果是政策类 → 解读影响角度
├── 如果是科技类 → 技术原理角度
├── 如果是社会类 → 民生关联角度
├── 如果是娱乐类 → 八卦故事角度
└── 如果是商业类 → 商业模式角度
```

## 三、受众分析

### 核心受众画像
- 年龄段
- 职业背景
- 关注领域
- 收听场景（通勤/运动/睡前）
- 内容偏好（深度/轻松/实用）

### 内容深度把控
| 受众类型 | 内容深度 | 语言风格 |
|---------|---------|---------|
| 专业型 | 深度的专业知识 | 术语准确 |
| 大众型 | 通俗易懂 | 比喻解释 |
| 年轻型 | 趣味性强 | 梗多网感 |
| 商务型 | 效率优先 | 精简干练 |

## 四、信息核实清单

在撰写文稿前，必须确认：

1. [ ] 事件基本信息准确
2. [ ] 数据来源可靠
3. [ ] 当事人回应已获取
4. [ ] 时间线清晰
5. [ ] 专业术语解释清楚
6. [ ] 避免未经证实的传言
7. [ ] 注意敏感内容边界

## 五、快速产出流程

### 10分钟产出法
1. **2分钟**：搜索热点，确定主题
2. **3分钟**：快速阅读3-5篇相关报道
3. **2分钟**：确定角度和结构
4. **3分钟**：撰写核心段落
5. **即时**：添加开场和结尾

### 质量检查点
- [ ] 有没有吸引人的开场？
- [ ] 逻辑线清晰吗？
- [ ] 关键信息有没有遗漏？
- [ ] 节奏适合收听吗？
- [ ] 结尾有没有记忆点？
