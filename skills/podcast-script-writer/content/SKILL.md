# 播音专员

将热点资讯快速转化为专业播客文稿的技能。

## 核心能力

- 热点资讯分析与提炼
- 播客结构化文稿设计
- 主播风格语言优化
- 节奏停顿标记
- 多场景适配

## 工作流程

### 1. 热点获取与分析

当用户提供热点话题时：
- 识别核心事件和关键信息
- 提炼受众关注的痛点
- 确定内容角度和深度

当用户未提供热点时：
- 使用网络搜索获取最新热点资讯
- 优先选择时效性强、受众广泛的话题
- 筛选具有讨论价值的素材

### 2. 结构设计

标准播客结构：
```
[开场]
- 问候语 + 节目名称
- 今日主题预告
- 吸引听众的开场钩子

[主体内容]
- 背景介绍（30秒）
- 核心事件解读（2-3分钟）
- 延伸分析与观点（1-2分钟）
- 案例或故事（可选）

[互动环节]
- 引发思考的问题
- 听众互动引导

[收尾]
- 内容总结
- 下期预告（可选）
- 结束语
```

### 3. 文稿撰写规范

**语言风格**：
- 口语化表达，自然流畅
- 避免书面语的生硬感
- 使用短句，便于呼吸停顿
- 适当使用语气词增加亲切感

**节奏控制**：
- 关键信息前后留白
- 数据和观点分开展现
- 故事叙述有起伏
- 高潮点使用强调语气

### 4. 节奏标记

在文稿中加入以下标记：
```
[P] - 停顿（1-2秒）
[PP] - 长停顿（3秒）
[BGM] - 背景音乐切换
[TONE:兴奋] - 语气指示
[TONE:低沉] - 语气指示
```

## 输出格式

生成完整的播客文稿，包含：

1. **标题**：节目名称 + 主题
2. **时长预估**：建议录音时长
3. **完整文稿**：带节奏标记的脚本
4. **补充素材**：背景资料、数据来源（可选）

## 适配场景

| 场景 | 文稿风格 | 时长建议 |
|------|---------|---------|
| 新闻解读 | 客观严谨，信息密集 | 5-8分钟 |
| 热点分析 | 观点鲜明，节奏明快 | 8-12分钟 |
| 知识科普 | 深入浅出，案例丰富 | 10-15分钟 |
| 娱乐资讯 | 轻松活泼，互动感强 | 5-10分钟 |
| 深度访谈 | 逻辑清晰，问题导向 | 15-20分钟 |

## 质量标准

优秀播客文稿的特征：
- 开场3秒抓住注意力
- 逻辑清晰，易于跟随
- 节奏感强，不拖沓
- 情感真实，有代入感
- 结尾有记忆点
