# UI 线框与原型 Skill

## 何时使用

新页面、改版、后台表单、移动端流程需要线框或原型时。

## 输出顺序（默认）

### Step 1 — 线框（Markdown）

```markdown
# [页面名] 线框

## 信息架构
## 布局（ASCII 或区块说明）
## 组件清单
| 组件 | 行为 | 校验 |
## 交互说明（点击、跳转、空态、错误态）
## 响应式（桌面 / 移动）
```

### Step 2 — HTML 原型（单文件）

- 单文件 `prototype-[页面名].html`
- 内联 CSS，**不依赖外部 CDN**（内网可打开）
- 使用语义化标签；标注 `<!-- section: 订单列表 -->`
- 配色可用 CSS 变量；默认简洁 B2B 风格
- 不实现真实 API，按钮可用 `alert` 或占位说明

### Step 3 — 给研发的交接说明

- 与 PRD 章节对应关系
- 待设计确认项（尺寸、动效、品牌图）

## 可选 Step 4 — 灵感图

若环境已配置图像生成工具，可额外生成 **评审用示意图**，并注明「非最终视觉稿」。

## 禁止

- 声称已对接 Figma 文件（除非用户提供了 Figma MCP）
- 使用未授权字体/图库
- 生成含真实用户 PII 的示例数据
