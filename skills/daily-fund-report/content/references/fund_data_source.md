# 基金净值数据源说明

## 天天基金网（东方财富）

### 实时净值估算 API

**接口地址**：
```
https://fundgz.1234567.com.cn/js/{fund_code}.js
```

**参数说明**：
- `fund_code`: 6位基金代码
- `rt`: 时间戳（可选，用于绕过缓存）

**返回格式**：
```json
jsonpgz({
  "fundcode":"000001",
  "name":"平安先锋混合A",
  "jzdate":"2024-12-19",
  "dwjz":"1.4645",
  "gsz":"1.4734",
  "gszzl":"0.61",
  "gztime":"2024-12-20 15:00"
})
```

**字段说明**：
| 字段 | 说明 |
|------|------|
| fundcode | 基金代码 |
| name | 基金名称 |
| jzdate | 最近净值日期 |
| dwjz | 昨日净值（单位净值） |
| gsz | 估算净值（盘中更新） |
| gszzl | 估算增长率(%) |
| gztime | 估算时间 |

### 历史净值 API

**接口地址**：
```
https://api.fund.eastmoney.com/f10/lsjz
```

**参数说明**：
| 参数 | 说明 |
|------|------|
| callback | 回调函数名（jQuery） |
| fundCode | 基金代码 |
| pageIndex | 页码 |
| pageSize | 每页数量 |
| startDate | 开始日期 |
| endDate | 结束日期 |

## 注意事项

1. **数据更新时机**：
   - 盘中：返回估算净值（基于持仓估算）
   - 收盘后（约16:00）：返回实际净值
   - 非交易日：无数据返回

2. **请求频率**：
   - 建议每次请求间隔 >= 0.5秒
   - 避免短时间内大量请求

3. **错误处理**：
   - 基金代码错误：返回默认数据
   - 网络超时：建议重试3次
   - 接口维护：备用方案为爬取网页
