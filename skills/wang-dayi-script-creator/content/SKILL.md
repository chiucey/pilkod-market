# 王大艺剧本创作技能

基于800集核心情节、60万字素材库的完整创作方法论。

## 创作前准备

### 创意发现清单（先完成这个）

在正式进入9步流程前，先回答以下问题：

1. **空间关系**：我家窗户/阳台/门能看到什么？
2. **权力关系**：谁能用更高权力压制谁？
3. **语言关系**：哪句常用话换什么词能产生笑点？
4. **阻力设计**：主角的"借口"是什么？（不是不能，是懒得/不想）
5. **道具三出现**：场景里什么东西出现3次后再当反转工具？
6. **金句结尾**：这个剧本的"轻松拿捏"是什么？

## 9步创作流程

### STEP 1: 锁定选题

**核心原则**：选对主题，剧本就成功了一半。

#### 爆款主题速查表（按优先级）

**高热主题（优先选）**：
- 家访 - 老师身份天然制造戏剧冲突
- 家长会 - 情感浓度最高，适合温情+反转
- 班会 - 半封闭场景，冲突集中
- 期末成绩 - 悬念感天然
- 马上开学 - 假期结束情绪反差
- 网课 - 居家场景，真实感强
- 分班 - 成长节点，仪式感结尾

**稳定主题**：
- 假期/出行、零食、家长开放日
- 叫家长去学校、一起上学/在教室、转学来学校

**补充主题**：
- 购物/消费、课外班/培训、电子产品/游戏
- 亲子沟通/温情、毕业/典礼

#### 五维灵感公式（选题验证）

选好主题后，用五维公式验证：
```
【生活场景】×【家长痛点】×【身份错位】×【反转】×【温情落点】
```
- 五维全开 = 爆款潜质
- 缺一维 = 及格
- 缺二维 = 方向跑偏

#### 五维验证表

| 维度 | 检查问题 | 常见答案 |
|------|----------|----------|
| ①生活场景 | 什么场景触发？ | 回家路上/饭桌/卧室/上学前 |
| ②家长痛点 | 家长最大焦虑？ | 成绩/视力/健康/花钱/没时间 |
| ③孩子痛点 | 孩子最怕什么？ | 被骂/加卷子/被比较/没收手机 |
| ④身份错位 | 谁的身份造成错位？ | 爸爸是老师/妈妈说一套做一套 |
| ⑤反转落点 | 反转点和温情落点？ | 签名反转/惊喜/温情和解 |

### STEP 2: 选人设锚

**核心原则**：选今天谁是主视角，决定食物链关系和戏剧张力。

#### 王大艺家食物链

```
妈妈 > 女儿 > 爸爸（名义权威）
爸爸管女儿，女儿拉妈妈入场反将
```

| 主视角 | 特点 | 弱点 |
|--------|------|------|
| 爸爸 | 管教女儿/支配家庭资源 | 被妈妈逻辑碾压、被女儿借力 |
| 妈妈 | 逻辑大师/家庭CEO | 偶尔对爸爸表面配合时被看穿 |
| 女儿 | 聪明反叛/神补刀 | 面对爸爸真情流露时容易破防 |

#### 欧文家角色池（备选）

| 角色 | 定位 | 性格特点 | 弱点 |
|------|------|----------|------|
| 倪炳（爸爸） | 理工爸/规划脑 | 爱画表格讲底层逻辑，控制欲强但经常被打脸 | 双标/爱算账/情绪上头 |
| 欧文（大儿子） | 2年级/偏佛 | 能听懂爸爸逻辑，会反怼爸爸 | 表面听话，暗中观察 |

### STEP 3: 套前5秒引子

**核心原则**：开头决定留存率。前5秒没有钩子，观众直接划走。

#### 引子选择四原则

1. **前3秒必须有异常事件或冲突预告**，不能平铺直叙
2. **最好有声音钩子**：喊声/疑问句/感叹句/突发状况声
3. **画面信息量要低**：观众不需要思考就知道发生了什么
4. **引子要和本集核心困境直接挂钩**，不放无关信息

#### 各主题前5秒引子精选

**家访**：
- "你赶紧准备一下，老师来家访了，什么情况？"（慌乱+紧张感）
- "老师你来的真快！等一下，我还没收拾好……"（反差+喜剧）
- "爸，家访老师来了……爸你快起来！"（爸爸在睡觉的经典场景）

**家长会**：
- "七点的家长会我六点就到了，老师我来了！"（主动出击型）
- "不是七点才开家长会吗，你怎么这么早？"（信息差喜剧）
- "老师，我都替你看完了，你回家吧"（反转+爸爸大冤种）

**班会**：
- "视频班会中，我现在在开班会，有的同学就在底下玩……"（真实感+吐槽）
- "老师点名怎么没点我的名？"（孩子视角+委屈感）
- "开会的时候小点声，我关静音了……我这边听得到！"（反转+尴尬）

**网课**：
- "妈，我卡出来进不去了……"（技术问题+孩子真实反应）
- "上课了还在啃鸭脖子……给，塞给爸爸手里啃"（吃零食+爸爸接锅）
- "爸爸拿着坐在电脑前——老师就在面前，进不去现场直播"（最高级反转）

**马上开学**：
- "明天就开学了，作业还没写完……"（共鸣最强）
- "爸，我不想上学……"（孩子视角开场）
- "还有一张卷子没做——爸你说很快就好？"（时间陷阱反转）

**期末成绩**：
- "考试成绩还没出来，我先去探探风声"（悬念+行动）
- "妈，成绩出来了……你猜我考了多少？"（悬念+孩子得意）
- "爸这次没发火，我觉得不对劲……"（反差+悬念）

**购物/消费**：
- "爸，今天商场打折，我们去买点东西吧"（诱惑爸爸）
- "这个多少钱？——便宜，买了"（爽快爸爸掏钱傻眼）
- "妈，我看中了一个……"（拉妈妈入场助攻）

**亲子沟通**：
- "爸，你能不能认真听我说完？"（孩子视角+诉求感）
- "妈妈你说句公道话！"（拉第三方入场）
- "我觉得我爸……其实挺好的"（傲娇开场+温情预告）

#### 引子类型模板

| 引子类型 | 模板公式 | 效果 |
|----------|----------|------|
| 异常事件型 | 突然事件发生了，___ | 突发状况，必须立刻处理 |
| 疑问句型 | ___，怎么回事？ | 用疑问制造悬念，引导观众追问 |
| 反差对比型 | ___（正常），结果___（异常） | 制造喜剧和悬念效果 |
| 喊话型 | ___！ | 用喊声吸引注意力，真实感强 |
| 道具型 | ___（拿着某个物品），这个___ | 用物品引出话题 |

### STEP 4: 设计困境

**核心原则**：困境是剧本的发动机。没有困境，就没有戏剧张力。

#### 困境的本质

困境的本质：**一方想做一件事，另一方或客观条件不让做**

好的困境：
1. 观众在生活中真的遇到过（代入感）
2. 解决它需要付出代价（两难选择）
3. 结果出乎意料（反转空间）

#### 困境分类表（56条精选）

**学习类**：
- 孩子不想做作业/复习/考试 → 用利诱/威胁/时间差绕过
- 爸爸布置额外卷子 → 求助妈妈+反将爸爸

**成绩类**：
- 考试成绩不理想 → 报喜不报忧/找借口/求妈妈帮忙

**规则类**：
- 没穿校服被扣分 → 用双关/逻辑反将爸爸
- 爸爸定家规太严 → 拉妈妈入场投票碾压

**消费类**：
- 想买某样东西爸爸不让 → 妈妈签字转移/先斩后奏
- 爸爸承诺买东西不兑现 → 录音留证/抓住把柄

**电子产品类**：
- 想玩手机/看视频被限制 → 时间差偷玩/借爸爸名义

**亲子类**：
- 爸爸太忙没时间陪孩子 → 温情偷袭/制造爸爸内疚
- 爸爸管教太严/太凶 → 借妈妈之力/用爸爸的话反将

**其他类**：
- 孩子之间发生矛盾 → 爸爸站队/妈妈调解
- 孩子生病/受伤 → 温情照顾/趁机提条件
- 假期不能出去玩 → 苦情+交易：用条件换出行
- 被要求做家务不想做 → 拖延/转移/让爸爸做
- 被嘲笑外表/打扮 → 爸爸趁机施压/妈妈护短

### STEP 5: 填五幕式结构

**核心原则**：用五幕式框架把剧本骨架搭出来，再填肉。

#### 五幕式详解

| 幕 | 名称 | 核心任务 | 时长 |
|----|------|----------|------|
| 第1幕 | 开场引入 | 抛出日常场景+异常事件，观众立刻代入 | 15-20秒 |
| 第2幕 | 设局/积压 | 矛盾放大，受害者入局，旁观者观望 | 20-30秒 |
| 第3幕 | 入局/升级 | 中招方反应+旁观者内心OS，喜剧效果积累 | 20-30秒 |
| 第4幕 | 反转揭晓 | 反转信息揭晓，中招方崩溃，全场爆点 | 15-20秒 |
| 第5幕 | 温情落点 | 家庭和解，具体动作收尾，不能说教 | 10-15秒 |

#### 完整剧本填空模板

**【第1幕：开场引入】15-20秒**

- 目的：让观众快速代入，这事我也遇到过

### STEP 6: 植入反转

**核心原则**：反转是灵魂。没有反转的剧本，等于没有灵魂的躯壳。

#### 五大反转类型

| 反转类型 | 前提 | 转折 | 台词 | 效果 |
|----------|------|------|------|------|
| **类型一：签名主体反转** | 妈妈答应签字 | 签的原来是爸爸的名字 | "我签的是你的名，爸爸买单" | 最高频，妈妈标志武器 |
| **类型二：身份角色反转** | 爸爸设局想整女儿 | 结果自己成了大冤种 | "这事好办……我怎么又……" | 爸爸自恋人设的必然结局 |
| **类型三：证据信息反转** | 爸爸拿证据施压 | 证据失效或被打脸 | "我有课堂回放……视频里没拍到……" | 权威崩塌的经典时刻 |
| **类型四：情感预期反转** | 以为爸爸不爱/不在乎 | 结果默默准备惊喜 | "这……这是给我的？" | 温情落点的关键手段 |
| **类型五：计划行动反转** | 计划看似稳了 | 中途被打乱完全相反 | "这事稳了……"结果完全相反 | 制造意外的常用手段 |

#### 7大万能公式（可直接套用）

| 公式 | 结构 | 说明 |
|------|------|------|
| **公式一：签字转移** | 妈妈答应 -> 签爸爸名 -> 爸爸买单 | 妈妈答应实际签爸爸名爸爸买单 |
| **公式二：调虎离山连环套** | 连环任务套住爸爸 -> 女儿趁机行动 -> 揭晓全是安排 | 连环设套让爸爸疲于奔命 |
| **公式三：逻辑绕晕双关** | 爸爸设规则 -> 妈妈用同一规则反将 -> 投票2:1碾压 | 把爸爸规则复制粘贴到爸爸身上 |
| **公式四：先惊后喜温情偷袭** | 爸爸先施压/拒绝 -> 制造意外惊喜 -> 父女温情和解 | 前半段紧张后暖心 |
| **公式五：借力打力联盟碾压** | 女儿拉妈妈入场 -> 2:1碾压爸爸 -> 投票制服 | 借妈妈之力形成人数优势 |
| **公式六：证据反击自我打脸** | 爸爸拿证据施压 -> 证据失效 -> 爸爸颜面尽失 | 铁证总是因关键细节失效 |
| **公式七：女儿补刀翻盘** | 爸爸刚失误 -> 女儿精准吐槽 -> 全场爆笑 | 最后一刀让喜剧效果拉满 |

### STEP 7: 写台词

**核心原则**：台词是角色的声音。每句台词都要让人物活起来。

#### 台词三原则

1. **每句台词只说一件事**，不能超过15个字（含语气词）
2. **对话要有来有往**，不能一方一直说另一方没反应
3. **每5句台词要有一个动作提示**，让人动起来

#### 爸爸台词库

**施压型（开场用）**：
- "去，把作业拿来检查一下。"
- "半小时爸爸都没来，刚要歇一会儿爸爸就进来了"
- "再做错简单的题就不要签字了"
- "我在学校是班主任，回到家还是你班主任"

**大冤种型（反转后用）**：
- "完喽……"
- "大意了……没想到……"
- "我这张老脸往哪搁……"
- "这闺女我是真教不了了"
- "当场石化，沉默三秒"

**温情型（结尾用）**：
- "行吧，这次就算了。"
- "赶紧吃饭，菜都凉了。"
- "下次考好点，爸爸给你买。"
- "你也不容易。"

#### 妈妈台词库

**设套型（中间用）**：
- "这事我不表态，你俩商量。"
- "我签的是你的名，又不是我的名。"
- "他也没穿裤子啊，扣不扣？"
- "表现怎么样，你心里没点数吗？"

**补刀型（反转后用）**：
- "我说什么来着？"
- "完了吧，大意了吧。"
- "你这爸爸当的，啧啧啧。"
- "默默拿出手机录像"

**温情型（结尾用）**：
- "行了行了，别说了，吃饭。"
- "你们俩啊……一个比一个气人。"
- "把菜往爸爸碗里夹，少说两句。"

#### 女儿台词库

**撒娇/耍赖型**：
- "妈～爸又欺负我！"
- "我不，我就要！"
- "这不公平！"

**补刀型（关键用）**：
- "爸，你太老了。"
- "完喽爸"（学爸爸语气）
- "妈，他说的是什么意思？"
- "你自己说的，不许反悔。"

**录音留证型**：
- "爸，你再说一遍，我录个音。"
- "你说的啊，我可不傻。"
- "你说的就是98分，你说的！"

**瞬间乖巧型（被识破后）**：
- "爸我错了，我这就做"
- "爸～我知道错了嘛"

#### 凯文话术原声库（欧文家专属）

凯文是欧文家最独特的角色，台词自带喜剧效果：
- "爸爸买玩具！快走走！"
- "哥哥他打我！"
- "我要看手机！看两分钟！"
- "婆婆你过来嘛！"
- "你傻了吧你听到没有！"
- "我说啥，我开枪啦喝呆呆！"
- "吃了就没有命了！"（吃饭时）
- "玩具到了没？"（催促快递）
- "妈，我不喜欢爸爸"（直接型）

### STEP 8: 检查落点

**核心原则**：结尾决定转发率。好的结尾让观众想转发给家人。

#### 温情落点检查（4问）

| 问题 | 要求 |
|------|------|
| 落点是家还是道理？ | 必须落家，不是落谁对谁错 |

#### 温情结尾模板（直接使用）

**动作落点**：
- 说明：夹菜/揉头/拍肩/给台阶
- 示例：别说了，吃饭。+把肉夹到对方碗里

**金句落点**：
- 说明：一句话收尾，留下余味
- 示例：你就嘴硬。下次还这样啊。行了，少说两句。

**反转温情型**：
- 说明：先反转再温情，反差感更强
- 示例：爸爸崩溃 -> 女儿悄悄给他倒杯水 -> 爸爸假装没事

**集体仪式型**：
- 说明：全家一起做某件事收尾
- 示例：一起吃饭/一起拍照/一起出门，形成家庭感画面

#### 常见失败模式

- ❌ 反转太多：一部剧只应有一个核心反转，多了会乱
- ❌ 说教太多：结尾讲道理，观众尴尬，不转发
- ❌ 爸爸太坏：让观众讨厌而不是觉得好笑，失去了喜剧本质
- ❌ 妈妈太正确：妈妈也需要偶尔失误才可爱
- ❌ 温情太满：结尾太煽情，观众尴尬症发作
- ❌ 中间塌掉：第3幕入局不够扎实，反转就显得突兀
