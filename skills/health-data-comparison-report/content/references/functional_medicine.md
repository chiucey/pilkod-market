# Functional Medicine Root-Cause Section (疾病底层逻辑·功能医学视角)

Framework source: 曾强主编《功能医学概论》（人民卫生出版社, 2016）— "七大生理失衡"理论.

## Purpose

Add one section that tells the client, in plain language, WHY their abnormal indicators appeared — the underlying imbalance, not a disease name. One read should answer "身体到底哪个环节出了问题，最底层的原因是什么".

## Core Logic Chain (Use as the section's opening frame)

功能医学的基本逻辑，用一句话讲给客户：

**不健康的生活方式与环境暴露（饮食、营养、毒素）→ 身体某些生理系统失衡 → 化验指标出现异常 → 长期失衡累积成器官损伤 → 疾病**

Key tenet to convey: 指标异常是"结果"，系统失衡是"原因"，生活方式是"根源"。疾病不是突然发生的，是失衡长期累积的结果——这正是体检数据纵向对比的意义。

## The Seven Physiological Imbalances (七大生理失衡)

Map the member's abnormal data to these seven systems. Pick ONLY the ones the data actually signals.

| # | 失衡系统 | 一句话解释（可直接改写使用） | 报告中对应的指标/检查线索 |
|---|---------|--------------------------|--------------------------|
| 1 | 消化、吸收与菌群失衡 | 肠道是营养吸收和免疫的第一道关口，菌群失调、"肠漏"会让吸收变差、炎症因子入血 | 白蛋白、Hb/MCV（贫血）、胃肠镜发现（息肉、炎症）、幽门螺杆菌、维生素D缺乏 |
| 2 | 免疫与炎症失衡 | 免疫系统长期"小火慢炖"（慢性低度炎症），或错误攻击自身组织 | WBC、中性粒细胞比例、尿潜血、自身抗体（如TPOAb）、慢性病灶反复、食物不耐受相关病症 |
| 3 | 解毒与生物转化失衡 | 肝脏是身体的"解毒工厂"，酒精、药物、环境毒素长期超负荷后解毒效率下降 | ALT、AST、GGT、胆红素、脂肪肝、饮酒史、长期用药史 |
| 4 | 内分泌与激素失衡 | 激素是身体的"调度系统"：压力轴（皮质醇）、血糖轴（胰岛素）、甲状腺轴节奏紊乱 | 空腹血糖、HbA1c、胰岛素、C肽（胰岛素抵抗）；TSH、FT3、FT4、甲状腺结节；血压、腰围 |
| 5 | 氧化还原失衡 | 线粒体是细胞的"发电厂"，自由基攻击超过抗氧化清除能力，血管和细胞加速"生锈"老化 | Hcy、血尿酸、尿微量白蛋白/UACR、血压升高、动脉硬化/斑块影像 |
| 6 | 循环运输失衡 | 血脂是血管里的"运输车队"，比例失衡后脂质沉积血管壁，运输通道变窄 | TG、TC、LDL-C、HDL-C、ApoA1/B、颈动脉/下肢动脉斑块、冠脉钙化 |
| 7 | 结构性失衡 | 骨骼肌肉是身体的"承重框架"，长期姿势不良、劳损、缺钙导致结构变形退变 | 骨密度（T值）、腰椎/颈椎影像退变、血钙、维生素D、体重负荷 |

## Cause Attribution (前置-诱发-媒介三层次)

When explaining causes, apply the book's three-layer attribution:
- **前置因素**: 年龄、家族史、既往病史（无法改变，只用于解释风险基础）
- **诱发因素**: 饮食结构、饮酒、久坐、熬夜、压力、药物（可改变，是干预抓手，写作重点）
- **媒介因素**: 已存在的失衡互相放大（如胰岛素抵抗加重炎症，炎症加重血管损伤）

Writing effort goes to 诱发因素 — they connect directly to the lifestyle prescription.

## Writing Rules

1. **Only explain what the data shows**: choose 2-4 imbalance systems actually signaled by THIS member's abnormal data. Never list all seven mechanically. No data support = no mention.
2. **Mechanism, not diagnosis**: describe the imbalance and its common drivers; never name or confirm a disease beyond the source reports, never contradict physician diagnoses.
3. **Each chosen system gets one short block** answering in order: ①哪个指标异常（带真实数值）②说明哪个系统环节失衡（可用一个生活化比喻，如"解毒工厂超负荷""细胞发电厂效率下降"）③最常见的诱因（与会员已知的饮食/饮酒/用药/运动/睡眠情况相符）.
4. **Structure**: opening 1-2 lines stating the logic chain (输入→失衡→指标异常→疾病) → 2-4 system blocks, each with a small bold heading (e.g., "① 激素失衡：血糖升高的底层原因") → closing 1-2 sentences bridging to the follow-up/lifestyle section (本节解释"为什么"，下一节给出"怎么做"——do not duplicate specific actions here).
5. **Length**: half a page to one page. Simple and clear beats comprehensive.
6. De-identification and anti-AI writing rules from SKILL.md apply here as everywhere: no "值得注意的是/综上所述", no hedging speculation, short sentences, one idea per sentence.

## Correct vs Wrong Example

- **Correct**: "空腹血糖连续三次超过7.0 mmol/L，HbA1c 7.3%。这组数据指向内分泌系统的胰岛素轴失衡：细胞对胰岛素越来越不敏感，吃进去的糖进不了细胞，只能留在血液里。最常见的诱因是精制碳水摄入多、运动不足和腹型肥胖。"
- **Wrong**: "值得注意的是，血糖问题可能意味着糖尿病前期，综上所述需要高度重视……"（AI腔、下诊断、空泛）
