# Layout Optimization Reference - 排版优化指南

## 核心排版原则

1. **信息密度最大化** - 减少空白，紧凑排列
2. **视觉层次分明** - 通过字号/颜色/间距建立清晰层级
3. **表格与图表联动** - 每个表格配一张趋势图，形成"表+图"组合
4. **一页一主题** - 每个生理系统尽量在一页内完成（表格+图表+解读）

## 页面布局规范

### A4 页面参数
- 页面: A4 portrait (210mm x 297mm)
- 页边距: 上2.8cm / 下2cm / 左2cm / 右2cm
- 可用宽度: 17cm
- 可用高度: 24.7cm

### 信息密度控制
- 每页有效内容区域 >= 85%
- 禁止大面积留白(>3cm空白区域)
- 表格后紧跟图表，禁止跨页断裂

## 模块排版顺序

每个生理系统模块的固定排版顺序:

```
[系统标题 h2]                    <- 12pt bold #005293, 距上方内容 16pt
[系统说明 1-2行]                 <- 10pt #333333, 行距1.4
[空白 8pt]
[数据对比表格]                    <- 表头9pt, 数据8.5pt
[空白 6pt]
[趋势折线图]                      <- 图表宽度与表格同宽
[空白 4pt]
[关键发现 2-3行]                  <- 10pt, 直接结论, 无AI味
[空白 12pt]                       <- 模块间距
[下一模块]
```

## 表格排版优化

### 列宽分配
- 第一列(指标名): 25% 宽度, 左对齐, #eef1f5背景
- 参考区间列: 15% 宽度, 居中
- 各时间点列: 等分剩余宽度, 居中
- 最少列数保证: 指标名 + 参考区间 + >=2个时间点

### 行高控制
- 表头行高: 24pt
- 数据行高: 20pt
- 表格总高度控制: 单表不超过页面高度的50%

### 多页表格处理
- 禁止单个表格跨页
- 如数据过多，拆分为多个子表格(如: 血常规拆为细胞计数+分类计数)
- 每个子表格配独立的趋势图

## 图表排版优化

### 图表尺寸
- 标准图: 宽度=可用宽度(17cm), 高度=7cm
- 双Y轴图: 宽度=17cm, 高度=7.5cm
- 子图组合: 宽度=17cm, 高度=10cm(2行子图)

### 图表位置
- 图表必须紧跟在对应表格之后
- 图表与表格的水平中心对齐
- 图表与表格之间间距: 6pt
- 图表下方与解读文字间距: 4pt

### 图表标题
- 图表标题放在图表上方左侧
- 格式: "图N: {指标名}趋势 ({时间段})"
- 字号: 10pt bold #005293

## 颜色应用规范

### 背景色使用
- 页面背景: #FFFFFF (纯白)
- 表格交替行: #F5F7FA
- 表格首列: #eef1f5
- 图表背景: #FAFBFC

### 文字色使用
- 标题: #005293
- 正文: #333333
- 注释/来源: #808080
- 异常高: #E85D4E bold，数值后紧跟红色"↑"
- 异常低: #005293 bold，数值后紧跟蓝色"↓"

## 紧凑排版技巧

1. **表格内精简**: 指标名使用缩写(如"空腹血糖"->"FPG"), 单位放表头
2. **合并说明**: 相近指标共用说明文字，避免重复
3. **图表共享**: 同系统多指标共用一张多线图，避免单指标单图
4. **解读精简**: 每条发现不超过2行，用数据说话

## 跨页控制

### 禁止跨页的元素
- 单个数据表格
- 单个趋势图表
- 表格+图表的组合模块

### 跨页处理策略
- 在模块开始前插入分页符
- 或调整上方内容间距，将模块整体推至下一页
- 每个模块完成后留12pt间距再开始下一模块

## 渲染与分页陷阱 (2026-07 实战修正)

HTML -> PDF 渲染时按此清单规避已验证的坑：

1. **封面单独处理**: 封面用 `@page :first { margin: 0 }` 并关闭页眉页脚；封面容器高度略小于 297mm（如 296mm），否则封面溢出产生空白第2页。
2. **不要只靠 `page-break-inside: avoid`**: Chromium 对 flex 布局的分页高度计算有偏差，会导致模块被整体推到下一页、留下大半页空白。改用 block/float 布局，或对模块手动放置分页符。
3. **差1-2行溢出时**: 不要重排全文。小幅降低 PDF 缩放（如 scale 0.95 -> 0.92），或压缩该页表格行高 / 精简超长单元格文字。
4. **大图表变形**: 单图被强制等高（如 7cm）会拉伸变形；一排两张的单图改用宽扁自然比例。
5. **逐页截图验收**: 渲染完成后用 `pdftoppm` 导出每页缩略图，先拼总览图看分布，再放大抽查页眉、图表、表格尾部，确认无跨页断裂、无大面积空白后再交付。
6. **工作文件持久化**: /tmp 可能在中途被清空。把 gen_report.py、HTML、charts 保存到 `/mnt/agents/work/<任务名>/`，用户后续微调（页眉、间距等）只需小改+重渲染。

## 沙箱环境陷阱 (2026-08-03 实战修正)

7. **渲染器选型**: `@page` margin-box 页眉/页脚/页码只有 WeasyPrint 能渲染；Chromium headless print-to-PDF 不支持 margin boxes。本报告默认用 WeasyPrint，Chromium 仅用于无 margin-box 的简单版式。
8. **pip 安装超时换镜像**: pythonhosted.org 的大 wheel（如 fonttools 5MB）在沙箱内反复 stalled/timeout。直接换国内镜像：`pip install -i https://mirrors.aliyun.com/pypi/simple/ <pkg>`。
9. **fontTools 导入名是驼峰**: 包目录为 `fontTools`，`import fonttools` 永远失败；`pip show fonttools` 显示已装但 import 失败 = 只有 dist-info 的残缺安装，需 `pip install --user --force-reinstall --no-deps fonttools`（WeasyPrint 依赖它）。验证安装用 `python3 -c "import fontTools, weasyprint"`。
10. **pdftoppm 批量出图勿写 /mnt**: portal 挂载点大批量写 PNG 触发 libpng write error + segfault。验收截图渲染到本地 /tmp（可重新生成）；脚本、HTML、charts 等持久工作文件仍按第6条放 /mnt/agents/work。
