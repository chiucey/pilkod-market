# 财产配置方案生成器

## 核心功能

根据用户输入的**资金金额**和**理财偏好**，结合2025年最新市场数据，生成个性化的财产配置方案。

**执行原则**：每一步操作必须进行 Double Check（自检 + 交叉验证），确保数据准确性和方案可靠性。

### Double Check 检查清单

#### 数据收集阶段
- [ ] **步骤1检查**：搜索结果 ≥ 5 条（否则重新搜索或扩大关键词）
- [ ] **步骤2检查**：提取数据完整（不缺漏关键字段）
- [ ] **步骤3检查**：核心数据（利率/收益率）至少2个来源一致

#### 数据分析阶段
- [ ] **步骤4检查**：`financial-data-latest.md` 存在且可读
- [ ] **步骤5检查**：对比表格中数据变化趋势合理（无突变）
- [ ] **步骤6检查**：趋势判断与数据一致（不矛盾）

#### 方案生成阶段
- [ ] **步骤7检查**：各风险类型配置比例之和 = 100%
- [ ] **步骤8检查**：预期收益在对应产品历史收益范围内
- [ ] **步骤9检查**：包含所有适用风险提示

### 风险偏好 × 期限 配置比例

#### 保守型配置
- **短期(1年内)**：现金管理理财40% + 定期存款30% + 货币基金20% + 国债10%

#### 成长型配置

- **长期(3年+)**：股票型基金40% + 混合基金25% + 权益类理财15% + 黄金10% + 固收+理财10%

#### 进取型配置
- **短期(1年内)**：混合基金35% + 债券基金25% + 固收+理财20% + 黄金10% + 货币基金10%
- **中期(1-3年)**：股票型基金40% + 权益类理财25% + 混合基金20% + 黄金10% + 货币基金5%

## 自动数据更新机制

### 执行时机

**每次调用本技能时**，必须执行以下数据更新流程：
1. 联网搜索上周最新理财数据
2. 对比分析近三次数据（上周、上上周、上上上周）
3. 综合研判当前市场趋势
4. 将结果写入 `references/financial-data-latest.md`

### 近三次数据综合分析方法

#### 数据收集

每次调用时，读取以下文件获取历史数据：
1. `references/financial-data-latest.md` - 上一次（本周）数据
2. 备份文件（如存在）- 上上周数据
3. 基准数据 `references/financial-data-2025.md` - 年度参考

#### 对比分析维度

| 分析维度 | 指标 | 关注点 |
|---------|-----|-------|
| 收益率变化 | 各产品年化收益 | 是否下调/上调 |
| 利率趋势 | 存款、国债利率 | 降息周期/加息周期 |
| 市场规模 | 银行理财规模 | 增长/萎缩 |
| 机构观点 | 各理财公司展望 | 乐观/谨慎 |
| 风险提示 | 破净率、波动率 | 风险是否上升 |

| 国债利率 | 2 | 财政部公告 + 银行公告 |
| 银行理财收益 | 1 | 普益标准 |

#### 数据时效性验证

- 银行存款利率：确认是否为本月内发布
- 国债利率：以财政部最新公告为准
- 黄金价格：确认为当日或近三日数据

## 数据文件管理

### 文件命名规范

| 文件名 | 用途 | 更新频率 |
|-------|-----|---------|
| `financial-data-latest.md` | 本次最新数据 | 每次调用时 |
| `financial-data-prev-week.md` | 上周数据 | 每次更新时自动备份 |
| `financial-data-2025.md` | 年度基准数据 | 每季度或重大变化时 |
| `financial-data-2024.md` | 历史参考数据 | 保留存档 |

### 数据备份机制

每次更新 `financial-data-latest.md` 时，执行以下备份流程：

```
1. 读取当前的 financial-data-latest.md
2. 将其内容写入 financial-data-prev-week.md（覆盖）
3. 更新 financial-data-latest.md 为最新数据
4. 保留时间戳记录
```
