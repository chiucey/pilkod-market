# IPO招股说明书分析技能

## Overview

本技能用于对上市公司IPO招股说明书进行专业投资分析。通过读取用户上传的IPO招股说明书PDF，提取企业基本情况、财务数据、业务与产品、股东与团队、治理与独立性、资金募集用途及风险提示等核心信息，生成一份结构化的招股说明书分析报告，并保存为docx格式文件。

## Workflow

### Step 1：检查招股说明书是否已上传

- 检查用户是否已上传IPO招股说明书文件（通常为PDF格式）
- 如果没有上传，提示用户："请先上传需要分析的公司的IPO招股说明书，然后再继续分析。"
- 确认文件已上传后，使用文件读取工具读取招股说明书内容，再进入后续步骤

### Step 2：提取财务数据（数据整理）

读取IPO招股说明书，提取以下财务数据并整理成表格：

#### 2.1 主营业务收入构成表

按以下格式提取并整理（覆盖报告期内各年度）：

|----------|-------------|-------------|-------------|-------------|-------------|-------------|

#### 2.2 财务指标表

按以下格式提取并整理（覆盖报告期内各年度）：

| 项目 | xxxx年 | xxxx年 | xxxx年 |
|------|--------|--------|--------|
| 营业收入 | - | - | - |

| 资产负债率（合并） | - | - | - |

**数据来源**：主要查找于招股说明书中的财务会计信息章节。

将提取结果暂存，供Step 4中"第4部分 财务指标"使用。

### Step 3：提取企业基本情况

读取IPO招股说明书，提取以下企业基本信息。**主要查找于IPO招股说明书"第二节 概览 二、发行人及本次发行的中介机构基本情况"**。

### Step 5：检查与保存

对Step 4生成的报告进行全面检查：

1. **数据核对**：将报告中的所有数字、百分比、金额与招股说明书原文逐一核对，确保无误
2. **逻辑修正**：检查前后文逻辑是否一致，表述是否通顺，分析结论是否有数据支撑
3. **完成检查后**，将报告整理成docx格式文件进行保存

## 信息检索优先级

1. **首先**在IPO招股说明书文件中检索相关内容
2. **如招股书中未找到**，使用联网搜索进行补充（特别是行业情况、竞争情况等外部信息）
3. 对于确实无法获取的信息，在报告中标注"未在招股说明书中披露"

## 招股说明书常用章节索引

以下为中国A股IPO招股说明书的典型章节结构，用于快速定位信息：

- **第二节 概览** → 基本情况、重大事项提示
  - 一、重大事项提示 → 特别风险提示（第7部分）
  - 二、发行人及本次发行的中介机构基本情况 → 企业基本情况（第1部分）
- **业务与技术章节** → 主要产品和服务、经营模式、行业情况、竞争情况（第2部分）
- **财务会计信息章节** → 财务指标、收入构成（第4部分）
- **股东及治理章节** → 股东信息、高管团队、治理与独立性（第3、5部分）
- **募集资金运用章节** → 资金募集用途（第6部分）

## Common Mistakes to Avoid

- **不要遗漏财务指标表中的任何项目**：必须包含全部10项财务指标
- **不要混淆"归属于母公司所有者的净利润"与"净利润"**：这是两个不同的指标
- **不要忽略关联交易和同业竞争信息**：这是治理和独立性评估的关键
- **不要在没有数据支撑的情况下做出定性判断**
- **年度数据必须对应正确的年份**：注意区分报告期内各年度
- **收入构成占比之和应为100%**：如不符需核查
- **不要遗漏"特别风险提示"部分**：这是投资决策的重要参考

## File & Output Conventions

- 最终报告保存为 `.docx` 格式
- 文件命名建议：`{公司名称}_IPO招股说明书分析报告.docx`
- 报告中的表格应使用规范的表格格式，确保在docx中正确显示
- 所有金额单位应统一（通常为万元或亿元），并在表头注明
