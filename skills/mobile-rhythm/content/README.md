# 阅读节奏

> 短段留白金句独立行，适配手机阅读

## 功能介绍

专为手机端阅读体验优化的排版节奏工具。让你的文字告别密集文字块，变得呼吸感十足、阅读零压力。

## 适用场景

- 文章段落太长太密
- 需要适配手机阅读的排版
- 网文/公众号文章节奏优化
- 短视频文案节奏调整

## 核心规则

### 段落规则
- 单段不超过手机屏幕3行
- 大量使用1-2行超短段落
- 70%段落控制在两行以内
- 长段用来描写/铺垫，短段用来动作/对话/高潮

### 节奏规则
- 关键句子独立成行
- 最狠那句话单独一段
- 带引号的句子独立成行
- 段落之间有呼吸感

### 对话规则
- 每句对话独立成行
- 说话人和内容同一行
- 长篇对话拆多句，中间插动作/反应
- 对话直白简洁，一问一答或一句一断

### 留白规则
- 动作/对话/心理经常独立成段
- 通过段落间空白给读者想象空间
- 降低阅读压力
