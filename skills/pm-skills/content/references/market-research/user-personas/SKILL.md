# 用户画像 (Personas)

系统性地创建用户画像，帮助团队深入理解目标用户，指导产品决策和沟通。

## 用户画像基础

### 什么是用户画像

```
用户画像 = 真实用户的代表
       = 基于数据的抽象
       = 团队决策的参考
```

### 画像类型

| 类型 | 描述 | 用途 |
|-----|------|-----|
| **定性画像** | 基于访谈和观察 | 理解动机和行为 |
| **定量画像** | 基于数据分析 | 分割和定位 |
| **原型画像** | 综合多种来源 | 指导产品开发 |

## 用户画像示例

### 画像示例：专业用户

```markdown
# 用户画像：专业用户

## 基本信息

| 项目 | 内容 |
|-----|-----|
| **画像名称** | "效率至上型" |
| **代号** | Alex |
| **占比** | 25% |
| **类型** | Power User |

## 人口统计

| 维度 | 描述 |
|-----|-----|
| **姓名** | Alex Chen |
| **年龄** | 30-40岁 |
| **职业** | 产品经理 |
| **职位** | 高级/资深 |
| **收入** | 30-50万/年 |
| **地点** | 一线城市 |
| **教育** | 本科+ |

## Goals (目标)

### 主要目标
- 完成每日工作任务
- 提升团队效率
- 展示工作成果

### 关键引用
> "我需要快速完成任务，然后有时间思考更重要的事。"

## Pain Points (痛点)

### 核心痛点
- 手动操作太多，浪费时间
- 信息分散在不同工具
- 需要导出数据再处理

### 典型场景
```
场景: 周五下午提交周报
情况: 需要汇总多个项目的数据
感受: 很烦躁，因为要重复操作
影响: 经常加班做报告
```

## Behaviors (行为)

### 使用特征
- 每日使用，使用时间长
- 使用多个核心功能
- 习惯使用快捷键
- 主动探索新功能

### 技术能力
- 高
- 愿意学习复杂功能
- 能接受一定的学习曲线
```

## 画像使用指南

### 产品决策

| 决策场景 | 画像应用 |
|---------|---------|
| 功能优先级 | 满足核心用户的主要需求 |
| UI设计 | 考虑核心用户的使用习惯 |
| 营销信息 | 使用核心用户的语言 |
| 客服策略 | 预判核心用户的问题 |

### 团队沟通

| 受众 | 如何使用画像 |
|-----|------------|
| 产品经理 | 需求验证、设计参考 |
| 设计师 | 用户研究、设计依据 |
| 开发 | 理解用户场景 |
| 营销 | 精准定位 |

## 画像维护

### 更新频率

| 触发条件 | 更新内容 | 优先级 |
|---------|---------|-------|
| 重大产品变更 | 行为变化 | 🔴高 |
| 用户群体变化 | 新增/调整画像 | 🔴高 |
| 市场环境变化 | 场景更新 | 🟡中 |
| 常规审视 | 数据验证 | 🟡中 |
| 季度回顾 | 整体评估 | 🟢低 |

### 验证清单

- [ ] 画像数据是否来自真实数据？
- [ ] 画像是否代表足够大的用户群？
- [ ] 团队是否理解和认同画像？
- [ ] 画像是否指导了实际决策？
- [ ] 画像是否与产品方向一致？
