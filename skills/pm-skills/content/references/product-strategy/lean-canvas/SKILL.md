# 精益画布 (Lean Canvas)

Ash Maurya 开发的精益画布是专为创业者和早期产品设计的商业模式工具，聚焦于风险验证。

## 精益画布 vs 商业模式画布

| 维度 | 精益画布 | 商业模式画布 |
|-----|---------|------------|
| **目标用户** | 创业者、早期产品 | 成熟企业 |
| **关注点** | 风险和假设验证 | 全面运营 |
| **结构** | 问题驱动 | 价值驱动 |
| **核心** | 不确定性管理 | 资源配置 |

### 关键指标 (Key Metrics)

#### 指标分层

| 层级 | 指标 | 作用 | 示例 |
|-----|-----|-----|-----|
| **北极星** | 核心成功指标 | 唯一最重要指标 | 日活用户 |
| **健康指标** | 运营健康 | 系统正常运转 | 可用性 |
| **执行指标** | 团队行动 | 可直接影响 | 转化率 |

#### 指标选择原则

| 原则 | 描述 |
|-----|------|
| **可归因** | 团队能直接影响的 |
| **可衡量** | 有明确数据来源 |
| **可理解** | 团队都理解的 |
| **可行动** | 有明确的后续行动 |
| **周期性** | 可定期追踪 |

#### 指标体系示例

```markdown
北极星指标:
├── [指标名称]: [目标值]

健康指标:
├── [系统可用性]: >99.9%
├── [错误率]: <1%
├── [响应时间]: <500ms

执行指标:
├── [获客]: 注册数/周
├── [激活]: 首次完成核心任务率
├── [留存]: 7日留存率
├── [收入]: MRR
├── [推荐]: NPS
```

### 独特价值主张 (UVP)

#### UVP 公式

```
针对 [目标用户]，
谁需要 [解决问题/抓住机会]，
我们的 [产品/服务] 是 [产品类别]，
能够 [核心利益]，
不同于 [主要替代方案]，
因为我们 [关键差异化]。
```

#### UVP 检验清单

| 问题 | 检查 |
|-----|-----|
| 这个 UVP 清晰吗？ | ✅/❌ |
| 目标用户能理解吗？ | ✅/❌ |
| 与竞品有明显差异吗？ | ✅/❌ |
| 解决了用户核心问题吗？ | ✅/❌ |
| 易于传播和记忆吗？ | ✅/❌ |

#### UVP 示例

| 产品 | UVP |
|-----|-----|
| Slack | "Slack 是一款为团队沟通协作而生的现代工具" |
| Notion | "一个将笔记、任务、数据库融为一体的工具" |
| Dropbox | "在任意设备上存储、同步、分享文件" |

### 不公平优势 (Unfair Advantage)

#### 优势类型

| 类型 | 描述 | 可持续性 |
|-----|------|---------|
| **技术壁垒** | 专利、专有技术 | 🔴高 🟡中 🟢低 |
| **网络效应** | 用户越多价值越大 | 🔴高 🟡中 🟢低 |
| **品牌** | 强大的品牌认知 | 🔴高 🟡中 🟢低 |
| **转换成本** | 用户迁移代价高 | 🔴高 🟡中 🟢低 |
| **独家资源** | 独占渠道、数据 | 🔴高 🟡中 🟢低 |
| **先发优势** | 早期进入市场 | 🔴高 🟡中 🟢低 |

#### 区分真伪不公平优势

| 真正的优势 | 伪优势 |
|-----------|-------|
| 难以复制或购买 | 想法/概念 |
| 可持续 | 知识/技能 |
| 有壁垒保护 | 规模 |
| 独占的 | 商业模式 |

#### 渠道类型

| 类型 | 描述 | 成本 | 控制度 |
|-----|------|-----|-------|
| **直销** | 团队直接销售 | 高 | 高 |
| **内容营销** | 博客、视频 | 低 | 高 |
| **SEO/SEM** | 搜索引擎 | 中 | 中 |
| **社交媒体** | 社交平台推广 | 低-中 | 高 |
| **分销** | 合作伙伴销售 | 中 | 低 |
| **市场平台** | 第三方平台 | 中 | 低 |
| **病毒传播** | 用户推荐 | 低 | 中 |

```

         低   │  测试   │  避免   │
              │  优化   │  投入   │
              └─────────┴─────────┘
```

### 成本结构 (Cost Structure)

#### 成本分类

| 类别 | 描述 | 优先级 |
|-----|------|-------|
| **获客成本 (CAC)** | 获取客户成本 | 🔴高 🟡中 |
| **生产/交付** | 产品/服务成本 | 🔴高 🟡中 |
| **人员** | 团队薪酬 | 🔴高 🟡中 |
| **基础设施** | 服务器、工具 | 🟡中 🟢低 |
| **销售** | 销售团队 | 🔴高 🟡中 |
| **营销** | 品牌推广 | 🟡中 🟢低 |

#### 成本指标

| 指标 | 公式 | 目标值 |
|-----|-----|-------|
| **CAC** | 总获客成本/新客数 | 尽量低 |
| **LTV** | 用户生命周期价值 | 尽量高 |
| **LTV:CAC** | 生命周期价值/获客成本 | >3:1 |
| **回收期** | CAC回收时间 | <12个月 |

### 收入来源 (Revenue Streams)

#### 收入类型

| 类型 | 描述 | 适用场景 |
|-----|------|---------|
| **一次性付费** | 买断产品 | 传统软件 |
| **订阅** | 持续付费 | SaaS |
| **用量计费** | 按使用量计费 | 云服务 |
| **交易费** | 交易百分比 | 电商平台 |
| **广告** | 广告展示/点击 | 内容平台 |
| **授权** | 技术/品牌授权 | IP |

#### 定价策略

| 策略 | 描述 | 示例 |
|-----|------|-----|
| **成本加成** | 成本+利润 | 制造业 |
| **竞品定价** | 参考竞品定价 | 竞争激烈市场 |
| **价值定价** | 基于用户价值 | 企业软件 |
| **渗透定价** | 低价进入市场 | 互联网产品 |
| **动态定价** | 根据需求调整 | 机票、酒店 |

## 精益画布使用流程

### 1. 团队协作
- 建议所有核心团队成员参与
- 使用便签和白板便于调整
- 鼓励激烈讨论

### 2. 快速迭代
- 初次完成控制在 30 分钟内
- 每 1-2 周回顾更新
- 用数据验证假设

### 3. 转化为行动
- 每个模块对应具体行动
- 设定验证实验
- 追踪关键指标
