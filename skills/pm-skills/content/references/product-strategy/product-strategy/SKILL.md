# 产品策略画布

9段式产品策略画布是一个综合性框架，帮助团队从愿景到防御性系统性地定义产品战略。

## 画布结构概览

│   ┌─────────────┐                    ┌─────────────┐            │
│   │   目标用户   │                    │   价值主张   │            │
│   │  (Segments) │                    │   (Value)   │            │

│   ┌─────────────┐                    ┌─────────────┐            │

## 第一部分：产品愿景 (Vision)

### 定义要素

| 要素 | 问题 | 回答 |
|-----|------|-----|
| **终极目标** | 产品存在的原因是什么？ | [描述产品最终解决的问题] |
| **改变什么** | 世界将如何因此不同？ | [描述理想状态] |
| **时间范围** | 3-5年后产品是什么样子？ | [愿景描述] |

### 愿景陈述模板

```
[公司/产品] 的使命是 [用动词描述行动]，
使 [目标用户] 能够 [核心能力]，
而不必 [当前痛点]，
最终实现 [愿景目标]。
```

### 示例愿景陈述

```
**Airbnb 的愿景**:
创造一个任何人都可以属于任何地方的世界。
Create a world where anyone can belong anywhere.
```

### 优秀愿景特征

1. **鼓舞人心**: 让人想要为这个目标工作
2. **可衡量**: 有明确的方向可评估进展
3. **持久性**: 5-10年内保持相关
4. **雄心勃勃**: 有挑战性但可达
5. **聚焦**: 明确不做什么

## 第二部分：目标用户 (Segments)

### 细分维度

| 维度 | 描述 | 示例 |
|-----|------|-----|
| **人口统计** | 年龄、性别、收入、教育 | 25-35岁白领 |
| **地理** | 地域、气候、城市等级 | 一线城市 |
| **心理** | 价值观、兴趣、生活方式 | 环保主义者 |
| **行为** | 使用频率、忠诚度、需求 | 重度用户 |
| **职业** | 工作职能、行业、层级 | 产品经理 |

## 第三部分：价值主张 (Value Proposition)

### 价值类型

| 类型 | 描述 | 示例 |
|-----|------|-----|
| **功能性价值** | 完成任务的效率 | 省时50% |
| **情感性价值** | 用户感受的提升 | 更有掌控感 |
| **社会性价值** | 社会身份和认可 | 显得专业 |
| **降低风险** | 减少不确定性 | 30天退款 |
| **降低成本** | 节省金钱或时间 | 减少人力成本 |

## 第四部分：成本 (Costs)

### 成本类型

| 类型 | 描述 | 示例 |
|-----|------|-----|
| **固定成本** | 不随产出变化的成本 | 人员工资、办公室 |
| **可变成本** | 随产出变化的成本 | 云服务、客服 |
| **边际成本** | 每增加一单位产品的成本 | 每用户服务器成本 |
| **机会成本** | 放弃的其他选择的价值 | 开发时间 |
| **沉没成本** | 已发生且无法收回的成本 | 前期研发投入 |

### 成本优化策略

| 策略 | 描述 | 实施方式 |
|-----|------|---------|
| **规模经济** | 产量增加降低单位成本 | 批量采购、规模化运营 |
| **范围经济** | 共享资源降低总成本 | 平台化、模块化 |
| **技术替代** | 用技术替代人力 | 自动化、流程优化 |
| **外包** | 外部专业服务 | 非核心业务外包 |
| **精益运营** | 消除浪费 | 持续改进 |

## 第五部分：增长 (Growth)

### 增长策略

| 策略 | 描述 | 适用场景 |
|-----|------|---------|
| **用户获取** | 获取新用户 | 增长初期 |
| **用户激活** | 提升激活率 | 有流量但转化低 |
| **用户留存** | 提升留存 | 流失率高 |
| **用户推荐** | 口碑传播 | NPS高 |
| **扩大钱包份额** | 提升单用户价值 | 成熟期 |

### 增长引擎

| 引擎 | 描述 | 关键指标 |
|-----|------|---------|
| **口碑** | 用户推荐用户 | K因子 |
| **有机** | 搜索/内容带来流量 | 流量增长率 |
| **付费** | 广告投放获取用户 | CAC |
| **病毒** | 产品内嵌分享机制 | 病毒系数 |
| **粘性** | 提升用户使用频率 | 频次/粘性指数 |

## 第七部分：指标 (Metrics)

### 指标体系

| 层级 | 指标类型 | 示例 |
|-----|---------|-----|
| **北极星** | 核心成功指标 | DAU、GMV |
| **健康指标** | 系统健康 | 性能、可用性 |
| **运营指标** | 日常运营 | 转化率、流失率 |
| **财务指标** | 财务表现 | MRR、Unit Economics |

### 目标设定

| 方法 | 描述 | 适用场景 |
|-----|------|---------|
| **历史趋势** | 基于历史数据推算 | 稳定增长 |
| **对标分析** | 参考行业/竞品 | 新市场 |
| **逆向推算** | 从目标倒推 | 明确deadline |
| **团队承诺** | 团队自下而上 | 需要ownership |

## 第八部分：权衡取舍 (Trade-offs)

### 战略选择

| 维度 | 选择A | 选择B | 选择C |
|-----|------|------|------|
| **用户vs用户** | 聚焦高端 | 聚焦大众 | 两者兼顾 |
| **短期vs长期** | 快速变现 | 长期投资 | 平衡 |
| **深度vs广度** | 深度功能 | 广泛覆盖 | 聚焦核心 |
| **自建vs采购** | 自建 | 采购 | 混合 |

## 策略迭代

### 定期回顾
- **月度**: 检视指标进展
- **季度**: 回顾策略有效性
- **年度**: 全面战略审视

### 触发重新评估
1. 市场重大变化
2. 竞品战略调整
3. 技术突破
4. 用户需求显著变化
5. 核心假设被证伪
