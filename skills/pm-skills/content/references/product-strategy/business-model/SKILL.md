## 第一模块：客户细分 (Customer Segments)

### 细分类型

| 类型 | 描述 | 示例 |
|-----|------|-----|
| **大众市场** | 广泛的客户群体，需求相似 | 消费者市场 |
| **利基市场** | 高度专业化的细分群体 | 奢侈品市场 |
| **细分市场** | 在大众市场中细分 | 按年龄/收入细分 |
| **多元化市场** | 多个不相关需求群体 | 亚马逊 |
| **多边平台** | 服务多个相互依存群体 | 淘宝、App Store |

### 细分标准

| 标准 | 描述 |
|-----|------|
| **人口统计** | 年龄、性别、收入、教育 |
| **地理** | 地域、气候、城市 |
| **心理** | 价值观、兴趣、生活方式 |
| **行为** | 使用频率、忠诚度 |
| **需求** | 具体需求和痛点 |

| **便利性** | 使用更方便 | 便利店 |
| **品牌/地位** | 身份象征 | 奢侈品 |

## 第三模块：渠道通路 (Channels)

### 渠道类型

| 类型 | 描述 | 优劣势 |
|-----|------|-------|
| **自有渠道** | 公司直接拥有 | 控制强，成本高 |
| **合作伙伴渠道** | 通过合作方销售 | 覆盖广，控制弱 |
| **直销** | 销售团队直接销售 | 关系深，成本高 |
| **在线销售** | 电商平台 | 成本低，互动少 |

### 渠道阶段

```
认知 ──────► 评估 ──────► 购买 ──────► 交付 ──────► 售后
   │           │           │           │           │
[如何让      [如何帮助    [如何完成    [如何传递    [如何维持
 客户知道]     评估]       购买]       价值]        关系]
```
