# PESTLE 分析

系统性地分析宏观环境中的六大因素，帮助企业识别机会和威胁，为战略决策提供外部环境视角。

## 分析最佳实践

### 数据来源

| 来源 | 类型 | 可靠性 |
|-----|-----|-------|
| 政府统计 | 一手数据 | 高 |
| 行业协会报告 | 二手数据 | 中-高 |
| 学术研究 | 二手数据 | 高 |
| 媒体新闻 | 实时信息 | 中 |
| 专家访谈 | 定性信息 | 中 |

### 分析原则

1. **系统性**: 覆盖所有六大维度
2. **客观性**: 基于数据和事实
3. **关联性**: 与业务紧密相关
4. **前瞻性**: 关注未来趋势
5. **可操作性**: 转化为具体行动

### 常见陷阱

1. ❌ 只关注负面因素
2. ❌ 过度依赖单一来源
3. ❌ 缺乏定期更新
4. ❌ 分析过于宽泛
5. ❌ 没有转化为行动
