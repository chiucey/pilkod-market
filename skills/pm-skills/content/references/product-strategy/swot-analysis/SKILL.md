# SWOT 分析

系统性地分析组织的内外部环境，为战略决策提供依据。

## SWOT 结构

```
                    内部环境
                      分析

         ┌─────────────────────────────┐
         │      优势 (Strengths)       │
         │  • 组织独特的正向能力      │
         │  • 有价值的资源和能力      │
         │  • 区别于竞品的优势        │
         ├─────────────────────────────┤
         │      劣势 (Weaknesses)     │
         │  • 限制组织发展的因素      │
         │  • 缺乏或不足的资源        │
         │  • 需要改进的地方          │
         └─────────────────────────────┘

                    外部环境
                      分析

         ┌─────────────────────────────┐
         │      机会 (Opportunities)   │
         │  • 市场趋势带来的可能性      │
         │  • 客户需求的新缺口        │
         │  • 技术/政策带来的机遇      │
         ├─────────────────────────────┤
         │      威胁 (Threats)        │
         │  • 可能损害组织的外部因素    │
         │  • 竞争对手的动向          │
         │  • 市场/技术/法规风险        │
         └─────────────────────────────┘
```

## SWOT 交叉分析 (TOWS 矩阵)

### SO 策略 (优势 + 机会)

使用优势抓住机会。

```
策略模式: [优势] + [机会] = [SO策略]

示例:
- 强大品牌(优势) + 新兴市场(机会) = 拓展新市场
- 技术领先(优势) + 政策支持(机会) = 获得政府项目
```

### WO 策略 (劣势 + 机会)

克服劣势抓住机会。

```
策略模式: 克服[劣势] + 抓住[机会] = [WO策略]

示例:
- 资金不足(劣势) + 融资环境好(机会) = 寻求融资
- 缺乏经验(劣势) + 培训可用(机会) = 建立培训体系
```

### ST 策略 (优势 + 威胁)

使用优势应对威胁。

```
策略模式: [优势] + 应对[威胁] = [ST策略]

示例:
- 客户忠诚度高(优势) + 竞品进入(威胁) = 强化客户关系
- 成本优势(优势) + 价格战(威胁) = 保持价格竞争力
```

### WT 策略 (劣势 + 威胁)

最小化劣势，回避威胁。

```
策略模式: 最小化[劣势] + 回避[威胁] = [WT策略]

示例:
- 市场份额低(劣势) + 强敌进入(威胁) = 寻找细分市场
- 技术落后(劣势) + 技术变革(威胁) = 技术合作/收购
```

## 详细分析指南

### 优势 (Strengths)

#### 分析维度

| 维度 | 问题 |
|-----|------|
| **资源** | 拥有关键资源吗？ |
| **能力** | 有什么独特能力？ |
| **资产** | 有什么有价值的资产？ |
| **竞争力** | 比竞品强在哪？ |
| **财务** | 财务状况如何？ |

#### 优势评估标准

| 评估问题 | 评估 |
|---------|-----|
| 这个优势对客户有价值吗？ | 是/否 |
| 这个优势难以复制吗？ | 是/否 |
| 这个优势可持续吗？ | 是/否 |
| 这个优势可量化吗？ | 是/否 |

### 劣势 (Weaknesses)

#### 分析维度

| 维度 | 问题 |
|-----|------|
| **资源** | 缺少什么资源？ |
| **能力** | 什么能力不足？ |
| **规模** | 规模是否制约发展？ |
| **效率** | 运营效率如何？ |
| **财务** | 财务压力在哪？ |

#### 劣势评估标准

| 评估问题 | 评估 |
|---------|-----|
| 这个劣势影响价值创造吗？ | 是/否 |
| 这个劣势让竞品有机可乘吗？ | 是/否 |
| 这个劣势可以快速改善吗？ | 是/否 |

### 机会 (Opportunities)

#### 分析维度

| 维度 | 例子 |
|-----|-----|
| **市场** | 新兴市场、新客户群 |
| **技术** | 技术进步、数字化 |
| **政策** | 政府支持、法规变化 |
| **社会** | 趋势变化、生活方式改变 |
| **经济** | 经济增长、消费升级 |

#### 机会评估

| 评估问题 | 评估 |
|---------|-----|
| 市场规模有多大？ | [量化] |
| 增长潜力如何？ | [描述] |
| 进入时机合适吗？ | 是/否 |
| 与战略方向一致吗？ | 是/否 |
| 竞争对手注意到了吗？ | 是/否 |

### 威胁 (Threats)

#### 分析维度

| 维度 | 例子 |
|-----|-----|
| **市场** | 市场萎缩、需求下降 |
| **竞争** | 新进入者、替代品 |
| **技术** | 技术颠覆、颠覆性创新 |
| **法规** | 法规收紧、合规成本 |
| **经济** | 经济下行、成本上升 |

#### 威胁评估

| 评估问题 | 评估 |
|---------|-----|
| 威胁发生的可能性？ | 高/中/低 |
| 威胁的潜在影响？ | 高/中/低 |
| 威胁的时间框架？ | 短期/中期/长期 |
| 竞争对手也面临这个威胁吗？ | 是/否 |

## 分析最佳实践

### 数据收集

1. **内部数据**: 财务报告、运营数据、客户反馈
2. **外部数据**: 市场报告、竞品分析、行业趋势
3. **专家输入**: 行业专家、顾问意见
4. **客户洞察**: 客户访谈、问卷调查

### 分析原则

1. **客观**: 基于事实而非偏见
2. **全面**: 考虑所有相关因素
3. **具体**: 避免模糊陈述
4. **可量化**: 尽可能量化评估
5. **定期更新**: 定期重新评估

### 常见陷阱

1. ❌ 过度聚焦于可量化的因素
2. ❌ 忽视外部环境快速变化
3. ❌ 过度自信于现有优势
4. ❌ 分析过度复杂化
5. ❌ 缺乏后续行动
