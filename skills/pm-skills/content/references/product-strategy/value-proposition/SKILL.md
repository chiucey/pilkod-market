# JTBD 价值主张

基于 Jobs-to-be-Done (JTBD) 框架的6部分价值主张，帮助产品经理深入理解用户价值并清晰传达产品价值。

## JTBD 价值主张结构

```

│                    6部分价值主张画布                             │

│   │  WHO            │              │  HOW             │          │

│   │                 │              │                 │          │

│   │  WHY                                                   │        │

│   └─────────────────────────────────────────────────────┘        │
```

## 第一部分：WHO - 目标用户

### 描述维度

| 维度 | 描述 | 示例 |
|-----|------|-----|
| **人口统计** | 年龄、职业、收入 | 25-35岁产品经理 |
| **行为特征** | 使用习惯、决策模式 | 重度数字产品用户 |
| **角色** | 在组织中的位置 | 决策者/影响者 |
| **场景** | 使用产品的具体场景 | 工作日处理客户反馈 |

### 用户细分框架

```markdown

**用户群B**: [描述]

- 使用场景: [场景]

```

## 第二部分：WHY - 动机

### JTBD 动机类型

| 类型 | 描述 | 示例 |
|-----|------|-----|
| **功能型动机** | 完成特定任务 | "我需要管理项目进度" |
| **情感型动机** | 感受某种情感 | "我希望工作更轻松" |
| **社会型动机** | 社会认同和地位 | "我想显得更专业" |

### 动机层级

```
深层动机 ──► 中层动机 ──► 表层动机
   │              │             │
[价值观]      [渴望]        [需求]
```

### 动机探询问题

**探询深层动机**:
- "为什么这个问题对你重要？"
- "如果解决了这个问题，对你意味着什么？"
- "这个问题对你的生活/工作有什么影响？"

**探询情感需求**:
- "解决这个问题后，你会感觉如何？"
- "现在处理这个问题时，你有什么感受？"
- "什么样的体验会让你感到满足？"

## 第六部分：ALTERNATIVES - 替代方案

### 替代类型

| 类型 | 描述 | 用户选择原因 |
|-----|------|-------------|
| **竞争产品** | 直接竞品 | 品牌、功能 |
| **自制** | 内部开发 | 控制、定制 |
| **不作为** | 忍受现状 | 成本、迁移成本 |
| **部分解决** | 凑合用现有方案 | 够用就行 |
| **替代品类** | 不同方式解决 | 价格、习惯 |

### 替代方案对比

```markdown
### 替代方案分析

| 方案 | 满足程度 | 痛点 | 我们的优势 |
|-----|---------|-----|---------|
| [竞品A] | 70% | [痛点] | [我们更好] |
| [自制] | 50% | [痛点] | [成本更低] |
| [不作为] | 0% | [痛点] | [解决问题] |
```

### 转换成本

| 成本类型 | 描述 | 壁垒高度 |
|---------|-----|---------|
| **财务成本** | 迁移需要多少钱 | 🔴高 🟡中 🟢低 |
| **时间成本** | 迁移需要多少时间 | 🔴高 🟡中 🟢低 |
| **学习成本** | 用户需要学习多久 | 🔴高 🟡中 🟢低 |
| **情感成本** | 放弃已有关系的代价 | 🔴高 🟡中 🟢低 |

## 价值主张陈述模板

### 标准模板

```
对于 [目标用户]，
他们 [动机/背景]，
我们的 [产品/服务] 是 [产品类别]，
它可以帮助你 [核心功能/价值]，
从而 [行动后的结果]，
不同于 [替代方案]，
因为我们 [差异化优势]。
```

### 情感模板

```
当你 [情境/痛点场景]，
你感到 [情感状态]，
你需要一个解决方案能让你 [期望情感]，
这就是为什么 [产品名称]，
它 [核心价值]，
让你 [最终感受]。
```

### 问题-方案-结果模板

```
[目标用户] 经常面临 [问题]，
这导致 [负面后果]，
我们提供了 [解决方案]，
帮助你 [获得的结果]，
从而 [更大的价值]。
```
