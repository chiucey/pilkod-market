# 访谈总结

将客户访谈转化为结构化的洞察文档，确保研究价值被完整捕获和有效利用。

## 访谈总结流程

### 第一步：转录整理

```
任务: 将原始访谈记录整理为可分析格式
输出: 时间戳标注的访谈记录
```

**整理原则**:
- 保持原始表达
- 记录非语言信息 (语气、停顿、情绪)
- 标记关键引用

### 第二步：结构化总结

```
任务: 提取关键信息并分类
输出: 分类整理的信息模块
```

### 第三步：洞察提炼

```
任务: 从数据中提炼可行动的洞察
输出: 洞察陈述 + 支持证据
```

## 洞察提炼方法

### 从数据到洞察

```
原始数据 → 模式识别 → 含义解读 → 洞察陈述
   ↓           ↓            ↓          ↓
[引用1]     [共同点]     [为什么重要] [行动导向的陈述]
[引用2]
[引用3]
```

### 好的洞察特征

1. **可行动**: 能指导具体决策
2. **有支撑**: 有多个数据点支持
3. **有意义**: 对业务/产品有影响
4. **非显而易见**: 不是表面现象
5. **具体明确**: 不模糊、可衡量

### 洞察陈述模板

```
[用户群体] 倾向于 [行为模式], 因为 [原因],
这意味着 [对产品的影响], 所以我们应该 [行动建议].
```
