## 第一步：精准陈述问题

### 核心目标
将模糊的问题转化为清晰、可定义、可解决的问题陈述。

### 问题陈述六大要素

| 要素 | 问题 | 检查清单 |
|------|------|----------|
| **决策者** | 谁来做最终决定？ | 明确决策权归属 |
| **执行者** | 谁来执行方案？ | 确认执行团队 |
| **时间限制** | 何时需要解决方案？ | 设定截止日期 |
| **成功标准** | 如何衡量成功？ | 量化指标定义 |
| **背景信息** | 问题的来龙去脉？ | 完整上下文 |
| **边界范围** | 问题涉及哪些范围？ | 明确边界条件 |

### 优质问题陈述模板

```
┌────────────────────────────────────────────────────────────┐
│                      问题陈述模板                            │
├────────────────────────────────────────────────────────────┤
│                                                            │
│  我们面临的核心问题是：[具体描述问题]                        │
│                                                            │
│  影响决策者的关键因素：                                     │
│  • [因素1]                                                 │
│  • [因素2]                                                 │
│  • [因素3]                                                 │
│                                                            │
│  期望达成的成果：                                           │
│  • [量化指标1]                                             │
│  • [量化指标2]                                             │
│                                                            │
│  约束条件：                                                 │
│  • 时间：[具体期限]                                         │
│  • 资源：[可用资源]                                         │
│  • 范围：[边界限定]                                         │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

## 第二步：分解议题（逻辑树法）

### 核心目标
将复杂问题拆解为可管理、可分析的小问题。

### 三种逻辑树结构

#### 1. 议题逻辑树（What型问题）

```
                      问题是什么？
                         │
        ┌────────────────┼────────────────┐
        ▼                ▼                ▼
    财务因素         运营因素         市场因素
        │                │                │
   ┌────┴────┐      ┌────┴────┐      ┌────┴────┐
   ▼         ▼      ▼         ▼      ▼         ▼
  成本     收入    流程     人员    客户     竞争
```

#### 2. 假设逻辑树（Why型问题）

```
                    假设：我们应该X
                         │
        ┌────────────────┼────────────────┐
        ▼                ▼                ▼
   因为A成立       因为B成立          因为C成立
        │                │                │
   A1 + A2          B1 × B2          C1 且 C2
```

#### 3. 是否逻辑树（Yes/No型问题）

```
                    问题成立吗？
                         │
              ┌──────────┴──────────┐
              ▼                     ▼
           是的                  不是的
              │                     │
     ┌────────┴────────┐   ┌────────┴────────┐
     ▼                  ▼   ▼                  ▼
  为什么是          什么改变     为什么不是     什么阻碍
```

### 分解原则

| 原则 | 说明 | 示例 |
|------|------|------|
| MECE原则 | 相互独立，完全穷尽 | 不重复、不遗漏 |
| 80/20法则 | 识别关键少数 | 20%因素影响80%结果 |
| 深入一层 | 每层至少三个分支 | 增加分析深度 |
| 可行动性 | 子问题可转化为行动 | 便于执行落地 |

### 分解检查清单
- [ ] 是否符合MECE原则？
- [ ] 每个分支是否清晰可界定？
- [ ] 是否能追溯到根本原因？
- [ ] 是否便于责任分工？

## 第三步：消除非关键议题（漏斗法）

### 核心目标
聚焦核心问题，排除干扰因素，优化资源分配。

### 漏斗式筛选流程

```
┌─────────────────────────────────────────────────────────────────┐
│                      漏斗筛选模型                                │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│    ┌───────────────────────────────────────────────┐           │
│    │              全部议题（100%）                  │           │
│    │  问题A  问题B  问题C  问题D  问题E  问题F      │           │
│    └──────────────────────┬────────────────────────┘           │
│                           ▼                                      │
│    ┌──────────────────────┴────────────────────────┐           │
│    │            初步筛选后（60%）                   │           │
│    │     问题A   问题C   问题D   问题F             │           │
│    └──────────────────────┬────────────────────────┘           │
│                           ▼                                      │
│    ┌──────────────────────┴────────────────────────┐           │
│    │           深度分析后（30%）                   │           │
│    │         问题A       问题D                      │           │
│    └──────────────────────┬────────────────────────┘           │
│                           ▼                                      │
│    ┌──────────────────────┴────────────────────────┐           │
│    │           关键核心议题（10%）                  │           │
│    │               问题A                          │           │
│    └───────────────────────────────────────────────┘           │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 筛选评估矩阵

| 评估维度 | 高优先级 | 中优先级 | 低优先级 |
|----------|----------|----------|----------|
| **影响程度** | 直接影响核心目标 | 间接影响 | 边缘影响 |
| **紧急程度** | 需立即处理 | 可延后处理 | 可忽略 |
| **可解决性** | 有明确解决方案 | 部分可解决 | 难以解决 |
| **资源需求** | 低资源高回报 | 中等投入 | 高投入低回报 |

### 决策判断标准
- 影响力：能否显著改变问题结果？
- 可行性：在现有资源下能否实现？
- 时效性：是否有时效要求？
- 可替代性：是否有更优替代方案？

### 自检清单
- [ ] 是否识别出前20%的关键问题？
- [ ] 排除的问题是否有充分理由？
- [ ] 关键问题是否获得足够资源？
- [ ] 是否避免过度分析？

## 第五步：进行关键分析

### 核心目标
运用适当工具和方法，深入分析关键问题，得出有效结论。

### 分析方法库

#### 定量分析方法

| 方法 | 适用场景 | 工具/技术 |
|------|----------|-----------|
| 回归分析 | 识别变量关系 | Excel, SPSS, Python |
| 敏感性分析 | 评估不确定性 | 蒙特卡洛模拟 |
| 成本效益分析 | 方案评估选择 | 净现值、内部收益率 |
| 趋势分析 | 预测未来发展 | 时间序列分析 |
| 基准对比 | 行业对标分析 | 同业数据收集 |

#### 定性分析方法

| 方法 | 适用场景 | 工具/技术 |
|------|----------|-----------|
| 专家访谈 | 深度洞察获取 | 结构化问卷、深度访谈 |
| 焦点小组 | 多元观点收集 | 小组讨论引导 |
| 案例研究 | 经验借鉴学习 | 成功/失败案例分析 |
| 德尔菲法 | 共识达成 | 多轮专家反馈 |
| 情景分析 | 未来可能性探索 | 情景构建与推演 |

## 第六步：综合结果并建立结论

### 金字塔结构

```
                         核心结论

            ┌───────────────┼───────────────┐
            │               │               │
        主要论据1        主要论据2        主要论据3
            │               │               │
       ┌────┴────┐     ┌────┴────┐     ┌────┴────┐
       ▼         ▼     ▼         ▼     ▼         ▼
     支持A1    支持A2   支持B1    支持B2  支持C1    支持C2
```

### 结论构建三原则

| 原则 | 说明 | 操作要点 |
|------|------|----------|
| **SCQA框架** | 情境-冲突-问题-答案 | 逻辑递进，说服有力 |
| **数据支撑** | 结论需有数据基础 | 图表结合，论据充分 |
| **行动导向** | 结论指向具体行动 | 清晰指明下一步 |

## 方法论应用指南

### 不同场景的应用建议

| 场景 | 重点步骤 | 时间分配建议 |
|------|----------|--------------|
| 战略规划 | 1→2→3→4→6→7 | 定义和分析占60% |
| 运营优化 | 2→3→4→5→6→7 | 分析和方案占70% |
| 危机处理 | 1→3→5→6→7 | 陈述和行动占80% |
| 日常决策 | 1→2→6→7 | 快速聚焦关键点 |

### 常见陷阱与规避

| 陷阱 | 表现 | 规避方法 |
|------|------|----------|
| 伪精确 | 过度追求精确数据 | 关注关键少数 |
| 分析瘫痪 | 无限期分析 | 设定截止日期 |
| 确认偏误 | 只看支持观点的数据 | 主动寻找反例 |
| 方案固化 | 提前确定答案 | 保持开放思维 |
| 忽视执行 | 只管出方案 | 方案必须可执行 |
