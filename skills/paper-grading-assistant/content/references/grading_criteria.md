# Grading Criteria Reference for Course Assignments

## Detailed Scoring Dimensions

### 1. Structure Completeness (20 points)

| Grade | Score | Criteria |
|-------|-------|----------|
| Excellent | 18-20 | Complete and clear structure, including abstract, keywords, introduction, body, conclusion, references, etc. |
| Good | 14-17 | Mostly complete structure, missing only 1-2 non-core sections, well-organized |
| Average | 10-13 | Basic structure exists, but some sections missing or poorly organized |
| Poor | 6-9 | Incomplete structure, missing core sections like introduction or conclusion |
| Very Poor | 0-5 | Chaotic structure, cannot identify basic paper framework |

**Evaluation Points**:
- Whether heading levels are standard (level 1, 2, 3 headings)
- Whether chapter length proportions are reasonable
- Whether paragraph transitions are natural
- Whether subject-specific writing conventions are followed

### 2. Content Quality (30 points)

| Grade | Score | Criteria |
|-------|-------|----------|
| Excellent | 27-30 | Clear and unique arguments, thorough and sufficient evidence, in-depth analysis, novel insights |
| Good | 22-26 | Clear arguments, adequate evidence, with reasonable analysis depth |
| Average | 15-21 | Basic clear arguments, lacking evidence, limited analysis depth |
| Poor | 8-14 | Vague arguments, insufficient evidence, lacking analysis |
| Very Poor | 0-7 | No clear arguments, empty content |

**Evaluation Points**:
- **Arguments**: Clear, definite, arguable
- **Evidence**: Sufficient, relevant, reliable
- **Analysis**: In-depth, multi-perspective, logical
- **Innovation**: Unique insights or new perspectives

### 3. Writing Standards (25 points)

| Grade | Score | Criteria |
|-------|-------|----------|
| Excellent | 23-25 | Accurate and fluent language, standard terminology, rigorous logic, no grammar errors |
| Good | 19-22 | Mostly fluent language, generally standard terminology, minor grammar issues |
| Average | 14-18 | Basic fluency, terminology misuse or grammar errors exist |
| Poor | 8-13 | Language expression problems affecting comprehension |
| Very Poor | 0-7 | Chaotic language, difficult to understand |

**Common Problem Checklist**:

#### Language Issues
- Improper or repetitive word choice
- Long, incomplete sentences
- Colloquial expressions
- Missing logical connectors

#### Terminology Issues
- Professional terminology errors
- Concept confusion
- Non-standard Chinese-English mixing

#### Punctuation Issues
- Punctuation usage errors
- Improper spacing between punctuation and text
- Citation punctuation format errors

### 4. Format Standards (15 points)

| Grade | Score | Criteria |
|-------|-------|----------|
| Excellent | 14-15 | Fully meets format requirements, proper citations, well-designed tables and figures |
| Good | 12-13 | Basically meets format requirements, minor flaws |
| Average | 9-11 | Some format irregularities, needs adjustment |
| Poor | 5-8 | Chaotic format, needs major revision |
| Very Poor | 0-4 | Format completely non-compliant |

**Format Checklist**:

- [ ] Consistent font, font size, line spacing
- [ ] Standard paragraph indentation
- [ ] Proper heading centering and bold formatting
- [ ] Consistent citation format
- [ ] Standard reference format
- [ ] Complete figure and table numbering and captions
- [ ] Correct header and footer settings

### 5. Innovation and Thinking (10 points)

| Grade | Score | Criteria |
|-------|-------|----------|
| Excellent | 9-10 | Unique insights, strong critical thinking, can propose new ideas or question existing theories |
| Good | 7-8 | Some depth of thinking, can comprehensively analyze existing viewpoints |
| Average | 5-6 | Some thinking but limited depth |
| Poor | 3-4 | Lacking independent thinking, mainly restating others' viewpoints |
| Very Poor | 0-2 | Completely lacking thinking, all content is paraphrased |

**Evaluation Points**:
- Whether proposing own viewpoints or hypotheses
- Whether critically analyzing problems
- Whether integrating and comparing different viewpoints
- Whether anticipating follow-up developments

## Grade Classification Standards

| Total Score | Grade | Description |
|-------------|-------|-------------|
| 90-100 | A / Excellent | Meets excellent standards for course papers |
| 80-89 | B / Good | Meets good standards for course papers |
| 70-79 | C / Average | Meets basic requirements for course papers |
| 60-69 | D / Pass | Basically meets course requirements, needs improvement |
| 0-59 | F / Fail | Does not meet basic course requirements |

## Annotation Examples

### Good Annotation Examples

```
[Strength] Introduction section
Your research background introduction is very comprehensive, accurately grasping
the current state of the field, and fully explaining the necessity and importance
of the research. Suggest maintaining this writing style in the future.
```

```
[Suggestion] Paragraph 3, Sentence 2
After "The experimental results show..." is lacking data interpretation.
Suggest adding:
"This result indicates that [Variable A] has a significant positive effect on
[Variable B], consistent with [Scholar]'s research findings."
```

```
[Issue] Conclusion section
Inconsistency between conclusion and body results:
- Body: "The difference between the two groups was not significant (p>0.05)"
- Conclusion: "There was a significant difference between the two groups"
Please verify the data and unify the expression.
```

```
[Question] Methods section
You mentioned using a "randomized controlled experiment," but the sample size is
only 20 people. How do you ensure the statistical power of the experiment?
Suggest supplementing the sample size calculation basis.
```

```
[Reference] Writing Improvement
Suggested reading to improve academic writing:
1. "Academic Writing Guide" - Improve paper structure planning ability
2. "APA Format Guide" - Standardize citations and reference formats
```

## Grading Focus by Paper Type

### 1. Course Papers
- Key evaluation: Understanding and application of course content
- Focus: Whether applying theories and methods learned in class

### 2. Survey Reports
- Key evaluation: Scientific rigor of survey design, standardization of data analysis
- Focus: Sample selection, questionnaire design, data processing

### 3. Literature Reviews
- Key evaluation: Comprehensiveness of literature collection, depth of analysis
- Focus: Whether covering main related research, ability to form own viewpoint

### 4. Case Analyses
- Key evaluation: Typicality of case selection, logical analysis
- Focus: Completeness of case description, accuracy of theory application

### 5. Lab Reports
- Key evaluation: Reasonableness of experiment design, standardization of data processing
- Focus: Detail level of method description, depth of result analysis
