# 抖音爆款嗅探

分析抖音近期爆款视频，为创作者提供趋势洞察和内容灵感。

## 核心能力

- **热门视频搜索**: 根据关键词搜索抖音近期爆款内容
- **趋势分析**: 识别爆款视频的共性规律
- **创意灵感**: 提供内容创作方向建议

## 使用流程

### 1. 关键词分析

接收用户输入的关键词后，进行以下分析：
- 核心主题识别
- 潜在热门方向扩展
- 相关长尾关键词建议

### 2. 爆款视频探查

使用以下方法探查爆款视频：

1. **网络搜索**: 搜索抖音热门视频、话题榜单
2. **话题分析**: 搜索相关话题热度
3. **创作者分析**: 搜索同领域热门创作者

### 3. 信息提取与整理

收集并整理以下信息：
- 视频标题、播放量、点赞数
- 发布时间和时效性
- 内容类型和表现形式
- 热门评论分析

### 4. 爆款规律总结

输出分析报告，包含：
- **爆款元素**: 选题、标题、封面、时长等
- **内容模式**: 常见叙事结构
- **时机把握**: 发布时间规律
- **差异化建议**: 如何脱颖而出

## 触发示例

- "帮我探查近期'露营'相关的爆款视频"
- "搜索抖音上'职场穿搭'热门内容"
- "分析'一人食'话题的爆款规律"
- "给我一些'家居好物'的短视频创意"

## 注意事项

1. **时效性**: 优先搜索近期（1-3个月内）的爆款内容
2. **数据来源**: 综合多个来源进行验证
3. **平台特性**: 考虑抖音用户画像和内容偏好
4. **合规性**: 不涉及版权内容或敏感话题
