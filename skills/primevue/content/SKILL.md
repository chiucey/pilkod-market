## Components

### Form Components

#### Text Inputs
- [InputText](https://primevue.org/inputtext): InputText is an extension to standard input element with theming.
- [InputNumber](https://primevue.org/inputnumber): InputNumber is an input component to provide numerical input.
- [InputMask](https://primevue.org/inputmask): InputMask component is used to enter input in a certain format such as numeric, date, currency, email and phone.
- [Textarea](https://primevue.org/textarea): Textarea adds styling and autoResize functionality to standard textarea element.
- [InputOtp](https://primevue.org/inputotp): Input Otp is used to enter one time passwords.
- [KeyFilter](https://primevue.org/keyfilter): A keyfilter is a directive used to block individual keystrokes based on a pattern.

#### Selection Components
- [Select](https://primevue.org/select): Select is used to choose an item from a collection of options.
- [MultiSelect](https://primevue.org/multiselect): MultiSelect is used to select multiple items from a collection.
- [CascadeSelect](https://primevue.org/cascadeselect): CascadeSelect is a form component to select a value from a nested structure of options.
- [Listbox](https://primevue.org/listbox): Listbox is used to select one or more values from a list of items.
- [TreeSelect](https://primevue.org/treeselect): TreeSelect is a form component to choose from hierarchical data.

#### Buttons & Toggles
- [Button](https://primevue.org/button): Button is an extension to standard input element with icons and theming.
- [ToggleButton](https://primevue.org/togglebutton): ToggleButton is used to select a boolean value using a button.
- [ToggleSwitch](https://primevue.org/toggleswitch): ToggleSwitch is used to select a boolean value.
- [SelectButton](https://primevue.org/selectbutton): SelectButton is used to choose single or multiple items from a list using buttons.
- [SplitButton](https://primevue.org/splitbutton): SplitButton groups a set of commands in an overlay with a default command.
- [SpeedDial](https://primevue.org/speeddial): When pressed, a floating action button can display multiple primary actions.

#### Checkbox, Radio & Rating
- [Checkbox](https://primevue.org/checkbox): Checkbox is an extension to standard checkbox element with theming.
- [RadioButton](https://primevue.org/radiobutton): RadioButton is an extension to standard radio button element with theming.
- [Rating](https://primevue.org/rating): Rating component is a star based selection input.
- [Knob](https://primevue.org/knob): Knob is a form component to define number inputs with a dial.
- [Slider](https://primevue.org/slider): Slider is a component to provide input with a drag handle.

#### Specialized Inputs
- [AutoComplete](https://primevue.org/autocomplete): AutoComplete is an input component that provides real-time suggestions when being typed.
- [ColorPicker](https://primevue.org/colorpicker): ColorPicker is an input component to select a color.
- [Password](https://primevue.org/password): Password displays strength indicator for password fields.
- [DatePicker](https://primevue.org/datepicker): DatePicker is a form component for date inputs.
- [FileUpload](https://primevue.org/fileupload): FileUpload is an advanced uploader with dragdrop support, multi file uploads, auto uploading, progress tracking and validations.

- [TreeTable](https://primevue.org/treetable): TreeTable is used to display hierarchical data in tabular format.
- [DataView](https://primevue.org/dataview): DataView displays data in grid or list layout with pagination and sorting features.
- [Paginator](https://primevue.org/paginator): Paginator displays data in paged format and provides navigation between pages.
- [VirtualScroller](https://primevue.org/virtualscroller): VirtualScroller is a performant approach to render large amounts of data efficiently.

#### Trees & Hierarchical Data
- [Tree](https://primevue.org/tree): Tree is used to display hierarchical data.
- [TreeSelect](https://primevue.org/treeselect): TreeSelect is a form component to choose from hierarchical data.

#### Cards & Containers

- [Panel](https://primevue.org/panel): Panel is a grouping component providing with content toggle feature.
- [Fieldset](https://primevue.org/fieldset): Fieldset is a grouping component with a content toggle feature.
- [Accordion](https://primevue.org/accordion): Accordion groups a collection of contents in panels.
- [Divider](https://primevue.org/divider): Divider is used to separate contents.
- [Toolbar](https://primevue.org/toolbar): Toolbar is a grouping component for buttons and other content.
- [Splitter](https://primevue.org/splitter): Splitter is utilized to separate and resize panels.

#### Visual Display

- [Chip](https://primevue.org/chip): Chip represents entities using icons, labels and images.
- [Tag](https://primevue.org/tag): Tag component is used to categorize content.
- [Skeleton](https://primevue.org/skeleton): Skeleton is a placeholder to display instead of the actual content.
- [ProgressBar](https://primevue.org/progressbar): ProgressBar is a process status indicator.
- [ProgressSpinner](https://primevue.org/progressspinner): ProgressSpinner is a process status indicator.

#### Images & Media

### Navigation Components

#### Menus & Navigation Bars
- [Menubar](https://primevue.org/menubar): Menubar also known as Navbar, is a horizontal menu component.
- [Menu](https://primevue.org/menu): Menu displays a list of items in vertical orientation.
- [Breadcrumb](https://primevue.org/breadcrumb): Breadcrumb provides contextual information about page hierarchy.
- [Dock](https://primevue.org/dock): Dock is a navigation component consisting of menuitems.
- [PanelMenu](https://primevue.org/panelmenu): PanelMenu is a hybrid of accordion-tree components.
- [TieredMenu](https://primevue.org/tieredmenu): TieredMenu displays submenus in nested overlays.
- [MegaMenu](https://primevue.org/megamenu): MegaMenu is a navigation component that displays submenus and content in columns.
- [Steps](https://primevue.org/stepper): The Stepper component displays a wizard-like workflow by guiding users through the multi-step progression.
- [Tabs](https://primevue.org/tabs): Tabs facilitates seamless switching between different views.

#### Context & Contextual Actions
- [ContextMenu](https://primevue.org/contextmenu): ContextMenu displays an overlay menu to display actions related to an element.

### Overlay Components

#### Dialogs & Modals
- [Dialog](https://primevue.org/dialog): Dialog is a container to display content in an overlay window.
- [DynamicDialog](https://primevue.org/dynamicdialog): Dialogs can be created dynamically with any component as the content using a DialogService.
- [ConfirmDialog](https://primevue.org/confirmdialog): ConfirmDialog uses a Dialog UI that is integrated with the Confirmation API.
- [ConfirmPopup](https://primevue.org/confirmpopup): ConfirmPopup displays a confirmation overlay displayed relatively to its target.
- [Popover](https://primevue.org/popover): Popover is a container component that can overlay other components on page.
- [Drawer](https://primevue.org/drawer): Drawer is a container component displayed as an overlay.

#### Feedback & Notifications
- [Toast](https://primevue.org/toast): Toast is used to display messages in an overlay.
- [Message](https://primevue.org/message): Message component is used to display inline messages.
- [BlockUI](https://primevue.org/blockui): BlockUI can either block other components or the whole page.

### Utility Components

#### Content Loading
- [DeferredContent](https://primevue.org/deferredcontent): DeferredContent postpones the loading the content that is initially not in the viewport until it becomes visible on scroll.
- [AnimateOnScroll](https://primevue.org/animateonscroll): AnimateOnScroll is used to apply animations to elements when entering or leaving the viewport during scrolling.
- [ScrollTop](https://primevue.org/scrolltop): ScrollTop gets displayed after a certain scroll position and used to navigates to the top of the page quickly.
- [ScrollPanel](https://primevue.org/scrollpanel): ScrollPanel is a cross browser, lightweight and skinnable alternative to native browser scrollbar.

#### Interactive Content
- [Inplace](https://primevue.org/inplace): Inplace provides an easy to do editing and display at the same time where clicking the output displays the actual content.
- [Editor](https://primevue.org/editor): Editor is rich text editor component based on Quill.
- [Terminal](https://primevue.org/terminal): Terminal is a text based user interface.

#### Labels & Form Helpers
- [FloatLabel](https://primevue.org/floatlabel): FloatLabel visually integrates a label with its form element.
- [IftaLabel](https://primevue.org/iftalabel): IftaLabel is used to create infield top aligned labels.
- [IconField](https://primevue.org/iconfield): IconField wraps an input and an icon.
- [InputGroup](https://primevue.org/inputgroup): Text, icon, buttons and other content can be grouped next to an input.

#### Layout
- [Fluid](https://primevue.org/fluid): Fluid is a layout component to make descendant components span full width of their container.

### Directives

#### Behavior Directives
- [Ripple](https://primevue.org/ripple): Ripple directive adds ripple effect to the host element.
- [Tooltip](https://primevue.org/tooltip): Tooltip directive provides advisory information for a component.
- [FocusTrap](https://primevue.org/focustrap): Focus Trap keeps focus within a certain DOM element while tabbing.

#### Style Directives
- [StyleClass](https://primevue.org/styleclass): StyleClass manages css classes declaratively to during enter/leave animations or just to toggle classes on an element.

```vue
        <h5>Basic</h5>
        <InputText v-model="value" placeholder="Enter text" />

        <h5>Floating Label</h5>
        <span class="p-float-label">
            <InputText id="float-input" type="text" v-model="floatValue" />
            <label for="float-input">Username</label>
        </span>

        <h5>Icons</h5>
        <span class="p-input-icon-left">
            <i class="pi pi-search" />
            <InputText type="text" v-model="searchValue" placeholder="Search" />
        </span>
        <span class="p-input-icon-right">
            <InputText type="text" v-model="emailValue" placeholder="Email" />
            <i class="pi pi-envelope" />
        </span>
    </div>
</template>

<script setup>
import { ref } from 'vue';
import InputText from 'primevue/inputtext';

const value = ref('');
const floatValue = ref('');
const searchValue = ref('');
const emailValue = ref('');
</script>
```

### Form with Validation

```vue
<template>
    <div class="form-demo">
        <Dialog v-model:visible="showMessage" modal header="Success" :style="{ width: '30vw' }">
            <p>Form submitted successfully!</p>
        </Dialog>

        <div class="card">
            <form @submit.prevent="handleSubmit" class="p-fluid">
                <div class="field">
                    <label for="name">Name</label>
                    <InputText id="name" v-model="formData.name"
                               :class="{ 'p-invalid': submitted && !formData.name }" />
                    <small class="p-error" v-if="submitted && !formData.name">Name is required.</small>
                </div>

                <div class="field">
                    <label for="email">Email</label>
                    <InputText id="email" v-model="formData.email"
                               :class="{ 'p-invalid': submitted && !formData.email }" />
                    <small class="p-error" v-if="submitted && !formData.email">Email is required.</small>
                </div>

                <Button type="submit" label="Submit" />
            </form>
        </div>
    </div>
</template>

<script setup>
import { ref } from 'vue';
import InputText from 'primevue/inputtext';
import Button from 'primevue/button';
import Dialog from 'primevue/dialog';

const formData = ref({ name: '', email: '' });
const submitted = ref(false);
const showMessage = ref(false);

const handleSubmit = () => {
    submitted.value = true;
    if (formData.value.name && formData.value.email) {
        showMessage.value = true;
    }
};
</script>
```
