## 七、常用计算公式汇总

### 溶液配制（C₁V₁ = C₂V₂）

**基础公式**：C₁V₁ = C₂V₂

其中：
- C₁ = 浓溶液浓度
- V₁ = 浓溶液体积（待求）
- C₂ = 稀溶液浓度
- V₂ = 稀溶液体积

**求V₁公式**：V₁ = (C₂ × V₂) / C₁

**例题**：用 10 mol/L NaOH 浓溶液配制 500 mL 0.5 mol/L NaOH 溶液
```
已知：C₁=10 mol/L，C₂=0.5 mol/L，V₂=500 mL
求：V₁

V₁ = (C₂ × V₂) / C₁
V₁ = (0.5 × 500) / 10
V₁ = 250 / 10
V₁ = 25 mL

操作：取 25 mL 10mol/L NaOH，加水稀释至 500 mL
```

### 质量计算

**公式**：质量 (g) = C (mol/L) × V (L) × Mw (g/mol)

**例题**：配制 0.5 mol/L Na₂CO₃ 溶液 200 mL，需称取 Na₂CO₃ 多少克？
```
已知：C=0.5 mol/L，V=0.2 L，Mw=105.99 g/mol

质量 = C × V × Mw
质量 = 0.5 × 0.2 × 105.99
质量 = 10.599 g

结论：称取 Na₂CO₃ 10.60 g，加水溶解并定容至 200 mL
```

### 百分比浓度

```
%(w/w) = 溶质质量(g) / 溶液总质量(g) × 100
%(w/v) = 溶质质量(g) / 溶液体积(mL) × 100
%(v/v) = 溶质体积(mL) / 溶液体积(mL) × 100
```

### 标示含量

```
标示含量% = (测得量 × 稀释倍数) / (取样量 × 标示量) × 100%
```

### 回收率

```
回收率% = [(C₂ - C₁) / C₀] × 100%
- C₁: 本底浓度
- C₂: 加标后测得浓度
- C₀: 加标浓度
```

### RSD

**公式**：
```
SD = √[Σ(xᵢ - x̄)² / (n-1)]
RSD% = (SD / x̄) × 100
```

**⚠️ 注意**：药典使用样本标准差（分母为 n-1），不是总体标准差（分母为 n）

**例题**：测定某样品含量，结果为 99.2%、98.8%、99.5%、99.0%、98.9%，计算 RSD
```
第一步：计算平均值
x̄ = (99.2 + 98.8 + 99.5 + 99.0 + 98.9) / 5
x̄ = 495.4 / 5
x̄ = 99.08%

第二步：计算偏差
| 测定值 | 偏差 (xi - x̄) | 偏差² |
|--------|---------------|--------|
| 99.2 | +0.12 | 0.0144 |
| 98.8 | -0.28 | 0.0784 |
| 99.5 | +0.42 | 0.1764 |
| 99.0 | -0.08 | 0.0064 |
| 98.9 | -0.18 | 0.0324 |

Σ(xᵢ - x̄)² = 0.0144 + 0.0784 + 0.1764 + 0.0064 + 0.0324 = 0.308

第三步：计算标准差
SD = √(0.308 / 4) = √0.077 = 0.277

第四步：计算 RSD
RSD = (0.277 / 99.08) × 100% = 0.28%

结论：RSD = 0.28%，符合药典含量测定 RSD ≤ 1.0% 的要求
```

### 溶出度

**标准公式**（常用）：
```
溶出率 (%) = [A × V₀ × D] / [W × L] × 100%
```
- A = 供试品溶液吸光度
- V₀ = 溶出介质总体积 (mL)
- D = 稀释倍数
- W = 取样量（标示量，单位需与分母一致）
- L = 标示量（单位需与 W 一致）

**简化公式**（当 A 直接对标准曲线时）：
```
溶出率 (%) = (A ÷ K) / (标示量 × 取样量) × 100%
```
其中 K 为标准曲线斜率（A/浓度）

**例题**：布洛芬片溶出度测定
```
已知条件：
- 溶出介质体积：900 mL
- 取样量：标示量 0.3 g（相当于1片）
- 吸光度 A = 0.452
- 标准曲线方程：A = 0.0683 × C + 0.0024（C 单位：mg/mL）
- 标示量：100 mg/g

计算标准曲线斜率 K = 0.0683

第一步：计算浓度
C = (A - 0.0024) / 0.0683
C = (0.452 - 0.0024) / 0.0683
C = 0.4496 / 0.0683
C = 6.59 mg/mL

第二步：计算溶出量
溶出量 = C × V × 稀释倍数
溶出量 = 6.59 × 900 × 1
溶出量 = 5931 mg = 5.931 g

第三步：计算溶出率
溶出率 = (溶出量 / 取样量) × 100%
溶出率 = (5.931 / 6.0) × 100%
溶出率 = 98.85%

结论：溶出率 98.85%，符合药典要求（≥70%）
```

**⚠️ 注意事项**：
- 每次取样后需补充等体积介质（累积溶出率计算时注意体积校正）
- 标准曲线需定期验证
- 多时间点测定时需记录每次取样体积

## 九、常见问题处理

### 浓度计算问题

**Q**: 如何将 % 浓度换算为 mol/L？
**A**: 使用公式：C (mol/L) = (ρ × 10 × w%) / M
- ρ: 溶液密度 (g/mL)
- w%: 质量百分比
- M: 摩尔质量 (g/mol)

### 滴定计算问题

**Q**: 滴定度不确定时如何处理？
**A**: 使用 F 值校正
```
实际浓度 = 标定浓度 × F
F = 实际消耗体积 / 理论消耗体积
```

### 溶出度计算问题

**Q**: 多个时间点溶出度如何计算？
**A**: 绘制溶出曲线，计算 AUC 或取关键时间点汇总
