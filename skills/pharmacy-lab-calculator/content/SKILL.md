## 计算类型详细规范

### 1. 溶液配制（C₁V₁ 稀释）

**识别关键词**：浓溶液、稀溶液、稀释、C₁V₁、储备液、母液

**必需参数**：
- 浓溶液浓度 C₁（或稀溶液浓度 C₂）
- 目标体积 V₂（或浓溶液体积 V₁）

**公式**：
```
C₁V₁ = C₂V₂（稀释定律）
V₁ = (C₂ × V₂) / C₁
V₂ = (C₁ × V₁) / C₂
```

### 2. 浓度换算

**识别关键词**：浓度换算、摩尔浓度、质量浓度、百分比浓度、mg/mL、μg/mL、mol/L换算

**必需参数**：
- 已知浓度及其单位
- 目标浓度单位
- 溶质分子量（如涉及摩尔换算）

### 3. 动物给药剂量

**识别关键词**：给药剂量、动物实验、小鼠给药、大鼠给药、注射体积、mg/kg、尾静脉、腹腔

**必需参数**：
- 药物剂量（mg/kg）或总剂量（mg）
- 动物体重（g 或 kg）
- 溶液浓度（mg/mL）

**公式**：
```
给药剂量 (mg/kg) = 药物总剂量 (mg) / 体重 (kg)
给药体积 (mL) = 剂量 (mg/kg) × 体重 (kg) / 溶液浓度 (mg/mL)
```

### 4. 标示含量测定

**识别关键词**：标示含量、含量测定、标示量、片剂含量、胶囊含量

**必需参数**：
- 样品测定值（吸光度、滴定体积等）
- 标准曲线斜率或滴定液浓度
- 取样量
- 稀释倍数
- 标示量（规格）

### 5. 回收率计算

**识别关键词**：回收率、加样回收、加标回收、回收率试验

**必需参数**：
- 本底测得量 C₁
- 加标后测得量 C₂
- 加入标准品量 C₀

**公式**：
```
回收率 (%) = (C₂ - C₁) / C₀ × 100%
```
⚠️ 所有浓度必须用相同单位

### 6. RSD（相对标准偏差）

**识别关键词**：RSD、相对标准偏差、精密度、数据分散、标准差

**必需参数**：
- 一组测定数据（n ≥ 2）

**公式**：
```
平均值 x̄ = Σxᵢ / n
SD = √[Σ(xᵢ - x̄)² / (n-1)]      ← 样本标准差（药典采用）
RSD (%) = (SD / x̄) × 100%
```
⚠️ 药典使用样本标准差（分母为 n-1），不是总体标准差（分母为 n）

### 7. 滴定分析计算

**识别关键词**：滴定、滴定度、标定、含量滴定、酸碱滴定

**必需参数**：
- 滴定体积 V（mL）
- 滴定液浓度 M（mol/L）
- 被测物分子量 Mw（g/mol）
- 样品质量 W（g）

**公式**：
```
含量 (%) = (V × M × Mw) / W × 100%
```
⚠️ V 用 mL，M 用 mol/L 时，计算中 ×1000/1000 = ×1（自动抵消）

### 8. 溶出度计算

**识别关键词**：溶出度、溶出率、溶出曲线、溶出测定

**必需参数**：
- 供试品吸光度 A
- 标准曲线斜率 K（A/浓度）
- 溶出介质体积 V₀（mL）
- 取样量 W（g 或标示量）
- 稀释倍数 D

**公式**：
```
第一步：浓度 C = (A - b) / K（标准曲线截距）
第二步：溶出量 = C × V₀ × D
第三步：溶出率 (%) = (溶出量 / 标示量) × 100%
```

### 9. ppm/ppb 换算

**识别关键词**：ppm、ppb、百万分之一、十亿分之一、mg/L、μg/L

**必需参数**：
- 已知浓度及单位
- 目标单位

**换算关系**：
```
1 ppm = 1 mg/L = 1000 μg/L = 1000 ppb
1 ppb = 1 μg/L = 1 ng/mL
1 % = 10 g/L = 10000 mg/L = 10000000 ppm
```

### 10. 数据修约

**识别关键词**：修约、有效数字、数据处理、四舍六入

**规则**：遵循"四舍六入五成双"规则
```
- 4舍去，6进入
- 5后有数则进，5后无数看奇偶（5前一位是奇数则进，偶数则舍）
```

### 11. 处方配比计算

**识别关键词**：处方、配比、处方量、制剂、投料量

**原则**：主药 + 基质/辅料 = 总处方量
需根据处方量和实际投料量进行换算。

## 单位换算（内建知识）

**体积**：
- 1L = 1000mL = 1000cm³
- 1mL = 1000μL

**质量**：
- 1kg = 1000g = 10⁶mg = 10⁹μg = 10¹²ng

**浓度**：
- 1mol/L = 1000mmol/L = 10⁶μmol/L
- 1ppm = 1mg/L = 1000ppb

## 计算准确性保障

**所有公式必须遵循以下原则**：

1. **单位一致性**：代入公式前必须统一单位（mL↔L，mg↔g，mol/L↔mmol/L）
2. **公式来源**：所有公式均基于药典《中国药典》2020年版及药学基础理论
3. **单位换算内置**：
   - V 必须用 mL，M 用 mol/L 时：
     - 质量 (g) = M (mol/L) × V (mL) / 1000 × Mw (g/mol)
   - 质量浓度 (g/L) = 物质的量浓度 (mol/L) × 摩尔质量 (g/mol)
4. **有效数字**：中间计算多保留一位，最终结果按规范修约
5. **可复验**：每一步计算必须清晰展示，结果可被用户验证
