# 品牌及运营设计师晋升评估标准

## 各职级晋升标准对比

### 初级设计师 → 资深设计师

| 评估维度 | 标准要求 | 评估方式 |
|----------|----------|----------|
| **专业技能** | | |
| 设计执行 | 能够独立完成中等复杂度品牌/运营设计项目 | 项目审核 |
| 设计质量 | 设计稿达标率≥85%，符合品牌规范 | 质量记录 |
| 设计效率 | 能够在规定周期内交付，平均周期缩短10%+ | 时间记录 |
| **业务贡献** | | |
| 项目支撑 | 主导完成3+个中等复杂度项目 | 项目清单 |
| 业务理解 | 深入理解业务目标，设计产出支撑业务指标 | 业务反馈 |
| 转化贡献 | 设计相关转化率提升≥15% | 数据验证 |
| **协作成长** | | |
| 跨部门协作 | 主导或深度参与跨部门项目≥3个 | 项目记录 |
| 知识分享 | 完成内部分享或文档建设≥2次 | 分享记录 |
| 指导带教 | 指导初级设计师或实习生≥1人 | 导师记录 |
| **创新贡献** | | |
| 流程优化 | 提出并实施设计效率提升方案≥1个 | 方案记录 |
| 方法创新 | 引入或创新设计方法≥1项 | 方法文档 |

### 资深设计师 → 首席设计师/设计专家

| 评估维度 | 标准要求 | 评估方式 |
|----------|----------|----------|
| **专业深度** | | |
| 复杂项目 | 主导完成5+个高复杂度/战略性项目 | 项目清单 |
| 专业引领 | 在某一设计领域具有专家级能力 | 专业评估 |
| 行业洞察 | 对行业趋势、设计趋势有深入洞察 | 洞察报告 |
| **业务影响** | | |
| 战略支撑 | 设计工作直接支撑公司/部门战略目标 | 战略关联 |
| 业务增长 | 设计驱动的业务增长贡献可量化衡量 | 业务数据 |
| 品牌建设 | 主导的品牌设计工作产生显著品牌价值 | 品牌指标 |
| **团队贡献** | | |
| 团队建设 | 主导团队能力提升项目，建立培训体系 | 培训记录 |
| 标准建立 | 建立或优化团队设计标准/流程≥2项 | 标准文档 |
| 人才梯队 | 培养资深设计师≥1人 | 晋升记录 |
| **战略贡献** | | |
| 前瞻布局 | 提出设计战略建议并被采纳≥2项 | 建议采纳 |
| 体系化建设 | 主导设计系统/品牌体系建设项目 | 项目成果 |
| 行业影响 | 参与行业分享/标准制定，提升公司影响力 | 对外输出 |

## 评估数据收集清单

### 定量指标（必须量化）

```
【设计产出类】
- 完成设计项目总数：____个
- 主导项目数：____个
- 参与项目数：____个
- 设计稿通过率：____%
- 设计周期平均时长：____天
- 按时交付率：____%

【业务贡献类】
- 设计相关转化率变化：____%
- 参与活动/项目GMV变化：____%
- 用户满意度评分变化：____
- 品牌相关指标变化：____

【效率提升类】
- 设计效率提升比例：____%
- 设计模板复用次数：____次
- 自动化/工具开发产出：____项
```

### 定性指标（需提供事例）

```
【专业能力】
- 代表性设计作品案例（3-5个）
- 设计方法论创新或沉淀
- 行业/专业领域的独特见解

【协作影响力】
- 跨部门协作项目及成效
- 团队内部知识分享
- 对初级成员的指导培养

【战略贡献】
- 对业务策略的理解和建议
- 设计战略层面的思考
- 未来规划与愿景
```

## 评估常见问题与建议

### 常见问题

| 问题 | 问题描述 | 改进建议 |
|------|----------|----------|
| 数据不足 | 业绩描述缺乏量化数据支撑 | 提前收集项目数据，建立个人成果档案 |
| 角色模糊 | 未清晰区分个人贡献与团队成果 | 明确标注个人主导/独立完成部分 |
| 缺乏案例 | 只有概述没有具体项目说明 | 选择2-3个代表性项目详细描述 |
| 发展不明 | 晋升后规划笼统不具体 | 结合目标职位要求制定SMART计划 |
| 佐证缺失 | 缺少第三方评估或数据验证 | 收集上级评价、业务方反馈作为补充 |

### 撰写技巧

1. **数据先行**：用具体数字开头，再用描述性语言补充
   - ✅ "转化率提升32%，从行业平均的2.1%提升至2.8%"
   - ❌ "转化率有显著提升，效果不错"

2. **结构清晰**：按"背景-行动-成果-反思"逻辑组织案例

3. **突出差异**：强调与同级设计师的差异化优势

4. **第三方视角**：适当引用上级评价、业务方反馈增强可信度

5. **未来导向**：展现对更高职位的理解和胜任信心

*本评估标准为通用参考，具体公司/团队可依据实际情况调整*
