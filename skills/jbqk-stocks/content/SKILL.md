# 基本情况选股系统

## 技能定位

专注于**基本面量化筛选**的选股系统，根据最新财务数据对股票池进行多维度对比排名。

## 适用场景

- 用户给出股票名单，要求"按基本面"分析和排名
- 用户要求"选估值低的股票"、"选增长最快的股票"
- 用户要求"基本面排名"

## 核心维度（基本面六芒星）

| 维度 | 指标 | 权重 | 评分标准 |
|------|------|------|---------|
| 盈利能力 | 净利润增速、ROE、毛利率 | 25% | 越高越好 |
| 成长性 | 营收增速、净利润增速 | 25% | 越高越好（规避负增长） |
| 估值 | PE、PB、PS | 20% | 越低越好（与行业均值比） |
| 偿债能力 | 资产负债率、现金流 | 10% | 合理范围 |
| 运营效率 | 应收账款周转、存货周转 | 10% | 越快越好 |
| 股东回报 | 分红率、股息率 | 10% | 越高越好 |

## 执行流程

1. **搜集数据**：用 `batch_web_search` 并行搜集每只股票最新年报/季报数据
2. **基本面表格**：整理股价、PE、PB、营收增速、净利润增速、毛利率、ROE、股息率
3. **综合评分**：六维度评分，加权汇总
4. **生成报告**：调用 `scripts/generate_report.py` 生成 .docx
5. **发送微信**：用 `message` 工具发送

## 脚本用法

```bash
# 测试模式
python3 scripts/generate_report.py --test

# 基本面选股报告
python3 scripts/generate_report.py --type fundamental --date 20260427 \
    --stocks "股票1,股票2,股票3" \
    --codes "001,002,003"
```

## 注意事项

- 必须使用最新年报/季报数据，注明数据日期
- PE为负或数据缺失的股票标注"数据不足，排在后"
- 估值参考：PE<20为低估值，20-40为合理，>40为高估值
- 生成报告后自动发微信，无需用户手动操作
