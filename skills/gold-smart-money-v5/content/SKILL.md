# 黄金聪明钱分析系统 (Gold Smart Money Analyzer)

## 简介

基于聪明钱理论（Smart Money Theory），综合分析黄金市场四类资金流向：非商业机构（投机资金）、商业机构（产业资本）、资管资金（CTA/对冲基金）、以及ETF零售资金，结合央行购金和亚洲实物需求，输出短/中/长期多周期趋势研判。

**核心价值**：识别机构资金动向 vs 散户情绪，捕捉趋势拐点信号。

## CFTC三类资金详解

### ① 非商业（Non-Commercial）— 对冲基金/CTA/投机资金

| 指标 | 说明 | 信号 |
|------|------|------|
| 非商业净多头 | 多头-空头合约数 | 值高→拥挤风险，值低→空头回补潜力 |
| COT Index | 净多头在52周中的分位数 | >80极度看多（反向），<20极度看空（反向） |
| 周变化 | 本周净多头-上周净多头 | 正→机构看多动量，负→机构撤退 |

**解读规则**：
- 净多头创历史新高 + COT Index>80 → ⚠️ 交易拥挤，反向预警（见顶）
- 净多头创历史新低 + COT Index<20 → ✅ 空头回补机会（见底）
- 净多头上升 + 价格上升 → 健康看多
- 净多头下降 + 价格上升 → 散户接盘，分歧预警

### ② 商业（Commercial）— 矿产商/冶炼商/掉期商

| 指标 | 说明 | 信号 |
|------|------|------|
| 商业净空头 | 空头-多头合约数 | 值高→矿商大量对冲产量（供应已被锁定） |
| 月变化 | 本月净空-上月净空 | 正→矿商增加对冲（中期供应压力↑） |
| 占总OI% | 商业净空占总未平仓合约比例 | 值高→产业资本看空中期 |

**解读规则**：
- 商业净空头增加（负值更负）→ 矿商增加对冲 → 中期供应压力积累 ⚠️
- 商业净空头减少（负值减少）→ 矿商减少对冲 → 供需收紧信号 ✅（中期利好）
- 商业净空头极高 + 金价上涨 → 矛盾：矿商在高位做空但价格仍涨 → 可能是逼仓行情

### ③ 资管资金（Managed Money）— 对冲基金子集/CTA动量

| 指标 | 说明 | 信号 |
|------|------|------|
| 资管净多头%（占总OI） | 资管净多头/总未平仓合约 | 值高→CTA追多拥挤，值低→CTA做空或离场 |
| 月变化 | 本月底%-上月底% | 正→动量增强，负→动量减弱 |

**解读规则**：
- MM净多头%下降 + 金价不跌 → 机构换手，散户接盘（见顶信号）
- MM净多头%上升 + 金价上升 → 机构+散户共振（健康上涨）
- MM净多头%持续>25% → 动量拥挤，回调风险高

## 评分模型（v5.1）

### 三周期加权体系

综合分 = 长期分×0.40 + 中期分×0.35 + 短期分×0.25


### 长期评分（权重40%）— 子指标各占50%

| 子指标 | 计算 | 权重 |
|--------|------|------|
| 央行购金趋势 | 本季吨数 vs 上季（环比）+ YoY | 50% |
| 供需缺口变化 | 本季缺口 vs 上季（环比）+ YoY | 50% |

**评分公式**：`long = CB_score×0.50 + SD_score×0.50`

### 中期评分（权重35%）— 三项加权

| 子指标 | 计算 | 权重 |
|--------|------|------|
| 商业净空头月变化 | 本月净空 vs 上月（方向+幅度） | 35% |
| 资管净多头%月变化 | 本月底% vs 上月底% | 35% |
| ETF月净流入 | 本月流入 vs 上月（方向+绝对水平） | 30% |

**评分公式**：`medium = COMM×0.35 + MM%×0.35 + ETF月流×0.30`

### 短期评分（权重25%）— 五项加权

| 子指标 | 计算 | 权重 |
|--------|------|------|
| COT非商业周变化 | 本周净多头 vs 上周（方向+COT Index） | 20% |
| COT非报告周变化 | 散户净多头COT Index（反向评分） | 15% |
| GLD持仓变化 | 日频持仓距高点% + 周变化 | 20% |
| 华安ETF情绪 | 连续流出天数 + 日流方向 | 25% |
| 全球ETF周流 | 周净流入方向 | 20% |

**评分公式**：`short = NC×0.20 + NR×0.15 + GLD×0.20 + 华安×0.25 + ETF周×0.20`

### 信号区间

| 综合分 | 信号 | 含义 |
|--------|------|------|
| 75-100 | 🟢强烈看多 | Smart Money全面做多，长期+中期+短期共振 |
| 60-74 | 🟢偏多 | 多周期方向一致，趋势健康 |
| 50-59 | ⚪中性 | 多空信号交织，观望 |
| 40-49 | 🔴偏空 | 空头信号主导，注意下行风险 |
| 20-39 | 🔴强烈看空 | Smart Money全面撤退，趋势极弱 |

## 矛盾识别

### 常见矛盾类型

**1. 短期拥挤 vs 长期支撑**
散户非报告净多头Index>80 + 央行持续购金
→ 散户追多极端，机构在出货 → 短期见顶风险，长期牛市不改
→ 建议：短期止盈/减仓，中长期逢低加仓

**2. 机构vs散户分歧**
非商业（机构）净多头下降 + 华安ETF（中国散户）净流入增加
→ 机构撤退，散户接盘 → 见顶预警

**3. 商业对冲 vs ETF配置**
商业净空头增加（矿商看空中期）+ ETF月流入持续（配置资金流入）
→ 产业资本vs金融资本分歧 → 中期震荡

**4. 价格与持仓背离**
GLD持仓下降 + 金价上涨 → 散户接盘，机构在卖
GLD持仓上升 + 金价横盘 → 机构吸筹，即将拉升

## 质量标准

1. **每个数据点必须标注更新时间**，过期数据必须注明
2. **环比数据（本周/上周/上月）必须完整**，缺项需标注"数据不可用"
3. **矛盾点必须显式输出**，绝不隐藏分歧
4. **评分必须带方向**：上涨/下跌/持平，不能只给中性
5. **信号必须有操作建议**：买入/持有/减仓/清仓
6. **代码必须可独立运行**：无API密钥依赖，有备用源降级方案
