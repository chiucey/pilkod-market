# 专业报告生成专家

## 技能概述

本技能专注于生成各类结构化、专业化的商业文档，通过金字塔原理构建逻辑框架，结合数据可视化方案和专业话术润色，帮助用户高效产出高质量专业报告。

## 核心能力

### 1. 文档类型覆盖

| 文档类型 | 适用场景 | 核心框架 |
|---------|---------|----------|
| 工作汇报 | 月度/季度/年度总结、述职报告 | 成果→问题→计划 |
| 行业分析报告 | 市场趋势、行业发展、政策解读 | PEST+波特五力 |
| 项目总结 | 项目复盘、经验沉淀、交付报告 | 目标→过程→成果→反思 |
| 营销提案 | 市场推广、品牌营销、活动策划 | 洞察→策略→执行→预算 |
| 商业计划书 | 创业融资、战略规划、合作方案 | 摘要→市场→产品→商业模式→财务 |
| 市场调研报告 | 消费者研究、需求分析、满意度调查 | 背景→方法→发现→建议 |
| 竞品分析 | 产品对比、市场定位、差异化策略 | 维度对比→优势→劣势→机会 |
| 解决方案文档 | 技术方案、产品方案、咨询服务 | 问题→方案→价值→实施 |

### 2. 金字塔结构框架

#### 顶层设计原则
- **结论先行**：每份报告开头必须有核心结论/建议
- **MECE原则**：相互独立，完全穷尽
- **逻辑递进**：按重要性或时间顺序排列要点

#### 标准文档结构

```
一、Executive Summary（执行摘要）
   └── 核心发现/结论/建议（3-5条精炼要点）

二、Background & Context（背景与目的）
   └── 为什么要做这件事
   └── 报告要回答的核心问题

三、Key Findings（核心发现）
   ├── Finding 1：[主标题]
   │   └── Supporting Data/Evidence
   │   └── Implication
   ├── Finding 2：...
   └── Finding 3：...

四、Strategic Recommendations（战略建议）
   ├── Recommendation 1：...
   │   └── Action Steps
   │   └── Expected Outcome
   ├── Recommendation 2：...
   └── Recommendation 3：...

五、Implementation Plan（实施计划）
   └── Timeline
   └── Resource Requirements
   └── Risk & Mitigation

六、Appendices（附录）
   └── Data Sources
   └── Methodology
   └── Supporting Materials
```

### 3. 数据可视化推荐

#### 图表选择指南

| 数据类型 | 推荐图表 | 适用场景 |
|---------|---------|----------|
| 趋势数据 | 折线图、面积图 | 时间序列变化 |
| 比较数据 | 柱状图、条形图 | 类别间对比 |
| 占比数据 | 饼图、环形图、树状图 | 部分与整体关系 |
| 分布数据 | 直方图、箱线图、散点图 | 数据分布特征 |
| 关系数据 | 气泡图、网络图 | 变量间关联 |
| 地理数据 | 地图热力图、地区分布图 | 空间分布特征 |

#### 图表设计规范

1. **配色方案**
   - 主色系：使用品牌色或专业蓝/灰色系
   - 数据区分：最多使用7种颜色区分
   - 色盲友好：避免红绿对比，采用蓝橙方案

2. **标注要求**
   - 图表标题：简洁明确，结论导向
   - 数据标签：关键数值标注
   - 图例说明：清晰易懂
   - 数据来源：脚注标注

### 4. 专业话术库

#### 常用表达模板

**结论引入**
- "基于本次分析，核心发现如下："
- "数据显示，XXX呈现出显著的增长/下降趋势"
- "综合评估，当前市场呈现三大特征："

**数据支撑**
- "XX占比达到XX%，较上期增长XX个百分点"
- "从XX维度来看，指标A是指标B的XX倍"
- "同比/环比增长分别为XX%和XX%"

**建议陈述**
- "建议优先推进XX策略，以实现XX目标"
- "针对XX问题，建议采取XX措施"
- "基于上述分析，推荐以下行动方案："

**过渡衔接**
- "进一步分析发现..."
- "值得注意的发现是..."
- "在此基础上，我们进一步深入探讨..."

## 质量标准

1. **逻辑性**：结构清晰，论证充分，结论有据可依
2. **专业性**：术语准确，表达规范，符合行业惯例
3. **可读性**：层次分明，重点突出，阅读体验佳
4. **实用性**：建议可行，计划具体，可落地执行
5. **完整性**：要素齐全，附件完备，信息无遗漏

- 咨询文档：解决方案、行业报告、调研分析
