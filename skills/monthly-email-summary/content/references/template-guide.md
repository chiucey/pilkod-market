# 月度邮件总结技能 - 参考文档

## 模板说明

### 四大板块定义

| 板块 | 定义 | 举例 |
|------|------|------|
| **本月主要对接沟通事项** | 正在沟通中、需多部门协调、等待决策的事项 | "与QA确认XX项目开发进度"、"与销售团队统计成本投入" |
| **已落地完成工作** | 有明确结论/交付/完成状态的事项 | "已完成XX报告"、"已确认XX申请"、"已开通权限" |
| **遗留待跟进事务** | 未完成、卡点、需后续持续跟进的事项 | "待实验室验证XX能力"、"待客户回复确认" |
| **重点注意事项** | 关键截止日期、重要提醒、需特别关注的风险点 | "6月1日前需完成"、"注意XX限值变更" |

## 分类判定规则

### 1. 判断"已落地完成"的标准
- 有明确的完成结论
- 对方已确认/已回复
- 有交付物产出
- 行动点已执行完毕

### 2. 判断"遗留待跟进"的标准
- 行动点未完成
- 等待对方回复
- 需要内部资源协调
- 有技术/能力问题待解决

### 3. 判断"重点注意事项"的标准
- 有明确截止日期
- 涉及标准/法规变更
- 影响后续工作安排
- 需多部门协作的关键节点

## 内容精炼原则

1. **每项不超过20字**：用最简洁语言概括
2. **去除"详细总结"**：直接给出结论
3. **合并同类项**：多封相关邮件合并为一条
4. **保留关键信息**：时间、人名、标准号等必要细节

## 邮件格式识别

### 支持的输入格式
- `.docx` 文件（使用 extract_docx_text.py 提取）
- `.txt` 纯文本
- 直接粘贴的邮件内容
- 包含日期标注的邮件列表

### 日期范围识别
- **单日邮件**：如 "26/5/22"
- **多日范围**：如 "26/5/18-26/5/22"
- **整月汇总**：如 "5月份"、"5月工作总结"

## 示例：同一主题多封邮件的合并

**原始多封邮件**：
1. Elva要求提供扩项标准 (5/18)
2. David要求Sprite提供建议 (5/18)
3. Sprite列出需求标准 (5/19)
4. David要求评估实验室条件 (5/20)
5. Carrie要求销售统计成本 (5/20)

**合并后**：
> 8月CNAS&CMA扩项准备，协调Elva/ David/ Sprite跟进标准统计，与实验室评估GB/T 46508-2025可行性

## 输出文件命名规范

```
[年份]年[月份]月度工作汇总.md
示例：2026年5月月度工作汇总.md
```
