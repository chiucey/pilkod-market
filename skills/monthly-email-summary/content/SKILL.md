# 月度工作邮件汇总技能

将多日/整月工作邮件内容精炼整理为规范月度工作总结报告。

## 工作流程

### 第一步：接收并分析邮件内容

1. **解析用户输入**：
   - 用户可发送 `.docx`、`.txt` 或直接粘贴邮件文本
   - 识别邮件日期范围（如"5月份"、"5月18日-22日"）

2. **提取邮件关键信息**：
   - 日期
   - 主题
   - 发送人/接收人
   - 核心内容摘要
   - 行动点（Action Items）

### 第二步：智能分类整理

按以下四大板块自动归类：

| 板块 | 判定标准 |
|------|----------|
| **本月主要对接沟通事项** | 需要跟进讨论、等待回复、需协调资源的事项 |
| **已落地完成工作** | 已确认完成、已交付、有明确结论的事项 |
| **遗留待跟进事务** | 未完成、待对方回复、卡点待解决的事项 |
| **重点注意事项** | 关键时间节点、注意事项、需特别关注的事项 |

### 第三步：按模板格式输出

```markdown
# [月份]月度工作汇总

## 一、本月主要对接沟通事项
（简洁列举主要沟通对象和事项）

## 二、已落地完成工作
（已完成的重点工作和交付成果）

## 三、遗留待跟进事务
（未完成事项及下一步行动）

## 四、重点注意事项
（关键节点、截止日期、特别提醒）
```

### 第四步：交付文件

1. **Markdown 直接输出**：适合复制粘贴到其他文档
2. **生成 .docx 文件**（如需要）：使用 minimax-docx 技能转换

## 输出规范

- **语言风格**：简洁正式，适合工作复盘存档
- **内容精简**：去除冗余废话，每项不超过两行描述
- **日期标注**：关键事项需标注时间节点
- **优先级排序**：按重要程度排列

## 示例

**输入**：用户提供5月份工作邮件文本（约50-100封邮件内容）
