# 金融公众号文章模板参考

## 模板一：热点快评型

**适用场景：** 降息、降准、监管政策出台、重大市场事件

```
【标题】事件+影响："降准落地，债市怎么走？"

【引】XX月XX日，[央行/证监会/XX]宣布[事件]，这是[多久以来第几次/市场预期如何]。

【数据】本次[降准0.XX个百分点/其他]，释放流动性约[X]亿元，
近一年类似操作后市场表现：[数据表格]

【分析】为什么此时出台？
1. [宏观背景]
2. [政策意图]
3. [市场影响机制]

【结论】短期/中长期，配置建议如下：
- 债券/债基：[具体建议]
- 权益资产：[具体建议]

【风险提示】历史表现仅供参考，不构成投资建议。理财有风险。
```

## 模板二：基金产品解读型

**适用场景：** QDII基金新发、ETF上市、热门基金深度分析

```
【标题】产品名+核心卖点："华宝油气（XXXX）值得买吗？"

【产品基本信息】基金代码、成立时间、规模、基金经理、申赎状态

【投资方向】重仓板块/资产类别 + 占比
与上一季度变化：[列表]

【业绩归因】
近一年收益率：XX%
跑赢基准：XX个百分点
夏普比率/最大回撤：[数据]

【适合人群】
- 风险偏好：[R3/R4/R5]
- 资金用途：[中长期配置/短期投机]
- 不适合：[明确说明]

【买入建议】当前时点怎么看？

【风险提示】QDII基金受汇率影响，申赎时间较长，详情见招募说明书。
```

## 模板三：资产配置型

**适用场景：** 月度配置建议、季报解读、理财科普

```
【标题】时间+人群+动作："2026年二季度，稳健型投资者怎么配？"

【核心结论】（一段话，50字以内）

【宏观环境】（3个要点，每个一行）

【各类资产展望】
- 债券/债基： [结论+原因]
- 权益基金：  [结论+原因]
- 海外资产：  [结论+原因]
- 商品/黄金： [结论+原因]

【具体配置比例】
| 资产类别 | 推荐配比 | 对应产品类型 |
|---------|---------|------------|
| 货币基金  | 10%     | 现金管理    |
| 纯债基金  | 30%     | 稳健理财    |
| 混合基金  | 35%     | 平衡配置    |
| 权益基金  | 25%     | 成长配置    |

【再平衡提醒】[触发条件+建议频率]

【风险提示】大类资产配置不等于保本，历史收益不代表未来。
```

## 合规检查清单

写完文章后，逐项核对：

- [ ] 数据有来源标注（官方/第三方/媒体）
- [ ] 数据有时时间戳（不超过24h热点/72h深度）
- [ ] 无"稳赚不赔"、"收益率保证"、"100%安全"等表述
- [ ] 无贬低同业的表述
- [ ] 基金代码和基金名称对应正确
- [ ] 风险提示出现在文章结尾
- [ ] 风险提示包含：历史业绩不代表未来、市场有风险、理财需谨慎
- [ ] 涉及海外资产有汇率风险提示
- [ ] 涉及私募/高风险产品有"非公开募集"等合规表述
