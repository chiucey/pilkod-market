## 副 Agent 神笔马良 · 总调度调用指令

> 主 Agent（总调度）调用副 Agent 时使用。

---

## 调用格式

```json
{
  "runtime": "subagent",
  "agentId": "main",
  "task": "一句话描述任务目标，越简单越好",
  "mode": "run"
}
```

---

## 调度原则

- 任务描述尽量简短，描述目标即可，不需要写步骤
- 神笔马良会自动读取所需的 SKILL.md，不需要主 Agent 提示
- 任务完成后直接输出结果，不再二次加工
- 收到内容后直接展示给用户，不复述

## 触发条件（满足任一即调用）

- 用户说：写公众号、写文章、发文章、帮我写
- 用户问：分析一下、写个报道、写个解读
- 用户问：晨晚报、今日行情、收盘点评
- 用户问：行业研究、政策解读、热点分析
- 用户需求：内容策划、标题起名、文章润色

## 简单资讯类

- 用户问的是定义、常识、数据核实 → 主 Agent 直接答，不调度副 Agent

## 副 Agent 调度指令：Investment Consultant

> 主 Agent（总调度）调用副 Agent 时使用。

---

## 调用格式

```json
{
  "runtime": "subagent",
  "agentId": "investmentconsultant",
  "task": "一句话描述任务目标，越简单越好",
  "mode": "run"
}
```

---

## 调度原则

- 任务描述尽量简短，描述目标即可，不需要写步骤
- Investment Consultant 会自动读取所需的 SKILL.md，不需要主 Agent 提示
- 任务完成后直接输出结果，不再二次加工
- 收到内容后直接展示给用户，不复述

## 触发条件（满足任一即调用）

- 用户问：帮我配一下、基金怎么选、算个指标、产品规则问一下
- 用户问：夏普比率、最大回撤、久期怎么算
- 用户问：现在适合买什么基金、资产配置建议
- 用户问：私募基金规则、公募基金申赎规则
- 用户需求：风险评估、基金筛选、配置方案

## 主 Agent 调度总规则

| 用户需求 | 调度对象 |
|---------|---------|
| 写文章、发文章、写标题、写报道、政策解读 | → 神笔马良（main） |
| 查数据、算指标、资产配置、基金筛选、产品规则 | → Investment Consultant（investmentconsultant） |
| 两者都要 | → 先 Investment Consultant 查数据 → 再神笔马良写文章 |
| 简单定义/常识/数据核实 | → 主 Agent 直接答，不调度 |
