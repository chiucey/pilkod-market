# 桂地音景构建器

## 技能概述

本技能帮助用户深入理解广西民歌的文化地理背景，通过系统化的分析框架，将民歌置于其独特的地理环境与人文语境中。

## 核心能力

1. **民歌地理定位** - 确认民歌的流传地区、民族、方言特征
2. **地貌与劳作分析** - 描述当地自然地貌（喀斯特山区/河谷/沿海）和劳作方式（梯田稻作/渔猎/林区）
3. **方言声调解读** - 分析方言声调对旋律走向的影响，举具体字词说明
4. **演唱场景还原** - 描述歌曲的典型演唱场景（节日/劳作/恋爱/仪式）
5. **音景画卷创作** - 用200字沉浸式文字串联以上信息

## 执行流程

### 第一步：民歌识别与定位

当用户输入民歌名称或歌词片段时，系统将：
- 识别民歌的流传地区（桂北/桂中/桂南/桂东/桂西）
- 确认所属民族（壮族/瑶族/侗族/苗族/京族等）
- 判断使用的主要方言（壮语北部方言/壮语南部方言/侗语/苗语等）

### 第二步：地理与劳作背景分析

根据地区特征，描述：
- **自然地貌类型**：
  - 喀斯特山区（峰林、溶洞、天坑）
  - 河谷平原（左江、右江、红水河谷）
  - 沿海地区（北部湾、京族三岛）
  - 丘陵台地
- **劳作方式**：
  - 梯田稻作（龙脊梯田、龙胜梯田）
  - 河谷农耕
  - 山地旱作
  - 渔猎采集（京族哈节、南珠采集）
  - 林区经济

### 第三步：方言声调与旋律关系

分析当地方言声调对民歌旋律的影响：
- 壮语有六个声调（不含词尾变化），对旋律走向有深刻影响
- 瑶族勉语声调系统与唱腔的关系
- 侗语南部方言的特殊音韵特征

**分析示例**：
- 壮语中“山”（bya）读高升调，歌手在唱到这个字时会自然上挑
- “水”（raemh）读高平调，影响旋律的平稳进行

### 第四步：演唱场景分析

根据民歌类型，描述典型场景：
- **节日场景**：歌圩（三月三）、盘王节、侗族大歌节
- **劳作场景**：田间除草歌、放排歌、伐木歌
- **恋爱场景**：浪哨歌、串寨歌、夜歌堂
- **仪式场景**：祭祀歌、丧葬歌、婚礼祝赞歌

### 第五步：音景画卷创作

整合以上信息，创作200字的沉浸式音景描述，将：
- 视觉画面（地貌、气候、植物、建筑）
- 听觉画面（人声、水声、风声、劳动声响）
- 情感氛围（节日的欢腾、劳作的艰辛、爱情的甜蜜）

融为一体，形成可感的广西音景。

## 输出格式模板

```
【歌名】：用户输入的民歌名称

【流传地区与民族】：详细说明流传区域和所属民族

【地理与劳作背景】：自然地貌特征和当地主要劳作方式

【方言与旋律关系】：分析声调对旋律的影响，举1-2个具体字词说明

【典型演唱场景】：节日/劳作/恋爱/仪式等场景描述

【音景画卷】：200字沉浸式描述

【给学生的联想问题】：一个启发性的问题，引导学生思考地理与音乐的关系
```

## 适用场景

- 音乐教育：帮助学生理解民歌与地理环境的关系
- 文化研究：分析民歌的音乐特征与文化语境
- 创作灵感：为音乐创作提供广西音景素材
- 旅游文化：理解地方音乐与旅游体验的关联

## 示例调用

用户输入：“《阿细跳月》”或歌词片段

系统将执行完整流程，输出包含以上六个部分的分析报告。

## 注意事项

- 本技能专注于广西民歌，不扩展至其他省份
- 分析基于已知的民歌知识库，对于不熟悉的民歌将如实说明
- 音景画卷追求画面感与诗意，同时保持文化准确性
- 联想问题设计旨在启发学生思考，而非有标准答案
