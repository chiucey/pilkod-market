## 一、整体视频提示词

### 1.1 基础提示词
```
[视频风格]风格的视频，关于[视频主题]，[文化元素]相关，[目标平台]平台适配
```

**示例**：
```
纪录片风格的视频，关于清明节气与传统农耕文化，清明节气相关，微信平台适配
```

### 1.2 详细描述提示词
```
一段关于[视频主题]的[视频风格]风格视频，[文化元素]为背景，展现[具体场景或内容]。[视觉风格描述]，[光影效果]，[色彩基调]，[动态元素]。[质量要求]，适合[目标平台]平台传播。
```

**参数解释**：
- **视觉风格**：写实、水墨、现代、简约、华丽等
- **光影效果**：自然光、戏剧光、柔和光、强对比等
- **色彩基调**：温暖色调、冷色调、复古色调、鲜艳色彩等
- **动态元素**：流畅运动、缓慢推移、快速切换、动态转场等
- **质量要求**：高清、4K、电影质感、专业制作等

### 1.3 完整提示词示例
```
cinematic documentary video about Qingming Festival and traditional farming culture, 
showcasing the connection between solar terms and agricultural wisdom, 
realistic visuals, natural lighting, warm color palette, smooth camera movements, 
4K quality, suitable for WeChat video platform, educational and informative style.
```

## 二、分镜头提示词模板

### 2.1 开场镜头（0-10秒）
**目的**：吸引注意力，引出主题

**提示词结构**：
```
[开场场景]的[景别]镜头，[视觉元素]突出，[运动方式]，[情感基调]，[技术参数]
```

**参数选项**：
- **开场场景**：文物特写、自然景观、历史场景、现代对比
- **景别**：特写、中景、全景、大远景
- **视觉元素**：焦点物体、色彩对比、光影效果
- **运动方式**：推镜头、拉镜头、摇镜头、固定镜头
- **情感基调**：神秘、庄严、亲切、震撼、温馨
- **技术参数**：慢动作、延时摄影、稳定画面

**示例**：
```
特写镜头聚焦古代青铜器纹饰，金色光线照亮细节，缓慢推近镜头，庄严神秘氛围，4K超清画质
```

### 2.2 主体内容镜头

#### 2.2.1 知识点讲解镜头
**目的**：传递核心知识点

**提示词结构**：
```
[知识点]的[呈现方式]，[视觉支持]，[解说配合]，[节奏控制]
```

**参数选项**：
- **呈现方式**：动画演示、实拍展示、图文结合、专家讲解
- **视觉支持**：图表、地图、时间轴、对比图
- **解说配合**：字幕强调、语音讲解、图文注解
- **节奏控制**：缓慢展开、节奏适中、快速切换

**示例**：
```
清明节气时间计算的动画演示，配合古代历法图表，字幕解说关键点，节奏适中便于理解
```

#### 2.2.2 文化背景镜头
**目的**：展示文化背景和历史渊源

**提示词结构**：
```
[历史时期]的[文化场景]，[时代特征]，[细节表现]，[氛围营造]
```

**参数选项**：
- **历史时期**：古代、近代、现代
- **文化场景**：生活场景、仪式活动、生产劳动
- **时代特征**：服饰、建筑、工具、习俗
- **细节表现**：纹理细节、色彩还原、动态真实
- **氛围营造**：历史感、文化氛围、情感共鸣

**示例**：
```
唐代清明时节百姓踏青场景，唐代服饰建筑特征，细节真实的历史再现，温馨欢乐的氛围
```

### 2.3 结尾镜头（最后10秒）
**目的**：总结升华，引导互动

**提示词结构**：
```
[总结场景]，[情感升华]，[视觉呼应]，[互动引导]，[结尾效果]
```

**参数选项**：
- **总结场景**：全景回顾、主题再现、现代关联
- **情感升华**：感动、思考、启发、行动
- **视觉呼应**：呼应开头、主题象征、意象表达
- **互动引导**：提问引导、行动号召、社交提示
- **结尾效果**：淡出、定格、字幕浮现、音乐收尾

**示例**：
```
现代城市清明场景全景，传统文化与现代生活结合的情感升华，呼应开场的视觉元素，字幕引导关注互动，音乐淡出结尾
```

## 七、使用建议

### 7.1 提示词优化技巧
1. **具体化**：越具体的描述效果越好
2. **层次化**：从整体到细节分层描述
3. **情感化**：加入情感词汇增强感染力
4. **技术化**：明确技术参数保证质量
5. **平台化**：针对平台特点优化提示

### 7.2 测试与迭代
1. 先生成短版本测试效果
2. 根据结果调整提示词
3. 重点关注文化准确性
4. 确保视觉质量达标
5. 验证平台适配性

### 7.3 质量控制
1. 内容准确性检查
2. 文化敏感性审核
3. 视觉质量评估
4. 技术参数验证
5. 平台兼容性测试
