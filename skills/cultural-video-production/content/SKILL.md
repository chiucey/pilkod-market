# 文化科普短视频策划技能

## 概述

本技能专为新闻从业者设计，提供文化科普短视频（行业常称"文化科普短视频"或"新媒体视觉产品"）的全流程策划支持。从创意策划到后期制作，涵盖视频制作的各个环节，特别针对节气、文物等传统文化内容与现代媒体平台的结合进行优化。

**适用场景**：
- 策划节气文化短视频（清明、冬至等）
- 制作文物科普内容
- 传统文化与现代生活结合的视频
- 新媒体平台（微信、抖音、B站等）内容制作
- 电视台/新闻客户端视觉产品制作

**触发关键词**：
- 文化科普短视频、新媒体视觉产品
- 节气视频策划、文物科普视频
- 拍摄脚本、剪辑思路、AI视频提示词
- 新闻短视频、文化传播视频
- 视频策划、拍摄方案、后期制作

## 工作流程详解

### 第一阶段：策划准备
#### 1.1 需求分析
- 明确视频主题（节气、文物等）
- 确定目标平台（微信、抖音、B站等）
- 设定视频时长和风格
- 确定制作类型（实拍、AI生成、混合）

#### 1.2 文化调研
- 收集相关文化资料
- 研究历史背景和传统习俗
- 分析现代意义和关联
- 确保内容准确性和专业性

### 第二阶段：创意开发
#### 2.1 概念策划
- 提炼核心概念
- 设计故事线
- 确定视觉风格
- 规划内容结构

#### 2.2 文案创作
- 撰写解说词
- 设计字幕内容
- 策划互动环节
- 优化语言表达

### 第三阶段：制作规划
#### 3.1 拍摄脚本
- 制作分镜头脚本
- 规划拍摄场景
- 制定设备清单
- 安排人员配置

#### 3.2 AI提示词
- 生成整体视频提示词
- 制作分镜头提示词
- 优化技术参数
- 适配平台要求

### 第四阶段：后期制作
#### 4.1 剪辑方案
- 规划剪辑节奏
- 设计转场效果
- 制定调色方案
- 规划音频处理

#### 4.2 平台适配
- 调整内容时长
- 优化视觉呈现
- 设计互动方式
- 制定推广策略

## 脚本工具使用指南

### 视频策划模板脚本
**位置**：`scripts/video_planning_template.py`
**功能**：生成视频策划方案，包括主题、概念、平台适配等
**使用方法**：
```python
from scripts.video_planning_template import VideoPlanningTemplate

planner = VideoPlanningTemplate()
plan = planner.generate_plan(
    theme="清明节气文化",
    concept="传统与现代的结合",
    platforms=["wechat", "douyin"]
)
```

### AI提示词生成脚本
**位置**：`scripts/ai_prompt_generator.py`
**功能**：生成AI视频提示词，支持多种风格和平台
**使用方法**：
```python
from scripts.ai_prompt_generator import AIPromptGenerator

generator = AIPromptGenerator()
prompts = generator.generate_video_prompt(
    subject="清明节气",
    style="纪录片",
    quality="高清",
    platform="wechat"
)
```

### 拍摄脚本模板
**位置**：`scripts/shooting_script_template.py`
**功能**：生成专业拍摄脚本，包括分镜头、设备、人员等
**使用方法**：
```python
from scripts.shooting_script_template import ShootingScriptTemplate

script_gen = ShootingScriptTemplate()
script = script_gen.generate_script(
    title="清明文化视频",
    scenes=scenes_list,
    platform="wechat"
)
```

### 剪辑思路模板
**位置**：`scripts/editing_plan_template.py`
**功能**：生成后期制作方案，包括剪辑、特效、音频等
**使用方法**：
```python
from scripts.editing_plan_template import EditingPlanTemplate

editor = EditingPlanTemplate()
plan = editor.generate_editing_plan(
    video_info=video_info_dict,
    style="科普教育",
    platform="wechat"
)
```

## 平台适配策略

### 多平台内容制作原则
1. **核心内容统一**：保持文化知识的准确性
2. **表现形式多样**：根据平台调整呈现方式
3. **互动方式适配**：设计平台特有的互动
4. **技术规格优化**：满足各平台技术要求

| 平台 | 最佳时长 | 画幅比例 | 节奏特点 | 内容策略 |

| 微信 | 1-3分钟 | 多种比例 | 叙事型 | 深度内容、知识传播 |
| B站 | 3-10分钟 | 16:9横屏 | 制作精良 | 知识深度、社区互动 |

## 常见问题解答

### Q1：如何确保文化内容的准确性？
A：使用`references/cultural_resources.md`中的权威资料，或通过技能内置的文化调研功能获取准确信息。

### Q2：AI生成的视频如何保证质量？
A：使用`scripts/ai_prompt_generator.py`生成优化提示词，结合`assets/templates/ai_prompt_template.md`中的专业模板。

### Q3：如何制作跨平台内容？
A：使用平台适配功能，首先生成核心内容，然后根据各平台特点进行调整优化。

### Q4：技能支持哪些视频制作类型？
A：支持实拍视频、AI生成视频、混合制作视频，可根据需求选择或组合使用。

### Q5：如何评估视频策划方案？
A：使用技能内置的质量评估模板，检查内容准确性、制作可行性和传播潜力。
