# 新法新规解读指南（法规解读轨道，整合自「regulation-interpreter」技能）

本指南规定「新法新规」板块**单条法规内部的解读与写作方式**，替代原先以"业务影响与合规方向指引整合表格"为主的单一产出形式，改为**贴原文、不延伸、按目标读者双版本产出**的解读方法。检索来源分级、禁止引用来源、URL链接验证等**检索类要求维持不变**（见 `references/regulation-output-guide.md` 第一至三节），本指南只规范拿到权威原文之后"怎么解读、怎么写"。

## 一、先读原文

- 用户给链接就先抓取，给文件就先读。**一切解读基于原文本身**，不得凭记忆或外部推断补充。
- 抓准关键事实字段：**发布日期、实施日期、过渡期、文号/局令号、发布机关、是否替代旧版**。这些是最不该出错的地方，不确定就核实。
- 分清材料类型：**法条全文** 与 **官方解读/问答**。二者都只做忠实梳理，均不引申。

## 二、铁律（贴原文，不延伸）

1. **只写原文有的。** 原文未覆盖的问题，明确写"本篇未覆盖，需另查《X》原文"，**绝不编造规则**。
2. **贴着原文用词。** 保留关键限定词（如"最小销售单元""独立区域""首次处理"）和标志性例子；不脱离原文表达自造术语或近义替换。
   - **俗称例外**：原文未使用的俗称/通俗指代，**不得进入"主要内容（摘录）"正文**；确有助于非专业读者理解的，仅可在**非专业版**中以"编者注"形式括注一次，并须与原文定义一致、注明其范围不等同于原文所指。
3. **摘录 ≠ 编者提示，严格分开。** 法规内容归入"主要内容（据原文梳理）"；任何业务判断、影响面、风险排序归入单列的"业务关注要点（编者提示）"。**不得把"最需警惕""红线"等主观定性混进摘录。**
4. **解读是导引，不出处方。** 不给具体到 SKU、动作、时限、优先级的整改内容——那属于另一份《自查清单》。编者提示只用"需关注/需评估/建议梳理"类方向性动词。
5. **概括不失真。** 归并、精简可以，但不得改变原意，不得把单一示例上升为普遍结论。

## 三、双受众产出

先确认目标读者；不明确时同时产两版。

**业务/专业相关人员版**——追求全、准、可操作：保留法条编号、适用情形、时限、答复期等细节，术语默认读者懂。

**非业务/非专业受众版**——换信息密度，而非逐词翻译术语：
- 砍掉操作细节，只答三问：**是什么 / 能带来什么 / 跟我有没有关系。**
- 术语就地一句话解释，或干脆不用。
- 加"一句话看懂""什么情况用得上"等抓手，用直觉场景替代法条罗列。
- 影响面提示帮读者判断"要不要往下看"；是否适用、需否推荐等专业判断交还专业岗。
- **小标题用书面但常用的词**（如"适用对象""禁止行为""违规后果""对我们的影响"），既保持简报正式度，又不引入专业术语；避免聊天口吻。

## 四、输出结构（模板，替代原"业务影响与合规方向指引整合表格"作为默认格式）

```
《X》标题
发布日期：__　实施日期：__（过渡期__）　标签：__ | __
[背景导语：谁发布、何时通过/施行、替代了什么，一段]

主要内容（据原文梳理）
1.〔一句话陈述，保留关键限定与标志性例子〕
2. ……

业务关注要点（编者提示）
〔只点方向/影响面，方向性动词，可按需标注涉及的业务线，如电商/交易、内容/社交、广告/营销、数据/AI技术、其他〕
（注：具体落地清单另行梳理。）

内容出处：__（权威官方渠道 + 可直接访问的URL链接）
```

**说明**：若用户明确要求按业务线拆分的对照表格（原「业务影响与合规方向指引」表格：主要影响/合规方向/关联业务），可在"业务关注要点（编者提示）"之后**追加**该表格作为补充产出，但默认输出以上文模板为准，且表格内容同样只给方向、不出处方。

## 五、输出前检查（强制前置，先做再出正文）

定稿正文**之前**，必须先完成以下两项客观核对——它们是绕不过去的一步，不是事后建议：

1. **字数核对**：逐版数正文汉字数，确认每版 **≤1000 字**，超出先精简再出。
2. **原文引用核对**：把稿中每一处关键限定词、数字、时限、罚则、定义、标志性例子，逐一回原文比对，确认无一处是原文没有、或被近义替换/俗称替代的。

两项通过后方可输出正文；如用户要求，将核对结果一并附在文末。

## 六、输出校验清单（随上两项一并逐条过）

- [ ] 每个要点都能在原文找到对应？无依据的删。
- [ ] 有没有原文里没有的表述/术语被加入？（近义替换也算延伸）
- [ ] 关键限定词、标志性例子是否保留且准确？
- [ ] 原文中**限定适用范围/前提的词句**是否完整保留？（如"……的除外""法律、行政法规没有规定的""本规定所称X是指……"等——漏掉这类限定会让读者误判适用范围或处罚前提，与"过度延伸"同属失真）
- [ ] 事实字段（日期、文号、过渡期）核对无误？
- [ ] "摘录"与"编者提示"是否分开？提示里有没有混进原文没有的定性/排序？
- [ ] 有没有出"处方"（动作/时限/优先级/SKU 级整改）？有则移出，降为方向性提示。
- [ ] 原文未覆盖处，是否已如实标注"需另查"，而非编造？
- [ ] 每版正文是否 ≤1000 字？
- [ ] 内容出处是否包含有效URL链接，来源是否为一级/二级/三级官方渠道（见 `regulation-output-guide.md`）？

## 七、与检索类要求的关系

本指南只改变"解读与写作方式"，以下要求**维持不变**（详见 `references/regulation-output-guide.md`）：
- 检索范围（当前年份/月份、九大重点监管领域）
- 信息来源规范（一级/二级/三级官方渠道、司法公开渠道、禁止引用来源）
- 链接要求（必须可公开访问，指向法规原文或官方公告）
- 当月无新规时的统一输出格式
- 飞书云文档自动输出流程（文档标题 `法务月刊-新法新规汇编（YYYY年MM月）`）
