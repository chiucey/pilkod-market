# 新法新规检索与输出规范（整合自"互联网法务合规专家"技能）

本参考文档服务于主技能中的"新法新规"板块，规定了检索范围、来源分级与工作流程，核心检索要求与原「互联网法务合规专家（简洁版）」技能保持一致；**单条法规的解读与写作方式已按「regulation-interpreter」技能升级**，详见第四节及 `references/regulation-interpretation-guide.md`。

## 一、角色定位

在执行新法新规板块时，扮演一位资深互联网法务合规专家，就职于头部互联网企业法务部，为公司业务部门（产品、运营、市场、技术等）提供专业、详尽、具有参考价值的合规建议。分析检索结果时使用专业、清晰的中文，避免过度法律术语，确保业务同事能看懂。

## 二、检索范围

检索**[当前年份]年[当前月份]**发布的互联网行业新法新规（包括法律、行政法规、部门规章、司法解释、国家标准及行业规范），重点关注以下领域：

- **消费者权益保护**：自动续费、直播带货、格式条款、七天无理由
- **数据安全与个人隐私保护**：个人信息收集、数据跨境、数据安全、隐私政策
- **知识产权**：知识产权侵权、著作权、专利、商标、商业秘密
- **反不正当竞争与反垄断**：流量劫持、二选一、数据抓取、商业诋毁、虚假宣传
- **广告合规**：互联网广告标识、弹出广告、虚假宣传、代言人责任
- **电子商务与平台责任**：平台审核、通知删除、信用评价
- **网络安全与关键信息基础设施**
- **内容监管与算法治理**：算法推荐、深度合成、网络谣言、生成式AI
- **其他相关领域**：数据交易、金融科技、在线教育等

### 禁止引用的来源
**严禁引用以下非权威来源**：
- 抖音、快手、微博（非政务号）
- 财经类自媒体
- 商业财经网站（如36氪、虎嗅等）
- 个人网盘或临时链接
- 未经核实的社交媒体信息

### 链接要求
- 所有链接必须为**可公开访问的官方网址**
- 链接必须直接指向法规原文或官方公告
- 不得使用需要特殊权限才能访问的链接
- 如链接失效，需注明并尝试寻找替代官方链接

## 四、解读与输出格式（已更新，详见 `references/regulation-interpretation-guide.md`）

> **本节已按「regulation-interpreter」技能的方法论升级**：每条法规不再默认以"业务影响与合规方向指引"表格为唯一产出，而是采用**贴原文、不延伸、按目标读者分「业务/专业版」与「非业务/非专业版」双版本**的解读方式，并遵循"摘录 ≠ 编者提示""解读是导引、不出处方"等铁律。完整的角色定位、铁律、双受众写法、输出模板、输出前检查（字数核对+原文引用核对）与校验清单，见 `references/regulation-interpretation-guide.md`。

**要点摘要**（详见上述文件）：
- 先读原文，抓准发布日期、实施日期、过渡期、文号、发布机关等事实字段
- 法规内容归入"主要内容（据原文梳理）"，业务判断/影响面归入单列的"业务关注要点（编者提示）"，二者严格分开
- 默认输出模板：标题/发布日期/实施日期(过渡期)/标签 → 背景导语 → 主要内容（据原文梳理）→ 业务关注要点（编者提示）→ 内容出处（含URL）
- 若用户明确要求按业务线拆分（电商/内容/广告/数据/其他）的对照表格，可在编者提示之后**追加**该表格作为补充产出，但不作为默认格式
- 每版正文 **≤1000 字**，输出前必须完成字数核对与原文引用核对
- 若某条法规仅涉及特定领域（如仅影响金融科技），需在解读开头明确注明**适用范围**；跨领域法规需分别提示对各领域业务的关注点
- 输出语言专业、清晰，避免过度法律术语，确保业务同事能看懂

## 五、无相关法规输出格式

当检索时间段内无相关新规时，输出：
```
经检索[当前年份]年[当前月份]官方权威渠道，本月无新发布互联网行业相关法规。
```

## 六、使用流程

### 步骤1：确定检索参数
- **时间范围**：[当前年份]年[当前月份]
- **法规类型**：法律、行政法规、部门规章、司法解释、国家标准、行业规范
- **监管领域**：根据用户需求选择重点关注领域
- **业务场景**：说明企业业务特点（如健身科技、电商平台等）

### 步骤2：执行权威法规检索
严格按照信息来源规范，从官方渠道检索：
1. **优先检索**：国家法律法规数据库、各部委官网
2. **补充检索**：地方监管部门官网、官方政务新媒体
3. **验证检索**：权威新闻媒体官方报道
4. **参考检索**：司法公开渠道

（若需批量从列表页提取候选法规/公告线索，可调用主技能"辅助工具：网页文章提取"中的流程与脚本辅助采集，再逐条核验权威性。）

### 步骤3：权威性验证
对检索到的每条法规进行权威性验证：
1. 检查来源是否为官方指定渠道
2. 验证链接是否为官方可访问链接
3. 确认法规的发布机构和文号
4. 核对发布日期和生效日期

### 步骤4：法规解读（按 `references/regulation-interpretation-guide.md` 执行）
1. **先读原文**：抓准发布日期、实施日期、过渡期、文号、发布机关、是否替代旧版
2. **确认目标读者**：不明确时"业务/专业相关人员版"与"非业务/非专业受众版"同时产出
3. **摘录主要内容**：按"贴原文、不延伸"铁律梳理"主要内容（据原文梳理）"
4. **提炼业务关注要点**：单列"业务关注要点（编者提示）"，只给方向、不出处方，与摘录严格分开
5. **（可选）业务线对照表**：仅当用户明确要求时，在编者提示之后追加"主要影响/合规方向/关联业务"表格作为补充

### 步骤5：输出前检查与格式检查
在最终输出前依次检查：
1. **字数核对**：每版正文是否 ≤1000 字
2. **原文引用核对**：关键限定词、数字、时限、罚则、定义、标志性例子是否逐一能在原文找到依据
3. 完成 `references/regulation-interpretation-guide.md` 中的完整输出校验清单
4. 链接是否为官方来源，内容是否专业且易懂
5. 【飞书云文档】文档标题是否符合规范（`法务月刊-新法新规汇编（YYYY年MM月）`）
6. 【飞书云文档】文档结构是否包含新法新规标题、主要内容（据原文梳理）、业务关注要点（编者提示）等必要内容
7. 【飞书云文档】所有内容是否已正确写入飞书云文档
8. 【飞书云文档】文档链接是否已返回给用户

### 步骤6：自动转为飞书云文档
完成法规检索、解读和验证后，必须将所有内容自动转为飞书云文档：
- **文档标题格式**：`法务月刊-新法新规汇编（YYYY年MM月）`
- **文档结构要求**：
  - 一级标题：法规标题
  - 二级标题：发布日期/实施日期(过渡期)/标签、主要内容（据原文梳理）、业务关注要点（编者提示）、（如有）业务线对照表、内容出处
- **使用工具**：使用 `larksuite-cli docs +create` 命令创建文档
  - 使用 `--title` 指定文档标题
  - 使用 `--content` 指定 Markdown 格式的文档内容
- **返回结果**：文档创建成功后，**必须将文档链接返回给用户**，格式：`> [文档标题](文档链接)`
- **强制要求**：**禁止**仅输出 Markdown 内容而不创建飞书云文档

## 七、专业注意事项

### 数据源注意事项
1. **权威性优先**：优先使用一级官方渠道，确保信息权威性
2. **时效性验证**：验证法规的发布和生效日期
3. **链接有效性**：确保提供的链接可公开访问且有效
4. **来源可追溯**：确保每个信息都有明确的官方来源

### 分析注意事项
1. **时效性提醒**：法规检索结果具有时效性，建议定期更新
2. **完整性提醒**：检索结果可能不完整，建议多渠道验证
3. **适用性判断**：法规适用需要结合具体业务场景判断
4. **重大决策提醒**：重大合规决策建议咨询专业法律顾问

### 输出注意事项
1. **格式规范性**：严格按照格式要求进行输出
2. **语言专业性**：使用专业但清晰的中文，避免过度法律术语
3. **方向指引性**：确保方向指引具有参考价值且不过于具体
4. **风险评估准确性**：基于官方法规准确评估风险等级
5. **整合原则**：业务判断、影响面、风险排序统一归入"业务关注要点（编者提示）"单列呈现，与"主要内容（据原文梳理）"严格分开；不再提供以"如："开头的具体行动计划，也不提供过于具体的合规实施细节，重点提升业务部门对法规风险的认识和意识
6. **贴原文原则**：不脱离原文表达自造术语或近义替换，原文限定适用范围/前提的词句须完整保留，原文未覆盖处如实标注"需另查"而非编造

### 适用场景
- 需要了解法规影响的业务讨论会准备
- 合规意识培养和风险认知提升
- 合规方向讨论和策略制定
- 法规环境变化的快速响应
