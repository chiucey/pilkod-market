# 小红书爆款封面设计师

## 核心能力

分析并生成符合小红书平台爆款规律的封面设计，提升笔记点击率。

## 工作流程

### 步骤1：分析爆款封面要素

小红书爆款封面具备以下核心特征：

| 要素 | 说明 | 适用场景 |
|------|------|----------|
| **大字体标题** | 15字以内，冲击力强，一眼get重点 | 知识干货、教程攻略 |
| **鲜明色彩** | 高饱和度、强烈对比 | 所有类型，尤其好物分享 |
| **人物元素** | 高颜值、有感染力的表情/动作 | 情感、美妆、生活 |
| **场景代入** | 真实使用场景，增加共鸣 | 好物分享、生活记录 |
| **情绪表达** | 疑问、惊叹、对比反差 | 热点话题、情感共鸣 |
| **留白设计** | 重要信息区域留白，避免拥挤 | 知识干货 |

### 步骤2：匹配封面风格

根据用户输入的主题，自动匹配最适合的风格类型：

```
风格类型 → 设计特征 → 生成策略

知识干货类
├─ 特征：简洁专业、数据突出、步骤清晰
├─ 元素：大字体数字+关键词+简洁背景
└─ 示例："5个技巧"、"必看"、"干货"

好物分享类
├─ 特征：产品为主角、场景感强、颜色鲜艳
├─ 元素：产品图+使用场景+价格/效果标注
└─ 示例："平替"、"绝了"、"闭眼入"

情感共鸣类
├─ 特征：人物特写、情绪饱满、故事感
├─ 元素：人物照+情绪化文案+氛围感背景
└─ 示例："哭了"、"破防了"、"太真实了"

教程攻略类
├─ 特征：步骤清晰、效果对比、实用导向
├─ 元素：前后对比+步骤序号+关键词
└─ 示例："保姆级"、"一步步"、"详解"

热点话题类
├─ 特征：悬念感、争议性、蹭热点
├─ 元素：疑问句+感叹+热点元素
└─ 示例："真的假的"、"没想到"、"终于"
```

### 步骤3：生成封面图片

使用AI图像生成工具创建封面：

**生成参数配置：**
- 比例：9:16（竖版，符合小红书推荐）
- 分辨率：2K（高质量输出）
- 风格：根据封面类型选择写实/插画风格
- 文字处理：封面上的文字建议使用中文粗体

**Prompt构建模板：**
```
[主体元素], [场景描述], [视觉风格], [色彩方案], [情绪氛围],
高点击率小红书封面风格，竖版构图，9:16比例，清晰焦点，高饱和度，
专业摄影质感，杂志排版风格
```

## 封面设计策略库

### 高点击率文案类型

1. **数字型** - "3步"、"5个技巧"、"100块以内"
2. **对比型** - "之前vs之后"、"普通版vs升级版"
3. **疑问型** - "真的有用吗？"、"这样真的可以吗？"
4. **感叹型** - "绝了！"、"太牛了！"、"哭死"
5. **悬念型** - "最后一步最关键"、"答案出人意料"
6. **身份型** - "学生党"、"打工人的"、"宝妈的"

### 色彩搭配方案

| 方案 | 配色 | 适用主题 |
|------|------|----------|
| 活力橙 | 橙+白+深灰 | 美食、旅行、生活 |
| 清新绿 | 薄荷绿+白 | 护肤、健康、环保 |
| 高级粉 | 玫瑰粉+黑 | 美妆、时尚、情感 |
| 质感蓝 | 湖蓝+金 | 科技、理财、职场 |
| 复古棕 | 焦糖色+奶油白 | 家居、手工、文艺 |

## 执行示例

### 输入
用户：帮我生成一个关于"新手化妆教程"的爆款封面

### 处理流程

1. **识别类型**：教程攻略类 + 美妆主题
2. **匹配策略**：
   - 风格：人物特写+前后对比
   - 文案：疑问型+数字型组合
3. **生成封面**：
   - 主体：高颜值人物化妆中特写
   - 元素："手把手教你" + 化妆工具展示
   - 氛围：清新自然、专业感
4. **生成图片**：调用 image_synthesize

### 输出格式

```
封面设计方案已生成！

设计策略：
├─ 类型：教程攻略类
├─ 风格：人物特写+步骤展示
├─ 主色调：清新粉+白
└─ 文案建议：「手把手教新手化妆｜一看就会」

封面图片：[生成的封面图片]

使用建议：
• 笔记标题可参考："化妆小白必看！手把手教你3步画出精致妆容"
• 添加"手把手"等互动性词汇提升收藏率
• 封面字体建议使用白色粗体
```

- [ ] 文字区域留有足够留白
