# 公开股票 PM 判断启发式

本文件给"多市场股票研究"系列技能提供共享的判断层:当用户在尽调一只上市股票、公开公司催化剂、上市公司模型、多空推介、卖方笔记、ETF/指数成分或组合头寸时,统一按这里的框架收尾。

## 一、受众模式

- `long_only_pm`:强调论点持久性、下行捕获、相对基准风险、流动性、加仓 / 减仓纪律,以及在组合中的角色。
- `long_short_hf`:强调变量感知、催化剂路径、情景偏度、可借券 / 拥挤度、对冲 / 平仓规则、毛 / 净敞口、时点风险。
- `sell_side_research`:强调评级与目标价纪律、估计修订、Street 争论框架、相对评级的风险、客户可读性,以及合规友好表达。
- `etf_index_diligence`:强调指数方法、成分权重、自由流通 / 流动性、ETF 持有人、被动资金流相关性、因子 / 板块敞口、再平衡风险、跟踪误差含义。
- `public_equity_diligence`:强调有来源支撑的发行人尽调、商业质量、管理层信誉、治理、会计质量、资本配置、估值风险,以及下一笔需要补的尽调来源。

## 二、老练 PM 必答题

任何实质输出在补充背景之前,先正面回答下列问题:

1. 哪里被错误定价(若有)?
2. 当前价格里已经包含了什么?
3. 什么会证伪 / 证实论点?
4. 什么会摧毁论点?
5. 为什么是现在?
6. 什么会改变 sizing / 评级 / 目标 / 对冲 / 减仓 / 退出 / 平仓 / watchlist?
7. 缺失的关键证据是什么?

## 三、核心启发式

- **变量楔子**:把"已知事实"和"被错误定价的洞察"区分开。没有变量楔子,就承认这只是一个监控项或 pass。
- **已被定价的预期**:在建议任何行动之前,先说明当前价格、一致预期、持仓或基准持股已经在折现什么。
- **估计路径**:指出推动股价工作所需变动的收入、利润率、EPS、FCF、KPI 或倍数路径。
- **估值偏度**:摆出基础 / 上行 / 下行,并判断当前价格是否已经为上行情景买单。
- **下行机制**:先解释"怎么亏钱",再解释"怎么赚钱"。
- **催化剂质量**:区分硬日期、证据窗口、软性叙事催化剂与"无催化剂"的局面。
- **持仓与头寸**:相关时,标记流动性、容量、被动持股、ETF / 指数敞口、卖空、可借券、拥挤度、因子 / 板块敞口。
- **基准与因子敞口**:说明这是 绝对收益想法 / 相对基准主动暴露 / 对冲 / 因子表达 / 成分尽调。
- **证伪条件**:让每条论点测试都可观察、有时间表,并挂钩具体来源、KPI、模型线或事件。
- **行动纪律**:把下一步动作归类为 `add`、`press`、`hold`、`trim`、`exit`、`cover`、`hedge`、`watchlist`、`pass`、`wait for proof`、`re-underwrite`。

## 四、品味规则

- 不要给"好公司便宜股票"这种泛泛结论。点名具体的定价错置,否则就说"没有看到"。
- 公司论点与股票论点分开:好公司可以是差股票;差业绩可能创造更好的局面。
- 给重要主张打标签:事实 / 管理层陈述 / 一致预期 / 行情数据 / 模型输出 / 假设 / PM 判断。
- 对一致预期、价格、持股、流动性、可借券、期权、指数、ETF、卖空数据使用 freeze time 与 as-of 日期。
- 惩罚未引用的催化剂、陈旧的行情、虚假精度、对"市场怎么想"的无支撑断言。
- 不要把缺失的数据藏到附录里。把"证据缺口"做进决策里,而不是仅仅做注脚。

## 五、PM / 风险工作流视角

供 `portfolio-risk-management` 在 sizing 或对冲公开股票头寸时共用:

- **阿尔法 vs 多余敞口**:把 PM 有意承担的特异 / 催化剂 / 因子 / 基准 / 指数暴露,与意外承担的 beta / 因子 / 板块 / 流动性 / 可借券 / 期权 / 汇率 / 商品 / 利率 / 拥挤 / 跳空风险区分开。
- **保留敞口**:在 sizing 或对冲建议之后,说明剩下什么风险。一个把核心股票论点也对冲掉的对冲,通常不如直接缩小仓位。
- **绑定约束**:指出最紧的限制:下行损失 / 流动性 / 可借券 / 毛 / 净 / beta / 因子敞口 / 主动权重 / 期权成本 / 希腊值 / 授权 / 催化剂时点 / 信心度。
- **对冲失败情境**:至少给一个"股票头寸承压时,对冲 / 配对 / ETF / 期权 / 宏观代理同步失效"的案例。
- **缩量 / 不对冲的替代方案**:在 basis risk、成本或阿尔法损耗大于敞口本身时,比较"缩小毛敞口、使用更小起手仓位、什么都不做"与建议的对冲。
- **行动规则**:add / trim / exit / cover / resize / roll / remove 都要挂钩可观察的价格、论点证据、流动性、可借券、期权到期、催化剂路径、因子暴露或对冲 basis。
- **信用信号边界**:CDS、信用利差、评级、再融资压力、到期墙、契约头条可作为公开股票下行 / 偿债风险的信息;但不要在"多市场股票研究"里 sizing 或推荐 CDS、债券、贷款、利差 DV01 / CS01、资本结构、不良、回收、契约交易,这些路由到 独立信用分析流程。
