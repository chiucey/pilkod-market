# A股 / 港股 / 美股市场规则

本文件汇总在做多市场速览时，三个市场各自需要注意的规则差异，以及无论哪个市场都要遵循的共同纪律。

## 通用前置动作

1. **先判断市场，再选 entity_type**：A股用 `a_stock`，港股用 `hk_stock`，美股用 `us_stock`。
2. **保留原始信息**：交易代码、交易所、币种、当地时区、交易日历都要存档。
3. **统一可比口径**：跨市场对照时统一币种、会计期间、财务口径、复权方式与估值日期。
4. **语言**：默认中文叙述，公司名、证券代码、指标名、公告名等专有名称保留原文。

## A股要点

- 适用中国企业会计准则，金额用人民币，节奏跟随中国交易日历。
- 必须考虑 T+1、涨跌停、ST/*ST、停复牌、退市风险与流动性限制。
- 报告期处理：清楚区分累计期、单季推导值、TTM；关注归母净利润、扣非净利润与经营性现金流。
- 股本结构：明确总股本、流通股本、限售股、解禁、增减持、回购、分红与再融资影响。
- 板块归类：行业对比优先按申万、中信、中证或证监会标准说明。

## 港股要点

- 跟港交所交易日历，币种是港币，需遵守相应上市规则。
- 板块身份：识别主板与 GEM、同股不同权、红筹与 H 股、双重主要上市与二次上市的差异。
- 交易细节：每手股数、停牌、配售、供股、可换股证券、控股股东持股变动都要纳入考量。
- 会计准则：明确是 IFRS、香港财务报告准则还是其他准则，并记录报告币种。
- A/H 对比：跨 A/H 比较时要处理股份类别、汇率、自由流通量与公司行动差异。

## 美股要点

- 时区按美东时间，币种为美元，节奏按 NYSE/Nasdaq 等交易所日历。
- 事实基础：SEC 文件、公司 IR、GAAP / 非 GAAP 口径、季度财报构成主要事实层。
- 必须区分：盘前 / 盘后披露、拆股、回购、股权激励、稀释股数、ADR 与双重上市。
- 事件分析：常规时段、盘前、盘后的价格反应分别讨论，不要混算。
- 财报分析：电话会议文字稿可以引用，但替代不了正式申报文件里的会计数字。

## 跨市场共同纪律

- 明确价格是否已复权，以及分红、拆股、配股、送转或其他公司行动如何处理。
- 股价、估值、事件、宏观数据都需要标注截至时间。
- 把正式披露、MCP 结构化数据、用户材料、分析师推导、假设、判断逐项区分开。
- 数据出现冲突时，以交易所 / 监管 / 公司正式披露为准，差异原样披露。
- 输出的是研究分析，不是面向个人的下单指令。
