# 指标库与行业叠加

本文件按"主体识别 → 通用财务 → 公开市场 → 行业差异化"的次序整理可选指标。它是清单参考，不是必填表；只把与当前任务相关、且有来源支撑的字段纳入。

## 一、通用主体识别字段

- 法定名称、常用名、股票代码、交易所、相关时的 CIK / LEI / ISIN / CUSIP。
- 总部、成立年份、员工数、股权结构、母公司 / 子公司、财年截止。
- 行业、子行业、相关时的 NAICS / SIC / GICS。
- 高管、审计师、评级机构、债务工具、相关时的交易所 / 上市标识。

## 二、通用财务指标

- 收入 / 净销售
- 毛利与毛利率
- EBITDA / 调整后 EBITDA / 经营利润
- EBITDA 利润率 / 经营利润率
- 净利润 / EPS
- 资本支出
- 自由现金流 / 经营现金流
- 现金及等价物
- 债务 / 净债务 / 相关时的租赁负债
- 净杠杆 / 总杠杆
- 利息支出 / 利息覆盖
- 有来源支撑时的市值 / 企业价值 / 估值

## 三、公开市场常用指标

- 股价 / 日期、市值、EV、自由流通、相关时的卖空
- LTM / NTM 收入、EBITDA、EPS、FCF、利润率
- 指引、一致预期、修订、超预期历史
- 分部结构、地域结构、KPI 趋势
- 估值倍数:EV/Sales、EV/EBITDA、P/E、P/FCF、P/B 等
- 近期业绩 / 催化剂、有来源时的评级 / 目标价背景

## 四、信用 / 独立信用分析流程相关字段

- 工具类型、金额、到期、摊销、利率 / 利差
- 债务结构、留置权、抵押、相关时的担保人
- 流动性、循环额度可用度、契约空间
- 报告 EBITDA、调整后 EBITDA、固定费用覆盖、DSCR
- 还本付息、到期墙、现金消耗、要约 / 交换条款
- 成交价、收益率、利差、OID、回收价值、评级 / 展望
- 结构优先级、有担保 / 无担保比例、限制集团、发行人 / 担保人范围

## 五、上市基金 / 管理人指标

- AUM / AUA、策略、地域、行业 / 阶段敞口、载体类型
- NAV、与 NAV 的溢 / 折价、市值、费用相关收益、管理费率
- 资金流、自然增长、业绩、披露的赎回 / 流动性结构
- 组合集中度、前几大持仓、杠杆、分红 / 分配率
- BDC 或封闭式基金:每股 NAV、NII、债务 / 权益、不良、已实现 / 未实现损益

## 六、行业叠加

### SaaS / 软件
ARR、净留存、毛留存、流失、CAC、LTV、回收期、Rule of 40、毛利率、销售效率、bookings、billings、RPO、ACV、客户数。

### 平台 / 交易型
GMV / GTV、抽成率、活跃买家 / 卖家、订单量、AOV、贡献利润率、cohort 留存、流动性指标。

### 银行 / 金融机构
贷款、存款、NIM、NII、手续费收入、CET1、杠杆率、ROA、ROE、不良、核销、拨备覆盖、AUM / AUA。

### 保险
保费、综合成本率、损失率、费用率、准备金、投资收益、账面值、RBC、保单数量。

### REIT / 房地产
NOI、同店 NOI、出租率、租金价差、AFFO / FFO、cap rate、NAV、债务收益率、租约展期、WALE。

### 能源 / E&P
产量、储量、实现价、提升成本、衰减率、capex、自由现金流、对冲、面积、已证实储量。

### 医疗 / 生物科技
管线阶段、试验读数、患者群体、TAM、现金跑道、研发支出、监管里程碑、报销敞口。

### 零售 / 餐饮 / 消费
同店销售、客流、客单价、门店数、单店经济模型、毛利率、库存周转、会员 / 用户、渠道结构。

### 工业 / 制造
出货量、价格 / 结构、在手订单、book-to-bill、产能、利用率、原材料、营运资本、capex、供应链敞口。

### 媒体 / 电信 / 互联网
订阅数、ARPU、流失、参与度、广告收入、MAU / DAU、内容支出、宽带 / 净增、相关时的频谱 / 债务。

## 七、市场、持仓与指数维度

需追踪:市值、企业价值、自由流通、ADV、换手、指数成分、基准权重、ETF 持有人、被动持股、卖空、可借券情况、因子敞口、beta、流动性评分、持股集中度、治理信号、资本配置,以及关键板块 KPI。

公开股票投资者速览还需追踪:前几大持有人、自由流通、退出天数、有来源支撑时的卖方覆盖数量 / 评级分布、一致预期格局、可借券成本 / 可得性、拥挤度阅读、回购授权、分红 / 资本回报姿态、相关时的内部人持股 / 减持,以及行情数据的 as-of 时间戳。任何缺失字段都要标记为来源缺口。
