# Fitness Tracker — 运动追踪规范

## 核心原则

每次收到平哥的运动相关消息，**必须按顺序执行**：

1. **解析运动类型** → 骑行/走路/力量/其他
2. **计算消耗热量** → 基于运动类型+时长/距离
3. **存档截图/数据** → 保存到 `memory/imgs/`
4. **更新日记** → 写入 `memory/YYYY-MM-DD.md`
5. **更新索引** → 追加到 `memory/media_index.md`

---

## 运动消耗标准（参考）

| 运动类型 | 单位 | 消耗kcal | 说明 |
|---------|------|----------|------|
| 骑行（一般） | 1小时 | 400-600 | 平均12-20km/h |
| 骑行（快） | 1小时 | 600-900 | >25km/h |
| 徒步 | 1小时 | 300-500 | 6-8km/h |
| 遛狗 | 1小时 | 200-300 | 慢走+站立 |
| 跑步 | 1小时 | 500-800 | 8-10km/h |
| 俯卧撑/深蹲 | 30分钟 | 100-200 | 力量训练 |
| 游泳 | 1小时 | 400-700 | 自由泳/混合 |

## 骑行数据解析规范

从截图读取骑行数据时，提取以下字段：
- 骑行距离（km）
- 骑行时间（HH:MM:SS）
- 平均速度（km/h）
- 最快速度（km/h）
- 总消耗（kcal）

**计算公式：**
- 消耗kcal ≈ 距离(km) × 40（大基数骑行者可×50）

---

## 周报生成规范

生成运动周报前：
1. 扫描 `memory/` 下所有日期文件，收集每日运动数据
2. 计算本周总运动天数、总消耗、平均每日消耗
3. 与上周对比（运动习惯是否进步）
4. 报告日期必须等于今天
