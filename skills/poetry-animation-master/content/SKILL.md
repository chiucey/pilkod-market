## 工作流程

### 第一阶段：诗词解析与意境分析

1. 接收用户提供的古诗词原文
2. 深度解析诗词的多层内涵：
   - 字面意象：诗中出现的具体景物、人物、事物
   - 情感基调：诗人表达的核心情感（豪迈、婉约、孤寂、欣喜等）
   - 时空背景：诗歌创作的时代背景、季节、时辰
   - 象征隐喻：意象背后的深层含义
3. 提取可视觉化的诗意元素：
   - 核心意象：最具代表性的1至3个核心意象
   - 色彩氛围：诗词传达的整体色调
   - 动态韵律：诗中蕴含的动作与流动感
   - 留白意境：东方美学中的虚实、疏密关系
4. 确定动画整体调性：
   - 艺术风格（工笔重彩、水墨写意、青绿山水、民俗年画等）
   - 动画节奏（舒缓悠长、跌宕起伏、动静相宜等）
5. 与用户确认选取的诗意元素和动画风格方向

### 第二阶段：分镜剧本创作

1. 根据诗词结构规划分镜节奏（按诗句或意群分段）
2. 为每个镜头设计：
   - 场景描述（山水、庭院、边塞、宫廷等）
   - 意象呈现（柳、月、雁、舟等诗意元素）
   - 色彩氛围（墨色、青绿、赭石、留白等）
   - 镜头运动（推、拉、摇、移、升、降）
   - 时间流动（日夜交替、四季轮转、瞬间定格）
3. 设计诗词文字呈现方式：
   - 书法字体选择（行书、楷书、草书等）
   - 文字出现动画（逐字显现、墨晕散开、飞白等）
   - 文字与画面的融合方式
4. 与用户确认分镜剧本内容

### 第三阶段：视觉风格与色彩设定

1. 确定整体视觉风格
2. 建立色彩体系：
   - 主色调（决定整体氛围）
   - 辅助色（丰富层次）
   - 点缀色（画龙点睛）
3. 设计关键意象的视觉表现
4. 与用户确认视觉风格方向

### 第四阶段：场景图像生成

1. 为每个分镜设计构图
2. 选择合适的景别、角度、构图
3. 构建场景图像生成提示词
4. 保持视觉风格的一致性

### 第五阶段：动画视频制作

1. 为重点场景制作动态视频
2. 描述具体的动态元素
3. 设计镜头运动
4. 保持与静态图的一致性

### 第六阶段：整合输出

1. 整理所有素材
2. 提供完整的分镜剧本文档
3. 输出场景图和视频文件列表
4. 给出后期制作建议
