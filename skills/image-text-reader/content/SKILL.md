# 图片文字读取技能

## 核心能力

本技能使 MiniMax Agent 能够准确读取和理解图片中的文字和内容。

## 触发条件

当用户请求以下操作时自动激活：
- 识别/提取图片中的文字
- OCR 文字识别
- 读取截图、文档扫描件、名片等图片内容
- 理解图片中的图表、数据、流程图
- 描述图片内容
- 解析图片中的表格信息
- 翻译图片中的文字

## 执行流程

### 1. 图片输入处理

接收来自以下来源的图片：
- 用户直接上传的图片文件
- 图片 URL 链接
- 截图内容

**支持格式**：PNG、JPG、JPEG、WebP 等常见图片格式

### 2. 文字识别执行

使用 `images_understand` 工具进行图片内容分析：

```json
{
  "image_info": [
    {
      "file": "<图片文件路径或URL>",
      "prompt": "请详细描述这张图片的内容，并提取图片中所有可见的文字内容。如果有表格，请以表格格式呈现。如果是中文内容，请保持原有文字不变。"
    }
  ],
  "display_text": "正在识别图片内容..."
}
```

### 3. 输出格式

根据图片类型，提供结构化的输出：

**文档/截图类图片**：
- 完整提取所有文字
- 保持原有排版和格式
- 标注不确定或模糊的文字

**图表/数据类图片**：
- 描述图表类型和主题
- 提取关键数据点和数值
- 解释数据趋势和关系

**场景/实物类图片**：
- 详细描述画面内容
- 识别主要元素和对象
- 提供文字标注和说明

**表格类图片**：
- 转换为结构化表格格式
- 保留表头和单元格内容
- 标注合并单元格

## 最佳实践

### 提升识别准确度

1. **明确指令**：在 prompt 中指定需要的输出格式
2. **多语言支持**：明确说明是否需要翻译或保留原语言
3. **格式要求**：如需特殊格式（如表格、列表），在指令中说明

### 常见场景指令模板

**通用文字提取**：
```
请提取这张图片中的所有文字内容，保持原有格式和排版。
```

**中英文混合**：
```
请提取图片中的文字，中文内容保持原样，英文内容也保持原样不翻译。
```

**表格提取**：
```
请将图片中的表格内容提取为Markdown表格格式，包含所有行列数据。
```

**图表分析**：
```
请描述这张图表的内容，包括图表类型、标题、坐标轴含义、所有数据点的数值和标签。
```

**多图批量处理**：
```
请依次分析这些图片，每张图片单独输出提取的内容。
```

## 错误处理

当识别失败时：
1. 检查图片格式是否支持
2. 确认图片清晰度是否足够
3. 提示用户图片可能需要：
   - 提高分辨率
   - 调整对比度
   - 去除水印或遮挡物

## 工具调用示例

```python
# 图片文字识别
images_understand(
    image_info=[
        {
            "file": "user_uploaded_image.png",
            "prompt": "请提取图片中的所有文字，保持原有格式。"
        }
    ],
    display_text="正在识别图片文字..."
)
```

## 质量保证

- 对于模糊或不清晰的文字，标注 `[?]` 或使用备选字
- 对于复杂排版，按阅读顺序输出
- 对于混合语言内容，保留原语言
- 对于表格，提供 Markdown 格式输出
