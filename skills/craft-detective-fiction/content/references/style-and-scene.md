## 1. 风格参数

用可观察、可检查的参数定义项目风格，不使用空泛的“高级感”“电影感”或单一作者姓名。

| 维度 | 可选方向 |
|---|---|
| POV | 第一人称、第三人称有限、多视角、文档体 |
| 叙事距离 | 贴近即时感受、适中、冷静远观 |
| 句法节奏 | 短促、平衡、长短交替、缓慢复句 |
| 信息密度 | 每段单一信息、线索密集、留白较多 |
| 心理呈现 | 只写行为、有限内心、深层自我辩论 |
| 描写方式 | 功能性细节、感官氛围、象征性意象 |
| 对话压力 | 日常自然、潜台词、交锋、程序询问 |
| 幽默 | 无、少量缓冲、黑色幽默、持续轻盈 |
| 暴力显隐 | 场外、结果导向、克制写实、直接但不猎奇 |
| 叙事温度 | 温暖、克制、冷峻、压迫、荒诞 |
| 时代与地域 | 现代中性、行业口语、方言点染、历史语感 |

把每个选择写成“做什么／不做什么”。例如：“使用具体物件承载情绪；避免连续三句抽象心理总结。”

## 2. 参考作品转译

用户给出作者或作品时：

1. 询问或判断其真正喜欢的是节奏、视角、氛围、人物关系还是谜题结构。
2. 提取 3–6 个高层特征。
3. 用原创示例验证这些特征。
4. 把特征写入风格指南，不把作者姓名写成“模仿目标”。

不要复制、续写或轻度改写参考作品的原句。对于在世作者的风格请求，明确转译为高层特征后创作原创文本。结构技法可以研究，但人物、专有设定、标志性语句和连续表达不得借用。

## 3. 样章校准

在正式长篇前写约 200–400 字原创样章，内容应同时测试：

- 主 POV 的观察方式
- 一段环境或物证细节
- 两名角色的对话压力
- 一个不被强调的小信息变化
- 章节基调和句法节奏

请用户只评价可操作维度，如“更冷静／更贴近人物”“句子更短／更舒展”“对话更生活化／更有潜台词”。确认后把修订版作为风格锚点。锚点用于校准，不要求全文复制相同句式。

确认锚点后将其写入 `style-guide.md` 并递增风格版本；此后每次经确认的基线更新同样递增版本，使审计快照能核对所依据的风格版本。

## 4. 场景引擎

每个完整场景至少发生一种不可逆变化：证据状态改变、人物关系改变、风险改变、调查模型改变或角色做出承诺。

写场景前回答：

1. POV 角色此刻想得到什么？
2. 谁或什么阻止他？
3. 场景开始时他相信什么？
4. 哪个观察、选择或冲突改变了这种相信？
5. 场景结束后，下一步为何不可避免？

删除只重复既有信息、只运输角色或只制造无后果气氛的场景，除非它承担明确的节奏呼吸与人物功能。

## 5. 调查场景

避免“问问题—得到答案—去下一处”的流水账。让每场调查同时包含：

- 调查者的具体目标
- 被调查者自己的目标
- 至少一个信息不对称
- 一项可观察行为或环境证据
- 一次关系或权力变化
- 一个新问题，且比旧问题更精确

询问场景中的谎言必须有动机。角色可以回避、选择性作答、误解或保护他人，但不要让所有嫌疑人都用同一种“神秘沉默”。

## 6. 线索呈现

把观察事实写清，把意义留给读者推断。

- 先写角色自然会注意的属性，再决定是否需要聚焦关键属性。
- 不用“他没有在意这个重要细节”之类作者提示。
- 避免以形容词替代证据，例如“可疑的杯子”；写杯子的位置、温度、残留或使用痕迹。
- 允许线索重复出现，但每次必须增加新语境、验证或误读。
- 让线索改变角色行为，而不是只躺在列表里等待终局。

## 7. 对话与人物

为主要人物定义：说话目的、回避方式、社会位置、词汇范围和在压力下的变化。口头禅只作为少量表征，不代替人物声音。

对话修订时检查：

- 每句是否有人想达成某事？
- 角色是否说了双方都知道、仅供读者听的说明台词？
- 同一信息能否通过打断、误解、停顿或动作更自然地出现？
- 谎言被揭穿后是否改变关系，而不只是提供线索？
- 方言、行业术语和时代用语是否影响可读性？

让受害者、真凶和嫌疑人都具有与谜题无关的欲望和关系。不要让人物只作为诡计零件存在。

## 8. 节奏控制

用“认知变化密度”而非固定章节长度控制节奏。

- 高压段：缩短场景目标，增加决定和不可逆后果。
- 调查段：在事实、假说、验证、受挫之间循环。
- 呼吸段：深化人物或主题，同时保留下一步驱动力。
- 反转段：先建立足够强的旧模型，再用既有事实迫使模型改变。

若连续两个场景结束时调查模型没有变化，检查是否可以合并、删减或让人物冲突承担新信息。

章节钩子不必总是危险或新尸体。可使用：证词矛盾、关系决裂、错误模型崩塌、道德选择、事实重新命名或即将验证的假说。

## 9. 揭晓场景

把长推理拆成交互：提出命题、展示事实、允许反驳、排除替代解释、观察人物反应、进入下一命题。

揭晓必须同时完成三件事：

1. 证明案件真相。
2. 让读者重新理解前文。
3. 让人物承担真相的后果。

不要让真凶仅因被说中就完整自白。若需要自白，先说明其心理、法律或关系动机；关键事实仍应由可验证证据支撑。

## 10. 修订顺序

按由大到小的顺序修订：

1. 案件因果与公平性
2. 章节功能与信息顺序
3. 人物动机和关系变化
4. 场景目标、冲突与转折
5. POV、连续性和节奏
6. 对话、段落和句子
7. 词汇、标点和格式

不要在核心手法尚未成立时花大量时间润色句子。完成内部修订后再生成不含元信息的清洁正文。
