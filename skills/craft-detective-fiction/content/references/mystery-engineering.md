## 1. 信息对象定义

使用精确术语，避免把所有细节都称作伏笔。

| 对象 | 定义 | 是否进入登记簿 |
|---|---|---|
| 客观事实 | 故事世界中真实发生或存在的事 | 若影响谜题则进入案件圣经 |
| 证据 | 故事中可被角色观察、保存或检验的事实载体 | 通常作为线索来源 |
| 线索 `C-###` | 读者可见、能够支持或排除某项推理结论的信息 | 是 |
| 伏笔 `F-###` | 为未来人物、情节、主题或情绪回报做准备的信息 | 是 |
| 红鲱鱼 `R-###` | 观察事实为真、但容易被解释成错误结论的信息 | 是 |
| 终局结论 `Q-###` | 揭晓必须证明、由一条或多条线索支持的稳定命题 | 否；只在案件圣经定义 |
| 氛围细节 | 主要承担质感和情绪，不需要未来解释 | 否 |
| 揭晓 | 把既有事实组织成可验证结论的过程 | 记录回收位置 |

一个细节可以同时承担两种功能，但必须分别写清。例如“湿雨伞”既可能建立天气氛围，也可能成为时间线索；只有后者需要登记。

**安全门槛：** 现实中的危险手法只设计到叙事所需的条件类别、可观察痕迹、后果和失败点，不提供可直接执行、优化伤害或规避侦查的参数与步骤；涉及犯罪、伤害、自伤、毒理、武器或安防时同时应用 `research-protocol.md`。

## 2. 真相优先设计法

按以下顺序建立案件：

1. 写一句完整真相：谁、为什么、何时何地、对谁、如何做、如何掩饰、哪里失败。
2. 从犯罪前的决定开始，写出不可逆的因果链。
3. 列出手法依赖的每个物理、社会和心理条件。
4. 建立真实时间线与空间移动。
5. 为主要嫌疑人分配动机表象、隐藏真相、机会表象和排除依据。
6. 列出侦探终局必须证明的结论。
7. 为每项结论设计足够、但可误读的读者可见线索。
8. 再安排叙事顺序、红鲱鱼和情感伏笔。

禁止先写一个“震撼反转”，再用新增事实强行解释前文。

## 3. 犯罪因果链

让每个环节回答“为什么下一个环节会发生”。推荐使用：

| 环节 | 必答问题 |
|---|---|
| 诱因 | 什么变化使凶手不能继续等待？ |
| 决定 | 凶手何时跨过心理或利益门槛？ |
| 准备 | 获取了什么、观察了什么、利用了谁？ |
| 接近 | 如何到达受害者、现场或关键系统？ |
| 实施 | 手法在故事规则下如何成立？ |
| 掩饰 | 凶手想让调查者相信什么替代解释？ |
| 善后 | 需要处理哪些物件、证人、记录或关系？ |
| 调查应对 | 调查开始后，凶手做了什么会产生新风险？ |
| 失败点 | 哪个选择、误判或不可控因素最终暴露真相？ |

检查每一步是否符合人物能力和风险偏好。若任何普通替代方案明显更安全、更简单，解释凶手为何不能或不会采用。

## 4. 嫌疑人矩阵

不要只给嫌疑人“动机”。为每名主要嫌疑人记录：

- 与受害者的真实关系
- 可见动机与真实利益
- 手段或相关知识
- 表面机会与真实位置
- 正在隐瞒的非凶案秘密
- 会说谎的具体问题和原因
- 支持其有罪的事实
- 排除其为真凶的可验证依据
- 对主角或主题的功能

良好的嫌疑人不是“轮流可疑”，而是在相同事实下产生不同合理解释。至少让数名嫌疑人在动机、手段、机会三个维度上各有强弱，避免一人从一开始就同时占满三项。

## 5. 时间线与空间模型

### 时间线

分开记录：

| 时间 | 实际行动 | 地点 | 谁能观察 | 留下的证据 | 对外说法 | 说法来源 |
|---|---|---|---|---|---|---|

使用故事真正需要的精度。时间诡计可以精确到分钟，心理或社会派案件可以只精确到上午、班次或事件顺序。伪精确会制造虚假可信度。

逐项验证：

- 移动时间与交通条件
- 门窗、钥匙、监控、通信和照明状态
- 物件何时由谁持有
- 伤势、药效、腐败或技术过程的合理时间范围
- 每条证词是亲眼所见、推断、转述还是伪造记录

### 空间模型

密室、复杂宅邸、列车、船舶或多现场案件应建立简图或房间邻接表。记录视线、声音、出入口、锁具状态、路线耗时和不可穿越区域。空间模型必须先于最终手法确认。

## 6. 结论—证据链

把终局证明拆成结论，不要只写“这些线索指向凶手”。

示例结构：

| 结论 | 必要线索 | 推理步骤 | 排除的替代解释 | 揭晓前是否可见 |
|---|---|---|---|---|
| 死亡发生在公布时间之前 | C-002, C-006 | 两项独立时间指标一致 | 时钟故障、证人记错 | 是 |
| 某人能进入现场 | C-004, C-009 | 权限与实际路线同时成立 | 复制钥匙、尾随进入 | 是 |

核心身份结论通常需要多条相互独立的事实共同支持。单一“指纹／DNA／录像”可以成为强证据，但仍需解释来源、污染、完整性和它证明了什么，避免技术一锤定音替代推理。

## 7. 公平线索设计

每条关键线索通过四项测试：

1. **可见**：读者在揭晓前实际接触过观察事实，而不是只听说“侦探发现了东西”。
2. **可理解**：若依赖专业知识，正文先以自然方式提供足够规则。
3. **可推导**：线索与结论之间存在可说清的推理步骤。
4. **可误读**：首次出现时至少有一种合理的非真相解释，但不是靠作者撒谎。

公平不意味着容易。读者可以在侦探之前猜中；真正目标是让猜中的读者有证据，让没猜中的读者在回看时承认信息已经给出。

### 控制显著性

使用以下方法调整线索显著性，而不是规定固定出现次数：

- 把关键属性置于有自然目的的场景中
- 同时给出多个真实细节，让关键细节不独占聚光灯
- 先让线索服务人物或环境，再在后文改变其解释
- 让不同人物对同一事实给出不同但诚实的理解
- 在必要时自然重现，但每次重现增加新功能

不要为了隐藏线索而省略其关键属性；也不要在揭晓前用不自然的反复提醒强行保鲜。

## 8. 红鲱鱼设计

红鲱鱼必须包含两层：

- **真实观察**：确实存在的行为、物证、关系或矛盾。
- **错误解释**：读者或调查者因上下文不足而得出的合理结论。

最终必须交代真实观察为何存在。理想的红鲱鱼还能揭示嫌疑人的另一项秘密、推动关系或证明主题，而不是纯粹浪费时间。

检查：

- 谁提出错误解释，依据是什么？
- 哪项既有事实最终排除它？
- 排除后是否仍产生剧情或人物价值？
- 作者是否曾以全知、可靠口吻直接陈述了虚假事实？若是，必须改写。

## 9. 密室与不可能犯罪

先写“表面不可能命题”，再逐一列出其前提。例如：门由内反锁、窗无损、现场全程有人监视、死者在锁门后死亡。手法只需推翻或重解释其中一项前提，不必堆叠机关。

完成以下验证：

1. 画出空间与状态变化。
2. 按分钟或必要粒度模拟凶手行动。
3. 写出目击者真正观察到的内容，不把推断伪装成观察。
4. 验证机关、材料和人体反应，不依赖虚构科学，除非世界规则明确。
5. 解释凶手为何选择复杂手法，以及复杂性带来的代价或痕迹。
6. 确保破解依赖已给线索，而不是侦探突然重演一个读者没见过的装置。

封闭嫌疑人圈只限定“谁可能作案”；密室限定“作案看似如何不可能”。分别验证。

## 10. 叙述性诡计

先制定叙述契约：谁在讲、何时讲、为何讲、知道什么、会在哪些方面不可靠。

### 可接受的隐藏

- 有限 POV 没有观察到的信息
- 角色有自然理由不去思考或命名的事实
- 双关、身份称谓或时间顺序造成的可回读歧义
- 明确不可靠叙述者的偏见、记忆错误或自我欺骗

### 高风险做法

- 可靠叙述者明知事实却使用只能解释为谎言的内心陈述
- 为防读者猜中而省略 POV 必然注意的关键事实
- 揭晓后改变既定词义、世界规则或人物身份规则
- 依赖排版、译名或语法漏洞，而作品未建立相应契约

揭晓后逐句回读所有涉及诡计的段落；每句都应在真相下仍然成立或具有明确的不可靠来源。

## 11. 揭晓设计

揭晓不是答案宣读，而是证明与人物后果同时发生。

推荐顺序：

1. 重述待解的精确问题。
2. 排除最有说服力的错误模型。
3. 串联读者已经见过的关键事实。
4. 展示每一步推理如何缩小可能性。
5. 处理凶手或其他角色提出的合理反驳。
6. 证明身份、手法与动机之间的闭环。
7. 让真相改变关系、价值判断或人物命运。

允许一次揭晓串联多条线索；不要机械限制“每章最多回收几条”。控制的是认知负荷：使用小结、反应、动作和对抗把长推理切成可消化单元。

## 12. 结构变更

修改真凶、手法、死亡时间、关键动机或核心线索时执行影响分析：

1. 更新案件圣经中的一句话真相和因果链。
2. 重算真实时间线与空间模型。
3. 重新检查嫌疑人矩阵。
4. 标记所有被强化、失效或需要新增的登记项。
5. 检查章节大纲中的信息释放顺序。
6. 搜索正文中所有受影响的人名、物件、时间、证词和内心陈述。
7. 重新执行公平性审计。

保留废弃记录和变更原因，不复用旧 ID。
