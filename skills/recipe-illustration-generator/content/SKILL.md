# 美食食谱插画生成技能 (Recipe Illustration Generator)

## 技能概述

**技能类型**: 图像生成
**核心能力**: 生成日系治愈风美食食谱插画，融合信息图表+手绘插画+食谱教程风格

## 定位说明

- **类型**: 融合信息图表（Infographic）+ 手绘插画 + 食谱教程的「治愈系美食指南」
- **目标受众**: 年轻女性、烘焙爱好者、插画收藏者、社交媒体内容创作者
- **适用场景**: 小红书/微博/Instagram传播、美食博主分享、食谱书籍插图

## 核心设计理念

### 核心理念
> "做美食，就像写诗一样，把温柔揉进每一步，时间会给我们最甜美的回报～"

以情感化语言贯穿始终，将烹饪升华为生活美学与情绪疗愈行为。

### 情感基调
- 温暖治愈、亲切感人
- 强调"过程的小成就感"
- 传递"值得等待的美好"

## 布局结构（三段式黄金比例）

### 1. 顶部横幅区（约12-15%）

**内容元素**:
- 标题: 手写体粗黑体 + 绿色渐变填充
- 副标题: 诗意过渡文字
- 吉祥物: 可爱小动物（熊/兔为主角）
- 装饰: 少量爱心、星星点缀

**设计要点**:
- 吸引注意力、点明主题
- 建立情感联结
- 装饰适量，避免过于花哨

### 2. 中部主体区（约55-60%）

#### 食材清单区（精简设计）
- 采用单行简洁列表形式
- 或少量圆角卡片（如4-6个）
- 每项含：食材名称 + 用量 + 简单图标

#### 步骤流程图区（丰富详细）
- 编号卡片式排版（①②③④⑤⑥）
- 每个步骤卡片包含：
  - 圆形编号底 + 白字
  - 插画主图（动态场景）
  - 小动物助手（熊/兔拟人化）
  - 右上角心形/星星装饰
  - 底部文字说明（口语化）

**设计要点**:
- 信息核心区域
- 清晰分层、逻辑递进
- 步骤说明含动作指令 + 原理解释

### 3. 底部收尾区（约25-30%）

**内容元素**:
- 成品展示大图（焦糖色、芝麻、飘香）
- 总结金句（情感升华）
- 小贴士卡片（实用技巧）
- 小动物庆祝场景
- 装饰元素（爱心、星星、闪光）

**设计要点**:
- 增强记忆点
- 引导分享冲动
- 装饰丰富但不杂乱

## 视觉风格规范

### 绘画风格
- **风格**: 日系治愈插画（Kawaii + Ghibli-inspired）
- **线条**: 柔和手绘线稿，边缘略带"毛边"质感（模拟水彩纸）
- **形态**: 物体拟人化（碗有笑脸、食物带腮红、蛋糕有眼睛）
- **光影**: 柔和侧光 + 微投影，营造"温暖厨房午后"氛围
- **质感**: 无强烈阴影，保持轻盈感

| 类型 | 颜色 | 用途 |

| 背景色 | #F5E6D3（暖米黄） | 整体底色 |
| 冷色调 | #A8C8A6（薄荷绿） | 开心果、清新主题 |
| 暖色调 | #E8B4B8（灰粉） | 温馨、柔软感 |
| 点缀色 | #C4A77D（燕麦棕） | 自然、朴实感 |

### 字体系统

| 类型 | 字体特征 | 用途 |
|------|----------|------|
| 主标题 | 手写体粗黑体 + 渐变填充 | 突出主题 |
| 副标题 | 细圆体 + 描边 | 诗意过渡 |
| 步骤编号 | 白底橙红圆圈 + 无衬线体 | 清晰导航 |
| 说明文字 | 手写体 + 连笔 | 口语化叙述 |
| 数据标注 | 无衬线体 | 重量/温度/时间 |

### 装饰元素系统

#### 爱心符号
- 位置：角落、箭头旁、食物上
- 数量：12+ 处
- 作用：温柔、推荐、情感提示

#### 闪光星
- 位置：关键点旁
- 作用：强调重点（如"冷藏4h+"、"入口即化～"）

#### 小动物角色
- **白熊（主角）**: 标题、步骤，代表"引导者"
- **白兔（辅助）**: 步骤，象征"耐心与细致"
- **角色动作**: 呼应步骤内容（搅拌、筛粉、守候烤箱）

#### 纹理背景
- 浅米黄底纹带细微纸张肌理
- 提升手作质感

## 信息传达策略

### 认知友好设计

#### 颜色编码系统
- 原味 = 米黄色系（暖）
- 开心果 = 薄荷绿系（冷）
- 关键操作 = 粉色/橙色高亮

#### 图标语义化
- 爱心 = 温柔/推荐/情感提示
- 时钟 = 时间节点
- 叶子 = 天然/清新
- 感叹号 = 注意事项

#### 动词具象化
"揉进"、"分两半"、"穿上油纸"、"画一朵心花" → 可视动作

### 科学性与人文性平衡

#### 精确数据
- 350g奶油奶酪
- 220°C
- 20分钟

#### 原理解释
- "震出表面气泡" → 防止凹陷
- "冷藏定型" → 蛋糕结构稳定
- "焦糖色蜕变" → Maillard反应可视化

#### 情感补偿
- "等我变得更好吃～"
- "入口即化～"
- 软化技术术语的冰冷感

## 内容处理规范

### 用户输入处理流程

1. **识别食谱信息**
   - 食谱名称和类型
   - 烹饪方式（烤、蒸、煮等）

2. **提取关键要素**
   - 食材列表和用量
   - 烹饪步骤数量（通常4-6步）
   - 温度、时间参数
   - 特殊技巧或提示

3. **标准化处理**
   - 重量单位统一（g、勺、ml）
   - 时间格式统一（分钟、小时）
   - 温度格式统一（°C）

4. **情感元素注入**
   - 添加诗意副标题
   - 口语化步骤说明
   - 总结金句

### 内容结构示例

```
【食谱名称】
副标题（情感化描述）

【食材】(精简直观)

② 步骤名 - 详细描述 - 小贴士

【小贴士】
- 技巧1

```
