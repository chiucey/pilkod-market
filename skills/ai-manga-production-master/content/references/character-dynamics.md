# 角色动态完整数据库

## 微动作四大法则详解

### 法则一：微动作永不停歇

#### 呼吸系统
- **基础呼吸**：胸腔缓慢起伏（每3秒一次）
- **紧张呼吸**：短促有力（每1秒一次）
- **激动呼吸**：急促，肩膀剧烈起伏（每0.5秒一次）
- **深沉呼吸**：腹部起伏为主（每5秒一次）

#### 眨眼节律
- 正常状态：每3-5秒一次
- 紧张状态：每1-2秒一次
- 专注状态：可能保持10秒以上不眨眼
- 情绪激动：快速眨动（眼睑颤抖）

#### 发丝飘动
- 微风响应：延迟0.3-0.5秒
- 强风响应：立即响应+过度飘动
- 能量场：反重力向上飘动
- 静止状态：每秒1-2根发丝自然落下

#### 手指微颤
- 紧张：指尖细微颤抖（频率5-8Hz）
- 激动：整根手指可见颤动
- 放松：偶发性微颤
- 蓄力：逐渐加剧的颤动

#### 视线游移
- 观察：缓慢扫视（每5秒完整周期）
- 锁定：死死盯住目标
- 思考：上下或左右移动
- 回想：视线失焦（看向虚空）

### 法则二：意图驱动一切

#### 动作目的性
每个动作必须回答：
1. 这个角色想要完成什么？
2. 他们现在处于什么阶段？
3. 下一步是什么？

#### 动作衔接
- **前摇**：动作开始前的准备
- **执行**：主要动作本身
- **收尾**：动作结束后的延续
- **过渡**：回到待机状态或进入下一个动作

#### 情绪层次
```
Level 1: 表面情绪（面部表情）
Level 2: 身体反应（姿势、肌肉紧张）
Level 3: 微动作泄露（颤抖、出汗、僵硬）
Level 4: 内心冲突（眼神变化、咬紧牙关）
```

#### 反应延迟
- 惊讶：0.2-0.5秒后开始反应
- 疼痛：0.3-0.8秒延迟
- 愤怒：逐渐积累（0.5-2秒）
- 恐惧：即时反应+持续颤抖

### 法则三：环境互动

#### 脚部与地面
- 踩踏：用力下压，鞋底变形
- 滑动：脚尖/脚跟引导方向
- 蹬地：爆发性力量释放
- 站立：重心分配（均衡/偏移）
- 攀爬：脚趾抓紧、手脚配合

#### 手部与物体
- 握拳：力度从0%到100%
- 抚摸：指尖轻触、节奏缓慢
- 支撑：体重转移、肌肉紧绷
- 操控：精确的手指动作
- 投掷：蓄力→释放→收手

#### 身体与气流
- 迎风：头发后飘、衣物紧贴
- 顺风：头发前飘、衣物飘起
- 无风：自然下垂
- 能量风：方向混乱、强度不一

#### 视线与环境
- 观察：聚焦→扫描→聚焦
- 追踪：平滑移动跟随目标
- 忽略：有意识转移注意力
- 警戒：扫视多个可疑点

### 法则四：动态Pose链

```
[待机Pose] → [预警Pose] → [预备Pose] → [蓄力Pose] → [释放Pose] → [惯性Pose] → [恢复Pose] → [待机Pose]
```

#### 各Pose详细说明

| Pose | 时长 | 特征 | 肌肉状态 |
|------|------|------|---------|
| 待机 | 持续 | 自然站立、重心居中 | 放松 |
| 预警 | 0.3s | 重心下沉、肌肉激活 | 轻度紧张 |
| 预备 | 0.5s | 肢体后撤、能量聚集 | 中度紧张 |
| 蓄力 | 0.2s | 全身绷紧、能量爆发前 | 极度紧张 |
| 释放 | 0.1s | 动作高潮、力量输出 | 瞬间爆发 |
| 惯性 | 0.3s | 动作延续、力量衰减 | 逐渐放松 |
| 恢复 | 0.5s | 回到平衡、调整姿态 | 放松 |
| 待机 | 持续 | 新平衡状态 | 放松 |

## 特殊状态微动作

### 变身/觉醒状态

| 阶段 | 时长 | 微动作 |
|------|------|--------|
| 触发 | 0.5s | 身体僵直、表情凝固 |
| 光芒 | 1-2s | 能量从核心爆发、光芒吞噬 |
| 转变 | 1-3s | 衣袍撕裂、形态重塑、痛苦表情 |
| 完成 | 0.5s | 猛然睁眼、力量外泄、震撼表情 |

### 受伤状态

| 程度 | 微动作 |
|------|--------|
| 轻伤 | 皱眉、轻微后仰、咬牙 |
| 中伤 | 踉跄、手捂伤口、单膝跪地 |
| 重伤 | 倒地、痉挛、挣扎爬起 |
| 濒死 | 呼吸困难、视线涣散、手无力抓握 |
