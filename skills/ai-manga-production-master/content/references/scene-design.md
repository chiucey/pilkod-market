# 场景灵动设计详细模板

## 四大维度详解

### 维度一：环境呼吸

#### 植物系统
| 植物类型 | 动态特征 | 参数 |
|----------|---------|------|
| 大树 | 整体摇摆（风）+ 叶片沙沙 | 摆动周期：3-5秒，振幅：5-15度 |
| 小草 | 随风倒伏 + 恢复 | 响应延迟：0.1秒，恢复：0.3秒 |
| 花朵 | 花瓣颤动 + 随风摇曳 | 颤动频率：2-4Hz |
| 藤蔓 | 末端摆动 + 缠绕旋转 | 旋转周期：10-20秒 |
| 竹林 | 整体波浪式摆动 | 波传播速度：2m/s |

#### 水体系统
| 水体类型 | 动态特征 | 参数 |
|----------|---------|------|
| 湖泊 | 波浪起伏 + 反射闪烁 | 波高：2-10cm，周期：2-4秒 |
| 河流 | 持续流动 + 漩涡 | 流速：1-3m/s |
| 瀑布 | 水花飞溅 + 水雾弥漫 | 溅射高度：0.5-2m |
| 雨滴 | 溅起水花 + 波纹扩散 | 涟漪持续：1-2秒 |
| 积水 | 反射晃动 + 涟漪 | 扰动衰减：0.5秒 |

#### 火焰系统
| 火焰类型 | 动态特征 | 参数 |
|----------|---------|------|
| 蜡烛 | 稳定摇曳 + 偶尔爆闪 | 摇曳幅度：5-10度 |
| 火把 | 剧烈摆动 + 火星飞散 | 火星数量：5-15/秒 |
| 篝火 | 火焰跳跃 + 烟尘上升 | 火舌高度变化：20% |
| 爆炸火球 | 膨胀 + 收缩 + 消散 | 持续：0.5-2秒 |
| 能量火焰 | 脉冲发光 + 色彩流动 | 脉冲频率：1-3Hz |

#### 云层系统
| 云类型 | 动态特征 | 参数 |
|--------|---------|------|
| 积云 | 缓慢膨胀 + 形状变化 | 变化周期：30-60秒 |
| 卷云 | 快速移动 + 丝状飘动 | 移动速度：5-20m/s |
| 乌云 | 翻涌滚动 + 颜色加深 | 翻涌周期：10-20秒 |
| 彩霞 | 色彩渐变 + 位置移动 | 变化周期：5-10分钟 |

#### 尘土系统
| 尘土类型 | 动态特征 | 参数 |
|----------|---------|------|
| 漂浮 | 缓慢下落 + 随机飘动 | 下落速度：0.1-0.5m/s |
| 扬起 | 被扰动后上升 | 扬起高度：1-5m |
| 沉降 | 战斗后的缓慢下落 | 沉降时间：5-30秒 |
| 龙卷 | 螺旋上升 + 吸力效果 | 旋转周期：2-5秒 |

### 维度四：空间深度

#### 层次划分
```
极远景（天空/宇宙）→ 远景（山峦/建筑）→ 中景（树木/人物）→ 近景（道具/粒子）→ 前景（虚化元素）
```

#### 各层动态特征

| 层次 | 移动速度 | 清晰度 | 动态特征 |
|------|---------|--------|---------|
| 极远景 | 极慢/静止 | 模糊 | 云层缓慢移动 |
| 远景 | 很慢 | 略清晰 | 建筑轮廓/山脉 |
| 中景 | 正常 | 清晰 | 主要角色/物体 |
| 近景 | 较快 | 非常清晰 | 可辨识细节 |
| 前景 | 快/极快 | 虚化 | 粒子/飘落物 |

## 场景类型设计模板

### 城市战斗场景

```
├── 地面层：积水反射火光、裂缝中冒出蒸汽、碎石散落
├── 前景：破碎的玻璃碎片（缓慢下落，旋转）
├── 中景：主角战斗、敌人被击飞、建筑残骸
├── 背景：倒塌的广告牌（随风晃动）、路灯闪烁
├── 极远：霓虹灯闪烁（色彩变化）、高楼剪影、天空云层
└── 环境音：玻璃碎裂、金属碰撞、远处爆炸、警报声
```

**关键灵动元素**：
- 玻璃碎片：每5秒下落一块，旋转落地
- 霓虹灯：红→蓝→紫循环，频率0.5Hz
- 积水波纹：爆炸→涟漪扩散→恢复
- 蒸汽：每3秒一股，持续1秒

---

### 森林场景

```
├── 地面层：落叶被踩碎、苔藓覆盖的石块、花瓣散落
├── 前景：草叶被脚步压倒后反弹
├── 中景：树木、蘑菇、花朵随气流摆动
├── 背景：远山剪影、云雾缭绕缓慢移动
├── 光线：阳光透过树叶形成光柱（丁达尔效应）+ 光斑
└── 环境音：鸟鸣、树叶沙沙、溪流潺潺、脚步踩落叶
```

**关键灵动元素**：
- 草叶：响应时间0.2秒，恢复0.5秒
- 光斑：随风移动，亮度闪烁
- 落叶：每10秒飘落2-3片
- 蘑菇：微微颤动（微观视角）

---

### 废墟场景

```
├── 地面层：碎石、裂缝、尘土覆盖
├── 前景：落灰（缓慢下落）、碎石（偶尔滚动）
├── 中景：残垣断壁、锈蚀的金属、倒塌的梁柱
├── 背景：坍塌的建筑轮廓、扭曲的钢筋
├── 光线：透过裂缝的光束（光柱中的尘埃）
└── 环境音：风穿过空洞的呜咽声、金属碰撞、滴水
```

**关键灵动元素**：
- 落灰：50-100粒子/帧，下落速度0.5m/s
- 光束：宽度10-30cm，随风摆动
- 滴水：每5-15秒一滴
- 金属晃：被风吹动，发出声响

---

### 宇宙/星空场景

```
├── 前景：能量粒子（蓝/金色）、飞船残骸碎片
├── 中景：主要角色/飞船、武器能量轨迹
├── 背景：星云（缓慢旋转）、银河系旋臂
├── 星光：闪烁（距离差异造成的时间差）
└── 特效：虫洞扭曲（螺旋变形）、星体爆炸光环、能量波纹
```

**关键灵动元素**：
- 星星闪烁：随机闪烁，频率0.1-0.5Hz
- 星云旋转：周期10000年（视觉化）
- 能量粒子：螺旋轨迹，速度变化
- 虫洞：中心向外螺旋扭曲

---

### 室内场景

```
├── 地面层：地板材质、阴影、反射
├── 前景：窗帘摆动、光线变化
├── 中景：家具、装饰品、人物
├── 背景：窗户（窗外光线）、墙面装饰
├── 光线：窗户光入射、灯泡闪烁、阴影移动
└── 环境音：时钟滴答、窗外车流（远处）、空调运转
```

**关键灵动元素**：
- 窗帘：摆动周期3-5秒
- 阳光角度：随时间缓慢移动
- 灰尘粒子：光线中可见，漂浮移动
- 阴影：随窗外物体移动
