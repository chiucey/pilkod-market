## Seedance 2.0 生视频系统

### 主要模式

| 模式 | 输入 | 适合场景 |
|------|------|---------|
| 文生视频 | 纯文字 | 开场、氛围建立、无参考场景 |
| 图生视频 | 参考图+文字 | 角色动作、场景延续 |
| **全能参考模式** | 多张参考图+文字 | 角色一致性、复杂动作、场景连续性 |
| 首尾帧 | 起始图+结束图+过渡 | 确定性的动作起止 |

### 全能参考模式参考策略

#### 策略一：角色多角度参考
```
├── 图片1：正面全身照（建立基础形象）
├── 图片2：侧面照（补充轮廓）
├── 图片3：面部特写（表情/眼神关键）
└── 图片4：动作姿态参考（如有特定动作）
```

#### 策略二：角色+环境参考
```
├── 图片1：角色全身/半身照
├── 图片2：目标环境/背景图
└── 效果：角色在指定环境中
```

#### 策略三：动作分解参考
```
├── 图片1：动作预备姿态
├── 图片2：动作高潮姿态
├── 图片3：动作结束姿态
└── 效果：流畅的完整动作
```

#### 策略四：风格参考
```
├── 图片1：角色形象
├── 图片2：参考风格图（如电影截图）
└── 效果：角色以参考风格呈现
```

## 提示词优化技巧

### 中文提示词书写规范

| 类别 | 准确词 | 模糊词 |
|------|--------|--------|
| 动词 | 挥砍、突刺、闪避、翻滚、腾空 | 动、移动、变化 |
| 形容词 | 凌厉眼神、肌肉紧绷、血液流淌 | 很好看、很厉害、很帅 |
| 场景 | 火山喷发映红天际、暴雨中霓虹闪烁 | 好看的天空、漂亮的背景 |
| 氛围 | 紧张感达到顶峰、压迫感逐秒增加 | 感觉很紧张、氛围很好 |

### 时间节点明确化

```
原：能量爆发
优化：00:00-00:01能量从胸口核心聚集，
     00:01-00:02能量达到临界点开始溢出，
     00:02瞬间爆发形成光柱
```

### 镜头运动具体化

```
原：镜头推进
优化：镜头从腰部全景在1.5秒内缓慢推进至面部特写，
     推进速度均匀，推进过程中焦点始终锁定角色眼睛
```

### 节奏把控描述

```
原：战斗激烈
优化：前3秒蓄力期动作缓慢，后2秒爆发期动作骤然加快，
     速度对比反差制造冲击力
```
