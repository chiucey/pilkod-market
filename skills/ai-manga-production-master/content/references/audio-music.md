### 战斗配乐结构

#### 1. 开场 Build-up（8秒）
```
元素：低频脉冲
特征：节奏逐渐加快
功能：氛围铺垫
音量：-20dB → -10dB
过渡：与背景音混合
```

#### 2. 爆发 Drop（高潮开始）
```
元素：鼓点爆炸
特征：铜管齐鸣
功能：力量爆发
音量：0dB
特效：配合能量释放
```

#### 3. 持续 Combat Loop（战斗持续）
```
元素：鼓点稳定
特征：节奏根据动作强度变化
功能：维持紧张感
音量：-5dB → 0dB
特效：特效音效融入配乐
```

#### 4. 变奏 Breakdown（关键时刻）
```
元素：节奏放慢
特征：旋律突出
功能：情绪聚焦
音量：-10dB
特效：单主角视角
```

#### 5. 终结 Finale（结束）
```
元素：所有元素汇聚
特征：最后一次爆发
功能：情绪顶点
音量：+3dB
过渡：余韵收尾
```

## 音量动态范围

### 音量级别定义

| 级别 | 分贝 | 用途 | 动态余量 |
|------|------|------|---------|
| 0 | 0dB | 峰值/爆炸 | 最大音量 |
| 1 | -5dB | 主要音效 | 常规使用 |
| 2 | -10dB | 次要音效 | 混音空间 |
| 3 | -20dB | 环境音 | 背景铺垫 |
| 4 | -30dB | 底层环境 | 氛围营造 |
| 5 | -40dB | 极低音量 | 隐约可闻 |

### 混音原则

```
1. 对话层：主音，确保清晰度
2. 音效层：辅助，增强真实感
3. 音乐层：铺垫，控制情绪
4. 环境层：氛围，可低可高

优先级：对话 > 关键音效 > 配乐 > 环境音
```
