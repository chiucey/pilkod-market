# Customer Profile Skill V2 - Export Version

根据客户名称，通过公开信息调研 + 结构化分析，生成符合 v2 样式规范的 HTML 客户档案网页。

## 工作流程

1. **信息收集**：优先从天眼查/企查查获取工商信息，结合官网、公众号及行业新闻补充业务细节。
2. **内容构建**：按照以下 13 个模块进行结构化排版。
3. **HTML 交付**：生成单文件 HTML，内联 CSS，无外部依赖。

## 核心样式规范 (v2)

### 1. 页面头图 (Hero Section)
- **背景**：深蓝色 (#1E3A66)，右侧配有半透明圆形渐变装饰。
- **标签系统**：左上角横向排列语义化标签（行业/优先级/状态），采用彩色圆角设计。
- **核心信息**：大号白色粗体公司名称，下方配置版本/日期元数据。
- **关键数据点**：横向排列关键指标（注册资本、成立时间、总部等），每项前配置不同颜色的语义化圆点。

### 2. KPI 概览卡片
- **布局**：4 张横向排列的圆角卡片。
- **语义着色**：蓝色 (历史)、橙色 (成就)、红色 (风险)、绿色 (增长)。

### 3. 基本信息模块
- **标题栏**：浅灰蓝底色 (#F8FAFC)，左侧带文档图标 (📄)，标题深蓝加粗。
- **字段排列**：左标签右内容两列结构，行间虚线分隔。
- **必填项**：企业名称、统一社会信用代码、法定代表人、注册资本、成立日期、企业类型、所属行业、注册地址、经营范围、经营状态、纳税人资质、人员规模、参保人数、营业期限、登记机关、联系电话、电子邮箱、官方网站。缺失项统一标记为“待调研”。

### 4. 业务板块网格
- **布局**：两行三列网格布局，圆角卡片配语义化图标。

### 5. 组织架构展示
- **布局**：分区块卡片式布局（创始层/管理层/股东）。
- **节点**：圆角矩形卡片，姓名深蓝加粗，职位浅灰，关键数据橙色高亮。

### 6. 决策链路矩阵
- **布局**：表格化布局（角色、影响力、关注重点、接触策略）。
- **视觉编码**：彩色圆点区分角色（红=决策者/橙=评估者/绿=关注者），影响力标签加粗。

### 7. 信息化与AI现状（细化版）
- **布局**：2x3 网格，浅青色科技感背景 (#E0F2F1)。
- **模块**：基础IT、业务制造、AI智能化、战略合作、品牌数字化、数据BI。
- **状态**：绿色对勾 (✅) 表完成，橙色标签表待确认/待建。

### 8. 痛点分析
- **布局**：卡片式列表，带阴影圆角容器。
- **分级**：彩色圆形徽章编号（1-4）表示紧迫程度（红/橙/紫/灰绿渐变）。

### 9. 协同办公平台展示
- **布局**：三栏卡片布局（钉钉/企微/飞书），极浅灰白背景。
- **元素**：对话气泡图标，状态标签及底部注释。

### 10. 财务与运营关键指标
- **布局**：卡片式表格，三列矩阵（指标、数据、备注）。
- **样式**：表头浅灰蓝，数据深蓝加粗，顶部配语义化图标。

### 11. 自研数字化/AI产品
- **布局**：卡片式模块化，浅紫/淡粉色调背景 (#F8F0FA)。
- **高亮**：发布标题及产品名粉红高亮 (#D81B60)。
- **升华区**：底部设黄色警示图标 (⚠️) 的价值升华区。

### 12. 跟进建议参考
- **布局**：2×2 四宫格卡片布局。
- **视觉**：语义化图标（🔥/👤/🎯/⚠️）及左侧强调色引导线。

### 13. 档案来源说明
- **位置**：页面底部，浅灰色小号字体。
- **内容**：列出多渠道来源（百度百科、天眼查、新浪财经等）及免责声明。

## 执行原则

- 所有信息须注明来源。
- 信息缺失项标注"待调研"，严禁虚构。
- 输出语言：简体中文。
