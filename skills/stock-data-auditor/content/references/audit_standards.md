# 股票数据审计标准参考

## 一、数据实时性标准

### 1.1 时间戳标准

| 数据类型 | 最大延迟 | 标注要求 |
|---------|---------|---------|
| 实时价格 | 5分钟 | 必须标注 |
| 盘口数据 | 10秒 | 必须标注 |
| 成交明细 | 30秒 | 建议标注 |
| 日K线 | 收盘后更新 | 标注日期 |

### 1.2 交易日判断

- A股：周一至周五 9:30-11:30, 13:00-15:00
- 港股：周一至周五 9:30-12:00, 13:00-16:00
- 美股：周一至周五 21:30-次日4:00（夏令时）

### 1.3 非交易时间数据状态

```
交易时间内：数据应为实时状态
非交易时间：
  - 显示"暂无更新"或最后更新时间
  - 明确标注"盘后数据"
  - 避免混用不同时间点数据
```

## 二、分析结果标准化

### 2.1 估值指标计算口径

| 指标 | 计算公式 | 注意事项 |
|-----|---------|---------|
| P/E (市盈率) | 市值/净利润 | 区分TTM/静态/动态 |
| P/B (市净率) | 市值/净资产 | 使用最新财报 |
| P/S (市销率) | 市值/营业收入 | 适用于亏损公司 |
| EV/EBITDA | 企业价值/息税折旧前利润 | 用于跨行业比较 |

### 2.2 涨跌幅计算

```
涨跌幅 = (现价 - 昨收价) / 昨收价 × 100%

特殊情况处理：
- 除权除息日：使用复权价格
- 新股上市首日：特殊标记
- 涨跌停板：标注涨停/跌停状态
```

### 2.3 数据来源分类

| 优先级 | 来源类型 | 可靠性 |
|-------|---------|-------|
| 1 | 交易所官方数据 | 最高 |
| 2 | 监管机构公告 | 高 |
| 3 | 上市公司公告 | 高 |
| 4 | 知名金融数据商 | 中高 |
| 5 | 其他公开渠道 | 中 |

## 三、失败案例分类

### 3.1 失败类型定义

| 类型编码 | 类型名称 | 描述 |
|---------|---------|-----|
| RT-01 | 数据延迟 | 超过规定延迟阈值 |
| RT-02 | 时间戳缺失 | 未标注数据时间 |
| RT-03 | 数据不一致 | 交叉验证发现差异 |
| STD-01 | 计算错误 | 指标计算结果错误 |
| STD-02 | 来源缺失 | 关键数据无来源 |
| STD-03 | 口径不一致 | 计算标准混乱 |
| MON-01 | 修复未执行 | 问题未按计划修复 |
| MON-02 | 修复无效 | 修复后问题仍存在 |
| MON-03 | 重复失败 | 同类问题反复发生 |

### 3.2 严重程度等级

| 等级 | 标识 | 影响范围 | 处理时限 |
|-----|-----|---------|---------|
| 严重 | Critical | 大范围/核心数据 | 立即处理 |
| 高 | High | 单项重要数据 | 24小时内 |
| 中 | Medium | 一般性数据 | 72小时内 |
| 低 | Low | 边缘数据/格式 | 7天内 |

## 四、修复监督流程

### 4.1 修复状态流转

```
[新发现问题] → [已分配] → [修复中] → [待验证] → [已关闭]
     ↓
  [问题升级]（如修复超时或失败）
```

### 4.2 验证检查清单

- [ ] 修复措施已实际执行
- [ ] 原始问题已解决
- [ ] 未引入新问题
- [ ] 相关联案例已同步更新
- [ ] 监控机制已建立

### 4.3 预防措施

1. 问题根因分析（RCA）
2. 建立检查点
3. 添加自动化监控
4. 完善文档和培训
