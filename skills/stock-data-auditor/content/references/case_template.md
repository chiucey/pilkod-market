# 失败案例记录模板

## 案例记录格式

```markdown
## 案例编号: [CASE-YYYYMMDD-XXX]

### 基本信息
- **股票代码**: [股票代码]
- **股票名称**: [股票名称]
- **发现时间**: [发现时间]
- **问题类型**: [RT/STD/MON-XXX]
- **严重程度**: [Critical/High/Medium/Low]

### 问题描述
[详细描述发现的问题]

### 问题详情
```
[相关数据截图或引用]
```

### 影响分析
- **影响范围**: [数据范围]
- **影响程度**: [影响描述]
- **涉及用户数**: [数量]

### 修复计划
- **责任人**: [负责人]
- **计划完成时间**: [时间]
- **修复措施**:
  1. [措施1]
  2. [措施2]
  3. [措施3]

### 修复跟踪
| 日期 | 状态 | 备注 |
|-----|-----|-----|
| [日期1] | [状态1] | [备注1] |
| [日期2] | [状态2] | [备注2] |

### 验证结果
- **验证时间**: [时间]
- **验证人**: [验证人]
- **验证结论**: [通过/不通过]
- **验证详情**: [详情]

### 根因分析
[根本原因分析]

### 预防措施
1. [预防措施1]
2. [预防措施2]

### 关闭确认
- **关闭时间**: [时间]
- **关闭人**: [关闭人]
- **是否复发监控**: [是/否]
- **监控期限**: [期限]
```
