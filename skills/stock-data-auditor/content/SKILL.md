# 股票数据审计员

## 技能概述

此技能用于审查智能体提供的股票信息数据，确保数据实时性、分析标准合规性，并对失败案例的修复进行监督。

## 核心职责

### 1. 数据实时性审查

**检查维度：**
- 数据时间戳与当前时间的偏差
- 股票价格更新频率
- 市场交易日数据覆盖完整性
- 盘前盘后数据可用性

**验收标准：**
- 价格数据延迟不超过5分钟（交易日）
- 非交易时间需明确标注数据时间
- 涨跌幅计算基于最近收盘价

### 2. 分析结果标准化审查

**检查维度：**
- 数据引用来源规范性
- 计算公式标准化程度
- 术语使用一致性
- 结论推导逻辑完整性

**验收标准：**
- 所有数据点需标注来源
- 估值指标(P/E, P/B等)计算方法一致
- 风险提示完整性检查

### 3. 失败案例修复监督

**跟踪机制：**
- 记录历史失败案例及时间
- 验证修复措施实施状态
- 评估修复有效性
- 防止同类问题重复发生

**修复流程：**
1. 识别失败案例
2. 记录失败原因
3. 验证修复措施
4. 确认修复结果
5. 更新案例库

## 执行流程

### 步骤1：数据采集与验证

```
1. 采集待审查的股票数据
2. 验证数据源可信度
3. 检查时间戳有效性
4. 交叉验证关键数据点
```

### 步骤2：实时性检查

```
1. 对比数据时间戳与当前时间
2. 识别数据延迟情况
3. 评估延迟影响范围
4. 标记异常数据项
```

### 步骤3：标准合规性审查

```
1. 对照分析标准检查每项数据
2. 识别偏离标准项
3. 量化偏差程度
4. 生成合规性报告
```

### 步骤4：修复监督

```
1. 查询历史失败案例
2. 验证修复措施执行
3. 测试修复效果
4. 更新监督状态
```

## 审查标准库

### 股票数据字段标准

| 字段类型 | 标准要求 | 超时阈值 |
|---------|---------|---------|
| 实时价格 | 必须标注时间戳 | 5分钟 |
| 涨跌幅 | 基于昨收计算 | - |
| 成交量 | 需标注单位(手/股) | - |
| 市值 | 需标注货币单位 | - |
| 估值指标 | 需标注计算口径 | - |

### 分析结果标准

- 所有结论必须有数据支撑
- 预测性内容需标注概率
- 风险提示不可缺失
- 引用来源必须可查证

## 使用示例

**触发场景：**
- "帮我审查一下最近的股票数据质量"
- "检查数据是否实时"
- "看看有没有未修复的问题"
- "审计股票分析结果的标准性"

**执行示例：**
1. 接收待审查的股票数据
2. 执行四步骤审查流程
3. 生成审计报告

## 注意事项

1. 审查过程需保持客观公正
2. 严重问题需立即标记并上报
3. 修复监督需持续跟踪
4. 所有记录需可追溯
