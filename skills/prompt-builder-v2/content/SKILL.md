# 提示词巧匠 v2.0（Prompt Builder v2.0）

## 重大升级说明

### v2.0 核心升级点
- **数据持久化**：所有生成的提示词自动保存到个人库
- **智能检索**：支持按场景、评分、时间、标签等多维度查询历史提示词
- **资产管理**：收藏、版本管理、一键复用优质提示词
- **模板库**：预设模板+用户自定义模板
- **数据统计**：使用统计、评分分布、趋势分析

### 双阶段工作流（保持不变）
- **阶段一**：提示词优化工具（输入需求 → 输出高质量提示词）
- **阶段二**：AI内容生成工具（输入最佳提示词 → 输出AI生成内容）

## 新功能：提示词资产管理

### 1. 自动存储机制
每次生成提示词后，系统自动：
- 保存提示词内容到个人库
- 记录14维度评分详情
- 保存场景、目标导向等元数据
- 生成唯一提示词ID

### 2. 我的提示词库
提供完整的资产管理界面：

```markdown
📚 我的提示词库

筛选条件：
• 场景：[全部/文案撰写/会议纪要/代码编程...]
• 评分：[全部/90分以上/80-89分/...]
• 时间：[全部/最近7天/最近30天/...]
• 标签：[收藏/高频使用/...]

┌─────────────────────────────────────────────────────────┐
│ ⭐ 提示词 #1                           评分: 92  收藏   │
│ 场景: 产品文案撰写    时间: 2025-03-19    使用: 5次      │
│                                                         │
│ 你是一位资深产品文案专家...                              │
│                                                         │
│ [查看详情] [一键复用] [生成内容] [导出Excel]            │
└─────────────────────────────────────────────────────────┘
```

### 3. 版本管理
记录提示词的优化历史：
- 保存每次修改的版本
- 对比不同版本的差异
- 查看评分变化趋势
- 回退到历史版本

### 4. 模板库
- **系统模板**：预设30个场景的常用模板
- **用户模板**：将优秀提示词保存为个人模板
- **模板分享**：导出/导入模板

### 5. 智能检索
支持多维度组合筛选：
- 按场景筛选
- 按评分区间筛选
- 按创建时间筛选
- 按标签筛选
- 全文关键词搜索

## 工作流程（升级增强版）

### 标准流程：提示词构建 + 自动存储

```markdown
用户输入需求
    ↓
智能体调用 prompt-builder-v2 Skill
    ↓
场景识别 → 要素推荐 → 信息收集 → 提示词生成 → 质量评估
    ↓
展示结果 + 自动存储到个人库
    ↓
用户选择：
  • [优化] → 调整要素 → 重新生成 → 保存新版本
  • [使用] → 复制提示词
  • [生成内容] → 进入阶段二 → AI生成内容
  • [收藏] → 加入收藏夹
  • [查看历史] → 打开提示词库
```

### 资产管理流程

```markdown
用户：查看我的提示词库
    ↓
展示历史提示词列表（支持筛选）
    ↓
用户操作：
  • 查看详情（含14维度评分）
  • 一键复用（带入原有要素）
  • 对比版本（查看优化历史）
  • 编辑/优化（创建新版本）
  • 批量导出（Excel格式）
  • 删除/收藏
```

当用户选择"一键复用"时：

3. 用户可以在此基础上修改优化
4. 生成新的提示词版本

## 数据存储说明

### 存储方式（扣子空间适配）

由于扣子空间是AI应用平台，采用以下存储方案：

**方案1：持久化存储（推荐）**
- 使用扣子空间的`存储`功能
- 数据以JSON格式存储
- 支持跨会话访问

**方案2：会话内存储**
- 在当前会话中维护提示词列表
- 会话结束后数据丢失
- 适合临时使用

**数据格式示例**：
```json
{
  "prompts": [
    {
      "prompt_id": "P20250319123045",
      "scenario": "产品文案撰写",
      "prompt_content": "你是一位资深产品文案专家...",
      "score": 92,
      "dimensions": {
        "identity": "资深产品文案专家",
        "target_audience": "25-35岁都市白领",
        ...
      },
      "created_at": "2025-03-19T12:30:45",
      "is_favorite": true,
      "use_count": 5
    }
  ]
}
```

## 重要规则

### 1. 自动存储规则
- **所有生成的提示词必须自动存储**
- 即使评分较低也要存储（便于后续优化）
- 存储时记录完整的元数据

### 2. 复用规则
- 复用时加载完整的要素信息
- 用户可以选择保持原样或修改
- 复用后生成新版本（不是覆盖原版本）

### 3. 导出规则
- 支持单条导出和批量导出
- 导出格式：Excel详细版/简洁版
- 导出范围：全部/筛选结果/收藏

### 4. 统计规则
- 实时统计使用数据
- 展示趋势分析
- 推荐高频使用的提示词
