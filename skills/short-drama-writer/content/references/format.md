# 短剧剧本格式规范

## 一、单集正文标准格式

```markdown
【第X集正文】          ← 集标题，深蓝底白字，sz=30，加粗居中

【X-1 场景地点  时间  事件描述】  ← 场次标题，深蓝底白字，sz=22

▲动作描写。          ← 动作行，以▲开头
角色名：台词内容。   ← 台词行，角色名加粗
（OS）角色名：内心独白内容。  ← 内心OS，紫色斜体
（VO）旁白/系统：内容。      ← 旁白/系统音，蓝色加粗

【X-2 场景  时间  事件】  ← 下一场

……

「第X集完」            ← 集尾标识，深灰底白字居中
字数：___字（600-900字，精确统计） ← 上限标准，右下角灰色
【下集预告】……         ← 预告，深红色斜体居中
```

## 二、台词创作方法论

### 2.1 戳人台词的心理学

- 最出圈的台词 = "被说过但没说透"的话，替观众说出说不出口的情绪
- 婆媳/母子场景：用"我以为你会……"比"你应该……"更戳人
- 道歉场景：说"对不起"不如说"我知道你等了很久"
- 强台词特征：3句话以内、有具体细节、能引发转发

### 2.2 反派台词写法

- 表面：无害、可怜、为你好
- 细思极恐：让观众看完回想才觉得不对劲
- 不用"我要毁了你"，用"我是为你好"
- 最好的反派台词是"你以为我想这样吗？"

### 2.3 系统台词风格

- 冷幽默，不说安慰话，说让人反思的话
- 永远冷静，不用感叹号
- 每集功德值变化必须明确标注
- 示例：
  - `（VO）【将功赎罪系统】懂得拒绝，功德值+5。`
  - `（VO）【提示：爱不是给十分，而是留三分给自己。】`

## 三、动作描写规范

### 3.1 OS使用限制（≤1处/集）

**能用演员表演呈现的，一律用 `▲` 动作描述，不加 OS 配音。**

```
✓ 正确：▲周梅芳的手微微一颤，眼眶红了。
✗ 错误：（OS）周梅芳心里很感动。
```

### 3.2 OS仅在以下情况使用（≤2句/处）

- 角色无法通过台词/动作表达内心时
- 重生者的"前世记忆闪回"补充说明
- 系统内心独白

## 五、重生类剧本特殊处理

- **弥留开场戏**：单独成集，约1500字
- **重生觉醒激动戏**：单独成集，约1200字
- **第一个冲突（拒绝给钱）**：单独成集，约1200字
- **全剧大高潮集**：必须至少3个泪点，可写到1500字

## 六、闪回片段规范（铁律）

**【最高优先级】所有闪回片段必须使用主观镜头（第一人称视角），禁止使用客观/全知视角。**

### 6.1 两种闪回长度

闪回分为两种，规则不同：

| 类型 | 适用场景 | 时长 | 台词量 |
|------|---------|:----:|:------:|
| 快闪镜头组合 | 快速交代前史、情绪冲击、蒙太奇剪接 | ≤6秒 | 2句以内 |
| 普通闪回片段 | 重要情感戏、关键回忆、关系揭示 | 10-30秒 | 3-6句，可多段 |

**如何判断用哪种：**
- 情绪爆点/大场面用快闪（≤6秒，紧凑有力）
- 情感铺垫/关系前史用普通闪回（更长更细腻）

### 6.2 快闪镜头组合格式

适用：情绪爆点、快速剪辑、蒙太奇式闪回

```
【闪进】
我看见/我听见/我记得——
（动作，主观视角，2句以内）
台词（2句以内，角色名：内容）
【闪出】
```

**正确示例：**
```
【闪进】
我站在医院窗口，手里攥着67块钱。
护士：挂号费不够，您还差3块。
（我看着窗口外的天，灰的。）
【闪出】
```

### 6.3 普通闪回片段格式

适用：情感铺垫戏、关系揭示、关键前史

```
【闪进】
我记得——
（动作描写，主观视角，2-3句）

台词1（角色名：内容）

（动作，补充细节）

台词2-3（角色名：内容，可多段）
【闪出】
```

**正确示例：**
```
【闪进】
我记得那天晚上。
（我蹲在楼道里，把散落的东西一件件捡进箱子。）

儿媳：（门里传来声音）妈，您别怪我们，这个家真的住不下了。

（我的手停在一张全家福上。那是老头子走后第一年拍的，我在最边上，脸是糊的。）

我：（把照片塞进口袋）好，我走。
【闪出】
```

### 6.4 主观镜头铁律

- 所有闪回必须是"我"的视角（我看见/我听见/我记得）
- 不能用客观描述（不能写"出租屋里，林晓蹲在地上"）
- 闪进前必须交代来源（如"意识渐渐涣散，那些画面浮现——"）

### 6.5 正确 vs 错误示例

```
✓ 正确（主观镜头）：
【闪进】
我透过门缝，看见志勇蹲在墙角，张磊居高临下地俯视他。
张磊：钱呢？
志勇：（发抖）磊哥……我真的没有了……
【闪出】

✗ 错误（客观镜头，禁止）：
【闪进】
逼仄的出租屋。深夜。周志勇蜷缩在墙角，张磊居高临下。
张磊：钱呢？
周志勇：（发抖）磊哥……
【闪出】
```

### 6.6 闪回自检问题

- [ ] 是否是"我"的主观视角？（我看见/我听见/我记得）
- [ ] 快闪镜头组合：台词是否≤2句，时长是否≤6秒？
- [ ] 是否在【闪进】前交代场景来源？
- [ ] 闪回是否推进了剧情或揭示了关系？

## 七、人物小传格式

### 7.1 角色卡片格式

每张人物小传包含七个固定模块：

```
【角色名称】林晓
【年龄/身份】28岁，广告公司资深策划

【家庭出身】
父母关系、成长背景、关键经历（2-3句）
示例：单亲家庭长大，母亲早逝，父亲沉默寡言，父女之间从小说不上三句话。

【性格底色】
行为模式而非形容词（2-3句）
示例：外人眼里是女强人，实际是把所有精力投入工作来逃避情感问题。别人找她帮忙从不拒绝，但从来不敢主动开口求人。

【核心缺陷】
这个角色最致命的弱点/原罪（1-2句）
示例：亏欠型人格——对谁都好，就是对自己狠。

【人物弧光】（详细版，不限字数）
这一部里这个角色经历了什么？核心变化是什么？要写得详细，把主要剧情变化全部写清楚，不能遗漏关键阶段。

格式：
```
起点（第1集前/前世状态）→ 阶段1（第X集发生什么）→ 阶段2（第X集）→ 阶段3（第X集）→ 终局（第X集）
```

示例（详细版）：
```
起点（第1集前）：林晓32岁，单身，工作狂，不懂拒绝，对前男友付出一切，被分手后崩溃。
→ 阶段1（第1集）：分手后用工作麻痹自己，拒绝承认失恋，阿金求陪玩被拒绝。
→ 阶段2（第3集）：决定带阿金去爬山散心，出发前给前男友发了一条消息，对方没回。
→ 阶段3（第4集）：坠崖，阿金跳下救她，她在恐惧中感受到被爱。
→ 阶段4（第6集）：醒来发现阿金已死，崩溃，这是她第一次为一个人/一条命痛哭。
→ 阶段5（第7-8集）：独处时前世记忆涌现，想起母亲的死、父亲的等待、对阿金的亏欠——她决定改变。
→ 阶段6（第9-10集）：回家看父亲，第一次主动拥抱父亲；做流浪狗志愿者，遇到陈锋。
→ 阶段7（第11-14集）：领养小金，和陈锋感情升温，建立动物救助中心。
→ 终局（第20集）：带着两只狗和陈锋登山，在阿金墓前说"我活出来了"。
```

【人物弧光·精简流程总结】
一行话概括这个角色在这部剧里的变化轨迹：
示例：林晓：从"为别人活"到"为自己活也为爱活"

【代表性台词】
2-3句，说出这个人物的声音
示例："我以为只要拼命赚钱，就不用面对那些我不想面对的事。"
     "你为什么不早点告诉我？"
     "这次我不逃了。"

【核心关系张力】
这个角色和其他角色的最大矛盾点
示例：和父亲——她想回家但不知道说什么；和前男友——被利用但不甘心；和阿金——她亏欠它一条命
```

### 7.2 主角/反派/关键配角的区别

| 角色类型 | 必须填几项 | 重点 |
|---------|:---------:|------|
| 主角 | 七项全填 | 弧光必须完整，性格缺陷是核心驱动力 |
| 反派 | 六项（弧光换"动机"） | 动机比坏更重要，反派要写得让人又恨又心疼 |
| 关键配角 | 四项（出身/性格/台词/关系） | 台词要有辨识度，关系张力要明确 |

### 7.3 人物小传自检问题

- [ ] 性格底色是否写成了"行为模式"而非形容词？（不能说"她很善良"，要说"她会把自己的饭分给流浪狗，但从不主动开口求人"）
- [ ] 核心缺陷是否是这个角色独有的？（不能和另一个角色撞型）
- [ ] 人物弧光是否写清了每个关键阶段？（不能只写"她改变了"，要写出具体经历了哪几个阶段、每阶段发生了什么）
- [ ] 弧光精简总结是否和详细弧光一致？（同一个角色，两种写法不能矛盾）
- [ ] 台词是否能听出声音？（读完能判断是谁说的）

### 3.3 场数与字数标准（v7.0 新增）

**每集场数上限：≤2场（不超过3场）**
- 标准结构：1场独立情绪任务 或 2场递进式情绪推进
- 超过3场 = 长剧思维，立刻压缩

**每集字数上限：≤600字（精确统计，不估算）**
- 字数 = 动作描写字数 + 台词字数（不含格式符号）
- 超出600字：压缩场景/精简台词/删OS三选一

**格式标注（在正文末尾标注，不算入正文字数）：**
```
【字数：___字 ✓】  【场数：X场 ✓】  【OS：X处 ✓】
```

### 3.4 OS豁免规则——独角戏（v7.1 新增）

**≤1处限制的例外场景：**

| 场景类型 | 典型例子 | OS规则 |
|---------|---------|-------|
| **单一演员画面，无对话对象** | 看手机/做饭/走路/发呆 | OS不受≤1处限制，但单句OS≤2句 |
| **主角内心活动本身是核心叙事内容** | 重生回忆前世/系统声音响起/闪回 | OS不受≤1处限制 |
| 多角色同场用OS代替台词 | 两人在场，一方OS代替对话 | **仍执行≤1处限制** |

**判断标准（本场能不能删OS）：**
- 去掉OS，这场戏还剩什么？（只剩动作=OS是唯一叙事工具，不应删）
- 情绪能不能用演员的表情/动作表演出来？（能=删OS；不能=保留）
- 连续OS超过3句？（是=直接打回，无论是否独角戏）


### 3.5 剧本五要素铁律（v7.2 新增）

> **剧本每一句话，只有五种出路，不存在第四种。**
> 每一句必须让制作人员看懂：这是要拍的画面，还是要录的声音，还是需要配的音。

| 类型 | 制作素材 | 格式标注 | 实例 |
|------|---------|---------|------|
| **画面** | 拍摄指示，演员表演 | `▲` 开头 | `▲ 她拿起手机，屏幕亮了。` |
| **台词** | 演员对白，现场收音 | `角色名：` | `周志勇：妈，钱打过来了吗？` |
| **OS** | 内心独白，需配音演员录制 | `（OS）角色名：` | `（OS 周梅芳）她心里一沉。` |
| **闪回** | 闪回画面，需拍摄 | `【闪回】` 开头 | `【闪回】上一世，她秒回"好，马上转"。` |
| **声音/VO** | 音效/旁白/系统音，需录制 | `（音效）` `（VO）` | `（VO）叮——系统激活。` |

**格式自检：拿到任何一句，问自己：**
- 这句是制作人员要**拍**的画面？还是**录**的声音？还是**配**的音？
- 制作人员看到这句话，知道自己要准备什么吗？

**禁止写法：**
```
❌ 上一世，她秒回"好，马上转"。
   → 制作人员不知道这是画面/台词/OS/闪回，懵了
```

**正确写法：**
```
✅ 【闪回】上一世，她秒回"好，马上转"。
   → 制作人员知道：这是闪回画面，需要拍摄
✅ （OS 周梅芳）上一世，她秒回"好，马上转"。
   → 制作人员知道：这是内心独白，需要配音
```
