## 一附录：分集大纲标准模板（通用版）

## 一、五维自检清单

每集写完后，必须逐项核查以下五个维度：

### 【时间轴】
- [ ] 每场戏的时间（晨/日/夜）是否与故事情节进展一致？
- [ ] 同一集内，时间推进是否连续？（早晨→上午→中午，不能倒退）
- [ ] 闪回/闪出是否明确标注了时间点？
- [ ] 人物年龄是否与当前集数时间线一致？

### 【空间轴】
- [ ] 每场戏的场景切换是否有明确标注？
- [ ] 位置信息（室内/室外）是否与场景内活动匹配？
- [ ] 同一场景内的人物是否都能合理出现在该场景？
- [ ] 室内场景是否有基本的场景资产描述？

### 【人物状态轴】
- [ ] 每个场景开始时，在场人物是否全部列出？
- [ ] 人物进入/离开场景是否有交代？
- [ ] 人物情绪状态是否与剧情进展匹配？
- [ ] OS是否只在真正需要表达"内心想法"时使用？

### 【逻辑轴】
- [ ] 剧情转折是否有铺垫？（不能突然180度转弯）
- [ ] 关键道具/数字是否与大纲一致？
- [ ] 结尾钩子是否足够强？
- [ ] 本集剧情是否推进了大纲中的核心事件？

### 【格式轴】
- [ ] 动作描述行是否以 `▲` 开头？
- [ ] 台词是否以 `角色名：` 格式？
- [ ] OS是否标注为 `（OS）角色名：内容`？
- [ ] VO是否标注为 `（VO）角色/系统：内容`？
- [ ] 每集结尾是否有 `「第X集完」` 标识？

## 二、【通用数值追踪系统】（任何剧本类型均可套用）

**【核心原则】剧本中的任何数值系统，都必须被追踪、被控制、被自检。**

数值系统的范围不限于"钱"，包括但不限于：功德值/好感度/复仇点数/财富值/声望值/生命值/倒计时/任务进度等。

### 2.1 通用数值系统模板

```markdown
【数值系统追踪表 · [项目名称] · v1】

【系统类型】请填写：功德值 / 好感度 / 复仇点数 / 财富值 / 声望值 / 其他___
【起点值】____  【目标值】____  【容错范围】±0（不允许任何偏差）

【第1集】触发/变化事件：________  变化量：+___/-___  当前值：___
【第2集】触发/变化事件：________  变化量：+___/-___  当前值：___
【第3集】触发/变化事件：________  变化量：+___/-___  当前值：___
...（逐集填写，集数与剧本总集数一致）
【终局】到达目标值：✓ / ✗  偏差值：___
```

### 2.2 常见剧本类型的数值系统示例

| 剧本类型 | 数值系统类型 | 示例 |
|---------|------------|------|
| 重生/救赎类 | 功德值/悔恨值 | 0→100，完成任务 |
| 甜宠/恋爱类 | 好感度/心动值 | 见面+5/吵架-10 |
| 复仇类 | 复仇进度/真相碎片 | 碎片0→100，揭露真相 |
| 逆袭/创业类 | 资产值/负债额 | 负债→清零，资产翻倍 |
| 悬疑/解谜类 | 真相进度/嫌疑人指数 | 每次推理+进度 |
| 系统流/末世类 | 生命值/血条/任务倒计时 | 死亡线收紧 |
| 豪门类 | 家族声望/继承权分 | 声望争夺 |
| 育儿/家庭类 | 亲子关系值/理解度 | 每次沟通+10 |

### 2.3 填写时机与三段卡口

```
立项阶段 ──→ 建立[数值追踪表v0.1]（空白，只填类型和已知数字）
    ↓
分集大纲阶段 ──→ 逐集规划[数值变化事件]，填入追踪表 → [v1.0]
    ↓ ③自检交叉核对
正文写作阶段 ──→ 对照追踪表，在对应场次嵌入系统VO → [v1.1]
    ↓ ④
五维自检阶段 ──→ 再次核对正文VO与追踪表是否完全一致
```

### 2.4 禁止出现的错误模式

```
✗ 只在正文里写数值变化，不在大纲里规划
✗ 大纲里规划了数值，但正文里没嵌入对应系统VO
✗ 数值凭空变化，没有对应的"触发事件"
✗ 数值变化超过了规定的上限或下限
✗ 数值没有在每集都有可追溯的记录
```

### 2.5 本次踩坑记录（沉淀为例）

```
项目：重生老妈将功赎罪
问题：功德值只在正文里出现，立项/大纲阶段均未规划
后果：分集大纲里功德值数字前后不一致，第1集写了47实际只能到30
根因：数值追踪规则里只有"钱"，功德值被当作"自由创作"处理
修复：新增通用数值追踪系统，要求任何剧本立项时同步建立
```

## 四、人物关系进展追踪系统

**【核心原则】人物关系的变化必须有因果、有过程、有时间，不能突然跳级。**

### 4.1 为什么人物关系需要独立追踪

数值系统（功德值/好感度）追踪的是"数量变化"，但人物关系的本质不是数字，是**行为模式和情感状态**。

一个关系从"敌对"到"和解"，中间隔着：
- 触发改变的事件（A做了什么 → B感受到了什么）
- 行为层面的试探（双方都在观察对方是否真诚）
- 情感层面的松动（B开始愿意给A一次机会）
- 外部危机检验（矛盾冲突是否暴露旧有问题）
- 最终的信任重建

**关系跳级的错误剧本特征：**
```
✗ 第1集两人还互相看不顺眼，第3集突然和解
✗ 重生者改变了，但周围人没有任何反应过程
✗ 儿媳/婆婆关系一夜之间变亲近
✗ 反派突然洗白，没有任何铺垫
```

### 4.2 关系进展阶段模板（适用于任何人物关系对）

对剧本中每一对重要关系，都要回答以下问题：

```
【关系对】：A ↔ B

① 初始状态（第1集前/前世）
  A对B的看法/态度：________________
  B对A的看法/态度：________________
  两人相处的日常模式：________________

② 关系变化的触发（A为什么开始改变？）
  外部触发（系统/金手指/事件）：____
  A的内在觉醒事件：____
  A开始对B采取的第一个具体行动：____

③ 关系进展阶段（逐集追踪）
  第X集：A做了____，B感受到：____
  第Y集：A做了____，B的反应：____
  第Z集：关系出现倒退/危机：____
  ...

④ 关系转折点（第几集）
  第一次软化（具体事件）：____
  重大转折（具体事件）：____
  最终和解（具体事件）：____

⑤ 终局状态
  A对B的态度：____
  B对A的态度：____
  两人相处模式：____
```

### 4.3 重生类剧本关系变化规律

重生剧的核心逻辑：**主角因系统/记忆改变 → 行为变化 → 被周围人感知 → 关系逐渐重建**

这不是"A突然变好，B突然接受"，而是：

```
主角前世对B的态度/行为 → 系统触发改变 →
主角对B采取的具体行动（变好） →
B感受到变化（需要时间，可能先怀疑） →
B的试探和观察 →
B开始松动（需要具体事件支撑） →
关系进展（需要继续正向事件巩固） →
重大危机检验（关系是否稳固） →
最终和解或分裂
```

### 4.4 常见错误与正确示范

**【错误示范1：婆媳关系跳级】**
```
✗ 第1集：婆媳互相不说话
✗ 第2集：儿媳叫了一声"妈"，关系突然变好
→ 突然，没有行为铺垫

✓ 正确：
第1集：婆婆重生，决定改变对儿媳的态度
第2集：婆婆第一次主动给儿媳夹菜（行为1），儿媳感到意外
第3集：儿媳发现婆婆说话方式变了，但仍保持距离（试探）
第4集：婆婆为儿媳出头（行为2），儿媳开始松动
第5集：儿媳第一次对婆婆说"谢谢"——关系正式破冰
```

**【错误示范2：祖孙关系跳级】**
```
✗ 第1集：小乐害怕奶奶，第3集突然黏着奶奶
→ 没有行为触发

✓ 正确：
第1集：周梅芳重生，想起上辈子从没抱过小乐
第2集：周梅芳第一次主动给小乐买糖（行为1），小乐感到奇怪
第3集：小乐观察奶奶好几天，发现奶奶变了（试探确认）
第4集：周梅芳带小乐去买书包（行为2），小乐开始主动靠近
第5集：小乐第一次主动拉着奶奶的手——祖孙关系破冰
```

**【错误示范3：反派洗白没有铺垫】**
```
✗ 第10集：张磊突然说"我其实不是坏人"
→ 突然，前面没有行为铺垫

✓ 正确：
第4集：张磊第一次出场，表面友善，实际在套信息（行为1）
第6集：张磊给周志勇小恩小惠（行为2），志勇开始信任
第8集：周梅芳发现张磊赌博记录（揭露面纱1）
第10集：张磊被揭穿，真面目暴露（揭露面纱2）
→ 观众看到了完整的"好人→露出真面目"过程，不突兀
```

### 4.5 人物关系自检问题清单

对剧本中每一对重要关系，逐项核查：

- [ ] **初始状态**：两人在第1集前/前世是什么关系？是否有明确交代？
- [ ] **触发因果**：A对B态度变化的触发事件是什么？（系统提醒/具体行为/外部事件）
- [ ] **行为链**：A对B做了什么具体行动？（必须是有画面感的动作，不是"变好了"）
- [ ] **B的感知**：B感受到了A的变化吗？感受到之后B做了什么？（必须体现B的主动性）
- [ ] **时间感**：从A改变到B回应，是否给了足够的集数铺垫？（至少2-3集）
- [ ] **关系倒退**：关系遇到危机时，是否暴露了旧有问题？（检验关系是否真实重建）
- [ ] **因果闭环**：关系最终和解或破裂的原因，是否与前面铺垫的事件一一对应？

### 4.6 本剧关系进展追踪示例

以《重生老妈将功赎罪》为例：

```
【周梅芳 ↔ 周小乐】
初始状态：祖孙不亲近，上辈子周梅芳只给钱不陪伴，小乐对她有距离感
触发：A因系统提醒，第一次主动对小乐好（买糖/买书包）
第2集：A主动买糖，小乐感到奇怪
第3-4集：小乐观察，A持续改变，小乐开始试探
第5集：A为小乐撑腰（学校事件），小乐主动拉手
终局：A是小乐最信任的人，小乐说"奶奶我喜欢这样的日子"

【周梅芳 ↔ 李晓丽】
初始状态：婆媳有隔阂，晓丽防备心强，嘴上凶但内心渴望被接纳
触发：A在仓库外看见B哭，没有走开（看见了脆弱）
第4-5集：A开始用行动表达关心，B感受但保持距离
```

### 9.2 钩子类型判断标准（通用技法）

**悬念钩（弱）—— 等答案**
- 句式："接下来会发生什么？""她会不会……？"
- 观众心理：等编剧给答案
- 信息差：主角知道，观众不知道
- 效果：会继续看，但不会主动讨论

**选择钩（强）—— 争对错**（优先使用）
- 句式："她这样做对吗？""如果是你，你选哪个？"
- 观众心理：和周围人争论，和自己争
- 信息差：观众知道主角不知道的信息
- 效果：会发弹幕/主动讨论

**选择钩实战技巧：**
- 结尾设计一个道德困境，让观众有立场
- 给出两个都能成立的选择
- 钩子不问"怎么办"，而问"你觉得她应不应该"

**选择钩实例（可直接复用）：**
```
✅ "周梅芳把诊断报告锁进抽屉，像什么都没发生过一样，给全家人做了晚饭。"
   → 观众争：她该瞒着还是说出来？

✅ "周志勇跪在她面前：妈，都是我的错。"
   → 观众争：该原谅第一次还是不原谅？
```

### 9.7 钩子评判标准体系（v2.0 重写）

#### 五种核心钩子类型

| 类型 | 行业叫法 | 效果 | 最强题材 |
|------|---------|------|---------|
| **情绪钩**⭐⭐⭐⭐⭐ | "这不就是说的我吗" | 共鸣即转发，出圈核心 | 家庭/代际/情感 |
| **反转钩**⭐⭐⭐⭐ | "怎么居然是这样？" | 意外感强，驱动验证 | 所有题材 |
| **信息钩**⭐⭐⭐⭐ | "原来是这样！怪不得……" | 重建认知，驱动重看 | 悬疑/身份揭露 |
| **危机钩**⭐⭐⭐ | "这下要出大事了" | 紧迫感强，驱动快看 | 生死/灾难场景 |
| **悬念钩**⭐⭐ | "接下来会发生什么？" | 问信息不问立场，弱 | 尽量少用 |

#### 自检四问（v2.0 升级版）

| # | 问题 | 通过标准 |
|---|------|---------|
| Q1 | 问的是"对错/好坏/应该站哪边"还是"发生什么"？ | 问立场=强 ✓ |
| Q2 | 观众看完会不会"太真实了/说得太对了"？ | 有情绪共振=强 ✓ |
| Q3 | 观众知道的信息，比角色多吗？ | 多了=信息差=强 ✓ |
| Q4 | 结尾在观众预期之外吗？ | 有意外感=反转钩 ✓ |

**四问全过 = 极强（5分）｜三问过 = 强（4分）合格｜二问过 = 中（3分）需加强｜≤2问过 = 弱（≤2分）打回**

#### 爆款三层叠加公式

> **情绪钩 + 反转钩 + 选择钩 = 最强结尾**
> 单用一种效果有限，两种以上叠加才是行业实战标准。
