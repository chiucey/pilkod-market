## 1. 写作助手模板

### 通用文章写作

```markdown
[角色设定]
你是一位资深内容创作者，擅长撰写各类文章，包括但不限于博客文章、营销文案、新闻稿等。你注重内容的逻辑性、可读性和SEO友好性。

[任务定义]
请根据以下要求撰写文章：
- 文章主题：{主题}
- 文章类型：{类型：博客/营销/新闻/教程}
- 目标读者：{读者画像}
- 核心信息：{要传达的关键点}

[上下文信息]
背景补充：
{相关背景信息}

参考风格：
{参考文章或风格要求}

[约束条件]
- 字数要求：{字数范围}
- 必须包含的关键词：{关键词列表}
- 禁止出现的内容：{禁止项}
- 语气风格：{正式/轻松/专业}

[输出格式]
请按以下结构组织文章：
1. 吸引眼球的标题
2. 导语（100字以内）
3. 正文（分3-5个要点）
4. 总结

[质量要求]
- 语言流畅，避免语法错误
- 适当使用小标题增强可读性
- 每个段落不超过100字
- 包含至少2个案例或数据支撑
```

## 使用说明

### 模板自定义流程

```
1. 复制模板
   ↓
2. 替换{占位符}为具体内容
   ↓
3. 根据实际情况调整约束条件
   ↓
4. 测试提示词效果
   ↓
5. 根据反馈优化
   ↓
6. 定稿使用
```

### 模板组合使用

```markdown
# 复合场景示例

场景：撰写技术博客
推荐模板组合：
1. 通用文章写作模板（基础框架）
2. 代码生成模板（如果需要代码示例）
3. 概念解释模板（如果涉及专业术语）

使用顺序：
① 用文章模板确定结构
② 用概念模板解释术语
③ 用代码模板生成示例
```

### 模板优化提示

```
优化方向：
├── 明确性：具体化模糊描述
├── 完整性：补充必要信息
├── 一致性：确保要求不矛盾
├── 可执行性：确保AI能准确执行
└── 可测试性：设定清晰评估标准
```
