# 技能行为评估指南

## 评估维度

### 1. 触发准确性

**评估标准**：
- [ ] 技能被正确识别和激活
- [ ] 非绘画相关请求未被错误触发

**测试用例**：
```
✓ "教我画一只小猫"
✓ "我想学简笔画"
✓ "教我画Q版人物"
✓ "怎么把东西画可爱"
✗ "我想学油画"（应拒绝）
✗ "帮我写代码"（应拒绝）
```

---

### 2. 教学结构完整性

**评估标准**：
- [ ] 每个教程都包含标准5步法
- [ ] 步骤清晰、可执行
- [ ] 每步都有鼓励性小贴士

**检查清单**：
- [ ] 第1步：几何形起稿
- [ ] 第2步：定位比例
- [ ] 第3步：添加细节
- [ ] 第4步：描线简化
- [ ] 第5步：上色建议

---

### 3. 语言风格一致性

**评估标准**：
- [ ] 使用通俗易懂的语言
- [ ] 语气活泼、亲切
- [ ] 包含鼓励性话语
- [ ] 无过度专业术语

**正向指标**：
- 使用"圆滚滚"、"胖乎乎"等形象词
- 包含"没关系"、"你可以的"等鼓励语
- 使用"可爱就是关键"等核心理念

**负向指标**：
- 过多专业绘画术语
- 语气生硬、过于正式
- 缺少鼓励性话语

---

### 4. 个性化定制能力

**评估标准**：
- [ ] 能根据主题定制教程
- [ ] 能调整难度等级
- [ ] 能调整详细程度

**测试场景**：
```
场景1："教我画Q版动漫男生"（主题定制）
场景2："来点简单的简笔画"（难度调整）
场景3："给我个超详细的教程"（详细程度）
```

---

### 5. 作品点评质量

**评估标准**：
- [ ] 能识别作品亮点
- [ ] 提供具体改进建议
- [ ] 保持正向鼓励基调

**点评结构**：
```
✅ 做得很棒的地方：（具体肯定）
💡 可以改进的地方：（具体建议）
🎯 下次可以试试：（可执行建议）
```

---

### 6. 万能技巧输出质量

**评估标准**：
- [ ] 公式易于理解和记忆
- [ ] 技巧具有普适性
- [ ] 配有过渡到实际练习

**预期输出**：
- 简化的记忆口诀
- 具体可操作的练习方法
- 鼓励用户尝试的引导

---

## 评分标准

### 优秀（90-100分）
- 所有维度都达到或超出标准
- 语言风格特别活泼亲切
- 教程案例丰富多样
- 鼓励性话语贯穿始终

### 良好（75-89分）
- 大部分维度达标
- 语言风格基本符合要求
- 教程结构完整清晰

### 合格（60-74分）
- 核心功能正常运行
- 主要维度基本达标
- 有少量需要改进的地方

### 不合格（<60分）
- 触发识别有严重问题
- 教程结构缺失严重
- 语言风格偏离要求
- 缺少鼓励性内容

## 迭代改进指南

### 常见问题及修复

| 问题 | 可能原因 | 修复方向 |
|------|----------|----------|
| 触发过度 | 关键词过于宽泛 | 收紧触发条件 |
| 触发不足 | 关键词不够全面 | 扩展触发短语 |
| 语言生硬 | 未遵循风格要求 | 添加更多口语化表达 |
| 步骤冗长 | 信息过载 | 精简每步内容 |
| 缺少鼓励 | 未嵌入鼓励语 | 在各环节添加 |
