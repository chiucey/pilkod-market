# 简笔画万能公式库

## 🔮 核心公式

### 万能变形公式
```
任何事物 = 基础几何形 + 卡通化特征
```

### 表情公式
```
表情 = 眼睛状态 + 嘴巴形状 + 辅助元素（腮红/汗滴/爱心等）
```

## 👤 人物篇

### Q版人物万能公式
```
头 = 大圆（占身体1/2~2/3）
身 = 小椭圆/梯形
四肢 = 短粗线条
眼睛 = 大圆+小圆高光
```

### 头部比例口诀
```
"三庭五眼"简化版：
- 眼睛在头部中间
- 眼睛间距约等于一只眼
- 下巴占三分之一
```

### 身体简化规律
| 部位 | 成人 | Q版 | 像素风 |
|------|------|-----|--------|
| 头身比 | 1:7~1:8 | 1:2~1:3 | 1:1 |
| 手 | 5指 | 3指/圆球 | 方块 |
| 腿 | 细长 | 短粗 | 直线 |

## 🐱 动物篇

### 圆球法则
```
所有可爱动物 = 圆脑袋 + 圆身体 + 小耳朵 + 圆眼睛
```

### 动物变可爱公式
```
真实动物 → 可爱动物
1. 圆化：尖角变圆角
2. 大眼：眼睛放大2-3倍
3. 简化：细节减少50%
4. 软化：线条变得圆润
```

### 常见动物简化

#### 猫
```
基础形：两个三角（耳朵）+ 圆头 + 圆身
特征：胡须、尾巴、粉色鼻子
```

#### 狗
```
基础形：圆头 + 垂耳朵 + 圆身
特征：舌头、摇尾巴
```

#### 兔子
```
基础形：长耳朵 + 圆头 + 胖身
特征：三瓣嘴、短尾巴
```

## 🍔 食物篇

### 食物可爱化公式
```
食物可爱化 = 放大特征 + 添加表情 + 圆润边角
```

### 常见食物简化

#### 汉堡
```
层叠结构：面包顶 + 生菜 + 肉饼 + 面包底
可爱化：画上眼睛和微笑
```

#### 蛋糕
```
基础形：圆柱 + 半球装饰
可爱化：加上草莓、蜡烛、笑脸
```

#### 饮料
```
基础形：圆柱杯 + 圆形吸管
可爱化：加上腮红、蒸汽/气泡表情
```

## 😊 表情篇

### 表情四要素
```
1. 眉毛（眉头、眉尾的走向）
2. 眼睛（形状、大小、眼神）
3. 嘴巴（弧度、形状）
4. 辅助（腮红、汗水等）
```

### 基础表情对照

| 表情 | 眉毛 | 眼睛 | 嘴巴 | 辅助 |
|------|------|------|------|------|
| 开心 | ↑↑ | 弯弯月牙 | 大U形 | 脸红 |
| 难过 | ↓↓ | 水汪汪 | 向下弧 | 眼泪 |
| 生气 | ┴┴ | 变小 | 向下W | 火焰 |
| 惊讶 | ○○ | 变大 | O形 | 汗滴 |
| 害羞 | / / | 闭眼 | 小波浪 | 脸红 |
| 得意 | ^^ | 半闭 | 歪嘴笑 | - |

## ✏️ 线条练习

### 线条进阶路线
```
1. 直线 → 波浪线 → 螺旋线
2. 小圆 → 大圆 → 连环圆
3. 点 → 短线 → 长线
```

## 🎨 上色技巧

### 配色原则
- **同色系**：和谐统一
- **互补色**：活泼对比（蓝+橙、紫+黄）
- **三色原则**：不超过3个主色

### 上色顺序
```
1. 先浅后深
2. 先大面积后小细节
3. 留出高光位置
4. 边缘可以稍微出界（显得更自然）
```

### 简易渐变
```
用同色系深浅两支笔
浅色打底 + 深色在边缘轻扫 = 自然渐变
```
