# 会议纪要 Skill

## 功能概述

支持三种输入形式，自动整理成结构化会议纪要：
- 🎙 **音频**：AMR/MP3/WAV 录音 → 语音识别 → 文字转纪要
- 🖼 **图片**：PPT截图、文档照片、白板照片 → 图片识别 → 提取内容
- 📝 **文本**：用户口述或粘贴的原始文字 → 整理成纪要格式

## 输入方式

### 1. 音频文件（语音识别）

使用 `audios_understand` 工具，prompt 固定为：
```
"请将这段会议录音转成文字，完整转写，不遗漏任何内容，保留说话人区分（如有）。"
```

上传音频后等待识别结果，再整理成纪要。

### 2. 图片文件（图片识别）

使用 `images_understand` 工具，prompt 固定为：
```
"请详细描述这张图片的全部内容，包括所有文字、图表、数据等。如果是截图或文档，请完整提取所有文字内容。"
```

支持：PPT截图、Word截图、白板照片、纸质文档照片、白板/草图等。

### 3. 纯文本

用户直接发送或粘贴原始文字、口述要点，无需额外工具，直接整理。

## 会议纪要标准格式

整理时统一使用以下格式（Markdown）：

```markdown
## 项目沟通纪要

**日期：** YYYY-MM-DD
**议题：** [会议主题]

---

### 会议背景
[简述会议背景和目的，1-3句话]

### 主要讨论内容
[按讨论顺序，分点列出。每点用编号如 "1. " "2. "]

### 形成共识
[已达成一致的结论，用 ✓ 或 ✅ 标注]

### 遗留问题
[未解决的问题或待跟进事项，用 ❌ 标注]

### 下一步安排
[后续行动、负责人、时间节点，用 → 标注]

---

**记录人：** AI 助手
**更新时间：** YYYY-MM-DD HH:mm UTC
```

## 输出方式

根据用户要求，生成以下格式之一：

| 格式 | 触发关键词 | 说明 |
|------|-----------|------|
| Markdown 文本 | 默认 | 直接在对话中返回 |
| DOCX 文档 | "导出Word" / "生成Word" / ".docx" | 使用 minimax-docx skill |
| 飞书文档 | "同步到飞书" / "写入飞书" | 使用 feishu-doc skill |
| 企业微信文档 | "同步到企微" / "写入企微文档" | 使用 wecom-doc-manager skill |

## 多媒体处理技巧

### 连续多张图片
用户发送多张会议截图时，逐张识别后再合并整理，不要混淆不同页面的内容。

### 混合输入（音频+图片）
处理顺序：音频 → 图片 → 用户口述补充。先完成语音转文字，再结合图片补充细节。

### 敏感信息处理
- 会议中涉及隐私、保密内容时，在纪要中用 **[敏感]** 标注
- 人名、身份证号、手机号等脱敏处理
