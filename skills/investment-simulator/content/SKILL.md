# 「沙盘推演」— 投资决策模拟器

## 简介

在你买入之前，先在沙盘上推演一遍。输入你想投资的标的，AI 模拟三种市场情景（牛市/震荡/熊市），计算盈亏比，给出"该不该动手"的决策建议。区别于事后分析——这是**事前决策辅助**。

## 核心能力

- **情景模拟**：牛市、震荡市、熊市三种情景下的盈亏预测
- **盈亏比计算**：计算买入后涨/跌不同幅度的实际盈亏金额
- **风险评估**：基于波动率、历史数据、仓位管理给出风险等级
- **决策建议**：综合给出"强烈建议/建议/谨慎/不建议"四个等级
- **策略推荐**：根据用户风险偏好推荐持仓比例、止损/止盈点位
- **历史回测**：基于该标的的历史数据模拟类似情景

## 三种情景模板

| 情景 | 定义 | 模拟条件 |
|------|------|---------|
| 乐观（牛市） | 市场情绪高涨，趋势向上 | 上涨 10-30% 的概率和路径 |
| 中性（震荡） | 横盘整理，无明显趋势 | 震荡 ±5-15% 的波动范围 |
| 悲观（熊市） | 市场下跌，趋势向下 | 下跌 10-30% 的极端情况 |

## 使用方法

### 基础用法

```
我想买入 [股票代码/基金名称]，
计划投入 [金额]，持有期 [短期/中期/长期]。
请帮我做沙盘推演。
```

### 进阶用法

```
我是保守型投资者，目前持仓了 [现有仓位]。
现在想加仓 [标的]，请从风险角度分析是否应该加仓，
以及加仓多少比例比较合理。
```

### 完整工作流

```
第一步：输入投资标的（股票/基金/加密货币）
第二步：输入买入计划（金额、价格、持仓周期）
第三步：输入风险偏好（保守/稳健/激进）
第四步：AI 抓取最新行情和历史数据
第五步：三情景模拟（牛市/震荡/熊市）
第六步：计算各情景下盈亏
第七步：综合给出决策建议和策略
第八步：生成带图表的投资分析报告
```

## 注意事项

- 本工具仅供决策参考，不构成投资建议
- 历史表现不代表未来收益
- 市场有风险，投资需谨慎
- 模拟结果基于历史数据和概率模型，实际市场可能走出极端行情
- 建议配合基本面分析一起使用
- 短线交易风险极高，请量力而行
