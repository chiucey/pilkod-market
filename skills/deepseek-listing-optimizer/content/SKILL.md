# deepseek刊登文案优化技能

## 技能概述

本技能用于根据业务提供的刊登文件(XLSX)，调用deepseek对文案内容进行优化。以专业跨境电商运营角度，结合产品数据给出优化后的标题、五点、搜索关键词。

## 触发条件

当用户输入包含以下关键词时触发：
- 生成文案
- 文案优化
- deepseek优化
- 智能文案

## 执行流程

### 步骤1：解析文件

从用户上传的XLSX文件中提取以下字段：
- 平台
- 站点
- 标题
- 关键词
- 描述
- 五点

**数据校验规则**：
- 如果任何必填字段（平台、站点、标题）缺失或为空，立即询问用户补充
- 允许描述、五点为空，但需在优化时说明

### 步骤2：确认优化范围

向用户确认需要优化的内容范围：
- 标题优化
- 关键词优化
- 描述优化
- 五点优化

用户可选择单独优化某一项或全部优化。

### 步骤3：调用deepseek API优化

使用deepseek API进行文案优化，传递以下上下文信息：
```
你是一位专业的[平台名称]-[站点名称]跨境电商运营专家。
请根据以下产品信息，优化listing文案以提升流量和转化。

产品标题：[原标题]
产品五点：[五点内容]
产品关键词：[关键词内容]
产品描述：[描述内容]

请严格按照以下规则优化：
```

### 步骤4：优化标准

#### 4.1 标题优化规则
- 至少包含2个核心关键词
- 将其中一个核心关键词前置后加逗号
- 同样名词和词组不出现2次以上
- 总字符控制在150左右
- **如果原标题带括号内容，括号位置不变**

#### 4.2 五点优化规则
- 语句通顺，符合美国人语言习惯
- 避免重复介词
- 不要夸大产品性能，避免高退款率
- 不要包含售后相关信息
- 不要包含价格相关描述
- 需要埋入主关键词
- 每一点要有小标题概括
- 小标题和内容之间用冒号隔开
- 每一点写在同一行，方便复制粘贴

#### 4.3 关键词优化规则
- 重复单词需要去重
- 去重后控制在200-220个字符数
- 仅计算字母字符
- 空格和换行符不计入
- 关键词用空格隔开

#### 4.4 通用规则
- 剔除侵权词
- 不要添加描述中不存在的认证信息、参数信息
- 如需换单位，数字需进行相应换算
- 使用对应站点的语言（如英语站点用英文）

### 步骤5：返回结果

优化完成后：
1. 使用对应站点的语言返回结果
2. 在原XLSX文件基础上添加对比展示列
3. 提供原内容与优化内容的对照

## 输出格式

### 优化结果展示

```
## 优化完成

### [站点名称]站点优化结果

#### 标题优化
| 原标题 | 优化后标题 |
|--------|------------|
| ... | ... |

#### 五点优化
| 原五点 | 优化后五点 |
|--------|------------|
| ... | ... |

#### 关键词优化
| 原关键词 | 优化后关键词 |
|----------|--------------|
| ... | ... |
```

## 错误处理

- **文件解析失败**：提示用户检查文件格式，确保为标准XLSX格式
- **必填字段缺失**：列出缺失字段，请用户补充
- **API调用失败**：提供重试选项，或提示用户稍后重试
- **网络问题**：提示用户检查网络连接

## 示例对话

**用户**：帮我优化这个刊登文件，使用deepseek优化标题和五点

**助手**：
1. 请上传您的XLSX刊登文件
2. 确认优化范围：标题、五点、关键词、描述（可多选）
3. 调用deepseek进行优化
4. 返回优化结果并提供对比展示

## 技术要求

- 支持.xlsx格式文件
- 依赖openpyxl库进行文件解析
- 调用deepseek API进行文案生成/优化
- 优化结果保存为新的对比展示文件
