# 游戏小说属性设计指南

## 一、属性体系设计原则

### 1.1 核心设计理念

| 原则 | 说明 | 示例 |
|-----|------|------|
| **可量化性** | 属性必须能用数值精确表达 | 攻击力=150，暴击率=25% |
| **可比性** | 读者能直观对比角色强弱 | 张三攻击200 vs 李四攻击150 |
| **可成长性** | 属性随修炼/剧情发展变化 | 筑基期攻击×1.5 |
| **策略性** | 不同属性组合产生不同流派 | 堆暴击流 vs 稳定输出流 |

### 1.2 属性数量控制

```
简单体系（新手推荐）：6-8个属性
├─ 生命值、法力值、体力值
├─ 攻击力、防御力、速度
└─ 可选：暴击率、闪避率

中等体系（玄幻标配）：12-15个属性
├─ 基础：生命、法力、体力、攻击、防御、速度
├─ 战斗：暴击率、暴击伤害、命中、闪避
├─ 元素：火抗、水抗、雷抗、风抗、土抗
└─ 特殊：幸运、悟性、感知、魅力

复杂体系（高阶玩法）：20+属性
├─ 基础属性 + 元素抗性 + 元素攻击
├─ 抗性细分：异常状态抗性（眩晕、流血、中毒等）
├─ 特殊能力：吸血、反弹、穿透
└─ 隐藏属性：气运、因果、业力
```

## 二、属性分类详解

### 2.1 资源类属性

| 属性 | 定义 | 典型数值范围 | 恢复方式 |
|-----|------|-------------|---------|
| **生命值(Life/HP)** | 角色存活根本，降至0则重伤/死亡 | 1000-100000 | 自动恢复、丹药、休息 |
| **法力值(Mana/MP)** | 使用技能/功法的消耗 | 500-50000 | 打坐、灵石、天材地宝 |
| **体力值(Stamina)** | 体力劳动/近战消耗 | 800-30000 | 进食、休息、灵果 |

### 2.2 战斗类属性

| 属性 | 定义 | 计算公式 | 优化建议 |
|-----|------|---------|---------|
| **攻击力(ATK)** | 造成伤害的基础值 | 功法+武器+境界加成 | 主角核心属性，增长快 |
| **防御力(DEF)** | 减免受到的伤害 | 护甲+功法+体质 | 反派略高于主角 |
| **暴击率(CRIT%)** | 触发暴击的概率 | 0%-100% | 封顶80%，过高失去意义 |
| **暴击伤害(CRIT DMG)** | 暴击时的伤害倍率 | 150%-400% | 通常为攻击力的1.5-3倍 |
| **命中/精准** | 攻击命中的概率 | 影响闪避属性 | 主角命中率略高 |
| **闪避/敏捷** | 躲避攻击的概率 | 对应命中属性 | 刺客/剑客类角色 |

### 2.3 速度类属性

| 属性 | 用途 | 设计要点 |
|-----|------|---------|
| **速度(SPD)** | 战斗行动顺序 | 高速角色先手优势明显 |
| **先手值** | 决定出手顺序 | 速度×(1+先手技能加成) |
| **行动次数** | 每回合可行动次数 | 高阶战斗可设计多动 |

### 2.4 元素类属性

#### 攻击属性
| 元素 | 特性 | 克制关系 |
|-----|------|---------|
| 火 | 高伤害、持续灼烧 | 克木、被水克 |
| 水 | 均衡、控制能力强 | 克火、被土克 |
| 雷 | 高爆发、麻痹效果 | 无明显克制 |
| 风 | 高速、闪避加成 | 被土克 |
| 土 | 高防御、控制 | 克水、被木克 |
| 冰 | 减速、冻结控制 | 被火克 |
| 暗 | 腐蚀、中毒 | 被光克 |
| 光 | 净化、治疗 | 克暗 |
| 毒 | 持续伤害、削弱 | 无明显克制 |

#### 抗性属性
```
抗性公式：实际伤害 = 基础伤害 × (1 - 抗性值)
├─ 0% 抗性：伤害不变
├─ 50% 抗性：伤害减半
└─ 100% 抗性：免疫该元素伤害
```

### 2.5 特殊属性

| 属性 | 对应能力 | 小说应用 |
|-----|---------|---------|
| **幸运值(Luck)** | 掉落稀有物品、触发奇遇 | 主角金手指之一 |
| **悟性(Comprehension)** | 功法领悟速度 | 影响修炼效率 |
| **感知力(Perception)** | 发现隐藏事物 | 探查秘境、发现伏笔 |
| **魅力(Charisma)** | NPC好感度、招募同伴 | 势力扩张 |
| **气运(Aura)** | 隐藏属性，影响剧情走向 | 主角光环 |
| **根骨(Bone)** | 修炼资质上限 | 决定成长天花板 |

## 三、属性派生公式

### 3.1 常见派生规则

```python
# 生命上限 = 基础生命 × 体质系数
max_hp = base_hp * constitution * realm_multiplier

# 法力上限 = 基础法力 × 精神系数
max_mp = base_mp * spirit * realm_multiplier

# 攻击伤害 = (攻击 - 防御/2) × 技能倍率
damage = (atk - def/2) * skill_multiplier

# 暴击伤害 = 基础伤害 × (1 + 暴击率 × (暴击倍率-1))
crit_damage = base_dmg * (1 + crit_rate * (crit_multiplier - 1))
```

### 3.2 境界压制公式

```python
# 境界压制伤害加成
if attacker_realm > defender_realm:
    damage *= 1 + (realm_gap * 0.2)  # 每高一个境界+20%伤害

# 境界压制减伤
if defender_realm > attacker_realm:
    damage *= 1 - (realm_gap * 0.1)  # 每高一个境界-10%伤害
```

## 四、属性平衡设计

### 4.1 属性克制表

```
攻击属性克制（造成额外伤害）：
火 > 木 > 土 > 水 > 火（循环）
雷 > 暗 > 光 > 雷（独立循环）
风 > 风（无克制）

防御抗性（减免伤害）：
高防御角色：防御力 = 攻击方攻击力的40-60%
均衡角色：防御力 = 攻击方攻击力的20-30%
脆皮角色：防御力 = 攻击方攻击力的10-15%
```

### 4.2 角色定位模板

#### 主角模板（后期全能型）
```json
{
  "growth_rate": 1.3,
  "stat_priority": ["attack", "life", "speed"],
  "breakthrough_ease": 1.2,
  "initial_stats_multiplier": 1.0
}
```

#### 战士模板（坦克型）
```json

  "breakthrough_ease": 1.0,
  "initial_stats_multiplier": {"defense": 1.5, "life": 1.3}

```

#### 刺客模板（爆发型）


## 五、属性设计检查清单

- [ ] 属性定义清晰，无歧义
- [ ] 属性数值范围合理，不会溢出
- [ ] 属性之间有派生关系，形成体系
- [ ] 不同角色有差异化属性分布
- [ ] 境界/等级对属性有明确加成
- [ ] 存在多种属性成长路线
- [ ] 属性克制/平衡机制完善
- [ ] 数值变更规则明确可执行
