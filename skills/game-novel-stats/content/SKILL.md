# 游戏小说数值设定系统

## 核心功能！！

### 1. 属性体系设计

#### 推荐的核心属性（可自定义）

| 属性类型 | 推荐属性 | 说明 |
|---------|---------|------|
| **基础属性** | 生命值(Life)、法力值(Mana)、体力值(Stamina) | 角色资源类数值 |
| **战斗属性** | 攻击力(ATK)、防御力(DEF)、暴击率、暴击伤害 | 直接影响战斗结果 |
| **速度属性** | 速度(SPD)、行动顺序、闪避率 | 战斗节奏把控 |
| **抗性属性** | 火焰抗性、冰霜抗性、雷电抗性、毒素抗性 | 元素体系适配 |
| **特殊属性** | 幸运值、魅力值、感知力、悟性 | 非战斗维度成长 |
| **境界/等级** | 炼气期、筑基期、金丹期... / LV.1-100 | 成长里程碑 |

#### 属性层级结构

```
境界 (Realm)
├── 等级 (Level)
│   ├── 经验值 (EXP)
│   └── 经验阈值
├── 基础属性 (基础值 × 境界加成)
└── 进阶属性 (派生计算)
```

### 2. 增长节点设计指南

#### 增长曲线模式

| 阶段 | 增长特点 | 数值变化 | 适用场景 |
|-----|---------|---------|---------|
| **前期(1-20%)** | 缓慢增长 | +5%~+15%/章节 | 新手期，建立数值感知 |
| **中期(20-70%)** | 稳定增长 | +15%~+30%/章节 | 成长期，积累实力 |
| **后期(70-90%)** | 加速增长 | +30%~+50%/章节 | 突破期，实力飞升 |
| **大结局(90-100%)** | 指数增长/暴涨 | +50%~+100%/章节 | 最终决战 |

#### 增长事件类型

| 事件类型 | 增长幅度 | 增长类型 | 示例 |
|---------|---------|---------|------|
| 日常修炼 | +5~+10 | 正向线性 | 打坐、练功 |
| 小型奇遇 | +15~+30 | 正向跳跃 | 发现灵草、偶得秘籍 |
| 中型突破 | +50~+100 | 正向暴涨 | 境界突破、觉醒血脉 |
| 重伤/心魔 | -10~-30 | 负向 | 被击败、走火入魔 |
| 永久损失 | -50~-100 | 负向暴跌 | 断臂、封印修为 |

#### 关键节点设计原则

1. **前置条件明确**: 境界突破需要满足特定条件
2. **风险与收益并存**: 高收益往往伴随高风险事件
3. **节奏张弛有度**: 暴涨后适当缓冲期
4. **伏笔埋设**: 早期数值异常暗示后期机遇

### 3. 数值计算与追踪

#### 核心计算公式

```python
# 境界加成公式
effective_value = base_value × realm_multiplier

# 暴击伤害计算
final_damage = base_damage × (1 + crit_rate × (crit_multiplier - 1))

# 经验阈值公式（可套用）
exp_threshold = base_exp × (1.5 ^ current_level)
```

#### 数值变更处理规则

| 变更类型 | 处理方式 | 示例 |
|---------|---------|------|
| **绝对值变更** | 直接加减 | 生命+100、攻击力-20 |
| **百分比变更** | 基于当前值计算 | 生命+20%、防御-15% |
| **倍数变更** | 乘以系数 | 攻击×2(临时)、力量×1.5(永久) |
| **状态标记** | 添加时间/条件限制 | 中毒(每回合-10HP，持续3回合) |

## 使用流程

### 流程1: 新角色创建

1. 确定角色定位（主角/配角/反派/NPC）
2. 选择属性体系模板
3. 设定初始数值（考虑成长起点）
4. 记录至角色数据库

### 流程2: 数值变更记录

1. 读取当前数值
2. 输入变更事件描述
3. 计算变更后数值
4. 更新历史记录
5. 检查触发条件（突破/debuff等）

### 流程3: 增长曲线规划

1. 确定小说总长度/预计章节数
2. 划分阶段（前期/中期/后期/结局）
3. 设定关键节点（突破点/危机点）
4. 计算各阶段增长率
