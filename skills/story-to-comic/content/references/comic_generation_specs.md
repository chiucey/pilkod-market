# 条漫生成规范

> 本规范用于【环节：系列条漫图文生成】，指导如何从《漫画生图提示词.md》提取内容并调用图生图工具（image_to_images）。

---

## 1. 单图多格强制规则（最高优先级）

### ⛔ 核心原则

**一个Prompt = 一张完整漫画图（含多个分镜格子）**

所有分镜格子必须在同一张图中呈现，禁止将不同分镜生成多张独立图片。

---

### ❌ 错误做法（严重违规）

**问题**：分镜脚本有4格，却生成了4张独立的图

```
错误调用：
第1次调用 → 生成图1（仅包含格子1）
第2次调用 → 生成图2（仅包含格子2）
第3次调用 → 生成图3（仅包含格子3）
第4次调用 → 生成图4（仅包含格子4）

结果：4格内容 = 4张图 ❌
```

**严重后果**：
- 🔴 **资源浪费**：本应1张图完成，却消耗4倍生图资源
- 🔴 **体验差**：读者需翻页4次才能看完一个完整情节
- 🔴 **叙事断裂**：破坏漫画的视觉连贯性

---

### ✅ 正确做法

**要求**：分镜脚本有4格，生成1张包含4格的完整漫画图

```
正确调用：
第1次调用 → 生成图1（包含格子1、2、3、4，按布局蓝图排列在同一画面中）

结果：4格内容 = 1张图 ✅
```

---

### 📋 生图前自检清单（强制执行）

**在每次调用生图工具前，必须逐项确认：**

| 序号 | 检查项 | 通过标准 |
|------|--------|----------|
| 1 | Prompt格式 | 必须为 `生成1张漫画图，X格分镜...` |
| 2 | 生图数量参数 | 必须为 `1`（禁止设置为分镜格数） |
| 3 | 布局蓝图 | 必须描述多个格子的位置排列 |
| 4 | 分镜内容 | 必须包含多个格子的描述（非单个） |

**若任何一项不符合，禁止调用生图工具，需返回提示词工程环节修正。**

---

## 2. 提示词强制使用规则（最高优先级）

### ⛔ 核心原则

**必须原样使用《漫画生图提示词.md》中的完整Prompt，禁止任何形式的修改、简化、删减。**

---

### ❌ 禁止行为（严重违规）

| 禁止行为 | 错误示例 | 后果 |
|---------|---------|------|
| 简化提示词 | 删除【布局蓝图】或【分镜内容】部分 | 画面结构丢失 |
| 删减分镜描述 | 将4格描述合并为2格 | 叙事不完整 |
| 修改角色定义 | 更改 `@角色名 = 参考图X` | 角色锁定错误 |
| 省略风格约束 | 只保留核心指令 | 风格不一致 |
| 自行重写提示词 | 用自己的话重新描述 | 丢失专业配置 |
| 仅使用部分提示词 | 只取分镜内容，丢弃其他模块 | 画面质量下降 |

---

### ✅ 正确做法

**必须完整提取并原样传入以下全部内容：**

```
【核心指令】生成1张漫画图，X格分镜，竖排布局，各个分镜在同一张图

【风格约束】
画风: xxx | 线条: xxx | 饱和度: xxx | 色调: xxx
字体: xxx | 字色: xxx | 图片比例: 3:4竖版 | 背景: 白底 | 分格线: 清晰

【角色定义】
@角色名1 = 参考图1
@角色名2 = 参考图2

【布局蓝图】
阅读顺序: Z字形
边距控制: xxx
格子 1 (位置)：xxx
格子 2 (位置)：xxx
...

【分镜内容】
格子 1 (位置)：xxx | xxx | xxx | 文字框(位置): "内容"
格子 2 (位置)：xxx | xxx | xxx | 文字框(位置): "内容"
...
```

**全部5个模块必须完整传入，缺一不可。**

---

### 📋 提示词提取自检清单（强制执行）

**在每次调用生图工具前，必须逐项确认：**

| 序号 | 检查项 | 通过标准 |
|------|--------|----------|
| 1 | 核心指令 | 完整提取，包含"生成1张漫画图，X格分镜" |
| 2 | 风格约束 | 完整提取所有风格参数（画风/线条/饱和度/色调/字体/字色） |
| 3 | 角色定义 | 完整提取所有 `@角色名 = 参考图X` |
| 4 | 布局蓝图 | 完整提取所有格子位置描述 |
| 5 | 分镜内容 | 完整提取所有格子的详细描述 |
| 6 | 无修改确认 | 确认未对原文做任何修改/简化/删减 |

**若任何一项不符合，禁止调用生图工具，需重新提取完整提示词。**

---

### ⚠️ 严重后果

**自行简化提示词会导致：**

- 🔴 **画面结构错误**：布局蓝被删除，分镜位置混乱
- 🔴 **角色形象错误**：角色定义被修改，角色特征丢失
- 🔴 **风格不一致**：风格约束被省略，系列图风格跳跃
- 🔴 **叙事不完整**：分镜内容被删减，情节缺失
- 🔴 **专业度下降**：提示词工程环节的工作白费

## 3. 从提示词文件提取关键参数

《漫画生图提示词.md》的结构如下，需提取对应内容：

| 提示词文件内容 | 用途 |
|---------------|------|
| 【参考图数组】 | 角色参考图，传入图生图工具的参考图参数 |
| **Prompt** 块内容 | 完整的生图提示词，传入图生图工具的提示词参数 |
| （固定负面词） | 负面提示词，传入图生图工具的负面词参数 |

### 3.1 提取参考图数组
```markdown
【参考图数组】
```
["URL1", "URL2", "URL3"]
```
```
提取 JSON 数组内的图片URL列表，作为角色参考图传入图生图工具。

### 3.2 提取 Prompt
```markdown
**Prompt（用于生成一张完整的漫画图）:**
```
【核心指令】...
【风格约束】...
【角色定义】...
【布局蓝图】...
【分镜内容】...
```
```
提取代码块内的完整内容，作为生图提示词传入。

## 4. 图生图工具调用规范

### 4.1 参数配置要求

| 参数 | 要求 | 说明 |
|------|------|------|
| 参考图 | 从提示词文件提取 | 角色形象照URL数组 |
| 提示词 | 从提示词文件提取 | 完整的生图提示词 |
| 负面提示词 | 固定内容（见下方） | 禁止与正向提示词混用 |
| 生成数量 | 1张 | 每次仅生成1张图 |
| 参考图权重 | 0.7-0.85 | 保障角色特征不混淆 |

### 4.2 负面提示词（强制使用）

```
文本, 水印, logo, 糟糕的解剖结构, 肢体缺失, 多余肢体, 畸形, 模糊, 低质量, 裁剪, 最差质量, 丑陋, 变异, 风格不一致, 更换衣服, 重复的文字, 多个文字框, 对话气泡, 箭头, 角标, 指向标, 对话气泡尾部, 带箭头文本框
```

### 4.3 参考图权重说明

参考图权重用于控制生成图片与角色形象照的相似程度：

- **范围**：0.7-0.85
- **作用**：权重越高，生成图片越接近参考图的角色特征
- **风险**：权重低于0.7可能导致角色特征互串（如角色A的发型被角色B覆盖）

---

## 5. 生图执行规则

### 5.1 按顺序逐张生成
- 必须等待当前图片生成完成并确认成功后，再开始下一张
- **禁止并行或批量生成**

### 5.2 生成顺序
1. 封面图（使用封面Prompt）
2. 第1张条漫（使用第1张条漫Prompt）
3. 第2张条漫（使用第2张条漫Prompt）
4. ...依次类推

### 5.3 失败处理
- 单张失败：自动重试2次
- 连续失败3次：标记报错，提示用户处理方案
