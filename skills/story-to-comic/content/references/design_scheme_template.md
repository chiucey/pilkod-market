# 设计方案模板
设计方案是连载配置文件，用于快速启动同系列漫画生成。

## 文件命名规范
设计方案文件名：`设计方案_连载复用.md`

## 设计方案格式

```markdown
# 【灵犀漫画图文·设计方案】

## 项目信息
- 项目名称：{系列名称}
- 创建日期：{YYYY-MM-DD}

## 美术设定

### 通用设定
- 主基调：{风格名称}
- 色板：{颜色名}#{Hex}、{颜色名}#{Hex}
- 图片比例：3:4竖版（默认）

### 封面图设定
- 字体风格：{字体描述，如：手写体}
- 字体效果：{效果描述，如：渐变描边}
- 情绪氛围：{氛围关键词，如：治愈、温馨}
- 主色调：{色调描述，如：暖色}
- 动感元素：{默认动感元素，如：飘落的枫叶、飞扬的发丝}

### 条漫设定
- 字体：{字体描述，如：手写体}
- 字色：{字体颜色描述，如：白底黑字}
- 线条：{线条风格，如：柔和、圆润}
- 饱和度：{饱和度描述，如：低、鲜艳}
- 背景底色：{背景色，如：白底}
- 分格线：{分格线样式，如：清晰}

## 角色档案

### {角色名}
- 外貌服饰：{简洁描述，包含发型/体型/标志性服饰}
- 参考图：{形象照URL}
- 形象照：![{角色名}_形象照]({形象照URL})

### {角色名2}
- 外貌服饰：{描述}
- 参考图：{URL}
- 形象照：![{角色名2}_形象照]({URL})

## 连载复用说明
1. 开启新对话，上传该文档；
2. 输入提示词（示例）
```
使用该设计方案，将以下故事生成系列漫画，严格遵循技能流程和规范执行，全自动化模式。

XXX（故事）
```
```
