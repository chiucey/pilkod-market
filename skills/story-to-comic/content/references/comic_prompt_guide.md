# 条漫图文生图提示词指导

## 0. 输出自检（硬性）

- 交付给用户的《漫画生图提示词.md》必须是"可直接复制使用"的成品文本，不得出现未替换的模板占位符。
- 禁止出现的典型占位符（示例）：`角色名`、`格子数`、`景别/镜头`、`核心动作/状态`、`场景关键词`、`文字内容`、`主设计风格描述` 等模板字段名。
- 参考图就绪闸门：执行页面提示词生成前，必须已获取核心角色参考图。参考图来源允许为"本技能生成的角色三视图"或"用户上传并指明角色归属的参考图"。否则禁止生成页面提示词。

### ⚠️ 中文双引号强制规范（最高优先级）

- **强制要求**：所有需要画面渲染的文字内容（主标题、吸引语、对话、旁白、内心独白、音效/拟声词）**必须**使用**中文双引号**
- **中文双引号**：左引号 `“` (U+201C)，右引号 `”` (U+201D)
- **禁止使用**：英文双引号 `"` (U+0022)、转义引号 `\"\"`
- **错误示例**：`主标题: "晚风与热可可"` ← 英文引号，生图模型无法正确识别
- **正确示例**：`主标题: “晚风与热可可”` ← 中文引号，确保正确渲染
- **原因**：中文双引号确保生图模型准确识别并渲染文字内容，英文引号会导致文字渲染失败或乱码

### ⚠️ 引号格式自检清单（输出前必查）

> **通用规则**：所有自检清单的执行过程/结果均属内部运行信息，不得写入输出文档。

**在输出《漫画生图提示词.md》前，必须执行以下检查：**

| 检查项 | 检查方法 | 通过标准 |
|--------|----------|----------|
| 1. 扫描所有文字内容 | 搜索 `"` 英文双引号 | **零匹配** |
| 2. 确认引号方向 | 检查引号是否为 `“` `”` 成对出现 | 左引号`“` + 右引号`”` |
| 3. 检查封面提示词 | 主标题、吸引语的引号 | 均为中文双引号 |
| 4. 检查条漫提示词 | 所有文字框内容的引号 | 均为中文双引号 |

**如果发现英文双引号，必须执行修正：**

```
错误修正对照表：
"  →  “  （英文左引号 → 中文左引号）
"  →  ”  （英文右引号 → 中文右引号）
```

**批量替换方法（AI执行）：**
1. 扫描提示词文本中所有英文双引号 `"` (U+0022)
2. 按顺序替换：第一个 `"` → `“`，第二个 `"` → `”`，依次交替
3. 确保每对引号是 `“内容”` 的格式

**禁止输出的情况：**
- ❌ 提示词中存在任何英文双引号 `"`
- ❌ 引号不成对（只有左引号或只有右引号）
- ❌ 引号方向错误（如两个都是左引号 `““`）

### ⚠️ 格式红线（禁止触碰）

- **【角色定义】块是生图提示词的必要组成部分，禁止剥离**
  - 错误做法：将"角色定义"单独成段，与"生图提示词"分离展示
  - 正确做法：【角色定义】块必须作为每页提示词的一部分，与后续内容连续构成完整的Prompt
- **禁止出现独立的"角色定义"标题段落**
  - 错误示例：
    ```
    角色定义
    图1 林晚...
    
    生图提示词
    (最佳质量, 4k, 8k)...
    ```
  - 正确示例：
    ```
    【核心指令】生成1张漫画图，X格分镜，竖排布局，各个分镜在同一张图
    
    【风格约束】
    画风: 主设计风格 | 线条: 描述 | 饱和度: 描述 | 色调: 描述
    
    【角色定义】
    @林晚 = 参考图1
    @苏冉 = 参考图2
    
    【布局蓝图】...
    ```
- **禁止使用错误的引号格式**
  - 错误示例：`椭圆文本框(左下): "\"林晚(内心)：...\""` ← 转义引号
  - 正确示例：`椭圆文本框(左下): “林晚(内心)：...”` ← 中文双引号（左“右”）
- **每个页面的提示词必须是一个完整、连续的整体**，包含：核心指令 → 风格约束 → 角色定义 → 布局蓝图 → 分镜内容

## 3. 封面提示词撰写规则

### 3.1 主标题处理规则
- **标题来源**：使用短文的原始标题
- **艺术化设计**：标题文字与主题元素融合（如飘落的花瓣环绕、蒸汽升腾效果）
- **关键词强调**：识别标题中的关键词，做放大/变色/描边/发光等视觉效果
- **示例**：
  - 标题：“晚风与热可可” → 关键词：“晚风”、“热可可”
  - 艺术化设计：标题文字由飘落的枫叶环绕，“热可可”三字带有蒸汽升腾效果

### 3.2 吸引语生成规则（核心）
- **来源**：AI从故事中提取的情感金句，一句话打动读者
- **生成原则**：
  - 传递故事核心情感或主题
  - 简洁有力，具有传播性
  - 引发读者共鸣或好奇
- **示例**：
  - 故事《晚风与热可可》→ 吸引语：“那些陪你喝热可可的人，才是最温暖的治愈”
  - 故事《最后一班地铁》→ 吸引语：“城市再大，总有人在终点等你”

### 3.3 角色呈现规则
- **数量**：选择1-2个核心角色
- **参考图**：使用【环节：角色形象照生成】中已生成的形象照
- **姿态要求**：动态姿态，与标题形成视觉关系（如仰望标题、伸手触碰标题）
- **情绪表达**：表情需传递故事核心情绪

### 3.4 场景氛围规则
- **背景**：延续条漫故事氛围的场景描述
- **光影**：必须有明确的光影效果（如逆光、侧光、聚光灯）
- **动感元素**：必须有动感元素（飘落的花瓣/飞扬的发丝/流动的光线/升腾的热气）

### 3.5 风格延续规则
- **画风一致**：封面必须延续条漫的主设计风格
- **字体统一**：使用与条漫相同的字体风格
- **色调协调**：色调与条漫保持一致或呼应

### 3.6 中文双引号规范（强制）
- 主标题、吸引语必须使用**中文双引号** `“”` 包裹
- **禁止使用**英文双引号 `""`
- 示例：`主标题: “晚风与热可可”` ✅ 正确

# 板块二：条漫生图提示词规范

> **执行顺序**：条漫提示词在封面提示词之后生成，统一输出到《漫画生图提示词.md》文件。

## 1. 条漫提示词结构

条漫提示词包含以下模块：

| 模块 | 说明 | 优先级 |
|------|------|--------|
| 【核心指令】 | 声明生图数量、分镜数、布局方式 | ⭐⭐⭐⭐⭐ 最高 |
| 【风格约束】 | 画风、线条、色调、字体、字色等风格参数 | ⭐⭐⭐⭐ 高 |
| 【角色定义】 | 角色与参考图的映射关系，使用 `@角色名` 引用 | ⭐⭐⭐ 中高 |
| 【布局蓝图】 | 各格子位置与大小的自然语言描述 | ⭐⭐ 中 |
| 【分镜内容】 | 每个格子的具体内容描述 | ⭐ 基础 |

## 2. 条漫提示词核心撰写规范

需满足**完整性、精准性、一致性、适配性**，包含上述5大模块，缺一不可。

### ⚠️ 核心原则（必须遵守）
- **一个Prompt = 一张完整漫画图（含多个分镜）**：生图模型必须将所有分镜格子合并到同一张图中，**禁止**将不同分镜生成多张独立图片。
- **单图多格概念**：每个Prompt生成的结果是一张完整的漫画页，页面上包含多个分镜格子，所有格子按布局蓝图排列在同一画面中。

## 3. 角色定义机制

### 【角色定义】块
- **格式**：`@角色名 = 参考图X`
- **示例**：
```
【角色定义】
@林晚 = 参考图1
@苏冉 = 参考图2
```

### ⚠️ 参考图顺序一致性（关键要求）
- **参考图X与数组的对应关系**：
  - 参考图1 → 参考图数组[0]
  - 参考图2 → 参考图数组[1]
  - 参考图X → 参考图数组[X-1]
- **参考图URL数组组织规则**：
  - 按【角色定义】块中的顺序，将对应角色的形象照URL组织成数组
  - 示例：【角色定义】中有参考图1=林晚、参考图2=苏冉，则参考图数组 = [林晚的形象照URL, 苏冉的形象照URL]
- **每页独立组织**：每张漫画页的参考图数组独立组织，不继承上一页
- **顺序错乱将导致角色错误，这是灾难性错误**

## 4. 分格布局（Layout Blueprint）

- 不允许默认"等分网格"。每页必须提供"布局蓝图"，明确每个格子的位置与相对大小，并声明阅读顺序（推荐 Z 字形）。
- **布局蓝图必须单独成行，放在分镜内容描述之前**，作为全局结构说明。
- **布局描述规则**：逐个格子使用自然语言描述，禁止混合描述（如"格子2/3中部并列"）。
- **比例描述规则**：使用中文自然语言描述比例（如"三分之一"、"一半"、"四分之一"），**禁止使用百分比数字**（如"30%"、"50%"），避免模型将数字渲染到画面中。

### ⚠️ 画面边距与留白控制（强制）

**问题现象**：生图模型默认保留较多边距，导致分镜内容未能充分填满画面，四周留白过多，视觉显得空洞松散。

**禁止出现的留白问题**：
- ❌ 左右留白超过画面宽度的 **10%**
- ❌ 上下留白超过画面高度的 **10%**
- ❌ 整体留白面积超过画面 **15%**
- ❌ 分镜格子之间间距过大，割裂叙事连贯性

**强制要求**：
- 分镜格子必须**紧贴画面边缘**，充分利用画面空间
- 格子之间间距**保持紧凑**，仅需"呼吸感"间距
- 分镜内容**撑满画面**，避免画面空洞

**提示词中的实现方式**：
在【布局蓝图】中添加边距控制指令：
```
【布局蓝图】
阅读顺序: Z字形
边距控制: 分镜格子紧贴画面边缘，四周留白最小化，格子间距紧凑
格子 1 (顶部横跨)：位于图片顶部，紧贴上边缘，横跨全宽，高度约三分之一
格子 2 (中部左侧)：紧贴左侧边缘，宽度一半，高度约四分之一
...
```

**正确示例**：
```
【布局蓝图】
阅读顺序: Z字形
边距控制: 分镜格子紧贴画面边缘，四周无额外留白，格子间保持呼吸感间距
格子 1 (顶部横跨)：紧贴画面顶部，横跨全宽，高度约三分之一
格子 2 (中部左侧)：紧贴画面左侧，宽度一半，高度约四分之一
格子 3 (中部右侧)：紧贴画面右侧，宽度一半，高度约四分之一
格子 4 (底部横跨)：紧贴画面底部，横跨全宽，高度约三分之一
```

**视觉对比**：
| 留白状态 | 视觉效果 | 问题 |
|---------|---------|------|
| 过多（>30%） | 空洞、松散、信息密度低 | 削弱剧情冲击力 |
| 适中（10-15%） | 紧凑、有呼吸感 | ✅ 最佳 |
| 过少（<5%） | 拥挤、压迫 | 影响阅读体验 |

- 推荐格式（示例）：
  - `Z字形阅读顺序, 布局蓝图: 格子1顶部横跨全宽(高度约三分之一); 格子2中部左侧(宽度一半、高度约四分之一); 格子3中部右侧(宽度一半、高度约四分之一); 格子4底部横跨全宽(高度约三分之一)`
  - `Z字形阅读顺序, 布局蓝图: 格子1左侧通栏大格(宽度过半、高度约三分之二); 格子2右上小格(宽度近半、高度约三分之一); 格子3右下小格(宽度近半、高度约三分之一); 格子4底部横跨全宽(高度约三分之一)`

## 5. 格子描述规范

- **格式**：`格子X(位置): 景别/镜头 + 角色名, 核心动作/状态 + 场景关键词 + 文字框`
- **角色引用**：直接使用角色名，无需前缀（【角色定义】块已定义映射关系）
- **长度控制**：每个格子描述控制在60-80字以内，保留核心元素，省略过度细节
- **必须保留**：景别 + 角色引用 + 核心动作 + 场景关键词 + 文字框
- **可选保留**：氛围词、光影描述（如果对叙事重要）
- **可以省略**：过度细节（如"同事们背景虚化"、"有人捧着书啃"等）

### 分镜内容格式规范

**格式**：`格子X(位置) | 景别/镜头 | 角色动作 | 场景氛围 | 文字框`

| 字段 | 说明 | 示例 |
|------|------|------|
| 格子 X (位置) | 格子编号与位置 | 格子 1 (顶部横跨), 格子 2 (中部左侧) |
| 景别/镜头 | 景别和镜头角度 | 全景/俯视, 特写/侧视 |
| 角色动作 | 角色引用 + 核心动作 | @林晚 抱文件站写字楼下 |
| 场景氛围 | 环境、光影、氛围词 | 秋日傍晚/风吹落叶 |
| 文字框 | 文字类型、位置、内容 | 椭圆框(底): "台词" / 旁白条(顶): "旁白" / 拟声词: "拟声" / 无文字用 `-` |

**关键提示**：
- **【参考图数组】独立于提示词代码块**：使用单独的代码块展示，供生图环节AI读取，不传入生图模型
- **权重分层**：提示词按优先级从高到低排列，模型对靠前内容关注度更高
- **角色引用**：使用 `@角色名` 格式，简洁明确
- **布局自然语言描述**：使用纯自然语言逐格描述位置与大小，清晰易懂
- **字体样式统一**：从 [design_style_guide.md](design_style_guide.md) 中选择与主设计风格匹配的字体，填入【风格约束】的"字体"字段，确保系列图文字体一致
- **字体颜色自然描述**：字体颜色使用自然语言描述（如"白底黑字"、"米白底深灰字"），**禁止使用十六进制颜色代码**（如 `#000000`）
- **分镜表格化**：每行一个格子，字段统一，便于校验和维护

### ⚠️ 微场景/背景描述规范（强制）
- **来源**：微场景描述必须从【环节：分镜脚本规划】的输出物中提取，禁止在提示词生成阶段临时编造
- **强制要求**：每个格子必须包含**场景关键词**，直接引用分镜脚本中的"微场景"字段
- **一致性保障**：使用分镜规划阶段确定的微场景，确保场景与故事内容和谐统一
- **格式**：在角色动作后添加从分镜脚本提取的场景关键词
- **示例**：
  - 分镜脚本中：`微场景：写字楼楼下，秋日傍晚，落叶飘零，街灯初亮`
  - 提示词中：`林晚抱着文件独自站着 + 写字楼楼下场景, 秋日傍晚, 落叶飘零, 街灯初亮`
- **自检标准**：每个格子的场景关键词是否与分镜脚本一致？是否缺失？

## 6. 文字内容规范（强制）

### 5.1 文字双引号规范（最高优先级）
- **强制要求**：所有需要画面渲染的文字（拟声词、对话、旁白、内心OS）**必须**使用**中文双引号**`""`（左引号"右引号"）包裹
- **禁止使用**：英文双引号`""`、转义引号`\"\"`、其他符号
- **原因**：中文双引号确保生图模型准确识别并渲染文字内容

#### 错误示例与正确示例
- ❌ **错误**（使用转义引号）：
  ```
  椭圆文本框(左下): "\"林晚(内心)：熬了三个通宵的方案...\""
  ```
- ❌ **错误**（使用英文引号）：
  ```
  椭圆文本框(左下): "林晚(内心)：熬了三个通宵的方案..."
  ```
- ✅ **正确**（使用中文双引号）：
  ```
  椭圆文本框(左下): “林晚(内心)：熬了三个通宵的方案...”
  ```

### 5.2 文字容器规范
- **椭圆文本框**：用于角色对话、角色(内心)，无指向，白底黑字
- **旁白条**：用于旁白，横跨格子宽度，无指向，位于格子顶部或底部，字体弱化
- **拟声词（音效字）**：独立渲染于画面中，不放在文本框内，格式为 `拟声词: “拟声内容”`（如“砰”、“呼——”、“哒哒哒”）
- **禁止使用**：带箭头的文本框、带角标的文本框

### 5.3 文本格式规范
- **对话格式**：`椭圆文本框(位置): “角色名：台词”` — 角色对话必须带角色名前缀
- **内心OS格式**：`椭圆文本框(位置): “角色名(内心)：内心独白内容”` — 内心OS必须带角色名前缀
- **旁白格式**：`旁白条(顶部/底部): “旁白内容”` — 旁白不带任何前缀，直接写内容

### ⚠️ 5.3.1 旁白处理高频错误警示（强制）

**禁止以下旁白处理方式：**

| 错误类型 | 错误示例 | 问题说明 |
|---------|---------|---------|
| ❌ 容器错误 | `椭圆文本框(顶): “旁白：小夫见状...”` | 旁白必须使用`旁白条`，禁止使用`椭圆文本框` |
| ❌ 内容带前缀 | `旁白条(顶部): “旁白：小夫见状...”` | 旁白内容禁止包含`旁白：`前缀，直接写内容 |
| ❌ 位置简略 | `旁白条(顶): “小夫见状...”` | 位置必须写完整：`顶部`或`底部`，禁止简写 |
| ❌ 英文引号 | `旁白条(顶部): “小夫见状...”` | 必须使用中文双引号`“”`，禁止英文引号 |

**正确示例：**
```
旁白条(顶部): “小夫见状，立刻挺直腰板，飞快地打开电脑，手指在键盘上胡乱敲击”
```

**关键规则总结：**
1. **容器**：旁白 → `旁白条`；对话/内心OS → `椭圆文本框`
2. **前缀**：旁白 → 无前缀；对话 → `角色名：`；内心OS → `角色名(内心)：`
3. **位置**：`顶部` 或 `底部`，禁止简写
4. **引号**：必须使用中文双引号 `“”`

### 5.4 文本框角色前缀规范

**核心规则**：文本框中的角色前缀直接使用角色名，**禁止加@符号**

| 用法场景 | 格式 | 示例 |
|---------|------|------|
| 【角色定义】块 | `@角色名 = 参考图X` | `@林晚 = 参考图1` |
| 格子描述中的角色名 | `@角色名` | `@林晚 抱着文件...` |
| 文本框中的角色前缀 | `角色名：` | `林晚：谢谢...` |

**⚠️ 禁止混淆**：
- ❌ 错误：`椭圆文本框(位置): “@角色名：台词”` — 文本框内容中禁止使用@符号
- ✅ 正确：`椭圆文本框(位置): “角色名：台词”` — 文本框内容中直接写角色名

**示例**：
```
椭圆文本框一(左下): “胖虎：明天我也试试高效工作法...”
椭圆文本框二(右下): “小夫：嗯, 不发朋友圈装忙了...”
```

### 5.5 文本提取规范（强制）
从分镜脚本规划中提取文字内容时，必须完整提取以下字段：

| 分镜规划字段 | 提示词对应格式 | 说明 |
|-------------|---------------|------|
| 台词气泡 → 旁白 | `旁白条(顶部/底部): “旁白内容”` | **必须提取**，不得遗漏 |
| 台词气泡 → 角色名：台词 | `椭圆文本框(位置): “角色名：台词”` | **必须提取**，不得遗漏 |
| 台词气泡 → 角色名(内心) | `椭圆文本框(位置): “角色名(内心)：内容”` | **必须提取**，不得遗漏 |
| 拟声词 | `拟声词: “拟声内容”` | 可选提取，独立渲染不放在文本框内 |

**错误示例**（文本遗漏）：
```
分镜规划中：
- 台词气泡：
  - 旁白（顶部居中）：胖虎听完，脸“唰”地一下红到了耳根...

提示词中（错误）：
格子 1: ... + 椭圆文本框(右下): “咳咳！”  ← 只有拟声词，旁白丢失！
```

**正确示例**：
```
分镜规划中：
- 台词气泡：
  - 旁白（顶部居中）：胖虎听完，脸“唰”地一下红到了耳根...
- 拟声词：“咳咳！”

提示词中（正确）：
格子 1: ... + 旁白条(顶部): “胖虎听完，脸《唰》地一下红到了耳根...” + 椭圆文本框(右下): "咳咳！"
```

**自检标准**：每个格子的文字内容是否与分镜规划的“台词气泡”字段完全对应？若有遗漏则必须补充。

### 5.6 引号嵌套处理规则
- **问题场景**：旁白条文字中包含需要强调的词汇，导致引号嵌套
- **错误示例**：`旁白条(顶部): “行业裁员风声一出,公司瞬间掀起”全能人才"内卷狂潮"` ← 嵌套引号冲突
- **正确处理**：
  - 便利贴、证书文字、屏幕文字等 → 使用《书名号》或省略引号
  - 拟声词、旁白、对话 → 保留中文双引号
- **正确示例**：`旁白条(顶部): “行业裁员风声一出,公司瞬间掀起《全能人才》内卷狂潮”`

### 5.7 文本拆分规则
- 默认优先使用"一个椭圆文本框 + 换行/断句"表达同一说话人或同一类型文本
- 仅当"不同角色对话"或"不同类型文本（对白+旁白/拟声词等）"同处一个格子时，才拆分为多个文本框
- 同一说话人多句台词，优先在同一个椭圆文本框内换行表达

### 5.8 去标签化规则
- 旁白、独白等描述性文本，**严禁**包含“旁白：”、“独白：”等元数据前缀
- 错误示例: `旁白条(顶部): “旁白：晚风吹过”`
- 正确示例: `旁白条(顶部): “晚风吹过”`

## 9. 条漫提示词优化规则

### 8.1 多格一致性保障
- 若多格出现同一角色，必须在每个格子描述中使用 `@角色名` 格式显式引用
- 在【角色定义】块中定义角色与参考图的映射关系

### 8.2 多框防合并规则
- 若同一格子内出现2个及以上文本框，推荐对每个框添加位置标记
- 示例: `椭圆文本框一（左下）: “林晚：谢谢你。”, 椭圆文本框二（右下）: “苏冉：回去再说。”`

### 8.3 小格承载规则
- 若某个格子需要2个及以上文本框，或单框文本需要多行排版，则该格子不应为小格
- 需在"布局蓝图"中分配为大格（横跨/通栏/占高更大）

### 8.4 色彩一致性处理
- 在【风格约束】中声明主色调，同时允许根据场景需要调整局部色调
- 例如：`画风: 藤子F不二雄Q版漫画风格 | 线条: 圆润 | 饱和度: 鲜艳 | 色调: 允许根据场景调整`
- 格子描述中可指定特定场景的光影氛围
