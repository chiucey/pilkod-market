# 设计风格指导

## 1. 核心设计风格分类及适配场景

### 1.1 主流漫画风格

| 风格类型 | 适配场景 | 核心设计特征 |
|---------|---------|-------------|
| Q版卡通风格 | 搞笑段子、职场日常、轻松剧情 | 线条圆润，色彩鲜艳，角色头身比1:3，表情夸张，场景简化 |
| 治愈手绘风格 | 情感故事、治愈短文、生活感悟 | 线条柔和，低饱和马卡龙色，画面细腻，注重光影/绿植氛围感 |
| 日系漫画风格 | 悬疑故事、青春校园、热血剧情 | 线条利落，色彩层次分明，角色比例协调，注重镜头张力和情绪表达 |
| 美式漫画风格 | 超级英雄、动作冒险、科幻题材 | 线条粗犷有力，高对比度色彩，动态构图，强调力量感和戏剧性 |
| 韩式条漫风格 | 网漫连载、都市情感、现代题材 | 柔和渐变，精致上色，垂直滚动优化，注重氛围渲染 |

### 1.2 插画绘本风格

| 风格类型 | 适配场景 | 核心设计特征 |
|---------|---------|-------------|
| 简笔画风格 | 科普故事、育儿场景、教程图解 | 线条简洁，色彩单一明快，角色造型简约，无冗余场景元素 |
| 水彩绘本风格 | 童话故事、儿童绘本、温馨故事 | 水彩质感，柔和晕染，梦幻色调，留白艺术，童趣温馨 |
| 扁平插画风格 | 商业故事、品牌内容、现代职场 | 几何造型，纯色填充，无阴影渐变，信息清晰，现代简约 |
| 剪纸拼贴风格 | 创意故事、艺术表达、儿童内容 | 层叠质感，色块分明，童趣造型，手工艺术感 |
| 蜡笔手绘风格 | 儿童故事、幼儿园材、亲子内容 | 蜡笔质感，稚拙线条，明快色彩，童真表达 |

### 1.3 国风与特色风格

| 风格类型 | 适配场景 | 核心设计特征 |
|---------|---------|-------------|
| 国潮写实风格 | 古风故事、历史题材、武侠内容 | 线条有质感，融入中国红/墨色，服饰贴合古风，场景加传统建筑/纹样 |
| 水墨国风风格 | 诗词意境、传统文化、禅意故事 | 水墨晕染，留白意境，墨色层次，飘逸洒脱，东方美学 |
| 赛博朋克风格 | 科幻未来、反乌托邦、游戏题材 | 霓虹色彩，高对比度，机械元素，故障艺术，未来感 |
| 蒸汽朋克风格 | 维多利亚科幻、机械美学、复古未来 | 黄铜齿轮，蒸汽机械，维多利亚服饰，复古科技感 |
| 像素复古风格 | 游戏怀旧、复古题材、极客文化 | 像素方格，8-bit色彩，游戏机风格，怀旧质感 |

### 1.4 潮流社交风格

| 风格类型 | 适配场景 | 核心设计特征 |
|---------|---------|-------------|
| 小红书图文风 | 生活方式、好物种草、干货分享 | 柔和滤镜，ins风配色，文字排版精致，注重留白和美感 |
| 抖音快闪风 | 段子短剧、热点梗图、快节奏内容 | 高饱和度，动感构图，文字醒目，适合竖屏浏览 |
| 表情包风格 | 社交互动、趣味表达、网络梗图 | 极简造型，表情夸张，文字点睛，高传播性 |
| MBTI人格风 | 职场吐槽、性格分析、社交话题 | 符号化角色，颜色编码，简化特征，人格标签化表达 |

### 1.5 艺术探索风格

| 风格类型 | 适配场景 | 核心设计特征 |
|---------|---------|-------------|
| 暗黑哥特风格 | 悬疑推理、恐怖故事、暗黑童话 | 暗色调，锐利线条，哥特元素，神秘氛围 |
| 波普艺术风格 | 时尚潮流、商业广告、艺术表达 | 高饱和撞色，重复图案，流行元素，视觉冲击 |
| 极简主义风格 | 哲学思考、现代故事、文艺表达 | 极简线条，大量留白，色彩克制，意境留白 |
| 浮世绘风格 | 日本题材、传统美学、艺术创作 | 平面色块，装饰线条，和风元素，江户美学 |

## 3. 字体风格指导

| 风格类型 | 推荐字体 | 字体特征 |
|---------|---------|---------|
| Q版卡通 | 圆润卡通体 | 笔画均匀，文字适当放大 |
| 治愈手绘 | 手写体 | 柔和有笔触感，颜色与画面协调 |
| 日系漫画 | 专业漫画体 | 笔画有粗细对比，大小适中 |
| 美式漫画 | 粗黑体/冲击体 | 粗犷有力，强调戏剧性 |
| 韩式条漫 | 细圆体/手写体 | 精致柔和，阅读舒适 |
| 简笔画 | 简约宋体/黑体 | 笔画清晰，优先黑/深灰色 |
| 水彩绘本 | 童趣手写体 | 可爱圆润，配合画面色调 |
| 扁平插画 | 无衬线字体 | 现代简约，几何感强 |
| 国潮写实 | 书法体 | 贴合古风，可选楷书/行书 |
| 水墨国风 | 毛笔字体 | 水墨质感，苍劲有力 |
| 赛博朋克 | 故障字体/霓虹字体 | 科技感，发光效果 |
| 暗黑哥特 | 哥特字体 | 锐利尖锐，神秘感 |
| 小红书风 | 纤细宋体/手写体 | 精致文艺，留白优雅 |

### 3.3 字体颜色选择原则
字体颜色使用自然语言描述，**禁止使用十六进制颜色代码**（如 `#000000`）。

**推荐配色方案：**
| 场景 | 推荐配色 | 说明 |
|------|---------|------|
| 通用场景 | 白底黑字 | 清晰易读，最常用 |
| 温馨氛围 | 米白底深灰字 | 柔和舒适 |
| 悬疑氛围 | 浅灰底深黑字 | 增加层次感 |
| 梦幻氛围 | 淡蓝底深蓝字 | 统一色调 |
| 复古氛围 | 泛黄底深棕字 | 怀旧质感 |
| 科技场景 | 深蓝底荧光蓝字 | 未来感 |

**描述示例：**
- 白底黑字
- 米白底深灰字
- 浅灰底深黑字
- 淡粉底深粉字
- 深蓝底荧光蓝字

**重要提示：**
- 确保文字与背景有足够对比度，保证可读性
- 系列连载漫画应保持字体颜色一致
- 特殊场景可使用描边或阴影增强可读性（如：白底黑字带白色描边）


## 4. 布局&格子风格指导

### 4.1 通用布局原则
- **统一要求**：竖向排版，格子间距均匀，画面整洁
- **简单情节（3-4格）**：格子大小均匀，无复杂布局
- **复杂情节（5-8格）**：按情节权重调整格子大小，核心分镜放大

### 4.2 分格线风格

| 风格类型 | 分格线特征 |
|---------|-----------|
| Q版卡通 | 粗黑线 2px，圆润边角 |
| 治愈手绘 | 细灰线 1px，柔和边角 |
| 日系漫画 | 细黑线 1.5px，直角边角 |
| 美式漫画 | 粗黑线 2-3px，动态不规则边角 |
| 韩式条漫 | 细线或无边框，渐变过渡 |
| 简笔画 | 虚线 1px 或无边框 |
| 水彩绘本 | 无边框或水彩晕染边框 |
| 扁平插画 | 细线 1px 或留白分隔 |
| 国潮写实 | 墨色线 1.5px，传统纹样装饰 |
| 水墨国风 | 水墨晕染边框或无边框 |
| 赛博朋克 | 霓虹发光线或故障断裂线 |


## 5. 文字容器风格指导

### 5.1 通用文字容器规范
- **椭圆文本框**：用于角色对话、角色(内心)，无指向，无箭头/无角标/无指向标，白底黑字
- **旁白条**：用于旁白，横跨格子宽度，无指向，位于格子顶部或底部，字体弱化，加轻微阴影提升可读性
- **禁用元素**：全系列禁用对话气泡（Speech Bubble）和云朵气泡（Cloud Bubble），避免遮挡画面和指向错误

### 5.2 风格化文字容器

| 风格类型 | 文本框特征 |
|---------|-----------|
| Q版卡通 | 圆角云朵框，彩色描边，可加表情装饰 |
| 治愈手绘 | 柔和椭圆框，淡色背景，手绘质感 |
| 日系漫画 | 标准椭圆框，清晰描边，爆炸框强调 |
| 美式漫画 | 锯齿爆炸框，粗描边，高对比度 |
| 韩式条漫 | 简约椭圆框，细线或无边框 |
| 水彩绘本 | 水彩晕染框，柔和边缘 |
| 扁平插画 | 几何圆角框，纯色背景 |
| 国潮写实 | 传统纹样框，水墨点缀 |
| 赛博朋克 | 故障效果框，霓虹描边 |
| 暗黑哥特 | 尖锐边角框，暗色背景 |
