# 灵犀漫画
**技能定位**：故事/小说/文章/灵感转漫画技能。文生漫画 | 故事转漫画 | 小说转漫画 | AI漫画 | 分镜条漫 | 小红书图文 | 抖音图文 | 微信贴图 | 图文创作 | 文配图 | 小说配图 | 图文带货


## 核心目标
- **极致简化**：用户仅需输入短文，其余配置（风格、角色、分镜）由AI自动规划。
- **一致性保障**：确保全系列角色形象、设计风格、排版逻辑统一。
- **支持连载**：生成标准化设计方案，支持快速连载。


## 流程概览（Process Overview）
1.  **【环节：短文输入与合理性检测】**：剧本源头把控，确保故事可改编。
2.  **【环节：角色与风格设定】**：纯文本工作，确定美术风格与角色人设文字描述。
3.  **【环节：角色形象照生成】**：基于文字设定，生成标准化三视图形象照。
4.  **【环节：分镜脚本规划】**：基于形象照，拆解剧本并规划详细分镜。
5.  **【环节：分镜提示词工程】**：生成标准化生图 Prompt（含封面提示词），校验逻辑与格式。
6.  **【环节：系列条漫图文生成】**：批量执行生图任务（含封面图），包含单图质量自检与容错重试。
7.  **【环节：设计方案生成】**：全流程归档，生成可复用的设计方案并支持后续连载复用。

## ⛔ 强制确认规则（最高优先级）

**默认行为**：每个环节输出完毕后，必须严格执行以下操作：

1. **输出环节完成标识**：`✅ 【环节：xxx】已完成`
2. **输出交付物**：展示本环节生成的文件/图片
3. **输出确认选项**：提示用户选择下一步操作
4. **输出停止词**：`【停止生成，等待用户确认】`
5. **立即停止生成**：等待用户回复

**停止词（强制输出）**：
```
【停止生成，等待用户确认】
```

**用户确认选项**：
- 用户回复 `1` 或 `确认` → 进入下一环节（单步模式）
- 用户回复 `2` 或 `全自动化运行` → 启用全自动化模式，后续环节自动运行

**禁止行为**：
- 禁止在没有用户确认的情况下自动输出下一环节内容
- 禁止遗漏停止词
- 禁止假设用户已确认

**全自动化模式例外**：
- 触发条件：用户回复"2"或"全自动化运行"，或初始输入包含"全自动化运行"、"后续无需确认"等明确指令
- 启用后：跳过逐环节确认，自动推进

- **最小输入规则**：用户仅需输入短文，不设置任何额外必填项。

- **叙事优先规则**：条漫格子数、图文拆分数量完全由短文情节节奏决定，不固定模板。

- **一致性规则**：全系列条漫需保证角色形象、设计风格、字体样式、字体颜色、排版逻辑统一；条漫生成必须以【环节：角色形象照生成】的形象照为参考。

- **字体颜色规则**：字体颜色使用自然语言描述（如"白底黑字"、"米白底深灰字"），**禁止使用十六进制颜色代码**（如 `#000000`）。

- **容错规则**：生图失败自动重试 2 次；连续失败 3 次标记报错并提示用户处理方案。

- **提示词规范强化规则**：提示词需满足"完整性、精准性、一致性、适配性"；核心信息（角色、人设、分镜、风格）需前置；冗余描述占比不超过 10%；同系列提示词的风格/禁止元素/画面规范模块完全复用，仅调整情节相关变量。

- **文字容器规则**：全系列禁用"气泡"，统一使用"方形旁白框"（Rectangular Caption Box）；同一说话人或同一类型文本默认不拆分多个文本框，优先在单框内换行；仅当同一格内出现不同角色对话或不同类型文本时才拆分多个文本框。

- **中文双引号强制规则**：生图提示词中所有文字内容（对话、旁白、内心独白、音效）必须使用**中文双引号** `""`（左引号 `U+201C`，右引号 `U+201D`），**禁止使用英文双引号** `""`（`U+0022`）。这是硬性规范，违反将导致生图模型无法正确渲染文字。

- **草案模式规则**：只有当用户明确要求"一口气生成/草案模式/先把整套文件跑出来"，才允许连续输出多个环节的草案；即便草案模式，也必须在每个环节输出末尾显式标注"待确认"，并提示用户从哪个环节开始回退修改。

- **模板占位符禁用规则**：任何交付给用户的输出物（尤其是《漫画生图提示词.md》）不得包含未替换的模板占位符，包括但不限于 `{风格约束}`、`{负面提示词}`、`{通用负面词}`、`{主设计风格描述}`、`{格子数}`、`{姓名}`、`{角色名}`、`{URL}` 等；一旦检测到占位符，必须回到本环节完成填充后再提交用户确认。

- **全自动化运行模式规则**：
    - **触发条件**（以下任一方式）：
      - 方式一：用户在任意环节确认时输入"2"或"全自动化运行"
      - 方式二：用户在初始输入时包含"全自动化运行"、"后续无需确认"、"自动跑完"、"不用确认直接生成"等明确指令
    - **必要输入**：短文或故事文本仍为必需输入项，AI必须在短文输入环节获取完整文本
    - **运行模式**：
      - 短文输入环节：正常执行，获取短文内容
      - 后续环节：AI自动确认并解锁下一环节，无需用户逐环节确认
      - 每个环节输出后，输出简洁的环节完成提示，立即进入下一环节
    - **输出格式**：
      ```
      ⚡ 全自动化模式运行中...
      
      ✅ 【环节：xxx】已完成
      📁 输出物：xxx.md
      
      ▶ 自动进入下一环节...
      ```
    - **异常处理**：若某环节生图失败或出现错误，暂停自动化运行，提示用户介入处理
    - **记忆记录**：在《项目日志.md》中标记"运行模式：全自动化"

- **死循环防护规则**：
    - **识别条件**：AI检测到对**同一具体目标**（如写入文件A、生成图片B、调用接口C）的重复尝试超过2次仍失败，且每次尝试结果相同或相似
    - **跳出机制**：立即停止当前任务，执行以下自检流程：
      1. **条件自检**：检查是否具备执行下一步任务的条件（如必需文件是否存在、参数是否齐全、依赖是否满足）
      2. **若具备条件**：跳过当前重复任务，继续推进后续流程
      3. **若不具备条件**：退出死循环，向用户说明情况并请求下一步指示
    - **用户提示模板**：
      ```
      ⚠️ 检测到任务执行受阻，已自动跳出循环。
      
      当前状态：[简述已完成的进度]
      阻塞原因：[说明为何无法继续]
      
      请选择下一步操作：
      1. 提供 [缺失的输入/信息]
      2. 跳过当前环节，继续后续流程
      3. 重新开始当前环节
      ```
    - **适用场景**：文件读写失败、生图工具调用异常、参数校验失败等任何可能导致循环的情况

- **连载复用快速通道规则**：
    - **触发条件**：用户上传 `设计方案_连载复用.md` + 新短文
    - **自动复用**：风格设定、角色配置（含形象照URL）
    - **跳过环节**：短文输入（仅合规检测）、角色与风格设定、角色形象照生成
    - **执行环节**：从【环节：分镜脚本规划】开始，需用户确认
    - **提示语识别**：用户输入包含"使用该设计方案"、"按这个方案"、"延续这个系列"等表达时触发

- **帮助咨询触发规则**：
    - **触发条件**：用户输入包含"帮助"、"如何使用"、"怎么用"、"使用方法"、"怎么开始"、"如何开始"、"功能介绍"、"能做什么"等咨询类关键词
    - **输出内容**：见 [help_guide.md](references/help_guide.md)，优先推荐全自动化模式
    - **核心目标**：引导用户快速开始创作

## 默认参数与工具约束
- **文本长度**：50-5000 字。
- **图片分辨率**：默认 2K。
- **图片比例**：默认 3:4（允许用户调整，但同系列需保持一致）。
- **生图工具**：
  - 角色形象照仅使用 `text_to_images`。
  - 条漫图文仅使用 `image_to_images`（必须传入角色参考图数组）。
- **参考图权重**：0.7-0.85（保障角色特征不混淆）。
- **参考图数组组织规则（重要）**：
  - 按【角色定义】块中`@角色名 = 参考图X`的顺序组织参考图URL数组
  - 参考图1对应数组[0]，参考图2对应数组[1]，参考图X对应数组[X-1]
  - 每张漫画页独立组织，不继承上一页的数组
- **负面提示词传递规则**：
  - 提示词文本中不包含负面提示词
  - 调用图生图工具时，负面提示词作为独立参数传入
  - 标准负面提示词：`水印, logo, 糟糕的解剖结构, 肢体缺失, 多余肢体, 畸形, 模糊, 低质量, 裁剪, 最差质量, 丑陋, 变异, 错误的参考图, 角色不一致, 箭头, 角标, 指向标, 对话气泡尾部, 带箭头文本框`

## 核心流程规范 (Standard Execution Model)
本技能分为多个环节，每个环节严格遵循「输入自检 → 任务处理 → 输出自检 → 用户确认 → 记忆流转」的标准子流程。


### 【环节：短文输入与合理性检测】
- **示例参考**：见 [examples_appendix.md](references/examples_appendix.md) 的"【环节：短文输入】输出物示例"。

1.  流程输入与自检
    - **输入物**：[必选] 用户输入的 50-5000 字故事化短文。
    - **自检规则**：
      - 检查是否记得用户短文？若无，提示输入。
      - 检查字数是否在 50-5000 字之间？若否，提示调整。
2.  任务处理（核心执行层）
    - **步骤1：合规性检测**：调用安全接口过滤敏感内容。
    - **步骤2：叙事合理性检测**：依据 **[短文检测与优化规则](references/story_validation_rules.md)** 分析情节/角色/逻辑。**注意：不自动修改原文**，仅生成建议。
    - **步骤3：文档生成**：创建 `短文.md`，包含【短文正文】、【检测报告】和【优化建议文本】。
3.  流程输出与自检
    - **输出物**：`短文.md`。
    - **自检标准**：必须包含正文和检测报告；合规检测必须通过；叙事建议非空。
4.  用户确认与反馈
    - **输出物展示**（用户可见）：
      ```
      ✅ 输出物：
      短文.md
      
      👉 下一环节：角色与风格设定
      
      请选择：
- 回复 1 或 确认 → 进入下一环节（单步模式）
- 回复 2 或 全自动化运行 → 确认本次结果并在后续环节自动运行
      
      【停止生成，等待用户确认】
      ```
    - **自检标准**（内部规范，不输出）：必须包含正文和检测报告；合规检测必须通过；叙事建议非空。
    - **交互形式**（内部规范，不输出）：用户预览 `短文.md`。
    - **用户操作**（内部规范，不输出）：确认通过（采纳优化建议文本，或保留原文并知悉风险），或手动修改正文。
5.  记忆更新与流转
    - **记忆操作**：
      - 创建《项目日志.md》；
      - 写入【环节：短文输入 状态：Done】；
      - 写入【短文摘要】（标题/字数/核心情节）及【《短文.md》引用路径】；
      - **特别记录**：用户在本环节提出的任何偏好（如"希望风格暗黑一点"）或特殊要求。
    - **流转**：解锁【环节：角色与风格设定】。


### 【环节：角色与风格设定】

1.  流程输入与自检
    - **输入物**：`短文.md`。
    - **自检规则**：
      - AI 自检：是否记得短文内容？若不记得，读取《项目日志.md》索引的《短文.md》文件。
      - 判定：若文件缺失，跳转至【环节：短文输入】补充输入；若文件存在，进入【任务处理】步骤。

      - **角色筛选规则**：若某角色仅在 **1个场景** 中出现，不将其设定为配角，也 **不需要为该角色生成角色形象照**。此类角色在分镜提示词中使用通用描述即可，无需参考图绑定。
    - **步骤3：文档生成**：生成 `角色设定表.md`。
3.  流程输出与自检
    - **输出物**：`角色设定表.md`。
    - **自检标准**：风格定义明确；核心角色人设完整（含 5 大要素）。
4.  用户确认与反馈
    - **输出物展示**（用户可见）：
      ```
      ✅ 输出物：
      角色设定表.md
      
      👉 下一环节：角色形象照生成
      
      请选择：
- 回复 1 或 确认 → 进入下一环节（单步模式）
- 回复 2 或 全自动化运行 → 确认本次结果并在后续环节自动运行
      
      【停止生成，等待用户确认】
      ```
    - **自检标准**（内部规范，不输出）：风格定义明确；核心角色人设完整（含 5 大要素）。
    - **交互形式**（内部规范，不输出）：用户检查文字设定。
    - **用户操作**（内部规范，不输出）：确认通过，或调整设定（AI 同步更新文档）。
5.  记忆更新与流转
    - **记忆操作**：
      - 更新《项目日志.md》；
      - 写入【环节：角色设定 状态：Done】；
      - 写入【关键配置摘要】（风格/角色数）及【《角色设定表.md》引用路径】；
      - **特别记录**：用户确认的风格偏好及文字人设修正点。
    - **流转**：解锁【环节：角色形象照生成】。


### 【环节：角色形象照生成】
- **示例参考**：见 [examples_appendix.md](references/examples_appendix.md) 的"【环节：角色形象照生成】输出物示例"。

1.  流程输入与自检
    - **输入物**：`角色设定表.md`，[可选] `设计方案_连载复用.md`（用户提供的既有设计方案）。
    - **自检规则**：
      - AI 自检：是否记得角色文字设定？若不记得，读取《项目日志.md》索引的对应文档。
      - **设计方案复用检测**：检查用户是否提供了 `设计方案_连载复用.md` 或类似的设计方案文档？
        - 若提供了设计方案，提取文档中「角色档案」下的「形象照URL」。
        - 建立「可复用形象照映射表」：`{角色名: 形象照URL}`。
      - 判定：若角色设定文件缺失，跳转至【环节：角色设定】补充设定；若文件存在，进入【任务处理】步骤。
2.  任务处理（核心执行层）
    - **步骤1：形象照复用判定**：
      - 对比 `角色设定表.md` 中的角色列表与「可复用形象照映射表」。
      - **复用规则**：若设计方案中存在同名角色的形象照URL，直接复用该URL，跳过该角色的生图流程。
      - **待生成列表**：整理出无可用形象照的角色列表。
      - 若所有角色均可复用，跳过步骤2-3，直接进入步骤4。
    - **步骤2：提示词构建**（仅针对待生成角色）：使用 **[角色设计指导](references/character_design_guide.md)** 中的"形象照专用模板"构建 Prompt。
      - **核心原则**：一个Prompt = 一张角色形象照（含正面/侧面/背面三视图），禁止生成3张独立图片。
      - **⚠️ 禁止仿真人**：提示词必须包含绘画/插画/漫画风格限定，负面提示词必须包含"仿真人, 真人照片, 写实人物, 真实人脸, 照片级渲染"。
    - **步骤3：形象照生成**（仅针对待生成角色）：调用 `text_to_images` 生成无场景三视图（正面/侧面/背面）。
      - **限制**：强制白底、全身站立、比例 4:3（横版）、**图片数量参数固定为1**、**禁止仿真人风格**。
    - **步骤4：形象照自检**（仅针对新生成的形象照）：使用视觉理解工具检查生成结果：
      - **完整性**：每个核心角色均有自然站立全身三视图（正面/侧面/背面在同一张图中并排展示）。
      - **纯净度**：形象照无多余文字、无复杂背景（仅白底）。
      - **质量**：无破图/多肢体/模糊/畸形。
      - **风格检查**：**必须为绘画/插画/漫画风格，禁止仿真人/真人照片风格**。若检测为仿真人风格，判定为不合格。
      - **异常处理**：若检测不合格，自动重试（最多2次）；连续失败3次标记报错并提示用户处理方案。
    - **步骤5：文档更新**：更新 `角色设定表.md` 中的【形象照】字段：
      - 状态：待生成 → 已生成（复用的形象照标记为「已复用」）
      - 使用markdown图片组件渲染形象照：`![角色名_三视图](图片URL)`
3.  流程输出与自检
    - **输出物**：角色三视图，更新后的 `角色设定表.md`。
    - **自检标准**：每个核心角色均有自然站立全身三视图；形象照无多余文字、背景；无破图/多肢体/模糊；形象照字段已更新状态并渲染图片。
    - **容错机制**：生图失败自动重试2次；连续失败3次标记报错并提示用户处理方案。
4.  用户确认与反馈
    - **输出物展示**（用户可见）：
      ```
      ✅ 输出物：
      角色设定表.md（已更新，含形象照）
      角色形象照
      
      👉 下一环节：分镜脚本规划
      
      请选择：
- 回复 1 或 确认 → 进入下一环节（单步模式）
- 回复 2 或 全自动化运行 → 确认本次结果并在后续环节自动运行
      
      【停止生成，等待用户确认】
      ```
    - **自检标准**（内部规范，不输出）：每个核心角色均有三视图；无破图/多肢体/模糊；形象照字段已更新状态并渲染图片。
    - **交互形式**（内部规范，不输出）：图片预览。
    - **用户操作**（内部规范，不输出）：确认通过，或要求重绘（AI 优化 Prompt 后重试）。
5.  记忆更新与流转
    - **记忆操作**：
      - 更新《项目日志.md》；
      - 写入【环节：角色形象 状态：Done】；
      - 写入【角色设定表引用路径】；
      - **特别记录**：用户对角色形象的视觉修正点。
    - **流转**：解锁【环节：分镜脚本规划】。


### 【环节：分镜脚本规划】
- **示例参考**：见 [examples_appendix.md](references/examples_appendix.md) 的"【环节：分镜脚本规划】输出物示例"。

1.  流程输入与自检
    - **输入物**：`短文.md` (正文), `角色设定表.md` (形象)。
    - **自检规则**：
      - AI 自检：是否记得角色形象和短文内容？若不记得，读取《项目日志.md》索引的对应文档。
      - 判定：若文件缺失，跳转至【环节：角色形象照生成】或【环节：短文输入】；若文件存在，进入【任务处理】步骤。
2.  任务处理（核心执行层）
    - **步骤0：台词提取与映射**（强制执行）：依据 **[方案规划细则·台词提取规则](references/storyboard_planning_rules.md#7-台词提取与映射规则强制执行)** 完成以下操作：
      - 从短文中提取所有对话、内心独白、旁白
      - 标注每句台词的说话者、类型、情绪、情节节点
      - 建立台词→分镜页的映射关系
      - 判定关键台词（P0/P1级别），确保不遗漏
    - **步骤1：图文拆分**：依据 **[方案规划细则](references/storyboard_planning_rules.md)** 将短文拆分为系列条漫页（3-6格/页）。
      - **检查**：确保叙事节奏动静结合。
      - **强制规则**：单张条漫页的各个分镜中，有且最多出现 **3个主要角色人物**，超出需拆分为多页。
    - **步骤2：分镜设计**：规划每页的景别、角度、格子形状、角色站位、台词。
      - **逻辑**：遵循 Z 字形阅读顺序。
      - **台词完整性**：对照映射表，确保所有P0/P1台词已映射到分镜。
    - **步骤3：文档生成**：生成 `分镜脚本规划.md`。
3.  流程输出与自检
    - **输出物**：`分镜脚本规划.md`。
    - **自检标准**：依据 **[方案规划细则·输出前自检清单](references/storyboard_planning_rules.md#9-分镜脚本输出前自检清单强制执行)** 逐项核对：
      - 必需字段完整性（景别/镜头角度/格子形状/角色站位/微场景/时间光影/台词气泡）
      - 台词气泡格式（字段名正确/引号包裹/字数≤30/禁止"无"/层级格式）
      - 角色数量（单页≤3个主要角色）
      - 微场景一致性（场景连贯/细节描述）
      - **台词完整性（P0/P1台词100%覆盖/内容忠实/逻辑连贯/视角正确）**
    - **输出格式**：遵循 **[方案规划细则·标准输出模板](references/storyboard_planning_rules.md#10-分镜脚本标准输出模板强制使用)**。
    - **禁止输出**：所有自检清单的执行过程/结果均属内部运行信息，**不得写入 `分镜脚本规划.md`**，仅在内部核对后输出符合模板的分镜内容。
4.  用户确认与反馈
    - **输出物展示**（用户可见）：
      ```
      ✅ 输出物：
      分镜脚本规划.md
      
      👉 下一环节：分镜提示词工程
      
      请选择：
- 回复 1 或 确认 → 进入下一环节（单步模式）
- 回复 2 或 全自动化运行 → 确认本次结果并在后续环节自动运行
      
      【停止生成，等待用户确认】
      ```
    - **自检标准**（内部规范，不输出）：依据 **[方案规划细则](references/storyboard_planning_rules.md)** 中的各项规范和自检清单核对；输出格式遵循标准输出模板。**所有自检结果均不写入输出文档**。
    - **交互形式**（内部规范，不输出）：分镜列表预览。
    - **用户操作**（内部规范，不输出）：确认通过，或调整分镜内容。
5.  记忆更新与流转
    - **记忆操作**：
      - 更新《项目日志.md》；
      - 写入【环节：分镜规划 状态：Done】；
      - 写入【分镜脚本规划文档引用路径】；
      - **特别记录**：用户对叙事节奏的偏好。
    - **流转**：解锁【环节：分镜提示词工程】。


### 【环节：分镜提示词工程】
- **示例参考**：见 [examples_appendix.md](references/examples_appendix.md) 的"【环节：分镜提示词工程】输出物示例"。

1.  流程输入与自检
    - **输入物**：`分镜脚本规划.md`, `角色设定表.md`, 短文标题, 短文正文。
    - **自检规则**：
      - AI 自检：是否记得角色信息和分镜规划？若不记得，读取《项目日志.md》索引的对应文档。
      - 判定：若文件缺失，返回【环节：分镜规划】或【环节：角色形象照生成】补充；若文件存在，进入【任务处理】步骤。

      - **主标题艺术化**：提取短文标题，与主题元素融合（如飘落的花瓣环绕、蒸汽升腾效果），关键词做强调设计。
      - **吸引语生成（核心）**：从故事中提取一句话情感金句，传递核心主题，打动读者。
      - **角色呈现**：选择1-2个核心角色，设计动态姿态，与标题形成视觉关系（如仰望标题）。

    - **步骤3：校验与优化**：检查 Token 限制，优化冗余（冗余描述占比不超过 10%，风格/禁止元素/画面规范模块同系列复用）。

    - **输出物**：`漫画生图提示词.md`（含封面提示词 + 条漫提示词）。
    - **自检标准**：
      - 封面提示词包含吸引语；条漫提示词数量与分镜一致；包含完整人设/风格/分镜描述；包含负面词。
      - 依据 **[条漫图文生图提示词指导](references/comic_prompt_guide.md)** 中的各项规范和自检清单核对。
    - **禁止输出**：所有自检清单的执行过程/结果均属内部运行信息，**不得写入 `漫画生图提示词.md`**。
4.  用户确认与反馈
    - **输出物展示**（用户可见）：
      ```
      ✅ 输出物：
      漫画生图提示词.md

- 回复 1 或 确认 → 进入下一环节（单步模式）
- 回复 2 或 全自动化运行 → 确认本次结果并在后续环节自动运行
      
      【停止生成，等待用户确认】
      ```
    - **自检标准**（内部规范，不输出）：封面提示词包含吸引语；条漫提示词数量与分镜一致；包含完整人设/风格/分镜描述；包含负面词；各项规范核对通过。**所有自检结果均不写入输出文档**。
    - **交互形式**（内部规范，不输出）：提示词预览。
    - **用户操作**（内部规范，不输出）：确认通过，或手动修改提示词。
5.  记忆更新与流转
    - **记忆操作**：
      - 更新《项目日志.md》；
      - 写入【环节：提示词工程 状态：Done】；
      - 写入【提示词文件引用路径】；
      - 写入【封面吸引语】。
    - **流转**：解锁【环节：系列条漫图文生成】。


### 【环节：系列条漫图文生成】
- **示例参考**：见 [examples_appendix.md](references/examples_appendix.md) 的"【全局记忆】输出物示例"中"【环节：系列条漫图文生成】"记录样式。

1.  流程输入与自检
    - **输入物**：`漫画生图提示词.md`, 角色形象照。
    - **自检规则**：
      - AI 自检：是否获取到提示词文件？
      - 判定：若缺失，返回【环节：分镜提示词工程】生成；若存在，进入【任务处理】步骤。
2.  任务处理（核心执行层）
    - **前置准备**：读取《漫画生图提示词.md》和 **[条漫生成规范](references/comic_generation_specs.md)**，掌握提示词提取方法和工具调用规范。
    - **⛔ 提示词强制使用规则**：依据 **[条漫生成规范·提示词强制使用规则](references/comic_generation_specs.md#2-提示词强制使用规则最高优先级)** 执行：
      - **必须原样使用**《漫画生图提示词.md》中的完整Prompt
      - **禁止**简化、删减、修改提示词内容
      - **禁止**自行重写或仅使用部分提示词
      - 必须**完整提取全部5个模块**：核心指令、风格约束、角色定义、布局蓝图、分镜内容
    - **⛔ 单图多格强制检查**：依据 **[条漫生成规范·单图多格规则](references/comic_generation_specs.md#1-单图多格强制规则最高优先级)** 逐项检查：
      - Prompt格式是否为 `生成1张漫画图，X格分镜...`？
      - 生图数量参数是否为 `1`？
      - 布局蓝图是否描述了多个格子的位置排列？
      - **若任何一项不符合，禁止调用生图工具，需返回提示词工程环节修正。**
    - **步骤1：封面生图**：调用图生图工具（image_to_images），**原样传入**《漫画生图提示词.md》中的封面Prompt，生成数量参数为1。
    - **步骤2：条漫生图**：按顺序逐张调用图生图工具，**原样传入**《漫画生图提示词.md》中各页条漫Prompt，生成数量参数为1。禁止并行生成。
    - **步骤3：容错处理**：单张失败自动重试2次；连续失败3次标记报错并提示用户处理方案。
3.  流程输出与自检
    - **输出物**：漫画封面图 + 系列条漫图文成品。
    - **自检标准**：封面包含标题文字和吸引语；条漫数量与提示词一致；分辨率达标；无崩坏/花屏。
    - **输出展示规范（强制）**：向用户展示系列图文时，必须使用markdown图片组件按顺序罗列渲染，格式如下：
      ```markdown
      ## 漫画封面
      ![封面]({封面图片URL})
      
      ## 系列条漫图文成品
      ![第1张]({图片URL})
      ![第2张]({图片URL})
      ![第3张]({图片URL})
      ```
      禁止仅输出URL链接或文件路径，必须使用 `![描述]({URL})` 语法渲染图片。
4.  用户确认与反馈
    - **输出物展示**（用户可见）：
      ```
      ✅ 输出物：
      漫画封面图
      系列条漫图文成品
      
      💡 温馨提示：
      当前生图模型生成的漫画图有一定的抽卡概率，如有瑕疵可尝试重新生成，或使用本技能输出的【漫画提示词文件】和【角色参考图】用其它生图模型试试（如香蕉模型、MiniMax模型）。
      
      👉 下一环节：设计方案生成
      
      请选择：
- 回复 1 或 确认 → 进入下一环节（单步模式）
- 回复 2 或 全自动化运行 → 确认本次结果并在后续环节自动运行
      
      【停止生成，等待用户确认】
      ```
    - **自检标准**（内部规范，不输出）：封面包含标题文字和吸引语；条漫数量与提示词一致；分辨率达标；无崩坏/花屏。
    - **输出展示规范**（内部规范，不输出）：必须使用markdown图片组件渲染，禁止仅输出URL链接或文件路径。
    - **交互形式**（内部规范，不输出）：画廊预览。
    - **用户操作**（内部规范，不输出）：确认通过，或选择单图重绘。
5.  记忆更新与流转
    - **记忆操作**：
      - 更新《项目日志.md》；
      - 写入【环节：条漫生成 状态：Done】；
      - 写入【封面图片URL】；
      - 写入【图文成品存储路径】；
      - 标记【项目状态：Completed】。
    - **流转**：解锁【环节：设计方案生成】。


### 【环节：设计方案生成】
- **示例参考**：见 [examples_appendix.md](references/examples_appendix.md) 的"【环节：设计方案生成】输出物示例"与"【全局记忆】输出物示例"。

1.  流程输入与自检
    - **输入物**：全流程所有输出物。
    - **自检规则**：
      - AI 自检：是否记得所有核心配置和最终成品？若不记得，遍历读取《项目日志.md》索引的所有文档。
      - 判定：若数据闭环完整，进入【任务处理】步骤；若缺失，提示用户。
2.  任务处理（核心执行层）
    - **步骤1：提取核心配置**：项目名称/代码、风格主基调/色板、封面图设定、条漫设定、角色档案（外貌服饰/参考图URL）。
    - **步骤2：方案生成**：依据 **[设计方案模板](references/design_scheme_template.md)** 生成 `设计方案_连载复用.md`。
3.  流程输出与自检
    - **输出物**：`设计方案_连载复用.md`（精简配置文件）。
    - **自检标准**：
      - 项目信息：名称、创建日期
      - 美术设定：通用设定（主基调、色板、图片比例）、封面图设定（字体风格/效果、情绪氛围、主色调、动感元素）、条漫设定（字体、字色、线条、饱和度、背景底色、分格线）
      - 角色档案：外貌服饰、参考图URL、形象照渲染
      - 连载复用说明
4.  用户确认与反馈
    - **输出物展示**（用户可见）：
      ```
      ✅ 输出物：
      设计方案_连载复用.md
      
      🎉 全流程已完成！
      
      💡 温馨提示：
      当前生图模型生成的漫画图有一定的抽卡概率，如有瑕疵可尝试重新生成，或使用本技能输出的【漫画提示词文件】和【角色参考图】用其它生图模型试试（如香蕉模型、MiniMax模型）。
      ```
    - **用户操作**（内部规范，不输出）：下载保存，或开始新创作。
5.  记忆更新与流转
    - **记忆操作**：归档项目，释放临时显存/上下文资源。
    - **流转**：流程结束。
