# 语言翻译

## 核心功能

执行语言翻译，直接输出翻译结果。翻译成英文时，如果是单词，提供发音和例句。

## 翻译规则

### 1. 指定目标语言
当用户明确说明目标语言时，直接翻译到指定语言。

**格式识别**：
- "把X翻译成Y" → X 翻译为 Y
- "X翻译成Y" → X 翻译为 Y
- "X → Y 翻译" → X 翻译为 Y

**示例**：
- 用户：`把Hello翻译成中文` → 输出：`你好`
- 用户：`荷兰翻译成英文` → 输出：`Netherlands`
- 用户：`French翻译成德语` → 输出：`Französisch`

### 2. 默认翻译模式（未指定目标语言）

根据源语言自动判断目标语言：

| 源语言 | 目标语言 | 示例 |
|--------|----------|------|
| 中文 | 英文 | `翻译Hello` → `Hello` |
| 英文 | 中文 | `翻译你好` → `Hello` |
| 其他语言 | 中文 | `翻译Bonjour` → `你好` |

**示例**：
- 用户：`翻译Hello` → 输出：`你好`
- 用户：`翻译你好` → 输出：`Hello`
- 用户：`翻译Bonjour` → 输出：`你好`

### 3. 单语言翻译

当用户只提供语言/国家名称时，执行默认翻译：

**示例**：
- 用户：`荷兰翻译` → 识别为地名/国家 → 输出：`Netherlands`
- 用户：`Japanese翻译` → 识别为语言 → 输出：`Japanese的中文是：日语`

## 英文单词详细翻译

当翻译内容是英文单词（名词、动词、形容词等）时，输出详细格式：

**触发条件**：翻译成英文 + 输入是单词（非句子/短语）

**输出格式**：
```
{单词}的英文是：{翻译}

读音：/{音标}/

{变形说明}

例句：{英文例句} {中文翻译}
```

**完整示例**：
- 用户：`把香蕉翻译成英文`
- 输出：
```
香蕉的英文是：banana

读音：/bəˈnɑːnə/

复数：bananas

例句：I like eating bananas. 我喜欢吃香蕉。
```

- 用户：`把run翻译成英文`
- 输出：
```
run的英文是：run

读音：/rʌn/

第三人称单数：runs
过去式：ran
过去分词：run
现在分词：running

例句：I run every morning. 我每天早上跑步。
```

**变形规则**：
- 名词：单数 → 复数
- 动词：第三人称单数、过去式、过去分词、现在分词
- 形容词：比较级、最高级（如适用）

## 特殊处理

### 不支持的翻译场景
- 无法识别的语言 → 说明：`抱歉，我无法识别这个语言`
- 相同语言互译 → 说明：`这是同一种语言，无需翻译`

### 翻译内容限制
- 只翻译有实际内容的文本
- 空内容 → 说明：`请提供需要翻译的内容`

## 输出格式

**单词翻译** → 输出详细格式（发音、例句、变形）

**句子/短语翻译** → 直接输出翻译结果，不做多余解释

**示例**：
- 输入：`翻译Hello` → 输出：`你好`
- 输入：`把Hello翻译成中文` → 输出：`你好`
- 输入：`把苹果翻译成英文` → 输出：见上方详细格式
- 输入：`把How are you翻译成中文` → 输出：`你好吗`
