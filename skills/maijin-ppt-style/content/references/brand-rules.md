# 品牌PPT风格规则库

## 规则概述

本文档定义了系统中所有品牌PPT风格的自动激活规则，确保在涉及特定品牌PPT设计时自动调用对应的视觉形象规范技能。

---

## 一、迈金PPT风格规则（优先级：高）

### 1.1 激活条件

当用户的请求包含以下任一关键词或场景时，自动激活"迈金PPT风格"技能：

| 触发类型 | 关键词/场景 |
|---------|-----------|
| 品牌名称 | 迈金、Magene、迈金科技 |
| PPT相关 | 迈金PPT、迈金演示、迈金幻灯片 |
| 风格相关 | 迈金风格、迈金VI、迈金品牌 |
| 语义场景 | 迈金公司演示、为迈金制作PPT、迈金品牌形象 |

### 1.2 执行规范

激活后必须执行以下操作：

#### (1) 加载技能文档
从技能文档加载完整规范

#### (2) 应用色彩体系

| 色彩类型 | 色值 | 用途 |
|---------|------|------|
| 强调色 | `#FF4D00` (迈金橙) | 重点强调、按钮、图标、装饰线 |
| 主文字色 | `#1A1A1A` (深灰) | 标题、主要文字 |
| 辅助文字色 | `#666666` (中灰) | 正文、次要文字 |
| 背景色 | `#FFFFFF` (白色) | 主背景 |

#### (3) 应用字体规范

| 文字类型 | 中文字体 | 英文字体 | 字重 |
|---------|---------|---------|------|
| 主标题 | Microsoft YaHei | Arial | Bold (700) |
| 副标题 | Microsoft YaHei | Arial | Medium (500) |
| 正文 | Microsoft YaHei | Arial | Regular (400) |
| 说明文字 | Microsoft YaHei | Arial | Light (300) |

#### (4) 应用版式规范

| 规范项 | 要求 |
|--------|------|
| 标志位置 | 左上角（首选）或右上角 |
| 标志边距 | 0.5个图形标志高度 |
| 标题对齐 | 与标志保持左侧对齐 |
| 主标题上沿 | 与标志保持一个图形标志高度距离 |
| 安全边距 | 四周 5% |
| 行距 | 1.5倍行距 |
| 段落间距 | 字号 2倍 |

#### (5) 标志应用规则

根据背景色选择合适的标志样式：

| 背景色 | 标志样式 |
|--------|---------|
| 白色/浅色背景 | 深灰色或黑色单色标志 |
| 深色背景 | 白色镂空单色标志 |
| 红橙背景（m值>50, y值100） | 必须使用白色镂空效果 |
| 灰色背景 | 白色或深灰色单色标志 |

### 1.3 禁止事项（必须严格遵守）

#### 标志使用禁止

❌ 更改标志任何元素
❌ 在标志中添加任何元素
❌ 将标志置入框架中
❌ 轮廓化标志或描边
❌ 拉伸标志或将其变形
❌ 立体化或添加投影
❌ 在图标内添加内容
❌ 随意组合图标及文字
❌ 更改图标外观或透明度
❌ 将图标渐变处理
❌ 将标志置放在相近色相底图
❌ 镜像或翻转图标
❌ 标志尺寸小于最小限制（屏幕端24px，印刷端4mm）

#### 设计规范禁止

❌ 使用非迈金品牌色彩
❌ 使用非规定字体
❌ 破坏标志安全区域
❌ 标题与标志不对齐

### 1.4 质量检查清单

设计完成后必须验证：

- [ ] 主色调使用迈金橙 `#FF4D00`
- [ ] 主文字使用深灰色 `#1A1A1A` 或 `#373A36`
- [ ] 强调色面积不超过页面总面积 20%
- [ ] 中文使用Microsoft YaHei，英文使用Arial
- [ ] 标题使用Bold字重，正文使用Regular字重
- [ ] 标志位于左上角（首选）
- [ ] 标题与标志左侧对齐
- [ ] 四周安全边距 5%
- [ ] 使用官方提供的标志文件
- [ ] 无任何禁止的标志使用行为

## 二、规则优先级

| 优先级 | 规则类型 | 说明 |
|--------|---------|------|
| 1 | 品牌保护规则 | 标志使用规范优先于所有其他规则 |
| 2 | 色彩规范 | 品牌色彩必须严格遵守 |
| 3 | 字体规范 | 品牌字体必须严格遵守 |
| 4 | 版式规范 | 基础版式规范优先于创意设计 |

## 三、异常处理

### 未找到标志文件

如果无法获取迈金官方标志文件：
1. 使用文字标志"迈金科技"作为替代
2. 避免使用任何图形标志
3. 确保文字清晰可读

### 特殊场景处理

对于以下特殊场景，在保持品牌一致性的前提下可适当调整：
1. 视频演示：考虑动效和转场
2. 长图：保持竖版比例适配
3. 印刷品：确保300dpi以上分辨率
