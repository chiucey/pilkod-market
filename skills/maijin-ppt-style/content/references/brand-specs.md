# 迈金品牌PPT视觉规范详细文档

## 一、品牌色彩体系

### 1.1 主色调

| 颜色名称 | HEX值 | RGB值 | CMYK值 | 用途 |
|---------|------|-------|--------|------|
| 迈金橙 | #FF4D00 | RGB(255,77,0) | C0 M70 Y100 K0 | 重点强调、按钮、图标、装饰线 |
| 深灰色 | #1A1A1A | RGB(26,26,26) | C0 M0 Y0 K90 | 主标题、主要文字 |
| 中灰色 | #666666 | RGB(102,102,102) | C0 M0 Y0 K60 | 正文、次要文字 |
| 白色 | #FFFFFF | RGB(255,255,255) | C0 M0 Y0 K0 | 主背景 |

### 1.2 辅助色彩

| 颜色名称 | HEX值 | RGB值 | 用途 |
|---------|------|-------|------|
| 浅杏色 | #EFC2B3 | RGB(239,194,179) | 辅助背景、装饰色 |
| 深蓝色 | #051C2C | RGB(5,28,44) | 强调色、标题 |
| 棕色 | #503624 | RGB(80,54,41) | 辅助装饰 |
| 紫色 | #3D1152 | RGB(61,17,82) | 特殊强调 |
| 墨绿色 | #1A3C34 | RGB(26,60,52) | 辅助装饰 |
| 浅灰 | #A7A8AA | RGB(167,168,169) | 次要文字、辅助元素 |
| 中灰 | #D9D8D6 | RGB(217,216,214) | 背景、分隔线 |

### 1.3 强调色使用指南

- **迈金橙 #FF4D00**: 用于重点强调、按钮、图标、装饰线
- **使用比例**: 强调色面积不超过页面总面积的20%
- **使用位置**: 标题装饰、图标强调、分隔线、按钮

## 二、字体规范

### 2.1 中文字体

| 字体名称 | 字重 | 用途 |
|---------|------|------|
| Microsoft YaHei | Bold (700) | 主标题、重点强调 |
| Microsoft YaHei | Medium (500) | 副标题 |
| Microsoft YaHei | Regular (400) | 正文 |
| Microsoft YaHei | Light (300) | 说明文字、注释 |

### 2.2 英文字体

| 字体名称 | 字重 | 用途 |
|---------|------|------|
| Arial | Bold | 主标题、强调 |
| Arial | Medium | 副标题 |
| Arial | Regular | 正文 |
| Arial | Light | 说明文字、注释 |

### 2.3 排版规范

- **行距**: 建议使用字体行高的1.5倍行距
- **段落间距**: 段落间的上下字距为字号的2倍
- **标题与正文间距**: 至少保持字号大小

## 三、版式规范

### 3.1 标准尺寸

| 类型 | 尺寸 | 比例 |
|------|------|------|
| 线上物料 | 1920×1080px | 16:9 |
| 竖版海报 | 1080×1920px | 9:16 |
| 印刷物料 | 210mm×285mm | A4竖版 |

### 3.2 标志位置规则

- **首选位置**: 左上角
- **备用位置**: 右上角、左下角、右下角
- **距离边沿**: 标志距版面边沿分别为0.5个"图形标志高度"

### 3.3 标题区域规范

| 规范项 | 要求 |
|--------|------|
| 主标题上沿与标志距离 | 至少保持一个"图形标志高度" |
| 主标题与主画面下沿距离 | 至少保持一个"图形标志高度" |
| 标题对齐 | 主标题、副标题、子标题与标志保持左侧对齐 |

### 3.4 安全区域

- **印刷物料**: 四周保留5mm安全边距
- **屏幕显示**: 四周保留5%安全边距

## 四、质量检查清单

设计完成后必须验证：

- [ ] 主色调使用迈金橙 #FF4D00
- [ ] 主文字使用深灰色 #1A1A1A
- [ ] 强调色面积不超过页面总面积20%
- [ ] 中文使用Microsoft YaHei，英文使用Arial
- [ ] 标题使用Bold字重，正文使用Regular字重
- [ ] 标志位于左上角（首选）
- [ ] 标题与标志左侧对齐
- [ ] 四周安全边距5%
- [ ] 使用官方提供的标志文件
- [ ] 无任何禁止的标志使用行为
