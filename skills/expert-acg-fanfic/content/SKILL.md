技能文档：二次元同人小说创作专家（番茄·起点双平台）
格式：纯文本参考版
■ 技能简介
专门创作二次元/ACG同人小说，覆盖番茄小说「动漫衍生」频道与起点中文网「二次元」频道。
适用题材：日漫同人（鬼灭/咒术/海贼/火影/龙珠/进击等）、国漫同人（斗罗/斗破/完美世界等）、
游戏同人（原神/崩坏/明日方舟/Fate等）、轻小说同人（Re0/刀剑/盾勇等）。
核心原则：原著还原 > 创新脑洞 > 套路爽文。OOC是同人创作的死刑判决。

■ 三、同人小说六大类型及写作规范
【类型一：原著向·改命改写】
定义：在原著时间线基础上，主角（穿越/重生/获得能力）改变原著悲剧
核心卖点：弥补读者意难平
写作规范：
- 必须严格遵守原著时间线和事件顺序
- 改变的蝴蝶效应要合理展开
- 不能一步到位改变所有悲剧，要有过程
- 每次改命成功都要有原著对照（"原著中他死在了这里"）
【类型二：穿越型·异世界融入】
定义：现代人/其他世界的人穿越到ACG世界
核心卖点：信息差+代入感
- 主角不能一上来就无敌，需要适应期
- 知道剧情是优势但不是万能的（蝴蝶效应）
- 要融入世界观而不是凌驾于世界观之上
- 主角对原著角色的态度要有层次（不是一见面就称兄道弟）
【类型三：AU架空型】
定义：保留原著角色人设，但置于全新世界观中
常见AU类型：
- 现代AU：古代/异世界角色放到现代
- 校园AU：角色们是同学
- 职场AU：角色们在现代职场
- 古代AU：现代角色放到古代
- 星际AU：宇宙/太空背景
- 核心：角色性格必须保留，环境可以完全改变
- AU不是随意捏造，要找到角色性格在新环境中的合理表现
- 世界观虽新但要有内在逻辑
- 不能因为AU就随意OOC
【类型四：前传续篇型】
定义：为原著创作前传或续篇
- 与原著衔接必须无缝
- 前传：补充原著未展开的背景
- 续篇：基于原著结局继续发展
- 不能推翻原著已有的设定
【类型五：平行世界型】
定义：保留部分原著设定，但走向完全不同的时间线
与AU的区别：平行世界保留原著世界观，只是事件走向不同
- 需要明确的分歧点（"如果XX没有发生"）
- 分歧后的蝴蝶效应要逻辑清晰
- 角色在新时间线中的成长要有说服力
【类型六：跨界联动型】
定义：两个或多个不同作品的角色/世界观融合
热门联动：鬼灭×迪迦、咒术×一拳、海贼×火影
- 需要找到两个世界观的"接口"
- 战力体系必须有一方做出调整
- 角色互动要有趣但不能贬低任何一方
- 联动要有意义（不是为了联动而联动）
■ 四、OOC防控体系（同人创作最高法则）
OOC（Out Of Character）是同人创作的死刑判决。读者来看同人，核心需求就是"看到我喜欢的角色"。
一旦OOC，读者会立刻弃书并在评论区差评。
【OOC三级判定标准】
一级OOC（致命）：角色做出完全违背核心性格的行为
例：冷酷反派突然变得温柔善良、胆小角色突然英勇无畏
→ 必须删除重写，没有任何补救余地
二级OOC（严重）：角色行为可理解但表达方式不对
例：傲娇角色的傲没有了只有娇、毒舌角色变得温和
→ 需要修改对白和行为描写，保留核心性格
三级OOC（轻微）：角色行为合理但语气/习惯不对
例：口头禅用错、说话节奏不符、动作习惯不一致
→ 可以通过修改细节修复
【OOC防控四步法】
第一步：角色核心三要素表
每个重要角色必须建立：
- 核心性格（不可改变的底色）：如"嘴硬心软""绝对理性""守护本能"
- 行为模式（遇到问题的反应方式）：如"先动手再说话""先分析再行动"
- 语言风格（说话方式和口头禅）：如"嘛""草""在下""本大爷"
第二步：场景代入测试
写完一个角色的对白/行为后，问自己：
"如果原作作者看到这段，他会觉得这个角色说出来/做出来是合理的吗？"
如果答案是"不确定"，就修改到确定为止。
第三步：原著对标法
遇到不确定的角色反应时，翻原著找到类似场景：
"原著中这个角色遇到类似情况时是怎么反应的？"
以此为基准来写当前场景。
第四步：读者视角检查
想象自己是最挑剔的原著粉丝：
"这段有没有让我觉得'这不是他/她会说的话/做的事'的地方？"
有就改，没有就过。
■ 五、金手指设计规范（同人专属）
同人小说的金手指与原创不同——核心在于"如何利用信息差和新能力改变原著走向"。
【金手指六种类型】
类型一：剧情预知型
主角知道原著剧情走向，可以提前布局
优势：读者也能获得"我知道接下来会发生什么"的上帝视角快感
限制：蝴蝶效应会让剧情偏离原著，预知优势递减
写法：前期靠预知碾压，中后期剧情偏离后靠实力和智慧
类型二：系统辅助型
主角获得系统，通过任务获得能力/道具
优势：升级线清晰，爽感直接
限制：系统不能太万能，要有规则和代价
写法：系统能力不能碾压原著最强角色，要有成长空间
类型三：血脉觉醒型
主角拥有特殊血脉/体质，在原著世界中有独特优势
优势：与原著战力体系自然融合
限制：不能凭空发明不存在的血脉设定
写法：在原著已有设定的基础上延伸
类型四：穿越继承型
主角穿越后继承了某个角色的能力/记忆
优势：身份感强，读者代入感好
限制：继承的能力不能太离谱
写法：主角需要学习和适应继承的能力
类型五：道具强化型
主角获得来自其他世界的道具/武器
优势：跨界感强，新鲜感足
限制：道具能力要有上限，不能碾压一切
写法：道具可以是优势但不能是唯一依赖
类型六：改命重生型
主角本身就是原著角色，重生回关键时间点
优势：角色认同感最强，改命动力最足
限制：重生后不能突然变全能
写法：保留前世的经验和记忆，但身体/能力需要重新积累
■ 六、战力体系借用与扩展规范
【核心原则】
同人的战力体系必须基于原著，可以扩展但不能推翻。
【用户自创体系·最高优先级】
若用户在具体创作项目中已建立自创体系（如自创呼吸法/自创修炼路线/自创技能树），
则该自创体系为当前项目的"项目宪法"，所有规范以此体系为准绳——
即：用户自创设定 > 本skill规范 > 默认原著设定。
这是为了保证创意一致性和项目自洽。
【借用规则】
1. 原著战力等级必须严格遵守
   鬼灭：柱级 > 甲级 > ... > 癸级（呼吸法剑技）
   咒术：特级 > 一级 > 二级 > 三级 > 四级（术式+领域）
   海贼：四皇级 > 大将级 > 中将级（霸气+果实）
2. 跨界联动的战力换算
   必须明确谁强谁弱的逻辑依据
   不能"A世界的最强者碾压B世界的最强者"没有理由
   建议：以破坏力/速度/耐久三个维度做量化对比
3. 原创能力的边界
   可以设计新招式，但不能超出该体系的能力范围
   鬼灭可以创新呼吸法的衍生技，但不能让呼吸法飞天遁地
   咒术可以设计新术式，但术式必须有明确的代价和限制
■ 七、感情线设计（同人专属）
【同人感情线三原则】
原则一：CP向必须在标题或简介中明确标注
读者对CP有极强偏好，不标注会导致读者进入后发现不是自己想看的CP然后差评
标注方式：标题带CP名（"五条悟×你"）或简介明确写BG/BL/GL
原则二：感情线不能OOC
角色的感情表达方式必须符合其性格
冷酷角色不会突然说情话，傲娇角色不会直接表白
感情的推进要符合角色的行为逻辑
原则三：原著感情线的处理
如果原著有官配：要么尊重官配，要么在AU中替换
如果原著没有官配：可以自由发挥但要合理
不能贬低原著中的其他角色来抬高自己的CP
【同人感情线常见写法】
写法一：日常互动积累
通过日常小事展现两人之间的默契和暧昧
适合：慢热型感情线，读者喜欢看的"暗糖"
写法二：共患难建立羁绊
通过共同战斗/面对危机建立深厚感情
适合：热血向同人，感情线服务于主线
写法三：命运纠葛
利用原著中的命运设定，让两人产生宿命般的联系
适合：虐向同人，读者想看的"命中注定"
■ 八、平台适配规范
- 标题格式：「原著名：一句话概括」（如"鬼灭之刃：开局获得呼吸法全精通"）
- 开篇节奏：300字出冲突，1000字出金手指
- 对话占比：≥60%
- 每段字数：≤3行（适配听读）
- 更新频率：日更5~10章
- 避坑：不能出现原著没有的设定、不能抄袭其他同人作品
- 标题格式：更自由，可以不用带原著名
- 开篇节奏：3000字内完成世界观建立+金手指亮相
- 对话占比：≥40%
- 每段字数：适中，5~8行
- 更新频率：日更2~3章
- 避坑：设定必须严谨、不能有明显逻辑漏洞
■ 九、避坑指南
坑1：OOC（最致命）
→ 解决：建立角色三要素表，每段对白过OOC检查
坑2：战力崩坏
→ 解决：严格遵守原著战力体系，越级战斗必须有充分理由
坑3：剧情抄袭原著
→ 解决：同人是二创不是复述，必须有新东西（新视角/新选择/新结局）
坑4：金手指太强导致无张力
→ 解决：金手指必须有代价和限制，不能碾压一切
坑5：CP争议
→ 解决：标题/简介明确标注CP向，不搞暧昧不清
坑6：设定自相矛盾
→ 解决：写之前整理原著设定清单，写作过程中随时对照
坑7：开局信息量过大
→ 解决：同人读者已经熟悉原著，不需要重新介绍世界观
→ 但需要简要交代"这个世界和原著有什么不同"
坑8：忽视原著粉丝情感
→ 解决：尊重原著角色，不要恶意贬低/丑化任何角色
→ 读者喜欢的角色你不喜欢，不代表你可以随便写崩
技能文档结束
■ 十、影视同人创作（电视剧/电影/国产剧）
【为什么影视同人是蓝海？】
2024-2025年爆款国产剧：
《狂飙》《繁花》《庆余年》《琅琊榜》《长相思》《苍兰诀》
《去有风的地方》《我的人间烟火》《你是我的荣耀》《偷偷藏不住》
这些剧完结后，读者会自发寻找"更多故事"——这是同人创作的最佳时机。
【影视同人的三大核心优势】
① 自带流量：剧在播期间，每天有几百万人搜索相关词
② 情感基础：观众对角色有深厚感情，等待"更多内容"
③ 创作空间：国产剧通常40集，有大量留白可以填充
【影视同人写作规范】
① 必须标注改编来源
→ 简介中明确："本文纯属同人创作，不针对原作"
→ 不能声称自己是原作
② 人物性格严格遵循剧版
→ 国产剧演员塑造的角色已经是"人设"的一部分
→ 不能把角色写成演员本人
③ 不能影射现实
→ 不要在同人里涉及真实地名/真实人物
→ 涉及政治/历史题材的剧要格外小心
【影视同人的热门方向】
方向一：前传/番外
→ 写剧里没有交代的角色过去
→ 例：《狂飙》高启强年轻时候的故事
→ 优势：读者已知结局，更关注"为什么会变成这样"
方向二：平行世界
→ 例：如果高启强没有遇到安欣
→ 优势：同一个角色，不同的可能性
方向三：CP续写
→ 剧中CP的后续故事
→ 例：《长相思》小夭×涂山璟婚后生活
→ 优势：读者对CP感情投入深，愿意付费看后续
方向四：角色个人视角
→ 以某个配角的视角重写主线
→ 例：《繁花》以宝总前女友视角重写
→ 优势：同一故事，不同视角，完全不同的体验
■ 十一、漫画同人创作
【日漫同人的特殊优势】
① 画面感强：读者已经看过动画/漫画，有极强的视觉记忆
② 设定明确：分镜/场景/台词都是已经存在的素材
③ 读者年龄层：18~30岁，有消费能力
【漫画同人分类】
① 动画改编同人
→ 基于动画版，有动画制作组设定的二次创作
→ 注意：动画有时会对漫画做改编，两者设定可能冲突
② 漫画原著同人
→ 直接基于漫画原作
→ 设定更原始，但读者基础相对动画观众更小
③ 条漫/四格同人
→ 短篇四格/条漫形式，轻松搞笑向
→ 适合微博/小红书传播，但不适合长篇
【漫画同人写作要点】
① 保留漫画语言的节奏感
→ 漫画有分镜，对话短促有力
→ 翻译成文字时，对话要保持这种节奏
② 利用漫画的画面优势
→ 漫画读者习惯"看图"，文字描写要更有画面感
→ 名场面要能用文字还原
③ 漫画式心理描写
→ 漫画有"内心OS泡泡"，文字版要把内心独白写得更有趣味
→ 可以用括号内的心理独白（像漫画泡泡一样）
■ 十二、小说原作同人（晋江/起点/纵横）
【网络小说同人的特殊性】
晋江/起点等平台的小说IP，已经有了大量读者基础。
晋江热门IP同人：
《天官赐福》《魔道祖师》《默读》《破云》《撒野》
【小说同人vs漫画/影视同人的核心差异】
① 读者基础不同
→ 晋江读者：深度粉丝，对角色感情极深
→ 动漫观众：视觉记忆为主，情感相对较浅
② 创作自由度不同
→ 小说文字想象空间大，同人可以更天马行空
→ 但粉丝对角色"人设"的要求也更严格
③ 语言风格不同
→ 网络小说有独特的语言风格（晋江风/起点风）
→ 同人要符合平台文风
【小说同人写作要点】
① 熟悉原作语言风格
→ 晋江风：细腻、文艺、有留白
→ 起点风：爽、快、节奏强
→ 不能混搭不同平台的语言风格
② 尊重原作的感情表达
→ 晋江/起点以感情戏为主
→ 同人的感情表达要符合原作基调
③ 原创剧情必须有新意
→ 如果只是复述原作剧情，读者会直接看原作
→ 同人必须提供原作没有的新东西
■ 十三、游戏同人创作（2025-2026年最新）
【游戏同人的独特魅力】
游戏读者是"深度玩家"——他们对游戏的了解程度远超其他IP的受众。
2025年热门游戏同人IP：
《原神》《崩坏：星穹铁道》《明日方舟》《Fate/Grand Order》
《赛博朋克2077》《艾尔登法环》《黑神话悟空》
【游戏同人的三大类型】
① 角色故事补完型
→ 写游戏中没有详细展示的角色背景故事
→ 例：原神各角色传说任务之外的故事
→ 优势：玩家渴望了解自己喜爱的角色
② 新篇章型
→ 主角进入游戏世界观，开始新冒险
→ 例：《明日方舟》罗德岛的新干员
→ 优势：新鲜的代入感，新的可能性
③ 穿越型
→ 游戏角色穿越到现实/其他世界
→ 例：角色来到现代都市，会发生什么？
→ 优势：反差萌，跨界喜剧
【游戏同人写作规范】
① 游戏数值体系必须准确
→ 原神的元素反应（蒸发/融化/超导等）必须准确
→ 崩坏星穹的命途体系必须准确
→ 数值写错会被玩家吐槽
② 游戏角色语音/语气要还原
→ 角色的口头禅和语气在游戏中已经固定
→ 写同人时必须保持一致
③ 不能超出游戏已有设定
→ 游戏IP的角色能力有上限
→ 不能在同人里给角色凭空增加游戏没有的能力
【明日方舟同人特别规范】
方舟同人的特殊之处：
→ 感染者/非感染者身份冲突是核心矛盾
→ 博士（玩家）是"指挥官"身份
→ 角色没有"等级"，但有"精英化"阶段
■ 十四、原创二次元创作（超越同人的创作）
【什么是原创二次元？】
原创二次元 = 借用ACGN的文化元素/审美/风格，但不是任何特定IP的同人。
作品特征：
→ 有ACGN风格的美术/叙事风格
→ 但角色和世界观是100%原创的
→ 在起点二次元频道/刺猬猫/菠萝包轻小说平台发布
【原创二次元的魅力】
① 无限自由度：
→ 不受任何IP限制，可以随意创造
→ 作者可以完全掌控自己的世界
② IP价值潜力：
→ 优秀的原创二次元可以成为IP
→ 有改编动画/漫画/游戏的潜力
③ 粉丝积累：
→ 原创角色做起来了，粉丝对角色的感情可以很深
【原创二次元写作要点】
① ACGN文化元素的融合
→ 轻小说风格叙事
→ 萌系角色设计
→ 跨界混搭（科幻+奇幻+日常）
② 角色设计的"萌点"体系
→ 萌点 = 让人喜欢的特质
→ 常见萌点：反差萌/傲娇/天然呆/腹黑/阳光等
→ 一个角色要有2~3个萌点，不能全是优点
③ 轻松日常与主线并重
→ 二次元读者喜欢看日常（轻喜剧）
→ 但也要有主线冲突
→ 日常服务于人物塑造，主线服务于情节推进
④ 世界观要有"独特性"
→ 不是简单的"异世界冒险"
→ 要有独特的设定切入点
【2025-2026年原创二次元热门方向】
方向一：综漫穿越
→ 主角穿越到多个动漫世界的综漫
→ 起点/刺猬猫平台非常火
→ 关键：要有自己的主线（金手指/身份），不是简单的番名串联
方向二：恋爱喜剧
→ 轻小说风格的校园恋爱喜剧
→ 萌系角色+轻喜剧日常+适度恋爱
→ 关键：角色萌点要鲜明，剧情要有反套路
方向三：异世界冒险
→ 日系异世界轻小说
→ 类《蜘蛛子》《史莱姆》风格
→ 关键：金手指要有独特性，不能是万能系统
方向四：赛博朋克/近未来
→ 科技感+二次元风格
→ 《赛博朋克：边缘行者》带起来的热潮
→ 关键：科幻设定要硬核，二次元风格要保持
■ 十五、OOC深度防控进阶手册
【为什么OOC在跨媒介创作中更难？】
影视同人的OOC比动漫同人更难：
→ 观众对演员演绎的角色有强烈印象
→ "这个角色在电视剧里不是这样的"会成为吐槽点
漫画同人的OOC比动漫同人更难：
→ 漫画是静态的，读者想象空间更大
→ "他/她应该长这样"比"他/她这样说才对"更难纠正
【OOC的四个层次】
层次一：性格OOC（最严重）
→ 角色做出完全不符合性格的行为
→ 例：高启强突然变得善良正直
层次二：动机OOC（严重）
→ 角色的行为动机不符合其背景
→ 例：一个贪婪的商人突然为了正义放弃利益
层次三：语言OOC（中等）
→ 角色的说话方式不符合其身份
→ 例：古代将军说"内卷"
层次四：细节OOC（轻微）
→ 口头禅/小动作/穿着打扮与原著不符
→ 例：五条悟平时戴墨镜的习惯被忽略
【OOC防控的三道关卡】
第一关：写前检查
→ 在动笔前，写下这个角色绝对不会做的三件事
→ 写的时候对照检查
第二关：写后朗读
→ 把角色的对白读出声
→ 读的时候想象演员/声优在演
→ 如果读出来"不像"，就改
第三关：粉丝视角
→ 想象最挑剔的粉丝看到这段会有什么反应
→ 有任何"这不像他/她"的感受，就改
【OOC的紧急补救措施】
已经写了OOC内容怎么办？
补救一：补设定
→ 在OOC内容前加一段解释
→ "他在极端情况下做出了这个选择，是因为……"
补救二：转视角
→ 把OOC内容归因于"信息差"
→ "他/她不知道，所以这样做了"
→ 但不能频繁使用这个方法
补救三：直接删除重写
→ 如果OOC内容严重影响角色
→ 最靠谱的方法就是删除重写

无OOC（三层次全部一致），感情线有进展，主线推进有逻辑，配角有独立性格，跨次元设定有平衡。

OOC深度防控核心细则：原角色性格决定行为逻辑，改变原角色必须有充分理由。不ooc的核心是保持原角色的核心特质（鸣人的羁绊，佐助的骄傲，路飞的橡皮，索隆的坚韧）。OOC检测五步法（第1步检查语言是否与角色说话方式一致，第2步检查行为是否与角色性格一致，第3步检查选择是否与角色价值观一致，第4步检查与其他角色的关系是否与原作一致，第5步检查在压力下的反应是否与角色一致）。

### 案例一：LOFTER鬼灭之刃同人（万赞）

**类型：** 炭治郎×祢豆子亲情向  
**字数：** 3万字短篇  
**点赞：** 12000+

**拆解：**
1. 开篇直接切入"如果祢豆子没有变成鬼"的平行世界，省去背景说明
2. 用"便当盒"作为情感锚点（日常物件承载深厚感情，OOC防控的最佳实践）
3. 结尾留白——兄妹对视，不写对话，让读者自行填充情感
4. 全文无一处"说教式"表达，情感全部通过行为和细节传递

**可复用技法：** 平行世界设定+日常物件情感锚点+留白结尾

### 案例二：AO3原神同人（Kudos Top 100）

**类型：** 钟离×公子（达达利亚）  
**字数：** 8万字长篇  
**Kudos：** 5000+

**拆解：**
1. 双线叙事：现代线（日常甜饼）+ 古代线（仙侠虐恋），每章交替
2. 角色语言风格截然不同——钟离古风用语vs公子直球表达，语言即人设
3. 战斗场景融合两人元素反应机制（岩+水），读者直呼"像在玩游戏"
4. 每章结尾有"下章预告"式的短句，提升追更率

**可复用技法：** 双线交替叙事+语言即人设+游戏机制融入战斗

### 案例三：B站转载火影同人（播放50万+）

**类型：** 宇智波鼬视角的短篇  
**形式：** 文字视频（配BGM+截图）  
**播放：** 50万+

**拆解：**
1. 全篇以鼬的第一人称独白展开（原著几乎没有的视角，天然高关注度）
2. 每段独白对应一个原著关键节点，时间线与正作完美对齐
3. 结尾回到鼬临终前的微笑，与开篇呼应，形成情感闭环
4. BGM选择《哀と悲》——读者"听到音乐就想哭"

**可复用技法：** 稀缺视角切入+原著时间线锚定+音乐协同情感爆发
