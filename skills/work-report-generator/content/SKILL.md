# 工作汇报生成器

智能将用户输入的零散工作事项，转化为5种专业汇报风格的完整文本。

## 核心能力

1. **多风格生成**：支持结构化输出、OKR对齐、向上管理、STAR法则、自然表达5种汇报范式
2. **内容密度控制**：详细展开（800-1500字）或精简概述（200-400字）
3. **批量对比**：一键生成所有风格版本，支持多版本并排对比

## 汇报风格说明

| 风格 | 适用场景 | 核心特征 |
|------|----------|----------|
| 结构化输出 | 制度性文档、正式汇报 | 层级标题、编号列表、摘要总结 |
| OKR对齐 | 战略对齐、季度汇报 | 目标-关键结果-举措结构 |
| 向上管理 | 争取资源、汇报进展 | 价值导向、ROI论证、资源请求 |
| STAR法则 | 述职、面试准备 | 情境-任务-行动-结果叙事 |
| 自然表达 | 内部同步、非正式沟通 | 口语化、轻松自然、重点突出 |

## 使用流程

### 步骤1：理解用户需求

确认以下信息：
- **场景类型**：周期性汇报、项目复盘、晋升述职、资源申请、团队同步
- **目标受众**：上级领导、跨部门协作、面试官、团队成员
- **内容密度**：详细展开 or 精简概述

### 步骤2：收集工作事项

引导用户输入工作内容，包括：
- 具体完成的任务
- 数据指标或量化成果
- 遇到的问题及解决方案
- 协作配合情况

### 步骤3：选择汇报风格

根据场景推荐最适合的风格：
- 正式汇报 → 结构化输出
- 战略对齐 → OKR对齐
- 争取资源 → 向上管理
- 述职面试 → STAR法则
- 内部同步 → 自然表达

### 步骤4：生成并输出

生成专业汇报文本，支持：
- 直接呈现生成结果
- 一键复制到剪贴板
- 下载为Markdown文件
- 多版本对比选择

## 示例对话

**用户**：帮我写一份本周的工作汇报

**助手**：
好的，我来帮您生成专业的工作汇报。请告诉我：
1. 本周主要完成了哪些工作？
2. 有哪些具体的成果或数据可以分享？
3. 汇报风格偏好？（正式文档/简洁版/争取资源版）

**用户输入示例**：
- 完成了用户调研报告，覆盖30+用户需求
- 优化了后台数据加载速度，提升40%
- 协调研发和产品解决了3个线上bug
- 输出了2份技术文档

**输出示例**（结构化输出风格）：
```
## 本周工作汇报

### 一、工作概述
本周期内，按照既定计划推进各项工作...

### 二、核心工作完成情况
1. 完成用户调研报告...
2. 优化后台数据加载...
...

### 三、关键成果指标
- 调研覆盖：30+用户
- 性能提升：40%
...
```

## 质量标准

生成内容需满足：
- **完整性**：包含背景、过程、结果、反思
- **可量化**：尽可能用数据支撑成果
- **结构清晰**：层级分明、重点突出
- **语言专业**：避免口语化、体现专业性
- **场景适配**：语气和详略符合受众需求

## 注意事项

- 输入越详细，生成质量越高
- 提醒用户补充数据指标可增强说服力
- 敏感信息需提醒用户脱敏处理
- 生成内容仅供参考，需用户审核确认
