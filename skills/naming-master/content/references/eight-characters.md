# 八字起名原理

## 八字基础

八字，即生辰八字，是根据一个人出生的年、月、日、时四个时间点，配以天干地支形成的八个字。

### 天干地支

**十天干**：甲、乙、丙、丁、戊、己、庚、辛、壬、癸

**十二地支**：子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥

### 六十甲子

天干地支组合成六十甲子，用于纪年、纪月、纪日、纪时。

| 天干 | 甲 | 乙 | 丙 | 丁 | 戊 | 己 | 庚 | 辛 | 壬 | 癸 |
|------|----|----|----|----|----|----|----|----|----|----|
| 阳 | 甲 | 丙 | 戊 | 庚 | 壬 | | | | | |
| 阴 | | 乙 | 丁 | 己 | 辛 | 癸 | | | | |

## 强弱判断

### 日主强弱判断方法

1. **得令**：月支为日干之五行或相生之五行
2. **得地**：其他三支中有日干之五行或相生之五行
3. **得助**：天干中有日干之五行或相生之五行
4. **失令**：月支为克日干之五行

### 八字强弱分类

- **极强**：得令、得地、得助三者具备
- **偏强**：得令且得地或得助
- **中和**：介于偏强与偏弱之间
- **偏弱**：失令且失地或失助
- **极弱**：失令、失地、失助三者俱无

## 喜用神

### 喜用神确定原则

1. **日主为木**：水为用神（水生木），木为喜神（木帮身）
2. **日主为火**：木为用神（木生火），火为喜神（火帮身）
3. **日主为土**：火为用神（火生土），土为喜神（土帮身）
4. **日主为金**：土为用神（土生金），金为喜神（金帮身）
5. **日主为水**：金为用神（金生水），水为喜神（水帮身）

### 调候用神

根据出生季节，还需要考虑调候用神：

| 季节 | 调候原则 |
|------|----------|
| 春季木旺 | 宜火（寒木需火温） |
| 夏季火旺 | 宜水（水能制火润燥） |
| 秋季金旺 | 宜火（火能制金暖寒） |
| 冬季水旺 | 宜火（火能温暖寒水） |

## 八字起名步骤

1. **排出八字**：根据出生时间排出年柱、月柱、日柱、时柱
2. **分析日主**：确定日干五行，分析日主强弱
3. **确定喜用**：根据日主强弱和调候需要，确定喜用神
4. **选择用字**：在喜用神五行范围内选择吉祥字
5. **综合考量**：兼顾音形义、数理、三才五格等因素

## 起名禁忌

1. **忌相冲**：名字五行与八字日主相冲
2. **忌相克**：名字五行过度克制日主
3. **忌孤寡**：八字本身偏枯，名字不宜再加强偏性
4. **忌浊乱**：用字杂乱，五行不纯

## 现代简化应用

对于不具备专业八字分析条件的情况，可以采用简化方法：

1. **生肖五行**：根据出生年份的生肖，推断基本五行倾向
2. **季节参考**：春季宜木火，夏季宜水金，秋季宜土金，冬季宜火木
3. **姓氏五行**：姓氏本身带五行，选择名字时注意平衡
