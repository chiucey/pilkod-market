| 商务蓝 | #1E3A5F | #4A90D9 | #F5A623 | 企业汇报、商业提案 |

| 奢华金 | #5D4037 | #FFD54F | #3E2723 | 高端定制、品牌展示 |

### 字体规范

**中文字体推荐**：
- 标题：思源黑体 Bold / 微软雅黑 Bold
- 正文：思源宋体 Regular / 微软雅黑 Regular
- 注释：思源黑体 Light

**英文字体推荐**：
- 标题：Arial Bold / Helvetica Bold
- 正文：Arial Regular / Calibri
- 代码/数据：Consolas / Monaco

**字号规范**：
- 主标题：36-44pt
- 副标题：28-32pt
- 正文：18-24pt
- 注释/标注：12-16pt

### 版式布局原则

1. **对齐**：元素边缘或中心点保持对齐，形成视觉引导
2. **对比**：标题与正文、层级之间形成明显大小/粗细对比
3. **亲密**：相关元素靠近，不相关元素远离
4. **重复**：视觉元素在整份PPT中保持一致性

## 技术实现

### Python pptx核心操作

```python
from pptx import Presentation
from pptx.util import Inches, Pt
from pptx.dml.color import RgbColor
from pptx.enum.text import PP_ALIGN

# 创建演示文稿（16:9比例）
prs = Presentation()
prs.slide_width = Inches(13.333)
prs.slide_height = Inches(7.5)

# 添加幻灯片
blank_layout = prs.slide_layouts[6]  # 空白布局
slide = prs.slides.add_slide(blank_layout)

# 添加文本框
left = Inches(1)
top = Inches(2)
width = Inches(11.333)
height = Inches(1)
textbox = slide.shapes.add_textbox(left, top, width, height)
tf = textbox.text_frame
tf.text = "标题文字"

# 设置段落格式
p = tf.paragraphs[0]
p.font.size = Pt(44)
p.font.bold = True
p.font.name = "微软雅黑"
p.alignment = PP_ALIGN.CENTER

# 添加图片
slide.shapes.add_picture("image.png", Inches(2), Inches(3), width=Inches(9))

# 保存文件
prs.save("output.pptx")
```

### 常用形状操作

```python
from pptx.enum.shapes import MSO_SHAPE

# 添加矩形
shape = slide.shapes.add_shape(
    MSO_SHAPE.RECTANGLE,
    Inches(1), Inches(1),
    Inches(2), Inches(1)
)
shape.fill.solid()
shape.fill.fore_color.rgb = RgbColor(0x1E, 0x3A, 0x5F)

# 添加圆形
circle = slide.shapes.add_shape(
    MSO_SHAPE.OVAL,
    Inches(5), Inches(3),
    Inches(1), Inches(1)
)

# 添加箭头
arrow = slide.shapes.add_shape(
    MSO_SHAPE.RIGHT_ARROW,
    Inches(3), Inches(5),
    Inches(2), Inches(0.5)
)
```

### 图表操作

```python
from pptx.chart.data import CategoryChartData
from pptx.enum.chart import XL_CHART_TYPE

# 添加柱状图
chart_data = CategoryChartData()
chart_data.categories = ['Q1', 'Q2', 'Q3', 'Q4']
chart_data.add_series('销售额', (100, 120, 150, 180))

chart = slide.shapes.add_chart(
    XL_CHART_TYPE.COLUMN_CLUSTERED,
    Inches(1), Inches(2),
    Inches(6), Inches(4.5),
    chart_data
).chart
```
