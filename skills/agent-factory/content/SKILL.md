# 超级智能体自动生成器

## 技能简介

🎯 **一句话定位**：让任何人都能快速创建属于自己的 Agent 技能

超级智能体自动生成器是一款帮助用户从零到一创建 Agent Skills 的工具。它提供：

- 🏗️ **技能设计** - 根据需求设计技能架构和触发逻辑
- 📝 **内容生成** - 自动生成 SKILL.md 骨架和示例
- ✨ **质量优化** - 改进触发短语、增强描述、提升示例
- 🧪 **测试验证** - 验证技能文件的正确性和完整性
- 📦 **打包发布** - 生成可分发的技能包

## 技能创建工作流

### 🚀 快速创建（5步法）

```
用户描述需求
    ↓
确认技能定位
    ↓
生成技能结构
    ↓
创建 SKILL.md
    ↓
测试与优化
```

### 详细步骤说明

**Step 1：需求收集**

我会通过一系列问题了解您的需求：

1. **技能用途** - 这个技能用来做什么？
2. **目标用户** - 谁会使用这个技能？
3. **触发场景** - 用户在什么情况下会用到？
4. **输出内容** - 技能应该输出什么？
5. **特殊要求** - 有没有额外的限制或偏好？

**Step 2：技能设计**

根据您的需求，我会设计：

1. **技能名称** - 英文+连字符格式
2. **Description** - 触发短语和场景描述
3. **功能模块** - 技能的具体功能
4. **触发逻辑** - 如何被正确触发

**Step 3：文件生成**

为您生成完整的技能文件：

1. **SKILL.md** - 主配置文件
2. **_meta.json** - 元数据文件
3. **references/** - 详细文档（可选）
4. **scripts/** - 自动化脚本（可选）

**Step 4：质量检查**

自动检查：

1. Frontmatter 格式是否正确
2. Description 是否包含触发短语
3. 文件结构是否完整
4. 命名是否规范

**Step 5：测试优化**

根据实际使用效果：

1. 测试触发是否准确
2. 优化触发短语
3. 补充更多示例
4. 完善边缘情况处理

## 触发短语设计原则

### ✅ 好的触发短语

1. **自然口语化**
   - "帮我写一封邮件"
   - "今天吃什么好"

2. **明确具体**
   - "帮我整理会议纪要" 而非 "帮我做事"
   - "预算1000元的旅行计划" 而非 "做个计划"

3. **覆盖多种表达**
   - "做饭" / "做菜" / "做菜谱" / "烹饪"
   - "买" / "采购" / "购物" / "清单"

### ❌ 不好的触发短语

1. **过于模糊**
   - "帮我"
   - "处理一下"
   - "搞一搞"

2. **歧义太多**
   - "分析" - 分析什么？
   - "整理" - 整理什么？

3. **触发范围过窄**
   - "番茄炒蛋的做法" - 只能触发这一道菜

## 常见问题解答

**Q: 创建一个技能需要多久？**

A: 简单技能（如单一功能）约5-10分钟，复杂技能（如多模块）约20-30分钟。

**Q: 技能可以有多少个功能？**

A: 没有限制，但建议每个技能专注于一个核心场景。

**Q: 如何让技能更智能？**

A: 1. 提供更多触发短语变体
   2. 添加详细的示例
   3. 处理边缘情况
   4. 增加错误处理和反馈

**Q: 技能可以调用外部工具吗？**

A: 可以，但需要与具体的 AI 平台配合实现。

**Q: 如何测试我的技能？**

A: 创建后可以通过对话测试触发是否准确。
