# IEC 62304 软件生命周期合规检查清单

## 软件安全分类

| 分类 | 定义 | 示例 | 过程要求 |
|------|------|------|---------|
| Class A | 软件故障不会造成伤害 | 电子健康记录的非关键功能 | 基础过程 |
| Class B | 软件故障可能造成非严重伤害 | 输液泵监控软件 | 推荐过程 |
| Class C | 软件故障可能造成死亡或严重伤害 | 心脏起搏器控制软件 | 必需过程 |

## 开发过程要求

### Class A - 基础过程

- [ ] 软件开发计划
- [ ] 软件需求规格
- [ ] 软件架构设计
- [ ] 软件详细设计
- [ ] 软件单元验证
- [ ] 软件集成和集成测试
- [ ] 软件系统测试
- [ ] 软件发布

### Class B - 推荐过程（增加）

- [ ] 软件需求评审
- [ ] 软件架构评审
- [ ] 软件详细设计评审
- [ ] 软件集成计划评审
- [ ] 软件验证计划评审
- [ ] 风险分析活动
- [ ] 配置管理系统
- [ ] 变更控制流程

### Class C - 必需过程（进一步增加）

- [ ] 软件需求可追溯性分析
- [ ] 软件架构详细分析
- [ ] 详细的软件验证和确认
- [ ] 独立安全验证
- [ ] 失效模式和影响分析（FMEA）
- [ ] 完整的测试覆盖率分析

## 文档要求

### 软件开发计划（SWDP）

```
内容要素：
1. 软件开发过程概述
2. 软件安全分类和依据
3. 软件开发环境
4. 角色和职责
5. 里程碑和时间线
6. 资源需求
7. 风险管理策略
8. 质量保证措施
```

### 软件需求规格（SRS）

```
要求：
1. 功能需求
2. 非功能需求（性能、安全、可靠性）
3. 接口规格（用户、硬件、软件接口）
4. 可追溯性标识
5. 验收标准
```

## 并行项目合规协调

### 共享过程元素

| 元素 | 复用方式 | 维护责任 |
|------|---------|---------|
| 开发过程模板 | 集中管理 | 质量部门 |
| 文档标准 | 统一规范 | 技术写作组 |
| 配置管理 | 单一库 | 配置管理员 |
| 变更控制 | 统一流程 | CCB |
| 风险管理 | 统一方法 | 安全团队 |

### 独立过程元素

| 元素 | 说明 |
|------|------|
| 项目特定需求 | 每项目独立维护 |
| 测试用例 | 可复用，需项目定制 |
| 验证报告 | 项目特定 |
| 上市后监督 | 产品特定 |
