# FDA 21 CFR Part 820 医疗器械质量体系合规指南

## 关键要求概述

### 设计控制（Sec. 820.30）

**适用范围**：Class II 和 Class III 器械

**核心要素**：

1. **设计策划**
   - 建立设计开发计划
   - 分配职责和权限
   - 确定输入输出要求
   - 评审、验证、确认、设计转换、设计转换评审、设计转换确认

2. **设计输入**
   - 物理、法规、性能要求
   - 风险管理输出
   - 软件需求（适用于软件器械）

3. **设计输出**
   - 完整的设计规格
   - 可用于采购和生产
   - 包含验收准则
   - 标识关键参数

4. **设计评审**
   - 正式评审点
   - 参与者记录
   - 评审结论文件化

5. **设计验证**
   - 确认设计输出符合输入
   - 测试报告和数据分析

6. **设计确认**
   - 确保产品符合预期用途
   - 临床评价/可用性测试

7. **设计转换**
   - 确保设计可生产
   - 完整记录

8. **设计变更**
   - 变更控制程序
   - 评估影响
   - 重新评审和验证（如需要）

### 生产和过程控制（Sec. 820.70）

- 过程参数监控
- 设备维护
- 环境控制
- 人员资质

### 纠正和预防措施（Sec. 820.100）

**CAPA 流程**：

```
1. 收集信息
   - 投诉处理
   - 不合格品报告
   - 审核发现
   - 过程数据

2. 调查根本原因
   - 技术分析
   - 统计方法
   - 风险评估

3. 制定措施
   - 纠正措施（消除原因）
   - 预防措施（预防潜在问题）

4. 实施和验证
   - 执行计划
   - 确认有效性

5. 文档化
   - 完整记录
   - 管理评审输入
```

## 多项目合规协调策略

### 质量体系架构

```
顶层：质量手册
    │
    ├── 通用程序（适用于所有项目）
    │   ├── 文件控制
    │   ├── 记录控制
    │   ├── 内部审核
    │   ├── 管理评审
    │   └── CAPA 系统
    │
    └── 项目特定程序
        ├── 设计控制计划
        ├── 风险管理文件
        └── 上市后监督计划
```

### 审计协调

| 审计类型 | 协调策略 |
|---------|---------|
| 内部审核 | 综合审核计划，覆盖所有活跃项目 |
| 外部审核 | 统一准备，避免重复工作 |
| 供应商审核 | 共享供应商资源池 |
| 注册审核 | 协调准备时间表 |

### 上市后监督协调

- 建立统一的不良事件报告系统
- 协调各项目的警戒活动
- 共享趋势分析结果
- 统一纠正措施策略
