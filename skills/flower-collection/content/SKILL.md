# 花朵集锦技能

## 技能简介

花朵集锦技能是一个专业的植物花朵识别系统，能够通过用户提供的图片或文字描述，识别花朵的分类学信息（界-门-纲-目-科-属-种），并结合中国传统诗词文化，为每种花朵提供一首契合的一手诗歌（原创诗词）。

## 识别流程

### 第一步：接收输入
- 接收用户上传的花朵图片
- 或接收用户对花朵的文字描述（形态特征、颜色、气味等）

### 第二步：花朵识别
根据输入信息判断花朵所属分类：

1. **界 (Kingdom)**: 植物界 (Plantae)
2. **门 (Phylum)**: 如被子植物门 (Angiospermae)
3. **纲 (Class)**: 如木兰纲 (Magnoliopsida)
4. **目 (Order)**: 如蔷薇目 (Rosales)
5. **科 (Family)**: 如蔷薇科 (Rosaceae)
6. **属 (Genus)**: 具体属名
7. **种 (Species)**: 具体种名

### 第三步：输出识别依据
提供识别的科学依据：
- 花朵形态特征
- 颜色与花瓣数量
- 叶序与茎干特征
- 开花季节
- 其他鉴别要点

### 第四步：匹配一手诗歌
根据花朵的特点和象征意义，创作或匹配一首中国古诗词风格的诗歌，内容需与花朵的特征、文化寓意或应用场景相关。

## 分类层级说明

```
界 Kingdom → 门 Phylum → 纲 Class → 目 Order → 科 Family → 属 Genus → 种 Species
```

例如，玫瑰的分类：
- 界：植物界
- 门：被子植物门
- 纲：木兰纲
- 目：蔷薇目
- 科：蔷薇科
- 属：蔷薇属
- 种：玫瑰

## 输出格式

当识别完成时，按以下格式输出结果：

```
【花卉名称】：
【界门纲目科属种】：
【识别依据】：从花瓣、花色、花型、叶片、特征说明
【对应经典古诗】：一首完整古诗
```

## 常见花朵识别示例

### 示例1：玫瑰
**识别依据**：
- 花瓣5片或重瓣，单生或数朵簇生
- 茎上有皮刺
- 叶为羽状复叶，小叶3-9片
- 花期5-6月，果期8-9月
- 香气浓郁

**一手诗歌**：
```
《玫瑰》
带刺蔷薇映日红，
芳华绝代傲春风。
玫瑰一朵香凝露，
醉倒人间几万重。
```

### 示例2：牡丹
**识别依据**：
- 花大而艳丽，直径可达20厘米
- 花瓣5片或重瓣，色彩丰富
- 叶为二回三出复叶
- 茎木质化
- 花期4-5月

**一手诗歌**：
```
《牡丹》
国色天香冠众芳，
花开时节动京城。
姚黄魏紫争春色，
富贵荣华伴此生。
```

### 示例3：荷花
**识别依据**：
- 花单生，大型，直径10-20厘米
- 花瓣多数，倒卵形
- 雄蕊多数，雌蕊离生
- 叶圆形，盾状
- 花期6-8月

**一手诗歌**：
```
《荷花》
碧波深处出芙蓉，
映日荷花别样红。
出淤泥而不染者，
清香十里醉春风。
```

## 识别技巧

### 花朵特征要点
1. **花瓣数量与形态**：单瓣、复瓣、重瓣
2. **花色与花纹**：纯色、渐变、斑点、条纹
3. **花序类型**：单生、总状、伞形、圆锥等
4. **叶形与叶序**：互生、对生、轮生
5. **茎干特征**：木质、草质、攀援、直立
6. **特殊器官**：刺、毛、腺点

### 季节与地域
- 考虑花朵的开花季节
- 了解不同地域的常见花卉
- 结合植物的生态习性

## 注意事项

1. 若无法确定具体种，可识别到属或科级别
2. 如图片质量不佳导致无法识别，应明确告知用户
3. 诗歌创作需契合花朵的文化内涵
4. 对于有毒植物应特别提醒

## 错误处理

- **图片不清晰**：请用户重新拍摄或提供更多细节
- **无法识别**：给出最接近的科属信息，并建议咨询专业人士
- **信息不足**：列出需要补充的特征信息

## 应用场景

- 花艺爱好者的植物识别工具
- 诗词爱好者的创作素材库
- 植物学学习者的分类参考
- 花卉摄影的辅助鉴定
