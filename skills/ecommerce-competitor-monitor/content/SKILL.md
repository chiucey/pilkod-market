# 电商竞品监控与分析技能

## 核心能力

本技能帮助用户监控京东、天猫商城特定品类的竞品数据，提供从数据采集、交叉验证、周维度趋势分析到运营策略建议的全链路服务。

### 核心功能矩阵

| 功能模块 | 说明 |
|---------|------|
| **数据采集** | 自动搜索并提取京东/天猫品类销量排行TOP10 |
| **交叉验证** | 时间维度+横向价格对比，确保数据准确性 |
| **周维度分析** | 追踪销量和ROI的周环比变化趋势 |
| **价位段分析** | 按价格区间分层分析，识别高价值价位段 |
| **TOP5深度分析** | 分析主图风格、详情页结构、投流特点 |
| **亮眼案例提炼** | 识别成功运营案例并详细拆解 |
| **PDF报告生成** | 输出专业PDF格式分析报告 |
| **分权重策略** | 按优先级和权重给出具体运营建议 |

## 工作流程

### 阶段1：需求确认

1. **确认监控品类**
   - 确定具体品类（如：手机、家电、美妆、AED等）
   - 确定目标平台（京东/天猫/两者分开）
   - 确定分析维度（全价位段/特定价位段）

2. **确认数据周期**
   - 单次分析：当天数据
   - 周分析：一周数据
   - 月度分析：整月数据（推荐）

### 阶段2：数据采集与交叉验证

1. **多平台数据采集**
   - 使用 `batch_web_search` 搜索品类排行
   - 使用 `extract_content_from_websites` 提取页面详情
   - 采集京东和天猫平台数据（分开执行）

2. **数据交叉验证**
   ```
   验证方法：
   ├── 时间维度：对比周环比变化
   ├── 横向对比：京东/天猫同款产品价格验证
   ├── 行业参照：参考行业权威数据
   └── 校正系数：评论数 × 3.5 ≈ 月销量
   ```

3. **历史数据对比**
   - 加载历史JSON数据（如存在）
   - 计算价格波动幅度（%）
   - 分析销量变化趋势
   - 标记异常波动产品

### 阶段3：周维度趋势分析

1. **周销量趋势追踪**
   - 按自然周划分数据（第1-4周）
   - 计算周环比变化率
   - 识别销量激增/下滑节点
   - 分析驱动因素

2. **ROI变化趋势**
   - 追踪ROI的周变化
   - 识别高ROI产品特征
   - 分析价格-ROI关系

### 阶段4：全价位段产品分析

1. **价位段划分**
   ```
   典型价位段（根据品类调整）：
   ├── 入门级：品类最低价 ~ 市场均价×0.7
   ├── 主流性价比：市场均价×0.7 ~ 市场均价×1.2
   ├── 中高端：市场均价×1.2 ~ 市场均价×2
   └── 高端专业：市场均价×2以上
   ```

2. **TOP10产品排名**
   - 按销量排序
   - 提取：品牌、型号、价格、评论数、预估销量、预估ROI
   - 标注周趋势变化

### 阶段5：TOP5深度分析

1. **主图分析**
   - 主图类型（白底实拍/场景图/渲染图）
   - 视觉风格和色调
   - 文字覆盖和促销标签
   - 价格展示策略

2. **详情页结构分析**
   - 首屏核心卖点呈现
   - 参数表结构
   - 差异化卖点展示方式
   - 用户评价引导

3. **投流策略识别**
   - 增值服务型（赠送培训/课程）
   - 服务承诺型（只换不修等）
   - 品牌背书型（国产品牌/进口品牌）
   - 性价比型（价格优势+功能齐全）

### 阶段6：亮眼案例提炼

1. **识别标准**
   - 销量环比增长 >15%
   - ROI高于行业均值 >20%
   - 运营动作可复制

2. **案例拆解**
   - 案例背景描述
   - 关键运营动作
   - 运营效果数据
   - 成功要素分析

### 阶段7：分权重运营建议

1. **策略分类**
   | 优先级 | 标识 | 说明 |
   |--------|------|------|
   | P0紧急 | 红色 | 需立即执行的重大动作 |
   | P1重要 | 橙色 | 本周内需要完成 |
   | P2常规 | 绿色 | 持续优化的常规工作 |

2. **权重分配**
   - 每个策略标注建议权重（10%-50%）
   - 按权重分配执行资源和时间

3. **行动计划**
   - 具体执行动作
   - 执行时间节点
   - 预期效果指标

### 阶段8：报告生成

1. **Markdown报告**
   - 市场概览与品牌格局
   - 周维度趋势分析
   - 全价位段产品分析
   - 亮眼案例详解
   - 分权重运营建议
   - 数据验证说明

2. **PDF报告**
   - HTML模板渲染
   - 专业排版设计
   - 平台风格区分（京东红色系，天猫橙色系）

## 技术实现要点

### 数据采集策略
1. 使用 `batch_web_search` 搜索品类排行
2. 使用 `extract_content_from_websites` 提取页面数据
3. 使用 `images_search_and_download` 下载主图参考

### PDF报告生成
1. 创建HTML模板（包含CSS样式）
2. 使用 `html_to_pdf` 工具转换
3. 京东报告使用红色系主题
4. 天猫报告使用橙色系主题

### 数据验证方法
```
评论转化率：约28%（20-35%区间）
校正公式：评论数 × 3.5 ≈ 月销量
ROI公式：毛利润 / 广告投入
```

## 已知限制

1. 销量数据为页面展示数据推算，存在一定误差
2. ROI为基于行业均值估算，非精确值
3. 投流分析为推断性质，仅供参考
4. 天猫平台数据采集存在一定难度

## 使用示例

### 示例1：全价位段月度分析
**用户输入**: "监控AED除颤仪3月份全月数据，京东和天猫分开分析"

**技能执行**:
1. 分别搜索京东/天猫AED品类数据
2. 进行数据交叉验证
3. 分析周维度销量和ROI趋势
4. 按价位段分层分析
5. 提炼亮眼案例
6. 制定分权重运营建议
7. 生成京东PDF报告
8. 生成天猫PDF报告

### 示例2：特定价位段分析
**用户输入**: "监控手机品类3500-5000价位段竞品数据"

**技能执行**:
1. 搜索手机品类排行
2. 筛选3500-5000价位产品
3. 提取TOP10数据
4. 深度分析TOP5产品
5. 生成3500-5000价位专项报告
