# 探物寻知 · 文案写作规范

> 基于26篇道荣文案提炼的风格规范，用于生成与道荣风格相似度92-95%的科普文案。

## 风格内核

**一句话概括：** "用游戏玩家的语言，讲一个反常识的科学道理，最后给你一个扎心或温情的落点。"

**核心价值观：**
- 不讲正确的废话
- 讲"我查完才知道"的冷知识
- 讲"原来如此"的恍然大悟感
- 讲"我怎么没想到"的惊奇感

## 第一步：选题判断

不是所有科普都适合用这个风格。道荣风格的选题必须满足：

**HKR质检：**
- **H (Hook)** 有没有反常识点？能不能在第一句就钉住观众？
- **K (Knowledge)** 有没有大多数不知道的冷知识？
- **R (Resonance)** 能不能落到生活场景或情感共鸣上？

选题通过HKR后，问自己：这个东西能不能用"地球online"或"技能树"来解释？

## 第二步：开头写法

### 必杀技（优先级从高到低）

**1. 反常识直接砸脸（最强）**
```
为什么XX明明XXX，却XXX？
直接说答案，XXXX。
```
示例：
- "为什么虾进化的这么适合被吃？" → "直接说答案，虾把自己的身体部位进行了垃圾分类。"
- "为什么以前富人吃的鲍鱼现在这么便宜了？" → "这个问题属于一目了然，以前的鲍鱼贵不是因为好吃，是因为少。"

**2. 谐音梗开路**
```
XXXX，这属于是夏侯惇XXXX。
```
系列库：
- 一目了然
- 读书（睁一只眼闭一只眼）
- 解题
- 相亲（一见钟情/一眼就爱上了）
- 看杨戬（四目相对）
- 垫脚尖（高看一眼）
- 开透视（一眼看穿）
- 路易十六（一眼望不到头）
- 读春秋（理解不了的时候）

**3. 自嘲开场（适合热点话题）**
```
果然XXXX，说话带着一股子XXXX味。
有没有一种可能，XXXX。
```

**4. 游戏化开场**
```
XXXX，对于XXXX来讲这就属于是降维打击。
```

**5. "问题本身就问错了"开场**
```
XXXX？诶，首先这个问题就问错了。事实上，XXXX。
```
适用于：纠正大众常见误解的选题

**6. 文艺金句开场**
```
牛奶会变馊，面包会发霉，就连爱情也会变质。那XXXX是不是也会XXX？
```
适用于：日常生活类选题，用诗意排比拉情绪再用科学打破

**7. 极端推演开场（把假设推到荒谬）**
```
说这话的人，你有没有考虑过XX的感受？你是想让XX去XXX吗？
```
适用于：脑洞类选题（如"为什么X不能像Y一样大"）

**8. "口误"热点引入开场**
```
喜欢XX，啊不，喜欢XX的朋友们有福了。
```
假装口误实则植入热点人物/事件，增加时效性和互动感。

**9. 反直觉事实开场**
```
XX往XX里掺XX，不是为了坑你，是因为XX太高必须加XX才能符合标准。
```
用看似荒谬但真实的事实做开头钩子。

**10. "拟人化对话"开场**
```
别的XX都会说XXXX，但XX会说：什么是XX？
```
让非生命体"开口说话"形成性格对比。

### 绝对禁区

- 禁止"随着科技的发展"、"在当今社会"等教科书开头
- 禁止"首先...其次...最后"的模板
- 禁止"值得注意的是"等废话

## 第三步：结构模板

### 通用结构（适用于90%的话题）

```
【开头】反常识/谐音，直接给答案（30字以内）
    ↓
【机制解释】为什么会有这个现象？（100-150字）
    ↓
【案例深化】举例子/算账/历史故事（150-250字）
    ↓
【同类扩展】类似的例子/反例（50-100字）
    ↓
【升华落点】往大了说/往深了说/往情了说（30-50字）
    ↓
【互动收尾】提问/祝福/自嘲（20-30字）
```

### 分类话题的结构偏好

**生物/进化类话题：**
```
反常识现象 → 寒武纪/进化史故事 → 机制解释 → 恐怖直立猿老六 → 升华
```
关键：把进化论讲成"技能树加点"的故事。

**食品/农业类话题：**
```
反常识现象 → 成为主粮/优质食材的标准 → 具体对照 → 算账（成本/产量） → 历史背景 → 情感落点
```
关键：把营养学讲成"成本核算"的故事。

**物理/化学类话题：**
```
反常识现象 → 机制解释（用生活比喻） → 历史故事（科学家血泪史） → 升华
```
关键：把原理讲成"武侠小说"的故事。

**历史/地理类话题：**
```
反常识现象 → 具体数据/典故 → 分析原因 → 延伸同类 → 升华
```

**战斗/对比类话题：**
```
直接给结论（XX秒杀）→ 自嘲现代人退化 → 但依然是恐怖直立猿 → 分析战斗优劣势 → 真实案例佐证 → 武器/装备分析（游戏逻辑）→ 对手心理分析 → 实用建议
```

**"纠正误解"类话题：**
```
抛出错误认知 → 直接否定 → 给出正确答案 → 数据/案例论证 → 延伸（类似误解）→ 实用信息
```

**末日推演/假设类话题：**
```
抛出假设 → 时间线推演（1个月→2个月→4个月→6个月）→ 逐步升级灾难 → 穿插真实案例（火星/金星） → 哲学升华（运气论）→ 抖机灵收尾
```
关键：按时间线逐步推进，每个阶段用"你以为→其实"反转，最终拔高到宇宙视角。

**地质/资源类话题：**
```
反直觉事实 → 数据对比（算笔账）→ 地质成因（讲成版本故事）→ 竞品分析（巴西vs澳大利亚）→ 条件归纳 → 抖机灵收尾
```
关键：把地质条件讲成"老天爷喂饭"，把竞争对手对比讲成产品评测。

**人体/运动科学类话题：**
```
擦边梗开场 → 游戏定位 → 数据震撼（心率/血量）→ 系统化讲解（三套系统/多阶段）→ 类比普通人 → 反向祝福收尾
```
关键：把人体机制讲成游戏的能量/供能系统，分阶段拆解。

## 第五步：修辞手法

### 谐音造词公式

**已知词根 + 新场景 = 原创谐音梗：**
- 享氟（享福/氟元素）
- 熊熊难熟（熊掌难熟）
- 自求多氟（自求多福）
- 浓缩的都是精华的反向应用
- 夏侯惇系列（见上文）

**秦始皇系列：**
- 秦始皇夸兵马俑 → 小淘气
- 秦始皇照镜子 → 双赢（嬴）

**路易十六系列：**
- 路易十六的生日 → 过到头了
- 路易十六的脖子 → 露头就秒
- 路易十六下楼梯 → 低人两头
- 路易十六的帽子 → 有心无力/毫无作用
- 路易十六的晚年 → 走到头了

**夏侯惇自由组合规则（重要）：**
夏侯惇不限于固定搭配，可以自由组合：
- 夏侯惇 + 动作 + 对象 → 谐音效果
- "夏侯惇鉴宝" → 一眼甲（假）
- "夏侯惇带着卡卡西下煤窑" → 两眼一抹黑（跨IP联动）
- "夏侯惇看刑天" → 一眼望不到头（刑天无头）
- "夏侯惇看司马迁" → 一眼望不到边（司马迁被宫刑，无鞭）
- "夏侯惇借宝" → 一言假（一眼假）
- "夏侯惇的冷漠" → 懒得看一眼
- "夏侯惇望魏忠贤" → 一眼望不到边（魏忠贤是太监，无鞭）
- "夏侯惇梦魏忠贤" → 一眼望不到边（梦=闭眼）

规则：核心是围绕"眼"做文章，找同音/谐音/联想词，结合历史人物或动漫角色的特征

**"攻读过XX学位的夏侯惇们都能一眼看穿"组合句式：**
学历梗+夏侯惇组合成固定过渡句：
- "攻读过高中物理学位的夏侯惇们都能一眼看穿"
- "攻读过初中生物学位的都知道"
- "攻读过《钢铁是怎样炼成的》的夏侯惇们都能一眼看穿"
- "吃过饭的夏侯惇们都能一眼看穿"

**造词/造信条：**
```
鳗生信条：躲生躲育，多生多育。
```
把谐音+押韵做成纲领性总结。

**如何造新的谐音：**
1. 找到一个关键词的核心字
2. 找一个同音或音近的字
3. 嵌入到一个"夏侯惇XXXX"或"XXXX眼"的结构里

### 成语/典故新编

**已知成语 + 新场景 = 意料之外的笑点：**
- "如芒在背、如鲠在喉、如坐针毡、如履薄冰"（四个并列）
- "我本将心向明月，奈何明月照沟渠"
- "说出吾名，吓汝一跳"
- "勃勃生机、万物竞发"
- "旧时王谢堂前燕，飞入寻常百姓家"
- "朝闻道夕死矣"

### 数据算账法

把成本/收益用数学算出来，制造"原来如此"的笑点：
```
十斤西瓜出糖半斤，成本五元，净亏三块五。
换算：吃一斤红薯拉两斤屎。
```

### 数学类比测算法

用已知数据等比推算目标，制造震撼感：
```
苏联用1颗14万吨核弹炸出484万立方米 → 泰山600亿立方米 → 需要12400颗
```

### 数据比值差异法

用两个数据的倍数差异制造"原来如此"：
```
当量提升了3300多倍，但火球半径只提升了20多倍。
```

### "保质期保的是X而不是Y"拆解法

把一个概念拆成两个部分，指出真正有意义的部分，纠正认知偏差。

### "恭喜"反讽句式

```
恭喜，要不了多久你就会得到一个XXXX。
```
用祝贺语气描述恐怖/荒谬结果。

### 排序/排名句式

```
如果给XX排个序的话，最XX的是A，其次是B，最不XX的是你/C。
```
最后一个要出人意料制造笑点。

### "如果XX了，就证明XX"反证法

```
如果盐发霉了，就证明发现了新的细菌。
```
用科学逻辑制造幽默。

### 跨时空类比串联

```
放金字塔里能送走法老，放冻土里能咽猛犸象，放厨房里能腌咸菜。
```
同一事物穿越不同时空场景，三段式排比。

### "上一个这么XX的还是XX"串联

```
上一个这么懂事的食物还是香蕉。
```
自然过渡到同类扩展话题。

### 改编鸡汤/名言

```
在哪里跌倒就在哪里睡觉。
受伤之前唯唯诺诺，被咬之后重拳出击。
```

### 四字排比轰炸

密集堆叠正经词+魔改词制造荒诞感：
```
什么叫王者之师，什么叫吊民伐罪，什么叫犁庭扫穴，什么叫马克西神功，什么叫加特林大法。
```

### 废话文学过渡

故意说正确但无用的话制造喜感，用作段落过渡：
```
爱喝水的朋友们都知道，海这个地方，就是水多。
三分钟的拳击，拳手觉得如同180秒那么漫长。
秉承着大就是好的原则，我们可以知道XX。
```

### "你以为→你错了"反转

先给观众一个直觉判断空间，再立刻打破：
```
你以为这是好事？温室气体少了气候不就凉快了？你错了。
```

### "对，但不完全对"修正句式

比直接否定更顺滑的纠正方式：
```
这个说法对，但不完全对。XX确实是XX，但XXXX。
```

### 逐级放大类比链

把一个抽象数据通过层层类比降维到日常感受：
```
1100个大气压 → 猴子被压500年也就几百个 → 奥特曼来了也得粉碎性骨折 → 你兄弟卧推50公斤都得喊救命
```

### 单位换算可视化

用观众熟悉的事物作为度量单位反复使用：
```
西湖蓄水量1400万立方米 → 1分钟灌满1座 → 1天1358座
```

### 能量级连续对比

用连续的数据对比让观众感受量级差距：
```
人类所有核弹500兆吨 vs 小行星60万兆吨 vs 恐龙灭绝7500万兆吨 vs 地震=核弹×20亿
```

### "三秒/三分钟"擦边暗示

用暗示性幽默做开头钩子，不说破但观众秒懂：
```
你问问你兄弟，三秒的运动都能给累瘫。
又能增粗又能变大，一听就是个好东西。
```

### 成语三连转折

前两个正经，第三个突然变调：
```
一气呵成，一鼓作气，一声不吭。
```

### 跨集自引用

引用自己之前视频的内容，形成"道荣宇宙"：
```
经常问为什么虾不能长得和猪一样大的朋友们……
之前讲过XX的故事……
```

## 第六步：科学解释方式

### 原则：清晰但不学术

**正确示范：**
- "辣椒素不溶于水，所以喝水不仅不能解辣，还会把它扩散到整个口腔。"
- "果糖的甜度是蔗糖的1.7倍，而且温度越低越甜。"

**错误示范：**
- "甲基黄嘌呤类生物碱在人体内会阻断腺苷受体……"

### 解释的三个层次

**第一层：生活比喻**（最优先）
- "相当于给你加了个高亮处理，就像战斗机雷达锁定一样。"

**第二层：数字对比**
- "蚊子的复眼300个小眼，蜻蜓有3万多个。"

**第三层：机制原理解释**（慎用，只有必要时）
- 只有当听众一定会有疑问时才解释机制，且要用生活化语言。

## 第七步：情感落点

### 升华的四种方向

**1. 回归温情（最常用）**
```
XX虽然有这些缺点，但它XXXX。
其实我们今天能吃到XXXX，要感谢XXXX。
```

**2. 自我反思（尺度要准）**
```
所以你看人类XXX。
那人类XXX呢？
```

**3. 哲学升华（慎用）**
```
进化没有对错，只是策略不同。
过程上失败了，但结果上成功了。
```

**4. 扎心收尾（尺度要准）**
```
所以说/所以说在XXXX，在地球online这个服务器上，从来不存在XXXX。
```

### 祝福收尾（适合食品类话题）

```
最后祝大家XXXX。
```

## 第八步：互动钩子设计

结尾留一个让观众评论的点：

**提问式：**
```
你们觉得XXXX？
评论区给我整两句。
```

**自嘲式：**
```
你们小时候有没有XXXX的经历？
```

**选择题式：**
```
A. XXX B. XXX C. XXX
```

**恐怖画面急刹车：**
```
至于什么是XX啊，我劝大家千万不要手贱去搜。
```
制造好奇心但不展开，引导观众自己搜索。

**结尾双关收束：**
从科学话题自然过渡到网络用语/人生哲理的双关：
- 动物舔盐 → "颜值越高舔你的人越多"
- 鳗鱼极危 → "大本钟下面送快递，上面摆下面寄"

**结尾引用古文不解释：**
```
说出吾名吓汝一跳。
```
直接收束，不解释出处，制造余韵。

**"具体的大家可以自己去看看"留白：**
不给结论，让观众自己去搜，引发评论区讨论。

## 第九步：绝对禁区

**禁用词/句式：**
- 首先、其次、最后（除非真的只有三点）
- 综上所述、总而言之
- 值得注意的是、不难发现
- 让我们来看看、接下来让我们
- 说白了、本质上、换句话说
- 不可否认

**禁用开头：**
- "随着科技的进步"
- "在当今社会"
- "大家都知道"

**标点禁令：**
- 冒号 ":" → 用逗号替代
- 破折号 "——" → 用逗号或句号替代
- 过多使用顿号"、" → 改用逗号

## 第十步：叙事角度

### 1. 站在食物/动物视角控诉人类

把虾/生蚝/鳗鱼等作为"受害者"，用它们的视角讲述人类的"暴行"，制造荒诞喜感。
```
人家特地进化的全身是刺儿，一看就不好惹，结果XX一看……
```

### 2. "帮对手算账"视角

站在狼/细菌/对立面的视角分析"打不打得过"，让观众代入弱势一方。

### 3. "纠正认知偏差"框架

全篇围绕"你以为的vs实际的"展开：
- 开头：点出高估/低估
- 中间：用数据和案例论证
- 结尾：回扣"所以还是那句话"

### 4. 博弈论/利弊分析

把动物行为翻译成经济学决策：
- 狗受伤有人治，狼受伤会饿死
- 成本对比：人工繁育100块 vs 野生捕捞几块钱

### 5. 地球/星球拟人化视角

站在地球/海洋视角嘲讽人类的渺小：
```
恐怖直立猿，竟然想着用我的皮肤碎片来炸我。
什么核弹？去和我1.4亿亿吨海水说去吧。
```

### 6. "地球online版本史"叙事

把地质年代讲成游戏版本迭代故事：
- 石炭纪 = 某个版本
- 白腐真菌出现 = 加更了一个版本
- 文明灭绝 = 版本被删/被重置
- 火星 = 另一个测试服，最终崩了

### 7. 时间线推演叙事

按时间节点逐步推进，每个阶段越来越严重：
```
雨刚开始→1个月后→2个月后→4个月后→6个月后→彻底失控
```
关键：每个时间点都有"你以为→其实"的小反转。

## 第十一步：比喻体系

### 职场/体制内语言

把动物行为翻译成职场语言：
- "管吃管住，医疗工伤全包"
- "带薪休假"
- "牺牲了还包丧葬，甚至包子女抚养"
- "多少狼想给人类当狗还没这门子呢"

### "讨好性XX"造词

把社交概念嫁接到非人事物上：
- "讨好性食物"（虾）
- 可拓展：讨好性设计、讨好性进化

### 学历梗

把常识性知识说成学位：
- "攻读过初中生物学位的都知道"

### 家电/电脑比喻

用日常电子设备比喻自然现象：
- "湿漉漉的微波炉"（温室效应的地球）
- "电脑在两种模式之间切换，系统报错"（身体能量拐点）
- "煤炭就是植物的压缩包，简称ZIP"
- "相当于给地球撑了一把伞"

### "老天爷追着喂饭吃"

形容天然优势碾压，不需要努力就赢了：
```
澳大利亚的铁矿石，简直是老天爷追着喂饭吃的存在。
```

### "一顿操作猛如虎"改编

网络句式改编，后半句出人意料：
```
一顿操作猛如虎，一看成本两万五。
```

### "七分天注定三分靠打拼"改编

经典歌词/俗语改编，故意数学不对增加笑点：
```
七分天注定，三分靠打拼，还有九十分靠的是地壳稳不稳、气候配不配。
```

### "梦中情X"造词

网络流行语套用：
- "梦中情矿"（铁矿石）
- 可拓展：梦中情菌、梦中情鱼

### "亲妈本妈"拟人

把来源/本质拟人化：
```
BIF就是铁矿石的亲妈本妈。
```

## 第十二步：影视/流行文化引入规则

可以引用电影、动漫、游戏中的经典场景做引子，但要：
1. 选大众认知度高的（侏罗纪公园、火影忍者等）
2. 先描述场景，再用科学打破
3. 引用后立刻给"夏侯惇"式评价

### 网络梗/流行语嵌入规则

可以直接使用但不解释的网络梗：
- "有的兄弟，有的" — 过渡句
- "啪的一下，很快啊" — 马保国梗
- "有一个算一个" — 强调
- "请受小弟一拜" — 表达佩服
- "当过牛马的都知道" — 打工人共鸣
- "打过泰森的朋友们都知道" — 用不可能的经历做"众所周知"

### 古诗文/历史典故嵌入

直接引用不解释，观众自行品味：
- "南村群童欺你老无力" — 杜甫《茅屋为秋风所破歌》
- "色厉胆薄，好谋无断，干大事而惜身" — 三国评语
- "说出吾名，吓汝一跳" — 张飞式霸气

### Minecraft等游戏攻略式收尾

突然跳到游戏攻略视角打破第四面墙：
```
从攻略来看，煤炭获取方式有露天矿场、洞穴挖矿、击败凋零骷髅、村民交易……小小煤炭，还想难倒我们mc玩家吗？
```

## 第十三步：实用信息嵌入规则

在科普文案中适当嵌入真正有用的生存/生活知识：
- "躲进小区的人防地下车库基本上都没事"
- "只要有两个人以上，狼群一般自己就散了"
- "趁着还有体力赶紧找到庇护所或者摇人"
这些信息增加视频的收藏价值。

## 第十四步：口播节奏与分行规则

### "啊"字节奏标记

单独成行的"啊"用作口播换气点和情绪转折：
- 在数据轰炸前用"啊"做缓冲
- 在反转前用"啊"做蓄力
- 不要连续两个"啊"，要有间隔

### "听到这就有人要问/说了"过渡

模拟弹幕/评论区质疑，先替观众问出来再回答：
```
听到这就有人要问了，XX呢？
听到这就有人要说了，那XX怎么办？
```
这个句式自带节奏停顿，适合引出新段落。

### 短句为王

- 口播文案单句不超过20字
- 长信息拆成多个短句
- 数据单独成句以增强冲击力
- 竖屏口播适合一行一句的视觉节奏

## 第十五步：四层质检清单

### L1 硬性规则检查

- [ ] 开头第一句有没有反常识点？
- [ ] 有没有使用"夏侯惇"系列谐音梗？
- [ ] 有没有具体数据/算账？
- [ ] 有没有游戏化概念（地球online/技能树等）？

### L2 风格一致性检查

- [ ] 短句是否占大多数？（单句不超过20字）
- [ ] 有没有语气词（啊/呢/嘛/啊）？
- [ ] 有没有顺口溜/成语新编？
- [ ] 结尾有没有情感落点？
- [ ] 有没有"听到这就有人要问了"过渡句？
- [ ] 有没有废话文学/擦边暗示增加活人感？

### L3 内容质量检查

- [ ] 科学解释是否清晰但不学术？
- [ ] 有没有历史/地理/生物知识的穿插？
- [ ] 有没有同类扩展（举一反三）？
- [ ] 有没有数据的单位换算可视化？
- [ ] 有没有嵌入实用信息（增加收藏价值）？

### L4 活人感检查

- [ ] 读起来像朋友聊天还是像写报告？
- [ ] 有没有"道龙腔"的感觉（自嘲/自黑/自嗨）？
- [ ] 有没有可以让观众评论的互动点？
- [ ] 有没有网络梗/流行语的自然嵌入？
- [ ] 有没有跨集自引用（道荣宇宙感）？
