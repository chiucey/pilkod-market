## 常见功能模块设计模式

### 登录/注册模块

#### 设计模式
- **社交登录优先**：降低注册门槛，减少表单填写
- **渐进式表单**：先收集最必要信息，后续逐步完善
- **魔法链接登录**：无密码登录，提升安全性和便捷性
- **手机号快捷登录**：验证码替代密码，适合移动端

#### 优质案例
| 产品名称 | 模块名称 | 设计亮点 |
|----------|----------|----------|
| Airbnb | 登录模块 | 社交登录突出、手机/邮箱切换便捷 |
| Notion | 登录模块 | 魔法链接登录、极简视觉 |
| Slack | 登录模块 | 企业邮箱识别、工作区记忆 |
| 微信 | 登录模块 | 扫码登录、无缝跨端体验 |
| Spotify | 注册流程 | 分步表单、个性化推荐引导 |

### 表单设计模块

#### 设计模式
- **分步表单**：长表单拆解，降低用户心理负担
- **智能默认值**：根据上下文预填充，减少输入
- **实时验证**：即时反馈错误，避免提交后才发现
- **条件展开**：根据用户选择动态显示相关字段

#### 优质案例
| 产品名称 | 模块名称 | 设计亮点 |
|----------|----------|----------|
| Typeform | 表单设计 | 分步展示、进度指示、对话式体验 |
| Google Forms | 表单设计 | 自动保存、响应式布局、数据分析 |
| Turbotax | 税务表单 | 复杂表单简化、智能引导 |
| 医疗预约平台 | 预约表单 | 时间选择器、科室筛选联动 |
| Stripe | 结算表单 | 卡号自动识别、实时验证 |

### 导航设计模块

#### 设计模式
- **底部导航**：移动端常用，拇指热区覆盖
- **抽屉导航**：节省空间，适合功能较多的应用
- **顶部标签导航**：适合功能扁平的产品
- **混合导航**：底部主功能 + 顶部子功能

#### 优质案例
| 产品名称 | 模块名称 | 设计亮点 |
|----------|----------|----------|
| Instagram | 底部导航 | 图标+文字、突出创建按钮 |
| 网易云音乐 | 侧边导航 | 抽屉式、个性化入口聚合 |
| Notion | 侧边栏导航 | 层级展开、收藏固定 |
| 支付宝 | 首页导航 | 九宫格布局、自定义入口 |
| iOS App Store | 标签导航 | 图标动态、Today突出 |

- **优惠信息聚合**：清晰展示可用优惠和已用优惠

### 空/错误状态模块

#### 设计模式
- **友好提示**：避免生硬的错误码，用通俗语言说明
- **行动引导**：提供明确的下一步操作
- **插画缓解**：用插图降低用户的负面情绪
- **自动恢复**：提供重试、刷新等自动恢复机制

#### 优质案例
| 产品名称 | 模块名称 | 设计亮点 |
|----------|----------|----------|
| Slack | 网络断开 | 顶部提示条、自动重连 |
| Dropbox | 空文件夹 | 插画+引导上传 |
| Chrome | 网页无法访问 | 恐龙游戏、错误说明清晰 |
| Asana | 空项目 | 引导创建第一个任务 |
| Spotify | 无搜索结果 | 推荐相关内容、热门搜索 |

## 搜索策略

### 根据评估对象确定搜索方向

1. **识别产品类型**
   - 电商、社交、工具、内容、金融、出行、健康等
   - 确定同类型的标杆产品

2. **识别功能模块**
   - 登录注册、表单、导航、搜索、购物车、个人中心等
   - 确定该模块的优质案例

3. **识别设计问题**
   - 根据评估发现的问题，搜索解决方案
   - 例如：表单填写慢 → 搜索"高效表单设计案例"

### 搜索关键词模板

```
[产品类型] + [功能模块] + 设计案例
[功能模块] + UI设计 + 最佳实践
[具体问题] + 设计解决方案
[竞品名称] + [功能模块] + 设计分析
```

## 使用建议

1. **优先参考同类型产品**：确保设计模式和用户场景匹配
2. **关注设计决策背后的原因**：而非仅仅模仿表面样式
3. **结合自身产品特点调整**：避免生搬硬套
4. **持续更新案例库**：关注行业动态和设计趋势
5. **验证案例可用性**：确保参考链接有效、图片可访问
