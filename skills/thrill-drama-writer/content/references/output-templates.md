# 完整输出格式模板

## 模块1：主题与创意定位器 (ThemeAnchor)

**输出格式**

```
【一句话故事】
[≤15字核心概念，精炼概括故事主线]

【赛道定位】
[类型/子类型/平台节奏要求，明确市场定位]

【目标受众】
[性别/年龄/核心诉求，精准画像]

【主题与价值观】
[主旨/价值底色/不可逾线点，明确作品精神内核与边界]

【差异化要素】
[独特设定/叙事结构创新/人物关系创新/情感表达创新，具体描述创新点]

【风险预警】
[同质化风险/逻辑漏洞风险/审查风险/审美疲劳点，具体列出潜在问题及规避建议]
```

**质量控制检查**
- [ ] 一句话可复述且不含大而空词
- [ ] 冲突源可连贯支撑多集推进
- [ ] 主题与价值观清晰且不含越界表达
- [ ] 赛道与受众匹配明确，避开主流雷区
- [ ] 差异化可落到具体桥段或设定

## 模块2：背景与世界观构建器 (WorldForge)

**输出格式**

```
【背景摘要】
[时间/地点/行业或圈层，简洁概括故事背景]

【世界规则清单】
- 身份/阶层：[具体描述身份阶层划分及其影响]
- 权力/制度：[具体描述权力结构、社会制度及其运作方式]
- 资源/禁忌：[具体描述稀缺资源、社会禁忌及其对人物行为的约束]

【规则的破坏与修复】
[当核心规则被打破时，会产生何种后果？剧情将如何通过人物行为或事件来修复/重塑这些规则？]

【冲突触发点】
[规则与人物目标的直接冲突点，明确矛盾爆发的核心]
```

**质量控制检查**
- [ ] 设定不喧宾夺主，服务剧情推进
- [ ] 规则可解释关键反转而非强行开挂
- [ ] 背景可生成持续性的矛盾与任务

## 模块3：人物设定工坊 (CharSmith)

**输出格式**

```
【主角档案】
- 身份标签：社会角色/外在特征/识别度
- 核心欲望：最强烈渴望获得的东西（具体化）
- 致命缺陷：性格弱点/能力盲区/情感创伤
- 独特能力：解决问题的专长/天赋
- 成长路径：从缺陷到成熟的转变轨迹

【配角群像】（2-4人）
- 功能定位：助攻型/镜像型/引导型/阻碍型
- 关系属性：与主角的情感连接和利益关系
- 记忆标签：观众容易记住的特质标签

【反派设计】
- 动机逻辑：行为的内在驱动力（非纯粹恶意）
- 能力评估：对抗主角的资源和手段
- 魅力包装：让观众"恨之入骨又欣赏"的特质

【关系图谱】
[核心人物间的利益、情感、权力关系网]
```

**质量控制检查**
- [ ] 主角"欲望-障碍-代价-成长"链闭环
- [ ] 反派有魅力且压强足够，非工具人
- [ ] 配角功能明确，能制造/化解节点性问题
- [ ] 人设可解释关键反转与爽点

## 模块4：总剧情框架架构师 (PlotFrame)

**输出格式**

```
【故事主线】
[6-10句完整事件链]

【幕次划分】
- 第一幕（建立）：人物登场/世界介绍/冲突萌芽
- 第二幕（对抗）：矛盾升级/多重阻碍/情感波动
- 第三幕（解决）：最终对决/真相揭示/价值确认

【关键转折点】
- 激发事件：故事真正开始的触发点
- 中点转折：改变局面的重大变化
- 危机时刻：主角面临最大威胁
- 高潮决战：最终冲突的爆发点
- 结局回响：主题落地的情感确认

【悬念布局】
[每幕结尾的钩子设计]
```

**质量控制检查**
- [ ] 每一阶段都有"可演化"的障碍
- [ ] 高潮前伏笔充分，反转合情合理
- [ ] 终局与人物弧/主题形成闭环

## 模块5：分集冲突设计器 (EpBuilder)

**输出格式**

```
【第X集设计】

开场钩子（前20秒）：
- 视觉冲击：异常画面/紧张情况
- 信息悬念：关键信息的部分透露
- 情绪调动：直击目标受众痛点

核心目标：主角本集要达成的具体目标

主要障碍：
- 外部阻力：他人阻挠/环境限制
- 内部冲突：心理障碍/能力不足
- 时间压力：截止期限/紧急情况

戏剧转折：信息反转/力量对比变化/关系重组

结尾钩子：
- 信息缺口：重要真相的部分揭露
- 危机升级：新威胁的出现
- 情感断点：关系的重大变化
```

**质量控制检查**
- [ ] 目标明确且与主线相关
- [ ] 冲突非重复堆砌，障碍类型有变化
- [ ] 爆点兼具"意外性+合理性"
- [ ] 收尾必留观看驱动力

```
【高潮爆发点】
- 触发时机：第X集第Y分钟
- 爆发形式：对话交锋/行动对决/真相大白
- 情感峰值：愤怒/感动/震撼的最高点
- 价值确认：主题思想的戏剧化体现
```

**质量控制检查**
- [ ] 升级非机械加码，来源多样可交叉
- [ ] 反转伏笔可回溯，非生造巧合
- [ ] 高潮兼顾情绪峰值与信息价值

## 模块7：爽点引擎 (ThrillEngine)

**输出格式**

```
【主爽点体系】（2-3个）

类型1：本能层（财富逆袭/颜值碾压/力量展示）
- 触发机制：特定情境下的能力释放
- 表现形式：视觉化的优势展示
- 情感回报：满足感/优越感/安全感

类型2：社会层（正义伸张/地位提升/权威认可）
- 触发机制：道德或制度的胜利
- 表现形式：他人的认可和敬畏
- 情感回报：尊严感/成就感/归属感

【辅爽点配置】
- 过渡型：缓解主爽点间的情感疲劳
- 铺垫型：为主爽点建立情感基础
- 变奏型：主爽点的不同表现形式

【释放节奏表】
| 集数 | 爽点类型 | 强度(1-10) | 持续时长 | 与悬念关系 |
|-----|---------|-----------|---------|-----------|
| 第1集 | 能力展示 | 6 | 30秒 | 制造期待 |
| 第3集 | 正义伸张 | 8 | 45秒 | 付费前预热 |

【创新爽点】
[结合当下热点的新型爽感设计]
```

**质量控制检查**
- [ ] 主爽点与主线绑定紧密
- [ ] 强度分级与间隔合理，避免疲劳
- [ ] 爽点与悬念/付费节点耦合良好

## 模块10：分集节奏与付费设计系统 (PacePay)

**输出格式**

```
【单集标准模板】（以3分钟为例）

0-20秒：开场钩子
- 冲击性画面或紧急情况
- 关键信息的悬疑性透露
- 目标受众痛点的直接触及

20秒-2分钟：核心冲突展开
- 目标建立：主角本集要达成什么
- 障碍出现：遇到什么阻力
- 努力过程：如何尝试解决

2-2.5分钟：转折爆点
- 信息反转：新情况的出现
- 力量对比变化：优劣势逆转
- 情感冲击：意外的人物反应

2.5-3分钟：悬念钩子
-更大威胁的预示
- 关键信息的部分揭露
- 情感关系的重大变化

【全剧节奏分区】
- 免费体验区（第1-5集）：建立人物+核心冲突
- 首付费区（第6-15集）：矛盾升级+局部高潮
- 深度付费区（第16-25集）：终极对决+主题升华

【付费节点设计】
- 触发时机：剧情最紧张的悬念点前
- 心理机制：强烈的"必须知道结果"冲动
- 价值包装：付费后的独特体验和信息
```

**质量控制检查**
- [ ] 免费区足够立人物与设悬念
- [ ] 付费节点落在"最想看的瞬间之前"
- [ ] 付费后强度与信息密度显著提升
- [ ] 单集模板不机械重复，存在变奏
