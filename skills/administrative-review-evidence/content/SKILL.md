# 行政复议证据准备技能

## 概述

本技能帮助行政机关及代理律师在行政复议程序中准备证据材料。根据行政行为的类型和具体案情，系统化地梳理需要提供的证据、编制证据目录、明确证明目的。

本技能依据以下法律法规设计：
- 《中华人民共和国行政复议法》（2023年修订，2024年1月1日起施行）
- 《中华人民共和国行政诉讼法》（2017年修正）
- 《最高人民法院关于行政诉讼证据若干问题的规定》（2002年）
- 《行政强制法》及各部门领域法律

## 法律依据

### 行政复议法证据规定（第四章第二节）

**第四十三条 证据种类**
行政复议证据包括：
（一）书证；
（二）物证；
（三）视听资料；
（四）电子数据；
（五）证人证言；
（六）当事人的陈述；
（七）鉴定意见；
（八）勘验笔录、现场笔录。

以上证据经行政复议机构审查属实，才能作为认定行政复议案件事实的根据。

**第四十四条 举证责任**
- **被申请人**：对行政行为的合法性、适当性负有举证责任
- **申请人**应当提供证据的情形：
  1. 认为被申请人不履行法定职责的，提供曾经要求履行的证据（被申请人依职权主动履行的除外）
  2. 提出行政赔偿请求的，提供受损害的证据（因被申请人原因导致无法举证的，由被申请人承担）
  3. 法律、法规规定需要申请人提供证据的其他情形

**第四十五条 行政复议机关调查取证权**
- 有权向有关单位和个人调查取证
- 查阅、复制、调取有关文件和资料
- 向有关人员进行询问
- 调查取证时不得少于两人，并应出示工作证件

**第四十六条 禁止事后取证**
- 行政复议期间，**被申请人不得自行向申请人和其他单位或个人收集证据**
- 自行收集的证据不作为认定行政行为合法性、适当性的依据
- 申请人或第三人提出行政行为作出时没有提出的理由或证据的，经行政复议机构同意，被申请人可以补充证据

**第四十七条 查阅权**
申请人、第三人及其委托代理人可以查阅被申请人提出的书面答复、证据、依据和其他有关材料（涉及国家秘密、商业秘密、个人隐私或危及国家安全、公共安全、社会稳定的除外）。

### 行政诉讼证据规定要点

**被告举证责任**
- 收到起诉状副本之日起**十日内**提供全部证据和规范性文件
- 逾期提供的，视为没有相应证据
- 不可抗力等正当事由可申请延期

**原告/申请人举证责任**
- 提供符合起诉条件的证据材料
- 起诉不作为案件需提供曾提出申请的证据
- 行政赔偿诉讼中证明损害事实

**禁止自行取证**
被告及其诉讼代理人在诉讼/复议过程中不得自行向原告/申请人和证人收集证据。

## 工作流程

### 步骤1：收集基础资料

用户需提供以下基础资料：

**必填信息：**
- 行政行为类型（八选一）
- 案件基本情况
- 行政行为作出时间
- 复议请求或答辩要点

**可选补充：**
- 已有证据材料清单
- 争议焦点说明
- 相关法律法规依据

### 步骤2：确定证据需求

根据行政行为类型，系统自动匹配该类行政行为的通用证据要求：

| 行政行为类型 | 核心证据模块 |
|-------------|-------------|
| 行政处罚 | 违法事实证据、程序合法证据、裁量合理性证据 |
| 行政强制 | 强制依据证据、执行程序证据、告知送达证据 |
| 行政征收 | 征收依据证据、数额计算证据、征缴程序证据 |
| 行政许可 | 申请材料、审查程序证据、决定依据证据 |
| 行政确认 | 确认事实证据、程序合法证据 |
| 行政裁决 | 事实认定证据、裁决程序证据 |
| 行政给付 | 给付依据证据、资格认定证据 |
| 行政检查 | 检查程序证据、事实认定证据 |

### 步骤3：生成证据清单

针对具体案件，生成以下内容：

**1. 证据清单**
- 序号
- 证据名称
- 证据类型
- 证据来源
- 证明内容摘要

**2. 证据目录**
- 按证据分组归类
- 标注证据页码范围
- 说明证据间的关联关系

**3. 证明目的对照表**
- 每项证明目的
- 对应证据
- 证明逻辑说明

### 步骤4：输出格式

最终交付：
- **证据清单**（Excel/Word格式）
- **证据目录**（标准格式）
- **证明目的说明书**

### 主体证据
- 行政主体资格证明
- 执法人员执法证件
- 组织机构代码证
- 授权委托书

- 立案审批材料

- 告知书及送达回证
- 听证笔录（如适用）

- 询问笔录

- 电子数据

- 送达凭证

## 证据准备注意事项

### 举证责任分配

1. **被申请人（行政机关）承担主要举证责任**
   - 证明行政行为合法性和适当性
   - 提供作出行政行为的全部证据和依据
   - 答复期限：**收到申请书副本或笔录复印件之日起十日内**

2. **申请人承担特定举证责任**
   - 不作为案件：提供曾要求履行的证据
   - 行政赔偿：提供受损害证据
   - 起诉条件：提供符合起诉条件的证据

### 证据时限要求

| 事项 | 期限要求 |
|------|----------|
| 被申请人答复并举证 | 收到申请书副本之日起10日内 |
| 行政复议机构受理后发送申请书副本 | 受理之日起7日内 |
| 被申请人补充证据 | 经行政复议机构同意 |
| 申请人查阅证据材料 | 行政复议期间 |

### 证据三性审查

1. **真实性**：证据应当真实、可靠
2. **合法性**：收集程序合法，不违反禁止性规定
3. **关联性**：与待证事实具有证明关系

### 证据排除规则

以下证据不能作为认定行政行为合法性的依据：
- 被申请人自行收集的证据（复议期间）
- 以违反法律禁止性规定或侵犯他人合法权益方法取得的证据
- 严重违反法定程序收集的证据

### 复议与诉讼衔接

- 复议机关可要求当事人提供或补充证据
- 申请人、第三人可查阅被申请人提出的书面答复、证据、依据等
- 复议期间，申请人提出新理由或证据的，经同意可补充
