# 行政复议证据检查清单

## 一、行政处罚类检查清单

### 基础信息确认
- [ ] 案件名称：
- [ ] 行政处罚决定书文号：
- [ ] 处罚类型：
- [ ] 当事人信息：
- [ ] 作出日期：
- [ ] 复议机关：

### 主体证据清单
- [ ] 行政主体：是否具有法定职权
- [ ] 执法人员：是否持有合法执法证件
- [ ] 当事人：主体资格证明是否齐全
- [ ] 利害关系人：是否需要通知第三人

### 程序证据清单
- [ ] 立案审批：是否有立案审批文书
- [ ] 调查取证：调查程序是否合法
- [ ] 权利告知：是否告知当事人陈述申辩权
- [ ] 听证程序：是否依法告知听证权利
- [ ] 集体讨论：重大处罚是否经集体讨论
- [ ] 法制审核：重大处罚是否经法制审核
- [ ] 审批程序：处罚决定是否经合法审批

### 事实证据清单
- [ ] 违法事实：事实是否清楚
- [ ] 证据充分：证据是否达到确实充分标准
- [ ] 证据关联：证据与违法事实是否具有关联性
- [ ] 证据来源：证据来源是否合法
- [ ] 证人证言：证人是否符合条件
- [ ] 鉴定意见：鉴定机构是否具有资质
- [ ] 当事人陈述：当事人陈述是否完整

### 法律依据清单
- [ ] 适用法律：法律条款是否准确
- [ ] 裁量基准：是否参照裁量基准
- [ ] 规章依据：规章是否现行有效

### 送达证据清单
- [ ] 告知书送达：送达回证是否完整
- [ ] 决定书送达：送达回证是否完整
- [ ] 送达方式：是否符合法定方式
- [ ] 送达时间：是否在法定期限内送达

- [ ] 公共利益：是否属于公共利益需要

### 程序证据清单
- [ ] 社会稳定风险评估：是否进行风险评估
