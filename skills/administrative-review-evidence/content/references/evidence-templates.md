# 行政复议证据准备模板

## 一、法律依据概述

### 行政复议法（2023年修订）证据规定

| 条款 | 主要内容 |
|------|----------|
| 第43条 | 证据种类：书证、物证、视听资料、电子数据、证人证言、当事人陈述、鉴定意见、勘验笔录/现场笔录 |
| 第44条 | 举证责任：被申请人承担合法性、适当性举证责任；特定情形下申请人承担举证责任 |
| 第45条 | 复议机关调查取证权：不少于两人，出示工作证件 |
| 第46条 | 禁止事后取证：被申请人复议期间不得自行收集证据 |
| 第47条 | 查阅权：申请人、第三人可以查阅证据材料（涉及国家秘密等除外） |

### 行政诉讼证据规定要点（2002年）

| 条款 | 主要内容 |
|------|----------|
| 第1条 | 被告应在收到起诉状副本之日起10日内提供全部证据 |
| 第4条 | 原告应提供符合起诉条件的证据材料 |
| 第7条 | 原告应在开庭审理前或法院指定日期提供证据 |
| 第60条 | 被告复议/诉讼中自行收集的证据不能作为认定合法性的依据 |
