# CNKI法学论文写作助手

中国知网(CNKI)是中国最大的学术文献数据库，本助手帮助科研工作者和研究生高效使用CNKI进行法学研究。

## 核心功能

### 1. 简单检索

适用于快速查找单一主题的法学文献：

**检索策略**：
- 输入核心关键词（如"刑事和解"、"知识产权保护"）
- 使用同义词扩展（如"合同欺诈"→"合同诈骗"）
- 添加学科限定（民商法学、刑法学、经济法学等）

**示例检索式**：
```
主题: "数据安全" AND "个人信息保护"
```

### 2. 高级检索

适用于精确查找和复杂查询：

**构建检索式**：
| 字段 | 说明 | 示例 |
|------|------|------|
| 题名 | 论文标题 | TI:消费者权益 |
| 关键词 | 核心概念 | KY:网络侵权 |
| 摘要 | 论文摘要 | AB:数据跨境 |
| 作者 | 研究者姓名 | AU:张三 |
| 单位 | 所属机构 | GAIN:北京大学 |
| 发表时间 | 出版年份 | PT:2020-2024 |

**逻辑运算符**：
- `AND`：同时包含两个关键词
- `OR`：包含任一关键词
- `NOT`：排除某个关键词

**复合检索示例**：
```
(TI:环境保护 AND KY:民事责任) NOT TI:行政法
```

### 3. 出版物检索

检索特定期刊、博硕士论文、会议文献：

**期刊分类导航**：
- 法学核心期刊（CLSCI来源期刊）
- CSSCI来源期刊
- 北大中文核心期刊
- 普通学术期刊

**学科分类**：
```
民商法学 | 刑事法学 | 行政法学 | 经济法学
环境与资源保护法学 | 国际法学 | 法律史 | 宪法学
```

### 4. 核心期刊检索

法学核心期刊识别与检索：

**CLSCI来源期刊**：
- 《法学研究》《中国法学》《法学研究》
- 《法学评论》《法律科学》《法商研究》
- 《政法论坛》《现代法学》《法学论坛》
- 《法制与社会发展》《比较法研究》

**检索策略**：
1. 选择期刊导航 → 法学
2. 勾选"核心期刊"筛选
3. 按影响因子/被引次数排序

### 5. 作者检索

查找特定学者及其学术产出：

**检索路径**：
1. 首页搜索框选择"作者"
2. 输入学者姓名（注意重名情况）
3. 结合单位筛选（如"武汉大学法学院"）

**作者画像信息**：
- 发表论文数量
- 合作网络分析
- 研究领域分布
- H指数/总被引频次

## 法学论文写作全流程支持

### 选题阶段

**文献调研策略**：
- 检索近5年核心期刊论文
- 追踪学术热点和争议问题
- 梳理研究脉络和发展趋势

**推荐检索式**：
```
时间范围: 近5年
来源: 核心期刊
学科: 法学
排序: 被引频次
```

### 写作阶段

**文献综述写作**：
- 系统检索相关主题文献
- 按观点流派分类整理
- 识别研究空白和争议点

**研究方法参考**：
- 法教义学分析方法
- 实证研究（案例分析）
- 比较法研究
- 法经济学分析

### 引用规范

**CNKI引用格式**：
```plaintext
[序号] 作者. 题名[D/J]. 刊名, 出版年, 卷(期): 页码.
例:
[1] 王利明. 论合同解除的条件[J]. 中国法学, 2020(3): 45-62.
```

**查重注意事项**：
- 正确引用，避免重复率过高
- 使用自己的语言表述
- 合理使用引用格式

## 检索技巧

### 提高查全率
- 使用同义词、近义词
- 使用截词符（*）模糊匹配
- 扩大时间范围

### 提高查准率
- 使用专业术语
- 限定来源期刊级别
- 使用精确匹配

### 常见问题解决

| 问题 | 解决方案 |
|------|----------|
| 检索结果过多 | 添加限定词、使用高级检索 |
| 检索结果过少 | 使用同义词、扩大时间范围 |
| 无法下载全文 | 使用机构权限、申请文献传递 |
| 查重率过高 | 改写表述、增加引用、合理使用检测工具 |

## 输出内容

完成检索后，提供：
1. **检索结果摘要**：相关文献列表及关键信息
2. **检索式建议**：优化的检索策略
3. **下一步建议**：深入检索方向或相关主题
4. **论文写作指导**：针对具体研究问题的建议

## 注意事项

- CNKI部分功能需要机构账号权限
- 法学研究需关注最新法律法规修订
- 建议交叉检索多个数据库（Westlaw、HeinOnline等）
- 注意学术规范，避免不当引用
