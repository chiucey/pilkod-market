## 概述

PPT制作团队是一个模块化的PPT制作系统，包含8个专业角色，通过三级严格审核机制确保输出质量。支持15+种专业风格，适用于不同场景需求。

### 核心特点

- **一键启动**：自然语言输入，自动调度所有角色
- **专业分工**：每个角色专注各自领域
- **三级审核**：自检→互检→终审，确保输出质量
- **15+风格**：覆盖政务、商务、科技、创意、高端等类别
- **质量门槛**：综合评分≥80分方可交付

## 团队协作机制

### 8个专业角色

#### 1. 项目经理 (ppt-pm)

**职责**：总负责人，协调所有角色，质量最终把控

**能力**：
- 解析用户需求
- 制定项目计划（含质量目标）
- 分配任务给各角色
- 监控整体进度
- 处理突发问题
- 终检确认

**入口命令**：
```
项目经理：帮我做一个产品发布会PPT，质量目标≥90分

**输出**：

## 三级审核体系

### 审核流程图

```
[内容创作] → [一级自检] → [二级互检] → [三级终审] → [交付]
     ↓           ↓           ↓           ↓
  制作专家    各角色自查   核查+制作    统筹+监督+经理
```

### 一级自检（角色自查）

**执行角色**：各内容创作角色
**触发时机**：每个角色完成自己负责的内容后
**检查项**：
- 数据来源是否标注
- 内容是否完整
- 格式是否符合规范
- 基本逻辑是否一致

**输出格式**：
```markdown
# [角色]一级自检报告

## 自检项目
| 检查项 | 标准 | 结果 | 说明 |
|--------|------|------|------|
| 来源标注 | 100%标注 | ✓/✗ | - |
| 内容完整 | 无遗漏 | ✓/✗ | - |
| 格式规范 | 符合规范 | ✓/✗ | - |
| 逻辑一致 | 基本无误 | ✓/✗ | - |

## 发现问题

## 工作流程详解

### 标准流程（推荐）

```
用户输入 → 项目经理 → 调研+核查 → 大纲+风格 → 制作 → 三级审核 → 交付
```

**时间参考**（20页PPT）：
- 项目启动：0.5小时
- 调研+核查：2小时
- 大纲+风格：1.5小时
- 制作：3小时
- 三级审核：1.5小时
- **总计**：约8.5小时

### 简化流程（快速）

```
用户输入 → 项目经理 → 大纲+风格 → 制作 → 二级审核 → 交付
```

**适用场景**：
- 内容简单（<10页）
- 时间紧迫
- 质量要求较低（≥70分）

### 完整流程（大型项目）

```
用户输入 → 项目经理 → 调研 → 核查 → 大纲 → 风格 → 制作 → 统筹 → 监督 → 修改 → 复审 → 交付
```

**适用场景**：
- 重要汇报（≥30页）
- 质量要求高（≥90分）
- 多轮审核

## 常见问题

### Q1: 如何指定质量目标？

**A**: 在启动项目时指定：
```
PPT：主题，风格，页数，质量目标≥85分
```

### Q2: 三级审核是必须的吗？

**A**: 根据项目规模和重要性：
- 大型项目（≥20页）：必须三级审核
- 中型项目（10-20页）：建议三级审核
- 小型项目（<10页）：可简化为二级审核

### Q3: 如何跳过某些步骤？

**A**: 使用跳过命令：
```
跳过：核查  # 跳过核查步骤
跳过：调研  # 跳过调研步骤（使用用户提供的资料）
```

**注意**：跳过步骤可能影响质量评分

### Q4: 审核不通过怎么办？

**A**: 根据审核报告修复问题：
1. 查看审核报告中的问题清单
2. 按级别修复（Critical > Major > Minor）
3. 提交复审

### Q5: 如何选择合适的风格？

**A**: 参考风格匹配表：

| 场景 | 推荐风格 |
|------|----------|
| 政府汇报 | 政务汇报、政务简洁 |
| 商业提案 | 商务蓝、专业灰 |
| 技术分享 | 科技黑、创新蓝 |
| 产品发布 | 创新蓝、科技黑 |
| 金融报告 | 金融严谨、高端金 |
| 创意展示 | 活力橙、艺术紫 |
| 高端定制 | 高端金、暗黑系 |

### Q6: 调研数据从哪来？

**A**: 调研专家会使用：
- 网络搜索（官方数据源）
- 公开数据（国家统计局、行业协会）
- 行业报告（艾瑞、易观、IDC等）
- 政府文件（政策文件、法规）
- 用户提供的资料

### Q7: 支持哪些输出格式？

**A**: 目前支持：
- PPTX格式（微软PowerPoint）
- PDF格式（导出）
- Keynote格式（需转换）

### Q8: 如何加快制作速度？

**A**: 优化方案：
1. 提供更详细的资料（减少调研时间）
2. 选择标准风格（减少风格设计时间）
3. 简化流程（跳过非必要步骤）
4. 预付费用（优先处理）
