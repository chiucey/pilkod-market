# PPT大纲模板 v2.0

## 标准大纲格式（含质量目标）

```markdown
# [PPT主题]

## 基本信息
- **主题**：[主题名称]
- **风格**：[从15+风格中选择]
- **页数**：[总页数]
- **受众**：[目标受众]
- **质量目标**：≥85分

## 页面结构

| 页码 | 类型 | 标题 | 核心要点 | 风格元素 |
|------|------|------|----------|----------|
| 1 | 封面 | [标题] | 主题、副标题、汇报人、日期 | [风格规范] |
| 2 | 目录 | [目录] | 章节列表 | 章节编号 |
| 3 | [类型] | [标题] | [要点1]、[要点2]、[要点3] | [风格规范] |
| ... | ... | ... | ... | ... |
| N | 结束 | [感谢] | 单位、联系方式 | [风格规范] |

## 章节结构

### 第一章：[章节名称]

#### [页面标题]
- 要点1
- 要点2
- 要点3

#### 一级自检报告
- 逻辑一致性：✓/✗
- 内容完整性：✓/✗
- 风格匹配度：xx%

### 第二章：[章节名称]

#### [页面标题]
- 要点1
- 要点2

## 内容要求

### 数据要求
- 必须有具体数据支撑
- 数据来源需标注（含可信度评估）
- 数据需定期更新（时效性标注）
- 交叉验证（3个独立来源）

### 视觉要求
- 每页不超过5个要点
- 关键数据需突出显示
- 图表配合文字说明
- 风格统一（符合风格指南）

## 风格指南

### 配色方案
- 主色：[颜色代码]
- 辅色：[颜色代码]
- 强调色：[颜色代码]
- 背景：[颜色代码]
- 文字：[颜色代码]

### 字体规范
- 标题：[字体] [大小] [样式]
- 正文：[字体] [大小] [样式]
- 注释：[字体] [大小] [样式]

### 布局规范
- 页边距：左右0.5英寸
- 标题栏高度：1.2英寸
- 行间距：1.5倍

## 质量门槛

| 维度 | 最低要求 | 本项目目标 |
|------|----------|-----------|
| 准确性 | ≥80% | ≥90% |
| 完整性 | 100% | 100% |
| 逻辑性 | ≥70分 | ≥85分 |
| 规范性 | ≥80% | ≥90% |
```

## 大纲设计原则

### 结构原则
1. **逻辑清晰**：层次分明，论证有力
2. **内容平衡**：各章节页数相对均衡
3. **重点突出**：核心内容分配更多篇幅
4. **受众导向**：符合目标受众阅读习惯

### 内容原则
1. **数据支撑**：每个观点有数据支撑
2. **来源可靠**：数据来源可信度高
3. **时效性强**：使用最新数据
4. **要点精炼**：每个要点简洁明了

### 风格原则
1. **统一性**：全程风格一致
2. **专业性**：符合行业规范
3. **可读性**：排版清晰易读
4. **美观性**：视觉设计协调
