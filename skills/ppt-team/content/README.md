# PPT制作团队 v2.0 (ppt-team)

> 完整的PPT制作团队体系，包含8个专业角色，15+种专业风格，三级严格审核机制，确保输出质量。

## 核心升级

### v2.0 新增功能

- **三级审核体系**：自检→互检→终审，确保输出质量
- **15+种专业风格**：覆盖政务、商务、科技、创意、高端等类别
- **质量门槛标准**：综合评分≥80分方可交付
- **质量目标指定**：支持自定义质量目标（≥85分、≥90分等）

## 概述

ppt-team 是一个智能PPT制作团队系统，包含8个专业角色：

- 项目经理 (ppt-pm)
- 调研专家 (ppt-researcher)
- 核查专家 (ppt-verifier)
- 大纲专家 (ppt-outliner)
- 风格专家 (ppt-stylist)
- 制作专家 (ppt-maker)
- 统筹专家 (ppt-coordinator)
- 监督专家 (ppt-supervisor)

通过自然语言命令即可一键启动完整PPT制作流程，包含三级严格审核。

## 快速开始

### 一键生成PPT

```
PPT：无人机行业分析PPT，商务蓝风格，20页，质量目标≥90分
```

### 分步制作

```
调研：收集市场数据
大纲：设计PPT结构
风格：商务蓝风格
制作：生成PPT
审核：执行三级审核
```

## 三级审核体系

```
[内容创作] → [一级自检] → [二级互检] → [三级终审] → [交付]
     ↓           ↓           ↓           ↓
  制作专家    各角色自查   核查+制作    统筹+监督+经理
```

### 审核流程

| 级别 | 执行角色 | 检查项 | 评分权重 |
|------|----------|--------|----------|
| 一级自检 | 各内容角色 | 来源标注、完整性、格式规范 | - |
| 二级互检 | 核查+制作 | 数据准确性、逻辑一致性、风格统一 | - |
| 三级终审 | 统筹+监督+经理 | 整体质量、受众匹配、专业度 | 100% |

### 质量等级

| 等级 | 分数 | 结论 | 处理方式 |
|------|------|------|----------|
| A（优秀） | 90-100 | ✓ | 直接交付 |
| B（良好） | 80-89 | ⚠ | 修复Minor问题 |
| C（合格） | 70-79 | ⚠ | 修复Major问题后复审 |
| D（不合格） | <70 | ✗ | 打回重做 |

## 15种专业风格

| 类别 | 风格名称 | 适用场景 |
|------|----------|----------|
| **政务类** | 政务汇报、政务简洁、红金典雅 | 政府汇报、党建、重大汇报 |
| **商务类** | 商务蓝、专业灰、金融严谨、咨询风格 | 商业提案、项目、金融报告 |
| **科技类** | 科技黑、创新蓝、AI智能 | 技术分享、产品发布、AI相关 |
| **创意类** | 清新绿、活力橙、艺术紫 | 环保、健康、营销、创意展示 |
| **高端类** | 高端金、简约白 | 奢侈品、极简风格、高端定制 |

## 团队架构

```
项目负责人（项目经理）
    ├── 调研专家 → 核查专家
    ├── 大纲专家
    ├── 风格专家
    ├── 制作专家
    ├── 统筹专家
    └── 监督专家
```

## 命令参考

| 命令 | 说明 |
|------|------|
| `PPT：主题，风格，页数，质量目标` | 一键启动项目（指定质量目标） |
| `调研：关键词` | 收集资料 |
| `大纲：主题` | 设计结构 |
| `风格：类型` | 确定视觉（可指定15+风格） |
| `制作` | 生成PPT |
| `审核：状态` | 查看审核状态 |
| `质量：目标` | 设置质量目标 |
| `状态` | 查看进度 |
| `报告` | 详细报告 |
