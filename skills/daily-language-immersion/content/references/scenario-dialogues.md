# 场景对话模板库

## 场景1：便利店篇 🇯🇵

### 词汇
- レジ (re-ji) - 收银台
- 温める (あたためる) - 加热
- 袋 (ふくろ) - 袋子
- 禁じて (きんじて) - 禁止
- |timezone - 时区

### 常用表达
```
「～を温めてください」请帮我加热～
「袋は要りますか？」需要袋子吗？
「これで払えますか？」可以用这个支付吗？
「レシートをお願いします」请给我小票
```

### 对话模板
```
客人：これ、温めてもらえますか？
店员：はい、レジにて温めますので、少々お待ちください。
客人：はい、お願いします。

店员：袋は 您需要袋子吗？
客人：はい、二枚ください。
店员：かしこまりました。

客人：合わせていくらですか？
店员：850円になります。
客人：カードで払えますか？
店员：はい、もちろんです。
```

## 场景2：餐厅点餐 🇯🇵

### 词汇
- 注文 (ちゅうもん) - 点餐
- おすすめ (おすすめ) - 推荐
- |lon (はい/いいえ) - 是/不是
- 頼む (たのむ) - 拜托/点餐
- お会計 (おかいけい) - 结账

### 常用表达
```
「おすすめはありますか？」有什么推荐吗？
「～をください」请给我～
「これをお願いします」请给我这个
「お水をください」请给我水
「お会計お願いします」买单
```

### 对话模板
```
服务员：いらっしゃいませ！何名様でしょうか？
客人：二人の場所です。
服务员：かしこまりました、こちらへどうぞ。

服务员：ご注文はお決まりですか？
客人：おすすめはありますか？
服务员：今日のおすすめは新鲜的三文鱼刺身です。
客人：じゃあ、それと天妇罗定食をお願いします。

服务员：お飲み物は如何ですか？
客人：啤酒两杯ください。

服务员：お会計、こちらで宜しいですか？
客人：はい、お願いします。カードで払えますか？
服务员：はい、大丈夫です。
```

## 场景3：问路指路 🇯🇵

### 词汇
- 駅 (えき) - 车站
- 道 (みち) - 路
- 右 (みぎ) - 右
- 左 (ひだり) - 左
- まっすぐ - 直走
- 交差点 (こうさてん) - 十字路口

### 常用表达
```
「～への道を教えてください」请告诉我去～的路
「ここですか？」是这里吗？
「何分くらいかかりますか？」大概需要多久？
「～は遠いですか？」～远吗？
```

### 对话模板
```
行人：すみません、迪士尼乐园への道は？
路人：迪士尼ですか？まず、この交差点を右に曲がって...
        300メートルほどまっすぐ行くと、左側にあります。

行人：左側ですね。ありがとうございます。
路人：いいえ、大丈夫です。
```

## 场景4：社交寒暄 🇯🇵

### 词汇
- 久しぶり (ひさしぶり) - 好久不见
- 最近 (さいきん) - 最近
- お元気ですか (おげんきですか) - 你好吗
- 仕事は (しごとは) - 工作是
- 趣味は (しゅみは) - 兴趣爱好

### 常用表达
```
「お名前は？」你叫什么名字？
「どこから来ましたか？」你从哪里来？
「ご職業は？」你的职业是？
「趣味は何ですか？」你的爱好是什么？
「 pleasure_meet you!」很高兴认识你！
```

### 对话模板
```
A：はじめまして、陳です。よろしくお願いします。
B：こちらこそ、田中です。どこから来ましたか？
A：中国から来ました。上海です。
B：へえ、上海言ったことがありますよ。很好的城市ですね！

A：陈です。Nice to meet you!
B：田中です。同上、お互に。
A：你在日本多久了？
B：已经3年了。你呢？
A：刚刚到这里，所以有很多不懂的地方。
B：有什么不懂的尽管问我。
```

## 场景5：职场交流 🇯🇵

### 词汇
- 会議 (かいぎ) - 会议
- 報告 (ほうこく) - 报告
- 確認 (かくにん) - 确认
- 資料 (しりょう) - 资料
- 質問 (しつもん) - 提问

### 常用表达
```
「～を確認してもいいですか？」可以确认一下～吗？
「質問があります」我有问题
「わかりました」我明白了
「下次开会是什么时候？」

「確認ですが、～ですか？」确认一下，是～吗？
「追加の質問ですが...」还有一个问题...
「了解しました」我知道了
```

### 对话模板
```
上司：今天的会议到此结束。大家有问题吗？

下属：确认一下，周五之前提交报告可以吗？

上司：是的，最好周四完成。

下属：了解。还有，报告需要用日语还是英语写？

上司：请用日语写。

下属：明白了。谢谢大家。
```

## 场景6：紧急情况 🇯🇵

### 词汇
- 助けて (たすけて) - 帮助我
- 病院 (びょういん) - 医院
- 警察 (けいさつ) - 警察
- 救急車 (きゅうきゅうしゃ) - 救护车
- 病院はどこですか？- 医院在哪里？

### 常用表达
```
「助けてください！」请帮帮我！
「警察を呼んでください」请叫警察
「病院はどこですか？」医院在哪里？
「大丈夫ですか？」你还好吗？
「何が来ましたか？」发生了什么？
```

### 对话模板
```
A：助けてください！
B：怎么了？

A：我的朋友晕倒了。
B：打119叫救护车！你在哪里？

A：在车站前面的咖啡店。
B：我们马上到。请让患者平躺，不要移动。
```

## 文化背景知识速览

### 日本服务文化
- 「おもてなし」款待精神
- 店员会说"欢迎下次光临"即使你买完就走
- 鞠躬礼仪：根据对方地位和场合不同，鞠躬角度不同

### 时间观念
- 日本人非常准时
- 约会迟到5分钟以上需要提前通知
- 商业场合提前5-10分钟到达

### 送礼文化
- 访客带伴手礼（持てなし）
- 颜色禁忌：白色（丧事）、绿色（ Healthcare相关）
- 数字禁忌：4（死）、9（苦）

### 餐桌礼仪
- 不要边走边吃
- 喝汤可以出声（拉面等）
- 吃面出声表示好吃
- 转盘式餐桌顺时针转
