# 督促机制与激励系统设计

## 连续打卡机制

### 打卡规则
```
每日打卡条件：
✓ 完成至少80%的训练内容
✓ 至少回复3条对话
✓ 通过当日小测验（正确率60%+）

补卡机制：
- 每周允许补卡1次
- 补卡需在48小时内完成
- 补卡不算连续天数
```

### 连续奖励
| 连续天数 | 奖励 | 徽章 |
|---------|------|------|
| 3天 | 解锁「初学者」称号 | 🏅 |
| 7天 | 解锁「坚持者」称号 | 🥉 |
| 14天 | 解锁「进阶者」称号 | 🥈 |
| 30天 | 解锁「专家」称号 | 🥇 |
| 60天 | 解锁「大师」称号 | 💎 |
| 100天 | 解锁「传奇」称号 | 👑 |

## 每日任务系统

### 必做任务
1. **晨间唤醒**（5分钟）- 复习昨日内容
2. **日间学习**（15分钟）- 今日新内容
3. **晚间巩固**（5分钟）- 打卡总结

### 周挑战
- **周一**：词汇周（背15个新词）
- **周二**：句型周（学10个句型）
- **周三**：对话周（完成3个场景）
- **周四**：听力周（听写练习）
- **周五**：口语周（录音练习）
- **周六**：复习周（本周内容总测）
- **周日**：自由周（选择薄弱项强化）

## 积分系统

### 积分获取
| 行为 | 积分 |
|------|------|
| 完成每日训练 | +10 |
| 连续打卡 | +2/天 |
| 主动造句 | +3/次 |
| 纠正错误并记住 | +5/次 |
| 分享学习心得 | +8/次 |
| 帮助其他学习者 | +10/次 |

### 积分商城
- 100积分：解锁一个新语言
- 200积分：获得「详细解析」功能
- 500积分：获得「1v1教练辅导」1次
- 1000积分：定制化学习路径

## 惩罚机制

### 温和惩罚（鼓励为主）
- **忘记打卡**：补卡后可继续连续天数
- **测验不及格**：提供详细解析，重新测试
- **连续3天未学习**：发送鼓励消息 + 降低当日任务难度

### 适度惩罚（增加责任感）
- **忘记打卡超过1天**：连续天数清零
- **作弊行为**：积分清零 + 取消徽章
- **辱骂他人**：禁言24小时

## 激励机制设计原理

### 目标设定理论（SMART原则）
- **S**pecific（具体）：每天学5个新词
- **M**easurable（可衡量）：完成对话练习
- **A**chievable（可达成）：难度适中
- **R**elevant（相关）：与融入目标相关
- **T**ime-bound（有时限）：20分钟内完成

### 即时反馈
- 每完成一个任务 → 立即获得积分/徽章
- 延迟满足感会导致动机下降
- 即时反馈保持学习热情

### 成就解锁
- 技能学习进度可视化
- 特殊日期成就（如「第1000个词汇」）
- 意外惊喜成就（如「午夜学习者」）
