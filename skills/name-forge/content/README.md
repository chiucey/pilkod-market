# 角色取名器

> 4路径×6记忆点，给角色起过目不忘的名字

## 功能介绍

从故事梗概和风格出发，一次性输出角色名、地名、组织名、道具名、书名/剧名的完整命名方案。每个名字都有来历、有记忆点、有口感。

## 适用场景

- 需要为角色/地点/宗派/道具起名
- 需要书名/剧名候选
- 有故事梗概需要配套命名
- 已有部分名字需要补全或优化
- 需要一套风格统一的命名体系

## 核心能力

1. **全套命名**：一个梗概输出全部命名需求
2. **风格适配**：搞笑/文艺/燃爽/甜虐/悬疑/史诗，不同风格不同法则
3. **记忆点锻造**：每个名字至少命中一种记忆点技巧
4. **系统一致性**：同一世界观下的名字像出自同一命名体系
5. **口感校验**：声调搭配、韵母错开、念出来顺口

## 4条命名路径

1. 意象映射路径
2. 音韵先行路径
3. 反差碰撞路径
4. 文化符号路径

## 6种记忆点技巧

1. 声调节奏（抑扬顿挫）
2. 意象反差（冷暖碰撞）
3. 谐音双关（话题属性）
4. 文化锚点（经典联想）
5. 视觉画面（一听就有画面）
6. 极简留白（少即是多）

## 知识库

内含顶流IP命名拆解（琅琊榜、三体、盗墓笔记等）、样本命名对照表、声调搭配速查。

---

**使用方式**：输入你的故事梗概/风格/角色特点，如"帮我取5个仙侠男主角名字，要有仙气但不烂俗"。
