# Summary Prompts Reference

## Extraction Prompts by Content Type

### Web Pages
```
"Extract the main content, key features, and purpose of this webpage"
"Give me a 2-sentence summary of this article"
"Summarize the key points and conclusions from this page"
"Extract all major sections and their content"
```

### PDFs
```
"Extract main findings, methodology, conclusions, and key takeaways"
"Provide a comprehensive summary of this document"
"Identify the main argument and supporting evidence"
"Summarize the abstract and conclusions"
```

### Videos
```
"Extract the main topics discussed, key insights, and important timestamps"
"What are the main points covered in this video?"
"Summarize the tutorial steps and key learnings"
"Identify the key moments and their significance"
```

### Audio
```
"Transcribe and summarize the main topics discussed"
"What are the key takeaways from this podcast episode?"
"Identify main themes, important quotes, and conclusions"
"Summarize the interview/discussion topics"
```

## Summary Generation Prompts

### Short Summary (1-2 sentences)
```
"Provide a very brief one-sentence overview of the main topic"
"Give me the tl;dr version of this content"
```

### Medium Summary (1 paragraph + points)
```
"Summarize with a brief overview paragraph followed by 3-5 key points"
"Give me an overview plus the main takeaways"
```

### Long Summary (detailed)
```
"Provide a comprehensive summary including background, main content, analysis, and conclusions"
"Create a detailed summary with all major sections and their key information"
```

## Prompt Templates

### Basic Summary Template
```
Extract and summarize the main content from [URL/FILE]:
- Main topic/theme
- Key points (3-5 items)
- Important details
- Conclusions or takeaways
```

### Academic Paper Template
```
For this research paper:
1. Research question/objective
2. Methodology used
3. Main findings
4. Conclusions and implications
5. Key limitations
```

### Tutorial/Guide Template
```
For this tutorial/guide:
1. What you'll learn
2. Prerequisites
3. Step-by-step overview
4. Key concepts covered
5. Expected outcomes
```

### News Article Template
```
For this news article:
1. What happened (main event)
2. Who was involved
3. When and where
4. Why it matters
5. Key quotes or reactions
```
