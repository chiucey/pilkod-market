# PDF内容识别与提取技能

## 核心能力

本技能使用专业的PDF内容识别技术，能够：

1. **文字识别** - 提取PDF中的所有文本内容
2. **样式识别** - 识别文字颜色、下划线、加粗、斜体等样式
3. **结构分析** - 识别标题、段落、列表等文档结构
4. **表格提取** - 将PDF中的表格数据提取为结构化格式（CSV/Excel）
5. **图像分析** - 对PDF中的图片进行内容理解

## 使用流程

### 步骤1：确认任务类型

根据用户需求确定处理方式：

| 任务类型 | 处理方式 | 输出格式 |
|---------|---------|---------|
| 提取关键信息 | `extract_pdfs_key_info` | JSON/文本 |
| 提取完整内容 | `extract_pdfs_full_content` | 完整文本 |
| 图片PDF识别 | `images_understand` | 文本描述 |
| 生成表格 | 自定义解析 | CSV/XLSX |

### 步骤2：执行内容提取

**对于文本PDF：**
```
使用 extract_pdfs_key_info 或 extract_pdfs_full_content 工具
```

**对于扫描件/图片PDF：**
```
1. 首先提取PDF页面为图像
2. 使用 images_understand 分析每页内容
```

### 步骤3：内容分析与格式化

**识别样式元素：**
- 搜索颜色标记（如 `<color>` 标签）
- 识别下划线（`_` 或特定标记）
- 分析字体大小识别标题层级

**表格提取：**
1. 识别表格边界（边框、对齐方式）
2. 解析行列结构
3. 生成CSV或Excel格式

### 步骤4：输出结果

根据用户需求提供：
- 纯文本内容
- 格式化文本（含样式标注）
- 结构化数据（表格）
- 分析报告

## 工具使用指南

### extract_pdfs_key_info
- 用途：快速提取PDF中的关键信息
- 参数：`pdf_path`, `prompt`（指定要提取的内容类型）
- 适用：提取特定字段、摘要、表格数据

### extract_pdfs_full_content
- 用途：获取PDF完整文本内容
- 参数：`pdf_path`, `view_range`（可选页面范围）
- 适用：需要完整分析PDF内容时

### images_understand
- 用途：分析PDF页面图像内容
- 适用：扫描件、图片型PDF
- 可识别：文字内容、颜色标记、手写内容

## 输出示例

### 表格提取示例

| 原始样式 | 识别结果 |
|---------|---------|
| 普通文字 | "产品名称" |
| 蓝色文字 | "<color:blue>重要提示</color>" |
| 下划线文字 | "<underline>关键数据</underline>" |
| 红色加粗 | "<color:red><bold>警告</bold></color>" |

### 表格转换示例

**输入（PDF内容）：**
```
姓名    年龄    城市
张三    25     北京
李四    30     上海
```

**输出（CSV格式）：**
```csv
姓名,年龄,城市
张三,25,北京
李四,30,上海
```

## 注意事项

1. **PDF格式兼容性**：优先尝试直接文本提取，对于扫描件使用图像识别
2. **表格识别准确性**：复杂表格可能需要人工校对
3. **样式识别限制**：部分PDF样式信息可能丢失，需明确告知用户
4. **大文件处理**：对于多页PDF，按页面范围分批处理
5. **编码问题**：处理中文PDF时确保正确的字符编码

## 错误处理

| 错误类型 | 解决方案 |
|---------|---------|
| 无法提取文本 | 尝试图像识别模式 |
| 表格结构混乱 | 提示用户手动确认或使用简化提取 |
| 文件损坏 | 通知用户并建议重新上传 |
| 页面太多 | 建议用户指定关键页面范围 |
