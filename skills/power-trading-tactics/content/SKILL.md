# 电力现货交易实战策略

## 触发条件

当用户询问以下内容时激活此技能：
- 电力现货市场申报策略
- 天气对负荷的影响分析
- 日前市场与实时市场研判
- 负荷预测方法
- 特定时段的交易决策

## 核心知识模块

### 1. 天气与负荷关系的核心认知

#### 湿度修正误区
- 降雨≠降温≠负荷下降
- 夏季降雨后湿度急剧攀升，高湿拉高体感温度，刺激空调负荷
- **必须同步纳入相对湿度**，不能只看气温预报
- 警惕雨后高湿环境的负荷推升潜力

#### 天气的滞后与累积效应
- 天气对负荷影响带有明显**滞后性**
- 某日凌晨降雨不仅影响当日凌晨负荷，还会影响次日
- 预测次日负荷时需**回溯前序天气**
- 前期持续高温→建筑物蓄热→即便降温，空调需求依然坚韧

#### 历史对标与典型日数据库
- 建立"典型日数据库"（晴热工作日、雨后闷热潮等）
- 快速匹配最相似历史对标日
- 根据天气微小差异进行加减法修正

### 2. 日前与实时市场的研判逻辑

#### 还原并评估官方日前预测偏差
- 通过还原夜间负荷差值，复刻调度发布的日前负荷预测
- 判断官方预测是否出现系统性偏差
- 在报价中抢占先机

#### 晚高峰临界负荷规则
- **核心阈值：80000（兆瓦/万千瓦）**
- 时间窗口：19:00-19:30
- 当实时负荷突破8万关口→实时价格大概率飙涨
- 操作：果断报大系数（如1.05）
- 这是典型的"条件—行动"规则

#### 午间光伏与空调负荷对冲
- 夏季中午需同时关注：
  - 高温推高的空调负荷
  - 光伏大发对净负荷的压低效果
- 精准判断两者对冲结果，避免误判

### 3. 现货申报实战策略（工作日）

> ⚠️ 以下结论均基于工作日经验，**周六、周日不适用**

| 时段 | 时间点 | 策略要点 |
|------|--------|----------|
| **凌晨** | 02:00-05:30 | 实时价格波动较大，控制系数；近期即使负荷低于日前，价格可能更高 |
| **早高峰** | 07:00 | 实时价格通常偏高 |
| **早高峰** | 08:30 | 报小概率很大 |
| **上午** | 09:30 | 报大性价比较高 |
| **午间** | 11:00, 12:00 | 不再能无脑报小；实时负荷高时应果断报大；建议系数1.05或0.95 |
| **午间** | 11:30 | 通常报大，除非实时负荷显著偏低 |
| **午间** | 13:00 | 报大性价比较高 |
| **午间** | 13:30 | 报小概率偏大，阴天时反转概率上升 |
| **下午** | 14:00-15:30 | 整体报大性价比较高 |
| **傍晚** | 16:30, 17:30 | 建议报小；17:30实时价格通常偏低 |
| **晚间** | 18:30-21:30 | 价格方向不确定，严格控制系数；19:00-19:30注意8万关口规则 |
| **夜间** | 22:30, 23:30 | 通常实时价格高于日前，价差较大；但日前价格已高位时需谨慎 |

## 执行流程

1. **收集信息**：当前时段、实时负荷、日前预测、天气预报
2. **判断触发条件**：是否触发晚高峰8万规则？其他特殊条件？
3. **选择策略**：根据时段和条件匹配对应策略
4. **确定申报系数**：0.95（保守）/ 1.0（中性）/ 1.05（激进）
