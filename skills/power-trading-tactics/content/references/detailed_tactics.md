# 电力现货交易实战策略 - 详细参考资料

## 一、天气与负荷关系深度解析

### 1.1 湿度修正的量化认知

**误区澄清**：
- 传统分析模型假设：降雨 → 温度下降 → 负荷下降
- 实际情况：夏季降雨后，空气相对湿度可能从40%飙升至80%+
- 人体体感温度公式包含湿度修正：高湿度环境下，汗液蒸发受阻，体感温度远高于实际气温

**实战修正方法**：
```
体感温度 ≈ 实际温度 + 湿度修正项
湿度修正项 ≈ (相对湿度 - 50%) × 0.5~1.0℃（取决于风力）
```

**案例**：
- 某日气温32℃，湿度40%，体感≈32℃
- 次日气温31℃，湿度75%，体感≈34-35℃
- 空调负荷不降反升约5-8%

### 1.2 滞后效应的多日传导

**单次降雨事件的负荷传导链**：
```
T日凌晨降雨 → T日白天地面积水蓄热 → T日夜间高湿环境
          → T+1日早晨高温基础 → T+1日午间热量累积
          → T+1日夜间负荷基数抬高
```

**建筑物蓄热效应**：
- 钢筋混凝土结构的热惯性：约24-48小时
- 持续高温后，即使气温下降，墙体/天花板的蓄热需要时间释放
- 中央空调系统为维持设定温度，需持续运转

### 1.3 典型日数据库构建方法

**分类体系**：
| 类型 | 特征描述 | 典型场景 |
|------|----------|----------|
| 晴热工作日 | 晴、微风、最高温>33℃ | 夏季典型 |
| 雨后闷热日 | 降雨后次日、湿度>70%、气温回升 | 梅雨季 |
| 降温首日 | 高温后首次大幅降温（>3℃） | 冷空气来袭 |
| 周末对比日 | 需区分工作日/周末差异 | 特殊日期 |

**匹配算法**：
1. 计算当日特征向量：[最高温, 最低温, 湿度, 风力, 是否降雨]
2. 在数据库中寻找欧氏距离最近的3个历史日
3. 取加权平均值作为基准预测
4. 根据当日与匹配日的具体差异进行修正

## 二、市场研判深度指南

### 2.1 日前负荷预测还原方法

**核心思路**：
通过历史夜间负荷差值，反推调度机构的预测模型参数

**还原公式**：
```
日前预测负荷 = 基荷 + Σ(时段系数 × 历史差值)
```

**实战操作**：
1. 收集前一周的夜间（00:00-06:00）负荷数据
2. 计算相邻日之间的负荷差值
3. 观察差值的规律性变化
4. 识别调度预测的系统性偏差方向

### 2.2 晚高峰8万规则的扩展应用

**规则边界条件**：
| 条件 | 结果 | 置信度 |
|------|------|--------|
| 实时负荷 > 80000 + 2000 | 实时高价 | 高 |
| 实时负荷 > 80000 | 实时高价概率>70% | 中高 |
| 实时负荷 75000-80000 | 需结合其他因素 | 中 |
| 实时负荷 < 75000 | 实时低价概率大 | 中高 |

**组合条件增强**：
- 8万关口 + 湿度>70% → 置信度提升至85%+
- 8万关口 + 前期高温持续3天+ → 置信度提升至90%+

### 2.3 光伏-空调对冲判断框架

**判断流程**：
```
1. 获取光伏出力预测（MW）
2. 获取空调负荷预估（基于气温+湿度+历史）
3. 计算净负荷 = 基础负荷 + 空调负荷 - 光伏出力
4. 对比日前预测净负荷
5. 决策申报方向
```

**危险信号识别**：
- 阴天突然转晴 → 光伏出力骤增，净负荷可能低于预期
- 高温+强光照 + 光伏故障/低效 → 空调负荷爆发

## 三、各时段策略详解

### 3.1 凌晨时段（02:00-05:30）

**市场特征**：
- 负荷处于日内最低区间
- 光伏出力为零
- 实时价格波动受偶然因素影响大

**策略要点**：
- 近期观察为主，不固化策略
- 当实时负荷低于日前预测时，实时价格可能反而更高
- 建议申报系数：0.95-1.0

### 3.2 早高峰（07:00-08:30）

**07:00策略**：
- 实时价格通常偏高
- 建议申报系数：1.0-1.05
- 原因：早高峰启动，负荷快速攀升

**08:30策略**：
- 报小概率很大
- 建议申报系数：0.95
- 原因：早高峰峰值已过，负荷趋于平稳

### 3.3 午间时段（11:00-13:30）

**11:00/12:00深度分析**：
```
不再适用"无脑报小"策略的原因：
- 光伏出力增加，但空调负荷同步增加
- 净负荷变化方向取决于光伏/空调的相对增幅
- 判断关键：实时负荷 vs 日前预测
```

**操作规则**：
| 条件 | 策略 | 系数 |
|------|------|------|
| 实时负荷 >> 日前 | 报大 | 1.05 |
| 实时负荷 ≈ 日前 | 中性 | 1.0 |
| 实时负荷 << 日前 | 报小 | 0.95 |
| 光伏波动不确定 | 灵活 | 1.05或0.95 |

**13:30特殊说明**：
- 报小概率仍偏大（历史统计约65%）
- 但近期阴天时反转概率上升至40%+
- 需关注当日天气实况

### 3.4 晚间时段（18:30-21:30）

**价格方向不确定性因素**：
1. 晚高峰结束后负荷下降速度
2. 光伏退出时间点
3. 工业负荷的晚班排班
4. 居民用电习惯

**19:00-19:30特殊规则**：
- 唯一需要跳过常规分析的时段
- 直接应用8万关口规则
- 一旦触发，果断报大

**20:30-21:30**：
- 负荷进入次低谷
- 建议保持中性策略
- 系数建议：1.0

### 3.5 夜间时段（22:30-23:30）

**高收益时段特征**：
- 通常实时价格高于日前
- 价差较大（历史上常见0.1-0.2元/kWh差异）
- 适合放大申报系数

**近期风险警示**：
当以下条件同时满足时需谨慎：
1. 夜间负荷高
2. 日前价格已处高位
3. 实际负荷难以达到日前预期

**操作建议**：
- 正常情况：系数1.0-1.05
- 高位风险情况：系数0.95-1.0
- 避免盲目追高

## 四、实战决策检查清单

### 决策前必问

- [ ] 当前时段是哪个？（对应哪个策略表行）
- [ ] 今日是工作日吗？（周六周日不适用本策略）
- [ ] 实时负荷是多少？是否触发8万关口？
- [ ] 当前天气状况如何？湿度多少？
- [ ] 光伏出力情况？
- [ ] 日前预测价格水平？

### 系数确定流程

```
1. 确定时段 → 2. 检查特殊条件 → 3. 匹配基础策略
→ 4. 根据实时负荷调整 → 5. 最终确认系数
```

### 常见错误避免

❌ 只看气温，不看湿度
❌ 忽视滞后效应，只看当日天气
❌ 周六周日使用工作日策略
❌ 19:00-19:30时段忽略8万规则
❌ 午间只看光伏或只看空调
