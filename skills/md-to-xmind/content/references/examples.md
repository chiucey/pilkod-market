# MD to XMind 示例参考

## 示例 1：基础标题结构

### Markdown 输入
```markdown
# 项目管理

## 需求分析
### 用户调研
### 需求文档

## 设计阶段
### 架构设计
### 界面设计

## 开发阶段
### 前端开发
### 后端开发

## 测试阶段
### 单元测试
### 集成测试

## 部署上线
```

### 转换结果
生成以 "项目管理" 为中心主题的思维导图，包含 5 个一级分支，每个分支下有子节点。

## 示例 2：混合列表结构

```markdown
# 学习计划

## 编程语言
- Python
  - 基础语法
  - 数据结构
- JavaScript
  - ES6+
  - React

## 数据库
1. MySQL
2. PostgreSQL
3. MongoDB

## 工具链
- Git
- Docker
- CI/CD

### 转换特性
- 无序列表生成子节点
- 嵌套列表生成深层结构
- 有序列表保持数字顺序

## 示例 3：待办事项

### Markdown 输入
```markdown
# 本周任务

## 开发任务
- [ ] 完成用户模块
- [x] 修复登录 bug
- [ ] 优化性能

## 文档任务
- [ ] 编写 API 文档
- [ ] 更新 README

## 会议
- [ ] 周一项目会议
- [x] 周三代码评审
```

### 转换结果
- `- [ ]` 待办项 → 带空心复选框节点
- `- [x]` 已完成 → 带勾选标记节点

## 示例 4：代码和格式化

### Markdown 输入
```markdown
# 开发指南

## 代码规范
- 使用 **ESLint** 检查代码
- 遵循 *PEP 8* 风格指南
- 使用 `git commit` 提交代码

## 常用命令
```bash
npm install
npm run build
npm test
```
```

### 转换特性
- 粗体 `**text**` → XMind 粗体
- 斜体 `*text*` → XMind 斜体
- 代码 `` `code` `` → XMind 代码样式

## 示例 5：完整项目文档

### Markdown 输入
```markdown
# 产品需求文档

## 概述
这是一个电商平台的移动应用

## 核心功能

### 用户模块
- 注册登录
  - 手机号注册
  - 第三方登录
- 用户中心
  - 个人信息
  - 收货地址
  - 订单历史

### 商品模块
1. 商品浏览
2. 商品搜索
3. 商品详情

### 购物车
- 添加商品
- 修改数量
- 删除商品

### 订单模块
> 订单模块是关键路径，需要重点测试

## 技术架构
- 前端：React Native
- 后端：Node.js + Express
- 数据库：MySQL + Redis
- 部署：Docker + K8s

- [x] 需求确认
- [ ] UI 设计完成
- [ ] 开发完成
- [ ] 测试通过
- [ ] 上线发布
```

## XMind 版本对比

| 特性 | XMind 8 | XMind 2020 | XMind Zen |
|-----|---------|------------|-----------|
| 文件格式 | XML | JSON | JSON |
| 压缩方式 | ZIP | ZIP | ZIP |
| 颜色方案 | 支持 | 支持 | 支持 |
| 贴纸/图标 | 基础 | 丰富 | 丰富 |
| Zen 模式 | 不支持 | 支持 | 支持 |

### 兼容性建议
1. **通用兼容性** → 使用 `xmind8` 格式
2. **现代功能** → 使用 `xmindzen` 格式
3. **未知目标版本** → 使用 `xmindzen`（最新兼容）
