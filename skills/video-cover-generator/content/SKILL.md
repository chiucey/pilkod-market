# 视频封面生成器

## 技能概述

接收【原始文章标题】和【文章正文】，通过深度信息降维，自动生成一段驱动文生图模型的高质量全中文提示词，并直接调用绘图工具输出结果。确保生成的封面具有极高的点击率（CTR）、电影级质感，尺寸1920x1080，横屏图片，且完美适配16:9的视频封面比例。

## 执行工作流

### Step 1: 数据校验与核心提炼

1. 阅读原始标题和正文
2. 摒弃所有抽象概念，提取出1到2个最具代表性、最能具象化的"核心视觉客体"
3. 核心视觉客体示例：
   - 黑客实验室、极客代码、脉冲跳动的量子芯片、被藤蔓缠绕的服务器、全息投影的机械眼
4. **根据文章真实情感基调决定视觉风格**：
   - 暗黑科技风（如：开源项目突破、数据爆发）
   - 明亮未来风（如：技术突破、成功发布）
   - 极简工业风（如：代码简洁、效率工具）

### Step 2: 爆款文案重构

#### 主标题提炼规则
- 制造悬念或情绪冲突，但不要丢掉主体
- 提炼成8个汉字以内的短句
- 高亮核心项目/技术名称

#### 副标题提炼规则
- 提取标题中最具冲击力的信息或核心结论
- 限制在12个汉字以内

#### 案例参考
- 案例一：标题"7天开发了7个智能体后，我似乎发现了未来软件的极简形态"
  - 主标题：`AI极简开发模式`
  - 副标题：`7天开发7个智能体`

- 案例二：标题"暴涨47.3k Stars！字节开源Harness项目DeerFlow 2.0，让智能体几乎能完成任何复杂任务"
  - 主标题：`DeerFlow 2.0`
  - 副标题：`暴涨47.3k Stars！`

- 案例三：标题"Harness Engineering 实战：harness的最佳理解方式"
  - 主标题：`Harness Engineering 实战`
  - 副标题：`harness的最佳理解方式`

- 案例四：标题"香港大学开源OpenHarness：1万行Python代码实现Claude Code 98%功能"
  - 主标题：`港大开源神作OpenHarness`
  - 副标题：`1万行代码实现Claude 98%功能`

### Step 3: 提示词组装

将元素代入文生图提示词框架：

```
一张高质量、超清分辨率、电影级质感的 16:9 比例科技类爆款视频封面照片。

[画面背景]：呈现一个[根据文章基调填写的具体场景，例如：深邃的暗黑超级计算机机房 / 未来实验室]，采用极具戏剧性的[体积光/丁达尔光效]，拥有丰富的层次感和专业的电影级景深效果，要有高级感，要有质感

[核心视觉焦点]：在背景偏后的位置，呈现一个细节极其丰富、极具视觉冲击力的[填入Step1提炼的核心视觉客体]。该物体必须与背景完美融合，展现出顶级的材质纹理（如高级金属、发光全息、玻璃折射等）。

[排版与文字约束 - 严禁妥协]：在画面的绝对正中央位置，完美对齐，并严格限制在画面宽度的正中间三分之一区域内（绝不超出该安全区以防平台裁剪），呈现以下极具视觉冲击力的 3D 悬浮中文字体：

第一行主标题是："[填入Step2重构的主标题]"，采用超大、粗体、极具张力的设计，带有[指定一种与背景对比强烈的高饱和度发光色]的发光边缘和强烈的能量纹理。
第二行副标题是："[填入Step2重构的副标题]"，位于主标题正下方，紧密贴合。字体稍小但极其清晰易读，采用高对比度的[指定高亮颜色，如：科技蓝色，纯白色+科技蓝渐变或亮黄色]以突出重点。

画面整体色彩对比强烈，背景如果暗色，主标题和副标题文字就要亮色，反之亦然，质感无瑕疵，确保文字完全融入画面空间，且绝不被任何前景视觉元素遮挡，呈现出顶级科幻/纪实大片的海报视觉体验。
```

### Step 4: 绘图工具调用

使用 `image_synthesize` 工具生成图片：

```json
{
  "requests": [{
    "output_file": "video_cover.png",
    "prompt": "<组装完成的纯中文文生图提示词>",
    "aspect_ratio": "16:9"
  }],
  "display_text": "生成视频封面图片"
}
```

### Step 5: 结果输出

**严格约束**：
- 工具返回结果后，**只能输出最终的图片链接**
- 绝不允许输出任何解释、寒暄、思考过程或多余的Markdown标记
- 图片严格要求16:9横屏，分辨率1920x1080
- 封面图片文字不能脱离主题

**输出格式示例**：`图片链接`

## 视觉风格映射表

| 文章基调 | 推荐视觉风格 | 颜色方案 |
|---------|------------|---------|
| 技术突破/开源发布 | 明亮未来风 | 科技蓝、亮白、金色发光 |
| 数据爆发/性能飙升 | 暗黑科技风 | 深蓝黑、霓虹紫、能量红 |
| 效率工具/极简开发 | 极简工业风 | 深灰、亮白、金属质感 |
| 学术研究/代码实现 | 专业实验室风 | 深色背景、实验蓝光 |

## 常见错误规避

1. **禁止**：主标题超过8个汉字
2. **禁止**：副标题超过12个汉字
3. **禁止**：背景和文字颜色对比不足
4. **禁止**：文字超出画面三分之一安全区
5. **禁止**：输出任何解释性文本，只输出图片链接
