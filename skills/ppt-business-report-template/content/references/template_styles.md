# PPT模板样式详解

## 一、视觉设计系统

### 1.1 色彩体系

#### 主色调（红色系）
```
Primary Red:     #E53935  // 主标题、强调元素
Light Red:       #FF5252  // 次级强调、hover状态
Pale Red:        #FF8A80  // 浅色背景、标签
Dark Red:        #C62828  // 深色标题、重要信息
```

#### 中性色
```
Dark Gray:       #424242  // 正文文字
Medium Gray:     #757575  // 次级文字
Light Gray:      #BDBDBD  // 边框线
Pale Gray:       #EEEEEE  // 卡片背景
Background:      #FAFAFA  // 页面背景
White:           #FFFFFF  // 纯白背景
```

### 1.2 字体系统

#### 层级定义
```
H1 (一级标题):
  - 字体: Microsoft YaHei
  - 字号: 32-36pt
  - 字重: Bold (700)
  - 颜色: #E53935
  - 行间距: 1.3倍

H2 (二级标题):
  - 字体: Microsoft YaHei
  - 字号: 24-28pt
  - 字重: SemiBold (600)
  - 颜色: #424242
  - 行间距: 1.3倍

H3 (三级标题):
  - 字体: Microsoft YaHei
  - 字号: 18-20pt
  - 字重: Medium (500)
  - 颜色: #424242
  - 行间距: 1.3倍

正文:
  - 字体: Microsoft YaHei
  - 字号: 14-16pt
  - 字重: Regular (400)
  - 颜色: #424242
  - 行间距: 1.3倍

注释/副文本:
  - 字体: Microsoft YaHei
  - 字号: 12pt
  - 字重: Regular (400)
  - 颜色: #757575
  - 行间距: 1.3倍
```

### 1.3 框体设计规范

#### 边框样式
```
边框粗细: ≤ 0.75pt (严格限制)
边框颜色: #E0E0E0 (浅灰色)
边框样式: solid (实线)
```

#### 圆角规范
```
禁止: 大圆角 (≥16px)
推荐: 小圆角 4-8px 或 直角 0px

示例:
┌──────────────┐  直角
│   直角边框    │
└──────────────┘

┌──────────────┐  小圆角 4px
│   圆角边框    │
└──────────────┘

┌──────────────┐  中圆角 8px
│   圆角边框    │
└──────────────┘

禁止使用:
┌──────────────┐  大圆角 (禁止!)
│   大圆角边框  │
└──────────────┘
```

#### 内边距规范
```
卡片内边距: 16-24px
元素间距: 12-16px
标题与内容间距: 8-12px
```

## 二、布局结构

### 2.1 页面布局网格

#### 常见布局比例
```
单栏布局:     100% 宽度
双栏布局:     50%  |  50%
三栏布局:     33%  |  33%  |  33%
四栏布局:     25%  |  25%  |  25%  |  25%
混合布局:     40%  |  60%
```

### 2.2 卡片布局

#### 标准卡片
```
┌─────────────────────────────────────┐
│  标题 (H3)                           │
│  ─────────────────────────────────  │
│  内容区域                            │
│  内容区域                            │
│                                      │
│  [可选: 底部标签或链接]              │
└─────────────────────────────────────┘

边框: 0.75pt solid #E0E0E0
圆角: 4px
内边距: 16px
背景: #FFFFFF
```

#### 信息卡片组
```
┌────────┐  ┌────────┐  ┌────────┐
│  卡片1 │  │  卡片2 │  │  卡片3 │
└────────┘  └────────┘  └────────┘
间距: 16px
对齐: 顶部对齐
```

## 三、图表样式

### 3.1 流程图符号

#### 箭头和连接线
```
线条粗细: 1-1.5pt
线条颜色: #E53935 (红色) 或 #757575 (灰色)
箭头样式: 实心三角
```

#### 流程框
```
形状: 圆角矩形
圆角: 4px
边框: 0.75pt solid #E0E0E0
背景: #FFFFFF 或 #FFF8E1 (淡黄)
```

### 3.2 数据可视化

#### 图表配色方案
```
系列1: #E53935 (红色)
系列2: #FF7043 (橙色)
系列3: #66BB6A (绿色)
系列4: #42A5F5 (蓝色)
系列5: #AB47BC (紫色)
```

## 四、交互状态

### 4.1 状态定义

```
默认状态:
  边框: 0.75pt solid #E0E0E0
  背景: #FFFFFF

悬停状态 (Hover):
  边框: 0.75pt solid #E53935
  背景: #FFF5F5 (淡红)
  阴影: 0 2px 8px rgba(0,0,0,0.1)

选中状态 (Selected):
  边框: 0.75pt solid #E53935
  背景: #FFEBEE
  左边框: 3px solid #E53935

禁用状态 (Disabled):
  边框: 0.75pt solid #EEEEEE
  背景: #FAFAFA
  文字: #BDBDBD
```

## 五、响应式设计

### 5.1 断点定义

```
超小屏幕: < 576px
小屏幕:   576px - 768px
中屏幕:   768px - 992px
大屏幕:   992px - 1200px
超大屏幕: ≥ 1200px
```

### 5.2 适配策略

```
文字: 响应式缩放 (使用相对单位)
间距: 基于屏幕尺寸的百分比
布局: 栅格系统自动调整
```
