## 二、模板结构对比

### 2.1 五种结构适用场景

| 结构类型 | 适用场景 | 核心优势 | 示例应用 |
|---------|---------|---------|---------|
| **总分结构** | 概览介绍、方案展示 | 层次清晰、重点突出 | 产品功能介绍、客群概览 |
| **递进结构** | 逻辑推导、层层深入 | 说服力强、印象深刻 | 价值主张、市场分析 |
| **循环结构** | 持续运营、迭代优化 | 展示闭环、体现价值 | 产品价值、用户运营 |
| **因果结构** | 决策依据、效果分析 | 逻辑严密、有理有据 | 客群选择、ROI分析 |
| **路标结构** | 执行计划、项目管理 | 路径清晰、便于跟踪 | 营销计划、开发里程碑 |

### 2.2 结构组合建议

```
单一结构场景:
├─ 简单汇报 → 总分结构
├─ 方案提案 → 递进结构
├─ 运营报告 → 循环结构
└─ 执行计划 → 路标结构

组合使用场景:
├─ 完整商业计划书:
│   ├─ 封面
│   ├─ 目录
│   ├─ 卖给谁 → 总分结构（概览）+ 因果结构（依据）
│   ├─ 卖什么 → 递进结构（价值）+ 循环结构（闭环）
│   ├─ 怎么卖 → 路标结构（计划）+ 循环结构（运营）
│   └─ 结束页

└─ 产品发布会:
    ├─ 封面
    ├─ 卖给谁 → 因果结构（洞察）
    ├─ 卖什么 → 递进结构（价值层层递进）
    ├─ 怎么卖 → 循环结构（生态）
    └─ 结束页
```

## 三、模板优化技巧

### 3.1 视觉层次优化

```
❌ 错误示例:
标题
内容内容内容内容内容内容内容内容内容
内容内容内容内容内容内容内容内容内容

✓ 正确示例:
┌─────────────────────────────────────┐
│  H3 标题                            │
│  ─────────────────────────────────  │
│  内容内容内容内容内容内容内容内容     │
│  内容内容内容内容内容内容内容内容     │
└─────────────────────────────────────┘
```

### 3.2 信息密度控制

```
合理密度:
├─ 每页聚焦1个核心信息
├─ 文字不超过200字
├─ 图表不超过2个
└─ 留白面积 > 30%

过度密集:
├─ 信息过载，缺乏焦点
├─ 文字密密麻麻
├─ 图表堆砌
└─ 无层次感
```

### 3.3 颜色使用原则

```
主色使用规范:
├─ 红色系用于: 标题、强调、重点标记
├─ 灰色系用于: 正文、边框、辅助信息
└─ 白色/浅灰用于: 背景、卡片底色

颜色比例:
├─ 红色系: 10-15%
├─ 灰色系: 40-50%
└─ 白色/浅灰: 35-50%
```
