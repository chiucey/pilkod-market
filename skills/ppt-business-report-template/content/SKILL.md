# PPT商业汇报模板生成器

## 核心定位

本技能为市场调研、产品设计及营销汇报场景提供专业PPT模板，聚焦商业汇报的三大核心问题：
- **卖给谁**（目标客群定位）
- **卖什么**（产品价值主张）
- **怎么卖**（营销策略路径）

## 设计规范

### 视觉风格

| 属性 | 规范 |
|------|------|
| 风格 | 科技公司风格、现代简洁 |
| 主色调 | 红色系（建议 #E53935、#FF5252、#FF8A80） |
| 辅助色 | 浅灰色（#F5F5F5、#EEEEEE） |
| 背景色 | 白色或极浅灰（#FAFAFA） |
| 强调色 | 深灰（#424242）用于正文 |

### 排版规范

| 属性 | 规范 |
|------|------|
| 字体 | 微软雅黑（Microsoft YaHei） |
| 标题层级 | 最多三层（H1/H2/H3） |
| 行间距 | 1.3倍 |
| 框圆角 | 禁止大圆角，建议 4-8px 或直角 |
| 框粗细 | ≤ 0.75pt |
| 框颜色 | 浅灰色（#E0E0E0 或 #BDBDBD） |

## 模板使用指南

### 选择合适的结构

| 场景 | 推荐结构 |
|------|----------|
| 汇报整体方案概览 | 总分结构 |
| 展示逻辑推导过程 | 递进结构 |
| 说明持续迭代机制 | 循环结构 |
| 解释决策依据 | 因果结构 |
| 展示执行计划 | 路标结构 |

### 关键注意事项

1. **标题层级**：严格控制在三层以内（H1/H2/H3）
2. **框的设计**：
   - 禁止大圆角（建议 4-8px 圆角或直角）
   - 边框粗细 ≤ 0.75pt
   - 边框颜色：浅灰色（#E0E0E0）
3. **行间距**：统一使用 1.3 倍行距
4. **字体**：全文使用微软雅黑
5. **配色**：红色系为主，辅以浅灰和白色

### 输出要求

生成的PPT应包含：
- 封面页
- 目录页
- 三大核心板块（卖给谁/卖什么/怎么卖）
- 每个板块包含5种结构示例
- 结束页

## 快速生成命令

当用户请求生成PPT时，执行以下流程：

1. **确认场景**：市场调研 / 产品设计 / 营销方案
2. **选择板块**：卖给谁 / 卖什么 / 怎么卖（或全部）
3. **选择结构**：总分 / 递进 / 循环 / 因果 / 路标
4. **填充内容**：根据用户提供的实际信息填入模板
5. **输出成品**：提供可直接使用的PPT结构描述或代码
