# 亚马逊设计需求文档结构说明

本文档详细说明 FMS 品牌亚马逊主图套图+A+套图设计需求文档的标准结构，供设计师参考。

## 文档总体结构

```
┌─────────────────────────────────────────┐
│ Row 1: 标题（设计需求表格表）           │
├─────────────────────────────────────────┤
│ Row 2: 风格说明 + 设计师信息填写位      │
├─────────────────────────────────────────┤
│ Row 3: 表头（8列字段）                  │
├─────────────────────────────────────────┤
│ Row 4~: 数据行（主图/副图/A+）         │
└─────────────────────────────────────────┘
```

## 表头字段（8列）

| 顺序 | 字段 | 说明 |
|------|------|------|
| A | 顺序 | 图片编号（1, 2, 3, 1.1, 1.2...） |
| B | 图片尺寸（宽 x 高）px | 图片像素尺寸 |
| C | 图片使用位置 | 主图/副图/A+ banner/A+ 导航栏/配件清单/细节图 |
| D | 想通过设计表达出来什么 | 设计目标和卖点 |
| E | 公司是否有满足的素材 | 素材编号或"选取合适图片" |
| F | 参考图 | 参考图说明 |
| G | 文案 | 中英文文案 |
| H | 备注 | 额外制作要求 |

## 颜色编码规则

- **黄色（#FFF2CC）**：主图区域（白底车型展示）
- **绿色（#E2EFDA）**：副图区域（卖点展示）
- **橙色（#FCE4D6）**：A+ 区域

## 标准图片清单（以 1/18 RC 攀爬车为例）

### 主图（1600×1600，3张）
每 SKU 一张主图，黑色车身/其他颜色车身/其他颜色车身
- 白底，底部带镜面效果
- 包含：整车 + 彩盒包装 + 遥控器
- 彩盒放底部
- 车身精修，车壳精致有光影，亮度提亮

### 副图（1600×1600，7张）
1. **官方授权图** - 场景图+授权文案+图标
2. **核心卖点 1** - 细节+场景+文案
3. **核心卖点 2** - 细节+场景+文案
4. **核心卖点 3** - 细节+场景+文案
5. **尺寸标注** - 标注车身尺寸+轴距+离地间隙
6. **动力系统** - 电机+电池细节
7. **底盘/悬挂** - 底盘图+细节标注

### A+ 产品长图（2个尺寸）
- 1464×2400（中等）
- 1200×3600（高）

包含 7 大模块：
1. 户外场景 + Banner + 图标
2. 核心卖点 1 细节
3. 核心卖点 2 细节
4. 核心卖点 3 细节
5. 动力系统细节
6. 导航栏（图片滑动效果 3 张）
7. 配件清单（含尺寸标注）

### A+ Banner（3个尺寸）
- 1464×600
- 1200×900
- 970×600

### A+ 导航栏（3个尺寸 × 3张）
每张 3 个尺寸：
- 1464×600
- 1200×900
- 970×600

### 配件清单（3个尺寸）
- 1464×600
- 1200×900
- 970×600

### 场景图（3个尺寸）
- 1464×600
- 1200×900
- 970×600

### 细节图（2600×1400，4-5张）
每张展示一个核心细节：
- 授权轮胎
- 授权车壳
- 特殊结构
- 底盘系统

## 设计风格统一要求

1. **色调**：参考已有产品，保持品牌一致
2. **字体**：中英文统一字体
3. **图标**：FMS / 2.4GHz / 比例 / 有刷/无刷 / 授权品牌
4. **场景**：户外/越野/攀爬为主，突出产品性能
5. **细节标注**：箭头+文字说明，专业感强
6. **配件清单**：摆放包装内实物+尺寸标注

## 命名规范

- **文件名**：`{型号}_{产品名}_设计需求表格.xlsx`
- **Sheet 名**：`{型号} {产品名}`（不超过 31 字符）
- **示例**：`118L01_Ford_F-100_设计需求表格.xlsx`

## 输出位置

- **默认**：当前工作目录
- **推荐**：`D:\minimax-亚马逊\`（工作区根目录）
- **可定制**：通过 `output_dir` 参数指定
