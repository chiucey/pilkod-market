# 亚马逊图片设计需求生成 Skill

## 概述

本 Skill 用于快速为 RC 遥控车/攀爬车的新品发布生成符合 FMS 品牌标准的亚马逊主图+副图+A+ 套图设计需求文档（Excel 格式）。

**适用产品**：1/10、1/18、1/24 比例的 RC 攀爬车（特别是 FMS 品牌产品）

**输出**：标准化 Excel 文档，可直接交付美工设计师

## 何时使用

当用户：
- 需要为新品制作亚马逊图片需求
- 发送了新品的产品信息（型号、颜色、卖点、参数等）
- 提到"设计需求"、"图片需求"、"套图"、"A+ 内容"
- 希望对接美工设计

## 使用流程

### Step 1：信息收集
向用户收集以下 5 类信息（可一次性提供，也可分步引导）：

#### 1️⃣ 基础信息
- 产品名称 / 型号
- 产品类型（如：1/18 RC 攀爬车）
- 比例 / 电机类型（有刷/无刷）

#### 2️⃣ 车型/外观
- 车型（如：福特 F100、丰田 LC80、GMC Sierra）
- 是否官方授权（如：Ford、Toyota、GM）
- 可选颜色（多 SKU 时）
- 外观色调整体风格

#### 3️⃣ 核心卖点（5-7 个，按优先级）
- 底盘/动力系统
- 品牌授权
- 特殊结构
- 独特卖点

#### 4️⃣ 技术参数
- 车身尺寸（L×W×H）
- 轴距
- 离地间隙
- 电池/电机型号

#### 5️⃣ 素材情况
- 是否有原始素材图
- 是否需要外景/场景图
- 是否需要拍摄或修图

脚本会自动生成 Excel 文件并返回路径。文件命名规范：

## 文档结构

生成的 Excel 文档包含以下结构（严格按照 FMS 5 款产品模板）：

### 1. 文档头部（3行）
- **第 1 行**：标题"设计需求表格表"
- **第 2 行**：风格说明 + 设计师信息填写位
- **第 3 行**：表头（顺序、尺寸、位置、表达内容、素材、参考图、文案、备注）

### 2. 主图（1600×1600，黄色标识）
- **每 SKU 一张**：车型展示+遥控+彩盒
- **白底镜面效果**、车身精修、彩盒放底部
- **顺序号**：1, 1.1, 1.2, 1.3...

### 3. 副图（1600×1600 × 7 张，绿色标识）
按照以下优先级顺序分配：
1. 官方授权 + 产品核心介绍（场景图 + 授权文案）
2. 核心卖点 1（如 LCG 底盘）
3. 核心卖点 2（如多品牌授权轮胎）
4. 核心卖点 3（如磁吸快拆）
5. 尺寸标注（L×W×H、轴距、离地间隙）
6. 动力/电机系统
7. 底盘/悬挂细节

### 4. A+ 套图（橙色标识）
- **A+ 产品长图**：1464×2400 / 1200×3600（两大尺寸）
  - 模块 1：户外场景 + Banner + 图标
  - 模块 2：核心卖点 1
  - 模块 3：核心卖点 2
  - 模块 4：核心卖点 3
  - 模块 5：动力系统
  - 模块 6：导航栏（图片滑动效果 3 张）
  - 模块 7：配件清单（含尺寸标注）

- **A+ Banner**：1464×600 / 1200×900 / 970×600（3 个尺寸）
- **A+ 导航栏**：3 张（每张 3 个尺寸）
- **配件清单**：3 个尺寸
- **场景图**：3 个尺寸
- **细节图**：2600×1400（4-5 张）

### 5. 颜色编码（视觉标识）
- **黄色**：主图区域
- **绿色**：副图区域
- **橙色**：A+ 区域

## 关键设计原则

1. **顺序号规范**：主图用 1, 1.1, 1.2；副图和 A+ 用 1, 2, 3, ...
2. **中英双语**：所有英文文案必须专业、地道（RC 行业术语）
3. **图标元素**：FMS、2.4GHz、1/18、有刷/无刷、授权品牌图标
4. **场景图**：突出产品户外/越野/攀爬场景
5. **细节标注**：箭头指示 + 文字说明
6. **配件清单**：包装内实物 + 尺寸标注

## 错误处理

- **信息不全**：若用户未提供完整信息，列出缺失项并请求补充
- **颜色未指定**：使用占位符"颜色 1/颜色 2/颜色 3"，待用户确认
- **卖点不足 5 个**：补充"细节拼图"、"电池仓"等通用副图
- **非 RC 车型**：礼貌说明本 Skill 专为 RC 攀爬车设计，可酌情调整
