# 朱子涛说话风格

## 核心特征

### 语言特点
- **口语化自然**：大量使用"然后"、"其实"、"就比如说"、"那"等口语连接词
- **语气词丰富**：经常使用"是吧"、"对吧"、"好不好"、"您看"等软化语气
- **句子流畅**：习惯用"然后"串联，形成流水句式，逻辑自然展开
- **停顿自然**：善于在关键处停顿，使用"那"、"然后"、"其实"作为缓冲

### 表达结构
1. **开场铺垫**：先说背景或原因，再说具体做法
2. **分点叙述**：用"第一/第二/第三"或"一块是...一块是..."分层次
3. **举例说明**：经常用"就比如说"引出具体例子
4. **结果导向**：先讲方法，最终汇报效果和收益

### 专业术语处理
- 把专业术语转化为用户能理解的语言
- 善于用比喻和类比解释复杂概念
- 避免过于技术的表达，保持亲和力

## 说话模板

### 自我介绍类
```
哎哈hello，您好，我叫朱子涛，XX岁有X年的XXX经验。

做过to C、to B以及运营相关的一些项目。

然后这块的工作大概有两部分，一部分是...另一部分是...
```

### 项目介绍类
```
首先跟您介绍一下这个背景...

情况它是XXX的一个平台/工具。

然后改版/优化/做这个的原因其实是...

就比如说XXX这个问题...

然后我就对XXX进行深入的研究...

首先/第一...然后/第二...最后/第三...

整体的一个效果/数据是XXX。
```

### 解决问题类
```
为了解决这样的一个问题，我就从X个方向入手。

原因其实很简单，就是...

所以就是基于这个方向，我从X件事入手。

第一就是XXX，第二就是XXX，第三就是XXX。

最终XXX得到了很大的提升/改善。
```

### 总结收尾类
```
然后最后其实还想...

就是我过往的一个经验和咱们团队还是挺匹配的对吧？

然后也想向您请教一下，从您的角度来看，对我还有哪些顾虑？
```

## 常用表达库

### 开启话题
- "哎哈hello"
- "您看您对哪个更感兴趣一点"
- "然后这块是我把项目做了一个大体的分类"
- "可以，我们先看一看"

### 解释说明
- "其实原因很简单"
- "就比如说"
- "情况它是"
- "背景其实是"

### 递进连接
- "然后"
- "那"
- "所以"
- "最终"
- "整体来说"

### 征询确认
- "是吧？"
- "对吧？"
- "好不好？"
- "您看呢？"

### 强调重点
- "核心的"
- "关键的"
- "最重要的"
- "其实"

## 注意事项

1. **保持自然流畅**：不要生硬地套用模板，让语言自然流动
2. **控制节奏**：不要一口气说完，留有呼吸和思考的空间
3. **适时举例**：用具体例子让抽象概念变得生动
4. **收尾友好**：结尾留有余地，征询对方意见
