# Speculative Essay Craft

> 这本手册是"招式库 / 工艺手册"，管"写得有多好"；
> 已有 `philosophical-edu-paper` 管"协同流程"，`philosophical-edu-draft` 管"从大纲出全文"，
> `philosophical-edu-revise` 管"修订已有草稿"。四者分工互补。

## Inputs to collect

在调用本 skill 前，模型应已从上下文或用户处获得以下输入（缺则主动问）：

1. **题目 / 核心命题**：用户想论证什么
2. **文章类型**：教育学 / 哲学 / 社科理论类（决定引文学派）
3. **目标字数**：5000 字短文 / 10000+ 字长文
4. **是否已有大纲**：有则按大纲走；没有则按本 skill 的 3×3 矩阵自行搭建
5. **目标风格**：经典哲学派 / 中国《教育研究》式思辨 / 跨学科对话式

> 缺第 5 项时默认走"中国《教育研究》式思辨"——这是本 skill 主要参照的范本。

## Procedure

### 第 1 步：识别写作任务是不是"思辨类"

判断标准（满足 ≥ 2 项即可视为思辨类）：

- 不依赖数据 / 案例 / 问卷作为主要论据
- 用"概念分析 / 命题推演 / 多家思想对话"作为论证手段
- 核心动作是"重新定义 / 重新框架化 / 跨范式整合"
- 读者读完应得到"一种新的看问题的方式"

不满足的情况：直接走别的 skill，不要硬套本手册。

> 原因：招式是为思辨论证服务的；如果论据是数据，硬塞"对子"和"排比反问"反而会显得空泛。

### 第 2 步：搭 3×3 骨架

把题目放入 3×3 矩阵：

```
                应然层            实然层            行动层
              （关键词）          （人心秤）         （北极星）
小节 1     ______________    ______________    ______________
小节 2     ______________    ______________    ______________
小节 3     ______________    ______________    ______________
```

填法：

- **同一行**：必须保持"应然→实然→行动"的内核呼应（详见 `references/framework.md`）
- **同一列**：必须层次递进——应然列选"概念/方向"、实然列选"行为/态度"、行动列选"路径/原则"
- **9 个格子**：每格 4-6 字短语，禁止空泛动词（"分析""探讨"）

> 为什么这么搭：3×3 是思辨论文里最稳定的"既深又稳"的结构；少于 3×3 显得单薄，
> 多于 3×3 容易散。陶蕾《教师需要什么样的教育数字化》就是 3×3 范本。

### 第 3 步：写引言（按六步法）

按 `references/framework.md` 第 1 节的"引言六步法"展开：

1. 共识降位（开篇是无人反驳的判断）
2. 一分为二（从共识里分出两条路径）
3. 辩证析理（给两方各自成立的前提 + 限定条件）
4. 反问推进（用 2-3 个反问暴露旧视角的边界）
5. 引文压舱（用非教育领域的批判哲学家作合法性）
6. 立场宣告（明确"本文将做什么"）

引言控制在 800-1200 字。

### 第 4 步：写三个主体的每一节（按八步法）

每个小节按"八步法"展开，三节共同构成一个完整的小节（详见 `references/framework.md` 第 2-4 节）：

```
步骤 1：摆现象 / 还原当下理解
步骤 2：极端推演 / 思想实验
步骤 3：揭示旧理解的隐患
步骤 4：自创命名 / 概念溯源
步骤 5：镜像对子（旧 vs 新）
步骤 6：具象化（排比反问 / 三个体验）
步骤 7：抽象回升（从具体回到概念）
步骤 8：辩证升华（落到"主体—客体相互成就"）
```

> 注意：每个小节不必严格走完八步，可以根据内容裁剪；但 4/5/6 三步是核心，**必走**。

### 第 5 步：调用招式库

在写作过程中，按需调用 `references/moves.md` 中的具体招式：

| 招式 | 何时调用 | 关键产出 |
|------|---------|---------|
| 概念命名五种方法 | 需要命名新概念时 | 4 字词组、比喻、反讽 |
| 概念对子四种配对 | 需要强化论证张力时 | 5 组对子最常见 |
| 引文三层递升 | 需要为立场加重量时 | 批判哲学→跨学科→根本哲学 |
| 排比反问五个一 | 需要暴露旧视角边界时 | 5 个同起手式反问 |
| 辩证转折话术 | 需要语气转换时 | 让步、推演、限定、因果、升华 |
| 闭环收尾双层呼应 | 写结尾时 | 与开头 + 主体关键词双层呼应 |

> **不要堆砌**：一篇 8000 字思辨论文，对子 5-8 组、引文 6-8 条、排比反问 2-3 处即可。

### 第 6 步：用自检清单验证

写完全篇后，按 `references/checklist.md` 逐项打勾，发现遗漏就回头补。

特别关注：

- 是否有"统摄性意象"贯穿全文（一对就够）
- 是否每个小节都有自创概念 + 对子
- 是否引文分层（不堆同一档次的引文）
- 结尾是否做了"双层呼应"

## Output contract

一份完成的思辨类论文应具备以下特征：

1. **结构完整**：3×3 矩阵 + 引言 + 收尾齐全
2. **概念密度**：每节至少 1 个自创概念 + 1 对镜像对子
3. **修辞密度**：每节至少 1 组排比反问或三个体验锚点
4. **引文层次**：引言用非教育领域批判哲学；行动层用哲学根本命题
5. **辩证张力**：每个核心论点都"先让对手露面，再用新概念包进来"
6. **闭环收尾**：呼应开头命题 + 串起主体关键词

## Failure handling

| 失败情况 | 处理方式 |
|---------|---------|
| 用户要写实证/案例研究 | 不要套本 skill；引导到 `philosophical-edu-revise` 或专门的实证类 skill |
| 用户只要标题和大纲 | 不要展开写；改用 `philosophical-edu-draft`（从大纲生成全文） |
| 用户要排版 / Word 输出 | 不要本 skill；改用 `docx` skill |
| 写出来的内容像评论文章 | 检查：是否每个论点都"先承认对方 + 再揭示局限"；如缺失，重写关键节 |
| 写出来的内容术语堆砌 | 检查：是否每个自创概念都有"具象化锚点"（具体场景或体验） |
| 引言超过 1500 字 | 砍掉冗余的论证细节，只留"共识—二分—辩证—反问—引文—立场"骨架 |
| 结尾变成口号 | 必须落到"双层呼应"——开头命题 + 主体关键词串起来 |

## Examples

### 例 1：教育学思辨类短文（6000 字）

**输入**：用户问"请论证'技术不应定义教师，教师应定义技术'"——5000 字教育学思辨论文

**执行路径**：

1. 识别任务为"思辨类"（满足 4 项标准）
2. 3×3 矩阵填入：
   ```
                  应然（关键词）        实然（人心秤）       行动（北极星）
   小节 1      主体性回归            拒绝单向度塑造        在地化表达
   小节 2      双向赋能              自主选择接受/参与      应用式演进
   小节 3      成长性愿景            持续获益而非短暂获益    教育者联盟
   ```
3. 引言按六步法展开（共识：技术很重要 → 二分：技术定义教师 vs 教师定义技术 → 辩证 → 反问 → 引马尔库塞 → 宣告立场）
4. 每一节按八步法展开，每节配对子、反问、自创概念
5. 收尾呼应开头 + 串起三组关键词

**输出**：一份结构完整的 6000 字思辨论文，包含 5 组以上对子、3 处排比反问、引文分层合理。

### 例 2：跨学科思辨类论文（哲学 + 教育学）

**输入**：用户问"用哲学思辨方式论证'AI 时代教育应守护什么'"

**执行路径**：

1. 识别任务为思辨类
2. 3×3 矩阵以"教育应守护 X"为主轴：
   - 应然层：守护人的不可计算性 / 守护具身经验 / 守护意义生成
   - 实然层：警惕数据化评价 / 警惕算法依赖 / 警惕效率至上
   - 行动层：在地化实践 / 应用式反思 / 教育家代言
3. 引言从"AI 越来越聪明，教育越来越困惑"切入
4. 行动层引海德格尔 / 梅洛-庞蒂 / 杜威作根本哲学背书
5. 闭环收尾：守护不是"反对 AI"，而是"让人始终是目的"

**输出**：一份具有哲学深度、对子密集、引文层次分明的跨学科思辨论文。
