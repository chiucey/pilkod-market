# 10 价值穷举与城市类比法（万科翡翠国宾实战）

> 本文件基于万科翡翠国宾故事线完整操盘文件提炼，呈现从「价值穷举」到「差异化提炼」再到「故事线构建」的完整思路链，是「城市类比法」最详尽的实战范本。

---

## 一、核心方法：价值穷举三步法

### 第一步：三维穷举

**在Workshop中，汇集建筑设计/景观设计/空间设计/营销/推广等多部门人员，分三个维度穷举项目价值：**

**维度①：项目特性（能给什么）**
列出项目所有可能的价值点，不筛选、不评判，先穷举。

**维度②：客群特性（他们要什么）**
精准描绘目标客群的生活状态、身份诉求、价值观取向。

**维度③：竞品特性（别人已经说了什么）**
梳理主要竞品的故事线和价值主张，明确哪些切入点已被占据。

---

### 第二步：价值分层

将穷举出的价值点，按重要性分三层：

```
初级价值点（共性，竞品也有）
↓
中级价值点（较差异，但不唯一）
↓
差异化价值点（唯一且排他，此为故事线切入口）
```

**万科翡翠国宾实战**：

初级：大西安国家中心城市、双CBD、低密住区、装修标准高
中级：五大公园环绕、公建化外立面（呼应国宾馆）
**差异化：西安国宾道（丈八东路）+ 陕西宾馆旁 + 目标客群「低调高知贵而不舍」**

→ 差异化价值点聚焦到：**「国宾道」**

---

### 第三步：要素提炼

将差异化价值点归纳为可支撑故事线的「价值体系要素」：

| 要素 | 内涵 |
|------|------|
| 城市要素 | 西安国宾道（国际化大都会的城市坐标） |
| 客群要素 | 高净值人群，注重身份与面子，低调富贵不富豪 |
| 产品要素 | 高端定制不动产，精工+安全+智能+园林+服务 |

→ 三要素共同指向故事线核心：**「西安国宾道·当代人物身份资产」**

---

## 二、城市类比法的完整操作示范

### 确定类比维度

找到差异化价值点（国宾道）后，追问：**全球哪些城市也有「国宾道」？**

类比维度设定为：**国际大都会 × 国宾道 × 国宾馆旁 × 公园集群 × 顶级住区** 五大共性

---

### 三城对标（伦敦/北京/西安）

**伦敦国宾道体系**：
- 国宾道：林荫道（The Mall）
- 国宾馆：白金汉宫
- 顶级住区：海德公园1号（世界收藏级顶级豪宅）
- 公园：海德公园、肯辛顿花园等4大公园
- 政经中心：哈咯德百货、唐宁街、国家美术馆

**北京国宾道体系**：
- 国宾道：长安街/国宾大道
- 国宾馆：钓鱼台国宾馆
- 顶级住区：钓鱼台七号院（收藏级北京顶级豪宅）
- 公园：玉渊潭公园、月坛公园
- 政经中心：天安门广场、金融街、西城政府

**西安国宾道体系**：
- 国宾道：丈八东路（国宾道）
- 国宾馆：陕西宾馆
- **顶级住区：万科翡翠国宾**（承接伦敦/北京的国宾住区传统）
- 公园：奥林匹克公园、唐城墙遗址公园、国宾公园等5大公园
- 政经中心：高新管委会、万达ONE、都市之门CBD

---

### 类比法的叙事结构

```
国宾道在世界（伦敦）→ 国宾道在中国（北京）→ 国宾道在西安（丈八东路）
                                                    ↓
                                          万科翡翠国宾 = 西安国宾住区
```

**叙事逻辑**：通过「全球国宾道共性」的论证，证明西安丈八东路具备同等级的城市属性，进而论证万科翡翠国宾是这条国宾道上当然的顶级住区选择——价值认定从「开发商说」变成了「城市历史规律证明」。

## 三、价值穷举的Workshop操作要点

**参与者**：建筑设计、景观设计、空间设计、营销、推广各业务端口核心成员同时在场

**输出物**：
1. 项目价值点穷举清单（三维度）
2. 竞品故事线梳理表
3. 差异化价值点确认
4. 故事线关键思考要素清单（含：候选故事线方向 × 落地可操作性评估）

**工作顺序**：
```
资料包技术交底 → 现场勘查/竞品踩盘 → 客户访谈（2-3场）
→ 封闭Workshop → 故事线初稿 → 提报 → 优化 → 落地顾问
```

**关键原则**：
- 先穷举，后筛选；先发散，后收敛
- 差异化价值点必须通过「竞品排他」检验
- 故事线方向必须通过「落地可操作性」检验——能在示范区/建筑/营销中真实呈现

## 四、故事线落地的「一气呵成」原则

故事线不止于文字，须贯穿所有客户触点：

| 触点 | 「一气呵成」要求 |
|------|----------------|
| 案名 | 与故事线核心意象直接关联（如「西雅图」「格拉美西」） |
| Slogan | 一句话精炼故事线精神内核 |
| 建筑/景观设计 | 设计命题由故事线驱动（如格拉美西的马蹄石路/百米香樟） |
| 示范区营造 | 客户进入示范区，画面和剧本是统一的，下意识走进故事 |
| 营销推广 | 所有推广内容围绕故事线展开，禁止出现游离于故事线之外的信息 |
| 销售说辞 | 置业顾问的开场白、讲解逻辑须与故事线一致 |

**检验标准**：一个陌生人在示范区走完全程，应该能自然感受到「这个项目在说什么」，无需任何解释。

---

## 五、故事线场景应用的策划标准（万科内部）

故事线在场景层面的应用，须覆盖：

**产品层**：产品规划设计方向（哪些产品特征需要被强化/弱化）、建筑设计主题（故事线在立面/户型上的体现）、景观设计命题（园区/示范区的核心体验）

**营销层**：示范区开放策略（如何用开放活动将故事线传播出去）、推广内容主题（所有物料的创意方向）、媒体传播策略（用什么角度输出故事，向谁输出）

**服务层**：物业/服务品牌的气质（与故事线人格一致）、业主社群的精神内核（业主身份认同与故事线的连接）

## 六、可迁移的类比目标库

遇到不同类型项目时，可参照以下方向寻找类比对象：

| 项目特征 | 类比方向 |
|---------|---------|
| 政府/权力机构附近 | 全球国宾道/使馆区/政务核心区的顶级住区 |
| 滨水/江湖资源 | 全球最知名滨水人居（如温哥华/西雅图/阿姆斯特丹滨水区） |
| 工业遗存改造 | 伦敦King's Cross/巴特西/纽约苏荷 |
| 科技园区旁 | 美国硅谷/西雅图/奥斯汀/深圳前海的生活方式 |
| 私人公园/稀缺绿地 | 纽约格拉美西/中央公园一号/伦敦海德公园旁住区 |
| 历史文化区 | 奈良町/京都岚山/罗马历史中心区的当代居住 |
| 顶级商业旁 | 巴黎第八区/米兰时装区/纽约第五大道旁住区 |
