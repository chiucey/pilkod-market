# 客户研究知识库

## 说明

本目录沉淀地产项目客户研究的核心方法论与案例，供生成故事线时调用——**在确定叙事切入角度之前，先理解客户是谁、他们真正在意什么**。

客户研究与故事线的关系：客户研究是故事线的情感锚点来源。知道「这类人在哪个人生阶段、面对什么困境、渴望什么认同」，才能让故事线击中真实痛点，而非悬空的产品自夸。

**调用时机**：在方法论01（切入角度选择）之后、开始写作之前，按「产品定位」匹配对应人群类型，读取客群特征，用于第三章节（客群情感锚点）和扩展模块E（销售说辞）的创作。

## 检索逻辑

1. **先读 00_客户细分方法论.md**，了解各产品定位对应的客群研究框架
2. **按城市**检索 `城市客户研究/` 目录，找到项目所在城市的客群偏好
3. **按人群**检索 `人群客户研究/` 目录，找到目标人群的深度画像
4. 将客群洞察转化为故事线的**情感锚点**（第三章节）和**销售说辞**（模块E）的具体表达
