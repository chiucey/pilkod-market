# 竞品陈列图片分析技能

## 核心能力

分析线下竞品陈列照片，通过图像识别技术提取结构化的竞品信息。

## 输入

- **图片文件**：竞品陈列照片（货架陈列、堆头陈列、端架陈列等）
- **分析需求**（可选）：指定重点关注的竞品、品牌或品类

## 分析维度

| 分析维度 | 输出内容 |
|---------|---------|
| **品牌识别** | 识别图片中的品牌 |
| **价格带** | 各品牌的常规价格区间 |
| **规格带** | 产品容量/包装规格分布 |
| **渠道售价** | 各渠道（如CS渠道、电商、商超等）的实际售价 |
| **促销信息** | 折扣力度、买赠活动、促销标签 |
| **陈列位置** | 陈列排面、层次、高度等 |
| **SKU数量** | 可见的SKU种类数 |

## 输出格式

### 结构化表格

```
| 品牌 | 产品名称 | 规格 | 标价 | 实际售价 | 折扣信息 | 渠道 | 陈列位置 |
|-----|---------|-----|-----|--------|---------|-----|---------|
| 品牌A | 产品名1 | 50ml | ¥89 | ¥71.2 | 8折 | CS店 | 第一层 |
...
```

### 分析摘要

- 价格带分布（低价/中价/高价区间占比）
- 规格带分布
- 促销力度对比
- 理然品牌的机会点分析

## 执行流程

1. **接收图片**：确认图片已上传或指定图片路径
2. **图像分析**：使用图像理解工具提取图片中的信息
3. **结构化输出**：
   - 生成竞品信息表格
   - 生成价格带分析
   - 生成竞品对比摘要
4. **机会点建议**：基于分析结果给出理然的机会点

## 分析提示词模板

```
请分析这张竞品陈列照片，完成以下内容：

1. **品牌识别**：列出图中所有可见的品牌
2. **产品信息**：识别每个品牌的产品名称、规格（ml/g）、包装类型
3. **价格信息**：
   - 标价（建议零售价）
   - 实际售价（如有促销）
   - 折扣信息（如8折、买二送一等）
4. **陈列分析**：
   - 陈列位置（层架高度、排面大小）
   - 是否为特殊陈列（堆头、端架等）
5. **总结**：
   - 价格带分布
   - 主要竞品价格策略
   - 促销力度评估

请以表格形式输出结构化数据。
```

## 注意事项

- 图片质量影响识别准确度，尽量使用清晰的照片
- 促销信息可能存在变化，以实际陈列为准
- 建议结合多个点位照片综合分析
