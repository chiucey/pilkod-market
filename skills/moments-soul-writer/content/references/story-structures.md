# 六种故事结构详解

## 1. 写用户故事（最强转化结构）

**结构**: 用户背景 → 遇到问题 → 解决方案 → 取得成果 → 情感反馈

**目的**: 身份共情，建立信任

**适用场景**: 晒单、案例见证、学员反馈

**核心技巧**:
- 先夸用户（抬TA，也抬自己的可信度）
- 讲TA的故事（身份、经历让人共情）
- 展示对比（用数据/截图/前后变化）
- 情感升华（不只是产品好，是人生变好了）

**示例框架**:
```
今天成交了一位[身份]的学员，她[背景/痛点]。
之前她[困境描述]，看着[对比/冲突]，特别[情绪]。
后来通过[方案/产品]，现在她[成果/变化]。
她说[用户原话/情感反馈]，我听了特别[你的感受]。
```

## 2. 写产品卖点（让产品有灵魂）

**结构**: 痛点场景 → 产品设计初衷（故事化） → 卖点与痛点绑定

**目的**: 让产品有温度、有意义

**适用场景**: 产品介绍、新品发布、功能说明

**核心技巧**:
- 不要上来就讲参数、材质、专利
- 先讲"为什么要做这个产品"的故事
- 把产品跟用户的痛苦、将来、家庭和谐联系在一起
- 让用户感觉"这个产品懂我"

**示例框架**:
```
[讲一个痛点故事：谁因为什么痛苦]
当时就在想，能不能有[产品概念]，让[理想状态]。
后来就设计了[产品]，希望它能[意义/愿景]。
这样[痛点]就不会再发生，[美好结果]。
```

## 3. 写推广理由（占领"道"）

**结构**: 我的受益经历 → 我为什么要推广 → 邀请你一起

**目的**: 占领"道"，让销售有正当性

**适用场景**: 分销、推荐产品、拉人进圈子

**核心技巧**:
- 强调"因为我受益，所以想让更多人受益"
- 展示你的理由（身份共鸣/价值观/改变命运）
- 不是为了钱，是为了一个充分的使命
- 让用户感觉"支持你=支持这个理念"

**示例框架**:
```
我是[身份]，曾经[困境/痛点]。
通过[产品/圈子]，我[改变/收获]。
我深切明白[某类人]的处境，因为[共情点]。
所以我想把[产品]推广给更多人，让[愿景]。
如果你也[痛点/身份]，欢迎[行动指令]。
```

## 4. 写使用场景（情怀驱动）

**结构**: 具体场景描绘 → 情绪/记忆触发 → 产品融入场景

**目的**: 非理性营销，情怀驱动

**适用场景**: 高客单价产品、有历史感的产品、需要情绪价值的产品

**核心技巧**:
- 低端销售讲卖点，高端销售讲情怀
- 用场景唤起用户的记忆/情绪/向往
- 让产品成为"那个场景"的一部分
- 用户买的不是产品，是"离理想中的自己更近一点"

**示例框架**:
```
[描绘一个具体场景：时间、地点、人物、动作]
那一刻，[情绪/记忆/感受]。
想到[过去/向往/某个人]，[情感渲染]。
[产品]就像[隐喻]，让[意义升华]。
```

## 5. 写痛点共鸣（推进成交进度条）

**结构**: 精准痛点描述 → 我也有同样经历 → 破局方案在这里

**目的**: 推进成交进度条（从0%到100%）

**适用场景**: 针对特定身份人群（宝妈/体制内/创业者等）

**核心技巧**:
- 用职业身份/经历身份建立强共情
- 直戳痛点（你最了解这类人的痛）
- 展示"破局方案就在你这里"
- 即使当下不买，未来某天也会买（成交进度条理论）

**示例框架**:
```
很多[身份]都会遇到[痛点]，比如[具体描述]。
我以前也是[身份]，特别懂[痛点的感受]。
后来我通过[方案]，现在[改变/状态]。
如果你也[痛点]，[行动指令/破局方案]。
```

## 6. 写用户证言（晒磨剑过程）

**结构**: 夸用户 → 讲TA的故事 → 展示对比/温情 → 我因此荣幸

**目的**: 晒磨剑过程，建立口碑

**适用场景**: 日常晒单、建立信任、展示交付能力

**核心技巧**:
- 做知识付费像庙里的菩萨：不是要什么，是能给什么
- 晒用户证言 = 晒你实现了多少人的愿望
- 重点不是"产品多好"，而是"这个人多好/这份信任多珍贵"
- 尤其晒"给家人买"的用户（有温情、可信度高）

**示例框架**:
```
今天[用户]给[家人/自己]买了[产品]。
[夸用户]，[讲TA的故事/特质]。
[展示对比/温情时刻]，我看到[感受]。
能通过[产品]见证[美好/温情]，我觉得特别荣幸。
```
