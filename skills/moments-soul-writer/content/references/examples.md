# 输出示例库

## 示例1：用户给案例素材

**用户输入**：
> 我想写一条朋友圈：今天有个学员成交了，她是全职宝妈，之前带娃很焦虑，通过我的课程3个月赚了2万，现在状态特别好。

**AI处理流程**：

1. **识别**：这是"案例内容30%"
2. **推荐**：最适合用"写用户故事"结构
3. **生成**：

```
A1 [观点内容 20%]
昨天一个学员告诉我，她3个月赚了2万。
不是运气，是她终于找到了自己的价值。
有时候，改变只需要一个开始。

B1 [案例内容 30% - 结构：写用户故事]
今天成交了一位全职宝妈的学员。
她说之前每天围着孩子转，不知道自己的价值在哪里。
后来通过我的课程，她找到了自己的方向。
3个月后，她告诉我：赚了2万。
但比钱更让她开心的是——她终于觉得自己有价值了。
她说："原来我也可以。"

C1 [干货内容 30%]
很多宝妈都有一个困境：
想赚钱，但不知道怎么开始。
或者觉得自己"只能"带娃。
其实，每个人的价值都不该被定义。
关键是你愿不愿意给自己一个尝试的机会。
```

## 示例2：热点观点类

**用户输入**：
> 我今天看了一个新闻，讲一个男的因为钱的事跟老婆吵架跳楼了，我想聊聊男女表达情绪的差异。

**AI处理流程**：

1. **识别**：这是"观点内容20%"
2. **推荐**：适合用"A类-直接有力"或"C类-洞察深度"
3. **生成**：

```
A1 [观点内容 20%]
男人不是不会哭，是不知道怎么哭。
女人不是爱抱怨，是习惯了用嘴表达。
我们总说男女差异，其实很多时候只是：
你不懂我的沉默，我不懂你的崩溃。

C1 [干货内容 30%]
有个现象很有意思：
男人崩溃的时候，往往是一个人扛着。
女人崩溃的时候，往往是要说出来。
不是谁对谁错，是表达方式不同。
下次看到他沉默，别追问，给他空间。
下次她想倾诉，别急着给建议，陪着就好。
```

## 示例3：指定方法论

**用户输入**：
> 用"写产品卖点"的方法，帮我写一条朋友圈介绍我的AI课程。

**AI处理流程**：

1. **识别**：这是"转化内容≤10%"
2. **执行**：按"写产品卖点"结构（痛点场景→设计初衷→卖点绑定）
3. **生成**：

```
A1 [转化内容 ≤10% - 结构：写产品卖点]
很多人学AI课程，学完就忘。
不是课程不好，是太理论、太空洞。
我设计AI课程的原则只有一个：
每节课必须能直接用。
学完就能用，用完就能出结果。

B1 [转化内容 ≤10% - 结构：写产品卖点]
有个学员跟我说过一句话：
"我之前买了3个AI课，都放在收藏夹吃灰了。"
当时我就想，能不能做一个不一样的课程？
不是教你"知道"，而是教你"做到"。
所以这个AI课程的设计理念是：
只讲最实用的，每周一个技能，当天就能用。
3个月后，你会的不是"AI知识"，是"AI能力"。

建议：这是转化内容，建议后续发2-3条干货/案例平衡
```

## 示例4：日常分享类

**用户输入**：
> 今天带娃去公园，发现现在的遛娃方式跟以前完全不一样了

**AI处理流程**：

1. **识别**：这是"生活内容20%"
2. **推荐**：适合用"B类-故事驱动"
3. **生成**：

```
A1 [生活内容 20%]
今天的公园，让我恍惚了。
以前的遛娃：一个沙坑，一片草地，一个下午。
现在的遛娃：社交能力、户外运动、早教启蒙...
养娃这件事，卷到我了。

B1 [生活内容 20% - 结构：写使用场景]
今天带娃去了公园。
阳光正好，娃在草地上跑。
突然看到一个妈妈，带着娃的同时还在看手机学英语。
我也掏出了手机，学了5分钟。
抬头一看，娃已经在跟别的小孩打成一片了。
突然觉得：卷娃不如卷自己。
你好了，娃自然跟着好。

C1 [生活内容 20%]
公园遛娃观察日记：
70后：孩子健康就好
80后：不能输在起跑线
90后：快乐最重要
00后：...还没孩子
每一代父母都有自己的焦虑。
但看着娃在草地上奔跑的样子，
我突然觉得：其实我们都是希望孩子好。
方式不同，爱是相同的。
```
