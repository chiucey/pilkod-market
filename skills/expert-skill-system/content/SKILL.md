# 技能体系设计专家

## 核心职责

设计有逻辑、有层次、有特色的技能系统，让主角的成长清晰可见，战斗场面丰富多变。

## 技能分类框架

### 战斗类技能

- 攻击型：直接伤害，冰/火/雷/物理系
- 防御型：减伤/格挡/护盾
- 控制型：眩晕/禁锢/沉默/减速
- 辅助型：治疗/增益/净化
- 位移型：瞬移/闪烁/加速
- 特殊型：时间/空间/因果（慎用，易OOC）

### 生活类技能

锻造、炼丹、制符、烹饪、驯兽

## 技能获取方式

| 获取方式 | 优点 | 缺点 |
|---------|------|------|
| 师徒传承 | 设定清晰，来源正统 | 容易受限 |
| 遗迹冒险 | 惊喜感强，独特性高 | 合理性容易受质疑 |
| 血脉觉醒 | 与身世绑定，合理性强 | 容易血统论 |
| 自我领悟 | 体现主角天赋 | 容易想什么就会什么 |
| 系统面板 | 数值清晰，升级感强 | 西方感过重 |

## 技能树设计原则

T1 基础技能（低消耗，效果一般）
  -> T2 进阶技能（T1的强化版，需要熟练度/材料）
  -> T3 奥义/必杀技（T2+特殊条件）
  -> T4 终极技能（全书仅1-2个，使用代价极大）

## 技能代价系统

- 体力/灵力（通用，最常见）
- 气血/生命力（高伤害技能，用多了会虚弱）
- 精神/神识（控制类技能，反噬会导致精神混乱）
- 物品消耗（符箓/丹药，用完即消失）
- 冷却时间（关键技能一天只能用一次）

## 技能命名法

【系别名.招式名】：效果描述

东方：玄冰.三尺雪 / 天火.流星坠 / 雷罚.九天荡魔
西幻：Fireball / Blizzard / Thunder Strike

禁忌招式：
【万灵.寂灭】：一次性消耗全部灵力，与敌人同归于尽
【时间回溯】：使用后回到1分钟前，每日限一次
