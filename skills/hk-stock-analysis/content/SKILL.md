# 港股分析技能

## 能力范围

本技能提供全面的港股分析能力，支持以下功能：

### 1. 实时行情查询
- 个股实时价格、涨跌幅、成交量
- 恒生指数及主要成分股
- 港股与A股联动分析

### 2. 财务数据分析
- 营收、净利润、毛利率
- 市盈率(PE)、市净率(PB)
- 股息率、ROE等价值指标

### 3. 资讯与事件
- 最新港股新闻
- 业绩发布、重大公告
- 港股通资金流向

### 4. 技术分析
- K线走势分析
- 均线系统
- 技术指标计算

### 5. 港股打新分析
- 新股申购分析
- 打新收益统计
- 中签率预测

## 工作流程

### 股票分析流程

1. **代码确认**
   - 用户提供股票名称或代码
   - 自动转换为标准港股代码格式 (XXXX.HK)

2. **数据获取**
   - 调用 `stocks_price` 获取历史价格数据
   - 调用 `stocks_info` 获取基本信息
   - 调用 `stocks_financial_data` 获取财务数据
   - 调用 `stocks_news` 获取最新新闻

3. **分析执行**
   - 基本面分析：财务指标、估值水平
   - 技术面分析：趋势判断、支撑阻力
   - 消息面分析：最新动态、行业影响

4. **报告生成**
   - 包含数据可视化建议
   - 提供投资建议参考
   - 风险提示

### 批量分析流程

当用户要求分析多只港股时（最多10只并行）：

1. 收集所有股票代码
2. 并行获取数据
3. 横向对比分析
4. 生成综合报告

## 工具调用示例

### 单股分析
```
stocks_info(symbol="0700.HK")
stocks_price(symbol="0700.HK", start_date="2024-01-01", end_date="2024-12-31")
stocks_financial_data(symbol="0700.HK")
stocks_news(symbol="0700.HK", snippet_count=10)
```

### 批量查询
```
# 最多10只股票并行查询
stocks_info(queries=[
  {"symbol": "0700.HK", "output_file": "data/tencent_info.json"},
  {"symbol": "9988.HK", "output_file": "data/alibaba_info.json"}
])
```

### 指数查询
```
stocks_price(symbol="^HSI", start_date="2024-01-01", end_date="2024-12-31")
stocks_price(symbol="^HSTECH", start_date="2024-01-01", end_date="2024-12-31")
```

## 注意事项

### 交易规则
- 港股交易时间：9:30-12:00, 13:00-16:00 (北京时间)
- T+0回转交易，当天可买卖
- 无涨跌幅限制（涡轮牛熊证除外）

### 数据限制
- 历史数据通常保留5年左右
- 部分财务数据可能存在滞后
- 新闻数据实时性依赖数据源

### 风险提示
- 本技能提供的数据仅供参考
- 不构成投资建议
- 投资有风险，决策需谨慎

## 常见问题

Q: 如何查询某只港股？
A: 直接提供股票名称或代码，例如"帮我分析腾讯控股"或"查询0700.HK"

Q: 支持港股打新分析吗？
A: 是的，可以分析新股基本面、发行估值、申购策略等

Q: 可以分析恒生指数吗？
A: 可以，使用代码 "^HSI" 查询恒生指数，"^HSTECH" 查询恒生科技指数
