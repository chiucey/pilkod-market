# 猎聘候选人寻访技能

## 功能概述

本技能用于在猎聘平台自动化执行候选人寻访工作：读取在线简历、按照关键词筛选候选人、对符合条件的候选人发起沟通并索要简历。

## 触发条件

当用户提供以下信息时触发本技能：
1. **筛选条件**：职位、城市、经验、学历等基础筛选条件
2. **筛选关键词**：需要在候选人简历中匹配的关键词（如技术栈、公司名、职位名等）
3. **沟通意图**：希望对符合条件的候选人进行沟通

## 工作流程

### 步骤1：打开猎聘平台

使用 `interact_with_website` 工具：
1. 打开浏览器访问 `https://www.liepin.com`
2. 等待页面加载完成
3. 确保已登录猎聘账号

### 步骤2：进入搜索人才页面

1. 在猎聘首页点击"搜索人才"入口
2. 进入候选人搜索列表页面
3. 等待列表加载完成

### 步骤3：设置筛选条件

根据用户提供的筛选条件进行设置：

| 筛选维度 | 操作说明 |
|---------|---------|
| 职位关键词 | 在职位搜索框输入目标职位关键词 |
| 目前城市 | 选择候选人目前所在城市 |
| 期望城市 | 选择候选人期望工作城市（可选） |
| 工作年限 | 设置经验年限范围 |
| 学历要求 | 选择最低学历要求 |
| 其他条件 | 薪资范围、公司规模等（按需设置） |

### 步骤4：执行搜索

1. 点击"搜索"或"确定"按钮
2. 等待搜索结果加载
3. 确认进入候选人列表页面

### 步骤5：遍历候选人列表

对列表中的每个候选人执行以下操作：

```
遍历每个候选人卡片：
  ├─ 点击候选人进入简历详情页
  ├─ 读取简历内容
  ├─ 检查是否包含所有筛选关键词
  │   ├─ 是 → 符合条件，继续步骤6
  │   └─ 否 → 不符合条件，返回列表继续下一个
  └─ 返回候选人列表
```

### 步骤6：沟通符合条件的候选人

对包含全部关键词的候选人执行：

1. **选择开聊职位**
   - 在沟通页面从招聘者的职位列表中选择一个合适的职位
   - 优先选择与候选人期望匹配的职位

2. **发送招呼语**
   - 使用默认常用招呼语进行打招呼
   - 默认招呼语：`您好，看您简历与我们的职位需求比较匹配，方便的话可以聊聊吗？`

3. **索要简历**
   - 在沟通中礼貌请求候选人提供简历
   - 可用话术：`方便的话可以把您的简历发给我吗？我这边帮您进一步推荐。`

### 步骤7：返回列表继续筛选

完成当前候选人沟通后：
1. 返回候选人搜索列表
2. 继续处理下一个候选人
3. 重复步骤5-6直到列表遍历完毕

## 筛选关键词匹配规则

### 匹配逻辑

```
候选人简历内容 必须 包含用户提供的 全部筛选关键词
```

### 关键词类型

| 类型 | 示例 | 匹配要求 |
|-----|------|---------|
| 技术栈 | Python、Java、React | 精确匹配 |
| 公司名 | 字节跳动、腾讯、阿里 | 精确匹配 |
| 职位名 | 产品经理、算法工程师 | 模糊匹配 |
| 行业关键词 | 金融、医疗、电商 | 精确匹配 |

### 匹配结果判定

- **✅ 符合**：简历内容包含全部筛选关键词
- **❌ 不符合**：简历内容缺少任何一个筛选关键词

## 关键词来源

**重要**：筛选关键词必须由用户（招聘者）提供，每次任务开始前确认。

用户需要提供的信息：
- 必需技能/技术栈关键词（如：必须掌握Python）
- 目标公司类型（如：必须有互联网大厂经验）
- 职位相关关键词（如：必须有推荐系统经验）
- 其他硬性要求

## 默认招呼语

在不指定自定义招呼语的情况下，使用以下常用语：

```
您好，看您的简历背景与我们的职位需求比较匹配，不知道方便聊聊吗？期待您的回复~
```

## 输出报告

任务完成后，生成以下格式的报告：

```
## 猎聘候选人寻访报告

### 任务信息
- 筛选条件：[用户提供的条件]
- 筛选关键词：[用户提供的关键词]
- 执行时间：[完成时间]

### 筛选结果
- 已浏览候选人：X 人
- 符合条件候选人：X 人
- 已沟通候选人：X 人
- 已索要简历：X 人

### 详细列表
| 候选人姓名 | 匹配关键词 | 沟通状态 | 简历获取 |
|-----------|-----------|---------|---------|
| 张三       | Python,算法 | ✅ 已沟通 | ⏳ 待回复 |
| 李四       | Java,架构   | ✅ 已沟通 | ✅ 已获取 |
```

## 注意事项

1. **每次任务前确认**：与用户确认筛选条件和关键词
2. **尊重候选人**：沟通时保持专业、礼貌
3. **合规操作**：遵守猎聘平台规则，不进行违规操作
4. **进度汇报**：处理过程中适时向用户汇报进度
5. **异常处理**：如遇页面变化、操作失败等情况，及时提示用户

## 适用场景

- 批量招聘某个职位的候选人
- 针对特定技能栈筛选人才
- 定向寻访有特定背景的候选人
- 高效进行候选人初筛和初步沟通
