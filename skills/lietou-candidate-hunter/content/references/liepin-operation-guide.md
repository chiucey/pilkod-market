# 猎聘平台操作参考指南

## 一、平台入口与基础操作

### 1.1 登录与首页

**操作步骤：**

1. 打开浏览器，访问猎聘官网：`https://www.liepin.com`
2. 点击页面右上角「登录」按钮
3. 选择登录方式（手机号验证码、账号密码、微信扫码等）
4. 登录成功后进入个人中心页面

**验证登录状态：**

- 检查页面右上角是否显示用户名
- 确认是否有「我的简历」「我的职位」「消息中心」等菜单

### 1.2 进入人才搜索页面

**入口路径：**

- 方式一：首页顶部导航栏 → 点击「搜索人才」
- 方式二：个人中心 → 「寻找人才」功能区
- 方式三：直接访问搜索页面URL

**页面加载等待：**

- 等待页面完全加载后再进行操作
- 注意页面是否出现验证码或滑动验证，如出现需手动完成验证

## 二、筛选条件设置详解

### 2.1 职位关键词筛选

**操作位置：** 搜索框（位于页面顶部显眼位置）

**输入规则：**

- 支持输入多个关键词，用空格分隔
- 例如：`Python 机器学习 算法`
- 系统会搜索包含这些关键词的职位

**建议：**

- 使用精确职位名称：如「推荐算法工程师」而非「算法」
- 使用通用技能词：如「TensorFlow」「PyTorch」

### 2.2 城市筛选

**操作位置：** 「目前城市」和「期望城市」下拉选择框

**筛选类型：**

| 类型 | 说明 | 适用场景 |
|-----|------|---------|
| 目前城市 | 候选人当前工作所在城市 | 关注候选人现所在地 |
| 期望城市 | 候选人期望工作地点 | 关注候选人意向城市 |

**多选规则：**

- 可单选一个城市
- 可多选多个城市
- 部分平台支持「不限」选项

### 2.3 经验年限筛选

**操作位置：** 「工作年限」或「工作经验」选择器

**常见选项：**

- 不限
- 应届毕业生
- 1年以下
- 1-3年
- 3-5年
- 5-10年
- 10年以上

**建议：**

- 根据招聘职级选择合适范围
- 高管岗位可选择10年以上
- 初级岗位选择1-5年

### 2.4 学历筛选

**操作位置：** 「学历」或「教育经历」选择器

**常见选项：**

- 不限
- 高中/中专及以下
- 大专
- 本科
- 硕士
- 博士

**建议：**

- 技术类岗位通常要求本科及以上
- 高级管理岗位通常要求本科及以上
- 特殊岗位可根据需求设置

### 2.5 其他筛选条件

**薪资范围：**

- 设置候选人期望薪资区间
- 注意选择货币单位（人民币/美元）

**公司规模：**

- 按照候选人所处公司员工数量筛选
- 常见选项：1-20人、20-99人、100-499人、500-999人、1000-9999人、10000人以上

**行业领域：**

- 互联网/IT/软件
- 金融/银行/保险
- 房地产/建筑
- 消费品/零售
- 制造业
- 教育/培训
- 医疗健康
- 其他

**职能类别：**

- 技术/研发
- 产品/设计
- 运营/市场
- 销售/商务
- 职能/支持
- 管理

## 三、候选人筛选流程

### 3.1 候选人列表浏览

**列表信息展示：**

- 候选人姓名（如未设置真实姓名则显示昵称）
- 当前职位和公司
- 工作年限
- 学历信息
- 目前所在地
- 最近活跃时间
- 简历更新日期

**列表操作：**

- 点击候选人卡片可查看详细简历
- 部分平台支持批量收藏候选人
- 注意候选人状态：在线、离线、已沟通、已投递

### 3.2 简历详情查看

**进入方式：** 点击候选人列表中的候选人卡片

**简历内容模块：**

| 模块 | 内容说明 |
|-----|---------|
| 基本信息 | 姓名、性别、年龄、学历、工作年限、现所在地 |
| 求职意向 | 期望职位、期望城市、薪资范围、入职时间 |
| 工作经历 | 公司名称、职位、在职时间、工作内容 |
| 项目经验 | 项目名称、时间、职责、成果 |
| 教育经历 | 学校、专业、学历、时间 |
| 技能特长 | 技术栈、证书、语言能力 |
| 自我评价 | 候选人自述 |

**关键词匹配检查：**

在阅读简历时，检查以下内容是否包含用户提供的关键词：

1. 工作经历中的公司名称
2. 工作经历中的职位名称
3. 工作内容描述
4. 项目经验中的技术栈
5. 技能特长列表
6. 自我评价

### 3.3 匹配结果判定

**完全匹配（符合条件）：**

简历内容包含用户提供的**全部**筛选关键词

**不匹配（不符合条件）：**

简历内容**缺少**任何一个筛选关键词

**模糊匹配（可选判断）：**

部分关键词可使用模糊匹配：

- 职位名称的同义词
- 技术栈的近义词（如Vue和Vue.js）
- 公司名称的简称

### 3.4 翻页与遍历

**翻页操作：**

- 使用列表底部的页码导航
- 或使用「下一页」按钮
- 注意每页候选人数量

**遍历策略：**

1. 从第一页开始逐页浏览
2. 每页候选人逐一检查
3. 符合条件的候选人进行沟通
4. 不符合的跳过继续下一个
5. 遍历完当前页面后进入下一页
6. 直到列表全部浏览完毕

## 四、沟通操作详解

### 4.1 选择开聊职位

**操作位置：** 沟通页面中的职位选择器

**选择原则：**

1. 选择与候选人期望最匹配的职位
2. 优先选择候选人期望城市有招聘需求的职位
3. 优先选择候选人期望薪资范围内的职位
4. 如候选人期望与多个职位匹配，选择最核心的职位

**注意事项：**

- 确认选择的职位仍在招聘中
- 确认职位与候选人背景匹配度高
- 部分平台要求必须先选择职位才能发起沟通

### 4.2 发送招呼语

**默认招呼语：**

```
您好，看您的简历背景与我们的职位需求比较匹配，不知道方便聊聊吗？期待您的回复~
```

**招呼语发送位置：** 沟通输入框

**发送步骤：**

1. 在输入框中输入招呼语（或使用默认）
2. 检查内容是否正确
3. 点击「发送」按钮
4. 等待发送成功提示

### 4.3 索要简历话术

**推荐话术：**

```
方便的话可以把您的简历发给我吗？我这边帮您进一步推荐。谢谢~
```

**索要时机：**

- 候选人回复确认有兴趣后
- 候选人主动询问职位详情后
- 初次沟通确认候选人基本符合要求后

**注意事项：**

- 不要在第一条消息就索要简历
- 先建立基本信任再请求简历
- 语气要礼貌、诚恳
- 提供自己的诚意（如标注会优先处理）

### 4.4 沟通状态记录

**常见状态：**

| 状态 | 说明 |
|-----|------|
| 未沟通 | 候选人符合条件但尚未发起沟通 |
| 已发送 | 已发送招呼语，等待候选人回复 |
| 已回复 | 候选人已回复消息 |
| 已索要简历 | 已向候选人请求简历 |
| 简历已获取 | 候选人已发送简历 |
| 不合适 | 沟通后发现候选人不适合 |

**记录建议：**

- 在执行过程中实时记录每个候选人的状态
- 方便最终生成执行报告
- 便于后续跟进已沟通的候选人

## 五、关键词匹配策略

### 5.1 关键词类型与匹配方式

| 关键词类型 | 示例 | 匹配方式 | 说明 |
|-----------|-----|---------|------|
| 技术栈 | Python、Java、React、MySQL | 精确匹配 | 必须在简历中出现 |
| 公司名 | 字节跳动、腾讯、阿里巴巴 | 精确匹配 | 可匹配公司全称或简称 |
| 职位名 | 产品经理、算法工程师 | 模糊匹配 | 可匹配职位名称及其同义词 |
| 行业词 | 金融、医疗、电商、在线教育 | 精确匹配 | 简历中需要体现相关行业经验 |
| 工具名 | Git、Docker、Kubernetes | 精确匹配 | 必须是实际使用过的工具 |

### 5.2 关键词组合策略

**AND逻辑（必须同时满足）：**

- 用户提供多个关键词时，简历必须包含**全部**关键词
- 例如：关键词「Python」AND「机器学习」→ 简历必须同时包含这两个词

**OR逻辑（满足其一即可）：**

- 如用户要求满足任一关键词，需特殊说明
- 例如：关键词「Python」OR「Java」→ 简历包含任一即可

### 5.3 常见匹配场景

**场景一：技术栈筛选**

- 筛选条件：必须掌握Python和TensorFlow
- 关键词：「Python」「TensorFlow」
- 匹配检查：在简历的技能模块或项目经验中查找这两个词

**场景二：公司背景筛选**

- 筛选条件：必须有互联网大厂经验
- 关键词：「字节跳动」「腾讯」「阿里巴巴」「美团」「京东」
- 匹配检查：在工作经历的公司名称中查找

**场景三：复合筛选**

- 筛选条件：5年以上经验，硕士学历，Python技术栈，金融行业
- 关键词：「Python」「金融」「硕士」
- 匹配检查：逐项核对年限、学历、技术和行业

## 六、异常情况处理

### 6.1 页面加载异常

**表现：** 页面长时间加载、显示空白、出现错误提示

**处理方法：**

1. 等待页面加载完成（最多等待30秒）
2. 如超时不响应，刷新页面
3. 刷新后重新进入当前步骤
4. 如持续异常，提示用户手动处理

### 6.2 登录状态失效

**表现：** 页面跳转到登录页、提示登录失效

**处理方法：**

1. 暂停当前操作
2. 提示用户重新登录猎聘
3. 用户登录完成后继续执行

### 6.3 验证码拦截

**表现：** 页面出现验证码或滑动验证

**处理方法：**

1. 暂停自动操作
2. 提示用户手动完成验证
3. 验证完成后继续执行

### 6.4 候选人信息无法访问

**表现：** 无法查看候选人简历详情、页面显示无权限

**可能原因：**

- 候选人设置了隐私保护
- 候选人不在可触达范围
- 平台限制访问

**处理方法：**

1. 跳过该候选人
2. 继续处理列表中其他候选人
3. 在报告中记录该情况

### 6.5 沟通功能受限

**表现：** 无法发送消息、提示操作受限

**可能原因：**

- 账号权限不足
- 今日沟通次数已达上限
- 候选人已被其他顾问联系

**处理方法：**

1. 记录该候选人
2. 提示用户手动处理或稍后重试
3. 继续处理其他符合条件的候选人

## 八、实用技巧

### 8.1 提升筛选效率

1. **精准设置初始条件**：在搜索时就设置较高的筛选条件，减少后续筛选工作量

2. **关键词优先原则**：先检查技术栈和公司等硬性关键词，再关注软性条件

3. **批量操作意识**：保持稳定的操作节奏，避免中途停顿

4. **善用收藏功能**：将重点候选人先收藏，后续可批量处理

### 8.2 提高沟通成功率

1. **个性化招呼语**：可根据候选人背景适度调整招呼语

2. **选择最佳沟通时机**：候选人活跃时间（如工作日上班前、下班后）发送消息

3. **简洁专业的表达**：保持消息简短、专业，避免长篇大论

4. **及时跟进**：对已回复的候选人及时跟进，保持沟通节奏

### 8.3 候选人维护建议

1. **建立候选人档案**：记录每位候选人的特点和沟通情况

2. **分类管理**：按匹配度、沟通进度等维度分类管理

3. **定期跟进**：对未回复的候选人适时再次联系

4. **资源积累**：长期积累候选人资源，形成人才库
