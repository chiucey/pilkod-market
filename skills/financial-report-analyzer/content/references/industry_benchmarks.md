# 财务报告分析技能 - 使用指南

## 技能简介

`financial-report-analyzer` 是一款专业的上市公司财报分析技能，支持A股、港股、美股市场的财务报告深度分析。

## 触发方式

### 直接触发
用户可直接使用以下关键词触发技能：

| 触发类型 | 示例 |
|---------|------|
| 财报分析 | "分析贵州茅台2023年年报" |
| 报表解析 | "请解析苹果公司最新季报的利润表" |
| 财务比率 | "计算腾讯的偿债能力和ROE" |
| 对比分析 | "对比阿里巴巴和京东的财务数据" |
| 异常检测 | "识别这份财报中的异常指标" |

### 间接触发
当用户询问与财报分析相关但未明确要求时：
- "这家公司值得投资吗？" → 引导至财报分析
- "帮我看看这家公司赚钱能力如何" → 引导至盈利能力分析
- "这个行业的平均水平是多少" → 引导至行业对比

## 核心功能

### 1. 三大报表解析
- 利润表：收入、成本、费用、利润结构分析
- 资产负债表：资产结构、负债水平、股东权益
- 现金流量表：三类现金流匹配度、自由现金流

### 2. 四大能力分析
| 能力类型 | 核心指标 |
|---------|---------|
| 偿债能力 | 流动比率、速动比率、资产负债率 |
| 营运能力 | 存货周转率、应收账款周转率、总资产周转率 |
| 盈利能力 | 毛利率、净利率、ROE、ROA |
| 成长能力 | 营收增长率、净利润增长率 |

### 3. 多维度对比
- 历史趋势：3-5年核心指标走势
- 同比分析：与上年同期对比
- 环比分析：与上季度对比
- 行业对比：与行业均值/龙头对比

### 4. 异常指标识别
- 财务造假预警信号检测
- 现金流与利润背离识别
- 关联交易异常检测
- 商誉减值风险评估

### 5. 可视化输出
- 趋势折线图：营收、利润、ROE等指标
- 对比柱状图：同业对比
- 雷达图：四大能力综合评分
- 瀑布图：利润构成拆解

## 支持的市场

| 市场 | 财报类型 | 数据格式 |
|-----|---------|---------|
| A股 | 年报、中报、季报 | 中文 |
| 港股 | 年报、中报、季报 | 中文/英文 |
| 美股 | 10-K、10-Q、8-K | 英文（GAAP/Non-GAAP） |

## 数据来源

技能仅使用以下合规数据源：
- **A股**：上交所、深交所官方公告；巨潮资讯网
- **港股**：港交所披露易（hkexnews.hk）
- **美股**：SEC EDGAR

## 注意事项

### 安全边界
1. 仅分析公开披露的财报数据
2. 不存储用户非公开信息
3. 分析结论仅供投资参考

### 分析限制
1. 异常指标识别为风险提示，不做欺诈定论
2. 不提供个股投资建议
3. 建议结合行业研究和宏观环境综合判断

## 常见问题

**Q: 支持哪些股票代码格式？**
A: A股（600519.SH）、港股（0700.HK）、美股（AAPL.O）

**Q: 能否分析非标准格式的财务数据？**
A: 建议使用标准披露格式，技能对非标准数据可能无法准确解析

**Q: 财报分析需要多长时间？**
A: 完整分析通常需要3-5分钟，具体取决于财报复杂度

**Q: 如何追问特定科目的细节？**
A: 直接在追问中指定科目名称，如"解释毛利率上升的原因"
