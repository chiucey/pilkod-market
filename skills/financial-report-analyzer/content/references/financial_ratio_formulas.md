# 财务比率计算公式参考

## 一、偿债能力指标

| 指标名称 | 计算公式 | 说明 | 健康范围 |
|---------|---------|------|---------|
| 流动比率 | 流动资产 / 流动负债 | 衡量短期偿债能力 | 1.5-2.0 |
| 速动比率 | (流动资产-存货) / 流动负债 | 剔除存货的短期偿债能力 | 1.0-1.5 |
| 现金比率 | 现金及现金等价物 / 流动负债 | 最严格的短期偿债指标 | >20% |
| 资产负债率 | 总负债 / 总资产 × 100% | 总体杠杆水平 | 40-60% |
| 产权比率 | 总负债 / 股东权益 | 财务杠杆程度 | <1 |
| 利息保障倍数 | EBIT / 利息费用 | 支付利息能力 | >3 |
| 长期资本负债率 | 非流动负债 / (非流动负债+股东权益) | 长期资本结构 | 因行业而异 |

## 二、营运能力指标

| 指标名称 | 计算公式 | 说明 | 健康范围 |
|---------|---------|------|---------|
| 存货周转率 | 营业成本 / 平均存货 | 存货变现速度 | 因行业而异 |
| 存货周转天数 | 365 / 存货周转率 | 存货周转一次的天数 | 因行业而异 |
| 应收账款周转率 | 营业收入 / 平均应收账款 | 应收账款回收速度 | 因行业而异 |
| 应收账款周转天数 | 365 / 应收账款周转率 | 应收账款回收天数 | 因行业而异 |
| 应付账款周转率 | 营业成本 / 平均应付账款 | 付款速度 | 因行业而异 |
| 应付账款周转天数 | 365 / 应付账款周转率 | 付款周期 | 因行业而异 |
| 现金循环周期 | 存货周转天数 + 应收账款周转天数 - 应付账款周转天数 | 营运资金效率 | 越短越好 |
| 总资产周转率 | 营业收入 / 平均总资产 | 资产使用效率 | >0.8 |
| 固定资产周转率 | 营业收入 / 平均固定资产 | 固定资产效率 | 因行业而异 |
| 营运资本周转率 | 营业收入 / 平均营运资本 | 营运资金效率 | >2 |

## 三、盈利能力指标

| 指标名称 | 计算公式 | 说明 | 健康范围 |
|---------|---------|------|---------|
| 毛利率 | (营业收入-营业成本) / 营业收入 × 100% | 核心业务盈利能力 | 因行业而异 |
| 营业利润率 | 营业利润 / 营业收入 × 100% | 营业活动盈利水平 | 因行业而异 |
| 净利率 | 净利润 / 营业收入 × 100% | 最终盈利能力 | >10% |
| ROE（净资产收益率） | 净利润 / 平均股东权益 × 100% | 股东回报水平 | >15% |
| ROA（资产收益率） | 净利润 / 平均总资产 × 100% | 资产盈利效率 | >5% |
| ROIC（投资资本回报率） | NOPAT / 投资资本 × 100% | 资本使用效率 | >WACC |
| EPS（每股收益） | 归母净利润 / 期末股本 | 股东回报 | 持续增长 |
| 基本EPS | (净利润-优先股股息) / 加权平均股本 | 基本每股收益 | - |
| 稀释EPS | 考虑稀释性潜在普通股调整后的EPS | 稀释后每股收益 | - |
| EBITDA | EBIT + 折旧 + 摊销 | 息税折旧摊前利润 | - |
| EBITDA率 | EBITDA / 营业收入 × 100% | 经营效率 | 因行业而异 |

## 四、成长能力指标

| 指标名称 | 计算公式 | 说明 | 分析意义 |
|---------|---------|------|---------|
| 营业收入增长率 | (本期营业收入-上期营业收入) / 上期营业收入 × 100% | 业务扩张速度 | 持续增长为佳 |
| 净利润增长率 | (本期净利润-上期净利润) / 上期净利润 × 100% | 盈利成长性 | 持续增长为佳 |
| 营业利润增长率 | (本期营业利润-上期营业利润) / 上期营业利润 × 100% | 核心业务成长 | 持续增长为佳 |
| 总资产增长率 | (期末总资产-期初总资产) / 期初总资产 × 100% | 规模扩张速度 | 稳健增长 |
| 股东权益增长率 | (期末股东权益-期初股东权益) / 期初股东权益 × 100% | 内生增长能力 | 持续增长为佳 |
| 经营性现金流增长率 | (本期经营现金流-上期经营现金流) / 上期经营现金流 × 100% | 现金流成长 | 正值为佳 |
| 扣非净利润增长率 | 扣除非经常性损益后的净利润增长率 | 主业成长性 | 持续增长为佳 |

## 五、估值指标

| 指标名称 | 计算公式 | 说明 | 分析意义 |
|---------|---------|------|---------|
| 市盈率（P/E） | 每股市价 / 每股收益 | 估值水平 | 与行业/历史比较 |
| 市净率（P/B） | 每股市价 / 每股净资产 | 净资产溢价 | <1为破净 |
| 市销率（P/S） | 市值 / 营业收入 | 收入溢价 | 因行业而异 |
| EV/EBITDA | 企业价值 / EBITDA | 企业估值 | 与同行比较 |
| PEG | 市盈率 / 净利润增长率 | 成长调整估值 | <1有价值 |
| 股息率 | 每股股息 / 股价 × 100% | 现金回报水平 | >无风险利率 |

## 六、每股指标

| 指标名称 | 计算公式 | 说明 |
|---------|---------|------|
| 每股收益（EPS） | 归母净利润 / 期末股本 |
| 每股净资产 | 股东权益 / 期末股本 |
| 每股经营现金流 | 经营现金流净额 / 期末股本 |
| 每股现金流 | 现金及等价物增加额 / 期末股本 |
| 每股未分配利润 | 未分配利润 / 期末股本 |
| 每股资本公积 | 资本公积 / 期末股本 |

## 七、杜邦分析体系

```
ROE = 净利率 × 总资产周转率 × 权益乘数
    = (净利润/收入) × (收入/总资产) × (总资产/股东权益)
```

| 分解指标 | 分析意义 |
|---------|---------|
| 净利率 | 盈利能力 |
| 总资产周转率 | 营运能力 |
| 权益乘数 | 财务杠杆 |

## 八、财务预警指标

### 高风险信号

| 指标 | 预警阈值 | 风险等级 |
|-----|---------|---------|
| 现金及等价物 / 总资产 | <5% | 高 |
| 经营现金流 / 净利润 | <0.5（连续2年） | 高 |
| 应收账款 / 营业收入 | >30% | 中 |
| 存货 / 营业成本 | >50% | 中 |
| 商誉 / 净资产 | >50% | 中 |
| 资产负债率 | >80% | 高 |
| 流动比率 | <1 | 高 |
| 利息保障倍数 | <1 | 高 |

### 财务造假常见模式

| 模式 | 识别指标 | 典型特征 |
|-----|---------|---------|
| 虚增收入 | 应收账款↑↑、现金流↓ | 赊销过度、期末突击确认 |
| 虚增利润 | 存货↑↑、成本降低 | 少计成本、推迟费用 |
| 隐藏负债 | 经营租赁不入表 | 表外融资 |
| 关联交易 | 关联方交易↑↑ | 利润转移 |
| 现金流造假 | 经营现金流持续为负 | 虚构现金流 |
