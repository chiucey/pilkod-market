# 财务报告分析技能

## 概述

本技能提供上市公司财报的深度分析能力，覆盖A股/港股/美股市场，支持年报、中报、季报等多种财报类型。分析维度包括三大财务报表解析、20+核心财务比率计算、多维度对比分析及异常指标识别。

## 执行流程

### 阶段1：初始化与数据加载

1. **初始化分析体系**
   - 加载三大报表解析规则（利润表/资产负债表/现金流量表科目定义）
   - 准备财务比率计算公式库（偿债/营运/盈利/成长四大类）
   - 加载行业基准数据库（中国/香港/美国市场行业均值）
   - 初始化异常财务指标识别规则库

2. **数据加载**
   - 获取目标公司官方披露的财报数据（仅限合规披露的公开信息）
   - 加载可比公司及行业龙头财务数据用于对比
   - 校验数据来源为官方公开渠道（交易所公告、公司官网 investor relations）

3. **指令解析**
   - 识别分析标的（股票代码或公司名称）
   - 确定财报类型（年报/中报/季报/全英文财报）
   - 明确分析维度（全面分析/专项分析/对比分析）
   - 确定对比基准（同行业/同市值/历史表现）

### 阶段2：报表深度解析

#### 利润表解析
- 营业收入：收入规模、同比增长率、毛利率
- 营业成本：成本结构、占比变化
- 三大费用：销售费用率、管理费用率、财务费用率
- 净利润：归母净利润、净利润率、扣非净利润
- 重点关注：收入确认方式变更、一次性损益、非经常性项目

#### 资产负债表解析
- 资产端：总资产、流动资产结构、非流动资产构成
- 负债端：总负债、流动/非流动负债比例、有息负债分析
- 所有者权益：股本、资本公积、未分配利润
- 重点关注：商誉减值风险、应收账款异常、存货周转

#### 现金流量表解析
- 经营性现金流：现金净流量、现金流与净利润匹配度
- 投资性现金流：资本开支、自由现金流分析
- 筹资性现金流：分红政策、融资活动
- 重点关注：现金流与利润背离、隐性负债、经营性现金流为负

### 阶段3：财务比率计算

#### 偿债能力指标
| 指标 | 计算公式 | 行业基准参考 |
|------|---------|-------------|
| 流动比率 | 流动资产/流动负债 | 制造业: 1.5-2.0 |
| 速动比率 | (流动资产-存货)/流动负债 | 制造业: 1.0-1.5 |
| 资产负债率 | 总负债/总资产 | 稳健: <50%, 激进: 50-70% |
| 利息保障倍数 | EBIT/利息支出 | >3 为健康 |
| 现金比率 | 现金及等价物/流动负债 | >20% 为佳 |

#### 营运能力指标
| 指标 | 计算公式 | 行业基准参考 |
|------|---------|-------------|
| 存货周转率 | 营业成本/平均存货 | 因行业差异大 |
| 应收账款周转率 | 营业收入/平均应收账款 | 因行业差异大 |
| 总资产周转率 | 营业收入/平均总资产 | >0.8 为活跃 |
| 固定资产周转率 | 营业收入/平均固定资产 | 因行业差异大 |
| 营运资本周转率 | 营业收入/平均营运资本 | >2 为高效 |

#### 盈利能力指标
| 指标 | 计算公式 | 行业基准参考 |
|------|---------|-------------|
| 毛利率 | (营收-成本)/营收 | 因行业差异显著 |
| 净利率 | 净利润/营业收入 | >10% 为优质 |
| ROE（净资产收益率） | 净利润/平均净资产 | >15% 为优秀 |
| ROA（资产收益率） | 净利润/平均总资产 | >5% 为良好 |
| EPS（每股收益） | 归母净利润/股本 | 持续增长为佳 |
| PEG | 市盈率/净利润增长率 | <1 有价值 |

#### 成长能力指标
| 指标 | 计算公式 | 分析意义 |
|------|---------|---------|
| 营收增长率 | (本期-上期)/上期 | 衡量业务扩张 |
| 净利润增长率 | (本期-上期)/上期 | 衡量盈利成长 |
| 资产增长率 | (本期-上期)/上期 | 衡量规模扩张 |
| 股东权益增长率 | (本期-上期)/上期 | 衡量内生增长 |
| 经营性现金流增长率 | (本期-上期)/上期 | 衡量现金流质量 |

### 阶段4：趋势与对比分析

#### 时间序列分析
- 3-5年核心指标趋势（营收、净利润、毛利率、ROE）
- 同比分析（YoY）与环比分析（QoQ）
- 识别增长/下滑拐点及驱动因素
- 判断成长可持续性

#### 行业对比分析
- 与行业均值对比：定位公司相对位置
- 与行业龙头对比：分析竞争优势与劣势
- 多维度雷达图：财务表现全面画像
- 估值对比：PE、PB、PS横向比较

### 阶段5：异常指标识别

#### 财报造假预警信号
| 预警类型 | 识别指标 | 风险等级 |
|---------|---------|---------|
| 收入虚增 | 营收↑但经营现金流↓、应收账款↑↑ | 高 |
| 毛利率异常 | 毛利率大幅高于行业均值 | 中 |
| 存货异常 | 存货↑↑但营收↓ | 高 |
| 商誉风险 | 商誉占净资产比例>50% | 中 |
| 关联交易 | 关联交易占比异常提升 | 中 |
| 审计意见 | 非标审计意见 | 高 |

#### 财务异常信号
- 利润与现金流长期背离
- 毛利率异常波动
- 应收账款/存货异常增长
- 突然变更会计政策
- 频繁资产重组
- 期末突击确认收入

### 阶段6：可视化输出

#### 图表类型
1. **趋势图**：营收/净利润/毛利率3-5年趋势
2. **对比柱状图**：同业对比、行业排名
3. **雷达图**：四大能力综合评分
4. **瀑布图**：利润构成拆解
5. **堆叠图**：收入结构/成本结构变化
6. **热力图**：财务指标季度变化

#### 图表规范
- 使用专业配色方案（蓝色系主调）
- 标注关键数值和变化率
- 图表标题清晰标注数据来源
- 支持交互式悬停查看详情

### 阶段7：报告生成与输出

#### 报告结构
```
一、执行摘要
   - 财报核心亮点（3-5条）
   - 主要风险提示（1-3条）
   - 财报质量评分（1-10分）

二、公司概况
   - 基本信息（代码、名称、行业、市值）
   - 报告期概况

三、报表解析
   3.1 利润表分析
   3.2 资产负债表分析
   3.3 现金流量表分析

四、财务比率分析
   4.1 偿债能力
   4.2 营运能力
   4.3 盈利能力
   4.4 成长能力

五、趋势与对比
   5.1 核心指标历史趋势
   5.2 行业对比分析

六、异常指标检测
   6.1 风险预警信号
   6.2 需持续关注事项

七、可视化图表
   - 图表1-6

八、分析结论与建议
```

#### 输出格式
- 主报告：Markdown格式结构化分析
- 数据表：CSV格式详细数据
- 图表：PNG/SVG格式可视化
- 综合包：HTML可交互报告（可选）

## 数据来源规范

### 合规数据源
- A股：上交所/深交所官方公告、巨潮资讯网
- 港股：港交所披露易、公司官网
- 美股：SEC EDGAR、公司官网 investor relations

### 数据校验规则
- 多源交叉验证数据一致性
- 校验报表平衡关系（资产负债表平衡、现金流量表勾稽）
- 核实关键科目的同期可比性
- 确认审计意见类型

## 安全与合规

### 数据隔离
- 仅处理公开披露的财报数据
- 不存储用户非公开信息
- 分析结果不涉及内幕信息

### 分析边界
- 本技能提供财务分析参考，不构成投资建议
- 异常指标识别为风险提示，不做欺诈定论
- 建议用户结合行业研究和宏观环境综合判断

## 交互支持

### 支持的追问类型
- 科目细节追问："请详细解释为何毛利率上升"
- 比率计算追问："能否详细展示ROE的计算过程"
- 异常原因追问："经营性现金流为负的主要原因是什么"
- 对比追问："与某竞争对手的差异在哪里"
- 趋势追问："近5年净利润变化的核心驱动因素"

### 输出精度
- 财务数据保留2位小数
- 百分比保留1位小数
- 同比/环比数据标注正负方向
- 图表标注清晰的数据来源和截止日期
