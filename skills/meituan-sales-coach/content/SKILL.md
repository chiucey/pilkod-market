# 美团销冠教练：销售能力锻造系统

## 一、核心理念

**一笔按照正确流程执行但最终输掉的单子，比一笔靠运气赢下的单子更有价值。因为流程可以复利，运气不行。**

销售教练不是告诉销售"你要努力"，而是帮助销售识别"真正卡在哪里"并给出"下一次沟通就能用的具体动作"。每一个复盘都应该产出可复制的经验，每一个诊断都应该导向可执行的下一步。

---

## 二、方法论体系

### 2.1 苏格拉底式提问四步法

不是给答案，而是通过提问让销售自己找到答案：

```
第一步：澄清问题
"你说的'客户不感兴趣'具体是什么表现？他是直接拒绝，还是说需要考虑？"

第二步：深挖原因
"如果让你猜，你觉得他真正担心的是什么？"

第三步：检验假设
"你问过他预算范围吗？你怎么确认他有这个需求？"

第四步：导向行动
"如果明天再联系他，你打算说什么不同的话？"
```

### 2.2 单子诊断六维度

每个单子都必须回答这六个问题：

| 维度 | 诊断问题 | 判断标准 |
|------|----------|----------|
| 需求真实性 | 客户真的有问题要解决吗？ | 有明确痛点、有时间压力 |
| 预算明确性 | 钱从哪里来、谁批？ | 有预算、有决策权 |
| 决策链清晰度 | 谁决策、谁影响、谁反对？ | 完整决策链已摸清 |
| 时间紧迫性 | 什么时候要结果？ | 有明确时间节点 |
| 竞争态势 | 有几个玩家？ | 竞对优势已分析 |
| 我方匹配度 | 我们能赢吗？ | 差异化优势明确 |

### 2.3 行为反馈三明治法则

```
第一层：认可具体行为
"你这次跟进客户的时机选择很好，在他发完朋友圈后立刻评论建立连接。"

第二层：指出改进空间
"但在价格谈判环节，你可以更主动地锚定价值，而不是跟着客户的话题走。"

第三层：约定下一步动作
"下次遇到客户问价格，你可以先说'价格确实重要，我先给你算一下ROI'，明天试试看。"
```

### 2.4 Forecast纪律三条铁律

```
铁律一：不确认的不进Commit
客户没有明确表态能签，就不能放进承诺数字。

铁律二：有卡点的不进Commit
有卡点没解决的单子，放进Best Case，不放进Commit。

铁律三：承诺就要兑现
Commit是承诺，不是预测。进了Commit就要全力拿下。
```

### 场景二：Pipeline Review

**触发词**：Pipeline Review、盘客户、全员复盘会

**会议节奏**：
- 周会：全体Pipeline过一遍，60分钟内
- 随时：重点单子随时过，不超过30分钟

**Pipeline分级标准**：

| 级别 | 定义 | 跟进频率 | 主管介入 |
|------|------|----------|----------|
| A级 | 需求+预算+决策链+时间四维全绿 | 每天跟进 | 每天了解 |
| B级 | 三维绿，有一维待确认 | 每2-3天 | 每3天过 |
| C级 | 两维及以下 | 每周 | 每周过 |
| D级 | 异常（7天无进展/失联/战败） | 暂缓 | 按需 |

**Review标准流程**：

```
第一步：客户状态确认
"这个客户现在在哪个阶段？"
选项：□需求确认 □方案报价 □商务谈判 □合同审批 □签约付款

第二步：卡点定位
"你觉得卡在哪里？"
选项：□需求不清 □预算不够 □决策人不见 □竞对缠斗 □时机未到 □其他

第三步：策略确认
"你打算怎么破这个卡点？"
引导说出具体动作，不是泛泛方向

第四步：行动承诺
"你打算什么时候做这件事？做完怎么让我知道？"
明确时间点和反馈机制

第五步：资源需求
"你需要我提供什么支持？"
资源类型：□价格政策 □协同拜访 □内部协调 □竞品信息 □其他
```

### 场景四：客户异议处理

**触发词**：客户有异议、客户不同意、客户拒绝、处理异议

**异议处理四步法**：

```
第一步：认可情绪
"完全理解，这个顾虑很正常，很多客户都有同感。"

第二步：确认理解
"让我确认一下，你担心的主要是___对吗？"

第三步：针对性回应
"关于___问题，我可以这样解释..."
提供事实、数据、案例

第四步：确认消除
"现在关于这个顾虑，还有其他问题吗？"
或"那我们就___达成一致了对吗？"
```

**常见异议话术库**：

| 异议类型 | 错误回应 | 正确回应 |
|----------|----------|----------|
| "太贵了" | 打折扣 | "你觉得贵是和其他家比，还是和预算比？能告诉我你的参考标准吗？" |
| "我再考虑考虑" | "好的您考虑" | "理解，这个决定需要慎重。我想问一下，您主要考虑的是哪方面？是XX吗？" |
| "不需要" | 放弃 | "我理解。你现在用的是___方案对吧？有没有遇到___问题？" |
| "用不上" | 强推功能 | "我好奇，是什么场景让你觉得用不上？是你本人用不上，还是你觉得团队用不上？" |
| "比你们便宜的很多" | 降价 | "是的，市场上有便宜的也有贵的。请问你在比较的时候，最看重的是什么？" |
| "负责人不在" | 等通知 | "完全理解。那我能问一下，通常你们这种采购是谁最终拍板吗？我直接联系他可以吗？" |

**苏格拉底提问引导**：

```
客户说"太贵了"

不要问："贵多少你能接受？"
要问："你觉得贵，是和预算比超了，还是和其他家比觉得不划算？"

不要问："我们质量好所以贵"
要问："如果价格不是问题，你觉得我们的产品能解决你的问题吗？"

不要问："便宜没好货"
要问："如果你发现便宜的产品后来成本更高，你会怎么想？"
```

### 场景六：Forecast审核

**触发词**：Forecast审核、预测数字、承诺单子、能不能签

**Forecast三级标准**：

| 级别 | 定义 | 准确率要求 | 管理方式 |
|------|------|------------|----------|
| Commit | 客户明确表态、本周/本月能签 | ≥95% | 每天检核 |
| Best Case | 努力可达成、有不确定性 | ≥50% | 每3天跟进 |
| Pipeline | 有希望、但时间远 | 参考 | 每周过 |

**审核三问**：

```
第一问：客户怎么说的？
"客户原话是什么？他明确说了'可以签'还是'我们在评估'？"

第二问：还有卡点吗？
"这个单子还有没解决的卡点吗？如果有，是什么级别的卡点？"

第三问：今天能做什么？
"为了确保这个单子本周签掉，今天你能做什么？"
```

**Forecast可信度检查**：

```
有以下情况，降为Best Case：
□ 客户未明确表态
□ 有价格卡点未解决
□ 决策人还未见面
□ 合同条款还在谈
□ 竞对还在缠斗
□ 时间节点不确定

有以下情况，保留为Commit：
□ 客户原话确认
□ 无卡点或卡点已解决
□ 决策人已同意
□ 合同条款已定稿
□ 时间节点明确
```

### 场景八：销售个人成长辅导

**触发词**：个人成长、能力提升、职业发展、怎么进步

**辅导四步法**：

```
第一步：诊断现状
"你现在觉得自己最强的和最弱的是什么？"
"如果让你给自己的成交率打个分，1-10分你打几分？"

第二步：设定目标
"你想在三个月后达到什么状态？"
"你觉得达成这个目标，需要提升什么能力？"

第三步：制定计划
"每周花多少时间练习？找谁练习？"
"第一个月重点练什么？第二个月呢？"

第四步：约定检核
"每周我们碰一次，看你的进步。你定还是我定时间？"
```

### 场景十：存量客户复购和异常召回

**触发词**：存量客户、复购、召回、沉睡客户、流失客户

**存量客户分级**：

| 类型 | 定义 | 策略 |
|------|------|------|
| 活跃客户 | 近30天有互动 | 挖掘增量需求、交叉销售 |
| 观望客户 | 近30-90天无进展 | 了解顾虑、重新激活 |
| 沉睡客户 | 近90天-6个月无互动 | 定向召回、重建关系 |
| 流失客户 | 超过6个月或已转竞对 | 深度复盘、挽回可能性评估 |

**沉睡客户召回四步**：

```
第一步：问题诊断
"客户为什么沉睡？是产品问题、服务问题、还是关系问题？"
打开CRM记录，分析最后一次跟进内容和结果

第二步：重新定位
"如果重新接触，你给客户带去什么新价值？"
新产品、新政策、新功能、新案例

第三步：触达设计
"你打算怎么联系他？说什么？"
设计破冰话术，不是简单问候

第四步：承诺跟进
"联系后怎么跟进？下次什么时候联系？"
建立持续跟进机制，不是联系一次就放弃
```

**召回话术模板**：

```
【沉睡客户召回】
━━━━━━━━━━━━━━━━━━━━━━━━
触达方式：□电话 □微信 □上门 □其他

开场话术：
"张总您好，我是美团的___。上次咱们合作是___月份，
这次联系您是想告诉您一个消息——我们最近升级了XX功能，
感觉和你们的需求很匹配，想约个时间给您做个演示，
您看这周三下午方便吗？"

关键点：
- 叫出客户名字
- 提及上次合作背景
- 带来新价值
- 给出具体时间选项
━━━━━━━━━━━━━━━━━━━━━━━━
```

## 四、教练纪律

### 4.1 教练行为准则

```
【必须做到】
- 每次辅导都产出可执行的下一步
- 每个问题都指向具体行为，不是泛泛态度
- 每次复盘都萃取可复用的经验
- 每次承诺都记录并检核

【绝对不做】
- 不在未了解事实前给结论
- 不把能力问题当态度问题
- 不只给方向不给具体动作
- 不做没有检核的承诺
```

### 4.2 教练检核三问

每次辅导结束时，必须问：

```
问题1：今天聊完，你觉得最重要的一件事是什么？
（确保销售理解了核心）

问题2：你打算什么时候做？做完了怎么让我知道？
（确保有行动承诺）

问题3：下次什么时候再聊这个话题？
（确保有跟进机制）
```

### 4.3 教练效果评估

| 评估维度 | 指标 | 检核频率 |
|----------|------|----------|
| 辅导产出率 | 每次辅导是否产出可执行动作 | 每次 |
| 承诺执行率 | 承诺动作是否按时完成 | 每周 |
| 问题解决率 | 辅导中提到的问题是否被解决 | 每月 |
| 能力提升率 | 核心能力评分是否有提升 | 每月 |

## 六、总结

**美团销冠教练的核心能力：**

1. **苏格拉底式提问**：通过提问让销售自己找到答案
2. **六维度诊断**：需求、预算、决策链、时间、竞对、匹配度
3. **行为反馈**：认可+改进+行动，闭环管理
4. **Forecast纪律**：不确认不进Commit，有卡点不承诺
5. **经验萃取**：每个输单都是学习机会

**核心理念：**
一笔按照正确流程执行但最终输掉的单子，比一笔靠运气赢下的单子更有价值。因为流程可以复利，运气不行。
