# 供应商信息提取 - 输出格式指南

## 一、文本复制格式

### 标准模板

```
供应商信息提取结果
================================================================================

供应商名称：        [供应商名称]
联系人姓名：        [联系人姓名]
联系人电话：        [联系人电话]
联系人邮箱：        [联系人邮箱]
公司地址：          [公司地址]
统一社会信用代码：  [统一社会信用代码]
开户行：            [开户行名称]
银行账号：          [银行账号]
开户银行联行号：    [联行号]

--------------------------------------------------------------------------------
提取时间：[YYYY-MM-DD HH:mm:ss]
注：标注 * 的字段为系统自动识别，可能存在误差
```

### 示例输出

```
供应商信息提取结果
================================================================================

供应商名称：        深圳市腾云科技有限公司

公司地址：          广东省深圳市南山区科技园南路88号
统一社会信用代码：  91440300MA5DQXPX2H

--------------------------------------------------------------------------------
提取时间：2024-04-09 10:49:44
```

## 二、Excel导出格式

### 文件命名规则

```
供应商信息_YYYYMMDD_HHmmss.xlsx
```

示例：`供应商信息_20240409_104944.xlsx`

### 列定义

| 列序号 | 字段名 | 数据类型 | 最大长度 | 说明 |
|-------|--------|---------|---------|------|
| A | 序号 | 整数 | - | 自动编号 |
| B | 供应商名称 | 文本 | 200 | 必填 |
| C | 联系人姓名 | 文本 | 50 | 必填 |
| D | 联系人电话 | 文本 | 20 | 必填 |
| E | 联系人邮箱 | 文本 | 100 | 选填 |
| F | 公司地址 | 文本 | 500 | 选填 |
| G | 统一社会信用代码 | 文本 | 18 | 选填 |
| H | 开户行 | 文本 | 200 | 选填 |
| I | 银行账号 | 文本 | 20 | 选填 |
| J | 开户银行联行号 | 文本 | 12 | 选填 |

### Excel样式规范

**表头样式**:
- 背景色: #4472C4 (蓝色)
- 字体颜色: #FFFFFF (白色)
- 字体: 微软雅黑, 11pt, 加粗
- 文字居中

**数据行样式**:
- 背景色: #FFFFFF (白色)
- 字体: 微软雅黑, 10pt
- 边框: 细线
- 文字左对齐

**交替行样式**:
- 背景色: #F2F2F2 (浅灰)
- 增强可读性

## 三、批量处理汇总表

当处理多个供应商文件时，生成汇总表：

### 附加列

| 列序号 | 字段名 | 数据类型 | 说明 |
|-------|--------|---------|------|
| K | 来源文件 | 文本 | 原始文件名 |
| L | 提取时间 | 日期时间 | 处理时间戳 |
| M | 提取状态 | 文本 | 成功/部分成功/失败 |

### 状态说明

| 状态 | 说明 |
|-----|------|
| 成功 | 所有字段均已提取 |
| 部分成功 | 1个或多个字段未提取 |
| 失败 | 无法识别有效信息 |

## 四、错误与空值处理

### 空值表示

- **文本复制**: 使用 `（未识别）` 表示
- **Excel导出**: 保持单元格为空，不填入任何值

### 格式标准化

| 字段 | 输入示例 | 标准化输出 |
|-----|---------|-----------|
| 电话 | 138-0013-8000 | 13800138000 |
| 电话 | 0755 1234 5678 | 0755-12345678 |
| 邮箱 | Zhangsan@Example.COM | zhangsan@example.com |
| 代码 | 91440300MA5DQXPX2H | 91440300MA5DQXPX2H |

## 五、特殊格式保留

### 保留原格式的字段

以下字段保留原始文本格式，不做标准化处理：

- 公司地址（包含省市区详细信息）
- 开户行（保留支行全称）

### 示例

```
输入：广东省深圳市南山区科技园南路88号T1栋3层301-02室
输出：广东省深圳市南山区科技园南路88号T1栋3层301-02室

输入：中国工商银行股份有限公司深圳科技园支行
输出：中国工商银行股份有限公司深圳科技园支行
```
