# 供应商信息提取器

## 功能概述

本技能自动从供应商资料（Word、PDF、图片）中识别和提取关键字段信息，并支持复制或导出为Excel格式。

## 支持的字段

| 字段名称 | 说明 | 正则匹配模式 |
|---------|------|-------------|
| vendor_name | 供应商名称 | 公司、企业、供应商等关键词后跟的名称 |
| contact_name | 联系人姓名 | 姓名、手机号、固话前的姓名 |
| contact_phone | 联系人电话 | 手机号(1开头的11位数字)或固话 |
| contact_email | 联系人邮箱 | 邮箱地址格式 |
| company_address | 公司地址 | 地址、省市县、街道门牌号 |
| unified_credit_code | 统一社会信用代码 | 18位统一社会信用代码 |
| bank_name | 开户行/开户银行 | 银行、支行等关键词 |
| bank_account | 银行账号 | 16-19位数字 |
| bank_union_code | 开户银行联行号 | 联行号、大小额行号 |

## 工作流程

### 步骤1：文件上传与分析

**输入格式支持：**
- Word文档：`.docx`、`.doc`
- PDF文件：`.pdf`
- 图片文件：`.jpg`、`.jpeg`、`.png`、`.webp`

**处理方式：**
1. Word/PDF：直接提取文本内容
2. 图片：使用OCR识别提取文本

### 步骤2：文本预处理

- 清理无关字符和格式符号
- 标准化空格和换行
- 按行或段落分割文本

### 步骤3：字段提取

**提取策略：**
1. **正则匹配**：使用预定义的正则表达式模式
2. **上下文分析**：根据字段前后的关键词（标签）定位
3. **结构化识别**：识别表格、列表等结构化数据

**优先级规则：**
- 带标签（如"供应商名称："）的字段优先
- 无标签时使用上下文推断
- 多个匹配项时取首个有效值

### 步骤4：结果输出

**输出格式：**
- **复制模式**：将提取结果格式化为文本，可直接复制
- **Excel导出**：生成`.xlsx`格式文件

**Excel格式模板：**
| 供应商名称 | 联系人姓名 | 联系人电话 | 联系人邮箱 | 公司地址 | 统一社会信用代码 | 开户行 | 银行账号 | 开户银行联行号 |
|-----------|-----------|-----------|-----------|---------|----------------|--------|---------|--------------|

## 注意事项

1. **图片质量**：OCR识别效果与图片清晰度相关，建议上传清晰扫描件
2. **复杂格式**：表格或结构化数据识别准确率更高
3. **缺失字段**：无法识别的字段留空，不填入猜测值
4. **隐私保护**：敏感信息仅用于本次处理，不做存储

## 错误处理

| 错误类型 | 处理方式 |
|---------|---------|
| 文件格式不支持 | 提示用户支持的格式列表 |
| 文件读取失败 | 提示具体错误原因 |
| OCR识别失败 | 建议用户提供更高质量的图片 |
| 部分字段缺失 | 标注缺失字段，继续提取其他字段 |
