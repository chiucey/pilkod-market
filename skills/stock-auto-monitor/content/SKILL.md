# 股票自动盯盘系统

## 一、核心设置

### 1.1 盯盘基础参数

| 参数 | 设置值 |
|------|--------|
| 盯盘周期 | 日内实时盯盘（9:30-11:30，13:00-15:00） |
| 盯盘依据 | 纯技术面（K线、量价、5/10日均线、换手率、分时走势） |
| 止损规则 | 固定-5%（跌破自动触发止损提醒） |
| 提醒频率 | 实时监控+每小时汇总，收盘后10分钟生成当日总结 |

### 1.2 监控标的

监控标的由用户指定，建议控制在3-5只股票。

## 二、信号识别与提醒

### 2.1 买入信号（主力加仓判定）

**触发条件（需同时满足）：**
- 主力加仓得分 ≥ 70分，出货得分 ≤ 40分
- 股价站稳5/10日均线
- 当日放量（量能 ≥ 近5日均量130%）
- 换手率3%-10%，分时呈阶梯抬升
- 回踩均线后快速拉回

**提醒格式：**
```
【买入信号】{股票名称}({代码})
主力加仓得分：{X}/100
当前股价：{价格} | 今日涨跌：{涨跌幅}%
换手率：{X}%
短线买入条件已满足，建议关注
止损价：{当前价 × 0.95}
```

### 2.2 卖出/减仓信号（主力出货判定）

**触发条件（满足任一即触发）：**
- 主力出货得分 ≥ 70分，加仓得分 ≤ 40分
- 股价有效跌破5日均线，且放量（量能 ≥ 近5日均量150%）
- 换手率 > 12%（天量换手）
- 出现高位放量长阴、分时冲高回落
- 股价跌破止损价（当前价 ≤ 买入价 × 0.95）

**提醒格式：**
```
【卖出/止损信号】{股票名称}({代码})
主力出货得分：{X}/100 | 当前亏损/盈利：{XX}%
当前股价：{价格} | 今日涨跌：{涨跌幅}%
换手率：{X}%
建议立即减仓/卖出
```

### 2.3 观望/洗盘信号

**触发条件：**
- 主力加仓得分 50-69分，出货得分 40-60分
- 股价在均线之间震荡，缩量回调（量能 < 近5日均量70%）
- 走势弱于板块，但未跌破关键均线

**提醒格式：**
```
【观望信号】{股票名称}({代码})
主力洗盘/无明显动作
当前股价：{价格} | 今日涨跌：{涨跌幅}%
建议观望，重点监控5日均线支撑
止损价：{当前价 × 0.95}
```

## 三、盯盘输出格式

### 3.1 实时提醒

每触发信号立即输出对应格式的提醒。

### 3.2 每小时汇总格式

```

得分：加仓{X}/100，出货{Y}/100
核心技术信号：
  1. {信号1}
  2. {信号2}
  3. {信号3}
当日操作建议：买入/持有/减仓/卖出/观望
止损价：{XXX} | 状态：未跌破/已跌破
后续监控：{重点监控项}
```

## 四、止盈止损规则

### 4.1 止损规则（刚性执行）
- 固定止损线：-5%
- 触发条件：当前价 ≤ 买入价 × 0.95
- 提醒：立即发送止损警报，要求确认执行

### 4.2 止盈规则（分批执行）
| 盈利幅度 | 操作建议 |
|----------|----------|
| ≥ 10% | 逐步止盈，保留部分仓位 |
| ≥ 15% | 清仓止盈 |

### 4.3 异常波动警报
- 日内波动 ≥ 8%：立即提醒
- 换手率突增 > 15%：立即提醒

## 五、技术指标参考标准

### 5.1 均线系统
| 指标 | 说明 |
|------|------|
| 5日均线 | 短线支撑/压力线 |
| 10日均线 | 中短线趋势线 |
| 站稳均线 | 收盘价 > 均线价格 |
| 有效跌破 | 收盘价 < 均线且放量确认 |

### 5.2 量能标准
| 类型 | 标准 |
|------|------|
| 放量上涨 | 量能 ≥ 近5日均量130% |
| 放量下跌 | 量能 ≥ 近5日均量150% |
| 缩量回调 | 量能 < 近5日均量70% |

### 5.3 换手率标准
| 类型 | 标准 |
|------|------|
| 正常范围 | 3% - 10% |
| 天量换手 | > 12% |
| 异常突增 | 突增 > 15% |

## 六、使用说明

### 6.1 启动盯盘
用户提供股票代码列表，启动自动盯盘系统。

### 6.2 信号处理流程
1. 系统实时监控所有设定股票
2. 触发任一信号立即输出对应提醒
3. 用户根据提醒执行操作
4. 系统记录操作并更新止损参考价

### 6.3 盯盘终止
- 用户主动终止
- 止盈/止损执行完毕
- 收盘后自动结束当日盯盘
