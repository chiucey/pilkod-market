# 股票盯盘技术分析参考指南

## 一、K线形态识别

### 1.1 底部反转形态
| 形态 | 特征 | 信号强度 |
|------|------|----------|
| 锤子线 | 下影线是实体2倍以上，收盘于高位 | 强 |
| 吞没形态 | 阳线完全吞没前一根阴线 | 强 |
| 早晨之星 | 三日组合，中间星线缩量 | 中强 |

### 1.2 顶部反转形态
| 形态 | 特征 | 信号强度 |
|------|------|----------|
| 射击之星 | 上影线是实体2倍以上 | 强 |
| 乌云盖顶 | 阴线跌破前阳线50%以上 | 强 |
| 黄昏之星 | 三日组合，顶部星线放量 | 中强 |

### 1.3 持续形态
| 形态 | 特征 | 信号强度 |
|------|------|----------|
| 旗形整理 | 短暂顺趋势整理 | 中 |
| 三角形 | 收敛震荡，突破方向确定 | 强 |

## 二、均线系统应用

### 2.1 均线参数设置
```
短期：5日均线（MA5）
中期：10日均线（MA10）
参考：20日均线（MA20）
```

### 2.2 均线交叉信号
| 交叉类型 | 条件 | 信号 |
|----------|------|------|
| 金叉 | MA5上穿MA10，且价格在双均线上方 | 买入 |
| 死叉 | MA5下穿MA10，且价格在双均线下方 | 卖出 |

### 2.3 均线支撑压力
| 角色 | 买入信号 | 卖出信号 |
|------|----------|----------|
| 支撑 | 回调至均线附近企稳 | 跌破均线支撑 |
| 压力 | 放量突破均线 | 反弹至均线遇阻 |

## 三、量价关系分析

### 3.1 经典量价配合
| 走势 | 量能特征 | 信号 |
|------|----------|------|
| 放量上涨 | 量能持续放大，价升量增 | 强势买入 |
| 缩量上涨 | 量能萎缩，价升量减 | 弱势，警惕 |
| 放量下跌 | 量能放大，恐慌抛售 | 离场 |
| 缩量下跌 | 量能萎缩，抛压减轻 | 可能见底 |

### 3.2 量能异常识别
```
天量：天量换手 > 12%，警惕主力出货
地量：换手 < 1%，交投清淡
堆量：连续多日放量，主力建仓迹象
散量：量能分散，无主力运作
```

### 3.3 量比指标
| 量比范围 | 含义 |
|----------|------|
| < 0.5 | 缩量，观望 |
| 0.5 - 1.5 | 正常波动 |
| 1.5 - 3.0 | 温和放量 |
| > 3.0 | 明显放量，关注 |

## 四、分时走势分析

### 4.1 强势分时特征
```
✓ 阶梯式抬升（台阶式上涨）
✓ 黄线（均价线）在白线（实时线）上方
✓ 回调不破均线，缩量
✓ 尾盘稳健，不跳水
```

### 4.2 弱势分时特征
```
✗ 尖刺式急拉（主力诱多）
✗ 白线远离黄线，虚假繁荣
✗ 冲高回落，形成M头
✗ 尾盘快速跳水
```

### 4.3 分时图买卖点
| 类型 | 特征 | 操作 |
|------|------|------|
| 突破买点 | 放量突破分时整理平台 | 买入 |
| 回踩买点 | 回调至均线支撑缩量 | 买入 |
| 顶背离卖点 | 创新高但量能萎缩 | 卖出 |
| 均线破位卖点 | 跌破分时均线且无力收回 | 卖出 |

## 五、换手率分析

### 5.1 换手率区间含义
| 换手率 | 含义 | 操作建议 |
|--------|------|----------|
| < 1% | 极度低迷 | 观望 |
| 1% - 3% | 正常偏低 | 蓄势阶段 |
| 3% - 7% | 活跃 | 关注机会 |
| 7% - 12% | 高度活跃 | 重点关注 |
| 12% - 20% | 异常活跃 | 警惕风险 |
| > 20% | 极度异常 | 主力对倒嫌疑 |

### 5.2 换手率变化预警
```
突增预警：换手率较前日增加 50% 以上
异常预警：连续3日换手 > 15%
```

## 七、止损技术判断

### 7.1 止损位设置
```
固定止损：买入价 × 0.95（-5%）
均线止损：5日均线跌破确认
时间止损：买入后3日未启动
```

### 7.2 止损执行标准
| 触发条件 | 执行动作 |
|----------|----------|
| 跌破止损价 | 立即提醒，确认执行 |
| 有效跌破5日均线 | 减仓50% |
| 放量跌破10日均线 | 清仓 |

### 7.3 止损后处理
1. 记录止损原因
2. 分析技术面变化
3. 等待企稳信号再考虑重新介入
