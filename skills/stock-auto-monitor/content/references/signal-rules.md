# 股票盯盘信号识别规则手册

## 一、信号分类体系

### 1.1 信号等级划分
```
A级信号（立即执行）
├── 止损触发（-5%红线）
├── 主力出货确认（得分>85）
└── 跌停/涨停异动

B级信号（当日执行）
├── 买入信号确认
├── 卖出信号确认
├── 止盈触发（+15%）
└── 异常波动警报

C级信号（持续观察）
├── 洗盘信号
├── 观望信号
└── 无明显动作
```

### 1.2 信号优先级
```
最高优先级：止损信号
    ↓
次高优先级：主力出货信号
    ↓
中等优先级：主力加仓信号
    ↓
普通优先级：观望/洗盘信号
```

## 二、买入信号详细规则

### 2.1 主力加仓信号（核心条件）
```
必要条件：
  主力加仓得分 ≥ 70分
  主力出货得分 ≤ 40分

辅助条件（至少满足2项）：
  □ 股价站稳5日均线
  □ 股价站稳10日均线
  □ 当日量能 ≥ 近5日均量130%
  □ 分时走势呈阶梯抬升
  □ 回踩均线后快速拉回
```

### 2.2 买入信号触发场景

#### 场景A：突破买入
```
触发条件：
  • 股价放量突破前期高点
  • 站稳5日、10日均线
  • 换手率3%-10%
  • 分时回调不破均线

买入时机：突破后回踩确认时买入
止损位：突破阳线最低价
```

#### 场景B：回踩买入
```
触发条件：
  • 上升趋势中的正常回踩
  • 缩量回调至均线附近
  • 快速拉回不破均线
  • 主力加仓得分持续高位

买入时机：企稳回升时买入
止损位：均线下方1%
```

#### 场景C：缩量整理买入
```
触发条件：
  • 连续缩量整理3-5日
  • 股价未跌破关键均线
  • 主力加仓得分稳定
  • 换手率持续低于3%

买入时机：放量启动时买入
止损位：整理区间下沿
```

### 2.3 买入信号排除项
```
以下情况不触发买入信号：
  ✗ 股价处于高位（距近期高点<5%）
  ✗ 换手率超过15%
  ✗ 分时出现尖刺式急拉
  ✗ 主力加仓得分<60
  ✗ 大盘处于下跌趋势
```

## 三、卖出信号详细规则

### 3.1 主力出货信号（核心条件）
```
必要条件：
  主力出货得分 ≥ 70分
  主力加仓得分 ≤ 40分

辅助条件（满足任一）：
  □ 股价有效跌破5日均线
  □ 放量下跌（量能≥近5日均量150%）
  □ 高位放量长阴
  □ 分时冲高回落形成M头
  □ 换手率>12%
```

### 3.2 卖出信号触发场景

#### 场景A：均线破位卖出
```
触发条件：
  • 股价跌破5日均线
  • 跌破时放量确认
  • 分时反弹无力

卖出时机：反弹至均线附近卖出
减仓比例：至少50%
```

#### 场景B：顶部形态卖出
```
触发条件：
  • 出现射击之星、乌云盖顶等形态
  • 伴随放量
  • 换手率异常

卖出时机：确认形态后立即卖出
减仓比例：全部或80%
```

#### 场景C：分时走弱卖出
```
触发条件：
  • 分时多次冲高回落
  • 均价线持续下移
  • 尾盘快速跳水

卖出时机：跌破分时均线时卖出
减仓比例：至少50%
```

### 3.3 止损执行规则
```
触发条件：当前价 ≤ 买入价 × 0.95

执行流程：
  1. 系统立即发出止损警报
  2. 提示用户确认执行
  3. 用户确认后以市价卖出
  4. 记录止损日志

绝对原则：跌破止损价必须执行，不存在侥幸
```

## 四、观望/洗盘信号规则

### 4.1 洗盘信号判定
```
条件组合：
  • 主力加仓得分：50-69分
  • 主力出货得分：40-60分
  • 量能 < 近5日均量70%
  • 股价在均线间震荡
  • 未跌破关键均线
```

### 4.2 洗盘信号处理
```
不操作：保持现有仓位或空仓观望
监控项：
  • 均线支撑是否有效
  • 缩量整理何时结束
  • 主力行为变化

重新评估条件：
  • 跌破均线 → 触发卖出
  • 放量启动 → 触发买入
  • 持续整理 → 继续观望
```

### 4.3 无信号状态
```
判定标准：
  • 主力加仓得分 < 50
  • 主力出货得分 < 40
  • 无明显技术信号
  • 走势跟随大盘

处理方式：
  • 不操作
  • 继续监控
  • 等待明确信号
```

## 五、特殊信号处理

### 5.1 涨停信号
```
触发条件：股价达到涨停价

监控重点：
  • 封单量变化
  • 是否有炸板风险
  • 换手率是否异常

操作建议：
  • 持有不追高
  • 涨停打开立即减仓
  • 次日高开观察封单
```

### 5.2 跌停信号
```
触发条件：股价达到跌停价

监控重点：
  • 封单量大小
  • 是否有撬板资金
  • 大盘环境

操作建议：
  • 止损单优先执行
  • 不抄底不补仓
  • 等待开板后决策
```

### 5.3 异常波动警报
```
触发条件：
  • 日内振幅 ≥ 8%
  • 换手率突增 > 15%
  • 股价瞬间涨跌 > 3%

处理流程：
  1. 立即发出警报
  2. 分析波动原因
  3. 根据原因决定操作
  4. 更新盯盘参数
```

## 六、信号输出规范

### 6.1 输出要素
```
每条信号输出必须包含：
  □ 股票名称和代码
  □ 信号类型（买入/卖出/观望）
  □ 信号评分
  □ 当前股价
  □ 今日涨跌幅
  □ 换手率
  □ 止损参考价
  □ 操作建议
  □ 监控重点
```

### 6.2 紧急程度标识
```
【紧急】- 止损触发、跌停风险
【重要】- 买卖信号确认
【提醒】- 止盈提醒、异常警报
【普通】- 观望信号、常规汇总
```
