# 证据诉讼整理师

## 技能概述

本技能用于将原始证据材料整合为符合诉讼要求的证据合集和目录。

## 工作流程

### 步骤1：材料读取与分析

1. **读取法律文书**
   - 提取答辩状/起诉状的核心观点
   - 识别请求事项和事实理由
   - 标注关键证据引用

2. **读取证据材料**
   - 支持格式：PDF、Word、图片
   - 提取文本内容和关键信息
   - 按时间线标注证据要素

### 步骤2：证据分类与排序

**分类维度**：

| 类别 | 说明 | 典型证据 |
|------|------|----------|
| 主体资格证据 | 证明当事人主体身份 | 营业执照、身份证 |
| 法律关系证据 | 证明法律关系性质 | 合同、协议、聊天记录 |
| 事实依据证据 | 证明具体事实 | 票据、往来记录、照片 |
| 程序性证据 | 证明程序合法 | 通知书、送达回证 |

**排序原则**：
- 主证据优先（直接证明核心争议）
- 时间顺序次之（便于事实还原）
- 关联性强的证据相邻排列

### 步骤3：证据合集编排

**证据条目格式**：

```markdown
### 证据N：[证据名称]
**证据来源**：[原始文件名]
**证明目的**：[简明表述]
**关键内容**：[摘录或摘要]
**页码**：第X页
```

**页码编排规则**：
1. 封面及目录：第1页
2. 主体资格证据：第2页
3. 核心法律关系证据：第3-X页
4. 事实依据证据：续排
5. 程序性证据：最后

### 步骤4：证据目录编制

**目录格式**：

```markdown
| 序号 | 证据编号 | 证据名称 | 页码 | 证据来源 | 证明目的 |
|:---:|:-------:|---------|:----:|---------|---------|
```

**必须包含**：
- 证据与观点对应表
- 证据来源清单
- 时间线（如涉及）

## 输出产物

1. **证据合集（带页码）**
   - 按逻辑顺序编排
   - 每份证据标注来源和证明目的
   - 包含关键内容摘要

2. **证据目录**
   - 与证据合集页码对应
   - 包含证据来源文件清单
   - 证据与诉讼观点对照

## 快速执行检查清单

- [ ] 法律文书核心观点已提取
- [ ] 证据材料已完整读取
- [ ] 证据按分类维度完成排序
- [ ] 证据合集包含页码标注
- [ ] 证据目录与合集页码对应
- [ ] 证据-观点对照关系已建立

## 典型使用场景

**场景1：劳动争议案件**
```
输入：答辩状 + 聊天记录PDF + 劳动合同
输出：
- 证据合集（劳动关系认定证据）
- 证据目录（按入职、任职、解约时间排序）
```

**场景2：合同纠纷案件**
```
输入：起诉状 + 合同文本 + 履行记录
输出：
- 证据合集（合同履行情况证据）
- 证据目录（按签约、履行、违约时间排序）
```
