# 数据源与口径说明

## 站点结构

栏目页（`www.csdata.cn`）：
- 「融资融券数据 → 融资融券市场每日数据统计」：列表分页 `d2bb5c19-N.html`，N=1..41，覆盖约 2025-02 起至今
- 「融资融券数据 → 融资融券历史数据 → 融资融券市场日度历史数据统计」：列表分页 `5cb2feab-N.html`，N=1..160，可回溯到 2012 年

每个列表项形如：
```html
<li><span>2026-10-27</span>
  <a href="/cmsmc/articleFileDir/2026-10/27/5dda113d....xlsx"
     title="融资融券市场每日数据统计20261027" ...>…</a></li>
```
- `title` 里的 `YYYYMMDD` 才是**数据日期**；`<span>` 是**上传日期**（多为次日），两者不要混用
- 文件 URL 前缀统一是 `/cmsmc/articleFileDir/...`，**不含任何栏目名**
  → 想知道一条数据来自哪个栏目，只能看它出现在哪个列表页，不能从文件 URL 推断

## 两种文件形态与口径统一

| | 新格式 | 老格式 |
|---|---|---|
| 扩展名 | `.xlsx`（个别是 `.xlsx_bak`） | `.xls`（BIFF8 二进制） |
| 时间段 | 2025-02 起 | 2024 全年 ~ 2025-02 |
| 比例存储 | 数值 + 百分比格式，`2.556273` | 文本，`"249.8%"` |
| 日期存储 | Excel 序列号（格式可能是 `yyyy年M月d日`，**也可能是 General 格式的裸序列号**） | 文本 `"2024年08月19日"` |

统一到「百分数数值」（255.6273 = 255.6273%）：
- 数值 + 格式串含 `%` → 值 × 100
- 文本以 `%` 结尾 → 去符号直接用
- 裸数值无格式 → 按量级判断：<10 视为比值 ×100，≥10 视为已是百分数
- 日期：优先文本里的 `YYYY年M月D日` / `YYYY-MM-DD`；否则按日期格式识别序列号；
  格式是 General 的裸序列号时用合理区间（20000~60000）兜底识别

## 已知坑（都已在脚本里处理）

1. **列表页陈旧缓存**：带 `Accept-Encoding: gzip` 请求时，站点会命中陈旧缓存，返回缺少最新条目的旧版本；
   集群里还有多个缓存节点，同一 URL 不同次返回的条目数不同。
   → 脚本用 `Accept-Encoding: identity` + 随机 query 破缓存，多轮抓取取**并集**。
   实际案例：2026-10-13 的文件在官网确实存在（`articleFileDir/2026-10/13/d171a688a....xlsx`，比例 262.1965%），
   但只抓一轮列表页时会因命中陈旧缓存而"看不到"它，被误判为官网未发布。
2. **`.xlsx_bak` 链接**：个别条目的 href 以 `.xlsx_bak` 结尾（2024-10-21 就是这种），
   按 `.xls|.xlsx` 结尾匹配会漏掉。→ 脚本按"含 xlsx 即按 zip 解析"处理。
3. **同日多版本**：2024-02-19 官网发了两个版本（06:35 的 .xls 文本版 249.8%、14:45 的 .xlsx 机器版 249.56%）。
   证金公司口径与证券时报报道为 249.6%，与 .xlsx 版一致。
   → 脚本优先取 .xlsx，并在 Excel 备注列注明「官网同日发布 N 个版本，已取 xlsx 机器格式版本」。
4. **交易日历兜底**：以交易所交易日历（上证指数实际有行情的日期）为准校验"应有几天"，
   与列表页抓到的日期做差集，缺的日子定向补抓。2024/2025/2026 官方交易日数分别为 242/243/194。
5. **当日数据未发布**：官网通常次日早上才出前一天的数据。请求到今天时，当天可能还没有文件，
   脚本会报告失败而不是编造数据。

## 校验方法（脚本已内建，交付时可复述）

- **交易日完整性**：与交易所日历逐日比对，列出缺失日期
- **文件内日期一致性**：每个源文件内部解析出的统计日期必须等于列表标题日期，不等则拒绝该文件
- **指数双源比对**：搜狐财经（主源，交易所 2 位小数收盘）与新浪财经（校验源，3 位小数）逐日比对，
  差异须 < 0.01 点
- **外部锚点**：2024-10-08 上证收盘 3489.78（证券时报报道）、2024-02-05 两融比例 222%（当日公开报道）、
  2024-09-30 比例 288.51%（与官网月度历史数据文件的月末值一致）
- **跨实现比对**：本技能的 Node 实现与独立的 Python 实现，680 个交易日的比例与指数逐行零差异

## 上证指数数据源

- 主源：`https://q.stock.sohu.com/hisHq?code=zs_000001&start=YYYYMMDD&end=YYYYMMDD&...`
  返回 JSONP，字段 `[日期,开盘,收盘,涨跌额,涨跌幅,最低,最高,成交量,成交额,换手]`
- 校验源：`https://money.finance.sina.com.cn/quotes_service/api/json_v2.php/CN_MarketData.getKLineData?symbol=sh000001&scale=240&ma=no&datalen=1400`
  返回 `[{day,open,high,low,close,volume}]`（最近 N 个交易日）

两个接口都不稳定（腾讯 WAF 拦截、东方财富空响应），换源时先验证再改。

## 模块地图

| 文件 | 职责 |
|---|---|
| `scripts/margin_report.mjs` | CLI 入口：参数解析 → 补数 → 组装 → 出 Excel/HTML |
| `scripts/lib/net.mjs` | HTTP 抓取、gzip 解压、重试、缓存破坏 |
| `scripts/lib/sources.mjs` | 中证数据列表页解析与文件下载、上证指数双源获取 |
| `scripts/lib/cache.mjs` | 增量缓存（records.jsonl + 源文件 + sse.json） |
| `scripts/lib/extract.mjs` | 从源文件提取比例与日期，统一口径 |
| `scripts/lib/xlsx-read.mjs` | 读 .xlsx（zip + OOXML） |
| `scripts/lib/xls-read.mjs` | 读 .xls（OLE2 + BIFF8，纯 Node 实现，172/172 与 LibreOffice 转换结果一致） |
| `scripts/lib/xlsx-write.mjs` | 写 .xlsx（OOXML 生成）。日期写成真正的 Excel 日期值（序列号 + `yyyy-mm-dd` 格式），不是文本 |
| `scripts/lib/html-report.mjs` | 生成自包含 HTML 报告 |
| `scripts/lib/stats.mjs` | 均值/中位数/相关系数/线性回归 |
