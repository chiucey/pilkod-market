# 阅文系列平台小说写作技能

## 核心定位

本技能专注于阅文集团旗下平台（起点中文网、起点读书、红袖添香、起点女生网等）的网络小说创作，为作者提供平台适配的写作指导、爆款分析和签约攻略。

## 一、平台特性分析

### 1.1 主要平台特征

| 平台 | 定位 | 主力读者群 | 主流类型 | 日更要求 |
|------|------|-----------|---------|---------|
| 起点中文网 | 综合性男频 | 18-35岁男性 | 玄幻/都市/科幻/游戏 | 3000-6000字 |
| 起点女生网 | 综合性女频 | 18-40岁女性 | 现言/古言/玄幻言情 | 3000-5000字 |
| 红袖添香 | 女性向精品 | 25-45岁女性 | 现言/总裁/婚恋 | 3000-5000字 |
| 晋江文学城 | 女性向综合 | 18-35岁女性 | 纯爱/言情 | 3000字以上 |

### 1.2 平台推荐机制

**起点推荐流程（男频）：**
1. 新书入库 → 分类强推 → 三江推荐 → 分频推荐 → 编辑推荐
2. 追读率是关键指标（前20章决定命运）
3. 上架前均订1000+可获得更多推荐资源

**起点女生网/红袖推荐流程：**
1. 新书入库 → 女生网推荐 → 编辑推荐 → APP曝光
2. 阅读留存率和付费率是核心
3. "爽点密度"决定读者留存

### 1.3 平台禁忌

- ❌ 涉政、涉黄、涉暴内容
- ❌ 抄袭、洗稿、融梗
- ❌ 断更超过7天（影响推荐）
- ❌ 章节重复内容超过30%
- ❌ 标题党、封面违规

## 二、爆款开篇公式

### 2.1 男频开篇模板

```
【黄金三章法则】
第1章：困境/金手指/冲突爆发
第2章：小高潮/解决第一个问题
第3章：世界观展开/长期目标建立

公式：困境→转机→第一个小胜利
```

**玄幻/都市通用结构：**
```
开篇场景：[危机/困境/机遇]
主角当前：[困境描述，100-200字]
金手指：[系统/异能/传承，简洁带出]
第一个冲突：[与反派的初次交锋或资源争夺]
第一个爽点：[碾压/打脸/获得好处]
钩子：[留下悬念，引导继续阅读]
```

### 2.2 女频开篇模板

```
【情感线+剧情线双轨并进】
第1章：人设展示+情感线起点
第2章：冲突介入+剧情推进
第3章：感情升温或关键转折

公式：人设吸引→情感张力→期待感
```

**现代言情结构：**
```
开篇场景：[与男主的初次接触/重逢/误会]
女主人设：[通过行为和内心展示，非介绍]
男主登场：[霸道/温柔/禁欲等特质快速确立]
情感张力：[暧昧/误解/对立关系建立]
悬念钩子：[未解之谜或情感纠葛伏笔]
```

**古代言情结构：**
```
开篇场景：[穿越/重生/及笄等关键节点]
女主处境：[穿越文：原主困境；重生文：前世记忆]
金手指：[医术/空间/剧透/现代知识]
宅斗/宫斗线索：[第一个冲突事件]
权贵男主：[身份揭示或隐藏身份]
```

## 三、大纲设计方法论

### 3.1 男频大纲结构

```
【主线路径】
1. 开局困境（1-3章）
2. 觉醒/成长阶段（4-30章）
3. 第一个大目标（30-100章）
4. 中期危机（100-200章）
5. 终极目标/大决战（200-300章）

【支线设计】
- 副本体系（副本名→难度→奖励）
- 感情线（若有）
- 势力扩张/团队建立
- 伏笔回收节点
```

### 3.2 女频大纲结构

```
【情感线+事业线双线结构】
情感线：相遇→相知→误会→升温→危机→圆满
事业线：立足→发展→危机→突破→成功

【高光章节规划】
- 女主高光时刻（每20-30章一个）
- 男主心动时刻（情感升温节点）
- 甜蜜互动（每10-15章）
- 虐点/冲突（每30-40章一个中等虐）
```

### 3.3 核心冲突设计

**冲突类型：**
- 生存冲突：生死存亡、资源争夺
- 利益冲突：利益分配、权力争夺
- 情感冲突：误会、背叛、三角关系
- 理念冲突：价值观对立、路线选择
- 身份冲突：身份暴露、身份错位

**冲突升级原则：**
- 小冲突引出大冲突
- 单方劣势→双方博弈→反转
- 冲突解决要彻底，避免反复

## 四、人物塑造指南

### 4.1 男频主角模板

```
【成长型主角】
- 出身：低微但有潜力
- 性格：隐忍→果断→杀伐果断
- 金手指：系统/传承/重生预知
- 目标：复仇/崛起/守护
- 成长曲线：吃亏→学习→蜕变

【无敌流主角】
- 起点即巅峰或快速成长
- 核心看点：装逼打脸、智商碾压
- 敌人：衬托主角的强大
- 爽点：碾压感、信息差
```

### 4.2 女频女主模板

```
【大女主模板】
- 独立自主，有明确目标
- 智商在线，不傻白甜
- 感情上拿得起放得下
- 事业线与情感线并行
- 闺蜜/盟友人设丰满

【甜宠文女主】
- 可爱/软萌/但有底线
- 依赖男主但不卑微
- 单纯但不愚蠢
- 专属萌点设计
```

### 4.3 反派设计

```
【工具型反派】
- 功能：制造冲突、推动剧情
- 特点：坏得彻底，不洗白
- 结局：被主角碾压

【复杂型反派】
- 有自己的立场和逻辑
- 与主角的对立有深层原因
- 可洗白或同归于尽
- 增加故事深度
```

## 五、爽点设计体系

### 5.1 男频爽点类型

| 爽点类型 | 触发场景 | 频率 |
|---------|---------|------|
| 打脸爽点 | 碾压敌人、嘲讽反噬 | 每10-15章 |
| 升级爽点 | 突破境界、获得宝物 | 每5-8章 |
| 装逼爽点 | 展示实力、震惊全场 | 每8-12章 |
| 收集爽点 | 收服美女/小弟/神兽 | 每15-20章 |
| 复仇爽点 | 报复仇人、夺回尊严 | 关键节点 |
| 守护爽点 | 保护亲人/爱人/势力 | 情感高潮 |

### 5.2 女频爽点类型

| 爽点类型 | 触发场景 | 频率 |
|---------|---------|------|
| 心动爽点 | 男主宠溺/吃醋/关心 | 每8-12章 |
| 打脸爽点 | 虐极品/撕绿茶/揭穿阴谋 | 每10-15章 |
| 事业爽点 | 项目成功/能力展示/逆袭 | 每20章 |
| 甜蜜爽点 | 亲密互动/告白/求婚 | 每15-20章 |
| 团宠爽点 | 众人偏爱/身份揭晓 | 关键节点 |
| 虐渣爽点 | 报复渣男/恶毒女配 | 阶段性 |

### 5.3 爽点节奏公式

```
【小爽点】：每3-5章一个
【中爽点】：每10-15章一个
【大爽点】：每30-50章一个（配合推荐）
【高潮爽点】：每个大阶段的结局
```

## 六、章节创作规范

### 6.1 章节结构

```
【单章标准结构】
开头（100-200字）：上章钩子回顾+新场景
铺垫（300-500字）：冲突酝酿
爆发（500-1000字）：核心情节推进
结尾（100-200字）：悬念/爽点/钩子

【章末钩子技巧】
- 悬念式：留下未解之谜
- 爽点式：留个得意瞬间
- 冲突式：冲突戛然而止
- 甜点式：感情线小高潮
```

### 6.2 日更节奏建议

| 日更字数 | 章节安排 | 适用阶段 |
|---------|---------|---------|
| 3000字/天 | 2章（每章1500字） | 新书期 |
| 5000字/天 | 2-3章 | 推荐期 |
| 6000字/天 | 3章 | 爆发期 |

### 6.3 章节命名规范

```
【男频命名】
- 章节名即核心爽点
- 示例：「第001章 废物少爷」「第045章 逆鳞不可触」

【女频命名】
- 章节名含情感/悬念元素
- 示例：「第一章 重逢」「第三章 心动」
```

## 七、新书上架指南

### 7.1 上架前准备

```
【存稿要求】
- 至少存稿20万字以上
- 确保上架后不断更
- 留好关键章节修改余地

【心态准备】
- 接受前期单机期（3万字前）
- 追读率是关键，稳住更新
- 拒绝中途烂尾太监
```

### 7.2 签约判断标准

| 平台 | 签约率 | 关键指标 |
|------|-------|---------|
| 起点男频 | 1-3% | 三万字申请，编辑看数据 |
| 起点女生网 | 3-5% | 开篇质量，人设是否讨喜 |
| 红袖添香 | 5-8% | 题材新颖度，前三章质量 |

### 7.3 推荐位冲刺

```
【冲榜技巧】
1. 编辑推荐前追读要稳
2. 章节末尾求票求收藏
3. 爆更（节假日多更）
4. 书名/简介优化
5. 积极回复读者评论
```

## 八、市场趋势分析

### 8.1 当前热门题材（2024-2025）

| 类型 | 热度 | 备注 |
|------|-----|------|
| 都市脑洞文 | ⭐⭐⭐⭐⭐ | 反套路、创意取胜 |
| 玄幻无敌流 | ⭐⭐⭐⭐ | 节奏快、爽感强 |
| 穿越种田文 | ⭐⭐⭐⭐ | 慢热但粘性高 |
| 总裁甜宠文 | ⭐⭐⭐⭐ | 刚需稳定 |
| 穿书/病娇/团宠 | ⭐⭐⭐⭐⭐ | 女频顶流 |
| 星际/末世 | ⭐⭐⭐ | 稳定赛道 |

### 8.2 题材避坑

```
【男频谨慎】
- 老套退婚流（除非创新）
- 无脑升级文（已审美疲劳）
- 绿帽/憋屈文（读者流失快）

【女频谨慎】
- 过度玛丽苏（被骂）
- 傻白甜女主（被骂）
- 无脑虐女主（容易被弃）
```

## 九、质量自检清单

完成章节后自检：

- [ ] 开篇300字内是否有钩子？
- [ ] 章节内是否有至少一个爽点/期待点？
- [ ] 主角是否有明确的目标/动机？
- [ ] 章节末是否留有钩子？
- [ ] 是否有错别字、语病？
- [ ] 冲突是否合理、是否升级？
- [ ] 章节字数是否达标（1500-2000字）？
