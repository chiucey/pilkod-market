# 阅文平台人物模板库

## 一、男频主角模板

### 1.1 成长型男主模板

```
【基础设定】
姓名：[由作者决定]
年龄：18-25岁（可根据题材调整）
外貌：清秀/普通外表→后期逐渐出众
性格：初期隐忍低调→中期果断→后期杀伐果断

【身世背景】
- 出身：底层/废物/被欺辱的开局
- 天赋：中等/隐藏/后期觉醒
- 家人：父母健在但弱势/或已故/或失散
- 转折点：获得金手指/奇遇/传承

【核心特质】
- 重情重义（对家人、朋友、爱人）
- 有恩必还，有仇必报
- 不惹事但也不怕事
- 隐忍但不窝囊
- 关键时刻敢于拼命

【成长曲线】
第一阶段（1-50章）：被压迫→觉醒
- 表现：隐忍、学习、快速成长
- 转折：第一次真正的胜利

第二阶段（51-150章）：崛起→小有名气
- 表现：主动出击、建立势力
- 转折：在更大舞台上证明自己

第三阶段（151-300章）：称雄→巅峰
- 表现：成为顶尖、有话语权
- 转折：面对终极敌人

【金手指类型】
- 系统流：完成任务获取奖励
- 传承流：获得上古传承
- 重生流：预知未来
- 血统流：隐藏血脉觉醒
- 空间流：随身空间/老爷爷

【目标设定】
- 主目标：复仇/守护/巅峰/探索
- 支目标：提升实力、收集宝物、建立势力
- 感情目标：得一佳人/建立后宫（视题材）
```

### 1.2 无敌流男主模板

```
【基础设定】
姓名：霸气/简洁
年龄：20-30岁
外貌：俊美/气场强大
性格：冷酷/霸气/但对特定人温柔

【核心设定】
- 起点即巅峰或快速登顶
- 智商碾压，布局深远
- 表面低调实则无敌
- 装逼打脸是核心爽点

【敌人类型】
- 不长眼的小人：衬托主角的强大
- 背后大佬：制造悬念和压力
- 势力对抗：最终Boss设定

【爽点设计】
- 信息差：敌人不知主角真实实力
- 智商碾压：轻松看穿阴谋
- 实力碾压：直接碾压不废话
- 身份碾压：主角身份超出想象
```

### 1.3 舔狗逆袭流男主模板

```
【基础设定】
姓名：普通
年龄：20-25岁
外貌：普通
开局：被女神抛弃/羞辱

【逆袭路径】
1. 开局打击：被分手/被嘲讽/被踩
2. 获得金手指：系统/异能/传承
3. 快速成长：一个月内脱胎换骨
4. 再次相遇：前任震惊/想复合
5. 霸气拒绝：打脸时刻

【核心爽点】
- 前任后悔
- 新欢更美
- 实力打脸
- 身份反转
```

## 二、女频主角模板

### 2.1 大女主模板

```
【基础设定】
姓名：有辨识度
年龄：20-28岁
外貌：非传统美女→独具气质
性格：独立、自主、聪明、有底线

【核心特质】
- 经济独立：不依附男人
- 精神独立：有主见不盲从
- 感情拎得清：拿得起放得下
- 有智商有情商
- 关键时刻不掉链子

【事业线】
- 起点：基层/困境
- 发展：通过能力/努力上升
- 危机：被排挤/被陷害
- 突破：证明自己/上位

【感情线】
- 初期：不相信爱情/受过情伤
- 中期：被男主的真诚打动
- 后期：相互扶持、共同成长
- 底线：不被爱情绑架自我

【高光时刻设计】
- 每20章至少一个能力展示
- 每30章一个关键抉择
- 每50章一个事业突破
```

### 2.2 甜宠文女主模板

```
【基础设定】
姓名：可爱/软萌/有特色
年龄：20-25岁
外貌：清纯可爱/小家碧玉
性格：软萌但有底线/可爱但不傻

【核心特质】
- 软萌可爱：撒娇/呆萌
- 但不傻白甜：有判断力
- 依赖但卑微：信任男主但不失去自我
- 善良有底线：会帮助人但不被欺负

【萌点设计】
- 反应呆萌
- 语言可爱
- 行为反差
- 专属小动作

【与男主互动】
- 日常：撒娇求抱抱
- 危机：躲进男主怀抱
- 甜蜜：脸红心跳
- 偶尔反击：展现傲娇一面
```

### 2.3 重生女主模板

```
【基础设定】
前世：悲惨结局/被辜负
今生：带着记忆归来
目标：复仇+改写命运

【前世记忆运用】
- 知道谁是真敌人
- 知道谁是真心人
- 知道未来走向
- 知道隐藏秘密

【今生改变】
- 避开前世坑
- 利用信息差反击
- 珍惜前世错过的人
- 活出不一样的人生

【性格变化】
- 前世：单纯/善良/软弱
- 今生：智慧/果断/有锋芒
```

## 三、男主/男配模板

### 3.1 霸道总裁型

```
【基础设定】
- 年龄：25-35岁
- 外貌：冷酷俊美/气场强大
- 身份：总裁/总裁家族继承人

【性格特征】
- 对外人：冷酷/霸道/强势
- 对女主：宠溺/温柔/例外
- 原则性强：认定的就不放手
- 占有欲强：我的女人别人碰不得

【常见设定】
- 童年阴影：父母不和/被伤害
- 遇见女主后改变：从冰山到融化
- 追妻火葬场：误会后追妻

【标签】
#高冷 #霸道 #占有欲强 #宠妻狂魔 #禁欲系
```

### 3.2 温柔守护型

```
【基础设定】
- 年龄：24-30岁
- 外貌：温润如玉/邻家哥哥
- 身份：竹马/医生/老师/邻居

【性格特征】
- 温柔体贴：照顾女主无微不至
- 默默守护：不求回报
- 包容大度：接纳女主的全部
- 偶尔吃醋：但不会强迫

【常见设定】
- 青梅竹马：从小喜欢女主
- 等待多年：终于等到女主回头
- 无条件支持：女主做什么都支持

【标签】
#温柔 #暖男 #守护 #深情 #治愈
```

### 3.3 病娇反派型

```
【基础设定】
- 年龄：22-28岁
- 外貌：病态美/阴郁
- 性格：偏执/占有欲/危险

【性格特征】
- 病态的爱：爱到疯狂
- 偏执：认定了就不放手
- 危险：对他和对别人都危险
- 隐藏：在女主面前装作温柔

【常见设定】
- 童年阴影导致心理扭曲
- 爱上女主后更加疯狂
- 与男主是对立关系

【标签】
#病娇 #偏执 #占有欲 #危险 #病态美
```

## 四、反派模板

### 4.1 男频工具型反派

```
【炮灰反派】
- 实力：不如主角
- 智商：不够用
- 下场：被碾压/打脸
- 功能：衬托主角强大

【中层反派】
- 实力：与主角相当
- 智商：有一定心机
- 下场：激战或艰难取胜
- 功能：制造危机感

【终极大反派】
- 实力：比主角强
- 智商：布局深远
- 背景：势力庞大
- 功能：作为终极目标
```

### 4.2 女频恶毒女配模板

```
【工具型恶毒女配】
- 功能：制造麻烦
- 智商：不在线
- 下场：被打脸/身败名裂
- 标签：恶毒/愚蠢

【有心机型女配】
- 功能：制造误会
- 智商：会伪装/会演戏
- 下场：被揭穿
- 标签：白莲花/绿茶

【身份型女配】
- 功能：身份压制
- 背景：出身高贵/后台硬
- 威胁：利用身份打压女主
- 下场：身份优势被男主压制
```

## 五、配角模板

### 5.1 男频兄弟/队友

```
【兄弟类型】
- 铁杆兄弟：从头到尾跟随
- 临时队友：某个阶段同行
- 亦敌亦友：竞争与合作并存

【必备特质】
- 忠诚
- 互补（一个冲动一个稳重）
- 有自己的成长线
- 在主角需要时出现
```

### 5.2 女频闺蜜/助攻

```
【闺蜜类型】
- 真闺蜜：从头到尾帮忙
- 傻白甜闺蜜：好心办坏事
- 心机闺蜜：背后捅刀（用来虐）

【必备特质】
- 与女主价值观一致
- 有自己的故事线
- 在关键时刻助攻/陪伴
```
