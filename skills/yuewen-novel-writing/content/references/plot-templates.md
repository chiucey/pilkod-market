# 阅文平台小说大纲模板库

## 一、男频玄幻/都市大纲模板

### 模板1：系统流崛起大纲

```
【基本信息】
- 字数目标：300-500万字
- 核心设定：主角获得逆天系统
- 爽点类型：系统任务+奖励+碾压

【主线结构】

第一章：系统觉醒
- 主角处境：社会底层/被欺辱/绝境
- 系统绑定：意外获得系统
- 第一个任务：简单任务获取初始奖励
- 章末钩子：任务有期限，压力感

第1-30章：新手期
- 目标：积累第一桶金
- 副本1：新手村挑战
- 收获：初始技能/资金/队友
- 第一个敌人：衬托主角的炮灰

第31-100章：崛起期
- 目标：在所在城池/学校崭露头角
- 副本2-5：逐步升级的挑战
- 收获：名声/资源/势力雏形
- 中BOSS登场：第一个真正的敌人

第101-200章：扩张期
- 目标：成为区域内顶尖存在
- 副本6-10：更大的舞台
- 收获：地盘/追随者/更强实力
- 大BOSS初现：幕后黑手露出端倪

第201-300章：终极决战
- 目标：击败最终BOSS
- 最终副本：高潮对决
- 结局：成为巅峰/守护一切

【感情线（可选）】
- 女主类型：冷傲女总裁/青梅竹马/红颜知己
- 相识：偶然/任务相关
- 发展：共患难→互相欣赏→确认关系
- 甜蜜点：每20-30章一个关键甜蜜场景
```

### 模板2：都市重生逆袭大纲

```
【基本信息】
- 字数目标：200-400万字
- 核心设定：重生回到过去，利用先知优势
- 爽点类型：信息差碾压+财富积累

【主线结构】

第一章：重生归来
- 重生节点：关键时间点
- 携带记忆：前世记忆/未来走向
- 第一件事：改变命运的关键决策
- 章末钩子：有人已经注意到变化

第1-30章：第一步
- 目标：完成原始资本积累
- 第一桶金：利用信息差获取资源
- 第一个敌人：前世仇人/今世利益冲突
- 感情线萌芽：与前世妻子的重逢/改变命运

第31-100章：布局
- 目标：构建商业帝国雏形
- 领域1-3：多线布局
- 敌人反击：商业竞争/暗中陷害
- 化解危机：展现智慧+人脉

第101-200章：扩张
- 目标：成为行业巨头
- 并购/扩张：吞并对手/建立同盟
- 隐藏敌人：前世幕后黑手
- 最终对决准备：收集证据/积蓄力量

第201-300章：决战与圆满
- 目标：击败终极敌人
- 商战高潮：生死对决
- 收获：财富/地位/爱情
- 结局：商业帝国+圆满家庭

【系统化爽点安排】
- 每次商业成功：+50章一个小高潮
- 每击败一个对手：+20章
- 感情升温：每30章一个甜蜜场景
```

## 二、女频大纲模板

- 目标：在男主身边站稳

- 第一个小高潮：女主展现独特魅力
- 感情萌芽：男主开始在意女主

第31-80章：感情升温期

- 阻碍出现：家族反对/白莲花/前女友

第81-120章：危机与守护

第121-150章：圆满

- 结局：幸福圆满+HE

【高光时刻设计】
- 女主高光：每20章至少一个闪光点
- 宠溺时刻：每10章一个甜蜜互动
- 打脸时刻：每个阻碍出现后反击

## 三、各类型核心冲突设计

### 男频冲突模板

```
【生存型冲突】
主角面临生死威胁，必须解决才能活命：
1. 被追杀→反杀/逃脱
2. 中毒/诅咒→寻找解药/破解方法
3. 资源枯竭→寻找新资源/抢夺
4. 天赋不足→后天弥补/另辟蹊径

【成长型冲突】
主角需要突破才能更强：
1. 境界瓶颈→奇遇/顿悟/资源
2. 功法缺陷→获得更强功法
3. 战斗经验不足→实战锻炼/高手指点
4. 心魔/心结→克服心理障碍

【利益型冲突】
围绕利益展开的对抗：
1. 资源争夺→宝物/地盘/传承
2. 地位挑战→挑战权威/取代
3. 门派恩怨→前世仇恨/门派对立
4. 商业竞争→市场份额/核心技术
```

### 女频冲突模板

```
【情感型冲突】
围绕感情展开的纠葛：
1. 误会型：男主误解女主
2. 阻挠型：家族/身份阻碍
3. 三角型：情敌介入
4. 背叛型：被爱人/亲人伤害

【生存型冲突】
女主需要自我保护：
1. 家族倾轧：嫡庶之争/遗产争夺
2. 后宅阴谋：姨娘/嫂嫂陷害
3. 职场危机：同事排挤/上司刁难

【成长型冲突】
女主实现自我价值：
1. 事业瓶颈：项目失败/资金链断裂
2. 能力质疑：被低估/被看不起
3. 选择两难：爱情vs事业/家人vs爱人
4. 自我怀疑：迷失方向→找回初心
```

## 四、大纲检查清单

完成大纲后自检：

- [ ] 主线目标是否清晰？
- [ ] 每个阶段的敌人是否明确？
- [ ] 爽点/甜点是否均匀分布？
- [ ] 是否有足够的冲突起伏？
- [ ] 伏笔是否埋下？回收点是否规划？
- [ ] 章节数与字数是否匹配目标？
- [ ] 结局是否圆满/有期待感？

## 五、常见问题解决

### Q：写到一半偏离大纲怎么办？
A：
- 大纲是方向，不是枷锁
- 如果偏离后故事更好，可以调整大纲
- 记录偏离原因，评估是否需要修正

### Q：大纲太详细会不会限制创作？
A：
- 大纲只写骨架，细节留给正文
- 保留20%的灵活空间
- 在关键节点（大高潮、大转折）必须按大纲走

### Q：卡文怎么办？
A：
- 回看大纲，找下一个爽点/冲突
- 从主角最想要的和最大的阻碍出发
- 快速推进剧情，跳过铺垫直接进入冲突
