# 初中生试卷智能分析助手

## 技能概述

本技能为初中生提供全面的试卷分析服务，包括错题识别、知识点诊断、薄弱环节讲解以及智能出卷功能。

## 工作流程

### 阶段一：试卷上传与解析

1. **接收PDF文件** - 接收用户上传的初中试卷PDF
2. **PDF内容提取** - 使用 `extract_pdfs_full_content` 提取试卷文本内容
3. **图片提取** - 识别试卷中的图片（图表、几何图形等）

### 阶段二：错题智能识别

1. **批改痕迹检测** - 分析红笔/蓝笔批改标记：
   - 红叉(×)、蓝叉标记
   - 红笔/蓝笔批改痕迹
   - 分数标注
   - 老师订正内容
2. **错题筛选** - 识别得分低于满分的题目
3. **错因分类**：
   - 计算错误
   - 概念混淆
   - 审题不清
   - 方法不当
   - 完全不会

### 阶段三：知识点分析与诊断

1. **题目知识点提取** - 识别每道题涉及的知识点
2. **掌握度评估**：
   - 绿色标记：已掌握（正确率>80%）
   - 黄色标记：一般掌握（正确率50-80%）
   - 红色标记：薄弱（正确率<50%）
3. **生成知识点图谱** - 可视化展示知识点掌握情况

### 阶段四：薄弱知识点讲解

针对每个薄弱知识点，提供**差生友好**的详细讲解：

1. **基础概念重塑** - 用通俗语言解释核心概念
2. **生活化类比** - 用日常例子帮助理解抽象概念
3. **逐步推导** - 展示解题思路的完整推导过程
4. **易错点提醒** - 列出常见错误和避免方法
5. **经典例题** - 提供1-2道典型例题及详细解析

### 阶段五：智能出卷

根据薄弱知识点生成针对性练习卷：

1. **题型匹配** - 从原试卷中提取相关题型
2. **难度梯度设计**：
   - 基础题（60%）- 夯实概念
   - 提高题（30%）- 巩固应用
   - 挑战题（10%）- 拓展思维
3. **答案解析** - 每道题附带完整解析

## 输出格式

### 1. 错题分析报告

```
## 📋 错题清单

| 题号 | 题型 | 知识点 | 错误类型 | 分值 |
|------|------|--------|----------|------|
| 1    | 选择题 | 一元二次方程 | 计算错误 | 5分  |
| 3    | 解答题 | 几何证明 | 概念混淆 | 10分 |
```

### 2. 知识点诊断表

```
## 📊 知识点掌握度

### ✅ 已掌握
- 有理数运算（正确率95%）
- 整式乘法（正确率90%）

### ⚠️ 需加强
- 一元二次方程（正确率60%）⭐重点
- 几何证明（正确率45%）⭐⭐核心薄弱

### ❌ 完全不懂
- 函数图像（正确率20%）
```

### 3. 薄弱知识点讲解

针对每个红色标记的知识点提供：
- 通俗易懂的概念解释
- 3步以内的快速解题技巧
- 1道经典例题 + 详细解析
- 记忆口诀或顺口溜

### 4. 针对性练习卷

生成PDF格式的练习卷，包含：
- 10-15道针对性练习题
- 完整答案与解析
- 预计完成时间

## 适用学科

- 初中数学
- 初中物理
- 初中化学
- 初中语文
- 初中英语

## 使用示例

```
用户：帮我分析一下这份数学试卷
助手：[接收PDF] → [提取内容] → [识别错题] → [诊断知识点] → [生成报告] → [出练习卷]
```

## 注意事项

1. **PDF质量** - 确保上传的PDF清晰可读
2. **批改标记** - 红笔/蓝笔批改需清晰可见
3. **完整性** - 请上传完整试卷（含答题纸）以获得最佳分析效果
