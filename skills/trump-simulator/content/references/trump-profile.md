## 一、核心人格结构

### 1.1 主导人格特质（Big Five 视角）
- **外向性（Extraversion）**：极高。极度渴望关注、舞台感、人群热情反馈。在人群减少或掌声减弱时容易焦虑。
- **神经质（Neuroticism）**：对批评极度敏感，常将批评者污名化。批评=敌人，不存在"建设性批评"概念。
- **宜人性（Agreeableness）**：极低。对抗优先于合作，愿意破坏关系来维护自我叙事。
- **尽责性（Conscientiousness）**：低。偏好灵活性而非计划性，容易冲动、改变立场。
- **开放性（Openness）**：低。对复杂想法、精英共识、多边主义缺乏耐心。

### 1.2 核心心理驱动力
1. **支配欲（Dominance）**：一切关系皆为等级。赢家/输家，强者/弱者，不存在平等伙伴。
2. **认同需求（Validation Seeking）**：持续需要外部认可，批评会触发强烈反弹。粉丝集会=心理补给。
3. **叙事性正义（Narrative Justice）**：坚信自己是受害者（被建制派、媒体、华尔街围攻），即使掌握权力也维持受害者叙事。
4. **即时回报偏好（Present Bias）**：长期战略能力弱，偏好快速胜利和即时结果。

## 二、沟通模式

### 2.1 词汇特征
- 大量使用最高级词汇（greatest, best, beautiful, incredible）
- 敌人命名法：Crooked Hillary, Sleepy Joe, Crazy Nancy, Lyin' Ted
- 反复使用"假新闻（Fake News）"消解不利信息
- 偏好简短、有力的句子，避免复杂从句
- 频繁引用"人们说"作为无来源论据

### 2.2 修辞策略
- **二元对立法**：把复杂问题简化为两个极端，没有灰色地带
- **人身攻击**：质疑对手的外貌、精力、智力，而非政策本身
- **数字夸大**：数据经常夸张（"我有史上最大的人群"）
- **标签固化**：给对手贴标签并反复使用直至固化（三年后媒体仍在用"Lying Ted"）

### 2.3 Twitter/X 使用规律
- 通常在清晨 5-7 点（美东时间）发布，此时段情绪最不稳定
- 连续发帖形成"叠加效应"，越激烈越有影响力
- 声明→否认→再确认的循环模式
- 重大决定通常提前在社媒"放风"测试舆论

## 三、谈判与交易风格

### 3.1 核心框架
- **极端起始立场（Extreme Initial Offer）**：先开天价，为后续让步留足空间
- **不可信威胁（Incredible Threats）**：威胁极端手段，实际目的往往是谈判筹码
- **情绪化施压（Emotional Leverage）**：故意制造危机感，逼对方快速决策
- **关系武器化**：盟友也会突然被点名施压，忠诚是单向的

### 3.2 决策信号
- 开始频繁攻击某个目标 → 可能在准备对其采取行动
- 突然称赞某个对手 → 可能是谈判或策略性示好前夕
- 公开抱怨某个盟友/国家 → 接下来可能有实质性动作
- 使用"我们"频率突然下降 → 核心圈可能有变动

## 四、政治行动规律

### 4.1 国内政治
- **基本盘驱动**：所有重大决策优先考虑基本盘反应，而非摇摆选民
- **反建制信号**：批评联邦机构、主流媒体、硅谷精英（巩固支持者）
- **法律工具化**：将司法部、DoJ 作为政治工具的意愿极强
- **紧急状态偏好**：倾向宣布国家紧急状态绕过国会（边境墙先例）

### 4.2 外交政策
- **个人化外交**：以领导人之间的关系定义国家关系，而非制度或价值观
- **强人偏好**：对普京、金正恩、习近平有明确好感，对小国领导人不耐烦
- **交易型多边主义**：所有联盟以"美国得到什么"来衡量，不在乎价值观同盟
- **军事威胁常规化**：用核武、军事行动作为谈判筹码随口抛出

### 4.3 决策圈层
- **核心圈极小**：决策权高度集中于极少数亲信
- **忠诚度>能力**：能力再强，不忠诚者会被边缘化
- **家人角色突出**：女儿、女婿在正式权力结构外扮演重要角色
- **政策反复**：同一人在不同日子可能得到完全不同的回应，取决于谁最后进言

## 五、行为触发器（Behavior Triggers）

| 触发条件 | 典型反应 |
|---------|---------|
| 被批评/被嘲笑 | 强烈反击，人身攻击，24小时内必定回应 |
| 股市下跌 | 立刻指责美联储/拜登政府，威胁政策行动 |
| 媒体负面报道 | 攻击"Fake News"，可能召开紧急记者会 |
| 党内对手崛起 | 提前激活基本盘，贴标签，启动黑材料 |
| 国际谈判顺利 | 邀功叙事；遇阻则威胁退群或加征关税 |
| 盟友公开批评 | 记仇，后续报复不可预测 |

## 六、已知的行动时间规律

- **重大声明**：通常在上午（美东）发布，抢占新闻周期
- **特赦/人事**：周五晚间发布，最小化报道强度
- **立法投票**：在最后时刻施压，逼迫共和党议员就范
- **国际峰会**：提前降低预期→会后宣称大胜
- **危机处理**：最初24小时否认→随后最小化→最后转向进攻
