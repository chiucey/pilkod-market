# 养生茶电商详情图生成 - 使用指南

## 快速开始

### 1. 触发技能
当用户提供养生茶产品图片或要求生成电商详情图时，此技能将被自动调用。

### 2. 必要信息收集
生成前需确认以下信息：

| 信息项 | 说明 | 优先级 |
|--------|------|--------|
| 产品图片 | 参考用，确保产品一致性 | **必须** |
| 产品名称 | 如"玫瑰枸杞茶" | **必须** |
| 产品类型 | 花草茶/草本类/温补类 | 推荐 |
| 主要原料 | 配料表 | 推荐 |
| 目标汤色 | 预期冲泡后颜色 | 可选 |

### 3. 执行生成
按以下顺序生成10张图片：

1. 首屏视觉主海报
2. 痛点共鸣场景图
3. 产品主体全景展示
4. 核心原料特写板块
5. 核心卖点解析板块
6. 茶汤质感对比展示
7. 冲泡步骤教程示意图
8. 适宜人群与饮用场景
9. 产品信息详情说明区
10. 最终转化逼单氛围图

## 常见问题解决

### Q1: 用户只提供了图片，没有其他信息
**解决方案**：
1. 使用图像理解工具分析产品外观、包装、颜色
2. 识别包装上的产品名称和配料表
3. 根据外观特征判断产品类型和色调
4. 补充缺失信息后执行生成

### Q2: 如何保证生成产品与原图一致
**关键要点**：
- 始终以用户提供的原图作为唯一参考
- 严格按照产品外观、颜色、包装复制
- 不添加、不替换任何产品元素
- 如需创意延伸，明确告知用户

### Q3: 色调如何自动适配
**映射规则**：

```
产品特征 → 推荐色调 → 示例文案色调标注

花瓣类原料（玫瑰、茉莉） → 浅粉柔紫奶白 → [浅粉#F5E6E8、柔紫#E8E0F0]
草本类原料（菊花、薄荷） → 浅绿淡青米白 → [浅绿#E8F5E9、淡青#E0F2F1]
滋补类原料（红枣、枸杞） → 暖黄浅橙杏色 → [暖黄#FFF8E1、浅橙#FFE0B2]
```

### Q4: 输出格式和尺寸
**统一规格**：
- 分辨率：1080 × 1440
- 比例：3:4 竖屏
- 格式：PNG/JPG
- 画质：8K 超高清晰度

## 提示词替换规则

### 占位符列表

| 占位符 | 替换内容 | 示例 |
|--------|----------|------|
| `[产品名称]` | 具体产品名 | "玫瑰桂圆红枣茶" |
| `[养生功效]` | 一句话功效描述 | "补气养血 焕颜靓肤" |
| `[具体痛点]` | 目标用户痛点 | "熬夜暗沉、气色不佳" |
| `[共鸣文案]` | 情感共鸣文字 | "给忙碌的自己一份温柔" |
| `[汤色描述]` | 冲泡后汤色 | "淡琥珀色透明" |
| `[主色调]` | 根据类型选择 | "浅粉色系" |
| `[原料列表]` | 所有配料 | "重瓣红玫瑰、黑枸杞..." |
| `[具体配料]` | 完整配料表 | "重瓣红玫瑰、枸杞、红枣..." |

## 输出检查清单

生成完成后，按以下标准检查：

- [ ] 产品外观与原图高度一致
- [ ] 色调符合产品类型
- [ ] 所有文字清晰无错误
- [ ] 无水印、无杂乱背景
- [ ] 画面整体高级治愈
- [ ] 10个模块完整覆盖
- [ ] 可直接用于电商上架

## 批量生成模式

当用户需要一次性生成整套详情图时：

1. **并行生成**：10个模块可同时启动生成任务
2. **统一命名**：
   ```
   [产品名]_01_首屏主图.png
   [产品名]_02_痛点共鸣.png
   [产品名]_03_产品展示.png
   [产品名]_04_原料特写.png
   [产品名]_05_卖点解析.png
   [产品名]_06_茶汤对比.png
   [产品名]_07_冲泡教程.png
   [产品名]_08_人群场景.png
   [产品名]_09_信息详情.png
   [产品名]_10_转化逼单.png
   ```
3. **最终合集**：打包提供完整图片包
