# 小天电力现货交易策略

基于"以天气定形状、以近期定价格、盘中做比较"的核心逻辑，提供电力现货交易决策支持。

## 策略核心框架

### 1. 天气相似日选定
- 选定标的日，使用天气相似日功能
- 在历史数据中寻找与标的日天气预报最接近的日期
- 将该日确定为天气相似日
- 提取该日的实际48点负荷曲线作为基准负荷形状

### 2. 量级过滤与匹配
- 在标的日前一个月时间窗口内筛选
- 逐日计算每日48点负荷曲线与基准形状的相似度
- **关键过滤条件**：总负荷量级必须与近期负荷水平处于同一量级
- 剔除负荷体量明显偏低或偏高的日期

### 3. 价格参考带构建
- 将筛选出的负荷形状相似日的48点日前出清价格按同一时点对齐
- 构建价格参考带（高位线 + 正常区间 + 低位线）
- 作为盘中交易的比较基准

### 4. 盘中实时决策
在滚动撮合交易时段，逐时段监测场上盘口价格：

| 实时价格 | 市场信号 | 交易考量 |
|---------|---------|---------|
| 明显低于参考带低位 | 低估 | 触发买入考量 |
| 处于正常区间内 | 正常 | 维持观望 |
| 明显高于参考带高位 | 高估 | 触发卖出考量 |

## 策略要点

1. **不直接使用历史价格**：历史时点过远，市场环境已发生显著变化
2. **量级匹配优先**：形状相似但量级不匹配的日期应予剔除
3. **近期价格参考**：在标的日前一个月内寻找匹配的近期日期
4. **实时动态调整**：根据盘口变化灵活调整交易决策

## 适用场景

- D-1 日前市场报价决策
- 滚动撮合交易时段实时参考
- 负荷曲线预测与形状匹配
- 价格区间判断与异常检测
