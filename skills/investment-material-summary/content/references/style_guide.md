# 报告排版规范（参考样式：专业研报风）

> 本规范定义 investment-material-summary skill 输出报告时的视觉样式，旨在贴近专业金融研报的排版风格。

## 一、设计原则

1. **可读性优先**：层级清晰、留白充足、长段落必须拆分为项目符号
2. **颜色克制**：仅用一种主色（深蓝 `#1F4E79` 或类似）做标题和强调，正文保持黑色
3. **结构外显**：通过中文序号 + 阿拉伯数字小节号形成清晰的"章·节·点"三层
4. **项目符号优先于段落**：除报告说明、免责声明外，正文内容尽量用 `•` 项目符号呈现

## 二、标题层级与样式

| 级别 | 用法 | 字号 | 颜色 | 加粗 | 编号方式 |
|---|---|---|---|---|---|
| 一级标题（章） | 报告标题 | 22pt | 黑色 | ✓ | 居中 |
| 二级标题（章） | 一、核心总结 | 18pt | 深蓝 | ✓ | 中文数字 |
| 三级标题（节） | 2.1 宏观与政策 | 14pt | 深蓝 | ✓ | 阿拉伯数字.阿拉伯数字 |
| 四级标题（小节） | 美联储与货币政策 | 12pt | 深蓝 | ✓ | 无序号 |
| 正文 | - | 11pt | 黑色 | - | - |
| 项目符号 | - | 11pt | 黑色 | - | • |

**主色推荐**：`#1F4E79`（深蓝，类似截图）或 `#2E5894`

## 三、正文写作规范

### 3.1 项目符号优先
将连续叙述拆分为项目符号。例如：

❌ 不推荐（大段落）：
> 美联储几乎绕不开扩表。理由有三：第一是 ESLR 放松监管后若金融机构仍不增持中长期美债，美联储别无选择只能扩表。第二是美国财政部对短债持有人需支付高额利息，若美联储不扩表则财政付息压力极大。第三是战争爆发后扩表目的从单纯"给财政部兜底"扩展到同时"给战争部兜底"。

✅ 推荐（项目符号）：
> **美联储与货币政策**
> - **扩表几乎不可避免**：ESLR 放松监管后若金融机构仍不增持中长期美债，美联储别无选择只能扩表
> - **付息压力倒逼**：美国财政部对短债持有人需支付高额利息，若美联储不扩表则财政付息压力极大
> - **新增兜底对象**：战争爆发后扩表目的从单纯"给财政部兜底"扩展到同时"给战争部兜底"

### 3.2 项目符号格式
- 每条项目符号尽量遵循"**关键词**：说明"的格式（关键词加粗）
- 单条内容不超过 2-3 行（约 60-90 个汉字）
- 同一层级的项目符号风格保持一致

### 3.3 关键数据呈现
- 关键位、关键百分比、关键日期使用**加粗**
- 多个数据并列时优先用表格而非项目符号

## 四、表格样式

- **表头**：浅蓝色背景（`#D9E2F3`），黑色加粗字体
- **正文行**：白色背景，黑色字体
- **边框**：浅灰色（`#BFBFBF`）单线
- **对齐**：表头居中，数字右对齐，文字左对齐
- **表格用途**：
  - 关键位汇总
  - 引用对照
  - 概念对比
  - 多维比较

## 五、特殊元素

### 5.1 引用块（`>`）
- 仅用于：报告说明、内容声明、《延伸思考》开头的免责声明、关键警告
- 浅灰色背景或左侧色条

### 5.2 强调
- **加粗**：用于关键词、关键数据、关键判断
- *斜体*：用于专业术语、英文术语
- 避免使用下划线或彩色文字（除标题外）

### 5.3 警告 ⚠️
- 仅在《延伸思考》章节开头使用
- 提示"非原材料内容、不构成投资建议"

## 六、页眉页脚

- **页眉**：可放报告标题（小字号，灰色）
- **页脚**：页码居中，"X / Y"格式

## 七、字体选择（PDF 生成时）

- **中文**：Noto Sans CJK SC / Source Han Sans SC / 思源黑体（开源、PDF 兼容好）
- **英文/数字**：与中文字体匹配的西文字重，避免 Times New Roman 与中文搭配
- **代码/等宽**：Source Code Pro / Consolas

## 八、PDF 生成路径推荐

针对中文 PDF 渲染，按可靠性排序：

1. **Markdown → docx (pandoc + 自定义 reference docx) → PDF (LibreOffice)**：最稳定，样式可控
2. **Markdown → HTML (自定义 CSS) → PDF (weasyprint)**：样式最灵活，但中文字体需要确保安装
3. **直接 reportlab**：中文字体处理麻烦，不推荐用于含中文的长报告

## 九、视觉自检清单

报告生成完成后核查：

- [ ] 二级标题（章）用深蓝色，醒目可识别
- [ ] 三级标题（小节）用深蓝色，与正文有明显区分
- [ ] 正文以项目符号为主，无超过 5 行的连续段落
- [ ] 关键数据已加粗
- [ ] 表格表头有浅蓝背景，边框清晰
- [ ] 整体留白舒适，不拥挤
- [ ] 中文渲染无乱码、无方框
