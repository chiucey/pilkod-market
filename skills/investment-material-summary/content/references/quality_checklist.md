# 报告交付前自检清单

在把报告交给用户之前，按以下清单逐项核查。任何一项未通过，需修改后再交付。

## A. 忠实性核查（最重要）

- [ ] 主体四章（市场分析、交易策略、风险管理、核心总结）中**没有**任何原材料未提及的具体数据、人名、机构名、产品名
- [ ] 主体四章中**没有**"我认为""建议""推荐""应该买/卖"等主观表述
- [ ] 报告中所有具体数字（百分比、金额、年份、参数值）都能在原材料中找到对应原文
- [ ] 引用观点时使用了明确的归属（"原材料指出"、"作者认为"、"讲师强调"等）
- [ ] 没有把通用知识当作原材料观点写入主体

## B. 结构完整性核查

- [ ] 报告开头有「报告说明」，包括来源、日期、内容声明三项
- [ ] 包含完整的五大章节（核心总结、市场分析、交易策略、风险管理、延伸思考）
- [ ] 《延伸思考》开头有醒目的免责声明（带 ⚠️ 标记）
- [ ] 章节标题层级清晰，子节编号正确

## C. 缺失处理核查

- [ ] 原材料未涉及的子节，明确标注"原材料未涉及"或"原材料对此论述较少"，**不是**用通用知识填充
- [ ] 原材料中的明显错误（如转录错别字）已用 "[原文如此，疑为 XX]" 标注，未自行替换

## D. 语言与风格核查

- [ ] 全文为中文（专业英文术语可保留并附中文注释）
- [ ] 语气客观中立，没有营销性、夸张性、煽动性词汇
- [ ] 没有使用"绝对""一定""稳赚""暴富"等极端表述
- [ ] 涉及具体投资品/策略时，未替原作者背书

## E. 延伸思考边界核查

- [ ] 《延伸思考》中的内容**不**与主体四章重复（避免读者把延伸内容误当作原材料观点）
- [ ] 《延伸思考》的每一个子节都基于原材料展开（而非凭空发挥）
- [ ] 《延伸思考》中没有具体的投资推荐

## F. 格式与可读性核查

- [ ] 数字、百分比格式统一（如统一为 "12.5%" 而非 "12.5 %"）
- [ ] 长段落已拆分，关键要点已加粗或分点
- [ ] 表格、列表使用恰当
- [ ] 输出格式（PDF/Word/MD）与用户需求一致

## G. 交付确认

- [ ] 已使用 `present_files` 工具呈现文件
- [ ] 简要告知用户报告结构与忠实性原则（一两句话即可，不啰嗦）

---

## 自检失败的常见情形

1. **"补全"冲动**：看到原材料对某模块涉及很少时，忍不住用通用投资知识填充。**必须忍住**，明确标注"未涉及"。
2. **观点混淆**：把自己的经验当作原材料观点写出来。**必须**用归属表述区分。
3. **过度解读**：原材料只说"控制仓位很重要"，报告写成"建议单只标的不超过 5%"。**禁止**这种具体化加工。
4. **延伸越界**：《延伸思考》变成了独立的投资建议书，与原材料无关。延伸必须**基于**原材料展开。
