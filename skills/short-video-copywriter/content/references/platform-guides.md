# 平台运营指南

## 抖音平台规范

### 内容规范

| 类型 | 要求 |
|------|------|
| 标题长度 | 15-30字 |
| 视频时长 | 15秒-3分钟（完播率关键） |
| 封面图 | 清晰、高对比、有文字 |
| 标签数量 | 1-3个相关话题 |

### 爆款文案结构

```
【开头3秒钩子】
{冲突/悬念/数字} + {情绪触发}
示例："月薪3000和30000的人，区别就在这3点"

【中间内容】
{问题} → {分析} → {解决方案}
保持节奏，每15秒一个小高潮

【结尾引导】
{总结} + {互动指令}
示例："觉得有用的扣1，下期教你怎么面试"
```

### 推荐话题标签

```
#抖音小助手 #dou+ #热门 #抖in
#生活小妙招 #职场干货 #种草 #好物推荐
```

### 敏感词/限制词

⚠️ 绝对化用语：最好、第一、顶级、极品、唯一、绝对
⚠️ 医疗功效：治疗、治愈、根治、药用
⚠️ 虚假承诺：100%有效、无效退款（需谨慎）
⚠️ 违禁词：可参考抖音官方违禁词列表

## 小红书平台规范

### 内容规范

| 类型 | 要求 |
|------|------|
| 笔记标题 | 含emoji，20字以内，有关键词 |
| 正文字数 | 300-1000字（太短没权重） |
| 图片数量 | 3-9张（封面+内容+结尾） |
| 标签数量 | 3-10个高热话题 |

### 爆款笔记结构

```
【封面图】
高颜值/高信息量/有对比
文字标题要醒目

【标题公式】
情绪词 + {数字} + {产品/主题} + {效果}
示例："绝了！这面膜用完皮肤嫩到发光✨"

【正文结构】
1. 场景引入（引发共鸣）
2. 产品介绍（多维度展示）
3. 使用感受（真实体验）
4. 优缺点分析（增加可信度）
5. 总结推荐（明确目标人群）

【结尾引导】
- 评论区互动
- 收藏点赞引导
- 相关话题提及
```

### 推荐话题标签

```
#小红书助手 #小红书运营 #笔记灵感
#种草 #好物分享 #护肤 #穿搭 #美食
#测评 #避坑 #攻略 #干货
```

## 微信公众号平台规范

### 内容规范

| 类型 | 要求 |
|------|------|
| 文章标题 | 引发好奇或共鸣，30字以内 |
| 正文段落 | 简短有力，适当留白 |
| 配图 | 清晰、有版权、相关性强 |
| 引导关注 | 文末必须有 |

### 爆款文章结构

```
【标题】
公式1：数字 + 悬念
    "99%的人都不知道的X个秘密"
公式2：痛点 + 利益
    "告别X，迎接Y的N个方法"
公式3：热点 + 观点
    "从X事件看Y现象的本质"

【开头】
痛点共鸣 → 引入话题
"你是不是也经常..."

【正文】
分点论述，每点有小标题
案例+观点+分析

【结尾】
总结升华 → 引导行动
"如果觉得有用，点个在看"
```

### 引导关注模板

```
---
长按识别二维码关注
第一时间收到我们的推送

点击下方「在看」
把文章分享给更多人

往期推荐：
{历史文章链接}
```
