# 文案评分标准

## 综合评分体系

### 评分维度

| 维度 | 权重 | 说明 |
|------|------|------|
| 结构完整度 | 25% | 文案框架是否完整合理 |
| 爆款潜力 | 25% | 是否具备传播爆点 |
| 转化能力 | 25% | 是否能推动用户行动 |
| 平台适配度 | 15% | 是否符合平台规范 |
| 合规安全度 | 10% | 是否规避违规风险 |

---

## 1. 结构完整度 (25分)

### 评分标准

| 等级 | 分数 | 标准 |
|------|------|------|
| 优秀 | 21-25 | 开头有钩子，正文有逻辑，结尾有引导，结构完整 |
| 良好 | 16-20 | 有开头结尾，部分结构完整，逻辑较清晰 |
| 一般 | 11-15 | 结构松散，缺少部分环节 |
| 较差 | 0-10 | 缺乏基本结构，杂乱无章 |

### 结构检查项

- [ ] 是否有吸引人的开头（钩子）
- [ ] 是否有清晰的信息传递
- [ ] 是否有逻辑递进或并列
- [ ] 是否有有力的结尾
- [ ] 是否有明确的行动引导

---

## 2. 爆款潜力 (25分)

### 评分标准

| 等级 | 分数 | 标准 |
|------|------|------|
| 优秀 | 21-25 | 多处爆款元素，具备病毒传播潜力 |
| 良好 | 16-20 | 有1-2个明显爆款元素 |
| 一般 | 11-15 | 爆款元素不明显 |
| 较差 | 0-10 | 平平无奇，缺乏传播点 |

### 爆款元素清单

- [ ] 数字/数据引用（增加可信度）
- [ ] 悬念/冲突设置（引发好奇）
- [ ] 情绪共鸣点（引发讨论）
- [ ] 反差/对比（增强记忆）
- [ ] 热点关联（借势流量）
- [ ] 金句/梗（便于传播）
- [ ] 身份标签（精准触达）

---

## 3. 转化能力 (25分)

### 评分标准

| 等级 | 分数 | 标准 |
|------|------|------|
| 优秀 | 21-25 | 强有力CTA，有效引导转化 |
| 良好 | 16-20 | 有CTA，转化引导较有效 |
| 一般 | 11-15 | CTA弱或缺失 |
| 较差 | 0-10 | 无转化意识 |

### 转化要素检查

- [ ] 痛点是否精准
- [ ] 卖点是否清晰
- [ ] 价值是否可感知
- [ ] 价格锚点是否合理
- [ ] 紧迫感是否到位
- [ ] 信任背书是否充分
- [ ] CTA是否明确有力

---

## 4. 平台适配度 (15分)

### 评分标准

| 等级 | 分数 | 标准 |
|------|------|------|
| 优秀 | 13-15 | 完全符合平台风格和规范 |
| 良好 | 10-12 | 基本符合，有小调整空间 |
| 一般 | 6-9 | 部分不符合平台特点 |
| 较差 | 0-5 | 完全不适合该平台 |

### 平台适配检查项

**抖音：**
- [ ] 标题有悬念/情绪/数字
- [ ] 开头3秒有钩子
- [ ] 节奏紧凑不拖沓
- [ ] 标签选择准确

**小红书：**
- [ ] 标题含emoji
- [ ] 有"避坑/攻略/测评"等关键词
- [ ] 内容真实有细节
- [ ] 标签数量适中（3-10个）

**微信公众号：**
- [ ] 标题引发好奇或共鸣
- [ ] 段落简洁有留白
- [ ] 有分点论述
- [ ] 文末有引导

---

## 5. 合规安全度 (10分)

### 评分标准

| 等级 | 分数 | 标准 |
|------|------|------|
| 安全 | 10 | 无任何违规风险 |
| 基本安全 | 7-9 | 有轻微风险但可控 |
| 存在风险 | 4-6 | 有明显违规风险 |
| 危险 | 0-3 | 严重违规，需立即修改 |

### 合规检查清单

⚠️ 绝对禁止：
- [ ] 无绝对化用语（最好、第一、顶级）
- [ ] 无虚假功效宣称
- [ ] 无医疗/药品功效承诺
- [ ] 无金融收益承诺
- [ ] 无侵犯知识产权内容

⚠️ 需要谨慎：
- [ ] 价格对比属实
- [ ] 数据来源可靠
- [ ] 竞品评价客观
- [ ] 名人使用有授权

---

## 综合评分计算

```
综合评分 = 结构完整度×0.25 + 爆款潜力×0.25 + 转化能力×0.25 + 平台适配度×0.15 + 合规安全度×0.10
```

### 评分结果解读

| 分数 | 等级 | 建议 |
|------|------|------|
| 90-100 | S级 | 精品文案，可直接使用 |
| 75-89 | A级 | 优秀，稍作优化即可 |
| 60-74 | B级 | 合格，需要针对性优化 |
| 45-59 | C级 | 一般，需大幅改进 |
| 0-44 | D级 | 不合格，建议重写 |
