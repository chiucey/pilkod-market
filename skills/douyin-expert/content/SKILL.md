## 短视频爆款公式

### 黄金3秒钩子（必选一）

| 类型 | 示例 |
|------|------|
| **冲突式** | "千万别买 XXX，除非你先看完这个" |
| **价值式** | "花了 XX 元解决了困扰我3年的问题" |
| **悬念式** | "我发现了 XX 行业不想让你知道的秘密" |
| **共情式** | "有没有人也每次遇到 XXX 就崩溃？" |
| **数字式** | "90% 的人都不知道的 XX 技巧" |
| **身份式** | "作为 XX 年经验的 XX，我要说句公道话" |

### 标准视频结构（30-60秒）

```
┌─────────────────────────────────────────┐
│ 第1-3秒：黄金钩子                        │
│   → 冲突/悬念/价值/共情，选一即可        │
├─────────────────────────────────────────┤
│ 第4-20秒：核心内容                       │
│   → 放大痛点 (2-3秒)                     │
│   → 引出解决方案 (3-5秒)                 │
│   → 使用演示/效果展示 (5-8秒)            │
│   → 关键数据/前后对比 (3-5秒)             │
├─────────────────────────────────────────┤
│ 第21-30秒：收尾+钩子                     │
│   → 一句话价值主张                       │
│   → 互动引导："你觉得值不值？评论区告诉我" │
│   → 系列预告："下期教你 XXX——关注不错过"   │
└─────────────────────────────────────────┘
```

### 完播率优化策略

| 策略 | 说明 |
|------|------|
| **视频时长控制** | 知识类 30-60秒，剧情类 15-30秒，切片类 15秒 |
| **节奏把控** | 每5秒有一个小高潮或转折 |
| **信息前置** | 把最有价值的信息放在前10秒 |
| **悬念留白** | 在结尾前留一个钩子，让用户看完 |
| **字幕引导** | 用字幕提示"最后有彩蛋"等 |

## DOU+ 投放策略

### 人群定向优先级

```
1. 相似达人粉丝（最精准）
   → 选择同赛道头部达人

2. 兴趣标签 + 行为定向
   → 兴趣：内容相关领域
   → 行为：最近30天有互动

3. 基础定向
   → 年龄、性别、地域
   → 仅在大盘测试时使用
```

### DOU+ 投放三阶段

| 阶段 | 目标 | 投放金额 | 人群 |
|------|------|----------|------|
| **测试期** | 找到能爆的内容 | 100-200元/条 | 系统推荐 |
| **放量期** | 追投潜力视频 | 500-1000元/条 | 相似达人 |
| **稳定期** | 维持流量 | 200-500元/天 | 精准人群 |

### 投放判断标准

| 视频数据 | 决策 |
|----------|------|
| 播放 > 5000，完播率 > 40% | 追投 |
| 播放 > 5000，完播率 25-40% | 优化后重投 |
| 播放 < 2000，完播率 < 25% | 放弃，换新内容 |

## 内容矩阵策略

### 账号矩阵结构

```
├── 主账号（品牌/IP）
│   ├── 人设鲜明，内容垂直
│   ├── 承担品牌曝光和转化
│   └── 发布频率：日更或隔日更
│
├── 子账号（细分领域）
│   ├── 聚焦细分人群
│   ├── 承担引流和粉丝沉淀
│   └── 发布频率：日更
│
└── 员工/矩阵号（流量分发）
    ├── 降低主账号风险
    ├── 快速测试内容形式
    └── 发布频率：批量制作，日更多更
```

## 抖音合规红线

⚠️ **绝对禁止**

- 使用绝对化用语："最好"、"第一"、"100%有效"
- 虚假宣传或夸大承诺
- 引导用户去其他平台（会触发限流）
- 食品/药品/化妆品违规宣传

⚠️ **限流风险**

- 搬运他人内容
- 频繁发布相似内容
- 硬广告植入过多
- 视频清晰度低
