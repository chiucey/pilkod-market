# 抖音脚本示例

## 产品种草类脚本

**目标**：推广一款智能保温杯
**时长**：30-45秒
**目标人群**：25-40岁上班族

```markdown
# 智能保温杯带货脚本

## 第1-3秒：黄金钩子（悬念式）
"我花了200块买了个保温杯，老婆骂我败家，结果..."

## 第4-20秒：核心内容
- [痛点] "每天早上倒的热水，到公司就凉了..."
- [方案] "这个杯子，我测试了12个小时，居然还有温度！"
- [演示] [特写杯子温度计显示]
- [数据] "早上8点倒的热水，下午6点打开，还有58度"

## 第21-30秒：收尾引导
- "而且这个杯盖可以直接喝茶，过滤茶渣"
- [互动] "你们平时用什么保温杯？评论区聊聊"
- [引导] "想要同款的点链接，今天直播间专属价"

## 拍摄要求
- 产品特写要清晰
- 温度测试要真实可见
- 话术要口语化，像朋友推荐
```

## 知识科普类脚本

**目标**：分享职场沟通技巧
**时长**：45-60秒

```markdown
# 职场沟通技巧科普脚本

## 第1-3秒：黄金钩子（共情式）
"为什么你说话别人总是不听？问题不在于你说的内容..."

## 第4-45秒：核心内容
- [痛点] "我见过太多人，专业能力很强，但就是不会表达"
- [转折] "其实只需要改变3个词"
- [干货1] "第一，把'但是'改成'同时'——'你说的有道理，同时我觉得..."
- [干货2] "第二，把'你应该'改成'我建议'——显得更尊重"
- [干货3] "第三，把'不行'改成'我再想想其他办法'——给自己留余地"
- [总结] "职场沟通，措辞比内容更重要"

## 第45-60秒：收尾引导
- [金句] "说话的艺术，决定你职场的高度"
- [互动] "学到了吗？评论区打卡说一句你今天的开场白"
- [系列] "关注我，下期教你如何用3句话搞定客户"
```

## 剧情演绎类脚本

**目标**：推广护肤品
**时长**：25-35秒

```markdown
# 护肤品剧情脚本

## 场景：闺蜜聚会

## 第1-5秒（开场冲突）
[闺蜜A对着镜子叹气]
"最近熬夜太多，脸都垮了..."
[闺蜜B凑过来]
"你这皮肤也太差了吧！"

## 第6-20秒（产品植入）
[闺蜜A无奈]
"用了好多产品都没用..."
[闺蜜B神秘一笑]
"你试试这个，我用了两周，室友都说皮肤变好了"
[展示产品]

## 第21-30秒（反差效果）
[一周后，闺蜜A皮肤明显变好]
"天哪，真的有效果！"
"我就说吧，这个牌子真的绝了"

## 第31-35秒（收尾）
[闺蜜A对镜头]
"姐妹们，冲！"
```

---

## 使用提示

1. **钩子必须在前3秒出现**，不要有任何铺垫
2. **产品演示要有冲击力**，让用户看到效果
3. **话术要口语化**，不要像在念广告
4. **结尾必须有引导**，不管是互动还是点击购买
