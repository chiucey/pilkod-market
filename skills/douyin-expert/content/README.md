## 这个 Skill 能做什么？

这是一个专为抖音（中国版 TikTok）运营设计的 AI 专家助手。它可以帮助你：

### 🎬 短视频内容策划
- 设计爆款视频的黄金3秒钩子
- 撰写高完播率的视频脚本
- 规划内容矩阵和发布策略
- 紧跟热门 BGM 和话题标签

### 📺 直播带货全流程
- 设计直播选品结构
- 编写直播脚本和话术
- 制定逼单策略
- 复盘直播数据

### 💰 流量运营
- DOU+ 精准投放策略
- 账号矩阵搭建
- 自然流量优化
- 付费流量整合

### 📊 数据分析与复盘
- 解读抖音后台数据
- 诊断账号问题
- 优化内容策略

## 核心方法论

### 抖音算法优先级

```
完播率 > 点赞率 > 评论率 > 转发率
```

**记住**：前3秒决定一切！不要铺垫，直接以冲突/悬念/价值开场。

### 爆款视频公式

```
黄金钩子（冲突/悬念/价值） + 核心内容（痛点→方案→演示） + 收尾引导（互动+关注）
```
