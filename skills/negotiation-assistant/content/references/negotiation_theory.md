# 谈判经典理论与方法论

## 一、经典谈判模型

### 1. 哈顿矩阵 (Harvard Negotiation Project)

**核心原则**：
- 把人和问题分开
- 聚焦利益而非立场
- 共同创造双赢选项
- 坚持客观标准

**应用场景**：
- 复杂利益冲突
- 需要长期合作关系
- 多方参与谈判

### 2. 原则式谈判 (Principled Negotiation)

**四象限模型**：
```
                    软              硬
                  妥协            对抗
                    │              │
         ┌─────────┴──────────────┴─────────┐
         │                              │
         │    原则式谈判 (最佳选择)      │
         │                              │
         └──────────────────────────────┘
```

**核心判断**：
- 如果有共同利益 → 合作
- 如果有冲突利益 → 坚持客观标准
- 如果对方不合作 → 防御策略

### 3. 谈判轮次模型

```
开局 (SETTLE) → 中局 (NAVIGATE) → 终局 (CLOSE) → 收局 (WRAP)
  │                    │                │              │
  探测意图            交换条件          锁定协议        确认执行
  建立信任            寻找让步           消除分歧        建立跟进
```

## 二、心理学原理应用

### 1. 认知偏差在谈判中的应用

| 偏差类型 | 表现 | 应对策略 |
|---------|------|---------|
| 锚定效应 | 首次数字影响后续判断 | 先发制人设置有利锚点 |
| 损失厌恶 | 对损失的反应大于收益 | 强调"不行动=损失" |
| 确认偏差 | 寻找支持自己观点的信息 | 提供符合对方立场的论据 |
| 权威效应 | 受权威人士影响 | 借助第三方权威 |
| 稀缺效应 | 稀缺物品更被重视 | 制造紧迫感和稀缺性 |

### 2. 情绪管理

**对方情绪激动时**：
```
1. 暂停：不要立即回应
2. 确认情绪："我能感觉到您很在意..."
3. 转向问题："让我们看看可以怎么解决..."
4. 重建信任：承认对方的感受
```

**自己情绪激动时**：
```
1. 物理暂停：喝水、深呼吸
2. 心理暂停：重复"冷静"30秒
3. 重构焦点：关注利益而非输赢
4. 必要时暂停谈判
```

## 三、经典书籍核心要点

### 《谈判力》(Getting to Yes) - Fisher & Ury

**核心理念**：不输即为赢 (Getting to Yes without giving in)

**四大原则**：
1. **人：把人和问题分开**
   - 关注对方的感受和利益
   - 不要被对方情绪带偏
   - 让对方参与解决问题

2. **利益：聚焦利益而非立场**
   - 立场是表面，利益是本质
   - 问"为什么"找出真实需求
   - 列出双方利益清单

3. **选项：创造双赢选项**
   - 扩大谈判范围
   - 寻找共同利益
   - 寻找对对方高价值、对我方低成本的选项

4. **标准：坚持客观标准**
   - 市场价值、行业标准、法规
   - 专业评估、以往案例
   - 公平第三方的判断

### 《优势谈判》(Never Split the Difference) - Chris Voss

**核心方法**：情感同步 + 战术同理心

**关键技巧**：

| 技巧 | 公式 | 示例 |
|-----|------|------|
| 镜像 | 重复关键词 | "所以您希望...?" |
| 标注 | "看起来..." "似乎..." | "看起来这个价格对您很重要" |
| 校准 | 开放式问题 | "我们怎样才能达成共识?" |
| 非暴力 | 表达需求而非指责 | "我需要..." 而非 "你应该..." |
| 绝对确认 | "告诉我" | "告诉我这个方案哪里不行" |

**战术层次**：
- **战术同理心**：理解对方的感受
- **战略同理心**：理解对方的驱动因素
- **情感连接**：建立信任和亲密度

### 《沃顿商学院最受欢迎的谈判课》(Getting More) - Stuart Diamond

**核心观点**：每个谈判都是一次获取更多的机会

**关键策略**：
1. 目标优先于妥协
2. 用"校准问题"引导对方
3. 利用对方的准则
4. 掌握信息不对称
5. 让对方有控制感

## 四、实用话术库

### 商业谈判话术

```
【开场】
"感谢您抽出时间... 基于我们对市场的了解..."

【探测】
"能否请您详细说说...?"
"这对您来说为什么重要?"

【对抗】
"我理解您的立场，但数据显示..."
"基于行业标准，我们认为..."

【让步】
"如果我们能在XX上调整，您能考虑...?"
"作为我们的诚意，您可以看到..."

【锁定】
"基于刚才讨论的，建议我们就...达成一致"
"我们的最终条件是...希望今天能确定下来"
```

### 日常沟通话术

```
【请求】
"能否请您帮忙...我知道这需要花费您一些时间..."

【拒绝】
"非常感谢您的邀请，但目前确实有冲突..."

【协调】
"我觉得我们可以找到一个双方都能接受的方案..."

【感谢】
"非常感谢您的理解和支持..."
```

### 微信回复话术

```
【确认】
"收到，我这边马上处理。"

【延时】
"好的，我了解一下情况，稍后给您回复。"

【拒绝】
"谢谢您的信任，这段时间实在安排不过来~"

【感谢】
"[表情] 太感谢了！有您帮忙轻松多了~"
```

## 五、谈判检查清单

### 开局前检查
- [ ] 明确自己的底线和最优方案
- [ ] 了解对方可能的立场和利益
- [ ] 确定谈判目标和优先级
- [ ] 准备替代方案(BATNA)
- [ ] 选择合适的谈判场地和时间

### 中局检查
- [ ] 是否在倾听对方
- [ ] 是否在探索对方利益
- [ ] 是否在创造选项
- [ ] 是否在坚持客观标准

### 终局检查
- [ ] 关键利益是否得到保障
- [ ] 是否明确了下一步行动
- [ ] 是否记录了协议内容
- [ ] 是否有跟进机制
