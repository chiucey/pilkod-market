# 场景化谈判策略模板

## 一、商业谈判场景

### 场景1: 价格谈判

**典型情境**：
- 供应商报价后要求降价
- 客户要求更多折扣
- 项目预算紧张需要压价

**策略选择**：
```
 상황: 供应商报价 100万, 你的预算 85万

 阶段1 - 锚定:
 "基于我们对市场的了解，这类项目的合理区间在 80-90 万..."

 阶段2 - 探测:
 "能否请您详细说明一下这个报价的构成?"

 阶段3 - 施压:
 "根据我们以往合作的项目，这个价格有 15% 的下降空间..."

 阶段4 - 让步:
 "如果你们能在交货期上配合，我们可以接受 88 万..."

 阶段5 - 锁定:
 "88 万是我们的最优价格，今天确认的话我们马上开始准备..."
```

**风险提示**：
- 避免过早暴露预算底线
- 确保让步有交换条件
- 保持专业但坚定

### 场景2: 合同条款谈判

**典型情境**：
- 付款方式争议
- 交付时间争议
- 违约责任争议

**策略选择**：
```
 付款方式争议:
  对方: "我们要求预付 50%"
  我方: "我们理解贵方的风控考量，能否考虑分阶段付款?

          比如签约付 30%，交付付 40%，验收后付 30%?"

 交付时间争议:
  对方: "必须在两个月内交付"
  我方: "根据项目规模，正常交付周期需要 3 个月。

          我们可以分阶段交付，在 2 个月内先交付核心功能..."
```

### 场景3: 合作条件谈判

**典型情境**：
- 合作模式选择
- 利益分配争议
- 权利义务争议

**策略选择**：
```
 利益分配:
 "我们建议按投入比例分配，同时设立一个业绩奖励机制..."

 权利义务:
 "关于知识产权，我们建议共有; 关于保密义务，双方对等..."
```

## 二、日常沟通场景

### 场景4: 请求上级支持

**典型情境**：
- 需要资源/预算
- 需要决策授权
- 需要跨部门协调

**策略选择**：
```
【示弱 + 价值展示】
"领导，关于 XX 项目遇到了一个挑战...

 (说明困难)

 目前我想到的方案是...但需要您的支持...

 (提出请求)

 如果能成功推进，预计可以带来...的效果，您看是否可行?"
```

### 场景5: 协调同事配合

**典型情境**：
- 需要其他部门支持
- deadline 冲突
- 资源争夺

**策略选择**：
```
【互惠 + 理解】
"小李，我知道你现在手头也很紧...

 (理解对方处境)

 我这边 XX 项目需要在周五前完成，时间确实紧张。

 (说明需求)

 你这边能不能先帮我看一下这部分? 我这边可以先做那个部分。

 (提出互惠方案)

 回头我这边整理好的资料也可以同步给你参考~"
```

### 场景6: 家人/朋友协商

**典型情境**：
- 家庭决策
- 费用分摊
- 时间安排冲突

**策略选择**：
```
【共情 + 方案】
"我知道你也很在意这个安排...

 (共情)

 让我想想有没有其他办法...

 (思考方案)

 我们的方案 A 是...，方案 B 是...

 (提供选项)

 你看哪个更合适? 或者我们再想想有没有其他可能?"
```

## 三、微信回复场景

### 场景7: 工作群消息回复

**典型情境**：
- 被 @ 要求回复
- 群里有决策需要表态
- 需要协调多的事项

**策略选择**：
```
【收到确认】
"收到，我这边负责 XX 部分，预计 XX 时间完成。"

【协调分配】
"大家先按这个方向准备，有问题随时沟通。我这边负责 XX，有想法随时说~"

【决策表态】
"综合大家的意见，我建议...理由是...大家看可以吗?"
```

### 场景8: 私聊请求回复

**典型情境**：
- 对方请求帮忙
- 对方询问进度
- 对方提出建议

**策略选择**：
```
【收到请求】
"好的，我看看，最迟明天给你回复~"

【请求帮助】
"[捂脸] 遇到个问题想请教你，方便吗?"

【感谢回应】
"[抱拳] 太感谢了! 有你帮忙轻松多了~"

【委婉拒绝】
"谢谢你的信任，这段时间确实安排不开。

 建议你联系一下 XX，他可能更专业~"
```

### 场景9: 朋友圈互动

**典型情境**：
- 点赞/评论互动
- 朋友圈文案
- 求助类朋友圈

**策略选择**：
```
【积极互动】
"[强] 这个观点很有启发!"

【回应评论】
"谢谢关注! 关于你说的 XX，确实是我们在重点推进的..."

【求助文案】
"[捂脸] 求助万能的朋友圈，有没有朋友了解 XX?

 提前感谢，麻烦了的请喝咖啡~"
```

## 四、敏感场景处理

### 场景10: 对方情绪激动

**策略选择**：
```
【暂停 + 共情】
"我能感觉到这件事对您很重要...

 (确认感受)

 让我们一起看看怎么解决..."

【重构话题】
"也许我们可以从另一个角度来看这个问题..."

【寻求方案】
"您希望怎么解决这个问题? 我们一起来想办法..."
```

### 场景11: 谈判陷入僵局

**策略选择**：
```
【重新定义】
"也许我们一开始的关注点可以调整一下..."

【引入新信息】
"最近市场有个变化，可能需要我们重新考虑..."

【提出小让步】
"如果我们能在 XX 上配合，你们能在 YY 上给予支持吗?"

【暂停策略】
"让我们都再考虑一下，明天我们再继续讨论?"
```

### 场景12: 需要拒绝对方

**策略选择**：
```
【商业场景】
"感谢您的信任，但这个条件目前对我们确实有困难。

 如果将来情况变化，我很愿意再探讨合作的可能。"

【日常场景】
"谢谢你的好意，这段时间真的安排不开。

 你看看找其他人是否更合适? 有需要我帮忙对接的话随时说~"

【微信场景】
"谢谢，但这段时间确实有点紧，改天有机会再约~"
```

## 五、情景模拟练习

### 练习1: 砍价场景

**情境**: 你在二手市场看中一个包，卖家开价 800 元，你心理价位 500 元。

**模拟对话**:
```
你: "这个包看起来不错，能便宜点吗?"

卖家: "800 不贵了，进价都要 600。"

你: "我理解，但现在网上类似款式的新的也就 600 左右..."

 (寻找支持论点)

卖家: "那你愿意出多少?"

你: "我看了下成色，500 左右比较合理。如果您能 550，我今天就可以带走。"

 (锚定 + 让步)

卖家: "550 太低了，650 吧。"

你: "550 是我的最高预算了，您看 600 怎么样? 我诚心买。"

 (坚持 + 互惠)

卖家: "那 620，最低的了。"

你: "成交!"
```

### 练习2: 工作汇报场景

**情境**: 你需要向领导申请增加预算，但预算超标。

**模拟对话**:
```
你: "领导，关于 XX 项目有个情况需要汇报..."

 (铺垫)

领导: "说。"

你: "目前项目进展顺利，但在 XX 环节遇到了超出预期的情况。

      之前预算在 XX，但实际需要 XX，超出约 15%。"

 (说明情况)

领导: "为什么会超?"

你: "主要是因为 XX(说明原因)，但这也为后续 XX 奠定了基础。

      我分析了几个方案，倾向于方案 A..."

 (分析 + 方案)

你: "您看是否可以追加 XX 的预算? 保证项目按质完成。"

 (提出请求)

领导: "好吧，但要注意控制成本。"

你: "明白，我会每周汇报进展，确保在预算内完成目标。"

 (承诺 + 跟进)
```
