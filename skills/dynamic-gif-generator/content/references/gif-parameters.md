# GIF参数选择指南

## 场景与参数对照表

| 场景类型 | 推荐时长 | 推荐帧率 | 推荐分辨率 | 文件大小目标 |
|---------|---------|---------|-----------|-------------|
| 表情包/贴纸 | 1-3秒 | 10-15fps | 240x240 / 320x320 | <500KB-2MB |
| 社交媒体帖子 | 2-5秒 | 15-20fps | 480x480 / 540x540 | 1-3MB |
| 产品展示 | 3-8秒 | 24-30fps | 640x640 / 720x720 | 2-5MB |
| 动态图标/Logo | 2-5秒 | 15-30fps | 256x256 / 512x512 | 500KB-2MB |
| 影视特效展示 | 3-10秒 | 24fps | 1280x720 / 1920x1080 | 5-15MB |

| 新闻/资讯 | 5-15秒 | 15-24fps | 480x360 / 640x480 | 2-5MB |

## 帧率详解

### 帧率对流畅度的影响

| 帧率 | 流畅度 | 文件大小 | 适用场景 |
|-----|-------|---------|---------|
| 8fps | 卡顿感明显 | 最小 | 极简图标、文字动画 |
| 10fps | 基本流畅 | 较小 | 简单表情、loading动画 |
| 12fps | 尚可 | 小 | 标准表情包 |
| 15fps | 良好 | 中等 | 社交媒体内容 |
| 20fps | 流畅 | 较大 | 高质量内容 |
| 24fps | 非常流畅 | 大 | 视频级内容 |
| 30fps | 超流畅 | 很大 | 高清视频 |

### 不同场景帧率建议

**表情包（强调可爱/萌感）**：
- 推荐帧率：10-12fps
- 原因：较低帧率反而增加"萌"的感觉，类似定格动画
- 示例：一休哥的表情包、小黄人动画

**产品展示（强调质感/流畅）**：
- 推荐帧率：24-30fps
- 原因：需要展示产品的流畅动作，高帧率更专业
- 示例：手表360度展示、手机旋转展示

**影视特效（强调震撼/真实）**：
- 推荐帧率：24fps
- 原因：电影标准帧率，视觉震撼
- 示例：爆炸特效、魔法效果

## 分辨率选择

### 常见分辨率及用途

| 分辨率 | 像素 | 适用场景 | 文件大小(3秒15fps) |
|-------|------|---------|------------------|
| 240p | 320x240 | 快速加载、低带宽 | ~300KB |
| 360p | 480x360 | 移动端、聊天 | ~800KB |
| 480p | 640x480 | 社交媒体 | ~1.5MB |
| 540p | 720x540 | 高质量社交 | ~2.5MB |
| 720p | 1280x720 | 高清展示 | ~5MB |
| 1080p | 1920x1080 | 超高清 | ~12MB |

### 宽高比选择

| 宽高比 | 尺寸示例 | 适用场景 |
|-------|---------|---------|
| 1:1 | 320x320, 480x480, 640x640 | 表情包、社交媒体头像 |
| 4:3 | 640x480, 800x600 | 传统视频、教程内容 |
| 16:9 | 1280x720, 1920x1080 | 电影级、影视特效 |
| 9:16 | 720x1280, 1080x1920 | 竖版视频、Stories |

### 分辨率与内容关系

**高分辨率适合**：
- 细节丰富的内容（产品质感、人物特写）
- 需要放大查看的内容
- 专业级展示（商业广告、产品目录）

**低分辨率适合**：
- 简单图形/图标
- 移动端优先
- 文件大小受限（聊天表情）

## 时长选择

### 各场景最佳时长

| 场景 | 最佳时长 | 原因 |
|-----|---------|-----|
| 表情包 | 1-3秒 | 短小精悍，便于快速传达情绪 |
| 动态图标 | 2-5秒 | 展示完整动画循环 |
| 产品展示 | 3-8秒 | 展示多个角度/功能 |
| 教程说明 | 5-15秒 | 需要完整展示步骤 |
| 影视特效 | 3-10秒 | 展示高潮视觉效果 |
| 新闻片段 | 5-15秒 | 传递完整信息 |

### 时长与信息量

| 时长 | 适合展示 | 不适合 |
|-----|---------|-------|
| 1-2秒 | 单一情绪/动作 | 复杂信息 |
| 3-5秒 | 2-3个要点 | 长叙述 |
| 5-10秒 | 完整故事 | 超长内容 |
| 10秒+ | 系列内容 | 即时分享 |

## 文件大小优化

### 文件大小估算

**基础公式**：
```
文件大小 ≈ 分辨率 × 帧率 × 时长 × 颜色深度 × 压缩率
```

**简化估算（以15fps为例）**：

| 分辨率 | 每帧约 | 3秒(45帧) | 5秒(75帧) | 10秒(150帧) |
|-------|-------|----------|----------|------------|
| 320x320 | 15KB | 675KB | 1.1MB | 2.2MB |
| 480x480 | 35KB | 1.5MB | 2.6MB | 5.2MB |
| 640x640 | 60KB | 2.7MB | 4.5MB | 9MB |
| 1280x720 | 150KB | 6.7MB | 11MB | 22MB |

### 优化策略

#### 策略1：降低分辨率
最有效的方法，文件大小随分辨率平方下降

#### 策略2：减少帧率
直接减少数据量，但可能影响流畅度

#### 策略3：减少时长
减少总帧数，最直接的方法

#### 策略4：使用调色板
256色调色板比真彩色小3-4倍

#### 策略5：裁剪不必要区域
只保留核心内容区域

## 循环方式

### 循环类型

| 类型 | 参数 | 适用场景 |
|-----|------|---------|
| 无限循环 | `-loop 0` | 表情包、背景、图标 |
| 单次播放 | `-loop 1` | 产品展示、教程 |
| 指定次数 | `-loop N` | 特殊效果 |

### 无缝循环技巧

**方法1：首尾帧一致**
- 确保第一帧和最后一帧完全相同
- 适合简单循环动画

**方法2：使用反向动画**
```bash
ffmpeg -i input.gif -filter_complex "[0:v]reverse[r];[0:v][r]concat=n=2:v=1:a=0" -loop 0 output_loop.gif
```

**方法3：使用blend模式**
```bash
ffmpeg -i input.gif -filter_complex "[0:v][0:v]blend=all_expr='A/2+B/2'" -loop 0 output_blend.gif
```
