# 动态GIF生成专家

## 核心能力

作为顶级影视专家和程序专家，本技能能够：

1. **文本描述转GIF** - 将创意描述转化为动态图像
2. **图片序列转GIF** - 多张图片合成流畅动画
3. **视频片段转GIF** - 提取精彩瞬间制作GIF
4. **特效GIF生成** - 影视级动态效果
5. **表情包制作** - 趣味动态表情
6. **产品展示GIF** - 商业级动态展示

## 工作流程

### 阶段1：需求分析与规划

**输入解析**：
- 识别GIF的用途场景（表情包/产品展示/影视特效/社交媒体）
- 确定时长要求（通常1-10秒）
- 分析画面风格（写实/卡通/抽象/影视级）
- 确认尺寸要求（通常320x320, 480x480, 640x480等）

**场景分类**：
| 场景类型 | 帧率建议 | 分辨率 | 循环方式 |
|---------|---------|-------|---------|
| 表情包 | 12-15fps | 320x320 | 无限循环 |
| 产品展示 | 24-30fps | 640x640 | 单次/循环 |
| 影视特效 | 24fps | 1920x1080 | 片段 |
| 社交媒体 | 15-20fps | 480x480 | 无限循环 |

### 阶段2：内容生成

#### 方案A：AI图像序列法（推荐用于复杂场景）

**步骤1**：生成关键帧图像序列

使用 `image_synthesize` 工具批量生成帧：

```json
{
  "requests": [
    {
      "prompt": "描述帧1的画面内容，包括主体、动作、背景、光线等细节",
      "output_file": "frame_001.png",
      "aspect_ratio": "1:1"
    },
    {
      "prompt": "描述帧2的画面内容（与帧1有连贯动作）",
      "output_file": "frame_002.png",
      "aspect_ratio": "1:1"
    }
  ]
}
```

**步骤2**：将图像转换为视频

使用 `batch_image_to_video` 工具：

```json
{
  "count": 5,
  "image_file_list": ["frame_001.png", "frame_002.png", "frame_003.png", "frame_004.png", "frame_005.png"],
  "output_file_list": ["clip_001.mp4"],
  "prompt_list": ["帧间过渡描述"],
  "duration_list": [6],
  "resolution_list": ["768P"]
}
```

**步骤3**：合成GIF

使用FFmpeg将视频转换为GIF：

```bash
ffmpeg -i clip_001.mp4 -vf "fps=15,scale=480:-1:flags=lanczos,split[s0][s1];[s0]palettegen[p];[s1][p]paletteuse" -loop 0 output.gif
```

#### 方案B：直接视频生成法（推荐用于连续动作）

**步骤1**：使用 `gen_videos` 或 `batch_text_to_video` 直接生成视频

```json
{
  "video_requests": [
    {
      "prompt": "详细的动态场景描述，包括主体动作、光影变化、背景动态等",
      "output_file": "generated_clip.mp4",
      "duration": 6,
      "resolution": "1080P"
    }
  ]
}
```

**步骤2**：视频转GIF（同上步骤3）

#### 方案C：图片编辑转换法（适用于已有素材）

**场景**：用户提供了一系列图片或视频

**步骤1**：图片预处理
- 调整所有图片为统一尺寸
- 确保帧顺序正确
- 可选：添加过渡效果

**步骤2**：合成GIF
使用FFmpeg命令：

```bash
# 图片序列转GIF
ffmpeg -framerate 15 -i frame_%03d.png -vf "scale=480:480:flags=lanczos,split[s0][s1];[s0]palettegen[p];[s1][p]paletteuse" -loop 0 output.gif

# 视频转GIF
ffmpeg -i input.mp4 -ss 00:00:02 -t 3 -vf "fps=15,scale=480:-1:flags=lanczos,split[s0][s1];[s0]palettegen[p];[s1][p]paletteuse" -loop 0 output.gif
```

## 技术参数指南

### 帧率（FPS）选择

| 用途 | 推荐帧率 | 流畅度 | 文件大小 |
|-----|---------|-------|---------|
| 极简动画 | 8-10fps | 一般 | 最小 |
| 标准表情 | 12-15fps | 良好 | 较小 |
| 标准视频 | 24fps | 流畅 | 中等 |
| 高清视频 | 30fps | 非常流畅 | 较大 |
| 电影级 | 24fps（电影格式） | 电影感 | 中等 |

### 分辨率与文件大小关系

| 分辨率 | 文件大小(3秒) | 适用场景 |
|-------|--------------|---------|
| 240p (320x240) | 0.5-1MB | 快速加载 |
| 480p (640x480) | 1-3MB | 通用场景 |
| 720p (1280x720) | 3-8MB | 高清展示 |
| 1080p (1920x1080) | 8-15MB | 专业级 |

### 色彩优化

```bash
# 减少颜色数量优化文件大小
ffmpeg -i input.gif -vf "split[s0][s1];[s0]palettegen=stats_mode=diff[p];[s1][p]paletteuse=dither=bayer" output_optimized.gif

# 限制颜色数量（256色）
ffmpeg -i input.gif -vf "palettegen=max_colors=256" palette.png
ffmpeg -i input.gif -i palette.png -lavfi "paletteuse=dither=sierra2_4a" output.gif
```

## 质量检查清单

生成GIF后，按以下标准检查：

- [ ] **流畅性**：动画无明显卡顿或跳变
- [ ] **循环性**：无限循环GIF首尾衔接自然
- [ ] **清晰度**：画面主体清晰可辨
- [ ] **文件大小**：符合使用场景的大小要求
- [ ] **色彩**：色彩鲜艳无明显色带/色块
- [ ] **比例**：宽高比符合预期（1:1/16:9等）
- [ ] **内容相关性**：符合用户原始需求意图

## 常见问题解决方案

### 问题1：GIF文件过大

**解决方案**：
1. 降低分辨率
2. 减少帧数（降低时长）
3. 使用调色板优化
4. 限制颜色数量

### 问题2：动画不够流畅

**解决方案**：
1. 增加帧率
2. 增加中间帧数量
3. 使用更平滑的过渡描述

### 问题3：首帧和尾帧衔接不自然

**解决方案**：
1. 在生成时确保首尾动作/状态一致
2. 调整GIF的循环方式
3. 移除不自然的过渡帧

### 问题4：画面模糊或失真

**解决方案**：
1. 提高源素材分辨率
2. 使用更高的生成分辨率
3. 避免过度放大低分辨率素材

## 进阶技巧

### 动态文字叠加

```bash
ffmpeg -i input.gif -vf "drawtext=text='标题':fontfile=font.ttf:fontsize=24:fontcolor=white:x=(w-text_w)/2:y=h-40" -codec:a copy output_with_text.gif
```

### 分段GIF合成

```bash
# 合并多个GIF
ffmpeg -i part1.gif -i part2.gif -i part3.gif -filter_complex "[0:v][1:v][2:v]concat=n=3:v=1:a=0[outv]" -map "[outv]" combined.gif
```

### 添加边框/特效

```bash
# 添加圆角边框
ffmpeg -i input.gif -vf "crop=iw-20:ih-20:10:10,curves=all='0/0 0.5/0.5 1/1'" output_border.gif
```
