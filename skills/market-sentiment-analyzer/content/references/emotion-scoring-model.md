# 市场情绪分析 - 技术参考资料

## 情绪评分模型详解

### 1. 舆情情绪采集规则

#### 1.1 数据源
- **财经新闻**：新浪财经、东方财富、同花顺等公开新闻源
- **社交媒体**：股吧、社区论坛等合规平台的市场言论
- **分析师评级**：主流券商研报评级汇总

#### 1.2 情感分析规则
- 正面词汇：上涨、突破、看好、增持、买入、超预期等
- 负面词汇：下跌、破位、看空、减持、卖出、不及预期等
- 中性词汇：震荡、观望、等待等

#### 1.3 评分计算
```
舆情得分 = (正面数量 × 1 + 中性数量 × 0 + 负面数量 × -1) / 总数量 × 100
```

### 2. 资金情绪指标

#### 2.1 北向资金
- **沪股通**：上海证券交易所的境外投资通道
- **深股通**：深圳证券交易所的境外投资通道
- **净买入** = 买入成交额 - 卖出成交额

#### 2.2 主力资金
- 超大单：大于等于50万股或100万元的成交
- 大单：大于等于10万股或20万元的成交
- 净流入 = 超大单净流入 + 大单净流入

#### 2.3 评分规则
```
资金得分 = 归一化(北向净买入) × 0.4 + 归一化(主力净流入) × 0.3 + 归一化(量比) × 0.3
```

### 3. 技术情绪指标

#### 3.1 涨跌家数比
- 上涨家数 / 下跌家数
- 比值 > 1 表示多方占优

#### 3.2 赚钱效应
```
赚钱效应 = (上涨股票数量 × 平均涨幅) / (下跌股票数量 × 平均跌幅)
```

#### 3.3 连板率
```
连板率 = 连续涨停股票数量 / 涨停股票总数 × 100%
```

#### 3.4 技术情绪评分
```
技术得分 = 涨跌家数比得分 × 0.35 + 赚钱效应得分 × 0.35 + 连板率得分 × 0.3
```

### 4. 综合情绪评分

```
综合评分 = 舆情得分 × 40% + 资金得分 × 35% + 技术得分 × 25%
```

评分范围：0-100

| 评分区间 | 情绪等级 | 市场特征 |
|----------|----------|----------|
| 0-20 | 极度悲观 | 市场全面恐慌，恐慌情绪蔓延 |
| 21-40 | 悲观 | 空方主导，观望情绪浓厚 |
| 41-60 | 中性 | 多空平衡，市场观望 |
| 61-80 | 乐观 | 多方主导，市场活跃 |
| 81-100 | 极度乐观 | 市场全面乐观，可能过热 |

### 5. 情绪拐点识别

#### 5.1 触底反弹信号
- 评分从 < 30 回升超过 10 点
- 成交量明显放大
- 涨跌家数比由负转正

#### 5.2 顶部回落信号
- 评分从 > 70 下降超过 10 点
- 主力资金大幅流出
- 连板率下降，炸板率上升

#### 5.3 背离信号
- 指数创新高但情绪评分下降 → 顶背离预警
- 指数创新低但情绪评分上升 → 底背离预警

### 6. 数据更新频率

| 数据类型 | 更新频率 | 延迟 |
|----------|----------|------|
| 舆情数据 | 实时 | 5-15分钟 |
| 北向资金 | 盘中实时 | 盘后2小时 |
| 主力资金 | 盘中实时 | 盘后2小时 |
| 涨跌统计 | 盘中实时 | 实时 |

### 7. 注意事项

1. **数据时效性**：收盘后的分析基于当日最终数据
2. **市场差异**：A股、港股、美股的数据源和指标权重可能不同
3. **特殊情况**：重大事件（政策、灾害）可能导致情绪异常
4. **仅供参考**：情绪分析不构成投资建议
