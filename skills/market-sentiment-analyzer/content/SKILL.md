# 市场情绪分析技能

## 触发边界

**应触发场景：**
- 用户要求分析市场/板块/个股的情绪状态
- 查询舆情情绪（财经新闻、社交媒体言论情感倾向）
- 追踪北向资金/主力资金流向
- 评估赚钱效应、连板率等技术情绪指标
- 计算情绪评分（0-100）
- 识别情绪拐点（触底/顶部信号）
- 分析热点板块与冷点板块情绪差异

**不应触发场景：**
- 基础行情查询（使用行情查询技能）
- 财务基本面分析（使用财务分析技能）
- 个股技术指标计算（使用技术分析技能）

## 核心工作流程

### 步骤1：初始化情绪分析体系

1. **舆情采集规则**
   - 合规采集财经新闻标题情感分析
   - 采集股吧、社区言论情感倾向标注
   - 过滤无效/垃圾信息

2. **情绪评分模型**
   - 正面情绪：+1分
   - 中性情绪：0分
   - 负面情绪：-1分
   - 加权计算舆情情绪得分

3. **资金情绪指标**
   - 北向资金净流入/净流出
   - 主力资金净流入行业排名
   - 成交量变化率（量比）

4. **技术情绪维度**
   - 涨跌家数比（上涨家数/下跌家数）
   - 赚钱效应指标
   - 连板率（连续涨停个股占比）
   - 炸板率

### 步骤2：数据采集与解析

**舆情数据采集（合规公开信息）：**
- 财经新闻标题情感分析
- 社交媒体市场言论采样
- 分析师评级汇总

**资金数据解析：**
- 北向资金：沪股通+深股通净买入
- 主力资金：超大单+大单净流入
- 成交量：当日成交额环比变化

**技术数据计算：**
- 全市场涨跌停家数统计
- 行业板块涨跌统计
- 概念板块热度排名

### 步骤3：情绪评分计算

**权重配置（默认值，可调整）：**
- 舆情情绪权重：40%
- 资金情绪权重：35%
- 技术情绪权重：25%

**评分公式：**
```
综合情绪评分 = 舆情得分×0.4 + 资金得分×0.35 + 技术得分×0.25
情绪评分范围：0-100
```

**情绪等级划分：**
- 极度悲观（0-20）：市场全面恐慌
- 悲观（21-40）：空方主导
- 中性（41-60）：多空平衡
- 乐观（61-80）：多方主导
- 极度乐观（81-100）：市场全面乐观

### 步骤4：关联分析与拐点识别

**情绪与指数关联分析：**
- 计算情绪评分与市场指数的皮尔逊相关系数
- 分析情绪领先/滞后指数的时间关系
- 识别背离信号（情绪与指数走势不一致）

**情绪拐点识别规则：**
- 情绪触底反弹：评分从低位回升超过10点
- 情绪顶部回落：评分从高位下降超过10点
- 情绪极度信号：评分<15或评分>85

### 步骤5：板块情绪分析

**行业情绪评分：**
- 按申万一级行业分类
- 计算各行业情绪得分排名
- 识别热点行业（情绪评分前3）
- 识别冷点行业（情绪评分后3）

**概念板块热度：**
- 跟踪近期热门概念
- 计算概念板块资金流入
- 评估概念持续性

### 步骤6：报告生成

**情绪分析报告结构：**

```markdown
# [市场]情绪分析报告 - [日期]

## 一、综合情绪评分
- 评分：[XX]/100
- 等级：[情绪等级]
- 趋势：[较昨日变化]

## 二、分维度分析
### 2.1 舆情情绪（权重40%）
- 得分：[XX]/100
- 正面新闻：[X]条 | 中性：[X]条 | 负面：[X]条
- 关键舆情：[摘录]

### 2.2 资金情绪（权重35%）
- 得分：[XX]/100
- 北向资金：[净买入/净卖出] [X]亿
- 主力资金：[净流入/净流出] [X]亿
- 量比：[X]

### 2.3 技术情绪（权重25%）
- 得分：[XX]/100
- 涨跌家数比：[X]:[X]
- 涨停家数：[X]家
- 连板率：[X]%

## 三、情绪拐点提示
[拐点信号描述]

## 四、板块情绪排名
### 热点板块（Top3）
1. [板块名]：[评分]
2. [板块名]：[评分]
3. [板块名]：[评分]

### 冷点板块（Bottom3）
1. [板块名]：[评分]
2. [板块名]：[评分]
3. [板块名]：[评分]

## 五、关联规律分析
[情绪与指数关联分析结果]

## 六、操作建议
[基于情绪分析的交易建议]
```

## 执行参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| market | string | "A股" | 分析市场：A股/港股/美股 |
| scope | string | "全市场" | 分析范围：全市场/行业/概念/个股 |
| target | string | null | 目标标的代码 |
| period | string | "日" | 时间周期：日/周/月 |
| sentiment_weights | dict | {舆情:0.4,资金:0.35,技术:0.25} | 情绪评分权重 |

## 依赖模块

- `public_opinion_analysis`：舆情数据采集与情感分析
- `capital_flow_analysis`：资金流向分析
- `sentiment_scoring`：情绪评分计算
- `inflection_point_recognition`：拐点识别算法
- `sector_analysis`：板块情绪分析

## 安全规则

1. **数据隔离**：仅使用合规公开数据
2. **禁止外部调用**：不调用未授权数据源
3. **合规舆情采集**：仅采集合规财经信息源
4. **禁止敏感信息提取**：不处理用户隐私数据
5. **仅情绪分析**：不提供投资建议，仅提供分析参考

## 错误处理

| 错误类型 | 处理方式 |
|----------|----------|
| 数据源不可用 | 返回"数据获取失败"，提示用户稍后重试 |
| 评分计算异常 | 使用备用计算方法，标注数据不完整 |
| 板块数据缺失 | 跳过该板块，在报告中注明 |

## 交互示例

**示例1：全市场情绪分析**
```
用户：分析今天A股市场情绪
返回：综合情绪评分、各维度得分、情绪拐点提示、热点板块
```

**示例2：板块情绪对比**
```
用户：分析今天新能源板块的情绪
返回：该板块情绪评分、与大盘对比、资金流向、技术情绪
```

**示例3：情绪拐点监测**
```
用户：最近有哪些情绪拐点信号？
返回：近期情绪拐点列表，包括日期、类型、信号强度
```
