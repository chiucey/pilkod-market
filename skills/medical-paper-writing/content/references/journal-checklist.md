# 医学论文投稿自检清单

## 投稿前必查项目

### 1. 伦理审批与知情同意

- [ ] 伦理委员会审批声明（IRB/EC编号）
- [ ] 知情同意书获取声明
- [ ] 临床试验注册号（如适用）
- [ ] 动物实验伦理审批声明
- [ ] 隐私保护措施说明

### 2. 作者署名

- [ ] 所有作者符合ICMJE authorship criteria
- [ ] 作者顺序已确认并签字
- [ ] 作者单位信息完整准确
- [ ] Corresponding author联系方式明确
- [ ] 作者贡献声明(CRediT)已完成

### 3. 利益冲突声明

- [ ] 所有作者利益冲突披露
- [ ] 资金来源声明
- [ ] 声明格式符合期刊要求

### 4. 格式规范

#### 标题 (Title)
- [ ] 简洁明了，不超过期刊规定字数
- [ ] 包含关键研究要素（PICO）
- [ ] 无缩写或仅用通用缩写
- [ ] 包含研究类型（随机对照试验、meta分析等）

#### 摘要 (Abstract)
- [ ] 结构化格式符合要求
- [ ] 字数符合期刊规定
- [ ] 包含研究背景/目的/方法/结果/结论
- [ ] 无文献引用
- [ ] 关键词选择恰当

#### 正文
- [ ] 字数/页数符合期刊要求
- [ ] 行号连续
- [ ] 页面格式设置正确
- [ ] 术语使用统一

### 5. 统计报告

- [ ] 样本量计算说明
- [ ] 主要结局指标定义明确
- [ ] 效应量及其95%CI均报告
- [ ] P值使用正确（明确检验方法）
- [ ] 多重比较校正说明
- [ ] 缺失数据处理说明
- [ ] 异质性分析（如meta分析）

### 6. 图表质量

- [ ] 图表数量符合限制
- [ ] 分辨率符合期刊要求（通常≥300 dpi）
- [ ] 图表自明性强
- [ ] 坐标轴标签完整
- [ ] 单位使用正确
- [ ] 误差线定义明确
- [ ] 统计数据标注规范

### 7. 参考文献

- [ ] 格式统一（Vancouver/Harvard等）
- [ ] DOI均已标注
- [ ] 近期文献占比合理
- [ ] 自我引用适度
- [ ] 文献数量符合要求
- [ ] 文中引用与参考文献一致

### 8. 补充材料

- [ ] 知情同意书/伦理批件
- [ ] CONSORT/PRISMA流程图
- [ ] 统计补充表
- [ ] 全文PDF版本

### 9. 投稿信 (Cover Letter)

- [ ] 标题和文章类型明确
- [ ] 研究创新点/重要性简述
- [ ] 适合该期刊的理由
- [ ] 作者资质说明
- [ ] 无一稿多投声明
- [ ] 建议/排除的审稿人

### 10. 常见错误避免

- [ ] 无拼写/语法错误
- [ ] 数字/统计数据核对
- [ ] 单位使用一致
- [ ] 缩写首次定义
- [ ] 图注表注完整
- [ ] 作者信息最新

## 常见医学期刊格式对比

| 要素 | NEJM | Lancet | JAMA | BMJ |
|------|------|--------|------|-----|
| 摘要字数 | 350 | 300 | 350 | 300 |
| 正文字数 | ~4500 | ~4000 | ~3500 | ~3000 |
| 参考文献格式 | Numbered | Numbered | Numbered | Numbered |
| 图表限制 | 5 | 5 | 5 | 5 |

## 各研究类型报告规范

### RCT (CONSORT 2010)
- 随机序列产生方法
- 分配隐藏机制
- 盲法实施情况
- 受试者流程图
- 基线特征表
- 效应量及CI
- 亚组分析说明

### Meta分析 (PRISMA 2020)
- 注册协议信息
- 检索策略完整
- 纳入排除标准
- 研究筛选流程图
- 偏倚风险评估
- 异质性分析(I²)
- 敏感性分析
- 证据质量评级(GRADE)

### 队列研究 (STROBE)
- 暴露/结局定义
- 随访时间
- 混杂因素控制
- 失访情况
- 亚组分析

### 病例对照研究 (STROBE)
- 对照选择
- 匹配策略
- 暴露测量
- 混杂因素控制
