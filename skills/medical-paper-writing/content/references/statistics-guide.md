# 医学论文统计学报告规范

## 基本原则

1. **完整性**：报告所有进行的分析
2. **透明性**：方法描述足以让他人重复
3. **精确性**：使用合适的精度报告数据
4. **客观性**：避免选择性报告

## 描述性统计

### 连续变量

| 数据分布 | 报告格式 | 示例 |
|----------|----------|------|
| 正态分布 | 均数 ± 标准差 | 收缩压 125 ± 15 mmHg |
| 非正态分布 | 中位数 (四分位距) | 住院天数 7 (4-12) 天 |
| 大样本正态 | 均数 (95% CI) | BMI 24.5 (23.8-25.2) kg/m² |

**判断正态性的方法**：
- Shapiro-Wilk检验 (n < 50)
- Kolmogorov-Smirnov检验 (n ≥ 50)
- 直方图/Q-Q图目测

### 分类变量

- 报告频数和百分比
- 分母需明确（如 n/N）
- 避免过多小数位（通常保留1位）

```
示例：
- 高血压：89例 (47.6%)
- 糖尿病：45例 (24.1%)，共187例患者
```

## 推断性统计

### 假设检验

| 检验类型 | 用途 | 常用检验 |
|----------|------|----------|
| t检验 | 两组均数比较 | 独立t检验/配对t检验 |
| ANOVA | 三组及以上均数比较 | 单因素/双因素 |
| 卡方检验 | 率的比较/关联性 | Pearson/趋势检验 |
| 非参数检验 | 等级/非正态数据 | Mann-Whitney/Kruskal-Wallis |
| 相关分析 | 两变量关联 | Pearson/Spearman |

### 效应量报告

**必须同时报告**：
- 统计量值（t, F, χ²等）
- 自由度
- P值
- 效应量及95%CI

```
正确示例：
收缩压降低 10 mmHg (95% CI: 6-14)，t(98) = 4.52, P < 0.001, Cohen's d = 0.91
```

### P值正确解读

**禁止**：
- ❌ "P = 0.04 < 0.05，具有统计学意义"
- ❌ "P = 0.06 > 0.05，无统计学意义"
- ❌ 仅报告"P < 0.05"或"P > 0.05"

**正确**：
- ✅ 报告精确P值：P = 0.042
- ✅ 结合效应量解释临床意义
- ✅ 讨论统计显著性与临床意义的区别

### 多重比较校正

当进行多次假设检验时：
- Bonferroni校正
- Benjamini-Hochberg FDR
- 必须说明采用的校正方法

## 回归分析

### 线性回归（连续结局）

```
报告内容：
- β系数及95%CI
- 标准误
- 标准化系数（可选）
- R²/调整R²
- F统计量及P值
```

### Logistic回归（二分类结局）

```
报告内容：
- OR值及95%CI
- 标准误/Wald χ²
- P值
- 模型拟合度（C statistic/Hosmer-Lemeshow）
```

### Cox回归（生存结局）

```
报告内容：
- HR值及95%CI
- 标准误/Wald χ²
- P值
- 生存曲线（KM曲线）
- log-rank检验P值
```

## 样本量与把握度

### 必须报告

- 主要结局的样本量计算
- 预期效应量
- Ⅰ类错误（α，通常0.05）
- Ⅱ类错误或把握度（通常80%）
- 考虑失访的增幅

### 敏感性分析

- 缺失数据处理方法的敏感性
- 极端值排除的敏感性
- 不同模型设定的敏感性

## 诊断准确性研究

### 必需指标

| 指标 | 定义 | 报告格式 |
|------|------|----------|
| 灵敏度 | 真阳性/(真阳性+假阴性) | XX% (95% CI: XX-XX%) |
| 特异度 | 真阴性/(真阴性+假阳性) | XX% (95% CI: XX-XX%) |
| 阳性预测值 | 真阳性/所有阳性 | XX% |
| 阴性预测值 | 真阴性/所有阴性 | XX% |
| 似然比 | 灵敏度/(1-特异度) | X.XX |
| AUC | ROC曲线下面积 | X.XX (95% CI: X.XX-X.XX) |

## Meta分析特有统计

### 效应量合并

- 连续变量：均数差（SMD/MD）、标准化均数差
- 二分类变量：RR、OR、RD
- 必须报告95%CI

### 异质性评估

| 统计量 | 解释 |
|--------|------|
| I² < 25% | 低异质性 |
| I² 25-50% | 中等异质性 |
| I² 50-75% | 高异质性 |
| I² > 75% | 极高异质性 |

### 固定效应 vs 随机效应

- 低异质性(I² < 50%)：固定效应模型
- 高异质性(I² > 50%)：随机效应模型
- 需讨论异质性来源

### 出版偏倚

- 漏斗图
- Egger检验/Begg检验
- Trim-and-fill法

## 软件与方法报告

### 统计分析软件

```
示例：
"所有分析使用Stata version 16.0 (StataCorp, College Station, TX)进行。
Meta分析使用metan命令包，双侧P < 0.05为差异有统计学意义。"
```

### 数据呈现原则

1. **一致性**：同一类型数据使用相同精度
2. **可读性**：大数字添加千分位分隔符
3. **准确性**：计算后四舍五入，避免累计误差
4. **避免误导**：Y轴从零开始，除非有充分理由
