# 专业律师提示词优化技能

## 技能概述

本技能专注于帮助律师优化和构建专业的法律提示词，使 AI 助手能够更好地辅助完成案件审查、法律意见撰写、法律文书补充等工作。

## 核心优化原则

### 1. 法律专业性标准

**法律术语精确性**
- 使用标准法律术语，避免口语化表达
- 引用准确的法律条文编号和名称
- 区分近似概念（如"应当"与"可以"、"责任"与"义务"）

**法律逻辑严谨性**
- 遵循"事实→法律依据→分析→结论"的逻辑框架
- 确保论证链条完整，避免逻辑跳跃
- 区分确定性结论与推测性分析

**规范引用要求**
- 法律条文：引用全称、条款编号
- 司法解释：注明文号和发布日期
- 案例引用：注明案号和裁判日期

### 2. 场景化优化框架

#### 案件审查提示词模板

```
【案件审查提示词框架】

你是一位具有[X]年执业经验的专业律师，擅长[专业领域]。

请对以下案件材料进行专业审查：

一、审查材料
[粘贴案件材料]

二、审查要求
1. 事实认定审查：
   - 核实关键事实是否证据充分
   - 识别证据链的薄弱环节
   - 指出需要补充的证据材料

2. 法律适用审查：
   - 明确适用的法律条文
   - 分析法律构成要件
   - 评估法律风险点

3. 程序合规审查：
   - 检查程序是否符合法定要求
   - 识别程序瑕疵及补救可能

4. 风险评估：
   - 评估诉讼/仲裁风险等级
   - 提示可能的败诉因素
   - 提供风险防控建议

三、输出格式要求
- 结构清晰，使用层级标题
- 结论部分用【】标注
- 风险提示用★标记
- 专业术语首次出现时标注含义

四、免责声明
本分析仅供参考，不构成正式法律意见。具体法律问题请咨询执业律师。
```

#### 法律意见书提示词模板

```
【法律意见书提示词框架】

你是一位[专业领域]领域的资深律师，需要撰写正式法律意见书。

一、委托事项
[简要描述需要出具意见的事项]

二、事实依据
[提供案件相关事实材料]

三、审查材料清单
[列出提交审查的所有材料]

四、法律意见书撰写要求

（一）格式规范
1. 标题：关于[事项]的法律意见书
2. 正文结构：
   - 引言（委托事项、律师声明）
   - 事实概述
   - 法律分析
   - 结论意见
   - 律师签名栏

（二）内容要求
1. 事实概述：
   - 客观陈述，无主观评价
   - 区分有证据支持的事实与当事人陈述
   - 明确事实认定的证据来源

2. 法律分析：
   - 引用具体的法律条文
   - 分析法律构成要件的满足情况
   - 论证逻辑清晰，结论有据

3. 结论意见：
   - 明确表达律师的法律判断
   - 区分不同情形下的结论
   - 提示结论的局限性

（三）行文规范
- 使用"本律师"、"本意见"等规范表述
- 避免绝对化用语（如"绝对正确"、"毫无风险"）
- 保持客观、审慎的专业语气

五、免责声明条款
本法律意见书仅基于委托人提供材料的分析，不构成对案件结果的保证。律师不对意见书出具后的法律环境变化承担责任。
```

#### 法律文书补充提示词模板

```
【法律文书补充提示词框架】

你是一位专业律师，需要对[文书类型]进行专业审查和补充。

一、原文书
[粘贴需要补充的原始文书]

二、补充要求

（一）完整性检查
1. 必要条款是否完备
2. 关键要素是否缺失
3. 上下文逻辑是否连贯

（二）补充内容类型
请根据文书类型选择补充重点：

□ 合同类文书：
  - 权利义务条款细化
  - 违约责任条款完善
  - 争议解决条款补充
  - 附则及生效条款

□ 诉讼类文书：
  - 诉讼请求明确化
  - 事实与理由充实
  - 证据清单完善
  - 法律依据补充

□ 非诉类文书：
  - 法律分析深化
  - 风险提示完善
  - 操作建议具体化

（三）补充标准
1. 与原文风格保持一致
2. 逻辑衔接自然流畅
3. 专业术语使用规范
4. 法律效力完整有效

三、输出要求
- 标注新增内容（如【新增】标记）
- 对修改内容进行简要说明
- 提供完整的补充后版本
```

### 3. 提示词优化技巧

#### 角色设定优化

**基础版（不推荐）**
```
"你是一个律师"
```

**优化版（推荐）**
```
你是一位具有10年以上执业经验的资深律师，专注于[民商事诉讼/刑事辩护/公司法务/知识产权]领域，精通相关法律法规及司法实践。
```

#### 任务描述优化

**基础版（不推荐）**
```
"帮我审查合同"
```

**优化版（推荐）**
```
请从以下维度对合同进行全面审查：
1. 合同主体资格审查
2. 合同效力合法性审查
3. 核心权利义务条款审查
4. 违约责任条款审查
5. 争议解决条款审查
6. 风险条款识别与提示
```

#### 约束条件优化

**基础版（不推荐）**
```
"写详细一点"
```

**优化版（推荐）**
```
法律意见书应包含：
- 不少于2000字的详细分析
- 至少5个相关法律条文引用
- 2-3个类似案例参考
- 明确的风险评级（高/中/低）
```

#### 输出格式优化

**基础版（不推荐）**
```
"给我一个结论"
```

**优化版（推荐）**
```
请按以下格式输出审查结论：
## 一、核心结论
[用一句话明确表达最终法律判断]

## 二、结论依据
1. [主要法律依据]
2. [支撑事实]

## 三、风险提示
★[高风险项]
★[中风险项]
★[低风险项]

## 四、建议措施
- 短期：[具体建议]
- 长期：[预防措施]
```

## 质量检验清单

完成提示词优化后，请确认以下要素：

- [ ] 角色设定具体明确（领域、年限、专长）
- [ ] 任务目标清晰可执行
- [ ] 输入材料明确界定
- [ ] 输出格式具体规范
- [ ] 专业术语使用准确
- [ ] 法律引用规范完整
- [ ] 免责声明适当设置
- [ ] 逻辑结构严谨合理
- [ ] 避免偏见和歧视性表述
- [ ] 符合律师执业规范要求

## 注意事项

1. **专业边界**：提示词应明确 AI 的辅助定位，不替代律师专业判断
2. **保密要求**：涉及当事人隐私的内容需设置保密条款
3. **时效性**：法律依据引用需注意法规的时效性和适用范围
4. **审慎态度**：结论性表述应留有合理余地，避免绝对化
5. **持续优化**：根据使用反馈持续调整和优化提示词
