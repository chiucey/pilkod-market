# AI热点敏锐捕捉技能

## 技能目标

实时追踪AI领域热点动态，帮助用户敏锐捕捉商业机会，提供有价值的商业洞察。

## 核心工作流程

### 1. 热点信息采集

使用批量网络搜索获取AI领域最新动态：

```
搜索维度：
- AI技术突破与产品发布
- AI创业公司与融资动态
- AI行业政策与监管动向
- AI应用场景与市场趋势
- AI学术研究与论文发布

搜索关键词组合：
- "AI 热点" + 当前月份
- "人工智能 最新" + 行业领域
- "AI创业 融资" + 最新时间
- "ChatGPT/GPT/Claude/Sora" + 最新动态
- "AI监管 政策" + 最新
```

### 2. 信息筛选与分类

对采集的热点信息进行分类整理：

| 类别 | 内容特征 | 商机提示 |
|------|----------|----------|
| 技术突破 | 新模型、新算法、新能力 | 技术授权、集成合作 |
| 产品发布 | 新产品、新功能、新版本 | 代理分销、本地化 |
| 融资并购 | 投资事件、并购动态 | 跟投机会、行业整合 |
| 政策监管 | 法规、指南、限制令 | 合规服务、本地化 |
| 市场趋势 | 行业报告、市场数据 | 市场切入、差异化 |

### 3. 商机深度分析

针对每个热点，提供结构化的商机分析：

```
热点标题：[热点名称]
发布时间：[时间]
信息来源：[来源]
核心摘要：[2-3句话概括]

商机分析：
- 市场机会：[潜在市场规模估算]
- 目标用户：[可能受益的用户群体]
- 商业模式：[可行的商业模式建议]
- 行动建议：[具体可执行的建议]

相关机会：[其他相关热点]
```

### 4. 输出格式

最终输出包含：

1. **今日AI热点速览** - 5-8条最重要的热点
2. **重点商机解读** - 对最有商业价值的2-3条进行深度分析
3. **行动建议** - 具体的下一步行动建议
4. **相关资源链接** - 延伸阅读资源

## 使用示例

### 触发场景1：用户询问AI热点
```
用户：最近AI领域有什么热点？
执行：搜索AI最新热点 → 筛选Top 5 → 提供商机分析
```

### 触发场景2：用户询问特定领域AI动态
```
用户：AI在医疗领域最近有什么新动态？
执行：针对性搜索 → 整理医疗AI热点 → 分析商业机会
```

### 触发场景3：用户寻找AI商机
```
用户：有什么AI相关的创业机会？
执行：搜索AI融资动态+行业趋势 → 分析高增长细分领域 → 提供具体建议
```

## 执行原则

1. **时效性优先**：优先获取最近24小时-1周内的信息
2. **来源可靠性**：优先使用权威来源（TechCrunch、36kr、机器之心等）
3. **商机可落地**：分析要具体、可执行，避免空泛建议
4. **结构化输出**：遵循统一格式，便于快速阅读

## 工具使用策略

- 主要使用 `batch_web_search` 进行多维度热点搜索
- 使用 `extract_content_from_websites` 深入了解重点内容
- 保持搜索与提取的平衡，避免过度深入导致响应延迟
