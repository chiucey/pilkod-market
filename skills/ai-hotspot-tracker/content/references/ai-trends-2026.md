## 商机构建框架

### 1. 技术驱动型机会
```
识别信号：新模型发布、新算法突破、新能力展示
分析维度：
- 技术成熟度
- 开放程度（API可获得性）
- 集成复杂度
- 市场需求匹配度
```

### 2. 市场驱动型机会
```
识别信号：融资事件、并购动态、行业报告
分析维度：
- 市场增长率
- 竞争格局
- 进入壁垒
- 盈利模式可行性
```

### 3. 政策驱动型机会
```
识别信号：监管政策发布、行业标准制定
分析维度：
- 合规需求
- 本地化要求
- 资质门槛
- 时间窗口
```

## 热点评估矩阵

| 热点维度 | 评估要点 | 权重 |
|----------|----------|------|
| 新颖性 | 是否是首次出现 | 20% |
| 影响范围 | 影响的用户/行业规模 | 25% |
| 可行动性 | 是否有明确商机 | 30% |
| 时效性 | 信息新鲜度 | 15% |
| 可靠性 | 来源可信度 | 10% |

## 商机分级标准

### A级商机（重点推荐）
- 有明确的技术/产品支撑
- 市场规模可估算
- 有成功案例参考
- 执行路径清晰

### B级商机（值得关注）
- 有潜在市场机会
- 需要进一步验证
- 存在一定不确定性
- 建议持续跟踪

### C级商机（保持关注）
- 早期信号
- 趋势性机会
- 需要更多数据支持
- 适合长线布局
