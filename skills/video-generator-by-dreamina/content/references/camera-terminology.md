# 景别与运镜术语参考表

## 景别术语

| 术语 | 符号标注 | 说明 | 适用场景 |
|------|----------|------|----------|
| 大远景 | 【大远景】 | 极其广阔的视野，常用于展示大自然、城市全景 | 开场、航拍、自然风光 |
| 远景 | 【远景】 | 大范围场景，人物占画面很小比例 | 展示环境、建立空间感 |
| 全景 | 【全景】 | 展现完整场景/人物全貌 | 展示完整动作、环境关系 |
| 中全景 | 【中全景】 | 人物从头到脚，但周围环境较多 | 舞蹈、全身动作 |
| 中景 | 【中景】 | 膝盖以上 | 日常对话、人物交互 |
| 中近景 | 【中近景】 | 腰部到大腿区域 | 强调手势、道具使用 |
| 近景 | 【近景】 | 胸部到头部 | 表情变化、情感表达 |
| 特写 | 【特写】 | 脸部或局部细节 | 眼神、微妙表情 |
| 大特写 | 【大特写】 | 眼睛、嘴唇、手部等 | 极致情感细节 |

| 术语 | 符号标注 | 说明 | 视觉效果 |
|------|----------|------|----------|
| 推 | 【推】 | 镜头向前推进 | 聚焦、强调、紧张感 |
| 拉 | 【拉】 | 镜头向后拉远 | 揭示、放松、孤独感 |
| 摇 | 【摇】 | 镜头左右/上下摇动 | 环顾、跟随、扫描 |
| 移 | 【移】 | 镜头平行移动 | 行走感、探索感 |
| 跟 | 【跟】 | 镜头跟随主体移动 | 代入感、参与感 |
| 升 | 【升】 | 镜头向上移动 | 升华、希望、胜利 |
| 降 | 【降】 | 镜头向下移动 | 下降、压抑、深入 |
| 甩 | 【甩】 | 快速摇动切换 | 快速转场、激烈情绪 |
| 固定 | 【固定】 | 镜头固定不动 | 稳定、观察、等待 |
| 环绕 | 【环绕】 | 镜头绕主体旋转 | 强调、神秘、突出 |
| 倾斜 | 【倾斜】 | 镜头倾斜拍摄 | 失衡、醉意、紧张 |
| POV | 【POV】 | 主观视角/第一视角 | 沉浸、代入 |
