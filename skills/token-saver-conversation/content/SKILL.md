# Token 节约大师 - 对话生成器

## 核心理念

在AI对话中，**信息密度 > 字数多少**。一个好的Prompt应该用最少的Token传达最多的有效信息。

---

## 黄金法则

### 1. 删除一切冗余词汇

❌ 错误示例：
```
"请帮我写一段非常详细的、包含很多细节的、关于如何学习编程的文章"
```

✅ 正确示例：
```
"写一篇编程学习指南"
```

### 2. 使用明确的指令词

| 冗余表达 | 精简表达 |
|---------|---------|
| "请帮我" | 直接说需求 |
| "可以吗？" | 直接说需求 |
| "麻烦你" | 直接说需求 |
| "非常感谢" | 删掉 |
| "请问一下" | 直接问 |

### 3. 利用上下文和指代

❌ 错误示例：
```
"我想要学习Python，我想学Python的语法，我还想学Python的数据结构"
```

✅ 正确示例：
```
"学习Python语法和数据结构"
```

### 4. 使用结构化简写

| 完整表达 | 简写 |
|---------|------|
| "首先...其次...最后..." | 简化为关键点 |
| "包括以下几点" | 用列表 |
| "例如" | 用"如" |
| "也就是说" | 用"即" |

## 场景模板

### 通用模板
```
[角色/身份] + [任务] + [约束条件(可选)] + [输出格式(可选)]

示例：
"充当Python导师，教我装饰器用法，给出代码示例"
```

### 代码相关
```
[语言] + [任务] + [要求]

示例：
"JS写一个防抖函数，ES6语法"
"Py实现快速排序，含注释"
```

### 写作相关
```
[类型] + [主题] + [风格/长度]

示例：
"写一封辞职邮件，专业，50字内"
"创作一个科幻短故事，500字"
```

### 问答相关
```
[问题]？

示例：
"为什么天空是蓝色的？"
"量子计算原理？"
```

## 实战技巧

### 1. 使用比喻和类比
```
❌ "我想了解计算机是如何进行计算的，包括CPU、内存、硬盘等各个部件的工作原理"
✅ "解释计算机工作原理，打比方"
```

### 2. 要求AI直接回答
```
❌ "请详细说明并举例，然后总结，最后给建议"
✅ "直接给建议+举例"
```

### 3. 限制输出长度
```
❌ "请详细描述..."
✅ "用3句话说..."
✅ "100字内解释..."
```

### 4. 善用否定句
```
❌ "不要写得太长，不要有太多专业术语，不要太复杂"
✅ "说人话，50字内"
```

### 5. 复用之前的上下文
```
首次："分析奶茶店选址，考虑人流量、租金、竞争对手"
追问："加入竞争分析"
```

## 常见场景极速生成

### 1. 翻译
```
中英互译：[原文] → [目标语言]

示例：
"翻译：人工智能将改变世界 → 英"
```

### 2. 总结
```
总结：[长文本] → [长度]

示例：
"总结这篇3000字文章 → 3点"
```

### 3. 解释概念
```
解释：[概念] → [难度/长度]

示例：
"解释区块链 → 说人话，2句"
```

### 4. 写代码
```
[语言]：[功能描述]

示例：
"Py：读取CSV，计算平均值，输出top5"
```

### 5. 润色
```
润色：[原文] → [风格]

示例：
"润色：我觉得这个产品很好用 → 商务"
```
