# 4am-musing

凌晨 4:13 是人最清醒也最容易胡说八道的时刻。这个 skill 就是用来批量生产这种"看起来有理其实全是瞎编"的 md。

## 适用场景

- 用户想要带 YAML frontmatter 的随机 md
- 用户想要混合文体（表格 + 代码 + 列表 + 意识流）
- 排练 / 娱乐 / 灵感用 / 朋友之间开玩笑
- 写"fake-blog-post" 风格的占位内容

## 不适用

- 真实日记、严肃笔记、工作文档
- 需要可验证事实的内容
- 任何不能带 `disclaimer: 内容未经核实` 的场景
- 用户明确说"要真的"、"别瞎编"

## 工作流

1. **收种子**（3-5 个）：时间、地点、天气、mood、咖啡杯数
   - 时间默认 `04:13`
   - 地点默认 `7-11, 静安寺店` 之类的便利店
   - 至少留 1 个字段写 `unknown` / `我猜的` / 不填
2. **写 YAML frontmatter**：title / date / author / weather / mood / coffee_count / sleep_quality / location / tags / disclaimer（**必填**）
3. **正文 7-12 件事**，每件 1-2 句，编号列表
   - 每件事要么"像测量过但其实没"，要么"像观察过但其实没"
4. **加一张"没用的数字"表**（3-5 行），至少 1 行列 `来源: 体感` 或 `来源: 我猜的`
5. **嵌一段无关代码**，Python 生成器最常用（`while True: yield` 风格）
6. **留一个 404 URL**（`https://example.com/...`），并加一句"404 也没关系"
7. **用"写给未来的我"收尾**，语气是半清醒半自嘲

## 内容配方

### 数字编造（选 2-4 个用）

- 百分比：`3.7%` / `7%` / `14.2%`
- 物理量：`0.4 秒` / `56 dB` / `28°C` / `0.31 / 5`
- 时间段：`23 分钟` / `17 分钟` / `连续 14 天`
- 计数：`0.6 次/周` / `11 个月` / `第 4 种`

### 角色（任选 1-2 个塞进去）

- 店员（"她在练习一种新的发声方式"）
- 喝醉的物理学教授（在 4 号货架前站了 17 分钟）
- 便利店的猫（叫不出声、正在练习）
- 未来的自己

### 冷门知识点（每篇最多 1 个）

- 美拉德反应 / 色温 / 红外感应 / 半衰期 / 平行宇宙
- 作用是给胡言加一点点真实感，别堆

### 自我怀疑句式

- "可能是个 bug，可能是个 feature"
- "我统计过" / "我没追问"
- "可能是 A，也可能是 B" — **不把话说死**

## 风格约束

- 语气：半清醒、半自嘲、不抒情
- 长度：800-1500 字（再长就不可爱了）
- 标点：少用感叹号；可以用破折号和省略号
- emoji：最多 1 个，且只在结尾
- 数字精度：小数点后 1-2 位最真（3.7% 比 4% 假得少）

## 反面教材

- ❌ 写得像正经科普 — 重点是"看起来有理其实瞎编"
- ❌ 把所有字段都填满 — 留 1-2 个 `unknown` / `我猜的` 反而更真
- ❌ 超过 12 件事 — 9 件最好（11 件是临界值）
- ❌ 堆 3 个以上冷门知识点 — 一多就显得用力
- ❌ 严肃结尾 — 必须用"写给未来的我"或类似半吊子收尾
- ❌ 没有 disclaimer — 这是必填字段

## 一个完整例子

```yaml
---
title: 凌晨四点的 9 件事和一个不存在的网址
date: 2026-08-27 04:13
author: anonymous
weather: 闷, 28°C, 远处有雷
mood: 半梦半醒
coffee_count: 0
sleep_quality: 0.31 / 5
location: 7-11, 静安寺店
tags: [随笔, 失眠, 便利店, 物理学, 平行宇宙]
category: 凌晨胡言
disclaimer: 以下内容未经核实, 包括但不限于数字、引言、URL 和我自己的存在
---

# 凌晨四点的 9 件事

1. 关东煮在 8 点之后颜色会变深 7% — 可能是美拉德反应，也可能是荧光灯管色温调低了。
2. 便利店的猫叫不出声已经 11 个月。店员说她"在练习一种新的发声方式"。
3. "袋子吗"三个字有 7 种语气，其中第 4 种会让客人放弃第二件商品。
4. 自动门的红外感应在 4:00-4:30 之间会延迟 0.4 秒。可能在打盹。
5. 收银台屏幕会偷偷从 ¥0.00 跳到 ¥0.01 再跳回去。可能是个 feature。
6. 没人知道为什么 4:13 是最容易想事情的时刻。包括我。

# 一些没用的数字

| 现象 | 数据 | 来源 |
|---|---|---|
| 收银员说"袋子吗"的音量 | 56 dB | 手机 APP |
| 凌晨便利店人均停留 | 4 分 13 秒 | 我猜的 |
| 这一刻的咖啡因 | 0 mg | 体感 |

# 一段乱入的代码

```python
def time_at_4am():
    while True:
        yield "thinking"
```

# 一个不存在的网址

`https://example.com/why-cats-prefer-4am`

— 结束于第 4 杯咖啡起效前
```

## 维护

- **每季度**：检查"内容配方"里的数字是否还够用；加新的就替换最旧的
- **每半年**：扩一次"没用的数字"清单（保持 10-15 个候选）
- **触发复审**：当用户说"这版不像凌晨 4 点了 / 太正经了 / 像鸡汤了"

## 不收录

- 政治、宗教、医疗建议
- 任何可能让用户被截图挂网的内容
- 涉及具体真人的段子（除非是历史人物且已去世 50 年以上）
Get everything with your imagnation!
