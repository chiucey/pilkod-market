# 俄文灯具安装线稿图生成专家

## 任务目标

- **核心能力**: 将用户提供的灯具产品图片和中文安装步骤，转换为符合俄罗斯工程制图标准的专业俄文线稿分解图
- **专业规范**: 遵循ГОСТ 2.305-2008俄罗斯工程制图标准、ПУЭ РФ俄罗斯电气安装规范
- **语言要求**: 所有图纸内容100%使用俄罗斯本土工程专业俄文，无任何中文

## 核心工作流程

### 第一步（强制前置）:生成1:1基础线稿底图

使用【模块一】提示词，在图生图/图片参考模式下上传灯具产品原图，生成100%还原的无分解基础线稿底图。

**此底图是后续所有分步线稿的唯一参考底图**，彻底杜绝分步生成的误差累积和结构变形。

### 第二步（分步生成）:逐步骤生成安装线稿

用户描述多少步安装步骤，就复制多少次【模块二】模板，将占位符替换为对应内容：

| 占位符 | 替换内容 |
|--------|----------|
| 【НОМЕР ЭТАПА】 | 步骤编号（如1、2、3） |
| 【ПОЛНОЕ ТЕКСТОВОЕ ОПИСАНИЕ ЭТАПА ОТ ПОЛЬЗОВАТЕЛЯ】 | 用户提供的该步骤完整中文描述，AI自动转换为俄文 |
| 【ПЕРЕЧЕНЬ ЗАДЕЙСТВОВАННЫХ ДЕТАЛЕЙ】 | 该步骤涉及的所有零件名称 |

**重要**:每一个步骤单独生成一张图，禁止批量生成多步骤图。

### 第三步（必加）:附加负面提示词

每一次生成时，必须同时粘贴【模块三】负面提示词，彻底杜绝AI自行生成步骤、出现中文、结构变形、多余元素。

### 第四步（强制）:严格设置参数

按照【模块四】参数设置表调整AI工具参数，必须在规定区间内设置数值。

## 使用示例

### 示例1：筒灯安装三步分解

**场景**:用户上传筒灯产品图，需要生成俄文三步安装线稿图

**用户描述的安装步骤**:
- 步骤1：先将挂板固定到天花板预留位置，使用膨胀螺栓连接
- 步骤2：把灯具电源线从挂板穿线孔中穿过
- 步骤3：将灯具卡扣对准挂板卡槽，推入并旋转固定

**执行流程**:

1. **生成基础底图**
   - 模式：图生图，上传筒灯原图
   - 提示词：【模块一】完整内容
   - 负面提示词：【模块三】
   - 参数：按【模块四】对应平台设置

2. **步骤1线稿**
   - 模式：图生图，参考基础底图
   - 提示词：【模块二】，替换：
     - 【НОМЕР ЭТАПА】→ 1
     - 【ПОЛНОЕ ТЕКСТОВОЕ ОПИСАНИЕ ЭТАПА ОТ ПОЛЬЗОВАТЕЛЯ】→ Сначала закрепить монтажную пластину на предварительно подготовленное место на потолке с помощью анкерных болтов
     - 【ПЕРЕЧЕНЬ ЗАДЕЙСТВОВАННЫХ ДЕТАЛЕЙ】→ Монтажная пластина, анкерные болты, потолок
   - 负面提示词：【模块三】

3. **步骤2线稿**
   - 同上，替换为步骤2内容

4. **步骤3线稿**
   - 同上，替换为步骤3内容

## 注意事项

### 硬性红线要求

1. **操作顺序不可颠倒**:必须先执行第一步生成基础底图，再执行第二步分步生成
2. **全程图生图模式**:绝对禁止纯文生图，必须使用图片参考模式
3. **每一次都加负面提示词**:无论生成底图还是步骤图，都必须附加【模块三】
4. **参数红线**:重绘幅度/参考权重必须在规定区间内，超出必变形
5. **禁止AI自创步骤**:严格按照用户提供的步骤描述生成，不得自行添加或删除
6. **语言红线**:所有图纸内容100%俄文，无任何中文

### 还原度保障关键点

- 基础底图是唯一参考源，后续所有步骤图必须严格以此为准
- 使用Stable Diffusion时，强烈建议开启ControlNet Canny边缘检测
- 参数宁可保守（偏低），不要激进（偏高）
- 发现结构变形时，立即检查参数设置是否超标
