# 分析框架参考

## 经济型数据分析框架

### 零售经济

**适用场景**: 电商、门店销售、订单数据

**核心指标**:
- GMV (Gross Merchandise Value)
- 客单价
- 转化率
- 复购率

**分析方法**:
- **RFM 分析**: Recency, Frequency, Monetary
- **ABC 分类**: 按销售额/利润分类商品
- **XYZ 分析**: 按波动性分类商品
- **价值链分析**: 采购→库存→销售→售后

**推荐问题**:
- 哪些是高价值客户？
- 商品销售趋势如何？
- 库存周转情况？

### 订阅经济

**适用场景**: SaaS、会员制、订阅服务

**核心指标**:
- MRR (Monthly Recurring Revenue)
- ARR (Annual Recurring Revenue)
- Churn Rate
- LTV (Lifetime Value)
- CAC (Customer Acquisition Cost)

**分析方法**:
- **Cohort 分析**: 按时间分组分析留存
- **留存曲线**: 随时间的用户留存情况
- **LTV 预测**: 用户生命周期价值预测
- **流失预测**: 识别高流失风险用户

**推荐问题**:
- 订阅流失率是多少？
- 用户留存情况如何？
- 如何提升 LTV？

### 注意力经济

**适用场景**: App 用户行为、广告点击、内容消费

**核心指标**:
- DAU / MAU
- 会话时长
- 转化率
- 点击率 (CTR)

**分析方法**:
- **AARRR 漏斗**: Acquisition → Activation → Retention → Referral → Revenue
- **漏斗分析**: 各步骤转化率
- **路径分析**: 用户行为序列
- **归因分析**: 转化来源归因

**推荐问题**:
- 用户转化漏斗哪里流失最多？
- 用户主要行为路径是什么？
- 哪些因素影响转化？

### 金融时序

**适用场景**: 股票价格、交易数据、财务指标

**核心指标**:
- OHLCV (Open, High, Low, Close, Volume)
- 收益率
- 波动率
- 夏普比率

**分析方法**:
- **技术分析**: K线、移动平均、MACD、RSI
- **波动率建模**: GARCH、EWMA
- **趋势分析**: 趋势线、支撑阻力
- **风险分析**: VaR、CVaR

**推荐问题**:
- 价格趋势是什么？
- 波动率如何变化？
- 风险敞口多大？

## 非经济型数据分析框架

### 科学测量

**适用场景**: 传感器数据、实验数据、监测数据

**核心指标**:
- 测量值范围
- 误差范围
- 置信区间

**分析方法**:
- **时序分解**: 趋势、季节、残差
- **极值分析**: 最大值、最小值、阈值检测
- **假设检验**: t检验、ANOVA
- **不确定性分析**: 误差传播

**推荐问题**:
- 数据是否符合预期分布？
- 存在哪些异常测量？
- 趋势和季节性如何？

### 社交网络

**适用场景**: 社交关系、合作网络、引用网络

**核心指标**:
- 度中心性
- 介数中心性
- 聚类系数
- 社区规模

**分析方法**:
- **中心性分析**: 识别关键节点
- **社区发现**: Louvain、Girvan-Newman
- **网络传播**: 信息/谣言传播模型
- **链接预测**: 预测未来关系

**推荐问题**:
- 谁是最重要的节点？
- 网络如何划分社区？
- 信息如何传播？

### 文本分析

**适用场景**: 评论、社交媒体、文档

**核心指标**:
- 词频
- 情感得分
- 主题分布

**分析方法**:
- **主题模型**: LDA、NMF
- **情感分析**: 正面/负面/中性
- **关键词提取**: TF-IDF、TextRank
- **文本分类**: 监督学习分类

**推荐问题**:
- 主要讨论主题是什么？
- 情感倾向如何？
- 关键词有哪些？

## 问题类型判定

| 问题类型 | 关键词 | 数据要求 | 推荐方法 |
|---------|--------|---------|---------|
| 描述型 | 现状、分布、特征 | 代表性样本 | 描述统计、可视化 |
| 诊断型 | 为什么、原因、归因 | 多维度对比 | 相关分析、回归分解 |
| 预测型 | 预测、未来、预警 | 历史数据 | 时序预测、机器学习 |
| 规范型 | 最优、应该、策略 | 行动-结果映射 | 优化模型、AB测试 |
| 因果型 | 因果、影响、效果 | 对照组/时间变化 | 因果推断、实验设计 |

## 选择框架的决策树

```
数据包含价格/收入/订单？
├── 是 → 经济型数据
│   ├── 有时间序列？→ 金融时序分析
│   ├── 有用户ID和复购？→ RFM + LTV
│   ├── 有事件序列？→ 漏斗分析
│   └── 通用 → 价值链分析
│
└── 否 → 非经济型数据
    ├── 连续测量？→ 时序分解
    ├── 有关系网络？→ 社交网络分析
    ├── 文本数据？→ NLP分析
    └── 其他 → 通用EDA
```
