## viral-topic-finder（爆款选题与标题生成）

`viral-topic-finder` 是一个用于**挖掘高流量具体选题**并**批量生成爆款标题**的 skill。它会先根据你给出的方向拆解出 3-5 个可落地的细分选题，再为每个选题产出 5 个标题变体（如果用户有要求，可以动态调整），并明确标题所用的“爆款标题原则”组合。

为了避免标题模板化，本 skill 会对“数字清单式标题”（如“3个/5步/7条”）做**占比限制**，并强制同一选题的多个标题在句式与结构上保持明显差异。

对应的 skill 定义见 `SKILL.md`。

## 适用场景

- **内容创作/自媒体运营**：需要持续产出选题与标题（公众号/小红书/知乎/短视频脚本标题等）
- **写作前选题**：只有一个大方向，不知道写什么更容易获得点击
- **标题优化**：已有内容框架，但标题不够抓人，需要多套可 A/B 测试的标题

## 你提供什么信息效果最好

最少只需要一句“选题方向”，但建议补充：

- **选题方向**：领域/主题（如“个人成长”“AI 工具”“职场”“育儿”“理财”）
- **目标受众**：新手/进阶、年龄段、身份（如“25-35 岁一线城市上班族”）
- **平台**：公众号/小红书/知乎/B站/短视频等（不同平台标题风格不同）
- **内容类型**：教程/观点/故事/清单/对比/测评等
- **限制条件**：字数、禁用词、是否要更克制/更冲击、是否避免夸张

## 输出是什么样

skill 会按以下结构输出（完整格式在 `SKILL.md` 的“输出格式”章节）：

- **每个选题方向给 3-5 个具体选题建议**
- **每个选题给 5 个标题变体**（如果用户有要求，可以动态调整）
- **每个标题标注使用的原则编号**，方便你复用/迭代

## 注意事项

- **真实性**：标题与内容必须匹配，避免标题党
- **受众匹配**：同一选题对不同人群的“痛点/利益点”不同，先明确目标受众
- **平台适配**：公众号/小红书/知乎等标题偏好不同，建议明确平台再生成
- **A/B 测试**：同一选题保留多标题版本，发布前后对比点击与完读数据
