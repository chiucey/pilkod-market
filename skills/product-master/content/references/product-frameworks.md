# 产品分析框架汇总

## 一、战略规划类框架

### 1.1 波特五力模型（Porter's Five Forces）
用于分析行业竞争态势和吸引力。

**五力要素**：
- 现有竞争者的竞争强度
- 新进入者的威胁
- 替代品的威胁
- 供应商的议价能力
- 购买者的议价能力

**适用场景**：市场进入决策、行业分析

### 1.2 SWOT分析
 Strengths（优势）、Weaknesses（劣势）、Opportunities（机会）、Threats（威胁）

**优势-劣势矩阵**：
| 内部因素 | 积极 | 消极 |
|---------|------|------|
| 有利 | S-O策略（增长） | W-O策略（改进） |
| 不利 | S-T策略（多元化） | W-T策略（收缩/防御） |

### 1.3 商业画布（Business Model Canvas）
描述企业创造、传递和获取价值的方式。

**九大模块**：
1. 客户细分（Customer Segments）
2. 价值主张（Value Propositions）
3. 渠道通路（Channels）
4. 客户关系（Customer Relationships）
5. 收入来源（Revenue Streams）
6. 核心资源（Key Resources）
7. 关键业务（Key Activities）
8. 关键合作（Key Partnerships）
9. 成本结构（Cost Structure）

## 二、产品规划类框架

### 2.1 精益画布（Lean Canvas）
针对初创企业的商业画布变体。

| 板块 | 内容 |
|-----|------|
| 问题 | Top 3问题 |
| 客户细分 | 目标客户 |
| 独特价值主张 | 啊哈时刻 |
| 解决方案 | Top 3功能 |
| 渠道 | 触达路径 |
| 收入来源 | 定价模式 |
| 成本结构 | 固定/可变成本 |
| 关键指标 | 核心指标 |
| 不公平优势 | 护城河 |

### 2.2 波特价值链
分析企业价值创造活动的工具。

**支持活动**：基础设施、人力资源、技术开发、采购
**主要活动**：入站物流、运营、出站物流、营销销售、服务

### 2.3 安索夫矩阵（Ansoff Matrix）
市场扩张与产品开发的二维矩阵。

| | 现有产品 | 新产品 |
|--|---------|--------|
| **现有市场** | 市场渗透 | 产品开发 |
| **新市场** | 市场开发 | 多元化 |

## 三、需求优先级类框架

### 3.1 RICE评分法
量化需求优先级的框架。

**公式**：RICE = (Reach × Impact × Confidence) / Effort

| 维度 | 说明 | 取值范围 |
|-----|------|---------|
| Reach（覆盖） | 影响的用户数/季度 | 数值 |
| Impact（影响） | 对用户的影响程度 | 0.25/0.5/1/2/3 |
| Confidence（信心） | 估算的确定性 | 50%/80%/100% |
| Effort（工作量） | 人力月数 | 数值 |

### 3.2 MoSCoW法则
需求分类方法。

| 分类 | 含义 | 建议占比 |
|-----|------|---------|
| Must have | 必须有 | 60% |
| Should have | 应该有 | 20% |
| Could have | 可以有 | 15% |
| Won't have | 不会有 | 5% |

### 3.3 Kano模型
用户需求分类模型。

**需求类型**：
- **基本型需求**：必须有，否则严重不满
- **期望型需求**：越满足越满意
- **兴奋型需求**：出乎意料，超越期望
- **无差异需求**：有或无无影响
- **反向需求**：有反而不满

## 四、增长分析类框架

### 4.1 AARRR漏斗模型
海盗指标，衡量产品增长。

| 阶段 | 指标 | 说明 |
|-----|------|------|
| Acquisition | 获取 | 用户如何发现产品 |
| Activation | 激活 | 用户是否首次体验到价值 |
| Retention | 留存 | 用户是否持续使用 |
| Referral | 推荐 | 用户是否推荐他人 |
| Revenue | 收益 | 如何变现 |

### 4.2 增长飞轮（Growth Flywheel）
持续增长的动力模型。

```
更好的体验 → 更多的用户 → 更多的数据 → 更好的算法/产品 → 更好的体验
```

### 4.3 RFM模型
用户价值分析模型。

| 维度 | 说明 |
|-----|------|
| Recency | 最近一次消费 |
| Frequency | 消费频率 |
| Monetary | 消费金额 |

**用户分层**：
- 高价值用户：R高+F高+M高
- 潜力用户：R低+F高+M高
- 流失风险用户：R低+F低+M高
- 低价值用户：R低+F低+M低

## 五、用户体验类框架

### 5.1 HEART模型
Google的用户体验度量框架。

| 维度 | 说明 | 指标示例 |
|-----|------|---------|
| Happiness | 满意度 | NPS、CSAT |
| Engagement | 参与度 | DAU/MAU、使用时长 |
| Adoption | 采纳率 | 新用户激活率 |
| Retention | 留存率 | 次日/7日/30日留存 |
| Task Success | 任务完成 | 完成率、错误率 |

### 5.2 用户体验地图（Customer Journey Map）
可视化用户与产品交互的全过程。

**核心要素**：
- 用户阶段
- 用户行为
- 用户触点
- 用户情绪
- 痛点与机会
- 改进方向

### 5.3 用户故事地图（User Story Mapping）
以用户故事为主线的需求梳理工具。

**结构**：
```
[用户角色] - [用户目标] - [用户任务] - [用户故事]
```

## 六、决策分析类框架

### 6.1 四象限决策法
快速决策工具。

| | 影响大 | 影响小 |
|--|--------|--------|
| **紧急** | 立即做（重要紧急） | 委托做（紧急不重要） |
| **不紧急** | 计划做（重要不紧急） | 删除做（既不紧急也不重要） |

### 6.2 决策树分析
量化决策选项的期望值。

**步骤**：
1. 定义决策点
2. 识别可能事件
3. 估算概率和结果
4. 计算期望值
5. 选择最优方案

### 6.3 六顶思考帽
全面思考问题的方法。

| 帽子 | 颜色 | 角色 |
|-----|------|------|
| 信息帽 | 白色 | 事实、数据 |
| 情感帽 | 红色 | 直觉、感觉 |
| 悲观帽 | 黑色 | 风险、问题 |
| 乐观帽 | 黄色 | 价值、收益 |
| 创意帽 | 绿色 | 创意、新想法 |
| 过程帽 | 蓝色 | 思考过程控制 |
