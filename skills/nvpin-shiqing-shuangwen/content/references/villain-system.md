## 核心欠揍准则（全程必守）

1. **踩底线**：恩将仇报、抢女主心血/爱人、拿女主最在意的人/事开刀（羞辱家人、毁掉事业）
2. **极致双标**：自己阴人抢功叫「有本事」，女主反击叫「你怎么这么恶毒小心眼」
3. **又菜又装**：实力全靠蹭女主/抱大腿，却当众装逼踩女主，人越多越不给面子，欺软怕硬只敢捏女主这个「软柿子」

## 绝对避崩红线（全程必守）

- **禁止把反派写得太强太有逻辑**：反派越强读者只会怕不会想揍；必须是「实力一般，脾气极大，本事没有，装逼第一」
- **禁止给反派加洗白光环**：短篇爽文不需要有魅力的反派，只需要「贱得很具体」的小人，洗白会消解全部爽感

## 三维反派生成公式

每次从以下三个维度各选1项组合，生成独特的反派人设：

### 维度一：核心身份（绑定冲突场景）

| 身份类型 | 具体角色 |
|----------|----------|
| 婚姻线 | 出轨丈夫、偏心婆婆、搅事小姑子 |
| 亲情线 | 重男轻女亲妈、吸血亲哥/弟、扶弟魔姐姐 |
| 职场线 | 抢功同事、甩锅领导、背刺下属、竞品内鬼 |
| 友情线 | 背刺闺蜜、两面派发小、嫉妒心强的朋友 |

组合规则：1个反派可绑定1-2个身份，如「出轨丈夫+职场甩锅领导」双重身份叠加作恶

### 维度二：作恶核心动机（决定作妖逻辑）

| 动机类型 | 行为逻辑 |
|----------|----------|
| 嫉妒型 | 见不得女主过得好，女主拥有的都想抢 |
| 利己型 | 纯纯精致利己，牺牲女主换自己的利益/前途 |
| 补偿型 | 原生家庭缺爱/穷怕了，靠掠夺女主填补自己 |
| 裹挟型 | 被家人/情人胁迫，不得不对女主作恶 |
| 赌徒型 | 一次作恶没被发现，越陷越深，只能往死里踩女主 |

组合规则：1个反派仅锁定1个核心动机，所有作妖行为围绕动机展开，避免人设分裂

### 维度三：致命弱点（决定打脸破防点）

| 弱点类型 | 打脸命中方式 |
|----------|--------------|
| 爱面子 | 最怕当众社死、人设崩塌 |
| 怕担责 | 一出事就甩锅，最怕承担法律/经济责任 |
| 缺靠山 | 所有底气来自蹭来的身份/关系，最怕靠山倒台 |
| 有黑料 | 过往有见不得人的秘密，最怕被公之于众 |
| 玻璃心 | 表面嚣张，实则内心自卑，一戳就破 |

组合规则：打脸环节必须精准命中反派的致命弱点，而非泛泛拆穿，爽感翻倍且不重复
