# 女频短篇世情爽文写作

## 任务目标
- 本 Skill 用于：按全流程公式生成女频短篇世情爽文的完整大纲与正文
- 能力包含：差异化变量组合、反派三维生成、五模块大纲构建、钩子与爽点锚点校验、正文写作
- 触发条件：用户要求写世情爽文、生成复仇打脸故事大纲、撰写婚姻/婆家/职场题材爽文

## 硬性铁则（全程必守）

1. **视角与人称**：全程女主第一人称「我」，无上帝视角，所有信息/情绪/动作通过女主感官传递
2. **角色命名**：全角色强制三字姓名，规避「苏/顾/林/江」等高频姓氏，选用低重复率姓氏+用字（详见 [references/naming-pools.md](references/naming-pools.md)）
3. **赛道定位**：婚姻背叛、重男轻女、婆家吸血、职场背刺、道德绑架等女性代入的世情场景
4. **爽感底层逻辑**：反派越欠揍 → 打脸越炸裂；每1000字设1个反派作妖点+1个钩子，每3000字完成1次小爽点爆发，10000-12000字完成全闭环大爽局
5. **总字数**：10000-12000字，分5个固定模块，每章约1000字
6. **书名要求**：15字左右，3秒内答出：女主是谁、这是什么故事、能获得什么情绪价值
7. **行文风格**：短句为主，每句不超20字；对话贴合人设、直白带情绪；每段为爽点服务

## 大纲生成 SOP

严格按以下6步执行，确保每次生成的大纲100%差异化且符合所有铁则：

### 第一步：变量组合锁定
从差异化创作开关中随机选择一组不重复的组合，确保与上一次组合重合度不超过30%：
- 调性开关 3选1
- 女主人设开关 4选1
- 核心冲突母题 6大母题选1-3个
- 爽感类型开关 5选2
- 男主定位开关 4选1

详细选项见 [references/differentiation-switches.md](references/differentiation-switches.md)

### 第二步：核心角色生成
从三字姓名生成池中生成女主、男主、核心反派、配角助攻的姓名：
- 全三字名、避高频姓氏、同一故事内无同音字/形近字
- 女主与男主不同姓；反派与主角名读音不近

详细姓氏/用字池见 [references/naming-pools.md](references/naming-pools.md)

### 第三步：反派设定与作妖路径
1. 用「三维反派生成公式」锁定反派：核心身份 → 作恶核心动机 → 致命弱点
2. 从「阶梯作妖变量池」选择3轮适配的作妖类型（试探越界 → 戳痛处 → 釜底抽薪）
3. 确定反派的完整作恶路径

详细公式与变量池见 [references/villain-system.md](references/villain-system.md)

### 第四步：分模块剧情大纲生成
按5个模块的核心锚点，从每个模块的「可插拔剧情单元池」中选择适配的剧情单元，填充完整大纲，严格控制总字数10000-12000字：

| 模块 | 字数 | 核心锚点 |
|------|------|----------|
| 模块一：导语 | 200字 | 开篇炸场+第一层钩子锁死 |
| 模块二：正文 | 2000字 | 反派3轮阶梯作妖+女主暗收底牌+第二层钩子 |
| 模块三：卡点付费 | 3000字 | 初轮打脸+爽感爆发+第四层钩子锁付费 |
| 模块四：高潮 | 3000字 | 全维度碾压+爽感顶峰+反派跪地求饶 |
| 模块五：大结局 | 4000字 | 反派彻底凉凉+女主圆满登顶+伏笔闭环 |

每个模块的核心锚点、可插拔剧情单元池、避坑红线见 [references/module-formula.md](references/module-formula.md)

### 第五步：钩子与爽点锚点校验
校验大纲是否符合节奏要求：
- 每1000字1个冲突/钩子
- 每3000字1个小爽点
- 10000-12000字全闭环大爽局
补齐遗漏的钩子和爽点

4层钩子体系详见 [references/villain-system.md](references/villain-system.md) 的钩子部分

### 第六步：合规性校验
对照避坑红线总表，校验大纲是否符合所有硬性规则，修正违规内容

完整红线表见 [references/red-lines.md](references/red-lines.md)

## 正文写作流程

大纲通过校验后，按以下顺序撰写正文：

1. **撰写书名**：15字左右，体现人设+题材+情绪价值
2. **撰写导语**（200字）：无铺垫直甩最高冲突名场面，反派1句话踩欠揍点，女主仅用细节埋反击伏笔，结尾留白狠话拉满期待
3. **撰写正文**（2000字，约2章）：反派3轮阶梯作妖，女主表面隐忍暗中收底牌，铺垫「全世界等女主完蛋」氛围
4. **撰写卡点付费**（3000字，约3章）：助攻配角登场补关键证据，女主选人最多场景小试牛刀放30%底牌，反派首次吃瘪反差拉满，卡点钩子锁付费
5. **撰写高潮**（3000字，约3章）：终极决战与开篇闭环，反派终极作死，女主甩全底牌层层递进（人设崩塌→经济犯罪→法律追责），反派跪地求饶名场面
6. **撰写大结局**（4000字，约4章）：反派终极下场对应作恶、女主事业圆满、感情线自然圆满、伏笔闭环、可选续集钩子
