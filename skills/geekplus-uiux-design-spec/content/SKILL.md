# Geekplus UI/UX 设计规范助手

本技能提供 Geekplus B端系统的完整 UI/UX 设计规范参考。

## 核心能力

1. **规范查询**：快速检索色彩、字体、间距、圆角、阴影、组件等设计规范
2. **设计审查**：对照规范检查设计方案是否符合标准
3. **开发指导**：提供 Design Token 映射和 CSS 变量配置
4. **示例参考**：提供代码片段和视觉示例

## 使用方式

### 查询规范
直接询问具体规范内容，例如：
- "品牌主色有哪些？"
- "按钮的交互状态颜色是什么？"
- "表格的行高是多少？"

### 设计检查
上传设计方案或描述设计稿，请我对照规范检查：
- "这个配色符合 Geekplus 规范吗？"
- "按钮样式对吗？"

### 开发参考
获取代码实现指导：
- "如何配置 Element Plus 主题？"
- "给出主按钮的完整样式代码"
