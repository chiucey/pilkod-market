# 涟漪金融研究分析 Skill

## 定位
涟漪的"华尔街分析师"模块。输入一个市场事件/主题，输出：多源新闻汇总 → 传导链路分析 → 七问评分 → 研报输出。

**与精选标的Skill的关系：**
- 精选标的Skill = 每日选股输出
- 本Skill = 深度研究分析引擎（为选股提供输入）

## 模块二：市场传导链路图

### 传导链路生成算法

**四步生成法：**

**Step 1：识别核心事件**
- 从新闻中提取"发生了什么"
- 标注：事件类型（政策/业绩/地缘/技术/情绪）

**Step 2：一级传导（直接影响的板块）**
```
地缘事件 → 影响：
  - 原油 → 能源板块、化工、航空
  - 黄金 → 贵金属板块、珠宝行业
  - 港口 → 航运板块
  
政策事件 → 影响：
  - 降息 → 银行、房地产、成长股
  - 产业政策 → 对应板块龙头
  
业绩事件 → 影响：
  - 龙头业绩超预期 → 同行业跟风
  - 龙头业绩不及预期 → 板块杀估值
```

**Step 3：二级传导（情绪+资金联动）**
```
情绪传导：
  某板块上涨 → 资金挖掘同类标的
  某板块下跌 → 恐慌蔓延到相关板块

资金联动：
  北向资金买入 → A股蓝筹、龙头
  南向资金买入 → 港股A股映射标的
```

**Step 4：个股锚定**
- 传导链末端 = 最有性价比的个股
- 优先选：龙头+超跌+机构建仓

### 传导链路文本格式
```
📍 核心事件：[描述]
⏰ 发生时间：[时间]
📊 影响程度：[强/中/弱]

一级传导（直接板块）
  → 受益板块A：[受益逻辑] [代表标的]
  → 受益板块B：[受益逻辑] [代表标的]
  → 受损板块C：[受损逻辑]

二级传导（情绪+资金）
  → 情绪联动：[描述]
  → 资金联动：[描述]

🎯 个股锚定（传导终点）
  首选：[标的] [建仓逻辑] [建仓区间]
  次选：[标的] [建仓逻辑]
```

## 模块三：AI智能评分预测

基于涟漪七问评分体系，对每个标的进行量化评分：

### 七问评分标准（0-10分）

| # | 问题 | 评分标准 |
|---|------|---------|
| 1 | 真的是机会吗？ | 有一手数据支撑=5分，有多个独立信源=+3分 |
| 2 | 涟漪评分够高吗？ | 基准6分，符合类型A=+2分，类型B=+1分 |
| 3 | 反向证据是什么？ | 找1个做空理由=-1分，2个=-2分，3个=-3分 |
| 4 | 真的理解吗？ | 能写出3条逻辑=5分，2条=3分，1条=1分 |
| 5 | 适合涟漪体系吗？ | 仓位/铁律/板块全合规=5分，1项违规=-2分 |
| 6 | 时机对吗？ | 回调5-8%买入=5分，现价可入=4分，追高=-2分 |
| 7 | 有没有被误导？ | 多源验证=5分，单源=-2分 |

**总分分级：**
- 9-10分：强烈推荐，A类仓位20-25%
- 7-8分：推荐，C类仓位10-15%
- 5-6分：观察，≤5%
- <5分：放弃，0%

### 情景分析
```
情景A（乐观X%）：
  触发条件：[描述]
  价格预测：[X] → [Y]（+Z%）

情景B（基准X%）：
  触发条件：[描述]
  价格预测：[X] → [Y]（+Z%）

情景C（悲观X%）：
  触发条件：[描述]
  价格预测：[X] → [Y]（-Z%）
```

## 执行命令

### 完整执行流程（7步）

```
第1步：接收任务
  V说："分析[主题]"

第2步：多源新闻搜索
  使用batch_web_search搜索5个以上不同信源
  使用extract_content_from_websites提取深度内容

第3步：新闻去重+摘要
  整理成统一的新闻汇总

第4步：生成传导链路图
  按四步生成法输出文本传导图

第5步：标的七问评分
  对传导链末端的每个标的执行七问评分

第6步：情景分析
  三情景概率+价格预测

第7步：生成研报
  按标准模板输出完整研报
  保存到 /workspace/research/YYYY-MM-DD-[主题].md
```

### 快速分析（精简版）

当V说"快速分析[主题]"时：
- 只搜索3个信源
- 跳过详细传导图，直接输出关键结论
- 评分从简，输出核心标的
- 保存到memory/而非research/

### 单标的分析

当V说"分析[具体标的]"时：
- 专注搜索该标的的新闻+公告+研报
- 输出该标的的七问评分+建仓建议
- 不生成传导链路图（单标的不需要）
