# 来源追踪与验证器

信息来源全生命周期管理专家。专注于研究信息来源的登记、验证、下载、引用、跟踪和缺口识别六大维度。

## 核心价值

- **基石保障**：信息来源是论证的基石、结论的支撑、可信度的保障
- **系统化管理**：解决来源管理往往被忽视或处理不当的问题
- **协作支撑**：与深度研究执行助手、内容增强器形成紧密协作

## 六大管理维度

### 1. 来源登记

建立规范化的来源登记体系，使用以下14个标准化字段：

| 字段 | 说明 |
|------|------|
| 来源编号 | 系统生成的唯一标识 |
| 来源类型 | 网页/学术文献/数据报告/图书/政策文件 |
| 来源标题 | 文献或网页的完整标题 |
| 作者机构 | 作者或发布机构的名称 |
| 作者姓名 | 主要作者或编者姓名 |
| 发布日期 | 年-月-日格式 |
| 获取日期 | 年-月-日格式 |
| 获取网址 | URL或DOI等永久标识符 |
| 核心摘要 | 50-100字的核心内容摘要 |
| 关键论点 | 1-3个关键论点列表 |
| 数据支撑 | 包含的关键数据点 |
| 可信度评级 | 高/中/低三级评定 |
| 引用状态 | 未引用/已引用/多次引用 |
| 关联来源 | 相关来源的编号列表 |

### 2. 来源验证

确保信息来源可信度的关键环节：

**来源权威性评估维度**：
- **机构权威性**：发布机构在相关领域的专业地位、行业认可度
- **内容专业性**：技术深度、分析方法的科学性、论证过程的严谨性
- **立场中立性**：是否存在明显立场倾向，是否受特定利益方影响
- **时效性**：内容是否最新，是否可能被新信息替代

**验证状态**：
- 待验证 → 验证通过 / 验证存疑 / 验证失败

### 3. 下载管理

确保来源材料的持久可获取性：

**应当下载**：
- 核心论证依据的重要来源
- 可能被引用多次的参考来源
- 包含关键数据需要反复核对的来源
- 原始网页可能随时消失的来源

**不必下载**：
- 可永久访问的官方数据库来源
- 具有DOI的学术文献
- 内容简单可直接引用的短信息

**存储目录结构**：
```
downloads/sources/
├── policy/      # 政策文件
├── academic/    # 学术文献
├── reports/     # 行业报告
├── webpages/    # 网页
└── data/        # 数据文件
```

### 4. 引用标准化

确保引用格式统一、完整、符合规范：

| 来源类型 | 引用格式 |
|----------|----------|
| 网页来源 | 作者/机构。标题。URL。（访问日期） |
| 学术文献 | 作者。（年份）。标题。期刊名称，卷（期），页码 |
| 数据报告 | 发布机构。（年份）。标题。URL。（获取日期） |
| 图书 | 作者。（年份）。书名。出版社 |

### 5. 来源跟踪

确保对重要来源的动态保持敏感：

- **定期检查机制**：对于政策文件和技术标准，建立定期检查机制
- **订阅提醒机制**：对于提供RSS订阅或邮件提醒服务的来源，建立订阅关系
- **关键词监测机制**：设置关键词监测，当出现相关新来源时及时发现

### 6. 缺口识别

来源管理的高级功能，评估研究来源覆盖完整性：

**缺口识别维度**：
- **主题覆盖**：各主题是否都有充分的来源支撑
- **时间覆盖**：信息来源的时间分布是否合理
- **空间覆盖**：信息来源的地域分布是否合理
- **主体覆盖**：信息来源的主体类型是否完整

**缺口影响评估**：

| 影响程度 | 说明 | 处理方式 |
|----------|------|----------|
| 高影响 | 对核心论点有直接支撑作用 | 必须优先补充 |
| 中影响 | 对论证完整性有辅助作用 | 应当尽量补充 |
| 低影响 | 对研究的边际贡献较小 | 可以选择性补充 |

## 使用流程

遵循标准化的使用流程：

1. **研究启动阶段**：建立来源登记的基本结构
2. **研究执行阶段**：同步进行来源登记和初步验证
3. **初稿撰写阶段**：补充完善来源标注
4. **内容增强阶段**：配合内容增强器进行来源追溯强化
5. **成果定稿阶段**：完成来源管理的最终审核

## 技能协作

三个技能形成闭环，持续迭代优化：

```
深度研究执行助手 → 内容增强器 → 来源追踪器
研究执行和初稿输出 → 质量增强和问题识别 → 来源管理和缺口反馈
```

## 质量保证

- **完整性保证**：所有在研究中使用的来源都经过规范登记
- **可追溯性保证**：任何引用都可以通过标注追溯到原始来源
- **可验证性保证**：所有来源都经过基本真实性验证
- **规范性保证**：引用格式符合标准化规范

## 执行示例

当用户要求进行来源管理时，按以下步骤执行：

1. **收集来源信息**：获取来源的完整元数据
2. **登记来源**：按照14字段标准进行登记
3. **验证来源**：评估权威性并记录验证状态
4. **决定下载**：根据下载标准判断是否需要下载
5. **标准化引用**：生成符合规范的引用格式
6. **评估缺口**：识别来源覆盖的薄弱环节
