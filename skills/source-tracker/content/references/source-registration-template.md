## 来源验证检查表

### 机构权威性评估
- [ ] 是否为该领域的权威机构
- [ ] 机构在该领域的认可度如何
- [ ] 是否有专业资质或认证

### 内容专业性评估
- [ ] 技术深度是否足够
- [ ] 分析方法是否科学
- [ ] 论证过程是否严谨
- [ ] 数据来源是否可靠

### 立场中立性评估
- [ ] 是否存在明显的立场倾向
- [ ] 是否受到特定利益方的影响
- [ ] 是否有多元视角的呈现

### 时效性评估
- [ ] 内容是否是最新的
- [ ] 是否可能被新信息替代
- [ ] 数据是否在有效期内

## 引用格式示例

### 网页来源
```
作者/机构。标题。URL。（访问日期）
例：人民日报。习近平主持召开中央全面深化改革委员会会议。https://paper.people.com.cn/。（2026-03-30）
```

### 学术文献
```
作者。（年份）。标题。期刊名称，卷（期），页码
例：李明。（2025）。人工智能在教育领域的应用研究。教育学报，15(3)，45-58。
```

### 数据报告
```
发布机构。（年份）。标题。URL。（获取日期）
例：中国互联网络信息中心。（2025）。第53次中国互联网络发展状况统计报告。https://www.cnnic.net.cn/。（2026-03-30）
```

### 图书
```
作者。（年份）。书名。出版社
例：张华。（2024）。深度学习原理与实践。清华大学出版社。
```

## 下载决策流程

```
开始
  │
  ▼
是否为核心论证依据？
  │ 是 → 下载
  │ 否 ↓
是否可能被多次引用？
  │ 是 → 下载
  │ 否 ↓
是否包含需要反复核对的关键数据？
  │ 是 → 下载
  │ 否 ↓
原始网页是否可能随时消失？
  │ 是 → 下载
  │ 否 ↓
是否可以永久访问（官方数据库/DOI）？
  │ 是 → 不下载
  │ 否 → 根据实际情况决定
```

## 缺口识别矩阵

| 维度 | 评估项目 | 覆盖情况 | 缺口等级 |
|------|----------|----------|----------|
| 主题覆盖 | 各主题的来源支撑 | 充足/不足 | 高/中/低 |
| 时间覆盖 | 来源的时间分布 | 合理/不合理 | 高/中/低 |
| 空间覆盖 | 来源的地域分布 | 合理/不合理 | 高/中/低 |
| 主体覆盖 | 来源的主体类型 | 完整/不完整 | 高/中/低 |
