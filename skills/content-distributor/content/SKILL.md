# 多平台内容自动分发调度器

## 简介

一份内容，秒发全网。一个 Prompt 让你的文章/文案同时触达所有主流平台，自动适配各平台格式，打通发布-数据回收全流程。

## 核心能力

- **多平台适配**：自动调整标题、正文长度、话题标签、格式风格
- **平台覆盖**：小红书、微信公众号、微博、知乎、抖音/快手、B站
- **定时排期**：支持设置发布时间，定时自动分发
- **数据回收**：追踪各平台阅读量、点赞、评论、收藏
- **内容变体**：根据平台特性生成不同版本，避免被识别为机器分发

## 支持平台

| 平台 | 适配格式 | 特殊处理 |
|------|---------|---------|
| 小红书 | 标题+正文+Tags | 自动添加 #话题 标签 |
| 微信公众号 | 标题+正文+封面建议 | 富文本格式适配 |
| 微博 | 短文本+话题+@提及 | 自动截断超长内容 |
| 知乎 | 标题+正文+问题关联 | 优化SEO结构 |
| B站 | 标题+简介+分区 | 自动添加投稿信息 |

## 使用方法

### 基础用法

```
我写了一篇文章：《[标题]》，内容如下：
[正文]
帮我同步发布到小红书、微信公众号、知乎。
```

### 进阶用法

```
把刚才的小红书文案，改一下风格，适合微博传播。
同时设置明天晚上8点定时发布。
发布后给我一份各平台数据汇总。
```

### 完整工作流

```
第一步：输入原始内容
第二步：选择目标平台
第三步：确认/调整各平台适配版本
第四步：设置发布时机（立即/定时）
第五步：执行发布
第六步：自动生成数据报告
```

## 输入格式

用户可提供以下任一形式：
- 纯文字文章
- 大纲/关键词
- 语音转文字稿
- 其他 AI 助手的草稿

## 输出形式

- 各平台适配后内容（可直接发布）
- 发布状态报告
- 数据追踪链接
- 周报/月报汇总（如需要）

## 注意事项

- 首次使用需要用户提供各平台的登录态或 API Token
- 微信公众号需要企业主体或已认证个人号
- 微博 API 有频率限制，大规模分发需要申请权限
- 各平台政策随时变化，建议发布前人工复核
