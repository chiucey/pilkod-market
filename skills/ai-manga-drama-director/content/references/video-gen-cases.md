## 三、7 个完整提示词实战(逐字抄录)

> 这 7 个是用户提交的完整原件,**核心参考**。

### 案例 1: 丹顶鹤湿地起舞(基础提示词 · 8 秒)

```
写实自然纪录片风格,电影级真实光影,清晨的薄雾中,在广阔的湿地芦苇荡@图片1里,
一只优雅的丹顶鹤正展翅起舞。
@图片2 丹顶鹤羽毛洁白如雪,头顶鲜红,身姿修长挺拔,动作轻盈高贵。
场景为秋季的浅水湿地,水面波光粼粼,周围长满金黄色的芦苇、浮萍与水草,
虚化背景中是远处的晨雾与初升的太阳。
镜头为低机位中景,轻微手持感,整体基本固定,始终保持丹顶鹤在画面中央。

0s-3s: 一只丹顶鹤静立在浅水中,身姿优雅。它刚开始缓慢地展开宽大的黑白双翼,
动作轻柔,水面被翅膀扇动的气流带起阵阵涟漪。晨风吹拂,阳光从地平线斜射过来,
穿透薄雾形成丁达尔光效。

3s-8s: 丹顶鹤在水面上轻盈跳跃,双脚交替点水,溅起晶莹的水花。它修长的颈部
向后仰起,鸟喙指向天空,随后身体轻盈落地,收拢双翼恢复站立姿态,头部优雅地
环顾四周,发出一声清脆的长鸣。

低机位,轻微手持感,轻微跟随丹顶鹤的跳跃轨迹上下移动。
景深自然,前景的芦苇轻微虚化,丹顶鹤主体清晰,背景的晨雾与朝阳柔和虚化。
自然环境音,水流声、翅膀扇动时有力的扑击声以及鹤鸣声,整体宁静、空灵、唯美。
```

**实战规律**:
- **风格锚定**:开头先定"风格 + 光影"调子(写实自然纪录片 + 电影级真实光影)
- **@图引用**:@图片1 = 场景参考,@图片2 = 主体参考(多张图分层使用)
- **主体描述要"质感化"**:羽毛洁白如雪/头顶鲜红/身姿修长挺拔 → AI 才能精确锁定
- **时间分段**:0s-3s + 3s-8s 显式分段,不要写"动作 A 然后动作 B"
- **镜头描述独立**:把镜头参数(低机位、轻微手持)放在主体描述之后单独成段
- **声音描述具体化**:"水流声、翅膀扑击声、鹤鸣声"——不要说"自然环境音",要列出具体声源

### 案例 2: 橘猫打工 Vlog_3 分钟(超长视频 · 180 秒)

```
全程3分钟,@图片1猫咪打工vlog ,视频比例16:9,以橘猫为主角当服务员的一天,
它从起床刷牙洗脸,骑电动车到街边小店,清晨上班擦桌签到,迎客引座递菜单,
场景参考@图6-10,餐厅整体参考@图11,他小心送餐到客户@图片2345的桌子上,
午休偷啃小鱼干打盹,傍晚收小鱼干小费、收拾桌面,最后打烊蜷在窗边休息,
骑电动车,回到房间@图12,洗漱,吃饭,睡觉。
全程无字幕,无背景音乐
```

**实战规律**:
- **"全程 X 分钟"锚定时长** + **"视频比例 16:9"锚定比例** 写在最前面
- **多个 @图编号引用**:@图1 主角 + @图6-10 场景 + @图11 餐厅整体 + @图2345 客户桌 + @图12 房间
- **时间流叙事**(起床→上班→午休→下班→回家),不用写具体秒数,AI 会自动分布
- **明确禁止项写在最后**:"全程无字幕,无背景音乐"——比放在开头更不容易漏
- **这种"一天流水账"是 AI 视频生成的最佳叙事结构**(有节奏、有起承转合)

### 案例 3: 雨天咖啡馆_1 分钟(超长视频 · 60 秒,3 段式)

```
视频时长 1 分钟,画幅比例 16:9,电影级写实画质,复古治愈风格。
一个阴雨天的午后,固定镜头记录着复古咖啡馆桌上冒着热气的咖啡,
以及透过玻璃窗看到的唯美雨景。

0s - 20s(静谧开场):
机位固定在木质咖啡桌前。桌面上放着一杯刚泡好的热咖啡,正缓缓向上冒着白色的热气。
背景是巨大的格子玻璃窗,窗外正在下着细雨,雨滴打在玻璃上汇聚成水珠缓缓滑落。
伴随淅沥的雨声。
镜头不要晃动,不要有人物入镜,禁止生硬切镜。

20s - 40s(细节推进):
镜头极其缓慢地向前方的咖啡杯推近。热气持续氤氲。一阵风吹过,
窗外有一一片金黄色的落叶飘过,贴在了玻璃窗外侧。
画面的焦点依然对准咖啡杯边缘和热气。
不要复杂的物理碰撞,物体禁止变形,禁止出现文字。

40s - 60s(焦点转移与淡出):
镜头保持微小的呼吸感,画面的焦点慢慢从前景的咖啡杯,平滑转移到背景窗外的雨景上。
窗外的街灯在雨水模糊下晕染成温暖的光斑。画面随着雨声逐渐变暗结束。
画面不要闪烁,不要任何突兀的转场。

画面与光影:
全程保持室内暖黄光与室外冷雨夜的高级色彩对比。镜头以极慢的推拉和固定机位为主,
追求极度的稳定感与氛围感。

声音与限制:
全程只需真实的自然白噪音(雨打玻璃声、细微的环境音)。全局无背景音乐(不要 bgm),
全局无字幕。
```

**实战规律**:
- **显式分段**(0s-20s / 20s-40s / 40s-60s)+ 每段加**小标题**(静谧开场/细节推进/焦点转移与淡出)
- **每段独立"约束清单"**:"镜头不要晃动"、"不要复杂的物理碰撞"、"画面不要闪烁"——AI 默认行为可能违反的项,要逐条排除
- **末尾汇总"画面与光影"+"声音与限制"**——把跨段的全局约束独立成节,让 AI 最后看一遍
- **抒情场景的"反套路"**:治愈风、衰减、复愈风都需要"显式禁止复杂性"(禁止生硬切镜、禁止复杂物理碰撞),不然 AI 会乱发挥
- **"禁止出现文字"**——视频生成模型经常自动加字幕,必须显式禁止

```
主角是@图1的壮汉战士,他正独自走在茂密的原始森林中,步伐稳健。
```

### 案例 5: 森林壮汉_延长 5 秒(延长模板)

```
参考@视频1的内容,延长视频5s向后延长。
要求延长自然、动作衔接流畅、动作衔接自然,
禁止生硬切镜、禁止物体凭空出现。
@图1壮汉战士突然察觉到异样,停下脚步,眼神变得锐利。
他迅速摆出防御姿态,紧紧盯着前方。
```

**实战规律(延长写法)**:
- **核心句**:"参考@视频1的内容,延长视频 N 秒" + 方向(向后/续写)
- **必须加"自然"约束**:"延长自然、动作衔接流畅、动作衔接自然"(重复强调是因为这是高频失败项)
- **必须加"禁止"约束**:"禁止生硬切镜、禁止物体凭空出现"——AI 默认会插帧/插物
- **续写动作要"突变而不突兀"**:停下脚步 → 眼神变锐利 → 摆防御姿态(三个递进,1 秒内)

### 案例 6: 白色背景改绿幕(高级编辑 · 时间段全替换)

```
把整个视频0-5秒,全部视频。白色的背景,都变成绿幕背景。
去掉声音,保持静音。
```

**实战规律(高级编辑写法)**:
- **极简指令**:"把 [范围] 的 [元素] 全部改为 [目标]"
- **时间范围 + 元素名 + 目标状态** 三要素齐全
- **次要约束单列**:"去掉声音,保持静音"——声音是常被忽略的项,要单独说
- **不要解释为什么**(AI 不需要理由,只要指令清晰)

### 案例 7: 森林壮汉_再次延长 10 秒(带遮罩转场)

```
参考@视频1的内容,延长视频10s延长续写。
要求需要在切镜处使用 "遮罩转场" 转场(禁止生硬切镜、禁止物体凭空出现)。

镜头 A 展示正在防御的@图1壮汉战士(近景),一阵风吹过,一片正常大小的落叶
```

**实战规律(转场延长写法)**:
- **指明转场类型**:"需要使用 遮罩转场"(落叶/烟雾/手部遮挡/黑场等)

## 六、避坑提示

| 坑 | 表现 | 解决 |
|---|---|---|
| 提示词太长 | AI 抓不到主次 | 基础段控制在 4-6 行,延长段 6-10 行 |
| 时间分布模糊 | "动作 A 然后动作 B" | 显式写 "0s-3s 动作 A,3s-8s 动作 B" |
| 没说声音 | AI 默认加 BGM | 治愈/纪录片场景必加"无背景音乐" |
| 没说禁止项 | AI 自动加字幕 | 显式写"禁止出现文字/无字幕" |
| 转场生硬 | AI 硬切 | 显式要求"遮罩转场 / 落叶挡镜 / 淡入淡出" |
| 角色不一致 | 跨镜换脸 | 用"参考的动态运镜、物理光影变化要保持一致" |
| 物体凭空出现 | AI 插入未定义道具 | 必加"禁止物体凭空出现" |

### 案例 4.1:鲸鱼替换白龙(0-8 秒全替换 + 去 BGM)

```
在整体视频的0-8秒,全部修改。把视频中的鲸鱼修改为一条白色的龙。

```

**实战规律(全段元素替换)**:
- **三要素齐全**:时间范围(0-8 秒)+ 元素名(鲸鱼)+ 目标状态(白色的龙)
- **"全部修改"加强语气**——AI 默认是局部修改,显式"全部"强制全段替换
- **次要约束单列**:"去掉 bgm"——声音是常被忽略的项
- **不需要解释为什么**(AI 不需要理由,只要指令清晰)

### 案例 4.2:白色背景改绿幕(0-5 秒全替换 + 去声音)

```
把整个视频0-5秒,全部视频。白色的背景,都变成绿幕背景。
去掉声音,保持静音。
```

**实战规律(背景替换)**:
- **跟案例 4.1 同结构**(时间 + 元素 + 目标),但元素是"背景"而非"前景物体"
- **"去掉声音,保持静音"双重强调**——AI 默认会保留声音,显式双重强调确保静音
- **绿幕是专业后期合成**——给二次合成用,可叠加其他素材
- **适用**:把白底产品演示视频转为后期可合成素材;把 PPT 录屏转绿幕;动态 logo 制作

## 八、白模提示词完整提示词(4 个)

> **分类 05** 的全部 4 个案例完整抄录。**核心能力**:把"白模动画"渲染为"最终成片"——白模是 AI 视频生成里**最重要的中间态**,让你用低成本白模当动作参考,再用高质量参考图渲染出最终角色。

### 案例 5.1:白模替换精灵女王(粗颗粒度)

```

保持角色一致性,不穿模不变脸。

场景整体为精灵大殿,保留@视频1中的场景。

机位与原视频保持一致,精灵女王跟随着参考视频里模型的动作优雅地抬起魔法手杖。
期间,她银白色的长发和宽大的白袍裙摆随着气流自然飘动,质感丝滑且有垂坠感。
伴随着动作,参考视频中的光效转化为一道神圣光柱从地上抬升,与女王手中法杖散发的耀眼金光交相辉映。

最终视频要求电影级 CG 写实画质,光影真实神圣且充满史诗感,画面高清,

```

**实战规律(粗颗粒度 = 大方向参考)**:
- **开头标"粗颗粒度"**——告诉 AI 这是大方向,允许自由发挥细节
- **"@视频1 的动态运镜、物理光影变化"**——只参考运镜和光影,不参考具体动作细节
- **"机位与原视频保持一致"**——核心约束,景别/角度不能变
- **"跟随参考视频里模型的动作 X"**——动作是"参考"而非"复刻"
- **不穿模不变脸**——5 字核心约束,避免 AI 复制白模的简单动作
- **末尾"画质/光影/细节"汇总要求**——独立段,把全局质量要求列全
- **适用**:有现成白模视频,但想换一个高质量角色;漫剧主角从白模升级为成品

### 案例 5.2:白模人物替换可爱小狗(粗颗粒度 + 场景替换)

```
粗颗粒度@图片1参考@视频1的人物动作和运镜。将视频中的白色人型模型,完全替换为@图片1的可爱小狗,
```

**实战规律(粗颗粒度 + 场景同步替换)**:
- **"粗颗粒度" + "完全替换"**——双重强调"白模彻底消失"
- **场景也改**:"@视频1中的白色高大建筑物渲染成高楼"——连背景白模一起改
- **物种切换的精髓**:人型模型 → 可爱小狗。**关键技巧:不要描述"小狗狗头人身体",要描述"小狗跟随视频的动作自然走动"**——直接告诉 AI 物种行为模式

- **适用**:广告片主角从人换成 IP 形象(狗/猫/熊);品牌吉祥物动画化

**实战规律(细颗粒度 = 分镜级控制)**:
- **开头标"细颗粒度"**——告诉 AI 这是分镜级控制,严格按时间分段执行
- **三段式 @ 引用声明**(写在分镜要求之前):
  - `@视频1` = 哪种参考(白模 viewport reference),**只用于哪种用途**(角色大小/站位/镜头距离/空间压迫感),**不要照抄**哪些东西
  - `@视频2` = 哪种参考(战斗动作 reference),**只用于哪个时间段**(20-25 秒关键反击),**可以复刻**哪些,**不能**做哪些
  - `@图片1-10` = 视觉参考全集,严格按图片,不要改变设定
- **6 段时间分镜,每段独立标题**:`0-5 秒:建立对峙` / `5-10 秒:boss 发起第一次攻击` / `10-15 秒:小骑士第一次反击失败` / `15-20 秒:小骑士发现新策略` / `20-25 秒:关键反击` / `25-30 秒:boss 倒下`
- **每段固定结构**:时间范围 + 段落标题 + 镜头/景别 + 主体动作 + 情绪节奏

- **多 @ 引用协同**:@图(视觉) + @视频(动作/光影) + @音频(背景音乐)——这是**多模态提示词的最高级形式**
- **保持叙事连贯**:段与段之间有"承上启下"(被打飞的位置自然衔接到发现果冻的位置)
- **适用**:复杂打斗/追逐/变身/特效场景的 AI 视频生成;**也适用于 AI 漫剧的高潮戏**——这段提示词的写法几乎就是"导演剧本 + 分镜脚本 + 后期合成说明"的合体

## 九、粗颗粒度 vs 细颗粒度(范式对比)

> 这是从案例 5.1-5.4 提炼出来的**核心范式**。

| 维度 | 粗颗粒度 | 细颗粒度 |
|---|---|---|
| **开头标识** | "粗颗粒度参考 @视频 X" | "细颗粒度 [整体任务描述]" |
| **@视频用法** | 只参考运镜/光影/动作轮廓 | 部分时间段严格复刻动作 |
| **AI 自由度** | 高,允许 AI 自由发挥细节 | 低,严格按时间分段执行 |
| **时间分段** | 通常不显式分段,AI 自动分布 | 显式 0-5s / 5-10s / 10-15s 等 |
| **适用场景** | 单段升级(白模→成品角色)、场景替换 | 复杂动作戏(Boss 战/追逐)、商业广告 |
| **段落数** | 通常 1 段 | 通常 3-6 段 |
| **末尾约束清单** | 简略(1-3 条) | 完整(8-15 条必须/不要) |
| **写起来** | 4-6 行 + 末尾汇总 | 20-50 行 + 多 @引用声明 |

## 十、白模替换通用结构(从 4 个案例提炼)

### 白模替换的两类需求

| 需求 | 用什么范式 | 参考案例 |
|---|---|---|
| **白模 → 高质量角色**(运镜光影动,角色是新的) | 粗颗粒度 | 5.1 精灵女王, 5.2 小狗 |
| **白模 → 高质量成片**(整体从白模动画渲染成片) | 细颗粒度 | 5.3 Boss 战, 5.4 香水广告 |

### 白模替换必加的 5 个约束

1. **"不要照搬白模动作"**——AI 默认会把白模的简单动作原样保留,必须显式禁止
2. **"不穿模不变脸"**——防止 AI 复制白模的简化身体结构
3. **"机位与原视频保持一致"**——核心约束,景别/角度不能变
4. **"参考 @视频1 的动态运镜、物理光影变化"**——明确 AI 能用什么类型
5. **末尾画质/光影/细节要求**——独立段,防止 AI 用白模质感草草收场

### 多 @ 引用协同清单

| @ 类型 | 用途 | 写法 |
|---|---|---|
| `@视频1` | 白模原版/动作参考 | "只用于参考运镜/动作轮廓,不要照搬白模动作" |
| `@视频2` | 特定时间段的动作复刻 | "只用于 X-X 秒关键反击段" |
| `@图片1` | 角色形象 | "严格参考,不穿模不变脸" |
| `@图片2-10` | 场景/道具/特效 | "最终画面需要严格参考这些图片,不要新增无关重要角色或道具" |
| `@音频1` | 背景音乐 | "背景音乐请使用@音频 1" |

### 白模替换的"二次合成"思路

白模提示词经常是**两步工作流**:
1. **第一步**:用 4.3 案例在视频里生成"白模 + 占位场景"
2. **第二步**:用 5.x 案例把白模替换为成品角色

> **为什么分两步**:直接生成"成品角色"成本高(算力+提示词复杂度),先用白模验证站位和镜头,再用白模替换省事且可控。这是**降本增效的关键技巧**。

- **空镜作为情绪缓冲**:`家中餐桌与台灯空镜` / `夜晚小客厅空镜`——空镜用来"让情绪落下来"

- **"余韵"结尾**:"在温暖而有余韵的画面里结束"——治愈系短片必须有"余韵",不能戛然而止


**实战规律(续写 + 关系递进 + 收尾余韵)**:
- **"延续上一段结尾"承接**:`延续上一段结尾,年轻女性站在雨夜街角,身体朝前,头慢慢回过去`——直接续接上一镜的状态
- **"终于看见"是情绪转折点**:用"终于"传达时间累积的等待
- **对手角色"像赶来得有些急,却又怕自己的出现太突兀"**——一个长定语精准刻画人物状态
- **"认出来的瞬间停留半秒"**——电影节奏:重要瞬间要"留",不要一镜过

- **"从隔着雨的对望过渡到并肩同框"**——这是关系形态学的电影术语
- **收尾用"余韵"**:"慢慢拉远,让他们一起融入霓虹、雨丝和潮湿街道的深处"——治愈系悬疑短片的标准结尾

### 视频延长范式总结(6 个案例提炼)

**链式延长的标准结构**:
```
[固定开头模板]延长参考视频,接续上一段 [明确上一段末尾的视觉/动作状态]。

[主体动作描述,承接上一段末尾的状态,不重新开始]
[新元素出现(可选,推动故事向前)]
[环境/空镜过渡(可选,作为情绪缓冲)]
[新角色登场(可选,如案例 6.3 小男孩、案例 6.6 男人)]
[情绪高潮/转折点]
[收尾余韵]
```

**链式延长的 4 个必加约束**:
1. **"接续/延续上一段"必须显式写**——AI 默认会"重新开始",显式禁止
2. **承接"上一段末尾的视觉/动作状态"**——不要让 AI 重新描述人物站位
3. **@图复用保持一致性**——延续上一段的角色/场景参考
4. **不要让 AI 突然切场景**——除非显式写"镜头转到/切入",否则保持同一空间

**双线并行的写法**:
```
[场景 A 描述]

双线并行镜头,包装条展示两个场景的双屏内容,分屏条特效效果参考@视频1的效果,
左侧画面内容:[具体描述]
右侧画面内容:[具体描述]

[回到主场景]
```

**关系/情绪递进的写法(案例 6.6 范式)**:
```
[起始状态] + [转折触发] + [微动作链 3-6 个动作] + [关系形态转换] + [收尾余韵]
```

**治愈系余韵结尾(案例 6.4 / 6.6)**:
- "在温暖而有余韵的画面里结束"
- "让他们一起融入 [环境] 的深处"
- 不用"圆满/幸福"等大词,用"安静、柔软、被治愈"
- 镜头语言:慢慢拉远 + 留白 + 让观众自己补完

**实战规律(25 镜头超长片)**:
- **整段用引号包裹**——给 AI 清晰边界,便于解析
- **每个镜头 4 要素固定结构**:`镜头 N(米米) 运镜 + 画面 + 音效/台词`
- **25 镜头适合"动作喜剧/快节奏"题材**——平均每镜 6-8 秒,适合密集反转
- **角色/演员名可以省略**(被原版隐藏),留 `@图N` 占位
- **每个镜头独立音效**——BGM 与音效并重,镜头切换时音效也要切换
- **漫画风拟声字/定格收尾**——商业广告/喜剧短片常用手法
- **"开场 + 过程 + 反转 + 收尾"的密集反转结构**:1-15 镜是连续失败,16 镜是吐槽,17-20 镜是意外转折,21-24 镜是"虚假胜利",25 镜是真正收尾
- **"虚假胜利 + 真收尾"双结尾**:镜头 24 摆胜利姿势,镜头 25 才真正收——这是喜剧反转的精髓

**实战规律(8 长段超长片)**:
- **每段使用"时间戳 + 逗号 + 长段落描述"**——不显式分段标题,直接连续叙事
- **每段 10-30 秒,整段当作"一组长镜头"写**——镜头语言内嵌,不分离成"运镜/画面/音效"
- **角色"环境镜头"和"群像调度"是核心**——12 个角色 + 1 个神秘人,每个 @图 都对应具体角色
- **"画面不止一次切入"**:0:13-0:30 段落里,从"镜头推入教学楼 → 停在教室前门 → 切进教室全景"——一个段落多个镜头连贯写
- **心理悬念的写法**:"他皱起眉毫,目光扫过全班逐一点数,数完后脸上露出明显的疑惑"——动作 + 微表情 + 心理变化
- **对话用角色直接引用**:"@图10 随即合上点名册,语气自然得仿佛刚才的停顿从未发生:'好了,各位先自习。'"——不是"她说:好了",而是把语气/动作/台词一体化
- **声音/台词/环境音**:"带电流杂音的校园广播缓缓响起:'欢迎十二位新同学。' 空旷的校园里只剩雨声、广播的滋滋回声与远处闷沉的雷响。"——氛围声音系统完整
- **场景之间用"软转场"**:"镜头缓缓从他身后拉远,扫过整间教室,后排的阴影里,一个白色的纤细人影一闪而过"——一个段落自然过渡到下一个
- **结尾收束在纯黑 + 余韵**:"画面瞬间切入纯黑。伴随一声悠远的上课铃轻响,全片结束。"——纯黑 + 单一声音 = 高级感收尾
- **整体结构**:`建立氛围 → 介绍角色群像 → 制造第一个悬念(第十三个名字) → 揭示第一个线索(照片/学籍册/哭泣) → 累积不安 → 真相揭示 → 终极反转 → 余韵收尾`

### 案例 7.1 vs 案例 7.2:两种超长片范式对比

|---|---|---|

| **总时长** | 2:55 | 3:00 |
