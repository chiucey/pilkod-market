# AI 漫剧风格提示词完整资料

> 主流风格 + 小众风格,每种含核心风格词 + 画面元素 + 镜头节奏 + 角色塑造。
> 提示词公式:`核心风格词 + 画面元素 + 镜头节奏 + 角色塑造`。

---

## 一、主流风格

### (一)日系动漫风格

#### 1. 热血少年漫(Jump 系)

- **核心词**:线条硬朗锐利,色彩饱和度高,对比强烈,动态感十足,分镜张力拉满
- **画面元素**:开阔场地(荒野、废墟、竞技场)+ 动态速度线 + 爆炸光效 + 烟尘粒子;角色战斗时肌肉线条清晰,衣物褶皱富有动感;日常场景色调温暖,细节丰富
- **镜头节奏**:低角度仰拍(凸显高大感)+ 快速跟拍 + 特写(聚焦眼神/拳头);战斗穿插慢动作
- **角色塑造**:眼神坚定锐利,刺猬头/短发,运动服/夹克/工装裤,配饰简洁(围巾/护腕/徽章),身材匀称偏健壮

#### 2. 治愈系少女漫

- **核心词**:线条柔和细腻,色彩清新淡雅(马卡龙/莫兰迪),光影温柔,氛围恬静舒适
- **画面元素**:田园/校园/温馨家庭 + 自然元素(樱花/向日葵/落叶/雨滴) + 生活化细节(精致餐具/柔软毛毯)
- **镜头节奏**:平视/俯拍 + 特写聚焦微表情(微笑/害羞/沉思);穿插大量空镜(飘落樱花/流淌溪流)
- **角色塑造**:脸型圆润可爱,眼神柔和灵动,长发/卷发/双马尾 + 精致发饰,连衣裙/水手服/针织衫,身材纤细娇小

#### 3. 暗黑系悬疑漫

- **核心词**:线条厚重压抑,色彩冷色调(黑/深灰/深蓝/暗红),光影对比强烈(大量阴影/逆光)
- **画面元素**:废弃建筑/阴暗小巷/雨夜城市 + 破碎窗户/生锈金属/摇曳灯光/诡异符号;颗粒感或噪点
- **镜头节奏**:低角度俯拍/侧拍 + 特写诡异细节(滴落液体/颤抖的手/模糊影子);穿插大量主观镜头
- **角色塑造**:眼神阴郁/空洞/锐利,面部冷漠或狰狞,发型凌乱或利落,黑色风衣/皮衣/破旧衣物,身材偏瘦或高大魁梧

### (二)国漫风格

#### 1. 古风玄幻国漫

- **核心词**:线条飘逸流畅,色彩浓郁厚重(中国红/墨黑/鎏金/青蓝),光影层次丰富,氛围恢弘大气或空灵缥缈
- **画面元素**:仙山云海/古色宫殿/幽深竹林/荒凉戈壁 + 飞檐斗拱/雕花窗棂/油纸伞/玉佩/剑穗 + 仙气/魔气/法术光效/神兽
- **镜头节奏**:全景(展现恢弘)+ 慢镜头(展现飘逸动作);穿插大量空镜展现东方意境
- **角色塑造**:古典脸型(鹅蛋脸/瓜子脸),束发/散发 + 发簪/步摇/玉冠,汉服/仙侠服/武侠装(飘逸丝绸/轻纱),身材修长,气质出尘或英气

#### 2. 现代都市国漫

- **核心词**:线条简洁明快,色彩贴近现实,光影自然,氛围真实接地气或时尚潮流
- **画面元素**:现代城市街道/写字楼/校园/便利店/地铁 + 本土化细节(中式小吃摊/共享单车/中式建筑与现代融合)
- **镜头节奏**:平视/跟拍 + 特写日常动作与微表情;流畅自然
- **角色塑造**:现实脸型,发型多样且符合现代审美,T恤/牛仔裤/连衣裙/职业装,配饰时尚简约,身材符合现实

### (三)美漫风格

#### 1. 超级英雄美漫

- **核心词**:线条粗犷有力,色彩鲜艳饱和,对比强烈,光影夸张,充满力量感与视觉冲击
- **画面元素**:繁华都市/高空/宇宙空间 + 爆炸/倒塌建筑/飞行轨迹/能量冲击波;背景简洁大气
- **镜头节奏**:广角/低角度仰拍/快速跟拍 + 特写肌肉/武器/表情
- **角色塑造**:身材夸张健硕,肌肉线条明显,服装色彩鲜艳带标志图案(披风/徽章/条纹),配饰带科技感或力量感

#### 2. 美式卡通漫剧

- **核心词**:线条简洁流畅,色彩明亮活泼,光影柔和,氛围轻松幽默,造型夸张可爱
- **画面元素**:家庭/校园/公园/小镇 + 卡通化道具(夸张食物/可爱玩具/个性化交通)
- **镜头节奏**:平视/俯拍 + 特写夸张表情(瞪大眼/张开嘴/扭曲面部)
- **角色塑造**:脸型夸张(圆形/方形/三角形),表情丰富,发型简洁卡通,服装色彩鲜艳款式简单,身材比例不协调(大头小身/长腿短身)

## 二、小众/特色风格

### (一)蒸汽朋克漫剧

- **核心词**:线条粗糙有质感,色彩棕褐/铜/黑 + 少量亮色(红/金),充满工业复古与科技感
- **画面元素**:蒸汽时代城市/工厂/飞艇基地 + 齿轮/管道/蒸汽机/飞艇/机械臂 + 维多利亚复古建筑;颗粒感与复古滤镜
- **镜头节奏**:全景展现宏大 + 特写机械细节;舒缓节奏 + 慢镜头展现机械运转
- **角色塑造**:复古发型(卷发/束发),面部可带疤痕/机械装饰,维多利亚服饰 + 机械装备融合,身材匀称

### (二)赛博朋克漫剧

- **核心词**:线条锐利简洁,霓虹色(紫/蓝/粉/绿)+ 黑色,对比强烈,光影充满科技感
- **画面元素**:未来都市街头/高楼/地下/虚拟空间 + 霓虹灯牌/全息投影/电子屏幕/机械义体/飞行汽车;霓虹光晕
- **镜头节奏**:仰拍(展现高楼压迫感)/侧拍/主观镜头;节奏快
- **角色塑造**:发型个性(渐变色/脏辫),面部可带电子纹身/机械装饰,未来科技风(紧身作战服/皮质外套/带线路服饰),配饰电子化(耳机/眼镜/终端)

### (三)暗黑奇幻漫剧

- **核心词**:线条厚重细腻,色彩深紫/黑/墨绿/暗红,光影昏暗,氛围诡异神秘
- **画面元素**:黑暗森林/古老城堡/诡异沼泽/魔界空间 + 奇幻生物(吸血鬼/狼人/精灵/恶魔) + 魔法光效/神秘符文
- **镜头节奏**:低角度俯拍/侧拍 + 特写奇幻细节;节奏忽快忽慢
- **角色塑造**:眼神阴郁/空洞/充满邪气,黑色长袍/皮质铠甲,配饰奇幻且有攻击性,身材夸张

### (四)治愈系田园漫剧

- **核心词**:线条柔和细腻,色彩清新自然(绿/黄/蓝/白),光影温暖柔和,氛围恬静舒适
- **画面元素**:乡村田野/农场/果园/溪边 + 自然元素(稻田/麦田/花朵/小动物) + 木质房屋/篱笆/农具
- **镜头节奏**:平视/俯拍 + 特写农作物/小动物/温馨表情;穿插空镜(风吹麦浪/流淌溪水)
- **角色塑造**:脸型圆润,发型简洁自然(短发/马尾辫),田园风服饰(布衣/围裙/草帽),身材匀称,气质淳朴

## 三、使用技巧

### (一)提示词组合逻辑

**核心公式**:
```
核心风格词 + 画面元素 + 镜头节奏 + 角色塑造
```

**完整示例**:
```
Jump系热血少年漫风格,线条硬朗锐利,色彩饱和度高,
战斗场景为荒野,搭配动态速度线与爆炸光效,
低角度仰拍镜头,角色眼神坚定,刺猬头发型,运动服造型
```

### (二)权重与负向词

**权重符号**(Midjourney `::`):
```
热血少年漫风格::2 樱花场景::1
```

**负向提示词**(排除不符合风格的元素):
```
--no 模糊画面、色彩灰暗、比例失调
```

### (三)工具适配

| 工具 | 调整要点 |
|---|---|
| **Midjourney** | 简洁精准,加 `manga panel`、`comic strip`、`shonen jump style` |
| **Stable Diffusion** | 详细,可加模型关键词 `AnyLoRA`、`AbyssOrangeMix` |
| **国内 AI(文心/通义)** | 中文表达,例:`古风玄幻国漫风格,线条飘逸,仙山云海场景,鎏金法术光效,汉服角色` |

### (四)风格融合技巧

- **明确主风格 + 副风格**:例"古风玄幻国漫为主,融入赛博朋克科技元素,古风服饰搭配机械义体"
- **元素自然过渡**:加"融合自然""风格统一"
