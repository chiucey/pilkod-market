# AI 生成人物角色提示词通用公式

> 一句话公式:`【核心定位】+【外貌细节】+【性格气质/神态】+【漫剧风格】+【画面参数】+【动作/场景适配】`
> 这个公式表是写角色 prompt 的"骨架检查表",确保不漏关键信息。

---

## 五层公式

| 分层 | 核心作用 | 填写要点 | 示例 |
|---|---|---|---|
| **基础定位层** | 明确核心身份与人设 | 年龄 + 身份/职业 + 核心人设标签(性格/剧情属性) | 19 岁女大学生 + 元气社团社长 + 阳光开朗、热心肠 |
| **细节描述层** | 补充外貌、穿搭、神态,避免形象模糊 | 外貌(五官/发型发色/肤色/体型)+ 穿搭(风格/款式/材质/配饰)+ 神态(表情/眼神/氛围感) | 杏眼、浅棕长卷发、冷白皮;浅蓝碎花连衣裙+珍珠耳饰;笑眼弯弯、自带柔光感 |
| **风格指令层** | 定义画面质感与艺术风格 | 画风类型 + 线条特点 + 色调风格 | 日系二次元赛璐璐画风 + 线条流畅柔和 + 暖色调(粉白+浅蓝) |
| **技术参数层** | 保障生成质量,规避 AI 崩坏 | 分辨率 + 画面比例 + 细节要求 + 避坑指令 | 8K 高清 + 16:9 漫剧分镜比例 + 面部细节精细、衣褶清晰 + 五官对称、无杂乱背景 |
| **动作/场景适配层** | 适配具体使用场景,方便后续动态延展 | 基础动作 + 适配场景(可选) | 单手托腮看书 + 适配校园图书馆场景 |
| **工具适配补充** | 针对特定 AI 工具优化 | 工具专属关键词(Lora 模型、风格预设) | SD:`Lora:校园甜妹:0.8`;醒图:简化细节描述,突出核心风格 |

---

## 公式填空模板(直接复制使用)

```
[年龄] + [身份/职业] + [核心人设标签]
+ [五官类型]、[发型发色]、[肤色/体型]
+ [穿搭风格]、[款式]、[材质]、[配饰]
+ [表情]、[眼神]、[氛围感]
+ [画风类型] + [线条特点] + [色调风格]
+ [分辨率] + [画面比例] + [细节要求] + [避坑指令]
+ [基础动作] + 适配[场景]
```

### 示例 C:作者电影风·留守孩子(用户主推)

```
8 岁 + 北方农村儿童 + 留守儿童、懂事、安静
+ 圆脸、黑色短发(自然凌乱)、皮肤被风吹微红、脸有灰尘痕迹、
  黑色明亮眼睛、眼神安静带轻微孤独感、瘦小
+ 深蓝色旧中式棉袄(褪色、袖口磨损、有细小补丁)、
  灰色旧毛衣、深色棉裤、灰色布鞋
+ 不哭泣、不夸张悲伤、真实儿童面部比例、真实皮肤毛孔
+ 超写实 AI 电影 + 35mm 胶片质感 + 冷蓝灰调、纪录片摄影
+ 8K + 2.35:1 电影宽幅 + 面部细节精细、衣褶真实 + 普通农村儿童外貌,没有精致网红感
+ 站在院子中间,手端搪瓷碗,抬头看天 + 适配北方农村冬季
```

> 三个示例对比:
> - A 是"漂亮精致",适合爽文
> - B 是"飘逸古典",适合言情
> - C 是"克制真实",适合作者电影
>
> **差异的关键不是画面精度,是细节密度和情绪层次**。

## 避坑指令合集(直接复制粘贴)

### 通用避坑

```
--no 模糊画面、色彩灰暗、比例失调、五官畸形、多余人物、穿帮元素
```

## 用法流程

1. **基础定位层**:3 秒钟填完,确定主角是谁
2. **细节描述层**:从五维档案里直接复制,确保跨镜一致
3. **风格指令层**:从 styles.md 选定风格包
4. **技术参数层**:写工具适配 + 比例(隐含 8K / 16:9)
5. **动作/场景适配层**:一句话说明这一镜在做什么

> **写完先自检**:对照五层表格,任何一层空白都会导致 AI 生成失败。
> 例:忘了填"色调风格",AI 默认输出灰白,跟你的题材冲突。
