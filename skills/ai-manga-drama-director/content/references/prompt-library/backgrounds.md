# AI 漫剧背景提示词手册

> 核心公式:`风格定位 + 场景主体 + 时空条件(时间+天气) + 氛围情绪 + 细节元素 + 镜头/光影`
> 一句话:把背景当成有情绪的角色去写,而不是"装饰品"。

## 二、创作技巧(进阶)

### (一)细节一致性保障

**(1)风格一致**:同一部漫剧所有背景提示词固定核心风格关键词(例:全部加"国漫仙侠风"前缀)。

**(2)元素复用**:重复使用固定细节元素(宗门标志、特定建筑风格、光影色调),强化世界观统一性。

**(3)角色关联**:背景提示词可补充角色比例参考(例:"适合 2D 动漫角色嵌入,人物与建筑比例 1:10"),确保角色与背景融合。

### (二)负向提示词(必看)

添加负向提示词排除无效元素。Midjourney 格式:`--no {无效元素}`

**常见负向提示词**:`--no 现代建筑、西方风格、照片写实、模糊、低细节、杂乱线条、多余人物、穿帮元素`

例:古风场景添加 `--no 现代汽车、霓虹灯、塑料材质`

### (三)工具适配调整

| 工具 | 调整要点 |
|---|---|
| 即梦(Dreamina) | 侧重角色锚定,背景加"与锁定角色风格一致""适配 2D 动漫分镜"。 |
| 海螺 AI / 香蕉 Pro | 强化细节描述,加"8K 分辨率""电影级渲染""动态粒子效果"。 |
| 文本转视频工具 | 补充镜头运动描述(例:"镜头缓慢推近""手持相机轻微抖动""跟拍角色移动轨迹")。 |

### (四)迭代优化技巧

1. **初次不理想**:逐步添加细节词(例:"森林"→"发光藤蔓缠绕的古森林,地面覆盖苔藓")
2. **调整色调描述**:例:"暖色调"→"橙红色夕阳色调","冷色调"→"蓝灰色冷调"
3. **翻译辅助**:水墨风 = ink wash painting style,仙侠 = xianxia fantasy

## 四、作者电影风格专用:现实主义背景

> 用户主推作者电影美学 + 社会议题,以上玄幻/赛博/奇幻风格都不太合适。补充 2 个写实背景模板。

### 北方农村冬季(留守儿童题材)

```
中国北方农村冬季,黄土地,旧砖房错落,空心村,
远处有冒烟的烟囱,天空灰蓝,地面残雪未化,
炊烟稀薄,老槐树光秃,枯草从残雪中探出,
35mm 胶片质感,贾樟柯早期电影,纪录片摄影,
冷蓝灰调,空气有颗粒感,景深明显,背景虚化,
晨雾散射的侧光,8K,电影宽幅 2.35:1
```

### 街道办办公室(基层公务员题材)

```
基层街道办办公室,90年代水泥建筑,白色瓷砖墙,铁皮档案柜,
绿色台面办公桌,日光灯管照得人影发黄,墙上贴满
红头文件和工作标语,饮水机嗡嗡作响,
老式吊扇低速旋转,光从百叶窗投射进来形成条纹阴影,
35mm 胶片质感,现实主义,新闻纪录片摄影,
冷调白平衡,空气混浊,8K
```

> 现实主义背景的关键词:**不精致、有年代感、有生活痕迹、有情绪层次**。
> 跟玄幻/赛博的"壮观漂亮"完全相反。
