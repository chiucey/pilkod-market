## 四、跨镜一致性锁定方案(按工具选)

### Midjourney(适合个人/小团队)

```
[场景描述] [动作] [运镜] --cref [三视图链接] --cw 100 --seed [重复值]
```

- `--cref`:锁定角色核心特征,允许更换场景/动作
- `--cw`:0-100 一致性强度,100=完全锁定
- `--seed`:固定生成起点,确保相同提示词生成相似结果
- **万能公式**:起名 → 垫图 → 微调 → 固化参数

### Stable Diffusion(专业级)

| 方案 | 适用 | 操作 |
|---|---|---|
| IP-Adapter + ControlNet | 高保真面部锁定 | 上传参考图 → 启用 Face Landmark → 锁定模型+权重 |
| LoRA 训练 | 长期连载角色 | 准备 20-50 张多角度图 → 训练 → 权重 0.6-0.8 |
| InstantID 插件 | 超精准面部还原 | 装 SDXL 版 → 上传正面照 → 自动匹配面部 |
| Embedding 嵌入 | 固定特征词 | 训练 Embedding → 提示词加 `<角色名>` |

### 即梦 / SEKO / 萌动 AI(国内一站式)

1. 上传 3-5 张角色参考图 → 生成专属角色库 → 锁定特征
2. 生成分镜时 @ 角色名,自动调取特征
3. 启用"角色记忆"或"特征码"功能

## 五、参数固化三大原则

```
1. 固定模型版本:全程 SDXL 1.0 / NIJI 6 / 即梦 V4,避免风格撕裂
2. 锁定核心参数:
   - 采样器:DPM++ 2M Karras
   - 步数:≥30 步(推荐 40-50)
   - CFG scale:7-8
   - Seed:记录满意结果的 seed,后续复用
3. 统一提示词结构:
   [角色核心特征] + [当前场景/动作/表情] + [风格词] + [一致性锁定词]
```

## 八、构建一致性"护城河"(进阶)

1. **360 度视图参考库**:正面 / 45° / 侧面 / 背面
2. **服饰拆解图**:标注各部分名称和特征
3. **常用动作库**:走 / 跑 / 坐 / 卧 / 战斗 各 3-5 张
4. **表情模板库**:日常 / 警觉 / 拒绝 / 悲伤 / 愤怒 各 1 张标准照
5. **镜头语言模板**:全景 / 中景 / 近景 / 特写 各 1 张标准照

> 这些参考图做一次,后续**所有剧集复用**,长期积累就是核心资产。
