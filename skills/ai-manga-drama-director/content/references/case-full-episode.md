# 完整长片案例: 《反正也没时间活》全流程 + 183 分镜

> 这是**完整 AI 短片全流程制作教程**的浓缩版,源自抖音爆款短片《反正也没时间活》(3D CG 科幻短片,首日 600 万点赞,作者@站立起来的影子)。
> 内容涵盖:**7 章全流程方法论 + 公共提示词库 + 183 分镜速记表 + 系列化方向**。
> 适用于想要**完整制作一部 2-3 分钟 AI 短片**的创作者。

---

## 一、剧作核心(故事主题与结构)

### 1.1 核心主题

**主题一:时间自由**——你以为自己拥有时间,其实时间拥有你
主角账面有 51 年寿命,但真正属于自己的时间只有 21 天。这不是科幻设定,是当代打工人的现实写照。

**主题二:打工人的系统性困境**
视频中的"扣除项"(工作 10 小时、通勤 2 小时、睡觉、刷手机)不是某人的不幸,是系统性的生活方式。每一个扣除项指向一个社会结构:加班文化、城市空间设计、生理限制、算法经济。

**主题三:现代生活的荒诞性**
一个寿命 3700 年的高等文明,最终来回收人类的"自由时间"——因为他们**连发呆的空当都没有**。

### 1.2 三幕结构

| 幕 | 内容 | 时长占比 | 情绪 |
|---|---|---|---|
| **第一幕(引入)** | 城市全景 → 主角日常 → 被债务压垮 → 决定卖时间 → 回收者出现 | ~25% | 压抑 → 绝望 |
| **第二幕(冲突)** | 回收者解释规则 → 开始算账 → 逐项扣除 → 数字越来越小 → 主角震惊 | ~50% | 好奇 → 紧张 → 震惊 |
| **第三幕(反转与升华)** | 回收者自述文明悲剧 → 揭示 21 天的残酷现实 → 金句收尾 | ~25% | 震撼 → 共鸣 → 释然 |

### 1.3 钩子设计

| 钩子类型 | 内容 | 功能 |
|---|---|---|
| **设定钩子**(0-30s) | 回收者从蓝光中出现,说明"只收自由时间"的规则 | 世界观独特性引发持续观看动力 |
| **数据冲击钩子**(中段) | 全息面板上数字不断缩小,每项扣除都像一记重锤 | 数字递减制造紧张感和"到底剩多少"的悬念 |
| **反转钩子**(高潮前) | "我们眼红你们那点无所事事的时间" | 认知颠覆——高等文明羡慕人类 |
| **情感钩子**(结尾) | "他们终于换来了那个未来,却发现已经没多少时间享受它了" | 引发分享欲和评论讨论,是传播的关键驱动力 |

### 1.4 情绪曲线设计

```
铺垫(0-15s,压抑沉闷) → 触发(15-30s,绝望中看到希望) → 
好奇(30-50s) → 紧张(50-80s,数字递减) → 震惊(80-95s,"21 天"定格) → 
反转(95-115s,"我们眼红你们"震撼) → 余韵(115s+,悲壮释然)
```

> **核心原则**:"让观众来不及消化上一秒的情绪,下一秒就已经扑面而来"。

## 二、角色设定

### 2.1 主角(打工人)

**基本信息**:
- 性别:男 / 年龄:30-32 / 身高 175cm / 中等身材偏瘦
- 外貌:五官端正但普通(地铁里每天见到但记不住的脸)/ 黑色短发略凌乱 / 眼袋重 / 黑眼圈 / 皮肤偏白无光泽
- **典型特征**:轻微驼背(长期伏案的痕迹)

**服装三场景**:
| 场景 | 服装 |
|---|---|
| 日常/出租屋 | 灰色棉质 T 恤(有褶皱)+ 深色运动裤 + 拖鞋 |
| 工作 | 深色衬衫(袖子挽到前臂)+ 西裤不够挺括 + 领带松垮 |
| 通勤 | 深色连帽卫衣 + 耳机挂脖子 + 双肩包 |

**表情与肢体**:
- 日常状态:眼神空洞、动作迟缓(像手机只剩 5% 电量)
- 看到账单:眉头紧锁、双手攥紧
- 面对回收者:恐惧 → 好奇 → 震惊
- 算账过程:轻松 → 皱眉 → 嘴唇微张 → 脸色发白 → 颤抖

**主角英文提示词模板(可直接用)**:
```
A Chinese man, 30 years old, short messy black hair with fringe,
ordinary facial features, noticeable dark circles under eyes,
pale dull skin, medium build slightly thin with mild slouch,
wearing a wrinkled gray cotton t-shirt, tired expression,
cinematic lighting, 3D render, Pixar-style realism,
front view portrait, neutral background, detailed face,
consistent character design sheet
```

### 2.2 回收者(外星时间回收员)

**基本信息**:
- 外形:身高 190cm,修长挺拔,完美比例(对比主角的中等偏瘦)
- 肤色:**半透明苍白蓝灰色**,无人类毛孔纹理
- 眼睛:发冷蓝色光、不眨眼、注视如扫描
- 头发:银白色,梳成 slicked back
- 服装:**无缝深灰金属紧身服**,关节处有蓝色电路纹路
- **胸口**:小型发光几何符号(类似沙漏的抽象图形)= 职业身份标识

**行为特征**:
- 默认状态:极度冷静、表情几乎不变、说话像 AI 助手
- 细微变化:说到自己文明困境时,蓝光微微闪烁、嘴唇几乎不可察觉颤抖(唯一流露情感)
- 肢体:动作精确经济,没有多余动作,双手自然垂在身侧

**关键反差点**(与主角对比):

| 维度 | 主角(打工人) | 回收者(高等文明) |
|---|---|---|
| 体型 | 中等偏瘦、驼背 | 修长挺拔、完美比例 |
| 肤色 | 暗沉苍白 | 半透明苍白蓝灰 |
| 眼睛 | 眼袋重、黑眼圈 | 冷蓝光、不眨眼 |
| 服装 | 褶皱、松垮、廉价感 | 无缝、贴身、未来科技感 |
| 表情 | 丰富(焦虑/恐惧/震惊/苦笑) | 几乎没有(只在关键时刻微变) |

> **视觉反差的隐喻**:看起来"低等"的人类拥有"高等"文明所没有的东西——这正是最终反转的视觉基础。

## 五、风格统一方案

### 主色调 + 辅助色

| 类型 | 颜色 | 用途 |
|---|---|---|
| 主色调 | 冷蓝色 #1a2a4a ~ #2a3a6a | 全片基调,低饱和度 |
| 辅助色 | 深紫色 #2a1a3a、暗灰 #1a1a2a | 阴影和暗部 |
| 强调色 | 回收者蓝光 #4a8aff、全息面板 #aaccff | 关键道具和角色 |
| 肤色 | 主角暗沉暖黄 / 回收者苍白蓝灰 | 两者鲜明对比 |

### 光影一致性

- **主光方向**:所有室内场景统一使用左上方 45° 主光(模拟窗户光/屏幕光)
- **轮廓光**:回收者始终有蓝色边缘光/轮廓光,主角没有(强调其"普通人"属性)
- **阴影**:硬朗阴影为主,减少柔和过渡,增强 CG 质感
- **环境光遮蔽**:所有场景启用 AO,增强空间纵深感

## 七、后期制作

### 7.1 剪辑节奏

1. 先按旁白音频铺设时间线,确定每个镜头的起止点
2. 粗剪:按顺序排好所有片段,检查叙事流畅性
3. 精剪:微调入点和出点,确保动作连贯
4. 节奏调整:在关键情节点加入静默/停顿,强化情绪

### 7.2 音效设计层次

| 层次 | 内容 | 音量 |
|---|---|---|
| **环境底层** | 城市低频嗡鸣、室内空调声、远处车流 | -18 ~ -24dB |
| **动作音效** | 脚步、开门、手机震动、椅子移动 | -12 ~ -6dB |
| **科幻音效** | 回收者出场能量声、全息面板操作音、数字变化音 | -8 ~ -3dB |
| **情绪音效** | 低频鼓点、心跳声、反转时的"嗡"声 | 视情绪调整 |
| **背景音乐** | 氛围音乐,随情绪变化 | -15 ~ -10dB |

### 7.3 调色统一(LUT 制作)

1. 在剪映中创建统一调色预设
3. 降低整体饱和度 20-30%
4. 阴影偏蓝(色温 -10,色调 -5)
5. 高光偏冷白
6. 增加对比度 10-15%
7. 添加轻微胶片颗粒(grain 3-5%)
8. 暗角效果(vignette 15-20%)

### 7.4 字幕设计

- **旁白字幕**:白色 + 微软雅黑/思源黑体,大小适中,位置画面下方 1/4 处,白色+轻微黑色描边
- **结尾金句字幕**:宋体/衬线体,较大居中,白色/浅金色,逐句缓慢淡入

**核心结构**:
- **镜 1-25**:开场 + 主角登场 + 回收者出现 + 规则说明(25 镜,25 秒)
- **镜 26-50**:主角决定卖时间 + 算账开始 + 第一个扣除(25 镜,25 秒)
- **镜 51-75**:算账逐项扣除 + 数字递减(25 镜,25 秒)
- **镜 76-100**:外星场景切换 + 回收者文明展示(20 秒)
- **镜 101-140**:主角日常蒙太奇 + 自由时间画面(40 秒)
- **镜 141-160**:回收者解释 + 规则深化(20 秒)
- **镜 161-178**:反思 + 算账结束 + 结尾铺垫(18 秒)
- **镜 179-183**:黑屏金句收尾 + 标题卡(5 秒)

> **核心创作启示**:**183 镜的高密度短句**适合抖音中长视频节奏(每镜 1-2 秒),**用对话推进剧情而不是画面动作**——这是"AI 短片 = 加速版广播剧"的本质。

**预期**:触及更深层的生死议题,情感浓度更高,适合清明节/重阳节传播。

**改编**:城市年轻人收到"想念接收器"装置,远方父母在想他们时装置亮起微光。

## 十四、避坑指南(本案例踩过的坑)

1. **183 镜容易过长**:很多新手做"高密度短句"时,会出现"183 镜 3 分钟"——密度太高观众消化不了。本教程的"镜头时长分配原则"(第六章)是解决方案。
2. **3D CG 风格容易"油腻"**:这是用户特别提到的痛点。规避方案:
   - **降低整体饱和度 20-30%**
   - **保留面部细节(毛孔、皱纹),不要过度磨皮**
   - **光影要"克制",不要全亮或全暗**
   - **避免 AI 默认的"完美比例",加入真实痕迹(驼背/眼袋/皱纹)**
3. **公共提示词要严格遵守**:每个分镜都要用"公共风格词"前缀,否则风格会漂移。
4. **数字递减节奏要精确**:每次"扣除"要有节奏感——像刀割,而不是流水账。**关键数字("21 天")要大、清晰,让观众也能看到**。
5. **结尾金句要"留白"**:不能太满。"你现在正在花多少时间看这个视频"是打破第四面墙的彩蛋,不是正经说教。
