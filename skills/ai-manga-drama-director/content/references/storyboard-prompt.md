# 分镜脚本提示词模板

> 把导演剧本转成 16-18 个分镜的 AI 生图 / 生视频提示词。

---

## 一、单镜头提示词公式

```
[运镜/景别] + [主体] + [场景细节] + [光影色调] + [技术参数]
```

### 范例 1 — 大远景开场

```
[大远景,缓推,8 秒]
北方农村冬季清晨,黄土地,空心村,旧砖房错落,远处有冒烟的烟囱,
天空灰蓝,地面残雪未化,炊烟稀薄,镜头从村庄边缘缓慢推向中心
一间亮着灯的房屋。

光影:晨雾散射的侧光,色调冷蓝灰,空气有颗粒感
声音:远处鸡叫,风穿过枯枝
风格:35mm 胶片质感,贾樟柯早期电影,8K,电影宽幅 2.35:1
```

### 范例 2 — 主角出场中景

```
[中景,固定,6 秒]
小宇(8 岁,圆脸,黑色短发,眼神安静)从屋内走出,
穿深蓝色旧中式棉袄(褪色,袖口有补丁),内穿旧灰色毛衣,
下深色棉裤,旧布鞋。站在院子中间,手里端着搪瓷碗,
碗里有半碗白粥。抬头看天,停顿 2 秒,又低头。
```

### 范例 3 — 对话近景

## 五、动态视频生成分镜提示词

分镜图转视频时,在原提示词末尾加:

```
[动态描述]:
- 人物动作:[头部微微转向 / 手抬起 / 眼睛慢慢睁开]
- 镜头运动:[固定 2 秒后缓推 / 横向跟踪 / 缓慢下摇]
- 环境动态:[风吹动衣摆 / 烟雾飘动 / 落叶飘过]
- 时长:[4-10 秒]
- 口型同步:[有对白时开启对口型功能]
```

## 七、生图 → 生视频 → 后期 标准流转

```
1. 用 [镜头提示词] + 角色 DNA + 三视图 cref → 生成分镜图
2. 检查五维一致性(参考 character-dna.md 第六节清单)
3. 用即梦 / SEKO 一键转视频(或海螺AI首尾帧功能)
4. 导出后导入剪映:
   - 添加 AI 配音(选适配人设的音色)
   - 添加环境音/动作音效
   - 自动字幕,字体选无衬线/楷体(适配电影质感)
   - 基础转场(溶解/推进)
   - 调色滤镜(墨染/电影色调)
5. 导出 9:16 或 2.35:1,1080P,30fps,无水印
```

## 八、常见失败模式

| 失败 | 修正 |
|---|---|
| 人物变形 | 每次生图前必须加 `--cref 三视图链接` |
| 场景跳脱 | 在场景描述里复述"延续上一镜的环境光/色调" |
| 镜头过满 | 每 2-3 镜必须有 1 个无对白镜头 |
| 动作僵硬 | 必须经"生视频"环节才能用 |
| 口型错位 | 有对白的镜头必须开启"对口型"功能 |
| 滤镜破坏冷暖调 | 调色前先定主色调(冷蓝灰 / 暖黄)再选滤镜 |

## 九、分镜脚本 10 大核心模块(结构化清单)

> AI 漫剧分镜脚本同时服务两个目标:**叙事完整 + AI 可生成**。每一镜按以下 10 项填写,缺一项就容易出问题。

| # | 模块 | 填写要点 | 常见坑 |
|---|---|---|---|
| 1 | **镜号** | 按剧情顺序编号(1/2/3),插入分镜用"2-A"避免混乱 | 后续删镜时忘了重编号 |
| 2 | **景别** | 远景/全景/中景/近景/特写/大特写(慎用) | 用错景别 → 信息密度错误 |
| 3 | **镜头运动** | 固定/推/拉/摇/移/跟/旋转,标注速度 | 复杂运动 AI 出错 → 拆多镜 |
| 4 | **画面内容** | 角色(动作+表情)+ 场景细节 + 光影氛围 + 关键道具 | 模糊描述("很开心")→ AI 出图跑偏 |
| 5 | **台词/旁白/音效** | 角色名:台词(语气);旁白:内容;音效:类型+时机+音量 | 没标语气 → 配音失准 |
| 6 | **时长** | 对话 1-2s/句,动作 2-5s,过渡 1-2s,特写 1-2s | 一句台词给 8s → 节奏拖沓 |
| 7 | **AI 风格提示** | 基础风格 + 绘画技法 + 画质 + 风格参考 + 特殊要求 | 风格不一致 → 视觉撕裂 |
| 8 | **备注** | AI 避坑(避免崩脸)+ 转场方式 + 字幕位置 | 没标 → 后期不知道要做什么 |

> **脚本开头**必须标注"全局风格设定",后续分镜简化为"延续全局风格"——避免前镜日系清新、后镜国风厚重的混乱。

## 十、画面内容精准描述公式(AI 适配核心)

**模糊 → 精准 对照**:

| 模糊 | 精准 |
|---|---|
| "主角在房间里开心" | "主角(17 岁少女,双马尾,校服)坐在书桌前,双手握拳放在胸前,嘴角上扬露出虎牙,眼神明亮;房间布局:左侧书架摆满漫画,右侧窗户透进暖黄色夕阳,书桌上放着一杯冒着热气的牛奶,桌角粉色闹钟显示 18:30;光影:夕阳斜照,在墙面投下主角的影子,色调温暖柔和" |

**精准描述的 5 个要素**:
1. **角色状态**:动作 + 神态 + 表情(分部位:眉/眼/嘴/鼻/头/肩)
2. **场景细节**:环境元素 + 布局(具体物件摆放,不写"一个房间")
3. **光影氛围**:光线类型(自然/人造/特殊) + 色调(冷/暖/复古)
4. **关键道具**:位置 + 状态
5. **细节具象化**:复杂动作拆解为肢体动作 + 衣物动态("跑步"→"弯腰奔跑,双臂前后摆动,校服裙摆向后飘动,脚步急促")

### 时长分配原则

| 类型 | 时长 |
|---|---|
| 对话(每句) | 1-2s,表情停顿 +0.5-1s |
| 简单动作(走路/递东西) | 2-3s |
| 复杂动作(战斗/奔跑) | 3-5s |
| 场景过渡 | 1-2s |
| 特写 | 1-2s,过长视觉疲劳 |

## 十二、提示词全体系(核心公式 + 模板)

### 通用核心公式

**基础公式(必选)**:`[核心主体(权重 1.5-1.7)] + [动作/状态] + [场景环境] + [风格定义] + [镜头语言] + [画质要求]`

**完整公式(进阶)**:`[核心主体(权重)] + [细节特征] + [动作/状态] + [场景环境] + [风格定义] + [镜头语言] + [光影效果] + [画质要求] | 负面提示词`

**权重标注(Midjourney / SD)**:`角色名:1.6` 形式,范围 1.0-2.0,核心 1.5-1.7,次要 1.2-1.4。

**正向 vs 反向**:
- **正向**:明确"画什么",越具体越精准("齐肩短发"而非"短发")
- **反向**:标注"别画什么",避免崩图(畸形肢体/多手指/模糊边缘/错位眼睛/杂乱背景)

## 十五、动态镜头适配 AI 的处理

| AI 工具能力 | 处理方式 |
|---|---|
| **仅静态出图** | 把"推/拉/摇/移"拆为"起点帧 + 过渡帧 + 终点帧",逐帧生成后拼接 |
| **支持动态生成** | 标注"镜头运动速度 + 帧速率(24/30fps)",备注"帧间连贯性强" |
| **复杂动态(旋转镜/鱼眼)** | 在备注里写"画面无畸变",避免 AI 抖动扭曲 |

> **避坑**:避免在一镜里塞太多信息。多人战斗场景拆成"特写单角色 → 中景两人对战 → 全景战场概览",**不要指望一镜搞定**。
