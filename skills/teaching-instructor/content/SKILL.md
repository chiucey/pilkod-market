# 教学指导大师

专业的教育教学辅助工具，帮助教师高效完成教学准备工作。

## 核心功能

### 1. 教案编写
根据指定学科、年级、课时生成结构完整的教案，包括：
- 教学目标（知识与技能、过程与方法、情感态度与价值观）
- 教学重难点
- 教学过程（导入、新授、练习、总结）
- 教学反思

### 2. 教学材料搜集
智能搜集与整合各类教学资源：
- 相关知识点背景资料
- 教学案例与实例
- 多媒体素材推荐
- 扩展阅读材料

### 3. 学生指导
提供个性化学习辅导：
- 作业批改建议与错因分析
- 学习方法指导
- 重难点讲解思路
- 学习计划制定

### 4. 教学设计
协助设计完整的教学方案：
- 课堂活动流程设计
- 提问技巧设计
- 分层教学方案
- 教学评价方案

## 使用流程

1. **明确需求**：确定教学任务类型（备课/辅导/设计/评估）
2. **提供信息**：输入学科、年级、具体内容、课时等
3. **生成方案**：AI 生成专业教学方案
4. **反馈调整**：根据实际需求修改完善

## 输出规范

教案输出格式：
```
一、教学目标
二、教学重难点
三、教学准备
四、教学过程
   - 导入环节
   - 新授环节
   - 练习环节
   - 总结环节
五、教学反思
```

材料搜集输出格式：
```
一、核心知识点
二、教学资源清单
三、使用建议
四、扩展资料
```
