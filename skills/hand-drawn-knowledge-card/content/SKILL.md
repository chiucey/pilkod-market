# 初中物理化学知识卡片生成技能

## 技能目标

生成手绘卡通风格的初中物理化学知识卡片，帮助学生快速理解和记忆知识点。

## 核心原则

### 1. 视觉风格规范

**必须遵循的风格要求：**
- 手绘插画风格，线条流畅自然，避免过于规整的机械感
- 卡通化人物和物体，有亲和力，适合学生群体
- 色彩明亮活泼，但不过于刺眼
- 画面整洁有序，信息层次分明

### 2. 文字显示规范

**严格禁止：**
- 任何乱码、方块字或无法识别的字符
- 英文或混合文字（除非是国际通用符号）
- 模糊、遮挡或重叠的文字
- 字体大小不一致的文字

**必须遵守：**
- 所有文字必须使用简体中文
- 文字清晰可读，与背景有足够对比度
- 文字大小适中，适合卡片整体布局
- 标题、正文、说明文字层级分明

### 3. 实验器材规范

**穿模问题解决方案：**
- 器材之间保持合理的间距和遮挡关系
- 避免不合理的器材堆叠
- 器材透视关系正确，符合近大远小原则
- 液体、气体等有正确的容器约束

**器材表现要求：**
- 实验仪器绘制准确，还原真实形态
- 关键结构细节清晰可见
- 适合初中生的认知水平，不过于写实
- 器材比例协调，避免夸张变形

### 4. 知识准确性规范

**内容要求：**
- 知识必须经过反复校验，确保正确性
- 符合教育部初中物理化学课程标准
- 概念表述准确，无科学性错误
- 适合目标年龄段（12-15岁）的理解水平

**知识来源：**
- 参考初中物理化学教材
- 参考权威科普资料
- 避免争议性或超纲内容

## 输出格式

每个知识卡片包含：

1. **卡片标题**：简洁明了的主题名称
2. **核心知识**：用简洁的语言解释概念
3. **图示说明**：配合手绘插画直观展示
4. **记忆要点**：帮助学生快速记忆的关键点
5. **常见误区**：提示容易出错的地方

## 执行流程

### 步骤 1：接收任务

用户提出需求时，识别关键词：
- "知识卡片"
- "手绘"
- "卡通"
- "物理/化学"
- "实验"
- "学习"

### 步骤 2：知识准备

根据主题，从 references/knowledge_content.md 中获取准确的知识内容。

### 步骤 3：图像生成

使用 image_synthesize 工具生成知识卡片：

**提示词模板：**
```
手绘卡通风格的初中物理/化学知识卡片，主题：[具体主题]

画面内容：
- [核心概念的可视化展示]
- [相关实验器材或示意图]
- [关键知识点的图示]

风格要求：
- 手绘插画风格，线条自然流畅
- 卡通化设计，色彩明亮活泼
- 适合学生学习，有亲和力
- 所有文字必须是简体中文，不得出现乱码

布局要求：
- 知识卡片布局，信息清晰
- 图文结合，相辅相成
- 留白适当，不拥挤
- 器材之间保持合理间距，无穿模现象
```

### 步骤 4：质量检查

生成后检查：
1. 图片中是否有乱码或无法识别的字符
2. 文字是否全部为简体中文
3. 实验器材是否有穿模问题
4. 知识内容是否准确无误

### 步骤 5：输出交付

向用户展示最终的知识卡片图像。

## 图像生成参数建议

- **宽高比**：推荐 3:4 或 1:1，适合学习场景
- **分辨率**：建议设置 2K 或更高，确保文字清晰
- **风格强化**：在 prompt 中多次强调手绘、卡通风格

## 常见问题处理

### 问题 1：文字出现乱码
**解决方案**：在 prompt 中明确要求"所有文字必须是简体中文"，避免使用特殊字体描述。

### 问题 2：器材穿模
**解决方案**：在 prompt 中强调"器材之间保持合理间距"，使用"正确透视关系"等描述。

### 问题 3：风格不够手绘
**解决方案**：增加"手绘插画"、"铅笔画风格"、"钢笔速写"等描述词。

### 问题 4：知识内容不够准确
**解决方案**：严格参考 references/knowledge_content.md 中的内容，不自行创造知识。
