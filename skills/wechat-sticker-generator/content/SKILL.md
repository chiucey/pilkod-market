# 微信表情包生成器

专为微信开放平台设计的GIF表情包生成技能，严格遵循微信上传规范，支持系列表情包的风格延续。

## 核心能力

- **微信规范兼容**：所有输出完全符合微信表情开放平台的尺寸、格式、文件大小要求
- **系列风格延续**：通过角色设定文件和风格配置，确保多次生成保持统一视觉风格
- **批量生成支持**：支持16张或24张一套的表情包批量生成
- **一键输出缩略图**：自动生成符合要求的缩略图

---

## 微信表情开放平台规范

### 表情主图规格

| 项目 | 要求 |
|------|------|
| 格式 | GIF |
| 尺寸 | 240×240 像素 |
| 文件大小 | 不大于 500KB（建议控制在100KB以内更易通过审核） |
| 数量 | 8张、16张或24张 |
| 动画 | 需设置永久循环播放 |
| 风格 | 同一套表情须全部动态或全部静态 |
| 描边 | 建议添加2像素白色描边，避免边缘锯齿 |

### 表情缩略图规格

| 项目 | 要求 |
|------|------|
| 格式 | PNG（透明背景） |
| 尺寸 | 120×120 像素（专辑）/ 240×240 像素（单品） |
| 文件大小 | 不大于 200KB（建议50KB以内） |
| 数量 | 与主图一致 |
| 描边 | **不可有白色描边** |

### 其他素材规格

| 素材 | 尺寸 | 文件大小 | 格式 |
|------|------|---------|------|
| 详情页横幅 | 750×400 像素 | ≤500KB | PNG/JPEG |
| 表情封面图 | 240×240 像素 | ≤500KB | PNG（透明底） |
| 聊天面板图标 | 50×50 像素 | ≤100KB | PNG（透明底） |
| 赞赏引导图 | 750×560 像素 | ≤100KB | PNG/GIF |
| 致谢图 | 750×750 像素 | ≤200KB | PNG/GIF |

## 工作流程

### 阶段1：角色与风格设定

**首次使用时，需建立角色设定文件：**

```
角色名称：[给你的表情角色起名]
角色外观：[详细描述外貌特征，如：圆脸、大眼睛、包子头等]
配色方案：[列出主色和辅助色，如：粉色系、蓝色系]
性格特点：[描述角色性格，如：活泼可爱、傲娇高冷]
常用动作：[列举招牌动作，如：捂脸、点头、比心]
风格参考：[可选，参考的艺术风格或已有形象]
```

**保存到 `/workspace/sticker_projects/[项目名]/character_profile.json`**

### 阶段2：表情含义规划

**规划表情内容列表（每个表情需提供）：**

1. 表情序号（01-24）
2. 表情含义词（不超过4个汉字）
3. 核心动作描述
4. 情绪状态

**含义词示例**：
- 01 - 开心
- 02 - 生气
- 03 - 委屈
- 04 - 点赞
- 05 - 害羞
- 06 - 惊讶
- 07 - 得意
- 08 - 委屈

### 阶段3：生成参数配置

**微信表情专用参数：**

```json
{
  "main_image": {
    "width": 240,
    "height": 240,
    "format": "GIF",
    "max_file_size_kb": 100,
    "framerate": 12,
    "max_frames": 16,
    "white_stroke": true,
    "stroke_width": 2
  },
  "thumbnail": {
    "width": 120,
    "height": 120,
    "format": "PNG",
    "transparent": true,
    "no_stroke": true
  }
}
```

### 阶段4：生成执行

**生成主图（GIF）:**

使用 `image_synthesize` 工具批量生成帧：

```json
{
  "requests": [
    {
      "prompt": "[角色描述] + [表情动作描述], 正面脸部特写, 白色背景或透明背景, 微信表情包风格, 240x240像素, 高清细腻",
      "output_file": "[output_path]/[序号]_[含义].png",
      "aspect_ratio": "1:1"
    }
  ]
}
```

**关键帧提示词模板：**

```
【开心】
[角色名]开心地眯起眼睛笑，露出可爱的[表情元素]，
嘴巴张大做成[形状]，脸颊微微泛红，
简单的[背景色]色背景，微信表情包风格，240x240像素

【生气】
[角色名]气得眉毛竖起，眼睛变成[形状]，
嘴巴撅起或咬牙切齿，脸颊[颜色]红，
简单的[背景色]色背景，微信表情包风格，240x240像素

【委屈】
[角色名]眼眶湿润，眉毛呈[形状]，嘴巴扁扁的，
低着头，[身体姿态描述]，
简单的[背景色]色背景，微信表情包风格，240x240像素

【点赞】
[角色名]伸出大拇指，眼睛弯成月牙形，
嘴巴微笑，身体[姿态]，
简单的[背景色]色背景，微信表情包风格，240x240像素
```

**转换为GIF：**

```bash
# 单张GIF生成（通过视频转GIF）
ffmpeg -framerate 12 -i frame_%03d.png \
  -vf "scale=240:240:flags=lanczos,split[s0][s1];[s0]palettegen=max_colors=128[p];[s1][p]paletteuse=dither=bayer" \
  -loop 0 output.gif

# 优化压缩（确保<100KB）
ffmpeg -i input.gif -vf "fps=12,scale=240:-1:flags=lanczos,split[s0][s1];[s0]palettegen=max_colors=64[p];[s1][p]paletteuse" -loop 0 -fs 100K output_optimized.gif
```

**生成缩略图（PNG）:**

从主图中提取关键帧，转换为120×120像素PNG：

```bash
# 提取第1帧作为缩略图
ffmpeg -i main_01.gif -vf "scale=120:120:flags=lanczos" -vframes 1 thumbnail_01.png

# 移除白色描边（如果需要）
convert thumbnail_01.png -trim +repage thumbnail_01_clean.png
```

      "happy": "眼睛眯成月牙,嘴巴张大微笑,脸颊红晕",

每次生成时，自动从角色设定中提取：

- **配色方案**：从 `color_palette` 提取
- **风格标签**：从 `style_keywords` 提取
- **表情变体**：从 `expression_variants` 提取

## 常见问题处理

### 问题1：GIF文件过大

**解决方案**：
1. 减少帧数（从16帧减少到8-12帧）
2. 降低颜色数量（使用调色板优化）
3. 使用 `palettegen` 生成优化调色板
4. 压缩命令：`ffmpeg -i input.gif -fs 100K output.gif`

### 问题2：动画播放不流畅

**解决方案**：
1. 确保帧率不低于10fps
2. 生成更多中间帧
3. 检查首尾帧是否衔接自然

### 问题3：系列风格不一致

**解决方案**：
1. 检查角色设定文件是否完整
2. 确保使用相同的风格关键词
3. 使用统一的配色方案
