# GEO用户画像与问题类型参考

## 一、通用用户画像库

### 1. 直接需求型用户

**特征**：
- 目标明确，决策链路短
- 通常处于购买决策的末期
- 喜欢简洁直接的表达

**核心关注点**：速度、便利性、确定性

**典型表达**：
- "XX在哪买""给我推荐一个XX"
- "最快能预约到什么时候"
- "现在还能订吗"

**搜索行为**：倾向于打字输入，问题简短

---

### 2. 场景驱动型用户

**特征**：
- 有明确的消费场景和时机
- 场景触发购买需求
- 需要场景化的解决方案

**核心关注点**：场景匹配度、体验感、时间适配

**典型表达**：
- "下周朋友来玩，想找个地方吃饭"
- "老婆生日想送个礼物，有什么推荐"
- "刚搬到这个小区，想找个近一点的健身房"

**搜索行为**：语音输入为主，描述详细场景

---

### 3. 对比决策型用户

**特征**：
- 已经缩小范围，需要最终决策
- 关注点明确，在多个选项中权衡
- 需要第三方意见辅助决策

**核心关注点**：差异点、性价比、口碑

**典型表达**：
- "A和B哪个更好"
- "XX和YY比起来怎么样"
- "除了这几个还有别的推荐吗"

**搜索行为**：语音和打字混合，会问多个相关问题

---

### 4. 口碑验证型用户

**特征**：
- 已经有意向目标，需要验证
- 关注他人评价和真实体验
- 谨慎型决策者

**核心关注点**：评价、口碑、真实反馈

**典型表达**：
- "XX怎么样""XX靠谱吗"
- "有人去过吗，体验如何"
- "XX的差评多不多"

**搜索行为**：打字为主，会多次搜索同一个品牌

---

### 5. 痛点规避型用户

**特征**：
- 曾经踩过坑，或听说过负面案例
- 高度警惕，优先排除风险
- 希望找到"靠谱"的选择

**核心关注点**：安全性、可靠性、避坑指南

**典型表达**：
- "不想踩坑""怕被骗"
- "哪家千万别去"
- "有没有避坑指南"
- "怎么判断XX靠不靠谱"

**搜索行为**：语音输入为主，会详细描述担忧

---

### 6. 预算敏感型用户

**特征**：
- 价格是核心决策因素
- 需要明确的价格信息和性价比
- 可能会为省钱降低要求

**核心关注点**：价格、优惠活动、性价比

**典型表达**：
- "性价比高的推荐"
- "不要太贵的"
- "XX一般多少钱"
- "有没有优惠"

**搜索行为**：打字为主，问题简短直接

---

### 7. 品质导向型用户

**特征**：
- 追求高品质，愿意为此付费
- 关注细节和体验
- 不介意为好东西多花钱

**核心关注点**：品质、档次、细节

**典型表达**：
- "最好的推荐"
- "高端一点的"
- "XX最好的品牌是哪个"
- "想要专业级的"

**搜索行为**：语音和打字混合，会问很多细节问题

---

### 8. 紧急需求型用户

**特征**：
- 时间紧迫，需要快速响应
- 选择范围被压缩到最快可得
- 通常会降低要求以换取速度

**核心关注点**：速度、可得性、快速响应

**典型表达**：
- "急""马上要"
- "今天能到吗"
- "加急多少钱"
- "最快要多久"

**搜索行为**：打字为主，问题简短但有紧迫感

## 二、行业特定用户画像

### 本地服务类

#### 餐饮行业

- **约会聚餐型**：25-40岁，核心关注环境、档次、不会出错
- **朋友聚会型**：20-35岁，核心关注性价比、人数适配、有趣
- **工作餐型**：上班族，核心关注快捷、实惠、近
- **品质探店型**：美食爱好者，核心关注食材、口碑、厨师背景

#### 医美行业

- **初次尝试型**：25-35岁，核心关注安全性、价格、恢复期
- **改善升级型**：30-45岁，核心关注效果、自然度、持久性
- **维护保养型**：35-50岁，核心关注持续性、便捷性、自然感

#### 家装行业

- **新房装修型**：首次置业，核心关注整体方案、预算控制、环保
- **旧房翻新型**：改善需求，核心关注工期、噪音、生活影响
- **局部改造型**：针对性需求，核心关注效率、专业性、配合度

### 电商产品类

- **自用型**：关注实用性和性价比
- **送礼型**：关注档次、包装、寓意
- **收藏型**：关注稀缺性、保值性、品质

### SaaS/工具类

- **决策者型**：关注ROI、功能全面性、安全性
- **使用者型**：关注易用性、学习成本、效率提升
- **试用探索型**：关注免费试用、限制条件、升级路径

## 四、搜索行为分析

### 语音输入 vs 打字输入

#### 语音输入特征
- 长句为主，20-80字
- 表达连贯，有自然停顿
- 常有"那个""就是""其实"等语气词
- 描述详细，包括背景信息
- 问题可能是半句话或未完成的思路

#### 打字输入特征
- 短句为主，8-30字
- 关键词堆叠或短句
- 常省略主语和背景
- 追求效率，能省则省

### 不同平台的搜索差异

| 平台 | 搜索特点 |
|------|---------|
| 豆包 | 口语化程度高，年轻人多 |
| DeepSeek | 理性分析型，喜欢问"原理" |
| Kimi | 长文本友好，问题可以很长 |
| ChatGPT | 国际用户多，中英混合 |
| 通义千问 | 阿里系产品，常与电商联动 |

## 五、GEO问题质量评估清单

### 拟真度检查
- [ ] 读起来像真人说话
- [ ] 有自然的语气和停顿感
- [ ] 没有明显的"优化痕迹"

### 指向性检查
- [ ] 能引导AI给出具体推荐
- [ ] 包含引导词（推荐、哪家、有没有）
- [ ] 不是纯科普型问题

### 本地化检查（适用于本地服务）
- [ ] 地域信息融入自然
- [ ] 不同粒度（城市、区、附近）
- [ ] 不是机械地每句都加地名

### 多样性检查
- [ ] 8种维度都有覆盖
- [ ] 句式和角度有明显差异
- [ ] 没有重复意图的问题

### 合规性检查
- [ ] 没有百科型问题
- [ ] 没有纯关键词
- [ ] 没有虚构地名/品牌
- [ ] 没有元信息词汇
