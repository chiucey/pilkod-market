# 关键信息识别模式参考

本文档详细说明各类关键信息的识别模式和示例。

## 1. 身份信息 (Identity)

### 识别关键词
| 中文 | English | 说明 |
|------|---------|------|
| 我叫 | my name is | 名字 |
| 叫我 | call me | 昵称 |
| 名字是 | name | 名字 |
| 头像 | avatar/profile | 头像描述 |
| 形象 | image/appearance | 外貌 |
| 样子 | look | 样子 |
| 我是 | I am | 身份描述 |

### 识别正则模式

```python
# 中文名字模式
r'(?:我(?:的)?名字|叫(?:我做|我)?|叫我)\s*["\']?([^\s"\'\n,，]+)["\']?'

# 英文名字模式
r'(?:my name(?: is)?|call me|named?)\s*["\']?([^\s"\'\n,]+)["\']?'

# 头像描述模式
r'(?:头像|形象|样子|外观)\s*(?:是|为|:|：)?\s*["\']?([^"\'\n]+)["\']?'
r'(?:avatar|profile image)\s*(?:is|:)?\s*["\']?([^"\'\n]+)["\']?'
```

### 示例对话

| 用户输入 | 提取结果 |
|----------|----------|
| "我叫小明" | `{"name": "小明"}` |
| "叫我Nova就好" | `{"nickname": "Nova"}` |
| "我的头像是月光下的男孩" | `{"avatar": "月光下的男孩"}` |
| "My name is Nova" | `{"name": "Nova"}` |
| "Call me Nova, I'm a wizard on a star" | `{"name": "Nova", "description": "wizard on a star"}` |

## 2. 偏好设置 (Preferences)

### 识别关键词
| 中文 | English | 说明 |
|------|---------|------|
| 叫我 | call me | 称呼偏好 |
| 喜欢 | like/love | 喜欢什么 |
| 讨厌 | hate/dislike | 讨厌什么 |
| 希望 | hope/want | 希望怎样 |
| 想要 | want | 想要什么 |
| 不要 | don't | 不要什么 |
| 偏好 | prefer | 偏好什么 |

### 识别正则模式

```python
# 称呼偏好
r'(?:叫我|称呼我)\s*["\']?([^\s"\'\n]+)["\']?'

# 喜欢/讨厌
r'(?:喜欢|love)\s+([^\s"\'\n]+)'
r'(?:讨厌|hate)\s+([^\s"\'\n]+)'
```

### 示例对话

| 用户输入 | 提取结果 |
|----------|----------|
| "叫我小明吧" | `{"nickname": "小明"}` |
| "我喜欢聊科技话题" | `{"likes": "科技话题"}` |
| "讨厌被叫全名" | `{"dislikes": "被叫全名"}` |
| "希望对话轻松一些" | `{"preference": "轻松的对话"}` |

## 3. 约定规则 (Agreements)

### 识别关键词
| 中文 | English | 说明 |
|------|---------|------|
| 说好了 | agreed | 已达成约定 |
| 记住 | remember | 需要记住 |
| 答应 | promised | 承诺 |
| 以后 | from now on | 未来约定 |
| 下次 | next time | 未来约定 |
| 禁止 | forbidden | 禁止事项 |
| 不要 | don't | 禁止事项 |

### 识别正则模式

```python
# 约定模式
r'(?:说好了|约定|答应)\s*[:：]?\s*["\']?([^"\'\n]+)["\']?'
r'(?:以后|下次|从现在起)\s*["\']?([^"\'\n]+)["\']?'
r'(?:不要|禁止|别)\s*["\']?([^"\'\n]+)["\']?'
```

### 示例对话

| 用户输入 | 提取结果 |
|----------|----------|
| "说好了，下次见面要打招呼" | `"下次见面要打招呼"` |
| "记住，以后叫我Nova" | `"叫我Nova"` |
| "不要叫我的全名" | `"不叫全名"` |

## 4. 重要事实 (Facts)

### 识别关键词
| 中文 | English | 说明 |
|------|---------|------|
| 生日 | birthday | 生日 |
| 日期 | date | 日期 |
| 生日是 | born | 出生日期 |
| 在...工作 | work at | 工作地点 |
| 学习 | study | 学习 |
| 住在 | live in | 居住地 |

### 识别正则模式

```python
# 日期模式
r'((?:19|20)\d{2}[年\-/]\d{1,2}[月\-/]\d{1,2})'
r'(?:生日|出生于)\s*([^\s"\'\n]+)'

# 地点模式
r'住在\s*([^\s"\'\n]+)'
r'工作(?:在|于)\s*([^\s"\'\n]+)'
```

## 5. 更新检测

### 检测原则

1. **同键更新**: 如果新消息包含已存在的键，视为更新
2. **否定更新**: "不叫..." 视为对 "叫..." 的更新
3. **时间戳**: 每次更新记录时间和状态为 `updated`

### 更新示例

| 旧记录 | 新消息 | 新记录 |
|--------|--------|--------|
| `name: 小明` | "我叫小明了" | `name: 小明` (不变) |
| `nickname: 小明` | "以后叫我Nova" | `nickname: Nova` (updated) |
| `avatar: 月光男孩` | "头像换成星空魔法师" | `avatar: 星空魔法师` (updated) |
