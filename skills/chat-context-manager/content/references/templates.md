# 记忆存储模板

本目录包含聊天上下文管理器使用的分类记忆模板。

## 文件结构

```
/workspace/chat-memory/
├── user_identity.md       # 用户身份信息
├── user_preferences.md    # 用户偏好设置
├── agreements.md          # 约定与规则
├── facts.md              # 重要事实记录
└── conversation_summary.md # 对话摘要
```

## 使用说明

1. **自动生成**: 这些文件由 `memory_manager.py` 脚本自动创建
2. **手动编辑**: 可以手动编辑，但建议保持格式一致
3. **状态标记**:
   - `active`: 当前有效
   - `updated`: 已更新过
   - `archived`: 已归档/不再使用

## 格式化规则

- 使用 Markdown 格式
- 每条记录包含: key、value、创建时间、更新时间、状态
- 记录之间用 `---` 分隔
- 支持中文和英文键名
