# 聊天上下文管理器

## 核心职责

自动管理聊天上下文，记录关键信息，过滤无效对话，延长聊天周期寿命。

## 工作流程

### 1. 信息识别与提取

**触发时机**：每次用户消息中可能包含关键信息时

**识别类型**：
- **身份信息**：名字、头像、外貌描述、性别、年龄
- **偏好设置**：语言偏好、主题偏好、交流风格
- **约定事项**：双方达成的协议、规则、计划
- **事实记录**：重要的事实、日期、事件
- **系统设置**：用户对AI的设置、称呼方式

### 2. 分类存储

在 `/workspace/chat-memory/` 目录下维护分类文件：

```
/workspace/chat-memory/
├── user_identity.md      # 用户身份信息
├── user_preferences.md   # 用户偏好设置
├── agreements.md         # 约定与规则
├── facts.md             # 重要事实记录
└── conversation_summary.md  # 对话摘要
```

### 3. 信息更新

**更新规则**：
- 新信息 → 追加到对应文件
- 已有信息更改 → 定位并更新该条目
- 冲突信息 → 保留最新，更新时间戳

### 4. 信息检索

**触发时机**：
- 开始新对话时
- 用户询问"你还记得..."
- 上下文不足时

**操作**：读取相关分类文件，还原记忆到当前上下文

## 文件格式规范

```markdown
# [分类标题]

## [信息类型]

- **项**: 描述
  - 创建时间: YYYY-MM-DD HH:MM
  - 更新状态: active/updated/archived

---
```

## 关键识别模式

### 身份信息关键词
- "我叫"、"名字是"、"叫我"
- "头像"、"形象"、"样子"
- "我是一个"、"我的性格"

### 偏好设置关键词
- "我喜欢"、"偏好"、"讨厌"
- "希望"、"想要"、"不要"
- "叫我...就好"（称呼偏好）

### 约定关键词
- "说好了"、"约定"、"答应"
- "下次"、"以后"、"记住"

## 自动执行时机

1. **消息后检查**：每次用户消息后检查是否包含关键信息
2. **定期摘要**：长对话（>20轮）后生成摘要
3. **新对话开始**：读取相关记忆文件
4. **信息冲突时**：自动更新最新信息

## 过滤原则

**保留**：
- 任何关于身份的描述
- 偏好和设定的表达
- 约定和规则
- 重要的事实数据
- 情感/关系相关的表达

**过滤**：
- 日常寒暄
- 重复确认
- 临时性问题
- 无意义对话

## 使用示例

**场景1：用户首次介绍自己**
```
用户: "我叫小明，你可以叫我明哥，头像是月光下的男孩"
→ 提取: 名字="小明", 昵称="明哥", 头像描述
→ 存储到: user_identity.md
```

**场景2：用户更改设置**
```
用户: "以后叫我Nova吧，头像换成星空下的魔法师"
→ 定位已有记录
→ 更新: user_identity.md
```

**场景3：新对话开始**
```
→ 读取 /workspace/chat-memory/user_identity.md
→ 读取 /workspace/chat-memory/user_preferences.md
→ 加载到上下文
→ 问候并确认身份
```

## 错误处理

- 文件不存在 → 自动创建
- 写入失败 → 记录错误，提示用户
- 格式错误 → 尝试修复，必要时重建

## 与其他技能的协作

此技能为基础服务，可被其他技能调用以获取上下文信息。
