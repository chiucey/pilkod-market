# A股历史数据获取 Skill

## 功能
获取A股股票的历史K线数据，计算指定时间段的涨跌幅。

## 使用方式

### 调用命令
当需要获取股票历史涨跌幅时，运行：

```bash
python3 /workspace/skills/stock_history_data/get_stock_history.py --codes "代码1,代码2,代码3" --days N
```

### 参数说明
- `--codes`: 股票代码，用逗号分隔
- `--days`: 获取天数，默认30天

### 示例
```bash
# 获取单只股票30日涨幅
python3 /workspace/skills/stock_history_data/get_stock_history.py --codes "300757" --days 30

# 获取多只股票30日涨幅
python3 /workspace/skills/stock_history_data/get_stock_history.py --codes "300757,300394,300308,002028,601899" --days 30

# 获取5日涨幅
python3 /workspace/skills/stock_history_data/get_stock_history.py --codes "300757,300394" --days 5
```

## 输出
- 当前价格
- N日前价格
- 涨跌幅
- 自动按涨跌幅排序

## 数据来源
新浪财经 API
