# ip-coach

> 一个让 Claude Code 变成你"个人 IP 起号教练"的 skill。

装上它，对你的 agent 说一句 **"我想起号"**，它会用 7 个阶段几十个追问陪你把定位问清楚，生成一份《起号档案》，然后把你的第一个里程碑交给 `/goal` skill 排进每日计划——从此你的 agent 知道你是谁、要服务谁、下一步做什么。

---

## 为什么需要它

很多人读完"怎么起号"的文章会点头，但合上之后还是不知道从哪开始。

**缺的不是方法论，是一个"逼你把方法论套到自己身上的环境"**。

ip-coach 就是那个环境。它不会告诉你"你应该这样做"——它会**一次问一个问题**，追问到你自己说出"只有我能写"那一句话为止。

---

## 背后的方法论（先看这个再决定要不要装）

这个 skill 提炼自 01fish 公众号 84 天从 0 到 1.5w 粉的实战复盘。如果你只想拿走一件事，那就是下面这张"脑子里走的那条线"：

> **敢干 → 定位 → 系统 → 感受迭代**

- **敢干**：一件事认为需要做，立刻开始。无头苍蝇乱飞没问题，第一步必须很烂——如果你第一步就做得很好，那叫"从 100 到 1"，不叫"从 0 到 1"。
- **定位**：先想明白**"为什么你是独特且稀缺的"**——这一个问题你回答不上来，别的事都免谈。这一步优先级最高。
- **系统**：定位之后立刻构建一套可持续迭代、可自动化的方法论。**系统永远大于散兵作战**（天才除外）。
- **感受迭代**：系统搭起来后，感受语感、文风、热点，找到"网感"的感觉，然后继续和系统一起调。

做一个内容系统，靠的其实是三件事叠在一起：

| 角色 | 是什么 |
|------|------|
| **地基** | 定位清晰 |
| **承重墙** | 系统完善 |
| **水泥** | 持续迭代 |

**一步到位不可能。任何 skill 都无法让你"啥也不干就做到"**——ip-coach 也不能。它能做的是把"定位"这一步从"想不清楚"逼到"被你自己说清楚"。剩下的系统和迭代，还是你自己往里注入时间。

---

## 7 个阶段

| # | 阶段 | 目的 |
|---|------|------|
| 1 | 现状盘点 | 挖出你手里已有的所有素材 |
| 2 | **生态位定位（最关键）** | 让你自己说出那句"只有我能写"的定位 |
| 3 | 平台规则解码 | 搞清楚你选的平台奖励什么 |
| 4 | 抄作业对象选定 | 找 3 个可"借壳换料"的参考账号 |
| 5 | 人脉地图 | 盘点你现在就能 DM 的 5 个人 |
| 6 | 第一个里程碑 | 定义一个具体、可庆祝的完成点 |
| 7 | 承诺机制 → 交棒 /goal | 锚定真实的人和时间，自动拆成日常计划 |

访谈约 30-60 分钟。可以中途说"暂停"，下次说"继续起号"从断点继续。

## 安装

```bash
cd ~/.claude/skills
git clone https://github.com/OrangeViolin/ip-coach
```

依赖 [Claude Code](https://claude.com/claude-code)。`/goal` skill 可选——没有也能跑，只是少了最后一步的自动计划交棒。

---

## 使用

在 Claude Code 里说一句：

```
> 我想起号
```

或 `/起号`。然后跟着对话走。

**产出**：

- 📄 《起号档案.md》——结构化的自我定位文档，保存到你指定位置
- 🔁 自动计划系统（经由 /goal 注册的定时任务）
- 🧠 注入 agent 记忆——未来所有涉及内容 / IP / 品牌的对话都会先读这份档案

---

## 这个 skill 的铁律

1. 一次只问一个问题
2. 追问到具体为止
3. 不替你做决定
4. 不美化——发现你在自我欺骗会直接指出
5. 不为进度放过模糊的答案
