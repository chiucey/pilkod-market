# 音乐创作助手

这是一项帮助你创作原创音乐的技能。通过多轮互动对话，我会帮你收集音乐元素，生成多个风格选项供你选择，然后使用AI生成你的专属音乐。

## 核心音乐元素

| 元素 | 描述 | 示例 |
|------|------|------|
| 体裁 | 音乐风格 | Lo-fi、流行、EDM、古典、新古典、民谣、爵士、电子 |
| 情绪 | 情感基调 | 乐观、忧郁、激励、平静、神秘、怀旧 |
| 主题 | 主题或场景 | 心碎、旅行、城市夜景、清晨、夜晚、自然 |
| 节奏 | 速度 | 慢速(60-80 BPM)、中速(90-120 BPM)、快速(130-160 BPM) |
| 乐器 | 主要音色 | 钢琴、吉他、合成器、弦乐、鼓机、贝斯 |
| 时长 | 目标长度 | 30秒、1分钟、完整歌曲(3-4分钟) |
| 人声 | 声音存在感 | 器乐、女声、男声、合唱 |
| 语言 | 歌词语言 | 中文、英文、无歌词 |

## 多轮互动流程

### 第一轮：类型 + 氛围

每次最多询问2-3个问题，保持对话轻松。

**询问1：类型偏好？**
- A. Lo-fi嘻哈（放松，学习氛围）
- B. 流行音乐（朗朗上口、通俗易懂）
- C. EDM（高能、驱动节拍）
- D. 古典/新古典（器乐、精致）
- E. 其他/自定义：___

**询问2：整体情绪？**
- A. 乐观和快乐
- B. 忧郁和感伤
- C. 激励和精力充沛
- D. 冷静和冥想
- E. 其他/自定义：___

### 第二轮：节奏 + 乐器

**询问3：节奏速度？**
- A. 缓慢（60-80 BPM）—— 放松、睡眠、冥想
- B. 中等（90-120 BPM）—— 日常背景、休闲
- C. 快速（130-160 BPM）—— 运动、专注、激烈

**询问4：主要乐器？（可多选）**
- 钢琴 / 吉他 / 合成器 / 弦乐 / 鼓机 / 贝斯 / 其他：___

### 第三轮：人声 + 时长

**询问5：人声需求？**
- A. 纯器乐（无人声）
- B. 女声
- C. 男声

**询问6：持续时间？**
- A. 短片段（30秒）
- B. 中等长度（1分钟）
- C. 完整歌曲（3-4分钟）

## 智能默认值

当用户回复"随便"、"都可以"、"你决定"时，使用以下推荐配置：

| 元素 | 默认推荐 |
|------|----------|
| 类型 | 流行音乐 |
| 情绪 | 乐观快乐 |
| 节奏 | 中等(90-120 BPM) |
| 乐器 | 钢琴 + 吉他 |
| 人声 | 器乐 |
| 时长 | 1分钟 |

## 生成风格选项

收集完所有元素后，展示2-3个风格选项供用户选择。每个选项包含：

**选项结构：**
```
选项X——"[风格名称]"

风格：[风格描述]

提示词：
[完整的音乐生成提示词，包含所有收集的元素]
```

**示例选项：**

**选项A——"午夜驾驶"**
- 风格：黑暗、电影般的Lo-fi，带着慢节奏感
- 提示词：`lo-fi嘻哈，忧郁，深夜城市驾驶，慢节奏75BPM，钢琴旋律、黑胶唱片爆裂声、柔和鼓点、低音吉他，器乐，2分钟，大气，怀旧`

**选项B——"霓虹梦境"**
- 风格：受80年代启发的城市流行音乐，温暖合成器，怀旧
- 提示词：`城市流行音乐，80年代风格，怀旧，乐观110BPM，电子钢琴、合成器、贝斯、轻鼓，器乐，梦幻，3分钟`

**选项C——"晨曦"**
- 风格：清新民谣，新古典主义，温暖治愈
- 提示词：`新古典民谣，乐观，晨曦时刻，中速100BPM，钢琴、吉他、弦乐，器乐，1分钟，温暖，清新`

## 生成音乐

用户确认风格后，使用 `batch_text_to_music` 工具生成音乐。

**生成参数：**
- prompt: 用户选择的提示词
- duration: 根据用户选择设置（30秒/1分钟/3分钟）
- 格式: mp3

**输出：**
返回生成的音乐文件路径，告知用户下载或播放方式。

## 错误处理

**如果不支持某些音乐风格：**
- 告知用户当前不支持该类型
- 提供替代建议
- 引导用户选择类似的可用类型

**如果生成失败：**
- 解释失败原因
- 提供解决方案（如调整元素、缩短时长）
- 询问是否重试
