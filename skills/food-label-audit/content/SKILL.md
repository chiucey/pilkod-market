# 食品标签审核技能

## 技能概述

本技能用于审核预包装食品标签的合规性，基于以下国家标准：
- **GB 7718**：预包装食品标签通则（强制标示内容、基本要求、日期标示等）
- **GB 28050**：预包装食品营养标签通则（营养成分表格式、强制标示营养素等）

## 审核范围

### 1. GB 7718 强制标示内容检查

**必须标示的项目：**
- 食品名称：应在醒目位置，清晰反映食品真实属性
- 配料表：标示所有配料，按用量降序排列
- 净含量和规格：与食品名称在同一展示版面
- 生产者、经销者信息：名称、地址、联系方式
- 生产日期和保质期：清晰标示，不得补印或篡改
- 贮存条件：标明适宜的贮存环境
- 食品生产许可证编号（SC/QS编号）
- 产品标准代号
- 产地：按行政区划标注到地市级

**其他需要标示的内容：**
- 辐照食品应标注辐照标识
- 转基因食品应标注转基因标识
- 营养标签（按GB 28050执行）
- 质量等级（如适用）
- 致敏物质（推荐标示）

### 2. GB 28050 营养标签检查

**强制标示内容（1+6模式）：**
- 能量
- 蛋白质
- 脂肪
- 饱和脂肪（或饱和脂肪酸）
- 碳水化合物
- 糖
- 钠

**营养成分表格式要求：**
- 以"方框表"形式表示
- 表头为"营养成分表"
- 必须标示含量值及占NRV百分比
- 能量单位：千焦（kJ）
- 蛋白质、脂肪、碳水化合物单位：克（g）
- 钠单位：毫克（mg）

**豁免强制标示的产品：**
- 生鲜食品（包装的生肉、生鱼、生蔬菜等）
- 乙醇含量≥0.5%的饮料酒类
- 包装总表面积≤100cm²或最大表面面积≤20cm²的食品
- 现制现售食品
- 包装饮用水
- 每日食用量≤10g或10mL的预包装食品

## 审核流程

### 第一步：接收标签信息

用户提供以下信息之一：
- 食品标签图片（上传图片供AI分析）
- 标签文字内容（手动输入或粘贴）
- 完整配料表和营养成分表数据

### 第二步：识别标签类型

判断食品类别：
- 普通预包装食品
- 特殊膳食用食品（参照GB 13432）
- 进口食品（需加贴中文标签）
- 豁免产品（确认是否需要标示）

### 第三步：逐项审核

按以下清单逐项检查：

**GB 7718检查清单：**
1. 食品名称是否真实反映产品属性
2. 配料表是否完整、排序是否正确
3. 净含量标示是否规范（计量单位正确）
4. 生产日期和保质期是否清晰、格式是否正确
5. 生产者/经销商信息是否完整
6. 贮存条件是否标注
7. SC许可证编号是否正确格式
8. 产品标准代号是否正确
9. 产地是否标注到地市级
10. 是否含有致敏物质但未标注

**GB 28050检查清单：**
1. 营养成分表格式是否规范
2. 是否包含强制标示的1+6营养素
3. 含量值和NRV%是否完整
4. 单位是否正确
5. "0"界限值处理是否正确
6. 文字格式是否适用于小包装食品

## 常见问题识别

### GB 7718 常见错误

1. **食品名称不规范**
   - 使用"新创名称"未标注真实属性
   - 名称与配料不符（如"草莓味饮料"实为调味糖水）

2. **配料表问题**
   - 未按用量降序排列
   - 复合配料未展开原始配料
   - 食品添加剂未使用通用名称

3. **日期标示问题**
   - 保质期格式不统一
   - 生产日期被遮挡或模糊
   - 额外加贴生产日期

4. **信息不完整**
   - 缺少联系方式
   - 地址不具体（未到门牌号）
   - 缺少贮存条件

### GB 28050 常见错误

1. **营养成分表格式错误**
   - 未使用方框表格式
   - 表头名称错误（非"营养成分表"）

2. **数值标示问题**
   - 使用范围值（如"≤20g"）
   - 修约间隔不符合规定

3. **NRV%计算错误**
   - 计算公式错误
   - 修约不正确

4. **声称不合规**
   - 进行营养声称但未满足含量要求
   - 功能声称用语不规范

## 适用场景

- 食品生产企业：产品标签设计审核
- 进口商：进口食品中文标签审核
- 经销商：产品合规性检查
- 监管机构：市场监督抽检
- 消费者：购买前标签识别

## 注意事项

1. 本技能基于GB 7718-2011和GB 28050-2011版本
2. 2025年新版GB 7718和GB 28050将于2027年实施，当前审核以2011版为准
3. 特殊食品类别（婴幼儿配方食品、特殊膳食用食品等）需参照其他标准
4. 本审核为辅助性质，正式合规性认定需咨询专业机构或监管部门
