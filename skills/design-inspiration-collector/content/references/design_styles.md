# 设计风格分类参考

## UI设计风格

### 1. 极简主义 (Minimalism)
- 大量留白
- 有限色彩
- 清晰层次
- 核心功能突出

### 2. 扁平化 (Flat Design)
- 无阴影、渐变
- 几何形状
- 鲜明色彩
- 简洁图标

### 3. 拟物化 (Skeuomorphism)
- 模拟真实材质
- 光影效果
- 纹理细节
- 触感反馈

### 4. 玻璃拟态 (Glassmorphism)
- 半透明背景
- 背景模糊
- 微妙边框
- 渐变叠加

### 5. 孟菲斯设计 (Memphis Design)
- 几何图案
- 鲜艳撞色
- 不对称布局
- 波点/锯齿元素

### 6. 新拟态 (Neumorphism)
- 柔和阴影
- 凸起/凹陷效果
- 低对比度
- 单色调为主

### 7. 瑞士国际风格 (Swiss/International)
- 网格系统
- 无衬线字体
- 功能主义
- 清晰排版

### 8. 赛博朋克 (Cyberpunk)
- 霓虹色彩
- 暗色背景
- 故障艺术
- 科技元素

## 行业分类标签

| 行业 | 特征标签 |
|------|----------|
| 电商 | 促销、红蓝配色、商品展示、卡片布局 |
| 金融 | 安全、专业、深蓝/绿、表格密集 |
| 社交 | 年轻、彩色、头像突出、动态元素 |
| 教育 | 友好、插图、清晰导航、进度展示 |
| 医疗 | 信任、清爽、绿/蓝、图标直观 |
| 旅行 | 沉浸、图片优先、卡片流、探索感 |
| 美食 | 暖色、高清美食图、食欲色、评价体系 |
| 娱乐 | 暗黑、渐变、动态、推荐算法 |

## 布局类型

- **卡片式**：模块化信息组织
- **列表式**：高效信息浏览
- **瀑布流**：图片主导、无限滚动
- **杂志风**：大图+文字混合
- **仪表盘**：数据可视化主导
- **全屏沉浸**：单一内容聚焦

## 元素特征

- **插画风**：手绘/矢量插画为主
- **摄影风**：真实照片为主
- **3D风**：C4D/3D渲染元素
- **动态风**：微交互/动画丰富
- **图标风**：图标系统主导
