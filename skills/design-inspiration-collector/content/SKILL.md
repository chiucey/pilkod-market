# 设计灵感收集器

专业的设计案例收集与分析工具，帮助设计师高效收集、分类、整理和导出设计灵感。

## 核心功能

### 1. 主流设计平台专项抓取

支持以下专业设计平台的案例抓取：

- **Dribbble**：全球设计师作品展示平台，涵盖 UI、插画、动效等各类设计
- **Behance**：Adobe旗下创意作品展示平台，包含品牌、UI、插画等高质量案例
- **Pinterest**：灵感图钉平台，适合收集情绪板和风格参考
- **花瓣网**：国内领先的设计灵感社区
- **站酷**：国内知名设计师互动平台
- **优设**：国内专业设计资讯平台
- **普通网页**：任何公开的网页设计案例
- **微信文章**：微信公众号文章中的设计案例

### 2. 无URL/关键词时的热门案例推荐

当用户未提供具体URL或关键词时，提供以下解决方案：

- **热门案例推荐**：基于当前设计趋势，主动推荐该领域的热门/高评分案例
- **Trending案例**：展示当前最受欢迎的设计趋势案例
- **编辑精选**：提供各平台编辑推荐的优质案例
- **相似案例扩展**：根据用户已有案例，推荐风格相似的其他案例

### 3. 网页/微信文章设计案例捕获

- 输入目标网页URL，自动提取页面内容
- 支持微信公众号文章链接
- 识别并保存关键设计元素截图
- 提取文章排版、插图、设计风格
- 记录来源URL、标题、发布时间

### 4. 智能标签分类与多维度筛选

自动为每个案例添加多维度标签：

- **设计风格**：极简、扁平化、拟物、玻璃拟态、孟菲斯、赛博朋克、国潮等
- **行业类型**：电商、金融、教育、医疗、社交、出行、旅游、美食等
- **色彩倾向**：单色、双色撞色、彩虹色、莫兰迪、莫兰迪色、马卡龙等
- **布局类型**：卡片式、列表式、瀑布流、杂志风、全屏式、栅格系统等
- **元素特征**：插画、摄影、3D、动态、AR/VR等
- **版式风格**：黄金比例构图、对称构图、三分法、留白设计、密恐填充等

**多维度筛选与排序功能**：

- 支持标签组合筛选（如"电商+极简风格"）
- 支持时间范围筛选（最近一周/一月/一年/自定义）
- 支持行业+风格组合筛选
- 支持颜色数量筛选（单色/双色/多色）
- 支持评分/热度排序
- 支持时间排序（最新/最旧）
- 支持来源平台筛选
- 支持自定义标签筛选

### 5. 配色方案提取

自动分析并提取：

- 主色调、副色调、强调色
- 配色比例（60-30-10法则）
- 渐变色板
- 文本可访问性对比度检查
- 导出格式：HEX、RGB、HSL、CMYK、CSS变量

### 6. 设计元素分析

- 字体组合分析（字体家族、大小层级、字重运用）
- 图标风格归纳（线性、面性、填充、手绘等）
- 间距系统识别（优先参考黄金比例构图，要求视觉平衡）
- 圆角/阴影/边框风格
- 动效节奏分析

### 7. 项目整理归档

按项目或主题创建收藏夹：

- 项目文件夹命名与层级管理
- 案例关联标注与备注
- 优先级标记（参考级/学习级/归档级）
- 案例来源追溯
- 支持批量移动/复制案例

### 8. 导出报告

支持多种导出格式：

- **设计灵感报告**：Markdown格式，包含截图+分析
- **配色色板**：PNG图片，可直接用于设计软件
- **元素清单**：JSON格式，便于程序化使用
- **Moodboard拼贴**：可视化灵感板图片
- **标签清单**：CSV格式，便于数据分析

## 工作流程

```
用户输入URL/关键词/无输入时推荐
        ↓
    内容抓取或热门推荐
        ↓
    设计分析 ← → 配色提取
        ↓
    智能打标（多维度标签）
        ↓
    项目归档或筛选排序
        ↓
    导出交付
```

## 使用示例

### 示例1：收集电商网站设计（基于平台搜索）

```
用户：帮我收集10个优秀的电商App首页设计案例
助手：
1. 搜索"Dribbble ecommerce app design"
2. 搜索"Behance ecommerce UI design"
3. 搜索"优秀电商App UI设计案例"
4. 对每个案例执行：
   - 截图保存
   - 提取配色
   - 分析布局特点
   - 自动打标签（电商+极简/卡片式等）
5. 整理成报告输出
```

### 示例2：无URL时的热门案例推荐

```
用户：我想看看最近流行的App设计风格
助手：
1. 推荐Dribbble/Behance的Trending案例
2. 提供编辑精选的App设计案例
3. 根据当前设计趋势推荐相似案例
4. 用户确认感兴趣的方向后深入收集
```

### 示例3：多维度筛选案例

```
用户：帮我筛选出电商行业的极简风格案例，按热度排序
助手：
1. 应用筛选条件：行业=电商，风格=极简
2. 按热度/评分排序
3. 展示筛选结果
4. 用户可进一步细化筛选条件
```

### 示例4：提取配色方案

```
用户：这个网站 https://example.com 的配色方案是什么？
助手：
1. 抓取页面内容
2. 提取主色、辅色、强调色
3. 计算配色比例
4. 输出可复用的色值（HEX/RGB/CSS）
5. 生成配色预览图
```

### 示例5：项目调研归档

```
用户：我正在做一个健身App，需要收集运动主题的设计
助手：
1. 搜索健身/运动App设计（Dribbble、Behance等）
2. 收集5-10个案例
3. 按界面类型分类（首页、详情页、成就页等）
4. 提取共性设计元素
5. 归档到"健身App调研"文件夹
6. 标注优先级（参考级/学习级）
```

## 输出结构

收集完成后，输出包含：

```
📁 项目名称/
├── 📄 design_report.md          # 设计分析报告
├── 🖼️ screenshots/              # 截图收藏
├── 🎨 color_palettes/           # 配色方案
├── 🏷️ tags.json                 # 标签元数据（多维度标签）
├── 🔍 filter_config.json        # 筛选配置
└── 📊 export_summary.json        # 导出摘要
```

## 设计原则

1. **真实性**：保留原始设计意图，不过度解读
2. **可追溯**：每个案例附带来源链接
3. **可复用**：输出格式支持设计工具直接使用

### 案例收集版权边界

本工具在收集和整理设计案例时，严格遵守以下版权规范：

- **仅收集公开可见的设计作品**：不收集付费墙、VIP专享等非公开内容
- **保留原始来源标注**：所有收集的案例必须保留原始来源链接
- **支持原创者权益**：收集前确认案例不侵犯第三方版权
- **用户自行判断**：用户应对所收集案例的版权合规性自行判断，本工具仅提供收集和整理功能

### 用户可设置的版权免责说明

用户可自定义以下设置：

- **使用场景声明**：个人学习/商业项目/教学演示等
- **是否公开分享**：设置案例库的可见范围

- **授权要求提醒**：商业使用前的授权确认提示

## 隐私保护机制

### 数据抓取隐私保护

在抓取网页内容时，自动执行以下隐私保护措施：

- **个人信息过滤**：自动识别并过滤网页中的个人信息，包括但不限于：
  - 姓名、电话、邮箱、地址等联系方式
  - 身份证号、护照号等证件信息
  - 社交媒体账号、私人聊天记录
  - 银行卡号、支付信息
- **敏感数据脱敏**：对无法完全过滤的敏感信息进行脱敏处理
- **隐私数据不存储**：明确排除个人隐私数据进入案例库

### 案例存储隐私

- **本地优先存储**：案例数据优先存储在本地环境
- **可选择性云同步**：用户可选择是否启用云端同步
- **数据可完全删除**：支持一键清空所有收集的案例数据
- **导出数据不含敏感信息**：导出的报告中自动过滤个人信息
- **会话数据保护**：工具使用过程中的临时数据在会话结束后自动清除

### 用户控制权

- **完全控制权**：用户对收集的案例拥有完全控制权
- **随时删除权**：用户可随时删除任意案例
- **批量管理**：支持批量选择、批量删除、批量导出
- **数据可携带**：支持将收集的案例完整导出
