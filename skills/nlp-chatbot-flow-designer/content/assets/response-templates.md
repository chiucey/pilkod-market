# 响应模板库

## 一、通用响应模板

### 1.1 问候类

```
标准问候:
您好！我是智能客服机器人，很高兴为您服务。请问有什么可以帮助您的？

VIP用户问候:
尊敬的用户您好！感谢您的信任，我是您的专属智能客服，我将竭诚为您服务。

首次访问问候:
欢迎您！我是智能客服，为您提供7×24小时在线服务。您可以随时向我咨询问题。
```

### 1.2 确认类

```
信息确认:
好的，请您确认以下信息：
• [信息项1]: [内容]
• [信息项2]: [内容]
确认无误请回复"是"，如有修改请告知。

操作确认:
即将为您执行以下操作：[操作描述]。确认继续吗？

时间确认:
请问您希望安排在什么时间？[时间选项]
```

### 1.3 澄清类

```
意图不明:
抱歉，我不太理解您的问题。您可以：
1. 换个说法描述
2. 从以下选项中选择：
[选项列表]

多意图澄清:
您的问题涉及多个方面：
1. [方面1]
2. [方面2]
请问您想先解决哪个问题？

信息不足:
为了更好地帮助您，请提供以下信息：[所需信息]
```

### 1.4 结束类

```
标准结束:
感谢您的咨询，祝您生活愉快！如还有其他问题，随时联系我。

问题解决结束:
很高兴帮您解决了问题！还有其他需要帮助的吗？

等待反馈结束:
请查看处理结果，如有任何疑问或需要进一步帮助，请随时联系我。
```

```
提供方案:

```

## 五、异常处理模板

### 5.1 系统异常

```
通用错误:
抱歉，系统现在繁忙，请稍后再试。您也可以拨打客服电话[号码]人工咨询。

API超时:
抱歉，您的请求处理超时。请您重试，或选择其他方式获取帮助。

服务不可用:
非常抱歉，当前服务暂时不可用。我们正在紧急处理中，请您稍后再试。
```

### 5.2 输入异常

```
空输入:
您好，请输入您想咨询的问题，我会尽力为您解答。

格式错误:
您输入的[字段]格式有误，请按以下格式重新输入：
[正确格式示例]

无法识别:
抱歉，我无法理解您输入的内容。请尝试使用简单的语言描述您的问题。
```

### 5.3 敏感内容

```
敏感词提示:
⚠️ 为保障您的账户安全，请勿在对话中透露密码、验证码等敏感信息。

隐私保护提示:
您好，我们会保护您的隐私安全。如果您的问题涉及个人隐私信息，建议您通过私密渠道反馈。

合规提示:
⚠️ 温馨提示：本回答仅供参考，不能替代专业意见。如有需要，请咨询专业人士。
```
