# 企业战略洞察分析

## 核心能力矩阵

本技能提供以下分析维度的综合战略洞察服务：

### 1. 市场与行业分析
- 行业趋势识别与预测（宏观政策、技术演进、消费变化）
- 市场规模估算与增长驱动因素分析
- 行业生命周期阶段判断
- 竞争格局与市场结构研判
- 产业链价值分布分析

### 2. 竞争对手洞察
- 竞企战略定位与商业模式解构
- 产品/服务组合与差异化分析
- 财务健康度与投资布局评估
- 组织能力与核心优势识别
- 竞争动作预测与威胁评估

### 3. 客户洞察
- 客户需求层次挖掘（功能/情感/社会价值）
- 客户旅程与触点分析
- 客户分层与画像构建
- 决策链条与关键影响因素
- 客户满意度与忠诚度驱动因素

### 4. 战略机会识别
- 市场空白点与蓝海机会
- 技术突破带来的颠覆性机会
- 跨界融合与生态协同机会
- 并购整合与资源互补机会
- 海外市场拓展机会

### 5. 商业模式分析
- 商业模式画布解构
- 价值主张与价值创造逻辑
- 收入模型与盈利性评估
- 成本结构与规模经济分析
- 商业模式创新路径

### 6. 投资并购战略
- 标的筛选与评估框架
- 协同效应与整合风险分析
- 估值方法与定价策略
- 交易结构设计建议
- 投后管理与价值提升

## 输入处理规范

### 支持的输入格式

| 类型 | 格式 | 处理方式 |
|------|------|----------|
| 文档 | PDF, Word, Markdown, TXT | 全文解析与关键信息提取 |
| 数据 | Excel, CSV, JSON | 结构化数据提取与分析 |
| 网页 | URL | 内容抓取与结构化 |
| 图片 | PNG, JPG | 图表OCR与视觉分析 |
| 文本 | 直接输入 | 语义理解与实体识别 |

### 输入预处理流程

1. **信息抽取**：从各类输入中提取关键实体、关系、数据
2. **结构化**：统一格式，构建分析数据湖
3. **交叉验证**：多源信息相互印证，识别一致性与矛盾点
4. **知识图谱**：构建企业-行业-竞品-市场关系图谱

## 分析方法论

### 宏观层面（行业趋势）

```
经典框架：
├── PESTEL 分析（政治/经济/社会/技术/环境/法律）
├── 行业生命周期理论
├── 技术成熟度曲线（Gartner Hype Cycle）
├── 宏观趋势驱动因素分解
└── 情景规划（Scenario Planning）

AI增强能力：
├── 实时新闻与政策情报聚合
├── 社交媒体舆情与情绪分析
├── 监管动向与合规风险预警
└── 跨行业对标与趋势外推
```

### 中观层面（竞争态势）

```
经典框架：
├── 五力模型（Porter's Five Forces）
├── 竞争格局地图（Competitive Positioning Map）
├── 战略群体图（Strategic Group Map）
├── 价值链分析（Value Chain Analysis）
└── 竞争对手画像（Competitive Profile Matrix）

AI增强能力：
├── 竞品动态实时监控
├── 专利与技术布局分析
├── 高管言论与战略信号提取
└── 市场份额实时估算
```

### 微观层面（战略决策）

```
经典框架：
├── 商业画布（Business Model Canvas）
├── SWOT/TOWS 分析
├── 战略时钟（Strategic Clock）
├── 波特竞争战略
├── 安索夫矩阵（Ansoff Matrix）
└── 价值主张画布（Value Proposition Canvas）

AI增强能力：
├── 财务预测与敏感性分析
├── 蒙特卡洛模拟（风险评估）
├── 博弈论策略分析
└── 决策树与情景推演
```

## 输出规范

### 输出格式选项

1. **结构化分析报告**
   - 执行摘要（1页）
   - 核心发现（3-5个关键洞察）
   - 详细分析（框架应用与论证）
   - 战略建议（优先级排序）
   - 风险提示与应对方案

2. **可视化图表**
   - 竞争格局图
   - 市场趋势图
   - 价值链映射图
   - 战略矩阵（SWOT、BCG等）
   - 客户画像雷达图

3. **战略建议清单**
   - 优先级矩阵
   - 行动项分解
   - 资源需求评估
   - 时间线规划
   - KPI设定建议

4. **PPT演示版**
   - 结论页优先（金字塔结构）
   - 数据驱动论证
   - 行动导向建议

## 执行流程

### 阶段1：需求解析（5分钟内）

```
输入 → 意图识别 → 范围确认 → 分析计划
```

- 识别用户核心问题与决策需求
- 确定分析深度与边界
- 选择适配的分析框架组合
- 明确输出形式偏好

### 阶段2：信息采集（10-30分钟）

```
内部数据 + 外部情报 + 实时网络 + 历史知识库
```

- 处理用户提供的数据/文档
- 补充公开信息（新闻、研报、专利等）
- 调用网络搜索获取最新情报
- 整合领域知识库

### 阶段3：深度分析（15-45分钟）

```
框架应用 → 模式识别 → 洞察提炼 → 建议生成
```

- 多框架交叉验证
- 识别关键驱动因素
- 提炼战略洞察
- 生成可执行建议

### 阶段4：输出交付（5-10分钟）

```
结构化报告 → 可视化图表 → 建议清单 → Q&A支持
```

- 根据偏好组装输出
- 提供交互式问答支持
- 标注置信度与不确定性
- 指出后续深入分析方向
