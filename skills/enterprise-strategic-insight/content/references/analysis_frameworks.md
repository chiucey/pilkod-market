# 战略分析框架参考手册

## 一、宏观分析框架

### 1.1 PESTEL分析框架

PESTEL是分析宏观环境的核心工具，通过六大维度系统评估外部环境影响：

#### 政治维度（Political）
- 政府稳定性与政策连续性
- 贸易政策与关税壁垒
- 政府采购倾向与规模
- 政企关系与监管环境
- 地缘政治风险

#### 经济维度（Economic）
- GDP增长率与经济周期
- 通货膨胀率与货币政策
- 利率与汇率变动
- 居民可支配收入水平
- 失业率与劳动力成本

#### 社会文化维度（Social）
- 人口结构变化趋势
- 消费习惯与价值观演变
- 教育水平与技能供给
- 生活方式与健康意识
- 社会流动性与阶层分布

#### 技术维度（Technological）
- 研发投入与创新能力
- 技术成熟度与迭代速度
- 数字化与自动化水平
- 知识产权保护力度
- 技术扩散与溢出效应

#### 环境维度（Environmental）
- 气候变化与极端天气
- 资源稀缺与能源转型
- 碳排放与环保法规
- 可持续发展压力
- 循环经济要求

#### 法律维度（Legal）
- 劳动法与雇佣法规
- 反垄断与竞争法
- 消费者保护法
- 数据隐私与安全法规
- 行业特定法规

### 1.2 行业生命周期模型

识别行业所处发展阶段，制定差异化战略：

| 阶段 | 特征 | 战略重点 |
|------|------|----------|
| 导入期 | 市场规模小、技术不成熟、用户认知低 | 市场教育、产品迭代、赛道卡位 |
| 成长期 | 市场需求爆发、竞争加剧、利润增长 | 规模化、渠道拓展、品牌建设 |
| 成熟期 | 市场饱和、增长放缓、竞争激烈 | 成本控制、差异化、细分深耕 |
| 衰退期 | 需求下降、替代品涌现 | 收缩战略、转型探索、价值收割 |

### 1.3 情景规划方法论

构建3-4种未来情景，评估战略韧性：

1. **基准情景**：延续当前趋势
2. **乐观情景**：有利因素叠加
3. **悲观情景**：风险集中爆发
4. **颠覆情景**：黑天鹅/灰犀牛事件

## 二、中观分析框架

### 2.1 波特五力模型

分析行业竞争结构与盈利能力：

#### 现有竞争者竞争
- 竞争者数量与规模分布
- 行业增长率
- 产品差异化程度
- 退出壁垒高低
- 战略赌注大小

#### 潜在进入者威胁
- 进入壁垒高度
  - 规模经济
  - 品牌忠诚度
  - 渠道控制
  - 监管许可
  - 技术专利
- 潜在进入者预期
- 进入壁垒vs进入激励

#### 替代品威胁
- 替代品性价比
- 替代品使用场景覆盖
- 替代品演变趋势
- 用户转向成本

#### 供应商议价能力
- 供应商集中度
- 替代供应商可得性
- 供应商产品差异化
- 前向整合威胁

#### 买方议价能力
- 买方集中度
- 买方转换成本
- 买方信息透明度
- 后向整合威胁

### 2.2 竞争格局分析方法

#### 战略群体图
按战略维度划分竞争者群体：
- 维度选择：价格vs质量、专业化vs多元化、地理覆盖、技术领先vs模仿
- 识别战略群体间的移动壁垒
- 发现潜在的战略空间

#### 竞争定位地图
二维矩阵展示竞争位置：
- X轴：核心竞争维度1
- Y轴：核心竞争维度2
- 气泡大小：市场份额
- 颜色/形状：战略群体

### 2.3 价值链分析

分解企业活动，识别竞争优势来源：

#### 主要活动
- 进货物流（原材料接收、存储、库存控制）
- 生产运营（制造、装配、设备维护）
- 出货物流（产成品仓储、订单处理、运输）
- 市场营销（广告、促销、渠道管理）
- 售后服务（安装、维修、培训）

#### 支持活动
- 企业基础设施（管理层、财务、法务）
- 人力资源管理（招聘、培训、激励）
- 技术开发（研发、设计、工艺改进）
- 采购（原材料、服务、设备）

## 三、微观分析框架

### 3.1 商业画布（Business Model Canvas）

九大要素系统描述商业模式：

| 要素 | 关键问题 | 分析要点 |
|------|----------|----------|
| 客户细分 | 我们为谁创造价值？ | 细分市场特征、优先级 |
| 价值主张 | 我们如何创造价值？ | 核心价值、问题解决、需求满足 |
| 渠道通路 | 如何触达客户？ | 发现、评估、购买、交付 |
| 客户关系 | 如何维护关系？ | 自助服务、专属服务、社区 |
| 收入来源 | 如何获取价值？ | 收入模式、价格机制 |
| 核心资源 | 谁来创造价值？ | 实体、知识、金融、人力 |
| 关键业务 | 做什么来创造价值？ | 平台、生产、解决方案 |
| 重要合作 | 谁来参与？ | 供应商、合作伙伴、联盟 |
| 成本结构 | 付出什么代价？ | 成本导向、价值导向 |

### 3.2 SWOT分析框架

内外部因素综合评估：

#### 优势（Strengths）
- 核心能力与资源
- 市场竞争优势
- 财务实力
- 品牌资产
- 技术领先

#### 劣势（Weaknesses）
- 资源短板
- 能力缺陷
- 运营效率问题
- 财务压力
- 市场份额下滑

#### 机会（Opportunities）
- 市场增长空间
- 技术突破带来的可能性
- 政策红利
- 产业转移
- 消费升级

#### 威胁（Threats）
- 竞争加剧
- 替代品威胁
- 监管收紧
- 经济下行
- 技术颠覆

### 3.3 战略时钟模型

八种竞争战略定位：

| 位置 | 战略类型 | 特征 | 适用场景 |
|------|----------|------|----------|
| 1 | 低价低值 | 成本领先 | 大众市场、充分竞争 |
| 2 | 混合战略 | 中等价格、中等价值 | 主流市场 |
| 3 | 聚焦低成本 | 低价满足细分 | 利基市场 |
| 4 | 差异化 | 高价值、合理价格 | 中高端市场 |
| 5 | 聚焦差异化 | 高价值、特定细分 | 高端细分 |
| 6 | 溢价战略 | 高价格、中等价值 | 奢侈品市场 |
| 7 | 竞争陷阱 | 高价格、低价值 | 危险区域 |
| 8 | 价值陷阱 | 低价格、高价值 | 短期可行、长期危险 |

### 3.4 安索夫矩阵

产品/市场扩张策略选择：

|  | 现有产品 | 新产品 |
|--|----------|--------|
| **现有市场** | 市场渗透 | 产品开发 |
| **新市场** | 市场开发 | 多元化 |

#### 市场渗透策略
- 增加现有客户使用量
- 抢夺竞争对手客户
- 吸引非用户转化

#### 产品开发策略
- 新功能/规格
- 产品升级
- 产品线延伸

#### 市场开发策略
- 地域扩张
- 渠道拓展
- 新客群开拓

#### 多元化策略
- 相关多元化（同心多元化）
- 不相关多元化（混合多元化）

### 3.5 价值主张画布

深度理解客户需求与价值契合：

#### 客户概况
- 客户任务（需完成的工作）
- 痛点（阻碍与风险）
- 收益（渴望与期望）

#### 价值地图
- 产品/服务（解决什么问题）
- 痛点缓解方案（如何消除痛点）
- 收益创造方案（如何创造收益）

#### 契合度检验
- 价值主张与客户任务匹配
- 痛点缓解与痛点强度对应
- 收益创造与收益渴望对齐

## 四、战略工具箱

### 4.1 BCG增长-份额矩阵

业务组合分析与资源配置：

```
                    高
                     │
         明星        │        问题
     （高增长/高份额）│（高增长/低份额）
                     │
    ─────────────────┼─────────────────
                     │
     金牛            │        瘦狗
  （低增长/高份额）   │（低增长/低份额）
                     │
                    低
              低相对市场份额    高
```

#### 战略含义
- **明星业务**：加大投资、巩固优势
- **金牛业务**：收割现金、稳定市场
- **问题业务**：选择性投资、打造明星
- **瘦狗业务**：收缩或退出

- 技术变革
- 监管环境

- 市场份额
- 品牌影响力
- 渠道覆盖

#### 战略建议
- 投资增长（右上格）
