# 电商主图制作专家

## 技能概述

本技能基于「京东京造德式小麦啤酒」5张主图的深入分析，提炼出通用的电商主图制作方法论。主图是用户搜索/浏览时第一眼看到的5张核心图片，决定了点击率和转化率。本技能聚焦于主图（非详情页）的设计规范，适用于任何品牌、任何类目。

## 5张主图逐张拆解

### 第1张：黄金营销图（The Hook）

**目标**：3秒内让用户知道"这是什么、好在哪、多少钱"，驱动点击。

**通用模板要素**：

| 要素 | 说明 | 变量格式 |
|------|------|----------|
| 品牌标识 | 置顶展示 | `{{品牌Logo}}` |
| 核心卖点 | 大字高亮，1-3个 | `{{核心卖点1-3个}}` |
| 产品主视觉 | 占据画面40%-50% | `{{产品高清图}}` |
| 促销信息 | 价格+优惠 | `{{促销价格}}` + `{{优惠力度}}` |
| 权威背书 | 小型徽章 | `{{权威背书}}` |

**设计规范**：
- **布局**：左文右图（产品在右，文字在左）
- **色彩**：品牌主色为底，核心卖点用对比色，价格用红色
- **字号层级**：品牌名(中) → 核心卖点(大) → 促销价(特大) → 次要信息(小)
- **画面占比**：产品图45%，文字区35%，装饰元素20%

**避坑指南**：
- 不要在主图上堆砌超过3个卖点
- 不要使用与竞品雷同的配色，必须有品牌识别度
- 价格必须清晰可见，不要和背景融合

### 第2张：感官种草图（The Desire）

**目标**：用场景激发购买欲望，让用户产生"我也想这样"的代入感。

**通用模板要素**：

| 要素 | 说明 | 变量格式 |
|------|------|----------|
| 使用场景 | 动态画面 | `{{使用场景}}` |
| 感官描述 | 1-3项感官特性 | `{{感官特性1-3项}}` |
| 产品展示 | 产品+使用效果同框 | `{{产品+使用效果}}` |
| 品质暗示 | 高端色调 | `{{品质关键词}}` |

**设计规范**：
- **布局**：对角线构图，产品左上→使用效果右下，形成视觉动线
- **色彩**：暖色调为主，背景干净明亮
- **文案**：感性描述，多用形容词（细腻/醇厚/丝滑），少用数据
- **画面占比**：使用场景60%，产品20%，文字20%

**按类目变体**：

| 类目 | 场景示例 | 感官关键词 |
|------|----------|------------|
| 食品饮料 | 食用/饮用动态特写 | 酥脆、丝滑、浓郁 |
| 美妆护肤 | 涂抹/使用过程 | 水润、服帖、透亮 |
| 数码家电 | 使用场景环境图 | 流畅、沉浸、便捷 |
| 家居日用 | 摆放在家中场景 | 温馨、整洁、质感 |
| 服饰鞋包 | 模特穿搭/上身效果 | 显瘦、舒适、百搭 |

### 第3张：理性说服图（The Proof）

**目标**：用对比数据让用户理性确认"这个确实更好"，打消比价心理。

**通用模板要素**：

| 要素 | 说明 | 变量格式 |
|------|------|----------|
| 对比标题 | 品牌 vs 普通类目 | `{{品牌}} vs 普通{{类目}}` |
| 对比维度 | 3-5个关键维度 | `{{3-5个关键维度}}` |
| 我方优势 | 每个维度的优势 | `{{每个维度的优势}}` |
| 参照对象 | 竞品/普通产品剪影 | `{{竞品/普通产品图}}` |
| 视觉区分 | 我方暖色/亮色 | 对方冷色/灰色 |

**设计规范**：
- **布局**：居中列表式，5行对比横行排列
- **色彩**：统一色系（如棕色系），我方标签加亮，对方灰色淡化
- **对比维度**：选用户最关心的维度，必须是真实可量化的差异
- **画面占比**：标题10%，对比表70%，产品背景20%

**对比维度选取策略**：

| 类目 | 推荐对比维度 |
|------|-------------|
| 食品饮料 | 原料、工艺、保质期、添加剂、口感 |
| 美妆护肤 | 成分浓度、吸收速度、持久度、安全性、质地 |
| 数码家电 | 性能参数、续航、材质、售后、兼容性 |
| 家居日用 | 材质、耐用性、清洁难度、收纳性、环保 |

### 第4张：信任构建图（The Trust）

**目标**：用权威证据消除最后顾虑，打通购买决策的"最后一公里"。

**通用模板要素**：

| 要素 | 说明 | 变量格式 |
|------|------|----------|
| 标题 | 信任背书标题 | `{{信任标题}}` |
| 证书展示 | 检测报告/证书排列 | `{{检测报告/证书}}` |
| 关键信息 | 证书关键信息放大 | `{{证书关键信息}}` |
| 视觉手法 | 暖色+金属质感 | 传递可靠感 |

**设计规范**：
- **布局**：证书扇形堆叠，中间最大最突出
- **色彩**：暖色背景，金属色边框，红色印章强调
- **证书选取**：选最权威、最相关、用户最认可的1-3份
- **画面占比**：证书80%，标题20%

**信任素材替代方案**（如无检测报告）：

| 替代方案 | 适用场景 | 展示方式 |
|----------|----------|----------|
| 销量数据 | 热销产品 | 「已售{{数量}}+」大字 |
| 用户好评截图 | 评价多的产品 | 精选3-5条好评卡片 |
| 明星/KOL推荐 | 有代言的产品 | 代言人+推荐语 |
| 品牌专利 | 有技术壁垒的产品 | 专利号+技术名称 |
| 媒体报道 | 有媒体曝光的产品 | 媒体Logo墙 |
| 获奖记录 | 有行业奖项的产品 | 奖杯/奖牌展示 |

---

### 第5张：规则总结图（The Close）

**目标**：将产品理念浓缩为口号式原则，让用户记住并愿意传播。

**通用模板要素**：

| 要素 | 说明 | 变量格式 |
|------|------|----------|
| 核心理念 | N大原则/N步标准 | `{{N大原则/N步标准}}` |
| 分点标题 | 简短有力 | `{{原则1-4}}` |
| 分点说明 | 每点一条解释 | `{{每原则1句说明}}` |
| 图标 | 每个原则配图标 | `{{每个原则配图标}}` |
| 排版 | 2×2网格 | 虚线分隔 |

**设计规范**：
- **布局**：4宫格（偶数原则），对称均衡
- **色彩**：柔和背景（米色/浅灰），点缀品牌色
- **文案**：每个原则≤4字，说明≤10字，朗朗上口
- **画面占比**：标题10%，4个模块各20%，装饰10%

**原则提炼公式**：
- **否定式**：「不XX」系列 → 不妥协、不将就、不添加、不虚高
- **肯定式**：「只XX」系列 → 只选优、只精工、只直供、只让利
- **数字式**：「X大标准」→ 5大品质标准、3重安全保障
- **流程式**：「X步XX」→ 3步养护、4道工序

## 通用制作流程

### 第一步：产品信息梳理

在动手设计前，先填写以下信息表：

```
品牌名称：________
产品名称：________
产品类目：________
目标用户：________
核心卖点1：________（最重要）
核心卖点2：________
核心卖点3：________
促销价格：________ / 原价：________
竞品名称：________
竞品弱点1：________
竞品弱点2：________
竞品弱点3：________
信任背书1：________（最强）
信任背书2：________
产品原则1：________
产品原则2：________
产品原则3：________
产品原则4：________
使用场景：________
感官特性1：________
感官特性2：________
品牌主色：________
```

### 第二步：套入5张主图模板

| 图序 | 模板 | 变量填充 |
|------|------|----------|
| 第1张 | 黄金营销图 | 品牌+产品+卖点1/2/3+促销价+背书 |
| 第2张 | 感官种草图 | 使用场景+感官特性+产品展示 |
| 第3张 | 理性说服图 | 品牌vs竞品+3-5维度对比 |
| 第4张 | 信任构建图 | 最强背书1-3个 |
| 第5张 | 规则总结图 | 4原则+图标+说明 |

### 第三步：统一视觉规范

- **字体**：不超过2种，标题/正文各一
- **配色**：品牌主色+1个强调色+中性色（白/灰/黑）
- **Logo位置**：5张图保持一致位置
- **字号层级**：统一3级（大标题/正文/辅助）

### 第四步：检查清单

- [ ] 第1张能否3秒内传达"是什么+好在哪+多少钱"？
- [ ] 第2张能否激发使用欲望？
- [ ] 第3张的对比是否真实可量化？
- [ ] 第4张的背书是否足够权威？
- [ ] 第5张的原则是否朗朗上口？
- [ ] 5张图放在一起，品牌调性是否统一？
- [ ] 与竞品主图并排对比，是否有差异化？

## 常见错误与避坑

### 错误1：主图信息过载
**症状**：第1张图塞了8个卖点+3个促销+2个logo
**后果**：用户看不清重点，直接划走
**纠正**：第1张最多3个卖点，其余分散到其他图

### 错误2：5张各自为政
**症状**：每张图风格不同，像5个不同品牌
**后果**：品牌感弱，用户记不住
**纠正**：统一色板、字体、Logo位置

### 错误3：对比图造假感强
**症状**："我们的产品 vs 普通产品"但差异夸大到不可信
**后果**：用户反感，信任崩塌
**纠正**：对比必须真实可验证，宁可有保留也不夸大

### 错误4：第5张敷衍了事
**症状**：前4张精心设计，第5张随便拼凑
**后果**：虎头蛇尾，品牌理念未落地
**纠正**：第5张是记忆点，比第2-4张更值得打磨

### 错误5：不区分平台规范
**症状**：同一套主图发淘宝、京东、拼多多
**后果**：某平台可能因违规被下架
**纠正**：了解各平台主图规范（如拼多多不允许价格、京东要求白底等）
