# 文档问答最佳实践

## 问答原则

### 1. 严格基于原文
- 只使用文档中明确提供的信息
- 不进行推测或假设
- 不引入外部知识

### 2. 引用来源
- 标注信息的原文位置
- 使用页码、章节或段落编号
- 对于长文档，提供上下文片段

### 3. 处理不确定性
- 文档未涉及的问题：明确告知用户
- 文档表述模糊时：说明"文档中提到但未详细说明"
- 存在多个可能解释时：列出所有可能的解读

## 问答模板

### 标准回答格式
```
**回答**：
[直接回答用户问题的内容]

**原文引用**：
> "[相关的原文内容]"

**出处**：
[第X页/第X章/第X段]
```

### 无法回答时的格式
```
**回答**：
很抱歉，当前已学习的文档中不包含与您问题相关的信息。
您可以：
1. 提供包含相关内容的其他文档
2. 更换/补充文档内容
3. 调整问题关键词后再试
```

## 问题类型与策略

### 1. 事实查询类
**问题示例**："这份文档的作者是谁？"
**策略**：直接提取文档元信息

### 2. 概念解释类
**问题示例**："什么是 XXX 技术？"
**策略**：
- 搜索文档中的定义段落
- 提取相关解释的完整上下文

### 3. 对比分析类
**问题示例**："A 方法和 B 方法有什么区别？"
**策略**：
- 分别提取两种方法的描述
- 整理对比点
- 如文档有专门对比章节，直接引用

### 4. 总结归纳类
**问题示例**："这篇论文的主要贡献是什么？"
**策略**：
- 提取摘要和结论部分
- 汇总方法创新点
- 整理实验贡献

### 5. 细节查找类
**问题示例**："文档中提到的实验参数是什么？"
**策略**：
- 定位相关章节
- 提取具体数值或参数
- 提供上下文

## 多轮对话处理

### 保持上下文
- 记住用户当前学习的文档
- 在后续问题中默认在当前文档中搜索
- 支持用户明确切换文档

### 指代消解
- "它"、"这篇文章"、"上述方法"等指代词
- 根据上下文推断指代对象
- 必要时向用户确认

### 渐进式深入
- 从概括性问题开始
- 逐步深入细节
- 支持用户逐步探索文档

## 边界情况处理

### 文档质量问题
- 扫描 PDF（无文本层）：提示用户转换格式
- 乱码：提示用户检查编码
- 结构混乱：尝试自动检测结构

### 复杂文档处理
- 超长文档：分段处理，提供导航
- 多文档：支持用户指定特定文档
- 混合语言：识别并处理

### 用户问题优化
当用户问题表述不清时：
```
我理解您想了解 [猜测的问题意图]。
请确认您想了解的是：
A. [选项1]
B. [选项2]
C. 其他（请详细描述）
```
