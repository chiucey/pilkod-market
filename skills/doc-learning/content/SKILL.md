# 文档学习技能

## 技能概述

本技能用于学习用户上传的文档、文献，并基于文档内容提供结构化总结和智能问答服务。

## 核心能力

1. **文档解析**：支持 PDF、Word(.docx)、TXT、Markdown 等常见格式
2. **结构化总结**：提取文档的核心信息，生成结构化概况
3. **智能问答**：严格基于文档内容回答用户问题，确保回答的准确性
4. **上下文记忆**：支持多轮对话，保持对已学习文档的引用

## 使用流程

### 第一步：接收文档

用户可以通过以下方式提供文档：
- 上传文件（系统自动解析）
- 提供文档路径
- 粘贴文档文本内容

### 第二步：文档解析与学习

使用适当的工具解析文档：

**对于 PDF 文件**：
```
使用 extract_pdfs_full_content 或 extract_pdfs_key_info 工具提取内容
```

**对于文本/代码文件**：
```
使用 Read 工具直接读取文件内容
```

**解析后操作**：
1. 清理和预处理文本（去除无关格式、页眉页脚等）
2. 识别文档结构（章节、标题、段落）
3. 提取关键信息（作者、日期、核心概念等）
4. 生成文档嵌入向量（用于后续问答）

### 第三步：生成结构化概况

基于文档内容，生成包含以下部分的文档概况：

```
# 文档概况

## 基本信息
- 文档标题：[提取或推断]
- 文档类型：[论文/报告/手册/其他]
- 预估页数/字数：[估算]

## 核心摘要
[2-3 句话概括文档主要内容]

## 主要章节
1. [第一章主题和关键点]
2. [第二章主题和关键点]
...

## 关键概念
- 概念1：[定义/解释]
- 概念2：[定义/解释]
...

## 重要数据/结论
[如有重要数据或结论，列出]

## 文档特点
[文档的优点、独特之处或局限性]
```

### 第四步：问答服务

当用户提问时：
1. 理解用户问题
2. 在文档内容中检索相关信息
3. 严格基于文档原文生成回答
4. 注明回答的原文出处（页码或段落位置）

**回答格式**：
```
回答：[基于文档内容的回答]

原文出处：[具体位置]
```

## 注意事项

1. **严格基于原文**：回答必须来自文档内容，不要添加外部知识
2. **不确定时说明**：如果文档没有相关信息，明确告知用户
3. **保持客观**：不要对文档内容进行主观评价或推断
4. **引用准确**：提供的信息要标注具体来源位置

## 错误处理

- 文档无法解析：提示用户尝试其他格式或手动粘贴文本
- 文档内容为空：提示用户确认文档是否包含有效内容
- 问题超出文档范围：明确说明该问题无法基于当前文档回答

## 适用场景

- 学术论文阅读与总结
- 技术文档学习
- 合同/协议分析
- 市场报告研究
- 任何需要从文档中提取信息的场景
