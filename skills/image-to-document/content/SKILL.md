# 图片转文档/表格技能

## 核心能力

将图片内容高精度识别后，生成 Doc 或 Excel 格式文档。支持单图处理和多图整合。

## 工作流程

### 阶段 1：图片内容识别（Generator 角色）

1. **接收用户输入**
   - 单张图片：直接处理
   - 多张图片：记录顺序和关联关系

2. **OCR 内容提取**
   - 使用 `images_understand` 工具进行深度理解
   - 提取所有文本内容、表格结构、数据关系
   - 识别图片类型（表格、文档、截图、手写等）

3. **内容预处理**
   - 整理提取的文本结构
   - 识别表格行列结构
   - 提取关键数据和标签

### 阶段 2：文档生成（Generator 角色）

根据用户指定的输出格式：

**生成 Word 文档 (.docx)**：
- 使用 `expert-skills:minimax-docx` 技能
- 保持原有结构和层级
- 包含标题、段落、列表、表格等元素

**生成 Excel 表格 (.xlsx)**：
- 使用 `expert-skills:minimax-xlsx` 技能
- 保留表格结构和数据关系
- 支持多 sheet 整合（多图场景）

### 阶段 3：质量验证（Validator 角色）

1. **完整性检查**
   - 验证提取内容与原图一致性
   - 检查关键数据是否遗漏
   - 确认表格结构完整性

2. **格式检查**
   - Doc 格式：标题层级、段落、列表、表格
   - Excel 格式：单元格合并、数据类型、公式引用

3. **问题修复**
   - 如发现问题，标记具体位置
   - 提供修复建议
   - 必要时重新生成

### 阶段 4：输出交付

1. 保存文件到用户指定位置
2. 提供预览说明
3. 如有质量问题，给出修复选项

## 输出格式映射

| 图片类型 | 建议输出格式 | 说明 |
|---------|-------------|------|
| 纯文本截图 | .docx | 保留段落结构 |
| 表格图片 | .xlsx | 还原行列结构 |
| 数据报表 | .xlsx | 保留数值和格式 |
| 文档扫描件 | .docx | 识别标题层级 |
| 多页截图 | .docx 或 .xlsx | 整合后输出 |
