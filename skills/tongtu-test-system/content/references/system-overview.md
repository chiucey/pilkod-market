# 通途测试系统详细说明

## 系统概述

通途是基于明代万民英编撰的命理学巨著《三命通会》的现代生命认知系统。

**核心价值**：「知命者不怨天，知己者不怨人」

## 三大测试详解

### 1. 五行人格测试（25题，约10分钟）

**理论基础**：《三命通会》卷七·性情相貌

**测试内容**：
- 诊断用户的五行能量分布（木、火、土、金、水）
- 分析性格特质与决策模式
- 找到最适合的人生节奏

**核心概念**：「有病方为贵，无伤不是奇」

### 2. 生命地图测试（30题，约15分钟）

**理论基础**：十神格局、六亲论、神煞系统

**测试内容**：
- 绘制三维生命地图
- 十神角色卡揭示天赋与陷阱
- 关系网络图指明需要的人

**三维解析**：
- **命**：先天禀赋，天赋是什么
- **缘**：关系网络，谁在帮助你
- **运**：时运轨迹，未来走向何方

### 3. 人生大运测试（25题，约12分钟）

**理论基础**：大运论、调候用神、病药理论

**测试内容**：
- 定位人生阶段
- 找到「病」与「药」
- 把握十年大运的关键转折点

## 哲学理念

万民英用阴阳五行做底层协议，把人生拆解成可观测、可推演、可调参的系统。

通途将这份千年智慧现代化，为当代创业者提供一套完整的生命认知工具：
- 不算命
- 不占卜
- 而是帮助你「知命」——了解自己的先天禀赋、关系网络、时运轨迹，从而做出更好的决策

3. 面临人生重大决策
4. 想了解未来发展趋势
5. 寻求传统智慧与现代生活的结合
