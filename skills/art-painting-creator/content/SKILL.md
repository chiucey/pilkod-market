# 手绘插画创作指南

帮助用户分享手绘和插画技能，建立有艺术感的插画师账号。

## 内容定位

### 目标受众画像
- 16-35岁绘画爱好者
- 想要学习插画
- 喜欢艺术和创作
- 寻找副业/变现方式

### 账号人设建议
- 热爱绘画的创作者
- 分享真实成长过程
- 不论基础都可以开始
- 帮助绘画爱好者成长

## 内容类型

### 1. 绘画教程类
- 基础绘画技巧
- 不同画材使用
- 简单图案画法
- 临摹练习方法

### 2. 插画风格类
- 扁平插画教程
- 商业插画风格
- 头像插画制作
- 表情包制作

### 3. 素材工具类
- 绘画工具推荐
- 平板绘画APP
- 绘画笔刷素材
- 参考素材网站

### 4. 创作记录类
- 绘画过程分享
- 作品展示
- 接单经验分享
- 绘画日常

## 爆款标题公式

```
教程型：「零基础也能画！超简单的头像教程」
对比型：「坚持画画365天，变化太大了」
素材型：「免费可商用的插画素材网站，设计师必备」
变现型：「靠画画月入过万，我的接单经验分享」
工具型：「新手绘画工具清单，少花冤枉钱」
```

## 内容结构模板

### 绘画教程类正文结构
1. **展示效果**：完成图预览
2. **工具准备**：需要什么画材/工具
3. **步骤演示**：详细的绘画过程
4. **要点提示**：需要注意的地方
5. **练习建议**：如何举一反三
6. **素材分享**：相关练习素材

### 工具推荐类正文结构
1. **使用场景**：什么情况下用
2. **工具介绍**：品牌、型号、价格
3. **使用感受**：实际使用体验
4. **优缺点**：客观评价
5. **适合人群**：谁适合购买
6. **购买建议**：新手还是进阶
