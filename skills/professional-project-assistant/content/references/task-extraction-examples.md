# 任务提取示例库

## 场景分类与提取规则

### 1. 明确的工作安排

| 用户输入 | 提取结果 |
|----------|----------|
| "这周五要给客户发项目方案" | 事项：发送客户项目方案；完成时间：本周五；负责人：我 |
| "明天上午10点开会讨论预算" | 事项：讨论预算会议；开始时间：明天10:00；负责人：我 |
| "小王负责跟进供应商合同" | 事项：跟进供应商合同；负责人：小王 |
| "本月25号前完成季度报告" | 事项：完成季度报告；完成时间：25号；负责人：我 |

### 2. 需要补充信息的任务

| 用户输入 | 提取结果 | 需要询问 |
|----------|----------|----------|
| "要做个PPT" | 事项：制作PPT | 完成时间、主题内容 |
| "联系一下供应商" | 事项：联系供应商 | 哪个供应商、完成时间 |
| "整理一下文件" | 事项：整理文件 | 什么文件、完成时间 |

### 3. 进度更新

| 用户输入 | 提取结果 |
|----------|----------|
| "XX任务做完了" | 当前进度：100%，状态：已完成 |
| "XX完成了80%" | 当前进度：80% |
| "XX还在推进中" | 当前进度：保持不变，备注更新 |
| "遇到点问题，暂停了" | 状态：进行中，备注：遇到问题待解决 |

### 4. 灵感与记录

| 用户输入 | 存储位置 |
|----------|----------|
| "突然想到可以优化流程..." | notes.md |
| "下次出差记得带..." | notes.md |
| "客户说想要..." | notes.md（带标签：客户需求） |

## 进度百分比参考

| 阶段 | 百分比 | 描述 |
|------|--------|------|
| 未开始 | 0% | 刚记录，尚未开始执行 |
| 规划中 | 10-20% | 正在制定计划/方案 |
| 启动 | 25% | 正式开始执行 |
| 进行中 | 40-60% | 核心执行阶段 |
| 收尾 | 75-90% | 接近完成 |
| 待确认 | 95% | 完成但需他人确认 |
| 已完成 | 100% | 全部完成 |

## 鼓励语料库

### 任务完成鼓励
- "太棒了！又完成一项，继续保持！"
- "效率超高！为你点赞！"
- "这项任务完成得很出色！"
- "专注让你越来越高效，继续加油！"

### 进度更新鼓励
- "稳扎稳打，胜利就在前方！"
- "每一步前进都是成长，你做得很好！"
- "进度不错，保持这个节奏！"

### 遇到困难时的鼓励
- "每个挑战都是成长的机会，你一定可以的！"
- "遇到问题是正常的，我们一起想办法解决。"
- "你已经做得很好了，困难只是暂时的。"

### 压力缓解
- "工作虽然忙，但你在努力克服，了不起！"
- "别给自己太大压力，一步一步来。"
- "记得照顾好自己，工作重要，但健康更重要。"
