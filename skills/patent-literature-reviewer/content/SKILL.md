# 专利文献检索与现有技术综述

## 核心能力

本技能从专利PDF文档中提取技术特征，构建PubMed检索式，筛选最相关文献并生成Word格式的现有技术报告。

## 工作流程

### 阶段1：专利文档处理

1. **PDF文本提取**
   - 使用 `extract_pdfs_full_content` 工具提取专利全文文本
   - 无需OCR处理，直接提取可搜索文本

2. **技术特征提取**
   - 分析专利摘要和权利要求书
   - 提取技术领域（1个）
   - 提取关键技术手段（2-3个）
   - 提取核心发明点

### 阶段2：检索式构建

根据提取的技术特征构建布尔检索式：

```
检索式格式：(技术领域[Title/Abstract]) AND (关键技术手段1[Title/Abstract]) AND (关键技术手段2[Title/Abstract])
```

**构建规则**：
- 技术领域使用规范的医学/生物学术语
- 关键技术手段需考虑同义词和上位概念
- 使用OR连接同义词，使用AND连接不同维度

### 阶段3：PubMed检索

1. 使用 `batch_web_search` 工具搜索PubMed
2. 关键词格式：`site:pubmed.ncbi.nlm.nih.gov 检索式`
3. 获取检索结果并按相关性排序

### 阶段4：相关性筛选

1. 提取检索结果前20篇
2. 使用大模型分析每篇文献的标题、摘要与本专利的相关性
3. 筛选出最相关的5篇文献
4. 选择标准：
   - 技术方案相似度
   - 应用领域重叠度
   - 解决技术问题的关联性

### 阶段5：报告生成

生成Word格式报告，结构如下：

```
1. 现有技术概况
   - 本申请技术领域概述
   - 相关技术发展脉络
   - 主要技术手段分类

2. 文献综述
   - 文献1：[标题]，相关性：[高/中]，公开内容：[具体技术内容]
   - 文献2：[标题]，相关性：[高/中]，公开内容：[具体技术内容]
   - 文献3-5：同上格式

3. 报告结论
   - 本申请核心发明点总结
   - 与现有技术的区别
   - 技术创新点分析
```

**输出文件**：`专利现有技术报告_YYYYMMDD_HHMMSS.docx`

### 阶段6：复盘与策略更新

每次任务完成后执行复盘：

1. **检索效果评估**
   - 检索结果数量是否充足
   - 筛选出文献的相关度
   - 是否遗漏重要文献

2. **检索式优化**
   - 分析低相关度文献的原因
   - 调整关键词和逻辑运算符
   - 补充同义词或下位概念

3. **策略文档更新**
   - 更新 `references/retrieval_strategy.md`
   - 记录本次检索经验
   - 优化筛选标准

## 关键提示

- 始终使用规范的医学/生物学术语进行检索
- 优先选择高影响力期刊和最新发表文献
- 报告需客观呈现现有技术，避免主观评价
- 复盘是持续改进检索效果的关键步骤
