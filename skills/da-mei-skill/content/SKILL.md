# 达美skill：上市公司分析与价值投资框架

> 本技能基于雪球大V"陈达美股投资"的投资理念和写作模式提炼

## 核心理念

### 价值投资三角

理解价值投资的核心三角：
1. **施洛斯的内在价值** - 企业的真实价值评估
2. **克拉曼的安全边际** - 买入价格与内在价值的缓冲空间
3. **格雷厄姆的市场解释** - 理解市场先生的运作方式

### 核心投资原则

```
"在折扣的价格上去买好的公司" —— Joel Greenblatt
```

**四不原则**：
- 不投业务与客户单一公司
- 不投不增长公司
- 不投市值过小的公司
- 不投周期股

**四必原则**：
- 必须是细分市场的领跑者
- 必须身处朝阳行业
- 必须有长久期的成长性
- 必须有至少可以看见的疑似壁垒

## 上市公司分析框架

### 第一步：收入分析
- 总收入及同比增长
- 收入结构变化
- 各业务板块收入拆分

### 第二步：业务深度分析
- 核心业务基本盘是否稳固
- 关键运营数据：GTV、用户数、订单数、门店数量、市场份额
- 新业务/战略业务的发展态势

### 第三步：盈利能力分析
- 毛利率变化及趋势
- 费用率分析（履约费用率、销售费用率、管理费用率、研发费用率）
- 单位经济效益（UE）分析
- Non-GAAP调整后利润

### 第四步：资产与现金流状况
- 现金储备
- 经营性现金流
- 股东回报（回购、分红）

### 第五步：未来展望与驱动力
- 管理层指引（guidance）
- 业务发展驱动力分析
- 政策影响评估
- 行业竞争格局

### 第六步：估值分析
- PE/P/S估值
- SOTP分部估值法
- 与同业对比
- 向前看而非静态估值

## 行业分析框架

### 电商/互联网
- **AI应用投资逻辑**：场景和电力是AI两大稀缺资源
- **协同效应**：电商+AI+云的整合视角
- **核心指标**：用户数、GMV、UE改善、货币化率

### 二手经济
- **产业链分析**："两头肥中间瘦"结构
  - 回收端：赚取服务费（8-9%）
  - 零售端：加价5-15%
  - 中间段：利润微薄
- **核心壁垒**：垂直整合能力
- **关键指标**：库存周转天数、市占率、单店模型

### 港股/中概股
- **核心配置**：ATM三件套（阿里、腾讯、小米）
- **估值方法**：前瞻PE、SOTP
- **资金面分析**：南向资金、公募配置

### 创新药
- **投资逻辑**：ADC、双抗新技术迭代 + BD出海
- **估值方法**：PB、PS分位数
- **关键公司**：信达生物、药明生物、百济神州等

### 科技股
- **AI产业链三件套**：
  - 上游（硬件/卖铲子）：芯片、服务器
  - 中游（软件/淘金块）：大模型、算法
  - 下游（应用/卖黄金）：应用场景

## 投资策略框架

### 神奇公式（Greenblatt）
1. 第一把筛子：**估值**（EBIT/EV，越高越好）
2. 第二把筛子：**ROIC**（资本回报率，越高越好）
3. 选取综合排名靠前的5-7家公司
4. 约20%-33%资金平均买入
5. 每2-3个月重复，持续3-5年

### 港股配置策略
- 港股通科技ETF + 港股通创新药ETF + 港股通消费ETF
- 哑铃式均衡配置

### 市场判断框架（霍华德·马克斯三阶段）
1. **积累阶段**：少数敏锐投资者买入
2. **上涨阶段**：大众涌入
3. **狂热阶段**：所有人都认为只会更好

## 写作模式指南

### 标题风格
- 比喻/双关：生动形象
- 押韵/对仗：朗朗上口
- 悬念/反问：吸引点击

### 文章结构
```
1. 开篇引入（故事/比喻/场景）
2. 核心逻辑（Investment Thesis）
3. 框架分析（图表/数据支撑）
4. 具体案例
5. 投资结论
6. 利益披露
```

### 数据呈现
- 多用表格对比
- 关键数字加粗标注
- 与行业大盘对比
- 引用权威机构数据

### 语言风格
- 生动幽默（俚语、网络用语适度使用）
- 逻辑清晰（数字序号、小标题）
- 专业但易懂（避免过度术语堆砌）
- 结论明确（投资建议清晰）

## 估值方法论

### 推荐的估值方法
- **DCF现金流折现法**
- **私募市场估值**
- **清算价值估值**
- **EBIT/EV（优于PE）**
- **SOTP分部估值**

### 反对的估值方法
- 纯市盈率（容易被操控）
- 账面价值
- 股息收益率（单独使用）

### 估值原则
- "模糊的正确远好于精确的错误"
- 估值一定是主观的，有预测成分
- 买好公司的前提是估值要合适
- 静态估值意义不大，要向前看

## 风险管理

### 仓位管理
- 通常手持30%-50%现金仓位
- 不要以为看懂的公司就重仓
- 分散投资能让你大概率"stay in the game"

### 风险识别
- 政策风险
- 周期性风险
- 竞争风险
- 流动性风险
