# 缠论算法参考文档

## 笔 (Bi)

### 定义
笔是缠论中最基础的构件，由顶分型和底分型之间的K线组成。

### 顶分型
```
    _
   / \    第二根K线高点最高，收盘最低
  |   |___
```

### 底分型
```
  ___    _
 |   |  / \
 |___| /
```

### 笔的规则
1. 笔必须由顶分型开始，底分型结束（或反之）
2. 中间至少有一根K线（不含包含关系）
3. 笔的起始点与结束点之间不能有包含关系

## 线段 (Segment)

### 定义
线段由至少3笔构成，且笔的方向一致。

### 规则
1. 线段内部至少有3笔
2. 线段的起始笔和结束笔方向一致
3. 线段内部笔之间没有破坏性包含关系

## 中枢 (Zhongshu)

### 定义
中枢是连续三段的重叠区域。

### 示意图
```
    |----段3----|
|---段2---|
|-------段1------|
   |====重叠====|  ← 中枢区间
```

## 背离 (Divergence)

### 顶背离
- 价格创出新高
- MACD指标未创新高（或创新低）
- 预示下跌动能增强

### 底背离
- 价格创出新低
- MACD指标未创新低（或创新高）
- 预示上涨动能积累

## 算法实现要点

```python

if high[i-1] < high[i] > high[i+1] and close[i-1] > close[i] < close[i+1]:
    # 顶分型

# 底分型判断
if low[i-1] > low[i] < low[i+1] and close[i-1] < close[i] > close[i+1]:
    # 底分型
```

