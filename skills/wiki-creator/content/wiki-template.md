# Wiki Template Reference

This document defines the visual design system, CSS tokens, and reusable HTML component patterns for all Wiki pages generated by the `wiki-creator` skill.

### Search JavaScript (Index Page)

```javascript
const input = document.getElementById('searchInput');
const cards = document.querySelectorAll('.term-card');
const sections = document.querySelectorAll('.category-section');

input.addEventListener('input', () => {
  const q = input.value.trim().toLowerCase();
  cards.forEach(card => {
    const name = (card.dataset.name || '').toLowerCase();
    const desc = (card.dataset.desc || '').toLowerCase();
    card.classList.toggle('hidden', q.length > 0 && !name.includes(q) && !desc.includes(q));
  });
  // Hide empty sections
  sections.forEach(sec => {
    const visible = [...sec.querySelectorAll('.term-card')].some(c => !c.classList.contains('hidden'));
    sec.classList.toggle('hidden', !visible);
  });
  document.getElementById('totalCount').textContent =
    [...cards].filter(c => !c.classList.contains('hidden')).length;
});
```

## Term ID Naming Convention

Convert term names to safe URL slugs:
- Lowercase all ASCII characters
- Replace spaces and `/` with `-`
- Remove all characters except `a-z`, `0-9`, `-`
- Examples:
  - `MQTT` → `mqtt`
  - `TLS/SSL` → `tls-ssl`
  - `K8s (Kubernetes)` → `k8s`
  - `消息队列` → `message-queue` (use English slug when term is Chinese)
  - `发布/订阅模式` → `pub-sub`
