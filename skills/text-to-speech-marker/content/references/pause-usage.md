# 停顿标记使用指南

## 基础语法

```
<#x#>
```

- `x`：停顿时长，单位秒
- 范围：0.01 - 99.99
- 精度：最多两位小数

## 时长选择指南

### 极短停顿 (0.1-0.3秒)
用于自然的呼吸和语法停顿：

```
今天<#0.2#>我们来说一个故事。<#0.2#>
从前<#0.1#>有座山。
```

### 短停顿 (0.3-0.5秒)
用于逗号、分号等语法停顿：

```
大家好，我是小明。(breath)<#0.5#>欢迎收听今天的节目。<#0.5#>
今天的话题很有意思<#0.3#>
让我来给大家介绍一下。
```

### 中等停顿 (1-2秒)
用于句号、问号后的自然停顿：

```
第一部分讲完了。<#1.5#>
接下来是第二部分。
```

### 长停顿 (2-3秒)
用于段落结束、重大转折、悬念设置：

```
故事讲到这里。(breath)<#2.5#>
你想知道后来发生了什么吗？
```

### 超长停顿 (3秒以上)
用于章节切换、重大事件间隔：

```
第三章 神秘的来客。(breath)<#3.5#>
那是一个风雨交加的夜晚...
```

## 停顿位置规则

### ✅ 正确位置

1. **句号/问号/感叹号之后**
   ```
   这是第一句。<#1.5#>这是第二句。
   ```

2. **逗号分隔的独立短语之后**
   ```
   主要原因有三个，<#0.5#>第一，<#0.5#>第二，<#0.5#>第三。
   ```

3. **段落之间**
   ```
   第一段内容结束。<#2#>
   第二段内容开始。
   ```

4. **引出重要信息之前**
   ```
   答案就是<#1#>
   42！
   ```

### ❌ 错误位置

1. **不可连续使用多个停顿**
   ```
   错误：<#1#><#1#><#1#>
   ```

2. **不可放在句首（无前文）**
   ```
   错误：<#1#>你好，我是小明。
   ```

3. **不可放在句尾（无后文）**
   ```
   错误：你好，我是小明。<#1#>
   正确：你好，我是小明。(breath)
   ```

```

```

```
在一个遥远的王国里。<#2#>
```


## 停顿时长与情感的对应

| 情感/场景 | 推荐时长 | 示例 |
|-----------|---------|------|
| 轻松对话 | 0.3-0.5s | 朋友聊天 |
| 正式讲解 | 0.5-1s | 教程、课程 |
| 叙事朗读 | 1-2s | 讲故事 |
| 诗歌朗诵 | 1.5-3s | 强调节奏 |
| 戏剧表演 | 2-4s | 戏剧化效果 |
| 悬念设置 | 2-5s | 制造期待 |
