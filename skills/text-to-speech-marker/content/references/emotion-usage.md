## 场景化使用示例

### 对话/访谈场景
```
大家好，欢迎来到今天的节目。(breath)
今天我们邀请到了一位特别的嘉宾。(breath)
让我们掌声欢迎！(laughs)

嘉宾：大家好，我是...
(breath)(emm)其实今天挺紧张的。
```

### 新闻播报场景
```
现在播报今天的头条新闻。(clear-throat)
据最新消息，...(breath)
这一事件引发了广泛关注。(gasps)
```

### 故事叙述场景
```
从前有座山。(breath)
山里有个庙...(chuckle)
(breath)
突然！(gasps)
```

### 教程/讲解场景
```
今天我们来学习一个新技能。(breath)

然后，找到这个选项。(emm)
对，就是这里。(humming)
```

```
(breath)
请问有什么可以帮助您的？(sniffs)
好的，我来帮您查询一下。(breath)
```

## 注意事项

1. **自然性**：语气词应该让语音更自然，不要过度使用
2. **匹配度**：语气词要与内容和情感匹配
3. **节奏感**：合理分布，给听众喘息空间
4. **避免滥用**：每100字建议不超过3-5个语气词
5. **位置选择**：通常放在句首或句尾，而非句中
