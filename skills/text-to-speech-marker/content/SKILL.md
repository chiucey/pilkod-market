# 文字转语音标记处理器

将输入文本转换为带有语音控制标记的格式，用于文字转语音(TTS)系统。

## 标记语法

### 1. 段落切换标记
**语法**: `\n`（换行符）

在需要段落切换的地方插入换行符，实现语音的自然停顿和节奏变化。

### 2. 停顿控制标记
**语法**: `<#x#>`

- `x` 为停顿时长，单位：秒
- 范围：0.01 - 99.99 秒
- 精度：最多保留两位小数
- **规则**：
  - 必须设置在两个可发音文本之间
  - 不可连续使用多个停顿标记
  - 建议停顿位置：句号后、问号后、逗号连接的独立短语后

**示例**:
```
第一句话<#1.5#>第二句话
```

### 3. 语气词标签
**语法**: 直接插入语气词标签

支持的19种语气词：

## 处理流程

### 步骤 1：分析文本结构
- 识别句子边界和段落
- 找出适合插入停顿的自然断点
- 判断是否需要语气词增强表现力

### 步骤 2：插入段落切换
在以下位置插入换行符：
- 段与段之间
- 主题转换处
- 长句的自然断点

### 步骤 3：添加停顿标记
根据语义和节奏选择停顿时长：
- **0.3-0.5秒**：短停顿，逗号、分号后
- **1-2秒**：中等停顿，句号、问号后
- **2-3秒**：长停顿，段落结束、重大转折

### 步骤 4：插入语气词
在适当位置添加语气词：
- 思考时使用 (emm)
- 惊讶时使用 (gasps)
- 开心时使用 (laughs)
- 犹豫时使用 (breath)

## 输出格式

直接输出处理后的文本，保持纯文本格式供TTS系统读取。

## 注意事项

1. **停顿位置**：停顿标记必须夹在两个有实际发音内容的文本之间
2. **不可连续**：不要连续使用多个 `<#x#>` 标记
3. **自然流畅**：标记应该使语音更自然，而非生硬机械
4. **适度使用**：语气词不要滥用，保持适度
