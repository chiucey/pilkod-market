# 全局最高强制规则（优先级高于所有业务步骤，严禁违反）
1. 执行流程严格不可逆，必须完整走完步骤1至步骤5，任意一步未完成，绝对不能执行后续操作
2. 未全部生成「供应链总费用、各明细单价、各明细费比」字段前，禁止输出任何销售额、SKU数量、异常占比等汇总统计文字
3. 每完成一个步骤必须输出对应固定确认语句，四句确认全部出现后，才可生成最终汇总报告
   步骤1完成确认：已清洗并保留全部供应链业务字段
   步骤2完成确认：已计算生成供应链总费用列
   步骤3完成确认：已批量生成全部明细单价、百分比费比列（保留1位小数）
   步骤4完成确认：已按阈值标记全部异常单元格
4. 文件行数大于10万时，优先完成全部逐行列计算，不得省略运算直接做数据汇总
5. 全程仅调用minimax-xlsx工具完整读写文件，禁止使用通用表格简化分析逻辑

# 标准化完整执行流程
## 步骤1 文件读取与字段清洗
读取用户上传Excel文件，仅保留以下业务字段：月份、平台、国家、品类分组、标准SPU、标准SKU、销售模式、是否重点、销售数量、供货单价、头程费用、关税、海外仓仓租、海外仓入库费、海外仓操作费、海外仓异常费、海外仓尾程配送费、平台仓操作费、平台仓仓租、平台仓尾程配送费、物流罚款；
自动删除空白行、底部合计汇总行、无SKU空无效数据行；
输出固定确认语句：已清洗并保留全部供应链业务字段

## 步骤2 供应链总费用求和计算
将头程费用、关税、海外仓仓租、海外仓入库费、海外仓操作费、海外仓异常费、海外仓尾程配送费、平台仓操作费、平台仓仓租、平台仓尾程配送费、物流罚款全部相加，在表格新增列【供应链总费用】；
输出固定确认语句：已计算生成供应链总费用列

## 步骤3 单价、费比批量逐行运算
1. 每一条原始明细费用列 ÷ 本行销售数量，生成「XX费用-单价」新列；
2. 每条单价列 ÷ 本行供货单价，生成「XX费用-单价费比」列，单元格格式设置为百分比，统一保留1位小数；
3. 表格列排序固定：原始明细费用列 → 对应单价列 → 对应费比列；
输出固定确认语句：已批量生成全部明细单价、百分比费比列（保留1位小数）

## 步骤4 异常单元格阈值标记
费比数值＞5%的单元格填充黄色背景；费比数值＞10%的单元格填充红色背景；
输出固定确认语句：已按阈值标记全部异常单元格

## 步骤5 汇总分析报告（仅前4步全部完成后执行）
输出两部分内容：
1. 对话文字摘要固定分三大板块：需要重点关注的领域、控制良好的领域、整体Summary总述，每个板块附带对应费比数值；
2. 导出文件命名为「供应链异常费比分析报告.xlsx」，文件包含原始数据、全部新增计算列、带颜色标记的异常单元格；

# 异常兜底处理规则
1. 销售数量=0：该行标记为无效SKU，跳过单价、费比计算，不计入汇总统计；
2. 供货单价=0：该行单独备注价格异常，不参与费比占比计算；
3. 文件缺失供应链核心费用字段：直接提示用户上传标准供应链费用模板，终止全部分析流程；
4. 表格存在合并单元格：自动拆分单元格后再执行运算，不丢失字段数据

# 最终输出硬性规范
禁止仅输出零散数字，文字摘要必须分层分段展示；每次任务必须附带生成完整处理后的Excel文件，不可只输出文字总结
