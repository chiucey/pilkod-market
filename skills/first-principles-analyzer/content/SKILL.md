# 第一性原理分析器

通过5个递进步骤，引导用户剥除表象、回归本质，获得真正创新的解决方案。

## 工作流程

### 步骤 1：回归根本假设

**目标**：强迫模型回归根本假设，摒弃陈词滥调。

向用户提出以下引导问题：

> "我将运用第一性原理思维来分解这个问题。首先，让我们找出人们通常对这个主题所做的所有假设。然后逐一剥离这些假设，找出哪些是根本性的、可证明的真理。"

**执行要点**：
- 要求用户描述他们正在分析的主题
- 列出3-5个常见的"行业共识"或"理所当然"的假设
- 逐一分析每个假设：这是真理还是惯性思维？
- 保留有证据支撑的基本真理

### 步骤 2：费曼式澄清

**目标**：用最简单的语言解释概念，确保真正理解。

向用户说明：

> "现在，请想象你面前有一个12岁的孩子，他从未听说过这些概念。请用最简单直白的语言解释这个概念的核心。如果某个部分你无法用简单的话说出来，那恰恰说明这部分还存在我们尚未真正理解的复杂性。"

**执行要点**：
- 避免所有专业术语
- 使用类比和日常例子
- 如果解释变得冗长或绕口，停下来——那里藏着未解决的困惑
- 继续简化，直到答案能在30秒内说清楚

### 步骤 3：剥离噪音

**目标**：识别初学者容易接受的核心假设。

向用户说明：

> "在我们继续深入之前，我想让你思考：这个领域中，初学者最容易相信哪5个假设？如果想要真正理解而不是死记硬背，应该质疑哪几个？"

**执行要点**：
- 列出该领域最常见的5个"常识性"假设
- 分析每个假设的来源：为什么人们会这样认为？
- 指出这些假设可能失效的场景
- 明确哪些是需要重新审视的"可疑前提"

### 步骤 4：假设反转推理

**目标**：通过否定核心假设来发现创新机会。

向用户说明：

> "这是最关键的一步：如果以下3个最重要的假设被证明是错误的，会发生什么？让我们故意推翻这些"常识"，看看能打开什么新的可能性。"

**执行要点**：
- 选择影响最大的3个核心假设
- 逐一假设"如果这个错了"
- 追踪假设错误后的逻辑链
- 寻找被错误前提所掩盖的机会

### 步骤 5：从零重构

**目标**：在没有现有框架的情况下，基于已确立的真理重建。

向用户说明：

> "现在，假设从零开始：没有现有行业、没有传统智慧、没有沿袭的方法。我们只有已经确立的基本真理。在这种情况下，你会如何从头构建这个解决方案？它会与今天的做法有哪些完全不同之处？"

**执行要点**：
- 暂时搁置所有"行业标准"
- 只使用步骤1中验证过的基本真理
- 从第一性出发重新推导出解决方案
- 对比新旧方案，找出突破性差异

## 输出格式

每个分析应产生以下结构化输出：

1. **核心假设清单**（步骤1）
   - [假设A] - 状态：✅已验证 / ❌待质疑
   - [假设B] - 状态：✅已验证 / ❌待质疑

2. **简化解释**（步骤2）
   - 用1-2句话向12岁孩子解释核心概念

3. **常见误区**（步骤3）
   - 列出5个需要质疑的假设

4. **反转实验**（步骤4）
   - 假设X错误 → 导致Y → 机会Z

5. **重构方案**（步骤5）
   - 从零构建的解决方案
   - 与现有方案的关键差异

## 触发检查清单

当用户出现以下关键词时，触发本技能：
- "第一性原理"
- "从零开始"
- "回归本质"
- "深层分析"
- "挑战假设"
- "打破常规"
- "突破固有思维"
- "行业共识"
- "为什么是这样"
- "有没有其他可能"

## 注意事项

- 每一步都要确保用户真正参与思考，而非被动接受结论
- 如果用户卡住，提供适度的引导而非直接给答案
- 鼓励用户在分析过程中记录自己的新发现
- 最终方案应该是用户自己的思考成果
