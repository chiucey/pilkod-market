## 主题与基调

### 主题

```
故事想要探讨的核心思想是什么？

例如：
- 真相与谎言的边界
- 牺牲与救赎
- 信任的代价
- 爱与失去
```

### 基调

```
故事的叙事氛围是什么？

例如：
- 黑暗压抑
- 阳光向上
- 悬疑紧张
- 轻松幽默
```

### 第二幕：对抗（第25-75%）

#### 上升行动（至中点）

```
主角遇到的前几个挑战：

【列出2-3个主要障碍或事件】
```

#### 中点转折

```
故事中间的关键转折：

【描述这个转折如何改变主角的认知或处境】
```

#### 逼近高潮（下半部分）

```
主角面对的更大挑战：

【描述情况如何变得更糟】
```

#### 危机时刻

```
主角面临的最大困境：

【描述主角最黑暗的时刻】
```


## 主要冲突

### 外部冲突

```
故事的主要外在矛盾是什么？

例如：
- 主角 vs 反派
- 主角 vs 环境
- 主角 vs 社会
```

### 内部冲突

```
主角的内在矛盾是什么？

例如：
- 理性 vs 情感
- 责任 vs 欲望
- 过去 vs 现在
```
