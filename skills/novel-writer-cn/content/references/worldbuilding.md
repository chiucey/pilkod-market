# 世界观构建指南

世界观是小说发生舞台的基础。一个好的世界观应该服务于故事，同时保持内在一致性。

---

## 世界观构建原则

### 核心原则

1. **服务故事**：只构建故事需要的内容
2. **内在一致**：规则之间不能矛盾
3. **展示而非讲述**：通过情节展现世界，而非直接说明
4. **留有空间**：为后续创作留有余地

### 服务故事

世界观的大小取决于故事需要：

- **短篇**：需要的世界观元素最少，可能只需要1-2个关键设定
- **中篇**：需要更完整的世界理解，但仍有侧重点
- **长篇**：需要系统性的世界观，但也要分主次

**构建原则：**
- 故事发生在哪里，世界观就详细到哪里
- 主角经历什么，就展现什么
- 不影响故事的元素可以留白

## 世界观构建层次

世界观可以从宏观到微观分为四层：

### 第一层：物理世界

物理世界是故事发生的舞台基础。

#### 地理环境

| 要素 | 说明 | 示例 |
|-----|------|------|
| 整体布局 | 世界的基本地理结构 | 大陆、海洋、岛屿、星球 |
| 气候带 | 不同区域的气候特征 | 热带、寒带、沙漠、绿洲 |
| 自然奇观 | 标志性的地理景观 | 禁地、圣山、古遗迹 |

**示例（奇幻）：**

```
阿尔特里亚大陆被「永墙」分为东西两域。

东域多山，终年积雪，有「冰原三雄」——苍岭、寒脊、冻瀑。
西域广袤，气候温和，最肥沃的「金穗平原」养育了帝国大半人口。
两域之间是「裂谷」，据说是千年前神战留下的伤痕。
```

**示例（科幻）：**

```
银河帝国分为核心区、边界区、蛮荒区。

核心区是高度发达的星系，行星改造率达到97%。
边界区是半开发地带，秩序混乱但机遇丰富。
蛮荒区是未探索区域，只有冒险者和亡命徒才会去。
```

#### 重要地点

每个重要地点都应该有：

- **外观**：物理形态
- **意义**：在故事中的作用
- **氛围**：给读者的感觉

**地点描写示例：**

```
铁脊关

外观：两山夹峙间的要塞，城墙由黑色铁岩砌成，嵌满历代战争的痕迹。

意义：东西域唯一的陆路通道，兵家必争之地。

氛围：厚重、压抑、死亡气息浓重。城墙上永远有洗不掉的血锈。
```

#### 时间规则

世界的时间规则影响故事节奏：

| 规则 | 说明 | 示例 |
|-----|------|------|
| 自然时间 | 日夜、季节、气候周期 | 永夜之地，极昼极夜 |
| 社会时间 | 历法、节日、纪念日 | 帝国历、英雄纪念日 |
| 特殊时间 | 影响故事的特殊时刻 | 魔力潮汐、星际风暴季 |

### 第二层：社会体系

社会体系展现人类（或类人社会）的组织方式。

#### 政治结构

| 要素 | 说明 |
|-----|------|
| 统治形式 | 王权、共和、联邦、神权等 |
| 权力核心 | 最高权力在哪里 |
| 行政体系 | 如何管理领土 |
| 地方自治 | 地方有多大自主权 |

**示例：**

```
二元制帝国

统治：皇帝（最高权力）+ 元老院（制衡）
行政区：行省制，省督由皇帝任命
地方：城市有自治权，但需缴纳贡金
特殊：教会独立于世俗权力，拥有自己的领地
```

#### 经济系统

| 要素 | 说明 |
|-----|------|
| 货币体系 | 货币类型、汇率、发行权 |
| 主要产业 | 什么支撑经济 |
| 阶级结构 | 社会分层 |
| 贸易网络 | 商品如何流通 |

**示例：**

```
帝国经济体系

货币：金本位，金币、银币、铜币三级
主要产业：农业（税收核心）、矿业（战略物资）、商业（新兴势力）
阶级：贵族（土地）、平民（劳动）、商人（金钱）、奴隶（无）
贸易：三大商路，东西、南北、海上，控制商路的家族权势滔天
```

#### 文化习俗

文化让世界更真实、更有质感。

| 要素 | 说明 | 示例 |
|-----|------|------|
| 信仰体系 | 宗教、神话、价值观 | 多神信仰，祖先崇拜 |
| 重要节日 | 社会性庆典 | 丰收节、建国日、成人礼 |
| 日常习俗 | 生活习惯、礼仪 | 见面礼、婚丧嫁娶 |
| 禁忌事项 | 文化红线 | 不可直呼神名、不可吃某种食物 |

**示例：**

```
阿尔特里亚文化

信仰：圣庭九神（创世、秩序、战争、死亡等各有司职）
节日：圣光节（新年）、丰收祭（秋收）、英灵日（纪念先烈）
习俗：
- 见面以右手抚心口行礼
- 丧葬需守灵七日
- 贵族子女成人需入圣庭学习一年
禁忌：
- 不可在神像前撒谎
- 不可食用龙类生物
- 不可在战场上投降
```

### 第三层：特殊系统

根据小说类型，需要设计不同的特殊系统。

#### 魔法体系（奇幻）

**核心问题：**

1. 魔力的来源是什么？
2. 如何施法？
3. 有什么限制和代价？
4. 不同派别/体系如何区分？

**魔力来源选项：**

| 来源 | 说明 |
|-----|------|
| 神灵 | 神灵赐予，需要信仰 |
| 自然 | 来自自然元素或生灵 |
| 修炼 | 个人修炼，积累力量 |
| 血脉 | 天生能力，遗传获得 |
| 物品 | 通过魔法物品施放 |

**施法方式选项：**

- 咒语/咏唱
- 手势/符文
- 道具/法器
- 意志/精神力

**代价设计：**

| 代价类型 | 说明 | 示例 |
|---------|------|------|
| 体力消耗 | 消耗身体能量 | 施法后极度疲惫 |
| 物质代价 | 消耗材料 | 需要宝石、草药 |
| 限制代价 | 使用时受限制 | 只能在特定时间/地点施法 |
| 长期代价 | 持续影响 | 每次施法都会消耗生命 |
| 随机代价 | 不可预测 | 可能产生副作用 |

**示例：**

```
阿尔特里亚魔法体系

魔力来源：大地脉轮——散布于六大山脉的能量节点

施法方式：
- 自然系：通过冥想与大地共鸣
- 元素系：咏唱咒语+手势引导
- 灵魂系：消耗自身精神力

代价：
- 施法需要消耗体力，普通法师一天最多施法三次
- 高阶魔法需要特殊材料（宝石、灵药）
- 灵魂系魔法会留下「灵魂伤痕」，不可逆转
- 在脉轮匮乏地区（如城市中心）施法效果减半

派别：
- 自然系（绿盟）：亲近自然，注重平衡
- 元素系（火塔）：追求力量，注重破坏
- 灵魂系（幽冥会）：研究生死，注重隐秘
- 禁忌系（已灭绝）：据说可以操控命运，但被圣庭封禁
```

#### 科技设定（科幻）

**核心问题：**

1. 科技的原理是什么？
2. 科技发展到什么程度？
3. 科技的限制是什么？
4. 科技如何影响社会？

**科技设定要素：**

| 要素 | 说明 | 示例 |
|-----|------|------|
| 核心科技 | 故事核心的科技 | 超光速引擎、量子计算 |
| 应用领域 | 科技在哪里应用 | 交通、医疗、军事 |
| 限制条件 | 科技的局限 | 需要稀有材料、稳定性问题 |
| 社会影响 | 科技如何改变生活 | 贫富分化、伦理争议 |

**示例：**

```
银河帝国科技设定

核心科技：
- 超光速航行：实现星系间旅行，但需要「星门」作为跳点
- 量子通讯：实现即时通讯，但存在被拦截风险
- 人工智能：广泛使用，但存在「觉醒」问题

科技水平：
- 核心区：高度发达，全自动化
- 边界区：中等水平，人类与机器协作
- 蛮荒区：落后，依靠传统方式

限制：
- 超光速引擎需要「恒星石」，产量有限
- AI受到严格监管，「三定律」植入所有型号
- 基因改造有伦理争议，法律限制严格

社会影响：
- 自动化导致大量失业，贫富差距加剧
- AI管家普及，「人机关系」成为新话题
- 星际殖民引发「原住民」权益问题
```

#### 武功系统（武侠）

**核心问题：**

1. 武功的体系是什么？
2. 如何修炼武功？
3. 各派别如何区分？
4. 武功如何影响江湖格局？

**武功设定要素：**

| 要素 | 说明 | 示例 |
|-----|------|------|
| 境界体系 | 武功的层次划分 | 初境、通脉、化境、宗师 |
| 主要流派 | 江湖主要门派 | 武当、少林、明教 |
| 传承方式 | 武功如何传递 | 师徒、血脉、秘籍 |
| 关键物品 | 与武功相关的道具 | 宝剑、秘籍、丹药 |

**示例：**

```
武林格局

境界体系：
- 入门：练习基础，强身健体
- 初窥：初窥门径，可练招式
- 通脉：打通经脉，内力运行
- 化境：内功化形，招式随心
- 宗师：一代宗师，开宗立派

主要流派：
- 武当派：以内功见长，道法自然
- 少林寺：以硬功著称，禅武合一
- 明教：行事诡秘，武功诡变
- 丐帮：人数众多，打狗阵法
- 移花宫：唯我独尊，邀月怜星

传承：
- 核心武功只传嫡传弟子
- 普通武功可广泛传授
- 部分绝学刻于山壁，等待有缘人
```

### 第四层：历史背景

历史为世界增加深度和厚度。

#### 重要历史事件

每个世界都应该有塑造当前的关键事件：

| 要素 | 说明 | 示例 |
|-----|------|------|
| 时间 | 事件发生在何时 | 500年前 |
| 主角 | 事件的核心人物 | 英雄、帝王、叛徒 |
| 经过 | 发生了什么 | 大战、革命、天灾 |
| 结果 | 造成了什么影响 | 帝国建立、制度改变 |

**示例：**

```
魔灾纪元

时间：500年前

事件：「魔灾」降临，恶魔从裂隙中涌入

经过：
- 恶魔入侵，生灵涂炭
- 人类联合抵抗，付出惨痛代价
- 英雄「圣光」牺牲自己封印裂隙

影响：
- 帝国从此建立，纪念英雄
- 圣庭成立，守护封印
- 「恶魔」成为禁忌词汇
```

#### 传说与神话

传说为世界增加神秘感：

- 起源神话：世界如何诞生
- 英雄传说：传奇人物的故事
- 预言禁忌：关于未来的预言或禁忌

**示例：**

```
阿尔特里亚传说

起源：创世神「太一」创造世界，分化九神各司其职

英雄传说：
- 「圣光」的故事：为了封印恶魔而牺牲自己
- 「先知」的故事：在魔灾前预言了灾难却无人相信
- 「叛徒」的故事：为了爱情背叛人类投靠恶魔

预言：
- 「当裂隙再开之时，真龙将归来」——这句话让所有人对「龙」字讳莫如深
- 「最终审判」——圣庭预言的末日景象
```

#### 隐藏秘密

为故事埋下伏笔：

- 未解之谜：历史上没有答案的问题
- 阴谋论：某些势力隐藏的真相
- 伏笔：与主线相关的隐藏信息

**示例：**

```
未解之谜

1. 魔灾真的结束了吗？
   - 圣庭坚称恶魔已被封印
   - 但每年都有人声称看到「异象」
   - 有人说封印在逐渐弱化

2. 「圣光」真的牺牲了吗？
   - 官方记载圣光与恶魔同归于尽
   - 但有人声称看到圣光在最后一刻微笑
   - 圣庭对任何关于圣光「未死」的传言都严厉镇压

3. 「叛徒」的真正动机
   - 传说叛徒是为了爱情背叛人类
   - 但有人在古籍中发现一段残缺的记录
   - 暗示叛徒可能是在执行某个更古老的计划
```

## 世界观构建流程

### 步骤一：确定核心设定

从故事需求出发，确定1-3个核心世界观设定：

```
问题：
1. 这个故事最独特的世界元素是什么？
2. 这个元素如何影响主角的选择？
3. 这个元素如何制造冲突？

示例：
故事：一群人在末日废墟中寻找传说中的「绿洲」

核心设定：
1. 「绿洲」的存在——末日中人类最后的希望
2. 「绿洲」的秘密——有人知道它是陷阱但仍在引导人们
3. 「绿洲」的代价——到达的人必须做出选择
```

### 步骤二：构建基本框架

快速构建世界的骨架：

- 地理：故事发生在哪里
- 社会：谁在统治、如何运作
- 特殊系统：故事需要的独特设定

### 步骤三：填充细节

根据需要，添加：

- 文化细节让世界更真实
- 历史背景增加深度
- 隐藏设定为伏笔服务

### 步骤四：检查一致性

检查世界观是否有矛盾：

- 规则是否自洽
- 设定是否与情节相符
- 是否为故事服务

## 世界观输出格式

以下是完整的世界观设定文档格式：

```markdown
# [世界/国家/地区名称] 世界观设定

## 物理世界
### 地理环境
[描述地理结构]

### 重要地点
- [地点名]：[描述]

### 时间规则
[描述时间体系]

## 社会体系
### 政治结构
[描述政治体制]

### 经济系统
[描述经济形态]

### 文化习俗
- 信仰：[描述信仰体系]
- 节日：[列出重要节日]
- 禁忌：[描述文化禁忌]

## 特殊系统
### [系统名称，如魔法/科技/武功]
- 来源：[魔力/科技/内力的来源]
- 施法方式：[如何施放]
- 限制与代价：[限制条件和代价]
- 派别/分支：[不同体系]

## 历史背景
### 重要事件
- [事件名]：[描述]

### 传说神话
- [传说名]：[描述]

## 隐藏设定
- [秘密名]：[描述]
```

## 世界观自检清单

完成世界观设定后，检查：

- [ ] 核心设定是否清晰且服务于故事？
- [ ] 物理世界是否完整且合理？
- [ ] 社会体系是否自洽且有趣？
- [ ] 特殊系统是否有明确规则？
- [ ] 历史背景是否为世界增加深度？
- [ ] 是否为故事留下了伏笔空间？
- [ ] 世界观是否保持内在一致性？
- [ ] 是否有未解释的空白需要补充？
