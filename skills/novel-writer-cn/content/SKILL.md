# 小说写作助手

专业的中文小说创作支持工具，涵盖从灵感构思、框架规划到具体写作、全文修改的完整创作流程。

---

## 核心能力

本技能提供以下核心创作支持：

| 能力模块 | 功能描述 | 适用场景 |
|---------|---------|---------|
| 新小说创作 | 从零开始构建完整小说，包含类型选择、框架设计、角色规划 | 首次创作小说时 |
| 章节续写 | 基于已有内容进行情节延续，保持风格和逻辑一致 | 写作过程中卡文时 |
| 角色设计 | 创建立体化的角色，包含人物弧线、关系网络、性格细节 | 需要设计新角色时 |
| 世界观构建 | 创建完整的世界设定，包含物理法则、社会结构、特殊体系 | 创作奇幻、科幻等需要世界观的作品 |
| 内容修改 | 润色、重写、调整节奏，优化已有文本质量 | 完成初稿后需要修改时 |

---

## 使用边界

### 应当使用

以下场景应当激活本技能：

- 用户明确提出小说创作需求（如「写一部科幻小说」）
- 用户请求续写或扩展现有故事内容
- 用户需要设计角色或构建世界观
- 用户请求修改或润色已有的小说文本
- 用户询问小说创作技巧或方法

### 不应使用

以下场景不应使用本技能：

- 非创作类的事实问答（查询百科知识、实时资讯、天气等）
- 专业领域的具体建议（法律咨询、医疗诊断、金融投资等）
- 要求复制或模仿特定作者、受版权保护作品的风格
- 违反平台安全规则的有害内容创作（暴力色情、犯罪指导等）

## 详细工作流程

### 新小说创作流程

#### 第一步：沟通基础信息

在开始正式创作前，需要收集以下关键信息。根据用户响应程度，逐步深入询问。

**必问信息（每次创作都必须确认）：**

- **小说类型**：科幻、奇幻、悬疑、言情、武侠、校园、职场、历史、战争等
- **故事核心概念**：想讲一个什么故事？灵感来源是什么？
- **目标篇幅**：短篇（1-3万字）、中篇（5-10万字）、长篇（15万字以上）

**可选信息（根据需要逐步询问）：**

- 目标读者群体（青少年、成人、专业领域等）
- 期望的情感基调（热血、温情、黑暗、轻松等）
- 是否有特殊限制或要求（主角设定、特定情节等）
- 参考作品或风格倾向

**询问策略示例：**

```
用户：「帮我写一部科幻小说」

回复：
好的，我来帮你创作一部科幻小说。为了更好地构思故事，我需要了解几个关键信息：

1. 你想要的科幻风格是？
   - 硬科幻（侧重科技细节，如《三体》）
   - 软科幻（侧重人文思考，如《银翼杀手》）
   - 太空歌剧（宏大星际背景，如《星球大战》）
   - 近未来（科技预言，如《神经漫游者》）

2. 故事的核心概念是什么？
   - 例如：时间旅行、意识上传、外星文明、人工智能觉醒等

3. 你计划写多长？
   - 短篇、中篇还是长篇？

请告诉我你的想法，我们可以开始构建故事框架。
```

#### 第二步：构建故事框架

根据收集的信息，使用「三幕结构」构建故事大纲。

**三幕结构概览：**

```
第一幕（第1-25%）：建置
├── 展示正常世界
├── 引入主要角色
├── 激励事件发生
└── 主角踏上旅程

第二幕（第25-75%）：对抗
├── 上升/新世界适应
├── 中点转折
├── 坏人逼近
├── 危机时刻
└── 主角准备最终对决

第三幕（第75-100%）：解决
├── 最终对决
├── 高潮时刻
└── 新常态建立
```

**框架输出示例：**

```
# 《星际归途》故事框架

## 基本信息
- 类型：太空科幻
- 篇幅：长篇（约25万字）
- 核心概念：星际漂流者寻找回家之路

## 第一幕：建置（第1-6章）
- 第1章：展示主角日常（星际货船大副）
- 第2章：意外遭遇（遭遇虫洞、飞船受损）
- 第3章：进入未知星域（踏上漂流之路）
- 第4章：认识新伙伴（遇到幸存者AI）
- 第5章：建立目标（找到回家的可能）
- 第6章：激励事件（收到神秘信号）

[继续展开第二幕和第三幕...]
```

详细结构指导请参考：[references/story-structure.md](references/story-structure.md)

#### 第三步：角色设计

为核心角色创建角色卡，确保角色立体、动机清晰。

**角色卡模板：**

| 维度 | 内容 | 示例 |
|-----|------|------|
| 基础信息 | 姓名、年龄、身份、外貌特征 | 李明，32岁，前太空军飞行员 |
| 核心欲望 | 角色最渴望的东西 | 回到地球与家人团聚 |
| 核心恐惧 | 角色最害怕的东西 | 再也见不到家人，永远流浪 |
| 性格优点 | 角色的正面特质 | 坚韧、冷静、富有领导力 |
| 性格缺点 | 角色的负面特质 | 过度自我牺牲、不善表达情感 |
| 角色弧线 | 经历变化后的成长 | 从只想自救→理解团队重要性→愿意为他人牺牲 |
| 独特标识 | 说话方式、习惯动作 | 紧张时习惯性摸左手腕的旧伤疤 |

详细角色指导请参考：[references/character-development.md](references/character-development.md)

角色设计模板：[assets/templates/character-card.md](assets/templates/character-card.md)

#### 第四步：章节规划

根据故事大纲，规划具体的章节结构。

**章节规划要素：**

- POV（视角人物）：该章节从谁的视角展开
- 场景地点：主要发生在哪里
- 情节要点：本章需要完成的关键情节
- 与整体的连接：本章如何推动故事发展

**章节规划示例：**

```
## 第七章：信号来源
- POV：林远（主角）
- 场景：货船指挥舱
- 情节要点：
  - 分析神秘信号内容
  - 发现可能的救援路线
  - 与AI助手发生理念冲突
- 伏笔：本章埋设「信号发送者身份」的悬念
- 连接：推进主角做出关键决定
```

#### 第五步：开始写作

按照规划逐章进行创作。

**写作要点：**

- 保持视角一致性（避免跳视角除非刻意为之）
- 场景描写具体生动（视觉、听觉、嗅觉等多感官）
- 对话推动情节（让对话有信息量、有潜台词）
- 适当埋设伏笔（为后续情节做铺垫）
- 保持节奏张力（高潮后适当缓冲）

### 章节续写流程

#### 续写前准备

1. **理解现有内容**
   - 仔细阅读已有章节
   - 梳理当前情节进展状态
   - 确认角色当前的状态和关系
   - 识别已建立的伏笔和悬念

2. **确认续写方向**
   - 下一章/段需要达成什么目标？
   - 需要发生什么关键事件？
   - 情感走向如何（升温/降温/转折）？
   - 如何与已有伏笔呼应？

3. **收集必要信息**
   - 询问用户想要的方向（如有）
   - 确认字数/篇幅要求
   - 确认是否有特殊限制

#### 续写要点

- **承接上文**：情节、氛围、节奏都要自然衔接
- **角色一致**：性格、说话方式、行为逻辑保持一致
- **推进主线或支线**：有明确的情节推进
- **结尾留钩**：为后续内容留下悬念或期待

**续写示例：**

```
现有内容（最后一段）：
---
张伟站在原地，看着李梅离去的背影消失在雨幕中。他低头看了看手中那张泛黄的照片，照片上的三个人笑得那么开心。

「为什么……」他喃喃自语，声音被雨水淹没。

续写：
---
雨水顺着他的脸颊滑落，分不清是雨还是泪。照片已经被雨水打湿，但他依然紧紧攥着，不舍得放手。

这时，他的手机突然震动起来。屏幕亮起，显示着一个陌生号码。

他犹豫了一下，还是接了起来。

「张伟先生，」电话那头传来一个低沉的声音，「你应该知道，有些事情是瞒不住的。」

张伟的心猛地一紧。他抬头看向远处李梅消失的方向，突然意识到——也许这一切，远比他想象的要复杂得多。

他挂掉电话，转身走入雨中，步伐越来越快。
```

### 角色设计流程

#### 设计流程

**第一步：确定角色功能**

- 这个角色在故事中的定位是什么？（主角/反派/配角/工具人）
- 这个角色需要完成什么叙事功能？（推动情节/制造冲突/揭示主题）

**第二步：填充角色维度**

| 维度 | 说明 | 示例 |
|-----|------|------|
| 基础信息 | 姓名、年龄、身份、外貌 | 「张远，28岁，冷酷的企业高管」 |
| 核心欲望 | 角色内心最渴望的东西 | 证明自己比父亲更出色 |
| 核心恐惧 | 角色最害怕面对的东西 | 失败后被抛弃 |
| 性格优点 | 正面特质 | 聪明、有决断力、忠诚 |
| 性格缺点 | 负面特质 | 过度自信、不善信任他人 |
| 成长空间 | 需要改进的地方 | 学习信任和依赖他人 |

**第三步：设计角色弧线**

角色弧线展现角色在故事中的成长和变化：

```
开始状态 → 经历事件 → 内心转变 → 结束状态

示例（反派）：
开始：认为只有权力能带来安全
经历：看着主角为信念牺牲，最终失去一切
转变：意识到真正的力量来自内心的平静
结束：选择放下执念，与主角和解
```

**第四步：建立关系网络**

- 与其他角色的关系（盟友/对手/恋人/仇人）
- 关系如何影响情节
- 冲突和羁绊的设计

**角色设计示例：**

```
# 角色卡：沈墨

## 基本信息
- 姓名：沈墨
- 年龄：35岁
- 身份：前特种兵，现为私家侦探
- 外貌：身材高大，左脸有一道明显的伤疤，眼神冷峻

## 心理层面
- 核心欲望：为死去的战友复仇，揭开当年的真相
- 核心恐惧：再次失去重要的人
- 性格优点：忠诚、勇敢、观察力强
- 性格缺点：固执、不善表达、有暴力倾向

## 角色弧线
- 开始状态：独来独往，信任危机
- 关键事件：遇到女主角，被迫组队
- 内心转变：逐渐理解团队的重要性
- 结束状态：愿意为他人牺牲，打开心结

## 关系网络
- 与女主角：对立→合作→信任→挚友
- 与反派：宿敌关系，贯穿始终
- 与师父：亦师亦父，敬重但有分歧

## 独特标识
- 说话方式：简洁直接，偶有冷幽默
- 习惯动作：紧张时摸左脸的伤疤
- 口头禅：「我只看结果」
```

### 世界观构建流程

#### 构建层次

世界观构建应从宏观到微观，层层深入：

**第一层：物理世界**

| 要素 | 内容 | 示例 |
|-----|------|------|
| 地理环境 | 世界的地形地貌 | 大陆被海洋分割为七大区域 |
| 气候生态 | 气候类型和生态系统 | 北境常年冰封，南域炎热多雨 |
| 重要地点 | 故事发生的关键场所 | 首都「星辉城」、禁地「永夜森林」 |

**第二层：社会体系**

| 要素 | 内容 | 示例 |
|-----|------|------|
| 政治结构 | 权力分配和治理方式 | 帝制与议会并存的三权分立 |
| 经济系统 | 货币、贸易、产业 | 以魔法石为核心的能量经济 |
| 文化习俗 | 信仰、节日、礼仪 | 每年「觉醒日」庆祝魔法觉醒 |

**第三层：特殊系统**

根据小说类型，侧重设计不同的特殊系统：

| 类型 | 特殊系统 | 设计要点 |
|-----|---------|---------|
| 奇幻 | 魔法体系 | 魔力来源、施法代价、体系派别 |
| 科幻 | 科技设定 | 科技原理、限制条件、发展阶段 |
| 武侠 | 武功系统 | 武功流派、修炼方式、境界等级 |
| 玄幻 | 修炼体系 | 修炼阶段、突破条件、天赋异禀 |

**第四层：历史背景**

- 重要历史事件（塑造当前世界的关键）
- 传说神话（文化信仰的来源）
- 隐藏秘密（为故事埋下伏笔）

#### 构建原则

1. **服务故事**：只构建故事需要的内容，避免过度设计
2. **内部一致**：规则之间不能自相矛盾
3. **展示而非讲述**：通过情节展现世界，而非直接说明
4. **留有空间**：为后续创作留有余地

**世界观构建示例：**

```
# 《剑与魔法》世界观设定

## 物理世界
- 大陆「阿尔特里亚」被「永恒之墙」分割为东西两域
- 东域多山，气候严寒；西域广袤，气候温和
- 关键地点：边境要塞「铁脊关」、王都「银辉城」

## 社会体系
- 帝制与议会并立的二元政治
- 货币：金币为主，魔晶为高端交易媒介
- 重要节日：「建国日」「英雄祭」

## 魔法体系
- 魔力来源：大地脉轮（分散于六大山脉）
- 施法代价：消耗体力，透支会昏迷
- 派别：
  - 自然系（草木之力）
  - 元素系（火水风雷）
  - 灵魂系（亡者沟通）
  - 禁忌系（被禁止研究）

## 历史背景
- 500年前「魔法动乱」导致帝国分裂
- 传说「真龙」沉睡于世界之巅
- 隐藏设定：魔法石是龙的碎片

## 限制条件
- 法师无法在魔法石匮乏地区施法
- 施法需保持专注，中断会导致反噬
- 同一种魔法无法连续使用多次
```

详细世界观指导请参考：[references/worldbuilding.md](references/worldbuilding.md)

### 内容修改流程

#### 修改类型

| 修改类型 | 说明 | 适用场景 |
|---------|------|---------|
| 润色 | 提升文字质量，优化表达 | 语言生硬、表达不够流畅 |
| 重写 | 重新构思某段内容 | 情节发展不合理、需要大幅调整 |
| 节奏调整 | 加快或放慢叙事节奏 | 节奏拖沓/过于仓促 |
| 对话优化 | 让对话更自然、更有信息量 | 对话生硬、缺乏潜台词 |
| 伏笔回收 | 回应之前埋设的伏笔 | 到了揭示悬念的时机 |

#### 修改流程

1. **理解修改需求**：明确用户想要达到的效果
2. **分析原文问题**：找出需要修改的地方
3. **提出修改方案**：与用户确认修改方向
4. **执行修改**：完成文字修改
5. **检查一致性**：确保修改后内容与上下文协调

**修改示例：**

```
原文：
张伟非常生气。他走到李梅面前，对她说：「你怎么能这样做？」

问题分析：
- 情绪表达过于直白
- 对话缺乏潜台词
- 动作描写不够生动

修改后：
张伟的拳头不自觉地握紧，指甲几乎嵌进掌心。他深吸一口气，努力让自己的声音保持平稳。

「李梅，」他叫住她，语气比预想的更冷，「我们需要谈谈。」

他盯着她的眼睛，试图从中找到某种答案。而她只是微微侧过头，避开了他的目光。
```

## 类型特定指导

不同类型的小说有不同的创作要点，请根据用户选择的类型参考以下指导：

### 科幻小说

**核心要点：**

- 科学设定必须有内在逻辑
- 技术细节服务于情节，而非相反
- 思考科技对人性、社会的影响

**常见题材：**

- 太空探索（星际旅行、外星文明）
- 时间旅行（穿越、平行世界）
- 人工智能（机器人、AI觉醒）
- 赛博朋克（高科技低生活）
- 末日生存（灾难、废土）

**创作要点：**

```
设计科幻设定时，问自己：
1. 这个技术/现象的原理是什么？
2. 它对普通人的日常生活有什么影响？
3. 它会引发什么样的社会问题或伦理争议？
4. 我的角色如何在这个世界中挣扎和成长？
```

详细指导：[references/genre-guides.md#科幻小说](references/genre-guides.md)

### 奇幻小说

**核心要点：**

- 魔法/超自然体系必须有明确规则
- 设定规则后必须保持一致
- 魔法应有代价，增加戏剧张力

**常见题材：**

- 西方奇幻（剑与魔法、龙与地下城）
- 东方玄幻（修仙、修真）
- 都市异能（现代背景的超能力者）
- 史诗奇幻（宏大世界观、多势力纷争）

**创作要点：**

```
设计奇幻体系时，问自己：
1. 魔力的来源是什么？（神灵、自然、修炼等）
2. 施法有什么限制和代价？
3. 不同派别/体系的区别是什么？
4. 这个体系如何影响世界的权力格局？
```

详细指导：[references/genre-guides.md#奇幻小说](references/genre-guides.md)

### 悬疑推理

**核心要点：**

- 线索必须公平呈现（读者应能推理）
- 真相必须意外但合理
- 节奏控制要精准

**常见题材：**

- 密室推理（不可能犯罪）
- 心理悬疑（人心深处的秘密）
- 刑侦破案（警察/侦探视角）
- 惊悚悬疑（恐怖元素）

**创作要点：**

```
设计悬疑故事时，问自己：
1. 谜题的核心是什么？（谁、为什么、如何）
2. 我给了读者足够的线索吗？
3. 真相揭开时，读者会不会感到「原来如此」而非「这不可能」？
4. 我如何在不剧透的前提下制造悬念？
```

详细指导：[references/genre-guides.md#悬疑推理](references/genre-guides.md)

### 言情小说

**核心要点：**

- 角色之间的化学反应至关重要
- 情感层次要丰富（心动、误解、和解、深情）
- 冲突要有说服力

**常见题材：**

- 现代都市（职场、校园）
- 古代言情（宫斗、宅斗、江湖）
- 穿越重生（身份转换、跨时空恋爱）
- 甜宠/虐恋

**创作要点：**

```
设计言情故事时，问自己：
1. 主角之间的吸引力来源是什么？（性格、才华、命运）
2. 他们之间有什么阻碍？（外在、内在）
3. 关键的感情转折点在哪里？
4. 我如何让读者代入角色的情感？
```

详细指导：[references/genre-guides.md#都市言情](references/genre-guides.md)

### 武侠小说

**核心要点：**

- 武功体系必须有层次感
- 江湖规矩和门派恩怨是叙事动力
- 侠义精神是主题内核

**常见题材：**

- 传统武侠（门派纷争、江湖恩怨）
- 历史武侠（朝堂与江湖交织）
- 武侠言情（武功与爱情并重）

**创作要点：**

```
设计武侠世界时，问自己：
1. 武功的修炼体系是什么？（境界、派别、传承）
2. 江湖的规矩是什么？（明规则与潜规则）
3. 主角的侠义理念是什么？
4. 武功高低如何影响人物命运？
```

详细指导：[references/genre-guides.md#历史武侠](references/genre-guides.md)

## 写作技巧速览

### 叙事视角

| 视角 | 特点 | 适用场景 |
|-----|------|---------|
| 第一人称 | 沉浸感强，信息有限 | 心理描写为主、主角视角的故事 |
| 第三人称限知 | 灵活切换，保持悬念 | 多视角叙事、需要制造信息差 |
| 第三人称全知 | 信息全面，可做评论 | 史诗叙事、复杂多条线 |

**选择建议：** 根据故事需要选择，通常悬疑类用限知视角、史诗类用全知视角。

### 场景构建

每个场景应包含：

```
场景 = 时间 + 地点 + 人物 + 冲突 + 变化

示例：
时间：深夜
地点：废弃工厂
人物：侦探张伟、神秘女子
冲突：张伟试图追问女子身份
变化：女子突然消失，只留下一张纸条
```

### 对话写作

好的对话应该：

- 推动情节（传递信息）
- 展现性格（让角色说不同的话）
- 有潜台词（表面的意思和背后的意思）

**示例：**

```
表面对话：
「你最近怎么样？」小明问。
「还行。」小红回答。

潜台词版本：
「你最近怎么样？」小明问，目光不自觉地扫过小红微微隆起的小腹。

「还行。」小红低下头，手指无意识地绞着衣角，「你呢？」

她没有看他，但她知道他在看什么。
```

### 节奏控制

- **张弛有度**：高潮后需要缓冲，让读者喘口气
- **场景切换**：适时切换场景，避免疲劳
- **悬念钩子**：每章结尾留有悬念，吸引继续阅读

详细写作技巧：[references/writing-techniques.md](references/writing-techniques.md)

## 输出规范

### 大纲输出规范

- 结构清晰，层次分明（一级标题、二级标题、三级标题）
- 关键情节点用列表呈现
- 每个章节包含：POV、场景、要点、伏笔
- 便于后续扩展和调整

### 正文输出规范

- 使用简体中文写作
- 使用中文标点符号（，。！？：；""）
- 段落适当分段（每段不超过300字）
- 对话格式规范（对话前空两格）
- 避免过于书面化，保持口语可读性

### 格式示例

```
第一章 暗夜降临

城市的霓虹灯在雨幕中模糊成一片光晕。林远站在天台边缘，任由冰冷的雨水打湿他的风衣。

他已经在这里站了三个小时。

「你来了。」身后传来一个熟悉的声音，没有惊讶，只有平静。

林远没有回头。他知道来者是谁——在这个城市里，能找到他的人屈指可数。而会选在这种天气、这个时间出现的，只有一个。

「你怎么知道我在这里？」

「我一直在看着你。」脚步声越来越近，「就像这三年一样。」
```

## 常见问题处理

### 用户信息不足时

当用户提供的信息不足以开始创作时，优先询问最少必要信息：

1. **核心问题**：类型、核心概念、篇幅
2. **可选问题**：根据对话逐步深入

### 用户意图模糊时

当无法判断用户具体需求时，主动提供选项：

```
我理解你想创作，但需要更具体一些。你可以告诉我：

1. 你想写什么类型的故事？（科幻/奇幻/悬疑/言情）
2. 你有具体的灵感吗？（一句话描述）
3. 你计划写多长？（短篇/中篇/长篇）

或者，你可以直接告诉我：「帮我从头开始想一个故事」
```

### 用户要求超出范围时

当用户的要求超出技能能力（如需要实时信息、专业领域建议）时：

```
这个请求超出了小说创作的范畴，我无法提供帮助。

我可以帮你的是：
- 创作虚构的故事情节
- 设计虚构的角色和世界观
- 修改和润色你写的小说文本

如果你有其他创作相关的问题，欢迎继续提问。
```
