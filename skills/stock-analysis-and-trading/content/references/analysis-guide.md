# 股票分析与交易策略参考文档

## 1. 基本面分析框架

### 1.1 估值指标

| 指标 | 计算公式 | 解读标准 |
|------|----------|----------|
| PE (市盈率) | 股价 / 每股收益 | 低于行业平均为低估，高于30需谨慎 |
| PB (市净率) | 股价 / 每股净资产 | 低于1可能是价值陷阱 |
| PS (市销率) | 股价 / 每股销售额 | 适合成长股评估 |
| EV/EBITDA | 企业价值/息税折旧前利润 | 用于跨行业比较 |

### 1.2 盈利能力指标

- **ROE (净资产收益率)**：>15% 为优质，<8% 需警惕
- **毛利率**：稳定或上升为佳，下降需分析原因
- **净利率**：>10% 为良好水平
- **扣非净利润**：排除一次性收益的真实盈利

### 1.3 成长性指标

- **营收增速**：>20% 为高成长
- **利润增速**：与营收增速匹配为健康
- **季度环比**：连续增长表明加速成长

## 2. 技术分析要点

### 2.1 支撑位与压力位

- **支撑位**：前期低点、均线密集区、成交密集区
- **压力位**：前期高点、均线压制位、历史套牢区

### 2.2 趋势判断

- **上升趋势**：高点高于前高，低点高于前低
- **下降趋势**：高点低于前高，低点低于前低
- **震荡趋势**：高低点无明显方向

### 2.3 关键均线

| 周期 | 应用场景 |
|------|----------|
| 5日均线 | 超短期趋势，快速波动 |
| 20日均线 | 短期趋势，短线操作参考 |
| 60日均线 | 中期趋势，牛熊分界线 |
| 120日均线 | 中长期趋势，长线布局参考 |
| 250日均线 | 长期趋势，年线级别判断 |

## 3. 仓位管理原则

### 3.1 建仓节奏

```
计划仓位    首次建仓    二次加仓    三次加仓
10%        3%         3%         4%
20%        7%         7%         6%
30%        10%        10%        10%
```

### 3.2 止损原则

- **固定止损**：亏损 7-10% 必须止损
- **移动止损**：盈利超过 15% 后，将止损提高到成本价
- **时间止损**：持有超过预期时间未启动，需重新评估

## 4. 风险管理清单

### 4.1 买入前检查

- [ ] 是否在主要均线之上
- [ ] 是否有明显支撑位可设止损
- [ ] 仓位是否超过计划上限
- [ ] 整体持仓是否过于集中单一行业

### 4.2 持仓中监控

- [ ] 是否有跌破关键支撑位
- [ ] 公司基本面是否发生重大变化
- [ ] 行业是否有政策利空
- [ ] 大盘是否进入系统性下跌

### 4.3 卖出信号

- [ ] 达到预设止盈位
- [ ] 有效跌破止损位
- [ ] 基本面出现恶化信号
- [ ] 发现更好的投资机会需调仓

## 5. 常见陷阱规避

1. **追高**：股价远离均线不追，等待回调
2. **重仓单一**：单票不超过总仓位 20%
3. **不止损**：任何单笔亏损不超过总资产 2%
4. **频繁交易**：减少无效交易，降低摩擦成本
5. **情绪化操作**：制定计划，严格执行
