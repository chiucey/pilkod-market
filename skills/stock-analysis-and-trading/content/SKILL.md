# 股票分析与交易策略技能

## 核心原则

**趋势为王，忌追高。利用回调，分批布局。**

## 工作流程

### 1. 数据获取

当用户提供股票名称或代码时，首先调用以下工具获取数据：

```python
# 获取股票基本信息、财务数据、统计信息
stocks_info(symbol="股票代码")
stocks_financial_data(symbol="股票代码")
stocks_statistics(symbol="股票代码")
stocks_insights(symbol="股票代码")
```

### 2. 基本面分析

基于获取的数据，从以下维度分析：

- **公司概况**：行业地位、主营业务、市场份额
- **财务健康**：营收增长、利润率、负债率、现金流
- **估值水平**：PE、PB、PS 与行业平均对比
- **盈利能力**：ROE、毛利率、净利润增速
- **成长性**：营收增速、利润增速、市场扩张
- **风险因素**：商誉、存货、应收账款、行业周期

### 3. 四大场景操作建议

#### 场景 A：尚未持仓，想买入

| 项目 | 内容 |
|------|------|
| 操作策略 | 判断当前趋势方向，决定是否等待回调低吸 |
| 理想买入点 | 关键支撑位 + 回调到该位置时介入 |
| 止损点 | 有效跌破支撑位下方 3-5% |
| 操作说明 | 分批建仓，首次建仓不超过计划仓位的 1/3，逢低补仓 |

#### 场景 B：已持仓，且盈利

| 项目 | 内容 |
|------|------|
| 操作策略 | 设置移动止损，保护利润；分批止盈 |
| 关键价位 | 压力位附近考虑减仓 |
| 操作说明 | 盈利超过 15% 可考虑减半仓；超过 30% 考虑清仓 |

#### 场景 C：已持仓，但亏损

| 项目 | 内容 |
|------|------|
| 操作策略 | 分析亏损原因，判断是暂时回调还是趋势反转 |
| 关键价位 | 重要支撑位能否守住 |
| 操作说明 | 轻仓可持有等待反弹；重仓建议止损控制风险 |

#### 场景 D：已持仓，成本较高

| 项目 | 内容 |
|------|------|
| 操作策略 | 利用反弹减亏，等待更好位置补仓拉低成本 |
| 关键价位 | 成本价附近的压力位 |
| 操作说明 | 切勿低位割肉，可考虑高抛低吸降低成本 |

### 4. 风险提示

必须包含以下风险提示内容：

1. **市场风险**：宏观经济、行业周期、政策变化
2. **流动性风险**：小市值股票可能面临流动性不足
3. **估值风险**：高估值股票回调风险大
4. **操作风险**：追高、满仓、不设止损
5. **分散风险**：建议单只股票仓位不超过总资产的 20%

### 5. 观点输出

在分析结尾，提供客观、有据可查的投资观点，涵盖：

- 当前市场情绪判断
- 短期和中长期趋势展望
- 主要风险点和机会点
