## 积分流动

```
每日免费积分 ──┬──→ 可用积分 ──→ 消耗
              │
底线积分 ←────┘
```

## 任务状态流转

```
用户启动
    │
    ▼
[检查积分] ──不足──→ [暂停] ──用户确认──→ [继续]
    │
   充足
    │
    ▼
[查找未完成任务]
    │
    ├── 有 → [恢复任务]
    │
    └── 无 → [新建任务]
                │
                ▼
           [执行工作流程]
                │
           每步检查积分
                │
                ├── 充足 → 继续下一步
                │
                └── 不足 → [暂停] + 提醒
                │
           步骤完成
                │
                ▼
           [保存状态] → [生成报告]
```

## 回滚策略

| 步骤 | 回滚操作 | 影响 |
|------|---------|------|
| 1-需求分析 | 重置状态 | 无文件删除 |
| 2-资源规划 | 重置规划数据 | 无文件删除 |
| 3-目录创建 | 删除目录树 | 删除所有已创建目录 |
| 4-SKILL.md编写 | 删除SKILL.md | 删除技能文件 |

## 积分消耗预估

| 操作类型 | 积分消耗 | 说明 |
|---------|---------|------|
| 需求分析 | 50 | 扫描、分析、评估 |
| 资源规划 | 30 | 估算、分配优先级 |
| 目录创建 | 20 | 创建文件系统结构 |
| SKILL.md编写 | 100-300 | 根据复杂度浮动 |
| 验证测试 | 50 | 结构验证、质量检查 |
| 打包发布 | 30 | 生成.skill文件 |

## 停止条件判断

```python
def should_stop(available_credits, floor_limit, next_step_cost):
    """
    判断是否应该停止任务

    返回:
        True: 应该停止
        False: 可以继续
    """
    # 停止条件1: 继续执行会低于底线
    if available_credits - next_step_cost < floor_limit:
        return True

    # 停止条件2: 当前步骤积分不足
    if available_credits < next_step_cost:
        return True

    return False
```
