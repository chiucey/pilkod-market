# Auto-Skill-Generator 技能

自动生成Agent Skills的智能助手，管理积分消耗、任务状态和创建流程。

## 核心功能

### 1. 积分管理系统

- **免费积分追踪**：每日免费积分独立记录，实时监控消耗
- **底线积分设置**：默认1000积分，可用户自定义
- **智能预警**：积分低于底线前停止任务并提醒
- **状态同步**：每次停止自动保存完整状态

### 2. 任务状态机

```
[空闲] → [检查积分] → [查找未完成任务]
    ↓                    ↓
继续执行          有 → [恢复任务]
                       无 → [新建任务]
```

**任务状态定义**：
- `idle`: 空闲，等待启动
- `analyzing`: 分析需求阶段
- `planning`: 规划资源阶段
- `creating`: 创建目录阶段
- `writing`: 编写SKILL.md阶段
- `paused`: 暂停等待用户确认
- `completed`: 任务完成
- `stopped`: 因积分不足停止

### 3. 工作流程（4步骤）

#### 步骤1：寻找分析需求
- 扫描用户输入和对话历史
- 分析潜在技能创建需求
- 评估需求复杂度和价值
- 更新状态：`analyzing`

#### 步骤2：规划资源
- 估算所需积分消耗
- 分配执行优先级
- 生成任务清单
- 更新状态：`planning`

#### 步骤3：创建目录
- 在 `/workspace/temp-skills/` 下创建技能目录
- 创建标准目录结构（scripts/、references/、assets/）
- 初始化 `_meta.json`
- 更新状态：`creating`

#### 步骤4：编写SKILL.md
- 生成技能ID（使用generate_skill_id）
- 编写frontmatter（name、description）
- 编写技能内容
- 更新状态：`writing`

### 4. 回滚机制

**可回滚的操作**：
- 目录创建 → 删除目录
- SKILL.md编写 → 删除文件内容
- 资源规划 → 重置规划状态

**回滚执行**：
1. 识别需要回滚的步骤
2. 执行反向操作
3. 更新任务状态为上一个有效状态
4. 记录回滚日志

### 5. 积分消耗规则

| 操作 | 预估积分消耗 |
|------|-------------|
| 需求分析 | 50积分 |
| 资源规划 | 30积分 |
| 目录创建 | 20积分 |
| SKILL.md编写 | 100-300积分 |

### 6. 停止条件

**触发停止的条件**：
1. 积分低于底线积分（默认1000）
2. 用户主动取消
3. 系统错误

**停止后行为**：
1. 保存完整任务状态到 `/memories/skill_generator_state.md`
2. 记录消耗积分总数
3. 生成任务摘要报告
4. 提醒用户积分状态

## 执行流程

```
1. 启动 → 检查免费积分
2. 读取状态文件（如存在）
3. 判断：有未完成任务？ → 恢复 / 新建
4. 执行工作流程（按步骤）
5. 每步检查积分余额
6. 积分不足 → 暂停 → 等待确认
7. 用户确认 → 继续执行
8. 任务完成 → 保存状态 → 报告结果
```

## 状态文件格式

```markdown
# Skill-Generator 状态

## 当前积分
- 免费积分: 2000
- 底线积分: 1000
- 已消耗: 450

## 任务状态
- 状态: analyzing
- 任务ID: task_xxx
- 当前步骤: 2/4
- 开始时间: 2026-04-15 10:00:00

## 回滚日志
- 步骤1: 完成
- 步骤2: 完成
- 步骤3: 回滚（已删除目录）

## 待完成任务
- 技能名称: xxx
- 描述: xxx
```

## 积分奖励机制

**被动积分来源**：
- 其他用户使用生成的skill时获得奖励积分
- 奖励自动记录并可查询

## 使用示例

**启动自动生成**：
```
用户："开始自动生成skill任务"
系统：检查积分 → 查找未完成任务 → 开始执行
```

**积分不足提醒**：
```
⚠️ 积分即将不足
当前积分: 1050
底线积分: 1000
剩余可消耗: 50积分

任务将在当前步骤完成后暂停。
如需继续，请确认：回复"确认继续"使用其他积分
```

**恢复任务**：
```
用户："继续任务"
系统：读取状态 → 从上次位置继续执行
```
