# 法考错题分析技能 - 输出格式规范

## 1. Word文档格式

### 1.1 文档属性

| 属性 | 规格 |
|------|------|
| 文件格式 | .docx (Microsoft Word 2007+) |
| 页面方向 | 纵向 |
| 页边距 | 默认值 (上下2.54cm，左右3.18cm) |

### 1.2 字体规范

| 位置 | 字体 | 字号 | 样式 |
|------|------|------|------|
| 文档标题 | 黑体 | 二号 (22pt) | 加粗、居中 |
| 一级标题 | 黑体 | 三号 (16pt) | 加粗 |
| 二级标题 | 黑体 | 小三号 (15pt) | 加粗 |
| 正文 | 宋体 | 四号 (14pt) | 常规 |
| 表格内容 | 宋体 | 五号 (10.5pt) | 常规 |

### 1.3 段落格式

| 属性 | 规格 |
|------|------|
| 行距类型 | 固定值 |
| 行距值 | 26磅 |
| 首行缩进 | 2字符 (约0.74厘米) |
| 段前间距 | 0pt |
| 段后间距 | 0pt |

### 1.4 文档结构

```
法考错题知识点总结
├── 一、错题统计概览
│   ├── 总错题数
│   └── 涉及科目数
├── 二、各科目错题分布
│   └── 表格（科目、错题数、占比）
├── 三、错误原因分析
│   └── 各原因数量及占比
├── 四、各科目知识点归纳
│   ├── 民法
│   │   ├── 题目1
│   │   ├── 选项
│   │   ├── 正确答案
│   │   ├── 错误原因
│   │   └── 解析（如有）
│   ├── 刑法
│   └── ...其他科目
└── 五、知识点掌握程度评估
    ├── 掌握薄弱数量
    ├── 掌握一般数量
    └── 需加强数量
```

## 2. Markdown思维导图格式

### 2.1 标题层级

| 层级 | 用途 | Markdown语法 |
|------|------|--------------|
| H1 | 文档总标题 | `# 标题` |
| H2 | 概览/分类标题 | `## 标题` |
| H3 | 各科目标题 | `### 标题` |
| H4 | 错误原因分组 | `#### 标题` |
| 列表 | 知识点项 | `- 内容` |

### 2.2 示例结构

```markdown
# 法考错题知识点思维导图

## 概览
- 总错题数：50
- 涉及科目：8个

## 法律科目分类

### 民法 (15题, 30.0%)

#### 概念混淆 (8题)
- 物权与债权的区别
- 合同解除与合同撤销
- ...

#### 重点遗漏 (5题)
- 民事法律行为的有效要件
- ...

### 刑法 (12题, 24.0%)
...
```

## 3. PNG图表格式

### 3.1 通用规范

| 属性 | 规格 |
|------|------|
| 文件格式 | PNG |
| 分辨率 | 150 DPI |
| 背景色 | 白色 (#FFFFFF) |
| 长宽比 | 根据图表类型自适应 |

### 3.2 颜色配置

**科目分布图颜色方案：**
```
['#FF6B6B', '#4ECDC4', '#45B7D1', '#FFA07A', '#98D8C8',
 '#F7DC6F', '#BB8FCE', '#85C1E2', '#F8B500', '#00CED1',
 '#FF69B4', '#32CD32', '#9370DB', '#20B2AA', '#FFD700']
```

**错误原因分布图颜色方案：**
```
同上
```

**掌握程度分布图颜色方案：**
```
薄弱:   #FF4444 (红色 - 需要重点关注)
一般:   #FFA500 (橙色 - 需要巩固)
需加强: #44AA44 (绿色 - 表现较好)
```

### 3.3 图表标题

| 图表 | 标题 |
|------|------|
| 图1 | 法律科目错题分布 |
| 图2 | 错误原因分布 |
| 图3 | 知识点掌握程度分布 |

### 3.4 图例格式

- 位置：图表右侧居中
- 格式：`科目名称 (百分比)`
- 字体大小：10pt

## 4. 文件命名规范

### 4.1 输出文件名

| 类型 | 命名格式 |
|------|----------|
| Word文档 | `法考错题知识点总结.docx` |
| 思维导图 | `法考错题知识点思维导图.md` |
| 科目分布图 | `图1-法律科目错题分布.png` |
| 错误原因图 | `图2-错误原因分布.png` |
| 掌握程度图 | `图3-知识点掌握程度分布.png` |

### 4.2 输出目录结构

```
output/
├── 法考错题知识点总结.docx
├── 法考错题知识点思维导图.md
├── 图1-法律科目错题分布.png
├── 图2-错误原因分布.png
└── 图3-知识点掌握程度分布.png
```
