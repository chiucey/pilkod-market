**战略重要性**

| 指标 | 数据 |
|------|------|
| 日均石油通过量 | 约1700万桶 |

**伊朗的"核选项"策略**

```
博弈论视角：
├─ 边缘政策(Brinkmanship)：推向战争边缘但不实际开战
├─ 目标：胁迫对方让步
└─ 威胁可信性：切断全球20%石油供应

历史先例：
├─ 1980年代两伊战争油轮战
└─ 当前：威胁封锁以反制西方制裁
```

| 温和派 | 改善经济 | 核谈判支持者 |

## 俄乌冲突与欧洲能源

### 制裁机制

**制裁措施演变**

| 时间 | 制裁措施 |
|------|---------|
| 2022年2月 | 金融制裁（SWIFT排除） |
| 2022年6月 | 禁止进口俄罗斯原油 |
| 2022年12月 | 欧盟原油禁运生效 |
| 2023年2月 | 石油产品禁运生效 |
| 2022年12月 | G7价格上限（原油60美元/桶） |

**价格上限机制**

```
机制设计：
├─ 原生原油：上限60美元/桶
├─ 精制产品：上限100美元/桶（高价值）、45美元/桶（低价值）
└─ 保险/融资：仅限价格低于上限的货物

执行挑战：
├─ 影子船队规模扩大
├─ 贸易记录不透明
└─ 制裁执行差异
```

├─ 印度日均进口：约175万桶
└─ 乌拉尔原油vs布伦特：折扣约10-15美元/桶

## 行为主体策略分析

### 产油国策略

**沙特阿拉伯**

```
核心目标：
├─ 财政平衡：需要约75-80美元/桶
├─ 市场份额：维持约10%全球产量
└─ 2030愿景：经济多元化转型

策略倾向：
├─ 短期：牺牲市场份额维护价格
├─ 中期：在价格和份额间寻求平衡
└─ 长期：平滑过渡到后石油时代
```

**俄罗斯**

```
核心目标：
├─ 财政收入：支撑战争经济
├─ 地缘政治：维护势力范围
└─ 能源地位：保持出口能力

策略倾向：
├─ 向东转：深化与中国合作
├─ 影子市场：绕过西方制裁
└─ 价格接受：放弃部分垄断租金
```

**伊朗**

```
核心目标：
├─ 解除制裁：经济改善
├─ 地区影响力：维护代理网络
└─ 核能力：技术推进

策略倾向：
├─ 边缘政策：地区紧张增加谈判筹码
├─ 非正规出口：维持有限出口
└─ 耐心等待：制裁疲劳效应
```

### 消费大国策略

**中国**

```
核心目标：
├─ 能源安全：多元化进口来源
├─ 成本控制：抑制输入性通胀
└─ 转型加速：发展清洁能源

策略倾向：
├─ 俄罗斯合作：增加进口、接受人民币结算
├─ 中东外交：稳定伊朗-沙特关系
└─ 战略储备：大规模收储
```

**美国**

```
核心目标：
├─ 能源价格：消费者 vs 生产者平衡
├─ 气候承诺：可再生能源发展
└─ 地缘影响：维护中东存在

策略倾向：
├─ 页岩油杠杆：作为边际供应调节市场
├─ 制裁工具：限制对手能源收入
└─ 页岩油产量：根据价格灵活调整
```

**印度**

```
核心目标：
├─ 成本优化：最便宜来源
├─ 能源安全：来源多元化
└─ 发展优先：支持经济增长

策略倾向：
├─ 俄罗斯石油：增加进口（折扣价）
├─ 中东平衡：与沙特、伊朗均保持关系
└─ 国内替代：发展电动汽车、生物燃料
```

## 结论

**核心发现**：

1. **霍尔木兹海峡是最大单一风险源**：任何封锁或严重受限都将导致油价剧烈波动

2. **俄乌冲突改变全球能源格局**：俄罗斯能源出口向东转移，欧洲能源安全加速转型

3. **地缘政治风险溢价显著**：当前油价包含约5-15美元/桶的地缘风险溢价

4. **多极化趋势明显**：能源地缘政治从"中东中心"向多元化转变

5. **制裁效果有限**：影子市场、替代贸易削弱了西方制裁效力
