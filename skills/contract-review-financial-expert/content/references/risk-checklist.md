# 合同财务风险检查清单

## 一、付款与现金流检查项

### 1.1 账期条款
- [ ] 付款账期是否明确（天数为具体数字而非"尽快"）
- [ ] 账期从何时起算（交货/验收/开票/到账）
- [ ] 是否存在分段付款节点
- [ ] 晚付款违约金是否约定

### 1.2 预付款风险
- [ ] 预付款比例是否过高（>30%需警惕）
- [ ] 预付款退还条件是否明确
- [ ] 是否要求银行保函或备用信用证覆盖预付款

### 1.3 垫资场景
- [ ] 最坏情况：履约垫资后对方违约
- [ ] 垫资金额与对方资信是否匹配
- [ ] 是否有阶段性验收保护垫资

## 二、金额与结算检查项

### 2.1 金额确定性
- [ ] 合同金额是否固定或有明确计算公式
- [ ] 开口合同是否有最高限价
- [ ] 变更/签证/增项流程是否明确

### 2.2 费率与单价
- [ ] 单价/费率是否包含所有成本
- [ ] 市场波动时价格调整机制
- [ ] 最低消费量/服务量约定

### 2.3 税务条款
- [ ] 税费承担方是否明确
- [ ] 税率变化时的调整机制
- [ ] 发票类型与时间要求

## 三、履约与违约检查项

### 3.1 违约金对等性
- [ ] 违约金条款是否双向对等
- [ ] 单方违约金是否过高（>合同金额20%）
- [ ] 是否存在惩罚性条款

### 3.2 赔偿边界
- [ ] 赔偿是否设置上限
- [ ] 间接损失/预期利润是否排除
- [ ] 不可抗力定义与后果

### 3.3 解除权
- [ ] 单方解除权的触发条件
- [ ] 解除后的结算与赔偿
- [ ] 过渡期义务

## 四、信用与担保检查项

### 4.1 担保措施
- [ ] 担保人/担保函要求
- [ ] 保证金条款（比例/返还条件）
- [ ] 抵押/质押物

### 4.2 主体变更限制
- [ ] 股权转让限制
- [ ] 合并分立处理
- [ ] 实际控制人变更通知

## 五、长周期风险检查项

### 5.1 有效期与续期
- [ ] 合同期限
- [ ] 自动续期条款及通知要求
- [ ] 续期价格调整

### 5.2 退出机制
- [ ] 提前终止条件
- [ ] 终止赔偿计算
- [ ] 业务连续性保障

### 5.3 知识产权
- [ ] 成果归属
- [ ] 授权范围
- [ ] 竞业限制
