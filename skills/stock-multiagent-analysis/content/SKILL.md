# 股票多 Agent 分析技能

## 核心流程

用户给出股票名称或代码 → 并行启动 4 个专业 Agent → 汇总辩论 → 输出综合报告

## Step 1：确认股票信息

从用户输入中提取：
- 股票名称
- 交易所/代码（如 002837、NVDA）
- 交易市场（A股/港股/美股）

若信息不完整，询问确认后继续。

## Step 2：并行启动 4 个分析 Agent

使用 `sessions_spawn` 并行启动 4 个 subagent（mode=run, runtime=subagent），每个 Agent 独立搜索信息并分析。

### Agent 1：技术分析师

```
你是资深技术分析师。请对 [股票名称/代码] 进行技术面分析。

请搜索并分析：
1. 近期K线形态、均线系统（MA5/10/20/60）
2. 成交量变化（近1个月）
3. MACD、KDJ等技术指标
4. 压力位与支撑位
5. 给出明确的技术面研判：短期/中期走势判断

只输出技术分析结论，语言精炼，结论明确。
```

### Agent 2：基本面分析师

```
你是资深基本面分析师。请对 [股票名称/代码] 进行基本面分析。

请搜索并分析：
1. 近2年营收与净利润增速
2. 主要产品毛利率及竞争力
3. 行业市场规模与增速
4. 大客户占比及稳定性
5. 估值水平：PE、PB在行业中的位置
6. 给出明确的基本面研判：成长性/价值/风险

只输出分析结论，语言精炼，结论明确。
```

### Agent 3：情绪/新闻分析师

```
你是资深市场情绪与新闻分析师。请对 [股票名称/代码] 进行情绪面分析。

请搜索并分析：
1. 近1个月新闻热度与重大事件
2. 机构持仓变化（近期增持/减持迹象）
3. 板块整体资金流向
4. 市场情绪：散户/机构/外资情绪
5. 政策面对行业的影响
6. 给出明确的情绪面研判：做多情绪浓厚/中性/偏空

只输出分析结论，语言精炼，结论明确。
```

### Agent 4：多空辩论研究员

```
你是多空辩论研究员。请对 [股票名称/代码] 进行多空辩论。

请搜索并构建：
1. 最强的2-3个做多催化剂（行业/公司/政策）
2. 核心技术壁垒与竞争护城河
3. 业绩预期差：可能超出市场预期的点

然后写出空头最可能反驳的2个弱点（从多空两个角度都写）。

最后给出判断：多空谁是主导力量？操作建议是什么？
```

## Step 3：等待所有 Agent 返回

等待 4 个 subagent 全部完成（会收到 completion 事件）。不要主动 poll。

## Step 4：汇总综合报告

将 4 个 Agent 的结论汇总为结构化报告，格式如下：

```
# 🏊 [股票名称]（代码）多 Agent 分析报告
**日期 | 股价参考：XX元**

## 各维度研判一览
| 维度 | 结论 | 核心依据 |
|------|------|---------|
| 技术面 | 🔴/🟡/🟢 | ... |
| 基本面 | 🔴/🟡/🟢 | ... |
| 情绪面 | 🔴/🟡/🟢 | ... |
| 多空辩论 | 中期多空博弈 | ... |

## 综合结论
**短期（1-3个月）**：谨慎/中性/积极
> 具体分析

**中长期（6-18个月）**：方向判断
> 具体分析

## 关键观察指标
- 下一个催化剂：...
- 风险点：...
```

## 输出要求

- 语言精炼，数据真实
- 结论用 emoji 标注情绪（🔴谨慎 🟡中性 🟢积极）
- 操作建议要具体（买入/观望/卖出/跟踪）
- 包含风险提示
- 每次分析完成后，询问用户是否要将其保存为观察标的，或设置定时跟踪
