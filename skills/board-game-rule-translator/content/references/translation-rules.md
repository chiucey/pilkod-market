# Translation Guidelines

## Core Principles

### 1. Accuracy First
- Translate game mechanics accurately
- Maintain original meaning without adding interpretation
- Preserve the author's intent

### 2. Natural Chinese
- Use natural Chinese phrasing
- Avoid literal translations
- Adjust sentence structure for Chinese readability

### 3. Consistency
- Use standardized terminology throughout
- Create terminology glossary for each game
- Cross-reference translations for consistency

## Translation Rules

### Article Handling

| English | Chinese | Usage |
|---------|---------|-------|
| a/an | 一个/一张/一只等 | Countable nouns |
| the | 这/那/此 | Specific items |
| some | 一些/若干 | Unspecified quantity |
| each | 每个 | Every individual |
| any | 任意 | Any/all possibilities |
| every | 每个 | All without exception |

### Number Handling

| English | Chinese | Notes |
|---------|---------|-------|
| one | 一 | Singular |
| two, three, etc. | 二、三等 | Numbers in text |
| first, second, etc. | 第一、第二等 | Ordinal numbers |
| both | 两个都/双方 | Two items |
| either | 任一/两者之一 | One of two |
| neither | 两者都不 | Neither of two |
| half | 一半/半个 | Fractions |
| double | 双倍/翻倍 | Multiplication |
| triple | 三倍 | Multiplication |

### Time & Sequence

| English | Chinese | Notes |
|---------|---------|-------|
| first/then/finally | 首先/然后/最后 | Sequence markers |
| before/after | 在...之前/之后 | Time relations |
| during | 在...期间 | Concurrent actions |
| until | 直到 | Time limit |
| when | 当...时 | Trigger conditions |
| immediately | 立即/立刻 | Instant action |
| at the start/end | 在开始/结束时 | Phase timing |

### Conditional Phrases

| English | Chinese |
|---------|---------|
| if...then | 如果...则 |
| unless | 除非 |
| except when | 除...之外 |
| only if | 仅当 |
| as long as | 只要 |
| provided that | 在...条件下 |
| in case of | 在...情况下 |

### Imperative Mood

| English | Chinese |
|---------|---------|
| do X | 做X |
| must do X | 必须做X |
| should do X | 应该做X |
| may do X | 可以做X |
| cannot do X | 不能做X |
| must not do X | 禁止做X |

### Passive Voice

Chinese rarely uses passive voice. Transform:

| English | Chinese |
|---------|---------|
| X is done | 执行X/进行X |
| X was chosen | 选择了X |
| X is placed on Y | 将X放置在Y上 |
| X is taken by Y | Y拿取X |

## Format Conventions

### Lists

**Bulleted lists in English:**
```english
- First item
- Second item
- Third item
```

**Should become in Chinese:**
```chinese
- 第一项
- 第二项
- 第三项
```

Or use numbered format for sequences.

### Tables

**Header row translation:**
```english
| Card | Cost | Effect |
```

```chinese
| 卡牌 | 费用 | 效果 |
```

### Numbered Rules

**Format as numbered list:**
```chinese
1. 首先，玩家执行设置步骤。
2. 然后，起始玩家开始第一回合。
3. 重复步骤直到满足胜利条件。
```

### Page References

| English | Chinese |
|---------|---------|
| See page X | 参见第X页 |
| As shown on page X | 如图X所示 |
| Refer to section X | 参见X节 |

## Special Element Handling

### Warning Boxes

Use traditional warning style:
```
【警告】此规则必须严格遵守。
```

### Example Boxes

```
【示例】
玩家A选择执行"攻击"行动。
然后，玩家A打出攻击卡。
结果：对手失去3点生命值。
```

### Side Notes

Format as indented block:
```
    （注：此配件在基础版中不包含）
```

## Cultural Adaptation

### Do Adapt
- Card suits (Spades → 黑桃, Hearts → 红桃, etc.)
- Currency references (adapt to Chinese yuan)
- Age/dates to Chinese calendar if relevant

### Do Not Adapt
- Game-specific terminology
- Proper nouns (game titles, publisher names)
- Technical terms without Chinese equivalents
- Trademarked terms

## Common Translation Patterns

### "A card that..." → "...的卡牌"

| English | Chinese |
|---------|---------|
| a card that costs 3 | 费用为3的卡牌 |
| a card that gives you 2 points | 给予你2分的卡牌 |

### "If you..." → "如果你..."

| English | Chinese |
|---------|---------|
| If you have 5 cards | 如果你有5张手牌 |
| If you control the area | 如果你控制该区域 |

### "You may..." → "你可以..."

| English | Chinese |
|---------|---------|
| You may draw a card | 你可以抽一张牌 |
| You may spend resources | 你可以消耗资源 |

### "X or Y" → "X或Y" / "X和Y"

| English | Chinese |
|---------|---------|
| Red or Blue | 红色或蓝色 |
| Both X and Y | X和Y同时 |

### "X to Y" → "X到Y" / "从X到Y"

| English | Chinese |
|---------|---------|
| 2 to 4 players | 2到4名玩家 |
| 30 to 60 minutes | 30到60分钟 |

## Quality Checklist

- [ ] All text translated (no "TBD" or skipped sections)
- [ ] Terminology consistent throughout document
- [ ] Sentence structure natural in Chinese
- [ ] Lists and tables properly formatted
- [ ] Cross-references point to correct sections
- [ ] Special elements (warnings, examples) properly formatted
- [ ] No spelling or grammatical errors
- [ ] Final review for readability
