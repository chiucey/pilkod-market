# 跨会话上下文同步

## 核心能力

1. **自动状态捕获** - 在关键节点自动保存会话上下文
2. **语义化索引** - 用自然语言标签标记当前工作状态
3. **跨渠道恢复** - 网页版/飞书/其他渠道共享同一状态空间
4. **智能状态合并** - 新会话自动获取最近的工作状态

## 工作流程

### 触发场景

当用户表达以下意图时激活：
- "接着上次继续"
- "继续之前的工作"
- "换个渠道/设备继续"
- "恢复上次的会话"
- "我之前在做..."
- "上次任务还没完成"

### 执行步骤

#### 步骤1：状态检查

检查 `/memories` 中的持久化状态：

```
检查是否存在：
- session_state.md (当前会话状态)
- task_queue.md (任务队列)
- artifacts/ (中间产物索引)
```

#### 步骤2：状态读取

读取最新的会话快照，包含：
- 当前任务描述
- 已完成的步骤
- 待完成的工作
- 生成的文件路径
- 用户偏好/上下文

#### 步骤3：状态恢复

向用户呈现：
```
📋 上次会话摘要：
• 任务：{任务描述}
• 进度：{已完成X步，还剩Y步}
• 文件：{生成的文件列表}
• 状态：{活跃/暂停/完成}

是否继续？
```

#### 步骤4：状态保存

在以下时机自动保存：
- 完成一个阶段性任务
- 生成重要文件
- 用户明确说"先到这里"
- 会话即将结束

### 保存内容结构

```markdown
# 会话状态快照

## 元信息
- 创建时间: {timestamp}
- 会话ID: {session_id}
- 渠道: {web/feishu/...}
- 用户标识: {user_id}

## 当前任务
- 任务类型: {task_type}
- 任务描述: {description}
- 任务状态: {in_progress/completed/paused}

## 进度追踪
- 已完成步骤:
  1. {step_1}
  2. {step_2}
- 当前步骤: {current_step}
- 下一步计划: {next_steps}

## 上下文摘要
{关键对话摘要、用户偏好、约束条件}

## 产物索引
- 文件1: {path} - {description}
- 文件2: {path} - {description}

## 待决事项
- {question_1}
- {question_2}
```

## 智能触发规则

### 自动保存触发条件

满足以下任一条件时自动保存：
1. 完成一个明确的子任务
2. 生成文件且用户确认
3. 用户说"暂停"、"先到这里"
4. 系统检测到会话可能中断
5. 达到5次关键交互节点

### 状态过期策略

- 最近7天内的状态优先恢复
- 超过30天的状态标记为归档
- 用户可手动清理过期状态

## 产物管理

### 文件命名规范

```
{项目标识}_{时间戳}_{内容类型}.{扩展名}
```

### 产物索引

每个文件记录：
- 文件路径
- 创建时间
- 用途描述
- 关联任务
- 有效性状态

## 错误处理

### 无历史状态

```
🔍 未找到之前的会话记录。
可能是首次会话，或历史记录已过期。

开始新会话？请描述您需要完成的任务。
```

### 状态损坏

检测到状态文件损坏时：
1. 尝试恢复最近备份
2. 如果无备份，提示用户重新开始
3. 记录问题供后续改进

### 多状态冲突

如果存在多个近期的会话状态：
1. 按时间戳排序
2. 询问用户选择或合并
3. 优先选择用户主动保存的状态

## 使用示例

### 示例1：跨渠道继续

**用户**：我刚才在网页版让你帮我写代码，现在换到飞书了，怎么继续？

**助手**：
```
📋 检测到您有未完成的任务：
• 任务：编写数据分析脚本
• 进度：已完成60%（完成需求分析，正在编写核心函数）
• 上次活动：15分钟前

正在加载上下文...
✅ 已恢复。继续完成代码编写？
```

### 示例2：中断后继续

**用户**：上次我让你帮我分析季度报告，还差什么？

**助手**：
```
📊 上次会话状态：
• 任务：Q4季度报告分析
• 进度：数据已获取，等待您上传报告文件
• 待决事项：需要您提供Q4数据文件

请上传报告文件，或描述您想进行的调整。
```

### 示例3：首次引导

**用户**：我想让你帮我做个网站

**助手**：
```
🆕 开始新会话

请详细描述您的网站需求：
1. 网站类型（电商/博客/企业官网/...）
2. 主要功能
3. 设计风格偏好
4. 是否有参考网站

我会记录所有信息，确保下次继续时无缝衔接。
```
