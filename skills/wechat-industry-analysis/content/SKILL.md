# 公众号产业经济分析技能

## 核心能力范围

本技能帮助用户高效完成以下类型的公众号文章创作：

| 内容类型 | 触发关键词 | 输出目标 |
|---------|-----------|---------|
| 投融资分析 | 融资、投资、并购、IPO、PE/VC | 产业资本流向图谱+重点案例解读 |
| 政策解读 | 政策发布、政策解读、法规 | 政策要点+行业影响+应对建议 |
| 热点产业分析 | 热点事件、突发、趋势 | 多维度产业影响分析 |
| 地方产业研究 | 地方经济、区域产业、园区 | 产业布局+优势分析+发展建议 |

## 工作流程

### 阶段1：选题与信息搜集

1. **明确分析主题**
   - 确定核心议题和目标受众
   - 划定时间范围（如最近3个月的政策）
   - 明确分析深度（快讯/深度/系列）

2. **信息搜集策略**
   - 投融资：IT桔子、36Kr、烯牛数据、天眼查
   - 政策：国务院、发改委、工信部、地方政府官网
   - 行业数据：国家统计局、行业协会报告
   - 舆情热点：微博热搜、知乎、百度指数

### 阶段2：信息处理与分析

1. **数据清洗与结构化**
   - 筛选关键事件时间线
   - 提取核心数据指标
   - 识别关联关系

2. **多维度分析框架**
   ```
   投融资分析框架：
   ├── 总量视角：融资数量/金额趋势
   ├── 结构视角：轮次分布/赛道分布
   ├── 主体视角：头部机构/明星项目
   └── 趋势视角：热点转换/冷门赛道

   政策分析框架：
   ├── 政策层级：国家/地方/行业专项
   ├── 政策类型：法律法规/指导意见/通知
   ├── 影响范围：直接/间接/潜在
   └── 落地节奏：试点/推广/强制执行
   ```

### 阶段3：文章结构设计

**标准深度文章结构**（约2000-3000字）：

```
1. 核心观点速览（200字）
   - 3-5个关键发现
   - 主要结论先行

2. 背景与现状（400字）
   - 事件/政策/趋势概述
   - 相关数据支撑

3. 深度分析（1000字）
   - 多维度拆解
   - 典型案例佐证
   - 数据可视化说明

4. 影响与趋势（500字）
   - 对产业的影响预判
   - 未来趋势展望

5. 总结与建议（300字）
   - 对读者的行动建议
   - 延伸阅读指引
```

### 阶段4：内容创作规范

1. **标题撰写**
   - 数字锚定：「3大趋势」「5个要点」
   - 疑问引导：「为什么XX」「如何XX」
   - 时效标签：「刚刚」「重磅」「首发」
   - 避免标题党，保持准确性

2. **数据呈现**
   - 核心数据突出显示
   - 图表辅助说明
   - 数据来源透明

3. **引用规范**
   - 政策原文引用需标注出处
   - 数据引用需注明来源和时间
   - 第三方观点需注明背景
