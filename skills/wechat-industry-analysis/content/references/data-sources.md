## 数据使用注意事项

1. **时效性检查**
   - 投融资数据：优先使用近3个月内数据
   - 政策文件：确认是否为现行有效版本
   - 统计数据：注意数据发布周期（月度/季度/年报）

2. **交叉验证**
   - 重要数据需2-3个来源交叉验证
   - 矛盾数据需分析口径差异

3. **引用规范**
   ```
   数据引用格式：
   来源：[平台/机构名称]
   网址：[URL]
   访问时间：[日期]
   数据截止时间：[具体日期]
   ```

4. **付费数据使用**
   - 付费数据需确认使用授权
   - 文章中引用需标注"付费数据"
