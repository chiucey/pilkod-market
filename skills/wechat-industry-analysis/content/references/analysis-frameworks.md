# 分析框架库

## 一、投融资分析框架

### 1.1 融资环境评估框架（VEC）

```
V - Velocity（速度）
├── 融资周期缩短/延长趋势
├── 从启动到关闭的平均时长
└── 融资轮次间隔变化

E - Environment（环境）
├── 一级市场资金面（募资难度）
├── 二级市场表现（估值锚定）
└── 政策支持力度

C - Capital Flow（资本流向）
├── 热门赛道轮动
├── 机构偏好变化
└── 外资进入/退出趋势
```

### 1.2 赛道竞争力评估模型

```
评估维度：
├── 市场规模
│   ├── 当前规模TAM
│   ├── 潜在规模SAM
│   └── 可服务市场SOM
├── 增长潜力
│   ├── 行业CAGR
│   ├── 渗透率提升空间
│   └── 政策红利期
├── 竞争格局
│   ├── 集中度（HHI指数）
│   ├── 头部效应 vs 分散化
│   └── 潜在进入者威胁
├── 盈利模式
│   ├── 商业模式成熟度
│   ├── 毛利率水平
│   └── 现金流状况
└── 资本热度
    ├── 融资事件数量趋势
    ├── 平均估值水平
    └── 头部机构布局
```

### 1.3 投资机构画像

```
机构分析维度：
├── 基本面
│   ├── 管理规模（AUM）
│   ├── 存续期/基金代数
│   └── 出资人结构（LP构成）
├── 投资策略
│   ├── 专注阶段（天使/VC/PE）
│   ├── 行业偏好
│   ├── 单笔投资规模
│   └── 持股比例偏好
├── 历史业绩
│   ├── IPO数量
│   ├── 独角兽数量
│   └── DPI/MOI指标
└── 近期动态
    ├── 活跃度变化
    ├── 新基金募集
    └── 退出案例
```

## 二、政策分析框架

### 2.1 政策影响评估模型（PIA）

```
P - Policy Clarity（政策清晰度）
├── 目标是否明确
├── 指标是否可量化
└── 执行路径是否清晰

I - Impact Scope（影响范围）
├── 直接影响行业/领域
├── 间接影响产业链
└── 地域范围（全国/地方）

A - Action Required（行动需求）
├── 企业需立即响应的事项
├── 需持续跟进的节点
└── 合规整改要求
```

### 2.2 政策生命周期分析

```
阶段1：政策酝酿期
├── 信号释放（领导讲话/官方吹风）
├── 征求意见稿发布
└── 行业讨论期

阶段2：政策出台期
├── 正式文件发布
├── 配套细则出台
└── 政策解读发布

阶段3：政策执行期
├── 试点阶段
├── 全面推行
└── 执法检查

阶段4：政策调整期
├── 中期评估
├── 修订完善
└── 延续/废止
```

### 2.3 政策对比分析模板

```
对比维度：
┌─────────────┬────────────┬────────────┐
│    维度     │   旧政策    │   新政策    │
├─────────────┼────────────┼────────────┤
│ 核心目标    │            │            │
│ 适用范围    │            │            │
│ 主体责任    │            │            │
│ 激励措施    │            │            │
│ 处罚机制    │            │            │
│ 实施时间    │            │            │
│ 配套要求    │            │            │
└─────────────┴────────────┴────────────┘

变化幅度评估：
├── 实质变化 vs 措辞调整
├── 放宽要求 vs 加严要求
└── 新增条款 vs 删减条款
```

## 三、热点事件产业分析框架

### 3.1 PEST+行业特定因素

```
P - Political（政治）
├── 监管态度变化
├── 政府支持/限制
└── 国际关系影响

E - Economic（经济）
├── 宏观经济影响
├── 资本市场反应
└── 消费信心变化

S - Social（社会）
├── 公众认知变化
├── 舆论走向
└── 消费者行为改变

T - Technological（技术）
├── 技术路线变化
├── 创新机会涌现
└── 技术替代威胁

+ 行业特定因素
├── 行业周期位置
├── 竞争格局影响
└── 产业链传导
```

### 3.2 各方影响矩阵

```
影响分析表：
┌────────────┬────────────┬────────────┬────────────┐
│   主体     │  短期影响   │  中期影响   │  长期影响   │
├────────────┼────────────┼────────────┼────────────┤
│ 龙头企业   │            │            │            │
│ 中小企业   │            │            │            │
│ 创业公司   │            │            │            │
│ 投资者     │            │            │            │
│ 消费者     │            │            │            │
│ 就业       │            │            │            │
└────────────┴────────────┴────────────┴────────────┘

影响性质：
├── 利好（+）/ 利空（-）/ 中性（0）
└── 影响程度：弱 / 中 / 强
```

### 3.3 事件发展推演模型

```
时间维度分析：
├── 已发生：事实梳理
├── 近期（1-3月）：各方反应与应对
├── 中期（3-12月）：格局演变
└── 长期（1年+）：行业重塑

情景推演：
├── 乐观情景：[概率X%]
│   └── 触发条件 + 演化路径 + 最终格局
├── 中性情景：[概率X%]
│   └── 触发条件 + 演化路径 + 最终格局
└── 悲观情景：[概率X%]
    └── 触发条件 + 演化路径 + 最终格局
```

## 四、地方产业研究框架

### 4.1 区域产业竞争力模型

```
钻石模型应用：
┌─────────────────────────────────────┐
│                                     │
│    生产要素 ──────→ 需求条件        │
│         ↖           ↗              │
│           ↖       ↗                │
│    企业战略      相关及支持产业      │
│           ↗   ↖                    │
│             ↗                      │
│         机会 + 政府                 │
│                                     │
└─────────────────────────────────────┘

评分维度（1-10分）：
├── 要素禀赋（人才、土地、资本）
├── 需求条件（本地市场+辐射能力）
├── 相关产业（产业链完整度）
├── 企业战略（本地企业竞争力）
├── 机会（外部机遇把握能力）
└── 政府（政策支持力度）
```

### 4.2 产业选择矩阵

```
吸引力 ────→ 竞争力

高吸引力    高竞争力 → 重点发展（龙头引进）
高吸引力    低竞争力 → 优先突破（差异化）
低吸引力    高竞争力 → 稳定维持（效率提升）
低吸引力    低竞争力 → 逐步退出（腾笼换鸟）

吸引力指标：
├── 市场空间
├── 增长潜力
├── 利润率水平
└── 政策支持

竞争力指标：
├── 产业基础
├── 区位优势
├── 人才储备
└── 营商环境
```

### 4.3 产业招商分析

```
招商目标筛选：
├── 行业匹配度
│   └── 是否符合主导产业定位
├── 企业适配度
│   ├── 规模匹配（不过大/过小）
│   ├── 阶段匹配（需要当地资源）
│   └── 文化匹配（长期经营意愿）
├── 带动效应
│   ├── 税收贡献
│   ├── 就业带动
│   ├── 产业链延伸
│   └── 品牌效应
└── 落地可行性
    ├── 要素需求匹配
    ├── 落地时间预期
    └── 合作条件达成
```

## 五、通用分析工具

### 5.1 逻辑树分析法

```
问题：为什么[核心现象]？

├── 维度1
│   ├── 原因1.1
│   ├── 原因1.2
│   └── 原因1.3
├── 维度2
│   ├── 原因2.1
│   └── 原因2.2
└── 维度3
    ├── 原因3.1
    └── 原因3.2

验证：每个原因是否有数据支撑？
```

### 5.2 波特五力分析

```
行业竞争格局：
├── 现有竞争者竞争程度
│   └── 集中度、差异化、退出壁垒
├── 潜在进入者威胁
│   └── 规模经济、品牌忠诚、资本需求
├── 替代品威胁
│   └── 替代品性价比、用户转换成本
├── 供应商议价能力
│   └── 供应商集中度、可替代性
└── 买方议价能力
    └── 买方集中度、信息透明度
```

### 5.3 SWOT分析模板

```
┌─────────────────┬─────────────────┐
│   Strengths     │    Weaknesses   │
│   优势          │    劣势         │
│                 │                 │
├─────────────────┼─────────────────┤
│   Opportunities │    Threats     │
│   机会          │    威胁         │
│                 │                 │
└─────────────────┴─────────────────┘

SO策略：利用优势抓住机会
WO策略：克服劣势抓住机会
ST策略：利用优势规避威胁
WT策略：减少劣势规避威胁
```
