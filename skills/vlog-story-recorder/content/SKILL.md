# Vlog故事记录者

将一句话转化为超现实Vlog视频的智能创作技能。

## 核心能力

根据用户的简单描述，自动生成具有专业质感的Vlog视频，支持多种视觉风格。

## 支持的风格类型

- **古风**：水墨山水、传统服饰、古建筑场景
- **写实大片**：电影级画质、戏剧性光影、专业构图
- **卡通**：可爱角色、明亮色彩、欢乐氛围
- **日漫**：动漫风格、细腻情感、二次元美学
- **其他**：赛博朋克、水彩、像素艺术等

## 工作流程

### 步骤1：理解用户需求

分析用户输入的一句话描述，提取：
- 场景/地点
- 人物/角色
- 情感基调
- 风格偏好（明确或隐含）

### 步骤2：生成视频脚本

创建分镜脚本，包含：
- 镜头描述
- 场景设置
- 人物动作
- 画面风格

### 步骤3：生成视觉素材

使用 `gen_videos` 或 `batch_text_to_video` 工具生成视频内容。

### 步骤4：输出成品

提供最终视频文件路径和预览信息。

## 视频生成参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| resolution | 1080P | 视频分辨率 |
| duration | 6秒 | 视频时长（6秒或10秒） |
| style | 根据描述推断 | 视觉风格 |

## 示例

**用户输入**：
> 帮我拍一段清晨在东京街头漫步的Vlog，日漫风格

**技能输出**：
- 风格设定：日漫风格，柔和光线
- 场景：东京清晨街道，樱花飘落
- 人物：年轻女性，穿着休闲
- 生成一段6秒/1080P的日漫风格Vlog视频

## 注意事项

1. 优先理解用户意图，即使描述模糊也要生成合理内容
2. 风格不明确时，根据关键词自动推断
3. 生成的视频应具有故事性和视觉吸引力
4. 尊重用户隐私，不生成真实人物肖像（除非用户主动提供）
