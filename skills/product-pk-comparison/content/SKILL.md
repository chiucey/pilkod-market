# Product PK Comparison Skill

## 核心工作流

### 阶段 1：确认主产品

当用户提供一个产品后：

1. **确认产品信息**
   - 产品名称、品牌、型号
   - 主要类别（电子产品/家电/日用品等）

2. **询问对比方式**
   ```
   您已选择 [产品名]。请选择对比方式：

   A. 手动输入竞品 - 输入具体的产品名称进行对比
   B. 智能推荐 - AI自动分析并推荐Top10竞品

   请输入 A 或 B，或直接输入您想对比的产品名称。
   ```

### 阶段 2A：手动输入竞品（选择A）

1. 收集用户输入的竞品名称
2. 确认竞品列表（可多个）
3. 执行对比分析

### 阶段 2B：智能推荐竞品（选择B）

**竞品网站SOP参考**（按优先级排序）：

| 网站 | 特点 | 语言 | 典型URL格式 |
|------|------|------|-------------|
| Rtings.com | 详细量化测试，数据驱动，有直接对比工具 | EN | https://www.rtings.com/headphones/reviews/compare |
| WhatHiFi | 权威音响媒体，评分客观 | EN | https://www.whathifi.com/compare |
| SoundGuys | 专项评测详细，降噪耳机评测权威 | EN | https://www.soundguys.com/ |
| Versus.com | 多维度对比，有中文版 | 中/EN | https://versus.com/cn/ |
| GSMArena | 手机数码专业评测 | EN | https://www.gsmarena.com/compare.php3 |
| TechSpot | 科技产品对比 | EN | https://techspot.com/ |

**智能搜索流程**：

1. **搜索竞品**
   ```
   搜索查询模板：
   - "[产品名] vs [竞品] comparison"
   - "[产品类型] best [年份] comparison"
   - "[产品名] alternatives top 10"
   - "[竞品网站] [产品名] vs"
   ```

2. **筛选Top10竞品**
   - 按销量/热度排序
   - 同价位产品优先
   - 同品牌/同类型产品
   - 过滤掉停售/过时产品

3. **呈现竞品列表**
   ```
   根据[产品名]，智能推荐的Top10竞品：

   1. [竞品1] - 核心差异：[主要卖点]
   2. [竞品2] - 核心差异：[主要卖点]
   ...

   请选择要对比的产品（可多选，序号用逗号分隔）：
   或输入 "全部对比" 进行完整对比
   ```

### 阶段 3：Customer Category 权重排序对比分析

**核心原则**：按Customer关心的Category分类，Subcategory按权重排序展示。

- 综合信息：厂商指导价、级别、能源类型、上市时间
- 动力系统：电机/发动机最大功率、峰值扭矩、电驱形式、电池容量、CLTC续航
- 车身尺寸：长宽高、轴距、后备厢容积、座椅材质、天窗类型
- 安全配置：气囊数量、主动安全、被动安全
- 辅助/操控：自动泊车、360影像、巡航系统
- 外部配置：大灯类型、天窗类型、轮毂尺寸
- 内部配置：方向盘材质、仪表盘类型、中控屏尺寸

## 竞品网站参考规范

### 懂车帝（汽车专项）

- **特点**：车型对比权威平台，支持2-4款车型同时PK
- **语言**：中文
- **对比维度**：综合信息、动力系统、车身尺寸、安全配置、辅助操控、舒适配置、科技配置、懂车实测
- **评分体系**：懂车分（综合评分）、懂车实测分、用户口碑评分
- **搜索关键词**：`懂车帝 [车型] 对比`，`懂车帝 [车型] PK`
- **对比工具**：https://www.dongchedi.com/auto/auto_compare/params
- **APP入口**：车型详情页左下角"PK"按钮 / 车型大全→车型对比

### Rtings.com
- **特点**：数据驱动，量化测试，可视化对比工具
- **语言**：英文
- **评分体系**：Overall + Value + Design + Noise Isolation + Sound
- **搜索关键词**：`rtings [product] vs [competitor]`
- **对比工具**：https://www.rtings.com/headphones/reviews/compare

### WhatHiFi
- **特点**：权威音响媒体，评分客观
- **语言**：英文
- **评分体系**：Sound Quality + Build Quality + Features + Value (5星制)
- **搜索关键词**：`whathifi [product] vs [competitor]`

### SoundGuys
- **特点**：专项评测详细，降噪耳机评测权威
- **语言**：英文
- **评分体系**：Overall + ANC + Battery + Comfort
- **搜索关键词**：`soundguys [product] review comparison`

### Versus.com
- **特点**：多维度对比，有中文版
- **语言**：中/英文
- **对比URL**：`https://versus.com/cn/[category]/[product1]-vs-[product2]`
- **搜索关键词**：`versus.com [product1] vs [product2]`

### GSMArena (手机专项)
- **特点**：手机数码专业评测，详细规格表
- **语言**：英文
- **对比工具**：`https://www.gsmarena.com/compare.php3`

### TechSpot
- **特点**：科技产品专业对比，性能测试详尽
- **语言**：英文
- **评分体系**：Performance + Value + Features 综合评分

## 注意事项

1. **Category权重**：根据产品类型动态选择权重矩阵，P0权重最高优先展示
2. **信息来源**：优先引用权威评测网站数据（Rtings > WhatHiFi > SoundGuys > Versus）
3. **时效性**：标注数据获取日期，价格/促销信息需标注时效
4. **客观性**：不偏向特定品牌，基于数据说话
5. **用户场景**：询问用户主要使用场景，根据场景推荐对应权重最高的维度
