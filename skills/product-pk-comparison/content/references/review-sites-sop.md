# 热门Review比价网站SOP参考

## 1. 懂车帝（汽车专项）

**网站特点**
- 字节跳动旗下汽车资讯平台
- 车型对比权威平台，支持2-4款车型同时PK
- 懂车实测数据（加速/刹车/续航/能耗实测）
- 懂车分综合评分体系
- 车友圈真实口碑

**对比维度**
- 综合信息：厂商指导价、级别、能源类型、上市时间
- 动力系统：电机/发动机最大功率、峰值扭矩、电驱形式、电池容量、CLTC续航
- 车身尺寸：长宽高、轴距、后备厢容积
- 安全配置：气囊数量、主动安全、被动安全
- 辅助/操控：自动泊车、360影像、巡航系统
- 舒适配置：座椅材质、天窗类型、后排座椅调节
- 科技配置：中控屏尺寸、车机芯片、OTA升级、手机互联
- 灯光配置：大灯类型、雾灯、氛围灯
- 空调/冰箱：空调类型、后排出风口

**评分体系**
- 懂车分（综合评分 0-5分）
- 懂车实测分（加速/刹车/续航/能耗）
- 用户口碑评分
- 性价比指数

**搜索关键词模板**
```
懂车帝 [车型] 对比
懂车帝 [车型] PK
懂车帝 [车型1] vs [车型2]
懂车帝 [新能源车型] 续航实测
懂车帝 [车型] 车主口碑
```

**对比工具URL**
```
https://www.dongchedi.com/auto/auto_compare/params
https://www.dcdapp.com/auto/auto_compare/params
```

**操作入口**
- APP：车型详情页左下角"PK"/"对比"按钮
- 车型大全→车型对比
- 最多支持4款车型同时对比

**特色功能**
- "仅看差异"模式：聚焦配置变更
- VIN码验证：实车出厂配置验证
- 懂车实测视频：专业测试数据可视化
- 车友圈口碑：真实车主评价

## 竞品智能搜索工作流

### Step 1: 确定产品类别
```
产品类别 → 对应专业网站
```

### Step 2: 搜索竞品列表
```python
search_queries = [
    f"[产品名] best alternatives",
    f"[产品类型] top 10 [年份]",
    f"[产品名] vs competitors",
    f"site:[权威网站] [产品名] comparison"
]
```

### Step 3: 筛选Top10竞品
**筛选标准**：
1. 同价位产品 (±20% 价格范围)
2. 同类型/同用途产品
3. 销量/热度排名靠前
4. 去除停售/过时产品
5. 保留2-3个同品牌产品作为参照

### Step 4: 获取对比数据
```python
对比数据源 = [
    "权威评测网站评分",
    "电商平台用户评价",
    "专业论坛口碑",
    "规格参数对比表"
]
```

### Step 5: 生成对比报告
按标准模板输出，包含：
- 基本信息对比表
- 关键差异分析
- 专业评测参考
- 选购建议
- 参考链接

## 数据时效性规范

| 数据类型 | 有效期 | 标注要求 |
|----------|--------|----------|
| 官方规格 | 长期有效 | 标注来源日期 |
| 价格信息 | 实时 | 标注查询日期 |
| 评测分数 | 6个月内 | 标注评测日期 |
| 用户评分 | 3个月内 | 标注聚合日期 |

## 输出质量标准

1. **准确性**: 所有数据需有明确来源
2. **客观性**: 不偏向特定品牌，基于事实
3. **实用性**: 根据用户场景给出可操作建议
4. **完整性**: 涵盖用户关心的主要维度
5. **时效性**: 标注数据获取日期
