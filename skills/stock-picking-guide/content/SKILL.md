# 股票选股实战指南

## 核心框架

**核心原则**：先选板块 → 再选个股 → 等对买点 → 设好止损 → 做好记录

## 一、选股核心思路

### 三步走策略

1. **看大势**：找到当前资金最关注的板块
2. **定龙头**：在板块里找到最强的股票
3. **找买点**：等合适的时机进去

### 五大核心原则

| 原则 | 内容 |
|------|------|
| 原则一 | 先板块后个股：板块不对，个股再好也别买 |
| 原则二 | 止损比赚钱重要：亏5%就走，别犹豫，保住本金第一 |
| 原则三 | 每笔交易都记录：记下来才能复盘，复盘才能进步 |
| 原则四 | 大盘不好就空仓：60日线下不操作，不亏就是赚 |
| 原则五 | 别用急钱炒股：用闲钱，心态好，操作才不变形 |

## 二、热点板块判断

### 三个信号

| 信号类型 | 判断方法 | 来源 |
|----------|----------|------|
| 资金信号 | 连续3日净流入前5名板块 | 东方财富APP |
| 新闻信号 | 同一关键词出现3次以上 | 财联社APP |
| 涨幅信号 | 板块涨幅前3名，且5只以上涨停 | 同花顺APP |

### 判断标准

- 三个都满足 → 强主线，重点跟
- 满足2个 → 主线，可以跟
- 只满足1个 → 一日游，别碰

### 热点持续性

| 类型 | 持续时间 | 操作策略 |
|------|----------|----------|
| 国家政策类 | 1-3个月 | 重点跟 |
| 产品涨价类 | 2-6周 | 可以跟 |
| 突发事件类 | 3-10天 | 快进快出 |
| 纯炒作类 | 1-3天 | 别碰 |

## 三、龙头股选择

### 两种龙头对比

| 类型 | 市值 | 特征 | 适合人群 |
|------|------|------|----------|
| 情绪龙头 | 30-150亿 | 最先涨停，连板最多 | 有时间盯盘者 |
| 中军龙头 | >300亿 | 走势稳，机构多 | 上班族 |

### 情绪龙头5个特征（满足4个以上是真龙头）

1. 板块里最先涨停，9:35前最好
2. 涨停封单大于5万手
3. 连板大于等于2天
4. 换手率大于5%
5. 日成交额大于3亿

### 买不进龙头怎么办

| 情况 | 应对方案 | 期望收益 |
|------|----------|----------|
| 龙头一字涨停 | 买龙二、龙三 | 5%-7% |
| 龙头已3连板 | 找板块补涨股 | 3%-5% |
| 第一波已结束 | 等回调，打回马枪 | 10%-20% |
| 什么都没赶上 | 空仓等下次 | 不亏就是赚 |

## 四、买点判断

### 三个最佳买点

| 买点 | 特征 | 建议仓位 | 成功率 |
|------|------|----------|--------|
| 突破买点 | 放量突破60日新高，量>5日均量2倍 | 30% | 60% |
| 回踩买点 | 回踩20日均线不破，缩量至前期50% | 20% | 70% |
| 二波买点 | 横盘5-10日后再次放量启动 | 30% | 50% |

### 绝对不能买的情况

- 股价在60日均线下方
- 成交量小于5000万/天
- 30日内有大额解禁
- 大股东正在减持
- 被ST或立案调查
- 连续2季度业绩下滑

## 五、卖点判断（止损止盈）

### 止损表

| 股票类型 | 止损位 |
|----------|--------|
| 龙头股 | 亏损8% |
| 龙二 | 亏损5% |
| 龙三及以后 | 亏损3% |
| 跌破20日线 | 至少卖一半 |
| 跌破60日线 | 全部卖 |

### 止盈表

| 涨幅 | 操作 |
|------|------|
| 5%-10% | 拿着，止损上移到成本价 |
| 10%-20% | 拿着，止损上移到盈利5%处 |
| 20%-30% | 卖一半，剩下继续拿 |
| >30% | 分批卖，别想赚最后一块钱 |

### 看龙头脸色卖股法

- 龙头继续涨停 → 持有
- 龙头涨停打开 → 卖一半
- 龙头跌3% → 全部卖
- 龙头跌停 → 第二天集合竞价跑

## 六、仓位管理

### 总仓位控制

| 大盘状态 | 建议仓位 |
|----------|----------|
| 在20日线上，成交量放大 | 70%-100% |
| 在20-60日线之间 | 30%-50% |
| 在60日线下 | 0%-20% |

### 单只股票仓位上限

| 股票类型 | 仓位上限 |
|----------|----------|
| 龙头股 | 50% |
| 龙二龙三 | 30% |
| 补涨股/埋伏股 | 20% |

### 加仓规则

1. 只有盈利了才能加仓
2. 每次加仓不超过原仓位的50%
3. 最多加仓2次
4. 加仓后止损位上移

## 七、指标使用

### 指标优先级

| 指标 | 重要性 | 说明 |
|------|--------|------|
| 成交量 | 5星，必须看 | 最真实，骗不了人 |
| 均线 | 5星，必须看 | 简单直观，支撑压力 |
| MACD | 3星，可参考 | 滞后，适合验证 |
| 筹码峰 | 2星，可以不看 | 太复杂，散户用不好 |
| KDJ/RSI | 1星，别看 | 容易误导 |

### 三条均线

| 均线 | 代表含义 |
|------|----------|
| 20日线 | 短期趋势，线上持有线下卖 |
| 60日线 | 中期趋势，线上可做线下别碰 |
| 250日线 | 长期趋势，线上牛市线下熊市 |

### 买入前检查表（3个指标）

1. 成交量是否放大，大于5日均量1.5倍
2. 股价是否在20日线上
3. 板块资金是否净流入

| 结果 | 操作 |
|------|------|
| 3个"是" | 可以买 |
| 2个"是" | 谨慎买 |
| 1个或0个"是" | 别买 |

### 卖出前检查表

1. 是否亏损达到止损位（负5%）
2. 是否跌破20日均线
3. 板块资金是否开始流出

| 结果 | 操作 |
|------|------|
| 满足1个 | 减仓 |
| 满足2个 | 卖一半 |
| 满足3个 | 全部卖 |

## 八、复盘方法

### 每日复盘记录字段

日期、主线板块、龙头股、龙二龙三、你的操作、买入理由、买入价、止损价、目标价、卖出价、盈亏、复盘总结

### 每周复盘问题

- 本周赚了多少，亏了多少
- 哪笔交易最成功，为什么
- 哪笔交易最失败，为什么
- 下周主线可能是哪个板块
- 有没有需要清理的股票

### 每月复盘问题

- 本月收益率是多少，跑赢大盘了吗
- 哪种方法最有效
- 哪种错误犯得最多
- 下个月需要改进什么

## 十、快速检查清单

### 买入前检查

- [ ] 板块是主线吗（3个信号满足2个以上）
- [ ] 是龙头或龙二吗
- [ ] 成交量放大大于5日均量1.5倍
- [ ] 股价在20日线上
- [ ] 板块资金净流入
- [ ] 设好止损价（负5%）
- [ ] 仓位合适（单只不超过50%）

### 卖出前检查

- [ ] 达到止损位了吗
- [ ] 跌破20日线了吗
- [ ] 板块热度退了吗
- [ ] 龙头跌停了吗
- [ ] 买了5天还不涨吗

## 十一、常见错误避免

1. **看到涨就追** → 等回踩或突破再买
2. **亏了死扛** → 设止损，无条件执行
3. **满仓一只股** → 单只不超过50%
4. **听消息买** → 只看新闻、资金、技术
5. **不记录** → 每笔交易都记
6. **频繁换股** → 一只股至少拿3天
7. **大盘不好还猛干** → 60日线下空仓
8. **买太多股票** → 同时不超过3只
9. **想赚每一波** → 只做自己看得懂的
10. **不休息** → 连续亏2天休息3天

## 十二、最后5句话（记住就能活下来）

1. **先选板块，再选个股** — 别看到股票就买
2. **买之前想好亏多少走** — 止损比赚钱重要
3. **每笔交易都记下来** — 时间长了你就厉害了
4. **大盘不好就空仓** — 不亏就是赚
5. **别用急钱炒股** — 用闲钱，心态好
