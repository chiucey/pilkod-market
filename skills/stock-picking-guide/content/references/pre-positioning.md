# 提前埋伏方法

## 一、三类可埋伏的机会

### 政策类

- **埋伏时间**：提前1-3个月
- **信息来源**：
  - 国务院APP的政策吹风会
  - 部委官网的征求意见稿
  - 两会、政府工作报告
- **操作策略**：国家政策类热点能持续1-3个月

### 涨价类

- **埋伏时间**：提前2-4周
- **信息来源**：
  - 同花顺期货栏目
  - 大宗商品价格走势
  - 行业协会数据
- **操作策略**：产品涨价类热点能持续2-6周

### 业绩类

- **埋伏时间**：提前1-2个月
- **信息来源**：
  - 东方财富数据研报栏目
  - 个股业绩预告
  - 行业景气度数据
- **操作策略**：业绩超预期时可能启动

## 二、期货与股票对应关系

| 期货品种 | 对应板块 |
|----------|----------|
| 原油 | 油气开采、石化 |
| 铜 | 有色金属 |
| 锂 | 锂电池、新能源车 |
| 黄金 | 黄金股 |
| 煤炭 | 煤炭开采 |

**判断方法**：期货连续涨3天，可以埋伏对应股票

## 三、埋伏仓位管理

| 阶段 | 仓位 | 说明 |
|------|------|------|
| 刚发现信号 | 10%-20% | 试试水，错了不心疼 |
| 信号确认 | 30%-40% | 加仓 |
| 开始上涨 | 50%-60% | 持有 |
| 大涨后 | 逐步卖 | 兑现利润 |

**重要**：永远别一上来就满仓埋伏

## 四、埋伏注意事项

1. **分批建仓**：不要一次全买
2. **设止损**：埋伏失败及时出局
3. **控制仓位**：单次埋伏不超过20%
4. **跟踪验证**：持续关注信号是否强化
5. **有耐心**：埋伏需要时间等待

## 五、埋伏失败的处理

| 情况 | 处理方法 |
|------|----------|
| 1个月内没启动 | 考虑减仓或出局 |
| 跌破埋伏价5% | 止损出局 |
| 发现更好机会 | 换股，调仓 |
| 大盘变差 | 跟随大盘处理 |
