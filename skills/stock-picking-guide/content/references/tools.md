# 必备工具清单

## 一、必备APP

| APP | 用途 | 每日使用时间 |
|-----|------|-------------|
| 财联社 | 看新闻、电报 | 10分钟 |
| 同花顺 | 看行情、选股 | 20分钟 |
| 东方财富 | 看资金流、龙虎榜 | 10分钟 |
| 国务院APP | 看政策吹风会 | 每周10分钟 |

## 二、各APP核心功能

### 财联社

- 电报栏目：实时财经快讯
- 关键词追踪：记录同一关键词出现频率
- 使用技巧：每天8:30前刷一遍，记录3个高频关键词

### 同花顺

- 行情-板块-涨跌幅：看板块排名
- 行情-板块-资金流向：看资金进出
- 问财：自定义选股公式
- 涨停股排名：找情绪龙头

### 东方财富

- 资金流向：查看板块/个股净流入
- 龙虎榜：查看大资金买卖
- 数据中心：查看个股资金进出
- 研报栏目：查看机构研报

### 国务院APP

- 政策吹风会：提前了解政策导向
- 征求意见稿：预判政策方向
- 部委官网：查看具体政策文件

## 三、辅助工具

| 工具 | 用途 |
|------|------|
| Excel/表格 | 每日复盘记录 |
| 记事本 | 记录板块、龙头 |
