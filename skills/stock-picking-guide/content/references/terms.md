# 术语解释

## 基本术语

| 术语 | 解释 |
|------|------|
| 涨停 | 股价上涨10%（创业板20%）后停止交易 |
| 连板 | 连续多天涨停 |
| 封单 | 涨停价上的买单数量 |
| 开板/炸板 | 涨停被打开，股价下跌 |
| 龙一/龙二 | 板块里第一、第二个涨停的股票 |
| 中军 | 板块里市值最大、最稳的股票 |
| 补涨 | 龙头涨完后，其他股票跟随上涨 |
| 放量 | 成交量比平时明显放大 |
| 缩量 | 成交量比平时明显缩小 |
| 均线 | 过去N天收盘价的平均值连线 |
| 止损 | 亏损达到预设位置时卖出 |
| 止盈 | 盈利达到预设位置时卖出 |
| 仓位 | 投入股票的资金占总资金的比例 |
| 空仓 | 全部卖出，不持有任何股票 |
| 满仓 | 全部资金投入股票 |
| 龙虎榜 | 交易所公布的当日大额买卖记录 |

## 技术分析术语

| 术语 | 解释 |
|------|------|
| 金叉 | 短期均线上穿长期均线，看多信号 |
| 死叉 | 短期均线下穿长期均线，看空信号 |
| 突破 | 股价向上穿过重要阻力位 |
| 回踩 | 股价上涨后回调到均线/支撑位 |
| 支撑位 | 股价下跌时可能遇到买盘支撑的价格 |
| 压力位 | 股价上涨时可能遇到卖盘压力的价格 |

## 资金相关术语

| 术语 | 解释 |
|------|------|
| 净流入 | 买入金额减去卖出金额 |
| 主力资金 | 大单买卖的资金 |
| 换手率 | 成交量/流通股本×100% |
| 成交额 | 当日成交的总金额 |
