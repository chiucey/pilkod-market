# 同花顺问财选股公式

## 情绪龙头公式

```
市值 30到150亿
所属板块 等于 XXX
今日涨停
涨停时间 小于 9点40分
近1月涨停次数 大于等于 2
换手率 大于 5%
日成交额 大于 3亿
```

**用途**：筛选板块内的情绪龙头股

## 中军龙头公式

```
市值 大于 300亿
所属板块 等于 XXX
股价 站上20日均线
近5日主力资金净流入 大于 0
近1月涨幅 大于 板块涨幅
```

**用途**：筛选板块内的中军龙头股

## 补涨股公式

```
所属板块 等于 XXX
涨幅 小于 3%
市值 50到200亿
股价 站上20日均线
日成交额 大于 5000万
```

**用途**：筛选板块内的补涨机会

## 放量突破公式

```
股价 站上20日均线
今日成交量 大于 5日均量 1.5倍
近3日涨幅 大于 0
总市值 小于 500亿
```

## 回踩均线公式

```
股价 回踩20日均线 不破
今日成交量 小于 5日均量
近5日涨幅 大于 0
```

---

## 使用说明

1. 打开同花顺APP
2. 点击「问财」或「选股」
3. 输入以上公式
4. 将「XXX」替换为目标板块名称
5. 根据筛选结果结合人工判断
