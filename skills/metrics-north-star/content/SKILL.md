# 产品指标体系与北极星指标搭建技能

## 技能定义

通过科学的指标体系设计方法，构建从北极星指标到细分指标的完整体系，搭建数据埋点方案和监控体系，支撑产品精细化运营决策。

## 核心SOP

### 步骤1：北极星指标定义

**北极星指标标准**：

| 标准 | 说明 | 检查 |
|------|------|------|
| 清晰可衡量 | 是一个具体数字 | □是 □否 |
| 反映用户价值 | 与用户价值正相关 | □是 □否 |
| 可操作 | 团队可影响/改变 | □是 □否 |
| 领先指标 | 是结果的前瞻信号 | □是 □否 |
| 单一性 | 避免多目标冲突 | □是 □否 |

**北极星指标候选**：

| 指标 | 候选度 | 理由 |
|------|-------|------|
| DAU | □高 □中 □低 | [理由] |
| WAU | □高 □中 □低 | [理由] |
| GMV | □高 □中 □低 | [理由] |
| 付费用户数 | □高 □中 □低 | [理由] |
| 核心行为完成数 | □高 □中 □低 | [理由] |
