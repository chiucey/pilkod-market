# 专利文献检索与综述技能

## 概述

本技能从专利文档PDF中提取关键技术术语，构建PubMed检索式，筛选最相关的文献并生成现有技术报告。

## 工作流程

### 步骤1：提取专利关键信息

使用 `extract_pdfs_key_info` 工具从PDF中提取：
- 技术领域关键词
- 发明摘要中的核心概念
- 权利要求书中的关键技术点

**提取提示词**：
```
请提取以下信息：
1. 技术领域（如：生物医药、化学、材料等）
2. 发明名称和摘要中的关键技术术语
3. 权利要求中的关键方法/化合物/技术特征
4. 任何药物名称、基因名称、蛋白质名称、疾病名称
```

### 步骤2：构建检索式

根据提取的关键词构建PubMed检索式：

1. **关键词组合策略**：
   - 主要技术概念作为主要检索词
   - 使用 MeSH 术语增强精确度
   - 使用布尔运算符 (AND/OR) 连接

2. **检索式格式**：
   ```
   (关键术语1 OR 关键术语2) AND (关键技术特征)
   ```

3. **检索限制**：
   - 仅限英文文献
   - 优先最近5年的文献（可根据需要调整）
   - 排除专利文献（pubmed[dp] NOT patent[pt]）

### 步骤3：执行PubMed检索

使用 `mcp__matrix__batch_web_search` 工具或直接通过 E-utilities API 执行检索。

**PubMed E-utilities 检索端点**：
- ESearch: `https://eutils.ncbi.nlm.nih.gov/entrez/eutils/esearch.fcgi?db=pubmed&term=<检索式>&retmax=20&retmode=json`

### 步骤4：相关性筛选

根据以下标准筛选最相关的5篇文献：

1. **相关性评分标准**：
   - 技术相关性：文献内容与专利技术的匹配程度
   - 引用频率：高被引文献优先
   - 发表时间：优先近期文献，但经典文献可保留
   - 期刊影响力：高影响力期刊优先

2. **筛选流程**：
   - 获取前20篇候选文献
   - 逐一评估与专利技术的相关性
   - 选择综合评分最高的5篇

### 步骤5：生成综述报告

为每篇筛选出的文献提取：
- 文章标题
- 作者及机构
- 发表期刊和年份
- 研究摘要
- 与专利技术的相关性说明

**报告格式**：
```markdown
# 专利相关现有技术文献综述

## 专利信息
- 技术领域：[领域]
- 关键技术点：[关键词]

## 相关文献综述

### 文献1：[标题]
- **作者**：xxx等
- **期刊/年份**：xxx, 2024
- **研究内容**：[摘要]
- **与本专利相关性**：[说明]

...（共5篇）

## 结论
[总结现有技术状况和专利创新点]
```

## 注意事项

1. **PDF处理**：如果PDF是扫描件或包含大量图片，使用 `extract_pdfs_full_content` 获取完整内容
2. **检索优化**：如果检索结果过多，使用更精确的检索词；如果过少，放宽检索条件
3. **API限制**：PubMed E-utilities 有访问频率限制，批量请求时注意添加延迟
4. **语言**：用户使用中文，报告输出为简体中文

## 复盘与迭代流程

每次完成检索任务后，必须执行以下复盘流程：

### 复盘检查项

1. **检索完整性**：是否覆盖了专利的所有关键技术点？
2. **结果相关性**：筛选的文献是否真正相关？是否有遗漏的重要文献？
3. **检索效率**：检索式是否过于宽泛或狭窄？需要优化的地方？
4. **输出质量**：报告内容是否准确、完整、格式规范？

### 复盘记录

每次复盘后，在 `references/search-strategy.md` 的复盘记录表中填写：

| 必填字段 | 说明 |
|----------|------|
| 日期 | 本次复盘日期 |
| 任务 | 对应的专利文档名称 |
| 问题 | 本次检索中发现的不足 |
| 解决方案 | 针对问题的改进措施 |
| 更新内容 | 对检索策略的修改说明 |

### 策略更新触发条件

当出现以下情况时，必须更新 `search-strategy.md`：

- 发现新的有效检索词/同义词
- 原有检索式效果不佳，需要调整
- 遇到新的PDF格式或特殊处理需求
- 筛选标准需要调整
- 发现API使用的限制或注意事项
