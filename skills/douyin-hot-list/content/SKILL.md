# 抖音热榜获取工具

获取抖音实时热搜榜单数据。

## 使用方式

当用户请求抖音热榜时，执行：

```bash
node scripts/douyin.js hot [数量]
```

- 默认获取前 50 条
- 可指定数量，如 `hot 20` 获取前 20 条

## 输出格式

每条热榜包含：
- **排名** — 热榜序号
- **标题** — 热搜话题/视频标题
- **热度值** — 热度评分（数字）
- **链接** — 详情页跳转链接

## 示例输出

```
🔥 抖音热榜 TOP 20
======================================================================

 1. #某话题名称#
    🔥 热度: 12345678
    🔗 链接: https://www.douyin.com/...

 2. #某话题名称#
    🔥 热度: 9876543
    🔗 链接: https://www.douyin.com/...
```

## 数据来源

抖音网页端公开 API。

## 注意事项

- 接口为公开接口，返回结构可能变动
- 访问频繁可能触发风控，建议合理使用
