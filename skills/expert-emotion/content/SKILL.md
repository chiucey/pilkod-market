# 情感共鸣设计专家

## 核心能力

设计情感场景，让读者与角色产生深度共情。覆盖：甜宠、虐心、亲情、友情、师徒情、兄弟情等全部情感维度。

## 情感场景类型

### 甜宠场景（正向情感）

- **日常撒糖**：不经意的小动作（记住对方随口说的话、受伤时第一时间出现）
- **高光守护**：主角在众人面前护短，台词要有记忆点
- **反差软化**：冷酷/强大角色在特定人面前展露柔软面（"只有你能这样跟我说话"）
- **共同成长**：两人一起变强，互相成就

### 虐心场景（负向情感，慎用）

- **遗憾美**：差一步就能在一起/成功，但错过
- **牺牲虐**：为保护对方/大义主动赴死，临别遗言要简洁有力
- **误解虐**：明明深爱却因误会疏远，知道真相时已无法挽回
- **回忆杀**：现在时叙事中插入闪回，形成情感对比

### 亲情/师徒情场景

- **严父型**：表面严厉，关键时刻为徒弟挡下致命一击
- **慈母型**：日常絮叨叨，实际早已铺好所有退路
- **亦师亦友型**：一起冒险、共同成长，身份感模糊

## 情感五感写作法

```
视觉（眼睛红了/紧握的手）+
听觉（声音发抖/沉默的空气）+
触觉（冰凉的指尖/灼热的胸膛）+
嗅觉（熟悉的草药香）+
心理（心跳漏了一拍）= 沉浸式情感场景
```

**禁忌**：不要用"他很开心""她很感动"等直接描述，用具体行为替代。

## 番茄短篇情感公式

```
建立羁绊（200字：相遇/互相看不顺眼）→
日常暖心或矛盾积累（500字）→
危机/冲突爆发（300字：检验羁绊）→
情感高潮（200字：行动证明/告白）→
余韵结尾（100字：一句台词或画面收尾）
```

## 情感锚点技术

在故事开头设置一个**情感锚点**（一个物品、一句话、一个画面），在故事高潮或结尾重新出现，形成情感闭环：

> 开头："那枚铜铃是他留给我的唯一信物。"
> 结尾："铃声再次响起，他终于回来了。"

## 常见错误

- 情感来得太快：没有足够的日常铺垫，情感会显得假
- 台词太满：情感场景要"留白"，沉默往往比千言万语更有力
- 只有主角有情感：配角的情感真实性会反过来强化主角
