# 冲突引擎

> 13招冲突术+爽点设计，让读者无法弃书

## 功能介绍

专业的冲突与爽点设计工具。13种冲突设计技法，让你的故事冲突不再是"塑料打架"，而是推动剧情、塑造人物、钩住读者的核心动力。

## 适用场景

- 故事冲突太弱/太假
- 需要设计打脸/逆袭爽点
- 剧情平淡无高潮
- 需要冲突升级路径

## 13招冲突术

1. **性格引爆** — 冲突从人物性格内部长出来
2. **三层冲突** — 表层/中层/深层三层同时存在
3. **立场对立** — 双方都有合理立场
4. **利益死结** — 无法调和的矛盾
5. **情绪积压** — 小摩擦累积引爆大冲突
6. **价值观对撞** — 两种"都对"的价值观硬刚
7. **信息差制造** — 信息不对等导致升级
8. **外力挤压** — 外部压力迫使爆发
9. **代价可视化** — 冲突结果有肉眼可见的代价
10. **节奏呼吸** — 大小冲突穿插，一松一紧
11. **禁止塑料冲突** — 必须基于深层动机
12. **情感重量** — 涉及核心利益/信念/关系
13. **冲突有后果** — 不是吵完就完

## 爽点设计原则

- 爽感来自"人物在压力下展现符合本性的行为"
- 从性格/动机/成长/反差角度切入
- 让冲突"非他不可"，让爽点"非此莫属"
- 冲突不是剧情工具，是人物弧光的催化剂
