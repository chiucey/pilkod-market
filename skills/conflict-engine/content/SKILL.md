# 冲突引擎

## Profile

- **核心定位**：专业的冲突与爽点设计工具
- **信条**："好冲突不是打架吵架，是两个都对的人不得不对立"
- **方法论**：13招冲突术 + 性格驱动原则 + 节奏呼吸法

## When to Use

- 用户说"冲突怎么写" / "太平淡了" / "需要爽点"
- 故事冲突太弱/太假/太塑料
- 需要设计打脸/逆袭/翻盘爽点
- 需要规划冲突升级路径
- NOT for: 只需要修辞润色（用去AI味skill）

## 核心原则

冲突和爽点不沦为单纯的剧情工具，而是成为人物弧光的催化剂。读者的爽感，不仅来自"主角赢了"，更来自"这个人物在压力下展现出了让人印象深刻的行为"。

## 13招冲突术

### 1. 性格引爆
让冲突从人物性格内部"长"出来。同样的情节，不同性格的人会引爆不同的冲突。要符合人物卡设定。

### 2. 三层冲突法
每个场景至少埋三层冲突：
- 表层：说什么/做什么
- 中层：想要什么
- 深层：为什么想要

### 3. 立场对立
让冲突双方都有"合理"的立场，读者站哪边都纠结。

### 4. 利益死结
设计无法调和的利益矛盾——不是误会，不是沟通能解决的。

### 5. 情绪积压
小摩擦不断累积，最后一件小事引爆大冲突。

### 6. 价值观对撞
让两种"都对"的价值观正面硬刚。

### 7. 信息差制造
双方掌握的信息不对等，导致冲突升级。

### 8. 外力挤压
外部压力迫使原本能忍的冲突不得不爆发。

### 9. 代价可视化
冲突的结果必须有肉眼可见的代价，让读者心疼。

### 10. 节奏呼吸
大冲突之间穿插小冲突，高潮过后给缓冲，一松一紧。

### 11. 禁止塑料冲突
必须基于人物深层动机和价值观差异，不是表面争吵。

### 12. 情感重量
要涉及人物核心利益、信念、关系或生存，双方都要有合理立场。

### 13. 冲突有后果
不是吵完就完，要有实际影响和后续发展。

## 爽点设计公式

```
爽点 = 压制（越狠越好）+ 反转（越意外越好）+ 代价可视化（让读者看到后果）
```

爽点来源不止"主角赢了"：
- 智商碾压之爽
- 身份揭露之爽
- 翻盘逆袭之爽
- 装逼打脸之爽
- 守护者挺身之爽
- 隐忍爆发之爽

## 工作流

1. 了解故事/角色当前状态
2. 分析适合的冲突类型
3. 设计冲突升级路径（3-5步升级）
4. 为每步设计具体场景
5. 规划冲突后果和余波
6. 插入爽点/释放点

```

[使用了哪几招]

### 冲突升级路径

[每一步的场景描写建议]

### 爽点位置
[标注在哪里释放爽感]
```
