# 全屋智能方案生成器参考文档

本参考文档提供详细的示例、边缘情况处理和场景模板，帮助更准确地生成专业的智能家居方案大纲。

## 场景一：适老化改造需求

### 典型客户对话示例

```
服务商：王先生您好，您之前提到想给老人房做智能化改造，能具体说说老人的生活情况吗？
客户：是的，我妈今年78岁了，腿脚不太方便，晚上起夜总是摸黑找开关，好几次差点摔倒。我就想让她住着安全点、方便点。
服务商：明白，那老人房的光线问题是首要解决的。另外老人对温度敏感吗？空调使用频率高吗？
客户：温度倒是还好，主要是晚上起夜这个事。还有我想在客厅也装个摄像头，这样我上班的时候能看看她的情况。
服务商：好的，我们来看看具体怎么规划...
```

### 生成的方案大纲示例

**Slide 2：项目概况与客户需求洞察**

- 客户画像：三代同堂家庭，78岁老人独居一室，子女远程关怀需求强
- 核心诉求：
  - 老人房夜间智能照明，感应亮灯防摔倒
  - 客厅安防监控，子女远程看护
  - 简化操作，一键控制
- 项目预算：待进一步确认

**Slide 3：全屋智能设计理念**

以“安全守护、简单易用”为核心，为长者打造无障碍的智慧生活环境，让科技成为温暖的陪伴。

**Slide 5：专属智慧生活场景**

**夜间微光感应模式**：当老人夜间起身，脚一落地，床边的地脚灯自动亮起柔和的暖光，既不刺眼又能照亮行走路径。走到卫生间门口时，廊灯无缝衔接亮起，全程无需任何操作。起身回床后，灯光在老人入睡后自动缓缓熄灭。

## 场景二：年轻家庭，有小孩和宠物

### 典型客户对话示例

```
服务商：李女士，我看您家是140平的，对吧？请问主要是谁住？
客户：我们一家三口，还有两只猫。我老公经常出差，我一个人带孩子。
服务商：明白了。那您最想解决什么问题？
客户：一个是早上叫孩子起床太难了，怎么叫都不起。还有就是我想控制孩子看动画片的时间，
每次都要去把电视拔电，太麻烦了。另外我那两只猫，我不在家的时候也担心。
服务商：完全理解，这些都是很实际的需求，我们来看看怎么规划...
```

### 生成的方案大纲示例

**Slide 2：项目概况与客户需求洞察**

- 客户画像：140平三口之家，育有一娃、养有双猫，全职妈妈独自带娃
- 核心诉求：
  - 儿童房智能唤醒，解决起床困难
  - 影音娱乐管控，控制孩子屏幕时间
  - 宠物远程看护，随时掌握猫咪动态
- 项目预算：8-12万元（参考范围）

**Slide 3：全屋智能设计理念**

以“智慧带娃、轻松生活”为主题，用科技减轻妈妈的管理负担，让亲子时光更加温馨有趣。

**Slide 5：专属智慧生活场景**

**魔法唤醒模式**：每天早上7点，窗帘缓缓拉开25%，让晨光自然透入。5分钟后，床头音箱开始播放孩子喜欢的轻快音乐，灯光逐渐从暖黄过渡到明亮。当孩子终于坐起身穿衣时，房间温度已悄然调至舒适的22度。

**安心离家模式**：出门时一键启动离家模式，灯光全部关闭，摄像头进入警戒状态。您可以在手机上随时查看客厅和猫咪活动区的实时画面，还可双向语音喊话，远程和猫咪互动。

## 场景三：追求极简美学的年轻业主

### 典型客户对话示例

```
服务商：张先生，我看您的房子是现代简约风格的装修，智能化方面您有什么想法？
客户：我不想要那种到处都是开关、面板的感觉。我想要一个干净整洁的空间，所有东西都藏在
看不见的地方，用起来却很方便。
服务商：明白，您追求的是“隐形智能”。那控制方式上您偏好哪种？手机、语音、还是自动化？
客户：手机能控制就好，语音太傻了。我希望设备能在我需要的时候自动工作，不需要我操心。
服务商：完全理解“无感智能”的理念，我们来具体规划...
```

### 生成的方案大纲示例

**Slide 2：项目概况与客户需求洞察**

- 客户画像：130平改善型住房，单身/年轻夫妻，追求极简美学和“无感智能”体验
- 核心诉求：
  - 极简空间美学，拒绝杂乱开关
  - 无感化控制，设备主动服务
  - 全屋灯光窗帘统一联动
- 项目预算：15-20万元

**Slide 3：全屋智能设计理念**

以“极简无痕、科技无感”为设计哲学，让智能成为空间的自然延伸，而非入侵者。每一处细节都为美学让步，每一次交互都恰到好处。

**Slide 5：专属智慧生活场景**

**极简归家模式**：指纹解锁门锁的瞬间，玄关的感应灯以20%亮度亮起，不刺眼却足够找到拖鞋。进门后，客厅的主灯缓缓亮至60%，窗帘自动拉开一半，空调已提前调至舒适温度。整个过程无需掏出手机，无需开口说话。

**光影随行模式**：坐在沙发上准备看电影，只需说一句“小维，影院模式”，窗帘自动拉满，灯光渐暗至10%，电视旁的氛围灯带亮起柔和的蓝紫色调。观影结束后，一切恢复原状，如同一位贴心的管家。

## 边缘情况处理

### 情况一：客户信息严重不足

当对话记录中客户信息较少时：

- 客户画像：标注为“信息有限，待进一步沟通确认”
- 核心诉求：只提取明确提及的需求，未提及的标注“待挖掘”
- 设计理念：使用通用描述，如“打造专属智慧家”

### 情况二：客户需求相互矛盾

当客户提出矛盾需求时（如既想要极简又想要很多控制面板）：

- 在方案中体现“定制化”的平衡解决方案
- 强调“按需配置、分步实现”的灵活性
- 在服务计划中标注需进一步确认

### 情况三：预算与需求不匹配

当客户期望的功能超出预算时：

- 在方案中体现“核心需求优先”的分级策略
- 建议“分期实现”的升级路径
- 诚实标注预算差距，不夸大承诺

## 子系统配置参考

### 智能照明系统

**配置思路**：根据家庭结构和采光情况，采用人体感应+光照感应双重策略

**解决的问题**：

- 夜间起夜安全照明
- 儿童护眼学习灯光
- 老人友好的一键总控
- 迎宾氛围灯光

### 智能安防系统

**配置思路**：采用“周界防护+室内监护+远程查看”三层防护

**解决的问题**：

- 门窗入侵报警
- 烟雾/燃气泄漏预警
- 老人跌倒检测（可选）
- 远程看护

### 智能遮阳/温控系统

**配置思路**：基于光照感应和时间策略的自动化控制

**解决的问题**：

- 夏季隔热降温
- 冬季保温节能
- 保护隐私
- 老人无需手动操作

### 影音娱乐系统

**配置思路**：与灯光窗帘联动，一键场景切换

**解决的问题**：

- 家庭影院一键启动
- 背景音乐分区控制
- 儿童娱乐时间管理
- 宠物独处安抚

## 服务计划标准流程

1. **现场细化勘测**：上门测量实际尺寸，确认设备安装位置
2. **点位图输出**：绘制详细的设备布置图和布线图
3. **预算明细确认**：提供详细的设备清单和报价单
4. **进场施工交底**：与装修施工方协调，确保预埋和布线到位
