## 六大思想体系概览

### 1. Charles Dow · 测量者操作系统
- **核心**：市场是晴雨表，不是预测工具
- **关键**：趋势确认、收盘价为锚、双指数验证、成交量确认
- **贡献**：趋势分析的基本框架

### 2. Alan Farley · 波段交易大师
- **核心**：捕捉趋势的中期波动（2天-6周）
- **关键**：Setup识别、支撑阻力、入场时机、止损纪律
- **贡献**：具体的交易策略框架

### 3. Benoit Mandelbrot · 分形混沌先驱
- **核心**：市场具有自相似性，粗糙度蕴含信息
- **关键**：幂律分布、分形维数、多重分形
- **贡献**：理解市场非线性和极端事件

### 4. Nassim Taleb · 反脆弱大师
- **核心**：从混乱中获益，构建反脆弱系统
- **关键**：黑天鹅、杠铃策略、尾部风险、Skin in the Game
- **贡献**：风险管理和不确定性思维

### 5. Warren Buffett · 价值投资大师
- **核心**：买股票就是买公司的一部分
- **关键**：护城河、安全边际、能力圈、集中投资
- **贡献**：长期投资视野和价值评估

### 6. William Gann · 周期预测大师
- **核心**：时间是最重要的因素
- **关键**：时间-价格平衡、周年效应、止损纪律
- **贡献**：周期分析和时间窗口

## 核心心智模型

### 模型1: 多时间框架趋势分析（Dow + Farley）

**一句话**：先用长期趋势过滤噪音，再在中期趋势中寻找波段机会。

**框架**：
```
┌─────────────────────────────────────────┐
│         三层趋势框架                    │
├─────────────────────────────────────────┤
│                                         │
│  主要趋势（1年以上）                   │
│  → Dow确认：等双指数确认反转信号       │
│  → 这是方向，不是预测                   │
│                                         │
│  次级趋势（3周-3个月）                 │
│  → Farley Setup：回调买入/突破入场     │
│  → 这是波段机会                         │
│                                         │
│  日间波动（噪音）                       │
│  → 忽略短期波动                        │
│  → 收盘价为锚                          │
│                                         │
└─────────────────────────────────────────┘
```

**应用**：
1. 首先确认主要趋势方向（Dow双指数验证）
2. 识别次级趋势中的回调或突破机会（Farley Setup）
3. 在日间波动中保持冷静，收盘价为锚
4. 永远顺着主要趋势交易

---

### 模型2: 分形市场结构（Mandelbrot）

**一句话**：市场在不同时间框架下呈现自相似模式，极端波动比正态分布预测的更频繁。

**核心洞察**：
```
传统观点（正态分布）：
- 极端事件极其罕见
- 99.7%的价格变动在±3σ内
- 风险可以被精确量化

Mandelbrot观点（幂律分布）：
- 极端事件比想象的更频繁
- 价格变动服从幂律分布
- 分形维数描述市场粗糙度

关键数字：
- 股票收益分布指数 ≈ 3.0
- 波动聚集效应
- 多重分形结构
```

**应用**：
1. 用分形维数评估市场粗糙度
2. 警惕"肥尾"——极端事件的可能性
3. 在不同时间框架中寻找自相似模式
4. 波动率聚类时提高警觉

---

### 模型3: 反脆弱风险管理（Taleb）

**一句话**：不赌命，用杠铃策略在保持安全的同时保留暴富机会。

**杠铃策略**：
```
传统策略：中等风险，中等收益
    ↓
    看似平衡
    ↓
    实际上脆弱

杠铃策略：
低风险 ────── 高风险
   ↓           ↓
  极度保守    极度激进
    ↓           ↓
   90%         10%
    ↓           ↓
  稳定本金    无限上行

投资组合应用：
90% 极度保守：国债、现金、黄金
10% 极度激进：期权、小盘股、创业投资
```

**风险管理原则**：
1. **不赌命**：永远不投资可能摧毁你的东西
2. **尾部对冲**：购买保护性期权
3. **保持冗余**：持有现金，不过度杠杆
4. **快速修复**：允许小失败，避免大崩溃
5. **Skin in the Game**：用自己钱交易，承担后果

---

### 模型4: 价值锚定（Buffett）

**一句话**：以企业内在价值为锚，在安全边际足够大时买入。

**核心公式**：
```
内在价值 = 未来现金流折现

安全边际 = 内在价值 - 当前价格

买入条件：
- 价格 < 内在价值 × 0.7
- 护城河宽阔且可持续
- 管理层值得信任
- 在能力圈内
```

**价值+趋势结合**：
- 在Dow确认的上升趋势中买入被低估的股票
- 用Farley的Setup确认具体入场时机
- 用Mandelbrot的分形视角评估估值极端性
- 用Taleb的风险管理控制下行风险

---

### 模型5: 时空周期（Gann）

**一句话**：时间是判断趋势最重要的因素，历史会重演。

**核心法则**：
1. **时间-价格平衡**：当特定交易日数对应特定价格单位时，趋势必反
2. **周年纪念日**：历史高低点在经过特定周期（1年、7年、30年）后倾向于重复
3. **回调位**：50%是最重要的支撑/阻力位，辅以八分位
4. **三重确认**：时间窗口 + 价格回调位 + 角度线交汇

**应用**：
1. 在周年纪念月提高警觉
2. 用7年、30年周期预判转折窗口
3. 结合Dow的趋势确认和Gann的时间窗口
4. 始终设止损，单笔损失不超过本金10%

---

### 模型6: 综合交易Setup（Farley强化版）

**高概率Setup的特征**：

1. **趋势一致性** — Setup方向与Dow确认的主要趋势一致
2. **多重确认** — Dow趋势 + Farley Setup + Mandelbrot分形 + Gann时间窗口
3. **明确风险/回报比** — 至少1:3，理想1:5
4. **Taleb检验** — 通过尾部风险评估和杠铃策略管理
5. **价值检验** — 有安全边际（Buffett）或接近关键支撑（Farley）

**经典Setup模式**：

- **上升通道突破** — 价格突破上升通道上沿（Dow确认）
- **回调买入** — 上升趋势中的回调至50%支撑位（Gann + Farley）
- **三角形突破** — 收敛形态的向上/向下突破（分形自相似）
- **双底/双顶** — 经典的反转形态（周年效应可能触发）
- **旗形/三角旗形** — 中继形态，趋势延续

## 决策启发式

### 1. 先测量，再判断（Dow）
**规则**：永远先描述市场现在是什么状态，再问它会往哪里去

### 2. 趋势确认才行动（Dow）
**规则**：等双指数确认反转信号，在此之前假设趋势持续

### 3. 波段只在趋势中（Farley）
**规则**：只在Dow确认的趋势中寻找Farley的波段机会

### 4. 分形视角评估（Mandelbrot）
**规则**：用幂律分布评估极端事件可能性，用分形维数量化粗糙度

### 5. 反脆弱检验（Taleb）
**规则**：问自己"最坏情况是什么？能摧毁我吗？有冗余吗？"

### 6. 价值锚定买入（Buffett）
**规则**：在安全边际足够大时买入，不追涨杀跌

### 7. 时间窗口警觉（Gann）
**规则**：在周年纪念月提高警觉，用周期预判转折

### 8. 三重确认入场
**规则**：趋势确认（Dow）+ 结构到位（Farley/Gann）+ 风险可控（Taleb）

### 9. 止损即纪律
**规则**：每笔交易必须设止损，单笔损失不超过本金10%

### 10. 记录预测
**规则**：入场前写下预期，包括价格目标和止损位

## 诚实边界

此Skill基于六大交易思想体系整合，存在以下**局限**：

- **预测能力有限**：即使整合多理论，也无法精确预测市场

- **市场条件**：不同市场环境下各理论的权重需调整
- **执行纪律**：所有理论的价值在于纪律执行
