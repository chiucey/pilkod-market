# 经济学研究选题生成器

## 工作流程

本技能将广泛搜索整理社会新闻讨论与经济学学术研究前沿，将现实现象与社会痛点与经济学学术热点和理论相结合，提出有价值且可行的研究问题。

### 第一步：关键词提取与信息收集准备

1. **分析用户输入**：
   - 从用户提供的**研究话题**中提取核心关键词
   - 从用户提供的**可用数据概况**（如有）中提取关键词
   - 如用户未提供数据概况或具体时期，设定搜索范围为**近10年**

2. **关键词扩展**：
   - 基于核心关键词，扩展同义词、近义词
   - 添加相关下位概念和上位概念
   - 识别中英文关键词

### 第二步：社会新闻与舆情广泛搜索

**必须使用 `batch_web_search` 工具**进行全面搜索，搜索范围包括：

1. **社会新闻搜索**：
   - 搜索引擎：综合搜索"关键词 近10年"
   - 新闻来源：官方媒体发布的政策新闻、热点事件报道
   - 社交媒体：微博、知乎等平台的热议话题和高赞讨论
   - 自媒体：微信公众号、头条号等点击量较高的分析文章
   - 官方文件：政府官方网站、政策法规文件

2. **搜索内容要求**：
   - 覆盖用户指定时期或近10年（2016-2026）
   - 识别社会关注焦点和矛盾点
   - 收集各方立场和诉求

### 第三步：学术研究全面搜索

**必须使用 `batch_web_search` 工具**搜索以下学术资源：

**指定期刊列表（近10年发表）**：
- **经济学顶刊**：AER, QJE, RES, JPE, Econometrica, EJ, REStat, AEJ系列, AER:Insight
- **应用经济学期刊**：JDE, JPubE, Labor Economics, JPopulationE, JEEM, JHE, JEBO, JIE
- **计量经济学期刊**：JEconometrics
- **欧洲经济学**：European Economic Review, China Economic Review
- **NBER working paper**
- **IZA working paper**
- **中科院一二区/高影响因子期刊**：JCL一区、影响因子10以上综合类科学期刊

**搜索策略**：
- 英文关键词 + 期刊名称/数据库名称
- 搜索近10年发表的研究
- 优先搜索高被引论文和最新发表

### 第四步：学术研究分析梳理

使用 `extract_content_from_websites` 工具深入分析重要学术论文，然后进行以下梳理：

1. **发表分布**：
   - 该话题主要发表在哪些期刊
   - 核心研究团队和代表性学者

2. **研究发展脉络**：
   - 研究问题的历史演变
   - 关键理论和方法的演进
   - 核心文献的时间线

3. **主要研究结论**：
   - 已形成共识的核心发现
   - 存在争议的分歧点
   - 政策含义

4. **研究局限（Limitation）**：
   - 数据限制
   - 方法论局限
   - 内生性问题
   - 尚未解决的问题

### 第五步：社会新闻与舆情分析梳理

基于搜索结果进行以下分析：

1. **主要矛盾识别**：
   - 核心社会问题是什么
   - 矛盾的主要方面

2. **利益相关方分析**：
   - 涉及哪些社会群体
   - 各方的立场和诉求

3. **政策需求评估**：
   - 当局需要什么信息
   - 哪些问题亟需研究支持

4. **研究价值判断**：
   - 科学基金会的优先资助方向
   - 研究的紧迫性和重要性

### 第六步：研究问题生成

综合学术文献和社会问题的梳理，提出研究问题：

**创新性标准**：
- 理论贡献：新视角、新机制、新理论
- 方法贡献：新数据、新方法、新识别策略
- 政策贡献：解决现实问题、指导政策制定

**研究问题类型**：
- 描述性问题：是什么、怎么样
- 因果性问题：为什么、由什么引起
- 评估性问题：政策效果如何
- 预测性问题：未来趋势怎样

### 第七步：可行性评估与最终输出

**数据可行性评估**：
- 用户提供的数据能否支撑研究
- 公开可用数据的补充可能性
- 数据匹配度分析

**输出报告格式**：

对于每个可行的研究问题，必须包含：

```
### 研究问题[N]

**具体研究问题及研究内容**：
[清晰界定的问题陈述和研究内容概述]

**研究的创新之处**：
[理论/方法/数据/政策层面的创新]

**研究的现实意义**：
[解决什么社会问题，有什么现实价值]

**科学研究的文献贡献**：
[对相关文献的贡献，明确列出参考文献（APA7格式）]
- 作者, A. A., & 作者, B. B. (年份). 标题. 期刊名称, 卷号(期号), 页码. DOI

**可行的研究方案**：
- 主要方法：[计量方法/实验方法/混合方法]
- 主要变量构建：[自变量、因变量、控制变量的构建思路]
- 因果识别策略：[工具变量/双重差分/断点回归/RCT等]
- 识别策略参考文献（APA7格式）：
  - 作者, A. A. (年份). 标题. 期刊名称, 卷号(期号), 页码. DOI
```

## 质量要求

1. **至少报告5个可行的研究问题**
2. **每个研究问题必须有完整的参考文献支持**
3. **学术文献搜索必须覆盖所有指定期刊范围**
4. **社会新闻搜索必须包含多种来源**
5. **最终输出的研究问题必须同时具有科学价值和现实意义**

## 输出格式

最终输出应包含：

1. **关键词提取结果**
2. **学术文献综述**（包含期刊分布、代表性学者、研究脉络、主要结论、局限）
3. **社会舆情综述**（包含主要矛盾、利益相关方、各方立场、政策需求）
4. **研究问题库**（初步提出的研究问题）
5. **可行性研究问题**（至少5个，每个包含完整的研究方案）

## 注意事项

- 搜索时使用**英文关键词**搜索学术文献以获得更准确的结果
- 中文关键词用于搜索中国社会现象和中文媒体报道
- 确保学术文献引用使用**APA7格式**
- 研究问题的表述应清晰、具体、可操作
- 创新点应突出但不夸大
