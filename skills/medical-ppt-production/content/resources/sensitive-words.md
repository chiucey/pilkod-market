# 医学PPT合规敏感词库

## 一、高风险词汇（禁止使用）

### 疗效绝对化类
- 根治、痊愈、根治性治愈
- 100%有效、完全缓解率100%
- 领先国际、世界领先、最先进
- 最好的、最优秀的、最安全
- 唯一有效方案、唯一选择

### 比较性宣称类（无头对头证据）
- 显著优于、明显优于、大幅领先
- 全面超越、全面领先
- 最好的选择、首选药物
- 超越竞品、碾压竞品

### 患者获益夸大类
- 延长生命长达X年（未注明人群与置信区间）
- 治愈率提升X%
- 生存获益显著（无具体数据支撑）
- 突破性进展、革命性突破

### 超适应证类
- 未经批准的适应症描述
- 扩大适用人群范围
- 超说明书用药推荐

### 绝对安全性类
- 安全无副作用
- 无任何不良反应
- 零风险、零毒性
- 适合所有患者

## 二、中风险词汇（需谨慎使用）

### 需加限定条件
- 显著改善 → 在XX研究中显示数值上的改善趋势
- 突破性成果 → 展现出令人鼓舞的研究数据
- 革命性疗法 → 代表治疗理念的重要进展
- 一线首选 → 根据XX指南，列为I级推荐（1A类证据）
- 最佳治疗 → 在现有治疗选择中的重要补充

### 需注明来源和数据
- 疗效显著 → 客观缓解率（ORR）为XX%（来源：XXX研究，n=XXX）
- 生存获益 → 中位OS延长XX个月（HR=XX，95%CI：XX-XX）
- 安全性良好 → 常见不良反应为XX，发生率为XX%

## 三、合规替代表述库

### 疗效类

| 原表述 | 合规替代表述 |
|--------|-------------|
| 显著优于 | 在XX研究中显示数值上的改善趋势（p=0.XX） |
| 全面领先 | 展现出独特的临床价值特征 |
| 突破性进展 | 研究数据为后续探索提供了重要方向 |
| 革命性突破 | 代表了治疗策略的重要演进 |
| 最好选择 | 值得在临床实践中进一步验证和探索 |

### 安全性类

| 原表述 | 合规替代表述 |
|--------|-------------|
| 安全无副作用 | 总体安全性良好，不良反应可管理 |
| 无任何风险 | 常见不良反应见说明书，临床应用中需关注 |
| 适合所有患者 | 需要根据患者个体情况进行评估 |

### 比较性宣称

| 原表述 | 合规替代表述 |
|--------|-------------|
| 优于竞品 | 在特定人群中显示出差异化的特征 |
| 领先一代 | 作用机制代表了该领域的创新方向 |
| 最佳疗效 | 在现有疗法中是重要的治疗选择之一 |

## 四、证据等级标注要求

### 必须标注的信息
1. **来源**：PMID/DOI/指南名称+年份
2. **样本量**：研究入组人数
3. **研究设计**：RCT、观察性、Meta分析等
4. **证据等级**：GRADE分级或Oxford CEBM等级
5. **置信区间**：所有统计数据必须标注95%CI
6. **P值**：统计显著性标注

### 警示语模板
- "证据有限，需谨慎外推"
- "该结果为探索性分析，未校正多重检验，不作为主要决策依据"
- "样本量有限，结果仅供参考"
- "亚组分析结果，需进一步验证"

## 五、NMPA近年通报案例高频词汇

根据国家药品监督管理局近年通报案例，以下词汇需特别警惕：
- "治愈率"
- "有效率100%"
- "无毒副作用"
- "独家"
- "最先进的"
- "唯一有效的"

---

## 六、场景化合规要求

### 学术会议场景
- 允许探讨机制假说和研究数据
- 可引用初步研究结果（需注明为探索性）
- 禁止直接疗效宣称

### 医院准入汇报
- 需规避营销化语言
- 强调指南推荐和循证依据
- 避免绝对化表述

### 患者教育材料
- 禁止专业术语误导
- 使用通俗易懂的语言
- 强调医嘱重要性

---

## 七、风险等级定义

| 风险等级 | 判定标准 | 处理方式 |
|---------|---------|---------|
| R1（绿色） | 有充分证据支持，表述中立 | 可继续推进 |
| R2（黄色） | 需加限定条件或脚注说明 | 建议补充说明 |
| R3（红色） | 存在实质性合规隐患 | 建议删除或重构 |
