# 医学PPT制作技能 (Medical PPT Production)

## 技能概述

本技能是一套完整的医学PPT制作工作流，涵盖从需求采集、内容策划、视觉设计到合规审查的全流程。专为药企医学事务团队、KOL（关键意见领袖）学术报告场景设计。

---

## 核心工作流（6阶段）

### 阶段1：初始化与数据验证

**核心职责**：引导用户明确关键背景信息，自动校验必填项完整性。

**必填信息项（8项）**：
1. 目标KOL领域与身份（如：肿瘤内科主任医师 / 心血管领域PI / 神经科青年学者）
2. 使用场景类型（单人汇报 / 小型圆桌会 / 卫星会演讲 / 学术沙龙）
3. 听众构成（纯专家 / 带学生团队 / 药企参与 / 混合型）
4. 报告主题与核心信息点（例："新型XX抑制剂在难治性患者中的探索性研究结果"）
5. 公司产品名称与拟植入方式（如："代号XXX药物"、"某机制代表性分子"）
6. 当前阶段资料完整性（是否有完整研究数据？有无发表论文支持？）
7. 视觉风格偏好（国际会议风 / 国内学术风 / 极简科技感 / 温暖人文向）
8. 禁忌要求（如：不得出现竞品对比、避免直接疗效宣称、禁用特定术语）

**质量标准**：信息完整度 ≥ 80% 才可进入下一步；若低于此阈值，输出："当前信息不足以支撑KOL级演示策略设计，请补充【XX项】以继续。"

**需要的输入资料**：
- PPT制作应用场景（KOL学术报告）
- 目标科室信息（如心血管内科、急诊、ICU等）
- 报告者相关信息：年龄，性别，医院级别，报告会议级别规模等
- 预期PPT页数及演讲时长

**决策分支**：
- 数据完整度≥80% → 继续分析
- 数据完整度<80% → 请求补充数据

**错误处理**：数据补充请求机制，超时自动降级处理，人工校验

---

### 阶段2：内容精准性、专业性评估

**核心职责**：对医学类演示文稿进行四维专业评估与结构优化建议。

**评估维度**：

#### 1. 内容精准性审查
- 核查术语使用是否规范（如ICD编码、治疗分型）
- 适应证表述是否准确
- 是否存在超适应证引用或夸大结论

#### 2. 专业性与循证强度评估
- 逐项审查所引用数据的证据等级（按GRADE或Oxford CEBM标准标注）
- 优先推荐RCT、Meta分析、指南推荐等高阶证据
- 低级别证据需明确标注局限性

#### 3. 写作结构与叙事逻辑诊断（"凤头—猪肚—豹尾"原则）

**凤头（开场）**：
- 是否直击临床痛点（如未满足需求、诊疗瓶颈）
- 能否在30秒内引发听众关注

**猪肚（主体）**：
- 是否遵循"假设-验证-推论"逻辑链
- 论点展开是否有层次（机制→疗效→安全性→卫生经济学）
- 案例与数据嵌入时机是否恰当

**豹尾（结尾）**：
- 是否实现总结升华
- 是否给出清晰的临床行动建议（如"推荐纳入一线方案""需开展真实世界验证"）

#### 4. 循证数据智能嵌入指导
- 针对关键主张，主动建议补充最具代表性的权威文献或最新指南出处
- 提示可视化呈现方式（如森林图、Kaplan-Meier曲线截图标注HR值及p值）

**执行标准**：
- 所有数据必须标明来源（PMID/DOI/指南名称+年份）、样本量、研究设计类型及证据等级
- 对存在偏倚风险、外部有效性受限或亚组分析结果的数据，必须加注说明"证据有限""需谨慎外推"等警示语
- 禁止无依据推测或扩大适用范围，杜绝营销化表述，保持学术中立性

**需要的输入资料**：
- 产品官方说明书PDF
- 最新相关临床指南/文献摘要
- 公司批准的核心信息文档
- 完整的演讲文稿
- PPT的大纲结构
- 公司标准的演讲结构模板
- 产品核心研究PDF
- 竞品对比数据表
- 最新指南摘录（包含发布日期）
- 证据等级标注规则
- 数据可视化模板

**决策分支**：
- 开场、主题、结尾 → 完整分析
- 内容不完整 → 请求补充内容
- 证据等级充分 → 继续下一步
- 证据等级不足 → 补充数据或调整表述

**错误处理**：数据不足时使用历史数据补充，标注数据来源；数据缺失时使用替代数据源，明确标注数据局限性

### 阶段3：幻灯片设计与视觉辅助评估

**核心职责**：对医学/学术类PPT进行四维视觉辅助功能评估，聚焦于其作为"演讲支持工具"的有效性。

**评估维度**：

#### 1. 信息层级与焦点控制
- 诊断每页是否遵循"单一核心信息原则"（One Message Per Slide）
- 检查标题是否准确概括本页主旨（应具结论性，如"PD-L1高表达患者ORR提升2.3倍"）
- 评估视觉动线是否引导观众注意力流向关键信息

#### 2. 布局结构与认知负荷管理
- 审查内容密度：文字是否过多导致"阅读疲劳"？
  - 建议：段落≤6行，要点≤6项，每项≤12字
- 判断图文关系是否协同：图像/图表是否真正解释文字，而非简单装饰
- 检查是否有冗余元素（重复边框、过度阴影、无关图标），提出精简建议

#### 3. 色彩与品牌规范执行
- 验证配色方案是否符合学术场景的专业调性（避免高饱和度、娱乐化色调）
- 确认是否使用机构/企业标准色板，主次色搭配是否利于信息区分
- 核查公司标识（Logo）、合规声明是否在每页固定位置清晰呈现，格式统一

#### 4. 图表有效性与数据可视化质量
- 评估图表类型选择是否恰当
  - 生存曲线用Kaplan-Meier
  - 分类比较用柱状图
  - 趋势分析用折线图
- 检查坐标轴标签、单位、图例是否完整可读，避免"无标注图表"
- 提示改进模糊或信息过载图表（如饼图超过6类、森林图未标CI区间）
- 建议增强数据可信度的视觉手段（如添加误差线、显著性标记p/<0.05）

**执行标准**：
- 所有页面须保持字体、标题样式、项目符号、对齐方式的一致性
- 中文推荐使用无衬线字体（如思源黑体、微软雅黑），英文搭配Arial/Helvetica
- 图表优先采用纯色填充、清晰线条，避免渐变、立体效果干扰数据判断
- 每页底部统一包含页码、保密级别、数据来源脚注（如适用）

**需要的输入资料**：
- 公司品牌视觉规范手册
- 医学数据可视化最佳实践案例
- 幻灯片设计检查清单

**决策分支**：
- 设计与视觉评估复杂度适中 → 直接进入下一节点
- 设计与视觉评估过于复杂 → 简化处理
- 设计与视觉评估过于简单 → 增强内容

**错误处理**：医学数据可视化最佳实践案例选择失败时使用默认模型，记录选择逻辑

### 阶段4：全方位合规审查

**核心职责**：对医学类PPT内容开展全方位合规基因检测与风险分级干预。

**审查维度**：

#### 1. 高风险表述自动标红与溯源核查
实时识别并标红以下高危内容：
- 超适应证推荐（off-label use）
- 疗效绝对化用语（"根治""痊愈""领先国际"）
- 比较性宣称无直接证据支持（如"A药优于B药"但无头对头研究）
- 患者生存获益夸大（如"延长生命长达X年"未注明人群与置信区间）
- 使用未经批准的评分系统或诊断标准

对每项声明强制核查是否附有原始文献支撑（PMID/DOI/指南名称+推荐等级）

#### 2. 合规替代方案建议与敏感词智能替换

**敏感词替换示例库**：
| 风险表述 | 合规替代表述 |
|---------|-------------|
| "显著优于" | "在XX研究中显示数值上的改善趋势" |
| "安全无副作用" | "总体安全性良好，常见不良反应见说明书" |
| "一线首选" | "根据2024 CSCO指南，列为I级推荐（1A类证据）" |

内置动态更新的行业敏感词库（含NMPA近年通报案例高频词汇）

#### 3. 合规沙箱模拟与风险评级

**场景模拟**：
- 学术会议（较低风险，允许探讨机制假说）
- 医院准入汇报（中等风险，需规避营销化语言）
- 患者教育材料（高风险，禁止专业术语误导）

**风险等级**：
- R1（绿色）：有充分证据支持，表述中立
- R2（黄色）：需加限定条件或脚注说明
- R3（红色）：存在实质性合规隐患，建议删除或重构

#### 4. 合规基因检测报告生成

最终输出一份《PPT合规性审计报告》，包含：
- 高风险语句清单（带原文、位置、风险类型、法规依据）
- 推荐修改方案（保留原句痕迹，采用"删除线+批注"形式）
- 文献支持核查表（列出所有引用及其证据等级）
- 整体合规指数评分（0–100分）

**执行标准**：
- 所有修改建议必须基于现行有效法规与行业共识
- 严格区分"学术探讨"与"推广暗示"，避免隐性诱导
- 对涉及真实世界数据、亚组分析、事后分析的结果，强制添加警示语

**需要的输入资料**：
- 最新合规政策包
- 话术审批记录数据库
- 敏感词监测清单
- 合规规则配置文件
- 历史合规案例库

**决策分支**：
- 合规检查通过 → 进入模拟测试
- 合规检查失败 → 返回修改或人工审核

**错误处理**：合规规则冲突时采用最严格标准，记录冲突点

### 阶段5：综合报告与个性化改进方案生成

**核心职责**：输出《KOL报告内容诊断与软植入可行性评估报告》。

#### 1. 综合内容诊断与可视化呈现

**内容质量评分体系（0-100分）**：
- 学术严谨性（证据等级、参考文献完整性）
- 逻辑清晰度（问题→方法→结论链条）
- 临床相关性（对当前诊疗痛点的回应程度）
- 受众适配度（语言深度是否匹配听众专业水平）
- 潜在协同点（与我方产品作用机制/适应症的契合空间）

**输出格式**：雷达图/热力矩阵图展示各维度表现，标注"高潜力区"与"待加强区"

**一句话总结**："本报告的核心学术价值为______；当前最适宜引入外部价值关联的环节是______。"

#### 2. 三大关键软植入机会点识别

基于"科学合理性 × 植入隐蔽性 × 影响潜力"三轴模型，识别并排序三个最具潜力的软植入位置。

每个机会点必须包含：
- **定位说明**：指出具体章节/页码（如"第7页：难治性患者管理挑战"）
- **机会分析**：解释此处为何适合引入我方产品相关概念
- **风险提示**：评估若强行植入可能引发的合规或学术质疑
- **替代建议**：若当前内容不支持植入，提出可补充的中立性数据建议

#### 3. 具体化、合规化的软植入改进建议

每个机会点提供一组非强制性、可选的优化建议包，包含：

**四要素**：
a. 原文片段引用（摘录需修改/补充的部分）
b. 优化方向建议（保持学术中立的前提下拓展讨论边界）
c. 范例语句输出（提供1-2条可用于替换或补充的中性表达）
d. 植入强度标识：
   - 🔹【轻量提示】仅提及机制/通路（最安全）
   - 🔸【中度关联】引用联合用药趋势或未满足需求
   - 🔺【增强引导】引用我方产品所在类别的临床进展（需谨慎）

#### 4. 个性化内容优化路径建议

根据合作阶段（初稿审阅 / 终稿前调整 / 回顾会复盘），生成分阶行动计划：

- **内容共创阶段**：建议以"共同撰写者"身份提出数据补充建议
- **第三方审阅角色**：提供"评论批注模式"的话术模板

**《软植入机会自查清单》5问**：
1. 当前内容是否涉及我方产品的适应症领域？
2. 是否存在明确的未满足临床需求描述？
3. 是否有机会提及相关生物标志物或病理机制？
4. 引用文献中是否有我方可借鉴的研究类型？
5. KOL是否有过往发表过与我方机制相关的研究？

**执行标准**：
- 所有建议必须严格遵守医药行业推广合规红线
- 软植入必须建立在已有科学证据基础之上
- 语言风格保持学术中立、客观陈述
- 尊重KOL学术自主权，所有建议标注为"供参考"

**需要的输入资料**：
- 各节点的详细评估反馈
- 改进话术范例库
- PPT优化案例库
- 培训资源索引
- 改进资源清单

**决策分支**：
- 测试通过率≥80% → 生成最终PPT
- 测试通过率<80% → 返回优化

**错误处理**：测试场景覆盖不足时补充测试场景

### 阶段6：效果追踪与持续优化

**核心职责**：持续打磨每一次KOL汇报的影响力、可信度与记忆点。

#### 1. 启动反馈采集引导

演示结束后1小时内主动询问：
- KOL口头评价摘要
- 第三方观察记录（同行参会者笔记、会议纪要）
- 提问环节内容整理（特别是质疑类问题）
- 自我复盘：哪些页引起了注意？哪些被跳过？

#### 2. 三维诊断模型

输出《KOL医学报告效果诊断报告》，三大关键改进领域：

| 维度 | 内容要求 |
|------|---------|
| ① 学术可信度 | 是否存在证据链薄弱、统计表述模糊、引用文献陈旧等问题 |
| ② 叙事流畅性 | 疾病→机制→未满足需求→研究进展→产品定位的逻辑是否自然无痕 |
| ③ 软植入有效性 | 产品出现时机、频率、表达方式是否符合KOL心理预期 |

#### 3. 个性化优化建议包（KOL适配型）

| 类型 | 示例 | 适用风格 |
|------|------|---------|
| 💡 轻量调整 | "将'我们的产品'改为'某新型XX抑制剂（代号XXX）'，保持客观语气" | 客观中立型KOL |
| 🔧 中度重构 | "用'同类药物对比表'替代文字描述，在最后一列轻描淡写加入本品特性" | 数据驱动型KOL |
| 🧠 深度升级 | "构建'未来治疗范式演进图'，让本品成为其中一环而非唯一主角" | 战略思想型KOL |

#### 4. KOL-PPT进化档案

为每份PPT创建独立档案，记录：
- 目标KOL专业方向、既往立场（支持/中立/怀疑）、沟通风格
- 使用场景：一对一拜访 / 小型圆桌会 / 大会卫星会
- 关键反馈摘要（尤其关于产品态度变化）
- 已实施优化项
- 待验证假设

#### 5. 持续学习机制（KOL Pattern Recognition）

每月生成《KOL沟通趋势洞察》，识别模式：
- "您在心血管KOL面前常过度强调机制细节，导致错过价值传递窗口"
- "神经科KOL更关注真实世界证据，但您目前PPT中RWE内容占比仅12%"

**执行标准**：
- ❌ 不建议任何可能被视为"不当影响KOL独立判断"的表述
- ✅ 所有产品相关信息必须基于获批适应症和公开文献
- ✅ "软植入"目标是"让人记住科学价值"，而非"强行推广"
- ✅ 若无足够反馈，仅输出："当前缺乏KOL真实反应数据，无法评估软植入效果"

**需要的输入资料**：
- 完整的评估报告（PDF格式）
- 评分明细表（Excel格式）
- 改进建议清单（可操作项）
- 资源推荐列表（培训材料、范例等）

**决策分支**：
- 效果良好 → 保持当前策略
- 效果不佳 → 触发优化流程

## 执行原则（强化限制与边界）

### 禁止事项
- ❌ 不生成具体话术、不编写幻灯片文本、不替代医学写作
- ❌ 不参与任何虚假或误导性信息的构建
