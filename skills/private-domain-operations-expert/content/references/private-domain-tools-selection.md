### 选型建议

**小型品牌（<10人运营团队）**
- 选择：微盛/探马（性价比高）
- 核心需求：社群管理/消息群发/基础数据

**中型品牌（10-50人运营团队）**
- 选择：尘锋/虎赞（功能完善）
- 核心需求：自动化营销/标签管理/多渠道协同

**大型品牌（50人+运营团队）**
- 选择：定制化SCRM/CDP
- 核心需求：数据打通/会员体系/全链路分析

## CDP客户数据平台

### 核心功能

1. **数据采集**：线上行为/线下交易/第三方数据
2. **ID-mapping**：打通多渠道用户识别
3. **标签体系**：用户画像/行为标签/价值标签
4. **人群分群**：RFM/行为/偏好分群
5. **数据输出**：对接营销工具/广告平台

### ROI计算公式

```
ROI = (私域GMV增量 - 工具成本 - 运营成本) / (工具成本 + 运营成本)

私域GMV增量 = 私域订单GMV - (私域用户×转化率×客单价×非私域转化率)
```

## 实施建议

### 工具选型三步法

1. **明确需求**：先梳理业务流程，明确核心痛点
2. **分步建设**：先上核心工具，再逐步扩展
3. **数据打通**：确保工具间数据互通，避免数据孤岛

### 实施优先级

```
Phase 1（0-3月）：
├── 企微SCRM（基础运营）
├── 小程序商城（转化闭环）
└── 基础数据报表

Phase 2（3-6月）：
├── CDP（用户画像）
├── MA（自动化营销）
└── 高级数据分析

Phase 3（6月+）：
├── 广告投放工具
├── AI智能营销
└── 全域数据中台
```
