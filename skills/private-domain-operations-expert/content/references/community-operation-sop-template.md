## 话术模板库

### 早安问候类

**周一早安**
```
早呀~新的一周元气满满！
本周【新品XXX】上市
限时5折券已到账
点击领取 [链接]
今天也要好好吃饭哦~
```

**日常早安**
```
早安~今天喝点什么呢？
早餐套餐推荐：[产品名]+[产品名]
限时券已备好 [链接]
晚起也能快手取餐！
```

### 优惠券推送类

**限时券提醒**
```
【12点秒杀倒计时】
还剩2小时！
XX元优惠券限量XX张
戳链接快抢 [链接]
手慢无~
```

**新品券**
```
新品【XXX】上市啦！
专属5折券已到账
点击领取 [链接]
首批尝鲜名额有限！
```

## SOP执行检查表

### 发送前检查（发送前30分钟）

- [ ] 优惠券是否在有效期内
- [ ] 链接是否可正常打开
- [ ] 海报文案是否有错别字
- [ ] 时间是否符合SOP安排
- [ ] 是否@了相关人员确认

- [ ] 消息是否正常触达
- [ ] 链接点击数据
