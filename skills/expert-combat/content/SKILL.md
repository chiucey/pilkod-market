# 战斗场面设计专家

## 核心原则

好战斗的三个标准：
1. **有过程**：不是瞬间结束，有来有回（但不能拖沓）
2. **有悬念**：读者知道主角能赢，但不知道"怎么赢"
3. **有代价**：胜利要有成本，惨胜比轻松赢更让人紧张

## 战斗类型与节奏模板

### 1. 越阶挑战战斗（最经典）

```
背景：主角弱于对手，但有特殊原因能战
第1回合：被压制，充分展示对手强大（建立压迫感）
转折：发现对手弱点/触发隐藏能力/使用底牌
第2回合：反攻，但对手也有隐藏手段
高潮：双方全力，主角用关键一招锁定胜局
结局：惨胜/险胜，消耗极大，需要后续恢复
```

### 2. 碾压式战斗（展示实力）

```
背景：主角实力远超对方，战斗目的是立威/救人
开局：主角一击击溃对手主要手段
中段：对手挣扎，主角从容应对
高潮：主角"轻松"终结，展现王者气度
重点：渲染旁观者的震惊反应（侧面描写）
```

### 3. 团战（多人战斗）

```
布阵阶段：双方站位/阵法展示
第一阶段：各角色配合作战，战斗混乱但有序
转折阶段：某方关键人物被集火/偷袭
爆发阶段：主角/关键角色出手，力挽狂澜
收尾：各自为战，以多胜少/战略撤退
```

## 战斗描写五要素

```
1. 环境：战场在哪里？有何特殊性？（室内/高空/水中/阵法内）
2. 气势：战前气场对抗（灵压/杀气/剑意）
3. 招式：具体动作名+效果（不能只写"打了过去"）
4. 音效：碰撞声/轰鸣/惨叫（声音增加画面感）
5. 结果：胜负分明，附带代价
```

## 战斗章节字数分配（2000字章节）

```
开篇拉仇恨/站位：100字
第一轮试探：300字
主角陷入危机：400字
转折/爆发：400字
最终对决：300字
战后余波（奖励/代价）：200字
+ 章节结尾悬念：300字
```

## 技能组合设计

好的战斗要有**技能combo**（组合技），不能一个技能用到底：

```
示例技能combo（剑修）：
【剑一·抽芽】：快速突刺，试探对方防守
↓ 命中后接
【剑三·裂石】：横斩，扩大伤口
↓ 对方防御崩溃时
【剑七·惊鸿】：高速移动至对方身后，一击必杀
（最终必杀技需要蓄力/代价，战斗中不能直接用）
```

## 战斗中的心理描写

战斗不仅是武力的比拼，也是心理的较量：

```
压迫心理：对手的强大给主角带来的心理压力
冷静分析：在战斗中寻找破绽的思考过程
信任爆发：在危急时刻，队友的配合/呼喊带来信心
心境突破：战斗中顿悟，战斗力飙升（配合情绪高潮）
```

## 常见战斗OOC问题

| 问题 | 错误示范 | 正确处理 |
|------|---------|---------|
| 配角实力飘忽 | 平时无敌，被主角秒 | 展示主角用了特殊手段/成长 |
| 战斗无代价 | 重伤后下一秒满血 | 设置恢复期/后遗症/资源消耗 |
| 战斗拖太长 | 10章都在打 | 每场战斗有明确节点，适时结束 |
| 技能无冷却 | 无限使用最强技能 | 设置代价/冷却/体力限制 |

## 西幻战斗 vs 东方玄幻战斗

| 维度 | 东方玄幻 | 西幻 |
|------|---------|------|
| 核心 | 剑气灵力、法则意境 | 魔法元素、物理攻击 |
| 关键 | 境界压制、功法克制 | 魔法属性、战术配合 |
| 描写重点 | 意境、画面、写意 | 元素效果、写实、咏唱 |
| 爆发技 | 必杀技/奥义/禁忌 | 禁咒、大招、变身 |
