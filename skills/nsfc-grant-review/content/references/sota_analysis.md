## Structure Contract

### Document Hierarchy

1. **Title line** (plain text, inline with first reviewer marker)
2. **7 reviewer sections** labeled `<1>` through `<7>`
3. Each reviewer section contains exactly **5 dimensions**

### Reviewer Markers

Format: `<N>具体评价意见：` where N = 1, 2, 3, 4, 5, 6, 7

Example: `<1>具体评价意见：`, `<2>具体评价意见：`, ... `<7>具体评价意见：`

### Five Standard Dimensions (Fixed Text, Fixed Order)

1. `一、请评述申请项目研究选题的创新性。请详细阐述判断理由。`
2. `二、请评述申请项目所提出研究问题的科学价值以及是否可推动某些学科领域或者科学前沿取得突破。`
3. `三、请评述申请项目研究方案的可行性；如有可能，请对完善研究方案提出建议。`
4. `四、请评述研究队伍构成、研究条件和与本项目相关的前期工作基础。`
5. `五、其他建议`

### Comment Length and Style

- Each dimension comment: **1-3 sentences**
- Typical length: 30-120 Chinese characters
- Style: Direct, specific, evidence-based
- Tone: Professional, objective, balanced
- Language: Chinese (formal academic), English for technical terms
- References specific proposal elements: proteins, cell lines, methods, publications

### Dimension 5 Special Case

When a reviewer has no additional suggestions, the response is simply:
`无` (on its own line after the dimension header)

## Extracted Review Patterns by Dimension

### Dimension 1: Innovation (创新性)

**Positive patterns:**
- "具有一定的创新性" — acknowledges some novelty
- "有较高的原创性" — high originality
- "本项目从[独特角度]研究[科学问题]，具有较高的原创性"

**Negative patterns:**
- "创新性略显不足" — core ideas already published
- "研究选题缺乏创新性" — unclear direction
- "需要更严格的实验数据支持"
- "研究选题的创新性略有不足"

**Mixed patterns:**
- "具有一定的创新性，但需要更严格的实验数据支持"
- "创新性略显不足" + reason (e.g., core published, broad scope)

### Dimension 2: Scientific Value (科学价值)

**Positive patterns:**
- Acknowledges disease importance (e.g., "NAFLD是第一大慢性肝病")
- "研究具有一定的科学意义和研究价值"
- "该科学问题具有较高的价值"

**Negative/cautious patterns:**
- "推动作用有限"
- "但其是否被学术界接受及其是否正确还有待考验"
- "与NAFLD的关系并不完全清楚"

### Dimension 3: Feasibility (可行性)

**Positive patterns:**
- "研究方案具有较好可行性"
- "实验设计基本合理可行"
- "研究层次较为清晰"

**Negative patterns:**
- "研究方案逻辑不够顺畅"
- "关联性不够清晰"
- "实验设计缺乏基本的对照"
- Cell line concerns: "HEK293T作为表达细胞，并不适合研究肝脏中的蛋白结合与行为"
- "研究方案简单、研究手段不够丰富"
- "研究手段过于单一，应引入更多有效、创新的实验技术"

### Dimension 4: Team & Foundation (研究队伍与基础)

**Positive patterns:**
- "研究队伍构成较合理"
- "申请人长期蛋白质工程研究和蛋白质药物开发，有多项成果和积累"

**Negative patterns:**
- "近5年没有参与或主持的基金，没有高水平的相关研究文章"
- "研究队伍结构也不合理，直接支持本项目的前期研究结果不足"
- "2016年以来的工作比较一般"

### Dimension 5: Other Suggestions (其他建议)

- Empty: "无"
- Technical: "建议设计knockin的小鼠品系以及人源化模型去研究"
- Methodological concerns
