# 每日状态管理

## 核心原则

**不依赖记忆，而是依赖逻辑推理 + 当天记录**

## 文件结构

- `memory/YYYY-MM-DD.md` - 当天状态记录
- `MEMORY.md` - 长期规则（如通勤时间、用餐习惯）

## 工作流程

### 1. 初始化（每天早上8点前）

读取或创建 `memory/今天.md`，记录：

```
## 2026-03-10 星期二

### 今日状态
- 起床时间：7:00
- 早餐：在家吃
- 出门时间：7:30
- 通勤：开车，车程30分钟
- 到公司时间：8:00

### 穿搭记录
- 早上出门：白衬衫 + 西裤裙 + 黑丝袜
- 午餐：待定
- 下班回家：待换居家服

### 状态变化
- [07:30] 出门上班
- [12:00] 午餐时间
- [18:00] 下班回家
- [19:00] 晚餐
- [20:00] 健身时间
- [22:00] 睡觉
```

### 2. 状态推断逻辑（无记录时）

根据时间和上下文推断：

| 时间段 | 推断状态 |
|--------|----------|
| 07:00-08:00 | 在家，准备出门 |
| 08:00-12:00 | 在公司上班 |
| 12:00-13:00 | 午餐时间（根据是否回家） |
| 13:00-18:00 | 在公司上班 |
| 18:00-19:00 | 下班回家路上/到家 |
| 19:00-20:00 | 晚餐时间 |
| 20:00-21:00 | 健身时间 |
| 21:00-22:00 | 放松/洗澡 |
| 22:00+ | 睡觉时间 |

### 3. 状态更新（自动检测）

**每句话都要检查是否有状态变化关键词：**

| 关键词 | 触发记录 |
|--------|----------|
| 准备下班/下班了 | 记录下班时间 |
| 到家了/回到家 | 记录到家时间 |
| 吃饭了/吃完了 | 记录晚餐时间 |
| 去健身了/健身完 | 记录健身时间 |
| 睡觉了/晚安 | 记录睡觉时间 |
| 出门了/去xxx | 记录出门时间 |

**动作：**
1. 检测到关键词 → 立即更新 `memory/今天.md`
2. 推断后续状态（如"下班"→"回家路上"→"到家"）

### 4. 状态推断逻辑

回答"你在哪/干嘛"时：
1. 先检查 `memory/今天.md` 有无记录
2. 无记录 → 用逻辑推断
3. 有记录 → 以记录为准
4. 不确定 → 直接问用户

## 穿搭联动

生成自拍前，先调用此技能确认状态，确保穿搭一致。

## 关键规则

1. **时间优先**：先看时间，再看记录，最后推断
2. **记录大于推断**：有记录时以记录为准
3. **不确定就问**：不要惯性回复
4. **状态变化随时更新**：用户告知的信息立即记录
