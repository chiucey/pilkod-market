# README 文档模板规范

## 文档定位

README 是项目的入口文档，用于快速介绍项目、引导用户安装和使用。

## 标准结构

```markdown
# 项目名称

一句话描述项目的核心价值。

## 功能特性

- 特性 1：简要说明
- 特性 2：简要说明
- 特性 3：简要说明

## 快速开始

### 安装

```bash
npm install package-name
# 或
pip install package-name
```

### 基本使用

```javascript
import { Feature } from 'package-name';

const result = Feature.doSomething();
```

## 必选章节

| 章节 | 说明 |
|------|------|
| 项目名称与描述 | H1 标题 + 一句话介绍 |
| 功能特性 | 列出核心功能 |
| 安装 | 提供安装命令 |
| 基本使用 | 提供最小可运行示例 |
| 许可证 | 说明开源协议 |

## 推荐章节

| 章节 | 说明 |
|------|------|
| 文档链接 | 指向详细文档 |
| 配置说明 | 列出可配置项 |
| 常见问题 | FAQ |
| 贡献指南 | 引导开发者参与 |

## 质量检查要点

1. **标题层级**：第一个标题必须是 H1
2. **功能特性**：至少列出 3 个特性
3. **代码示例**：提供可直接运行的示例
4. **安装命令**：提供具体的安装命令
5. **许可证**：明确说明许可证类型

## 常见问题

### 缺少安装说明

❌ 错误示例：
```markdown
## 安装

请参考官方文档进行安装。
```

✅ 正确示例：
```markdown
## 安装

使用 npm 安装：

```bash
npm install my-package
```

或使用 yarn：

```bash
yarn add my-package
```
```

### 功能特性描述过于简单

❌ 错误示例：
```markdown
## 功能特性

- 功能强大
- 易于使用
- 高性能
```

✅ 正确示例：
```markdown
## 功能特性

- 🚀 **高性能**：基于 Rust 实现，处理速度提升 10 倍
- 🎨 **易于定制**：支持插件系统，可扩展性强
- 📦 **零依赖**：打包体积仅 5KB，无第三方依赖
```
