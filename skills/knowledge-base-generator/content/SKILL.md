# 知识库生成器技能

## 触发条件

当用户需要以下操作时触发：
- 将文档内容整理成培训材料
- 生成练习题库（单选、判断题）
- 创建知识知识点体系
- 整理培训课件

## 核心能力

### 1. 知识拆分

将原始内容拆分为多个独立知识点，每个知识点包含：
- **名称**：简洁明确的知识主题
- **解释**：通俗易懂的语言说明
- **使用场景**：实际应用情境
- **常见坑**：容易出错或需要注意的地方

### 2. 题库生成

每个知识点生成：
- **2道单选题**：考察理解和应用
- **1道判断题**：考察概念掌握

### 3. 输出格式

输出结构化的知识库文档：
- Markdown 格式，便于阅读和编辑
- 可选：Excel 格式的题库表
- 可选：HTML 格式的在线课件

## 执行流程

### Step 1: 内容输入

```
接收用户提供的原始内容
可以是：
- 粘贴的文字内容
- 上传的文档（.txt, .md, .docx）
- URL 链接（网页内容）
```

### Step 2: 知识分析

```
识别核心主题和子主题
确定知识层级结构
标记关键概念和术语
```

### Step 3: 知识点拆分

```
按逻辑结构拆分内容
生成知识点卡片：
- 知识点名称
- 通俗解释
- 适用场景
- 避坑提示
```

### Step 4: 题库生成

```
为每个知识点生成题目：
单选1：概念理解
单选2：应用分析
判断1：真伪辨别
```

### Step 5: 输出交付

```
整理后的知识库文档
可选附加文件：
- 题库.xlsx
- 知识点卡片.pdf
```

## 使用示例

### 示例：客服培训知识库

**输入内容**：
```
退货政策：
1. 7天内可无理由退货
2. 15天内因质量问题可退货
3. 定制商品不支持退货
4. 退货需要保留原包装
5. 运费承担规则...
```

**输出结果**：

```markdown
# 客服培训知识库：退货政策

## 知识点 1：7天无理由退货

**解释**：顾客购买商品后7天内，不需要任何理由即可申请退货

**使用场景**：
- 顾客改变主意想要退货
- 收到的商品与预期不符

**常见坑**：
- ❌ 误以为所有商品都适用（定制商品除外）
- ❌ 忽略了商品要保持完整

## 知识点 2：质量问题退货

**解释**：15天内因商品质量问题可申请退货，由商家承担运费

**使用场景**：
- 商品有破损或缺陷
- 商品功能不正常

**常见坑**：
- ❌ 混淆"质量问题"和"个人原因"
- ❌ 未要求顾客提供证据照片

## 题库

### 知识点1 题目

1. 【单选】顾客购买后第6天要求退货，商品完好，以下处理正确的是？
   A. 拒绝退货，因为已过7天
   B. 同意退货，7天内无理由 ✓
   C. 要求顾客支付运费
   D. 告知需经理批准

2. 【单选】以下哪种情况适用于7天无理由退货？
   A. 定制生日蛋糕
   B. 刻有名字的戒指
   C. 普通款式的T恤
   D. 按照顾客尺寸定制的西装

3. 【判断】只要在7天内申请退货，即使商品已被使用过也可以无理由退货。
   ❌ 错误。退货商品需保持完好状态。
```

## 依赖工具

- **文档解析**：读取用户上传的文档内容

## 注意事项

1. **内容质量**：确保输入内容清晰、结构化
2. **知识完整性**：知识点之间保持逻辑连贯
3. **题目难度**：题目难度适中，覆盖核心概念
4. **隐私保护**：处理时脱敏敏感信息
