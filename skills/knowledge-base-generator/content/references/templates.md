# 知识库模板参考

## 知识点结构模板

```markdown
## 知识点 N：[主题名称]

**一句话解释**：[用一句话说明核心概念，15-30字]

**详细说明**：
[3-5句话展开解释，涵盖定义、关键要素]

**使用场景**：
- 场景1：[具体情境说明]
- 场景2：[具体情境说明]
- 场景3：[具体情境说明]

**常见误区**：
- ❌ [错误理解或做法1]
- ❌ [错误理解或做法2]

**正确做法**：
- ✅ [正确理解或做法1]
- ✅ [正确理解或做法2]

**记忆口诀**：[可选，帮助记忆的简短口诀]
```

## 题目模板

### 单选题模板

```markdown
### 知识点N - 单选1：概念理解

[题干描述一个情境或概念]

A. [选项1：干扰项]
B. [选项2：干扰项或正确项]
C. [选项3：干扰项]
D. [选项4：正确项]

**答案**：B

**解析**：[解释为什么选B，以及为什么其他选项错误]
```

### 判断题模板

```markdown
### 知识点N - 判断题：概念辨析

[陈述一个需要判断正误的命题]

A. 正确
B. 错误

**答案**：B

**解析**：[解释判断依据，纠正常见误解]
```

## 题库生成规则

### 题目数量标准

| 知识点类型 | 单选题 | 判断题 | 合计 |
|-----------|-------|-------|-----|
| 概念型 | 2道 | 1道 | 3道 |
| 操作型 | 2道 | 1道 | 3道 |
| 流程型 | 2道 | 1道 | 3道 |

### 题目难度分布

| 难度 | 占比 | 考察点 |
|-----|------|-------|
| 基础 | 50% | 概念识记、直接应用 |
| 中等 | 30% | 理解分析、变式应用 |
| 进阶 | 20% | 综合判断、问题解决 |

### 选项设置规则

**单选题选项要求**：
- 正确答案1个
- 干扰选项2-3个
- 选项长度相近，避免明显提示
- 选项之间互斥，不重叠

**判断题要求**：
- 题目陈述明确，无歧义
- 正确/错误概率接近50%
- 错误选项通常是常见误解

## 格式规范

### 输出文件命名

```
知识库文档：{主题}_知识库_{日期}.md
题库表格：{主题}_题库_{日期}.xlsx
知识卡片：{主题}_卡片_{编号}.png
```

### 格式要求

- Markdown 使用标准语法
- 表格边框清晰
- 代码块使用 ``` 包裹
- 标题层级不超过4级
