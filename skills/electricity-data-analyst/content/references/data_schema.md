# 电力账单数据模式参考

## 数据层级结构

### 1. 账单文件层级

```
账单文件
├── 文件名格式: YYYY-MM账单.ext (如: 2024-01账单.xlsx)
│
├── 分界室1 (Billing Point)
│   ├── 基本信息
│   │   ├── 户号: 客户唯一标识
│   │   ├── 户名: 客户名称
│   │   ├── 集团户名: 所属集团
│   │   ├── 用电类别: 大工业/一般工商业等
│   │   └── 市场化属性: 市场化用户/非市场化用户
│   │
│   └── 计量点列表
│       ├── 计量点1
│       │   ├── 电表号: 计量设备编号
│       │   └── 用电数据...
│       └── 计量点2...
│
└── 分界室2...
```

### 2. 分时段电价结构

中国电力市场通常将一天24小时划分为四个时段：

| 时段类型 | 时段 | 说明 | 电价特征 |
|---------|------|------|----------|
| 尖段 (Peak) | 11:00-15:00, 18:00-21:00 | 用电最高峰 | 最高价 |
| 峰段 (Shoulder) | 8:00-11:00, 15:00-18:00, 21:00-23:00 | 用电较高峰 | 较高价 |
| 平段 (Flat) | 7:00-8:00, 23:00-24:00 | 正常用电 | 中等价 |
| 谷段 (Valley) | 0:00-7:00 | 用电低谷 | 最低价 |

### 3. 统计字段说明

#### 基本信息字段

| 字段名 | 中文名 | 数据类型 | 说明 |
|--------|--------|----------|------|
| customer_id | 户号 | string | 电力客户唯一编号 |
| customer_name | 户名 | string | 客户名称 |
| group_name | 集团户名 | string | 所属集团名称 |
| usage_category | 用电类别 | string | 如: 大工业、一般工商业、居民等 |
| market_attribute | 市场化属性 | string | 如: 市场化用户、电网代购 |

#### 计费数据字段

| 字段名 | 中文名 | 数据类型 | 单位 | 说明 |
|--------|--------|----------|------|------|
| total_power_kwh | 本期电量 | float | kWh | 本期总用电量 |
| total_cost_yuan | 本期电费 | float | 元 | 本期总电费 |
| avg_price | 平均电价 | float | 元/kWh | total_cost / total_power |

#### 分时段字段

| 时段 | 电量字段 | 费率字段 | 电费字段 |
|------|----------|----------|----------|
| 尖段 | peak_kwh | peak_rate | peak_cost |
| 峰段 | shoulder_kwh | shoulder_rate | shoulder_cost |
| 平段 | flat_kwh | flat_rate | flat_cost |
| 谷段 | valley_kwh | valley_rate | valley_cost |

#### 其他费用字段

| 字段名 | 中文名 | 说明 |
|--------|--------|------|
| capacity_cost | 输配容需量电费 | 按变压器容量或最大需量计收的输配电费 |
| power_factor_cost | 功率因数调整电费 | 根据功率因数水平调整的电费 |

### 5. 常见列名映射

脚本支持多种列名写法：

```python
FIELD_MAPPINGS = {
    # 户号
    '户号': 'customer_id',
    '用户编号': 'customer_id',
    '客户编号': 'customer_id',

    # 电量
    '本期电量': 'total_power_kwh',
    '总电量': 'total_power_kwh',
    '用电量': 'total_power_kwh',

    # 电费
    '本期电费': 'total_cost_yuan',
    '总电费': 'total_cost_yuan',

    # 费率
    '尖段标准': 'peak_rate',
    '尖段单价': 'peak_rate',
    # ...
}
```

### 6. 数据验证规则

1. **数值字段**: 必须为有效数字
2. **月份格式**: YYYY-MM 格式
3. **数据一致性**:
   - `total_power_kwh ≈ peak_kwh + shoulder_kwh + flat_kwh + valley_kwh`
   - `total_cost ≈ peak_cost + shoulder_cost + flat_cost + valley_cost + capacity_cost + power_factor_cost`
