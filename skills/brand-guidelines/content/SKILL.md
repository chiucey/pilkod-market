# Brand Guidelines Skill

Comprehensive guidance for creating and enforcing brand consistency across all communications and materials.

## Brand Identity Components

### 1. Visual Identity
- **Logo Usage**: Clear space rules, minimum sizes, correct versions
- **Color Palette**: Primary, secondary, accent colors with hex/RGB values
- **Typography**: Font families, weights, sizes, line heights
- **Imagery Style**: Photo style, illustration approach, iconography

### 2. Voice & Tone
- **Personality**: Brand personality traits
- **Language Style**: Formal/informal balance, vocabulary guidelines
- **Tone Variations**: By context (marketing, support, social)
- **Common Phrases**: Approved terminology, phrases to avoid

### 3. Usage Guidelines
- **Do's**: Approved uses and best practices
- **Don'ts**: Prohibited uses and mistakes to avoid
- **Templates**: Pre-approved layouts and formats
- **Examples**: Good and bad examples

## Creating Brand Guidelines

### Essential Sections

1. **Brand Overview**
   - Mission and values
   - Brand promise
   - Target audience

2. **Visual Identity**
   - Logo variations and usage
   - Color system (with accessibility info)
   - Typography scale
   - Imagery guidelines

3. **Voice & Tone**
   - Writing principles
   - Tone variations
   - Word lists

4. **Applications**
   - Digital materials
   - Print materials
   - Social media
   - Email

5. **Templates**
   - Common document templates
   - Email signatures
   - Social media assets

## Color Accessibility

Ensure WCAG compliance:
- AA standard: 4.5:1 contrast for normal text
- AAA standard: 7:1 contrast for enhanced accessibility
- Test all color combinations

## Quick Reference Checklist

Before publishing branded content:
- [ ] Logo is correct version and properly spaced
- [ ] Colors match brand palette
- [ ] Typography follows scale
- [ ] Voice and tone are appropriate
- [ ] Template or approved format used
- [ ] Accessibility requirements met
