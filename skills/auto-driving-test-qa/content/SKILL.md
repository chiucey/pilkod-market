```
## 📚 专业解答

### 一、测试用例分层结构

| 层级 | 测试目标 | 覆盖率要求 | 典型用例数 |
|-----|---------|-----------|-----------|
| 功能逻辑MIL | 感知-决策-执行逻辑 | 100% | 50-100 |
| 算法SIL | 路径规划/TTC计算 | MC/DC | 100-200 |
| 系统HIL | 传感器融合+执行 | 场景覆盖80%+ | 200-500 |

### 二、AEB核心测试场景矩阵

**1. 前车静止场景 (CCRs)**
```
场景配置：
- 目标车速度：0 km/h
- 测试车速度：[20, 40, 60, 80] km/h
- 距离梯度：[30, 50, 70, 100] m
- 覆盖：Euro NCAP V4.4.1 AEB CCRs
```

**2. 前车慢行场景 (CCRm)**
```
场景配置：
- 目标车速度：[20, 40, 60] km/h
- 测试车速度：[80, 100, 120] km/h
- 速度差：≥20 km/h
```

**3. 误触发测试**
```
- 金属护栏/标志牌
- 抛洒物(纸箱/塑料桶)
- 对向/横穿车辆
```

### 三、HIL测试关键配置

```
传感器模拟配置：
- 雷达：目标RCS=10dBsm，距离精度±0.5m
- 摄像头：FOV=120°，畸变校正

时间同步要求：
- V2X延迟 < 20ms
- 雷达周期 < 50ms
```

### 四、Pass/Fail判定标准

| 测试阶段 | 碰撞预警要求 | 制动介入要求 |
|---------|-------------|-------------|
| FCW | 速度差>20km/h时，TTC<2.7s报警 | - |
| AEB-1 | - | TTC<1.7s开始制动 |
| AEB-2 | - | 避免碰撞或速度<40km/h |
```

**Q：dSPACE SCALEXIO如何搭建激光雷达HIL测试环境？**

**A：**
```
## 🔍 问题理解
在dSPACE SCALEXIO平台上搭建激光雷达传感器模拟的HIL测试环境。

## 📚 专业解答

### 一、硬件连接拓扑

```
[LiDAR模拟器] → [SCALEXIO I/O] → [目标ECU]
     ↓
[实时处理器]
```

### 二、软件配置步骤

**1. Sensor Actuator配置**
```
路径：Configuration → Sensors → LiDAR
参数设置：
- 扫描模式：机械旋转/固态
- 线数：16/32/128线
- 垂直FOV：[-15°, +15°]
- 距离范围：0.5~200m
```

**2. 回波模型配置**
```
Environment：
- 地面反射率：0.1~0.3
- 目标物反射率：0.5~0.9
- 大气衰减：0.05 dB/m
```

**3. 目标物注入**
```
使用 AutomationDesk 或 CANoe：
- 静态目标物：交通标志、护栏
- 动态目标物：车辆、行人
- 注入频率：10Hz
```

### 三、关键注意事项

⚠️ **时延控制**：端到端延迟需<10ms
⚠️ **点云格式**：确认ECU支持的点云格式（XYZ/ XYZI/ XYZI_RCS）
⚠️ **同步校准**：与摄像头/雷达时钟同步误差<1ms

### 四、验证方法

```
1. 静态测试：
   - 在仿真环境放置已知距离的平面目标
   - 验证距离测量误差 < ±0.1m

2. 动态测试：
   - 使用预定义轨迹的目标物
   - 验证目标跟踪连续性
```

### 核心变化一览

| 变化项 | 旧版(2021) | 新版(2024) | 影响 |
|-------|-----------|-----------|------|

| 评分权重 | 基础功能 | 增加高级功能加分 | 推动技术升级 |

### 关键新增场景

**1. AEB骑行人(CCRa)**
```
- 速度工况：20-60km/h
- 碰撞点：正面、斜向(45°)
- 目标物：成人骑行者假人
```

**2. 高级AEB**
```
- 交叉路口AEB
- 对向来车AEB
- 逆向行驶车辆AEB
```

1. **硬件升级**：摄像头分辨率≥2MP，雷达探测距离>200m
2. **算法迭代**：增加夜间/低光照模型训练数据
3. **测试覆盖**：场景库需扩展30%以上
```
