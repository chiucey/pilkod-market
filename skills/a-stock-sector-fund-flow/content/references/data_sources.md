# A股板块资金流向数据源参考

## 主要数据源：东方财富 (Eastmoney)

### 板块资金流向API

**接口地址**：
```
https://push2.eastmoney.com/api/qt/clist/get
```

**请求参数**：
- `pn`: 页码（默认1）
- `pz`: 每页条数（默认20）
- `po`: 排序字段（1=降序，0=升序）
- `np`: 行业类型（1=行业, 2=概念, 3=地域）
- `fltt`: 浮动类型（2=百分比）
- `invt`: 投资类型（2=主力）
- `fid`: 排序依据（f3=主力净流入）
- `fs`: 板块范围（m:0+t6表示全部）
- `fields`: 返回字段

**完整请求示例**：
```
https://push2.eastmoney.com/api/qt/clist/get?pn=1&pz=100&po=1&np=1&fltt=2&invt=2&fid=f3&fs=m:0+t:6,m:0+t:13,m:0+t:80,m:1+t:2,m:1+t:23&fields=f12,f14,f3,f6,f10,f8
```

**返回字段映射**：
- `f12`: 板块代码
- `f14`: 板块名称
- `f3`: 涨跌幅
- `f6`: 主力净流入额
- `f10`: 主力净流入占比
- `f8`: 成交量

### 个股资金流向API

**接口地址**：
```
https://push2.eastmoney.com/api/qt/stock/get
```

**请求参数**：
- `ut`: 用户token
- `fltt`: 浮动类型
- `invt`: 投资类型
- `fields`: 返回字段

## 数据字段说明

### 主力资金定义
- **主力净流入**：特大单买入金额 - 特大单卖出金额
- **特大单**：单笔成交额>=100万元
- **大单**：单笔成交额>=10万元

### 数据更新频率
- 盘中使用：每分钟更新
- 盘后：收盘后30分钟内更新当日最终数据

## 数据质量验证

1. **完整性检查**：确保所有主要板块都有数据
2. **合理性检查**：
   - 涨跌幅应在[-10%, +10%]范围内
   - 主力净流入占比应在[-100%, +100%]范围内
3. **一致性检查**：与前一交易日数据对比，差异应在合理范围内
