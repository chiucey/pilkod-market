# A股板块资金流向分析技能

## 功能概述

获取东方财富等权威金融数据源的A股各板块实时资金流入流出情况，提供板块级别的资金流向分析。

## 数据来源

- **主数据源**：东方财富（eastmoney.com）- 板块资金流向
- **备用数据源**：同花顺（10jqka.com.cn）- 行业资金流

## 数据字段

获取的数据包含以下关键指标：
- 板块名称（sector_name）
- 板块代码（sector_code）
- 今日主力净流入（main_net_flow）
- 今日主力净流入占比（main_net_flow_ratio）
- 今日主力净流入金额（main_net_amount）
- 5日主力净流入（main_net_flow_5d）
- 10日主力净流入（main_net_flow_10d）
- 板块涨跌情况（price_change）
- 成交量（volume）

## 执行流程

1. **确定数据源**：优先使用东方财富API接口获取数据
2. **构建请求**：调用数据获取工具获取板块资金流数据
3. **数据处理**：解析返回的JSON数据，提取关键指标
4. **格式化输出**：以结构化表格或列表形式展示数据
5. **排序分析**：支持按主力净流入、净流入占比等指标排序

## 输出格式

### 标准表格输出
```
| 排名 | 板块名称 | 主力净流入(万) | 净流入占比 | 涨跌幅 |
|------|----------|----------------|------------|--------|
| 1    | xxx板块  | +12,345.67     | 8.5%       | +2.3%  |
| ...  | ...      | ...            | ...        | ...    |
```

### 分析报告输出
- 资金流入最多的板块TOP5
- 资金流出最多的板块TOP5
- 板块资金流向趋势分析

## 注意事项

1. **时效性**：资金流向数据为实时或日频更新
2. **数据验证**：确保数据来源的权威性和可靠性
3. **误差说明**：部分小市值板块数据可能存在较大波动
4. **合规提示**：数据仅供分析参考，不构成投资建议

## 错误处理

- 数据获取失败时，尝试备用数据源
- 记录错误日志，返回友好提示信息
- 支持部分数据获取场景下的降级处理
