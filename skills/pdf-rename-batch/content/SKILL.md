# PDF批量重命名技能

自动识别PDF中的姓名信息并生成规范文件名。

## 核心能力

- 从PDF中提取文本或通过OCR识别扫描件
- 智能识别真实人名，过滤职务、称谓等干扰
- 支持批量处理，自动处理重名情况

## 处理流程

### 1. 提取PDF内容

**优先使用服务器端提取工具**（稳定性更高）：

```
mcp__matrix__extract_pdfs_key_info 或 extract_pdfs_full_content
```

仅当服务器端提取失败时，才使用浏览器端方案（pdfjs-dist + tesseract.js）

### 2. 姓名识别规则

只提取2-4个汉字组成、以常见姓氏开头的人名：

- **姓氏白名单**：王、李、张、刘、陈、杨、黄、赵、周、吴、徐、孙、马、朱、胡、郭、何、林、高、罗、郑、梁、谢、宋、唐、许、韩、冯、邓、曹、彭、曾、萧、蔡、潘、田、董、袁、余、叶、蒋、杜、苏、魏、程、吕、丁、沈、任、姚、卢、傅、钟、姜、崔、谭、廖、范、汪、陆、金、石、戴、贾、韦、夏、覃、丘、方

**过滤排除**：
- 职务称谓：经理、总监、主任、工程师、老师、教授、博士、女士、先生等
- 组织机构：有限公司、公司、集团、医院、学校、大学等
- 长度不符：小于2或大于4个字符

### 3. 命名规则

- 格式：`{姓名}_{文件类型}.pdf`
- 重名处理：自动追加序号 `{姓名}_1.pdf`、`{姓名}_2.pdf`
- 无法识别时：`未识别姓名_{原文件名}.pdf`

## 输出格式

向用户清晰展示：

```
| 项目 | 内容 |
|------|------|
| 原文件名 | xxx.pdf |
| 提取姓名 | 张三 |
| 新文件名 | 张三_准考证.pdf |
```

## 交付方式

- 提供重命名后的文件下载（使用 deliver_assets 组件）
- 如用户要求批量处理多个文件，逐一处理并汇总结果

## 注意事项

- PDF可能是扫描件或加密格式，服务器端工具更可靠
- 姓名可能在表格中（如"考生姓名"后），需匹配标签模式
- 证件照、印章区域不是姓名，不应识别
