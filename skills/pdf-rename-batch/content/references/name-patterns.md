# 姓名识别模式参考

## 常见PDF姓名标签格式

### 1. 表格形式（准考证类）
```
考生姓名: 张三
姓名    王五
```

### 2. 键值对形式
```
姓名：张三
证件姓名：李四
```

### 3. 证件照片区域（应排除）
```
照片区 - 不应识别为姓名
```

## 正则表达式模式

### 标签匹配
```javascript
/(?:考生姓名|姓名|名字|名\s*称)[:：\s]*([\u4e00-\u9fa5]{2,4})/gi
/(?:持\s*有\s*人|所\s*有\s*人|归\s*属\s*人)[:：\s]*([\u4e00-\u9fa5]{2,4})/gi
/(?:证件姓名|证件\s*号\s*姓\s*名)[:：\s]*([\u4e00-\u9fa5]{2,4})/gi
```

### 频率统计
```javascript
// 姓名出现次数越多越可能是主姓名
// 位置越靠前越可能是主姓名
score = occurrences * 10 + positionScore * 5
```

## 真实案例数据

### 准考证格式
| 字段 | 示例 |
|------|------|
| 考生姓名 | 朱玉洁 |

- 新文件名：`朱玉洁_准考证.pdf`
