# 对外俄语（ТРКИ）作文题生成技能

## 技能目标

根据用户指定的 ТРКИ 级别，生成符合该级别考查规律和语言要求的俄语作文题，
并以 Word 文档（.docx）输出。题目内容仅包含：**俄语题目说明** + **字数/句数要求**。

---

## 第一步：识别级别

从用户的输入中提取目标级别。ТРКИ 六个级别与常见别称对应如下：

| 级别 | 别称 / 常见表达 |
|------|----------------|
| A1   | 元素级、入门级、Элементарный |
| A2   | 基础级、Базовый |
| B1   | 一级、第一认证级、ТРКИ-1、Первый сертификационный уровень |
| B2   | 二级、第二认证级、ТРКИ-2、Второй сертификационный уровень |
| C1   | 三级、第三认证级、ТРКИ-3、Третий сертификационный уровень |
| C2   | 四级、第四认证级、ТРКИ-4、Четвёртый сертификационный уровень |

如果用户没有说明级别，用中文礼貌询问："您需要哪个级别的作文题？（A1 / A2 / B1 / B2 / C1 / C2）"

---

## 第二步：询问生成数量

确认级别后，询问用户：

> 您需要生成**一道单独的题目**，还是**一套完整的作文任务**（包含该级别考试的所有题型）？

- **单道题**：从该级别的所有任务类型中随机选取一种，生成一道题目
- **整套题**：按考试顺序生成该级别的所有任务，统一输出到一个 Word 文档

---

## 第三步：按级别要求生成题目

每个级别的作文题在**话题范围**、**任务类型**、**语言复杂度**、**字数**上都有明确规律。
生成题目时，严格遵照以下规范：

### A1 — Элементарный（元素级）

本级别共 **2 道任务**，套题时须全部生成：

**任务一：填写简单表格**
- **形式**：根据提示填写一张个人信息表格（姓名、年龄、国籍、职业、爱好等）
- **字数要求**：按表格项目填写，无严格字数限制，内容简短即可
- **话题范围**：个人基本信息、家庭、居住地
- **语言特征**：单词或短语，无需成句，词汇极为基础
- **题目风格示例**：
  > Заполните анкету. Напишите информацию о себе.
  > Имя: ___　Фамилия: ___　Возраст: ___　Страна: ___　Профессия: ___　Хобби: ___

**任务二：写明信片或简短留言**
- **形式**：给朋友写一张明信片或简短问候信息
- **字数要求**：30–40 слов
- **话题范围**：自我介绍、居住地、日常生活、兴趣爱好（非常基础）
- **语言特征**：简单句，常见词汇，无需复杂语法
- **题目风格示例**：
  > Напишите открытку другу. Расскажите, где вы сейчас живёте и что вы любите делать в свободное время. (30–40 слов)

### A2 — Базовый（基础级）

本级别共 **2 道任务**，套题时须全部生成：

**任务一：写短信或简短留言**
- **形式**：给朋友或家人发一条简短的文字留言，告知某件事或提出请求
- **字数要求**：30–50 слов
- **话题范围**：约定见面、告知行程、提醒某事、简单请求帮助
- **语言特征**：简单句，非正式语气，常用日常表达
- **题目风格示例**：
  > Напишите сообщение другу. Расскажите, где вы сейчас находитесь и когда вернётесь домой. Попросите его о помощи. (30–50 слов)

**任务二：给朋友写信**
- **形式**：给朋友写一封信，描述近期的生活、计划或经历
- **字数要求**：50–80 слов
- **话题范围**：学习、工作、购物、城市、交通、天气、休闲、节假日
- **语言特征**：简单复合句，常用连接词（и, но, потому что, поэтому）
- **题目风格示例**：
  > Напишите письмо другу. Расскажите о том, как вы провели последние выходные. Что вы делали? С кем? Понравилось ли вам? (50–80 слов)

### B1 — Первый сертификационный уровень（一级 / ТРКИ-1）

本级别共 **2 道任务**，套题时须全部生成：

**任务一：读写结合——阅读理解后作答并写作**
- **形式**：提供一篇俄语阅读材料（200–300 词），要求考生阅读后用俄语回答若干问题，并在此基础上写一封信或短文
- **字数要求**：回答问题 + 正文，合计不少于 20 句（не менее 20 предложений）
- **话题范围**：旅行、文化、社会生活、节假日、自然与城市
- **语言特征**：能提取文中信息，组织成有逻辑的叙述，使用过去/将来时，能表达个人观点
- **题目结构**：先呈现阅读文本，再列出若干问题要点（用破折号 — 列出），最后写明字数/句数要求
- **题目风格示例**：
  > Задание 1. Прочитайте текст «...» и напишите:
  > — [问题1]
  > — [问题2]
  > — [问题3]
  > — [个人观点问题]
  > В Вашем письме должно быть не менее 20 предложений.

**任务二：个人书信——叙述个人经历**
- **形式**：给朋友写信，描述一段真实发生的个人经历（购物、出行、节日等）
- **字数要求**：不少于 20 句（не менее 20 предложений）
- **话题范围**：购物经历、周末活动、旅行见闻、节日庆祝、学习/工作经历
- **语言特征**：叙述性文体，能描述时间顺序、地点变换，表达感受与评价
- **题目结构**：描述一个具体情境，列出若干要表达的内容要点（破折号列出）
- **题目风格示例**：
  > Задание 2. Вчера вы ... Сегодня вы пишете письмо своему другу (подруге), в котором хотите рассказать о ...
  > В письме сообщите следующее:
  > — [内容要点1]
  > — [内容要点2]
  > — [内容要点3]
  > В Вашем письме должно быть не менее 20 предложений.

### B2 — Второй сертификационный уровень（二级 / ТРКИ-2）

本级别共 **3 道任务**，套题时须全部生成：

**任务一：信息推荐信（半正式，信息摘选类）**
- **形式**：基于题目提供的广告/资讯/材料信息，写一封向朋友或同事推荐的信
- **字数要求**：题目中不硬性规定字数，但答卷应在 150–200 слов 左右
- **时间限制参考**：20 分钟
- **话题范围**：留学项目、培训课程、文化活动、旅游项目等
- **语言特征**：半正式文体，能筛选、概括并转述信息，逻辑清晰，语气适当
- **题目风格示例**：
  > Задание 1. Представьте, что Ваш друг хочет [目的]. На основе предлагаемой информации напишите ему письмо, в котором рекомендуете несколько вариантов. Ваше письмо должно содержать информацию, достаточную для принятия решения.
  > （此处附上 3–5 条模拟广告/简介信息供考生提取）

**任务二：正式信件（官方请求类）**
- **形式**：根据题目描述的情境，写一封正式信件，提出有理有据的申请或请求
- **字数要求**：约 100–150 слов
- **时间限制参考**：15 分钟
- **话题范围**：会议安排变更、申请更改日程、投诉、询问官方信息等
- **语言特征**：官方书面语体，措辞正式，有礼貌，论据充分
- **题目风格示例**：
  > Задание 2. Представьте, что [情境描述]. Напишите письмо [收信人], в котором аргументированно просите [请求内容].

**任务三：非正式个人信件（描述人物特征类）**
- **形式**：给朋友写一封非正式信件，介绍或推荐某个认识的人
- **字数要求**：约 100–150 слов
- **时间限制参考**：20 分钟
- **话题范围**：推荐某人担任某职位、描述朋友的性格与能力、介绍某人的经历与特点
- **语言特征**：非正式文体，语气友好，能描述人物性格、能力、经历等多个维度
- **题目结构**：描述情境，列出需要涵盖的描述要点（破折号列出）
- **题目风格示例**：
  > Задание 3. Представьте, что Ваш коллега обратился к Вам с просьбой порекомендовать [某人/某类人]. Напишите дружеское письмо, в котором охарактеризуйте [人物]，а именно:
  > — [特征要点1]
  > — [特征要点2]
  > — [特征要点3]

### C1 — Третий сертификационный уровень（三级 / ТРКИ-3）

本级别共 **3 道任务**，套题时须全部生成：

**任务一：分析性信件（基于阅读文本）**
- **形式**：阅读一篇 400–500 词的俄语文章，写一封信，对文章内容进行分析和评价
- **字数要求**：200–250 слов
- **时间限制参考**：25 分钟
- **话题范围**：社会现象、媒体与文化、科技与生活、当代社会问题
- **语言特征**：学术色彩，能摘引、概括、分析、评价，立场明确，逻辑清晰
- **题目结构**：先呈现阅读文本（400–500 词），再给出写信的具体要求（破折号列出）
- **具体要点**（题目须包含）：
  - 说明信息来源
  - 阐述文中所描述的现状
  - 列举支持或反对某观点的论据
  - 描述未来发展前景
  - 表达对文章内容的个人态度
- **题目风格示例**：
  > Задание 1. Прочитайте текст и на основе прочитанного напишите письмо своему русскому знакомому, который интересуется [话题].
  > При этом:
  > — сообщите об источнике информации;
  > — сообщите о современном положении дел в области [话题];
  > — перечислите факты и укажите предпосылки/причины ...;
  > — изложите аргументацию точек зрения за и против ...;
  > — опишите перспективы развития ... в будущем;
  > — выразите своё отношение к информации, изложенной в статье.
  > Объём текста: 200–250 слов.

**任务二：信息摘要/电子邮件（压缩改写类）**
- **形式**：阅读一篇 300–350 词的文章，将其压缩改写为一封电子邮件或信息摘要
- **字数要求**：50–70 слов
- **时间限制参考**：20 分钟
- **话题范围**：大学招生政策、机构介绍、官方通知等信息类文本
- **语言特征**：精炼、客观，使用常见缩写，符合电子邮件/信息传递的格式规范
- **具体要点**（题目须包含）：减少句子数量、压缩句子、使用常用缩写、符合电子通信格式
- **题目风格示例**：
  > Задание 2. Прочитайте текст. Напишите на основе прочитанного сообщение для передачи по электронной почте тому, кто хотел бы узнать о [话题]. Для этого сократите количество предложений и сами предложения, используйте общепринятые сокращения, оформите сообщение так, как принято при передаче информации по электронным каналам связи.
  > Объём текста: 50–70 слов.

**任务三：议论文/散文（多题选一）**
- **形式**：从三个话题中选择一个，写一篇议论文或散文
- **字数要求**：150–200 слов
- **时间限制参考**：30 分钟
- **话题范围**：哲学性、人文类、社会类话题（如教育、技术与人、文化认同等）
- **语言特征**：论点清晰，能引用事例，体现个人思考，文体统一
- **题目结构**：提供三个话题供选择（用序号列出）
- **题目风格示例**：
  > Задание 3. Напишите рассуждение-эссе, изложите свои размышления на одну из трёх тем:
  > 1. [话题一]
  > 2. [话题二]
  > 3. [话题三]
  > Объём текста: 150–200 слов.

### C2 — Четвёртый сертификационный уровень（四级 / ТРКИ-4）

本级别共 **3 道任务**，套题时须全部生成：

**任务一：发言提纲（论点陈述类）**
- **形式**：从若干话题中选择一个，写一篇发言提纲，对比分析本国与俄罗斯（或两种文化/制度）在该方面的异同
- **字数要求**：200–250 слов
- **时间限制参考**：20 分钟
- **话题范围**：跨文化对比类议题（教育体制、家庭观念、节日传统、城市生活等）
- **语言特征**：条理清晰，能使用对比结构，论证有力，适合口头发言
- **具体要点**（题目须包含）：对比对象须明确（本国 vs. 俄罗斯），涵盖多个维度
- **题目风格示例**：
  > Задание 1. Представьте, что Вас приглашают выступить с сообщением в интернациональном клубе. Выберите одну из тем:
  > 1. [对比话题一]
  > 2. [对比话题二]
  > 3. [对比话题三]
  > Ваша задача: написать тезисы Вашего сообщения, в котором объектами сопоставления являются:
  > — [对比维度1]
  > — [对比维度2]
  > — [对比维度3]
  > Объём текста: 200–250 слов.

**任务二：建议/推荐信（个人化指导类）**
- **形式**：给即将到本国（考生所在国）工作或生活的俄语母语者写一封信，提供实用建议
- **字数要求**：150–200 слов
- **时间限制参考**：20 分钟
- **话题范围**：文化适应、职场礼仪、生活习惯、社会规范等
- **语言特征**：个人化、友好，建议具体，文体自由，但语言精准
- **题目风格示例**：
  > Задание 2. Ваш русский знакомый (знакомая / друг / коллега) едет работать в Вашу страну. Напишите ему/ей письмо с рекомендациями: что важно знать о [本国]，на что обратить внимание, как лучше адаптироваться.
  > Объём текста: 150–200 слов.

**任务三：内容复述（评论文/复述类）**
- **形式**：基于一部文学/影视/艺术作品，写一篇内容复述，仅复述情节，不作评价
- **字数要求**：300–350 слов
- **时间限制参考**：20 分钟
- **话题范围**：文学作品（小说、中篇小说）、影视作品（电影、剧集）、戏剧演出
- **语言特征**：客观叙述，语言精准，能准确概括情节，结构清晰，符合复述文体规范
- **具体标准**（题目须列出）：内容完整、逻辑连贯、语言准确、文体一致
- **题目风格示例**：
  > Задание 3. Напишите пересказ произведения (фильма, спектакля, книги, рассказа) в форме рецензии — только той её части, в которой пересказывается основное содержание/сюжет (без оценки). Ваш текст должен соответствовать следующим критериям:
  > — полнота содержания;
  > — логическая связность;
  > — точность языкового оформления;
  > — единство стиля.
  > Объём текста: 300–350 слов.

## 第四步：生成话题时的注意事项

- 每次生成的题目话题应有**多样性**——避免重复同一话题（如不要每次都出"写给朋友的信"或"科技话题"）。
- 题目本身用地道的**俄语**写成，语言要符合该级别考生能够理解的水平。
- 字数/句数要求写在题目最后，格式如：`(100–150 слов)` 或 `не менее 20 предложений`。
- **B1、B2、C1 级别**的任务一需要包含**阅读材料或参考信息**（自行创作，话题合理即可）。
- 生成整套题时，各任务之间**话题尽量不重复**，以体现题型的多样性。
- **不添加**中文解释、评分标准、参考答案或其他额外内容。Word 文档中只有题目本身。

## 第五步：生成 Word 文档

使用 Python 的 `python-docx` 库生成 .docx 文件。

### 文档结构

**单道题：**
```
[总标题]   Субтест «Письмо» — Уровень XX  （居中，加粗，字号16，蓝色）
[空一行]
[题目正文]  俄语题目文本（含阅读材料，如有）  （正文，字号12，行距1.5）
```

**整套题（多任务）：**
```
[总标题]   Субтест «Письмо» — Уровень XX  （居中，加粗，字号16，蓝色）
[空一行]
[任务标题] Задание 1                        （加粗，字号13）
[空行]
[任务一正文]                                （正文，字号12，行距1.5）
[分隔线]   ————————————————
[空行]
[任务标题] Задание 2                        （加粗，字号13）
[空行]
[任务二正文]                                （正文，字号12，行距1.5）
…（以此类推）
```

### 代码模板

```python
from docx import Document
from docx.shared import Pt, RGBColor
from docx.enum.text import WD_ALIGN_PARAGRAPH

doc = Document()

# 总标题
title = doc.add_heading(level=1)
title.alignment = WD_ALIGN_PARAGRAPH.CENTER
run_title = title.add_run(f"Субтест «Письмо» — Уровень {level}")
run_title.font.size = Pt(16)
run_title.font.bold = True
run_title.font.color.rgb = RGBColor(0x1F, 0x49, 0x7D)

doc.add_paragraph()  # 空行

# 若为整套题，循环写入各任务；若为单道题，只写一个任务块
for i, task_text in enumerate(tasks, start=1):
    if len(tasks) > 1:
        # 任务小标题（仅套题时显示）
        task_title = doc.add_paragraph()
        run_t = task_title.add_run(f"Задание {i}")
        run_t.font.size = Pt(13)
        run_t.font.bold = True
        doc.add_paragraph()  # 小标题后空行

    # 题目正文
    body = doc.add_paragraph()
    body.paragraph_format.line_spacing = Pt(18)
    run_body = body.add_run(task_text)
    run_body.font.size = Pt(12)

    # 套题任务间分隔（最后一题后不加）
    if len(tasks) > 1 and i < len(tasks):
        sep = doc.add_paragraph("─" * 40)
        sep.alignment = WD_ALIGN_PARAGRAPH.CENTER
        doc.add_paragraph()

# 保存
suffix = "Комплект" if len(tasks) > 1 else "Задание"
filename = f"ТРКИ_{level}_{suffix}.docx"
doc.save(filename)
```

将文件保存在当前工作目录，然后用 `publish_artifact` 交付给用户。
