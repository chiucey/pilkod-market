# 数字经济核心知识库

## 一、数字经济定义与框架

### 官方定义
- **国家统计局（2021）**：数字经济是指以数据资源为关键要素，以现代信息网络为主要载体，以信息通信技术融合应用、全要素数字化转型为重要推动力，促进公平与效率更加统一的新型经济形态。
- **G20峰会**：数字经济是指以使用数字化的知识和信息作为关键生产要素、以现代信息网络作为重要载体、以信息通信技术的有效使用作为效率提升和经济结构优化的重要推动力的一系列经济活动。

### 数字经济四大组成部分（中国信通院框架）
1. **数字产业化**：即信息通信产业，包括电子信息制造业、电信业、互联网、软件和信息技术服务业等。
2. **产业数字化**：即传统产业因应用数字技术带来的产出增加和效率提升部分，包括工业互联网、平台经济、智慧农业等。
3. **数字化治理**：包括多元治理、数字技术支撑的政府治理等。
4. **数据价值化**：包括数据采集、数据标注、数据存储、数据加工、数据流通、数据分析、数据应用等。

## 二、核心指标体系

### 宏观规模指标
| 指标名称 | 计算方式 | 说明 |
|---------|---------|------|
| 数字经济规模 | 数字产业化规模 + 产业数字化规模 | 核心衡量指标 |
| 数字经济占GDP比重 | 数字经济规模 / GDP × 100% | 反映数字化程度 |
| 数字产业化增加值 | ICT行业增加值合计 | 直接数字产出 |
| 产业数字化增加值 | 各传统行业数字化贡献加总 | 间接数字产出 |

### 基础设施指标
- 互联网普及率 = 网民数 / 总人口 × 100%
- 宽带接入渗透率 = 宽带用户数 / 家庭总数 × 100%
- 5G基站密度 = 5G基站数量 / 国土面积（万平方公里）
- 数据中心机架数（万架）

### 创新能力指标
- 数字经济相关专利申请数/授权数
- 软件著作权登记数
- 数字经济领域研发投入强度（R&D支出/数字经济规模）

### 市场活力指标
- 数字经济市场主体数量（企业注册数）
- 互联网企业营业收入
- 电商交易额及增速
- 移动支付交易规模

## 三、重点领域与细分赛道

### 平台经济
- **定义**：以互联网平台为基础，利用算法、数据、技术等要素组织资源，形成多边市场的新型经济形态。
- **主要形态**：电商平台（阿里、京东）、出行平台（滴滴）、外卖平台（美团）、内容平台（抖音、B站）
- **监管重点**：反垄断、数据安全、算法公平

### 数据要素市场
- **数据确权**：数据资源持有权、数据加工使用权、数据产品经营权三权分置
- **数据交易**：上海数据交易所、北京国际大数据交易所、深圳数据交易所
- **数据估值方法**：成本法、收益法、市场法

### 工业互联网
- **核心功能**：设备互联、数据采集、边缘计算、平台集成、应用开发
- **五层架构**：设备层、网络层、平台层（IaaS/PaaS）、数据层、应用层
- **典型平台**：卡奥斯（海尔）、徐工汉云、航天云网

### 数字金融
- **范畴**：互联网银行、第三方支付、数字货币（DCEP/数字人民币）、金融科技
- **数字人民币**：央行发行，M0替代，双层运营（央行-商业银行-用户）

### 智慧城市
- **核心系统**：城市大脑、CIM平台、政务数据共享、智慧交通、智慧医疗
- **评价体系**：IDC、麦肯锡、住建部等多套评价标准

## 四、政策法规体系

### 国家战略文件
| 文件名称 | 发布时间 | 核心要点 |
|---------|---------|---------|
| 《数字中国建设整体布局规划》 | 2023年2月 | "2522"总体框架，夯实数字基础设施和数据资源体系两大基础，推进数字技术与经济、政治、文化、社会、生态五位一体深度融合 |
| 《数字经济发展战略纲要》 | 2021年12月 | 确立数字经济发展路线图，提出2025年、2035年目标 |
| 《"十四五"数字经济发展规划》 | 2022年1月 | 7大重点工程，目标数字经济核心产业增加值占GDP10% |
| 《数据安全法》 | 2021年9月 | 数据分类分级保护，数据安全审查 |
| 《个人信息保护法》 | 2021年11月 | 个人信息处理规则，权益保护 |
| 《网络安全法》 | 2017年6月 | 网络安全基础法律框架 |
| 《关于构建数据基础制度更好发挥数据要素作用的意见》（数据二十条） | 2022年12月 | 数据产权、数据流通、数据分配、数据治理四大制度 |

### 地方政策亮点
- **上海**：打造全球数字之都，建设数据交易所、数字人民币试点
- **北京**："两区"建设，全国数字经济创新引领区
- **深圳**：数字经济先行示范区，数字人民币全场景试点
- **杭州**：数字经济第一城，城市大脑样板

## 六、数字经济分析框架

### PEST分析框架（数字经济版）
- **Policy（政策）**：数字经济战略、数据监管、平台治理政策
- **Economy（经济）**：数字经济规模、渗透率、增速、就业贡献
- **Society（社会）**：数字鸿沟、数字素养、消费习惯变化
- **Technology（技术）**：AI、云计算、区块链、量子计算发展水平

### 产业链分析框架
```
上游：基础设施层
├── 芯片、服务器、网络设备（硬件）
└── 操作系统、数据库、中间件（基础软件）

中游：平台服务层
├── 云计算（IaaS/PaaS/SaaS）
├── 大数据平台
└── AI平台

下游：应用场景层
├── 工业互联网
├── 智慧城市
├── 数字金融
└── 数字贸易
```

### 竞争格局分析
- **波特五力**：新进入者威胁、替代品威胁、买方议价能力、供方议价能力、行业竞争
- **平台经济特殊性**：网络效应、多边市场、赢者通吃、数据壁垒
