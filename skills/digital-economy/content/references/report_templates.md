# 数字经济研究报告模板库

## 模板一：行业数字化转型分析报告

### 标准结构
```
封面
执行摘要（300-500字，含核心结论3-5条）

一、行业数字化现状
   1.1 行业基本概况（规模、增速、格局）
   1.2 数字化进程评估（渗透率、成熟度）
   1.3 标杆企业案例

二、驱动因素分析
   2.1 政策驱动
   2.2 市场需求驱动
   2.3 技术突破驱动
   2.4 竞争压力驱动

三、关键挑战与痛点
   3.1 技术瓶颈
   3.2 数据治理挑战
   3.3 人才缺口
   3.4 安全合规风险

四、典型应用场景与案例
   [每个场景：背景→方案→成效→可复制性]

五、未来趋势展望
   5.1 短期（1-2年）趋势
   5.2 中期（3-5年）趋势
   5.3 颠覆性变革预判

六、政策建议/战略建议
   [面向政府/企业/行业协会的差异化建议]

附录：数据来源、术语表
```

## 写作规范

### 数据引用规范
- 所有数据必须标注来源和时间
- 格式：数据内容（来源机构，发布年份）
- 示例：2024年中国数字经济规模达56.1万亿元，占GDP比重47.0%（中国信通院，2025年）

### 图表配套规范
- 趋势数据 → 折线图/面积图
- 占比数据 → 饼图/环形图/树图
- 对比数据 → 柱状图/条形图
- 多维度评估 → 雷达图
- 空间分布 → 热力地图

### 语言风格规范
- 使用专业但可读的语言，避免过度堆砌术语
- 结论前置，先观点后数据
- 量化描述优先（"增长32%"优于"大幅增长"）
- 关键数据加粗或用表格呈现

### 执行摘要写法
1. 第一句：点明报告核心结论（最重要的1个发现）
2. 第2-4句：支撑性数据或事实
3. 第5-7句：关键挑战或风险
4. 最后：核心建议（1-2条）
