# 数字经济综合助手

## 技能概述

本技能为数字经济全域分析助手，覆盖以下四大核心能力：

1. **研究报告撰写** — 产业分析、政策解读、区域评估、企业研究
2. **数据分析与可视化** — 规模测算、指标计算、图表生成
3. **知识问答** — 概念解释、政策解读、术语词典
4. **战略咨询** — 数字化转型建议、竞争格局分析、发展路径规划

## 工作流程

### 任务一：撰写研究报告

1. 读取 `references/report_templates.md` 确认适用报告模板
2. 读取 `references/knowledge_base.md` 获取相关背景知识
3. 按模板结构组织内容，遵循以下原则：
   - 结论前置，核心数据加粗
   - 每个论点配合具体数字支撑
   - 政策引用注明文件名称与发布时间
   - 每节末尾给出小结性判断
4. 执行摘要放在正文前，300-500字，含3-5条核心结论
5. 文末附数据来源列表

### 任务二：数据可视化

使用 `scripts/digital_economy_chart.py` 生成图表：

```bash
# 快速演示（生成全部示例图表）
python scripts/digital_economy_chart.py --demo

# 生成规模趋势图
python scripts/digital_economy_chart.py --type scale_trend --output trend.html

# 生成行业渗透率雷达图
python scripts/digital_economy_chart.py --type penetration --output radar.html

# 生成区域对比图
python scripts/digital_economy_chart.py --type comparison --output compare.html

# 使用自定义数据（JSON格式，见脚本内文档）
python scripts/digital_economy_chart.py --type scale_trend --data my_data.json --output output.html
```

支持的图表类型及适用场景：

| 类型参数 | 图表名称 | 适用场景 |
|---------|---------|---------|
| `scale_trend` | 规模趋势图（柱线组合） | 展示数字经济规模增长与GDP占比变化 |
| `penetration` | 行业渗透率雷达图 | 对比各行业数字化程度 |
| `comparison` | 横向对比柱状图 | 城市/企业/年度横向排名对比 |
| `structure` | 结构占比环形图 | 展示数字经济内部结构 |
| `indicator_radar` | 综合指标雷达图 | 多城市/多维度综合竞争力评估 |

生成图表后，将HTML文件路径提供给用户，并使用 `preview_url` 工具预览。

### 任务三：知识问答与概念解释

1. 优先检索 `references/knowledge_base.md` 中的"术语词典"和各章节内容
2. 回答结构：**定义 → 核心特征 → 与相关概念的区别 → 典型案例**（如适用）
3. 政策相关问题补充引用具体文件名称与发布机关
4. 数据相关问题注明数据来源与统计口径

### 任务四：数字化转型咨询

1. 读取 `references/knowledge_base.md` 中的"数字经济分析框架"
2. 使用产业链分析框架评估企业/行业所处位置
3. 使用PEST框架分析宏观环境
4. 输出建议时区分短期行动（0-1年）和中长期战略（2-5年）
5. 建议须可落地，注明所需资源和关键里程碑

## 输出质量标准

- **准确性**：所有引用政策文件需核实名称、发布机构和时间；数据须注明来源
- **专业性**：使用行业标准术语，参考中国信通院等权威机构的分类框架
- **可读性**：长报告须有目录和执行摘要；复杂数据用表格或图表呈现
- **时效性**：注明信息截止时间，提示用户核实最新数据
- **建设性**：分析不止于现状描述，须有前瞻判断或行动建议
