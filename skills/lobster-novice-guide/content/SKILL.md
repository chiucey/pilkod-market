# 龙虾新手使用向导

## 技能介绍

欢迎使用龙虾AI助手！本向导将引导您快速上手龙虾的5个核心基础功能，帮助您从零开始体验龙虾的强大能力。

## 功能列表

### 1. 创建文档

**功能说明**：教用户如何在桌面创建文档文件

**操作步骤**：
1. 打开龙虾AI助手对话界面
2. 输入创建文档的指令，例如："请帮我创建一个三季度财务报告文档"
3. 龙虾将自动在桌面创建文档文件
4. 文档内容将包含您指定的主题

**示例场景**：
- 桌面创建"三季度财务报告素材文件"
- 内容包含：三季度扭亏为盈，盈利100万
- 文档字数约500行

---

### 2. 快速截图

**功能说明**：使用龙虾的快速截图功能，在桌面进行屏幕截图

**操作步骤**：
1. 在龙虾对话中输入："截图" 或 "帮我截一张图"
2. 龙虾将启动截图功能
3. 您可以选择截取全屏或自定义区域
4. 截图将自动保存到桌面

**示例场景**：
- 桌面截图名称：截图1
- 快速保存当前屏幕内容
- 支持快速分享到飞书

---

### 3. 对接飞书

**功能说明**：引导用户完成龙虾与飞书的集成对接

**操作步骤**：
1. 在龙虾中输入："对接飞书" 或 "连接飞书"
2. 龙虾将提供飞书集成的操作指南
3. 按照指引完成飞书应用配置
4. 配置完成后进行连接测试
5. 对接成功后即可使用飞书相关功能

**详细流程**：
- 步骤1：获取飞书开放平台应用凭证
- 步骤2：在龙虾中配置飞书Webhook地址
- 步骤3：验证连接是否成功
- 步骤4：开始使用飞书消息推送功能

---

### 4. 发送消息到飞书

**功能说明**：将文件或消息发送到飞书群或个人

**操作步骤**：
1. 确认已完成飞书对接（见功能3）
2. 输入发送指令，例如：
   - "把这个文档发到飞书"
   - "发送桌面的三季度报告到飞书"
3. 选择接收的飞书群或个人
4. 龙虾将自动发送文件或消息内容

**示例场景**：
- 将桌面的三季度财务报告发送到飞书群
- 体验AI驱动的智能聊天交互
- 支持多种文件格式发送

---

### 5. 智能对话交互

**功能说明**：与龙虾进行自然语言对话交互

**操作步骤**：
1. 在主对话界面直接输入问题或指令
2. 龙虾将理解您的意图并给出回应
3. 可以进行多轮对话深入交流
4. 支持追问和澄清

**常用对话场景**：
- "帮我总结一下这个文档"
- "这段代码有什么问题吗"
- "解释一下这个概念"
- "帮我写一段文案"

---

### 6. 高级技巧

**功能说明**：进阶使用技巧，提升使用效率

**技巧列表**：
- **快捷指令**：使用预定义的快捷指令快速完成任务
- **批量操作**：支持一次性处理多个文件或任务
- **上下文记忆**：龙虾会记住对话上下文，支持多轮对话
- **文件拖拽**：直接将文件拖入对话窗口上传

## 常见问题

### Q1: 如何开始使用龙虾？
**A**: 直接在对话框中输入您的问题或指令即可，龙虾会理解并执行。

### Q2: 截图功能在哪里？
**A**: 在对话中输入"截图"或"帮我截一张图"，龙虾会启动截图功能。

### Q3: 如何对接飞书？
**A**: 输入"对接飞书"或"连接飞书"，龙虾会提供详细的配置指南。

### Q4: 可以发送哪些类型的文件？
**A**: 支持发送文档、图片、压缩包等多种文件类型。

### Q5: 对话内容会被保存吗？
**A**: 龙虾会记住当前会话的上下文，关闭会话后会清除记录。
