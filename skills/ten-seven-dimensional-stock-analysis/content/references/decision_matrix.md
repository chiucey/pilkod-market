## 二、一票否决制

### 触发条件（直接降为⭐级）

| 否决项 | 触发条件 | 说明 |
|--------|----------|------|
| 财务造假 | 被证监会立案调查、审计师出具"无法表示意见" | 违法 |
| 退市风险 | 触及面值退市（<1元20日）、财务退市指标 | 退市 |
| 实控人问题 | 实控人失联/被抓/变更 | 治理瘫痪 |
| 流动性枯竭 | 日均成交额<2000万（小盘股视情况） | 出不去 |
| 重大事故 | 安全事故导致停产、重大赔偿 | 经营中断 |

## 四、仓位管理算法

### 基础仓位计算

```
建议仓位 = 基础仓位 × 市场系数 × 个股系数

市场系数：
- 主升期：1.0
- 回暖期：0.6
- 退潮期：0.3
- 冰点期：0

个股系数（基于十维评分）：
- ⭐⭐⭐⭐⭐：1.0
- ⭐⭐⭐⭐：0.8
- ⭐⭐⭐：0.5
- ⭐⭐：0.2
- ⭐：0
```

### 仓位调整规则

| 情况 | 加仓 | 减仓 |
|------|------|------|
| 盈利后回调 | 盈利>10%后回调，不破均线 | 破均线减半 |
| 连续大涨 | 涨>20%后不再加仓 | - |
| 触及压力位 | 放量滞涨减仓 | - |
| 触及支撑位 | 缩量企稳加仓 | 放量跌破止损 |

## 五、盈亏比测算

### 公式

```
盈亏比 = 潜在收益 / 潜在风险

理想盈亏比：
- 优秀：≥3:1
- 良好：2:1 ~ 3:1
- 一般：1:1 ~ 2:1
- 较差：<1:1（不建议参与）
```

### 测算示例

```
当前价：50元
止损位：45元（跌破支撑）
目标位：65元（量度涨幅/压力位）

潜在收益 = 65 - 50 = 15元 (30%)
潜在风险 = 50 - 45 = 5元 (10%)
盈亏比 = 15/5 = 3:1 ✓

入场区间：48-52元（回调入场更佳）
止损纪律：跌破45元无条件离场
```
