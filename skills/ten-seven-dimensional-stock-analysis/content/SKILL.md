# 十维全景 + 七维穿透股票投资决策分析

## 核心定位
专业级A股/港股/美股投资分析技能，采用"宏观定方向，中观选赛道，微观择个股，技术找买点，风控保本金"的核心理念。

## 工作流程

### 第一步：市场环境诊断（前置过滤器）

**必须首先判断市场"天气"**，若环境恶劣则终止个股分析：

| 阶段 | 涨跌比 | 连板高度 | 炸板率 | 成交量能 | 操作 |
|------|--------|----------|--------|----------|------|
| ❄️ 冰点期 | <0.3 | <2板 | >50% | 缩量极致 | 空仓观望 |
| 🌱 回暖期 | 0.4-0.6 | 3-4板 | 30%-45% | 温和放量 | 轻仓试错 |
| 🔥 主升期 | >0.7 | ≥5板 | <25% | 万亿+ | 重仓出击 |
| 🍂 退潮期 | <0.4 | 高位断板 | >40% | 放量滞涨 | 防守撤退 |

**执行规则**：若市场诊断为"冰点"或"退潮"，后续分析流程自动终止。

### 第二步：十维全景扫描（定量评分）

对个股进行10维度体检，每项满分10分：

**宏观与战略层（权重15%）**
1. **商业模式**：护城河类型（垄断/差异化/同质化）
2. **风险压力测试**：负债率、现金流、潜在风险

**中观与成长层（权重25%）**
3. **收入结构健康度**：主业占比、客户集中度、现金流/净利润比
4. **成长性与壁垒**：订单能见度、国产替代程度、CAGR预期
5. **筹码分布**：位置、获利盘比例、机构持仓变化

**微观与交易层（权重60%）**
6. **估值水平**：PE/PB历史分位、PEG
7. **盈利能力**：ROE、毛利率、盈利稳定性
8. **管理层与治理**：回购分红、股权激励、管理层行为
9. **技术面形态**：均线排列、平台突破、量价配合
10. **资金流向**：主力净流入、北向/机构持仓变化、龙虎榜

**加权总分计算**：
```
总分 = 宏观层×15% + 中观层×25% + 微观层×60%
```

### 第三步：七维深度穿透（定性验证）

在评分基础上挖掘深层逻辑，寻找"预期差"：

| 穿透维度 | 核心问题 |
|----------|----------|
| **宏观穿透** | 政策是"真金白银"还是"口号"？利率敏感度？ |
| **中观穿透** | 产业链话语权？竞争格局？新进入者威胁？ |
| **微观穿透** | 财务勾稽关系？隐性资产/负债？ |
| **情绪穿透** | 市场一致性预期？舆情与走势背离？ |
| **博弈穿透** | 主力意图（建仓/洗盘/出货）？筹码交换率？ |
| **时空穿透** | 时间窗口（财报/解禁）？空间位置（周期位置）？ |
| **事件穿透** | 确定性催化剂？潜在黑天鹅？ |

### 第四步：综合决策与策略生成

**评级映射**：

| 总分区间 | 星级 | 评级 | 建议仓位 |
|----------|------|------|----------|
| 90-100 | ⭐⭐⭐⭐⭐ | 强烈推荐 | 80%-100% |
| 75-89 | ⭐⭐⭐⭐ | 积极配置 | 50%-80% |
| 60-74 | ⭐⭐⭐ | 中性观察 | 20%-40% |
| 40-59 | ⭐⭐ | 谨慎回避 | 0%-10% |
| <40 | ⭐ | 坚决卖出 | 0% |

**必须输出三种情景应对**：
- **情景A（乐观）**：触发条件 → 目标价 → 加仓动作
- **情景B（中性）**：震荡区间 → 高抛低吸策略
- **情景C（悲观）**：止损位 → 无条件离场纪律

**一票否决项**（直接降为⭐级）：
- 财务造假/立案调查
- 触及退市指标
- 实控人失联/被抓
- 流动性枯竭（日均成交<2000万）

## 输出标准模板

报告必须包含：
1. 市场状态诊断（阶段判定+依据+操作建议）
2. 十维全景评分表（10维度得分+加权总分+星级）
3. 七维核心洞察（逻辑、预期差、疑点）
4. 关键价位（支撑/压力/盈亏比）
5. 情景策略推演（A/B/C三种情况）
6. 风险提示（至少3条具体风险）
7. 终极结论（操作指令+仓位+核心观点）
