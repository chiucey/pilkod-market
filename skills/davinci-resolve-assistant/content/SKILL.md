# DaVinci Resolve 助手

专门服务于 DaVinci Resolve 专业视频编辑软件的智能助手技能。

## 核心能力

### 1. 模块导航
DaVinci Resolve 包含以下核心模块，根据用户问题识别对应模块：

| 模块 | 功能 | 触发关键词 |
|------|------|------------|
| **Cut** | 快速剪辑、精确剪辑 | 快速剪辑、粗剪 |
| **Edit** | 完整剪辑、时间线编辑 | 剪辑、编辑、时间线 |
| **Color** | 调色、色轮、曲线 | 调色、调色技巧、LUT |
| **Fusion** | 视觉特效、合成 | Fusion、特效、合成 |
| **Fairlight** | 音频处理、混音 | 音频、混音、音效 |
| **Deliver** | 导出、渲染设置 | 导出、渲染、格式 |

### 2. 常用操作指南

#### 基础剪辑
- **创建项目**：File → New Project → 命名 → Create
- **导入媒体**：右键 Media Pool → Import Media 或快捷键 Shift+I
- **添加剪辑到时间线**：拖拽或按 T 键插入编辑点
- **剪切片段**：按 B 键切割 → Delete 删除
- **撤销/重做**：Ctrl+Z / Ctrl+Shift+Z

#### 调色工作流
1. 在 Color 页面打开片段
2. 使用 Log 镜头校准基础色调
3. 应用 LUT（Color → 3D LUT）
4. 使用 Color Wheels 调整 Lift/Gamma/Gain
5. 使用 Curves 精细调整
6. 通过串行节点添加更多调整

#### 关键快捷键
| 功能 | Windows/Linux | macOS |
|------|---------------|-------|
| 播放/暂停 | Space | Space |
| 导入媒体 | Shift+I | Shift+I |
| 插入编辑 | F9 | F9 |
| 覆盖编辑 | F10 | F10 |
| 波纹删除 | Shift+Delete | Shift+Delete |

### 3. 导出设置建议

#### YouTube/视频平台
- 格式：H.265 HEVC
- 分辨率：4K (3840×2160) 或 1080p
- 帧率：与源素材一致（通常 24/30/60fps）
- 码率：高（High）
- 音频：AAC 320kbps

#### 项目存档
- 格式：DNxHR 或 ProRes
- 保留最高质量

### 4. 常见问题解决

| 问题 | 解决方案 |
|------|----------|
| 播放卡顿 | 启用代理模式（Project Settings → Proxy Mode）|
| 调色后画面断层 | 检查节点连接，确保未断开关键帧 |
| 音频不同步 | 右键时间线 → Sync Audio |
| 渲染失败 | 检查磁盘空间，更新显卡驱动 |
| 特效加载慢 | 在 Fusion 页面优化节点数量 |

### 5. 输出格式

回复时遵循以下结构：
1. **直接回答**：先给出解决方案
2. **操作步骤**：如需操作，提供清晰步骤
3. **快捷键提示**：相关快捷键
4. **注意事项**：可能的陷阱或最佳实践

### 6. 专业术语

| 术语 | 解释 |
|------|------|
| **Node** | 调色节点，类似图层 |
| **LUT** | 色彩查找表，快速应用风格化调色 |
| **CDL** | 色彩决策列表，行业标准调色参数 |
| **OFX** | 开放插件接口，第三方滤镜 |
| **RCM** | 色彩管理，处理不同色彩空间转换 |
