# 阿里巴巴国际站产品详情页生成器

## 功能概述

本技能能够分析阿里巴巴国际站产品页面的设计风格，并基于用户提供的素材生成符合该风格的产品详情页。

## 工作流程

### 步骤 1：接收阿里巴巴国际站链接

**接收内容**：
- 阿里巴巴国际站产品详情页链接
- 或多个产品链接（用于批量风格参考）

**处理方式**：
1. 使用 `extract_content_from_websites` 工具提取页面内容
2. 分析页面结构、配色方案、排版布局
3. 提取关键风格元素：
   - 主色调和辅助色
   - 字体样式和大小层级
   - 模块间距和内边距
   - 图片展示比例和布局
   - 按钮和交互元素样式

### 步骤 2：接收用户素材

**支持素材类型**：
- 产品图片（PNG/JPG/WebP，支持拖拽上传）
- 产品参数信息（名称、规格、价格、MOQ等）
- 描述文案（可提供结构化或自由文本）
- 公司信息（品牌Logo、企业介绍等）

**素材接收方式**：
- 用户直接粘贴图片URL或上传本地文件
- 用户提供产品参数的结构化描述
- 用户提供文案内容或关键卖点数

### 步骤 3：风格分析与像素规范确认

**阿里巴巴国际站详情页规范**：
- 详情页宽度：750px（移动端）/ 1200px（桌面端）
- 图片推荐尺寸：
  - 横版大图：750x400px
  - 竖版产品图：400x500px
  - 详情模块图：750x auto（保持比例）
- 字体规范：
  - 标题：24px-32px，加粗
  - 副标题：18px-20px
  - 正文：14px-16px
  - 辅助文字：12px
- 模块间距：20px-30px
- 内边距：15px-20px

**提取的风格元素**：
- 配色方案（主色、辅色、背景色、文字色）
- 排版风格（居中/左对齐/卡片式）
- 模块布局（单列/双列/网格）
- 视觉层次（分隔线、图标、留白）

### 步骤 4：生成详情页

**生成内容**：
1. HTML结构文件
2. 内联CSS样式（响应式设计）
3. 图片资源处理（压缩、优化路径）

**输出规格**：
- 格式：单文件HTML（便于嵌入和分享）
- 响应式：支持移动端和桌面端自适应
- 图片：内联Base64或外部CDN链接
- 兼容性：现代浏览器（Chrome、Firefox、Safari、Edge）

## 使用示例

### 示例 1：分析链接风格

```
用户：请分析这个阿里巴巴产品页面的风格
链接：https://www.alibaba.com/product-detail/xxx.html
```

### 示例 2：基于链接风格生成详情页

```
用户：按照这个链接的风格，为我的产品生成详情页
链接：https://www.alibaba.com/product-detail/xxx.html
产品名：智能蓝牙音箱
主图：https://example.com/speaker.jpg
参数：防水等级IPX7，蓝牙5.0，续航24小时
描述：便携式蓝牙音箱，适合户外使用
```

### 示例 3：提供素材和参考

```
用户：参考这个风格页面，生成我的产品详情页
参考链接：https://www.alibaba.com/product-detail/yyy.html
素材：
- 产品图片：[上传5张产品图]
- 产品名称：无线充电板
- 规格：15W快充，Qi认证
- 特点：智能散热、过压保护、轻薄设计
```

## 注意事项

1. **版权合规**：生成的详情页仅供学习参考，使用时请确保素材版权合规
2. **图片优化**：建议用户提供适当尺寸的图片，过大图片会自动压缩
3. **文字内容**：用户需确保提供的文案内容真实准确
4. **响应式测试**：生成后建议在移动端和桌面端都进行预览

## 技术实现

- 前端：HTML5 + CSS3 + 响应式设计
- 图片处理：支持Base64内嵌或CDN外链
- 布局引擎：Flexbox + CSS Grid
- 字体：系统字体栈 + 阿里巴巴普惠体（可选）
