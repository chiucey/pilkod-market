# 数据合规法规速查手册

## 一、个人信息保护法（PIPL）核心条款

### 敏感个人信息识别

| 类型 | 举例 | 特殊要求 |
|-----|------|---------|
| 生物识别 | 人脸识别、指纹、虹膜 | 需单独告知、单独同意 |
| 宗教信仰 | 宗教信仰信息 | 需单独告知、单独同意 |
| 特殊身份 | 残障人士、患者信息 | 需单独告知、单独同意 |
| 金融账户 | 银行账户、证券账户 | 需单独告知、单独同意 |
| 行踪轨迹 | 位置跟踪、出行记录 | 需单独告知、单独同意 |
| 未成年人信息 | 14岁以下儿童信息 | 需监护人同意 |

### 合法性基础（第13条）

```
可处理的合法性基础：
□ 取得个人同意
□ 订立、履行合同所必需
□ 履行法定职责或义务
□ 应对突发公共卫生事件
□ 公共利益实施新闻报道、舆论监督
□ 已在合理范围内处理已公开信息
□ 法律、行政法规规定的其他情形
```

### 个人信息主体权利

| 权利类型 | 法律依据 | 处理时限 |
|---------|---------|---------|
| 知情权 | 第17条 | 收集时告知 |
| 决定权 | 第14条 | 同意可撤回 |
| 查询权 | 第45条 | 15日内回复 |
| 更正权 | 第45条 | 15日内回复 |
| 删除权 | 第47条 | 15日内删除 |
| 解释权 | 第45条 | 合理期限内 |
| 可携带权 | 第45条 | 15日内回复 |
| 拒绝权 | 第44条 | 不得拒绝 |

## 二、数据安全法核心要求

### 数据分类分级参考

```
一般数据 → 内部数据 → 重要数据 → 核心数据
   ↓          ↓           ↓          ↓
低敏感    中敏感      高敏感     极高敏感
```

### 重要数据识别要素

1. 关系国家安全的数据
2. 关系公共利益的数据
3. 关系特定群体利益的数据
4. 大规模个人信息聚合后的数据
5. 可能危害国家安全、公共利益的数据

## 三、数据出境安全评估要点

### 申报流程图

```
开始
  ↓
判断是否需要申报?
  ↓是
准备申报材料
  ↓
提交至省级网信部门
  ↓
形式审查（7个工作日）
  ↓
受理并报国家网信部门
  ↓
安全评估（45个工作日）
  ↓
出具评估结果
  ↓
评估通过/不通过/整改后重新申报
```

### 风险自评估检查清单

```
一、数据出境必要性
□ 业务确需出境
□ 无国内替代方案
□ 出境范围最小化

二、数据类型和规模
□ 个人信息类型清单
□ 个人信息数量统计
□ 敏感个人信息识别
□ 重要数据识别

三、境外接收方评估
□ 所在国家/地区法律环境
□ 数据保护水平
□ 实际控制人背景
□ 合作历史和信誉

四、安全措施评估
□ 技术保护措施
□ 合同保护措施
□ 组织管理措施

五、数据主体权益保障
□ 告知同意机制
□ 权利行使渠道
□ 救济机制
```

## 四、合规体系建设检查表

### 组织架构

```
□ 指定数据保护负责人（DPO）
□ 建立数据安全管理部门
□ 明确各部门数据安全职责
□ 建立数据安全委员会（如适用）

培训与意识
□ 全员数据安全培训
□ 专项培训（研发、法务、业务）
□ 定期演练和考核

制度体系
□ 数据安全总则
□ 个人信息保护政策
□ 数据分类分级制度
□ 数据访问控制制度
□ 数据安全事件应急响应预案
□ 数据出境安全管理制度
□ 第三方数据共享管理制度

技术措施
□ 身份认证和访问控制
□ 数据加密（传输和存储）
□ 日志审计和监控
□ 数据脱敏和匿名化
□ 备份和恢复
□ 入侵检测和防护
```

## 五、处罚标准参考

| 违法行为 | 处罚依据 | 处罚措施 |
|---------|---------|---------|
| 违规处理个人信息 | PIPL第66条 | 责令改正、警告、没收违法所得、罚款（最高5000万或上年营业额5%） |
| 违规向境外提供个人信息 | PIPL第66条 | 同上 |
| 违规开展数据出境安全评估 | 评估办法第16条 | 责令改正、警告、罚款 |
| 危害数据安全 | 数据安全法第45条 | 责令改正、警告、罚款、停业整顿、吊销许可证 |

## 六、常用模板清单

| 模板名称 | 用途 | 关键要素 |
|---------|------|---------|
| 隐私政策 | 向用户告知 | 收集范围、目的、方式、存储期限、权利行使 |
| 用户协议 | 约定服务条款 | 服务内容、责任限制、争议解决 |
| 数据处理协议（DPA） | 与第三方约定 | 角色定义、安全要求、审计权、违约责任 |
| 标准合同（SCC） | 个人信息出境 | 双方义务、数据主体权利、救济机制 |
| 数据安全影响评估（DPIA） | 事前评估 | 处理目的、风险分析、保护措施 |
| 安全事件报告 | 事件上报 | 时间线、影响范围、处置措施 |
