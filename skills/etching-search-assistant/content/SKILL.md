# 蚀刻工艺开发工程师 AI搜索对比助手

## 核心功能

当用户（蚀刻工艺开发工程师）提出技术问题时，本技能自动执行以下操作：

### 1. 多源AI搜索对比
自动从以下AI搜索引擎获取答案：
- **DeepSeek** - 深度推理和技术分析
- **通义千问** - 阿里大语言模型视角
- **专家/秘塔搜索** - 专业知识库和文献检索

### 2. 文献整理与引用
- 提取各来源的关键信息
- 列出相关技术文献和参考资料
- 提供来源标注和链接

### 3. 答案整合
- 对比各来源的答案差异
- 提炼共性和独特见解
- 给出综合建议

## 搜索策略

### 蚀刻工艺相关关键词
- 干法蚀刻 / 湿法蚀刻
- 等离子蚀刻 / ICP蚀刻
- 刻蚀速率 / 选择比
- 光刻胶掩模 / 金属蚀刻
- 半导体工艺 / 硅基蚀刻

### 文献类型优先级
1. 学术论文和专利
2. 技术白皮书和应用指南
3. 工艺参数和实验数据
4. 行业标准和最佳实践
