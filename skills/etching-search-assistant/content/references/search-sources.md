## 蚀刻工艺核心术语

| 英文术语 | 中文术语 | 描述 |
|---------|---------|------|
| Etching | 蚀刻 | 材料去除工艺 |
| Dry Etching | 干法蚀刻 | 使用等离子体的蚀刻 |
| Wet Etching | 湿法蚀刻 | 使用化学溶液的蚀刻 |
| ICP Etching | 电感耦合等离子体蚀刻 | 高密度等离子体源 |
| Etch Rate | 刻蚀速率 | 单位时间内去除的材料量 |
| Selectivity | 选择比 | 对不同材料的选择性 |
| Aspect Ratio | 深宽比 | 特征深度与宽度之比 |
| RIE | 反应离子刻蚀 | 物理+化学蚀刻机制 |
