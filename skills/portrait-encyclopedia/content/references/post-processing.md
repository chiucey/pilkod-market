## 二、RAW处理基础

### Camera Raw / Lightroom 基础调整

#### 基础面板

```
白平衡 (Temperature/Tint)
    ├── 色温：控制冷暖
    └── 色调：控制绿-品方向

曝光 (Exposure)
    ├── 曝光：整体明暗
    ├── 对比度：高光-阴影范围
    ├── 高光：恢复亮部细节
    ├── 阴影：提亮暗部
    ├── 白色色阶：设置白点
    └── 黑色色阶：设置黑点

偏好 (Presence)
    ├── 清晰度：中间调对比
    ├── 自然饱和度：轻度色彩增强
    └── 饱和度：整体色彩强度
```

#### 人像关键调整

**曝光调整原则**
```
宁欠勿过 → 保留高光细节
    ↓
皮肤曝光正常 → 不死白/不过暗
    ↓
背景可过曝/欠曝 → 根据风格调整
```

**高光恢复**
- 皮肤高光不过曝
- 婚纱/白色服装可保留细节
- 窗户/天空恢复白云

## 三、皮肤精修技术

### 皮肤处理流程

```
观察皮肤 → 瑕疵修复 → 影调调整 → 质感保留
    │         │         │         │
    ↓         ↓         ↓         ↓
 整体评估   污点修复   双曲线     低频/高频
```

### 瑕疵修复工具

#### 污点修复画笔
- 大小：略大于瑕疵
- 对称：关闭
- 强度：80-100%
- 用于：痘痘、痣、杂物

#### 修复画笔
- 取样点：无瑕疵皮肤
- 用于：较大区域修复
- 模式：正常/正片叠底/叠加

---

### 中性灰双曲线技术 (Dodge & Burn)

#### 双曲线原理
```
新建两个曲线调整图层
    │
    ├── 提亮曲线（全白蒙版）
    │   └── 用黑色画笔涂抹提亮
    │
    └── 压暗曲线（全黑蒙版）
        └── 用白色画笔涂抹压暗
```

#### 操作步骤

**Step 1: 创建图层**
```
图层 → 新建 → 图层
图层 → 图层样式 → 混合选项
    混合颜色带：
        本图层：0 / 128
        下一图层：0 / 128
```

**Step 2: 填充蒙版**
```
编辑 → 填充
    内容：50%灰色
    混合模式：叠加
```

**Step 3: 观察图层**
```
视图 → 排列 → 新建窗口
    一个正常视图
    一个中性灰视图
```

**Step 4: 精细调整**
```
黑色画笔 → 提亮凹陷
白色画笔 → 压暗凸起
    │
    ├── 鼻梁阴影
    ├── 颧骨高光
    ├── 下巴阴影
    └── 眼窝、颈部阴影
```

---

### 高低频分离磨皮

#### 原理
```
高频层 → 保存纹理信息
    ↓
与原图对比 → 提取纹理
    ↓
低频层 → 保存形状/色彩信息
    ↓
分别在两层处理 → 不互相影响
```

#### 操作步骤

**Step 1: 复制图层**
```
Ctrl+J → 复制两次
    图层1 → 高频层
    图层1副本 → 低频层
```

**Step 2: 处理低频层**
```
选中"图层1副本"
滤镜 → 模糊 → 高斯模糊
    半径：5-10px（根据皮肤细节）
```

**Step 3: 处理高频层**
```
选中"图层1副本"(隐藏低频层)
图像 → 应用图像
    图层："图层1副本"
    混合：减去
    缩放：2
    补偿值：128
图层混合模式：线性光
```

**Step 4: 修图**
```
在高频层 → 修复画笔/仿制图章
    去除瑕疵
在低频层 → 调整形状色彩

盖印可见图层(Shift+Ctrl+Alt+E)
添加蒙版 → 画笔精细调整
```

---

### 通道计算磨皮

#### 原理
```
在通道中 → 皮肤与背景对比最大
    ↓
计算差异 → 创建观察通道
    ↓
基于通道选区 → 精细处理
```

#### 操作步骤

**Step 1: 观察通道**
```
打开通道面板
    ├── 红通道：皮肤偏亮
    ├── 绿通道：皮肤较均匀
    └── 蓝通道：皮肤偏暗

选择对比最明显的通道复制
```

**Step 2: 计算差异**
```
图像 → 计算
    源1：明度副本（当前通道）
    源2：明度副本（反向）
    混合：差值
    结果：新通道
```

**Step 3: 调整对比**
```
Ctrl+L → 色阶
    黑场右移
    白场左移
    灰度系数调整
    → 皮肤区域呈灰色
```

**Step 4: 创建选区**
```
载入选区（Ctrl+点击通道缩略图）
返回RGB模式
新建曲线调整图层
    → 精细处理皮肤
```

## 四、调色系统

### 肤色校准

#### 肤色标准
```
理想肤色范围：
    色相：25-35°（橙黄色）
    明度：60-75%
    饱和度：15-35%

检测方法：
    Adobe Color → 吸管工具
    吸取皮肤高光区域
```

#### 肤色调整

**HSL调整**
```
色相：
    ├── 红色：+5至+10（偏暖）
    ├── 橙色：控制肤色主体
    └── 黄色：微调

饱和度：
    ├── 红色：-10至-20（去红）
    ├── 橙色：-10至-30（皮肤）
    └── 黄色：适当降低

明亮度：
    ├── 橙色：+5至+15（提亮皮肤）
    └── 黄色：适当调整
```

**色调曲线**
```
红通道：
    中间调偏青 → 去红
    高光偏红 → 统一肤色

蓝通道：
    阴影偏蓝 → 冷调氛围
    高光偏黄 → 暖调肤色
```

---

### 经典调色风格

#### 高端商业灰

**特点**
- 整体偏灰（对比度低）
- 色彩饱和度低
- 中间调丰富
- 质感保留好

**参数参考**
```
曝光：+0.3EV
对比度：-15至-30
高光：-30至-50
阴影：+10至+20
白色：-10至-20
黑色：-10至+10
清晰度：-10至-20
自然饱和度：-20至-40
```

---

#### 青橙色调 (Teal & Orange)

**特点**
- 中间调青色
- 高光橙色
- 阴影青蓝色
- 互补色对比

**曲线调整**
```
RGB曲线：
    S型轻微曲线

红通道：
    高光偏橙
    阴影偏青

绿通道：
    轻微S型

蓝通道：
    高光偏黄
    阴影偏蓝
```

**HSL调整**
```
饱和度：
    橙色：+10至+20
    黄色：+5至+10
    青色/蓝色：-10至-20
```

---

#### 经典黑白

**转换方法**
```
方法1：去饱和度
    饱和度：-100
    优点：简单
    缺点：不做精细控制

方法2：黑白调整
    滤镜 → 转换为黑白
    优点：通道控制
    缺点：不可逆

方法3：通道混合器
    图像 → 调整 → 通道混合器
    输出通道：灰色
    优点：精确控制
    缺点：需要经验
```

**黑白影调控制**
```
红通道权重：+70至+80（皮肤亮）
绿通道权重：+20至+30（过渡）
蓝通道权重：0至+10（背景/衣服）
```

## 五、液化塑形

### 液化基础

**打开液化**
```
滤镜 → 液化
快捷键：Shift+Ctrl+X
```

**工具选择**
```
向前变形工具 (W)
    └── 推挤像素

重建工具 (R)
    └── 恢复修改

平滑工具 (E)
    └── 平滑边缘

抓手工具 (H)
    └── 移动视图

缩放工具 (Z)
    └── 缩放视图
```

### 人像液化重点

#### 脸型调整

**瘦脸**
```
工具：向前变形
压力：30-50
从脸颊边缘向内推
不要推到面部中心
```

**下巴塑形**
```
下巴过宽：从两侧向内
下巴过长：从下向上
下颌角：轻微内收
```

**颧骨**
```
颧骨过高：轻微压低
颧骨过低：轻微提亮（不建议液化）
```

#### 五官液化

**眼睛**
```
大小：轻微调整
眼距：轻微内推
眼形：轻微平滑
不对称：精细微调
```

**鼻子**
```
鼻梁：可微调
鼻翼：可微调
鼻尖：谨慎操作
注意：避免液化变形
```

**嘴唇**
```
厚度：轻微调整
形状：平滑曲线
对称：精细微调
```

#### 身体塑形

**肩膀**
```
溜肩：轻微提拉
宽肩：轻微内收
斜肩：谨慎调整
```

**腰腹**
```
收紧腰线
消除臃肿
保持自然比例
```

**臀部**
```
轻微提拉
保持自然弧度
```

### 液化原则

```
"液化是为了让照片更完美，而非改变人物本身"

规则1：宁少勿多
规则2：保持对称
规则3：尊重真实
规则4：不要过度
规则5：原图备份
```
