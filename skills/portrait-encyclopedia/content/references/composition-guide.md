# 人像摄影进阶构图完全指南

## 一、构图基础回顾

### 经典构图法则

#### 三分法 (Rule of Thirds)
```
原理：
├── 将画面横竖各分三等份
├── 形成4个交叉点
├── 交叉点为视觉兴趣点
└── 人眼自然关注这些位置

人像应用：
├── 眼睛位于上1/3线
├── 主体位于交叉点
├── 视线方向留空间
├── 身体位于另一侧
└── 引导线指向主体
```

#### 中心构图
```
原理：
├── 主体位于画面中央
├── 对称平衡
├── 直接有力
└── 形式感强

适用场景：
├── 证件照
├── 正式肖像
├── 庄严场合
├── 正面全身
├── 框架式构图
└── 创意表达
```

#### 对角线构图
```
原理：
├── 主体沿对角线分布
├── 动态感强
├── 引导视线
└── 打破静态

人像应用：
├── 身体侧躺
├── 手臂延伸
├── 视线方向
├── 头发/服装延伸
└── 道具引导
```

## 二、人像构图进阶

### 头部区域构图

#### 头部位置
```
特写构图：
├── 头顶留白：1/4-1/3
├── 下巴下方留白：适当
├── 面部朝向留空间
└── 耳朵可出画

半脸/侧脸：
├── 留白方向：视线方向
├── 背景考量：可与轮廓呼应
└── 情绪表达：内敛/神秘
```

#### 眼睛区域
```
眼睛位置：
├── 上1/3线交叉点
├── 黄金分割点
├── 视觉中心
└── 情绪焦点

眼神方向：
├── 视线方向留2/3空间
├── 不看镜头可留任意方向
├── 视线与身体形成张力
└── 反向留白形成延伸
```

### 身体区域构图

#### 站姿构图
```
全身人像：
├── 头部位于黄金分割
├── 身体偏向一侧
├── 重力脚位置
├── 呼吸空间
└── 脚部不出画

三分法站姿：
```
    A        B
    │  ┌───┐│
    │  │   ││
    └──│   │┘
       └───┘
```
头部：A或B点
身体：延伸线
脚部：画框底部
```

#### 坐姿构图
```
坐姿要点：
├── 坐骨支撑点
├── 背部曲线
├── 腿部延伸
├── 脚部收紧
└── 整体高度

俯拍vs平拍：
├── 俯拍：强调顶部（头发/肩膀）
├── 平拍：自然视角
├── 仰拍：强调腿/身高
└── 选择取决于主题
```

### 肢体引导构图

#### 手臂引导
```
引导线作用：
├── 手臂线条延伸
├── 指向面部/视线
├── 引导观众目光
├── 塑造身体曲线
└── 填补画面空白

常见引导：
├── 手触脸颊
├── 手搭肩膀
├── 手拿道具
├── 手插口袋
└── 手持花束
```

#### 腿部引导
```
站姿引导：
├── 重心脚为主
├── 另一腿放松
├── 脚尖方向引导
├── 形成三角形
└── 避免死板站立

坐姿引导：
├── 腿部线条延伸
├── 脚尖绷直显修长
├── 交叉腿优雅
└── 脚踝收紧
```

特点：
├── 稳定庄重
├── 正式感强
├── 平衡感好
└── 适合正装肖像

构图方式：
├── 双人正面站立
├── 新人正面全身
├── 家庭合照
└── 团体肖像
```

```
特点：
├── 动态平衡
├── 趣味性强
├── 不死板
└── 现代感

实现方式：
├── 大小平衡
├── 色彩平衡

├── 形状平衡
└── 虚实平衡
```

## 八、后期二次构图

### 裁切原则

#### 裁切时机
```
前期不足后期补：
├── 构图偏斜
├── 留白过多
├── 主体太小
├── 背景杂乱
└── 去除杂物

适度裁切：
├── 不损失主体
├── 保持比例
├── 头部完整
├── 眼睛清晰
└── 呼吸空间
```

#### 人像裁切点
```
可裁切位置：
├── 腋下
├── 腰/胯部
├── 大腿中部
├── 小腿
├── 手腕
└── 颈部

不可裁切位置：
├── 关节处（膝盖/肘部）
├── 手指
├── 脚踝
├── 颈部（除非特殊）
├── 头部（除非特殊）
└── 眼睛
```

## 十、构图能力提升

### 练习方法

#### 日常练习
```
每天练习：
├── 观察100个画面
├── 用眼睛构图
├── 记录光线变化
├── 分析他人作品
└── 模仿拍摄

拍摄练习：
├── 同一场景多构图
├── 同一主体多角度
├── 尝试打破规则
├── 记录失败原因
└── 定期回顾复盘
```

#### 模仿练习
```
模仿步骤：
1. 选择大师作品
2. 分析构图要素
3. 寻找类似场景
4. 尝试复现
5. 对比分析差异
6. 理解原理后创新

推荐模仿对象：
├── 布列松：决定性瞬间
├── 阿维顿：极简白色背景
├── 纽顿：戏剧性光影
├── 莱博维茨：叙事场景
└── 森山大道：街头抓拍
```

```
构图评估：
