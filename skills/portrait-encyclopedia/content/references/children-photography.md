# 儿童摄影完全指南

## 一、儿童摄影概述

### 年龄阶段分类

| 阶段 | 年龄 | 特点 | 拍摄方式 | 建议时长 |
|------|------|------|----------|----------|
| 新生儿 | 0-14天 | 睡眠多、柔软 | 裹布/睡姿 | 3-4小时 |

| 7-12岁 | 7-12岁 | 少年感、气质 | 主题/风格 | 2-3小时 |

## 二、新生儿摄影

### 新生儿特点
```
生理特点：
├── 睡眠时间长（20小时/天）
├── 蜷缩姿态（子宫记忆）
├── 皮肤敏感
├── 骨骼柔软
└── 头颈无力

拍摄时机：
├── 出生后5-14天最佳
├── 吃饱后睡眠期
├── 室温26-28°C
└── 需专业看护
```

### 安全守则

#### 绝对禁止
```
✗ 任何危险姿势（趴睡枕头、悬挂等）
✗ 强制改变婴儿姿势
✗ 任何可能伤害婴儿的道具
✗ 让婴儿离开视线
✗ 关闭监护设备
```

#### 必备安全措施
```
✅ 助手全程看护
✅ 母婴同室/近距监护
✅ 道具稳固测试
✅ 室温实时监控
✅ 备用安全姿势
✅ 紧急情况预案
```

### 新生儿姿势类型

#### 1. 包裹式 (Wrapped)
```
包裹技巧：
├── 舒适松紧度
├── 露出脸/手
├── 臀部包裹圆
├── 头部包裹安全
└── 层层包裹感

服装搭配：
├── 素色纯棉
├── 柔软毯子
├── 蕾丝/花边
└── 简约配饰
```

#### 2. 侧卧式 (Side Lying)
```
姿势要点：
├── 侧躺放松
├── 双手合拢
├── 双腿蜷曲
├── 侧面轮廓
└── 眼神温柔
```

#### 3. 趴卧式 (Tummy)
```
姿势要点：
├── 双手支撑头部
├── 臀部高于肩部
├── 双腿自然下垂
├── 表情放松
└── 注意呼吸
```

#### 4. 亲子式 (Family)
```
类型：
├── 妈妈怀抱
├── 爸爸手掌
├── 兄弟合影
├── 家庭总动员
└── 父母轮廓
```

### 新生儿道具清单

```
必备道具：
├── 裹布/毯子（不同材质/颜色）
├── 背景布（白色/灰色/莫兰迪色）
├── 豆袋/软垫
├── 篮子/木箱（安全测试）
├── 帽子/发带
└── 配饰（树枝/羽毛/花环）

可选道具：
├── 复古箱子
├── 梯子/椅子
├── 轮胎/木箱
├── 仿真皮草
└── 艺术画框
```

### 光线设置

#### 窗户自然光
```
最佳时段：
├── 上午9-11点
├── 下午2-4点
└── 避免正午顶光

窗光技巧：
├── 北窗/东窗最佳
├── 白色窗帘柔化
├── 柔光板补阴影
└── 侧光制造立体
```

#### 人工光源
```
方案A：自然光+反光板
├── 主光：窗光
├── 辅光：反光板
└── 适合：初学者

方案B：持续光灯
├── 主灯：LED柔光箱
├── 辅灯：小型补光
└── 适合：稳定输出

方案C：闪光灯
├── 高速凝固瞬间
├── 大功率输出
└── 适合：专业团队
```

## 八、后期处理

### 儿童皮肤处理

#### 原则
```
✓ 保留真实质感
✓ 去除明显瑕疵
✓ 均匀肤色
✓ 保留细节

✗ 不要过度磨皮
✗ 不要改变真实比例
✗ 不要液化变形
✗ 不要过度美白
```

#### 处理流程
```
1. 基础调整
   ├── 曝光正常
   ├── 白平衡准确
   └── 对比度适中

2. 皮肤处理
   ├── 污点修复（明显瑕疵）
   ├── 轻微磨皮（可选）
   └── 质感保留

3. 局部调整
   ├── 提亮面部
   ├── 眼神光增强
   └── 头发细节
```
