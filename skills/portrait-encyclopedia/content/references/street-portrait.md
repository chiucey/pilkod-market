# 街头人像摄影完全指南

## 一、街头人像概述

### 街头人像特点
```
定义：
├── 在公共场所拍摄的人像
├── 与环境融合
├── 真实自然
├── 时机性强
└── 具有纪实性

与影棚区别：
├── 光线：自然光为主
├── 背景：真实环境
├── 姿态：自然流露
├── 互动：真实情感
└── 创作：瞬间把握
```

### 街头人像类型

| 类型 | 特点 | 方式 | 难度 | 设备 |
|------|------|------|------|------|
| 抓拍肖像 | 不告知/瞬间抓取 | 远距离长焦 | 高 | 长焦 |
| 街拍互动 | 短暂交流后拍摄 | 中距离 | 中 | 标准变焦 |
| 正式请求 | 明确请求同意 | 近距离 | 低 | 标准/广角 |
| 环境肖像 | 请求+场景选择 | 中距离 | 中 | 标准 |
| 偷拍/隐蔽 | 完全隐蔽拍摄 | 远距离 | 高 | 隐蔽设备 |

```
避免情况：
├── 宗教场所不当拍摄

├── 无家可归者利用
├── 儿童单独拍摄
├── 医疗/救助场景
└── 犯罪/违法行为
```

#### 公共场所拍摄权
```
法律常识：
├── 中国：公共场所可拍
├── 美国：公共场所可拍
├── 欧洲：各国不同
├── 日本：可拍但有限制
└── 通用：商业使用需授权

注意事项：
├── 私人场所需授权
├── 个人隐私需保护
├── 儿童拍摄需监护人同意
├── 商业使用需肖像权授权
└── 敏感区域禁止拍摄

```
授权情况：
