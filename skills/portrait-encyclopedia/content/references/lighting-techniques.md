# 人像摄影布光技术完全指南（80+种经典布光）

## 一、布光基础理论

### 布光核心概念

```
主光 (Key Light)
    │
    ├── 位置：主光源放置方向
    ├── 强度：亮度与曝光
    └── 质地：硬光/软光

辅光 (Fill Light)
    │
    ├── 位置：阴影侧补光
    ├── 强度：与主光的光比
    └── 作用：降低反差

轮廓光 (Rim/Hair Light)
    │
    ├── 位置：人物后方
    ├── 作用：分离主体与背景
    └── 效果：边缘发光感

背景光 (Background Light)
    │
    ├── 位置：打向背景
    ├── 作用：背景明暗控制
    └── 效果：氛围塑造
```

### 光比 (Lighting Ratio)

| 光比 | 主光:辅光 | 明暗差距 | 影调风格 |
|------|-----------|----------|----------|
| 1:1 | 1:1 | 无差异 | 高调 |
| 2:1 | 2:1 | 1EV | 柔和自然 |
| 3:1 | 3:1 | 1.5EV | 标准人像 |
| 4:1 | 4:1 | 2EV | 经典肖像 |
| 8:1 | 8:1 | 3EV | 戏剧性 |
| 16:1 | 16:1 | 4EV | 极端低调 |

### 光位图解

```
                    12点钟
                       │
                       │
              10点 ────┼──── 2点
               │       │       │
               │       │       │
        9点 ───┤       │       ├── 3点
               │       │       │
               │       │       │
              8点 ────┼──── 4点
                       │
                       │
                      6点钟
                       │
                    (相机位置)
```

## 二、经典基础布光（6种）

### 1. 伦勃朗布光 (Rembrandt Lighting)

**特点**
- 以荷兰画家伦勃朗命名
- 45度侧上方主光
- 鼻翼与颧骨形成三角形阴影
- 经典戏剧性肖像

**光位图**
```
        主光(45°)
           ↘
            ↘
    背景 ───●─── 人物
              ↘
               ↘
              相机
```

**参数设置**
| 参数 | 数值 |
|------|------|
| 主光角度 | 45°水平 / 45°垂直 |
| 光比 | 4:1 或 3:1 |
| 光质 | 软硬均可 |
| 光圈 | F2.8-F4 |

**适用场景**
- 男性肖像
- 戏剧性人像
- 艺术家肖像
- 强调性格

**常见问题**
Q：三角形阴影太小怎么办？
A：将主光向上调整或靠近

Q：阴影太硬怎么办？
A：使用更大的柔光附件

---

### 2. 环形布光 (Loop Lighting)

**特点**
- 30-45度侧光
- 鼻影向下，不连接颧骨阴影
- 阴影在鼻子侧面形成"环形"
- 通用性最强的布光

**光位图**
```
          主光(30°)
             ↘
              ↘
     背景 ───●─── 人物
                ↘
                 ↘
                相机
```

**参数设置**
| 参数 | 数值 |
|------|------|
| 主光角度 | 30-45°水平 / 30-45°垂直 |
| 光比 | 2:1 或 3:1 |
| 光质 | 中等柔光 |
| 光圈 | F2.8-F4 |

**适用场景**
- 女性肖像
- 商业肖像
- 证件照
- 通用人像

**变化形式**
- 宽位环形光：向镜头方向转30°
- 窄位环形光：远离镜头45°

---

### 3. 蝴蝶光/派拉蒙布光 (Butterfly/Paramount Lighting)

**特点**
- 正面偏上方
- 鼻子下方形成蝴蝶形阴影
- 也称"美人光"
- 时尚杂志常用

**光位图**
```
           蝴蝶光
             ↓
             ↓
    人物 ───●─── 背景
             │
             │
            相机
```

**参数设置**
| 参数 | 数值 |
|------|------|
| 主光角度 | 0°水平 / 45-60°垂直 |
| 光比 | 2:1 或 4:1 |
| 光质 | 柔和散射 |
| 光圈 | F4-F5.6 |

**适用场景**
- 女性肖像
- 时尚摄影
- 杂志封面
- 强调颧骨

**常见变化**
- 高位蝴蝶光：更戏剧性阴影
- 低位蝴蝶光：柔美效果

---

### 4. 分割布光 (Split Lighting)

**特点**
- 90度侧面主光
- 脸部一半明一半暗
- 极度戏剧性
- 神秘感强烈

**光位图**
```
      │←暗│←│←明→│
      │   │ 人 │   │
背景──┤   │ 像 │   ├──背景
      │   │   │   │
      │   │   │   │
           相机
```

**参数设置**
| 参数 | 数值 |
|------|------|
| 主光角度 | 90°水平 / 0°垂直 |
| 光比 | 无限:1 (只用主光) |
| 光质 | 硬光效果更佳 |
| 光圈 | F4-F5.6 |

**适用场景**
- 男性肖像
- 戏剧性角色
- 音乐人肖像
- 强调个性

**技巧**
- 让被摄者微微转身调整分割线
- 可在暗侧加微弱辅光

---

### 5. 短光 (Short Lighting)

**特点**
- 阴影侧对着相机
- 明亮面远离相机
- 显瘦效果
- 立体感强

**光位图**
```
    明→│←暗
      人│
      像│相机
```

**适用场景**
- 圆润脸型
- 女性肖像
- 追求立体感
- 时尚摄影

**对比：宽光 (Broad Lighting)**
- 明亮侧对着相机
- 显胖效果
- 适合瘦削脸型

---

### 6. 顶光 (Top Lighting)

**特点**
- 光源在头顶正上方
- 眼窝阴影深
- 颧骨阴影明显
- 自然日光效果

**适用场景**
- 正午户外
- 创造戏剧性
- 配合反光板使用
- 男性肖像

**注意事项**
- 需用反光板补眼窝
- 可用于创造神秘感

## 三、进阶布光技术（20+种）

### 边缘光系统

#### 发际光/轮廓光 (Hair Light/Rim Light)

**作用**
- 将人物与背景分离
- 勾勒头发/肩部轮廓
- 增加立体感
- 创造"发光"效果

**布光方法**
```
         发际灯
            ↓
    背景 ═══════════
          │    │
          │ 人 │
          │ 像 │
          │    │
           相机
```

**参数**
| 参数 | 数值 |
|------|------|
| 角度 | 45°背后上方 |
| 强度 | 比主光强 |
| 附件 | 蜂巢/雷达罩 |
| 色温 | 可偏暖(+200K) |

---

#### 分离光 (Separation Light)

**特点**
- 打亮肩部轮廓
- 与背景分离
- 侧后方低位
- 强调形态

---

### 眼神光系统

#### 眼神光 (Catch Light)

**重要性**
- 眼睛的生命感
- 传达情绪
- 判断布光的标志

**标准眼神光**
| 形状 | 特点 | 适用 |
|------|------|------|
| 圆形 | 雷达罩效果 | 时尚摄影 |
| 方形 | 柔光箱效果 | 商业肖像 |
| 条形 | 窗户/门效果 | 纪实风格 |
| 多个 | 多个光源效果 | 复杂布光 |

**位置规律**
- 10点钟或2点钟方向
- 眼球上1/3处
- 不要在瞳孔中央

---

### 双灯经典布光

#### 书页式布光 (Book Lighting)

**特点**
- 双灯对称
- 45度侧光
- 两侧均匀
- 立体感强

**光位图**
```
左灯(45°)          右灯(45°)
    ↘              ↙
      ╲          ╱
        ╲      ╱
          ╲  ╱
           ●
         人物
```

**适用场景**
- 证件照
- 商业肖像
- 正式场合
- 企业形象

---

#### 45度经典双灯

**布光设置**
```
主光：45°侧光 (伦勃朗)
辅光：对面45°反光板
轮廓光：后上方
```

**特点**
- 经典五灯简化
- 实用性最强
- 可加背景光
- 适合大多数场景

---

### 高调布光 (High Key Lighting)

**特点**
- 明亮背景
- 低反差
- 白色/浅灰背景
- 青春时尚感

**布光方法**
```
主灯：正面/Fill(1:1)
背景灯：过曝1-2档
辅光：几乎不需要
```

**参数**
| 参数 | 数值 |
|------|------|
| 背景 | 过曝+1到+2EV |
| 主光 | 正面柔光 |
| 光比 | 2:1 或 1:1 |
| 整体 | 明亮通透 |

**适用场景**
- 女性肖像
- 时尚摄影
- 婚纱摄影
- 青春主题

---

### 低调布光 (Low Key Lighting)

**特点**
- 深色背景
- 高反差
- 戏剧性阴影
- 神秘感强烈

**布光方法**
```
主光：侧面/侧逆
辅光：微弱或不用
背景：黑色/欠曝
轮廓光：强调分离
```

**参数**
| 参数 | 数值 |
|------|------|
| 背景 | 欠曝-1到-2EV |
| 主光 | 硬光/聚光 |
| 光比 | 8:1 或更高 |
| 整体 | 深沉神秘 |

**适用场景**
- 男性肖像
- 戏剧性主题
- 艺术摄影
- 电影感

## 四、专业布光方案（30+种）

### 时尚杂志布光

**方案A：简单有效**
```
灯1：雷达罩 (主光) 45°侧上方
灯2：裸灯+蜂巢 (轮廓光) 后方
背景：渐变灰/白
```

**方案B：杂志封面级**
```
灯1：大柔光箱 (主光) 正面略侧
灯2：雷达罩 (辅光) 正面另一侧
灯3：条形柔光箱 (发际光) 头顶后方
灯4：背景分离灯 (分离光)
背景：品牌色/创意背景
```

#### 专业团队合影

**布光方案**
```
排数：不超过3排
灯位：每排上方柔光箱
排数×灯数：
- 1排5人：1盏主灯+1盏辅灯
- 2排10人：2盏主灯+2盏辅灯
- 3排15人：3盏主灯+反光系统
```

**注意事项**
- 每排高度递增
- 中间人略前
- 最前排最近
- 表情同步

## 五、布光故障排除

### 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 眼神无光 | 眼神光缺失 | 添加眼神光 |
| 皮肤油光 | 主光太硬/太近 | 柔化/拉远 |
| 眼窝阴影深 | 顶光太强 | 降低/加辅光 |
| 背景太暗 | 背景光不足 | 添加背景灯 |
| 光比太大 | 辅光太弱 | 增加辅光 |
| 轮廓光不足 | 分离灯太弱/太远 | 靠近/加强 |

---

### 光比控制

**调整方法**
1. 移动主光距离
2. 改变柔光附件大小
3. 调整辅光功率
4. 使用反光板
5. 增减光源数量

**快速计算**
```
光圈每差1档 = 2倍光量
每移动1倍距离 = 4倍光量衰减
```
