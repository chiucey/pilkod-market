# 多维度股票分析技能

## 核心定位

为投资者提供专业、客观、全维度的股票分析服务，涵盖基本面、技术面、估值、风险四大分析维度，输出结构化分析报告。

**仅作为投资参考，不构成任何交易建议。**

## 分析框架

### 1. 预处理流程

1. **初始化分析体系**
   - 加载A股/港股/美股财务指标库
   - 配置技术指标计算规则（20+指标）
   - 设置估值模型参数
   - 初始化风险评估维度

2. **数据加载**
   - 获取股票行情数据（OHLCV）
   - 获取财务报表数据（资产负债表、利润表、现金流量表）
   - 获取行业分类和宏观数据
   - **仅使用合规公开数据源**

3. **指令解析**
   - 识别分析标的（股票代码或名称）
   - 确定分析维度（基本面/技术面/估值/风险）
   - 识别对比标的（如有）
   - 确定时间周期

4. **标的校验**
   - 验证股票代码合法性
   - 确认已上市状态
   - 排除未合规披露数据的标的

### 2. 基本面分析模块

**财务指标提取：**
- 盈利能力：毛利率、净利率、ROE、ROA、ROIC
- 成长能力：营收增速、净利润增速、EPS增速
- 偿债能力：资产负债率、流动比率、速动比率
- 运营效率：存货周转率、应收账款周转率、总资产周转率
- 现金流质量：经营现金流/净利润比率、自由现金流

**同比/环比分析：**
- 单季度vs去年同期
- 单季度vs上季度
- 年度趋势分析（至少3年）

**盈利质量评估：**
- 非经常性损益占比
- 应收账款变化趋势
- 存货变化与营收匹配度

### 3. 技术面分析模块

**趋势指标：**
- 移动平均线（MA5/MA10/MA20/MA60/MA120/MA250）
- 指数移动平均线（EMA）
- MACD（12,26,9）
- DMA（差分移动平均）
- DMI趋势指标

**动量指标：**
- RSI（相对强弱指标，6/12/24周期）
- KDJ随机指标
- WR威廉指标
- CCI顺势指标
- ROC变动率指标

**成交量指标：**
- VOL成交量
- OBV能量潮
- VR容量比率
- ADL集散量

**波动性指标：**
- BOLL布林带
- ENE轨道线
- ATR平均真实波幅

**支撑压力分析：**
- 黄金分割线
- 趋势线分析
- 均线支撑/压力位
- 前期高低点

**K线形态识别：**
- 趋势持续形态（旗形、三角形）
- 趋势反转形态（头肩顶/底、双顶/底）
- 包含形态、吞没形态、十字星

**技术信号输出：**
- 买入信号（强烈/中性）
- 持有信号
- 卖出信号（中性/强烈）

### 4. 估值分析模块

**相对估值法：**
- PE（市盈率）：当前PE vs 历史PE vs 行业PE
- PB（市净率）：当前PB vs 历史PB vs 行业PB
- PEG（市盈率相对盈利增长比率）：<1为低估
- PS（市销率）：适合成长股
- EV/EBITDA：企业价值倍数

**绝对估值法：**
- DCF（现金流折现模型）
  - 预测未来5-10年自由现金流
  - 确定永续增长率（通常2-4%）
  - 确定折现率（WACC）
  - 计算内在价值
- 股息折现模型（DDM）：适合高股息股票

**估值区间判定：**
- 显著低估
- 轻度低估
- 合理估值
- 轻度高估
- 显著高估

### 5. 风险评估模块

**系统性风险：**
- Beta系数：相对于市场指数的波动性
- 历史波动率（年化）
- VaR（在险价值）

**非系统性风险：**
- 行业集中度
- 客户集中度
- 业务单一性

**回撤分析：**
- 最大回撤（历史）
- 平均回撤幅度
- 回撤恢复时间

**流动性风险：**
- 日均成交量
- 成交量变化趋势
- 涨跌停频率

**风险等级：**
- 低风险（1-2级）
- 中风险（3-4级）
- 高风险（5级）

**风险提示：**
- 行业政策风险
- 竞争加剧风险
- 经营管理风险
- 财务造假风险（预警信号）

### 6. 对比分析模块（如指定对比标的）

**多维度对比：**
- 财务指标对比表
- 估值指标对比表
- 技术面对比（强弱指数）
- 风险指标对比

**优劣势分析：**
- 相对优势识别
- 相对劣势识别
- 综合评分对比
