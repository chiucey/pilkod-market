# 估值模型参考手册

## 相对估值法

### PE (Price-to-Earnings Ratio)

```
静态PE = 当前股价 / 上年度EPS
滚动PE = 当前股价 / 最近4个季度EPS总和
动态PE = 当前股价 / 预测本年度EPS
```

**行业PE参考范围**：
- 银行：4-8倍
- 保险：8-15倍
- 房地产：5-12倍
- 消费：20-40倍
- 科技：30-60倍
- 医药：25-50倍

### PB (Price-to-Book Ratio)

```
PB = 当前股价 / 每股净资产
```

**适用场景**：
- 金融业（银行、保险）
- 周期性行业
- 资产重型企业

### PEG (Price/Earnings to Growth)

```
PEG = PE / 年化净利润增速 × 100
```

**判断标准**：
- PEG < 1 → 相对低估
- PEG = 1 → 合理估值
- PEG > 1 → 相对高估

### PS (Price-to-Sales Ratio)

```
PS = 总市值 / 营业收入
```

**适用场景**：
- 成长型企业
- 互联网公司
- 营收稳定但利润波动大的企业

### EV/EBITDA

```
EV = 市值 + 净负债
EBITDA = 净利润 + 利息 + 税 + 折旧 + 摊销
EV/EBITDA = 企业价值 / EBITDA
```

## 绝对估值法

### DCF (Discounted Cash Flow) 模型

**基本公式**：
```
企业价值 = Σ [FCFt / (1 + WACC)^t] + TV / (1 + WACC)^n
```

其中：
- FCFt = 第t年的自由现金流
- WACC = 加权平均资本成本
- TV = 终值
- n = 预测期

**参数设置**：

#### 自由现金流预测

```
FCF = 净利润 + 折旧摊销 - 资本支出 - 营运资本增加
```

**增长率假设**：
- 成长期（前5年）：10%-25%
- 成熟期（后5年）：5%-10%
- 永续期：2%-4%

#### WACC 计算

```
WACC = Ke × E/(D+E) + Kd × (1-T) × D/(D+E)

其中：
Ke = 无风险利率 + β × 市场风险溢价
Kd = 债务成本
T = 所得税率
E/(D+E) = 权益占比
D/(D+E) = 债务占比
```

**参数参考**：
- 无风险利率：10年期国债收益率（约2.5%-3.5%）
- 市场风险溢价：A股约6%-8%
- β系数：个股相对市场波动
- 债务成本：银行贷款利率或债券收益率

#### 永续增长率

```
永续增长率 = 行业长期增速 ≈ GDP增速 × 行业系数
```

**通常取值**：2%-4%

**敏感性分析**：
| 永续增长率 | 估值影响 |
|-----------|---------|
| 2% | 保守估值 |
| 3% | 合理估值 |
| 4% | 乐观估值 |

### DDM (Dividend Discount Model)

**适用场景**：高股息、稳定分红的公司

**Gordon Growth Model**：
```
内在价值 = D1 / (r - g)
D1 = D0 × (1 + g)
```

其中：
- D0 = 当前股息
- D1 = 明年股息
- r = 必要收益率
- g = 股息增长率

## 估值区间判定

### 综合判断矩阵

| 指标 | 显著低估 | 轻度低估 | 合理估值 | 轻度高估 | 显著高估 |
|------|---------|---------|---------|---------|---------|
| PE相对行业 | <0.6倍 | 0.6-0.85倍 | 0.85-1.15倍 | 1.15-1.4倍 | >1.4倍 |
| PB相对行业 | <0.6倍 | 0.6-0.85倍 | 0.85-1.15倍 | 1.15-1.4倍 | >1.4倍 |
| DCF折溢价 | <-30% | -30%~-10% | -10%~+10% | +10%~+30% | >+30% |

### 估值质量评估

1. **数据可靠性**：财报数据是否经过审计
2. **模型适用性**：行业特性是否匹配模型假设
3. **参数合理性**：增长率和折现率是否符合行业规律
4. **结果交叉验证**：多模型结果是否一致
