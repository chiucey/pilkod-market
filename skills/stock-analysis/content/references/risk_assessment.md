# 风险评估参考手册

## 系统性风险

### Beta系数

```
β = Cov(Ri, Rm) / Var(Rm)

其中：
Ri = 个股收益率
Rm = 市场收益率
```

**解读**：
- β > 1：波动大于市场（进攻型）
- β = 1：与市场同步
- β < 1：波动小于市场（防御型）
- β < 0：与市场负相关（极少数）

### 历史波动率

```
年化波动率 = 日收益率标准差 × √252
```

**区间划分**：
- 低波动：< 20%
- 中等波动：20%-40%
- 高波动：> 40%

### VaR (Value at Risk)

```
VaR = 均值 - Zα × 标准差
```

**置信水平**：
- 95%置信度
- 99%置信度

## 非系统性风险

### 行业集中度

```
行业营收占比 = 某行业营收 / 总营收
```

### 客户集中度

```
前五大客户营收占比 = 前五大客户营收 / 总营收
```

**风险警示**：>30%需关注

### 业务单一性

单一业务或单一产品收入占比>50%为高风险

## 回撤分析

### 最大回撤

```
最大回撤 = (谷值 - 峰值) / 峰值 × 100%
```

**历史最大回撤参考**：
- 优质成长股：-30% ~ -50%
- 周期股：-50% ~ -70%
- 蓝筹股：-20% ~ -40%

### 回撤恢复周期

从最大回撤恢复到前期高点的平均时间

## 流动性风险

### 日均成交量

```python
日均成交量 = N日内成交量总和 / N
```

### 成交量变化趋势

- 放量上涨：健康上涨
- 缩量上涨：警惕
- 放量下跌：可能见底
- 缩量下跌：趋势延续

## 风险等级划分

### 综合风险评分

```
综合得分 = α × 系统性风险 + β × 非系统性风险 + γ × 流动性风险
```

### 等级定义

| 等级 | 分数区间 | 风险描述 |
|------|---------|---------|
| R1 | 0-20 | 低风险 |
| R2 | 21-40 | 中低风险 |
| R3 | 41-60 | 中等风险 |
| R4 | 61-80 | 中高风险 |
| R5 | 81-100 | 高风险 |

## 风险预警信号

### 财务风险

1. 应收账款异常增长
2. 存货异常堆积
3. 经营现金流持续为负
4. 关联交易异常
5. 毛利率异常下降

### 经营风险

1. 大客户流失
2. 核心技术人员流失
3. 重大诉讼仲裁
4. 监管处罚
5. 主营业务变更

### 市场风险

1. 行业政策重大变化
2. 竞争格局恶化
3. 需求端重大变化
4. 原材料价格剧烈波动
