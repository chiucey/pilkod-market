# 技术指标参考手册

## 趋势指标

### 移动平均线 (MA)

| 周期 | 用途 |
|------|------|
| MA5 | 短期趋势，快速响应 |
| MA10 | 短期趋势 |
| MA20 | 中期趋势 |
| MA60 | 中长期趋势 |
| MA120 | 长期趋势 |
| MA250 | 年线，长期牛熊分界 |

**均线多头排列**：短期 > 中期 > 长期 → 上涨趋势
**均线空头排列**：短期 < 中期 < 长期 → 下跌趋势

### MACD (Moving Average Convergence Divergence)

```
DIF = EMA12 - EMA26
DEA = DIF的EMA9
MACD = (DIF - DEA) × 2
```

**信号解读**：
- DIF > 0 且 DIF > DEA → 金叉（买入信号）
- DIF < 0 且 DIF < DEA → 死叉（卖出信号）
- DIF从上向下穿越DEA → 死叉
- DIF从下向上穿越DEA → 金叉

**背离**：
- 顶背离：价格创新高，MACD未创新高 → 下跌预警
- 底背离：价格创新低，MACD未创新低 → 上涨预警

## 动量指标

### RSI (Relative Strength Index)

```
RS = N日内上涨幅度平均值 / N日内下跌幅度平均值
RSI = 100 - (100 / (1 + RS))
```

**周期设置**：
- 短期：6日RSI
- 中期：12日RSI
- 长期：24日RSI

**信号区间**：
- RSI > 80：超买区域（警惕回调）
- RSI < 20：超卖区域（关注反弹）
- RSI = 50：多空平衡点

### KDJ 随机指标

```
RSV = (C - L) / (H - L) × 100
K = 2/3 × 前K值 + 1/3 × RSV
D = 2/3 × 前D值 + 1/3 × K
J = 3K - 2D
```

**信号解读**：
- K、D < 20 → 超卖区域
- K、D > 80 → 超买区域
- K从下向上穿越D → 金叉（买入）
- K从上向下穿越D → 死叉（卖出）

### CCI 顺势指标

```
CCI = (TP - MA) / (MD × 0.015)
TP = (H + L + C) / 3
```

**信号解读**：
- CCI > 100 → 强势区域
- CCI < -100 → 弱势区域
- CCI从上向下穿越+100 → 卖出信号
- CCI从下向上穿越-100 → 买入信号

## 成交量指标

### OBV (On Balance Volume)

```
上涨日：OBV = 前日OBV + 今日成交量
下跌日：OBV = 前日OBV - 今日成交量
```

**应用**：
- OBV创新高 → 资金流入确认
- OBV创新低 → 资金流出确认
- 价格创新高但OBV未跟上 → 顶背离

### VR (Volume Ratio)

```
VR = (上涨日成交量 + ½平盘日成交量) / (下跌日成交量 + ½平盘日成交量) × 100
```

**信号区间**：
- VR < 40 → 警惕抛售
- VR = 40-150 → 正常区域
- VR > 300 → 警惕过热

## 波动性指标

### BOLL (Bollinger Bands)

```
中轨 = MA20
上轨 = 中轨 + 2 × 标准差
下轨 = 中轨 - 2 × 标准差
```

**应用**：
- 股价触及上轨 → 强势但警惕回调
- 股价触及下轨 → 弱势但关注反弹
- 布林带收口 → 突破在即
- 布林带开口 → 趋势加速

## 支撑压力分析

### 黄金分割

| 比例 | 用途 |
|------|------|
| 0.382 | 弱支撑/压力 |
| 0.5 | 强支撑/压力 |
| 0.618 | 强支撑/压力 |
| 0.786 | 极强支撑/压力 |

### 前期高低点

- **前期高点**：潜在压力位
- **前期低点**：潜在支撑位

## K线形态

### 趋势持续形态

1. **旗形**：短暂休整后延续原趋势
2. **三角旗形**：收敛形态后顺势突破
3. **矩形整理**：横盘震荡后延续

### 趋势反转形态

1. **头肩顶/底**：经典反转形态
2. **双顶/双底**（M顶/W底）
3. **三重顶/底**
4. **圆弧顶/底**

### 单根K线形态

1. **锤子线**：底部反转信号
2. **上吊线**：顶部反转信号
3. **吞没形态**：强反转信号
4. **十字星**：警惕信号
