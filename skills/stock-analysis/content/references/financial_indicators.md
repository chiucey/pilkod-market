# 财务指标参考手册

## 盈利能力指标

### 毛利率 (Gross Margin)
```
毛利率 = (营业收入 - 营业成本) / 营业收入 × 100%
```
- **优秀**：>40%
- **良好**：20%-40%
- **一般**：<20%

### 净利率 (Net Margin)
```
净利率 = 净利润 / 营业收入 × 100%
```
- **优秀**：>20%
- **良好**：10%-20%
- **一般**：<10%

### ROE (Return on Equity)
```
ROE = 净利润 / 股东权益 × 100%
```
- **优秀**：>15%
- **良好**：10%-15%
- **一般**：<10%

### ROA (Return on Assets)
```
ROA = 净利润 / 总资产 × 100%
```
- **优秀**：>8%
- **良好**：5%-8%
- **一般**：<5%

### ROIC (Return on Invested Capital)
```
ROIC = NOPAT / 投入资本 × 100%
```
- **优秀**：>15%
- **良好**：10%-15%

## 成长能力指标

### 营收增速
```
营收增速 = (本期营收 - 上期营收) / 上期营收 × 100%
```

### 净利润增速
```
净利润增速 = (本期净利润 - 上期净利润) / 上期净利润 × 100%
```

### EPS增速
```
EPS增速 = (本期EPS - 上期EPS) / 上期EPS × 100%
```

## 偿债能力指标

### 资产负债率
```
资产负债率 = 总负债 / 总资产 × 100%
```
- **保守**：<40%
- **稳健**：40%-60%
- **激进**：>60%

### 流动比率
```
流动比率 = 流动资产 / 流动负债
```
- **优秀**：>2
- **良好**：1.5-2
- **一般**：<1.5

### 速动比率
```
速动比率 = (流动资产 - 存货) / 流动负债
```
- **优秀**：>1
- **良好**：0.8-1

## 运营效率指标

### 存货周转率
```
存货周转率 = 营业成本 / 平均存货
```

### 应收账款周转率
```
应收账款周转率 = 营业收入 / 平均应收账款
```

### 总资产周转率
```
总资产周转率 = 营业收入 / 平均总资产
```

## 现金流质量指标

### 经营现金流/净利润比率
```
比率 = 经营活动现金流净额 / 净利润
```
- **优秀**：>1
- **良好**：0.8-1
- **风险信号**：<0.5

### 自由现金流
```
FCF = 经营活动现金流净额 - 资本支出
```
