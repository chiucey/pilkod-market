# 客户筛选与AI潜力分析

## 执行流程

当用户提供客户公司名称时，按以下6阶段执行完整分析。

### 第一阶段：基础信息搜集

使用 `batch_web_search` 进行多维度并行搜索：
- 「公司名称」+ 「官方网站」+ 「企业介绍」
- 「公司名称」+ 「业务范围」+ 「主营业务」
- 「公司名称」+ 「所属领域」+ 「行业分类」
- 「公司名称」+ 「品牌矩阵」+ 「旗下品牌」
- 「公司名称」+ 「最新动态」+ 「2024」+ 「2025」

提取：企业基本信息、主营业务、关联品牌、企业规模、最新新闻

### 第二阶段：行业地位分析

专项搜索：
- 「公司名称」+ 「行业排名」+ 「市场份额」
- 「公司名称」+ 「竞争对手」+ 「行业对比」
- 「XX行业」+ 「TOP10」+ 「2024」+ 「2025」

分析：市场定位、核心优势、主要竞争对手、市场份额

### 第三阶段：AI应用现状调研

针对性搜索：
- 「公司名称」+ 「AI人工智能」+ 「应用案例」
- 「公司名称」+ 「大模型」+ 「AIGC」
- 「公司名称」+ 「智能客服」+ 「AI技术」
- 「公司名称」+ 「微软Azure」+ 「百度云」+ 「阿里云」+ 「腾讯云」+ 「AI合作」

AI现状评估标准：

| AI应用阶段 | 特征描述 | 识别关键词 |
|-----------|---------|-----------|
| 萌芽期 | 有转型意向，尚未落地 | "计划探索"、"有意向" |
| 探索期 | 初步尝试，单点应用 | "试点"、"首次"、"小范围" |
| 成长期 | 规模化应用，持续迭代 | "全面部署"、"规模化" |
| 成熟期 | 深度应用，输出能力 | "AI赋能"、"开放平台" |

### 第四阶段：AI应用方向预测

业务类型匹配逻辑：
- 高频交互 → 智能客服
- 内容产出 → AIGC
- 文档密集 → 文档处理
- 数据分析 → BI+AI

行业通用应用方向：
- 电商零售：智能客服、商品推荐、库存预测、个性化营销
- 金融保险：智能风控、文档处理（合同审核）、反欺诈
- 医疗健康：辅助诊断、医学影像分析、智能问诊
- 教育培训：智能答疑、个性化学习、作业批改
- 制造业：质量检测、预测性维护、智能排产
- 企业服务：智能客服、文档处理、流程自动化

### 第五阶段：API用量预估

用量计算公式：
```
月预估API用量 = 基础量级 × 业务强度系数 × AI渗透率系数
```

基础量级：
- 小型企业：1万-10万次/月
- 中型企业：10万-100万次/月
- 大型企业：100万-1000万次/月
- 超大型企业：1000万+次/月

业务强度系数：
- 高频客服：×2.0-3.0
- 内容创作密集：×3.0-5.0
- 对外API服务：×5.0-10.0

AI渗透率系数：
- 萌芽期：×0.05-0.1
- 探索期：×0.2-0.3
- 成长期：×0.5-0.7
- 成熟期：×0.8-1.0

### 第六阶段：综合评估

技术 Readiness（4维度×5分=20分）：
| 评估维度 | 评估指标 | 评分标准 |
|---------|---------|---------|
| 技术团队 | 是否有AI/ML团队 | 无=1，有专职团队=5 |
| 技术储备 | 现有技术栈与AI兼容性 | 完全不兼容=1，高度兼容=5 |
| 基础设施 | 云服务使用成熟度 | 传统IT为主=1，全面云化=5 |
| 数据能力 | 数据治理成熟度 | 数据混乱=1，数据资产化=5 |

商务 Readiness（4维度×5分=20分）：
| 评估维度 | 评估指标 | 评分标准 |
|---------|---------|---------|
| 预算意愿 | 对技术投入的预算水平 | 无预算=1，预算充足=5 |
| 决策链路 | 决策流程复杂度 | 多层级审批=1，快速决策=5 |
| 供应商偏好 | 对外部API服务的开放度 | 完全自研=1，开放合作=5 |
| 时间窗口 | 项目推进的紧迫程度 | 无计划=1，近期启动=5 |

## 输出规范

输出完整分析报告，包含8个部分：

1. **企业概览** - 基本信息、主营业务、品牌矩阵
2. **行业地位分析** - 所处行业、竞争格局、行业排名
3. **AI应用现状** - 现有AI应用、技术基础设施
4. **AI应用潜力分析** - 推荐方向、应用场景、行业标杆
5. **API用量预估** - 用量测算、增长预期
6. **综合评估** - 技术/商务 Readiness 评分、合作价值
7. **拓展建议** - 优先级、切入策略、风险提示、下一步行动
8. **信息来源** - 搜索来源、信息置信度

## 质量控制

- [ ] 基础信息完整（公司名称、业务描述、规模）
- [ ] 行业分析覆盖（行业分类、竞争格局）
- [ ] AI现状评估有据可查（至少1个AI相关事实）
- [ ] 用量预估有测算依据
- [ ] 事实性信息标注来源
- [ ] 评估性判断说明依据
