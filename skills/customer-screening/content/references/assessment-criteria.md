# 评估标准参考

## AI应用阶段判定

| AI应用阶段 | 特征描述 | 识别关键词 |
|-----------|---------|-----------|
| 萌芽期 | 有转型意向，尚未落地 | "计划探索"、"有意向"、"将引入" |
| 探索期 | 初步尝试，单点应用 | "试点"、"首次"、"小范围" |
| 成长期 | 规模化应用，持续迭代 | "全面部署"、"深入应用"、"规模化" |
| 成熟期 | 深度应用，输出能力 | "AI赋能"、"对外服务"、"开放平台" |

| 法律服务 | 合同审查、法律检索、案例分析、文书生成 |
| 媒体娱乐 | 内容创作、视频生成、智能剪辑、版权保护 |
| 企业服务 | 智能客服、文档处理、数据分析、流程自动化 |

## 用量预估模型

### 基础量级因子

| 公司规模 | 日均交互量估算 | API调用基础量级 |
|---------|--------------|----------------|
| 小型企业 | 100-1000次 | 1万-10万次/月 |
| 中型企业 | 1000-10000次 | 10万-100万次/月 |
| 大型企业 | 10000-100000次 | 100万-1000万次/月 |
| 超大型企业 | 100000+次 | 1000万+次/月 |

### 业务强度系数

| 业务特征 | 系数调整 |
|---------|---------|
| 高频客服场景 | ×2.0-3.0 |
| 内容创作密集 | ×3.0-5.0 |
| 文档处理密集 | ×1.5-2.5 |
| 内部效率工具 | ×0.5-1.0 |
| 对外API服务 | ×5.0-10.0 |

### AI渗透率系数

| AI应用阶段 | 渗透率 | 系数调整 |
|-----------|-------|---------|
| 萌芽期 | 5-10% | ×0.05-0.1 |
| 探索期 | 20-30% | ×0.2-0.3 |
| 成长期 | 50-70% | ×0.5-0.7 |
| 成熟期 | 80-100% | ×0.8-1.0 |

### 计算公式

```
月预估API用量 = 基础量级 × 业务强度系数 × AI渗透率系数
```

## 技术 Readiness 评估

| 评估维度 | 评估指标 | 评分标准（1-5分） |
|---------|---------|-----------------|
| 技术团队 | 是否有AI/ML团队 | 无=1，有专职团队=5 |
| 技术储备 | 现有技术栈与AI兼容性 | 完全不兼容=1，高度兼容=5 |
| 基础设施 | 云服务使用成熟度 | 传统IT为主=1，全面云化=5 |
| 数据能力 | 数据治理成熟度 | 数据混乱=1，数据资产化=5 |

总分：4维度×5分=20分

## 商务 Readiness 评估

| 评估维度 | 评估指标 | 评分标准（1-5分） |
|---------|---------|-----------------|
| 预算意愿 | 对技术投入的预算水平 | 无预算=1，预算充足=5 |
| 决策链路 | 决策流程复杂度 | 多层级审批=1，快速决策=5 |
| 供应商偏好 | 对外部API服务的开放度 | 完全自研=1，开放合作=5 |
| 时间窗口 | 项目推进的紧迫程度 | 无计划=1，近期启动=5 |

总分：4维度×5分=20分

## 特殊场景处理

### 场景1：信息不足
- 明确标注「信息不足」区域
- 提供「建议补充搜集」信息清单
- 基于有限信息给出初步判断（标注置信度）

### 场景2：信息矛盾
- 列出所有来源信息差异
- 分析矛盾原因
- 提供「最可能」和「次可能」两种判断

### 场景3：非上市公司
- 以工商信息、媒体报道为主
- 财务数据参考行业估算
- 重点关注业务动态和新闻事件

### 场景4：大型集团企业
- 分业务板块进行分析
- 识别AI需求最迫切的板块
- 评估集团整体API用量潜力
