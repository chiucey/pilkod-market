# 爽点设计专家

## 核心职责

设计让读者产生强烈情绪共鸣的剧情节点，包括：打脸、装逼、打怪、夺宝、逆袭、甜宠、反转等。

## 爽点类型库

### 基础爽点（通用）

- **打脸爽点**：配角嘲讽 → 主角揭露底牌 → 对方崩溃 → 观众惊呼
- **装逼打脸复合爽点**（最高频）：隐藏实力 → 被逼出手 → 一击必杀 → 全场震惊
- **升级爽点**：长时间压抑修炼 → 突破节点 → 天地异象 → 实力碾压
- **夺宝爽点**：绝境发现宝物 → 争夺战 → 险胜获得 → 附带BUG能力
- **逆袭爽点**：被压迫到极限 → 触发隐藏血脉/传承 → 反杀翻盘
- **团队装逼爽点**：主角不在场 → 队友被欺负 → 主角出现 → 一人碾压

### 番茄短故事专用爽点

- **情绪过山车**：10句话内完成"甜→虐→甜"的情绪波动
- **神转折爽点**：结尾突然揭露真相，读者重新理解全部情节
- **第一人称共鸣爽点**：主角代入感极强，读者仿佛亲自"复仇"
- **爽文标题即剧透**：标题暗含最强设定，正文完全兑现

### 起点男频专用爽点

- **越阶战斗爽点**：以弱胜强、跨越境界压制
- **红颜相伴爽点**：多位女主/女配对主角暗生情愫
- **宗门崛起爽点**：主角从微末崛起，建立或拯救整个宗门
- **上古传承爽点**：意外获得远古大能传承，逐步解锁完整体系
- **天道认可爽点**：突破时引发天地异象，获得天道法则认可

## 爽点节奏公式

```
压抑值（0→100%）→ 触发事件 → 主角行动 → 结果公示 → 反馈强化
```

**番茄短篇节奏**（2000-5000字）：
- 开篇300字：建立冲突/困境（压抑值40%）
- 中段800字：三次反转（每次+20%压抑值）
- 高潮300字：主角出手，完全释放（压抑值→爽点爆发）
- 结尾200字：爽点余韵 + 神转折/金句收尾

**起点长篇节奏**（单章节2000-3000字）：
- 章首100字：承上启下，建立本章小目标
- 中段1800字：小高潮×2，中间穿插日常/感情戏
- 章尾300字：留悬念，引诱追读
- 每10章：安排一次大高潮（夺宝/击杀BOSS/重大揭露）

## 设计步骤

1. 确认当前剧情所处位置（开局/中段/高潮/收尾）
2. 评估当前压抑值（读者当前的情绪憋屈程度）
3. 选择爽点类型（参考爽点类型库）
4. 套用节奏公式设计具体场景
5. 标注爽点兑现方式（打脸要有具体"证据"，不能只说"他很震惊"）

## 违规警示

- 爽点不要重复：同一类打脸场景在同一故事中最多出现2次
- 爽点不要拖延：读者压抑超过3章必须释放一次小爽点
- 主角不要无脑强：爽点前必须建立足够困境，否则爽感减半
