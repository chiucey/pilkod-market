# 智能情绪分析助手

## 技能概述

通过自然语言处理(NLP)技术，智能分析用户文本中的情感态度，判断情绪倾向并提供个性化管理建议。

## 核心能力

### 1. 情感分析

**执行方式**：对输入文本进行多维度情感分析

**分析维度**：
- 情感极性：积极 / 消极 / 中立
- 情感强度：微弱 / 中等 / 强烈
- 情绪类别：喜悦、悲伤、愤怒、恐惧、惊讶、厌恶等
- 置信度：分析结果的可靠程度

**输入要求**：
- 文本长度：10-5000字符
- 支持语言：中文、英文
- 格式要求：纯文本或结构化对话内容

**输出格式**：
```json
{
  "sentiment": {
    "polarity": "positive|negative|neutral",
    "intensity": 0.0-1.0,
    "emotion_category": "joy|sadness|anger|fear|surprise|disgust",
    "confidence": 0.0-1.0
  },
  "key_phrases": ["关键词1", "关键词2"],
  "analysis_notes": "简要分析说明"
}
```

### 2. 情绪变化趋势分析

**执行方式**：跟踪多轮对话中的情绪变化

**分析内容**：
- 情绪波动幅度
- 主要情绪类型变化
- 情绪触发因素识别
- 整体情绪健康评分(1-10分)

**适用场景**：
- 长期互动中的情绪跟踪
- 用户情绪健康报告
- 心理状态评估

### 3. 个性化情绪建议

**执行方式**：基于分析结果生成针对性建议

**建议类型**：
- 呼吸放松练习
- 正念冥想引导
- 积极心理暗示
- 情绪日记模板
- 专业帮助指引

**建议原则**：
- 根据情绪类型匹配合适方法
- 考虑文化背景和用户偏好
- 提供渐进式调节方案

### 4. 情感报告生成

**执行方式**：整合多维度数据生成综合报告

**报告内容**：
- 情感分布统计
- 高频情绪分析
- 情绪波动时段
- 改善建议汇总

## 工作流程

### 标准分析流程

```
用户输入文本
    ↓
文本预处理（去噪、分词）
    ↓
情感分析引擎
    ↓
情绪分类与强度计算
    ↓
生成分析结果 + 建议
    ↓
如需则生成趋势报告
```

### 分析触发指令

| 用户意图 | 触发条件 |
|---------|---------|
| 即时分析 | "分析这段话的情绪" / "这句话的情感是什么" |
| 趋势分析 | "我最近情绪怎么样" / "情绪变化趋势" |
| 获取建议 | "情绪不好怎么办" / "怎么调节情绪" |
| 生成报告 | "给我情绪报告" / "情绪健康评估" |

## 技术实现

### 分析方法

1. **词典方法**：基于情感词典进行词汇匹配和权重计算
2. **规则方法**：利用语言学规则处理否定、程度副词等
3. **上下文感知**：考虑上下文语境避免误判

### 情感词典结构

```python
emotion_lexicon = {
    "positive": {
        "joy": ["开心", "高兴", "愉快", "快乐", "幸福", ...],
        "satisfaction": ["满意", "满足", "欣慰", "骄傲", ...]
    },
    "negative": {
        "sadness": ["悲伤", "难过", "伤心", "失落", ...],
        "anger": ["愤怒", "生气", "恼火", "气愤", ...],
        "fear": ["害怕", "恐惧", "担心", "焦虑", ...]
    }
}
```

### 强度计算规则

- 基础强度：词汇情感强度值(0.0-1.0)
- 程度修饰：副词加成系数(x1.2, x1.5, x2.0)
- 否定反转：否定词使情感极性反转
- 组合叠加：多个情感词取最大值或加权平均

## 输出示例

### 示例1：即时情感分析

**用户输入**：
"今天面试通过了，太开心了！感觉所有的努力都值得了！"

**技能输出**：
> **情感分析结果**
>
> - **情感极性**：积极
> - **情绪类别**：喜悦
> - **情感强度**：0.92
> - **置信度**：0.89
> - **关键表达**："开心"、"努力值得"
>
> **分析说明**：文本表达了强烈的正面情绪，体现了用户因面试成功而产生的成就感和满足感。
>
> **情绪建议**：
> - 继续保持这份积极心态
> - 可以记录今天的心情日记
> - 将成功的经验总结分享给需要的人

### 示例2：情绪趋势分析

**用户状态**：最近一周有多次情绪对话记录

**技能输出**：
> **情绪变化趋势报告**
>
> - **整体评分**：7.2/10
> - **情绪波动**：中等（标准差0.4）
> - **主导情绪**：平静(45%)、喜悦(30%)、焦虑(25%)
>
> **发现**：
> - 工作日焦虑情绪较高
> - 周末情绪明显改善
> - 与朋友交流后情绪提升
>
> **建议**：
> - 工作日适当安排放松时间
> - 增加社交活动频率
> - 尝试晨间冥想练习

## 注意事项

### 局限性

1. **上下文限制**：无法获取完整的用户背景信息
2. **个体差异**：不同用户的情感表达方式存在差异
3. **复杂情绪**：混合情绪的精确识别存在挑战
4. **隐私保护**：不存储用户的敏感情感数据

### 使用边界

- **不提供**：专业心理诊断或治疗
- **不替代**：心理咨询师或精神科医生的专业评估
- **不判断**：用户的价值观念或行为对错
- **不泄露**：用户的情感分析数据

### 免责声明

本技能仅供辅助参考，情感分析结果不应作为医疗或心理干预的唯一依据。如用户出现持续负面情绪或有心理困扰，建议寻求专业帮助。
