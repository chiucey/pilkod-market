## 否定词

| 否定词 | 效果 |
|--------|------|
| 不、没、未、非、别、无 | 情感极性反转 |
| 难以、不能、不太 | 情感减弱 |
| 不得不、只能 | 无奈/压力情感 |

## 组合规则

### 否定+积极 → 消极
- "不开心" = 消极 (强度0.5-0.7)
- "不满意" = 消极/中性

### 否定+消极 → 积极/中性
- "不难过" = 积极/中性
- "不害怕" = 积极

### 双否定 → 积极
- "不得不承认" = 中性偏积极
- "未尝不是" = 积极
