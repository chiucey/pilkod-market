# 微信公众号文章运营SOP

## 一、选题策划阶段

### 1.1 选题来源收集
- **热点追踪**：每日查看微博热搜、知乎热榜、百度指数、微信指数
- **竞品分析**：关注同领域头部账号，分析其爆款文章选题方向
- **用户反馈**：整理后台留言、社群讨论中的高频问题
- **行业报告**：定期查阅行业白皮书、研究报告获取趋势洞察
- **内容日历**：提前规划节日、纪念日、行业大事件相关内容

### 1.2 选题评估标准
| 评估维度 | 权重 | 评分标准 |
|---------|------|---------|
| 受众相关性 | 25% | 目标用户是否关心这个话题 |
| 时效性 | 20% | 热点窗口期是否在48小时内 |
| 原创价值 | 20% | 能否提供独特观点或信息增量 |
| 可操作性 | 20% | 团队是否有能力产出高质量内容 |
| 传播潜力 | 15% | 是否具备社交货币属性（转发/讨论价值） |

### 1.3 选题确认流程
1. 每周一召开选题会，每人提交3-5个选题
2. 使用选题评分表进行打分排序
3. 确定本周主推选题（2-3个）和备选选题（3-5个）
4. 分配撰稿人和截稿时间

## 二、内容创作阶段

### 2.1 大纲撰写（Day 1）
**结构模板**：
```
标题：主标题 + 副标题（吸引点击）
开头：痛点引入/数据冲击/故事开场（200字内抓住注意力）
正文：
  - 核心观点1 + 论据/案例
  - 核心观点2 + 论据/案例
  - 核心观点3 + 论据/案例
结尾：总结升华 + 行动号召/互动引导
```

### 2.2 初稿撰写（Day 2-3）
**写作 checklist**：
- [ ] 开头3秒抓住注意力（使用冲突、疑问、数据）
- [ ] 每300字设置一个信息锚点（小标题/重点标注）
- [ ] 案例真实可溯源，标注数据来源
- [ ] 专业术语首次出现时添加通俗解释
- [ ] 全文控制在1500-2500字（深度文可至4000字）

### 2.3 内容审核（Day 4）
**三级审核机制**：
1. **撰稿人自审**：语法、错别字、事实核查
2. **编辑审核**：结构逻辑、表达流畅度、合规性检查
3. **负责人终审**：品牌调性、商业风险、发布时机

**审核重点**：
- 政治敏感词、广告法禁用词检查
- 图片版权、字体版权确认
- 外部链接有效性验证
- 二维码/联系方式准确性

## 三、排版设计阶段

### 3.1 排版规范
**视觉标准**：
- 字号：标题16-18px，正文14-16px，注释12px
- 行间距：1.5-1.75倍
- 段落间距：空一行分隔
- 配色：主色不超过3种，符合品牌VI
- 侧边距：两端缩进16px

### 3.2 配图规范
- 封面图：900×383px，信息密度适中，避免纯文字
- 头图：与封面呼应，强化主题
- 正文配图：每800字至少1张图，缓解阅读疲劳
- 信息图：复杂数据使用图表可视化
- 图片来源：优先使用原创/购买版权/CC0图库

### 3.3 排版工具
- 秀米XIUMI：模板丰富，适合快速排版
- 135编辑器：样式多样，SVG组件丰富
- 壹伴插件：数据采集、定时发布功能
- 新榜编辑器：爆文分析、素材灵感

## 四、发布前准备

### 4.1 发布检查清单
- [ ] 标题：不超过25字，含关键词，避免标题党
- [ ] 摘要：手动编写，50字内概括核心价值
- [ ] 封面图：已上传并预览效果
- [ ] 原文链接：如需跳转，链接已测试
- [ ] 合集/话题：已归入相应专辑
- [ ] 留言功能：已开启并设置精选规则
- [ ] 群发对象：确认分组（全部/标签分组）

### 4.2 发布时间策略
| 账号类型 | 最佳时段 | 备注 |
|---------|---------|------|
| 职场/商业 | 周二-周四 8:00-9:00 | 通勤时间 |
| 情感/生活 | 周一、周五 21:00-22:00 | 睡前阅读 |
| 教育/知识 | 周六-周日 10:00-11:00 | 周末学习时间 |
| 新闻/资讯 | 每日 7:30-8:30 | 早间资讯 |

## 五、推广传播阶段

### 5.1 内部推广
1. **朋友圈**：运营团队全员转发，配个性化推荐语
2. **社群分发**：按内容类型分发至对应用户群
3. **一对一推送**：对高价值用户/合作伙伴定向分享
4. **菜单栏更新**：重要文章置顶至公众号菜单

### 5.2 外部推广
- **跨平台分发**：知乎、小红书、今日头条、百家号同步
- **KOL合作**：邀请行业大V转载/点评
- **付费推广**：朋友圈广告、公众号互推、广点通
- **SEO优化**：文章内嵌入长尾关键词，提升搜索流量

## 六、数据复盘阶段

### 6.1 核心指标监控（发布后24h/72h/7d）
| 指标 | 健康基准 | 优化方向 |
|------|---------|---------|
| 打开率 | >5% | 优化标题+封面+发送时间 |
| 分享率 | >3% | 增强内容价值+社交货币 |
| 完读率 | >40% | 优化开头+结构+篇幅 |
| 涨粉数 | 正向增长 | 设置关注引导+裂变活动 |
| 留言率 | >1% | 结尾设置互动话题 |

| 用途 | 工具推荐 |

### 7.2 素材库建设
- **标题库**：按类型分类（悬念式、数字式、痛点式）
- **金句库**：行业名言、数据金句、观点提炼
- **案例库**：按主题分类的真实案例（含出处）
- **排版库**：保存常用排版样式，快速复用

## 八、应急处理机制

### 8.1 内容出错应急
1. **事实错误**：立即在评论区置顶勘误，严重者删除重发
2. **排版错误**：快速修改后重新推送（注意每日群发次数限制）
3. **舆情危机**：暂停推广，准备官方回应话术，上报管理层

### 8.2 发布延迟应急
- 建立内容储备池（常备3-5篇备用稿）
- 制定「热点快反」机制（2小时内产出短图文）

## 九、团队协作规范

### 9.1 角色分工
| 角色 | 职责 |
|------|------|
| 运营负责人 | 选题把关、终审发布、数据复盘 |
| 内容编辑 | 大纲审核、稿件修改、排版优化 |

### 9.2 工作流程图
```
选题会 → 大纲确认 → 初稿撰写 → 编辑审核 → 负责人终审 → 排版设计 → 发布推广 → 数据复盘
（周一）   （Day1）    （Day2-3）  （Day4）    （Day4）     （Day5）    （定时发布）  （发布后）
```

3. **年度复盘**：总结全年数据，制定下年度内容规划
