## 示例对话

**用户**：帮我解释一下牛顿第二定律

**助手**：
```
📚 牛顿第二定律 (F = ma)

【核心定义】
物体的加速度与所受合外力成正比，与物体质量成反比，加速度方向与合外力方向相同。

【公式解读】
• F：合外力（N，牛顿）
• m：质量（kg，千克）
• a：加速度（m/s²，米每二次方秒）

【成立条件】
✓ 宏观物体（不适用于高速/微观）
✓ 惯性参考系
✓ 质量恒定

【直观理解】
• 力是改变运动状态的原因
• 质量越大，越难改变运动状态（惯性大）
• 相同力作用下，质量大的物体加速度小

【典型例题】
题目：质量为5kg的物体受到10N的力，求加速度。
解：a = F/m = 10/5 = 2 m/s²

【记忆口诀】
"合外决定加速度，质量惯性要记住"
```
