# A股「抓主线」投资方法论

基于国投证券策略团队（林荣雄、黄玮宗）三篇系列研报提炼的标准化框架，用于识别 A股市场主线、研判驱动因素、把握投资节奏。

完整方法论正文见 `references/methodology.md`，本文件提供工作流与速查。

## 触发场景

- "当前 A股主线是什么 / 怎么抓主线"
- "用宏观叙事 / 产业趋势 / 增量资金 / 风格切换分析市场"
- "科技股到 N 字型哪一段了、C 点来了吗"
- "抱团是不是快见顶了、增量资金还能撑多久"
- "风格切换 / 高切低 / 反杠铃策略研判"

## 核心认知（先校准）

1. **目标**：不缺席大盛宴，不随便赶潮流。
2. **主线不是一网打尽**：主线多了就不叫主线。
3. **主线非时时清晰**：A股一年约 60% 时间主线清晰，40% 无明确主线（约 4-5 个月/年）。主线清晰度指标 >55% 清晰，<55% 混乱。
4. **初心**：敬畏市场、迭代进化；最危险是盲目延续过往逻辑。

## 两大思路

- **宏观策略定价**：首要识别政治周期 vs 经济周期主导。政治周期→叙事驱动；经济周期→周期时钟。
- **产业赛道定价**：短期轮动用"高切低"；中期趋势用"三率体系"。

## 四大抓手（选 1-2 个，不可杂糅）

| 抓手 | 作用周期 | 关键 |
|------|----------|------|
| 宏观叙事 | 2-3 年 | 新旧动能转换定价；视角控制 3 年内；非阴谋论需权威验证 |
| 产业趋势 | 1-2 年 | 三率体系（渗透率/替代率/市占率）；科技四阶段；N 字型 |
| 增量资金 | ~3 年 | 凡是趋势皆为抱团；抱团三要素见顶顺序 |
| 风格切换 | ≥1 季度 | Q1 定全年、Q3-Q4 切换；仓位失衡+宏观巨变=瞬时切换；反杠铃 |

**排序**：定价持续有效 宏观叙事>产业趋势>增量资金>风格切换；实操辨别难易 增量资金>宏观叙事>风格切换>产业趋势。

## 标准工作流（SOP）

**步骤 1｜主线清晰度初判**
- 主线清晰度指标 >55%？否 → 控制仓位，不做主线假设。
- 主导是政治周期还是经济周期？

**步骤 2｜选定 1-2 个抓手**（不可杂糅）
- 偏中长期叙事 → 宏观叙事
- 偏产业景气 → 产业趋势
- 偏资金面 → 增量资金
- 偏风格轮动 → 风格切换

**步骤 3｜按所选抓手研判**
- *产业趋势*：用三率体系定位环节；科技股判断 N 字型处在 A/B/C/D 哪段——**C 点（重仓胜负手，1-4 个月阶段）是否到来**；B-C 死扛、C-D 获超额，优秀者不参与 A-B、C 点重仓。
- *增量资金*：识别资金来源（体制先验 vs 市场化后验）；跟踪抱团三要素见顶顺序 **超额收益→估值分化→增量资金**（超额先顶、资金最后顶）；机构仓位是否失衡；口诀"A 卖可不定卖，B 卖必须卖"。
- *风格切换*：Q1 定全年、Q3-Q4 切换；中长期看 M1-M2/10Y 国债/成长-价值盈利差；突发条件"仓位失衡+宏观巨变=瞬时切换"（如 2021 茅→宁、2022 宁→煤炭；2025 关税因仓位未失衡未动摇）；10Y 国债陡降→杠铃，震荡→反杠铃回流中间资产。
- *宏观叙事*：抓叙事主体性；国内核心"新旧动能转换"（当前"新胜于旧"后期、反杠铃超额）；视角 3 年内。

**步骤 4｜短期叠加高切低**
- A股高切低指数：上沿 ~60 切向低位、下沿 ~30 补涨尾声/酝酿、极值 >90 共振。每年 2-3 次，周期 2-3 月。

**步骤 5｜长期底色校验**
- 30%-60% 定律：板块占 A股（剔金融）盈利破 30% 后 5-8 年升 60% 为基本面主线（当前科技+出海近 40%，向 60% 靠拢）。

**步骤 6｜纪律复盘**
- 不盲目延续过往逻辑；交叉验证逻辑信号与交易信号；警惕历史不代表未来、政策不及预期。

## 关键图表/指标速查

- 主线清晰度阈值：55%
- 高切低指数：上沿 60 / 下沿 30 / 极值 90
- 抱团见顶顺序：超额收益 → 估值分化 → 增量资金
- N 字型胜负手：C 点重仓
- 三因素框架：高增长细分 >50% 景气投资 / 25-50% 核心资产 / <25% 产业主题
