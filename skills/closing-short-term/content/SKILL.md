# 尾盘稳健短线策略 · 完整版 V3.0

## 一、适用风格

- **尾盘 T+1 超短**
- **只做主板**，不做创业板/科创板/ST
- 不格局、不扛单、不补仓、不做T
- 目标：小赚常赚、零大亏、低回撤

---

## 二、大盘环境判断（每日第一步，决定能否开仓）

**满足任意一条 → 全天空仓，不看任何票**

| 条件 | 阈值 |
|------|------|
| 沪指跌幅 | > 0.3% |
| 下跌家数 - 上涨家数 | > 1000只 |
| 市场炸板率 | > 35% |
| 跌停个股 | > 15家 |
| 高位连板股出现批量核按钮 | — |

> 只有环境全部达标，才进入选股。

---

## 三、选股硬条件（14:30 之后开始筛选）

### 基础条件

| # | 条件 | 标准 |
|---|------|------|
| 1 | 市场 | 仅沪市主板、深市主板 |
| 2 | 时间 | 14:30 后定型再选 |
| 3 | 涨幅 | 2.5% ～ 5%，**排除涨停股**（当日已涨停、封板买不进的标的不推荐） |
| 4 | 股性 | 近20个交易日内有过涨停（股性活跃） |
| 5 | 量能 | 量比 ≥ 1.3 |
| 6 | 市值 | 40亿 ～ 180亿 |
| 7 | 换手率 | 4.5% ～ 9% |

### 强势与风控条件

| # | 条件 | 说明 |
|---|------|------|
| 8 | 分时均价线 | 全天在均线上方运行，尾盘10分钟不跳水、不跌破均线 |
| 9 | 均线位置 | 股价同时站在5日、10日均线上方 |
| 10 | 上影线 | 近3日无放量长上影线（避雷针） |
| 11 | 高位股 | 不属于30日新高高位股（只做中段，不做鱼尾） |
| 12 | 板块 | 所属板块为当日涨幅前1/3主流板块，不做冷门孤股 |
| 13 | 排除项 | 减持、业绩暴雷、ST、问题庄股 |

---

## 四、买入规则

| 项目 | 规则 |
|------|------|
| 买入时间 | 14:45 ～ 14:55 |
| 标的数量 | 只选1只最强的 |
| 仓位控制 | 单只 ≤ 3成仓 |
| 买入方式 | 不低吸、不半路、不提前埋伏、不追涨，只做"确认强势" |

---

## 五、卖出铁律（次日必执行）

| 情况 | 动作 |
|------|------|
| 9:30～10:00 不快速冲高 | 直接卖出 |
| 盈利 ≥ 3% | 止盈，不贪 |
| 低开 ≤ -1.5% 且无承接 | 直接走 |
| 亏损达到 -3% | 无条件止损 |
| 无论盈亏 | 10点前基本了结 |
| 纪律红线 | 绝不格局、绝不补仓、绝不加仓做T |

---

## 六、风险底线（策略灵魂）

- 环境差 → **空仓**
- 不符合条件 → **空仓**
- 看不懂 → **空仓**
- 连续小赚后更保守
- **宁可错过，绝不做错**

---

## 七、一句话总结

> 只在大盘安全日，尾盘选主板中段强势股，次日冲高就跑，**空仓比乱做更重要**。
