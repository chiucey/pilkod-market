## 视频提示词结构体系

### A. 基础五要素

所有视频提示词必须包含：

1. **主体（Subject）**：谁/什么出现在画面中，具体描述人物、动物、物体、场景
2. **动作（Action）**：主体的动态，用动词驱动画面
3. **场景（Setting）**：地点、环境、光线、天气
4. **风格（Style）**：写实/动漫/水墨/赛博朋克/吉卜力
5. **氛围（Mood）**：情绪核心，温暖/压抑/欢快/孤独/紧张

### B. 即梦/Seedance 正确格式

```
✅ 正确："一位穿白色长裙的女生站在海边，海风吹起裙摆，夕阳侧光，温暖色调，电影感，竖屏9:16，写实风格"
❌ 错误："女孩在海边"（过于简略）
```

### C. 即梦/Seedance 格式规范补充

| 参数 | 选项 |
|:---|:---|
| 比例 | 竖屏9:16 / 横屏16:9 / 方形1:1 |
| 分辨率 | 768P / 1080P |
| 时长 | 6秒 / 10秒 |
| 运镜 | 推镜头/拉镜头/摇镜头/跟拍/航拍/固定机位 |

## 四种模态创作指南

### 模态一：文本→视频（Text-to-Video）

适用工具：即梦Seedance、Seedance 2.0 Fast、豆包

模板：主体 + 动作/变化 + 场景 + 风格 + 氛围 + 技术参数

例：
```
主体：一位穿着深色大衣的男人
动作：站在城市街道上，步履匆匆向前走，围巾随风飘动
场景：夜晚霓虹灯街道，雨后积水倒映灯光
风格：电影感，写实风格
氛围：孤独但充满希望
技术：竖屏9:16，固定机位，侧跟拍
```

### 模态二：图像→视频（Image-to-Video）

适用工具：即梦图生视频、Seedance I2V

```
基础版（保持原图）："保持原图画面主体和风格，主体进行自然微动（如：呼吸、眨眼、风吹）"
进阶版（添加运镜）："基于原图画面，镜头向前缓慢推进，主体保持不动，环境产生微风吹拂效果"
首尾帧版：开头帧：[分镜图A描述] → 结尾帧：[分镜图B描述]
```

### 模态三：视频→视频（Video-to-Video）

适用工具：Seedance风格迁移、即梦视频风格化

```
模板：将[参考视频]转化为[目标风格]版本，保持[需要保留的元素]
例：将现实拍摄的城市街道视频转化为水墨画风格，保持建筑轮廓和人流动态
```

### 模态四：音频/音乐→视频（Audio-to-Video）

根据音乐节奏匹配画面：
- 节奏快（140BPM+）→ 画面切换快、运镜急促、色彩饱和
- 节奏慢（70BPM-）→ 慢镜头、长停留、暖色调
- 情绪悲伤 → 冷色调、留白、缓慢推拉镜头
- 情绪欢快 → 暖色调、跳切、色彩丰富

## 分镜设计标准流程

### Step 1：需求确认
```
1. 视频主题：（一句话描述核心内容）
2. 时长要求：（秒数）
3. 竖屏/横屏：（比例）
4. 情绪基调：（治愈/紧张/浪漫/悬疑/燃向）
5. 目标受众：（决定语言风格和画面尺度）
```

### Step 2：镜头拆分

| 镜号 | 时长 | 景别 | 画面内容 | 运镜 | 提示词 |
|:---:|:---:|:---:|:---|:---|:---|
| 1 | 2s | 远景 | 开场定场 | 固定/航拍 | [完整提示词] |
| 2 | 3s | 中景 | 主体出场 | 推镜头 | [完整提示词] |
| 3 | 2s | 特写 | 情绪细节 | 固定 | [完整提示词] |

### Step 3：生成顺序
```
① 先用文本生成（Text2V）验证风格方向
② 确认风格后，生成/收集分镜图
③ 用首尾帧（I2V）生成关键过渡镜头
④ 用图生视频（I2V）生成主体镜头
⑤ 补齐环境/空镜镜头
```

## 常见问题处理

| 问题 | 解决方案 |
|:---|:---|
| 画面抖动太厉害 | 添加"稳定器效果，固定机位" |
| 风格不统一 | 在所有镜头提示词末尾统一添加相同风格标签 |
| 主体在多镜头中不一致 | 建立"主体特征描述库"，每条提示词引用 |
| 运镜效果差 | 改用"固定机位"，改用剪辑实现运镜 |
| 生成画面太暗/太亮 | 指定光线方向和强度："温暖侧光，光比2:1" |
| 人物表情僵 | 用"自然表情，微表情"替代"微笑"等抽象描述 |

## 执行原则

- 先问目的，再动笔："这个视频发在哪里？给谁看？"
- 提示词宁实勿虚："穿白裙的女生" > "美女"
- 风格标签统一加在每条提示词末尾
- 分镜数量按时长控制：15秒 → 4-6镜头；60秒 → 8-12镜头
- 始终提醒用户：AI生成有随机性，最终效果需实测调整

## 一句话原则

**先有画面感，再写提示词；先有结构，再动笔；提示词宁多勿少，风格前后一致。**
