# 招聘智能匹配系统

## 功能概述

本技能实现招聘岗位数据的智能采集与候选人评估匹配，提供一站式人才评估解决方案。

## 工作流程

### 阶段1：数据采集

#### 1.1 招聘岗位抓取
- **输入**：关键词、地点（默认上海）、平台选择
- **输出**：结构化岗位数据（JSON格式）
- **支持的平台**：
  - 猎聘 (liepin.com)
  - Boss直聘 (zhipin.com)
  - 51Job (51job.com)
  - 企业官网（需提供URL）
  - 微信小程序岗位（通过官网链接）

#### 1.2 采集数据字段
```json
{
  "platform": "平台名称",
  "company": "公司名称",
  "position": "岗位名称",
  "location": "工作地点",
  "salary": "薪资范围",
  "requirements": ["技能要求数组"],
  "experience": "经验要求",
  "education": "学历要求",
  "job_desc": "岗位描述",
  "post_date": "发布日期",
  "url": "原始链接"
}
```

### 阶段2：候选人评估

#### 2.1 简历解析
- **支持格式**：PDF、Word、图片（OCR）
- **解析字段**：
  - 基本信息（姓名、年龄、联系方式）
  - 教育背景（学校、专业、学历、留学经历）
  - 工作经验（公司、职位、时长、成就）
  - 技能清单（硬技能、软技能）
  - 薪资期望

#### 2.2 评估维度
| 维度 | 权重 | 说明 |
|------|------|------|
| 胜任力 | 30% | 技能匹配度、岗位适应性 |
| 工作经验 | 25% | 相关经验年限、行业匹配 |
| 教育背景 | 15% | 学历等级、专业相关度 |
| 薪资匹配 | 15% | 与岗位薪资的匹配度 |
| 稳定性 | 15% | 工作年限、换工作频率 |

### 阶段3：潜在分析

#### 3.1 家境评估
- 留学背景识别（国家、学校排名）
- 留学开销估算（学费、生活费）
- 家庭经济支撑能力

#### 3.2 婚姻家庭
- 年龄与婚姻状态推断
- 家庭负担评估
- 工作稳定性因素

#### 3.3 发展潜力
- 职业路径预测
- 技能成长曲线
- 晋升可能性评估
- 行业转换概率

### 阶段4：匹配输出

#### 4.1 匹配报告结构
```json
{
  "match_id": "唯一标识",
  "candidate": {
    "name": "候选人姓名",
    "basic_score": 85,
    "education_score": 90,
    "experience_score": 80,
    "skill_score": 88
  },
  "matched_jobs": [
    {
      "position": "岗位名",
      "company": "公司名",
      "match_rate": 92,
      "salary_match": 95,
      "recommendation": "强烈推荐/推荐/一般"
    }
  ],
  "potential_analysis": {
    "family_background": "家境分析",
    "career_potential": "职业潜力评估",
    "risk_factors": ["风险因素数组"]
  },
  "overall_evaluation": "综合评价",
  "generated_at": "生成时间"
}
```

#### 4.2 输出格式
- 默认：JSON结构化数据
- 可选：HTML可视化报告
- 批量：CSV汇总表

## 使用方式

### 单次匹配
```
开始评估：
1. 选择/上传候选人简历（支持PDF/Word/图片）
2. 选择评估的招聘平台（可多选）
3. 输入目标岗位关键词
4. 等待分析完成
```

### 批量处理
```
批量评估：
1. 上传候选人文件夹（ZIP或文件夹路径）
2. 配置评估参数（权重、阈值）
3. 启动批量处理
4. 导出所有评估报告
```

## 配置参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| min_match_rate | 60 | 最低匹配阈值（%） |
| top_n_jobs | 10 | 每个候选人推荐岗位数 |
| analysis_depth | "standard" | 分析深度（simple/standard/deep） |
| language | "zh-CN" | 报告语言 |
| include_potential | true | 是否包含潜力分析 |

## 注意事项

1. **数据隐私**：所有上传的简历仅用于本次评估，不做持久化存储
2. **网站限制**：部分平台可能有访问频率限制，采集可能需要排队
3. **OCR精度**：图片简历的OCR识别准确率约85-95%，重要信息请核实
4. **评估建议**：综合评估仅供参考，最终决策需结合实际情况

## 错误处理

| 错误类型 | 处理方式 |
|----------|----------|
| 网站访问失败 | 记录日志，尝试备选平台 |
| 简历解析失败 | 提示用户检查文件格式 |
| 匹配超时 | 返回已完成的匹配，跳过失败项 |
| 数据不完整 | 标记不确定性，仅输出可信结果 |
