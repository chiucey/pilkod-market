# 不良反应与毒性分级标准

## CTCAE v5.0 常见毒性分级

### 血液学毒性

#### 中性粒细胞减少
| 分级 | ANC (×10⁹/L) | 临床表现 |
|------|--------------|----------|
| 1级 | 1.5 - <2.0 | 无发热 |
| 2级 | 1.0 - <1.5 | 无发热 |
| 3级 | 0.5 - <1.0 | 或伴发热 |
| 4级 | <0.5 | 危及生命 |

#### 血小板减少
| 分级 | PLT (×10⁹/L) | 临床表现 |
|------|--------------|----------|
| 1级 | 75 - <100 | 无出血 |
| 2级 | 50 - <75 | 轻微出血 |
| 3级 | 25 - <50 | 出血需干预 |
| 4级 | <25 | 危及生命 |

#### 贫血
| 分级 | Hb (g/L) | 临床表现 |
|------|----------|----------|
| 1级 | 100 - <正常下限 | 无症状 |
| 2级 | 80 - <100 | 轻度症状 |
| 3级 | 65 - <80 | 需输血/氧疗 |
| 4级 | <65 | 危及生命 |

#### 淋巴细胞减少
| 分级 | 淋巴细胞 (%) |
|------|--------------|
| 1级 | 20 - <正常下限 |
| 2级 | 10 - 20 |
| 3级 | 5 - 10 |
| 4级 | <5 |

### 免疫相关不良反应（irAE）

#### irAE分级原则
| 分级 | 处理原则 |
|------|----------|
| 1级 | 密切监测，可继续免疫治疗 |
| 2级 | 暂停免疫治疗，糖皮质激素 |
| 3级 | 永久停用免疫治疗，住院治疗 |
| 4级 | 永久停用，紧急干预 |

#### 常见irAE管理
| irAE | 2级处理 | 3-4级处理 |
|------|---------|-----------|
| 皮疹 | 局部激素 | 全身激素，永久停用 |
| 肝炎 | 暂停，激素 | 永久停用，激素 |
| 肺炎 | 暂停，评估 | 永久停用，激素+抗生素 |
| 甲状腺 | 对症 | 激素（如严重） |
| 结肠炎 | 暂停，激素 | 永久停用，激素 |

### 常用毒性分级标准对照

| 1级(轻度) | 2级(中度) | 3级(重度) | 4级(危及生命) |
|-----------|-----------|-----------|---------------|
| 无症状 | 中度症状 | 严重症状 | 危及生命 |
| 无需干预 | 最小干预 | 积极干预 | 紧急干预 |
| 不影响日常 | 影响日常 | 明显影响 | 功能丧失 |

### 不良事件严重程度判定

#### 严重不良事件(SAE)定义
- 导致死亡
- 危及生命
- 需要住院或延长住院
- 导致永久或显著功能障碍
- 导致先天畸形
- 其他重要医学事件

#### 不良事件因果关系判定
| 关系 | 定义 |
|------|------|
| 肯定有关 | 明确时间关系，符合已知反应 |
| 可能有关 | 时间合理，符合可能反应 |
| 可能无关 | 时间不典型，难以用疾病解释 |
| 肯定无关 | 确定非药物原因 |
| 无法判定 | 资料不足 |

## 支持治疗参考

### 骨髓抑制支持
| 毒性 | 支持治疗 |
|------|----------|
| 中性粒细胞减少 | G-CSF（3-4级或伴发热） |
| 血小板减少 | IL-11、TPO受体激动剂、输注 |
| 贫血 | 促红素、输血 |
| 粒缺伴发热 | 广谱抗生素，住院 |

### 恶心呕吐预防
| 风险级别 | 方案示例 |
|----------|----------|
| 高致吐 | 5-HT3+地塞米松+NK1 |
| 中致吐 | 5-HT3+地塞米松 |
| 低致吐 | 地塞米松或甲氧氯普胺 |

### 腹泻管理
| 分级 | 处理 |
|------|------|
| 1-2级 | 洛哌丁胺，补液 |
| 3级 | 停药，洛哌丁胺，奥曲肽 |
| 4级 | 住院，静脉补液 |
