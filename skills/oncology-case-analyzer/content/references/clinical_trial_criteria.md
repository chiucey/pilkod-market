# 临床试验患者筛选标准参考

## 标准入选/排除标准模板

### 一般入选标准

| 参数 | 典型标准 | 说明 |
|------|----------|------|
| 年龄 | ≥18岁 | 部分试验要求≥75岁或有宽松上限 |
| 组织学/细胞学 | 确诊恶性实体瘤 | 需有明确病理诊断 |
| 疾病状态 | 复发/难治/转移性 | 根据试验目的 |
| 既往治疗 | 标准治疗失败/不耐受 | 或初治患者 |
| RECIST评估 | 可测量病灶 | 靶病灶≥10mm |
| 器官功能 | 代偿良好 | 具体标准见下 |

### 器官功能入选标准

#### 血液学指标
| 参数 | 标准值 | 单位 |
|------|--------|------|
| **ANC** | ≥1.5 或 ≥2.0 | ×10⁹/L |
| **血小板** | ≥100 或 ≥75 | ×10⁹/L |
| **血红蛋白** | ≥90 或 ≥80 | g/L |
| **淋巴细胞** | 无特定 或 ≥0.5 | ×10⁹/L |

#### 肝脏功能
| 参数 | 标准值 | 单位 |
|------|--------|------|

| **总胆红素** | ≤1.5 或 ≤ULN | μmol/L |

#### 凝血功能
| 参数 | 标准值 | 单位 |

## 常见排除标准

### 器官功能障碍
- 活动性肝炎（HBV/HCV）
- 严重肝/肾功能不全
- 心脏疾病（心衰、不稳定心绞痛）
- 严重肺部疾病

### 合并用药限制
- 免疫抑制剂
- CYP3A4强抑制剂/诱导剂
- 抗凝药物（如特定要求）

### 既往治疗限制
- 洗脱期不足（化疗2-4周、生物制剂2-4周）
- 既往同靶点药物使用
- 放疗完成不足时间窗

### 其他排除
- 妊娠/哺乳
- 活动性感染
- 自身免疫疾病
- 脑转移（特定试验）
- 精神疾病/药物滥用

## 特定瘤种筛选要点

### 肺癌（NSCLC）
| 参数 | 常见要求 |
|------|----------|
| 基因突变 | EGFR/ALK/ROS1检测要求 |
| PD-L1 | TPS≥1%或≥50%（部分试验） |
| 既往免疫治疗 | 通常排除 |
| 脑转移 | 多为排除（部分纳入） |

### 乳腺癌
| 参数 | 常见要求 |
|------|----------|
| HR状态 | ER/PR阳性比例 |
| HER2状态 | IHC/FISH检测 |
| BRCA突变 | gBRCA1/2（部分试验） |
| 既往抗HER2 | 洗脱期要求 |

### 消化道肿瘤
| 参数 | 常见要求 |
|------|----------|
| MSI状态 | MSI-H/dMMR检测 |
| HER2 | IHC/FISH检测 |
| 肝炎状态 | HBV/HCV筛查 |
| 营养状态 | 白蛋白、BMI要求 |

### 淋巴瘤
| 参数 | 常见要求 |
|------|----------|
| 疾病类型 | 确诊亚型 |
| 既往治疗线数 | 具体要求 |
| 自体干细胞移植 | 既往是否进行 |
| PET-CT | Deauville评分 |

## ECOG评分标准

| 评分 | 描述 | 体力状态 |
|------|------|----------|
| **0** | 完全正常，无症状 | 活动自如 |
| **1** | 有症状，但几乎完全活动 | 限制剧烈活动 |
| **2** | 卧床时间<50% | 能生活自理 |
| **3** | 卧床时间≥50% | 生活仅限简单护理 |
| **4** | 完全卧床 | 无法生活自理 |
| **5** | 死亡 | - |

## 常用计算公式

### Cockcroft-Gault公式（CrCl）
```
男性: CrCl = (140 - 年龄) × 体重(kg) / (72 × 血清肌酐mg/dL)
女性: CrCl = 上述结果 × 0.85
```

### 体表面积（BSA）
```
Mosteller公式: BSA = √(身高cm × 体重kg / 3600)
```

### NLR和PLR
```
NLR = ANC / 淋巴细胞计数
PLR = 血小板计数 / 淋巴细胞计数
```

## 临床试验筛选流程

### 初筛阶段
1. 病历回顾（诊断、分期、既往治疗）
2. 筛选标准核对
3. 预约筛选期访视

### 筛选期评估
1. 知情同意
2. 人口学资料
3. 病史采集
4. 体格检查
5. ECOG评分
6. 生命体征
7. 心电图
8. 实验室检查
9. 影像学评估
10. 组织样本采集

### 合格性确认
1. 所有入排标准核对
2. 不良事件评估
3. 合并用药审核
4. 随机化（如适用）

### 常见失败原因
| 原因类别 | 常见问题 |
|----------|----------|
| 疾病相关 | 无可测量病灶、疾病进展 |
| 器官功能 | 肝/肾功能不达标、骨髓抑制 |
| 既往治疗 | 洗脱期不足、禁止用药 |
| 患者因素 | 拒绝知情、失访 |
| 其他 | 妊娠、感染、合并肿瘤 |
