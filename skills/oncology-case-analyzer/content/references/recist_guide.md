# RECIST 1.1 评估标准详解

## 核心原则

RECIST 1.1 (Response Evaluation Criteria in Solid Tumors) 是评估实体瘤治疗疗效的国际标准。

## 靶病灶选择标准

### 数量限制
- **总计 ≤5个**靶病灶
- **每器官 ≤2个**靶病灶
- 选择代表疾病负荷最大的病灶

### 测量要求
| 病灶类型 | 最小测量尺寸 | 测量方法 |
|----------|-------------|----------|
| 实体瘤 | ≥10 mm | CT扫描层厚≤5mm |
| 淋巴结 | ≥15 mm（短径） | CT短轴测量 |
| 胸片 | ≥20 mm | - |
| 体格检查 | ≥10 mm | 卡尺测量 |

### 不可作为靶病灶
- 骨病变（除非是无可争议的软组织成分）
- 既往放疗区域的病灶（除非明确进展）
- 脑病变（需专门评估标准）

## 疗效评估标准

### 靶病灶评估

| 疗效 | 定义 | 计算公式 |
|------|------|----------|
| **CR** (完全缓解) | 所有靶病灶消失 | 靶病灶总和=0 |
| **PR** (部分缓解) | 靶病灶总和减少≥30% | (基线和-评估和)/基线和≥30% |
| **SD** (疾病稳定) | 变化在PR和PD之间 | 既不符合PR也不符合PD |
| **PD** (疾病进展) | 靶病灶总和增加≥20% | (评估和-基线和)/基线和≥20% |
| **PD (最小变化)** | 绝对值增加≥5mm | 靶病灶总和增加≥5mm |

### 非靶病灶评估

| 疗效 | 定义 |
|------|------|
| **CR** | 所有非靶病灶消失，肿瘤标志物正常 |
| **Non-CR/Non-PD** | 存在一个或多个非靶病灶持续存在 |
| **PD** | 任何非靶病灶明确进展 |

### 新病灶评估
- **新病灶出现**：无论靶病灶评估如何，均判定为PD
- 必须通过重复扫描确认（避免假阳性）
- 骨扫描新热区需进一步评估

## 整体疗效综合评估

| 靶病灶 | 非靶病灶 | 新病灶 | 总体疗效 |
|--------|----------|--------|----------|
| CR | CR | 无 | CR |
| CR | Non-CR/Non-PD | 无 | PR |
| PR | 任何 | 无 | PR |
| SD | 任何 | 无 | SD |
| PD | 任何 | 无 | PD |
| 任何 | 任何 | 有 | PD |
| CR | 任何 | 无 | CR |

## 最佳总体疗效确认

1. 首次达到CR或PR的时间点后，需**4周后确认**
2. SD评估需在**基线后≥6周**进行
3. 疾病稳定但随访不足6周的患者，最佳疗效为"无法评估"

## 特殊情况的评估

### 混合反应
- 同一患者部分病灶PR/CR，部分病灶PD
- 判定为PD（有新病灶或靶病灶总体进展）

### 液性病灶（如胸腹水）
- 不纳入靶病灶评估
- 需单独评估是否作为非靶病灶

### 囊肿/囊性病变
- 需测量实性成分
- 若完全为囊性，评估为"非靶病灶-无证据"

## 时间点评估

### 常规评估间隔
| 治疗类型 | 评估间隔 |
|----------|----------|
| 化疗 | 每2-3周期（6-9周） |
| 靶向治疗 | 每6-8周 |
| 免疫治疗 | 可延长至每8-12周（irRC标准） |

### 评估注意事项
- 同一治疗线内需保持评估方法一致
- 每次评估需包含所有靶病灶
- 需记录每个靶病灶的绝对测量值

## RECIST 1.1 vs 1.0 主要变化

1. **淋巴结评估**：新增短径≥15mm标准
2. **靶病灶数量**：从10个减少到5个
3. **骨病变**：更明确排除标准
4. **确认时间**：CR/PR确认时间从4周缩短为4周（但SD评估时间延长）
5. **新增"non-CR/non-PD"**用于非靶病灶评估
