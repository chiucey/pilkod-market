# Truth Finder · 真相发现器

基于《非理性决策》五大认知陷阱体系的结构化信息真伪分析工具。

## 核心框架：五大认知陷阱

| 陷阱类型 | 关键词信号 | 典型手法 |
|---------|---------|---------|
| **逻辑陷阱** | "只能"、"所有"、"100%"、诉诸权威、诉诸情感 | 绝对化谬误、轻率归纳、滑坡论证 |
| **言语陷阱** | 细节魔鬼、偷换概念、诱饵调包 | 用无关细节分散注意力、混淆相似概念 |
| **心理陷阱** | 确认偏误、幸存者偏差、后见之明 | 只展示支持性证据、只谈成功案例 |
| **数据陷阱** | 无基准的大数、百分比缺基数、相关当因果 | 数字游戏、平均值陷阱、虚假相关 |
| **传播陷阱** | 匿名来源、情绪化标题、过期信息重发 | 媒体偏见、回音室效应、愤怒机器 |

## 工作流程

### 第一层：规则引擎检测（快速扫描）

按以下顺序检测，每个陷阱类型对应扣分：

```
逻辑陷阱命中 → 扣8分
言语陷阱命中 → 扣6分
心理陷阱命中 → 扣7分
数据陷阱命中 → 扣10分
传播陷阱命中 → 扣5分
利益冲突命中 → 扣12分
```

### 第二层：语义深度分析

对每条信息，依次回答：
1. **绝对化表述？** → 逻辑陷阱
2. **情绪化包装？** → 言语陷阱
3. **只展示单方证据？** → 心理陷阱（确认偏误）
4. **数字是否缺基准？** → 数据陷阱
5. **来源可信吗？** → 传播陷阱

### 第三层：交叉验证

对每个事实主张，搜索至少1个对立数据源进行验证。
对每个因果主张，进行反事实推演（若没有X，Y还会发生吗？）

## 输出格式

分析完成后，按以下结构输出：

```
🔴/🟡/🟢 真相可信度：X/100
🔴/🟡/🟢 评级：[可靠/可疑/高度存疑/虚假]

⚠️ 红色警告：
  · [命中的陷阱类型及具体证据]
  · [缺失的关键语境]

✅ 事实修正版本：
  [中性、客观的修正表述]

💡 认知陷阱归类：
  《非理性决策》- [对应章节]
  属于[陷阱类型名称]
```

## 评分标准

| 得分 | 评级 | 含义 |
|------|------|------|
| 80-100 | 🟢 可靠 | 有多个可靠来源支持，无重大陷阱信号 |
| 50-79 | 🟡 可疑 | 存在1-2类陷阱，需进一步核实 |
| 20-49 | 🔴 高度存疑 | 存在3类以上陷阱，证据不充分 |
| 0-19 | 🔴 虚假 | 主要主张与权威证据矛盾 |

## 核心原则

> **先反思再反应，遵从证据而非情绪。**
> 人类本质是非理性的，信息传播常常利用这些弱点大做文章。
> 对任何"常识"都应多问一句：证据是什么？
