# 五大陷阱检测规则库

## 一、逻辑陷阱（扣8分/项）

### 1.1 绝对化表述
```
- "只能"、"必须"、"所有"、"全部"、"没有...任何"、"100%"、"永远"、"从不"
- 典型正则：r"只能|必须|所有|全部|100%|永远|从不|没有.*任何"
```

### 1.2 诉诸权威（滥用）
```
- 无具体姓名的"专家说"、"权威人士称"
- 无具体机构的"研究表明"、"数据显示"
- 典型正则：r"(专家|权威人士|研究表明|权威机构)说"（无具体名称时触发）
```

### 1.3 诉诸情感
```
- 情绪词汇：震惊、可怕、秘密、国人必看、紧急
- 操控性表述：必须知道、赶紧、马上、立刻
- 典型正则：r"(震惊|可怕|秘密|国人必看|紧急|必须知道|赶紧|马上)"
```

### 1.4 滑坡论证
```
- 模式：如果A→B→C→...→Z（无根据的连锁推断）
- 典型正则：r"如果.{0,15}那么.{0,15}必然.{0,10}最终"
```

### 1.5 非黑即白
```
- 模式：不是A就是B / 只有A才能B
- 典型正则：r"不是.{0,8}就是|只有.{0,8}才能"
```

### 1.6 轻率归纳
```
- 从单个案例推断全体
- 典型信号："有人...所以全部"、"张三如此，所以所有人都..."
```

## 二、言语陷阱（扣6分/项）

### 2.1 细节魔鬼
```
- 用大量无关具体细节分散对核心论点的注意力
- 触发条件：信息中包含超过3个无关具体细节（时间/地点/人物）与核心主张无关
```

### 2.2 偷换概念
```
- 将两个相似但不同的概念混用
- 检查：同一词语在不同语境中的含义是否发生变化
```

### 2.3 诱饵-调包
```
- 用一个合理问题悄悄替换真正需要讨论的问题
- 检查：文章/信息是否在回答一个与标题/核心主张不同的问题
```

### 2.4 双重标准
```
- 对相似情况采用不同评判标准
- 检查：事件A和事件B本质相同但表述是否存在明显双标
```

## 三、心理陷阱（扣7分/项）

### 3.1 确认偏误
```
- 只展示支持某一立场的事实，忽略对立证据
- 检测：信息是否只引用单一来源、单一年份、单一案例
```

### 3.2 幸存者偏差
```
- 只展示成功案例，不提失败率
- 检测：是否出现"XXX成功了，所以方法Y可行"但不提失败数据
```

### 3.3 后见之明偏误
```
- 用事后已知结果反推当初"必然"
- 检测：是否用"结果证明"来代替"过程分析"
```

### 3.4 锚定效应
```
- 首次出现的信息影响后续判断
- 检测：第一个数字/判断是否被无依据地当作基准
```

### 3.5 稀缺性操控
```
- "限时"、"名额有限"、"仅此一次"——制造虚假紧迫感
- 典型正则：r"限时|名额有限|仅此一次|紧急|抢完为止"
```

## 四、数据陷阱（扣10分/项）

### 4.1 无基准的绝对数
```
- 触发条件：出现数字+单位，但缺少对比参照
- 例："增长300%"——缺少和什么比？"增长至300%"——缺少原始值
```

### 4.2 百分比缺基数
```
- 触发条件：出现百分比，但未提供样本总量
- 例："有效率95%"——总数是10人还是10000人？
```

### 4.3 相关冒充因果
```
- 触发条件：A和B相关→直接声称A导致B
- 必要检查：是否排除了混杂变量？
```

### 4.4 均值/中位数陷阱
```
- 触发条件：提到平均值但未说明分布
- 例：某公司平均薪资50万——可能99%拿3000，CEO拿几千万
```

### 4.5 样本偏差
```
- 触发条件：小样本+大范围结论
- 检测：样本量是否≥30？是否随机抽样？
```

### 4.6 人工干预的平均值
```
- 排除极值后的平均值、不对称加权平均
- 检测：是否说明了数据处理方式？
```

## 五、传播陷阱（扣5分/项）

### 5.1 来源不明
```
- 触发：匿名来源（"网友"、"某知情人士"、"消息人士"）
- 典型正则：r"网友|知情人士|据消息人士|据内部人士"
```

### 5.2 自媒体+情绪化标题
```
- 触发：自媒体来源 + 含情绪词的标题
- 组合风险：高于单一风险之和
```

### 5.3 旧闻重发
```
- 触发：超过1年的信息被标注为"最新"、"刚刚"
- 检测：publish_time与now的差距
```

### 5.4 回音室效应
```
- 触发：多个来源引用同一单一信息源
- 检测：信息链中是否只有一个原始来源
```

### 5.5 选择性报道
```
- 触发：对同一事件，挑选最极端版本报道
- 检测：是否只呈现事件的一个侧面
```

## 六、利益冲突检测（扣12分）

### 6.1 来源与被报道者重合
```
- 信息来源本身是被报道的主体
- 例：公司官网发布"我们公司全球第一"
```

### 6.2 付费信息
```
- 软文、广告、合作内容未声明
- 检测：是否有"推广"、"广告"标识
```

## 七、交叉验证规则

### 7.1 事实核查流程
```
对每个含数字的主张：
  1. 搜索该数字的原始来源
  2. 搜索该领域的权威数据（国家统计局、WHO等）
  3. 若多个来源数据差异>50% → 标记为"矛盾"
  4. 若差异<20% → 标记为"已验证"
```

### 7.2 因果主张检验（反事实推演）
```
对每个因果主张（A导致B）：
  1. 假设A不发生，B还会发生吗？
  2. 若B仍然发生 → 因果关系存疑
  3. 是否存在C同时导致A和B？（混杂变量）
  4. 时间顺序：A是否发生在B之前？
```

### 7.3 科学主张分级
| 等级 | 描述 | 验证要求 |
|------|------|---------|
| 共识 | 被多个独立研究反复证实 | 无需额外验证 |
| 有证据 | 有研究支持但尚有争议 | 需提供研究来源 |
| 初步 | 少数研究支持 | 需标注"初步研究" |
| 存疑 | 与主流科学矛盾 | 需提供推翻主流的证据 |
