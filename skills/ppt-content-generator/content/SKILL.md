# PPT内容生成器

## 技能概述

专业的PPT内容生成专家，能够根据主题自动生成结构化的大纲和详细内容填充，涵盖封面、目录、内容页、结尾页等完整PPT结构。支持中英文双语内容创作。

## 核心能力

- 根据主题生成完整PPT大纲
- 为每个页面生成专业文案内容
- 创建封面页、目录页、内容页、结尾页
- 支持中英文双语内容
- 根据受众调整语气和风格
- 生成演讲逐字稿
- 提炼关键词和要点
- 提供视觉设计建议

## 输入参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| topic | string | 是 | - | PPT主题 |
| subtopic | string | 否 | - | 副标题/关键词 |
| audience | string | 否 | 商务人士 | 目标受众 |
| tone | enum | 否 | professional | 语气风格：formal/casual/friendly/professional |
| language | enum | 否 | zh | 内容语言：zh/en/bilingual |
| page_count | number | 否 | 10 | 页数要求（5-50页） |
| style | enum | 否 | 商务 | PPT风格：商务/教育/科技/简约/创意 |

## 输出结构

```json
{
  "outline": ["PPT大纲结构数组"],
  "content": {"各页面详细内容对象"},
  "design_suggestions": ["设计建议数组"]
}
```

## 使用示例

**示例1：AI发展趋势PPT**
- 输入：生成一个关于AI发展趋势的PPT，10页，商务风格
- 输出：完整的PPT大纲和内容，包括封面《AI发展趋势》、目录、5个内容页（技术进展、应用场景、市场分析、未来预测、总结）、结尾页

**示例2：企业文化培训PPT**
- 输入：创建一个员工培训PPT，主题是企业文化
- 输出：包含企业愿景、核心价值观、团队精神、职业发展路径等内容的培训PPT结构

## 最佳实践

1. 明确PPT的使用场景和目标受众
2. 提供具体的主题和子主题
3. 说明期望的页数和风格
4. 指定是否需要中英双语

## 限制说明

- 不直接生成图片素材
- 不生成复杂的图表数据
- 不提供动画效果设计
