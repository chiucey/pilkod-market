# 摄影照片描述生成器

## 技能概述

本技能帮助摄影师为作品撰写吸引人的描述文字，适用于图虫、500px、Lofter、小红书等摄影平台。

## 工作流程

### 步骤 1：收集图片信息

首先，请用户提供：
- 照片主题/场景描述
- 摄影类型（风光/人文/人像/街拍/建筑/微距/静物等）
- 拍摄地点（如果适用）
- 拍摄时间/季节（如果适用）

### 步骤 2：确认用户偏好

**风格选择**（单选）：
| 风格 | 特点 | 适用场景 |
|------|------|----------|
| 诗意文艺 | 意境深远、富有想象力、善用比喻 | 艺术摄影、风光、情绪片 |
| 专业严谨 | 技术参数、客观描述、摄影术语 | 商业摄影、技术讨论 |
| 温暖随性 | 亲切自然、生活气息、轻松活泼 | 生活记录、人文纪实 |
| 简洁大气 | 短句有力、留白意境、重点突出 | 所有平台通用 |
| 故事叙事 | 讲述背景、传达情感、引人入胜 | 人文纪实、旅行摄影 |

**字数选择**（单选）：
| 长度 | 字数范围 | 适用场景 |
|------|----------|----------|
| 精简版 | 20-50字 | 快速发布、平台限制 |
| 标准版 | 50-100字 | 常规发布、图文匹配 |
| 详细版 | 100-200字 | 深度介绍、作品阐述 |
| 完整版 | 200-300字 | 作品集、专题介绍 |

### 步骤 3：生成描述

根据用户选择，结合照片内容，生成符合以下要求的描述：

**基本要求**：
- 语言优美流畅，避免语法错误
- 紧扣照片主题，突出核心亮点
- 融入情感表达，引发观者共鸣
- 自然融入摄影术语（如适用）

**平台适配**：
- 图虫：支持较长描述，可加入话题标签
- 小红书：适合故事性强的描述，可添加emoji
- 500px：简洁专业，可加入设备参数
- Lofter：文艺风格，诗意表达

**禁止内容**：
- 虚假夸大、不实描述
- 直接复制他人评价
- 敏感政治话题
- 抄袭侵权内容

### 步骤 4：输出结果

生成 3 个不同角度的描述方案，供用户选择或参考：

```
【方案一：诗意风格 · 标准版】
[描述文字1]

【方案二：故事风格 · 详细版】
[描述文字2]

【方案三：简洁风格 · 精简版】
[描述文字3]
```

## 快速参考

### 常见场景模板

**风光摄影**：
> [季节/时间]的[地点]，[光线描述]洒落，[主体]静静伫立，[意境表达]。[情感升华]

**人文纪实**：
> 在[地点]，我遇见了[人物/场景]。[故事背景]。[背后含义/思考]

**人像摄影**：
> [人物状态]的眼神里，藏着[情绪/故事]。[光影/构图特点]让这一刻[意义]

**建筑摄影**：
> [建筑名称/类型]的[线条/结构]，在[光线下/角度]呈现出[视觉效果]。[设计感/历史感]

**街拍摄影**：
> 市井的烟火气，[场景描述]。[决定性瞬间]。[人文观察]

### 摄影术语参考

- 光线：逆光、侧光、柔光、硬光、黄金时刻、蓝色时刻
- 构图：三分法、对角线、引导线、框架构图、留白
- 色彩：冷暖对比、莫兰迪色系、高级灰、低饱和
- 氛围：电影感、胶片感、梦幻、纪实、抽象

## 示例对话

**用户输入**：
> 一张黄昏时分在海边拍摄的照片，夕阳倒映在海面上，有几只海鸥飞过

**技能输出**：
```
【风格建议】
根据您的照片，我推荐以下风格：
- 诗意文艺：意境深远，适合艺术表达
- 温暖随性：自然亲切，记录美好瞬间
- 简洁大气：短句有力，突出画面美感

【生成结果 · 诗意文艺 · 标准版】
黄昏的海面被染成橘红色，夕阳如同一枚熟透的果实，缓缓沉入海的怀抱。几只海鸥掠过天际，划破这份静谧，也划破了我的思绪。此刻，时间仿佛凝固。

【生成结果 · 温暖随性 · 详细版】
终于等到了这个黄昏！
海边的风很轻，夕阳刚好落在海平面上，把整片海面都点亮了。
看到那几只海鸥飞过的时候，赶紧按下了快门。
这就是我想要的画面——有光，有生命，有远方。

【生成结果 · 简洁大气 · 精简版】
海天之间，夕阳作别。
飞鸟掠影，岁月无声。
```

## 注意事项

1. **图片理解**：尽可能从用户描述中提取关键信息进行创作
2. **用户修正**：生成后询问是否需要调整风格、字数或角度
3. **平台适配**：可根据目标平台调整表达方式和长度
4. **版权意识**：描述内容应为原创，避免抄袭他人文案
5. **情感真实**：鼓励真实情感表达，避免过度煽情或虚假描述

## 质量检查清单

生成描述后自检：
- [ ] 语言流畅，无病句错字
- [ ] 风格与用户选择一致
- [ ] 字数在约定范围内
- [ ] 与照片内容相关度高
- [ ] 无敏感或不当内容
- [ ] 具有可读性和吸引力
