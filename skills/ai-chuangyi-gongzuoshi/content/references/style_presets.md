# 风格预设详细说明

## 视频风格预设

### 1. 电影感短剧

**适用场景**
- 故事性强的短片
- 情感表达为主的内容
- 追求画面质感的作品

**技术参数**
| 参数 | 设置 |
|------|------|
| 比例 | 16:9 (1920x1080) |
| 色调 | 中性偏冷，灰色基调 |
| 对比度 | 中高对比 |
| 饱和度 | 自然饱和 |

**运镜特点**
- 平稳的相机运动
- 慢速推进/拉出
- 延迟跟随
- 大量使用特写

**后期风格**
- 轻度的 film grain
- 暗角效果
- 柔和的色彩分级
- 背景音乐：钢琴/弦乐

**提示词示例**
```
cinematic film look, anamorphic lens flare,
shallow depth of field, emotional lighting,
neutral color grade, cinematic atmosphere
```

---

### 2. 抖音/短视频风格

**适用场景**
- 快速传播的娱乐内容
- 信息密度高的内容
- 追求高互动率

**技术参数**
| 参数 | 设置 |
|------|------|
| 比例 | 9:16 (1080x1920) |
| 色调 | 鲜明饱和 |
| 对比度 | 高对比 |
| 饱和度 | 高饱和 |

**运镜特点**
- 快速切换
- 手持/运功效果
- 频繁的视角切换
- 动态转场

**后期风格**
- 快速剪辑节奏
- 字幕动画
- 特效叠加
- 背景音乐：流行/电子

**提示词示例**
```
vibrant colors, high contrast,
energetic mood, trending style,
mobile-optimized, engaging visuals
```

---

### 3. 赛博朋克风格

**适用场景**
- 科幻主题内容
- 未来都市场景
- 暗黑科技感

**技术参数**
| 参数 | 设置 |
|------|------|
| 比例 | 16:9 或 21:9 |
| 色调 | 霓虹紫/青/粉 |
| 对比度 | 极高对比 |
| 饱和度 | 中高饱和 |

**光效特点**
- 霓虹灯光
- 体积光/辉光
- 雨夜反射
- 激光/全息投影

**后期风格**
- 暗角和光晕
- 色彩分离
- 数字故障效果
- 背景音乐：电子/合成器

**提示词示例**
```
cyberpunk neon lights, rain-soaked streets,
volumetric fog, holographic projections,
futuristic cityscape, dark atmosphere,
purple and cyan color palette, rim lighting
```

## 3D风格预设

### 1. 低多边形（Low-Poly）

**适用场景**
- 手游/休闲游戏
- AR/VR应用
- 快速原型
- 简约风格项目

**技术参数**
| 参数 | 设置 |
|------|------|
| 面数范围 | 500-5000 |
| 贴图分辨率 | 256-512px |
| 材质类型 | 扁平着色/简约PBR |
| 风格参考 | 几何感强、色彩分明 |

**建模要点**
- 几何形状简化
- 避免复杂曲线
- 硬边为主
- 色彩分区清晰

**导出格式**
- GLB/GLTF（优先）
- FBX（兼容性）
- OBJ（简单模型）

---

### 2. 写实风格（Photorealistic）

**适用场景**
- 影视制作
- 广告产品展示
- 建筑可视化
- 高端游戏

**技术参数**
| 参数 | 设置 |
|------|------|
| 面数范围 | 50000+ |
| 贴图分辨率 | 2K-8K |
| 材质类型 | 完整PBR通道 |
| 渲染引擎 | 光线追踪/HDR |

**建模要点**
- 高精度拓扑
- 细分曲面
- 法线贴图细节
- 正确的UV展开

**PBR材质通道**
| 通道 | 说明 |
|------|------|
| Base Color | 基础颜色/反照率 |
| Normal | 法线贴图 |
| Roughness | 粗糙度 |
| Metallic | 金属度 |
| AO | 环境遮蔽 |
| Height | 高度/位移 |
| Emissive | 自发光 |

**渲染设置**
- 三点布光
- HDRI环境光
- 焦散效果
- 色彩分级

**导出格式**
- FBX（动画支持）
- BLEND（保留编辑）
- OBJ + MTL（简单兼容）

---

### 3. 卡通/风格化风格

**适用场景**
- 动画制作
- IP形象设计
- 儿童内容
- 插画向渲染

**技术参数**
| 参数 | 设置 |
|------|------|
| 面数范围 | 5000-20000 |
| 贴图分辨率 | 1K-2K |
| 材质类型 | 卡通着色/Toon Shader |
| 风格参考 | 色彩鲜明、轮廓清晰 |

**建模要点**
- 简化的解剖结构
- 夸张的比例
- 清晰的轮廓线
- 风格化的细节

**着色器特点**
- 边缘光
- 渐变阴影
- 高饱和色彩
- 卡通描边

**导出格式**
- GLB/GLTF（Web/游戏）
- FBX（动画）
- PSK/PSA（Unreal）

## 混合风格指南

### 视频+3D混合

| 组合 | 效果 | 应用 |
|------|------|------|
| 电影感 + 写实3D | 无缝融合 | 高端产品 |
| 赛博朋克 + 低多边形 | 对比冲击 | 创意内容 |
| 抖音风格 + 卡通3D | 轻松活泼 | 品牌IP |

### 统一性检查

1. **色调统一**：确保所有素材使用相同的色彩方案
2. **光照一致**：统一光源方向和色温
3. **比例协调**：视频与3D物体比例正确
4. **风格匹配**：视觉风格贯穿始终

---

## 风格选择决策树

```
项目类型判断
│
├─ 视频为主
│   ├─ 高端/电影感 → 电影感短剧风格
│   ├─ 快节奏传播 → 抖音/短视频风格
│   └─ 科幻/未来 → 赛博朋克风格
│
└─ 3D为主
    ├─ 游戏/移动 → 低多边形
    ├─ 影视/广告 → 写实风格
    └─ 动画/IP → 卡通风格
```
