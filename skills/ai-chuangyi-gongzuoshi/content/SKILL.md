# AI创意工作室

端到端AI内容创作系统，整合视频制作与3D建模。

## 核心能力

| 模块 | 功能 | 产出 |
|------|------|------|
| 剧本解析 | 分析剧本或设计需求 | 场景列表、人物设定 |
| 分镜/模型设计 | 镜头脚本或3D规格 | 分镜表、模型参数 |
| 素材生成 | 场景图像或3D模型 | 素材资产 |
| AIGC视频 | 图像+文字→动态视频 | 视频片段 |
| 场景渲染 | 光影/粒子/特效 | 渲染效果 |
| 后期剪辑 | 拼接、音效、配乐 | 完整作品 |

## 工作流程

### 阶段1：输入解析

**决策分支：根据输入类型选择处理路径**

```
输入类型判断：
├── 剧本/脚本 → 视频类处理（见A）
├── 概念描述/参考图 → 3D类处理（见B）
└── 混合需求 → 并行处理
```

**A. 视频类：剧本解析**
```
输入：剧本文本
↓
输出：
├── 场景列表（时间、位置、氛围）
├── 人物列表（外貌、性格、服装）
├── 情绪曲线
└── 剧情节奏分析
```

**B. 3D类：概念解析**
```
输入：设计描述或参考图
↓
输出：
├── 模型类型（角色/物体/场景/建筑）
├── 复杂度等级（低/中/高/写实）
├── 风格方向（写实/卡通/科幻/奇幻）
└── 用途规格
```

### 阶段2：设计规划

**A. 分镜脚本（视频）**
```
每个场景包含：
├── 镜头类型（特写/中景/全景）
├── 运镜方式（推/拉/摇/移/跟）
├── 场景描述（视觉元素）
├── 人物动作/对白
├── 运镜提示词
└── 建议风格
```

**B. 3D模型规格**
```
设计文档：
├── 多边形预算
├── 拓扑结构要求
├── UV展开方案
├── 材质通道规划
└── 渲染风格定位
```

### 阶段3：素材生成

**A. 图像生成（视频）**
```json
{
  "aspect_ratio": "9:16(竖屏) 或 16:9(横屏)",
  "resolution": "2K",
  "quality": "AIGC, cinematic, high quality"
}
```

**B. 3D模型构建**
```
流程：几何体创建 → 细节添加 → 拓扑优化 → UV展开
```

### 阶段4：AIGC视频制作

**图像 + 运镜提示词 → 动态视频**

**生成规则：**
1. 每个视频片段必须基于剧本内容
2. 运镜提示词必须与场景动作匹配
3. 品质标准：1080P（最低768P），6-10秒

**示例模板：**
```
剧本："男主惊讶地看向窗外"
图像：咖啡馆窗边场景
提示词："slow camera pan right following the man's gaze,
        subtle dust particles floating in sunbeams,
        cinematic depth of field, emotional tension"
```

### 阶段5：场景渲染（可选）

| 效果类型 | 关键词 | 适用场景 |
|---------|-------|---------|
| 体积光 | volumetric light, god rays | 窗户、灯光 |
| 粒子系统 | dust particles, snowflakes | 氛围 |
| 天气效果 | rain, fog, mist, wind | 环境 |
| 散景 | bokeh, shallow DOF | 人像 |
| 动态模糊 | motion blur, speed lines | 动作 |
| 霓虹光效 | neon glow, rim light | 赛博朋克 |

### 阶段6：后期剪辑

**视频类**
```
1. 片段组织 → 按时间线排列
2. 转场效果 → 叠化/推拉/黑场
3. 音效配乐 → 背景音乐+氛围音
4. 字幕特效 → 标题/对白字幕
5. 最终输出 → MP4
```

**3D类**
```
1. 格式导出 → GLB/GLTF/FBX/OBJ
2. 贴图打包 → PNG/TGA/EXR
3. 多角度渲染 → 展示图集
```

## 风格预设

### 视频风格
| 风格 | 比例 | 色调 | 运镜 |
|------|------|------|------|
| 电影感 | 16:9 | 中性偏冷 | 平稳 |
| 抖音风格 | 9:16 | 鲜明饱和 | 快速 |
| 赛博朋克 | 16:9 | 霓虹紫/青/粉 | 流畅 |

### 3D风格
| 风格 | 面数 | 特点 | 用途 |
|------|------|------|------|
| 低多边形 | 500-5000 | 几何感强 | 手游、AR/VR |
| 写实风格 | 50000+ | 照片级真实 | 电影、广告 |
| 卡通风格 | 5000-20000 | 色彩鲜明 | 动画、IP |

## 触发场景

当用户要求以下内容时触发：
- 根据剧本生成AI短剧
- 图像+文字提示词生成视频
- 3D模型创建与渲染
- 产品/建筑可视化
- 角色设计与动画素材
- 故事可视化/剧本演示
- 一站式视频+3D创作

## 限制

- 单次视频总时长建议不超过2分钟
- 3D模型根据用途选择合适面数
- 复杂特效场景可能需要多次迭代
- 建议正式发布前人工审核
