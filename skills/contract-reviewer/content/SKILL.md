# 合同智能审阅系统

## 概述

本系统提供专业的合同智能审阅服务，采用**批注式审阅**方式，仅添加批注而不修改原文，保持合同原始格式不变。通过三层审阅模型（基础层/业务层/法律层）进行全面分析，并根据合同类型自动应用相应的审阅标准。

---

## 核心能力

### 审阅能力

#### 批注式审阅
- 仅添加批注，不修改原文
- 保持合同原始格式完整
- 批注包含风险等级标注（🔴高风险/🟡中风险/🟢低风险）

#### 三层审阅模型

**基础层（文本质量）**
- 数值、日期、术语准确性检查
- 编号一致性验证
- 表达清晰度评估

**业务层（商业条款）**
- 合同目的与标的物
- 期限与有效期
- 价格与付款条款
- 履行程序
- 权利与义务

**法律层（法律条款）**
- 生效与解除条件
- 违约责任
- 争议解决机制
- 保密条款
- 知识产权归属

#### 合同类型识别
系统自动识别以下合同类型并应用相应审阅标准：
- 劳动合同
- 销售合同
- 服务合同
- 租赁合同
- 采购合同
- 合作协议

#### 风险分级评估
| 风险等级 | 标识 | 说明 |
|---------|------|------|
| 高风险 | 🔴 | 需要特别关注，可能导致重大损失 |
| 中风险 | 🟡 | 需要注意，可能影响合同履行 |
| 低风险 | 🟢 | 常规条款，建议优化 |

风险分级通过审阅人名字编码实现，例如：`reviewer-H`（高风险）、`reviewer-M`（中风险）、`reviewer-L`（低风险）

#### 多语言支持
- 自动检测合同语言（中文/英文）
- 输出内容自动适配相应语言
- 支持中英文双语批注

## 输出能力

### 1. 批注版合同（.docx）
- 包含风险等级批注的合同文档
- 保持原始合同格式不变
- 批注采用颜色编码区分风险等级

### 2. 合同概要（.docx）
结构化表格形式，包含：
| 项目 | 内容 |
|------|------|
| 合同基本信息 | 合同名称、编号、当事人信息 |
| 合同类型 | 自动识别的合同类型 |
| 主要条款摘要 | 标的、期限、价格等核心要素 |
| 风险分布 | 各层级风险点统计 |

### 3. 综合审核意见（.docx）
两段式响应结构：
- **第一段：总体评价** - 合同整体评估、风险概述
- **第二段：具体建议** - 分层级的详细建议

### 4. 业务流程图（Mermaid + PNG）
使用 Mermaid 语法生成可视化的业务交易流程图，包括：
- 合同签订流程
- 权利义务关系
- 资金流向
- 关键节点标注

## 适用场景

### 劳动合同审阅要点
- 试用期条款合规性

- 社会保险缴纳
- 竞业限制条款

- 验收标准与程序
- 知识产权归属
- 保密义务

## 使用流程

### 输入要求
**文件格式要求**
- 推荐格式：.docx（Word 2007 及以上版本）
- 兼容格式：.doc（Word 97-2003 版本，将自动转换为 .docx）
- 系统自动检测文件格式

### 处理流程

```
上传合同文件
    ↓
文件格式检测与转换（如需要）
    ↓
解包合同文档（docx → XML）
    ↓
智能分析合同文本
    ↓
合同类型自动识别
    ↓
执行三层审阅（基础/业务/法律）
    ↓
根据合同类型加载特定审阅要点
    ↓
生成风险评估报告
    ↓
添加批注到文档
    ↓
生成合同概要
    ↓
生成综合审核意见
    ↓
生成业务流程图（Mermaid → PNG）
    ↓
重新打包为 .docx
    ↓
输出结果
```

### 输出结果
1. **批注版合同** - 包含风险等级批注的合同文档
2. **审核报告** - 详细的审阅过程记录
3. **合同概要** - 结构化的合同内容概要
4. **综合审核意见** - 两段式的专业审核意见
5. **业务流程图** - 可视化的业务交易流程（PNG格式）

## 技术实现

### 文档处理
- 使用 python-docx 库处理 Word 文档
- 解析 XML 结构提取文本内容
- 保持原有格式的批注添加

### 流程图生成
- 使用 Mermaid 语法描述业务流程
- 通过 mermaid-cli 或等效工具渲染为 PNG
- 支持自定义样式和主题

### 多语言支持
- 文本语言检测（中文/英文）
- 输出内容语言自动适配
- 批注语言与合同原文匹配

---

## 重要特点

1. **原文不变** - 所有风险点通过批注形式标注，保持合同原始内容不变
2. **风险等级明确** - 通过颜色和审阅人名字编码区分风险等级
3. **类型适配** - 根据合同类型自动应用相应的审阅标准
4. **结构化输出** - 生成多维度、结构化的审阅结果
5. **双语支持** - 中英文合同均可处理，输出语言自动适配

---

## 注意事项

1. 合同审阅意见仅供参考，**不构成正式法律意见**
2. 对于涉及重大金额、复杂交易或特殊行业的合同，**建议咨询专业律师**
3. 注意合同的整体平衡，避免因追求单方面利益导致合同无法达成
4. 本系统仅为辅助工具，最终决策应结合实际情况做出
