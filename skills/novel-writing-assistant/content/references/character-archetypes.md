# 网络小说人物原型库

## 主角类型

### 1. 废柴逆袭型

**特征**：
- 初始身份低微，被人看不起
- 拥有隐藏天赋或金手指
- 性格坚韧，有韧性
- 成长路径清晰

**经典模板**：
```
起点：被退婚/被嘲讽/被背叛
转折：获得金手指
中期：展露头角，遭遇打压
高潮：绝地反击，一战成名
结局：功成名就，抱得美人
```

### 2. 隐藏大佬型

**特征**：
- 表面普通，实则深藏不露
- 不喜欢张扬，低调行事
- 关键时刻力挽狂澜
- 身份层层揭露

**经典模板**：
```
身份设定：退休兵王/隐世家族/上古传承
日常：普通生活，暗中观察
危机：身边的人受欺负
爆发：展露真正实力
震惊：全场目瞪口呆
```

### 3. 重生逆袭型

**特征**：
- 带着前世记忆重生
- 知道未来走向
- 弥补前世遗憾
- 避开前世坑

**经典模板**：
```
前世：错过机会/被背叛/遗憾收场
重生：回到关键节点
优势：知道未来信息
布局：改变命运
复仇/崛起：双线并进
```

## 女主类型

### 1. 高冷御姐型

**特征**：
- 外表高冷，内心柔软
- 身份尊贵，能力出众
- 对主角态度逐渐软化
- 有自己的骄傲和坚持

**描写要点**：
```
外貌：高挑、气质出众、冷艳
性格：独立、要强、不服输
变化：从冷漠→好奇→心动→沦陷
萌点：傲娇、口是心非
```

### 2. 软萌可爱型

**特征**：
- 天真无邪，单纯善良
- 对主角依赖信任
- 关键时刻勇敢成长
- 给人治愈感

**描写要点**：
```
外貌：小巧玲珑、娃娃脸、大眼睛
性格：温柔、体贴、善解人意
能力：可能有隐藏实力
萌点：天然呆、撒娇、吃货属性
```

### 3. 霸气女王型

**特征**：
- 气场强大，掌控全局
- 事业有成，女强人
- 对感情专一深情
- 保护主角的霸气

**描写要点**：
```
外貌：精致、气场全开、御姐范
性格：果断、强势、有担当
关系：平等对话，相互扶持
萌点：反差萌、偶尔小女人
```

## 反派类型

### 1. 家族大少型

**特征**：
- 出身豪门，目中无人
- 嫉妒主角，抢夺资源
- 有一定能力但不及主角
- 最终被主角打脸

### 2. 伪君子型

**特征**：
- 表面正人君子
- 背后阴险狡诈
- 善于伪装，欺骗主角
- 揭露时刻最解气

### 3. 天才竞争对手型

**特征**：
- 真有实力，不容小觑
- 与主角亦敌亦友
- 有自己的骄傲和底线
- 可能是最强对手

## 配角体系

### 功能型配角

```
财神：给主角送钱送资源
情报员：提供关键信息
工具人：推动剧情发展
见证者：增加场景真实感
```

### 成长型配角

```
小弟：跟着主角成长
师父：引导主角成长
前辈：激励主角进步
对手：迫使主角变强
```
