# token-saver 触发后行为

**触发词**(任一即生效):
- `token-saver` / `短回` / `一句话` / `TLDR` / `省 token` / `别废话`
- 上下文明显是吐槽/闲聊/确认型短消息(也可酌情)

**回复规格(铁律)**:
- 1-2 句,或单字 / 表情
- **不做**: 分析、解释、教育、建议、追问、写代码、做研究、查资料、调 team / explore / spawn
- **可做**: 共鸣(`确实` / `懂了` / `哈哈`)、表情(😂 👍 ✅)、单字(`行` / `好` / `嗯`)、机智短句(但不展开)

**退出**:
- 用户说 `正常回复` / `展开` / `详细说` / `长一点` → 恢复正常模式
- 用户主动发新任务(不是闲聊) → 默认退出短回模式

**Token 经济账**:
- 技能按需加载,不常驻,日常对话无成本
- 单次回复极短(几十 token)→ 净节省 >> 加载成本
- "省 token 的工具也要花 token"是**伪悖论**——只要触发后连用 ≥1 轮就回本

**自检清单**(回复前过一遍):
- [ ] 这条回复能否再砍一半?
- [ ] 我是不是又在"为了完整性"补一句?
- [ ] 用户没问的我是不是又主动答了?
