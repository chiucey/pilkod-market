# 网文写作大师

> 11规则+9题材适配，写出有人味的网文

## 功能介绍

涵盖网文写作全部底层规则和9大热门题材的专项适配。不管你写什么题材，这套规则让你的文字告别AI味、告别脸谱化、告别流水账。

## 适用场景

- 写任何题材的网文/网络小说
- 需要系统性的写作规则指导
- 文字有AI味想改善
- 想提升节奏感和可读性

## 11条硬规则

1. 对话与动作推进剧情（对话≥50%）
2. 润色去AI味
3. 精简描写（禁止形容词堆砌）
4. 祛AI味说人话
5. 冲突与爽点设计
6. 血肉之躯（告别工具人）
7. 人设锚定（防崩塌）
8. 修辞与文采
9. 开篇3秒钩人
10. 结尾必留钩子
11. 排版节奏（适配手机）

## 9大题材适配

- 都市爽文 · 耽美 · 种田文
- 古言 · 末世 · 系统文
- 升级流 · 仙侠 · 脑洞文

每个题材有独立的规则包和技巧包。

## 自查清单

写完自动过11项检查：对话占比、AI味检测、形容词密度、段落长度、章末钩子……

---

**使用方式**：告诉我你在写什么题材的网文，我会加载对应规则帮你创作或优化。
