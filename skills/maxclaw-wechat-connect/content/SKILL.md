# MaxClaw 微信连接技能

将 MaxClaw AI 助手通过 OpenClaw 生态接入个人微信，只需简单三步即可完成配置。

## 工作流程

### 第一步：安装 weixin-connect 技能

1. 打开 MaxClaw 网页端
2. 进入 **Skills 社区**
3. 搜索关键词：`weixin-connect`
4. 点击 **添加到技能库**

### 第二步：触发连接指令

在 MaxClaw 对话框中输入以下指令：

```
严格使用 /workspace/skills/weixin-connect/SKILL.md 里的 skill，给我连接个人微信。
```

**预期行为：**
- MaxClaw 会自动安装所需插件
- 系统会自动生成配对二维码
- 二维码会在半分钟内显示

**二维码查看方式：**
- 通过对话中的图片链接查看
- 或前往指定文件夹查看
- 如二维码未出现，重新部署 MaxClaw 即可

### 第三步：扫码配对

1. 在 **一分钟二维码有效期内** 完成扫码
2. 使用个人微信扫描配对二维码
3. 确认授权完成配对

## 配对成功后的功能

- MaxClaw 账号最多支持 **3 个微信号**同时部署
- 支持在微信中直接与 AI 助手对话
- 已打通微信、飞书、钉钉等主流 IM 渠道

## 故障排除

| 问题 | 解决方案 |
|------|----------|
| 二维码未显示 | 重新部署 MaxClaw |
| 扫码超时 | 在一分钟内完成扫码 |
| 配对失败 | 检查微信版本，确保已更新至最新 |
| 多账号需求 | MaxClaw 支持最多 3 个微信号 |

## 技术背景

MaxClaw 是 MiniMax 推出的 AI 智能体，依托 **OpenClaw 开源生态** 构建，为用户提供便捷的 AI 助手接入体验。
