# 技术交底书撰写技能

## 技能定位

本技能将技术文字材料转化为规范、完整、清晰的技术交底书文档，适用于专利申请、技术文档编制等场景。

## 工作流程

### 阶段1：材料阅读与理解

1. **完整阅读**用户提供的技术材料
2. **识别核心要素**：
   - 技术领域定位
   - 技术问题/背景
   - 现有技术及缺陷
   - 发明/技术方案核心内容
   - 关键创新点
   - 技术效果/优势
   - 实施方式

### 阶段2：材料充分性评估

**评估维度**：

| 评估项 | 必要程度 | 说明 |
|--------|----------|------|
| 技术问题明确性 | 必填 | 必须清晰描述要解决的技术问题 |
| 技术方案完整性 | 必填 | 包含实现方案的核心技术特征 |
| 创新点说明 | 必填 | 明确说明与现有技术的区别 |
| 实施方式描述 | 建议 | 提供至少一种具体实施方式 |
| 技术效果数据 | 建议 | 如有量化效果更佳 |

**评估结论**：
- **不充分**：返回《材料补充清单》，明确告知缺少哪些必要信息
- **基本充分**：可开始撰写，但标注可能需要用户补充的内容
- **充分**：具备完整撰写条件

### 阶段3：领域分析与关键信息识别

1. **技术领域判定**
   - 根据材料内容确定一级学科领域
   - 识别二级子领域
   - 标注相关技术分类

2. **创新点支撑分析**
   - 提取每个创新点的技术特征
   - 识别支撑创新点的关键技术信息
   - 分析技术特征之间的关联关系

3. **关键信息提炼**
   - 核心技术特征清单
   - 关键技术参数/指标
   - 核心实施步骤
   - 技术边界条件

### 阶段4：技术交底书撰写

**文档结构规范**：

```
【技术交底书】

一、发明名称
[简洁明了的技术名称]

二、技术领域
[所属技术领域及相关应用场景]

三、背景技术
3.1 现有技术现状
[详细描述相关现有技术]
3.2 现有技术的不足
[分析存在的问题或缺陷]

四、发明/技术方案要解决的技术问题
[清晰、客观地描述要解决的技术问题]

五、发明/技术方案的核心内容
5.1 总体技术方案
[完整的技术方案描述]
5.2 关键技术特征
[核心技术特征的详细描述]
5.3 技术方案流程/结构
[流程步骤或系统结构]

六、发明的关键技术特征详细描述
[对每个关键技术特征进行详细说明]

七、技术效果
7.1 预期达到的技术效果
[定性和定量描述]
7.2 技术优势
[相比现有技术的优势]

八、实施方式
8.1 优选实施方式
[具体实施例]
8.2 具体实施例
[详细实施步骤]

九、附图说明（如适用）
[描述相关附图内容]

十、其它需要说明的事项
```

**文风要求**：
- 客观、专业、严谨
- 使用技术术语准确描述
- 避免主观评价和文学性描述
- 结构清晰，层次分明
- 逻辑连贯，表述准确

### 阶段5：质量评估与迭代修改

**评估指标体系**：

| 评估维度 | 指标 | 目标值 | 评估方法 |
|----------|------|--------|----------|
| 完成度 | 内容完整性 | ≥95% | 检查各章节是否完整，关键信息是否覆盖 |
| 清晰度 | 表述清晰性 | ≥90% | 评估语言表达是否准确、无歧义 |
| 结构规范性 | 格式符合度 | 100% | 对照标准模板检查 |
| 逻辑连贯性 | 内部一致性 | 100% | 检查前后表述是否一致 |
| 技术准确性 | 专业术语正确性 | 100% | 核验技术术语使用 |

**评估方法**：
1. **自评检查**：逐项对照评估指标打分
2. **问题识别**：列出不达标项及具体问题
3. **迭代修改**：针对问题进行优化
4. **复评确认**：直至所有指标达标

**迭代终止条件**：
- 完成度 ≥ 95% 且
- 清晰度 ≥ 90% 且
- 其他指标均达到目标值

### 阶段6：输出交付

1. **最终文档**：完整的技术交底书
2. **质量报告**：各维度评估结果
3. **补充建议**（如有）：建议用户补充的材料信息

## 输出格式

### 主要输出

1. **技术交底书正文**：Markdown格式的完整文档
2. **质量评估报告**：包含各维度评分和改进记录

### 补充说明

如发现材料存在不足，在输出交底书的同时，输出：

```
【材料补充建议】
以下信息建议补充以提升交底书质量：
1. [具体补充项及理由]
2. ...
```

## 适用场景

- 专利申请前的技术交底书撰写
- 技术方案文档化整理
- 研发成果技术文档编制
- 技术合作项目的技术说明撰写

## 注意事项

1. 本技能不生成插图/附图，仅提供文字描述
2. 如涉及复杂数据结构，建议用户同时提供相关资料
3. 对于专业性极强的领域，可能需要用户提供行业术语对照表
4. 交底书完成后，建议用户请技术专家进行最终审核
