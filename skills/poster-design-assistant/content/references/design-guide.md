## 电商促销海报标准

### 双十一/618大促海报

```
【基础规格】
尺寸: 750x750px（方形主图）/ 750x350px（横幅）
分辨率: 72dpi
色彩模式: RGB

【配色方案】
主色: #FF4444（促销红）- 60%
辅助色: #FF8800（活力橙）- 25%
点缀色: #FFD700（金色）- 15%

【字体规范】
主标题: 思源黑体 Bold 72px
副标题: 思源黑体 Medium 48px
价格: Bebas Neue 96px
正文: 思源黑体 Regular 28px

【布局结构】
安全边距: 40px
主视觉区: 上方40%
信息区: 下方60%
价格标签: 右下角突出显示

【元素清单】
✓ 促销标签（限时/秒杀/爆款）
✓ 价格对比（原价划线价）
✓ 倒计时元素
✓ 主推商品图
✓ 品牌LOGO
```

## 社交媒体封面标准

### 微信公众号封面

```
【基础规格】
尺寸: 900x383px（封面图）/ 200x200px（头像）
分辨率: 72dpi

【布局要求】
- 核心信息集中在中央区域（安全区）
- 避免边缘放重要内容
- 考虑移动端竖屏显示效果

【标题位置】
- 主标题: 画面中央偏上
- 副标题: 主标题下方20-30px
- LOGO: 右下角或左下角
```

### 小红书封面

```
【基础规格】
尺寸: 1242x1660px（3:4竖版）/ 1242x930px（4:3横版）
分辨率: 72dpi

【配色方案】
高点击率配色:
- 马卡龙色系: #FFB6C1 + #E6E6FA + #98FB98
- 莫兰迪色系: #B5C4B1 + #D4A59A + #E8D5C4
- 电影感色调: #2C3E50 + #E74C3C + #F39C12

【字体规范】
主标题: 思源黑体 Bold 72px（白色描边）
副标题: 思源黑体 Medium 40px

【布局公式】
封面 = 高质量图 + 大字标题 + 关键词标签
- 图片占封面60-70%
- 标题字号≥60px
- 留白充足，呼吸感强
```

### 抖音/快手封面

```
【基础规格】
尺寸: 1080x1920px（9:16竖版）
分辨率: 72dpi

【布局要求】
- 核心内容在中央80%区域
- 上下留边≥100px
- 标题控制在画面上半部分

【字体规范】
主标题: 思源黑体 Bold 80-100px
副标题: 思源黑体 Medium 48px
标签: 思源黑体 Bold 36px
```

## 设计软件适配参数

### Photoshop (PS)

```
【新建文档设置】
文件 → 新建
预设: 自定
宽度/高度: 根据需求
分辨率: 72（屏幕）/ 300（印刷）
颜色模式: RGB（屏幕）/ CMYK（印刷）
背景内容: 透明或白色

【常用快捷键】
Ctrl+N: 新建文档
Ctrl+R: 显示标尺
Ctrl+; : 显示参考线
Ctrl+T: 自由变换
Ctrl+J: 复制图层
Ctrl+E: 合并图层
Ctrl+Shift+U: 去色
```

```
【新建文档设置】

画板尺寸: 根据需求
分辨率: 72（屏幕）

【常用快捷键】
Ctrl+N: 新建文档
```
