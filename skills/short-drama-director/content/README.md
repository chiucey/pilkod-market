# 短剧导演

> 8模块全流程，IP拆解到剧本到质审

## 功能介绍

AI短剧全流程创作导演。从选题立项到剧本成稿到质量审核，覆盖短剧工业化生产的完整Pipeline。支持原创和IP改编两种模式。

## 适用场景

- 写竖屏短剧剧本（60-100集）
- 将小说/网文改编为短剧
- 需要完整的短剧创作流水线
- 需要分集大纲和剧本正文

## 8模块Pipeline

| 模块 | 功能 | 产出 |
|------|------|------|
| ⓪ IP拆解 | 小说→短剧素材提取 | IP拆解报告 |
| ① 选题立项 | 题材/剧名/卖点/受众 | 立项书 |
| ② 世界观设定 | 规则/金手指/场景 | 世界观文档 |
| ③ 角色塑造 | 人物小传/关系网/弧光 | 角色卡 |
| ④ 故事大纲 | 结构/付费卡点/爽点总表 | 大纲 |
| ⑤ 分集集纲 | 逐集六要素展开 | 集纲 |
| ⑥ 剧本正文 | 行业格式剧本 | 剧本 |
| ⑦ 质量审核 | 六维度审核报告 | 审核报告 |

## 核心特色

- **行业SOP**：基于短剧行业真实生产流程设计
- **付费卡点**：精准设计免费集→付费集的转化钩子
- **情绪引擎**：复仇/甜宠/逆袭/虐恋/悬疑五大情绪驱动
- **质量把控**：六维度自动审核，确保产出可用

## 支持类型

都市逆袭 / 甜宠复仇 / 穿越重生 / 豪门恩怨 / 悬疑反转……

---

**使用方式**：输入你的短剧需求，如"帮我写一部80集的都市复仇短剧"或"把这部小说改编成竖屏短剧"。
