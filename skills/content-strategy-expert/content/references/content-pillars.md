# 内容支柱设计指南

## 什么是内容支柱？

内容支柱是品牌内容战略的核心主题维度，通常 3–5 个，确保内容的一致性和多样性。

---

## 内容支柱设计框架

### Step 1：品牌定位矩阵

| 维度 | 问题 | 品牌答案 |
|------|------|---------|
| 是什么 | 我们提供什么产品/服务？ | |
| 为谁 | 目标客户是谁？ | |
| 为什么 | 为什么我们比竞争对手更好？ | |
| 价值观 | 我们坚守什么核心价值？ | |

### Step 2：内容支柱类型

```
支柱类型
  ├─ 教育型（How-to / 知识科普）
  │   示例：「如何用 3 步做好内容策略」
  ├─ 娱乐型（故事 / 幽默 / 情感共鸣）
  │   示例：「我们走过的那些创业弯路」
  ├─ 启发型（行业洞察 / 趋势预测）
  │   示例：「2026 年内容营销的 5 大趋势」
  ├─ 转化型（产品 / 案例 / 促销）
  │   示例：「客户使用我们后增长了 300%」
  └─ 互动型（UGC / 投票 / 话题讨论）
      示例：「你认为 XX 最重要的是什么？」
```

### Step 3：支柱配比建议

| 场景 | 教育 | 娱乐 | 启发 | 转化 | 互动 |
|------|------|------|------|------|------|
| 新品牌建立信任 | 40% | 20% | 20% | 10% | 10% |
| 成熟品牌维持热度 | 25% | 25% | 20% | 20% | 10% |
| 活动/促销期 | 15% | 20% | 15% | 40% | 10% |
| 社区建设期 | 20% | 20% | 15% | 10% | 35% |

## 行业内容支柱示例

### B2B SaaS 品牌
1. **产品教育** — 功能讲解、使用技巧、最佳实践
2. **行业洞察** — 数据报告、趋势分析、白皮书
3. **客户成功** — 案例研究、ROI 故事、用户证言
4. **团队文化** — 公司故事、员工访谈、价值观展示
5. **社区互动** — AMA、调查问卷、用户共创

### 消费品品牌（DTC）
1. **生活方式** — 产品使用场景、美学内容
2. **产品故事** — 原料/工艺/设计背后的故事
3. **用户共创** — 买家评测、真实使用照片
4. **教育科普** — 类目知识、使用教程
5. **品牌价值** — 可持续发展、社会责任

### 个人 IP / 知识付费
1. **干货分享** — 方法论、工具、资源
2. **个人故事** — 经历、失败、成长
3. **行业观察** — 点评热点、趋势判断
4. **产品/课程** — 付费内容预告、学员反馈
5. **互动答疑** — Q&A、留言精选
