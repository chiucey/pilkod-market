# 各平台内容格式规范

## 微信公众号

| 要素 | 规范 |
|------|------|
| 标题 | ≤26 字，含情绪词/数字/悬念 |
| 开头 | ≤50 字，直击痛点或反常识开场 |
| 正文长度 | 800–3000 字（服务号建议 1000–2000）|
| 段落 | 每段 ≤5 行，留白充足 |
| 图片 | 首图 900×500px，正文每 300 字一张配图 |
| 行动号召 | 结尾一句话号召：「点击阅读原文」「分享给需要的朋友」 |
| 话题标签 | 不适用（用超链接代替）|
| 发布频率 | 服务号 4 次/月，订阅号 1–2 次/天 |

**黄金标题公式：**
- 「X个让你...的秘密（大部分人不知道）」
- 「为什么...的人，最后都...」
- 「我用了X年才明白：...」

## 小红书

| 要素 | 规范 |
|------|------|
| 标题 | ≤20 字，含痛点/情绪词/利益点，禁止过度夸张 |
| 正文长度 | 300–1000 字，建议 500–700 字 |
| 段落 | 每段 2–3 行，多用换行和 emoji 分隔 |
| 图片 | 首图 3:4 竖版，建议 9 张组图，首图文案 ≤10 字 |
| 话题标签 | 5–10 个，1–2 个大流量词 + 3–5 个精准词 + 2 个品牌词 |
| 行动号召 | 「收藏备用」「点赞支持我」「评论你的经历」 |
| 发布频率 | 建议 1–3 次/天，黄金时间：7–9 点、12–13 点、21–23 点 |

**爆款结构：**
```
钩子（提出问题/场景代入）
↓
共鸣（我也遇到过）
↓
解决方案（干货 3–5 点）
↓
结尾号召（互动引导）
```

## 抖音 / 视频号

| 要素 | 规范 |
|------|------|
| 时长 | 抖音：15s/60s/3min；视频号：≤30min |
| 比例 | 9:16 竖版（抖音），1:1 或 16:9 也可（视频号）|
| 前3秒 | 必须有钩子：冲突/悬念/反常识/直接说结论 |
| 标题/文案 | ≤30 字，含关键词 |
| 话题 | 3–5 个相关话题标签 |
| 字幕 | 必须有字幕，字体大小清晰可读 |
| 发布频率 | 每天 1–3 条，避免「断更」超过 3 天 |

**脚本四段式结构：**
```
1. 钩子（0–3s）：「99%的人不知道...」/ 展示结果
2. 冲突（3–15s）：放大问题或制造期待
3. 解决（15–50s）：核心价值/步骤/干货
4. 行动（最后3s）：「关注我，每天分享...」
```

## LinkedIn / 职场 B2B

| 要素 | 规范 |
|------|------|
| 帖子长度 | 150–300 字（原生帖），长文 800–1500 字 |
| 开头 | 第 1 行必须 ≤140 字且有冲击力（「展开」前可见）|
| 语调 | 专业、有观点、数据支撑 |
| 格式 | 大量空行、项目符号、短段落 |
| 图片/视频 | 有图比无图互动高 98% |
| 话题标签 | 3–5 个，选择 1 万–50 万粉丝规模的标签 |
| 发布频率 | 3–5 次/周，工作日上午 8–10 点最佳 |

## 博客 / SEO 长文

| 要素 | 规范 |
|------|------|
| 字数 | 1500–4000 字（取决于竞争激烈度）|
| H1 | 仅 1 个，含主关键词，≤60 字 |
| H2/H3 | 层次清晰，H2 含相关关键词 |
| 关键词密度 | 1–2%（不要堆砌）|
| 元描述 | ≤160 字，含主关键词和价值主张 |
| 内链 | 每 500 字 1–2 个内链 |
| 外链 | 2–3 个权威外链 |
| 图片 ALT | 描述性文字 + 关键词 |
| URL | 简短、含关键词，使用连字符 |
| 发布后 | 提交 sitemap，分发到社媒 |

## 播客

| 要素 | 规范 |
|------|------|
| 时长 | 新节目建议 20–40 分钟；成熟节目可到 60+ 分钟 |
| 结构 | 开场（1–2min）→ 主题引入 → 正文（分 3–5 段）→ 总结 → 号召行动 |
| 采访提纲 | 5–7 个核心问题 + 3–5 个追问备用 |
| 封面图 | 1400×1400px，文字清晰，人脸突出 |
| 简介 | ≤200 字，含关键词，说明听众能获得什么 |
| 发布频率 | 周更（建议）或双周更 |
| 分发渠道 | 小宇宙、喜马拉雅、苹果播客、Spotify |
