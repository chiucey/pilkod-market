# 宗教文化影响分析

## 基督教民主主义

### 天主教传统 (拉丁美洲、东欧)
- 社会教义影响政策取向
- 教会与国家关系历史张力
- 宗教身份与政治身份交织
- 教宗声音的政治影响
- 对社会议题(堕胎、同性恋)的保守立场

**代表领导人行为模式**:
- 杜特尔特(菲律宾)：天主教背景但实际政策矛盾
- 波兰领导人：高度宗教保守主义
- 巴西领导人：天主教名义支持者

### 新教传统 (美国、北欧)
- 个人责任与自助精神
- 政教分离原则
- 福音派政治影响力(美国)
- 社会福利的宗教动力

**代表领导人行为模式**:
- 特朗普：福音派核心支持者
- 北欧社民党：基督教民主传统+社会民主主义

### 东正教传统 (俄罗斯、希腊)
- 与国家权力的历史结合
- 民族身份与宗教身份合一
- 教会对政治的影响力
- 反西方意识形态资源

**代表领导人行为模式**:
- 普京：利用东正教强化民族主义
- 俄罗斯外交政策的宗教维度
