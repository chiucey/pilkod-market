## PubMed检索式构建指南

### 布尔运算符使用

- `AND`: 两个条件都必须满足
- `OR`: 满足任一条件即可
- `NOT`: 排除特定条件

### 优先级控制

使用圆括号 `()` 控制优先级，例如：
```
(heart failure) AND (biomarker OR marker)
```

### 字段限制

| 字段标签 | 说明 |
|----------|------|
| [Title] | 仅搜索标题 |
| [Abstract] | 仅搜索摘要 |
| [MeSH Terms] | 搜索MeSH词 |
| [Author] | 搜索作者 |
| [Publication Date] | 搜索出版日期 |

### 示例检索式

1. **药物+疾病组合**
   ```
   (aspirin[Title/Abstract]) AND (cardiovascular[Title/Abstract])
   ```

2. **技术领域+方法**
   ```
   (DNA sequencing[MeSH Terms]) AND (nanopore[Title/Abstract])
   ```

3. **复杂组合**
   ```
   ((cancer[Title]) AND (immunotherapy[Title])) OR ((tumor[Abstract]) AND (checkpoint inhibitor[Abstract]))
   ```

## 相关性评估标准

### 评估维度

1. **技术领域匹配度** (1-5分)
   - 1: 完全不相关
   - 3: 部分相关
   - 5: 完全匹配

2. **关键技术手段重叠度** (1-5分)
   - 评估文献公开的技术特征与本申请关键技术手段的相似程度

3. **发明点覆盖度** (1-5分)
   - 评估文献是否公开了本申请的核心发明点

### 筛选阈值

- 总分 >= 12分：高度相关，纳入前5
- 总分 8-11分：中等相关，可能纳入
- 总分 < 8分：低相关，排除
