# 专利现有技术文献检索与综述

## 工作流程

### 阶段1：专利文档处理

1. **读取专利PDF文件**
   - 使用 `extract_pdfs_full_content` 工具提取PDF文本内容
   - 不需要OCR，仅提取文本信息

2. **分析专利内容**
   - 识别技术领域（至少1个）
   - 提取关键技术手段（2-3个核心特征）
   - 识别发明目的和技术效果

### 阶段2：检索策略构建

1. **技术领域提取**
   - 从专利摘要和权利要求中识别主要技术领域
   - 使用MeSH术语或相关关键词

2. **关键技术手段识别**
   - 从权利要求书中提取2-3个核心技术特征
   - 每个特征使用关键词或短语表达

3. **布尔检索式构建**
   ```
   (技术领域) AND (关键技术手段1) OR (关键技术手段2) OR (关键技术手段3)
   ```
   - 使用PubMed支持的布尔运算符：AND, OR, NOT
   - 适当使用括号控制优先级

4. **检索策略文档**
   - 保存检索式到 `references/search_strategy.md`
   - 记录：检索日期、技术领域、检索式、预期结果

### 阶段3：PubMed检索

1. **执行检索**
   - 使用 PubMed E-utilities API 或网页搜索
   - 请求返回结果按相关性排序
   - 获取前20篇检索结果

2. **结果处理**
   - 解析返回的文献元数据（标题、摘要、作者、期刊、发表年份）
   - 存储检索结果用于后续分析

### 阶段4：相关性筛选

1. **初步筛选**
   - 按相关性排序取前20篇

2. **深度相关性评估**
   - 使用LLM分析每篇文献与专利技术方案的相关性
   - 评估标准：
     - 技术方案相似度
     - 关键技术手段重叠度
     - 技术领域匹配度
     - 发明点覆盖程度

3. **最终筛选**
   - 从20篇中筛选出最相关的5篇
   - 记录筛选理由

### 阶段5：文献综述生成

1. **现有技术概况**
   - 综述与本申请关键技术手段相关的现有技术
   - 按技术领域分组描述

2. **文献综述**
   - 简要概述5篇最相关文献的具体内容
   - 每篇文献说明：
     - 公开的技术方案
     - 与本申请的关联性
     - 关键技术点的相似/差异

3. **报告结论**
   - 分析现有技术与本申请的关系
   - 明确本申请的核心发明点
   - 指出相对于现有技术的改进

### 阶段6：报告输出

1. **生成Word报告**
   - 使用 `minimax-docx` skill 将报告转换为Word格式
   - 报告结构：
     - 标题
     - 一、现有技术概况
     - 二、文献综述
     - 三、报告结论
   - 保存到 `outputs/patent_prior_art_report_[日期].docx`

### 阶段7：检索策略回顾与更新

1. **检索过程回顾**
   - 分析检索结果的覆盖度和准确性
   - 识别遗漏的潜在相关文献
   - 评估检索式的有效性

2. **更新检索策略**
   - 补充优化后的检索式
   - 记录反思和改进建议
   - 更新 `references/search_strategy.md`

## 输入要求

- 用户提供专利PDF文件路径
- 可选：指定特定技术领域或关键词

## 输出产物

1. **专利现有技术报告** (Word格式)
2. **检索策略文档** (Markdown格式)

## 质量控制

- 确保检索式包含技术领域和至少2个关键技术手段
- 筛选结果必须包含5篇最相关文献
- 报告需明确指出本申请的核心发明点
