# 八字基础知识参考

## 一、八字概述

八字，又称四柱八字，是中国传统命理学的核心概念。
- 年柱：出生年份的天干地支
- 月柱：出生月份的天干地支
- 日柱：出生日期的天干地支
- 时柱：出生时辰的天干地支

每柱由一个天干和一个地支组成，共八个字，故称"八字"。

## 二、天干地支

### 天干（10个）
甲、乙、丙、丁、戊、己、庚、辛、壬、癸

顺序：1甲、2乙、3丙、4丁、5戊、6己、7庚、8辛、9壬、10癸

### 地支（12个）
子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥

属相：子鼠、丑牛、寅虎、卯兔、辰龙、巳蛇、午马、未羊、申猴、酉鸡、戌狗、亥猪

## 三、节气与月柱

月柱以节气为分界，不是农历月份：

| 节气 | 月支 | 出生月份参考 |
|------|------|-------------|
| 立春 → 惊蛰 | 寅月 | 2月4日-3月5日 |
| 惊蛰 → 清明 | 卯月 | 3月6日-4月4日 |
| 清明 → 立夏 | 辰月 | 4月5日-5月5日 |
| 立夏 → 芒种 | 巳月 | 5月6日-6月5日 |
| 芒种 → 小暑 | 午月 | 6月6日-7月6日 |
| 小暑 → 立秋 | 未月 | 7月7日-8月7日 |
| 立秋 → 白露 | 申月 | 8月8日-9月7日 |
| 白露 → 寒露 | 酉月 | 9月8日-10月7日 |
| 寒露 → 立冬 | 戌月 | 10月8日-11月7日 |
| 立冬 → 大雪 | 亥月 | 11月8日-12月6日 |
| 大雪 → 小寒 | 子月 | 12月7日-1月5日 |
| 小寒 → 立春 | 丑月 | 1月6日-2月3日 |

## 五、日柱计算

日柱需要通过万年历查询或使用公式计算。

快速查询方法：
- 使用万年历工具查询
- 记住1900年1月1日为"甲子"日

## 六、年柱计算

年柱以立春为分界，非公历1月1日。

计算公式：
- 天干 = (年份 - 3) % 10（取整）
- 地支 = (年份 - 3) % 12（取整）
