# 五行基础知识参考

## 一、五行概述

五行指：金、木、水、火、土五种基本物质和能量。

相生：木 → 火 → 土 → 金 → 水 → 木（循环）
相克：木 → 土 → 水 → 火 → 金 → 木（循环）

## 六、用神选取原则

用神是对日主最有帮助的五行。

选取原则：
1. 日主过弱：选取生助日主的五行（印星、比劫）
2. 日主过强：选取克泄日主的五行（官杀、食伤、财星）

## 七、五行平衡

最佳状态：五行俱全，力量均衡

失衡类型：
- 五行缺一：需要补足
- 五行偏枯：某行过强或过弱
- 从格：某一五行极强或极弱时的特殊格局
