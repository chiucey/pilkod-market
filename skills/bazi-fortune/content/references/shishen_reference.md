# 十神详解参考

## 一、十神概述

十神是八字命理中用来分析人际关系的十个符号，基于五行生克关系确定。

关系图：
```
        印星（生我）
           ↑
      比肩← 日主 →劫财
           ↓
        财星（我克）
           ↑
        食伤（我生）→ 伤官
           ↑
        官杀（克我）→ 正官
```

## 二、十神定义

### 正官（克日主）
- 含义：正当的管束、约束、法律、规则
- 代表：上司、官职、法律、责任
- 性格：正直、有责任心、守法

### 七杀/偏官（克日主）
- 含义：不正当的管束、压力、竞争
- 代表：压力、挑战、小人、疾病
- 性格：果断、激进、有魄力

### 正财（我克）
- 含义：正当的财富、工资、收入
- 代表：金钱、财产、固定资产
- 性格：务实、稳重、守财

### 偏财（我克）
- 含义：意外的财富、投资、流动资金
- 代表：投机、意外之财、流动资产
- 性格：慷慨、大方、善于交际

### 正印（生我）
- 含义：学历、证书、母亲、贵人
- 代表：学习、智慧、名誉、保护
- 性格：善良、包容、有耐心

### 偏印/枭神（生我）
- 含义：继母、偏门学问、不劳而获
- 代表：偏业、创意、独特思维
- 性格：独立、敏感、善于分析

### 食神（我生）
- 含义：表达、创造、食欲、享受
- 代表：才华、艺术、饮食、福气
- 性格：温和、善良、有口福

### 伤官（我生）
- 含义：创新、反叛、口才、表现欲
- 代表：技术、创新、官司是非
- 性格：聪明、叛逆、有才华

### 比肩（与我同类）
- 含义：兄弟姐妹、同事、伙伴
- 代表：合作、竞争、独立、自主
- 性格：自信、固执、有毅力

### 劫财（与我同类）
- 含义：竞争、争夺、冒险
- 代表：破财、口舌、变动
- 性格：冲动、豪爽、不服输

## 五、十神配合分析

### 官印相生
- 特点：仕途顺利，有名气
- 组合：正官+正印/偏印

### 杀印相生
- 特点：有权势，能服众
- 组合：七杀+正印/偏印

### 财官相生
- 特点：富中取贵，贵中求富
- 组合：正财+正官

### 食伤生财
- 特点：靠技艺才华求财
- 组合：食神/伤官+正财/偏财

### 比劫夺财
- 特点：财来财去，易破财
- 组合：比肩/劫财+正财/偏财
