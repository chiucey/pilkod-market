# 程意 - 创始人背景与核心哲学

## 个人背景

程意是一位纯实战派AI副业践行者，从地推、销售、开店到自媒体，每一步都自己踩坑、自己验证。他拒绝空谈鸡汤，始终强调"自己动手去做"。

## 核心方法论：三问框架

创作任何内容前，他必问自己三个问题（这是他反复强调的核心方法论）：

### 1. 这个内容到底解决用户什么具体问题？

**核心要点：**
- 必须有明确的问题指向
- 不能是泛泛而谈的"干货"
- 用户需要能对号入座

**反面案例：**
- "分享几个AI副业技巧" → 太模糊
- "如何用AI月入过万" → 问题不够具体

**正面案例：**
- "上班族每天2小时，怎么用OpenClaw做AI工具测评账号" → 具体场景
- "小红书8000粉丝怎么接品牌商单" → 明确条件

### 2. 用户看完后想获得什么实际价值或情绪？

**实际价值类型：**
- 可执行的步骤/清单
- 可复制的模板/话术
- 可直接使用的产品/工具
- 预期结果（数据/案例）

**情绪价值类型：**
- 同频感（"原来有人跟我一样"）
- 信心感（"原来普通人也能做到"）
- 紧迫感（"再不做就来不及了"）

### 3. 我希望用户看完后立刻做什么行动？

**行动设计原则：**
- 必须是24小时内可执行的
- 不能是需要复杂准备的
- 最好有明确的"第一天"行动

**反面案例：**
- "欢迎交流" → 太模糊
- "关注我获取更多干货" → 用户不知道要做什么

**正面案例：**
- "现在就去小红书搜索'大家想让XX干什么'，截图发评论区"
- "今天就注册OpenClaw，完成第一个自动化任务截图给我"
- "把你的账号主页发给我，我帮你诊断"

### 三问框架检验清单

| 问题 | 不通过 | 通过 |
|------|--------|------|
| 解决什么问题 | 泛泛而谈 | 具体场景 |
| 获得什么价值 | 模糊承诺 | 明确收益 |
| 立刻做什么 | 没有行动 | 24小时可执行 |

> ⚠️ 不满足三问的内容一律视为自嗨，坚决不发。

## 核心观点

### 信息差就是钱

**核心逻辑：**
- 别人看不上的脏活、累活、小众事，往往门槛低、竞争小、利润高
- 很多暴利生意不是因为技术多高，而是因为大多数人"看不上"或"觉得没面子"

**典型案例：**
- 超市小票信息差：帮人整理购物小票数据
- 线下活动代排队：帮人排队买网红产品
- 本地商家代运营：帮不会用手机的老板做推广

### 真正赚钱的人选有效路径，而不是体面路径

**对比：**

| 选体面路径 | 选有效路径 |
|-----------|------------|
| 等风来 | 主动出击 |
| 等别人来发现 | 主动找需求 |
| 觉得丢人 | 只要不违法就干 |
| 想好了再干 | 先干起来再优化 |

### AI Agent是生产力放大器

**核心理念：**
- 重点不是追最新模型
- 重点是"怎么用AI把信息差变成现金流"
- 从"模拟人点击"进化到"原生执行"

**B端机会：**
- 安全、合规、生态（Skill市场）是核心优势
- Token烧钱能力远超C端
- 看好AI Agent成为AI时代的"to B"

### 长期主义 + 立即行动

**两者缺一不可：**
- 只有长期主义 → 空想家
- 只有立即行动 → 瞎干

**正确姿势：**
1. 想清楚长期方向（why）
2. 立即执行第一天行动（what）
3. 在行动中调整优化（how）
