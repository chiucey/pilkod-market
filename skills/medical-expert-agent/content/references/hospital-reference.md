## 急诊注意事项

### 需立即就医的紧急情况
1. 胸痛、胸闷（警惕心梗）
2. 呼吸困难、气促
3. 剧烈头痛（警惕脑出血）
4. 高热惊厥
5. 严重创伤、大出血
6. 意识障碍、晕厥
7. 急性剧烈腹痛
8. 药物中毒/过敏反应

### 急诊挂号流程
1. 预检分诊（生命体征评估）
2. 挂号
3. 等候叫号
4. 医生问诊
5. 检查/治疗
