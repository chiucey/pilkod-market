# 治疗方案报告HTML模板说明

## 报告生成工作流程

```
用户请求 → 收集信息 → 生成报告 → 部署分享
```

## HTML报告标准结构

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>治疗方案报告 - [疾病名称]</title>
    <style>
        /* 专业医疗报告样式 */
    </style>
</head>
<body>
    <header>
        <!-- 报告标题、患者信息、生成日期 -->
    </header>

    <main>
        <!-- 1. 病情概述 -->
        <!-- 2. 症状分析 -->
        <!-- 3. 检查建议 -->
        <!-- 4. 治疗方案 -->
        <!-- 5. 注意事项 -->
        <!-- 6. 复诊建议 -->
    </main>

    <footer>
        <!-- 免责声明、参考来源 -->
    </footer>
</body>
</html>
```

## 报告模块设计

### 1. 报告头部
- 标题：治疗方案报告
- 患者昵称/基本信息
- 报告生成日期
- 疾病名称标签

### 2. 病情概述卡片
- 主要症状描述
- 症状持续时间
- 伴随症状列表

### 3. 症状分析区块
- 可能病因分析
- 鉴别诊断要点
- 相关医学图解（可选SVG）

### 4. 检查建议区块
- 推荐检查项目（表格形式）
- 检查目的说明
- 注意事项提示

### 5. 治疗方案区块
- 方案分级（保守/药物/手术）
- 详细用药指导
- 非药物治疗方法
- 预期效果

### 6. 生活方式指导
- 饮食建议
- 运动建议
- 作息调整
- 禁忌事项

### 7. 复诊建议
- 复诊时间节点
- 复诊检查项目
- 预警症状提示

### 8. 免责声明页脚
- 医疗免责声明
- 建议就医声明
- 参考资料来源

## 样式设计要求

### 配色方案
- 主色调：#2563EB（医疗蓝）
- 辅助色：#10B981（健康绿）
- 警示色：#EF4444（警示红）
- 背景色：#F8FAFC（浅灰白）
- 文字色：#1E293B（深灰）

### 字体
- 标题：思源黑体/Noto Sans SC
- 正文：系统默认中文字体
- 数字：Roboto/DIN

### 卡片设计
- 圆角：12px
- 阴影：轻微阴影效果
- 内边距：24px
- 卡片间距：16px

### 图标使用
- 使用SVG图标（Lucide图标库）
- 尺寸：24px
- 颜色：与内容匹配

## 部署输出

生成报告后，用户可选择：
1. 一键部署获取分享链接
2. 下载HTML文件本地查看
3. 打印为PDF格式

## 示例输出路径

```
dist/
├── report_[疾病名]_[日期].html
└── assets/
    ├── css/
    └── images/
```
