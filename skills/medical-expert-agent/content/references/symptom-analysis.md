# 常见症状分析与鉴别指南

## 头痛

### 初步评估要点
| 问题 | 关键信息 |
|------|----------|
| 部位 | 前额/两侧/后脑勺/全头痛 |
| 性质 | 胀痛/刺痛/跳痛/钝痛 |
| 持续时间 | 几分钟/数小时/持续/反复 |
| 诱因 | 睡眠/情绪/月经/饮食 |
| 伴随症状 | 恶心呕吐/视物模糊/肢体麻木 |

### 常见原因
- 紧张性头痛（最常见）：双侧压迫感，与压力相关
- 偏头痛：单侧跳动痛，伴恶心畏光
- 高血压头痛：枕部胀痛，晨起明显
- 颅内病变：进行性加重，需警惕

### 建议检查
- 血压测量
- 头部CT/MRI（必要时）
- 颈动脉超声（50岁以上）

## 胸痛

### 危险信号（需立即就医）
- 压榨样/撕裂样疼痛
- 伴出汗/恶心/濒死感
- 向左肩/下颌/背部放射
- 持续>20分钟不缓解

### 鉴别诊断
| 类型 | 特点 |
|------|------|
| 心绞痛 | 运动诱发，休息3-5分钟缓解 |
| 心肌梗死 | 持续不缓解，含服硝酸甘油无效 |
| 主动脉夹层 | 撕裂样痛，血压差大 |
| 肺栓塞 | 呼吸困难，低氧血症 |
| 肋间神经痛 | 沿肋骨走向刺痛 |

### 建议检查
- 心电图
- 心肌酶谱
- D-二聚体
- 胸部CT（必要时）

## 腹痛

### 定位诊断
| 部位 | 可能病因 |
|------|----------|
| 右上腹 | 胆囊炎、肝炎、胆结石 |
| 左上腹 | 胰腺炎、胃溃疡 |
| 脐周 | 阑尾早期、肠炎 |
| 右下腹 | 阑尾炎、结肠炎 |
| 左下腹 | 结肠炎、妇科疾病 |
| 全腹 | 腹膜炎、肠梗阻 |

### 危险信号
- 持续剧烈腹痛
- 腹肌紧张
- 发热
- 呕血/便血
- 进行性腹胀

### 建议检查
- 腹部超声/CT
- 血常规
- 淀粉酶/脂肪酶
- 大便常规

## 发热

### 发热分度
- 低热：37.3-38°C
- 中等热：38.1-39°C
- 高热：39.1-41°C
- 超高热：>41°C

### 伴随症状分析
| 伴随症状 | 可能病因 |
|----------|----------|
| 咽痛 | 上呼吸道感染 |
| 咳嗽咳痰 | 肺炎、支气管炎 |
| 尿频尿痛 | 泌尿系统感染 |
| 腹泻 | 胃肠炎 |
| 皮疹 | 病毒感染、风湿性疾病 |
| 头痛呕吐 | 脑膜炎 |

### 建议检查
- 血常规
- C反应蛋白
- 降钙素原
- 病原学检查（必要时）

## 咳嗽

### 咳嗽性质
| 类型 | 特点 | 常见病因 |
|------|------|----------|
| 干咳 | 无痰 | 咽炎、过敏、哮喘 |
| 湿咳 | 有痰 | 支气管炎、肺炎 |
| 夜间咳 | 卧床加重 | 哮喘、心衰 |
| 餐后咳 | 与进食相关 | 胃食管反流 |

### 伴随症状
- 发热+咳嗽 → 呼吸道感染
- 喘息 → 哮喘、COPD
- 咯血 → 结核、肺癌（需警惕）
- 胸痛 → 胸膜病变

### 建议检查
- 胸片/胸部CT
- 肺功能
- 痰培养
- 过敏原检测

## 体重下降

### 体重下降原因分类

#### 非疾病因素
- 饮食控制/运动增加
- 生活压力
- 睡眠不足

#### 疾病因素
| 系统 | 常见病因 |
|------|----------|
| 消化系统 | 胃癌、肠癌、肝炎、胰腺炎 |
| 内分泌 | 糖尿病、甲亢 |
| 恶性肿瘤 | 各种癌症 |
| 感染 | 结核、HIV |
| 风湿免疫 | 系统性红斑狼疮、类风湿 |

### 需警惕情况
- 体重下降>5%在6个月内
- 伴乏力、盗汗
- 伴消化道症状
- 中老年新发

### 建议检查
- 肿瘤标志物
- 甲状腺功能
- 血糖
- 腹部超声/CT
- 胃镜/肠镜（必要时）

## 水肿

### 水肿分类
| 类型 | 特点 | 常见病因 |
|------|------|----------|
| 凹陷性水肿 | 按压后凹陷 | 肾病、心衰、肝病 |
| 非凹陷性水肿 | 按压无凹陷 | 甲状腺功能减退 |
| 单侧水肿 | 一侧为主 | 静脉血栓、淋巴水肿 |
| 双侧水肿 | 两侧对称 | 全身性疾病 |

### 伴随症状分析
- 蛋白尿 + 水肿 → 肾病
- 呼吸困难 + 水肿 → 心衰
- 黄疸 + 水肿 → 肝病
- 怕冷便秘 → 甲减

### 建议检查
- 肝肾功能
- 尿蛋白
- 心脏超声
- 甲状腺功能
- 下肢静脉超声
