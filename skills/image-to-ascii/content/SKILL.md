# 图片转ASCII艺术技能

## 核心功能

将图片转换为ASCII字符艺术，通过灰度处理和字符映射实现。

## 工作流程

### 1. 读取图片

读取用户提供的图片文件，支持以下格式：
- PNG
- JPEG/JPG
- GIF
- BMP
- WebP

### 2. 灰度处理

将彩色图片转换为灰度图像，使用加权平均法：

```
灰度值 = 0.299 * R + 0.587 * G + 0.114 * B
```

### 3. 降维处理

调整图像尺寸以适应ASCII输出：
- 计算合适的宽高比（考虑字符的高宽比约为 2:1）
- 默认宽度：100-150个字符
- 保持宽高比以避免图像变形

### 4. ASCII字符映射

将灰度值(0-255)映射到ASCII字符，使用从暗到亮的字符序列：

```
字符序列（从暗到亮）：@%#*+=-:.
```

映射规则：
- 灰度值 0-25 → `@`
- 灰度值 26-51 → `%`
- 灰度值 52-77 → `#`
- 灰度值 78-103 → `*`
- 灰度值 104-129 → `+`
- 灰度值 130-155 → `=`
- 灰度值 156-181 → `-`
- 灰度值 182-207 → `:`
- 灰度值 208-233 → `.`
- 灰度值 234-255 → ` ` (空格)

### 5. 输出ASCII艺术

生成ASCII字符画文本，每行对应图像的一行像素。

## 可调参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| width | 120 | ASCII输出的字符宽度 |
| invert | false | 是否反转字符映射（暗变亮，亮变暗）|
| charset | @%#*+=-:. | 用于映射的ASCII字符序列 |

## 执行示例

当用户提供图片时，技能将：
1. 接收图片文件路径或Base64编码
2. 加载并处理图片
3. 输出ASCII艺术文本
4. 可选：保存为文本文件或显示预览

## 注意事项

- 高对比度的图片通常产生更好的ASCII艺术效果
- 人物肖像和风景照片效果较好
- 纯文字截图不适合此转换
- 可通过调整width参数控制输出精细度
