# 认知条目模板参考

## 标准认知条目格式

```markdown
## [认知标题 - 简洁明了，不超过30字]

**录入时间**：[YYYY-MM-DD HH:mm]
**分类来源**：[技术面/情绪面/基本面/政策面/散户心理/主力意图/关注票池/近期盘面]
**综合评分**：[X/100]
**时效标记**：[短期有效(30天内)/中期有效(1年内)/长期有效(永久)]

### 核心内容
[用1-3句话准确描述此认知的核心要点。使用清晰、无歧义的语言。]

### 量化依据
- 逻辑完整性：[X/25] - [简要说明扣分原因]
- 数据支撑：[X/25] - [数据来源或支撑依据]
- 时效适用：[X/25] - [适用市场环境描述]
- 可执行性：[X/25] - [可转化为何种操作]

### 原始输入
> [用户的原始输入内容，保留原始表述]

### 适用条件
1. [第一个适用条件]
2. [第二个适用条件]
3. [第三个适用条件]

### 注意事项
- ⚠️ [可能的失效场景1]
- ⚠️ [可能的失效场景2]
- 💡 [与此认知相关的其他认知索引]

### 复核记录
- [YYYY-MM-DD] 复核：[通过/需调整/已失效] - [复核说明]
```

## 各维度认知条目示例

### 技术面示例

```markdown
## MACD金叉买入法

**录入时间**：2024-03-15 14:30
**分类来源**：技术面
**综合评分**：72/100
**时效标记**：中期有效

### 核心内容
MACD指标在零轴上方形成金叉（DIFF上穿DEA），且伴随成交量放大至5日均量1.5倍以上时，是较强的买入信号。

### 量化依据
- 逻辑完整性：18/25 - 逻辑基本完整，但未考虑市场环境差异
- 数据支撑：17/25 - 基于历史统计，但具体成功率数据需补充
- 时效适用：18/25 - 在趋势行情中效果较好，震荡市中信号失真
- 可执行性：19/25 - 买入条件明确，但止损位置需进一步定义

### 原始输入
> "MACD金叉的时候买，配合放量，成功率挺高的"

### 适用条件
1. 适用于上升趋势或震荡偏多市场
2. 个股或指数日线级别以上周期
3. 非ST、非新股开板初期

### 注意事项
- ⚠️ 熊市或震荡市中MACD金叉频繁失灵
- ⚠️ 需要结合量能和其他指标综合判断
- 💡 相关认知：#量价配合 #RSI超买配合

### 复核记录
- [2024-04-15] 复核：通过 - 保持不变
```

### 基本面示例

```markdown
## ROE连续三年超过15%是优质公司重要标志

**录入时间**：2024-02-20 10:00
**分类来源**：基本面
**综合评分**：78/100
**时效标记**：长期有效

### 核心内容
净资产收益率（ROE）连续三年超过15%的公司，往往具备较强的竞争优势和持续的盈利能力，是筛选优质白马股的重要财务指标。

### 量化依据
- 逻辑完整性：20/25 - 逻辑严密，ROE是巴菲特最看重的指标
- 数据支撑：19/25 - 有大量学术研究和投资实践支撑
- 时效适用：19/25 - 长期有效，但需注意周期性行业特殊性
- 可执行性：20/25 - 可直接用于选股筛选

### 原始输入
> "找那种ROE一直保持在15%以上的公司，这样的公司一般都不会太差"

### 适用条件
1. 适用于挑选各行业龙头白马股
2. 需结合行业平均ROE对比分析
3. 排除强周期行业（如券商、钢铁、煤炭）

### 注意事项
- ⚠️ 周期性行业（如猪周期、航空）的ROE波动是正常的
- ⚠️ 高负债公司的ROE可能虚高，需结合资产负债率
- ⚠️ 一次性收益可能导致短期ROE异常
- 💡 补充指标：#净利润增速 #经营现金流

### 复核记录
- [2024-03-20] 复核：通过 - 补充注意事项
```

### 情绪面示例

```markdown
## 散户情绪极端时往往是反向指标

**录入时间**：2024-01-10 16:00
**分类来源**：情绪面
**综合评分**：75/100
**时效标记**：长期有效

### 核心内容
当市场出现极端贪婪（开户数激增、基金抢购、遍地股神）或极端恐惧（恐慌抛售、讨论区冷清、无人问津）时，往往是市场即将反转的信号。

### 量化依据
- 逻辑完整性：19/25 - 反向投资逻辑成立，但需明确极端的定义
- 数据支撑：17/25 - 有行为金融学研究支撑，但具体阈值需量化
- 时效适用：20/25 - 长期有效，但需适应不同市场特征
- 可执行性：19/25 - 情绪判断标准需要进一步细化

### 原始输入
> "当大家都说股票的时候反而要小心了，相反没人敢提股票的时候反而可能是机会"

### 适用条件
1. 适用于判断大盘整体顶底
2. 适用于判断热门板块阶段性顶部
3. 需与其他指标配合使用

### 注意事项
- ⚠️ "极端"的判断具有一定主观性
- ⚠️ 新兴市场散户比例高，反向指标效应更明显
- ⚠️ 不能精确判断反转时间点
- 💡 结合指标：#恐惧贪婪指数 #融资融券余额

### 复核记录
- [2024-02-10] 复核：通过
```

## 认知更新与版本管理

### 更新类型

1. **修正更新**：发现认知存在错误时
2. **补充更新**：增加适用条件或注意事项
3. **时效更新**：调整时效标记
4. **合并更新**：合并相似的重复认知

### 版本记录格式

```markdown
### 更新历史
- **v1.1** [YYYY-MM-DD] 修正：[修改原因]
- **v1.0** [YYYY-MM-DD] 初始创建
```

## 认知标签系统

使用标签方便检索和关联：

| 标签 | 含义 | 示例 |
|------|------|------|
| #买入信号 | 买入相关 | MACD金叉、缩量回踩 |
| #卖出信号 | 卖出相关 | 放量滞涨、天量见天价 |
| #选股标准 | 选股条件 | ROE>15%、净利润增速>20% |
| #风险警示 | 风险提示 | 高杠杆、商誉减值 |
| #市场顶底 | 判断顶底 | 极端情绪、成交量异常 |
| #行业通用 | 跨行业适用 | 竞争优势、管理层质量 |
