# 投资认知记忆系统 - 八大维度详解

## 维度概览

| 维度 | 权重 | 核心关注点 | 量化难点 |
|------|------|-----------|---------|
| 技术面 | 20% | 价格形态、指标信号、量价关系 | 滞后性、失效频繁 |
| 情绪面 | 15% | 市场情绪、板块轮动、人气指标 | 主观性强、难以量化 |
| 基本面 | 25% | 财务质量、竞争优势、估值水平 | 信息滞后、分析深度 |
| 政策面 | 20% | 宏观政策、行业监管、改革动向 | 解读分歧、传导时滞 |
| 散户心理 | 10% | 行为偏差、认知陷阱、群体行为 | 逆向难度高 |
| 主力意图 | 10% | 资金动向、建仓痕迹、控盘特征 | 信息不对称 |
| 关注票池 | 动态 | 入池标准、持仓跟踪、关注级别 | 持仓管理 |
| 近期盘面 | 记录 | 盘面解读、操作记录、复盘反思 | 格式化记录 |

## 1. 技术面 (Technical Analysis)

**定义**：通过分析价格走势、成交量、技术指标等市场交易数据来预测价格变动的方法。

**核心要素**：

| 要素类别 | 主要内容 | 量化指标 |
|---------|---------|---------|
| 趋势判断 | 上升/下降/震荡趋势识别 | MA(5,10,20,60,120,250)、趋势线 |
| 形态分析 | 头肩顶/底、双顶/底、三角形等 | 形态完成度、突破有效性 |
| 指标应用 | MACD、KDJ、RSI、布林带等 | 金叉死叉、超买超卖、背离 |
| 量价关系 | 放量上涨、缩量回调、天量见顶 | 量比、换手率、量能均线 |
| 支撑阻力 | 关键价位、成交密集区 | 支撑/阻力位强度、回踩确认 |

**量化评分重点**：
- 逻辑完整性（20%）：指标组合是否有内在逻辑
- 数据支撑度（15%）：历史胜率统计
- 时效适用性（30%）：当前市场环境适配度
- 可执行性（35%）：信号明确程度

**常见认知陷阱**：
- 过度依赖单一指标
- 忽视量价配合
- 将震荡行情的信号用于趋势行情
- 指标钝化时仍机械使用

## 2. 情绪面 (Market Sentiment)

**定义**：衡量市场整体参与者的情绪状态，包括乐观、悲观、贪婪、恐惧等情绪。

**核心要素**：

| 要素类别 | 主要内容 | 量化指标 |
|---------|---------|---------|
| 市场情绪 | 整体乐观/悲观程度 | 恐惧贪婪指数、腾落线 |
| 板块轮动 | 热点切换节奏、轮动规律 | 板块涨跌家数比、资金流向 |
| 人气指标 | 交易活跃度、市场关注度 | 成交量、换手率、开户数 |
| 资金情绪 | 杠杆资金、北向资金态度 | 融资融券余额、北向净流入 |
| 预期差 | 预期与实际的偏离程度 | 研报预期差、财报预期差 |

**量化评分重点**：
- 逻辑完整性（30%）：情绪传导机制是否清晰
- 数据支撑度（15%）：情绪指标的可靠性
- 时效适用性（25%）：情绪周期的当前位置
- 可执行性（30%）：情绪信号的实操价值

**常见认知陷阱**：
- 情绪极端时过于自信
- 忽视情绪惯性
- 将短期情绪波动当作趋势
- 过度关注他人情绪而失去独立判断

## 3. 基本面 (Fundamental Analysis)

**定义**：通过分析公司的财务状况、经营管理、行业地位、宏观经济等基本面因素来评估投资价值。

**核心要素**：

| 要素类别 | 主要内容 | 量化指标 |
|---------|---------|---------|
| 财务质量 | 盈利能力、偿债能力、运营效率 | ROE、ROA、毛利率、资产负债率 |
| 成长性 | 收入增长、利润增长、市场份额 | 营收增速、净利润增速 |
| 估值水平 | 绝对估值、相对估值 | PE、PB、PS、EV/EBITDA |
| 竞争优势 | 护城河、品牌、技术壁垒 | 市场份额、毛利率趋势 |
| 管理层 | 治理结构、管理能力、激励机制 | 高管变动、股权激励计划 |

**量化评分重点**：
- 逻辑完整性（25%）：财务逻辑链是否完整
- 数据支撑度（35%）：数据来源和可靠性
- 时效适用性（20%）：财务数据的时效性
- 可执行性（20%）：选股标准的可操作性

**常见认知陷阱**：
- 机械使用PE指标，忽视行业差异
- 过度关注短期业绩波动
- 忽视现金流只看利润
- 将行业龙头与高成长混为一谈

## 4. 政策面 (Policy Impact)

**定义**：分析宏观经济政策、产业政策、监管政策对市场和企业的影响。

**核心要素**：

| 要素类别 | 主要内容 | 量化指标 |
|---------|---------|---------|
| 宏观政策 | 货币政策、财政政策、汇率政策 | 利率、M2增速、财政赤字 |
| 产业政策 | 行业发展规划、扶持/限制政策 | 补贴力度、准入门槛变化 |
| 监管政策 | 交易监管、信息披露、退市制度 | 监管文件、窗口指导 |
| 改革政策 | 资本市场改革、国企改革等 | 改革进度、试点范围 |
| 国际政策 | 贸易政策、制裁清单、国际关系 | 加关税清单、实体清单 |

**量化评分重点**：
- 逻辑完整性（20%）：政策传导机制
- 数据支撑度（25%）：政策信息的权威性
- 时效适用性（35%）：政策窗口期判断
- 可执行性（20%）：政策受益标的的选择

**常见认知陷阱**：
- 过度解读单一政策信号
- 忽视政策的实际执行力度
- 将政策意图等同于市场反应
- 忽视政策的边际变化

## 5. 散户心理 (Retail Psychology)

**定义**：研究散户投资者在决策过程中的认知偏差和行为模式，以及如何识别和避免这些陷阱。

**核心要素**：

| 要素类别 | 主要内容 | 量化指标 |
|---------|---------|---------|
| 认知偏差 | 确认偏误、可得性启发、锚定效应 | 偏差出现频率 |
| 情绪偏差 | 损失厌恶、过度的自信、羊群效应 | 交易频率、持仓时长 |
| 决策陷阱 | 卖出盈利、持有亏损、频繁交易 | 盈利卖出比例、止损执行率 |
| 反向思维 | 如何利用散户的错误决策获利 | 逆向信号识别 |
| 心理防线 | 关键心理点位的市场反应 | 整数关口、持仓成本区 |

**量化评分重点**：
- 逻辑完整性（30%）：心理模型的严谨性
- 数据支撑度（15%）：行为金融学依据
- 时效适用性（25%）：当前市场情绪位置
- 可执行性（30%）：逆向操作的可行性

**常见认知陷阱**：
- 知道偏差存在但无法克服
- 过度自信能战胜市场
- 将运气误认为能力
- 忽视行为偏差的累积效应

## 6. 主力意图 (Smart Money Intent)

**定义**：通过分析大资金的行为模式来推断主力（机构、庄家）的操作意图和可能动向。

**核心要素**：

| 要素类别 | 主要内容 | 量化指标 |
|---------|---------|---------|
| 资金流向 | 大单净流入、主力动向 | 主力资金净流入、超大单比例 |
| 建仓痕迹 | 低位吸筹、温和放量 | 吸筹周期、换手率变化 |
| 控盘特征 | 分时走势、买卖盘挂单 | 分时线平滑度、压单托单 |
| 出货信号 | 高位放量、形态破位 | 天量、高位长上影 |
| 龙虎榜 | 营业部交易、机构席位 | 机构买入比例、敢死队特征 |

**量化评分重点**：
- 逻辑完整性（25%）：主力行为逻辑链
- 数据支撑度（20%）：数据获取的准确性
- 时效适用性（25%）：当前主力操作周期
- 可执行性（30%）：跟随主力策略的可行性

**常见认知陷阱**：
- 迷信"庄家"概念
- 将随机大单当作主力行为
- 忽视主力也可能亏损
- 过度解读龙虎榜数据

## 7. 关注票池 (Watchlist)

**定义**：管理投资者重点关注的标的清单，包括入池标准、持仓状态、关注级别等。

**管理要素**：

| 要素类别 | 主要内容 | 记录项目 |
|---------|---------|---------|
| 入池标准 | 为什么要关注这只股票 | 入池理由、预期逻辑 |
| 基本信息 | 公司概况、行业地位 | 代码、名称、行业、市值 |
| 持仓状态 | 当前持仓情况 | 持仓数量、成本、盈亏 |
| 关注级别 | 重点关注程度 | A/B/C级 |
| 跟踪要点 | 需要持续关注的关键点 | 催化剂、风险因素 |
| 操作计划 | 潜在的操作思路 | 买入区间、止损位、目标位 |

**动态调整机制**：
- 定期复核：每月评估一次是否保留
- 触发调整：重大事项发生后立即评估
- 进出池记录：记录所有进出池操作

## 8. 近期盘面 (Recent Market Analysis)

**定义**：记录近期盘面解读、操作记录和复盘反思，为后续分析积累素材。

**记录要素**：

| 要素类别 | 主要内容 | 记录要求 |
|---------|---------|---------|
| 盘面解读 | 当日市场概况、热点板块 | 涨跌停数量、成交量、北向流向 |
| 关键事件 | 影响市场的重大消息 | 政策、行业、公司消息 |
| 操作记录 | 当日买卖操作及理由 | 标的、价格、数量、理由 |
| 持仓变化 | 持仓标的的重要变化 | 公告、异动、跟踪事项 |
| 复盘反思 | 对操作的反思总结 | 成功/失败原因、改进方向 |
| 重要价位 | 关注的支撑阻力位 | 画线标记、理由 |

**记录规范**：
- 日志格式：按日期组织，便于回溯
- 定期汇总：每周/每月形成阶段性总结
- 关联分析：关联到具体认知条目

## 决策优先级

1. **政策面 > 基本面 > 技术面**：政策决定方向，基本面决定质量，技术面决定时机
2. **主力意图 > 散户心理**：跟随大资金，逆向思维
3. **情绪面**：作为辅助验证，不可作为主要依据
4. **关注票池 + 近期盘面**：执行层面的记录和管理
