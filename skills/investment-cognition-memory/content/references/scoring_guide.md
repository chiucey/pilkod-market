# 量化评分细则参考

## 四维评分体系详解

### 1. 逻辑完整性（0-25分）

评估投资观点的推理链条是否完整、前提是否成立。

**评分标准**：

| 分数 | 等级 | 描述 | 示例 |
|------|------|------|------|
| 23-25 | 优秀 | 前提明确、逻辑严密、结论可靠 | "当MACD金叉且成交量放大至5日均量1.5倍以上，同时股价突破20日均线，且RSI<70时，成功率约70%" |
| 18-22 | 良好 | 逻辑基本完整，有轻微不确定性 | "业绩预增的股票往往有超额收益" |
| 13-17 | 一般 | 有明显逻辑缺陷但核心观点成立 | "PE低的股票更安全" |
| 8-12 | 较差 | 逻辑存在较大漏洞 | "涨停的股票第二天还会涨" |
| 0-7 | 差 | 逻辑存在根本性问题 | "所有亏损股都会被ST" |

**检查清单**：
- [ ] 前提条件是否明确列出
- [ ] 因果关系是否有依据
- [ ] 是否存在以偏概全的问题
- [ ] 是否混淆了相关性和因果性

### 2. 数据支撑度（0-25分）

评估观点是否有具体数据、市场证据支撑。

**评分标准**：

| 分数 | 等级 | 描述 | 示例 |
|------|------|------|------|
| 23-25 | 优秀 | 有具体数据、来源可靠、可验证 | "统计2010-2024年数据，茅台ROE连续14年超过20%" |
| 18-22 | 良好 | 有数据支撑，来源较可靠 | "根据券商研报，2024年新能源汽车渗透率将超40%" |
| 13-17 | 一般 | 有数据但不够充分 | "很多优质公司都有高ROE" |
| 8-12 | 较差 | 数据模糊或来源不可靠 | "据说这个方法很有效" |
| 0-7 | 差 | 缺乏任何数据支撑 | "我觉得这只股票会涨" |

**数据来源可靠性排序**：
1. 交易所官方数据
2. 公司财报/公告
3. 监管机构数据
4. 权威财经媒体
5. 券商研究报告
6. 数据服务商（Wind、Choice等）
7. 社区/论坛（非正式）

### 3. 时效适用性（0-25分）

评估观点在当前市场周期和环境下是否仍然有效。

**评分标准**：

| 分数 | 等级 | 描述 | 示例 |
|------|------|------|------|
| 23-25 | 优秀 | 完全适用于当前市场环境 | "在A股做短线，集合竞价9:15-9:25是重要的价格发现时段" |
| 18-22 | 良好 | 大部分适用，需轻微调整 | "定投指数基金长期来看能获得市场平均收益" |
| 13-17 | 一般 | 有适用性但有明显限制条件 | "高股息策略在低利率环境下表现较好" |
| 8-12 | 较差 | 与当前环境明显不符 | "全面注册制后，打新股仍是无风险收益"（已不适用） |
| 0-7 | 差 | 与当前市场环境完全相悖 | 2024年仍使用2015年杠杆牛市的经验 |

**时效性判断框架**：

| 时间维度 | 适用情况 | 复核频率 |
|---------|---------|---------|
| 短期有效（<1月） | 事件驱动型观点、盘中策略 | 每周 |
| 中期有效（1-12月） | 行业趋势、政策影响 | 每月 |
| 长期有效（>1年） | 投资哲学、基本规律 | 每季度 |

**环境因素检查**：
- [ ] 宏观经济周期是否匹配
- [ ] 政策环境是否发生变化
- [ ] 市场结构是否已改变
- [ ] 行业周期处于什么阶段

### 4. 可执行性（0-25分）

评估观点能否转化为具体的投资操作。

**评分标准**：

| 分数 | 等级 | 描述 | 示例 |
|------|------|------|------|
| 23-25 | 优秀 | 可转化为明确的操作指令 | "当股价回踩20日均线且缩量至5日均量0.5倍以下时，止损设在均线下3%" |
| 18-22 | 良好 | 有明确操作方向但需进一步细化 | "在估值低位买入优质公司" |
| 13-17 | 一般 | 可作为参考，但执行细节需自行把握 | "关注有业绩拐点的公司" |
| 8-12 | 较差 | 仅提供模糊方向 | "要做价值投资" |
| 0-7 | 差 | 无法转化为任何操作 | "这只股票会涨" |

**可执行性要素检查**：
- [ ] 入场条件是否明确（价格/时间/信号）
- [ ] 出场条件是否明确（止盈/止损）
- [ ] 仓位如何确定
- [ ] 是否有明确的持仓周期

## 综合评分决策

| 综合评分 | 决策建议 | 用户操作 |
|---------|---------|---------|
| 80-100 | 强烈建议加入 | 确认后可立即加入 |
| 70-79 | 建议加入 | 可直接加入或小幅修改 |
| 60-69 | 可以加入 | 建议加入但需补充说明 |
| 40-59 | 谨慎加入 | 需用户明确确认 |
| 20-39 | 不建议加入 | 记录但不推荐加入 |
| 0-19 | 拒绝加入 | 明确告知原因 |

## 权重调整规则

根据不同维度，四个评估维度可以适当调整权重：

**基本面**：
- 逻辑完整性：25%
- 数据支撑度：35%（更依赖财报数据）
- 时效适用性：20%
- 可执行性：20%

**技术面**：
- 逻辑完整性：25%
- 数据支撑度：15%
- 时效适用性：30%（更依赖当前环境）
- 可执行性：30%

**政策面**：
- 逻辑完整性：20%
- 数据支撑度：25%
- 时效适用性：35%（时效性最强）
- 可执行性：20%

**情绪面/散户心理**：
- 逻辑完整性：30%（心理模型需要严密的逻辑）
- 数据支撑度：15%
- 时效适用性：25%
- 可执行性：30%
