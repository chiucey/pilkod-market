# 抖音账号数据收集技能

## 技能概述

本技能用于一键采集抖音对标达人的核心数据指标，并支持批量解析抖音视频的详细信息。适用于竞品分析、内容策略制定、账号运营参考等场景。

## 核心功能

### 功能一：批量采集抖音达人数据表

**输入**：
- 抖音达人主页链接列表（支持多个）
- 或达人uid/抖音号列表

**采集数据维度**：

| 数据类别 | 采集字段 |
|---------|---------|
| 基础信息 | 抖音号、昵称、头像URL、粉丝数、关注数、获赞数、认证信息 |
| 账号属性 | 性别、地区、生日、简介、绑定平台（微博/微信） |
| 内容数据 | 作品总数、近期作品列表、爆款视频分布 |
| 互动数据 | 平均点赞/评论/转发率、粉丝互动率 |
| 商业数据 | 带货数据、星图指数、接单报价（若有） |

**输出格式**：
- 结构化数据表（支持导出Excel/CSV）
- 数据概览可视化

### 功能二：批量解析抖音视频

**输入**：
- 抖音视频链接列表（支持多个）
- 或视频av号/bv号列表

**解析数据维度**：

| 数据类别 | 解析字段 |
|---------|---------|
| 基础信息 | 视频标题、描述、时长、封面图、发布时间 |
| 内容数据 | 话题标签、@提及账号、音乐信息 |
| 流量数据 | 点赞数、评论数、分享数、收藏数 |
| 互动分析 | 评论热词、评论情感分布 |
| 作者信息 | 作者昵称、粉丝数、账号主页链接 |

**输出格式**：
- 视频详情JSON/表格
- 视频数据对比分析

## 执行工作流

### 阶段一：数据源准备

1. **接收用户输入**
   - 达人主页链接或视频链接列表
   - 格式支持：单条文本粘贴、多行输入、Excel导入

2. **输入验证**
   - 验证链接格式有效性
   - 去重处理
   - 格式标准化

### 阶段二：数据采集/解析

1. **达人数据采集**
   - 调用抖音数据接口获取账号信息
   - 补充公开数据字段
   - 数据清洗与格式化

2. **视频数据解析**
   - 提取视频元信息
   - 获取互动统计数据
   - 关联作者基础信息

### 阶段三：数据处理

1. **结构化处理**
   - 统一字段命名
   - 数据类型转换
   - 空值处理

2. **增强分析**（可选）
   - 计算同比/环比变化
   - 分类标签标注
   - 竞品对比排名

### 阶段四：结果输出

**输出方式**：
- 实时展示在对话中
- 导出为Excel文件
- 生成数据报告链接

## 使用示例

### 示例一：采集对标达人数据

**用户输入**：
```
帮我采集这几个抖音达人的数据：@疯狂小杨哥、@李子柒、@疯狂体育网
```

**执行流程**：
1. 解析输入的达人账号
2. 批量获取各账号公开数据
3. 整合成统一格式数据表
4. 输出结果并提供导出选项

### 示例二：解析视频数据

**用户输入**：
```
解析这几个视频的数据：
https://v.douyin.com/xxxxx1
https://v.douyin.com/xxxxx2
```

**执行流程**：
1. 提取视频链接
2. 获取各视频详细数据
3. 汇总成表格展示
4. 提供数据对比分析

## 注意事项

1. **数据合规性**
   - 仅采集公开可见数据
   - 不采集私有/受限信息
   - 遵守抖音平台协议

2. **数据时效性**
   - 粉丝数/点赞数等为实时或准实时数据
   - 历史数据基于接口返回的已有记录

3. **批量限制**
   - 单次建议不超过50个账号/视频
   - 大批量任务建议分批执行

4. **数据准确性**
   - 以抖音官方接口返回为准
   - 数据可能因平台策略调整而变化

## 常见问题

**Q: 支持采集私密账号吗？**
A: 不支持，仅能采集公开可见的账号数据。

**Q: 数据多久更新一次？**
A: 每次采集均为实时获取，显示当前时刻的数据状态。

**Q: 支持定时自动采集吗？**
A: 可配合定时任务实现周期性数据监控。

**Q: 能采集历史数据趋势吗？**
A: 单次采集仅获取当前快照，历史趋势需要建立定时采集任务积累数据。
