# NetWin × win-football-predictor 融合引擎使用指南

## 一、融合效果

| 指标 | V14（NetWin单模型） | 融合模型 | 变化 |
|------|-------------------|---------|------|
| 准确率（有ELO覆盖） | 37.18% | **39.77%** | **+2.59pp** ✅ |
| 覆盖比赛数 | 2625场 | 2625场 | — |

## 二、核心原理

两个模型各有所长：
- **NetWin**：擅长盘口分析（让球/平手盘）、6大联赛ELO分析
- **win-football-predictor**：Pi-Rating三模型融合、赔率特征工程、小联赛覆盖

**融合策略**：
- 6大联赛：各50%权重（算术平均）
- 杯赛（欧冠/欧联）：30% NetWin + 70% win-fp
- 小联赛（无ELO）：100% win-fp
- 客胜boost：当NetWin认为客胜>15%但win-fp<12%时，轻微boost客胜

## 四、使用方法

### 基本预测
```bash
cd /workspace/netwin-predictor
python3 fuse_engine.py <主队> <客队> <联赛> <主胜> <平赔> <客胜>

# 示例
python3 fuse_engine.py 曼城 阿森纳 英超 2.10 3.50 3.40
python3 fuse_engine.py 拜仁 皇马 欧冠 1.85 3.80 4.00
python3 fuse_engine.py 博洛尼亚 尤文 意甲 2.80 3.20 2.60
```

### 批量预测（JSON格式）
```bash
python3 fuse_engine.py --batch < matches.json
```

### 回测
```bash
python3 fuse_engine.py --backtest
```

### 帮助
```bash
python3 fuse_engine.py --help
```

```
⚽ 曼城 vs 阿森纳

==================================================
  赔率:  主胜=2.10  平局=3.50  客胜=3.40
  概率:  主胜=42.7%  平局=39.3%  客胜=18.0%
  隐含:  主胜=2.34  平局=2.54  客胜=5.57

==================================================
```

- **概率**：融合后的预测概率
- **隐含**：换算成赔率（1/概率）
- **模型**：两个子模型的独立判断
- **置信度**：两模型一致=高/中，分歧=⚠️分歧
- **factorTags**：自动显示客胜冷门信号等警示

## 七、已知局限

1. **客胜预测偏低**：融合模型客胜命中率仍低于真实频率（4% vs 27%）
2. **ELO覆盖有限**：约32%比赛缺ELO数据（已全力扩充映射）
3. **Pi-Rating预置球队有限**：约30支球队，未覆盖的球队用默认值(1.0,1.0)
4. **win-fp在客胜上压制NetWin**：通过boost客胜缓解，但未能完全解决

## 八、下一步优化方向

1. **扩大Pi-Rating覆盖**：补充更多球队评分
2. **意甲专项模型**：意甲客胜冷门密集区，单独处理
3. **主客场分离**：当前ELO为主客场总和，可考虑分离
4. **联赛真实基率校正**：用各联赛真实胜平负频率替代固定DB值
