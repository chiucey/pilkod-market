# 客胜因子专项研究报告 v1.0
> 研究日期：2026-04-17 | 数据源：8575场 | 作者：小虾 🦐

---

## 一、核心发现

### 1.1 客胜冷门分布（319场）

| oH区间 | 客胜冷门场次 | 占冷门比例 | 平均oA | 典型联赛 |
|--------|------------|-----------|--------|---------|
| oH < 1.50 | 60场 | 19% | 17.76 | 意甲/英超/欧冠 |
| 1.50 ≤ oH < 2.00 | 80场 | **25%** | 5.10 | 意甲为主 |
| 2.00 ≤ oH < 2.50 | 52场 | 16% | 3.40 | 意甲/英超 |
| 2.50 ≤ oH < 3.00 | 33场 | 10% | 2.64 | 混搭 |
| oH ≥ 3.00 | 94场 | 29% | 1.87 | 混搭（主队本就不强）|

**核心问题**：oH 1.50-2.50区间（主队偏热但非极热）有**132场冷门**，是模型最大弱点。

### 1.2 联赛特征
- **意甲**贡献最多（62场，oH 1.50-2.50区间）
  → 意甲小球文化：主队进攻效率低，防守反击型球队容易在主场被弱队偷袭
- **ELO差>100的客胜冷门**：意甲86场 + 英超78场 + 西甲30场
- **意甲ELO差>100但客胜**：249场，平赔均值4.15（极高）

### 1.3 赔率特征（关键）
- 冷门客胜的oD均值：**3.64**（正常客胜也达4.13）
- 关键组合：**oD > 3.80 + oA < 5.00 + oH > 1.60** → 庄家抬高平赔、压低主胜 → 实际客胜概率被低估

### 1.4 ELO差区间分析
| ELO差区间 | 客胜率 | 说明 |
|-----------|--------|------|
| ELO差<0（客强） | 30.2% | 正常，模型较准 |
| 0≤ELO差<50 | 25.5% | 实力接近 |
| 50≤ELO差<100 | 26.9% | 偏主但客胜不少 |
| **ELO差≥100（主强）** | **20.5%** | 模型弱点！ |

**关键洞察**：ELO说主队强（差≥100）时客胜反而更少（20.5%），
但这些"应该赢"的强队一旦被客胜，就是最典型的冷门。
这类冷门的赔率特征是：**oD被庄家大幅抬高**。

## 二、回测验证结果

| 版本 | 条件 | 有效样本 | 准确率 | 变化 |
|------|------|---------|--------|------|
| V14基准 | 无因子修正 | 2775场 | 33.87% | — |
| V17 | 意甲冷门+强势客胜修正 | 2775场 | 33.73% | **-0.14pp ❌** |
| V17b | 简化版（仅平赔修正） | 待测 | — | — |

**结论**：简单ELO差修正无效，反而降低准确率。
原因：热门的庄家控盘复杂，单向修正破坏已有主胜判断。

## 三、可用因子（信息展示层）

### 3.1 客胜冷门检测条件
```
触发条件（同时满足）：
  oD > 3.80（平赔被庄家高估）
  oA < 5.00（客队赔率偏低=被低估）
  oH > 1.60（主队偏热门但非极热）
  ELO差 > 50（主队表面实力更强）
  
→ 信号："🚨客胜冷门风险"（factorTags显示）
```

### 3.2 意甲特殊子集
```
触发条件：
  联赛 = SA（意甲）
  oD > 3.50
  oA > 4.00
  
→ 信号："🇮🇹意甲主队过热风险"（factorTags显示）
```

### 3.3 oH热门极热区间保护
```
触发条件：
  oH < 1.50（极热主队）
  oD > 3.80（平局被抬）
  oA > 6.00（客队被极度低估）
  
→ 信号："⚠️极热主队+冷门条件并存"（factorTags显示）
```

## 五、待研究方向

### P0优先级
1. **意甲数据集独立建模**：意甲需要单独的概率模型（平局率更高、大球更难）
2. **联赛Elo基率校正**：用真实联赛频率替代固定DB值
3. **扩大ELO覆盖率**：当前32%→目标70%+（扩充中文队名映射）

### 理论框架
> **核心假设**：当oD被庄家大幅抬高（>3.80），说明庄家在主动引导资金流向平局；
> 此时主队表面热门，但庄家并不真正看好——这恰恰是客胜的最佳温床。
> 这一现象在意甲最为密集（意甲主场平局率本就偏高，庄家常借平局掩护客胜）。
