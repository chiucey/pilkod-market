# 小虾足球预测系统 · NetWin Predictor

## 快速使用

### 方式一：手动预测（输入赔率）
```bash
cd /workspace/skills/netwin-predictor/scripts
python3 fuse_engine.py <主队> <客队> <联赛> <主胜> <平赔> <客胜>

# 示例
python3 fuse_engine.py 曼城 阿森纳 英超 2.10 3.50 3.40
python3 fuse_engine.py 拜仁 皇马 欧冠 1.85 3.80 4.00
python3 fuse_engine.py 博洛尼亚 尤文 意甲 2.80 3.20 2.60
```

### 方式二：自动预测（API实时赔率）
```bash
cd /workspace/skills/netwin-predictor/scripts
python3 auto_predict.py --fetch
```

### 方式三：批量预测（JSON文件）
```bash
python3 auto_predict.py --file matches.json
```

## 输出解读

```
⚽ 曼城 vs 阿森纳
🏆 英超 | 盘口: 主队受让0.52球
==================================================
  赔率:  主胜=2.10  平局=3.50  客胜=3.40
  概率:  主胜=42.7%  平局=39.3%  客胜=18.0%
  隐含:  主胜=2.34  平局=2.54  客胜=5.57
  模型:  小虾=H  win-fp=D  (权重 NetWin=0.5 win-fp=0.5)
==================================================
🎯 推荐: 【胜】 置信度: ⚠️分歧
==================================================
```

**字段说明：**
- `概率`：融合后的预测概率（H=主胜 D=平局 A=客胜）
- `隐含`：换算赔率（1÷概率），低于市场赔率=价值位
- `模型`：两个子模型的独立判断（一致时置信度高）
- `置信度`：高=两模型一致+概率>50%，中=一致+概率>38%，⚠️分歧=两模型判断不同

| 📊平手盘双重平局信号 | \|hand_v\|<0.13 且 2.5≤oD≤3.6 | 平手盘+高平赔=平局强信号 |

## 融合模型原理

```
最终概率 = 50% × NetWin概率 + 50% × win-fp概率
客胜boost：NetWin认为客胜>15% 但 win-fp<12% 时 → 客胜+30%
```

- **NetWin**：ClubElo 630队 + 让球盘口规则引擎
- **win-fp**：Pi-Rating + CatBoost/XGBoost/Dixon-Coles 三模型融合（权重45%/35%/20%）
- **联赛专项校正**：欧冠平局+5%、西甲主胜-3%、德甲平局+4%（710期9940场验证）
