# 电视财经新闻稿撰写 Skill

## 输入准备

用户需要提供：
1. **新闻主题**（一句话描述）
2. **同期声内容**（采访对象姓名+职务+讲话原文，保留所有停顿和语气词）
3. **播出日期**（可选）

## 工作流程

### 第1步：理解主题与行业背景

收到主题后，先用 `batch_web_search` 搜索相关行业背景信息（政策、数据、趋势），搜索3-5个关键词，每词10条结果。

常用搜索方向（根据主题调整）：
- 行业政策：支持、监管、规划
- 行业数据：市场规模、增长率、头部企业
- 行业趋势：转型、升级、整合、出海

### 第2步：确定结构

根据同期声数量确定结构：

**单段同期声（1人1段）：**
```
【标题】
【导语】
【解说词】（行业背景+新闻由头）
【同期声】（姓名+职务+讲话原文，原文保留）
【解说词】（收尾，呼应主题）
```

**多段同期声（1人多段/多人多段）：**
```
【标题】
【导语】
【解说词】
【同期声】第一人
【解说词】
【同期声】第二人（以此类推）
【解说词】收尾
```

### 第3步：撰写各部分内容

**【标题】**
- 字数：12-20字
- 格式：居中，不加粗，无【】符号
- 要求：概括核心事实，带数据或动作词更佳
- 示例：`城市更新驱动旧梯改造需求释放 外资企业加速布局存量市场`

**【导语】**
- 字数：80-150字
- 格式：段落开头标注【导语】，正文紧跟其后
- 要求：交代新闻由头（时间/地点/事件），点明核心看点，自然引出解说词
- 语言：平实，可有一两句稍长复合句，避免直播腔

**【解说词】**
- 字数：每段100-180字
- 格式：段落开头标注【解说词】，正文换行
- 要求：
  - 语言平实流畅，可读性强
  - 融入行业背景（数据、政策、趋势）
  - 不修改同期声内容，在解说词中不重复同期声句子
  - 解说词之间逻辑连贯
  - 信息来源要可信（国家统计局、行业协会、权威媒体等）

**【同期声】**
- 格式：`【同期声】姓名 职务：`后直接接讲话原文
- 要求：
  - **原文完整保留**，包括停顿标记（……）、语气词、重复词
  - 不删改、不润色、不补充
  - 如同期声分段多段，在每段前标注【同期声】+姓名职务
  - 同期声与解说词之间用空行分隔

### 第4步：生成 Word 文档

使用 minimax-docx skill 输出文档：

**文档格式规范：**
- 页面：A4
- 页边距：上1440、下1440、左1800、右1800（EMU单位）
- 正文字体：宋体/SimSun，等宽提示标签用黑体/SimHei
- 正文字号：12pt（24半磅）
- 行距：1.15倍行距（line="360" lineRule="auto"）
- 标题：居中，黑体，12pt，无下划线
- 【解说词】【导语】【同期声】标签：黑体，12pt，加粗

**Word文档输出流程（C#）：**
1. 使用 `scripts/dotnet/MiniMaxAIDocx.Cli` 的 `create` 命令
2. 配置参数：`--type memo`，`--page-size a4`，`--margins standard`
3. 或直接用 C# 脚本写入结构化段落（参考 Scenario A 流程）

**文档输出路径：** `/workspace/output/YYYYMMDD_新闻标题.docx`

### 第5步：告知用户

- 告知文件路径
- 告知预估时长（解说词约120字/10秒，同期声按实际时长估算）
- 如有数据来源，说明来源

## 字数与时长参考

| 内容 | 字数 | 预估时长 |
|------|------|---------|
| 标题 | 12-20字 | - |
| 导语 | 80-150字 | 15-20秒 |
| 每段解说词 | 100-180字 | 15-25秒 |
| 每段同期声 | 按实际，原文保留 | 按录音实际时长 |
| 单条完整新闻 | 400-700字 | 1分30秒-2分30秒 |

## 注意事项

- 同期待声**原文保留**，这是最重要的原则
- 解说词要"配音友好"：避免超长从句，多用短句，朗读流畅
- 不确定的数据必须搜索核实，不编造
- 财经频道风格：信息量大、有深度、引用权威来源
