# 美术资产命名规范参考

## 角色资源
```
char_[name]_[type]_[variant]_[state].ext
示例: char_hero_sheet_idle_normal.png
```

## 场景资源
```
scn_[location]_[type]_[variant].ext
示例: scn_forest_bg_day_v1.png
```

## UI资源
```
ui_[category]_[name]_[state].ext
示例: ui_btn_confirm_normal.svg
```

## 3D资源
```
3d_[type]_[name]_[variant].ext
示例: 3d_prop_tree_oak_v1.glb
```

# 风格指南参考

## 常见游戏风格
- **Low Poly**: 低多边形风格，适合休闲游戏
- **Anime**: 二次元/日式动漫风格
- **Realistic**: 写实风格
- **Pixel Art**: 像素艺术
- **Cartoon**: 卡通风格

## 输出分辨率标准
| 用途 | 最低分辨率 | 推荐分辨率 |
|------|-----------|-----------|
| 图标 | 64x64 | 256x256+ |
| 角色 | 512x512 | 1024x1024+ |
| 场景 | 1920x1080 | 4K |
| UI | 可缩放SVG | 2x/3x PNG |
