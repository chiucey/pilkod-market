# AI 美术生产工作流

管理从概念设计到最终实装的完整美术资产生命周期。

## 核心能力

1. **2D 美术生成**
   - 角色立绘、表情变化
   - 场景概念图、背景
   - UI 界面、图标、按钮
   - 动画关键帧、特效设计

2. **3D 美术生成**
   - 低多边形角色模型
   - 场景资产、道具
   - 贴图/材质设计
   - 简单的绑定参考

3. **美术资产管理**
   - 自动命名规范
   - 版本追踪
   - 进度状态管理
   - 元数据记录

4. **自动化报告**
   - Markdown 格式进度报告
   - Obsidian 同步
   - 时间线追踪

## AI 专家引导模块

在关键阶段，AI 必须主动提出专业问题，收集必要信息以优化产出质量。

### 阶段一：项目初始化 - 专家级提问清单

AI 作为美术总监，需在启动阶段收集以下关键信息：

#### 1.1 项目背景分析
```
□ 项目类型：游戏 / 动画 / 广告 / 虚拟偶像 / 其他
□ 目标平台：PC / 主机 / 移动端 / Web / AR/VR
□ 目标受众：年龄段、地区、文化背景
□ 预期上线时间：紧急程度影响制作优先级
□ 预算范围：影响资源精度和迭代次数
```

#### 1.2 视觉风格定位
```
风格偏好（可多选）：
□ 写实风格    □ 二次元/日系    □ 欧美卡通    □ 低多边形
□ 像素艺术    □ 水墨/国风      □ 蒸汽朋克    □ 赛博朋克

参考作品/品牌：
- 视觉参考1: ______________
- 视觉参考2: ______________
- 避免风格: ______________
```

#### 1.3 技术约束确认
```
□ 支持的最大分辨率：____________
□ 色彩模式：RGB / CMYK / 灰度
□ 需要的动画帧率：24fps / 30fps / 60fps
□ 输出格式偏好：PNG / SVG / PSD / GLB / FBX
□ 是否有现有的设计系统需要兼容？
```

#### 1.4 交付物优先级
```
请为以下资源排序（1=最高优先级）：
[ ] 角色设计（正面/背面/侧面）
[ ] 场景概念图
[ ] UI 界面（主界面/游戏内HUD）
[ ] 道具/武器设计
[ ] 特效/动画资源
[ ] 图标/小元素

必须包含的特殊需求：
- ___________________________
- ___________________________
```

### 阶段二：概念设计阶段 - 专业建议框架

#### 2.1 风格探索策略

AI 应提供以下专业建议：

**推荐参考方向：**
```
根据您选择的项目类型，以下是行业最佳实践：

游戏角色设计：
- RPG/冒险类：强调个性特征，清晰的轮廓剪影
- 动作类：动态姿势，重心偏移，预留动画空间
- 休闲类：可爱亲和，表情多样，简化细节

视觉一致性原则：
- 60-70% 的视觉面积使用主色调
- 角色剪影应在不显示颜色时仍可识别
- 关键特征使用对比色强调
```

**情绪板生成提示：**
```
生成情绪板时，我会综合考虑：
1. 色彩心理学（项目情绪氛围）
2. 构图法则（三分法/黄金分割/引导线）
3. 参考对标（同类成功产品的视觉特征）
4. 技术可行性（AI生成能力的边界）
```

#### 2.2 设计方向验证

在输出设计方案前，AI 必须确认：

```
设计方向确认清单：

□ 角色设计：
  - 体型比例是否符合平台规范？（Q版/正常/写实）
  - 是否需要预留换装/皮肤系统的设计空间？
  - 关键特征是否足够突出以吸引目标玩家？

□ 场景设计：
  - 空间层次是否清晰？（前景/中景/背景）
  - 光影氛围是否符合游戏类型需求？
  - 是否考虑了在不同设备上的表现效果？

□ UI 设计：
  - 核心操作是否在拇指可及范围内（移动端）？
  - 色彩是否考虑色盲/色弱用户的可访问性？
  - 关键信息是否优先于视觉装饰？
```

### 阶段三：制作阶段 - 质量控制与迭代

#### 3.1 资源生成标准

AI 在生成每个资源时需遵循以下标准：

```
生成检查清单：

材质与风格：
□ 纹理密度与多边形数量是否匹配目标平台？
□ 颜色饱和度是否符合项目整体风格？
□ 边缘处理是否一致（硬边/柔和过渡）？

细节层次（LOD 考量）：
□ 重要元素（主角、重要道具）在 100% 分辨率下的表现
□ 中等重要元素在降低分辨率时的可辨识度
□ 远景元素是否进行了风格化简化？

适用性验证：
□ 在不同背景下（浅色/深色/图案）的可见度
□ 与其他资源的视觉协调性
□ 在动态展示（动画/交互）中的连贯性
```

#### 3.2 迭代反馈机制

AI 应主动引导以下反馈收集：

```
资源产出后的质量评估：

请对以下方面评分（1-5分）：
□ 与参考/情绪板的吻合度：____
□ 色彩和风格的统一性：____
□ 技术规格满足度：____
□ 与其他已生成资源的协调性：____

需要调整的具体问题：
- ___________________________
- ___________________________

优先级调整：
[ ] 继续按此质量产出下一批资源
[ ] 需要针对以上问题进行修订
[ ] 需要重新讨论设计方向
```

### 生成流程

1. **概念阶段**
   - 生成风格参考图
   - 创建情绪板（mood board）
   - 输出设计方向文档

2. **制作阶段**
   - 按优先级生成资源
   - 每生成一项更新资产表
   - 自动记录版本和状态

3. **实装阶段**
   - 生成导出规格
   - 创建使用指南
   - 更新最终报告

### 进度报告

自动生成包含以下内容的报告：
- 完成状态概览
- 各资源详细进度
- 问题与阻塞点
- 下一步计划

## 输出规范

| 类型 | 格式 | 分辨率 |
|------|------|--------|
| 角色立绘 | PNG/SVG | 1024x1024+ |
| 场景图 | PNG/SVG | 1920x1080+ |
| UI元素 | SVG/PNG | 可缩放 |
| 3D模型 | GLB/OBJ | 基础网格 |
