# 行业资讯技能

## 概述

行业资讯技能专注于深度市场研究与战略分析，通过系统化的信息收集、数据分析和洞察提炼，为企业决策提供有力支撑。本技能产出结构化、专业化的行业研究报告。

## 设计风格规范

### 配色方案

| 用途 | 颜色 | 色值 |
|------|------|------|
| 主色调 | 深藏青色 | #1B2E4B |
| 辅助色 | 中蓝色 | #3B5998 |
| 点缀色 | 青绿色 | #4DB6AC |
| 背景色 | 浅灰蓝 | #F5F7FA |
| 文字色 | 深灰色 | #2C3E50 |

### 布局规范

1. **顶部核心区 (Hero Section)**
   - 大面积深色背景突出核心主题
   - 主标题使用引号强调关键词
   - 底部采用斜切线设计增加动感

2. **导航栏**
   - 深蓝色水平导航栏
   - 列出报告主要章节

3. **内容卡片区**
   - 白色圆角卡片，带微弱阴影
   - 模块化布局，便于阅读

4. **数据可视化区**
   - 环形图：展示占比分布
   - 横向柱状图：展示对比数据
   - 面积折线图：展示趋势变化
   - 颜色需与图例一一对应

### 排版规范

- **标题系统**：
  - 主标题：最大字号，加粗
  - 章节标题：深蓝色，下方配青色装饰短线
  - 卡片标题：居中，加粗
- **字体**：无衬线字体（如微软雅黑）
- **对齐**：标题居中，正文左对齐
- **间距**：大量留白，保持呼吸感

## 工作流程

### 步骤 1：需求解析

分析用户问题，确定：
- 行业范围与主题
- 分析深度与角度
- 报告用途与受众

### 步骤 2：信息收集

使用网络搜索收集：
- 行业最新动态与政策
- 市场规模与增长数据
- 主要参与者和竞争格局
- 典型案例与产业链结构

### 步骤 3：深度分析

基于收集的信息，进行：
- 市场结构分析（供给端、需求端、渠道）
- 政策影响评估
- 趋势预测与机会识别
- 问题诊断与对策建议

### 步骤 4：报告生成

按照以下结构生成报告：

```
# 主标题（政策/主题关键词）
## 副标题/导语

### 一、行业背景与市场规模
- 市场数据
- 增长趋势

### 二、主要回收/处理渠道
- 渠道分类
- 各渠道占比

### 三、核心处理环节
- 分类暂存
- 专业化拆解
- 资源再生

### 四、政策监管与环境效益
- 全程可追溯管理
- 环境效益量化评估

### 五、现存问题及对策建议
- 现存问题
- 对策建议
```

### 步骤 5：数据可视化

- 根据内容类型选择合适的图表
- 确保图表颜色与报告整体风格一致
- 添加清晰的图例和数据标签

## 输出要求

1. **专业性**：使用行业术语，数据来源可靠
2. **实用性**：结论明确，建议可操作
3. **可视化**：适当使用图表增强表达
4. **时效性**：关注最新政策和市场动态

## 适用场景

- 行业趋势分析报告
- 政策影响评估研究
- 市场机会识别分析
- 竞争格局研究报告
- 产业链研究分析
- 企业战略决策支持
