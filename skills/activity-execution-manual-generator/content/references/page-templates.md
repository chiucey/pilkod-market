# 活动执行手册 - 页面模板库

## 一、页面类型分类

| 类型 | 说明 | 适用部分 |
|------|------|----------|
| 封面页 | 标题、版本、日期 | 总纲 |
| 目录页 | 内容导航 | 总纲 |
| Charter页 | 使命/目标/指标/边界 | 总纲 |
| RACI页 | 角色职责矩阵 | 总纲 |
| Risk页 | 风险登记 | 总纲 |
| Checklist页 | 任务清单 | 机制执行 |
| 附录页 | 模板/通知 | 附录 |
