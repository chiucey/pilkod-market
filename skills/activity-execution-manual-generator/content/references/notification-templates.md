# 通知类模板库

## 一、通知分类

| 类型 | 编号 | 触发时机 |
|------|------|----------|
| 启动公告 | A1 | 活动正式开始前 |
| 报名开启 | A2 | 开始接受报名/参与 |
| 截止提醒 | A3 | 临近截止时间 |
| 结果公布 | A4 | 结果确定后 |
| 变更通知 | A5 | 规则/时间调整 |
| 获奖通知 | A6 | 特定场景 |

---

## 二、邮件标准格式

### 2.1 标准头部

```markdown
收件人: {{RECIPIENT}}
抄送: {{CC}}
主题: 【{{PROJECT_NAME}}】{{NOTIFICATION_TITLE}}
优先级: {{PRIORITY}}
```

### 2.2 标准正文结构

```markdown
## {{NOTIFICATION_TITLE}}

### {{SUBTITLE}}

尊敬的 {{AUDIENCE}}：

[开场问候]

### 一、[内容主题1]
[正文内容1]

### 二、[内容主题2]
[正文内容2]

### 三、行动项
- [ ] [行动项1]
- [ ] [行动项2]

### 四、相关链接
- 报名入口：{{REGISTRATION_URL}}
- 详情页：{{INFO_URL}}
- FAQ：{{FAQ_URL}}

---
如有疑问，请联系 {{CONTACT_PERSON}}（{{CONTACT_EMAIL}}）

{{SENDER_NAME}}
{{DATE}}
```

| `{{REG_URL}}` | 报名链接 | https://... |
