# 公众号文章润色 Skill（合并版）

把 AI 写的文章，变成人写的文章。

## 什么时候用

- 用户说"文章AI味太重""帮我润色一下""把语气改自然一点"
- 用户说"humanize""去AI味""让文章读起来像人写的"
- 需要把 AI 生成的文本改得更自然、更有温度

## 工作流程

### Step 1：读取原文

读取 `/workspace/output/wechat-articles/` 目录下的 Markdown 文件，或用户提供文本。

### Step 2：AI 味诊断

按以下清单逐项检查原文（基于 Wikipedia AI Writing Signs + 公众号风格标准）：

**词汇层面：**
- 是否有"首先、其次、此外、综上所述、值得注意的是"（AI 连接词）
- 是否有"非常、极其、相当、简直"（AI 程度副词）
- 是否有空洞的"强大、卓越、极致、非凡"（AI 形容词）
- 是否有 tricolon（三项并列的华丽排比）

**句式层面：**
- 是否有大量"XXX的XXX的XXX"（多项修饰语叠加）
- 是否句句都以动词开头、过于规整（AI 节奏单一）
- 是否有破折号开头的解释说明（AI 习惯用破折号）

**逻辑层面：**
- 是否有 superficial -ing 分析（"通过XXX，我们可以看到..."）
- 是否有 vague attribution（"研究表明""数据显示"无来源）
- 是否逻辑跳跃但用过度词汇遮掩

**情感层面：**
- 是否过于正向/ promotional（AI 的"安全讨好"倾向）
- 是否有 negative parallelism（双重否定句式过多）

### Step 3：生成润色版

**核心原则：**
- 句子有多短就多短，能断句就断句
- 删除所有 AI 连接词，替换为简短口语表达
- 删除空洞形容词，替换为具体细节
- 保留原文结构和核心信息不变
- 注入真实个人视角和感受（不创造事实）
- 结尾有 call-to-action 或开放讨论

**口语化替换参考：**
| AI 写法 | 自然写法 |
|---|---|
| 首先、其次、最后 | （直接开始，或用"刚讲到""接着"） |
| 此外 | 而且、不过 |
| 综上所述 | 总之、话说回来 |
| 值得注意的是 | 说白了 |
| 非常感谢 | 谢谢（就够了） |
| 强大的功能 | 用起来顺手的功能 |
| 卓越的体验 | 真正用下来不错的体验 |

### Step 4：输出格式

润色后的完整 Markdown 文章，标注修改处（如有需要可输出对比）。

## 注意事项

- 不改变文章的核心信息和观点
- 不添加未经用户确认的新事实
- 保持公众号排版风格（短段落、分点清晰）
- 如原文已很自然，可直接跳过润色并告知用户
