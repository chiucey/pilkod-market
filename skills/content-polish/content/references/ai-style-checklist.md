# AI味诊断清单

逐项检查原文，存在任意一项即是"AI味"信号，需要润色。

## 句式类

- [ ] 大量出现"首先、其次、此外、最后、综上所述"
- [ ] 段落开头使用"值得注意的是""这意味着""从某种角度来说"
- [ ] 句子以"可以""应当""需要"开头（命令式语气过强）
- [ ] 超过3个"的"字连用（主谓宾嵌套过深）

## 结构类

- [ ] 每个要点都是"是什么-为什么-怎么做"三段式
- [ ] 列表用"第一、第二、第三"而非更自然的节奏
- [ ] 每个案例后面都有"这说明……"的过度总结
- [ ] 结语必是"综上所述"开头的气泡总结

## 词汇类

- [ ] 出现"从实践来看""从数据来看""研究表明"
- [ ] 使用"有效""显著""至关重要"等夸大词
- [ ] "这意味着……"出现超过3次
- [ ] 用"我们"而不是"你"或"老板"

## 温度类

- [ ] 没有一句是"人"会说的话
- [ ] 金句是道理而不是感受
- [ ] 没有一句能让读者想说"对！"的共鸣句
