# 爆款故事生成器

> 8维标签碰撞，一键生成爆款故事概念

## 功能介绍

用标签碰撞生成有记忆点、有话题度的故事灵感。从一句话概念到完整梗概+人设速写。

**核心方法论**：8维标签矩阵 × 18种戏剧内核 × 近5年平台爆款数据 = 高命中率灵感引擎。

## 适用场景

- 想找故事灵感 / 写作方向
- 需要爆款选题建议
- 需要标签组合碰撞出新概念
- 需要设计有记忆点的人设
- 需要平台适配建议（番茄/短剧/爱优腾长剧）

## 核心能力

1. **标签碰撞**：8个维度各抽标签强制碰撞，寻找反差感/新鲜感/冲突感最强组合
2. **一句话钩子**：每个概念浓缩成一句话让人想看
3. **人设记忆点**：角色自带截图转发属性——身份反差/视觉锚点/专属标签
4. **话题度预判**：识别天然自带社交传播基因的概念
5. **平台适配**：根据目标平台调整标签权重

## 8维标签矩阵

- 维度1：戏剧内核（18种）
- 维度2：题材赛道
- 维度3：人设标签
- 维度4：世界观设定
- 维度5：情感引擎
- 维度6：视觉锚点
- 维度7：社交话题
- 维度8：平台适配

## 输出示例

每次生成至少3个方向，包含：
- 一句话概念（≤50字）
- 人设记忆点三件套
- 完整梗概（≤800字）
- 平台适配度评分
- 话题度预判

## 数据来源

番茄小说官方分类+热推数据、红果/抖音短剧爆款排行、爱优腾芒剧场分类、ADX短剧版2025H1榜单、阅文/晋江销售数据、中国社科院网络文学报告。
