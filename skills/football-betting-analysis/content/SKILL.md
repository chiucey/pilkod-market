# 竞彩足球投注分析技能

## 一、核心数据源

### 赔率查询（每次分析前必须执行）
- **赔率数据来源**：https://www.lottery.gov.cn/jc/jsq/zqspf/
- 使用 `extract_content_from_websites` 工具提取数据
- 如提取失败，使用之前提取的数据文件：`/workspace/extract/raw_content/www_lottery_gov_cn_*.txt`

### 赛果查询（赛后比对时使用）
- **赛果数据来源**：https://www.sporttery.cn/jc/zqsgkj/
- 使用 `extract_content_from_websites` 工具提取结果

## 二、投注类型说明

### 单关投注
- 用户会告诉您哪些比赛支持单关投注（标记为"单"）
- 单关比赛可单独投注，也可与其他比赛组成2串1

### 2串一投注
- 所有查询到的比赛都可以自由组合成2串1
- 单关比赛也可以和非单关比赛组成2串1

## 三、分析流程

### 步骤1：数据提取
1. 从 lottery.gov.cn 提取赔率数据
2. 记录所有比赛的胜平负赔率（主胜/平/客胜）
3. 确认哪些比赛是单关

### 步骤2：伤病与战意分析
对每场比赛进行以下分析：
1. **伤病情况**：搜索两队的伤病信息
2. **战意评估**：分析联赛形势、排名、目标
3. **赔率分析**：计算隐含概率，与市场支持率对比

### 步骤3：投注建议
1. 对单关比赛给出独立投注建议
2. 推荐2串1组合方案
3. 区分稳健型/平衡型/高回报型组合

## 四、投注建议格式

### 单关比赛分析
```
| 编号 | 比赛 | 推荐选项 | 赔率 | 信心度 |
|------|------|----------|------|--------|
```

### 2串1组合
```
| 组合 | 比赛1 | 比赛2 | 总赔率 |
|------|-------|-------|--------|
```

## 五、投注原则

### 只分析胜平负
- **仅分析胜平负赔率**，不分析让球赔率
- 每个选项赔率必须来自原始数据

### 赔率计算
- 2串1总赔率 = 选项1赔率 × 选项2赔率

### 分析必须包含
1. 赔率分析
2. 伤病情况
3. 战意评估
4. 投注建议

## 六、档案保存

### 分析报告保存位置
- 路径：`/workspace/analysis_archive/`
- 文件命名：`betting_report_YYYY_MM_DD.md`

### 档案内容
1. 所有比赛的赔率数据
2. 每场比赛的分析
3. 投注建议
4. 比赛结果记录表格（用于赛后填写）

## 七、赛后比对

当用户要求查询比赛结果时：
1. 从 sporttery.cn 提取赛果
2. 与分析报告中的预测进行比对
3. 更新档案中的结果记录
