# 浙江电网负荷预测技能

## 技能概述

本技能用于基于实际负荷数据和气象条件，预测特定日期（0030-2400每半小时）的统调负荷曲线。适用于电力现货交易、日前市场申报等场景。

---

## 输入数据要求

用户需提供以下数据：

| 数据类型 | 说明 | 格式 |
|---------|------|------|
| 预测日期 | 需要预测负荷的目标日期 | YYYY-MM-DD |
| 预测日期星期几 | 用于判断是否周末 | 周一至周日 |
| 实际负荷数据 | 参考日期的半小时负荷值 | 0030-2400共48个点 |
| 实际负荷日期星期几 | 参考日期的类型 | 周一/周二.../周六/周日/非周末 |
| 预测日气温 | 预测日期的气温数据 | 摄氏度 |
| 参考日气温 | 实际负荷对应日期的气温 | 摄氏度 |
| 实际光伏出力 | 0630-1730实际光伏值 | 可选 |
| 日前光伏出力 | 预测日日前光伏值 | 可选 |
| 光伏系数 | 各时刻差值系数 | 可选 |

---

## 预测规则体系

### 第一阶段：基础负荷调整（0030-0800）

#### 规则1：周一预测调整

**适用条件**：预测日为周一，且参考实际负荷日期为非周一、非周日（非周末工作日）

**调整规则**：

| 时段 | 调整量 | 说明 |
|------|--------|------|
| 0030-0430 | **-2500** | 每半小时减少2500 |
| 0500 | **-2000** | 该点减少2000 |
| 0530-0600 | **-1000** | 每半小时减少1000 |

**反向条件**：若预测日为非周一，参考日为周一，则在参考负荷基础上**增加**对应数值。

#### 规则2：周日参考数据预测周一

**适用条件**：使用周日的实际负荷数据预测周一的负荷

**调整规则**：

| 时刻 | 调整量 | 说明 |
|------|--------|------|
| 0700 | **+3000** | 该时刻增加3000 |
| 0730-0800 | **+4000** | 每半小时增加4000 |

**反向条件**：若用周一数据预测周日，则在周一数据基础上**减少**对应数值。

---

### 第二阶段：温度调节（0030-2400全天）

**规则说明**：基于预测日与参考日的温度差异，对全天负荷进行修正。

**调整公式**：
```
温度差值 = 预测日气温 - 参考日气温
调整量 = 温度差值 × 1500（每度）
```

**适用时段**：0030-2400，每半小时一个点

**示例**：
- 预测日气温30°C，参考日气温25°C，温差+5°C
- 每半小时负荷增加：5 × 1500 = 7500

---

### 第三阶段：周末效应调整

**适用条件**：预测日为周六或周日

#### 周六预测规则

| 时段 | 调整量 | 说明 |
|------|--------|------|
| 1700-2000 | **-2000** | 每半小时减少2000 |
| 2030-2400 | **-1500** | 每半小时减少1500 |

#### 周日预测规则

| 时段 | 调整量 | 说明 |
|------|--------|------|
| 0700 | **-3000** | 该时刻减少3000 |
| 0730-1700 | **-4000** | 每半小时减少4000 |
| 1730-2000 | **-6000** | 每半小时减少6000 |
| 2030-2400 | **-3500** | 每半小时减少3500 |

**反向条件**：预测非周末时使用周末数据，需**增加**对应数值。

---

### 第四阶段：光伏出力叠加（0630-1730）

**规则说明**：将光伏出力影响叠加到统调负荷预测中。

**计算公式**：
```
差值 = 实际光伏出力 - 日前光伏出力
分时出力 = 差值 × 时刻系数
新统调负荷 = 实际统调负荷 + 分时出力
```

#### 特殊日期叠加规则

**周六实际数据预测非周末**：

| 时段 | 调整量 | 说明 |
|------|--------|------|
| 1700-1730 | **+2000** | 每半小时增加2000 |

**周日实际数据预测非周末**：

| 时段 | 调整量 | 说明 |
|------|--------|------|
| 0700 | **+2000** | 该时刻增加2000 |
| 0730-1700 | **+4000** | 每半小时增加4000 |
| 1730 | **+6000** | 该时刻增加6000 |

**反向条件**：日期条件相反时，需**减少**对应时刻负荷。

---

## 完整预测流程

### Step 1: 初始化基础负荷

从用户提供的实际负荷数据（参考日数据）作为起点。

### Step 2: 应用周一调整（如适用）

判断是否满足周一预测的特殊调整条件，执行相应的增减操作。

### Step 3: 温度修正

计算预测日与参考日的温度差，对全天48点负荷进行统一修正。

### Step 4: 周末效应叠加（如适用）

若预测日为周末，执行第三阶段的周末负荷调整。

### Step 5: 光伏出力叠加（如适用）

在0630-1730时段，结合光伏出力差值和系数，生成新的统调负荷曲线。

### Step 6: 输出最终预测结果

生成0030-2400共48个点半小时负荷曲线。

---

## 数据格式说明

### 半小时时刻表示

采用HHMM格式，表示该半小时的起始时刻：

| 时刻代码 | 含义 | 对应时间 |
|---------|------|---------|
| 0030 | 0:00-0:30 | 凌晨时段 |
| 0100 | 1:00-1:30 | 凌晨时段 |
| ... | ... | ... |
| 0700 | 7:00-7:30 | 早高峰前 |
| ... | ... | ... |
| 1700 | 17:00-17:30 | 晚高峰 |
| ... | ... | ... |
| 2400 | 24:00 | 日终 |

全天共48个点半小时数据。

### 星期判断标准

- 周一至周五：工作日（非周末）
- 周六：周六
- 周日：周日

---

## 输出格式

技能将输出：

1. **预测负荷曲线表**：0030-2400共48点负荷值
2. **调整明细**：列出各项调整的时段和数值
3. **汇总数据**：
   - 预测日期
   - 预测日星期
   - 预测日气温
   - 总负荷（日/夜/峰谷）

---

## 使用示例

**用户输入**：
- 预测日期：2024-06-10（周一）
- 参考实际负荷日期：2024-06-05（周三）
- 参考负荷：0030-0800各点半小时值
- 预测日气温：28°C
- 参考日气温：24°C
- 实际光伏出力：0630-1730光伏值
- 日前光伏出力：0630-1730日前值
- 光伏系数：各时刻系数值

**处理过程**：
1. 以参考负荷为基准
2. 因预测周一且参考为非周末，执行周一调整（-2500/-2000/-1000）
3. 温度差+4°C，每点加6000
4. 0630-1730叠加光伏差值
5. 输出最终48点预测负荷

---

## 注意事项

1. 所有调整量均为半小时维度的负荷变化值
2. 温度调节影响全天48点，需确保温度数据完整
3. 光伏叠加仅限0630-1730时段
4. 周末效应与其他规则可叠加执行
5. 反向条件时，调整方向取相反数
6. 所有数值以MW为单位
