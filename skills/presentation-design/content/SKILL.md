# 演示文稿设计 (Presentation Design)

## 核心理念

**Max-De$ign 主张：要么设计，要么被设计。**

好的演示不仅是信息的堆砌，而是通过精心设计的视觉叙事，传递观点、说服受众、留下深刻印象。

---

## 1. 演示设计框架

### 演示类型

| 类型 | 目的 | 时长 | 受众特征 | 设计重点 |
|------|------|------|----------|----------|
| 商业提案 | 说服决策 | 15-30min | 高管/客户 | 专业、数据支撑 |
| 公司介绍 | 建立认知 | 5-15min | 合作伙伴 | 品牌调性、实力展示 |
| 工作汇报 | 展示成果 | 10-20min | 领导/同事 | 成果导向、逻辑清晰 |
| 培训课件 | 传授知识 | 30-60min | 学员 | 结构清晰、案例丰富 |
| 融资路演 | 获得投资 | 5-10min | 投资人 | 增长故事、盈利预期 |
| 产品发布 | 发布新品 | 20-60min | 媒体/用户 | 创新亮点、情感共鸣 |

## 2. 内容策划

### 幻灯片规划表

| 序号 | 幻灯片标题 | 类型 | 核心信息 | 视觉建议 | 时长 |
|------|-----------|------|----------|----------|------|
| 1 | 封面 | 标题页 | 主题/演讲者 | 大标题+品牌 | 30s |
| 2 | 目录 | 导航页 | 演讲大纲 | 简洁列表 | 15s |
| 3 | 背景/问题 | 内容页 | 现状分析 | 数据图表 | 2min |
| ... | ... | ... | ... | ... | ... |

### 信息优先级

| 层级 | 内容 | 数量 | 占比 |
|------|------|------|------|
| 核心信息 | 一句话能说清的结论 | 1个/页 | 即刻传达 |
| 支撑信息 | 2-3 个关键论点 | 2-3个 | 理解强化 |
| 背景信息 | 详细数据、案例 | 按需 | 参考补充 |

## 3. 视觉设计系统

### 幻灯片尺寸

| 规格 | 尺寸 | 比例 | 适用场景 |
|------|------|------|----------|
| 16:9 (标准) | 1920×1080 | 1.778 | 大多数场景 |
| 16:9 (高清) | 2560×1440 | 1.778 | 大屏幕 |
| 4:3 (传统) | 1024×768 | 1.333 | 传统投影 |
| 方形 | 1080×1080 | 1:1 | 社交媒体 |

### 品牌元素应用

```
┌─────────────────────────────────────────────────────────────┐
│                    演示品牌规范                            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   Logo 位置                                                │
│   ├── 封面页: 底部居中或右下角                             │
│   ├── 内容页: 右下角 (淡化处理)                            │
│   └── 封底页: 底部居中                                     │
│                                                             │
│   色彩应用                                                │
│   ├── 主色调: 品牌色 ≤ 60%                                │
│   ├── 背景色: 白色或浅灰 80%                              │
│   ├── 强调色: 品牌辅色 ≤ 20%                              │
│   └── 文字色: 深灰 #333 或 #1a1a1a                        │
│                                                             │
│   字体规范                                                │
│   ├── 标题: 品牌字体，32-48pt，bold                       │
│   ├── 正文: 系统字体，18-24pt，regular                    │
│   └── 注释: 14-16pt，灰色                                │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 布局类型

| 布局 | 形式 | 适用场景 | 示例 |
|------|------|----------|------|
| 全屏图 | 大背景+文字 | 封面/分隔 | 标题+关键词 |
| 左右分栏 | 50/50 或 40/60 | 对比/说明 | 左图右文 |
| 内容+侧栏 | 主内容+笔记 | 详细内容 | 带侧边说明 |
| 卡片式 | 多卡片排列 | 特点/步骤 | 3-4卡片 |
| 数据仪表盘 | 数据面板 | 数据展示 | KPI展示 |
| 纯文字 | 居中/左对齐 | 引言/金句 | 核心观点 |

### 排版规范

| 元素 | 字号 | 位置 | 规范 |
|------|------|------|------|
| 页面标题 | 36-44pt | 左上或居中 | 不超过一行 |
| 副标题 | 24-28pt | 标题下方 | 颜色淡化 |
| 正文 | 18-24pt | 内容区 | 行高 1.3-1.5 |
| 注释 | 12-14pt | 底部或侧边 | 淡化处理 |
| 页码 | 12pt | 底部角落 | 格式: 5/20 |

### 间距规范

```
┌─────────────────────────────────────────────────────────────┐
```

## 4. 数据可视化

### 图表选择指南

| 数据类型 | 推荐图表 | 用途 |
|----------|----------|------|
| 趋势 | 折线图 | 展示随时间变化 |
| 占比 | 饼图/环形图 | 展示部分与整体 |
| 比较 | 柱状图/条形图 | 展示项目对比 |
| 关系 | 散点图/气泡图 | 展示关联性 |
| 流程 | 流程图/漏斗图 | 展示步骤 |
| 排名 | 条形图 | 展示排序 |

### 图表设计原则

1. **删除无关元素**：去掉网格线、刻度线等
2. **强化数据元素**：突出数据系列
3. **标注关键数据**：数值、标签直接标注
4. **色彩传达语义**：区分数据或表达正负
5. **选择合适类型**：根据数据关系选图表

## 5. 图标与插图

### 图标使用规范

| 规范 | 说明 |
|------|------|
| 风格统一 | 同一演示使用同系列图标 |
| 尺寸一致 | 同级图标保持相同尺寸 |
| 颜色协调 | 与整体配色系统一致 |
| 简洁清晰 | 避免过于复杂的细节 |

### 图标风格选择

| 风格 | 特点 | 适用场景 |
|------|------|----------|
| 线性 (Line) | 简洁、优雅 | 科技、现代 |
| 填充 (Filled) | 稳重、清晰 | 商务、正式 |
| 双色 | 品牌感强 | 品牌演示 |
| 扁平 | 友好、易懂 | 培训、教育 |

### 图标来源推荐

| 来源 | 风格 | 许可 |
|------|------|------|
| Phosphor Icons | 多种风格 | 开源 |
| Heroicons | 线性/填充 | 开源 MIT |
| Font Awesome | 丰富全面 | 开源/付费 |
| Flaticon | 风格多样 | 免费需署名 |

## 6. 动效与转场

### 动效类型

| 类型 | 说明 | 使用场景 |
|------|------|----------|
| 进入动画 | 元素出现方式 | 内容展示 |
| 强调动画 | 吸引注意力 | 关键数据 |
| 退出动画 | 元素消失 | 页面切换 |
| 转场动画 | 页面切换效果 | 整体风格 |

### 动效参数建议

| 参数 | 建议值 | 说明 |
|------|--------|------|
| 持续时间 | 300-500ms | 不要过慢 |
| 延迟 | 100-200ms | 依次出现 |
| 缓动 | ease-out | 自然感 |
| 重复 | 避免 | 不分散注意 |

### 页面转场

| 转场类型 | 感觉 | 适用场景 |
|----------|------|----------|
| 淡入淡出 | 柔和 | 正式商务 |
| 推进/滑出 | 流畅 | 现代简洁 |
| 翻页 | 传统 | 正式场合 |
| 分割 | 动感 | 创新演示 |

## 7. 演讲技巧

### 演讲结构

```
┌─────────────────────────────────────────────────────────────┐
│                    演讲时间分配                            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   开场 (10%)                                               │
│   └── 吸引注意、建立连接、预告内容                         │
│                                                             │
│   正文 (80%)                                               │
│   ├── 核心论点1 (25%)                                     │
│   ├── 核心论点2 (25%)                                     │
│   └── 核心论点3 (30%)                                     │
│                                                             │
│   结尾 (10%)                                               │
│   └── 总结回顾、呼吁行动、感谢                             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 开场技巧

| 技巧 | 示例 |
|------|------|
| 提问 | "在座有多少人经历过...?" |
| 数据 | "过去一年，我们服务了 100 万用户" |
| 故事 | "三年前，我在一次客户拜访中..." |
| 引言 | "马云说过：..." |
| 视频 | 播放相关短片 |

### 语言技巧

| 技巧 | 说明 | 示例 |
|------|------|------|
| 重复强调 | 关键信息多次出现 | "创新、创新、再创新" |
| 数字说话 | 用数据支撑观点 | "效率提升 300%" |
| 类比比喻 | 复杂问题简单化 | "就像汽车的发动机..." |
| 暂停 | 给观众消化时间 | 关键数据后停顿 |

## 9. 质量检查清单
