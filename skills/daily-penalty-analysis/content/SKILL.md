# SKILL.md — 每日证监会行政处罚分析

## 触发条件
每日早上自动触发（定时任务），对上一日证监会及各省证监局公布的行政处罚案例进行分析。

## 分析框架

### 一、数据来源
- 证监会官网：www.csrc.gov.cn（行政处罚决定书栏目）
- 各省证监局网站：厦门/深圳/广东/北京/上海/江苏/浙江等主要证监局
- 搜索关键词：`site:csrc.gov.cn 行政处罚 2026-XX-XX` 或 `证监会 + 行政处罚 + 具体日期`

### 二、分析维度

#### 1. 案由分类
严格按以下四类归类：
- **信息披露违规**：财务造假、误导性陈述、未按规定披露、虚假记载、重大遗漏等
- **内幕交易**：利用内幕信息交易、泄露内幕信息
- **市场操纵**：操纵证券期货市场价格
- **其他**：证券公司/中介机构违规、违规减持、超比例持股等

#### 2. 案情分析（逐案）
对每个案例分析：
- 当事人
- 违规事实摘要
- 涉案金额/违法所得
- 处罚结果（罚款金额、没收金额、证券市场禁入等）

#### 3. 裁量情节分析（核心重点）
严格对照《中国证监会行政处罚裁量基本规则》（2025年3月1日施行）：

**裁量阶次**（第5条）：不予处罚 → 免予处罚 → 减轻处罚 → 从轻处罚 → 一般处罚 → 从重处罚

**从重处罚情节**（第11条）：
- 严重违反市场公开公平公正原则，可能引发金融风险
- 严重损害投资者权益，影响恶劣
- 涉及行贿或受贿
- 殴打/围攻执法人员、毁损证据、转移涉案财产
- 五年内再次实施同一类型违法行为
- 违法持续时间长、涉及面广、社会危害较大
- 主观过错较大
- 拒不接受调查、提供虚假陈述

**从轻/减轻情节**（第9、10条）：
- 主动采取补救措施，消除危害后果（减轻）
- 受他人严重胁迫或严重诱骗（减轻）
- 主动减轻危害后果（从轻）
- 受他人胁迫或诱骗实施（从轻）
- 主动供述监管机构尚未掌握的违法行为（从轻）
- 如实陈述、积极配合、签署认错认罚具结书（从轻）
- 对资本市场秩序/投资者权益损害较小（从轻）

#### 4. 与近期同类案例对照
- 对比近3个月内同类案由的处罚力度（罚款金额、是否涉及禁入等）
- 分析本案的处罚力度是否偏重或偏轻

#### 5. 监管执法导向研判
综合分析证监会近期（最近1-2个月）的执法重点：
- 哪类违规是打击重点
- 处罚力度趋势（趋严还是趋宽）
- 新型违规形态（如蹭热点、误导性陈述等）的监管态度

### 四、注意事项
- 本分析仅针对已公布的行政处罚决定书/事先告知书，不含监管措施
- "上一日"以文件落款日期或官网公布日期为准
- 如某日无新增案例，输出简短提示即可，不生成完整报告
- 裁量情节分析是核心，每案必写，不可省略
