# PPT备注文件格式规范

## 文件格式要求

### 支持的备注文件格式
- `.txt`（推荐）- 纯文本文件
- `.md` - Markdown格式（会自动转换为纯文本）
- `.rtf` - 富文本格式

### 文件命名规范

**重要**：文件名决定备注导入到哪个幻灯片

命名格式：`[序号]_[可选描述].扩展名`

| 示例 | 对应幻灯片 |
|------|-----------|
| `01.txt` | 第1张幻灯片 |
| `02.txt` | 第2张幻灯片 |
| `03_intro.txt` | 第3张幻灯片 |
| `10_notes.txt` | 第10张幻灯片 |

**命名规则**：
- 序号必须与幻灯片顺序一一对应
- 序号使用阿拉伯数字（1, 2, 3... 或 01, 02, 03...）
- 序号后可用下划线分隔添加描述（可选）
- 文件扩展名必须正确（.txt, .md, .rtf）

### 内容格式

每个文件的内容是该幻灯片的备注文本。

**示例文件 `01.txt` 内容**：
```
这是第一张幻灯片的备注内容。
可以包含多行文字。
```

**示例文件 `03_main.txt` 内容**：
```
这是第三张幻灯片的备注。
可以详细说明演讲要点：
- 要点1
- 要点2
- 要点3
```

## 文件夹结构示例

## 常见问题

### Q: 序号不连续怎么办？
A: 脚本会自动跳过没有对应文件的序号，按实际文件数量匹配幻灯片。

### Q: 文件名有中文可以吗？
A: 不推荐。强烈建议使用阿拉伯数字和英文，确保兼容性。

### Q: 备注内容有特殊字符怎么办？
A: Python-pptx库会处理大部分特殊字符，但建议避免使用Windows文件名不允许的字符（\ / : * ? " < > |）。

### Q: 如何查看哪些备注已成功导入？
A: 打开生成的PowerPoint文件，在"视图"选项卡中选择"演讲者视图"查看备注。
