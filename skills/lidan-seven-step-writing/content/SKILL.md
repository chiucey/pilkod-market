# 李诞七步写作法

源自李诞口述教学的七步写作框架，帮助你将任何复杂概念写得深入浅出。

## 核心目标

让读者不仅"知道是什么"，更能"懂了，还能讲给别人听"——这是内容创作的终极目标。

## 七步框架

### 第一步：开场故事（3分钟抓住注意力）

用一个具体的、有戏剧性的开场场景或故事开头，像脱口秀开场包袱一样炸裂。
- 制造悬念或冲突
- 让读者产生好奇心
- 与主题紧密相关

### 第二步：三种错误答案（先走弯路再给答案）

先展示3个常见的错误理解或做法，让读者产生"我好像也这么想过"的共鸣。
- 错误答案要真实、常见
- 不要直接说"这是错的"
- 制造"原来如此"的快感铺垫

### 第三步：正确答案是...（一句话说清本质）

给出真正的答案，一句话概括核心本质。
- 简洁有力
- 给出可验证的标准
- 让读者有"原来如此"的顿悟感

### 第四步：触类旁通（4-5个领域案例）

用4-5个不同领域的例子来印证这个知识点。
- 涵盖不同场景
- 让知识无处不在
- 帮助读者建立多元认知

### 第五步：对比冲击（用数据制造认知落差）

用具体数据或对比来强化认知。
- 制造认知落差
- 让抽象概念具体化
- 增强说服力

### 第六步：延伸与应用

提供具体的应用场景和行动建议。
- 读者能立即实践
- 解决实际问题
- 给出操作清单

### 第七步：结尾升华（闭环结构）

用精炼的结尾回应开头，形成闭环。
- 留下洞察和余韵
- 呼应开场的故事
- 让读者回味无穷

## 输出格式

当用户输入一个概念时，按照以下格式输出完整文章：

```
【开场故事】
[描述一个具体场景，3分钟内抓住注意力]

【常见的三个误解】
1. [错误理解1]
2. [错误理解2]
3. [错误理解3]

【正确答案】
[一句话核心本质]

【触类旁通】
- [领域1]: [具体案例]
- [领域2]: [具体案例]
- [领域3]: [具体案例]
- [领域4]: [具体案例]

【数据对比】
[用具体数据或对比强化认知]

【实战应用】
[具体可操作的建议]

【结语】
[呼应开场的升华结尾]
```

## 使用方法

直接输入你想讲解的概念，格式如：
- "用七步法讲清楚什么是认知偏差"
- "用李诞方法写什么是内卷"
- "将区块链深入浅出地讲给普通人"

系统将引导你完成从开场到结尾的完整创作流程。
