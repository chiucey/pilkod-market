## 常用公式速查

### 灵敏度计算
```
Sensitivity (dBm) = -174 + NF (dB) + 10*log10(BW) + SNR_req (dB)
```

### 噪声级联（Friis 公式）
```
NF_total = NF1 + (NF2-1)/G1 + (NF3-1)/(G1*G2) + ...
```

### 链路预算
```
Received Power = Tx Power + Tx Gain - Path Loss + Rx Gain
```

### P1dB 与 IP3 关系（近似）
```
IP3 (dBm) ≈ P1dB + 10 dB
```

### 阻抗匹配（Smith Chart）
- Z_L = R + jX
- Y_L = 1/Z_L
- 反射系数 Γ = (Z_L - Z_0)/(Z_L + Z_0)

### S 参数基础
- S11: 输入反射系数
- S12: 反向传输系数
- S21: 正向传输系数
- S22: 输出反射系数

### 波束赋形算法
- 权值计算：w = H^H * s（MR接收）
- MMSE波束赋形：w = (H^H H + σ^2 I)^(-1) H^H s
- 混合波束赋形：W_RF * W_BB ≈ W_opt

### 信道估计（MMSE）
- 估计信道：H_est = R_HH * (R_HH + σ^2 I)^(-1) * Y_pilot / P_pilot

### 信号检测
- ZF检测：x̂ = (H^H H)^(-1) H^H y
- MMSE检测：x̂ = H^H (HH^H + σ^2 I)^(-1) y

### AGC算法
- 自动增益控制：G = P_target / P_measured
- 迭代AGC：G[n+1] = G[n] * α + G_fixed * (1-α)
