# 射频前端技术参考手册

## 1. 射频基础知识

### 1.1 电磁频谱划分
- **HF (High Frequency)**: 3-30 MHz
- **VHF (Very High Frequency)**: 30-300 MHz
- **UHF (Ultra High Frequency)**: 300 MHz - 3 GHz
- **SHF (Super High Frequency)**: 3-30 GHz
- **EHF (Extremely High Frequency)**: 30-300 GHz

### 1.2 常用频段
- **GPS L1**: 1575.42 MHz
- **WiFi 2.4GHz**: 2400-2483.5 MHz
- **WiFi 5GHz**: 5150-5850 MHz
- **WiFi 6E 6GHz**: 5925-7125 MHz
- **LTE Band 1**: 1920-1980 / 2110-2170 MHz
- **5G NR n78**: 3300-3800 MHz
- **5G NR n258**: 24.25-27.5 GHz (毫米波)

## 2. 射频关键指标

### 2.1 增益 (Gain)
- **功率增益 (dB)**: 10 * log10(P_out/P_in)
- **电压增益 (dB)**: 20 * log10(V_out/V_in)
- **天线增益 (dBi)**: 相对于全向天线的增益
- **天线增益 (dBd)**: 相对于偶极子天线的增益

### 2.2 噪声系数与噪声因子
- **噪声因子 (F)**: F = SNR_in / SNR_out
- **噪声系数 (NF)**: NF = 10 * log10(F)
- **级联噪声系数**: F_total = F1 + (F2-1)/G1 + (F3-1)/(G1*G2) + ...

### 2.3 线性度指标
- **P1dB (1dB 压缩点)**: 输出功率比线性预期低 1dB 的点
- **IP3 (三阶截点)**:
  - OIP3 = Pout + (OIP3 - Pout)/2
  - IIP3 = Pin + (OIP3 - Pout)/2
- **IMD3 (三阶互调失真)**: 2*f1 - f2 和 2*f2 - f1 的产物

### 2.4 动态范围
- **SFDR (无杂散动态范围)**: SFDR = (2/3)(IIP3 - No) + (1/3)SNR_req
- **DR (动态范围)**: DR = P_max - P_min

## 3. 阻抗匹配

### 3.1 常用阻抗
- **Z_0 (特性阻抗)**: 50Ω (射频系统标准)
- **Z_L (负载阻抗)**: 实际负载的复阻抗

### 3.2 匹配网络拓扑
- **L 型匹配**: 最简单的两元件匹配
- **π 型匹配**: 三元件，适合高 Q 应用
- **T 型匹配**: 三元件，适合低 Q 应用
- **传输线匹配**: 短路线/开路线

### 3.3 Smith Chart 应用
- 归一化阻抗: z = Z/Z_0
- 导纳: y = 1/z
- 反射系数: Γ = (z-1)/(z+1)

## 4. 滤波器设计

### 4.1 滤波器类型
| 类型 | 特性 | 应用 |
|------|------|------|
| Butterworth | 平滑通带 | 宽带系统 |
| Chebyshev | 纹波通带 | 陡峭过渡带 |
| Bessel | 线性相位 | 脉冲系统 |
| Elliptic | 纹波通带/阻带 | 极陡过渡 |

### 4.2 滤波器实现
- **SAW (声表面波)**: 低于 2.5 GHz，成本低
- **BAW (体声波)**: 2-10 GHz，Q 值高
- **LC (电感电容)**: 低于 1 GHz，可调谐
- **腔体滤波器**: 高功率，基站应用
- **介质滤波器**: 紧凑，高 Q

## 5. 功率放大器

### 5.1 PA 分类
- **Class A**: 导通角 360°，线性最好，效率 25-50%
- **Class B**: 导通角 180°，效率可达 78.5%
- **Class AB**: 导通角 180-360°，平衡线性与效率
- **Class C**: 导通角 < 180°，效率高，线性差
- **Class D/E/F**: 开关模式，高效率

### 5.2 PA 线性化技术
- **DPD (数字预失真)**: 最常用的线性化方法
- **Feedforward**: 宽带线性化
- **Envelope Tracking**: 包络跟踪电源调制
- **Predistortion**: 模拟预失真

## 8. 常用公式速查

### 8.1 基本公式
```
λ = c / f (波长)
f = c / λ (频率)
VSWR = (1+|Γ|)/(1-|Γ|)
|Γ| = (VSWR-1)/(VSWR+1)
```

### 8.2 功率与电压
```
P(dBm) = 10 * log10(P_mW)
V = sqrt(P * R)
```

### 8.3 自由空间路径损耗
```
FSPL(dB) = 20*log10(d) + 20*log10(f) + 32.44
```
其中 d 单位 km，f 单位 MHz

### 8.4 链路预算
```
Rx = Tx + G_tx - PL + G_rx - L_system
```

## 11. 射频系统架构

### 11.1 接收机架构对比

| 架构类型 | 优点 | 缺点 | 典型应用 |
|----------|------|------|----------|
| 超外差 | 高性能、高选择性 | 复杂度高、镜像干扰 | 基站、雷达 |
| 零中频 (ZIF) | 简单、集成度高 | DC偏移、IQ不平衡 | 手机、IoT |
| 低中频 (Low-IF) | 折中方案 | 镜像抑制要求 | 蓝牙、WiFi |
| 射频直采 | 灵活性高 | ADC要求高、功耗大 | SDR、5G |

### 11.2 超外差接收机架构
```
天线 → SAW滤波器 → LNA → 镜像抑制滤波器 → Mixer → IF滤波器 → PGA → ADC
                                    ↓
                              LO (本振)
```
- 镜像抑制比 (IRR): IRR = (1+α²)/(1-α²)，其中α为IQ幅度不平衡度
- 镜频抑制滤波器 (IRF): 需在混频前抑制镜像频率

### 11.3 零中频接收机架构
```
天线 → LNA → I/Q解调器 → 基带滤波器 → PGA → ADC
                    ↓
              LO (本振)
```
- DC偏移自消除：使用数字校准或AC耦合
- 闪烁噪声：1/f噪声在基带显著

### 11.4 5G NR 射频前端架构

#### Sub-6GHz (FR1) 架构
```
TRX链路:
天线阵列 → 开关矩阵 → 双工器 → LNA → 混频器 → 滤波器 → ADC
                        ↓
                    PA (发射)
```

#### 毫米波 (FR2) 架构
```
天线模块 → 相控阵列 → 射频链路 → I/Q调制/解调 → 中频 → ADC/DAC
```

### 11.5 Massive MIMO 系统架构
- **传统MIMO**: 8T8R/16T16R
- **Massive MIMO**: 64T64R/128T128R/256T256R
- **有源天线系统 (AAS)**: 集成天线与射频单元
- **数字波束赋形**: 每个天线通道独立ADC/DAC
- **混合波束赋形**: 减少射频链路数量

### 11.6 射频前端模组架构

#### 典型射频前端模组
- **FEM (前端模块)**: PA + LNA + 开关
- **TRX (收发模块)**: 完整的收发链路
- **DFE (数字前端)**: 数字信号处理
- **LNA Bank**: 多频段LNA阵列

## 12. 射频信号处理算法

### 12.1 波束赋形算法

#### 基本原理
- **模拟波束赋形**: 移相器 + 功分网络
- **数字波束赋形**: 每个天线通道独立DAC/ADC
- **混合波束赋形**: 模拟子阵列 + 数字权值

#### 权值计算算法
```
MR (最大比合并): w = H^H
ZF (迫零): w = (H^H H)^(-1) H^H
MMSE: w = (H^H H + σ²I)^(-1) H^H
```

#### 混合波束赋形
```
目标: W_opt = W_RF × W_BB
约束: W_RF 中的元素幅度固定
算法: 迭代优化/稀疏重构
```

### 12.2 信道估计算法

#### 导频辅助信道估计
```
最小二乘 (LS): Ĥ = Y_pilot × X_pilot^(-1)
MMSE: Ĥ = R_HH × (R_HH + σ² I)^(-1) × Ĥ_LS
```

#### 时频插值
- 线性插值
- 高斯插值
- 维纳滤波

### 12.3 信号检测算法

#### MIMO 检测
| 算法 | 复杂度 | 性能 | 适用场景 |
|------|--------|------|----------|
| MRC | O(N) | 接近最优(SISO) | 单流传输 |
| ZF | O(N³) | 较好 | 低阶MIMO |
| MMSE | O(N³) | 好 | 标准MIMO |
| ML | O(N^M) | 最优 | 小规模MIMO |

#### 检测公式
```
ZF: x̂ = (H^H H)^(-1) H^H y
MMSE: x̂ = H^H (HH^H + σ²I)^(-1) y
```

### 12.4 自适应滤波算法

#### LMS 算法
```
w[n+1] = w[n] + μ × e[n] × x[n]
其中: μ 为步长, e[n] = d[n] - w^H[n]x[n]
```

#### RLS 算法
```
P[n] = (P[n-1] - K[n]x^H[n]P[n-1])/λ
K[n] = P[n-1]x[n]/(λ + x^H[n]P[n-1]x[n])
w[n] = w[n-1] + K[n]e[n]
```

#### 性能对比
| 算法 | 收敛速度 | 复杂度 | 跟踪能力 |
|------|----------|--------|----------|
| LMS | 慢 | O(N) | 中 |
| NLMS | 中 | O(N) | 中 |
| RLS | 快 | O(N²) | 好 |

### 12.5 AGC 算法

#### 功率检测 AGC
```
目标功率: P_target
测量功率: P[n] = α × P[n-1] + (1-α) × |x[n]|²
增益调整: G[n+1] = G[n] × (P_target / P[n])
```

#### 分段 AGC
- 快AGC: 检测信号峰值
- 慢AGC: 检测平均功率
- 混合AGC: 结合快慢速

### 12.6 数字预失真 (DPD)

#### DPD 结构
```
x[n] → DPD模块 → PA输入
              ↓
        PA输出 → 反馈链路 → 观测信号
```

#### DPD 模型
- **记忆多项式**: x_dpd[n] = Σ a_k x[n-k] + Σ b_kl x[n-k] |x[n-k]|²
- **Volterra级数**: 高阶非线性建模
- **神经网络DPD**: 深度学习建模

#### 自适应DPD
```
误差信号: e[n] = y_feedback[n] - G × x_dpd[n]
参数更新: 使用LMS/RLS更新DPD系数
```

### 12.7 同步算法

#### 载波同步
```
相位同步: θ̂ = atan(Im{y}/Re{y})
频率同步: Δf = (1/2π) × d(θ̂)/dt
```

#### 定时同步
- 前导码相关检测
- Gardner算法（插值定时恢复）
- Mueller-Muller算法

### 12.8 频率合成算法

#### 锁相环 (PLL)
```
鉴相器 → 环路滤波器 → VCO
    ↑                   ↓
    ←────分频器←────────┘
```

#### 小数分频 PLL
- Σ-Δ调制器实现小数分频
- 相位噪声优化
- 杂散抑制技术

### 14.9 前传接口

#### CPRI 接口
- 速率: 2.4-10 Gbps
- 延迟: ≤5 μs
- 用途: 4G LTE

#### eCPRI 接口
- 速率: 10-100 Gbps
- 延迟: ≤100 μs
- 分组化: 支持以太网
- 用途: 5G NR

#### 前传带宽计算
```
CPRI 带宽 = I/Q采样率 × 位宽 × 天线端口数 × 过采样率
eCPRI 带宽 = 用户面数据速率 + 控制开销
```

## 15. 中射频软特性分析

### 15.1 软特性概述

#### 软特性定义
- **软特性**: 通过软件配置即可调整的射频/系统参数
- **硬特性**: 固定硬件参数，通常在设计时确定
- **软特性优势**: 灵活调优、远程配置、现场优化

|------|----------|----------|

| 干扰协调 | ABS配置 | 子帧配置 |

### 15.2 功率控制参数

#### Open Loop Power Control (OLPC)
```
P_PUSCH[i] = min{
  Pmax,
  10*log10(MPUSCH[i]) + P0_PUSCH[j] + α[j]*PL + ΔTF[i] + f(i)
}
```
- **Pmax**: 最大发射功率
- **MPUSCH**: 分配的PRB数量
- **P0_PUSCH**: 目标功率基准
- **α**: 路径损耗补偿因子 (0~1)
- **PL**: 路径损耗估计

#### Closed Loop Power Control (CLPC)
```
P_PUSCH[i] = P_OLPC[i] + f(i)
其中 f(i) 为闭环调整量
```
- **TPC Command**: +1, +3, -1, -3 dB 步进
- **Accumulated/Dynamic 模式**

#### 下行功率分配
```
P_DSCH = Ptotal - Σ P_other_signal
```
- **Reference Signal Power (CRS/SSB)**
- **PDCCH Power Offset**
- **PBCH/SSS Power**

## 16. 能耗分析与节能方案

### 16.1 射频系统功耗组成

#### 功耗分解
| 模块 | 功耗占比 | 影响因素 |
|------|----------|----------|
| 功率放大器 (PA) | 50-70% | 输出功率、PAE |
| 射频链路 | 10-20% | 增益、噪声系数 |
| 数字基带 | 10-20% | 处理带宽、MIMO层数 |
| 电源模块 | 5-10% | 转换效率 |
| 散热系统 | 5-15% | 环境温度 |

#### 功耗模型
```
P_total = P_PA + P_RF + P_BB + P_PS + P_thermal

其中:
P_PA = P_DC_PA / η_PA (PA效率)
P_RF = Σ(V * I) for LNA, Mixer, etc.
P_BB = k * f_clk * N_gates (数字处理)
```

### 16.2 功率放大器效率优化

#### PA 效率指标
| 指标 | 定义 | 典型值 |
|------|------|--------|
| PAE | (P_RF_out - P_RF_in) / P_DC | 30-50% |
| Drain Efficiency | P_RF_out / P_DC | 35-55% |
| Power Added | (P_RF_out - P_RF_in) / P_DC | 同PAE |

#### 效率优化技术
- **Doherty PA**: 主辅功放协同
- **Envelope Tracking**: 包络跟踪供电
- **Outphasing**: 异相功率合成
- **GaN器件**: 高效率材料

### 16.3 基站节能技术

#### 载波关断 (Carrier Sleep)
| 参数 | 配置 | 说明 |
|------|------|------|
| Sleep Duration | 1s~配置 | 休眠持续时间 |
| Activation Threshold | PRB利用率 | 触发门限 |
| Wake-up Time | <50ms | 唤醒延迟 |

#### 通道休眠 (Channel Sleep)
- **TRX通道关断**: 降低同时工作的TRX数量
- **天线端口休眠**: 减少PA工作数量
- **适用场景**: 低负荷时段

#### 符号级关断 (Symbol Shutdown)
- **符号关断**: 无数据传输时关闭PA
- **突发传输**: Burst模式设计
- **MIMO降阶**: 高负荷时减少流数

### 16.4 节能效果评估

#### 能耗评估指标
| 指标 | 计算方法 | 说明 |
|------|----------|------|
| Energy Efficiency | Throughput / Power (bits/J) | 能效比 |
| Power Saving Ratio | (P_base - P_new) / P_base | 节电比例 |
| Sleep Factor | Sleep Time / Total Time | 休眠因子 |

#### 节能策略选择
```
场景判断:
if (PRB_utilization < threshold_sleep):
    启用载波关断
elif (Traffic < threshold_channel):
    启用通道休眠
elif (MIMO_layers > 2 && load < threshold_mimo):
    启用MIMO降阶
else:
    全功率运行
```

#### 能耗指标
