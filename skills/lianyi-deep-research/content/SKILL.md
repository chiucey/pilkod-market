# 涟漪深度投研 Skill

## 触发条件

满足以下任一条件时激活：
- V 说"深度研究一下..."
- V 说"帮我调研..."
- 涉及全新投资赛道/项目
- 涉及复杂宏观问题

## 标准深度研究流程（5步）

### 🔬 Step 1：问题界定（15分钟内完成）

**目标：** 把研究问题定义清楚，防止研究范围蔓延

```
研究标的：
研究问题：
研究边界：
成功标准：（完成后能回答什么问题？）
```

### 📚 Step 2：信息穷举（使用batch_web_search）

**研究框架（按序执行）：**

1. **基本面** — 官方信息
   - 项目官网、白皮书
   - 官方公告（近3-6个月）
   - 团队背景调查

2. **市场面** — 数据验证
   - 交易所数据（CoinMarketCap / Yahoo Finance）
   - 链上数据（如适用）
   - 历史价格走势

3. **舆情面** — 市场情绪
   - Twitter/X 社区讨论
   - Reddit/论坛分析
   - 主流媒体评价

4. **竞品面** — 横向对比
   - Top 3 竞品是谁
   - 核心差异点
   - 估值对比

5. **风险面** — 隐患识别
   - 监管风险
   - 技术风险
   - 市场风险

### 🎯 Step 3：七问评分（必须完整填写）

| # | 问题 | 评估 | 备注 |
|---|------|------|------|
| 1 | 真的是机会吗？ | ✅/❌ | |
| 2 | 涟漪评分够高吗？ | ___/10 | |
| 3 | 反向证据是什么？ | | |
| 4 | 真的理解吗？ | ✅/❌ | |
| 5 | 适合涟漪体系吗？ | ✅/❌ | |
| 6 | 时机对吗？ | ✅/❌ | |
| 7 | 有没有被误导？ | ✅/❌ | |

**总分：___/10 → 仓位建议：___**

### 📈 Step 4：情景分析（ABC矩阵）

```
情景A（乐观 X%）：
- 假设条件：
- 预期走势：
- 触发信号：

情景B（基准 X%）：
- 假设条件：
- 预期走势：
- 触发信号：

情景C（悲观 X%）：
- 假设条件：
- 预期走势：
- 触发信号：
```

### 📝 Step 5：综合建议

```
结论：（一句话，清晰的）
依据：（2-3个最有力依据）
风险：（诚实，不回避）
时机：（现在 / 等待信号）
仓位：（如果适用，具体建议）

涟漪理解度：X/5
- 能否向V解释清楚：是/否
- 主要不确定性：
```

## 输出规范

- 结论先行，不废话
- 每个结论必须有依据
- 不确定的说"涟漪不确定"
- 永远设置止损/离场条件

## 时间管理

- 快速研究（1-2小时）：聚焦核心问题
- 深度研究（半天）：全框架穷举
- 重大研究（1天+）：需分阶段，可设提醒
