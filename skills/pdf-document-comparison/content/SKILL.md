# PDF文档校对技能

## 核心能力

本技能用于精确比对PDF源文档与OCR/解析后的文本内容，检测内容层面的差异，不关注格式差异。

## 工作流程

### 步骤1：准备文档

**输入要求**：
- 源文档：原始PDF文件路径
- 解析文档：OCR或文本提取后的内容（可以是.txt文件或直接输入的文本）

**注意**：如果用户已有解析后的文本，直接使用；如果是PDF需要先提取文本。

### 步骤2：文本预处理

对两份文档进行规范化处理，移除格式差异：
- 统一空格和换行
- 规范化标点符号
- 统一数字格式

### 步骤3：分块处理（针对大文档）

对于100页以上的文档，采用分块策略：
- 将文档按固定长度或段落分块
- 逐块进行比对
- 记录上下文位置信息

### 步骤4：差异检测

使用difflib和自定义算法检测：
1. **文字错误**：错别字、字符替换
2. **数字错误**：数字差异、小数点位置错误
3. **遗漏内容**：原文中存在但解析后缺失
4. **多余内容**：解析后多出的原文没有的内容

### 步骤5：生成报告

输出Markdown格式的差异报告，包含：
- 差异类型标记
- 具体位置（页码/段落）
- 原文内容
- 解析后内容
- 差异描述

## 差异类型定义

| 类型 | 说明 | 标记 |
|------|------|------|
| 文字错误 | 字符不匹配 | `[文字错误]` |
| 数字错误 | 数值差异 | `[数字错误]` |
| 遗漏 | 原文有，解析无 | `[遗漏内容]` |
| 多余 | 解析有，原文无 | `[多余内容]` |

## 输出格式

```markdown
# 文档校对报告

## 文档信息
- 源文件：[文件名]
- 解析文件：[文件名]
- 比对时间：[时间]

---

## 差异详情

### 第1处差异
**位置**：第X页，第Y段
**类型**：[差异类型]
**原文**：[原文内容]
**解析后**：[解析内容]
**描述**：[详细说明]

---

### 第2处差异
...

---

## 无差异区域

[逐段展示已确认一致的内容]

---

**校对完成**
```

## 关键原则

1. **仅指出差异，不修改内容**
2. **不总结、不判断重要性**
3. **所有错误都必须报告**
4. **关注内容准确性，忽略格式差异**

## 执行脚本

核心比对逻辑由 `scripts/compare_documents.py` 执行，支持：
- 大文件分片处理（默认每块5000字符）
- 内存优化
- 上下文保存
- 详细日志输出
