# 标准化PRD输出与需求边界管控技能

## 技能定义

通过标准化的PRD模板和规范的撰写流程，输出完整、清晰、无歧义的需求文档，精准定义需求边界，确保团队对齐，减少返工。

### PRD标准结构

### 需求边界管控检查

| 检查维度 | 检查问题 | 状态 |
|---------|---------|------|
| 功能边界 | 是否明确哪些做、哪些不做？ | □是 □否 |
| 数据边界 | 数据来源、去向是否清晰？ | □是 □否 |
| 权限边界 | 不同角色的权限是否定义？ | □是 □否 |
| 异常边界 | 异常场景是否穷举？ | □是 □否 |
| 性能边界 | 性能指标是否量化？ | □是 □否 |

## 需求评审 Checklist

| 评审项 | 内容 | 通过标准 |
|--------|------|---------|
| 完整性 | 覆盖所有用户场景 | □通过 □待补充 |
| 清晰性 | 无歧义、可执行 | □通过 □待补充 |
| 一致性 | 与现有逻辑一致 | □通过 □待补充 |
| 可行性 | 技术可实现 | □通过 □待补充 |
| 优先级 | 优先级合理 | □通过 □待补充 |
| 验收标准 | 验收条件明确 | □通过 □待补充 |
