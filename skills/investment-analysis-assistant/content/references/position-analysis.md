# 筹码分布分析专业指南

## 一、筹码分布基础

### 筹码概念
筹码即股票在不同价格区间的持仓成本分布。通过分析筹码分布，可以判断主力资金动向、支撑压力位、以及可能的价格波动方向。

### 筹码数据来源
1. 成交量加权的平均成本
2. 换手率累积计算
3. 持仓账户成本估算

## 二、筹码分布形态

### 1. 单峰密集型

**特征**：筹码集中在一个狭窄的价格区间内（通常振幅<10%）

**解读**：
- 市场成本高度一致
- 变盘概率大
- 向上突破：爆发力强
- 向下破位：跌幅大

**操作策略**：
```
突破前：观望等待
向上突破：追入，止损在峰底下方5%
向下破位：空仓，避免抄底
```

### 2. 双峰密集型（筹码峡谷）

**特征**：高价位和低价位各有一个筹码峰，中间形成峡谷

**解读**：
- 高位筹码峰：套牢区，压力位
- 低位筹码峰：建仓区，支撑位
- 峡谷区间：观望区，无方向

**操作策略**：
```
突破上方筹码峰：看涨信号
跌破下方筹码峰：看跌信号
峡谷区间内：震荡对待
```

### 3. 多峰分散型

**特征**：筹码分散在多个价格区间

**解读**：
- 市场分歧大
- 无明确方向
- 可能形成新的主力建仓区

**操作策略**：
```
耐心等待筹码重新聚集
寻找缩量整理的区间
突破时跟进
```

### 4. 发散型（筹码转移）

**向上发散**：
- 获利筹码增加
- 持仓成本上移
- 主力吸筹迹象

**向下发散**：
- 套牢筹码增加
- 持仓成本下移
- 主力出货迹象

## 三、主力行为识别

### 建仓期特征
1. 成交量：温和放大，量能稳定
2. 筹码：低位单峰密集
3. 走势：窄幅震荡，涨跌有限
4. 时间：可能持续数周至数月

### 拉升期特征
1. 成交量：量价齐升，配合良好
2. 筹码：低位筹码减少，高位筹码增加
3. 走势：角度陡峭，涨速加快
4. 回调：缩量回调，量能萎缩

### 出货期特征
1. 成交量：放量滞涨或缩量上涨
2. 筹码：高位单峰密集
3. 走势：高位震荡，波动加大
4. K线：长上影线、吊颈线频繁出现

## 四、支撑压力判断

### 支撑位识别
```
1. 筹码峰下限（密集区下沿）
2. 均线支撑位
3. 前低/前高位置
4. 整数关口
```

### 压力位识别
```
1. 筹码峰上限（密集区上沿）
2. 均线压力位
3. 前高位置
4. 前期套牢区
```

### 支撑压力转化
- 支撑被有效跌破 → 变成压力位
- 压力被有效突破 → 变成支撑位

## 五、缺口理论结合

### 筹码与缺口关系
1. **向上跳空缺口**：强势信号，回调不补缺口
2. **向下跳空缺口**：弱势信号，反弹不过缺口
3. **普通缺口**：3-5天内回补，参考价值有限

### 操作建议
```
普通缺口回踩不破 → 支撑有效
突破缺口后回踩不破 → 趋势延续
衰竭缺口出现 → 警惕反转
```

## 六、实战案例分析

### 案例一：低位单峰密集后的突破
```
形态：股价长期横盘，筹码在低位聚集
信号：放量突破横盘区间
操作：突破买入，止损在横盘区间下方
目标：高位筹码峰的80%位置
```

### 案例二：高位双峰向单峰转化
```
形态：高位震荡，筹码向中间移动
信号：震幅收窄，量能萎缩
操作：警惕突破方向，突破前观望
风险：向下突破概率大
```

### 案例三：筹码快速下移
```
形态：股价下跌，筹码峰向下移动
信号：放量下跌，资金出逃
操作：空仓，不盲目抄底
等待：底部筹码重新聚集
```

## 七、综合分析流程

### Step 1: 确认筹码形态
- 是单峰还是多峰？
- 峰位在高位还是低位？
- 密集程度如何？

### Step 2: 识别主力阶段
- 建仓期？拉升期？出货期？
- 资金流向如何？

### Step 3: 找准支撑压力
- 哪里是支撑？
- 哪里是压力？
- 当前股价位置？

### Step 4: 判断突破方向
- 向上概率大？
- 向下概率大？
- 条件是什么？

### Step 5: 制定操作计划
- 买入/卖出/观望？
- 仓位多少？
- 止损止盈位？
- 风险收益比？

## 八、注意事项

### 局限性
1. 筹码数据有滞后性
2. 无法区分长线短线资金
3. 主力可能使用对倒手法误导

### 使用原则
1. 不单独使用，结合其他指标
2. 关注量价配合
3. 重视趋势方向
4. 严格执行止损
