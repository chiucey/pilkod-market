# 技术分析方法参考资料

## 一、均线系统分析

### 常用均线参数
- **MA5**: 5日均线，短期趋势线
- **MA10**: 10日均线，短线操作参考
- **MA20**: 20日均线，中短期趋势
- **MA60**: 60日均线，中期趋势线
- **MA120**: 120日均线，长期趋势线

### 均线应用法则
1. **多头排列**: 短期均线>中期均线>长期均线，价格在均线上方 → 强势上涨
2. **空头排列**: 短期均线<中期均线<长期均线，价格在均线下方 → 弱势下跌
3. **均线金叉**: 短期均线上穿长期均线 → 买入信号
4. **均线死叉**: 短期均线下穿长期均线 → 卖出信号

## 二、MACD指标

### 计算公式
```
DIF = EMA(close, 12) - EMA(close, 26)
DEA = EMA(DIF, 9)
MACD = (DIF - DEA) * 2
```

### 交易信号
| 信号类型 | 判断条件 | 操作建议 |
|---------|---------|---------|
| 金叉 | DIF上穿DEA，MACD红柱出现 | 买入信号 |
| 死叉 | DIF下穿DEA，MACD绿柱出现 | 卖出信号 |
| 顶背离 | 股价创新高，MACD未创新高 | 警惕回调 |
| 底背离 | 股价创新低，MACD未创新低 | 关注反弹 |

## 三、KDJ指标

### 计算公式
```
RSV = (Cn - Ln) / (Hn - Ln) * 100
K = 2/3 * K_prev + 1/3 * RSV
D = 2/3 * D_prev + 1/3 * K
J = 3 * K - 2 * D
```

### 超买超卖区间
- **超买区**: KDJ > 80 → 警惕回调风险
- **超卖区**: KDJ < 20 → 关注反弹机会
- **金叉**: K线从下往上穿过D线
- **死叉**: K线从上往下穿过D线

## 四、布林带指标

### 参数设置
- 中轨: 20日均线 (MA20)
- 上轨: MA20 + 2 * 标准差
- 下轨: MA20 - 2 * 标准差

### 应用法则
1. **开口放大**: 波动加大，可能出方向
2. **收口缩小**: 横盘整理，等待突破
3. **触碰上轨**: 可能承压回落
4. **触碰下轨**: 可能反弹向上
5. **中轨支撑**: 强势股回调位置

## 五、成交量分析

### 量价关系
| 形态 | 价格 | 成交量 | 含义 |
|------|------|--------|------|
| 价升量增 | 上涨 | 放大 | 资金参与积极，趋势延续 |
| 价升量缩 | 上涨 | 缩小 | 上涨乏力，警惕见顶 |
| 价跌量增 | 下跌 | 放大 | 恐慌抛售，可能见底 |
| 价跌量缩 | 下跌 | 缩小 | 抛压减轻，可能见底 |

### 量能形态
- **堆量**: 成交量温和放大，机构建仓特征
- **突量**: 成交量突然放大，可能突破或出货
- **散兵坑**: 成交量芝麻点，主力控盘特征

## 六、筹码分布分析

### 筹码形态识别
1. **单峰密集**: 成本集中在某一区间，突破后爆发力强
2. **双峰密集**: 高位和低位各有一个密集区，震荡整理
3. **多峰密集**: 筹码分散，趋势不明
4. **发散形态**: 筹码向上或向下转移

### 筹码转移判断
- **向上转移**: 获利筹码减少，被套筹码增加 → 主力吸筹
- **向下转移**: 获利筹码增加，被套筹码减少 → 主力出货

### 支撑压力位
- **支撑位**: 筹码密集区下限，股价回落至此易反弹
- **压力位**: 筹码密集区上限，股价上涨至此易回调

## 七、K线形态

### 常见反转形态
| 形态 | 特征 | 信号 |
|------|------|------|
| 锤子线 | 下影线长，实体小 | 底部反转 |
| 上吊线 | 上影线长，实体小 | 顶部反转 |
| 吞没形态 | 两根K线完全相反 | 反转信号 |
| 早晨之星 | 三K线组合 | 底部反转 |
| 黄昏之星 | 三K线组合 | 顶部反转 |

### 持续形态
- **旗形整理**: 短时间整理后延续原趋势
- **三角形整理**: 收敛后突破方向确定
- **矩形整理**: 震荡区间内高抛低吸

## 八、综合判断原则

### 买入时机
1. 多指标共振：均线多头 + MACD金叉 + KDJ低位
2. 成交量配合：价升量增
3. 筹码支持：主力吸筹 + 支撑位之上
4. 形态确认：底部反转形态完成

### 卖出时机
1. 多指标共振：均线空头 + MACD死叉 + KDJ高位
2. 量价背离：价升量缩或放量滞涨
3. 筹码转移：主力出货特征
4. 形态确认：顶部反转形态完成

### 风险控制
1. **仓位管理**: 单只股票不超过总仓位30%
2. **止损原则**: 亏损不超过7-10%必须止损
3. **止盈原则**: 盈利达到15-20%考虑分批止盈
4. **分散投资**: 不把鸡蛋放在一个篮子里
