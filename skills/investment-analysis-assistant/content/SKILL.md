# 专业投资分析助手

## 核心能力

本技能提供专业的短线投资分析服务，涵盖筹码分布分析、趋势判断、买入卖出信号识别等核心功能。

## 工作流程

### 第一步：信息收集与分析

当用户提供股票代码或请求分析时，执行以下步骤：

1. **获取市场数据**
   - 通过网络搜索获取最新股价、成交量数据
   - 收集近期K线形态信息
   - 获取资金流向数据

2. **筹码分布分析**
   - 分析成本集中区域
   - 识别支撑位与压力位
   - 追踪主力持仓变化
   - 判断筹码转移方向

3. **趋势技术分析**
   - 短期均线系统（5日、10日、20日）
   - MACD指标状态
   - KDJ随机指标
   - 布林带位置分析
   - 成交量配合情况

### 第二步：信号识别

**买入信号识别：**
- 股价回踩重要均线获得支撑
- 缩量回调后放量突破
- MACD低位金叉
- KDJ超卖区金叉
- 筹码峰上移显示主力吸筹
- 连续出现缩量十字星后大阳线

**卖出信号识别：**
- 股价触及压力位滞涨
- 放量冲高回落
- MACD高位死叉
- KDJ超买区死叉
- 筹码峰下移显示主力出货
- 连续出现放量大阴线

### 第三步：风险评估

1. **市场环境判断**
   - 大盘趋势与个股联动性
   - 板块轮动热点
   - 政策影响因素

2. **仓位建议**
   - 根据信号强度建议仓位比例
   - 设定止损止盈位
   - 风险收益比评估

### 第四步：输出分析报告

提供结构化分析报告，包含：
- 基本面简述
- 技术面分析
- 筹码分布解读
- 买卖信号总结
- 操作建议与风险提示

## 分析维度

### 上证指数分析
- 指数当前位置与均线关系
- 筹码密集区分布
- 主力资金动向
- 近期关键支撑压力位

### 个股分析
- 短期走势形态
- 成交量能变化
- 筹码成本分布
- 买卖点信号强度

## 信号等级划分

| 等级 | 信号类型 | 说明 |
|------|---------|------|
| A级 | 强烈买入/卖出 | 多指标共振，高确定性信号 |
| B级 | 谨慎买入/卖出 | 部分指标支持，需结合盘面 |
| C级 | 观望 | 信号不明确，建议等待 |

## 风险提示规范

每次分析必须包含以下风险提示：

```
⚠️ 风险提示：
1. 本分析仅供参考，不构成投资建议
2. 股市有风险，投资需谨慎
3. 短线交易风险较高，请控制仓位
4. 建议设置止损位，亏损不超过10%
5. 市场瞬息万变，请结合实时行情判断
```

```markdown
[风险提示内容]
```

## 注意事项

1. **数据时效性**：所有分析基于获取的最新数据，市场变化可能导致分析失效
2. **指标局限性**：技术指标存在滞后性，不可单独作为买卖依据
3. **组合判断**：建议综合多个指标和信号进行判断
4. **仓位管理**：短线操作建议仓位不超过总资金的30%
5. **止损纪律**：必须严格执行预设止损位，避免深度套牢
