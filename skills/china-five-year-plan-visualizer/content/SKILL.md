# 中国五年规划可视化技能

## 核心能力

本技能帮助用户分析和可视化中国五年规划文档，提取核心信息并生成交互式可视化网页。

## 工作流程

### 步骤 1：文档获取与解析

支持多种文档格式：

- **PDF 文档**：使用 `extract_pdfs_full_content` 或 `extract_pdfs_key_info` 提取内容
- **网页文档**：使用 `extract_content_from_websites` 获取在线发布的规划内容
- **用户提供文件**：读取用户上传的文档文件

### 步骤 2：核心信息提取

从规划文档中识别和提取：

1. **总体目标**：经济发展、创新驱动、民生福祉、绿色生态、安全保障等五大类目标
2. **主要指标**：GDP增速、研发投入比重、居民收入、城镇化率等量化指标
3. **重点任务**：科技创新、产业发展、改革开放、乡村振兴、区域协调等战略任务
4. **重大项目**：标志性工程和重大基础设施项目
5. **政策举措**：重要改革措施和政策支持方向

### 步骤 3：数据结构化

将提取的信息整理为结构化数据格式：

```json
{
  "plan_name": "十四五规划",
  "release_date": "2021-03-12",
  "overall_goals": {
    "economic": { "description": "...", "metrics": [...] },
    "innovation": { "description": "...", "metrics": [...] },
    "livelihood": { "description": "...", "metrics": [...] },
    "green": { "description": "...", "metrics": [...] },
    "security": { "description": "...", "metrics": [...] }
  },
  "key_indicators": [...],
  "major_tasks": [...],
  "key_projects": [...]
}
```

### 步骤 4：可视化网页生成

创建交互式可视化网页，包含：

- **首页概览**：规划总体框架和核心目标展示
- **目标分解图**：五大发展理念的可视化呈现
- **指标仪表盘**：关键量化指标的图表展示（柱状图、折线图、仪表盘）
- **重点任务时间线**：战略任务的时间规划可视化
- **领域分布图**：饼图/环形图展示各领域投入占比
- **对比分析**（如有多期规划）：不同五年计划的指标对比

### 步骤 5：网页部署

使用 `deploy` 工具将可视化网页部署到线上，提供可访问的 URL。

## 技术实现建议

### 前端框架选择

- **React + Tailwind CSS**：适合复杂交互的数据可视化
- **纯 HTML + CSS + JavaScript**：适合轻量级展示
- **图表库**：Chart.js、ECharts、D3.js 用于数据可视化

### 推荐项目结构


## 使用示例

### 示例 1：分析十四五规划

**用户输入**：
> 请分析"十四五"规划的经济发展目标，并生成可视化网页

**执行流程**：
1. 获取十四五规划全文
2. 提取经济发展相关章节
3. 识别关键指标（GDP增速6%、全员劳动生产率增长等）
4. 生成包含柱状图、仪表盘的网页
5. 部署并提供访问链接

### 示例 2：多期对比分析

**用户输入**：
> 对比十三五和十四五规划的科技创新目标

**执行流程**：
1. 获取两份规划文档
2. 提取科技创新章节
3. 对比研发投入、专利指标等变化
4. 生成双期对比图表
5. 部署可视化网页

## 注意事项

1. **数据准确性**：确保从官方权威渠道获取规划文档
2. **指标解读**：准确理解指标定义，避免误读
3. **可视化设计**：遵循数据可视化最佳实践，图表清晰易读
4. **响应式布局**：确保网页在各种设备上正常显示
5. **加载性能**：优化大数据集的渲染性能
