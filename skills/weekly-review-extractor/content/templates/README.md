# Weekly Review Extractor

Converts your weekly review PDFs into concise reports for communicating with labmates.

## Supported Formats

- Input: `YYYY-Wnn.pdf` (e.g., `2026-W19.pdf`)
- Content should include: weekly overview, daily summary, completed items, data statistics, pattern recognition, next week adjustments

## Output Content

### Last Week Review
- Main outputs (thesis, learning progress, etc.)
- What went well / challenges
- Core weekly insight

### Next Week Plan
- Continuing tasks and goals
- Adjustment measures
- Key milestones and deadlines

## Usage Example

When you upload `2026-W19.pdf`, the system will:
1. Extract PDF content
2. Analyze key information
3. Generate concise yellow highlight formatted report

You can directly copy the output to share with labmates, or request further format adjustments.
