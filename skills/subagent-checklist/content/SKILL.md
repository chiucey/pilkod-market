# 子代理强制自检表

> ⚠️ 本技能是每日流水线质量保障核心。所有子代理在「写稿→生图→上传」全流程结束后、生成JSON之前，**必须逐项通过本清单**。任何一项不通过 → 立即修正 → 重新过检 → 通过后交付。

---

## 一、日期校验（第一步！）

今日日期：`2026-06-10`

- ❌ 正文/标题出现"6月9日""昨天""上周" → 立即打回重写
- ❌ 文件名含 `_0609` → 图是旧的，废弃重新生成
- ❌ 热榜搜索时间戳不是今天 → 重新搜
- ✅ 正文第一句必须出现今日日期（如"6月10日国家发改委…"）

---

## 二、标题校验

### 违禁词（零容忍！违者删文封号）

绝对禁止：`最`字辈、绝对化表述、涉钱夸大、政策定性

### 字数
✅ ≤16字

### 情绪钩子
- 有对比：涨vs跌、内vs外、国内vs海外
- 有疑问：问句结尾激发好奇
- 有反常识：让人想"真的是这样吗"

---

## 三、正文校验

### 字数
- 标准系列：正文（不含标签）≥ 3000字（约4500字符）
- 民生价格系列：正文字符≥300字即可，不受3000限制

### 三层结构（每段必须有）
- **事实层**：数字+时间+来源
- **洞察层**：有态度（"说实话……""真正的问题是……"）
- **共鸣层**："你/我们"代入，落到普通人处境

### 去AI味（5条铁律）
- ❌ "首先/其次/最后" → 自然过渡
- ❌ "值得注意的是" → "但最扎心的是……"
- ❌ "让我们共同努力" → 具体场景收尾
- ❌ "从数据可以看出" → 数字融进故事
- ❌ 大段背景铺陈 → 开头直接给冲突

---

## 四、配图校验

### 格式检查（最常见翻车点！）
WebP伪装成.jpg → 微信上传报40113

生成或拿到图片后立即执行：
```bash
file /workspace/xxx.jpg
```
- ✅ 输出含 "JPEG image data" → 合格
- ❌ 输出含 "RIFF ... Web/P ... VP8" → 是WebP，执行：
  ```bash
  convert /workspace/xxx.jpg /workspace/xxx.jpg
  ```
  直接覆盖，自动转真JPEG

### 分辨率
- 封面图：≥ 1280×1920 px（2:3）
- 内文图：≥ 1920×1080 px（16:9）
- 低于 → 重新生成

### 图文相关性
- 封面图主题必须与文章核心事件强相关
- 内文图放入相邻段落时，读者不会觉得"这张图放这里干嘛"
- prompt锚点词必须包含文章核心关键词，禁止通用笼统prompt

### 图表文字（全中文！）
折线图/柱状图/仪表盘：坐标轴/图例/单位全部中文。发现英文 → 重新生成

## 五、上传前校验（最后一步）

### JSON完整性
- 字符数 > 3000（民生价格系列 > 300）
- body中 `<img` 标签数量 = 实际配图数量
- 标题字数 ≤ 16字

### 上传命令
```bash
python3 /workspace/batch_draft_v6.py /workspace/draft_[系列]_[日期].json
```
- 等待出现 "✅" 才算成功
- 若40113 → convert转换后重新上传，不要跳过

## 六、高频错误档案（翻车后必查）

| 错误现象 | 根因 | 解决方案 |
|---------|------|---------|
| 内文图上传40113 | WebP伪装成.jpg | `convert x.jpg x.jpg` 覆盖转格式 |
| 封面图分辨率太低 | 生成时resolution设置过低 | 改用2K分辨率重新生成 |
| 正文出现旧日期 | 复制了旧稿没有改日期 | 写稿前先确认今日日期是2026-06-10 |
| 字符数不足3000 | 民生系列写了长正文 | 价格系列≥300字即可，不受3000限制 |
| 标题踩违禁词 | 没有过违禁词表 | 写完标题后对照违禁词表检查 |
| image_synthesize连续失败 | 模型服务抖动 | 改用images_search_and_download下载替代图 |
| 草稿内容截断 | 字符数不足/图片数不对 | 上传前双重验证字符数+img标签数 |

## 八、爆款标题公式（必须用！）

每篇标题从以下公式里选一个，对号入座：

| 类型 | 公式 |例子 |
|------|------|------|
| 对比式 | [数字/事件] vs [数字/事件] | 国内暴跌21%！海外却暴涨2511%！ |
| 反常识式 | 颠覆认知的核心矛盾 | 油价跌了，但菜市场反而更贵了 |
| 疑问式 | 问句结尾激发好奇 | 猪肉跌破5元一斤，为什么超市还是贵？ |
| 揭秘式 | 揭露不为人知的一面 | 加油站挂牌价和实际油价，差了一整个世界 |

❌ 禁止：纯陈述句、无情绪词、无数字对比
✅ 必须：对比/疑问/反常识三选一

## 九、正文爆款结构（必须用！）

### 开头（黄金5句）
- 前3句话必须出现：具体的人/场景/数字
- ❌ "随着XXX发展，XXX引发关注" →0.5秒划走
- ✅ "昨天加油，花了450块。加油站的价格牌，悄悄创了新高"

### 中段节奏
- 每段不超过3-4句，留白感=呼吸感
- 有数字要融进场景里讲，不要"从数据可以看出"
- 有态度：「说实话……」「真正的问题是……」「最扎心的是……」

### 结尾
- ❌ 口号式结尾："让我们共同努力……"
- ❌ 总结式结尾："综上所述……"
- ✅ 落到一个人身上，一个具体场景，一个没有标准答案的问题

## 十、去AI化操作表（写完必须过！）

对照检查，有则改之：

| AI特征 | 发现即修改 |
|--------|-----------|
| "首先/其次/最后" | 删掉，用自然过渡句替代 |
| "值得注意的是……" | 改为"但最扎心的是……" |
| "让我们共同努力……" | 改为具体场景收尾 |
| "从数据可以看出……" | 把数字融进故事场景 |
| 段落长度完全一致 | 长短交错，有呼吸感 |
| 连续3段以上没有具体数字 | 插入真实数字（时间/价格/涨幅） |
| 全篇没有具体的人名/场景 | 加一个"我有个朋友……""邻居老王……" |
| 问句都是自问自答 | 改为留白式提问，答案留给读者想 |
