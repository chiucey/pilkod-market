# 朋友圈文案神器

## 核心能力

快速生成吸引眼球的朋友圈文案，适配多种场景和平台风格。

## 支持的场景

| 场景类型 | 触发关键词 | 说明 |
|---------|-----------|------|
| 节日祝福 | 节日、春节、中秋、元宵、端午、国庆、圣诞、新年 | 节日专属祝福语 |
| 生日祝福 | 生日、生日快乐、寿星 | 温馨或创意生日贺词 |
| 心情文案 | 心情、感悟、励志、正能量、文艺 | 表达生活感悟 |
| 平台适配 | 小红书风格、微博风、ins风 | 特定平台调性文案 |
| 互动文案 | 接龙、抽奖、转发、投票、问答 | 促活互动文案 |

## 输出格式

根据用户选择的风格，生成符合要求的文案：

```
【文案类型】[类型名称]

[正文内容 - 2-4句，配合适当emoji]

[可选：互动引导语]
[可选：话题标签 #话题#]
```

## 文案风格指南

### 1. 节日祝福风格
- 温馨感人型：情感真挚，适合长辈和朋友
- 创意幽默型：轻松活泼，适合同龄人
- 古风诗意型：文雅有意境

### 2. 生日祝福风格
- 温情款款：温暖祝福，适合亲密关系
- 幽默调侃：轻松有趣，适合损友
- 诗意浪漫：文艺清新

### 3. 心情文案风格
- 文艺小清新：短句+意境
- 励志正能量：激励人心
- 随性自然：记录生活点滴

### 4. 平台适配风格
- **小红书风**：emoji多、分段清晰、结尾引导互动
- **微博风**：简短精炼、话题标签、热点结合
- **朋友圈风**：生活化、真实感、适度文艺

### 5. 互动文案风格
- **接龙文案**：押韵或关联性强，便于续写
- **抽奖文案**：吸引眼球、明确规则、转发引导
- **问答文案**：悬念感、引导评论

## 使用流程

1. **识别场景**：根据用户输入判断文案类型
2. **确认风格**：用户可指定风格或由AI推荐
3. **生成文案**：输出2-3个备选方案
4. **调整优化**：根据反馈修改

## 文案生成规则

### 字数控制
- 朋友圈正文：50-200字
- 微博风格：50-100字
- 小红书风格：100-300字

### 元素搭配
- emoji使用：每50字1-2个
- 话题标签：1-3个为宜
- 换行使用：增加呼吸感和层次

### 避坑指南
- 避免过于矫情或负能量
- 节日祝福不涉及敏感话题
- 抽奖文案需明确活动时间与规则
