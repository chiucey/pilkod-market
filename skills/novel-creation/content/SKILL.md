# 长篇小说创作技能

## 核心工作流程

本技能遵循系统化的创作流程，确保故事的完整性和一致性。

### 阶段一：主题与梗概

#### 1.1 故事主题提炼

引导用户明确故事的核心主题：

- **一句话主题**：用一句话概括故事的核心理念或情感
- **主题关键词**：提取3-5个核心关键词
- **主题深度**：探讨主题的多层次含义

#### 1.2 故事梗概概述

在主题基础上，构建完整的故事轮廓：

- **背景设定**：时代、地点、社会环境
- **核心冲突**：主要矛盾和次要冲突
- **主线与支线**：故事主轴和分支情节
- **起始与结局**：明确的起点和终点

### 阶段二：背景资料收集

#### 2.1 时代背景研究

根据故事设定时代，系统收集相关资料：

- **社会结构**：政治制度、经济状况、阶层关系
- **文化风貌**：风俗习惯、宗教信仰、艺术风格
- **科技水平**：技术发展、生活方式
- **历史事件**：与故事相关的重大事件

#### 2.2 真实感增强

- 引用真实历史细节增加可信度
- 避免时代错位和常识性错误
- 收集专业领域的术语和规范

### 阶段三：世界观构建

#### 3.1 基础世界观

- **地理环境**：故事发生的主要场所
- **社会规则**：法律、制度、潜规则
- **价值体系**：社会主流价值观、道德标准

#### 3.2 特殊设定（如适用）

- 魔法体系/科技体系
- 种族/势力分布
- 势力关系图谱

### 阶段四：角色塑造

#### 4.1 主要角色设计

为每个核心角色创建详细档案：

| 要素 | 内容 |
|------|------|
| 身份 | 姓名、年龄、职业、社会地位 |
| 外貌 | 体貌特征、着装风格 |
| 性格 | 性格特点、行为模式 |
| 动机 | 核心欲望、内心恐惧 |
| 成长弧线 | 角色在故事中的变化轨迹 |

#### 4.2 角色关系网络

- 主角与配角的从属关系
- 对立角色的冲突设计
- 角色间的情感纽带

### 阶段五：情节设计

#### 5.1 结构规划

采用经典三幕结构或自定义结构：

- **第一幕（25%）**：建置 - 介绍世界、人物、冲突
- **第二幕（50%）**：对抗 - 主角面临挑战、挫折
- **第三幕（25%）**：解决 - 高潮、结局

#### 5.2 章节规划

- 按结构分配章节数量
- 确定每章的核心事件
- 设计章节间的钩子/悬念

#### 5.3 情节点设计

为每个关键情节点编写：

- **场景**：时间、地点、环境
- **事件**：发生的具体事件
- **冲突**：面临的矛盾和挑战
- **转折**：可能的方向变化

### 阶段六：章节写作

#### 6.1 写作前准备

- 回顾前文埋下的伏笔
- 确认本章核心任务
- 规划场景切换

#### 6.2 写作要点

- **开篇**：用场景/对话/事件迅速抓住读者
- **发展**：通过冲突和对话推进情节
- **收尾**：留下悬念或呼应主题
- **节奏**：长短句结合，张弛有度

#### 6.3 写作检查清单

- [ ] 视角一致性
- [ ] 细节前后一致
- [ ] 对话自然流畅
- [ ] 情感表达适度
- [ ] 与前后章节衔接自然

## 触发指令示例

- "我要写一部关于...的长篇小说"
- "帮我设计一个...的故事大纲"
- "创作一个...类型的小说角色"
- "帮我写第X章的内容"
- "构建一个...的世界观"
- "设计主角与反派的对决场景"
