# 故事结构参考指南

## 经典三幕结构详解

### 第一幕：建置（25%）

**功能**：建立世界、介绍人物、抛出冲突

| 章节 | 任务 | 关键要素 |
|------|------|----------|
| 1 | 世界亮相 | 时代、地点、氛围 |
| 2-3 | 人物登场 | 主角及核心配角 |
| 4-5 | 日常打破 | 打破主角原有生活 |

**转折点**：催化剂事件，主角被迫踏上旅程

### 第二幕：对抗（50%）

**功能**：深化冲突、增加难度、角色成长

| 阶段 | 章节占比 | 任务 |
|------|----------|------|
| 中点前 | 25% | 追逐目标、获得资源 |
| 中点 | - | 重大揭示或转折 |
| 中点后 | 25% | 更大挑战、失去一切 |

**中点转折**：假胜利或假失败，改变一切

### 第三幕：解决（25%）

**功能**：高潮对决、情感满足、主题闭环

| 章节 | 任务 |
|------|------|
| 高潮前 | 集结所有力量 |
| 高潮 | 最终对决/抉择 |
| 结局 | 展示变化、收束支线 |

## 章节字数参考

| 小说类型 | 单章字数 | 总字数目标 |
|----------|----------|------------|
| 短篇 | - | 1-5万 |
| 中篇 | 3000-5000 | 5-15万 |
| 长篇 | 3000-6000 | 15-50万 |
| 超长篇 | 4000-8000 | 50万+ |

## 节奏控制技巧

### 开篇钩子类型

1. **动作开场**：从紧张场景开始
2. **对话开场**：用对话揭示关系
3. **描述开场**：用氛围抓住注意力
4. **悬念开场**：抛出问题吸引阅读

### 章末钩子设计

1. 突然转折
2. 揭示秘密
3. 危险逼近
4. 重大决定
5. 情感高潮
