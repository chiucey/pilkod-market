# 公差分析方法

## 公差选项卡概述

OpticStudio 公差选项卡提供完整的公差分析工具，用于评估制造和装配误差对光学性能的影响。

### 主要功能组

| 功能组 | 说明 |
|--------|------|
| 生产工具组 | 成本估计、设计锁定、光线生成 |
| 公差分析组 | 公差编辑器、向导、分析工具 |
| 加工图纸与数据组 | CAD 出图、表面数据 |

## 公差分析组

### 公差数据编辑器 (Tolerance Data Editor, TDE)

**功能**：定义和管理公差参数。

#### 公差类型

| 类型 | 说明 | 典型值 |
|------|------|--------|
| TFRN | 曲率半径公差 | ±0.1% ~ ±0.5% |
| TTHI | 厚度公差 | ±0.01 ~ ±0.1mm |
| TSDX | X 偏心公差 | ±0.01 ~ ±0.05mm |
| TSDY | Y 偏心公差 | ±0.01 ~ ±0.05mm |
| TSDZ | Z 倾斜公差 | ±1' ~ ±5' |
| TIRR | 不规则公差 | 0.1 ~ 0.5 wave |
| TIND | 折射率公差 | ±0.0005 ~ ±0.002 |
| TABB | 阿贝数公差 | ±0.5% ~ ±1% |
| TEDX | 元件 X 偏心 | ±0.01 ~ ±0.05mm |
| TEDY | 元件 Y 偏心 | ±0.01 ~ ±0.05mm |
| TEDZ | 元件倾斜 | ±1' ~ ±5' |

#### 列说明

| 列名 | 说明 |
|------|------|
| # | 公差编号 |
| 表面 | 参考表面 |
| 修饰符 | 修饰符类型 |
| 公差类型 | TFRN, TTHI, etc. |
| 值 | 公差值 |
| 补偿器 | 补偿器表面 |

#### 公差修饰符

| 修饰符 | 说明 |
|--------|------|
| 无 | 公差应用于指定表面 |
| TCOMP | 公差应用于整个透镜 |
| TTIR | 总指示读数 |

### 公差分析向导 (Tolerancing Wizard)

**功能**：快速设置标准公差分析。

**向导选项**：

| 选项 | 说明 |
|------|------|
| 分析类型 | 灵敏度/蒙特卡洛 |
| 公差等级 | 精密/标准/经济 |
| 补偿器 | 是否使用补偿器 |
| 操作数 | 评价参数 |

**预设公差等级**：

| 等级 | 半径 | 厚度 | 偏心 | 倾斜 |
|------|------|------|------|------|
| 精密 | ±0.1% | ±0.01mm | ±0.005mm | ±30" |
| 标准 | ±0.5% | ±0.05mm | ±0.025mm | ±2' |
| 经济 | ±1.0% | ±0.1mm | ±0.05mm | ±5' |

### 公差分析 (Tolerancing)

**功能**：执行公差分析计算。

#### 分析类型

| 类型 | 说明 |
|------|------|
| 灵敏度 (Sensitivity) | 分析单个公差影响 |
| 反灵敏度 (Inverse) | 确定达到目标的公差 |
| 蒙特卡洛 (Monte Carlo) | 统计模拟 |

#### 补偿器设置

| 类型 | 说明 |
|------|------|
| 无补偿器 | 直接评估 |
| 后焦距 | BFL 作为补偿 |
| 中心厚度 | 透镜厚度补偿 |
| 空气间隙 | 元件间距补偿 |

### 公差报告 (Tolerance Report)

**功能**：查看和导出分析结果。

**报告内容**：
- 公差灵敏度排序
- 统计汇总
- 蒙特卡洛分布

### 公差脚本 (Tolerance Script)

**功能**：自定义公差分析脚本。

**用途**：
- 复杂公差规则
- 条件公差
- 批量分析

## 分析方法详解

### 灵敏度分析 (Sensitivity Analysis)

**原理**：计算每个公差参数对性能的影响。

**输出格式**：
```
Tolerance Sensitivity Report
------------------------------------------
参数     公差值    灵敏度      RSS 贡献
------------------------------------------
R2      ±0.5%    +0.123 μm   0.062
T3      ±0.05mm  +0.089 μm   0.045
DX2     ±0.025mm +2.301 μm   1.151
DY2     ±0.025mm +1.956 μm   0.978
N3      ±0.001   +15.023 μm  0.751
------------------------------------------
RSS 总计                   1.897 μm
```

**解读**：
- **灵敏度**：单位公差变化引起的性能变化
- **RSS 贡献**：均方根贡献值
- **优先级**：高贡献值需要更严格控制

### 反灵敏度分析 (Inverse Sensitivity)

**原理**：确定达到目标性能所需的公差。

**用途**：
- 从性能目标反推公差预算
- 制造能力匹配
- 设计可行性评估

### 蒙特卡洛分析 (Monte Carlo)

**原理**：随机模拟大量公差组合。

**统计指标**：
| 指标 | 说明 |
|------|------|
| 平均值 (Mean) | 性能偏移 |
| 标准差 (Std) | 性能分散 |
| 3σ 值 | 最坏情况估计 |
| 良率 (Yield) | 满足规格的比例 |
| 最小/最大 | 极端值 |

**示例结果**：
```
Monte Carlo Results (1000 trials)
------------------------------------------
MTF @ 30 lp/mm:
  目标值:      0.450
  平均值:      0.430
  标准差:      0.020
  最小值:      0.380
  最大值:      0.480
  良率 ≥0.40:  85.3%
  良率 ≥0.45:  52.1%
```

**嵌套蒙特卡洛 (Nested Monte Carlo)**：
- 用于多重结构分析
- 分别考虑结构和公差变化

## 补偿器设置

### 目的
使用可调节元件吸收部分公差，提高良率。

### 常用补偿器

| 补偿器 | 说明 | 典型范围 |
|--------|------|----------|
| 后焦距 | BFL 调整 | ±0.5mm |
| 中心厚度 | 透镜厚度 | ±0.1mm |
| 空气间隙 | 元件间距 | ±0.1mm |
| 垫片 | 机械垫片 | ±0.01mm |

### 设置方法

```python
# 设置后焦距补偿器
tde = TheSystem.TDE
tde.AddTolerance(0, "COMP", CompensationTypes.BackFocalLength, 0.5)

# 设置中心厚度补偿器
tde.AddTolerance(3, "COMP", CompensationTypes.CenterThickness, 0.1)
```

### 补偿器评估

**评估指标**：
- 补偿范围利用率
- 补偿器分布
- 敏感性

## 公差优化策略

### 1. 分级控制

```
关键表面 → 严格公差 (±0.1%)
次要表面 → 标准公差 (±0.5%)
辅助表面 → 宽松公差 (±1.0%)
```

### 2. 灵敏度加权

根据灵敏度分配不同公差等级：

| 灵敏度 | 公差等级 |
|--------|----------|
| 高 (>10 μm/unit) | 精密 |
| 中 (1-10 μm/unit) | 标准 |
| 低 (<1 μm/unit) | 经济 |

### 3. 配对补偿

相邻表面使用相反方向的公差偏移：
- 透镜前后表面偏心方向相反
- 减少系统偏心影响

### 4. 成本权衡

```
高成本公差 ← 低灵敏度参数
严格公差 ← 高灵敏度参数
简单装配 ← 补偿器设计
```

## 多重结构公差分析

### 变焦镜头公差

**考虑因素**：
- 每个结构的公差敏感性
- 结构间耦合
- 变焦机构精度

**分析策略**：
1. 分别分析每个结构
2. 使用嵌套蒙特卡洛
3. 评估最坏情况

### 热公差

**温度影响**：
- 材料膨胀（TCE）
- 折射率变化（dn/dT）

**热公差参数**：

| 参数 | 说明 |
|------|------|
| TEMP | 温度变化 |
| TCE | 热膨胀系数 |
| dn/dT | 折射率温度系数 |

## 公差分析流程

### 标准流程

```
1. 优化设计
   └── 达到性能目标

2. 设置公差数据编辑器
   ├── 选择公差类型
   ├── 定义公差值
   └── 设置补偿器

3. 运行灵敏度分析
   ├── 识别关键公差
   └── 调整公差分配

4. 执行蒙特卡洛模拟
   ├── 设置试验次数
   ├── 运行分析
   └── 评估良率

5. 优化公差分配
   ├── 放宽低灵敏度
   └── 严格高灵敏度

6. 生成报告
   └── 交付制造
```

### 公差报告解读

**关键指标**：
| 指标 | 说明 | 阈值 |
|------|------|------|
| 性能衰减 | vs 理想值 | < 10% |
| RSS 值 | 均方根总偏差 | < 设计容差 |
| 良率 | 满足规格比例 | ≥ 95% |
| 最坏情况 | 3σ 估计 | < 规格限制 |

**判断标准**：
```
良率 ≥ 95%：良好设计
良率 85-95%：可接受，需优化
良率 < 85%：需要重新设计或放宽规格
```

## ZOS-API 公差分析

```python
# Python 示例
import clr
clr.AddReference("ZOSAPI")

from ZOSAPI import ZOSAPI

# 连接
app = ZOSAPI.ZOSAPI_Application.CreateApplication()
system = app.PrimarySystem

# 设置公差
tde = system.TDE
tde.AddTolerance(2, "TFRN", 0.5)   # 半径 ±0.5%
tde.AddTolerance(2, "TSDX", 0.025)  # X 偏心 ±0.025mm
tde.AddTolerance(2, "TSDY", 0.025)  # Y 偏心 ±0.025mm
tde.AddTolerance(3, "TTHI", 0.05)   # 厚度 ±0.05mm
tde.AddTolerance(3, "TIND", 0.001)   # 折射率 ±0.001

# 设置补偿器
tde.AddCompensator(0, "COMP", 0.5)   # 后焦距补偿

# 执行灵敏度分析
tools = system.Tools
tolerancing = tools.Tolerancing
tolerancing.SensitivityOrInverse = SensitivityOrInverseType.Sensitivity
tolerancing.CompensationType = CompensationTypes.BackFocalLength
tolerancing.Run()

# 执行蒙特卡洛分析
tolerancing.AlgoType = TolerancingAlgorithm.MonteCarlo
tolerancing.NumberOfTrials = 1000
tolerancing.Run()

# 获取结果
results = tolerancing.GetResults()
mean = results.GetMeanAt(0)
std = results.GetStdAt(0)
minimum = results.GetMinimumAt(0)
maximum = results.GetMaximumAt(0)
```

## 常见问题与解决

### 问题：良率过低

**原因**：
- 公差过严
- 灵敏度参数未控制
- 补偿器设置不当

**解决**：
1. 放宽经济参数公差
2. 使用补偿器
3. 改进设计降低灵敏度
4. 考虑分级制造

### 问题：补偿器范围不足

**原因**：
- 补偿器选择不当
- 公差过严

**解决**：
1. 改用其他补偿器
2. 放宽公差
3. 添加额外补偿器

### 问题：分析结果不稳定

**原因**：
- 蒙特卡洛次数不足
- 随机数种子问题

**解决**：
1. 增加试验次数至 5000+
2. 多次运行验证
3. 检查模型稳定性
