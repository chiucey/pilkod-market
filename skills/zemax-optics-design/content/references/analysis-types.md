# 光学分析类型详解

## 分析选项卡概述

OpticStudio 分析选项卡提供两种模式下的完整分析功能：

- **序列模式分析** (Sequential UI Mode)
- **非序列模式分析** (Non-Sequential UI Mode)

## 像质分析组 (Image Quality)

### 1. 光线迹点 (Ray Fan)

**用途**：分析从一点发出的光线经系统后的像差分布，以光线在像面上的落点偏移为纵坐标，光线入射高度为横坐标。

**分析内容**：
- 子午光线迹点 (Tangential Ray Fan)
- 弧矢光线迹点 (Sagittal Ray Fan)

**参数设置**：
| 参数 | 说明 |
|------|------|
| 采样 | 光线数量 |
| 波长 | 分析波长 |
| 视场 | 分析视场 |
| 坐标 | 归一化/实际坐标 |

**解读**：
- 零斜率 = 焦点位置
- 曲线弯曲 = 像差类型
- 对称弯曲 = 球差
- 非对称弯曲 = 彗差

### 2. 像差分析 (Aberration Analysis)

#### 赛德尔系数 (Seidel Coefficients)

**五大单色像差**：

| 像差 | 符号 | 描述 |
|------|------|------|
| 球差 | S_I | 边缘光线与近轴光线焦点不一致 |
| 彗差 | S_II | 非轴对称的像差，形成彗星状光斑 |
| 像散 | S_III | 子午和弧矢方向焦线分离 |
| 场曲 | S_IV | 平面物体成曲面像 |
| 畸变 | S_V | 直线变成曲线 |

**色差**：
- **位置色差 (LoCA)**：不同波长焦点位置不同
- **倍率色差 (LCA)**：不同波长放大率不同

**输出格式**：
```
Seidel Surface Data Report
-----------------------------------------
表面    球差      彗差      像散      场曲      畸变
1       0.123     0.045     0.012     0.234     0.001
2       0.089     0.032     0.008     0.156     0.000
...
总计    0.456     0.123     0.045     0.678     0.003
```

### 3. 点扩散函数 (Point Spread Function, PSF)

**用途**：评估点光源经系统后的能量分布。

**分析模式**：
| 模式 | 说明 |
|------|------|
| 衍射 PSF | 基于惠更斯积分的精确衍射计算 |
| 几何 PSF | 基于光线追迹的几何近似 |

**关键参数**：
- **峰值强度** (Peak Intensity)
- **半高宽** (FWHM)
- **RMS 半径**
- **GEO 半径**

**质量判断**：
```
衍射极限: RMS < Airy 半径
良好: RMS < 1.5 × Airy 半径
可接受: RMS < 3 × Airy 半径
```

### 4. MTF 曲线 (Modulation Transfer Function)

**用途**：评估光学系统对不同空间频率的对比度传递能力。

**参数设置**：
| 参数 | 说明 |
|------|------|
| 采样大小 | 4×4 到 64×64 |
| 空间频率 | 最大频率 (lp/mm) |
| 视场 | 分析的视场点 |
| 对比度 | 对比度归一化 |

**输出数据**：
- **切向 MTF (Tv-MTF)**：子午方向
- **弧矢 MTF (Sv-MTF)**：弧矢方向
- **衍射极限 MTF**：理论极限值
- **相位传递函数 (PTF)**：可选

**解读指南**：
| MTF 值 | 质量等级 |
|--------|----------|
| > 0.6 @ 30 lp/mm | 优秀 |
| 0.4-0.6 @ 30 lp/mm | 良好 |
| 0.2-0.4 @ 30 lp/mm | 一般 |
| < 0.2 @ 30 lp/mm | 较差 |

### 5. RMS 分析

**类型**：
| 类型 | 说明 |
|------|------|
| RMS 波前 | 波前的均方根误差 |
| RMS 光斑 | 像面上光斑的 RMS 半径 |
| RMS 质心偏移 | 光斑质心与参考点的偏移 |

**质量标准**：
| Strehl 比 | RMS 波前 (λ) | 质量 |
|-----------|--------------|------|
| > 0.8 | < 0.074 | 衍射极限 |
| > 0.5 | < 0.15 | 良好 |
| > 0.2 | < 0.25 | 一般 |

### 6. 圈入能量 (Encircled Energy)

**用途**：评估进入特定半径内的能量比例。

**参数设置**：
| 参数 | 说明 |
|------|------|
| 半径范围 | 开始/结束半径 |
| 半径步长 | 采样间隔 |
| 参考中心 | 质心/主光线 |

**关键指标**：
| 指标 | 说明 |
|------|------|
| EE50 | 50% 能量集中半径 |
| EE80 | 80% 能量集中半径 |
| EE95 | 95% 能量集中半径 |

**应用**：
- 光纤耦合效率评估
- 探测器像元匹配
- 照明系统均匀性

### 7. 扩展图像分析 (Extended Scene Analysis)

**用途**：模拟实际场景的成像效果。

**分析内容**：
- 图像重建
- 畸变效果可视化
- 渐晕效果评估

## 偏振与表面物理组

### 偏振分析 (Polarization)

**分析功能**：
| 分析 | 说明 |
|------|------|
| Jones Matrix | 偏振态传递矩阵 |
| Polarization Pupil Map | 偏振瞳图 |
| Polarization Ray Tracing | 偏振光线追迹 |

### 表面分析 (Surface)

| 分析 | 说明 |
|------|------|
| 矢高图 (Sag Plot) | 表面面型 |
| 曲率图 (Curvature Plot) | 表面曲率分布 |
| 相位图 (Phase Plot) | 表面相位延迟 |

### 膜层分析 (Coatings)

**分析功能**：
| 分析 | 说明 |
|------|------|
| 膜层性能 | 透过率/反射率 vs 波长 |
| 膜层瞳图 | 入射角依赖性 |
| 膜层优化 | AR/HR 膜层设计 |

## 激光与光纤组

### 物理光学传播 (Physical Optics Propagation, POP)

**用途**：基于菲涅尔衍射的精确光束传播。

**参数设置**：
| 参数 | 说明 |
|------|------|
| 采样网格 | X/Y 采样点 |
| 传播距离 | 起始/结束/步长 |
| 光束参数 | 束腰/瑞利范围 |

**分析内容**：
- 光束半径 vs 距离
- 相位分布
- 干涉图案
- 耦合效率

## 报告组

### 系统数据摘要 (System Summary)

**输出内容**：
```
OpticStudio System Summary
=========================================
有效焦距:        100.00 mm
入瞳直径:        25.00 mm
工作 F/#:        4.00
视场数:          3
波长数:          3
总长度:          150.23 mm
后焦距:          15.67 mm
```

### 表面数据报告 (Surface Data Report)

**输出内容**：
- 所有表面的完整参数
- 曲率半径
- 厚度
- 材料
- 半口径
- 求解类型

### 分类数据报告 (Prescribed Data Report)

**输出内容**：
- 系统规格摘要
- 基面数据
- 主光线数据
- 光学特性

### 基面数据 (Cardinal Data)

**输出内容**：
| 参数 | 说明 |
|------|------|
| 物方焦距 | 第一焦点到主平面距离 |
| 像方焦距 | 最后焦点到主平面距离 |
| 主平面位置 | 相对于顶点 |
| 节点位置 | 角放大率 = -1 的点 |

## 非序列模式分析

### 光线追迹组

| 分析 | 说明 |
|------|------|
| 光线追迹 (Ray Trace) | 标准光线追迹 |
| Lightning 追迹 | 高效大量光线追迹 |
| 特定光线比对 | 指定光线比较 |

### 探测器组

| 分析 | 说明 |
|------|------|
| 探测器查看器 | 能量分布可视化 |
| 探测器工具 | 探测器数据处理 |

### 光线数据库查看器

**用途**：分析单条光线的完整追迹路径。

**输出内容**：
- 光线命中序列
- 每次交互的坐标
- 反射/折射角度
- 偏振状态

## 通用绘图工具

### 一维通用绘图 (Universal Plot 1D)

**用途**：参数扫描分析。

**参数设置**：
- X 轴：可选择任意变量
- Y 轴：任意分析类型
- 扫描范围和步长

### 二维通用绘图 (Universal Plot 2D)

**用途**：双参数扫描分析。

**参数设置**：
- X/Y 轴：两个变量
- 颜色映射：分析结果

## 分析结果导出

### 支持的导出格式

| 格式 | 说明 |
|------|------|
| CSV | 数值数据 |
| TXT | 文本数据 |
| PNG | 图像 |
| EMF | 矢量图 |

### 数据提取方法

1. **手动复制**：使用 Windows 剪贴板
2. **分析窗口菜单**：文件 → 导出
3. **ZOS-API**：程序化数据提取
4. **ZPL 宏**：自动化脚本
