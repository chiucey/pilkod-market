# 电子显微镜技术助手

## 技能范围

本技能涵盖电子显微镜领域的两大主要类型及其核心分析技术：

### 1. 扫描电子显微镜 (SEM)

**基本原理**
- 利用聚焦电子束扫描样品表面
- 通过检测二次电子、背散射电子等信号成像
- 分辨率：通常 1-10nm

**主要成像模式**
| 成像模式 | 检测信号 | 应用场景 |
|---------|---------|---------|
| 二次电子像(SEI) | 二次电子 | 表面形貌观察 |
| 背散射电子像(BEI) | 背散射电子 | 成分对比、晶界识别 |
| 阴极荧光(CL) | 阴极荧光 | 材料发光特性 |
| 电子束感应电流(EBIC) | 感应电流 | 半导体缺陷检测 |

### 2. 透射电子显微镜 (TEM)

**基本原理**
- 电子束穿透超薄样品成像
- 可实现原子级分辨率(球差校正后可达0.5Å)
- 样品厚度要求：<100nm

**主要成像模式**
| 成像模式 | 说明 | 应用场景 |
|---------|-----|---------|
| 明场像(BF) | 中心束成像 | 常规形貌观察 |
| 暗场像(DF) | 衍射束成像 | 缺陷、位错分析 |
| 高分辨像(HRTEM) | 相位衬度 | 晶格结构分析 |
| STEM像 | 扫描透射 | Z-衬度成像 |

### 3. 电子衍射技术

**选区电子衍射(SAED)**
- 原理：聚光束照射样品特定区域，晶格衍射形成衍射花样
- 应用：相鉴定、晶体取向测定

**会聚束电子衍射(CBED)**
- 原理：电子束呈锥形会聚照射样品
- 应用：对称性分析、晶体缺陷精确测定

**电子背散射衍射(EBSD)**
- 原理：入射电子与倾斜样品晶格相互作用产生背散射电子衍射
- 应用：晶粒取向、织构分析、相分布
- 空间分辨率：20-50nm

### 4. X射线特征分析

**能量色散X射线谱(EDS/EDX)**
- 原理：电子束激发样品产生特征X射线
- 检测范围：Be(4)-Am(95)
- 应用：元素定性定量分析、元素分布图(线扫描、面扫描)

**波谱色散X射线谱(WDS)**
- 原理：利用分光晶体按波长分离X射线
- 优势：分辨率高于EDS，定量精度高
- 应用：高精度元素分析

## 厂商与技术现状

### 主要厂商

| 厂商 | 代表产品 | 技术特点 |
|-----|---------|---------|
| FEI/Thermo Fisher | Quanta系列、Helios | 场发射枪、低电压成像 |
| JEOL | JSM系列、JEM系列 | 浸没式物镜、球差校正 |
| Zeiss | Gemini系列 | 镜筒内InLens探头 |
| Hitachi | SU系列 | 快速成像、 cryo-SEM |

### 技术发展趋势

**球差校正技术**
- 物镜球差校正器实现亚埃级分辨率
- STEM-HAADF可达0.5Å点分辨率

**低电压成像**
- 1kV以下低电压SEM，减少样品损伤
- 低电压TEM成像技术

**原位电镜**
- 加热、冷却、电场、力学加载原位样品杆
- 实时观察材料动态行为

**Cryo-EM技术**
- 冷冻电镜用于生物样品
- 2020年诺贝尔化学奖相关技术
- 单颗粒分析实现原子分辨率

## 常见应用领域

1. **材料科学**
   - 纳米材料表征
   - 晶界、析出相分析
   - 力学行为原位观察

2. **半导体工业**
   - 工艺监控与缺陷分析
   - 失效分析
   - 良率提升

3. **生命科学**
   - 细胞超微结构观察
   - 病毒颗粒分析
   - 组织病理学

4. **地质矿物学**
   - 矿物鉴定
   - 成矿作用研究
