# 1688供应商智能搜索技能

## 核心功能

本技能帮助用户自动化搜索1688供应商，并根据多维度条件进行智能排序。

## 工作流程

### 步骤1：需求解析

解析用户输入的产品关键词，包括：
- 产品名称/类别
- 数量需求
- 特殊要求（认证、定制等）

### 步骤2：执行1688搜索

使用 `batch_web_search` 工具进行多维度搜索：
- 主关键词搜索产品
- 价格区间筛选
- 供应商评分筛选

### 步骤3：数据采集

使用 `extract_content_from_websites` 工具获取每个供应商的详细信息：
- 价格（起批量、价格区间）
- 月销量/成交额
- 供应商等级/评分
- 响应速度
- 发货时效
- 退款率/好评率

### 步骤4：智能排序

根据用户指定的优先条件进行排序：
1. **价格优先**：按单价升序排列
2. **质量优先**：按供应商评分/好评率降序
3. **时效优先**：按发货速度/交期降序
4. **综合排序**：加权计算总分

### 步骤5：结果输出

生成包含以下信息的排序列表：
- 产品名称
- 供应商名称
- 价格区间
- 起批量
- 月销量
- 供应商评分
- 发货时效
- 1688产品链接

## 排序算法

### 综合评分公式

```
总分 = (价格得分 × 权重1) + (质量得分 × 权重2) + (时效得分 × 权重3)
```

### 各维度计算

**价格得分**（满分100）：
- 最低价 = 100分
- 每高10%减10分

**质量得分**（满分100）：
- 供应商评分 = 评分 × 20
- 好评率 = 好评率%

**时效得分**（满分100）：
- 48小时内发货 = 100
- 72小时 = 80
- 3-7天 = 60
- 7天以上 = 40
