# Excel 数据整理技能

## 触发条件

当用户上传 Excel 文件并提出以下需求时触发：
- 整理/清洗 Excel 数据
- 匹配/对齐表头
- 标准化列名
- 重命名表头字段
- 数据去重或格式化

## 核心能力

### 1. 表头识别与匹配

**智能表头匹配**：
- 支持模糊匹配（包含关键词即匹配）
- 支持同义词映射（如"姓名"/"名称"/"Name"）
- 支持大小写不敏感匹配
- 生成匹配报告，显示原始列与目标列的对应关系

**预定义表头模板**：
```
通用字段映射表（references/header-mapping.md）
```

### 2. 数据整理操作

| 操作类型 | 说明 | 使用场景 |
|---------|------|---------|
| 列重排 | 按指定顺序重新排列列 | 数据规范化 |
| 列重命名 | 更改列标题名称 | 统一命名规范 |
| 数据清洗 | 去除空格、特殊字符、空值处理 | 数据质量提升 |
| 去重 | 删除重复行 | 数据去重 |
| 数据类型转换 | 文本转数值/日期格式化 | 数据标准化 |
| 缺失值填充 | 用指定值或计算值填充空白 | 数据完整化 |

### 3. 输出格式

- 保持原文件格式（.xlsx）
- 可选：同时输出整理报告（CSV格式）
- 自动命名：`原文件名_整理后.xlsx`

## 执行流程

### Step 1: 读取文件

```
使用 xlsx 技能读取上传的 Excel 文件
提取表头行和数据内容
显示原始数据概览
```

### Step 2: 表头分析

```
分析原始表头内容
识别列数据类型
检测潜在问题（空表头、重复列名）
```

### Step 3: 匹配与映射

```
根据用户需求或模板进行表头匹配
显示匹配结果确认
用户可调整匹配规则
```

### Step 4: 数据整理

```
执行选定的整理操作
实时预览效果
记录数据变更
```

### Step 5: 输出结果

```
生成整理后的 Excel 文件
可选：生成数据变更报告
提供下载链接
```

## 使用示例

### 示例 1：标准化表头

**用户输入**：
```
上传员工表.xlsx，需要将表头标准化为：工号、姓名、部门、职位、入职日期
```

**执行过程**：
1. 读取文件，识别原始表头：`["ID", "Name", "Dept", "Pos", "HireDate"]`
2. 智能匹配：`ID→工号, Name→姓名, Dept→部门...`
3. 用户确认映射关系
4. 执行重命名，生成标准化文件

### 示例 2：数据清洗

**用户输入**：
```
上传销售数据.xlsx，需要：
1. 去除"金额"列中的货币符号
2. 将"日期"列格式化为 YYYY-MM-DD
3. 删除"客户名称"为空的行
```

**执行过程**：
1. 识别各列数据类型
2. 应用清洗规则
3. 预览清洗效果
4. 确认后生成干净的数据集

## 错误处理

| 错误类型 | 处理方式 |
|---------|---------|
| 文件格式不支持 | 提示用户上传 .xlsx 或 .xls 文件 |
| 空文件 | 提示文件无数据内容 |
| 表头匹配失败 | 显示未匹配列，提供手动映射选项 |
| 数据类型错误 | 跳过问题单元格，生成错误报告 |

## 依赖工具

- **xlsx 技能**：用于读取和写入 Excel 文件
- **minimax-xlsx**：高级表格处理能力

## 注意事项

1. **数据安全**：不保存上传的原始文件，处理后自动清理
2. **格式兼容**：优先使用 xlsx 格式，支持 .xls 向下兼容
3. **大数据处理**：单文件超过 10 万行时提示用户分割文件
4. **备份建议**：处理前提示用户备份原始文件
