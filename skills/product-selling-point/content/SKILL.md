# 产品卖点挖掘专属技能

## 触发口令（任意一句都能激活）
- 帮我提炼产品卖点
- 上传资料挖卖点
- 产品卖点分析
- 把这份产品介绍提炼优势
- 卖点挖掘助手启动

## 适用输入
1. 用户粘贴纯文字产品介绍
2. 用户上传产品说明书、参数文档、详情页文案
3. 用户发产品图文、参数表、原材料/工艺介绍
4. 工业产品/日用品/数码/食品/家居全品类通用

## 强制执行SOP（AI必须按步骤来）

### 步骤1：全文清洗&抓核心信息
- 剔除广告废话、重复话术、无效修饰词
- 锁定关键板块：参数、材质、工艺、功能、颜值、售后、性价比、适用人群、使用场景、专利资质

### 步骤2：分层挖掘3级卖点

1. **硬核功能卖点**（参数/性能/配置/专利/技术）
2. **体验场景卖点**（好用/省心/便捷/安全/美观）
3. **差异化竞品卖点**（别人没有、我们独有、升级优化）

### 步骤3：标准化输出格式（固定模板，不许乱改）

📌【一、核心硬核卖点（技术/参数/资质）】
逐条短句精炼，每条10–20字，直白有力

📌【二、用户体验卖点（场景/感受/便利）】
贴合日常使用，讲痛点解决

📌【三、差异化独家卖点（比同行强在哪）】
突出稀缺性、独有优势、升级点

📌【四、可直接复用文案（短视频/标题/详情页）】
提炼5条短文案，适合发圈、上架、口播

### 步骤4：兜底规则
- 资料太少：主动提示「请补充产品参数/材质/用途/目标人群」
- 专业产品（工业/器械）：加重技术、资质、耐用性卖点
- 日用电商产品：加重颜值、场景、性价比、便捷性

## 使用示例

**用户输入**：粘贴一堆保温杯资料

**AI输出**：直接按上面四级模板输出精炼卖点+可用文案

# 卖点挖掘执行手册

## 一、信息清洗规则

### 必须剔除的内容
- 空洞形容词：优质、卓越、领先、顶级、极致
- 重复表述：同一卖点说三遍以上
- 无效修饰：精美的外观、贴心的设计（需具体化）
- 绝对化用语：100%、绝对、保证（规避极限词）

### 必须保留的内容
- 具体参数：功率、容量、尺寸、材质型号
- 认证信息：专利号、检测报告、标准认证
- 对比数据：与XX相比提升X%
- 使用场景：具体的人物、时间、地点行为

## 二、卖点分级标准

### A级卖点（必须突出）
| 特征 | 示例 |
|------|------|
| 行业独家/首创 | 首款、独家专利、唯一认证 |
| 数据硬核 | 99.9%灭菌率、10年质保、5秒速热 |
| 颠覆认知 | 比同类轻60%、省电80% |

### B级卖点（重点展示）
| 特征 | 示例 |
|------|------|
| 明显优于同行 | 双层隔热、无缝内胆 |
| 解决痛点 | 防滑底垫、静音电机 |
| 场景适配 | 车载/户外/母婴专用 |

### C级卖点（锦上添花）
| 特征 | 示例 |
|------|------|
| 通用优势 | 精美包装、颜色多样 |
| 常规配置 | 一年质保、售后无忧 |

## 三、行业差异化策略

### 工业/机械类
- 重点挖掘：技术参数、耐用性、售后响应、资质认证、安全标准
- 弱化：外观颜值、情感诉求
- 文案风格：专业、数据化、权威背书

### 食品/保健品类
- 重点挖掘：成分配方、安全认证、功效数据、适用人群
- 弱化：过度承诺、绝对化表述
- 文案风格：可信、科学、具体

### 日用/消费品类
- 重点挖掘：使用场景、外观设计、性价比、便捷性
- 弱化：过于专业的技术参数
- 文案风格：生活化、有画面感、引发共鸣

### 数码/电子产品类
- 重点挖掘：性能参数、创新功能、智能体验、兼容生态
- 弱化：抽象的技术名词
- 文案风格：科技感、场景化、易理解

## 四、文案复用模板

### 短视频口播脚本
```
开场痛点：还在为XX烦恼？
产品解决：有了它，XX秒搞定！
核心卖点：关键是XX（数据/专利）
使用场景：不管是XX还是XX，都能XX
行动号召：点击下方链接，XX元带回家！
```

### 电商标题公式
```
核心词 + 差异化卖点 + 场景/人群 + 情感词
示例：304不锈钢保温杯 | 24h保冷保热 | 户外运动车载专用 | 送礼自用两相宜
```

### 详情页首图文案
```
产品名 + 核心USP（一句话解决什么）
示例：五层锁温技术，24小时热水随行
```

## 五、质量自检清单

输出前必须检查：
- [ ] 每条卖点是否具体、可感知？
- [ ] 是否有具体数据支撑？
- [ ] 是否避免了极限词/绝对化用语？
- [ ] 文案是否朗朗上口、易记忆？
- [ ] 是否区分了不同级别的卖点？
- [ ] 是否适配目标用户的理解水平？
