## 组件详解

### MaxHermes (赫尔墨斯)

赫尔墨斯是希腊神话中的信使，象征通信和传递。在本系统中代表：

**核心职责：**
1. **意图识别** - 理解用户想要什么
2. **对话状态管理** - 维护多轮对话上下文
3. **响应生成** - 生成自然、连贯的回复

**技术实现：**
```python
# 意图分类
intents = ['research', 'development', 'creative', 'coding', 'design', 'general']

# 对话状态
dialogue_state = {
    'turn_count': int,
    'last_intent': str,
    'context_window': List[str],  # 最近N轮对话
    'user_preferences': Dict
}
```

### MaxClaw (爪子)

爪子象征力量和执行能力。在本系统中代表：

**核心职责：**
1. **工具选择** - 根据任务选择合适的工具
2. **代码执行** - 安全地执行代码
3. **错误处理** - 优雅地处理异常

**支持的工具类型：**
- 文件操作（read, write, edit）
- 命令执行（bash）
- API调用
- 代码执行
- 数据处理

### DeerFlow (鹿流)

鹿象征优雅和流畅。在本系统中代表：

**核心职责：**
1. **任务分解** - 将复杂任务分解为可管理的子任务
2. **依赖管理** - 管理子任务之间的依赖关系
3. **结果整合** - 合并多个子任务的结果

**任务图结构：**
```python
TaskGraph = {
    'nodes': {
        'task_id': {
            'description': str,
            'status': 'pending' | 'running' | 'completed' | 'failed',
            'result': Any
        }
    },
    'edges': {
        'task_id': ['dependent_task_ids']
    }
}
```

## 记忆体层次

### L1: 短时会话记忆

**特征：**
- 容量：100条
- 有效期：1小时
- 淘汰策略：LRU

**用途：**
- 当前对话的上下文
- 最近的查询和回复
- 临时计算结果

### L2: 任务记忆

**特征：**
- 作用域：当前任务
- 持久性：任务期间

**用途：**
- 当前任务状态
- 子任务列表
- 任务历史

### L3: 项目记忆

**特征：**
- 持久化存储
- 跨会话

**用途：**
- 项目上下文
- 相关文档
- 长期目标

### L4: 知识库

**特征：**
- 向量化存储
- 语义检索

**用途：**
- 结构化知识
- 最佳实践
- 技术文档

### L5: 进化记忆

**特征：**
- 经验存储
- 模式提取

**用途：**
- 成功案例
- 失败教训
- 优化建议

## 进化机制

### 学习循环

```
执行任务 → 记录结果 → 分析模式 → 提取知识 → 优化策略 → 执行任务
    ↑                                                            │
    └────────────────────────────────────────────────────────────┘
```

### 优化触发条件

1. **成功率下降** - 当某个任务类型的成功率低于阈值
2. **性能下降** - 当平均执行时间超过历史平均
3. **经验积累** - 当积累了足够多的新经验

### 优化策略

1. **任务分解** - 将大任务分解为小任务
2. **并行执行** - 利用任务间的独立性并行执行
3. **缓存复用** - 复用之前的计算结果
4. **策略切换** - 尝试不同的执行策略

### 自定义记忆层

```python
# 扩展 FiveLayerMemory
class ExtendedMemory(FiveLayerMemory):
    async def store(self, layer, key, value, metadata=None):
        if layer == 6:  # 新增第6层
            return await self._store_l6(key, value)
        return await super().store(layer, key, value, metadata)
```

## 性能考虑

1. **异步优先** - 所有I/O操作使用异步
2. **缓存策略** - 合理使用L1缓存减少重复计算
3. **批量操作** - 批量读写减少I/O次数
4. **连接池** - 复用数据库连接
