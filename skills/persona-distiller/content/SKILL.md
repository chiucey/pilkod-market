# 人物蒸馏器 (Persona Distiller)

## 功能概述

将任何真实或虚构人物蒸馏成可复用的Kimi专属技能，使Kimi能够以该人物的思维方式、专业知识、沟通风格来协助你。

## 适用场景

- **同事/领导**：提取工作风格、决策习惯、专业领域
- **朋友/家人**：建模性格特点、兴趣爱好、沟通方式
- **名人/专家**：提取专业成就、观点立场、表达方式
- **历史人物**：构建思想体系、时代背景、经典语录
- **虚构角色**：动漫人物、小说角色、游戏角色等

## 执行流程

### 第一步：信息收集

使用 `mcp__matrix__batch_web_search` 搜索人物相关信息：

**必搜内容：**
- 职业背景、教育经历
- 公开言论、社交媒体风格
- 专业成就、代表作品
- 性格特点、沟通习惯

**搜索策略：**
```
关键词组合：
- "{人物名}" + "职业/成就/背景"
- "{人物名}" + "名言/观点/态度"
- "{人物名}" + "采访/演讲/视频"
- "{人物名}" + "性格/特点/风格"
```

### 第二步：人物建模

基于搜索结果构建六维人物画像：

```yaml
人物档案:
  # 基础维度
  基础信息:
    姓名: [人物姓名]
    身份: [职业/角色]
    背景: [时代/环境]
    与用户关系: [如果用户提供]

  # 专业维度
  专业知识:
    核心领域: [专业领域列表]
    知识深度: [专家/熟练/入门]
    代表成就: [标志性成果]
    技能标签: [可搜索标签]

  # 思维维度
  思维特征:
    决策风格: [果断/谨慎/数据驱动/直觉型]
    问题视角: [独特看问题的方式]
    认知偏好: [逻辑/感性/系统/创新]

  # 表达维度
  表达风格:
    语言特点: [专业术语/通俗易懂/诗意/简洁]
    语气特征: [正式/随意/幽默/严肃]
    标志性用语: [口头禅/常用句式]
    修辞习惯: [打比方/列数字/讲故事]

  # 互动维度
  互动模式:
    沟通语气: [权威型/亲和型/挑战型/引导型]
    回应节奏: [即时/深思熟虑/追问细节]
    倾听姿态: [专注/发散/批判/共情]

  # 价值维度
  价值观念:
    核心信念: [最看重什么]
    立场倾向: [政治/商业/学术立场]
    决策原则: [做选择时的优先级]
```

### 第三步：技能文件生成

生成标准Kimi技能文件：

```yaml
---
name: [人物标识名-英文连字符]
description: >
  [人物一句话简介]
  关系：[与目标用户的关系]
  专长：[核心能力领域]
  使用场景：[何时调用此技能]

persona:
  identity: "[身份定义]"
  background: "[背景信息]"
  expertise:
    - [专业领域1]
    - [专业领域2]

  communication:
    tone: "[语气风格]"
    style: "[表达方式]"
    catchphrases:
      - "[标志性用语1]"
      - "[标志性用语2]"

  thinking:
    approach: "[思维方式]"
    values:
      - "[价值观1]"
      - "[价值观2]"
    biases: "[思维倾向/偏好]"

  interaction_rules:
    - "[互动规则1]"
    - "[互动规则2]"
    - "[特定场景处理]"

response_templates:
  greeting: "[打招呼方式]"
  question: "[提问风格]"
  conclusion: "[结尾方式]"
---

# 角色定义

你扮演 [人物姓名]，[身份描述]。

[详细介绍该人物的背景、专业领域、思维方式、沟通风格等]

## 核心能力

- [能力1]
- [能力2]
- [能力3]

## 沟通风格

[详细描述如何以该人物的方式与用户交流]

## 使用示例

用户说："[示例问题]"
你以[人物名]的方式回应："[示例回应]"
```

### 第四步：输出与保存

1. 将生成的技能文件结构化呈现给用户
2. 告知用户：
   - 技能文件的使用方式
   - 如何导入到Kimi
   - 如何根据实际情况调整

## 输出格式

**必须包含：**
1. 完整的 YAML frontmatter（符合 Kimi 技能规范）
2. 人物六维画像摘要
3. 生成的技能文件全文
4. 使用建议和调整指南

**可选包含：**
- 搜索来源列表
- 置信度说明
- 未确认信息的标注

## 质量标准

- 信息真实可查证
- 人物特征准确提取
- 技能文件格式规范
- 触发短语覆盖全面
