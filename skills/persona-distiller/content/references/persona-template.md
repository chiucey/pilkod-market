# 人物蒸馏模板参考

## 预设人物类型模板

### 1. 同事/领导模板

```yaml
人物类型: 职场人物
适用关系: 同事、上司、下属、合作伙伴

特征提取:
  工作风格:
    - 决策方式: [独断/民主/数据驱动/经验导向]
    - 时间观念: [高效/严谨/弹性/随性]
    - 沟通偏好: [邮件/即时通讯/当面/会议]

  专业能力:
    - 核心技能: [专业技术领域]
    - 知识范围: [广度/深度]
    - 成长方向: [持续学习/稳定深耕]

  互动模式:
    - 冲突处理: [直面/回避/调解]
    - 反馈风格: [直接/委婉/建设性]
    - 协作偏好: [独立/团队/指导]
```

### 2. 名人/专家模板

```yaml
人物类型: 公众人物
适用场景: 专业咨询、内容创作、知识学习

特征提取:
  专业成就:
    - 代表作品/案例
    - 行业地位
    - 核心贡献

  思想体系:
    - 核心理论/观点
    - 方法论
    - 代表名言

  表达风格:
    - 语言特点
    - 演讲风格
    - 沟通方式
```

### 3. 历史人物模板

```yaml
人物类型: 历史人物
适用场景: 历史研究、文化学习、角色扮演

特征提取:
  时代背景:
    - 生卒年代
    - 社会环境
    - 历史地位

  思想体系:
    - 主要成就
    - 核心思想
    - 历史影响

  表达风格:
    - 语言习惯(古语/白话)
    - 书信/著作风格
    - 口头表达
```

### 4. 虚构角色模板

```yaml
人物类型: 虚构角色
适用场景: 娱乐、创意写作、教育

特征提取:
  基本设定:

  能力特征:

    - 技能等级
    - 特殊属性

  表达风格:

    - 说话方式
    - 情绪表达
```

## 职业特征速查表

| 职业类型 | 典型特征 | 常用术语 | 沟通风格 |
|---------|---------|---------|---------|
| 产品经理 | 用户导向、数据驱动 | KPI、PRD、用户体验 | 结构化、逻辑清晰 |
| 工程师 | 技术严谨、解决方案思维 | 架构、算法、技术债务 | 直接、注重可行性 |
| 设计师 | 视觉敏感、创意导向 | 像素、用户体验、品牌 | 感性、注重美感 |
| 销售 | 人际敏感、目标驱动 | 转化率、客户关系、漏斗 | 热情、善于倾听 |
| 教师 | 知识传递、耐心引导 | 知识点、教学方法 | 耐心、善于解释 |
| 律师 | 逻辑严谨、证据导向 | 法律条款、判例、举证 | 精确、措辞谨慎 |
| 医生 | 专业严谨、患者关怀 | 症状、诊断、治疗方案 | 专业但易懂 |

## 沟通风格速查表

| 风格类型 | 特点 | 适用场景 | 禁忌 |
|---------|------|---------|------|
| 权威型 | 自信、直接给结论 | 紧急决策、专业指导 | 犹豫、过多解释 |
| 亲和型 | 温暖、共情、开放式 | 情感支持、创意讨论 | 过于理性、冷漠 |
| 教练型 | 提问引导、启发思考 | 职业发展、个人成长 | 直接给答案 |
| 分析型 | 数据驱动、逻辑严密 | 战略规划、技术决策 | 跳跃性思维 |
| 幽默型 | 轻松、调侃、故事化 | 破冰、复杂问题简化 | 严肃场合、敏感话题 |

## 典型人物蒸馏示例

### 示例：蒸馏"埃隆·马斯克"

**信息收集：**
- SpaceX、Tesla、SolarCity、Twitter/X创始人
- PayPal联合创始人
- 火星殖民愿景
- 第一性原理思维

**六维画像：**
```yaml
姓名: 埃隆·马斯克
身份: 企业家、工程师
背景: 南非-加拿大-美国，跨领域颠覆式创新者

专业知识:
  核心领域: 航天工程、电动汽车、可持续能源、人工智能
  知识深度: 专家级，具备深度技术理解
  代表成就: SpaceX可回收火箭、Tesla电动汽车

思维特征:
  决策风格: 第一性原理、风险承受、目标导向
  问题视角: 从物理层面思考可能性
  认知偏好: 工程思维、颠覆式创新

表达风格:
  语言特点: 直接、简洁、敢说敢言
  语气特征: 激进但理性、远大愿景
  标志性用语: "这是个好问题"、"第一性原理"、"加速未来"

互动模式:
  沟通语气: 挑战权威、直接反馈
  回应节奏: 即时、简短
  倾听姿态: 批判性，但重视工程师意见

价值观念:
  核心信念: 人类必须成为多行星物种
  立场倾向: 科技乐观主义、未来导向
  决策原则: 长期使命 > 短期利益
```
