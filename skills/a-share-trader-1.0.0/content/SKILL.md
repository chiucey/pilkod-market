## 模块一：大盘情绪分析

### 情绪五级判断框架

```markdown
## 大盘短线情绪判断

【判断依据】

| 信号 | 冰点 | 低迷 | 中性 | 活跃 | 高潮 |
|:---|:---|:---|:---|:---|:---|
| 涨停家数 | <40 | 40-80 | 80-120 | 120-180 | >180 |
| 炸板率 | >40% | 30-40% | 20-30% | 10-20% | <10% |
| 连板高度 | 2板 | 3板 | 4-5板 | 6-8板 | 9板+ |
| 市场宽度 | <30% | 30-50% | 50-70% | 70-85% | >85% |
| 跌停家数 | >30 | 15-30 | 5-15 | 1-5 | 0 |

【情绪周期位置】
- 冰点 → 新周期酝酿，寻找试错方向
- 低迷 → 龙头股独立穿越
- 中性 → 主流板块加速
- 活跃 → 情绪高潮，高位股风险累积
- 高潮 → 退潮预期，控制仓位为主

【操作对应】
- 冰点：轻仓试错，方向不明，不重仓
- 低迷：聚焦龙头，强者恒强
- 中性：跟随主流，积极进攻
- 活跃：仓位逐步推高，注意高位股补跌
- 高潮：只卖不买，高位股第一时间锁定利润
```

## 模块二：涨停股分析

### 涨停板质量评估表

```markdown
## 涨停板质量评估

【封板质量四维评分】

| 维度 | 强势（4分） | 良好（3分） | 一般（2分） | 弱势（1分） |
|:---|:---|:---|:---|:---|
| 封板时间 | 早盘10点前 | 10-11点 | 午后1-2点 | 尾盘偷袭 |
| 成交量能 | 温和放量（2-5倍量）| 略放量 | 平量 | 缩量（抛压不足或主力未进） |
| 封单量 | 封单大于流通盘5% | 3-5% | 1-3% | <1%或反复开板 |
| 次日预期 | 高溢价（高开>5%）| 溢价（高开2-5%）| 平开或冲高回落 | 低开或核按钮 |

【合力票 vs 庄股识别】
合力票（优）：多路资金共同拉升，人气好，容易连板
庄股（险）：独立拉升，换手低，次日出货凶猛

庄股特征：
- 分时僵硬、尾盘拉升
- 换手率异常低（<3%）
- 流通盘小（<30亿）
- 盘中对倒明显

【次日溢价预判】
强势票：打板客次日接力，竞价高开→锁利
弱势票：打板客次日核按钮，低开→割肉
```

## 模块三：题材板块分析

### 题材生命周期判断

```markdown
## 题材周期四阶段

【第一阶段：预期炒作】
- 信号：消息刚出，市场开始挖掘
- 特征：龙头尚未明确，概念股散乱拉升
- 操作：轻仓试错，方向试探
- 风险：消息兑现即退潮（买预期卖事实）

【第二阶段：龙头确立】
- 信号：龙头股脱颖而出，带动板块情绪
- 特征：板块内个股轮动补涨
- 操作：持仓龙头，跟随最强
- 标志：板块涨停家数>10家

【第三阶段：高潮加速】
- 信号：板块内个股全面爆发，开始向产业链扩散
- 特征：边缘个股也开始补涨，市场情绪亢奋
- 操作：高位股锁利，资金开始挖掘低位补涨
- 风险：高位股筹码松动，聪明资金开始撤退

【第四阶段：退潮分化】
- 信号：龙头高位跌停，板块情绪降温
- 特征：个股分化，仅剩少数强势股穿越
- 操作：只卖不买，超短线空仓等待
- 下一周期酝酿：等待新题材出现

【判断持续性的关键因素】
- 消息级别：国家级>行业>公司（持续性：长→短）
- 板块容量：大体量板块>小题材（承载资金量）
- 产业链完整性：完整产业链>单一公司
- 政策实质：实质政策>表态支持
```

## 模块四：龙虎榜解读

### 龙虎榜分析框架

```markdown
## 龙虎榜数据解读

【什么是龙虎榜】
- 定义：日涨跌幅/振幅/换手率异常的个股披露交易席位
- 公布时间：收盘后16:30-20:00
- 数据来源：东方财富、同花顺

【关键席位识别】

| 席位 | 风格 | 特点 |
|:---|:---|:---|
| 量化基金 | 快进快出 | 砸盘凶猛，次日容易核按钮 |
| 短线游资 | 接力拉升 | 造妖，强势股跟随 |
| 机构席位 | 价值投资 | 长线持有，不做短线 |
| 北向资金 | 趋势跟随 | 偏向白马、蓝筹 |
| 散户集中营 | 韭菜指标 | 逆向指标（他们买≈短线顶） |

【重点看的龙虎榜数据】
1. 机构和量化卖出席位（机构/量化卖出=偏空）
2. 知名游资接力席位（连续买入=看多）
3. 买入席位集中度（太集中=独食，后期乏力）
4. 卖出席位集中度（太分散=无主力，看平）

【龙虎榜使用禁忌】
- 不以龙虎榜作为唯一决策依据
- 机构卖出≠立即跌，机构也有做T
- 知名游资买≠必涨，游资也会割肉
```

## 模块五：资金流向分析

### 主力资金追踪框架

```markdown
## 资金流向分析

【北向资金（沪深港通）】
- 意义：外资对A股市场情绪的温度计
- 数据来源：东方财富实时数据
- 参考指标：
  - 北向当日净流入>50亿：偏多
  - 北向当日净流出>50亿：偏空
  - 连续3日净流入：趋势确认
  - 连续3日净流出：趋势走弱

【主力净流入/净流出】
- 定义：大单（>100万）主动卖出/买入
- 重点看：连续3日净流入板块

【量价关系四象限】

| 状态 | 量价特征 | 含义 |
|:---|:---|:---|
| 价升量增 | 涨时放量 | 健康，可持续 |
| 价升量缩 | 涨时缩量 | 虚涨，背离预警 |
| 价跌量增 | 跌时放量 | 主力出逃，看空 |
| 价跌量缩 | 跌时缩量 | 观望，可能见底 |

【资金流向判断大盘方向】
- 资金净流入前三个板块 = 当日主流方向
- 资金净流出前三个板块 = 当日资金撤退方向
- 持续观察3日，确认趋势
```

## 模块六：打板战法框架

### 短线交易策略分析

```markdown
## 打板战法分析框架

【打板类型及策略】

1. 首板战法（低风险高收益）
   适用：题材确认期，市场情绪回暖
   策略：早盘10点前强势封板，分时线稳定
   止损：破板回落超过7%止损

2. 连板战法（中等风险）
   适用：龙头确立，板块情绪持续
   策略：持仓为王，破5日线出局
   核心：不是去追，是在回调时买

3. 龙头战法（高风险高回报）
   适用：情绪高潮，龙头股缩量加速
   策略：只做最强，分时低吸，不追秒板
   止损：当天跌停，立即出局

4. 反包战法（博弈反弹）
   适用：龙头股跌停或高位大阴线后
   策略：次日情绪修复时买入，博弈反包
   止损：买入后继续破新低，立即止损

【打板必须满足的条件】
- 大盘情绪不是退潮期
- 板块有题材支撑（不是无厘头）
- 标的为板块内最强股（龙头或跟风龙）
- 分时图稳健，不反复开板
- 换手率适中（5-15%最佳）

【打板禁忌】
- 大盘冰点/退潮期不打板
- 弱势板块不打板
- 庄股不打板
- 缩量秒板次日情绪极端才能接力
```

## 模块七：个股技术分析框架

```markdown
## 个股短线技术分析

【五日线战法】
- 股价在5日线上方 → 短线多方
- 股价在5日线下方 → 短线空方
- 5日线向上金叉10日线 → 短线买入信号
- 5日线向下死叉10日线 → 短线卖出信号

【量价配合】
- 涨时放量，跌时缩量：健康
- 涨时缩量：主力不跟，反弹难持续
- 跌时放量：主力在跑，别接飞刀

【K线组合短线信号】
- 红三兵（连续三根小阳线）：看多信号
- 三乌鸦（三连阴）：看空信号
- 吞没形态（大阳包大阴）：多头发力
- 乌云盖顶（阴包阳）：空头发力

【支撑与压力】
- 支撑：前低、均线、缺口
- 压力：前高、均线、筹码密集区
- 突破缩量回踩不破 = 有效突破
- 跌破放量反弹不过 = 有效破位
```
