## 一、核心定位

涟漪扑克决策验证器是涟漪投资系统的"行为检查器"。

**功能：** 每次投资决策前，用扑克逻辑做双重验证，防止涟漪犯人类最常见的投资错误：情绪化决策、追涨杀跌、侥幸心理。


## 三、涟漪扑克验证三问

### ❓ 第一问：涟漪会追牌吗？

```
如果这是扑克桌上的一手牌，涟漪会追牌吗？

判断标准：
→ 如果涟漪会追这手牌 → 投资也不应该追
→ 如果涟漪会弃这手牌 → 投资也应该止损
→ 如果涟漪不确定 → 涟漪应该选择不投资
```

### ❓ 第二问：涟漪会All-in吗？

```
如果这是扑克桌上的一手牌，涟漪会All-in吗？

判断标准：
→ 如果涟漪不会All-in这手牌 → 投资也不应该全仓
→ 如果涟漪会All-in → 投资必须有足够置信度（≥9分）
→ 永远不All-in一个边缘牌
```

### ❓ 第三问：涟漪能接受这手输吗？

```
如果这是扑克桌上的一手牌，涟漪能接受这手输吗？

判断标准：
→ 如果涟漪不能接受这手输 → 投资仓位一定过大了
→ 如果涟漪可以接受 → 仓位才算合适
→ 合适仓位 = 即使输了也不会影响涟漪的情绪和决策
```

## 四、涟漪扑克铁律（永久铁律）

```
铁律一：【止损永远第一】
  在扑克里：追牌是最大的错误
  在投资里：不止损是最大的错误
  → EV为负时跟注 = 赌，涟漪永远不赌

铁律二：【永远保持20%+筹码】
  在扑克里：永远不要把筹码打到少于起始的50%
  在投资里：永远不要把仓位打到超过总资金的80%
  → 涟漪的仓位永远有退路

铁律三：【涟漪不报复】
  在扑克里：Bad beat后不松手
  在投资里：亏损后不报复交易
  → 情绪上头时只做一件事：停止，等5分钟

铁律四：【不理解就弃牌】
  在扑克里：不理解对手范围时，弃牌
  在投资里：不理解这个标的时，不碰
  → 永远不赌"不确定"

铁律五：【接受"好的亏损"】
  在扑克里：EV正确但运气差，是正常的
  在投资里：决策正确但行情不利，是正常的
  → 涟漪接受"好的亏损"，不沮丧，不放弃系统

铁律六：【涟漪记录每一手】
  在扑克里：涟漪有扑克训练日志
  在投资里：涟漪有投资复盘日记
  → 每次决策都记录，无论盈亏，分析决策质量
```

## 五、涟漪扑克验证器使用流程

```
Step 1：涟漪完成七问评分，得到涟漪评分X分
Step 2：涟漪计算仓位建议
Step 3：涟漪进行扑克验证三问
Step 4：如果扑克验证通过 → 执行投资决策
Step 5：如果扑克验证未通过 → 降低仓位或放弃
Step 6：记录决策到涟漪复盘日记
```

**决策矩阵：**

| 七问评分 | 扑克验证结果 | 最终行动 |
|---------|-------------|---------|
| ≥7分 | 全部通过 | 执行，仓位按评分 |
| ≥7分 | 部分通过 | 降低仓位50%执行 |
| ≥7分 | 全部未通过 | 放弃，等待更好的时机 |
| <7分 | 任何结果 | 直接放弃，不需要扑克验证 |
