# 五行十神内容创作

输入任意公历日期，自动完成五行十神分析并输出完整内容方案。

## 输入格式

```
分析 [YYYY-MM-DD] 的五行结构，日主是 [天干]
例：分析 2026-03-21，日主是癸
```

> **日主 = 用户出生日的天干。** 输入格式中「日主」字段决定十神判断的基准。

## Step 1 — 排天干地支

万年历或手掌诀定位日柱：

- **日柱 = 当日天干 + 当日地支**
- 天干顺序：甲乙丙丁戊己庚辛壬癸
- 地支顺序：子丑寅卯辰巳午未申酉戌亥
- 日柱按60甲子循环，可查表或用算法推算

**日柱速查原则（无需死记，用手掌诀）：**
立春后寅月建为首起算点，日干按5日一位循环推算。日常使用中直接查万年历更高效。

## Step 3 — 能量结构分析

### 表里分析法（核心框架）

对日柱分别从「天干」和「地支藏干」两个维度分析：

**天干 = 表层（外在表现）**
> 这一天在外人面前呈现的能量特征

**地支藏干 = 里层（内在支撑）**
> 这一天的底层能量，支撑天干的表现

**分析格式：**

```
日柱：[X]   天干[X] — [表层特征]
日支藏干：[本气A/中气B/余气C]

表层：天干[十神] → [外在表现]
里层：地支[十神]+[十神]+[十神] → [内在格局]
综合主题：[一句话概括]
```

### ⚠️ 十神计算注意事项（必读）

**判断基准是「日主阴阳」，不是藏干阴阳。**

计算步骤：
1. 计算藏干天干索引与日主天干索引的差值
2. 差值 → 确定五行生克关系
3. **同时根据日主阴阳，决定用同性栏还是异性栏**

示例（甲午日，日主=甲木）：
- 甲木 index=0，午藏干丁火 index=3，差值=3
- 差值3=「我生者」：甲木生丁火
- 日主甲木=阳木 → 阳生阴（异性）→ **伤官**
- 易错点：丁火是阴火，但这不是判断基准；「甲木生丁火=异阴阳」才是判断基准

常见错误：直接用藏干的阴阳套用十神栏位，而不看日主阴阳。**日主阴阳决定用哪一栏。**

## Step 5 — 三层内容结构（高转发公式）

玄学/命理/穿搭类内容统一用三层结构：

```
第1张：诊断钩子
  → 筛选目标用户（你是不是X？）
  → 字数：≤30字
  → 情绪：好奇/轻微焦虑

第2张：核心共鸣
  → 2-3个具体特征/场景
  → 字数：≤60字
  → 情绪：对照感、"对！"

第3张：深度获得感+转发钩子
  → 具体行动方案/判断标准
  → 结尾加转发理由（转给闺蜜/转给特定人）
  → 字数：按需
```

### 高转发内容三驱动

1. **社交荣誉感** — "我怎么知道的这么多"
2. **关系润滑剂** — "转给xxx看看"
3. **情绪共鸣释放** — "终于有人说明白了"
