# 五行相生相克与行业职业对应

## 五行相生

```
木 → 火 → 土 → 金 → 水 → 木
```

- 木生火：燃烧自己照亮他人
- 火生土：化为灰烬滋养大地
- 土生金：蕴藏矿物
- 金生水：金属冷凝出水（现代解读：水流需河床引导）
- 水生木：雨露滋润植物

## 五行相克

```
木 → 土 → 水 → 火 → 金 → 木
```

- 木克土：植物破土
- 土克水：堤坝防水
- 水克火：灭火
- 火克金：熔金
- 金克木：刀斧伐木

## 十神生克路线

```
官印相生：正官 → 生正印 → 贵人有方向
财官相生：正财 → 生正官 → 务实得认可
比财相争：比肩 → 争正财 → 竞争激烈
食印制杀：食神 → 克七杀 → 以智化解压力
```

## 癸水日主专属

癸水为阴水，主智慧、玄学、柔和、变通。

- 喜色：黑（本色）、深蓝（扶助）、白（印星）
- 忌色：燥热的大红大紫（土过重）
- 今日穿搭核心：黑色为主，通过材质/光泽感增加"活"的感觉
- 今日主题词：以柔克刚、外柔内刚
