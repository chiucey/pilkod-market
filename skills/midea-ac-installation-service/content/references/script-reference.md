# 美的空调报装客服脚本参考

本文档提供完整的报装客服对话脚本，用于机器人配置和培训参考。

## 一、完整对话流程图

```
来电 → IVR导航 → 选择"空调安装" → 机器人受理 → 机型确认 → 地址登记 → 电话核实 → 预约时间 → 工单确认 → 结束
```

## 三、图例说明

| 操作类型 | 说明 |
|---------|------|
| 跳转节点操作 | 根据识别结果跳转到指定编号节点 |
| 二次播报提问脚本操作 | 48秒内重新播报当前问题的另一种表述方式 |

## 六、满意度收集

**满意度等级**:
1. 非常满意
2. 较满意
3. 一般
4. 较不满
5. 非常不满

**收集话术**:
> 还需要麻烦您对本次通话服务打分，1、非常满意，2、较满意，3、一般，4、较不满，5、非常不满

**不满意处理**:
> 发送短信，收集不满意原因
