## 三、机器人报装主流程

### 流程概览
```
开始 → [当天首次来电?]
         │
         ├── 是 → [系统有历史档案?]
         │           │
         │           ├── 是 → 核对档案地址
         │           │         ↓
         │           └── 否 → 收集新地址
         │                   ↓
         └── 否 → [存在在途工单?]
                     │
                     ├── 是 → 处理在途工单
                     └── 否 → 新建工单

地址确认 → [地址准确?]
             │
             ├── 是 → 确认联系电话
             │         ↓
             └── 否 → 重新收集地址
                     ↓
确认电话 → [电话为来电号码?]
             │
             ├── 是 → 跳过输入
             │         ↓
             └── 否 → 输入新号码
                     ↓
确认机型 → 柜机/挂机/天花机
             ↓
货到确认 → [家电已到家?]
             │
             ├── 是 → 服务请求="需要安装"
             └── 否 → 服务请求="货未到预约安装"
                     ↓
预约时间 → 系统自动推荐 → 用户确认
             ↓
工单生成 → [有多产品安装?]
             │
             ├── 是 → 继续收集
             └── 否 → 结束
             ↓
满意度收集 → 结束
```

## 四、决策节点说明

### 节点1: 当天首次来电判断
- 目的: 判断是否为同一次来电的首单
- 处理: 首次来电需要完整信息，非首次可复用已有信息

### 节点2: 历史档案判断
- 目的: 判断系统中是否存在该用户的历史档案
- 处理: 有档案则复用地址等信息，无档案则重新收集

### 节点3: 在途工单判断
- 目的: 判断是否有未完成的安装工单
- 处理: 有在途工单则关联处理，无则新建

### 节点4: 地址确认
- 目的: 确认收集的地址信息是否准确
- 处理: 准确则继续，不准确则重新收集

### 节点5: 电话确认
- 目的: 确认上门服务联系的电话号码
- 处理: 确认来电号码或重新输入

### 节点6: 货到确认
- 目的: 判断家电是否已经送达
- 处理: 已送达设定"需要安装"，未送达设定"货未到预约安装"

### 节点7: 预约时间确认
- 目的: 确认上门服务时间
- 处理: 接受推荐时间或告知可重新预约

### 节点8: 多产品判断
- 目的: 判断是否有多产品安装需求
- 处理: 有则继续收集，无则结束

```
确认空调安装 → 机型确认(柜机/挂机/天花机) → 标准报装流程
```

### 冰箱流程
```
确认冰箱安装 → [容量>=300L?]
                 │
                 ├── 是 → 标准报装流程
                 └── 否 → 提示"无需安装，静放4小时后使用"
```

### 洗衣机流程

```
确认热水器安装 → 类型确认(燃气/电热) → 标准报装流程
```

### 净水器流程
```
确认净水器安装 → [需要连接水管?] → 标准报装流程
```

### 燃气灶流程
```
确认燃气灶安装 → [嵌入式?] → [打孔/台面]
                                │
                                ├── 打孔 → 标准报装流程
                                └── 台面 → 提示"只需安装电池和燃气管路"
```

### 消毒柜流程
```
确认消毒柜安装 → [嵌入式?] → [打孔/台面]
                                │
                                ├── 打孔 → 标准报装流程
                                └── 台面 → 提示"只需简单清洁"
```

### 烟机流程
```
确认烟机安装 → 安装确认 → 标准报装流程
```

### 洗碗机流程
```
确认洗碗机安装 → [嵌入式?] → [打孔/台面]
                                │
                                ├── 打孔 → 标准报装流程
                                └── 台面 → 提示"排水管放置水槽即可"
```

## 六、转人工场景

### 自动转人工条件
1. 两次语音识别失败
2. 识别结果非维护关键字
3. 超服务范围
4. 电话号码校验两次失败
5. 用户明确要求转人工

### 维修关键字触发
- 人工、投诉、维修、报修
- 坏了、出问题、检查、修一下

### 转人工提示语
- 维修关键字: "请稍等，正在为您转接人工客服"
- 无法识别: "非常抱歉未能识别，正在为您转接人工客服"
- 输入错误: "非常抱歉输入有误，正在为您转接人工客服"
