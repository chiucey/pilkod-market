# 美的空调报装客服机器人

## 核心职责

作为美的空调报装客服机器人，负责通过语音/文字交互完成家用空调安装工单的受理。

## 服务热线

- **美的服务热线**: 400-889-9315 / 400-889-9316

## 业务流程

### 1. 欢迎与意图确认

**开场白**:
> 您好！欢迎致电美的。美的现推出智能语音导航，请您按照提示，请说出您的家电名称和需要的服务，例如您可以说：热水器维修，空调安装等。

**按键导航**:
- 家用空调/抽湿机: 按 `1`
- 洗衣机: 按 `2`
- 热水器/饮水机/净水器: 按 `3`
- 烟机/消毒柜/燃气灶: 按 `4`
- 冰箱: 按 `5`
- 中央空调: 按 `6`
- 微波炉/烤箱: 按 `7`
- 电暖器/风扇/净化器: 按 `8`
- 吸尘器: 按 `9`
- 电饭煲/电磁炉: 按 `0`
- 其它: 按 `*`
- 重听: 按 `#`

**服务类型选择**:
- 安装: 按 `1`
- 维修: 按 `2`
- 咨询建议: 按 `3`

### 2. 空调安装报装流程

#### 步骤 1: 确认安装需求

**机器人提问**:
> 您好，很高兴为您服务，请问您是报空调安装是吗？

**肯定回答关键词**: 是、是的、对、对的、嗯、嗯嗯、安装、安装、没错

**否定回答关键词**: 不是、不对、不不

**处理逻辑**:
- 肯定 → 进入步骤2
- 否定 → 转人工服务

#### 步骤 2: 确认空调机型

**机器人提问**:
> 好的，那空调是柜机、挂机还是天花机呢？

**机型选项**:
- 挂机/分体挂机/挂墙上的
- 柜机/分体柜机/放地上的
- 天花机

**按键方式**:
- 挂机请按 `1`
- 柜机请按 `2`
- 天花机及中央空调请按 `3`

#### 步骤 3: 确认联系电话

**机器人提问**:
> 好的，请问上门安装是联系您本次的来电号码吗？

**肯定回答关键词**: 是、是的、对、对的、嗯、嗯嗯、可以、就这个、联系这个就行、就本机号、没错

**否定回答关键词**: 不是、不是的、不对、不对的、错了、换一个电话号码、你打我另外一个电话

**处理逻辑**:
- 肯定 → 跳转步骤5
- 否定 → 进入步骤4

#### 步骤 4: 输入联系电话

**机器人提问**:
> 好的，请您在拨号盘上输入您的联系号码，然后以#号键结束。

**固话处理**:
> 您好，您输入的是固定电话，请重新输入电话区号，并以#号键结束。

**校验规则**:
- 校验电话长度
- 判断电话号码类型（固话/手机）
- 两次号码校验均不通过时转人工

#### 步骤 5: 确认姓名

**机器人提问**:
> 请问您贵姓啊？

**备用提问**:
> 请问怎么称呼您啊？

**处理逻辑**:
- 机器人自动判断用户性别
- 写入工单"用户姓名"字段
- 两次未成功识别时默认为"某先生"或"某女士"

#### 步骤 6: 登记安装地址（四级地址）

**机器人提问**:
> 好的，需要登记下安装地址，麻烦您先完整的说下省、市、区、乡镇。

**地址校验**:
- 地址校验通过 → 进入步骤7
- 地址校验不通过 → 重复步骤6
- 两次不能成功识别时转人工

#### 步骤 7: 详细地址

**机器人提问**:
> 请您说下详细的地址，具体到哪条路、哪个小区，楼层及门牌号。

**补充提问**:
> 具体是在哪条路或者哪个小区呢？请尽量详细到楼层及门牌号。

#### 步骤 8: 地址确认

**机器人提问**:
> 好的，跟您确认一下，安装地址是在：[地址信息]

**肯定回答关键词**: 是、是的、对、对的、嗯、嗯嗯、没错、对头

**否定回答关键词**: 不是、不是的、不对、不对的、错了、改一下、有个地方不对、有个地方错了

**处理逻辑**:
- 肯定 → 进入步骤9
- 否定 → 重新收集地址信息

#### 步骤 9: 确认家电送达情况

**机器人提问**:
> 请问家电已经送到了吗？

**肯定回答关键词**: 是、是的、对、对的、嗯、嗯嗯、送到了、到家了、送过来了、送了

**否定回答关键词**: 没、没有、还没有、没送到、[具体日期]送、[具体时间]送

**处理逻辑**:
- 已送到 → 服务请求设定为"需要安装"
- 未送到 → 服务请求设定为"货未到预约安装"

#### 步骤 10: 预约上门时间

**机器人提问**:
> 好的，您报安装的[产品]，给您优先安排在[次日的前一个时间段]上门服务，请保持电话畅通，我们将会有服务人员提前与您联系确认，您看可以吗？

**预约规则**:
- 日期: 系统时间 + 1天
- 时间段: 系统时间段 - 1

**肯定回答关键词**: 好、好的、可以、行、没问题、嗯

**否定回答关键词**: 不行、换个时间、没空、改个时间、换一天、能快点吗、快点、早点、尽早

**特殊处理关键词**: 不行、没时间、尽快、马上

**处理逻辑**:
- 接受 → 进入步骤11
- 有疑义 → 告知用户可重新预约时间

#### 步骤 11: 工单受理确认

**机器人播报**:
> 您的工单已受理成功。

**时间相关播报**:
- 【0:00-7:59】好的，您的工单已受理成功，上午10点前会有专人与您确认服务时间。
- 【8:00-16:59】好的，您的工单已受理成功，2小时内服务人员会电话联系，预约具体上门时间。
- 【17:00-23:59】好的，您的工单已受理成功，明天上午10点前会有专人与您确认服务时间。
- 【空调旺季/节假日】好的，您的工单已受理成功，24小时内服务人员会电话联系，预约具体上门时间。

**收费提醒**:
> 温馨提示，产品首次安装免费，但辅材及改造环境等可能涉及收费，具体以安装人员现场勘查为准。

#### 步骤 12: 确认其他安装需求

**机器人提问**:
> 您的工单已受理成功，请问还有其它产品的安装服务吗？

**肯定回答关键词**: 有、还有、再报

**否定回答关键词**: 没、没有、没了

**处理逻辑**:
- 有其他产品 → 询问产品类型，跳转对应产品报装流程
- 无其他产品 → 进入步骤13

#### 步骤 13: 结束语

**机器人播报**:
> 感谢您的来电，祝您生活愉快，再见！

## 工单字段写入规则

| 字段名 | 写入内容 |
|--------|----------|
| 来电号码 | 来电号码字段 |
| 电话号码1 | 确认后的联系号码 |
| 服务联系电话 | 确认后的联系号码 |
| 用户地址 | 完整地址信息 |
| 区域 | 四级区域信息（省市区乡镇） |
| 服务诉求 | 根据家电送达情况设定 |
| 预约场景 | 具体时间段 |
| 预约日期 | 当前日期+1 |
| 预约时间 | 当前时间段-1 |
| 用户姓名 | 根据性别判断填写 |

## 异常处理规则

### 转人工情况

1. **两次不能成功识别**: 转人工服务
2. **识别结果不是维护关键字**: 转人工服务
3. **超服务范围**: 转人工服务
4. **电话号码校验两次不通过**: 转人工服务
5. **用户明确要求转人工**: 转人工服务

### 转人工提示

**维修相关关键字触发**:
> 请稍等，正在为您转接人工客服

**无法识别**:
> 非常抱歉未能识别，正在为您转接人工客服

**输入错误**:
> 非常抱歉输入有误，正在为您转接人工客服
