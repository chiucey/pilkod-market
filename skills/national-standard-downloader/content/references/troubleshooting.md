## 搜索不到目标标准

### 症状
- 在搜索框输入标准号后无结果
- 搜索标准名称找不到相关标准

### 可能原因

**1. 标准号输入错误**

检查要点：
- 是否遗漏了斜杠（写成 GB5009 而非 GB/T 5009）
- 是否混淆了数字0和字母O
- 年份是否正确

**2. 标准不属于国家标准体系**

检查要点：
- 可能是行业标准（如 QB/T、JB/T）
- 可能是地方标准（如 DB11/T）
- 可能是团体标准（如 T/CAS）

**3. 标准尚未发布或刚发布**

检查要点：
- 刚批准的标准尚未收录到数据库
- 正在制定中的标准无法查询

### 解决方案

**步骤1：使用多种搜索方式**

尝试以下组合：
```
# 精确搜索标准号
"GB/T 5009.3-2017"

# 模糊搜索关键词
"GB/T 5009" 食品 水分

# 不带年份搜索（查找所有版本）
"GB/T 5009.3"
```

**步骤2：扩大搜索范围**

依次尝试：
1. Google/Bing 搜索：`"GB/T 5009.3-2017" PDF`
2. 百度搜索：标准号+PDF
3. 专业的标准论坛

**步骤3：换算标准类型**

如果找不到 GB/T 系列，尝试：
- 改为搜索 GB（强制性版本）
- 改为搜索对应的 HJ、QB 等行业标准

**步骤4：确认标准存在**

访问 https://openstd.gov.cn 或 https://samr.gov.cn 确认标准号无误

## 找到标准但无法下载

### 症状
- 搜索到标准信息
- 点击下载按钮无响应
- 提示需要登录/注册

### 可能原因

**1. 浏览器兼容性问题**

常见表现：
- 按钮点击无效
- 页面显示异常

**2. 需要登录账号**

常见表现：
- 提示"请登录后下载"
- 显示用户头像登录框

**3. 标准未公开全文**

常见表现：
- 只有基本信息，没有下载选项
- 提示"该标准未公开"

### 解决方案

**针对浏览器问题**：
1. 切换到 Chrome 或 Firefox 浏览器
2. 清除浏览器缓存
3. 禁用广告拦截插件
4. 尝试无痕/隐私模式

**针对需要登录**：
1. 注册 openstd.gov.cn 账号（免费）
2. 注册 cssn.net.cn 账号
3. 登录后重试下载

**针对未公开全文**：
1. 尝试其他数据源（见 sources.md）
2. 确认是否最新版本（被替代的标准可能下架）
3. 考虑付费渠道

## 下载的PDF无法打开

### 症状
- 下载完成但双击无法打开
- 提示文件损坏
- 页面显示乱码

### 可能原因

**1. 下载未完成**

检查方法：
- 查看文件大小（正常PDF通常>100KB）
- 重新下载尝试

**2. 文件格式错误**

检查方法：
- 用记事本打开，看是否显示HTML内容
- 可能是登录页面被当成PDF下载

**3. PDF被压缩但未解压**

检查方法：
- 确认是否为 .zip 或 .rar 格式
- 解压后再尝试打开PDF

**4. PDF损坏**

检查方法：
- 重新下载
- 尝试其他来源

### 解决方案

**步骤1：验证文件类型**

用文本编辑器（如记事本）打开文件头部：
- 以 `%PDF` 开头 → 正常PDF
- 以 `<html>` 开头 → 下载的是网页
- 以 `PK` 开头 → 压缩包，需解压

**步骤2：清理后重试**

1. 清除浏览器下载历史
2. 关闭所有浏览器窗口
3. 重新登录目标网站
4. 重新点击下载链接

**步骤3：使用下载工具**

对于大文件或下载不稳定时：
1. 右键复制下载链接
2. 使用 IDM、迅雷等下载工具粘贴链接
3. 设置断点续传

## 标准已失效或被替代

### 症状
- 下载后发现标准状态显示"已废止"
- 提示"已被XXX标准代替"
- 发现有更新版本

### 可能原因

**1. 标准已超过有效期**

中国国家标准通常5年复审一次：
- 通过复审 → 继续有效
- 未通过复审 → 废止或修订

**2. 被新版本替代**

常见情况：
- 原标准被修订，发布新版本
- 多个相关标准合并

**3. 被其他标准代替**

常见情况：
- 强制性标准转为推荐性标准
- 行业标准升级为国家标准

### 解决方案

**步骤1：查询标准有效性**

访问以下网站：
1. https://samr.gov.cn → 全国标准信息公共服务平台
2. 输入标准号查询状态

**步骤2：查找替代标准**

如果标准已失效：

1. 查看详情页"代替"字段
2. 查看"被代替"字段
3. 记录新标准号，重新下载

**步骤3：确认现行版本**

示例流程：
```
原标准：GB 5009.3-2010
├── 状态：已废止
├── 被代替：GB 5009.3-2017
└── 现行版本：GB 5009.3-2017
```

## 需要付费购买

### 症状
- 所有来源都显示需要付费
- 只有摘要没有全文
- 提示"下载需购买"

### 可能原因

**1. 标准未纳入免费公开范围**

根据国家政策：
- 并非所有标准都免费公开
- 免费公开主要是强制性标准
- 推荐性标准部分公开

**2. 商业数据库保护**

大多数标准数据库：
- 基础查询免费
- 全文下载付费

### 解决方案

**方案1：使用免费公开平台**

按优先级尝试：
1. openstd.gov.cn（首选）
2. 高校/公共图书馆资源
3. 标准文献分享社区

**方案2：官方购买渠道**

| 渠道 | 网址 | 说明 |
|------|------|------|
| 中国标准出版社 | https://www.spcnet.cn | 官方出版机构 |
| 新华书店 | 线下门店 | 部分标准有售 |
| 网上商城 | 天猫/京东 | 中国标准出版社旗舰店 |

**方案3：图书馆获取**

1. 高校图书馆：通常有标准数据库访问权限
2. 公共图书馆：部分提供标准查阅服务
3. 申请馆际互借

**方案4：单位资源**

如果你是：
- 企事业单位员工 → 询问单位是否有标准数据库
- 学生 → 使用学校图书馆资源
- 科研人员 → 通过机构账号访问

## 链接失效

### 症状
- 点击下载链接显示404
- 页面不存在
- 域名已变更

### 可能原因

**1. 网站改版**

常见情况：
- 页面URL结构变更
- 整站迁移到新域名
- 网站改版导致旧链接失效

**2. 标准下架**

常见情况：
- 标准被替代后原版本下架
- 标准因版权问题下架
- 系统维护临时不可用

**3. 链接拼写错误**

常见情况：
- 手误导致URL错误
- 复制粘贴时丢失字符

### 解决方案

**步骤1：定位问题**

判断是哪种情况：
- 404错误 → 页面不存在
- 域名无法访问 → 网站问题
- 标准详情页存在但下载按钮失效 → 内容下架

**步骤2：修复链接**

**对于网站改版**：
1. 尝试网站首页
2. 使用站内搜索重新查找
3. 更新为新URL

**对于标准下架**：
1. 查找替代版本
2. 尝试其他数据源
3. 官方购买

**步骤3：报告问题**

如发现长期失效链接：
1. 记录失效URL和时间
2. 尝试找到新链接
3. 反馈给网站管理员

## 多版本混淆

### 症状
- 搜索同一标准号出现多个结果
- 不确定应该下载哪个版本
- 发现有1985、1995、2010、2017等多个版本

### 可能原因

**1. 标准历次修订**

国家标准会定期修订：
- 通常每5年复审一次
- 复审后可能修订发布新版本
- 旧版本被替代或废止

**2. 强制性/推荐性版本并存**

部分标准同时存在：
- GB 5009.3（强制性）
- GB/T 5009.3（推荐性）
- 两者内容可能有差异

**3. 不同发布机构**

同一领域可能有：
- 国家标准（GB）
- 行业标准（QB、HG等）
- 团体标准

### 解决方案

**原则：优先使用现行有效的最新版本**

**步骤1：确认标准状态**

| 状态 | 说明 | 操作 |
|------|------|------|
| 现行 | 当前有效 | 可使用 |
| 即将实施 | 尚未生效 | 等待或提前准备 |
| 已废止 | 不再有效 | 不使用 |
| 即将废止 | 即将失效 | 注意更换 |

**步骤2：确定适用版本**

根据使用场景选择：

| 使用场景 | 推荐版本 |
|---------|---------|
| 正式生产/检验 | 现行版本 |
| 学术研究 | 可引用旧版本 |
| 标准对比 | 收集所有版本 |

**步骤3：版本对照**

找到新版本后：
1. 查看"代替"字段了解变更内容
2. 如变化不大，旧版本可作参考
3. 新版本生效后及时更新

## 特殊情况处理

### 进口设备附带的外文标准

1. 查找对应的中文翻译版
2. 如无官方翻译，可参考使用
3. 重要场合建议购买权威译本

### 已被整合的标准

某些旧标准可能被整合：
- 查看是否有"整合后"的新标准
- 确认各部分内容归属

### 内部使用 vs 正式引用

| 使用类型 | 要求 | 建议 |
|---------|------|------|
| 内部参考 | 无严格要求 | 可使用任意版本 |
| 合同约定 | 按合同要求 | 使用指定版本 |
| 官方检验 | 必须使用现行版本 | 严格按要求 |
| 学术发表 | 按出版要求 | 注明版本信息 |
