# 中国标准体系与编号规则

本文档详细介绍中国标准的分类体系、标准编号规则以及各类型标准的含义。

## 标准层级分类

### 国家标准 (GB)

由**国家标准化管理委员会**（隶属市场监管总局）批准发布，对全国经济技术发展有重大意义。

**层级细分**:

| 代码 | 名称 | 说明 | 示例 |
|------|------|------|------|
| GB | 强制性国家标准 | 具有法律约束力，必须执行 | GB 5009.3-2017 |
| GB/T | 推荐性国家标准 | 自愿采用，非强制 | GB/T 5009.3-2017 |
| GB/Z | 国家标准化指导性技术文件 | 供参考，不强制执行 | GB/Z 22758-2015 |

**编号结构**:
```
GB/T + 顺序号 + 年号
     │      │
     │      └── 发布年份（4位数字）
     │
     └───────── 标准类型代码
```

**示例解读**:
- `GB 5009.3-2017`
  - GB：强制性国家标准
  - 5009.3：顺序号（5009为食品检测大类，.3为具体项目）
  - 2017：2017年发布

---

### 行业标准

由国务院有关行政主管部门制定，报国家标准化管理委员会备案。

**常见行业代码**:

| 代码 | 行业 | 主管部门 |
|------|------|---------|
| QB | 轻工行业 | 工业和信息化部 |
| JB | 机械行业 | 工业和信息化部 |
| HG | 化工行业 | 工业和信息化部 |
| SH | 石油化工行业 | 工业和信息化部 |
| SY | 石油天然气行业 | 国家能源局 |
| HJ | 环境保护行业 | 生态环境部 |
| LY | 林业行业 | 国家林业和草原局 |
| SB | 商业行业 | 商务部 |
| WB | 物资管理行业 | 国务院国有资产监督管理委员会 |
| WH | 文化行业 | 文化和旅游部 |
| TY | 体育行业 | 国家体育总局 |
| JR | 金融行业 | 中国人民银行 |
| QC | 汽车行业 | 工业和信息化部 |

**编号结构**:
```
QB/T + 顺序号 + 年号
  │
  └───── 行业代码
```

**示例**:
- `QB/T 1803-2017` 轻工行业推荐标准
- `JB/T 5000-2019` 机械行业推荐标准
- `HJ 2541-2016` 环境保护行业推荐标准

---

### 地方标准 (DB)

由省、自治区、直辖市标准化行政主管部门制定，报国务院标准化行政主管部门备案。

**编号结构**:
```
DB + 省份代码 + / + 顺序号 + 年号
   │
   └───── 省份代码（两位字母）
```

**省份代码示例**:

| 代码 | 省份 |
|------|------|
| DB11 | 北京市 |
| DB31 | 上海市 |
| DB44 | 广东省 |
| DB33 | 浙江省 |
| DB32 | 江苏省 |

**示例**:
- `DB11/T 1234-2018` 北京市推荐标准
- `DB31/T 567-2019` 上海市推荐标准

---

### 团体标准 (T)

由学会、协会、商会、联合会等社会团体制定。

**编号结构**:
```
T + 团体代号 + 顺序号 + 年号
  │
  └───── 团体代码（如 CAS、CMA 等）
```

**常见团体代码**:

| 代码 | 团体名称 |
|------|---------|
| T/CAS | 中国标准化协会 |
| T/CNIA | 中国信息产业商会 |
| T/CC | 中国煤炭工业协会 |
| T/CSTE | 中国技术经济学会 |

---

### 企业标准 (Q)

由企业制定，在企业内部适用。

**编号结构**:
```
Q + 企业代号 + 顺序号 + 年号
```

---

## 标准号解析指南

### 解析步骤

**步骤1：识别前缀**
- `GB`/`GB/T`/`GB/Z` → 国家标准
- 两位字母 + `/T` → 行业标准
- `DB` + 省份代码 → 地方标准
- `T/字母` → 团体标准
- `Q/字母` → 企业标准

**步骤2：提取顺序号**
- 标准号中 `/` 前面的数字部分
- 部分标准有小数点（如 5009.3）

**步骤3：识别年份**
- 年号通常为4位数字
- 位于标准号末尾
- 如 2017、2023

## 标准版本与修订

### 版本标识

| 标识 | 含义 | 示例 |
|------|------|------|
| 首次发布 | 第一次发布该标准 | - |
| 第X号修改单 | 对标准的修改 | GB 5009.3-2017/X1-2018 |
| 代替 | 替代旧版本 | GB 5009.3-2017 代替 GB/T 5009.3-2010 |
| 废止 | 标准已废止 | - |

### 版本查询

**查询现行有效版本**:
1. 访问 samr.gov.cn 标准信息平台
2. 输入标准号查询
3. 查看"状态"字段

**判断是否为最新**:
- 如显示"已被 GB/T xxx-2023 代替"，则不是最新
- 如显示"现行"，则为现行有效版本

## 交叉引用与替代关系

### 替代关系类型

| 关系 | 说明 | 查询方法 |
|------|------|---------|
| 代替 | 新版本完全替代旧版本 | 查看详情页"代替"字段 |
| 部分代替 | 新版本替代旧版本的部分内容 | 查看标准前言 |
| 废止 | 标准不再有效 | 查看状态 |

### 查询替代信息的网站

1. **全国标准信息公共服务平台**
   - 网址：https://samr.gov.cn
   - 功能：查询标准替代关系

2. **国家标准全文公开系统**
   - 网址：https://openstd.gov.cn
   - 功能：查看被替代信息

## 识别标准有效性的要点

### 现行标准特征
- 状态显示"现行"
- 未被新标准替代
- 未被宣布废止

### 已废止标准特征
- 状态显示"已废止"
- 被新标准"代替"
- 超过复审周期未确认继续有效

### 正在修订的标准
- 标准状态显示"正在起草"或"征求意见"
- 尚未正式发布新版本

## 快速参考表

### 标准类型优先级（法律效力）

```
强制性国家标准 (GB)
    ↓
推荐性国家标准 (GB/T)
    ↓
行业标准
    ↓
地方标准
    ↓
团体标准
    ↓
企业标准
```

|---------------|---------|

| 地方标准 | 各省市场监管局网站 |
