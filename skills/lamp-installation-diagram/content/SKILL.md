# Эксперт по взрывным схемам сборки светильников

## Цель задачи

Данный навык предназначен для генерации 6-этапных взрывных чертежей поэтапной сборки светильника по предоставленному пользователем референсному изображению. Применяется для руководств по установке, технических описаний, учебных материалов.

## Режим генерации

**ОБЯЗАТЕЛЬНО использовать режим «Рисование по изображению» (Image-to-Image)**

- Входные данные: референсное изображение светильника
- Режим: Img2Img с контролем структуры
- Сила преобразования: 0.3-0.5 (сохранение структуры 85-95%)
- Дополнительные контрольные сигналы: не использовать

## Основные стилистические требования

### Базовые требования
- Холст: белый фон, чистые чёрные линии
- Линии: равномерные, плавные, без заусенцев, одинаковая толщина
- Перспектива: ортографическая проекция или изометрия, точность структуры
- Разрешение: 8K Ultra HD (8192x8192 или пропорциональное)

### Категорически запрещено
- Заливки, градиенты, тени, цвета, рендеринг
- Сложный фон, декоративные элементы, логотипы, водяные знаки
- 3D-эффекты, объёмные эффекты, имитация материалов
- Деформация, ошибки структуры, нарушение пропорций, размытие

## Руководство по генерации 6-этапных чертежей

### Шаг 1: Проверка компонентов при распаковке

**Основная задача**: Разложить и показать все компоненты с соответствующей нумерацией

**Промпт на шаге 1**:
```
Белый фон, чистая линейная графика, без заливок, градиентов, теней, цветов, рендеринга, без фона, строгое 1:1 воспроизведение референсного изображения светильника, полное сохранение формы, размеров, пропорций всех деталей, нулевая деформация, ЭТАП 1 Установки: Проверка компонентов, разложить и показать все детали с соответствующими номерами, без сборочных операций, равномерные плавные линии без заусенцев, 8K ультра HD, без лишних элементов

[Список компонентов]:
- Крепёжная пластина/подвес x1
- Основной корпус светильника x1
- Рассеиватель/плафон x1
- Крепёжные винты (по количеству)
- Анкерные болты (по количеству)
- Клеммная колодка/провода
- Прочие аксессуары

Требования к отображению:
- Все детали разложены в кадре
- Каждая деталь показана отдельно, равномерные промежутки
- Рядом с каждой деталью номер (①, ②, ③...)
- Под или рядом с каждой деталью название
```

### Шаг 2: Крепление монтажной пластины

**Основная задача**: Показать монтажную пластину, анкерные болты, установочные отверстия

**Промпт на шаге 2**:
```
Белый фон, чистая линейная графика, без заливок, градиентов, теней, цветов, рендеринга, без фона, строгое 1:1 воспроизведение референсного изображения светильника, полное сохранение структуры и размеров, нулевая деформация, ЭТАП 2 Установки: Крепление монтажной пластины, разборный вид только для пластины, анкерных болтов, установочных отверстий, скрыть лишние детали, точная логика монтажа, равномерные плавные линии без заусенцев, 8K ультра HD, без лишних элементов

Отображаемое содержание:
- Сечение стены/потолка (тонкие линии)
- Фронтальный/боковой разборный вид пластины
- Позиции анкерных болтов
- Обозначения установочных отверстий
- Соединение винтов с пластиной
- Размерные линии (опционально)

Логика разборки:
- Пластина отделена от стены
- Показать последовательность вкручивания
- Схема расширения анкера
```

### Шаг 3: Электроподключение

**Основная задача**: Показать клеммную колодку, соответствие фазного, нулевого, заземляющего проводов

**Промпт на шаге 3**:
```
Белый фон, чистая линейная графика, без заливок, градиентов, теней, цветов, рендеринга, без фона, строгое 1:1 воспроизведение референсного изображения светильника, полное сохранение структуры и размеров, нулевая деформация, ЭТАП 3 Установки: Электроподключение светильника, разборный вид только для клеммной колодки, соответствия фазного(L), нулевого(N), заземляющего(⊥) проводов, скрыть лишние детали, нормированная логика подключения, равномерные плавные линии без заусенцев, 8K ультра HD, без лишних элементов

Отображаемое содержание:
- Крупный план клеммной колодки
- Обозначения фазного(L), нулевого(N), заземляющего(⊥) проводов
- Различение цвета проводов (только типом линии, не цветом)
- Схема соединений клеммной колодки
- Обработка выступающих концов проводов
- Подсказки по безопасности

Типы линий:
- Фазный провод: сплошная линия
- Нулевой провод: пунктирная линия
- Заземляющий провод: штрих-пунктирная линия
```

### Шаг 4: Крепление основного корпуса

**Основная задача**: Показать корпус светильника, крепёжные винты, крепёжную пластину

**Промпт на шаге 4**:
```
Белый фон, чистая линейная графика, без заливок, градиентов, теней, цветов, рендеринга, без фона, строгое 1:1 воспроизведение референсного изображения светильника, полное сохранение структуры и размеров, нулевая деформация, ЭТАП 4 Установки: Крепление основного корпуса, разборный вид только для корпуса, крепёжных винтов, крепёжной пластины, скрыть лишние детали, чёткие сборочные уровни, равномерные плавные линии без заусенцев, 8K ультра HD, без лишних элементов

Отображаемое содержание:
- Фронтальный/боковой вид корпуса
- Позиции крепёжных винтов
- Подвесная связь корпуса с пластиной
- Направление затяжки винтов
- Обозначения последовательности сборки

Логика разборки:
- Уровень крепёжной пластины
- Уровень корпуса
- Уровень винтовых соединений
- Чёткие межуровневые связи
```

### Шаг 5: Установка рассеивателя/плафона

**Основная задача**: Показать рассеиватель, защёлки и корпус светильника

**Промпт на шаге 5**:
```
Белый фон, чистая линейная графика, без заливок, градиентов, теней, цветов, рендеринга, без фона, строгое 1:1 воспроизведение референсного изображения светильника, полное сохранение структуры и размеров, нулевая деформация, ЭТАП 5 Установки: Установка рассеивателя, разборный вид только для рассеивателя, защёлок и корпуса, скрыть лишние детали, точная логика монтажа, равномерные плавные линии без заусенцев, 8K ультра HD, без лишних элементов

- Направление вращения/защёлкивания

Логика разборки:

- Стрелки направления сборки
```

## Примеры использования

### Пример 1: Установка потолочного светильника

**Ввод пользователя**:
Пользователь загрузил референс современного минималистичного потолочного светильника, требуется генерация полной линейной графики процесса установки.

**Процесс выполнения**:
1. Анализ референса, идентификация структуры (кремёжный диск, LED-корпус, акриловый рассеиватель, анкерные болты, клеммная колодка)
2. Вызов возможностей генерации изображений, создание 6 чертежей поэтапно
3. Применение соответствующего промпта для каждого шага

**Результат генерации**:
- Шаг 1: Разложить кремёжный диск x1, корпус x1, рассеиватель x1, комплект винтов x4, анкерные гильзы x4, инструкция x1
- Шаг 2: Кремёжный диск отделён от стены, показать 4 установочных отверстия и сборку анкеров
- Шаг 3: Крупный план клеммной колодки, схема подключения трёх проводов
- Шаг 4: Корпус подвешен на кремёжный диск, установлены крепёжные винты
- Шаг 5: Акриловый рассеиватель защёлкнут в корпус
- Шаг 6: Готовый потолочный светильник

### Пример 2: Установка подвесного светильника

**Ввод пользователя**:
Пользователь предоставил изображение скандинавского подвесного светильника, требуется генерация схемы установки.

**Процесс выполнения**:
1. Анализ референса, идентификация структуры (цепь, чашка, патронник, рассеиватели x3, резьбовая шпилька)
2. Корректировка списка компонентов в промпте
3. Акцент на регулировку длины цепи и способ подвеса рассеивателей

**Особые корректировки**:
- Шаг 2: Показать потолочную распределительную коробку и соединение цепи
- Шаг 3: Электропроводка внутри чашки
- Шаг 4: Регулировка высоты подвеса на цепи
- Шаг 5: Раздельный подвес нескольких рассеивателей

### Пример 3: Установка настенного светильника

**Ввод пользователя**:
Пользователь предоставил референс современного настенного светильника.

**Процесс выполнения**:
1. Изменение угла отображения на настенную установку
2. Акцент на настенный способ крепления и угол кронштейна

**Особые корректировки**:
- Шаг 2: Крепление задней пластины настенного светильника
- Шаг 4: Соединение кронштейна с задней пластиной
- Сохранение линейной графики фона стены на всём протяжении

## Решение типичных проблем

### Проблема 1: Неопределённое количество компонентов
- Сначала генерировать по стандартной комплектации (4 винта, 4 анкерных гильзы)
- Корректировать обозначения после замечания пользователя

### Проблема 2: Сложная структура светильника
- Упростить некритичные компоненты
- Сохранять точность основной структуры
- На разборных видах скрывать декоративные элементы

### Проблема 3: Несоответствие стиля
- Сохранять единую толщину линий (основная линия 1-2px, вспомогательная 0.5px)
- Унифицировать стиль обозначений
- Использовать одинаковый угол обзора и масштаб
