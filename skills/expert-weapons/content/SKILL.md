# 武器装备设计专家

## 核心原则

好武器的三个标准：
1. **有名字**：能让读者一眼记住
2. **有性格**：与使用者的气质完全匹配
3. **有成长**：能跟随主角一起变强/进化

## 武器命名法

### 东方风格命名

```
前缀（材质/元素/意象）+ 后缀（武器类型）= 完整名
```

**前缀库**：
- 元素：赤霄（赤火）、玄冰（黑水）、青冥（风）、金霄（金）
- 天象：星河、苍穹、幽冥、九霄
- 意象：逆鳞（龙）、凤羽、麒麟角、泰初（天地之始）
- 材质：玄铁、寒玉、血纹钢、星辰金

**后缀库**：
- 剑类：剑、剑器、仙剑、凶剑
- 刀类：刀、战刀、霸刀
- 其他：戟、枪、锤、尺、环、绫

**经典命名**：
> 逆鳞·不灭剑（龙之逆鳞，触之即怒）
> 玄冰·九幽绫（寒冰所化，束缚一切）
> 苍穹·破虚戟（捅破苍穹之力）

### 西方风格命名

```
武器名 + of + 起源/特性
```

**经典命名**：
> 霜之哀伤（剑）
> 毁灭之刃
> 龙魂守护者（盾）
> 暗影猎手（弓）

## 武器类型与战斗风格对应

```
剑（通用，最适合装逼）：适合快意恩仇、剑意境界
刀（霸气，适合匪气/草莽主角）：适合霸道、以力压人
枪（战场、王者气概）：适合万人敌、有帝王相的主角
法杖（魔法体系）：适合法师主角，附带魔法效果
弓箭（远程）：适合冷静型、箭无虚发的主角
双刃/匕首（暗杀）：适合刺客/灵活性角色
锤（重武器）：适合力量型、以刚克刚
```

## 武器进化路线模板

```
**觉醒一阶**（出身/获得）：
武器的原始形态，威力有限，但有特殊属性与主人契合。

**蜕变二阶**（主人成长后）：
武器首次进化，外形改变，威力倍增，出现器灵/意识。

**进化三阶**（中期）：
武器核心材质升级，可能融合新元素，形成全新能力。

**终极形态**（大后期）：
神兵觉醒完整形态，主人与武器合二为一，可改写规则。
```

## 武器战斗描写框架

### 东方玄幻剑战

```
起手：剑意弥漫，主人气场全开
第一式：试探，剑光如丝，感知对方实力
第二式：展开，杀招尽出，天地失色
转折：剑意突破，心意即剑意，无招胜有招
终结：人剑合一，一剑定乾坤
```

**描写要点**：
- 声音：剑鸣如龙吟
- 视觉：剑气纵横三千里
- 感受：剑意刺骨，如芒在背

### 西幻武器战斗

```
起手：武器附魔激活，光芒/火焰/寒冰缠绕
施法：咏唱+武器引导，元素汇聚
爆发：终极技能释放（龙息/连锁闪电/神圣制裁）
终结：敌人倒下，武器吸收灵魂/能量

描写要点**：
- 声音：金属碰撞、魔法轰鸣
- 视觉：色彩斑斓的元素效果
- 代价：使用者体力/精神力大量消耗
```

## 装备系统（防具/饰品）

### 装备槽位

```
头（头盔/头饰）→ 胸（胸甲/护体软甲）→ 腰（腰带/护符）→
腿（护腿/护踝）→ 脚（靴子）→ 左手（盾牌/副手）→ 右手（主武器）
+ 饰品×2（戒指/项链/耳环等，可有特殊效果）
```

### 装备品质分级（东方）

```
凡品 → 灵品 → 玄品 → 地品 → 天品 → 仙品 → 神品 → 帝器
```

### 装备品质分级（西方）

```
普通（白色）→ 优秀（绿色）→ 精良（蓝色）→ 史诗（紫色）→ 传说（橙色）→ 神话（金色）
```

## 武器专属技能设计

每个神兵至少有一个"专属技能"，格式：

```
【技能名】：[效果描述]。使用条件：[限制条件/代价]
```

> 逆鳞·不灭剑专属技能：
> 【龙鳞守护】：激活后5秒内免疫一切伤害。代价：消耗等量寿元。每章限用一次。
