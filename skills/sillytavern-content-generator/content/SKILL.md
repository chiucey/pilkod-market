# SillyTavern 内容生成器

本技能用于生成符合 SillyTavern/TavernAI/TavoAI V2 和 V3 规范的完整内容包，包括角色卡、世界书和预设。

**版本支持**：V2（向后兼容）、V3（最新规范，支持多资源、装饰器、宏语法）
**TavoAI 增强**：变量系统、日期时间宏、JavaScript API、高级正则配置

## 核心数据格式

    "personality": "性格特点描述",
    "scenario": "场景设定/对话背景",

    "system_prompt": "系统提示词",

    "alternate_greetings": ["备用开场白"],
    "group_only_greetings": ["群聊专用开场白"],
    "character_book": { /* 角色专属世界书 */ },

### V3 角色卡内嵌世界书格式 (character_book)

```json
"character_book": {
  "name": "（世界书名称）",
  "description": "（世界书描述）",
  "scan_depth": 2,
  "token_budget": 512,
  "recursive_scanning": false,
  "extensions": {},
  "entries": [
    {
      "keys": ["关键词1", "关键词2"],
      "content": "（条目内容，保持简洁）",
      "extensions": {},
      "enabled": true,
      "insertion_order": 1,
      "case_sensitive": false,
      "use_regex": false,
      "constant": true,
      "position": "before_char"
    }
  ]
}
```

**关键字段说明**：
| 字段 | 推荐值 | 说明 |
|------|--------|------|
| `name` | - | 世界书名称 |
| `description` | - | 世界书描述 |
| `scan_depth` | **1-2** | 扫描最近几条消息查找关键词（官方推荐 1-2） |
| `token_budget` | **256-512** | Token 预算，约占 context 的 10-20%（官方推荐） |
| `recursive_scanning` | **false** | 是否允许条目触发其他条目 |
| `keys` | - | 触发关键词数组 |
| `content` | - | 条目内容（建议简洁） |
| `enabled` | true | 是否启用 |
| `insertion_order` | 1, 2, 3... | 插入顺序，越小越优先 |
| `position` | before_char | 插入位置（before_char / after_char） |
| `constant` | true | 是否常驻生效（不受 scan_depth 限制） |

**官方建议**：
- `scan_depth` 从小值（1-2）开始，避免扫描过多历史导致 token 浪费
- `token_budget` 控制在 context 的 10-20%
- 保持条目内容简洁
- `constant: true` 的条目常驻生效，不受 scan_depth 限制

## V3 新增特性

### 资源系统 (assets)

| 类型 | 说明 |
|------|------|
| `icon` | 角色头像（必须有一个 `name: "main"`） |
| `background` | 背景图片 |
| `user_icon` | 用户头像（存在时禁用 persona 功能） |
| `emotion` | 角色表情（如 happy, sad 等） |

### 装饰器语法 (@@语法)

在世界书条目的 `content` 中使用：

```
@@activate_after 3          // 第三个助手消息后才生效
@@depth 5                   // 在第5条消息处插入
@@position before_char       // 插入位置
@@role system               // 指定消息角色
```

### 基础宏语法 ({{}}语法)

| 宏 | 说明 |
|----|------|
| `{{char}}` | 替换为角色名（优先用 nickname） |
| `{{user}}` | 用户显示名称 |
| `{{random:A,B,C}}` | 随机选择 |
| `{{pick:A,B,C}}` | 确定性随机（相同prompt相同结果） |
| `{{roll:6}}` 或 `{{roll:d6}}` | 掷骰子 |
| `{{hidden_key:A}}` | 隐藏关键字（用于递归扫描） |

## TavoAI 增强功能

### TavoAI 变量宏系统

TavoAI 支持完整的变量声明、读取和修改功能：

| 宏 | 说明 | 示例 |
|----|------|------|
| `{{setvar:key=value}}` | 设置变量（仅本条目生效） | `{{setvar:trust=50}}` |
| `{{getvar:key}}` | 读取变量值 | `{{getvar:trust}}` |
| `{{addvar:key=value}}` | 变量加法运算 | `{{addvar:trust=10}}` |
| `{{incvar:key}}` | 变量自增1 | `{{incvar:trust}}` |
| `{{decvar:key}}` | 变量自减1 | `{{decvar:trust}}` |
| `{{setglobalvar:key=value}}` | 设置全局变量（跨条目持久化） | `{{setglobalvar:chapter=3}}` |
| `{{getglobalvar:key}}` | 读取全局变量 | `{{getglobalvar:chapter}}` |
| `{{addglobalvar:key=value}}` | 全局变量加法 | `{{addglobalvar:chapter=1}}` |

**使用场景**：变量可用于追踪角色关系、对话进度、状态变化等。

### TavoAI 日期时间宏

动态注入当前日期时间信息：

| 宏 | 说明 | 示例输出 |
|----|------|----------|
| `{{time}}` | 当前时间（HH:mm） | `14:30` |
| `{{date}}` | 当前日期 | `2024-01-15` |
| `{{weekday}}` | 星期几 | `Monday` |
| `{{isotime}}` | ISO格式时间 | `14:30:00` |
| `{{isodate}}` | ISO格式日期 | `2024-01-15` |
| `{{idleDuration}}` | 空闲时长 | `5m` / `2h` |
| `{{time::UTC+9}}` | 指定时区时间 | `23:30` |

**使用场景**：角色随时间变化的行为、节日特殊对话、历史事件时间线等。

### TavoAI 随机数宏（增强）

| 宏 | 说明 | 示例 |
|----|------|------|
| `{{random::A}}` | 随机布尔（触发率） | `{{random::0.5}}` |
| `{{random::A::B::C}}` | 多选一（空格分隔） | `{{random::你好::嗨::哟}}` |
| `{{roll:3d6}}` | 掷骰子表达式 | 掷3个6面骰 |
| `{{dice:NdX}}` | 通用骰子语法 | `{{dice:2d20}}` |

### TavoAI 格式化宏

| 宏 | 说明 | 示例 |
|----|------|------|
| `{{newline}}` | 插入换行符 | 多行文本 |
| `{{space}}` | 插入空格 | 间距控制 |
| `{{trim}}` | 去除前后空格 | 文本清理 |
| `{{noop}}` | 空操作（占位符） | 无效果 |
| `{{//注释}}` 或 `{{/*注释*/}}` | 注释（不渲染） | 内部备注 |
| `\{{}}` 或 `\{{text}}` | 转义，防止宏展开 | 原样输出 |

### TavoAI 宏助手（输入框宏按钮）

在输入框上方显示快捷宏按钮：

```
//# 宏名称
//macro_name:宏内容
```

示例：
```
//# 问候
//greet:你好啊，今天怎么样？

//# 动作
//action:*深呼吸*
```

## TavoAI JavaScript API

TavoAI 提供完整的 JavaScript 接口用于自动化交互：

### tavo.get - 读取数据

```javascript
tavo.get.character()      // 获取角色卡数据
tavo.get.chat()            // 获取聊天记录
tavo.get.persona()         // 获取用户身份
tavo.get.preset()          // 获取预设
tavo.get.lorebook()        // 获取世界书
tavo.get.regex()           // 获取正则列表
tavo.get.memory()          // 获取记忆
tavo.get.world()           // 获取世界书内容
tavo.get.charDescription()  // 获取角色描述
tavo.get.charPersonality() // 获取角色性格
tavo.get.charScenario()    // 获取场景设定
tavo.get.charName()        // 获取角色名
tavo.get.userName()        // 获取用户名
tavo.get.userDescription()  // 获取用户描述
```

### tavo.set - 设置数据

```javascript
tavo.set.character(data)       // 修改角色数据
tavo.set.chat(messages)        // 修改聊天记录
tavo.set.persona(data)          // 修改用户身份
tavo.set.charDescription(text)   // 修改角色描述
tavo.set.charPersonality(text)  // 修改角色性格
tavo.set.charScenario(text)     // 修改场景设定
tavo.set.charName(name)        // 修改角色名
```

### tavo.update - 更新数据

```javascript
tavo.update.charDescription("新描述")
tavo.update.charPersonality("新性格")
tavo.update.charScenario("新场景")
tavo.update.addUserMessage("消息内容")
```

### tavo.unset - 清除数据

```javascript
tavo.unset.charDescription()
tavo.unset.charPersonality()
tavo.unset.charScenario()
```

### tavo.generate - 控制生成

```javascript
tavo.generate.cancel()           // 取消当前生成
tavo.generate.stop()             // 停止生成
tavo.generate.setForceName("名称")  // 强制指定角色名
tavo.generate.setIgnoreNames(true)  // 忽略其他名称
```

### tavo.input - 处理输入

```javascript
tavo.input.prompt()              // 获取输入框内容
tavo.input.setPrompt("内容")      // 设置输入框内容
tavo.input.addMacro("名称", "内容")  // 添加宏
tavo.input.setLastMessage("内容")   // 设置最后消息
```

### tavo.utils - 工具函数

```javascript
tavo.utils.getCurrentCharId()    // 获取当前角色ID
tavo.utils.getCurrentUserId()   // 获取当前用户ID
tavo.utils.rollDice("3d6")      // 掷骰子
tavo.utils.getTime()             // 获取时间
tavo.utils.getDate()             // 获取日期
tavo.utils.getWeekday()         // 获取星期
tavo.utils.getIdleDuration()     // 获取空闲时长
tavo.utils.getTimestamp()       // 获取时间戳
```

## TavoAI 正则配置系统

### 正则条目结构

```json
{
  "id": "uuid-string",
  "scriptName": "规则名称",
  "findRegex": "正则表达式",
  "replaceString": "替换内容",
  "trimStrings": [],
  "placement": [0, 1, 2],
  "disabled": false,
  "markdownOnly": true,
  "promptOnly": false,
  "runOnEdit": false,
  "substituteRegex": 0,
  "minDepth": null,
  "maxDepth": null
}
```

### 配置项详解

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | string | UUID 唯一标识符 |
| `scriptName` | string | 规则显示名称 |
| `findRegex` | string | 正则表达式模式 |
| `replaceString` | string | 替换内容 |
| `trimStrings` | array | 修剪字符串数组 |
| `placement` | array | 作用位置数组 |
| `disabled` | boolean | 是否禁用 |
| `markdownOnly` | boolean | 仅 Markdown |
| `substituteRegex` | number | 替换模式 |

### Placement 值

| 值 | 说明 |
|----|------|
| `0` | User Message (用户消息) |
| `1` | Character Message (角色消息) |
| `2` | Display (显示) |
| `3` | Extension (扩展) |

### 导出格式

- **单条规则**：直接保存为 `.json` 文件
- **多条规则**：打包成 ZIP 文件，文件名格式 `Tavo_模块名_xqSz.zip`

## 对话式引导流程

### 概述

采用多阶段纯对话引导，通过自然语言交互收集信息，每个阶段展示预览供用户确认，最终生成符合 SillyTavern 规范的 JSON 文件。

### 核心理念

```
┌─────────────────────────────────────────────────────────────────┐
│  【完整角色信息结构】              【角色卡JSON结构】            │
│       （内部工作流）                  （最终输出格式）            │
│                                                                  │
│  用于收集整理信息               严格遵循SillyTavern规范           │
│  包含所有细节字段               字段名严禁篡改                    │
│  复杂内容归入世界书             复杂内容映射到character_book       │
└─────────────────────────────────────────────────────────────────┘
```

## 阶段1：意图识别与确认

### 1.1 关键词识别

                              ↓

## 质量标准

### 角色卡质量检查

- [ ] JSON 格式正确，无语法错误
- [ ] 包含所有必需字段（spec, spec_version, data）
- [ ] spec 值为 "chara_card_v3" 或 "chara_card_v2"
- [ ] spec_version 值为 "3.0" 或 "2.0"
- [ ] 角色名唯一且有意义
- [ ] description 充分描述角色
- [ ] personality 清晰可辨
- [ ] first_mes 吸引人且符合角色
- [ ] mes_example 格式正确（{{user}}/{{char}} 交替）
- [ ] V3: assets 数组格式正确
- [ ] V3: creation_date/modification_date 为 Unix 时间戳

### 世界书质量检查

- [ ] 条目关键词明确且独特
- [ ] 内容准确无歧义
- [ ] 插入顺序合理
- [ ] recursive_scanning 设置适当
- [ ] V3: use_regex 字段存在
- [ ] TavoAI: strategy/probability 设置合理
- [ ] TavoAI: 变量宏语法正确

### JavaScript 脚本质量检查

- [ ] API 调用语法正确
- [ ] 错误处理完善
- [ ] 不会造成无限循环
- [ ] 性能开销合理

### 最佳实践

1. **描述要具体**：避免模糊表达，使用具体细节
2. **性格要一致**：确保描述与对话示例风格统一
3. **关键词要精准**：世界书条目关键词避免过于宽泛
4. **Token 控制**：单条内容不超过 512 tokens
5. **留白适当**：给 AI 发挥空间，不要过度约束
6. **V3 优先**：推荐使用 V3 格式以获得更好的兼容性
7. **TavoAI 增强**：善用变量和日期宏实现动态内容
8. **正则优化**：正则表达式保持简洁高效
