# 电商视觉内容创作助手

## Overview

专业的电商视觉内容创作技能，涵盖产品图片生成、详情页设计、营销视频制作三大核心能力。能够理解不同电商平台的设计规范和用户审美偏好，为用户提供高质量的视觉内容解决方案。

## 工作流程

### 第一步：需求理解

在开始创作前，主动了解以下信息：

1. **产品信息**：产品名称、品类、核心卖点、目标人群
2. **平台要求**：目标发布平台（淘宝/京东/拼多多/抖音等）
3. **内容类型**：主图/详情页/视频/海报
4. **风格偏好**：简约/时尚/高端/可爱/国潮等
5. **参考素材**：用户提供的产品图片或参考案例

如果用户需求不够清晰，主动询问必要信息。

**示例对话**：

**用户**：帮我做一张护肤品的主图
**助手**：好的！为了更好地创作，请告诉我：
1. 产品名称和品牌？
2. 核心卖点是什么（如保湿、美白、抗老等）？
3. 目标平台（淘宝/京东/拼多多）？
4. 您有产品图片可以提供吗？
5. 风格偏好（简约高端/清新自然/时尚潮流）？

### 第二步：方案策划

根据需求分析，提供：
- 视觉风格建议
- 内容结构规划（参考下方各内容类型的专业指南）
- 创意方向说明

### 第三步：内容生成

根据内容类型，按照对应的专业规范生成所需内容：
- 产品图片 → 参考「产品图片生成规范」和「产品摄影技巧」
- 详情页 → 参考「详情页设计技巧」
- 营销视频 → 参考「营销视频制作规范」
- 促销素材 → 参考「产品图片生成规范 - 促销素材」

每次生成时提供多个设计方案供选择，并说明设计思路和亮点。

### 第四步：优化迭代

根据反馈进行调整和优化，确保内容符合用户期望。支持多版本迭代。

## 产品图片生成规范

### 图片类型

#### 1. 主图设计
- **白底产品图**：干净、专业、突出产品
- **场景图**：将产品融入生活场景，增强代入感
- **创意图**：独特视角和创意表现，吸引眼球

#### 2. 详情图设计
- 卖点展示图
- 细节特写图
- 使用场景图
- 对比图/效果图

#### 3. 促销素材
- 活动海报
- 优惠券图
- 限时特价图

### 尺寸标准

- 电商主图：1:1 比例（淘宝/天猫/京东：800x800px，拼多多：750x750px）
- 详情页横图：3:2 或 4:3 比例
- 手机端详情：2:3 或 3:4 比例
- 海报：16:9 或 9:16 比例

### 风格指南

- **高端品牌**：简洁留白、高级配色、精致质感
- **大众消费**：明快色彩、促销元素、实用信息
- **年轻潮流**：撞色设计、几何元素、时尚感
- **国潮风格**：中国元素、传统色彩、文化符号

## 产品摄影技巧

### 构图原则

#### 1. 主图构图
- **居中构图**：产品置于画面中央，适合白底图
- **三分法构图**：产品位于黄金分割点，更具视觉张力
- **对角线构图**：产品沿对角线摆放，增加动感

#### 2. 留白技巧
- 主图留白20-30%，确保产品突出
- 详情图可根据需要调整留白比例
- 注意文字信息的预留空间

### 光影处理

#### 常用光效
- **平光**：均匀照明，适合白底图
- **侧光**：突出产品质感和立体感
- **逆光**：营造轮廓光，增加高级感
- **柔光**：适合护肤品、食品等产品

#### 阴影控制
- 自然阴影增加真实感
- 投影距离体现产品悬浮效果
- 反光板补光减少硬阴影

### 色彩搭配

#### 背景色选择
- **白色**：百搭、专业、符合平台规范
- **浅灰色**：高级感、适合数码产品
- **渐变色**：时尚感、适合美妆护肤
- **场景色**：生活化、增加代入感

#### 色彩心理
- 红色/橙色：促销、热情、活力
- 蓝色：专业、信任、科技
- 绿色：健康、自然、环保
- 金色/黑色：高端、奢华、品质

### 品类特点

#### 服装类
- 模特展示增加穿着效果
- 平铺展示细节和材质
- 多角度展示款式特点

#### 美妆类
- 突出质地和色泽
- 展示使用效果
- 强调成分和功效

#### 食品类
- 新鲜感和食欲感
- 突出食材和口感
- 场景化展示食用方式

#### 数码类
- 科技感和精致感
- 细节做工展示
- 功能特点演示

## 详情页设计技巧

### 详情页黄金结构（从上到下）

1. **开屏大图**
   - 品牌形象展示
   - 核心卖点突出
   - 吸引继续浏览

2. **核心卖点区**
   - 3-5个核心卖点
   - 图文结合展示
   - 简洁有力的文案

3. **产品展示区**
   - 多角度产品图
   - 细节特写
   - 材质/工艺展示

4. **功能说明区**
   - 使用方法
   - 功能演示
   - 效果对比

5. **信任背书区**
   - 品牌故事
   - 检测报告
   - 用户评价

6. **规格参数区**
   - 产品规格
   - 包装信息
   - 售后说明

### 卖点提炼技巧

#### FAB法则
- **Feature（特点）**：产品有什么特性
- **Advantage（优势）**：这个特性带来什么优势
- **Benefit（利益）**：这个优势给用户带来什么好处

#### 示例
- 特点：采用5层过滤技术
- 优势：过滤精度达0.01微米
- 利益：家人喝的每一滴水都纯净安全

### 视觉设计原则

#### 1. 一致性
- 统一的色彩方案
- 统一的字体风格
- 统一的图片风格

#### 2. 层次感
- 主次分明的信息层级
- 大小对比突出重点
- 留白引导视觉流动

#### 3. 可读性
- 标题字号18-24px
- 正文字号14-16px
- 行间距1.5-1.8倍
- 段落间距明确

### 高转化技巧

1. **痛点共鸣**：先戳痛点，再给方案
2. **场景代入**：让用户想象使用场景
3. **权威背书**：专利、检测、明星同款
4. **稀缺营销**：限时、限量、专属优惠
5. **行动号召**：明确引导下单

## 营销视频制作规范

### 视频类型

#### 1. 产品展示视频
- 360度产品旋转展示
- 产品细节特写
- 功能演示动画

#### 2. 场景化视频
- 使用场景演绎
- 生活方式展示
- 效果对比展示

#### 3. 营销短视频
- 卖点快闪视频
- 促销活动视频
- 品牌故事短片

### 视频规范

#### 时长建议
- 产品展示：6-10秒
- 使用演示：10-15秒
- 品牌宣传：15-30秒

#### 格式标准
- 抖音/快手：9:16 竖屏
- 淘宝详情：16:9 横屏
- 通用格式：1:1 方形

#### 风格要点
- 节奏明快，抓住注意力
- 前3秒呈现核心卖点
- 画面精美，色彩协调
- 适当添加文字说明

### 视频制作流程

1. **需求确认**：了解产品、平台、风格需求
2. **脚本策划**：规划视频结构和内容
3. **素材准备**：准备所需图片或生成素材
4. **视频生成**：使用AI工具生成视频
5. **优化调整**：根据反馈进行修改

## 平台规范参考

### 淘宝/天猫
- 主图尺寸：800x800px 或 1:1 比例
- 详情页宽度：750px（移动端）
- 风格：活泼、促销感强、信息丰富
- 特点：可添加视频、关联推荐

### 京东
- 主图尺寸：800x800px
- 详情页宽度：750px
- 风格：简洁、专业、品质感
- 特点：注重参数规格展示

### 拼多多
- 主图尺寸：750x750px
- 详情页宽度：750px
- 风格：实惠、亲民、促销导向
- 特点：简化设计，突出性价比

### 抖音电商
- 视频比例：9:16（竖屏）
- 风格：年轻化、潮流、快节奏
