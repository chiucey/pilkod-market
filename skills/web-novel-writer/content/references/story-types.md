# 网文类型参考指南

## 玄幻修仙类

### 核心元素
- **境界体系**：炼气、筑基、金丹、元婴、化神、渡劫、大乘、飞升等
- **修炼资源**：灵石、丹药、灵草、兽核、天材地宝
- **势力类型**：宗门、家族、帝国、散修联盟
- **常见设定**：灵根体质、血脉传承、功法神通、秘境遗迹

### 经典套路
1. 废柴觉醒流：被测出废灵根或无灵根，意外获得传承逆袭
2. 家族弃子流：被家族抛弃，涅槃重生打脸众人
3. 拜师学艺流：偶遇高人收徒，一步步崛起
4. 宗门崛起流：建立或重振宗门，对抗大势力

### 爽点设计
- 境界突破的瞬间快感
- 以弱胜强的战斗快感
- 打脸嘲讽者的逆袭快感
- 获得珍稀宝物的惊喜感
- 红颜倾心的满足感

## 都市异能类

### 核心元素
- **异能类型**：透视、读心、控火、瞬移、时间倒流等
- **社会设定**：隐藏的超凡世界、明面与暗面的交织
- **势力分布**：古武家族、异能组织、地下势力
- **赚钱方式**：赌石、鉴宝、治病、投资、直播

### 经典套路
1. 重生1990/2000流：带着未来记忆重生，炒股买房做首富
2. 兵王回归流：特种兵王退役回归都市，保护美女总裁
3. 神医下山流：隐世神医弟子下山行医，救美撩妹
4. 继承遗产流：突然获得神秘遗产或古老传承

### 爽点设计
- 装逼打脸的畅快感
- 赚钱暴富的满足感
- 保护美人的英雄感
- 碾压对手的优越感

## 穿越重生类

### 核心元素
- **穿越方式**：车祸、触电、落水、猝死、跳楼（慎用）
- **重生设定**：带着前世记忆重生到过去
- **身份设定**：嫡女、庶女、公主、丫鬟、路人甲
- **时代背景**：古代、架空、民国、异世

### 经典套路
1. 嫡女逆袭流：原主被欺负，穿越女强势反击
2. 废柴小姐流：原主是修炼废柴，穿越后开挂
3. 宫斗生存流：在后宫斗智斗勇，保命争宠
4. 宅斗发家流：斗倒恶毒亲戚，发家致富

### 爽点设计
- 智斗反派的机智感
- 虐渣打脸的痛快
- 收获真情的温暖感
- 改变命运的成就感

## 系统流

### 核心元素
- **系统类型**：签到系统、任务系统、抽奖系统、属性面板
- **任务设计**：日常任务、主线任务、隐藏任务
- **奖励机制**：经验值、技能点、道具、称号
- **副本设定**：秘境、副本、BOSS战

### 经典套路
1. 超级外卖系统：送外卖获得各种神奇能力
2. 娱乐天王系统：成为娱乐明星的系统
3. 神豪系统：花钱就变强
4. 咸鱼系统：什么都不干也能变强

### 爽点设计
- 获得奖励的惊喜感
- 面板数值的成长感
- 完成任务的成就感
- 碾压对手的爽快感

## 甜宠文

### 核心元素
- **情感模式**：1V1双洁、甜宠不虐
- **男主类型**：霸道总裁、阳光学长、冷酷校草、温柔竹马
- **女主类型**：软萌小白、坚强独立、马甲大佬
- **互动方式**：互怼、暗恋、明恋、契约恋爱

### 经典套路
1. 契约恋爱流：假扮情侣，日久生情
2. 青梅竹马流：从小一起长大，暗恋多年
3. 先婚后爱流：闪婚或被迫结婚，渐生情愫
4. 追妻火葬场：前期虐女主后期追妻

### 甜点设计
- 互动的甜蜜感
- 撒糖的瞬间快感
- 误会解除的释然
- 终成眷属的满足

## 悬疑灵异类

### 核心元素
- **探险场景**：古墓、鬼宅、老宅、秘境
- **灵异元素**：鬼魂、僵尸、妖怪、精怪、邪修
- **破解方式**：风水、符箓、道术、推理
- **氛围营造**：恐怖、紧张、刺激、烧脑

### 经典套路
1. 盗墓笔记流：摸金校尉探险古墓
2. 茅山捉鬼流：茅山弟子降妖除魔
3. 灵异直播流：主播探险灵异地点
4. 刑事侦查流：破解离奇死亡案件

### 爽点设计
- 恐怖氛围的刺激感
- 破解谜团的成就感
- 降妖除魔的正义感
- 揭开真相的释然感
