# 股票财报短视频脚本生成技能

## 技能概述

本技能从股票财报数据中提取关键财务指标，生成吸引人的短视频口播脚本，适用于抖音、快手、视频号等短视频平台。

## 输入要求

支持以下输入方式：

1. **文件输入**：PDF财报文件、Excel财务数据文件
2. **URL输入**：财务数据页面、财报发布页面
3. **直接内容**：用户提供的财务数据文本

## 工作流程

### 步骤1：数据提取与解析

- 提取关键财务指标：营收、净利润、毛利率、每股收益等
- 计算同比/环比变化
- 识别财务亮点与风险点

### 步骤2：财务分析框架

分析以下维度：

| 维度 | 关键指标 |
|------|----------|
| 盈利能力 | 毛利率、净利率、ROE |
| 成长性 | 营收增长率、净利润增长率 |
| 偿债能力 | 资产负债率、流动比率 |
| 运营效率 | 存货周转、应收账款周转 |
| 估值水平 | PE、PB、市值 |

### 步骤3：短视频脚本生成

根据分析结果生成结构化口播脚本，包含：

1. **开场钩子**（3-5秒）：吸引观众注意力的开场
2. **财报亮点**（15-20秒）：核心数据解读
3. **分析与观点**（20-30秒）：专业分析判断
4. **结尾引导**（5秒）：关注/评论引导

### 步骤4：输出格式

生成的脚本包含：

- 建议时长标注
- 台词文本
- 情绪提示
- 关键数据展示建议
- BGM/配图建议

## 输出示例结构

```markdown
## 【股票简称】财报解读 | [季度/年份]

### 视频信息
- 时长建议：60-90秒
- 风格：专业分析型
- 目标受众：股票投资者

### 开场钩子（0-5秒）
[画面：股票K线图+标题字幕]
台词：这家公司的财报，让我觉得必须说两句...

### 财报亮点（5-25秒）
[画面：关键数据图表]
台词：营收同比增长XX%，净利润XX亿，超出市场预期...

### 专业分析（25-55秒）
[画面：财务指标对比图]
台词：从三个维度来看...

### 结尾引导（55-60秒）
[画面：关注按钮+评论区引导]
台词：觉得这家公司怎么样？评论区聊聊...
```

## 质量标准

1. 数据准确：所有财务数据必须来源于原始财报
2. 分析客观：同时呈现利好和风险因素
3. 语言通俗：专业术语简化解释
4. 结构清晰：遵循短视频完播率优化原则
5. 合规提示：包含投资风险提示

## 注意事项

- 如财报数据不完整，标注数据缺失项
- 涉及预测的内容需明确标注为个人观点
- 保持客观中立，不构成投资建议
