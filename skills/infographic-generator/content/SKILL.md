# 智能信息图生成器

将小组讨论、会议纪要等内容智能转化为16:9手绘风格信息图。

## 核心功能

| 功能 | 说明 |
|------|------|
| 智能推荐 | 基于关键词语义分析，自动推荐最佳信息组织模型 |
| 双输入 | 支持直接文本输入 + 图片OCR识别 |
| 8种模型 | SCQA/SWOT/四象限/MECE/黄金圈/时间线/漏斗/对比图 |
| 16:9输出 | 标准宽屏格式，可导出PNG |
| 一句话总结 | 自动生成核心观点总结 |

## 支持的模型

### 1. SCQA 框架
**适用场景**: 讲故事式结构，适合有情境-冲突-问题-答案逻辑的内容

```
情境(Situation) → 冲突(Complication) → 问题(Question) → 答案(Answer)
```

### 2. SWOT 分析
**适用场景**: 战略分析，评估优势/劣势/机会/威胁

```
┌─────────────┬─────────────┐
│   优势 S    │   劣势 W    │
│  Strengths  │ Weaknesses  │
├─────────────┼─────────────┤
│   机会 O    │   威胁 T    │
│Opportunities│   Threats   │
└─────────────┴─────────────┘
```

### 3. 四象限分析
**适用场景**: 双重维度对比分析（如：紧急/重要、影响/难度）

**智能推荐X轴Y轴**: 系统会根据内容自动推断最合适的维度组合

### 4. MECE 分类
**适用场景**: 系统化分类整理，相互独立、完全穷尽

### 5. 黄金圈
**适用场景**: 理念传达，从为什么开始思考

```
WHY(为什么) → HOW(如何做) → WHAT(是什么)
```

### 6. 时间线
**适用场景**: 流程展示、历史回顾

### 7. 漏斗图
**适用场景**: 筛选转化过程、层级递减

### 8. 对比图
**适用场景**: A/B方案比较、优缺点分析

## 工作流程

### 步骤1: 内容输入
- 直接粘贴讨论文本
- 或上传讨论截图（自动OCR提取）

### 步骤2: 智能分析
系统自动分析内容，检测关键词模式：

| 模式关键词 | 推荐模型 |
|------------|----------|
| 优势/劣势/机会/威胁 | SWOT |
| 情境/冲突/问题/答案 | SCQA |
| 为什么/如何做/是什么 | 黄金圈 |
| 维度/比较/对比 | 四象限 |
| 分类/层次/体系 | MECE |
| 首先/然后/流程/步骤 | 时间线 |

### 步骤3: 模型选择
- 接受系统推荐（置信度最高的模型）
- 或手动切换到其他模型

### 步骤4: 内容编辑
- 自动解析文本填充各板块
- 支持手动调整内容

### 步骤5: 生成导出
- 预览16:9信息图
- 一键导出PNG

## 示例对话

### 示例1: SWOT分析
```
用户: 我们团队最近讨论了产品竞争力的分析
助手: 检测到包含"竞争力"相关内容，推荐SWOT分析模型
→ 自动生成SWOT四象限信息图
```

### 示例2: 流程总结
```
用户: [粘贴会议纪要: 首先讨论了...然后确定了...]
助手: 检测到时间顺序结构，推荐时间线模型
→ 自动生成流程时间轴信息图
```

## 输出规范

### 16:9 画布尺寸
- 宽度: 1920px
- 高度: 1080px
- 比例: 16:9

### 手绘风格规范
- 字体: Ma Shan Zheng (手写风格)
- 配色: 柔和色系（非纯黑线条）
- 元素: 圆角卡片、手绘箭头、装饰点缀

### 一句话总结
自动从内容中提取核心观点，格式示例：
> "提高效率需从时间管理、任务拆解、工具纪律、会议优化四个维度入手"

## 技术实现

- 前端框架: React + TypeScript
- 样式: TailwindCSS + 手绘SVG组件
- 图表: SVG手绘矢量图
- OCR: Tesseract.js
- 导出: html2canvas
