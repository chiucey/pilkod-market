# 信息组织模型适用场景详解

## SCQA 框架

### 适用场景
- 产品发布/营销推广
- 项目汇报/问题分析
- 演讲开场/故事讲述

### 触发关键词
- 情境、情况、背景、现状
- 冲突、问题、挑战、困难
- 如何、怎么、为什么
- 因此、所以、解决方案

### 示例结构
```
S(情境): "我们的产品市场份额下降了15%"
C(冲突): "竞争对手推出了更具价格优势的产品"
Q(问题): "我们如何在不降低品质的前提下提升竞争力？"
A(答案): "通过优化供应链和规模化生产降低成本"
```

## SWOT 分析

### 适用场景
- 商业战略规划
- 个人职业规划
- 项目可行性分析
- 市场竞争分析

### 触发关键词
- 优势、长处、Strength
- 劣势、短处、Weakness
- 机会、Opportunity
- 威胁、风险、Threat

### 智能推断逻辑
系统会自动检测文本中是否同时包含S/W/O/T四类关键词，只要满足3类以上即推荐SWOT。

## 四象限分析

### 适用场景
- 优先级排序（紧急/重要）
- 风险评估（概率/影响）
- 产品定位（价格/功能）
- 时间管理（紧急/重要度）

### 智能X/Y轴推荐
| 内容特征 | 推荐X轴 | 推荐Y轴 |
|----------|---------|---------|
| 任务管理 | 紧急程度 | 重要程度 |
| 产品分析 | 价格 | 功能 |
| 风险评估 | 发生概率 | 影响程度 |
| 团队协作 | 难度 | 价值 |

## MECE 分类

### 适用场景
- 系统性分类整理
- 问题分解
- 知识体系构建
- 会议要点归纳

### MECE原则
- **Mutually Exclusive**: 相互独立，不重叠
- **Collectively Exhaustive**: 完全穷尽，无遗漏

### 常见分类模式
- 二分法: 是/否、内/外
- 要素法: 产品、价格、渠道、促销
- 流程法: 输入、处理、输出
- 矩阵法: 组合以上方法

## 黄金圈

### 适用场景
- 企业愿景传达
- 品牌故事
- 领导力沟通
- 产品理念说明

### 三层结构
```
WHY (为什么) - 核心理念、使命初心
   ↓
HOW (如何做) - 方法论、独特价值
   ↓
WHAT (是什么) - 具体产品、服务
```

### 适用行业
- 科技公司（苹果、特斯拉）
- 社会企业
- 创业公司
- 个人品牌

## 漏斗图
