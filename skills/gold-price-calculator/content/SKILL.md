# 国际金价计算器

## 功能说明

实时获取国际黄金价格并转换为人民币/克单位。

## 数据来源

- **国际金价**：使用金融数据API获取美元/盎司单位的实时价格
- **汇率数据**：获取美元兑人民币实时汇率进行转换

## 计算公式

```
人民币/克 = (国际金价 美元/盎司 ÷ 31.1035) × 美元兑人民币汇率
```

其中：
- 31.1035 = 1金衡盎司转换为克的系数
- 汇率 = 1美元对应的人民币数量

## 执行流程

### 步骤 1：获取国际金价
使用 `batch_web_search` 搜索 "gold price today live" 获取当前国际金价（美元/盎司）

### 步骤 2：获取汇率数据
使用 `extract_content_from_websites` 从 xe.com 获取实时汇率（更可靠的数据源）

### 步骤 3：数据解析与计算
1. 提取国际金价（美元/盎司）
2. 提取美元兑人民币汇率
3. 按公式计算人民币/克价格

### 步骤 4：结果展示
输出格式化的结果，包括：
- 国际金价（美元/盎司）
- 美元兑人民币汇率
- 计算所得人民币/克价格
- 数据更新时间

## 输出格式示例

```
📊 黄金价格实时数据

🌍 国际金价：$2,051.50 / 盎司
💱 美元兑人民币：¥7.24
📐 人民币金价：¥477.68 / 克

数据更新时间：2026-03-23 11:22:42
```

## 注意事项

- 数据来源于公开金融网站，可能存在轻微延迟
- 计算结果仅供参考，实际交易价格以当地金店/银行为准
- 黄金单位换算标准：1金衡盎司 = 31.1035克
