# 短线买卖决策技能

## 核心决策逻辑

基于**主力行为分析**结合**技术面信号**，执行以下决策规则：

### 决策规则表

| 条件组合 | 决策结果 |
|---------|---------|
| 主力加仓 + 加仓分≥70 | **买入** |
| 主力洗盘 + 趋势不坏 | **持有观望** |
| 主力出货 + 出货分≥70 | **减仓或卖出** |
| 从买入价下跌达到 -5% | **无条件止损卖出** |
| 盈利＞10%后开始走弱 | **逐步止盈** |

---

## 决策流程

### 第一步：收集信息

用户需提供以下数据（或由系统获取）：

```
【必填】
- 主力行为：加仓 / 洗盘 / 出货
- 加仓分数（0-100）：______
- 出货分数（0-100）：______
- 买入价（如有持仓）：______
- 当前价：______
- 持仓盈亏（%）：______

【选填】
- 趋势状态：上升 / 震荡 / 下降
- 技术面信号：强势 / 中性 / 走弱
```

### 第二步：执行决策判断

按以下优先级执行：

```
优先级1：止损判断
├─ 条件：持仓亏损 ≥ -5%
└─ 结果：→ 【无条件止损卖出】

优先级2：止盈判断
├─ 条件：盈利 > 10% 且 技术面走弱
└─ 结果：→ 【逐步止盈】

优先级3：买卖决策
├─ 主力加仓 + 加仓分≥70 → 【买入】
├─ 主力洗盘 + 趋势不坏 → 【持有观望】
└─ 主力出货 + 出货分≥70 → 【减仓或卖出】
```

### 第三步：输出决策结论

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【今日决策】买入 / 持有 / 减仓 / 卖出
【止损价】______（若无持仓则填写"无"）
【止盈策略】逐步止盈 / 持有 / 不适用
【核心逻辑】简述决策依据
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 决策案例

### 案例1：买入信号

```
输入：
- 主力行为：加仓
- 加仓分数：85
- 当前价：12.50
- 趋势：上升

判断：
✓ 主力加仓 → 加仓分85 ≥ 70
✓ 趋势上升 → 趋势不坏

输出：
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【今日决策】买入
【止损价】11.88（-5%）
【止盈策略】持有，盈利>10%后开始关注走弱信号
【核心逻辑】主力加仓信号强（85分），上升趋势延续
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 案例2：止损执行

```
输入：
- 持仓买入价：15.00
- 当前价：14.10
- 持仓盈亏：-6%

判断：
✓ 亏损 -6% ≥ -5%止损线

输出：
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【今日决策】卖出
【止损价】14.25（已触发止损）
【止盈策略】不适用
【核心逻辑】触发-5%无条件止损线
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 案例3：减仓信号

```
输入：
- 主力行为：出货
- 出货分数：78
- 当前价：18.50
- 持仓盈利：12%

判断：
✓ 盈利12% > 10%，技术面走弱
✓ 主力出货分数78 ≥ 70

输出：
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【今日决策】减仓或卖出
【止损价】17.58（-5%）
【止盈策略】逐步止盈（盈利12%，技术面走弱）
【核心逻辑】主力出货信号强+盈利后走弱，双重减仓信号
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

---

## 风险控制原则

1. **止损优先**：-5%止损为铁律，不可动摇
2. **分批止盈**：盈利>10%后走弱，分2-3批卖出
3. **仓位管理**：新买入仓位不超过总仓位30%
4. **趋势为王**：下降趋势中，减少操作频率
