# BD分析报告生成

## 概览

此skill用于生成标准化的企业BD分析报告，包含13个章节 + 3个附录，输出格式为 Markdown。

报告基于行业细分画像评分及输出标准，最终输出质量对标中美瑞康Phase 4范例报告（约1200-1400行MD / 2700-2900行HTML）。

## 执行流程

### Step 1：收集输入信息

从用户处获取以下信息：

- **企业名称**：公司全名（中文+英文/品牌名）—— **必填**
- **行业画像**：用户可选指定的二级或三级行业画像标签（如 "数字化与智能化"、"低空经济_eVTOL"、"创新药_小分子" 等）。—— **非必填，未提供时自动分析**
- **分析日期**：默认当天

**行业画像获取流程**：

根据用户是否提供行业画像，分两条路径：

#### 路径A：用户提供了行业画像

1. 使用四级匹配策略在 `references/industry-profiles/` 目录下查找最匹配的画像文件（详见下方匹配规则）
2. 找到 → 使用该画像继续后续流程
3. 找不到 → 执行自动生成流程（见下方）

#### 路径B：用户未提供行业画像

1. 基于企业名称、品牌、业务关键词等信息，智能分析该公司所属行业
2. 使用四级匹配策略在 `references/industry-profiles/` 目录下查找最匹配的画像文件
3. 找到 → 使用该画像继续后续流程，并在报告中说明行业判断依据
4. 找不到 → 执行自动生成流程（见下方），基于分析出的行业特征自动生成画像

**行业画像四级匹配策略**（按优先级从高到低）：

1. **精确匹配**：输入完整匹配画像文件名中的行业名称部分
   - 例：输入"工业软件" → 匹配 `03_细分行业画像_数字化与智能化_工业软件_v1.2.md`
   - 例：输入"大分子" → 匹配 `03_细分行业画像_生命科学_创新药_大分子_v1.2.md`

2. **关键词匹配**：输入匹配文件名中的任意部分（支持部分匹配）
   - 例：输入"芯片" → 匹配 `03_细分行业画像_集成电路_芯片设计-数字_v1.2.md`
   - 例：输入"无人机" → 匹配 `03_细分行业画像_低空经济_工业级无人机_v1.2.md`
   - 例：输入"光伏" → 匹配 `03_细分行业画像_新能源与双碳_光伏_v1.2.md`

3. **行业树匹配**：根据 `01_框架总览_Map_v0.5.md` 中的行业分类树，匹配输入对应的二级/三级行业
   - 例：输入"EDA" → 匹配到"集成电路_EDA与IP"三级画像
   - 例：输入"动力电池" → 匹配到"新能源与双碳_动力电池与储能"三级画像
   - 例：输入"机器人" → 匹配到"智能经济_人形机器人"或"机器人_工业机器人"

4. **降级匹配**：当三级画像找不到时，尝试匹配二级画像
   - 例：输入"数字化" → 匹配 `02_细分行业画像_数字化与智能化_v1.2.md`
   - 例：输入"消费" → 匹配 `02_细分行业画像_消费与品牌升级_v1.2.md`

**匹配优先级规则**：
- 层级优先级：03_三级画像 > 02_二级画像（三级更精确，优先选择）
- 多版本时：选择最高版本号（如 v1.2 > v1.1 > v1.0）
- 多个同级别匹配时：选择文件名包含输入部分最多的（最精确匹配）

**自动生成流程**：
当四级策略都找不到匹配的行业画像时：
1. 读取 `references/01_框架总览_Map_v0.5.md` 作为行业画像生成模板
2. 基于框架总览中的行业分类体系、信号体系（预警信号/确认信号/风险信号）、Phase定义、BD紧迫性评分模型，结合目标行业关键词，生成一个新的三级行业画像
3. 新文件命名格式：`03_细分行业画像_[行业名称]_v0.1.md`
4. 新文件保存到 `references/industry-profiles/` 目录
5. ⚠️ 向用户明确提示：本次使用的行业画像是基于框架总览自动生成的 v0.1 草稿版，非已有画像
6. 使用新生成的画像继续完成后续报告生成

### Step 2：读取参考文件

1. 读取 `references/report-framework-v2.md` — 完整的报告框架和写作规范
2. 读取 Step 1 中匹配到或自动生成的 **行业画像文件** — 作为报告生成的行业依据，完全以此为准

**重要**：必须使用匹配到或自动生成的行业画像，不得随意替换为其他已有画像文件。行业画像中的 Phase 定义、信号权重、BD紧迫性评分公式等内容直接用于报告的 Phase 判定和 BD 策略制定。

**自动生成画像时的标注**：如果使用的是自动生成的 v0.1 草稿画像，必须在报告第二章"行业画像依据"中明确标注：
> ⚠️ 注意：本报告使用的行业画像为 AI 基于 `01_框架总览_Map_v0.5.md` 自动生成的 v0.1 草稿版（文件：`03_细分行业画像_[行业名称]_v0.1.md`），非已有画像库中的画像。建议后续补充完善该画像的行业专属信号和真实IPO案例数据。

**智能分析行业时的标注**：如果用户未提供行业画像而由系统自动分析得出，应在报告中说明：
> 行业判断依据：根据企业名称、主营业务、产品线等信息，AI 判定该公司属于 [行业名称] 行业，匹配画像文件 `03_细分行业画像_[行业名称]_vX.X.md`。如判断有误，可重新指定行业画像后重新生成。

### Step 3：信息收集（联网搜索）

使用 WebSearch 和 WebFetch 工具进行以下维度的信息收集：

1. **企业基本信息**：官网、天眼查、企查查等
2. **核心产品/管线**：产品官网、ClinicalTrials.gov、CDE/ADC等
3. **融资/资本**：36氪、IT桔子、天眼查融资历史
4. **创始人/团队**：官网、学术数据库、新闻报道
5. **行业动态**：行业报告、券商研报、媒体报道
6. **竞对信息**：竞争对手官网、新闻、融资信息
7. **政策法规**：FDA、CDE相关政策
8. **地域动态**：总部所在地政府/园区新闻

### Step 4：生成MD报告

严格按照 `references/report-framework-v2.md` 中的13章+3附录结构生成完整Markdown报告。

**关键写作规则**：
- 标题不含任何版本标签（"Final"、"完整版"等）
- 章节从"一、"开始平级编号（一~十三）
- 第六章（BD武器库）占全文40%+篇幅
- 数据驱动，每个论断尽量有数字支撑
- 仅在6.X子节末尾和7.3末尾放置AI提示块
- 文件名：`企业BD分析范例_[企业名]_Phase[X].md`

**质量检查**：生成后对照框架中的"质量检查清单"逐项核对（40+项）。

## 行业画像文件说明

用户可传入行业画像标签（如 "数字化与智能化"、"低空经济_eVTOL"、"芯片"、"无人机"）来指定报告使用的行业依据，也可不传——不传时 Skill 会基于企业名称和业务信息自动分析所属行业并匹配画像。匹配使用四级策略（精确匹配 → 关键词匹配 → 行业树匹配 → 降级匹配）。

**匹配逻辑**：
1. 精确匹配：输入完整匹配画像文件名中的行业名称
2. 关键词匹配：输入匹配文件名中的任意部分（支持部分匹配，如"芯片"→"芯片设计"）
3. 行业树匹配：根据 `01_框架总览_Map_v0.5.md` 中的行业分类树，映射输入到对应行业
4. 降级匹配：三级画像找不到时，尝试匹配二级画像
5. 优先级：`03_三级行业画像_*.md` > `02_细分行业画像_*.md`（三级更精确）
6. 同标签多版本时，选择最高版本号（如 v1.2 > v1.1 > v1.0）
7. **多个同级别匹配时，选择最精确的（文件名包含输入部分最多的）**

**自动生成**：如果以上策略均无匹配，Skill 会基于 `references/01_框架总览_Map_v0.5.md` 自动生成一个新的三级行业画像（v0.1草稿版），保存到 `references/industry-profiles/` 目录，并在报告中明确标注该画像为自动生成。

**智能分析**：如果用户未提供行业画像，Skill 会先分析企业名称和业务信息判断所属行业，再执行上述匹配流程。判断结果会在报告中说明，用户可后续纠正。

**文件命名格式**：
- 二级画像：`02_细分行业画像_[行业大类]_vX.X.md`
- 三级画像：`03_细分行业画像_[行业大类]_[子行业]_vX.X.md`
- 自动生成：`03_细分行业画像_[行业名称]_v0.1.md`

如需添加新的行业画像文件，放入 `references/industry-profiles/` 目录下。
