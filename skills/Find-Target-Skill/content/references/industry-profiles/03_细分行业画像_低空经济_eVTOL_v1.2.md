## 一、行业定义

eVTOL（Electric Vertical Takeoff and Landing）是低空经济的核心赛道，指电动垂直起降飞行器，包括载人飞行汽车和物流eVTOL。监管归属中国民航局CAAC，需取得型号合格证（TC）、生产许可证（PC）、适航证（AC）后方可商业化运营。

### 1.1 核心特征

| 特征 | 说明 | 代表企业 |
|------|------|---------|
| 监管严格 | 需通过CAAC适航认证 | 所有eVTOL企业 |
| 研发烧钱 | 单机研发成本超10亿 | 亿航智能(累计融资超20亿) |
| 技术壁垒高 | 飞控/电池/材料集成 | 小鹏汇天(小鹏汽车背景) |
| 政策驱动 | 低空经济政策支持 | 所有eVTOL企业 |

### 1.2 细分类型

| 类型 | 代表产品/应用 | BD优先级 | 上市通道 | 典型IPO案例 |
|------|------------|---------|---------|-----------|
| **载人eVTOL** | 飞行汽车/空中出租车 | ⭐⭐⭐ | 科创板/纳斯达克 | 亿航智能(纳斯达克) |
| **物流eVTOL** | 大型货运无人机 | ⭐⭐ | 科创板 | 峰飞航空(待上市) |

## 三、eVTOL行业BD实操规律

### 3.1 BD窗口极短，核心在"预测"而非"追击"

| 信号 | 到上市时间 | BD含义 |
|------|-----------|---------|
| TC申请受理 | 2-4年 | 🔴 **还有时间，但需立即行动** |
| 大额融资（单笔≥5亿） | 2-4年 | 🔴 **资本押注，值得关注** |
| 进入头部客户供应链 | 2-4年 | 🔴 **客户验证，值得关注** |
| 首飞成功 | 1-3年 | 🟡 **技术验证，窗口已窄** |
| CFO引入（有IPO经验） | <1-2年 | 🔴 **最后窗口，几乎来不及** |
| IPO递表 | 0 | ⚫️ **窗口已关闭** |

### 3.2 为什么"TC申请受理"是最强信号

从真实案例看：
- 亿航智能：2018年IPO时TC还未受理 → 2020年才获得TC
- 小鹏汇天：2023年TC受理 → 待上市

**TC申请受理意味着：1）技术得到监管认可 2）商业化路径清晰 3）IPO故事更完整。这是比CFO引入更早、更有价值的信号。**

### 3.3 eVTOL企业的"烧钱周期"

| 企业 | 创立到上市 | 累计融资 | 上市时营收 | 上市时亏损 |
|------|-----------|---------|-----------|-----------|
| 亿航智能 | 5年 | 超20亿人民币 | 0 | - |

**eVTOL企业的特点是：烧钱周期长、商业化前无收入、IPO时大多亏损。BD时需要关注企业的"适航证进展"和"融资能力"，而不是短期盈利。**

## 五、BD紧迫性评分

```
BD紧迫性 = 预警信号加权之和 − 风险信号扣分

⚠️ 核心变化：CFO引入从权重20降为10！
   因为CFO引入距离上市通常<1-2年，此时BD已几乎无操作空间
   CFO引入的真正价值是"确认该企业会上市"，而不是"还有时间BD"

评级：
  ≥40 → A级（Phase 4，全力推进）
  30-39 → B级（Phase 3，保持接触）
  20-29 → C级（Phase 3，偶尔接触）
  10-19 → D级（Phase 2，建立认知）
  <10 → E级（Phase 1，观察）

⚠️ 确认信号出现 → BD紧迫性=0，标记"窗口已关闭"
```
