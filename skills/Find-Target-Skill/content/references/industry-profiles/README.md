# 行业画像文件目录

## 用途

存放三级行业画像文件，供 BD 分析报告生成时参考行业数据。

## 命名规范

文件格式：`03_三级行业画像_[对应行业]_vX.X.md`

示例：
- `03_三级行业画像_小核酸药物_v1.0.md`
- `03_三级行业画像_细胞治疗_v1.0.md`
- `03_三级行业画像_基因治疗_v1.0.md`

## 使用方式

生成报告时，根据企业所属行业选择对应的行业画像文件。例如：

- 企业属于"小核酸药物"赛道 → 读取 `03_三级行业画像_小核酸药物_vX.X.md`
- 企业属于"细胞治疗"赛道 → 读取 `03_三级行业画像_细胞治疗_vX.X.md`

## 如何添加

将新的行业画像文件放入此目录即可。命名需遵循上述规范。
