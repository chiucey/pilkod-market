## 一、行业概述

### 1.1 行业特征

- **极重资产**：晶圆厂建厂动辄百亿
- **政策极敏感**：制裁/大基金/国产替代三重驱动
- **子赛道差异极大**：制造vs设计vs设备vs材料的成长路径完全不同
- **上市通道以科创板为主**（通常已盈利，与生物医药18A不同）

### 1.2 八大三级细分赛道

| 三级细分 | 代表企业 | 上市周期 | 盈利特点 | BD优先级 |
|---------|---------|---------|---------|---------|
| **晶圆制造（Foundry）** | 中芯国际、华虹、晶合集成 | 15-25年 | 资本密集，盈利周期长 | ⭐⭐⭐ |
| **芯片设计-数字** | 寒武纪、海光信息、紫光展锐 | 8-14年 | 高毛利，研发高 | ⭐⭐⭐ |
| **芯片设计-模拟** | 思瑞浦、圣邦股份、纳芯微 | 8-12年 | 高毛利，产品周期长 | ⭐⭐ |
| **功率半导体** | 斯达半导、时代电气、士兰微 | 10-15年 | 新能源车驱动，需求稳 | ⭐⭐ |
| **半导体设备** | 北方华创、中微公司、拓荆科技 | 10-15年 | 国产替代核心，壁垒高 | ⭐⭐⭐ |

| 对比维度 | 晶圆制造 | 芯片设计 | 半导体设备 | 功率半导体 |

## 二、各子赛道成长时间线（Phase定义）

### 2.1 半导体设备（典型路径）

```
Phase 1          Phase 2            Phase 3            Phase 4            Phase 5
技术研发          产品验证            客户导入与放量       Pre-IPO           IPO
(0-4年)          (4-8年)            (8-12年)          (12-15年)          (15年+)
  │                │                  │                  │                 │
  ├─海归/大厂技术团队│ ├─样机开发+验证   ├─进入主流产线       ├─确认信号≥2个    ├─辅导备案
  ├─天使/政府引导基金│ ├─流片/工艺验证   ├─重复订单出现        ├─审计招标         ├─招股书
  ├─核心专利布局    │ ├─A/B轮融资      ├─C轮/大基金投资      ├─招股书            ├─挂牌
  │                │ │                  │                  │ (Phase 5)         │
  估值:<1亿RMB     估值:1-10亿RMB     估值:10-50亿RMB     估值:50-200亿RMB    市值:200亿+
  收入:无           收入:百万-千万级     收入:1-10亿RMB       收入:10亿+          收入:公开
  利润:亏损         利润:可能微利       利润:盈利             利润:稳定盈利

  ▲ BD最佳窗口: Phase 2中后期（样机验证+客户导入时）
  ▲ 审计招投标信号: Phase 3后期 ~ Phase 4
```

### 3.3 Phase 4触发条件（v0.4）

> 满足以下任一条件 → 进入Phase 4
```
① CFO引入（具有IPO经验）+ 融资进入C轮或以后 → Phase 4
② 单笔融资≥5亿RMB + 进入Phase 3 → Phase 4
③ 审计招标 + 券商/律所已签约 → Phase 4（确认信号≥2个）
```
> 辅导备案单独出现 → **Phase 5**，不再归入Phase 4

## 四、BD紧迫性评分（v0.4修订版）

```
BD紧迫性 = 预警信号加权之和 − 风险扣分

评级阈值（v0.4修订）：
  50+ → A级（必须拿下）
  36-49 → B级（重点跟进）
  20-35 → C级（保持接触）
  0-19  → D级（观察）
```
