## 一、行业概述

2026年新能源汽车渗透率持续提升，智能驾驶与电动化深度融合。插混/增程快速增长，固态电池上车加速，800V高压平台成为中高端标配。一级市场BD机会集中在智能化零部件、核心零部件国产替代和海外出口三个方向。

---

## 二、核心技术与产品方向

| 方向 | 说明 |
|------|------|
| 智能驾驶 | 城市NOA普及、高阶智驾降本、端到端大模型落地 |
| 800V高压平台 | SiC功率器件、电池快充、热管理系统 |
| 插混/增程 | 增速领先，PHEV出口爆发 |
| 核心零部件国产替代 | 线控底盘、空气悬架、智驾域控制器 |

---

## 三、行业特征

| 维度 | 说明 |
|------|------|
| 阶段分布 | 新势力造车 Phase 3-4；零部件 Tier2/3 Phase 1-2 |
| 资本密度 | 极高——整车需百亿级，核心零部件数亿至数十亿 |
| 政策依赖 | 强——购置税补贴、牌照政策 |
| 上市通道 | 港股（新能源整车主要通道）、科创板、纳斯达克 |
