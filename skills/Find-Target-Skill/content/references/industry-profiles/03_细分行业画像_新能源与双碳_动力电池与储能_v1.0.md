## 一、行业概述

动力电池与储能是新能源与双碳的核心赛道。2026年，固态电池/钠离子电池技术加速迭代，大储（大型储能）和工商业储能需求爆发，行业进入精细化竞争阶段，一级市场关注具备差异化技术能力和海外市场突破能力的标的。

---

## 二、核心技术与产品方向

| 方向 | 说明 |
|------|------|
| 固态电池 | 下一代电池方向，2026年加速商业化；半固态已量产装车 |
| 钠离子电池 | 成本优势明显，储能场景快速渗透 |
| 大储/工商业储能 | 电网侧储能，政策强制配储驱动 |
| 动力电池回收 | 电池梯次利用+原材料回收 |

---

## 三、行业特征

| 维度 | 说明 |
|------|------|
| 阶段分布 | 动力电池已 Phase 3-4（成熟期）；钠离子储能 Phase 1-2 |
| 资本密度 | 极高——产能建设需数十亿级资本 |
| 政策依赖 | 强——补贴、配储政策直接影响需求 |
| 上市通道 | 科创板（新能源属性）、创业板、港股 |
