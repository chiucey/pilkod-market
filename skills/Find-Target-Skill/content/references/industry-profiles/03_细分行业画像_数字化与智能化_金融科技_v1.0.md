## 一、行业概述

金融科技2026年进入规范发展期，数字人民币推广加速，供应链金融科技和智能风控为核心方向。AI大模型在金融场景加速落地（客服/风控/投研），一级市场关注具备金融监管合规能力和差异化数据资产的标的。

---

## 二、核心技术与产品方向

| 方向 | 说明 |
|------|------|
| 数字人民币 | 硬钱包/软钱包、跨境支付、供应链金融场景 |
| 供应链金融科技 | 核心企业确权、票据融资、区块链溯源 |
| 智能风控/反欺诈 | 联邦学习、图数据库、实时风控模型 |
| 金融AI应用 | 智能投顾、AI客服、AI投研 |

---

## 三、行业特征

| 维度 | 说明 |
|------|------|
| 阶段分布 | 供应链金融 Phase 2-3；金融AI Phase 1-2 |
| 资本密度 | 中——软件和数据为主，监管合规成本高 |
| 政策依赖 | 极强——金融监管沙盒、数据安全法直接影响业务边界 |
| 上市通道 | 港股主板（金融科技主要通道）、科创板、北交所 |

## 四、主要信号

| 信号类型 | 内容 |
|---------|------|
| 预警信号 | 进入银行/保险核心系统、完成监管沙盒准入、接入数字人民币互联互通平台 |
| 确认信号 | 头部银行千万级合同落地、完成亿级融资、引入金融背景CFO |
| 风险信号 | 监管政策收紧（数据/征信）、金融客户续约率下降 |
