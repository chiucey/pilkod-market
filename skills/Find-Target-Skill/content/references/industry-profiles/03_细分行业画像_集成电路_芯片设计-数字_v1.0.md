## 一、行业概述

数字芯片设计是集成电路产业的核心环节，覆盖CPU、GPU、FPGA、AI加速芯片、SoC等产品。2026年，受AI算力需求驱动，数字芯片进入新一轮增长周期，国产替代从非关键应用向数据中心/AI推理场景延伸。

---

## 二、核心技术与产品方向

| 方向 | 说明 |
|------|------|
| AI加速芯片/GPU | 大模型训练/推理需求爆发，国产GPU加速追赶 |
| CPU | 国产CPU（鲲鹏/飞腾/龙芯）服务器/PC渗透 |
| SoC | 消费电子、物联网、边缘计算 |
| FPGA | 通信、工业控制、AI推理 |

---

## 三、行业特征

| 维度 | 说明 |
|------|------|
| 阶段分布 | 消费级SoC Phase 2-3；AI芯片 Phase 1-2（部分进入Phase 3） |
| 资本密度 | 高——流片成本数千万至数亿 |
| 技术壁垒 | 极高——IP复用、EDA工具、先进制程 |
| 上市通道 | 科创板（半导体属性）、港股18C |

| 信号类型 | 内容 |
