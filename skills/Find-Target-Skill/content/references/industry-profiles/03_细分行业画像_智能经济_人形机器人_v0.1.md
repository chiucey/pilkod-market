## 一、行业定义

人形机器人是以人形形态为基础、具备双足行走能力、灵活双臂和双手操作的智能机器人，核心技术包括：运动控制、具身智能感知、灵巧手、关节伺服电机、力控柔顺等。是具身智能的代表性产品形态。

---

## 二、产业链结构

```
上游核心零部件
├─无框力矩电机（关节驱动）  → 步科、汇川技术
├─谐波减速器（关节传动）    → 绿的谐波、国贸股份
├─力传感器（触觉感知）      → 坤维科技、敏芯股份
├─灵巧手（末端执行器）      → 思灵机器人、JM Advantage
├─行星滚柱丝杠（线性关节）  → 南京工艺、汉江机床
└─惯性测量单元（IMU）        → 深迪半导体、士兰微

中游：整机厂商
├─傅利叶智能（Fourier GR-1）
├─智元机器人（远征A1）
├─宇树科技（Unitree H1） ← 杭州，六小龙
├─魔法原子（MagicBot）    ← 苏州天使P3新增
├─星动纪元（StarMotion）
└─逐际动力（LimX Dynamics）

下游：应用场景
├─工业制造（汽车总装、3C装配）
├─商业服务（导览/迎宾/酒店）
└─特种作业（巡检/危险环境）
```
