## 一、行业概述

模拟芯片涵盖信号链（放大器/ADC/DAC/接口）和电源管理芯片（PMIC/功率IC）两大类。行业壁垒在于经验积累与工艺磨合，国内企业从中低端消费电子切入，向工业/汽车渗透。

---

## 二、核心技术与产品方向

| 方向 | 说明 |
|------|------|
| 信号链芯片 | ADC/DAC（高精度转换）、运算放大器、比较器、接口芯片（SerDes） |
| 电源管理芯片 | 快充PMIC、BQ系列替代、汽车级DC-DC、碳化硅驱动IC |
| 隔离器/车规芯片 | 数字隔离器、车身控制芯片 |

---

## 三、行业特征

| 维度 | 说明 |
|------|------|
| 阶段分布 | 消费级已 Phase 3-4；工业/汽车级 Phase 1-2 |
| 资本密度 | 中——无需最先进制程，0.11-28nm为主 |
| 技术壁垒 | 高——需长年工艺磨合，车规认证周期长（3-5年） |
| 上市通道 | 科创板（半导体属性）、创业板 |

---

## 四、主要信号

| 信号类型 | 内容 |
|---------|------|
| 预警信号 | 进入头部手机/汽车厂商供应链、ISO 26262认证通过、营收过亿 |
| 确认信号 | 车规芯片量产订单、工业级产品通过验证、完成C轮融资 |
| 风险信号 | 产品被国际大厂降价挤压、关键人才流失 |
