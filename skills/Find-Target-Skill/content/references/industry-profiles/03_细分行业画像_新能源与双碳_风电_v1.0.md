## 一、行业概述

风电行业2026年海风成为核心增长点，漂浮式风电开始商业化验证。陆上风电进入成熟期，整机价格竞争激烈。一级市场BD机会集中在海风产业链（海缆/桩基/主机）和漂浮式风电先行企业。

---

## 二、核心技术与产品方向

| 方向 | 说明 |
|------|------|
| 海上风电 | 15MW+大机组，深远海漂浮式开始商业化 |
| 陆上风电 | 低风速风机，老旧机组改造（以大代小） |
| 风电安装/运维 | 海风放量后运维市场兴起 |

---

## 三、行业特征

| 维度 | 说明 |
|------|------|
| 阶段分布 | 陆上风电 Phase 3-4；漂浮式 Phase 1-2 |
| 资本密度 | 高——海风项目单体投资超百亿 |
| 政策依赖 | 极强——补贴/核准政策直接决定装机节奏 |
| 上市通道 | 科创板（核心零部件）、港股主板 |
