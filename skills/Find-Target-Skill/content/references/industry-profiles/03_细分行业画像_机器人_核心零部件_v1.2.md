## 一、行业定义

机器人核心零部件是机器人产业的上游，包括精密减速器（RV/谐波）、伺服电机、控制器等。国产替代空间大，技术壁垒高。

### 1.1 核心特征

| 特征 | 说明 | 代表企业 |
|------|------|---------|
| 技术壁垒高 | 精度要求高 | 绿的谐波(谐波减速器龙头) |
| 国产替代 | 打破国外垄断 | 汇川技术(伺服电机龙头) |
| 客户集中 | 机器人/自动化主机厂 | 所有核心零部件企业 |
| 周期性强 | 受下游需求影响 | 所有核心零部件企业 |

## 三、核心零部件BD实操规律

### 3.1 BD窗口极短，核心在"预测"而非"追击"

| 信号 | 到上市时间 | BD含义 |
|------|-----------|---------|
| 主机厂（机器人/自动化）批量导入 | 2-4年 | 🔴 **还有时间，但需立即行动** |
| 产品通过车规级认证 | 1-3年 | 🟡 **质量壁垒，窗口已窄** |
| CFO引入（有IPO经验） | <1-2年 | 🔴 **最后窗口，几乎来不及** |
| 辅导备案公示 | 0 | ⚫️ **窗口已关闭** |

### 3.2 为什么"主机厂批量导入"是最强信号

从真实案例看：
- 绿的谐波：2017年进入ABB → 2020年上市（间隔3年）
- 汇川技术：2007年进入三一重工 → 2010年上市（间隔3年）

**主机厂批量导入意味着：1）技术得到验证 2）有稳定收入来源 3）IPO故事更完整。这是比CFO引入更早、更有价值的信号。**

### 3.3 核心零部件企业的"盈利能力"

| 企业 | 创立到上市 | 上市时营收 | 上市时利润 | 上市时毛利率 |
|------|-----------|-----------|-----------|-----------|
| 绿的谐波 | 9年 | 2亿 | 0.5亿 | 50% |
| 汇川技术 | 7年 | 6亿 | 2亿 | 45% |

**核心零部件企业的特点是：技术壁垒高、毛利率稳定、客户集中度高。BD时需要关注企业的"客户结构"和"技术壁垒"，而不是短期规模。**

## 五、BD紧迫性评分

```
BD紧迫性 = 预警信号加权之和 − 风险信号扣分

⚠️ 核心变化：CFO引入从权重20降为10！
   因为CFO引入距离上市通常<1-2年，此时BD已几乎无操作空间
   CFO引入的真正价值是"确认该企业会上市"，而不是"还有时间BD"

评级：
  ≥40 → A级（Phase 4，全力推进）
  30-39 → B级（Phase 3，保持接触）
  20-29 → C级（Phase 3，偶尔接触）
  10-19 → D级（Phase 2，建立认知）
  <10 → E级（Phase 1，观察）

⚠️ 确认信号出现 → BD紧迫性=0，标记"窗口已关闭"
```
