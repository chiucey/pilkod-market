## 一、行业定义

智能经济新形态是AI+算力+机器人+自动驾驶的综合体，是新一轮技术革命的核心赛道。其本质是以人工智能为核心驱动力，通过算力基础设施、智能终端、自动化系统重构传统产业的生产方式和商业模式。

### 1.1 核心特征

| 特征 | 说明 | 代表企业 |
|------|------|---------|
| 算力密集 | 训练+推理需要大规模GPU/TPU集群 | 寒武纪、地平线 |
| 数据驱动 | 模型迭代依赖海量数据 | 商汤、第四范式 |
| 场景落地 | 从技术到商业需要场景验证 | 云从、旷视 |
| 资本密集 | 研发投入巨大，烧钱周期长 | 百度Apollo、小马智行 |

## 三、智能经济BD实操规律

### 3.1 BD窗口极短，核心在"预测"而非"追击"

| 信号 | 到上市时间 | BD含义 |
|------|-----------|---------|
| 进入华为/车企/大厂供应链 | 2-5年 | 🔴 **还有时间，但需立即行动** |
| 大额融资（单笔≥5亿） | 2-4年 | 🔴 **资本押注，值得关注** |
| 芯片流片成功/大模型发布 | 1-3年 | 🟡 **技术验证，窗口已窄** |
| CFO引入（有IPO经验） | <1-2年 | 🔴 **最后窗口，几乎来不及** |
| IPO递表 | 0-1年 | ⚫️ **窗口已关闭** |

### 3.2 为什么"进入头部客户供应链"是最强信号

从真实案例看：
- 寒武纪：2018年进入华为供应链 → 2020年上市（间隔2年）
- 地平线：2019年进入长安供应链 → 2024年上市（间隔5年）
- 第四范式：2018年进入建行供应链 → 2023年上市（间隔5年）

**进入头部客户供应链意味着：1）技术得到验证 2）有稳定收入来源 3）IPO故事更完整。这是比CFO引入更早、更有价值的信号。**

### 3.3 智能经济企业的"烧钱周期"

| 企业 | 创立到上市 | 累计融资 | 上市时营收 | 上市时亏损 |
|------|-----------|---------|-----------|-----------|
| 寒武纪 | 4年 | 超50亿人民币 | 4.6亿 | -4.3亿 |
| 商汤 | 7年 | 超30亿美元 | 47亿 | -171亿 |
| 地平线 | 9年 | 超25亿美元 | 15.5亿 | -67亿 |
| 第四范式 | 9年 | 超10亿美元 | 30.8亿 | -16.5亿 |

**智能经济企业的特点是：烧钱周期长、亏损大、营收增长快。BD时需要关注企业的"烧钱速度"和"融资能力"，而不是短期盈利。**

## 五、BD紧迫性评分

```
BD紧迫性 = 预警信号加权之和 − 风险信号扣分

⚠️ 核心变化：CFO引入从权重20降为10！
   因为CFO引入距离上市通常<1-2年，此时BD已几乎无操作空间
   CFO引入的真正价值是"确认该企业会上市"，而不是"还有时间BD"

评级：
  ≥40 → A级（Phase 4，全力推进）
  30-39 → B级（Phase 3，保持接触）
  20-29 → C级（Phase 3，偶尔接触）
  10-19 → D级（Phase 2，建立认知）
  <10 → E级（Phase 1，观察）
```
