## 一、行业定义

eVTOL（Electric Vertical Takeoff and Landing）是低空经济的核心赛道，指电动垂直起降飞行器，包括载人飞行汽车和物流eVTOL。监管归属中国民航局CAAC，需取得型号合格证（TC）、生产许可证（PC）、适航证（AC）后方可商业化运营。

## 三、信号体系

### 3.1 预警信号（🔔）

| # | 信号 | 权重 | 说明 |
|---|------|------|------|
| E1 | **CFO引入（有IPO经验）** | **20** | 最强预警，上市准备启动 |
| E2 | **CAAC适航证TC受理** | **18** | 商业化前提条件 |
| E3 | **头部客户战略合作/预订单** | **18** | 电网/物流/出行巨头 |
| E4 | 大额融资（单笔≥5亿） | 15 | 研发烧钱，资本密集 |
| E5 | 整机定型/首飞成功 | 12 | 技术里程碑 |
| E6 | 量产线投产/产能建设 | 12 | 产能准备 |
| E7 | 环评公示 | 8 | 扩产前步骤 |

### 3.2 确认信号（📌）— BD窗口关闭

| 信号 | 出现时行动 |
|------|-----------|
| 辅导备案公示 | → Phase 5，窗口关闭 |
| 审计招标公示 | → Phase 5，窗口关闭 |

### 3.3 风险信号（⚠️）

| 信号 | 扣分 |
|------|------|
| TC申请被驳回/无限期延迟 | -20 |
| 核心技术人员离职 | -10 |
| 头部客户订单取消 | -10 |
| 安全事故 | -15 |

## 四、BD紧迫性评分

```
BD紧迫性 = 预警信号加权之和 − 风险信号扣分

评级：
  ≥40 → A级（Phase 4，全力推进）
  30-39 → B级（Phase 3，保持接触）
  20-29 → C级（Phase 3，偶尔接触）
  10-19 → D级（Phase 2，建立认知）
  <10 → E级（Phase 1，观察）

⚠️ 确认信号出现 → BD紧迫性=0，标记"窗口已关闭"
```
