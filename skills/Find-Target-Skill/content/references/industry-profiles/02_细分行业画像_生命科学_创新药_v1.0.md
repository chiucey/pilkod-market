## 一、行业概述

### 1.1 行业特征

- **长研发周期**：8-15年（从立项到上市）
- **高投入高回报**：单药研发成本约10-20亿美元
- **专利驱动**：上市后约8-10年独占期
- **子赛道差异极大**：大分子 vs 小分子 vs 基因疗法的上市速度和路径完全不同
- **政策极敏感**：医保谈判、NMPA优先审评、突破性治疗药物认定

### 1.2 三级细分与差异化特征

| 三级细分 | 代表靶点/技术 | BD优先级 | Phase 2→3时长 | 典型上市周期 | 盈利到达 |
|---------|------------|---------|--------------|------------|---------|
| **大分子-单克隆抗体** | PD-1/PD-L1, HER2, CD20 | ⭐⭐⭐ | 5-7年 | 8-12年 | 上市后 |
| **大分子-双抗/多抗** | PD-1×CTLA-4, EGFR×MET | ⭐⭐⭐ | 5-7年 | 8-12年 | 上市后 |
| **大分子-ADC** | HER2-ADC, TROP2-ADC | ⭐⭐⭐ | 5-7年 | 8-12年 | 上市后 |
| **小分子-靶向** | EGFR, BTK, BCL2, KRAS | ⭐⭐⭐ | 5-8年 | 8-14年 | 上市后 |
| **小分子-PROTAC** | AR, ER, KRAS | ⭐⭐ | 更早期 | 10-15年 | 更晚 |
| **基因/细胞疗法-CAR-T** | CD19, BCMA | ⭐⭐ | 5-8年 | 10-15年 | 上市后 |
| **基因/细胞疗法-基因疗法** | AAV载体 | ⭐ | 更早期 | 15年+ | 更晚 |

## 二、典型成长路径

### 2.1 通用成长模型

```
Phase 1          Phase 2            Phase 3             Phase 4          Phase 5
种子孵化          管线验证            商业化突破          Pre-IPO           IPO冲刺
(0-3年)          (3-7年)            (7-10年)           (10-13年)         (13年+)
  │                │                  │                  │                 │
  ├─海归/本土科学家│ ├─核心管线进临床  ├─NDA递交/获批     ├─确认信号≥2个   ├─辅导备案
  ├─天使/种子轮    │ ├─A/B轮融资      ├─商业化放量        ├─审计招标        ├─招股书披露
  ├─1-2个早期pipeline│ ├─License-in/out│ ├─营收确认       ├─招股书          ├─上市挂牌
  ├─入驻产业园     │ ├─政府批地/GMP准备│ ├─医保谈判        │ (Phase 5)       ├─持续审计
  │                │ │                  │                  │                 │
  估值:<5000万USD  估值:5000万-3亿USD  估值:3-10亿USD    估值:10亿+USD     市值:30亿+USD
  收入:无          收入:无/微          收入:5000万-5亿RMB  收入:5亿+ RMB     收入:公开

  ▲ BD最佳窗口: Phase 2中后期~Phase 3早期
  ▲ 审计招投标信号: Phase 4（约Phase 3中后期）
  ▲ Phase 4触发条件（v0.4）：≥2个确认信号，或CFO引入+C轮后，或单笔融资≥5亿
```

### 3.3 Phase 4触发条件（v0.4）

> 满足以下任一条件 → 进入Phase 4
```
① CFO引入（具有IPO经验）+ 融资进入C轮或以后 → Phase 4
② 单笔融资≥5亿RMB + 进入Phase 3 → Phase 4
③ 审计招标 + 券商/律所已签约 → Phase 4（→2个确认信号）
```
> 辅导备案单独出现 → **Phase 5**，不再归入Phase 4
