## 一、行业概述

数据要素与隐私计算是数据要素市场化改革的核心支撑技术。2026年，数据资产入表政策落地，隐私计算在金融/医疗/政务领域规模化应用加速。一级市场关注具备可信数据空间技术和数据交易所接入能力的标的。

---

## 二、核心技术与产品方向

| 方向 | 说明 |
|------|------|
| 隐私计算 | 联邦学习、安全多方计算（MPC）、可信执行环境（TEE） |
| 数据交易所 | 各地数交所建设运营，数据产品登记与交易 |
| 数据资产管理 | 数据治理/分类分级/数据质量评估 |
| 可信数据空间 | 工业/医疗/金融数据互联互通标准 |

---

## 三、行业特征

| 维度 | 说明 |
|------|------|
| 阶段分布 | 整体 Phase 1-2，隐私计算医疗/金融 Phase 2 |
| 资本密度 | 中——技术驱动型，软件和解决方案为主 |
| 政策依赖 | 极强——数据要素政策、数据安全法直接决定市场空间 |
| 上市通道 | 科创板（软件属性）、北交所、港股 |
