## 一、行业概述

高端装备涵盖数控机床、精密仪器、航空航天配套、特种设备等领域。2026年国产替代加速，数控机床和航空航天零部件进入关键突破期。一级市场BD机会集中在具备核心材料能力、精密加工能力和军工/半导体认证资质的民营企业。

---

## 二、核心技术与产品方向

| 方向 | 说明 |
|------|------|
| 数控机床/刀具 | 五轴联动、高端数控系统；国产替代加速 |
| 航空航天零部件 | 机体结构件、发动机叶片、起落架；军品认证为核心壁垒 |
| 精密仪器 | 半导体检测设备、计量仪器；国产替代空间大 |
| 特种设备 | 工业母机、高端液压/气动元件 |

---

## 三、行业特征

| 维度 | 说明 |
|------|------|
| 阶段分布 | 机床/刀具 Phase 2-3；航空航天配套 Phase 2 |
| 资本密度 | 高——精密设备扩产需较大资本 |
| 技术壁垒 | 高——军工认证周期长（3-5年），精密加工工艺积累深 |
| 上市通道 | 科创板（军工/高端制造属性）、创业板、港股 |

## 四、主要信号

| 信号类型 | 内容 |
|---------|------|
| 预警信号 | 进入军工配套体系、五轴机床小批量出货、完成关键材料突破 |
| 确认信号 | 头部军工/半导体客户批量导入、营收过亿、完成C轮融资 |
| 风险信号 | 军工认证周期过长、资金压力、核心人才流失 |
