## 二、基于真实案例的IPO路径

### 2.1 华大九天（301269.SZ）— 国产EDA第一股

| 时间 | 事件 | 信号类型 | 距上市 |
|------|------|---------|---------|
| 2009 | 刘伟平创立，依托华大电子EDA团队 | — | 13年前 |
| 2011 | 发布首款模拟电路设计全流程EDA工具 | 预警-产品验证 | 11年前 |
| **2014** | **进入中芯国际、华虹等晶圆厂供应链** | 🔔**头部客户突破（权重18）** | **8年前** |
| 2016 | 完成股改，变更为股份有限公司 | 预警-股改 | 6年前 |
| **2018** | **获得国家大基金投资** | 🔔**国家战略资本（权重18）** | **4年前** |
| 2019 | 营收突破3亿 | 预警-营收过亿 | 3年前 |
| **2020** | **引入有IPO经验的财务团队** | 🔔**CFO/财务团队引入（权重15）** | **2年前** |
| 2021.06 | 辅导备案公示 | 📌确认信号 | 1年前 |
| 2022.03 | 创业板过会 | 📌确认信号 | 即将上市 |
| **2022.07** | **创业板上市（301269）** | 📌**确认信号** | **BD窗口关闭** |

**BD窗口复盘：华大九天成立13年才上市，周期较长。BD黄金窗口在2014-2018年（头部客户突破到大基金投资），此时企业已有明确国产替代定位但尚未进入上市冲刺。真正的"黄金窗口"是2016-2018年（股改后到大基金投资前）。**

## 六、BD紧迫性评分

```
BD紧迫性 = 预警信号加权之和 − 风险信号扣分

⚠️ 确认信号出现时，BD紧迫性=0，标记"窗口已关闭"

评级：
  ≥40 → A级（Phase 4，全力推进）
  30-39 → B级（Phase 3，保持接触）
  20-29 → C级（Phase 3，偶尔接触）
  10-19 → D级（Phase 2，建立认知）
  <10 → E级（Phase 1，观察）
```
