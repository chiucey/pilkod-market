## 一、行业概述

网络与信息安全覆盖网络边界安全、云原生安全和数据安全三大方向。2026年，数据安全法三年执法期+AI安全新威胁，驱动安全需求持续增长。信创政策加速国产安全产品替代，一级市场关注具备差异化安全能力和头部央国企客户覆盖的标的。

---

## 二、核心技术与产品方向

| 方向 | 说明 |
|------|------|
| 数据安全 | 数据分类分级、DSMM认证、数据安全治理平台 |
| 云原生安全 | 容器安全、零信任架构、CNAPP |
| AI安全 | AI模型安全评测、对抗样本防护、AI合规检测 |
| 工业互联网安全 | OT/IT融合安全、工控安全审计 |

---

## 三、行业特征

| 维度 | 说明 |
|------|------|
| 阶段分布 | 头部安全厂商 Phase 3-4；新兴安全（AI安全/云原生）Phase 1-2 |
| 资本密度 | 中——软件为主，研发投入稳定 |
| 政策依赖 | 强——等保2.0、数据安全法、关基保护直接驱动需求 |
| 上市通道 | 科创板（安全属性）、创业板、港股 |
