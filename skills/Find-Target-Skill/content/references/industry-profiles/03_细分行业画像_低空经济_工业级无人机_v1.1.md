## 一、行业定义

工业级无人机是低空经济的另一核心赛道，包括物流无人机、巡检无人机、农业植保无人机、测绘无人机等。与eVTOL相比，工业级无人机技术更成熟，商业化周期更短（3-6年），监管要求相对较低。

---

## 二、成长路径

```
Phase 1          Phase 2            Phase 3             Phase 4            Phase 5
(0-2年)          (2-4年)            (4-7年)             (7-10年)           (10年+)
  │                │                  │                   │                  │
  ├─飞手团队组建   ├─整机定型+认证    ├─头部客户突破       ├─预警信号≥40      ├─辅导备案

  │                │                  │                   ├─大额融资          ├─上市
  估值:<5000万     估值:5000万-3亿    估值:3-10亿         估值:10亿+         市值:20亿+

  ⚠️ Phase 4 = 预警信号≥40且确认信号未出现 = BD唯一窗口
```
