## 一、BD核心认知（最重要）

### ⚠️ BD白金时间窗口 = 上市意向公开前的几周

**一旦新闻中出现上市意向（辅导备案、审计招标、招股书）→ BD窗口已关闭或极度拥挤**

| 时机      | 企业状态       | BD价值                 |
| ------- | ---------- | -------------------- |
| 预警信号累积期 | 企业在准备，但未公开 | **最高** — 提前介入，建立关系   |
| 确认信号出现时 | 企业已公开上市意向  | **极低** — 已在筛选审计师或已签约 |
| 招股书披露后  | 企业已提交上市申请  | **无** — 已尘埃落定        |

### BD ≠ 销售，BD = 投资投人投知识（P\&K）

| 维度      | VC/PE 投钱    | 四大审计 BD 投P\&K         |
| ------- | ----------- | --------------------- |
| 早期      | 少量天使/A轮资金   | 少量接触，建立关系，提供力所能及的帮助   |
| 成长期     | 逐步加码，B轮C轮D轮 | 逐步加深合作，签署单项审计/税务/咨询合同 |
| **预警期** | Pre-IPO轮押注  | **BD最佳窗口：预警信号累积到临界值** |
| 公开期     | 退出获利        | 窗口关闭，竞对分析             |
| 上市后     | —           | 持续服务，交叉销售，异地上市机会      |

## 二、Phase阶段定义（v0.5重构版）

### 核心原则

**Phase 4 = 预警信号累积到临界值，确认信号未出现 = BD唯一有效窗口**

**Phase 5 = 确认信号已出现 = BD窗口关闭**

### Phase定义表

| Phase       | 名称      | 定义                      | BD紧迫性  | 行动              |
| ----------- | ------- | ----------------------- | ------ | --------------- |
| **Phase 1** | 种子期     | 成立不久，无融资/种子轮，预警信号<10    | 观察     | 记录，不主动          |
| **Phase 2** | 成长期     | A/B轮融资，产品研发中，预警信号10-19  | 低      | 建立认知，偶尔接触       |
| **Phase 3** | 扩张期     | C轮以上，产品获批/商业化，预警信号20-39 | 中      | 保持接触，提供帮助       |
| **Phase 4** | **预警期** | **预警信号≥40，确认信号未出现**     | **最高** | **全力推进，这是唯一窗口** |
| **Phase 5** | **公开期** | **确认信号已出现（辅导备案/审计招标）**  | **关闭** | **窗口关闭，竞对分析**   |

### Phase判定流程

```
1. 检查确认信号是否出现
   ├─ 辅导备案公示出现 → Phase 5（窗口关闭）
   ├─ 审计招标公示出现 → Phase 5（窗口关闭）
   └─ 招股书披露 → Phase 5（已上市在即）
   
2. 确认信号未出现，计算预警信号得分
   ├─ 得分 ≥ 40 → Phase 4（BD最佳窗口）
   ├─ 得分 20-39 → Phase 3（保持接触）
   ├─ 得分 10-19 → Phase 2（观察）
   └─ 得分 < 10 → Phase 1（早期）
```

## 三、信号体系（v0.5重构版）

### 3.1 预警信号（🔔）— BD价值所在

**预警信号是BD的核心价值，能提前6-24个月预示企业可能上市**

| #   | 信号                 | 权重     | 说明              |
| --- | ------------------ | ------ | --------------- |
| E1  | **CFO引入（有IPO经验）**  | **20** | 最强预警信号，企业开始准备上市 |
| E2  | **大额融资（单笔≥5亿RMB）** | **18** | 资本押注，企业有上市退出压力  |
| E3  | 政府批地/GMP工厂/产能建设    | 15     | 产能扩张，需要资金支持     |
| E4  | 环评/安评公示            | 12     | 扩产前必要步骤，预示产能扩张  |
| E5  | SPV/境外架构设立         | 12     | 海外上市准备          |
| E6  | 销售团队大规模扩张          | 10     | 商业化加速，营收增长      |
| E7  | 融资轮次升级（A→B→C）      | 10     | 资本认可            |
| E8  | 产品/技术验证（临床/流片/订单）  | 10     | 技术成熟            |
| E9  | Big Player合作/投资    | 10     | 战略认可            |
| E10 | 资质认定（专精特新/小巨人/独角兽） | 10     | 政策认可            |
| E11 | 纳入医保/大客户订单         | 8      | 商业验证            |

### 3.2 确认信号（📌）— BD窗口关闭

**确认信号出现 = BD窗口关闭，竞争激烈，价值大幅下降**

| #  | 信号                 | 出现时行动                    |
| -- | ------------------ | ------------------------ |
| C1 | **辅导备案公示**         | → Phase 5，标记"窗口已关闭"，竞对分析 |
| C2 | **审计/税务招标公示**      | → Phase 5，标记"窗口已关闭"，竞对分析 |
| C3 | **中介机构已签约（券商+律所）** | → Phase 5，标记"窗口已关闭"      |
| C4 | **招股书披露**          | → Phase 5，已上市在即，无BD价值    |

### 3.3 风险信号（⚠️）— 扣分

| #  | 信号        | 扣分      |
| -- | --------- | ------- |
| R1 | 赛道拥挤/竞争恶化 | -5至-10  |
| R2 | 技术/临床失败   | -10至-20 |
| R3 | 核心高管离职    | -8      |
| R4 | 监管处罚/合规问题 | -10     |

## 四、BD紧迫性评分模型（v0.5版）

### 评分公式

```
BD紧迫性 = 预警信号加权之和 − 风险信号扣分

⚠️ 确认信号出现时，不管分数多高，都标记"窗口已关闭"，BD紧迫性=0
```

### 评级阈值

| 得分    | Phase   | BD评级         | 行动          |
| ----- | ------- | ------------ | ----------- |
| ≥40   | Phase 4 | **A级（必须拿下）** | 全力推进，这是唯一窗口 |
| 30-39 | Phase 3 | B级（重点跟进）     | 保持接触，提供帮助   |
| 20-29 | Phase 3 | C级（保持接触）     | 偶尔接触        |
| 10-19 | Phase 2 | D级（观察）       | 建立认知        |
| <10   | Phase 1 | E级（早期）       | 记录，不主动      |

### 确认信号出现时的处理

```
if (辅导备案出现 || 审计招标出现 || 招股书出现) {
  Phase = 5
  BD紧迫性 = 0
  标记 = "窗口已关闭"
  行动 = "竞对分析，观察后续机会"
}
```
