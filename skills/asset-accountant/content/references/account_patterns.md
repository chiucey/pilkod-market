# 账户类型识别模式参考

## 资产类账户

### 1. 银行存款 (bank_savings)
**识别特征**：
- 活期存款、定期存款、大额存单
- 显示"余额"、"可用余额"、"账户余额"
- 银行卡正反面截图

**常见平台**：
- 国有大行：工商银行、农业银行、中国银行、建设银行、交通银行、邮储银行
- 股份制银行：招商银行、浦发银行、中信银行、光大银行、华夏银行、民生银行、广发银行、兴业银行、平安银行
- 城商行：北京银行、上海银行、江苏银行等
- 外资银行：汇丰、渣打、花旗等

### 2. 证券账户 (securities)
**识别特征**：
- 持仓、股票、基金、市值
- "总资产"、"可用资金"、"盈亏"
- K线图、买卖界面

**常见平台**：
- 券商：华泰证券、中信证券、国泰君安、招商证券、海通证券、广发证券等
- 第三方：天天基金、蚂蚁财富、且慢等

### 3. 理财产品 (wealth_mgmt)
**识别特征**：
- 持有份额、累计收益、万份收益
- "理财账户"、"我的理财"
- 封闭式理财、开放式理财

**常见平台**：
- 银行理财子公司、支付宝理财、微信理财通、京东金融等

### 4. 公积金账户 (housing_fund)
**识别特征**：
- 公积金、账户余额、缴存基数
- 个人公积金账户查询

### 5. 第三方支付余额 (payment_asset)
**识别特征**：
- 支付宝余额、微信零钱、零钱通
- 显示"余额"、"可用余额"

## 负债类账户

### 1. 信用卡 (credit_card)
**识别特征**：
- 信用卡、已出账单、未出账单
- "账单日"、"还款日"、"最低还款"
- 额度、使用额度、已用额度

**常见平台**：各银行信用卡

### 2. 贷款账户 (loan)
**识别特征**：
- 贷款、还款计划、剩余本金
- "已还本金"、"待还金额"、"年利率"

**常见类型**：
- 房贷、车贷、消费贷、信用贷、经营贷

### 3. 第三方信用支付 (payment_liability)
**识别特征**：
- 花呗、借呗、京东白条、微信分付
- "可用额度"、"待还金额"

---

## 混合型账户

### 第三方支付 (payment)
**特点**：支付宝、微信支付等既有余额（资产）也有信用支付（负债）

**判断规则**：
1. 截图显示"余额" → 记录为资产
2. 截图显示"花呗/借呗" → 记录为负债
3. 如同时显示 → 询问用户想要记录哪部分

---

## 识别优先级

1. **关键词匹配** → 首先识别明显的账户类型关键词
2. **视觉特征** → APP界面、颜色、logo
3. **用户确认** → 如不确定，询问用户

## 常见问题

**Q: 如何区分储蓄卡和信用卡？**
A: 信用卡通常显示"信用额度"、"账单日"、"还款日"，且卡号以4/5/37等开头

**Q: 证券账户如何计算余额？**
A: 总资产 = 可用资金 + 持仓市值（股票+基金+现金理财）

**Q: 理财产品和基金有何区别？**
A: 理财产品收益相对稳健，基金净值波动较大；两者都属于"投资类资产"

**Q: 截图金额为负数怎么办？**
A: 通常表示负债（如信用卡欠款），记录为负值资产或单独计入负债
