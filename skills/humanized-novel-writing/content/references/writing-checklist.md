# 去AI味自检清单与修改示例

## 一、时间线逻辑自检

### 常见时间线错误

```
错误类型1：时光倒流
❌ 错误："他吃完晚饭去上班，回到家才早上八点。"
✅ 正确："他上完夜班回到家，天刚蒙蒙亮。"

错误类型2：季节矛盾
❌ 错误："七月流火，他呼出的白气在空气中凝结成霜。"
✅ 正确："腊月寒冬，他呼出的白气在空气中凝结成霜。"

错误类型3：时间压缩
❌ 错误："他受伤了，躺在床上休息，然后立刻跳起来开始打拳。"
✅ 正确："他养了三个月伤，伤愈后才重新开始练拳。"

错误类型4：遗忘前置事件
❌ 错误："他打开门，王铁匠递给他一把剑。"（但前文没提找王铁匠打剑）
✅ 正确："他三天前找到王铁匠订制宝剑，今日来取。王铁匠递给他一把——"
```

### 时间线自检代码

```markdown
## 检查方法：倒推法

从结局倒推：
1. 角色A活到了结局，那么他/她在前文不能死亡
2. 角色B拿到了房产证，那么前文必须有继承/购买的情节
3. 角色C会了某技能，那么前文必须有学习/训练的情节

时间标记法：
✓ 每个事件后标注：（第X天/第X章）
✓ 如果事件A在事件B之前，事件B在事件C之前
✓ 检查是否有事件D出现在事件C之后，却用了"随后""接着"等表示先发生的词
```

## 二、角色死亡/消失检查

### 致命逻辑错误

```
错误类型：死而复生（无伏笔）
❌ 错误：第5章他被枪击中，倒在血泊中死去。
       第8章他出现在酒吧，和朋友喝酒聊天。
       （除非是鬼魂/复活设定，且有明确铺垫）

✅ 正确（灵异设定）：
第5章他被枪击中，倒在血泊中死去。
第6章道士说："此人气数未尽，若找到九转还魂丹，或有一线生机。"
第8章他出现在酒吧，苍白着脸，眼底有诡异的青光。

✅ 正确（双胞胎/替身设定）：
前文铺垫：他们家族是双胞胎血统，有心灵感应
后文：他死了，但他的双胞胎兄弟继承了他的身份
```

### 检查清单

```
□ 角色死亡时是否明确宣告？（"再也没能醒来""永远闭上了眼睛"）
□ 死亡后是否还有大量戏份？
□ 如果有鬼魂/复活设定，前文是否有铺垫？
□ 如果是替身/双胞胎，是否有足够的伏笔？
□ 读者是否会困惑？（如果会，需要更多解释）
```

## 三、能力/物品获得检查

### 常见漏洞

```
错误类型1：无中生有
❌ 错误："他掏出钥匙打开门。"（但前文没提他有钥匙）
✅ 正确："他从口袋里摸出备用钥匙，打开门。"

错误类型2：能力突变
❌ 错误："他是个普通上班族，从没练过武。"（第3章）
       "他一拳打断了碗口粗的树。"（第5章）
✅ 正确（两种改法）：
A. 前文铺垫："他虽然没正经学过武，但父亲是拳击手，从小耳濡目染"
B. 前文铺垫："那天之后，他每天凌晨四点起床练拳，风雨无阻"（有过渡期）

错误类型3：能力时有时无
❌ 错误："他一个箭步冲上三楼"（展示了攀爬能力）
       "他被困在三楼，无法下去"（又忘了之前的能力）
✅ 正确："他可以冲上三楼，但冲下来需要借助绳索"（给出合理限制）
```

## 四、性格一致性检查

### 暴躁型角色检查

```
性格设定：暴躁冲动，一言不合就动手

检查以下场景：
□ 被挑衅时是否立刻发火？（不应该：冷静分析）
□ 争论时是否语速越来越快？（不应该：慢条斯理）
□ 愤怒时是否有肢体动作？（攥拳、跺脚、摔东西）
□ 愤怒时是否爆粗口或语气词？（他妈的、X的）
□ 愤怒时是否听不进解释？（不应该：耐心听完）
□ 冷静后是否后悔/尴尬？（可以有，可以没有）
```

### 冷静型角色检查

```
性格设定：冷静理性，喜怒不形于色

检查以下场景：
□ 遇到危机时是否先沉默思考？（不应该：立刻慌张）
□ 争论时是否逻辑清晰、有条理？（不应该：语无伦次）
□ 愤怒时是否反而更冷静？（冷笑、语调更低）
□ 悲伤时是否外露？（不应该：当众痛哭）
□ 是否经常说"让我分析一下""这不合理"？
```

### 内向外向检查

```
内向角色检查：
□ 多人场合是否沉默/局促？
□ 是否需要独处时间来恢复精力？
□ 对话是否简短，不爱主动开口？
□ 是否在人群中感到消耗而非充电？

外向角色检查：
□ 是否主动和人搭话？
□ 是否在热闹场合更有活力？
□ 是否话多，需要表达欲出口？
□ 独处时是否感到无聊/不安？
```

## 五、情感描写去AI味检查

### AI味表达大赏

```
❌ AI味1：直接写心理标签
"她感到悲伤""他内心充满愤怒""她觉得委屈"

✅ 人类写法：
"眼泪啪嗒掉下来，她抬手去擦，却越擦越多。"
"他深吸一口气，把那股火硬生生压了下去，太阳穴突突跳。"
"她张了张嘴，想说什么，最后还是咽了回去，嗓子眼堵得慌。"

❌ AI味2：情感词汇堆砌
"她悲伤地、痛苦地、绝望地哭了起来"
"他愤怒地、激动地、大声地吼了出来"

✅ 人类写法：
"她蹲在地上，把脸埋进膝盖里，肩膀一抽一抽的。"
"他吼了一嗓子，脖子上的青筋都鼓起来了，手握成拳，指节发白。"

❌ AI味3：生理反应模板化
"心跳加速""瞳孔收缩""血液沸腾"

✅ 人类写法：
"心脏砰砰砰擂鼓似的，震得他耳朵里嗡嗡的。"
"后脖颈子一阵发麻，那种感觉顺着脊椎往下窜。"
"太阳穴突突跳，像是有小锤子在里头敲。"
```

### 替换练习

```
将以下AI味表达改写为人类写法：

1. "他感到紧张"
改写：_________________________________

2. "她很害怕"
改写：_________________________________

3. "他很愤怒"
改写：_________________________________

4. "她很感动"
改写：_________________________________

参考答案：
1. "他下意识咽了口唾沫，手心黏糊糊的，老想往裤腿上蹭。"
2. "她往后退了一步，脚跟磕在门槛上，差点摔了个仰八叉。脑子一片空白，就一个念头：跑。"
3. "他牙关咬紧，脸皮绷得能弹琵琶。嘴唇哆嗦着想骂什么，又生生憋了回去，那口气堵在胸口，上不去下不来。"
4. "她愣在那，眼眶发酸，想说点什么客套话，张了张嘴，一个字也没说出来。最后只是狠狠点了点头，使劲眨了眨眼，把那股湿意逼了回去。"
```

## 六、对话去AI味检查

### AI味对话特征

```
❌ AI味1：信息密度过高
"你好，我是来自北京的大学生，今年22岁，专业是计算机科学。"
（正常人会分段说，或者被追问才补充）

❌ AI味2：过于正式/书面化
"我认为我们应该重新评估这个方案的风险收益比。"
（朋友之间谁这么说话？除非人设是精英律师）

❌ AI味3：过于直白
"我爱你，嫁给我吧。"
（正常人要么说不出口，要么要铺垫浪漫氛围）

❌ AI味4：角色声音模糊
A："今天天气真好。"
B："是啊，阳光明媚。"
C："我同意你的观点。"
（三个人的说话方式一模一样，没有区分度）
```

### 人类对话特征

```
✅ 人类对话1：欲言又止
"那个……算了，没什么。"
"有些事……算了，跟你说了你也不懂。"

✅ 人类对话2：话里有话
"门怎么开着？"（潜台词：你是不是带人进来了？）
"这咖啡不错。"（潜台词：暗示想再来一杯）

✅ 人类对话3：废话/闲聊
"吃了吗？"
"嗯。"
"天气真他妈热。"
"可不是嘛。"
（废话是拉近距离的方式，AI总觉得废话没用）

✅ 人类对话4：打断/重叠
"我也觉得——"
"你闭嘴，先听我说完。"
```

## 七、场景描写去AI味检查

### AI味场景特征

```
❌ AI味1：摄像机式描写
"房间里有床、桌子、椅子、窗户。床上有被子，桌上有一盏灯。"
（信息罗列，没有重点，没有情绪）

❌ AI味2：五感堆砌
"他走进房间，看到墙上的画，听到窗外的鸟鸣，闻到桌上的花香，感受到微风拂过脸颊。"
（刻意凑齐五感，反而假）

❌ AI味3：比喻过于文艺
"她的眼睛像深邃的星空，又如清澈的湖水，仿佛藏着无尽的秘密。"
（用力过猛）

✅ 人类场景：选择性聚焦
"他推开门，屋里一股霉味。灯没开，窗帘拉着，只有床头的烟灰缸满了。"
（床头的烟灰缸满了——这一细节传达了：失眠、焦虑、时间流逝）
```

### 场景聚焦练习

```
任务：根据情绪选择该聚焦什么

情绪：压抑
应该聚焦的感官：___________________________
不应该聚焦的感官：___________________________

情绪：紧张
应该聚焦的感官：___________________________
不应该聚焦的感官：___________________________

情绪：幸福
应该聚焦的感官：___________________________
不应该聚焦的感官：___________________________

参考答案：
情绪：压抑
应该聚焦的感官：视觉（灰暗色调、空旷）、触觉（闷热/阴冷）
不应该聚焦的感官：味觉（除非是苦涩的味道）、嗅觉（除非是刺鼻气味）

情绪：紧张
应该聚焦的感官：听觉（滴答声、自己的心跳）、触觉（手心出汗）
不应该聚焦的感官：味觉

情绪：幸福
应该聚焦的感官：视觉（明亮）、嗅觉（食物香气、花香）、触觉（温暖阳光）
不应该聚焦的感官：听觉（除非是喜欢的音乐）
```

## 八、综合自检流程

```
第一步：通读全文，记录以下信息
□ 所有事件的时间顺序
□ 所有角色的生死状态
□ 所有物品/能力的获得时间
□ 所有主要角色的性格表现

第二步：交叉比对
□ 死亡的角色是否还有戏份？
□ 物品是否在使用前获得？
□ 能力是否有学习过程？
□ 性格反应是否一致？

第三步：重点检查
□ 开头的伏笔，结尾是否回收？
□ 承诺的悬念，是否给出答案？
□ 情感铺垫，是否给出高潮？

第四步：朗读检查
□ 大声朗读对话，听起来像人话吗？
□ 情绪描写，读起来有画面吗？
□ 有没有自己读着都尴尬的表达？

第五步：冷却检查
□ 放一晚上再回来读
□ 能否一眼看出哪里是AI味？
□ 哪段读起来最像人写的？
□ 重点修改那些最AI味的部分
```

## 九、快速检查脚本（适用于AI辅助检查）

```
检查要点清单（复制到笔记软件）：

【时间线】
□ 事件A发生在事件B之前/之后？
□ 时间标记是否一致？（上午→下午→晚上 vs 早上→下午→夜里）
□ 是否有时间压缩/膨胀需要解释？

【角色状态】
□ [角色名]此时是活着还是死了？
□ [角色名]此时是否在[地点]？
□ [角色名]此时是否知道[信息]？

【能力/物品】
□ [角色名]在[章节]之前是否会[能力]？
□ [物品名]在[章节]之前是否获得？
□ 是否有矛盾（获得前使用/死亡后出现）？

【性格一致性】
□ [角色名]是[性格类型]，遇到[事件]会[反应]吗？
□ [反应]是否符合[性格类型]的典型表现？
□ 有没有突兀的性格转变？

【情感描写】
□ 是否有"感到XX"的直接心理标签？
□ 是否有情感词汇堆砌？
□ 是否有模板化的生理反应？
□ 是否有画面感的具体描写？

【对话】
□ 是否有废话/闲聊？
□ 是否欲言又止？
□ 是否话里有话？
□ 角色声音是否区分？
```

## 十、修改示例

### 修改前（AI味）

```markdown
他走进房间，看到房间里有一张床，一张桌子，桌子上放着一盏灯。床上躺着一个女人，女人的脸上露出悲伤的表情。

"你来了。"女人说。
"是的，我来了。"他说。
"你为什么来？"
"因为我爱你。"
"可是我们已经不可能了。"
"为什么？"
"因为我得了绝症。"
他感到震惊，感到悲伤，感到绝望。
```

### 修改后（人情味）

```markdown
他推门进去，屋里一股子消毒水味，呛得他皱了下眉头。

床上的被子鼓鼓的，就露了个脑袋顶。她瘦得颧骨都凸出来了，眼窝陷进去一块，皮肤黄得跟旧报纸似的。

听见动静，她把脸转过来，嘴角扯了扯，像是想笑，又没笑出来。

"来啦。"

"嗯。"

他站在门口，不知道该往前走还是往后退。脚底下像灌了铅，挪不动。

"坐啊，杵着干嘛。"她拍了拍床沿，声音虚得跟纸片似的。

他在床边坐下，床垫凹下去一块，两人挨着，却像隔着十万八千里。

她盯着天花板看，半天才开口："有些事，得跟你说清楚。"

他没吭声，攥着拳头，指甲往肉里掐。

"我这病，查出来了。"她顿了顿，"治不了。"

那两个字砸下来，砸得他耳朵里嗡嗡的，眼前一阵发黑。
```

**修改要点**：

1. 场景描写用细节代替罗列（消毒水味→医院/病重）
2. 对话打断、沉默、废话（正常人的说话方式）
3. 肢体语言代替心理标签（攥拳头、指甲掐肉）
4. 环境映射情绪（消毒水味、瘦脱相）
5. 最后一句用身体反应代替"他感到震惊绝望"
