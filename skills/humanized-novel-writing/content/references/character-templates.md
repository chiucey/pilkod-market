# 人物性格设定模板与示例

## 暴躁冲动型角色示例

### 示例一：街头混混张铁柱

```
- **性格标签**：A型暴躁冲动
- **性格详解**：从小在街头摸爬滚打，拳头比脑子先动。被人瞪一眼都觉得是挑衅，非要争个输赢。讲义气但方式粗暴，护短护得恨不得把兄弟揣兜里。
- **口头禅**："你瞅啥？""老子今天非得——"
- **习惯动作**：撸袖子、攥拳头、歪着脑袋瞪人
- **遇到困境会**：先骂一顿再说，"他妈的，这破事怎么让老子赶上了"
- **遇到帮助会**：嘴硬心软，"行吧，看你小子还有点用"
- **害怕/弱点**：被在乎的人看不起，那比挨打还难受
```

### 示例二：战场老兵李猛

```
- **性格标签**：A型暴躁冲动（但有底线）
- **性格详解**：战场上活下来的，脾气火爆但不是莽夫。骂人凶但判断准，关键时刻反而冷静。对新兵蛋子没耐心，但对真正的战士服气。
- **口头禅**："都给我精神点！""屁大点事，惊弓之鸟一样"
- **习惯动作**：背手站立、皱眉扫视、用脚碾烟头
- **遇到困境会**："都给老子稳住！慌什么！"
- **遇到帮助会**：简短道谢，"嗯，记住这份情"
- **害怕/弱点**：看着战友死在眼前却无能为力
```

## 冷静理性型角色示例

### 示例一：天才医生林若水

```
- **性格标签**：B型冷静理性
- **性格详解**：见惯生死，手术台上容不得半点情绪。说话条理清晰，像是在写病历。对感情迟钝，或者说故意迟钝，因为太清醒所以痛苦。
- **口头禅**："让我先理一下。""这不是情绪化能解决的问题。"
- **习惯动作**：推眼镜、双手交叉抱胸、目光下视思考
- **遇到困境会**：沉默片刻，然后开始分析"目前有三条路……"
- **遇到帮助会**：表达感谢，然后评估利弊，"你的方案可行，但风险在……"
- **害怕/弱点**：无法控制的局面，比如亲人生病
```

### 示例二：商业精英陈墨白

```
- **性格标签**：B型冷静理性
- **性格详解**：商场沉浮多年，早已喜怒不形于色。谈判时像一台精密的计算机，永远在计算利弊。对感情疏离，觉得那是弱点。
- **口头禅**："这个决定会带来什么后果？""数据说话。"
- **习惯动作**：敲桌面思考、扶眼镜、负手而立
- **遇到困境会**：快速评估损失，制定止损方案
- **遇到帮助会**：不动声色地记下，日后图报
- **害怕/弱点**：被信任的人背叛，那会摧毁他的整个世界观
```

## 阴郁深沉型角色示例

### 示例一：复仇者沈夜

```
- **性格标签**：C型阴郁深沉
- **性格详解**：被命运碾压过，眼中永远有一层霜。看人先看弱点，像猎食者。不轻易信任任何人，但一旦信任就是全部。
- **口头禅**："……"（经常沉默，或者说一句就够）"别让我失望。"
- **习惯动作**：黑暗中独坐、手指摩挲旧物、嘴角一抹冷笑
- **遇到困境会**：冷笑，"有意思，又来一个"
- **遇到帮助会**：试探动机，"你想要什么？"
- **害怕/弱点**：发现自己恨错了人，复仇失去意义
```

### 示例二：落魄贵族苏晚棠

```
- **性格标签**：C型阴郁深沉（带点骄傲）
- **性格详解**：曾经锦衣玉食，一朝落魄。骨子里的傲气还在，但学会了隐忍。眼神时常放空，像在想念再也回不去的从前。
- **口头禅**："不必了。""……随你们怎么想。"
- **习惯动作**：整理衣袖（曾经的习惯）、垂眸、指尖微颤
- **遇到困境会**：沉默，然后咬牙撑下去
- **遇到帮助会**：警惕中带着一丝感激，但不会表现出来
- **害怕/弱点**：曾经的家人/爱人看到自己落魄的样子
```

## 开朗阳光型角色示例

### 示例一：热血记者何暖暖

```
- **性格标签**：D型开朗阳光
- **性格详解**：像一颗小太阳，走到哪都热闹。眼泪来得快去得也快，永远相信好人多。用幽默化解尴尬，是团队的润滑剂。
- **口头禅**："哎呀，这都不是事儿！""来来来，想开点！"
- **习惯动作**：拍人肩膀、双手比划、歪头笑
- **遇到困境会**："没事没事，天塌不下来，就算塌下来还有高个子顶着嘛！"
- **遇到帮助会**：使劲道谢，非要请人吃饭不可
- **害怕/弱点**：看见真正在乎的人受伤，那笑容就挂不住了
```

### 示例二：草根创业者赵大嘴

```
- **性格标签**：D型开朗阳光（带点痞气）
- **性格详解**：嘴贫脸皮厚，被拒绝一百次还能笑嘻嘻第一百零一次。但夜深人静时会一个人抽烟，眼里有藏不住的野心。
- **口头禅**："兄弟，听我一句——""信我，没错的！"
- **习惯动作**：搓手、拍胸脯、递烟
- **遇到困境会**：自嘲"看来老天爷觉得我还没被玩够"
- **遇到帮助会**：认真记下，拍着胸脯说"这份情兄弟记一辈子"
- **害怕/弱点**：连累了在乎的人，那笑容就变成了苦笑
```

## 性格组合与演变

### 性格组合示例

```
# 表面开朗实则阴郁：喜剧演员型

表面特征：
- 话多、爱开玩笑、总是笑着
- 用幽默化解一切尴尬
- 朋友眼中的开心果

内心真实：
- 独处时沉默、失眠
- 笑容是面具，摘不下来
- 害怕安静，因为安静时杂念会涌上来

触发点：
- 深夜独处
- 触景伤情（某些歌曲、某些气味）
- 被真正懂自己的人看穿
```

### 性格演变伏笔

```
# 暴躁者学会隐忍

前期：遇事就炸，拳头解决一切
转折事件：一次冲动导致挚友受伤/死亡
后期：看似还是那个暴脾气，但关键时刻会先沉默三秒
          那个三秒，就是成长
          但如果被逼急了，那三秒会消失
          因为有些东西是刻在骨子里的

# 冷漠者学会动心

前期：觉得感情是负担，是弱点
转折事件：遇到一个让他/她破防的人
后期：笨拙地学着关心人
          方式可能很别扭，但那份真心藏不住
          可能会说反话："谁稀罕你啊"然后偷偷准备惊喜
```

```markdown
## 龙套角色快速设定

【小贩】
- 性格：A/D混合
- 口头禅："便宜卖了便宜卖了！"
- 动作：搓手、吆喝、看人下菜碟
- 用途：提供信息、制造氛围、衬托主角

- 用途：传递信息、观察环境

【邻居大妈】
- 性格：A/D混合，爱八卦
- 口头禅："哎呀，听说……""那家可不简单……"
- 动作：探头、招手、拉家常
- 用途：传播信息、制造误会、调节节奏
```

## 写作检查：性格一致性

```
完成角色戏份后，检查：

1. 语言是否一致？
   - 一个平时话少的人会突然长篇大论吗？（除非有特殊原因）
   - 粗人会突然文绉绉吗？

2. 行为是否合理？
   - 暴躁的人会先打还是先想？（先打）
   - 理性的人会先分析还是先行动？（先分析）
   - 内向的人会在公开场合大声发言吗？（不太可能）

3. 反应是否过度或不足？
   - 普通程度的坏事：对应普通程度的情绪反应
   - 巨大的打击：对应剧烈但符合性格的情绪反应
   - 不是所有坏事都要哭/吼/摔东西
```
