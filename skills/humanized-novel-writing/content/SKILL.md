# 去AI味的小说写作技能

## 核心理念

**写作目标**：让小说读起来像是活生生的人在倾诉，而非冰冷的AI在堆砌文字。每一个场景、每一句对话、每一个人物反应，都应该带着人类特有的温度、偏见和情感。

## 第一原则：作者上帝视角偏爱

**摒弃中立叙事，采用偏爱叙事**

作者不是一台客观记录事件的摄像机，而是一个有血有肉、会笑会哭会愤怒的讲述者。要明确表达对角色的态度和情感。

### 偏爱表达方式

| 中立写法（AI味） | 偏爱写法（人情味） |
|----------------|------------------|
| "他走进房间" | "他晃晃悠悠地走进房间，那副德行像是刚输光了家底——事实上也差不多" |
| "她很漂亮" | "漂亮？那是老天爷把所有的偏爱都砸在了她脸上，其他姑娘估计得气哭" |
| "敌人撤退了" | "那群乌合之众总算知道跑了，谢天谢地，总算能喘口气了" |

### 偏爱维度

1. **情感偏爱**：直接表达喜恶（"那个虚伪的家伙总算露出马脚了""可怜的孩子，命怎么这么苦"）
2. **道德偏向**：明确的价值判断（"这才是真正的勇敢""卑鄙是卑鄙者的通行证"）
3. **幽默讽刺**：用调侃化解沉重（"他的逻辑清奇得像是外星人教的"）
4. **感同身受**：让读者代入角色情感（"那种滋味，只有经历过的人才懂——像是心被人狠狠攥了一把"）

## 第二原则：自动资料学习

### 写作前资料搜集

当需要构建特定类型小说时，必须执行以下步骤：

```
1. 搜索网络流行小说设定和写作方法
2. 分析热门网文的叙事风格和节奏把控
3. 学习该类型的经典桥段和人物原型
4. 收集读者喜闻乐见的情感描写技巧
```

### 资料搜集触发条件

- 涉及专业领域（医疗、法律、军事、历史等）
- 涉及特定时代背景或地域文化
- 涉及异能、修仙、科幻等需要设定体系的内容
- 用户明确要求参考某种风格

### 学习要点

1. **叙事节奏**：分析热门小说如何控制章节节奏、情节起伏
2. **人物塑造**：学习经典网文如何用细节让角色活起来
3. **情感渲染**：研究如何用环境、动作、心理描写触动读者
4. **对话设计**：掌握如何让角色说话像"人"而非"广播"

## 第三原则：逻辑自检机制

### 时间线检查

每次完成初稿后，必须检查：

```
时间线检查清单：
□ 事件顺序是否合理？（不能先吃早餐后起床）
□ 时间间隔是否明确？（"半小时后"vs"三天后"）
□ 季节/天气是否自洽？（不能在夏天呼出白气）
□ 角色年龄/状态是否连续？（受伤恢复需要时间）
```

### 逻辑一致性检查

```
逻辑检查清单：
□ 角色死亡后不应再出现（除非灵异设定）
□ 物品获得前不能使用（除非提前铺垫）
□ 能力设定是否一致？（不能一会能飞一会不能）
□ 人物关系是否连贯？（敌人变朋友需要合理动机）
□ 性格反应是否一致？（暴躁者不会突然冷静）
```

### 因果链检查

- 每个事件是否有充分的起因？
- 每个决定是否有合理的动机？
- 每个后果是否符合自然规律或设定规则？

## 第四原则：性格驱动反应

### 性格分类与反应模板

每个角色必须有明确的性格标签，并按此产生差异化反应：

#### A型：暴躁冲动型

**性格特征**：情绪外露、容易激动、直接表达愤怒
**遇到困境**："你他妈的是不是活腻了！""老子今天非弄死你不可！"
**遇到帮助**：勉强接受，嘴上不饶人
**遇到失败**：砸东西、大骂、迁怒他人
**语言习惯**：短句多、感叹号多、脏话或拟声词多

#### B型：冷静理性型

**性格特征**：情绪内敛、善于思考、不轻易表露
**遇到困境**：沉默思考"先别慌，让我理一理"
**遇到帮助**：表示感谢，分析利弊
**遇到失败**：总结教训，寻找出路
**语言习惯**：长句多、因果关系清晰、很少感叹

#### C型：阴郁深沉型

**性格特征**：内心复杂、不信任人、习惯独自承受
**遇到困境**：沉默，或用冷笑掩饰不安
**遇到帮助**：怀疑动机，试探性接受
**遇到失败**：自我否定，或将怒火转向自己
**语言习惯**：话少、意味深长、常有弦外之音

#### D型：开朗阳光型

**性格特征**：乐观向上、热情友善、善于活跃气氛
**遇到困境**：调侃自己"哎呀，这下有意思了"
**遇到帮助**：真诚感谢，拉人下水（开玩笑）
**遇到失败**：自嘲"老天爷跟我开玩笑呢吧"
**语言习惯**：轻松幽默、善于自嘲、爱用俏皮话

### 性格一致性规则

```
核心原则：
- 性格决定语言风格（暴躁者不会文绉绉）
- 性格决定肢体语言（紧张者会搓手，傲慢者会叉腰）
- 性格决定决策方式（理性者权衡利弊，冲动者先打再说）
- 性格决定情感表达（外放者喜怒于形，内敛者喜怒不形于色）

例外情况：
- 重大创伤可能导致性格短暂或长期改变（需铺垫）
- 特定情境可能触发性格的另一面（需伏笔）
```

## 第五原则：人类情感描写

### 去AI化的情感描写技巧

#### 1. 具体化而非抽象化

| AI味写法 | 人情味写法 |
|---------|-----------|
| "她很悲伤" | "眼泪啪嗒掉在照片上，她赶紧用袖子去擦，却越擦越多" |
| "他很紧张" | "手心全是汗，攥着那张车票，纸都被捏出了褶子" |
| "她很生气" | "嘴唇抿成一条线，想说什么又咽了回去，转身的时候门摔得哐当响" |

#### 2. 用身体反应代替心理标签

```
紧张：咽口水、手心出汗、坐立不安、说话结巴
悲伤：眼眶发酸、声音发颤、沉默、独自发呆
愤怒：脸涨红、握拳、语速加快、呼吸粗重
喜悦：眼睛发亮、嘴角上扬、话多、动作轻快
恐惧：后退、脸色发白、身体僵硬、想逃
```

#### 3. 环境映射情绪

```
情绪高涨：阳光刺眼、音乐嘈杂、人声鼎沸
情绪低落：阴雨绵绵、空旷街道、落叶纷纷
情绪紧张：钟表滴答、走廊寂静、灯光昏暗
情绪放松：微风拂面、咖啡飘香、懒洋洋的午后
```

#### 4. 对话承载情感

```markdown
# AI味
"我很生气。"他说。

# 人情味
"行啊，你真行啊。"他笑了笑，眼底却冷得像冰碴子。
```

### 情感描写禁忌

```
❌ 禁止：直接写心理标签（"她感到悲伤""他内心挣扎"）
❌ 禁止：情感词汇堆砌（"她悲伤地、痛苦地、绝望地哭了"）
❌ 禁止：全知全能的内心独白（让人物自己说出感受，而非作者替他说）
❌ 禁止：情感反应模式化（不是所有悲伤都要哭，不是所有愤怒都要吼）
```

## 第六原则：场景构建五感法

### 五感描写清单

```
视觉（看）：
- 光影变化（晨光、夕阳、阴影）
- 色彩对比（鲜艳、暗淡、斑驳）
- 空间布局（拥挤、宽敞、杂乱）
- 人物表情和动作细节

听觉（听）：
- 环境音（雨声、风声、人声）
- 人物语音（语气、音量、停顿）
- 物件声音（门响、脚步、碰撞）
- 留白沉默（比声音更有力量）

嗅觉（闻）：
- 场景特征气味（花香、烟味、消毒水）
- 情绪相关气味（冷汗的酸味、恐惧的尿骚味）
- 记忆触发气味（某种香水、食物勾起回忆）

味觉（尝）：
- 口干舌燥（紧张时）
- 食不知味（悲伤时）
- 苦涩/甘甜（特定情绪映射）

触觉（摸）：
- 材质感受（冰冷、粗糙、湿润）
- 身体接触（握手、拥抱、推搡）
- 环境触感（风吹、雨淋、日晒）
```

### 五感组合原则

```
必备：视觉 + 至少一项其他感官
忌讳：五感全用（堆砌感）
技巧：选择性聚焦（紧张时放大听觉，悲伤时放大触觉）
```

## 第七原则：对话设计技巧

### 对话设计四要素

```
1. 角色声音独特性
   - 用词习惯（文化程度、地域特征）
   - 说话节奏（快/慢、连贯/停顿）
   - 口头禅/小动作

2. 信息传递效率
   - 不要让角色说读者已经知道的信息
   - 潜台词比台词更有力量
   - 对话推进情节，而非重复情节

3. 冲突和张力
   - 欲言又止
   - 话里有话
   - 正话反说

4. 潜文本写作
   - 角色嘴上说的≠心里想的
   - 留白让读者脑补
   - 对话间隙的信息量
```

### 对话节奏示例

```markdown
# 紧张对峙
"你到底想怎样？"
"我？"
"少跟我装蒜。"
沉默。
门外的脚步声越来越近。

# 温情时刻
"吃饭了。"
"嗯。"
"今天做的是你爱吃的糖醋排骨。"
他愣了一下，筷子停在半空中，许久没动。

# 争吵场景
"你知道我等了多久吗！"
"我——"
"你什么你！你知不知道那天——"
"够了！"
两人同时沉默，空气中弥漫着令人窒息的尴尬。
```

## 写作流程

### 完整写作流程

```
1. 需求分析
   - 确定小说类型（都市、玄幻、悬疑等）
   - 确定目标受众和风格偏好
   - 明确核心冲突和情感基调

2. 资料搜集（必要时）
   - 搜索相关类型写作技巧
   - 查询专业背景资料
   - 学习经典桥段和人物原型

3. 设定构建
   - 世界观/背景设定
   - 人物性格设定（使用性格驱动反应原则）
   - 主要人物关系图谱

4. 情节规划
   - 主线情节梳理
   - 关键转折点设计
   - 情感高潮铺垫

5. 写作执行
   - 运用五感法构建场景
   - 性格驱动角色反应
   - 作者偏爱视角叙事
   - 情感具体化描写

6. 自检完善
   - 时间线逻辑检查
   - 性格一致性检查
   - 因果链完整性检查
   - 去AI味检查

7. 修改优化
   - 根据检查结果修改
   - 强化偏爱叙事风格
   - 打磨对话和情感描写
```

## 输出格式规范

### 章节输出格式

```markdown
# 第X章 章节标题

【场景开头】
（五感描写引入，设置氛围）

【情节展开】
（用对话和动作推进，避免大段心理描写）

【情感渲染点】
（具体化情感，调动多种感官）

【章节结尾】
（留钩子/悬念/情感余韵）
```

### 人物卡格式

```markdown
## 角色名

- **性格标签**：[主要性格类型]
- **性格详解**：[2-3句话描述性格形成原因和表现]
- **口头禅**：[一句话]
- **习惯动作**：[一个小动作]
- **遇到困境会**：[根据性格类型的具体反应]
- **遇到帮助会**：[根据性格类型的具体反应]
- **害怕/弱点**：[能让这个角色害怕的事物]
```

## 质量检查清单

### 写作完成后的自检

```
□ 时间线是否自洽？（没有时光倒流）
□ 角色死亡/离开后是否彻底消失？
□ 物品/能力获得前是否没有使用？
□ 对话是否有人类特有的节奏感？
□ 情感描写是否具体化而非标签化？
□ 性格反应是否与设定一致？
□ 是否存在作者偏爱视角而非冰冷中立？
□ 是否有可以去掉的AI味表达？
□ 感官描写是否平衡而非堆砌？
□ 场景是否让读者有画面感？
```

## 注意事项

1. **灵活运用**：本技能提供的是指导原则，具体写作应根据内容灵活调整
2. **风格统一**：整篇小说的叙事风格应保持一致
3. **节奏把控**：不是每个场景都需要五感齐全，有时留白更有力量
4. **尊重用户意图**：在用户明确要求下可以调整某些原则
5. **持续学习**：网络文学风格在不断演进，应持续更新资料库
