# stock-portfolio-advisor · A股持仓顾问技能

> 🎯 **核心卖点：持仓诊断 + 六维风险评估 + 调仓优化**，个性化投资顾问

---

## 功能概览

| 功能 | 说明 |
|------|------|
| 📸 **截图持仓识别** | 券商App截图AI识别，零配置，自动提取名称/代码/成本 |
| 📊 **持仓结构分析** | 行业分布 / 市值风格 / 集中度(HHI) / 仓位占比 |
| 🎯 **仓位健康诊断** | 总仓位、单股仓位、行业占比、配置合理性评估 |
| 🚨 **六维风险评估** | 集中度/波动性/流动性/趋势/仓位/相关性 各25分 |
| ⚖️ **调仓优化建议** | 优先级操作清单（止损/止盈/加仓/持有）|
| 📡 **多数据源管理** | 腾讯(主)/新浪(备)/聚宽/TuShare/自定义API |
| 🔧 **用户自定义数据源** | 支持自行添加、测试、启用/禁用数据源 |
| 🔐 **API Key安全存储** | 环境变量加密，不明文存储密钥 |

## 快速开始

```
分析我的持仓 / 帮我看看配置是否合理 /

需要调仓吗 / 帮我规划资金配置 /

接入聚宽 / 配置tushape
```

### 持仓传递方式（4种）

#### 方式一：券商截图（⭐ 最简单）

将券商App持仓截图直接发给儿臣，AI自动识别持仓数据：
- 支持所有券商App截图
- 自动提取：股票名称、代码、持股数、成本价、现价、盈亏

#### 方式二：对话中直接提供

```
请分析我的持仓：
示例股票A sh600519 500股 成本1800元
示例股票B sz000858 300股 成本150元
示例股票C sh601012 200股 成本50元
```

#### 方式三：JSON格式（精准传递）

```json
[
  {"code":"sh600519","name":"示例股票A","shares":500,"cost":1800},
  {"code":"sz000858","name":"示例股票B","shares":300,"cost":150}
]
```

#### 方式四：配置文件

将持仓写入 `~/.holdings.json`，脚本自动加载。

## 六维风险评估

| 维度 | 权重 | 优秀(25分) | 良好(20分) | 一般(15分) | 较差(8分) |
|------|------|-----------|-----------|-----------|-----------|
| 集中度风险 | 25分 | <20% | <30% | <40% | ≥40% |
| 波动性风险 | 25分 | <2% | <4% | <6% | ≥8% |
| 流动性风险 | 25分 | >2亿股 | >1亿股 | >5000万 | <5000万 |
| 趋势风险 | 25分 | +10%↑ | +5%↑ | 平盘 | -5%↓ |
| 仓位风险 | 25分 | <50% | <65% | <80% | ≥90% |
| 相关性风险 | 25分 | <30% | <45% | <60% | ≥60% |

**综合评级：**
- 135-150分：🟢 低风险
- 100-134分：🟡 中低风险
- 75-99分：🟠 中风险
- 50-74分：🔴 中高风险
- <50分：⚫ 高风险

## 持仓结构分析

输出内容：
- **行业分布图**：各行业持仓占比（含条形图）
- **市值风格分布**：大盘/中盘/小盘比例
- **集中度指标**：单只最大仓位、前三仓位、HHI指数
- **行业重叠警示**：检测相关行业集中风险

## 调仓建议规则

| 条件 | 操作 | 优先级 |
|------|------|--------|
| 浮亏 ≤ -10% | 🔴 止损 | 最高 |
| 浮亏 ≤ -5% | ⚠️ 关注止损 | 高 |
| 浮盈 ≥ 40% | ⚠️ 分批止盈 | 高 |
| 浮盈 ≥ 25% | ✅ 持有等更高 | 中 |
| 浮亏+技术反弹 | 🟢 逢低加仓 | 中 |
| 趋势向上+浮盈 | 🟢 加仓机会 | 中 |
| 其他 | ✅ 继续持有 | 低 |

## 数据源管理

### 支持的数据源

| 数据源 | 类型 | 状态 | 说明 |
|--------|------|------|------|
| 腾讯财经 | tencent | ✅ 内置已启用 | A股主要数据源 |
| 新浪财经 | sina | ⚠️ 内置备用 | 港股支持 |
| 聚宽 JoinQuant | joinquant | ➕ 可添加 | 需要注册 |
| TuShare Pro | tushare | ➕ 可添加 | 免费token |
| 自定义REST API | custom_rest | ➕ 可添加 | 接入任意API |

### 添加数据源命令

```bash
# 添加聚宽
python3 scripts/source_manager.py --add joinquant --name "我的聚宽" username=手机 password=密码

# 添加TuShare
python3 scripts/source_manager.py --add tushare --name "我的TuShare" token=你的token

# 添加自定义API
python3 scripts/source_manager.py --add custom_rest --name "我的接口" \
  url="https://api.com/price?codes={codes}"
```

### 管理操作

```bash
clawhub list                          # 列出所有数据源
python3 scripts/source_manager.py --test <id>   # 测试连通性
python3 scripts/source_manager.py --enable <id>  # 启用数据源
python3 scripts/source_manager.py --disable <id>  # 禁用数据源
python3 scripts/source_manager.py --remove <id>   # 删除数据源
```

## 使用限制

- **A股专用**：不支持港股、美股
- **数据延迟**：腾讯财经约3-5秒延迟，盘中数据仅供参考
- **截图识别**：需图片清晰、信息完整，准确率>95%
- **投资风险**：本报告仅供参考，不构成投资建议
