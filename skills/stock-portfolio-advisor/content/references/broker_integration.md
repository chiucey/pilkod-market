# 券商数据对接方案

## 方案一：截图解析（✅ 推荐，已实现）

### 原理
通过 AI 视觉识别（多模态大模型）直接读取券商App截图中的持仓数据。

### 支持的券商
- ✅ 国泰海通证券（国泰君安合并）
- ✅ 东方财富
- ✅ 同花顺
- ✅ 中信建投
- ✅ 华泰证券（涨乐财富通）
- ✅ 中信证券
- ✅ 广发证券
- ✅ 招商证券
- ✅ 其他任意券商App截图

### 使用方式
```
用户发送持仓截图 → AI识别持仓 → 生成持仓JSON → 调用持仓顾问分析
```

### 识别准确率
- 清晰截图（无遮挡、信息完整）：>95%
- 模糊截图：>80%
- 关键字段（名称/代码/持股数/成本）：都能识别

### 截图要求
- 需包含持仓列表区域（名称+代码+持股数+成本）
- 支持横屏/竖屏截图
- 支持JPG/PNG格式
- 建议分辨率为720p以上

## 推荐方案：截图 + akshare 混合

| 数据 | 来源 | 频率 |
|------|------|------|
| 持仓信息（名称/股数/成本）| 用户截图解析 | 手动 |
| 实时股价 | akshare / 腾讯财经API | 自动 |
| 财务数据 | akshare | 自动 |
| 持仓盈亏 | 计算得出 | 自动 |

**优势：**
- 无需券商API权限
- 不受API限制影响
- 数据完全准确（用户截图就是真实账户数据）
- 支持所有券商
