# 六维风险评估模型

## 模型概览

| 维度 | 权重 | 优秀(25) | 良好(20) | 一般(15) | 较差(8) | 差(3) |
|------|------|---------|---------|---------|--------|------|
| 集中度风险 | 25分 | <20% | <30% | <40% | <50% | ≥50% |
| 波动性风险 | 25分 | <2% | <4% | <6% | <8% | ≥8% |
| 流动性风险 | 25分 | >2亿股 | >1亿股 | >5000万 | <5000万 | 极差 |
| 趋势风险 | 25分 | +10%↑ | +5%↑ | 平盘 | -5%↓ | <-5%↓ |
| 仓位风险 | 25分 | <50% | <65% | <80% | <90% | ≥90% |
| 相关性风险 | 25分 | <30% | <45% | <60% | <75% | ≥75% |

## 各维度详解

### 1. 集中度风险（满分25分）
衡量单只股票占持仓比例。
- 单只超过40%：集中度过高，一只股票出问题影响巨大
- 理想状态：单只不超过20%，前三大不超过50%

### 2. 波动性风险（满分25分）
用持仓股票平均振幅衡量。
- 振幅 = (最高价 - 最低价) / 昨收 × 100%
- 振幅大说明日内波动剧烈，止损风险高

### 3. 流动性风险（满分25分）
用总成交量衡量（万股）。
- 成交活跃：便于快速买卖，冲击成本低
- 成交稀少的股票：大额买卖时价格冲击大

### 4. 趋势风险（满分25分）
用持仓整体浮盈/浮亏方向衡量。
- 浮盈方向：赚钱效应强，趋势交易者入场信号
- 浮亏方向：需要分析是市场整体下跌还是个股问题

### 5. 仓位风险（满分25分）
用持仓市值占总资产比例衡量。
- <50%：轻仓，保留子弹，回调时有加仓能力
- 70-80%：中高仓，攻防兼备
- >85%：重仓，大盘回调时压力巨大

### 6. 相关性风险（满分25分）
用最大行业占比衡量。
- 单一行业超过50%：行业系统性风险高
- 理想：单一行业不超过30%，分散配置

## 综合评分标准

| 总分 | 评级 | 说明 |
|------|------|------|
| 125-150 | 🟢 低风险 | 分散配置，攻防兼备 |
| 100-124 | 🟡 中低风险 | 基本健康，略有隐患 |
| 75-99 | 🟠 中风险 | 需要关注，部分调整 |
| 50-74 | 🔴 中高风险 | 风险较大，建议减仓 |
| 0-49 | ⚫ 高风险 | 清仓或大幅减仓 |

## 仓位健康度评分规则

```
基准分：75分

仓位问题：
- 仓位 > 80%：-20分
- 仓位 > 70%：-10分
- 仓位 < 30%：+5分

集中度问题：
- 单只 > 40%：-15分
- 单只 > 30%：-8分

行业问题：
- 单一行业 > 50%：-10分
- 小盘股 > 30%：-8分
```

## 调仓优先级算法

```
优先级得分 = 风险得分 × (1 + 仓位权重)

1. 最高优先级（>100分）：止损卖出
   条件：浮亏 ≤ -10% 且逻辑破坏

2. 高优先级（80-100分）：分批止盈
   条件：浮盈 ≥ 30% 且估值偏贵

3. 中优先级（50-80分）：换仓优化
   条件：有更优替代标的，且当前持仓趋势走弱

4. 低优先级（<50分）：继续持有或小幅加仓
```

## HHI指数（赫芬达尔指数）

衡量持仓集中度的综合指标：

```
HHI = Σ(各股票仓位%)²
```

| HHI区间 | 含义 |
|---------|------|
| <1500 | 高度分散 |
| 1500-2500 | 适度集中 |
| >2500 | 高度集中 |
| >3500 | 极度集中，风险很高 |
