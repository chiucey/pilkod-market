## 一、涟漪情报搜索系统（重写版）

### 搜索三层架构

**第一层：精准新闻搜索（首选，30秒）**
```
并发搜索（2-4个关键词）：
- "site:cls.cn OR site:wallstreetcn.com <标的> 2026"
- "site:coindesk.com OR site:cointelegraph.com <标的> 2026"
- "site:bloomberg.com OR site:reuters.com <标的> 2026"
```

**第二层：情绪+社媒搜索（备选，20秒）**
```
并发搜索：
- "<标的> twitter sentiment 2026"
- "<标的> whale OR institutional buy OR sell 2026"
- "<标的> 做多 OR 做空 OR 预警 2026"
```

**第三层：交叉验证（验证重要发现，15秒）**
```
搜索"相反观点"验证：
- 如果信号是"做多" → 搜索"<标的> 做空 OR 风险 OR 预警"
- 如果信号是"做空" → 搜索"<标的> 反弹 OR 抄底 OR 机构买入"
```

## 二、涟漪AI情报评分系统（核心）

### 每条情报评分（0-100）

```json
{
  "标题": "...",
  "来源": "...",
  "涟漪评分": 75,
  "信号": "long | short | neutral",
  "相关市场": ["加密", "A股"],
  "涟漪置信度": "高 | 中 | 低",
  "涟漪判断": "一句话结论"
}
```

### 评分规则（精确版）

**基础分：情报来源**
- S级（交易所/监管）：+5分
- A级（CoinDesk/CoinTelegraph/财联社）：+3分
- B级（新浪/东方财富）：+1分
- C级（Twitter/社区）：0分

**信号加分（做多）：**
- 机构大额买入/ETF净流入：+20分
- 政策利好/技术创新：+15分
- 技术突破/均线多头：+10分
- KOL公开唱多：+8分
- 恐慌暴跌后大资金抄底：+15分

**信号减分（做空）：**
- 机构大额卖出/ETF净流出：-20分
- 政策利空/监管打压：-15分
- 技术破位/均线死叉：-10分
- KOL公开唱空/警告风险：-8分
- 全民讨论/全民推荐：-15分（反转信号！）

### 涟漪综合情绪指数（0-100）

**计算公式：**
```
涟漪情绪 = (做多信号评分总和 - 做空信号评分总和) / 信号总数
```

**分级：**
| 涟漪情绪 | 分数 | 颜色 | 操作 |
|---------|------|------|------|
| 极度贪婪 | 80-100 | 🥊 深红 | 减仓，保留现金 |
| 贪婪 | 60-79 | 🔴 红 | 持仓，不追高 |
| 中性偏多 | 55-59 | 🟡 黄 | 轻仓，结构机会 |
| 中性 | 45-54 | 🟡 黄 | 轻仓观望 |
| 中性偏空 | 40-44 | 🟠 橙 | 减仓，等信号 |
| 恐慌 | 20-39 | 🟢 绿 | 空仓，等恐慌买点 |
| 极度恐慌 | 0-19 | ⚫ 深绿 | 清仓，持有现金 |

## 三、情报处理流水线（标准执行）

```
收到任务
    ↓
【并行搜索】第一层精准搜索（2-4个并发）
    ↓
【提取内容】extract_content前5个URL
    ↓
【涟漪评分】逐条评分，标注信号
    ↓
【交叉验证】第三层搜索验证矛盾信号
    ↓
【整合研报】输出情报研报
    ↓
【存档成长】记录到涟漪情报库
    ↓
【下次优化】记录搜索关键词命中率
```

**执行时间：每份情报研报≤10分钟**
