# 项目文档创建技能

## 支持的文档类型

| 触发词 | 文档类型 | 输出格式 |
|--------|----------|----------|
| `#写点文档-PDA操作手册` | PDA/RF手持端操作手册 | Word文档 + 原图保留 |
| `#写点文档-WEB操作手册` | 网页端操作手册 | Word文档 + 原图保留 |
| `#写点文档-蓝图文档` | 项目蓝图文档 | Word文档 + 原图保留 |
| `#写点文档-接口文档` | 接口配置说明书 | Word文档 + 原图保留 |

## 核心能力

### 1. 附件保留与排版
当用户上传包含图片或其他附件的文档时：
- **图片处理**：
  - 保留原始图片文件，不进行压缩或失真处理
  - 图片按实际比例嵌入文档
  - 图片嵌入到对应的操作步骤说明之后
  - 多图场景：按操作流程顺序连续展示

- **附件排版规则**：
  - 单图：居中显示，保持原始宽高比
  - 多图：按操作顺序连续嵌入
  - 图片与上下文字间距至少1倍行高
  - 支持的格式：PNG、JPG、JPEG、GIF、WEBP、BMP

## 图片排版规范

### 排版规则

1. **图片嵌入方式**：
   - 使用标准Markdown图片语法：`![](media/image.png)`
   - 图片保持原始宽高比
   - 图片尺寸根据文档页面自动适配

2. **多图排版**：
   - 按操作流程顺序连续嵌入
   - 不做网格布局，保持阅读连贯性
   - 图片之间留1倍行高间距

3. **图注规范**：
   - 图片位于操作说明之后
   - 可在图片前添加简短说明文字
   - 关键操作区域在说明文字中标注

### 附件处理流程

```
用户上传文档/截图
       ↓
识别文档中的所有图片和附件
       ↓
分析附件内容（业务含义、操作步骤）
       ↓
按操作顺序整理截图
       ↓
按照文档类型选择对应模板
       ↓
将附件嵌入模板指定位置
       ↓
生成最终Word文档
```

## 工作流程

### 1. 接收用户需求
用户发送触发词（如 `#写点文档-PDA操作手册`），然后提供：
- **功能名称**：如"采购入库收货"
- **适用场景**：业务场景描述（序列号/非序列号管理等）
- **操作步骤**：每个步骤的详细说明
- **截图/附件**：每个步骤的界面截图

### 2. 分析输入内容
- 识别并提取用户提供的所有图片
- 分析图片内容，确定对应的操作步骤
- 按操作顺序排列截图
- 检查图片质量，必要时请求补充

### 3. 生成文档
- 选择对应的文档模板
- 将图片按照操作顺序嵌入文档
- 生成说明文字
- 输出标准化的Word文档

### 4. 输出格式
- 文件格式：Word文档（.docx）
- 图片保留：原始图片文件，嵌入文档
- 文件命名：`[功能名称]_[文档类型]_[日期].docx`

## 注意事项

1. **截图要求**：
   - 截图需包含完整界面（顶部栏、表单区域、操作按钮）
   - 关键按钮在说明文字中用【】或\[\]标注
   - 截图命名应清晰表达业务含义

2. **排版要求**：
   - 标题层级清晰（一级、二级、三级标题）
   - 操作步骤用表格或编号列表呈现
   - 段落间距统一

3. **文档规范**：
   - 重要信息加粗显示
   - 警告信息用特殊样式标注
   - 代码块使用等宽字体

4. **附件保留**：
   - 不压缩、不裁剪原始图片
   - 保持图片原始分辨率
   - 按操作顺序整理附件
