# 化工仪表知识库

本文件汇总压力变送器和差压变送器的核心知识点，供出题时参考。

---

## 一、压力变送器概述

### 1.1 定义与功能

**定义**：压力变送器是一种将压力信号转换为可传输的标准电信号的仪器。

**核心功能**：
- 感知压力信号
- 转换为标准信号（通常为4~20mA DC）
- 传输至二次仪表或控制系统

**主要组成**：
1. 压力传感器（核心部件）
2. 信号处理电路
3. 输出电路
4. 外壳及连接件

### 1.2 分类

| 分类方式 | 类型 | 说明 |
|---------|------|------|
| 按测量对象 | 表压变送器 | 以大气压为参考 |
| 按测量对象 | 绝对压力变送器 | 以绝对真空为参考 |
| 按测量对象 | 差压变送器 | 测量两点压力差 |
| 按测压范围 | 一般压力变送器 | 0.001~20MPa |
| 按测压范围 | 微差压变送器 | 0~1.5kPa |

## 二、压力变送器工作原理

### 2.1 电容式压力变送器

**原理**：利用两个金属电极之间的电容随压力变化而改变的原理。

**工作过程**：
1. 过程压力作用于隔离膜片
2. 经硅油灌充液传至中心膜片
3. 中心膜片产生位移
4. 位移形成差动电容变化
5. 电子线路调节、震荡、放大
6. 转换为4~20mA信号输出

### 2.2 压阻式压力变送器

**原理**：基于压阻效应，半导体材料的电阻值随压力变化。

**工作过程**：
1. 压力作用于测量体
2. 测量体产生微小弹性变形
3. 电阻网格的电阻值变化
4. 利用电桥原理转化为电压信号
5. 电压信号与压力成正比

### 2.3 压电式压力变送器

**原理**：某些晶体材料在受到压力作用时会产生电荷。

**特点**：电荷量与所受压力成正比。

## 三、差压变送器工作原理

### 3.1 基本原理

将一个空间用敏感元件（膜盒）分割成两个腔室，分别向两个腔室引入压力时：
- 传感器在两方压力共同作用下产生位移
- 位移量与两个腔室压力差成正比
- 将位移转换成标准信号输出

### 3.2 测量过程

```
正压端压力 → 隔离膜片 → 密封液 → 测量元件 → 电信号
负压端压力 → 隔离膜片 → 密封液 ↗
                                    ↓
                              转换器放大
                                    ↓
                            标准信号输出(4~20mA)
```

### 3.3 关键组件

| 组件 | 功能 |
|-----|------|
| 隔离膜片 | 直接感受压力，保护内部元件 |
| 密封液 | 传递压力信号 |
| 测量元件 | 将差压转换为电信号 |
| 转换器 | 信号放大和处理 |

## 四、零点迁移与量程调整

### 4.1 零点调整

**目的**：使变送器输出信号的下限值（4mA）与测量信号的下限值相对应。

**方法**：调整零点电位器（W2，标记Z）

### 4.2 量程调整

**目的**：使变送器输出信号的上限值（20mA）与测量范围的上限值相对应。

**方法**：改变反馈部分的反馈系数F
- F越大，量程越大
- F越小，量程越小

### 4.3 零点迁移

**定义**：将测量范围起点由零迁移到某一个数值。

**三种类型**：
| 类型 | 条件 | 测量范围示例 |
|-----|------|-------------|
| 无迁移 | 迁移量=0 | 0~40kPa |
| 正迁移 | 迁移量>0 | 20~60kPa |
| 负迁移 | 迁移量<0 | -40~0kPa |

**公式**：
```
测量范围 = 量程范围 + 迁移量
```

### 4.4 调整注意事项

1. 调整量程螺钉会影响零点
2. 调整零点螺钉会影响满度
3. 需要反复调整直至都符合要求
4. 零位校准调整范围：压力范围的±8%
5. 量程校准调整范围：压力范围的30%~100%

## 五、差压变送器应用

### 5.1 液位测量

**测量原理**：利用液体自身重力产生的压力差来测量容器内液体的液位。

**安装要求**：
- 高压侧（H）连接容器下部的取压口
- 低压侧（L）连接容器上部的取压口
- 负压侧需装入隔离水（防止蒸汽冷凝）

**计算公式**：
```
ΔP = P+ - P- = ρg(h1 - h2)

其中：
- ΔP：差压值
- P+：正压侧压力
- P-：负压侧压力
- ρ：液体密度
- g：重力加速度
- h1：工艺零点到上部取压口高度
- h2：实际液位高度
```

**液位与差压关系**：
- 液位为0时：ΔP最大
- 液位最高时：ΔP最小（可能为0或负值）

### 5.2 流量测量

**测量原理**：配合节流装置（如孔板），测量流体通过节流件时产生的差压。

**流量公式**：
```
Q = K × √ΔP

其中：
- Q：流量
- K：常数（与节流装置相关）
- ΔP：差压值
```

**重要特性**：流量与差压的平方根成正比

**常用节流装置**：
- 孔板
- 阿牛巴（笛形管）
- 文丘里管

**计算示例**：
```
已知：
- 差压变送器量程：0~40kPa
- 对应流量：0~160m³/h
- 输出电流：8mA

求：此时流量和差压

解：
1. 8mA对应的百分比 = (8-4)/(20-4) × 100% = 25%
2. 流量 = 160 × √0.25 = 80m³/h
3. 差压 = 40 × 0.25 = 10kPa
```

## 六、安装与维护

### 6.1 安装要求

| 类型 | 安装要点 |
|-----|---------|
| 表压变送器 | 避免安装在振动或冲击位置 |
| 绝对压力变送器 | 保持密封腔清洁 |
| 差压变送器 | H口在下，L口在上（测量液位时） |
| 微差压变送器 | 水平安装，位置度要求高 |

### 6.2 日常维护

| 项目 | 周期 | 内容 |
|-----|------|------|
| 零点检查 | 每月 | 检查输出是否为4mA |
| 精度校验 | 每半年 | 按检定规程校验 |
| 清洁保养 | 每季度 | 清洁外壳和连接件 |
| 防潮检查 | 每月 | 检查密封性 |

### 6.3 常见故障及处理

| 故障现象 | 可能原因 | 处理方法 |
|---------|---------|---------|
| 输出信号为零 | 电源未接通、接线断开 | 检查电源和接线 |
| 输出信号不稳 | 压力源波动、干扰 | 检查接地、屏蔽 |
| 读数偏高 | 零点飘移、迁移设置错误 | 重新调校零点 |
| 读数偏低 | 引压管堵塞、泄漏 | 检查引压管 |

## 七、化工行业应用

### 7.1 主要应用领域

| 行业 | 应用场景 |
|-----|---------|
| 石油化工 | 管道压力、储罐液位、流量测量 |
| 电力 | 锅炉压力、汽轮机监控 |
| 冶金 | 高炉压力、除尘系统 |
| 制药 | 反应釜压力、发酵罐监控 |
| 食品 | 灭菌锅压力、灌装控制 |

### 7.2 选型要点

| 考虑因素 | 选择建议 |
|---------|---------|
| 测量介质 | 腐蚀性介质选用耐腐蚀材质 |
| 工作温度 | 高温环境需耐高温变送器 |
| 防爆要求 | 易燃易爆场所用防爆型 |
| 精度要求 | 根据工艺要求选择合适精度 |
| 安装方式 | 管道直连或导压管取压 |

### 7.3 智能变送器特点

1. **数字通信**：支持HART协议
2. **远程配置**：可通过手操器远程设置
3. **自诊断**：具备故障自诊断功能
4. **温度补偿**：内置温度补偿算法
5. **历史记录**：可存储校准数据

---

## 八、安全规范

### 8.1 防爆要求

在易燃易爆场所必须使用防爆型变送器：
- 防爆标志：Ex d、Ex ia 等
- 防护等级：IP65以上

### 8.2 接地要求

1. 变送器外壳应可靠接地
2. 屏蔽线应单端接地
3. 接地电阻应小于10Ω

### 8.3 检定周期

- 强制检定：每年一次
- 期间核查：每半年一次
- 日常检查：每月一次
