# 化工仪表培训考试卷生成技能

## 技能概述

本技能用于为化工企业变换工段（含变换和硫回收岗位）的员工生成仪表相关知识的培训考试卷。生成的试卷为填空题，共30道，从易到难排序，每道题附带标准答案。

## 工作流程

### 步骤1：接收用户需求

用户需提供以下信息：
- **培训主题**：具体的仪表知识主题（如"压力变送器知识培训"、"差压变送器知识培训"等）
- **难度要求**：基础/中等/困难，或"不作要求"
- **是否有培训资料**：如有，需用户提供

### 步骤2：搜集相关知识（如无培训资料）

使用 `mcp__matrix__batch_web_search` 工具搜索相关仪表知识：

**搜索关键词建议**：
- 压力变送器：工作原理、结构组成、分类、选型、安装、调校、零点迁移、量程调整
- 差压变送器：测量原理、液位测量、流量测量、安装要求、故障处理
- 通用仪表：化工应用、维护保养、安全规范

### 步骤3：生成试卷结构

按照从易到难的顺序组织试卷：

| 题目类型 | 题号范围 | 每题分值 | 难度等级 |
|---------|---------|---------|---------|
| 基础概念题 | 1-10 | 3分 | 易 |
| 工作原理题 | 11-20 | 3分 | 中 |
| 应用计算题 | 21-27 | 4分 | 中难 |
| 综合分析题 | 28-30 | 5分 | 难 |

### 步骤4：出题原则

1. **知识相关性**：所有题目必须与化工生产或本工段岗位相关
2. **答案明确性**：填空题的答案必须唯一、无歧义
3. **难度递进性**：题目从基础概念到综合应用逐步加深
4. **内容覆盖性**：覆盖用户指定主题的核心知识点

### 步骤5：输出试卷格式

生成的试卷必须包含以下部分：
- 试卷标题（含岗位、题型、时间、总分）
- 题目正文（按编号排列）
- 标准答案（每题后附答案）
- 参考答案汇总表
- 试卷信息栏（出卷人、审核人、考试日期）

## 题型说明

### 填空题出题要点

1. **题干**：清晰描述考察点，避免歧义
2. **空格**：使用"________"表示填空位置
3. **答案**：简短、明确，通常为1-3个关键词或数值

### 题目类型示例

**基础概念题示例**：
```
压力变送器的作用是将被测 ________ 信号转换成便于传输的标准化信号输出。
答案：压力
```

**工作原理题示例**：
```
压力变送器的"零点迁移"就是把测量范围下限所对应的被测参数值由 ________ 迁移到某一个数值。
答案：零
```

**应用计算题示例**：
```
某差压变送器量程为0-40kPa，对应流量为0-160m³/h。当输出电流为8mA时，流量为 ________ m³/h。
答案：80
```

**综合分析题示例**：
```
在化工生产中，差压变送器测量液位出现误差的主要原因包括传感器老化、环境 ________ 变化以及介质特性差异等。
答案：温度
```

## 质量检查清单

出题完成后，自查以下内容：
- [ ] 题目数量为30道
- [ ] 所有题目都有标准答案
- [ ] 答案无歧义、无争议
- [ ] 题目从易到难排序
- [ ] 内容与化工/仪表相关
- [ ] 无错别字、无语法错误
- [ ] 知识点覆盖用户指定主题

化工仪表培训考试卷_[主题]_[年月].md
