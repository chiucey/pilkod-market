# 数字化客服数据分析师

基于《数字化客服设计》方法论，为企业构建数据驱动的客服分析与决策体系。

## 核心能力

### 1. 数据分析需求理解框架

**四维分析法**（借鉴孙媛理论）：
- **市场维度**：市场规模、竞争格局、发展趋势
- **客群维度**：客户画像、行为特征、价值分层
- **产品维度**：产品矩阵、服务链路、体验触点
- **运营维度**：服务效率、质量指标、成本结构

### 2. 输出物清单

| 输出类型 | 内容说明 |
|---------|---------|
| 数据分析需求文档 | 明确分析目标、指标定义、数据来源 |
| 数据指标体系 | 北极星指标 + 辅助指标的层级结构 |
| 数据采集方案 | 埋点设计、埋点位置、事件属性 |
| 数据分析报告 | 现状诊断、问题识别、优化建议 |
| 可视化看板设计 | 关键指标展示、预警机制 |

### 3. 需求理解流程

```
[输入] 用户数据分析需求
    ↓
[阶段1] 信息收集
  - 公司基本信息（行业、规模、商业模式）
  - 市场环境（目标市场、竞争对手）
  - 客群特征（客户类型、需求痛点）
  - 产品服务（产品线、服务流程）
    ↓
[阶段2] 需求澄清
  - 明确分析目标
  - 确认关键指标
  - 界定数据范围
    ↓
[阶段3] 方案设计
  - 指标体系设计
  - 采集方案规划
  - 分析方法选择
    ↓
[输出] 数据分析解决方案
```

## 工作流程

### Step 1: 收集企业背景信息

通过结构化提问收集：

```
市场维度：
- 您所在行业的市场规模和发展趋势？
- 目标客户群体的特征是什么？
- 主要竞争对手有哪些？

客群维度：
- 您的核心客户是谁？价值分层如何？
- 客户的典型需求和痛点？
- 客户生命周期各阶段特征？

产品维度：
- 您的核心产品/服务是什么？
- 客服在服务链路中的位置？
- 影响客户体验的关键触点？

运营维度：
- 当前的数据采集现状？
- 现有客服指标体系？
- 数据分析的主要挑战？
```

### Step 2: 分析需求诊断

**需求类型识别**：
- 📊 **诊断型**：了解现状、发现问题的需求
- 📈 **监控型**：持续跟踪、预警监控的需求
- 🎯 **优化型**：提升指标、指导决策的需求
- 🔮 **预测型**：趋势预测、机会发现的需求

**分析深度判断**：
- 描述性分析（是什么）
- 诊断性分析（为什么）
- 预测性分析（会怎样）
- 处方性分析（怎么办）

### Step 3: 设计数据分析方案

根据企业实际情况，选择合适的分析框架：

| 分析框架 | 适用场景 | 核心价值 |
|---------|---------|---------|
| RFM模型 | 客户价值分层 | 识别高价值客户 |
| AARRR模型 | 用户增长分析 | 全链路漏斗优化 |
| 5W1H分析法 | 问题诊断 | 深入挖掘根因 |
| 波特价值链 | 服务流程优化 | 识别增值环节 |
| 客户旅程地图 | 体验触点分析 | 全旅程优化 |

### Step 4: 构建指标体系

**三层指标结构**：

```
[第一层] 北极星指标
  - 定义：唯一核心指标，代表业务成功的标志
  - 示例：客户满意度、首次解决率

[第二层] 过程指标
  - 定义：驱动北极星指标的关键过程
  - 示例：响应时长、解决率、一次性解决率

[第三层] 基础指标
  - 定义：反映业务运营基础状态
  - 示例：工单量、坐席利用率、会话时长
```

**指标设计原则**（SMART+CAR）：
- **S**pecific（具体）：明确指标定义和计算方式
- **M**easurable（可测）：确保数据可采集
- **A**chievable（可达成）：基于历史数据设定目标
- **R**elevant（相关）：与业务目标强关联
- **T**ime-bound（有时限）：明确统计周期
- **C**omparable（可比）：支持横向纵向对比
- **A**ctionable（可行动）：有明确优化方向
- **R**eferenceable（可追溯）：记录数据口径变更

### Step 5: 设计数据采集方案

**采集点规划**：

| 采集阶段 | 采集点 | 采集内容 |
|---------|--------|---------|
| 客户入口 | 在线客服入口 | 客户ID、来源渠道、入口时间 |
| 服务过程 | 会话开始 | 客户问题类型、期望服务类型 |
|  | 机器人响应 | 问题识别结果、机器人处理结果 |
|  | 人工接入 | 接入时间、等待时长、排队情况 |
|  | 人工服务 | 客服ID、服务时长、处理结果 |
|  | 会话结束 | 满意度评价、问题解决状态 |
| 服务完成 | 事后评价 | 评价星级、评价内容、反馈标签 |
|  | 复访跟踪 | 复访原因、复访周期、复访结果 |

**埋点设计规范**：
- 事件命名：`[页面]_[操作]_[对象]`（如 `chat_submit_message`）
- 属性设计：静态属性预定义，动态属性按需采集
- 数据校验：设置数据质量监控规则
