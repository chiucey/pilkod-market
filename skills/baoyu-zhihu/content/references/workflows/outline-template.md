# 知乎大纲模板

```yaml
---
strategy: structured

---

## 封面（Image 1）
- 类型：封面
- 内容：核心结论 / 争议性观点
- 视觉：Professional 深色风格，冲击力强

## 背景铺垫（Image 2）
- 类型：数据/背景
- 内容：行业数据或现状
- 布局：Data-viz 风格

## 核心论点（Image 3）
- 类型：论点展开
- 内容：3个核心观点，每个配图或数据
- 布局：structured 或 comparison

## 个人见解（Image 4）
- 类型：观点表达
- 内容：独特视角 + 行动建议
- 布局：editorial 风格
```

## 知乎结构公式

1. **Hook**：一句话颠覆认知或激发共鸣
2. **TL;DR**：先给结论（节省读者时间）
3. **论据**：数据/案例/逻辑
4. **独特见解**：你的判断和理由
5. **CTA**：评论区讨论引导
