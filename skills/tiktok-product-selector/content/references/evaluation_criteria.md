# 10维选品模型 - 详细评分标准

## 各维度评分细则与典型案例

---

## 维度1：市场需求程度

### 评分细则

| 评分 | 等级 | 搜索趋势 | 痛点紧迫性 | 市场特征 |
|------|------|----------|------------|----------|
| 9-10 | 极强需求 | 持续上升趋势 | 强刚需，无法推迟 | 庞大用户基础 |
| 7-8 | 稳定需求 | 平稳波动 | 明确需求 | 清晰目标群体 |
| 5-6 | 一般需求 | 偶有波动 | 中等紧迫 | 需要推广 |
| 3-4 | 弱需求 | 趋势不明 | 可替代性强 | 小众市场 |
| 1-2 | 伪需求 | 下降趋势 | 伪痛点 | 极小众或概念性产品 |

### 典型案例参考

**高分案例（9-10分）：**
- 疫情期间的居家健身器材（弹力带、哑铃凳）
- 宠物用品（自动喂食器、宠物玩具）
- 厨房小工具（开罐器、切菜器）

**低分案例（1-3分）：**
- 过于垂直的小众收藏品
- 功能复杂需高度教育的产品
- 已过风口的潮流单品

## 维度2：竞争激烈程度

### 评分细则

| 评分 | CR5占比 | 头部竞品数量 | 市场特征 |
|------|---------|--------------|----------|
| 9-10 | <20% | 无绝对头部 | 市场分散 |
| 7-8 | 20-40% | 1-2个头部 | 存在机会 |
| 5-6 | 40-60% | 3-5个头部 | 红海边缘 |
| 3-4 | 60-80% | 多个头部 | 红海竞争 |
| 1-2 | >80% | 1-2家垄断 | 几乎无机会 |

### 风险警示指标

⚠️ **高风险信号：**
- 头部竞品评价数>10,000
- 头部链接已有>100个相似SKU
- 价格战已白热化（利润<20%）

## 维度3：利润率空间

### 成本结构标准

**标准TikTok Shop成本结构：**
```
产品成本: 25-35%
头程物流: 10-15%
平台抽成: 8-15%
尾程配送: 10-20%
广告投流: 15-25%
其他费用: 5-10%
─────────────────
总成本占比: 73-130%
```

### 评分标准

| 评分 | 毛利率 | 可投流性 | ROI潜力 |
|------|--------|----------|---------|
| 9-10 | >65% | 高强度投流 | ROI>4:1 |
| 7-8 | 50-65% | 可支撑投流 | ROI 3-4:1 |
| 5-6 | 35-50% | 有限投流 | ROI 2-3:1 |
| 3-4 | 20-35% | 谨慎投流 | ROI 1-2:1 |
| 1-2 | <20% | 难以投流 | ROI<1:1 |

### 计算公式

```
毛利率 = (售价 - 产品成本 - 头程) / 售价 × 100%
净利润 = 毛利率 - 平台抽成 - 尾程 - 广告 - 其他
建议毛利率警戒线: >40%
```

## 维度4：物流可行性

### 产品分类评估

| 产品类型 | 评分 | 说明 |
|----------|------|------|
| 普货（普通塑料/金属/纺织品） | 9-10 | 无特殊要求 |
| 带电池产品（内置电池<100Wh） | 7-8 | 需专业包装 |
| 液体/膏体（<100ml） | 6-7 | 特殊包装防漏 |
| 液体（>100ml） | 4-5 | 限制较多 |
| 粉末/颗粒 | 3-4 | 清关风险 |
| 敏感货（带磁、化妆品） | 2-3 | 高成本高风险 |
| 危险品 | 1 | 禁止或限制 |

### 物流成本评估标准

**体积重计算：**
```
实际重量 vs 体积重（长×宽×高/5000）
取较大值计费
```

**理想状态：**
- 体积重<500g
- 不规则形状少
- 破损率<0.5%

## 维度5：内容呈现潜力

### 内容类型评分

| 内容类型 | 评分 | 典型产品 |
|----------|------|----------|
| 高感官冲击（美容仪、开箱、ASMR） | 9-10 | 美容仪器、3C配件 |
| 功能演示型（前后对比、使用展示） | 8-9 | 减肥产品、清洁工具 |
| 情景剧型（生活场景植入） | 7-8 | 家居用品、厨房工具 |
| 知识科普型 | 6-7 | 健康产品、数码产品 |
| 平铺直叙型（简单展示） | 4-5 | 基础日用品 |
| 内容枯燥型 | 1-3 | 工业配件、办公用品 |

### UGC潜力评估

**高UGC潜力特征：**
- 产品可引发"挑战"（如呼啦圈挑战）
- 可进行前后对比
- 有"惊喜"或"反常识"元素
- 适合"开箱"体验

## 维度6：消费者心智认可

### 决策周期分类

| 品类 | 决策周期 | 教育成本 | 典型品类 |
|------|----------|----------|----------|
| 冲动消费品 | <1分钟 | 极低 | 9.9美元以下小商品 |
| 快速决策品 | 1-10分钟 | 低 | 时尚饰品、节日礼品 |
| 考虑型产品 | 10-60分钟 | 中 | 电子产品、家用电器 |
| 重决策产品 | >1小时 | 高 | 家具、珠宝 |
| 超重决策 | >1天 | 极高 | 汽车、房产 |

### 冲动消费特征

✓ 价格锚点清晰（限时折扣感）
✓ 视觉效果强烈
✓ 使用场景明确
✓ 社交证明充足（评价、销量）
✓ 限量/稀缺感

## 维度7：季节性影响

### 季节性分类

| 类型 | 评分 | 特征 | 风险 |
|------|------|------|------|
| 全年稳定品 | 9-10 | 无明显淡旺季 | 低库存风险 |
| 轻微季节性 | 7-8 | 可预测波动 | 精准备货可控 |
| 中度季节性 | 5-6 | 明显淡旺季 | 需提前备货 |
| 强季节性 | 3-4 | 高度依赖节日/天气 | 高库存风险 |
| 极端季节性 | 1-2 | 仅特定时期需求 | 极高库存风险 |

### 典型季节性产品

**强季节性（需谨慎）：**
- 圣诞装饰品（Q4集中）
- 泳装/防晒（夏季）
- 开学季文具（8-9月）
- 万圣节用品

**全年稳定品（优先）：**
- 家居收纳
- 厨房小工具
- 健身配件
- 美妆工具

## 维度10：供应链稳定性

### 供应链风险评估

| 因素 | 高分标准（9-10） | 低分标准（1-3） |
|------|------------------|-----------------|
| 生产门槛 | 无特殊资质 | 需要认证/专利 |
| 备货周期 | <15天 | >45天 |
| MOQ | <100件 | >1000件 |
| 原料波动 | 稳定 | 大宗商品相关 |
| 工厂配合 | 灵活可定制 | 大厂不接小单 |

### 供应链稳定性警示

⚠️ **高风险信号：**
- 原材料依赖进口（如铜、芯片）
- 专利保护产品
- 工厂位于不稳定地区
- 季节性原料（如农产品）

✓ **低风险信号：**
- 国内成熟产业带
- 标准化产品
- 多工厂可替代
- 现货/半现货

## 综合评分计算

### 加权系数（可根据市场调整）

| 维度 | 权重 | 说明 |
|------|------|------|
| 市场需求程度 | 20% | 核心是有人要买 |
| 利润率空间 | 15% | 商业可持续 |
| 竞争激烈程度 | 15% | 市场是否有机会 |
| 物流可行性 | 10% | 执行可行性 |
| 内容呈现潜力 | 10% | TikTok核心能力 |
| 消费者心智认可 | 10% | 转化效率 |
| 季节性影响 | 5% | 库存风险 |
| 差异化空间 | 5% | 护城河 |
| 复购与延伸性 | 5% | LTV价值 |
| 供应链稳定性 | 5% | 长期稳定性 |

### 最终等级判定

```
S级（立刻做）：
- 综合加权分≥80分
- 且无单维度<5分
- 且最多1个维度<6分

A级（观察）：
- 综合加权分60-79分
- 或有2-3个维度<6分
- 需要进一步验证

B级（放弃）：
- 综合加权分<60分
- 或超过3个维度<6分
- 或有维度<4分
```

## 快速决策检查表

### 一票否决项（出现即B级）

- [ ] 毛利率<25%
- [ ] 物流破损率>3%
- [ ] 需要特殊进口许可
- [ ] 竞品已形成垄断（CR5>80%）
- [ ] 极端季节性产品错过旺季

### 加分项（总分外额外加分）

- +5分：天然TikTok爆款属性
- +3分：专利保护或独家供应
- +3分：强复购+配件延伸
- +2分：低竞争+高需求组合

### 减分项

- -5分：需要复杂认证（FDA等）
- -3分：高退货率品类
- -3分：平台政策风险
- -2分：季节性+库存压力大
