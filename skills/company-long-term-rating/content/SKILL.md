# 上市公司长期价值评级系统

## 核心目标

筛选可放心持有10年以上的公司，避免本金永久性损失。

## 使用原则

**先逐项分析事实，再评分，最后加权综合。不要用印象打分，每项评分必须与锚定描述对照。**

---

## 评级维度与权重

| 维度 | 权重 | 说明 |
|------|------|------|
| 业务本质 | 5% | 基础起点，但非决定性 |
| 商业模式 | 15% | 天生好模式是长期复利的基础 |
| 财务与估值 | 15% | 安全边际的直接来源 |
| 企业基因与文化 | 10% | 长期竞争力内核 |
| 管理团队 | 15% | 资本配置者，护城河建造者 |
| 成长潜力 | 10% | 放大最终回报 |
| 宏观与行业环境 | 10% | 是否顺风 |
| 护城河 | 20% | 最核心的持久竞争优势 |
| 致命风险 | 合格/不合格 | 一票否决，不计入加权总分 |

---

## 一、业务本质（权重5%）

**核心问题**：生意是否简单、可感知？业务聚焦度如何？

### 必须收集的事实
- 能否用一句话讲清公司为谁解决什么问题
- 主要产品/服务数量及其营收占比
- B2C：消费者能否直接买到、直观评价好坏
- B2B：客户转换成本、产品对客户业务的关键程度、终端消费者是否能间接感知
- 产品/服务是否具备"硬通货"属性（无论经济好坏都有持续需求）

### 评分标准（5分制）

| 分数 | 描述 |
|------|------|
| **5分** | 一句话即懂，主营≤2个高度关联业务，C端可直观感受且产品有硬通货属性；或B端属于客户核心命脉、转换成本极高且终端能间接验证 |
| **4分** | 满足大部分，但某一个点稍弱（如产品非常聚焦但不是硬通货） |
| **3分** | 业务简单但无法直观感知，或业务3个且关联性一般 |
| **2分** | 需要较多专业知识才能理解其产品，或业务超过3个且缺乏协同证据 |
| **1分** | 业务复杂、多变、无关联，普通投资者完全无法感知其价值 |

---

## 二、商业模式（权重15%）

**核心问题**：公司靠什么环节赚钱，这种模式是否天生优越、能长久持续？

### 必须回答的问题
- 收入从谁那里来、回款周期多长、是否预收
- 成本结构固定/变动比例，规模效应是否明显
- 客户生命周期价值(LTV)与获客成本(CAC)之比
- 需要持续高强度营销或资本投入才能维持，还是可以"等客上门"
- 商业模式可持续的关键假设是什么，若假设逆转会怎样

### 评分标准

| 分数 | 描述 |
|------|------|
| **5分** | 预收款或高复购、轻资产、高客户粘性、规模效应极强，关键假设极难逆转 |
| **4分** | 具备上述多数特征，但有一项中等风险点 |
| **3分** | 商业模式一般，无显著优势也无致命弱点 |
| **2分** | 依赖高杠杆、高资本投入、低客户锁定率中的两项以上 |
| **1分** | 模式有根本缺陷，如持续烧钱且无改善路径、必须不断融资才能存活 |

---

## 三、财务全景与估值（权重15%）

**核心问题**：历史财务是否健康？当前价格是否合理？

### 近3年趋势分析（逐项比较变化方向）
- **盈利能力**：ROE、销售净利率、毛利率
- **成长能力**：营业收入增长率、净利润增长率
- **营运与现金**：总资产周转率、经营现金流、自由现金流
- **偿债能力**：流动比率、资产负债率

### 深度检验项目
- **ROE三因子拆解**：高ROE来自利润率/周转率/杠杆率？若杠杆主导则扣分
- **自由现金流/净利润比值**：连续三年<1需详查资本支出的合理性
- **经营现金流与净利润对比**：持续背离标记为红色信号
- **当前估值（TTM）及合理性判断**：市盈率、市净率、企业价值/自由现金流、PEG
- 要求结论："当前估值透支了大约______年的增长预期"
- 与历史估值中枢、行业可比公司对比

### 评分标准

| 分数 | 描述 |
|------|------|
| **5分** | 财务极其稳健（高现金流、低负债、持续高ROE由经营优势驱动），且估值显著低于内在价值，为多年增长留有极大安全边际 |
| **4分** | 财务健康，估值合理或略低 |
| **3分** | 财务指标平庸但无重大风险，估值合理 |
| **2分** | 多项指标承压，或估值明显透支3年以上增长 |
| **1分** | 高负债、现金流差、估值严重泡沫化 |

---

## 四、企业基因与文化（权重10%）

**核心问题**：使命愿景价值观是刻在骨子里的，还是贴在墙上的？

### 必须回答的问题
- 公司是做什么起家的？关键基因是什么
- 使命、愿景、价值观的表述及实践证据
- **压力测试案例**：找到一次重大危机事件，详述其文化如何影响了决策和结果。若找不到任何真实案例，该维度不得给高分
- 使命愿景价值观是否在未来仍能助其避免毁灭性错误

### 评分标准

| 分数 | 描述 |
|------|------|
| **5分** | 有清晰、独特的文化，且经多次危机考验，文化直接导向正确决策并转危为安 |
| **3分** | 有文化口号，日常执行过得去，但缺乏极端情况下的验证 |
| **1分** | 文化空泛，管理层言行不一，历史危机中表现出短视和损害长期利益的行为 |

---

## 五、管理团队（权重15%）

**核心问题**：管理层是否值得托付？是否天生为长期股东服务？

### 硬事实检查清单（用事实代替形容词）
- 过去5-10年资本配置记录：收购、回购、分红决策是否优于行业平均？
- CEO及核心团队薪酬是否与滚动5年平均ROIC等长期指标挂钩，而非短期利润或股价
- 对比3-5年前年报中的战略承诺与现实结果，承诺是否持续兑现
- 核心团队是内部培养选拔为主，还是频繁空降？独立运作能力如何
- 持股情况与股东利益一致性

### 评分标准

| 分数 | 描述 |
|------|------|
| **5分** | 资本配置出色，薪酬与长期价值创造一致，言行高度一致，核心团队稳定且内部人才梯队深厚 |
| **3分** | 无明显劣迹，但也不够卓越，薪酬结构偏短期，或部分承诺未完全达成 |
| **1分** | 有损害股东记录，薪酬与股价短周期绑定，频繁变换关键人员，承诺经常落空 |

---

## 六、成长潜力（权重10%）

**核心问题**：十年后体量能有多大？增长靠什么驱动？

### 量化估算要求
- 估算行业十年后总规模(TAM)，给出公司的合理市占率上限
- 计算：十年后推测收入/利润相较于现在的倍数（2倍/5倍/10倍/100倍）
- 增长拆分：多少来自行业扩容、多少来自提价、多少来自份额提升

### 评分标准

| 分数 | 描述 |
|------|------|
| **5分** | 有极高确定性实现5倍以上增长，且主要动力来自提价或行业扩容，市占率远未触及天花板 |
| **3分** | 增长确定性一般，或主要依赖份额争夺 |
| **1分** | 市场饱和，十年后规模大概率停滞或萎缩 |

---

## 七、宏观与行业环境（权重10%）

**核心问题**：大环境和竞争格局是在帮公司，还是在害公司？

### 分析规则

每个PESTEL因素和五力维度（含第六力互补品），给出趋势符号：

- ↗（增强优势/有利）
- ↘（减弱/增加威胁）
- →（稳定）

并附一句话关键驱动力。

若公司业务多元，对占营收超10%的业务分别进行，但只详细展开三个最具不确定性的因素，其余仅记趋势。

**互补品(第六力)必做**：如果某个互补品突然极便宜或极普及，会怎样重塑行业权力结构？

### 汇总产出

总净势头判断：统计所有↗与↘，得出：
- 环境总体更有利
- 中性
- 更不利

### 评分标准

| 分数 | 描述 |
|------|------|
| **5分** | 大部分趋势有利，且公司在关键维度上处于强势位置，环境改善明显快于恶化 |
| **3分** | 趋势多空交织，公司地位中等 |
| **1分** | 多个核心趋势严重不利，行业竞争结构恶化，公司处于被动弱势地位 |

---

## 八、护城河与长期确定性（权重20%）

**核心问题**：为什么竞争对手打不垮它？十年二十年后模样能否清晰预见？

### 必须完成的任务
1. **标注护城河类型**：
   - 无形资产
   - 转换成本
   - 网络效应
   - 成本优势
   - 有效规模

2. **反证**：竞争对手究竟卡在哪里？（打不起价格战？买不到许可？撬不动用户习惯？）必须是具体的、不可复制的障碍

3. **趋势判断**：结合第七部分，护城河是在加固 ↗ 还是 减弱 ↘？说明关键依据

4. **回答**：10年、20年后公司是否依然在解决同一个根本需求，且解决方式仍比对手强很多

### 评分标准

| 分数 | 描述 |
|------|------|
| **5分** | 护城河极宽，反证清晰，可高度确定预见20年后的行业地位且大概率更强，趋势加固 |
| **3分** | 有阶段性优势，但窗口期可能在5-10年内收窄 |
| **1分** | 几乎无壁垒，仅靠运气或行业顺风，难以预见十年后位置 |

---

## 九、致命风险与极端压力测试

**核心问题**：什么能真正杀死这家公司？我们能否安然度过？

### 四类毁灭风险清单（逐项填写）

| 风险类型 | 分析要点 |
|----------|----------|
| **1. 需求消失** | 被颠覆性技术、产品永久替代 |
| **2. 致命债务或流动性断裂** | 最坏情况下的现金流与资产负债表推演 |
| **3. 关键人物/牌照/供应链单点崩溃** | 依赖关系的脆弱性评估 |
| **4. 无法对冲的宏观或法律冲击** | 如资产被没收、核心技术被禁止出口 |

### 管理层应对评估
- 公司在年报或公开言论中是否坦诚讨论此类风险？有无具体预案？

### 一票否决规则

**若任何一项可能导致本金永久性损失且公司无有效对冲，则无论其他维度分数多高，该标的直接评为"不可投资"。**

## 综合评分计算

### 加权总分公式

```
总分 = Σ(各维度评分 × 权重)
```

满分5分。

### 评级与行动映射

| 综合得分 | 评级 | 含义与操作建议 |
|----------|------|----------------|
| ≥4.5 | **A级（卓越）** | 可重仓长期持有，罕见的机会 |
| 3.8 – 4.5 | **B级（优秀）** | 可纳入核心持仓，持续跟踪 |
| 2.5 – 3.8 | **C级（一般）** | 只有当价格极度低估时才考虑，或仅观察 |
| <2.5 | **D级（回避）** | 无论价格多低都不参与 |
| 致命风险触发 | **淘汰** | 直接排除 |

## 执行工作流

1. **收集事实**：按维度逐一收集事实数据，不要先入为主
2. **逐项评分**：每个维度对照锚定描述打分，引用事实依据
3. **致命风险检查**：独立进行，任何不合格直接淘汰
4. **加权计算**：汇总总分
5. **给出结论**：明确评级和投资建议
