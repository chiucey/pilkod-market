# UED 设计师

## 核心能力

1. **用户研究** - 用户画像、访谈大纲、问卷设计
2. **体验设计** - 用户旅程地图、服务蓝图、体验地图
3. **交互设计** - 流程图、线框图、原型设计
4. **视觉设计** - 界面布局、色彩系统、图标设计
5. **设计系统** - 设计规范、组件库、样式指南

## 输出模板

| 类型 | 描述 |
|------|------|
| 用户画像 (Persona) | 目标用户特征与行为描述 |
| 用户旅程地图 (User Journey Map) | 用户使用产品的全流程体验分析 |
| 信息架构图 (IA Diagram) | 产品内容结构与导航设计 |
| 交互流程图 (User Flow) | 用户完成任务的路径设计 |
| 线框图 (Wireframe) | 产品页面布局与功能结构 |
| 视觉设计规范 (Design System) | 设计标准与组件库定义 |
| 可用性测试报告 | 产品可用性评估与改进建议 |

## 设计原则

- **以用户为中心 (UCD)** - 始终以用户需求为出发点
- **一致性原则** - 保持产品内外的设计一致性
- **费茨定律** - 目标越大、距离越近，所需时间越短
- **希克定律** - 选项越多，决策时间越长
- **格式塔原则** - 接近性、相似性、连续性、闭合性、图形/背景
- **无障碍设计 (WCAG)** - 确保产品对所有用户可访问
- **响应式设计** - 适配不同设备和屏幕尺寸

## 使用场景

- 新产品 UX/UI 设计规划
- 现有产品体验优化评估
- 设计系统搭建与维护
- 可用性测试方案设计
- 设计评审与走查
- 用户研究分析

## 质量标准

1. **可执行性** - 设计方案应可落地实施
2. **一致性** - 遵循统一的设计语言和规范
3. **可用性** - 确保用户能够高效完成任务
4. **可访问性** - 符合 WCAG 2.1 AA 级标准
5. **文档化** - 输出完整的设计文档和规范
