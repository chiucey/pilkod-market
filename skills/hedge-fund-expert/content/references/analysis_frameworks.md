# 四维专业分析框架

## 1. 估值分析师

| 公司类型 | 主要方法 | 辅助方法 |
|----------|----------|----------|
| 成熟盈利型 | DCF、P/E | EV/EBITDA |
| 高成长型 | 收入倍数、DCF | P/S、PEG |
| 金融机构 | P/B、DDM | P/E |
| 周期型 | 正常化P/E | EV/EBITDA |

**DCF公式**：
- FCFF = EBIT × (1 - 税率) + 折旧 - 资本支出 - 净营运资本变化
- WACC = 股权比重 × 股权成本 + 债务比重 × 债务成本 × (1 - 税率)
- 内在价值 = Σ FCFFt / (1 + WACC)^t + 终值 / (1 + WACC)^n

**输出**：估值方法选择、DCF每股价值、相对估值结论、综合估值与安全边际、信号

## 2. 情绪分析师

**分析维度**：
- 新闻情绪评分（-5 到 +5）
- 社交媒体情绪比率
- 机构持仓、分析师共识评级
- 内部人交易
- 情绪周期定位：极度恐惧→极度贪婪

**输出**：新闻情绪(X/10)、社交情绪比率、机构共识、极端情绪警示、情绪综合评分(X/100)

## 3. 基本面分析师

**盈利能力指标**：
- 毛利率 = (营收 - 成本) / 营收
- 营业利润率 = 营业利润 / 营收
- 净利率 = 净利润 / 营收
- ROE = 净利润 / 股东权益
- ROIC = EBIT(1-税率) / (股权 + 债务 - 现金)

**杜邦分析**：ROE = 净利率 × 资产周转率 × 权益乘数

**成长性**：1年/3年/5年CAGR

**财务健康**：
- 流动比率 > 1.5
- 债务/权益 < 1.0
- 利息覆盖倍数 > 3

**现金流质量**：
- 经营现金流 / 净利润 > 1
- 自由现金流为正

**输出**：盈利能力(X/100)、成长性(X/100)、财务健康(X/100)、现金流(X/100)、综合评分

## 4. 技术分析师

**趋势分析**：
- 多时间框架（月/周/日）
- 均线系统：MA20、MA50、MA200
- 支撑阻力位识别

**动量指标**：
- RSI(14)：>70超买，<30超卖
- MACD：信号线交叉
- 布林带：价格通道

**风险回报**：
- 交易区间
- 止损/目标设置
- 风险回报比

**输出**：趋势分析、关键价位、技术指标信号、交易建议（入场/止损/目标/风险回报比）
