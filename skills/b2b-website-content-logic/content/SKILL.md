# 外贸B2B独立站页面内容逻辑框架

本技能提供外贸B2B独立站各类页面的内容逻辑设计参考，基于大量案例网站分析和行业最佳实践总结。

## 一、首页内容逻辑

### 1.1 必选模块

**网站头部**：Logo、导航菜单、语种切换、社交链接，必选。

**Banner轮播图**：展示品牌形象、主要优势、主营产品，建议3组Banner。

**公司介绍**：简短公司简介+工厂照片，解决"我是谁"问题。

**热销产品**：调用后台产品数据，利于SEO，建议选择展示。

**网站底部**：主导航、产品分组、联系信息、版权声明。

### 1.2 可选模块

**产品分组**：分组名称+简介+图片，直观展示产品线。

**优势卖点**：4-6段优势，解决"为什么选我们"问题。

**应用场景**：3-6个场景，图片+描述，增强代入感。

**服务介绍**：OEM/免费样品/售后等核心服务说明。

**项目案例**：3-6个完整案例展示。

**合作伙伴**：品牌Logo轮播，增强信任。

**客户好评**：3-6条评价+客户信息。

**新闻/FAQ列表**：调用后台模块，利于SEO。

**发送询盘**：首页内嵌询盘入口，缩短转化路径。

### 1.3 模块排列顺序

```
网站头部 → Banner → 公司介绍 → 产品分组 → 热销产品 →
优势卖点 → 应用场景 → 服务介绍 → 项目案例 →
合作伙伴 → 客户好评 → 新闻列表 → FAQ列表 →
发送询盘 → 网站底部
```

**逻辑主线**：吸引注意（Banner）→ 建立认知（公司介绍）→ 满足需求（产品浏览）→ 建立信任（优势/案例）→ 转化闭环（询盘入口）

## 二、关于我们页面

### 2.1 页面定位

详细介绍公司整体情况，解决客户"为什么选择这家公司"的信任问题。篇幅建议2屏。

### 2.2 推荐模块

| 模块 | 说明 |
|------|------|
| Hero区域 | 醒目标题+公司形象大图 |
| 公司概况 | 成立时间、核心业务、目标市场、企业使命 |
| 企业实力数据 | 行业年限/工厂面积/员工数量/工程师数量 |
| 发展历程 | 时间线展示重要里程碑（正序或倒序） |
| 核心团队 | 创始人、研发、生产、销售负责人介绍 |
| 资质认证 | ISO/产品认证/行业认证证书展示 |
| 质量与服务 | 四列卡片布局展示核心优势 |
| 产品/解决方案 | 简要展示产品线，链接至产品页 |

### 2.3 案例参考

WELPING About Us页面结构：
```
标题区 → 公司简介 → 数据背书(17年/20000m²/100+员工) →
质量服务四列 → 发展历程时间线 → 创始人介绍 →
团队介绍 → 产品展示 → 专家支持 → 页脚
```

**逻辑**：吸引注意 → 建立认知 → 初步信任 → 深化信任 → 品牌故事 → 人格化信任 → 产品落地 → 行动转化

## 三、落地页（Why Choose Us）

### 3.1 页面定位

专门为广告投放设计的着陆页，提升转化率。篇幅建议4-5屏。

### 3.2 核心模块（按优先级）

| 优先级 | 模块 | 说明 |
|--------|------|------|
| P0 | 页首海报 | 核心价值主张+初步CTA |
| P0 | 公司精华介绍 | 差异化优势+核心数据 |
| P0 | 认证资质 | ISO/BSCI/产品认证 |
| P1 | 产品分组/主推产品 | 调用后台产品数据 |
| P1 | 核心优势卖点 | 4-8项差异化卖点 |
| P1 | 服务细则 | OEM/设计/质检等服务流程 |
| P2 | 客户案例/合作伙伴 | Logo墙+项目简介 |
| P2 | 制作工艺 | 生产流程/关键工艺展示 |
| P2 | 团队介绍 | 核心成员展示 |
| P2 | FAQ | 解答常见采购疑虑 |
| P3 | 客户好评 | 真实评价内容 |
| P3 | 视频列表 | YouTube嵌入产品/公司视频 |
| P3 | 应用场景 | 场景图片+描述 |
| P3 | 代理政策 | 吸引经销商合作 |

### 3.3 转化逻辑设计

```
第一屏：页首海报（价值主张+CTA）
第二屏：公司精华+认证资质（初步信任）
第三屏：产品分组（核心了解需求）
第四屏：优势卖点（深化差异化认知）
第五屏：服务细则/制作工艺（专业能力）
第六屏：客户案例（社会证明）
第七屏：FAQ（解答疑虑）
第八屏：客户好评（信任增强）
第九屏：最终CTA+联系表单（转化闭环）
```

### 3.4 案例参考

JOSOO Why Choose Us页面结构：
```
导航 → 标题+使命宣言 → 8项核心优势 →
Amazon供应商背书+BSCI/ISO认证+18项专利 →
增值服务(3D设计/产品拍摄/视频拍摄/包装设计) →
全球30+国家覆盖 → 4位核心团队成员 →
16个合作伙伴Logo → 页脚询价表单
```

## 四、产品详情页

### 4.1 内容结构

| 区块 | 内容要求 |
|------|----------|
| 产品标题 | 产品名\|核心参数\|应用场景\|服务标识（如OEM manufacturer） |
| 简要描述 | 2-3段核心卖点，每段聚焦一个差异化优势 |
| 关键词 | 6-8个产品关键词（材质/功能/用途/OEM等维度） |
| 产品属性 | 至少3条属性：材质/颜色/尺寸/MOQ/付款方式/交货时间等 |
| 产品图片 | 白底主图+场景应用图+细节特写图（≥3张）+Alt标签 |
| 卖点展示 | 3-6个核心卖点，标题+说明文字，可配图标 |
| 操作步骤 | 步骤图形式展示使用方法 |
| 规格参数 | 表格形式，清晰展示尺寸/功率/材质等功能参数 |
| 细节展示 | 产品细节/工艺特点，图片+标题+描述 |
| 应用场景 | 场景图片+描述，帮助客户想象应用 |
| 定制服务 | OEM/ODM说明：可定制项目/MOQ/设计支持/周期 |
| 采购指南 | 选择产品的关键考量因素和决策支持信息 |
| 询盘入口 | 页面各位置合理设置CTA按钮或内嵌表单 |

### 4.2 转化逻辑

```
产品认知（标题+描述）
    ↓
价值确认（卖点+图片）
    ↓
技术确认（规格+细节）
    ↓
场景代入（应用场景）
    ↓
定制需求（如有）
    ↓
决策支持（采购指南）
    ↓
行动转化（询盘入口）
```

## 五、工厂制造能力页面

### 5.1 推荐模块

| 模块 | 说明 |
|------|------|
| 工厂概况 | 工厂面积/成立时间/地理位置/生产线数量 |
| 生产能力 | 月产能/设备数量/员工构成（工人/工程师/QC比例） |
| 生产流程 | 流程图展示从原材料到成品的完整工序 |
| 质量控制 | 来料检验(IQC)+过程检验(IPQC)+成品检验(FQC/OQC) |
| 检测设备 | 关键检测设备名称+能力说明+图片 |
| 环保安全 | 环保措施/安全生产/可持续发展举措 |
| 供应商 | 知名品牌供应商合作展示 |

### 5.2 展示维度

**规模化数据**：具体数字证明规模（如"10000㎡"、"2条生产线"、"8个生产区"）

**标准化流程**：详细工序说明（如"10道工序：切割→铣削→表面处理..."）

**国际化认证**：质量管理体系认证（如ISO9001/ISO14001/BSCI）

### 5.3 案例参考

ROPO工厂页面结构：
```
欢迎横幅+360°全景入口 → 生产定制能力(Made in China) →
工厂环境(10000㎡+2条线+8个区) → 质量理念四大原则 →
工厂图片展示 → 质量控制计划(来料/过程/成品检验详细表格) →
FAQ(位置/月产能/参观) → 快速询价表单 → 供应商Logo → 产品分类
```

## 十三、内容设计核心原则

### 13.1 价值导向

所有文案从客户角度出发，强调能为客户带来的价值，避免自嗨式内容表达。

### 13.2 信任递增

遵循"初步认知→深入信任"的递进逻辑：新访客先建立基本认知，再逐步深入了解细节，最终产生合作信任。

### 13.3 行动明确

每个页面都有明确的行动引导，帮助访客知道下一步该做什么，避免浏览后不知如何继续。

### 13.4 信息适度

内容篇幅适中，关键信息突出展示，详细信息可通过折叠或跳转方式提供。

## 十四、页面类型差异化策略

| 页面类型 | 内容侧重 | 核心元素 |
|----------|----------|----------|
| 展示型页面 | 建立信任 | 具体数据/真实案例/权威认证 |
| 产品型页面 | 信息传达 | 完整规格/应用价值/高质量图片 |
| 转化型页面 | 行动转化 | 核心卖点/明显CTA/减少干扰 |

## 十五、移动端适配要点

- 标题简短有力，适合小屏快速阅读
- 段落精简，减少长段落阅读压力
- CTA按钮足够大且易于点击
- 图片优化尺寸保证加载速度
- 表格和参数考虑折叠或简化展示
