# ТРКИ 全级别语法·词汇练习题生成器

## 一、触发后的标准对话流程

### 步骤 1：选择级别

向用户展示以下菜单，请其选择一个级别：

```
请选择练习级别：
A1 — 元素级（基础入门）
A2 — 基础级
ТРКИ-1（B1）— 第一级
ТРКИ-2（B2）— 第二级
ТРКИ-3（C1）— 第三级
ТРКИ-4（C2）— 第四级
```

如果用户在触发请求中已经明确了级别（如"出一些B2的题"），跳过此步骤。

### 步骤 2：询问题目数量

问用户需要多少道题（请输入 1–100 之间的整数）。

如果用户已在触发请求中提及数量，直接跳过。

### 步骤 3：生成题目并输出 Word 文档

按照下方「各级别题型规格」生成对应数量的题目，**以 Word 文档形式输出**（不在对话中逐条显示题目）。

**文档格式要求：**
- 文件名：`练习题_[级别]_[日期].docx`
- 标题：【ТРКИ [级别] 练习题】
- 副标题：生成日期 + 题目数量
- 每题清晰编号，选择题列出所有选项（А/Б/В/Г），填空题用 ___ 表示空缺
- 题目之间留足够空行，便于手写答案
- 文档末尾附上答题说明：「请将您的答案发送给我，格式如：1А 2В 3-поехал …，我将逐题为您批改和解析。」

**生成方式（Python + python-docx）：**

```python
from docx import Document
from docx.shared import Pt
from docx.enum.text import WD_ALIGN_PARAGRAPH
import datetime

doc = Document()

# 标题
title = doc.add_heading(f'【ТРКИ {level} 练习题】', 0)
title.alignment = WD_ALIGN_PARAGRAPH.CENTER

# 副标题
sub = doc.add_paragraph(f'日期：{datetime.date.today()}　　共 {total} 题')
sub.alignment = WD_ALIGN_PARAGRAPH.CENTER
doc.add_paragraph()

# 逐题写入（不含答案）
for q in questions:
    stem_para = doc.add_paragraph()
    stem_para.add_run(f'{q["number"]}. {q["stem"]}').bold = True
    if q.get('options'):  # 选择题
        for opt in q['options']:
            doc.add_paragraph(f'   {opt}')
    doc.add_paragraph()  # 题间空行

# 末尾答题说明
doc.add_paragraph('【答题说明】请将您的答案发送给我，格式如：1А 2В 3-поехал …，我将逐题为您批改和解析。')

filename = f'练习题_{level}_{datetime.date.today()}.docx'
doc.save(filename)
```

生成后调用 `publish_artifact` 发布 docx 文件，并在对话中简短提示：
> 已生成 [N] 道 [级别] 练习题，请下载 Word 文档作答后，将答案发给我批改。

## 二、各级别题型规格

生成题目时，严格遵守以下规则：
- 所有题目必须是**纯语法或词汇选择/填空题**，不包含写作任务、阅读理解或听力。
- 难度应**尽可能接近该级别官方考试上限**，但绝不超出该级别的词汇和语法范围。
- 选项设计要有**合理的干扰项**，不能一眼看出答案。
- 生成的句子必须**自然、地道**，来源于日常、社会、文化、学术等真实语境。

---

### A1（元素级）

**题型一：双项选择（1–13题型）**
给出句子，右侧提供两个词语，要求选出正确的一个。
测试重点：нет/не、наречие对比（хорошо/хороший）、近义词辨析（недавно/недалеко）、动词选择（учится/изучает/занимается）。

示例：
```
Маша ... говорит по-французски.    А) хороший   Б) хорошо
```

**题型二：三项选择（14–43题型）**
给出不完整句子，三个选项，选出正确格形/词形/动词形式。
测试重点：格的选择（主/宾/与/生/造/前置格）、形容词一致、动词变位、时态（过去/现在/将来）、完成体与未完成体。

示例：
```
Антон приехал из ....    А) Франция   Б) Франции   В) Францию
```

**题型三：成对题（44–59）**
给出一组相关句子（两句共用一对选项，А=未完成体 Б=完成体），判断各句选哪个。

**题型四：三项选择–动词移动（60–63）**
区分 ехать/ездить/поехать 等移动动词。

**题型五：连词（64–70）**
选择正确的连词：и/а/но, когда/что/почему, который 等。

**出题比例建议（当题目数量 ≥ 10 时）：**
格形题 40%、动词题 35%（含体/时态/移动动词）、词汇选择 15%、连词 10%。

---

### A2（基础级）

**题型一：四项选择–词汇辨析（1–19）**
四个选项，重点测试近义词选择：
- 动词对：сказать/рассказать/советовать/разговаривать；получить/взять/сделать/послать；мочь/знать/уметь；смотреть/видеть；слушать/слышать；помнить/вспоминать
- 形容词/副词对：старый/старший；холодно/холоднее

示例：
```
Недавно я ... письмо от друга.    А) взял  Б) сделал  В) получил  Г) послал
```

**题型二：格与代词（20–40）**
四项选择，测试格的正确使用（尤其是前置词搭配）、代词格形、指示代词变格。

**题型三：动词体与时态（41–60）**
四项选择，注重完成体/未完成体语境区分、过去/现在/将来时、祈使句形式。

**题型四：复合句连词（61–80）**
选择正确从句连词：потому что/поэтому/так как；чтобы/чтоб；хотя/несмотря на；如果/когда/пока 等。

**题型五：比较级与最高级（81–100）**
形容词比较级（更长、最大等）与名词数量搭配（5 минут/2 минуты）。

**出题比例建议：** 词汇辨析 25%、格形/前置词 35%、动词体/时态 25%、连词/句法 15%。

---

### ТРКИ-1（B1）

**题型一：词汇对辨析–成对题（1–27）**
每对句子共用两个词（А/Б），判断各句选哪个。常见对：
- выучить/изучать，научить/учить
- может/знает/умеет
- назвала/позвала
- поставил/положил/повесил
- осталась/оставила/остановилась
- нести/вести/везти
- помнит/вспоминает，видит/смотрит，слушал/слышал

**题型二：格与前置词（28–83）**
四项选择，涵盖所有格的复杂搭配，重点：
- 带前置词的格（у+生格、к+与格、с+造格等）
- 短语：поздравляю с…、желаю…、пригласить участвовать в…
- 时间表达：в/на/по+时间，за/через/после/перед

**题型三：时间表达（73–81）**
选择时间状语中正确的格形与前置词：
в 2018 году；на следующей неделе；перед экзаменом；через неделю；за 2 дня；первого сентября；по средам

**题型四：数量与量词（67–68, 51, 54等）**
несколько человек；5 компьютерных игр；сколько минут；три года

**出题比例建议：** 词汇辨析成对题 20%、格与前置词 50%、时间表达 20%、数量 10%。

---

### ТРКИ-2（B2）

**核心特点：** 题目涉及更抽象词汇、书面语、复杂句法。题目背景可取自文化、历史、社会议题。

**题型一：四项选择–书面语词汇**
测试书面体词汇、同义词区分、高频动词搭配：
- подвижник/меценат/коллекционер 类高级词汇
- беспрецедентный/традиционный/уникальный 等形容词
- посвятить себя/посвятить кому 搭配
- подготовиться к / надеяться на 等动词搭配

**题型二：格与前置词（复杂）**
延续B1，但增加难度：
- 固定搭配中罕见前置词的选择
- 带有名词性结构的格（подготовка к чему / надежда на что）
- 介词短语辨析：на + 对格（目的）vs. в + 前置格（位置）

**题型三：阅读推断型选择**
给一段 150–250 词的短文，后跟 5–8 道选择题，测试对文意的推断（不测词汇）。
注意：这是词汇+语法练习，因此阅读材料本身要简短，题目测的是语言能力，不是背景知识。

**题型四：从句连词与句法**
区分：хотя/несмотря на；как будто/будто/словно；так как/потому что/из-за того что；вследствие/благодаря/из-за 等带格的前置词。

**出题比例建议：** 词汇辨析 30%、格与前置词 35%、句法连词 25%、文意推断 10%。

---

### ТРКИ-3（C1）

**核心特点：** 涵盖文体差异、预测词、书面语动词短语、复杂语义推断。

**题型一：四项选择–预测词与前置词**
- 固定短语的格形搭配：называть в честь + 生格；подведение итогов；опасаться + 生格；типично для + 生格；характерно для
- 方位与位置：в незнакомой улице vs. на незнакомой улице；из этого района

**题型二：填写适当形式（14–17）**
给出一段文字（如注释、摘要），空缺处要求填入语法形式正确、语义合适的词（不提供选项）。
测试：动词-谓语一致、主语人称/数。

**题型三：书面语特征动词短语（18–20）**
四项选择，判断哪个是「报刊公文体」（газетно-публицистический стиль）的典型表达。
示例：
```
Делегаты конференции единогласно ... о защите прав человека.
А) издали постановление  Б) постановили  В) приняли постановление  Г) принимали постановление
```

**题型四：语义替换（21–25）**
将含有特殊句式（双宾语否定、泛指结构等）的句子改为近义结构。
示例：Отцу не отговорить Сергея → 选近义句（不能/无法/不想）

**题型五：格形与前置词（26–44）**
同В2，但增加含抽象名词短语、被动构词等复杂结构。

**题型六：语义功能标注（45–50）**
分析短语的语义功能：分词/副动词短语表达原因/时间/方式等。

**出题比例建议：** 填空（无选项）10%、书面语动词 15%、语义替换 15%、格形 35%、语义功能 10%、词汇辨析 15%。

---

### ТРКИ-4（C2）

**核心特点：** 最高难度——动词语义细分、文段语境填空、语义歧义辨析、多答案连词题。

**题型一：文段连续填空（1–15）**
给出 150–200 词的连贯文段（文学性/叙述性），编号空缺 1–15，每题为四选一。
测试：动词体与时态在连续叙事中的精准选择（如 пошёл/шёл/ходил/сходил）。

**题型二：语义功能辨析（16–18）**
给出含有「语气词+动词」的特殊结构，判断其语义功能：
- 祈使（побуждение）
- 被迫（вынужденность）
- 非必要性（нецелесообразность）
- 不可能（невозможность）

**题型三：语义等值判断（19–20）**
给出一句话，判断它更接近 А 还是 Б 的语义含义（涉及否定、限定副词等微妙差别）。

**题型四：格形与语序（26–36）**
四项选择，涉及：
- 数词形容词（трёхсотлетняя）
- 名词修饰结构（хитрость лисы vs. хитрость у лисы）
- 被动/主动名词化短语（чистота эксперимента）
- 书面语方位短语

**题型五：无提示填空（21–25, 37–44）**
给出段落，空缺处需填入语义、语体、语法三重合适的词。
分两类：
  - **叙述体填空**（描写段落，填入自然体词汇）
  - **注释体/文摘体填空**（按文体规范填动词，如 включает/подразделяется/посвящён）

**题型六：多答案连词（45–50）**
每题选出**所有正确**选项（不止一个），测试连词/关联词的语义互换性：
что/будто/якобы；пока/когда/как только；так как/потому что/оттого что/из-за того что 等。

**出题比例建议：** 文段连续填空 25%、无提示填空 20%、语义辨析 20%、格形句法 25%、多答案连词 10%。

## 三、答案批改流程

当用户以**对话形式**提交答案时（格式如"1А 2В 3-поехал ..."），执行以下流程：

### 3.1 逐题批改输出（对话形式）

对每道题，依次输出：

```
第N题：用户答案 → [✅正确 / ❌错误，正确答案为X]
解析：[用1–3句话解释语法/词汇规则，指出为何此答案正确，其他干扰项错在哪里]
```

批改完所有题目后，给出总结：
```
共 N 题，答对 M 题，错 K 题。
```

### 3.2 生成错题 Word 文档

如果用户有错题，**自动**生成一份 Word 文档，文件名格式：`错题本_[级别]_[日期].docx`。

**文档内容：**
- 标题：【ТРКИ [级别] 错题集】
- 仅包含用户做错的题目（**不附答案，不附解析**）
- 保留原题目编号和完整题目内容（含选项，若为填空则保留空格）
- 每题之间留适当空行，便于用户再次练习

**生成方式（Python）：**

```python
from docx import Document
from docx.shared import Pt, RGBColor
from docx.enum.text import WD_ALIGN_PARAGRAPH
import datetime

doc = Document()

# 标题
title = doc.add_heading(f'【ТРКИ {level} 错题集】', 0)
title.alignment = WD_ALIGN_PARAGRAPH.CENTER

# 日期
date_para = doc.add_paragraph(f'练习日期：{datetime.date.today()}')
date_para.alignment = WD_ALIGN_PARAGRAPH.CENTER
doc.add_paragraph()  # 空行

# 逐题添加错题（不附答案）
for q in wrong_questions:
    p = doc.add_paragraph()
    p.add_run(f'{q["number"]}. {q["stem"]}').bold = False
    if q.get("options"):
        for opt in q["options"]:
            doc.add_paragraph(f'   {opt}')
    doc.add_paragraph()  # 题间空行

filename = f'错题本_{level}_{datetime.date.today()}.docx'
doc.save(filename)
```

生成后调用 `publish_artifact` 发布文件，供用户下载。

## 四、出题质量控制原则

1. **绝不混入该级别以上的语法结构或词汇**。每题出完后，在心里过一遍：「这个结构/词汇是否在该级别的大纲内？」

2. **干扰项要有意义**。每个选项都应该是学习者「可能会犯的错误」，而不是明显无关的词。

3. **句子语境要真实**。不要出现「Маша купила хлеб」这种毫无语境的空洞句；应设置生活场景、社会情境、人物关系，让句子有意义。

4. **高级别题目（B2–C2）可适当引入书面语、正式文体**。C1/C2 级别的题目应涵盖газетно-публицистический стиль 和 научный стиль 的典型表达。

5. **填空题（ТРКИ-3/4中）不提供选项**，要求用户自行填写正确的词形，批改时给出标准答案和解析。

6. **保持格式一致**：选择题统一用А/Б/В/Г标注选项；填空题用"___"表示空缺。

## 五、多轮练习支持

- 用户可以在一次会话中进行多轮练习（选同一级别或换级别）。
- 每轮生成新的题目，**不重复上一轮已出过的题目**（在会话内跟踪已使用的考点/句子，尽量变化语境和词汇）。
- 如果用户说「再来一组」「继续练」，直接问数量，跳过选级别步骤（默认使用上次选的级别），除非用户明确要换级别。
