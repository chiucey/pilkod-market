# suanming - 中国古代命理算命技能

## 概述

本技能提供中国古代命理学的综合分析能力，包括奇门遁甲、风水、八字、五行、属相、生肖等传统命理知识。可进行命运分析、事业运势、情感婚姻、健康运势、小孩起名等多方面推算。

## 核心概念

### 八字基础

八字由年柱、月柱、日柱、时柱四柱组成，每柱包含天干和地支：

- **天干**: 甲、乙、丙、丁、戊、己、庚、辛、壬、癸
- **地支**: 子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥

### 五行属性

五行相生相克关系：

- **相生**: 木生火、火生土、土生金、金生水、水生木
- **相克**: 木克土、土克水、水克火、火克金、金克木

### 十二属相

子鼠、丑牛、寅虎、卯兔、辰龙、巳蛇、午马、未羊、申猴、酉鸡、戌狗、亥猪

### 奇门遁甲基础

奇门遁甲由天盘、地盘、人盘三盘组成：

- **天盘九星**: 天蓬、天任、天冲、天辅、天英、天芮、天柱、天心、天禽
- **地盘八门**: 休门、生门、伤门、杜门、景门、死门、惊门、开门
- **人盘八神**: 值符、腾蛇、太阴、六合、白虎、玄武、九地、九天

### 八卦六十四卦

八卦和六十四卦是易经的核心内容，用于占卜预测：

- **八卦**: 乾（天）、坤（地）、震（雷）、巽（风）、坎（水）、离（火）、艮（山）、兑（泽）
- **六十四卦**: 由八卦两两相重而成，每卦有卦辞、彖辞、象辞、爻辞
- **起卦方法**: 金钱卦、蓍草卦、梅花易数

### 黄历择日

黄历结合阴阳五行、天干地支、节气、吉凶宜忌等内容：

- **二十四节气**: 立春、雨水、惊蛰、春分、清明、谷雨等
- **十二建除**: 建、除、满、平、定、执、破、危、成、收、开、闭
- **冲煞**: 冲、害、刑、破
- **神煞**: 吉神（天德、月德、天喜等）、凶煞（月破、大耗、五鬼等）

## 使用流程

### 步骤1: 确定分析类型

根据用户需求确定分析类型：

| 分析类型 | 所需信息 | 输出内容 |
|---------|----------|---------|
| 命运分析 | 出生年月日时 | 八字排盘、五行分析、命格推断 |
| 事业运势 | 出生年月日时 | 流年运势、事业方向、吉凶方位 |
| 情感婚姻 | 出生年月日时 | 婚姻运势、配偶特征、桃花年份 |
| 健康运势 | 出生年月日时 | 五行健康分析、疾病预防、调理建议 |
| 小孩起名 | 出生年月日时、姓氏 | 八字分析、五行缺补、推荐名字 |
| 风水分析 | 房屋方位、布局 | 风水格局、吉凶方位、调整建议 |
| 奇门遁甲 | 起卦时间 | 三盘排布、吉凶判断、行动建议 |
| 八卦占卜 | 所问事项 | 起卦结果、卦象解读、运势推断 |
| 黄历择日 | 事项、日期范围 | 宜忌分析、冲煞检查、择日建议 |

### 步骤2: 收集必要信息

根据分析类型收集用户信息：

**八字分析必需信息**:
- 出生年份（农历或公历）
- 出生月份
- 出生日期
- 出生时辰（子丑寅卯辰巳午未申酉戌亥）

**起名必需信息**:
- 婴儿性别
- 出生年月日时
- 姓氏（可选）
- 期望字数（可选）

**风水分析必需信息**:
- 房屋朝向
- 房屋结构
- 主要房间布局

**八卦占卜必需信息**:
- 所问事项
- 起卦时间（可选，默认当前时间）
- 起卦方法（可选，默认金钱卦）

**黄历择日必需信息**:
- 要办事项
- 日期范围（可选）

### 步骤3: 执行分析

根据分析类型执行相应计算：

#### 八字排盘

1. 根据出生时间确定年柱、月柱、日柱、时柱
2. 分析天干地支的五行属性
3. 计算五行强弱
4. 推断命格特征

#### 五行分析

1. 统计八字中各五行数量
2. 判断五行平衡状态
3. 识别缺弱五行
4. 提出补益建议

#### 奇门遁甲排盘

1. 确定值符和值使
2. 排布天盘九星
3. 排布地盘八门
4. 排布人盘八神
5. 分析格局吉凶

#### 起名分析

1. 分析八字五行
2. 识别缺弱五行
3. 选择补益字
4. 考虑音韵、寓意
5. 提供候选名字

### 步骤4: 生成分析报告

输出结构化的分析报告，包含：

- **基本信息**: 八字排盘、五行分布
- **核心分析**: 命格特征、五行强弱
- **运势推断**: 各方面运势分析
- **建议**: 改运建议、注意事项

## 常见分析类型

### 命格类型

常见命格包括：

| 命格 | 特征 | 吉凶 |
|-------|------|------|
| 正官格 | 日主坐官星，官星得令 | 吉 |
| 七杀格 | 日主坐杀星，杀星有制 | 吉凶参半 |
| 财格 | 日主坐财星，财星得令 | 吉 |
| 印格 | 日主坐印星，印星得令 | 吉 |
| 食伤格 | 日主坐食伤，食伤泄秀 | 吉 |
| 比劫格 | 日主坐比劫，比劫帮身 | 吉凶参半 |

### 五行缺补

根据八字五行分析，提供补益建议：

- **缺木**: 选用带木字旁字，如林、森、梅、柏
- **缺火**: 选用带火字旁字，如炎、炜、煜、烨
- **缺土**: 选用带土字旁字，如坤、培、城、坦
- **缺金**: 选用金字旁字，如锋、钰、铭、锦
- **缺水**: 选用水字旁字，如浩、淼、涵、清

### 风水布局

常见风水布局要点：

- **客厅**: 宜明亮宽敞，沙发靠实墙
- **卧室**: 宜安静私密，床头不冲门
- **厨房**: 宜通风良好，水火不冲
- **书房**: 宜安静明亮，文昌位设书桌
- **卫生间**: 宜保持清洁，门不冲厕所

## 注意事项

### 命理分析原则

1. **客观性**: 命理分析仅供参考，不可迷信
2. **综合性**: 需结合多种方法综合判断
3. **时代性**: 古代命理需结合现代生活理解
4. **主观能动性**: 命运可由个人努力改变

### 信息准确性

1. 出生时间需准确到时辰
2. 区分农历和公历
3. 注意地域时差
4. 考虑夏令时影响
