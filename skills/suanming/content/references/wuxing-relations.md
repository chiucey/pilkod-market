## 五行相生

### 相生关系图

```
    木 → 火 → 土 → 金 → 水
    ↑                   ↓
    └───────────────────┘
```

### 相生详解

| 生者 | 被生者 | 生克原理 | 现实意义 |
|-----|--------|---------|---------|
| 木生火 | 木燃烧生火 | 木燃烧产生火 | 木主仁，火主礼，仁能生礼 |
| 火生土 | 火燃烧成灰 | 火燃烧后化为灰土 | 火主礼，土主信，礼能生信 |
| 土生金 | 土中藏金 | 金矿埋藏于土中 | 土主信，金主义，信能生义 |
| 金生水 | 金熔化成水 | 金属熔化后成液体 | 金主义，水主智，义能生智 |
| 水生木 | 水滋养树木 | 水灌溉使树木生长 | 水主智，木主仁，智能生仁 |

### 相生在八字中的作用

1. **印星生身**: 印星（生我者）生日主，代表贵人、长辈、学习
2. **食伤泄秀**: 食伤（我生者）泄日主，代表才华、表达、子女
3. **财星养身**: 财星（我克者）受日主克制，代表财富、妻子
4. **官星约身**: 官星（克我者）克制日主，代表事业、丈夫、权力
5. **比劫帮身**: 比劫（同我者）帮扶日主，代表兄弟、朋友、竞争

| 克者 | 被克者 | 克制原理 | 现实意义 |

| 金克木 | 金属砍木 | 斧头砍伐树木 | 金主义，木主仁，义能克仁 |

### 相克在八字中的作用

1. **官星克身**: 官星克制日主，代表约束、压力、管理
2. **七杀攻身**: 七杀猛烈克制日主，代表压力、挑战、危机
3. **财星坏印**: 财星克制印星，代表因财坏德、因财失学
4. **比劫争财**: 比劫克制财星，代表破财、竞争、纠纷
5. **食伤克官**: 食伤克制官星，代表抗上、叛逆、才华

## 五行平衡

### 五行强弱判断

**强旺判断标准**：

1. **得令**: 五行在当令季节为旺
2. **得地**: 五行在地支有根为强
3. **得生**: 五行有印星生扶为强
4. **得助**: 五行有比劫帮扶为强

**衰弱判断标准**：

1. **失令**: 五行不在当令季节为衰
2. **失地**: 五行在地支无根为弱
3. **受克**: 五行被其他五行克制为弱
4. **泄气**: 五行被食伤泄气为弱
