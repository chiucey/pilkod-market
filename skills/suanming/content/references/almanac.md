# 黄历详解

## 黄历概述

黄历是中国传统历法，结合阴阳五行、天干地支、节气、吉凶宜忌等内容，用于指导日常生活和重要活动的择日。

### 黄历构成

| 组成部分 | 说明 |
|---------|------|
| 年柱 | 农历年份的天干地支 |
| 月柱 | 农历月份的天干地支 |
| 日柱 | 农历日期的天干地支 |
| 节气 | 二十四节气 |
| 宜忌 | 当日宜做和忌做的事项 |
| 冲煞 | 当日冲煞的生肖和方位 |
| 神煞 | 当日吉神和凶煞 |
| 建除 | 十二建除 |

## 择日方法

### 择日原则

1. **避凶就吉**: 避开凶煞日，选择吉神日
2. **冲煞回避**: 避开冲煞生肖和方位
3. **建除配合**: 根据建除选择适宜日期
4. **节气结合**: 结合节气选择适宜时机

### 择日步骤

1. **确定事项**: 明确要办的事项
2. **查询宜忌**: 查询该事项的宜忌
3. **选择吉日**: 选择吉神临门、避凶煞日
4. **冲煞检查**: 检查冲煞生肖和方位
5. **建除验证**: 验证建除是否适宜
6. **最终确定**: 确定最终日期

### 择日示例

**事项**: 嫁娶

**步骤**:
1. 查询嫁娶宜忌: 宜天德、月德、天喜、月红、三合、六合日
2. 避开月破、大耗、五鬼、月害、月刑日
3. 选择吉神临门日: 如天德、月德日
4. 检查冲煞: 避开冲煞生肖和方位
5. 验证建除: 选择建日、成日、开日
6. 最终确定: 综合考虑确定最佳日期
