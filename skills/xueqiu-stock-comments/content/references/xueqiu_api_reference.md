# 雪球网站结构与API参考

## 雪球个股页面URL格式

### 标准格式
```
https://xueqiu.com/S/股票代码
```

### 示例
- 深圳主板：`https://xueqiu.com/S/SZ001896`
- 上海主板：`https://xueqiu.com/S/SH600519`
- 创业板：`https://xueqiu.com/S/SZ300750`
- 科创板：`https://xueqiu.com/S/SH688981`

## 页面结构分析

### 雪球个股页面主要标签

1. **讨论** - 用户发帖讨论区（主要分析目标）
2. **资讯** - 股票相关新闻
3. **公告** - 公司公告
4. **财务** - 财务报表数据
5. **股东** - 股东信息

## API接口参考

### 讨论区API（推测）

雪球讨论区可能使用类似以下的API：

```
GET https://xueqiu.com/statuses/stock_timeline.json
Parameters:
  - symbol_id: 股票代码（如SZ001896）
  - page: 页码
  - count: 每页数量（最大200）
  - type: 类型（discussion/snews等）
```

## 数据处理建议

### 1. 文本清洗
- 移除HTML标签
- 处理特殊字符和emoji
- 统一换行符
- 处理引用内容

### 2. 情绪判断逻辑
```
情绪得分 = Σ(看多关键词权重) - Σ(看空关键词权重)

得分 > 正阈值：判定为看多
得分 < 负阈值：判定为看空
其他情况：判定为中性
```

### 3. 权重考虑
- 否定词反转（"不看好"应该算看空而非看多）
- 程度副词加强（"非常看好"、"强烈推荐"）
- 双重否定处理
- 讽刺反语识别（较难，可标记后人工确认）

### 4. 高质量帖子筛选
- 点赞数 > 10
- 评论数 > 5
- 排除转发内容（原创内容权重更高）
- 认证用户内容权重更高

## 合规使用建议

1. **访问频率**：建议每次分析间隔至少5秒
2. **数据量限制**：单次分析建议不超过500条帖子
3. **结果验证**：分析结果仅供参考，不构成投资建议
4. **隐私保护**：不要保存或分享用户个人信息
5. **来源标注**：使用分析结果时请注明数据来源为雪球

## 常见问题排查

| 问题 | 可能原因 | 解决方案 |
|------|---------|---------|
| 访问被拒绝403 | 反爬虫触发 | 更换User-Agent，添加Cookie |
| 内容为空 | 需要登录 | 添加有效的登录Cookie |
| 数据不完整 | API限制 | 多次请求合并结果 |
| 帖子加载慢 | 网络问题 | 增加重试次数和间隔 |
| 分析结果异常 | 样本偏差 | 增加样本量或过滤异常值 |
