本技能用于抓取和分析雪球（xueqiu.com）个股讨论区的帖子，通过情感分析识别投资者情绪，并总结对股价有影响的关键观点。

# 雪球个股评论分析技能

## 功能概述

本技能用于抓取和分析雪球（xueqiu.com）个股讨论区的帖子，通过情感分析识别投资者情绪（看多/看空/中性），并总结对股价有影响的关键观点。

## 触发条件

当用户请求以下操作时触发：
- 分析雪球个股评论
- 抓取雪球帖子
- 个股讨论分析
- 雪球舆情分析
- 个股情绪分析
- 雪球评论情感分析

## 输入参数

| 参数 | 说明 | 示例 |
|------|------|------|
| stockCode | 股票代码 | SZ001896, SH600519 |
| count | 抓取帖子数量（默认200条） | 200 |

## 执行流程

### 步骤1：构建访问URL

根据股票代码构建雪球个股讨论区URL：
```
https://xueqiu.com/S/股票代码
```

例如：`https://xueqiu.com/S/SZ001896`

### 步骤2：抓取讨论区内容

使用网页抓取工具访问雪球个股讨论页面，提取"讨论"标签下的帖子内容。

**抓取字段**：
- 帖子ID
- 作者昵称
- 发布时间
- 评论内容
- 点赞数
- 评论数
- 转发数

**注意事项**：
- 雪球网站可能需要处理反爬虫机制
- 部分内容可能需要登录cookie才能访问
- 建议设置适当的请求间隔

### 步骤3：情感分析

对每条帖子进行情感分析，识别：
- **看多情绪**：表达买入、看好、后市乐观的观点
- **看空情绪**：表达卖出、悲观、后市谨慎的观点
- **中性情绪**：客观描述、无明显倾向

**情感分析关键词**（部分）：

| 看多关键词 | 看空关键词 |
|-----------|-----------|
| 买入、加仓、看好、做多 | 卖出、减仓、看空、做空 |
| 抄底、布局、低吸 | 割肉、止损、高位 |
| 主升浪、突破、爆发 | 破位、回调、见顶 |
| 价值投资、长期持有 | 泡沫、风险、警惕 |
| 业绩增长、估值修复 | 业绩下滑、泡沫化 |

### 步骤4：观点提取与总结

从评论中提取对股价有影响的关键观点：

1. **资金动向**：大资金流入/流出、主力动向
2. **机构持仓**：机构持仓变化、增减仓情况
3. **技术分析**：支撑位、压力位、趋势判断
4. **基本面**：业绩预期、估值水平、行业前景
5. **消息面**：政策影响、公告解读、市场传闻
6. **风险提示**：潜在风险、注意事项

## 技术实现注意事项

### 网页抓取策略

1. **请求头设置**：模拟浏览器访问
2. **频率控制**：设置请求间隔避免被封
3. **Cookie处理**：处理登录状态和反爬虫验证
4. **内容解析**：提取帖子列表和详细内容

### 情感分析策略

1. **规则匹配**：使用关键词匹配识别基础情绪
2. **上下文理解**：考虑否定词和程度副词的影响
3. **长文处理**：对长帖子分段分析取主要情绪
4. **垃圾信息过滤**：过滤广告、无意义内容

### 数据存储

- 分析结果可保存为JSON格式便于后续处理
- 建议记录分析时间戳以便追踪历史变化

## 常见问题处理

| 问题 | 解决方案 |
|------|---------|
| 访问被拒绝 | 添加User-Agent，使用代理IP |
| 内容加载失败 | 等待页面完全加载后重试 |
| 帖子数量不足 | 扩大时间范围或分批抓取 |
| 情感判断不准确 | 增加关键词库，引入AI辅助分析 |

## 安全与合规

- 遵守雪球网站的robots.txt规定
- 不要过于频繁地访问网站
- 尊重用户隐私，不要收集个人信息
- 分析结果仅供投资参考，不构成投资建议
