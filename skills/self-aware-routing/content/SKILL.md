# Self-Aware Routing 智能路由技能

自动分析请求复杂度，智能路由到最优模型，实现高达 58% 的成本节省。

## 工作流程

### 1. 需求分析

评估以下关键因素：
- **查询类型**：事实问答、代码生成、创意写作、复杂推理
- **质量要求**：精确度、完整性、响应风格
- **成本约束**：预算限制、吞吐量需求
- **延迟要求**：实时交互 vs 批处理场景

### 2. 模型能力评估

使用以下框架评估可用模型：

| 模型层级 | 代表模型 | 典型成本 | 适用场景 |
|---------|---------|---------|---------|
| 顶级 | GPT-4o, Claude Opus, Gemini Ultra | 高 | 复杂推理、创意写作、精确代码 |
| 中级 | GPT-3.5-turbo, Claude Haiku, Gemini Flash | 中 | 一般对话、摘要、翻译 |
| 轻量 | Llama 3 8B, Mistral 7B | 低 | 简单问答、格式转换、嵌入 |

### 3. 路由策略选择

根据场景选择最优策略：

**A. 相似度加权路由 (RouteLLM)**
```
适用场景：高质量偏好明确、批量处理
流程：
1. 将请求转为向量嵌入
2. 计算与训练集偏好数据的相似度
3. 基于相似度预测最优模型
4. 执行路由决策
```

**B. 级联路由 (FrugalGPT)**
```
适用场景：成本敏感、延迟容忍
流程：
1. 先使用廉价模型尝试
2. 评估响应质量
3. 质量不足则升级到更贵模型
4. 达到质量阈值或最高级模型为止
```

**C. 直接路由 (CARROT)**
```
适用场景：实时性要求高
流程：
1. 预训练路由分类器
2. 单次推理直接决策
3. 无需回退机制
```

### 4. 成本效益计算

执行前估算：
```
预期节省 = (1 - 路由后平均成本/原成本) × 100%
质量影响 = 路由后质量分数 - 原质量分数
净收益 = 成本节省 - 质量损失惩罚
```

### 5. 实施建议

**小型项目 (< 10000 req/day)**
- 使用 RouteLLM 云服务
- 默认使用中级模型，按需升级

**中型项目 (10000-100000 req/day)**
- 自托管路由系统
- 建立查询分类器
- 实施缓存策略

**大型项目 (> 100000 req/day)**
- 多级路由架构
- 实时性能监控
- A/B 测试持续优化
