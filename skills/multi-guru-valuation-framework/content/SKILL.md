# 多大师协同投资估值框架

本框架整合七位投资大师的核心估值方法论，为投资决策提供多维度、立体化的分析视角。

## 核心大师方法论

### 1. 沃伦·巴菲特 (Warren Buffett) - 价值投资之父
**核心理念**: 内在价值、安全边际、护城河

**估值公式**:
```
内在价值 = 自由现金流 ÷ (折现率 - 永续增长率)
```

**关键指标**:
- 自由现金流 (FCF) = 经营现金流 - 资本支出
- 股权收益率 (ROE) > 15%
- 护城河宽度评估
- 管理层质量

**安全边际**: 股价 < 内在价值 30%以上

---

### 2. 本杰明·格雷厄姆 (Benjamin Graham) - 价值投资奠基人
**核心理念**: 保守估值、Net-Net、工作资本

**估值公式**:
```
Net-Net 价值 = (流动资产 - 全部负债) × 0.75
内在价值 = EPS × (8.5 + 2×预期增长率)
```

**关键指标**:
- 市盈率 (P/E) < 15
- 市净率 (P/B) < 1.5
- 流动比率 > 2
- 股息率 > AAA债券收益率2/3

---

### 3. 彼得·林奇 (Peter Lynch) - 成长股大师
**核心理念**: PEG估值、主营业态分析

**估值公式**:
```
合理PE = 增长率 × 2
PEG = 市盈率 ÷ 盈利增长率
```

**关键指标**:
- PEG < 1 为低估
- 隐蔽资产识别
- 现金流与盈利匹配度
- 负债结构分析

---

### 4. 约翰·邓普顿 (John Templeton) - 逆向投资大师
**核心理念**: 逆向思维、绝对估值、全球视野

**估值原则**:
- 极度悲观时买入
- 关注长期价值而非短期波动
- 全球市场比较估值

**关键指标**:
- 市盈率相对历史均值偏离度
- 股息率 vs 无风险收益率
- 全球同业比较

---

### 5. 乔尔·格林布拉特 (Joel Greenblatt) - 神奇公式
**核心理念**: 资本回报率、企业价值

**估值公式**:
```
ROC = EBIT / (净营运资本 + 净固定资产)
EV/EBIT = 企业价值 / 息税前利润
```

**关键指标**:
- ROC (资本回报率) > 15%
- EBIT收益率 > 15%
- 神奇公式综合排名

---

### 6. 威廉·奥尼尔 (William O'Neil) - CAN SLIM
**核心理理念**: 趋势动量、技术分析、基本面结合

**CAN SLIM 要素**:
- C: 当季每股收益增长 > 20%
- A: 年度每股收益增长加速
- N: 新产品/新管理层/新高潮
- S: 供需平衡(成交量确认)
- L: 行业龙头地位
- I: 机构认可度
- M: 市场方向判断

---

### 7. 乔治·索罗斯 (George Soros) - 反身性理论
**核心理念**: 反身性、宏观视角、认知偏差

**分析维度**:
- 基本面与市场预期的背离
- 宏观周期定位
- 认知偏差识别
- 拐点判断

---

## 分析框架

### 第一步：数据收集
```
输入: 股票代码或公司名称
输出: 七位大师所需的完整数据集
```

**收集指标**:
- 财务指标: EPS、FCF、EBIT、ROE、ROIC
- 估值指标: P/E、P/B、PEG、EV/EBIT
- 质量指标: 毛利率、负债率、护城河评估
- 动量指标: 价格趋势、相对强弱

### 第二步：分项估值
对每位大师的方法论进行独立计算:

1. **巴菲特内在价值区间**
2. **格雷厄姆保守估值**
3. **林奇PEG评级**
4. **邓普顿逆向评估**
5. **格林布拉特神奇公式得分**
6. **奥尼尔CAN SLIM评分**
7. **索罗斯反身性分析**

### 第三步：综合评分
```
综合得分 = 巴菲特(20%) + 格雷厄姆(20%) + 林奇(15%) +
          邓普顿(15%) + 格林布拉特(15%) + 奥尼尔(10%) +
          索罗斯(5%)
```

### 第四步：决策建议
| 综合得分 | 建议 |
|---------|------|
| 80-100 | 强烈买入 |
| 60-79 | 买入 |
| 40-59 | 持有/观察 |
| 20-39 | 谨慎/减持 |
| 0-19 | 卖出 |

## 使用示例

**示例输入**: "分析贵州茅台(600519)的投资价值"

**预期输出**:
1. 收集贵州茅台完整财务数据
2. 运行七位大师的估值模型
3. 生成综合估值报告
4. 提供具体的买入/持有/卖出建议及理由

**预期输出**:
1. 分别对两只股票进行多大师估值
2. 生成对比分析表
3. 给出相对价值判断

## 注意事项

1. **数据准确性**: 所有分析基于公开财务数据,需确认数据时效性
2. **行业差异**: 不同行业适用不同估值方法权重
3. **周期因素**: 宏观经济周期影响估值结果
4. **主观判断**: 部分评估(如护城河)存在主观性
5. **风险提示**: 本框架仅供辅助决策,不构成投资建议
