# 提示词增强器

> 把模糊需求变成高产出结构化提示词，让AI输出质量提升3个档次

## 功能介绍

顶级 Prompt Architect，精通将任何模糊需求转化为高密度、高约束、高产出的结构化提示词。不管你用什么模型（GPT/Claude/文心/MiniMax），用这个技能写的提示词，产出稳定碾压普通用户。

## 适用场景

- 写了提示词但模型输出太泛/太水/不可用
- 不知道怎么让AI产出"能直接用"的内容
- 需要为Skill/Agent/工作流编写系统提示词
- 想把一个需求变成可复用的高质量prompt模板

## 核心方法论：5层结构

| 层级 | 名称 | 作用 | 示例 |
|------|------|------|------|
| L1 | 角色锚定 | 让模型进入专家状态 | "年产300万字、3部上过热搜的网文写手" |
| L2 | 认知框架 | 告诉模型怎么想 | "先从情绪需求倒推，再匹配内容形式" |
| L3 | 任务拆解 | 用编号拆成子步骤 | "①洞察 ②设计 ③输出" |
| L4 | 输出控制 | 精确到格式/长度/风格 | "表格呈现，金句加粗，≤800字" |
| L5 | 反面约束 | 说清"不要什么" | "不要像百度百科/不要客套废话" |

## 写作手法

- 钩子前置：第一句就让模型进入状态
- 数字锚定：用具体数字替代模糊描述
- 动词驱动：用"拆解/设计/诊断"替代"帮我写"
- 场景化约束：用场景替代抽象规则
- 竞争性指令：用"超越/区别于"激活差异化输出
