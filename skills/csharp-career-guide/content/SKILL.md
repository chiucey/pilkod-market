## 🎓 酱酱的学习路线建议

### 🌟 小白入门路线（0-6个月）

**目标**：能够开发简单的桌面应用和Web小工具

**学习计划**：

```
第1-2个月：C#基础语法
├── 变量、数据类型、运算符
├── 条件判断、循环语句
├── 数组、集合(List、Dictionary)
└── 面向对象基础(类、对象、继承)

第3-4个月：.NET桌面开发
├── WinForms/WPF入门
├── 常用控件使用
├── 事件处理机制
└── 小项目：计算器、记事本

第5-6个月：数据库基础
├── SQL基础语句
├── SQL Server/MySQL使用
├── ADO.NET操作数据库
└── 项目：学生管理系统
```

**酱酱小贴士**：
- 不要被"面向对象"吓到，酱酱会用超简单的比喻教你！
- 多动手写代码，看100遍视频不如自己敲10遍！
- 遇到问题先百度，很多小可爱都遇到过同样的问题喵～

### 💪 进阶提升路线（6-18个月）

**目标**：能独立完成企业级Web应用开发

**学习计划**：

```
第7-9个月：ASP.NET Core Web开发
├── ASP.NET Core基础概念
├── MVC架构模式
├── RESTful API设计
├── Entity Framework Core
└── 项目：博客系统、电商后台

第10-12个月：高级技能
├── 异步编程(async/await)
├── 依赖注入(DI)
├── JWT身份认证
├── Docker容器化
└── Git版本控制

第13-18个月：分布式与微服务
├── 微服务架构设计
├── Redis缓存
├── RabbitMQ消息队列
├── Docker Compose
└── 项目：微服务电商平台
```

**酱酱小贴士**：
- 这个阶段要开始关注"为什么"，不只是"怎么做"！
- 尝试参与开源项目，GitHub上有超多.NET开源项目～
- 开始写技术博客，输出是最好的学习方式喵！

## 📝 简历撰写小技巧

### ✨ 让HR眼前一亮的简历怎么写？

**1. 技术栈要写清晰**

```markdown
【推荐写法】
熟练度：精通 ⭐⭐⭐⭐⭐
技术栈：C# / .NET 8 / ASP.NET Core / Entity Framework Core / SQL Server / Redis

【不推荐】
熟悉C#、了解.NET、会写SQL
```

**2. 项目经验要量化**

```markdown
【推荐写法】
• 独立负责用户模块开发，日均处理请求100万+，接口响应时间<50ms
• 优化数据库查询性能，单表查询时间从3s降至200ms，性能提升15倍
• 设计并实现微服务架构，支撑日订单量10万+，系统可用性99.9%

【不推荐】
负责用户模块开发
优化了数据库性能
实现了微服务架构
```

**3. 突出业务价值**

```markdown
【推荐写法】
• 开发风控规则引擎，识别交易风险，拦截欺诈交易2000+笔/月
• 搭建实时数据看板，运营决策效率提升40%

【不推荐】
写了风控规则
做了数据看板
```
