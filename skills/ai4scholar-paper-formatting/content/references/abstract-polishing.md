# Abstract Structure Polishing Guide

## IMRaD Structure Five Elements

Academic abstracts should contain the following five structural elements:

### 1. Background
- Describe the real-world problem or knowledge gap in the research
- Explain why this issue is important
- Establish research motivation for readers

**Diagnostic Criteria**:
- ✅ Present: Clearly identifies current status and problems in the field
- ⚠️ Vague: Mentioned but not specific
- ❌ Missing: No background description at all

### 2. Objective
- Clearly state the specific question this research aims to answer
- Or state the specific research objectives
- Should be closely related to background

**Diagnostic Criteria**:
- ✅ Present: Clearly states research purpose
- ⚠️ Vague: Purpose unclear or too broad
- ❌ Missing: No research purpose statement

### 3. Methods
- Specific methods used in the research
- Sample or data sources
- Analysis methods or technical approaches

**Diagnostic Criteria**:
- ✅ Present: Describes research methods in detail
- ⚠️ Vague: Method description incomplete
- ❌ Missing: No method description

### 4. Results
- Core findings
- Should include specific data or key metrics
- Highlight main contributions

**Diagnostic Criteria**:
- ✅ Present: Contains specific data and findings
- ⚠️ Vague: Has results but lacks specific data
- ❌ Missing: No results statement

### 5. Conclusion/Significance
- Contribution to the field
- Practical implications or application value
- Research limitations or future directions

**Diagnostic Criteria**:
- ✅ Present: Clearly states research significance
- ⚠️ Vague: Significance description vague
- ❌ Missing: No conclusion

## Word Count Requirements

| Type | Word Count |
|-----|---------|
| Chinese Abstract | 200–300 characters |
| English Abstract | 150–250 words |

## Diagnostic Output Format

```
✅ Background: Clear - research question well-defined
⚠️ Objective: Present but vague - suggest adding specific research hypothesis
❌ Results: Missing - need to add core metric numbers
✅ Methods: Clear - method description complete
✅ Conclusion: Present - conclusion clear

【Modification Suggestions】
1. Background section suggests adding description of current research gaps
2. Results section suggests adding specific data (e.g., accuracy, recall)

【Revised Abstract】
[Complete rewritten version with modifications marked in brackets]
```

## Constraints

- Do not change author's core arguments
- Do not add data or conclusions not mentioned in original text
- Maintain original research contributions
- Modifications should make structure clearer
