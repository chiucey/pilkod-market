# Reference Formatting Guide

## Common Citation Format Standards

### IEEE Format
- Maximum 6 authors before using et al.
- Article titles in double quotes
- Journal names use standard abbreviations
- Format: [Number] Author(s), "Title," Journal, vol. X, no. X, pp. XX–XX, Month Year.

### APA Format (7th Edition)
- Maximum 3 authors before using et al.
- Year immediately follows authors
- Article titles without quotes, journal names in italics
- Format: Author(s). (Year). Title. Journal, Volume(Issue), Pages. DOI

### Vancouver Format
- Maximum 3 authors before using et al.
- Journal names use standard abbreviations
- Format: Author(s). Title. Journal. Year;Volume(Issue):Pages.

### Nature Format
- Maximum 5 authors before using et al.
- Title is concise, no quotes
- Format: Author(s) Title. Journal Volume, Pages (Year). DOI

## Journal Name Standard Abbreviations

| Full Name | Standard Abbreviation |
|---------|---------|
| Nature | Nature |
| Science | Science |
| Nature Communications | Nat. Commun. |
| Journal of the American Chemical Society | J. Am. Chem. Soc. |
| Proceedings of the National Academy of Sciences | Proc. Natl Acad. Sci. USA |
| IEEE Transactions on Pattern Analysis | IEEE Trans. Pattern Anal. |
| ACM Computing Surveys | ACM Comput. Surv. |

## Example

**Input**：
```
Vaswani et al, attention is all you need, 2017, neurips
LeCun Y, Bengio Y, Hinton G. Deep learning. Nature. 2015.
```

**IEEE Output**：
```
[1] A. Vaswani et al., "Attention is all you need," in Advances in Neural
    Information Processing Systems, 2017, vol. 30, pp. 5998–6008.

[2] Y. LeCun, Y. Bengio, and G. Hinton, "Deep learning," Nature, vol. 521,
    no. 7553, pp. 436–444, May 2015.
```
