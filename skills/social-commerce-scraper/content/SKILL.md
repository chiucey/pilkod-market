# 社交电商热销爆款商品抓取技能

## 触发条件

当用户请求以下内容时触发此技能：
- 抓取小红书/B站/抖音热销商品
- 获取社交平台爆款榜单
- 分析热门带货商品趋势
- 查询抖音带货销量排行
- 小红书商品热度分析
- B站电商商品数据

## 执行流程

### 步骤 1：确定目标平台

根据用户需求确定抓取平台：
- **小红书**：关注「好物分享」「种草」类内容中的商品链接
- **抖音**：关注「抖音商城」「带货榜单」「热卖商品」
- **B站**：关注「会员购」「UP主带货」商品信息

### 步骤 2：执行数据抓取

使用网页内容提取工具抓取各平台数据：

```
平台数据源：
- 小红书：好物分享、种草笔记关联商品
- 抖音：抖音商城热卖榜单、带货主播关联商品
- B站：会员购热卖、UP主带货推荐
```

### 步骤 3：提取商品信息

从抓取内容中提取关键信息：

| 字段 | 说明 |
|------|------|
| 商品名称 | 商品标题/名称 |
| 价格 | 当前售价 |
| 销量/热度 | 平台显示的销量或热度指数 |
| 来源平台 | 小红书/抖音/B站 |
| 商品链接 | 原始商品页面链接 |
| 发布时间 | 内容/榜单发布时间 |

### 步骤 4：数据整理输出

将抓取结果整理为结构化格式，包含：
1. 各平台热销商品汇总表
2. 商品热度/销量排名
3. 价格区间分布
4. 商品分类标签

## 输出格式

```json
{
  "platform": "抖音/小红书/B站",
  "hotProducts": [
    {
      "name": "商品名称",
      "price": "价格",
      "sales": "销量/热度",
      "category": "商品分类",
      "link": "商品链接",
      "updateTime": "更新时间"
    }
  ],
  "summary": {
    "totalProducts": "商品总数",
    "priceRange": "价格区间",
    "topCategory": "热门分类"
  }
}
```

## 注意事项

1. **遵守平台规则**：尊重各平台的数据使用政策
2. **数据时效性**：标注数据抓取时间，提示用户数据可能有时效限制
3. **链接有效性**：检查商品链接是否有效，标注失效或已下架商品
4. **增量更新**：对于重复请求，支持增量更新而非全量重新抓取
