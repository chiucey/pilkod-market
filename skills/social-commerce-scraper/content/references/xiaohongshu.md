# 小红书热销商品抓取指南

## 平台特点

小红书是以「种草」内容为核心的社交电商平台，商品信息主要通过：
- 好物分享笔记
- 商品测评内容
- 种草推荐文章

## 推荐数据源

### 1. 小红书商城热卖榜
- 路径：APP内「我」→「购物」→「热卖榜单」
- 特点：官方榜单，数据较为准确

### 2. 笔记关联商品
- 通过「好物分享」「开箱测评」类笔记
- 提取笔记中插入的商品卡片信息

### 3. 品牌合作商品
- 「合作」标签笔记中的推广商品
- 通常带有商品链接

## 抓取字段说明

| 字段 | 抓取位置 | 备注 |
|------|---------|------|
| 商品名称 | 商品标题 | 通常包含品牌+品名 |
| 价格 | 商品卡片 | 注意原价/活动价区分 |
| 销量 | 部分商品显示 | 非全量显示 |
| 热度/点赞 | 笔记互动数据 | 间接反映商品热度 |
| 店铺名 | 店铺入口 | 标注店铺类型 |
| 商品图 | 商品卡片 | 用于商品识别 |

## 注意事项

1. 小红书商品数据部分需要登录态
2. 笔记中的商品卡片可能包含多个SKU
3. 热门笔记的发布时间影响商品热度
4. 建议关注「本周热卖」「飙升榜」等维度
