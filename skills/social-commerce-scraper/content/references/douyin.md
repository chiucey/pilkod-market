# 抖音热销商品抓取指南

## 平台特点

抖音是短视频带货的核心平台，商品数据来源丰富：
- 直播间带货商品
- 短视频挂车商品
- 抖音商城热卖榜单

## 推荐数据源

### 1. 抖音商城热卖榜单
- 路径：APP内「我」→「抖音商城」→「排行榜」
- 数据维度：
  - 实时热卖榜
  - 每日热卖榜
  - 品类榜单

### 2. 带货主播关联商品
- 头部主播带货专场
- 垂类达人推荐商品

### 3. 直播间商品
- 实时在线人数与商品销量关联
- 爆款商品上车时间节点

## 抓取字段说明

| 字段 | 抓取位置 | 备注 |
|------|---------|------|
| 商品名称 | 商品标题 | 直播间展示名称 |
| 价格 | 直播间/商品详情 | 原价、秒杀价区分 |
| 销量 | 带货榜单 | 实时/累计销量 |
| GMV | 带货榜单 | 商品成交额 |
| 关联主播 | 带货记录 | 标注主播名称 |
| 商品分类 | 品类榜单 | 一级/二级类目 |

## 注意事项

1. 抖音数据更新频率高，需标注数据时间戳
2. 直播间商品与商城数据可能存在差异
3. 爆款商品生命周期短，需关注时效性
4. 部分数据需要抖音账号登录
