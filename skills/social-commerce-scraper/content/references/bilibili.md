# B站热销商品抓取指南

## 平台特点

B站（哔哩哔哩）是以ACG内容起家的视频社区，电商业务主要通过：
- 会员购（手办、周边、数码）
- UP主带货推荐
- 会员购热卖榜单

## 推荐数据源

### 1. 会员购热卖榜单
- 路径：APP内「会员购」→「热卖」
- 优势品类：手办、周边、数码3C、动漫衍生品

### 2. UP主带货内容
- 带「商品」标签的视频
- UP主推荐/恰饭视频中的商品

### 3. 会员购分类榜单
- 手办热卖榜
- 周边热卖榜
- 数码热卖榜

## 抓取字段说明

| 字段 | 抓取位置 | 备注 |
|------|---------|------|
| 商品名称 | 商品标题 | 通常包含IP/品牌+品名 |
| 价格 | 商品卡片 | 预售价/现货价区分 |
| 销量 | 热卖榜单 | 榜单显示销量 |
| 预约数 | 手办类商品 | 反映市场热度 |
| 预计发货 | 预售商品 | 标注发货时间 |
| 商品分类 | 会员购类目 | 手办/周边/数码等 |

## 注意事项

1. B站会员购以手办、周边为主，品类相对集中
2. 预售商品需关注发货时间
3. UP主带货数据相对分散，需多维度采集
4. 二次元属性强，用户画像鲜明

## 典型URL格式

```
# 会员购
https://show.bilibili.com

# 商品详情
https://show.bilibili.com/productdetail?pid=xxxxx

# 会员购热卖
https://show.bilibili.com/bangumi
```
