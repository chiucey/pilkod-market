# 具身智能本体硬件专家

## 核心能力概述

具身智能（Embodied AI）是指具有物理身体的智能体通过与环境交互来学习和决策的能力。本技能专注于具身智能硬件系统的全栈技术，从底层电机驱动到上层系统集成，提供专业的技术咨询和解决方案。

### 核心知识领域

- **本体硬件**：机器人构型设计、末端执行器、传感器融合
- **电机系统**：伺服驱动、力矩控制、运动规划
- **结构设计**：轻量化机构、关节设计、材料选型
- **电气工程**：电源系统、信号完整性、安全标准
- **控制器开发**：实时系统、运动控制算法、嵌入式开发
- **系统集成**：标定测试、可靠性验证、量产工艺

```python
# 关节电机选型计算示例
def motor_selection(joint_spec):
    """
    关节规格参数
    """
    # 负载惯量计算（简化模型）
    load_mass = joint_spec['link_mass']  # kg
    link_length = joint_spec['link_length']  # m
    load_inertia = load_mass * link_length**2 / 3  # 简化梁模型

    # 期望加速度
    max_acceleration = joint_spec['max_acceleration']  # rad/s²
    required_torque = load_inertia * max_acceleration

    # 安全系数（考虑关节摩擦、传动损失）
    safety_factor = 2.0
    rated_torque = required_torque * safety_factor

    # 转速需求
    max_velocity = joint_spec['max_velocity']  # rad/s
    gear_ratio = joint_spec.get('gear_ratio', 1)
    motor_rpm_required = max_velocity * gear_ratio * 60 / (2 * 3.14159)

    return {
        'rated_torque': rated_torque,  # N·m
        'max_rpm': motor_rpm_required,
        'inertia_match_ratio': load_inertia / motor_inertia
    }
```

### 2.2 电机驱动技术

#### FOC矢量控制原理

磁场定向控制（FOC）是高性能电机控制的核心技术：

```
FOC控制流程
1. Clark变换：三相电流 → αβ坐标系
2. Park变换：αβ → dq旋转坐标系
3. PI控制：d轴（励磁）/ q轴（转矩）独立控制
4. 反Park变换：dq → αβ
5. SVPWM：空间矢量调制输出三相PWM
```

#### 驱动器关键参数

| 参数 | 低性能方案 | 高性能方案 | 超高性能方案 |
|-----|-----------|-----------|-------------|
| 电流采样精度 | 12-bit | 16-bit | 18-bit |
| PWM频率 | 10-20 kHz | 20-40 kHz | 40-100 kHz |
| 控制周期 | 1-2 ms | 100-500 μs | <100 μs |
| 位置分辨率 | 14-bit encoder | 17-bit encoder | 21-bit encoder |
| 通讯接口 | CAN | EtherCAT | FSOE |

#### 全身运动控制（WBC）

```python
# 全身运动控制基本框架
class WholeBodyController:
    def __init__(self, robot_model):
        self.model = robot_model
        self.task_stack = []  # 任务优先级队列

    def add_task(self, task, priority):
        """添加控制任务"""
        self.task_stack.append({
            'task': task,
            'priority': priority
        })
        # 按优先级排序
        self.task_stack.sort(key=lambda x: x['priority'], reverse=True)

    def compute_control(self, state, desired):
        """
        WBC核心计算
        1. 正运动学/动力学
        2. 任务层级QP求解
        3. 关节力矩分配
        """
        # 关节空间动力学
        M = self.model.mass_matrix(state.q)
        C = self.model.coriolis(state.q, state.qd)
        G = self.model.gravity(state.q)

        # 任务雅可比矩阵
        J_list = [task.jacobian() for task in self.task_stack]
        J_dot = self.model.task_jacobian_dot(state)

        # QP求解：最小化关节加速度/力矩
        H = M.T @ M + rho * I  # 正则化
        f = -M.T @ state.qdd_des

        # 添加任务约束
        for J, task in zip(J_list, self.task_stack):
            # 任务加速度约束
            f += J.T @ task.acceleration_error(state)

        return self.solve_qp(H, f)
```

#### 多传感器标定

# 手眼标定流程（Eye-in-Hand）
def eye_hand_calibration(robot, camera):
    """
    标定相机到末端执行器的齐次变换矩阵
    """
    poses = []
    for i in range(N_poses):
        # 移动机器人到不同姿态
        robot.move_to(calibration_poses[i])

        # 采集标定板位姿
        T_cam_marker = camera.estimate_pose()

        # 记录末端执行器位姿
        T_base_end = robot.forward_kinematics()

        poses.append({
            'base_end': T_base_end,
            'cam_marker': T_cam_marker
        })

    # 手眼标定求解
    T_end_cam = calibrate_eye_hand(poses)
    return T_end_cam
