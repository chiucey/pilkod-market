# 每周资讯整合技能

## 功能概述

本技能自动抓取并整合多类别新闻，生成精美的HTML格式周报，支持下载。

## 数据分类目录

| 序号 | 主类别 | 子类别 | 新闻数量 |
|------|--------|--------|----------|
| 1 | 国内外热点 | - | 10-15条 |
| 2 | 宏观经济 | 国际/国内/地方 | 各5-8条 |
| 3 | 金融 | - | 10-15条 |
| 4 | 股市 | - | 10-15条 |
| 5 | 楼市 | - | 10-15条 |
| 6 | 产业 | 车辆设备/新质生产力/热门产业 | 各4-5条 |

## 执行流程

### 第一步：新闻数据采集

使用网络搜索工具抓取各类别新闻，确保：
- **时间范围**：指令发起时近一周（7天）
- **数据源**：权威媒体（新华社、人民日报、央视新闻、第一财经、财新等）
- **去重规则**：同事件新闻仅保留最完整的一条
- **时效性**：优先最新发布的重大新闻

### 第二步：数据整理与分类

按以下标签结构化每条新闻：
```
{
  "title": "新闻标题",
  "source": "来源媒体",
  "publishTime": "发布时间",
  "summary": "简明摘要(100字内)",
  "impact": "影响标签(利好/利空/中性)",
  "category": "所属类别",
  "url": "原文链接"
}
```

### 第三步：HTML报告生成

生成的HTML报告需包含：
- 报告标题与生成日期
- 各板块导航目录
- 每条新闻的时间、来源、影响标签
- 精美CSS样式，支持打印/下载
- 响应式布局，适配多种设备

## 新闻来源优先级

| 优先级 | 来源 | 类型 |
|--------|------|------|
| 1 | 新华网、人民网 | 官方权威 |
| 2 | 央视新闻 | 官方权威 |
| 3 | 第一财经、财新 | 财经专业 |
| 4 | 证券时报、上海证券报 | 证券专业 |
| 5 | 澎湃新闻、界面新闻 | 综合媒体 |

## 影响标签定义

| 标签 | 含义 | 适用场景 |
|------|------|----------|
| 利好 | 积极正面影响 | 政策利好、业绩增长 |
| 利空 | 消极负面影响 | 监管收紧、行业下行 |
| 中性 | 无明显影响 | 一般资讯、信息披露 |

## 输出规格

- **文件格式**：HTML（单文件，可直接浏览器打开）
- **文件名**：`weekly_news_YYYYMMDD.html`
- **下载方式**：浏览器右键另存为 / 打印功能

## 质量标准

1. 每条新闻必须包含时间、来源标签
2. 避免同一事件的多条相似报道
3. 标题简洁，不超过30字
4. 摘要精炼，突出核心信息
5. HTML排版精美，有良好阅读体验

## 快速执行

当用户请求"生成每周新闻报告"、"生成资讯整合报告"或类似请求时，直接执行本技能，无需额外确认。
