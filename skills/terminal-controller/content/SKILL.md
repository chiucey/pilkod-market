# Terminal Controller Skill

## 核心能力

此技能提供直接的终端控制能力，支持：

### 1. 命令执行
- 执行单个或多个命令
- 支持管道和重定向
- 命令序列执行（使用 `&&` 或 `;`）
- 后台任务执行

### 2. 文件系统操作
- 浏览目录结构
- 创建、读取、编辑、删除文件和目录
- 权限管理
- 文件搜索

### 3. 系统信息
- 查看系统配置
- 监控资源使用（CPU、内存、磁盘）
- 网络状态检查
- 进程管理

### 4. 开发工具
- Git 操作
- 包管理器（pip、npm、apt等）
- 构建工具执行
- 编译器运行

## 使用方法

用户只需直接描述他们想要执行的操作：

```
"运行 ls -la 查看当前目录"
"执行 python script.py"
"安装 nginx"
"查看系统内存使用"
"查找所有 .py 文件"
"运行 git status"
```

## 执行原则

1. **明确性**：使用清晰的风险评估标注
2. **安全性**：
   - 高风险操作（删除系统文件、修改配置）需确认
   - 不执行不可逆的破坏性操作
   - 避免执行来源不明的脚本
3. **透明度**：
   - 说明每个命令的作用
   - 显示完整输出
   - 报告任何错误

## 命令执行格式

每个命令执行时包含：
- **操作说明**：解释将要执行的操作
- **风险等级**：低/中/高
- **完整命令**：显示实际执行的命令
- **结果输出**：命令的 stdout 和 stderr
- **状态报告**：成功/失败及原因

## 常用命令参考

### 文件操作
```bash
ls -la                    # 列出所有文件（含隐藏）
cd <dir> && <command>     # 进入目录后执行
mkdir -p path/to/dir      # 创建目录树
rm -rf <path>             # 递归删除（谨慎使用）
cp -r source dest         # 递归复制
mv source dest            # 移动/重命名
```

### 系统监控
```bash
top                       # 实时进程监控
htop                      # 增强版进程监控
df -h                     # 磁盘使用情况
free -h                   # 内存使用情况
uname -a                  # 系统信息
```

### 网络操作
```bash
ping <host>               # 测试连通性
curl <url>                # HTTP 请求
wget <url>                # 下载文件
netstat -tuln             # 查看监听端口
```

### 开发命令
```bash
git status                # Git 状态
pip install <package>     # 安装 Python 包
npm install               # 安装 Node 依赖
make build                # 项目构建
```

## 错误处理

- **命令不存在**：建议替代方案
- **权限不足**：解释需要的权限
- **执行超时**：提供超时处理选项
- **语法错误**：显示修正建议

## 安全边界

### 禁止执行
- 未经确认的系统配置修改
- 递归删除根目录或系统目录
- 下载和执行来源不明的脚本
- 格式化操作
- 破坏性磁盘操作

### 需要确认的操作
- 删除多个文件
- 安装系统级软件包
- 修改配置文件
- 重启系统服务
- 网络端口扫描

## 输出格式

执行命令后提供结构化输出：

```
[操作] <描述>
[命令] <实际执行的命令>
[风险] <低/中/高>
[状态] <成功/失败>
[输出]
<命令输出内容>
```
