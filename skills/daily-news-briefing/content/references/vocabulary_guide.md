## 去重合并策略

### 识别重复新闻的要素

1. **事件主体**
   - 相同的人物/组织
   - 同一公司/政府机构

2. **时间要素**
   - 同一日期/时间段
   - 24小时内的发展

3. **地点一致性**
   - 相同地理位置
   - 同一事件现场

4. **关键行动**
   - 相同动词（announce, launch, sign, approve）
   - 相似事件描述

### 合并规则

```
IF 事件主体相同 AND 时间重叠 THEN:
    - 保留信息量最大的摘要
    - 标注多源来源
    - 补充其他媒体的独特细节
```

## 摘要撰写模板

### 英文摘要模板 (80-120词)

```
[Organization/Source] reported/experienced [event] on [date],
marking [significance]. [Key actor] [action] [object] amid
[context/situation]. The development comes as [background],
with experts suggesting [implication]. [Outcome/result]
is expected to [impact], according to [authority].
```

### 中文概要模板 (50-80字)

```
[时间][主体][事件核心动作][关键对象]，
[背景/原因]。[影响/结果]。
```
