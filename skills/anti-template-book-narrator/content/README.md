# 反模板化单人讲书引擎

> 一个专为短视频口播设计的反模板化讲书技能，适配抖音/快手2分钟短视频。

## 功能概述

将投资理财/商业认知/财富心理类书籍，改编成极具沉浸感的单人讲书脚本。人设为"亏过钱的金融老炮儿"，面向月薪5k-2w打工人，每期500-700字，预估1分40秒-2分20秒口播时长。

## 核心特色

- **反模板化叙事**：拒绝AI式均匀句式，长短句交替、情绪不对称、允许逻辑断裂
- **7种开局策略**：实盘亏损共情、市场乱象吐槽、反常识结论、生活场景代入、书中极端案例、热搜新闻切入、听众提问切入
- **武器式收尾**：每期结尾递出一件"明天就能用"的行动武器
- **金融内容红线**：零承诺措辞、零具体买卖建议、零收益数字

## 使用方法

1. 提供书名或书籍内容
2. AI自动规划5-10期内容大纲
3. 确认后逐期生成讲书脚本
4. 直接复制粘贴即可口播录制

## 触发词

- 讲书 / 讲书脚本
- 书籍解读 / 读书分享
- 播客脚本 / 讲一本书
- 拆书 / 解读一本书
- 做读书节目

## 适用书籍类型

- 投资理财类
- 商业认知类
- 财富心理类
- 经济通识类

> 非财经类书籍需先确认切入角度，不可强行套用投资框架。
