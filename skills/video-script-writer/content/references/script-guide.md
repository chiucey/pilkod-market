# 视频脚本参考文档

## 常见视频类型脚本要点

### 1. 产品宣传片（30秒-1分钟）
- **结构**: 痛点引入 → 产品亮相 → 功能展示 → 使用场景 → 情感升华
- **节奏**: 快慢结合，重点镜头停留2-3秒
- **景别**: 多用近景和特写，突出产品细节

### 2. 知识科普视频（3-5分钟）
- **结构**: 悬念开场 → 问题解析 → 知识讲解 → 案例验证 → 总结收尾
- **节奏**: 均匀稳定，重点内容重复强调
- **景别**: 中景为主，适当穿插资料画面和动画

### 3. 品牌故事片（1-3分钟）
- **结构**: 情感共鸣 → 品牌理念 → 发展历程 → 社会价值 → 号召行动
- **节奏**: 舒缓大气，情绪层层递进
- **景别**: 大全景建立氛围，特写捕捉情感细节

### 4. 抖音/短视频（15-60秒）
- **结构**: 前3秒抓眼球 → 中间快速信息 → 结尾引导互动
- **节奏**: 快节奏剪辑，每个镜头2-4秒
- **景别**: 竖版构图，近景和特写为主

## 专业术语对照表

| 术语 | 含义 |
|------|------|
| 全景 (Wide Shot) | 展示完整场景，人物占画面1/3 |
| 中景 (Medium Shot) | 膝盖以上，常用于对话 |
| 近景 (Close-up) | 胸部以上，突出表情 |
| 特写 (Extreme Close-up) | 局部细节，如眼睛、手部 |
| 固定 | 镜头不动 |
| 推 | 镜头向前推进 |
| 拉 | 镜头向后拉远 |
| 摇 | 镜头左右旋转 |
| 移 | 镜头跟随运动 |
| 跟 | 镜头跟随主体移动 |

## 分镜脚本模板

```markdown
| 镜号 | 画面描述 | 景别 | 机位/运动 | 时长 | 对白/旁白 | 配乐/音效 | 特效/转场 |
|------|---------|------|-----------|------|----------|----------|----------|
| 1 | 城市天际线航拍，日出时分 | 全景 | 无人机缓慢后退 | 4s | [无] | 轻柔钢琴前奏 | 淡入 |
| 2 | 切换到咖啡馆内景，阳光透过窗户 | 中景 | 固定 | 3s | "每一天，都是新的开始..." | 咖啡馆环境音 | 叠化 |
```

## 常用转场效果

| 转场 | 适用场景 |
|------|---------|
| 淡入/淡出 | 时间过渡，情绪铺垫 |
| 叠化 | 梦境、回忆、柔和过渡 |
| 硬切 | 快节奏、强调、突发 |
| 甩切 | 快速切换，视觉冲击 |
| 滑动 | 空间转移，场景切换 |
