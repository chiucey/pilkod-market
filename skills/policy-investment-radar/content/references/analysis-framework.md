# 投资分析框架参考

## 影响路径模板

### 政策类新闻
```
政策出台 → 财政/货币政策 → 流动性变化 → 行业盈利预期 → 股价变动
```

### 行业政策
```
监管变化 → 行业门槛 → 竞争格局 → 龙头企业优势 → 股价分化
```

### 国际事件
```
地缘政治 → 汇率波动 → 进出口影响 → 产业链重构 → 行业机会
```

## 持续性判断标准

| 分类 | 判断标准 | 典型案例 |
|------|----------|----------|
| 短期 | < 3个月 | 单一事件刺激、季节性波动 |
| 中期 | 3-12个月 | 政策落地周期、行业周期 |
| 长期 | > 12个月 | 产业趋势、人口结构、技术革命 |

## 情绪方向判定

| 类型 | 判定标准 | 信号词 |
|------|----------|--------|
| 利多 | 利好行业盈利、流动性宽松 | 支持、促进、加大、鼓励、宽松 |
| 中性 | 规则调整、影响不确定 | 规范、完善、调整、平衡 |
| 利空 | 收紧、监管加强、成本上升 | 限制、加强、抑制、收紧、打击 |

## 行业分类映射

| 政策方向 | 利好行业 | 利空行业 |
|----------|----------|----------|
| 新能源政策 | 光伏、风电、储能、新能源车 | 传统煤炭、火电 |
| 科技自立 | 半导体、操作系统、芯片 | 依赖进口技术的企业 |
| 消费刺激 | 白酒、食品饮料、家电 | - |
| 房地产调控 | 建材、家电 (间接) | 中小型开发商 |
| 医疗改革 | 创新药、医疗器械 | 仿制药、辅助用药 |
