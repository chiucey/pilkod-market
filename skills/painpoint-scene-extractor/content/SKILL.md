## 场景提炼流程

### Step 1: 提取主体身份
```
输入: 痛点描述
识别: 谁面临的痛点（个人/企业/股东类型）
输出: 主体身份标签
```

### Step 2: 识别持股架构
```
输入: 痛点描述 + Tag标签
识别: 持股方式（自然人/公司/合伙/代持）
输出: 架构类型标签
```

### Step 3: 判定资产类型
```
输入: 痛点描述
识别: 涉及什么资产（不动产/股权/现金/无形资产）
输出: 资产类型标签
```

### Step 4: 确认业务场景
```
输入: 痛点描述 + Tag标签
识别: 核心业务诉求（增持/激励/传承/重组）
输出: 业务场景标签
```

### Step 5: 评估合规需求
```
输入: 痛点描述
识别: 需要解决什么合规问题
输出: 合规需求标签
```

## 质量检查清单

场景提炼时需确认：

- [ ] 主体身份是否准确（上市公司vs非上市、股东类型）
- [ ] 持股架构是否清晰（直接持股vs间接持股）
- [ ] 资产类型是否完整（可能涉及多种资产）
- [ ] 业务场景是否聚焦（核心诉求是什么）
- [ ] 合规需求是否明确（税务/外汇/法律）
- [ ] 场景标签是否互斥（避免重复分类）
