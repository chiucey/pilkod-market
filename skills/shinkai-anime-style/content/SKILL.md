# 新海诚写实二次元风格技能

> **Author**: 起始终下
> **Copyright**: © 2025 起始终下. All Rights Reserved.

---

## 技能定位

本技能将用户的图像需求转化为新海诚写实动漫美学风格的Prompt，专门适配千问系列图像生成模型。

**核心价值**：以照片级天空和光影呈现青春的孤独、美好与命运的交织，让观众感受"风景比人物更会说话"的意境。

---

## 适用场景

### 主要适用场景

| 场景类型 | 具体示例 | 输出特点 |
|---------|---------|---------|
| **天空景观** | 夕阳、云海、星空、流星 | 戏剧性天空渐变 |
| **都市夜景** | 东京街头、霓虹灯光 | 光影繁华与孤独 |
| **浪漫瞬间** | 擦肩而过、仰望天空 | 青春的遗憾美 |
| **自然风景** | 乡下小镇、海边、废墟 | 孤独与美好并存 |
| **雨中场景** | 雨中漫步、避雨时刻 | 情绪渲染氛围 |

### 不适用场景

| 不适用场景 | 原因说明 |
|-----------|---------|
| **纯手绘动漫** | 新海诚风格写实感强，非卡通风 |
| **暗黑恐怖** | 风格唯美浪漫，非恐怖 |
| **激烈动作** | 风格偏静态情绪，非动作片 |
| **CG塑料感** | 追求真实光影质感 |
| **缺乏氛围** | 天空和情绪是核心 |

## 输入要求

### 必填信息

| 信息类型 | 说明 | 示例 |
|---------|------|------|
| **主体** | 主要人物或场景 | "少女站在街头"、"夕阳海边" |
| **天空状态** | 天空是核心元素 | "黄昏"、"星空"、"云海" |
| **情感基调** | 整体情绪 | "孤独"、"期待"、"忧伤" |

### 选填信息

| 信息类型 | 说明 | 缺失时处理 |
|---------|------|-----------|
| **天气状态** | 雨/晴/阴/雪 | 使用夕阳黄昏 |
| **时间设定** | 晨/昏/夜 | 使用黄昏或夜晚 |
| **场景类型** | 都市/自然 | 使用经典东京街头 |
| **情绪细节** | 具体情感 | 使用"孤独与美好" |

### 模糊需求处理

当用户只说"新海诚风格"而无具体描述时，**必须先确认**：

```
了解您需要新海诚写实动漫美学的图像。为了更精准生成，请告诉我：

1. 【主体】画面主要内容是什么？
   - 人物（少女/少年/两人）？
   - 纯场景（天空/城市/自然）？

2. 【天空状态】天空是什么样的？（这是新海诚风格的核心）
   - 黄昏夕照 / 星空流星 / 云海翻涌 / 雨后彩虹？

3. 【情感基调】希望传达什么感受？
   - 孤独与美好 / 命运相遇 / 遗憾错过 / 青春期待 / 忧伤怀旧？

4. 【场景类型】在哪里发生？
   - 东京都市 / 乡下小镇 / 海边 / 废墟？

如需快速开始，我可以按默认方案生成：
【少女仰望黄昏天空，橙粉渐变，孤独期待感，东京街头】
```

## 处理方法

### 核心美学原则

#### 1. 天空系统（核心元素）

| 天空类型 | 描述 | Prompt关键词 |
|---------|------|-------------|
| **夕阳渐变** | 橙粉紫多层渐变 | 夕阳, 橙粉渐变, 紫色云层, 黄昏 |
| **星空** | 满天繁星、银河 | 星空, 银河, 流星, 星云 |
| **云海** | 翻涌云层、宫崎骏式 | 云海, 云朵翻涌, 壮阔 |
| **雨后** | 彩虹、光线穿透 | 雨后, 彩虹, 穿透云层 |
| **蓝调时刻** | 深蓝与暖色 | 蓝调时刻, 冷暖对比 |

## 千问模型Prompt框架

### 框架A：长文叙述式（Qwen-Image-2.0/3.0推荐）

```
【整体定调】
- 画幅：[横幅/竖幅/方形]
- 风格：新海诚写实动漫风格，写实级天空渲染
- 色调：[夕阳橙粉/蓝调冷暖/电光蓝]

【主体描述】
- 人物：[性别、年龄、发型、服饰描述]
- 姿态：[站立/仰望/行走等]
- 表情：[忧伤/期待/平静等]
- 位置：[在场景中的具体位置]

【场景设定】
- 地点：[东京街头/乡下小镇/海边/神社/废墟]
- 时间：[黄昏/夜晚/黎明]
- 天空描写：[具体天空状态，这是核心元素]

【天空渲染】（新海诚风格关键）
- 云层：[具体云彩描写，如"翻涌的积云染成橙红色"]
- 渐变：[具体色彩过渡，如"从橙红到深紫的层次"]
- 光效：[光晕/bokeh/穿透光等]

【光影氛围】
- 光源：[夕阳/灯光/月光]
- 反射：[霓虹倒影/水面反光/玻璃反光]
- 粒子：[光尘/云朵/光芒射线]

【细节层次】
- 前景：[虚化街道元素/飘落物]
- 中景：[人物与主要场景]
- 背景：[详细环境/天空主体]

【情感基调】
- 氛围：[孤独/期待/遗憾/美好]
- 美学：[风景胜于人物, 青春遗憾美]

【约束条件】
- 包含：[必须出现的元素]
- 禁止：[不应出现的元素]
```

### 常见错误修正

| 错误类型 | 原因 | 修正方法 |
|---------|------|----------|
| 天空太"平" | 缺少渐变层次 | 添加"多层渐变""云层染色""色彩过渡" |
| 人物太"卡" | 过于卡通 | 改为"写实渲染""照片级""真实比例" |
| 缺少"情绪" | 没有氛围感 | 添加"孤独""期待""遗憾"等情感词 |
| 缺少"特效" | 没有新海诚特色 | 添加"bokeh""光晕""逆光" |

## 应用示例

### 示例1：擦肩而过

**用户需求**："两人在夕阳下的东京街头擦肩而过"

**生成Prompt（框架A）**：

```
【整体定调】
- 画幅：横幅，2.39:1电影比例
- 风格：新海诚写实动漫风格，照片级天空渲染
- 色调：黄昏橙粉渐变为主

【主体描述】
- 人物1：一位17岁左右的少女，穿着校服裙，
  黑色长发随风飘动，低着头走在街道上
- 人物2：一位同龄的少年，穿着校服，
  与少女方向相反，即将擦肩而过
- 位置：两人在画面中线附近，即将错过

【场景设定】
- 地点：东京繁华街头，傍晚时分
- 时间：黄昏，太阳即将落山
- 前景：飘落的樱花花瓣
- 背景：繁华街道，店铺灯光渐亮

【天空渲染】
- 云层：大范围积云，被夕阳染成橙红色
- 渐变：从画面顶部深蓝渐变到橙红
- 光效：金色阳光斜射，Bokeh散景

【光影氛围】
- 光源：夕阳，温暖的橙色光线
- 反射：地面水洼中的倒影
- 气氛：两人即将错过，遗憾与美好并存

【情感基调】
- 氛围：青春的遗憾美，命运的错过
- 美学：人物只是风景的点缀，情感胜于叙事

【约束条件】
- 包含：两人、擦肩、夕阳东京、樱花
- 禁止：过度浪漫化、人物占主导、缺乏孤独感
```

### 示例2：仰望星空

**用户需求**："少年独自站在乡下草地上仰望星空"

**生成Prompt（框架C）**：

