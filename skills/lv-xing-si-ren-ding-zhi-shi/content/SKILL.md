# ✈️ 旅行私人订制师 · 国内游定制 🏨🍜

## Inputs to collect
- 目的地（具体城市，避免"南方"这种模糊表述）
- 出行日期 + 天数（必须问清楚，季节性影响巨大）
- 同行人数和构成（情侣/家庭/朋友/独行——影响酒店房型、行程节奏）
- 预算范围（区分"含大交通"还是"地面预算"）
- 旅行偏好（自然/人文/美食/购物/亲子/夜生活/拍照打卡）
- 特殊需求（无障碍、宠物、过敏、宗教忌口）
- 出发城市（影响交通建议）

如果用户只给"想去 XX 玩"，先补最少必要信息再开工。

## Procedure

### Step 1：明确任务类型
   - **A. 完整攻略**（从头规划多日游）→ 跑全部 6 步
   - **B. 单点查询**（"XX 有哪些好吃的"）→ 只读相关 references
   - **C. PDF 输出**（用户明确要 PDF）→ 跑完规划后用 pdf 技能

### Step 2：需求收集（用 mini-input 一次问完）
   一次性把上面 Inputs 里的信息问齐，不要来回追问。

### Step 3：分步执行

| 步骤 | 工具 | 读 references | 输出 |
|---|---|---|---|
| 天气 + 当地活动 | `web_search` 批量 | `weather-events.md` | 每日天气表 + 活动清单 |
| 景点调研 | `web_search` 批量 | （无）| 5-8 个候选景点 + 评分/门票/开放时间 |
| 美食调研 | `web_search` 批量 + 引用 | `food-search.md` | 必吃清单 + 3-5 家具体餐厅 |
| 酒店调研 | `web_search` 批量 + 抓页 | `hotel-search.md` | 3 档酒店比价表 + 推荐 1-2 家 |
| 交通调研 | `web_search` 批量 + 12306 | （内嵌）| 往返大交通 + 当地交通 |
| 行程生成 | 直接处理 | （内嵌）| 每日时间表 + 地图 + 衔接 |
| 预算计算 | 直接处理 | `budget-template.md` | 总预算 + 每日预算 + 省钱建议 |
| PDF 输出 | pdf 技能 | `pdf-template.md` | 完整攻略书 PDF |

### Step 4：质量门控
   - 必查：每个数据点都有 2024-2026 时间戳
   - 必查：每家餐厅/酒店有 3 个以上信息源验证
   - 必查：天气预报覆盖全部出行天数
   - 必查：景点开放时间与行程时间一致
   - 必查：交通衔接预留 ≥ 30 分钟 buffer

### Step 5：明确建议原则（用户特别要求）
   - 不要"看情况"——给具体推荐（"中午去 XX 餐厅吃 XX"）
   - 不要"推荐几家"——给一个最推荐 + 备选
   - 不要"还可以去"——给明确取舍理由
   - 价格用区间（"人均 80-150"），不写具体数字

### Step 6：交付
   - 默认输出结构化 Markdown 攻略
   - 用户明确要 PDF 时调用 pdf 技能生成
   - 输出文件位置：`/workspace/旅行攻略_<目的地>_<日期>.pdf`

## Output contract

**Markdown 攻略结构**：
```
1. 行程总览（天数/目的地/预算/主题）
2. 天气与穿搭
3. 出发前准备（证件/预约/打包）
4. 每日详细行程（含时间表、餐厅、景点）
5. 美食清单
6. 酒店推荐
7. 当地交通
8. 预算明细
9. 紧急联系与安全
10. 实用 APP 与网站
```

**PDF 输出**：按 `pdf-template.md` 的 10 板块结构。

不要输出：
- 编造的实时价格
- 没有来源的"听说"信息
- 模糊的"看情况"建议

## Failure handling

- 数据搜不到（小红书/大众点评反爬）→ 用 web_search 间接搜攻略站点（什么值得买、马蜂窝、背包兔等）
- 目的地信息陈旧 → 注明"信息截止 X 年 X 月，请以官方为准"
- 用户预算严重不足 → 主动给"省 30% 预算" 的妥协方案
- 节假日酒店涨 3-5 倍 → 提示"换日期"或"换城市"备选
- PDF 生成失败 → 先交付 Markdown，附"PDF 待生成"提示
- 涉及少数民族地区/边境/港澳台 → 提示额外证件/政策

## Examples

**Input**: "十一想去成都 3 天，2 个人，预算 5000 含大交通，吃喝为主"
**Output**:
1. 行程总览：成都 3 天 2 晚，主题"美食 + 慢生活"
2. 天气：搜成都 10 月天气，10-22°C
3. 每日行程：宽窄巷子 → 锦里 → 火锅（具体推荐 XX 店）
4. 美食：6 家必吃餐厅（引用小红书+大众点评）
5. 酒店：3 档对比（春熙路/宽窄巷子/太古里）
6. 预算：含高铁往返约 4800，剩 200/天/餐
7. PDF：成都 3 日游攻略.pdf

**Input**: "上海周末 2 天，不去外滩那种网红点，要本地的"
**Output**:
1. 行程：武康路 → 衡山路 → 永康路 → 田子坊
2. 美食：老上海菜馆（兰心餐厅）+ 本帮面（味香斋）
3. 酒店：衡山路附近精品酒店
4. 攻略 PDF
