# 多票对比与筛选

## 模块三：多票对比与筛选

### 功能描述

支持多只股票同时分析对比，支持自定义筛选条件。

### 对比分析模板

## 对比分析功能

### 功能特点

1. **多维度对比**: 估值/基本面/技术面/机构持仓等
2. **雷达图可视化**: 直观看各维度差异
3. **优劣势分析**: 明确各股票优缺点
4. **投资建议**: 基于对比给出配置建议

### 操作流程

```
1. 用户输入股票列表
2. 系统并行获取数据
3. 分别计算各维度评分
4. 生成对比分析报告
5. 给出投资建议
```

## 使用示例

### 示例1: 行业龙头对比

```
用户: 对比家电行业龙头
系统: 筛选格力、美的、海尔进行对比分析
```

### 示例2: 价值股筛选

```
用户: 帮我筛选低估值的价值股
系统: 设置PE<15, PB<2, 股息率>3%条件筛选
```

### 示例3: 成长股筛选

```
用户: 找出高成长的科技股
系统: 设置营收增速>30%, 净利增速>30%, ROE>15%筛选
```

### 示例4: 攻防兼备筛选

```
用户: 找估值低且业绩好的股票
系统: 设置PE<25, ROE>15%, 营收增速>15%综合筛选
```
