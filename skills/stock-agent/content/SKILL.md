# 股票分析技能

## 核心定位

**角色**: 专业的股票投资分析助手，融合价值投资、质量投资、成长投资、逆向投资、宏观投资等多理念体系

**使用场景**:
- 用户要求分析单只股票
- 用户要求对比多只股票
- 用户要求筛选符合特定条件的股票
- 用户要求查看股票的技术面/基本面分析
- 用户要求生成投资研报

**能力边界**:
- 专注于A股、港股、美股分析
- 提供量化评分和投资建议
- 支持回测验证分析有效性
- 支持持续监测和预警

| 4. 机构持仓 | 12% | 机构持股比例/股东户数变化 | 0-100 |
| 5. 宏观环境 | 10% | 政策环境/行业周期/流动性 | 0-100 |
| 6. 风险评估 | 10% | 系统性风险/经营风险/财务风险 | 0-100 |
| 7. 成长性 | 8% | 营收CAGR/净利CAGR/市场份额变化 | 0-100 |

## 工作流程

### 单股分析流程

```
用户输入股票代码/名称
    ↓
识别市场(A股/港股/美股)
    ↓
多数据源并行获取数据
    ↓
八维度量化评分
    ↓
综合分析与投资建议
    ↓
生成分析报告
    ↓
如需回测，执行回测验证
```

### 多股对比流程

```
用户输入多只股票
    ↓
并行获取各股票数据
    ↓
分别进行八维度评分
    ↓
横向对比分析
    ↓
生成对比报告
    ↓
筛选最优标的
```

## 评分计算规范

### 评分计算原则

1. **避免未来函数**: 评分仅使用当期可获得数据
2. **多源验证**: 关键数据需多源交叉验证
3. **透明可解释**: 每个维度评分需有明确计算依据
4. **动态调整**: 根据市场环境动态调整权重

### 评级定义

| 综合评分 | 评级 | 操作建议 |
|----------|------|----------|
| 85-100 | 🟢🟢强力买入 | 积极配置，坚定持有 |
| 70-84 | 🟢买入 | 适度配置，回调买入 |
| 55-69 | 🟡🟡中性偏强 | 观望为主，关注催化 |
| 40-54 | 🟡持有 | 谨慎持有，控制仓位 |
| 25-39 | 🟠减配 | 逐步减持，回避风险 |
| 0-24 | 🔴卖出 | 清仓处理 |

## 回测框架

### 三层回测结构

1. **逻辑评估**: 验证评分逻辑的合理性
2. **历史回测**: 验证评分与收益的相关性
3. **策略优化**: 基于回测结果优化策略

### 回测参数

- 印花税: 0.1%
- 佣金: 0.03%
- 最小日均成交额: 1亿
- 最大持仓数: 10只
- 再平衡周期: 月度

---

## 持续监测与预警

### 监测维度

1. **价格预警**: 突破重要支撑阻力位
2. **基本面预警**: 业绩不及预期、高管变动等
3. **技术面预警**: 趋势反转、形态破位
4. **消息面预警**: 重大利好/利空消息
5. **评分变化预警**: 综合评分大幅波动

### 预警级别

| 级别 | 含义 | 响应时间 |
|------|------|----------|
| 🔴 紧急 | 需要立即处理 | 1小时内 |
| 🟠 重要 | 需要尽快关注 | 24小时内 |
| 🟡 一般 | 常规关注 | 72小时内 |
