# 框架与理念

## 核心理念

融合价值投资、质量投资、成长投资、逆向投资、宏观投资等多理念体系，为投资者提供专业、客观、深度的股票分析。

**分析原则**：
- 股票价值是客观的，用数据说话
- 多视角交叉验证，不迷信单一指标
- 长期趋势比短期波动更重要

---

## 8阶段专业尽调框架

本技能采用机构级8阶段尽调框架，对股票进行全面深度的分析：

| 阶段 | 研究重点 | 核心输出 |
|------|----------|----------|
| **1. 公司事实底座** | 公司基本情况 | 产品/营收结构/商业模式/核心优势 |
| **2. 历史财务分析** | 过去5-10年财务表现 | 成长性/盈利能力/资产质量/现金流 |
| **3. 未来业绩测算** | 未来3年业绩预测 | 盈利预测/关键假设/敏感性分析 |
| **4. 估值建模** | DCF/相对估值 | 内在价值/估值区间/安全边际 |
| **5. 竞争格局分析** | 行业地位/竞争对手 | 市场份额/竞争优势/护城河 |
| **6. 风险识别** | 潜在风险评估 | 风险清单/概率评估/影响程度 |
| **7. 投资决策** | 综合研判 | 投资评级/目标价/持有期限 |
| **8. 跟踪监测** | 持续跟踪 | 业绩预警/催化剂追踪/持仓建议 |

## 投资理念融合

### 价值投资要素
- 安全边际原则
- 内在价值评估
- 长期持有理念

### 质量投资要素
- ROE/ROIC分析
- 盈利质量评估
- 管理层质量

### 成长投资要素
- 营收/净利增速
- 市场份额扩张
- 新业务潜力

### 逆向投资要素
- 估值底部识别
- 市场情绪分析
- 拐点信号捕捉

### 宏观投资要素
- 政策环境影响
- 行业周期判断
- 流动性分析

## 分析方法论

### 定量分析
1. **财务指标计算**: ROE、ROIC、PE、PB、PEG等
2. **趋势分析**: 5年/10年历史趋势
3. **同业比较**: 与行业龙头对比
4. **因子分析**: 多因子打分

### 定性分析
1. **商业模式评估**: 可持续性/护城河
2. **竞争格局研判**: 五力模型
3. **管理层评估**: 能力/诚信/激励
4. **行业前景判断**: 成长空间/周期位置

### 综合研判
1. **信息综合**: 定量+定性融合
2. **情景分析**: 乐观/基准/悲观
3. **决策建议**: 评级+目标价+仓位

## 持续迭代机制

- **季报更新**: 基本面数据刷新
- **年度审视**: 战略层面重新评估
- **实时预警**: 重大事项即时提示
