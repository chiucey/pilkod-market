# 持续监测与预警

## 模块一：回测能力

### 功能描述

对历史分析记录进行回测验证，量化AI分析的准确率，持续优化分析质量。

### 回测信号格式

```json
{
  "backtest_signal": {
    "report_id": "xxx",
    "report_date": "2026-04-12",
    "stock_code": "000333.SZ",
    "signal": "BUY",
    "signal_strength": 4,
    "target_price": 85.5,
    "stop_loss": 70.0,
    "analyst_rating": "强力买入",
    "comprehensive_score": 82
  }
}
```

### 回测跟踪指标

| 指标 | 说明 | 计算方式 |
|------|------|----------|
| 胜率 | 盈利交易占比 | 盈利次数/总交易次数 |
| 盈亏比 | 平均盈利/平均亏损 | 总盈利/总亏损绝对值 |
| 最大回撤 | 最大亏损幅度 | 历史最大浮亏 |
| 夏普比率 | 风险调整收益 | (收益-无风险)/波动率 |
| 持有期收益 | 不同周期收益率 | 1月/3月/6月/1年收益 |

### 回测报告格式

```markdown
# 回测报告

## 基础信息

|------|------|
```

## 模块二：持续监测

### 监测维度

1. **价格预警**: 突破重要支撑阻力位
2. **基本面预警**: 业绩不及预期、高管变动等
3. **技术面预警**: 趋势反转、形态破位
4. **消息面预警**: 重大利好/利空消息
5. **评分变化预警**: 综合评分大幅波动

### 监测频率

| 数据类型 | 监测频率 |
|----------|----------|
| 实时价格 | 交易时段实时 |
| 日线技术指标 | 每日收盘后 |
| 基本面数据 | 每周更新 |
| 财务数据 | 季报发布后 |
| 研报数据 | 实时跟踪 |

### 预警级别

| 级别 | 含义 | 响应时间 | 标注 |
|------|------|----------|------|
| 🔴 紧急 | 需要立即处理 | 1小时内 | 红色 |
| 🟠 重要 | 需要尽快关注 | 24小时内 | 橙色 |
| 🟡 一般 | 常规关注 | 72小时内 | 黄色 |
| 🟢 提醒 | 参考信息 | 周报提及 | 绿色 |

## 数据存储

### 监测数据表结构

```sql
CREATE TABLE stock_monitoring (
    id INT PRIMARY KEY AUTO_INCREMENT,
    stock_code VARCHAR(20),
    monitor_date DATE,
    close_price DECIMAL(10,2),
    volume BIGINT,
    change_pct DECIMAL(10,2),
    comprehensive_score DECIMAL(5,2),
    rating VARCHAR(20),
    alert_level VARCHAR(10),
    alert_type VARCHAR(50),
    alert_content TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE backtest_records (
    id INT PRIMARY KEY AUTO_INCREMENT,
    report_id VARCHAR(50),
    stock_code VARCHAR(20),
    signal_date DATE,
    signal_type VARCHAR(20),
    signal_strength INT,
    target_price DECIMAL(10,2),
    stop_loss DECIMAL(10,2),
    entry_price DECIMAL(10,2),
    exit_price DECIMAL(10,2),
    holding_days INT,
    profit_pct DECIMAL(10,2),
    status VARCHAR(20),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

## 预警推送机制

### 推送渠道

1. **即时消息**: 紧急预警实时推送
2. **日报**: 每个交易日收盘后
3. **周报**: 每周一发送上周汇总
4. **月报**: 每月初发送上月分析

### 推送格式

```
📊 [持仓监测日报] 2026-04-12

🌶️ 持仓动态
├── 000333.SZ 美的集团

    ├── 综合评分: 85分(持平)
    └── 评级: 🟢强力买入

⚠️ 预警提醒
└── 暂无紧急预警

📈 本周收益
```

## 持续优化机制

### 月度评审

1. **准确率回顾**: 分析上月评分准确率
2. **权重调整**: 根据回测结果调整维度权重
3. **指标优化**: 调整评分指标和阈值
4. **模型更新**: 更新预测模型参数

### 反馈收集

- 用户反馈收集
- 实际收益追踪
- 模型误差分析
- 持续迭代优化
