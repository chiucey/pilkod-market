# 评分体系（可量化版本）

## 8维度统一评分体系

> **设计原则**: 投行分析模块(分析师预期、盈利预测等)作为第8维度，整合形成完整的8维度评分体系

### 维度权重总览

| 维度 | 权重 | 核心指标 | 评分范围 |
|------|------|----------|----------|
| 1. 估值分析 | 20% | PE/PB/PEG/股息率/安全边际 | 0-100 |
| 2. 基本面分析 | 18% | ROE/ROIC/营收净利增速/现金流 | 0-100 |
| 3. 技术面分析 | 15% | 趋势/动量/波动率/支撑阻力 | 0-100 |
| 4. 机构持仓 | 12% | 机构持股比例/股东户数变化 | 0-100 |
| 5. 宏观环境 | 10% | 政策环境/行业周期/流动性 | 0-100 |
| 6. 风险评估 | 10% | 系统性风险/经营风险/财务风险 | 0-100 |
| 7. 成长性 | 8% | 营收CAGR/净利CAGR/市场份额变化 | 0-100 |
| 8. 投行预期 | 7% | 分析师评级/盈利预测/目标价 | 0-100 |

---

## 维度1: 估值分析 (权重20%)

### 核心指标

| 指标 | 计算方式 | 评分逻辑 |
|------|----------|----------|
| PE_TTM | 市价/近12个月每股收益 | 低于行业均值加分 |
| PE_forward | 市价/预期每股收益 | 低于预期增速加分 |
| PB | 市价/每股净资产 | 低于行业均值加分 |
| PEG | PE/净利润增速 | <1为低估，>2为高估 |
| 股息率 | 股息/股价 | 高于无风险利率加分 |
| 安全边际 | (内在价值-当前价)/内在价值 | 越大越好 |

### 评分规则

```
估值得分 = Σ(各指标得分 × 权重) / Σ权重

- PE_TTM: 低于行业均值20%以上 → 25分；均值附近 → 15分；高于均值20%以上 → 5分
- PEG: <0.5 → 25分；0.5-1 → 20分；1-1.5 → 10分；>1.5 → 5分
- 股息率: >5% → 25分；3%-5% → 20分；1%-3% → 10分；<1% → 5分
- 安全边际: >30% → 25分；20%-30% → 20分；10%-20% → 10分；<10% → 5分
```

## 维度2: 基本面分析 (权重18%)

### 核心指标

| 指标 | 计算方式 | 评分逻辑 |
|------|----------|----------|
| ROE | 净利润/股东权益 | >15%优秀，>10%良好 |
| ROIC | EBIT/投入资本 | >10%优秀 |
| 毛利率 | 毛利/营收 | 越高越有护城河 |
| 净利率 | 净利/营收 | 稳定且高为好 |
| 营收增速 | (本期-上期)/上期 | 增长越快越好 |
| 净利增速 | (本期-上期)/上期 | 增长越快越好 |
| 现金流 | 经营现金流/净利润 | >1为优秀 |

### 评分规则

```
基本面得分 = Σ(各指标得分 × 权重) / Σ权重

- ROE: >20% → 25分；15%-20% → 20分；10%-15% → 12分；5%-10% → 8分；<5% → 3分
- ROIC: >15% → 20分；10%-15% → 15分；5%-10% → 10分；<5% → 5分
- 营收增速: >30% → 20分；20%-30% → 15分；10%-20% → 10分；5%-10% → 5分；<5% → 2分
- 净利增速: >30% → 20分；20%-30% → 15分；10%-20% → 10分；5%-10% → 5分；<5% → 2分
- 现金流/净利: >1.2 → 15分；1-1.2 → 10分；0.5-1 → 5分；<0.5 → 2分
```

## 维度3: 技术面分析 (权重15%)

### 核心指标

| 指标 | 计算方式 | 评分逻辑 |
|------|----------|----------|
| 均线多头 | 短期均线>长期均线 | 多头排列加分 |
| MACD | DIF>DEA | 金叉加分 |
| KDJ | K>80超买 | 适中为好 |
| 布林带 | 价格位置 | 中轨附近适中 |
| 成交量 | 量能变化 | 放量上涨加分 |
| 趋势强度 | ADX指标 | 趋势强加分 |

### 评分规则

```
技术面得分 = Σ(各指标得分 × 权重) / Σ权重

- 均线多头: 完全多头 → 25分；部分多头 → 15分；空头 → 5分
- MACD: 强势金叉 → 20分；普通金叉 → 12分；死叉 → 5分
- 趋势: 上升通道 → 20分；震荡 → 10分；下降通道 → 5分
- 量能: 放量突破 → 20分；温和放量 → 15分；缩量 → 8分；放量下跌 → 5分
```

| 指标 | 计算方式 | 评分逻辑 |
|------|----------|----------|
| 机构持股比例 | 机构持股/总股本 | 越高越稳定 |

```

- 股东户数: 持续减少 → 20分；基本稳定 → 12分；持续增加 → 5分

## 维度5: 宏观环境 (权重10%)

### 核心指标

| 指标 | 分析维度 | 评分逻辑 |
|------|----------|----------|
| 政策环境 | 行业政策/监管 | 利好政策加分 |
| 行业周期 | 周期位置 | 复苏期/成长期加分 |
| 流动性 | 货币政策/利率 | 宽松加分 |
| 汇率 | 人民币汇率 | 稳定或升值加分 |
| 全球环境 | 外盘影响 | 风险偏好高加分 |

### 评分规则

```
宏观环境得分 = Σ(各指标得分 × 权重) / Σ权重

- 政策环境: 强力支持 → 30分；支持 → 22分；中性 → 15分；限制 → 5分
- 行业周期: 复苏/成长早期 → 25分；成长中后期 → 20分；成熟 → 12分；衰退 → 5分
- 流动性: 宽松 → 25分；中性 → 18分；收紧 → 10分
```

## 维度6: 风险评估 (权重10%)

### 核心指标

| 指标 | 计算方式 | 评分逻辑 |
|------|----------|----------|
| 资产负债率 | 总负债/总资产 | 越低风险越小 |
| 流动比率 | 流动资产/流动负债 | >1.5安全 |
| 商誉占比 | 商誉/净资产 | 越低越好 |
| 股权质押 | 质押比例 | 越低越好 |
| 应收账款周转 | 周转天数 | 越短越好 |
| 存货周转 | 周转天数 | 越短越好 |

### 评分规则

```
风险评估得分 = 100 - Σ(各风险指标扣分)

- 资产负债率: <40% → 不扣分；40%-60% → 扣5分；60%-70% → 扣10分；>70% → 扣20分
- 流动比率: >2 → 不扣分；1.5-2 → 扣5分；1-1.5 → 扣10分；<1 → 扣20分
- 商誉占比: <10% → 不扣分；10%-30% → 扣10分；30%-50% → 扣20分；>50% → 扣30分
- 股权质押: <20% → 不扣分；20%-40% → 扣10分；40%-60% → 扣20分；>60% → 扣30分
```

```

- 净利CAGR: >30% → 30分；20%-30% → 25分；15%-20% → 18分；10%-15% → 12分；<10% → 5分

## 维度8: 投行预期 (权重7%)

### 核心指标

| 指标 | 数据来源 | 评分逻辑 |
|------|----------|----------|
| 分析师评级 | 券商研报综合 | 买入/增持加分 |
| 目标价空间 | (目标价-现价)/现价 | 空间大加分 |
| 盈利预测 | 券商预测均值 | 增速高加分 |
| 一致预期 | EPS/PE一致预期 | 偏离度评估 |

### 评分规则

```
投行预期得分 = Σ(各指标得分 × 权重) / Σ权重

- 分析师评级: 强烈买入 → 30分；买入 → 25分；增持 → 20分；中性 → 12分；减持/卖出 → 5分
- 目标价空间: >50% → 30分；30%-50% → 25分；20%-30% → 18分；10%-20% → 12分；<10% → 5分
- 盈利预测分歧: 低分歧 → 20分；中分歧 → 15分；高分歧 → 8分
```

## 综合评分计算

### 公式

```
综合评分 = Σ(各维度得分 × 权重)

综合评分 = 估值分析×20% + 基本面×18% + 技术面×15%
         + 机构持仓×12% + 宏观环境×10% + 风险评估×10%
         + 成长性×8% + 投行预期×7%
```

### 评级映射

| 综合评分 | 评级 | 操作建议 |
|----------|------|----------|
| 85-100 | 🟢🟢强力买入 | 积极配置，坚定持有 |

| 0-24 | 🔴卖出 | 清仓处理 |

## 权重设定依据说明

### 权重设计逻辑

1. **估值(20%)**: 价值投资核心，安全边际是首要考量
2. **基本面(18%)**: 盈利能力和质量是长期收益来源
3. **技术面(15%)**: 择时辅助，但不作为主要依据
4. **机构持仓(12%)**: 专业投资者行为参考
5. **宏观环境(10%)**: 系统性因素影响
6. **风险评估(10%)**: 风险控制是长期生存关键
7. **成长性(8%)**: 成长潜力但非核心考量
8. **投行预期(7%)**: 辅助参考，不是主要依据

### 权重调整原则

- **熊市**: 提高估值和风险评估权重
- **牛市**: 提高成长性和技术面权重
- **行业特性**: 成长股提高成长性权重，价值股提高估值权重
