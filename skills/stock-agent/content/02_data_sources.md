# 数据来源与时效性

## 数据来源规范

| 数据类型 | 主要来源 | 延迟 | 可靠性 | 说明 |
|----------|----------|------|--------|------|
| 实时价格 | Baostock / akshare / 港交所 | <3秒 | 高 | 多源验证 |
| 技术指标 | Baostock / akshare / 同花顺 | 分钟级 | 高 | 基于实时价格计算 |
| 基本面数据 | **Baostock** / 公司公告 / Wind | 日更 | 高 | 财报发布后更新 |
| 财务数据 | **Baostock** / 同花顺 / 东方财富 | 日更 | 高 | 历史+最新财报 |
| 机构持仓 | 基金季报 / 上市公司公告 | 季更 | 高 | 季度末后15个工作日 |
| 宏观数据 | 国家统计局 / 央行 | 月/季更 | 高 | 官方权威发布 |
| 行业数据 | 行业协会 / 第三方研究 | 不定 | 中 | 参考使用 |
| 研报数据 | 券商研报 / wind | 不定 | 中高 | 需多源验证 |

## 数据源优先级

### A股数据源
1. **Baostock** (首选)
   - 优点: 无需注册，稳定可靠，免费使用
   - 数据: 日线/分钟线/财务数据/个股资料
   - 地址: https://www.baostock.com

2. **akshare** (备用)
   - 优点: 数据全面，接口丰富
   - 数据: 股票/基金/债券/期货/期权
   - 安装: pip install akshare

3. **新浪财经** (实时行情补充)
   - 优点: 实时性强
   - 用途: 盘中实时行情

### 港股数据源
1. **akshare** (首选)
   - 数据: 实时行情/历史K线/财务数据

2. **港交所** (官方数据)
   - 用途: 公告/股本结构

### 美股数据源
1. **akshare** (首选)
   - 数据: 实时行情/历史数据/基本面

2. **Yahoo Finance** (备用)
   - 用途: 补充数据/验证

## 数据时效性管理

### 实时数据
- **交易时段**: 实时推送
- **非交易时段**: 显示最新收盘价
- **港股**: 9:30-12:00, 13:00-16:00 (北京时间)
- **美股**: 夏令时 21:30-次日4:00，冬令时 22:30-次日5:00 (北京时间)

### 日线数据
- **收盘后**: 16:00-17:00 更新(A股)
- **复权处理**: 前复权为默认选项

### 财务数据
- **季报**: 季度结束后15个工作日内
- **半年报**: 8月31日前
- **年报**: 4月30日前
- **数据调整**: 财报更正时同步更新

---

## 数据质量控制

### 多源交叉验证
1. 关键数据(如PE、ROE)需至少两个数据源验证
2. 数据差异超过5%需标记并说明
3. 以Baostock数据为准，akshare作为验证

### 异常值处理
1. 识别数据异常: 超出合理范围
2. 数据修正: 参考历史均值
3. 标注说明: 明确标注异常数据

### 数据缓存策略
- **实时数据**: 不缓存
- **日线数据**: 缓存24小时
- **财务数据**: 缓存1周
- **研报数据**: 缓存实时更新

## API调用规范

### Baostock 示例
```python
import baostock as bs

# 登录
lg = bs.login()

# 查询日线数据
rs = bs.query_history_k_data_plus(
    "sh.600519",  # 股票代码
    "date,code,open,high,low,close,volume",
    start_date='2024-01-01',
    end_date='2024-12-31',
    frequency="d"
)

# 登出
bs.logout()
```

### akshare 示例
```python
import akshare as ak

# 实时行情
df = ak.stock_zh_a_spot_em()

# 历史行情
df = ak.stock_zh_a_hist(
    symbol="000333",
    period="daily",
    start_date="20240101",
    end_date="20241231"
)
```

| 标注 | 含义 |
|------|------|
| 🟢 新鲜 | 数据在24小时内更新 |
| 🟡 一般 | 数据在1周内更新 |
| 🔴 过期 | 数据超过1个月未更新 |
