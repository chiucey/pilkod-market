## 导出功能实现

### Markdown导出
```python
def export_markdown(report_content, filename):
    """导出为Markdown格式"""
    with open(f"{filename}.md", "w", encoding="utf-8") as f:
        f.write(report_content)
```

### PDF导出
```python
def export_pdf(markdown_file, output_file):
    """Markdown转PDF"""
    # 使用markdown和weasyprint
    md = markdown.Markdown()
    html = md.convert(markdown_file)
    PDF(filename=output_file).write_cell(html)
```

### Word导出
```python
def export_docx(markdown_file, output_file):
    """Markdown转Word"""
    # 使用pandoc
    os.system(f"pandoc {markdown_file} -o {output_file}")
```

### HTML导出
```python
def export_html(markdown_file, output_file):
    """Markdown转HTML"""
    md = markdown.Markdown(extensions=['tables', 'toc'])
    html = md.convert(markdown_file)
    # 添加样式
    styled_html = add_css_style(html)
    with open(output_file, "w") as f:
        f.write(styled_html)
```
