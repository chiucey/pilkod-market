## 报告基础信息

| 字段 | 说明 | 必填 | 示例 |
|------|------|------|------|
| report_id | 报告唯一标识(UUID) | 是 | rpt_20260412_001 |
| report_date | 报告生成时间 | 是 | 2026-04-12 10:30:00 |
| data_source | 主数据源 | 是 | Baostock |
| data_freshness | 数据新鲜度 | 是 | 🟢 最新 |
| stock_code | 股票代码 | 是 | 000333.SZ |
| stock_name | 股票名称 | 是 | 美的集团 |
| market | 市场 | 是 | A股 |
| analysis_version | 分析版本 | 是 | v2.6 |
