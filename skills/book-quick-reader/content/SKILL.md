# 书籍速读

快速为用户提取一本书的核心内容，按照标准化的结构输出阅读指南。支持多种文件格式和在线书名查询。

## 支持的输入格式

| 格式类型 | 输入方式 | 处理方式 |
|----------|----------|----------|
| **在线书名** | 书名如《原子习惯》 | 搜索+网络信息提取 |
| **EPUB** | 上传 .epub 文件 | 解析 XML 结构 |
| **MOBI/AZW3** | 上传 .mobi/.azw3 文件 | 解析结构化内容 |
| **PDF** | 上传 .pdf 文件 | 提取文本+页码 |
| **DOCX** | 上传 .docx 文件 | 解析 XML 内容 |
| **TXT/纯文本** | 上传 .txt 或粘贴文本 | 直接处理 |

## 执行流程

### 步骤 1：识别输入类型并提取内容

#### A. 在线书名（默认）
1. 使用网络搜索查询书籍信息
   - 搜索词：`书名 豆瓣评分 作者 出版社`
   - 同时获取书籍基本信息和评分
2. 使用搜索结果中的书籍介绍补充内容

#### B. EPUB 文件
1. 读取 .epub 文件内容（ZIP 格式，包含 XML/HTML 文件）
2. 解析 OPF 文件获取元数据（书名、作者、出版信息）
3. 按阅读顺序解析 HTML/XHTML 章节内容
4. 提取 TOC 目录结构

#### C. MOBI/AZW3 文件
1. 解析 MOBI 格式头部结构
2. 提取 docx/HTML 内容流
3. 解析 EXTH 头获取元数据
4. 按章节顺序处理内容

#### D. PDF 文件
1. 使用 `extract_pdfs_full_content` 或 `extract_pdfs_key_info` 提取全文
2. 识别章节标题（字号、样式变化）
3. 记录页码与内容的对应关系

#### E. DOCX 文件
1. 解析 document.xml 获取正文内容
2. 从 core.xml 获取元数据
3. 按段落和标题层级重建章节结构

#### F. TXT/纯文本
1. 直接读取文本内容
2. 识别章节标题模式（数字编号、特殊符号分隔）
3. 按行或段落进行结构化处理

### 步骤 2：获取书籍信息

1. **豆瓣评分**（仅在线书名）
   - 搜索查询：`书名 site:douban.com 豆瓣`
   - 提取评分（满分10分）和评价人数

2. **书籍基本信息**（从文件元数据或搜索结果获取）
   - 书名
   - 作者
   - 出版社
   - 出版年份
   - 总页数/章节数

### 步骤 3：核心内容概括

用 300-500 字概括整本书的核心内容：
- 书籍的主要主题
- 作者的核心观点
- 书籍要解决的核心问题
- 主要结论或建议

### 步骤 4：章节结构梳理

按照书籍原有的章节结构，逐章处理：

对于每个章节：
1. **章节标题**（如支持，标注页码：第三章 习惯的四大定律 P.45）
2. **章节一句话概括**：用一句话说明本章核心内容
3. **关键段落提取**：选取 3-5 个重要段落，每个段落用一句话概括

### 步骤 5：重点标记

在输出中用标记符号区分章节重要性：

| 标记 | 含义 | 阅读时间占比 |
|------|------|-------------|
| ⭐⭐⭐ | 核心章节，必须精读 | 60% |
| ⭐⭐ | 重要章节，建议细读 | 30% |
| ⭐ | 辅助章节，可快速浏览 | 10% |

**标记依据**：
- 内容与核心主题的相关度
- 读者评价和推荐程度
- 实践价值和可操作性

## 输出格式

```markdown
# 《书名》速读指南

## 📊 书籍信息
- **豆瓣评分**：X.X / 10（X万人评价）[仅在线书名显示]
- **作者**：[作者名]
- **出版社**：[出版社]
- **出版年份**：[年份]
- **格式来源**：[EPUB/PDF/DOCX/TXT/在线书名]
- **章节总数**：[X] 章

## 📖 核心内容概括

[300-500字的核心内容概括]

---

## 📚 章节速读

### ⭐⭐⭐ 第一部分：核心习惯

#### 第一章 基础知识
**章节一句话概括**：[用一句话说明本章核心]

**关键内容**：
- [段落1核心]（P.XX 或 位置信息）
- [段落2核心]（P.XX 或 位置信息）
- [段落3核心]（P.XX 或 位置信息）

---

### ⭐⭐ 第二部分：实践应用

[以相同结构继续]

---

### ⭐ 第三部分：进阶策略

[以相同结构继续]

---

## 🎯 阅读建议

1. **优先阅读**：先读 ⭐⭐⭐ 标记的章节
2. **时间分配**：
   - 核心章节：60% 阅读时间
   - 重要章节：30% 阅读时间
   - 辅助章节：10% 阅读时间
3. **实践结合**：边读边思考如何应用书中原则
4. **笔记建议**：重点记录 ⭐⭐⭐ 章节中的核心观点
```

## 注意事项

1. **页码标注**：
   - PDF：精确页码（如 P.45）
   - EPUB/MOBI：按位置百分比或估算页码
   - DOCX/TXT：标注段落编号或行号
   - 在线书名：基于常见版本估算

2. **结构还原**：严格按照原书章节顺序，保持逻辑连贯

3. **价值判断**：根据内容判断章节重要性，给出合理标记

4. **概括精准**：每个段落的概括要准确反映原文含义

5. **格式兼容**：不同格式采用最适合的提取策略

6. **内容完整性**：确保提取内容覆盖全书 90% 以上章节
