# 巴菲特与芒格价值投资核心理念

## 巴菲特投资哲学

### 核心理念
1. **买股票就是买公司** - 股票不仅是一张纸，而是企业所有权的凭证
2. **市场先生** - 市场每天报价，要利用其情绪波动而非被其左右
3. **安全边际** - 只在价格显著低于内在价值时买入
4. **能力圈原则** - 只投资自己真正理解的行业

### 选股标准
- **业务简单易懂**
- **长期稳定的盈利历史**
- **有宽护城河（竞争优势）**
- **管理层诚实有能力**
- **价格合理**

### 护城河类型
1. 无形资产（品牌、专利、政府许可）
2. 转换成本
3. 网络效应
4. 成本优势（规模经济）

## 芒格投资智慧

### 逆向思维
> "我只想知道我会死在哪里，然后永远不去那里。"

### 多元思维模型
芒格强调要用多个学科的框架来分析投资：
- 心理学（理解人类行为）
- 经济学（理解供需和竞争）
- 会计学（理解财务数据）
- 数学（概率和赔率思维）

### 投资检查清单
- 这个公司是否有持久的竞争优势？
- 管理层是否理性、坦诚、以股东利益为重？
- 管理层是否在自己的能力圈内？
- 价格是否具有安全边际？

## 关键财务指标

### 盈利能力指标
- ROE > 15% 持续多年
- ROIC（投资资本回报率）> WACC（加权平均资本成本）
- 毛利率稳定或上升
- 净利率具有竞争力

### 现金流指标
- 经营现金流持续为正
- 自由现金流 = 经营现金流 - 资本支出 > 0
- 净利润与经营现金流匹配

### 财务健康指标
- 资产负债率适中（非金融企业 < 50%）
- 利息保障倍数 > 5倍
- 没有大量的短期债务

## 安全边际计算方法

### 1. DCF估值
估算未来10年自由现金流，折现到现值

### 2. 清算价值法
假设公司明天破产，所有资产能卖多少钱

### 3. 相对估值法
与历史估值和行业平均比较

**安全边际建议**：至少30%的折扣
