# 政府采购类投标文件模板

## 适用场景
- 机关事业单位办公设备采购
- 政府采购服务项目
- 教育、医疗系统采购

## 特点
- 格式规范严格
- 资质要求明确
- 价格分权重较高

## 使用说明
使用此模板时，请根据实际招标要求调整以下内容：
1. 项目名称和编号
2. 采购需求参数
3. 资质和业绩要求
4. 报价明细

# 投标文件示例内容

## 第一章 投标函

```
投 标 函

[采购单位名称]：

一、我方已仔细研究了[项目名称]（编号：[XX]）招标文件的全部内容，愿意以人民币（大写）_______________元（RMB¥__________）的投标总报价，提供招标文件约定货物/服务。

二、我方承诺本投标报价包含所有费用，包括但不限于货物价格、税费、运输费、安装费、培训费等。

三、如我方中标，我方承诺：
   （1）在收到中标通知书后30日内签订合同；
   （2）按照合同约定的时间和数量供货/提供服务；
   （3）提供招标文件要求的质量保证和售后服务。

四、我方同意本投标函在招标文件规定的投标有效期90天内有效。

五、我方声明：我方具有履行合同所必需的设备和专业技术能力，所投产品符合国家相关标准。

投标人（盖章）：_________________
法定代表人或委托代理人（签字）：_________________
日期：______年______月______日
```

## 投标文件封装说明

### 正本要求
- 1份正本，使用A4纸打印
- 左侧装订，装订线宽度不小于15mm
- 逐页加盖公章
- 逐页签字（法人代表或授权代理人）

### 副本要求
- ____份副本，内容与正本一致
- 封面注明"副本"字样

### 电子文件
- U盘存储，PDF格式
- 内容与纸质文件一致
- U盘置于正本内

### 外层包装
- 外层使用专用封条
- 封面注明：项目名称、招标编号、投标人名称
- 封口处加盖投标人公章
