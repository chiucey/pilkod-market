# 标书制作技能

智能分析招标公告，自动匹配标书模板，生成专业投标文件。

## 核心能力

1. **招标公告解析** - 提取关键信息：项目名称、采购单位、资质要求、技术规格、评分标准、截止时间
2. **模板智能匹配** - 根据行业类型、采购方式识别最佳标书模板
3. **应标文件生成** - 基于招标要求填充模板，生成完整投标文件

## 工作流程

### 步骤1：上传招标公告

用户可提供以下形式的招标信息：
- 完整的招标公告文本
- PDF/Word格式的招标文件
- 招标公告链接（系统将提取内容）

**提取的关键信息清单：**
```
- 项目基本信息：名称、编号、采购单位
- 采购需求：货物/服务/工程类型、数量、规格
- 资质要求：资质证书、业绩要求、人员要求
- 评分办法：技术分/商务分权重、评审细则
- 投标要求：保证金、履约要求、合同条款
- 时间节点：报名截止、投标截止、开标时间
```

### 步骤2：匹配套餐书模板

系统根据招标公告特征自动推荐模板：

| 招标类型 | 推荐模板 | 适用场景 |
|---------|---------|---------|
| 政府采购 | 政府采购买家型 | 机关单位、教育、医疗 |
| 工程建设 | 工程建设投标书 | 建筑、安装、装饰 |
| IT信息化 | IT项目投标方案 | 软件开发、系统集成 |
| 货物采购 | 货物类投标文件 | 设备、材料、办公用品 |
| 服务类 | 服务类投标方案 | 咨询、物业、运输 |

**模板组成结构：**
```
标准标书模板包含：
├── 投标函/投标函附录
├── 法人代表证明/授权委托书
├── 投标保证金
├── 资格审查文件
│   ├── 营业执照/资质证书
│   ├── 财务状况
│   ├── 业绩证明
│   └── 人员配置
├── 投标报价单
├── 技术标/服务方案
│   ├── 项目理解
│   ├── 实施方案
│   ├── 质量保证
│   ├── 进度计划
│   └── 应急预案
├── 商务标
│   ├── 公司简介
│   ├── 资质荣誉
│   └── 业绩案例
└── 合同条款响应
```

### 步骤3：生成应标文件

**智能填充规则：**

1. **资质匹配检查**
   - 比对招标资质要求与自身资质
   - 标注缺失项，提醒补充
   - 自动调整业绩描述以匹配要求

2. **技术方案定制**
   - 根据技术规格调整响应内容
   - 突出与招标要求的对应关系
   - 量化技术指标承诺

3. **报价策略建议**
   - 分析预算与市场行情
   - 提供报价区间建议
   - 自动生成报价明细表

4. **评分点对点响应**
   - 逐条对应评分细则
   - 生成评分点应答矩阵
   - 优化技术方案以获取高分

### 步骤4：输出与交付

**生成文件格式：**
- Word格式（.docx）- 可编辑版本
- PDF格式（.pdf）- 正式提交版

**自动生成文件清单：**
```
投标文件/
├── 封面.docx
├── 目录.docx
├── 投标函.docx
├── 法人授权书.docx
├── 资格审查文件.docx
├── 投标报价单.docx
├── 技术投标书.docx
├── 商务标书.docx
└── 封装清单.docx
```

## 使用示例

### 示例1：工程类投标

**输入：**
用户粘贴招标公告，包含某教学楼装修工程招标信息

**系统处理：**
1. 解析项目类型：工程建设-建筑装饰
2. 匹配模板：工程建设投标书
3. 提取关键需求：资质要求（二级建造师）、工期（90天）、预算（500万）
4. 智能填充模板内容

**输出：**
完整的教学楼装修工程投标文件，包含施工方案、人员配置、进度计划等

### 示例2：IT项目投标

**输入：**
用户提供智慧校园系统集成项目招标公告

**系统处理：**
1. 解析项目类型：IT信息化-系统集成
2. 匹配模板：IT项目投标方案
3. 提取技术要求：系统架构、安全等级、集成标准
4. 生成技术方案和实施计划

**输出：**
智慧校园投标方案，包含系统设计、实施路线、运维保障

## 注意事项

1. **信息完整性** - 提供的招标公告信息越完整，生成的标书质量越高
2. **资质核实** - 生成的标书需人工核实资质匹配情况
3. **合规性检查** - 最终提交前需检查文件格式、签字盖章要求
4. **时间预留** - 建议预留足够时间进行人工审核和修改

## 适用限制

- 本技能生成的标书为初稿，需人工审核确认
- 不提供虚假资质或业绩信息
- 不代替专业的标书撰写服务
- 涉及重大项目的标书建议咨询专业人士
