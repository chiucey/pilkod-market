# 评分标准响应矩阵模板

## 一、评分标准分类

### 1.1 常见评分方式

| 评分方式 | 特点 | 适用场景 |
|---------|------|---------|
| 综合评分法 | 技术+商务+价格综合评定 | 复杂项目 |
| 最低价中标 | 价格最低者中标 | 标准化项目 |
| 性价比法 | 价格/技术指标比值 | 设备采购 |
| 技术评分最低价 | 技术达标后比价格 | 工程建设 |

### 1.2 分值权重分布

| 项目类型 | 技术分 | 商务分 | 价格分 |
|---------|-------|-------|-------|
| 工程建设 | 50-70% | 10-20% | 20-30% |
| IT项目 | 60-80% | 10-15% | 10-20% |
| 货物采购 | 30-50% | 15-25% | 30-50% |
| 服务类 | 40-60% | 20-30% | 15-25% |
| 政府采购 | 30-60% | 10-20% | 20-40% |

## 三、技术评分要点详解

### 3.1 项目理解评分要点

| 评审要点 | 评分细则 | 撰写建议 |
|---------|---------|---------|
| 项目背景理解 | 0-5分 | 准确描述项目背景，体现对项目的深入了解 |
| 需求分析 | 0-5分 | 逐条对应招标需求，体现针对性 |

**高分要点：**
- 引用招标公告中的关键信息
- 分析项目实施的重要意义
- 提出独到见解

### 3.2 技术方案评分要点

| 评审要点 | 评分细则 | 撰写建议 |
|---------|---------|---------|
| 技术路线 | 0-8分 | 技术路线先进、合理、可操作 |
| 方案完整性 | 0-12分 | 覆盖所有技术要求，内容详实 |
| 创新点 | 0-5分 | 体现技术优势和创新 |
| 可行性 | 0-5分 | 方案切实可行，风险可控 |

**高分要点：**
- 技术选型有充分依据
- 方案与需求高度匹配
- 突出企业技术优势

### 3.3 实施计划评分要点

| 评审要点 | 评分细则 | 撰写建议 |
|---------|---------|---------|
| 进度计划 | 0-5分 | 计划合理，有甘特图 |
| 工期承诺 | 0-5分 | 工期满足或优于招标要求 |
| 保障措施 | 0-5分 | 有具体的进度保障措施 |

### 3.4 人员配置评分要点

| 评审要点 | 评分细则 | 撰写建议 |
|---------|---------|---------|
| 项目经理 | 0-5分 | 资历深、类似经验多 |
| 技术负责人 | 0-5分 | 技术职称高、经验丰富 |
| 团队配置 | 0-5分 | 专业齐全、结构合理 |

**高分要点：**
- 提供人员证书和社保证明
- 突出类似项目经验
- 人员稳定性承诺

## 五、价格评分计算

### 5.1 价格分计算公式

**常用公式一（最低价法）：**
```
价格分 = (评标基准价 / 投标报价) × 价格总分
```

**常用公式二（平均价法）：**
```
价格分 = (1 - |投标报价 - 平均价| / 平均价) × 价格总分
```

**常用公式三（合理低价法）：**
```
价格分 = 基准分 - (投标报价 - 合理低价) / 基准价 × 扣减系数
```

### 5.2 报价策略建议

| 策略 | 适用场景 | 操作方法 |
|-----|---------|---------|
| 最低价中标 | 竞争激烈，薄利多销 | 压低利润，争取最低价 |
| 平衡报价 | 综合评分项目 | 技术标+价格平衡 |
| 策略报价 | 后续项目机会 | 牺牲本项目，获取入场券 |
| 精准报价 | 熟悉的领域 | 接近预算上限报价 |
