# 标准投标文件结构与编写指南

## 一、投标文件组成

### 1.1 封面格式
```
[项目名称]投标文件
投标人：[公司全称]
日期：[YYYY年MM月DD日]
```

### 1.2 目录结构
```
第一章 投标函及投标函附录
第二章 法人代表证明或授权委托书
第三章 投标保证金
第四章 资格审查文件
第五章 投标报价
第六章 技术标
第七章 商务标
第八章 其他材料
```

---

## 二、投标函部分

### 2.1 投标函格式

```
投 标 函

[采购单位名称]：

1、我方已仔细研究了[项目名称]招标文件的全部内容，愿意以人民币（大写）_______________元（RMB¥__________）的投标总报价，按招标文件约定的条款和条件，承担本项目。

2、如我方中标，我方承诺：
   （1）在收到中标通知书后，按照招标文件和中标通知书的要求签订合同；
   （2）按照合同约定完成项目内容；
   （3）提供招标文件要求的所有服务。

3、我方同意本投标函在招标文件规定的提交投标文件截止期后90天内有效。如我方中标，有效期将延至合同执行完毕之日。

4、我方声明：所递交的投标文件及有关材料真实有效，如有虚假，我方愿承担相应法律责任。

投标人（盖章）：_________________
法定代表人或委托代理人（签字）：_________________
日期：______年______月______日
```

### 2.2 投标函附录

| 序号 | 内容 | 约定条款 |
|-----|------|---------|
| 1 | 项目负责人 | [姓名] |
| 2 | 工期/供货期 | [日历天/月] |
| 3 | 质量标准 | 合格/优良 |
| 4 | 投标有效期 | [天数]天 |
| 5 | 履约保证金 | [金额/比例] |
