# 招标类型分类与模板匹配指南

## 一、政府采购类

### 1.1 政府采购（机关单位）
- **适用场景**：办公设备、后勤服务、咨询服务
- **模板特点**：格式规范、响应明确、价格导向
- **评分特点**：价格分权重较高（通常30-60%）

### 1.2 教育系统采购
- **适用场景**：教学设备、校园信息化、后勤物业
- **模板特点**：技术参数详细、售后服务要求高
- **评分特点**：技术分与价格分均衡

### 1.3 医疗系统采购
- **适用场景**：医疗设备、药品采购、后勤服务
- **模板特点**：资质要求严格、质量标准明确
- **评分特点**：产品质量和资质权重高

## 二、工程建设类

### 2.1 房屋建筑
- **适用场景**：新建、扩建、改建工程
- **模板结构**：施工组织设计为核心
- **评分特点**：业绩和项目经理权重高

### 2.2 装饰装修
- **适用场景**：室内装修、外墙改造
- **模板结构**：工艺方案、材料清单
- **评分特点**：施工方案和报价综合评定

### 2.3 市政工程
- **适用场景**：道路、桥梁、管网
- **模板结构**：技术标为主
- **评分特点**：企业资质和业绩要求高

### 2.4 园林绿化
- **适用场景**：景观工程、养护服务
- **模板结构**：绿化方案、养护计划
- **评分特点**：方案创意与报价结合

## 三、IT信息化类

### 3.1 软件开发
- **适用场景**：应用系统定制开发
- **模板结构**：需求理解、技术架构、开发计划
- **评分特点**：技术方案和实施能力权重高

### 3.2 系统集成
- **适用场景**：智慧城市、网络建设、数据中心
- **模板结构**：系统设计、设备配置、集成方案
- **评分特点**：产品选型和实施方案并重

### 3.3 运维服务
- **适用场景**：IT运维、数据安全、云服务
- **模板结构**：服务范围、响应机制、团队配置
- **评分特点**：服务能力和价格综合评定

## 四、货物采购类

### 4.1 办公设备
- **适用场景**：电脑、打印机、办公家具
- **模板结构**：产品参数、供货方案、售后服务
- **评分特点**：性价比导向

### 4.2 专用设备
- **适用场景**：生产设备、科研仪器
- **模板结构**：技术规格、检测报告、培训计划
- **评分特点**：技术指标和资质要求严格

### 4.3 物资材料
- **适用场景**：建材、五金、耗材
- **模板结构**：产品清单、价格报价、质量保证
- **评分特点**：价格竞争激烈

## 五、服务类

### 5.1 物业管理
- **适用场景**：商业楼宇、住宅小区、学校医院
- **模板结构**：服务方案、人员配置、应急预案
- **评分特点**：服务方案和管理能力权重高

### 5.2 保安服务
- **适用场景**：安保派遣、押运服务
- **模板结构**：人员配置、培训计划、管理制度
- **评分特点**：资质和经验要求高

### 5.3 保洁服务
- **适用场景**：日常保洁、深度清洁、开荒保洁
- **模板结构**：服务标准、人员配置、设备清单
- **评分特点**：服务标准和价格综合

### 5.4 咨询服务
- **适用场景**：审计、评估、规划设计
- **模板结构**：项目理解、研究方法、团队配置
- **评分特点**：团队能力和业绩权重高

## 模板匹配决策树

```
招标公告
  │
  ├─ 工程建设 → 工程项目模板
  │     ├─ 房屋建筑 → 建筑施工标书
  │     ├─ 装饰装修 → 装修工程标书
  │     └─ 市政园林 → 市政园林标书
  │
  ├─ IT项目 → IT项目模板
  │     ├─ 软件开发 → 软件开发标书
  │     ├─ 系统集成 → 集成方案标书
  │     └─ 运维服务 → 运维服务标书
  │
  ├─ 货物采购 → 货物采购模板
  │     ├─ 办公设备 → 办公设备标书
  │     └─ 专用设备 → 专用设备标书
  │
  ├─ 服务类 → 服务类模板
  │     ├─ 物业服务 → 物业服务标书
  │     └─ 咨询服务 → 咨询服务标书
  │
  └─ 政府采购 → 政府采购模板
        ├─ 通用采购 → 综合投标文件
        └─ 专用采购 → 行业特标书
```

## 模板选择关键要素

1. **采购方式识别**
   - 公开招标 → 完整投标文件
   - 竞争性磋商 → 响应文件+报价
   - 单一来源 → 议价方案

2. **预算金额判断**
   - 大额项目 → 详细技术方案
   - 小额项目 → 简化商务文件

3. **行业特性匹配**
   - 制造业 → 产品质量为核心
   - 服务业 → 服务方案为核心
   - 建筑业 → 资质业绩为核心

4. **评分标准适配**
   - 价格导向 → 报价为核心
   - 综合评分 → 方案与价格平衡
   - 技术导向 → 技术方案为核心
