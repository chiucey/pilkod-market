# 五级标题规范与质检细则

## 标题层级格式

```
一级：第一章
二级：第一节
三级：一、
四级：（一）
五级：1. （每个四级下的五级独立重置，从1开始）
如仍需更细：（1）（2）……
```

## 标题字数约束

- 每级标题：**8-20个汉字**
- 五级标题下如仍需标题：用（1）（2）……

## 某级标题下内容不足300字：不设该级标题，直接写正文

## 节内标题数量

- 四级标题：每节 **5-15个**（按内容体量自然分布，不强制等分）
- 五级标题：每个四级下 **1-4个**（核心重点充分展开，概述类2个足够）
- 严禁每节四级数量完全相同、每四级下五级数量完全相同的机械化结构

## 字数估算原则

每节约8000-10000字：
- 3节章 ≈ 2.4-3万字（中等难度）
- 4节章 ≈ 3.2-4万字（内容丰富）
- 5节章 ≈ 4-5万字（重点篇核心章节）

标题细化深度：
- 每节约3-5个三级标题
- 每个三级下1-3个四级
- 每个四级下1-3个五级
- 五级下内容约300-500字

## 章节内容重复核查

大纲生成后必须回答：
1. 本章与前两章是否有内容重叠？
2. 同一概念的定义是否在多处重复？
3. 章节之间是否存在包含关系？

## 参考文献格式

### 专著
```
序号. 作者.书名.出版社,年份.
```
### 期刊
```
序号. 作者.期刊名.期刊,年份,卷(期):页码.
URL: https://kns.cnki.net/kcms2/article/abstract/...
```

### 检索优先级
- 高被引期刊（水利学报/水科学进展/水利水电技术等）
- 带 URL 链接的题录优先
- 时间范围：2020-2026年

## 参考文献真实性要求

- 所引专著、期刊、年份须可核实
- 期刊有 URL 链接
- 法律法规、政策文件须为当前有效版本，注明文号/发布时间
- 英文缩写首次出现须有全称（括号），全文统一

## 目录.md 大纲.md 章名节名一致性要求

两个文件的章名、节名、三级分类（基础篇/重点篇/前沿篇）必须**完全一致**，质检时逐章比对。
