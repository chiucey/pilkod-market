# 目录文件格式规范（最终定稿模板）

## 目录.md 段落顺序（强制）

1. **书名**：纯文本，无书名号，无副标题，无"字数"标注行
2. **内容简介**：`内容简介：` + 正文（一段，不换行）
3. **写作分工**：`本书共X章，总计实际X万字，具体分工如下：` 下一行起，每行一个作者
4. **目录**（无"目录"标题，直接列章节）
5. **结束语**
6. **参考文献**（仅专著+期刊，分列两小节）

## 目录正文格式

- **全书所有文字均加粗**（Word格式）
- 章标题格式：`第X章 章节标题`（中间空一格）
- 节标题格式：`第一节 节标题`（前空两格）
- 三篇分类：`基础篇`/`重点篇`/`前沿篇`（独占一行，不加"第X篇"前缀）
- 每节标题行前空两格（两个空格）
- 章标题行无缩进（顶格）
- 无参考文献列表在章节目录中（仅在末尾）

## 内容简介标准收束句

结尾必须有：
> 可为……提供系统的理论参考与实践指导。

## 字数要求
- 内容简介：200-300字
- 按"基础→重点→前沿"三层逻辑展开

## 结束语格式
- 独立一行：`结束语`
- 无内容正文（正文集中在各章节）

## 参考文献格式

### 专著列表
```
参考文献：
专著：
1. 作者.书名.出版社,年份.
2. 作者.书名.出版社,年份.
```

### 期刊列表
```
期刊：
1. 作者.期刊名.期刊,年份,卷(期):页码.
URL: https://kns.cnki.net/kcms2/article/abstract/...
```
