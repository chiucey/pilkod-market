# 司南图书大纲策划

## 标准工作流（严格按序执行）

### 第一步：收集需求（司南确认）

确认以下全部信息后方可启动，不得跳过：
- 书名（含副标题）
- 总字数要求（万字）
- 三分版块比例（基础/重点/前沿，默认 20%/55%/25%）
- 作者分工（若有）
- 参考文献（专著+期刊；若无可空缺）

---

### 第二步：文献检索（DeepSeek V3.2）

**调用模型**：`siliconflow/Pro/deepseek-ai/DeepSeek-V3.2`
**API**：`https://api.siliconflow.cn/v1/chat/completions`
**Temperature**：0.3，**Max tokens**：8192

使用 `batch_web_search` 并发执行，不低于3个检索任务：

1. **专著检索**：书名核心词 → 全国图书馆参考联盟
2. **期刊检索**：核心词 + 细分主题，2020-2026年 → 知网，附 URL
3. **政策/标准检索**：最新政策、技术动态

---

### 第三步：章节目录第一稿（DeepSeek V3.2）→ 司南审核

**调用模型**：`siliconflow/Pro/deepseek-ai/DeepSeek-V3.2`
**Temperature**：0.3，**Max tokens**：8192

根据需求和文献检索结果，计算章数并出章节目录第一稿：

```
章数 = 6 + ceil((字数 - 20万) / 2万)
```

| 字数区间 | 章数 |
|---------|------|
| 10-20万 | 6章 |
| 20-22万 | 7章 |
| 22-24万 | 8章 |
| … | … |

**目录格式**（仅输出章名和节名，等待司南审核）：

```
【基础篇/重点篇/前沿篇】
第一章 章节标题
  第一节 节标题
  第二节 节标题
  第三节 节标题

第二章 章节标题
  ……
```

司南审核修改确认后，进入第四步。

---

### 第四步：五级标题大纲生成（DeepSeek V3.2）

**调用模型**：`siliconflow/Pro/deepseek-ai/DeepSeek-V3.2`
**Temperature**：0.3，**Max tokens**：8192

司南确认目录后，生成五级标题细化大纲：

- 每节深化到五级标题
- 每节下方：`参考文献：……` + `字数估算：约XXXX字`
- 五级标题格式：每个四级（一）（二）下的五级从1.独立编号
- 标题字数约束：每级8-20汉字
- 每节四级标题5-15个，每个四级下五级1-4个

---

### 第五步：GLM-5 全链路质检

**调用模型**：`siliconflow/Pro/zai-org/GLM-5`
**API**：`https://api.siliconflow.cn/v1/chat/completions`
**Temperature**：0.3，**Max tokens**：8192

将第三步目录 + 第四步大纲输入 GLM-5，执行逐项质检：

**一、格式检查**
- [ ] 五级序号每个四级下独立重置
- [ ] 每节有且仅有一行字数估算
- [ ] 每节参考文献≥2条专著
- [ ] 每节四级标题5-15个，每个四级下五级1-4个

**二、内容检查**
- [ ] 正文无 `XX等《书名》` 引用格式
- [ ] 无禁忌标题（领导谈话/案例/公式推导/国内外对比/现状描述）
- [ ] 章节内容不重叠

**三、重复与机械化检查（重点）**
- [ ] 全书四级标题无完全相同
- [ ] 节名全书中无重复
- [ ] 相邻两章同位置节名内容差异≥40%
- [ ] 四级标题结构是否存在机械化等分问题（禁止每节四级数量完全相同、每四级下五级数量完全相同）
- [ ] 四级、五级标题下的概念或内容，展开后是否存在潜在重复，酌情标注预警

**四、作者分工核查**
- [ ] 若有作者分工，逐一核验每章归属唯一作者，不设协同写作章节
- [ ] 作者分工格式符合要求：每行一个作者，注明负责章节

**五、参考文献核查（重点）**
- [ ] 每节所引用的专著、期刊参考文献，写在该节名下方（不是章末）
- [ ] 所引专著/期刊/年份须可核实，期刊须附 URL 链接
- [ ] 法律法规、政策文件须为当前有效版本，注明文号/发布时间
- [ ] 英文缩写首次出现须有全称（括号），全文统一

**六、简介检查（目录.md）**
- [ ] 字数200-300
- [ ] 基础→重点→前沿三层逻辑
- [ ] 标准收束句

输出格式：每类检查列出结果（✅/❌）+ 整改建议，标注重点预警项。

---

### 第六步：DeepSeek V3.2 按质检报告修改

**调用模型**：`siliconflow/Pro/deepseek-ai/DeepSeek-V3.2`
**Temperature**：0.3，**Max tokens**：8192

将 GLM-5 质检报告全文反馈给 DeepSeek V3.2，逐条修改。

修改完成后返回修改说明，**重新进入第五步**（GLM-5 质检），直到全部检查项通过。

全部通过后，输出以下两个最终文件：

---

#### 目录.md（最终定稿格式）
```
书名：书名（全称，无引号无副标题）
内容简介：正文一段200-300字
本书共X章，总计实际X万字，具体分工如下：
第一作者XXX，负责撰写第X、X、X章，共计X万字。

目录：
基础篇/重点篇/前沿篇（如有）
第一章 章节标题
  第一节 节标题
  ……

结束语
参考文献：
专著：1.作者.书名.出版社,年份.
期刊：1.作者.期刊名.期刊,年份,卷(期):页码. URL
```

#### 大纲.md（五级标题细化）
- 每节深化到五级标题
- 每节下方：`参考文献：……` + `字数估算：约XXXX字`
- 五级标题格式：每个四级（一）（二）下的五级从1.独立编号
- 标题字数约束：每级8-20汉字

## 内容禁忌

以下**不得单独设章节**：
- 领导人谈话/语录
- 案例分析（用"某工程/某地区"代替）
- 公式推导
- 国内外对比（可融入各章）
- 现状描述（改为"发展态势"）
- 消极内容

## 三分版块比例

| 板块 | 权重 |
|------|------|
| 基础 | ~20% |
| 重点 | ~55% |
| 前沿 | ~25% |

重点篇章节数 > 基础篇、前沿篇。
