# 全球新闻热点播报

## 核心规则

### 日期规则（最高原则）
- **每条新闻发布日期距播报时间绝不能超过24小时**
- 播报时间（北京时间）07:00 = 前推24小时，即收录窗口为前一天07:01至当日07:00
- **每条新闻必须标注具体发布时间**，标注时间超过播报时间24小时的一律排除
- 搜索结果必须严格过滤时间，不符合窗口的新闻直接跳过

### 来源名单（严格限定）

|------|--------|
| BBC News | BBC News |

| NHK | NHK |
| 韩联社 | Yonhap |

### 硬性排除规则
- 任何新闻发布日期距播报时间超过24小时 → 排除
- 不在上述11个名单内的任何来源 → 排除
- **每来源最多5条**

## 执行流程

### 第一步：搜索新闻
使用 `batch_web_search` 工具搜索以下关键词组合：
```
1. "top news today breaking" + 今日日期
2. "world news latest" + 今日日期
3. "breaking news" + 来源名
```

### 第二步：来源验证与内容提取
1. 严格检查每条新闻的来源是否为上述11个之一
2. 核实发布日期是否在24小时窗口内
3. 使用 `extract_content_from_websites` 提取详细内容
4. 每来源最多收录5条

### 第三步：真实性核实
- 交叉验证关键事实
- 排除未经证实的传言
- 确保信息来源可靠

## 输出格式（永久锁定）

```
第一部分
🌐 全球新闻热点播报 | 北京时间 Y年M月D日 H:00
━━━━━━━━━━━━━━━━━━━━

第二部分

**【来源名】**
1. 🔥/📌/📰 + 新闻标题（时间）— 一句话摘要

（重复各来源，最多5条/来源）

第三部分
📊 整体局势 → 🟢 好转 / 🟡 平稳 / 🔴 恶化 + 一句话说明
━━━━━━━━━━━━━━━━━━━━
```

### 标签说明
- 🔥 = 重大突发新闻
- 📌 = 重要新闻
- 📰 = 一般新闻

## 注意事项
- 所有时间均为北京时间
- 严格遵守24小时规则，绝不妥协
- 核实信息来源后再输出
