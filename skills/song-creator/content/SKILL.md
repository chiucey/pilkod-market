# 歌词创作技能

## 核心能力

帮助用户创作歌词，支持以下场景：

1. **续写歌词**：用户提供了部分歌词，根据主题、风格、韵律续写完整歌词
2. **主题创作**：用户只提供主题或歌名，创作完整歌词
3. **风格定制**：根据用户指定风格（情歌、民谣、说唱、流行、古风等）创作

## 工作流程

### 步骤1：分析用户需求

**收集信息（如果未提供则询问）：**
- 歌词主题（如：爱情、友情、梦想、乡愁等）
- 歌曲风格（如：流行、摇滚、民谣、说唱、古风、R&B等）
- 是否已有部分歌词
- 歌曲情绪（欢快、深情、忧伤、励志等）
- 目标受众

**输出格式要求：**
- 标准歌词格式：段落清晰，有主歌/副歌标记
- 押韵工整，节奏感强
- 符合指定风格特点

### 步骤2：创作歌词

**续写模式**（用户提供了部分歌词）：
```
分析已有歌词的风格、韵律、主题
保持一致性和连贯性
创作剩余部分（主歌→副歌→过渡→结尾）
```

**创作模式**（用户提供主题）：
```
确定歌曲结构（通常4-8段）
设计主歌-副歌-桥段布局
撰写符合风格的歌词
确保押韵和节奏感
```

### 步骤3：输出与确认

**输出内容：**
- 完整歌词（含段落标记）
- 简短创作说明（风格、结构概述）

**询问用户：**
> "歌词已创作完成！您是否需要我生成配套的音乐？"

## 输出格式模板

```
【歌名：《xxx》】
【风格：xxx | 情绪：xxx】

【主歌1】
...
【副歌】
...
【主歌2】
...
【副歌】
...
【桥段】
...
【结尾副歌/尾声】
...
```

## 风格特点参考

| 风格 | 特点 | 押韵方式 |
|------|------|----------|
| 流行 | 通俗易懂，旋律流畅 | AABB/ABAB |
| 民谣 | 叙事性强，质朴真诚 | AABB |
| 说唱 | 节奏密集，词汇丰富 | AA BB CC |
| 古风 | 典雅含蓄，意象丰富 | AABB/押韵更自由 |
| 摇滚 | 激情有力，情感强烈 | ABAB |
| R&B | 温柔细腻，旋律感强 | ABAB |

## 注意事项

1. **理解用户意图**：如果用户描述模糊，主动询问确认
2. **保持一致性**：续写时严格保持原歌词的风格和韵律
3. **创意适度**：不要过度创作，尊重用户的创作方向
4. **检查质量**：确保歌词通顺、无病句、情感真挚
