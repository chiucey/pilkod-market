# SoloForest 五行人格测试

## 测试说明

本测试基于《三命通会》卷七·性情相貌的理论，通过25道题目诊断你的五行能量分布，揭示你的先天禀赋和性格特质。

**预计用时**：约10分钟

**五行能量对应**：
- 木（生发之力）：创造力、规划能力、成长潜力
- 火（炎上之力）：热情表达、领导魅力、目标驱动
- 土（承载之力）：稳定踏实、资源整合、信任建立
- 金（肃杀之力）：决断力、审美能力、规则意识
- 水（流动之力）：智慧适应、人际敏锐、变通能力

## 结果解读

### 主导能量分析

**主导能量（≥40%）**：
代表你最核心的天赋特质，是你最自然、最本能的行事方式。

**辅助能量（25-39%）**：
代表你的次要特质，是你需要时可以调用的能力。

**短板能量（<20%）**：
代表你的成长空间，是你需要刻意练习的领域。

### 五行能量组合解读

| 组合类型 | 特征描述 | 创业建议 |
|---------|---------|---------|
| 木火主导 | 理想主义者，创意与激情并存 | 适合创新领域，需要土型合伙人平衡 |
| 火土主导 | 实践主义者，热情与稳健兼具 | 适合运营类岗位，需要金水补充理性 |
| 土金主导 | 务实主义者，稳定与决断并存 | 适合传统行业，需要木火激发创新 |
| 金水主导 | 理性主义者，分析与适应并存 | 适合咨询领域，需要木土补充深度 |
| 水木主导 | 智慧主义者，洞察与创造并存 | 适合新兴领域，需要火金补充行动力 |

### 核心洞见

**「有病方为贵，无伤不是奇」** — 《三命通会》

你的五行偏性不是缺陷，而是独特的天赋：
- 木旺者：用创意和规划能力，但要防止过于理想化
- 火旺者：用热情和行动力，但要防止过于冲动
- 土旺者：用稳定和信任感，但要防止过于保守
- 金旺者：用决断和专业性，但要防止过于苛刻
- 水旺者：用适应和洞察力，但要防止过于漂浮

## 个性化发展建议

### 木主导者（≥40%木）

**天赋特质**：
- 超强的创造力和战略思维
- 对未来的洞察力和愿景构建能力
- 学习和成长的内在动力

**潜在挑战**：
- 想法多但行动力不足
- 过于理想化，与现实脱节
- 缺乏耐心，急于求成

**发展建议**：
1. 选择能发挥创造力的创业方向（科技、教育、绿色产业）
2. 搭配土型合伙人增强执行力和稳定性
3. 在团队中担任战略规划角色
4. 设置阶段性目标，保持行动节奏

### 火主导者（≥40%火）

**天赋特质**：
- 强大的感染力和领导魅力
- 快速行动和果断决策的能力
- 激励他人和点燃热情的天赋

**潜在挑战**：
- 冲动决策，缺乏深思熟虑
- 情绪波动大，影响判断
- 缺乏耐心，难以坚持

**发展建议**：
1. 选择需要快速响应和热情推动的领域（营销、媒体、娱乐）
2. 搭配金型或水型搭档增强理性和变通
3. 建立决策流程约束冲动
4. 学习冥想和情绪管理

### 土主导者（≥40%土）

**天赋特质**：
- 稳定性和可信赖度
- 资源整合和关系维护能力
- 踏实执行和持续坚持的能力

**潜在挑战**：
- 过于保守，抗拒变化
- 缺乏冒险精神和创新意识
- 对新事物反应迟钝

**发展建议**：
1. 选择稳定可持续的创业方向（制造、地产、服务）
2. 搭配木型或火型成员激发创新
3. 设定明确的冒险边界，适度尝试
4. 关注行业趋势，主动学习新事物

### 金主导者（≥40%金）

**天赋特质**：
- 强大的逻辑分析和决断能力
- 专业性和品质意识
- 规则意识和流程优化能力

**潜在挑战**：
- 过于严肃和挑剔
- 人际交往中缺乏温度
- 难以接受模糊和不确定性

**发展建议**：
1. 选择需要专业性和精准度的领域（金融、法律、咨询）
2. 搭配火型或水型成员增强温度和灵活
3. 学习情商技巧，关注人际感受
4. 接受不完美，培养包容心

### 水主导者（≥40%水）

**天赋特质**：
- 出色的适应力和洞察力
- 良好的人际敏感度和同理心
- 灵活变通和随机应变的能力

**潜在挑战**：
- 缺乏明确方向和坚定立场
- 过于灵活，缺乏原则
- 难以持久，容易半途而废

**发展建议**：
1. 选择需要洞察力和适应力的领域（互联网、创意、服务）
2. 搭配木型或土型成员增强方向感
3. 设定清晰目标，建立固定习惯
4. 学习专注和深度工作
