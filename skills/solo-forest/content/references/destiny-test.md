# SoloForest 人生大运测试

## 测试说明

本测试基于《三命通会》大运论、调候用神、病药理论，通过25道题目帮助你定位人生阶段、找到"病"与"药"、把握十年大运的关键转折点。

**预计用时**：约12分钟

**核心概念**：
- **病**：你当前面临的核心问题或困境
- **药**：解决这个问题的关键能量或方法
- **调候用神**：能激活你最佳状态的五行能量
- **转折期**：人生的关键抉择时刻

## 第一部分：人生阶段定位（1-8题）

## 结果解读

### 人生阶段定位

| 阶段 | 特征 | 核心任务 | 行动建议 |
|-----|-----|---------|---------|
| 初期（0-30岁） | 探索、学习、积累 | 找到方向，打好基础 | 多尝试，不设限 |
| 成长期（30-40岁） | 突破、扩张、证明 | 抓住机会，快速成长 | 加大投入，敢于冒险 |
| 成熟期（40-50岁） | 稳固、深耕、建立 | 打造护城河，稳健发展 | 聚焦核心，精益求精 |
| 转型期（50-60岁） | 重构、突破、新生 | 重新定义，寻找新增长 | 主动求变，拥抱变化 |
| 后期（60岁+） | 传承、分享、智慧 | 培养后人，传承价值 | 放权授权，享受成果 |

### 病药分析

#### 五行病象

| 病象 | 表现 | 药方 | 调候方式 |
|-----|-----|-----|---------|
| 木病 | 想太多不行动、规划过度 | 行动药：先干起来 | 多运动、增加刺激 |
| 火病 | 热情过头、缺乏冷静 | 冷静药：延迟决策 | 冥想独处、降低期待 |
| 土病 | 过于保守、不敢变化 | 冒险药：适度突破 | 接触新事物、走出舒适区 |
| 金病 | 过于苛刻、人际紧张 | 包容药：增加弹性 | 社交活动、表达情感 |
| 水病 | 过于漂浮、缺乏定力 | 聚焦药：明确目标 | 制定计划、建立习惯 |

#### 核心病药配对

**木火主导者**：
- 常见病：行动力不足、过于理想化
- 药方：搭配土金型人才、增强执行力
- 调候：设置截止日期、外部约束

**土金主导者**：
- 常见病：过于保守、缺乏创新
- 药方：搭配木火型人才、激发活力
- 调候：接触创意人群、尝试新事物

**水木主导者**：
- 常见病：方向不明、漂浮不定
- 药方：搭配土金型人才、增强稳定性
- 调候：设定明确目标、建立规律

### 转折期分析

#### 转折类型

| 转折类型 | 特征 | 把握策略 |
|---------|-----|---------|
| 学业转折 | 升学、毕业、留学 | 早规划、多尝试 |
| 事业转折 | 跳槽、创业、转行 | 谨慎评估、做好储备 |
| 家庭转折 | 结婚、生子、离婚 | 做好准备、平衡关系 |

#### 转折信号识别

**上升转折信号**：
- 出现新的机会和资源
- 遇到能帮助你成长的人
- 内心感到强烈的召唤

**下降转折信号**：
- 持续感到疲惫和无力
- 周围环境发生重大变化
- 做事越来越不顺

**关键识别**：
「命运转折处，往往伴随内心的不安」

## 个性化决策建议

### 初期阶段（0-30岁）

**核心任务**：探索方向，积累能力

**行动策略**：
1. 多尝试，找到真正热爱的事
2. 打牢基础，不要急于赚钱
3. 建立人脉，找到同行者
4. 保持开放，不要过早固化

**大运把握**：
- 印星运（学习积累期）：多学习，提升认知
- 比劫运（人脉建立期）：多交友，建立关系
- 食伤运（创意爆发期）：多尝试，找到方向

### 成长期（30-40岁）

**核心任务**：抓住机会，快速成长

**行动策略**：
1. 找准方向，全力以赴
2. 建立团队，学会借力
3. 把握时机，敢于冒险
4. 积累资源，为未来铺垫

**大运把握**：
- 食伤运（创意爆发期）：大胆创新，快速迭代
- 财星运（财富积累期）：抓住机会，扩大规模
- 官杀运（成就达成期）：追求目标，获得认可

### 成熟期（40-50岁）

**核心任务**：稳固优势，建立护城河

**行动策略**：
1. 聚焦核心，放弃非核心
2. 建立系统，减少依赖
3. 培养团队，实现传承
4. 适度冒险，寻找新增长

**大运把握**：
- 财星运（财富稳固期）：稳健经营，资产配置
- 印星运（智慧沉淀期）：总结经验，传承智慧
- 比劫运（关系深化期）：深化关系，资源共享

### 转型期（50-60岁）

**核心任务**：重新定义，寻找新生

**行动策略**：
1. 放下过去，重新出发
2. 利用积累，转型升级
3. 培养新人，实现传承
4. 关注健康，平衡生活

**大运把握**：
- 官杀运（责任转型期）：承担更大责任
- 印星运（智慧觉醒期）：顿悟提升，找寻意义
- 水用神激活：灵活转型，找到新方向

### 病药决策框架

**当感到迷茫时**：
- 病：方向不明（木病）
- 药：行动药——先做起来，在行动中找方向

**当感到疲惫时**：
- 病：能量不足（火病）
- 药：激励药——寻找能点燃你的人和环境

**当感到焦虑时**：
- 病：不稳定（土病）
