# 浏览器研究员

通过浏览器自动化进行高效的网络搜索和信息提取。

## 核心能力

- 网页内容搜索与提取
- 多来源信息整合
- 结构化数据收集
- 图片搜索与下载

## 工作流程

### 1. 信息搜索

**使用 `batch_web_search` 进行批量搜索：**
- 构建精确的搜索查询（3-5个关键词）
- 根据需要添加时间范围（如最新信息）
- 设定合理的返回数量（通常10条）

### 2. 内容提取

**使用 `extract_content_from_websites` 提取网页内容：**
- 为每个URL提供明确的提取目标
- 使用结构化提示词指导提取
- 批量处理多个来源

### 3. 图片资源

**使用 `images_search_and_download` 搜索图片：**
- 提供清晰的图片描述提示
- 指定下载目录
- 处理多个搜索任务

### 4. 复杂交互任务

**使用 `agent-browser` 进行浏览器自动化：**
- 导航到特定网页
- 填写表单和搜索框
- 点击按钮和链接
- 截取页面截图
- 提取动态加载的内容

## 最佳实践

1. **搜索策略**
   - 使用具体关键词而非模糊描述
   - 对于最新信息添加时间限制
   - 尝试多种搜索表述以获得全面结果

2. **内容提取**
   - 先搜索找到相关页面，再提取详细内容
   - 优先提取权威来源
   - 注意信息的时效性

3. **结果整理**
   - 去重和过滤低质量来源
   - 标注信息来源便于引用
   - 按主题或相关性组织结果

## 工具选择指南

| 任务类型 | 推荐工具 |
|---------|---------|
| 快速信息搜索 | `batch_web_search` |
| 深度内容提取 | `extract_content_from_websites` |
| 图片搜索下载 | `images_search_and_download` |
| 交互式网页操作 | `agent-browser` |

## 示例场景

- **研究主题**："帮我研究一下人工智能的最新发展"
- **查找教程**："搜索Python爬虫的入门教程"
- **获取新闻**："查找最近一周的科技新闻"
- **数据查询**："搜索某个公司的最新财报信息"
