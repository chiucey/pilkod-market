# 投研分析报告Skill

## 概述

本Skill自动生成专业的投研分析报告，支持快速概览和深度分析两种模式，覆盖多个行业和市场。

## 触发场景

当用户出现以下表达时，激活本Skill：

- **单公司分析**："这公司怎么样"、"分析一下宁德时代"、"帮我看看腾讯"、"写个投研报告"、"做个深度研究"
- **对比分析**："宁德时代和比亚迪哪个好"、"阿里vs京东"、"美的和格力对比"
- **行业分析**："新能源车行业怎么样"、"半导体行业投资"、"互联网公司分析"
- **估值需求**："估值分析"、"DCF估值"、"目标价"

## 分析模式

### 快速模式（~3分钟）

适用于需要快速了解一家公司的核心情况：

```
输出格式：
- 一句话定位：公司主营业务 + 市场地位
- 关键指标：营收、净利润、PE、ROE等核心财务指标
- 亮点/风险：3条核心亮点 + 3条主要风险
- 投资结论：BUY/HOLD/SELL + 目标价区间
```

### 深度模式

适用于需要全面深入的分析，输出完整投研报告：

```
分析维度：
1. 公司概况与业务模式
2. 竞争优势与护城河分析
3. 技术研发投入与创新
4. 市场份额与竞争格局
5. 客户结构与渠道
6. 成长路径与规划
7. 历史与预测财务数据
8. 海外业务与地缘风险
9. 股权结构与公司治理
10. 估值分析（DCF + 可比公司）
11. 投资结论
```

## 执行流程

### Step 1: 信息收集

1. **识别公司**：从用户输入中提取公司名称
2. **确定模式**：快速模式 vs 深度模式
3. **确定行业**：根据公司业务判断所属行业
4. **确定市场**：A股、港股、或对比模式

### Step 2: 数据获取

使用可用工具获取：
- 公司基本信息（主营业务、上市地点）
- 财务数据（营收、利润、ROE等）
- 行业数据（市场份额、竞争格局）
- 估值数据（PE、PB、市值）
- 近期新闻和公告

### Step 3: 分析生成

根据选择的模式、行业模板生成分析：

**快速模式输出示例**：
```
# 宁德时代 快速分析

## 一句话定位
全球动力电池龙头，主营新能源汽车动力电池系统， 国内市占率超50%，全球市占率超30%。

## 关键指标（2024年）
- 营收：4,422亿（+22%）
- 净利润：441亿（+43%）
- 毛利率：23%（同比+2pp）
- ROE：24%
- PE(TTM)：18x

## 亮点
1. 动力电池全球龙头地位稳固，技术领先
2. 储能业务快速增长，第二增长曲线明确
3. 规模效应显著，成本控制能力强

## 风险
1. 原材料价格波动（锂、镍）
2. 竞争加剧（比亚迪、LG新能源）
3. 行业产能过剩风险

## 投资结论
HOLD | 目标价：180-220元
理由：行业龙头地位稳固，但估值合理，需等待更好的买入时机
```

### Step 4: 输出格式

根据模式输出：

| 模式 | 格式 | 建议 |
|------|------|------|
| 快速模式 | 简洁版Markdown | BUY/HOLD/SELL + 目标价 |
| 深度模式 | 完整投研报告 | BUY/HOLD/SELL + 详细逻辑 |

## 输出规范

### BUY/HOLD/SELL 定义

- **BUY**：预期涨幅>20%，风险收益比佳
- **HOLD**：预期涨幅-10%~20%，持有等待
- **SELL**：预期跌幅>10%，建议卖出

### 估值方法选择

| 公司特征 | 推荐方法 |
|----------|----------|
| 稳定盈利 | DCF + PE |
| 高成长 | PS + DCF |
| 周期性 | PB + EV/EBITDA |
| 金融业 | PB + 股息折现 |

## 注意事项

1. **信息核实**：重要数据需交叉验证
2. **时效性**：财务数据使用最新财报
3. **客观性**：亮点与风险需平衡
4. **合规性**：不提供具体买卖建议
5. **不确定性**：标注预测假设和风险
