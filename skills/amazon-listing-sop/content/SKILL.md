# 亚马逊Listing撰写SOP（基于COSMO算法）

## 核心理念

本SOP基于Amazon COSMO（Common Sense Knowledge Generation and Serving System）算法，核心思想：

- **用户意图挖掘（Intent Mining）**：理解用户搜索背后的真实需求
- **常识知识生成（Commonsense Knowledge Generation）**：构建产品与用户需求的关系图谱
- **典型性评分（Typicality Scoring）**：判断哪些属性对用户最重要

## COSMO关系类型框架

| 关系类型 | 含义 | Listing应用位置 |
|---------|------|----------------|
| usedFor | 产品用于解决什么问题 | 标题、五点第1条 |
| capableOf | 产品具备什么能力 | 五点第1-2条 |
| isA | 产品属于什么类别 | 标题、后台关键词 |
| usedOn | 在什么表面/对象上使用 | 五点第3条 |
| usedIn | 在什么环境/场合中使用 | 五点第3条 |
| usedBy | 被什么人群使用 | 五点第2条、标题 |
| usedWith | 与什么产品搭配使用 | 描述、A+页面 |
| cause | 什么原因促使购买 | 五点第5条 |

## 执行流程

### 第一步：收集产品信息

```
  2. _______________
  3. _______________

尺寸/规格：_______________
颜色选择：_______________

【目标用户】
主要人群：_______________
年龄范围：_______________
使用场景：_______________
购买时机：_______________

【核心卖点与差异化】
与竞品相比的优势：
  1. _______________
  2. _______________
  3. _______________

【关键词信息】
核心搜索词（用户会搜什么）：
  1. _______________

  3. _______________

【竞品信息】（可选但推荐）

【信任背书】

【定价策略】（重要）

```

### 第二步：构建三层意图模型

分析用户搜索意图：

```
┌─────────────────────────────────────────┐
│  表层意图（Surface Intent）              │
│  用户搜索的词：_______________           │
├─────────────────────────────────────────┤
│  中层意图（Functional Intent）           │
│  用户想要的功能：_______________         │
├─────────────────────────────────────────┤
│  深层意图（Emotional Intent）            │
│  用户真正的诉求：_______________         │
│  • 想避免：_______________               │
│  • 想获得：_______________               │
│  • 想成为：_______________               │
└─────────────────────────────────────────┘
```

### 第三步：构建产品知识图谱

基于COSMO关系类型填写：

| 关系类型 | 内容 | 典型性评分 |
|---------|------|-----------|
| usedFor | 产品用途 | 高/中/低 |
| capableOf | 产品能力 | 高/中/低 |
| usedBy | 目标用户 | 高/中/低 |
| usedIn | 使用场景 | 高/中/低 |
| cause | 购买原因 | 高/中/低 |
| usedWith | 搭配产品 | 高/中/低 |

### 第四步：搭建关键词金字塔

```
        ▲
       /A\      核心词（1-3个）：最高搜索量
      /   \     放置：标题最前
     /  B  \
    /       \   功能词（5-10个）：描述产品能力
   /         \  放置：标题、五点前两条
  /     C     \
 /             \ 场景词（10-20个）：描述使用场景
/               \放置：五点、描述
─────────────────
        D        长尾词（20-50个）：具体需求组合
                 放置：后台Search Terms、描述
```

### 第五步：撰写Listing内容

#### 标题撰写公式

```
[品牌] + [核心产品词] + [最重要功能（usedFor）]
+ [目标用户（usedBy）] + [核心场景（usedIn）] + [差异化卖点]
```

**要求：**

- 字符数：150-180字符（不超过200字节）
- 核心关键词在前30字符内
- 无促销词（Free、Sale等）
- 无主观评价词（Best、Amazing等）

#### 五点描述结构

| 五点 | COSMO关系 | 内容重点 | 字符数 |
|-----|----------|---------|--------|
| 第1条 | capableOf | 核心能力（最高典型性属性） | 200-300 |
| 第2条 | usedBy | 目标用户+痛点解决 | 200-300 |
| 第3条 | usedIn/usedOn | 使用场景覆盖 | 200-300 |
| 第4条 | 材质工艺 | 支撑功能可信度 | 200-300 |
| 第5条 | cause | 购买理由+信任背书 | 200-300 |

**每条五点公式：**

```
【标签词】核心描述（20字内）+ 具体实现方式 + 用户直接收益
```

#### 产品描述结构

```
【情感共鸣段落（50-80字）】
描述用户痛点场景，建立情感连接

【核心功能段落（100-150字）】
用数据和具体描述说明产品功能

【适用人群段落（50-80字）】
明确说明谁适合购买

【选购建议段落（50-80字）】
提供具体的选购建议

【信任背书段落（50-80字）】
认证、评价、售后保障
```

#### 后台Search Terms

- 不超过250字节
- 词与词之间用空格分隔
- 不重复标题中已有的词
- 无标点符号

### 第六步：质量评估

#### 典型性评分（10分）

| 检查项 | 是(2分) | 否(0分) |
|-------|--------|--------|
| 标题中的功能词是否是用户最期待的？ | | |
| 五点第1条是否描述了最高典型性属性？ | | |
| 场景描述是否符合用户实际使用情况？ | | |
| 是否避免了低典型性属性占据重要位置？ | | |
| 目标用户描述是否准确？ | | |

#### 合理性评分（10分）

| 检查项 | 是(2分) | 否(0分) |
|-------|--------|--------|
| 功能描述是否有具体数据支撑？ | | |
| 是否避免了无法验证的夸张描述？ | | |
| 材质/工艺描述是否具体可信？ | | |
| 场景描述是否符合实际使用逻辑？ | | |
| 是否有信任背书（认证/评价）？ | | |

#### 完整性评分（10分）

| 检查项 | 是(2分) | 否(0分) |
|-------|--------|--------|
| 是否覆盖了主要使用场景（≥3个）？ | | |
| 是否明确了目标用户群体？ | | |
| 是否说明了核心功能（≥3个）？ | | |
| 是否提供了选购建议？ | | |
| 是否包含售后保障信息？ | | |

**总分评级：**

- 25-30分：优秀，可直接发布
- 20-24分：良好，小幅优化后发布
- 15-19分：一般，需要重点修改
- 15分以下：较差，建议重写

## 高端定价策略（溢价营销）

当产品定价高于市场均价时，需要特别处理：

### 溢价价值支柱

1. **健康安全价值**：无毒材料、安全认证
2. **长期使用价值**：耐用性、质保
3. **专业品质价值**：材质优越性、专业效果
4. **节省价值**：替代更贵产品、节省空间

### 溢价营销话术

- "You can't put a price on safety"
- "One quality purchase beats replacing cheap alternatives"
- "The question isn't why pay more—it's why would you settle for less?"
- "That $XX difference represents real value—not marketing markup"

## 输出格式

最终输出应包含：

1. **产品知识图谱**（三层意图+关系图谱）
2. **关键词金字塔**
3. **标题**（含字符数）
4. **五点描述**（每条含字符数）
5. **产品描述**
6. **后台Search Terms**（含字节数）
7. **质量评估报告**（三维度评分+总分）
8. **关键词覆盖检查**
