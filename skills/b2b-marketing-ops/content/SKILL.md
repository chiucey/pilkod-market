# To B软件企业市场营销运营技能

## 技能概述

本技能专为To B软件企业的市场营销人员设计，提供从内容创作到客户运营的全方位支持。

## 核心能力模块

### 1. 内容运营

#### 1.1 公众号运营
- **文章创作**：产品介绍、行业分析、案例分享、客户故事
- **标题优化**：吸引点击的标题公式、A/B测试策略
- **排版规范**：Markdown排版、emoji使用规范、阅读节奏
- **发布节奏**：内容日历规划、热点借势、节日营销

#### 1.2 小红书运营
- **笔记创作**：产品种草、使用教程、行业干货、客户案例
- **标签策略**：热门话题、长尾关键词、垂直领域标签
- **封面设计**：文字标题、图片风格、视觉统一
- **互动运营**：评论回复、粉丝维护、数据分析

#### 1.3 视频脚本
- **产品演示**：功能展示、场景应用、优势对比
- **品牌故事**：企业背景、团队介绍、价值观传递
- **客户证言**：访谈提纲、拍摄脚本、后期剪辑建议
- **短视频脚本**：15秒/60秒脚本模板、节奏把控、行动号召

### 2. 物料设计

#### 2.1 产品易拉宝
- **标准尺寸**：80cm×200cm、60cm×160cm
- **内容结构**：主标题、副标题、核心卖点、CTA
- **视觉规范**：Logo位置、配色方案、字体选择
- **场景应用**：展会、门店、会议室、签到区

#### 2.2 线下活动背景板
- **标准尺寸**：3m×6m、4m×8m、定制尺寸
- **内容布局**：主视觉区、Logo墙、赞助商区、议程区
- **风格类型**：科技风、商务风、简约风、活泼风
- **物料清单**：背景板、签到台、引导牌、展示架

#### 2.3 产品宣传手册
- **手册类型**：产品手册、功能手册、解决方案手册
- **内容结构**：封面、目录、产品概述、功能详情、案例展示、联系方式
- **设计规范**：页数建议、尺寸规格、纸张材质、装订方式
- **多语言版本**：中文版、英文版、中英对照版

#### 2.4 企业宣传册
- **品牌故事**：企业愿景、使命、价值观、发展历程
- **核心业务**：产品线、解决方案、行业应用
- **客户案例**：行业标杆、典型客户、合作成果
- **团队展示**：核心团队、企业资质、合作伙伴

### 3. 市场活动

#### 3.1 活动策划
- **活动类型**：新品发布会、行业峰会、合作伙伴大会、线下沙龙、客户答谢
- **策划要素**：目标设定、预算规划、时间节点、场地选择、嘉宾邀请
- **执行清单**：前期准备、当日流程、应急预案、收尾总结
- **ROI评估**：投入产出比、线索转化、客户满意度

#### 3.2 市场活动合作
- **合作模式**：联合主办、赞助合作、内容合作、渠道合作
- **合作伙伴**：行业协会、媒体平台、渠道商、生态伙伴
- **合作方案**：权益包设计、价格体系、合同条款
- **项目管理**：进度跟踪、效果评估、关系维护

#### 3.3 活动评估
- **数据指标**：参与人数、线索数量、转化率、ROI
- **质性评估**：客户反馈、媒体曝光、口碑传播
- **报告模板**：活动总结、效果分析、改进建议
- **知识沉淀**：经验总结、模板复用、流程优化

### 4. 客户运营

#### 4.1 私域运营
- **私域矩阵**：微信公众号、企业微信、小程序、官网
- **用户分层**：潜在客户、意向客户、成交客户、忠实客户
- **内容策略**：日常内容、活动内容、个性化内容
- **转化路径**：引流→培育→转化→复购→推荐

#### 4.2 企微运营
- **社群建设**：客户群、粉丝群、行业群、区域群
- **运营规范**：入群欢迎、群公告、群规则、互动频率
- **内容运营**：早报晚报、干货分享、活动预告、优惠通知
- **SOP流程**：新客接待、需求挖掘、方案推荐、成交跟进

#### 4.3 客户生命周期管理
- **阶段划分**：认知→兴趣→考虑→购买→使用→推荐
- **触点设计**：首次接触、定期维护、关键节点、升级机会
- **价值提升**：交叉销售、向上销售、续费提醒、转介绍激励

## 使用指南

### 触发条件
当用户请求以下类型的任务时，自动触发本技能：

**内容创作类**
- "写一篇关于XX产品的公众号文章"
- "帮我写小红书笔记，内容是XX"
- "需要视频脚本，主题是XX"

**物料设计类**
- "设计一个产品易拉宝"
- "制作线下活动背景板"
- "写一份产品宣传手册"

**活动策划类**
- "策划一场新品发布会"
- "做一个市场活动合作方案"
- "撰写活动评估报告"

**客户运营类**
- "制定私域运营方案"
- "设计企微社群运营SOP"
- "客户生命周期管理策略"

### 交互流程
1. **明确需求**：确认具体任务类型、目标受众、交付形式
2. **收集信息**：了解产品特点、品牌调性、竞品情况
3. **内容创作**：根据模板和最佳实践生成初稿
4. **迭代优化**：根据反馈调整内容
5. **交付验收**：提供最终版本和使用建议

### 质量标准
- 内容原创度≥90%
- 信息准确无误
- 符合品牌调性
- 适配目标平台
- 行动号召明确
