# 线索卡片设计规范

## 标准线索卡格式

┌─────────────────────────────────────┐
│ 【线索编号】线索名称                 │
├─────────────────────────────────────┤
│ **线索类型**：[直接证据/间接证据/干扰线索] │
│ **发现地点**：[从哪里发现]             │
│ **发现时机**：[第几轮搜证/讨论时获得]   │
│ **线索来源**：[谁发现/谁提供的]         │
├─────────────────────────────────────┤
│ 【线索内容】                          │
│ [详细的线索描述，可以包含物品外观、    │
│  内容摘要、对话记录等]                │
├─────────────────────────────────────┤
│ 【线索解读】                          │
│ [表面上能看到的信息]                   │
│ [需要推理才能得出的结论]               │
│ [与其他线索的关联]                     │
├─────────────────────────────────────┤
│ 【可分享程度】                        │
│ [建议何时分享/是否建议分享]            │
└─────────────────────────────────────┘

## 线索类型说明

### 直接证据
能够直接证明凶手身份或作案手法的证据。

### 间接证据
需要结合其他线索才能推断出真相的证据。

### 动机证据
证明某人有作案动机的证据。

### 机会证据
证明某人在特定时间出现在特定地点的证据。

### 干扰线索（红鲱鱼）
看似重要但实际上与凶案无关的证据，用于误导玩家。

---

## 线索平衡检查表

- [ ] 线索总数合适（不过多导致混乱，不过少导致卡关）
- [ ] 关键证据足够（玩家能推理出真相）
- [ ] 红鲱鱼数量适中（增加难度但不导致死局）
- [ ] 线索难度递进合理（从易到难）
- [ ] 每条线索都有用（没有完全无意义的线索）
- [ ] 线索之间有逻辑关联（不是随机拼凑）
- [ ] 证据链完整闭合（没有无法解释的死角）
```

## 模板四：时间线设计模板

```markdown
# 时间线设计指南

## 标准时间线格式

| 时间 | 事件 | 地点 | 参与者 | 备注 |
|------|------|------|--------|------|
| XX:00 | [事件描述] | [地点] | [人物] | [补充说明] |

## 时间线设计原则

### 1. 时间跨度适中
- 游戏时长2-3小时：时间跨度4-8小时
- 游戏时长3-4小时：时间跨度8-12小时
- 游戏时长4小时以上：可跨越1-3天

### 2. 节点设置合理
```
关键节点：
├── 死者最后出现的时间
├── 作案时间窗口（30分钟-2小时）
├── 第一发现者目击时间
├── 其他关键证人时间点
└── 尸体被发现时间
```

### 3. 嫌疑人不在场证明设计
每个嫌疑人至少需要一个不在场证明：
- 完全成立（有人证物证）
- 部分成立（时间模糊，地点存疑）
- 存在漏洞（可以被揭穿）

### 4. 时间线陷阱设计
```
陷阱类型：
├── 误导性时间：看似关键实则无关
├── 时间重叠：多人声称同一时间在不同地点
├── 时间误差：钟表被调、记忆偏差
└── 心理时间：时间感知被干扰
```

## 模板五：结局设计模板

```markdown
# 结局设计指南

## 结局类型框架

### 一、主线结局

#### 完美真相结局
**触发条件**：玩家找出真凶并正确还原全部真相
**结局内容**：
- 凶手认罪伏法
- 所有悬念解开
- 死者身份和动机完全明确
- 角色命运交代清楚

#### 普通真相结局
**触发条件**：玩家找出真凶但遗漏部分真相
**结局内容**：
- 凶手被绳之以法
- 主线真相还原
- 部分支线悬念留白
- 可能触发隐藏信息

#### 冤案结局
**触发条件**：玩家冤枉无辜者
**结局内容**：
- 真正凶手揭露
- 冤案平反
- 冤枉者洗清嫌疑
- 凶手受到双重惩罚

#### 逍遥法外结局
**触发条件**：真凶成功隐藏身份
**结局内容**：
- 玩家无法确定凶手
- 开放性结局
- 可能揭露部分真相
- 为续篇埋下伏笔

---

### 二、隐藏结局

#### 隐藏结局触发条件
```
通用触发条件：
├── 找出全部真相
├── 特定角色存活到最后
├── 完成特定支线任务
├── 发现隐藏线索
└── 所有角色进行特定行为
```

#### 隐藏结局类型
- **剧情补完型**：补充主线未揭露的深层真相
- **情感升华型**：角色获得救赎或完美结局
- **恐怖反转型**：看似好的结局背后隐藏更大阴谋
- **彩蛋型**：与其他作品的联动或惊喜内容

## 关键节点引导

### 冷场处理
```
应对策略：
├── 抛出提示性问题
├── 触发新的线索公开
├── 增加紧迫感（时间限制）
├── 角色"闹鬼"（NPC出现）
└── 直接发问（点名询问）
```

### 跑题拉回
```
拉回技巧：
├── "让我们回到XX话题"
├── "时间紧迫，我们需要关注XX"
├── 引入新的案件信息
└── 角色提出紧急问题
```

### 撕逼控制
```
适度撕逼是剧本杀的乐趣，但需要控制：
├── 保持游戏氛围友好
├── 适时打断人身攻击
├── 将矛盾引向角色而非玩家
└── 严重时暂停调解
```

---

## 特殊状况处理

### 凶手自爆
```
应对方案：
├── 询问自爆动机
├── 给予适当惩罚（失去部分任务）
├── 允许其他玩家质疑
├── 可以让凶手"悔过"但继续游戏
└── 统计最终结果时标注
```

### 玩家掉线
```
处理方式：
├── 暂停游戏等待
├── 由DM临时接管角色（不公开秘密）
├── 跳过该角色环节继续
└── 根据进度决定是否延后
```

### 玩家求助
```
处理原则：
├── 适度提示（不直接给答案）
├── 用问题回答问题
├── 提示关键词
├── 指向相关线索
└── 绝对不能剧透真相
```

---

## 复盘要点

### 必须覆盖的内容
1. 完整的时间线还原
2. 每个角色的真实身份和秘密
3. 凶手的作案动机和手法
4. 关键证据的解读
5. 玩家推理中的对与错

### 复盘技巧
- 先让玩家分享自己的推理
- 逐步揭示真相
- 解答玩家的疑问
- 分享剧本设计初衷
- 询问玩家体验反馈
