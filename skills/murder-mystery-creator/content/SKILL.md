# 剧本杀创作助手

## 技能简介

本技能致力于帮助创作者设计完整、饱满、引人入胜的剧本杀作品。涵盖多种题材类型，包括但不限于古风仙侠、民国谍战、现代都市、科幻未来、恐怖惊悚、宫廷权谋等，能够从零开始构建完整的世界观、角色体系、凶案逻辑和线索网络。

## 剧本杀核心要素

### 1. 题材分类与特点

#### 古风题材
- **仙侠玄幻**：涉及修仙、法宝、门派斗争
- **武侠江湖**：武林秘籍、江湖恩怨、帮派纷争
- **宫廷权谋**：皇位争夺、后宫斗争、权臣博弈
- **历史传奇**：根据真实历史或民间传说改编

#### 现代题材
- **都市情感**：家庭矛盾、情感纠葛、商业阴谋
- **职场风云**：商业竞争、职场潜规则、公司秘密
- **校园青春**：校园霸凌、学术造假、青春秘密
- **刑侦推理**：连环杀人、变态心理、破案追凶

#### 民国题材
- **谍战风云**：特工潜伏、情报交易、爱国情怀
- **十里洋场**：黑帮火拼、商会斗争、名媛悲歌
- **乱世浮沉**：军阀混战、民不聊生、义薄云天

#### 科幻题材
- **赛博朋克**：高科技低生活、AI统治、义体改造
- **星际探索**：太空殖民、外星生物、星际战争
- **末日生存**：丧尸爆发、核战之后、资源争夺

#### 恐怖题材
- **灵异惊悚**：鬼魂作祟、诅咒传说、祭祀仪式
- **心理恐怖**：精神分裂、人格分裂、催眠暗示
- **血腥暴力**：变态杀手、食人恶魔、黑暗秘密

## 剧本结构设计

### 1. 故事框架构建

```
【开场设定】
├── 时代背景（时间+地点+社会环境）
├── 核心事件（导致所有人聚集的原因）
├── 初始氛围（悬疑/紧张/诡异等）
└── 游戏目标（找出真凶+还原真相）
```

### 2. 角色体系设计

#### 角色数量规划
- **6人本**：2-3凶手阵营 + 3-4好人阵营
- **7-8人本**：1凶手+若干帮凶+若干好人
- **9-10人本**：双凶手/多线并行结构
- **12人以上**：阵营对抗+个人任务模式

#### 角色类型分布
| 角色类型 | 功能定位 | 占比建议 |
|---------|---------|---------|
| 核心嫌疑人 | 凶案直接关联者 | 30-40% |
| 知情者 | 掌握关键线索 | 20-30% |
| 侦探型 | 推动调查进程 | 10-20% |
| 情感线角色 | 增加戏剧张力 | 10-20% |
| 氛围角色 | 营造场景氛围 | 10-20% |

### 3. 凶案设计原则

#### 核心三要素
1. **动机（Motive）**：每个嫌疑人都必须有合理动机
2. **手段（Method）**：凶案手法必须可行且可推理
3. **机会（Opportunity）**：作案时间线必须无懈可击

#### 经典凶案模式
```
模式一：密室杀人
├── 物理密室：门窗锁死、无人进出
├── 时间密室：某时间段无人接近现场
├── 心理密室：看似不可能的嫌疑人
└── 雪地密室：无脚印/脚印指向矛盾

模式二：毒杀案件
├── 慢性毒药：长时间累积致死
├── 急性毒药：即时发作
├── 伪装自然死亡：病发/过敏/猝死
└── 延时装置：定时释放毒物

模式三：意外伪装
├── 伪装成自杀
├── 伪装成意外事故
├── 伪装成其他嫌疑人所为
└── 利用死者自身疾病

模式四：连环杀人
├── 相同手法：标志性杀人风格
├── 不同手法：多起独立案件
├── 模仿杀人：有人模仿历史案件
└── 真相反转：看似连环实为单案
```

## 线索设计体系

### 1. 线索分类

#### 按公开程度
| 线索类型 | 公开时机 | 获取方式 |
|---------|---------|---------|
| 公共线索 | 游戏开始 | 全员共享 |
| 个人线索 | 角色阅读 | 每人独有 |
| 搜证线索 | 搜证环节 | 消耗搜证点 |
| 讨论线索 | 讨论交换 | 玩家自愿分享 |
| 隐藏线索 | 触发条件 | 特定操作解锁 |

#### 按功能分类
```
【直接证据】
├── 物证：凶器、指纹、DNA、毛发
├── 书证：信件、日记、遗嘱、合同
├── 电子证据：通话记录、监控录像、邮件
└── 目击证言：直接目击者陈述

【间接证据】
├── 动机证据：证明某人具有作案动机
├── 机会证据：证明某人在案发时出现在附近
├── 能力证据：证明某人具备作案技能/知识
└── 行为证据：证明某人案发后行为异常

【干扰线索】（红鲱鱼）
├── 指向其他嫌疑人的假证据
├── 误导调查方向的错误信息
├── 看似关键实则无用的信息
└── 转移注意力的突发事件
```

```markdown
示例：

```

## 剧本杀创作流程

### 第一阶段：构思立项
1. 确定题材类型和风格基调
2. 设定故事发生的时代背景
3. 规划角色数量和基本阵营
4. 构思核心凶案的基本框架

### 第二阶段：世界观构建
```markdown
【世界观设计清单】
□ 社会结构（阶层、势力、规则）
□ 地理环境（场景布局、关键地点）
□ 历史背景（与凶案相关的往事）
□ 势力关系（派系、联盟、敌对）
□ 特殊设定（本剧本独有的规则/能力）
```

### 第三阶段：角色设计
1. 根据凶案需要分配角色类型
2. 为每个角色设计完整的背景故事
3. 建立角色之间的复杂关系网络
4. 设计角色的秘密和隐藏任务
5. 平衡各角色的戏份和信息量

### 第四阶段：凶案设计
1. 确定凶手身份和最终动机
2. 设计完整的作案手法和时间线
3. 布置各角色的不在场证明
4. 安排凶手的弱点和可被揭穿的破绽
5. 设计多个推理路径增加游戏性

### 第五阶段：线索网络
1. 规划线索的分配和公开顺序
2. 设计线索之间的关联和递进关系
3. 布置红鲱鱼和干扰项
4. 确保关键证据链完整闭合
5. 平衡信息量，避免过于简单或困难

### 第六阶段：流程设计
```markdown
【游戏流程模板】

┌────────────────────────────────────┐
│ 第一幕：开场（15-20分钟）           │
├────────────────────────────────────┤
│ - 背景介绍                          │
│ - 自我介绍                          │
│ - 第一轮搜证                        │
│ - 初步讨论                          │
├────────────────────────────────────┤
│ 第二幕：深入（30-40分钟）           │
├────────────────────────────────────┤
│ - 核心线索公开                      │
│ - 秘密揭露环节                      │
│ - 指认嫌疑人                        │
│ - 关键证据展示                      │
├────────────────────────────────────┤
│ 第三幕：高潮（20-30分钟）           │
├────────────────────────────────────┤
│ - 集中推理环节                      │
│ - 凶手最后挣扎                      │
│ - 完整真相揭示                      │
│ - 结局复盘                          │
└────────────────────────────────────┘
```

## 题材创作指南

### 古风仙侠类

**世界观要素**
- 修仙体系：境界划分、法宝等级、功法类型
- 宗门势力：正邪两道、主要门派、实力排行
- 天地法则：天道规则、灵气分布、禁地秘境

**常见凶案类型**
- 夺宝杀人：争夺神兵利器、珍稀灵材
- 门户之争：门派内斗、争夺掌门之位
- 情仇纠葛：师徒反目、爱恨情仇
- 邪祟作乱：妖物作祟、魔功反噬

**氛围营造**
```markdown
【场景描写示例】

玄天宗·后山禁地

夜色如墨，寒风凛冽。

后山禁地的入口处，古老的石碑上刻着"擅入者死"
四个血红大字，在月光下显得格外刺目。

穿过石碑，是一条蜿蜒的石阶，两旁的松柏在
风中沙沙作响，仿佛有无数双眼睛在暗中窥视。

石阶尽头，是一座巍峨的石门。门上的封印已经
被人为破坏，淡淡的灵气从门缝中溢出......

【凶案现场】

掌门倒在密室中央，一柄长剑贯穿胸口。

密室内灵光闪烁，到处是打斗的痕迹。墙壁上的
星图被打乱，地上散落着几片破碎的玉简。

最诡异的是，掌门脸上竟然带着一丝诡异的微笑，
仿佛看到了什么不可思议的事情。
```

**世界观要素**
- 社会阶层：贫富差距、职业分层、圈子文化
- 行业生态：各行各业的潜规则和秘密
- 人际关系：家庭、职场、社交网络
- 社会议题：房住不炒、教育内卷、医疗困境

**常见凶案类型**
- 商业阴谋：商业竞争、并购陷阱、资金骗局
- 情感悲剧：婚姻出轨、家庭暴力、爱恨纠葛
- 职场黑暗：职场霸凌、学术造假、商业贿赂
- 社会事件：网络暴力、隐私泄露、正义伸张

**场景设计**
```markdown
【现代场景示例】

云顶大厦·顶层宴会厅

夜幕降临，璀璨的灯光将云顶大厦装点得如同一
颗镶嵌在城市天际线上的钻石。

顶层宴会厅内，名流云集，觥筹交错。

落地窗外，是整座城市的繁华夜景；窗内，是一场
暗流涌动的财富盛宴。

【凶案现场】

宴会厅角落的休息区，富豪王某倒在沙发上。

他手边的威士忌酒杯中，液体已经见底。

他的脸上呈现出不正常的潮红，嘴唇发紫，
显然是中毒身亡。

更诡异的是，他的手机屏幕上显示着一条
刚刚发出的短信："我知道一切，明天见。"

而收信人的名字，却被人为涂改了......
```

### 民国谍战类

**世界观要素**
- 历史背景：军阀混战、国共对峙、抗日战争
- 社会风貌：十里洋场、新旧交替、中西碰撞
- 势力格局：国民党、共产党、日本特务、帮派势力

**常见凶案类型**
- 情报泄露：机密文件被窃、卧底身份暴露
- 锄奸行动：刺杀叛徒、清除内鬼
- 宝藏谜案：历史宝藏、掠夺文物

**氛围营造**
```markdown
【民国场景示例】

上海·法租界·百乐门大饭店

1943年的上海，霓虹灯闪烁。

百乐门大饭店灯火辉煌，这是这座城市最奢华的
娱乐场所。爵士乐声从门内飘出，舞女的歌声
在夜空中回荡。

然而，在这座不夜城的繁华背后，暗流涌动。

【凶案现场】

饭店三楼的贵宾包厢内，著名实业家李某被发现
死在餐桌旁。

他手中紧握着一张烧焦的纸条，上面依稀可见
几个字："明晚八点......接头......"

包厢内的保险箱被打开，里面的重要文件不翼而飞。

而包厢的门锁，从内部反锁着，
窗户却大敞着，夜风吹动着窗帘......
```

## 游戏平衡性设计

### 1. 信息平衡

```markdown
【信息分配原则】

凶手视角：
- 知道自己何时、如何作案
- 知道其他角色的哪些行为是自己造成的
- 需要隐瞒的关键信息
- 可以引导错误方向的"假线索"

好人视角：
- 各自掌握不同碎片化信息
- 需要通过交流拼凑完整真相
- 有人掌握关键证据
- 有人只掌握动机证据

平衡技巧：
- 确保没有角色掌握完整真相
- 让每个角色都有可分享的信息
- 关键证据分散在不同角色手中
- 给凶手一定"可辩驳"的狡辩空间
```

### 2. 阵营平衡

```
【6人本阵营配置示例】

配置A（对抗型）：
- 凶手 × 1
- 帮凶 × 1（知道凶手身份但不是凶手）
- 好人 × 4
特点：凶手需要隐藏，帮凶需要配合演戏

配置B（隐藏身份型）：
- 凶手 × 1
- 侦探 × 1（知道凶手但不知手法）
- 知情者 × 1（知道全部真相但有私心）
- 好人 × 3
特点：侦探和知情者之间存在博弈

配置C（双线型）：
- 凶手A × 1（主线凶手）
- 凶手B × 1（副线凶手）
- 好人 × 4
特点：两个凶手的动机和手法可能有关联
```

### 3. 难度调节

| 难度等级 | 线索数量 | 复杂程度 | 推荐人数 |
|---------|---------|---------|---------|
| 入门级 | 15-20条 | 单一主线，逻辑清晰 | 新手玩家 |
| 标准级 | 25-35条 | 一主一副双线 | 有经验玩家 |
| 困难级 | 40-50条 | 多线并行，真相嵌套 | 硬核玩家 |
| 地狱级 | 50条以上 | 层层反转，细节陷阱 | 骨灰级玩家 |

## 结局设计

### 1. 结局类型

```
【结局分类】

一、根据玩家表现
├── 完美结局：找出全部真相，正确惩罚凶手
├── 普通结局：找出凶手，但遗漏部分真相
├── 失败结局：冤枉好人，真凶逃脱
└── 隐藏结局：达成特殊条件触发额外剧情

二、根据剧情走向
├── 正义结局：凶手伏法，正义得到伸张
├── 悲剧结局：凶手死亡或自杀，真相永远埋葬
├── 悬疑结局：留下开放式结局，真相不明
├── 反转结局：看似正义的结局背后另有隐情

三、根据情感基调
├── 热血结局：正义战胜邪恶，坏人得到惩罚
├── 感人结局：揭示人性温暖，角色得到救赎
├── 恐怖结局：真相揭露后更加恐怖
└── 荒诞结局：黑色幽默，反转不断
```

## 使用场景

### 触发关键词
- 创作剧本杀/设计剧本杀
- 编写谋杀推理故事
- 设计角色和线索
- 策划悬疑游戏
- 创作古风/现代/民国/科幻剧本
- 编写凶案手法
- 设计角色关系
- 制作剧本杀模板
- 策划剧本杀游戏流程

### 输出规范
1. **完整剧本杀结构**：世界观、角色、凶案、线索
2. **详细角色档案**：每个角色都有完整的背景故事
3. **线索网络设计**：清晰的信息递进和推理路径
4. **游戏流程安排**：时间分配和各阶段目标
5. **主持指南**：DM（主持人）的操作指引

## 创作小贴士

1. **动机要合理**：每个角色的动机必须符合其人设
2. **线索要公平**：玩家能通过线索推理出真相
3. **节奏要紧凑**：避免过多无效信息和拖延
4. **反转要精彩**：关键反转必须出乎意料又在情理之中
5. **情感要饱满**：让玩家沉浸其中，产生情感共鸣
6. **细节要严谨**：避免出现逻辑漏洞和矛盾
7. **结局要圆满**：无论好坏结局都要让玩家满意
