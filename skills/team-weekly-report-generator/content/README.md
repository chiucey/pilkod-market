# 团队周报生成技能 (team-weekly-report-generator)

> 将团队各成员的周报合并为一份结构化的项目管理团队周报，并同步生成邮件正文。
> 适用于任何需要定期汇总团队成员周报的项目经理或团队负责人。

## 功能特性

- **一键合并**：提供各成员周报文件路径，自动按标准结构合并
- **风险汇总**：自动提取各成员周报中的风险项，按等级排序
- **邮件正文**：同步生成精简邮件正文，可直接复制发送
- **灵活适配**：通过配置文件适配不同团队、不同行业的周报格式

## 适用场景

- 项目经理定期汇总团队成员周报
- 部门负责人合并下属小组的工作汇报
- 任何需要将多份个人周报整合为团队周报的场景

## 安装步骤

### 方式一：从 ZIP 包安装（推荐）

1. 解压 `team-weekly-report-generator.zip` 得到 `team-weekly-report-generator/` 文件夹
2. 将整个文件夹复制到 WorkBuddy 技能目录：
   - **Windows**：`C:\Users\<你的用户名>\.workbuddy\skills\`
   - **macOS/Linux**：`~/.workbuddy/skills/`
3. 复制后目录结构应为：
   ```
   ~/.workbuddy/skills/team-weekly-report-generator/
   ├── SKILL.md
   ├── README.md
   └── references/
       └── team_members.md
   ```

### 方式二：手动创建

1. 在 `~/.workbuddy/skills/` 下创建 `team-weekly-report-generator` 文件夹
2. 在该文件夹下创建 `SKILL.md`，内容复制自本技能的 SKILL.md
3. 在该文件夹下创建 `references/team_members.md`，填入你的团队信息

## 首次使用配置

安装完成后，**必须**编辑 `references/team_members.md` 填入你的团队信息：

1. 用任意文本编辑器打开 `team_members.md`
2. 修改**团队基本信息**：团队名称、负责人、输出路径
3. 填写**核心成员清单**：姓名、负责项目、角色
4. 根据需要填写**项目与客户对应关系**
5. 保存文件

### team_members.md 关键配置项

| 配置项 | 说明 | 是否必填 |
|:---|:---|:---|
| 团队名称 | 出现在周报标题和文件名中 | 必填 |
| 负责人 | 周报署名和封面信息 | 必填 |
| 周报输出路径 | 生成的周报文件存放目录 | 必填 |
| 核心成员 | 团队成员及对应项目 | 必填 |
| 项目与客户对应关系 | 用于周报中的客户关联信息 | 可选 |

## 使用方法

安装并配置完成后，在 WorkBuddy 对话中使用以下方式触发：

### 触发指令

| 指令示例 | 说明 |
|:---|:---|
| "生成团队周报" | 最常用触发方式 |
| "合并周报" | 同上 |
| "帮我生成周报" | 同上 |
| "生成本周团队工作汇报" | 同上 |

### 提供周报文件

触发后，提供各成员的周报文件路径，例如：

```
帮我生成团队周报，成员周报在以下位置：
@C:/Users/张三/Desktop/周报/张三_周报.md
@C:/Users/李四/Desktop/周报/李四_周报.md
@C:/Users/王五/Desktop/周报/王五_周报.md
```

### 输出结果

技能会生成两个文件：

| 文件 | 说明 |
|:---|:---|
| `<团队名称>_项目管理团队周报_<周期>.md` | 完整的团队周报（含各成员详情、风险汇总、下周重点） |
| `<团队名称>_团队周报_<周期>_邮件正文.md` | 精简版邮件正文（可直接发送邮件使用） |

## 输出结构

生成的团队周报包含以下章节：

```
封面信息（报告周期、汇报人、日期）
├── 一、团队整体概况（概述 + 成员×项目汇总表）
├── 二、项目A：XXX（成员A）
│   ├── 本周数据概览
│   ├── 关键进展
│   ├── 未关闭/待处理事项
│   └── 下周计划
├── 三、项目B：XXX（成员B）
│   └── ...
├── 风险汇总（🔴高风险 → 🟠中风险 → 🟡低风险）
├── 下周全团队重点（优先级矩阵）
└── [单独文件] 邮件正文
```

## 常见问题

### Q: 新成员加入了怎么办？
直接在对话中提供新成员的周报文件即可，技能会自动识别新成员并更新周报。建议同步更新 `team_members.md`。

### Q: 成员周报格式不一样怎么办？
技能能适配不同格式的周报，会尽量从自由文本中提取结构化信息（进展、问题、计划），无法提取的保留原文。

### Q: 输出路径不存在怎么办？
技能会自动创建所需的目录结构，无需手动建文件夹。

### Q: 支持哪些文件格式？
目前支持 Markdown (.md) 和纯文本 (.txt) 格式的周报文件。也支持直接在对话中粘贴周报内容。
