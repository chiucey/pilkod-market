# 专业调解人操作指南

本指南为从事建设工程商事调解的专业调解人提供标准化操作规范，贯彻循证调解方法论，确保调解质量与效率。

## 一、调解员角色定位

### 1.1 核心职责

**三大角色功能**
1. **程序主持者** - 控制调解节奏，维护调解秩序
2. **信息沟通桥梁** - 促进信息对称，引导理性对话
3. **方案推动者** - 提出调解建议，促进利益平衡

### 1.2 专业能力要求

| 能力维度 | 具体要求 | 评估标准 |
|---------|---------|---------|
| 法律知识 | 建设工程法律体系、民法典合同编 | 能够准确引用法条 |
| 工程技术 | 施工流程、计价方式、质量标准 | 能够理解技术争议 |
| 调解技能 | 沟通技巧、利益识别、方案设计 | 能够引导当事人 |
| 类案应用 | 检索能力、分析能力、转化能力 | 能够提供证据支撑 |

## 二、标准化调解流程

### 2.1 受理审查阶段

**接收与初步审查**
```
受理审查清单：
□ 调解申请材料是否齐全
□ 当事人主体资格证明
□ 授权委托手续
□ 争议事实陈述
□ 证据材料目录
□ 调解意向书
```

**案件登记**
- 分配案件编号
- 建立案件档案
- 初步识别争议类型
- 评估案件复杂程度

### 2.2 调解准备阶段

**调解员选定**
| 选定方式 | 适用情形 | 确认时限 |
|---------|---------|---------|
| 当事人共同选定 | 双方协商一致 | 即时确认 |
| 调解机构指定 | 共同委托调解机构 | 2日内确认 |
| 当事人各自选定 | 各自选择后组合 | 3日内确认 |

**事实调查**
1. 审阅申请人提交的书面材料
2. 向被申请人征询答辩意见
3. 要求补充证据材料（如需要）
4. 整理案件时间线与争议焦点

**类案准备**
```
类案准备清单：
□ 相关争议类型的最高院指导案例
□ 本省高院典型案例
□ 类似金额段的裁判规则
□ 可能适用的法律条款
□ 调解成功案例参考
```

### 2.3 调解会议阶段

**标准化开场**
```
调解开场陈述模板：

各位当事人，欢迎参加本次调解会议。

我是[调解机构名称]的调解员[姓名]，今天主持本次调解。

本次调解的依据是《商事调解规范》，调解遵循自愿、中立、保密、高效原则。

调解过程中各方陈述的事实和提交的材料，仅用于调解目的，不对后续可能进行的诉讼或仲裁产生不利影响。

本次调解预计时长[XX]分钟/小时，调解过程中各方可以随时申请休息。

调解达成协议的，我们将协助制作书面调解协议；调解不成的，不影响各方依法维权的权利。

现在，请各位确认是否愿意继续参加本次调解？
```

**争议焦点归纳**
```
争议焦点归纳流程：
1. 请申请人陈述争议事实（5-10分钟）
2. 请被申请人陈述答辩意见（5-10分钟）
3. 调解员总结确认争议焦点
4. 询问各方是否补充
5. 确定争议焦点清单
```

**分组协商（如适用）**
| 协商模式 | 适用情形 | 操作要点 |
|---------|---------|---------|
| 联合调解 | 双方分歧不大 | 共同讨论方案 |
| 分组调解 | 涉及商业秘密 | 轮流沟通 |
| 背靠背 | 分歧严重、需要让步空间 | 单独沟通各方 |

### 2.4 协议达成阶段

**调解方案设计原则**
1. **合法性** - 方案内容不违反法律强制性规定
2. **可行性** - 方案应具有实际履行可能
3. **平衡性** - 各方利益得到合理照顾
4. **明确性** - 条款表述清晰，无歧义

**协议审查要点**
| 条款类型 | 审查要点 |
|---------|---------|
| 工程款条款 | 金额确定/分期/利息计算 |
| 履行期限 | 节点明确/可核实 |
| 违约责任 | 标准合理/可操作 |
| 争议解决 | 后续争议处理机制 |
| 协议效力 | 司法确认或仲裁确认 |

## 三、类案应用技巧

### 3.1 类案引导方法

**预期管理四步法**
```
步骤1：陈述类案结论
"我查阅了类似案件，这类争议通常的裁判结果是..."

步骤2：分析本案差异
"但这个案件有[XX]方面的特殊之处..."

步骤3：引导合理预期
"基于类案分析和本案情况，建议各方考虑..."

步骤4：提出调解建议
"我建议以[XX]为基础进行协商..."
```

### 3.2 常见争议类案索引

**工程款计价争议**
| 类案场景 | 裁判规则 | 调解引导要点 |
|---------|---------|-------------|
| 固定总价合同 | 按合同约定总价结算，无变更不减 | 引导关注变更签证是否齐全 |
| 单价合同工程量争议 | 按实际完成量×单价计算 | 引导核对施工日志与签证 |
| 市场价调差争议 | 合同约定可调时参照信息价 | 引导确认调价依据和时间点 |

**工期延误争议**
| 类案场景 | 裁判规则 | 调解引导要点 |
|---------|---------|-------------|
| 承包方主张顺延 | 须提供发包方原因导致延误的证据 | 引导关注签证单和往来函件 |
| 延误损失认定 | 直接损失需证据支持 | 引导提供损失计算的依据 |
| 混合责任划分 | 按过错比例分担 | 引导分析各自过错程度 |

**质量争议**
| 类案场景 | 裁判规则 | 调解引导要点 |
|---------|---------|-------------|
| 擅自使用后果 | 视为质量合格，但保修期起算 | 引导区分不同责任阶段 |
| 保修责任范围 | 保修期内非使用原因的质量问题 | 引导界定保修范围 |
| 修复费用分担 | 按过错比例分担 | 引导分析质量缺陷成因 |

## 四、质量控制标准

### 4.1 调解质量评估指标

| 指标名称 | 计算方式 | 优秀标准 | 良好标准 |
|---------|---------|---------|---------|
| 调解成功率 | 达成协议数/受理案件数 | ≥75% | ≥60% |
| 协议履行率 | 按时履行数/协议总数 | ≥90% | ≥80% |
| 平均调解周期 | 总天数/案件数量 | ≤15日 | ≤30日 |
| 当事人满意度 | 满意评价数/评价总数 | ≥85% | ≥70% |
| 类案应用率 | 应用类案案件数/总案件数 | ≥80% | ≥60% |

### 4.2 调解员自评清单

```
每案调解后自评：

□ 是否准确识别了全部争议焦点？
□ 是否充分了解了各方的核心诉求与底线？
□ 是否有效利用类案进行了预期管理？
□ 调解方案是否有法律依据支撑？
□ 是否为当事人提供了充分的选择？
□ 协议条款是否清晰、可行？
□ 是否妥善处理了调解不成的情况？
□ 案件档案是否完整归档？
□ 本案是否可以为案例库贡献经验？
□ 本案有哪些可以改进的地方？
```

## 五、特殊情形处理

### 5.1 复杂争议应对

**技术问题识别**
```
技术问题信号：
- 当事人对工程技术细节存在重大分歧
- 需要专业鉴定才能确定事实
- 争议涉及行业专业技术标准

应对策略：
1. 暂停调解，委托专业鉴定
2. 鉴定期间保持沟通
3. 鉴定结论作为调解基础
```

**多方争议调解**
```
多方当事人情形：
- 涉及总包、分包多方法律关系
- 涉及建设单位、施工单位、监理单位
- 涉及多个关联合同

处理要点：
1. 识别各方利益关系
2. 明确调解范围
3. 设计分步解决路径
4. 确保协议可执行性
```

### 5.2 调解僵局突破

**僵局识别**
- 双方坚持立场不让步
- 情绪对抗明显升级
- 陷入细节争论无法推进

**突破技巧**
| 技巧类型 | 操作方法 | 适用情形 |
|---------|---------|---------|
| 搁置争议 | 暂时搁置分歧最大的问题 | 分歧过多 |
| 分层方案 | 提供多个层次的调解方案 | 金额分歧 |
| 分期履行 | 设计分期付款方案 | 资金困难 |
| 条件交换 | 明确各方让步的条件 | 互有胜负 |
| 权威引入 | 引用类案增加方案可信度 | 预期差异大 |

### 5.3 调解终止情形

**应当终止调解的情形**
1. 一方明确表示不愿意继续调解
2. 调解超过法定期限无实质进展
3. 发现涉嫌犯罪线索
4. 一方当事人下落不明
5. 其他不宜继续调解的情形

**终止程序**
```
终止调解程序：
1. 宣布调解终止
2. 记录调解过程（不公开）
3. 告知当事人后续救济途径
4. 整理案件档案
5. 归档案件材料
```
