# 代理人操作指南

本指南为建设工程商事调解中的代理人（律师、法律顾问）提供标准化操作规范，涵盖从接受委托到调解达成的全流程指引。

## 一、代理前的案件评估

### 1.1 接受委托决策框架

**代理价值评估矩阵**

| 评估维度 | 评估要点 | 决策参考 |
|---------|---------|---------|
| 法律依据充分性 | 争议是否有明确法律支撑 | 支撑越充分，代理价值越高 |
| 证据完备程度 | 核心证据是否齐全 | 证据决定胜诉概率 |
| 争议金额 | 争议标的大小 | 需覆盖代理成本 |
| 调解可行性 | 对方调解意愿 | 影响调解效率 |
| 时间成本 | 诉讼/仲裁周期预估 | 对比调解周期 |

**利益冲突核查**
```
接受委托前核查清单：
□ 是否与对方当事人存在利益冲突
□ 是否曾为对方提供法律服务
□ 是否与调解机构存在利益关系
□ 是否符合律师执业规范要求
```

### 1.2 案件信息采集

**委托人访谈要点**
1. 争议背景与起因
2. 己方主张与诉求
3. 对方可能的抗辩
4. 既往协商/诉讼经历
5. 商业目标与调解底线
6. 保密需求与关系考量

**争议材料清单收集**

| 材料类别 | 具体内容 | 重要性 |
|---------|---------|-------|
| 合同文件 | 施工合同、补充协议、变更签证 | 核心证据 |
| 履行证据 | 开工报告、验收记录、付款凭证 | 事实认定 |
| 往来函件 | 索赔函、回复函、催款函 | 时效与意思表示 |
| 鉴定材料 | 工程造价鉴定、质量鉴定报告 | 专业问题 |
| 财务凭证 | 工程款支付记录、发票 | 付款事实 |

## 二、证据准备与组织

### 2.1 证据清单编制

**工程款纠纷证据清单**

```
第一类：合同依据
□ 建设工程施工合同（含专用条款）
□ 中标通知书
□ 补充协议/会议纪要
□ 合同变更文件

第二类：工程量证据
□ 工程报价单/清单
□ 施工图纸
□ 变更签证单
□ 竣工图
□ 结算书（含异议回复）

第三类：付款证据
□ 付款计划/进度表
□ 已付款凭证
□ 欠款对账单
□ 利息计算明细

第四类：期限证据
□ 开工报告
□ 竣工报告
□ 验收记录
□ 交付证明

第五类：其他证据
□ 类案检索报告
□ 行业惯例参考
□ 往来函件
```

### 2.2 类案检索报告准备

**类案检索策略**
1. **己方优势类案** - 检索支持己方主张的裁判规则
2. **对方风险类案** - 检索对对方不利的裁判结果
3. **中间结果类案** - 展示争议的不确定性
4. **调解成功类案** - 寻找可参考的调解方案

**类案引用技巧**
- 引用审级较高的案例
- 关注案件事实的相似性
- 说明类案对本案的适用性
- 避免断章取义

### 2.3 证据目录编制

**标准化证据目录格式**

```
证据目录

案号：[内部案号]
编制人：[律师姓名]
日期：[YYYY-MM-DD]

序号 | 证据名称 | 证明目的 | 证据类型 | 页码
-----|---------|---------|---------|-----
1    | 建设工程施工合同 | 证明合同关系及权利义务 | 书证 | 1-20
2    | 竣工验收报告 | 证明工程已竣工验收 | 书证 | 21-25
3    | 工程结算书 | 证明工程款数额 | 书证 | 26-30
...  | ...     | ...     | ...   | ...

共计：[X]份证据，[X]页
```

## 三、调解方案设计

### 3.1 己方调解目标设定

**调解目标层次分析**

| 层次 | 目标类型 | 说明 | 优先级 |
|-----|---------|------|-------|
| 理想目标 | 必须达成的底线 | 低于此则无调解意义 | 最高 |
| 合理目标 | 期望达成的标准 | 正常情况应可实现 | 高 |
| 可接受目标 | 最低可接受条件 | 需要对方一定让步 | 中 |
| 放弃目标 | 可以放弃的条件 | 对方核心诉求可能涉及 | 低 |

**让步策略设计**

```
让步策略模板：

[核心让步点1]
- 让步条件：[满足什么条件才让步]
- 让步底线：[最低可接受程度]
- 让步方式：[一次性/分次/交换]

[核心让步点2]
...

[禁止让步点]
- [无论如何不能放弃的条件]
```

### 3.2 调解方案库

**工程款调解方案模板**

| 方案类型 | 适用情形 | 核心内容 |
|---------|---------|---------|
| 全额支付方案 | 对方资金充裕 | 按结算金额一次性/分期支付 |
| 折让方案 | 双方对金额存在争议 | 按一定比例折让后支付 |
| 分期付款方案 | 对方资金紧张 | 分期支付，设定履约担保 |
| 债权转股权 | 长期合作关系 | 部分债权转为股权 |
| 资产抵债方案 | 对方有可变现资产 | 以资产抵偿工程款 |

**工期延误调解方案模板**

| 方案类型 | 适用情形 | 核心内容 |
|---------|---------|---------|
| 互不追究方案 | 双方均有过错 | 各自承担己方损失 |
| 过错分担方案 | 可分清责任比例 | 按比例分担延误损失 |
| 补偿方案 | 一方明显过错 | 过错方向对方补偿 |
| 工期顺延方案 | 延误系发包方原因 | 顺延工期+费用补偿 |

## 四、调解会议参与

### 4.1 会前准备清单

```
调解会议前48小时检查清单：

□ 证据材料准备完整
  □ 证据原件/复印件准备
  □ 证据目录更新
  □ 类案检索报告准备

□ 调解方案准备
  □ 己方调解意见书
  □ 备选方案准备
  □ 让步预案准备

□ 人员安排
  □ 委托人出席确认
  □ 授权手续完备
  □ 备份联系人确定

□ 技术准备
  □ 会议室设备确认
  □ 材料打印份数
  □ 电子设备备用

□ 心理准备
  □ 委托人预期管理
  □ 谈判策略复习
  □ 僵局应对预案
```

### 4.2 会议陈述技巧

**开场陈述要点**
1. 清晰表达己方立场
2. 引用证据支持主张
3. 引用类案增强说服力
4. 表明调解诚意
5. 提出初步调解方案

**陈述结构模板**

```
代理人陈述结构：

1. 案件背景（1-2分钟）
   "本案系[发包人/承包人]与[承包人/发包人]之间的建设工程施工合同纠纷..."

2. 事实陈述（3-5分钟）
   "关于本案争议焦点，我方认为..."

3. 法律分析（2-3分钟）
   "根据《民法典》第XXX条及建设工程司法解释第XXX条..."

4. 类案支持（1-2分钟）
   "检索显示，类似案件的裁判规则是..."

5. 调解建议（1-2分钟）
   "基于上述分析，我方建议的调解方案是..."
```

### 4.3 谈判应对技巧

**常见情形应对**

| 情形 | 应对策略 | 话术示例 |
|-----|---------|---------|
| 对方质疑证据 | 强调证据三性 | "该证据符合证据的真实性、合法性、关联性要求" |
| 对方提出类案 | 分析事实差异 | "该案与本案在[XX]方面存在显著差异" |
| 对方僵持不让 | 引入第三方参考 | "从类案来看，双方各让一步是比较常见的结果" |
| 对方情绪激动 | 暂停+引导 | "我们建议休息5分钟，冷静后继续讨论" |
| 对方突然加码 | 坚守底线 | "这超出了我方的授权范围，需要与委托人确认" |

## 五、协议确认与签署

### 5.1 协议审查要点

**调解协议审查清单**

| 审查维度 | 审查要点 | 风险提示 |
|---------|---------|---------|
| 主体 | 当事人名称、印章是否准确 | 主体错误导致协议无效 |
| 标的 | 工程款金额、计算方式是否明确 | 金额模糊易生争议 |
| 履行 | 付款节点、验收标准是否清晰 | 节点不清无法执行 |
| 期限 | 各阶段时限是否明确 | 时限不明难以主张违约 |
| 违约 | 违约情形、责任标准是否明确 | 违约责任过轻等于无约束 |
| 解除 | 协议解除条件是否合理 | 保留退出条款 |
| 争议 | 后续争议解决途径 | 约定仲裁优于诉讼 |

### 5.2 委托人确认程序

```
协议签署前确认流程：

1. 协议草案阶段
   □ 律师内部审核
   □ 向委托人汇报要点
   □ 收集委托人修改意见

2. 协议定稿阶段
   □ 确认各方修改意见
   □ 整合形成最终版本
   □ 委托人最终确认

3. 签署阶段
   □ 核实签署人授权
   □ 确认协议份数
   □ 留存签署记录

4. 签署后
   □ 及时送达各方
   □ 跟进履行情况
   □ 建立履行台账
```

## 六、调解不成后的处理

### 6.1 程序转换决策

**是否进入诉讼/仲裁评估**

| 评估因素 | 评估内容 | 决策参考 |
|---------|---------|---------|
| 调解差距 | 调解方案与期望的差距 | 差距越小诉讼价值越高 |
| 证据状态 | 核心证据是否有变化 | 新证据可能改变态势 |
| 时间成本 | 诉讼周期预估 | 调解已耗费时间 |
| 成本收益 | 诉讼成本与预期收益 | 综合评估代理价值 |
| 关系考量 | 是否需要维护商业关系 | 诉讼可能破坏关系 |

### 6.2 程序转换衔接

```
调解转诉讼/仲裁衔接清单：

□ 收集调解过程中形成的所有书面材料
□ 整理调解中对方自认的事实
□ 评估调解中展示的证据策略
□ 准备诉讼/仲裁立案材料
□ 申请财产保全（如需）
□ 准备答辩状/仲裁反请求
□ 跟进调解未达成的新进展
```
