# 申请人/当事人操作指南

本指南为建设工程商事调解中的申请人（发包方、承包方、分包方等当事人）提供全面指引，帮助理解调解流程、准备材料、维护权益。

## 一、了解商事调解

### 1.1 什么是商事调解

**商事调解的定义**
商事调解是指在调解机构或调解员的主持下，依据法律、政策和商业惯例，在当事人自愿的基础上，促成各方达成和解的专业争议解决方式。

**调解与诉讼/仲裁的区别**

| 对比维度 | 调解 | 诉讼 | 仲裁 |
|---------|-----|------|-----|
| 启动方式 | 双方自愿申请 | 一方起诉即可 | 需仲裁协议 |
| 主持人 | 调解员（中立） | 法官（裁判者） | 仲裁员（裁判者） |
| 结果形式 | 调解协议 | 判决书 | 裁决书 |
| 法律效力 | 合同效力 | 强制执行效力 | 强制执行效力 |
| 保密性 | 完全保密 | 公开审理 | 一般保密 |
| 周期 | 短（通常1个月内） | 长（数月到数年） | 中等 |
| 费用 | 低 | 中等 | 较高 |
| 关系维护 | 有利于维护 | 可能损害 | 可能损害 |
| 专业性 | 可选专业调解员 | 法官不一定精通专业 | 可选专业仲裁员 |

### 1.2 建设工程调解的适用场景

**适宜调解的争议类型**
- 工程款结算争议（金额存在争议但事实基本清楚）
- 工期延误索赔（责任划分存在争议）
- 合同变更争议（变更范围、费用存在争议）
- 质量缺陷争议（保修责任存在争议）
- 合作关系维护（双方有长期合作意向）

**不适宜调解的情形**
- 一方存在根本违约且无调解诚意
- 涉及第三方权益（在建工程抵押、购房者权益）
- 涉嫌违法犯罪线索
- 需要法院调查取证的事实问题

### 1.3 调解的优势

**为什么选择调解**

| 优势维度 | 具体说明 |
|---------|---------|
| 效率高 | 通常1个月内完成，远快于诉讼/仲裁 |
| 成本低 | 调解费用远低于诉讼/仲裁代理费 |
| 保密好 | 调解过程和结果保密，不影响商业声誉 |
| 关系维护 | 调解氛围平和，有利于维护长期合作关系 |
| 执行好 | 自愿达成的协议履行意愿更高 |
| 灵活强 | 调解方案可以超越诉讼救济范围 |
| 专业强 | 可选择具有工程技术背景的调解员 |

## 二、申请调解

### 2.1 申请前准备

**自我评估清单**

```
调解适宜性自评：

1. 争议事实是否基本清楚？
   □ 是 - 适合调解
   □ 否 - 可能需要鉴定或诉讼前置

2. 对方是否有调解意愿？
   □ 有 - 可直接申请
   □ 无 - 需要先沟通或选择其他途径

3. 我的核心诉求是什么？
   □ [填写]

4. 我的底线是什么？
   □ [填写]

5. 我能接受的让步范围？
   □ [填写]

6. 调解不成能否接受诉讼/仲裁？
   □ 是 - 可放心参与调解
   □ 否 - 需要评估调解风险
```

### 2.2 选择调解机构

**主流调解机构参考**

| 机构类型 | 代表机构 | 特点 |
|---------|---------|------|
| 法院附设调解 | 各地法院调解中心 | 与诉讼衔接便利 |
| 行业协会调解 | 建设工程协会调解委员会 | 专业性强 |
| 商会调解 | 各地商会调解中心 | 商业氛围浓厚 |
| 人民调解 | 街道/社区人民调解 | 费用低 |
| 仲裁机构调解 | 仲裁委调解中心 | 可直接转仲裁确认 |

**选择因素考量**

| 考量因素 | 说明 |
|---------|------|
| 专业性 | 是否具有建设工程专业背景调解员 |
| 公信力 | 机构声誉与权威性 |
| 费用 | 调解费用标准 |
| 效率 | 平均调解周期 |
| 衔接性 | 能否便捷申请司法确认 |

## 三、参与调解会议

### 3.1 会前准备

**心理准备**

```
调解心理准备要点：

1. 正确认识调解性质
   - 调解是协商解决，不是"打官司"
   - 调解员是中立的，不会偏袒任何一方

2. 合理设定预期
   - 调解结果通常是双方让步的结果
   - 不可能完全按照己方意愿达成

3. 控制情绪
   - 避免情绪化表达
   - 聚焦问题解决而非指责对方

4. 准备让步预案
   - 明确哪些可以让步
   - 明确让步的底线
```

**材料准备**

```
会议材料准备清单：

□ 身份证件原件（用于核验）
□ 授权委托书原件（如委托代理人）
□ 证据原件（用于质证）
□ 调解申请书副本
□ 己方调解方案
□ 计算器/电子设备（计算金额用）
□ 纸笔记录
□ 名片（初次见面）
```

### 3.2 调解会议流程

**各阶段参与要点**

| 阶段 | 调解员工作 | 当事人参与要点 |
|-----|-----------|--------------|
| 开场 | 介绍程序规则 | 确认同意参与 |
| 陈述 | 引导各方陈述 | 清晰陈述己方事实 |
| 质疑 | 归纳争议焦点 | 针对性回应对方陈述 |
| 协商 | 提出调解建议 | 提出方案、讨论让步 |
| 确认 | 达成或终止 | 确认协议或记录分歧 |

**陈述技巧**

| 技巧 | 说明 | 示例 |
|-----|------|------|
| 事实陈述 | 客观描述事实 | "合同约定工程款为1000万元" |
| 证据支撑 | 用证据支持主张 | "我方已提交结算书证明" |
| 类案引用 | 引用类似案件 | "类似案件通常这样处理" |
| 表达诉求 | 明确表达期望 | "我方希望一次性解决" |
| 展现诚意 | 表示调解意愿 | "我方愿意考虑合理让步" |

### 3.3 协商与让步

**让步原则**

```
调解让步原则：

1. 有原则的让步
   - 让步必须有交换
   - 让步必须有回报
   - 避免单方面让步

2. 有底线的让步
   - 提前确定底线
   - 底线不能让步
   - 底线不明时及时暂停

3. 有记录的让步
   - 让步条件书面记录
   - 避免口头承诺
   - 留存协商记录

4. 有策略的让步
   - 让步时机要恰当
   - 让步幅度要合理
   - 让步方式要灵活
```

**常见问题应对**

| 问题 | 应对方式 |
|-----|---------|
| 对方提出不合理要求 | 引用证据和类案说明不合理性 |
| 双方差距过大 | 提出中间方案或搁置分歧 |
| 对方情绪激动 | 建议短暂休息 |
| 对方突然加码 | 坚守底线，暂停协商 |
| 调解员建议与预期不符 | 理性分析，可拒绝但需说明理由 |

## 四、签署调解协议

### 4.1 协议签署前审查

**必须审查的内容**

| 审查要点 | 审查内容 | 如有问题 |
|---------|---------|---------|
| 当事人信息 | 名称、印章是否正确 | 当事人主体错误 |
| 争议金额 | 是否与协商一致 | 金额计算错误 |
| 履行期限 | 各节点是否明确 | 时限模糊无法执行 |
| 履行方式 | 付款方式、地点 | 约定不明易生争议 |
| 违约责任 | 违约情形、责任标准 | 违约条款缺失 |
| 争议解决 | 后续争议如何处理 | 需明确后续途径 |

### 4.2 协议效力选择

**不同效力级别**

| 效力类型 | 取得方式 | 特点 |
|---------|---------|------|
| 一般协议 | 当场签署 | 合同效力，依赖自愿履行 |
| 司法确认 | 申请法院确认 | 可强制执行（民诉法第201条） |
| 仲裁确认 | 申请仲裁机构确认 | 可强制执行 |

**建议**
- 争议金额较大时，建议申请司法确认
- 对方信用状况一般时，建议司法确认
- 涉及复杂履行条件时，建议仲裁确认

### 4.3 协议签署注意事项

```
签署注意事项：

1. 核对无误后再签署
   - 核对当事人名称
   - 核对金额数字
   - 核对履行期限
   - 核对违约条款

2. 确保签署人有授权
   - 法定代表人直接签署
   - 或持有有效授权委托书

3. 保留协议副本
   - 己方留存协议原件或清晰复印件
   - 记录签署时间和地点

4. 跟进履行
   - 建立履行提醒
   - 保留履行凭证
   - 及时主张违约
```

## 五、协议履行与违约

### 5.1 履约管理

**己方履约管理**

```
履约管理清单：

1. 仔细阅读协议条款
   □ 明确各阶段履行节点
   □ 理解违约责任条款
   □ 留存协议文本

2. 按时履行己方义务
   □ 设置履行提醒
   □ 提前准备履行资金/文件
   □ 按时完成各节点

3. 规范履行过程
   □ 保留履行凭证
   □ 通知对方履行情况
   □ 要求对方书面确认

4. 应对履行困难
   □ 提前与对方沟通
   □ 争取协议变更
   □ 避免违约
```

**督促对方履约**

```
督促履约流程：

1. 履行期限届满前
   □ 提醒对方即将到期
   □ 确认对方准备情况

2. 履行期限届满后
   □ 向对方发送书面催告
   □ 载明已到期款项
   □ 要求限期履行

3. 催告无果后
   □ 评估违约程度
   □ 准备启动后续程序
   □ 考虑司法确认执行

4. 协议已司法确认
   □ 直接申请强制执行
   □ 提供财产线索
```

### 5.2 违约应对

**对方违约的应对**

| 违约情形 | 应对措施 |
|---------|---------|
| 部分违约 | 书面催告，要求补救 |
| 完全违约 | 评估是否解除协议 |
| 预期违约 | 提前采取保全措施 |
| 反复违约 | 考虑司法途径 |

**己方违约的处理**

| 违约原因 | 建议措施 |
|---------|---------|
| 资金困难 | 主动沟通，申请分期 |
| 条件未成就 | 提供证明，争取理解 |
| 理解分歧 | 协商解释，达成补充 |
| 不可抗力 | 及时通知，保存证据 |

## 六、调解不成后的选择

### 6.1 程序选择

**调解不成后的救济途径**

| 程序 | 适用条件 | 周期 | 费用 | 特点 |
|-----|---------|------|-----|------|
| 诉讼 | 几乎所有民事纠纷 | 长 | 中 | 审级完整，可上诉 |
| 仲裁 | 需有仲裁协议 | 中 | 高 | 一裁终局，专业性强 |
| 再次调解 | 条件变化或分歧缩小 | 短 | 低 | 视情况选择 |

### 6.2 转换程序准备

```
从调解转换到诉讼/仲裁准备清单：

□ 收集调解过程中形成的书面材料
□ 整理调解中各方的陈述记录
□ 评估调解中获得的新信息
□ 准备诉讼/仲裁立案材料
□ 考虑是否申请财产保全
□ 聘请专业代理律师（如需）
```

### 6.3 调解经验总结

```
从调解中学习的要点：

1. 了解对方立场
   - 调解中了解对方的真实诉求
   - 为后续谈判/诉讼积累信息

2. 评估己方证据
   - 发现己方证据的优劣
   - 为后续程序补充证据

3. 识别争议焦点
   - 明确核心争议所在
   - 聚焦后续争议解决

4. 建立沟通渠道
   - 与对方保持联系
   - 为再次协商保留可能
```

## 七、常见问题解答

### Q1：调解是否意味着我认输了？

**答**：不是。调解是双方自愿协商解决争议的方式，不代表任何一方认输。调解结果通常是双方让步后的折中方案，是正常解决商业争议的方式。

### Q2：调解员会偏袒对方吗？

**答**：不会。调解员必须保持中立，不偏袒任何一方。调解员的工作是帮助双方找到共同点，促进达成双方都能接受的解决方案。

### Q3：如果调解成功，我可以反悔吗？

**答**：一般不可以。调解协议是双方自愿达成的合同，双方应当遵守。如果已申请司法确认，则具有强制执行效力。

### Q4：调解不成会影响我的诉讼权利吗？

**答**：不会。调解不成是正常的争议解决过程，不影响任何一方依法维权的权利。调解中的陈述在诉讼中也不能作为不利证据。

### Q5：调解费用是多少？

**答**：调解费用因机构和争议金额而异，通常按争议标的金额的一定比例收取，远低于诉讼费用。具体标准可咨询相关调解机构。
