## 三、商事调解规范

### 3.1 SB/T 10946-2012《商事调解规范》核心要求

**调解基本原则**
1. **自愿原则** - 当事人自愿申请、选择调解员、达成协议
2. **中立原则** - 调解员保持中立，不偏袒任何一方
3. **保密原则** - 调解过程保密，不得泄露
4. **效率原则** - 及时、便捷解决争议

**调解程序要求**
| 程序阶段 | 核心要求 | 时限标准 |
|---------|---------|---------|
| 申请受理 | 提交申请材料 | 3日内审查 |
| 调解员选定 | 双方选定或指定 | 2日内确认 |
| 调解准备 | 事实调查与证据 | 不超过15日 |
| 调解会议 | 主持调解协商 | 协商达成或终止 |
| 协议制作 | 书面调解协议 | 当场或3日内 |
| 司法确认 | 可申请法院确认 | 按民诉法程序 |

**调解协议效力**
- 一般效力：合同约束力
- 司法确认效力：强制执行效力（民诉法第201条）
- 仲裁确认效力：仲裁执行依据

## 四、类案裁判规则汇编

### 4.1 工程款计价类案

**典型裁判要旨**
1. **总价合同结算**：合同约定总价，在无变更签证情况下，按总价结算
2. **单价合同结算**：按实际完成工程量乘以单价计算
3. **市场价调整**：合同约定可调价时，参照工期信息价调整
4. **鉴定优先原则**：双方对工程量有争议时，依申请启动鉴定

**类案检索关键词**
- "建设工程施工合同" + "工程款" + "结算"
- "黑白合同" + "工程款" + "优先适用"
- "固定总价" + "工程变更" + "计价"

### 4.2 工期延误类案

**典型裁判要旨**
1. **举证责任**：承包方主张工期延误的，由承包方举证证明延误事实及原因
2. **因果关系**：须证明延误与发包方过错有因果关系
3. **工期顺延**：因发包方原因导致，工期应相应顺延
4. **损失计算**：延误损失须有证据支持，以直接损失为限

**类案检索关键词**
- "工期延误" + "责任划分" + "因果关系"
- "工期顺延" + "签证" + "举证责任"
- "延误索赔" + "窝工损失" + "证明标准"

### 4.3 工程质量类案

**典型裁判要旨**
1. **验收标准**：工程质量应符合国家标准及合同约定
2. **擅自使用**：发包方擅自使用未经竣工验收工程，视为质量合格
3. **保修责任**：在保修期内，承包方应承担保修责任
4. **修复费用**：质量缺陷修复费用按过错比例分担

**类案检索关键词**
- "工程质量" + "验收标准" + "合格认定"
- "擅自使用" + "质量责任" + "视为合格"
- "质量保修" + "保修期" + "修复费用"

### 4.4 优先受偿权类案

**典型裁判要旨**
1. **主体范围**：与发包人订立建设工程施工合同的承包人享有优先受偿权
2. **行使期限**：自发包人应当给付工程价款之日起算18个月
3. **权利范围**：包括工程款本金、利息、违约金、损害赔偿金
4. **优先顺位**：优先于抵押权、普通债权，劣后于消费者购房请求权

**类案检索关键词**
- "建设工程优先受偿权" + "18个月" + "起算点"
- "优先受偿权" + "工程款" + "范围认定"
- "优先受偿权" + "消费者购房" + "对抗效力"

1. 鉴定申请由主张权利方提出
