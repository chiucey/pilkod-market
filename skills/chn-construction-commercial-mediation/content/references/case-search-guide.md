# 类案检索与数据库建设指南

本文档为建设工程商事调解提供系统化的类案检索方法论与数据库建设规范，贯彻循证医学方法论的最佳证据原则。

## 一、类案检索理论基础

### 1.1 循证调解的证据等级体系

在建设工程调解中建立类案检索的证据金字塔：

| 证据等级 | 类型 | 来源 | 检索优先级 |
|---------|------|------|-----------|
| **Level 1** | 最高院指导性案例 | 最高人民法院公报、最高院官网 | ★★★★★ |
| **Level 2** | 高院典型案例 | 各省高院发布的参考案例 | ★★★★☆ |
| **Level 3** | 中院裁判规则 | 裁判文书网、审判白皮书 | ★★★☆☆ |
| **Level 4** | 类案裁判要旨 | 学术整理、实务汇编 | ★★☆☆☆ |
| **Level 5** | 调解实践经验 | 行业协会、调解中心案例库 | ★☆☆☆☆ |

### 1.2 类案检索的价值

**对于调解员**
- 建立合理裁判预期，引导当事人决策
- 识别争议解决的关键证据与法律问题
- 形成有说服力的调解方案

**对于代理人/申请人**
- 评估己方诉讼风险与调解优势
- 准备支持己方主张的类案依据
- 预测对方可能提出的抗辩理由

| 数据库 | 内容特点 | 适用场景 |

### 2.2 检索策略矩阵

**按争议类型匹配检索策略**

| 争议类型 | 核心关键词 | 扩展关键词 | 关联法条 |
|---------|-----------|-----------|---------|
| 工程款计价 | 工程款结算、固定总价、可调单价 | 计价方式变更、市场价调整、清单计价 | 合同解释一第19-21条 |
| 工期延误 | 工期延误、工期顺延、延误责任 | 窝工损失、开竣工日期、进度延误 | 合同解释一第10条 |
| 质量争议 | 工程质量、竣工验收、质量缺陷 | 保修责任、修复费用、验收标准 | 合同解释一第11-15条 |
| 合同无效 | 合同无效、建设工程合同、无效后果 | 资质挂靠、违法分包、折价补偿 | 合同解释一第1-6条 |
| 优先受偿权 | 优先受偿权、工程款优先、18个月 | 行使期限、优先顺位、受偿范围 | 合同解释一第22-27条 |
| 黑白合同 | 黑白合同、阳合同、工程款结算 | 实质性变更、中标合同、结算依据 | 合同解释一第6、21条 |

## 三、类案分析与应用

### 3.1 裁判要旨提取方法

**要素化分析框架**
```
案例名称：[案号] [当事人] 案件
法院层级：[最高人民法院/XX省高院/XX市中院]
裁判日期：[YYYY-MM-DD]
争议类型：[根据类型体系归类]

【裁判要旨】
[核心裁判规则，一句话概括]

【案情概述】
[关键事实摘要，重点关注与本案相似的事实]

【法律适用】
[引用的法律条文与司法解释]

【调解参考要点】
1. [对调解方案设计有价值的要点]
2. [对当事人预期管理有价值的要点]
3. [对证据准备有价值的要点]
```

### 3.2 类案适用规则

**类案拘束力评估**
1. **指导性案例**：具有事实上的拘束力，应当参照
2. **公报案例**：具有重要参考价值，可资借鉴
3. **本院案例**：同院裁判具有先例约束
4. **他院案例**：仅具有说服参考价值

**类案适用注意事项**
- 识别案件事实的差异性，不可机械套用
- 关注法律适用背景的变化（司法解释更新）
- 区分调解解决与裁判解决的路径差异

### 3.3 类案引导调解实践

**基于类案的调解预期管理**

| 类案结论 | 调解引导策略 |
|---------|-------------|
| 支持某方主张 | 引用类案增强该方信心，促成让步 |
| 双方均有风险 | 展示类案的不确定性，促进折中方案 |
| 裁判结果分散 | 说明争议的法律模糊性，推动灵活解决 |

## 四、数据库建设规范

### 4.1 建设工程调解数据库架构

**数据库层级结构**
```
chn-construction-mediation-db/
├── case_library/              # 案例库
│   ├── level1_supreme/       # 最高院指导案例
│   ├── level2_highcourt/     # 高院典型案例
│   ├── level3_midcourt/      # 中院参考案例
│   └── level4_practice/      # 调解实践案例
├── legal_reference/           # 法律依据库
│   ├── civil_code/          # 民法典相关
│   ├── judicial_interp/     # 司法解释
│   └── regulatory_docs/     # 部门规章
├── mediation_patterns/       # 调解模式库
│   ├── payment_dispute/     # 工程款纠纷模式
│   ├── quality_dispute/     # 质量争议模式
│   └── schedule_dispute/    # 工期延误模式
└── template_library/         # 模板库
    ├── case_search_report/   # 类案检索报告
    ├── mediation_plan/      # 调解方案模板
    └── agreement_draft/     # 协议草案模板
```

### 4.2 案例标签体系

**核心标签维度**

| 标签维度 | 可选值 | 说明 |
|---------|-------|------|
| dispute_type | 工程款/工期/质量/合同效力/优先权 | 争议类型一级分类 |
| dispute_subtype | 计价方式/变更索赔/验收争议等 | 争议类型二级分类 |
| contract_type | 总价合同/单价合同/成本加酬金 | 合同类型 |
| case_outcome | 支持原告/支持被告/折中/驳回 | 裁判结果 |
| mediation_result | 成功/部分成功/失败 | 调解结果 |
| amount_range | <100万/100-500万/500-2000万/>2000万 | 争议金额 |
| region | 东部/中部/西部/东北 | 地域分布 |
| court_level | 最高院/高院/中院/基层 | 审级 |
| case_year | 2019/2020/2021/2022/2023/2024/2025 | 裁判年份 |

### 4.3 数据采集标准

**案例采集字段要求**
```
必填字段：
- 案号
- 审理法院
- 裁判日期
- 争议类型
- 裁判要旨

推荐字段：
- 当事人信息（脱敏处理）
- 案件基本事实
- 证据采信情况
- 法律适用分析
- 调解参考要点

可选字段：
- 调解过程记录（脱敏）
- 调解方案细节
- 协议履行情况
```

### 4.4 数据库维护与更新

**更新机制**
| 更新类型 | 触发条件 | 更新周期 |
|---------|---------|---------|
| 指导案例新增 | 最高院发布新指导案例 | 即时更新 |
| 司法解释变化 | 新司法解释施行 | 即时更新 |
| 类案库扩充 | 调解案例积累达到阈值 | 季度更新 |
| 标签体系优化 | 基于使用反馈优化 | 半年度评估 |

### 5.2 快速检索清单

**调解前快速类案核实清单**

```
□ 1. 本案争议焦点是否已有明确裁判规则？
□ 2. 最高院是否有指导性案例？
□ 3. 本省/本市高院是否有典型案例？
□ 4. 类案裁判结果是否一致？
□ 5. 类案事实与本案是否高度相似？
□ 6. 类案形成时间是否在新司法解释之后？
□ 7. 类案裁判结果对调解方案设计的启示？
□ 8. 是否需要专业数据库进行深度检索？
□ 9. 类案证据要求对己方证据准备的启示？
□ 10. 类案结果是否影响当事人调解预期？
```
