# 中国建设工程商事调解技能

**核心公式：循证调解 = 最佳可用证据 + 调解员专业判断 + 当事人价值取向**

循证医学方法论应用于建设工程商事调解，通过系统化的证据收集、类案分析和标准化流程，提升调解的专业性与可预测性。

## 一、循证五步法

将循证医学的严谨步骤系统性地应用于建设工程纠纷解决：

| 步骤 | 循证医学 | 建设工程调解 |
|-----|---------|-------------|
| 第一步 | 提出临床问题 | 识别争议焦点 |
| 第二步 | 检索最佳证据 | 收集支撑材料 |
| 第三步 | 评价证据质量 | 证据等级分级（GRADE适配版） |
| 第四步 | 应用证据于临床 | 制定调解策略 |
| 第五步 | 评价治疗效果 | 持续迭代改进 |

## 二、五大核心模块

### 模块一：争议证据图谱（DEM）——调解的"诊断"

争议证据图谱（Dispute Evidence Map, DEM）是调解的起点与"诊断"工具，借鉴循证医学中的系统评价（Systematic Review）方法。

**核心交付物：**
- 证据图谱：可视化矩阵形式，清晰呈现"争议焦点-证据支撑"的完整证据链
- 证据等级分类评价报告：基于GRADE体系适配版
- 证据缺口诊断报告：识别证据链中的薄弱环节

**GRADE适配版证据分级体系：**

| 等级 | 可信度 | 标准 | 示例 |
|-----|-------|------|-----|
| **A级** | 高可信度 | 多源、可交叉印证的书证/物证 | 双方签章合同原件、竣工验收报告、监理日志与施工日志交叉印证、司法鉴定报告 |
| **B级** | 中高可信度 | 单方制作但可通过其他方式部分验证 | 单方施工日志、进度照片、单方委托检测报告（附资质） |
| **C级** | 中等可信度 | 间接证据或基于行业惯例的推定 | 政府发布造价信息、行业定额标准、同期市场价格数据 |
| **D级** | 低可信度 | 口头证言或无书证佐证的主观陈述 | 当事人单方陈述、证人证言（无其他证据佐证） |

**降级因素：** 偏倚风险、不一致性、间接性、不精确性、发表偏倚

**实践案例：** 在潍坊"老窑匠"调解中心处理的建材质量纠纷中（案号：WF-LYJ-TJ-2023-015），双方均无书面质检报告。通过组合供应商出厂批次影像记录（B级）、物流签收与运输记录（B级）、同批次物料留样（B级），构建完整替代证据链，最终促成和解。

### 模块二：类案知识库（CMCR）——调解的"参考系"

类案知识库（Construction Mediation Case Repository, CMCR）为调解建立量化"参考系"，借鉴Meta分析思路。

**核心元数据维度：** 纠纷类型、工程类型、金额区间、调解周期、调解结果、关键证据等级、所用策略、和解比例、行业领域

**专项数据产品：**
- 调解前景评估报告：量化预测个案调解成功率，建议和解金额区间与调解周期
- 和解方案合理性审查意见：与类案基准对照，包含风险警示
- 行业年度调解数据报告：宏观趋势分析

**知识库建设三阶段：**
1. 启动期：依赖专家经验估算与框架搭建
2. 成长期：持续案件数据入库，实证校准
3. 成熟期：自动化统计分析、智能匹配与趋势预测

### 模块三：多专业协同评估（MDEA）——调解的"会诊"

多专业协同评估（Multi-Disciplinary Evidence Assessment, MDEA）借鉴循证医学MDT模式。

**团队构成：**
- 调解员（主持人）- 主导协调，控制会议流程
- 法律专家 - 负责法律合规性与证明力评价
- 工程技术专家 - 负责工程技术合理性与质量评估
- 造价专家 - 负责造价一致性与经济性评估

**MDEA工作流程：**
```
┌─────────────────────────────────────────────────────────────┐
│                    MDEA协同评估流程                         │
├─────────────────────────────────────────────────────────────┤
│ 1. 案件受理 → 调解员识别需要MDEA介入                         │
│ 2. 组建团队 → 按需邀请法律/工程/造价专家                     │
│ 3. 独立评审 → 各专家分别出具专项意见                         │
│ 4. 联合"会诊" → 三方意见交叉印证                             │
│ 5. 综合汇总 → 主持人整合形成《综合评估报告》                  │
│ 6. 反馈应用 → 评估结果用于指导调解策略                       │
└─────────────────────────────────────────────────────────────┘
```

**核心产品：**
1. 争议焦点"会诊"意见：三方专家分别出具意见，汇总形成《综合评估报告》
2. 证据可信度联合评价：法律证明力、工程合理性、造价一致性三维度交叉审查
3. 调解方案可行性评估：法律合规性、工程技术可行性、造价合理性三维度论证

**适用情形：**
- 争议金额超过一定门槛（如500万元以上）
- 涉及复杂工程技术问题
- 造价鉴定存在争议
- 双方对事实认定分歧较大

### 模块四：循证调解策略（EIMP）——调解的"治疗"

循证调解策略（Evidence-Informed Mediation Plan, EIMP）核心原则：**证据等级决定策略类型**

| 证据构成特征 | 主要证据等级 | 推荐策略 | 策略要点 |
|-------------|-------------|---------|---------|
| 权利义务关系清晰 | A级为主 | 评估型调解（Evaluative） | 调解员基于强证据直接评估法律结果，引导回归契约理性 |
| 事实争议较大 | B/C级为主 | 分段调解法 | 分解为若干子议题，逐项核对证据、弥合认知差距 |
| 商业关系仍可维系 | C/D级为主 | 促进型调解（Facilitative） | 弱化对抗，挖掘潜在利益和未来合作可能 |
| 证据极为薄弱 | D级为主 | 如实告知型 | 清晰揭示证据劣势及法律风险，为后续程序做准备 |

**策略制定嵌入要求：** 必须符合《商事调解条例》（2023年）自愿原则（第3条）、保密原则（第4条）、合法性原则（第5条）、诚信原则（第6条）。

**专项服务与产品：**
- 调解策略备忘录：精简版策略指导文件
- 和解方案设计服务：涵盖金额合理性、支付方式、履约保障机制、税务处理、执行便利性及长期关系维护等多维度方案设计与评估
- 调解谈判过程记录与偏差分析：记录谈判动态，分析策略执行效果

### 模块五：效果评价与知识管理（MOKMS）——调解的"随访"

效果评价与知识管理系统（Mediation Outcome & Knowledge Management System, MOKMS）核心原则：**未调成案例与调成案例同等重要**

**多维评价指标：**
- 结果指标：调解成功率、和解协议履行率
- 质量指标：当事人满意度、程序公正感、实质公正感
- 效能指标：纠纷复发率、平均调解周期、成本效益比

**失败分析制度（借鉴M&M讨论会）：**
从调解员因素（如策略失当）、证据因素（如关键证据缺失）、当事人因素（如缺乏和解意愿）三个维度进行根因分析，并将分析结论转化为改进措施。

**知识管理闭环：** 实践→效果记录→知识提炼→知识入库→指导实践

**持续专业发展（CPD）：**
基于评价结果和分析结论，为调解员设计CPD方案，重点提升：
- 证据评价能力
- 策略制定能力
- 僵局处理能力
- 沟通引导能力
- 新法规跟进能力

## 三、标准化工作流程

循证调解的标准工作流程将五大核心模块有机串联，形成从案件受理到知识沉淀的完整闭环。

### 阶段一：案件评估与证据初始化（DEM应用）

**对于专业调解人：**
1. 接收调解申请材料
2. 核验当事人主体资格与授权委托
3. 识别争议焦点与法律关系
4. 构建争议证据图谱（DEM）
5. 进行证据等级分级评价

**对于代理人/申请人：**
1. 整理证据材料清单（按GRADE分级整理）
2. 准备争议事实陈述
3. 收集类案检索报告
4. 评估己方诉讼/调解优势

### 阶段二：类案检索与数据库建设（CMCR应用）

**检索策略（证据等级排序）：**
1. 最高人民法院指导性案例
2. 省级高级人民法院典型案例
3. 同一法院/仲裁机构关联案例
4. 行业协会调解案例库

**数据库建设要求：**
- 建立类案标签系统（争议类型、裁判结果、调解成功率）
- 追踪调解方案与裁判结果的对照
- 积累最佳实践调解方案库

### 阶段三：调解方案设计与论证（EIMP应用）

**基于证据的调解方案框架：**
1. **法律依据层** - 引用具体法条与类案裁判要旨
2. **事实认定层** - 证据清单、举证责任分配、证据等级评价
3. **利益平衡层** - 各方核心诉求与底线分析
4. **方案推荐层** - 基于证据等级的策略选择与分层调解建议

**建设工程调解核心问题清单：**
| 问题类型 | 关键证据 | 裁判规则要点 |
|---------|---------|-------------|
| 工程款计价 | 合同、变更签证、结算书 | 计价方式优先、市场价调整 |
| 工期延误 | 开工报告、进度计划、签证单 | 责任划分、因果关系认定 |
| 质量争议 | 验收记录、鉴定报告 | 保修责任、质量标准 |
| 优先受偿权 | 竣工证明、催款函 | 行使期限、范围认定 |

### 阶段四：调解会议程序（MDEA应用）

**标准化调解流程：**
1. 开场陈述（调解员介绍程序规则）
2. 事实澄清（各方陈述与证据展示）
3. 争议归纳（调解员总结焦点）
4. 多专业协同评估（如需要，启动MDEA）
5. 方案讨论（基于EIMP策略框架）
6. 达成协议（或记录分歧）

### 阶段五：协议固化与履行跟踪（MOKMS应用）

**调解协议类型选择：**
1. **一般调解协议** - 双方自愿履行
2. **司法确认协议** - 申请法院确认（民诉法第201条）
3. **仲裁确认协议** - 申请仲裁机构确认

**效果评价与归档：**
- 记录调解结果与履行情况
- 进行调解效果评价
- 未调成案例必须进行失败分析

## 四、质量底线（不可逾越）

1. **不可编造类案数据**：所有引用的类案数据及统计指标，必须有明确、可追溯的来源记录。严禁虚构或篡改案例数据。

2. **不可超出证据等级做结论**：所有分析、预测和策略建议，必须严格基于当前案件的证据等级。禁止将C级证据的推断作为A级证据的确定性结论输出，即"**A证说A话，D证说D话**"。

3. **未调成案例必须做失败分析**：每个案例都是宝贵的学习资产。对于未达成和解的案件，必须严格执行MOKMS中的"失败分析"流程。

## 五、适用场景与对象

**适用场景：**
1. 调解方案设计：为特定纠纷量身定制调解路线图与和解方案
2. 争议焦点分析：系统梳理并定位纠纷的核心法律与事实争点
3. 类案数据查询：为案件预测和策略制定提供数据基准
4. 证据等级评价：对现有证据材料进行标准化分级与可信度评估
5. 调解策略制定：根据证据等级和案件特点，选择并规划最优调解策略
6. 调解效果评估：对已完成的调解案件进行多维度后评估
7. 商事调解条例合规咨询：确保调解程序与方案符合《商事调解条例》要求

**适用对象：**
1. 商事调解组织与调解员
2. 建设工程施工企业（承包商）
3. 建设单位（业主方）
4. 造价咨询机构
5. 建设工程专业律师团队
6. 行业协会与司法行政机关
