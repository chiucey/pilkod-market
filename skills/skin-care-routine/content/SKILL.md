# 护肤保养指南

帮助用户分享科学护肤方法，建立有专业度的护肤博主账号。

## 内容定位

### 目标受众画像
- 18-40岁女性
- 关注皮肤健康和美容
- 有护肤困扰（痘痘、敏感、美白等）
- 愿意尝试新护肤品

### 账号人设建议
- 专业护肤知识分享者
- 真实测评护肤品
- 不追求完美皮肤
- 帮助粉丝找到适合自己的产品

## 内容类型

### 1. 护肤教程类
- 早晚护肤步骤
- 不同肤质护理方法
- 护肤手法教学
- 护肤顺序详解

### 2. 产品测评类
- 护肤品测评
- 护肤品对比
- 新品试用
- 平替推荐

### 3. 问题解决类
- 痘痘肌护理
- 敏感肌修护
- 美白淡斑
- 抗老紧致

### 4. 生活护肤类
- 内调外养
- 护肤习惯养成
- 医美心得
- 换季护肤

## 爆款标题公式

```
痛点型：「油痘肌逆袭！我用了这套方法终于不长痘了」
数字型：「坚持护肤100天，皮肤状态年轻了5岁」
对比型：「用错护肤品烂脸？看看这10个护肤误区」
清单型：「精简护肤只需要这5步！省时又有效」
揭秘型：「贵的护肤品一定好用？揭秘大牌平替」
```

## 内容结构模板

### 护肤步骤类正文结构
1. **肤质判断**：先了解自己的肤质
2. **问题分析**：常见的护肤困扰
3. **步骤详解**：每一步的作用和要点
4. **产品推荐**：不同价位的好物推荐
5. **注意事项**：避免的护肤误区

### 产品测评类正文结构
1. **产品信息**：品牌、价格、容量
2. **包装设计**：外观质地
3. **成分分析**：主要成分及功效
4. **使用感受**：实际使用效果
5. **适合肤质**：谁适合这款产品
6. **总结推荐**：是否值得购买

## 注意事项

1. **实事求是**：真实评价，不夸大效果
2. **因人而异**：强调肤质差异，不强推
3. **成分安全**：关注成分，不推荐三无产品
4. **专业边界**：不提供医疗建议，引导就医
