# REITs基金分析参考手册

## 一、核心分析指标体系

### 1. 估值指标

| 指标 | 计算公式 | 理想范围 | 说明 |
|------|---------|---------|------|
| P/NAV | 市值/NAV | <1.0折价, >1.0溢价 | NAV为净资产价值，越低越有投资价值 |
| 预期分派率 | 年度分红/市价 | 4%-8% | 中国REITs分派率通常在4%-8%之间 |
| IRR | 内部收益率 | >5% | 综合考虑分红和资本增值 |

### 2. 运营指标

| 指标 | 计算公式 | 理想范围 | 说明 |
|------|---------|---------|------|
| 出租率 | 实际出租面积/可租赁面积 | >90% | 越高越好，但需关注行业特性 |
| 租金增长率 | (本期租金-上期)/上期 | >2% | 抗通胀能力体现 |
| 续租率 | 续租面积/到期面积 | >70% | 越高越稳定 |
| 租户集中度 | 最大租户占比 | <30% | 越低越分散风险 |

### 3. 财务指标

| 指标 | 计算公式 | 理想范围 | 说明 |
|------|---------|---------|------|
| EBITDA | 息税折旧摊销前利润 | 正向稳定 | 核心运营盈利能力 |
| 资产负债率 | 总负债/总资产 | <40% | REITs通常低于传统公司 |
| 现金流分派率 | 可分配现金流/分红 | 90%-110% | 中国要求不低于90% |

## 二、中国公募REITs底层资产分类

### 1. 产业园类
- **代表基金**：博时蛇口产园REIT、中金厦门安居REIT
- **特点**：租金收入稳定，但受区域经济影响大
- **关注点**：出租率、租约到期分布、租户行业结构

### 2. 仓储物流类
- **代表基金**：中金普洛斯REIT、盐港REIT
- **特点**：租金水平与物流需求相关
- **关注点**：辐射范围、自动化程度、租户结构

### 3. 高速公路类
- **代表基金**：平安广州广河REIT、浙商沪杭甬REIT
- **特点**：现金流稳定但缺乏增长性，受宏观影响大
- **关注点**：通行量变化、剩余收费期限

### 4. 清洁能源类
- **代表基金**：中航首钢生物质REIT、鹏华深圳能源REIT
- **特点**：政策支持，但受补贴政策影响
- **关注点**：电价政策、发电效率

### 5. 保障性住房类
- **代表基金**：厦门安居REIT、深圳人才安居REIT
- **特点**：政策属性强，租金受限
- **关注点**：出租率、租金溢价空间

## 三、主要风险识别清单

### 政策风险
- [ ] 底层资产相关政策变化（如房地产调控、环保政策）
- [ ] REITs监管政策调整
- [ ] 税收政策变化

### 市场风险
- [ ] 利率变化对REITs估值的影响
- [ ] 区域市场供需变化
- [ ] 行业竞争加剧

### 资产质量风险
- [ ] 出租率下降
- [ ] 租金下调压力
- [ ] 租户违约或退租
- [ ] 资产折旧或减值

### 流动性风险
- [ ] 日均成交量过低
- [ ] 折溢价率异常
- [ ] 市场整体流动性紧张

### 管理风险
- [ ] 管理人更换
- [ ] 关联交易风险
- [ ] 扩张策略激进

## 四、投资评级标准

### 买入评级
- P/NAV < 0.9（折价明显）
- 预期分派率 > 5%
- 出租率稳定 > 85%
- 无重大风险事项

### 持有评级
- P/NAV 在 0.9-1.1 之间
- 预期分派率 4%-5%
- 运营平稳
- 无明显催化剂

### 减持评级
- P/NAV > 1.2（溢价明显）
- 预期分派率 < 4%
- 出租率下降或风险上升
- 存在重大风险事项

## 五、行业数据参考

### 中国公募REITs市场概况（2024-2025）
- 已上市REITs数量：30+只
- 总市值：约600亿元
- 平均分派率：约5%
- 平均P/NAV：约1.0

### 主要交易所
- 上海证券交易所（REITs代码以508开头）
- 深圳证券交易所（REITs代码以180开头）

### 重要时间节点
- **季报披露**：每个季度结束后15个工作日内
- **半年报披露**：上半年结束后2个月内
- **年报披露**：年度结束后3个月内
- **分红除息**：通常在年报披露后1-2个月
