# Content Automation Workflow - 内容自动化工作流技能

## 激活条件
当用户要求以下内容时激活：
- "内容自动化"、"一站式内容创作"
- "热门选题生成"、"选题策划"
- "多平台分发"、"内容矩阵"
- "社交媒体运营"、"自动生成内容"
- "内容工作流"、"内容发布"
- "帮我写一篇[主题]文章"
- "生成一周的内容选题"
- "将内容发布到[平台]"

## 核心功能

本技能整合完整的内容自动化工作流，将以下步骤串联成自动化流水线：

```
信息收集 → 热门选题 → 长文创作 → 多平台拆解 → 人性化润色 → 发布提示
```

### 第一步：信息收集（免费工具）

使用内置搜索工具收集相关信息，支持多种免费来源：

**搜索策略：**
- 使用 `batch_web_search` 搜索行业最新资讯
- 使用 `extract_content_from_websites` 提取目标内容
- 使用 `brave_search` 进行深度信息检索

**搜索关键词模板：**
```
行业关键词 + "最新" + "趋势"
领域关键词 + "热门话题" + "讨论"
主题 + "观点" + "分析" + "2026"
```

**信息收集清单：**
- [ ] 行业最新动态和趋势
- [ ] 热门话题和讨论焦点
- [ ] 竞品/同行内容分析
- [ ] 用户痛点和需求挖掘
- [ ] 数据统计和研究报告
- [ ] 专家观点和案例分享

### 第二步：热门选题生成

基于收集的信息，生成高质量选题库：

**选题生成原则：**
1. **价值驱动** - 提供实用价值（教程/技巧/资源）
2. **情感共鸣** - 引发读者情感反应
3. **时效性强** - 紧跟热点和趋势
4. **差异化** - 提供独特视角
5. **可执行** - 读者能立即行动

**选题类型模板：**

| 类型 | 模板 | 适用平台 |
|------|------|----------|
| 教程类 | "X步教你[达成目标]" | 公众号/知乎 |
| 清单类 | "[N]个[相关主题]技巧" | 全平台 |
| 对比类 | "[A] vs [B]：你应该选哪个" | 知乎/公众号 |
| 案例类 | "[品牌/人物]是如何做到的" | 微博/小红书 |
| 观点类 | "[争议性观点]的真相" | 知乎/公众号 |
| 资源类 | "[主题]必备资源清单" | 全平台 |
| 趋势类 | "[年份][主题]趋势预测" | 知乎/公众号 |
| 问题类 | "为什么你[失败经历]" | 全平台 |

**选题输出格式：**
```json
{
  "topics": [
    {
      "title": "选题标题",
      "angle": "切入角度",
      "target_audience": "目标读者",
      "key_points": ["要点1", "要点2"],
      "seo_keywords": ["关键词1", "关键词2"],
      "platform_suggestion": "推荐平台"
    }
  ]
}
```

### 第三步：长文内容创作（母版）

生成高质量长文内容母版，适用于进一步拆解：

**内容结构模板：**

```markdown
# [标题] - 吸引眼球的标题

## 开篇钩子（100字以内）
- 痛点陈述
-惊人数据
- 反差对比
- 故事引入

## 正文框架

### 核心观点1
- 论点说明
- 案例/数据支持
- 读者收益点

### 核心观点2
- 论点说明
- 案例/数据支持
- 读者收益点

### 核心观点3
- 论点说明
- 案例/数据支持
- 读者收益点

## 实用建议/行动清单
1. 具体建议1
2. 具体建议2
3. 具体建议3

## 总结升华
- 核心要点回顾
- 金句收尾
- 行动号召（CTA）

## 结尾互动
- 引发评论的问题
- 分享引导语
```

**写作要点：**
- 每个段落不超过3-4句话
- 使用具体数据和案例
- 保持口语化，避免AI痕迹
- 自然嵌入关键词
- 段落间逻辑连贯

### 第四步：多平台内容拆解

将长文拆解为各平台适配的短内容：

#### 4.1 Twitter/X 帖子（3-10条推文线程）

**格式规范：**
- 每条推文：最多280字符
- 钩子推：吸引点击
- 核心内容推：3-7条
- 结尾CTA推：引导互动

**线程结构：**
```
1/ 🧵 [主题]深度解析
   为什么[反常识观点]...

2/ [核心要点1]
   关键论据和案例...

3/ [核心要点2]
   具体数据和支撑...

[继续核心要点...]

N/ 结论 + CTA
   你的收获是？
   评论区见👇
```

#### 4.2 LinkedIn 文章

**格式规范：**
- 字数：1000-2000字
- 开头：个人故事或痛点
- 中间：3-5个核心观点
- 结尾：思考题 + 互动引导

**模板：**
```
[个人经历/故事开头 - 50字]

⚡️ [核心观点标题]

你是否也遇到过[痛点]？
今天分享[核心洞察]...

📌 关键点1：[标题]
   [2-3句说明]

📌 关键点2：[标题]
   [2-3句说明]

📌 关键点3：[标题]
   [2-3句说明]

💡 [升华观点]

你怎么看？
评论区聊聊👇

#相关话题标签
```

#### 4.3 微信公众号

**格式规范：**
- 字数：1500-3000字
- 小标题清晰
- 配图位置标注
- 互动引导

**模板：**

**格式规范：**
- 字数：200-500字
- 短平快
- 多用#话题#

**模板：**

```
[互动问题]
```

**格式规范：**
- 标题：30字内，含关键词
- 正文：500-1000字
- 标签：#关键词#

**模板：**

### 第五步：人性化润色（去除AI痕迹）

基于Wikipedia AI写作特征指南进行润色：

**识别的AI写作模式（需消除）：**
1. ❌ 过度强调重要性/趋势/遗产
2. ❌ "令人惊叹"、"改变游戏规则"等夸张词汇
3. ❌ 以-ing结尾的浅层分析
4. ❌ 促销和广告语言
5. ❌ 模糊归属（"研究表明"、"专家说"）
6. ❌ 公式化结构（"挑战与前景"）
7. ❌ AI常用词汇（"深入探索"、"释放"）
8. ❌ 避免使用"is/are"系动词
9. ❌ 负面排比结构
10. ❌ 规则三过度使用
11. ❌ 破折号过度使用
12. ❌ 虚假具体性（"研究表明XXX人"）

**润色后的特征：**
- ✅ 句子长度自然变化
- ✅ 使用简单直接的词汇
- ✅ 保留系动词正常使用
- ✅ 具体人名/案例/数据
- ✅ 语气口语化/个性化
- ✅ 段落长度自然分布
