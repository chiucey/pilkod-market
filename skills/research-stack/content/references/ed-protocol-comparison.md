# 实验方案差异分析框架
> ED 在 Step 3 对研究者提供的多个实验方案进行对比分析的核心框架。
> 本文件是 domain-agnostic 通用工具，适用于任何科学领域的实验设计对比。

---

## 一、差异分析的逻辑前提

**不是罗列差异，是分析差异背后的科学推理逻辑。**

研究者在文献或实验记录中看到的不同方案，差异本身不是目的——
选择哪个方案，取决于你想回答的科学问题。

```
方案 A 的选择理由 = 该方案最适合回答你的核心假设
方案 B 的选择理由 = B 的某个特征在特定条件下优于 A
```

**ED 的职责**：帮助研究者理解差异，并基于研究目的做出有依据的选择。

## 二、通用对比维度（适用于任何领域）

对任何实验方案，从以下维度进行对比分析：

### 维度 1：测量方式（Measurement Approach）
```
对比问题：该方案测量的是什么？是直接测量还是间接测量？
- 直接测量：观察/计数/仪器读取
- 间接测量：用代理指标推断

对研究问题的影响：
  直接 → 因果推断更强
  间接 → 需要控制更多混杂因素
```

### 维度 2：控制水平（Control Level）
```
对比问题：该方案控制了哪些变量？没有控制什么？
- 全面控制：实验室环境（温度、光照、营养等）
- 部分控制：现场/自然条件
- 无控制：观察性研究

对研究问题的影响：
  控制越强 → 内部效度越高，生态效度可能越低
  控制越弱 → 更接近真实世界，但需处理更多混淆变量
```

### 维度 3：时间维度（Temporal Structure）
```
对比问题：是一次测量还是重复测量？是前瞻性还是回顾性？
- 横断面：一时点快照
- 队列/纵向：多时点追踪
- 干预前后：自身对照设计

对研究问题的影响：
  纵向 → 可推断时间顺序，但失访是主要风险
  横断面 → 经济高效，但因果推断受限
```

### 维度 4：样本来源（Sample Source）
```
对比问题：样本来自什么群体？样本量依据是什么？
- 随机抽样：可推广至更大群体
- 便利抽样：经济高效，但有选择性偏差风险
- 病例对照：基于结局回溯暴露

对研究问题的影响：
  样本代表性越强 → 外部效度（可推广性）越高
```

### 维度 5：检测手段（Detection Method）
```
对比问题：测量工具的精度如何？选择性/灵敏度如何？
- 高分辨率仪器：可检测低丰度分析物
- 低分辨率仪器：检测限较高，但操作简单
- 新型方法 vs 经典方法：精度 vs 稳健性的权衡

对研究问题的影响：
  检测限以上的效应才能被发现
  方法灵敏度决定了你能检测到的效应大小下限
```

## 三、研究类型专项对比框架

### A. 分析化学 / 仪器方法对比
```
常见对比维度：
- 分离效率（色谱分辨率）
- 灵敏度（LOD / LOQ）
- 精确度（重复性 RSD%）
- 准确度（回收率%）
- 样本通量（样品/小时）
- 耗材成本 vs 数据质量

方案对比表模板：
| 指标 | 方案 A | 方案 B | 推荐 |
|------|--------|--------|------|
| 检出限 | | | |
| 定量限 | | | |
| 重复性(%RSD) | | | |
| 回收率(%) | | | |
| 线性范围 | | | |
| 样本通量 | | | |
| 每次分析成本 | | | |

决策原则：
→ 如果研究目的是发现/探索：优先灵敏度
→ 如果研究目的是定量验证：优先精确度和准确度
→ 如果样本量有限：优先样本通量和耗材成本
```

### B. 生物学 / 医学干预研究对比
```
常见对比维度：
- 随机化方式
- 盲法设计
- 对照组设置
- 干预剂量/强度
- 结局指标测量时间点
- 样本量估算依据

方案对比表模板：
| 指标 | 方案 A | 方案 B | 推荐 |
|------|--------|--------|------|
| 设计类型 | | | |
| 随机化 | | | |
| 盲法 | | | |
| 对照 | | | |
| 主要结局 | | | |
| 样本量 | | | |
| 效应量假设 | | | |

决策原则：
→ 优效性研究：需要足够样本量检测有临床意义的最小效应
→ 等效性/非劣效研究：需要基于等效边界的特定设计
→ 探索性研究：样本量可较小，但需预先说明局限性
```

### C. 心理学 / 行为科学对比
```
常见对比维度：
- 被试内 vs 被试间 vs 混合设计
- 效应量（d）基准
- 测量工具信度
- 实验范式生态效度

方案对比表模板：
| 指标 | 方案 A | 方案 B | 推荐 |
|------|--------|--------| |
| 设计类型 | | | |
| 被试量（power=.80）| | | |
| 效应量假设 | | | |
| 测量工具信度 | | | |
| 实验时长 | | | |
| 生态效度 | | | |

决策原则：
→ 被试内设计：更敏感（控制个体差异），但有练习效应风险
→ 被试间设计：操作简单，但需要更大样本量
```

### D. 生态学 / 农学对比
```
常见对比维度：
- 田间试验布局（随机区组/裂区设计）
- 重复数（生物学重复 vs 技术重复）
- 抽样策略（破坏性抽样 vs 非破坏性）
- 空间尺度

方案对比表模板：
| 指标 | 方案 A | 方案 B | 推荐 |
|------|--------|--------|------|
| 试验布局 | | | |
| 生物重复 | | | |
| 技术重复 | | | |
| 抽样方法 | | | |
| 分析单元 | | | |

决策原则：
→ 田间变异大 → 适当增加区块重复
→ 破坏性抽样 → 考虑时间序列或空间替代抽样方案
```

## 四、ED 差异分析输出格式

当研究者提供了多个方案时，ED 输出：

```
## 实验方案差异分析 — [研究问题 / 实验目的]

### 方案概览
| 方案 | 主要特征 | 推荐情境 |

### 关键差异对比
[使用上述适用领域的对比维度表格]

### ED 分析：每个差异背后的科学推理

对于每个关键差异：
"方案 A 选择了 [特征 X]，而方案 B 选择了 [特征 Y]。
差异的科学理由是：[分析]。"

### ED 推荐

| 如果你的研究目的是 | 推荐方案 | 理由 |
|-------------------|---------|------|
| [具体研究目的] | [方案名] | [理由] |

### 待研究者确认
- [研究者需要做出判断的关键选择点]
```

## 五、使用说明

**谁用：**
- ED 在 Step 3 使用此框架分析研究者提供的方案
- 分析维度根据研究类型选择（ABCD任选，跨类型时组合使用）

**输出：**
→ ED 基于此框架输出分析结论
→ 推荐研究者确认方向后，写入实验设计草案
→ 如需更专业的领域参数，ED 向 LR 或 DA loop back
