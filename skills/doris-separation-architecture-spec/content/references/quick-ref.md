## 2. 压缩算法决策

| 场景 | 预期缓存命中率 | 瓶颈 | 推荐压缩 | 理由 |
|------|--------------|------|---------|------|
| 高频查询热表（小表） | >70% | CPU解压 | **LZ4** | 数据已在本地Cache |
| 实时同步ODS表 | 30-50% | 混合 | **LZ4** | 写入频繁但查询也频繁 |
| 离线日志/归档表（大表） | <30% | 网络IO | **ZSTD** | 主要从MinIO读取 |
| 全表扫描分析 | <20% | 网络IO | **ZSTD** | 大量数据从远端读取 |

## 3. 分区分桶决策

### 分区判断标准

| 总数据量 | 是否分区 | 分区粒度 |
|----------|----------|----------|
| < 10GB | 不分区 | - |
| 10GB - 100GB | 可选分区 | 按月 |
| 100GB - 1TB | 建议分区 | 按日 |
| > 1TB | 必须分区 | 按日/小时 |

### 分桶数决策

| 分区数据量 | 推荐分桶数 | 单桶数据量 |
|------------|------------|------------|
| < 1GB | 1-4 | 250MB-1GB |
| 1GB - 10GB | 4-8 | 250MB-2.5GB |
| 10GB - 50GB | 8-16 | 625MB-6.25GB |
| 50GB - 200GB | 16-32 | 1.56GB-12.5GB |
| > 200GB | 32-64 | 需配合二级分区 |

**公式**: 分桶数 = 分区数据量(GB) / 目标单桶数据量(GB)
**规则**: 分桶数应 >= BE节点数 × 2

## 4. 索引选择决策

```
查询条件是什么？
    │
    ├── 等值过滤（=, IN）
    │   ├── 高基数 → 布隆过滤器
    │   └── 低基数 → Bitmap
    │
    ├── 范围查询
    │   ├── Key列 → 前缀索引
    │   └── 非Key列 → 倒排索引
    │
    └── 文本匹配 → 倒排索引
```

## 5. 数据仓库分层速查

| 层级 | 作用 | 表模型 | 审计字段 |
|------|------|--------|----------|
| ODS | 原始数据保留 | UNIQUE KEY | etl_time, source_system, source_table |
| DWD | 数据清洗标准化 | DUPLICATE | dw_start_date, dw_end_date, is_current |
| DWS | 轻度汇总 | AGGREGATE | stat_date |
| ADS | 应用指标 | DUPLICATE | update_time |
| DIM | 维度表 | UNIQUE KEY | 拉链字段 |

## 8. 建表Checklist
