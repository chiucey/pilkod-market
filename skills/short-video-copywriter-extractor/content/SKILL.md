# 短视频文案提取工具

## 技能概述

专业的短视频文案智能提取工具，支持抖音、快手、小红书等主流平台公开分享链接解析，一键提取视频标题、简介、人声口播文案，输出纯净可直接复制的文本。

## 核心能力

### 多平台支持
- **抖音**：支持 v.douyin.com 短链接和完整分享链接
- **快手**：支持 v.kuaishou.com 短链接和分享链接
- **小红书**：支持 xhslink.com 和 xiaohongshu.com 分享链接

### 内容提取
- **标题提取**：精准识别视频标题
- **简介提取**：完整获取视频描述信息
- **口播文案**：提取视频中的人声口播内容

### 输出格式
- 结构化分类输出
- 纯净无冗余排版
- 一键复制功能
- Markdown 格式导出

## 使用方式

### 输入格式
```
抖音链接示例：
- https://v.douyin.com/xxxxx
- https://www.douyin.com/video/xxxxx

快手链接示例：
- https://v.kuaishou.com/xxxxx
- https://www.kuaishou.com/short-video/xxxxx

小红书链接示例：
- https://xhslink.com/xxxxx
- https://www.xiaohongshu.com/explore/xxxxx
```

### 提取结果
提取完成后将返回以下结构化内容：
- 📌 标题：视频标题
- 📝 简介：视频描述信息
- 🎤 口播文案：人声内容（若有字幕/语音识别数据）
