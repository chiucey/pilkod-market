# 蚀刻问题AI回答汇总技能

## 功能说明

本技能帮助蚀刻工程师快速获取和对比多个AI平台对蚀刻问题的专业回答，通过表格形式直观展示不同AI的解答差异。

## 触发条件

当用户以蚀刻工程师身份提出以下类型问题时触发：
- 蚀刻工艺参数问题（如：蚀刻速率、选择比、均匀性等）
- 蚀刻设备故障诊断
- 蚀刻工艺优化建议
- 蚀刻缺陷分析与解决方案
- 蚀刻气体配方咨询
- 等离子蚀刻技术问题
- 干法/湿法蚀刻工艺问题

## 工作流程

### 步骤1：识别蚀刻问题

解析用户问题，提取关键技术要素：
- 问题类型（工艺/设备/缺陷/优化）
- 材料体系（硅/金属/光刻胶/介质层等）
- 蚀刻类型（干法/湿法/ICP/RIE等）
- 具体症状或参数

### 步骤2：构建搜索查询

根据问题内容构建三个AI平台兼容的查询：
- 通用蚀刻术语
- 专业技术描述
- 问题上下文

### 步骤3：模拟AI回答

基于蚀刻工程领域的专业知识，针对用户问题提供三个视角的回答：

| AI平台 | 回答特点 |
|--------|----------|
| 千问 | 注重基础原理和通用方案 |
| DeepSeek | 侧重数据驱动的分析和建议 |
| 专家 | 提供行业最佳实践和深度见解 |

### 步骤4：生成汇总表格

将三个AI的回答整理成统一的对比表格格式：

```
| 对比维度 | 千问 | DeepSeek | 专家 |
|---------|------|----------|------|
| 问题诊断 | ... | ... | ... |
| 原因分析 | ... | ... | ... |
| 解决方案 | ... | ... | ... |
| 参数建议 | ... | ... | ... |
| 注意事项 | ... | ... | ... |
```

## 表格说明

汇总表格按以下维度对比：

1. **问题诊断** - 对问题的定性判断
2. **原因分析** - 可能的技术原因
3. **解决方案** - 具体处理建议
4. **参数建议** - 推荐的工艺参数范围
5. **注意事项** - 操作风险和禁忌

## 回答模板

### 表格标题
**《[具体蚀刻问题]》多AI回答对比分析**

### 表格内容
包含上述5个对比维度的完整回答

### 底部总结
基于三个AI回答，给出综合建议和最优方案推荐

## 适用场景示例

- "等离子蚀刻机腔室污染怎么解决？"
- "硅深孔蚀刻选择比偏低是什么原因？"
- "如何提高金属蚀刻的各向异性？"
- "蚀刻速率不稳定怎么调试参数？"
- "光刻胶去除不干净有什么好方法？"

## 专业术语库

本技能使用的蚀刻专业术语：
- 选择比（Selectivity）
- 各向异性（Anisotropy）
- 各向同性（Isotropy）
- 蚀刻速率（Etch Rate）
- 均匀性（Uniformity）
- 负载效应（Loading Effect）
- 侧壁钝化（Sidewall Passivation）
- 深刻蚀（Deep Etch）
- BOSCH工艺
- DRIE（深反应离子蚀刻）
