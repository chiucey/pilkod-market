# FB-WhatsApp 产品宣传视频自动化技能

## 核心工作流

本技能将产品效果图自动转化为适配 Facebook 和 WhatsApp 的竖屏宣传视频。

### 流程链路

```
产品效果图 → 生成标准电商产品主图 → 图生短视频 → 自动配旁白+字幕 → 裁剪9:16竖屏 → 导出直接发FB/WhatsApp
```

---

## 执行步骤

### 第一步：分析产品信息

**输入处理**：
- 如果用户提供了产品效果图（图片文件），先分析图片内容
- 如果用户仅提供文字描述，提取产品关键信息

**固定产品信息模板**（用于外贸电商）：
- 材质：甘蔗浆/纸浆模塑
- 特性：可降解、环保、微波安全、高阻隔覆膜
- 用途：餐饮打包、商超零售、外贸跨境

---

### 第二步：生成电商产品主图

**使用工具**：`image_synthesize`

**模型**：`image-01`

**提示词模板**：
```
专业电商产品摄影，[产品描述]，纯白背景，影室柔光，45° 俯拍，高清 8K，材质肌理真实，无文字无水印，产品居中
```

**示例**：
```
专业电商产品摄影，一次性甘蔗浆餐盒，纯白背景，影室柔光，45° 俯拍，高清 8K，材质肌理真实，无文字无水印，产品居中
```

**参数设置**：
- 比例：`1:1` 或 `9:16`
- 负面词：`模糊、变形、多余物体、文字、水印、杂色`

**核心逻辑**：先用高清标准产品图打底，再图生视频，比直接文生视频稳定太多，不会变形。

---

### 第三步：图生视频（核心节点）

**使用工具**：`gen_videos`

**模型**：`video-01`

**视频动态指令模板**：
```
产品缓慢 360° 旋转展示，镜头平稳推拉，柔和光影微动，纯白背景不动，只产品动态，专业电商宣传片质感，无多余特效
```

**参数设置**：
- 时长：`15 秒`（WhatsApp 最佳）或 `30 秒`
- 运动幅度：**低**（避免产品扭曲变形，外贸产品必须稳）
- 画幅：`9:16 竖屏`（适配 FB Reels、WhatsApp 状态）

---

### 第四步：配音 + 自动字幕

**音频生成**：
- 使用工具：`gen_audios`
- 配音文案模板（外贸通用英文）：
```
Our [product name], eco-friendly biodegradable, microwave safe, with [special feature], perfect for food packaging and retail.
```

**参数设置**：
- 语音：女声专业播音腔
- 语速：稍慢（适合外语受众）

**字幕生成**：
- 双语字幕（中文 + 英文）
- 字体：加粗、白色描边
- 适配手机竖屏观看

---

### 第五步：视频合成与导出

**使用工具**：`gen_videos` 或手动合成

**设置参数**：
- 分辨率：`1080P`
- 格式：`MP4`
- 画幅：`9:16 竖屏`
- 压缩：适配 WhatsApp 发送（不卡顿、不压缩画质）

---

## 预设模板

### 产品类型适配

| 产品类型 | 主图提示词特征 | 视频动态 |
|---------|--------------|---------|
| 食品容器 | 强调材质、安全认证 | 展示容量、盖子开合 |
| 电子产品 | 科技感、光泽质感 | 360° 展示、接口细节 |
| 服装饰品 | 挂拍/平铺、柔软质感 | 飘动效果、微距展示 |
| 家居用品 | 场景化、生活氛围 | 使用演示、功能展示 |

### 社媒平台适配

| 平台 | 画幅 | 时长 | 特点 |
|-----|------|------|------|
| Facebook Reels | 9:16 | 15-30s | 字幕醒目、前3秒抓眼球 |
| WhatsApp 状态 | 9:16 | 30s 内 | 压缩率低、画质优先 |
| Instagram | 1:1 / 9:16 | 15-60s | 品牌水印可选 |

---

## 输出交付

**最终产物**：
1. 高清产品主图（PNG/JPG）
2. 竖屏宣传视频（MP4，带配音+字幕）
3. 可直接发布到 FB 主页/Reels、WhatsApp 社群/状态

**文件命名规范**：
```
[产品名]_[平台]_[日期].mp4
示例：sugarcane_container_fb_20260429.mp4
```

---

## 注意事项

1. **产品稳定性**：视频运动幅度必须设为"低"，避免外贸产品展示变形
2. **静音友好**：FB/WhatsApp 静音播放居多，字幕必须清晰可见
3. **竖屏优先**：外贸电商移动端流量大，9:16 是标配
4. **画质保证**：导出前确认 1080P，压缩不过度
