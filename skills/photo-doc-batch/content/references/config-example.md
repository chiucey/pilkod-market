# config.json 字段说明

## 顶层

| 字段 | 说明 |
|---|---|
| `src_root` | 照片所在目录的绝对路径 |
| `out_size` | 输出 `[宽, 高]`，默认 `[2000, 2829]`（A4 比例，约 242 dpi） |
| `inset` | 裁切内缩比例，默认 `0.02`。纸边有桌面残留就调到 0.03 |
| `sources` | 每张照片一条 |
| `documents` | 每份文件一条，决定 PDF 合并 |

## sources[]

| 字段 | 说明 |
|---|---|
| `photo` | 源照片文件名（含扩展名） |
| `rotate` | 旋转角度：`0` / `90` / `180` / `270`。90 = 顺时针 |
| `deskew` | 是否做小幅去斜，默认 `true`，幅度小于 0.6° 自动跳过 |
| `pages` | 该照片内的页面列表，顺序 = 从左到右 |

### pages[]

| 字段 | 说明 |
|---|---|
| `key` | 页面唯一标识，后面 `documents` 靠它引用，如 `簇一_1号_第一面` |
| `surname` | 签名者姓氏，仅用于文档命名与交付说明 |
| `mask` | 打码参数 `[y0, y1, x0, x1, bar_x0, bar_x1]`，**认不出可置空跳过打码** |
| `pdf_name` | 仅在不使用 `documents` 时生效 |

### mask 参数怎么来的

- `y0, y1, x0, x1`：签名在**页面内**的归一化范围。手工看缩略图量一次，同版式复用。
- `bar_x0, bar_x1`：黑条在 `x0..x1` 这段宽度内的起止位置（0~1 相对值）。
  口径是宽松的：`bar_x0` 宁可往左多留 0.02 盖住一点姓氏，`bar_x1` 留够盖住名字末笔。

纵向黑条会自动铺满整个签名 ROI 的上下留白区，无需精确贴合笔画。

## documents[]

| 字段 | 说明 |
|---|---|
| `pdf_name` | 输出文件名（不含 `.pdf`） |
| `pages` | 有序的 `key` 列表，第一页在前 |

不写 `documents` 时，脚本会把每个 `pdf_name` 非空的页面各自单独成 PDF。

## 命名序号冲突

同名姓氏 + 相同序号会撞名（如两个簇都有"1 号"且同姓）。
用**全局连续序号**而不是簇内号，例如簇一 1-6、簇二 7、簇三 8-13，
并在交付回复里给出「序号 ↔ 簇/号」对照表。
