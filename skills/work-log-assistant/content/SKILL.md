# 工作日志记录助手

## 技能说明
这是一个用于帮助用户系统化记录每日工作日志的技能。通过交互式问答，引导用户完成日志的构建、记录和分析，并将日志保存到指定目录。

## 适用场景
- 每日工作结束后的复盘记录
- 项目完成后的总结记录
- 学习成长记录的积累
- 任何需要系统性记录工作内容的场景

## 前置要求
- 确保 `F:\个人文档\日志` 目录存在
- 确保有文件写入权限
- 日志文件将以 `YY-MM-DD.md` 格式保存

## 技能使用方法

### 启动方式
用户只需说："帮我记录今天的日志" 或类似表达，AI 将自动加载此 skill 并开始交互式记录。

### 交互式记录流程

#### 第一步：获取日期和时间信息
AI 会询问：
- 工作日期（默认今天）
- 开始工作时间
- 结束工作时间
- 工作总时长

**示例对话：**
```
AI：请问今天的工作日期是？（默认：2026-01-27）
用户：2026-01-27
AI：今天的工作时间从几点到几点？
用户：08:30 - 18:00
```

AI 会询问今天的主要工作类型，并提供选项：

- [ ] 设计/创意
- [ ] 学习/研究
- [ ] 管理/协调
- [ ] 运维/支持
- [ ] 其他

用户：开发/编程

**示例对话：**

用户：用户认证系统重构

### 日志文件生成

#### 文件命名规则
日志文件将按照以下规则命名：
```
工作日志_YYYY-MM-DD.md
```

示例：`工作日志_2026-01-27.md`

#### 保存路径
日志文件将保存到：`F:\个人文档\日志\工作日志_2026-01-27.md`

## 最佳实践

### 建议的记录时间
- **每日记录**：每天工作结束前5-10分钟
- **周总结**：每周五下午或晚上
- **月度回顾**：每月最后一个工作日

### 记录质量建议
1. **及时性**：工作完成后立即记录，避免遗漏
2. **准确性**：确保时间和内容的准确性
3. **完整性**：覆盖所有重要信息和细节
4. **简洁性**：避免冗余，突出重点
5. **一致性**：保持格式和风格的统一

### 分析深度建议
1. **初期阶段**：重点记录工作内容和产出
2. **中级阶段**：增加效率分析和经验总结
3. **高级阶段**：深度分析工作模式，优化方法论

## 注意事项

### 数据安全
1. **隐私保护**：日志中避免包含敏感信息
2. **数据备份**：定期备份日志文件
3. **信息安全**：日志文件存储在本地，相对安全

### 使用限制
1. **文件数量**：建议按月归档历史日志
2. **存储空间**：单个日志文件建议不超过50KB
3. **编辑权限**：日志生成后可以手动编辑完善

## 常见问题

### Q1：忘记记录当天的日志怎么办？
A：可以补记，但时间信息可能不准确。建议尽量当天记录。

### Q2：日志内容可以修改吗？
A：可以。生成的日志文件可以手动编辑修改。

### Q3：能查询多长时间的日志？
A：可以查询所有已保存的历史日志。建议按月归档管理。

### Q4：日志会自动备份吗？
A：不会。建议定期手动备份重要日志文件。

### Q5：能导出日志数据吗？
A：可以。日志文件是标准的Markdown格式，可以导出或转换。
