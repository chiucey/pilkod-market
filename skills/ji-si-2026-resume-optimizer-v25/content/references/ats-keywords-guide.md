# ATS关键词优化指南

## 关键词分类

### 技术类岗位
- 编程语言：Python, Java, JavaScript, C++, Go, Rust
- 框架工具：React, Vue, Angular, Spring, Django
- 数据库：MySQL, PostgreSQL, MongoDB, Redis
- 云服务：AWS, Azure, GCP, Kubernetes, Docker

### 产品类岗位
- 产品设计：PRD, MRD, 用户研究, 竞品分析
- 数据分析：DAU, MAU, 转化率, 用户留存
- 项目管理：敏捷, Scrum, 迭代, 需求管理

### 运营类岗位
- 用户运营：AARRR, 增长黑客, 用户画像
- 内容运营：选题策划, 内容矩阵, SEO
- 数据运营：GMV, ROI, CTR, CVR

## 关键词密度标准

| 要素 | 建议出现次数 |
|------|------------|
| 核心技能词 | 3-5次 |
| 工具名称 | 2-3次 |
| 软技能词 | 1-2次 |

## 禁用词

- 独立完成（非团队协作）
- 熟练掌握（非精通夸大）
- 全面负责（范围过宽）
