# 三段式输出模板

## 标准格式

```
---

## 第一段：优化后简历

[Markdown格式完整简历]

---

## 第二段：核心优化说明

**1. 关键词优化**
[基于目标岗位的关键词调整说明]

**2. 格式结构调整**
[结构优化具体说明]

**3. 内容优化建议**
[量化表述、动词替换等具体建议]

---

## 第三段：合规声明

本简历已通过真实性校验，符合求职市场规范。
```

## 简化格式（无分割线）

```
## 优化简历

[Markdown简历内容]

## 优化说明

1. [说明1]
2. [说明2]
3. [说明3]

## 合规声明

本简历已通过真实性校验，符合求职市场规范。
```

## 注意事项

- 三段之间使用清晰分隔
- 每段内容完整独立
- 合规声明不得删减
- 禁止添加额外段落
