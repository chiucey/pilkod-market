## 数据获取路径

### D-1日分户号总电量
- **数据源**：浙江电力交易平台 → 信息披露 → 特定信息 → 代理用户用电量查询
- **操作**：导出D-1日分户号总电量数据（不含损耗）

### D-3日分户号48点电量明细
- **数据源**：浙江电力交易平台 → 信息披露 → 特定信息 → 代理用户48点电量明细/汇总查询
- **操作**：导出D-3日分户号48点电量明细数据

## 数据处理流程

### 步骤1：D-1日数据处理
1. 将D-1数据复制到表格中
2. 按户号和序号进行筛选分类
3. 将分类后的数据填入"用户负荷统计表—天气"表

### 步骤2：48点电量明细分类汇总
1. 将分类汇总结果填入"用户负荷统计表—2026开始负荷分类"表
2. 将小类汇总为10大类，便于负荷预测

## 负荷预测方法

### 天气数据采集
- **气温数据**：两个气象源（墨迹和Windy）
- **天气情况**：以Windy为主
- **更新要求**：历史的实际天气数据要及时更新

### 4.2.1 2025存量用户预测（用户1-8）

**电量与气温关系**：
- **春秋季（3-5月、11-12月）**：最高温≥3℃变化时，第一天2-3万度变化，第二天6万度左右
- **夏冬季（6-10月、1-2月）**：每升温/降温1℃，增/减量固定，需参考近期数据

**类型日规律**：
- 周一至周四：电量稳定
- 周五/周六：较周一至周四涨8万度
- 周日：较周一至周四涨4万度
- 节假日前1-2天：开始涨负荷
- 节假日期间：负荷涨幅明显
- 节假日结束后1天：略有涨幅
- 结束后第2天：恢复正常

**曲线选取原则**：
- 同类型日曲线（周一至周四/周五/周六/周日）
- 相似温度变化曲线
- 排除异常曲线（如夜间暴雨导致电量骤降）
- 节假日建议使用前一年同期曲线

### 4.2.2 202601系统内加油站/充电站预测（用户9、10、14）
- 建议与存量用户分开预测
- 参考存量用户预测方法

### 4.2.3 系统外用户预测（用户11、15）
- 充电站用户与气温强相关
- 工厂用户与气温也有关系
- 需考虑光伏影响（3户左右）
- 需找天气情况相同的相似日

## 预测注意事项

1. 参考近期相同温度变化趋势的历史数据
2. 季节交替时注意电量阶段性抬升或下降
3. 尽量选择两周以内的历史数据
4. 节假日曲线建议使用前一年同期（如充电站8、9、16、17参考充电站4往年同期曲线导致偏差较大）
