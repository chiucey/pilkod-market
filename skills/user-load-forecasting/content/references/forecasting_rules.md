## 数据获取详细路径

### D-1日分户号总电量

**数据源**：浙江电力交易平台 → 信息披露 → 特定信息 → 代理用户用电量查询

**操作步骤**：
1. 进入浙江电力交易平台
2. 选择"信息披露"→"特定信息"→"代理用户用电量查询"
3. 导出D-1日分户号总电量数据（不含损耗）

### D-3日分户号48点电量明细及汇总

**数据源**：浙江电力交易平台 → 信息披露 → 特定信息 → 代理用户48点电量明细/汇总查询

**操作步骤**：
1. 进入浙江电力交易平台
2. 选择"信息披露"→"特定信息"→"代理用户48点电量明细/汇总查询"
3. 导出D-3日分户号48点电量明细数据

## 各类型用户预测方法详解

### 4.2.1 2025存量用户预测（含用户类型1、2、3、4、5、6、8）

#### 电量与气温关系

**春季和秋季（3-5月、11-12月）**：
- 最高温发生≥3℃变化时
- 用户负荷第一天有2-3万度电量变化
- 第二天有6万度左右电量变化

**夏季和冬季（6-10月、1-2月）**：
- 每升温/降温1℃
- 负荷的增量/减量相对固定
- 需根据近期历史数据判断增/减量大小

#### 预测注意事项

1. 参考近期相同温度变化趋势的历史数据
2. 季节交替时注意电量是否有阶段性抬升或下降
3. 尽量不要选择两周以前的历史数据

#### 与类型日的关系

| 类型日 | 电量特征 |
|--------|----------|
| 周一至周四（同温） | 电量稳定 |
| 周五和周六 | 较周一至周四涨8万度 |
| 周日 | 较周一至周四涨4万度 |
| 节假日前1-2天 | 开始涨负荷 |
| 节假日期间 | 负荷涨幅明显 |
| 节假日结束后1天 | 略有涨幅 |
| 结束后第2天 | 恢复正常 |

#### 曲线选取原则

1. **周类型匹配**：
   - 周一至周四：只选取历史周一至周四的48点曲线
   - 周五/周六/周日：只选取历史周五/周六/周日曲线

2. **气温考虑**：
   - 若有明显降温/升温，要用相似温度变化的曲线

3. **异常排除**：
   - 不要选用历史数据中有特殊异常的曲线
   - 例如：某日夜间大暴雨导致夜间电量骤降的曲线

4. **节假日曲线**：
   - 建议使用前一年同期曲线
   - 原因：最近几个节假日负荷预测曲线不准，主要因为很多用户没有历史同期数据
   - 例如：充电站8、9、16、17都是参考了充电站4的往年同期曲线，导致偏差较大
   - 若今年数据完整，明年的节假日预测应该会更准确

5. **节假日前1-2日的曲线**：
   - 不要直接用历史同期曲线
   - 可以参考历史曲线的变化趋势

### 4.2.3 202601、03系统外用户预测（含用户类型11、15）

#### 电量特征

**与气温的关系**：
- 系统外用户中有8户是充电站用户
- 充电站用户电量和气温强相关
- 系统外工厂用户用电和气温也有关系

**与类型日的关系**：
- 和系统内用户一样
- 分周一至周四、周五、周六、周日4种类型日

**与光伏的关系**：
- 系统外用户中有3户左右电量和光伏有关

#### 预测方法

除了考虑气温和类型日外，还要找到天气情况相同的相似日。

#### 曲线特征

需要考虑天气情况的相似性，选择光伏影响较小的数据作为参考。
