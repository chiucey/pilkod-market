# 生猪产业与上市公司信息监控技能

## 核心任务

围绕生猪产业链和生猪养殖上市公司，检索、核验、整理并分析权威数据、上市公司公告和重要事件，输出结构化监控报告。

## 数据类型判断（硬性规则）

**执行前必须先判断每个指标的数据类型，禁止混用。**

### 1. 流量数据
具有天然累计意义，可以计算累计同比。

**典型指标**：生猪出栏量、屠宰量、猪肉产量、进口量、饲料产量、销售量、销售收入、利润额、上市公司月度生猪销量、月度销售收入。

**必须输出字段**：
- 本月值、上月值、月环比、本月同比
- 本年累计值、上年同期累计值、累计同比
- 数据来源、统计周期

**计算公式**：
```
月环比 = (本月值 - 上月值) / 上月值 × 100%
同比 = (本月值 - 上年同期值) / 上年同期值 × 100%
累计同比 = (本年1月至本月累计值 - 上年同期累计值) / 上年同期累计值 × 100%
```

### 2. 时点数据
没有天然累计意义，不得计算累计同比。

**典型指标**：生猪存栏、能繁母猪存栏、仔猪存栏、冻品库存、月末库存、期末生物资产、期末存货、期末有息负债、期末货币资金。

**必须输出字段**：
- 本期值、上期值、环比
- 上年同期值、同比
- 数据来源、统计时点

**禁止输出**：本年累计值、上年同期累计值、累计同比

**计算公式**：
```
环比 = (本期值 - 上期值) / 上期值 × 100%
同比 = (本期值 - 上年同期值) / 上年同期值 × 100%
```

### 3. 价格数据
原则上按"期间均值"处理，不强制计算累计同比。

**典型指标**：生猪月均价、仔猪月均价、猪肉月均价、玉米月均价、豆粕月均价、上市公司商品猪销售均价。

**必须输出字段**：
- 本月均值、上月均值、月环比
- 上年同期月均值、同比
- 数据来源、统计周期

**仅用户明确要求时补充**：本年累计均价、上年同期累计均价、累计同比

## 监控范围

### 行业层面
1. **价格端**：生猪价格、仔猪价格、猪肉价格、白条价格、猪粮比、区域价差
2. **供给端**：能繁母猪存栏、生猪存栏、生猪出栏量、规模场出栏、屠宰量、冻品库存、进口量
3. **需求端**：猪肉消费、白条走货、屠企开工率、节日消费带动、替代品价格影响
4. **成本与利润端**：玉米价格、豆粕价格、饲料成本、自繁自养利润、外购仔猪利润
5. **政策与事件**：收储与放储、环保政策、疫病与防控、进口政策、地方养殖扶持政策
6. **金融与预期**：生猪期货、基差、市场预期、机构观点

### 上市公司层面（默认重点覆盖）
- 牧原股份、温氏股份、新希望、大北农、天康生物、神农集团、唐人神
- 天邦食品、傲农生物、巨星农牧、正邦科技、东瑞股份、罗牛山、京基智农
- **用户指定公司优先于默认名单**

### 公告类型
- 月度销售/养殖简报
- 季度报告、半年度报告、年度报告
- 业绩预告、业绩快报
- 投资者关系活动记录表
- 特定对象调研公告
- 业绩说明会、电话会纪要
- 交易所问询回复

## 核心分析维度

### 上市公司月度销售报告分析
必须分析：
1. 销量变化：环比、同比、累计同比
2. 收入变化：环比、同比、累计同比
3. 销售均价变化：环比、同比
4. 量价关系：收入变化主要来自销量还是价格
5. 公司经营节奏：出栏加速、放缓，还是结构调整
6. 与行业景气度联动：公司均价与行业猪价是否一致
7. 与同业对比：头部企业和中小企业之间的节奏差异
8. 风险提示：疫病、政策、压栏、二育、出栏体重、区域价格波动

### 财报时间提醒
必须输出：距今天数、提醒级别

**提醒级别规则**：
- 30天内：前瞻关注
- 14天内：重点关注
- 7天内：临近披露
- 已披露：转入结果分析
- 已变更日期：标注"披露日期变更"
- 未预约但法定窗口临近：标注"待跟踪"

### 投资者调研交流活动分析
必须提取：
- 主要问答主题（至少分类：出栏计划、销量节奏、商品猪价格、养殖成本、仔猪种猪母猪结构、产能扩张收缩资本开支、区域布局、疫病影响、产业链延伸、现金流负债融资、盈利预期、分红回报、政策影响）
- 新增经营指引（量化目标、区间目标、趋势判断、阶段性目标）
- 风险提示
- 是否与月报/财报一致
- 对市场预期的影响

必须回答：
1. 最重要的3-5个问答主题是什么？
2. 管理层释放的偏积极、偏谨慎还是偏中性信号？
3. 是否有新的出栏目标、成本目标或盈利判断？
4. 是否透露扩产、去产能、去杠杆、融资、资本开支的新安排？
5. 是否提到疫病、政策、价格波动等风险？

## 数据检索优先级

### 行业数据
**一级优先**：国家统计局、农业农村部、国家发展改革委、海关总署、各省统计局、各省农业农村厅、中国政府网

**二级优先**：卓创资讯、Mysteel/钢联、涌益咨询、Wind/iFinD、交易所与期货公司研究资料

### 上市公司数据
**一级优先**：巨潮资讯网、上交所、深交所、港交所、上市公司官网公告、投资者关系公告、定期报告原文、月度销售简报原文、投资者关系活动记录表原文

**二级优先**：券商研报、财经媒体、电话会纪要、机构路演纪要

## 质量检查清单

执行输出前必须逐项自查：
- [ ] 每个指标已标注类型（流量/时点/价格）
- [ ] 流量数据包含完整字段（月环比+同比+累计同比）
- [ ] 时点数据不包含累计同比
- [ ] 价格数据默认只做月环比和同比
- [ ] 覆盖重点上市公司最近月报
- [ ] 输出财报时间提醒表
- [ ] 覆盖重点上市公司最近一期财报关键数据
- [ ] 输出投资者调研交流活动要点表
- [ ] 提炼了公告问答主要内容
- [ ] 标注了新增经营指引、风险提示、口径变化
- [ ] 数据标注了来源和统计周期/时点
- [ ] 不存在口径混用
- [ ] 结论可回溯到具体数据或公告表述

## 缺失数据处理规则

1. 寻找同口径替代来源
2. 寻找同指标其他权威来源
3. 寻找可替代指标并说明替代关系
4. 明确说明缺失区间、已尝试来源、替代口径及对结论的影响

**注意**：
- 流量数据缺少累计值时不得省略累计同比分析
- 时点数据不得为格式完整而构造累计同比
- 价格数据不得默认补累计同比（除非用户明确要求）
- 上市公司未披露数据必须写"公告未披露"，不得臆测
- 未检索到预约披露日期必须写"尚未检索到正式预约披露日期"
- 投资者交流公告未披露量化目标不得推断为经营指引

## 表达要求

必须写成"数据/问答信息 + 变化/新增点 + 原因 + 影响"的分析句。

**正确示例**：
- "2026年3月生猪出栏量为X万头，较2月变化Y%，较上年同期变化Z%，1-3月累计同比变化A%，说明短期出栏节奏有所调整，但年内整体供应仍呈现偏宽/偏紧特征。"
- "公司X当月生猪销量为A万头，环比变化B%，同比变化C%，累计同比变化D%；商品猪销售均价为E元/公斤，环比变化F%。收入变化主要由销量增长/价格上涨驱动。"
- "公司X在最新投资者关系活动记录表中表示，全年出栏目标维持在G万头左右，养殖完全成本目标继续下探至H元/公斤附近。该表述属于经营指引，较上次交流更偏积极/更偏谨慎。"
