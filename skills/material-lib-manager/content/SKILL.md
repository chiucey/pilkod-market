## 二、素材拆分核心逻辑（物理切分）

**核心原则：拆分是加法，切分为独立素材单元，简单相加等于原文整体。**

### 预分类规划——五维度框架

先判断文档核心价值方向，按以下五维度预判：

| 维度 | 特征 | 适合提取的内容 |
|------|------|--------------|
| **言** | 经典语录、观点提炼、金句引用 | 有冲击力/反差的原话，可直接引用 |
| **人** | 人物经历、特征故事、交往细节 | 具体人物的行为和选择 |
| **事** | 完整事件、起因经过结果、个人感悟 | 有时间线的故事，有头有尾 |
| **物** | 具体物件、产品特点、场景描述 | 物件的功能、特点、感官属性 |
| **景** | 环境描写、氛围营造、感官体验 | 有画面感的描写，带入感强 |

### 结构化切分操作

1. **以章节/段落为单位拆分**，保留核心信息完整性
2. **长段落切短模块**，每个模块聚焦一个观点或素材
3. **删冗余修饰，保留核心信息**——不需要原文的全部文字
4. **删除不影响原文整体意思的连接词和重复部分**

### 典型场景提取优先级

| 类型 | 提取原则 |
|------|---------|
| 问题类素材 | 每个问题配对应案例，单页只放1-2个 |
| 情感类素材 | 保留强冲击力内容（画面感、反差感），独立存储 |
| 案例类素材 | 提炼核心事实+观点，保留原始来源标注 |
| 场景类素材 | 有画面感/感官体验的内容优先提取 |

### 拆分与拆解的区分

| 操作 | 关系 | 适用场景 |
|------|------|---------|
| **拆分**（加法） | 切分，单元独立 | 独立使用，不依赖上下文 |
| **拆解**（乘法） | 还原底层逻辑+解读 | 深层论点，需要分析才能使用 |

**判断标准：** 能单独拎出来不失去意义 → 拆分；需要解读才有价值 → 拆解（存入分析笔记而非素材表）

### 拆分原则总结

| 原则 | 说明 |
|------|------|
| 独立性 | 每个素材能单独使用，不依赖原文上下文 |
| 价值聚焦 | 一个素材只保留一个核心信息点 |
| 可检索 | 给素材添加对应标签，方便后续搜索取用 |
| 动态更新 | 使用中不断优化分类，补充新素材 |

## 四、素材写入流程（必须逐条确认）

### 预览阶段
将所有拟写入素材逐条展示，格式：

> **素材N**：[子表] [内容类型]
> 标题：……
> 摘要：……（50字以内）
> 正文：……

### 确认阶段
用户逐条回复"可以"/"不要"/"修改某条"。

### 写入阶段
用户确认后，逐条写入飞书。每次只写一条，等完成后再写下一条。
