# CPO概念板块热点追踪与资金流向分析

## 技能定位

实时追踪A股CPO（Co-Packaged Optics，共封装光学）概念板块的市场动态，包括热点概念、资金流向、龙头股分析、涨停板筛选等。

## 核心功能

### 1. CPO概念热点捕捉

使用 `stock-hot-concept` 技能获取CPO概念的最新市场热点：

1. **搜索策略**：
   - 关键词：CPO、共封装光学、Co-Packaged Optics、光模块、AI算力
   - 优先获取今日涨停板、涨幅排名靠前的个股

2. **数据维度**：
   - 板块整体涨跌幅
   - 成交额变化
   - 主力资金净流入/流出
   - 板块内个股联动性

### 2. CPO成分股分析

识别CPO概念的核心成分股：

**核心标的**（按主营业务分类）：

| 类型 | 代表个股 | 业务关联 |
|------|----------|----------|
| 光模块龙头 | 中际旭创、天孚通信 | 高速光模块核心供应商 |
| 芯片封装 | 亨通光电、通宇通讯 | 光电共封装技术 |
| 交换机设备 | 锐捷网络、新华三 | CPO交换机 |
| PCB载板 | 兴森快捷、深南电路 | 封装基板 |
| 激光器 | 源杰科技、仕佳光子 | 硅光芯片配套 |

### 3. 资金流向追踪

使用 `stock-hot-analysis` 技能进行深度资金分析：

1. **超大单、大单净流入排名**
2. **主力资金动向**（5日/10日/20日持续净流入）
3. **散户资金与主力资金对比**
4. **板块资金轮动轨迹**

### 4. 涨停板分析

使用 `stock-limit-up` 技能筛选CPO涨停股：

1. 今日涨停的CPO概念股
2. 连板股追踪（2板、3板及以上）
3. 涨停原因分析（研报、订单、政策等）
4. 明日涨停预测参考

## 执行流程

### Step 1: 概念热点扫描
- 调用 `stock-hot-concept` 获取CPO概念板块最新热度
- 重点关注：涨幅前5、成交额放大、资金净流入

### Step 2: 个股筛选
- 使用 `stock-limit-up` 筛选CPO涨停股
- 使用 `stock-hot-analysis` 分析资金流向

### Step 3: 综合分析输出
按以下结构输出报告：

```
【CPO概念板块热点追踪】📊 {日期}

## 一、板块概况
- 板块指数涨跌幅
- 成交额变化（同比/环比）
- 主力资金净流入

## 二、热点个股
| 股票名称 | 代码 | 涨跌幅 | 主力净流入 | 涨停原因 |
|----------|------|--------|------------|----------|

## 三、资金流向TOP10
[超大单/大单净流入排名]

## 四、龙头股点评
[重点个股分析]

## 五、投资机会提示
[风险提示+机会点]
```

## 数据源优先级

1. **实时行情**：通过 `stocks_price` 获取最新价格
2. **资金数据**：通过 `stock-hot-analysis` 获取资金流向
3. **热点概念**：通过 `stock-hot-concept` 获取概念热度
4. **涨停数据**：通过 `stock-limit-up` 获取涨停信息

## 注意事项

- CPO概念与光通信、AI算力、半导体封装高度关联，分析时注意跨板块联动
- 共封装光学技术仍在早期阶段，需关注技术突破和订单落地情况
- 短期炒作注意风险，中长期关注技术替代进度和市场份额变化
- 资金流向仅作参考，需结合基本面综合判断
