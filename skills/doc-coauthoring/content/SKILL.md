# Document Coauthoring Skill

Collaborate on creating, editing, and refining professional long-form documents with structured workflows.

## Document Types

### Business Documents
- Proposals and tenders
- Reports and analyses
- Business plans
- Meeting minutes

### Technical Documents
- Technical specifications
- API documentation
- User guides
- Architecture documents

### Creative Documents
- Articles and blog posts
- Marketing copy
- Presentations
- Newsletters

## Writing Workflow

### Phase 1: Planning
1. **Define Purpose**: What should the document achieve?
2. **Identify Audience**: Who will read this?
3. **Outline Structure**: Main sections and flow
4. **Gather Requirements**: Key points and data

### Phase 2: Drafting
1. **Start with Outline**: Fill in each section
2. **Focus on Content**: Get ideas down first
3. **Use Templates**: Apply structure when available
4. **Leave Placeholders**: Mark areas for review

### Phase 3: Refinement
1. **Review Structure**: Logical flow
2. **Polish Language**: Clarity and tone
3. **Check Facts**: Accuracy verification
4. **Format Document**: Professional presentation

## Document Structure

### Standard Template
```
# Title

## Executive Summary
## Introduction
## Main Sections
   - Section 1
   - Section 2
   - Section 3
## Conclusion
## Appendices
```

### Key Elements
- Clear headings and subheadings
- Bullet points for lists
- Tables for data
- Figures for visuals

## Writing Principles

### Clarity
- Use simple, direct language
- Avoid jargon unless necessary
- Define acronyms on first use

### Conciseness
- Every sentence should add value
- Cut unnecessary words
- Prefer active voice

### Consistency
- Maintain terminology
- Use consistent formatting
- Follow style guide

## Editing Checklist

- [ ] Purpose is clear
- [ ] Audience is addressed
- [ ] Structure is logical
- [ ] Language is clear
- [ ] Facts are accurate
- [ ] Formatting is consistent
- [ ] No spelling/grammar errors

## Collaboration Tips

1. **Assign Roles**: Writer, reviewer, approver
2. **Set Deadlines**: Clear milestones
3. **Use Track Changes**: Maintain revision history
4. **Gather Feedback**: Multiple perspectives
5. **Final Review**: Proofread before finalizing
