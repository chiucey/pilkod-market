# 风格设计指南

本文档提供各种设计风格的详细参考，包括关键词、元素、色调和示例提示词。

## 1. 日式禅意风格 (Japanese Zen)

### 核心关键词
```
Japanese Zen, Wabi-sabi, Minimalist Japanese, 侘寂
```

### 标志性元素
| 元素类别 | 具体元素 |
|---------|---------|
| 水景 | 锦鲤池、枯山水、流水小景 |
| 植物 | 松树盆景、竹林、青苔、枫树 |
| 硬景 | 石灯笼、汀步路、木桥、枯木 |
| 建筑 | 障子门（shoji）、榻榻米、茶室 |
| 材料 | 原木、竹子、石头、白砂 |

### 色调风格
- 主色：米白、浅灰、淡木色
- 点缀色：深绿（松）、暗棕（木）、灰蓝（水）
- 氛围：宁静、素雅、禅意

### 示例提示词
```
Japanese Zen garden with koi pond, wooden bridge, stepping stones.
Pine bonsai, moss garden, stone lantern, bamboo grove.
White sand raked patterns (karesansui), traditional elements.
Serene atmosphere, soft natural light, peaceful mood.
Minimalist design, authentic Japanese aesthetics.
```

## 风格混搭指南

### 推荐的风格组合

| 组合 | 融合方式 | 应用场景 |
|-----|---------|---------|
| 日式 + 现代 | 日式禅意元素 + 现代极简材料 | 精致露台、极简庭院 |
| 新中式 + 轻奢 | 中式元素 + 大理石金属 | 高端住宅、公共空间 |
| 法式 + 北欧 | 法式浪漫 + 北欧功能 | 温馨家居、咖啡厅 |
| 工业 + 日式 | 工业材质 + 日式禅意 | 艺廊、创意空间 |

### 混搭示例

```
现代日式混搭 (Modern Japanese Fusion)
=========================================
元素组合：
- 保留：清水混凝土墙（日本现代）
- 添加：枯山水石组（传统日式）
- 材料：黑色金属框 + 原木（日本现代）
- 植物：单株红枫盆景（日本现代）
- 照明：极简线性灯 + 纸艺灯笼（融合）

提示词模板：
Modern Japanese fusion interior with raw concrete walls.
Traditional karesansui stone garden, black metal frames, natural wood.
Single red maple bonsai, paper lanterns, minimalist design.
Zen atmosphere combined with contemporary aesthetics.
Soft natural lighting, sophisticated yet serene.
```
