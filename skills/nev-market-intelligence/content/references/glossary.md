# 新能源汽车核心技术术语表

## 三电系统术语

### 电池系统（Battery System）

| 术语 | 英文 | 说明 |
|------|------|------|
| 电芯 | Cell | 电池最小能量存储单元 |
| 模组 | Module | 由多个电芯组成的单元 |
| 电池包 | Pack | 完整的电池系统总成 |
| CTP | Cell to Pack | 电芯直接到电池包技术 |
| CTC | Cell to Chassis | 电芯集成到底盘技术 |
| BMS | Battery Management System | 电池管理系统 |
| SOC | State of Charge | 荷电状态（剩余电量） |
| SOH | State of Health | 健康状态（电池寿命） |
| 能量密度 | Energy Density | 单位质量/体积存储的能量 |
| 功率密度 | Power Density | 单位质量/体积输出的功率 |

### 电机系统（Motor System）

| 术语 | 英文 | 说明 |
|------|------|------|
| PMSM | Permanent Magnet Synchronous Motor | 永磁同步电机 |
| IM | Induction Motor | 感应异步电机 |
| SRM | Switched Reluctance Motor | 开关磁阻电机 |
| 扁线电机 | Hair-pin Motor | 采用扁铜线的电机 |
| 油冷电机 | Oil-cooled Motor | 油冷散热的电机 |
| 800V平台 | 800V Platform | 高电压电动汽车平台 |
| SiC | Silicon Carbide | 碳化硅功率器件 |
| IGBT | Insulated Gate Bipolar Transistor | 绝缘栅双极晶体管 |

### 电控系统（Power Electronics）

| 术语 | 英文 | 说明 |
|------|------|------|
| VCU | Vehicle Control Unit | 整车控制器 |
| MCU | Motor Control Unit | 电机控制器 |
| OBC | On-board Charger | 车载充电机 |
| DC/DC | DC-DC Converter | 直流转换器 |
| PDU | Power Distribution Unit | 配电单元 |
| OTA | Over-The-Air | 空中下载（软件升级） |

## 动力总成术语

| 术语 | 英文/缩写 | 说明 |
|------|----------|------|
| BEV | Battery Electric Vehicle | 纯电动汽车 |
| PHEV | Plug-in Hybrid Electric Vehicle | 插电式混合动力汽车 |
| HEV | Hybrid Electric Vehicle | 混合动力汽车 |
| REEV | Range Extended Electric Vehicle | 增程式电动汽车 |
| e-Axle | Electric Axle | 电驱动桥 |
| 三合一 | 3-in-1 | 电机+减速器+控制器集成 |
| 多合一 | Multi-in-1 | 更多部件集成系统 |
