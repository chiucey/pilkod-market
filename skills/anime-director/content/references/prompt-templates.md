# Anime Production Prompt Templates Reference

## Scene Image Generation Prompt Templates

### Basic Structure
```
[Scene Location/Environment], [Time/Lighting], [Main Action], [Character Description], [Atmosphere], [Style], [Composition], [Quality]
```

### Common Scene Templates

#### Interior Scenes
```
[Specific room type], warm/cool interior lighting, [time period] natural light from windows, [main character action], detailed furniture and decorations, [atmosphere keywords], anime interior, [composition], high quality, detailed
```

#### Exterior Scenes
```
[Specific location], [weather conditions], [time period] sunlight/sunset, [background buildings/natural elements], [main character action], atmospheric lighting, [seasonal feeling], anime exterior, [composition], high quality, detailed
```

#### Battle/Action Scenes
```
Dramatic [location], dynamic lighting with contrast, [character action description], [opponent/enemy description], intense atmosphere, action pose, anime battle scene, cinematic composition, high quality, detailed, motion blur effect
```

#### Emotional Scenes
```
[Location], soft [color tone] lighting, [character emotion description], gentle atmosphere, emotional moment, [background bokeh], anime style, close-up/medium shot, high quality, detailed, warm/cool color grading
```

## First/Last Frame Prompt Templates

### First Frame Characteristics
- Establish starting image
- Define character's initial pose/expression
- Set scene atmosphere
- Create visual tone

### Last Frame Characteristics
- Echo first frame but with changes
- Show result of action/emotion
- May introduce new elements
- Leave space for next scene

### Template
```
First Frame: [Character initial pose], [starting expression], [scene starting state], anime key visual, [aspect ratio]
Last Frame: [Character ending pose], [ending expression], [scene ending state], anime key visual, [aspect ratio]
```

## Character Dialogue Prompt Templates

### Structure
```
[Speaker]: "[Specific dialogue]"
[Emotion Tag]: [Emotion type] - [Intensity]
[Action Tag]: [Accompanying body language/expression changes]
[Shot Suggestion]: [Framing suggestion]
```

### Emotion Types
- Joy: Happy, Excited, Blissful, Content
- Sadness: Downcast, Grieving, Painful, Desperate
- Anger: Annoyed, Frustrated, Furious, Restrained
- Fear: Nervous, Scared, Terrified, Worried
- Surprise: Shocked, Startled, Curious, Puzzled
- Calm: Relaxed, Steady, Detached, Relieved

## Frame-to-Video Prompt Templates

### Basic Structure
```
[Cinematography style], [starting action], [duration], [rhythm], [transition suggestion]
```

### Camera Movement Types
- **Push In**: Dolly in, Zoom in, Tracking shot
- **Pull Out**: Dolly out, Zoom out, Pull back
- **Pan**: Pan left/right, Tilt up/down
- **Orbit**: Orbit, 360 degree shot, Revolve
- **Stable**: Static shot, Hold, Pause

### Duration Guidelines
- Shot transition: 2-4 seconds
- Action completion: 3-5 seconds
- Emotional pause: 4-6 seconds
- Transition cut: 1-2 seconds

### Template Example
```
Camera [movement], [subject action start], [key action complete], [duration], [rhythm description]
```
