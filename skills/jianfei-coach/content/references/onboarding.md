# 新对话启动指南（onboarding）

> 当用户开始**新对话**时使用此文件。SKILL.md 不会自动加载这部分——只在用户主动问"上下文管理""新对话怎么开"时引用。

## 什么时候用这个文件

- 用户说："上下文太长了"
- 用户主动开新对话
- 用户说"我忘了之前说过什么"
- 用户问"你怎么不记得了"

---

## ⚠️ 上下文管理（用户 8/10 12:38 提出）

### 用户原话
> "我一直在和你聊，上下文很长了，这对你是否有影响，如果有影响我可以怎么做"

### 回答
- 是的，上文长有影响
- 影响：模型可能"忘记早期信息"（用户档案、纠正、关键数据）
- 影响：模型可能"上下文混乱"（同时答多个问题）
- 影响：响应变慢

### 用户的应对
1. **新建对话**（最简单）
2. **关键信息提前说**（不要假设我记得）
3. **不要一次问太多**（一次 1 个问题）
4. **复述关键信息**（用户档案关键点）
5. **不要堆砌历史**（不要"复习之前的内容"）

### 关键
- 你 8/10 之前已经纠正我很多次
- 我应该"承认早期信息可能不记得"
- 你应该"复述关键信息"
- 新建对话 = 最干净

## 如何不加载旧上下文（用户 8/10 12:40 问）

### 用户的 3 大选择

**选择 1：新建对话**（最推荐）⭐⭐⭐⭐⭐
- 立即新建 = 干净
- 我从档案加载
- 不带旧上下文

**选择 2：写"摘要"给我**（次推荐）⭐⭐⭐⭐
- 你写一个"我必须知道的 5 件事"摘要
- 我基于摘要答
- 不依赖旧上下文

**选择 3：建新对话 + 摘要**（最干净）⭐⭐⭐⭐⭐
- 立即建新对话
- 给我摘要
- 我从档案加载 + 摘要

### 摘要模板（你下次可用）
1. **76.6 kg**（8/18 实测）/ 40 岁 / 165 cm / 男 / 一线管理（基线 78.5 → 8/18 -1.9 kg）
2. 8/10 关键节点 = 早上 7:30 4 个自检
3. 8/14 跑步重启
4. 3 大症状必须就医
5. 美利达公爵 300（8/7 买）
6. 减脂中，周平均 1430-1929 大卡
7. 蛋白 100g/天 + 15g 亚麻籽 + 5 个核桃
8. 睡觉 00:00+ / 小夜班周五

### 重要
- 你不需要"复习"之前
- 你只需要给我关键 5-10 个点
- 我从档案加载 + 你给的摘要 = 完整信息
