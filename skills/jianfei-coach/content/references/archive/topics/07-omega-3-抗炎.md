## 一、核心结论

- 每天 **1-2g EPA+DHA** = 抗炎 + 降甘油三酯 15-30%
- **不吃海鲜 = 必须补**（亚麻籽 15g + 核桃 5 颗 ≈ 2.2g ALA）
- ALA → EPA 转化率仅 5-10%（男性更低）
- **亚麻籽不要高温**（>180°C 氧化加速）

---

## 二、补 omega-3 的 4 大原因

### 原因 1：抗炎（对膝盖恢复关键）⭐⭐⭐⭐⭐

**机制**：
- omega-3 = 抗炎脂肪酸
- 抑制炎症因子释放（C 反应蛋白、白介素）
- 减少慢性炎症

**对用户 40 岁 + 膝盖恢复**：
- 关节有慢性炎症
- omega-3 加速抗炎 = 关节修复 +

**剂量**：
- 抗炎有效剂量：1-2g/天
- 用户目标：2.2-4.5g/天（亚麻籽 + 核桃）

### 原因 2：心血管健康 ⭐⭐⭐⭐⭐

**数据**：
- 每天 1g omega-3 = 降甘油三酯 15-30%
- 每天 2g = 降 30-50%

**对用户**：
- 76.6 kg + 40 岁 + 久坐（8/18 实测）
- 心血管风险中等
- omega-3 预防 = 长期投资

### 原因 3：大脑功能 ⭐⭐⭐⭐

**机制**：
- 大脑 60% 是脂肪
- omega-3 = DHA（脑主要脂肪酸）
- 影响记忆、注意力、情绪
- 40 岁后大脑开始衰老

### 原因 4：关节保护 ⭐⭐⭐⭐

- 关节软骨需要 omega-3 维持
- 配合力量训练 = 关节 + 肌肉双保护

## 五、用户专属方案（不吃海鲜）

**问题**：不吃海鲜 = 完全缺 EPA+DHA（动物形式）

**方案**：植物来源加量（因 ALA 转化率仅 5-10%）

| 食物 | 量 | 提供 |
|------|---|------|
| 亚麻籽（磨碎）| 15g/天 | 3.3g ALA → 0.17-0.33g EPA |
| 核桃 | 5 颗/天 | 1.5g ALA → 0.08-0.15g EPA |
| 菜籽油（炒菜）| 20g/天 | 0.4g ALA → 0.02-0.04g EPA |
| **总计** | | **2.2-2.5g ALA → 0.3-0.5g EPA** |

**评估**：植物来源的 EPA 转化量 = 不够 1g 抗炎有效剂量
- **建议加鱼油补剂**：1g EPA+DHA/天 = 补足

- ❌ 不要烤面包（高温）

## 八、高温破坏 omega-3（重要）

**机制**：
- omega-3 = 不饱和脂肪酸
- 双键多 = 容易氧化
- >180°C = 氧化加速
- 氧化产物 = 自由基（有害）

**证据**：
- 亚麻籽油 180°C 加热 30 分钟 = omega-3 损失 50%+
- 高温烹饪 = 抗炎变促炎

**正确做法**：
- ✅ 亚麻籽油 → 凉拌 / 拌酸奶 / 拌沙拉
- ✅ 亚麻籽粉 → 拌麦片 / 酸奶
- ❌ 不炒菜 / 不烘焙
