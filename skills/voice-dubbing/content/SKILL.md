# 智能配音系统

## 技能概述

智能配音技能可以将多角色对话文本自动转换为语音配音文件。用户只需按照「角色名称（情绪）：台词内容」的格式输入对话，即可生成各角色的配音音频。

**核心特性**：

- 同一角色的所有台词保持音色一致性
- 支持模糊搜索的可搜索音色选择器
- 用户确认后批量生成配音

## 输入格式说明

### 基本格式
```
角色名称（情绪）：台词内容
```

### 多角色对话示例
```
小明（开心）：今天天气真好啊，我们去公园玩吧！
小明（惊讶）：哇，这只蝴蝶好漂亮！
小美（兴奋）：快看快看，那边有个热气球！
小美（温柔）：等等我，我马上就来！
小明（着急）：快点快点，热气球要起飞了！
小美（紧张）：呼...我来了，我们走吧！
```

## 使用流程

### 第一步：准备对话内容

用户按照格式准备对话内容：

- 每行一个角色发言
- 格式：`角色名称（情绪）：台词内容`
- 不同角色会自动识别为不同说话者
- 相同角色连续发言会按顺序生成

### 第二步：选择并确认角色音色

**重要：在生成配音之前，必须为每个角色选择对应的音色**

系统会自动分析对话中的角色，并显示音色选择界面供用户确认或修改：

#### 音色一致性保证

**同一个角色的所有台词必须使用相同的音色**，确保配音连贯性：

- 选择音色后，该角色的所有台词都会使用这个音色
- 修改音色会影响该角色所有的台词
- 不同角色可以使用不同的音色

### 第三步：生成配音

完成音色确认后，系统开始生成配音：

1. **用户点击确认按钮**：用户确认音色选择后，点击"确认音色选择，开始生成配音"
2. **解析对话**：提取角色名、情绪、台词
3. **音色应用**：根据确认的音色生成对应音频
4. **情绪参数**：将情绪标签转换为语音参数
5. **顺序生成**：按对话顺序生成所有音频
6. **文件整理**：将文件保存到统一的文件夹

### 第四步：获取配音结果

生成完成后，用户会获得一个包含所有配音文件的文件夹。

## 技术实现

### 音色一致性规则

**核心原则**：同一角色的所有台词必须使用完全相同的音色

| 角色 | 第一次选择音色 | 后续台词处理 |
|------|--------------|-------------|
| 小明 | male-qn-qingnian | 自动使用 male-qn-qingnian |
| 小美 | female-shaonv | 自动使用 female-shaonv |
| 老师 | neutral | 自动使用 neutral |

- **选择即固定**：用户选择音色后，该角色的所有台词都使用这个音色
- **修改影响全局**：修改角色音色会影响该角色所有的台词
- **生成时验证**：生成前验证每个角色都已选择音色

## 注意事项

1. **音色一致性**：同一角色的所有台词必须使用相同音色
2. **必须确认音色**：在生成前必须为每个角色确认音色
3. **支持模糊搜索**：可以输入音色名称或拼音搜索
4. **清晰的角色名**：建议使用简单、清晰的角色名
5. **准确的情绪**：选择最符合台词语境的情绪
6. **适当的台词长度**：每句台词建议控制在50字以内
7. **文件整理**：所有文件自动整理到统一文件夹

## 技术规格

- **输出格式**：MP3
- **采样率**：32000 Hz
- **比特率**：128000 bps
- **单句最大字数**：100字
- **支持角色数**：不限制
- **文件名长度**：最大100字符
- **音色一致性**：同一角色所有台词使用相同音色

## 错误处理

| 错误情况 | 处理方式 |
|---------|---------|
| 未确认音色 | 提示用户必须确认每个角色的音色 |
| 音色不一致 | 系统自动保持音色一致性 |
| 格式错误 | 提示正确的输入格式 |
| 情绪不识别 | 使用默认"平静"情绪 |
| 台词过长 | 自动截断或分段处理 |
| 角色名缺失 | 标记为"未知角色" |
| 文件名非法字符 | 自动清理和转换 |
