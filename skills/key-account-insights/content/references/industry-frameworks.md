# 行业分析框架

本文档提供不同行业客户分析的专业框架，帮助市场团队深入理解特定行业的业务特点和技术需求。

## 一、行业分类与特征概览

### 1.1 主要行业分类

| 行业大类 | 典型子行业 | 数字化成熟度 | 核心诉求 | 我司产品契合度 |
|----------|------------|--------------|----------|----------------|
| 金融 | 银行、保险、证券、基金 | 高 | 安全、合规、性能 | 高 |
| 制造 | 离散制造、流程制造 | 中高 | 效率、质量、供应链 | 高 |
| 政府 | 政务服务、公共安全 | 中 | 惠民、安全、协同 | 高 |
| 零售 | 电商、实体零售、连锁 | 高 | 体验、运营、渠道 | 中高 |
| 能源 | 电力、石油石化、新能源 | 中高 | 安全、效率、绿色 | 高 |
| 交通 | 航空、铁路、港口、物流 | 中 | 安全、调度、智能化 | 高 |
| 医疗 | 医院、药企、医保 | 中 | 服务、质量、合规 | 中高 |
| 教育 | 高教、职教、K12 | 中 | 资源、体验、公平 | 中 |

### 2.1 制造业分析框架

#### 制造业数字化转型阶段模型

```
阶段一：单元级（25%）
├── 单一设备/工序的数字化
├── 局部数据采集
└── 典型技术：PLC、SCADA

阶段二：流程级（45%）
├── 跨工序/产线协同
├── 业务流程数字化
└── 典型技术：MES、ERP集成

阶段三：网络级（20%）
├── 企业内部门户协同
├── 供应链上下游协同
└── 典型技术：工业互联网平台

阶段四：生态级（10%）
├── 产业链数字化协同
├── 平台化运营
└── 典型技术：工业APP、数字孪生
```

#### 制造业客户分析检查清单

- [ ] 生产模式：离散/流程/混合
- [ ] 核心痛点：质量/效率/成本/交付
- [ ] 数字化基础：ERP/MES/PLM使用情况
- [ ] 工业互联网应用：设备连接、数据采集
- [ ] 智能制造目标：黑灯工厂、柔性产线
- [ ] 供应链数字化：上下游协同程度
- [ ] 典型供应商：西门子公司、达索、PTC
- [ ] 政策导向：智能制造2025、绿色制造

## 五、机会评估框架

### 5.1 机会评分模型

**战略契合度评分（1-5分）**

| 分数 | 评估标准 |
|------|----------|
| 5 | 客户核心战略与我司产品高度匹配，是客户战略级投资 |
| 4 | 客户重点发展方向与我司产品相关 |
| 3 | 客户有相关需求，但非核心优先级 |
| 2 | 客户有潜在需求，需要培育 |
| 1 | 客户暂无相关需求或与我司产品关联度低 |

**采购可能性评分（1-5分）**

| 分数 | 评估标准 |
|------|----------|
| 5 | 已进入采购短名单，决策链清晰，预算已落实 |
| 4 | 进入决策层视野，有明确需求，预算待确认 |
| 3 | 有初步意向，需要进一步培育 |
| 2 | 竞品已深入，客户关系一般 |
| 1 | 客户已有强绑定供应商，我司机会渺茫 |

**竞争强度评分（反向计分，1-5分）**

| 分数 | 评估标准 |
|------|----------|
| 5 | 无直接竞争，蓝海市场 |
| 4 | 1-2个弱竞争者 |
| 3 | 有成熟竞争对手，但可差异化竞争 |
| 2 | 有1个强势竞争对手 |
| 1 | 竞品已深度绑定，市场壁垒高 |

**时间窗口评分（1-5分）**

| 分数 | 评估标准 |
|------|----------|
| 5 | 最佳介入时机，未来3个月内是黄金期 |
| 4 | 机会窗口明确，未来6个月内是窗口期 |
| 3 | 时间窗口一般，需要持续关注 |
| 2 | 时间窗口较长，1年内持续有机会 |
| 1 | 时间窗口已过或暂不明显 |

**综合得分计算**：

```
综合得分 = 战略契合度(30%) + 采购可能性(30%) + 竞争强度(20%) + 时间窗口(20%)
```
