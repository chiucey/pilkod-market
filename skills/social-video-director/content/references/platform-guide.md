# 社交媒体平台运营指南

## 一、小红书（Xiaohongshu）

### 1.1 平台特点
- **用户画像**：一二线城市年轻女性为主，18-35岁，消费力强
- **内容调性**：精致生活、真实分享、有用干货
- **核心指标**：收藏率、点赞率、评论互动

### 1.2 视频规范
| 参数 | 要求 |
|------|------|
| 时长 | 15秒-5分钟，1-3分钟最佳 |
| 比例 | 9:16竖版或3:4方版 |
| 分辨率 | 1080P以上 |
| 封面 | 3:4，文字+画面结合，高质感 |

### 1.3 内容偏好
- **高热度话题**：美妆护肤、穿搭、美食、旅行、家居、母婴
- **新兴领域**：职场技能、理财知识、健身塑形、宠物
- **内容形式**：干货教程>好物分享>探店>Vlog

### 1.4 爆款规律
1. 封面要有冲击力和信息量
2. 标题要包含关键词和痛点
3. 正文要有实用价值，干货满满
4. 善用emoji和分段提升可读性
5. 结尾要有互动引导

---

## 二、抖音（Douyin）

### 2.1 平台特点
- **用户画像**：全年龄段，下沉市场渗透率高
- **内容调性**：娱乐化、碎片化、强节奏
- **核心指标**：完播率、点赞率、转发率

### 2.2 视频规范
| 参数 | 要求 |
|------|------|
| 时长 | 15秒-4分钟，15-60秒最佳 |
| 比例 | 9:16竖版 |
| 分辨率 | 1080P以上 |
| 封面 | 9:16，系统自动截取关键帧 |

### 2.3 内容偏好
- **高热度话题**：剧情段子、知识科普、才艺展示、生活记录
- **新兴领域**：职场、情感、健身、知识付费
- **内容形式**：剧情>干货>音乐/舞蹈>种草

### 2.4 爆款规律
1. 前3秒必须有"钩子"留住用户
2. BGM选择要与内容节奏匹配
3. 字幕要大、要醒目
4. 善用热门话题和挑战
5. 固定开场/结尾形成记忆点

---

## 三、微信视频号（Video Account）

### 3.1 平台特点
- **用户画像**：30-50岁中年人群，消费能力强
- **内容调性**：正向积极、真实可信、有深度
- **核心指标**：点赞率、分享率、朋友圈曝光

### 3.2 视频规范
| 参数 | 要求 |
|------|------|
| 时长 | 1分钟-30分钟，1-3分钟最佳 |
| 比例 | 16:9横版或9:16竖版 |
| 分辨率 | 1080P以上 |
| 封面 | 6:7，简洁大气 |

### 3.3 内容偏好
- **高热度话题**：新闻资讯、情感故事、养生健康、财富教育
- **新兴领域**：职场晋升、子女教育、退休规划
- **内容形式**：深度内容>热点解读>生活记录

### 3.4 爆款规律
1. 内容要有情感共鸣和价值认同
2. 信任背书很重要（专业资质、权威背景）
3. 善用朋友圈和社群裂变
4. 公众号图文+视频号联动效果佳
5. 评论区互动能提升算法推荐

---

## 四、B站（Bilibili）

### 4.1 平台特点
- **用户画像**：18-30岁年轻人，Z世代为主
- **内容调性**：专业有料、二次元文化、真实有趣
- **核心指标**：播放量、弹幕互动、投币收藏

### 4.2 视频规范
| 参数 | 要求 |
|------|------|
| 时长 | 3分钟-30分钟，5-15分钟最佳 |
| 比例 | 16:9横版为主 |
| 分辨率 | 1080P以上 |
| 封面 | 16:9，要有视觉冲击力 |

### 4.3 内容偏好
- **高热度话题**：数码科技、游戏电竞、动漫二次元、知识科普
- **新兴领域**：职场技能、理财投资、个人成长
- **内容形式**：深度测评>教程解说>Vlog>动画

### 4.4 爆款规律
1. 内容要有深度和专业度
2. 弹幕互动是重要指标
3. 系列内容更容易积累粉丝
4. 结尾要有"一键三连"引导
5. 标题要有悬念感和信息量

---

## 五、快手（Kuaishou）

### 5.1 平台特点
- **用户画像**：三四线城市及农村用户
- **内容调性**：接地气、真诚、老铁文化
- **核心指标**：点赞、评论、老铁值

### 5.2 视频规范
| 参数 | 要求 |
|------|------|
| 时长 | 11秒-10分钟，15-60秒最佳 |
| 比例 | 9:16竖版 |
| 分辨率 | 720P以上 |
| 封面 | 9:16，真实生活感 |

### 5.3 内容偏好
- **高热度话题**：农村生活、才艺展示、搞笑段子、情感故事
- **新兴领域**：农技知识、小生意经营、技能培训
- **内容形式**：真实记录>才艺展示>剧情段子

### 5.4 爆款规律
1. 真实感比精致更重要
2. 建立"老铁"人设很重要
3. 直播+短视频联动效果佳
4. 善用方言增加亲切感
5. 评论区互动要及时

## 七、跨平台运营策略

### 7.1 内容复用原则
1. **一次制作，多平台分发**：根据平台特点做适当剪辑
2. **差异化调整**：封面、标题、比例要适配各平台
3. **平台联动**：引导粉丝跨平台关注

### 7.2 推荐内容矩阵

| 层级 | 内容类型 | 发布频率 | 平台侧重 |
|------|----------|----------|----------|
| 流量款 | 热点/爆款话题 | 每天 | 抖音为主 |
| 人设款 | 个人故事/日常 | 每周2-3次 | 快手/视频号 |
| 干货款 | 专业内容/教程 | 每周1-2次 | 小红书/B站 |
| 种草款 | 产品测评/推荐 | 每周1-2次 | 小红书/抖音 |
