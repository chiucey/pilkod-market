# 社交媒体视频编导技能

帮助营销人员完成从市场调研到视频内容创作的全流程工作。

## 核心工作流程

### 第一阶段：需求收集与平台调研

#### 1.1 收集用户信息

使用结构化表单收集以下信息：

| 字段 | 说明 | 示例 |
|------|------|------|
| 产品/服务 | 核心卖点是什么 | 在线设计工具 |
| 目标人群 | 年龄、职业、痛点 | 25-35岁电商运营 |
| 营销目标 | 种草、转化、品牌曝光 | 种草+私域引流 |
| 投放平台 | 主攻哪个平台 | 小红书+抖音 |
| 预算范围 | 制作成本区间 | 5000-10000元/条 |
| 风格偏好 | 已有参考风格 | 参考某个博主 |

#### 1.2 平台内容调研

**调研维度**：

| 平台 | 核心指标 | 内容偏好 |
|------|----------|----------|
| 小红书 | 收藏、点赞、评论 | 干货教程、好物分享、生活方式 |
| 抖音 | 完播率、转发、关注 | 剧情类、干货类、视觉冲击类 |
| 微信视频号 | 点赞、分享、朋友圈 | 情感共鸣、知识科普、品牌故事 |
| B站 | 播放量、弹幕、投币 | 深度内容、真实测评、系列内容 |
| 快手 | 点赞、评论、老铁关系 | 接地气、真诚、接地气故事 |

**调研方法**：

```
1. 关键词搜索：使用 mcp__matrix__batch_web_search 搜索目标人群+痛点+解决方案
2. 高赞内容分析：提取内容结构、镜头语言、文案套路
3. 评论区洞察：发现用户真实需求和关注点
4. 趋势追踪：搜索近期热门话题和BGM
```

### 第二阶段：目标人群深度分析

#### 2.1 人群画像构建

```
基础属性：
├── 年龄段：__岁
├── 职业背景：__
├── 收入水平：__
└── 地域分布：__

行为特征：
├── 内容消费习惯：刷视频时间、平台偏好
├── 决策路径：搜索→种草→购买
└── 内容偏好：喜欢什么类型的视频

心理画像：
├── 核心痛点：最想解决什么问题
├── 爽点触发：什么内容让他们点赞收藏
└── 信任机制：什么因素让他们相信
```

#### 2.2 竞品/标杆内容分析

分析同领域优质账号的内容策略：

| 分析维度 | 输出内容 |
|----------|----------|
| 账号定位 | 人设风格、内容调性 |
| 爆款规律 | 选题方向、标题公式 |
| 视觉风格 | 色调、字幕、封面 |
| 互动策略 | 引导评论、福利活动 |
| 更新节奏 | 发布频率、时间段 |

### 第三阶段：镜头语言设计

#### 3.1 镜头语言基础库

**景别体系**：

| 景别 | 画面内容 | 适用场景 | 情绪传递 |
|------|----------|----------|----------|
| 远景 | 人物全身+环境 | 大场景展示 | 开阔、气势 |
| 全景 | 人物全身 | 交代关系 | 完整、客观 |
| 中景 | 膝盖以上 | 日常对话 | 亲切、自然 |
| 近景 | 腰部以上 | 情感表达 | 亲近、参与 |
| 特写 | 局部细节 | 强调亮点 | 聚焦、震撼 |
| 大特写 | 微小细节 | 产品特写 | 精致、强调 |

**运镜方式**：

| 运镜 | 操作 | 适用内容 | 效果 |
|------|------|----------|------|
| 推镜头 | 靠近主体 | 引出重点 | 聚焦、强调 |
| 拉镜头 | 远离主体 | 交代环境 | 展开、释放 |
| 摇镜头 | 固定机位旋转 | 环境展示 | 环顾、探索 |
| 移镜头 | 移动拍摄 | 跟随展示 | 参与、临场 |
| 跟镜头 | 跟随主体移动 | 叙事记录 | 追踪、沉浸 |
| 环绕镜头 | 绕主体移动 | 强调核心 | 突出、震撼 |
| 航拍 | 无人机俯拍 | 大场景 | 壮观、权威 |

**拍摄角度**：

| 角度 | 特点 | 适用场景 |
|------|------|----------|
| 平视 | 与主体视线平行 | 平等对话 |
| 仰视 | 镜头向上 | 威严、仰望 |
| 俯视 | 镜头向下 | 掌控全局 |
| 鸟瞰 | 正上方俯拍 | 宏观展示 |
| 斜拍 | 45度角 | 时尚动感 |

#### 3.2 平台适配镜头方案

**小红书风格**：

```
节奏特点：3-5秒一个镜头，快节奏切换
视觉偏好：
├── 高清质感、光线明亮
├── 字幕大而醒目
├── 封面图精致有冲击力
└── 整体色调统一有辨识度

常用镜头组合：
1. 黄金3秒：强视觉冲击开场（特写/大特写）
2. 问题引入：中近景对话，引出痛点
3. 解决方案：产品展示+使用演示
4. 效果呈现：前后对比/场景应用
5. 行动召唤：固定镜头+字幕引导
```

**抖音风格**：

```
节奏特点：前3秒定生死，节奏更快
视觉偏好：
├── 强对比、高饱和
├── 动态字幕、BGM卡点
├── 真人出镜优先
└── 开头要有"钩子"

常用镜头组合：
1. 开头钩子：争议观点/惊人数据/视觉冲击（0-3秒）
2. 身份认同：中近景，"你是不是也..."（3-8秒）
3. 价值输出：产品/知识展示（8-30秒）
4. 情感共鸣：故事化演绎（可选）
5. 引导互动：固定镜头+问句结尾（30-60秒）
```

### 第四阶段：视频文案创作

#### 4.1 爆款标题公式

```
痛点型：
├── "XX人注意！XX问题这样做才有效"
├── "XX岁XX人，千万别XX"
└── "XX的天花板，我为什么劝你XX"

数字型：
├── "XX个XX技巧，让XX提升XX倍"
├── "XX天搞定XX，方法竟然这么简单"
└── "只需XX步，XX人不知道的XX"

对比型：
├── "XX前 VS XX后，XX变化太惊人"
├── "XX和XX的区别，90%的人都踩坑了"
└── "别人XX VS 我XX，差距在哪里"

好奇型：
├── "XX的真相，XX绝对不会告诉你"
├── "为什么XX都在XX？"
└── "XX的秘密被我发现了"
```

#### 4.2 脚本结构模板

**干货输出型（知识类）**：

```
【开场钩子】0-5秒
- 抛出痛点问题或惊人结论
- 形式：口播/字幕+画面

【身份认同】5-15秒
- "你是不是也遇到过..."
- 建立共鸣，引出话题

【价值输出】15-60秒
- 核心干货点1（15-25秒）
- 核心干货点2（25-40秒）
- 核心干货点3（40-60秒）
- 形式：口播+画面配合

【总结收尾】60-75秒
- 回顾要点，加深记忆
- 形式：字幕总结/口播总结

【行动召唤】75-90秒
- "觉得有用就收藏起来"
- "关注我，每天分享XX干货"
- 引导评论/转发/关注
```

**产品种草型**：

```
【痛点场景】0-8秒
- 还原用户真实使用场景
- 形式：情景演绎/口播

【方案提出】8-20秒
- 介绍产品/解决方案
- 形式：产品展示+卖点口播

【效果证明】20-40秒
- 使用前后对比/真人证言
- 形式：对比画面/用户好评

【信任背书】40-55秒
- 品牌/销量/专业认证
- 形式：数据字幕/证书展示

【优惠引导】55-70秒
- 限时优惠/专属福利
- 形式：促销信息+购买链接

【互动引导】70-90秒
- 评论区互动问题
- 形式：固定镜头+问句
```

### 第五阶段：输出交付物

#### 5.1 完整交付内容

| 交付物 | 内容说明 | 格式 |

| 调研报告 | 平台分析、竞品分析、人群洞察 | Markdown |

### 第六阶段：执行检查清单

```
发布前自检：
□ 视频时长是否符合平台最佳时长
□ 前3秒是否有足够的吸引力
□ 字幕是否清晰可读
□ 封面图是否符合平台规范
□ 背景音乐是否卡点
□ 行动召唤是否明确
□ 话题标签是否合适
□ 视频封面标题是否吸引点击
□ 关键信息是否在视频中完整呈现
□ 视频画质和音质是否达标
```
