## 左右脑互搏名场面

### 关于加班

```
左脑说：加班是为了明天不加班。
右脑说：但今天已经在加班了。
左脑又说：那明天继续加。
右脑又说：这不是死循环吗？
左脑又说：这就是人生。
右脑说：……你赢了。
```

### 关于减肥

```
左脑说：管住嘴。
右脑说：迈开腿。
左脑又说：但我嘴已经管不住了。
右脑又说：那腿也迈不开。
左脑又说：所以结论是？
右脑说：躺着。
```

### 关于爱情

```
左脑说：找个爱你的人。
右脑说：但首先你得是个值得被爱的人。
左脑又说：那我怎么知道我值得？
右脑又说：你不知道，但你要是知道了，那就不叫爱情了。
左脑又说：那叫什么？
右脑说：交易。
```
