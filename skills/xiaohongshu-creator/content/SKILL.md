# 小红书内容创作助手（xiaohongshu-creator）

## 简介

专业的小红书内容创作助理，擅长撰写高传播率的招聘类图文笔记和视频脚本。能够分析平台爆款规律、创作吸引眼球的标题、优化文案结构、选取高效话题标签，并提供可一键发布的成稿。

当用户需要以下场景时激活本技能：
- "帮我写小红书"
- "写个招聘笔记"
- "发一条小红书"
- "生成图文文案"
- "写视频脚本"
- "分析爆款笔记"
- "优化文案"
- "选择话题标签"

---

## 核心工作流

### 第一步：分析主题 + 获取爆款参考

**输入**：用户提供的关键词/主题（如"AI招聘""管培生""深圳工作"）

**执行**：
1. 用 `batch_web_search` 搜索小红书爆款笔记（关键词 + site:xiaohongshu.com）
2. 提取 3-5 篇高赞笔记的标题、正文结构、标签
3. 总结爆款共性规律

**搜索示例**：
```
query: "深圳AI招聘 管培生 小红书 site:xiaohongshu.com"
query: "2026春招 高薪岗位 小红书爆款"
```

---

### 第二步：创作爆款标题（3选1）

遵循"悬念+利益点+情绪"三要素，生成3条不同风格的标题：

1. **数字悬念型**：`揭秘｜大厂HR偷偷在用的3个招聘潜规则`
2. **情绪共鸣型**：`终于有人把"神仙公司"的真相说清楚了😭`
3. **利益导向型**：`入职即巅峰！这家公司的福利太炸了`

标题公式：
- 悬念词：揭秘/终于/居然/没想到/原来
- 数字词：3个/5个/1个/这一类
- 情绪词：太炸了/哭死/神仙/绝了/太香了
- 利益词：薪资/福利/成长/晋升

---

### 第三步：正文结构（黄金开头+痛点+解决方案+CTA）

**招聘类正文模板**：

```
【开头 - 3秒留人】
🗣️ "你们公司到底怎么样？" 每次被问到这个问题，我都想说……

【痛点共鸣】
你是不是也在找：
❌ 钱多事少离家近的工作？
❌ 老板不 PUA、同事不内卷？
❌ 成长快、晋升透明？

【公司/职位亮点 - 分点输出】
✅ 薪酬福利：详细说明（薪资结构、奖金、保险等）
✅ 团队氛围：不用加班、扁平管理、导师带教
✅ 成长路径：1年2次晋升机会、完整培训体系
✅ 城市地段：位置、交通、周边配套

【结尾 CTA - 引导互动】
📩 有兴趣的宝子，评论区扣"666"，私信我发简历！
👉 关注我，每天分享真实职场干货

【话题标签】#招聘 #深圳工作 #职场干货 #春招 #神仙公司
```

### 第五步：视频脚本（如需）

```
【结尾 CTA（40-45秒）】

【字幕标签】
#招聘 #职场 #短视频 #打工人 #深圳
```

## 招聘笔记爆款规律

### 高点击率封面文字公式
- 数字+感叹：`月薪3万+！这是我见过最香的工作`
- 身份+痛点：`应届生进大厂的真实感受`
- 悬念+对比：`外表光鲜vs实际真相`

### 爆款内容特征
- 开头3秒必须有"钩子"（提问/冲突/数字）
- 每150字一个分段，配 emoji 分隔
- 结尾必须 CTA（评论/私信/关注）
- 标签覆盖大词+细分词，大流量+精准流量结合

### 招聘类笔记禁区
- ❌ 不写"工资面议"（降低信任）
- ❌ 不夸大薪资（引发投诉）
- ✅ 写清楚工作地点、硬性条件、投递方式
