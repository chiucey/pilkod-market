# 小红书平台算法与用户偏好

## 平台算法机制

### 推荐逻辑（CES）

小红书使用 CES 评分算法：
- **C**（collect）：收藏
- **E**（enter）：互动（点赞、评论、分享）
- **S**（share）：分享

评分公式：`CES = 点赞×1 + 收藏×2 + 评论×4 + 分享×4`

笔记发布后经历3个流量池：
1. **初始池**（200-500曝光）：系统小范围测试，考核CES
2. **二级池**（3000-5000曝光）：CES达标后进入，内容标签匹配分发
3. **热门池**（10万+曝光）：高CES笔记获得大规模推送

### 影响推荐的关键因素

| 因素 | 权重 | 说明 |
|------|------|------|
| 打开率 | ★★★★★ | 封面标题决定是否被点击 |
| 互动率 | ★★★★☆ | 点赞+收藏+评论+分享总和/曝光量 |
| 收藏率 | ★★★☆☆ | 收藏量/曝光量，反映内容价值 |
| 评论率 | ★★★☆☆ | 引导评论可提升推荐 |
| 账号质量 | ★★★☆☆ | 账号历史表现、违规记录 |
| 发布时机 | ★★☆☆☆ | 用户活跃高峰期发布效果更好 |

### 发布时间建议（用户活跃高峰）

- **工作日**：7:30-8:30（通勤）、12:00-13:00（午休）、18:00-19:30（下班后）
- **周末**：10:00-12:00（睡醒后）、14:00-16:00（下午休闲）

## 用户画像

### 主要用户群体

| 群体 | 占比 | 内容偏好 |
|------|------|---------|
| Z世代（18-27岁） | 约45% | 职场、穿搭、美妆、学习 |
| 都市白领（25-35岁） | 约35% | 职场、理财、生活方式 |
| 精致妈妈（28-40岁） | 约15% | 母婴、家居、美食 |

### 招聘类内容用户心理

1. **求稳心理**：渴望稳定、有发展、福利好的工作
2. **慕强心理**：向往大厂光环、高薪、精英同事
3. **代入感**：喜欢"真实经历""内部视角"的内容
4. **行动焦虑**：想快速行动，需要明确的投递方式和指引
5. **社群归属**：评论互动、归属感、参与感

### 用户内容消费习惯

- **图文优先**：用户更爱图文，信息获取效率高
- **短平快**：文字精简、分段清晰、要点突出
- **视觉冲击**：封面图决定点击，标题决定停留
- **信任感**：真实数据、具体描述、HR或内部员工视角更可信

## 招聘类笔记特殊算法

### 搜索流量占比高

招聘类笔记约 **60%** 流量来自搜索（关键词），远高于其他品类（均值20%）。

**搜索关键词分类**：
- 品牌词：腾讯招聘、字节跳动春招
- 岗位词：管培生、深圳运营招聘
- 场景词：大厂打工人、应届生入职
- 痛点词：找不到工作、薪资太低

### 爆款笔记结构特征

招聘类 Top 10% 笔记共性：
1. 标题含数字（3个/5个/这个数）
2. 封面有人物/头像（增强信任感）
3. 正文含emoji（提升可读性）
4. 结尾含CTA（引导私信/评论）
5. 标签精准（长尾词>通用词）

## 平台违规敏感词

### 招聘类禁用词

- ❌ "薪资面议"（平台不支持模糊薪资）
- ❌ "学历不限"（需明确写出硬性要求）
- ❌ "形象气质佳"（涉容貌歧视）
- ❌ "优秀者可放宽"（表述不规范）
- ❌ 绝对化承诺："一定""保证""绝不"

### 违规后果

发布违规内容会：降低账号权重 → 减少推荐曝光 → 严重封禁账号

---

## 提升内容质量的技巧

1. **添加数据**：具体数字远比"很高""不错"有说服力
2. **第一人称**：用"我""我们"比"公司"更有亲近感
3. **真实细节**：工位环境、午饭价格、同事氛围等具体细节
4. **适度情绪**：积极正面但不过度浮夸，避免"凡尔赛"
5. **定期更新**：招聘行情变化快，内容需时效性
