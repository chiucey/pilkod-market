## 三、爆款标题生成公式

### 数字型（高点击率）
```
公式：[数字]+[悬念词]+[利益点]
示例：
"3年换了5份工作，劝你应届生别太老实"
"月薪4万+，大厂内部推荐渠道首次公开"
"这5个职场道理，后悔没早点知道"
```

### 悬念型
```
公式：[悬念词]+[隐藏信息]+[好奇驱动]
示例：
"公司团建去巴厘岛，我却想辞职"
"入职第一天，HR偷偷告诉我的3件事"
"同事工资是我的3倍，发现真相后我哭了"
```

### 对比型
```
公式：[A]vs[A']-[反差结果]
示例：
"入职前vs入职后：理想与现实的差距"
"大厂vs小厂：3年后差距有多大"
"体制内vs体制外：10年后的真实对比"
```

### 情绪共鸣型
```
公式：[情绪词]+[共同经历]+[情绪释放]
示例：
"打工人破防瞬间：第3条太真实了"
"终于有人把加班费说清楚了"
"工作3年，钱没存到，头发没了"
```

### 利益导向型
```
公式：[利益点]+[获得方式]+[紧迫感]
示例：
"白嫖入职体检！这些羊毛必须薅"
"免费领取：2026最新面试题库"
"简历写这个，HR看了贼开心"
```
