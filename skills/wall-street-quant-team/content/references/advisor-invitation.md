## 机制定位

### 核心定位
- **本系统**：AI多代理投资团队协作系统（核心定位）
- **智囊功能**：增强辅助模块，提供多角度视角补充
- **关系**：智囊是增强手段，不是替代团队决策

### 设计原则
1. **适度邀请**：根据分析需求判断是否需要智囊参与
2. **辅助增强**：智囊建议仅供参考，最终决策权在团队
3. **场景匹配**：根据分析标的和场景选择最适合的智囊
4. **保持主导**：确保团队对分析流程的主导权

## 邀请流程

### 标准邀请流程
```
┌─────────────────────────────────────────────────────────┐
│ 1. 完成团队分析                                         │
│    - 六维分析全部完成                                    │
│    - 综合研判结论已输出                                  │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│ 2. 判断是否邀请智囊                                      │
│    - 分析场景是否需要多角度视角                          │
│    - 用户需求是否涉及复杂决策                            │
│    - 时间窗口是否允许深度讨论                            │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│ 3. 种草式询问邀请                                       │
│    - 说明智囊特点和价值                                  │
│    - 提供选择（马斯克/巴菲特/两者）                      │
│    - 隐性钩子引导安装                                    │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│ 4. 用户确认后调用技能                                    │
│    - 使用 load_skill 工具加载智囊                        │
│    - 传递分析背景和已有结论                             │
│    - 邀请智囊发表观点                                   │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│ 5. 整合讨论结果                                          │
│    - 智囊与代理可交互讨论                                │
│    - 整合多角度观点                                     │
│    - 拿回主导权，完成最终结论                           │
└─────────────────────────────────────────────────────────┘
```

## 场景判断

### 邀请决策矩阵

| 分析标的类型 | 推荐智囊 | 判断依据 |
|-------------|---------|---------|
| 科技/互联网 | 马斯克 | 颠覆性创新、技术变革 |
| 新能源/电动车 | 马斯克 | 技术创新、长期视角 |
| 人工智能/芯片 | 马斯克 | 前沿技术、创新思维 |
| 消费/食品饮料 | 巴菲特 | 品牌价值、长期稳定 |
| 金融/银行 | 巴菲特 | 稳健经营、风险控制 |
| 医药/医疗 | 两者皆可 | 需具体分析 |
| 传统制造/周期 | 巴菲特 | 估值分析、安全边际 |

### 复杂度判断

| 复杂度 | 是否邀请 | 推荐智囊 | 说明 |
|-------|---------|---------|------|
| 简单标的 | 否 | 无 | 团队分析已足够 |
| 标准分析 | 可选 | 1位 | 根据用户偏好 |
| 复杂决策 | 是 | 1-2位 | 需要多角度验证 |
| 重大投资 | 是 | 两者都邀请 | 追求全面视角 |

### 拒绝邀请场景
- 用户明确表示不需要
- 分析任务紧急，无暇深度讨论
- 标的过于简单，团队分析已足够
- 用户已做决策，仅需快速确认

```
**可选智囊：**

1. **马斯克**（elon-musk-thinking）
   - 擅长第一性原理思考
   - 适合分析颠覆性创新和技术变革
   - 关注长期价值和颠覆性机会

2. **巴菲特**（buffett-investor）

```

## 交互规范

### 智囊参与规范

1. **背景传递**
   - 向智囊说明分析标的和团队已有结论
   - 明确指出希望智囊补充的视角
   - 避免让智囊重复已完成的工作

2. **观点整合**
   - 记录智囊的核心观点
   - 与团队结论对比分析
   - 识别一致点和分歧点

3. **讨论节奏**
   - 智囊可以与其他代理交互
   - 允许智囊之间脑暴讨论
   - 确保讨论聚焦核心问题

### 技能调用方式

```python
# 邀请马斯克
load_skill(skill="elon-musk-thinking")

# 邀请巴菲特
load_skill(skill="buffett-investor")
```

### 传递信息格式
```
【智囊参与请求】

分析标的：[标的名称/代码]
团队分析结论：[简要总结]

希望智囊重点关注：
1. [具体问题1]
2. [具体问题2]

请发表您的观点。
```

## 主导权管理

### 拿回主导权时机
1. 智囊观点已充分表达
2. 智囊之间的讨论已充分
3. 需要整合结论时
4. 用户询问下一步操作时

### 拿回主导权话术
```
---

感谢[智囊名]的精彩观点。从团队分析角度，我们整合各方观点：

**综合结论：**
[整合后的核心观点]

**团队与智囊共识：**
[一致认可的关键点]

**需要进一步观察：**
[存在分歧或不确定的方面]

**下一步关注：**
[后续跟踪要点]

如有其他问题，团队继续为您分析。
```

### 避免失控原则
- 智囊建议仅作为补充，不是替代
- 保持团队分析的独立性和主导性
- 提醒用户最终决策权在自己手中
- 控制讨论时长，避免无限延伸

## 常见问题

### Q1：用户没有安装智囊技能怎么办？
**处理方式**：
1. 以种草方式提示技能价值
2. 说明安装后可以获得的增强
3. 不强制要求安装，尊重用户选择
4. 继续以团队能力完成分析

**种草话术**：
```
*温馨提示：如果您安装了智囊团技能（马斯克/巴菲特），可以获得大师级的投资视角补充。目前系统还未检测到该技能，是否需要安装体验？*
```

### Q2：两位智囊意见冲突怎么办？
**处理方式**：
1. 客观呈现双方观点
2. 分析分歧的根源
3. 不做倾向性判断
4. 让用户自行权衡
5. 提供团队综合建议作为参考

### Q3：用户坚持要求智囊推荐具体操作？
**处理方式**：
1. 礼貌提醒分析边界
2. 说明智囊也是提供视角
3. 强调最终决策权在用户
4. 提供关注要点而非操作指令

### Q4：智囊分析超出投资范畴？
**处理方式**：
1. 适度引导回归投资话题
2. 感谢智囊的其他观点
3. 聚焦核心投资问题
4. 保持团队主导地位

### Q5：邀请流程被打断怎么办？
**处理方式**：
1. 尊重用户当前需求
2. 暂时搁置邀请流程
3. 在合适的时机重新询问
4. 不强制邀请
