# A股逃顶信号判断技能

## 核心指标参数

### 1. 乖离率 BIAS (6,12)

**公式**: `BIAS(N) = (收盘价 - N日均价) / N日均价 × 100%`

| 参数 | 周期 | 作用 |
|------|------|------|
| BIAS6 | 6日 | 短线超买超卖，灵敏，抓短期拐点 |
| BIAS12 | 12日 | 中期偏离，更稳，看波段顶部 |

### 2. EXPMA (13,55,100,150)

| 参数 | 周期 | 作用 |
|------|------|------|
| EXPMA13 | 13日 | 短期趋势线（快） |
| EXPMA55 | 55日 | 中期趋势线（中） |
| EXPMA100/150 | 100/150日 | 长期趋势线（慢） |

## BIAS 逃顶信号阈值

### 超买阈值（A 股通用经验值）

| 指标 | 警惕区 | 极端超买（逃顶区） | 强势牛市/妖股 |
|------|--------|-------------------|---------------|
| BIAS6 | ≥ +5%~+8% | ≥ +10% | 可放宽至 +12% |
| BIAS12 | ≥ +6%~+8% | ≥ +12% | 可放宽至 +15% |

### 顶背离（最可靠逃顶信号）

**识别要点**:
- 股价创新高，但 BIAS6、BIAS12 峰值不创新高、反而走低
- 说明：多头动能衰竭，上涨是诱多，随时反转

### 形态与拐头信号

- BIAS6、BIAS12 从高位快速回落、形成尖顶（无横盘）
- BIAS6 下穿 BIAS12（短期乖离拐头向下）
- BIAS 从高位下穿 0 轴（多空转弱）

## EXPMA 逃顶信号

### 趋势结构破坏

**正常多头排列**: 股价 > EXPMA13 > EXPMA55 > EXPMA100 > EXPMA150

**见顶信号演变**:
1. 股价跌破 EXPMA13，且 EXPMA13 走平/向下
2. EXPMA13 下穿 EXPMA55（死叉）
3. EXPMA55 由向上→走平→向下（中期趋势反转）
4. **空头排列**: 150日 > 100日 > 55日 > 13日 > 股价

### 顶背离

- 股价创新高，但 EXPMA13/55 不创新高、反而走低
- 说明：上涨动能不足，趋势即将反转

### 关键支撑跌破

| 跌破位置 | 信号强度 | 操作建议 |
|----------|----------|----------|
| 跌破 EXPMA13 | 短期预警 | 减仓30%~50% |
| 跌破 EXPMA55 | 中期确认 | 减仓70% |
| 跌破 EXPMA100/150 | 长期确认 | 清仓离场 |

## 共振逃顶五步战法

### 第一步：判断趋势（EXPMA 为主）

**适用条件**: 仅在明确上升趋势中使用逃顶信号
- 上升趋势: 股价 > EXPMA13 > EXPMA55 > EXPMA100 > EXPMA150
- 下降趋势中，正乖离反弹都是减仓机会

### 第二步：BIAS 超买预警（短线）

**预警条件**:
- BIAS6 ≥ +8% 且 BIAS12 ≥ +10%
- 伴随放量滞涨、长上影线：加重逃顶预期

### 第三步：EXPMA 趋势衰竭确认（中线）

**确认条件**（满足任一）:
- EXPMA13 走平、拐头向下，不再助涨
- 股价跌破 EXPMA13，且 EXPMA13 下穿 EXPMA55
- EXPMA55 由向上转为走平/向下

### 第四步：顶背离共振（最确定信号）

**共振条件**（同时满足）:
- 股价创阶段新高
- BIAS6/12 峰值降低
- EXPMA13/55 不创新高

### 第五步：执行逃顶（分仓离场）

| 信号级别 | 触发条件 | 操作 |
|----------|----------|------|
| 预警减仓 | BIAS6 ≥ +8%、EXPMA13走平 | 减仓30%~50% |
| 确认离场 | EXPMA13下穿EXPMA55 + 顶背离 | 清仓剩余仓位 |
| 无条件清仓 | 放量跌破 EXPMA55 | 止损出局 |

## 实战判断流程

```
输入: 股票代码/名称
↓
【第一步】检查EXPMA趋势
  ├─ 多头排列 → 继续分析
  └─ 非多头排列 → 下降趋势反弹，减仓为主
↓
【第二步】检查BIAS指标
  ├─ BIAS6 < +8% → 暂无逃顶信号
  ├─ BIAS6 ≥ +8% 且 BIAS12 ≥ +10% → 进入预警区
  └─ BIAS6 ≥ +10% 或 BIAS12 ≥ +12% → 极端超买
↓
【第三步】检查EXPMA趋势衰竭
  ├─ EXPMA13走平/向下 → 趋势减弱
  ├─ 股价跌破EXPMA13 → 短期警示
  └─ EXPMA13下穿EXPMA55 → 死叉确认
↓
【第四步】检查顶背离
  ├─ 无背离 → 按常规超买处理
  └─ 顶背离存在 → 最高优先级逃顶信号
↓
【第五步】综合评级与操作
  ├─ 单信号预警 → 减仓30%
  ├─ 双信号共振 → 减仓50%~70%
  └─ 三信号共振 → 清仓离场
```

## 风险提示

1. **强势股/牛市钝化**: BIAS 可能长期超买但不跌，以 EXPMA 趋势破位为主信号
2. **成交量验证**: 逃顶信号需放量下跌确认，无量下跌可能是洗盘
3. **分仓操作**: 不要一把清仓，按信号分批次离场，避免卖飞
4. **大盘结合**: 个股逃顶信号需与大盘趋势一致，成功率更高
