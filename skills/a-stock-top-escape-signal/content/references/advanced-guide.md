# A股逃顶信号判断 - 详细参考指南

## 一、指标计算公式

### 1. BIAS 乖离率计算

```
BIAS(N) = (收盘价 - N日均价) / N日均价 × 100%
```

**简单移动平均(SMA)计算**:
```
SMA(N) = (C1 + C2 + ... + CN) / N
```
其中 C 为每日收盘价

### 2. EXPMA 指数平滑移动平均计算

```
EXPMA(N) = α × 今日收盘价 + (1-α) × 昨日EXPMA
α = 2 / (N + 1)
```

**常用周期参数**:
| 参数 | α值 | 特点 |
|------|-----|------|
| 13日 | 2/14 ≈ 0.143 | 灵敏，跟随快速 |
| 55日 | 2/56 ≈ 0.036 | 稳健，中期趋势 |
| 100日 | 2/101 ≈ 0.020 | 较慢，长期趋势 |
| 150日 | 2/151 ≈ 0.013 | 最慢，长期支撑 |

## 二、BIAS 详细应用指南

### 2.1 超买超卖区间划分

#### 震荡市/弱趋势环境

| BIAS6 值 | 市场状态 | 操作建议 |
|----------|----------|----------|
| < -3% | 短线超卖 | 关注低吸机会 |
| -3% ~ +3% | 正常区间 | 观望 |
| +3% ~ +5% | 偏热 | 谨慎追涨 |
| +5% ~ +8% | 超买预警 | 准备减仓 |
| ≥ +8% | 极端超买 | 果断减仓 |

#### 强势趋势/牛市环境

| BIAS6 值 | 市场状态 | 操作建议 |
|----------|----------|----------|
| < -5% | 超卖 | 正常低吸 |
| -5% ~ +5% | 正常 | 顺势持有 |
| +5% ~ +10% | 偏热但可接受 | 不追涨 |
| +10% ~ +12% | 极端区域 | 准备逃顶 |
| ≥ +12% | 大概率见顶 | 清仓信号 |

### 2.2 顶背离识别详解

#### 标准顶背离（最可靠）

```
形态特征:
- 股价走出 A-B-C 三点，A 和 C 均为阶段高点
- B 为回调低点
- A 点对应 BIAS 峰值: X
- C 点股价创新高，但 BIAS 峰值: Y < X
```

#### 隐性顶背离（需警惕）

```
形态特征:
- 股价持续上涨，不明显回调
- BIAS 持续高位钝化后，突然快速下降
- 伴随成交量萎缩
```

### 2.3 BIAS 形态学

#### 尖顶形态（最危险）

```
特征:
- BIAS 从高位快速回落
- 回落角度陡峭（>45度）
- 无明显横盘整理
- 预示快速下跌
```

#### 双顶形态

```
特征:
- BIAS 两次触及高位区域
- 第二次峰值低于第一次
- 中间有回调但不下穿0轴
```

#### 圆顶形态

```
特征:
- BIAS 缓慢下降
- 持续时间较长（5-10天）
- 相对温和的顶部
```

## 三、EXPMA 详细应用指南

### 3.1 趋势状态判断

#### 多头排列五种状态

| 状态 | 排列顺序 | 市场含义 | 操作 |
|------|----------|----------|------|
| 完美多头 | 股价>13>55>100>150 | 主升浪 | 坚定持有 |
| 强势多头 | 股价>13>55>150>100 | 略强势 | 持有 |
| 标准多头 | 股价>13>55>100>150 | 正常上升 | 持有 |
| 弱势多头 | 股价>55>13>100>150 | 震荡上行 | 谨慎 |
| 濒临破位 | 股价在13附近挣扎 | 可能转势 | 观察 |

#### 空头排列五种状态

| 状态 | 排列顺序 | 市场含义 | 操作 |
|------|----------|----------|------|
| 标准空头 | 150>100>55>13>股价 | 主跌浪 | 清仓 |
| 弱势空头 | 150>100>13>55>股价 | 反弹无力 | 观望 |
| 修复空头 | 150>55>100>13>股价 | 底部震荡 | 等待 |
| 濒临转多 | 13>股价>55>100>150 | 可能见底 | 观察 |
| 盘整状态 | 交织缠绕 | 无趋势 | 短线 |

### 3.2 死叉与金叉详解

#### EXPMA13 下穿 EXPMA55（死叉）

**标准死叉**:
```
条件:
- EXPMA13 由上向下穿越 EXPMA55
- 交叉点股价在 EXPMA55 下方
- 伴随成交量放大

信号强度:
- 股价在 EXPMA55 上方: ★★★☆☆ (中期调整)
- 股价在 EXPMA13 和 EXPMA55 之间: ★★★★☆ (趋势转弱)
- 股价在 EXPMA13 下方: ★★★★★ (确认转空)
```

#### EXPMA13 上穿 EXPMA55（金叉）

**标准金叉**:
```
条件:
- EXPMA13 由下向上穿越 EXPMA55
- 交叉点股价在 EXPMA55 上方
- 伴随成交量放大

信号强度:
- 股价在 EXPMA55 上方: ★★★★★ (确认转多)
- 股价在 EXPMA13 和 EXPMA55 之间: ★★★★☆ (初步转多)
- 股价在 EXPMA55 下方: ★★★☆☆ (反弹信号)
```

### 3.3 支撑与压力

#### EXPMA 支撑作用

```
上升趋势中的支撑位:
- 股价首次回踩 EXPMA13: 强支撑 (加仓点)
- 股价回踩 EXPMA55: 中等支撑 (持有观察)
- 股价回踩 EXPMA100: 弱支撑 (警惕)
- 股价回踩 EXPMA150: 生死线 (必须守住)
```

#### EXPMA 压力作用

```
下降趋势中的压力位:
- 股价首次反弹至 EXPMA13: 强压力 (减仓点)
- 股价反弹至 EXPMA55: 中等压力 (离场点)
- 股价反弹至 EXPMA100: 弱压力 (观察)
- 股价反弹至 EXPMA150: 生死线 (必须突破)
```

## 四、共振战法实战详解

### 4.1 五步战法详细步骤

#### 第一步：趋势判断（EXPMA 为主）

**判断标准**:

```
明确上升趋势 (可使用逃顶信号):
✓ 股价站稳 EXPMA55 以上
✓ EXPMA55 向上运行
✓ EXPMA13 > EXPMA55 > EXPMA100

模糊/下降趋势 (减仓为主，慎用追涨):
△ 股价在 EXPMA55 附近徘徊
✗ 股价在 EXPMA55 以下
✗ EXPMA55 向下运行
```

#### 第二步：BIAS 超买预警

**预警触发条件**:
```
轻度预警:
- BIAS6 ≥ +5% (短线偏热)

中度预警:
- BIAS6 ≥ +8% 且 BIAS12 ≥ +10%

重度预警:
- BIAS6 ≥ +10% (极端超买)
- BIAS12 ≥ +12% (中期见顶)
- 任意周期 BIAS ≥ +15% (妖股/牛市顶部)
```

**加重预警因素**:
- 伴随放量滞涨（成交量放大但涨幅收窄）
- 出现长上影线/射击之星
- 盘中多次打开涨停板
- 涨停封单快速减少

#### 第三步：EXPMA 趋势衰竭确认

**趋势衰竭信号（按重要性排序）**:

```
1. EXPMA13 走平/拐头
   - 判断方法: 连续3日 EXPMA13 值变化 < 0.1%
   - 信号强度: ★★★☆☆

2. 股价跌破 EXPMA13
   - 判断方法: 当日收盘价 < EXPMA13 值
   - 信号强度: ★★★★☆

3. EXPMA13 下穿 EXPMA55（死叉）
   - 判断方法: EXPMA13 < EXPMA55
   - 信号强度: ★★★★★

4. EXPMA55 由升转降
   - 判断方法: 连续5日 EXPMA55 值变化由正转负
   - 信号强度: ★★★★★★
```

#### 第四步：顶背离共振

**三重顶背离（最高确定性）**:

```
1. 价格顶背离
   - 股价创新高
   - 但涨幅明显收窄

2. BIAS 顶背离
   - 股价新高，但 BIAS6/12 峰值降低
   - 或 BIAS 高位钝化后快速下滑

3. EXPMA 顶背离
   - 股价新高，但 EXPMA13/55 不创新高
   - 或 EXPMA 高位走平

三背离同时出现 = 历史大顶信号
```

#### 第五步：执行逃顶

**分仓操作策略**:

```
阶段一：预警减仓
触发: BIAS6 ≥ +8% + EXPMA13走平
动作: 减仓 30%~50%
仓位: 保留 50%~70%

阶段二：确认减仓
触发: EXPMA13死叉 + 顶背离
动作: 再减仓 30%~40%
仓位: 保留 20%~30%

阶段三：清仓离场
触发: 放量跌破 EXPMA55 + 任意顶背离
动作: 清仓剩余全部
仓位: 0%

底线止损:
触发: 股价放量跌破 EXPMA55 且无法快速收回
动作: 无条件清仓
```

## 五、实战案例分析

### 5.1 标准逃顶案例

**背景**: 某新能源股票，经历3个月上涨

```
第1周:
- 股价沿 EXPMA13 稳步上涨
- BIAS6 在 +3%~+5% 区间波动
- EXPMA 完美多头排列
→ 正常持有

第2周:
- 股价加速上涨，出现2个涨停
- BIAS6 达 +11%，BIAS12 达 +9%
- EXPMA13 开始走平
→ 预警减仓30%

第3周:
- 股价创新高，但出现长上影线
- BIAS6 快速回落至 +6%
- BIAS6 下穿 BIAS12
→ 确认减仓50%

第4周:
- 股价跌破 EXPMA13
- EXPMA13 下穿 EXPMA55（死叉）
- 同时出现价格、BIAS、EXPMA 三重顶背离
→ 清仓离场
```

### 5.2 假突破案例（需警惕）

**背景**: 某科技股，高位震荡

```
特征:
- 股价多次尝试突破前高
- 但每次 BIAS 都无法突破前期峰值
- EXPMA55 持续走平

判断:
- 这是主力诱多行为
- 每次反弹高点都是减仓机会
- 不应追涨
```

### 5.3 强势钝化案例

**背景**: 牛市中的龙头股

```
特征:
- BIAS6 长期维持在 +10% 以上
- 股价不断创新高
- EXPMA 持续多头排列

操作策略:
- 以 EXPMA 趋势破位为主信号
- 忽略 BIAS 超买警告
- 持有至 EXPMA13 有效跌破 EXPMA55
```

## 六、注意事项与风险控制

### 6.1 环境适应性调整

| 市场环境 | BIAS 阈值调整 | 重点指标 |
|----------|---------------|----------|
| 强势牛市 | BIAS6 可至 +12%，BIAS12 可至 +15% | EXPMA趋势 |
| 震荡市 | 标准阈值，BIAS6 ≥ +8% 触发 | 双向信号 |
| 弱势市场 | 降低阈值，BIAS6 ≥ +5% 预警 | 趋势破坏 |

### 6.2 成交量验证

```
有效逃顶信号:
✓ 放量下跌 + 缩量反弹
✓ 跌破关键均线时成交量放大
✓ 反弹时成交量明显萎缩

可能是洗盘:
✗ 无量下跌
✗ 下跌时缩量，反弹时放量
✗ 跌破均线后快速收复
```

### 6.3 大盘联动分析

```
个股逃顶成功率:
- 大盘上升 + 个股逃顶信号 = 60% 成功率
- 大盘横盘 + 个股逃顶信号 = 80% 成功率
- 大盘下降 + 个股逃顶信号 = 90% 成功率

建议:
- 大盘上升时，可适度放宽逃顶阈值
- 大盘横盘时，标准执行逃顶信号
- 大盘下降时，优先执行逃顶信号
```

### 6.4 仓位管理建议

```
标准仓位管理:
- 底仓: 30% (长期持有，不轻易动)
- 趋势仓: 40% (跟随趋势，EXPMA13止损)
- 短线仓: 30% (BIAS 超买超卖来回做)

逃顶时的仓位控制:
- 预警信号: 先减趋势仓
- 确认信号: 再减短线仓
- 最终信号: 保留底仓或清全部
```
