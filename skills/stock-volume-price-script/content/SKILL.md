# 量价八阶短视频话术生成器

## 功能概述

基于量价八阶技术分析理论，接收股票代码，调用量价分析技能获取分析结果，生成适合短视频平台的股票分析口播话术脚本。

## 工作流程

### 1. 接收股票信息

接收用户提供的股票代码，格式：`股票代码` 或 `股票名称`。

### 2. 获取股票数据

调用 `a-stock-akshare-data` 技能获取股票历史数据（至少60个交易日）：

```
调用 expert-skills:a-stock-akshare-data
参数：股票代码、获取60日K线数据
```

### 3. 执行量价八阶分析

调用 `volume-price-eight-stages` 技能进行深度分析：

```
调用 expert-skills:volume-price-eight-stages
参数：股票代码、60日K线数据
```

### 4. 生成短视频话术

基于量价分析结果，生成结构化的短视频口播脚本：

```
生成规则：
1. 开场白（3-5秒）：吸引注意力，建立专业形象
2. 行情概述（10-15秒）：简述当前走势位置
3. 量价解读（15-20秒）：核心分析观点
4. 风险提示（5-8秒）：合规风险提示
5. 互动引导（3-5秒）：引导关注/评论

话术风格：
- 口语化、自然流畅
- 专业但不晦涩
- 情绪适度、理性分析
- 每段有明确结论
```

### 5. 输出格式

```markdown
# 【股票名称】量价分析短视频话术
**股票代码**: XXX
**分析日期**: YYYY-MM-DD
**当前走势**: [建仓/拉升/派发/回落/筑底/反弹/出货/洗盘]期

## 脚本正文

### 🎬 开场白（建议时长：5秒）
[开场白内容]

### 📊 行情概述（建议时长：15秒）
[行情概述内容]

### 🔍 量价解读（建议时长：25秒）
[量价分析核心内容]

### ⚠️ 风险提示（建议时长：8秒）
[风险提示内容]

### 💬 互动引导（建议时长：5秒）
[互动引导内容]

---
**视频总时长**：约58秒
**建议配乐**：轻商务/沉稳
**视觉建议**：K线图+成交量叠加图表
```

## 注意事项

1. 风险提示必须包含："以上内容仅供参考，不构成投资建议"
2. 话术避免绝对化用词，如"一定"、"必然"、"保证"
3. 控制情绪化表达，保持客观理性
4. 结合当前市场热点和板块轮动

## 错误处理

- 若股票代码无效：提示用户检查代码格式
- 若数据获取失败：返回友好提示，询问是否重试
- 若分析超时：分段返回已获取内容
