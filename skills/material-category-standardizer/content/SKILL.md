# 材料类别标准化映射工具

## 功能概述

本技能将混乱的建筑材料、检测材料等类别名称标准化为统一规范格式，自动识别原始类别并输出优化后类别及大类归属。同时支持**标准参数自动更新**，能够从外部数据源获取最新标准并同步更新。

### 核心能力

| 功能 | 说明 |
|------|------|
| 类别标准化 | 将混乱材料名称映射为标准类别 |
| 大类归属 | 自动识别所属大类（8大类） |
| 标准参数 | 附带执行标准、规格范围、检测项目 |
| **自动更新** | 支持从外部标准数据库自动更新参数 |

## 分类体系结构

### 大类划分（8大类）

| 大类编码 | 大类名称 | 说明 |
|---------|---------|------|
| 01 | 金属材料 | 黑色金属、有色金属及其合金 |
| 02 | 非金属材料 | 无机非金属、有机非金属 |
| 03 | 建筑主体材料 | 混凝土、砂浆、砖瓦等结构材料 |
| 04 | 保温隔热材料 | 保温板、隔热材料、吸声材料 |
| 05 | 防水密封材料 | 防水卷材、密封材料、堵漏材料 |
| 06 | 装饰装修材料 | 涂料、瓷砖、板材、门窗等 |
| 07 | 管材管件 | 给排水管、电线管、线缆等 |
| 08 | 其他材料 | 紧固件、胶粘剂、防护用品等 |

## 输入格式

支持两种输入方式：

### 1. 单条查询
直接输入需要标准化的材料类别名称：
```
钢绞线
C30混凝土
聚氨酯保温板
```

### 2. 批量处理
提供 JSON 格式的批量数据：
```json
{
  "categories": [
    "钢绞线",
    "C30混凝土",
    "聚氨酯保温板"
  ]
}
```

## 映射规则

### 1. 精确匹配
直接匹配预设的标准化名称映射表

### 2. 模糊匹配
对于未精确匹配的输入，采用以下策略：
- 提取关键词进行匹配
- 支持别名、俗称、简称
- 使用相似度算法辅助判断

### 3. 强度等级处理
对于混凝土等材料，自动提取强度等级：
- `C30混凝土` → 标准类别：`普通混凝土`，强度等级：`C30`
- `M5砂浆` → 标准类别：`水泥砂浆`，强度等级：`M5`

## 标准自动更新功能

### 更新触发方式

| 触发方式 | 说明 |
|---------|------|
| 手动触发 | 用户明确要求"更新标准参数"时执行 |
| 定期更新 | 配置定时任务自动同步最新标准 |
| 按需更新 | 指定特定类别进行更新 |

### 更新数据源

支持从以下来源自动获取标准参数：
- 国家标准数据库（如 GB 标准）
- 行业标准数据库（如 JC、JG 标准）
- 地方标准库
- 自定义标准文件（Excel/JSON/YAML）

### 更新流程

```
1. 检测数据源变化 → 2. 获取最新标准 → 3. 比对差异 → 4. 确认更新 → 5. 同步到映射表
```

### 更新配置

```json
{
  "update_config": {
    "enabled": true,
    "source": "national_standards",
    "schedule": "weekly",
    "auto_merge": false,
    "conflict_resolution": "newest_wins"
  }
}
```

| 指标 | 目标值 |
|-----|--------|
| 精确匹配率 | ≥ 85% |
| 模糊匹配准确率 | ≥ 90% |
| 无法识别率 | ≤ 5% |
| 标准更新成功率 | ≥ 95% |

## 使用示例

**示例1：单条标准化**
- 输入：`热镀锌钢管`
- 输出：`热镀锌焊接钢管`，大类：`01 金属材料`

**示例2：批量处理**
- 输入：批量材料清单
- 输出：标准化后的完整映射表，可导出为 Excel/CSV

**示例3：报告整理**
- 自动识别报告中混乱的材料名称，统一规范化格式

**示例4：标准参数更新**
- 输入："更新钢筋相关标准参数"
- 输出：自动从标准库获取最新钢筋标准，更新到映射表中

**示例5：批量更新**
- 输入："同步最新国家标准参数"
- 输出：比对并更新所有类别的新标准，生成更新报告
