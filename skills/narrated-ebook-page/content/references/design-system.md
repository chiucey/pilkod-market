# 设计系统

模板的全部视觉规则都在 `template.html` 的 `<style>` 里，这里是「读法」与「为什么」。
改样式前先读这里，改完把新规则补回本文。

## 一、配色契约

三个层次，各有唯一职责，不可互换：

| 层级 | token | 值 | 用在哪 |
|---|---|---|---|
| 纸面 | `--paper` | `#FFFFFF` | 页面与卡片底色 |
| 纸面（次级） | `--paper-sunk` | `#FBFAF8` | 提示框、图注底、悬停态 |
| 描边 | `--rule` / `--rule-soft` | `#E8E6E1` / `#F2F0EC` | 卡片分隔线、表格线 |
| 正文 | `--ink` | `#17191E` | 正文近黑，不用纯 `#000`（纯黑在屏幕上发硬） |
| 次级文字 | `--ink-70` / `--ink-60` / `--ink-45` | `#4A4F58` / `#6B7078` / `#8A8F98` | 卡片描述、图注、轴标签 |
| **大标题 / 强调** | `--amber` | `#F2A100` | 章标题、大数字、强调线、当前朗读段底色 |
| 强调（深） | `--amber-deep` | `#C87C02` | 琥珀底上的文字、链接悬停（保证对比度） |
| 强调（浅） | `--amber-soft` | `#FFF4DE` | 提示框底、图表强调块底 |
| **小标题 / 强调块** | `--deep` | `#0E1826` | 小标题、引文文字、深色强调块 |
| 深色次级 | `--deep-60` | `#33414F` | 提示框正文 |

**橙黄不是点缀色，是标题色**：`--amber` 用在章标题、封面大标题、当前朗读段落、
图表强调块上。正文里不要随手撒琥珀色——一旦正文段落出现琥珀，读者就分不清
哪里是章节、哪里是正文了。琥珀底上的文字一律用 `--amber-deep`，
否则 `#F2A100` 上放白字对比度不足。

## 二、字号：基准 × 倍率两层

```css
--fs-base: 18px;      /* 基准，由断点决定 */
--fs-scale: 1;        /* 倍率，读者用 A−/A+ 调，存 localStorage */
--fs: calc(var(--fs-base) * var(--fs-scale));
```

必须拆两层。不要把绝对像素写进 `--fs` 的内联样式：内联优先级压过媒体查询，
手机上「降一档」的规则会永远不生效（实测每行只剩十五个字）。
读者偏好存的是倍率不是像素，换设备、换断点都继续成立。

档位：`0.88 / 0.94 / 1 / 1.07 / 1.15 / 1.24`。

正文行高 `--lh: 2.0`（手机 1.9）。中文正文行高比西文低，否则段落之间会散架。
正文栏宽 `--measure: 41rem`，超出这个宽度眼睛要重新找行首。

## 三、响应式六档

| 断点 | 变什么 |
|---|---|
| ≥1200px | 图表与宽表从版心破格放大，右侧给朗读浮条留 27rem 空档 |
| ≤1199px | 图表可横向拖动；宽表设最小宽度，保持可读列宽 |
| ≤1080px | 版心收窄（`--gap: 3rem`） |
| ≤860px | 目录收成抽屉；出现顶栏 + 底部朗读条；正文上下让出固定层高度 |
| ≤560px | 手机档：`--fs-base: 16px`；要点卡单列；宽表摊成卡片 |
| ≤380px | `--fs-base: 15.5px` |

**固定层必须让出位置**：移动端顶栏与底部朗读条是 `position:fixed`，
正文区的 `padding-top` / `padding-bottom` 要减去 `--mbar-h` / `--bbar-h`，
否则固定层直接压在字上。这是移动端最难读的一类问题。

**宽表在手机上摊成卡片**：`thead` 隐藏，每行变成带边框的块，
每个 `td` 用 `td::before { content: attr(data-l) }` 把列名显示成行内小标签。
所以写表格时每个 `td` 都必须带 `data-l="列名"`。

**宽表摊成卡片只作用于屏幕**：打印样式要把 `display` 还原成 `table`，
纸面上仍然是规规矩矩的表格。

### 卡片化规则写在后面那个 560px 块里（顺序陷阱）

模板里有 **两个** `@media (max-width:560px)` 块和 **两个** `@media (max-width:1199px)` 块。
跟宽表有关的是这两个，选择器完全相同：

| 位置 | 块 | 规则 |
|---|---|---|
| 靠前 | `@media (max-width:1199px)` | `.chapter .tablewrap table { min-width: 760px }`（保持可读列宽） |
| 靠后 | `@media (max-width:560px)` | `.chapter .tablewrap table { min-width: 0; display: block }`（摊成卡片） |

两条选择器**优先级相同**（都是 `.chapter .tablewrap table`），所以**靠书写顺序决胜**：
560px 块写在后面，于是手机上 `min-width:0` 生效、表格摊成卡片。

**后果**：如果你把 560px 块往前挪，或者在 1199px 块里再加一条 `min-width`，
卡片化立刻失效——表格又被撑回 760px 宽，在手机上横向溢出。
要改表格在手机档的表现，就改**靠后那个** 560px 块，别动 1199px 块。
同理，别在 1199px 块里写 `.chapter .tablewrap table` 的任何 `min-width` 以外的属性，
它会被后面同优先级的规则覆盖掉。

## 四、组件清单

| 类名 | 用途 | 什么时候用 |
|---|---|---|
| `.cover__card` | 封面卡：书名 + 副题 + 关键数字 + 双入口 | 每份文档第一屏（纯文字卡片，不放图） |
| `.cover__nums` / `.cover__num` | 封面关键数字（结论前置） | 有 4 个左右可一眼带走的结论时 |
| `.cover__top` / `.cover__kicker` / `.cover__badge` | 封面顶栏：分类标签 + 版本或状态 | 想在首屏标出文档类别时 |
| `.cover__hint` | 首屏能力说明（能听、能打印） | 一行小字把用法讲清楚 |
| `.cover__intro` | 封面导语 | 读者第一眼看到的结论；不参与朗读 |
| `.chapter` / `.chapter__head` | 章节容器 + 章号 + 章标题 + 导语 | 每章一个 |
| `.btn` / `.btn--primary` | 圆角按钮 / 琥珀实心按钮 | 页面里的操作入口 |
| `.prose` | 正文段落 | 主体文字；缩进两字，靠段间距断段 |
| `.h.h--3` / `.h.h--4` | 小标题（深色） | 章内分组；`h--3` 带琥珀色短竖线 |
| `.pull` | 引文（琥珀色竖线） | 稀缺资源，一章最多一两条 |
| `.cards` / `.card` | 并列要点卡 | 真的并列的三到五条 |
| `.callout` / `.callout--note` | 提示框 | 读者必须注意的补充（琥珀）/ 延伸材料（中性） |
| `.list` / `.list--dot` / `.list--check` | 列表 | 并列条目；`list--dot` 用于目录式清单 |
| `.bars` / `.bar__row` | 数据条 | 占比型数据，`--w` 是 0–100 的比例 |
| `.tablewrap` | 表格容器 | 多行多列对照 |
| `.timeline` | 时间轴 | 带先后顺序的事件 |
| `.figure` / `.figure--svg` | 插图 | 内联 SVG 走 `figure--svg` |
| `.svgfig` | SVG 容器与入场动效 | `data-motion="reveal"` 进场淡入，`none` 不动 |
| `.slot` | 待补图占位 | 素材还没到位时用，别硬编一张图 |
| `.tags` / `.tag` | 标签 | 少量并列属性 |
| `.divider` | 大段落分隔（`◆ ◆ ◆`） | 只在大的内容分区之间用（模板里只在封面与序章之间用了一次） |
| `.ttsbar__main` | 朗读播放/暂停主键（琥珀实心） | 停着显示 ▶、念着显示 ⏸，靠 `is-on` 切换（详见 reading-mode.md） |
| `.colophon` | 版权页 | 结尾的书名 / 作者 / 版本 |

**组件克制**：一段话不要做成卡片，两句话不配卡片（卡片之间靠 1px 线分隔，
多了会碎）；`.pull` 是稀缺资源；`.divider` 不是装饰，别每几段放一个。

**封面只做文字卡片**：不引外部图片、不放图片占位框、不依赖任何图文件。
封面图会同时破坏两个前提——单文件自包含（离线可读、不下载外部文件）与
打印不失真。要图就用正文的 `.slot` 占位，素材到位后换成内联 SVG。
`--cover-w` 只是封面卡的宽度上限（820px），不是图片宽度。

## 五、打印 / 导出 PDF

模板已带 `@media print`：

- 隐藏所有交互层：目录、朗读条、朗读面板、字号控件、进度条、顶栏、矢量图全屏层
- 正文基准字号改 `11.5pt`，`--fs-scale` 强制回 1（它是 JS 写在元素内联样式里的，
  普通打印规则压不住）
- 每章 `page-break-before: always`，封面 `page-break-after: always`
- 卡片、图、提示框、表格、数据条、时间轴、引文一律 `break-inside: avoid`
- 插图动效冻结到完整状态，不能印出半途的淡出
- 宽表还原成真表格，不带手机的卡片化形态

打印后用 ⌘P → 存为 PDF。导出前先确认「背景图形」是否勾选：卡片底色、琥珀
强调块需要它才能保留；正文可读性不依赖它。

## 六、可访问性

- 正文 `--ink` 对白底对比度约 15:1，次级文字 `--ink-45` 对白底约 3.4:1——
  只用于图注、轴标签这类辅助信息，不要用它写正文
- 焦点可见：`:focus-visible` 统一用琥珀色描边，键盘用户能看见自己在哪
- 朗读面板、目录、朗读条都有 `aria-label`；开关用 `aria-expanded` 同步状态
- SVG 插图必须有 `role="img"` 和 `aria-label`；图内装饰元素放 `aria-hidden="true"`
- 尊重系统「减少动态效果」：`prefers-reduced-motion` 下所有入场动效关闭，
  图必须仍然可见（不许停在透明状态）
- 图注不是装饰，要说明「这张图在讲什么」，不是重复图里的文字

## 七、字体

只用系统字体，不引外链字体（离线可读、单文件交付）：

```css
--serif: "Songti SC","STSong","Source Han Serif SC","Noto Serif SC","Times New Roman",serif;
--sans:  "PingFang SC","Hiragino Sans GB","Source Han Sans SC","Noto Sans SC",-apple-system,"Helvetica Neue",sans-serif;
--mono:  "SF Mono",ui-monospace,Menlo,Consolas,monospace;
```

正文与小标题用衬线（长文可读），界面元素（目录、按钮、图注、标签）用无衬线，
数字与代码用等宽。封面大标题用衬线。
