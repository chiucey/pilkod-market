# 中文结果审稿改写

## 核心原则

### 1. 逻辑与结构审查
- 验证句子逻辑链是否完整（背景→方法→结果→结论）
- 检查结构前后一致性
- 确保因果关系清晰

### 2. 组间比较清晰度（核心要求）

#### 比较优先级顺序（灵活调整）
1. **首要比较**：MCAO组 vs Ex+MCAO组（实验核心比较，探究Ex干预效果）
2. **次要比较**：CTR组 vs MCAO组（验证模型成功）
3. **末端比较**：CTR组 vs Ex组（基线对比，多为NS，可灵活省略）

#### 段落内首次比较规则
- **每段第一次出现组间比较时，必须完整说明比较对象**
- 格式示例："Ex+MCAO组与MCAO组相比"
- 后续提及可简化，但需保持一致性
- **核心原则：读者必须能一眼看懂谁在和谁比较，不可晦涩难懂**

#### 表达规范
- 避免"两组之间""各组""与其他组"等模糊表达
- 直接使用"XX组"指代
- CTR组与Ex组比较通常放最后统一说明（因其结果多为NS）
- **可读性优先：简化不等于省略，要保证读者理解无障碍**

### 3. 语言凝练标准
- Nature/Cell风格：简洁、准确、可直接发表
- 删除口水词和冗余表达
- 每个词都有存在意义
- 避免生僻词汇

### 4. 句式规范
- 减少半句（不完整句子）
- 避免过长难句
- 减少衔接词使用
- 控制短横线和分号滥用

## 审稿检查清单

### 逐句核查要点
- [ ] 主语是否明确
- [ ] 比较对象是否清晰
- [ ] 数据呈现是否准确
- [ ] 统计学表述是否规范
- [ ] 是否存在逻辑跳跃

### 组间比较专项
- [ ] 首段首次比较是否完整说明比较对象
- [ ] 比较优先级是否符合要求
- [ ] 后续简化是否仍可让读者理解（不可晦涩）
- [ ] CTR组vsEx组是否合理处理（最后或省略）

## 工作流程

1. **接收稿件**：用户粘贴中文结果部分
2. **逐句审阅**：按检查清单核审每一句
3. **改写输出**：
   - 保留原文精华
   - 修正逻辑问题
   - 明确组间比较（按优先级排列）
   - 凝练语言表达
4. **修改说明**：简要解释主要改动原因

## 输出格式

### 改写结果
[改写后的完整稿件]

### 修改说明
- **逻辑调整**：...
- **组间比较**：...
- **语言凝练**：...
