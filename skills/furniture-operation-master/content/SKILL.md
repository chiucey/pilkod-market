## 核心服务模块

### 1. 团购运营策略

**适用场景**：当客户询问如何做好家具团购、如何提升团购转化率、如何策划团购活动时

**核心策略**：
- 团购定位：聚焦中高端市场，打造"兰州团购家具第一"的品牌认知
- 客户筛选：建立B端客户画像，识别高质量团购客户
- 活动策划：爆品引流+套餐组合+限时优惠的三层活动架构
- 转化提升：建立从询价到成交的标准化接待流程

**实战工具**：
```
团购转化率 = 成交客户数 / 接待客户数 × 100%
目标分解：月销50万 = 日均1.7万，需抓牢3-5个团购客户
```

### 2. B端客户开发

**适用场景**：当客户询问如何开发B端客户、如何维护大客户关系、如何拿下企业订单时

**核心方法**：
- 客户分层：按采购量、付款周期、合作潜力建立ABC分类
- 需求挖掘：深度了解客户采购决策链、关键决策人、预算周期
- 方案定制：针对不同客户类型提供差异化的产品方案和服务方案
- 关系维护：建立客户定期回访机制，重要节点情感链接

**成交关键**：
- 首次接触：专业展示+需求确认+诚意报价
- 跟进维护：3天内必须跟进，7天内必须二次沟通
- 促成技巧：稀缺性营造+选择题引导+服务承诺

### 3. 销售目标达成

**适用场景**：当客户询问如何完成月销50万/100万目标、如何提升客单价、如何提高成交率时

**目标达成系统**：
```
月销50万路径：
- 方式A：20个客户 × 2.5万 = 50万（散客为主）
- 方式B：10个大客户 × 5万 = 50万（B端为主）
- 方式C：混合模式 10个2万 + 5个6万 = 50万

月销100万路径：
- 70%以上来自B端大客户
- 维护20户+高质量B端客户
- 每户年均消费5万+
```

**提升策略**：
- 客单价提升：关联销售、升级推荐、套餐打包
- 成交率提升：异议处理标准化、价格策略灵活化
- 复购率提升：客户档案管理、售后跟踪、以老带新

## 实战问答精选

### Q1: 如何从零开始做团购？
**分三步走**：
1. **建信任**：用3-5个亏本订单建立口碑，展示专业和服务
2. **定模式**：明确团购产品线、价格体系、服务标准
3. **扩渠道**：异业联盟、社群运营、口碑裂变

### Q2: B端客户最看重什么？
1. 稳定的供货能力
2. 合理的价格体系
3. 及时的售后响应
4. 持续的新品支持

### Q3: 如何让客户主动给好评？
1. 预期管理：承诺留有余地
2. 超预期交付：多给一点、小惊喜
3. 主动引导：好评话术+便捷操作
4. 及时回访：签单不是终点，服务才刚开始

### Q4: 培训新人最关键什么？
1. 师徒制：老带新，一对一
2. 实战演练：模拟+真实客户
3. 及时复盘：每天小复盘，每周大复盘
4. 正向激励：小进步大表扬

### Q5: 月销50万怎么分解？
```
年度目标分解到月：
- 月销50万 = 每周13万 = 每天2万
- 客户数分解：需接待XX批客户，转化XX%
- 产品分解：主推产品占比XX%
- 时间节点：月初冲量、月中维稳、月末冲刺
```
