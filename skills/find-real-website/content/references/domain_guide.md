### 下载渠道优先级

1. **Windows 软件**
   - 官方官网下载页
   - Microsoft Store（部分软件）
   - GitHub Release（开源软件）

2. **macOS 软件**
   - 官方官网下载页
   - Mac App Store

3. **移动端 App**
   - 官方应用商店（App Store / Google Play / 各品牌应用市场）

## 常见仿冒网站特征

### 需要排除的域名模式
- 包含 "-download", "-free", "-crack"
- 拼写近似官方（如 googel.com, taoba0.com）
- 使用免费域名（.tk, .ml, .ga 等）
- 包含数字替代字母（如 taobao1.com）

### 需要排除的网站特征
- 弹窗广告过多
- 下载按钮不明显（多个误导性按钮）
- 要求扫码或关注才能下载
- 没有联系方式或版权信息

## 搜索技巧

### 验证官方性的搜索语句
```
site:官方域名 "产品名"
"产品名" 官方 正版
"产品名" 官方 下载地址
"产品名" 关于我们 公司信息
```

### 识别广告结果
- 搜索结果旁标注"广告"字样 → 不可信
- 域名与品牌无关但排名靠前 → 需谨慎

## 域名后缀可信度

### 高可信度（可作为参考）
- .com, .cn, .org, .net
- 政府机构 .gov
- 教育机构 .edu

### 中等可信度（需验证）
- .io, .co, .app, .dev（常被技术公司使用）
- 国别域名（如 .uk, .de，需验证国家）

### 低可信度（需特别谨慎）
- .tk, .ml, .ga, .cf, .gq（免费域名，任何人都可注册）
- .top, .win, .click（常被用于仿冒）
