# 六爻八卦命理技能

根据中国传统命理体系，通过出生时间排出八字和六爻卦象，进行性格解读和运势分析。

## 输入要求

用户需提供：
- **出生年月日时分**（时分可选，默认为12:00）

## 输出内容

1. **八字·四柱** — 年柱、月柱、日柱、时柱
2. **五行·力量分布** — 木、火、土、金、水的力量对比
3. **六爻·卦象** — 上卦、下卦、卦名、动爻位置
4. **性格·日主特质** — 日干日支的性格解读
5. **大运·走势** — 简要运势分析

## 执行脚本

```bash
python3 /workspace/skills/liuyao-bagua/scripts/liuyao.py <年> <月> <日> [时] [分]
```

示例：
```bash
python3 /workspace/skills/liuyao-bagua/scripts/liuyao.py 1990 5 15 14 30
```

## 核心逻辑

- **年柱**：由出生年份推算天干地支
- **月柱**：由出生月份配合日干推算
- **日柱**：以1900年1月1日为甲子基准，按天数累加推算
- **时柱**：由出生时辰配合日干推算
- **起卦**：上下卦由年+月+日及时干支组合运算，取8余数为卦位
- **动爻**：由四柱八字的干支序数总和，取6余数确定动爻位置

## 解卦原则

- 卦象解释以《易经》卦辞为本
- 五行力量分析用于判断命盘旺衰和喜忌
- 性格解读以日干（日主）为核心，结合日支辅助

## 注意事项

- 六爻命理分析**仅供娱乐参考**，不能作为人生重大决策的唯一依据
- 命理分析涉及复杂传统理论，本技能提供简化版解读
- 如需精确命盘，请咨询专业命理师
