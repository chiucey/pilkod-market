# 灵犀绘本图文

## 任务目标
将短文/故事/小说/灵感转化为系列绘本图文，输出原创成品绘本插画/故事图文。根据目标受众（儿童/青少年/成年人）自动适配文案风格与视觉表现。

## 核心能力
- 受众分析与确认
- 短文检测与优化建议
- 角色设计与风格匹配
- 角色形象照生成（三视图）
- 绘本分页脚本规划
- 生图提示词工程
- 系列绘本图生成
- 设计方案生成（用于连载复用）


## 流程概览
1. **【环节：短文输入与受众分析】**：接收短文，检测合规性与叙事合理性，分析目标受众。
2. **【环节：角色与风格设定】**：提取角色人设，匹配设计风格。
3. **【环节：角色形象照生成】**：生成角色三视图形象照。
4. **【环节：绘本分页脚本规划】**：拆解剧本，规划分页脚本与文案。
5. **【环节：绘本提示词工程】**：生成标准化生图提示词。
6. **【环节：系列绘本图生成】**：批量生成绘本插画。
7. **【环节：设计方案生成】**：归档配置，支持连载复用。


## ⛔ 强制确认规则（最高优先级）

**默认行为**：每个环节输出完毕后，必须严格执行以下操作：

1. **输出环节完成标识**：`✅ 【环节：xxx】已完成`
2. **输出交付物**：展示本环节生成的文件/图片
3. **输出确认选项**：提示用户选择下一步操作
4. **输出停止词**：`【停止生成，等待用户确认】`
5. **立即停止生成**：等待用户回复

**停止词（强制输出）**：
```
【停止生成，等待用户确认】
```

**用户确认选项**：
- 用户回复 `1` 或 `确认` → 进入下一环节（单步模式）
- 用户回复 `2` 或 `全自动化运行` → 启用全自动化模式，后续环节自动运行

**禁止行为**：
- 禁止在没有用户确认的情况下自动输出下一环节内容
- 禁止遗漏停止词
- 禁止假设用户已确认

**全自动化模式例外**：
- **触发条件**：用户回复"2"或"全自动化运行"，或初始输入包含"全自动化运行"、"后续无需确认"等明确指令
- 启用后：跳过逐环节确认，自动推进

## 核心规则

### 执行约束
1. **一页一图**：一个Prompt = 一张完整绘本插画，禁止拆分
2. **文字上图**：每页必须在画面内渲染文字，且文字清晰可读
3. **中文双引号**：所有文字内容必须使用中文双引号 `""`
4. **禁止仿真人**：角色形象照必须为绘画/插画风格
5. **受众适配**：文案风格必须与目标受众匹配
6. **提示词原样使用**：禁止简化、删减、修改提示词
7. **禁止并行生图**：按顺序逐张生成

### 动作-道具-空间一致性
1. 道具追踪：明确谁拿、拿几件、另一件在哪里
2. 肢体追踪：明确左右手分别做什么，禁止"三只手"谬误
3. 空间合理性：互动动作必须考虑两人的空间距离与体势
4. 文案-画面对齐：画面描述与文字内容必须描述同一时刻

## 核心流程规范
本技能分为多个环节，每个环节严格遵循「输入自检 → 任务处理 → 输出自检 → 用户确认 → 记忆流转」的标准子流程。

1. **流程输入与自检**
   - **输入物**：[必选] 用户输入的短文内容（50-5000字）
   - **自检规则**：
     - 检查是否获取用户短文？若无，提示输入
     - 检查字数是否在50-5000字之间？若否，提示调整

2. **任务处理**
   - **步骤1：受众识别**：
     - 若用户已指定受众 → 直接使用
     - 若用户未指定 → 根据内容特征分析推断受众
   - **步骤2：合规性检测**：执行敏感词、违规场景检测
   - **步骤3：叙事合理性检测**：
     - 文本篇幅是否充足
     - 逻辑是否连贯
     - 角色是否有基础描述
     - 是否具有叙事性
     - 画面可展示性
     - 对话密度是否合理
     - 场景切换是否流畅
   - **步骤4：文档生成**：创建《短文.md》，包含短文正文、受众分析结果、检测报告

3. **流程输出与自检**
   - **输出物**：《短文.md》
   - **自检标准**：必须包含正文和检测报告；合规检测必须通过

4. **用户确认与反馈**
   - **输出物展示**（用户可见）：
     ```
     ✅ 输出物：
     短文.md
     
     👉 下一环节：角色与风格设定
     
     请选择：
     - 回复 1 或 确认 → 进入下一环节（单步模式）
     - 回复 2 或 全自动化运行 → 确认本次结果并在后续环节自动运行
     
     【停止生成，等待用户确认】
     ```
   - **自检标准**（内部规范，不输出）：必须包含正文和检测报告；合规检测必须通过。
   - **交互形式**（内部规范，不输出）：用户预览《短文.md》。
   - **用户操作**（内部规范，不输出）：确认通过，或手动修改正文。

5. **记忆更新与流转**
   - **记忆操作**：
     - 创建《项目日志.md》

   - **自检标准**（内部规范，不输出）：每个核心角色均有三视图；无破图/多肢体/模糊；形象照字段已更新状态并渲染图片。
   - **交互形式**（内部规范，不输出）：图片预览。
   - **用户操作**（内部规范，不输出）：确认通过，或要求重绘（AI优化Prompt后重试）。

5. **记忆更新与流转**
   - **记忆操作**：
     - 更新《项目日志.md》
     - 写入【环节：角色形象 状态：Done】
     - 写入【角色设定表引用路径】
     - **特别记录**：用户对角色形象的视觉修正点
   - **流转**：解锁【环节：绘本分页脚本规划】


### 【环节：绘本分页脚本规划】
- **示例参考**：见 [examples_appendix.md](references/examples_appendix.md) 的"【环节：绘本分页脚本规划】输出物示例"。

1. **流程输入与自检**
   - **输入物**：《短文.md》、《角色设定表.md》
   - **自检规则**：
     - 检查是否记得短文和角色信息？若不记得，读取《项目日志.md》索引的文件
     - 若文件缺失，跳转至对应环节补充

2. **任务处理**
   - **步骤1：分页拆分**：根据故事长度和情节节点拆分页面
     - 50-200字 → 4-8页
     - 200-500字 → 8-14页
     - 500字以上 → 按情节节点拆分
   - **步骤2：文案风格设定**：根据目标受众确定文案风格
     - 儿童：简单短句、日常词汇、拟声词、动作化表达
     - 青少年：中等复杂度、情感细腻、可保留部分对白
     - 成年人：可接受复杂叙事、抽象概念、含蓄表达
   - **步骤3：页面设计**：为每页规划景别、构图、角色站位、文案等
   - **步骤4：文档生成**：创建《绘本分页脚本规划.md》

3. **流程输出与自检**
   - **输出物**：《绘本分页脚本规划.md》
   - **自检标准**：分页数量合理；每页信息完整；文案风格匹配受众

4. **用户确认与反馈**
   - **输出物展示**（用户可见）：
     ```
     ✅ 输出物：
     绘本分页脚本规划.md
     
     👉 下一环节：绘本提示词工程
     
     请选择：
     - 回复 1 或 确认 → 进入下一环节（单步模式）
     - 回复 2 或 全自动化运行 → 确认本次结果并在后续环节自动运行
     
     【停止生成，等待用户确认】
     ```
   - **自检标准**（内部规范，不输出）：依据 **[storyboard_planning_rules.md](references/storyboard_planning_rules.md)** 中的各项规范和自检清单核对；输出格式遵循标准输出模板。**所有自检结果均不写入输出文档**。
   - **交互形式**（内部规范，不输出）：分页列表预览。
   - **用户操作**（内部规范，不输出）：确认通过，或调整分页内容。

5. **记忆更新与流转**
   - **记忆操作**：
     - 更新《项目日志.md》
     - 写入【环节：分页规划 状态：Done】
     - 写入【绘本分页脚本规划文档引用路径】
     - **特别记录**：用户对叙事节奏的偏好
   - **流转**：解锁【环节：绘本提示词工程】

   - **交互形式**（内部规范，不输出）：提示词预览。

### 【环节：系列绘本图生成】
- **示例参考**：见 [examples_appendix.md](references/examples_appendix.md) 的"【全局记忆】输出物示例"中"【环节：系列绘本图生成】"记录样式。

1. **流程输入与自检**
   - **输入物**：《绘本生图提示词.md》、角色形象照
   - **自检规则**：
     - 检查是否获取提示词文件和形象照？若缺失，跳转至对应环节

2. **任务处理**
   - **步骤1：封面生图**：调用图生图工具生成封面，数量参数为1
   - **步骤2：分页生图**：按顺序逐张生成分页图，禁止并行生成
   - **步骤3：容错处理**：单张失败自动重试2次；连续失败3次标记报错

3. **流程输出与自检**
   - **输出物**：绘本封面图 + 系列绘本页成品
   - **自检标准**：封面包含标题文字；分页数量与提示词一致；文字清晰可读；分辨率达标；无崩坏/花屏
   - **输出展示规范（强制）**：向用户展示系列图文时，必须使用markdown图片组件按顺序罗列渲染，格式如下：
     ```markdown
     ## 绘本封面
     ![封面]({封面图片URL})
     
     ## 系列绘本页成品
     ![第1页]({图片URL})
     ![第2页]({图片URL})
     ```
     禁止仅输出URL链接或文件路径，必须使用 `![描述]({URL})` 语法渲染图片。

4. **用户确认与反馈**
   - **输出物展示**（用户可见）：
     ```
     ✅ 输出物：
     绘本封面图
     系列绘本页成品
     
     👉 下一环节：设计方案生成
     
     请选择：
     - 回复 1 或 确认 → 进入下一环节（单步模式）
     - 回复 2 或 全自动化运行 → 确认本次结果并在后续环节自动运行
     
     【停止生成，等待用户确认】
     ```
   - **自检标准**（内部规范，不输出）：封面包含标题文字；分页数量与提示词一致；文字清晰可读；分辨率达标；无崩坏/花屏。
   - **输出展示规范**（内部规范，不输出）：必须使用markdown图片组件渲染，禁止仅输出URL链接或文件路径。
   - **交互形式**（内部规范，不输出）：画廊预览。
   - **用户操作**（内部规范，不输出）：确认通过，或选择单图重绘。

5. **记忆更新与流转**
   - **记忆操作**：
     - 更新《项目日志.md》
     - 写入【环节：绘本生成 状态：Done】
     - 写入【封面图片URL】
     - 写入【图文成品存储路径】
   - **流转**：解锁【环节：设计方案生成】
