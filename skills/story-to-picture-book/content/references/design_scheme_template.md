# 设计方案模板
设计方案是连载配置文件，用于快速启动同系列绘本生成（文字上图版）。

## 文件命名规范
设计方案文件名：`设计方案_连载复用.md`

## 设计方案格式

```markdown
# 【灵犀绘本图文·设计方案】

## 项目信息
- 项目名称：{系列名称}
- 创建日期：{YYYY-MM-DD}
- 目标受众：{儿童/青少年/成年人/全年龄}
- 文案风格：{根据受众自动适配，如：简单短句/中等复杂/可接受复杂叙事}

## 美术设定

### 通用设定
- 主基调：{风格名称}
- 色板：{颜色名/自然语言描述}、{颜色名/自然语言描述}
- 图片比例：3:4竖版（默认）

### 封面图设定
- 字体风格：{字体描述，如：手写体}
- 字体效果：{效果描述，如：渐变描边}
- 字色：{字体颜色描述，如：米白底深灰字}
- 情绪氛围：{氛围关键词，如：治愈、温馨}
- 主色调：{色调描述，如：暖色}
- 动感元素：{默认动感元素，如：飘落的枫叶、飞扬的发丝}

### 绘本页设定（文字上图版）
- 字体：{字体描述，如：手写体}
- 字号：{统一字号，如：中号/大号}
- 字色：{统一字色，如：深棕/深灰}
- 字色适配规则：默认统一；特殊色调画面以对比度、清晰度、舒适度优先调整
- 线条：{线条风格，如：柔和、圆润}
- 饱和度：{饱和度描述，如：低、鲜艳}
- 背景底色：{背景色，如：柔和浅色/米白}
- 文字留白区：{默认位置，如：画面留白处}
- 文字呈现方式：纯文字直接渲染，无装饰框、无气泡
- 单页文本区：单一文本区，多段文本用行间距分隔
- 兜底策略：背景复杂时叠加轻微半透明浅色底

### 文案风格参数（按受众自动设定）
- 单页字数预算：{儿童12-20字/青少年20-35字/成年人25-45字/全年龄20-35字}
- 单段字数上限：{儿童15字/青少年25字/成年人35字/全年龄28字}
- 拟声词使用：{儿童鼓励/青少年适度/成年人谨慎/全年龄适度}
- 对白处理：{儿童转旁白/青少年可保留部分/成年人可保留完整/全年龄视内容}

## 角色档案

### {角色名}
- 外貌服饰：{简洁描述，包含发型/体型/标志性服饰}
- 参考图：{形象照URL}
- 形象照：![{角色名}_形象照]({形象照URL})

### {角色名2}
- 外貌服饰：{描述}
- 参考图：{URL}
- 形象照：![{角色名2}_形象照]({URL})

## 连载复用说明
1. 开启新对话，上传该文档；
2. 输入提示词（示例）
```
使用该设计方案，将以下故事生成系列绘本，严格遵循技能流程和规范执行，全自动化模式。

XXX（故事）
```
3. 系统将自动复用目标受众设定与文案风格参数
```
