# 角色设计指导


## 1. 角色基础人设核心要素
每个角色必须包含：
- **基础信息**（姓名、年龄、性别、身高体型）
- **外貌特征**（发型、五官、肤色、标志性特征）
- **性格特质**（+1-2个神态习惯）
- **穿搭规范**（上衣、下装、鞋子、配饰），且穿搭贴合主设计风格。


## 2. 角色生图提示词规范
- **完整性**：包含“角色人设、主设计风格、画面规范、禁止元素、核心情绪”5大核心部分；
- **精准性**：描述具体，避免模糊（如“齐肩黑色卷发”而非“长发”）；
- **统一性**：同系列提示词的风格、画面规范、禁止元素完全一致，仅调整情绪/动作。


## 3. 角色生图提示词标准化模板

### 3.1 角色形象照专用模板
此模板专用于生成**【环节：角色形象照生成】**的全身三视图形象照，严禁用于后续绘本生成。

**⚠️ 图片比例强制要求**：角色形象照必须使用 **4:3** 比例（横版），生图模型必须严格遵守此比例，不得擅自修改。

**⚠️ 核心指令**：生成1张角色形象照，包含正面、侧面、背面的全身三视图，三个视角在同一张图中并排展示。

```markdown
生成1张角色形象照，包含正面、侧面、背面的全身三视图，三个视角在同一张图中并排展示。
{主设计风格描述：如日系动漫风格, 粗线条, 鲜艳色彩}，白底，全身站立。中性表情，双手自然下垂，看向观众，三视图并排展示。图片比例4:3，分辨率2K。

角色描述：{核心人设描述：年龄+性别+发型+发色+五官+体型}；{核心穿搭描述：上衣+下装+鞋子+配饰}。

负面提示词：文本, 水印, logo, 糟糕的解剖结构, 肢体缺失, 多余肢体, 畸形, 模糊, 低质量, 裁剪, 最差质量, 丑陋, 变异, 竖版构图, 纵向排版, 3:4比例, 仿真人, 真人照片, 写实人物, 真实人脸, 照片级渲染。
```

**说明**：
- **三段式结构**：第一段（核心指令+风格约束+画面规范+生图参数）→ 第二段（角色描述）→ 第三段（负面提示词）
- **角色描述**：人设与穿搭用分号分隔，便于不同角色替换
- **禁止仿真人**：负面提示词必须包含"仿真人, 真人照片, 写实人物, 真实人脸, 照片级渲染"
- 角色形象照统一使用 **4:3 横版比例**，适合在横向画布上并排展示全身三视图


## 4. 角色形象照生成要求

### ⚠️ 核心原则（必须遵守）
- **一个Prompt = 一张角色形象照（含正面、侧面、背面三视图）**：生图模型必须将三视图合并到同一张图中，**禁止**生成3张独立的图片。
- **三视图并排展示**：正面、侧面、背面三个视角在一张横向图片中并排呈现，形成完整的角色设定图。

### 生图工具与参数
- **生图工具**：文生图工具(text_to_images)；
- **画面内容**：角色3面全身照，无场景/多余元素，清晰展示外貌/穿搭/标志性特征；
- **数量限制**：**图片数量参数固定为1**，确保生图模型只生成一张图片；
- **生图参数**：2K分辨率，**图片比例强制为 4:3（横版）**，高清模式，细节拉满，无模糊/虚化。
- **⚠️ 风格限制（禁止仿真人）**：角色形象照必须为**绘画/插画/漫画风格**，禁止生成仿真人/真人照片风格。原因：仿真人形象在部分社媒平台被禁止，且不符合漫画创作定位。
- **生图标准限制（防破图/防干扰）**：
  - **背景限制**：强制白色背景，禁止任何场景元素；
  - **构图限制**：全身完整展示，人物居中，禁止裁切头部/脚部；
  - **姿态限制**：自然站立，正面/侧面/背面并排展示，禁止大幅度动作或遮挡面部；
  - **比例限制**：强制 4:3 横版比例，禁止竖版构图；
  - **负面提示词**：文本, 水印, logo, 糟糕的解剖结构, 肢体缺失, 多余肢体, 畸形, 模糊, 低质量, 裁剪, 最差质量, 丑陋, 变异, 竖版构图, 纵向排版, **仿真人, 真人照片, 写实人物, 真实人脸, 照片级渲染**。
