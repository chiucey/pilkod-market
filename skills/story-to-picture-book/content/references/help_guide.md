# 灵犀绘本图文 · 使用指南

## 标准模式
```
以下故事生成系列绘本，目标受众为{目标群体}，全自动化运行（可选，不输入默认为逐环节确认模式）。

{故事内容}
```

**参数说明**：
- **目标受众**：儿童 / 青少年 / 成年人 / 全年龄（可选，不填写则自动分析）
- **全自动化运行**：可选，不输入则默认为逐环节确认模式

**示例**：
```
以下故事生成系列绘本，目标受众为成年人，全自动化运行。

《晚风与热可可》
深秋的傍晚，晚风裹着细碎的凉意，吹乱了林晚的刘海...
```

## 灵感模式
提供主题或灵感，由AI扩展为完整绘本故事：
```
主题"{主题内容}"，生成系列绘本，目标受众为{目标群体}。
```

**示例**：
```
主题"允许一切发生"，生成系列绘本，目标受众为成年人。
```

## 连载复用模式
上传设计方案文件后，系统自动复用设计风格、角色形象照和受众设定：
```
[上传设计方案_连载复用.md]

使用该设计方案，将以下故事生成系列绘本：

《最后一班地铁》
城市再大，总有人在终点等你...
```
