# 短文检测与优化规则

## 1. 合规检测规则
- **过滤内容**：敏感词、违规场景、不良导向内容，检测到则终止流程，提示用户修改后重新输入；
- **检测范围**：仅覆盖用户原始短文，不涉及AI优化文本（若用户选择自动优化，需同步检测优化后文本）。

## 2. 受众分析规则

### 2.1 受众识别逻辑
**优先级顺序**：
1. 用户明确指定 → 直接使用
2. 用户未指定 → AI根据内容特征分析推断 → 向用户确认

### 2.2 受众分类定义

| 受众群体 | 年龄范围 | 内容特征 |
|---------|---------|---------|
| 儿童 | 3-12岁 | 简单句式、拟人化角色、童话元素、教育意义、正向结局 |
| 青少年 | 12-18岁 | 校园题材、成长困惑、青春期情感、自我探索 |
| 成年人 | 18岁+ | 职场压力、情感关系、人生思考、社会议题、复杂叙事 |
| 全年龄 | 不限 | 无明显年龄特征、普世主题、家庭共读 |

### 2.3 受众分析维度

AI需从以下维度综合判断目标受众：

| 分析维度 | 儿童 | 青少年 | 成年人 |
|---------|------|--------|--------|
| **句式复杂度** | 简单短句为主 | 中等复杂度 | 可接受复杂长句 |
| **词汇特点** | 日常词汇、拟声词 | 流行语、情感词 | 抽象概念、隐喻 |
| **主题内容** | 冒险、友谊、成长 | 校园、恋爱、自我认同 | 职场、婚姻、人生哲理 |
| **角色设定** | 拟人化动物、儿童主角 | 学生、同龄人 | 成年人、职场人 |
| **情感表达** | 外显、动作化 | 细腻、内敛 | 深沉、含蓄 |
| **冲突类型** | 外部冲突为主 | 内外部冲突并存 | 内心冲突、社会冲突 |
| **结局导向** | 正向、教育意义 | 开放、思考性 | 可接受悲剧、现实性 |

### 2.4 受众分析示例

**示例1：儿童内容**
```
原文：小兔子白白在森林里迷路了，它害怕地哭了起来。这时，一只小鸟飞过来说："别怕，我带你回家。"

分析：
- 句式：简单短句
- 角色：拟人化动物（小兔子、小鸟）
- 主题：迷路与帮助
- 冲突：外部冲突（迷路）
- 结局：正向（得到帮助）

推断受众：儿童（3-12岁）
```

**示例2：青少年内容**
```
原文：教室后排的座位总是空的，直到转学生林浅出现。她安静地坐在那里，像一道解不开的谜题。陈默发现自己开始频繁回头，却说不清为什么。

分析：
- 句式：中等复杂度，含比喻
- 角色：学生（林浅、陈默）
- 主题：校园、暗恋、自我探索
- 情感：细腻、内敛
- 冲突：内心困惑

推断受众：青少年（12-18岁）
```

**示例3：成年人内容**
```
原文：凌晨三点的写字楼，只有她工位上的灯还亮着。三十五岁，未婚，没有存款，工作随时可能被年轻人取代。她盯着屏幕上的PPT，突然不知道这一切有什么意义。

分析：
- 句式：复杂句式，含时间状语和内心独白
- 角色：职场人，明确年龄
- 主题：职场压力、中年危机、人生意义
- 情感：深沉、焦虑
- 冲突：内心冲突、社会压力

推断受众：成年人（18岁+）
```

### 2.5 受众确认机制

**输出格式**：
```markdown
# 检测报告

## 1. 受众分析
- **用户指定**：{已指定/未指定}
- **分析结果**：{儿童/青少年/成年人/全年龄}
- **判断依据**：{从哪些维度判断}
- **确认状态**：{待确认/已确认}

## 2. 合规性检测
...
```

**确认话术**：
- 若AI推断受众，需向用户确认："根据内容特征分析，建议目标受众为【X】，是否正确？如需调整请告知。"

## 3. 叙事合理性检测规则（核心：仅输出问题+建议，不自动优化）
- **文本过短（<50字）**：
  - 标注问题："文本篇幅过短，可能导致绘本分页拆分不完整"
  - 建议："补充过渡情节/角色动作/场景细节（不新增核心内容）"
- **逻辑断裂**：
  - 标注问题："XX段落/语句存在逻辑断层，叙事不连贯"
  - 建议："补充XX过渡语句/情节，衔接XX内容"
- **角色模糊**：
  - 标注问题："XX角色仅提及名称，无外貌/性格/动作特征描述"
  - 建议："补充贴合短文场景的基础外貌（如齐肩黑发、休闲卫衣）/性格特征（如活泼、内敛）"
- **无叙事性文本**：
  - 标注问题："文本无故事化情节（如纯说明/罗列类内容）"
  - 建议："调整为故事化表达（如补充角色、场景、情节冲突）"或"确认是否转换为故事化形式"。
- **画面可展示性差**：
  - 标注问题："XX段落为纯心理活动/抽象概念，难以转化为具体画面"
  - 建议："将心理活动转化为具象动作（如'他很焦虑'->'他来回踱步，眉头紧锁'）或添加旁白"；
- **对话密度过高**：
  - 标注问题："XX场景对话超过5轮，容易导致单页文字密度过高"
  - 建议："精简非必要对话，或将对话拆分到多个页面/场景"；
- **对白承载关键信息**：
  - 标注问题："对白中包含关键因果/承诺/决定（如'我们一起改'、'明天一定…'），若改为旁白或压缩页数可能导致叙事跳跃"
  - 建议："将关键信息改写为叙述旁白保留含义，并增加分页承接信息密度（优先增页而非加长单页文字）"
- **场景跳跃过快**：
  - 标注问题："XX与XX之间场景切换突兀"
  - 建议："补充转场过渡（如'第二天'、'转眼间'）或拆分为独立章节"。

## 4. 提示与预览生成规则
### 4.1 问题标注
AI输出检测结果时，用「【检测问题】」标注待优化点，用「【修改建议】」给出具体方向。

### 4.2 优化建议文本（Preview）生成逻辑
若用户选择查看优化建议，AI需执行以下逻辑生成预览文本：
1.  **保持原意**：核心情节、人物关系、对话内容不得删减。
2.  **定向修补**：仅针对上述检测出的问题（如"心理活动抽象"、"场景缺失"）进行针对性扩写或润色。
3.  **格式统一**：生成的文本需保持与原文一致的段落结构。
4.  **标注变化**：在预览文本中，修改/新增的部分建议使用 *斜体* 或 **加粗** 标注，方便用户对比。
