# 绘本生成规范（文字上图版）

> 本规范用于【环节：系列绘本图生成】，指导如何从《绘本生图提示词.md》提取内容并调用图生图工具（image_to_images）。

---

## 1. 一页一图强制规则（最高优先级）

### ⛔ 核心原则
**一个Prompt = 一张完整绘本插画（包含文字上图）**

每次调用生图工具只生成**1张**图片；每张图片对应**1页绘本**（或封面），禁止把同一页拆成多张独立图片生成。

---

### ❌ 错误做法（严重违规）
**问题**：第1页被拆成3次调用，生成3张“半页图”

```
错误调用：
第1次调用 → 生成图1（只画背景）
第2次调用 → 生成图2（只画人物）
第3次调用 → 生成图3（只画文字区）

结果：1页内容 = 3张图 ❌
```

---

### ✅ 正确做法
**要求**：第1页生成1张完整绘本插画（含文字内容）

```
正确调用：
第1次调用 → 生成图1（完整一页：画面+文字内容）

结果：1页内容 = 1张图 ✅
```

---

### 📋 生图前自检清单（强制执行）
在每次调用生图工具前，必须逐项确认：

| 序号 | 检查项 | 通过标准 |
|------|--------|----------|
| 1 | Prompt格式 | 必须包含“生成1张绘本插画/绘本封面插画” |
| 2 | 生图数量参数 | 必须为 `1` |
| 3 | 画面内容 | 必须包含【画面内容】板块 |
| 4 | 文字内容 | 必须包含【文字内容】板块 |

若任何一项不符合，禁止调用生图工具，需返回提示词工程环节修正。

---

## 2. 提示词强制使用规则（最高优先级）

### ⛔ 核心原则

**必须原样使用《绘本生图提示词.md》中的完整Prompt，禁止任何形式的修改、简化、删减。**

---

### ❌ 禁止行为（严重违规）

| 禁止行为 | 错误示例 | 后果 |
|---------|---------|------|
| 简化提示词 | 删除【画面内容】部分 | 画面结构丢失 |
| 删减页面内容 | 删掉关键动作/场景/文字内容 | 叙事不完整 |
| 修改角色定义 | 更改 `@角色名 = 参考图X` | 角色锁定错误 |
| 省略风格约束 | 只保留核心指令 | 风格不一致 |
| 自行重写提示词 | 用自己的话重新描述 | 丢失专业配置 |
| 仅使用部分提示词 | 只取画面内容，丢弃其他模块 | 画面质量下降 |

---

### ✅ 正确做法

**必须完整提取并原样传入以下全部内容：**

```
【核心指令】生成1张绘本插画，竖排布局。

【风格约束】
画风: xxx| 饱和度: xxx | 色调: xxx
画面质感: 细腻笔触, 高清细节, 清晰边缘, 柔和光影过渡
图片比例: 3:4竖版

【角色定义】
@角色名1 = 参考图1
@角色名2 = 参考图2

【画面内容】
画面: xxx

【文字内容】
位置: {AI根据画面构图规划的具体留白位置}，不遮挡{具体画面元素}
内容: "内容"
字体: 字体风格
字号: 精致小字
字色: 字体颜色
呈现: 文字直接绘制在插画画面肌理上，无任何背景底色，无文本框，无白底，与场景光影色调完全融合，文字边缘柔和融入画面，无独立文字区块，无图文分割，文字横排书写，文字不遮挡画面主体，文字不渲染在道具或纸张上

```

**全部5个模块必须完整传入，缺一不可。**

---

### 📋 提示词提取自检清单（强制执行）

**在每次调用生图工具前，必须逐项确认：**

| 序号 | 检查项 | 通过标准 |
|------|--------|----------|
| 1 | 核心指令 | 完整提取，包含“生成1张绘本插画” |
| 2 | 风格约束 | 完整提取所有风格参数（画风/饱和度/色调/画面质感） |
| 3 | 角色定义 | 完整提取所有 `@角色名 = 参考图X` |
| 4 | 画面内容 | 完整提取【画面内容】板块 |
| 5 | 文字内容 | 完整提取【文字内容】板块 |
| 6 | 无修改确认 | 确认未对原文做任何修改/简化/删减 |

**若任何一项不符合，禁止调用生图工具，需重新提取完整提示词。**

---

### ⚠️ 严重后果

**自行简化提示词会导致：**

- 🔴 **画面结构错误**：【文字内容】板块被删除，文字呈现方式缺失
- 🔴 **角色形象错误**：角色定义被修改，角色特征丢失
- 🔴 **风格不一致**：风格约束被省略，系列图风格跳跃
- 🔴 **叙事不完整**：页面内容/文字内容被删减，情节缺失
- 🔴 **专业度下降**：提示词工程环节的工作白费

---

## 3. 从提示词文件提取关键参数

《绘本生图提示词.md》的结构如下，需提取对应内容：

| 提示词文件内容 | 用途 |
|---------------|------|
| 【参考图数组】 | 角色参考图，传入图生图工具的参考图参数 |
| **Prompt** 块内容 | 完整的生图提示词，传入图生图工具的提示词参数 |
| （固定负面词） | 负面提示词，传入图生图工具的负面词参数 |

### 3.1 提取参考图数组
```markdown
【参考图数组】
```
["URL1", "URL2", "URL3"]
```
```
提取 JSON 数组内的图片URL列表，作为角色参考图传入图生图工具。

### 3.2 提取 Prompt
```markdown
**Prompt（用于生成一张完整的绘本插画）:**
```
【核心指令】...
【风格约束】...
【角色定义】...
【画面内容】...
```
```
提取代码块内的完整内容，作为生图提示词传入。

## 4. 图生图工具调用规范

### 4.1 参数配置要求

| 参数 | 要求 | 说明 |
|------|------|------|
| 参考图 | 从提示词文件提取 | 角色形象照URL数组 |
| 提示词 | 从提示词文件提取 | 完整的生图提示词 |
| 负面提示词 | 固定内容（见下方） | 禁止与正向提示词混用 |
| 生成数量 | 1张 | 每次仅生成1张图 |
| 参考图权重 | 0.7-0.85 | 保障角色特征不混淆 |

### 4.2 负面提示词（强制使用）

**⚠️ 重要：负面提示词作为独立参数传入图生图工具，禁止添加到正向提示词中。**

```
文字过大，大号字体，巨大文字，文字遮挡画面，文字遮挡人物，文字叠加在角色身上，文字居中叠加，文字渲染在纸张上，文字在文件上，竖排文字，vertical text，文字白底，白色文本框，独立文字块，图文分割，分割线，边框，卷边，装饰框，色块背景，文字阴影过重，模糊文字，杂乱字体，高饱和，噪点，低清，边缘模糊，人物变形，水印, logo, 糟糕的解剖结构, 肢体缺失, 多余肢体, 畸形, 模糊, 低质量, 裁剪, 最差质量, 丑陋, 变异, 风格不一致, 更换衣服, 对话气泡, 箭头, 角标, 指向标, 对话气泡尾部, 带箭头文本框
```

### 4.3 参考图权重说明

参考图权重用于控制生成图片与角色形象照的相似程度：

- **范围**：0.7-0.85
- **作用**：权重越高，生成图片越接近参考图的角色特征
- **风险**：权重低于0.7可能导致角色特征互串（如角色A的发型被角色B覆盖）

---

## 5. 生图执行规则

### 5.1 按顺序逐张生成
- 必须等待当前图片生成完成并确认成功后，再开始下一张
- **禁止并行或批量生成**

### 5.2 生成顺序
1. 封面图（使用封面Prompt）
2. 第1页（使用第1页Prompt）
3. 第2页（使用第2页Prompt）
4. ...依次类推

### 5.3 失败处理
- 单张失败：自动重试2次
- 连续失败3次：标记报错，提示用户处理方案
