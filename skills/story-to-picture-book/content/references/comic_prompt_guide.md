# 绘本文生图提示词指导（文字上图版）

## 0. 输出自检（硬性）

- 交付给用户的《绘本生图提示词.md》必须是"可直接复制使用"的成品文本，不得出现未替换的模板占位符。
- 禁止出现的典型占位符（示例）：`角色名`、`页面类型`、`景别/镜头`、`构图要点`、`微场景`、`文字内容`、`主设计风格描述` 等模板字段名。
- 参考图就绪闸门：执行页面提示词生成前，必须已获取核心角色参考图。参考图来源允许为"本技能生成的角色三视图"或"用户上传并指明角色归属的参考图"。否则禁止生成页面提示词。

### ⚠️ 中文双引号强制规范（最高优先级）

- **强制要求**：所有需要画面渲染的文字内容（主标题、吸引语、旁白、音效/拟声词）**必须**使用**中文双引号**
- **中文双引号**：左引号 `“` (U+201C)，右引号 `”` (U+201D)
- **允许场景（仅此一种）**：当旁白中需要嵌入一句对白时，允许在中文双引号内部使用英文双引号 `"` (U+0022) 标注对白，例如：`内容: “身后传来熟悉的声音："风这么大。"”`
- **禁止使用**：英文双引号 `"` 作为文字内容/标题/吸引语的最外层引号；转义引号 `\"\"`
- **错误示例**：`主标题: "晚风与热可可"` ← 英文引号，生图模型无法正确识别
- **正确示例**：`主标题: “晚风与热可可”` ← 中文引号，确保正确渲染
- **原因**：中文双引号确保生图模型准确识别并渲染文字内容，英文引号会导致文字渲染失败或乱码

### ⚠️ 引号格式自检清单（输出前必查）

> **通用规则**：所有自检清单的执行过程/结果均属内部运行信息，不得写入输出文档。

**在输出《绘本生图提示词.md》前，必须执行以下检查：**

| 检查项 | 检查方法 | 通过标准 |
|--------|----------|----------|
| 1. 扫描英文双引号使用 | 搜索 `"` 英文双引号 | 仅用于中文双引号内部的“夹叙夹引”对白，且成对出现 |
| 2. 确认引号方向 | 检查引号是否为 `“` `”` 成对出现 | 左引号`“` + 右引号`”` |
| 3. 检查封面提示词 | 主标题、吸引语的引号 | 均为中文双引号 |
| 4. 检查分页提示词 | 所有文字内容的引号 | 均为中文双引号 |

**如果发现英文双引号使用不符合上述“允许场景”，必须执行修正：**

```
错误修正对照表：
外层 "  →  “  （英文左引号 → 中文左引号）
外层 "  →  ”  （英文右引号 → 中文右引号）
```

**批量修正方法（AI执行）：**
1. 若英文双引号被用作外层引号：替换为中文双引号 `“”`
2. 若英文双引号用于夹叙夹引对白：保留，但必须成对出现且位于中文双引号内部

**禁止输出的情况：**
- ❌ 标题/吸引语/文字内容外层使用英文双引号 `"`
- ❌ 引号不成对（只有左引号或只有右引号）
- ❌ 引号方向错误（如两个都是左引号 `““`）

### ⚠️ 格式红线（禁止触碰）

- **【角色定义】块是生图提示词的必要组成部分，禁止剥离**
  - 错误做法：将"角色定义"单独成段，与"生图提示词"分离展示
  - 正确做法：【角色定义】块必须作为每页提示词的一部分，与后续内容连续构成完整的Prompt
- **禁止出现独立的"角色定义"标题段落**
  - 错误示例：
    ```
    角色定义
    图1 林晚...
    
    生图提示词
    (最佳质量, 4k, 8k)...
    ```
  - 正确示例：
    ```
    【核心指令】生成1张绘本插画，竖排布局。
    
    【风格约束】
    画风: 主设计风格| 饱和度: 描述 | 色调: 描述
    
    【角色定义】
    @林晚 = 参考图1
    @苏冉 = 参考图2
    
    【画面内容】...
    ```
- **禁止使用错误的引号格式**
  - 错误示例：`内容: "\"晚风裹着细碎的凉意...\""` ← 转义引号
  - 正确示例：`内容: “晚风裹着细碎的凉意...” | 字体: 字体风格 | 字号: 中等大小 | 字色: 字体颜色` ← 中文双引号（左“右”）
- **每个页面的提示词必须是一个完整、连续的整体**，包含：核心指令 → 风格约束 → 角色定义 → 画面内容

# 板块一：绘本封面提示词规范

> **执行顺序**：封面提示词优先于分页提示词生成，统一输出到《绘本生图提示词.md》文件。

## 1. 封面提示词结构

封面提示词包含以下模块：

| 模块 | 说明 | 优先级 |

| 【核心指令】 | 声明生图数量、类型、布局方式、视觉目标 | ⭐⭐⭐⭐⭐ 最高 |

## 3. 封面提示词撰写规则

### 3.1 主标题处理规则
- **标题来源**：使用短文的原始标题
- **艺术化设计**：标题文字与主题元素融合（如飘落的花瓣环绕、蒸汽升腾效果）
- **关键词强调**：识别标题中的关键词，做放大/变色/描边/发光等视觉效果
- **示例**：
  - 标题：“晚风与热可可” → 关键词：“晚风”、“热可可”
  - 艺术化设计：标题文字由飘落的枫叶环绕，“热可可”三字带有蒸汽升腾效果

### 3.2 吸引语生成规则（核心）
- **来源**：AI从故事中提取的情感金句，一句话打动读者
- **生成原则**：
  - 传递故事核心情感或主题
  - 简洁有力，具有传播性
  - 引发读者共鸣或好奇
- **示例**：
  - 故事《晚风与热可可》→ 吸引语：“那些陪你喝热可可的人，才是最温暖的治愈”
  - 故事《最后一班地铁》→ 吸引语：“城市再大，总有人在终点等你”

### 3.3 角色呈现规则
- **数量**：选择1-2个核心角色
- **参考图**：使用【环节：角色形象照生成】中已生成的形象照
- **姿态要求**：动态姿态，与标题形成视觉关系（如仰望标题、伸手触碰标题）
- **情绪表达**：表情需传递故事核心情绪

### 3.4 场景氛围规则
- **背景**：延续绘本故事氛围的场景描述
- **光影**：必须有明确的光影效果（如逆光、侧光、聚光灯）
- **动感元素**：必须有动感元素（飘落的花瓣/飞扬的发丝/流动的光线/升腾的热气）

### 3.5 风格延续规则
- **画风一致**：封面必须延续绘本正文页的主设计风格
- **字体统一**：使用与正文页相同的字体风格
- **色调协调**：色调与正文页保持一致或呼应

### 3.6 中文双引号规范（强制）
- 主标题、吸引语必须使用**中文双引号** `“”` 包裹
- **禁止使用**英文双引号 `""`
- 示例：`主标题: “晚风与热可可”` ✅ 正确

# 板块二：绘本分页生图提示词规范（文字上图版）

> **执行顺序**：分页提示词在封面提示词之后生成，统一输出到《绘本生图提示词.md》文件。

## 1. 分页提示词结构

分页提示词包含以下模块：

| 模块 | 说明 | 优先级 |
|------|------|--------|
| 【核心指令】 | 声明生图数量、布局方式 | ⭐⭐⭐⭐⭐ 最高 |
| 【风格约束】 | 画风、饱和度、色调等风格参数 | ⭐⭐⭐⭐ 高 |
| 【角色定义】 | 角色与参考图的映射关系，使用 `@角色名` 引用 | ⭐⭐⭐ 中高 |
| 【画面内容】 | 本页画面与文字内容的具体内容 | ⭐⭐⭐⭐ 高 |

## 2. 分页提示词核心撰写规范

需满足**完整性、精准性、一致性、适配性**，包含上述5大模块，缺一不可。

### ⚠️ 核心原则（必须遵守）
- **一页一图**：一个Prompt = 一张完整绘本插画（不分格、不做多分镜）。
- **文字上图**：每页必须在画面内渲染文字，且文字清晰可读。
- **版式优先**：先解决文字留白区与构图留白，再写画面细节，避免文字压脸、压关键道具。
- **文字内容数量**：单页默认1块，最多2块；优先使用“留白文字区”或“留白文字区”，禁止气泡尾巴与箭头。

## 2.1 提示词生成流程（AI执行）
1. 读取《绘本分页脚本规划.md》，逐页提取：页面类型、情节节点、景别/镜头、构图要点、角色站位、微场景、时间/光影、文案、道具（如有）。
2. 组织每页的 4 模块：核心指令 → 风格约束 → 角色定义 → 画面内容 + 文字内容。
3. 按“画面丰富度最低标准”补齐画面信息：层次、细节、材质、叙事道具，避免抽象形容词堆叠。
4. 写入文字内容：确保中文双引号成对出现，单页文字内容数量与位置合理。
5. 输出前强制自检：占位符清零、中文双引号成对、英文双引号仅用于夹叙夹引内引号、禁用装饰、每页富集达标、动作-道具-文案一致性通过。

## 2.2 一致性闸门（强制）
- **目的**：避免提示词出现“物理不可能/动作与文案冲突/道具数量前后矛盾”，导致模型随机取舍、成图不稳定。
- **执行方式**：每页在输出前必须逐项检查，不通过则回到本页提示词修订。

### 2.2.1 动作可视化
- 文案里出现“说/喊/问/回答/低声开口”等时，画面描述必须加入可视化线索：嘴唇微张/气息/说话姿态/眼神与对方对视。
- 文案里出现“发呆/沉默/失语”等时，避免同页同时出现“说话”语义；需要说话则改成“愣住后开口”并在画面描述体现“先愣住→再开口”的同一瞬间。

### 2.2.2 物理与空间一致性（道具与肢体追踪）
- **道具追踪**：任何“递出/接过/捧着/抱着/放下/拿起”的道具，都必须说明：谁拿、拿几件、另一件在哪里。
- **肢体追踪（防变异）**：明确角色的左手和右手分别在做什么。人类只有两只手，**禁止出现“左手做A，右手做B，同时还在做C”的逻辑谬误**（例如：左手递咖啡，右手拿咖啡，并轻拍肩膀——这需要三只手）。
- **空间合理性**：互动动作必须考虑两人的空间距离与体势。如果两人并排坐着，拍肩膀是合理的；如果两人面对面隔着桌子，拍肩膀可能需要探身。
- **强制检查**：在输出提示词前，AI必须在后台进行“动作模拟自检”：想象自己是该角色，能否仅用两只手、在当前姿态下完成描述的所有动作？如果不成立，必须精简动作（如：改为“左手递出热可可，眼神温柔地看着对方”）。

### 2.2.3 文案-画面对齐（同一瞬间）
- 画面描述与文字内容必须描述同一时刻的动作状态；禁止“画面还没接到杯子，文字却写已接过”。
- 若需要表达先后动作，优先拆页；不拆页则把动作落到“同一瞬间”表达（例如“刚接过/正要接过/愣住后开口”）。

## 3. 角色定义机制

### 【角色定义】块
- **格式**：`@角色名 = 参考图X`
- **示例**：
```
【角色定义】
@林晚 = 参考图1
@苏冉 = 参考图2
```

### 一次性角色处理规则
- **定义**：一次性角色指仅出现在单个场景、后续不再登场的非核心角色
- **处理方式**：无需生成形象照，直接在【画面内容】块中以文本描述刻画角色特征
- **示例**：
```
【画面内容】
画面: 中景 | @林晚 侧身聆听 | 咖啡厅一角 | 午后暖光 | 氛围温馨 | 前景: 咖啡杯冒着热气 | 一位中年女服务员（盘发、围裙、温和笑容）正在递上菜单，只在本场出现
```
- **核心角色 vs 一次性角色**：
  - 核心角色：多次登场 → 生成形象照 → 在【角色定义】块用 `@角色名 = 参考图X` 引用
  - 一次性角色：单场登场 → 不生成形象照 → 在【画面内容】块用纯文本描述特征

### ⚠️ 参考图顺序一致性（关键要求）
- **参考图X与数组的对应关系**：
  - 参考图1 → 参考图数组[0]
  - 参考图2 → 参考图数组[1]
  - 参考图X → 参考图数组[X-1]
- **参考图URL数组组织规则**：
  - 按【角色定义】块中的顺序，将对应角色的形象照URL组织成数组
  - 示例：【角色定义】中有参考图1=林晚、参考图2=苏冉，则参考图数组 = [林晚的形象照URL, 苏冉的形象照URL]
- **每页独立组织**：每张绘本页的参考图数组独立组织，不继承上一页
- **顺序错乱将导致角色错误，这是灾难性错误**

## 4. 构图与文字布局原则

### 4.1 画面留白设计原则
- 画面构图应有留白区域，用于文字渲染，文字与插画融合不分区
- 文字位置灵活：可位于画面中上部、页底、页顶等非主体区域的空白处
- 留白区域要求简洁，无角色面部、无关键道具、无复杂纹理
- 主体元素布局时主动避让留白区域，确保文字清晰可读

### 4.2 文字位置安排
- **位置灵活**：根据画面构图选择合适的空白区域放置文字（不限于页底）
- **位置示例**：
  - 中上部空白：角色间空隙、天空与地面交界处
  - 页底空白：地面、水面、简洁背景
  - 页顶空白：天空、天花板等简洁区域
- **避让原则**：文字不遮挡画面主体（角色面部、动作关键点、叙事道具）

### 4.3 文字呈现规范
- **无装饰原则**：纯文字直接渲染，无装饰框、无背景底色、无气泡、无箭头
- **文字与插画融合**：文字即插画的一部分，不分区呈现，直接位于画面留白区域
- **字色选择**：根据留白区底色选择对比度高的字色（深底浅字/浅底深字）
- **字体统一**：同一绘本系列所有页面使用相同字体、字号

### 4.4 禁止事项
- 禁用装饰框、背景底色、半透明遮罩等任何文字装饰
- 禁用气泡框、对话气泡尾巴、箭头指向等漫画式装饰
- 禁用相框边框、照片边框、卷轴纸、贴纸装饰、复古相纸纹理

## 5. 画面内容描述规范

- **画面描述**：用一句话描述本页核心动作/状态，并补齐“微场景、时间/光影、氛围”。
- **文字内容描述**：用“内容: “内容” | 字体: 字体风格 | 字号: 中等大小 | 字色: 字体颜色”描述。
- **来源约束**：微场景描述必须从【环节：绘本分页脚本规划】输出物中提取，禁止在提示词生成阶段临时编造。

### 5.1 景别与镜头规范（强制）
- **景别定义**：
  - **特写**：聚焦局部（手部、脸部、道具），人物只露出相关部位，背景完全虚化或不可见
  - **中近景**：人物上半身为主体，腰部以上，手部动作清晰
  - **中景**：人物膝盖以上，动作与场景均可见
  - **全景**：人物全身，场景环境完整呈现
  - **远景**：人物较小，场景为主，氛围感强
- **特写镜头强制要求**：
  - 必须明确"只露出{具体部位}"，如"只露出双手和部分手臂"
  - 必须明确"背景完全虚化"或"不出现人物脸部"
  - 禁止特写镜头出现完整人物或大半身人物
- **景别一致性**：画面描述中的景别必须与画面内容严格对应，禁止景别与内容矛盾

### 5.2 角色情绪与表情规范（强制）
- **情绪一致性**：角色表情必须与情节氛围、文字内容保持一致
- **情绪表达方式**：
  - 通过面部表情描述：如"眼角微红"、"嘴角下垂"、"眉头紧锁"
  - 通过肢体动作描述：如"指节发白"、"双肩紧绷"、"握紧拳头"
  - 通过眼神描述：如"眼神黯淡"、"目光低垂"、"眼眶含泪"
- **禁止情绪矛盾**：
  - 错误示例：氛围是"挫败与压抑"，角色却"开心微笑"
  - 错误示例：文字内容表达悲伤，角色却"表情轻松"
- **情绪描述模板**：@角色名 {动作描述}，{表情描述}，表现{情绪关键词}

### 5.3 画面丰富度最低标准（强制）
- **层次**：每页必须明确“前景/中景/背景”的至少两层信息，避免画面像舞台布景一样空。
- **场景细节**：每页至少补充3个可见细节（如玻璃幕墙反光、路灯光晕、落叶堆、纸张边缘、长椅木纹、行人剪影）。
- **材质质感**：每页至少包含2个材质描述（如风衣呢料、纸张纤维、玻璃反射、热可可蒸汽、水汽光斑）。
- **叙事道具**：优先绑定1个叙事道具（如设计稿、热可可杯、笔、路灯），并在画面里显著出现。
- **来源约束**：细节必须从短文/分页脚本/角色设定中提取或合理外推，禁止凭空加“无关装饰”。
  - 叙事道具不可“空白化”：例如设计稿必须可见打印纹理与修改痕迹；手机屏幕必须有界面元素而非纯白块。

## 6. 文字内容规范（强制）

### 6.1 文字双引号规范（最高优先级）
- **强制要求**：所有需要画面渲染的文字（旁白、拟声词）**必须**使用**中文双引号**`“”`包裹。
- **允许场景（仅此一种）**：旁白中嵌入一句对白时，允许在中文双引号内部使用英文双引号 `"` 标注对白（夹叙夹引）。
- **禁止使用**：英文双引号 `"` 作为文字内容/标题/吸引语的最外层引号；转义引号 `\"`。
- **示例**：`内容: “晚风裹着细碎的凉意。” | 字体: 字体风格 | 字号: 中等大小 | 字色: 字体颜色`

### 6.2 文字呈现与可读性规范（行业标准）

#### 6.2.1 无装饰原则（强制）
- **纯文字渲染**：文字直接绘制在画面留白区，无任何装饰
- **无装饰框**：禁止矩形框、圆角框、气泡框等任何形式的边框
- **无背景底色**：禁止半透明底色、纯色底、渐变底等任何背景装饰
- **留白区利用**：利用画面自然的简洁区域放置文字，而非人为添加装饰
- **横排书写**：文字必须横向排列（从左到右），禁止竖排文字

#### 6.2.2 字体统一性（强制）
- **字体统一**：同一绘本系列所有页面使用相同字体
- **字号统一**：同一绘本系列所有页面使用相同字号
- **字色原则**：默认使用统一字色；遇到特殊图片色调时，以对比度、清晰度、舒适度优先，可调整字色确保可读性
- **示例**：暖色调画面用深棕/深灰字；冷色调画面用深蓝/深灰字；深色背景用浅色字

#### 6.2.3 文本区规范（强制）
- **单一文本区**：同一页绘本的所有文字必须在同一个文本区内，禁止出现多个独立的文本区
- **多段处理**：同一页有多段文本时，在同一个文本区内通过适当行间距分隔，保持视觉整体性
- **禁止割裂**：禁止将多段文字分散到画面不同位置，避免视觉割裂感

#### 6.2.4 字号大小规范（强制）
- **字号比例**：文字占画面面积比例应控制在**5%-10%**以内，精致小巧，不抢夺视觉焦点
- **视觉层级**：文字为画面的**辅助叙事元素**，角色与场景始终是视觉主体
- **禁止过大**：文字过大（占画面面积超过15%）会破坏插画美感，形成"字幕感"而非绘本感
- **字号描述**：提示词中统一使用"小字号"或"精致小字"，禁止使用"大字""醒目大字"等描述

#### 6.2.5 文字位置规范（强制）
- **AI规划位置**：文字位置必须由AI根据每页画面构图、角色站位、场景元素**实际规划**，禁止使用模板化固定描述
- **位置规划原则**：
  1. 分析画面构图：识别人物位置、动作方向、场景元素分布
  2. 识别留白区域：找出天空、地面、背景等自然简洁区域
  3. 避开画面主体：确保不遮挡角色脸部、手部动作、关键道具
  4. 具体描述位置：使用精确描述如"画面左上角天空留白处，不遮挡人物与玻璃幕墙反光"
- **禁止遮挡主体**：文字不得遮挡角色脸部、手部动作、关键道具、核心场景元素
- **禁止居中叠加**：禁止文字位于画面正中央叠加在角色身上
- **示例**：
  - ❌ 错误：`位置: 画面留白处（如左上角天空/页底地面/右上角背景简洁处），禁止遮挡角色脸部与关键道具`
  - ✅ 正确：`位置: 画面右上角天空留白处，不遮挡人物与玻璃幕墙反光`

#### 6.2.6 位置与长度
- **位置灵活**：根据画面构图选择合适的空白区域（如中上部/页底/页顶等）
- **长度控制**：单个文字内容建议最多两行，单块文案不超过20字
- **行业参考**：单块建议 12–28 字；上限 36 字。若需要更长文本，优先拆页

### 6.3 文本格式规范
- **旁白（正文形式）**：`内容: “旁白内容” | 字体: 字体风格 | 字号: 中等大小 | 字色: 字体颜色`（第三人称或全知视角；不写“旁白：”前缀）
- **夹叙夹引（可选）**：允许在旁白文本中包含一段对白，写法为 `……：“对白内容”` 或 `“对白内容”……`，用以增强表现力；避免多轮对话。
- **拟声词（可选）**：`拟声词(位置): “拟声内容”`（可独立渲染于画面中，也可放入文字内容）

### 6.4 文本前缀规范
**核心规则**：`@角色名`只用于【角色定义】块；文字内容中禁止使用`@`符号。

| 用法场景 | 格式 | 示例 |
|---------|------|------|
| 【角色定义】块 | `@角色名 = 参考图X` | `@林晚 = 参考图1` |
| 画面描述中的角色引用 | `@角色名` | `@林晚 低头快走` |
| 文字内容中的角色前缀 | 禁止 | 禁止出现`角色名：...`、`角色名(内心)：...` |

### 6.5 文本提取规范（强制）
从绘本分页脚本中提取“文案”字段时，必须完整提取并转换为文字内容/拟声词：

| 分页脚本字段 | 提示词对应格式 | 说明 |
|-------------|---------------|------|
| 旁白内容 | `内容: “内容”` | 直接上图，无任何前缀 |
| 拟声词：内容 | `拟声词(位置): “内容”` | 可选独立渲染 |

**自检标准**：每页的文字内容是否与分页脚本“文案”字段逐条对应？若有遗漏必须补充。

### 6.6 引号嵌套处理规则
- **问题场景**：文字内容中包含需要强调的词汇，导致引号嵌套冲突。
- **处理原则**：文字内容整体使用中文双引号；块内强调词使用《书名号》或省略引号。
- **正确示例**：`内容: “公司瞬间掀起《全能人才》内卷狂潮。” | 字体: 字体风格 | 字号: 中等大小 | 字色: 字体颜色`
 - **对白嵌入建议**：当旁白中嵌入对白时，优先使用英文双引号作为内引号，避免与文字内容外层中文双引号产生嵌套冲突。
 - **示例**：`内容: “身后传来熟悉的声音:"傻站着干嘛？风这么大。"” | 字体: 字体风格 | 字号: 中等大小 | 字色: 字体颜色`

### 6.7 文本拆分规则
- 默认优先使用“一个文字内容 + 换行/断句”表达同一类型文本。
- 仅当同页出现“旁白 + 拟声词（需独立上图）”或“单页文字过长影响可读性”时，才拆分为两段文字内容。

## 8. 绘本分页提示词优化规则
- **系列一致性**：同一角色在相邻页面的发型、服饰、标志性细节保持一致；除非剧情明确要求换装。
- **场景一致性**：同一地点的连续页保持同一光源方向与主色调，避免跳色导致断裂。
- **文字可读性**：文字区背景尽量简洁；必要时增强文字框底色与描边，保证清晰锐利。
- **文字密度**：单页默认1块，最多2块；过长文案拆页，不在同页塞满文字。
