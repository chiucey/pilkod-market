## ⚠️ 核心铁律（2026.06.17 鑫总确认）—— **技术判断必须基于公开数据独立形成**

> **BP 里的"企业自评"一律不信，只看客观参数；企业给的参数要公开市场数据交叉验证；技术判断不收企业 BP 评价影响。**

### 必须遵守的 5 条铁律

1. **企业自评一律不信**——"国内唯一""业内最快""全球领先""独家储备"等营销话术必须用公开数据戳穿
2. **企业给的参数可以参考**——90μm 像素、±2%LFL、T63≤12s 等数字要 **用公开市场 datasheet 交叉验证**
3. **技术判断必须独立形成**——海曼/迈来芯/Sensirion/Amphenol/Infineon/Figaro/四方光电/汉威/敏芯的 datasheet 全部用上
4. **估值跟着公开市场走**——四方光电 PS 5-6x、Sensirion PS 0.6x、汉威 PS 2-3x
5. **叙事泡沫要被戳穿**——BP 自评的"唯一/最快/第一"等所有话术都要列在"叙事戳穿"专章

### 公开数据来源清单

| 类型 | 来源 | 用途 |
|---|---|---|
| 国际 Tier 1 datasheet | 海曼（heimannsensor.com）、迈来芯（melexis.com）、Sensirion（sensirion.com）、Amphenol、Infineon、Figaro、TDK、Bosch、ST | 参数对标 + 戳穿"业内最快/国内唯一" |
| 国内对手公开产品页 | 四方光电（gassensor.com.cn）、汉威科技、敏芯股份（memsensing.com）、攀藤科技、苏州敏芯 | 戳穿"国内唯一" + 真实市占率 |
| 财报与市值 | 东方财富、Wind、Bloomberg、Yahoo Finance | 估值锚点（PS/PE） |
| 行业报告 | Yole Group、IDC、Counterpoint、IHS Markit、FMI | 市场规模 + 行业增速 |
| 政策文件 | GB/T 标准、UL Standards、IEC 官网、ASHRAE、EPA | 政策时间表（**比 BP 原文更激进**） |
| 工商档案 | 天眼查、企查查 | 股东结构 + 历史融资 |

### 必查公开数据清单（每份 BP 都要查）

- [ ] 国际 Tier 1 至少 2 家的核心产品 datasheet
- [ ] 国内头部对手（科创板/创业板/港股上市）至少 1 家的产品页 + 财报
- [ ] BP 提到的所有政策标准——查官方原文确认时间表
- [ ] BP 提到的所有"国内唯一/第一"——查公开市场是否有同款产品
- [ ] BP 提到的所有"业内最快/最优"——查公开 datasheet 是否有更好参数
- [ ] 工商档案——查股东结构、实控人、关联企业
- [ ] 财报——查 PS/PE 锚点

## BP 研判 4 段框架（30 分钟内出）

### 1. 赛道 + 切入点

**回答的核心问题**：这是个什么赛道、用什么技术切、卡在产业链哪一环？

**输出字段**：
- **产业链位置**：上游 / 中游 / 下游
- **技术路线**：3 条主流路线对比（基于公开数据，不是 BP 自评）
- **商业本质**：卖什么（器件/模组/整机/平台/数据）
- **目标客户**：B 端（大客户/中小客户/政府） / C 端 / 双边
- **可触达市场 TAM**：用真实可触达（不是行业总规模）× 5% 市占率上限

### 2. 壁垒识别 —— **基于公开数据独立判断**

**回答的核心问题**：是真壁垒还是假壁垒？和国内/国际 Tier 1 的具体参数差异？

**必查 3 个对标**：
1. **国际 Tier 1**：海曼/迈来芯/Sensirion/Amphenol/Infineon/Figaro 等同赛道头部公司
2. **国内跟随者**：科创板/创业板/港股上市的同赛道公司
3. **价格战玩家**：深圳/苏州/上海中小厂（用以判断护城河宽度）

**输出字段**：
- **真壁垒类型**（按强度排序）：
  1. **客户验证壁垒**（已签 Tier 1 独家协议）⭐⭐⭐⭐⭐
  2. **认证壁垒**（UL/IEC/AEC-Q/医疗 FDA 等）⭐⭐⭐⭐
  3. **技术参数壁垒**（像素/精度/响应时间/寿命等具体数字）⭐⭐⭐
  4. **规模/产能壁垒**（Fab 锁定/独家供应）⭐⭐⭐
  5. **专利/IP 壁垒**（数量 + 法律状态）⭐⭐
  6. **创始人/团队壁垒**（院士/海归/连续成功）⭐⭐
- **叙事戳穿专章**（必填）：
  - BP 原文"国内唯一/第一" → 公开市场是否真有同款？是否真是第一？
  - BP 原文"业内最快/最优" → 公开 datasheet 是否有更好参数？
  - BP 原文"独家储备" → 国际 Tier 1 是否已商业化？
- **护城河宽度**：18-24 个月技术窗口期 / 3-5 年认证窗口期 / 5-10 年客户黏性

### 3. 业绩三角

**回答的核心问题**：人/技术/钱闭环了吗？订单可验证吗？

**输出字段**：
- **客户验证**：是否签了 Top 3 客户？是样品/POC/小批量/独家协议哪一阶段？单车价值量？
- **收入质量**：分产品线收入占比、毛利率结构、ASP 趋势、应收账款周转
- **业绩兑现**：收入 CAGR、净利率趋势、亏损收窄速度
- **产业方股东**：美的/海尔/比亚迪/宁德/京东方等产业方是否在股东列表？这是**最稀缺的资源结构**
- **历史融资**：融了几轮、估值变化、上一轮投后估值
- **本轮估值锚点**：按公开市场可比公司 PS/PE 测算，给出合理区间

### 4. 雷点扫描

**回答的核心问题**：缺什么？能不能补？值不值得为这个雷点买单？

**输出字段**：
- **叙事戳穿**（必填，复用第 2 段戳穿清单）
- **信息缺失清单**（BP 没给的字段，按重要性排序）：
  1. 收入/订单/客户名单
  2. 创始团队具名履历
  3. 上一轮估值
  4. 分产品线收入拆分
  5. 财务三表
- **结构性雷点**：
  - 创始人控制权风险
  - 关联交易风险
  - 国际 Tier 1 中国本地化反扑
  - 政策窗口期被截胡
- **执行性雷点**：
  - Fabless 产能锁定
  - 团队完整度（CFO/CSO/销售 VP 缺失）
  - 海外业务合规（出口管制/制裁名单）

## 与"立项检查" skill 的关系

| 流程 | Skill | 触发条件 | 输出 |
|---|---|---|---|
| 第一接触 | **BP 研判（本 skill）** | 鑫总发 BP / "看看这个项目" | 4 段速判 + 拍板选项 |
