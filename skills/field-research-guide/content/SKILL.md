# 田野采风实战向导

本技能为民族音乐田野调查提供系统化指导，帮助研究者高效规划采风行程、规范访谈流程、妥善整理资料。

## 执行流程

### 步骤一：确认采风基本信息

首先明确以下关键信息：

- **采风地点**：具体到县/乡镇/村屯名称
- **目标民族/乐种**：如壮族族嘹歌、侗族大歌、京族民歌、桂剧等
- **预计时间**：采风周期与具体日程安排
- **调研目的**：学术研究、创作素材、非遗记录等

### 步骤二：生成代表性乐种清单

根据目标地区和民族，提供至少5项当地代表性民歌或乐种的详细清单，包括：

- 乐种名称与当地方言称呼
- 基本音乐特征（调式、节拍、旋律特点）
- 典型代表曲目
- 流行区域与传习现状
- 相关非遗项目级别

### 步骤三：提供艺人寻访线索

根据乐种分布与传习情况，给出可寻访的具体地点和人物类型：

- **传统歌圩/歌场地址**：如"三江侗族多耶坪""龙州壮族歌圩遗址"
- **文化站/非遗中心联系方式**：县文化馆、乡镇文化站的地址与联系方式
- **代表性歌师/艺人**：已知的省级/市级非遗传承人名单与所在村屯
- **歌队/乐团信息**：当地活跃的歌队、民间乐团的活动地点与时间

### 步骤四：设计访谈提纲

按照暖场、核心、收尾三段式结构设计访谈问题，并在开头使用当地常用问候语：

- **暖场问题（1-2个）**：建立信任关系，了解艺人基本信息
- **核心问题（3-5个）**：围绕音乐技能、传承经历、歌曲背后的故事展开
- **收尾问题（1-2个）**：表达感谢，了解后续联系意愿

### 步骤五：列出设备清单与参数设置

提供采风所需设备建议及参数配置：

- **录音设备**：专业录音笔或便携录音机的型号推荐与设置参数
- **摄像设备**：摄像机或手机拍摄参数建议
- **辅助设备**：三脚架、指向性麦克风、防风罩等
- **存储与备份**：存储卡容量、备份方案建议

### 步骤六：提醒伦理事项

强调田野调查中的伦理规范：

- **知情同意**：录制前必须获得艺人明确同意，说明用途与署名方式
- **署名方式**：尊重艺人意愿，选择实名、化名或不署名
- **回赠礼物**：准备适当礼物表示感谢，如土特产、纪念品或现金补贴

### 步骤七：提供资料整理模板

给出采风后资料整理的标准模板与格式建议：

- **文件名规范**：日期-地点-艺人名-内容类型的命名规则
- **记谱格式**：五线谱/简谱记录的规范要求
- **采访稿结构**：时间线、事件线、人物线的整理框架

## 输出格式示例

根据用户提供的采风目标，生成以下结构的完整指南：

```
【采风地】：[具体地点名称]

【目标乐种清单】（至少5项，附简短说明）：
1. [乐种名称]：[特征描述与代表曲目]
2. [乐种名称]：[特征描述与代表曲目]
3. [乐种名称]：[特征描述与代表曲目]
4. [乐种名称]：[特征描述与代表曲目]
5. [乐种名称]：[特征描述与代表曲目]

【艺人线索】（可寻访的地点或人物类型）：
• [具体村屯/场所]：[推荐理由与联系方式]
• [文化站/非遗中心]：[地址与服务时间]
• [代表性传承人]：[姓名、村屯、联系方式]

【访谈提纲】
- 暖场（1-2个问题）：
  1. [使用当地问候语开头的问题]
  2. [了解基本信息的问题]

- 核心（3-5个问题）：
  1. [关于音乐技能的问题]
  2. [关于传承经历的问题]
  3. [关于歌曲背景的问题]
  4. [关于生活与音乐关系的问题]
  5. [关于传承困境与期望的问题]

- 收尾（1-2个问题）：
  1. [表达感谢与后续联系意愿的问题]
  2. [了解其他资源或推荐艺人的问题]

【设备清单与设置】：
| 设备类型 | 推荐型号 | 参数设置建议 |
|----------|----------|--------------|
| 录音设备 | [型号] | [采样率/位深建议] |
| 摄像设备 | [型号] | [分辨率/帧率建议] |
| 辅助设备 | [配件名称] | [使用注意事项] |

【伦理提醒】（3条关键提示）：
1. [知情同意的具体要求]
2. [署名方式的规范]
3. [回赠礼物的建议]

【采风后整理模板】（含文件名建议、记谱格式、采访稿整理结构）：
• 文件名格式：[YYYYMMDD]-[地点]-[艺人]-[内容类型]
• 记谱要求：[五线谱/简谱选择]，[调号拍号标注规范]
• 采访稿结构：[时间顺序整理]，[关键事件标记]，[艺人原话引用格式]
```

## 变量占位符

本技能使用以下变量占位符以便用户定制：

- `{采风地点}`：用户指定的具体采风目的地
- `{目标民族}`：用户选择的调研民族
- `{目标乐种}`：用户关注的具体音乐类型
- `{预计天数}`：采风行程的预计天数
- `{调研目的}`：用户的具体调研目的
