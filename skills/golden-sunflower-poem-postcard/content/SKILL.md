# 金葵毕业诗歌明信片生成器

将用户提供的寄语或专业信息，转化为嵌入"金葵"（向日葵）意象的毕业诗歌，并合成到精美明信片背景上。

## 工作流程

### 步骤 1：信息收集

1. **用户寄语/专业信息**（必须）：用户提供的内容，可以是：
   - 直接的毕业寄语/祝福语
   - 毕业生的专业名称（如"人工智能技术专业"）
   - 两者结合

2. **明信片背景**（可选）：
   - 如果用户未提供背景图，自动生成一张金葵主题背景
   - 如果用户提供了自定义背景图，直接使用

### 步骤 2：诗歌生成

根据用户专业信息，创作一首嵌入"金葵"意象的七言或五言律诗/古风诗。

**诗歌结构**：
- 标题：融入"金葵"意象 + 专业元素
- 正文：8句（呼应毕业）
- 落款：致XX专业

**诗歌元素映射**：
- 🌻 金葵/向日葵 → 象征阳光、前程、初心
- 💻 代码/算法 → 理工科/AI专业
- 📚 书卷/笔墨 → 文科专业
- 🔬 实验/研究 → 科研专业
- 🌟 星辰/梦想 → 通用意象

### 步骤 3：明信片合成

1. **生成/获取背景图**
   - 无自定义背景 → 使用 image_synthesize 生成金葵主题背景
   - 有自定义背景 → 使用用户提供的图片

2. **HTML 排版**
   - 创建包含背景图的 HTML 明信片
   - 设置诗歌文本的字体、大小、颜色、位置
   - 添加装饰元素（角框、分隔线、水印）

3. **图片输出**
   - 使用 html_to_pdf 或 image_synthesize 将 HTML 转为最终图片
   - 图片尺寸建议：1200x1600px（3:4竖版）

### 步骤 4：输出交付

- 将最终图片路径返回给用户
- 使用 GenUI 展示图片
- 提供 deliver_assets 块交付

## 技术规范

### 图片尺寸
- 竖版明信片：1200x1600px（3:4比例）
- 横版明信片：1600x1200px（4:3比例）
- 默认使用竖版

### 字体规范
- 标题：56px，棕色（#8B4513）
- 正文：38px，深棕色（#5D4037）
- 落款：32px，金棕色（#8B6914）
- 字间距：4-6px
- 行高：2.2em

### 背景风格
- 水彩画风格
- 暖色调（琥珀、金色、橙色渐变）
- 金葵/向日葵元素
- 复古明信片美学

### 诗歌排版位置
- 垂直居中于背景图
- 左右边距：80-100px
- 与背景图中心对齐

## 错误处理

- 如果 image_synthesize 生成失败，尝试使用预设的纯色/渐变背景
- 如果用户未提供任何信息，使用默认值（如"人工智能技术专业"）
- 始终确保最终输出可交付

## 示例

**输入**：人工智能技术专业毕业生

**输出诗歌**：
```
金葵·AI·毕业赋

金葵万朵向阳开
恰似代码落尘埃
模型深处藏星辰
算法如光照未来
数据流转成诗行
神经网络织锦才
智能征途从此始
金葵之心永不改

——致人工智能技术专业
```

**输出格式**：
- 最终明信片图片（带诗歌排版）
- 直接展示给用户
