## 诗歌模板

### 七言律诗模板（8句）

```
金葵向阳开
恰似XX落尘埃
XX深处藏XX
XX如光照未来
XX流转成诗行
XX织出锦绣才
XX征途从此始
金葵之心永不改
```

### 替换规则
- 第1句：金葵 + 专业意象
- 第2句：恰似 + 专业元素 + 意境
- 第3-6句：4个专业相关的意象对
- 第7句：XX + 动词 + 从此始
- 第8句：金葵之心永不改（固定结尾）

## 毕业场景变体

### 考研上岸
```
金葵向阳开
恰似书卷伴晨昏
题海深处藏星辰
榜上有名照未来
```

### 就业启程
```
金葵向阳开
恰似简历展风采
职场深处藏机遇
offer如光照未来
```

### 继续深造
```
金葵向阳开
恰似文献堆成山
论文深处藏真知
答辩如光照未来
```
