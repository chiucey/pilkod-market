# 数据应用场景挖掘

本技能帮助企业发现已有数据的应用价值，通过网络搜索权威公开案例，提炼框架方法论，为用户输出定制化的数据应用场景建议。

## 工作流程

### 第一步：信息收集与分析

1. **明确用户需求**
   - 了解用户所属行业或业务领域
   - 确认用户拥有的数据类型或希望解决的问题
   - 识别用户的业务目标和痛点

2. **构建搜索策略**
   - 制定关键词组合：行业关键词＋数据应用＋案例
   - 确定权威信息来源：国家数据局、各地数据交易所、行业协会
   - 搜索近期（近1-2年）的典型案例和创新实践

### 第二步：案例搜索与收集

**重点搜索来源**：
- 国家数据局官方网站及政策文件
- 各省市大数据管理局网站
- 数据交易所典型案例库（如上海数据交易所、北京国际大数据交易所）
- 行业白皮书和研究报告
- 权威媒体和行业垂直网站

**搜索示例**：
```
"行业" + "数据要素" + "应用案例" + "国家数据局"
"行业" + "数据资产" + "典型场景" + "优秀案例"
"行业" + "数字化转型" + "数据应用" + "实践"
```

### 第三步：框架提炼与方法论抽象

从收集的案例中提炼共性模式：

**数据应用场景分类框架**：
| 场景类别 | 典型特征 | 适用行业 |
|---------|---------|---------|
| 运营优化 | 流程自动化、效率提升 | 制造、物流、零售 |
| 决策支持 | 数据可视化、预测分析 | 金融、医疗、政府 |
| 产品创新 | 个性化推荐、智能服务 | 电商、互联网、金融 |
| 风险控制 | 信用评估、欺诈检测 | 金融、保险、安全 |
| 监管合规 | 数据治理、隐私保护 | 金融、医疗、教育 |

**数据价值评估维度**：
1. **业务契合度**：与应用场景的匹配程度
2. **实施难度**：技术复杂度和资源需求
3. **价值潜力**：预期收益和投资回报
4. **可落地性**：与企业现有能力的匹配

### 第四步：定制化场景输出

为用户生成结构化的数据应用场景建议：

## 输出模板

### 一、行业背景分析
简要分析目标行业的数字化发展趋势和数据应用现状。

### 二、典型案例参考
列出3-5个权威公开案例，包括：
- 案例名称和来源
- 应用场景描述
- 实施效果和数据类型
- 可借鉴要点

### 三、数据应用场景推荐
针对用户情况推荐5-8个具体场景：

| 场景名称 | 场景描述 | 数据需求 | 预期价值 | 实施建议 |
|---------|---------|---------|---------|---------|
| ... | ... | ... | ... | ... |

### 四、实施路径建议
1. **短期（1-3个月）**：快速见效的场景
2. **中期（3-6个月）**：需要一定数据基础的场景
3. **长期（6-12个月）**：需要系统性建设的场景

### 五、风险与注意事项
- 数据合规和隐私保护要求
- 技术实施风险
- 组织变革挑战

## 质量标准

- 案例来源必须权威可信（政府官网、官方媒体、知名研究机构）
- 场景建议必须具体可操作，避免泛泛而谈
- 必须包含明确的实施建议和价值评估
- 语言简洁专业，适合企业决策层阅读
