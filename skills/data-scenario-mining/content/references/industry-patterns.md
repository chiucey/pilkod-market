# 行业数据应用模式参考

本文档汇总主要行业的数据应用典型场景，供场景推荐时参考。

## 制造业

### 核心数据资产
- 生产设备运行数据（IoT传感器）
- 供应链数据
- 质量检测数据
- 工艺参数数据
- 能源消耗数据

### 典型应用场景
| 场景 | 数据来源 | 价值 |
|------|---------|------|
| 预测性维护 | 设备传感器数据 | 减少停机时间30-50% |
| 质量追溯 | 生产工艺数据 | 质量问题定位效率提升 |
| 供应链优化 | 库存+物流数据 | 降低库存成本20% |
| 能耗优化 | 能源监测数据 | 节能10-15% |
| 工艺优化 | 历史工艺参数 | 良品率提升 |

## 零售业

### 核心数据资产
- 销售交易数据
- 会员数据
- 商品数据
- 门店运营数据
- 线上行为数据

### 典型应用场景
| 场景 | 数据来源 | 价值 |
|------|---------|------|
| 精准营销 | 会员+购买历史 | 营销转化率提升 |
| 智能选品 | 销售+市场数据 | 商品结构优化 |
| 门店选址 | 周边数据 | 开店成功率提升 |
| 库存优化 | 销售预测+库存 | 减少缺货和积压 |
| 价格优化 | 竞品+销售数据 | 利润提升 |

## 通用场景（跨行业）

以下场景在多个行业中均有应用价值：

| 场景 | 适用行业 | 核心价值 |
|------|---------|---------|
| 客户画像分析 | 零售、金融、服务 | 客户洞察 |
| 文本分析挖掘 | 客服、舆情、合规 | 智能化处理 |
| 异常检测 | 制造、金融、安全 | 风险预警 |
| 知识图谱构建 | 制造业、金融、医疗 | 知识管理 |
| 数据可视化 | 所有行业 | 决策支持 |
