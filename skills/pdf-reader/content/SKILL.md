# PDF 读取技能

使用此技能读取、提取和分析 PDF 文件内容。

## 工具选择策略

根据用户需求选择合适的提取工具：

| 需求类型 | 工具选择 | 说明 |
|---------|---------|------|
| 获取关键信息/摘要 | `extract_pdfs_key_info` | 快速提取特定信息，适合筛选和概览 |
| 完整内容理解 | `extract_pdfs_full_content` | 完整提取全文，适合深度分析 |
| 特定页面范围 | 两个工具都支持 `view_range` 参数 | 可指定起始和结束页码 |

## 执行流程

### 1. 确认 PDF 来源

支持两种来源：
- **本地文件**：提供完整文件路径（如 `/workspace/docs/report.pdf`）
- **网络 URL**：提供有效的 HTTPS URL（如 `https://example.com/doc.pdf`）

### 2. 选择提取模式

```
提取模式决策：
├── 用户需要"关键信息"、"摘要"、"重点"？
│   └── 使用 extract_pdfs_key_info
├── 用户需要"完整内容"、"全文"、"详细分析"？
│   └── 使用 extract_pdfs_full_content
└── 用户指定了具体页面？
    └── 添加 view_range: [起始页, 结束页]
```

### 3. 构造提取任务

根据 `extract_pdfs_key_info` 或 `extract_pdfs_full_content` 的参数格式构造任务：

```json
{
  "tasks": [
    {
      "pdf_path": "<文件路径或URL>",
      "prompt": "<用户需求的描述>",
      "view_range": [<起始页>, <结束页>] // 可选
    }
  ]
}
```

### 4. 处理结果

- 将提取结果直接呈现给用户
- 如果是多页文档且未指定范围，可建议用户关注特定页面
- 如提取失败，尝试备用方案或请求用户提供替代文件

## 常见场景示例

| 场景 | prompt 示例 |
|-----|-----------|
| 获取摘要 | "请提取文档的主要内容和核心观点" |
| 提取数据 | "请提取所有关键数据和统计信息" |
| 搜索内容 | "请找出关于 [主题] 的所有相关内容" |
| 完整阅读 | "请完整提取文档的全部内容" |
| 指定页面 | "请提取第 5-10 页的内容" |

## 注意事项

- PDF 文件应不超过合理大小（建议 <100MB）
- 每次最多处理 10 个 PDF 任务
- 完整内容提取单次最多 30 页，超出需分段
- 关键信息提取单次最多 20 页
- 对于扫描版 PDF（无文本层），提取效果可能有限

## 错误处理

| 错误类型 | 处理方式 |
|---------|---------|
| 文件不存在 | 提示用户提供正确路径 |
| 提取超时 | 建议缩小范围或分段提取 |
| 安全检查失败 | 跳过该文件，提示用户 |
| 格式不支持 | 提示用户文件可能已损坏 |
