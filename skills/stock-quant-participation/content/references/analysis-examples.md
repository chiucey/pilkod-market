### 指标计算

#### 1. 资金流向维度
```
超大单净流入率 = (2.5 - 1.8) / 8.5 × 100% = 8.24%
大单净流入率 = (1.2 - 1.5) / 8.5 × 100% = -3.53%
主力资金净流入天数比 = 4/5 × 100% = 80%

维度得分 = 0.6 × 8.24 + 0.2 × (-3.53) + 0.2 × 80 = 4.94 + (-0.71) + 16 = 20.23
归一化得分 = 85/100
```

#### 2. 交易行为维度
```
委托成交比 = 125,000 / 45,000 = 2.78
撤单率 = 8000 / 150000 × 100% = 5.33%
盘口异动 = 280 × 120 / 500 = 67.2

维度得分 = 0.4 × 75 + 0.3 × 85 + 0.3 × 90 = 30 + 25.5 + 27 = 82.5
归一化得分 = 83/100
```

#### 3. 综合评分
```
总评分 = 85×0.25 + 83×0.25 + 75×0.20 + 80×0.20 + 70×0.10
       = 21.25 + 20.75 + 15 + 16 + 7
       = 80.00

参与等级：极高（80-100区间）
```

```

✅ 信号2：5日/10日主力资金净流入天数 > 70%
✅ 信号3：日内振幅收窄，K线稳定性增强
```

```
同时满足3个以上 → 量化资金撤离概率高
```
