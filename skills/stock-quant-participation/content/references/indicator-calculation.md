# 量化资金参与度指标计算详解

## 1. 资金流向指标详细计算

### 1.1 超大单净流入率 (权重: 10%)

```python
# 超大单定义：单笔成交额 >= 100万元
超大单净流入率 = (超大单买入额 - 超大单卖出额) / 成交额 × 100%

# 评级标准
# 极高: > 15%
# 高: 5% - 15%
# 中: -5% - 5%
# 低: -15% - -5%
# 极低: < -15%
```

### 1.2 大单净流入率 (权重: 8%)

```python
# 大单定义：20万元 <= 单笔成交额 < 100万元
大单净流入率 = (大单买入额 - 大单卖出额) / 成交额 × 100%
```

### 1.3 主力资金净流入天数比 (权重: 7%)

```python
# 主力资金定义：超大单 + 大单
统计周期 = 5日 / 10日 / 20日
主力资金净流入天数比 = 主力净流入天数 / 统计周期 × 100%

# 评级标准 (以5日为例)
# 极高: > 80% (5日中4天以上净流入)
# 高: 60% - 80%
# 中: 40% - 60%
# 低: 20% - 40%
# 极低: < 20%
```

## 2. 交易行为指标详细计算

### 2.1 委托成交比 (权重: 10%)

```python
# 买入委托笔数 / 成交笔数
# 异常值检测：正常范围 1.0 - 3.0
委托成交比 = 买入委托笔数 / 成交笔数

# 评级标准
# 极高: > 5.0 (大量委托但少成交，典型量化特征)
# 高: 3.0 - 5.0
# 中: 1.5 - 3.0
# 低: 1.0 - 1.5
# 极低: < 1.0
```

### 2.2 撤单率 (权重: 8%)

```python
# 撤单率 = 撤单金额 / 总委托金额 × 100%
# 需要Level2数据支持

# 评级标准
# 极高: > 30%
# 高: 20% - 30%
# 中: 10% - 20%
# 低: 5% - 10%
# 极低: < 5%
```

### 2.3 盘口异动指数 (权重: 7%)

```python
# 检测盘口挂单撤单的频率和金额变化
# 采样频率：每秒采样
盘口异动指数 = 挂单变化次数 × 平均变化金额 / 基准金额

# 评级标准
# 极高: > 50次/分钟 且 金额变化 > 20%
# 高: 30-50次/分钟
# 中: 10-30次/分钟
# 低: 5-10次/分钟
# 极低: < 5次/分钟
```

## 3. 波动特征指标详细计算

### 3.1 日内振幅稳定性 (权重: 8%)

```python
# 计算方法：分时数据标准差
# 样本：每5分钟采样点
日内振幅 = (最高价 - 最低价) / 昨收价 × 100%

# 振幅稳定性 = 1 / (振幅标准差 + 1)
# 稳定性越高，量化参与可能性越大

# 评级标准
# 极高: CV < 0.1 (极稳定)
# 高: CV 0.1 - 0.2
# 中: CV 0.2 - 0.4
# 低: CV 0.4 - 0.6
# 极低: CV > 0.6
```

### 3.2 价格冲击系数 (权重: 7%)

```python
# 衡量下单对价格的影响程度
# 冲击系数 = ΔP / V
# ΔP: 价格变动百分比
# V: 成交量（标准化）

冲击系数 = |价格变动| / (成交量 / 平均成交量)

# 评级标准
# 极高: < 0.5 (少量成交就能影响价格)
# 高: 0.5 - 1.0
# 中: 1.0 - 2.0
# 低: 2.0 - 3.0
# 极低: > 3.0
```

### 3.3 流动性指标 (权重: 5%)

```python
# 换手率/成交额占流通市值比
流动性指标 = 成交额 / 流通市值 × 100%

# 评级标准
# 极高: > 5%/日
# 高: 2% - 5%
# 中: 1% - 2%
# 低: 0.5% - 1%
# 极低: < 0.5%
```

## 4. 持仓结构指标详细计算

### 4.1 股东户数变化 (权重: 10%)

```python
# 股东户数减少幅度
股东户数变化率 = (当期户数 - 上期户数) / 上期户数 × 100%

# 评级标准 (负值为减少)
# 极高: < -30% (户数急剧减少)
# 高: -20% - -30%
# 中: -10% - -20%
# 低: -5% - -10%
# 极低: > -5%
```

### 4.2 户均持股变化 (权重: 5%)

```python
# 户均持股增长趋势
户均持股变化率 = (当期户均持股 - 上期户均持股) / 上期户均持股 × 100%
```

### 4.3 机构持仓变动 (权重: 5%)

```python
# 从季报/年报提取
机构持仓变化 = (当期机构持股比例 - 上期机构持股比例) × 100

# 评级标准
# 极高: > +5%
# 高: +2% - +5%
# 中: -2% - +2%
# 低: -5% - -2%
# 极低: < -5%
```

## 5. 量化特征指标详细计算

### 5.1 涨停板封单分析 (权重: 4%)

```python
# 封单时间序列特征
# 1. 封单金额与流通市值比
封单比例 = 封单金额 / 流通市值 × 100%

# 2. 封单持续性（每秒撤单再封次数）
封单稳定性 = 封单金额变化的标准差倒数

# 综合评分
涨停板量化特征 = 0.6 × 封单比例得分 + 0.4 × 封单稳定性得分
```

### 5.2 融资融券异动 (权重: 3%)

```python
# 融资余额变化率
融资余额变化率 = (当日融资余额 - 前日融资余额) / 前日融资余额 × 100%

# 融券余额变化率
融券余额变化率 = (当日融券余额 - 前日融券余额) / 前日融券余额 × 100%

# 融资融券比异动
融资融券异动 = |融资余额变化率 - 融券余额变化率|
```

### 5.3 大宗交易频率 (权重: 3%)

```python
# 月度大宗交易次数
大宗交易频率 = 月内大宗交易次数

# 大宗交易折溢价率
平均折溢价率 = Σ(成交价/收盘价-1) / 交易次数

# 量化嫌疑指数
大宗交易嫌疑 = 大宗交易频率 × (1 + |平均折溢价率|)
```
