# 股票量化资金参与度分析技能

## 核心能力

本技能通过多维度指标综合评估一只股票被量化资金参与的程度，提供量化的参与度评分（0-100分）和详细分析报告。

## 分析维度与指标体系

### 1. 资金流向指标（权重 25%）
- **超大单净流入率**：超大单净流入/成交额
- **大单净流入率**：大单净流入/成交额
- **主力资金净流入天数比**：近N日内主力净流入天数/总天数

### 2. 交易行为指标（权重 25%）
- **委托成交比异动**：买入委托/成交笔数比
- **撤单频率**：当日撤单率与历史平均对比
- **盘口异动**：盘口挂单撤单频繁度

### 3. 波动特征指标（权重 20%）
- **日内振幅波动**：高频振幅稳定性分析
- **价格冲击系数**：下单对价格的影响程度
- **流动性指标**：成交额/流通市值比率

### 4. 持仓结构指标（权重 20%）
- **股东户数变化**：股东人数急剧减少可能为机构化
- **户均持股变化**：户均持股数增长趋势
- **机构持仓变动**：季报/年报机构持仓变化

### 5. 量化特征指标（权重 10%）
- **涨停板封单时间序列**：秒级封单分析
- **融资融券余额变化**：融资余额异动检测
- **大宗交易频率**：异常大宗交易模式

## 评分计算方法

### 参与度评分公式

```
总评分 = Σ(各维度得分 × 权重)

各维度得分计算：
- 指标归一化：min-max标准化到[0, 1]
- 异常值处理：使用IQR方法剔除极端值
- 趋势加成：近期趋势向好额外加分
```

### 评分等级划分

| 评分区间 | 参与等级 | 说明 |
|---------|---------|------|
| 80-100 | 极高 | 量化资金高度控盘，需谨慎操作 |
| 60-79 | 高 | 量化资金参与明显 |
| 40-59 | 中等 | 有一定量化参与，非主导 |
| 20-39 | 低 | 量化资金参与较少 |
| 0-19 | 极低 | 基本无量化资金参与 |

## 执行流程

### Step 1: 数据采集
1. 获取股票实时行情数据（分时、K线）
2. 获取Level2行情数据（盘口、资金流）
3. 获取基本面数据（股东结构、机构持仓）
4. 获取交易龙虎榜数据（如有）

### Step 2: 指标计算
按照上述5大维度、12+个子指标逐一计算：

```
对于每个指标：
1. 获取原始数据
2. 计算当日值
3. 与历史均值/中位数对比
4. 归一化处理
5. 乘以权重求和
```

### Step 3: 综合评分
1. 计算各维度得分
2. 加权汇总得出总分
3. 确定参与等级
4. 识别主要量化特征

### Step 4: 报告生成
输出包含以下内容的分析报告：
- 综合评分及等级
- 各维度得分雷达图
- 核心发现列表
- 风险提示（如有）
- 操作建议

## 数据来源优先级

1. **首选**：实时Level2数据（盘口、资金流）
2. **次选**：东方财富/同花顺实时数据接口
3. **备选**：新浪财经/腾讯财经数据
4. **补充**：公司公告、季报年报、研报数据

## 注意事项

1. **时效性**：量化分析对数据时效性要求高，建议使用实时或准实时数据
2. **样本量**：单一交易日数据可能存在偶然性，建议参考近5-20日趋势
3. **特殊情况**：新股、次新股、ST股的分析方法需特殊处理
4. **风险警示**：高量化参与度不等于会涨，需结合市场整体环境判断
