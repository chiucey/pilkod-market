# 海外社媒平台文案模板库

## LinkedIn 推广文案模板

### 模板1：行业洞察型

```
[Hook - 行业数据/趋势]

你是否注意到[行业痛点]？

我们最近[动作/发现]，想和大家分享[洞察]：

→ [要点1]
→ [要点2]
→ [要点3]

这对[目标受众]意味着[价值/机会]。

[一句话总结价值主张]

---
想了解更多？评论区留言"DM"获取完整报告。
```

### 模板2：案例故事型

```
[结果导向的Hook]

[客户名称]在[时间周期]内实现了[量化成果]。

他们是如何做到的？

[挑战描述 - 30字]

关键洞察：[一句话核心经验]

你的公司准备好实现类似的突破了吗？
```

## 多语言适配建议

### 英文优化要点

| 中文表达 | 英文替代 | 适用场景 |
|----------|----------|----------|
| 遥遥领先 | industry-leading | 产品优势 |
| 遥遥领先 | ahead of the curve | 技术领先 |
| 遥遥领先 | setting the standard | 行业标杆 |

### 语气调整参考

- **中文习惯**：排比句、感叹号加强语气
- **英文习惯**：简洁句式、数据支撑、问句互动
