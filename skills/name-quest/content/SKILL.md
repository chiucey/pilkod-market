# 🎯 名字探险家 Name Quest

还在为给孩子起名而纠结吗？别担心！名字探险家来帮你啦！

根据父母的姓名、生肖属性、身高、星座等信息，结合中国传统文化中的五行、生辰八字理念，生成各种好玩又有寓意的孩子名字组合，并给出详细解释和未来预测。

## 🎮 支持的冒险模式

| 模式 | 说明 | 推荐数量 |
|------|------|----------|
| 👦 单胎男孩 | 普通家庭首选 | 3个组合 |
| 👧 单胎女孩 | 普通家庭首选 | 3个组合 |
| 👬 双胞胎男孩 | 两兄弟组合名 | 3对组合 |
| 👭 双胞胎女孩 | 两姐妹组合名 | 3对组合 |
| 👫 龙凤胎 | 一男一女组合 | 3对组合 |
| 🌈 中性风格 | 不分性别的名字 | 3个组合 |

## 🗺️ 工作流程

### 第一步：收集情报（表单收集）

**页面1 - 爸爸妈妈档案**
- 爸爸姓名（必填）
- 妈妈姓名（必填）
- 爸爸生肖（必填：鼠/牛/虎/兔/龙/蛇/马/羊/猴/鸡/狗/猪）
- 妈妈生肖（必填）

**页面2 - 身体数据**
- 爸爸身高（必填，cm）
- 妈妈身高（必填，cm）
- 爸爸星座（必填）
- 妈妈星座（必填）

**页面3 - 起名偏好**
- 姓氏（必填，默认用爸爸的姓）
- 想要几个孩子？（必填：1个/2个/龙凤胎）
- 性别（如果知道的话）
- 名字风格（多选：古风仙侠/呆萌可爱/高端大气/文艺清新/搞笑逗比）
- 名字寓意（多选：聪明伶俐/健康长寿/财源广进/学业有成/幸福美满/勇敢自信）
- 家族规矩（有没有要避开的字，或者必须要有的辈分字）
- 其他要求（随便写~）

### 第二步：数据分析

#### 身高预测公式

```
男孩身高 = (爸爸 + 妈妈) ÷ 2 × 1.08 ± 5cm
女孩身高 = (爸爸 + 妈妈) ÷ 2 ± 5cm
```

#### 五行相生相克

| 生肖 | 五行 | 相生 | 相克 |
|------|------|------|------|
| 鼠、猪 | 水 | 金生水 | 土克水 |
| 牛、龙、羊、狗 | 土 | 火生土 | 木克土 |
| 虎、兔 | 木 | 水生木 | 金克木 |
| 蛇、马、猴、鸡 | 金 | 土生金 | 火克金 |
| 龙 | 土/水 | 木生火 | 水克火 |

#### 星座元素

| 元素 | 星座 |
|------|------|
| 火象 | 白羊、狮子、射手 |
| 土象 | 金牛、处女、摩羯 |
| 风象 | 双子、天秤、水瓶 |
| 水象 | 巨蟹、天蝎、双鱼 |

### 第三步：生成名字

根据用户选择的模式生成推荐：

1. **单胎模式**：生成3个完整的"姓氏+名字"组合
2. **双胞胎模式**：生成3对有呼应感的名字
3. **龙凤胎模式**：生成3对有CP感但不重名的组合

每个名字都要满足：
- 五行平衡（跟爸妈的八字互补）
- 音韵好听（读起来顺口）
- 寓意美好（典故出处）
- 好写好看（笔画搭配协调）
- 独一无二（不跟长辈撞名）
