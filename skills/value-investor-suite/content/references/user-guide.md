# 技能使用指南

## 快速开始

### 基本用法

在对话中输入以下指令即可触发技能：

```
分析贵州茅台
估值 600519
企业价值分析 建设银行
帮我看看中国平安的基本面
```

### 高级用法

#### 使用PDF年报分析
1. 在配置中填入PDF提取服务API Key
2. 上传公司年报
3. 技能将自动提取关键财务数据

#### 实时推送
1. 配置企业微信/钉钉Webhook
2. 每次分析完成后自动推送结果

## 配置项说明

### eastmoney_api_key（必需）
- 申请地址：东方财富开发者平台
- 用于获取实时行情和财务数据
- 免费额度足够日常使用

### pdf_extractor_service（可选）
- 支持服务：parseur, google_docai, azure
- 用于深度年报分析
- 如不配置，技能将使用内置简化分析

### webhook_url（可选）
- 企业微信或钉钉群机器人
- 格式：`https://qyapi.weixin.qq.com/...`
- 用于实时推送分析结果

## 输出解读

### 估值区间
- 绿色区间：低估，适合买入
- 黄色区间：合理，谨慎持有
- 红色区间：高估，考虑卖出

### 86体系评分
- 80分以上：优秀，强烈推荐
- 60-80分：良好，适度配置
- 40-60分：一般，谨慎考虑
- 40分以下：不推荐

### 风险提示
- 技能会列出主要风险因素
- 投资前请仔细阅读
- 分散投资降低风险

## 常见问题

### Q: 为什么分析需要时间？
A: 技能需要调用多个API获取数据，并行分析多个维度，确保结果全面准确。

### Q: 估值结果准确吗？
A: 估值基于多种方法（DCF、相对估值、股息折现），结果仅供参考，不构成投资建议。

### Q: 如何提高分析准确性？
A: 1) 配置完整的API Key
   2) 使用PDF年报分析
   3) 提供更多公司背景信息

### Q: 支持港股和美股吗？
A: 当前版本主要支持A股，港股和美股支持在规划中。
