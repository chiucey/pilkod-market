## 二、每位大神·详细风格解析与模仿模板

### 2.1 辰东（波澜壮阔派）

**代表作：**《神墓》《遮天》《完美世界》《圣墟》

**数据来源：** 知乎「辰东写作风格分析」/豆瓣/龙空评价

#### 核心写作特点

**① 世界观宏大，信息密度极高**

辰东的书最大特点就是世界观铺得大。《遮天》从地球穿越到北斗古星，地图一层层展开，每个星球、每个禁区都是独立的文化体系。他写世界的方式不是平铺直叙，而是用悬念引导：

```
普通写法：
「这个世界很大，有很多强者。」

辰东写法：
「禁区。\n\n这两个字，在北斗星域代表着绝对的禁忌。\n\n没有人知道禁区里有什么，因为进去的人，从来没有出来过。」\n\n→ 用"禁区"这个悬念，瞬间建立起读者对这个世界危险程度的认知。
```

**② 配角高光（画外音渲染法）**

辰东最擅长的技巧之一：通过配角的震惊反应，来渲染主角的强大。

```
正派道友：「他竟然……做到了这种事？！」\n\n敌方高手：「不可能！这种事怎么会发生！」\n\n某位隐世老祖：「……我错了。」\n\n→ 三个旁观者的反应，比直接写主角有多强，更有说服力。
→ 每人100-150字，三个人=300-450字。
```

**③ 悬念递进法**

辰东的书往往在每章结尾留下巨大的悬念：

```
「他低头，看向手中的那枚戒指。\n\n戒指上，刻着一个字——」\n\n→ 章节戛然而止。读者必须继续读下去。
→ 每个悬念的揭晓，要比读者期待的更震撼。
```

**④ 战斗场面渲染法**

辰东的战斗不写招式数量，而是写场面感和破坏力：

```
「一剑挥出。\n\n天崩。\n\n地裂。\n\n整个禁区，都在颤抖。」\n\n「那道剑光，只有一道。\n\n但就是这一道光，照亮了整片黑暗。」\n→ 简洁但有力量。用极简的语言写极致的破坏。
```

#### 辰东风·扩充模板

```
【新地点出现时·世界观填充模板】

这个地点的名字，在很久以前，就已经是禁忌。

据说——（插入300字背景说明）

但没有人知道真相。

因为去过的人，都死了。

直到今天——（主角出现，触发新剧情）

【战斗胜利后·配角反应填充模板】

「他……他竟然……」

第一个看到这一幕的老者，已经说不出话来。

他活了八千年，自认为见过无数天才。

但今天这一幕，他从来没有见过。

第二个开口的是一个年轻人。

他的嘴唇在发抖。

「这……这真的是人力所能及的吗？」

没有人回答。

因为所有人都被眼前的景象震惊了。

主角站在废墟中央。

他的身上，连一点伤都没有。

→ 3个配角反应 = 约400字。
→ 可叠加辰东式"极简战斗描写"结尾。
```

### 2.2 梦入神机（设定创新派）

**代表作：**《佛本是道》《阳神》《圣王》《星河大帝》《拳镇山河》

**数据来源：** 知乎「梦入神机写作风格」/中国网络文学研究论文

#### 核心写作特点

**① 洪荒流开创者：设定即内容**

梦入神机是"洪荒流"的开山祖师。他的核心技巧是：用一套完整的神话设定作为框架，把历史传说、佛道经典全部融合进去。

```
他的设定不是道具，而是内容本身。

《阳神》里，每一个境界都有详细解释：
「武者的修炼，分为三个阶段：\n炼精化气、炼气化神、炼神返虚。\n每个阶段都有九重天。\n达到炼神返虚巅峰，才能突破到鬼仙……」

→ 这些设定说明本身就是内容，每段可写300-500字。
→ 读者学到了世界观，同时也在消费内容。
```

**② 战斗描写：武道精神**

梦入神机的战斗，不只是打斗，而是写"武道精神"。

```
普通战斗：
「他一拳打出，敌人倒下了。"

梦入神机式战斗：
「他的拳意，是不屈。\n\n哪怕面对再强的敌人，也要站着倒下。\n\n这是武者的尊严。\n\n也是他这一拳的意志。」\n\n→ 每一场战斗，都有一个精神内核。
→ 战斗结束后，这个精神内核会影响后续剧情。
```

**③ 东西方融合（斗法场面）**

梦入神机的《圣王》里，东方修炼体系和西方异能对决，这是他独特的爽点来源。

```
「你的异能，很强。」主角说。

「但在我的道面前——」

「不堪一击。」

→ 用文化冲突制造爽点：东方神秘学 vs 西方科学异能。
→ 这种冲突天然具有张力。
```

#### 梦入神机风·扩充模板

```
【新体系/境界出现时·设定说明模板】

这套体系的名称，叫XX。

它的核心理念是：……（300字理念说明）

它的修炼分为X个阶段：
第一阶段：……（100字）
第二阶段：……（100字）
第三阶段：……（100字）

它和普通修炼体系最大的区别是：……（200字对比说明）

主角第一次接触这个体系时，感觉到——（身体反应描写，100字）
→ 一段设定说明 = 约900字。
```

### 2.3 天蚕土豆（套路循环派）

**代表作：**《斗破苍穹》《武动乾坤》《大主宰》《元尊》

**数据来源：** 知乎「天蚕土豆写作水平分析」/Bilibili书评

#### 核心写作特点

**① 退婚流：情绪反转公式**

天蚕土豆创造了网文最经典的套路之一——"退婚流"。

```
公式：
1. 弱势开局（废材/被羞辱）
2. 积累（三年之约/隐忍修炼）
3. 反转（一鸣惊人/当众打脸）
4. 爽点爆发（对方震惊/后悔）
5. 收尾（获得新机缘）

「三十年河东，三十年河西，莫欺少年穷！」\n\n→ 这句话成为网文最经典的台词之一。
→ 核心：情绪的压抑与释放。
```

**② 套路可复制：循环结构**

土豆的每本书都是这个循环的变体：

```
新地图 → 遇到天才 → 被看不起 → 隐藏实力 → 比武胜利 → 获得资源
↓（循环）
下一个地图
```

**③ 爽点密集排布**

土豆的节奏是：每一章至少一个爽点。

```
章节结构：
第1段：危机（敌人出现）
第2段：压抑（主角被压制）
第3段：爆发（主角反击）
第4段：收获（新能力/宝物/声望）

→ 每4段 = 一个完整爽点节奏。
→ 每章2-3个爽点节奏 = 章节信息量充足。
```

#### 天蚕土豆风·扩充模板

```
【退婚流·打脸模板】

「你以为你还是以前那个天才吗？」对方冷笑。

「现在的你，不过是个废物。」

主角没有说话。

他只是缓缓抬起头。

然后——

他的气息，在那一刻，彻底变了。

对方的脸，僵住了。

「你……你的修为……」

「没错。」主角的声音平静。

「我回来了。」

然后——

一招。

仅仅一招。

曾经那个高高在上的人，倒在了他的面前。

全场死寂。

→ 标准退婚流打脸公式：质疑→沉默→反转→震惊→胜利。
→ 全程约400字，情绪饱满。
```

### 2.4 辰东（宏大型世界观·续）

**① 世界观层层递进揭示法**

辰东从不一次性把世界观全盘托出，而是像剥洋葱一样，一层层揭示：

```
第一步：只告诉你这个地方叫"禁区"，很危险。（引发好奇）
第二步：借配角之口，说出禁区的历史传说。（加深恐惧）
第三步：主角亲自进入禁区，发现历史传说是真的。（满足好奇）
第四步：禁区深处，还有更大的秘密。（引出下一个悬念）

→ 每一步 = 300-500字。
→ 四个步骤 = 一章完整的"世界观揭示节奏"。
```

**② 战斗场面三段式（辰东版）**

```
第一段：蓄势（双方对峙，气势压迫）——200字
「两个强者的气势在空中碰撞。周围的一切，都在颤抖。」

第二段：碰撞（技能/招式对决）——300字
「他挥出了那一拳。这一拳，是他毕生修炼的精华。」

第三段：余波（战后场景描写）——200字
「拳风过处，天崩地裂。很久之后，那里才恢复了平静。」
→ 三段式战斗 = 约700字。紧凑而完整。
```

### 2.5 烽火戏诸侯（文青细腻派）

**代表作：**《雪中悍刀行》《极品公子》《陈二狗的妖孽人生》《剑来》

**数据来源：** 知乎「烽火戏诸侯写作风格分析」/龙空书评

#### 核心写作特点

**① 文青范儿：文字克制但情感浓郁**

烽火的文字不像传统网文那样直白，他习惯用"留白"和"意象"：

```
普通写法：
「他很孤独。」

烽火写法：
「他的院子里，有一棵枇杷树。\n\n那是他亲手种的。\n\n但他再也没有机会，和那个人一起，在树下乘凉了。」\n\n→ 用"枇杷树"这个意象，暗示失去挚爱的孤独。
→ 读者自己脑补，比直接说出来更有力。
```

**② 人物出场：先渲染后登场**

烽火写重要人物，从不直接写本人，而是先写别人的评价、传说、行踪，最后才正面亮相。

```
第一步：别人口中的传说（150字）
「江湖上有个传说——」

第二步：传说的离谱程度（100字）
「有人说他是剑神转世，有人说他是天煞孤星。」

第三步：主角的印象（100字）
「他不信。」

第四步：第一次见面（正面描写，200字）
→ 三步铺垫 + 一次正面亮相 = 约550字。
→ 读者的期待值被拉到最高。
```

**③ 金句制造法**

烽火的书里有大量让人记住的金句：

```
「剑来。」

「我有一剑，可搬山，断江，倒海，降妖，镇魔，敕神，摘星，摧城，开天！」

「身后纵有万古名，不如生前一杯酒。」

→ 金句公式：简单直白 + 宏大意象 + 情感共鸣
→ 一章一个金句，足以让读者记住这一章。
```

**④ 权谋布局：草蛇灰线**

烽火写权谋，表面是武侠江湖，内核是政治博弈。

```
每章的政治博弈推进一点，但不明说。

「那个人笑了一下。」

「没有人知道他在笑什么。」

「但在场的人，都感觉到了寒意。」

→ 留下悬念，暗示更大的阴谋在后面。
→ 让读者主动去猜测，比直接告诉答案更有趣。
```

#### 烽火戏诸侯风·扩充模板

```
【重要人物出场·渲染模板】

在江湖上，有一个人的名字，已经很多年没有人敢提起了。

不是因为忘记。

而是因为不敢。

（插入100字江湖传说）

有人说，他是某个大门派的弃徒。

也有人说，他是某个王朝的落魄皇子。

更有人说，他根本不是人。

（插入50字主角的反应）

直到今天——

他终于出现了。

（人物正式登场，200字正面描写）

→ 铺垫渲染 = 约400字。
→ 读者对这个人物的期待值拉到最满。
```

### 2.6 江南（情感共鸣派）

**代表作：**《龙族》《九州缥缈录》《上海堡垒》《此间的少年》

**数据来源：** 知乎「江南写作风格分析」/豆瓣书评

#### 核心写作特点

**① 情绪描写：身体感知法**

江南写情绪，不直接说"他很悲伤"，而是通过身体反应传达：

```
「他的眼眶有些发热。\n\n但他忍住了。\n\n他总是这样，把所有的情绪，都藏在那张面无表情的脸下面。」\n\n→ 眼眶发热 = 悲伤。
→ 忍住了 = 压抑。
→ 面无表情 = 伪装。
→ 三层叠加 = 读者完全感受到了角色的内心。
```

**② 情绪×3原则（详述版）**

```
第一层：直接情绪（50字）
「他很难过。」

第二层：身体感知（100字）
「他的手在发抖。\n心口像是被什么东西堵住了。\n呼吸，变得很重。」

第三层：回忆对比（250字）
「他想起了很久以前的事。\n那时候，也是一样的黄昏。\n那个人拍了拍他的肩膀，说了一句话。\n那句话，他一直记得。」\n\n→ 情绪×3 = 约400字。
→ 情感浓度：普通写法的8倍。
```

**③ 遗憾美学**

江南最擅长的，就是写"差一点"的遗憾：

```
「他伸出手，想要抓住什么。\n\n但手指穿过了那个人的轮廓。\n\n他抓不住。」\n\n→ 物理层面的"抓不住"，象征情感层面的"留不住"。
→ 读者自然产生共鸣。
```

**④ 场景感：五感描写**

```
视觉：「夕阳把整片天空染成了橙红色。」
听觉：「远处传来钟声，一下，两下。」
嗅觉：「空气里有桂花的香味。」
触觉：「风吹过来，有些凉了。」
味觉：「他想起小时候，母亲做的桂花糕。」\n\n→ 五个感官同时启动 = 沉浸感极强。
→ 每个感官50字 = 250字场景填充。
```

#### 江南风·扩充模板

```
【情感高潮·情绪深化模板】

他站在那里。

没有说话。

（视觉）
风吹过，他的衣角飘了起来。

（听觉）
远处，有人在喊他的名字。

但他听不见。

他只听见自己心跳的声音。

咚。咚。咚。

（身体反应）
他的手，慢慢地握紧。

指甲，嵌进了肉里。

疼。

但他没有松手。

（回忆）
他想起了她曾经说过的话。

「你会记得我吗？」

他当时笑着说：「不会。」

（现实）
但他记得。

他记得很清楚。

只是，他再也没有机会说了。

→ 情绪深化 = 约500字。
→ 可让读者流泪的情感段落。
```

### 2.7 耳根（逆天改命派）

**代表作：**《仙逆》《求魔》《我欲封天》《一念永恒》《三寸人间》

**数据来源：** 知乎「耳根写作风格分析」/Bilibili

#### 核心写作特点

**① "逆"字核心：悲情英雄**

耳根的所有主角，都在做同一件事：对抗命运。

```
《仙逆》王林：天才被夺，走上逆天之路。
《求魔》苏铭：被命运操控，一步步觉醒反抗。
《我欲封天》孟浩：平凡少年，逆天改命成真仙。

→ "逆"的主题，贯穿所有作品。
→ 核心情感：悲壮、不屈、孤独。
```

**② 悬念大师：章章有钩子**

耳根的书，平均每章结尾都有一个悬念：

```
「就在他转身的瞬间——\n\n他感觉到了什么。\n\n是他的气息。\n\n明明已经死了的气息。」\n\n→ 悬念类型：死而复生？假死？另有其人？
→ 读者立刻想翻到下一章。
```

**③ 升级与心性并重**

很多升级流只写力量增长，耳根同时写心性变化：

```
「修为提升了。\n\n但他的心，却没有变。\n\n他还是以前那个他。\n\n只是，多了一些东西。」\n\n→ 升级不只是力量变化，还有心理成长。
→ 让读者看到角色的立体感。
```

**④ 世界观宏大：地图切换**

耳根的书，地图是一个地图接一个地图，每个地图都是一个新的文明体系：

```
第一地图：楚国（凡人世界）
第二地图：修王国（修真界）
第三地图：仙界
第四地图：更高级的宇宙

→ 每个地图 = 新的文明 + 新的势力 + 新的敌人。
→ 地图切换自然，不突兀。
```

#### 耳根风·扩充模板

```
【逆天宣言·悲情模板】

「我不是天。」

他的声音很平静。

但在这平静之下，是无尽的怒火。

「天要灭我，我便灭天。」

「神要压我，我便杀神。」

「仙要收我，我便——」

他抬起头。

「我便踏碎这仙。」

→ 经典逆天宣言 = 约200字。
→ 可作为章节情绪高潮的收尾。
```

### 2.8 跳舞（嘴炮对白派）

**代表作：**《恶魔法则》《邪气凛然》《天骄无双》

**数据来源：** 知乎「跳舞写作风格」/阅文作家访谈

#### 核心写作特点

**① 对话即情节**

跳舞的对话不只是说话，而是情节本身：

```
普通对话：
「你好。」
「你好。」
「我们去打怪吧。」
「好。」

跳舞式对话：
「你想变强吗？」对方问。

「想。」他没有犹豫。

「很好。但你知道变强的代价是什么吗？」

「不知道。」

「代价是——」

对方笑了一下。

「放弃一些东西。」

「什么东西？」

「你最重要的东西。」

→ 对话本身有信息量，有冲突，有悬念。
→ 一段对话 = 一段微型情节。
```

**② 性格鲜明：每人一口音**

跳舞的人物，每个都有独特的说话方式：

```
正派君子：说话文雅，满口仁义道德。
反派小人：说话尖酸，嘲讽不断。
热血兄弟：说话直接，不绕弯子。
腹黑谋士：说话绕弯，每句话三层意思。

→ 用对话风格代替外貌描写，效率更高。
→ 读者听到这个人物说话，就能认出他是谁。
```

**③ 情节推进靠"说"完成**

跳舞经常让角色通过对话来推动剧情：

```
「有件事，我一直没告诉你。」

「什么事？」

「其实，我不是这个世界的人。」

「什么？！」

「而且，我是来杀你的。」

→ 一段对话，直接揭露核心秘密。
→ 比平铺直叙快十倍。
```

#### 跳舞风·扩充模板

```
【嘴炮反击·模板】

反派：「你以为你是谁？不过是个——」

主角：「说完了吗？」

反派：「我还没说完！」

主角：「好。那我等你说。」

（停顿）

反派：「……」

主角：「说完了？那轮到我了。」

→ 嘴炮公式：接话→打断→沉默→反攻
→ 每轮嘴炮 = 约300字。
→ 嘴炮结束紧接着战斗开始，节奏感最强。
```

### 2.9 我吃西红柿（体系详解派）

**代表作：**《盘龙》《吞噬星空》《星辰变》《寸芒》

**数据来源：** 知乎「我吃西红柿写作风格分析」/百度百科

#### 核心写作特点

**① 升级体系极度清晰**

番茄的每本书，都有一个玩家能看懂的"等级表"：

```
例（星辰变）：
凡人 → 行星期 → 恒星期 → 星核期 → 星域期 → 星系期 → 宇宙期

每个境界分9层。
每升一层，有明确的技能提升说明。
→ 读者对主角的成长，有清晰的认知地图。
→ 升级感=爽感。
```

**② 每个境界有专属仪式感**

```
突破新境界时，番茄会写：
① 身体的反应（发光/震动/疼痛）——100字
② 能力的变化（力量/速度/感知增强）——200字
③ 周围人的反应（震惊/恐惧/难以置信）——200字
④ 主角的内心独白（感慨/坚定/新的目标）——100字
→ 一次完整突破 = 约600字。
```

**③ 宝物/技能获得时，详细功能列表**

```
「这是一枚储物戒指。\n它的内部空间，有一百立方米。\n可以存放任何非生命物体。\n存入的物体，时间静止，不会腐烂。」\n→ 每个宝物 = 约200字功能说明。
→ 读者觉得主角在"赚装备"，积累财富感强。
```

**④ 战斗：简洁高效**

番茄的战斗描写不拖沓：

```
「他出手了。」

就这么三个字。

然后——

「对方死了。」

→ 简洁的代价是：需要用其他内容填补战斗前后的铺垫。
→ 战斗前（敌我分析）300字 + 战斗（3个字）+ 战斗后（收获清单）200字 = 503字。
```

#### 番茄风·扩充模板

```
【突破新境界·完整模板】

那一夜，他感觉到了屏障的存在。

那是阻碍他继续前进的关卡。

（「屏障是什么」——设定说明，100字）

他开始调动全身的力量。

下丹田的气血，翻涌而上。

上丹田的神识，俯冲而下。

两股力量，在身体正中央碰撞——

（「两力交汇」——感觉描写，150字）

那一刻，他感觉到了疼痛。

剧烈的疼痛。

像是有什么东西，正在被撕裂。

（「疼痛描写」——身体反应，100字）

但他没有停下。

他不能停。

（「内心独白」——意志描写，100字）

一个时辰后。

疼痛消失了。

取而代之的，是一种前所未有的充盈感。

他睁开眼睛。

世界，变得不一样了。

（「新境界达成」——感官变化，150字）

他突破了。

→ 完整突破 = 约600字。
```

### 2.10 老鹰吃小鸡（对话扩充派）

**代表作：**《全球高武》《万族之劫》

**数据来源：** 知乎「老鹰吃小鸡手速与写作」/阅文作家采访

#### 核心写作特点

**① 核心心法："对话即情节"**

老鹰的一天两万字，靠的不是战斗描写，而是对话填充：

```
每章3段对话场景，每段200-400字。
对话夹带信息：
- 敌人身份
- 战局变化
- 新任务
- 世界观更新

「根据情报，敌方有10万人。」

「10万？」他皱起眉。

「是的。而且——」

「而且什么？」

「他们的统帅，是我们的老朋友。」

「谁？」

「……王建国。」

→ 一段对话 = 交代了4个信息，同时留下悬念。
→ 约300字。
```

**② 战斗压缩，信息前置**

老鹰的战斗，只用两句话：

```
「他出手了。」

「对方倒下了。」

→ 剩下的篇幅，全部用来写战斗后的对话和信息交换。
→ 节奏极快，读者阅读体验：爽+信息多。
```

**③ 每章结尾甩任务**

```
「现在，我们有一个任务。」

「什么任务？」

「去非洲。」

「去那里做什么？」

「杀一个人。」

「谁？」

「这个任务，还没有结束。」

「因为——」

她看向窗外。

「真正的任务，才刚刚开始。」

→ 结尾甩悬念 = 读者追读。
```

#### 老鹰风·扩充模板

【战前会议·对话扩充模板】

「不太好。」

「哪里不好？」

「三个方面。」

他伸出手指。

「第一，敌人的数量，比我们预计的多。」

「多少？」

「多一倍。」

「第二？」

「我们的补给线，被切断了。」

「谁切的？」

「不知道。但肯定不是普通人干的。」

「第三呢？」

他停了一下。

「第三，我们的内部——」

「有内鬼。」

（停顿）

「谁？」

「还在查。」

→ 一段战前会议 = 约500字 + 三个悬念。
```

### 2.11 zhttty（无限流智斗派）

**代表作：**《无限恐怖》《无限曙光》《死亡开端》

**数据来源：** 知乎「zhttty写作风格」/龙空

#### 核心写作特点

**① 主神空间体系：规则即内容**

zhttty的设定体系是"规则"：

```
主神空间的规则：
1. 完成任务，获得奖励点。
2. 奖励点可以兑换技能、能力、寿命。
3. 死在任务中，现实中的本体也会死亡。
4. 团队任务必须合作，Solo任务风险更大。

→ 规则越详细，世界越真实。
→ 读者在规则里学习"怎么变强"。
```

**② 智斗精彩：计划与应变**

无限流的核心不是战斗力，而是智力：

```
第一步：分析任务（200字）
「这个任务的目标是杀死BOSS。」

「但BOSS的能力是——」

「所以我们需要三个步骤：」

「第一步：削弱它的护甲。」

「第二步：切断它的补给。」

「第三步：致命一击。」

（以上200字）

第二步：执行中出意外（100字）
「计划出了变故——」

第三步：临场应变（200字）
「改变策略——」

→ 完整的"智斗三步" = 约500字。
```

**③ 恐怖氛围：留白法**

```
不写：
「他看到一个鬼，很可怕。」

zhttty写法：
「他转过头。\n\n他身后，什么都没有。\n\n但他感觉到——\n\n有什么东西，正在看着他。」\n\n→ 读者的想象力，比任何画面都有力。
→ 写恐怖，最忌讳写得太满。
```

#### zhttty风·扩充模板

【任务解析·智斗模板】

「这次任务，有三个目标。」

第一个：主线任务——杀死BOSS。奖励：5000点。

第二个：支线任务——救出被囚禁的人质。奖励：1000点。

第三个：隐藏任务——目前未知。

（沉默）

「第三个呢？」

「第三个……」他看向资料。

「我不知道。」

→ 任务解析 = 约400字。
→ 同时留下"隐藏任务"的悬念。
```

### 2.12 血红（爽点密集派）

**代表作：**《升龙道》《逆龙道》《邪龙道》《巫颂》

**数据来源：** 知乎「血红写作风格」/中国作家网

#### 核心写作特点

**① 明暗双爽点**

血红的书，永远有两条爽线：

```
明线：主角打赢/突破/获得资源
暗线：敌人在别处受挫/内部分裂/阴谋曝光

两线交叉 = 信息量翻倍 = 爽点翻倍
```

**② 升级速度极快**

血红不像番茄那样详细写每个小境界，他的写法是"跨越式升级"：

```
「他突破了。」

没有铺垫，直接宣告。

然后立刻写新能力有多强。

「此刻的他，已经是筑基期的修士。」

「在整个宗门里，这个实力，足以排进前十。」

→ 省去升级过程，直接写结果。
→ 用结果倒推实力差距，制造爽感。
```

**③ 信息轰炸：每章3个新信息**

```
① 新能力
② 新敌人
③ 新阴谋
④ 新宝物

→ 每章4个信息 = 读者觉得内容充实。
→ 血红的书，节奏极快，让人停不下来。
```

#### 血红风·扩充模板

```
【双重爽点·模板】

明爽点：主角赢了比武。

暗爽点：与此同时——敌对势力内部，正在发生内讧。

「你什么意思？！」

「我的意思是，你不行。」

「你才不行！」

「那你为什么打了三年，都没拿下那座城？」

（敌人内部吵起来了）

主角在比武场上，收到了这个消息。

他笑了。

→ 明线+暗线同时推进 = 约400字。
→ 读者同时追两条线，爽感翻倍。
```

### 2.13 鹅是老五（严谨体系派）

**代表作：**《凡人修仙传》《不朽凡人》《天下第九》《弃宇宙》

**数据来源：** 知乎「鹅是老五写作风格」/百度经验

#### 核心写作特点

**① 扮猪吃虎：低调流**

鹅是老五的主角，从不高调亮相：

```
韩立的处事原则：
① 永远隐藏真实修为。
② 永远不主动惹事。
③ 永远在最后一刻才展示实力。
④ 永远留有后手。

→ 读者知道主角很强，但书里的人不知道。
→ 这种"信息差" = 扮猪吃虎的核心爽感。
```

**② 世界观严谨：凡人流体系**

```
修炼境界：炼气 → 筑基 → 结丹 → 元婴 → 化神 → 炼虚 → 大乘 → 渡劫

每个境界有：
- 修炼资源（灵草/矿石/兽核）
- 修炼时间（几年/几十年/几百年）
- 战斗风格（近战/术法/傀儡）

→ 体系越严谨，世界越真实。
→ 读者相信这个世界的规则。
```

**③ 资源积累：积少成多**

```
韩立获得宝物时，不是一下子拿到逆天道具。
而是：
- 一次机缘，获得一株灵草。
- 一次冒险，获得一件下品法器。
- 一次交易，换来一张丹方。

→ 慢慢积累的感觉，让读者有"养成"快感。
→ 每次小收获 = 一次小爽点。
```

#### 鹅是老五风·扩充模板

```
【扮猪吃虎·展示模板】

敌人：「就你这点修为，也敢在我面前放肆？」

（停顿）

（瞬间释放真实修为）

### 2.14 宅猪（多视角切换派）

**代表作：**《牧神记》《择日飞升》《独步天下》

**数据来源：** 知乎「宅猪写作风格」/百度百科

#### 核心写作特点

**① 配角视角填充法**

同一场景，用多个人的视角来看：

```
场景：主角打赢了。

主角视角（自评）：「还不够。下一次，要更快。」

对手视角（震惊）：「他……他竟然……」

队友视角（自豪）：「我早就说过他能行！」

观众视角（哗然）：「不可思议！这简直是——」

→ 四个视角 = 约600字。
→ 同一事件，信息量和情绪浓度翻倍。
```

**② 古典文学融合**

宅猪喜欢在书里用诗词、历史典故：

```
主角出招时，嘴里念一首诗。

「大漠孤烟直，长河落日圆。」

→ 招式和诗词融为一体。
→ 文雅感和力量感并存。
```

**③ 诙谐幽默调剂**

紧张场景里，插入一个笑点，让读者喘口气：

```
「你确定这是最好的策略？」

「不确定。」

「那你还——」

「但这是唯一的策略。」

→ 用逻辑矛盾制造幽默感。
→ 一句幽默 = 轻松感 = 读者不会弃书。
```

### 2.15 忘语（凡人逆袭派）

**代表作：**《凡人修仙传》（仙界篇/凡人篇）

#### 核心写作特点

**① 谨慎低调哲学**

韩立的核心性格：永远不冲动，永远留后手：

```
遇到机遇：「先观察。」
遇到危险：「先撤退。」
遇到强敌：「先隐藏。」

→ 三步决策法 = 约100字。
→ 让读者觉得主角是"聪明人"。
```

**② 升级慢热，但每步扎实**

忘语的升级，是真的"修炼"：

```
韩立修炼一天 = 200字。
第二天 = 200字。
第三天 = 200字。
……坚持了三年 = 质变。

→ "慢"
→ 读者见证主角一步步成长。
→ 真实感极强，代入感极强。
```

### 2.16 禹枫（热血激情派）

**代表作：**《不灭元神》《星河领主》

#### 核心写作特点

**① 热血战斗描写**

```
「热血」是禹枫的核心词。

主角的每一次战斗，都是"燃烧生命"式的。

「他燃烧了自己的精血。」

「他的头发，在那一刻，变成了白色。」

「但他不在乎。」

→ 用"代价"来表达热血。
→ 代价越大，爽感越强。
```

**② 内心独白高频使用**

禹枫的书，主角的内心独白极多：

```
「我不能输。」

「我还没有——」

「还没有报仇。」

→ 内心独白 = 角色塑造 = 读者理解动机。
→ 每章3-4段内心独白 = 约300字。
```

```
□ 是否写满了3段以上的对话场景？（老鹰法：每段200-400字）

□ 是否有主角的情绪深化段落（不少于100字）？（江南法）

□ 是否有战斗场面（不少于200字）？（天蚕土豆/辰东法）

→ 每项满足 +300字
→ 全部满足 = 章节可扩充2100字+
