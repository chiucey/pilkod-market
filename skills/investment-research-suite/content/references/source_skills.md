# 源技能说明

本文档列出合并技能 `investment-research-suite` 的源技能及其贡献。

## 技能来源列表

| 源技能 | 版本 | 贡献模块 | 核心功能 |
|--------|------|----------|----------|
| b2b-lead-engine | 1.0.0 | 商机组 | B2B商机挖掘、竞品分析、BD材料生成 |
| daily-market-review | 1.0.0 | 市场复盘 | A股/港股/美股每日复盘 |
| hot-topic-tracker | 1.0.0 | 热点追踪 | 话题挖掘、信源搜索、长文撰写 |
| html-presentation-generator | 1.0.0 | 报告生成 | 专业HTML幻灯片生成 |
| investment-research-analyst | 1.0.0 | 深度投研 | 多维度股票分析 |

## 模块对应关系

### 市场复盘模块 ← daily-market-review
- 每日A股/港股/美股收盘分析
- 板块轮动追踪
- 资金流向监控
- 龙虎榜分析
- 涨跌停统计

### 热点追踪模块 ← hot-topic-tracker
- 输入理解与歧义处理
- 多维度信源搜索
- 爆点话题挖掘
- 长文内容撰写
- 事实核查

### 深度投研模块 ← investment-research-analyst
- 基本面分析（财务报表、估值）
- 新闻分析
- 情绪分析
- 技术分析
- 多空辩论
- 风险评估
- 事实核查
- Dashboard生成

### 报告生成模块 ← html-presentation-generator
- 幻灯片类型定义（Cover/TOC/Content/Summary）
- 配色方案选择
- HTML生成规范
- 截图验证流程
- 部署发布

### 商机组 ← b2b-lead-engine（adapted）
- 投资机会信号识别
- 商机评分体系
- 个性化触达材料生成
- LinkedIn/Email话术模板

## 合并改进

1. **统一入口**：单一触发条件覆盖所有功能
2. **模块化路由**：根据用户需求自动选择执行模式
3. **流程整合**：从市场监控到深度研究到报告输出无缝衔接
4. **去重精简**：合并重复内容，保留核心功能

## 使用建议

| 场景 | 推荐模块组合 |
|------|--------------|
| 每日晨会准备 | 市场复盘 |
| 深度研究个股 | 深度投研 → 报告生成 |
| 追踪行业热点 | 热点追踪 → 商机组 |
| 投研汇报 | 深度投研 → 报告生成 |
| 发现投资机会 | 市场复盘 + 热点追踪 + 商机组 |
