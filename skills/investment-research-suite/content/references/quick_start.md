# 快速开始指南

## 快速执行检查清单

在执行任务前，确认以下条件：

- [ ] 已理解用户需求
- [ ] 确定执行的模块/模式
- [ ] 准备所需的数据源
- [ ] 确认输出格式要求

## 执行模式选择

```
用户输入 → 识别触发类型 → 选择执行模式

市场分析请求 → 模式A：市场复盘
个股深度研究 → 模式B：深度投研
热点话题追踪 → 模式C：热点追踪
报告/PPT需求 → 模式D：报告生成
投资机会发现 → 模式B+C组合
```

## 常用命令

### 运行验证
```bash
python scripts/quick_validate.py /path/to/skill
```

### 打包技能
```bash
python scripts/package_skill.py /path/to/skill
```

### 运行测试
```bash
python scripts/test_validation.py
```

## 输出文件命名规范

## 常见问题

### Q: 如何选择配色方案？
A: 根据报告性质选择：
- 金融分析/年度汇报 → 商务与权威（#2）
- 科技投资 → 科技与夜景（#9）
- 市场分析/教育培训 → 教育与图表（#10）

### Q: 幻灯片数量建议？
A:
- 快速概览：5-8页
- 深度报告：10-15页
- 完整演示：15-25页

### Q: 如何平衡分析深度与输出速度？
A:
- 快速需求 → 优先执行市场复盘 + 关键指标
- 深度需求 → 执行完整多维度分析流程
