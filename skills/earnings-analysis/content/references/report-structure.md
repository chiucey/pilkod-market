## Formatting Checklist

- [ ] Font: Times New Roman throughout
- [ ] Page margins: 1 inch all sides
- [ ] Page numbers: bottom right
- [ ] Header: "Earnings Update — [Company] [Ticker] — [Date]"
- [ ] Chart source footnotes: Times New Roman 8pt grey
- [ ] Hyperlink color: Blue (#0000FF) with underline
- [ ] Section headers: bold, 14pt, dark blue
- [ ] Body text: 11pt, 1.15 line spacing
- [ ] Table headers: dark blue background, white bold text
