## 1. Skill Overview

### 1.1 What This Skill Does

This skill transforms hardware product development insights into a systematic methodology for creating professional **Market Requirements Documents (MRD)** and **Product Requirements Documents (PRD)**. It provides templates, frameworks, and calculation models applicable to any hardware product category.

### 1.2 When to Use This Skill

Consider using this skill when you need to create product planning documents from scratch, validate existing product concepts, develop business cases for hardware startups, plan product line extensions, or enter new markets with existing technology.

### 1.3 Key Differentiators

- Comprehensive MRD/PRD framework
- Pricing methodology with margin-based approach
- Sales projection models for multiple markets
- Universal templates adaptable to any hardware category

## 4. Pricing Methodology

### 4.1 Cost Structure Framework

The skill uses a generic BOM structure template. Material costs typically include:

- Core modules (WiFi/BT, MIC, Speaker)
- Power module (Charging circuit)
- Main board (PCB + power management)
- Housing (Structure + finish)
- Other components (Connectors, etc.)

### 4.2 Margin-Based Pricing

- Default target: 45% gross margin
- Domestic formula: Cost ÷ (1 - margin)
- Overseas formula: (Cost + logistics) ÷ (1 - margin)

### 4.3 Price Competitiveness Analysis

Evaluate pricing through competitive positioning, assessing value proposition versus cost.

## 6. Best Practices

### 6.1 User Research Excellence

- At least 20 in-depth interviews for qualitative insights
- XX+ survey responses for quantitative validation
- Triangulate findings across multiple data sources

### 6.2 Scenario Development

Develop 5-8 core scenarios covering the full user journey. Each scenario should capture persona, triggers, goals, behaviors, pain points, and emotional transitions.

### 6.3 Feature Prioritization

Apply MoSCoW classification rigorously. Limit Must-have features to ~20% of total.

### 6.4 Pricing Validation

Validate pricing through willingness-to-pay studies. Consider both absolute and relative value perception.

## 7. Quality Assurance

### 7.1 MRD Quality Checklist

- [ ] Market size quantified with data sources cited
- [ ] Target users clearly defined with 3+ personas
- [ ] Pain points validated with evidence
- [ ] Competitive landscape comprehensively analyzed
- [ ] Core scenarios mapped to user journeys
- [ ] Emotional needs identified and prioritized

### 7.2 PRD Quality Checklist

- [ ] Product differentiation clearly articulated
- [ ] Feature priority aligned with user needs
- [ ] Technical specifications feasible and testable
- [ ] Cost model detailed with BOM breakdown
- [ ] Pricing justified with margin targets
- [ ] Sales projections grounded in assumptions
- [ ] Success metrics defined with measurable KPIs
