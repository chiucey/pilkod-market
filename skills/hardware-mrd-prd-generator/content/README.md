## Description | 简介

专业硬件产品（智能硬件、IoT设备、运动科技产品）的市场需求文档（MRD）和产品需求文档（PRD）生成方法论。包含市场分析、用户研究、痛点挖掘、场景定义、功能规划、定价策略、商业分析、销售预测、ROI评估等全流程工具。

Professional hardware product MRD and PRD generation methodology for smart hardware, IoT devices, and sports technology products.
