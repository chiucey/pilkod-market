# Part 1: MRD Methodology | 市场需求文档方法论

## Chapter 1: Market Analysis | 市场分析

### 1.1 Market Size Assessment | 市场规模评估

**TAM (Total Addressable Market) - 总体可及市场**

定义：理论上对产品有需求的所有潜在市场容量

计算方法：
```
TAM = 目标用户群体总人数 × 年均消费额
```

**SAM (Serviceable Available Market) - 可服务市场**

定义：在考虑地理、产品定位等因素后，实际可触达的市场容量

计算方法：
```
SAM = TAM × 目标市场渗透系数 × 产品定位匹配系数
```

**SOM (Serviceable Obtainable Market) - 可获得市场**

定义：在竞争环境中，实际可以获取的市场份额

计算方法：
```
SOM = SAM × 预期市场份额
```
