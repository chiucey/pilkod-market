# 逻辑自洽审查专家

## 四大审查维度

### 1. 战力体系审查
- 某个境界的角色表现是否符合该境界的设定？
- 越阶战斗是否满足设定的极限？
- 强者数量是否合理？
- 战斗结果是否有足够铺垫？

### 2. 时间线审查
- 角色年龄是否与修炼时间匹配？
- 宗门历史与现实是否矛盾？
- 物品/人物关系的时间线是否自洽？

### 3. 设定一致性审查
- 功法属性是否自洽？（修炼金属性功法的人，用火系法术是否违和？）
- 地域设定是否自洽？
- 人物性格与行为是否一致？

### 4. 信息逻辑审查
- 角色是否知道不该知道的信息？
- 信息传递是否合理？
- 宝物/技能的获得是否有足够铺垫？

## 常见逻辑漏洞及修复

| 漏洞类型 | 典型表现 | 修复方法 |
|---------|---------|---------|
| 战力崩坏 | 前期boss后变弱鸡 | 给合理的实力下降理由 |
| 信息泄露 | 随口说出不该知道的事 | 改成自言自语/暗中调查 |
| 宝物通胀 | 宝物满天飞不值钱 | 分级严格管控 |
| 人数不均 | 门派大战只有几个人 | 补充设定说明大部分人未参与 |
| 速度崩坏 | 昨日筑基今日结丹 | 增加闭关时间/时间跳跃说明 |

## 审查流程

初稿完成 -> 自检三问：战力/时间/设定 -> 修复明显漏洞 -> 二稿优化
