# 输出模式参考

本文档提供各类输出的详细结构模板和示例，供技能执行时参考。

## 爆款内容生成模板

### 公众号文章结构

```
【标题备选】
1. [数字/痛点] + [解决方案] + [效果]
2. [反常识认知] + 为什么+怎么办
3. [身份标签] + 必看 + 核心价值

【正文结构】
一、开篇钩子（200字内）
   - 场景描述/痛点共鸣
   - 引发好奇或认同

二、核心内容（分3-4点）
   - 每个观点独立成段
   - 案例+方法论结合
   - 小标题清晰区分

三、结尾行动号召
   - 总结核心要点
   - 引导互动评论
   - 转发收藏邀请
```

### 小红书笔记结构

```
【封面标题】
大数字 + 痛点/爽点 + 解决方案
例：3个习惯 | 让我从月光族到存款10万

【正文】
开头：身份认同 + 痛点引入（3-5行）
正文：干货清单式，每个要点配说明
结尾：总结 + 互动引导（求赞求收藏）

【标签建议】
#标签1 #标签2 #标签3 #长尾词 #热门话题
```

### 抖音文案结构

```
【开头3秒钩子】
- 痛点开场：「你是不是也...」
- 反常识：「大多数人都做错了...」
- 利益前置：「学会这3招，...」

【中间内容】
- 快节奏信息密度
- 每5秒一个小高潮
- 避免平铺直叙

【结尾悬念/引导】
- 引发评论：「你同意吗？」
- 引导关注：「下期讲...」
```

## 信息整理模板

```
• 观点2：[一句话概括]

【金句摘抄】
「引用原文金句」

【我的行动清单】
- [ ] 立即执行：...
- [ ] 本周内：...
- [ ] 长期习惯：...
```

## 短视频脚本模板

### 30秒口播脚本

```
【基本信息】
时长：30秒
类型：口播干货
平台：抖音/视频号

【分镜脚本】

| 镜头 | 时长 | 画面 | 口播台词 |
|------|------|------|----------|
| 1 | 0-3秒 | 近景，正视镜头 | 「你知道吗？大多数人都做错了...」 |
| 2 | 3-10秒 | 近景 | 「第一步，你要先...」 |
| 3 | 10-20秒 | 配合手势 | 「第二步，关键是...」 |
| 4 | 20-28秒 | 总结性画面 | 「最后，只要你做到这两点...」 |
| 5 | 28-30秒 | 近景，微笑 | 「觉得有用就点个赞，我们下期见！」 |

【拍摄建议】
- 背景简洁，光线充足
- 语速稍快，保持活力
- 眼神自然，避免死盯提词器感
```

### 1-2分钟脚本（增加故事线）

```
【结构】
开头（10秒）：痛点共鸣/场景带入
正文（60-90秒）：核心干货分点讲解
结尾（10-20秒）：总结+关注引导

【开头模板】
「上周有个读者问我：...」
「我发现一个特别有意思的现象...」
「我曾经也和你一样，直到...」

【正文节奏】
每15-20秒一个小转折或新知识点
配合字幕强调关键信息
画面切换保持视觉新鲜感
```

## 素材管理维度

### 素材分类标签体系

```
【主题大类】
- 个人成长/职场发展
- 生活方式/消费理财
- 知识干货/技能分享
- 情感关系/家庭生活

【内容形式】
- 干货知识型
- 情感共鸣型

- 产品种草型

【情绪调性】
- 温暖治愈
- 激励热血
- 幽默搞笑
- 冷静理性

【适用平台】
- 微信公众号
- 小红书
- 抖音
- 视频号
- B站
- 微博

【复用优先级】
- P0：可直接用
- P1：需修改后用
- P2：灵感参考
```

## 平台特性速查

| 平台 | 内容风格 | 最佳时长 | 核心指标 |
|------|----------|----------|----------|
| 公众号 | 深度、完整、有价值 | 1000-3000字 | 点赞、在看、分享 |
| 小红书 | 真实、实用、精致 | 300-800字/图集 | 点赞、收藏、评论 |
| 抖音 | 节奏快、有记忆点 | 15-60秒 | 完播率、点赞 |
| 视频号 | 真实、温暖、正能量 | 30秒-3分钟 | 分享、点赞 |
| B站 | 有深度、有趣味 | 5-15分钟 | 弹幕、硬币 |
