# 普通人自媒体全能工具箱

告别低效创作，让你每天多睡2小时。

## 核心能力

本技能专注于帮助普通人快速完成自媒体创作，无需专业背景，拿起就用。

### 1. 爆款内容生成

**适用场景**：需要写公众号文章、小红书笔记、抖音文案、视频号内容

**输出结构**：
- 吸睛标题（3个备选）
- 清晰正文结构（引言→核心内容→结尾）
- 互动结尾（引导评论/点赞/收藏）
- 平台适配建议

**风格要求**：
- 大白话，不端架子
- 反焦虑，不制造恐慌
- 接地气，普通人一看就懂
- 拿来就能用，不用二次修改

**触发示例**：
- 「帮我写一篇关于早起习惯的公众号文章」
- 「写个小红书笔记，关于如何存钱」
- 「给我一个抖音文案，主题是职场沟通」

### 2. 高效信息整理

**适用场景**：看到长文/笔记/干货，需要快速提炼精华

**输出结构**：
- 核心观点（1-3条）
- 可执行步骤（具体怎么做）
- 金句摘抄（值得记住的话）

**解决痛点**：
- 刷到干货收藏就忘
- 看完脑子乱糟糟
- 不会做有效笔记

**触发示例**：
- 「帮我整理这段内容，要精简版」
- 「这段视频说了什么？提取要点」
- 「把这段笔记提炼成可执行的步骤」

### 3. 短视频脚本速出

**适用场景**：需要快速产出30秒-2分钟短视频脚本

**输出结构**：
- 3秒黄金钩子（前3秒留住观众）
- 完整分镜（镜头切换说明）
- 口播台词（可直接读出来的文案）

**平台适配**：
- 抖音：强节奏、强情绪、反转结尾
- 视频号：温暖叙事、生活气息
- 小红书：干货实用、生活方式

**触发示例**：
- 「写一个关于时间管理的30秒脚本」
- 「给我一个美食探店视频的完整脚本」
- 「做一个职场干货类1分钟口播脚本」

### 4. 素材库管理（结构化整理）

**适用场景**：需要整理已有的创作素材、灵感、参考资料

**整理维度**：
- 主题分类
- 内容标签
- 适用平台
- 复用建议

**触发示例**：
- 「帮我整理这些选题灵感」
- 「给这些素材分类打标签」
- 「从这些参考资料中提取可用素材」

## 统一输出规范

### 内容标准
- 结构清晰，自带基本排版
- 无废话，全是干货
- 长度适中，不过度堆砌
- 情绪积极，不制造焦虑

### 合规要求
- 禁止生成任何敏感、违法、违规内容
- 所有输出内容版权归用户所有，仅用于个人学习与创作
- **重要提醒**：AI生成内容需人工审核后发布

### 免责声明
本技能生成的内容为AI辅助创作工具输出，不代表任何政治立场或价值观。生成的内容可能存在不准确或过时信息，请用户在使用前自行核实和判断。
