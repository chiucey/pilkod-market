# PPT与演讲视频自动生成器

全自动化的演示文稿和配套演讲视频生成系统，支持从主题、提纲、页数、时长等参数输入，完成内容策划、图片生成、PPT制作和视频合成的全流程。

## 核心能力

- **内容策划**：根据主题和提纲自动生成详细内容
- **PPT生成**：使用PptxGenJS创建专业级演示文稿
- **配图生成**：为每页内容生成高质量配图
- **语音合成**：生成配套的语音旁白
- **视频合成**：将PPT页面与语音合成为完整视频

## 输入参数

| 参数 | 必填 | 说明 |
|------|------|------|
| topic | 是 | 演示主题 |
| outline | 是 | 演示大纲（可以是简短描述或详细列表） |
| page_count | 否 | 目标页数（默认根据提纲自动计算） |
| duration | 否 | 目标时长（分钟） |
| style | 否 | 风格偏好（商务/简约/创意/学术等） |
| language | 否 | 演示语言（默认跟随用户） |

## 工作流程

### 阶段1：内容策划

1. **解析提纲结构**
   - 如果提纲是简短描述，使用AI展开为详细大纲
   - 如果提纲已是列表形式，按顺序展开每页内容
   - 计算所需页数，确保内容均衡分布

2. **生成每页内容**
   - 封面页：主题 + 副标题 + 视觉元素描述
   - 目录页：主要章节列表
   - 内容页：标题 + 要点 + 详细说明 + 配图描述
   - 结尾页：总结 + 感谢语

3. **时间分配**
   - 根据目标时长分配每页讲解时间
   - 确保视频节奏适中

### 阶段2：视觉素材生成

1. **为每页生成配图**
   - 使用 `images_search_and_download` 搜索相关图片
   - 使用 `image_synthesize` 生成定制化配图
   - 优先使用生成的图片以确保质量和版权

2. **图片要求**
   - 尺寸：16:9 比例（1920x1080）
   - 风格统一，与演示主题契合
   - 避免文字叠加

### 阶段3：PPT制作

1. **初始化项目**
   ```
   使用 pptx-generator 技能创建PPT
   ```

2. **幻灯片结构**
   ```
   - Slide 1: 封面页
   - Slide 2: 目录页
   - Slide 3-N: 内容页（根据提纲）
   - Slide N+1: 总结页
   - Slide N+2: 感谢页
   ```

3. **设计规范**
   - 布局：标题栏 + 内容区 + 页脚
   - 配色：根据风格选择配色方案
   - 字体：标题使用无衬线字体
   - 动画：简洁过渡效果

4. **生成流程**
   - 创建幻灯片对象
   - 添加文本内容
   - 插入配图
   - 应用样式
   - 导出PPTX文件

### 阶段4：语音旁白生成

1. **语音内容准备**
   - 为每页生成讲解文字
   - 控制语速：约150字/分钟
   - 添加适当的停顿标记

2. **语音合成**
   ```
   使用 get_voice_list 选择合适音色
   使用 gen_audios 生成各页语音
   ```

3. **语音参数**
   - 语速：根据时长要求调整
   - 音量：1.0（标准）
   - 情感：根据内容选择（中性/专业/热情）

### 阶段5：视频合成

1. **分页视频生成**
   ```
   使用 images_understand 分析PPT每页内容
   使用 batch_image_to_video 将每页转为视频片段
   ```

2. **音频对齐**
   - 将语音与对应PPT页面同步
   - 计算每页停留时间

3. **最终合成**
   ```
   合并所有片段为完整视频
   添加片头片尾
   导出MP4文件
   ```

## 输出产物

| 产物 | 格式 | 说明 |
|------|------|------|
| PPT文件 | .pptx | 可编辑的演示文稿 |
| 配图素材 | .png/.jpg | 各页配图素材包 |
| 语音旁白 | .mp3 | 各页讲解音频 |
| 演讲视频 | .mp4 | 完整演讲视频 |

## 执行模式

### 完整流程（生成PPT + 视频）
当用户需要完整演示包时执行全部5个阶段

### 快速流程（仅PPT）
当用户仅需要PPT文件时跳过视频相关步骤

### 自定义流程
根据用户指定的参数选择执行特定阶段

## 错误处理

1. **图片生成失败**：回退使用搜索图片或纯色背景
2. **语音合成失败**：使用系统默认语音或跳过语音
3. **视频合成失败**：提供PPT文件和素材包供用户自行合成
4. **参数不足**：主动询问缺失参数或使用默认值

## 质量标准

- PPT结构清晰，层次分明
- 每页内容精炼，重点突出
- 配图与内容高度相关
- 语音节奏适中，表达流畅
- 视频画面清晰，音画同步
