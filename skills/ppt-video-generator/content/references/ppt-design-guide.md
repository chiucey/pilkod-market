## 布局规范

### 标准16:9布局（1920x1080）

```
┌─────────────────────────────────────────────────┐
│  [LOGO]                    [页码]   [日期]      │  <- 顶部栏 (80px)
├─────────────────────────────────────────────────┤
│                                                 │
│                                                 │
│                  内容区域                        │  <- 内容区 (900px)
│                                                 │
│                                                 │
├─────────────────────────────────────────────────┤
│  [章节名]                    [演示主题]          │  <- 底部栏 (100px)
└─────────────────────────────────────────────────┘
```

### 常见页面类型

#### 封面页
```
- 大标题居中
- 副标题在下方
- 装饰性背景
- 日期/演讲者信息
```

#### 目录页
```
- 标题"目录"或"CONTENTS"
- 章节列表
- 可添加编号或图标
- 简洁明了
```

#### 内容页
```
- 左上标题
- 主体内容区域
- 可添加配图
- 右下角页码
```

#### 总结页
```
- 标题"总结"或"要点回顾"
- 主要观点列表
- 简洁有力
```

#### 感谢页
```
- 大字"感谢聆听"
- 联系方式（可选）
- 装饰性元素
```

## 字体规范

### 标题字体

| 层级 | 字号 | 字重 | 示例 |
|------|------|------|------|
| 主标题 | 44pt | Bold | 演示标题 |
| 副标题 | 32pt | SemiBold | 副标题 |
| 章节标题 | 28pt | Bold | 第一章 |
| 页标题 | 24pt | Bold | 页面标题 |

### 正文字体

| 用途 | 字号 | 字重 | 行距 |
|------|------|------|------|
| 正文要点 | 18pt | Regular | 1.5 |
| 详细说明 | 16pt | Regular | 1.6 |
| 注释文字 | 14pt | Regular | 1.4 |

### 推荐字体组合

```
标题：思源黑体 / Noto Sans / 微软雅黑
正文：思源宋体 / Noto Serif / 宋体
英文：Arial / Helvetica / Roboto
代码：Consolas / Monaco / Source Code Pro
```

## 动画效果

### 推荐的过渡效果

| 效果 | 适用场景 | 时长 |
|------|----------|------|
| Fade | 页面切换 | 0.5s |
| Wipe | 内容进入 | 0.3s |
| Zoom | 强调元素 | 0.3s |
| Fly | 元素移动 | 0.4s |

### 动画原则

1. **简洁为主**：避免复杂动画干扰内容
2. **一致性**：同类元素使用相同动画
3. **适度使用**：每页不超过3个动画
4. **提前预览**：确认动画效果符合预期

## 配图规范

### 图片尺寸

| 用途 | 尺寸 | 分辨率 |
|------|------|--------|
| 全页背景 | 1920x1080 | 72dpi |
| 内容配图 | 800x600 | 150dpi |
| 图标 | 128x128 | 300dpi |
| 头像/头像 | 200x200 | 300dpi |

### 图片格式

- 优先使用 PNG（透明背景）
- 照片使用 JPG（压缩优化）
- 图表使用 SVG（矢量可缩放）

### 图片获取策略

1. **AI生成**：`image_synthesize` 生成定制配图
2. **图库搜索**：`images_search_and_download` 搜索相关图片
3. **用户上传**：使用用户提供的高质量图片
