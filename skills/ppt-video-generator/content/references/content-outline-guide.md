# 内容策划与提纲生成指南

## 提纲解析规则

### 1. 简短描述展开

当用户只提供简单描述时，自动扩展为完整大纲：

**输入示例**：
```
主题：人工智能发展趋势
```

**自动展开**：
```
1. 引言：AI的定义与重要性
2. 发展历程回顾
   - 萌芽期
   - 突破期
   - 爆发期
3. 当前技术趋势
   - 大语言模型
   - 多模态AI
   - 边缘计算
4. 应用场景分析
   - 医疗健康
   - 金融科技
   - 智能制造
5. 未来展望与挑战
6. 总结
```

### 2. 列表式提纲处理

当用户提供详细列表时，按顺序分配页数：

**输入示例**：
```
1. 项目背景
2. 项目目标
3. 技术方案
4. 实施计划
5. 预期成果
```

**页面分配**：
- 封面页
- 目录页
- 背景（1页）
- 目标（1页）
- 技术方案（2页）
- 实施计划（1页）
- 预期成果（1页）
- 总结页
- 感谢页

### 3. 页数自动计算

| 内容复杂度 | 每页要点数 | 平均页数 |
|------------|-----------|---------|
| 简单 | 3-4点/页 | 内容点数/3 |
| 中等 | 2-3点/页 | 内容点数/2 |
| 复杂 | 1-2点/页 | 内容点数 |

## 时间分配算法

```
总时长 = 封面(30秒) + 目录(30秒) + 内容页(每页X秒) + 总结(1分钟)

每页时长 = (总时长 - 2分钟) / 内容页数

推荐值：
- 5分钟演示：每页40-50秒
- 10分钟演示：每页50-60秒
- 15分钟演示：每页60-70秒
- 20分钟以上：每页70-90秒
```

## 内容质量标准

### 每页内容结构

```
标题（必需）：
- 简洁明了
- 不超过20字
- 使用关键词吸引注意

要点（必需）：
- 3-5个要点
- 每个要点一句话
- 使用项目符号或编号

详细说明（可选）：
- 支持要点展开
- 保持简洁
- 避免大段文字

配图描述（必需）：
- 具体描述所需图片
- 包含风格、颜色、氛围要求
- 提供画面元素建议
```

### 语音旁白模板

```
【封面页】
"大家好，今天我将为大家介绍【主题】。"

【目录页】
"首先，让我们看一下今天的目录。"

【内容页】
"接下来，我们来看【章节名】。"

【过渡页】
"那么，除了【上一主题】，还有【下一主题】。"

【总结页】
"最后，让我们回顾一下今天的主要内容。"
```
