# 视频合成技术指南

## 视频生成流程

### 阶段1：准备阶段

1. **收集素材**
   - PPT页面图片（每页一张）
   - 语音旁白文件（每个片段一段）
   - 片头/片尾素材（可选）

2. **计算参数**
   ```
   每页时长 = 语音时长 + 过渡时间
   过渡时间 = 0.5秒
   最小停留时间 = 3秒
   ```

3. **创建时间轴**
   ```
   0:00 - 0:05  片头
   0:05 - 0:10  第一页
   0:10 - 0:15  第二页
   ... 以此类推
   最后    片尾
   ```

### 阶段2：分页视频生成

使用 `batch_image_to_video` 工具：

```javascript
{
  "count": 5,
  "image_file_list": ["page1.png", "page2.png", "page3.png", "page4.png", "page5.png"],
  "output_file_list": ["clip1.mp4", "clip2.mp4", "clip3.mp4", "clip4.mp4", "clip5.mp4"],
  "prompt_list": [
    "页面内容讲解中，保持画面稳定",
    "页面切换后的新内容展示",
    "图表数据动态展示",
    "强调要点时的画面效果",
    "过渡到下一个主题"
  ],
  "duration_list": [6, 6, 6, 6, 6],
  "resolution_list": ["1080P", "1080P", "1080P", "1080P", "1080P"]
}
```

### 阶段3：音频处理

1. **语音合并**
   - 按顺序拼接各页语音
   - 确保衔接自然
   - 添加适当间隔

2. **背景音乐（可选）**
   ```
   建议：
   - 轻柔的背景音乐
   - 音量低于语音
   - 添加淡入淡出
   ```

### 阶段4：最终合成

1. **视频合并**
   - 使用 `batch_video_to_video` 或其他工具
   - 按时间轴排列片段
   - 确保画面过渡平滑

2. **音画同步**
   - 将语音与视频合并
   - 调整音量平衡
   - 添加片头片尾

3. **输出设置**
   ```
   格式: MP4
   分辨率: 1920x1080
   帧率: 30fps
   编码: H.264
   音频: AAC 128kbps
   ```

## 视频参数参考

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 分辨率 | 1920x1080 | 全高清 |
| 帧率 | 30fps | 流畅度与文件大小平衡 |
| 码率 | 5000kbps | 高质量视频 |
| 音频码率 | 128kbps | 清晰语音 |
| 视频时长 | 根据内容 | 保持节奏适中 |

## 质量检查清单

- [ ] 所有页面都有对应的视频片段
- [ ] 语音与画面同步
- [ ] 视频无卡顿

- [ ] 片头片尾完整

## 常见问题处理

### 问题1：语音与画面不同步

**解决方案**：
- 重新计算每页时长
- 调整语音片段
- 使用视频编辑软件微调

### 问题2：视频片段不连贯

**解决方案**：
- 添加转场效果
- 统一画面风格
- 使用相同的动画效果

### 问题3：文件过大

**解决方案**：
- 降低视频码率
- 减少帧率到25fps
- 压缩音频码率

### 问题4：部分页面缺少素材

**解决方案**：
- 使用纯色背景代替
- 生成通用配图
- 使用图标填充
