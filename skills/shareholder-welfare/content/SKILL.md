# 股东福利搜索技能

搜索并整理A股上市公司股东回馈福利公告的专业工具。

## 使用场景

- 用户输入"回馈股东福利"搜索近期股东福利活动
- 查询特定公司的股东赠品、试用品申领信息
- 获取股东专享活动的登记日、申领时间等关键信息

## 工作流程

### 1. 获取搜索配置

运行配置脚本获取搜索参数：
```bash
python3 scripts/search_config.py
```

返回包含：
- 搜索关键词列表
- 日期范围（近30天）
- 需排除的关键词（分红、派息等）

### 2. 搜索股东福利公告

使用网络搜索工具，针对以下关键词组合进行搜索：

**核心关键词：**
- 回馈股东
- 股东福利
- 股东赠礼
- 股东赠送
- 股东申领
- 股东专享
- 股东试用品
- 股东礼品
- 股东权益
- 股东活动

**搜索技巧：**
- 优先搜索 `site:cninfo.com.cn` 或 `site:szse.cn` 或 `site:sse.com.cn`
- 结合日期范围过滤
- 排除包含"分红"、"派息"、"送转"、"股权分派"、"现金红利"的结果

### 3. 获取官方PDF公告链接

巨潮资讯网(cninfo.com.cn)是深交所法定信息披露平台，提供官方公告PDF下载。

**PDF链接获取方式：**

#### 方式一：通过搜索页面直接获取
访问巨潮资讯网搜索页面：
```
https://www.cninfo.com.cn/new/search?tab=announcement&keyWord=公司名称+股东
```

在搜索结果中：
1. 点击公告标题进入公告详情页
2. 在详情页中查找"查看PDF"或"下载PDF"按钮
3. 复制PDF链接地址

#### 方式二：通过API获取（推荐）
```bash
# 获取公告PDF链接
python3 scripts/get_pdf_link.py --code 股票代码 --date 公告日期

# 示例
python3 scripts/get_pdf_link.py --code 300908 --date 2026-03-09
```

#### 方式三：手动构造PDF链接
巨潮资讯网PDF链接格式：
```
http://static.cninfo.com.cn/finalpage/{年份}/{公告编号}.PDF
```

**示例：**
- 仲景食品 2026年3月9日公告：
  `http://static.cninfo.com.cn/finalpage/2026/20260309-300908-001.PDF`

**官方来源优先级：**
1. 巨潮资讯网 (cninfo.com.cn) - 首选
2. 深交所官网 (szse.cn)
3. 上交所官网 (sse.com.cn)
4. 公司官网投资者关系页面

### 3. 信息提取与整理

从公告中提取以下关键信息：

| 字段 | 说明 |
|------|------|
| 股票名称/代码 | 公司名称及股票代码 |
| 活动名称 | 福利活动的正式名称 |
| 股权登记日 | 确定股东资格的日期 |
| 申领时间 | 福利申领的具体时间段 |
| 活动时间 | 福利活动的整体时间范围 |
| 参与范围 | 哪些股东可以参与（如持股数量要求） |
| 福利内容 | 具体的赠品或服务内容 |
| 申领方式 | 线上/线下申领渠道 |
| 活动细则 | 详细的参与规则和注意事项 |
| 公告原文 | PDF下载链接 |
| 公告日期 | 公告发布时间 |

### 4. 输出格式

以清晰、简洁的方式呈现结果：

```
📌 [公司名称] ([股票代码])
════════════════════════════════════════
🎁 活动名称: xxx
📅 股权登记日: YYYY-MM-DD
⏰ 申领时间: xxx
📆 活动时间: xxx
👥 参与范围: xxx
🎉 福利内容: xxx
📝 申领方式: xxx
📋 活动细则: xxx
📄 公告原文: [PDF链接]
📢 公告日期: YYYY-MM-DD
```

## 注意事项

1. **排除分红信息**：严格筛选掉分红、派息、送转股等相关公告
2. **时效性**：只搜索近30天内的公告
3. **信息完整性**：尽可能提取所有关键字段，缺失的字段标注"未披露"
4. **来源可靠**：优先使用巨潮资讯网(cninfo.com.cn)、深交所、上交所等官方来源
5. **PDF链接**：提供公告原文的PDF下载链接

## 📄 官方PDF链接获取指南

### 巨潮资讯网 (cninfo.com.cn)
**官网地址**: https://www.cninfo.com.cn

**获取步骤：**
1. 打开巨潮资讯网首页
2. 在搜索框输入公司名称或股票代码（如"仲景食品"或"300908"）
3. 选择"公告"标签页
4. 在公告列表中找到股东福利相关公告
5. 点击公告标题进入详情页
6. 点击"查看PDF"按钮，复制浏览器地址栏中的PDF链接

**PDF链接特征：**
- 域名：`static.cninfo.com.cn`
- 路径：`/finalpage/{年份}/{公告编号}.PDF`
- 示例：`http://static.cninfo.com.cn/finalpage/2026/20260309-300908-001.PDF`

### 深交所 (szse.cn)
**官网地址**: http://www.szse.cn

**获取步骤：**
1. 进入深交所官网 → 信息披露 → 上市公司信息
2. 搜索股票代码或公司名称
3. 在公告列表中找到相关公告
4. 点击PDF图标下载或复制链接

### 上交所 (sse.com.cn)
**官网地址**: http://www.sse.com.cn

**获取步骤：**
1. 进入上交所官网 → 披露 → 上市公司信息
2. 搜索股票代码或公司名称
3. 在公告列表中找到相关公告
4. 点击PDF图标下载或复制链接
