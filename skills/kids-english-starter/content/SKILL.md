# 儿童英语启蒙课程助手

## 核心功能

### 1. 课程方向选择
支持以下英语启蒙主题，分为**词汇积累**和**场景口语**两大类：

#### 词汇积累课程
- **字母学习** (Alphabet)：26个英语字母的发音和书写
- **数字认知** (Numbers)：1-20数字的英语表达
- **颜色识别** (Colors)：基础颜色的英语单词
- **动物世界** (Animals)：常见动物的英语名称
- **食物水果** (Food)：日常食物和水果的英语表达
- **家庭成员** (Family)：家庭成员称呼的英语
- **身体部位** (Body Parts)：身体各部位的英语表达

#### 场景口语课程（重在口语表达）
- **早上起床** (Morning Routine)：起床、穿衣、洗漱的日常对话
- **餐桌时光** (Mealtime)：吃饭、点餐、表达饥饿/口渴
- **超市购物** (Shopping)：挑选商品、询问价格、结账对话
- **公园玩耍** (At the Park)：和朋友玩耍、描述天气、邀请一起玩
- **看医生** (At the Doctor)：表达不舒服、描述症状、配合检查
- **生日派对** (Birthday Party)：祝福送礼物、表达开心、感谢他人
- **学校日常** (At School)：和老师同学打招呼、课堂用语
- **睡前故事** (Bedtime)：洗澡、换睡衣、听故事的睡前对话

### 2. 课程计划生成
根据用户选择的主题，生成包含以下内容的课程计划：
- 课程总数和总时长预估
- 每节课的学习目标（重点标注口语表达目标）
- 核心句型和对话模板
- 建议的学习顺序
- 课后复习和家庭练习建议

### 3. 视频课程
提供与课程配套的视频教程：
- **词汇课程**：每节3-4分钟，包含单词学习、跟读、互动游戏
- **场景口语课程**：每节4-5分钟，包含情境动画、对话示范、跟读练习
- 视频风格：卡通动画为主，色彩鲜艳，吸引儿童注意力
- 包含暂停跟读环节，鼓励孩子开口说英语
- 每个主题包含5-8节课程

### 4. 进度追踪
- 记录每节课的观看状态（未学/学习中/已完成）
- 展示总体学习进度百分比
- 支持从上次中断处继续学习
- 进度数据保存在浏览器本地存储

## 课程特色

### 口语表达优先
- 不仅学习单词，更注重完整句型
- 场景化学习，在真实情境中练习对话
- 提供替换练习，学会举一反三

### 核心句型示例
```
场景：早上起床
- "Good morning, Mom/Dad!"
- "I'm hungry. Can I have some breakfast?"
- "What do you want for breakfast?"
- "I want some milk/bread/eggs."
- "Thank you for the delicious food!"
```

## 使用流程

### 第一步：选择学习主题
用户输入想要学习的英语方向，系统展示可选主题卡片（词汇/场景分类展示）

### 第二步：生成课程计划
系统根据主题生成详细的课程计划，标注每节课的口语学习目标

### 第三步：开始学习
用户选择课程开始学习，观看视频并跟读，系统提供跟读提示

### 第四步：进度追踪
系统自动记录学习进度，用户可随时查看总体进度和单项进度

## 交互示例

**用户输入**："我想让孩子学习超市购物的英语"

**系统响应**：
1. 展示"超市购物"场景口语课程计划
2. 列出5节课程的学习目标：
   - Lesson 1: "I want to buy..." 选购商品
   - Lesson 2: "How much is it?" 询问价格
   - Lesson 3: "Can I have a bag?" 请求帮助
   - Lesson 4: "Here you are!" 结账对话
   - Lesson 5: 场景综合练习
3. 用户确认后进入视频学习界面
4. 记录并展示学习进度

## 技术实现

- 前端使用原生HTML/CSS/JavaScript
- 视频使用第三方视频托管服务
- 进度数据使用localStorage本地存储
- 响应式设计，支持桌面和移动设备
