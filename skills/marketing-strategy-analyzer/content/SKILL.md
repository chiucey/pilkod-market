# 营销策略分析器

系统性地分析产品卖点和用户痛点，输出结构化、可执行的营销策略。

## 工作流程

### 步骤1：信息收集

向用户收集以下核心信息：

**产品信息**
- 产品名称/类型
- 核心功能
- 目标用户群体
- 定价（如适用）
- 差异化特点

**市场背景**（可选）
- 主要竞争对手
- 行业趋势
- 目标市场特征

### 步骤2：产品卖点分析

从以下维度提炼产品卖点：

| 维度 | 分析要点 |
|------|----------|
| 功能价值 | 解决什么具体问题 |
| 情感价值 | 满足什么情感需求 |
| 价格价值 | 性价比优势 |
| 便利价值 | 省时省力程度 |
| 品牌价值 | 信任感和身份认同 |

**输出格式**：
```
核心卖点（N个）：
1. [卖点1] - 对应[痛点/需求]
2. [卖点2] - 对应[痛点/需求]
...
```

### 步骤3：用户痛点分析

按马斯洛需求层次结构化分析：

| 需求层次 | 痛点类型 | 示例 |
|----------|----------|------|
| 自我实现 | 成长、成就 | 技能提升、效率瓶颈 |
| 尊重需求 | 自尊、地位 | 社交认可、专业形象 |
| 社交需求 | 归属、关系 | 团队协作、沟通障碍 |
| 安全需求 | 保障、风险 | 数据安全、资金安全 |
| 生理需求 | 生存、便利 | 成本控制、操作简化 |

### 步骤4：痛点-卖点匹配矩阵

建立痛点与卖点的对应关系：

```
痛点 → 卖点映射：
┌─────────────────────┬─────────────────────┐
│ 用户痛点             │ 对应产品卖点        │
├─────────────────────┼─────────────────────┤
│ [痛点1]              │ [卖点1]             │
│ [痛点2]              │ [卖点2]             │
│ [痛点3]              │ [卖点3]             │
└─────────────────────┴─────────────────────┘
```

### 步骤5：营销策略输出

基于分析结果，输出以下策略：

**1. 价值主张（精简版）**
一句话说明：针对[目标用户]，提供[核心价值]，区别于[竞品]的最大优势是[差异化]。

**2. 核心信息框架**
- 主标题：直击痛点/渴望
- 副标题：产品核心价值
- 支撑点（3个）：功能/情感/信任证据

**3. 传播策略建议**
- 渠道选择：基于目标用户画像
- 内容方向：痛点型 vs 卖点型
- 转化路径：认知→兴趣→决策→行动

**4. 差异化定位**
对比主要竞品，明确：
- 竞争优势
- 竞争劣势
- 机会点

当用户需要快速输出时：

```

2. ...

核心痛点（≤3个）：
1. [痛点]
2. ...

价值主张：[一句话]

营销重点：[核心信息]
```

## 适用场景示例

| 场景 | 输入 | 输出 |
|------|------|------|
| 新品上市 | 产品详情+目标市场 | 完整营销策略报告 |
| 竞品分析 | 产品+竞品信息 | 差异化定位报告 |
| 卖点提炼 | 产品功能列表 | 卖点优先级矩阵 |
| 文案撰写 | 目标用户+痛点 | 核心信息框架 |

## 常见问题处理

**信息不足时**：先输出框架，向用户确认缺失的关键信息
**信息过多时**：优先提取与目标用户最相关的卖点
**多产品线**：分别分析后横向对比，突出各产品定位差异
