# 国际投行焦煤/冶金用煤期货一体化分析工具

## 一、全流程量化执行框架（6个子模块）

本Skill为闭环执行逻辑，按6个连贯子模块顺次自动执行，也支持单独调用任一子模块完成专项分析。所有子模块均内置投行标准量化公式、可自定义参数、Tushare Pro数据自动匹配规则。

---

### 子模块1：中国钢铁供需高频量化校验（Morgan Stanley周度框架）

**核心目标**：完成钢材供需三角校验，拆分地产长材与制造扁平材供需格局，量化地产需求对钢铁产量的边际影响。

**量化公式**：
- 分品种表观消费量 = 周度产量 + 周度进口量 - 周度出口量 + (期初库存 - 期末库存)
- 库存消费比 = 期末总库存 / 周度表观消费量 × 100%
- 供需松紧度分位值 = 本期库存消费比在过去3年同周期数据中的分位数
- 电炉利用率 = 电炉周度实际产量 / 电炉设计周度产能 × 100%
- 高炉开工率 = 高炉周度铁水产量 / 高炉设计周度铁水产×
- 地产需求边际影响系数 = 长材表观消费WoW × (长材表观消费量 / 钢材总表观消费量)

**Morgan Stanley信号规则**：
- 长材表观消费WoW≥0.5%、库存消费比低于50分位 → 高炉开工率环比+0.5~1pct
- 长材表观消费WoW<0、库存消费比高于80分位 → 高炉开工率环比-0.3~0.8pct

### 子模块2：钢铁-焦煤需求传导量化测算（UBS中国基础材料框架）

**核心目标**：将钢铁端数据量化转化为焦煤的表观需求量与供需缺口，完成钢铁→焦煤核心链路传导。

**量化公式**：
- 生铁耗焦煤需求量 = 周度高炉铁水产量 × 吨铁耗焦系数（基准0.55~0.58吨焦煤/吨铁水）
- 焦化厂焦煤需求量 = 周度焦炭产量 × 吨焦耗精煤系数（基准1.33吨精煤/吨焦炭）
- 焦煤总表观需求量 = 生铁耗焦煤 + 焦化厂焦煤 + 其他需求（3~5%固定系数）
- 焦煤供需缺口 = 焦煤总表观需求量 - (国内产量 + 进口量 - 出口量)
- 钢铁-焦煤需求弹性系数 = 焦煤需求量变动率 / 钢材产量变动率（基准0.95~1.05）

---

### 子模块3：全球冶金煤供需平衡量化分析（UBS全球煤炭专家会框架）

**核心目标**：搭建全球焦煤供需平衡表，量化国别价差、贸易流向、供给扰动对国内焦煤的影响。

**量化公式**：
- 全球供需缺口 = 主产国产量合计 - 主消费国进口量合计
- 中澳套利价差 = 中国到岸价 - 澳FOB价 - 海运费（阈值≥$15/吨触发进口窗口）
- 印度CFR价差 = 印度CFR价 - 中国到岸价（阈值>$10/吨触发分流）
- 美煤折价影响：折价每扩大$10/吨 → 中国进口俄煤量环比+5~8%
- 全球价格传导系数 = 国内焦煤价格变动率 / QLD基准价变动率（基准0.7~0.9）
- 供给扰动影响 = (预计减产量 / 全球可贸易量) × 价格弹性系数（基准1.8~2.2）

---

### 子模块4：焦煤期货多因子定价与驱动归因（三大投行整合）

**核心目标**：整合三大投行核心驱动因子，搭建多因子量化定价模型，完成价格归因与趋势判断。

**因子权重**：
| 因子类型 | 核心因子 | 权重 |
|---------|---------|------|
| 需求端 | 高炉开工率、钢材消费增速、地产边际变化 | 45% |
| 供给端 | 国内焦煤产量、进口量增速、全球供给扰动 | 30% |
| 库存与估值 | 焦煤总库存消费比、基差率、钢厂利润 | 15% |
| 宏观与替代 | 动力煤价、原油价格、汇率、地缘风险溢价 | 10% |

**定价模型**：
- Z-score = (本期因子值 - 过去3年均值) / 过去3年标准差
- 综合得分 = Σ(单因子Z-score × 权重)
- 合理价格 = 过去3年均价 × (1 + 综合得分 × 价格波动系数)
- 趋势判断：综合得分≥0.8→上行；≤-0.8→下行；-0.8~0.8→震荡
- 基差率 = (现货价 - 期货主力价) / 现货价 × 100%

---

### 子模块5：产业链风险情景量化回测与压力测试（三大投行情景分析）

**核心目标**：三情景压力测试 + 风险收益比量化，适配期货风控与策略制定。

**三情景框架**：

| 变量 | 乐观情景 | 基准情景 | 悲观情景 |
|------|---------|---------|---------|
| 长材表观消费增速 | 月环比+2%以上 | 月环比0~+1% | 月环比-1%以上 |
| 月度焦煤进口增速 | 月环比-10%以上 | 月环比-5%~+5% | 月环比+10%以上 |
| QLD焦煤基准价变动 | 月环比+15%以上 | 月环比-5%~+5% | 月环比-10%以上 |
| 钢铁限产力度 | 全国高炉限产10%以上 | 无大范围限产 | 限产放松 |

**风险收益比**：
- 风险收益比 = (乐观目标价 - 当前价) / (当前价 - 悲观目标价)
- ≥3:1 → 趋势性策略；1:1~3:1 → 震荡套利；<1:1 → 观望/对冲

---

### 子模块6：投行级投研结论自动化输出

**输出内容**：
1. 产业链核心结论：地产-钢铁-焦煤全链路供需格局、核心边际变化、周期位置
2. 价格判断：主力合约合理价格区间、短期/中期趋势、关键支撑阻力位
3. 交易策略：趋势/套利方向、入场点位、止损止盈、仓位建议
4. 风险提示：上/下行核心风险因素、发生概率、潜在影响幅度

## 五、校验与运行规则

1. **数据三角校验**：钢材供需差与库存变动误差≤2%；焦化耗煤量与采购量误差≤3%；全球进出口量合计误差≤5%，不通过则触发数据复核
2. **异常处理**：Tushare API失败自动切换备用数据源；极端值超出3倍标准差自动标记异常
3. **回测要求**：过去2年价格拟合R²≥0.7；情景回测方向吻合度≥80%，不达标自动优化因子权重
