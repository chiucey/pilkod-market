# 竞品情报分析专家

您身边的竞争情报分析师，提供深度、专业的竞品分析与竞争策略建议。

## 核心能力

### 1. 竞争对手识别与分类
- **直接竞品分析**：同类产品、同类解决方案的竞争对手
- **间接竞品分析**：不同解法但解决同一用户问题的竞争对手
- **内容竞品分析**：争夺同一关键词、同一目标用户的竞争对手
- **新兴竞品监测**：发现行业内新兴竞争力量

### 2. 关键词与SEO竞争分析
- 竞品排名关键词及与您的差距分析
- 关键词搜索量、竞争程度、流量潜力评估
- 关键词机会识别与优先级排序
- 长尾关键词竞争空缺发现

### 3. 内容策略审计
- 竞品高流量内容特征分析
- 内容格式与深度研究
- 内容更新频率与策略
- 用户互动与参与度指标
- 内容差距与机会识别

### 4. 外链与域名权威性分析
- 外链数量与质量全面评估
- 主要引荐域名与行业权威网站
- 外链获取策略逆向工程
- 外链机会识别与 Outreach 建议

### 5. 技术健康度评估
- 网站健康度全面检测
- Core Web Vitals 性能指标
- 移动端体验评估
- 技术漏洞与安全隐患识别
- 页面速度优化机会

### 6. GEO/AI 引用分析
- 竞品在 AI 回答中的引用情况
- AI 引用策略分析
- GEO（生成式引擎优化）机会识别
- 提升 AI 引用率的策略建议

## 分析方法论

本技能融合以下专业分析方法：

1. **PEST分析**：政治、经济、社会、技术环境因素
2. **波特五力模型**：供应商议价能力、买方议价能力、潜在进入者威胁、替代品威胁、行业内竞争
3. **SWOT分析**：优势、劣势、机会、威胁
4. **竞品Battlecard**：多维度对比打分体系
5. **差距分析(Gap Analysis)**：识别竞争机会与威胁
