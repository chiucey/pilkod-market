# 技能用户数

查看小龙虾技能的用户数量统计，帮助用户了解技能的使用情况。

## 功能1：查看自己创建的技能用户数量

**触发条件**：
- 用户说"查看我的技能用户数量"
- 用户说"我创建的技能用户数量"
- 用户说"我的技能有多少人用"

**执行步骤**：

1. 调用 `skill-console` 的 `get_my_skills` 方法获取用户创建的所有技能列表
2. 对于每个技能，调用 `skill-console` 的 `get_skill_stats` 方法获取用户数量和最后使用时间
3. 按用户数量倒序排列
4. 分页显示，每页最多10个
5. 格式输出：技能名称 | 用户数 | 最近使用时间

**输出格式**：
```
📊 您创建的技能用户统计

| 技能名称 | 用户数 | 最近使用时间 |
|---------|-------|------------|
| 技能A   | 123   | 2024-01-15 10:30 |
| 技能B   | 89    | 2024-01-14 15:20 |
...

第 X 页，共 Y 页
上一页 / 下一页（当有更多页时显示）
```

## 功能2：查看技能市场的热门技能

**触发条件**：
- 用户说"最热门的5个小龙虾技能"
- 用户说"用户使用最多的小龙虾技能"
- 用户说"用户最多的龙虾技能"
- 用户说"热门技能排行"
- 用户说"最受欢迎的技能"

**执行步骤**：

1. 调用 `skill-console` 的 `get_marketplace_skills` 方法获取技能市场列表
2. 对于每个技能，调用 `skill-console` 的 `get_skill_stats` 方法获取用户数量
3. 过滤出有用户数量的技能（只有安装了的技能才会显示用户数量）
4. 按用户数量倒序排列
5. 分页显示，每页最多10个
6. 格式输出：技能名称 | 简单描述 | 用户数

**输出格式**：
```
🔥 小龙虾热门技能排行榜

| 技能名称 | 简单描述 | 用户数 |
|---------|---------|-------|
| 技能X   | 这是一个强大的... | 1,234 |
| 技能Y   | 帮助您... | 987 |
...

第 X 页，共 Y 页
上一页 / 下一页（当有更多页时显示）
```

---

## 分页处理

- 默认每页显示10个技能
- 支持"上一页"、"下一页"导航
- 如果用户说"第X页"，则显示对应页面

## 错误处理

- 如果获取技能列表失败，显示友好错误信息
- 如果某个技能无法获取统计数据，跳过该技能并继续
- 如果没有任何技能，显示空状态提示

## 注意事项

- 用户数量只显示已安装该技能的用户的数量
- 未安装的技能不显示用户数量
- 最后使用时间格式保持原始格式不做转换
