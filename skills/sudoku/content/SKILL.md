# 数独求解技能

## 核心原则

数独三大规则：
- 每行包含数字 1-9，且不重复
- 每列包含数字 1-9，且不重复
- 每宫(3x3格子) 包含数字 1-9，且不重复

## 工作流程

### 步骤1：识别数独

接收用户上传的数独图片，使用 OCR/图像识别技术读取 9x9 宫格中的所有数字。

**输入格式：** 用户上传的图片文件(JPG/PNG)

**输出：** 81 位数字的数独数组，0 代表空格

### 步骤2：空白格中的数字推演

每个数字都必须优先使用以下技巧中的一种，如仍未得出答案，则可以选择其它未列明的技巧，必须说明技巧名称。但仍不得使用回溯/搜索算法。

#### 低阶技巧（基础直观法）

| 技巧名称 | 英文名 | 说明 |
|---------|-------|------|
| 唯一数法 | Last Possible Number | 当某行、列或宫中只剩下最后一个空格时，直接填入缺失的数字 |
| 宫内排除法 | Hidden Single in Box | 观察某数字在某宫内因同行列已有该数，只剩一个空格可填 |
| 行列排除法 | Hidden Single in Row/Column | 某行/列缺少的数字，结合对应列/行的分布排除锁定位置 |
| 唯余解法 | Naked Single | 某空格在行、列、宫中已有8个数字，只能填剩下的那个 |

#### 中阶技巧（进阶逻辑推理）

| 技巧名称 | 英文名 | 说明 |
|---------|-------|------|
| 区块排除法 | Block Interaction | 某数字在宫内只能出现在某行/列的两个或三个空格，形成区块排除其他位置 |
| 数对占位法 | Naked Pair | 两空格都只能填相同两数字，这两个数字被锁定，删除其他候选 |
| 隐性数对 | Hidden Pair | 两数字只能填在特定两空格，删除其他候选数 |
| 数组占位法 | Naked/Hidden Triple & Quad | 三/四个空格锁定三/四个数字 |

#### 高阶技巧（复杂结构）

| 技巧名称 | 英文名 | 说明 |
|---------|-------|------|
| X-Wing | X-Wing | 两行某数字只在相同两列出现，矩形顶点排除其他位置该数字 |
| 剑鱼 | Swordfish | 三行某数字只在相同三列出现，排除其他位置该数字 |
| XY-Wing / XYZ-Wing | XY-Wing / XYZ-Wing | 三格候选数关联推导排除 |
| 唯一矩形 | Unique Rectangle | 避免多解的致命模式 |

#### 专家级技巧（复杂链式推理）

| 技巧名称 | 英文名 | 说明 |
|---------|-------|------|
| XY-Chain | XY-Chain | 双值格链式推理 |
| Remote Pair | Remote Pair | 多个显性数对形成长链 |
| ALS-XZ | ALS-XZ | 几乎锁定集之间的强关系 |
| SK-Loop | SK-Loop | 罕见复杂循环链结构 |

#### 大师级技巧（抽象链与集合）

| 技巧名称 | 英文名 | 说明 |
|---------|-------|------|
| 交替推理链 | AIC | 强关系和弱关系交替的逻辑链 |
| 高级鱼结构 | Finned Fish / Sashimi Fish | 带鱼鳍或缺刺的鱼结构 |
| 强制链 | Forcing Chain | 假设推导收敛 |
| BUG+1 | Bivalue Universal Grave + 1 | 避免致命模式 |

**输出要求：** 每成功推导出数字，记录使用的技巧名称

### 步骤3：验证解答

推演完成后，对最终解进行严格验证：
- 检查每行是否包含 1-9 且无重复
- 检查每列是否包含 1-9 且无重复
- 检查每宫是否包含 1-9 且无重复

如果验证失败：重新执行步骤2，尝试更高级的数独技巧

### 步骤4：输出答案图片

将最终解答生成为九宫格图片：
- 保持与原图相同的格式 (JPG/PNG)
- 清晰展示 9x9 解答结果
- 保持原始图片风格

### 步骤5：技巧统计汇总

以表格形式展示推演过程中使用的所有数独技巧及其使用次数。

## 典型触发场景

- 用户：解答这个数独
- 用户：请给出答案
- 用户：帮忙解题
- 用户：[上传数独图片]

## 输出格式

- **答案图片**：九宫格展示完整解答
- **技巧统计表**：汇总所有使用的技巧
- **验证状态**："解答已验证，符合数独规则"

## 注意事项

- 仅使用逻辑推理技巧求解
- 禁止使用任何形式的回溯/搜索算法
- 如果数独无解或无法通过纯技巧求解，应告知用户
