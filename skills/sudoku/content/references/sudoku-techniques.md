# 数独技巧详细参考

本文档提供了数独求解过程中使用的各种技巧的详细说明。

## 1. 低阶技巧（基础直观法）

### 1.1 唯一数法 (Last Possible Number)
**适用场景**：当某行、某列或某宫中只剩下最后一个空格时。

**示例**：
- 如果某行已有8个数字，缺失的那个数字直接填入
- 如果某宫已有8个数字，剩余位置填入缺失数字

### 1.2 宫内排除法 (Hidden Single in Box)
**适用场景**：某个数字在某3x3宫内，由于同行/列已有该数，只剩一个空格可填。

**示例**：
```
某宫：
[1] [ ] [6]
[3] [ ] [ ]
[ ] [ ] [5]

数字8在该宫可能的唯一位置在第二行第二列
```

### 1.3 行列排除法 (Hidden Single in Row/Column)
**适用场景**：某行/列缺少某个数字，结合该数字在其他行列的分布排除锁定位置。

### 1.4 唯余解法 (Naked Single)
**适用场景**：某空格在行、列、宫中已有8个不同数字，只能填剩下的那个。

## 2. 中阶技巧（进阶逻辑推理）

### 2.1 区块排除法 (Block Interaction)
**原理**：当数字在宫内只能出现在某行/列的2-3个空格时，形成"区块"，可排除同行的其他宫内该数字。

### 2.2 数对占位法 (Naked Pair)
**原理**：两空格只能填相同两数字，这两个数字被锁定。
- 可以排除该行/列/宫中其他空格填这两个数字的可能

### 2.3 隐性数对 (Hidden Pair)
**原理**：两个数字只能填在特定两空格（可能还有其他候选数）
- 可以删除这两个空格的其他候选数

### 2.4 数组占位法 (Naked/Hidden Triple & Quad)
**扩展**：三/四个空格锁定三/四个数字

## 3. 高阶技巧（复杂结构）

### 3.1 X-Wing
**结构**：两行某数字只在相同两列出现
```
行2: ... [X] ... [X] ...
行5: ... [X] ... [X] ...

→ 这两列的其他位置排除该数字
```

### 3.2 剑鱼 (Swordfish)
**扩展**：三行某数字只在相同三列出现

### 3.3 XY-Wing / XYZ-Wing
**结构**：三个格子候选数关联推导排除

### 3.4 唯一矩形 (Unique Rectangle)
**目的**：避免多解的致命模式

## 4. 专家级技巧

### 4.1 XY-Chain
**原理**：双值格链式推理

### 4.2 Remote Pair
**原理**：多个显性数对形成长链

### 4.3 ALS-XZ
**原理**：几乎锁定集之间的强关系

## 5. 大师级技巧

### 5.1 AIC (Alternating Inference Chain)
**原理**：强关系和弱关系交替的逻辑链

### 5.2 Finned Fish / Sashimi Fish
**变种**：带鱼鳍或缺刺的鱼结构

### 5.3 Forcing Chain
**原理**：假设推导收敛

### 5.4 BUG+1
**目的**：避免致命模式

## 技巧选择优先级

1. **首先尝试**：唯一数法 > 唯余解法 > 宫内排除法 > 行列排除法
2. **其次尝试**：区块排除法 > 数对占位法 > 隐性数对
3. **再次尝试**：数组占位法 > X-Wing > 剑鱼
4. **最后尝试**：XY-Wing > 唯一矩形 > XY-Chain > AIC > BUG+1

**重要提示**：必须按优先级顺序尝试所有技巧，仅在低级技巧无法解决时才使用高级技巧。
