# 30分钟轻运营规划师 - 参考模板

## 不同目标的计划模板

### 模板1：公众号日更计划（30分钟/天）

| 星期 | 任务 | 时间分配 |
|------|------|----------|
| 周一 | 选题 | 10分钟想3个选题 |
| 周二 | 写稿 | 30分钟写完500字 |
| 周三 | 发布 | 20分钟排版+发布 |
| 周四 | 写稿 | 30分钟写完500字 |
| 周五 | 发布+互动 | 15分钟发布，15分钟回复 |
| 周六 | 复盘 | 15分钟看数据，15分钟想下周选题 |
| 周日 | 休息 | 自由安排 |

### 模板2：短视频/小红书计划（30分钟/天）

| 星期 | 任务 | 时间分配 |
|------|------|----------|
| 周一 | 选题 | 10分钟想1个爆款选题 |
| 周二 | 拍/写 | 25分钟拍摄或写脚本 |
| 周三 | 发布 | 5分钟发布 |
| 周四 | 互动 | 30分钟回复评论、找对标 |
| 周五 | 选题 | 10分钟想下周选题 |
| 周六 | 储备 | 30分钟拍2-3条备稿 |
| 周日 | 休息 | 自由安排 |

### 模板3：副业项目计划（15分钟/天）

| 星期 | 任务 | 时间分配 |
|------|------|----------|
| 周一-周五 | 核心任务 | 15分钟推进一个关键动作 |
| 周六 | 复盘 | 15分钟总结本周+规划下周 |
| 周日 | 休息 | 自由安排 |

## 心态引导话术库

### 开场引导
- "没关系，我们不追求完美，每天只做一点点就够了。"
- "你愿意开始，就已经比80%的人强了。"

### 遇到困难时
- "今天没做到？没关系，明天继续就好了。"
- "计划被打乱很正常，重要的是不要放弃。"

### 取得进步时
- "看，你做到了！这些积累都会慢慢显现的。"
- "比昨天的自己好一点，这就够了。"

### 长期坚持时
- "慢就是快，踏实前行比什么都重要。"
- "你已经坚持X天了，这本身就是胜利。"

## 常见问题应对

### Q：突然有事打断计划怎么办？
A：跳过这一天，不补。明天继续原计划。

### Q：任务完不成怎么办？
A：减少任务量。宁可少做，不要烂尾。

### Q：做了一半不想做了怎么办？
A：先休息5分钟，然后告诉自己"只做5分钟"。通常开始后就会继续。

### Q：看不到效果想放弃怎么办？
A：效果需要时间。先坚持30天再说。
