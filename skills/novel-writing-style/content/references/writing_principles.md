# 创作原则详解

## 核心理念

本书面的写作风格融合了硬科幻的冷静客观与情感文学的细腻感知，目标是让读者在阅读过程中既感受到宇宙的宏大与冷酷，又不失人性的温度。

## 冷热交织的写作技巧

### 什么是"冷"？
- 数字、术语、科学描述
- 报告式的语气
- 客观陈述事实

### 什么是"热"？
- 日常细节
- 人物感受
- 物件与情感的联系

### 如何交织？
不要在"冷"段落之后加"热"过渡，而是直接切。

```
冷：太阳熄灭的计算过程
热：一个女人在给孩子系鞋带

这两段之间不需要任何过渡词。
```

## 历史人物写作检查

当描写历史人物时，确保：

1. **语言习惯**：查找该人物生平的真实语录
2. **性格特征**：不违背已知性格
3. **时代背景**：避免现代用语
4. **社会阶层**：考虑教育、职业背景

示例检查：
- 杜甫：沉郁顿挫，忧国忧民
- 李白：豪放飘逸，自信张扬
- 苏轼：旷达乐观，多才多艺
- 雍正：勤勉刻板，雷厉风行

## 科幻写作的技术要点

### 数字的力量
不要写"很大的数字"，写具体的数字。

- ✓ "光速的0.99倍"
- ✗ "非常快的速度"

### 术语的使用
使用专业术语但不解释。让读者在困惑中感受科技的力量。

### 时间压缩
可以一秒跳一亿年。科幻允许时间尺度的巨大跨越。

## 质量自检指南

写完一段后，用以下问题检查：

| 问题 | 是 | 否 |
|------|----|----|
| 1. 有"人的味道"吗？ | | |
| 2. 有"冷热交织"吗？ | | |
| 3. 有"不相干的细节"吗？ | | |
| 4. 有"没说完"的地方吗？ | | |
| 5. 有"物件替代感受"吗？ | | |
| 6. 结尾没收太满吗？ | | |

至少 4 个"是"才能通过。

## 常见错误

### ❌ 口号式表达
```
错误：人类要团结起来对抗外星入侵！
正确：联合舰队的旗帜在太空中飘扬。旗面上有193个国家的标志。现在只剩三个国家还在运转。
```

### ❌ 悬浮设定
```
错误：这是一个神秘的星球，充满了危险。
正确：氧含量23%，重力1.3G。没有发现大气循环系统。
```

### ❌ 工具人角色
```
错误：主角坚定地说："为了正义，我必须战斗！"
正确：他攥紧拳头。"早饭还没吃完。"他看了眼墙上的挂钟，七点十五分。
```

### ❌ 断裂因果
```
错误：她很伤心。宇宙爆炸了。
正确：她很伤心。宇宙爆炸了。这两件事没有关联。但它们同时发生。
```

## 练习建议

1. 每天写一个"冷热切换"的片段
2. 收集生活中的物件描写
3. 阅读刘慈欣和一十四洲的作品，标注冷热段落
4. 练习"写一半"的技巧
5. 观察生活中的"不相干细节"
