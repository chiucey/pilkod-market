# 高股息优质股票筛选技能

## 触发条件

当用户要求以下操作时触发本技能：
- 筛选高股息股票
- 获取高分红股票名单
- 按股息率排名选股
- 寻找稳定分红股票
- 价值投资选股
- A股高股息分析
- 评估股票分红可持续性

## 筛选框架

### 一、基础剔除条件（必须满足）

| 序号 | 条件 | 说明 |
|------|------|------|
| 1 | 剔除ST、*ST、退市风险股 | 规避退市风险 |
| 2 | 剔除近一年重大财务异常、审计非标、重大处罚 | 规避财务舞弊风险 |
| 3 | 剔除上市未满3年 | 规避次新股分红不稳定 |
| 4 | 剔除长期亏损或最近一年亏损 | 盈利是分红基础 |
| 5 | 剔除流动性过差（日均成交额<5000万） | 确保可交易性 |

### 二、股息条件（核心筛选）

| 序号 | 条件 | 优先级 |
|------|------|--------|
| 1 | 近12个月股息率 > 4% | 必须 |
| 2 | 近3年平均股息率 > 3% | 必须 |
| 3 | 连续分红至少3年 | 必须 |
| 4 | 优先：连续分红5年以上 | 加分项 |

**排除标准**：一次性特别分红导致的虚高股息率（如期末大比例分红）

### 三、分红可持续性（关键评估）

| 指标 | 理想区间 | 说明 |
|------|----------|------|
| 近3年股利支付率 | 20% - 70% | 兼顾股东回报与留存发展 |
| 近3-5年经营现金流 | 正 | 分红资金来源保障 |
| 近3-5年自由现金流 | 大多数年份为正 | 真实盈利能力 |
| 股息支出 vs 自由现金流 | 股息 ≤ FCF的80% | 避免透支分红 |
| 净利润 vs 经营现金流 | 匹配度 > 70% | 盈利质量 |

### 四、财务质量评估

| 指标 | 标准 | 说明 |
|------|------|------|
| 最近一年盈利 | 扣非净利润 > 0 | 基础盈利要求 |
| 近3年扣非净利润 | 不持续恶化 | 趋势健康 |
| ROE | 正且相对稳定 | 股东回报能力 |
| 资产负债率 | < 70% | 财务杠杆可控 |
| 利息保障倍数 | > 3 | 偿债能力 |
| 应收账款/存货 | 无明显异常恶化 | 资产质量 |

### 五、估值条件

| 指标 | 要求 | 说明 |
|------|------|------|
| PE | > 0 | 必须为正 |
| PE vs 行业中位数 | 低于行业 | 相对估值优势 |
| PB vs 行业中位数 | 低于行业 | 相对估值优势 |
| 股息率 vs 行业中位数 | 高于行业 | 股息优势 |
| 当前估值位置 | 近5年相对低位 | 安全边际 |

### 六、位置条件

| 指标 | 要求 | 说明 |
|------|------|------|
| 股价/估值位置 | 历史中低区间 | 避免追高 |
| 股息率分位 | 近3年较高分位 | 性价比高 |
| 基本面 | 无明显恶化 | 趋势健康 |

## 执行流程

### Step 1: 数据获取

使用 `a-stock-akshare-data` 技能获取A股股票数据：
1. 获取全市场股票列表
2. 获取每只股票的基本财务数据
3. 获取分红历史数据
4. 获取估值数据（PE、PB）
5. 获取现金流数据

### Step 2: 初步筛选

按以下顺序执行筛选：
```
ST/*ST/退市风险股 → 上市不足3年 → 流动性差 → 近一年亏损 → 股息率不达标
```

### Step 3: 可持续性评估

对通过初筛的股票计算：
- 连续分红年数
- 平均股利支付率
- 经营现金流趋势
- 自由现金流趋势
- 盈利与现金流匹配度

### Step 4: 财务质量评分

计算综合评分：
```
财务得分 = ROE得分 × 0.25 + 负债得分 × 0.20 + 盈利得分 × 0.30 + 资产质量得分 × 0.25
```

### Step 5: 估值位置分析

计算：
- PE/PB相对行业分位
- 股价历史分位
- 股息率历史分位

### Step 6: 综合排序

综合评分公式：
```
综合得分 = 股息质量分 × 0.30 + 可持续性分 × 0.25 + 财务质量分 × 0.20 + 估值优势分 × 0.15 + 位置分 × 0.10
```

## 关键指标说明

| 指标 | 计算方式 | 理想值 |
|------|----------|--------|
| 股息率 | 近12个月分红/当前股价 | > 4% |
| 股利支付率 | 分红/净利润 | 20%-70% |
| 自由现金流 | 经营现金流 - 资本支出 | 正且稳定 |
| ROE | 净利润/净资产 | > 10%稳定 |

## 风险提示

1. 股息率基于历史分红，不代表未来分红
2. 周期股高股息可能不可持续
3. 需关注公司基本面变化
4. 分散投资降低单只股票风险
