# 财务质量评估指标

## 一、盈利能力评估

### 1.1 净利润指标

| 指标 | 计算公式 | 评估标准 |
|------|----------|----------|
| 最近一年净利润 | 直接取值 | > 0（必须） |
| 近3年净利润趋势 | 线性回归斜率 | 正或持平为佳 |
| 扣非净利润 | 净利润 - 非经常性损益 | > 0 且不持续恶化 |

### 1.2 ROE（净资产收益率）

```python
ROE = 净利润 / 平均净资产 × 100%
```

**评估标准**：
| ROE区间 | 评分 | 说明 |
|---------|------|------|
| > 15% | 优秀 | 股东回报极佳 |
| 10% - 15% | 良好 | 回报稳定 |
| 5% - 10% | 一般 | 尚可接受 |
| < 5% | 较差 | 资本效率低 |

**稳定性评估**：
```python
# ROE波动系数
roa_volatility = std(roa_3y) / mean(roa_3y)
if roa_volatility < 0.3:
    roa_stability = "稳定"
elif roa_volatility < 0.5:
    roa_stability = "波动"
else:
    roa_stability = "剧烈波动"
```

### 1.3 毛利率与净利率

```
毛利率 = (营业收入 - 营业成本) / 营业收入 × 100%
净利率 = 净利润 / 营业收入 × 100%
```

**评估标准**：
- 毛利率稳定或上升：优秀
- 净利率 > 10%：良好
- 毛利率持续下降：风险信号

## 二、负债与偿债能力

### 2.1 资产负债率

```python
资产负债率 = 总负债 / 总资产 × 100%
```

**评估标准**：
| 资产负债率区间 | 评价 | 适用行业 |
|---------------|------|----------|
| < 50% | 优秀 | 保守型公司 |
| 50% - 60% | 良好 | 稳健型公司 |
| 60% - 70% | 一般 | 正常经营 |
| > 70% | 风险 | 杠杆过高 |

### 2.2 利息保障倍数

```python
利息保障倍数 = EBIT / 利息支出
（EBIT = 净利润 + 利息支出 + 所得税）
```

**评估标准**：
| 利息保障倍数 | 评价 |
|-------------|------|
| > 5倍 | 优秀 |
| 3 - 5倍 | 良好 |
| 1.5 - 3倍 | 一般 |
| < 1.5倍 | 风险 |

### 2.3 流动比率与速动比率

```python
流动比率 = 流动资产 / 流动负债
速动比率 = (流动资产 - 存货) / 流动负债
```

**评估标准**：
- 流动比率 > 1.5：短期偿债能力强
- 速动比率 > 1：短期偿债能力良好

## 三、现金流质量

### 3.1 经营现金流评估

**核心指标**：
| 指标 | 计算 | 评估 |
|------|------|------|
| 经营现金流净额 | 直接取值 | > 0（必须） |
| 经营现金流/净利润 | 比值 | > 80%（优秀） |
| 近3-5年经营现金流趋势 | 趋势分析 | 多数年份为正 |

### 3.2 自由现金流评估

```python
自由现金流 = 经营现金流净额 - 购建固定资产等投资支出
```

**评估标准**：
| 情况 | 评价 |
|------|------|
| 连续3年以上FCF为正 | 优秀 |
| 大多数年份FCF为正 | 良好 |
| FCF经常为负 | 风险 |

### 3.3 盈利与现金流匹配

```python
匹配度 = min(净利润, 经营现金流) / max(净利润, 经营现金流) × 100%
```

**评估标准**：
- > 80%：优秀（盈利真实）
- 60% - 80%：良好
- < 60%：存疑（盈利质量可能有问题）

## 四、资产质量

### 4.1 应收账款评估

**核心指标**：
```python
# 应收账款周转天数
DSO = 应收账款 / 营业收入 × 365

# 应收账款增速 vs 营收增速
if 应收账款增速 > 营业收入增速 × 1.5:
    # 存在放宽信用政策风险
```

**评估标准**：
| 指标 | 评价 |
|------|------|
| DSO < 90天 | 优秀 |
| DSO 90-120天 | 良好 |
| DSO > 120天 | 一般 |
| DSO持续恶化 | 风险 |

### 4.2 存货评估

**核心指标**：
```python
# 存货周转天数
DIO = 存货 / 营业成本 × 365

# 存货增速 vs 营收增速
if 存货增速 > 营收增速 × 1.3:
    # 存在滞销风险
```

**评估标准**：
| 指标 | 评价 |
|------|------|
| DIO稳定或下降 | 优秀 |
| DIO小幅上升 | 良好 |
| DIO大幅上升 | 风险 |

### 4.3 商誉占比

```python
商誉占比 = 商誉 / 总资产 × 100%
```

**评估标准**：
- < 10%：安全
- 10% - 30%：关注
- > 30%：风险（减值风险）

## 五、综合财务评分

def financial_quality_score(stock):
    # 盈利能力 (30分)
    if roe >= 15 and roe_volatility < 0.3:
        profit_score = 30
    elif roe >= 10:
        profit_score = 25
    elif roe >= 5:
        profit_score = 15
    else:
        profit_score = 5

    # 负债水平 (25分)
    if debt_ratio < 50:
        debt_score = 25
    elif debt_ratio < 60:
        debt_score = 20
    elif debt_ratio < 70:
        debt_score = 15
    else:
        debt_score = 5

    # 现金流质量 (25分)
    if fcf_positive_years >= 3 and cash_match >= 80:
        cash_score = 25
    elif fcf_positive_years >= 2:
        cash_score = 20
    else:
        cash_score = 10

    # 资产质量 (20分)
    if goodwill_ratio < 10 and dso_stable and dio_stable:
        asset_score = 20
    elif goodwill_ratio < 30:
        asset_score = 15
    else:
        asset_score = 5

    return profit_score + debt_score + cash_score + asset_score

## 六、风险信号清单

### 6.1 硬性排除信号
- [ ] 净利润连续2年为负
- [ ] 审计报告为非标（保留意见、无法表示意见）
- [ ] 被证监会立案调查
- [ ] 资产负债率 > 80%
- [ ] 利息保障倍数 < 1

### 6.2 软性警示信号
- [ ] 应收账款增速持续高于营收
- [ ] 存货周转天数持续上升
- [ ] 经营现金流连续2年低于净利润
- [ ] ROE持续下降超过2年
- [ ] 商誉占总资产比例 > 30%
- [ ] 分红来源依赖借款或资产出售
