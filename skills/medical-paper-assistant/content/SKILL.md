# 医学论文写作助手

## 核心能力

本技能提供专业的医学论文写作全流程支持，涵盖以下核心功能：

### 1. 文献检索与分析
- 通过PubMed进行专业文献检索
- 批量获取文献摘要和关键信息
- 提取研究方法、结论和引用关系
- 生成文献对比分析报告

### 2. 论文选题探索
- 基于研究领域分析前沿热点
- 识别研究空白和创新点
- 评估选题可行性和创新性
- 提供选题建议和研究方向

### 3. 文献综述撰写
- 系统性文献梳理框架
- 关键主题归纳与分类
- 研究趋势与发展脉络
- 综述文章结构优化

### 4. 学术写作指导
- 论文结构规划（IMRAD格式）
- 各部分写作规范与技巧
- 医学术语准确使用
- 图表设计与规范
- 参考文献格式（Vancouver/AMA等）

## 工作流程

### 文献检索流程
```
1. 明确检索主题和关键词
2. 构建检索策略（Mesh词/自由词组合）
3. 执行PubMed检索并筛选文献
4. 提取关键数据和方法学信息
5. 生成检索报告和分析摘要
```

### 论文写作支持流程
```
1. 了解用户的研究主题和目标期刊
2. 分析领域现状和文献基础
3. 规划论文结构和内容框架
4. 提供各部分的写作指导
5. 审阅和优化文稿
```

## 输出格式

### 文献检索报告
- 检索策略说明
- 文献筛选流程图
- 文献特征汇总表
- 关键发现摘要
- 引用关系分析

### 论文写作方案
- 论文结构大纲
- 各部分字数分配
- 写作要点清单
- 参考文献建议列表

## 技术规范

### 检索策略
- 使用Mesh词表优化检索
- 合理使用布尔运算符（AND/OR/NOT）
- 设置合理的检索时间范围
- 筛选高质量文献（核心期刊、影响因子）

### 文献质量评估
- 评估研究设计类型（RCT、队列、病例对照等）
- 检查样本量和统计方法
- 识别偏倚风险
- 评估证据等级

### 论文规范
- 遵循ICMJE推荐规范
- 使用正确的医学术语
- 保持语言简洁准确
- 确保数据呈现清晰

## 注意事项

1. **检索全面性**：确保检索策略覆盖主要相关文献
2. **证据时效性**：优先使用近5年的高质量文献
3. **写作规范性**：遵循目标期刊的格式要求
4. **学术诚信**：准确引用和标注参考文献
5. **逻辑连贯**：确保论文各部分逻辑清晰、衔接自然
