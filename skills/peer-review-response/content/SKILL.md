# peer-review-response

## 功能

根据审稿意见，生成符合杜老师习惯的审稿回复。

## 使用方法

收到审稿意见原文（粘贴发送）后，直接调用本 skill。

## 输入

- 论文全文或摘要（用于写一句话总结）
- 审稿意见原文（逐条粘贴）

## 输出格式（严格遵循以下规范）

```
[一句话总结全文核心工作，不超过50字]

回复审稿意见：

1. [主要意见1，直接描述问题，无分号]
2. [主要意见2，直接描述问题，无分号]
3. [主要意见3，直接描述问题，无分号]
4. [主要意见4，直接描述问题，无分号]
5. [主要意见5，直接描述问题，无分号]
```

## 杜老师审稿回复习惯（必须严格遵循）

| 要素 | 规范 |
|------|------|
| 总结句 | 一句话概括核心工作，≤50字 |
| 意见数量 | **固定5条**，选最重要的5条，不多不少 |
| 标点 | **不使用分号（；）**，每条意见独立成句/句群 |
| 表达 | 像人写的回复，不用刻意对仗工整，不用"审稿人指出"等套话 |
| 语言 | 中文文章→中文回复；英文文章→英文回复 |

## ⚠️ 禁止出现

- 分号（；）出现在意见描述中
- "以下""如下"等提示语紧跟标点
- 过多分层编号（① ② ③ 或 1.1 1.2 等）
- "审稿人指出/认为/建议"等套话开头

## 示例

**输入：** [论文摘要 + 5条审稿意见]

**输出：**

本研究利用视频头脉冲测试（vHIT）扫视波定量分析鉴别梅尼埃病与前庭性偏头痛患者。

回复审稿意见：

1. 样本量较小，建议增加样本或说明局限性
2. 分期标准应明确是哪一版分期标准
3. 部分统计方法描述不够详细
4. 讨论部分对机制探讨不够深入
5. 图表可读性有待提高
