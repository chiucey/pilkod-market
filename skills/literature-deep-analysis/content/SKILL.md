# 文献深度解析助手

## 技能定位

本技能专为深度解析学术文献而设计，支持多种输入格式（PDF、文本、网页链接），提供结构化的中文分析报告，帮助用户全面理解文献的核心内容、研究方法、创新点和领域价值。

## 核心工作流程

### 一、文献内容简介

用3~5句话概括文献的核心内容，包括：

- **研究背景**：阐明要解决的主要问题或研究动机
- **研究方法**：高度概括采用的关键思路或方法（不展开细节）
- **主要发现**：概括研究的主要结论或贡献

### 二、原文阅读

从文献中挑选3~5个重要章节或段落进行深度分析：

- **引言**：问题陈述、研究动机
- **方法**：核心实验步骤、技术路线
- **结果**：关键实验数据、重要发现
- **讨论**：核心结论、理论意义

对每个选中的段落，依次执行：

1. **原文摘抄**：完整复制原文（保持原始语言）
2. **逐句翻译**：将原文逐句翻译为中文
3. **解析说明**：简要说明选择理由、核心含义、在研究中的作用

**输出格式**：
```
### 段落 [N]

**原文**：
[完整摘抄的原文内容]

**翻译**：
[逐句中文翻译]

**解析**：
[选择理由和核心含义说明]
```

### 三、创新点分析

提取文献的1~3个核心创新点，每个创新点需详细解释：

1. **解决的问题**：它解决了什么已有问题或局限？
2. **本质区别**：与现有方法/理论相比的根本差异是什么？
3. **领域意义**：为何该创新对领域发展有重要价值？

### 四、试验方法（技术）详解

全面、详细地介绍文献采用的试验方法或关键技术：

- **技术原理**：用通俗易懂的语言解释技术原理
- **操作流程**：详细描述实验步骤和操作流程
- **创新设计**：说明相比传统方法的改进之处
- **流程图**：使用Mermaid流程图展示实验流程

### 五、领域背景与拓展阅读

- **领域概述**：用2~3句话介绍文献所属研究领域及当前热点
- **拓展文献推荐**：推荐3篇相关文献
  - 1篇奠基性/经典文献
  - 1篇相近方向的最新文献
  - 1篇视角互补的综述或方法文献

### 六、问答交互

完成上述分析后，主动提示用户可以进行深入讨论：

> "以上是初步解析，您对该文献有任何具体问题，可以随时向我提问。"

对用户后续问题，基于文献内容准确、具体地回答。若问题超出文献范围，应明确说明并尝试提供相关线索。

## 输出格式规范

- 使用清晰的分段标题（如「一、文献内容简介」「二、原文阅读」等）
- 关键术语首次出现时加粗或给出简短解释
- 简介、创新点、方法解释建议用无序列表分点说明
- 原文阅读部分使用分段分隔，确保每段都有原文、翻译、解析三部分
- 拓展文献部分使用编号列表，标注类型（经典/前沿/综述/互补）

## 工具使用策略

### 文献输入处理

| 输入格式 | 处理方式 |
|---------|---------|
| PDF文件 | 使用 `extract_pdfs_full_content` 或 `extract_pdfs_key_info` 提取内容 |
| 粘贴文本 | 直接分析文本内容 |
| 网页链接 | 使用 `extract_content_from_websites` 提取内容 |

### 信息获取

- 使用 `batch_web_search` 搜索领域背景和相关文献
- 使用 `extract_content_from_websites` 获取补充信息
- 必要时使用 `mcp__matrix__images_understand` 分析图表

## 质量标准

1. **准确性**：准确理解文献内容，避免误解或遗漏关键信息
2. **完整性**：覆盖所有六个核心模块，不遗漏重要内容
3. **专业性**：使用准确的学术术语，同时保持通俗易懂
4. **实用性**：提供有价值的分析视角和拓展阅读建议

## 完成标志

当完成以下全部内容时，技能执行完毕：

- [ ] 文献内容简介（3~5句话概括核心内容）
- [ ] 原文阅读（3~5个重要段落，含原文、翻译、解析）
- [ ] 创新点分析（1~3个创新点详细解释）
- [ ] 试验方法详解（含原理、流程、创新点，可视化展示）
- [ ] 领域背景与拓展阅读（领域概述+3篇推荐文献）
- [ ] 问答交互引导（提示用户可进一步提问）
