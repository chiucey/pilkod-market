# AI辅助内容创作

## 核心价值主张

本Skill为您提供用AI工具提升小红书内容创作效率的完整指南。从工具选择到提示词工程，从内容生成到人工优化，帮您打造高效的内容生产流水线。

## AI工具选择指南

### 主流AI写作工具

ChatGPT：通用型AI，适合生成文案框架、大纲、标题等。优势是逻辑清晰、生成速度快。

Claude：长文本处理能力强，适合生成深度内容、案例分析等。优势是内容更加细腻。

国内工具：文心一言、通义千问等更适合中文语境，对国内热点更敏感。

### 专业创作工具

专门针对小红书优化的AI工具通常内置了平台调性和爆款逻辑，更适合直接生成小红书风格内容。

图片生成AI如Midjourney、DALL-E可用于生成封面图和配图。

视频AI如剪映AI、万兴播爆可用于生成视频脚本和数字人视频。

## 提示词工程技巧

### 高质量提示词结构

角色设定：告诉AI你是谁，你擅长什么。例如"你是一位资深小红书博主，擅长种草文案"。

任务描述：明确需要AI完成什么任务。例如"帮我生成5个小红书爆款标题"。

背景信息：提供必要的上下文。例如"产品是敏感肌适用的精华液"。

输出要求：指定输出格式和风格。例如"每个标题15-20字，带有数字和情绪词"。

### 爆款标题提示词示例

```
请生成10个小红书爆款标题，要求：
1. 针对敏感肌精华液这个产品
2. 每个标题15-25字
3. 包含痛点+解决方案结构
4. 使用情绪词增加吸引力
5. 至少3个标题包含数字
```

### 文案生成提示词示例

```
请生成一篇小红书种草文案，要求：
1. 产品：XX品牌敏感肌精华液
2. 目标用户：25-35岁都市女性
3. 文章结构：痛点引入→产品介绍→使用体验→效果展示→总结推荐
4. 风格：真实、自然、有温度
5. 字数：500-800字
6. 包含emoji和话题标签
```

## AI+人工优化流程

### 内容生产流水线

AI生成→人工筛选→结构优化→情感润色→发布。

AI负责快速生成初稿和提供灵感，人工负责注入灵魂和把控质量。

### 优化重点

保留AI内容的框架和逻辑，但加入个人经历和真实感受。

检查AI内容的准确性和真实性，避免出现虚假信息。

调整语言风格，使其更符合个人账号的调性。

## 效率提升实战

### 日更内容方案

利用AI实现小红书日更：早上用AI生成3个选题，中午用AI生成内容初稿，下午人工修改并发布。

批量生产：用AI同时生成多个选题的内容初稿，批量修改后发布。

### 内容复用策略

一篇长内容拆分成多篇短内容。一篇图文内容改编成视频脚本。一篇内容改编成不同角度的版本。

## 注意事项与避坑

### AI内容常见问题

过于模板化：AI生成的内容可能缺乏独特性，需要加入个人特色。

事实错误：AI可能生成不准确的信息，需要人工核实。

缺乏情感：AI内容可能过于平淡，需要加入真实情感。

### 合规使用建议

AI是辅助工具，不是替代工具。最终发布的内容必须是自己审核过的。

避免直接发布AI生成内容而不做任何修改，这可能影响账号权重。

标注AI辅助创作可以增加用户信任，也是负责任的做法。
