# 初次见面问题清单

## 问题分类框架

```
┌─────────────────────────────────────────────────────────────────┐
│                    初次见面问题清单（6大类）                       │
├─────────────────────────────────────────────────────────────────┤
│  1. 技术与产品 ← 验证技术真实性与领先性（含国际对比）              │
│  2. 市场与客户 ← 验证市场需求与获客能力                          │
│  3. 商业与财务 ← 验证商业模式可行性                              │
│  4. 团队与治理 ← 验证团队稳定性与执行力                          │
│  5. 竞争与护城河 ← 验证壁垒持续性                              │
│  6. 融资与退出 ← 验证资本市场认可度                              │
└─────────────────────────────────────────────────────────────────┘
```

## 技术与产品问题（必问）

| 序号 | 问题类型 | 具体问题 | 观察要点 |
|------|----------|----------|----------|
| T1 | 技术真实性 | "能否展示核心技术的demo或测试数据？" | 数据的完整性、真实性 |
| T2 | 技术国际对比 | "核心技术指标与国际/国内竞品对比，数据来源？" | 技术验证、第三方测试 |
| T3 | 竞争定位 | "国际巨头/国内龙头是否已有同类技术？你们差异？" | 竞争定位、技术壁垒 |
| T4 | 技术成熟度 | "技术成熟度在哪个阶段？TRL等级？" | 产业化风险 |
| T5 | 量产准备 | "量产工艺是否打通？良率多少？" | 量产可行性 |
| T6 | 专利布局 | "核心专利布局？是否覆盖关键工艺？" | 壁垒完整性 |
| T7 | 高校竞争 | "高校/科研院所有无同类技术？产业化进度？" | 技术来源、潜在竞争 |

## 市场与客户问题（必问）

| 序号 | 问题类型 | 具体问题 | 观察要点 |
|------|----------|----------|----------|
| M1 | 市场需求 | "目标客户的痛点是什么？现有方案有何不足？" | 需求真实性 |
| M2 | 客户验证 | "已有客户POC或订单？头部客户接触进展？" | 客户认可度 |
| M3 | 市场策略 | "如何切入大客户供应链？直销or代理？" | 销售路径 |
| M4 | 市场规模 | "目标市场的TAM/SAM/SOM分别是多少？" | 市场判断 |
| M5 | 竞品对比 | "客户为什么选择你们而非现有方案？" | 差异化价值 |
| M6 | 客户周期 | "从接触到成交的周期？客户决策链？" | 销售效率 |
| M7 | 时机判断 | "为什么是现在？不是3年前或3年后？" | 技术成熟度、价格临界点 |
| M8 | 痛点量化 | "客户不用你们会怎样？量化损失？" | 痛点真实性 |

## 创始人特质观察

| 期待特质 | 观察方法 | 警惕特质 |
|----------|----------|----------|
| 抗压能力 | 面对挑战时的反应 | 逃避问题、甩锅 |
| 迭代速度 | 对反馈的响应和调整 | 固执己见 |
| 学习能力 | 对陌生领域的吸收速度 | 只在自己舒适区 |
| 坦诚度 | 对问题/风险的承认程度 | 过度包装、回避质疑 |

## 团队结构评估

| 关键角色 | 核心要求 | 验证方法 |
|----------|----------|----------|
| 技术负责人 | 技术实战经验、产品落地能力 | 论文/项目/产品佐证 |
| 产品负责人 | 场景理解、需求转化能力 | 过往产品经验 |
| 销售/增长 | 目标客户资源、客情能力 | 客户名单验证 |
| 交付/服务 | 落地能力、客户服务意识 | 客户反馈收集 |

### 团队完整性检查

- 有技术+产品+销售的铁三角
- 技术负责人是否理解商业目标
- 销售是否有行业客户积累
- 交付团队是否能支撑规模化
