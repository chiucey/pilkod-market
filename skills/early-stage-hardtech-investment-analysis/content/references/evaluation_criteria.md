# 多维评估体系详细标准

## 1. 技术壁垒评估（25分）

### 评分标准

| 评分 | 等级 | 标准 |
|------|------|------|
| 21-25 | 极高壁垒 | 全球领先、专利覆盖、难以复制 |
| 16-20 | 高壁垒 | 国内领先、独特工艺、差异化明显 |
| 11-15 | 中壁垒 | 技术改良、存在一定可复制性 |
| 6-10 | 低壁垒 | 容易被逆向、差异化弱 |
| 1-5 | 极低壁垒 | 同质化竞争、无护城河 |

### 评估要点

- 技术是否自主可控
- 专利布局的覆盖度和保护力度
- 核心团队的技术积累深度
- 竞争对手复制难度
- 与国际/国内竞品的技术对比定位

## 2. 技术成熟度评估

| 成熟度等级 | TRL | 评估标准 |
|------------|-----|----------|
| 基础研究 | 1-3 | 原理验证，尚未形成技术方案 |
| 实验室验证 | 4-5 | 实验室环境验证，有demo |
| 原理样机 | 6-7 | 工程样机验证，有小试 |
| 量产定型 | 8-9 | 量产验证，有客户验证 |

## 3. 技术护城河评估

| 护城河类型 | 持续性 | 判断标准 |
|------------|--------|----------|
| 专利壁垒 | 高 | 核心专利覆盖、难以绕开 |
| 工艺壁垒 | 高 | 独特工艺know-how、保密协议 |
| 数据壁垒 | 中-高 | 私有数据积累、难以获取 |
| 算法壁垒 | 中 | 持续迭代、先发优势 |
| 工程壁垒 | 中-高 | 复杂集成、定制化程度高 |
| 先发壁垒 | 低-中 | 客户切换成本 |

## 4. 市场空间评估（20分）

| 评分 | 等级 | 标准 |
|------|------|------|
| 17-20 | 巨大市场 | 全球>500亿美元，CAGR>20% |
| 13-16 | 大市场 | 全球100-500亿美元，CAGR>15% |
| 9-12 | 中等市场 | 全球10-100亿美元，CAGR>10% |
| 5-8 | 小市场 | 全球<10亿美元或CAGR<10% |
| 1-4 | 极小市场 | 细分市场有限 |

### 评估要点

- 目标市场的TAM/SAM/SOM
- 市场增速是否符合预期
- 渗透率提升空间
- 政策驱动的增量空间

## 5. 团队实力评估（20分）

| 评分 | 等级 | 标准 |
|------|------|------|
| 17-20 | 顶级团队 | 连续创业者、头部企业高管、院士级专家 |
| 13-16 | 强团队 | 头部企业资深背景、学术带头人 |
| 9-12 | 中等团队 | 有相关经验但非顶级 |
| 5-8 | 一般团队 | 经验较少、存在明显短板 |
| 1-4 | 弱团队 | 经验不足、团队不完整 |

### 创始人背景评估

| 背景类型 | 加分项 | 风险项 |
|----------|--------|--------|
| 行业深耕 | 10年+行业经验、深刻理解客户 | 警惕只懂技术不懂商业 |
| 连续创业 | 有成功退出或关键里程碑 | 警惕失败归因外部 |
| 从0到1 | 从0搭建团队/产品/销售经验 | 警惕只有大厂背景 |
| 可验证交付 | 有可查证的项目/产品成果 | 警惕PPT型创始人 |

### 风险创始人特征

- □ 只有学术title或大厂背景，但缺商业闭环
- □ 过度强调"我有XX大厂背景"而非用户价值
- □ 讲愿景但无法回答"你怎么验证"
- □ 过早谈论"平台化"而非聚焦单一场景
- □ 对竞品了解不足或过度轻视

## 6. 商业模式评估（15分）

| 评分 | 等级 | 标准 |
|------|------|------|
| 13-15 | 优秀模式 | 高毛利、可规模化、壁垒高 |
| 10-12 | 良好模式 | 毛利合理、模式清晰 |
| 7-9 | 一般模式 | 毛利一般、存在不确定性 |
| 4-6 | 较弱模式 | 毛利低、模式待验证 |
| 1-3 | 差模式 | 商业模式不成立 |

### 定价策略评估

| 定价模式 | 适用场景 | 优缺点 |
|----------|----------|--------|
| 按量付费 | 工具型、API产品 | 收入可预测性低，客户风险小 |
| 订阅制 | SaaS类产品 | 收入稳定，续费关键 |
| 人头制 | 协作类产品 | 与用户数挂钩，扩张有瓶颈 |
| 效果付费 | 强结果导向 | 定价难，毛利可能低 |
| 项目制 | 定制化交付 | 难规模化，现金流压力大 |

### 定价合理性判断

- 是否与客户价值匹配
- 毛利率目标（硬科技应>40%）
- 定价是否支撑获客成本回收

## 7. 融资结构评估（10分）

| 评分 | 等级 | 标准 |
|------|------|------|
| 9-10 | 优秀 | 估值合理，资金效率高 |
| 7-8 | 良好 | 估值偏高但可接受 |
| 5-6 | 一般 | 估值偏高，资金用途模糊 |
| 3-4 | 较差 | 估值过高、条件苛刻 |
| 1-2 | 差 | 融资条件极不合理 |

### 评估要点

- 估值是否合理（对比同类项目）
- 融资额是否支撑里程碑
- 资金使用计划清晰度
- 后续融资预期

## 8. 时机窗口评估（10分）

| 评分 | 等级 | 标准 |
|------|------|------|
| 9-10 | 最佳时机 | 政策红利、市场爆发初期 |
| 7-8 | 好时机 | 市场高速增长、政策支持 |
| 5-6 | 一般时机 | 市场平稳、无明显窗口 |
| 3-4 | 较差时机 | 市场已过高峰 |
| 1-2 | 差时机 | 市场萎缩或监管收紧 |

### 评估要点

- 是否处于政策窗口期
- 市场是否处于上升周期
- 竞争格局是否未定型
- 替代技术威胁程度

## 综合评分计算

```
综合得分 = 技术壁垒(25%) + 市场空间(20%) + 团队实力(20%)
         + 商业模式(15%) + 融资结构(10%) + 时机窗口(10%)
```

| 综合得分 | 投资建议 |
|----------|----------|
| 8.5-10 | 强烈推荐，重点跟进 |
| 7.0-8.4 | 推荐，可进入深入尽调 |
| 5.5-6.9 | 谨慎推荐，需补充信息 |
| 4.0-5.4 | 不推荐，关注后续发展 |
| <4.0 | 放弃，寻找更优标的 |
