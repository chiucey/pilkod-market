# 风险与陷阱识别

## 风险分类

| 风险类型 | 典型风险 |
|----------|----------|
| 技术风险 | 流片失败、良率不足、性能不达标 |
| 市场风险 | 客户导入慢、市场不及预期、竞争加剧 |
| 资金风险 | 资金断裂、估值倒挂、后续融资困难 |
| 团队风险 | 核心人员流失、团队内讧 |
| 政策风险 | 监管收紧、出口管制 |
| 供应链风险 | 产能不足、原材料涨价 |

### 风险等级定义

- **极高**：高概率 + 高影响
- **高**：高概率 + 中影响 或 中概率 + 高影响
- **中**：中概率 + 中影响
- **低**：低概率 + 低影响

## 赛道陷阱识别

| 陷阱类型 | 特征 | 识别方法 | 严重度 |
|----------|------|----------|--------|
| 伪需求陷阱 | 看起来有需求，但客户不会付费/迁移 | 追问：真实付费？续费/留存？替代方案？ | 极高 |
| 红海陷阱 | 巨头已覆盖，差异化不足 | 对标竞品后，"唯一优势"是否可持续？ | 高 |
| 伪刚需陷阱 | 只是"更好"不是"必须" | 追问：不做会怎样？能否量化损失节省？ | 高 |

## 硬科技项目常见陷阱

| 陷阱类型 | 描述 | 识别信号 | 应对策略 |
|----------|------|----------|----------|
| PPT融资陷阱 | 只有PPT没有产品 | Demo与实际差距大 | 要求看真实产品/测试报告 |
| 技术领先陷阱 | 技术好但无法落地 | 有技术无客户 | 重点评估量产能力和销售 |
| 技术造假陷阱 | 核心指标夸大 | 数据无法第三方验证 | 要求现场测试/客户验证 |
| 国际差距陷阱 | 与国际巨头差距被掩盖 | 只对比国内竞品 | 要求国际对标分析 |
| 量产难产陷阱 | 小试成功但量产失败 | 工艺问题频发 | 评估量产工艺成熟度 |
| 高校依赖陷阱 | 技术来自高校但未转化 | 核心人员在高校兼职 | 评估技术转让完整性 |
| 大厂碾压陷阱 | 巨头入场即死 | 壁垒无法对抗大厂 | 评估差异化深度 |
| 估值泡沫陷阱 | 估值远超业务支撑 | PS/PB倍数极高 | 要求业务数据匹配 |

## 伪需求快速诊断

**伪需求信号（满足任一即需警惕）**：

- □ 客户说"有兴趣"但不愿付定金
- □ 需求来自"未来预期"而非当前痛点
- □ 用Excel/表单/脚本就能解决
- □ 依赖用户彻底改变习惯
- □ demo好看但落地阻力大（数据/合规/集成）

## 场景真实性评估

| 维度 | 评估标准 | 加分项 | 减分项 |
|------|----------|--------|--------|
| 使用频率 | 高频（每日/每周）> 低频（月/季） | 工作流核心环节 | 边缘辅助功能 |
| 决策链条 | 短（单人决策）< 长（多层审批） | 2-3人决策 | >5人决策链 |
| 痛点强度 | 客户愿意付多少钱/时间/风险解决 | 可量化损失 | 模糊痛点 |
| AI价值 | 效率/成本/质量提升可量化程度 | 具体百分比 | "体验提升" |

### 评估公式

```
场景价值 = 使用频率 × 决策权重 × 痛点强度 × AI价值量化度
```

## 价值量化要求

| 量化维度 | 最低要求 | 优秀表现 |
|----------|----------|----------|
| 效率提升 | >30%效率提升 | >3倍效率或节省X人/月 |
| 成本降低 | >20%成本下降 | >50%成本节省 |
| 质量提升 | 可测量指标改善 | 误差率/缺陷率降低X% |
| 收入影响 | 带来可归因收入增长 | 收入增长X%或新创收X万元 |

## 积极信号（Positive Signals）

| 信号类型 | 具体表现 | 权重 |
|----------|----------|------|
| 技术突破 | 流片成功、获得头部客户POC | 高 |
| 客户认可 | 获得头部客户订单或战略合作 | 高 |
| 团队稳定 | 核心成员全职加入、股权落地 | 高 |
| 融资顺利 | 多家机构争抢、超额认购 | 中 |
| 政策利好 | 获得重大政策支持、资质认证 | 中 |
| 竞争壁垒 | 专利获批、技术持续领先 | 中 |

## 警示信号（Warning Signals）

| 信号类型 | 具体表现 | 严重度 |
|----------|----------|--------|
| 技术造假 | 演示数据与实际不符 | 极高 |
| 团队分裂 | 创始人之间矛盾、核心退出 | 极高 |
| 客户虚假 | 所谓头部客户不存在 | 高 |
| 估值虚高 | 估值远超合理区间 | 高 |
| 资金断裂 | 资金耗尽、无法支撑运营 | 高 |
| 大厂碾压 | 巨头推出竞品、市场份额下滑 | 中 |
| 政策收紧 | 出口管制、监管收紧 | 中 |

## 一票否决项

| 否决条件 | 说明 |
|----------|------|
| 技术造假 | Demo与实际能力严重不符 |
| 数据造假 | 核心数据无法验证或夸大 |
| 客户造假 | 所谓客户不存在或未真实使用 |
| 团队缺失 | 核心技术/销售负责人缺失且无招聘计划 |
| 商业模式不成立 | 无论怎么算都赚不到钱 |
