## 参考对比对象分类

| 类别 | 代表性企业/机构 | 评估要点 |
|------|-----------------|----------|
| 国际巨头 | Intel、NVIDIA、TSMC、Caterpillar、Siemens、Bosch等 | 技术天花板、专利壁垒、供应链控制 |
| 国内龙头 | 华为、中芯国际、比亚迪、宁德时代、隆基绿能等 | 国产化能力、成本优势、政策支持 |
| 上市公司 | 各细分赛道龙头 | 资金实力、客户资源、量产能力 |
| 同类初创 | 近3年融资的同赛道项目 | 技术路线差异化、市场切入点 |
| 高校/院所 | 清华、上交、西交、中科院、哈工大等 | 技术先进性、产业化意愿、人才输送 |

## 技术定位判断标准

| 定位 | 定义 | 投资价值 |
|------|------|----------|
| 全球领先 | 技术指标优于国际巨头 | 极高壁垒，优先跟进 |
| 国内领先 | 技术指标优于国内龙头 | 强壁垒，可重点关注 |
| 国际同步 | 与国际巨头技术同步 | 有机会，需验证 |
| 国内追赶 | 接近国内龙头水平 | 存在差距，需观察 |
| 技术落后 | 明显落后于主要竞品 | 风险较高 |

## 竞争格局分析维度

| 分析维度 | 具体内容 |
|----------|----------|
| 全球玩家 | 巨头份额、产品布局、技术路线 |
| 国内玩家 | 上市公司营收、创新企业动态 |
| 潜在进入者 | 跨界巨头、产业链延伸 |
| 替代威胁 | 技术路线迭代、跨界替代 |
| 细分空白 | 未被满足的需求、市场缝隙 |
| 竞争壁垒 | 技术壁垒，品牌壁垒、渠道壁垒 |

## 市场分析维度

| 维度 | 评估内容 | 数据来源 |
|------|----------|----------|
| 市场规模 | 全球/中国/细分市场规模 | 行业报告、券商研究 |
| 市场增速 | CAGR、历史增长率 | 行业报告 |
| 市场驱动因素 | 政策、技术、需求 | 行业研究 |
| 市场天花板 | 潜在空间 | 逻辑推算 |
| 渗透率 | 当前渗透率、趋势 | 行业数据 |
| 周期属性 | 顺周期/逆周期 | 历史分析 |

## 市场规模层级判断

| 层级 | 定义 | 评估要点 |
|------|------|----------|
| TAM | 全球潜在市场总额 | 理论最大值，是否叙事驱动 |
| SAM | 可服务市场 | 你的技术/产品能触达的市场 |
| SOM | 可获得市场 | 当前能力+渠道可触及的目标 |

### 数据质量检查清单

- [ ] 数据来源是否可追溯（权威机构 vs 自估算）
- [ ] 假设条件是否明确（渗透率、CAGR、客单价）
- [ ] 是否基于真实付费行为而非"潜在需求"
- [ ] 竞品数据是否交叉验证
