# 早期硬科技项目投资分析 Skill

## 核心能力

为种子轮、天使轮、Pre-A轮硬科技项目提供标准化、系统化的投资价值评估，涵盖技术、市场、团队、商业模式、融资结构等多维度分析，并生成初次见面沟通策略。

## 分析框架

```
项目信息提取 → 行业研究 → 多维评估 → 价值判断 → 沟通设计 → 投资建议
```

## 评估维度权重

| 维度 | 权重 |
|------|------|
| 技术壁垒 | 25% |
| 市场空间 | 20% |
| 团队实力 | 20% |
| 商业模式 | 15% |
| 融资结构 | 10% |
| 时机窗口 | 10% |

## 评分标准

| 综合得分 | 投资建议 |
|----------|----------|
| 8.5-10 | 强烈推荐，重点跟进 |
| 7.0-8.4 | 推荐，可进入深入尽调 |
| 5.5-6.9 | 谨慎推荐，需补充信息 |
| 4.0-5.4 | 不推荐，关注后续发展 |
| <4.0 | 放弃，寻找更优标的 |

## 核心评估要点

### 1. 技术壁垒评估
- 与国际/国内竞品的技术对比定位
- TRL成熟度等级（1-9）
- 专利布局完整度
- 技术护城河类型（专利/工艺/数据/算法/工程）

### 2. 团队评估
- 创始人背景与特质（抗压、迭代、学习、坦诚）
- 团队完整性（技术+产品+销售+运营）
- 股权结构合理性
- 核心成员稳定性

### 3. 商业模式评估
- 毛利率水平（硬科技>40%为佳）
- 客户获取成本与周期
- 可规模化路径
- 单位经济模型（CAC/LTV/回收周期）

### 4. 赛道陷阱识别
- 伪需求陷阱
- 红海陷阱
- 技术造假陷阱
- 量产难产陷阱
- 估值泡沫陷阱

## 输出内容

1. **项目档案表**：基本信息、产品技术、商业模式、团队信息
2. **行业分析报告**：市场规模、竞争格局、政策环境、国际对比
3. **多维评分表**：6大维度评分与综合得分
4. **SWOT分析**：优势、劣势、机会、威胁
5. **风险矩阵**：6类风险评估与应对策略
6. **初次见面问题清单**：6大类必问问题
7. **投资建议**：推荐/不推荐/有条件推荐

## 一票否决项

- 技术造假（Demo与实际能力严重不符）
- 数据造假（核心数据无法验证或夸大）
- 客户造假（所谓客户不存在或未真实使用）
- 团队缺失（核心技术/销售负责人缺失且无招聘计划）
- 商业模式不成立

## 使用流程

1. **输入**：BP文档、路演材料、行业报告
2. **提取**：从材料中提取项目基本信息
3. **研究**：搜索行业数据、竞争格局、国际对标
4. **评估**：按6大维度评分（含国际对比）
5. **识别**：验证需求真实性与陷阱风险
6. **设计**：针对疑问设计见面问题
7. **输出**：形成完整投资分析报告
