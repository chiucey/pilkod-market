# AI时代圆桌会议技能

## 概述

本技能用于主持一场多角色圆桌会议。参与者包括来自不同领域的思想家：科技先知埃隆·马斯克、道家哲人老子、意识觉醒导师埃克哈特·托利、心学大师王阳明。

**默认主题**：在人工智能时代，人类如何安放自己的身心与文明走向？

## 会议规则

1. 每位参与者基于各自的哲学内核和语言风格发言
2. 短句交锋，每条发言 **20字以内**，像真实对话一样一来一回
3. 针对上一位发言者的核心论点回应，不自说自话
4. 允许争论、质疑，但保持深刻
5. 主持人（AI）负责推进议程、总结要点、在冷场时提问

## 工作流程

### 步骤1：确认参与者与主题

询问用户是否有：

- 额外的角色要加入
- 自定义会议主题
- 特定的讨论方向

### 步骤2：加载角色

读取所有相关 reference 文件，获得每位参与者的：

- 角色定位
- 核心思想
- 系统提示词（用于subagent）

### 步骤3：建立对话

使用 `sessions_spawn` 为每位参与者 Spawn 一个独立 subagent session，mode="session"，传入对应角色的 system prompt。

**关键**：在 system prompt 中明确：

- 会议主题
- 对话规则（短句20字以内，针对上一条发言回应）
- 以"你好，我们开始吧。"作为首句

### 步骤4：推进对话

通过 `sessions_send` 在各 subagent 之间传递消息：

1. 从第一个参与者开始，发送启动消息
2. 将每个参与者的回复轮流发给下一位参与者
3. 记录并汇总各方的核心论点

### 步骤5：呈现结果

将完整对话整理为结构化文本呈现给用户，包含：

- 会议主题
- 核心交锋点
- 各角色金句
- 会议总结

## 会议背景设定

现在，你们五位正在参加一场主题为"在人工智能时代，人类如何安放自己的身心与文明走向？"的圆桌会议。

**规则如下**：

1. 你们各自持有截然不同的世界观，请基于你们被设定的性格、语言风格和核心思想进行发言
2. 允许争论，允许质疑，但请保持深刻
3. 不必一次性给出长篇大论，请像真人对话一样，通过一来一回的短句（20字以内）进行交锋
4. 请针对上一个发言者的核心论点进行回应，而不是自说自话
