# 行政处罚案件材料准备指南

> 依据：《市场监督管理行政处罚程序规定》（总局令第61号，2022年9月29日第二次修正）

---

## 一、行政处罚案件材料准备总览

从投诉举报转化为行政处罚案件时，当事人（或其代理人）需要准备的材料，以及需要注意的执法程序要点。

---

## 二、执法人员办案材料清单

### 立案阶段

| 材料名称 | 依据 | 要点 |
|---------|------|------|
| 立案审批表 | 第19条 | 载明：当事人情况、违法线索来源、立案理由 |
| 两名以上办案人员指定 | 第19条 | 须具有行政执法资格 |
| 证据材料（初查） | 第23条 | 证明存在违法行为+应予处罚+属本部门管辖+未超时效 |

### 调查取证阶段

| 材料名称 | 依据 | 要点 |
|---------|------|------|
| 调查终结报告 | 第48条 | 含：当事人情况、案件来源/调查经过/强制措施、事实/证据、违法行为性质、处理意见/依据、自由裁量理由 |
| 现场笔录 | 第28条 | 时间、地点、事件；办案人员+当事人签名或盖章 |
| 询问笔录 | 第29条 | 个别进行；核对无误后逐页签名 |
| 抽样取证记录 | 第31条 | 当事人到场、加贴封条、开具清单、签名或盖章 |
| 先行登记保存清单 | 第34条 | 当事人+办案人员签名或盖章；交付当事人一份 |
| 查封/扣押决定书及清单 | 第37条 | 依照《行政强制法》程序进行 |
| 电子数据取证记录 | 第26条 | 注明制作方法、制作时间、制作人 |

### 审核阶段

| 材料名称 | 依据 | 要点 |
|---------|------|------|
| 法制审核意见 | 第50-51条 | 重大复杂案件须由法制审核人员审核 |
| 案件审核意见 | 第52条 | 普通程序案件须案件审核 |
| 审核退还材料 | — | 审核后退回办案机构 |

### 告知阶段

| 材料名称 | 依据 | 要点 |
|---------|------|------|
| 行政处罚告知书 | 第57条 | 须书面：拟处罚内容+事实+理由+依据；陈述权+申辩权；听证权（听证范围） |
| 责令退款通知书 | 第59条 | 法律法规要求时 |
| 当事人陈述/申辩材料 | 第58条 | 当事人提出的事实、理由和证据；须依法采纳 |
| 听证申请书及听证笔录 | — | 当事人要求听证时 |

### 决定阶段

| 材料名称 | 依据 | 要点 |
|---------|------|------|
| 行政处罚决定书 | 第62条 | 七项内容（当事人/事实/陈述申辩采纳/处罚内容/履行方式/救济途径/部门+日期） |
| 负责人集体讨论记录 | 第60条 | 第五十条案件须集体讨论 |
| 结案审批表 | 第77条 | 具备结案条件后15个工作日内填写 |

### 执行阶段

| 材料名称 | 依据 | 要点 |
|---------|------|------|
| 罚款缴纳凭证 | 第72条 | 指定银行或电子支付系统缴纳 |
| 加处罚款决定书 | 第75条 | 逾期不缴纳时 |
| 强制执行申请书 | 第76条 | 向人民法院申请 |
| 退还财物清单 | 第42条 | 解除查封扣押时；当事人+办案人员签名 |

## 三、当事人（经营者）应对指南

### 收到调查通知时

| 事项 | 操作建议 |
|------|---------|
| **确认执法人员身份** | 要求出示执法证件（不少于两人） |
| **确认管辖权** | 核查该部门是否有管辖权（违法行为发生地/平台住所地等） |
| **保存证据** | 保留能证明不存在违法行为的证据（进货单据、检验报告、合法经营资质等） |
| **准备陈述申辩** | 如认为不存在违法行为，在告知后5个工作日内提出陈述、申辩 |
| **申请听证** | 涉及重大公共利益/重大权益的案件，在告知后5个工作日内申请听证 |

### 收到处罚决定书时

| 事项 | 操作建议 |
|------|---------|
| **核对基本信息** | 当事人信息、违法事实、处罚依据是否准确 |
| **核对救济途径** | 申请行政复议（60日）/ 提起行政诉讼（6个月）的期限是否正确 |
| **确有困难可申请延期/分期缴纳** | 书面申请，经负责人批准（第74条） |
| **不服决定** | 可在法定期限内申请行政复议或提起行政诉讼 |
| **复议/诉讼期间** | 行政处罚**不停止**执行（法律另有规定除外） |

### 申请法院强制执行时（经营者被动）

| 事项 | 操作建议 |
|------|---------|
| **催告书** | 收到催告书后10个工作日内可提出异议 |
| **确有困难** | 可申请**暂缓或分期缴纳**（须在强制执行前申请） |
| **强制执行** | 法院裁定后，依照法院执行程序处理 |

## 四、行政处罚决定书核对清单

当事人收到行政处罚决定书后，建议逐项核对：

- [ ] **当事人信息**是否正确（名称/姓名/地址）
- [ ] **违法事实**是否与实际情况相符
- [ ] **证据**是否充分（是否有充分证据证明违法事实）
- [ ] **适用依据**是否正确（引用的法律条款是否准确）
- [ ] **处罚种类和幅度**是否在法定范围内（有无明显不当）
- [ ] **陈述申辩**的采纳情况是否在决定书中体现
- [ ] **救济途径和期限**是否正确载明
- [ ] **作出决定的部门**和日期是否正确
