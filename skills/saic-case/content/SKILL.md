# 市场监督管理投诉举报案件处理技能（SAIC-Case）

基于《市场监督管理投诉举报处理办法》（国家市场监督管理总局令第121号，2026年4月15日施行）构建的专业技能。

## 核心能力

- **案件材料审查**：对照《办法》第10-11条，核查投诉/举报材料是否齐备
- **投诉书/举报书起草**：根据《办法》规定的形式要件，起草规范化文书
- **管辖判断**：依据第13-14条（投诉）、第29-33条（举报），确定有管辖权的部门
- **时限监控**：跟踪7日受理、60日调解、15日核查等关键节点
- **程序合规检查**：对照《办法》全文，检查各环节程序是否合法
- **违法线索研判**：分析涉嫌违反的市场监督管理法律法规条款
- **举报策略**：根据第35条重复举报规则，优化举报策略
- **恶意索赔识别**：依据第16条、第42条，识别和应对恶意索赔行为

## 核心法律依据速查

### 《投诉举报处理办法》（总局令第121号）

| 关键条款 | 内容摘要 |
|---------|---------|
| 第3条 | 投诉/举报的定义 |
| 第7条 | 投诉举报禁止滥用权利 |
| 第10-11条 | 投诉提交材料要求 |
| 第15条 | 7个工作日受理决定 |
| 第16条 | 不予受理的七种情形 |
| 第17条 | "非为生活消费"的判断因素 |
| 第23条 | 终止调解八种情形 |
| 第28条 | 举报提交材料要求 |
| 第35条 | 举报处理规则（重复举报、并案处理） |
| 第42条 | 涉嫌敲诈勒索/骗取赔偿移送公安机关 |

### 《行政处罚程序规定》（总局令第61号，2022年修正）

| 关键条款 | 内容摘要 |
|---------|---------|
| 第18-20条 | 立案：线索核查15工作日，立案条件四要素，不予立案情形 |
| 第21-35条 | 调查取证：两人执法、8类证据、先行登记保存7日 |
| 第36-42条 | 查封扣押：30日+30日，委托第三人保管 |
| 第49-55条 | 法制审核（重大案件）与案件审核（普通案件） |
| 第56-59条 | 行政处罚告知：陈述申辩权、听证权、责令退款 |
| 第60-64条 | 处罚决定书内容、公开规定；90日+30日办案期限 |
| 第66-70条 | 简易程序：自然人200元以下/法人3000元以下罚款或警告 |
| 第71-79条 | 执行：15日缴纳、3%加处罚款、申请法院强制执行3个月 |
| 第80-83条 | 送达：直接/留置/电子/邮寄/公告送达五方式 |

## 注意事项

- 本技能依据2026年4月15日施行的总局令第121号构建
- 投诉须证明"为生活消费需要"（第16条第3项）
- 举报须提供"具体线索和事实依据"（第28条）
- 重复举报同一事实不再处理，但补充新事实可合并处理（第35条）
- 涉嫌敲诈勒索、夹带掉包造假等行为须移送公安机关（第42条）
- 调解须双方同意，任何一方拒绝则不能强制调解（第18条）

## 投诉举报与行政处罚程序的衔接

投诉举报中发现违法线索后，依法进入行政处罚程序。两者构成**"前段行政救济+后段行政处罚"**的完整监管链条。

### 衔接触发点

投诉举报中发现违法线索后，核查阶段依《投诉举报处理办法》第27条（15工作日核查）处理；核查属实的，依据《行政处罚程序规定》转入正式立案查处程序。

**常见衔接情形：**
- 举报人提供具体违法线索，市场监管部门核查证实后立案查处
- 投诉调解中发现经营者存在违法行为（如销售过期食品、虚假宣传）
- 同一经营者被多名消费者投诉同一违法行为，线索累积后启动调查

### 衔接中的核心注意事项

| 阶段 | 依据 | 关键要求 |
|------|------|---------|
| **线索核查** | 《投诉举报处理办法》第27条 | 15工作日核查，可+15工作日；核查不中止调解 |
| **移送涉嫌犯罪** | 《投诉举报处理办法》第42条 | 夹带/掉包/造假/敲诈勒索→移送公安机关 |
| **立案决定** | 《行政处罚程序规定》第19条 | 四项立案条件：有证据+应处罚+属本部门管辖+在法定期限内 |
| **调查取证** | 《行政处罚程序规定》第21-35条 | 两人执法；8类证据；先行登记保存7个工作日 |
| **法制审核** | 《行政处罚程序规定》第50条 | 重大复杂案件须法制审核 |
| **处罚告知** | 《行政处罚程序规定》第57条 | 陈述申辩权、听证权、责令退款 |
| **处罚决定** | 《行政处罚程序规定》第60条 | 五种决定类型 |
| **简易程序** | 《行政处罚程序规定》第66条 | 自然人200元以下/法人3000元以下罚款或警告 |

### 投诉举报人不服行政处罚的救济

| 救济途径 | 时限 | 依据 |
|---------|------|------|
| **行政复议** | 知道处罚决定之日起60日内 | 《行政复议法》 |
| **行政诉讼** | 知道处罚决定之日起6个月内 | 《行政诉讼法》 |
| **举报奖励** | 符合奖励条件的，可申请 | 《投诉举报处理办法》第36条 |
