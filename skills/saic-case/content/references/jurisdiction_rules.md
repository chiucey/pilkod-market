# 投诉举报管辖规则详解

## 一、投诉管辖规则

### 基本管辖原则（第13条）

| 被投诉人类别 | 管辖部门 | 法律依据 |
|------------|---------|---------|
| 一般经营者 | 被投诉人**实际经营地或住所地**县级市场监管部门 | 第13条第1款 |
| 电商平台经营者 | 其**住所地**县级市场监管部门 | 第13条第2款 |
| 通过自建网站/其他网络服务的电商经营者 | 其**住所地**县级市场监管部门 | 第13条第2款 |
| 平台内经营者（地址可联系） | 平台公示地址所在地县级部门 **或** 平台住所地县级部门（任选） | 第13条第3款 |
| 平台内经营者（地址无法联系） | **平台经营者住所地**县级市场监管部门 | 第13条第3款 |

**层级管辖：**
- 上级市场监管部门认为有必要的，可处理下级收到的投诉
- 下级认为需由上级处理，可报请上级决定

### 管辖权冲突（第14条）

> 对同一消费者权益争议的投诉，两个以上市场监督管理部门均有处理权限的，由**先收到投诉的**市场监督管理部门处理。

**先受理原则**——不争抢、不推诿，先收到者处理。

## 二、举报管辖规则

### 基本管辖原则（第29-30条）

| 被举报人类别 | 管辖部门 | 法律依据 |
|------------|---------|---------|
| 一般违法行为 | 被举报行为**发生地**县级以上市场监管部门 | 第29条 |
| 县级部门派出机构 | 以本部门名义处理（法律授权除外） | 第30条 |

### 电商相关举报（第31条）

| 被举报人类别 | 管辖部门 | 说明 |
|------------|---------|------|
| 电商平台经营者 | **住所地**县级以上市场监管部门 | 平台本身 |
| 通过自建网站/其他网络服务的电商经营者 | **住所地**县级以上市场监管部门 | 平台类似 |
| 平台内经营者 | **实际经营地**县级以上市场监管部门 | 店铺 |
| 平台住所地部门先收到举报 | 也可以处理 | 平行管辖 |

### 广告违法举报（第32条）

> **删除**了原暂行办法中广告领域举报移送程序，改为同案管辖。

| 广告类型 | 管辖部门 |
|---------|---------|
| 大众传播媒介违法广告 | **广告发布者所在地**市场监管部门 |
| 互联网广告（一般） | 广告发布者所在地；广告主/广告经营者所在地先收到也可管 |
| 广告主自行发布违法互联网广告 | **广告主所在地**市场监管部门 |

### 管辖权争议处理（第33条）

- 争议发生后 **7个工作日内** 协商解决
- 协商不成 → 报请**共同上一级市场监管部门指定**
- 也可直接由共同上一级市场监管部门指定

## 三、平台责任强化（2026年修订亮点）

### 平台内经营者地址无法联系时

**问题背景：** 网店经营者公示地址虚假或无法联系，消费者无法确定管辖。

**解决规则（第13条第3款）：**
> 未在平台依法公示地址，或者通过平台公示的地址无法取得联系的，由**平台经营者住所地**县级市场监督管理部门处理。

**实操要点：**
- 平台须依法公示经营者的真实地址
- 消费者应注意保存平台公示地址的截图作为证据
- 平台经营者住所地通常在平台ICP备案地

## 四、实务指引

### 投诉人策略建议

1. **首选平台内经营者公示地址所在地县级部门**
2. 若公示地址无法联系 → 转向**平台经营者住所地**县级部门
3. 两地均无法确定时，可向**实际经营地**县级部门申诉
4. 提交投诉前，务必保存平台公示信息的截图/公证

### 举报人策略建议

1. 举报前先明确**被举报人类型**（平台/平台内经营者/广告发布者）
2. 选择对自己最便利的管辖部门（尤其是广告举报）
3. 一次性提供全部线索和事实依据，避免重复举报
4. 发现新事实时，优先在原举报中补充，而非另案举报

## 五、管辖示意总表

```
投诉/举报
    │
    ├─→ 一般经营者/行为 ──→ 实际经营地/住所地/行为发生地 县级
    │
    ├─→ 电商平台 ──→ 平台住所地 县级以上
    │
    ├─→ 平台内经营者（地址有效）──→ 公示地址所在地县级
    │                              平台住所地县级（均可）
    ├─→ 平台内经营者（地址无效）──→ 平台住所地 县级
    │
    └─→ 广告发布 ──→ 发布者所在地
           └─→ 互联网广告主自发布 ──→ 广告主所在地
```
