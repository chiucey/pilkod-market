## 二、时限计算通则（第80条）

| 规则 | 内容 |
|------|------|
| 起算 | 以时、日、月计算，期间开始的**时或者日不计算**在内 |
| 在途时间 | **不包括**在途时间（邮寄不以到达为准，以寄出邮戳为准） |
| 届满日 | 期间届满最后一日为**法定节假日**的，以节假日后**第一日**为届满日 |
| 工作日 | 指**法定工作日**（周一至周五），不含法定节假日 |

## 三、不计入办案期限的时间（第64条）

以下时间**不计入**立案至处罚决定的90日（+30日+延期）期限：

| 时间类型 | 说明 |
|---------|------|
| **中止** | 案件调查中止的时间 |
| **听证** | 听证程序进行期间 |
| **公告** | 公告送达的公告期间 |
| **检测/检验/检疫/鉴定** | 委托鉴定机构的时间 |
| **权利人辨认或者鉴别** | 权利人辨认/鉴别的期间 |
| **责令退还多收价款** | 责令退款程序进行的期间 |

## 四、简易程序与普通程序时限对比

| 对比项 | 简易程序 | 普通程序 |
|--------|---------|---------|
| **适用条件** | 事实确凿+有法定依据 | 一般案件 |
| **罚款限额** | 自然人≤200元/法人≤3000元 | 无上限 |
| **办案人员** | 一人可当场办理 | 不少于两人 |
| **立案审批** | 无需单独立案审批 | 须填写立案审批表 |
| **法制审核** | 无需 | 重大复杂案件须审核 |
| **处罚决定书** | 预定格式、编有号码 | 正式制作 |
| **归档期限** | **7个工作日**内 | 结案后15工作日内 |
| **罚款缴纳期限** | 当场可以收缴 | 15日内缴纳 |

## 五、强制执行时间线

```
行政处罚决定书送达
         │
         ├── 15日内未缴纳
         │         │
         │         ▼
         │    催告 → 10个工作日后仍不履行
         │               │
         │               ▼
         │    3个月内向法院申请强制执行
         │               │
         │               ├── 法院裁定执行 → 执行完毕
         │               │
         │               └── 法院裁定不予执行 → 行政处理
         │
         ├── 申请行政复议（60日内）──→ 复议期间不停止执行
         │
         └── 提起行政诉讼（6个月内）──→ 诉讼期间不停止执行
```
