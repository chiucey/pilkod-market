# Fuhe - 复合题型专精技能

## Overview

本技能专注于公务员结构化面试中的**复合题型**，提供完整的出题、答题、排版流程。当用户输入内容含有“复合”时，触发该技能的全流程。

### ⚠️ 复合题型 vs 应急突变 核心区别

| 特征 | 复合题型 | 应急突变 |
|:---|:---|:---|
| **性质** | 复杂问题，不着急，需调查了解 | 突发事件，需紧急处置 |
| **关键词** | 群众投诉、反映、举报 | 突然发生、突发、紧急 |
| **处理重心** | 先了解情况，再分类处理 | 先控制局面，再解决问题 |
| **典型场景** | 政务服务投诉、营商环境、投诉处理 | 冲突打架、群体事件、紧急故障 |

### ⚠️ 复合题型典型场景

- 群众反映窗口服务态度差
- 企业投诉办事流程繁琐
- 投诉处理不及时
- 政务APP使用不便
- 历史遗留问题
- 多部门协调问题
- 社区治理
- 社会治理
- 民生问题
- 其他社会热点问题、矛盾

### 适用范围

- 基于热点出复合题型练习题
- 回答复合题型面试题

## 复合题型答题框架

**三段式结构**：调查了解 → 分情况处理 → 后续做法

### 框架详解

1. **板块零·开场白（粗体）**：表明对该问题的重视和处理态度（普通字体下划线）
2. **板块一·调查了解**：了解问题的具体情况（三步走）
3. **板块二·分情况处理**：根据不同原因采取针对性措施
4. **板块三·后续做法**：总结预防，形成长效机制

## 出题规范

### 题目要求
- 字数：80-150字
- 结尾：用"你怎么办？"

### 题目结构
```
题目：[矛盾冲突描述]你怎么办？
```

### 文档结构

- 题目：题目描述（80-150字）
- 关键词：逗号分隔，不用【】
- 核心事件：高度概括题目中的核心矛盾（1句话）
- 联想要点：根据题目情境设置主体维度
- 答题正文

### 核心事件格式
**格式**：一句话概括题目中的核心矛盾
**示例**：
> 核心事件：市民张先生办理跨境投资备案，因工作人员未一次性告知所需材料，多次往返仍未办成

### 联想要点格式（v2·2026-04-27）

**【核心规则】联想要点分三行，前两行根据题目情境灵活编写，第三行事后做法固定不变。**

**三行结构**：
1. **开展调查**：根据题目情境，列出调查主体和调查内容（**灵活**）
2. **分情况处理**：根据调查发现的问题，列出问题维度和应对措施（**灵活**）
3. **事后做法**：固化内容，不变（**固定**）

**第四行·事后做法（固定·禁止修改）**：
```
事后做法：总结，常态化，定期、不定期，反馈
```

**格式**：每行`主体A：要点1、要点2；主体B：要点3、要点4`

**示例**（以政务服务窗口投诉为例）：
```
开展调查：群众：困难、诉求；窗口：流程、材料；实地体验：发现堵点
分情况处理：告知不到位：一次性告知清单、培训考核；环节繁琐：流程优化、减少审批；信息不共享：数据打通、一网通办
事后做法：总结，常态化，定期、不定期，反馈
```

**格式要点**：
1. 分三行：**开展调查、分情况处理、事后做法**
2. 前三行**根据题目意思灵活更改**
3. 第三行**事后做法固定**：`事后做法：总结，常态化，定期、不定期，反馈`
4. 每行先写主体维度，主体后用冒号
5. 同一主体的多个要点用顿号或逗号分隔
6. 不同主体之间用分号分隔

## 弹药库句式

### 开场白公式
> **【高度概括的题目核心事件：如窗口出现群众投诉】，如不妥善处理，【后果：如将会影响群众办事】，对此，我会认真对待，采取以下措施解决。**（弹药库）

**⚠️ 使用要点**：
- "如不妥善处理，将会..."——后果描述
- 定性评价常用词：**不合理的 / 应当引起重视的 / 需要妥善处理的 / 不负责任的 / 错误的**
- 整段约60-70字，开口直接说，无需思考

**排版**：开场白整体**加下划线**（普通字体，不加粗）

**公式拆解**：
- 【题目核心行为】：如"高新技术企业认定审批出现问题"
- 【后果】：如"打击企业创新积极性"

**示例**：
> **高新技术企业认定审批出现问题**，如不妥善处理，将会打击企业创新积极性，对此，我会认真对待，采取以下措施解决。

### 调查了解句式（一段式·弹药库）
> 调查了解：首先，我会对此事进行全面的调查了解。（过渡句下划线，不换行）
> 一方面，向相关工作人员和负责人了解情况，请他们谈谈存在的问题。（弹药库，加下划线）
> [简单具体化：简单了解情况。]（加下划线）
> 另一方面，和前来办事的群众聊一聊，听听他们的意见和建议。（弹药库，加下划线）
> [简单具体化：简单了解情况。]（加下划线）
> 另外，我会到现场进行体验，发现实际问题。（弹药库，加下划线）

**⚠️ 使用要点**：
- "首先，我会对此事进行全面的调查了解"——固定开头
- "一方面...另一方面...另外..."——三段式结构
- 约80字，完整覆盖调查对象

**排版说明**：
- 板块标题："调查了解："（粗体）
- 过渡句：下划线（弹药库，不换行）
- 分情况单点要点标题（如果是...；如果是....）：粗体（不换行）
- 扩展解释：**普通字体，不加下划线（用户填充）**

**示例**：
> 调查了解：首先，我会对这个问题进行详细了解。 一方面，我会向相关工作人员和负责人了解情况，请他们谈谈存在的问题。（下划线·弹药库） 比如是不是系统经常出现故障。（简单具体化，下划线） 另一方面，和前来办事的群众聊一聊，听听他们的意见和建议。（下划线·弹药库）
> 比如是不是办事流程过于繁琐。（简单具体化，下划线） 另外，我会到现场进行体验，发现实际问题。（弹药库，下划线）
### 分情况处理句式
> 分情况处理：其次，根据了解到的情况进行处理。（下划线，弹药库） **如果是[原因A]**。（单点要点标题，粗体） 我会[措施A]。（扩展解释：**普通字体，不加下划线） **如果是[原因B]**。（单点要点标题，粗体） 我会[措施B]。扩展解释：**普通字体，不加下划线） **如果是[原因C]**。（单点要点标题，粗体） 我会[措施C]。（扩展解释：**普通字体，不加下划线）

**排版说明**：
- 板块标题："分情况处理："（粗体）
- 弹药库过渡句：下划线(其次，根据了解到的情况进行处理。)
- 单点要点（"如果是..."）：**粗体**（不换行）
- 应对措施：**普通字体（扩展解释，不加下划线）**

**示例**：
> __分情况处理：其次，根据了解到的情况进行处理__。 **如果是因部门间信息壁垒导致企业重复提交材料**。 我会协调相关部门推进数据共享，打通信息孤岛，实现材料一次提交、多部门共享。 **如果是因审批流程设置不合理导致办理时限过长**。 我会优化审批流程，精简不必要的审核环节，明确各环节办理时限，加快审批速度。 **如果是因企业对政策流程不熟悉导致来回跑动**。 我会加强政策宣传，提供帮办代办服务，全程指导企业准备材料，确保一次办结。

### 后续做法句式（弹药库·固化版）

**【固化】事后做法四要素**：**总结、常态化、定期、不定期、反馈**

> 后续做法：利民之事，丝发必兴。事后，我会把处理结果形成书面报告上报领导。建立**常态化**检查机制，**定期、不定期**对【相关主体或工作，如：文化中心】进行检查，发现问题及时解决，把问题处理在萌芽状态。畅通**反馈**渠道，欢迎【相关主体，如：居民】随时反馈问题，及时回应他们的意见和建议。

**⚠️ 使用要点**：
- "利民之事，丝发必兴"——固定开头
- "把处理结果形成书面报告"——完整表述
- 定期、不定期检查——固定搭配
- 畅通反馈渠道——固定表述

**排版说明**：
- 板块标题："后续做法："（粗体）
- 整体内容：**下划线**
- **4个关键词必须全部出现**：总结、常态化、定期、不定期、反馈
