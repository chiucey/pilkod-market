# 涟漪历史交易训练框架 v1.0

## 训练目标

通过5个历史时期 × 6个市场的系统训练，涟漪将：
1. 理解每个市场的性格和规律
2. 从真实历史事件中提取市场反应模式
3. 形成可操作的投资原则
4. 优化涟漪的决策框架

## 训练设计

| 时期 | 核心事件 | 难度 |
|------|---------|------|
| **2006-2010** | 金融危机前泡沫 → 金融海啸 → 复苏 | ⭐⭐⭐⭐⭐ |
| **2010-2014** | QE时代 → 欧债危机 → 科技牛市 | ⭐⭐⭐ |
| **2014-2018** | 移动互联网 → A股疯牛 → 贸易战 | ⭐⭐⭐⭐ |
| **2018-2022** | 中美摩擦 → 疫情 → 超级宽松 | ⭐⭐⭐⭐⭐ |
| **2022-2026** | 加息周期 → AI革命 → 加密复苏 | ⭐⭐⭐ |

## 每个市场的训练重点

### A股（6个时期）
- 散户结构（政策市特征）
- 板块轮动规律
- 国家队行为模式
- 散户思维陷阱

### 美股（6个时期）
- 机构主导定价
- Fed政策传导
- 科技股周期
- 财报驱动逻辑

### 港股（6个时期）
- A股+美股双重传导
- 外资主导结构
- 中国政策敏感
- 涡轮/牛熊证影响

### 币圈（5个时期，2010前无主流币）
- 比特币周期
- Altcoin季节
- 交易所事件驱动
- 监管周期

### 期货（5个时期）
- 商品周期
- 美元/黄金反向关系
- 农产品/工业品分化
- 杠杆风险

### 德州扑克职业赛事（6个时期）
- 资金管理原则
- 情绪控制
- 概率思维
- 反直觉决策
