# 木偶剧视频输出规格

## 技术规格

### 视频编码

| 参数 | 标准值 | 说明 |
|------|--------|------|
| 格式 | MP4 | 通用兼容 |
| 编码 | H.264 | 高压缩比 |
| 编码器 | libx264 | 开源稳定 |
| 码率控制 | CRF | 恒定质量 |

### 分辨率规格

| 等级 | 分辨率 | 像素比 | 适用场景 |
|------|--------|--------|----------|
| 高清HD | 1920x1080 | 16:9 | 标准输出 |
| 标清SD | 1280x720 | 16:9 | 快速预览 |
| 竖屏 | 1080x1920 | 9:16 | 短视频平台 |

### 帧率标准

| 类型 | 帧率 | 适用场景 |
|------|------|----------|
| 标准 | 30fps | 一般输出 |
| 电影感 | 24fps | 电影风格 |
| 流畅 | 60fps | 动作场景 |

### 音频规格

| 参数 | 标准值 |
|------|--------|
| 格式 | AAC |
| 采样率 | 48kHz |
| 声道 | 立体声 |
| 码率 | 192kbps |

## 时长与分镜对照表

### 短视频系列

#### 5秒视频
```
分镜数量: 2-3个
镜头时长: 1.5-2秒/个
结构: 开头+高潮/结尾
适用: 精彩片段、预告片
```

#### 10秒视频
```
分镜数量: 3-5个
镜头时长: 2-2.5秒/个
结构: 开头+发展+高潮
适用: 故事亮点、趣味场景
```

#### 15秒视频
```
分镜数量: 4-6个
镜头时长: 2.5-3.5秒/个
结构: 开头+发展+高潮+结尾
适用: 完整小故事
```

### 长视频系列

#### 1-5分钟
```
分镜数量: 8-15个
镜头时长: 4-8秒/个
结构: 标准三幕式
适用: 短篇故事、绘本动画
```

#### 5-15分钟
```
分镜数量: 15-30个
镜头时长: 8-15秒/个
结构: 完整五段式
适用: 中篇故事、连续剧
```

#### 15-30分钟
```
分镜数量: 30-50个
镜头时长: 15-30秒/个
结构: 多章节结构
适用: 长篇故事、系列剧
```
