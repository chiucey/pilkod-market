### 大师级调色技巧

#### 低饱和度高对比
- 适合：戏剧性、电影感
- 技巧：降低饱和度至70%，提升对比度至120%

#### 暖色调溢出
- 适合：温馨、怀旧
- 技巧：高光偏暖(+10%)，阴影偏冷(-5%)

#### 冷暖对比
- 适合：情感冲突、戏剧张力
- 技巧：主体暖色，背景冷色

## 运镜大师技巧

### 基础运镜

| 运镜方式 | 效果 | 使用时机 |
|----------|------|----------|
| 推镜头 | 强调、紧张 | 揭示重点、制造压力 |
| 拉镜头 | 舒缓、交代 | 展示全貌、引出角色 |
| 摇镜头 | 探索、连贯 | 展示空间、跟随动作 |
| 移镜头 | 动态、参与 | 展示环境、增加动感 |
| 跟镜头 | 亲密、追踪 | 跟随角色、增加代入 |

### 高级运镜组合

#### 开场序列
```
1. 远景固定 - 建立场景
2. 缓慢推镜 - 聚焦主体
3. 摇镜头 - 展示环境
4. 固定镜头 - 开始对话
```

#### 追逐场景
```
1. 跟镜头 - 跟随主角
2. 快速移镜头 - 切换视角
3. 俯冲镜头 - 展示速度
4. 固定镜头 - 捕捉反应
```

#### 情感高潮
```
1. 近景固定 - 捕捉表情
2. 缓慢推镜 - 情感积累
3. 特写 - 情绪爆发
4. 拉镜头 - 舒缓情绪
```

## 服装化妆道具标准

### 木偶剧角色设计规范

#### 主角设计
- 服装：色彩鲜明，轮廓清晰
- 化妆：表情夸张，特征突出
- 道具：标志性物品，便于识别

#### 配角设计
- 服装：辅助主色，不喧宾夺主
- 化妆：简化处理，特征明确
- 道具：功能性强，服务剧情

#### 反派设计
- 服装：深色系，视觉压迫
- 化妆：冷酷线条，阴影突出
- 道具：威胁性物品

### 道具分级

#### A级道具（主演）
- 精细制作，材质高档
- 多次使用，核心剧情

#### B级道具（场景）
- 标准制作，配合场景
- 一次性使用，营造氛围

#### C级道具（背景）
- 简化处理，大效果
- 批量制作，成本控制

## 木偶剧剧本结构模板

### 三幕式结构

```
第一幕：设定（25%时长）
├── 场景1：建立世界
├── 角色登场
└── 埋下伏笔

第二幕：对抗（50%时长）
├── 主角面临挑战
├── 多次尝试失败
├── 中点转折
└── 危机升级

第三幕：解决（25%时长）
├── 最终对决
├── 情感高潮
└── 完美落幕
```

### 五段式结构

```
1. 开场钩子（5%）
   - 立即吸引注意力

2. 设定背景（10%）
   - 介绍角色和世界

3. 第一事件（20%）
   - 打破平衡

4. 中点（20%）
   - 重大转折

5. 结局（45%）
   - 高潮+解决
```
