# 木偶剧视频生成技能

## 核心能力

本技能支持两种生成模式：

### 模式一：一句话AI自动联想生成（默认）
- **一句话输入**：用户只需提供一句话描述
- **AI自动联想**：智能扩展故事情节、角色、场景
- **固定时长**：自动生成为10秒视频
- **即时输出**：MP4格式，即时可用

### 模式二：完整剧本生成
- 小说/故事文本一键转化
- 完整剧本生成、精细分镜设计
- 大师级导演视角、顶级制作水准

## 一句话AI联想生成工作流

### 1. 智能解析（一句话输入）

**输入示例**：
```
"小兔子去森林探险"
"魔法师的奇幻冒险"
"公主与龙的友谊"
```

**AI自动联想内容**：
| 要素 | 联想内容 |
|------|----------|
| 角色 | 自动生成2-4个角色，包含主角、配角 |
| 场景 | 自动设计3-5个场景切换 |
| 情节 | 扩展为完整故事弧线 |
| 情感 | 设定情感基调与起伏 |
| 风格 | 自动匹配合适色调与氛围 |

### 2. 自动剧本生成

**10秒剧本结构**：
```
[开场] 0-2秒 - 吸引注意，建立场景
[发展] 2-6秒 - 推进情节，角色互动
[高潮] 6-8秒 - 情感爆发，视觉冲击
[结尾] 8-10秒 - 完美收束，余韵留白
```

**台词自动润色**：
- 基于角色性格智能生成
- 生动有趣，适配木偶剧风格
- 情感丰富，对话自然

### 3. 自动分镜设计

**10秒固定分镜**：
| 分镜序号 | 时长 | 镜头类型 | 运镜方式 | 内容描述 |
|----------|------|----------|----------|----------|
| S1 | 2秒 | 开场全景 | 缓慢推镜 | 建立场景氛围 |
| S2 | 3秒 | 中景对话 | 正反打 | 角色互动 |
| S3 | 3秒 | 近景特写 | 固定+微推 | 情感高潮 |
| S4 | 2秒 | 全景收尾 | 缓慢拉镜 | 完美落幕 |

### 4. 角色自动配置

**角色固定系统**：
- 角色名称与外形自动生成
- 服装、化妆、道具自动设计
- 全程角色一致性保持

**角色库联想**：

勇敢型: 小骑士、小战士、小英雄

## 完整剧本模式工作流

### 1. 需求解析与创意策划

**输入处理**：
- 分析用户提供的小说/故事文本
- 提取核心人物、场景、情感基调
- 确定视频风格定位

**色调设计原则**：
| 风格类型 | 主色调 | 辅助色 | 情感表达 |
|---------|--------|--------|----------|
| 温馨童趣 | 暖黄/橙 | 浅粉/天蓝 | 温暖、快乐 |
| 悬疑惊悚 | 深蓝/墨绿 | 暗红/灰黑 | 紧张、神秘 |
| 浪漫爱情 | 玫瑰粉/香槟金 | 柔白/浅紫 | 浪漫、温馨 |
| 历史传奇 | 棕褐/墨绿 | 金色/深红 | 厚重、庄严 |
| 奇幻冒险 | 紫色/青色 | 亮橙/银白 | 神秘、刺激 |

### 2. 自动剧本生成

**剧本结构**：
```
[第一幕] 设定场景 - 介绍角色与背景
[第二幕] 冲突发展 - 推进故事情节
[第三幕] 高潮转折 - 制造情感爆发点
[第四幕] 结局收束 - 完美落幕
```

### 3. 分镜与运镜设计

**运镜指令库**：
```
- 推镜头 (Push In): 强调重点，制造紧张感
- 拉镜头 (Pull Out): 交代环境，引出场景
- 摇镜头 (Pan): 展示空间，环顾四周
- 移镜头 (Track): 跟随角色，营造参与感
- 跟镜头 (Follow): 追踪动作，增强代入
- 固定镜头 (Static): 稳定叙事，突出台词
```

### 4. 角色设计系统

**角色固定配置**：
- 角色名称与定位
- 外形特征描述
- 服装设计细节
- 化妆造型要求
- 道具配置清单
