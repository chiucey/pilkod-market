# ClickUp项目设置指南

## 现有项目评估与优化

**重要原则**：当项目文档已存在时，**优先评估与优化现有结构**，而非推倒重建。

### 快速诊断清单（30分钟内完成）

当接手一个已有项目时，按以下顺序快速诊断：

| 步骤 | 检查内容 | 判断标准 |
|------|----------|----------|
| 1 | 查看任务列表数量 | 是否覆盖主要施工阶段 |
| 2 | 查看任务状态分布 | 是否有过多"进行中"超过1周 |
| 3 | 查看逾期任务数量 | 逾期>5个需重点关注 |
| 4 | 查看最近更新时间 | 超过3天未更新需激活 |
| 5 | 查看文档/附件 | 关键节点是否有记录 |

### 差距分析与优化策略

| 发现的差距 | 处理方式 | 工作量评估 |
|------------|----------|------------|
| 缺少某些阶段任务 | 在现有列表中补充 | 低 |
| 任务缺少依赖关系 | Gantt视图中补全 | 中 |
| 任务状态长期不变 | 找负责人激活更新 | 低 |
| 缺少关键文档记录 | 补充上传 | 中 |
| 列表结构混乱 | 调整列表顺序/命名 | 低 |

### 渐进式优化原则

```
✅ 应该做：
- 补充缺失阶段的任务
- 修复任务依赖关系
- 更新过期任务状态
- 补充缺失的文档记录
- 调整不合理的截止日期

❌ 避免做：
- 删除所有任务重新创建（除非完全无法使用）
- 大规模修改已建立的命名规则
- 改变现有的工作流程（除非明显低效）
```

### 场景判断标准

| 场景 | 判断依据 | 推荐操作 |
|------|----------|----------|
| **无需改动** | 结构完整、状态活跃、文档齐全 | 正常维护 |
| **轻度优化** | 结构完整、个别任务滞后 | 激活+补充文档 |
| **中度优化** | 缺少部分阶段、任务状态混乱 | 补充+重新分配+激活 |
| **重建关键路径** | 结构严重缺失、无法追踪 | 仅重建关键路径任务 |

### 优化示例

**示例1：缺少防水阶段任务**
```
现状：任务列表中缺少"05-防水工程"
操作：在对应位置插入列表 → 补充标准防水任务 → 设置与前后阶段的依赖
注意：不需要重建其他已完成阶段的结构
```

**示例2：多个任务长期"进行中"**
```
现状：[结构-03]墙体砌筑 状态：进行中（已15天）
操作：1. 联系Zack确认实际进展 → 2. 更新为正确状态 → 3. 如确实未完成，分析原因并调整时间线
```

## 新项目初始化清单

### 1. 创建项目文件夹

1. 进入ClickUp工作空间
2. 点击「+ 新建」→「文件夹」
3. 命名格式：`{项目编号} - {项目名称}`
   - 示例：`PRJ-001 - 23 Harden Ave, Northbridge`

### 2. 设置项目信息

```
项目名称: 23 Harden Ave, Northbridge
项目类型: 别墅建筑/翻新
开始日期: 2024-XX-XX
预计完工: 2024-XX-XX
项目经理: [姓名]
```

### 3. 创建标准任务列表

在每个项目文件夹下创建以下列表：

| 列表名称 | 用途 |
|----------|------|
| 00-拆除阶段 | 拆除相关任务 |
| 01-基础工程 | 挖掘、地基相关任务 |
| 02-结构工程 | 墙体、结构相关任务 |
| 03-屋面工程 | 框架、屋顶相关任务 |
| 04-水电预埋 | 水电相关任务 |
| 05-防水工程 | 防水相关任务 |
| 06-门窗工程 | 门窗安装任务 |
| 07-泥水工程 | 铺砖、石材任务 |
| 08-木工工程 | 橱柜、木作任务 |
| 09-油漆工程 | 油漆涂料任务 |
| 10-安装工程 | 灯具、洁具、五金安装 |
| 11-验收移交 | 竣工验收、整改、移交 |
| 采购追踪 | 材料采购状态追踪 |
| 风险待办 | 风险事项跟踪 |
| 文档库 | 重要文档归档 |

### 4. 创建标准任务模板

每个阶段任务应包含以下字段：

**任务名称格式**: `[阶段-序号] 任务描述`
**示例**: `[DEMO-01] 建筑主体拆除`

**必填字段**:
- 负责人 (Assignee)
- 截止日期 (Due Date)
- 优先级 (Priority)
- 状态 (Status)
- 依赖任务 (Dependencies)
- 预计工期 (Estimated Time)

**建议字段**:
- 成本 (Cost)
- 质量标准 (Quality Standards)
- 附件 (Attachments)

### 5. 设置任务依赖

1. 在Gantt视图中查看任务
2. 点击任务右侧的「依赖」图标
3. 添加前置任务 (Blocking)
4. 设置完成后，前置任务未完成时，后续任务自动锁定

### 6. 配置自动化规则

**建议启用的自动化规则**:

| 触发条件 | 自动化动作 |
|----------|------------|
| 任务状态变为「已完成」 | 通知下一个负责人 |
| 任务逾期 | 发送提醒邮件 |
| 任务状态变为「整改中」 | 创建缺陷跟踪任务 |
| 新任务创建 | 自动分配默认负责人 |

### 7. 设置通知规则

```
邮件通知触发条件:
- [x] 任务分配给我
- [x] 任务状态变更
- [x] 截止日期临近(1天前)
- [x] 逾期提醒
- [x] 任务评论提及我
- [x] 文档更新
```

### 8. 创建Dashboard看板

建议创建的Dashboard Widget:

1. **今日到期任务** - 按优先级排序
2. **逾期任务** - 红色高亮
3. **各阶段进度** - 饼图/柱状图
4. **采购状态概览** - 追踪表视图
5. **风险清单** - 最新风险更新

### 9. 设置视图模板

**推荐的默认视图**:

| 视图类型 | 用途 |
|----------|------|
| List View | 任务清单管理 |
| Board View | 看板式进度跟踪 |
| Gantt Chart | 关键路径和时间线 |
| Calendar View | 截止日期管理 |
| Box View | 按阶段/负责人分组 |

## 每日ClickUp操作流程

### 晨间检查 (8:30-9:00)

1. 打开Dashboard
2. 查看「今日到期任务」
3. 查看「逾期任务」
4. 逐个更新任务状态

### 任务状态更新步骤

1. 打开对应任务
2. 更新状态 → 选择新状态
3. 添加评论说明进展
4. 上传相关照片/文件
5. 如有问题，创建子任务或关联任务

### 下午更新 (17:00-17:30)

1. 批量更新今日进展
2. 调整明日到期任务
3. 更新风险清单
4. 同步团队评论

## 文件上传规范

### 照片命名格式

```
{日期}_{项目缩写}_{位置}_{内容描述}.jpg
示例: 20240329_HardenAve_LivingRoom_WallCrack_001.jpg
```

### 文档命名格式

```
{日期}_{项目缩写}_{文档类型}_{版本}.pdf
示例: 20240329_HardenAve_WaterproofTestReport_v1.pdf
```

### 推荐附件大小

| 类型 | 最大建议大小 |
|------|--------------|
| 照片 | 2MB/张 |
| 文档 | 10MB/份 |
| 视频 | 50MB/个 |
