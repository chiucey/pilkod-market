# 采购追踪管理表

## 材料追踪状态定义

| 状态码 | 状态名称 | 说明 |
|--------|----------|------|
| P0 | 待下单 | 等待确认规格/图纸后可下单 |
| P1 | 已下单 | 订单已确认，工厂接单 |
| P2 | 生产中 | 工厂开始生产 |
| P3 | 质检中 | 生产完成，等待出厂质检 |
| P4 | 已发货 | 物流已发出 |
| P5 | 运输中 | 货物在途 |
| P6 | 到场待验 | 货物已到达工地 |
| P7 | 验收通过 | 质量确认，可使用 |
| P8 | 验收不通过 | 需退换货 |
| P9 | 已安装 | 安装完成 |
