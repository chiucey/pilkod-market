# Premium Frontend Generator

生成具有高级感、现代美学的前端页面，参考 Linear、Vercel、Stripe 的设计语言。

## 核心原则

1. **设计前置**：必须先输出设计方案，等待用户确认后再生成代码
2. **避免 AI 味**：拒绝千篇一律的模板化设计
3. **移动优先**：所有布局和交互必须先考虑移动端

## 设计前置流程

当用户提出页面生成需求时：

### Step 1: 需求分析

分析用户需求的关键要素：
- **页面类型**：Landing Page、作品集、产品展示、关于页面等
- **核心主题**：科技、金融、艺术、时尚等
- **目标受众**：设计师、开发者、商务人士等
- **情感调性**：专业、活泼、极简、温暖等

### Step 2: 输出设计方案

必须包含以下四个维度的设计规划：

#### A. 配色方案

```
主色 (Primary): [色值] - 传达品牌调性
辅助色 (Secondary): [色值] - 层次与对比
强调色 (Accent): [色值] - CTA 和关键元素
背景色系: [渐变或分层方案]
文字色系: [主文字、次级文字、辅助文字]
```

配色禁止：
- 纯黑 #000000 或纯白 #FFFFFF
- 高饱和度对比色

#### B. 字体系统

```
标题字体: [Google Font 名称]
正文字体: [Google Font 名称]
字号层级: [h1/h2/h3/body/small 的具体值]
字重策略: [强调/正文/轻盈的分布]
行高建议: [标题 1.1-1.3 / 正文 1.5-1.7]
```

禁止使用系统字体栈如 `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto`

#### C. 布局策略

明确指出：
- 页面采用不对称或错落网格
- 视觉重心分布（左偏/右偏/中心偏移）
- 内容区域宽度限制（max-width 策略）
- 留白节奏（密集区 vs 呼吸区）

#### D. 动效思路

```
入场动画: [fade-up / fade-in / slide 等]
悬停交互: [上浮 / 边框渐变 / 背景渐变 / 发光]
微交互动效: [光标跟随 / 渐变流动 / 边框动画]
时间曲线: [ease-out / cubic-bezier 建议]
```

### Step 3: 等待用户确认

使用 GenUI 确认表单收集用户反馈：

```
<genui-form-wizard>
  - 确认设计方向
  - 允许微调配色/字体
  - 收集特定内容素材
</genui-form-wizard>
```

## 生成阶段

用户确认后，生成包含以下元素的代码：

### 必须包含的高级感元素

1. **非对称布局**
   - 网格不均匀分布（如 1:2:1 或 2:3）
   - 元素偏移对齐
   - 打破传统居中对称

2. **多层阴影**
   - 小阴影 + 大阴影叠加
   - 避免单一平面阴影
   - 阴影颜色倾向使用主色调的半透明版本

3. **微妙渐变**
   - 同色系渐变（深→浅）
   - 相邻色渐变（如蓝→紫）
   - 角度控制在 135°-180° 之间

4. **精致微动效**
   - 悬停上浮：translateY(-4px) + 阴影加深
   - 渐变边框：background-origin + 渐变 border
   - 交错入场：stagger delay 100-150ms

5. **差异化圆角**
   - 大卡片：大圆角 16-24px
   - 小元素：中圆角 8-12px
   - 微小组件：小圆角 4-6px

6. **边框效果**
   - 半透明边框（rgba 或 hsla）
   - 发光边框（box-shadow glow）
   - 渐变边框（border-image 或伪元素）

### 禁止项清单

```
❌ 禁止"标题+副标题+按钮"三段式居中布局
❌ 禁止纯黑 #000 / 纯白 #fff
❌ 禁止所有卡片相同圆角值
❌ 禁止三列等宽卡片列表
❌ 禁止 transition: all
❌ 禁止系统字体栈
❌ 禁止 0 透明度的纯色
❌ 禁止平均分布的网格
```

## 技术规范

### 输出格式

单个 HTML 文件，内联 CSS 和 JS

### CSS 要求

- 使用 CSS 自定义属性（variables）
- 优先使用 Grid 和 Flexbox
- 支持 backdrop-filter 毛玻璃效果
- 使用 @keyframes 定义动画
- 避免 !important

### 响应式断点

```
移动端: < 768px
平板端: 768px - 1024px
桌面端: > 1024px
```

### Tailwind CSS

可内联使用 Tailwind CDN，需补充的自定义样式写在 `<style>` 标签内

### 性能考虑

- 动画使用 transform 和 opacity（GPU 加速）
- 避免 layout thrashing
- 图片使用懒加载
