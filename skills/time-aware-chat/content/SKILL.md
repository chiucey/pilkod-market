# 时间感知对话技能

## 核心功能

在每次对话回复中主动获取并参考当前时间，确保回复内容与实际时间段相符。

## 时间段定义

| 时段 | 时间范围 | 应避免使用的词汇 |
|------|----------|------------------|
| 黎明 | 05:00-06:59 | 深夜、漆黑、繁星 |
| 早晨 | 07:00-08:59 | 夜幕、夜色 |
| 上午 | 09:00-11:59 | 夜、晨曦 |
| 中午 | 12:00-13:59 | 晨曦、夜色 |
| 下午 | 14:00-17:59 | 夜幕、晨曦 |
| 傍晚 | 18:00-19:59 | 阳光灿烂（可适当使用） |
| 晚间 | 20:00-21:59 | 阳光明媚、晴空万里 |
| 深夜 | 22:00-04:59 | 阳光、晴朗、鸟鸣 |

## 工作流程

1. **获取当前时间**：每次回复前获取系统当前时间
2. **判断时间段**：根据时间判断当前属于哪个时段
3. **语境适配**：根据时间段调整回复用词和场景描述
4. **一致性检查**：确保回复中不出现与时间矛盾的元素

## 场景词对照表

### 白天常用词（07:00-19:59）
- 阳光、晴朗、蓝天、白云
- 鸟鸣、微风、温暖的阳光
- 新的一天开始了
- 精神饱满、神清气爽

### 夜晚常用词（20:00-06:59）
- 夜色、月光、星空
- 宁静、安静、放松
- 结束一天的工作
- 好好休息、晚安氛围

## 使用场景示例

### 用户：今天天气怎么样？
- **早晨(07:00)**：今天是个美好的早晨，阳光温和，适合晨练。
- **中午(12:00)**：现在是正午时分，阳光明媚。
- **夜晚(21:00)**：夜幕已降临，今天天气整体不错，现在更适合安静地休息。

### 用户：给我讲个故事
- **早晨**：清晨的故事总是充满希望，今天想听什么样的？
- **深夜**：夜深人静，最适合讲一个温馨的睡前故事了。

### 用户：有什么推荐的活动吗？
- **早晨**：早上好！可以出门散散步，呼吸新鲜空气。
- **夜晚**：夜晚适合看看书或者听听音乐放松一下。
