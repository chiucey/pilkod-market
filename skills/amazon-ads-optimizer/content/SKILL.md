# 亚马逊广告优化大师

## Overview

专业的亚马逊PPC广告优化技能，帮助卖家分析广告数据、优化关键词策略、降低广告成本、提高投资回报率（ROI）。涵盖广告数据分析、关键词研究与优化、竞价策略制定、广告结构优化和竞品分析五大核心能力。

## 工作流程

当用户提供广告数据或请求优化建议时，按以下流程执行：

### 1. 数据接收与确认
- 确认数据格式（CSV、Excel或截图）和完整性
- 确认数据时间范围
- 统一数据格式和单位
- 如缺少必要信息，主动询问用户

### 2. 初步分析
- 快速计算核心指标（ACoS、ROAS、CTR、CVR、CPC）
- 识别关键问题和机会点
- 与行业基准对比

### 3. 深度诊断
- 分层分析（广告活动→广告组→关键词/ASIN）
- 关键词四象限评估
- 搜索词与投放词匹配分析
- 检查问题诊断清单

### 4. 策略建议
- 提供具体可执行的优化方案
- 包含操作步骤和预期效果

### 5. 优先级排序
- 按影响程度和执行难度排序建议
- 标注执行优先级（高/中/低）

## 核心指标与公式

```
ACoS = 广告花费 / 广告销售额 × 100%
TACoS = 广告花费 / 总销售额 × 100%
ROAS = 广告销售额 / 广告花费
CTR = 点击量 / 曝光量 × 100%
CVR = 订单量 / 点击量 × 100%
CPC = 广告花费 / 点击量
盈亏平衡ACoS = 利润率
```

### 指标释义
- **曝光量**：广告展示次数
- **点击量**：广告被点击次数
- **CTR（点击率）**：点击量/曝光量
- **花费**：总广告支出
- **CPC（单次点击成本）**：花费/点击量
- **订单量**：通过广告产生的订单
- **CVR（转化率）**：订单量/点击量
- **销售额**：广告带来的销售金额
- **ACoS**：花费/销售额
- **ROAS**：销售额/花费

## ACoS 分析框架

- **ACoS < 15%**：表现优秀，可考虑扩量
- **ACoS 15-25%**：良好，持续优化
- **ACoS 25-35%**：需要关注，找出问题
- **ACoS > 35%**：需要重点优化或暂停

## 行业基准参考

| 指标 | 优秀 | 良好 | 一般 | 需改进 |
|------|------|------|------|--------|
| CTR | >0.5% | 0.3-0.5% | 0.15-0.3% | <0.15% |
| CVR | >15% | 10-15% | 5-10% | <5% |
| ACoS | <15% | 15-25% | 25-35% | >35% |

*注：基准因类目而异，仅供参考*

## 广告数据深度分析

当用户提供广告报表数据（CSV、Excel或截图）时，按以下步骤进行系统化分析。

### 第一步：数据清洗与整理
1. 确认数据时间范围
2. 检查数据完整性
3. 统一数据格式和单位

### 第二步：核心指标计算
计算所有关键指标（见上方"核心指标与公式"部分）。

### 第三步：分层分析

#### 广告活动层面
- 各活动表现对比
- 预算消耗情况
- 活动类型效果对比（SP/SB/SD）

#### 广告组层面
- 各组表现差异
- 定位类型效果（关键词/商品/类目）

#### 关键词/ASIN层面
- 高转化词识别
- 高花费低转化词识别
- 搜索词与投放词匹配分析

### 第四步：问题诊断清单

检查以下常见问题：
- [ ] ACoS是否超过目标值
- [ ] 是否有大量曝光但零点击的词
- [ ] 是否有高点击低转化的词
- [ ] 是否有搜索词与产品相关性差
- [ ] 预算是否被低效词消耗
- [ ] 是否存在重复投放

## 关键词研究与优化

当用户需要进行关键词研究、评估现有关键词表现、或制定关键词策略时，使用此部分。

### 关键词分类体系

#### 按搜索意图分类
1. **品牌词**：包含自有品牌名称
2. **竞品词**：包含竞争对手品牌名称
3. **类目词**：产品类目通用词
4. **属性词**：产品特征描述词
5. **场景词**：使用场景相关词
6. **长尾词**：多词组合的精准词

#### 按匹配类型分类
- **广泛匹配**：最大曝光，需要严格否词
- **词组匹配**：平衡曝光和精准度
- **精准匹配**：最高转化，曝光受限

### 关键词评估矩阵

#### 四象限分析法

```
         高转化率
            ↑
   潜力词   │   明星词
  (提升曝光) │  (重点投入)
─────────────┼─────────────→ 高点击量
   无效词   │   引流词
  (考虑否定) │ (优化listing)
            ↓
         低转化率
```

#### 评估标准
| 类型 | 点击量 | 转化率 | 操作建议 |
|------|--------|--------|----------|
| 明星词 | >50 | >10% | 增加竞价，扩大投放 |
| 潜力词 | <20 | >10% | 提高竞价获取更多曝光 |
| 引流词 | >50 | <5% | 检查listing相关性 |
| 无效词 | <20 | <5% | 添加为否定词 |

### 关键词挖掘方法

#### 1. 搜索词报告挖掘
- 筛选高转化客户搜索词
- 识别新的长尾词机会
- 发现用户真实搜索习惯

#### 2. 竞品关键词分析
- 分析竞品投放的广告位
- 研究竞品标题和要点
- 使用品牌分析工具

#### 3. 自动广告挖掘
- 设置自动广告投放
- 定期导出搜索词报告
- 筛选优质词转手动投放

#### 4. 关联类目扩展
- 分析"一起购买"产品
- 研究关联类目热门词
- 探索跨类目机会

### 否定关键词策略

#### 必须否定的词类型
1. **不相关词**：与产品完全无关
2. **竞品词**（可选）：ROI过低的竞品词
3. **低效词**：长期高花费零转化
4. **错误匹配**：匹配到错误产品类型

#### 否定词实施步骤
1. 导出搜索词报告
2. 筛选满足以下条件的词：
   - 点击>20 且 转化=0
   - 或 花费>$10 且 转化=0
3. 人工审核相关性
4. 添加为词组或精准否定

#### 否定词层级选择
- **活动层否定**：影响整个广告活动
- **广告组否定**：仅影响特定广告组

## 竞价策略

### 基于ACoS的竞价调整
```
目标ACoS = 利润率

如果 当前ACoS < 目标ACoS × 0.8：
    → 可提高竞价 10-20%

如果 当前ACoS > 目标ACoS × 1.2：
    → 应降低竞价 10-20%

如果 点击量太少无法判断：
    → 考虑提高竞价获取数据
```

### 竞价公式参考
```
建议竞价 = 目标ACoS × 产品售价 × 预期转化率
```

### 分时段竞价策略
- 分析不同时段的转化率差异
- 在高转化时段提高竞价
- 在低效时段降低竞价或暂停

### 广告位竞价优化
- 首页顶部：适合品牌词和高转化词
- 商品页面：适合竞品定投
- 其他位置：适合长尾词测试

### 预算分配优化
- 优先分配给高ROAS的广告活动
- 新品期适当增加预算获取数据
- 避免预算过早耗尽导致错过高峰时段

## 广告结构优化

### 广告活动架构设计
- 按产品线/变体分组
- 按匹配类型分活动
- 按目标（品牌防御/竞品抢夺/拓展）分活动

### SP/SB/SD广告类型选择建议
- **SP（Sponsored Products）**：基础投放，适合所有阶段
- **SB（Sponsored Brands）**：品牌建设，适合有品牌注册的卖家
- **SD（Sponsored Display）**：再营销和拓展，适合成熟产品

### 自动广告与手动广告配合策略
- 自动广告用于关键词挖掘
- 手动广告用于精准投放高效词
- 定期将自动广告优质词转入手动广告
- 在手动广告中否定已转移的精准词

### 广告组织和命名规范
- 使用统一的命名格式：`[产品]-[广告类型]-[匹配类型]-[目标]`
- 示例：`ProductA-SP-Exact-Brand`

## 竞品分析

- 分析竞品广告投放的关键词
- 研究竞品广告位排名
- 识别竞品核心关键词
- 制定差异化广告定位建议
- 分析竞品标题和要点中的关键词布局

- 建议需要具体可执行，包含操作步骤
- 提醒用户测试和监控效果
