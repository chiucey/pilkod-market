# 网站重构需求文档模板

## 文档结构说明

本文档描述了网站重构需求文档的标准格式和填写指南。

### 必填章节

1. **项目概述** - 描述原始项目的核心功能和目标
2. **技术栈分析** - 识别的技术框架和架构模式
3. **界面与UI分析** - 详细的界面结构分解
4. **交互与功能分析** - 用户交互和业务逻辑
5. **重构建议** - 具体的技术改进方案

### 可选章节（游戏项目）

6. **数据架构** - 游戏特有的数据结构
7. **游戏机制** - 玩法和规则的详细定义

### 文档质量标准

- 每个章节需包含具体的技术细节
- 使用编号列表呈现组件和功能点
- 关键数据需标注单位（如px、ms、帧率）
- 重构建议需包含优先级标记（P0/P1/P2）

## 输出示例

```markdown
# 示例网站重构需求

## 1. 项目概述
- 目标：重构一个响应式博客系统
- 核心功能：文章发布、评论、用户管理

## 2. 技术栈分析
- 前端框架：Vue 3 + TypeScript
- 状态管理：Pinia
- CSS框架：Tailwind CSS
- 构建工具：Vite
```

## 与AI开发工具的协作

生成的文档应：
1. 包含完整的项目结构描述
2. 明确定义接口和数据模型
3. 提供实现优先级和时间估计参考
4. 附带必要的资源链接和参考文档
