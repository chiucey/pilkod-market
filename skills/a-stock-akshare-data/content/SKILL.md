# A股股票历史数据获取技能

## 技能概述

本技能使用akshare开源金融数据库获取A股股票的历史行情数据，默认获取最近120个交易日的数据。

## 核心功能

### 1. 获取单只股票历史数据

获取指定A股股票的历史行情数据，包括：
- 交易日期
- 开盘价
- 收盘价
- 最高价
- 最低价
- 成交量
- 成交额
- 涨跌幅

### 2. 批量获取多只股票数据

支持同时查询多只股票的历史数据，便于对比分析。

### 3. 数据导出

支持将数据导出为CSV或JSON格式，方便后续分析处理。

## 使用方法

### 基本查询

用户提供股票代码（如600519、000001）或股票名称即可查询。

## 技术实现

### 依赖库

```python
akshare - 金融数据接口库
pandas - 数据处理库
```

### 核心函数

```python
import akshare as ak
import pandas as pd
from datetime import datetime, timedelta

def get_stock_data(stock_code: str, days: int = 120) -> pd.DataFrame:
    """
    获取A股股票历史数据

    参数:
        stock_code: 股票代码（如600519、000001）
        days: 获取天数，默认120天

    返回:
        包含历史行情数据的DataFrame
    """
    # 使用akshare获取数据
    df = ak.stock_zh_a_hist(symbol=stock_code, period="daily",
                           start_date=(datetime.now() - timedelta(days=days*2)).strftime('%Y%m%d'),
                           end_date=datetime.now().strftime('%Y%m%d'),
                           adjust="qfq")

    # 返回最近days天的数据
    return df.tail(days)
```

### 股票代码格式

- 上证股票：6位数字，以6开头（如600519）
- 深证股票：6位数字，以0、2、3开头（如000001、300750）

## 注意事项

1. **数据限制**：akshare数据源可能存在一定延迟，实时数据需参考交易所官方接口
2. **停牌处理**：停牌期间无交易数据，查询结果会自动跳过
3. **复权处理**：默认使用前复权数据，保证历史价格的连续性
4. **查询频率**：避免高频查询，建议间隔5秒以上
5. **数据完整性**：部分股票历史数据可能不完整

## 错误处理

| 错误类型 | 处理方式 |
|----------|----------|
| 股票代码不存在 | 提示用户检查股票代码 |
| 网络连接失败 | 提示检查网络，重试查询 |
| 数据获取超时 | 减少查询天数或重试 |
| 停牌股票 | 提示股票当前停牌 |
