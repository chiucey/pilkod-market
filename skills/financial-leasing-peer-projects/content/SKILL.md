## 标准化工作流程

### 步骤一：确定调研范围

接受用户任务后，先确认以下要素：

- **对标分组**：指定对标组（1-6）或全行业扫描
- **目标公司**：指定同业公司名单或组内公司
- **时间范围**：近3个月/半年/年度汇总
- **业务类型**：航空/设备/医疗/新能源/船舶/基础设施等
- **输出形式**：Excel表格/Word报告/Markdown摘要/PPT

### 步骤二：多源信息采集

使用 `batch_web_search` 并行执行以下搜索：

```
搜索关键词模板：
- "<公司名> + 租赁 + <行业> + <年份>"（公司项目动态）
- "<公司名> + 债券 + 募集说明书"（深度业务布局）
- "金融租赁 + <行业> + 项目 + <年份>"（行业整体动态）
- "<公司名> + 年报 + <年份>"（财务与业务全景）
- "融资租赁 + 监管 + <年份>"（合规与政策动态）
```

每次搜索建议设置 `num_results=10`，按相关性和时间排序。

### 步骤三：深度内容提取

对高价值页面使用 `extract_content_from_websites` 提取：

- 项目公告中的融资金额、期限、增信信息
- 募集说明书中的业务结构、行业分布
- 年报中的战略方向、新增业务领域

## 信息质量评估标准

| 质量等级 | 标注 | 标准 |
|----------|------|------|
| 高 | ✅ | 来自官方公告、年报、募集说明书 |
| 中 | ⚠️ | 来自专业财经媒体（21世纪经济报道、证券时报等） |
| 低 | ⚠️ | 来自一般新闻源，尚未证实 |

> **注意**：金融租赁项目信息部分属于商业敏感信息，仅搜集和分析公开渠道可获取的内容，不得搜集或使用任何非公开信息（Non-Public Information）。

## 注意事项

1. **时效性优先**：金融行业项目动态更新快，优先采集近30天内的公开信息
2. **来源交叉验证**：关键数据点需在2个以上独立来源中确认
3. **金额单位标注**：区分人民币/美元，注明汇率换算基准
4. **合规边界**：仅使用公开信息，不涉及内幕信息或未公开数据
5. **历史对比**：尽可能与上期数据进行环比，便于发现趋势变化
