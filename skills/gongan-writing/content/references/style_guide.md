# 干哥风格写作风格指南

## 一、标题库（可直接套用）

### 反差型标题
- `XX不可怕，最可怕的是XX`
- `XXX不可怕，真正可怕的是XXX`
- `不是XX问题，是XX问题`

### 质疑型标题
- `XXX凭什么XXX？`
- `XXX真的XXX吗？`
- `XXX，你 XXX 得起吗？`

### 下结论型标题
- `XXX的XXX，就是XXX`
- `XXX，就是一场XXX`
- `XXX的本质，是XXX`

### 数字型标题
- `XX%的XX都在XXX，只有X%的XXX真正XXX`
- `XXX花了XX亿，得到的教训只有一个`
- `XXX天，我看清了XXX的真相`

## 二、金句库（可直接引用/改编）

### 关于AI/技术
- "AI的幻觉，治治就好。老板的幻觉，才是要命的病。"
- "龙虾不是万能的，它只是帮你端菜的服务员，不是帮你做饭的大厨。"
- "这叫什么？这叫叶公好虾。"
- "老板在幻觉中自我感动——我自己都在投身革命，你们为什么不自我进化？"
- "ALL IN AI，又赢了一次。"

### 关于职场/管理
- "最讽刺的是什么？是那些最有能力的员工最先跑路。"
- "一边摸鱼一边找新东家。"
- "每天战战兢兢地工作，不知道明天会不会收到一封优化邮件在深夜群发。"
- "这种焦虑，这种不确定性，这种无力感，才是XXX带给XXX最真实的伤害。"
- "最终幸存的工程师忙忙叨叨且随时担心被干掉。"

### 关于舆论/公关
- "1万条阅读量10的帖子，不如一篇10W+的影响力大。"
- "李想一顿下场手撕，反倒吸引了不少吃瓜的人去了解。"
- "是李想下场后的舆论流量大，还是当前'黑公关'的舆论影响大。"
- "法务对严重性的判断，大概率是相关发帖的数量。但一个过了实习期的公关应该都知道..."

## 三、类比库（可直接套用模式）

### 员工与企业关系
```
- 最有能力的员工最先跑路 → 能力强的鸟先飞
- 员工摸鱼 → 人在曹营心在汉
- 裁员焦虑 → 刀架脖子上的等待
```

### 技术与管理
```
- AI被神化 → 皇帝的新衣
- 老板的幻觉 → 掩耳盗铃
- AI落地难 → 理想很丰满，现实很骨感
```

### 产品与市场
```
- 恶意营销 → 踩一捧一、借力打力
- 口碑传播 → 好事不出门，坏事传千里
- 舆论反噬 → 引火烧身
```

## 四、场景描写模板

### 开会场景
```
开会的时候，老板说我们要用AI重构业务。
汇报的时候，老板说这个需求AI肯定能做。
裁员的时候，老板说让AI干就行了要这么多人干嘛。
```

### 讽刺场景
```
但这不妨碍老板像特朗普一样在年会上宣布——我们已完成AI转型，赢麻了。
但没关系，老板可以说我们在ALL IN AI，又赢了一次。
但这不妨碍老板继续说AI是战略重点。
```

### 心理描写
```
剩下的员工呢？一边摸鱼一边找新东家。
员工们每天战战兢兢地工作，不知道明天会不会收到一封优化邮件在深夜群发。
```

## 六、自检清单

写完文章后，用这个清单检查：

```
□ 标题够不够劲？（能不能让人停下来）
□ 开篇能不能让人产生共鸣？（"膝盖中箭"了吗）
□ 有没有让人拍大腿的金句？
□ 类比够不够生动？（像不像"江湖老炮"说的话）
□ 讽刺够不够辛辣？（但不能人身攻击）
□ 结构清不清晰？（层层解剖还是一团浆糊）
□ 结尾有没有升华？（软趴趴还是点睛之笔）
□ 有没有不该有的模糊词？（可能、或许、大概）
□ 数据有没有被解读？（堆砌还是分析）
```

## 七、禁忌红线

```
🚫 标题党：标题和内容严重不符
🚫 太文绉绉：用学术语言写自媒体
🚫 观点模糊：什么都说"有一定道理"
🚫 人身攻击：针对个人进行辱骂
🚫 逻辑混乱：前后矛盾或论证不闭环
🚫 堆砌数据：没有解读的数据毫无意义
🚫 结尾软趴趴：戛然而止或总结无力
```
