# 评分标准详解

## 方法新颖性 (Novelty)

| 分数 | 标准 |
|------|------|
| 9-10 | 开创性新范式 (如 Transformer, Diffusion 首次提出) |
| 7-8 | 显著架构创新 (如 Mamba, RetNet 等替代注意力) |
| 5-6 | 有效改进但非突破 (如注意力变体、损失函数调整) |
| 3-4 | 简单组合或应用迁移 |
| 1-2 | 增量改进或复现 |

## 问题重要性 (Significance)

| 分数 | 标准 |
|------|------|
| 9-10 | 领域长期瓶颈或新兴关键挑战 |
| 7-8 | 重要子领域的核心问题 |
| 5-6 | 具体问题但影响范围有限 |
| 3-4 | 边缘问题或已有充分解决方案 |
| 1-2 | 伪问题或过度简化 |

## 实验说服力 (Rigor)

| 分数 | 标准 |
|------|------|
| 9-10 | 多数据集 SOTA + 完整消融 + 统计显著性检验 |
| 7-8 | 主数据集 SOTA + 关键消融 |
| 5-6 | 有提升但对比不充分 |
| 3-4 | 实验设计有缺陷或对比不公平 |
| 1-2 | 缺乏关键实验或结果不可复现 |

## 潜在影响力 (Impact)

| 分数 | 标准 |
|------|------|
| 9-10 | 范式改变 + 工业界广泛采用潜力 |
| 7-8 | 显著影响特定子领域 |
| 5-6 | 对现有方法的有效补充 |
| 3-4 | 边际改进 |
| 1-2 | 适用范围有限 |

## 可复现性 (Reproducibility)

| 分数 | 标准 |
|------|------|
| 9-10 | 代码完全开源 + 预训练模型 + 详细配置 |
| 7-8 | 代码开源 + 核心实现完整 |
| 5-6 | 部分代码或伪代码可用 |
| 3-4 | 仅论文描述 |
| 1-2 | 无任何复现信息 |
