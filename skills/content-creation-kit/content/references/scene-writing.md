# 场景描写五感模板

## 五感清单（每场景至少覆盖2感）

| 感官 | 写什么 |
|------|--------|
| 视觉 | 形状、颜色、光影、距离 |
| 听觉 | 声音、静音（对比更强） |
| 嗅觉 | 气味 |
| 触觉 | 温度、质感、重量 |
| 味觉 | 味道（较少用，但用好很有效）|

---

## 核心技巧：对比

最有力的场景描写，是对比：
- **安静中的声音**：寂静的走廊里，只有自己的脚步声
- **黑暗中的光**：什么都看不见，只有远处一盏灯
- **人群中的孤独**：周围全是人，但没有一个认识

---

## 黑暗场景五感写法

```
他推开那扇门。

首先闻到的是一股霉味，像很久没晒的衣服。

然后是冷。

空气是湿的，贴在皮肤上不舒服。

他听到自己的脚步声。

咚、咚、咚。

在这安静的环境里，声音显得特别大。

他试着说话。

没有人回答。

只有回声。

他慢慢适应了黑暗。

能看到一些东西了。

墙角堆着几个箱子。

箱子上落满了灰。

还有很多蜘蛛网。

白色的，在风中轻轻晃动。

他突然觉得。

这里可能不是只有他一个人。
```

## 危险场景五感写法

```
森林里很安静。

安静得有些可怕。

没有鸟叫。

没有虫鸣。

只有脚踩在落叶上的声音。

咔嚓、咔嚓。

每一步都会发出声音。

他不敢走快了。

因为不知道黑暗中有什么。

突然。

一根树枝断了。

啪。

他猛地回头。

什么都没有。

但他感觉。

有什么东西在看他。

一直在看。
```

## 自检清单
- [ ] 至少覆盖了2个感官？
- [ ] 有没有对比手法（安静vs声音/黑暗vs光）？
- [ ] 细节够具体吗？（不是"很可怕"，而是"手心出汗，腿发软"）
- [ ] 叙述语气够冷静吗？（越冷静，越可怕）
