## 核心原则（所有模块通用）

**写给人看，不是写给算法看。**

1. 有画面感：读者能"看见"你写的东西
2. 有声音：句子有节奏，不是机器人在朗读
3. 有温度：情绪真实，不堆词藻
4. 有目的：每句话都有理由存在

## AI去味速查

见到以下词汇/句式，立刻替换：

| AI常用（换掉） | 人类写法 |
|--------------|---------|
| 综上所述 | 说了这么多 |
| 显而易见 | 你看 |
| 首先/其次/再次 | 先说/还有 |
| 总而言之 | 说白了 |
| 值得注意的是 | 说实话 |
| 深入挖掘 | 研究了研究 |
| 赋能 | 帮忙/让……更强 |
| 打造 | 做出来/弄出来 |
| 闭环 | 做完形成一套 |
| 链路 | 流程/步骤 |

## 句子长短节奏速查

**描写时用长句，推进时用短句。**

```
长句示例（场景/心理）：
图书馆很大，大到我一眼看不到边，
顶很高，大概有三四层楼那么高，
书架是木头的，颜色很深，看起来很旧了，
但是很结实，每一排都有两米多高，一直顶到天花板。

短句示例（剧情/关键时刻）：
他举起剑。
刺下去。
血溅了出来。
人倒了。
```

## 场景描写五感清单

每写一个场景，至少覆盖2感：

| 感官 | 示例 |
|------|------|
| 视觉 | 形状、颜色、光影 |
| 听觉 | 声音、静音 |
| 嗅觉 | 气味 |
| 触觉 | 温度、质感 |
| 味觉 | 味道 |

**对比写法最有效：**
安静中的声音 / 黑暗中的光 / 人群中的孤独

## 策划写作5步（完整文章）

1. **选内容**：平台最近在推的 + 读者真正需要的 + 自己能写明白的
2. **写标题**：直接模仿同领域已火过的标题，换核心词
3. **填内容**：开头（痛点引入）→ 中间（1/2/3点）→ 结尾（总结+提问）
4. **排版**：一段不超过3行；重要内容加粗；少用大段文字
5. **看数据**：阅读量、完读率、互动 → 下次改进

完整策划流程 → references/huoshi-biaozhun.md

## 自检清单（写完必读）

- [ ] 有没有一个3秒内让人想读下去的开头？
- [ ] 有没有具体的感官细节（视觉/听觉/触觉）？
- [ ] 对话像不像真实的人在说话？（每句都有目的吗？）
- [ ] 句子长短交错了吗？（没有全篇碎句，也没有全篇长句）
- [ ] 有没有可以说服读者的具体案例/数据？
- [ ] 结尾有没有让人想说点什么的空间？
