# 电子书内容提炼技能

## 核心原则

**严格忠于原文** - 所有总结内容必须基于电子书的实际文本，绝不添加、推测或编造任何内容。

## 工作流程

### 步骤 1：识别电子书格式

识别用户上传的电子书格式：
- **PDF**：使用 `extract_pdfs_full_content` 提取完整内容
- **EPUB/MOBI/TXT**：使用 `extract_content_from_websites` 或读取文件内容
- **其他格式**：根据扩展名选择合适工具

### 步骤 2：内容提取

1. 使用对应的提取工具获取电子书全文或核心章节
2. 对于长文档（>30页），分段提取，每段 20-30 页
3. 记录书籍基本信息：书名（如果可识别）、章节结构

### 步骤 3：深度分析与提炼

#### 提取以下核心元素：

1. **书籍概述**（1-2 段）
   - 主题是什么
   - 主要探讨什么问题
   - 目标读者群体

2. **核心观点**（3-7 条）
   - 书中最重要的 3-7 个核心论点
   - 每个论点需包含原文支撑或明确引用位置
   - 按重要性排序

3. **关键要点**（10-20 条）
   - 各章节的核心论据
   - 重要概念定义
   - 关键数据和事实
   - 重要引述

4. **精华摘录**（5-10 条）
   - 最具启发性的段落或语句
   - 原文引用，保持准确性
   - 简短点评说明为何重要

5. **逻辑结构**
   - 书籍的整体论证结构
   - 各部分之间的逻辑关系
   - 作者的论述思路

### 步骤 4：输出结构化总结

按照以下格式输出：

```
# 《[书名]》核心内容提炼

## 书籍概述
[1-2段书籍简介]

## 核心观点
1. [观点1]（原文依据）
2. [观点2]（原文依据）
...

## 关键要点
- [要点1]
- [要点2]
...

## 精华摘录
> "[原文摘录1]"
> "[原文摘录2]"
...

## 整体结构
[书籍的论证结构和逻辑线索]
```

## 质量控制

### 必须遵守：
- 只呈现书中**明确表达**的内容
- 引用重要段落时使用引号标注
- 对于推断性内容，明确标注"根据原文推断"
- 结构清晰，层次分明

### 严格禁止：
- 添加原文中不存在的内容
- 基于个人理解添加补充说明（除非用户明确要求）
- 编造名人名言或典故
- 夸大或歪曲作者原意

## 输出要求

- **篇幅控制**：核心观点 3-7 条，关键要点 10-20 条
- **语言风格**：简洁、专业、客观
- **可读性**：使用清晰的结构和小标题
- **实用性**：让读者能快速把握全书精华

## 适用场景

- 用户上传电子书并要求"总结"
- 用户要求"提炼精华"
- 用户要求"提取关键要点"
- 用户要求"萃取核心内容"
- 用户询问"这本书讲了什么"
