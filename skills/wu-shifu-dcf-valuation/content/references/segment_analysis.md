# 分部门分析模板

## 一、分部门分析框架

### 1.1 基本公式

```
部门营收 = 部门产量 × 部门平均售价(ASP)
         = Min(市场需求, 最大产能) × ASP
```

### 1.2 增长驱动因素分解

| 驱动因素 | 说明 | 量化方法 |
|----------|------|----------|
| 产量增长 | 市场份额/产能扩张 | YoY% |
| 价格增长 | ASP调整 | YoY% |
| 产品组合 | 高/低端产品占比 | Mix impact |
| 新产品 | 新品类贡献 | NTM contribution |

## 三、常见部门类型

### 3.1 产品型部门

| 分析要点 | 数据来源 |
|----------|----------|
| 销量 (Units) | 公司披露, 渠道调研 |
| 平均售价 (ASP) | 公司披露, 拆解 |
| 产品组合 | 产品线结构 |
| 市场份额 | 第三方数据 |

**公式**:
```
营收 = Σ (各产品线销量 × 对应ASP)
```

### 3.2 服务型部门

| 分析要点 | 数据来源 |
|----------|----------|
| 客户数量 | 公司披露 |
| 单客户价值 (ARPU) | 计算: 营收/客户数 |
| 客户留存率 | 公司披露 |
| 续费率 | 公司披露 |

**公式**:
```
营收 = 客户数 × ARPU
```

### 3.3 平台型部门

| 分析要点 | 数据来源 |
|----------|----------|
| GMV / 交易额 | 公司披露 |
| 货币化率 | 公司披露 |
| 活跃用户 (MAU/DAU) | 公司披露 |
| Take Rate | 计算 |

**公式**:
```
营收 = GMV × Take Rate
GMV = 活跃用户 × 交易频次 × 单笔金额
```

## 四、产量/产能分析

### 4.1 产能估算

```
产能 = 设备数量 × 每台产能 × 运转率
     = 产线数 × 每线产出 × 利用率
```

### 4.2 产能约束分析

| 指标 | 计算方法 | 参考值 |
|------|----------|--------|
| 利用率 | 实际产量/设计产能 | 70-95% |
| 产能利用率 | 已用产能/总产能 | 75-90% |
| 产能缺口 | 需求-供给 | >0表示短缺 |

### 4.3 扩张时间表

```
产能扩张里程碑:
├─ 2024Q1: Fab1 扩产20K/月
├─ 2024Q3: Fab2 完工
├─ 2025Q1: Fab2 量产爬坡
└─ 2025Q4: 总产能达200K/月
```

## 五、价格/ASP分析

### 5.1 ASP驱动因素

| 因素 | 影响方向 | 分析方法 |
|------|----------|----------|
| 产品结构 | 混合效应 | 高端占比↑ → ASP↑ |
| 定价策略 | 直接影响 | 公司指引 |
| 竞争态势 | 压力/支撑 | 竞品对比 |
| 成本传导 | 定价权 | 成本+毛利模型 |

### 5.2 ASP预测框架

```
ASP_t = ASP_t-1 × (1 + 价格调整%) × (1 + 结构变化%)
```

## 六、季节性处理

### 6.1 季节性因子

| 季度 | 历史占比 | 季节因子 |
|------|----------|----------|
| Q1 | 20% | 0.80 |
| Q2 | 25% | 1.00 |
| Q3 | 25% | 1.00 |
| Q4 | 30% | 1.20 |

### 6.2 季节性预测

```
季度营收 = 年度预测 × 季节因子
```

## 七、跨部门抵消

### 7.1 合并口径

```
总收入 = Σ 各分部营收 - 部门间抵消
```

### 7.2 示例

| 部门 | 营收 | 部门间销售 | 合并营收 |
|------|------|------------|----------|
| 部门A | 100 | (20) | - |
| 部门B | 80 | (10) | - |
| 合计 | 180 | (30) | 150 |

## 八、实战模板

### 8.1 半导体行业示例

```
【部门: 先进制程】
├─ 产能: 50K晶圆/月 (Fab 3未量产前)
├─ 利用率: 85% (季节性调整Q4 95%)
├─ ASP: $12,000/晶圆
└─ 预测:
   ├─ Y1: 50 × 12 × 85% × $12,000 = $612M
   └─ Y2: 70 × 12 × 90% × $12,000 = $907M

【部门: 成熟制程】
├─ 产能: 100K晶圆/月
├─ 利用率: 95%
├─ ASP: $6,000/晶圆
└─ 预测:
   ├─ Y1: 100 × 12 × 95% × $6,000 = $684M
   └─ Y2: 100 × 12 × 95% × $6,200 = $707M
```

### 8.2 消费品行业示例

```
【部门: 高端产品】
├─ 销量: 100万件 (YoY +15%)
├─ ASP: ¥500 (YoY +5%)
└─ 营收: ¥500M × 1.15 × 1.05 = ¥604M

【部门: 大众产品】
├─ 销量: 500万件 (YoY +3%)
├─ ASP: ¥100 (YoY +0%)
└─ 营收: ¥500M × 1.03 × 1.00 = ¥515M

【合并营收】: ¥604M + ¥515M = ¥1,119M
```
