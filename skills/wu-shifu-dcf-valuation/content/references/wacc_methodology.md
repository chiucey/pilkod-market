# WACC计算方法论

## 一、WACC基础框架

加权平均资本成本 (Weighted Average Cost of Capital) 是折现DCF现金流的核心参数。

```
WACC = Ke × E/(D+E) + Kd × (1-T) × D/(D+E)
```

| 符号 | 定义 |
|------|------|
| Ke | 股权成本 |
| Kd | 债务成本（税前） |
| E | 股权市场价值 |
| D | 债务市场价值 |
| T | 所得税税率 |

---

## 二、股权成本 (Ke) - CAPM模型

### 2.1 基本公式
```
Ke = Rf + β × (Rm - Rf)
   = Rf + β × ERP
```

### 2.2 参数说明

#### 2.2.1 无风险利率 (Rf)

**选择标准**:
- 主权债券收益率（与现金流期限匹配）
- 通常使用10年期国债收益率
- 中国市场：考虑中债国债收益率

**数据来源**:
- Bloomberg
- Wind
- 中国债券信息网

**示例**:
```
2024年1月 10年期国债收益率: 2.5%
```

#### 2.2.2 Beta系数 (β)

**定义**: 个股相对于市场的系统性风险

**计算方法**:
1. **历史Beta**: 基于历史收益率回归
   ```
   β = Cov(Ri, Rm) / Var(Rm)
   ```

2. **调整Beta**: 适用于小样本
   ```
   Adjusted β = 2/3 × Raw β + 1/3 × 1.0
   ```

3. **杠杆Beta与去杠杆化**
   ```
   βLevered = βUnlevered × [1 + D/E × (1-T)]

   βUnlevered = βLevered / [1 + D/E × (1-T)]
   ```

**数据来源**:
- Bloomberg (raw Beta, adjusted Beta)
- Capital IQ
- Yahoo Finance

#### 2.2.3 股权风险溢价 (ERP)

**定义**: 投资者因承担股票风险所要求的超额回报

**计算方法**:

1. **历史ERP (Historical)**
   - 使用历史数据估算
   - 中国：沪深300 vs 10年期国债

2. **隐含ERP (Implied)**
   - 基于当前股价和未来现金流倒推

3. **前瞻性ERP**
   - 结合历史和专家判断

**参考值**:
```
成熟市场 (美国): 5-6%
新兴市场 (中国): 6-8%
```

## 三、债务成本 (Kd)

### 3.1 方法一：基于评级
```
Kd = Rf + Credit Spread
```

| 评级 | 信用利差 |
|------|----------|
| AAA | 0.5-0.8% |
| AA | 0.8-1.2% |
| A | 1.2-1.8% |
| BBB | 1.8-2.5% |
| BB | 3.0-4.0% |

### 3.2 方法二：基于实际债务
```
Kd = 年利息支出 / 总债务 × 100%
```

### 3.3 方法三：基于债券收益率
- 使用可比公司债券
- 考虑期限结构

## 四、资本结构

### 4.1 目标资本结构 vs 当前结构

**两种方法**:

1. **当前市值法**
   - 使用当前股票市值
   - 使用债券面值或市值

2. **目标资本结构法**
   - 使用行业平均D/E
   - 假设公司会维持该结构

### 4.2 行业参考

| 行业 | 典型D/E |
|------|---------|
| 科技/成长 | 0.1-0.3 |
| 消费品 | 0.3-0.6 |
| 工业 | 0.5-0.8 |
| 金融 | 1.0-2.0 |
| 公用事业 | 0.8-1.2 |

## 五、WACC计算示例

### 5.1 假设参数

| 参数 | 数值 |
|------|------|
| 无风险利率 (Rf) | 2.5% |
| Beta (β) | 1.2 |
| 股权风险溢价 (ERP) | 6.0% |
| 税前债务成本 (Kd) | 4.0% |
| 所得税税率 (T) | 25% |
| 股权市值 (E) | 100亿 |
| 债务市值 (D) | 30亿 |

### 5.2 计算过程

**步骤1: 股权成本**
```
Ke = Rf + β × ERP
   = 2.5% + 1.2 × 6.0%
   = 2.5% + 7.2%
   = 9.7%
```

**步骤2: 加权计算**
```
E/(D+E) = 100/(100+30) = 76.9%
D/(D+E) = 30/(100+30) = 23.1%

WACC = Ke × E/(D+E) + Kd × (1-T) × D/(D+E)
     = 9.7% × 76.9% + 4.0% × (1-25%) × 23.1%
     = 7.46% + 0.69%
     = 8.15%
```

## 六、WACC敏感性分析

### 6.1 单因素敏感

| WACC | 每股价值 | 变化率 |
|------|----------|--------|
| 7.0% | ¥85.0 | +15% |
| 8.0% | ¥76.0 | +3% |
| **8.15%** | **¥73.8** | **基准** |
| 9.0% | ¥66.5 | -10% |
| 10.0% | ¥60.0 | -19% |

### 6.2 双因素敏感 (WACC vs g)

|  | g=2.5% | g=3.0% | g=3.5% |
|------|--------|--------|--------|
| WACC=7.5% | ¥82 | ¥88 | ¥95 |
| WACC=8.0% | ¥73 | ¥78 | ¥84 |
| **WACC=8.15%** | ¥69 | ¥73 | ¥78 |
| WACC=8.5% | ¥64 | ¥67 | ¥71 |

## 七、注意事项

### 7.1 常见错误

1. ❌ 使用错误的期限匹配的无风险利率
2. ❌ 未对Beta进行杠杆/去杠杆调整
3. ❌ 使用历史而非目标资本结构
4. ❌ 忽略小公司溢价
5. ❌ ERP与Beta来源不一致

### 7.2 合理性检查

- WACC应高于无风险利率
- WACC通常在8-12%范围（成熟市场）
- 新兴市场可能更高
