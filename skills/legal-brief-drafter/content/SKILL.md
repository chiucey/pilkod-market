# ⚖️ 法律文书起草助手 · Legal Brief Drafter

## 功能说明

当用户提供案件素材（庭审笔录、证据清单、法律条文、口头陈述要点等），需要整理成结构化法律文书时使用本技能。

支持：**庭后意见书、代理词、上诉状、答辩状、反驳意见书、质证意见**等常见法律文书。

---

## 支持场景

| 场景 | 说明 |
|------|------|
| 行政诉讼 | 行政相对人 vs 行政机关 |
| 民事诉讼 | 合同纠纷、侵权纠纷等 |
| 消费者权益保护 | 消费者维权案件 |
| 互联网平台纠纷 | 电商、平台责任、账号封禁等 |
| 合同纠纷 | 违约、解除、效力争议 |

## 核心功能模块

### 1. 文书类型选择
根据用户提供的素材类型，自动识别最合适的文书格式：
- `答辩状` — 被告针对起诉状的正式回应
- `代理词` — 诉讼代理人在庭审中的意见陈述
- `上诉状` — 当事人不服一审判决的正式上诉
- `反驳意见书` — 针对对方观点的逐一反驳
- `质证意见` — 对证据三性（真实性/合法性/关联性）的意见
- `法律意见书` — 综合法律分析报告

### 2. 论证策略库
- 核心论证策略库（法律要件分析）
- 程序合法性攻击框架（针对程序违法）
- 格式条款效力六维分析（民法典第497条）
- 循环论证识别与破解
- 逻辑矛盾揭示与利用

### 3. 置信度评估
每个法律论点附带置信度评级：
- 🟢 高置信度：有明确法条或判例支撑
- 🟡 中置信度：学理通说或地方性规定
- 🔴 低置信度：学理争议或仅理论推导

### 4. 类案检索指引
- 检索方向建议（关键词、法律要件）
- 裁判规则提炼方法
- 类案对比例证技巧

## 使用方法

### 基本用法

用户提供案件基本要素，我方自动生成结构化文书。

**标准输入格式：**
```
文书类型：答辩状
对方诉求：要求支付货款10万元及利息
我的立场：已付款，有银行转账记录
争议焦点：付款事实是否成立
适用法条：民法典第565、566条
案件材料：转账记录（附件1）、合同（附件2）
```

**输出：** 完整法律文书，含：事实陈述、法律分析、论证结论三大部分。

### 质证场景用法

用户提供证据清单，我方输出逐条质证意见：

**输入格式：**
```
质证对象：原告提交证据清单
证据1：购销合同（原告自制）
证据2：送货单（无签字）
证据3：证人证言（有利害关系）
```

**输出：** 逐条质证意见，标注证据三性质证结论。

## 注意事项

⚠️ **法律免责声明**
- 本技能生成的法律文书仅供参考，不构成正式法律意见
- 引用法条请以现行有效法条为准，我方可能引用错误或过时条款
- 重要案件请务必咨询执业律师或法律专业人士

⚠️ **数据安全**
- 避免输入当事人真实姓名、身份证号等敏感信息（脱敏后使用）
- 案件材料建议在可信网络环境下传输

⚠️ **内容核实**
- 生成的法律论点需自行核实法条依据
- 判例引用需核实时效性（2026年数据）
