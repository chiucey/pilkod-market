# 抖音账号管理 - 集成指南

## 概述

本技能提供抖音账号数据的自动化采集、同步和监控功能，通过与飞书平台集成实现实时的账号动态管理。

## 架构图

```
┌─────────────┐     ┌──────────────┐     ┌─────────────┐
│  抖音账号   │────>│ 数据采集器   │────>│ 飞书多维表格│
└─────────────┘     └──────────────┘     └─────────────┘
                           │
                           ▼
                    ┌──────────────┐
                    │ 飞书机器人   │
                    │ 通知推送     │
                    └──────────────┘
```

## 飞书集成步骤

### 1. 获取飞书 Webhook

1. 在飞书群中添加"自定义机器人"
2. 复制 Webhook 地址
3. 配置机器人名称和头像

### 2. 获取多维表格 App Token

1. 打开飞书多维表格
2. 点击右上角"..." -> "获取应用身份令牌"
3. 记录 App Token 和 Table ID

### 3. 配置权限

在飞书开放平台创建应用，添加以下权限：
- `docx:document:readonly`
- `bitable:app:readonly`

## 数据字段说明

| 字段名 | 类型 | 说明 |
|--------|------|------|
| account_id | string | 抖音账号唯一标识 |
| account_name | string | 账号昵称 |
| followers | int | 粉丝数量 |
| following | int | 关注数量 |
| likes | int | 获赞总数 |
| videos | int | 作品数量 |
| last_update | timestamp | 最后更新时间 |

## 定时任务配置

使用 cron 表达式配置定时采集：

```bash
# 每小时采集一次
0 * * * * /usr/bin/python3 /path/to/scripts/douyin_scraper.py

# 每天早上9点发送日报
0 9 * * * /usr/bin/python3 /path/to/scripts/feishu_bot.py
```

## 错误处理

| 错误码 | 说明 | 处理方式 |
|--------|------|----------|
| E001 | 账号不存在 | 检查账号ID是否正确 |
| E002 | Webhook无效 | 重新获取飞书Webhook |
| E003 | 同步超时 | 增加重试机制 |
| E004 | 数据解析失败 | 检查数据格式 |
