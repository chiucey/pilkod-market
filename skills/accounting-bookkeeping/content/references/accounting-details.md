# 会计做账详细参考

## 小规模纳税人 vs 一般纳税人

### 小规模纳税人
- 年应税销售额 < 500万元
- 不得开具增值税专用发票（可申请代开）
- 不得抵扣进项税额
- 征收率：1%（2023-2027）、5%（不动产租赁等）
- 按季度申报增值税

### 一般纳税人
- 年应税销售额 >= 500万元
- 可以开具增值税专用发票
- 可以抵扣进项税额
- 税率：13%（货物）、9%（服务、不动产）、6%（现代服务）
- 按月申报增值税

## 常见科目使用说明

### 应收账款 (1122)
核算因销售商品、提供劳务等应向购买方收取的款项。

**分录示例：**
```
销售商品未收款：
借：应收账款
  贷：主营业务收入
      应交税费-应交增值税（销项税额）

收到款项：
借：银行存款
  贷：应收账款
```

### 应付账款 (2202)
核算因购买材料、商品或接受劳务供应等应付给供应单位的款项。

### 管理费用 (6603)
核算企业为组织和管理生产经营发生的费用。

**明细科目：**
- 工资、社保、公积金
- 办公费、差旅费
- 业务招待费
- 折旧费、无形资产摊销
- 咨询费、顾问费

### 销售费用 (6602)
核算企业销售商品和材料、提供劳务的过程中发生的各种费用。

**明细科目：**
- 工资、社保
- 差旅费、业务招待费
- 广告费、宣传费
- 运费、装卸费

### 财务费用 (6604)
核算企业为筹集生产经营所需资金等而发生的筹资费用。

**明细科目：**
- 利息支出（减利息收入）
- 手续费
- 汇兑损益

## 月末结转模板

### 结转收入
```
借：主营业务收入            100,000
    其他业务收入              5,000
    投资收益                 10,000
    营业外收入               20,000
  贷：本年利润              135,000
```

### 结转成本费用
```
借：本年利润               100,000
  贷：主营业务成本           60,000
      其他业务成本            5,000
      销售费用               10,000
      管理费用               15,000
      财务费用                5,000
      营业外支出              5,000
```

### 计提企业所得税（盈利时）
税率：25%（一般企业），小微企业实际税负5%

```
借：所得税费用              8,750
  贷：应交税费-应交企业所得税  8,750
```

### 结转所得税
```
借：本年利润                8,750
  贷：所得税费用            8,750
```

## 发票类型及税率

### 增值税专用发票
- 一般纳税人之间使用
- 可以抵扣进项税
- 税率：13%、9%、6%

### 增值税普通发票
- 不能抵扣进项税
- 税率同专用发票

### 增值税电子普通发票
- 与普通发票同等效力
- 可抵扣需勾选认证

### 发票税率速查
| 行业 | 一般纳税人税率 | 小规模征收率 |
|------|---------------|-------------|
| 货物销售 | 13% | 1%/3% |
| 农产品 | 9% | 1%/3% |
| 运输服务 | 9% | 1%/3% |
| 建筑服务 | 9% | 1%/3% |
| 不动产租赁 | 9% | 5% |
| 餐饮住宿 | 6% | 1%/3% |
| 现代服务 | 6% | 1%/3% |

## 税收优惠

### 小微企业优惠
- 应纳税所得额 <= 100万元：实际税负2.5%
- 100万元 < 应纳税所得额 <= 300万元：实际税负5%
- 超过300万元：25%

### 增值税优惠
- 小规模纳税人月度销售额 <= 10万元（季度 <= 30万元）：免征增值税
- 2023-2027年：减按1%征收率

## 原始凭证整理要求

### 银行类
- 银行回单（收款、付款）
- 银行对账单
- 银行日记账

### 发票类
- 增值税专用发票抵扣联
- 增值税普通发票
- 收据（财政监制票据可税前扣除）

### 费用类
- 工资表（需盖章）
- 社保公积金缴费凭证
- 合同、协议
- 验收单、出库单

## 建账初始化数据

首次做账需要整理：
1. 注册资本及到位时间
2. 股东及出资比例
3. 公司成立日期
4. 固定资产原值及折旧年限
5. 开户银行及账号
6. 期初科目余额（如有）
