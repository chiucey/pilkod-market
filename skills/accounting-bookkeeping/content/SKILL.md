# 会计做账技能

## 快速开始

1. 确认客户纳税人类型（小规模/一般纳税人）
2. 收集原始单据：银行回单、发票、工资表、费用票据
3. 按业务流程处理

---

## 客户需要提供的资料

### 每月必须提供
- 🏦 银行对账单及回单
- 🧾 发票（进项票、销项票）
- 👥 工资表
- 📋 费用票据（差旅、业务招待、办公费等）

### 首次建账需要
- 🏢 营业执照副本
- 📝 公司章程
- 💰 注册资本及出资方式
- 👥 股东信息
- 🏠 注册地址

## 常见业务分录模板

### 银行收款
```
借：银行存款
  贷：主营业务收入
      应交税费-应交增值税（销项税额）
```

### 银行付款
```
借：原材料/管理费用-办公费/销售费用-差旅费等
  贷：银行存款
```

### 收到发票（进项）
```
借：原材料/管理费用等
  应交税费-应交增值税（进项税额）
  贷：应付账款/银行存款
```

### 开出发票（销项）
```
借：应收账款/银行存款
  贷：主营业务收入
      应交税费-应交增值税（销项税额）
```

### 工资计提
```
借：管理费用-工资
  贷：应付职工薪酬-工资
```

### 社保公积金计提
```
借：管理费用-社保/公积金
  贷：应付职工薪酬-社保/公积金
```

### 折旧计提
```
借：管理费用-折旧费
  贷：累计折旧
```

### 利息收入
```
借：银行存款
  贷：财务费用-利息收入（负数冲减）
```

## 月末处理流程

### 1. 核对银行账
- 银行对账单 vs 银行存款日记账

### 2. 核对发票
- 进项票认证（一般纳税人）
- 销项票汇总

### 3. 结转成本
```
借：主营业务成本
  贷：库存商品
```

### 4. 计提折旧
```
借：管理费用-折旧费
  贷：累计折旧
```

### 5. 计提工资及社保
```
借：管理费用-工资
  贷：应付职工薪酬
```

### 6. 结转收入
```
借：主营业务收入
  贷：本年利润
```

### 7. 结转成本费用
```
借：本年利润
  贷：主营业务成本
      管理费用
      销售费用
      财务费用
```

### 8. 计算所得税（如有盈利）
```
借：所得税费用
  贷：应交税费-应交企业所得税
```

### 9. 结转所得税
```
借：本年利润
  贷：所得税费用
```

## 报表输出

### 资产负债表
- 反映某一时点财务状况
- 资产 = 负债 + 所有者权益

### 利润表
- 反映一定期间经营成果
- 收入 - 费用 = 利润

---

## 增值税处理

### 小规模纳税人
- 征收率：3%（2023年起1%优惠）、5%
- 不得抵扣进项税
- 按季度申报

### 一般纳税人
- 税率：13%、9%、6%、0%
- 可以抵扣进项税
- 按月申报
- 一般计税方法：销项税 - 进项税 = 应纳税额

---

## 输出格式

做账完成后，提供：
1. **凭证汇总表** - 本月所有凭证清单
2. **科目余额表** - 各科目期初、期末余额
3. **资产负债表**
4. **利润表**
5. **税务建议** - 增值税、所得税申报提示

---

## 注意事项

1. **票账合一**：确保银行、发票、凭证三流一致
2. **合规性**：遵守会计准则，不做假账
3. **保留凭证**：原始单据妥善保存至少15年
4. **税负优化**：合理利用税收优惠政策
