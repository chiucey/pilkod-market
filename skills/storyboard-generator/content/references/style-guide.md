# 分镜风格配置参考指南

## 画幅比例详解

| 比例 | 名称 | 适用场景 | 分辨率示例 |
|------|------|----------|-----------|
| 16:9 | 标准电影 | 电视剧、网络视频 | 1920x1080, 1280x720 |
| 2.39:1 | 宽银幕 | 电影大片 | 2560x1080, 2048x858 |
| 4:3 | 经典比例 | 复古风格、纪录片 | 1440x1080 |
| 1:1 | 方形画幅 | 社交媒体、Instagram | 1080x1080 |

## 光影风格详解

### 自然光 (Natural Lighting)
- 柔和均匀的光线分布
- 适合日常场景、家庭戏
- 色温：5500K-6500K

### 黄昏光 (Golden Hour)
- 温暖的日落氛围
- 长阴影效果
- 适合浪漫、怀旧场景
- 色温：2700K-3500K

### 夜晚 (Night Scene)
- 深沉的夜色氛围
- 月光或人工照明
- 适合悬疑、科幻场景
- 色温：2000K-4000K

### 戏剧性侧光 (Dramatic Side Lighting)
- 强烈的明暗对比
- 强调人物轮廓
- 适合紧张、冲突场景
- 色温：6500K+

### 高对比黑白 (Film Noir)
- 经典黑色电影风格
- 硬调高对比
- 适合悬疑、黑色电影
- 无彩色

## 氛围色调详解

### 温暖 (Warm Palette)
- 暖色调：红、橙、黄
- 温馨、舒适的情感
- 适合爱情、家庭片

### 寒冷 (Cold Palette)
- 冷色调：蓝、青、灰
- 冷酷、疏离的情感
- 适合科幻、惊悚片

### 赛博朋克 (Cyberpunk)
- 霓虹色彩
- 未来科技感
- 适合科幻、动作片
- 常见色：品红、青、电蓝

### 复古 (Vintage)
- 褪色胶片感
- 怀旧、温馨
- 适合年代剧、爱情片
- 常见效果：颗粒、晕影

### 日式治愈 (Japanese Aesthetic)
- 清新自然
- 柔和色调
- 适合日常、治愈系
- 常见元素：樱花、绿植

### 电影冷峻 (Cinematic)
- 专业电影质感
- 中性色调
- 适合剧情、文艺片
- 常见风格：低饱和、高对比

## 镜头语言详解

### 远景 (Wide Shot / Establishing Shot)
- 广阔视野
- 展示环境全貌
- 常用于开场建立场景

### 全景 (Full Shot)
- 展示完整人物
- 人物与环境关系
- 常用于动作场面

### 中景 (Medium Shot)
- 人物腰部以上
- 平衡的人物与环境
- 最常用的对话镜头

### 近景 (Close-up)
- 人物肩部以上
- 突出表情
- 常用于情感表达

### 特写 (Extreme Close-up)
- 强调细节
- 情绪放大
- 常用于关键道具或表情

### 主观视角 (POV Shot)
- 第一人称视角
- 增强沉浸感
- 常用于追逐、恐怖

### 航拍 (Aerial / Drone Shot)
- 俯视全景
- 壮观展示
- 常用于开场或转场

## 剧本格式示例

### 基础格式
```
外景/日内 - 城市街道
男主角走向咖啡馆，步伐轻快

内景/夜 - 咖啡馆内
男主角推门而入
```

### 带时间码格式
```
00:00:15 - 00:00:22
女主角在窗边整理书架，偶尔望向窗外
```

### 复杂格式
```
[场号] 外景/日内 - 地点
- 动作描述
- 情绪描述
- 镜头指示
```
