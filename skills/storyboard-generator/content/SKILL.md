# Storyboard Generator - 场景角色分镜板

## 触发识别

当用户请求以下内容时触发此技能：
- 创建分镜 / 生成分镜
- 故事板设计 / 故事板制作
- 剧本可视化 / 剧本分镜
- 角色场景设定图
- 视觉叙事规划
- 影视制作分镜

## 核心能力

### 1. 角色参考管理
- 支持拖拽或点击上传角色参考图（最多4个）
- 支持 JPG/PNG/WEBP 格式，最大 10MB
- 为每个角色添加名称标注
- 支持预览和删除已上传角色

### 2. 剧本解析
- 多行文本区域，支持段落分隔
- 自动识别场景编号（数字序号）
- 支持时间码输入格式（如 `00:00:15 - 00:00:22`）
- 实时统计场景数和字符数

### 3. 风格配置
| 参数 | 选项 |
|------|------|
| 画幅比例 | 16:9 电影、2.39:1 宽银幕、4:3 经典、1:1 方形 |
| 光影风格 | 自然光、黄昏光、夜晚、戏剧性侧光、高对比黑白 |
| 氛围色调 | 温暖、寒冷、赛博朋克、复古、日式治愈、电影冷峻 |
| 镜头语言 | 远景、全景、中景、近景、特写、主观视角、航拍 |

### 4. 分镜生成
- 根据剧本段落数自动生成分镜图数量
- 保持角色一致性
- 显示生成进度
- 生成风格提示词（可复制到专业图像生成工具）

### 5. 分镜展示
- **网格视图**：4列缩略图展示
- **时间线视图**：横向时间轴浏览
- 点击放大预览
- 支持单帧下载和提示词复制

## 工作流程

### 标准流程

```
1. 初始化项目
   └─ 创建项目目录和 SPEC.md 规范文档

2. 上传角色参考
   └─ 用户拖拽或选择图片文件
   └─ 验证格式和大小
   └─ 转换为 base64 存储

3. 输入剧本内容
   └─ 用户输入场景描述
   └─ 自动解析场景段落
   └─ 提取时间码信息

4. 配置风格参数
   └─ 选择画幅比例
   └─ 选择光影风格
   └─ 选择氛围色调
   └─ 选择镜头语言

5. 生成分镜
   └─ 解析剧本段落为帧序列
   └─ 为每帧生成风格提示词
   └─ 调用图像生成工具
   └─ 更新生成进度

6. 展示与导出
   └─ 渲染分镜网格/时间线
   └─ 支持点击预览
   └─ 支持下载和复制
```

### 提示词生成逻辑

// 风格提示词组合
const stylePrompt = `
