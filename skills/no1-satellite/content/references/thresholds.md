# A股量化看板 - 参考文档

## 详细阈值表

### Z值状态定义

| 状态 | 阈值范围 | 含义 |
|------|----------|------|
| 极强 | > +2.0 | 个股相对大盘显著强势 |
| 偏强 | +1.0 ~ +2.0 | 相对大盘偏强 |
| 中性 | -1.0 ~ +1.0 | 与大盘同步 |
| 偏弱 | -2.0 ~ -1.0 | 相对大盘偏弱 |
| 极弱 | < -2.0 | 个股相对大盘显著弱势 |

### 换手率状态（小盘股参考标准）

| 状态 | 阈值范围 | 含义 |
|------|----------|------|
| 冰点 | < 2% | 交易极度清淡 |
| 正常 | 2% ~ 5% | 正常交易水平 |
| 活跃 | 5% ~ 15% | 交易活跃 |
| 高热 | 15% ~ 25% | 交易过热 |
| 极值 | > 25% | 极端投机 |

### Z值动量状态

| 状态 | 阈值范围 | 含义 |
|------|----------|------|
| 极强修复 | > +0.5 | Z值快速上升 |
| 强修复 | +0.3 ~ +0.5 | Z值明显上升 |
| 温和修复 | +0.1 ~ +0.3 | Z值缓慢上升 |
| 横盘 | -0.1 ~ +0.1 | Z值基本持平 |
| 温和恶化 | -0.3 ~ -0.1 | Z值缓慢下降 |
| 加速恶化 | < -0.3 | Z值快速下降 |
| 速度突变 | < -0.6 | 极端下跌信号 |

### 融资买入占比状态

| 状态 | 阈值范围 | 含义 |
|------|----------|------|
| 杠杆冷清 | < 10% | 融资参与度低 |
| 正常 | 10% ~ 20% | 正常杠杆水平 |
| 偏高 | 20% ~ 25% | 杠杆拥挤信号 |
| 极度拥挤 | > 25% | 极高杠杆风险 |

## 计算示例

### 示例数据

```
分析标的：【宁德时代 300750】
时间区间：2024-01-15 至 2024-02-05 (共16个交易日)
起始上证指数：2870.00
是否两融标的：是
近3个月最高价：218.00

逐日数据：
日期 | 收盘价 | 换手率 | 上证指数 | MA20 | 融资买入额 | 融资余额 | 成交额
2024-01-15 | 168.50 | 1.85% | 2870.00 | 170.23 | 8.52 | 85.23 | 42.60
2024-01-16 | 170.20 | 2.10% | 2880.50 | 170.45 | 9.15 | 86.58 | 45.75
...
```

### 逐日计算示例（2024-01-16）

1. **比价**：170.20 ÷ 2880.50 = 0.05906
2. **Z值**：假设近20日均值=0.0585，标准差=0.0012
   - Z值 = (0.05906 - 0.0585) / 0.0012 = 0.47
3. **换手/Z倍率**：2.10% ÷ 0.47 = 4.47
4. **Z值动量**：0.47 - (前日Z值如0.42) = +0.05
5. **融资净买入**：86.58 - 85.23 = +1.35亿
6. **融资买入占比**：9.15 ÷ 45.75 = 20.02%

## 信号触发示例

### 🟡 黄色预警示例

触发条件：换手/Z倍率连续3日 > 12
```
日期 | 换手/Z倍率
Day1 | 13.2 ✅ 触发
Day2 | 14.5 ✅ 触发
Day3 | 15.8 ✅ 触发
→ 🟡 黄色预警（禁止买入）
```

### 🔴 红色警报示例

触发条件：速度突变（Z值动量 < -0.6）
```
日期 | Z值动量
Day1 | -0.35
Day2 | -0.52
Day3 | -0.68 ✅ 触发
→ 🔴 红色警报（减仓至半仓以下）
```

### 🔴🔴 黑色警报示例

假设3日前Z值高点为+1.5：
- 当前Z值：+0.85（回落0.65 ≥ 0.5 ✅）
- 当日换手率：8.5%，近5日峰值12%（8.5% ≥ 12%×60%=7.2% ✅）
- Z值动量：-0.15 (< -0.1 ✅)
- 三项同时满足 → 🔴🔴 黑色警报

## 仓位管理速查

| 信号阶段 | 建议仓位 | 操作说明 |
|----------|----------|----------|
| 左侧标准（Z<-1.0） | ⅙ | 轻仓试错，分2-3天介入 |
| 左侧标准（Z≥-1.0） | ¼ | 轻仓试错 |
| 强势延续 | ¼ | 入场价下方-5%或MA20止损 |
| 右侧确认 | 80% | 加仓至正常仓位 |
| 末端背离 | ⅙ | 轻仓试错 |
