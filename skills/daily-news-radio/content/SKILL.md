# 每日新闻电台

## 技能概述

以电台播报形式，为用户快速汇总当日最新、最热的新闻资讯。语言通俗易懂，适合快速了解当日要闻。

## 执行流程

### 1. 确定播报日期

确认是生成今日新闻还是指定日期的新闻汇总。

### 2. 多平台新闻采集

使用网络搜索工具，从以下渠道获取最新新闻：

| 平台 | 搜索关键词策略 |
|------|---------------|
| 央视新闻 | `site:cctv.com 今日新闻` + 当天日期 |
| 今日头条 | `site:toutiao.com 热点新闻` |
| B站热搜 | `bilibili 热搜 最新` |
| 抖音热点 | `抖音 热榜 今日` |
| YouTube新闻 | `youtube 新闻 最新` |

**搜索批次安排**：
- 批次1：央视新闻 + 今日头条（权威官方渠道）
- 批次2：B站热搜 + 抖音热点（年轻人关注热点）
- 批次3：微博热搜 + 百度热搜（综合热度参考）

### 3. 新闻分类整理

将采集到的新闻分为以下类别：

```
📰 时事要闻
🎭 娱乐热点
🎉 有趣趣闻
💡 科技动态
📺 视频热点
```

### 4. 电台播报格式输出

采用以下结构化播报格式：

```markdown

📰 【时事要闻】
• 头条新闻标题
  简要播报内容（2-3句话通俗易懂）

  简要播报内容...

🎭 【娱乐热点】

  内容简述...
```

## 输出质量标准

1. **时效性**：新闻必须是最近7天内的内容
2. **通俗性**：避免专业术语，用简单语言解释复杂事件
3. **平衡性**：涵盖政治、娱乐、科技、社会多个领域
4. **趣味性**：适当加入趣闻，调节严肃新闻的节奏
5. **简洁性**：每条新闻控制在50字以内的核心内容

## 数据来源优先级

1. 央视新闻、人民日报（权威性）
2. 今日头条、微博热搜（热度参考）
3. B站、抖音热榜（年轻群体关注）
4. YouTube新闻频道（国际视角补充）
