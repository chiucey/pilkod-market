# 校准证书PDF提取技能

## 功能概述

从校准证书PDF和图像中提取关键信息，生成标准化的8列Excel汇总表。支持PDF文档和测试数据图像（如功率测试、功率因数测试等）的识别提取。

## 输出格式

### Excel列定义

| 列名 | 说明 |
|------|------|
| 证书编号 | 证书唯一标识符（如J26134S00066） |
| 器具名称 | 被校准设备/仪器的名称 |
| 型号/规格 | 设备的具体型号和技术规格 |
| 制造单位 | 生产厂家 |
| 出厂编号 | 设备出厂时的唯一序列号/资产编号 |
| 校准日期 | 校准执行日期 |
| 校准依据 | 引用的校准规范/规程（包含完整名称） |
| 数据测试内容 | 测试项目、测试条件、测试点数据 |

## 提取规则

### 1. 校准依据（必填）

- 提取所有校准依据，包括完整的规范名称
- 包含括号内的补充说明（如"JJF（鲁）90-2011 工作用数字温度计校准规范"）
- 多条依据分行显示

### 2. 数据测试内容（必填）

**核心原则**：数据测试内容只需记录"测了什么项目、有没有额外条件、测了几个点"，**不需要**记录误差值、重复性值、稳定性值或不确定度。

格式结构：
```
[测试项目名称]
通道：[T1/T2/T3...或具体通道名称]
测试条件：[温度/电压/频率等参数]
测试点(单位)：[数值列表]
```

#### 必须记录的测试项目

**所有测试项目必须完整记录，包括：**

1. **带"*"的测试项目**：如"*外观检查"、"*常规检查"等，星号项目必须写入
2. **重复性测试**：如"重复性"、"流量重复性"、"波数重复性"、"透射比重复性"等
3. **稳定性测试**：如"稳定性"、"流量稳定性"等
4. **示值误差测试**：如"示值误差"、"流量示值误差"、"波数示值误差"等
5. **其他测试项目**：分辨力、平直度、噪声、计时误差等

**重要**：不要对PDF中的测试项目名称进行联想或简化，保持原文记录。如PDF写"波数示值误差"就记录"波数示值误差"，不要简化为"示值误差"。

#### 通道信息（必填）

当PDF测试页有"通道"信息时，必须完整记录：
- **通用通道**：T1/T2/T3/T4/T5/T6/T7等
- **专用通道**：环境温度、壳体温度、吸气温度等
- **通道总数**：如"(10CH)"、"(30通道)"
- **格式**：通道：T1/T2/T3/环境温度/壳体温度/吸气温度(10CH)

#### 测试条件包含项

- 温度条件：测试环境温度（如"环境温度22.1℃"）
- 湿度条件：测试环境湿度（如"湿度56.2%RH"）
- 电压/电流：供电参数（如"DC 5V"）
- 频率：工作频率（如"50Hz"、"60Hz"）
- 通道数：传感器通道（如"10CH"、"(10通道)"）
- 特殊状态：水平试验状态、重力加速度等

#### 测试点数据格式

- 标称值/示值/实际值数据点
- 单位标注在括号内（如"(MPa)"、"(℃)"、"(μL)"）
- 多组数据用"/"分隔
- 特殊情况标注（如"(一号仓/二号仓)"）

#### 测试点分布图（必填）

当PDF中有测试点分布图且标明了方向性位置时，必须记录：
- **测试点编号**：A/B/C...或数字编号
- **层级分布**：上层/中层/下层（或前/中/后）
- **方向性位置**：左前角/右后角/中心点等
- **与内壁距离**：前/后/左/右/上/下的具体距离（mm）

**示例**：
```
测试点分布：15点（上中下三层）
- 上层：A(甲)/B/C/D/E
- 中层：F/I(丁)/G/H/O(丙)
- 下层：M/J/L/K(乙)/N
与内壁距离：前120mm/后120mm/左120mm/右120mm/上100mm/下100mm
```

#### ⚠️ 排除项

**不提取的内容：**

1. PDF第二页的环境温度和湿度（不是测试条件，是校准环境）
   - 如"环境温度22.5~23.5℃，湿度54.5~56.5%RH"出现在证书第二页环境条件处时应忽略

2. **测试页的实测值数据**
   - 只提取测试点列表（如"测试点(kg)：1/10/40/100/150"）
   - **不提取**每个测试点的具体测量结果（如"1kg时示值1.002kg、实际值1.001kg"）
   - 只需要知道测哪几个数据点，不关心具体测下来是多少

3. **测量不确定度**
   - 不提取PDF中的测量不确定度数据
   - 如"U=0.1kg, k=2"、"扩展不确定度U=0.05%"等数据应忽略
   - 测量不确定度通常出现在证书的专门章节或附表中，不需要写入汇总表

4. **误差值、重复性、稳定性数值（具体测量结果）**
   - **不提取**示值误差的具体数值（如"误差+0.002kg"）
   - **不提取**重复性测试的具体数值（如"重复性0.01%"）
   - **不提取**稳定性测试的具体数值（如"稳定性0.02%"）
   - **不提取**任何百分比或绝对值形式的误差数据
   - **✅ 但必须记录**：测试项目名称本身（"重复性测试"、"稳定性测试"等）

5. **比较性描述中的阈值**
   - 不提取"大于XX"、"小于XX"、"不低于XX"等比较性描述中的具体数值
   - 如"亮度大于250cd/m²" → 记录为"[亮度测试]"或"[亮度]"
   - 如"均匀性大于80%" → 记录为"[均匀性测试]"或"[均匀性]"
   - **只需记录测试项目名称**，不记录"250"或"80"等数值

#### ⚠️ 完整性要求（必须遵守）

**核心原则**：每个测试项目下的**所有测试条件**和**所有测试点**都必须完整提取，**不能遗漏任何内容**。

**多条件测试项目处理规则：**
1. **同一测试项目有多个频率条件** → 每个频率条件分别记录
   - 例如："电压（50Hz）"、"电压（60Hz/400Hz/DC）"是不同的测试条件，都要记录

2. **同一测试项目有多个量程/单位** → 每个量程分别记录
   - 例如：电流测试有mA档和A档 → 测试点(mA)：... / 测试点(A)：...

3. **同一测试项目有多个PF条件** → 每个PF条件分别记录
   - 例如：电能测试有PF=1、PF=0.5、PF=-0.5 → PF=1测试点：... / PF=0.5测试点：... / PF=-0.5测试点：...

4. **测试点完整性检查** → 提取后必须核对
   - 逐一核对PDF中每个测试项目的表格行数
   - 确保所有测试点（输入值）都已记录，不能只记录部分
   - 例如：功率测试表格有17行输入值，就必须记录17个输入值点

**示例 - 电能测试的正确记录方式：**
```
[电能]
通道：CH1/CH2/CH3
PF=1测试点(mWh)：11.000(Wh)/0.02/0.05/0.1/0.2/0.5/1/10/100/1000
PF=0.5测试点(mWh)：1/10/100
PF=-0.5测试点(mWh)：1/10/100
```
**错误示范（遗漏）：**
```
[电能]
测试点(mWh)：...（只记录了PF=1，遗漏了PF=0.5和PF=-0.5）
```

### 3. 测试条件示例

| 场景 | 示例 |
|------|------|
| 温度测试 | 测试条件：-20.0℃/0.0℃/50.0℃/100.0℃/150.0℃ |
| 通道测试 | 通道：T1/T2/T3/T4/T5/T6/T7/环境温度/壳体温度(10CH) |
| 频率测试 | 测试条件：50Hz, 60Hz |
| 速度测试 | 测试点(m/s)：2±0.2 |
| 力值测试 | 测试点(N)：100/200/400/800/1200/1600/2000 |

## 执行流程

### 步骤1：PDF内容提取（标准化提示词）

使用 `extract_pdfs_key_info` 工具批量提取PDF内容，**必须使用以下标准化提示词**：

```
请从校准证书PDF中提取以下信息，按固定格式输出：

【基本信息】
1. 证书编号：（如J26134S00066）
2. 器具名称：（设备名称）
3. 型号/规格：（具体型号）
4. 制造单位：（生产厂家）
5. 出厂编号：（序列号/资产编号，若无则填"-"）
6. 校准日期：（如2026年4月1日）
7. 校准依据：（完整规范名称，含括号内容）

【数据测试内容】
格式固定为：
[测试项目名称]
通道：[完整通道列表]
测试点(单位)：[数值用"/"分隔]

【必须记录的所有测试项目】
- 所有测试项目（包括示值误差、重复性、稳定性、计时误差等）
- 重复性测试：如"重复性"、"流量重复性"、"重复性、稳定性"等
- 稳定性测试：记录测试项目名称，不需要记录稳定性具体数值
- 时间测试：如"计时误差"、"时间"等时间相关测试
- 其他测试项目都要列出名称

【测试点分布图】（如有）
- 测试点编号和层级分布
- 方向性位置（左前角、右后角、中心点等）
- 与内壁距离（前/后/左/右/上/下mm）

【排除项】
- 不提取PDF第二页的环境温湿度（校准环境）
- 不提取测试页的详细实测值（每个点的示值/实际值）
- 不提取测量不确定度
- 不提取重复性、稳定性、误差的具体数值
- 不提取比较性描述中的阈值（如"大于250"、"不低于80"）
```

**重要**：
- 通道信息必须完整提取，包括T1/T2/T3和环境温度、壳体温度、吸气温度等
- 测试点分布图的方向性位置必须记录
- 所有测试项目必须完整记录，包括带"*"的项目（如"*外观检查"）
- 重复性、稳定性、示值误差等测试项目必须完整记录原始名称
- 不要对测试项目名称进行联想或简化，保持原文记录
- **每个测试项目下的所有测试条件和所有测试点必须完整提取，不能遗漏**
- **对于有多个频率条件、多个量程单位、多个PF条件的测试项目，必须分别记录每个条件**
- **提取后必须核对PDF中每个测试项目的表格行数，确保所有测试点都已记录**
- 每次提取必须严格按照上述固定格式，确保输出一致性

### 步骤2：数据整理

按8列格式组织数据：
1. 证书编号
2. 器具名称
3. 型号/规格
4. 制造单位
5. 出厂编号
6. 校准日期
7. 校准依据
8. 数据测试内容

### 步骤3：生成Excel

使用Python openpyxl库生成Excel文件：
- 表头加粗、居中
- 自动换行显示长文本
- 保持数据可读性

## 图像数据提取规则（适用于测试数据图片）

### 适用场景

当用户提供的是测试数据图像（如截图、照片、PDF中的测试数据表格图片）时，使用以下规则：

### 图像提取标准化提示词

使用 `images_understand` 工具提取图像数据，**必须使用以下标准化提示词**：

```
请识别这张图片中的所有测试参数数据，按固定格式输出：

【提取内容】
1. 测试项目名称（如：功率、功率因数）
2. 测试条件（如：电压/电流/频率参数）
3. 输入值（如：220V/20mA/PF=1）
4. 实际值
5. 各通道数据：CH1、CH2、CH3等（如有）

【输出格式】
| 测试点 | 输入值 | 实际值 | CH1 | CH2 | CH3 |
|--------|--------|--------|-----|-----|-----|

【重要】
- 严格按照表格结构提取
- 每行数据都要完整提取
- 保持数值精度
```

### 图像提取示例

#### 示例1：功率测试

```
测试项目：功率
| 测试点 | 输入值 | 实际值 | CH1 | CH2 | CH3 |
|--------|--------|--------|-----|-----|-----|
| 1 | 220V/20mA/PF=1 | 4.4000 W | 4.40 W | 4.40 W | 4.40 W |
| 2 | 220V/50mA/PF=1 | 11.000 W | 11.00 W | 11.00 W | 11.00 W |
```

#### 示例2：功率因数测试

```
测试条件：功率因数(100V/1A@50Hz)
| 测试点 | 实际值 | CH1示值 | CH2示值 | CH3示值 |
|--------|--------|---------|---------|---------|
| 1 | 1.0000 | 1.0000 | 1.0000 | 1.0000 |
| 2 | 0.8000C | 0.8000 | 0.8000 | 0.7999 |
| 3 | 0.5000C | 0.5001 | 0.5000 | 0.4999 |
```

### 常见测试类型

| 测试类型 | 提取字段 |
|----------|----------|
| 功率测试 | 输入值、实际值、CH1、CH2、CH3 |
| 功率因数测试 | 测试条件、实际值、CH1示值、CH2示值、CH3示值 |
| 多通道测试 | 测试点、各通道示值 |
| 参数扫描 | 输入参数、对应输出值 |

### 图像提取后Excel生成

图像数据提取后，生成独立的Excel文件或单独的Sheet：
- Sheet名称：测试项目名称（如"功率测试"、"功率因数测试"）
- 列标题：表头内容（如"测试点"、"输入值"、"CH1"、"CH2"、"CH3"）
- 数据格式：保持原始精度

## 注意事项

1. **环境条件区分**：区分"测试环境条件"和"测试项目条件"
2. **规范完整性**：校准依据必须包含括号内内容
3. **数据点完整性**：记录所有测试点数值，不遗漏
4. **多通道标注**：对于多通道测试，明确标注通道数量
5. **图像数据完整性**：图像提取时必须提取所有行数据，保持表格结构
6. **通道信息完整性**：通道信息必须完整提取，包括T1/T2/T3和环境温度、壳体温度、吸气温度等专用通道
7. **测试点分布图**：当有分布图时，必须记录测试点编号、层级分布、方向性位置和与内壁距离
