# 校准证书PDF提取指南

## PDF来源

本技能适用于**上海市质量监督检验技术研究院有限公司**出具的校准证书。

## PDF结构分析

### 第一页通常包含

1. **证书编号**：页面顶部，如"J26134S00066"
2. **器具信息**：
   - 器具名称：如"燃烧性测试机"
   - 型号/规格：如"JY-08"
   - 制造单位：如"苏州苏试试验集团股份有限公司"
3. **校准日期**：如"2026年4月1日"
4. **校准依据**：完整的规程/规范名称
5. **校准条件**：测试时的环境条件
6. **校准项目**：列出所有校准项目及测试点

### 第二页通常包含

1. **详细测试数据**：标称值、示值、实际值
2. **环境条件**：校准实验室的温湿度（**不提取**）
3. **不确定度分析**
4. **签名和印章**

## 提取提示词模板

### 批量提取PDF内容

```
请提取以下信息（如果存在）：
1. 证书编号
2. 器具名称
3. 型号/规格
4. 制造单位
5. 校准日期
6. 校准依据（完整名称，包含括号内容）
7. 测试项目及其测试条件
8. 测试点数据（标称值、示值、实际值）

注意：
- 排除证书第二页的环境温度和湿度（不是测试条件）
- 测试条件应包含温度、湿度、频率、通道数等参数
- 测试点数据应包含单位标注
```

### 单个PDF详细提取

```
请详细提取此校准证书中的：
- 证书基本信息（编号、名称、型号、制造单位、日期）
- 所有校准依据（完整引用）
- 校准项目列表
- 每个项目的测试条件
- 所有测试点及其实测数据

格式要求：
测试项目名称
  测试条件：[参数]
  测试点(单位)：[数值列表]
```

## 数据验证检查清单

提取后，请验证：

- [ ] 证书编号格式正确（如J26xxx格式）
- [ ] 器具名称完整，无遗漏
- [ ] 型号/规格包含完整技术参数
- [ ] 校准日期格式统一（如"2026年4月1日"）
- [ ] 校准依据包含括号内补充说明
- [ ] 测试条件包含必要的参数（温度/频率/通道等）
- [ ] 测试点数据完整，无遗漏

## 常见问题处理

### Q: PDF中找不到某些字段怎么办？

A: 检查是否为可选字段，或尝试在不同页面查找。部分信息可能在备注或附件中。

### Q: 测试条件缺失怎么办？

A: 如果PDF未提供测试条件，可以标注"测试条件：详见证书正文"，但应尽量提取。

### Q: 多条校准依据如何处理？

A: 每条依据单独一行，使用换行符分隔。

### Q: 环境温湿度是否提取？

A: **不提取**。证书第二页的环境温湿度是实验室条件，不是测试条件。只有测试项目内明确标注的温湿度才需要提取。
