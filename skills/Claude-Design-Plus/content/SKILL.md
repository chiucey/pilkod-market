# Claude-Design-Plus

让 AI 成为你的设计伙伴。通过自然语言对话，即可生成专业级设计稿、可交互原型和演示文稿。

## 核心能力

| 能力 | 说明 |
|------|------|
| 🎯 **自然语言驱动** | 说出你的想法，AI 帮你转化为专业设计 |
| 🏢 **50+ 设计系统内置** | 覆盖国际大厂 + 中国知名企业，开箱即用 |
| ⚡ **所见即所得** | HTML 原型可交互调整，Tweak 实时预览 |
| 📊 **多格式导出** | PPTX、PDF、HTML，满足不同场景 |
| 🎨 **一键切换风格** | 不同品牌设计系统，视觉一致性保障 |
| 🔧 **无需设计工具** | 不需要 Figma、Sketch，在对话中完成设计 |

## 工作流程

```
1️⃣ 描述需求
   "帮我设计一个电商 App 的登录页面"
   "做一个 SaaS 产品的落地页"
   "设计一个金融 App 的首页"

            ↓

2️⃣ 选择设计系统
   从内置列表中选择，或描述你的品牌风格
   AI 会根据选择的设计系统生成对应风格的设计

            ↓

3️⃣ 探索变体
   AI 展示 2-3 个不同设计方案
   你可以：选择喜欢的 / 提出修改 / 混合风格

            ↓

4️⃣ 精细调整 (Tweak)
   使用 Tweak 面板实时调整：
   - 颜色、字体、间距
   - 布局变体、组件状态
   - 内容文案、图标风格

            ↓

5️⃣ 导出交付
   HTML 原型 → 可分享链接
   PPTX → 可编辑演示文稿
   PDF → 打印/导出
```

## 设计原则

### DO ✅
- 描述你的用户是谁、他们的需求是什么
- 说明设计的使用场景（移动端、网页、印刷品）
- 提供品牌素材或参考链接
- 明确指出必须包含的元素
- 要求多个变体进行比较

### DON'T ❌
- 不要只说"做个好看的设计"
- 不要期望 AI 完全猜对你的意图
- 不要跳过设计系统的选择

## 常见问题

**Q: 需要设计经验吗？**
A: 不需要。你只需要描述你的想法，AI 会处理专业的设计细节。

**Q: 生成的设计可以商用吗？**
A: 生成的设计属于你，可以用于任何商业目的。设计系统本身（如 Ant Design）是开源的。

**Q: 如何选择设计系统？**
A: 如果你有品牌指南，用你的品牌；否则根据产品类型选择：开发者工具用 Vercel/Linear，消费产品用 Apple/Google，金融产品用 Stripe/支付宝。

**Q: 支持自定义设计系统吗？**
A: 支持。你可以提供 Figma 文件、设计规范文档，或描述你的品牌特征。

**Q: 导出格式有什么区别？**
- HTML: 可交互原型，最灵活
- PPTX: 演示文稿，可编辑
- PDF: 打印用，高保真
