# 判断内核:主力阶段 · 洗盘vs出货 · 量价 · 承接力

## 1. 主力完整四阶段模型

读懂主力周期是为了辅助判定个股所处位置。**同样的 K 线组合在不同阶段意义完全相反**,先定位再谈买卖。

| 阶段 | 特征 | 应对 |
|---|---|---|
| **建仓(吸筹)** | 长期阴跌后小阴小阳横盘;低点缓慢抬高和放大;下跌缩量 | 不急于介入,放入自选跟踪 |
| **洗盘/震仓** | 成本区震荡 3~5 天;主升途中日内振幅突增至 8%+;长下影/十字星;**略放量或持平,非暴量** | 黄金低吸点;持仓者锁仓,场外轻仓低吸 |
| **主升拉升** | 连续新高,多头排列;良性回落缩量;中后期缩量加速板 | 沿 5/10 日线锁仓;首次爆量分歧日二次上车 |
| **出货(派发)** | 高位放量滞涨;长上影/墓碑线/高开低走大阴;历史天量;**量顶天价不涨** | 坚决规避;持仓者分批清仓 |

## 2. ★ 震仓(洗盘) vs 出货 六大区分标准

回答"出货还是洗盘"的标准答案。每条对照时必须落到**具体数据**。

| # | 维度 | 震仓(洗盘) | 出货(派发) |
|---|---|---|---|
| 1 | **位置** | 主升途中 / 突破前高之前 | 高位爆量滞涨区 |
| 2 | **分时** | 急杀 -3%~-6% 后**有承接迅速拉回**;均价线不跟随股价创新低 | 下跌带持续大单砸;均价随股价同步创新低;反抽无力 |
| 3 | **K线** | 长下影阴/阳线、十字星;烂板但**不破关键位** | 高位墓碑线;跌破关键均线后无量反抽 |
| 4 | **量能** | **略放量或平量**,次日快速缩量反包 | 高位**持续放量不涨**,或下跌带量 |
| 5 | **板块** | 板块有其他助攻,中军稳住 | 板块集体退潮,龙头孤立补跌 |
| 6 | **锚点** | **不破锚**(5日线 / 大阳半分位 / 分歧日最低) | **破锚无承接** |

### 判定规则
- 命中"出货"特征 **≥3 条** → 判派发
- 命中"洗盘"特征 **≥4 条且破锚** → 破位走人
- 两条都沾(典型:放量长上影 + 主力净流出但换手仍可控) → 定性为**分歧临界**,给条件式结论(带明确触发条件)

### 锚点(防守位)怎么定
| 场景 | 锚点 |
|---|---|
| 主升首分歧 | 分歧日最低价 |
| 涨停回踩 | 涨停阳线半分位(强票不破开盘价) |
| B 点 | B 点当日最低价 -0.5% |
| 涨停缩量回踩 | 止跌 K 线最低价 -5% |
| 通用 | 5 日线 |

### 常见误判
- **把下跌中继当震仓**:退潮期的急跌反抽多是下跌中继,不按震仓低吸处理
- **把高位放量滞涨当洗盘**:位置错了,量能再漂亮也是派发
- **只看一天资金流就下结论**:单日大单可能是对倒换手,必须看 3-5 日连续方向 + 换手率

## 3. ★ 量价关系六大原则

**同样的量价组合在高位和低位意义完全相反**,先说位置再下结论。

| 量价组合 | 低位 | 高位 |
|---|---|---|
| **量增价涨** | 多头主动买入推升,趋势健康,坚定持有 | 加速赶顶,需谨慎 |
| **量缩价涨** | 筹码锁定,等补量 | **虚涨背离,见顶预警,不追** |
| **量增价跌** | 恐慌盘涌出 / 主力挖坑震仓,等企稳 | **主力疯狂派发,果断离场** |
| **量缩价跌** | 无主动抛压的自然回落,良性回调,等企稳 | 无人接盘,继续看跌 |
| **量增价平** | 横盘滞涨常见主力温和吸筹,可关注 | **出货前兆(量顶天价不涨),坚决清仓** |
| **量缩价平** | 交投清淡,底部磨底或方向选择前夕,观望 | 下跌中继,回避 |

**买入纪律:必须等量缩至"地量芝麻点"后,再次出现"倍量红阳"拐头向上。**

## 4. ★ 分时承接力(真承接 vs 无承接)

承接是主力主动护盘和吸筹的语言。判定靠两个观察:**下探时的量能** + **均价线是否跟随创新低**。

| 良性承接(真) | 劣质无承接(诱多出货) |
|---|---|
| 股价随板块下杀时抛压呈**缓跌或锯齿状**回落 | 分时呈 **90° 垂直直线跳水** |
| 分时低点**逐级抬高**,两次回踩不破前低 | 买一~买五挂单极薄弱,被快速扫单下破,**下破后不补** |
| Level2 下探时量能**极度萎缩**,拐头拉升时中/大单(B字单)连续吃货,成交量密集放大 | **反弹无量而下跌带量**;均价线随股价同步创新低 |
| 重要均价线 / 昨日收盘价横盘筑底 | 坚决规避 |

### 量能分布分析法(比"全天总量"更有信息量)
用分时累计量占比看资金在哪个时段出手:

| 形态 | 读法 |
|---|---|
| 日高/日低出现在**累计量 10-20%** 处,之后放量但守住涨幅 | 良性:高位换手,筹码在强手里 |
| 日高出现在**累计量 <20%**,之后**放量下跌**且尾盘不收回 | 高位一次性派发 |
| 全天量能**均匀分布**,价格重心逐步抬高 | 持续吸筹/推升 |
| **开盘 15 分钟内大单一次性涌入**(如超大单在 09:45 前完成全部净流入),之后全天零增量 | 一次性建仓或一次性派发,取决于后续价格方向:守住=建仓,回落=派发 |

## 5. 有效突破 vs 假突破

| 维度 | 有效突破 | 假突破 |
|---|---|---|
| 位置 | 底部震荡已久,或前高充分换手整理后再突破 | 高位突然无量突破,或下降途中无量突破 |
| 量能 | 温和放量(1.5~2.5 倍均量),收盘站上前高 | 历史天量长上影,或无量次日回落破位 |
| 收盘质量 | 收盘近最高价,上影线短 | 长上影墓碑线,上影 > 实体 2 倍 |
| 回踩验证 | 回踩缩量,不破突破阳半分位 | 回踩破前高,或反抽无量再跌 |
| 板块共振 | 同题材有跟风助攻,或中军同步突破 | 孤立票,无板块联动 |

**操作用法:有效突破日极轻仓试错(5%~10%),回踩缩量不破半分位再确认加仓。**

## 6. 高位出货的典型盘面信号
- 高位放量滞涨(**量顶天价不涨**)
- 长上影 / 墓碑线 / 高开低走大阴
- **利好公布日不涨反跌,或冲高回落**
- 底部筹码峰完全消失,高位形成密集峰
- 偏离均线过远、巨量长上影、板块后排掉队(警戒减仓级)

## 7. 用大盘反推资金态度
| 现象 | 结论 |
|---|---|
| 大盘大跌,标的横盘不跌 | 场内 **≥51% 筹码高锁仓**,存在隐性多头维护 |
| 大盘大涨,标的不涨 | 筹码极松散,或主力正在**压盘派发** |

## 8. 底层公式
```
题材高度 = 政策/事件级别 × 板块容量 × 资金合力 × 情绪周期位置
```
K 线和技术指标只是多空资金博弈留下的"脚印",属于**结果**而非预测工具。
技术面(MA/RSI/MACD/连板数)经大样本回测证实无稳定预测力,**只能用于展示,不能单独作为结论依据**。
