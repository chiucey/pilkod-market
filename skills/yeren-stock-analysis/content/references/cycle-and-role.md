# 情绪周期 · 主线筛选 · 角色定位

## 1. ★ 情绪周期五阶段(定仓位上限,先判周期再看个股)

短线超短的本质是情绪与流动性的溢价。**先判明处于周期哪一阶段,再决定对应仓位动作。**

| 阶段 | 判定特征 | 仓位 | 动作 |
|---|---|---|---|
| **冰点期**(混沌磨底) | 连板高度被全面压制在 2~3 板以内;核按钮频现;昨日涨停今日跌停;跌停 ≥10~20 家 | 0 或 ≤5% | 大仓位防守空仓;仅在跌停骤减、连板高度止跌的转折点,用极轻仓位试错新题材破冰首板 |
| **启动期**(新周期确立) | 旧主线退潮;新题材有重磅政策催化;首日呈现批量首板潮(≥3~5 只涨停);跌停减少;老龙止跌 | 5%~10% | 轻仓出手模式内**最先封板的强先锋**或一进二换手板;不抢冷门和无板块效应标的 |
| **发酵/主升期**(黄金进攻窗口) | 空间龙打出辨识度(≥4~5 板突破高度压制);梯队完整(空间龙+中位晋级+低位补涨+百亿中军放量助攻);首分歧有承接 | 20%~40%(单票 ≤50%) | **黄金出手期**;敢于推仓位,围绕主线真龙做首次良性大分歧低吸或弱转强确认 |
| **高潮期**(盛极而衰预警) | 板块大面积涨停;后排垃圾股全面补涨;中位票缩量加速秒板;全网自媒体狂吹;场外资金因惜售买不到核心 | 减至 20%~30% | **持仓者的盛宴,持币者的禁区**;绝对不追高,严格执行去弱留强,分批减仓锁定利润,防范极致一致后的剧烈炸板负反馈 |
| **退潮期**(全面杀跌) | 高度标的集体被核按钮闷杀,A 字杀绝不反包;中位股成排跌停;亏钱效应扩散(面率 >30%) | 0 | 无条件清仓,停止一切低吸和打板尝试 |

**节奏口诀:冰点试错 → 启动确认加 → 主升做分歧 → 高潮减 → 退潮空仓。**

## 2. 四大关键交易节点

只在这些节点动手,中段持股日和一致加速日不新建重仓。

| 节点 | 判定 | 动作 |
|---|---|---|
| **冰点节点** | 退潮末端,跌停收敛、核按钮减少 | 空仓等信号,盯首板试错,**唯一低风险窗口** |
| **启动节点** | 新题材 ≥2~3 只首板,老龙止跌 | 轻仓试错模式内先锋 / 潜在龙 |
| **主升确认节点(首分歧)** | 空间龙 ≥4~5 板,首次爆量烂板 / 尾盘未断 | **黄金上车点**,次日低吸或弱转强确认 |
| **退潮节点** | 空间龙爆量断板 / 被核,中位跌停扩散 | 清仓持仓,空仓等下一冰点 |

## 3. 一致性判断(做多一致性四维度)

1. **板块效应**:同题材 ≥3~5 只涨停,有先锋 + 空间板 + 中军
2. **龙头表态**:高开 / 缩量加速 / 爆量分歧后承接强
3. **指数与情绪环境**:大盘企稳,连板高度 ≥4 板,跌停 <5 只
4. **资金流向**:中军温和放量上攻,机构 + 游资共振

**过度一致(顶部信号)**:早盘板块大范围一字涨停、龙头百万手封单缩量加速、中位秒板、后排补涨全红、自媒体狂吹。

## 4. ★ 鱼尾行情(必须主动规避)

| 特征 | 观察点 |
|---|---|
| 过度一致 | 早盘 ≥3 只一字涨停,龙头缩量加速 |
| 中位补涨全面启动 | 此前只有龙头+先锋,突然首板全是**低位冷门补涨** |
| 龙头爆量断板 / 被核 | 空间龙爆量不封板,或次日大幅低开核按钮 |
| 舆论过热 | 抖音/股吧/群刷屏"星辰大海""目标价 XX" |

**应对:持仓者分批减仓 → 断板清仓;空仓者绝不降低审美标准去买跟风伪补涨。**
接力中位股次日闷杀大面率 >60%。

## 5. ★ 主线筛选五步法

核心板块特征口诀:**有高度、有宽度、有深度、有回流**。

| 步骤 | 内容 | 门槛 |
|---|---|---|
| 1 | **看消息级别** | 必须具备国家级战略红利、重磅会议点名或重大事件催化,想象空间大(新质生产力、商业航天、低空经济等) |
| 2 | **看首日异动** | 开盘 30-60 分钟内密集爆发首板潮,同题材个股同日涨停 **>3~5 家**,板块指数同步带量突破前高,**非个股独立庄股行为** |
| 3 | **看容量中军** | 板块内必须有**百亿市值以上**的趋势大票同步高开高走或放量大阳助攻。中军强 = 机构与游资共振,主线才有持续深度;只有小票乱炒、中军走弱,必是一日游 |
| 4 | **看老龙异动** | 上一轮炒作沉淀的、在大众心中有强记忆的人气老龙,在底部率先出现堆量止跌、温和放量突破压力线或拉出首板 = 资金大规模回流主线的风向标 |
| 5 | **次日溢价验证** | 空间龙候选获得高溢价、昨日首板活口留存率高、中军无负反馈 → 主线地位确认,开始聚焦核心操作 |

## 6. ★ 五种角色定位

| 角色 | 硬指标 | 买点 | 防守 / 离场 |
|---|---|---|---|
| **空间龙(总龙头)** | ①当前周期连板最高(或并列但带动性更强)②板块助攻(小弟跟涨跟跌,非孤立庄股)③情绪标杆(资金认可度高) | 主升**首分歧低吸** / 弱转强确认 | **锚 = 分歧日最低价**;真龙 A 字杀时补涨立即清仓 |
| **中军** | 百亿+市值,机构 + 游资共振,沿趋势均线上行 | 首阳启动,或回踩 10/20 日线缩量企稳低吸 | **破 20 日线走** |
| **补涨龙** | 龙头打出高度后才低位启动;高度 ≤ 龙头 50%~70%;无独立带动性;跟真龙,真龙倒它先 A | 极小仓试错或直接放弃 | 鱼尾行情快进快出;**主升期专注真龙,不做补涨** |
| **穿越龙** | 旧周期退潮时逆势走出、扛过冰点不死 | 新周期共振日**弱转强**确认打板或低吸 | **掉队即假穿越,立即离场** |
| **题材老龙头** | 上一轮同题材炒作中市场合力选出的总龙头(一般 ≥5 板),有高度有人气有资金记忆 | ①启动试错:底部温和放量站上 5 日线 → 极小仓 ②确认加仓:首板/反包阳 + 板块 ≥2 只助攻 → 顺势加仓 | 只做右侧确认,不做下跌途中接飞刀;高位前高附近爆量不板不追 |

### 老龙头的三大作用
1. **新题材温度计**:老龙动 → 行情质量高;老龙不动 → 一日游概率大
2. **反抽 / 二波锚定**:调整到重要支撑缩量止跌,配合消息二次点火
3. **退潮期抱团载体**:无新题材时,活跃资金偶尔抱团老龙做记忆反抽

### 真龙与补涨龙核心区别速查
| 维度 | 真龙头 | 补涨龙 |
|---|---|---|
| 启动时间 | 题材最早首板中走出 | 真龙打出高度后低位启动 |
| 板块带动性 | 有(小弟跟涨跟跌) | 无/弱(真龙倒它先 A) |
| 高度预期 | 情绪上限(最高板) | ≤ 真龙 50%~70% |
| 分歧承接 | 首次分歧有承接不 A | 分歧易直接核,承接弱 |
| 退潮表现 | 横盘震荡或 A 字 | 直接 A 字杀无反抽 |

## 7. 提高交易审美的训练方法
- 每天翻涨幅榜前 50 + 涨停复盘,标记龙头 / 中军 / 跟风
- 记录买过的杂毛票及亏损原因,建立"不买清单"
- 行情差时空仓,不乱买降低标准的票
- 看懂资金介入信号(堆量、板块联动、老龙异动)第一时间试错;等加速高潮再去就是审美不够
