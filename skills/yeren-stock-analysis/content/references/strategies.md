# 经典战法 · 复盘 SOP · 交易体系底座

## 1. "520 战法"(5 日均线上穿 20 日均线)

**定义**:两条均线组合的均线交叉战法。
- **5 日均线 = 攻击线**:反映短期情绪和资金动向,信号最敏感
- **20 日均线 = 生命线**:代表中期趋势,是过去一个月持仓者的平均成本

### 核心买卖信号
| 信号 | 条件 |
|---|---|
| 买入(金叉) | 5 日均线上穿 20 日均线形成金叉 |
| 卖出(死叉) | 5 日均线下穿 20 日均线形成死叉 |

### 操作细节(判定真假金叉是关键)
1. **辨别金叉真伪**:20 日均线必须**向上或走平**;向下时出现的金叉多为假信号。**真正的买点是金叉次日收阳线且收盘价高于金叉当日**,否则应放弃。
2. **量价配合**:股价上穿 20 日线时**必须放量**,且回调时**必须缩量**。
3. **回踩加仓**:股价站上 20 日线后,若 5 日线回踩 20 日线**但不跌破**,随后再次拐头向上,是加仓信号。
4. **止损**:有效跌破 5 日线**减半仓**,有效跌破 20 日线**清仓**。
5. **止盈**:短线思维,持股不超过 **5 个交易日**,目标涨幅 2%-5% 即可止盈。

**适用边界**:这是波段/趋势型战法,用于判断"是不是该按趋势做",不适用于追涨当日情绪高潮的票。

## 2. "老太太扶楼梯战法"(倒 T 解套,向下也赚钱)

**核心逻辑**:股价不只能向上赚钱,**向下也能赚钱**。被套后利用下跌过程中的波动,每日开盘卖出、盘中低位接回,赚取差价。每天降低 1%-2% 成本,积累下来能显著减少亏损甚至盈利。

### 两种模式
| 模式 | 主体 | 目的 | 特征 |
|---|---|---|---|
| 模式一 | 主力 / 量化控盘 | 大资金连续高抛低吸,制造"阶梯式缓跌"逼迫散户交出筹码 | 日 K 阴跌或小阴小阳逐步下行;分时常见"拉高→缓跌" |
| 模式二 | 散户解套 | 持仓被套后主动降低成本 | 口诀"不要怕卖飞",有底仓,卖飞也可在更低位置接回 |

### 触发条件("5V10"战术)
连续下跌 **5 个交易日**,或跌幅超 **10%**,满足任一即可启动。
**须排除基本面有严重问题(亏损为负)的高位股。**

### 散户实战五步循环
| 阶段 | 动作 |
|---|---|
| **第 1-3 日** | 机械做 T:早盘竞价或开盘即卖出;待盘中跌至 **-3% ~ -5%** 的相对低位时接回;次日重复 |
| **第 4-5 日** | 择机格局:若某天高开或盘面转强,先观望;若冲高至成本线附近,先卖出一半锁定利润,剩余继续持有;若仍低开弱势,继续先卖后买 |

**关键细节**
- 执行果断,卖飞或买早都正常,只要长期平均下来有差价即可
- 常规方向为"先 S(卖)后 B(买)"倒 T;遇急跌机会也可"先 B 后 S"正 T
- 目的是解套而非短期暴富,积小胜为大胜
- **风险提示:属于左侧交易,在单边下跌或流动性枯竭的个股上风险极高,可能越做 T 亏得越多。**

## 3. "圆弧底 75A"

**"75A"中的 A 指均线(MA),75A 即 75 日均线**(或 75 周均线),介于 60 日(季线)与 90 日之间的重要中期趋势线,站上则强、跌破则弱。

**核心定义**:经典圆弧底 + 75 日均线确认。
- **圆弧底**:K 线图中宛如锅底状的盘整形态,通常出现在价格底部区域,形成过程漫长(数月甚至更久),是主力资金长期建仓的结果,可靠性极高
- **75 日均线**:形态构筑过程中逐步走平并向上拐头;股价完成右半边并**有效站上 75 日均线**,意味着中期趋势正式由空转多

### 形态识别要点
- **形态**:左半部缓跌 → 底部长时间横盘 → 右半部缓慢爬升;多为小阴小阳,振幅较小
- **成交量**:左半部逐渐萎缩 → 底部极度缩量 → 右半部温和放大,呈圆弧状
- **时间**:形成时间越长越可靠,通常建议超过 **3 个月**
- **75 日线**:构筑中逐步走平并向上拐头;右半部股价需放量站上

### 实战四步
| 步骤 | 动作 |
|---|---|
| 1. 识别形态(左侧潜伏) | 找到长期下跌后出现"锅底"的个股;确认左半缩量、底部地量、右半温和放量 |
| 2. 等待突破(右侧确认) | **股价放量突破圆弧底颈线位(右半部高点) + 有效站上 75 日均线**;必须放量(倍量更佳),缩量突破多为假信号 |
| 3. 择机介入 | 激进:右半小幅爬升、温和放量时轻仓;稳健:放量突破颈线+站上 75 日线买入;回踩:突破后缩量回踩颈线或 75 日线不破,两日不破则介入 |
| 4. 目标与防守 | 目标 = 理论最小涨幅"颈线位价格 - 圆弧底最低价格",**保守估计 30%-50%**;止损:跌破圆弧底最低价,或有效跌破 75 日均线 |

**关键细节**:短期均线系统最好呈多头排列;圆弧底在上升趋势初期成功率更高;**没有绝对最低点,分批买入,不要一次性满仓**。

## 4. ★ 每日职业化复盘 SOP(收盘后 30-60 分钟)

1. **涨跌停复盘**:将当日两市涨停板逐一按题材归类,梳理出身位梯队与连板高度,标记出**最早封板的先锋**;统计跌停家数与"昨日涨停今日大面"的核按钮数量 → **精准为当日情绪周期定位**(冰点/启动/主升/高潮/退潮)
2. **持仓校验**:逐一检查持仓 —— 个股锚定点(5 日线 / 分歧日最低价 / 突破阳半分位)在盘中守住了吗?走势是否符合盘前预期?将走弱的伪强势股列入**次日竞价优先处理清仓名单**
3. **异动扫描**:翻看自选股池,观察核心主线的优质中军或人气老龙在底部是否有温和的右侧堆量、逆势抗跌迹象,挑选出明日盘中重点盯盘的目标
4. **填写交易日志**:详细记录今日每一笔交易 —— 是否在模式内?盈亏的根本原因(靠系统赚的还是靠运气蒙的)?是否存在破锚不死心扛单、踏空乱买的违章操作?对违章交易**红灯标注**,按月统计错误台账,逼迫模式外交易占比趋近 0
5. **周期定性**:综合连板高度、梯队、跌停数 → 定阶段,预告明日对应动作

**周/月复盘**:统计模式内胜率、盈亏比、最大连亏、模式外亏损占比 → 模式外趋近 0 且胜率 + 盈亏比可接受则系统 OK 微调参数,否则冻结审视。

## 5. 坚持模式的实操纪律
- 模式外再"确定"也不做 —— 听消息票、群喊单、看别人晒翻倍单跟风 = 模式外,短期可能蒙对,长期必负
- 只坚持一种模式足够长时间,才能统计胜率、盈亏比、最大连亏、适合的情绪阶段;不断换模式永远无法改进
- **写下模式说明书**(选股 + 买点 + 仓位 + 止损 + 止盈 + 适用周期);盘前读一遍,非模式内机会盘中涨再猛 → 划掉不买
- 模式连续 10~20 笔负期望 → 冻结检视,不随意放弃前先确认样本量足够
- 看别人赚快钱不眼红:问"那是我的模式内吗?" → 否 → 恭喜他,不跟

## 6. 成熟交易者 vs 散户思维的根本区别

| 维度 | 散户 | 成熟交易者 |
|---|---|---|
| 对待亏损 | 死扛、补仓、"不卖就不亏" | 预设止损,破锚无条件走,亏损是系统成本 |
| 交易依据 | 消息 / 群喊单 / 感觉 | 只做写好的模式内交易 |
| 节奏感知 | 不管牛熊退潮猛干、主升恐高踏空 | 先判情绪周期,再定仓位与动作 |
| 面对错误 | 找借口"庄家洗盘"扛着等回本 | 立即纠错减清仓,盘后复盘记人台账 |
| 空仓能力 | 看不懂也满仓找机会 | 无模式、无主线、退潮期主动空仓 |
| 人性控制 | 贪婪追高、恐惧割肉、从众跟风 | 按锚定点 + 预期管理机械执行,反人性操作 |

## 7. 悟道的实质标志
- 不再追求每笔必赢,将模式内的止损视为营业成本
- 坚决执行交易系统,模式外的机会涨上天也不做
- 具备强大空仓自控力,不因怕踏空而随手交易
- 情绪与账户彻底脱钩,大赚不膨胀、大亏不报复交易
- **长期视角:交易赚认知钱和纪律钱,不是消息钱**

## 9. 底层逻辑再提炼(五句)
1. 短线炒的是**情绪 + 资金合力 + 板块容量**,选对周期比选对票重要
2. K 线是资金博弈痕迹,问"谁在买谁在卖",不盲信形态
3. **情绪周期是所有题材的母体** —— 冰点试错 → 启动确认 → 主升做分歧 → 高潮减 → 退潮空仓
4. **控制回撤 × 只做模式内 = 稳定盈利基础**,技术第二位
5. 你交易的不是 K 线,是你对贪婪 / 恐惧 / 从众的管理能力

**野人哥告诫**:"你今天省下的每一笔模式外交易、每一次空仓等待、每一次 -5% 机械止损 —— 都在为三年后那个稳定盈利的账户铺路。盯 K 线眼前跳动的是赌徒,盯系统执行的是交易员。"
