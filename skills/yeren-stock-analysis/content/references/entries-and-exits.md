# 买点 · 卖点 · 仓位 · 盈亏比 · 预期管理

## 1. ★ 五大买点体系

### (1) 波段有效买点
**前置条件(缺一不可)**
- 周线、月线处于历史底部区域
- 基本面无雷,排除下降通道
- **20 日均线走平并明确拐头向上**(均线向下时,任何超卖信号、支撑位均无效)
- 5 日均线上穿 10 日均线,或即将金叉

**买点顺序**
- **第一买点**:底部首根放量突破大阳线确认日;或在**震仓洗盘末端**(日内冲高急跌、尾盘带量拉起阶段)逢低价介入
- **第二买点**:错过第一买点后,耐心等待股价回踩 10 日线或 20 日线,出现**缩量止跌的阳线或十字星**时作为二次安全上车点
- 辅助信号:60 分钟 K 线"红肥绿瘦"(红柱多且长、绿柱少且短),代表主力运作

**修正买点滞后**:不要等所有技术指标确认(等均线多头排列完全形成 = 买在主升中段或高位乖离过大处)。
通过读懂主力操盘阶段,在 20 日线**即将拐头或刚转为向上**的初期介入。

### (2) 主升首分歧低吸(最优黄金买点)
**条件**
- 主线空间龙打出高度(≥4~5 板),板块梯队完整
- 首次爆量分歧(烂板 / 尾盘漏单但**未断板**)
- 次日不核按钮,低开有承接或平开带量上攻(弱转强)

**买点**
- 分歧日尾盘确认承接 → 尾盘低吸
- 次日弱转强带量上攻翻红 → 半路或打回封

**防守位 = 分歧日最低价,破位走人。**

### (3) 弱转强确认买点
- 标准:昨日烂板 / 分歧,次日竞价高开 **2%~5%**;集合竞价 **9:20-9:25 表现出主力坚决的吃单意图**;开盘后快速上攻、带量
- 操作:持股不动,或盘口打回封加仓
- 判据:**"该强不强则为弱,该弱不弱则为强"**。昨日强板今日平开 / 低开无承接 → 竞价或开盘速走,不幻想

### (4) 多空博弈转折点(B 点)识别与试错
**定义** = 空头力量耗尽、多头开始主动承接并反击的临界区域(多空比值从 70:30 转为 51:49)

**识别条件**
1. 前期从近期高点回撤 **15%~30%** 以上,成交量极致萎缩(地量)
2. B 点当日:早盘急杀至支撑有大单承接,不破锚或微破瞬时收回,收盘拉回均价线
3. K 线:缩量止跌小阳 / 十字星 → 次日放量反包阳;或当日收长下影阳线

**操作**:极小仓(5%~10%)试错,**防守位 = B 点当日最低价 -0.5%**,破位走

### (5) 涨停缩量回踩战法(修正方法)
**正确逻辑**:涨停(多头表态)→ 缩量回踩不破涨停阳线关键位 → 抛压轻、筹码锁定 → 再次放量可期待二波

**标准流程**
1. 筛选:主线 / 潜在主线内、**有地位**的票(先锋/龙/核心老龙),早盘牢固封板
2. 观察回踩:次日~3 日内缩量回踩,**不破涨停阳半分位**(强票不破开盘价)
3. 等待止跌 K 线:缩量小阳 / 十字星止跌,不急于当天买
4. 试错买:止跌后再次放量上穿 5 日线或突破小平台 → 轻仓(5%~10%)试错
5. **防守 = 止跌 K 线最低 -5%**,破支撑走人,禁止补仓

**五大常见错误**:①退潮期不用此法(假支撑后补跌)②破半分位立即走不扛单 ③不用尾盘偷袭板/烂板做样本 ④缩量是必要条件,还需止跌 K 线确认 ⑤只做主线核心票,跟风票放弃

## 2. ★ 无条件止损铁律

- 亏损 50% 需要涨 100% 才能回本,本金亏光将彻底丧失翻盘资格
- **单笔最大亏损阈值 -5% ~ -7%**,触发或开仓买入逻辑消失必须无条件砍仓
- **破锚立即走**(锚 = 分歧日最低 / 大阳半分位 / 5 日线)
- **严禁死扛、严禁补仓摊成本**
- 炸板秒割不眨眼,认错走人重新来

## 3. ★ 移动保本止盈与减仓信号

**移动保本**:盈利后把止损上移到成本价上方,永不让盈利变亏损。

| 级别 | 信号 | 动作 |
|---|---|---|
| **警戒减仓** | 加速上涨偏离均线过远、巨量长上影、板块后排掉队 | 减半仓,或去弱留强 |
| **明确减仓/止盈** | 有效跌破 10 日线反抽无力、爆量不涨、空间龙被核 | 清掉剩余仓位 |
| **彻底清仓** | 有效破 20 日线趋势线、跌破启动阳线 1/2 | 波段结束,全清 |

**高位出货典型信号**:高位放量滞涨(量顶天价不涨)/ 长上影墓碑线 / 高开低走大阴 / 利好公布日不涨反跌或冲高回落 / 底部筹码峰完全消失高位形成密集峰。

## 4. ★ 仓位管理金字塔

**核心原则:仓位跟着确定性走,确定性高推仓,不确定性空仓或极小仓。**

| 层级 | 场景 | 比例 |
|---|---|---|
| 试错仓 | 新周期启动首日 / 新题材首板 | 5%~10% |
| 确认仓 | 主线发酵 → 龙头首分歧低吸 / 弱转强确认 | 递进至 20%~30% |
| 主仓 | 高确定性主升期核心票二次加仓 | ≤50%(留回旋空间) |
| 空仓 / 迷你仓 | 退潮期、看不懂、无模式内机会 | 0 或 ≤5% |

**禁止动作**:满仓梭哈单只 / 被套后补仓摊成本(先满仓套牢→跌了补仓=大亏根源)/ 浮盈盲目加仓

**去弱留强**:同一时间持仓严格控制在 **2~3 只**以内,资金集中在最强核心上;盘中走弱、不符合预期的跟风杂毛优先卖出。

**动态降仓信号**:连亏 2~3 笔 → 降至试错仓或强制空仓 3~5 天;阶段回撤 **-10%~-15%** → 停止开新仓直至找回节奏;情绪退潮 → 全线降仓或空仓。

## 5. ★ 盈亏比(≥3:1)开仓前置条件

```
潜在盈利空间 ÷ 潜在止损亏损 ≥ 3:1 才值得做(最少 2:1)
```
- 选**支撑位明确**(止损空间小)+ **上方有空间**(压力远)的票
- 胜率 50% 但盈亏比 3:1,长期必盈利;胜率高但盈亏比 1:1,长期必亏
- **盈亏比不达标 → 结论直接给"观望/不买",不给模糊建议**

## 6. ★ 预期管理(盘前推演 → 盘中对照)

**短线的预期**不是主观希望它怎么涨,而是盘前根据前一日盘面、消息面、板块连板梯队及当前情绪周期,对次日开盘及走势做出的合理推演区间。

| 分类 | 昨日表现 → 今日竞价 | 操作 |
|---|---|---|
| **超预期** | 昨日烂板或强分歧,今日竞价竟**高开 3% 以上**且带量快速上攻(= 弱转强确认) | 持股不动,或盘口打回封加仓 |
| **符合预期** | 昨日强板今日 1%~3% 正常溢价高开;或昨日分歧今日平开震荡换手 | 根据锚定点看**分时流畅度**,决定持股或分批止盈 |
| **不及预期** | 昨日极端强板今日平开甚至低开闷杀;板块集体大涨它独弱;竞价量能严重萎缩无人接力 | **竞价或开盘速走**,不抱幻想,**绝不补仓** |

## 7. ★ 鱼尾行情的应对
见 `cycle-and-role.md` 第 4 节。要点:持仓者分批减 → 断板清仓;**空仓者绝不接缩量加速中位**。

## 8. ★ 与量化轮动市"做朋友"

**量化特征**:程序化高频、做 T+ 套利、秒撤单封单、追涨杀跌放大波动、日内网格套利。

| 策略 | 做法 |
|---|---|
| **买分歧** | 量化砸盘恐慌时回踩支撑(锚定点)低吸 |
| **卖一致** | 量化程序抢筹、缩量加速时逢高分批减仓 |
| 避开收割区 | 不追早盘无换升高开秒板 / 直线脉冲(几秒内拉升 5%+);不参与日内板块急速轮动末端;退潮期不做高换手热门首板 |
| 顺向隔日套利 | 做模式内核心龙/先锋,今日牢固封板 + 板块梯队 → 次日量化竞价有溢价愿意接 |

**心法**:"量化消灭无规则随手单和追涨杀跌,但消灭不了正期望的系统交易。你按情绪周期 + 锚定点 + 模式内做,量化反而是提供流动性的工具。"

## 9. ★ 开盘前三问(防腰斩,任一为否 → 空仓观望)

1. 这笔交易完完全全在我的交易模式之内吗?(拒绝分时好看、听消息、群喊单的模式外随手单)
2. 当前的情绪周期环境以及板块梯队允许我做这个动作吗?(主升做分歧,高潮渐减仓,退潮死管手)
3. 如果这笔交易做错了,防守锚定点是否清晰?能否在盘中无条件机械化执行止损并完全接受这笔亏损?

**防腰斩五问**:①当前情绪周期允许重仓吗 ②这是模式内交易吗?有清晰买点/止损/锚定点吗 ③是鱼尾行情吗 ④仓位符合试错→确认递进吗?是否满仓梭哈 ⑤若错了我能止损且接受吗

## 10. 四类错误的即时纠错

| 类型 | 场景 | 纠错动作 |
|---|---|---|
| **买错** | 盘中情绪上头或听群推荐误入模式外杂毛 | 一旦发现,次日竞价或开盘**无论输赢直接清仓**;输得起手续费,输不起变深套 |
| **卖错** | 因恐高过早卖飞核心总龙头 | 若总龙头再次触发模式内买点(首次爆量分歧稳住 / 二波放量突破),允许**极小仓位**追回,绝不频繁开陌生杂毛发泄情绪;若破锚不舍得走,属最严重违纪,分时反抽不过均价线必须全清 |
| **节奏错** | 退潮杀跌期还在打接力板 | 当天立刻停止一切新开仓动作,承认节奏错误,清理走弱持仓,收回流动性 |
| **系统错** | 某子模式(如高潮期打板)统计胜率 <30% 且盈亏比极差 | 立刻**冻结该子模式**,微调参数,写入交易手册 |

**心法**:"你可以买错、卖错、踏空,这都正常;唯一不能原谅的是明知错了还扛、还补仓、还骗自己会回来的。"

## 11. 人性四大死穴(盘中识别)

| 死穴 | 盘面镜像 | 克服 |
|---|---|---|
| **贪婪** | 看到翻倍晒单或妖股连板按捺不住,怕踏空而在高潮末端追缩量加速板(接鱼尾),高位站岗 | 用交易系统代替盘中情绪决策 |
| **恐惧** | 上升途中正常震仓时吓破胆割肉在地板;真正的顺趋势低吸点出现时又不敢出手 | 买卖点/止损位提前写好,触发即执行 |
| **侥幸** | 破位后"再等等说不定会反弹""不卖就不亏" | 破锚即走,不幻想 |
| **锚定** | 死盯买入成本价,高喊"回本再卖",错过最佳止损时机 | 看锚定点(分歧日低/半分位/5日线),破位走 |

## 12. ★ 事件风险快检(技术面看不到的"定时炸弹")

技术面和资金面再漂亮,也看不出**几天后会不会突然来一刀**。每次分析都要顺手查一次,
查不到就如实写"未查证",不要编造。

`python3 scripts/fetch.py <code> --events` 会一次拉齐下列全部项(恒生接口,详见 `data-sources.md`)。

| 检查项 | 恒生 api_id | 查什么 | 怎么处理 |
|---|---|---|---|
| **定期报告披露日** | `FinanceReportDisclosure` | 三季报 / 年报的**预约披露时间** | 披露前 5 个交易日内一律降档;连续亏损的公司在披露日前是高危窗口,即使形态好也要收敛仓位 |
| **限售股解禁** | `RestrictedStockLifting` | 解禁日 + 解禁股数占总股本比例 | 解禁前后抛压骤增;大比例解禁 = 直接减仓信号 |
| **股东减持 / 询价转让** | `ShareholdingChangePlan` + `KeyHolderTrande` | 减持计划进度、股东实际成交均价 | 现价远高于减持价 = 卖方成本极低,后续减持预期持续;询价转让受让方通常有锁定期,到期是潜在抛压 |
| **股东户数变化** | `ShareholderNum` | 户数增减 + 户均持股 + 前十大持股比例 | 户数**大增** = 散户接盘(派发嫌疑加重);户数**骤降** = 筹码集中(需结合股价位置判断是主力吸筹还是散户割肉) |
| **估值与盈利** | `StockValueAnalysis` + `PerformanceForecast` | PE(TTM)、PB、营收/净利同比、预告类型(首亏/预增) | PE 上百倍 + 亏损 + "首亏" = 纯题材票,只能按情绪周期对待,不能按价值持有;主业收入下滑 + 连续亏损 = 反弹只当反抽 |
| **龙虎榜席位** | `DailyStockHeroDetails` | 上榜原因、买入额、卖出额、净买额 | 席位净卖 = 当日主导方在跑;跌停日的"日跌幅偏离值达7%"是强证据 |
| **融资盘** | `StockSecuritiesMargin` | 融资余额 + 融资净买入 | 融资余额逆势增加 = 杠杆资金在追高,是危险信号而非看多信号 |

**查到什么就在第 10 段(风险与失效条件)里如实列出**,并把"披露日 / 解禁日"这类**具体日期**
写进关键价位表旁边的提醒里 —— 用户需要知道的是"哪一天",不是"有风险"。
