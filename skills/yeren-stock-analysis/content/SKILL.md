# 野人哥交易体系 · A股个股分析

给个股做**交易判断**的一套流程。核心目的:在数据噪声里分清"主力在洗盘"和"主力在派发",并给出可机械执行的动作。

## Inputs to collect

缺省就直接用合理默认往下走,不要为了凑齐信息反复追问用户:

| 输入 | 默认行为 |
|---|---|
| 股票代码或名称 | 用户给了就用;只给名称用代码搜索接口反查(腾讯 smartbox),**必须确认代码再取数** |
| 时间点 | 用户说"今日"就用最新可得数据;盘中取实时并标注时点,收盘后取日线收盘 |
| 是否持仓 | 未说明时按"未持仓"给结论,并额外给"若已持仓"的处置 |
| 分析侧重 | "出货还是洗盘" → 重点跑震仓六标准;默认全流程 |

需要区分的是 **A 股代码**:深市 `000/001/002/003/300/301`、沪市 `600/601/603/605/688`、北交所 `8xx/920`。
"002853 是皮阿诺,不是奥佳华"这类混淆曾发生过,取数前先核对名称。

## Procedure

### 1. 取数(用 `scripts/fetch.py`,不要手写请求)

```bash
python3 scripts/fetch.py <code> --days 14          # 实时 + 日线 + 资金流 + 分时轨迹
python3 scripts/fetch.py <code> --days 14 --events  # 追加事件风险快检(财报/解禁/减持/户数/龙虎榜/两融/估值)
python3 scripts/fetch.py <code> --days 14 --json   # 同上,机器可读
```

**数据源优先级(用户明确要求):恒生金融数据库(MiniMax Finance) → 东方财富 → 腾讯 → 新浪。**
按模块独立降级,输出里逐项标注实际来源。完整接口映射见 `references/data-sources.md`。

恒生是首选,因为它**字段中文名直接写在列头、自带守恒结构**,不用猜口径:

```
主力净额(大单净额DDE) = 特大单净买入额 + 大单净买入额
守恒:主力DDE + 中单 + 小单 == 0
```

**降级到东财时,资金流字段口径必须先校验再引用**:`f52`=主力净额 / `f53`**小单** / `f54`**中单** / `f55`大单 / `f56`超大单,
校验式 `f53+f54+f55+f56 ≈ 0` 且 `f55+f56 == f52`。
把 f53/f54 误读成超大单/大单会让结论**完全反向**——曾据此把"主力吸筹"误判成"机构出货",这个坑不能再踩。

其他已处理的坑(自己写请求容易踩):

- **恒生分时只返回最近 30 分钟**,`pageNo>1` 为空 → 全天分时轨迹用腾讯 `minute/query` 补。
- **恒生返回最新在前(倒序)**,取末尾会拿到最旧数据 → `hengsheng.py` 已统一按日期升序输出,下游取 `[-N:]`。
- **东财接口会 403 限流**,脚本自动轮换 6 个子域名并降级新浪口径(`r0_net`=特大单净额,`netamount`=全口径净额)。
  **口径不同不可直接跨源比数值**,只可比方向与相对变化。
- **新浪日 K 成交量单位是股**,腾讯是手,换算时统一成"万手"。
- **时区**:判断是否交易时段用北京时间(UTC+8)。`agent-context.date` 可能给的是 UTC,
  形如 `2026-10-22 09:58:44 (UTC)` → 北京时间 17:58。周一~周五,9:15-11:31 / 13:00-15:02 为盘中。

### 2. 定位主力阶段(先定位,再谈买卖)

用四阶段模型:**建仓(吸筹) → 洗盘/震仓 → 主升拉升 → 出货(派发)**。
阶段决定了后面所有动作的基调,详见 `references/judgement-core.md`。

同样的 K 线组合在不同阶段意义完全相反(高位缩量上涨是见顶,低位缩量上涨是锁筹),
所以"先看位置和阶段,再看形态"。

### 3. 跑震仓 vs 出货六标准打分表(回答"出货还是洗盘"的核心)

逐条对照,**每条都要落到具体数据**(不是定性描述),最后统计命中数:

| # | 维度 | 洗盘 | 出货 |
|---|---|---|---|
| 1 | 位置 | 主升途中/破前高前 | 高位爆量滞涨区 |
| 2 | 分时 | 急杀 -3%~-6% 有承接迅速拉回,均价线不跟新低 | 下跌带持续大单砸,均价随新低,反抽无力 |
| 3 | K线 | 长下影/十字星,烂板不破关键位 | 墓碑线 + 破均线无量反抽 |
| 4 | 量能 | 略放量或平量,次日快速缩量反包 | 高位持续放量不涨或下跌带量 |
| 5 | 板块 | 有助攻、中军稳住 | 板块集体退潮、龙头孤立补跌 |
| 6 | 锚点 | 不破锚(5日线/大阳半分位/分歧日最低) | 破锚无承接 |

**判定:命中出货 ≥3 条 → 判派发;命中洗盘 ≥4 条且破锚 → 破位走人。**
两条都沾(典型:放量长上影 + 主力净流出但换手仍可控)→ 定性为"分歧临界",给条件式结论。

### 4. 量价六原则落位 + 分时承接力

量价组合**高位低位意义完全相反**,必须先说位置再下结论(表见 `references/judgement-core.md`)。

分时承接力是真承接还是假承接,决定当天是"低吸机会"还是"诱多出货":
看日高/日低出现时点 + 对应的累计量占比 + 均价线是否跟随创新低。典型陷阱是
**开盘 15 分钟内大单一次性涌入、随后全天再无增量**——那是高位一次性派发而非持续建仓。

### 5. 板块背景与个股地位

用主线五步法(消息级别 → 首日 ≥3-5 只首板潮 → 百亿中军助攻 → 人气老龙异动 → 次日溢价验证)
判断题材**有没有背景**;再用角色定位(空间龙 / 中军 / 补涨龙 / 穿越龙 / 题材老龙 / 跟风)
判断该股**是什么地位**。地位决定用什么买点、防守位设在哪。详见 `references/cycle-and-role.md`。

### 6. 情绪周期定位 → 定仓位上限

按五阶段判定当前周期(冰点/启动/主升/高潮/退潮),给出该周期允许的仓位上限。
**周期不对,个股再好也降档**:退潮期个股再好也只是"持仓不动/卖出",不给"强烈推荐"。

### 7. 算盈亏比,不达标直接给"观望/不买"

```
盈亏比 = (上方压力位空间) ÷ (止损位到买入价空间)
```
**<3:1 不值得开仓(最少 2:1)。** 压力位远、止损位近的票才有交易价值。
止损空间也要合理:止损设在有意义的结构位(锚点/支撑),不是随手一个百分比。
盈亏比不达标、或个股不在模式内 → 结论直接写"观望/不买",不用给模糊建议。

### 9. 事件风险快检(每次都要顺手查,查不到就写"未查证")

技术面和资金面看不出"明天会不会突然来一刀"。这类**定时炸弹**必须单独查一次,查不到就如实写"未查证",不要编。
`fetch.py --events` 会一次拉齐,对应恒生 api_id 见 `references/data-sources.md`:

| 检查项 | 恒生 api_id | 为什么要查 |
|---|---|---|
| **定期报告披露日** | `FinanceReportDisclosure` | 披露前 5 个交易日内一律降档;连续亏损的公司在披露日前是高危窗口 |
| **限售股解禁** | `RestrictedStockLifting` | 解禁前后抛压骤增 |
| **股东减持 / 询价转让** | `ShareholdingChangePlan` + `KeyHolderTrande` | 现价远高于减持价 = 卖方成本极低,后续减持预期持续 |
| **股东户数变化** | `ShareholderNum` | 户数大增 = 散户接盘;户数骤降 = 筹码集中(两者含义相反,都要写明) |
| **估值与盈利** | `StockValueAnalysis` + `PerformanceForecast` | PE 上百倍 + 亏损 = 纯题材票,只能按情绪周期对待,不能按价值持有 |
| **龙虎榜席位** | `DailyStockHeroDetails` | 席位净买还是净卖,比资金流更能说明当日谁在主导 |
| **融资盘** | `StockSecuritiesMargin` | 融资余额逆势增加 = 杠杆资金在追高,是危险信号 |

**查到什么就在第 10 段如实列出,并把"披露日 / 解禁日"这类具体日期写进关键价位表旁边的提醒里** —— 用户要的是"哪一天",不是"有风险"。

### 10. 开盘前三问自检(任一为否 → 空仓)

1. 这笔交易完全在我的交易模式之内吗?
2. 当前情绪周期和板块梯队允许我做这个动作吗?
3. 如果做错了,防守锚定点清晰吗?能无条件机械止损吗?

### 11. 预期管理对照

盘前推演 vs 今日实际:
- **超预期**(昨日烂板/分歧,今日竞价高开 3%+ 且带量快速上攻)→ 持股不动或打回封加仓
- **符合预期**(1-3% 高开或平开震荡换手)→ 看分时流畅度,持股或分批止盈
- **不及预期**(平开低开闷杀 / 板块涨它独弱 / 竞价量能萎缩)→ 速走,绝不补仓

## Output contract

固定 **十段式**,全部用 Markdown 表格(用户硬约束:数字、字段、对比一律表格,不用 bullet 罗列):

| 段 | 标题 | 必备内容 |
|---|---|---|
| 1 | 数据快照表 | 现价/涨跌、开高低、量/换手/量比、外内盘、主力+超大单+大单+中单+小单、5日/10日累计、偏离 MA5/MA10、距 10 日高点 |
| 2 | 近10日日线+资金流合并表 | 逐日:收盘/涨跌幅/最高/最低/量/换手/主力/超大单/大单/中单/小单;用 🔴 标注涨停日、巨量日、破位日 |
| 3 | 主力四阶段定位 | 建仓/洗盘/主升/出货 + 依据 |
| 4 | **震仓vs出货六标准打分表** | 六行逐条:实测数据 + 指向(🟢洗盘 / 🔴出货) + **末尾命中数统计** |
| 5 | 量价六原则 + 分时承接力 | 六原则落位表 + 真/假承接判定(给日高日低时点与累计量占比) |
| 6 | 板块主线五步法 + 角色定位 | 五步走查 + 该股角色 + 对应买点与防守位 |
| 7 | 情绪周期定位 + 仓位建议 | 当前周期 + 该周期仓位上限 |
| 8 | **状态四档结论** | 强烈推荐 / 持仓不动 / 观望 / 卖出 + 一句话依据 |
| 9 | 关键价位表 | 支撑 / 压力 / 生死线 / 锚定防守位 / 止损位(带百分比) |
| 10 | ⚠️ 风险与失效条件 | 什么情况下结论作废 + **事件风险快检结果**(定期报告/解禁/减持/股东户数/估值) |

格式细则:

- 数字列右对齐;正负号清晰;百分比带 %;金额带 亿/万
- 关键阈值用 emoji:🟢 利好信号、🔴 风险信号、⚠️ 过阈值标注
- 每张表前用一行小标题说明数据时间与来源(如"数据时间 2026-10-22 11:30 盘中,来源:腾讯+新浪")
- 末尾一句话总结,**控制在 15 字内,单独一行,不进表格**

### 状态四档的判定标准

| 状态 | 条件 |
|---|---|
| **强烈推荐** | 今日未涨停(可买入)+ 今日涨跌幅 > -3% + 洗盘判定成立 + 盈亏比 ≥3:1 + 周期允许 + 事件风险无雷 |
| **持仓不动** | 今日已涨停(不给新买点,涨停买不进);或形态未破但上方压力位未到;或盈亏比达标但方向未确认 |
| **观望** | 洗盘与出货信号**确实混杂**(两边命中数接近)、盈亏比不足 3:1、处于压力位、或周期不支持 |
| **卖出** | 出货判定命中 ≥3 条 / 跌破锚点 / 跌破 10 日线反抽无力 / 板块退潮中孤立补跌 / 单笔亏损已达 -5%~-7% |

### 结论硬度规则(避免模棱两可)
- **出货命中 ≥3 条 → 状态不得给"观望",必须给"卖出"。** 证据已指向派发时,"观望"是回避责任。
- **盈亏比 <3:1 且无持仓 → 结论写"观望/不买",不要写"可以小仓位试试"。**
- 已持仓但结论是"卖出" → **必须同时给机械动作**(反弹到哪个价位减多少、跌破哪个价位全清、剩余仓位止损百分比),并写明"禁止补仓摊成本"。
- 每个结论附**一句话依据 + 量化锚**(命中数 / 盈亏比 / 关键价位),不要只给形容词。

**不打板**(用户既定风格):涨停票一律用"涨停缩量回踩""主升首分歧低吸""弱转强确认"逻辑,
不给追涨停板的建议。

## Failure handling

| 情况 | 处置 |
|---|---|
| **恒生(mcode-tools)调用失败** | 脚本自动降级东财→腾讯→新浪,并在输出里标注实际源;若全失败,明确告诉用户"数据获取失败,无法给结论",**不要凭记忆编数据** |
| 资金流字段口径没验证 | 恒生自带守恒校验;降级到东财时必须自己验 `f53+f54+f55+f56≈0` 且 `f55+f56==f52`,验不过就只用量价+分时,不下资金流结论 |
| 恒生返回倒序 | `hengsheng.py` 已统一升序输出;若自己调原始接口,取**前 N 条**才是最近的 |
| 恒生分时只有 30 分钟 | 全天轨迹用腾讯 `minute/query`;别拿 30 分钟当全天分析 |
| 集合竞价前无成交 | 实时价取 `prevClosePrice` 并标注"未开盘";估值/市值/涨跌停价仍有效 |
| 盘中数据 | 必须标注时点,并说明"非收盘数据";不给基于盘中数据的"最终"结论 |
| 用户只要简短回答 | 仍给十段式,但可把参考细节折叠为表格行内备注,不省略核心四段(数据快照/六标准打分/状态结论/关键价位) |
| 算不出盈亏比 | 说明缺哪个价位(上方压力或结构止损),给条件式结论而非含糊表述 |
| 结论可能与用户持仓冲突 | 先给结论,再给"若已持仓"的处置动作,不因为用户已持有就软化判断 |

## Examples

**Example 1 — "江龙船艇这票是出货还是洗盘?"**

```
1. 数据快照表(现价/涨幅/换手/量比/外内盘/五档资金流/累计/偏离MA/距高点,标注 11:30 盘中)
2. 近10日日线+资金流合并表(标出 10/13 涨停、10/20 巨量)
3. 主力阶段:10/13 涨停+净流入 1.26亿 → 10/20 巨量净流出 7941万 → 10/21 反包收阳
4. 六标准打分:
   位置 🟢(未到高位滞涨区) | 分时 🔴(10:09 冲高后放量回落) | K线 🟢 |
   量能 🔴(换手24%天量) | 板块 🟢 | 锚点 🟢 → 出货2 / 洗盘4 → 判定:高位换手,洗盘为主但已进入压力区
5. 量价六原则 + 分时承接力(日高16.01只用16%量,84%量在15.4-15.7换手后收+8%,属放量守住涨幅)
6. 板块五步法 + 角色(游资小票,非中军)
7. 情绪周期(权重军工跌+小票涨 → 非板块行情,是个股行情)
8. 状态:观望(已过 14.94 但换手过热,盈亏比不足)
9. 关键价位:支撑 15.43-15.50 / 14.94,压力 16.14,止损 14.94(-5.7%)
10. 风险:跌破 14.94 = 假突破,回落 14.36
```

**Example 2 — "深桑达A 还能拿吗?"(已持仓)**

不给"再看看"。先落结论:跌破 12.35 洗盘失败线 → 状态"卖出";
再给动作(反弹到哪个价位减多少 / 跌破哪个价位全清 / 剩余仓位止损百分比,不给补仓摊成本);
再给六标准打分表证明依据;最后补事件风险快检。

**实际验证(2026-10-22 收盘,恒生数据)**:当日 -10.00% 跌停收 11.88,
主力DDE 净流出 **-20,795 万**(特大单 -16,015 / 大单 -4,780),中单 +9,054、小单 +11,742 接盘;
10/21 那笔 +14,898 万特大单全额被埋;龙虎榜"日跌幅偏离值达7%"净卖出 4,994 万;
三季报预约 **10/27** 披露,2026 中报首亏净利 -2.43 亿~-1.93 亿(同比 -149%~-98%)。
→ 事件风险 + 资金结构 + 龙虎榜三方同向,**直接落"卖出",不做"再看看"**。
