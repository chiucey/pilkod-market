## 作品简介

本作品是一款专为上海交通大学学生设计的智能论文排版技能。核心定位是"**粘贴+点击，论文自动排版**"——用户只需将论文草稿粘贴给 AI，AI 即可自动识别文章结构，按照《上海交通大学学位论文撰写要求》进行格式化输出。

### 核心价值

- **零学习成本**：无需学习 Word/LaTeX 排版操作，全程对话式交互
- **智能识别**：自动识别章、节、子节、图表、公式、参考文献
- **标准规范**：严格遵循 SJTU 学位论文撰写要求
- **双格式支持**：同时支持 Word 样式指导 和 LaTeX 代码输出
- **迭代修正**：用户可随时提出修改要求，AI 实时响应

### 目标用户

正在撰写学位论文的上海交通大学本科生、硕士研究生、博士研究生，尤其是：
- 不了解论文格式规范的低年级本科生
- 希望节省排版时间的高年级学生
- 需要使用 LaTeX 但经验不足的研究生
