# 学员报考专业查询

根据专业名称精确查询对应的职业(工种)信息，用以判断学员是否符合技能等级证书报考条件（仅限上海地区）。

## 输入要求

- **专业名称**：用户输入的专业名称（如：日语、会计、计算机、英语等）
- **可选筛选**：按职业类别筛选（A类、B类、C类）

## 输出格式

返回该专业对应的所有职业(工种)列表，包含：
- 职业名称
- 职业编码
- 院校类别
- 所属类别（A/B/C类）

## 工作流程

1. 读取Excel数据文件（包含A类、B类、C类三个Sheet，共2818条记录）
2. 根据用户输入的专业名称进行**精确匹配**（专业名称完全相等）
3. 按职业类别筛选（如用户指定）
4. 将结果按专业名称分组，展示对应的职业工种列表
5. 显示职业编码和院校类别等详细信息

## 数据结构

数据包含以下字段：
- 职业编码：职业的官方编码
- 职业(工种)名称：职业的具体名称
- 专业名称：对应的专业名称
- 院校类别：高职及以上等
- 类别：职业分类（A类/B类/C类）

## 匹配规则

- **精确匹配**：只返回专业名称与输入完全相等的记录
- 例如：输入"日语"只返回专业="日语"的记录，不包含"日语笔译"、"旅游日语"等

## 注意事项

- 数据来源于Excel文件，包含A类(1125条)、B类(882条)、C类(811条)
- 搜索需要用户主动触发（点击搜索或按回车）
- 支持按职业类别(A/B/C类)进行筛选
