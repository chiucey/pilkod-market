# 裁判文书网数据库使用指南

专为科研工作者和研究生打造的裁判文书网使用助手，覆盖简单检索、高级检索、出版物检索、核心期刊检索、作者检索等全功能，助力法学论文写作全流程。

## 五大检索模式

### 1. 简单检索
- 输入任意关键词即可搜索
- 系统自动匹配文书标题、正文等内容
- 支持中英文混合检索

**操作步骤**：
1. 访问裁判文书网首页
2. 在搜索框中输入关键词
3. 点击搜索按钮或按回车
4. 浏览搜索结果并选择目标文书

**适用场景**：快速了解某法律问题的基本案例

### 2. 高级检索
- 文书类型筛选（判决书、裁定书等）
- 案件类型筛选（刑事、民事、行政等）
- 法院层级筛选（最高院、高院、中院等）
- 审理程序筛选（一审、二审、再审等）
- 裁判日期范围筛选
- 当事人信息精确匹配

**操作步骤**：
1. 点击"高级检索"入口
2. 选择或输入文书类型
3. 设置案件类型和法院层级
4. 设定时间范围
5. 添加其他筛选条件
6. 点击检索获取结果

**适用场景**：进行系统化的案例收集和数据分析

### 3. 出版物检索
- 法律法规条文检索
- 司法解释和指导案例
- 审判指导与参考
- 法律年鉴和统计资料
- 典型案例汇编

**操作步骤**：
1. 进入"出版物"检索模块
2. 选择出版物类型
3. 输入相关关键词
4. 查看详细目录和摘要
5. 获取文献引用信息

### 4. 核心期刊检索
- CSSCI来源期刊检索
- 北京大学《中文核心期刊要目》
- 中国社会科学引文索引(CSSCI)
- 论文作者和机构检索
- 被引频次和下载量统计

**操作步骤**：
1. 切换至"核心期刊"检索界面
2. 输入期刊名称或论文主题
3. 设置期刊级别筛选条件
4. 查看期刊影响因子和排名
5. 获取论文的引用信息和下载链接

### 5. 作者检索
- 法官姓名精确检索
- 律师执业信息查询
- 学者论文成果统计
- 当事人诉讼记录追踪
- 机构代理人批量查询

**操作步骤**：
1. 进入"作者/人物"检索模块
2. 输入姓名或相关标识
3. 选择检索对象类型
4. 查看关联文书和成果列表
5. 分析办案风格和研究领域

## 常用检索字段

| 字段名 | 说明 | 示例 |
|--------|------|------|
| 案号 | 案件的唯一标识符 | （2023）最高法民终123号 |

| 法院 | 审理案件的法院名称 | 北京市中级人民法院 |
| 法官 | 案件的主审法官姓名 | 王法官、李法官 |
| 律师 | 代理案件的律师事务所 | 某某律师事务所 |
| 法律依据 | 裁判引用的法律条文 | 《民法典》第123条 |
| 关键词 | 文书内容的关键词 | 房屋买卖、违约 |

## 高级检索技巧

1. **精确匹配**：使用双引号包裹关键词，如"合同无效"
2. **排除检索**：使用减号排除词，如合同-租赁
3. **组合检索**：使用AND/OR连接词，如民法典 AND 合同纠纷
4. **模糊检索**：使用星号通配符，如民法*

## 常见问题

**Q: 如何检索特定法律条文的适用案例？**
A: 使用高级检索中的"法律依据"字段，输入相关法律条文编号，如"民法典第584条"，即可检索引用该条文的所有裁判文书。

**Q: 批量下载案例有什么限制？**
A: 为保护数据安全，系统对批量下载功能设置了访问频率限制。建议分批次下载，或使用API接口进行合规的数据获取。

**Q: 如何获取完整的裁判文书内容？**
A: 登录账号后点击文书详情页的"下载原文"按钮，可获取带有法院印章的完整PDF版本。部分敏感信息可能经过脱敏处理。

**Q: 为什么检索结果为空？**
A: 可能原因：1）关键词拼写有误；2）检索条件过于严格；3）相关文书尚未公开；4）系统正在维护。建议调整关键词或使用同义词检索。

**Q: 如何追踪某位法官的裁判风格？**
A: 使用"作者检索"功能输入法官姓名，可查看其主审的全部案件列表，进而分析其裁判偏好、法律适用习惯和量刑/赔偿标准。
