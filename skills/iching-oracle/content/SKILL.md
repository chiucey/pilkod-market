## 大衍之数卜卦法

### 算法原理

大衍之数源于《易经·系辞传》：
> "大衍之数五十，其用四十有九。分而为二以象两，挂一以象三，揲之以四以象四时，归奇于扐以象闰，五岁再闰，故再扐而后挂。"

### 完整运算流程

#### 第一步：准备（50根蓍草）

```
1. 取50根蓍草（可用50根筷子或硬币代替）
2. 取出1根放旁边不用（代表太极）
3. 剩下49根用于演算
```

#### 第二步：分二

```
1. 将49根蓍草随机分成两堆
2. 左手拿一堆，右手拿一堆
3. 象征太极生两仪
```

#### 第三步：挂一

```
1. 从右手堆中取出1根蓍草
2. 将这根蓍草挂在左手小指间
3. 象征三才（天、地、人）
```

#### 第四步：揲四（核心步骤）

```
对左右两堆蓍草分别操作：

1. 用右手数左手的蓍草
   - 每4根为一组
   - 记录余数（1、2、3、4根）
   - 余数放在一边

2. 用右手数右手的蓍草
   - 每4根为一组
   - 记录余数
   - 余数放在一边

3. 挂1 + 左余数 + 右余数 = 5或9
```

#### 第五步：归奇

```
将余数和挂一的蓍草归到一旁

第一种情况：挂1 + 左4余1 + 右4余0 = 5
第二种情况：挂1 + 左4余1 + 右4余1 = 7
第三种情况：挂1 + 左4余0 + 右4余1 = 7
第四种情况：挂1 + 左4余0 + 右4余0 = 9
```

#### 第六步：记录一爻

```
根据剩余蓍草数判断阴阳：

剩余40根 → 阳爻（九）☰
剩余44根 → 阴爻（六）☷

记录这一爻的结果
```

#### 第七步：重复18次

```
将以上步骤重复6次：
- 第1-6次：得到初爻到上爻
- 组成完整的六爻卦象

总运算次数：6爻 × 3次揲四 = 18次
```

### 简化算法（硬币法）

如果手边没有蓍草，可用三枚硬币代替：

```
1. 准备三枚硬币
2. 心中默念问题
3. 摇动硬币，记录结果
   - 3正面 → 少阳（阳爻）☰
   - 2正面1背面 → 少阴（阴爻）☷
   - 1正面2背面 → 少阴（阴爻）☷
   - 3背面 → 老阳（变爻）☰ → 变为阴爻 ☷
4. 重复6次，得到卦象
5. 记录变爻位置
```

```

📿 运算过程：
   第1爻：剩余40根 → ☰ 阳
   第2爻：剩余44根 → ☷ 阴
```
