# 质量检查清单 · Checklist

> 本清单是确保HTML PPT生成质量的关键工具。每一条都是踩坑后的经验总结，按重要性分为P0/P1/P2/P3四个级别。生成PPT前先通读一遍，生成后逐项检查。

---

## 🔴 P0 · 致命问题（必须全部通过）

这些问题会导致PPT无法正常使用或显示严重错误，必须在交付前全部修复。

### 0.1 类名校验（最重要）

**检查方法**：在浏览器开发者工具中检查元素样式，确认类名生效。

**问题现象**：

- 布局样式全部丢失，大标题变成默认字体
- 数据卡片字体小得像正文
- Pipeline多页糊成一坨
- 图片堆到浏览器底部

**根本原因**：layouts.md中的类名在template.html中没有定义。

**解决方案**：

1. 确认`assets/template.html`已被复制到项目目录
2. 检查使用的所有类名是否在template.html的`:root`或`.slide`样式块中定义
3. 常用类名必须存在：`.h-hero`、`.h-xl`、`.h1-zh`、`.lead`、`.meta-row`、`.stat-card`、`.stat-label`、`.stat-nb`、`.stat-unit`、`.stat-note`、`.pipeline-section`、`.pipeline-label`、`.pipeline`、`.step`、`.step-nb`、`.step-title`、`.step-desc`、`.grid-2-7-5`、`.grid-2-6-6`、`.grid-2-8-4`、`.grid-3-3`、`.grid-6`、`.grid-3`、`.grid-4`、`.frame`、`.frame-img`、`.img-cap`、`.callout`、`.callout-src`、`.kicker`

### 0.2 图片路径检查

**检查方法**：在浏览器中打开PPT，逐页检查图片是否正常显示。

**问题现象**：

- 图片显示为破图图标
- 图片位置空白
- 控制台显示404错误

**常见错误**：

- 路径使用绝对路径`/`而非相对路径
- 图片文件名拼写错误
- 图片文件未上传到正确目录

**正确写法**：

```html
<!-- 正确：相对路径 -->
<img src="./assets/xxx.png" alt="">

<!-- 正确：使用变量 -->
<img src="var(--img-path)xxx.png" alt="">

<!-- 错误：绝对路径 -->
<img src="/assets/xxx.png" alt="">
```

### 0.3 主题变量检查

**检查方法**：切换light/dark主题，确认颜色变化正常。

**问题现象**：

- 深色主题下文字不可见（前景色和背景色相同）
- 强调色不显示

**根本原因**：CSS变量未正确定义或未在template.html中声明。

**解决方案**：确认`:root`中包含所有必要变量：`--bg`、`--fg`、`--accent`、`--bg-secondary`、`--gray-1`到`--gray-7`。

### 0.4 翻页功能检查

**检查方法**：使用键盘方向键、鼠标滚轮、触摸滑动测试翻页。

**问题现象**：

- 按键无响应
- 只能前进不能后退
- 翻页动画卡顿严重

**常见原因**：

- JavaScript文件未正确加载
- 事件监听器冲突
- CSS动画性能问题

## 🟠 P1 · 严重问题（必须在发布前修复）

这些问题会影响用户体验，但不会导致完全无法使用。

### 1.1 字体加载检查

**检查方法**：在网络慢的环境下测试，确认有字体回退方案。

**检查项**：

- Google Fonts链接是否有效
- 字体文件是否正确加载
- 是否设置了字体回退（fallback fonts）
- 中文字体是否完整

**正确写法**：

```css
font-family: 'Noto Serif SC', 'Source Han Serif SC', 'SimSun', serif;
```

### 1.2 响应式布局检查

**检查方法**：使用浏览器开发者工具测试以下视口：

- 桌面端：1920×1080、1440×900
- 平板端：1024×768、768×1024
- 移动端：375×667、414×896

**检查项**：

- 内容是否溢出容器
- 文字是否过小无法阅读
- 图片是否变形或裁剪过度
- 网格布局是否错乱

### 1.3 对比度检查

**检查方法**：使用浏览器开发者工具或axe插件检查颜色对比度。

**标准**：WCAG 2.1 AA级

- 普通文字：至少4.5:1
- 大号文字（18px+）：至少3:1
- 图形和UI组件：至少3:1

**常见问题**：

- 深色主题下灰色文字对比度不足
- 占位符文字与背景对比度不足

### 1.4 动画性能检查

**检查方法**：使用Chrome DevTools Performance面板录制翻页动画。

**检查项**：

- 帧率是否稳定在60fps
- 是否有长任务（>50ms）阻塞动画
- GPU加速是否启用（transform、opacity变化）

**优化建议**：

- 减少同时动画的元素数量
- 使用transform和opacity而非width、height
- 添加`will-change`提示浏览器优化

## 🟡 P2 · 常规问题（建议修复）

这些问题影响专业度，建议修复但不紧急。

### 2.1 内容完整性检查

**检查方法**：对照需求清单逐项核对。

**检查项**：

- [ ] 所有章节页面都已生成
- [ ] 所有数据都已填充
- [ ] 所有图片都已替换

**检查方法**：大声朗读PPT内容或使用拼写检查工具。

**检查项**：

- [ ] 数字格式统一（如2024年而非2024 year）
- [ ] 无明显错别字

### 2.3 导航一致性检查

**检查方法**：逐页检查页眉页脚。

**检查项**：

- [ ] 页码顺序连续（01, 02, 03...）
- [ ] 总页数与实际页数一致
- [ ] 章节名称在各页保持一致
- [ ] foot.center的项目名称在各页一致

### 2.4 图片质量检查

**检查方法**：在浏览器中放大图片到200%检查。

**检查项**：

- [ ] 图片分辨率足够（至少1.5倍显示尺寸）
- [ ] 无明显锯齿或模糊
- [ ] 截图类图片文字清晰可读
- [ ] 图片比例正确无拉伸

## 🟢 P3 · 优化建议（锦上添花）

这些是提升体验的优化项，可根据时间决定是否实施。

### 3.1 加载性能优化

**检查方法**：使用Lighthouse审计。

**建议项**：

- 图片使用WebP格式
- 启用Gzip压缩
- 添加CSS/JS文件合并
- 使用CDN加速

### 3.2 无障碍优化

**检查方法**：使用axe或WAVE工具审计。

**建议项**：

- 所有图片添加alt属性
- 表单元素关联标签
- 焦点顺序合理
- 添加ARIA标签

### 3.3 打印适配检查

**检查方法**：使用浏览器打印预览功能。

**检查项**：

- [ ] 深色主题打印效果（可添加`@media print`样式）
- [ ] 分页位置合理
- [ ] 页眉页脚打印适配

### 3.4 浏览器兼容性检查

**测试浏览器**：

- Chrome 90+
- Firefox 88+
- Safari 14+
- Edge 90+

**常见兼容性问题**：

- CSS变量在旧浏览器支持
- Flex布局差异
- 滚动条样式差异

## 常见问题与解决方案

### Q1: 样式丢失怎么办？

**A**: 按以下顺序排查：

1. 检查template.html是否被正确引用
2. 检查类名是否在template.html中定义
3. 检查CSS变量是否正确定义
4. 检查是否有CSS优先级覆盖问题

### Q2: 图片无法显示怎么办？

**A**: 按以下顺序排查：

1. 检查图片路径是否正确
2. 检查图片文件是否存在
3. 检查图片格式是否支持（推荐PNG/JPG/WebP）
4. 检查图片文件大小（过大可能导致加载失败）

### Q3: 动画不流畅怎么办？

**A**: 优化建议：

1. 减少同时动画的元素数量
2. 使用transform/opacity而非其他属性
3. 关闭后台标签页的动画
4. 降低动画复杂度（减少stagger步骤）

### Q4: 深色主题颜色不对怎么办？

**A**: 检查：

1. 确认`data-theme="dark"`属性存在
2. 检查`[data-theme="dark"]`样式块是否存在
3. 检查深色主题的变量是否定义
4. 清理浏览器缓存

### Q5: 页码不连续怎么办？

**A**: 手动检查每个slide的chrome.right和foot.left/foot.right，确保：

1. 编号从01开始
2. 编号连续递增
3. 总页数与实际页数一致
4. 不使用前导零以外的前缀
