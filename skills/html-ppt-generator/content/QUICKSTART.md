# HTML PPT Generator - 快速入门指南

> 本指南帮助你在5分钟内了解如何使用本Skill生成专业的HTML演示文稿。

## 什么是HTML PPT？

HTML PPT是一种基于网页技术（HTML/CSS/JavaScript）构建的演示文稿，它可以：

- 在任何现代浏览器中直接打开
- 支持键盘、鼠标、触摸多种交互方式
- 提供流畅的翻页动画和过渡效果
- 无需安装任何软件，跨平台兼容
- 可以轻松部署到网页或转换为PDF

## 快速开始（3步走）

### 第1步：触发Skill

告诉AI你需要制作PPT，使用以下任一方式：

```
"帮我做一个HTML PPT"
"生成一个商务汇报PPT"
"做一个智慧城市建设汇报"
"制作产品发布演示文稿"
```

### 第2步：回答6个问题

AI会通过6个问题了解你的需求：

| 问题 | 示例回答 | 说明 |
|------|----------|------|
| **受众是谁** | 公司管理层、评审专家、客户 | 决定表达方式和信息深度 |
| **分享时长** | 15分钟、30分钟 | 决定页数和信息密度 |
| **原始素材** | 有/无 | 有素材可提高效率 |
| **图片素材** | 有/无 | 图片是视觉重要组成 |
| **主题色** | 政务庄重、科技未来 | 从7套预设中选择 |
| **硬约束** | 必须包含XX数据 | 必须包含/避免的内容 |

### 第3步：等待生成

AI会根据你的需求自动生成完整的HTML PPT，包含：

- 所有页面结构和内容
- 选定主题色的样式
- 适合场景的布局和组件
- 流畅的翻页动画

## 常见问题

### Q: 如何修改PPT内容？

A: 直接编辑生成的HTML文件，找到对应的文字内容进行修改。

### Q: 如何更换主题色？

A: 编辑HTML文件中的`:root`选择器，替换CSS变量值。或者告诉AI"切换到XX主题色"，AI会自动帮你修改。

### Q: 如何导出为PDF？

A: 在浏览器中打开PPT，按`Ctrl+P`（Mac为`Cmd+P`），选择"另存为PDF"。

### Q: 图片无法显示怎么办？

A: 检查图片路径是否正确，确保使用相对路径（相对于HTML文件）。

### Q: 如何添加新页面？

A: 复制现有的`<section class="slide">`块，修改内容和页码即可。
