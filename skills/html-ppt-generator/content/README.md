# HTML PPT Generator Skill

> 一个强大的HTML演示文稿生成Skill，能够根据用户需求自动生成专业、美观、响应式的网页PPT。支持10种场景类型、7套主题色、18种页面布局，专为商务汇报、政务汇报、产品展示等场景设计。

## 效果预览

生成的HTML PPT具有以下特点：

- 🎨 **多套主题色**：7套预设主题色，从政务庄重到科技未来
- 📐 **丰富布局**：18种页面布局模板（含6个新变体），满足各类场景需求
- 🏛️ **架构图支持**：政务场景专用架构图模板（五横三纵、业务架构、数据架构等）
- 📊 **数据可视化**：支持多种图表和数据卡片展示
- 🎬 **流畅动画**：平滑的翻页动画和元素入场动画
- ⌨️ **多种交互**：支持键盘、鼠标滚轮、触摸滑动翻页
- 🔍 **全文搜索**：Ctrl+F 快速搜索内容并跳转
- 🖨️ **打印优化**：深色主题自动转换为浅色打印
- ♿ **无障碍支持**：键盘导航、屏幕阅读器适配、减少动画模式
- 📱 **响应式设计**：自适应不同屏幕尺寸
- 📚 **完整文档**：快速入门指南、场景模板、CSS变量速查表

## 使用方法

### 触发方式

用户可以使用以下方式触发本Skill：

- "帮我做一个HTML PPT"
- "生成一个网页演示文稿"
- "制作一个商务汇报PPT"

- "做一个产品发布会PPT"

### 6步工作流程

#### 步骤1：需求澄清

生成PPT前，AI会通过以下6个问题收集需求：

1. **受众是谁** - 明确PPT的阅读或演示对象
2. **分享时长多久** - 决定PPT的页数和每页信息密度
3. **有没有原始素材** - 文档、数据、旧PPT、文章链接等
4. **有没有图片素材** - 产品图片、数据截图等
5. **想要使用哪套主题色** - 从6套预设中选择
6. **有没有硬约束** - 必须包含或必须避免的内容

#### 步骤2：场景识别

根据用户提供的场景类型，确定内容结构模板。不同场景有不同的内容框架：

- 政务信息化汇报：概述→架构→成果→数据→计划→问题
- 商务汇报：业绩→区域→客户→趋势→对策→目标
- 项目提案：背景→方案→路径→团队→案例→回报→风险

#### 步骤3：模板选择

从以下选项中选择合适的模板：

**主题色选择**（必须选择）：

- 🖋 墨水经典 - 通用默认，商业发布
- 🔴 政务庄重 - 传统政务汇报，官方场合
- 🔵 政务科技 - 智慧城市，数字化政务（蓝色科技融合）
- 🌊 科技未来 - 科技产品，技术发布
- 🌿 教育清新 - 教育培训，知识分享
- 📊 数据专业 - 数据分析，运营报告
- 🎨 创意艺术 - 创意展示，艺术呈现

**布局选择**（根据内容选择）：

- Hero全屏封面
- 章节幕封
- 左文右图
- Stat数字大字报
- Pipeline流程步骤
- 大引用金句
- Before/After对比
- 图片网格
- 问题与建议
- 时间轴/里程碑
- 三栏支柱
- 结束致谢

#### 步骤4：内容填充

将用户提供的素材和关键信息填充到选定的模板中。遵循原则：

- 每页聚焦一个核心信息点
- 标题简洁有力
- 数据可视化优先
- 层级分明
- 适当留白

#### 步骤5：自检优化

生成完成后，对照`references/checklist.md`逐项检查。常见问题：

- 类名错误导致样式丢失
- 图片路径错误
- 字体加载失败
- 响应式布局异常
- 动画过于花哨

#### 步骤6：交付迭代

提供生成结果，根据反馈进行迭代优化。常见迭代需求：

- 内容调整
- 样式调整
- 布局调整
- 动画调整

## 政务架构图（政务场景专用）

当选择政务信息化汇报场景时，可按需选择以下架构图模板：

### 1. "五横三纵"总体架构

适用于全面汇报、领导汇报场景，展示政务信息化的整体架构：

- **五横**（自下而上）：基础设施层 → 数据资源层 → 支撑平台层 → 应用系统层 → 交互展现层
- **三纵**（贯穿全局）：安全体系（网络安全、数据安全、应用安全）、标准规范（技术标准、管理标准）、运维保障（运营管理、运维服务）

### 2. 业务架构

适用于业务梳理、能力展示场景：

- 政务服务域（事项管理、审批管理、证照管理、电子监察）
- 民生保障域（社保服务、就业服务、民政服务、公积金）
- 城市治理域（网格管理、应急指挥、城管执法、生态环境）
- 经济发展域（市场监管、投资项目、企业服务、统计分析）

### 3. 数据架构

适用于数据治理、共享交换场景：

- 数据源层：业务系统、政务文档、空间数据、IoT感知、互联网
- 数据中台：数据归集、数据治理、数据共享、数据分析
- 数据应用层：数据目录、数据报表、数据检索、AI服务

### 4. 应用架构

适用于应用系统、渠道展示场景：

- 用户层：企业群众、工作人员、管理人员
- 渠道层：Web门户、移动App、微信小程序、自助终端
- 应用层：政务服务类、城市治理类、民生服务类

### 5. 技术架构

适用于技术评审、选型说明场景：

- 基础设施：云服务器、云数据库、对象存储、CDN网络
- 中间件：容器平台、消息队列、分布式缓存、搜索引擎
- 数据层：PostgreSQL、MongoDB、时序数据库、图数据库
- 应用框架：Spring Cloud、React/Vue、Python/AI、.NET Core

> 💡 **使用建议**：架构图模板可按需组合使用。全面汇报选"五横三纵"，业务梳理选业务架构，数据相关选数据架构，应用展示选应用架构，技术评审选技术架构。

## 质量检查

生成完成后，请对照`references/checklist.md`进行检查：

### P0 致命问题（必须修复）

- 类名是否匹配
- 图片路径是否正确
- 主题变量是否定义
- 翻页功能是否正常

### P1 严重问题（发布前修复）

- 字体加载是否正常
- 响应式布局是否正常
- 颜色对比度是否达标
- 动画性能是否流畅

### P2 常规问题（建议修复）

- 内容是否完整
- 语法是否正确
- 导航是否一致
- 图片质量是否清晰

## 常见问题

### Q: 如何修改主题色？

A: 编辑`assets/template.html`，找到`:root`选择器，替换相应的CSS变量值。

### Q: 如何添加新页面？

A: 复制`assets/template.html`中的一个`<section class="slide">`块，修改内容和页码。

### Q: 如何导出为PDF？

A: 在浏览器中打开PPT，使用浏览器自带的打印功能（Ctrl+P），选择"另存为PDF"。

### Q: 图片无法显示怎么办？

A: 检查图片路径是否正确，确保使用相对路径而非绝对路径。

### Q: 动画不流畅怎么办？

A: 减少同时动画的元素数量，或移除`data-anim`属性禁用动画。
