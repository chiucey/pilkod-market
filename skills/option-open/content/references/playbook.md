# 期权开仓 Playbook（华尔街职业交易员方法论）

> 核心纪律：**先判环境，再选结构，最后定腿**。永远不要带着"我最熟的策略"进场——先问市场现在是买方环境还是卖方环境。

## 一、环境判定（开仓前的第一道工序）

### 1. 波动率定价：贵还是便宜
| 指标 | 数据含义 | 判定 |
|---|---|---|
| ATM IV vs 20日HV | 隐波对已实现波动的溢价（VRP） | 溢价 > 4pts → 卖方有优势；≈0 → 买方不吃亏；IV < HV → 买方折扣 |
| IV Rank（1年分位） | 隐波贵贱的历史坐标 | < 30 → 便宜，偏向买方/vega多头；> 60 → 贵，偏向卖方/vega空头 |
| 期限结构 | 近月 vs 远月 IV | 近月 > 远月（倒挂）→ 事件驱动，短久期买方；正常上倾 → 日历/卖远月 |

### 2. 做市商定位（Gamma 结构）
- **Gamma Flip 价位**：现价在 flip 上方（正 gamma 区）→ 做市商高抛低吸、波动被抑制，适合卖方；现价在 flip 下方（负 gamma 区）→ 追涨杀跌、波动放大，适合买方。
- **Call Wall / Put Wall**：最大 gamma 敞口行权价 = 天然阻力/支撑。卖方短腿尽量贴墙内侧收租；买方目标位看到墙前（墙是磁铁也是天花板）。
- 现价紧贴 flip（±1%）→ 方向必然选择，买方宽跨式的标准格局。

### 3. 事件日历（硬约束）
- **财报**：卖方绝不持有跨财报（铁律）。买方吃财报必须提前 1-2 周进场吃位移，财报当周不追（IV crush 吃掉大部分涨幅）。
- **FOMC / CPI / 大选 / 产品发布**：同财报逻辑，事件前 IV 被抬高 → 事件前 1-2 天是卖方窗口（卖高 IV），事件后买方已死。
- 到期日选择标准：**标准月度链（第三个周五）流动性最好**；30-45 DTE 给卖方留 theta 空间，7-25 DTE 给事件买方留杠杆。

## 二、策略菜单（按环境匹配，买方卖方都摆上桌）

### 买方环境（IV 便宜 / 负 gamma 区 / 卡 flip 刀刃）
| 结构 | 适用场景 | 关键参数 |
|---|---|---|
| Long Straddle | 事件在到期内、IV 低于预期波动 | ATM 双买，成本 = 1 straddle，需 |S| > 成本才回本 |
| Long Strangle | 方向不明但必出方向（卡 flip） | OTM 双买（±5% 档），成本减半、需要更大幅度 |
| Bull/Bear Vertical（借方价差） | 有方向观点、想压缩成本 | 买 ATM 卖 OTM（墙位），最大收益 100-200% |
| 日历价差（买远卖近） | 事件在近月到期后、远月 IV 低 | 卖近月 ATM + 买跨事件远月，吃 vega 回升 |

### 卖方环境（IV 贵 / 正 gamma 区 / 区间震荡）
| 结构 | 适用场景 | 关键参数 |
|---|---|---|
| Iron Condor | 双边墙清晰、无财报窗口 | 短腿贴 wall 内侧 delta 0.15-0.20， wings 4-5 档 |
| Credit Spread（单边） | 有方向+波动率双优势 | 短腿 delta 0.20-0.30，收租 ≥ 风险带宽的 1/4 |
| Cash-Secured Put | 想低位接货 | 行权价 = 愿意接货的价位（支撑/wall 下方） |
| PMCC（对角） | 长期看多、持有期间收租 | 深值 LEAPS 做底 + 滚动卖短月 call |

### 中性/不确定
- 蝶式（Butterfly）：预期钉在某个价位（max pain/wall）时用，卖中翼买双翼。
- 价差替代裸卖：任何裸腿都优先降级为定义风险的价差。

## 三、开仓执行纪律

1. **避开开盘前 30 分钟**：价差最宽、滑点最大。用限价单挂中间价，不追市价。
2. **四巫日**：机构 roll 集中在开盘后第一小时，尾盘清算波动大——开仓选上午 10 点后或干脆等下周一。
3. **仓位**：单笔权利金支出/收租承担的风险 ≤ 账户 5%；相关性高的标的（如同时开 GOOG+AMZN，相关系数 ~0.8）合计 ≤ 10%。
4. **每单必带退出条件**：开仓时同时写下止盈位、止损位、delta 警戒位（卖方短腿 0.30）、财报避让日——没有退出计划不开仓。
5. **报价核验**：所有市价报价过一遍 `scripts/options_pricer.py strategy` 的 BS 理论价对比，偏差 > 15% 的腿不碰（流动性陷阱或报价过期）。

|---|---|---|---|---|---|---|---|
