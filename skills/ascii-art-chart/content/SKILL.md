# ASCII 艺术图表生成器

## 能力概览

此技能可将数据转换为精美的 ASCII 艺术图表，支持多种图表类型、ANSI 颜色渲染和丰富的主题样式。

## 支持的图表类型

| 类型 | 触发关键词 | 最佳场景 |
|------|----------|---------|
| 柱状图 | `bar`, `柱状图`, `条形图` | 比较分类数据 |
| 折线图 | `line`, `折线图`, `趋势图` | 展示时间序列趋势 |
| 饼图 | `pie`, `饼图`, `占比图` | 显示比例分布 |
| 散点图 | `scatter`, `散点图` | 展示变量关系 |
| 甘特图 | `gantt`, `甘特图`, `进度图` | 项目时间安排 |
| 面积图 | `area`, `面积图` | 累积数据展示 |
| 直方图 | `histogram`, `直方图` | 频率分布统计 |

## 使用方法

### 基本语法

```
[图表类型] [标题]
---
[数据标签] : [数值或系列]
---
[样式选项]
```

### 数据格式

**单系列数据（柱状图）**：
```
项目A : 75
项目B : 120
项目C : 45
```

**多系列数据（折线图）**：
```
季度    系列A    系列B
Q1      30       45
Q2      45       60
Q3      60       55
Q4      75       80
```

## 样式配置

### 颜色支持（ANSI 转义序列）

| 颜色名 | 代码 | 用途 |
|-------|------|-----|
| 红色 | `red` | 高亮/警告 |
| 绿色 | `green` | 增长/成功 |
| 蓝色 | `blue` | 主数据 |
| 黄色 | `yellow` | 警示 |
| 紫色 | `purple` | 次要数据 |
| 青色 | `cyan` | 强调 |
| 白色 | `white` | 默认 |

### 主题预设

| 主题名 | 描述 | 适用图表 |
|-------|------|---------|
| `simple` | 简洁单色风格 | 快速预览 |
| `classic` | 传统终端风格 | 复古爱好者 |
| `modern` | 粗体多彩风格 | 演示文稿 |
| `minimal` | 极简无边框 | 现代简约 |
| `grid` | 完整网格线 | 数据分析 |

### 自定义选项

| 选项 | 语法 | 说明 |
|------|------|-----|
| 高度 | `height: N` | 图表高度 (5-50) |
| 宽度 | `width: N` | 图表宽度 (20-200) |
| 字符 | `char: X` | 填充字符 |
| 边框 | `border: on/off` | 显示边框 |
| 数值 | `values: on/off` | 显示数据值 |
| 图例 | `legend: on/off` | 显示图例 |
| 颜色 | `color: NAME` | 指定颜色 |

## 高级功能

### 数据缩放

使用 `scale: linear/log` 切换线性/对数刻度：
```
scale: log
height: 40
```

### 堆叠模式

对于柱状图和面积图，使用 `stacked: on` 启用堆叠显示。

### 自定义填充字符

```
char: ▓   // 使用半填充字符
char: █   // 实心块（默认）
char: ░   // 浅色块
char: ╬   // 特殊图案
```

### 数值格式化

| 格式 | 语法 | 示例 |
|------|------|-----|
| 原始值 | `format: raw` | 12345 |
| 千分位 | `format: comma` | 12,345 |
| 百分比 | `format: percent` | 45% |
| 货币 | `format: currency` | $12,345 |
| 科学计数 | `format: scientific` | 1.23e4 |

## 提示与技巧

1. **清晰的数据格式**：使用一致的分隔符和数据顺序
2. **合理的数值范围**：避免极端值导致的图表失真
3. **颜色选择**：考虑终端背景色，选择对比度好的颜色
4. **高度调整**：数据范围大时增加高度以提高精度
5. **标题添加**：为复杂图表添加说明性标题

## 故障排除

| 问题 | 解决方案 |
|------|---------|
| 图表显示异常 | 检查数据格式是否正确 |
| 颜色不显示 | 确认终端支持 ANSI 颜色 |
| 数值重叠 | 增加宽度或减少小数位 |
| 字符错位 | 使用等宽字体（如 Consolas, Monaco） |
