|------|------|

### 256色扩展

格式：`\033[38;5;Nm` (前景) 或 `\033[48;5;Nm` (背景)

示例：
- `\033[38;5;196m` - 标准红色
- `\033[38;5;208m` - 橙色
- `\033[38;5;226m` - 亮黄色
- `\033[38;5;46m` - 亮绿色
- `\033[38;5;21m` - 标准蓝色

### RGB 真彩色

格式：`\033[38;2;R;G;Bm` (前景) 或 `\033[48;2;R;G;Bm` (背景)

示例：
- `\033[38;2;255;100;0m` - 橙红色
- `\033[38;2;0;255;255m` - 青色
- `\033[38;2;255;0;255m` - 洋红色

## 使用示例

### Python 示例

```python
class AsciiColors:
    HEADER = '\033[95m'
    OKBLUE = '\033[94m'
    OKGREEN = '\033[92m'
    WARNING = '\033[93m'
    FAIL = '\033[91m'
    ENDC = '\033[0m'
    BOLD = '\033[1m'

    @classmethod
    def color(cls, text, color_code):
        return f"{color_code}{text}{cls.ENDC}"

# 使用
print(f"{AsciiColors.OKGREEN}成功：{AsciiColors.ENDC} 操作完成")
```

### JavaScript 示例

```javascript
const colors = {
  reset: '\x1b[0m',
  red: '\x1b[31m',
  green: '\x1b[32m',
  yellow: '\x1b[33m',
  blue: '\x1b[34m',
  bold: '\x1b[1m'
};

const colored = (text, color) => `${colors[color]}${text}${colors.reset}`;
console.log(colored('警告信息', 'yellow'));
```

## 兼容性注意事项

1. **Windows CMD**：默认支持 16 色，256 色需 Windows 10+
2. **Windows PowerShell**：更好的 ANSI 支持
3. **Linux/macOS 终端**：完全支持所有 ANSI 代码
4. **Web 浏览器**：使用 CSS 颜色转换
5. **某些远程终端**：可能不完全支持

## 最佳实践

1. 始终使用 `\033[0m` 重置颜色
2. 嵌套颜色时确保正确闭合
3. 在不支持彩色的环境中提供降级方案
4. 使用环境变量检测终端能力
5. 测试多种终端兼容性
