## 时区要求

**所有页面显示时间必须用 Asia/Shanghai(北京时间)**。

`fetch_and_push.py` 已实现:
```python
from zoneinfo import ZoneInfo
_BJ = ZoneInfo("Asia/Shanghai")

def now_bj():
    return datetime.now(_BJ)

def now_bj_str():
    return now_bj().strftime("%Y-%m-%d %H:%M:%S")
```

**校验**:跑脚本后第一行日志必须是 `2026-07-06 13:xx:xx`(北京时间),不能是 `05:xx:xx`(UTC)。

如果看到 UTC 时间,立刻修复:
1. 确认 `from zoneinfo import ZoneInfo` 没被注释
2. 确认所有 `datetime.now()` 替换为 `now_bj()`
3. 系统时区不需要改(脚本内部时区转换即可)

## 需要协作事项的标记规则(2026-07-19 改版)

**关键原则: 需要协作 = 需要其他部门推动, 研发本职的事不算。**

- **本职工作**(申请物料编码/归档文件/设计/调试/验证)→ 不列为需要协作事项
- **需要采购/计划/中试/销售市场/其他部门推动的** → 列为需要协作事项,每条后面跟 [部门] 标签

### 公司部门职责对照表

| 部门 | 职责 |
|------|------|
| **采购** | 负责买物料。缺物料、需要采购设备找他。 |
| **计划和生产** | 负责公司内样品制作、批量产品生产。内部生产的事情找他。 |

| **研发(本职)** | 申请物料编码、归档文件、设计/调试/验证等本职技术工作。 |

### 不分类,改为每条加标签

### 流程末端任务过滤 (v6 重点)

**关键规则:** 同一项目下的子任务有流程顺序

```
项目
├── 原理图设计 → 原理图评审 → PCB设计 → PCB评审
├── 测试验证 → 型式试验 → 送样 → 验收
└── 文件归档 (末端, 等前面所有完成后才能做)
```

**过滤逻辑** (在 8+ 天未更新、近 2 周未更新、协作事项 三处都加):
- 任务名 = "文件归档/归档/物料编码/物料申请"
- 且同父项目下还有更早阶段任务 (测试验证/送样/型式试验/验收/高压测试/样品测试/调试/测试/小批量) 未完成
- → **不计入 8+ 天未更新**, 不算"前置阻塞", 归"流程末端"分类

**为什么需要:** 张云 6 条文件归档 8+ 天未更新, 实际都是因为父项目卡在更早阶段, 本来就不能做。催张云是冤枉人。催真正该催的:父项目负责人。

### 部门标签 (v8 整句理解 - 2026-07-27 重要改版)

**关键设计原则: 不能只靠关键词, 要理解整句意思。**

#### 三步判定法

1. **看主语** - 谁去做什么事?
   - 研发自己 定底座尺寸/写原理图/调电阻 → 研发本职
   - 采购 催供应商/找物料 → 采购
   - 销售 联系客户/对客户 → 销售和市场
   - 生产 排产/贴片/上线 → 计划和生产
   - 中试 负责型式试验/高压测试 → 中试

2. **看动作** - 做什么?
   - 买/催/找/问价/下单/开模 → 采购
   - 排期/排产/投产/贴片 → 计划和生产
   - 高压测试/型式试验/复现/验报告 → 中试
   - 联系客户/发PO/催客户/客户验收 → 销售和市场
   - 写代码/调参数/设计/改原理图/出报告 → 研发本职

3. **看对象** - 对谁做?
   - 对供应商 → 采购
   - 对客户/项目/PO → 销售和市场
   - 对产品/电路/代码 → 研发本职
   - 对生产排期 → 计划
