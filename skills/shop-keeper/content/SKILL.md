# 店铺管家 Skill

## 核心功能

1. **每日数据记录**：录入营收（美团/饿了么/堂食）和食材成本
2. **自动计算利润**：毛利、扣除日固定成本后的净利润
3. **日对比**：今日 vs 昨日
4. **周对比**：本周（近7天）vs 上周（8-14天）
5. **月对比**：本月 vs 上月
6. **月度目标追踪**：可设置月度营收目标并追踪进度

---

## 固定成本（已内置，无需重复录入）

- 房租：3,800元/月
- 物业费：145元/月
- 员工A：4,000元/月
- 员工B：4,000元/月
- **月固定成本合计：11,945元**

分摊计算：
- 日固定成本 = 11,945 ÷ 当月天数
- 利润 = 营收 - 浮动成本 - 日固定成本

## 每日数据录入

二哥每天发送今日数据，格式如下：

```
今日数据：
美团：___元
饿了么：___元
堂食：___元
食材：___元
推广：___元（如有）
其他：___元（如有）
```

或简洁格式：
```
今日：美团120，饿了么40，堂食30，食材85，推广50
```

**注意：**
- 固定成本（房租/物业/工资）无需每天说，系统自动计算
- 燃气和水电**每月发一次**给我，格式见下方

---

## 月度数据录入（每月发一次）

当月燃气和水电费用告诉我，格式：

```
本月水电：
燃气：___元
水电：___元
```

我收到后会自动分摊到每日成本中计算。

## 查看报告

当二哥说「看看今天数据」「今日对比」「本周数据」「本月数据」时，执行报告命令。

也可以直接说「今日」，我会自动对比昨日数据。

---

## 脚本调用方式

### 记录每日数据
```
python3 scripts/daily_record.py record YYYY-MM-DD 美团金额 饿了么金额 堂食金额 食材金额 [推广金额] [其他金额]
```

### 生成对比报告
```
python3 scripts/daily_record.py report [YYYY-MM-DD]
```

### 录入月度燃气水电
```
python3 scripts/daily_record.py set_utility YYYY-MM 燃气金额 水电金额
```

### 初始化数据文件
```
python3 scripts/daily_record.py init
```

---

## 输出格式规范

报告输出包含：

1. **今日 vs 昨日**：营收、食材、毛利、净利润对比（带箭头和百分比）
2. **本周 vs 上周**：总营收、日均营收、天数、毛利对比
3. **本月 vs 上月**：总营收、日均、食材成本、推广成本、燃气水电、毛利、净利润对比
4. **月度目标进度**：进度条展示

---

## 数据存储

- `records.json`：每日收支记录（自动累积）
- `monthly_utilities.json`：月度燃气水电记录
- 文件路径：`skills/shop-keeper/records.json` 和 `monthly_utilities.json`

---

## 注意事项

- 数据文件在 SKILL.md 同目录下（`skills/shop-keeper/`）
- 每次录入自动追加，不会覆盖历史数据
- 月份自动以文件修改时间判定，无需告知今日日期
- 所有金额单位：元，无需加"元"字
