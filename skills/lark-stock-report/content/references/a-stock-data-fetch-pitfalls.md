### §44.1 Sina `Market_Center.getHQNodeData` 数字字段是 STRINGS (重要工程坑)

**6/29 实测踩坑**:

```python
# ❌ 错误: 直接当 float 用
for s in data:
    prev_close = s["trade"] / (1 + s["changepercent"] / 100)  # TypeError!
```

**错误信息**:
```
TypeError: unsupported operand type(s) for /: 'str' and 'float'
```

**根因**:
- Sina `Market_Center.getHQNodeData?page=N&num=100&sort=changepercent&asc=0&node=hs_a` 返回的 `trade` / `open` / `changepercent` / `volume` / `amount` 等数字字段**全部是 STRINGS, 不是 floats**
- 这是**该具体接口的特殊行为** — 同一系列的 Sina K-line (`CN_MarketData.getKLineData`) 数字字段是 floats, EastMoney push2 (`f3`/`f4`/`f8` 等) 也是 floats
- **只有 Sina 这个具体接口是字符串**. 之前的 `count_limit_accurate.py` / `parse_push2_breadth.py` / `market_breadth_sampling.py` 等脚本都默认它们是数字 (因为同系列 Sina K-line 接口是数字), **遇到这个接口就翻车**

**【铁律】所有 Sina `Market_Center.getHQNodeData` 处理必须 `to_float()` 包装**:
```python
def to_float(v):
    """Sina API 数字字段 → float 包装. 字符串/空值/无效值都安全返回 0.0"""
    if v is None or v == "":
        return 0.0
    try:
        return float(v)
    except (ValueError, TypeError):
        return 0.0

for s in data:
    trade = to_float(s.get("trade", 0))   # ✓
    pct = to_float(s.get("changepercent", 0))  # ✓
    opn = to_float(s.get("open", 0))  # ✓
    prev_close = trade / (1 + pct / 100.0)  # ✓ 正常
```

**判断字段类型**:
```python
# 调试时打印字段类型
print(type(s.get("trade")))  # <class 'str'>  ← Sina 涨幅榜
print(type(s.get("f3")))      # <class 'float'>  ← push2
print(type(s.get("close")))   # <class 'str'>  ← Sina K-line (但 close 是 string)
```

**Sina 字段类型对照表**:

| 接口 | trade/close/open | changepercent/pct | volume/amount | 备注 |
|---|---|---|---|---|
| Sina `Market_Center.getHQNodeData` | **STRING** | **STRING** | **STRING** | 6/29 踩坑 |
| Sina `CN_MarketData.getKLineData` | STRING | (无 pct 字段) | (无 volume) | 已知 string |
| EastMoney `push2` (f3, f4, f8 等) | float (÷100) | float | float (÷1e8 转亿) | 已知 float |
| 腾讯 `qt.gtimg.cn` | float | float | float | 已知 float |

**配套脚本**:
- `scripts/sina_field_type_safe.py` (skill `lark-stock-report`) — 含 `to_float()` helper + 自动扫描 sina p1-p5 + bottom100.json 全字段 + 4 象限 V-reversal 计算 + 涨停/跌停分类 + 涨停主线集中度统计
- 用法: `python3 scripts/sina_field_type_safe.py /tmp/idx_data`, 输出 `/tmp/idx_data/sina_parsed.json`
- 6/29 实测: 387 stocks → 3-5% 涨幅 133 只 (V 74.44%), 涨停 19 (含 7 ST + 1 N) / 跌停 0, 涨停集中度半导体 25% / 化工 25% < 30%

**预防 checklist**:
- 写新 Sina 涨幅榜处理脚本时, **先打印 `type(s.get("trade"))` 确认是 STRING**
- 在循环内**统一用 `to_float()`**, 不要假设字段是 float
- **不要**用 `(s.get("trade") or 0)` (短路 0 也是 float 0, 不会触发错误) — 必须显式 `to_float()`

**症状**:
- `https://push2.eastmoney.com/api/qt/clist/get?pn=1&pz=20&po=1&fid=f3&fs=m:90+t:2` 在 **9:30 阶段**返回的**涨幅 0.02-0.06%** (正常交易日应在 ±2% 量级)

- 集合竞价阶段 (9:15-9:25) + 开盘首分钟 (9:30-9:35), push2 板块榜的**实时计算尚未完成** (需要分钟级数据累积)
