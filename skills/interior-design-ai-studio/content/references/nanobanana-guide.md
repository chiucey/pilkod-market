# NANOBANANA 室内设计完整指南

## 一、工具概述

### 什么是 NANOBANANA？
NANOBANANA 是基于 Google Gemini 图像模型的 AI 生图工具，内部代号"Nano Banana"。它能快速将手绘平面图、SketchUp 模型截图或房间实景照片转化为专业级 4K 渲染图。

**核心优势**：
- 完全免费使用（基础功能）
- 无需复杂提示词
- 支持连续迭代编辑
- 平面图转效果图准确率 90%+

### 版本选择

| 版本 | 入口 | 费用 | 功能 |
|------|------|------|------|
| 免费版 | nanobanana.io | 免费 | 基础生图、局部编辑 |
| Pro 版 | nanobanana.art | 付费 | 更高分辨率、无水印 |
| 国内镜像 | katuai.cn | 免费/付费 | 网络更稳定、中文界面 |

## 二、核心功能详解

### 1. 平面图转效果图（最强大功能）

**适用场景**：
- 设计师快速出效果图
- 客户方案汇报
- 竞品方案分析

**操作流程**：
```
第一步：上传平面图
- 支持格式：JPG、PNG、PDF
- 手绘草图或 CAD 导出图均可
- 建议清晰度：至少 1024px

第二步：选择空间类型
- 客厅、卧室、厨房、卫生间
- 办公空间、商业空间

第三步：输入风格描述
- 越具体效果越好
- 包含材质、色彩、氛围

第四步：生成并微调
- 1-3 分钟出图
- 可局部调整或重新生成
```

**提示词模板**：

奶油风客厅：
```
将此平面图转化为奶油风格客厅效果图

设计要求：
- 主色调：奶油白 #FFF8E7、燕麦色 #E8DFD0
- 沙发：羊羔绒材质，浅米色，圆弧造型
- 地面：原木色木地板，人字拼
- 墙面：奶油色乳胶漆，局部艺术涂料
- 装饰：拱形元素、藤编收纳、棉麻抱枕
- 光线：午后暖阳，柔和阴影
- 氛围：温馨治愈，适合年轻家庭
```

```

设计要求：
- 色调：米灰 #D4C5B0、原木 #8B7355
- 墙面：微水泥，哑光质感
- 床：地台设计，低矮框架
- 床头：藤编/木制，简约造型
- 床品：亚麻材质，低饱和度
- 灯光：散射光，床头壁灯

设计要求：
- 色调：米白、焦糖色、金色点缀
- 地面：人字拼木地板或仿古地砖
- 门：拱形门洞、法式双开门
- 家具：大理石台面、黄铜把手

- 装饰：艺术画框、复古镜子、雕花线板
- 窗帘：纱帘+绒布，绑带设计
```

### 2. 实景照片改造

**操作流程**：
```
第一步：上传房间现状照片
- 尽量选择正面、清晰的照片
- 包含完整空间结构
- 光线尽量均匀

第二步：描述改造目标
- 保留哪些部分
- 改造哪些部分
- 目标风格

第三步：生成设计方案
- 可生成多个方案对比
- 支持局部调整
```

**提示词模板**：
```
将此客厅照片改造为奶油风格

保留：空间结构、大窗户位置
改造：
- 沙发换成羊羔绒浅米色款
- 添加拱形装饰元素
- 墙面换成奶油色
- 地面保留木地板
- 添加藤编收纳、绿植

整体氛围：温馨、治愈、适合拍照
```

### 3. 局部编辑功能

**使用场景**：
- 只换沙发不换其他
- 只改墙面颜色
- 只想换窗帘/地毯
- 细节微调

**操作方法**：
```
1. 选择"局部编辑"模式
2. 用画笔涂抹要修改的区域
3. 输入该区域的修改要求
4. 生成并对比效果
```

**局部编辑提示词示例**：
```
局部1（沙发区域）：
将沙发换成焦糖色丝绒材质复古款

局部2（墙面区域）：
将背景墙换成抹茶绿色，搭配装饰画

局部3（地毯区域）：
添加奶油色圆形地毯，毛绒材质
```

### 4. 多图联动

**功能说明**：
可以加载多个参考图，让 AI 综合多个图的特点生成新图。

**使用场景**：
- 参考多个案例的精华
- 融合不同风格的元素
- 保持系列设计的一致性

**操作方法**：
```
1. 上传主参考图（你想要的空间结构）
2. 上传风格参考图（你想要的风格）
3. 上传材质参考图（你想要的材质）
4. 输入融合要求
5. 生成综合效果图
```

### 5. 连续迭代编辑

**核心优势**：
生成结果不满意可以直接在原图上继续编辑，不用重新开始。

**工作流**：
```
初稿生成 → 局部调整 → 效果优化 → 细节深化 → 最终导出
    ↓            ↓           ↓           ↓
  第1次生成    第2次生成    第3次生成    第4次生成
```

## 三、进阶使用技巧

### 1. 提示词优化

**结构化提示词公式**：
```
[空间]+[风格]+[核心元素]+[材质]+[色彩]+[光线]+[氛围]+[细节]

示例：
"现代奶油风格客厅，白色羊羔绒L型沙发，
原木色茶几和电视柜，圆弧形拱门设计，
人字拼木地板，米白色墙面，
落地窗引入自然光，午后暖阳氛围，
抱枕、地毯、绿植点缀，4K高清效果图"
```

**效果提升技巧**：
| 技巧 | 示例 | 效果 |
|------|------|------|
| 具体材质 | 羊羔绒沙发 | 比"软沙发"更准确 |
| 具体色彩 | #FFF8E7奶油白 | 避免偏色 |
| 光线描述 | 午后暖阳、柔和阴影 | 光感更自然 |
| 氛围词汇 | 温馨治愈 | 整体调性统一 |
| 细节补充 | 抱枕、地毯、绿植 | 画面更丰富 |

### 2. 风格混搭技巧

**奶油风 + 法式复古**：
```
将此平面图设计为奶油法式风格

融合要点：
- 奶油色调（主色）
- 法式元素（拱形门洞、鱼骨拼）
- 现代舒适感（羊羔绒、大沙发）
- 复古点缀（黄铜、金色）

材质搭配：
- 丝绒+羊羔绒
- 大理石+原木
- 金属+藤编
```

**侘寂 + 日式**：
```
将此空间设计为侘寂日式风格

融合要点：
- 侘寂的留白+日式的精致
- 微水泥+天然木材
- 低饱和度配色
- 自然材质回归

具体元素：
- 榻榻米地台
- 障子门/推拉门
- 枯山水装饰
- 竹/藤/木制品
```

### 3. 常见问题解决

**问题1：生成效果偏离预期**
解决：
- 更具体地描述每个元素
- 提供参考图
- 分步骤生成（先生成基础再局部调整）

**问题2：空间结构变形**
解决：
- 上传更高质量的原始图
- 减少一次性修改的元素
- 使用"保留原结构"提示词

**问题3：风格不够纯粹**
解决：
- 在提示词中强调核心风格元素
- 提供该风格的参考图
- 使用风格关键词（如"法式"而非"浪漫法国风"）

## 五、应用场景实战

### 场景1：客户方案汇报

**需求**：100㎡三居室，现代简约风格

**操作步骤**：
```
1. 绘制简单平面图（或用 CAD 导出）
2. 上传 NANOBANANA，选择"客厅"
3. 输入提示词：
   "现代简约风格客厅，白色为主，
   灰色布艺沙发，木质家具，
   落地窗，大叶绿植点缀，
   极简吊灯，无主灯设计，4K"
4. 同样方式生成卧室、厨房、卫生间
5. 组合排版制作方案册
```

**耗时**：约 30 分钟（4 个空间）

### 场景2：竞品分析

**需求**：分析当下最流行的奶油风元素

**操作步骤**：
```
1. 收集 5-10 张优质奶油风案例图
2. 上传 NANOBANANA 作为参考
3. 输入提示词：
   "分析这些案例的共同元素：
   - 沙发材质/颜色
   - 地面材质/颜色
   - 墙面处理方式
   - 装饰元素
   - 色彩比例"
4. 生成融合这些元素的新方案
```

### 场景3：小红书爆款内容

**需求**：制作"装修前后对比"爆款内容

**操作步骤**：
```
1. 上传毛坯/旧房照片
2. 输入目标风格提示词
3. 生成效果图
4. 用 Canva 制作对比图
5. 用剪映制作视频
6. ChatGPT 写种草文案
```

**文案提示词**：
```
为以下装修前后对比图写小红书种草文案：

风格：[具体风格]
面积：[X]㎡
亮点：[1-3个核心卖点]

要求：
- 300-500字
- 生活化、有代入感
- 包含热门话题标签
- 首图15字内吸引标题
```
