# 室内设计一人公司AI工作室

## 核心定位

专为室内设计培训师、独立设计师、设计工作室主理人打造的AI团队工作流。实现单人+AI团队即可完成传统团队的全流程工作。

## AI团队架构

### 1. 灵感记录员 (Research Agent)
**职能**：自动归档碎片化灵感，构建专属设计知识库
**工具**：Notion、Obsidian、AI知识图谱工具
**输出**：
- 风格素材库（奶油风、法式复古、侘寂等）
- 材质灵感库（木质、金属、织物、石材）
- 配色方案库（潘通色、情绪板）
- 案例拆解库（优秀设计案例分析）

**提示模板**：
```
帮我整理以下灵感素材，建立分类标签体系：
[粘贴灵感内容]
标签维度：风格/材质/配色/空间/情绪
```

### 2. 市场分析师 (Trend Analyst Agent)
**职能**：实时抓取行业趋势，解析用户偏好与市场痛点
**数据源**：小红书、抖音、Pinterest、行业报告平台
**输出**：
- 2026年流行趋势报告（温感极简、奶油风、自然主义等）
- 用户需求变化追踪（从"拍照好看"到"居住舒适"）
- 竞品分析报告
- 热门设计方案拆解

**提示模板**：
```
分析[具体风格]在当下的市场热度、用户反馈、优劣势：
- 搜索近30天相关内容热度
- 提取用户核心诉求关键词
- 对比同类风格的差异化特点
```

### 3. 文案生成器 (Copywriter Agent)
**职能**：批量产出爆款内容，支持多种风格
**支持类型**：
- 悬念式脚本（吸引点击）
- 干货式内容（建立专业形象）
- 宋代美学内容拆解
- 营销话术模板
- 客户沟通文案

**提示模板**：
```
为[设计方案/风格]创作小红书文案，要求：
- 字数：300-500字
- 风格：[悬念式/干货式/故事型]
- 包含热门话题标签
- 首图文案建议
```

### 4. 视觉生产组 (Visual Production Team)
#### 4.1 效果图生成（核心工具：NANOBANANA）
**职能**：根据文字描述或平面图生成专业级效果图
**核心工具**：NANOBANANA（必选）

**NANOBANANA 核心功能**：
- 手绘平面图转4K 3D渲染图（准确率90%+）
- 照片生图：上传现有房间照片生成设计方案
- 局部编辑：只改选定区域，保留其他部分不变
- 多图联动：加载多个参考图作为生成依据
- 连续编辑：生成结果可直接在原图上继续迭代
- 一键换家具/材质/软装

**使用入口**：
- 免费版：nanobanana.io
- Pro版：nanobanana.art（支持更高分辨率）
- 国内镜像：katuai.cn

**NANOBANANA 生图流程**：
```
第一步：上传图片/草图
↓
选择模式：
- [平面图模式] 上传CAD图纸/手绘草图
- [实景模式] 上传房间现状照片
- [风格模式] 纯文字描述生成
↓
输入提示词（越具体效果越好）
↓
生成4K效果图（1-3分钟）
↓
局部调整/换风格/换家具
↓
导出最终效果图
```

**NANOBANANA 提示词模板**：

奶油风客厅：
```
将此平面图/照片转化为奶油风格室内设计
- 主色调：奶油白、燕麦色
- 沙发：羊羔绒材质，浅米色
- 地面：木地板，暖调
- 装饰：拱形元素、棉麻抱枕

```

```
- 装饰：艺术画框、复古镜子
- 线条：拱形门洞、鱼骨拼地板
- 氛围：优雅但温馨
```

#### 4.2 动态演示生成
**职能**：自动生成硬装到软装的生长动画
**工具**：Runway Gen-4.5、Kling、可灵AI
**输出**：
- 空间演变动画
- 硬软装对比视频
- 材质细节展示
- 360度全景漫游

### 5. 短视频导演 (Video Director Agent)
**职能**：智能生成带专业运镜的营销视频
**工作流程**：
1. 脚本解析 → 2. 分镜设计 → 3. 运镜规划 → 4. 素材生成 → 5. 剪辑合成
**输出**：
- 装修前后对比视频
- 设计方案展示片
- 软装搭配教程
- 品牌故事短片

**提示模板**：
```
为[设计方案]创作15秒营销视频：
- 核心卖点：[1-3个亮点]
- 目标受众：[年龄段/职业]
- 视频风格：[高端感/温馨感/科技感]
- 运镜要求：[推拉摇移跟升降]
```

## 工作流模板

### 场景：完成一套设计方案的全流程

```
阶段1：灵感收集（10分钟）
↓
[灵感记录员] → 整理风格参考、材质库、配色方案

阶段2：市场分析（5分钟）
↓
[市场分析师] → 确认当前流行趋势、竞品对比

阶段3：方案设计（15分钟）
↓
[视觉生产组-效果图] → 生成3套以上效果图

阶段4：内容创作（10分钟）
↓
[文案生成器] → 产出小红书文案、朋友圈素材

阶段5：视频制作（15分钟）
↓
[短视频导演] → 生成前后对比视频、方案展示片
```

**总耗时：约55分钟完成传统团队1-2周的工作量**

## 场景化应用

### 场景1：客户需求分析
**输入**：客户描述"想要温馨的家，有小朋友，需要收纳强"
**AI处理**：
1. [市场分析师] → 提取同类需求的热门方案
2. [灵感记录员] → 匹配相似案例库
3. [文案生成器] → 生成需求确认清单
**输出**：需求分析报告+初步方案建议

### 场景2：设计方案产出
**输入**：风格定位"奶油风混搭法式复古"
**AI处理**：
1. [灵感记录员] → 调取风格素材库
2. [视觉生产组] → 生成效果图+材质板
3. [市场分析师] → 验证该风格的市场接受度
**输出**：完整设计方案+效果图套图

### 场景3：营销素材批量生产
**输入**：完成10套设计方案
**AI处理**：
1. [文案生成器] → 批量产出种草文案
2. [视觉生产组] → 生成对比图、细节图
3. [短视频导演] → 批量生成展示视频
**输出**：1个月的社交媒体内容素材

## 质量控制

### AI输出审核清单
- [ ] 效果图：风格一致性、空间比例合理、光线自然
- [ ] 文案：品牌调性匹配、无夸大宣传、数据准确
- [ ] 视频：运镜流畅、转场自然、节奏适当
- [ ] 数据分析：来源可靠、时效性在90天内

### 迭代优化机制
1. 建立反馈循环：客户/学员反馈 → 提示词优化
2. 素材库更新：每月更新趋势热点库
3. 工具升级：跟踪AI工具最新能力
