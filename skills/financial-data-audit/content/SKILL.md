# 财务报表勾稽校验技能

> 协助用户对财务报表进行勾稽校验，支持资产负债表、利润表、现金流量表三大报表类型的表内校验，通过大模型自动解析报表数据并验证财务逻辑关系

## 功能概述

本技能调用大模型（DeepSeek-V3.1）实现财务报表的智能解析与勾稽校验：

1. **报表解析** - 自动识别Markdown格式的财务报表，提取标准财务科目和金额数据
2. **表内校验** - 验证报表内部各科目之间的勾稽关系是否成立
3. **结果汇总** - 输出详细的校验结果，包含通过/失败统计及差异分析

### 支持的校验规则

**资产负债表：**
- 资产合计 = 流动资产合计 + 非流动资产合计
- 负债合计 = 流动负债合计 + 非流动负债合计
- 资产合计 = 负债合计 + 所有者权益合计

**利润表：**
- 利润总额 = 营业利润 + 营业外收入 - 营业外支出
- 净利润 = 利润总额 - 所得税费用

**现金流量表：**
- 现金及现金等价物净增加额 = 经营活动现金流量净额 + 投资活动现金流量净额 + 筹资活动现金流量净额

## 执行流程

### 第一步：接收报表数据

**任务：** 获取用户提供的Markdown格式财务报表

**执行流程：**

1. 接收用户的财务报表内容（Markdown字符串格式）
2. 解析输入参数，提取 report_content 和 tolerance（可选）
3. 校验报表内容是否有效（非空）

### 第二步：调用大模型标准化数据

**任务：** 将Markdown格式的财务报表转换为结构化数据

**执行流程：**

1. 调用 `call_llm_standardize_data` 方法
2. 大模型自动识别报表类型（资产负债表/利润表/现金流量表）
3. 同一类型多张表按顺序编号（如资产负债表1、资产负债表2）
4. 将财务科目标准化为标准科目名称
5. 整合所有金额列数据

**标准财务科目：**
- 资产负债表：资产合计、流动资产合计、非流动资产合计、负债合计、流动负债合计、非流动负债合计、股东权益合计、所有者权益合计、货币资金、未分配利润
- 利润表：营业收入、营业成本、营业利润、营业外收入、营业外支出、利润总额、所得税费用、净利润总额
- 现金流量表：经营活动现金流量净额、投资活动现金流量净额、筹资活动现金流量净额、现金及现金等价物净增加额

### 第三步：执行勾稽校验

**任务：** 验证报表内部的勾稽关系

**执行流程：**

1. 调用 `execute_dynamic_check` 方法
2. 对每张报表的每个金额列分别执行校验
3. 按照预设规则计算期望值
4. 比对实际值与计算值
5. 根据容差判断是否通过

### 第四步：返回校验结果

**任务：** 输出完整的校验报告

**执行流程：**

1. 汇总所有校验结果
2. 统计总校验条数、通过数、失败数
3. 按报表维度细分统计
4. 返回结构化的JSON结果

## 注意事项

1. **执行耗时** - 大模型调用通常需要2-4分钟，与输入文本长度相关
2. **数据格式** - 输入必须是Markdown格式的表格，表格需包含明确的金额列
3. **容差设置** - 默认容差为0.001，可根据实际需求调整
4. **校验范围** - 目前仅支持表内校验，不支持表间校验
5. **金额处理** - 所有金额转为浮点型并保留2位小数，空值填0.0
