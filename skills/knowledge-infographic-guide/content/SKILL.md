## 二、标准内容结构（六大模块）

### 模块0：术语预热区（Term Preview）⭐ 新增

**目的**：在正式内容前，消除专业术语障碍，让零基础读者做好理解准备。

**底色**：浅蓝/浅灰渐变背景

**内容格式**：
```
┌─────────────────────────────────┐
│  📖 课前术语卡                   │
├─────────────────────────────────┤
│  • 术语A = 用普通人能理解的类比   │
│  • 术语B = 一句话通俗定义         │
│  • 术语C = 生活化比喻            │
└─────────────────────────────────┘
```

**设计要求**：
- 放在标题区下方、核心概念区上方
- 最多展示3-5个核心术语
- 使用「术语 = 通俗解释」格式
- 可用图标增强可读性

**示例**：
```
「复利效应」= 像滚雪球，越滚越大
「认知偏差」= 大脑自动走的"捷径"，容易出错
「第一性原理」= 回到最底层重新思考
```

**内容结构**（三层递进）：
```

│  💡 核心洞见                                │

│  【一句话总结】(16字以内，零基础也能懂)      │
│                                            │
│  【通俗解读】                               │
│  用日常生活中的例子解释核心观点              │
│                                            │

```

**零基础设计要点**：
- 一句话总结：用「XX就是YY」句式，避免专业术语
- 通俗解读：必须有生活类比或具体场景
- 关键结论：用数字编号，方便记忆

**布局**：左右对称，色彩区分

**左侧（蓝色系）**：基础概念/原因

**右侧（红色系）**：应用/结果

**每张卡片的标准格式**（⭐ 核心新增）：
```
┌────────────────────────────────────────────┐
│  概念名称                                   │
├────────────────────────────────────────────┤
│  【是什么】专业定义（简短）                  │
│                                            │
│  【通俗解释】← ⭐ 零基础关键                 │
│  用非专业人也能理解的话重新说一遍            │
│                                            │
│  【生活案例】← ⭐ 零基础关键                 │
│  一个具体的、熟悉场景中的例子                │

```

**设计要点**：
- 「是什么」：一句话定义，不超过两行
- 「通俗解释」：必须用「就像...」「相当于...」句式
- 「生活案例」：必须是普通人日常能接触到的场景
- 虚线箭头指向中央汇聚点

## 三、内容提炼框架（含零基础增强）

### 步骤1：识别核心主题
- 找出文章/文档的核心论点
- 提炼**16字以内**的一句话概括
- 确保这句话**不带专业术语**

### 步骤2：分解为三大维度

| 维度 | 核心问题 | 输出要求 |
|------|---------|---------|
| **What（是什么）** | 这个概念的基本定义 | 一句话通俗定义，无术语 |
| **Why（为什么）** | 为什么会这样/起作用 | 列出机制，加入通俗类比 |
| **How（怎么办）** | 普通人能怎么用 | 具体可操作步骤 |

### 步骤3：提取关键元素（重点增强）

**每个维度下提取3-5个要点，并完成以下工作**：

```
原内容要点 → 通俗化处理清单：
□ 识别专业术语
□ 为每个术语写「一句话通俗定义」
□ 找一个生活化的比喻/类比
□ 找一个具体的现实案例
□ 确认非专业读者能完全理解
```

**术语处理优先级**：
1. **消除**：能不用就不用的专业术语
2. **替换**：用通俗词替代，如「认知偏差」→「思维误区」
3. **解释**：必须用的术语，后面必须跟通俗解释

### 步骤4：设计逻辑链条

**建立从概念→机制→应用的完整逻辑链**：

```
术语预热 → 核心观点 → 基础理解 → 深入机制 →
实际应用 → 行动策略 → 收束记忆
```

**确保每个环节**：
- 无内容重复
- 每块信息独立完整
- 零基础读者顺畅理解（无断层）

## 七、成功要素与避坑指南

### ✅ 确保成功的关键要素

1. **简化Prompt结构**：每个内容只描述一次，避免AI重复生成
2. **保持视觉一致性**：深墨绿背景 + 金色强调是经过验证的黄金组合
3. **内容结构准确**：每个讲次/主题内容要独立，不混淆
4. **数据可视化**：具体数字用饼图/柱状图呈现，增强说服力
5. **金句收尾**：底部卷轴/引用框风格增强仪式感
6. **⭐ 术语预热优先**：在核心概念前先消除术语障碍

### ❌ 必须避免的错误

1. **内容混淆**：不要把其他讲次的内容放进来
2. **重复内容**：每个案例/观点只出现一次
3. **过度描述**：Prompt越简洁，生成效果越精准
4. **过度迭代**：第一版简洁Prompt往往效果最好
5. **⭐ 隐含假设**：不要假设读者学过原课程，每处专业内容都要解释

### ❌ 零基础可理解性常见错误

| 错误类型 | 错误示例 | 正确做法 |
|---------|---------|---------|
| 术语无解释 | 直接写「认知偏差」 | 「认知偏差（思维误区）：大脑自动走的捷径」 |
| 缺乏类比 | 「复利效应显著」 | 「复利效应：像滚雪球，越滚越大」 |
| 案例太专业 | 「用于量化投资」 | 「用于日常生活：存钱、健身、学习」 |
| 隐含前提 | 「这是第3讲的内容」 | 「这个概念将在后面详细解释」 |
| 跳过基础 | 直接讲高级应用 | 必须从零基础开始铺垫 |

## 八、万维钢系列标准结构（可直接套用）

```
1. 核心观点卡片（核心Slogan）
   └─ 一句话总结 + 通俗解读 + 生活类比

2. 分类/分级展示（2×3网格或阶梯式）
   └─ 每个条目包含：定义 + 通俗解释 + 案例

3. 现实vs想象对比（左右布局）
   └─ 左：理论/原因（含通俗解释）
   └─ 右：实践/结果（含适用场景）

4. 具体案例（数据可视化）
   └─ 图表 + 数字 + 普通人能理解的解读

5. 行动策略/四大约束总结
   └─ 每个策略：做法 + 为什么有效 + 适用场景

6. ⭐ 术语预热区（新增必选项）
   └─ 3-5个核心术语的通俗解释
```
