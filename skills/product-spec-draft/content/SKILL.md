# 产品文档 Skill

## 何时使用

PRD、功能说明书、用户手册章节、发版说明、需求评审材料。

## PRD 默认结构

```markdown
# [功能名] PRD

## 1. 背景与目标
## 2. 用户与场景
## 3. 用户故事（As a / I want / So that）
## 4. 功能范围
### 4.1 在范围内
### 4.2 不在范围内
## 5. 交互与规则
## 6. 验收标准（Given/When/Then）
## 7. 非功能需求（性能、安全、兼容）
## 8. 依赖与风险
## 9. 里程碑
## 10. 待确认项（必须列出）
```

## 产品说明书结构

```markdown
# [产品名] 使用说明

## 概述
## 角色与权限
## 功能模块（按菜单）
### 模块名
- 操作步骤 1…n
- 常见问题
## 术语表
## 修订记录
```

## 规则

- 无输入数据处标 **【待填】**，禁止编造指标
- 对外承诺、价格、法务表述标 **【需法务/产品确认】**
- 与研发术语一致（接口名、状态枚举与仓库一致时可读代码核对）
- 中文为主，专有名词保留英文

## Release Notes

- 面向客户/实施，无内部 Jira 号堆砌
- 分：新功能 / 改进 / 修复 / 已知问题
