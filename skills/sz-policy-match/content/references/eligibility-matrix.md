# 企业资质-政策匹配评分矩阵

> 本文件用于评估企业特定条件下适合申报哪些政策项目。按企业画像快速判断优先级。

---

## 评分维度

评分围绕4个核心维度展开，满分10分，≥7分可视为高优先级匹配：

| 维度 | 权重 | 说明 |
|------|------|------|
| 硬性条件满足率 | 40% | 政策申报门槛的核心指标 |
| 行业契合度 | 25% | 企业所在行业与政策支持方向匹配程度 |
| 资金/资源杠杆 | 25% | 政策可带来的实际价值（金额、税收优惠等） |
| 申报可行性 | 10% | 时间窗口、材料准备难度、通过概率 |

## 常见企业画像 → 推荐政策路线

### 画像A：初创型科技企业（成立 < 3年，营收 < 1000万）

**特征**：研发驱动，但营收和资质积累不足
**推荐政策优先级**：

| 优先级 | 政策项目 | 匹配原因 |
|--------|---------|---------|
| P0 | 深圳市科技型中小企业评价 | 入门级，门槛低，是申报其他科技政策的前提条件 |
| P0 | 区级研发补贴 | 部分区有研发投入事后补贴，覆盖面广 |
| P1 | 广东省科技专项资金（创业项目） | 有创业类专项支持 |
| P1 | 国家高新技术企业认定（培育入库） | 先入库再认定，各省市有入库补贴 |
| P2 | 技术合同登记税收优惠 | 可叠加其他政策一起使用 |

**注意**：初创企业应优先完成"科技型中小企业评价"入库，积累资质是后续申报高金额项目的基础。

---

### 画像B：成长型制造业企业（成立3-10年，营收1000万-2亿）

**特征**：已过生存期，有一定营收基础，有技术改造和扩产需求
**推荐政策优先级**：

| 优先级 | 政策项目 | 匹配原因 |
|--------|---------|---------|
| P0 | 广东省/深圳市技术改造专项资金 | 金额大，门槛相对不高，制造业核心补贴 |
| P0 | 国家高新技术企业认定 | 15%税率优惠 + 各区现金奖励 |
| P1 | 深圳市数字化转型扶持 | 工业互联网、数字化改造专项 |
| P1 | 省级专精特新中小企业认定 | 衔接国家级专精特新的跳板 |
| P2 | 区级技术中心/工程中心认定 | 长期竞争力建设 |

---

### 画像C：成熟型专精特新企业（成立5年以上，营收1亿+，有专利储备）

**特征**：资质完善，目标冲击国家级认定和更大额度补贴
**推荐政策优先级**：

| 优先级 | 政策项目 | 匹配原因 |
|--------|---------|---------|
| P0 | 国家级专精特新"小巨人"认定 | 最高荣誉，配套最丰厚，各区最高200万奖励 |
| P0 | 国家高新技术企业认定（复审） | 保住资质，避免断档 |
| P1 | 国家企业技术中心认定 | 行业标杆认证，申报门槛高但奖励丰厚 |
| P1 | 省级/市级工程技术研究中心 | 研发平台认定 |
| P2 | 国家重点研发计划（行业细分项目） | 金额大但竞争激烈，适合有深厚积累的企业 |

---

### 画像D：现代服务业企业（软件信息、金融科技、咨询等）

**特征**：轻资产，人才密集，研发费用占比高
**推荐政策优先级**：

| 优先级 | 政策项目 | 匹配原因 |
|--------|---------|---------|
| P0 | 国家高新技术企业认定 | 软件企业15%税率优惠核心路径 |
| P0 | 深圳市软件产业高质量发展专项 | 软件企业专属补贴 |
| P1 | 广东省数字经济专项资金 | 大数据、云计算、人工智能方向 |
| P1 | 深圳市技术攻关（软件类） | 核心技术攻关 |
| P2 | 软件著作权/专利申请资助 | 部分区有资助 |

## 硬性条件快速对照表

### 营收门槛

| 政策项目 | 营收门槛 |
|---------|---------|
| 国家高新企业认定 | 无硬性营收门槛，但研发占比和知识产权是门槛 |
| 国家级专精特新"小巨人" | 上年度营收≥1亿元 |
| 省级专精特新 | 上年度营收≥1000万元 |
| 深圳市技术改造 | 无营收门槛，但投资额门槛（设备≥500万） |
| 国家企业技术中心 | 年营收≥2亿元 |

### 注册时间

| 政策项目 | 注册时间要求 |
|---------|------------|
| 国家高新企业认定 | 注册满1年的居民企业 |
| 国家级专精特新"小巨人" | 无明确年限，但经营数据要求较高 |
| 科技型中小企业评价 | 无年限要求 |
| 深圳市科技计划项目 | 深圳市注册即可 |

### 研发费用

| 政策项目 | 研发费用要求 |
|---------|-----------|
| 国家高新企业认定 | 研发占比：<5000万≥5%，5000万-2亿≥4%，>2亿≥3% |
| 国家级专精特新"小巨人" | 研发占比≥3% |
| 省级专精特新 | 研发占比≥3% |
| 深圳市技术攻关 | 需单独建账，无固定比例要求 |

## 申报时间窗口规划建议

| 季度 | 重点申报项目 |
|------|------------|
| Q1（1-3月） | 国家高新认定第一批、市级科技计划项目（全年第一批） |
| Q2（4-6月） | 国家高新认定第二批、省级专精特新、国家重点研发计划 |
| Q3（7-9月） | 市级技术改造（事后申报）、国家高新第三批、省级工程中心 |
| Q4（10-12月） | 区级专项资金集中发布、次年项目储备规划 |

## 评分计算示例

**示例企业**：深圳某AI创业公司，2023年成立，150人规模，年营收约3000万元，已拥有3项发明专利、10项软件著作权，研发投入占比约40%，已认定为科技型中小企业。

**匹配分析**：
- 国家高新技术企业认定：匹配度★★★☆☆（注册时间满1年，研发占比高，但知识产权积累偏少，建议加强知识产权布局后再申报）
- 深圳市技术攻关（人工智能方向）：匹配度★★☆☆☆（公司规模偏小，建议待营收过亿后再申报）
- 区级研发费用补贴：匹配度★★★★☆（研发投入高，最容易拿到）
