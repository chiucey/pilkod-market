# 深圳政策库匹配 Skill（含申报历史追踪）

## 核心功能

1. **已申报项目整理** — 整理企业历年已成功申报/获批的政府扶持项目（含级别/年份/金额/状态）
2. **潜力项目匹配** — 基于企业画像，推荐最值得申报的政策项目

## 企业信息收集

激活后，先向用户收集以下信息（如已有则跳过）：

| 字段 | 重要性 | 说明 |
|------|--------|------|
| 企业全称 | 必填 | 用于查资质和历史申报 |
| 所在行业 | 必填 | 互联网/制造/生物医药/新能源等 |
| 注册时间 | 必填 | 决定是否有资格报新认定类项目 |
| 员工人数 | 必填 | 判断规模及社保缴纳资格 |
| 年营收（万元） | 推荐 | 判断规模档次 |
| 纳税额（万元） | 推荐 | 部分项目要求 |
| 是否有 R&D 投入 | 推荐 | 研发类补贴必要条件 |
| 知识产权情况 | 推荐 | 专利、软件著作权、商标等 |
| 现有资质 | 推荐 | 高新企业、专精特新等 |
| 希望申报的级别 | 可选 | 区级/市级/省级/国家级 |

> 用自然语言提问，不需要列表清单式追问，一次问完再开始匹配。

## 完整分析流程

### 第 0 步：调查企业历史申报记录（新增）

使用 `batch_web_search` 搜索以下维度，整理企业历年申报情况：

**搜索策略：**
- `"[企业全称] + 高新技术企业 + [年份]"`
- `"[企业全称] + 专项资金 + 公示"`
- `"[企业全称] + 扶持资金 + 资助名单"`
- `"[企业全称] + 专精特新 + 认定"`
- `"[企业全称] + 研发投入补贴 + 公示"`

**信息提取：**
对每个搜索结果，用 `extract_content_from_websites` 抓取相关页面，整理出：

```
【企业历史申报记录】
| 序号 | 申报项目名称 | 申报级别 | 申报年份 | 资助金额（万元）| 当前状态 | 信息来源 |
|------|------------|---------|---------|--------------|---------|---------|
| 1 | 南山区企业研发投入补贴 | 区级 | 2025 | 40 | 已公示 | [URL] |
| 2 | 国家高新技术企业认定 | 国家级 | 2023 | 减税优惠 | 有效期内 | [URL] |
```

**状态字段说明：**
- `已公示` — 已在官方名单中公示，等待拨款
- `已拨款` — 资金已到账
- `有效期内` — 资质认定类项目（如高新企业）在证书有效期内
- `已到期` — 资质或资助已过期
- `复审中` — 正在申请复审或续期

---

### 第 1 步：搜索最新政策库

使用 `batch_web_search` 搜索以下维度（每次匹配至少搜索 3 个层面）：

**区级** — 搜索 "深圳 + [区名，如南山/福田/宝安] + 扶持资金 + [行业] + 2025 2026"
**市级** — 搜索 "深圳市 + [行业] + 补贴 + 扶持 + 2025 2026"
**省级** — 搜索 "广东省 + [行业] + 专项资金 + 2025 2026"
**国家级** — 搜索 "[行业] + 国家补贴 + 专项资金 + 2025 2026 + site:gov.cn"

### 第 2 步：打开重点政策页面

用 `extract_content_from_websites` 抓取搜索结果中的关键政策页面，提取：
- 申报条件（硬性指标）
- 资助金额
- 申报截止时间
- 主管部门

### 第 3 步：生成完整报告

**分两部分输出：**

#### Part A：企业历史申报记录

```
## 📋 企业历史申报记录

| 申报项目 | 级别 | 年份 | 资助金额 | 状态 | 备注 |
|--------|------|------|---------|------|------|
| （整理表格）| | | | | |

**历史申报总结：**
- 累计获批项目数：X个
- 累计获批资助总额：约X万元
- 资质认定类：XXXX（在有效期内/已到期）
- 最近申报年份：XXXX年
```

#### Part B：潜力项目匹配

```
## 🏆 潜力项目推荐

（按 P0/P1/P2 优先级排列，格式同原匹配报告）
```

### 第 4 步：推荐最优先的 1-2 个项目

给出具体申报建议，说明理由。

## 输出格式要求

- **清晰二分结构**：历史记录在前，潜力推荐在后
- 清晰分级（国家 → 省 → 市 → 区）
- 每个推荐项目注明匹配度（★级）
- 标注申报截止日期（醒目提示即将截止的项目）
- 附上信息来源 URL

## 注意事项

- 优先使用最新年度政策（2025/2026年度）
- 注意分辨"事后补贴"和"事前补贴"
- 创业企业重点关注研发费用加计扣除、科技型中小企业评价等
- 制造业企业关注技术改造、数字化转型、绿色制造等方向
- 如企业信息不足，优先匹配硬性条件（注册时间、规模等）已满足的项目
- 高新企业证书有效期3年，务必标注到期年份，提醒用户及时复审
