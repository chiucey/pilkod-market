# A股均线趋势量化分析

## 功能说明

本技能通过新浪财经API获取真实K线数据，计算MA5/MA10/MA20/MA60均线，判断股票趋势并给出操作建议。

## 触发方式

用户输入6位A股股票代码，附加任意说明文字：

- `600036 趋势判断`
- `000001 均线分析`
- `300750 买入建议`
- `贵州茅台 600519 走势`

## 技术实现

### 数据来源
- **实时行情**: 新浪财经hq.sinajs.cn API
- **历史K线**: 新浪财经quotes.sina.cn API
- **均线计算**: API预计算MA5/MA10/MA30 + 本地计算MA20/MA60

### 均线系统
| 均线 | 周期 | 用途 |
|------|------|------|
| MA5 | 5日 | 短期趋势、短线操作参考 |
| MA10 | 10日 | 短期偏中期趋势 |
| MA20 | 20日 | 中期趋势、月线 |
| MA60 | 60日 | 长期趋势、季线 |

### 趋势判断逻辑

**多头排列（上升趋势）**
- 完整多头: 价格 > MA5 > MA10 > MA20 > MA60
- 中期多头: 价格 > MA5 > MA10 > MA20
- 短期反弹: 价格 > MA5 > MA10

**空头排列（下降趋势）**
- 完整空头: 价格 < MA5 < MA10 < MA20 < MA60
- 中期空头: 价格 < MA5 < MA10 < MA20
- 短期回调: 价格 < MA5 < MA10

**震荡整理**
- 不满足上述条件时，根据价格在均线上下的数量判断偏强/偏弱/中性

### 操作策略

| 趋势 | 策略 | 风险 |
|------|------|------|
| 强势多头 | 持股待涨 | 低 |
| 中期多头 | 逢低做多 | 中低 |
| 短期反弹 | 谨慎追涨 | 中 |
| 完整空头 | 减仓观望 | 高 |
| 中期空头 | 逢高减仓 | 中高 |
| 短期回调 | 观望等待 | 中 |
| 震荡整理 | 高抛低吸 | 中 |

## 输出格式

```
【股票名称｜代码｜市场】

┌─ 实时行情 ─────────────────────────
│ 现价、涨跌、今开、昨收、最高、最低、成交量
└────────────────────────────────────

┌─ 均线系统 ─────────────────────────
│ MA5、MA10、MA20、MA60（数据更新日期）
└────────────────────────────────────

┌─ 趋势研判 ─────────────────────────
│ 趋势类型 + 趋势强度描述
└────────────────────────────────────

┌─ 操作建议 ─────────────────────────
│ 主策略 + 风险等级 + 具体建议
└────────────────────────────────────

⚠️ 免责声明
```

## 使用限制

1. 仅支持沪深A股（6位数代码）
2. 0/1/2/3开头自动识别为深市，其余为沪市
3. 需至少60个交易日数据才能计算MA60
4. 数据仅供参考，不构成投资建议
