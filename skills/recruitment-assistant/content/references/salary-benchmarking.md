# 薪酬体系设计参考

## 市场薪酬调研方法

### 数据来源

1. **公开数据**
   - 招聘网站薪资数据（BOSS直聘、智联、拉勾等）
   - 行业薪酬报告（美世、韦莱韬悦、怡安翰威特等）
   - 上市公司薪酬披露

2. **调研参与**
   - 行业HR协会调研
   - 同业对标小组
   - 猎头数据

### 薪酬分位值概念

| 分位值 | 含义 | 适用场景 |
|-------|------|---------|
| P25 | 25%分位，市场较低水平 | 控制成本导向 |
| P50 | 50%分位，市场中位值 | 市场通用策略 |
| P75 | 75%分位，市场较高水平 | 吸引优秀人才 |
| P90 | 90%分位，市场领先 | 关键稀缺人才 |

## 典型薪酬结构

### 互联网行业（研发岗）

```
年薪 = 月薪 × 12 + 年终奖 × (2-6个月) + 期权/股票

典型比例：
- 固定薪酬：浮动薪酬 = 70:30
- 现金：股权 = 80:20
```

### 传统行业（职能岗）

```
年薪 = 月薪 × 12 + 年终奖 × (1-3个月) + 福利补贴

典型比例：
- 固定薪酬：浮动薪酬 = 85:15
```

### 销售岗位

```
年薪 = 月薪 × 12 + 业绩提成 + 年终奖金

典型比例：
- 固定薪酬：浮动薪酬 = 40:60
```

## 非现金福利组合

### 基础福利包
- 五险一金/六险二金
- 带薪年假（10-20天）
- 法定节假日
- 年度体检

### 竞争力福利包
- 商业保险（补充医疗、重疾、意外）
- 弹性工作制
- 远程办公选项
- 培训发展预算

### 特色福利包
- 员工股票购买计划
- 住房/租房补贴
- 子女教育支持
- 心理咨询服务
- 健身/运动补贴

## 薪酬调整策略

### 年度调薪
| 绩效评级 | 调薪比例建议 |
|---------|------------|
| A（卓越） | 15-25% |
| B（优秀） | 8-15% |
| C（良好） | 3-8% |
| D（待改进） | 0-3% |
| E（不合格） | 0%或降薪 |

### 晋升调薪
- 建议晋升调薪幅度：15-30%
- 建议配合岗位调整进行
