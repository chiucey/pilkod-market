# Jaccard 相似度计算公式

## 公式

$$J(A, B) = \frac{|A \cap B|}{|A \cup B|}$$

其中：
- $A$ 和 $B$ 是两个集合（技能触发词集合）
- $|A \cap B|$ 是交集的元素数量
- $|A \cup B|$ 是并集的元素数量

## 取值范围

- $J(A, B) \in [0, 1]$
- $J = 0$: 两个集合完全不相交
- $J = 1$: 两个集合完全相同

## 示例计算

### 示例 1：高度相似

```
技能A触发词: ["诊断", "修复", "问题"]
技能B触发词: ["诊断", "修复", "优化"]

交集 = {"诊断", "修复"} = 2
并集 = {"诊断", "修复", "问题", "优化"} = 4

Jaccard = 2/4 = 0.5 (50%)
```

### 示例 2：完全相同

```
技能A触发词: ["诊断", "修复"]
技能B触发词: ["诊断", "修复"]

交集 = {"诊断", "修复"} = 2
并集 = {"诊断", "修复"} = 2

Jaccard = 2/2 = 1.0 (100%)
```

### 示例 3：完全不相交

```
技能A触发词: ["诊断", "修复"]
技能B触发词: ["优化", "重构"]

交集 = {} = 0
并集 = {"诊断", "修复", "优化", "重构"} = 4

Jaccard = 0/4 = 0.0 (0%)
```

## 融合决策阈值

| 相似度范围 | 决策 | 操作 |
|-----------|------|------|
| > 60% | 🚨 必须融合 | 立即执行 |
| 30% - 60% | ⚠️ 建议融合 | 询问用户 |
| < 30% | ✅ 不融合 | 保持现状 |
