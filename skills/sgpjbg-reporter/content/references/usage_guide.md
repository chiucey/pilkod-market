# 三个皮匠报告网站自动化 - 使用指南

## 概述

三个皮匠报告(sgpjbg.com.cn)是一个专业的行业研究报告分享下载平台，提供超过500万份研究报告，涵盖人工智能、金融、医疗、消费等20+行业领域。

## 网站功能

### 主要栏目

1. **行业深潜** - 深度行研、券商报告、会议资料
2. **全球视野** - 外文报告、美股财报、国际投行研究
3. **产业透视** - 数据图表、财报库、政策库
4. **自研报告** - 十五五规划、人工智能、高端制造等热点领域

### 登录方式

- 账号密码登录
- 手机快捷登录
- 微信扫码登录

### VIP会员体系

| 等级 | 权益 |
|------|------|
| 标准VIP | 基础下载额度 |
| 高级VIP | 更多下载次数 |

## 使用流程

### Step 1: 准备凭证

用户需要提供:
- 用户名/手机号
- 密码

### Step 2: 执行登录

使用 `interact_with_website` 工具执行登录流程:
1. 打开 https://www.sgpjbg.com/
2. 点击登录入口
3. 填写用户名密码
4. 确认登录

### Step 3: 搜索报告

在搜索框输入关键词，如:
- "人工智能行业报告"
- "新能源汽车2024"
- "医疗健康研报"

### Step 4: 浏览结果

搜索结果页面展示:
- 报告标题
- 来源机构
- 发布日期
- 页数/字数

### Step 5: 下载PDF

点击目标报告的下载按钮:
1. 进入报告详情页
2. 找到下载入口
3. 下载PDF文件
4. 保存到本地目录

### Step 6: 阅读内容

使用PDF提取工具:
- `extract_pdfs_key_info` - 提取关键信息
- `extract_pdfs_full_content` - 获取完整内容

## 常见问题

### Q: 登录失败怎么办？
A: 检查用户名密码是否正确，确认网络连接，尝试刷新页面后重新登录

### Q: 搜索没有结果？
A: 尝试简化关键词，或使用行业分类导航浏览

### Q: 下载失败？
A: 检查账户下载额度，尝试更换浏览器或清除缓存

### Q: PDF无法打开？
A: 确保PDF文件完整，尝试重新下载

## 技术实现

### 关键脚本

1. **reporter.py** - 核心自动化逻辑
2. **quick_validate.py** - 验证脚本

### 浏览器自动化

使用 `interact_with_website` 工具处理:
- 页面导航
- 表单填写

### 文件处理

下载的PDF保存到: `/downloads/sgpjbg-reports/`

文件名格式: `{报告标题}_{日期}.pdf`
