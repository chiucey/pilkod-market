# 三个皮匠报告自动化助手

自动化处理三个皮匠报告网站(sgpjbg.com.cn)的登录、搜索、下载和阅读流程。

## 核心能力

1. **网站登录** - 支持账号密码方式登录三个皮匠报告
2. **智能搜索** - 根据关键词搜索行业研究报告
3. **报告下载** - 选择性下载PDF格式的研究报告
4. **PDF阅读** - 提取并总结下载的PDF报告内容

## 工作流程

### 阶段1: 凭证收集与登录

1. **获取用户凭证**
   - 如果未提供用户名和密码，使用 GenUI 表单收集
   - 表单字段: 用户名(username)、密码(password)

2. **执行登录**
   - 访问 https://www.sgpjbg.com/
   - 定位登录入口并填写凭证
   - 点击登录按钮并等待页面跳转

### 阶段2: 搜索报告

1. **确定搜索关键词**
   - 如果用户已指定主题，直接使用
   - 如果未指定，询问用户想要搜索的行业/主题

2. **执行搜索**
   - 在搜索框中输入关键词
   - 点击搜索或按回车键
   - 等待搜索结果加载

### 阶段3: 浏览与选择

1. **展示搜索结果**
   - 显示报告标题、来源、日期等基本信息
   - 提供筛选选项(日期、来源、类型)

2. **收集用户选择**
   - 询问用户想要下载哪篇/哪些报告
   - 支持多选或指定数量(如"下载前3篇")

### 阶段4: 下载报告

1. **执行下载**
   - 点击目标报告的下载按钮
   - 等待PDF下载完成
   - 保存到 `/downloads/sgpjbg-reports/` 目录

2. **重命名文件**
   - 使用报告标题+日期作为文件名
   - 确保文件名为有效的文件系统路径

### 阶段5: 阅读PDF

1. **提取内容**
   - 使用 `extract_pdfs_key_info` 提取报告关键信息
   - 或使用 `extract_pdfs_full_content` 获取完整内容

2. **生成摘要**
   - 提供报告的核心观点、主要发现、结论摘要

## 使用示例

```
用户: 帮我登录三个皮匠，搜索"人工智能行业报告"，下载最新的5篇
助手: [启动sgpjbg-reporter技能]
     1. 收集登录凭证
     2. 执行登录
     3. 搜索"人工智能行业报告"
     4. 下载最新5篇PDF
     5. 阅读并总结内容
```

## 错误处理

- **登录失败**: 提示检查用户名密码，尝试重新登录
- **搜索无结果**: 建议更换关键词或扩大搜索范围
- **下载失败**: 重试或跳过该报告，继续处理其他报告
- **PDF损坏**: 标记并跳过，报告下载失败

## 依赖工具

- `interact_with_website`: 浏览器自动化(登录、搜索、下载)
- `extract_pdfs_key_info`: 提取PDF关键信息
- `extract_pdfs_full_content`: 提取PDF完整内容
- `download_file`: 下载文件到本地

## 输出格式

下载完成后，提供:
- 下载报告列表(文件名、路径、大小)
- 每篇报告的简短摘要(50字以内)
- 询问是否需要详细阅读某篇报告
