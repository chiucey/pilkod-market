# Python反混淆与逆向分析

## 核心能力

### 1. 混淆类型识别与应对

| 混淆类型 | 识别特征 | 反混淆方法 |
|---------|---------|-----------|
| **字符串加密** | 字符串常量被替换为函数调用或bytes | 动态执行trace或静态分析解密逻辑 |
| **变量名混淆** | 变量名为单字符或无意义字符 | 结合上下文和字节码分析语义 |
| **控制流扁平化** | 基本块被重构为switch结构 | 构建控制流图(CFG)还原跳转关系 |
| **死代码注入** | 包含永不到达的代码块 | 静态分析识别不可达代码 |
| **exec/eval加密** | 代码以字符串/字节形式存在 | 动态执行捕获或符号执行解密 |
| **PyArmor加密** | 特殊magic number和加密区块 | 使用pyarmor-decrypt或密钥提取 |
| **PyInstaller打包** | exe内部包含PYZ加密资源 | pyinstxtractor提取后反编译 |
| **Hyperion混淆** | 多层嵌套base64+marshal+zip | 逐层解包还原字节码 |

### 3. 常用工具脚本

#### 3.1 exec加密代码解码器
适用于处理以下模式：
- `exec(__import__('base64').b64decode(...))`
- `exec(__import__('marshal').loads(...))`
- `exec(__import__('zlib').decompress(...))`
- 多层嵌套的加密壳

#### 3.2 PyInstaller exe提取器
从PyInstaller打包的exe中提取pyc文件，支持：
- 单文件模式 (-Fw)
- 目录模式 (-D)
- 加密字节码检测

#### 3.3 字节码分析工具
- 使用 `dis` 模块进行字节码反汇编
- 构建控制流图
- 识别关键操作码模式

## 技能使用指南

### 触发场景
- 用户提供混淆的Python代码要求分析
- 需要从exe中还原Python源码
- 分析恶意软件或加密壳
- 破解商业软件的Python保护

### 执行步骤

1. **代码获取**
   - 直接提供源码/字节码
   - 提供PyInstaller打包的exe文件
   - 提供特定混淆模式的代码片段

2. **分析与处理**
   - 识别混淆类型
   - 调用对应脚本进行反混淆
   - 对于复杂混淆进行多轮处理

3. **结果输出**
   - 可读的Python源码
   - 字节码分析报告
   - 控制流图(如有需要)

### 注意事项
- 仅用于合法的逆向工程场景
- 遵守相关法律法规
- 尊重知识产权
