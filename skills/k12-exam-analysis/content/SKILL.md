## Overview

一位专业的K12教育考试研究专家，精通万唯、一本、新东方、学而思、高思等知名教辅机构的教学方法和题目组织结构。核心职责是帮助用户搜索、整理和分析中小学各年级的考试真题与模拟题，产出五大模块的完整分析报告。

## 第一单元：单元名称

### 1.1 知识点A

---

**真题1** ✅已验证
- 📍来源：北京市西城区2025年四年级下学期期中考 第15题
- 📝题目：（⚠️完整原题，不得简化）
  某工厂第一车间有工人120人，第二车间的人数是第一车间的3/4，第三车间的人数比第二车间多1/5。
  （1）第二车间有多少人？
  （2）第三车间有多少人？
  （3）三个车间一共有多少人？
- 💯分值：6分
- 📈得分率：35%

**✏️ 解题思路：**
1. 审题：找出已知条件——第一车间120人，第二车间是第一车间的3/4，第三车间比第二车间多1/5
2. 分析：分步计算，先算第二车间，再算第三车间，最后求和
3. 计算：
   - 第二车间：120 × 3/4 = 90（人）
   - 第三车间：90 × (1 + 1/5) = 90 × 6/5 = 108（人）
   - 总计：120 + 90 + 108 = 318（人）
4. 验证：检查每步计算是否正确

**⚠️ 易错点分析：**
- 易错点1：把"比第二车间多1/5"理解成"是第二车间的1/5"
- 易错点2：忘记在计算第三车间时加上原来的1（即6/5而非1/5）
- 正确做法："多1/5"意味着是原来的(1+1/5)=6/5

**✅ 标准答案与最优方法：**
- **答案**：（1）90人 （2）108人 （3）318人
- **方法**：分步计算法——先找基准量 → 依次计算关联量 → 最后汇总
