# Investor Decision Model Detailed Reference

This document provides detailed decision frameworks for 11 investors, for reference during independent analysis.

---

## Warren Buffett (Value Investing)

### Core Principles
- Invest in stable businesses within "circle of competence"
- Seek companies with wide economic moats
- Long-term holding focus, concerned about permanent loss risk

### Decision Variables
| Variable | Description | Ideal Value |
|----------|-------------|-------------|
| Moat | Brand, network effects, cost advantage, switching costs | Wide and durable |
| Management | Integrity, capability, capital allocation | Excellent |
| ROIC | Return on Invested Capital | >15% |
| Free Cash Flow | Operating CF - CapEx | Positive and stable |
| Valuation | Intrinsic value vs market price | Adequate margin of safety |

### Rejection Criteria
- Complex businesses outside circle of competence
- Highly cyclical industries (exceptions apply)
- Highly leveraged companies
- Competitive industries without moats

## 段永平 (Duan Yongping) (Value Investing / Entrepreneur Perspective)

### Core Principles
- Invest in simple, understandable businesses that generate long-term profits
- Emphasize "doing the right thing" vs frequent trading
- Conviction-based concentrated positions

### Decision Variables
| Variable | Description | Ideal Value |
|----------|-------------|-------------|
| Simplicity | Business model easy to understand | Simple |
| Sustained Profit | Long-term profitability | 5+ consecutive years |
| Management | Trustworthy, capable | Excellent |
| Conviction | Confidence in concentrated position | Can go all-in |

### Rejection Criteria
- Overly complex business
- Requires frequent trading to make money
- Untrustworthy management

## Jim Simons (Quantitative Investing)

### Core Principles
- Find quantifiable market inefficiencies
- Rely on statistical models and algorithms
- Short-to-medium term trading frequency

### Decision Variables
| Variable | Description | Ideal Value |
|----------|-------------|-------------|
| Signal Strength | Statistical significance | >2σ |
| Stability | Signal persistence | Historically verified |
| Cost | Trading cost ratio | <0.5% |
| Capacity | Strategy capacity ceiling | Match fund size |

### Rejection Criteria
- Unquantifiable opportunities
- Low signal-to-noise ratio
- High trading costs eroding profits

## George Soros (Macro / Reflexivity Theory)

### Core Principles
- Discover macro-level cognitive errors
- Exploit "reflexivity" - expectations affect reality
- Medium-term opportunistic approach

### Decision Variables
| Variable | Description | Ideal Value |
|----------|-------------|-------------|
| Expectation Gap | Market pricing vs true value | Significant mismatch |
| Liquidity | Ability to enter/exit | High |
| Policy | Government/Central bank policy impact | Key catalyst |
| Catalyst | Event triggering expectation correction | Clear |

### Rejection Criteria
- No clear macro mismatch
- Unclear trend
- Insufficient liquidity

## Stanley Druckenmiller (Trend Investing)

### Core Principles
- Follow clear trends, concentrated bets
- Emphasize liquidity management
- Flexible absolute return strategy

### Decision Variables
| Variable | Description | Ideal Value |
|----------|-------------|-------------|
| Trend Clarity | Price trend direction and strength | Strong trend |
| Catalyst | Logic driving the trend | Clear |
| Liquidity | Market depth | Adequate |
| Position | Risk-reward ratio | >3:1 |

### Rejection Criteria
- Unclear trend
- High uncertainty
- Difficult stop-loss

## Ray Dalio (All-Weather / Macro Allocation)

### Core Principles
- Asset allocation based on macro cycles
- Risk parity and diversification
- Medium-to-long term view

### Decision Variables
| Variable | Description | Ideal Value |
|----------|-------------|-------------|
| Growth Environment | Economic growth vs recession | Within framework |
| Inflation Level | Inflation expectations | Modelable |
| Policy Response | Central bank/fiscal policy | Predictable |
| Portfolio Balance | Hedge effectiveness | Reduce volatility |

### Rejection Criteria
- Cannot fit into macro framework
- Unstable correlations
- Large tail risk

- Emphasize diversification and liquidity
- Non-traditional asset allocation

### Decision Variables
| Variable | Description | Ideal Value |
|----------|-------------|-------------|

| Return Premium | Potential to beat benchmark | Reasonable |

- Focus on risk rather than return

### Decision Variables

|----------|-------------|-------------|
| Cycle Position | Pendulum location | Not extreme |

## John Bogle (Index Investing)

### Core Principles
- Low-cost index investing
- Long-term holding
- Avoid behavioral mistakes

### Decision Variables
| Variable | Description | Ideal Value |
|----------|-------------|-------------|
| Cost | Management fee + trading cost | Lowest |
| Diversification | Coverage breadth | Broad market index |
| Long-term Compounding | Index growth potential | Positive growth |

## Peter Lynch (Growth Investing)

### Core Principles
- Invest in growth stocks you can understand
- Seek growth with PEG < 1
- "Tenbagger" potential

### Decision Variables
| Variable | Description | Ideal Value |
|----------|-------------|-------------|
| Earnings Growth | EPS growth rate | >15% |
| PEG Ratio | PE/Growth rate | <1.5 |
| Industry Outlook | Sector space | Broad |
| Cognitive Edge | Personal/institutional info advantage | Exists |

### Rejection Criteria
- Complex and incomprehensible
- False growth (high PE with no growth)
- Cycle peak

## Divergence Dimension Reference

### 1. Valuation Judgment Divergence
- Value investors: Focus on absolute/relative valuation
- Growth investors: Accept high PE depending on growth
- Quant investors: Focus on valuation factor effectiveness
- Macro investors: Focus on relative mismatch

### 2. Time Horizon Divergence
| Investor | Time Frame |
|----------|------------|
| Simons | Short-to-medium (weeks-months) |
| Soros | Medium-short (months-1 year) |
| Druckenmiller | Medium (6-18 months) |
| Lynch | Medium-to-long (1-3 years) |
| Marks | Medium (1-3 years) |
| Dalio | Medium-to-long (3-10 years) |
| Buffett | Long-term (5+ years) |
| 段永平 | Long-term (5+ years) |
| Swensen | Long-term (5+ years) |
| Bogle | Ultra-long (10+ years) |

### 3. Risk Definition Divergence
- Buffett: Permanent loss
- Simons: Model failure
- Soros: Wrong direction
- Marks: Insufficient downside protection
- Lynch: False growth trap
