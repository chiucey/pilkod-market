# 3D Deep Blue Tech Style（3D深蓝科技风格）

## 视觉定义

深蓝科技风格以深海军蓝为基底，融合全息浮空界面与玻璃拟物设计，传达深邃、稳重、信赖的专业B端科技气质。

## 色彩系统

| 用途 | 色值 | 名称 |
|------|------|------|
| 背景 | `#0D1B2A` | 深海军蓝（Dark Navy） |
| 主色 | `#0A84FF` | 科技蓝（Tech Blue） |
| 亮色 | `#00D4FF` | 激光青（Laser Cyan） |
| 高光 | `#E8F4FF` | 冰白（Ice White） |
| 强调 | `#1E6FFF` | 深海蓝（Deep Blue） |
| 弱化文字 | `#6B8CAE` | 灰蓝（Gray Blue） |
| 模块分隔 | `rgba(10,132,255,0.3)` | 半透明蓝线 |

## 图标风格：3D全息浮空面板

核心特征：
- **玻璃通透**：图标主体为半透明玻璃材质，可见内部微结构
- **蓝色描边**：边缘有 `#00D4FF` 色光晕描边，模拟全息投影边缘
- **3D深度**：图标有前倾视角（slight perspective tilt），底部有阴影
- **内部纹理**：透明区域内有细微电路纹理或六边形网格
- **悬浮感**：图标底部有渐变阴影，暗示悬浮于背景之上

## 背景装饰

- **蓝图网格**：细密的 `#1a3a5c` 色网格线，间距约40px
- **坐标刻度**：边缘有极简坐标刻度标记
- **电路纹理**：`#0A84FF` 色，透明度10-20%
- **光晕效果**：背景中央偏上有柔和 `#0A84FF` 渐变光晕

## 排版规范（深蓝版）

- **大号数字编号**：激光青 `#00D4FF`，超大字号（3-4cm等效），全息玻璃质感，是模块的核心视觉锚点
- **正文内容**：白色 `#FFFFFF` 或淡灰 `#C8DCE8`，无衬线
- **标题**：冰白 `#E8F4FF`，中粗体
- **数字条目符号**：激光青 `#00D4FF`
