# 3D Light Blue Tech Style（3D浅蓝科技风格）

## 视觉定义

浅蓝科技风格以冰白/浅蓝为主色调，适合明亮环境、宣传物料和移动端展示，传达清新、专业、明快的B端科技气质。与深蓝版形成对比，供不同使用场景选择。

## 色彩系统

| 用途 | 色值 | 名称 |
|------|------|------|
| 背景 | `#E8F4FF` | 冰白（Ice White） |
| 背景渐变 | `#D6EFFF` | 浅天蓝（Light Sky） |
| 主色 | `#0066CC` | 标准蓝（Standard Blue） |
| 亮色 | `#0A84FF` | 科技蓝（Tech Blue） |
| 辅助 | `#00D4FF` | 激光青（Laser Cyan） |
| 深色文字 | `#0D1B2A` | 深海军蓝（Dark Navy） |
| 中色文字 | `#2D5F8B` | 中蓝（Medium Blue） |
| 模块背景 | `rgba(0,102,204,0.05)` | 极淡蓝填充 |

## 图标风格：3D全息浮空面板（浅色适配）

核心特征：
- **玻璃通透**：白色/淡蓝半透明玻璃材质，可见内部微结构
- **蓝色描边**：边缘有 `#0066CC` 色光晕描边，浅色背景下更清晰
- **3D深度**：图标有前倾视角，底部有淡蓝渐变阴影
- **内部纹理**：透明区域内有细微六边形网格
- **悬浮感**：底部阴影暗示悬浮于背景之上

## 背景装饰

- **细网格线**：极细的 `#B8DAF0` 色网格线，间距约50px
- **坐标刻度**：边缘极简坐标刻度
- **光晕效果**：顶部有柔和的 `#0A84FF` 渐变光晕（比深蓝版更轻）
- **浅色过渡**：背景从 `#E8F4FF` 到 `#D6EFFF` 的细微渐变

## 排版规范（浅蓝版）

- **大号数字编号**：标准蓝 `#0066CC`，超大字号，全息玻璃质感，3D浮空效果
- **正文内容**：深海军蓝 `#0D1B2A`，无衬线，高对比度易读
- **标题**：标准蓝 `#0066CC`，中粗体
- **数字条目符号**：科技蓝 `#0A84FF`

## 深蓝 vs 浅蓝：如何选择

| 场景 | 推荐版本 |
|------|---------|
| 深色官网/Banner/大会背景 | 深蓝版 |
| 微信公众号/朋友圈/小红书 | 浅蓝版（更明亮） |
| PPT封面/报告插图 | 浅蓝版（打印友好） |
| 产品彩页/三折页 | 深蓝版（更有质感） |
| 微博/短视频封面 | 浅蓝版（抓眼球） |
| 黑暗模式展示 | 深蓝版（原生适配） |

## 整体氛围

- 冰白背景 + 蓝色光晕 → 清新、专业、明快
- 全息数字编号 + 玻璃图标 → 科技感、轻盈、现代
- 浅色主题 → 亲和力、传播力、适合社交媒体
