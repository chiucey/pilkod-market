# Bento Grid Layout（五宫格布局）

## 布局结构

```
┌─────────────┬─────────────┐
│   模块1      │   模块2      │
│  客户类型    │  客户特点    │
├─────────────┼─────────────┤
│   模块3      │   模块4      │
│  用户痛点    │  产品价值    │
├─────────────┴─────────────┤
│        模块5              │
│      可复制经验            │
└───────────────────────────┘
```

2行布局：上面2×2网格（4格）+ 下面1行（1格）。

## 模块比例建议

- 上排两格：等宽，各占50%
- 下排一格：撑满全宽
- 模块内边距：各24px
- 模块间距：16px

## 模块内部结构

每个模块内部：
```
┌──────────┬─────────────────┐
│  3D图标   │  标题（模块名）  │
│  (60×60) │                 │
│          │  内容文字        │
│          │  （2-4行）       │
└──────────┴─────────────────┘
```

- 图标区：左侧，固定宽度
- 内容区：右侧，弹性宽度
- 标题：模块名称，冰白色，粗体
- 内容：白色正文，简洁条目式

## 标题区（信息图顶部）

- 案例名称/标题：大字，居中或左对齐
- 可加上公司Logo或产品名标注
- 与下方模块有明确分隔

## 分隔与装饰

- 模块边框：半透明蓝 `#0A84FF`，1px
- 或用细微渐变分隔，替代硬边框
- 背景网格线贯穿全局（见3d-blue-tech.md）

## 5个模块内容纲要

| 模块 | 标题文案 | 图标建议 |
|------|---------|---------|
| 1 | 客户类型 | 六边形/建筑/组织架构图标 |
| 2 | 客户特点 | 标签/徽章/奖杯图标 |
| 3 | 用户痛点 | 闪电/警告/锁链/障碍图标 |
| 4 | 产品价值 | 齿轮/火箭/上升箭头图标 |
| 5 | 可复制经验 | 灯泡/指南/复制/扩展图标 |
