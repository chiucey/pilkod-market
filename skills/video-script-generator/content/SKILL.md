# Short Video Script Generator

## Core Capabilities

Transform "abstract topics" into "filmable storyboard scripts" with fast-paced, engaging style for Douyin/Xiaohongshu.

## Key Features

- **Storyboard Generation**: Topic + Duration + Style → Scene + Dialogue + Music + Duration
- **Style Adaptation**: Plot / Tutorial / Vlog / Comedy
- **Filming Suggestions**: Angle, movement, props for each shot

## Workflow

### 1. Receive Requirements

**Required Information**:
- Topic: What is the video about? (e.g., "Tomato Egg Stir-fry")
- Duration: How long? (e.g., "30 seconds", "1 minute")
- Style: What type? (Plot / Tutorial / Vlog / Comedy)
- Platform: Where will it be posted? (Douyin / Xiaohongshu / Bilibili)

**Ask clarifying questions when needed**:
- "What's the target audience?"
- "Any specific products or props needed?"
- "Do you want voiceover or subtitles?"

### 2. Output Structure

```
# [Topic] Storyboard Script - [Duration]

- Platform: ...
- Total Duration: ...
```

## Style Guidelines

### Tutorial/Knowledge (干货)
- Clear step-by-step structure
- Quick cuts between steps
- Text overlays for key points
- End with call-to-action

### Vlog/Lifestyle
- Personal narrative voiceover
- Varied camera angles
- Natural lighting preferred
- Focus on atmosphere

### Comedy/Entertainment
- Exaggerated expressions
- Fast pacing
- Sound effects for emphasis
- Unexpected plot twists

### Plot/Story
- Character-driven narrative
- Build tension/curiosity
- Emotional resonance
- Satisfying conclusion

## Platform Best Practices

### Douyin (TikTok China)
- 15-60 seconds optimal
- Hook in first 3 seconds
- Fast-paced editing
- Trending sounds
- Challenge participation

### Xiaohongshu
- 30-90 seconds
- Higher quality visuals
- Tutorial/Review focused
- Authentic, relatable
- Detailed captions

### Bilibili
- 3-10 minutes typical
- More in-depth content
- Commentary heavy
- Community engagement
- Long-tail views

## Quality Standards

1. **Filmable**: Every scene has clear visual direction
2. **Time-Accurate**: Total matches requested duration
3. **Engaging**: Hook in opening, CTA in closing
4. **Specific**: Camera angles, movements, props detailed
5. **Adaptable**: Can adjust complexity on request

## Adjustment Keywords

| User Says | Adjust By |
|-----------|-----------|
| "Too complex" | Simplify to 3-4 scenes |
| "Not funny enough" | Add comedy elements, punchlines |
| "Too long" | Condense to shorter scenes |
| "Want more detail" | Break into more granular shots |
