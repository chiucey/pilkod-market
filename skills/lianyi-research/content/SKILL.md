## 一、涟漪研究分类（按深度）

### 快速研究（≤5分钟）
**触发：** "帮我看看BTC"、"BTC现在怎么样"

```
步骤：
1. batch_web_search × 2（精准+S/A级来源）
2. extract_content × 2（前2条最重要URL）
3. 七问快速评分（简化版）
4. 一句话结论 + 建议
```

### 标准研究（≤15分钟）
**触发：** "分析一下ETH"、"帮我看看这个标的"

```
步骤：
1. 并行搜索 × 4（精准+情绪+机构+风险）
2. extract_content × 4
3. 七问完整评分
4. 情景ABC矩阵
5. 仓位建议
6. 标准研报输出
```

### 深度研究（≤30分钟）
**触发：** "深度研究一下"、"帮我调研这个赛道"

```
步骤：
1. 第一轮：基础搜索（标的+行业+竞品）
2. 第二轮：深度内容提取
3. 第三轮：竞品对比分析
4. 七问完整评分
5. 三情景深度分析
6. 综合研报 + 涟漪理解度自评
```

## 三、涟漪七问评分标准（完整版）

### 评分计算方法

| 问题 | 通过 | 部分通过 | 不通过 |
|------|------|---------|--------|
| 1.真的是机会吗？ | +5分 | +2分 | +0分 |
| 2.评分够高吗？ | 基准6分 | +1分 | -2分 |
| 3.反向证据是什么？ | +2分（找到了） | 0分 | -3分（没找） |
| 4.真的理解吗？ | +3分 | +1分 | +0分 |
| 5.适合涟漪体系吗？ | +2分 | 0分 | -5分 |
| 6.时机对吗？ | +3分 | +1分 | -3分 |
| 7.有没有被误导？ | +2分 | 0分 | -3分 |

**总分上限：20分 → 转换为10分制**

### 七问逐条标准

**Q1：真的是机会吗？**
```
通过标准：
✅ 有一手数据（交易所/监管机构）
✅ 有至少2个独立来源验证
❌ 无来源/"据知情人士"不算通过
```

**Q2：涟漪评分够高吗？**
```
基准：6分
加分：评分≥7分时+1分
减分：评分<5分时-2分
```

**Q3：反向证据是什么？**
```
通过：找到了至少1个有力的做空理由（+2分）
未找到：-3分
涟漪必须在研报中明确写出反向证据
```

**Q4：真的理解吗？**
```
通过：能写出3条以上的逻辑链（+3分）
部分：能写出1-2条（+1分）
不理解：无法解释核心逻辑（+0分）
```

**Q5：适合涟漪体系吗？**
```
通过：仓位/铁律/板块规则全合规（+2分）
部分：1项违规（0分）
违规：仓位超标或板块超标（-5分）
```

**Q6：时机对吗？**
```
类型A低位（历史低位建仓）：回调即可入（+3分）
类型B已启动：回调5-8%再入（+1分）
追高（已涨>15%后再入）：-3分
```

**Q7：有没有被误导？**
```
S/A级来源：+2分
B级来源：0分
C/D级来源：-3分
```

### 仓位转换表

| 总分（满分20） | 10分制 | 仓位 |
|---------------|--------|------|
| 18-20分 | 9-10分 | A类20-25% |
| 14-17分 | 7-8分 | B/C类10-15% |
| 10-13分 | 5-6分 | 观察仓≤5% |
| <10分 | <5分 | 0%（放弃） |

## 四、涟漪情景矩阵（标准版）

每个标的必须输出三种情景：

```markdown
### 情景A（乐观）概率：__%
**触发条件：** [什么情况下发生]
**价格区间：** [低] → [高]
**概率计算依据：** [为什么给这个概率]

### 情景B（基准）概率：__%（涟漪基准情景）
**触发条件：** [什么情况下发生]
**价格区间：** [低] → [高]
**概率计算依据：** 这是涟漪最可能的预期

### 情景C（悲观）概率：__%
**触发条件：** [什么情况下发生]
**价格区间：** [低] → [高]
**概率计算依据：** [为什么会发生最悲观情景]

涟漪情景概率之和 = 100%
```

**概率设定规则（不能随意给）：**
- 乐观+悲观+基准 = 100%
- 基准情景概率永远最高（50%左右）
- 市场恐慌期：乐观概率可给到35-40%
- 市场狂热期：悲观概率可给到35-40%

## 八、涟漪研究质量标准

**涟漪研报的及格线：**
- ✅ 结论不模糊（不是"可能涨也可能跌"）

- ❌ 不超过5%的模糊表达

**涟漪信条：宁可说"涟漪不确定"，也不模糊**
