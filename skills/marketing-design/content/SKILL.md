# 营销物料设计 (Marketing Design)

## 核心理念

**Max-De$ign 主张：要么设计，要么被设计。**

营销物料是品牌与用户沟通的重要触点，通过精准的视觉语言传递品牌价值、吸引目标受众、促进商业转化。

## 3. 视觉设计原则

### 视觉焦点设计

```
┌─────────────────────────────────────────────────────────────┐
│                      视觉焦点引导                          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   用户视线流动路径:                                        │
│                                                             │
│   ┌─────────────────────────────────────┐                 │
│   │              标题                    │  ← 首先看到      │
│   │              主视觉                   │  ← 吸引注意      │
│   │    ┌─────────┬─────────┐           │                 │
│   │    │  副标题  │   CTA   │           │  ← 最终聚焦      │
│   │    └─────────┴─────────┘           │                 │
│   └─────────────────────────────────────┘                 │
│                                                             │
│   原则:                                                    │
│   1. 最重要的信息放在视觉中心或黄金分割点                    │
│   2. 使用对比、大小、色彩引导视线                           │
│   3. 留白让焦点更突出                                      │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 设计要素层级

| 层级 | 元素 | 字号/尺寸 | 优先级 |
|------|------|-----------|--------|
| 1 | 主标题 | 最大 | 必须清晰 |
| 2 | 主视觉 | 画面60%+ | 必须吸引 |
| 3 | 核心卖点 | 次大 | 必须传达 |
| 4 | CTA | 醒目色 | 必须突出 |
| 5 | 辅助信息 | 较小 | 适度展示 |

### 色彩搭配原则

| 原则 | 说明 | 示例 |
|------|------|------|
| 主色突出 | 品牌色为主 | 背景/大面积 |
| 对比明确 | 文字与背景 | 文字加阴影 |
| 色彩克制 | 不超过3色 | 避免杂乱 |
| 情感匹配 | 色彩有情感 | 促销用红/绿 |
| 节日适配 | 节日主题色 | 春节红/圣诞绿 |

## 4. 创意文案策略

### 标题公式

| 类型 | 公式 | 示例 |
|------|------|------|
| 数字型 | 数字+利益点 | "3步教你月入过万" |
| 痛点型 | 问题+解决方案 | "还在为XXX烦恼?" |
| 利益型 | 直接利益承诺 | "省时省力就选它" |
| 好奇型 | 制造悬念 | "这个技巧只有1%的人知道" |
| 权威型 | 权威背书 | "XX专家推荐" |
| 限时型 | 紧迫感 | "仅限今天" |

### CTA 设计

| 场景 | CTA 文案 | 风格 |
|------|----------|------|
| 电商促销 | "立即抢购" "马上抢" | 紧迫感 |
| 品牌宣传 | "了解更多" "探索更多" | 引导型 |
| 下载APP | "立即下载" "免费体验" | 价值型 |
| 留资表单 | "立即领取" "获取报价" | 利益型 |
| 会员注册 | "立即加入" "免费注册" | 低门槛 |

### 促销信息呈现

| 信息类型 | 呈现方式 | 示例 |
|----------|----------|------|
| 折扣 | 数字+符号 | "5折起" "直降30%" |
| 赠品 | 图文结合 | "买一送一" |
| 限时 | 时间紧迫 | "仅此3天" |
| 限量 | 稀缺感 | "限量100份" |
| 特价 | 价格对比 | "原价999 现价299" |

## 7. 线下印刷物料

### 印刷色彩规范

| 参数 | 规范 | 说明 |
|------|------|------|
| 色彩模式 | CMYK | 不能用 RGB |
| 黑色文字 | C0 M0 Y0 K100 | 纯黑更清晰 |
| 深色底 | 加反白字 | 确保可读 |
| 出血 | 3mm | 裁切留余量 |
| 安全区 | 5mm | 内容不贴边 |

### 常用纸张材质

| 材质 | 克重 | 用途 | 特点 |
|------|------|------|------|
| 铜版纸 | 128-300g | 宣传册、海报 | 光泽好 |
| 哑光纸 | 128-200g | 名片、折页 | 质感强 |
| 特种纸 | 按需 | 高端物料 | 独特质感 |
| 不干胶 | 按需 | 标签、贴纸 | 方便粘贴 |

### 印刷工艺

| 工艺 | 效果 | 适用物料 |
|------|------|----------|
| 覆膜 | 光膜/哑膜保护 | 名片、折页 |
| 烫金/银 | 金属质感 | 高端物料 |
| UV | 局部凸起 | 标题、Logo |
| 击凸 | 立体触感 | 名片、卡片 |
| 压痕 | 方便折叠 | 折页、礼盒 |

## 10. 质量检查清单

### 设计规范检查

- [ ] 尺寸符合投放要求
- [ ] 品牌元素使用正确
- [ ] 色彩搭配协调
- [ ] 排版层级清晰
- [ ] 文字无错别字
- [ ] 信息完整无遗漏

### 技术规范检查

- [ ] 分辨率符合要求
- [ ] 色彩模式正确 (CMYK/RGB)
- [ ] 格式后缀正确
- [ ] 文件命名规范
- [ ] 字体已嵌入/转曲
- [ ] 图层命名清晰

### 印刷检查 (线下物料)

- [ ] 出血设置正确
- [ ] 安全区留白足够
- [ ] 文字转曲/嵌入
- [ ] 图片链接完整
- [ ] 色彩值正确
- [ ] 纸质工艺标注
