# 数学动画生成器

## 核心能力

AI数学动画生成器能够将自然语言指令转化为高质量的数学动画视频，支持以下功能：

### 1. 几何变换可视化
- **基本图形**：点、线段、圆、多边形、多面体
- **变换动画**：平移、旋转、缩放、反射、形变（Homotopy）
- **示例**："生成红色圆形，让它绕中心旋转360度"

### 2. 函数与坐标系绘制
- **坐标系**：笛卡尔坐标系、极坐标系、三维坐标系
- **函数类型**：三角函数、多项式、指数函数、对数函数、参数方程
- **动态演示**：轨迹追踪、切线动画、面积填充、微积分概念
- **示例**："绘制y=sin(x)和y=cos(x)，标注交点"

### 3. 数学公式排版
- **LaTeX支持**：出版级公式渲染
- **动画类型**：逐字书写、公式变换、等式推导
- **示例**："展示勾股定理a²+b²=c²的推导过程"

### 4. 算法流程演示
- **数据结构**：数组、链表、树、图
- **算法可视化**：排序算法（冒泡、选择、快速排序）、图论算法、搜索算法
- **示例**："演示冒泡排序的过程"

## 工作流程

### 步骤1：解析自然语言指令

接收用户的自然语言描述，提取以下关键信息：

```
| 提取内容 | 示例 |
|---------|------|
| 图形类型 | 圆形、正方形、三角形、点、直线 |
| 颜色属性 | 红色、蓝色、渐变色 |
| 变换类型 | 旋转、平移、缩放 |
| 动画参数 | 360度、3秒、匀速 |
| 坐标系 | 笛卡尔坐标、极坐标 |
| 函数表达式 | y=sin(x)、x²+y²=1 |
| LaTeX公式 | a^2 + b^2 = c^2 |
```

### 步骤2：构建动画脚本

将解析结果转换为Manim动画代码：

```python
from manim import *

class MathAnimation(Scene):
    def construct(self):
        # 根据用户指令生成动画
        # 几何图形、函数图像、公式动画等
```

### 步骤3：渲染输出视频

使用Manim引擎渲染高质量动画：

```
支持的输出格式：MP4 (H.264), WebM, GIF
默认分辨率：1920x1080 (1080p)
帧率：60fps (可配置)
```

## 动画类型映射

### 几何变换

| 指令关键词 | 对应Manim类 | 说明 |
|-----------|-------------|------|
| 旋转 | Rotate | 绕点或轴旋转 |
| 平移 | ApplyMethod | 移动位置 |
| 缩放 | ApplyMatrix | 放大或缩小 |
| 形变 | Homotopy | 连续变形 |
| 反射 | Reflect | 对称反射 |

### 函数绘制

| 指令关键词 | 对应Manim类 | 说明 |
|-----------|-------------|------|
| 坐标系 | Axes, PolarPlane | 创建坐标系统 |
| 函数图像 | FunctionGraph | 绘制函数曲线 |
| 参数方程 | ParametricFunction | 参数化曲线 |
| 追踪 | Tracing, MoveAlongPath | 动态追踪 |

### 公式动画

| 指令关键词 | 对应Manim类 | 说明 |
|-----------|-------------|------|
| 书写 | Write | 逐字显示 |
| 变换 | Transform | 公式变换 |
| 匹配 | TransformMatchingTex | 匹配替换 |

## 示例指令与输出

### 示例1：几何动画
**用户指令**："生成一个红色圆形，让它以画面中心为圆心旋转360度，动画时长5秒"

**解析结果**：
- 图形：Circle，color=RED
- 变换：Rotate，angle=2π，radians=True
- 时长：duration=5

**生成动画**：红色圆形绕中心匀速旋转一周

### 示例2：函数图像
**用户指令**："在坐标系中绘制y=sin(x)和y=cos(x)，用不同颜色区分，并标注交点"

**解析结果**：
- 坐标系：Axes，x_range=[-2π, 2π]
- 函数1：sin(x)，color=BLUE
- 函数2：cos(x)，color=RED
- 标注：交点Dot标注

**生成动画**：显示完整坐标系，两条函数曲线依次绘制成交点标注

### 示例3：公式推导
**用户指令**："展示勾股定理公式a²+b²=c²的书写动画"

**解析结果**：
- 公式：a^2 + b^2 = c^2
- 动画：Write，逐一字符显示

**生成动画**：公式逐字符优雅书写呈现

### 示例4：算法可视化
**用户指令**："演示冒泡排序算法对数组[5,3,8,4,1]的排序过程"

**解析结果**：
- 算法：BubbleSort
- 数据：[5,3,8,4,1]
- 可视化：比较交换动画

**生成动画**：数组元素逐步交换排序的完整过程

### 示例5：3D动画
**用户指令**："创建一个3D场景，展示球体沿螺旋线上升"

**解析结果**：
- 维度：3D
- 图形：Sphere
- 运动：螺旋线参数方程
- 路径：ParametricFunction3D

**生成动画**：3D球体沿螺旋路径上升旋转

## 错误处理

| 错误类型 | 处理方式 |
|---------|---------|
| 表达式语法错误 | 提示正确的数学表达式格式 |
| 图形参数无效 | 使用默认值并提示修正建议 |
| 渲染超时 | 提供低分辨率预览选项 |
| 未知指令 | 请求澄清或提供建议选项 |
