# 逻辑一致性校验系统

## 校验层级架构

```
【第一层：事实校验】
世界基础设定的一致性
    │
【第二层：规则校验】
力量体系/物理规则的逻辑自洽
    │
【第三层：行为校验】
角色行为与性格的一致性
    │
【第四层：情节校验】
事件因果链的合理性
    │
【第五层：伏笔校验】
埋线与收线的呼应性
```

## 一、时间线校验

### 时间线问题清单

```
【时间点校验】
□ 事件A发生在事件B之前还是之后？
□ 角色年龄在两个时间点是否一致？
□ 季节变化是否符合时间流逝？
□ 节气节日是否与历法匹配？

【时间跨度校验】
□ 从A地到B地需要多长时间？
□ 角色修炼到某个境界需要多久？
□ 势力从弱到强需要多长时间？
□ 怀孕/疾病等有明确周期的事件是否匹配？

【时间跳跃校验】
□ 大段时间跳跃是否有交代？
□ 跳跃期间发生了什么？
□ 跳跃前后角色状态是否合理衔接？
```

### 时间线冲突示例

```
【冲突案例】
✗ 问题：
第10章："张凡今年十八岁"
第50章："那是十五年前的往事"
第65章：张凡十八岁生日

✓ 正确：
第10章：张凡今年十八岁
第50章："那是十五年前" → 但当时张凡三岁
第65章：张凡二十岁生日（十八+两年后）

【修正方法】
- 建立详细年表
- 标注每个事件的时间点
- 检查时间跨度合理性
```

## 二、能力边界校验

### 能力设定校验

```
【力量体系校验】
□ 力量等级是否清晰定义？
□ 等级之间的差距是否明确？
□ 越级战斗的条件是否合理？
□ 力量来源是否一致？

【技能/功法校验】
□ 技能的威力和限制是否明确？
□ 技能修炼的前置条件是否满足？
□ 技能之间是否有冲突？
□ 技能升级的代价是否合理？

【特殊能力校验】
□ 主角金手指的范围是什么？
□ 有没有设定边界/代价/冷却？
□ 其他角色是否也有特殊能力？
□ 能力是否会随时间/状态变化？
```

### 能力边界问题

```
【边界模糊问题】
✗ 描述："他能做到任何事"
✓ 描述："他能在特定条件下使用某种能力"

【越级战斗问题】
✗ 描述：筑基期打败金丹期，没解释原因
✓ 描述：筑基期主角凭借顶级功法+偷袭+对手大意取胜

【能力通货膨胀】
✗ 描述：第一章能打败筑基期，第三章金丹期随便打
✓ 描述：能力成长有清晰的阶段性标志
```

### 战力对比模板

```
【势力A VS 势力B】

【高端战力】
- 势力A：元婴期×2
- 势力B：元婴期×1，金丹期×5

【中端战力】
- 势力A：筑基期×100
- 势力B：筑基期×200

【综合评估】
- 高端：A略占优势
- 中端：B有数量优势
- 总体：短期A强，长期B强

【战争预测】
- 遭遇战：A胜
- 消耗战：B胜
- 外交可能：势力均衡时可能结盟
```

## 三、性格一致性校验

### 性格漂移检测

```
【问题模式】

原始设定：
"李明性格内向，不善言辞，但内心善良"

↓ 章节发展后

第10章：内向，表现符合
第20章：内向，偶尔说话
第50章：突然变得很健谈，参与多人社交
第80章：又变回内向

↑ 这就是性格漂移

【检测方法】
- 列出角色的5个核心性格特征
- 每个章节检查是否都符合
- 任何偏离都需要解释
```

### 性格一致性矩阵

```
【内向型角色】

场景            │ 预期行为  │ 实际行为  │ 是否一致
────────────────┼──────────┼──────────┼────────
多人社交场合     │ 沉默/旁观  │ 积极发言  │ ✗
独处时          │ 舒适/放松  │ 焦虑不安  │ ✗
紧急情况        │ 行动但少言  │ 滔滔不绝  │ ✗
与亲密朋友相处   │ 稍微放开   │ 极度外向  │ ✗
陌生人接近      │ 警惕后退   │ 热情拥抱  │ ✗
```

### 性格变化合理性

```
【合理变化】
触发事件：重大创伤/成长契机/持续影响
变化过程：渐进式，有过渡
结果：新性格与旧性格有逻辑联系

【不合理变化】
触发事件：无/轻微/临时
变化过程：突然跳跃
结果：完全矛盾的性格
```

## 五、利益逻辑校验

### 利益动机一致性

```
【角色利益校验】

问：这个行为是否符合角色的利益？

答：
- 短期利益 vs 长期利益
- 个人利益 vs 集体利益
- 物质利益 vs 精神利益

【势力利益校验】

问：这个决策是否符合势力的利益？

答：
- 核心利益（生存、基本盘）
- 重要利益（发展、扩张）
- 次要利益（名声、小利）
```

### 利益冲突处理

```
【合理冲突】
- 角色A和角色B有不同的利益诉求
- 双方都有自己的道理
- 冲突推进剧情

【不合理冲突】
- 冲突一方明显吃亏
- 角色做出损己利人的事没道理
- 为了冲突而冲突
```

## 六、因果逻辑校验

### 事件因果链

```
【强因果】
事件A直接导致事件B
"他打破了茶杯，所以地上有碎片"

【弱因果】
事件A间接/可能影响事件B
"他心情不好，可能导致他失误"

【无因果】
两个独立事件
"他打破了茶杯，而且天下雨了"
```

### 因果漏洞检测

```
【缺失环节】
✗ 问题：
张凡成为掌门 → 门派变强
缺失：为什么成为掌门就能变强？

✓ 完整：
张凡成为掌门 → 制定新政策 → 吸引人才 → 门派变强

【不合理跳跃】
✗ 问题：
他修炼了三天 → 他成为了天下第一
缺失：三天能修炼到什么程度？

✓ 合理：
他修炼了三十年 → 积累足够 → 突破 → 天下闻名
```

### 因果类型总结

```
【必要因果】
没有A就没有B
"不吃饭就会饿死"

【充分因果】
有A就一定有B
"有火就一定有热度"

【或然因果】
有A可能有B
"努力可能成功"
```

## 七、伏笔校验系统

### 伏笔类型

```
【明线伏笔】
- 明显设置，但不知指向
- 读者看到会有印象
- 回收时恍然大悟

【暗线伏笔】
- 隐约提及，甚至一笔带过
- 读者可能没注意
- 回收时让人惊讶

【草蛇灰线】
- 分散在多处
- 每处都很微小
- 累积后揭示
```

### 伏笔校验清单

```
【伏笔设置】
□ 我埋下了什么伏笔？
□ 伏笔的隐蔽程度如何？
□ 伏笔与核心剧情的关联度？
□ 伏笔的回收时间是否合理？

【伏笔回收】
□ 之前埋的伏笔是否都有回收？
□ 回收方式是否合理？
□ 回收时是否有新信息揭示？
□ 伏笔回收是否让读者满足？

【伏笔遗漏】
□ 有没有忘记回收的伏笔？
□ 有没有无法回收的伏笔？
□ 需要如何补救？
```

### 伏笔回收模板

```
【伏笔记录表】

伏笔编号：P001
伏笔内容：第一章提到主角有一枚神秘玉佩
伏笔位置：第1章
预期回收：第50章（身份揭示时）
回收方式：玉佩是身份证明
状态：待回收

---

伏笔编号：P002
伏笔内容：第三章提及某个人的死因存疑
伏笔位置：第3章
预期回收：第30章（真相大白）
回收方式：非自然死亡，是谋杀
状态：已回收（第31章）✓
```

## 九、问题修复指南

### 修复优先级

```
【P0：致命问题】
- 完全颠覆核心设定
- 导致故事无法继续
- 必须立即修复

【P1：严重问题】
- 影响重要情节
- 读者可能发现
- 尽快修复

【P2：一般问题】
- 不影响主要剧情
- 细心读者可能发现
- 后续章节注意

【P3：微小问题】
- 基本不会注意到
- 不影响阅读体验
- 可以忽略或后续优化
```

### 修复方法

```
【打补丁法】
问题：某个设定有漏洞
修复：补充一个新设定来解释
风险：可能产生新漏洞

【重构法】
问题：根本性问题
修复：重新设计这部分
成本：较大，但更彻底

【忽略法】
问题：微小问题
修复：暂时不管
风险：可能累积

【模糊处理法】
问题：无法解释的漏洞
修复：避免详细描写
风险：可能回避了问题
```
