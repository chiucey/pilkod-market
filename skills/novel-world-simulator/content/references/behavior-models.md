# 角色行为模拟系统

## 核心架构

```
性格层（底层）
    ↓
价值观层
    ↓
动机层
    ↓
情绪层
    ↓
决策层（表层）
```

## 一、性格建模系统

### MBTI性格分类适配

```
【外向型(E)角色】

决策倾向：
- 行动前先讨论
- 从外部获得能量
- 喜欢多样性

行为模式：
- 主动出击型：积极拓展，主动社交
- 社交催化型：善于联络，调动气氛
- 表现展示型：喜欢舞台，享受关注

网文典型：
- 话痨型主角
- 社交达人
- 团队润滑剂
```

```
【内向型(I)角色】

决策倾向：
- 行动前先思考
- 从内部获得能量
- 喜欢深度交流

行为模式：
- 独立行动型：不依赖他人，独自解决问题
- 观察分析型：先看再做，谋定后动
- 深度专研型：沉浸自我领域，不理会外界

网文典型：
- 隐世高人
- 独狼刺客
- 技术宅/炼器师
```

### 大五人格维度

```
【开放性(O)】
高开放：好奇心强，追求新颖，思维发散
- 适合：谋士、创新者、探险家
低开放：务实保守，遵循传统，思维稳定
- 适合：管理者、执行者、保守派

【尽责性(C)】
高尽责：自律性强，目标导向，有计划
- 适合：大师、掌门、团队核心
低尽责：灵活随性，不拘小节，随遇而安
- 适合：浪子、游侠、散修

【外向性(E)】
高外向：社交活跃，精力充沛，寻求刺激
- 适合：帝王、掌门、社交型主角
低外向：内敛沉静，谨慎内省，低调行事
- 适合：隐士、卧底、幕后黑手

【宜人性(A)】
高宜人：信任他人，乐于助人，善于合作
- 适合：圣母型角色、医者、和平使者
低宜人：怀疑他人，竞争性强，坚持己见
- 适合：枭雄、反派、独行侠

【神经质(N)】
高神经质：情绪敏感，容易焦虑，反应强烈
- 适合：复杂角色、需要情绪张力的剧情
低神经质：情绪稳定，沉着冷静，不易动摇
- 适合：冷血杀手、心机深沉者
```

## 二、价值观系统

### 核心价值层级

```
【第一层级：生存本能】
- 活下去
- 保护至亲
- 避免痛苦

【第二层级：安全需求】
- 稳定的生活
- 可预测的未来
- 安全的居所

【第三层级：归属需求】
- 被群体接纳
- 获得认同
- 建立羁绊

【第四层级：尊重需求】
- 获得地位
- 建立威信
- 证明自己

【第五层级：自我实现】
- 追求理想
- 实现价值
- 超越自我
```

### 价值冲突处理

```
场景：主角面临选择

选项A：保护队友（牺牲个人安全）
选项B：保全自己（放弃队友）

【分析】
- 如果"保护"是核心价值 → 选A
- 如果"生存"是核心价值 → 选B
- 如果"自我牺牲"是核心价值 → 可能选A
- 如果"理性计算"是核心价值 → 权衡后选

价值层级决定最终选择
```

## 三、动机系统

### 表面动机 vs 深层动机

```
【角色表面行为】
"我要成为天下第一"

【表面动机】
变强、获得权力、声望

【深层动机】
- 证明给看不起自己的人看？
- 保护重要的人？
- 复仇？
- 掩盖某种恐惧？
- 完成某个人的遗愿？

深层动机往往比表面动机更能解释角色行为
```

### 动机类型矩阵

```
          │ 个人利益 │ 社会价值 │ 情感驱动 │ 理想追求 │
──────────┼─────────┼─────────┼─────────┼─────────┤
主动型动机│  权力    │  使命    │  爱情    │  信仰    │
被动型动机│  自保    │  责任    │  羁绊    │  宿命    │
```

## 四、情绪系统

### 情绪触发机制

```
【愤怒】
触发：被冒犯、被轻视、目标受阻
表现：提高音量、身体紧绷、攻击性语言
影响：降低理性判断，增强行动力
消退：需要时间/道歉/问题解决

【恐惧】
触发：面临威胁、未知情境、失去控制
表现：退缩、颤抖、声音发颤
影响：限制行动、引发逃跑或僵住
消退：需要安全感建立/确认威胁解除

【悲伤】
触发：失去、失败、背叛
表现：沉默、眼泪、能量下降
影响：降低行动意愿，引发反思
消退：需要时间/支持/新的希望

【喜悦】
触发：成功、获得、团聚
表现：笑容、能量提升、愿意分享
影响：提高创造力和合作意愿
持续：短暂，需要新的刺激维持

【愧疚】
触发：违反自我标准、伤害他人
表现：回避、内疚言语、自我惩罚
影响：推动补偿行为
消退：需要道歉、弥补、原谅
```

### 情绪曲线设计

```
【单章节情绪曲线】

起点（平静）→ 冲突触发 → 情绪升级 → 爆发点 → 余韵

示例：
主角发现被背叛
↓
回忆起曾经的美好（悲伤上升）
↓
看到对方得意表情（愤怒上升）
↓
想起曾经的誓言（愧疚混合）
↓
爆发质问（情绪顶点）
↓
转身离去（压抑情绪，留白）
```

## 五、决策系统

### 决策模型

```
【理性决策模型】
1. 识别问题
2. 收集信息
3. 评估选项
4. 权衡利弊
5. 做出选择
6. 执行行动
7. 评估结果

适用：高智商角色、复杂局面、关键选择
```

```
【直觉决策模型】
1. 感知情境
2. 直觉反应
3. 快速选择
4. 行动
5. 事后合理化

适用：经验丰富的角色、紧急情况、简单判断
```

```
【情感决策模型】
1. 情感触发
2. 情感主导
3. 忽略理性分析
4. 行动
5. 情绪满足/后悔

适用：年轻角色、极端情绪、感情戏
```

### 决策风格分类

```
【冲动型】
特征：不假思索，行动先于思考
优势：抓住机会，行动迅速
劣势：考虑不周，容易后悔
代表角色：热血青年、战斗狂人

【谨慎型】
特征：深思熟虑，全面考量
优势：风险低，考虑周全
劣势：速度慢，可能错失良机
代表角色：谋士、老狐狸

【随缘型】
特征：看情况，灵活应对
优势：适应性强，不僵化
劣势：缺乏坚持，可能摇摆
代表角色：圆滑者、墙头草

【信念型】
特征：由价值观驱动，不计后果
优势：意志坚定，感召力强
劣势：可能不顾现实，一条道走到黑
代表角色：殉道者、狂热者
```

## 六、行为模式库

### 经典角色行为模板

```
【傲娇型角色】
语言模式：
- 嘴上说不要，身体很诚实
- 关心用批评表达
- 正面评价绕着说

行为模式：
- 遇到问题先嘴硬
- 关键时刻会出手
- 需要给台阶才软化

示例：
"我才不是在帮你！只是顺路而已！"
```

```
【腹黑型角色】
语言模式：
- 表面和善，暗藏机锋
- 说话留余地，不留把柄
- 赞美可能是陷阱

行为模式：
- 每句话都有目的
- 提前布局多步棋
- 关键时刻才暴露真实意图

示例：
"这真是太好了，您一定有这个能力。"
```

```
【热血型角色】
语言模式：
- 直来直去，不绕弯子
- 经常喊口号
- 情绪化表达

行为模式：
- 二话不说就上
- 不管输赢先干了再说
- 为朋友两肋插刀

示例：
"废话少说！我要上了！"
```

```
【高冷型角色】
语言模式：
- 言简意赅，能省则省
- 很少主动开口
- 讽刺一针见血

行为模式：
- 除非必要，不出手
- 出手就是碾压
- 对特定人态度不同

示例：
"哦。"
"知道了。"
"与我无关。"
```

## 七、角色关系演化

### 关系类型

```
【羁绊关系】
- 血缘羁绊：家族纽带
- 师徒羁绊：传承关系
- 战友羁绊：共同经历
- 救命羁绊：生死之恩

【情感关系】
- 爱情：最强烈的情感连接
- 友情：志同道合的伙伴
- 仇恨：强烈的负面情感
- 嫉妒：隐藏的敌意

【利益关系】
- 合作关系：共同利益
- 利用关系：单向获益
- 对抗关系：利益冲突
```

### 关系演变模型

```
【关系发展阶段】

陌生 → 接触 → 了解 → 认可 → 信任 → 深层羁绊
   ↓       ↓       ↓       ↓       ↓
警惕    试探    观察    犹豫    确认

【关系破裂阶段】

信任 → 动摇 → 裂痕 → 爆发 → 决裂
  ↓      ↓      ↓      ↓
怀疑   试探   掩饰   爆发

【关系修复阶段】

决裂 → 冷静 → 反思 → 契机 → 修复/释然
```

## 八、行为一致性校验

### 核心校验问题

```
【历史行为一致性】
Q: 这个角色过去在类似情况下会怎么做？
Q: 有没有与过去行为矛盾的地方？
Q: 成长/改变是否有迹可循？

【性格逻辑一致性】
Q: 这个行为符合角色的核心性格吗？
Q: 是否有更符合性格的其他选择？
Q: 性格改变是否有合理原因？

【处境合理性】
Q: 这个处境下，角色能获得这些信息吗？
Q: 角色有能力执行这个行为吗？
Q: 时间、空间是否合理？

【动机充分性】
Q: 角色为什么要这样做？
Q: 表面动机下是否有更深层的原因？
Q: 动机是否足够支撑行为？
```

### 一致性违规类型

```
【性格漂移】
定义：角色性格变得与最初设定不一致
原因：作者忘记/刻意改变
修正：回顾角色核心特质，修正后续行为

【能力膨胀/缩水】
定义：角色能力忽高忽低
原因：剧情需要/忘记设定
修正：建立清晰的能力边界和成长曲线

【价值观矛盾】
定义：角色做出违背自身价值观的行为
原因：剧情需要/设定不完善
修正：挖掘价值观背后的更深层动机

【关系突变】
定义：关系变化缺乏铺垫
原因：跳过发展阶段
修正：增加过渡场景，建立情感基础
```

## 九、特殊情境行为预测

### 面对背叛

```
【复仇型角色】
反应：愤怒、策划反击
行为：收集证据、等待时机、一击致命
风险：可能失控、牺牲其他目标

【隐忍型角色】
反应：压抑愤怒、评估损失
行为：若无其事、暗中布局、等待机会
风险：可能压抑过度、爆发时更可怕

【释怀型角色】
反应：失望、痛苦、但选择放下
行为：切断关系、专注自己、可能祝福
风险：被看作软弱、可能被再次伤害
```

### 面对危机

```
【领导型角色】
反应：接管指挥、稳定局面
行为：分配任务、做出决策、保护弱者
表现：果断、有担当、给人安全感

【逃避型角色】
反应：恐惧、想逃跑
行为：找借口离开、躲藏、推卸责任
表现：怯懦、但可能有隐情

【战斗型角色】
反应：战意昂扬、准备迎战
行为：第一个冲上去、鼓舞士气
表现：勇敢、鲁莽、不计后果
```

### 面对感情

```
【主动型】
表白方式：直接告白、行动证明
追求方式：送礼物、制造机会、强势接近
危机处理：主动沟通、主动解决

【被动型】
表白方式：暗示、试探、等人来追
追求方式：等待、若即若离、给暗示
危机处理：回避、冷战、等人主动

【纠结型】
表白方式：说不出口、话到嘴边
追求方式：想接近又退缩、反复无常
危机处理：内心戏丰富、行动迟缓
```
