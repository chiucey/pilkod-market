# 小说世界观模拟器

## 核心定位

基于已有小说内容和设定，对小说世界进行**真实、开放、自洽**的演变推演。让不同角色行为更加鲜明独特，同一角色前后变化更加协调统一。

## 核心能力

| 能力 | 描述 |
|------|------|
| 世界演变推演 | 基于现有设定推演政治、经济、文化走向 |
| 角色行为预测 | 根据性格和处境推断角色行为模式 |
| 势力消长模拟 | 模拟各方势力的兴衰变化 |
| 情节走向推算 | 预测可能的情节发展方向 |
| 逻辑一致性校验 | 确保推演结果与已有设定不冲突 |

---

## 工作流程

### 阶段一：世界建档（World Profiling）

**输入**：小说大纲、已有章节、人物设定文档

**执行步骤**：

1. **提取世界骨架**
   - 时代背景与地理环境
   - 政治格局与势力分布
   - 社会结构与阶层关系
   - 核心规则与运行法则

2. **构建势力图谱**
   ```
   【势力类型】
   - 主要势力（3-5个）
   - 次要势力（5-10个）
   - 隐藏势力（1-3个）
   - 独立个体/散修

   【势力属性】
   - 核心利益
   - 资源控制
   - 人员规模
   - 关键人物
   - 行动模式
   ```

3. **建立角色档案**
   ```
   【角色核心】
   - 性格特质（MBTI/大五模型）
   - 核心价值观
   - 能力边界
   - 情感锚点
   - 行为动机层

   【关系网络】
   - 亲属关系
   - 师徒传承
   - 利益纠葛
   - 情感羁绊
   - 仇恨怨恨
   ```

**输出**：世界状态文档（World State Document）

---

### 阶段二：行为引擎（Behavior Engine）

**核心原则**：角色行为 = 性格底色 + 当前处境 + 历史记忆 + 即时情绪

**执行步骤**：

1. **性格建模**
   ```
   【性格维度】
   - 外向/内向
   - 理性/感性
   - 独立/依赖
   - 保守/激进
   - 冷漠/热情

   【决策风格】
   - 冲动型：先行动后思考
   - 谨慎型：三思而后行
   - 随缘型：看情况决定
   - 算计型：利弊权衡优先
   ```

2. **行为预测**
   ```
   【输入】
   - 当前处境描述
   - 相关人物影响
   - 情绪状态评估

   【输出】
   - 可能的行动选项（1-3个）
   - 最可能的行为（概率排序）
   - 行为后果推演
   ```

3. **行为校验**
   ```
   检查项：
   ✓ 行为是否符合角色性格？
   ✓ 行为是否有合理动机？
   ✓ 与角色历史行为是否一致？
   ✓ 是否产生预期之外但合理的新变量？
   ```

---

### 阶段三：世界推演（World Evolution）

**核心方法**：因果链推演 + 蝴蝶效应模拟 + 势力博弈分析

**执行步骤**：

1. **初始状态确定**
   ```
   时间节点：故事发展到第X章/第X卷
   空间范围：涉及的地理区域
   势力状态：各势力的当前实力对比
   角色状态：主要角色的当前处境
   ```

2. **触发事件分析**
   ```
   【事件类型】
   - 外部冲击：战争、自然灾害、外敌入侵
   - 内部变革：权力更迭、政策变动、技术突破
   - 角色行动：关键人物的重大决策
   - 随机变量：偶发事件的介入

   【因果链条】
   事件A → 变量X变化 → 变量Y响应 → 事件B
   ```

3. **多路径推演**
   ```
   【分支结构】

   主线推演：最可能的演变路径
   │
   ├── 乐观分支：如果X发生...
   ├── 悲观分支：如果Y发生...
   └── 意外分支：原本未考虑的变量...

   【概率评估】
   - 主线：60%
   - 乐观分支：20%
   - 悲观分支：15%
   - 意外分支：5%
   ```

4. **势力博弈模拟**
   ```
   【势力行动模式】
   - 扩张型：主动出击，扩大势力
   - 防守型：稳固现有，等待时机
   - 观望型：跟随趋势，伺机而动
   - 破坏型：搅乱局势，从中获利

   【利益博弈】
   - 资源争夺
   - 势力消长
   - 联盟形成/破裂
   ```

---

### 阶段四：逻辑校验（Consistency Check）

**核心目标**：确保推演结果与已有设定不冲突

**校验清单**：

```
【时间线校验】
□ 推演结果是否与已有时间线矛盾？
□ 角色年龄、能力成长是否合理？

【能力边界校验】
□ 角色行为是否超出能力范围？
□ 力量体系是否保持一致？

【性格一致性校验】
□ 推演行为是否符合角色性格？
□ 是否有前后矛盾的迹象？

【世界规则校验】
□ 是否违背已建立的世界法则？
□ 经济、政治体系是否自洽？

【伏笔呼应校验】
□ 推演结果是否呼应已有伏笔？
□ 是否为后续剧情留下空间？
```

## 核心推演模型

### 1. 势力兴衰模型

```
【势力生命周期】

崛起期：
- 核心创始人出现
- 初期核心成员聚集
- 找到立足之地/资源
- 形成初步势力范围

鼎盛期：
- 势力规模达到顶峰
- 核心利益最大化
- 影响力覆盖最广
- 内部矛盾开始积累

衰退期：
- 核心人物离去/陨落
- 外敌压力增大
- 内部分裂
- 资源供给不足

消亡/重生：
- 彻底消亡
- 被吞并重组
- 转型重生
```

### 2. 角色行为模型

```
【行为决策树】

当前处境
    │
    ├── 威胁感知 ──→ 战斗/逃跑/投降
    │
    ├── 利益诱惑 ──→ 评估风险/收益
    │
    ├── 情感触发 ──→ 冲动/克制
    │
    └── 规则约束 ──→ 服从/违规

性格修正：
- 同样的处境，不同性格→不同选择
```

### 3. 世界演变模型

```
【演变驱动因素】

内因（可控）：
- 势力决策
- 角色行动
- 技术进步
- 制度变革

外因（扰动）：
- 外部入侵
- 自然灾害
- 偶发事件
- 意外发现

演变类型：
- 渐进式：缓慢积累，最终质变
- 突变式：突发事件，格局剧变
- 周期性：兴衰交替，循环往复
```

## 注意事项

1. **开放性原则**：推演结果应保持开放，不要过度锁定剧情走向
2. **一致性优先**：任何推演都必须与已有设定保持一致
3. **角色为中心**：世界服务于角色，角色驱动世界
4. **留白艺术**：推演应提供方向，而非硬性规定
5. **动态更新**：随着故事发展，持续更新世界模型
