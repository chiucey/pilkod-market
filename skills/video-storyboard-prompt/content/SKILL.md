# 15秒电影级分镜提示词工程

## 📋 提示词目标

将小说文案拆解为适配 AI 视频生成模型（如 Seedance 2.0 / 即梦 2.0）的 15 秒电影级分镜脚本。

## ⚙️ 核心能力要求

### 1. 模型逻辑对齐
- **长视频连贯性**：确保分镜间人物、场景、动作无缝衔接
- **中式审美建模**：运用留白、意境、光影层次等东方美学元素
- **物理运动规律**：符合真实世界的重力、惯性、光影变化
- **精准对口型**：台词与唇形精确同步，表情与语气高度匹配

### 2. 人物控制约束
- **单人画面原则**：禁止出现其他人物
- **视觉重心锁定**：通过特写、主观视角或环境遮挡突出主角
- **细节刻画**：瞳孔、泪痕、指甲、呼吸等微观表现

---

## 📐 输出架构

### 维度一：音画双轨协议

| 类型 | 定义 | 画面表现 |
|------|------|----------|
| **台词 Dialogue** | 角色直接说的话 | 开启对口型，人物张嘴，表情与语气同步 |
| **画外音 VO** | 旁白/心理活动/环境渲染 | 人物不张嘴，通过眼神、呼吸、环境空镜表达 |

### 维度二：时空连贯性

```
场景锚定 → 动作衔接 → 视觉一致
   ↓           ↓           ↓
明确地点   姿态连贯    着装/光影统一
```

### 维度三：运镜词库（必须标注）

| 运镜类型 | 适用场景 | 示例元素 |
|----------|----------|----------|
| **极焦特写** | 情感峰值 | 瞳孔收缩、泪滴、指缝发白、喉结滚动 |
| **近景推轨** | 压迫感/递进 | 匀速拉近、增强情绪张力 |
| **环绕摇镜** | 混乱/迷茫 | 360度旋转、情感包围 |
| **慢动作** | 爆发/余韵 | 情感瞬间定格、神态延续 |
| **手持震动** | 愤怒/恐惧 | 心理不稳、虚弱颤抖 |

## 📝 分镜脚本格式

```
【分镜序号】：[核心冲突点描述]
场景描述：[地点 / 光影 / 人物状态]
时间轴拆解：
├── 0-4秒：【运镜】动作起始 + (VO：内容)
├── 4-8秒：【运镜】细节反应 + 角色名说："台词"
├── 8-12秒：【运镜】情绪转折 + (VO：心理活动)
└── 12-15秒：【运镜】定格收尾，预留衔接
```

## ⚠️ 风险规避规则

### 禁止表现
- 低俗、暴露内容
- 直接暴力血腥镜头
- 多人物同框

### 高级感替代方案

| 低俗表现 | 高级感替代 |
|----------|------------|
| 大喊大叫 | 呼吸起伏、指甲陷入掌心 |
| 肢体冲突 | 眼神角力、空间对峙 |
| 情绪失控 | 面红耳赤、热气氤氲 |
