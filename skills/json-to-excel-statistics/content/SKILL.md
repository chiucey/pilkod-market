# JSON 转 Excel 统计分析技能

## 技能概述

本技能专门用于处理 JSON 数据的转换和统计分析工作，能够将各种结构的 JSON 数据快速转换为格式规范的 Excel 文件，并提供丰富的数据统计分析功能。

## 核心功能

### 1. 数据格式转换

- **JSON 转 Excel**: 将 JSON 数组或嵌套对象转换为 Excel 表格
- **结构化处理**: 自动处理嵌套 JSON，生成平面化或分层结构
- **格式保留**: 保持数据类型（字符串、数字、日期等）的一致性

### 2. 统计分析功能

- **描述性统计**: 计算均值、中位数、众数、标准差等
- **频次分析**: 统计各值出现频率
- **分组聚合**: 按指定字段分组并进行聚合运算
- **交叉分析**: 生成数据交叉表

### 3. Excel 输出特性

- **多工作表支持**: 一个 Excel 文件包含多个工作表
- **格式美化**: 自动设置表头样式、数据格式、条件格式
- **图表生成**: 可选生成数据可视化图表

## 使用方法

### 基础转换

```
用户：请将以下 JSON 数据转换为 Excel：
[
  {"name": "产品A", "price": 100, "sales": 50},
  {"name": "产品B", "price": 200, "sales": 30}
]
```

**处理流程**:

1. 解析 JSON 数据结构
2. 识别字段类型和关系
3. 生成 Excel 表格
4. 应用格式化样式

### 带统计分析的转换

```
用户：分析这份销售数据，生成包含统计信息的 Excel 报表
```

**处理流程**:

1. 数据导入与清洗
2. 执行描述性统计分析
3. 生成汇总工作表
4. 创建数据明细工作表
5. 输出完整报表

### 分组聚合分析

```
用户：按月份统计各区域的销售额和订单数
```

**处理流程**:

1. 识别分组字段（月份、区域）
2. 执行分组聚合计算（求和、计数）
3. 生成分组汇总表
4. 可选生成趋势图表

## 输入格式要求

### 支持的 JSON 结构

```json
// 数组格式
[
  {"字段1": "值1", "字段2": 123},
  {"字段1": "值2", "字段2": 456}
]

// 对象格式
{
  "data": [
    {"字段1": "值1"},
    {"字段1": "值2"}
  ],
  "metadata": {...}
}

// 嵌套格式
{
  "records": [
    {
      "id": 1,
      "details": {
        "name": "项目名",
        "values": [1, 2, 3]
      }
    }
  ]
}
```

### 数据类型支持

| JSON 类型 | Excel 格式 | 说明 |
|-----------|------------|------|
| String | 文本 | 保持字符串格式 |
| Number | 数字 | 数值型，可计算 |
| Boolean | 逻辑值 | TRUE/FALSE |
| Date | 日期 | 自动识别并格式化 |
| Array | 多值单元格 | 用逗号分隔或拆分 |
| Object | 嵌套展开 | 可选平面化或保留 |

## 输出说明

### Excel 文件结构

生成的 Excel 文件通常包含以下工作表：

1. **Data** - 原始数据或转换后的表格数据
2. **Statistics** - 统计分析结果汇总
3. **Summary** - 分组聚合汇总（如适用）

### 样式设置

- **表头行**: 蓝色背景 (#4472C4)，白色加粗字体
- **数据行**: 交替颜色，隔行变色
- **数字格式**: 千分位分隔，保留两位小数
- **条件格式**: 最高值/最低值高亮显示

## 使用场景示例

### 场景一：销售报表生成

**用户输入**:
```
将销售数据转换为 Excel，并统计每个销售员的总销售额和平均订单金额
```

**输出结果**: 包含销售明细和统计汇总的 Excel 文件

### 场景二：日志数据分析

**用户输入**:
```
分析这个 API 调用日志 JSON，统计各接口的调用次数和平均响应时间
```

**输出结果**: 接口调用统计报表 Excel

### 场景三：数据透视分析

**用户输入**:
```
根据订单数据生成透视表，按产品类别和月份展示销售额
```

**输出结果**: 多维度数据透视 Excel

## 注意事项

1. **大数据量处理**: 超过 10 万行数据时会分批处理
2. **嵌套数据**: 复杂嵌套结构会询问用户选择展开方式
3. **编码问题**: 中文数据会自动使用 UTF-8 编码
4. **文件命名**: 默认使用 "data_report_YYYYMMDD.xlsx" 格式
