# 闭眼照片睁眼复原

## 功能说明

将用户上传的闭眼照片，自动生成4种不同风格的睁眼照片，并附带文案，方便用户直接下载使用。

## 支持类型

- 人类照片（成人、儿童、老人）
- 动物照片（猫、狗、兔子等）
- 通用闭眼场景

## 工作流程

### 步骤1：接收用户上传的闭眼照片

接收用户上传的图片文件，支持格式：JPG、PNG、WebP

### 步骤2：使用 AI 图像编辑技术生成睁眼照片

调用 `image_synthesize` 工具，使用以下参数：
- prompt（核心提示词）：根据照片内容选择合适的提示词
- input_files：用户上传的照片
- 输出4个不同眼睛风格版本

### 步骤3：生成配套文案

为每张照片生成适配的文案，包括：
- 风格描述
- 使用建议
- 下载说明

## 提示词模板

### 人类照片通用
```
睁开眼睛，保持原图的发型、脸型、服装和整体风格，眼睛自然有神，与原图肤色、光线完美融合
```

### 动物照片通用
```
睁开眼睛，保持原图的毛色、体型、姿态和整体风格，眼睛明亮有神，与原图完美融合
```

### 4种风格变体

1. **自然日常**：
```
睁开眼睛，眼神自然柔和，如同日常清醒状态
```

2. **明亮有神**：
```
睁开眼睛，眼神明亮有神，光彩照人
```

3. **温柔含蓄**：
```
睁开眼睛，眼神温柔含蓄，微微带笑的感觉
```

4. **活力阳光**：
```
睁开眼睛，眼神充满活力，阳光灿烂的感觉
```

## 输出格式

生成4张睁眼照片，每张照片附带文案：

```
【风格1：自然日常】
描述：眼神自然柔和，适合日常照片
建议：适合家庭照、朋友合影

【风格2：明亮有神】
描述：眼神明亮光彩，适合证件照、写真
建议：适合正式场合、纪念照片

【风格3：温柔含蓄】
描述：眼神温柔含蓄，适合艺术照
建议：适合写真、创意照片

【风格4：活力阳光】
描述：眼神活力阳光，适合运动、户外
建议：适合旅游照、活动照
```

## 使用示例

用户说："帮我把这张闭眼的照片眼睛睁开"

回复：
1. 询问用户上传照片
2. 分析照片类型（人类/动物）
3. 生成4种风格的睁眼照片
4. 提供每张照片的文案说明
5. 提供下载选项

## 注意事项

- 确保原图清晰度足够
- 动物照片注意保持物种特征
- 复杂背景照片效果可能受影响
- 建议选择光线均匀的照片效果更好
