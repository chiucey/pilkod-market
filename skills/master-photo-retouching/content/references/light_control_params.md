# 光影控制参数详解

## 环境光分析协议

### 1. 色温映射系统

| 色温范围(K) | 光源类型 | 视觉特征 | 调整策略 |
|------------|---------|---------|---------|
| 2700-3200 | 烛光/白炽灯 | 暖橙色调 | 保持暖色倾向，可微调白平衡 |
| 3200-4500 | 荧光灯/日出日落 | 中性偏暖 | 适度还原，根据情绪需求调整 |
| 4500-5500 | 闪光灯/正午阳光 | 中性白 | 标准色彩还原基准 |
| 5500-7000 | 阴天/阴影 | 冷蓝调 | 可加强冷色以增强深度感 |
| 7000-12000 | 蓝调时刻/深阴影 | 极冷蓝 | 强化冷色用于戏剧性氛围 |

### 2. 光比计算公式

```
光比 (Lighting Ratio) = (主光EV + 补光EV) / 主光EV

理想光比参考：
- 高调人像: 1.5:1 - 2:1
- 标准人像: 2:1 - 3:1
- 戏剧人像: 4:1 - 5:1
- 艺术氛围: 5:1 - 8:1
```

### 3. 补光比例计算

```
填充比 (Fill Ratio) = 填充光强度 / 主光强度

常用补光比例：
- 自然风格: 1:2 (主光60%, 补光30%)
- 柔和风格: 1:3 (主光45%, 补光35%)
- 戏剧风格: 1:4 (主光70%, 补光20%)
- 高调风格: 1:1.5 (主光55%, 补光40%)
```

## 光质调整参数详解

### 基础曝光参数

| 参数 | 取值范围 | 调整步进 | 视觉影响 |
|------|---------|---------|---------|
| 曝光度 | ±5 EV | 0.1 EV | 整体亮度控制 |
| 对比度 | -100 至 +100 | 1 | 高光与阴影的分离程度 |
| 高光 | -100 至 +100 | 1 | 亮部细节与溢出控制 |
| 阴影 | -100 至 +100 | 1 | 暗部细节与深度 |
| 白色阶 | -100 至 +100 | 1 | 画面最亮处的定位 |
| 黑色阶 | -100 至 +100 | 1 | 画面最暗处的定位 |

### 白平衡微调参数

| 参数 | 取值范围 | 调整步进 | 视觉影响 |
|------|---------|---------|---------|
| 色温 | 2000K - 10000K | 100K | 整体冷暖倾向 |
| 色调 | -150 至 +150 | 1 | 绿色-洋红偏移 |
| 清晰度 | -100 至 +100 | 1 | 中间调细节增强 |
| 去除薄雾 | -100 至 +100 | 1 | 远景雾气处理 |

### 光影重塑技术参数

```json
{
  "center": "x,y 坐标百分比",
  "radius": 0-100,
  "feather": 0-100,
  "exposure": -5 to +5,
  "brightness": -150 to +150,
  "contrast": -100 to +100,
  "saturation": -100 to +100,
  "temperature": -150 to +150,
  "tint": -150 to +150

```

#### 线性渐变 (Linear Gradient)
```json
{
  "angle": 0-360度,
  "feather": 0-200,
  "transition": 0-100,
  "range": {
    "start": "阴影/中间调/高光",
    "end": "阴影/中间调/高光"
  },
  "adjustments": {
    "exposure": -5 to +5,
    "contrast": -100 to +100,
    "temperature": -150 to +150
  }
}
```

#### 画笔蒙版 (Brush Mask)
```json
{
  "flow": 0-100,
  "density": 0-100,
  "size": 1-500,
  "feather": 0-100,
  "autoMask": true/false,
  "concentration": 0-100
}
```

### 光晕控制参数

| 效果类型 | 参数范围 | 典型应用 |
|---------|---------|---------|
| 光晕强度 | 0-100 | 控制自然光散射效果 |
| 光晕范围 | 0-200px | 模拟镜头光晕 |
| 光晕色调 | 0-360 | 统一光晕色彩倾向 |
| 镜头眩光 | 开/关 | 模拟镜头特性 |

### 眼神光增强参数

```json
{
  "catchlightIntensity": 0-100,
  "catchlightSize": 0-100,
  "catchlightPosition": {
    "x": -100 to +100,
    "y": -100 to +100
  },

  "highlightRecovery": 0-100

```

## 光影情绪映射

| 光影模式 | 情绪传达 | 参数配置要点 |
|---------|---------|-------------|
| 高调光 | 积极、明亮、开放 | 高曝光、低对比、亮部细节丰富 |
| 低调光 | 深沉、内敛、神秘 | 低曝光、高对比、暗部保留细节 |
| 柔光 | 温柔、浪漫、亲和 | 散射光、低对比、无硬阴影 |
| 硬光 | 力量、冲突、紧张 | 定向光、高对比、深色阴影 |
| 背光 | 戏剧、轮廓、梦幻 | 主体剪影、光边效果 |
| 蝴蝶光 | 经典、优雅、专业 | 主光头顶、鼻下阴影对称 |
