# 工作总结撰写技能

## 技能说明

本技能帮助用户快速生成规范的工作总结文档，支持：
- **周工作总结**：回顾一周内的工作完成情况
- **月工作总结**：月度工作回顾与下月计划
- **年度工作总结**：全年工作汇总与展望

## 工作流程

### 步骤1：信息收集

当用户触发技能时，按以下顺序收集信息：

1. **总结类型**（必选）
   - 周工作总结
   - 月工作总结
   - 年度工作总结

2. **版本选择**（必选）
   - 简易版：精简版，突出重点成果
   - 详细版：完整结构，包含详细分析

3. **时间段**（必选）
   - 具体的时间范围，如"2024年1月15日-1月19日"

4. **工作关键词**（必选）
   - 用户提供的核心工作事项
   - 使用顿号、分号或换行分隔多个事项

5. **角色/岗位**（可选）
   - 帮助调整语言风格和专业表述

### 步骤2：内容扩展与结构化

根据用户提供的关键词，智能扩展为完整的总结内容：

**扩展维度**：
- 背景说明：为什么要做这项工作
- 目标设定：预期达成的成果
- 具体行动：采取的关键措施
- 成果数据：量化的成绩指标
- 经验总结：成功要素或改进点

### 步骤3：生成总结文档

根据版本类型生成对应格式：

## 关键词扩展规则

### 输入格式
用户可以用以下方式提供关键词：
- 顿号分隔：`项目A、项目B、任务C`
- 分号分隔：`项目A；项目B；任务C`
- 换行分隔：
  ```
  项目A
  项目B
  任务C
  ```

### 扩展逻辑

对于每个关键词，AI自动补充以下信息：

1. **工作类别识别**
   - 项目类：规划、开发、测试、上线等
   - 日常类：维护、运营、数据处理等
   - 协作类：会议、培训、评审等

2. **量化指标建议**
   - 百分比：完成率、覆盖率
   - 数量：任务数、人数
   - 时间：周期、天数

3. **成果表述优化**
   - 使用主动宾结构
   - 突出价值和贡献
   - 适当使用数据支撑

## 版本差异说明

| 维度 | 简易版 | 详细版 |
|-----|-------|-------|
| 结构 | 3-4个模块 | 7个完整模块 |
| 内容 | 要点式 | 段落式详述 |
| 表格 | 无 | 多表格支撑 |
| 问题反思 | 简略带过 | 专项分析 |
| 下期计划 | 简单列举 | 表格化任务分解 |
| 适用场景 | 快速汇报、周报 | 正式述职、总结会 |

## 输出质量标准

1. **格式规范**
   - 标题层级清晰（一、二、三...）
   - 序号使用规范（1. 1.1 1.1.1）
   - 时间格式统一

2. **语言风格**
   - 客观陈述，避免主观夸张
   - 使用正式书面语
   - 体现专业性和严谨性

3. **内容要求**
   - 数据真实可查证
   - 逻辑层次分明
   - 详略得当，重点突出

## 注意事项

1. 如用户未指定版本，默认询问偏好
2. 如关键词不足，主动询问补充
3. 年度总结应突出战略性和全局视角
4. 周/月总结应侧重执行和效率
5. 生成的总结供用户参考，可根据实际情况调整
