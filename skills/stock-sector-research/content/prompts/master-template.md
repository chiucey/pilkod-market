## 快速调用模板

### 方式一：通用调用
```
请帮我研究[市场名称]的[板块名称]，输出完整研究报告
```

### 方式二：板块特色调用
```
请帮我研究A股的[半导体/新能源/白酒]板块，
同时补充[国产替代进度/技术路线/品牌高端化]等特色分析
```

### 方式三：对比研究调用
```
请对比研究以下三个板块的估值和景气度：
1. A股[白酒板块]
2. 港股[互联网板块]
3. 美股[AI应用板块]
```
