# 快速调用指南

> 使用者只需复制对应模板，替换 `[ ]` 中的内容即可开展研究

---

## 一、标准化调用格式

### 方式一：通用调用（推荐新手）

**复制以下模板并替换内容：**

```
请帮我研究[市场名称]的[板块名称]，输出完整研究报告

市场名称：A股 / 港股 / 美股
板块名称：具体板块名称，如"白酒"、"互联网"、"半导体"
```

**示例：**
```
请帮我研究A股的白酒板块，输出完整研究报告
```

---

### 方式二：板块特色调用（深度研究）

**复制对应板块模板并替换内容：**

| 板块类型 | 模板文件 | 快速关键词 |
|---------|---------|-----------|
| 科技/互联网 | `tech-sector-template.md` | 互联网、科技、AI |
| 消费 | `consumer-sector-template.md` | 白酒、食品、消费 |
| 新能源/制造 | `new-energy-template.md` | 新能源、半导体、锂电 |

**示例：**
```
请帮我研究A股的半导体板块，同时补充国产替代进度等特色分析
```

---

### 方式三：跨市场对比调用

**复制以下模板并替换内容：**

```
请对比研究以下板块的估值和景气度：
1. A股[白酒板块]
2. 港股[互联网板块]
3. 美股[AI应用板块]
```

**示例：**
```
请对比研究以下板块的估值和景气度：
1. A股白酒板块
2. 港股互联网板块
3. 美股AI应用板块
```

## 三、必填项清单

使用任何模板时，请确保填写以下必填项：

### 基础信息
- [ ] 市场名称：A股 / 港股 / 美股
- [ ] 板块名称：具体板块名称
- [ ] 研究日期：YYYY-MM-DD

### 分析维度（可选）
- [ ] 研究深度：概览 / 深度 / 投资机会
- [ ] 是否需要产业链分析：是 / 否
- [ ] 是否需要龙头股推荐：是 / 否
- [ ] 是否需要跨市场对比：是 / 否

## 六、常见问题

**Q: 如何选择市场模板？**
A: 根据您的研究对象选择：
- 研究A股 → `a-share-template.md`
- 研究港股 → `hk-stock-template.md`
- 研究美股 → `us-stock-template.md`
- 三市场对比 → `master-template.md`

**Q: 如何选择板块类型模板？**
A: 根据板块特性选择：
- 科技/互联网公司 → `tech-sector-template.md`
- 消费品公司 → `consumer-sector-template.md`
- 制造业/新能源 → `new-energy-template.md`

**Q: 如何进行跨市场对比？**
A: 使用 `master-template.md` 中的对比研究模板，列出需要对比的板块即可

**Q: 模板中的数据如何获取？**
A: 可以配合技能的数据获取脚本，或使用搜索工具获取最新数据
