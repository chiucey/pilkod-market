# 产业链研究实战案例

## 案例一：新能源汽车产业链分析

### 1.1 产业链全景图

```
新能源汽车产业链：

[上游] 矿产资源
├── 锂矿：赣锋锂业、天齐锂业
├── 钴矿：洛阳钼业、华友钴业
├── 镍矿：格林美、盛屯矿业
└── 石墨：贝特瑞、璞泰来

[中游] 核心零部件
├── 电池材料：
│   ├── 正极：宁德时代、比亚迪
│   ├── 负极：贝特瑞、杉杉股份
│   ├── 隔膜：恩捷股份、星源材质
│   └── 电解液：天赐材料、新宙邦
├── 电池芯：宁德时代、比亚迪、中创新航
└── 电机电控：汇川技术、卧龙电驱

[下游] 整车制造
├── 纯电动：比亚迪、特斯拉、蔚来、小鹏、理想
├── 插电混动：比亚迪、理想、问界
└── 燃料电池：亿华通、重塑股份

[配套] 基础设施
├── 充电桩：特锐德、国家电网
├── 换电站：蔚来、宁德时代
└── 运营平台：滴滴、T3出行
```

### 1.2 价值链分布（微笑曲线）

```
                    附加值高

          /         \

```

### 1.3 投资机会分析

```
各环节投资价值评估：

上游矿产资源：
- 周期性明显，受价格波动影响大
- 供给刚性，龙头企业有资源壁垒
- 当前周期位置：高位回调
- 投资评级：中性，关注周期性机会

中游电池材料：
- 技术迭代快，龙头集中度高
- 成本控制能力是关键竞争力
- 当前供需：结构性过剩
- 投资评级：分化，精选龙头

下游整车制造：
- 品牌效应强，智能化是核心差异
- 竞争激烈，淘汰赛进行中
- 当前格局：比亚迪特斯拉双寡头
- 投资评级：龙头优先

基础设施：
- 重资产，回报周期长
- 政策支持，充电桩加速建设
- 当前渗透率：仍有很大空间
- 投资评级：长期配置价值
```

## 案例二：半导体产业链分析

### 2.1 产业链结构

```
半导体产业链：

[上游] 设备与材料
├── 硅片：沪硅产业、立昂微
├── 光刻胶：彤程新材、南大光电
├── 刻蚀设备：中微公司、北方华创
├── 沉积设备：北方华创、中微公司
└── 封装设备：长川科技、华峰测控

[中游] 设计、制造、封装
├── IC设计：韦尔股份、卓胜微、兆易创新
├── IC制造：中芯国际、华虹半导体
├── 封装测试：长电科技、通富微电、华天科技
└── IDM模式：士兰微、华润微

[下游] 应用领域
├── 消费电子：手机、电脑、家电
├── 汽车电子：智能驾驶、电动化
├── 工业控制：PLC、变频器
├── 通信设备：基站、路由器
└── AI算力：GPU、CPU、FPGA
```

### 2.2 国产替代机会

```
半导体各环节国产化率及机会：

环节            国产化率   投资机会
─────────────────────────────────────
芯片设计         30-40%    设计环节相对成熟
晶圆制造         20-30%    成熟制程有机会
封装测试         40-50%    技术相对成熟
半导体设备       10-15%    替代空间大，难度高
半导体材料       10-20%    替代空间大，难度高
EDA软件          <5%       高度依赖进口
```

### 2.3 投资逻辑

```
半导体投资框架：

短期催化：
□ 国产替代政策加码
□ 设备订单释放
□ 涨价周期启动

中期逻辑：
□ 技术突破带来的市场份额提升
□ 产能扩张带来的业绩增长
□ 产业链垂直整合

长期空间：
□ 自主可控是长期战略
□ 新兴应用带来增量需求
□ 全球化竞争格局重塑
```

## 案例三：医药产业链分析

### 3.1 医药产业链结构

```
医药产业链：

[上游] 原料药与中间体
├── 化学原料药：九洲药业、普洛药业
├── 生物原料：键凯科技、药明生物
└── 药用辅料：山河药辅、威尔药业

[中游] 制药与医疗器械
├── 化学制药：恒瑞医药、中国生物制药
├── 生物制药：百济神州、信达生物
├── 中药：片仔癀、云南白药、同仁堂
├── 医疗器械：迈瑞医疗、微创医疗
└── 体外诊断：安图生物、新产业

[下游] 医药流通与医疗服务
├── 医药流通：国药股份、上海医药
├── 零售药店：大参林、益丰药房
├── 医院：爱尔眼科、通策医疗
└── 互联网医疗：京东健康、阿里健康
```

### 3.2 细分领域机会

```
各细分领域投资逻辑：

创新药：
- 政策支持创新转型
- 医保谈判加速创新药放量
- 国际化是下一增长点
- 代表公司：恒瑞医药、百济神州、信达生物

医疗器械：
- 国产替代是长期主线
- 细分领域龙头有机会
- 集采影响逐步消化
- 代表公司：迈瑞医疗、微创医疗

CXO（医药外包）：
- 全球产业转移趋势
- 工程师红利优势
- 订单持续增长
- 代表公司：药明康德、泰格医药

中药：
- 政策支持中药发展
- 品牌中药有定价权
- 配方颗粒空间大
- 代表公司：片仔癀、云南白药
```

## 案例五：跨市场板块对比

### 5.1 互联网板块对比

```
中美互联网巨头对比：

A股互联网：
- 主要是细分领域龙头
- 芒果超媒、东方财富等
- 估值相对合理

港股互联网：
- 腾讯、阿里、美团、京东
- 字节跳动待上市
- 政策底部已现

美股互联网：
- 谷歌、Meta、亚马逊
- AI驱动新一轮增长
- 估值偏高但确定性强

对比总结：
- 港股互联网性价比最高
- 美股互联网成长性最强
- A股互联网防御性较好
```

### 5.2 新能源板块对比

```
全球新能源车板块对比：

中国市场：
- 渗透率最高，竞争激烈
- 比亚迪市占率领先
- 产业链完整，电池技术领先
- 投资标的：整车、电池、材料

美国市场：
- 特斯拉主导
- IRA法案支持
- 电动化加速
- 投资标的：特斯拉、电池材料

欧洲市场：
- 碳排放政策推动
- 大众、宝马转型
- 增速最快
- 投资标的：车企、充电桩

港股新能源：
- 理想、小鹏、蔚来
- 国内新势力代表
- 竞争加剧中
```
