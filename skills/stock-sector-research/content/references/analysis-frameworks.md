# 板块研究分析框架

## 一、产业链分析方法论

### 1.1 产业链定义

产业链是指在一定的技术经济联系和时空布局关系下，各产业部门之间基于特定的专业化分工和协作形成的具有层级关系的网络结构。

### 1.2 产业链分析步骤

```
第一步：绘制产业链全景图
├── 上游：原材料、零部件供应
├── 中游：生产制造、组装加工
├── 下游：渠道分销、终端应用
└── 配套：物流、金融、技术服务

第二步：识别关键环节
├── 瓶颈环节（议价能力强）
├── 核心环节（技术壁垒高）
└── 增值环节（利润丰厚）

第三步：评估价值分布
├── 微笑曲线分析
├── 利润分布测算
└── 成长性评估
```

### 1.3 产业链分析模板

```
产业链分析框架：

[上游] 原材料/零部件
    ↓ 供应关系
[中游] 生产制造
    ↓ 加工关系
[下游] 终端应用
    ↑ 服务关系
[配套] 物流/金融/技术

关键问题清单：
□ 产业链长度是多少？
□ 哪些环节是瓶颈？
□ 利润在哪些环节集中？
□ 技术壁垒在哪里？
□ 哪些环节容易整合？
□ 产业转移趋势如何？
```

## 二、波特五力分析框架

### 2.1 五力模型说明

```
供应商议价能力：
- 集中度 vs 买方集中度
- 替代品供应情况
- 供应量对买方的重要性
- 前向整合能力

购买者议价能力：
- 买方数量和集中度
- 转换成本
- 价格敏感性
- 后向整合能力

新进入者威胁：
- 规模经济
- 品牌认知
- 渠道控制
- 政策壁垒
- 资本需求

替代品威胁：
- 替代品性价比
- 用户转换成本
- 替代品研发趋势

行业内竞争：
- 竞争者数量和实力
- 行业增长情况
- 固定成本比例
- 产品差异化
- 退出壁垒
```

## 三、板块轮动分析框架

### 3.1 美林时钟模型

```
经济周期 → 板块轮动：

复苏期（低通胀+高增长）：
→ 股票 > 债券 > 现金 > 大宗商品
→ 周期性行业受益：科技、可选消费

过热期（高通胀+高增长）：
→ 大宗商品 > 股票 > 现金 > 债券
→ 周期性行业：原材料、能源、有色

滞胀期（高通胀+低增长）：
→ 现金 > 大宗商品 > 债券 > 股票
→ 防御性行业：公用事业、医疗、必需消费

衰退期（低通胀+低增长）：
→ 债券 > 现金 > 股票 > 大宗商品
→ 防御性行业：消费、医疗、金融
```

### 3.2 A股风格轮动规律

```
年度风格特征：
- 春季（1-3月）：政策预期主导，关注科技、新能源
- 夏季（4-6月）：业绩验证期，关注绩优白马
- 秋季（7-9月）：中报行情，关注成长股
- 冬季（10-12月）：估值切换，关注明年预期

资金风格：
- 北向资金：偏好大盘蓝筹、核心资产
- 公募基金：偏好成长、赛道股
- 私募基金：偏好弹性、主题投资
- 散户：偏好热点、概念炒作
```

### 3.3 板块轮动信号识别

```
领先指标：
□ 宏观政策转向（货币政策、财政政策）
□ 利率走势变化
□ 汇率波动
□ 大宗商品价格

同步指标：
□ 板块成交量放大
□ 板块涨跌家数比
□ 主力资金净流入
□ 融资融券变化

滞后指标：
□ 机构持仓变化
□ 分析师评级调整
□ 业绩报告兑现
□ 估值修复/泡沫化
```

## 四、龙头股识别框架

### 4.1 龙头股分类

```
绝对龙头：
- 市占率第一
- 定价权最强
- 行业标杆
- 抗风险能力强

细分龙头：
- 子行业市占率领先
- 技术/渠道/品牌壁垒
- 成长性突出

隐形冠军：
- 细分市场占有率极高
- B2B业务为主
- 全球市场布局
- 低调但实力强
```

### 4.2 龙头股评估指标

```
规模指标：
□ 市值排名（行业内）
□ 营收规模
□ 净利润规模

质量指标：
□ ROE水平及稳定性
□ 毛利率水平
□ 现金流质量
□ 应收账款管理

成长指标：
□ 营收增速
□ 净利润增速
□ 市占率提升趋势
□ 新业务拓展能力

壁垒指标：
□ 专利数量和质量
□ 品牌知名度
□ 渠道控制力
□ 客户粘性

估值指标：
□ PE相对行业溢价
□ PB水平
□ EV/EBITDA
□ PEG
```

## 五、政策分析框架

### 5.1 政策分类

```
顶层政策：
├── 五年规划
├── 国家战略（科技自立、内循环）
└── 重大改革（注册制、国企改革）

产业政策：
├── 支持类（补贴、税收优惠）
├── 规范类（行业标准、环保要求）
└── 限制类（产能限制、准入门槛）

货币政策：
├── 利率政策
├── 流动性管理
└── 汇率政策

财政政策：
├── 税收政策
├── 支出政策
└── 政府投资
```

### 5.2 政策影响评估

```
政策评估矩阵：

| 政策类型 | 影响范围 | 影响程度 | 持续时间 | 受益板块 |
|---------|---------|---------|---------|---------|
| 产业补贴 | 特定行业 | 高 | 中期 | 直接受益 |
| 环保政策 | 高污染行业 | 高 | 长期 | 供给侧改革 |
| 消费刺激 | 消费行业 | 中 | 短期 | 终端需求 |
| 科技支持 | 科技行业 | 高 | 长期 | 研发投入 |
| 房地产调控 | 地产链 | 高 | 长期 | 负面影响 |
```

## 六、跨市场比较框架

### 6.1 A股 vs 港股 vs 美股

```
市场特征对比：

A股特点：
- 散户占比高，波动大
- 政策影响显著
- 新兴行业估值溢价
- 退市制度不完善

港股特点：
- 机构为主，估值理性
- 受外围市场影响大
- 新经济占比提升
- 做空机制完善

美股特点：
- 全球定价中心
- 科技股主导
- 盈利驱动增长
- 完善的做空机制
```
