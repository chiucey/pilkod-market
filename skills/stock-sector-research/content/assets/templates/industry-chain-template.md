# 产业链图谱模板

## 使用说明

本模板用于绘制和分析产业链上下游关系，帮助投资者理解产业结构和价值分布。

---

## 产业链图谱绘制规范

### 基本结构

```
                    研发设计
                       ↑
                       │
    ┌──────────────────┼──────────────────┐
    │                  │                  │
    │                  ▼                  │
[上游]────────────[中游]────────────[下游]
原材料/零部件       生产制造          终端应用
    │                  │                  │
    │                  │                  │
    └──────────────────┴──────────────────┘
                       │
                       ▼
                    服务配套
                  物流/金融/技术
```

### 图例说明

| 符号 | 含义 | 示例 |
|-----|------|------|
| ● | 核心环节 | 电池芯 |
| ○ | 配套环节 | 设备制造 |
| → | 物料流向 | 锂矿→正极材料 |
| ⟲ | 资金流向 | 下游→上游 |
| ★ | 高壁垒环节 | 半导体设备 |
| ◆ | 高利润环节 | 品牌溢价 |

## 产业链分析 Checklist

### 上游分析
- [ ] 主要原材料是什么？
- [ ] 原材料供应集中度如何？
- [ ] 价格波动对中下游影响？
- [ ] 是否有替代材料？

### 中游分析
- [ ] 核心制造环节是什么？
- [ ] 技术壁垒有多高？
- [ ] 产能扩张周期？
- [ ] 成本结构如何？

### 下游分析
- [ ] 主要应用领域？
- [ ] 终端需求增速？
- [ ] 渠道结构？
- [ ] 品牌溢价能力？

### 配套服务
- [ ] 物流配套是否完善？
- [ ] 金融服务支持？
- [ ] 技术服务需求？
- [ ] 信息流整合？
