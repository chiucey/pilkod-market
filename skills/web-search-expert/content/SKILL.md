# 超级搜索专家

## 任务目标

- 本 Skill 用于：从互联网海量信息中精准检索、验证并整合高质量内容
- 能力包含：多源信息检索、权威来源识别、交叉验证、结构化输出
- 触发条件：用户需要查询政策法规、新闻资讯、学术研究、行业数据、人物事件等任何需要可靠信息来源的场景

## 核心原则

- **来源可靠**：优先政府官网、权威媒体、学术期刊等可信来源
- **信息全面**：多维度搜索，不遗漏重要信息，提供完整视角
- **格式美观**：结构清晰、层次分明、易于阅读
- **内容准确**：交叉验证、标注来源、确保真实性

## 搜索策略（分层次搜索法）

### 第一层：官方权威来源
优先级最高，适用于政策、法规、统计数据等

1. **政府机构网站**
   - 国务院及各部委官网（www.gov.cn）
   - 地方政府门户网站
   - 政府信息公开平台
   - 官方新闻发布会

2. **事业单位网站**
   - 新华网（www.xinhuanet.com）
   - 人民网（www.people.com.cn）
   - 央视网（www.cctv.com）
   - 中国政府网

### 第二层：权威媒体来源
适用于新闻事件、社会热点、深度报道

1. **主流媒体**
   - 中央媒体：人民日报、新华社、光明日报、经济日报等
   - 省级党报：各地日报、晚报等
   - 行业媒体：各领域专业媒体

2. **正规新闻网站**
   - 中国新闻网、澎湃新闻、界面新闻
   - 各地新闻网、主流门户网站新闻频道

3. **排名网站**
   - 权威榜单发布机构
   - 政府认可的评估网站
   - 行业协会发布平台

### 第三层：学术专业来源
适用于研究数据、学术论文、专业分析

1. **学术期刊**
   - 中国知网、万方数据、维普期刊
   - 各大学学报、专业期刊
   - 国际学术数据库

2. **科研机构**
   - 中科院、社科院等研究机构官网
   - 高校研究院、智库报告
   - 行业研究院白皮书

### 第四层：社交媒体来源
补充视角、实时信息、公众观点

1. **微信公众号**
   - 政府官方公众号
   - 主流媒体公众号
   - 行业专家公众号

2. **视频号/短视频**
   - 官方媒体视频号
   - 政务新媒体
   - 行业KOL

3. **知识平台**
   - 知乎专业回答
   - 百度百科（需验证）
   - 行业论坛

## 执行步骤

### 步骤1：需求分析与关键词提取
- 理解用户真实需求
- 提取核心关键词
- 确定搜索范围和深度
- 选择合适的来源层次

### 步骤2：系统性搜索
- 使用 `web_search` 工具进行检索
- 按优先级从第一层到第四层逐步搜索
- 每层使用多个关键词组合
- 记录重要信息来源

**搜索技巧**：
- 使用精确匹配：关键词加引号 `"政策名称"`
- 限定时间范围：添加年份 `2024年`
- 限定网站：使用 `site:gov.cn`
- 排除干扰：使用减号 `-广告`

### 步骤3：信息验证与交叉核实
- 对关键信息进行多源验证
- 优先采用官方来源信息
- 标注信息来源和发布时间
- 对矛盾信息进行说明

### 步骤4：信息整合与结构化
- 按逻辑顺序组织信息
- 提取核心观点和数据
- 保持信息完整性
- 建立清晰的信息层次

### 步骤5：格式化输出
- 选择合适的输出模板（见资产模板）
- 使用清晰的标题层级
- 保持段落间距合理
- 重点内容加粗或列表展示

## 输出格式规范

### 基本结构
```
# 主题标题

## 概述
简要总结核心信息（2-3句话）

## 详细内容

### 子主题1
内容要点...

### 子主题2
内容要点...

## 数据支撑
- 关键数据1
- 关键数据2

## 来源列表
1. 来源名称 - 具体链接 - 发布时间
2. ...

## 备注
补充说明、注意事项等
```

### 格式要求
- 标题层级不超过4级
- 段落之间空一行
- 列表项对齐整齐
- 重要信息加粗标注
- 来源链接完整准确

## 注意事项

1. **时效性判断**：优先最新信息，注意信息发布时间，标注时效性
2. **来源可信度**：优先 .gov.cn、官方媒体、学术期刊，谨慎使用自媒体信息
3. **信息完整性**：不遗漏重要信息，提供多维度视角
4. **客观中立**：如实呈现信息，避免主观解读，对争议信息标注多方观点
5. **版权意识**：大段引用注明出处，优先提炼和整合

## 使用示例

### 示例1：政策查询
**用户需求**：查询2024年新能源汽车补贴政策

**执行流程**：
1. 关键词：`"新能源汽车补贴" 2024 site:gov.cn`
2. 优先来源：工信部、财政部、发改委官网
3. 补充来源：新华社、经济日报等权威媒体解读
4. 输出：政策要点+适用范围+补贴标准+申请流程+来源链接

### 示例2：新闻事件调查
**用户需求**：了解某社会热点事件的真相

**执行流程**：
1. 多关键词组合搜索
2. 官方通报优先（政府发布会、官方公众号）
3. 权威媒体报道（央视、新华社、人民日报）
4. 多方观点呈现
5. 输出：事件经过+各方说法+时间线+最新进展

### 示例3：学术资料收集
**用户需求**：查找某领域的研究现状

**执行流程**：
1. 学术数据库检索
2. 知网、万方等平台搜索
3. 行业报告、白皮书
4. 专家学者观点
5. 输出：研究综述+主要观点+数据支撑+参考文献
