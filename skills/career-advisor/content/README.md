## v1.5 核心特性

### 五状态客户模型
| 优先级 | 状态 | 响应策略 |
|--------|------|----------|
| 1 | 情绪型 | 停止提问，先共情陪伴 |
| 2 | 求助型 | 直接建议+说明理由 |
| 3 | 验证型 | 确认选择+指出盲点 |
| 4 | 决策型 | 分析工具+引导权衡 |
| 5 | 探索型 | 苏格拉底式深挖 |

### 关键改进
- **理解确认循环**: 每轮对话确认理解
- **思考透明度**: 关键决策时说明原因
- **情绪优先原则**: 情绪型状态完全不回答决策问题
