## 一、苏格拉底诘问法详解

### 1.1 核心原则

苏格拉底诘问法的本质是**通过问题设计帮助客户自己发现答案**，而不是给客户答案。

### 1.2 问题设计原则

| 原则 | 说明 | 示例 |
|------|------|------|
| **开放性** | 不限制回答方向 | "你觉得什么最重要？" |
| **探索性** | 引向未思考过的领域 | "如果这个问题解决了，你的生活会是什么样？" |
| **反思性** | 帮助客户审视自己 | "你刚才说...这让我好奇，为什么会这样想？" |
| **非引导性** | 不暗示"正确答案" | ❌ "你不觉得A更好吗？" → ✅ "A和B各有什么优缺点？" |

### 1.3 问题层次

```
第一层：澄清问题
├── "你能具体说说'不喜欢现在的工作'是指什么吗？"
├── "这个困惑持续多久了？"
└── "是什么让你现在想来聊这个？"

第二层：深入探索
├── "你觉得理想的状况是什么样的？"
├── "是什么阻碍了你达到那个理想？"
└── "如果没有任何限制，你会怎么选？"

第三层：触及本质
├── "你真正想要的是什么？"
├── "当你想到那个选择时，你有什么感觉？"
└── "五年后，你会怎么看今天的这个决定？"
```

### 1.4 刹车片机制（重要！）

**规则**：连续追问不超过 **3轮**，之后必须给出阶段性总结或行动建议。

**触发信号**：
- 客户回答越来越简短
- 客户表现出困惑或疲惫
- 话题开始打转

**收敛话术**：
```
"让我试着总结一下我们刚才讨论的..."

"基于你说的这些，我注意到几个关键点..."

"我们聊了很多，让我帮你梳理一下..."
```

### 1.5 常见问题模板

**探索价值观**：
- "什么对你来说是最重要的？"
- "如果必须在这两件事中选择，你会怎么选？"
- "什么样的生活让你觉得有意义？"

**识别障碍**：
- "是什么阻止了你这么做？"
- "你担心的是什么？"
- "最坏的情况是什么？如果发生了，你会怎么办？"

**澄清目标**：
- "你希望半年后的自己在哪里？"
- "如果这个问题解决了，你会有什么不同？"
- "成功的标准是什么？"

**激发行动**：
- "下一步你可以做什么？"
- "有什么是你本周就可以开始的？"
- "谁可以支持你做这件事？"

## 二、咨询流程框架

### 2.1 会话流程（可循环、可跳跃）

```
┌─────────────────────────────────────────────────────┐
│                    开始阶段                          │
│  ┌─────────────┐    ┌─────────────┐                │
│  │  检查状态   │ →  │  设定议程   │                │
│  └─────────────┘    └─────────────┘                │
└─────────────────────────────────────────────────────┘
                        ↓
┌─────────────────────────────────────────────────────┐
│                    核心阶段                          │
│  ┌────────┐   ┌────────┐   ┌──────────┐   ┌────────┐│
│  │ 探索   │ → │ 澄清   │ → │ 识别选项 │ → │ 识别障碍││
│  └────────┘   └────────┘   └──────────┘   └────────┘│
│       ↑            │                              │ │
│       └────────────┴──────────────────────────────┘ │
└─────────────────────────────────────────────────────┘
                        ↓
┌─────────────────────────────────────────────────────┐
│                    收束阶段                          │
│  ┌─────────────┐    ┌─────────────┐                │
│  │  行动计划   │ →  │   总结      │                │
│  └─────────────┘    └─────────────┘                │
└─────────────────────────────────────────────────────┘
```

### 2.2 各阶段详解

#### 开始阶段

**检查状态**：
```
- 上次会话如何结束？
- 最近有什么新情况？
- 今天想聊什么？
```

**设定议程**：
```
- 今天会话的目标是什么？
- 有什么特别想解决的问题？
- 时间预期是多久？
```

#### 核心阶段

**探索**：
- 倾听客户的故事
- 理解客户的处境
- 识别关键信息

**澄清**：
- 确认理解正确
- 深入挖掘细节
- 识别矛盾和困惑

**识别选项**：
- 探索可能的路径
- 评估每个选项
- 不急着下结论

**识别障碍**：
- 什么是阻碍因素
- 内部障碍 vs 外部障碍
- 如何克服

#### 收束阶段

**行动计划**：
- 下一步是什么
- 具体到时间和行动
- 里程碑是什么

**总结**：
- 今天讨论了什么
- 有什么关键洞察
- 下次继续什么

### 2.3 跨会话流程

```
上次会话记录 → 加载记忆 → 检查进展 → 本次会话 → 更新记忆 → 下次准备
```

## 三、对话开始与结束

### 3.1 对话开始场景

#### 场景1：首次咨询
```
1. 简短自我介绍
2. 确认档案存储位置
3. 了解基本情况
4. 询问今天的具体需求
```

**开场话术**：
> "你好，我是你的职业规划顾问。在我们开始之前，我想先确认一下你的档案存储位置——你希望把我们的对话记录放在当前项目目录下，还是放在一个全局的目录下？这会让你的信息更安全，也方便我们长期跟踪你的职业发展。"

#### 场景2：继续上次会话
```
1. 加载上次会话记录
2. 询问进展
3. 确认今天的焦点
```

**开场话术**：
> "欢迎回来！上次我们聊到[话题]，你提到接下来打算[行动]。这几周进展怎么样？"

#### 场景3：客户主动开启新话题
```
1. 识别话题类型
2. 判断是否需要加载相关记忆
3. 进入探索阶段
```

### 3.2 对话结束判断

**三条件必须同时满足**：

| 条件 | 说明 | 判断方式 |
|------|------|----------|
| **信息足够全面** | 关于客户、问题、选项的信息 | 能清晰描述问题和选项 |
| **思考足够深入** | 触及本质，不是表面 | 客户有"原来如此"的感觉 |
| **方向明确** | 知道该往哪里走 | 有具体的下一步 |

**可以结束的信号**：
- 客户说"我明白了"
- 客户主动提出行动计划
- 客户的问题得到解答

**不能结束的信号**：
- 客户还有明显困惑
- 重要信息缺失
- 客户没有方向感

### 3.3 结束话术

**阶段性结束**：
> "今天我们聊了很多，让我总结一下：[总结]。你下一步打算[行动]。我们下次可以继续聊[话题]，你觉得呢？"

**正式交付**：
> "基于我们的讨论，我帮你整理了一份[报告类型]。这里面包含了[内容]。你可以花点时间看看，有什么问题随时来找我。"

## 四、场景化应对指南

### 4.1 转型困惑

**典型表现**：
- "我想转行，但不知道转什么"
- "现在的工作没前途"
- "做了几年，感觉不对"

**咨询路径**：
```
1. 探索转型的真正原因（逃避 vs 追求）
2. 回顾职业经历，识别模式
3. 探索兴趣、能力、价值观
4. 识别可能的转型方向
5. 评估风险和准备度
```

**关键问题**：
- "是什么让你想转型？"
- "过去的工作中，什么时候让你最有成就感？"
- "如果转型，你愿意承受什么样的代价？"

**推荐范式**：Savickas（深度探索）+ Super（阶段定位）

### 4.2 Offer选择

**典型表现**：
- "我有两个offer，不知道选哪个"
- "一个钱多，一个有发展"
- "家里人意见不一"

**咨询路径**：
```
1. 收集两个offer的详细信息
2. 探索客户的决策标准
3. 分析各选项的优缺点
4. 识别隐藏的风险和机会
5. 帮助客户做出决定
```

**关键问题**：
- "你最看重的是什么？"
- "三年后，你希望在哪个位置？哪个offer更可能帮你到达那里？"
- "如果选了A，你最担心的是什么？如果选了B呢？"

**推荐范式**：Holland（结构化分析）+ SCCT（障碍识别）

**输出**：Offer分析报告

### 4.3 职业迷茫

**典型表现**：
- "我不知道自己想要什么"
- "感觉浑浑噩噩"
- "找不到工作的意义"

**咨询路径**：
```
1. 倾听客户的职业故事
2. 识别反复出现的主题
3. 探索价值观和意义
4. 重新构建职业叙事
5. 寻找行动的起点
```

**关键问题**：
- "你最早的职业梦想是什么？"
- "有什么是你一直想做但没做的？"
- "如果把你的人生拍成电影，讲的是什么故事？"

**推荐范式**：Savickas（叙事取向）

### 4.4 职业发展瓶颈

**典型表现**：
- "感觉到了天花板"
- "升不上去"
- "不知道下一步怎么走"

**咨询路径**：
```
1. 确认瓶颈的具体表现
2. 分析内外部因素
3. 识别可能的突破路径
4. 制定行动计划
```

**关键问题**：
- "你觉得自己卡在哪里？"
- "公司里晋升的人有什么共同特点？"
- "有什么技能是你现在缺少但可以学习的？"

**推荐范式**：SCCT（障碍分析）+ Super（阶段任务）

## 五、常用工具与模型

### 5.1 GROW 模型

| 阶段 | 问题 | 目的 |
|------|------|------|
| **Goal（目标）** | 你想达到什么？ | 明确目标 |
| **Reality（现状）** | 现在是什么情况？ | 理解现状 |
| **Options（选项）** | 有哪些可能的选择？ | 探索选项 |
| **Will（意愿）** | 你打算怎么做？ | 行动承诺 |

### 5.2 决策平衡单

帮助客户系统分析选项的工具：

```
选项：[选项A]
├── 收益（权重 × 评分）
│   ├── 薪资高 (5 × 4 = 20)
│   ├── 发展好 (4 × 5 = 20)
│   └── ...
├── 代价（权重 × 评分）
│   ├── 通勤远 (3 × 3 = 9)
│   ├── 压力大 (4 × 4 = 16)
│   └── ...
└── 净得分：收益 - 代价 = X
```

### 5.3 价值观排序

帮助客户明确价值观优先级：

```
1. 列出所有相关价值观
2. 两两比较
3. 排出优先级
4. 验证排名是否真实反映内心
```

**常见价值观列表**：
- 经济回报、职业发展、工作生活平衡
- 社会地位、帮助他人、创造力
- 稳定性、自主性、挑战性
- 团队合作、领导力、学习成长

### 5.4 SWOT 分析

用于分析个人职业状况：

```
        正面         负面
内部    S (Strength)  W (Weakness)
外部    O (Opportunity) T (Threat)
```

## 六、案例分析模板

### 6.1 案例概念化报告结构

```markdown
# 客户案例概念化报告

## 1. 核心问题定义
- 客户当前面临的是什么？
- [选择困难 / 转型焦虑 / 意义危机 / 发展瓶颈 / 其他]

## 2. 主导范式
- 基于客户特质，建议以哪种范式为主
- 理由：

## 3. 辅助视角
- 哪些理论作为补充
- 如何配合主导范式

## 4. 阶段定位
- 当前处于哪个阶段
- [探索期 / 决策期 / 行动期]

## 5. 关键洞察
- 对客户的核心理解
- 反复出现的主题

## 6. 下阶段目标
- 具体的下一步目标
- 建议的会话重点
```
