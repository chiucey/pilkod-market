## 佣金类型详细说明

### 1. 比例佣金
- **定义**：按成交金额的一定比例计算佣金
- **计算公式**：佣金 = 成交总价 × 佣金比例
- **适用场景**：基础佣金、团队奖励等

### 2. 固定奖励
- **定义**：每套或每次满足条件时发放的固定金额
- **计算公式**：佣金 = 套数 × 单套金额
- **适用场景**：首单奖励、活动激励等

### 3. 阶梯奖励
- **定义**：按销售业绩阶梯递增的奖励
- **计算公式**：根据累计套数或金额确定阶梯档次
- **示例**：
  - 1-5套：2000元/套
  - 6-10套：3000元/套
  - 11套以上：5000元/套

### 4. 现金奖励
- **定义**：特定活动或条件的即时现金奖励
- **计算公式**：条件触发即发放固定金额
- **适用场景**：国庆首单激励、开盘当天签约奖励等

### 5. 溢价分成
- **定义**：超出底价或指导价的溢价部分按比例分成
- **计算公式**：佣金 = (成交总价 - 底价) × 分成比例
- **适用场景**：溢价房源销售奖励

## 角色定义

| 角色 | 说明 | 常见佣金规则 |
|-----|------|------------|
| 置业顾问 | 一线销售人员，直接对接客户 | 基础佣金、成交奖励 |
| 高级置业顾问 | 资深销售人员 | 基础佣金、进阶奖励 |
| 销售主管 | 团队管理者 | 团队管理佣金、团队业绩奖励 |
| 销售经理 | 项目销售负责人 | 项目整体佣金、管理奖励 |
| 项目经理 | 项目负责人 | 项目奖金、利润分成 |

## 触发条件示例

| 条件类型 | 示例 | 说明 |
|---------|------|------|
| 首单条件 | 首单奖励500元/套 | 当月/活动期间第一套成交 |
| 付款方式 | 全款奖励、按揭无奖励 | 按付款方式区分 |
| 时间条件 | 国庆期间签约额外奖励 | 特定时间段 |
| 户型条件 | 126㎡以上户型奖励 | 特定户型 |
| 面积条件 | 大户型额外奖励 | 按面积段 |
| 优惠条件 | 无折扣成交奖励 | 无优惠订单 |

## 排除范围示例

| 排除类型 | 说明 | 处理方式 |
|---------|------|---------|
| 退房订单 | 退款退房 | 不计算佣金，已发佣金追回 |
| 换房订单 | 换房变更 | 重新计算佣金 |
| 特价房 | 一口价房源 | 使用特价房专属规则 |
| 工抵房 | 工程抵款房源 | 按特殊协议处理 |
| 员工房 | 内部员工购房 | 按员工购房政策 |
| 渠道房 | 渠道带客成交 | 渠道佣金单独计算 |

## 规则优先级定义

| 优先级 | 说明 | 冲突处理 |
|-------|------|---------|
| 1 | 最高优先级 | 覆盖其他规则 |
| 2 | 高优先级 | 优先级1规则除外 |
| 3 | 标准优先级 | 默认执行 |
| 4 | 低优先级 | 仅当无其他规则时执行 |

## 佣金计算示例

### 示例1：基础比例佣金
```
规则：成交总价 × 3%
销售数据：房间A-101，成交总价100万元
计算：100万 × 3% = 3万元
```

### 示例2：固定奖励
```
规则：126㎡以上户型额外奖励3000元/套
销售数据：房间B-201，面积135㎡
计算：1套 × 3000元 = 3000元
```

### 示例3：阶梯奖励
```
规则：
  - 1-5套：2000元/套
  - 6-10套：3000元/套
  - 11套以上：5000元/套

销售数据：置业顾问张三本月成交8套
计算：5套 × 2000 + 3套 × 3000 = 10000 + 9000 = 19000元
```

### 示例4：溢价分成
```
规则：超出底价部分 × 20% 分成
销售数据：房间C-301，底价80万，成交价95万
计算：(95万 - 80万) × 20% = 15万 × 20% = 3万元
```
