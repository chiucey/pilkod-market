# Nano PDF Skill

轻量级、无外部网络依赖的纯本地PDF处理技能，适配Minimax Agent。

## 核心功能

1. PDF文本内容提取
2. PDF元数据读取（标题、作者、页数、创建时间等）
3. PDF多文件合并
4. PDF单文件按页码拆分
5. PDF指定页面提取
6. 本地文件读写，不上传任何数据

## 技术特性

- 无OpenClaw依赖
- 无外部网络请求
- 纯Python本地处理
- 基于pypdf官方库
- 支持标准PDF格式

## 使用方式

对话中直接触发：
- 提取这个PDF的文本
- 查看PDF的元数据
- 合并这几个PDF文件
- 把PDF拆分成单独页面
- 提取PDF的第1-5页

## 权限说明

- read:file：读取本地PDF文件
- write:file：输出处理后的PDF/文本文件
- network:false：禁止访问外部网络

## 依赖

Python 3.8+
pypdf>=4.0.0

## 约束条件

- 仅处理标准PDF文件，不支持加密/损坏PDF
- 所有操作本地完成，不上传任何数据
- 不修改原始PDF文件，只输出新文件
- 禁止访问外部网络
- 页码从1开始计算
- 保护用户文件隐私
