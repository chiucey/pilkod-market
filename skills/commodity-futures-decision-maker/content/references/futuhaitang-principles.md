# 傅海棠投资理念核心要点

## 一、核心投资哲学

傅海棠是中国期货市场的传奇人物，以"现货调研+供需周期"的价值投资方法著称。其核心理念可概括为：

### 1.1 做便宜生意
- **低价买入**：等待价格跌至成本线附近或以下，行业普遍亏损时入场
- **高价卖出**：等待价格涨至暴利区域，产能大规模扩张后离场
- **不做中间段**：价格处于中位时，减少交易，专注等待极端机会

### 1.2 供需决定一切
- 价格上涨的终极原因是供不应求
- 价格下跌的终极原因是供过于求
- 技术分析只能辅助择时，不能预测方向

### 1.3 从产业出发
- 深入产业链调研，了解真实的供需状况
- 关注上游（原材料）、中游（加工）、下游（消费）的利润分配
- 库存是供需关系的滞后指标，需综合判断

## 二、五因子评分体系详解

### 因子1：低价格（0-2分）
```
2分：价格 ≤ 成本线，行业深度亏损（企业大面积停产）
1分：价格在成本线附近，利润微薄
0分：价格远离成本，行业暴利
```

### 因子2：低库存（0-2分）
```
2分：库存极低，市场"一货难求"，现货升水明显
1分：库存偏低，去库趋势
0分：库存累积，货满为患
```

### 因子3：负利润（0-2分）
```
2分：产业链上游深度亏损，持续减产
1分：利润微薄，勉强维持
0分：暴利状态，刺激扩产
```

### 因子4：需求好（0-2分）
```
2分：需求超预期，淡季不淡，旺季更旺
1分：需求平稳
0分：需求疲软，下游采购谨慎
```

### 因子5：高价差（0-2分）
```
2分：现货升水，期货深度贴水，错价明显
1分：基差中性
0分：期货升水，预期过于乐观
```

## 三、傅海棠式机会模板

### A级机会（8-10分）
同时满足以下多个条件：
- ✅ 价格低位/接近成本
- ✅ 行业亏损/利润微薄
- ✅ 去库存进行中
- ✅ 现货表现强于期货
- ✅ 供需关系即将/正在拐点

### B级机会（5-7分）
满足部分条件，但证据不够充分：
- 可能有价格低位但需求未启动
- 可能有供需缺口但价格已涨一段
- 需要等待触发条件确认

### C级机会（0-4分）
不符合傅海棠体系：
- 价格不高不低
- 库存偏高
- 利润正常
- 现货不强
- 供需无明显矛盾

## 五、分析推理链模板

### 偏多逻辑链示例
```
低价 + 亏损 → 产能收缩/减产 → 供应减少
↓
需求平稳/增长 → 去库存化
↓
库存降至低位 → 现货紧张
↓
现货率先涨价 → 期货贴水
↓
供需拐点确认 → 价格回归
```

### 偏空逻辑链示例
```
高价 + 暴利 → 产能扩张/复产 → 供应增加
↓
需求受抑/下滑 → 累库
↓
库存升至高位 → 现货压力
↓
现货率先跌价 → 期货升水
↓
供需拐点确认 → 价格回落
```

## 六、常见误区提醒

1. **❌ 不能只看技术图形做多/做空**
   - 技术指标反映的是过去，不能预测未来供需

2. **❌ 不能在暴利时追多**
   - 高利润 = 未来供应增加 = 下跌风险

3. **❌ 不能在亏损时杀跌做空**
   - 低利润 = 未来供应减少 = 上涨机会

4. **❌ 不能忽视库存变化**
   - 库存是供需博弈的结果，不是原因

5. **❌ 不能轻信单一数据源**
   - 需交叉验证：现货、期货、库存、利润、基差
