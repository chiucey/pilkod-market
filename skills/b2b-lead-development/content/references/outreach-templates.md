## 1. 标准邮件模板

### 模板A: 直接切入型

**适用场景**: 有明确采购需求的公司

```

Hi [姓名],

I noticed that [对方公司名] has been expanding in [对方市场/行业] market, and we're specialized in [产品名] with 10+ years of experience serving [对方市场] clients.

What makes us different:
✓ [核心优势1，如：我们是[对方市场]多家知名品牌的OEM供应商]
✓ [核心优势2，如：产品通过CE/FCC/RoHS认证]
✓ [核心优势3，如：支持小批量定制，最MOQ 100pcs]

I'd love to share how we've helped similar companies in [对方市场] reduce costs by 20-30% while maintaining quality.

Would you be open to a 15-minute call this week to discuss your specific needs?

Best regards,
[你的名字]
[职位]
[公司名]
[手机号]
[WhatsApp/微信]
```

## 3. 邮件主题行优化

### 高打开率主题行类型

| 类型 | 示例 |
|------|------|
| 提问式 | "Are you looking for [产品] suppliers?" |
| 价值式 | "[产品名] Solution - Save 30% on [对方产品]" |
| 个性化 | "[对方公司名] Custom Quote Inside" |
| 好奇心 | "Quick question about your [产品线]" |
| 紧迫感 | "Limited availability for [日期]" |
| 社交证明 | "Working with [知名客户] - Here's why" |

### 避免使用
- "我们是专业[产品]制造商"（太泛）
- "Please find attached"（无聊）
- 全大写标题
- 过多标点符号
- 明显的推销语气

## 4. 话术个性化要点

### 必须个性化的地方
1. **对方公司名** - 每封必用
2. **对方市场/行业** - 展示研究
3. **对方产品线** - 展示了解
4. **联系人姓名** - 确认拼写正确
5. **对方动态** - 提及最近新闻/活动

### 话术风格调整
- **美国人**: 直接、自信、强调数据和结果
- **欧洲人**: 正式、专业、重视流程
- **墨西哥/西班牙语**: 友好、建立关系、适当使用西班牙语问候
- **中东人**: 耐心、建立信任、强调长期关系
- **东南亚人**: 友好、灵活、重视人际关系
- **非洲人**: 直接、务实、重视性价比

## 5. 跟进节奏

| 阶段 | 时间点 | 方式 | 内容 |
|------|--------|------|------|
| 第1次 | 即时 | 邮件+WhatsApp | 标准开发信 |
| 第2次 | 3天后 | 邮件 | 价值内容+追问 |
| 第3次 | 7天后 | WhatsApp | 简短私信 |
| 第4次 | 14天后 | 邮件 | 替代方案/市场报告 |
| 第5次 | 30天后 | 邮件 | 激活邮件 |
| 第6次 | 60天后 | 最终 | 冷淡激活 |
| 停止 | 90天后 | - | 移入休眠列表 |

## 6. 多语言话术片段

### 西班牙语（墨西哥/拉美）

**问候**:
```
Hola [Nombre],
Buenos días/tardes [Nombre],
```

**开场**:
```
Vi su empresa en línea y me impresionó...
Nos especializamos en [产品] para el mercado [国家].
Creemos que podríamos ser un buen socio para su empresa.
```

**结尾CTA**:
```
¿Estaría interesado en una llamada breve?
¿Podemos enviarle nuestro catálogo?
Quedamos atentos a sus comentarios.
```

### 德语（德国/奥地利/瑞士）

**问候**:
```
Sehr geehrte/r [Name],
Guten Tag [Name],
```

**开场**:
```
Wir sind auf [产品] spezialisiert und bedienen den [国家] Markt seit über 10 Jahren.
Ihre Firma ist uns durch [来源] aufgefallen.
Wir könnten Ihnen bei [痛点] helfen.
```

**结尾CTA**:
```
Wäre ein kurzes Gespräch diese Woche möglich?
Dürfen wir Ihnen unseren Katalog zusenden?
Wir freuen uns auf Ihre Rückmeldung.
```

### 法语（法国/非洲法语区）

**问候**:
```
Bonjour [Nom],
Cher/Chère [Nom],
```

**开场**:
```
Nous sommes spécialisés dans [产品] et servons le marché [国家].
Votre entreprise nous a été recommandée par [来源].
Nous pourrions vous aider avec [痛点/需求].
```

**结尾CTA**:
```
Serieez-vous disponible pour un appel bref cette semaine?
Puis-je vous envoyer notre catalogue?
Nous restons à votre disposition.
```

### 葡萄牙语（巴西/葡萄牙）

**问候**:
```
Olá [Nome],
Bom dia/tarde [Nome],
```

**开场**:
```
Somos especializados em [产品] e atendemos o mercado [国家].
Sua empresa chamou nossa atenção por [来源].
Podemos ajudá-lo com [痛点/需求].
```

**结尾CTA**:
```
Estaria disponível para uma breve ligação esta semana?
Posso enviar nosso catálogo?
Ficamos à disposição.
```
