# 股票基本面对比分析 Skill

## 核心方法论

本skill提供两种对比分析模式：

### 1. 横向对比（同行业头部标的）
- 选择同行业头部1-2只股票进行同时期基本面横向对比
- 对比维度：盈利能力、成长性、偿债能力、运营效率、现金流、估值
- 输出：对比表格 + 雷达图 + 结论卡片

### 2. 纵向对比（本公司历史变化）
- 对本公司连续三年及连续三个季度进行纵向对比
- 分析趋势：盈利能力变化、成长性变化、财务安全变化、运营效率变化
- 输出：趋势图表 + 关键变化标注 + 风险提示

## 数据采集流程

### 数据源优先级
1. **neodata-financial-search**：自然语言查询，实时数据（优先）
2. **MX_FinData**：东方财富专业数据库，用于数据校验
3. **Tushare Pro API**：结构化API，补充字段（备选）

### 数据校验机制
用MX_FinData对neodata获取的核心数据进行交叉校验：
- 营收、净利润、扣非净利润等关键科目一致性
- ROE、毛利率、资产负债率等财务指标准确性
- PE、PB、市值等估值指标时效性
- 偏差>5%以MX_FinData为准，标注校验状态

### 必备数据字段
**利润表**：营收、营业成本、净利润、扣非净利润、毛利率、净利率
**资产负债表**：总资产、总负债、净资产、货币资金、应收账款、存货
**现金流量表**：经营/投资/筹资现金流净额
**财务指标**：ROE、ROA、资产负债率、流动比率、速动比率、存货周转率
**估值指标**：PE(TTM)、PB、PS、总市值、股息率

## 报告生成流程

### Step 1：数据采集
通过neodata-financial-search获取目标股票的财务数据，用MX_FinData校验。

### Step 2：数据对比
按照六维度框架逐项对比，计算同比变化，标注优劣方。

### Step 3：生成报告
- **Markdown文档**：完整数据对比表 + 分析结论（见 [references/report_template.md](references/report_template.md)）
- **可视化HTML**：雷达图 + 柱状图 + 趋势图 + 结论卡片（见 [assets/html_template.html](assets/html_template.html)）

## 输出规范

### 文件命名
- Markdown：`{股票代码}-fundamental-comparison-{日期}.md`
- HTML：`{股票代码}-fundamental-comparison-{日期}.html`
- 路径：`{workspace}/reports/`

### 报告结构
1. **标题**：股票代码 + 名称 + 对比类型（横向/纵向）
2. **数据摘要**：关键指标对比表
3. **可视化图表**：雷达图（六维度） + 柱状图（关键指标）
4. **分析结论**：综合评价 + 优劣标注 + 投资建议
5. **风险提示**：数据时效性 + 报告期标注

### 数据时效性标注
- 必须标注数据截止日期（如"数据截至2026-04-23"）
- 必须标注报告期（如"2025年报"、"2026Q1一季报"）
- 若某期数据未披露，明确标注"尚未披露"

## 使用示例

### 横向对比示例
```
用户：对比分析兴业银锡与藏格矿业的2025年报和2026Q1基本面
执行：
1. 用neodata获取000426和000408的2025年报+2026Q1财务数据
2. 用MX_FinData校验数据准确性
3. 六维度对比：盈利/成长/偿债/运营/现金流/估值
4. 生成对比表格 + 雷达图 + 结论卡片
输出：000426-vs-000408-fundamental-comparison-20260423.md/html
```

### 纵向对比示例
```
用户：分析藏格矿业近三年的基本面变化
执行：
1. 用neodata获取000408的2023/2024/2025年报 + 2025Q3/2025Q4/2026Q1季报
2. 计算各指标同比变化率
3. 绘制趋势图（营收/净利润/ROE等）
4. 标注关键变化节点 + 风险提示
输出：000408-fundamental-trend-20260423.md/html
```

## 注意事项

1. **报告期判断**：根据当前日期判断最新可获取的报告期（A股年报4月底、一季报4月底、中报8月底、三季报10月底）
2. **数据缺失处理**：若某期数据未披露，用最近可用数据并标注
3. **客观性原则**：对比分析必须客观，不偏袒任何一方
4. **校验机制**：所有核心数据必须经过MX_FinData校验，偏差>5%需标注
