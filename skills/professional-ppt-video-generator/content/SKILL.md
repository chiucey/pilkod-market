# 专业PPT与演讲视频生成技能

## 功能概述

本技能提供从**主题提纲**到**完整演讲视频**的全流程自动化生成服务。

## 输入参数

| 参数 | 说明 | 示例 |
|------|------|------|
| PPT主题 | 演示文稿的核心主题 | "人工智能发展趋势" |
| 提纲要点 | 大致的PPT结构要点 | "引言、技术现状、应用场景、未来展望、总结" |
| PPT页数 | 预期的幻灯片数量 | 10页 |
| 视频时长 | 演讲视频总时长 | 5-8分钟 |
| 风格偏好 | 可选：商务/科技/教育/创意等 | "科技风格" |
| 特殊要求 | 可选：配色、字体、Logo等 | "使用公司品牌色" |

## 工作流程

### 阶段一：内容策划与图片生成

**步骤1：信息收集与整理**
- 联网搜索PPT主题相关的最新资讯、数据、案例
- 整理搜索结果，提取关键信息和数据支撑
- 按PPT结构将内容分配到各页面

**步骤2：PPT图片生成**
- 调用图片生成工具，按每页内容生成对应的演示图片
- 使用pptx-generator技能创建PPT文件
- 提示用户确认生成的图片效果

**步骤3：内容修订（如需要）**
- 用户可提出修改意见
- 根据反馈重新生成指定页面的图片
- 重复确认直到用户满意

### 阶段二：PPT文件生成

**步骤4：PPT组装**
- 使用pptx-generator技能将图片组装成完整的PPTX文件
- 添加统一的标题页、目录页、转场页
- 应用统一的视觉风格和配色方案

### 阶段三：演讲视频生成

**步骤5：音频内容生成**
- 根据每页PPT内容生成相应的演讲稿
- 调用语音生成工具生成音频
- 首先生成第一页音频供用户确认

**步骤6：音频效果确认**
- 播放第一页音频供用户审核
- 如需调整，提供修改提示词
- 重新生成验证音频直到满意

**步骤7：批量音频生成**
- 确认音频效果达标后
- 按页依次生成所有演讲音频
- 确保音频与页面内容精确匹配

**步骤8：视频合成**
- 将PPT图片与对应音频整合
- 使用视频生成工具制作完整演讲视频
- 导出最终视频文件

## 工具调用

### 图片生成
```json
{
  "tool": "image_synthesize",
  "params": {
    "requests": [{
      "prompt": "PPT页面描述内容",
      "output_file": "ppt_slide_01.png",
      "aspect_ratio": "16:9"
    }]
  }
}
```

### PPT生成
```json
{
  "tool": "pptx-generator",
  "params": {
    "title": "PPT标题",
    "slides": [...],
    "template": "professional"
  }
}
```

### 语音生成
```json
{
  "tool": "gen_audios",
  "params": {
    "audio_requests": [{
      "text": "演讲稿内容",
      "output_file": "audio_slide_01.mp3",
      "voice": "professional_male"
    }]
  }
}
```

### 视频合成
```json
{
  "tool": "batch_image_to_video",
  "params": {
    "count": 10,
    "image_file_list": [...],
    "output_file_list": [...],
    "prompt_list": [...]
  }
}
```
