# 书籍层级整理技能

将书籍内容整理为清晰的多层次结构，保留核心内容脉络。

## 工作流程

### 1. 内容输入与预处理

接收书籍内容后，进行以下预处理：

- **全文通读**：快速浏览整体内容，了解主题范围和写作风格
- **结构识别**：识别原书的章节标题、编号系统、段落组织方式
- **内容评估**：判断内容复杂度，决定整理深度（2-5层结构）

### 2. 层级规划

根据内容特征规划层级结构：

| 层级 | 适用场景 | 格式示例 |
|------|----------|----------|
| L1 | 书籍/全书主题 | `# 主题标题` |
| L2 | 主要部分/篇 | `## 第一部分：XXX` |
| L3 | 章节 | `### 第一章 XXX` |
| L4 | 小节 | `#### 1.1 XXX` |
| L5 | 子要点 | `- 要点内容` |

**决策规则**：
- 学术著作：建议4-5层深度
- 商业/实用类：建议2-3层深度
- 小说/叙事类：按故事线/时间线组织

### 3. 内容提取与归类

对每个内容块执行：

1. **核心观点提取**：识别该部分的核心论点/情节
2. **关键细节保留**：提取重要的论据、案例、引用
3. **关系映射**：标注与其他部分的关系（前导、扩展、对比）
4. **层级归属**：判断该内容应归属的层级位置

### 4. 结构编织

按从粗到细的顺序构建结构：

```
L1: 全书主题
├── L2: 第一部分
│   ├── L3: 第一章
│   │   ├── L4: 核心概念
│   │   │   └── L5: 具体要点
│   │   └── L4: 关键论述
│   └── L3: 第二章
└── L2: 第二部分
```

### 5. 输出格式化

生成结构化输出：

**首选格式（Markdown）**：
```markdown
# 书籍主题

## 第一部分：XXX

### 第一章 XXX

#### 1.1 核心概念
- 要点1
- 要点2

#### 1.2 关键论述
> 重要引用/案例
```

**可选格式**：
- JSON树状结构（用于程序化处理）
- 纯文本缩进结构（用于快速预览）

### 6. 质量校验

输出前进行自检：

- [ ] 层级逻辑清晰，无跳跃或混淆
- [ ] 所有主要内容均已覆盖
- [ ] 同级条目互斥，不重复
- [ ] 层级深度合理，不过于扁平或过深
- [ ] 关键信息无遗漏

## 输出规范

### 标题层级
- 使用标准Markdown标题（`#` 至 `####`）
- 最多使用4级标题，超出部分用列表项

### 列表使用
- 无序列表：用于同级别要点罗列
- 有序列表：用于步骤、编号场景

### 补充标注
- **加粗**：核心概念、重点强调
- `引用块`：重要引用、案例、原文摘录
- *斜体*：术语定义、补充说明

### 关键词标注
在整理时识别并标注：
- [核心概念]：全书最重要的3-5个概念
- [关键术语]：需要定义的专有名词
- [关联]：与其他章节的引用关系

## 限制说明

本技能：
- ✅ 擅长：结构重组、层级规划、内容提炼
- ⚠️ 受限：原始文本识别（需用户提供可处理的文本）
- ❌ 不做：内容创作、观点评判、价值评估
