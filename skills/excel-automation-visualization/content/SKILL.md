#### 函数自动生成

根据需求描述生成复杂公式：

**跨表查询（XLOOKUP）**
```excel
=XLOOKUP(A2, 员工表!A:A, 员工表!B:B, "未找到")
说明：在员工表A列查找当前行A2值，返回对应B列数据
适用版本：Microsoft 365 / Excel 2021
```

**多条件求和（SUMIFS）**
```excel
=SUMIFS(C:C, A:A, "销售部", B:B, ">=2024-01-01", B:B, "<=2024-01-31")
说明：统计销售部2024年1月份的销售额合计
适用版本：Excel 2007 及以上
```

**嵌套逻辑（IF多层）**
```excel
=IF(A2>=90, "优秀", IF(A2>=80, "良好", IF(A2>=60, "及格", "不及格")))
说明：根据分数自动评级
适用版本：所有版本
```

#### VBA 自动化

常用宏代码示例：

**一键导入外部TXT/CSV**
```vba
Sub 导入TXT文件()
    Dim fd As FileDialog
    Set fd = Application.FileDialog(msoFileDialogFilePicker)
    fd.Filters.Clear
    fd.Filters.Add "文本文件", "*.txt; *.csv"

    If fd.Show = -1 Then
        With ActiveSheet.QueryTables.Add( _
            Connection:="TEXT;" & fd.SelectedItems(1), _
            Destination:=Range("A1"))
            .TextFileCommaDelimiter = True
            .Refresh
        End With
    End If
End Sub
```

**一键拆分工作表**
```vba
Sub 按部门拆分工作表()
    Dim ws As Worksheet
    Dim dict As Object
    Dim cell As Range
    Dim key As Variant

    Set dict = CreateObject("Scripting.Dictionary")
    For Each cell In Range("A2:A" & Cells(Rows.Count, 1).End(xlUp).Row)
        If Not dict.Exists(cell.Value) Then
            dict.Add cell.Value, Nothing
        End If
    Next

    For Each key In dict.Keys
        Sheets.Add.Name = key
        ' 复制数据逻辑...
    Next
End Sub
```

## 约束与规则

### 公式准确性
- 所有生成的公式必须**经过逻辑验证**
- 避免 `#N/A`、`#REF!`、`#VALUE!` 等错误
- 使用 `IFERROR` 包裹可能出错的公式
- 提供错误排查步骤

### 性能优化
| 场景 | 优化建议 |
|------|----------|
| 大数据量 >1万行 | 避免数组公式，改用 SUMIFS |
| 多条件查询 | 使用 Power Query 而非嵌套 VLOOKUP |
| 复杂计算 | 考虑 Python Pandas 预处理 |
| 频繁刷新 | 设置手动计算模式 |

### 工具推荐优先级
1. **Excel 内置功能**：表格、透视表、条件格式（优先）
2. **Power Query**：ETL、数据清洗、多表合并
3. **Power BI**：复杂仪表盘、数据模型
4. **Python Pandas**：超大数据处理、自动化报表
5. **不推荐**：收费插件（除非开源免费）

### 数据安全
- 处理敏感财务数据时**启用保护**
- 工作表保护：审阅 → 保护工作表
- 工作簿保护：审阅 → 保护工作簿
- 隐藏公式：设置单元格格式 → 保护 → 隐藏
- 建议设置只读访问权限

## 常见问题解答

### Q1：公式显示错误怎么办？
**排查步骤**：
1. 检查数据类型（文本数字？用 VALUE 转换）
2. 检查引用范围（是否有空行/错误值）
3. 检查括号配对（IF 嵌套容易出错）
4. 使用「公式求值」工具逐步调试

### Q2：表格卡顿怎么解决？
**优化方案**：
1. 删除多余的空行空列
2. 关闭自动计算（公式 → 计算选项 → 手动）
3. 减少条件格式使用
4. 大数据量考虑 Power Query

### Q3：如何保护公式不被修改？
**操作步骤**：
1. 选择要保护的单元格
2. 右键 → 设置单元格格式 → 保护 → 勾选"锁定"
3. 审阅 → 保护工作表
4. 设置密码（可选）
