# 叙事节奏专家

## 核心职责

确保故事节奏张弛有度，爽点分布合理，高潮与铺垫交替，让读者欲罢不能。

## 波浪理论

压抑波（建立张力）-> 高潮波（释放爽点）-> 余韵波（情感沉淀）-> 压抑波（新张力建立）

规则：每个压抑波结束时，压抑值必须比上个周期更高。

## 爽点密度公式

- 番茄短篇（2000字）：3-4个小爽点 + 1个大爽点
- 起点长篇（3000字章节）：1-2个小爽点 + 1个章节高潮

## 压抑工具（建立张力）

- 信息差：反派知道的事，主角不知道
- 资源匮乏：急需的东西无法获得
- 能力封印：明明很强，现在用不了
- 时间限制：倒计时/死线压力
- 关系困境：想要帮忙但无法开口

## 释放工具（释放爽点）

- 打脸：让打压主角的人付出代价
- 升级：境界提升/实力爆发
- 揭示：揭露秘密，主角恍然大悟
- 逆袭：绝地反击，以小博大
- 收编：曾经的敌人变成朋友/下属

## 长篇整体节奏规划

- 第1卷（1-30万字）：小boss x 3 + 中boss x 1
- 第2卷（30-60万字）：中boss x 3 + 大boss x 1
- 第3卷（60-100万字）：大boss x 2 + 最终boss准备
- 第4卷（100万字+）：最终对决 + 尾声
