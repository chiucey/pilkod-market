# 内容一致性审查

## 触发条件

以下场景自动触发本技能：

- 用户要求"审查一致性"、"校对内容"、"核对数字"
- 用户要求"检查人名/地名统一性"、"验证全文一致性"
- 用户要求"交叉核对"、"一致性审核"
- 用户提交"资金支付资料"、"变更联系单"、"付款申请"等工程文档
- 用户要求"工程联系单审核"、"设计联系单审查"

## 核心审查维度

### 1. 基础信息一致性

**必查要素：**
- 工程名称、标段、合同编号是否完整填写
- 申报周期、申报单位与实际一致
- 签章手续齐全（公章、项目经理签字）
- 报送日期与文档内容逻辑一致

**常见错误：**
- 汇总表表头期数写错（如"25年11月期"写成"12月期"）
- 标段信息混淆（如1标写成2标，表头标段写错）
- 日期逻辑错误（落款日期比实际时间提前太久）

### 2. 金额数据一致性（高优先级）

**交叉核对清单：**
- 拨付情况表 ↔ 审计意见单 ↔ 支付审批单 ↔ 汇总表
- 阿拉伯数字与大写金额一致
- 单位正确（万元/元）且全文统一
- 百分比与绝对值匹配

**常见错误类型：**
- 拨付情况表与意见单金额不一致
- 拨付情况表与支付审批单金额不一致
- 拨付情况表链接没更新导致累计金额汇总错
- 意见单中申报金额与总包盖章的申报金额不一致
- 民工工资金额漏写
- 扣回预付款算错
- 实际支付金额算成小于应付民工工资
- 拨付表完成占合同价比例不一致

### 3. 申报进度一致性

- 申报进度与现场实际施工进度一致
- 符合合同约定的进度节点
- 无"报多干少、未干先报"虚报情况
- 与施工日志汇报、监理会议纪要等资料核对

### 4. 主体名称一致性

**重点核对：**
- 建设单位、施工单位、设计单位名称规范
- 同一标段在不同文档中名称统一
- 建工与建设等易混淆名称区分清楚

**常见错误：**
- 1标是"建设"，2标是"建工"，常写反
- 三个标段审核口径不统一（意见单写法、安文计算口径）

### 5. 合同条款一致性

- 引用合同支付条款需引用原句，不擅自修改
- 合同支付金额与申报金额一致
- 合同暂定价与实际完成量比例计算一致
- 成果资料与合同付款条件匹配

### 6. 附件完整性

- 附件与正文内容一一对应
- 纸质资料数量正确，无混杂其他标段资料
- 作废单据已移除，无旧单掺杂
- 各标段资料分开整理，无互相夹错

### 7. 逻辑一致性

- 日期逻辑合理（申报日期、支付日期、落款日期）
- "建设单位应在X年X月X日前支付"的日期，申报时未过期
- 累计产值=上期审计拨付表累计产值+本期申报产值
- 审核汇总表中合同价相加等于合同价

### 8. 变更联系单专项审查

#### 工程联系单
- 联系单编号、工程名称、标段、报送日期要素完整
- 签章手续：施工单位项目部公章、项目经理签字齐全
- 附件完整：计算稿、现场照片、修改前后对比图
- 事由符合合同约定的可签证范围
- 杜绝施工单位自身失误导致的变更
- 无重复上报（签证、另一份联系单）
- 描述精准：无模糊表述（如"某部位"需明确轴线标高）
- 数据准确：无多算、错算

#### 设计联系单
- 编号、工程名称、设计专业（建筑/结构/安装）、出图日期、版本号完整
- 图纸配套：修改后图纸、节点详图、前后对比图
- 规范符合性：符合国家/行业/地方设计规范
- 项目匹配性：与已批复施工图审查意见一致
- 现场适配性：与已施工工序、已进场材料适配
- 多专业协同：建筑与结构、水电与暖通无冲突
- 变更理由充分：建设单位需求调整/地质条件变化/工艺优化/规范更新
- 技术可行：施工可行、成本合理
- 与施工衔接：出具时间与现场进度匹配

## 审查工作流程

### 步骤 1：信息提取与分类

1. **基础信息**：提取工程名称、标段、合同编号、申报周期
2. **金额数据**：提取所有金额、百分比、累计值
3. **日期信息**：提取申报日期、支付日期、落款日期
4. **主体信息**：提取建设单位、施工单位、设计单位、标段
5. **附件清单**：核对附件数量、内容对应关系

### 步骤 2：建立交叉核对矩阵

| 核对项 | 文档A | 文档B | 文档C | 一致性 |
|--------|-------|-------|-------|--------|
| 申报金额 | 100万 | 100万 | 95万 | ❌ B与C不一致 |
| 意见单日期 | 2025.11 | - | 2025.12 | ⚠️ 需核实 |
| 累计产值 | - | 500万 | 500万 | ✅ 一致 |

### 步骤 3：按优先级逐项检查

**🔴 严重（必须修正）：**
- 金额数据冲突（不同文档同一数据不一致）
- 主体名称错误（建工/建设混淆）
- 合同条款引用错误
- 金额单位错误（万元/元混淆）

**🟡 中等（建议修正）：**
- 表头信息错误（期数、标段）
- 纸质资料数量偏差
- 日期逻辑问题
- 口径不统一

**🟢 轻微（标注备查）：**
- 格式微差
- 表述风格差异

## 专业审核场景应用

### 场景1：资金支付资料审核

```
审核重点：
1. 基础要件：工程名称/标段/合同编号/申报周期/签章
2. 金额核对：拨付表 ↔ 意见单 ↔ 审批单 ↔ 汇总表
3. 进度匹配：申报进度与现场/合同节点一致
4. 附件完整：资料无缺失、无混杂
```

### 场景2：变更联系单审核

```
审核重点：
1. 合规性：编号/签章/附件齐全
2. 合理性：事由真实/符合合同/无重复
3. 准确性：描述清晰/数据准确
4. 设计变更额外：规范符合/专业协同/施工衔接
```

### 场景3：合同条款引用核查

```
审核重点：
1. 引用合同原句，不擅自修改
2. 支付金额与合同条款对应
3. 支付条款理解正确（节点金额 vs 实际完成量比例）
```

## 审查原则

1. **严格性原则**：工程财务文档必须零差错，发现问题绝不放过
2. **交叉核对原则**：同一数据必须多文档交叉验证
3. **可追溯原则**：每个问题标注具体文档、页码、位置
4. **保守原则**：不确定时标注，不擅自修改原文
5. **逻辑优先原则**：日期、金额逻辑优先检查

## 适用文档类型

- 资金支付资料（拨付表、意见单、审批单、汇总表）
- 工程联系单（施工方发起）
- 设计联系单（设计方发起）
- 付款申请书、进度申报表
- 合同及变更协议
- 审计报告、审核稿

## 常见错误速查表

| 错误类型 | 典型表现 | 检查方法 |
|---------|----------|----------|
| 金额不一致 | 拨付表≠意见单≠审批单 | 三表交叉核对 |
| 单位错误 | 万元写成元 | 逐项核查单位 |
| 名称混淆 | 建工/建设互换 | 标段-名称对照表 |
| 日期逻辑 | 落款>申报>实际 | 时间线验证 |
| 数量错误 | 纸质数量不符 | 清单计数 |
| 口径不统一 | 多标段计算差异 | 标准对照 |
| 链接错误 | 累计金额汇总错 | 重算验证 |
| 表头错误 | 期数/标段写错 | 首行核查 |
