# 简历模板参考

## 技术岗模板结构

```
1. 个人信息
   - 姓名、联系方式、LinkedIn/GitHub链接

2. 技术摘要（可选）
   - 3-5行技术专长概览

3. 技术技能
   - 编程语言、框架、工具、平台

4. 工作经历（突出技术贡献）
   - 公司 | 职位 | 时间
   - • 使用[技术X]实现[功能Y]，提升[指标Z]
   - • 主导[项目X]，采用[技术栈Y]

5. 项目经验（核心）
   - 项目名称 | 技术栈 | 时间
   - 项目描述 + 技术亮点 + 量化成果

6. 教育背景
```

## 管理岗模板结构

```
1. 个人信息
   - 姓名、联系方式

2. 管理概述（核心）
   - 管理哲学、核心成就、管理规模

3. 核心能力
   - 战略规划、团队建设、跨部门协作等

4. 工作经历（突出管理成就）
   - 公司 | 职位 | 时间
   - • 带领X人团队，实现[业务成果Y]
   - • 推动[变革X]，提升[指标Y]%

5. 关键项目/成就
   - 战略级项目及影响

6. 教育背景 + 专业培训
```

## 国企模板结构

```
1. 个人信息（完整）
   - 姓名、政治面貌、联系方式、居住地

2. 求职意向
   - 明确的目标职位

3. 教育背景（前置）
   - 学校、专业、学历、毕业时间、相关培训

4. 工作经历
   - 规范格式，突出稳定性
   - 强调组织认可、培训进修

5. 技能证书
   - 职称、职业资格证书、语言能力

6. 自我评价
   - 稳重踏实、综合发展

7. 获奖情况（可选）
```

## ATS最优格式

### 标准结构
- 标题使用标准职位名称（Software Engineer, Product Manager）
- 日期格式统一（YYYY-MM 或 MM/YYYY）
- 使用项目符号（• 或 -）
- 避免合并单元格

### 推荐样式
```
工作经历
ABC公司 | 高级软件工程师 | 2020年3月 - 至今

• 负责[职责描述]，使用[技术栈]
• 主导[项目名称]，实现[量化成果]
```

### 不推荐样式
```
┌──────────────┐
│ Software     │  ← 表格
│ Engineer     │
└──────────────┘

📅 2020.03 ~ Now  ← 特殊字符

★ 负责...       ← 图标符号
```
