# 股票投资分析框架

## 一、评分体系总览

| 维度 | 权重 | 评分范围 | 评级说明 |
|------|------|----------|----------|
| 基本面质量 | 35分 | 0-35 | 公司盈利能力、成长性、运营效率 |
| 估值与性价比 | 20分 | 0-20 | PE、PB、PS等估值指标相对历史和行业的位置 |
| 筹码与风险 | 20分 | 0-20 | 股东结构、筹码分布、解禁压力 |
| 资金与预期 | 15分 | 0-15 | 机构持仓、资金流向、业绩预期 |
| 趋势与位置 | 10分 | 0-10 | 股价趋势、均线系统、MACD等指标 |

**总分 = 各项得分之和，满分100分**

### 投资评级划分

| 总分区间 | 评级 | 操作建议 |
|----------|------|----------|
| 80-100分 | 强烈推荐买入 | 积极建仓，持有为主 |
| 65-79分 | 推荐买入 | 择机介入，中期持有 |
| 50-64分 | 观察 | 等待更好的买点 |
| 35-49分 | 建议减仓 | 逢高减持 |
| 0-34分 | 建议卖出 | 清仓回避 |

## 二、数据调用清单

### 1. 公司画像数据

| 数据项 | 字段说明 | 重要性 |
|--------|----------|--------|
| 股票代码/名称 | 基础信息 | 必填 |
| 上市时间 | 评估股龄 | 必填 |
| 所属行业 | 板块定位 | 必填 |
| 主营业务 | 了解公司做什么 | 必填 |
| 总股本/流通股本 | 评估流通性 | 必填 |
| 公司简介 | 了解公司背景 | 参考 |

**调用方式**: Tushare `stock_basic` + `company_info`

### 2. 行情与估值数据

|--------|----------|--------|
| 最新收盘价 | 当前价格 | 必填 |

## 三、各维度评分细则

### 3.1 基本面质量评分（35分）

**评分维度**:

| 细分项 | 最高分 | 评分标准 |
|--------|--------|----------|
| 盈利能力 | 12分 | ROE>20%得满分，15-20%得8-11分，10-15%得4-7分，<10%得0-3分 |
| 成长性 | 10分 | 营收增速>30%得满分，20-30%得7-9分，10-20%得4-6分，<10%得0-3分 |
| 盈利质量 | 8分 | 经营现金流>净利润得满分，>0得4-7分，<0得0-3分 |
| 财务安全 | 5分 | 资产负债率<50%得满分，50-70%得3-4分，>70%得0-2分 |

### 3.2 估值与性价比评分（20分）

**评分维度**:

| 细分项 | 最高分 | 评分标准 |
|--------|--------|----------|
| PE历史分位 | 8分 | PE<20%分位得满分，20-40%得6-7分，40-60%得4-5分，60-80%得2-3分，>80%得0-1分 |
| 相对行业PE | 6分 | 折价行业均值20%以上得满分，折价0-20%得3-5分，溢价0-20%得1-2分，溢价>20%得0分 |
| PB合理性 | 4分 | PB在行业合理区间得满分 |
| PS合理性 | 2分 | PS<行业均值得满分 |

### 3.3 筹码与风险评分（20分）

**评分维度**:

| 细分项 | 最高分 | 评分标准 |
|--------|--------|----------|
| 筹码集中度 | 8分 | 股东户数连续下降得满分，持平得4-7分，持续增加得0-3分 |
| 机构持仓 | 6分 | 机构持仓>50%得满分，30-50%得4-5分，<30%得0-3分 |
| 解禁压力 | 4分 | 未来3月无解禁或小解禁得满分，大解禁得0-2分 |
| 商誉风险 | 2分 | 商誉/净资产<10%得满分，10-30%得1分，>30%得0分 |

### 3.4 资金与预期评分（15分）

**评分维度**:

| 细分项 | 最高分 | 评分标准 |
|--------|--------|----------|
| 主力资金 | 6分 | 近5日净流入得满分，近5日持平但近20日净流入得3-5分，持续净流出得0-2分 |
| 外资持仓 | 4分 | 陆股通持股持续增加得满分，持平得2分，持续减少得0-1分 |
| 业绩预期 | 5分 | 机构预期持续上调得满分，持平得2-3分，下调得0-1分 |

### 3.5 趋势与位置评分（10分）

**评分维度**:

| 细分项 | 最高分 | 评分标准 |
|--------|--------|----------|
| 均线多头 | 4分 | 5/10/20/60日均线多头排列得满分 |
| MACD状态 | 3分 | MACD在0轴上方得满分，0轴附近得1-2分，0轴下方得0分 |
| 相对强弱 | 3分 | 相对大盘(沪深300)强势得满分 |

## 五、分析原则

1. **数据真实性**: 所有数据必须来源于Tushare官方API，不可篡改
2. **时效性**: 使用最近一个交易日的数据
3. **客观性**: 多空因素都要呈现
4. **风险第一**: 任何情况下都要提示风险
5. **免责声明**: 报告仅供参考，不构成投资建议
