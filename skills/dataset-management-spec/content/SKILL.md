# 数据集管理功能说明技能

## 使用场景

当用户需要创建数据集管理功能规范文档时，激活此技能。

## 输入信息

开始创建之前，收集以下关键信息：

1. **数据类型**: 文本、图像、音频、视频或多模态数据
2. **标注类型**: 分类、检测、分割、序列标注等
3. **团队规模**: 单人/多人协作需求
4. **数据规模**: 小型数据集/大规模数据处理需求
5. **安全要求**: 数据权限、脱敏、审计需求

## 核心模块输出

创建完整的数据集管理功能说明文档，包含以下核心模块：

### 一、业务需求与场景梳理

| 功能模块 | 关键要素 |
|---------|---------|
| 数据上传与预处理 | 支持数据类型、格式要求、清洗去重、质量检查 |
| 数据标注管理 | 标注工具类型、人工/自动标注、标注规范、协作流程 |
| 数据版本管理 | 版本控制策略、回滚机制、版本对比 |
| 数据安全与权限 | 权限模型、用户角色、数据脱敏、审计日志 |

### 二、技术可行性评估

**研发侧评估**：
- 现有架构兼容性分析
- 存储系统改造需求
- 任务调度系统评估
- 开发周期预估（分阶段计划）

**算法侧评估**：
- 数据格式对模型训练的影响
- 标注质量对模型效果的影响
- 自动化标注可行性（预标注、异常检测）
- 数据-模型联动机制

### 三、风险与协作机制

识别并分析：
- 数据隐私合规性风险
- 标注数据与实际场景偏差风险
- 技术实现风险
- 协作沟通风险

### 四、会议输出目标

明确：
- 功能优先级（核心功能 vs 优化功能）
- 技术实现路径
- 资源投入计划
- 后续行动计划与时间节点

### 五、附录材料

建议包含：
- 竞品功能分析（Hugging Face、Label Studio等）
- 用户调研摘要
- 功能原型草图或流程图

## 输出格式

生成结构化的功能说明文档，包含：

1. **执行摘要**：核心功能概述
2. **功能详细说明**：每个模块的具体需求
3. **技术方案**：实现路径和技术选型
4. **风险评估**：潜在风险及缓解措施
5. **实施计划**：分阶段落地计划

## 示例输出结构

```markdown
# [平台名称] 数据集管理功能说明

## 1. 执行摘要
## 2. 业务需求
   2.1 数据上传与预处理
   2.2 数据标注管理
   2.3 数据版本管理
   2.4 数据安全与权限
## 3. 技术方案
   3.1 架构设计
   3.2 技术选型
   3.3 开发计划
## 4. 风险评估
## 5. 附录
```

## 质量检查清单

完成文档后，确保：

- [ ] 所有核心模块（上传、标注、版本、权限）均已覆盖
- [ ] 技术可行性和风险评估完整
- [ ] 功能优先级明确
- [ ] 实施计划包含时间节点
- [ ] 文档格式规范、结构清晰
