# 天气查询与穿衣出行建议技能

## 核心能力

根据指定日期和地点获取天气信息，并提供专业的穿衣搭配和出行建议。

## 工作流程

### 1. 信息提取

从用户消息中提取：
- **地点**：城市名称（如：北京、上海、东京）
- **日期**：具体日期或相对日期（今天、明天、后天、本周末）
- **特殊需求**：如有特殊活动或行程

### 2. 天气数据获取

使用天气查询工具获取以下数据：

| 数据项 | 说明 |
|--------|------|
| 温度 | 最高温、最低温、体感温度 |
| 天气状况 | 晴、多云、阴、雨、雪、雾等 |
| 湿度 | 相对湿度百分比 |
| 风速 | 风速和风向 |
| 空气质量 | AQI指数、PM2.5浓度 |
| 紫外线 | 紫外线指数 |
| 日出日落 | 日出日落时间 |
| 能见度 | 能见度距离 |

### 3. 穿衣建议生成

根据温度和天气状况提供建议：

#### 温度穿搭指南

| 温度区间 | 建议穿搭 |
|----------|----------|
| < 0°C | 羽绒服/厚棉服、保暖内衣、围巾、手套、帽子 |
| 0-10°C | 厚外套、毛衣、保暖内衣、围巾 |
| 10-15°C | 夹克、风衣、毛衫、牛仔裤 |
| 15-20°C | 薄外套、长袖衬衫、长裤 |
| 20-25°C | 短袖、薄长袖、休闲装 |
| 25-30°C | 短袖、短裤/轻薄长裤 |
| > 30°C | 透气短袖、防晒装备、清凉装束 |

#### 特殊天气应对

| 天气状况 | 建议 |
|----------|------|
| 雨天 | 雨伞/雨衣、防滑鞋、避免白色系衣物 |
| 雪天 | 防水外套、保暖靴、防滑鞋底 |
| 大风天 | 防风外套、避免长裙/宽松衣物 |
| 雾霾天 | 口罩、帽子、减少户外活动 |
| 晴天/高紫外线 | 防晒霜、太阳镜、遮阳帽 |

### 4. 出行建议

#### 交通出行

| 天气 | 出行建议 |
|------|----------|
| 雨天 | 提前出门、携带雨具、选择公共交通 |
| 雪天 | 安装防滑链、小心路滑、预留更多时间 |
| 大雾 | 注意行车安全、保持车距、开启雾灯 |
| 高温 | 避免长时间户外、车内不放易燃物 |
| 大风 | 远离广告牌、临时搭建物 |

#### 户外活动

| 天气 | 建议 |
|------|------|
| 晴好 | 适宜户外运动、野餐、郊游 |
| 多云 | 适宜各类户外活动、拍照 |
| 阴天 | 适合运动、注意保暖 |
| 雨天 | 室内活动为主 |
| 雾霾 | 减少户外活动 |

### 5. 健康提示

根据天气状况提供健康建议：

- **温差大**：注意增减衣物，预防感冒
- **空气干燥**：多喝水、使用加湿器
- **湿度高**：注意防潮、食物保存
- **高紫外线**：防晒、戴墨镜、多喝水
- **气压变化**：敏感人群注意身体反应

## 触发验证

当用户发送以下内容时激活本技能：
- "今天天气怎么样"
- "明天要穿什么"
- "北京今天适合出门吗"
- "带伞吗"
- "周末天气如何"
- 查询特定日期的天气
- 询问穿衣建议

## 注意事项

1. **日期处理**：区分"今天"、"明天"等相对日期与具体日期
2. **地点识别**：支持中英文城市名
3. **数据时效**：标注天气数据的发布时间
4. **个性化建议**：考虑用户的特殊需求（如商务、运动）
5. **综合考虑**：温度、湿度、风速、紫外线等多因素综合建议
