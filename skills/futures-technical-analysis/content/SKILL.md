# 期货交易综合分析系统

## 核心原则

所有结论必须基于数据或指标变化，不允许主观判断。优先分析"边际变化"，而非绝对水平。技术分析必须给出明确趋势判断（多头/空头/震荡）。

## 数据获取策略

### 推荐数据源（优先级排序）

1. **Tushare Pro API** - 专业的Python金融数据接口，支持期货持仓、仓单等数据
2. **东方财富Choice金融数据终端** - 机构级数据服务
3. **同花顺iFinD** - 期货产业链数据
4. **大连商品交易所/上海期货交易所/郑州商品交易所** - 官方交易所数据
5. **Wind万得金融终端** - 机构级全品类数据

### 数据获取代码模板

```python
# Tushare Pro 示例
import tushare as ts
pro = ts.pro_api('YOUR_TOKEN')

# 获取期货持仓数据
df = pro.fut_holding(date='20240301', exchange='DCE', fut_type='1')

# 获取仓单数据
df = pro.ed置yield(date='20240301', commodity='Y')  # 豆粕为例

# 获取现货价格
df = pro.co置置置置置(name='豆粕', date='20240301')
```

## 分析框架

### 一、基本面分析

#### 1. 供给端评估
- 产能利用率 > 85% → 供给偏紧
- 新增产能集中释放 → 未来压力
- 产量增速变化 → 判断供需拐点

#### 2. 库存体系分析
| 库存位置 | 仓单变化 | 解读 |
|---------|---------|------|
| 高 | 增加 | 现货压力加大 |
| 高 | 减少 | 去库中，现货支撑 |
| 低 | 增加 | 警惕虚盘增加 |
| 低 | 减少 | 真实去库，偏多 |

#### 3. 需求端评估
- 下游开工率 > 80% → 需求旺盛
- 订单变化趋势 → 预判未来需求
- 终端消费指标 → 验证真实需求

#### 4. 结论输出
```
驱动类型：供给驱动/需求驱动/库存驱动/预期驱动
边际拐点：存在/不存在
方向判断：偏多/偏空/中性
```

---

### 二、技术面分析（强制输出）

#### 趋势判断规则

| 条件 | 趋势判断 |
|------|---------|
| MA多头排列（短>中>长）且价格>MA20 | 多头趋势 |
| MA空头排列（短<中<长）且价格<MA20 | 空头趋势 |
| 均线缠绕/反复交叉 | 震荡 |
| 数据冲突 | 震荡 |

#### 趋势强度判断

| MACD柱状 | RSI | 强度 |
|----------|-----|------|
| 放大 > 0 | > 70 | 强 |
| 收缩 | 40-70 | 中 |
| 收缩至0附近 | 30-40 | 弱 |

#### 判断依据（必须包含）

**必备（至少1条）：**
1. MA排列状态（多头/空头/收敛/发散）
2. MACD柱状方向与动能
3. DMI趋势方向（ADX > 25 确认趋势）

**量价验证（必须1条）：**
1. 成交量放量/缩量
2. 持仓量增减变化
3. OBV累积能量潮

**可选辅助（最多2条）：**
1. RSI超买/超卖
2. BOLL轨道位置
3. KDJ交叉信号
4. CCI极端值

#### 关键位置识别
```
上方阻力：最近前高/斐波那契61.8%/整数关口
下方支撑：最近前低/MA60/成本线
```

### 三、资金与持仓分析

#### 持仓量结构规则

| 持仓量变化 | 价格变化 | 解读 |
|-----------|---------|------|
| 增仓 | 上涨 | 多头主动做多，强趋势 |
| 增仓 | 下跌 | 空头主动做空，强趋势 |
| 减仓 | 上涨 | 空头回补，反弹概率大 |
| 减仓 | 下跌 | 多头止损，弱势延续 |

#### 龙虎榜分析规则

```
多头集中度 = 多头前十持仓 / 总持仓
空头集中度 = 空头前十持仓 / 总持仓

集中度 > 30% → 主力控盘
净多头增加 → 偏多
净空头增加 → 偏空
```

#### 机构行为判断

| 信号 | 含义 |
|------|------|
| 机构净多增加 + 散户净空 | 机构看多，跟随 |
| 机构净空增加 + 散户净多 | 机构看空，跟随 |
| 机构减仓 + 价格上涨 | 机构减仓，风险累积 |

---

### 四、拐点识别

#### 拐点信号（触发式）

**顶部拐点信号：**
1. MACD顶背离（价格创新高，MACD未创新高）
2. RSI顶背离（价格新高，RSI < 前高）
3. 成交量异常放大 + 价格滞涨
4. BOLL上轨连续3日未能突破

**底部拐点信号：**
1. MACD底背离（价格创新低，MACD未创新低）
2. RSI底背离（价格新低，RSI > 前低）
3. 持仓量持续下降 + 价格企稳
4. BOLL下轨连续3日获得支撑

#### 拐点强度判定

| 信号数量 | 强度 | 建议 |
|---------|------|------|
| 1条 | 弱信号 | 观望或轻仓 |
| 2条 | 中等 | 可尝试逆势 |
| ≥3条 | 强信号 | 趋势可能反转 |

---

### 五、多周期分析

#### 周线 + 日线共振规则

| 周线 | 日线 | 共振结果 | 交易优先级 |
|------|------|---------|-----------|
| 多头 | 多头 | 共振上涨 | 强（顺势做多） |
| 空头 | 空头 | 共振下跌 | 强（顺势做空） |
| 多头 | 空头 | 逆势 | 弱（日线回调） |
| 空头 | 多头 | 逆势 | 弱（日线反弹） |
| 震荡 | 任意 | 震荡 | 中（区间操作） |

---

### 六、跨品种资金流向

#### 强弱排序方法
```
综合得分 = 涨跌幅×0.4 + 持仓变化×0.3 + 资金净流入×0.3

得分排序：
第1名 → 领涨/领跌（关注）
第2-3名 → 跟随
最后一名 → 弱势/补跌风险
```

#### 板块共振判断
- 同板块3个以上品种同向 → 板块趋势确认
- 龙头品种率先启动 → 板块行情延续

---

### 七、评分系统

| 维度 | 权重 | 评分标准 |
|------|------|---------|
| 基本面 | 35% | 供需缺口/库存变化/利润变化 |
| 技术面 | 35% | 趋势强度/量价配合/关键位置 |
| 资金面 | 30% | 主力持仓/机构动向/持仓结构 |

**总分计算：**
```
总分 = 基本面分×0.35 + 技术面分×0.35 + 资金面分×0.30
```

| 总分 | 机会等级 | 仓位建议 |
|------|---------|---------|
| ≥10 | 强趋势机会 | 50%-70% |
| 7-10 | 结构性机会 | 20%-50% |
| <7 | 观望 | <20% |

---

### 八、优先级规则

**资金面 > 基本面 > 技术面**

| 冲突情况 | 处理方式 |
|---------|---------|
| 资金 + 基本面共振 | 强趋势信号，重仓 |
| 资金 + 技术冲突 | 降仓或观望 |
| 基本面 + 技术共振 | 中等仓位 |
| 三者冲突 | 观望 |

## 规则总结

| 规则 | 要求 |
|------|------|
| 结论依据 | 必须基于数据/指标变化 |
| 趋势判断 | 必须明确（多头/空头/震荡） |
| 理由数量 | 每个结论最多3条核心 |
| 表达方式 | 禁止模糊词（可能/偏强/大概） |
| 数据冲突 | 判定为震荡 |
| 数据缺失 | 明确说明"无法判断" |
| 信息类别 | 至少3类（基本面+技术面+资金面） |
| 优先级 | 资金面 > 基本面 > 技术面 |

## 执行流程

1. **接收输入数据** → 验证数据完整性
2. **基本面分析** → 供需库存驱动判断
3. **技术面分析** → 趋势方向与位置
4. **资金面分析** → 主力行为识别
5. **拐点识别** → 反转信号筛选
6. **多周期共振** → 交易优先级
7. **跨品种比较** → 资金流向
8. **综合评分** → 信号输出
9. **策略制定** → 可执行方案
