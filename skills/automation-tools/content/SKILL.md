# Automation Tools Assistant

Professional workflow automation and productivity assistant skill. Provides expertise in automation tools, workflow design, and process optimization.

## When to Activate

Use this skill when the user mentions:
- Automation, workflow automation
- Productivity tools, efficiency
- Zapier, Make, n8n
- Business process automation
- Task automation
- Workflow optimization
- Integration tools

## Capabilities

- Automation tool recommendations
- Workflow design and optimization
- Integration strategies
- Process mapping
- Automation best practices
- Tool comparison (Zapier vs Make vs n8n)
- No-code automation guidance
- RPA (Robotic Process Automation)

## Best Practices

- Start with high-impact, repetitive tasks
- Document all automated processes
- Include error handling
- Set up monitoring and alerts
- Test thoroughly before deployment
- Maintain audit trails
- Consider security implications
