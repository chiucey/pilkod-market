# 图片文字处理改写技能

## 核心能力

本技能支持从图片中提取文字并进行多种处理操作：

### 1. 文字提取 (OCR)
- 从截图、照片、文档图片中提取文字
- 支持中英文混合内容
- 处理模糊、低质量图片（尽力而为）

### 2. 文字改写类型

| 类型 | 说明 | 触发关键词 |
|------|------|-----------|
| 翻译 | 将图片文字翻译为目标语言 | 翻译、译成、翻译成 |
| 润色 | 优化文字表达，使其更流畅 | 润色、优化、写得更好 |
| 简化 | 将复杂内容简化为简洁版本 | 简化、精简、概括 |
| 正式化 | 转换为正式/商务语气 | 正式、商务、书面语 |
| 口语化 | 转换为轻松、口语化表达 | 口语化、通俗、白话 |
| 风格改写 | 按指定风格重写 | 改成...风格、写成...风格 |

### 3. 输出格式控制
- 保留原文结构（段落、列表）
- 仅输出处理后内容
- 可添加原文对照

## 工作流程

### 标准流程

```
用户提交图片 → 识别处理需求 → 提取图片文字 → 执行改写操作 → 输出结果
```

### 详细步骤

1. **接收图片**
   - 支持本地文件路径
   - 支持图片URL
   - 记录用户指定的处理需求

2. **分析需求**
   - 识别改写类型（翻译/润色/简化等）
   - 确定目标语言（如需翻译）
   - 确定输出格式要求

3. **文字提取**
   - 使用 OCR 工具识别图片中的文字
   - 处理多语言混合情况
   - 保留基本结构（换行、段落）

4. **执行改写**
   - 根据需求类型调用相应处理逻辑
   - 保持与原文的语义一致性
   - 优化表达的自然度

5. **输出结果**
   - 清晰呈现处理后的文字
   - 如有需要，附带原文对照
   - 标注处理类型和目标语言

## 使用示例

### 示例 1：截图文字翻译

**用户输入：**
```
请翻译这张图片中的文字：[图片]
目标语言：英文
```

**执行过程：**
1. 识别图片类型：截图/照片
2. 提取图片中的文字
3. 执行中译英
4. 输出翻译结果

### 示例 2：文档图片润色

**用户输入：**
```
帮我润色这张图片中的文字：[图片]
```

**执行过程：**
1. 提取图片文字
2. 优化表达，使其更流畅专业
3. 输出润色后的内容

### 示例 3：社交媒体图片文字简化

**用户输入：**
```
把这张图里的文字简化一下：[图片]
```

**执行过程：**
1. 提取图片中的长文字
2. 提取核心要点
3. 输出简洁版本

## 输出规范

### 成功输出

```
**处理类型**：[翻译/润色/简化等]
**目标语言**：[如有]

---

[处理后的文字内容]

---

*原文对照*
[原始提取文字]
```

### 提取失败处理

```
⚠️ 无法从图片中识别出可用的文字内容

可能原因：
• 图片中不含文字
• 图片质量过低无法识别
• 文字被严重遮挡

建议：
• 提供更高质量的图片
• 确保文字清晰可辨
• 检查图片方向是否正确
```

## 注意事项

1. **图片质量**：图片清晰度直接影响识别准确率
2. **文字方向**：确保图片方向正确（正向）
3. **语言混合**：混合语言内容可能影响翻译效果
4. **特殊符号**：数学公式、特殊符号可能无法完美处理
5. **手写文字**：手写体识别准确率较低，请知悉

## 适用场景

- 📱 从手机截图/照片中提取文字
- 📄 处理扫描文档的图片版本
- 🌐 翻译外语文档截图
- ✍️ 优化图片中文字的表达
- 📝 提取海报/宣传物料中的文字
- 💬 处理聊天截图中的文字内容

## 限制说明

- 不处理违规内容的图片
- 不处理涉及隐私敏感信息的图片
- 识别准确率受图片质量影响
- 复杂的排版格式可能丢失
