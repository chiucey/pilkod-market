# AI小说创作辅助技能

## 核心能力

本技能基于15个核心维度构建专业的小说创作框架，涵盖从世界观设定到读者互动的完整创作流程。

## 15个核心维度规范

### 1. 独特世界观设定

**关键指标：**
- 差异化元素 ≥3（创新组合，如克苏鲁+蒸汽朋克+东方符咒）
- 逻辑漏洞率 ≤5%
- 禁用同质化组合（如"系统+修仙"未加创新）

**执行流程：**
1. 输入：世界观类型（修仙/科幻/都市/其他）
2. 处理：生成3+创新元素组合 + 逻辑一致性检查
3. 输出：完整世界观规则表（含等级/能力/限制）

### 2. 高共鸣主角塑造

**关键指标：**
- 缺陷数量 = 2（如：谨慎+孤独、傲慢+敏感）
- 成长阶段 = 3（初期/中期/后期）
- 无敌描述频率 = 0（避免"突然开挂"）

**执行流程：**
1. 输入：主角身份定位
2. 处理：强制生成2个缺陷 + 3阶段成长线
3. 输出：角色弧线图（含关键转折点）
4. 风险规避：检测关键词"无敌""开挂"并自动重写

### 3. 节奏紧凑无水文

**关键指标：**
- 开篇钩子 ≤3章
- 每章结尾悬念率 = 100%
- 情节推进密度 ≥1 per 1000字

**执行流程：**
1. 输入：章节文本
2. 处理：扫描"悬念句"（结尾含"没想到/竟然是/然而"等）+ 计算情节推进点
3. 输出：节奏评分（0-10分）
4. 风险规避：拒绝长篇环境描写（>200字无情节推进）

### 4. 情节逻辑闭环

**关键指标：**
- 伏笔标记数 ≥5（生成时自动标记）
- 伏笔回收率 ≥80%
- 禁用"无理由反转"

**执行流程：**
1. 输入：章节文本
2. 处理：提取伏笔关键词 → 后期扫描回收
3. 输出：伏笔-回收映射表

### 5. 强情感驱动线

**关键指标：**
- 情感类型 ≥3（爱情/亲情/友情/师徒情/家国情）
- 冲突升级 = 3级（日常→矛盾→生死）

**执行流程：**
1. 输入：角色关系图谱
2. 处理：生成冲突升级路径
3. 输出：情感冲突强度曲线图

### 6. 合理爽点设计

**关键指标：**
- 爽点频率 = 每3-5章1个
- 爽点类型 = 智慧破局（禁止外挂）
- 禁用"无脑爽"（如"打脸反派不解释"）

**执行流程：**
1. 输入：剧情节点
2. 处理：检查爽点是否绑定逻辑
3. 输出：爽点合理性评分

### 7. 社会议题共鸣

**关键指标：**
- 热点议题 = 1-2个（如：职场内卷、教育焦虑、婚恋观念）
- 价值观 = 正向（奋斗/正义/成长）
- 禁用负面导向（如"躺平合理化"）

**执行流程：**
1. 输入：平台热榜关键词
2. 处理：嵌入议题 + 情感分析
3. 输出：议题融合度报告

### 8. 精准读者定位

**关键指标：**
- 语言风格精准匹配：
  - 女频：句长>20字+细腻比喻+情感丰富
  - 男频：句长<15字+短句+节奏明快
- 目标人群 = 明确（如：20-35岁女性/18-40岁男性）

**执行流程：**
1. 输入：读者画像
2. 处理：自动适配语言风格
3. 输出：文本风格适配报告

### 9. 流行文化融合

**关键指标：**
- 热词频率 ≤2 per 1000字
- 热词来源 = 平台热榜（如抖音/小红书/起点榜单）
- 禁用过度玩梗（>5个/章）

**执行流程：**
1. 输入：热词库
2. 处理：按频率嵌入热词
3. 输出：热词融合度指数

### 10. 文化认同感强化

**关键指标：**
- 传统文化元素 ≥3（如：武侠/民俗/诗词/中医/风水）
- 西化内容率 ≤10%

**执行流程：**
1. 输入：文化元素库
2. 处理：植入≥3种传统文化元素
3. 输出：文化认同度评分

### 11. 系列化潜力

**关键指标：**
- 开放结局关键词 ≥2（如："新世界""未解之谜""更大的危机"）
- 世界观扩展点 ≥2（如：势力地图/门派体系/位面层级）

**执行流程：**
1. 输入：结局文本
2. 处理：检测开放性元素
3. 输出：系列化潜力评分

### 12. AI生成内容优化

**关键指标：**
- AI味检测率 ≤15%
- 人味注入 = 3处/章（方言/情绪细节/生活化描写）

**执行流程：**
1. 输入：AI初稿
2. 处理：注入方言（5%概率）+ 情绪细节
3. 输出：人味优化报告
4. 风险规避：禁用模板化对话（如"主角：我很强"）

### 13. 持续更新稳定性

**关键指标：**
- 日更字数 ≥2000
- 断更预警 = 0

**执行流程：**
1. 输入：更新计划
2. 处理：监控字数/时间
3. 输出：更新稳定性指数

### 14. 规避风险要素

**关键指标：**
- 敏感词过滤率 = 100%（政治/伦理/违规内容）
- 版权安全 = 100%（AI生成原创化）
- 禁用历史歪曲/性别对立内容

**执行流程：**
1. 输入：文本内容
2. 处理：扫描敏感词库 + 版权检测
3. 输出：合规报告

### 15. 读者互动设计

**关键指标：**
- 互动钩子 = 1个/章（如：投票"选A还是B"、悬念提问）
- 评论分析频率 = 每章后
- 禁用诱导性投票（如"选女主A"无铺垫）

**执行流程：**
1. 输入：评论区数据
2. 处理：提取高频词 + 分析读者期待
3. 输出：互动优化建议

## 创作工作流程

### 阶段一：世界观与角色构建

```
1. 确定世界观类型
2. 生成差异化元素组合（≥3）
3. 创建角色体系（含主角缺陷设计）
4. 构建势力/门派/等级体系
```

### 阶段二：情节框架设计

```
1. 设计三段式结构（起始/发展/高潮）
2. 规划成长阶段（初期/中期/后期）
3. 埋设伏笔（≥5个）
4. 设计情感冲突线（≥3种情感类型）
```

### 阶段三：节奏与爽点编排

```
1. 规划章节悬念布局
2. 分配爽点位置（每3-5章1个）
3. 设计情感冲突升级路径
4. 植入社会议题（1-2个）
```

### 阶段四：语言风格适配

```
1. 确定读者定位（男频/女频）
2. 适配语言风格
3. 注入流行热词（≤2/千字）
4. 添加文化认同元素（≥3种）
```

### 阶段五：质量检查与优化

```
1. 逻辑一致性审查
2. 伏笔回收检查
3. AI味检测与人味注入
4. 敏感词过滤
5. 互动钩子植入
```

## 禁用清单

- 同质化组合（系统+修仙无创新）
- 无敌/开挂描述
- 无理由反转
- 无脑爽点
- 躺平合理化
- 长篇环境描写无推进（>200字）
- 诱导性投票无铺垫
- 过度玩梗（>5个/章）
- 全盘西化内容
- 大团圆无续作空间结局
- 模板化对话
- 历史歪曲/性别对立内容

## 输出格式

创作完成后，输出以下内容：

1. **世界观规则表**：完整的世界观设定文档
2. **角色弧线图**：主角成长轨迹与关键转折
3. **情节大纲**：三段式章节规划
4. **伏笔映射表**：伏笔埋设与回收对应
5. **情感冲突曲线图**：情感线设计
6. **节奏规划表**：章节悬念与爽点布局
7. **量化指标报告**：各维度达成情况
8. **风险检测报告**：敏感词/合规检查结果
