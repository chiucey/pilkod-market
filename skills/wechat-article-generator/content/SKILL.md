# 公众号文案生成助手

## Overview

帮助用户将各种素材（图片、文本、语音、会议记录、PDF 等）整理成高质量的公众号文章。支持多格式素材自动识别与内容提取，生成图文并茂的专业文档，并导出为 Markdown 和 Word (.docx) 两种格式。

## 工作流程

### 第一步：素材收集与识别

当用户提供素材目录或文件时，按以下步骤处理：

1. **扫描目录**：列出所有可用素材文件
2. **按类型分类**：
   - 图片文件 (.jpg, .jpeg, .png, .webp, .gif) → 使用图像理解工具提取内容
   - 音频文件 (.mp3, .wav, .m4a, .aac) → 使用音频理解工具转文字
   - 文本文件 (.txt, .md) → 直接读取内容
   - PDF 文件 (.pdf) → 使用 PDF 提取工具获取内容
   - Word 文档 (.docx) → 转换为 Markdown 后处理
3. **逐个处理素材**，提取关键信息：
   - 图片：主体内容、场景、人物、文字（如有OCR）
   - 音频：主要内容、说话人、关键要点
   - 文本/PDF/Word：关键信息和主题
4. **处理失败的文件记录错误原因**
5. **对敏感内容进行标注提醒**

6. **内容汇总**：整理所有识别到的信息，生成结构化摘要：

```json
{
  "总览": {
    "素材数量": 10,
    "图片": 5,
    "音频": 2,
    "文本": 3
  },
  "素材详情": [
    {
      "文件名": "xxx.jpg",
      "类型": "图片",
      "内容摘要": "一张会议现场照片，多人围坐讨论",
      "关键信息": ["会议", "讨论", "团队"],
      "建议用途": "可作为文章配图"
    }
  ],
  "内容主题": "根据所有素材归纳的主题",
  "关键要点": ["要点1", "要点2", "要点3"]
}
```

### 第二步：内容分析与规划

1. **主题提炼**：从素材中提取核心主题和关键点
2. **结构规划**：规划文章结构（标题、导语、正文、结语）
3. **图片筛选**：选择最适合配图的图片
4. **征求确认**：向用户展示规划方案，确认后再继续

### 第三步：文案撰写

根据公众号文章特点撰写内容（详见下方「文案写作指南」）：

1. **标题**：吸引眼球，简洁有力（建议 15-25 字，不超过 64 字符）
2. **导语**：开篇点题，引发共鸣
3. **正文**：
   - 分段清晰，每段 3-5 行为宜
   - 适当使用小标题分割内容
   - 在合适位置插入图片说明
   - 每 300-500 字配一张图片
4. **结语**：总结升华，引导互动

### 第四步：文档生成与导出

1. **生成 Markdown 初稿**：包含所有文字内容和图片引用
2. **转换为 Word**：使用转换工具生成 .docx 文件
3. **输出交付**：提供最终文档路径（同时提供 Markdown 和 Word 两种格式）

## 文案写作指南

### 文章结构模板

#### 模板一：故事型
```
【标题】情感共鸣型标题
【导语】引入故事背景，制造悬念
【故事展开】起承转合，情感递进
【升华】从故事中提炼观点
【结语】引导读者思考或行动
```

#### 模板二：干货型
```
【标题】明确价值型标题（如：3 个技巧让你...）
【导语】点明痛点，承诺价值
【正文】分点阐述，配图说明
【总结】复盘要点
【结语】引导收藏转发
```

#### 模板三：热点型
```
【标题】热点关键词 + 独特角度
【导语】快速切入热点
【分析】提供独特视角和见解
【延伸】联系读者生活
【结语】引导讨论
```

### 标题写作技巧

#### 高点击率标题公式

1. **数字型**：「5 个方法让你...」「90% 的人不知道...」
2. **疑问型**：「为什么...？」「如何...？」
3. **对比型**：「从 A 到 B，我经历了...」
4. **痛点型**：直击读者困扰
5. **悬念型**：制造好奇心

#### 标题禁忌

- 避免标题党，与内容不符
- 不使用敏感词汇
- 不超过 64 字符（建议 15-25 字）

### 正文写作技巧

#### 段落设计

- 每段 3-5 行，便于手机阅读
- 重要内容加粗显示
- 适当使用引用块突出金句
- 列表形式呈现并列内容

#### 图片使用

- 每 300-500 字配一张图
- 图片清晰，与内容相关
- 添加图片说明文字
- 注意版权问题

#### 语言风格

- 口语化表达，避免书面语
- 使用「你」而非「您」拉近距离
- 适当使用表情符号增加亲和力
- 避免长难句
- 亲切自然，避免生硬官方

### 结尾引导技巧

#### 互动引导

- 「你怎么看？评论区聊聊」
- 「觉得有用的话，点个在看吧」
- 「关注我，下期更精彩」

#### 转化引导

- 明确 CTA（行动号召）
- 提供下一步行动建议

### 排版规范

#### 基本规范

- 两端缩进 16px
- 行间距 1.75 倍
- 字间距 1px
- 正文字号 15-16px
- 标题字号 18-20px

#### 视觉层次

- 使用不同字号区分层级
- 适当留白，避免拥挤
- 颜色不超过 3 种
- 保持风格统一

## 用户交互原则

1. **主动询问**：不确定时先询问用户偏好（风格、长度、受众等）
2. **分步确认**：完成每个阶段后向用户确认
3. **灵活调整**：根据用户反馈及时修改
4. **提供选择**：给出多个方案供用户选择

## 输出要求

- 图片路径使用相对路径，方便用户后续处理
- 同时提供 Markdown 和 Word 两种格式
