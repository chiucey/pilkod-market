## 二、循证医学资源

### 系统综述与Meta分析

1. **Cochrane Pregnancy and Childbirth Group**
   - 数据库：Cochrane Library
   - 网址：https://www.cochranelibrary.com/
   - 优先级：最高

2. **PubMed Clinical Queries**
   - 路径：PubMed → Clinical Queries → Systematic Reviews
   - 用途：快速检索高质量系统综述

3. **UpToDate / Dynamed**
   - 用途：临床实践参考（非原始研究来源）

### 临床试验注册

1. **ClinicalTrials.gov**
   - 用途：验证RCT注册状态、结果
   - 优先级：高

2. **ISRCTN**
   - 用途：英国临床试验注册

3. **Chinese Clinical Trial Registry (ChiCTR)**
   - 用途：中国临床试验注册

## 四、证据等级分类系统

### Oxford循证医学中心（OCEBM）证据等级

| 等级 | 定义 | 置信度 |
|------|------|--------|
| 1a | RCT的系统综述（有同质性） | 最高 |
| 1b | 单项RCT（有窄置信区间） | 高 |
| 2a | 队列研究的系统综述 | 高 |
| 2b | 单项队列研究（包括低质量RCT） | 中 |
| 3a | 病例对照研究的系统综述 | 中 |
| 3b | 单项病例对照研究 | 中-低 |
| 4 | 病例系列（低质量队列或病例对照） | 低 |
| 5 | 专家意见、基础研究 | 最低 |

### GRADE证据质量评级

| 等级 | 定义 | 含义 |
|------|------|------|
| 高(A) | 非常有把握估计真实效应值接近估计值 | 进一步研究不太可能改变估计值的置信度 |
| 中(B) | 对效应估计值有中等置信度 | 真实值可能接近估计值，但也可能明显不同 |
| 低(C) | 对效应估计值置信度有限 | 真实值可能与估计值明显不同 |
| 极低(D) | 对效应估计值置信度很低 | 估计值非常不确定，可能与真实值差异很大 |

## 五、PMID验证与引文规范

### PMID格式要求

所有可验证引文必须使用以下格式：
```
[PMID:XXXXXXXX]
```

### PMID查询方法

1. **PubMed检索**：https://pubmed.ncbi.nlm.nih.gov/
2. **直接查询**：`PMID:XXXXXX` 搜索

### 无PMID的处理（近两年新进展）

对于近两年内发表的研究（尚无PMID分配或尚未收录）：

**格式**：
```
[研究缩写/作者名 - 需人工核实]
例：[TRITON trial - 需人工核实]
例：[通讯作者Smith, 2024 - 需人工核实]
```

**标注要求**：
- 明确标注"需人工核实"
- 提供研究完整名称或作者
- 标注发表年份

### 禁止行为

1. ❌ 猜测或编造PMID
2. ❌ 使用模糊引文（如"多项研究显示"）
3. ❌ 引用未经验证的网络来源
4. ❌ 引用非同行评审的灰色文献（除非作为补充）

## 八、质量控制清单

### 输出前检查

- [ ] 问题是否准确解析？
- [ ] 是否检索了最高等级证据？
- [ ] 所有PMID是否可验证？（或标注需人工核实？）
- [ ] 专家意见是否标注了证据等级？
- [ ] 学术争议是否客观呈现？
- [ ] 是否包含免责声明？
- [ ] 建议是否与证据等级匹配？
- [ ] 是否存在"由现有数据无法得出结论"的情况？

### 禁止项检查

- [ ] 无PMID的引文是否已标注？
- [ ] 无高质量证据时是否明确说明？
- [ ] 是否避免使用模糊表达？
- [ ] 是否未编造数据？
