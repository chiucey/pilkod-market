# 公开股票 PM 判断启发式

本启发式在多市场股票研究系列技能中共享。当用户在尽调某只上市股票、上市公司催化剂、上市公司模型、多空建议、卖方报告、ETF / 指数成分或组合仓位时，按本文件给出的口径思考。

## 受众模式

- `long_only_pm`：强调论点持久度、下行捕获、相对基准风险、流动性、增 / 减仓纪律、组合定位。
- `long_short_hf`：强调差异化认知、催化剂路径、情景偏度、借券 / 拥挤度、对冲 / 平仓规则、净 / 总敞口、时点风险。
- `sell_side_research`: 强调评级与目标价纪律、预测修订、街端争议框架、风险—评级关联、客户可读性、合规友好措辞。
- `etf_index_diligence`：强调指数方法论、成分权重、自由流通 / 流动性、ETF 持仓、被动资金流相关性、因子 / 板块敞口、再平衡风险、跟踪误差影响。
- `public_equity_diligence`：强调有来源支撑的发行人尽调、业务质量、管理层公信力、治理、会计质量、资本配置、估值风险、下一步所需的尽调来源。

### `long_only_pm` 二次分类（按风格）

当用户为多头基金经理输出时，先识别其风格归属，再叠加对应口径。可与 `long_only_pm` 主模式叠加使用。

- `long_only_pm.growth`（成长型基金经理）：
  - **重点关注**：营收复合增速、TAM 扩张路径、单位经济学（LTV / CAC、贡献利润）、产品 / 渠道周期、再投资回报、可选性、稀释与股权激励、研发资本化。
  - **估值口径**：以 PEG、EV / Sales→EV / EBITDA→EV / FCF 的折现路径估值，关注规模化后的稳态利润率与终值假设的可证伪性。
  - **下行机制**：增长曲线减速、单位经济学恶化、客户集中度、护城河被压缩、估值倍数压缩（rate / risk-off 敏感）。
  - **催化剂偏好**：KPI 拐点、产品发布、净新增 / 留存数据、毛利率扩张、指引上调；对硬数据 > 叙事。
  - **动作纪律**：在论点出现"增长质量恶化"信号（留存掉头、CAC 走高、毛利掉头）时降低 `add` 阈值；对单纯估值压缩谨慎 `trim`，只要复合路径未破。

- `long_only_pm.value`（价值型基金经理）：
  - **重点关注**：自由现金流收益率、净资产价值、重置成本、分红 / 回购、资本配置纪律、资产负债表强度、均值回归触发器、管理层与治理改善。
  - **估值口径**：以 EV / FCF、P / B、P / NAV、股息收益率 + 增长、分部加总（SOTP）为锚；强调安全边际与下行保护。
  - **下行机制**：价值陷阱（终端衰退、资本错配、再投资回报低于资本成本）、治理 / 会计风险、资产减值、再融资压力。
  - **催化剂偏好**：资产剥离、分红 / 回购加速、管理层更替、激进股东介入、估值重估、行业整合；耐心持有，看重多年期收敛。
  - **动作纪律**：把"便宜"和"错价"分开——只有出现催化剂或资本配置改善证据才 `add`；当 FCF 路径破或资本配置恶化时 `exit`，不被估值便宜锚住。

- `long_only_pm.cyclical`（周期型基金经理）：
  - **重点关注**：周期位置（库存、产能利用率、订单 / 出货比、定价 vs 成本）、运营杠杆、宏观与商品 / 利率敏感度、产能资本开支周期、终端需求领先指标。
  - **估值口径**：用 mid-cycle EPS / EBITDA 倍数而非峰值 / 谷底点估；P / B 在周期底部、EV / EBITDA 在中段、自由现金流在峰值更可靠。
  - **下行机制**：周期顶部利润率均值回归、产能扩张反噬、需求拐头、库存堆积、定价权丢失、固定成本杠杆反向放大。
  - **催化剂偏好**：领先指标拐点（PMI、库存出货比、利差、商品价格、运价、订单簿）、产能纪律信号、补库 / 去库节奏、政策 / 地缘扰动。
  - **动作纪律**：在周期底部 / 早周期 `add`，警惕"峰值盈利 × 峰值倍数"的双杀；当领先指标转向且利润率达到 mid-cycle 以上时进入 `trim` / `exit` 序列，不等基本面坐实。

## 资深 PM 必答的七问

任何实质输出在补背景之前，先回答：

1. 什么被错价了（如果有）？
2. 当前已被定价了什么？
3. 什么能证明论点？
4. 什么能杀死论点？
5. 为什么是现在？
6. 什么会改变仓位、评级、目标价、对冲、减仓、退出、平仓或观察名单状态？
7. 缺哪些证据？

## 核心启发式

- **差异化楔形**：把"已知事实"与"被错价的洞察"分开。没有差异化楔形，就把这个想法标记为观察项或跳过。
- **已定价部分**：在建议任何动作之前，先说明当前价格、一致预期、仓位或基准持仓似乎已折扣进什么。
- **预测路径**：指出为了让股票兑现，需要哪条营收、利润率、EPS、FCF、KPI 或估值倍数路径走出来。
- **估值偏度**：给出基 / 上 / 下案例，并指出当前股价是否已为上行案例付费。
- **下行机制**：先解释怎么亏钱，再解释怎么赚钱。
- **催化剂质量**：分清硬日期、证据窗口、软叙事催化剂、以及无催化剂局面。
- **持有结构与仓位**：相关时，标出流动性、容量、被动持股、ETF / 指数敞口、空头利息、借券、拥挤度、因子 / 板块敞口。
- **基准与因子敞口**：说明这只标的是绝对收益想法、相对基准主动头寸、对冲、因子表达，还是成分尽调项。
- **证伪条件**：每个论点测试都要可观察、有日期，并连接到来源、KPI、模型线或事件。
- **动作纪律**：把"下一步动作"归类为 `add`、`press`、`hold`、`trim`、`exit`、`cover`、`hedge`、`watchlist`、`pass`、`wait for proof` 或 `re-underwrite`。

## 品味规则

- 不要写"好公司 / 便宜股票"这种泛结论。要么指出具体错价点，要么说没有显然的错价。
- 把公司论点与股票论点分开：好公司可以是坏股票；坏财报可以制造更好的入场点。
- 给每条重要论断打标签：事实、管理层说法、一致预期、市场数据、模型输出、假设、PM 判断。
- 给一致预期、价格、持股、流动性、借券、期权、指数、ETF、空头利息数据打冻结时间 / 截至日期。
- 惩罚未引用的催化剂、陈旧的市场数据、虚假精度、对"市场怎么想"的未支撑论断。
- 不要把缺失数据糊过去。把缺失证据写进决策，而不是只写在附录里。

## PM / 风险工作流视角

本视角与 `portfolio-risk-management` 共享。每当用户在为公开股票仓位定 size 或对冲时按此处理。

- **Alpha vs 不想要的敞口**：把 PM 故意为之付费持有的特异、催化剂、因子、基准或指数敞口，从意外的 beta、因子、板块、流动性、借券、期权、外汇、商品、利率、拥挤、跳空风险中剥离出来。
- **保留的敞口**：在 size 或对冲建议之后，明确剩下哪些风险。一个把股票论点也对冲掉的对冲，通常不如把仓位做小。
- **绑定约束**：在下行损失、流动性、借券、总 / 净 / beta / 因子敞口、主动权重、期权权利金 / 希腊值、授权、催化剂时点、置信度中，找出最紧的那条。
- **对冲失败情景**：包含一个对冲、配对、ETF、期权或宏观代理在股票仓位承压时同时失败的情景。
- **缩小 / 不对冲的备选**：当基差风险、成本或 alpha 破坏度比直接持有更严重时，把所提对冲与"减总敞口、降起手仓、什么都不做"做对比。
- **动作规则**：增 / 减 / 退出 / 平仓 / 调仓 / 滚动 / 移除规则，要绑定到可观察的价格、论点证据、流动性、借券、期权到期、催化剂路径、因子敞口或对冲基差上。
- **信用信号边界**：CDS 水平、信用利差、评级、再融资压力、到期墙、契约头条新闻可以为公开股票下行或偿付能力风险提供输入。CDS、债券、贷款、利差 DV01 / CS01、资本结构、困境、回收率或契约相关交易的 size 或推荐不在本系列内——这些走独立信用分析流程。
