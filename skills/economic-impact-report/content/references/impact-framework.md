# 经济影响框架

`economic-impact-report` 已选中后再加载本文件。主入口保持紧凑，留给这里来承载完整的因果映射、时间分桶以及公开股票传导纪律。跨资产事实在这里只是输入，不是终极产物。

## 因果主线

强报告的推演骨架始终是一条线：

1. 事件 → 新发生了什么。
2. 新发生的事 → 传导渠道。
3. 传导渠道 → 第一个被定价进去的变量。
4. 首次重定价 → 直接受益者与受损者。
5. 直接效应 → 二阶、三阶、四阶后果。
6. 后果 → 情景、催化剂、发行人 / 板块影响、组合可执行性。

如果你说不出渠道，就说明对影响的理解还不够，不要继续。

## 时间分桶

- 即时：0–5 个交易日。
- 近期：1–12 周。
- 中期：1–4 个季度。
- 结构性：1 年以上。

## 置信度标签

- 高：证据扎实，机制清晰，依赖链短。
- 中：机制成立，但尚有未决假设或定价不确定。
- 低：逻辑可成立但证据偏薄，或对路径高度依赖。

## 直接性标签

- 直接：对事件参与方或主要受敞主体产生即时机械性影响。
- 二阶：供应商、客户、竞争者、替代品、融资链、保险方、分销方、政策反应。
- 三阶：劳动力、库存、信用质量、资本开支、跨境资金流、二轮通胀 / 增长传导、市场结构连锁。
- 四阶：机制层面变化、产业政策、储备 / 资本流向迁移、战略行为重置、长久期资本配置后果。

## 传导渠道清单

从下列里挑出真正驱动论点的 2–5 条，不要堆砌：

- 需求；
- 供给、产能、物流、吞吐；
- 定价能力；
- 监管、诉讼、政策先例；
- 融资条件、再融资、抵押品、信贷可得性；
- 劳动力、工资、用工；
- 商品、能源、运费、原材料；
- 地缘政治、制裁、关税、贸易管制；
- 库存、订单、营运资金；
- 财政响应、补贴、税收、主权发债；
- 央行响应与利率路径（如何作用到股票久期、融资成本、利润率、资本回报、估值倍数）；
- 跨境资金流、储备动态、外部平衡、外汇折算（如何作用到上市发行人）；
- 仓位、系统性资金流、对冲、拥挤交易；
- 资产负债表期权属性、资本配置、回购、股息、并购、股票下行风险。

## 量化口径

宁可给个粗略量级也别给模糊方向。相关时尽量量化：

- 营收敞口；
- 成本传导与利润率敏感性；
- EPS、FCF、ROIC、资本回报、估值倍数敏感性；
- 进口依赖度与出口结构；
- 再融资需求与融资成本敏感性；
- 库存、订单、产能利用率；
- 营运资金影响；
- 利率、外汇、商品敏感性；
- 曲线形状、基差、Carry、利差、商品对发行人经济性的传导；
- 隐含波动幅度、隐含波动率、偏度、期限结构；
- 情景概率与"出真相所需时间"。

明确使用以下标签：`Known`、`Inferred`、`Assumed`、`Disconfirmers`、`Action / monitoring`。

## 领域检查

只覆盖确实重要的领域，但每个领域都要在内部做一次自检：

- **上市发行人**：方向、直接性、机制、首要受影响报表项、时点、置信度、市场已定价部分、可执行的研究/组合动作。
- **板块与同业组**：结构性 vs 情绪驱动、子板块差异、周期 / 长期 / 监管 / 事件型属性、预测修订离散度。
- **组合与仓位**：持仓 / 观察 / 基准敞口、主动权重、流动性、拥挤度、空头利息、ETF / 指数资金流、对冲相关性。
- **宏观 / 外汇 / 利率 / 商品 / 期权 / 期货**：仅在它们传导到收入、成本、利润率、融资、贴现率、估值、波动率或股票仓位时才纳入。
- **信用信号**：仅作普通股下行或偿付能力侧写读取；信用工具、相对价值、契约条款、回收率、债务证券选择走独立信用分析流程。
