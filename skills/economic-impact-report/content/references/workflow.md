# 经济影响完整工作流

完整报告和高风险公开股票事件分析走本文件。

## 推荐步骤

1. 精确定义事件，把它与周围噪声剥离开。
2. 确定相对基线 / 一致预期，真正"新"的是什么。
3. 给本次分析挂上一个公开股票决策类型：发行人尽调、板块观点、业绩预告、估值支撑、仓位 size、对冲 / 观察、组合复盘。
4. 解释"为什么是现在"：即时重定价、中期盈利 / 政策效应、结构性迁移，还是大概率会褪色。
5. 草拟首版传导图：事件 → 渠道 → 发行人 / 板块驱动 → 财务报表项 → 股票 / 组合影响。
6. 在收集大量事实之前先写假设。每条核心渠道都给：假设、首个股票市场变量、确认信号、证伪信号。
7. 然后再收集证据来测试与排序假设。优先一手材料，优先回答价值最高的未决问题。
8. 按方向、量级、时点、置信度、直接性、定价状态对影响排序。
9. 覆盖确实重要的股票领域：上市发行人、同业组、板块、预测路径、估值 / 倍数支撑、因子 / 基准 / ETF 敞口、仓位、组合动作。
10. 宏观、利率、外汇、商品、期权、期货、信用——只作为公开股票输入。如果最优产物是非股票交易或信用证券观点，路由出去。
11. 判断在即期价、一致预期、波动率、融资、供应链 / 监管先例、持有结构、被动资金流、空头利息、拥挤度中，"已定价"和"未定价"分别在哪里。
12. 写出最强反方论点，并说明它是更强、更弱、被推迟、已定价，还是悬而未决。
13. 建基 / 上 / 下情景，能支撑时附粗略概率。
14. 收尾给监测信号、证伪条件、会改变组合动作的因素。
15. 最终交付前在内容层检查来源、时效性、缺口与证据立场；HTML 文件的打开、响应式和断链检查交给 `visual-page`。

## 无组合 / 观察名单时的兜底

用户没给持仓、论点、观察名单、基准、主动权重时——不要装作知道账户的样子。改成构建通用敞口筛选，并满足：

- 推断受影响的行业、国家 / 货币、商品、上市公司、相关非上市公司、上下游、二阶同业；
- 把组合特定动作标记为"在没有持仓 / 主动权重 / 授权 / 风险限额前不可用"；
- 用 `watchlist` / `wait for proof` / `pass` / `research queue` / `re-underwrite candidate`，不要用增 / 减 / 退出表达；
- 指出要把通用筛选升级到组合动作还需要什么数据；
- 每条渠道仍需要终落到发行人、板块、盈利 / 预测、估值 / 倍数、仓位 / 资金流以及下一步工作流。

## 常见失败形态

凡是符合下列任意一条，要么打回要么改写：

- 把文章总结一遍，而不是分析经济影响；
- 列出受影响名字却不解释传导渠道；
- 把头条强度当成经济重要性；
- 忽视已有预期或已被定价部分；
- 把利率、外汇、期权、期货、商品、信用当独立产物，而不是公开股票传导输入；
- 过度聚焦于被点名的公司，错过供应商、客户、竞争者或融资链；
- 把所有时间跨度合并成一个模糊结论；
- 投机性高阶后果与直接效应给同等置信度；
- 在可以给区间的位置仍用定性语言；
- 漏掉发行人 / 板块、盈利、估值、仓位、组合影响；
- 漏掉证伪条件。
