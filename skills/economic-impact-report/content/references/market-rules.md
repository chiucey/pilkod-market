# 三地市场口径规则（A股 / 港股 / 美股）

## 市场识别

- 先决定证券所在市场，再选主体类型：A股用 `a_stock`、港股用 `hk_stock`、美股用 `us_stock`。
- 保留原始交易代码、交易所、币种、当地时区、当地交易日历。
- 做跨市场对比时，统一币种、会计期、财务口径、复权口径与估值日期。
- 默认用中文说明，但公司、证券、指标、公告名称可以保留原文。

## A股专项

- 采用中国企业会计准则、人民币计价、中国交易日历。
- 处理 T+1、涨跌停、ST/*ST、停复牌、退市风险、流动性约束。
- 区分累计报告期、单季度推导值与 TTM；重点关注归母净利润、扣非净利润、经营现金流。
- 标明总股本、流通股本、限售股、解禁、增减持、回购、分红、再融资影响。
- 行业对比优先标注申万、中信、中证或证监会分类口径。

## 港股专项

- 采用港交所交易日历、港币计价、相应上市规则。
- 区分主板 / GEM、同股不同权、红筹 / H 股、双重主要上市、二次上市。
- 处理每手股数、停牌、配售、供股、可换股证券、控股股东持股变动。
- 标明财务报告所用准则（IFRS、香港财务报告准则等）与报告币种。
- A/H 联动比较时处理股份类别、汇率、自由流通、公司行动差异。

## 美股专项

- 采用 NYSE / Nasdaq 等交易所日历、美元计价、美东时间。
- 主要事实依据：SEC 文件、公司 IR、GAAP / 非 GAAP、季报。
- 处理盘前 / 盘后披露、拆股、回购、股权激励、稀释股数、ADR、双重上市。
- 事件分析要分别说明正常交易时段、盘前与盘后的价格反应。
- 财报分析可参考电话会文字稿，但文字稿不能替代正式申报中的会计数据。

## 跨市场通用规则

- 明确价格是否复权，以及分红、拆股、配股、送转及其他公司行动的处理方式。
- 股价、估值、事件、宏观数据都要记录截至时间。
- 区分正式披露、MCP 结构化数据、用户材料、分析师推导、假设、判断。
- 数据冲突时以交易所、监管或公司正式披露为准，并披露差异点。
- 输出的是研究分析，不是面向个人的交易指令。
