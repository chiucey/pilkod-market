# 领域加查清单

只有当某一领域确实会推动报告结论时才用对应清单。不要为了凑结构而强填。

## 上市发行人

每点名一家上市公司，回答下面这一组：

- 它经过哪条传导渠道？
- 是直接、二阶、三阶还是四阶影响？
- 哪一项先变：营收、毛利率、营业费用、营运资金、自由现金流、估值倍数、资产负债表，还是期权属性？
- 影响是落在量、价、产品组合、产能利用率、订单、客户行为、供应商成本、库存需求、资本开支、融资成本，还是监管负担？
- 时间跨度多长？
- 哪一部分可能已被股价反映？
- 这是主流表达、二阶非显性表达，还是要避开的拥挤交易？
- 影响会改变预测方向、目标价支撑、评级 / 立场、仓位大小、对冲，还是观察名单状态？

## 板块与同业组

要回答：

- 哪条同业组、行业、指数或主题篮子最受影响？
- 影响是周期性、结构性、监管性、仓位驱动，还是纯事件型？
- 它是否改变需求、定价、利润率、资本开支、营运资金、资本回报或估值惯例？
- 影响是整行业，还是只覆盖某子板块、某地理区域、某类客户群或某种商业模式？
- 冲击会带来预测修订离散度、估值倍数离散度，还是配对交易机会？
- 哪个板块 KPI 应该最先动？什么会证伪这条解读？

## 组合与仓位

要回答：

- 这只受影响标的是持仓、观察名单、基准成分、ETF / 指数成分、配对腿，还是对冲候选？
- 事件是否改变主动权重、因子敞口、流动性 / 容量、拥挤度、空头利息、借券风险、被动资金流风险？
- 是否催生增、减、退出、补仓、对冲、等待证据、还是重新审视的需求？
- 哪个市场信号最先证明股票市场已重新定价这一事件？

如果用户没给组合、观察名单、论点、基准或仓位：

- 不要倒推持仓或主动权重。
- 改成构建跨行业、国家 / 货币、上市公司、相关非上市公司、商品、上下游、二阶同业的通用敞口图。
- 组合特定动作标记为不可用，改用观察名单 / 研究队列 / 等待证据 / 跳过 / 重新审视候选。
- 写明在给出增 / 减 / 退出 / 对冲建议之前还需要哪些持仓、主动权重、授权、成本基础、风险限额。

## 宏观 / 外汇 / 利率 / 商品 / 期权 / 期货——只作为输入

它们在本技能里只是公开股票结论的传导变量。要问：

- 事件是否改变了"增长—通胀"组合？
- 是否改变了财政立场、经常账户、贸易条件或政治稳定？
- 哪些发行人有营收、成本、资产负债表、久期、外汇折算、商品或融资敞口？
- 利率 / 外汇 / 商品 / 波动率走势是否已被一致预期、即期价或估值倍数吸收？
- 事件在隐含波动率层面是否错价？
- 是否改变受影响个股的跳空风险、偏度或事件风险溢价？
- 期货曲线、库存、对冲行为、交割约束是否改变发行人毛利率、现金流或客户行为？

## 信用信号作为股票读取

信用工具、信用资质、重组、困境、回收率、利差、收益率、契约条款与债务证券分析，均由独立信用分析流程承接。本技能里，信用信号只在以下情况下被允许作为普通股下行或估值/盈利侧写读取：

- 再融资压力或流动性紧张影响普通股；
- 到期墙风险、评级压力或契约头条新闻改变下行；
- 融资成本变化影响盈利、FCF、回购、并购或估值倍数支撑；
- 来自独立信用分析流程的公开股票传导结论。
