# 质量基线与失败模式

## 标杆水平

一份强经济影响报告不是新闻汇编、宏观随笔或跨资产交易笔记，而是一份公开股票决策文件。

它要告诉资深公开股票投资者：

- 发生了什么变化；
- 为什么这件事对上市股票重要；
- 在受影响发行人、同业组、板块、因子或基准 / ETF 敞口中，什么会首先重定价；
- 哪些方面仍不确定；
- 在盈利、预测、估值、仓位、流动性、组合动作中，置信度最高的影响在哪里。

它的逻辑流是事件 → 机制 → 公开股票影响，要分清事实与判断、直接效应与高阶效应、近期股票后果与长久期战略后果。

对实质性的独立 HTML 报告，首读层应围绕事件状态、市场基线、事件→股票传导图、发行人/板块影响排名展开，而不是堆固定的仪表板模块清单。

## 证据标准

- 优先一手材料。
- 必须有可见的 `Source And Freshness` 章节，含数据截止 / 截至日期、所用来源、证据立场、陈旧 / 缺失数据、来源冲突。
- 必须有可见的 `Event Status And Market Baseline` 块，分别标注已确认事实、已报道或假设事件、时效性市场观察值。盘中观察值确实影响报告时，给出精确研究截止时间与时区。商品冲击要写明基准并区分现货 / 期货 / 盘中 / 收盘观察值（如相关）。
- 每条重大论断都连到公开股票机制上。
- 不确定性重要时，把判断标记为事实 / 推断 / 情景。
- 能给出粗略量级时就给。
- 用历史类比框定结果区间，而不是假定历史会重演。
- 让置信度跟随证据质量，而不是跟随措辞自信度。
- 显式暴露未知项。
- 引文以"决策有用"为优先：关键事实在使用位置邻近引文；不要让表格或监测队列被一遍遍重复的引文标签塞满。
- 只有当传导渠道、首要受影响报表项、方向性解读三者真正一致时才把代表性上市敞口归入同一行；主题相近不算同一行。
- 判断"已被定价"主要参考受影响个股 / 板块、预测修订、估值变化与相关传导市场；宽基指数表现只能当背景，不能作为敞口判断的主证据。

## 来源关卡

最终交付不允许通过"缺失 / 陈旧 / 薄弱"证据立场。内容层必须确认：报告有专门的 `Source And Freshness` 章节、写明数据截止 / 截至日期、列出所用来源、披露陈旧 / 缺失数据评估，并把关键证据的状态标为已核实、初步、假设主导或不可支撑。HTML 文件自身的打开、响应式和断链检查交给 `visual-page`。

## 答前自检

写完之前自问：

1. 我是否找到了相对基线真正"新"的东西？
2. 我是否解释了"为什么是现在"以及可能的重定价顺序？
3. 我是否给出了传导渠道的名字？
4. 我是否说出了股票市场最先会关心的事？
5. 我是否把直接效应与二、三、四阶效应分开了？
6. 我是否按方向、幅度、时点、置信度、直接性给影响排了序？
7. 在可量化处我是否量化了？
8. 我是否点明了发行人、板块、盈利、估值、仓位、组合影响？
9. 我是否说明了在受影响个股里"已定价"与"可能被错价"的分别？
10. 我是否包含了最强反方论点？
11. 我是否包含了情景、催化剂以及"什么会改变观点"？
12. 来源 / 时效性立场是否足以支持最终交付？
13. 用户没给组合 / 观察名单时，我是否构建了行业、国家 / 货币、公司、商品、上下游、二阶同业的通用敞口图，而不是杜撰持仓？
14. 一位资深公开股票投资者读完后，能不能做出比之前更锐利的决策？

任何一项是 "否"——回去改。

## 常见失败形态

凡是出现下列情况之一，就要返工：

- 没有发行人 / 板块 / 盈利 / 估值 / 仓位 / 组合影响；
- 推荐了一份独立的利率 / 外汇 / 期权 / 期货 / 商品 / 信用证券表达，而不是公开股票结论或显式转交；
- 没说"已定价的是什么"；
- 没指出"什么会改变 PM 动作"；
- 把文章总结了一遍而不是分析公开股票影响；
- 罗列了受影响名字但没解释传导渠道；
- 把头条强度当成经济重要性；
- 忽略了已有预期或已定价部分；
- 把利率 / 外汇 / 期权 / 期货 / 商品 / 信用当成独立策略输出，而不是公开股票的传导输入；
- 过度聚焦于被点名的公司，错过供应商、客户、竞争者、同业组、板块篮子或融资链；
- 把所有时间跨度塞进一个结论；
- 把投机性的高阶后果与直接效应给同样的置信度；
- 在可以给区间的地方仍用定性表达；
- 把非股票资产作为答案，却没把交易构建路由出多市场股票研究之外；
- 漏掉最强反方论点；
- 漏掉证伪条件或监测信号；
- 通过"什么都同等重要"来制造平衡感；
- 用户没要标准化仪表板时却把实质报告硬塞进固定仪表板模块；
- 把分组的发行人示例当成证券层面的投资结论，却没有公司特定证据；
- 把传导渠道明显不同的敞口合并到同一排名行；
- 用宽基指数表现作为"已定价"的主证据；
- 让重复的来源标签或内部证据机制喧宾夺主，盖住投资者结论。

## 语调检查

文字应当：

- 资深；
- 简洁；
- 先结论；
- 证据驱动；
- 不确定性显式但不含糊。

避免：

- 开场客套；
- 泛宏观填充；
- "这可能利好也可能利空"的反复对冲；
- 点名公司但没有机制；
- 数据弱时却用虚假精度。
