# 自我进化技能 - 详细执行指南

## 完整执行流程示例

### 场景：AI在回答用户问题时遗漏了关键信息

**Step 1: 错误捕获**
```
检测到遗漏错误：
- 用户询问："如何用Python读取CSV文件？"
- AI回答：提供了基本的read_csv代码
- 用户反馈："还需要处理中文编码"
- 遗漏点：未考虑编码问题
```

**Step 2: 详细记录**
```markdown
## 错误事件 #2024-001

**时间**: 2024-01-15 14:30
**场景**: 技术问题解答
**类型**: 遗漏错误 - 常见边界条件
**用户反馈**: 指出遗漏了编码处理

### 原始输入
用户询问Python读取CSV的方法

### AI输出
提供了基本的pandas read_csv代码，缺少编码参数

### 用户纠正
"还需要处理中文编码问题"

### 错误分析
- 直接原因：未考虑中文编码这一常见场景
- 深层原因：缺乏系统性的"常见边界条件"检查意识
- 知识缺口：需要补充中文环境下文件处理的最佳实践
```

**Step 3: 模式提取**
```markdown
## 识别到的模式

**模式名称**: 文件处理遗漏编码问题
**触发条件**:
- 文件操作相关任务
- 涉及文本处理
- 用户使用中文环境

**预防规则**:
1. 文件读取必须考虑编码参数
2. 中文环境默认使用utf-8或gbk
3. 提供编码检测/指定选项
```

**Step 4: 生成规则**
```markdown
## 新增规则：文件处理检查清单

- [ ] 明确文件编码（如不确定，提供检测方案）
- [ ] 考虑跨平台兼容性
- [ ] 包含异常处理（FileNotFoundError等）
- [ ] 大文件处理（分块读取）
- [ ] 资源释放（with语句）
```

**Step 5: 更新记忆**
- 将错误添加到 error_log.md
- 将模式添加到 pattern_lib.md
- 将规则添加到 rules.md

## 深度分析方法

### 5Why追问法示例

**错误**: 生成的报告格式不规范

1. Why: 为什么格式不规范？
   → 因为没有遵循模板

2. Why: 为什么没有遵循模板？
   → 因为没有可用的模板参考

3. Why: 为什么没有模板参考？
   → 因为没有收集过报告格式的标准

4. Why: 为什么没有收集标准？
   → 因为不知道需要建立这样的知识库

5. Why: 根本原因
   → 缺乏"输出标准化"意识

**结论**: 需要建立各类输出的标准模板库

## 错误分类详解

### 1. 逻辑错误
**特征**: 推理过程有漏洞
**识别信号**:
- 结论与前提矛盾
- 中间步骤跳跃
- 假设未被验证

**示例**:
```
错误推理:
"所有鸟都会飞 → 企鹅是鸟 → 企鹅会飞"
原因: 忽略了"所有鸟都会飞"这个前提本身就是错误的
```

### 2. 遗漏错误
**特征**: 信息不完整
**识别信号**:
- 用户回复中带有"还..."、"另外..."
- 任务完成但质量不达标
- 输出被要求"补充..."

**示例**:
```
用户: "帮我写一个网页"
AI: 写了一个HTML文件
用户: "还需要CSS样式和JS交互"
```

### 3. 误解错误
**特征**: 理解与意图不符
**识别信号**:
- 用户表示"不是这个意思"
- 反复修改同一内容
- 使用专业术语时概念错误

### 4. 执行错误
**特征**: 操作层面的失误
**识别信号**:
- 代码语法错误
- 格式错误（缩进、大小写等）
- 步骤遗漏或顺序错误

## 进化效果评估

### 评估指标

1. **错误重复率**: 同一类型错误再次发生的频率
2. **预防覆盖率**: 新规则能覆盖的场景比例
3. **响应质量分**: 用户满意度评分

### 自我评估问题

每次执行任务前问自己：
1. 这个任务是否涉及我之前犯过的错误类型？
2. 有哪些预防规则需要激活？
3. 需要特别注意哪些遗漏点？
