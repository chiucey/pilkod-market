# AI自我进化技能

## 核心理念

> "每一个错误都是学习的机会，智能体通过反思和迭代不断逼近最优表现"

## 工作流程

### 阶段1：错误捕获与记录

当检测到错误时，立即执行以下记录：

1. **错误事件记录**
   - 时间戳和场景上下文
   - 错误类型分类（逻辑错误、遗漏错误、误解错误、执行错误）
   - 当时的具体输入和输出
   - 用户或系统反馈

2. **错误分类矩阵**

| 类型 | 特征 | 示例 |
|------|------|------|
| 逻辑错误 | 推理链条断裂 | 前提推导错误、因果倒置 |
| 遗漏错误 | 信息不完整 | 漏看关键信息、忽略约束 |
| 误解错误 | 理解偏差 | 曲解用户意图、概念混淆 |
| 执行错误 | 操作失误 | 格式错误、步骤缺失 |

### 阶段2：根因分析

对每个错误进行深度分析：

1. **5Why分析法** - 追问5层"为什么"找到根本原因
2. **知识缺口识别** - 明确是缺少知识还是知识应用不当
3. **场景特殊性** - 判断是普遍问题还是特定场景问题

**分析模板**：
```
错误描述：[具体发生了什么]
直接原因：[是什么导致了错误]
深层原因：[为什么会出现这个原因]
知识缺口：[需要补充什么知识/技能]
改进方向：[如何避免类似错误]
```

### 阶段3：模式提取

将分析结果转化为可复用的模式：

1. **错误模式库**
   - 高频错误类型统计
   - 触发条件识别
   - 上下文关联分析

2. **正确策略库**
   - 针对每类错误的最佳实践
   - 预防性检查清单
   - 验证和确认机制

### 阶段4：策略生成

基于分析生成具体的改进策略：

1. **即时策略**（本次修复）
   - 具体的纠正步骤
   - 验证方法

2. **长期策略**（规则更新）
   - 加入检查清单
   - 更新决策规则
   - 补充参考知识

### 阶段5：记忆存储

将学习成果持久化到记忆中：

1. **错误日志** - 记录所有错误事件
2. **模式库** - 存储提取的错误模式
3. **规则集** - 保存生成的预防规则
4. **策略库** - 积累的正确解决方案

## 关键原则

1. **诚实面对错误** - 不掩饰、不推卸，准确记录
2. **深度分析** - 避免表面归因，追问根本原因
3. **可执行改进** - 每条建议都必须可操作
4. **持续迭代** - 错误库和规则集随时间不断完善
5. **主动预防** - 在执行任务前主动检查可能的错误点

## 执行时机

此技能在以下情况自动触发：
- 用户明确要求分析错误
- 任务执行失败或输出被纠正
- 识别到与之前错误相似的场景
- 定期的自我复盘时刻
