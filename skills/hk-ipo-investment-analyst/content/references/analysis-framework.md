# 港股打新分析数据源指南

## 一、官方数据源

### 1.1 港交所披露易

**网址**：https://www.hkexnews.hk

**核心功能**：

- 招股说明书（H股：A股招股书、C股招股书）
- 上市文件
- 财务报告
- 公告及通函
- 上市发行人的披露信息

**使用指南**：

1. 进入「披露易」网站
2. 选择「IPO新股」栏目
3. 输入股票代码或公司名称
4. 下载相关PDF文件

**数据时效性**：官方实时更新，可作为最终数据依据

---

### 1.2 港交所IPO专区

**网址**：https://www.hkex.com.hk/IPO

**核心功能**：

- 在上市发行人名单
- IPO日历
- 发售公告
- 上市日程

**适用场景**：

- 查找即将上市新股
- 确认申购时间窗口
- 获取上市发行信息

---

## 四、数据获取流程

### 4.1 招股说明书获取流程

```
步骤1：确认股票代码（XXXX.HK格式）
    ↓
步骤2：登录港交所披露易（https://www.hkexnews.hk）
    ↓
步骤3：进入「披露易」-「新股认购」
    ↓
步骤4：搜索股票代码
    ↓
步骤5：下载「上市文件」PDF
    ↓
步骤6：提取关键信息填入分析表格
```

### 4.2 孖展数据获取流程

```
步骤1：登录捷利交易宝或富途
    ↓
步骤2：进入新股认购页面
    ↓
步骤3：查看孖展认购数据
    ↓
步骤4：记录超购倍数、甲组乙组分布
    ↓
步骤5：持续跟踪直到认购截止
```

### 4.3 基石投资者数据获取流程

```
步骤1：查看招股说明书「基石投资者」章节
    ↓
步骤2：核实港交所披露易的更新信息
    ↓
步骤3：查询捷利交易宝的基石数据
    ↓
步骤4：搜索各投资机构的背景资料
    ↓
步骤5：评估认购金额和锁定期
```

## 五、数据交叉验证

### 5.1 核心数据验证矩阵

| 数据项 | 第一来源 | 验证来源 | 容许差异 |
|-------|---------|---------|---------|
| 发行价 | 港交所披露 | 券商认购页面 | 无差异 |
| 募资规模 | 招股说明书 | 港交所公告 | ±5% |
| 基石投资者 | 招股说明书 | 港交所更新 | 无差异 |
| 财务数据 | 招股说明书 | 审计报告 | 无差异 |
| 孖展数据 | 捷利交易宝 | 富途/雪球 | ±10% |
| 暗盘数据 | 捷利交易宝 | 富途 | ±2% |

### 5.2 数据异常处理

**异常情况1：数据不一致**

- 处理流程：优先采用港交所披露易数据
- 次级参考：券商平台数据
- 标注说明：在报告中注明数据来源差异

**异常情况2：数据缺失**

- 处理流程：标注为「数据待披露」
- 补充渠道：联系保荐人或公司投资者关系
- 替代方案：使用可比公司数据估算

**异常情况3：数据滞后**

- 处理流程：标注数据更新时间
- 时效说明：提醒用户注意数据时效性
- 更新计划：承诺在数据更新后补充

## 六、数据时效性管理

### 6.1 不同阶段数据更新频率

| 阶段 | 数据类型 | 更新频率 | 注意事项 |
|------|---------|---------|---------|
| 招股期 | 孖展认购 | 每日/实时 | 关注截止日前最后数据 |
| 截止日 | 认购统计 | 截止后公布 | 最终数据为准 |
| 上市前夜 | 暗盘数据 | 盘中实时 | 反映市场预期 |
| 上市日 | 首日表现 | 收盘后 | 最终确认数据 |
| 上市后 | 追踪数据 | 定期更新 | 持续跟踪 |

### 6.2 数据有效期说明

- **招股说明书**：认购期内均为有效数据
- **孖展数据**：以截止日最终公布为准
- **暗盘数据**：仅当日有效
- **投资建议**：基于当时市场环境，后续需更新
