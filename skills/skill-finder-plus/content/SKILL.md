# Skill-Finder-Plus 增强版技能搜索

## 1. 技能概述

Skill-Finder-Plus 是 MaxClaw 平台的高级技能搜索与管理模块，专为大型 Agent 团队（≥10个Agent）设计。它在基础 find-skills 能力之上，提供了完整的团队级技能管理生态系统，包括智能筛选、多维度匹配、自动化组合推荐、冲突检测与解决、以及跨 Agent 技能库同步等功能。

### 1.1 核心能力矩阵

| 能力维度 | 功能描述 | 适用场景 |
|---------|---------|---------|
| 技能分类筛选 | 按类型/场景/版本多级分类体系 | 快速定位目标技能 |
| 多维度匹配 | 能力/性能/权限/兼容性四维评估 | 精准技能推荐 |
| 技能组合推荐 | 复杂任务的最优技能链生成 | 端到端任务处理 |
| 冲突自动解决 | 技能间冲突检测与智能决策 | 团队协作一致性 |
| 团队库同步 | 跨 Agent 技能配置批量同步 | 大规模部署维护 |

**筛选算法**：

```python
def classify_filter(skills, filters):
    result = skills

    # 类型过滤
    if filters.type:
        result = [s for s in result if s.type in filters.type]

    # 场景过滤
    if filters.scenario:
        result = [s for s in result if s.scenario in filters.scenario]

    # 版本过滤
    if filters.version:
        result = [s for s in result if s.version == filters.version]

    # 组合过滤
    if filters.combination:
        result = apply_combination_filter(result, filters.combination)

    return result
```

```

│                    多维度匹配评分系统                         │
├─────────────────┬─────────────────┬───────────────────────┤
│    能力匹配      │    性能匹配       │      权限匹配          │
│   (0-100分)     │    (0-100分)     │      (0-100分)         │
├─────────────────┼─────────────────┼───────────────────────┤
│ • 功能覆盖率     │ • 响应速度       │ • 团队权限等级          │
│ • 精度指标      │ • 资源占用       │ • 数据访问范围          │
│ • 适用场景覆盖   │ • 并发能力       │ • 操作权限范围          │
├─────────────────┴─────────────────┼───────────────────────┤
│          兼容性匹配 (0-100分)        │     综合评分           │
├─────────────────────────────────────┼─────────────────────┤
│ • 与已挂载技能冲突检测               │                     │
│ • 依赖关系满足度                      │   加权求和           │
│ • 接口兼容性                          │   (可自定义权重)     │
└─────────────────────────────────────┴─────────────────────┘
```

**匹配计算公式**：

```
综合评分 = w1 × 能力匹配 + w2 × 性能匹配 + w3 × 权限匹配 + w4 × 兼容性匹配

默认权重:
w1 = 0.35 (能力优先)
w2 = 0.25 (性能重要)
w3 = 0.20 (权限必要)
w4 = 0.20 (兼容保证)

可配置项:
- 用户可根据任务特点调整权重
- 支持保存自定义权重配置
```

#### 3.2.4 技能冲突解决

**冲突类型定义**：

```yaml
冲突分类:
  功能冲突:
    定义: 两个技能功能高度重叠
    示例: 两个网页抓取技能
    影响: 资源浪费，执行不确定

  依赖冲突:
    定义: 技能间依赖关系矛盾
    示例: A依赖B的v1版本，但B已升级到v2
    影响: 执行失败或异常

  权限冲突:
    定义: 权限要求相互矛盾
    示例: 技能A需要管理员权限，技能B禁止管理员权限
    影响: 安全风险或功能受限

  资源冲突:
    定义: 资源使用策略矛盾
    示例: 技能A使用GPU，技能B禁用GPU
    影响: 性能下降或执行失败
```

**解决策略**：

```yaml
冲突解决策略:
  策略1_保留高匹配度技能:
    原理: 保留综合评分最高的技能
    适用: 功能重复类冲突
    优点: 简单直接，效果可控

  策略2_合并功能:
    原理: 整合两个技能的核心功能
    适用: 互补型重叠
    优点: 功能完整，性能最优
    要求: 需要技能支持模块化

  策略3_设置调用优先级:
    原理: 定义技能调用顺序规则
    适用: 版本兼容类冲突
    优点: 保持功能多样性
    配置: priority规则表

  策略4_用户手动确认:
    原理: 列出冲突由用户选择
    适用: 复杂冲突场景
    输出: 冲突详情+推荐方案
```
