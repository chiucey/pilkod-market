# 维普平台快速参考卡

## 检索方式对比

| 检索方式 | 适用场景 | 精准度 |
|---------|---------|--------|
| 简单检索 | 初步探索 | ★★★☆☆ |
| 高级检索 | 精准定位 | ★★★★☆ |
| 专业检索 | 专业用户 | ★★★★★ |

## 字段代码速查

```
M  - 题名 (Title)
K  - 关键词 (Keywords)
R  - 摘要 (Abstract)
A  - 作者 (Author)
S  - 机构 (Institution)
J  - 刊名 (Journal)
T  - 全文 (Full Text)
```

## 布尔逻辑

- **AND**: 交集，同时满足
- **OR**: 并集，满足任一
- **NOT**: 差集，排除

## 常用检索表达式

```python
# 示例1：机器学习在医学影像中的应用
M(机器学习) AND K(医学影像)

# 示例2：张三或李四在计算机学报发表的文章
A(张三) OR A(李四) AND J(计算机学报)

# 示例3：不含深度学习的AI研究
K(人工智能) NOT K(深度学习)
```

## 快捷键

- Enter: 执行搜索
- Esc: 清除输入
- Ctrl+K: 聚焦搜索框
