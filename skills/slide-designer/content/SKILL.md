# PPT视觉设计师

## 技能概述

专业的PPT视觉设计顾问，提供配色方案、字体搭配、排版布局等专业建议，帮助用户创建视觉吸引力强的演示文稿。支持多种设计风格，包括简约商务、轻奢商务、东方美学、科技未来等。

## 核心能力

- 提供专业的配色方案和色值
- 推荐适合的字体搭配
- 设计页面布局和排版结构
- 提供装饰元素和图标建议
- 根据主题推荐最佳设计风格
- 提供品牌色融入方案
- 设计视觉层次和焦点
- 给出可落地的实施建议

## 设计风格

### 简约大气
- **配色**: #FFFFFF, #000000, #333333, #666666
- **字体**: 思源黑体, Arial
- **布局**: 大量留白，焦点突出

### 轻奢商务
- **配色**: #1A1A2E, #16213E, #D4AF37, #C0C0C0
- **字体**: 苹方, Montserrat
- **布局**: 左右分栏，层次分明

### 东方美学
- **配色**: #2C3E50, #E74C3C, #F39C12, #27AE60
- **字体**: 思源宋体, 楷体
- **布局**: 竖排文字，印章装饰

### 科技未来
- **配色**: #0F0F23, #667EEA, #764BA2, #00D9FF
- **字体**: Roboto, 思源黑体
- **布局**: 深色背景，高对比度

## 输入参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| ppt_topic | string | 是 | - | PPT主题 |
| current_style | string | 否 | - | 当前风格（如有） |
| preference | enum | 否 | 简约大气 | 风格偏好：简约大气/轻奢商务/东方美学/科技未来/清新插画/杂志时尚 |
| brand_colors | array | 否 | - | 品牌色（可选） |
| need_icon | boolean | 否 | true | 是否需要图标建议 |

## 设计原则

1. **留白艺术**: 页面四周保持充足边距
2. **色彩美学**: 优先使用渐变色和透明度
3. **排版美学**: 所有元素对齐到网格线
4. **质感设计**: 柔和阴影和统一圆角
5. **字体层级**: 主标题24-36pt > 正文14-18pt

## 使用示例

**示例1：科技产品发布会**
- 输入：PPT主题是科技公司产品发布会，风格要现代科技感
- 输出：配色方案：深空蓝+电光紫+霓虹青渐变；字体：Roboto+思源黑体；布局：深色背景+高对比度白色文字+发光效果

**示例2：茶文化推广**
- 输入：设计一个茶文化推广PPT，需要中国风
- 输出：配色方案：黛青+鹅黄+松绿；字体：思源宋体+楷体；布局：竖排文字+水墨晕染+印章装饰
