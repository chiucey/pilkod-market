# 讲义与速记卡规范

三件套里，HTML 题库负责「检验」，讲义和速记卡负责「输入」。分工不同，**不要把讲义原样塞进卡片**。

## 1. 讲义（`讲义-<章节>.md`）

目标：让一个**完全没学过这门课的人**，在限定时间内看懂每个概念为什么长这样。

### 章节内部固定结构

```markdown
# 第3章 确定性推理方法

## 0. 本章一句话
用"知识 + 推理 = 智能"这条线串起来：知识表示好了还不够，得让机器能"推"出来。

## 1. 知识点正文
（每个小节都用下面这个模板）

### 3.1.1 推理的定义

**大白话**：打个比方 / 说明它解决什么问题。

**术语**：
- 推理（inference）：从已知事实出发，用知识推出结论的思维过程。
- 证据（evidence）：推理起点的已知事实。
- 知识（knowledge）：推理时使用的规则。

**结构**（有图/公式的画出来）：
```

推理
├─ 证据（已知事实） ──┐
├─ 知识（规则）  ────┤──→ 结论
└─ 某种策略    ──┘

**记忆锚点**：一句话能复述的东西。

**易错**：⚠️ 考生最容易写错/理解错的地方。

## 2. 速记卡（`速记卡-<章节>.md`）

目标：**考前 1-2 小时能扫完**，只留"必须写得出关键词"的东西。

- 每条不超过 3 行。
- 只写**可默写的短答案**，不写推导。
- 用 `❗` 标高频，用 `⚠️` 标易错。
- 章节末尾放一个**「如果只能背 10 条」**清单——这是整份速记卡的兜底。

示例：

```markdown
## 1.2 归结原理

- 归结式：$L_1 \cup L_2 - \{L_1',L_2'\}$
- 前提：①子句集变子句集 ②消去的文字互补 ③不出现新文字 ❗
- 归结反演 = 归结 + 引入否定结论
- 海伯伦定理：不可满足 ⟺ 存在空子句 ⚠️ 不是"存在空子句 ⟹ 不可满足"
```

## 3. 时间盒路径（写在讲义开头）

用户没给具体时间时**不要瞎写**——按下面三种预设给，并在交付时问他实际有多少时间。

| 剩余时间 | 必看 | 只看结论 | 可放弃 |
|---------|------|-----------|--------|
| **2 小时** | 标记为 ❗ 的全部知识点 | 速记卡全文 | 所有完整例题 |
| **一整天（6h）** | 全部知识点 | 速记卡 + 题库刷一轮 | 图谱类扩展内容 |
| **3 天以上** | 全部 + 每章题库刷两轮 | — | — |

写的时候**必须落到具体节号**，不能只说"重点看前三节"。

## 4. 三件套的一致性

- 讲义的每个小节 → 至少 1 张卡片。**没有卡片的讲义说明没想清楚考什么**。
- 速记卡每条 → 必须能在题库里找到对应卡片。
- 卡片答案里出现的公式 → 讲义里必须有完整推导。
- 交叉核对一遍再交付，三者对不上的地方就是没吃透的考点。
