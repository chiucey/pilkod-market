# 卡片 Schema

## topics.json 顶层结构

```json
[
  {
    "title": "3.1 推理的基本概念",
    "week": "第30-37页",
    "colorKey": "concept",
    "summary": "一句话说清这个主题覆盖什么。",
    "cards": [ ... ]
  }
]
```

- `title` 必填。侧边栏和首页卡片都显示它，写成「章节号 + 标题」便于定位回 PPT 页码。
- `week` 建议写成 PPT 页码范围（`第30-37页`），考前对答案用得上。
- `colorKey` 可选，取 `concept|calculation|diagram|comparison|fill`，决定首页进度条颜色。
- `summary` 一句话，**不要写成目录**。它的作用是让人在首页三秒内决定先刷哪个。

## card 字段

| 字段 | 必填 | 类型 | 说明 |
|------|------|------|------|
| `id` | ✅ | string | 全局唯一。建议 `<topic-slug>-<序号>`，如 `reasoning-07` |
| `type` | ✅ | enum | `concept` / `fill` / `calculation` / `comparison` / `diagram` |
| `difficulty` | ✅ | int | 1-3，渲染为 ★☆☆。**按"你第一次看到能不能马上答出来"评**，不是按知识难度 |
| `question` | ✅ | string | 题面。填空卡必须含 `____`（3 个以上下划线） |
| `answer` | ✅ | string \| object | 见下方两种形态 |
| `hint` | | string | 一句话提示。**不要给答案**，给的是"往哪个方向想" |
| `explain` | | string | 折叠的知识点讲解。讲原理和推导，不是复述答案 |
| `priority` | | bool | true 时卡片头部显示「高频」红标 |

### answer 的两种形态

纯字符串：

```json
"answer": "反证法：P ⊨ Q，当且仅当 P ∧ ¬Q 不可满足。"
```

对象（多段式，填空卡强烈建议用）：

```json
"answer": {
  "answer": "1975 年；肖特里菲（E. H. Shortliffe）",
  "常见错答": ["1976 年", "肖特利夫", "Shortlife"],
  "记忆提示": "CF = certainty factor，1975 年，肖…特…里…菲"
}
```

渲染顺序固定为：`answer` → `⚠️ 常见错答` → `🧠 记忆提示`。

## 五种题型的适用场景

写卡片前先判断这条考点**最可能以什么题型出现**，再选 type。

### `fill` 填空题
考**精确字**：年份、人名、术语全称、缩写、公式符号、编号。

- 答案要短到能默写，超过 15 字就不像填空题了，改成 `concept`。
- `常见错答` 是这张卡最有价值的部分——**写错在哪比写对更重要**。
- 一个句子最多挖 2 个空。挖 5 个空是做阅读理解。

### `concept` 概念题
考定义、特点、原理、背景。**新概念必须在这里讲全**，因为用户不假设任何前置知识。

- 答案用「定义 + 分点罗列」，别写成散文。
- 长论述只在概念题出现，且要点化——考试简答是按点给分的。

### `calculation` 计算题
考公式套用、数值演算。**只给公式 + 解题套路 + 一道完整样例**，不要每道都写全步骤——用户自己动手写，写一遍才记得住。

- 答案里必须写清**每一步在干什么**，而不只是数字。
- 结尾给一行「套路总结」，把这类题的通用步骤固化下来。

### `comparison` 比较题
考 A 与 B 的区别。**答案固定用对照结构**（表格或成对的「A：… / B：…」），不要写成两段独立叙述——对照着记才快。

### `diagram` 画图题
考结构图、流程图、框架图。答案用 ASCII 图或缩进层级表达，**必须能照着画出来**。纯文字描述在这类考点上等于没答。

## 硬性写作约束

1. **`question` 里不出现答案**。写完自检一遍：能不能只读题面就答上来。
2. **`hint` 不泄漏答案**。提示给方向（"想想它和前一章方法的区别"），不给结论。
3. **新概念用大白话先解释一遍，再给术语**。用户明确说过：这门课里所有知识都是新概念，突击时要全部讲清楚。
4. **数学优先写 Unicode，不要写 LaTeX**——`→ ¬ ∧ ∨ ∅ ⊕ ≤ ≥ Σ ∀ ∃ ⊆ ∈`，算子名直接写 `min` `max`。
   `latex_to_unicode.py` 只覆盖已验证的符号集（见下），**它转不了的命令会原样显示在浏览器里**，
   而 `build_panel.py` 会直接报错拦下。写 `$...$` 也能用，但必须让整个文件都通过转换器。
   已覆盖：`\to \neg \lor \land \forall \exists \subseteq \iff \oplus \varnothing
   \min \max \sum \le \ge \times \cdot \cap \cup \models \boxed \bigl \xrightarrow` 等。
5. **`difficulty` 3 的卡不超过 20%**。全是三星等于没有三星。
