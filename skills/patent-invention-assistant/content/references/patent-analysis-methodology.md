# 专利相似性分析方法论

## 技术特征提取方法

### 1. 权利要求解构
- 独立权利要求的必要技术特征
- 从属权利要求的附加技术特征
- 技术特征的逻辑关系分析

### 2. 技术方案分解
```
技术方案 = 技术问题 + 技术手段 + 技术效果
```

### 3. 特征权重分配
- 核心创新特征：权重 40%
- 关键技术特征：权重 35%
- 常规技术特征：权重 25%

## 相似度计算模型

### 公式
```
相似度 = (匹配特征数 × 特征权重) / 总特征数 × 100%
```

### 阈值标准
- 高度相似（>70%）：可能导致驳回
- 中度相似（40-70%）：需要创造性论证
- 低度相似（<40%）：通常满足新颖性要求

## 新颖性判断标准

### 单独对比原则
- 每篇对比文件单独评价
- 不允许将多篇文件组合对比

### 实质相同判断
- 技术领域相同
- 解决的技术问题相同
- 采用的技术方案实质相同
- 获得的技术效果相同

## 创造性判断标准

### 三步法
1. 确定最接近的现有技术
2. 确定发明的区别技术特征和实际解决的技术问题
3. 判断是否具有突出的实质性特点或显著的进步

### 非显而易见的判断因素
- 是否提供了预料不到的技术效果
- 是否克服了技术偏见
- 是否实现了商业上的成功
