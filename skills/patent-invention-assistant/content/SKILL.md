# 发明专利辅助申请助手

专业的发明专利辅助申请工具，通过全文检索比对相似专利，深度分析技术相似性，科学评估授权可能性，并提供针对性的修改建议。

## 核心工作流程

### 第一步：发明内容解析

当用户提供发明专利申请内容时，首先对发明进行结构化解析：

1. **技术领域识别**：确定发明所属的技术领域和分类号
2. **技术问题**：明确发明要解决的技术问题
3. **技术方案**：提取发明的核心技术方案和关键步骤
4. **技术效果**：识别发明的预期技术效果和创新点

### 第二步：相似专利全文检索

使用多维度检索策略查找相似专利：

1. **关键词检索**：提取发明的核心关键词进行检索
2. **语义检索**：基于技术领域进行语义扩展检索
3. **分类号检索**：利用相关技术分类号进行精准检索

**检索数据库**：
- CNIPA中国国家知识产权局专利数据库
- USPTO美国专利商标局
- WIPO世界知识产权组织
- EPO欧洲专利局

### 第三步：全文比对与相似性分析

对检索到的相似专利进行深度全文比对：

1. **技术特征提取**：从每篇相似专利中提取技术特征
2. **特征对比矩阵**：建立发明与相似专利的技术特征对比矩阵
3. **相似度计算**：计算技术特征的相似度百分比
4. **创新点识别**：识别发明相对于现有技术的创新点

**相似性评估标准**：
- 相似度 < 30%：高度新颖，易于授权
- 相似度 30%-60%：中等新颖，需要突出创新点
- 相似度 > 60%：高度相似，授权难度较大

### 第四步：获批可能性评估

基于相似性分析结果，评估专利申请的授权可能性：

**新颖性评估**：
- 评估发明是否具有新颖性特征
- 识别破坏新颖性的相似文献
- 提供新颖性补救建议

**创造性评估**：
- 分析发明的技术效果是否非显而易见
- 评估是否具有预料不到的技术效果
- 提供创造性论证支持

**授权可能性等级**：
- 高（>80%）：创新性突出，授权前景良好
- 中（50%-80%）：需进一步完善，存在授权可能
- 低（<50%）：相似度较高，需重大修改

### 第五步：修改建议

根据分析结果，提供针对性的修改建议：

1. **权利要求书修改建议**
   - 调整保护范围
   - 增加区别技术特征
   - 修改独立/从属权利要求

2. **说明书修改建议**
   - 补充技术效果数据
   - 强化发明点描述
   - 完善具体实施方式

3. **申请策略建议**
   - 分案申请策略
   - 优先权调整
   - 保护范围优化

## 输出格式

技能将生成完整的专利辅助分析报告，包括：

1. **相似专利检索报告**
   - 相关专利列表（标题、申请号、公开号）
   - 专利摘要和核心权利要求

2. **相似性分析报告**
   - 技术特征对比表
   - 相似度评分
   - 关键差异点识别

3. **授权可能性评估报告**
   - 新颖性评估结论
   - 创造性评估结论
   - 综合授权可能性评分

4. **修改建议报告**
   - 具体修改方案
   - 修改优先级排序
   - 预期效果说明

## 使用示例

**用户输入**：
```
我有一项关于"基于深度学习的图像超分辨率重建方法"的发明专利申请，需要进行专利检索和相似性分析。

发明内容摘要：
本发明公开了一种基于深度学习的图像超分辨率重建方法，包括以下步骤：
1. 采用改进的残差网络作为特征提取骨干
2. 引入注意力机制增强特征表达
3. 使用多尺度融合策略提升重建效果
4. 采用新型损失函数优化训练过程

预期解决的技术问题：现有方法存在计算复杂度高、重建效果不佳的问题。
```

**预期输出**：
完整的专利辅助分析报告，包含相似专利检索结果、相似性分析、授权可能性评估及修改建议。
