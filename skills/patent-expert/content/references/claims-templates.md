# 权利要求书模板库

## 模板一：产品类权利要求

```text
1. 一种[产品名称]，包括[共有特征A]、所述[共有特征B]，
其特征在于，还包括[区别特征X]，
所述[区别特征X]与所述[共有特征A]连接，
用于[达到的技术效果]。

2. 根据权利要求1所述的[产品名称]，其特征在于，
所述[区别特征X]包括[具体结构描述]。

3. 根据权利要求2所述的[产品名称]，其特征在于，
所述[具体结构]的尺寸为[数值范围]mm。

4. 根据权利要求1-3任一项所述的[产品名称]，其特征在于，
还包括[附加功能部件]，
所述[附加功能部件]与所述[区别特征X]通信连接。
```

## 模板二：方法类权利要求

```text
1. 一种[方法名称]，其特征在于，包括以下步骤：
S1：[步骤一描述]；
S2：[步骤二描述]；
S3：[步骤三描述]，
其中，[区别技术特征的描述]，用于[技术效果]。

2. 根据权利要求1所述的[方法名称]，其特征在于，
所述S2具体包括：
S2-1：[子步骤描述]；
S2-2：[子步骤描述]。

3. 根据权利要求1所述的[方法名称]，其特征在于，
在执行S1之前还包括：
S0：[预处理步骤描述]。
```

## 模板三：软硬件结合类权利要求

```text
1. 一种[系统/装置名称]，包括：
存储模块，用于存储[数据/程序]；
处理模块，与所述存储模块连接，用于[处理功能]；
其特征在于，还包括：
感知模块，用于采集[环境/用户]信息；
所述处理模块根据所述感知模块采集的信息，
执行[区别技术特征描述]，用于[技术效果]。

2. 根据权利要求1所述的[系统/装置名称]，其特征在于，
所述感知模块包括[传感器类型]。

3. 根据权利要求1所述的[系统/装置名称]，其特征在于，
所述处理模块运行有[算法/模型]，
用于[具体功能描述]。
```

## 常见技术特征表述库

| 技术特征 | 专利规范表述 |
|---------|------------|
| 两个部件连接 | 所述第一部件与所述第二部件连接 |
| 多个部件配合 | 所述多个部件协同配合 |
| 实现某种功能 | 用于实现[功能描述] |
| 检测信号 | 感测[物理量]信号 |
| 数据处理 | 对[数据/信号]进行处理 |
