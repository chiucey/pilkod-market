# 专利撰写规范指南

## 一、权利要求书撰写规范

### 1.1 独立权利要求撰写要点

**基本结构**：
```
一种[产品/方法名称]，包括[技术特征A]、所述[技术特征B]，其特征在于，
所述[区别技术特征C]，用于[达到的技术效果描述]。
```

**撰写原则**：
- 使用"包括"、"包含"、"由...组成"等开放性词汇最大化保护范围
- 避免使用"其特征在于"后紧跟过多限定性描述
- 区别技术特征应清晰对应要解决的技术问题

### 1.2 从属权利要求撰写要点

**引用格式**：
```
根据权利要求1所述的[产品/方法名称]，其特征在于，
所述[进一步限定的技术特征]。
```

**层次布局**：
- 第二层：材料、组成、结构细节
- 第三层：具体实施方式、优化方案
- 第四层：具体参数、数值范围

## 二、说明书撰写规范

### 2.1 技术领域
```
本发明涉及[技术领域]，具体涉及[细分领域]。
```

### 2.2 背景技术
```
现有技术中存在[现有技术描述]，[指出缺陷/问题]。
```

### 2.3 发明内容
```
本发明的目的是提供[技术方案名称]，以解决[技术问题]。
```

### 2.4 具体实施方式
```
以下结合附图和具体实施例对本发明进行说明。
实施例1：[具体描述]
有益效果：[列出技术效果]
```

## 三、术语规范对照表

| 规范用语 | 避免用语 |
|---------|---------|
| 其特征在于 | 大约、差不多 |
| 所述 | 那个、这个 |
| 包括 | 可能、大概 |
| 设置有 | 好像、似乎 |
| 连接 | 接上、连着 |
