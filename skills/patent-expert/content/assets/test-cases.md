# 专利专家技能测试用例集

## 测试用例 1：保温杯专利交底书解析

**输入**：
> 我发明了一种新型保温杯，内胆有一层石墨烯涂层，盖子上有个温度显示屏靠温差发电，请帮我写权利要求。

**预期输出要求**：
1. 准确提取"石墨烯涂层内胆"和"温差发电温度显示屏"作为核心区别技术特征
2. 构建至少1个独立权利要求
3. 构建至少2个从属权利要求
4. 权利要求结构完整，包含引用关系
5. 使用规范的专利法言法语

**评估标准**：
- [ ] 准确识别石墨烯涂层技术特征
- [ ] 准确识别温差发电显示屏技术特征
- [ ] 独立权利要求保护范围合理
- [ ] 从属权利要求层次递进
- [ ] 术语使用规范

## 测试用例 2：OA答复逻辑测试

**输入**：
> 审查员用对比文件1（一种普通保温杯）和对比文件2（一种温差发电手环）结合，认为我的保温杯发明没有创造性。怎么反驳？

**预期输出要求**：
1. 必须运用"三步法"进行分析
2. 指出对比文件2属于不同技术领域
3. 说明温差发电手环与保温杯水环境的技术差异
4. 论述缺乏将温差发电结合到保温杯水环境中的技术启示
5. 提出本申请的有益技术效果

**评估标准**：
- [ ] 运用三步法完整分析
- [ ] 技术领域差异论证充分
- [ ] 技术启示不存在论证有力
- [ ] 有益效果论述清晰
- [ ] 答复策略具有可操作性

## 测试用例 3：AI算法专利

**输入**：
> 我开发了一种新的图像识别算法，结合了注意力机制和图神经网络，能够在保持精度的同时大幅降低计算量。请帮我撰写专利。

**预期输出要求**：
1. 正确识别"注意力机制+图神经网络"的组合方案
2. 正确识别"精度保持+计算量降低"的技术效果
3. 独立权利要求应涵盖算法核心步骤
4. 从属权利要求应包含具体实现细节
5. 说明书应包含技术领域、背景技术、具体实施方式

**评估标准**：
- [ ] 算法技术特征提取准确
- [ ] 技术效果识别完整
- [ ] 权利要求涵盖核心发明点
- [ ] 保护范围合理
- [ ] 说明书框架完整

## 测试用例 4：机械结构专利

**输入**：
> 我设计了一种可折叠自行车的车架结构，通过巧妙的连杆机构设计，实现了单手一键折叠，折叠后体积缩小80%。请帮我写专利。

**预期输出要求**：
1. 准确识别"连杆机构"和"单手一键折叠"作为核心特征
2. 识别"体积缩小80%"作为技术效果
3. 权利要求应包含结构特征和功能特征
4. 从属权利要求应包含具体连杆配置细节
5. 说明书应包含附图说明和具体实施方式

**评估标准**：
- [ ] 核心结构特征提取准确
- [ ] 功能实现特征描述清晰
- [ ] 技术效果与特征对应关系明确
- [ ] 权利要求层次合理
- [ ] 说明书结构完整
