# 播客助手

专业播客处理工具，提供完整的播客内容处理工作流。

## 核心功能

### 1. 下载播客音频 🎙️
**触发**: "下载播客"、"下载音频"、"RSS URL下载"、"获取播客"

**执行流程**:
1. 解析RSS Feed URL，获取播客元数据（标题、描述、作者）
2. 提取所有音频文件链接
3. 下载用户指定的单集或全部音频
4. 保存到 `downloads/podcasts/` 目录

**输出格式**:
```json
{
  "title": "播客标题",
  "author": "作者",
  "episodes": [
    {
      "title": "单集标题",
      "audio_url": "音频URL",
      "duration": "时长",
      "pub_date": "发布日期"
    }
  ]
}
```

### 2. AI 转录（Whisper）📝
**触发**: "转录"、"语音转文字"、"Whisper"、"音频转文字"

**执行流程**:
1. 使用 Whisper 模型进行语音识别
2. 支持中文、英文及多语言自动检测
3. 输出时间戳对齐的文本
4. 保存转录结果为 SRT/VTT 格式（带时间戳）

**输出格式**:
```json
{
  "text": "完整转录文本",
  "segments": [
    {
      "start": "00:00:00",
      "end": "00:00:05",
      "text": "说话内容"
    }
  ]
}
```

### 3. 生成摘要 🧠
**触发**: "摘要"、"总结播客"、"关键内容"、"show notes"

**执行流程**:
1. 分析转录文本内容
2. 提取关键主题、观点和要点
3. 生成结构化摘要
4. 识别重要时间点和嘉宾发言

**输出格式**:
```json
{
  "summary": "核心内容摘要（200字内）",
  "highlights": ["要点1", "要点2", "要点3"],
  "timestamps": [
    {"time": "00:05:00", "topic": "讨论主题"}
  ],
  "guests": ["嘉宾名称"]
}
```

### 4. 播客对话搜索 💬
**触发**: "搜索播客"、"播客对话搜索"、"查找内容"

**执行流程**:
1. 在已转录的播客内容中建立索引
2. 支持自然语言查询
3. 返回相关片段及时间戳
4. 高亮显示匹配内容

**输出格式**:
```json
{
  "query": "搜索内容",
  "results": [
    {
      "episode": "单集标题",
      "timestamp": "00:15:30",
      "text": "相关内容片段",
      "relevance": 0.95
    }
  ]
}
```

## 工作流程示例

```
用户: 下载这个播客 https://example.com/feed.xml 第1-3集
↓
解析RSS → 获取元数据 → 下载指定音频 → 返回文件路径

用户: 转录 downloads/podcasts/episode1.mp3
↓
加载音频 → Whisper转录 → 输出带时间戳文本 → 保存文件

用户: 总结这个播客
↓
读取转录 → 生成摘要 → 输出结构化内容

用户: 搜索"AI发展趋势"
↓
查询索引 → 检索相关内容 → 返回匹配片段
```

## 技术实现

| 功能 | 工具/模型 | 说明 |
|------|----------|------|
| RSS解析 | feedparser | Python RSS/Atom解析库 |
| 音频下载 | requests + FFmpeg | 流式下载与格式转换 |
| 语音转录 | OpenAI Whisper | 支持中文的高精度模型 |
| 摘要生成 | LLM | 基于转录内容智能摘要 |
| 对话搜索 | 向量数据库 | 支持语义搜索 |

## 文件存储结构

```
downloads/
└── podcasts/
    ├── [播客名称]/
    │   ├── metadata.json      # 播客元数据
    │   ├── audio/
    │   │   ├── episode1.mp3
    │   │   └── episode2.mp3
    │   ├── transcripts/
    │   │   ├── episode1.json
    │   │   └── episode1.srt
    │   └── summaries/
    │       └── episode1.json
    └── index.json             # 全局索引
```

## 错误处理

| 错误类型 | 处理方式 |
|---------|---------|
| RSS解析失败 | 提示用户检查URL格式 |
| 音频下载超时 | 重试3次，增加超时时间 |
| 转录失败 | 检查音频格式，建议转换为MP3 |
| 空转录结果 | 提示音频质量问题 |

## 触发边界

**应触发**:
- 用户提供RSS URL并要求下载
- 用户要求转录、摘要或搜索已下载的播客
- 用户提及播客相关的任何操作

**不应触发**:
- 通用音频处理（非播客场景）
- 音乐下载或处理
- 视频内容处理
