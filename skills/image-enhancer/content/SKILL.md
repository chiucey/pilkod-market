# Image Enhancer

修图质感，让图片更清晰、更专业。

## 适用场景

- 截图质量提升（文档/博客/演示）
- 社交媒体配图优化
- 低分辨率图片放大
- 模糊照片锐化
- 压缩伪影去除
- 批量处理文件夹内图片

## 触发词

- "修这张图"
- "放大到4K"
- "让截图更清晰"
- "去掉压缩伪影"

## 核心行为

1. 分析原图质量（分辨率/锐度/压缩情况）
2. 智能放大
3. 增强边缘细节
4. 清理压缩噪声
5. 按用途优化（网络/打印/社交）

## 注意

- 保留原文件作为备份
- 对截图和数字图像效果最好
- 可批量处理

## 与 image_synthesize 的关系

两者都有放大能力：
- **image_synthesize**的 upscale：AI重绘放大，适合插图/照片
- **image-enhancer**：保留原始细节，提升清晰度，适合截图/UI图
