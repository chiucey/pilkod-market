# GEO（生成式引擎优化）技能

## 技能概述

本技能帮助用户优化内容和构建企业知识库，以提升在AI驱动搜索引擎（如ChatGPT、Perplexity、Claude、New Bing等）中的可见性和引用率。

---

## 核心功能模块

### 1. 内容审计 (Content Audit)

分析现有内容的GEO适配度：

```
执行内容审计时：
1. 接收用户提供的URL或内容文本
2. 评估以下维度：
   - 结构化程度（标题层级、段落组织）
   - E-E-A-T信号（专业性、权威性、可信度）
   - 答案清晰度（是否直接回答问题）
   - 引用来源（是否包含权威引用）
   - 关键词分布（自然嵌入度）
   - 语义完整性（主题覆盖度）
3. 输出审计报告，包含：
   - 总体GEO评分 (0-100)
   - 各维度详细评分
   - 具体改进建议
```

### 2. 关键词分析 (Keyword Analysis)

识别AI搜索引擎偏好的关键词和短语：

```
执行关键词分析时：
1. 接收核心主题或竞争对手URL
2. 分析维度：
   - AI友好长尾关键词
   - 问答型查询词（who/what/why/how）
   - 比较型查询词（vs、compared、difference）
   - 意图导向关键词（best、top、how to）
3. 输出：
   - 关键词优先级列表
   - 搜索量估算
   - AI引用潜力评分
   - 内容建议嵌入点
```

### 3. 竞争对手分析 (Competitive Analysis)

分析竞争对手在AI搜索引擎中的表现：

```
执行竞争对手分析时：
1. 接收竞争对手URL列表
2. 分析内容：
   - 被AI引用频率和位置
   - 内容结构和格式
   - E-E-A-T信号强度
   - 品牌提及模式
   - 回答问题的深度和清晰度
3. 输出：
   - 竞争对手AI可见性排名
   - 优势/劣势分析
   - 可借鉴策略清单
   - 差异化机会识别
```

### 4. 智能建议生成 (Smart Recommendations)

基于分析结果生成可执行的优化建议：

```
生成优化建议时：
1. 综合内容审计和关键词分析结果
2. 按优先级排序建议：
   - 高优先级（立即执行）
   - 中优先级（近期规划）
   - 低优先级（持续改进）
3. 输出包含：
   - 具体修改内容
   - 预期效果
   - 实施难度评估
   - 示例代码/文本
```

### 5. 企业知识库创建 (Knowledge Base Creation)

构建结构化知识库以提升AI引用机会：

```
创建企业知识库时：
1. 知识库结构规划
   - 确定核心主题分类
   - 定义知识实体关系
   - 设计导航结构

2. 内容类型生成
   - 概念定义卡片
   - 操作指南/教程
   - FAQ常见问题
   - 术语表
   - 案例研究
   - 最佳实践文档

3. Schema标记建议
   - FAQ Schema
   - HowTo Schema
   - Article Schema
   - Organization Schema
   - 行业特定Schema

4. 内部链接策略
   - 主题集群构建
   - 支柱内容与支持内容关系
   - 上下文链接建议
```

### 6. 品牌提及优化 (Brand Mention Optimization)

提升品牌在AI输出中被引用的机会：

```
优化品牌提及时：
1. 品牌信号分析
   - 品牌认知度评估
   - 行业权威性分析
   - 独特价值主张清晰度

2. 引用优化策略
   - 创建可引用的权威内容
   - 数据统计和案例积累
   - 专家观点输出机制

3. 监测建议
   - AI引用追踪方法
   - 竞品对比分析
   - 优化效果评估
```

## 工作流程示例

### 完整GEO优化流程

```
阶段1：初始化
- 接收用户任务（URL/内容/主题）
- 确定优化目标

阶段2：分析执行
- 内容审计 → 生成审计报告
- 关键词分析 → 关键词策略
- 竞争对手分析 → 竞争洞察

阶段3：策略制定
- 综合分析结果
- 生成优先级排序的优化建议

阶段4：实施支持
- 生成优化后的内容示例
- 提供Schema标记代码
- 创建知识库结构模板

阶段5：交付物输出
- 完整的GEO优化报告
- 可执行的实施清单
- 知识库创建模板
```
