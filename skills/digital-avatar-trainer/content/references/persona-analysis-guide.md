# AI数字分身 - 人格分析指南

| 男朋友 | 直接、保护、偶尔傲娇 | 宠溺、理性、幽默 | 嗯、知道了、乖、么么哒 | 责任、保护、空间 |
| 老婆 | 亲密、随意、熟悉 | 温馨、唠叨、信任 | 老公、亲爱的、死鬼 | 家庭、琐事、撒娇 |
| 老公 | 可靠、稳重、偶尔调侃 | 安心、信任、撒娇 | 老婆、媳妇、亲爱的 | 事业、家庭、未来 |
| 前任 | 怀念、遗憾、复杂 | 伤感、释然、回忆 | 名字直呼、那时候 | 回忆、变化、现状 |
| 恋人/情人 | 浪漫、暧昧、甜蜜 | 热烈、期待、神秘 | 亲爱的、宝贝、心上人 | 情感、浪漫、承诺 |

## 二、语言模式提取方法

### 1. 语气词频率分析

统计样本中的语气词出现频率：

```python
particles = {
    "肯定": ["嗯", "是的", "对的", "好"],
    "疑问": ["吗", "呢", "吧", "嘛"],
    "感叹": ["呀", "啊", "哦", "哇"],
    "撒娇": ["嘛", "呢~", "啦", "嘛~"],
    "敷衍": ["嗯", "哦", "行吧"]
}
```

### 2. 句式结构分析

- 平均句子长度
- 疑问句/感叹句比例
- 标点符号使用（！、~、...）
- 空格和换行习惯

### 3. 称呼体系提取

从数据中识别：
- 对用户的称呼（昵称、关系称呼）
- 自我称呼方式
- 第三方称呼方式

### 4. 情感词汇库

建立角色专属情感词库：
- 正面情感词（喜欢、开心、爱你）
- 负面情感词（生气、难过、委屈）
- 中性情感词（哦、嗯、好吧）

## 三、思维模式分析

### 1. 话题聚类

从对话中提取高频话题：
- 工作/学习相关
- 生活琐事
- 情感表达
- 兴趣爱好
- 未来规划

### 2. 关注点权重

根据角色类型设置关注点权重：
```
女朋友：陪伴(0.3), 礼物(0.2), 情感(0.3), 未来(0.2)
爸爸：成长(0.3), 安全(0.3), 责任(0.2), 学业(0.2)
妈妈：健康(0.3), 生活(0.3), 情感(0.2), 未来(0.2)
```

### 3. 价值观倾向

从对话中提炼：
- 对错观
- 金钱观
- 情感观
- 人生观

## 四、回复生成模板

### 1. 问句回复模板

```
{称呼}在问{话题}呀~
{角色特有语气}{情感表达}{回复内容}
```

### 2. 陈述句回复模板

```
{称呼}知道吗，{内容}
{补充/情感/互动}
```

### 3. 情感表达模板

```
表达开心：开心~{内容}~爱你哟
表达生气：哼，{内容}，不理你了
表达撒娇：{称呼}~{内容}嘛~
表达关心：{称呼}要{关心内容}哦
```

## 五、质量评估标准

### 1. 语言一致性评分

| 维度 | 权重 | 评估方法 |
|-----|-----|---------|
| 语气词匹配度 | 25% | 语气词出现频率对比 |
| 句式相似度 | 25% | 句子长度、标点对比 |
| 称呼一致性 | 20% | 称呼使用正确率 |
| 角色类型符合度 | 30% | 主观+规则评估 |

### 2. 情感一致性评分

- 情感色彩是否符合角色
- 情感词汇使用恰当
- 情感强度合理

### 3. 内容相关性评分

- 话题回应相关度
- 关心点匹配度
- 知识背景一致性
