# 歌词获取技能

## 核心能力

根据用户提供的歌曲名称，搜索并返回歌曲的完整歌词。

## 工作流程

### 1. 接收歌曲名称
- 解析用户输入，提取歌曲名称
- 如果用户描述模糊，尝试理解并提取歌曲名
- 处理中英文歌曲名称

### 2. 搜索歌词
- 使用网络搜索工具搜索歌曲歌词
- 搜索关键词格式：`"{歌曲名称}" 歌词`
- 优先搜索权威歌词网站或百科

### 3. 提取并返回歌词
- 从搜索结果中提取歌词内容
- 返回完整歌词文本
- 标注歌词来源

### 4. 失败处理
如果无法获取歌词，明确告知原因：
- 歌曲不存在或名称错误
- 版权限制无法获取
- 网络搜索失败
- 其他技术原因

## 输出格式

```
【歌曲名称】
【歌手】（如可知）

[完整歌词内容]

---
歌词来源：XXX
```

## 示例

**用户输入**："月亮之上的歌词"

**输出**：
```
【月亮之上】
【凤凰传奇】

我在仰望 月亮之上
有多少梦想 在自由地飞翔
昨天遗忘啊 风干了忧伤
我要和你重逢在那苍茫的路上

生命已被牵引 潮落潮涨
有你的远方 就是天堂
...

---
歌词来源：百度百科/QQ音乐
```

## 注意事项

- 直接返回歌词，不做过多解释
- 歌词获取失败时，说明具体原因
- 支持中文、英文及其他语言歌曲
- 对于纯音乐或无人声曲目，如实告知
