# 更新日志

## [1.3.0] - 2026-04-09

### 新增
- ✨ **智能正文边界检测**：自动识别正文结束位置，排除广告、推广、相关阅读等内容
- ✨ 支持多种检测策略：关键词定位、结构分析、内容密度分析
- ✨ 检测信息记录到文章数据中，便于追溯

### 优化
- ✨ **智能水印过滤**：动态获取公众号名称，自动过滤该公众号的水印文字
- ✨ 支持公众号名称的多种写法变体（加后缀、去空格、大小写）
- ♻️ 优化OCR过滤规则，过滤更多常见推广文字（转载需注明、来源、阅读数等）

## [1.2.0] - 2026-04-09

### 优化
- 智能水印过滤 - 动态获取公众号名称作为过滤词
- 支持公众号名称的多种写法变体（加后缀、去空格、大小写）
- 新增：过滤更多常见推广文字（转载需注明、来源、阅读数等）

## [1.1.1] - 2026-04-07

### 修复
- 🐛 图片下载数量不对：优先使用 `data-src` 属性获取图片URL
- 🐛 图片位置不对：按HTML位置排序，穿插在正文中
- 🐛 过滤条件过严：放宽图片过滤条件，避免误伤正常图片

### 新增
- 📝 经验教训文档 `LESSONS_LEARNED.md`
- 📝 SKILL.md 添加常见问题与解决方案

### 技术改进
- 从正文区域 `#js_content` 获取图片，避免获取头像/图标
- Word生成时分析HTML结构，按位置排序渲染

## [1.1.0] - 2026-04-07

### 新增
- ✨ 图片按原文位置排列（图文穿插）
- ✨ Word文档自动输出到桌面
- ✨ 支持普通文章和图片文章两种模式

### 修复
- 🐛 修复正文内容无法提取的问题
- 🐛 修复Python调用Node.js的编码问题
- 🐛 修复图片尺寸比例错误

### 优化
- ♻️ 重构Word生成脚本，优化排版逻辑
- 📝 更新文档，添加详细使用说明

## [1.0.0] - 2026-04-07

### 新增
- 初始版本发布
- 支持微信公众号文章抓取
- 支持图片下载和保存
- 支持图片文字识别（OCR）
- 支持评论区抓取
- 支持Word文档生成
- 支持批量抓取

### 功能特性
- 自动提取文章标题、作者、发布时间
- 智能过滤水印和推广文字
- 保持原文排版格式
- 支持多种OCR引擎（EasyOCR、PaddleOCR、Tesseract）
- 支持Edge和Chrome浏览器
- 支持无头模式
- 支持自定义配置

### 依赖
- Python 3.8+
- Node.js 16+
- Selenium
- docx (npm)
- 可选：EasyOCR / PaddleOCR / Tesseract
