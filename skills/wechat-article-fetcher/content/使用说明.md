## 🚀 快速开始

### 1. 安装依赖

双击运行 `install.bat`，或手动执行：

```bash
# Python依赖
pip install selenium requests Pillow

# Node.js依赖
npm install -g docx

# OCR（可选）
pip install easyocr
```

### 2. 检测环境

```bash
python scripts/check_env.py
```

### 3. 使用示例

```bash
# 抓取单篇文章
python scripts/fetch_article.py "https://mp.weixin.qq.com/s/xxxxxx"

# 批量抓取
python examples/batch_fetch.py
```

## ✨ 功能特性

- ✅ 自动提取文章标题、作者、时间
- ✅ 下载文章中的所有图片
- ✅ 图片文字识别（OCR）
- ✅ 自动过滤水印和推广文字
- ✅ 生成排版精美的Word文档
- ✅ 支持评论区抓取
- ✅ 支持批量处理
- ✅ 支持无头模式

## 🔧 依赖要求

### 必需
- Python 3.8+
- Node.js 16+
- Edge 或 Chrome 浏览器

### 可选
- EasyOCR / PaddleOCR / Tesseract（用于OCR）

## ⚠️ 注意事项

1. **微信反爬**：建议请求间隔 >= 2秒
2. **评论限制**：部分文章评论需要登录
3. **OCR准确性**：取决于图片质量
