# 追读力系统 - 读者留存与吸引力设计

## 核心理念

**追读力 = 读者愿意继续阅读的动力**

核心公式：
```
追读力 = Hook(吸引力) + Cool-points(爽点) - 债务(未兑现承诺)
```

好的追读力设计 = 持续给予读者"奖励" + 合理管理"期待"

---

## Hook类型（开篇钩子）

### 1. 悬念钩子
**原理**：留下未解之谜，激发读者好奇心

**写法**：
- 「他醒来时，发现自己躺在陌生的棺材里。」
- 「三年后，没人知道那晚发生了什么。」
- 「直到今天，他才知道自己不是普通人。」

**适用场景**：章节开头、故事开篇

### 2. 冲突钩子
**原理**：展示核心矛盾，立刻建立紧张感

**写法**：
- 「家族长老宣布：今日起，他被逐出家门！」
- 「敌人已经兵临城下，而他的修为尽失。」
- 「她刚要开口，却发现他就是杀害父亲的凶手。」

**适用场景**：情节转折点、矛盾爆发时

### 3. 反差钩子
**原理**：出人意料的情境，打破读者预期

**写法**：
- 「所有人都以为他是废物，直到那天他一剑开天。」
- 「他本是来退婚的，却看到了她给的休书。」
- 「她以为自己在救人，却不知正踏入陷阱。」

**适用场景**：身份反转、实力揭露

### 4. 情感钩子
**原理**：强烈的情感冲击，引发共鸣

**写法**：
- 「当他看到母亲的白发，终于忍不住跪下。」
- 「那一刻，她决定为他背叛整个家族。」
- 「他用尽最后一丝力气，只为把那封信送到。」

**适用场景**：感情高潮、人物塑造

### 5. 信息钩子
**原理**：揭示重要信息，满足读者求知欲

**写法**：
- 「原来这一切，都是她的计划。」
- 「他终于明白，为何父亲要他隐藏实力。」
- 「真相是：他从来就不是人类。」

**适用场景**：真相揭露、重大发现

## Cool-point爽点类型

### 1. 打脸爽文
**核心**：实力碾压，让敌人出丑

**节奏**：
```
铺垫（敌人嚣张）→ 嘲讽（贬低主角）→ 打脸（展现实力）→ 收尾（敌人震惊）
```

**字数配比**：铺垫30% + 打脸70%

**示例场景**：
- 退婚流：未婚妻退婚 → 三年后打脸
- 嘲讽流：被嘲笑废物 → 实力碾压

### 2. 扮猪吃虎
**核心**：隐藏实力，关键时刻反转

**节奏**：
```
隐藏（假装弱小）→ 试探（有人挑衅）→ 忍让（继续隐藏）→ 爆发（展现实力）
```

**关键点**：
- 隐藏要有理由（保护自己、避免麻烦）
- 爆发要有意义（为了保护他人、不得已）

**示例场景**：
- 都市兵王：回归都市隐藏身份
- 玄幻废柴：实为天才隐藏修为

### 3. 绝地翻盘
**核心**：绝境中逆转，燃爆全场

**节奏**：
```
绝境（陷入危机）→ 希望（最后一搏）→ 转折（意外收获/突破）→ 翻盘
```

**字数配比**：铺垫40% + 翻盘60%

**关键点**：
- 绝境要足够绝望
- 翻盘要足够震撼
- 读者压抑越久释放越爽

### 4. 收获积累
**核心**：获得宝物、能力、资源

**节奏**：
```
发现（找到宝物）→ 鉴定（了解价值）→ 获取（得到宝物）→ 展示（首次使用）
```

**爽点层级**：
- 普通收获：金钱、资源
- 进阶收获：功法、秘籍
- 顶级收获：神器、传承

### 5. 复仇清算
**核心**：恩怨分明，有仇必报

**节奏**：
```
仇恨（遭受屈辱）→ 隐忍（积蓄力量）→ 成长（实力提升）→ 清算
```

**关键点**：
- 仇恨要有铺垫，读者认同
- 清算要有仪式感
- 可以分多次复仇，增加爽点密度

### 6. 守护反击
**核心**：为保护他人而战，情感升华

**节奏**：
```
危机（亲人/爱人遇险）→ 愤怒/决心 → 爆发 → 胜利/守护
```

**关键点**：
- 守护的对象要提前建立感情
- 爆发要有情感铺垫
- 战斗要精彩激烈

### 7. 突破晋升
**核心**：境界/等级突破，实力飞跃

**节奏**：
```
积累（修炼/沉淀）→ 瓶颈（难以突破）→ 契机（遇到机遇）→ 突破
```

**关键点**：
- 突破要艰难，读者才觉得珍贵
- 突破要有异象描写
- 突破后要立刻展示提升

### 8. 情感突破
**核心**：感情线重大进展

**节奏**：
```
暧昧（互相试探）→ 危机（感情危机）→ 坦白/行动 → 确定关系
```

**关键点**：
- 暧昧要适度拉扯
- 危机要有张力
- 突破要有仪式感

## 债务管理

### 什么是"债务"？

埋下的伏笔、世界观承诺、人物关系暗示，都是"债务"。

**债务类型**：
- **伏笔债**：前面埋的线索，后面要回收
- **期待债**：主角要达到的目标
- **关系债**：人物之间的关系承诺

### 债务管理原则

1. **债务要定期偿还**
   - 每3-5章至少偿还一个小债务
   - 每20-30章偿还一个大债务
   - 永远不要忘记债务

2. **新债要可控**
   - 每章最多埋1-2个新钩子
   - 保持债务总量在读者可接受范围
   - 给读者"甜头"的同时制造新期待

3. **大小债务搭配**
   - 大债务：贯穿全书的主线
   - 中债务：10-20章的小高潮
   - 小债务：1-3章内兑现

### 债务追踪表

| 类型 | 内容 | 埋设章节 | 计划回收 | 实际回收 |
|------|------|----------|----------|----------|
| 伏笔 | XXX身份之谜 | ch5 | ch30 | - |
| 期待 | 主角报仇 | ch10 | ch50 | - |
| 关系 | 两人的感情 | ch15 | ch40 | - |

## 微兑现策略

### 什么是"微兑现"？

定期给读者"小甜头"，保持阅读兴趣，不让读者感到"无聊"。

### 微兑现类型

| 类型 | 说明 | 频率 | 示例 |
|------|------|------|------|
| 小爽点 | 小的胜利/收获 | 每章1-2个 | 打脸小喽啰、获得小宝物 |
| 暧昧互动 | 感情线的小进展 | 每5-10章 | 对视、牵手、脸红 |
| 情报透露 | 揭露一点小秘密 | 每10章 | 暗示更大阴谋 |
| 角色高光 | 配角的精彩表现 | 每15章 | 忠诚小弟的爆发 |

### 节奏黄金比例

```
章节结构 = 30% 铺垫 + 50% 推进 + 20% 高潮/钩子
```

## 章节结尾Cliffhanger设计

### Cliffhanger类型

1. **悬念式**：留下未解之谜
   - 「就在他转身的瞬间，背后传来一声——」

2. **危机式**：主角陷入危险
   - 「看着逼近的敌人，他发现自己的修为尽失。」

3. **反转式**：出人意料的转折
   - 「他终于报了仇，却发现仇人不是真正的凶手。」

4. **情感式**：强烈的情感冲击
   - 「她把匕首刺入他的胸膛，却不知那是她的亲哥哥。」

### Cliffhanger禁忌

- ❌ 不要在章节末尾解释太多
- ❌ 不要让cliffhanger太久不回收（超过20章）
- ❌ 不要设置太多cliffhanger（保持1-2个）
- ❌ 不要设置无法回收的cliffhanger

## 追读力评估表

| 维度 | 优秀(5) | 良好(4) | 一般(3) | 较差(2) | 很差(1) |
|------|---------|---------|---------|---------|---------|
| Hook质量 | 开头立刻抓住眼球 | 有吸引力但不够强 | 中规中矩 | 有些无聊 | 完全无法吸引 |
| 节奏控制 | 张弛有度高潮不断 | 节奏稳定 | 偶有拖沓 | 多处拖沓 | 完全没有节奏感 |
| 爽点密度 | 每章2+爽点 | 每章1-2个 | 平均每章1个 | 2-3章一个 | 没有爽点 |
| Cliffhanger | 悬念极强想看下一章 | 比较吸引人 | 一般 | 没什么悬念 | 没有悬念 |
| 债务管理 | 完美平衡新债旧债 | 基本平衡 | 偶尔失控 | 债务堆积 | 完全失控 |

**总分**：30-25优秀 / 24-20良好 / 19-15一般 / 14-10较差 / 9-5很差
