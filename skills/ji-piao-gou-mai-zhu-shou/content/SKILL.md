# 机票购买助手

## Inputs to collect
- 出发地、目的地（机场或城市均可）
- **是否愿意到相邻城市出发**（决定要不要展开 nearby-cities 推荐）
- 大致出行时间窗口（"国庆前后" / "11 月中" / "下学期开学前"）
- 乘客人数和构成（大人/儿童/婴儿）—— 有儿童/婴儿会触发特殊场景
- 舱位偏好（经济/商务、是否接受廉航/转机）
- **特殊需求**（老人/孕妇/轮椅/餐食/宠物/超规行李）—— 有就触发 special-cases
- **行李需求**（件数、重量、是否有锂电池/液体/特殊物品）—— 触发 baggage 精算
- 预算上限（可选，有就更好筛选）
- 是否需要"降价提醒"——需要就配 cron

如果用户只给了一半信息（光说"查机票"），按"先补最少必要信息再开工"的原则问，不要等全问完再动。

## Procedure

1. **先承认能力边界**
   开头一句话告诉用户：这个 skill 不拉实时票价，但能给"在哪儿搜、怎么搜、什么时候搜最划算"。原因：避免用户期待"给我个最低价"，最后交付的是搜索清单。

2. **判断这次请求是哪种模式**

   | 模式 | 触发 | 输出 |
   |---|---|---|
   | 比价指引 | "XX 到 XX 怎么订最便宜" | 多平台搜票 SOP + 参数模板 + **含行李总成本** |
   | 相邻城市推荐 | "出发地太贵"、"从旁边城市飞呢"、用户没明说但出发地票价偏高 | 附近机场/高铁可达城市清单 + 总成本对比表 |
   | 行程规划 | "X 月想去 Y 玩，几号出发便宜" | 出行窗口建议 + 节假日/价格规律 |
   | 特殊场景 | 多人/儿童/婴儿/老人/孕妇/轮椅/餐食/宠物 | 读 `references/special-cases.md` 的硬规则 + 通用清单 |
   | 行李精算 | "行李超重怎么算"、"我行李 30kg 够吗"、"锂电池能带吗" | 读 `references/baggage.md`：免费额查询 + 超额计算 + 优化方案 |
   | 降价追踪 | "到时提醒我查 X 路线" | 配 cron 任务 + 检查清单 |
   | 综合 | 上面几种混着来 | 上面六种各给一段 |

3. **比价指引模式** → 读 `references/platforms.md` 和 `references/search-patterns.md`
   - 给出 3-5 个平台，按"信息聚合/价格最低/服务可靠/廉航专用"分类
   - 每个平台给具体搜索参数（出发机场代码、是否勾选"附近机场"、日期范围 ±3 天）
   - 强调：跨平台比价要在**同一时间窗口**搜，不要一个查 1 月 1 日另一个查 1 月 5 日
   - 提一句"私域优势"：航司官网有时比 OTA 还便宜，记得列出来
   - **比价时必须把行李成本算进去**——读 `references/baggage.md` 的"决策树"section，给出含行李的总价（用户没说行李也要主动问"你行李多少"）

4. **相邻城市推荐模式** → 读 `references/nearby-cities.md`
   - 默认**主动推荐**，不要等用户问。原因：这是这个 skill 的差异化价值，死磕一个出发地经常贵 500-2000
   - 三个层级，**全部给出**：
     - **同城多机场**：北京 PEK+PKX、上海 SHA+PVG、广州 CAN+广州周边
     - **高铁 2 小时可达**：列出 2-3 个候选城市（武汉、长沙、成都、重庆等枢纽）
     - **国际/长航线专属"小机场"模式**：考虑去香港 HKG、仁川 ICN、新加坡 SIN 等枢纽出发，跨境机票反而便宜
   - 每个候选城市给**总成本** = 机票差价 - 到达该城市的高铁/打车成本
   - **必须**给一个决策框架："差价 < 200 → 别折腾；差价 200-800 → 算上时间看情况；差价 > 800 → 强烈建议换出发地"
   - 提醒：跨城出行要给"时间 buffer"——提前一天到达出发城市机场，避开高铁晚点误机

5. **行程规划模式** → 用历史规律 + 节假日数据
   - 周中（周二/周三）出发通常比周末便宜 10-20%
   - 提前 6-8 周订国际线、提前 3-6 周订国内线（这是统计规律，不是保证）
   - 避开当地节假日、寒暑假峰值
   - 大促节点：双 11、618、航司会员日（南航每月 28 日、东航每月 9 日等）
   - 提示：所有"经验值"都要说"基于一般规律，最终看实时价格"

6. **特殊场景模式** → 读 `references/special-cases.md`
   - **先识别场景**：人数/年龄/身体状况/特殊需求任意一个 → 强制读
   - **输出规则要"硬"**：年龄分段、孕周限制、宠物预订窗口等是**硬规则**，写错一步票就废了
   - 给出该场景**专属清单**（不是通用清单）
   - 提醒**航司官网预订** vs OTA 预订：特殊服务（轮椅/餐食/婴儿摇篮/宠物）几乎只能在官网或客服完成
   - **必须**给预订时序：起飞前 72 小时 / 48 小时 / 24 小时分别要做什么

7. **行李精算模式** → 读 `references/baggage.md`
   - **必须走"决策树"**：免费额 → 实际行李 → 计算超额 → 算钱 → 给方案（**5 步不能省**）
   - 区分计件制/计重制（国内/国际差别）
   - **核心输出**：
     - 实际超额费用
     - 重打包方案（如何免费消化超重）
     - 提前买 vs 现场买的差价（5-10 倍）
     - 多人/特殊物品合并规则
   - **必查项**：锂电池容量、液体限制、违禁品清单
   - 给一句"如果你现在决定换舱位/航司，行李政策也会变"——提醒用户综合决策

8. **降价追踪模式** → 读 `references/deal-tracker.md`
   - 配 cron 任务：定期提醒用户"现在该去 X 平台查 X 路线了"
   - 频率建议：出行前 8 周起每周一次，临近 4 周改成每 3 天一次
   - active_hours 设到用户方便看消息的时段（默认 9:00-21:00）
   - 不要替用户去搜——明确告诉他"提醒到了你自己点链接查"

9. **汇总输出**
   不管哪种模式，最后都附一段"接下来你可以做的一步"——给一个最具体的动作（比如"先打开 Skyscanner 搜 北京→东京 11/1-11/8，勾选'灵活日期 ±3 天'"），让用户看完就能动。

## Output contract

- **比价指引**：3-5 个平台清单 + 每个平台的搜索参数 + **含行李总价**
- **相邻城市推荐**：3 个层级的候选清单 + 总成本对比表 + 决策阈值
- **行程规划**：最佳窗口建议（具体到几号）+ 大促日历
- **特殊场景**：硬规则 + 专属清单 + 预订时序
- **行李精算**：免费额 + 超额计算 + 重打包方案 + 省钱建议
- **降价追踪**：cron 配置片段 + 手动检查清单
- **综合**：上面六种都输出

不要输出：
- 编造的价格数字
- 声称"我帮你查到了最低价"
- 任何对实时票价的直接断言

## Failure handling

- 用户只问"机票多少钱"→ 明确说实时拿不到，引导到比价指引模式
- 用户给的地点没有机场/航线数据 → 提示最近的可用机场
- 相邻城市成本数据陈旧（高铁票价、机场大巴价格）→ 给区间不要给具体数字
- 用户有特殊需求但没说全（光说"带小孩"不说几岁）→ 按年龄分段主动给出全规则
- 用户只说"行李多"不说具体件数重量 → 主动问；如果不愿意说，按 25kg 1 件给参考方案
- 行李超出免费额但用户没意识到 → **必须主动提醒**，这是这个 skill 的核心价值之一
- 降价追踪 cron 创建失败 → 给出失败原因 + 手动替代方案（标在日历上）
- 出行日期临近（<2 周）→ 模式切到"现在立刻搜"而不是"等降价"

## Examples

**Input**: "下个月想去东京，从北京出发，3 个人，预算人均 4000 以内，最好直飞。国庆太挤了能不能避开？"
**Output**:
1. 相邻城市推荐：天津/上海/香港出发的可行性 + 总成本对比
2. 比价指引：Skyscanner / Google Flights / 携程 / 春秋官网 各一句
3. 行程规划：11 月避开 11/1-3 周末、11/22-24 周末；周二/周三出发；提前 5-7 周订
4. **行李精算**：3 人 1 件 23kg/人，国航国际 1 件免费额 → 需多买 2 件行李
5. 接下来一步：先打开 Skyscanner 搜 北京→东京 10/15-11/15，勾选"灵活日期 ±3 天"

**Input**: "上海飞伦敦太贵了，还有别的办法吗？"
**Output**:
1. 相邻城市推荐：香港 HKG 出发（经常便宜 1500-3000）+ 杭州/南京/北京作为国内二选
2. 比价指引：BA / 维珍 / 卡塔尔官网重点查
3. 接下来一步：先看香港→伦敦的卡塔尔航空/阿联酋中转，对比上海直飞的总价

**Input**: "3 大人 1 个 5 岁小孩，春节去普吉岛，预算 2 万。怎么订最划算？"
**Output**:
1. 特殊场景：儿童票 5 岁 = CHD 段，票价 75%；航司官网儿童票比 OTA 便宜；春节高峰
2. 相邻城市推荐：广州/深圳/香港/昆明出发（飞东南亚首选） + 总成本对比
3. 比价指引：南航官网/国航官网/携程/飞猪
4. 接下来一步：先打开南航官网查 CAN→HKT 春节价 + 儿童票规则

**Input**: "我去趟美国出差 2 周，行李大概 30kg，可以托运吗？会被收多少超重费？"
**Output**:
1. 行李精算：美联航/达美美国国内段 0 件免费额；国际段 1 件 23kg 免费；30kg 必须分 2 件
2. 重打包方案：30kg → 2 件 15kg（0 元）vs 1 件 23kg + 1 件 7kg（0 元）vs 1 件 30kg（拒载）
3. 省钱建议：航司官网提前买第二件 ≈ 1000 元 vs 机场买 ≈ 3000-5000 元
4. 接下来一步：去美联航官网查国际段行李政策 + 用金卡/联名信用卡权益

**Input**: "我老婆怀孕 28 周，6 月想去日本，有什么要注意的？"
**Output**:
1. 特殊场景：28 周国内航司可飞，**32 周前安全**；必须带"适宜乘机证明"（起飞前 7 天内开具）
2. 比价指引：ANA / JAL 官网 + Skyscanner
3. 行程规划：6 月非高峰，东京/大阪都不错
4. 接下来一步：去医院开"适宜乘机证明"英文版（国际线）+ 查 ANA 孕妇政策

**Input**: "帮我设个提醒，下学期开学前查上海到伦敦的机票"
**Output**:
1. 配 cron：每周一上午 9:00 提醒"检查 SHA→LHR 机票价格"，到 1 月改成每 3 天
2. 检查清单：Skyscanner 看曲线、BA/维珍官网比价、申根签证预留时间提醒
