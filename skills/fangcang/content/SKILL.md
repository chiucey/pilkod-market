# 货运放舱核对工具

## 功能

对比船公司订舱清单与货代订舱表，找出以"177"开头的订舱号中：船公司状态为"已确认(confirmed)"但货代状态为"未标记"的记录。

## 使用方式

用户输入：`查放舱,对比 xxx` (xxx = 货代订舱表文件名，可包含多人如"刘莉,张琳,岳文青")

## 执行流程

### 第一步：定位文件

1. **船公司订舱清单**：在 `/Users/clay/Downloads` 目录查找以 `ASTA_HS_` 开头的 `.xls` 文件
2. **货代订舱表**：在 `/Users/clay/Downloads` 目录查找 `xxx.xlsx` 文件

### 第二步：读取Excel文件

使用 Python + xlrd 读取船公司 `.xls` 文件，openpyxl 读取货代 `.xlsx` 文件

### 第三步：提取177开头的订舱号

- 从船公司清单：提取 `BookingNumber` 列以"177"开头的记录
- 从货代订舱表：提取 `BookingNumber` 列以"177"开头的记录

### 第四步：对比状态

1. 找出两表都存在的177订舱号
2. 筛选满足以下条件的订舱：
   - 船公司清单：`Status` 列 = **Confirmed**
   - 货代订舱表：`Status` 列 = **空/未标记**

### 第五步：输出结果

直接向用户展示匹配的177订舱号，无需生成文件
