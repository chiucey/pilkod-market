# 国际旅行卫生保健中心体检报告审核技能

## 技能概述

本技能用于分析用户上传的体检报告（PDF或图片格式），识别医学指标的异常情况，并生成国际旅行健康检查证明书。

## 核心功能

1. **体检报告解析**：支持PDF和图片格式（JPG、PNG）的体检报告上传和分析
2. **指标异常检测**：识别以下三类异常：
   - 超出正常范围的指标
   - 阳性异常结果
   - 带*标记的异常指标
3. **医学说明**：为每项异常指标提供专业医学解释和建议
4. **健康证明生成**：为体检合格的报告自动生成国际旅行健康检查证明书

## 工作流程

### 步骤1：接收体检报告

接收用户上传的体检报告文件，支持以下格式：
- PDF文件（优先推荐）
- 图片文件（JPG、PNG）

### 步骤2：提取报告内容

根据文件类型选择提取方式：
- **PDF文件**：使用 `extract_pdfs_full_content` 或 `extract_pdfs_key_info` 提取文本内容
- **图片文件**：使用 `images_understand` 进行OCR识别和内容提取

提取时指定关键信息提取提示：
```
请提取体检报告中的所有医学指标，包括：
1. 血常规检查指标（白细胞、红细胞、血红蛋白、血小板等）
2. 尿常规检查指标
3. 肝功能检查指标（ALT、AST、胆红素等）
4. 肾功能检查指标（肌酐、尿素氮、尿酸等）
5. 血糖、血脂检查指标
6. 心电图检查结果
7. 胸部X光检查结果
8. 其他所有检查项目和指标值
请列出每项指标的：指标名称、检测值、参考范围、单位
```

### 步骤3：分析指标异常

对提取的每项指标进行异常分析：

#### 3.1 超出范围异常
判断指标是否超出参考范围：
- **高于上限**：标记为"↑升高"
- **低于下限**：标记为"↓降低"

#### 3.2 阳性异常
识别以下阳性结果：
- 乙肝表面抗原（HBsAg）阳性
- 丙肝抗体（Anti-HCV）阳性
- 梅毒螺旋体抗体（TPPA）阳性
- HIV抗体阳性
- 结核菌素试验阳性

#### 3.3 带*异常
识别报告中任何带有星号(*)标记的指标，这些通常表示：
- 超出参考范围
- 需要关注的结果
- 建议复查的项目

### 步骤4：生成异常说明

为每项异常指标提供以下信息：
- 指标名称和检测值
- 异常类型（升高/降低/阳性/*标记）
- 医学解释
- 对国际旅行的影响
- 建议措施

### 步骤5：判断与输出

#### 5.1 存在异常情况
如果检测到任何异常：
- 详细列出所有异常指标
- 提供每项异常的医学说明
- 给出具体建议
- 提示用户可能需要的复查项目
- 说明对获取健康证明的影响

#### 5.2 全部指标正常
如果所有指标均在正常范围内：
- 确认所有指标正常
- 立即生成《国际旅行健康检查证明书》

### 健康证明书输出格式
直接输出完整的《国际旅行健康检查证明书》，包含所有必要信息。

## 注意事项

1. **文件格式**：优先使用PDF格式以获得更准确的文本提取
2. **图片质量**：如使用图片，请确保清晰可读
3. **报告完整性**：确保报告中包含所有检查项目的完整数据
4. **参考范围**：不同医院的参考范围可能略有差异，以报告标注为准
5. **专业建议**：本技能提供的建议仅供参考，具体医疗决策请咨询专业医生
