## 变量替换说明

| 变量 | 说明 | 示例 |
|------|------|------|
| `{{YEAR}}` | 签发年份 | 2024 |
| `{{RANDOM_NUMBER}}` | 随机编号 | 000001 |
| `{{ISSUE_DATE}}` | 签发日期 | 2024年01月15日 |
| `{{PATIENT_NAME}}` | 受检者姓名 | 张三 |
| `{{GENDER}}` | 性别 | 男/女 |
| `{{BIRTH_DATE}}` | 出生日期 | 1990年01月01日 |
| `{{NATIONALITY}}` | 国籍 | 中国 |
| `{{PASSPORT_NUMBER}}` | 护照号码 | E12345678 |
| `{{EXAMINATION_DATE}}` | 体检日期 | 2024年01月15日 |
| 其他指标变量 | 对应检测值 | 根据实际报告填写 |

## 证书编号规则

证书编号格式：`ITC-YYYY-NNNNNN`

- `ITC`：International Travel Certificate 缩写
- `YYYY`：签发年份
- `NNNNNN`：6位顺序编号

示例：`ITC-2024-000001`
