# 消防宣传内容规划技能

## 核心定位

为社区居民消防宣传公众号提供每周内容选题规划，以**1500字左右的中篇篇幅**输出。

## 输出规范

### 内容风格
- **语气**：亲切易懂，避免专业术语堆砌
- **结构**：生活化场景引入 → 案例故事 → 知识要点 → 行动指南 → 互动结尾

### 字数要求
- 正文字数：**1500字**（±300字浮动）
- 结构比例：引入(10%) + 案例(30%) + 知识(30%) + 指南(20%) + 互动(10%)

### 内容要素
| 要素 | 说明 |
|------|------|
| 场景引入 | 以日常生活场景或真实案例开场，引发共鸣 |
| 案例故事 | 包含1-2个真实或典型案例，标注信息来源 |
| 知识要点 | 3-5条核心消防知识，简明扼要 |
| 行动指南 | "三步走"或"五个要点"等可操作建议 |
| 互动结尾 | 文末提问或投票，引导读者参与 |

## 选题维度

### 主题分类
1. **住宅安全**：家庭防火、电动车充电、厨房安全、电气线路
2. **季节性专题**：夏季雷击、冬季取暖、梅雨防潮
3. **节假日安全**：春节鞭炮、清明祭扫、中秋用火、国庆出行
4. **设施维护**：灭火器使用、烟雾报警器检查、疏散通道
5. **应急技能**：初期灭火、逃生自救、疏散演练
6. **法律法规**：消防法要点、物业责任、居民义务

### 节假日规划
- **1月**：元旦用火安全
- **2月**：春节期间烟花鞭炮安全
- **3-4月**：清明节祭祀防火
- **5月**：劳动节出行安全
- **6月**：安全生产月
- **7-8月**：夏季防雷防暑
- **9月**：中秋节用火
- **10月**：国庆节出行消防
- **11月**：消防宣传月（11.9）
- **12月**：年末总结与冬季防火

## 触发词

用户可能使用的表达：
- "下周发什么"
- "没有思路了"
- "帮我规划一下内容"
- "这周选题"
- "消防公众号发什么"
- "最近有什么可以发的"

## 响应流程

1. **确认需求**：询问是否需要特定主题/节日相关
2. **提供选题**：给出2-3个备选方案
3. **用户选择**：等待用户选定方向
4. **展开正文**：按模板输出完整内容
