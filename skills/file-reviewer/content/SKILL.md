# 文件审查技能

审查多份文件的数据完整性，包括空值检查、模板一致性验证和逻辑相关性分析。

## 核心能力

1. **空值审查** - 检查多份文件中指定栏位是否为空
2. **模板一致性审查** - 验证文件结构/内容是否符合预期模板
3. **逻辑相关性审查** - 检查文件间数据的逻辑关联（如ID匹配、金额汇总等）
4. **自定义模板配置** - 支持用户定义审查规则和模板

## 审查流程

### 步骤 1：收集文件信息

用户需提供：
- 需要审查的文件路径（支持 Excel、CSV、JSON）
- 审查类型（空值检查/模板验证/逻辑审查）
- 模板文件（可选，用于一致性验证）

### 步骤 2：读取并解析文件

根据文件类型选择解析方式：
- **Excel/CSV**: 使用 pandas 读取，识别列名和数据类型
- **JSON**: 解析嵌套结构，提取关键字段

### 步骤 3：执行审查

根据审查类型执行相应检查：

#### 空值审查
```
检查指定栏位是否包含：
- 空字符串 ""
- NULL/None
- 空白字符
- 仅包含空格的字符串
```

#### 模板一致性审查
```
验证项：
- 必填栏位是否存在
- 栏位顺序是否正确
- 数据类型是否匹配
- 值域范围是否合规
```

#### 逻辑相关性审查
```
支持规则：
- 跨文件ID匹配（如订单ID存在于订单表和明细表）
- 金额汇总验证（如明细金额之和=总金额）
- 日期逻辑（如结束日期>开始日期）
- 外键约束验证
```

### 步骤 4：生成审查报告

输出结构化的审查结果：
- 审查类型和范围
- 发现的问题列表
- 问题严重程度（错误/警告/提示）
- 修复建议

## 模板配置格式

用户可通过 JSON 配置文件定义审查模板：

```json
{
  "template_name": "订单审查模板",
  "file_type": "excel",
  "required_columns": ["订单号", "客户名称", "金额", "日期"],
  "nullable_columns": ["备注", "折扣"],
  "column_order": ["订单号", "客户名称", "金额", "日期", "备注"],
  "data_types": {
    "订单号": "string",
    "金额": "number",
    "日期": "date"
  },
  "value_ranges": {
    "金额": {"min": 0, "max": 1000000}
  },
  "cross_file_rules": [
    {
      "rule_name": "订单明细汇总",
      "description": "订单金额应等于明细金额之和",
      "master_file": "orders.csv",
      "detail_file": "order_items.csv",
      "master_key": "订单号",
      "detail_key": "订单号",
      "master_field": "金额",
      "detail_field": "小计",
      "aggregation": "sum",
      "tolerance": 0.01
    }
  ],
  "null_check_columns": ["订单号", "客户名称", "金额"]
}
```

## 使用示例

### 示例 1：基础空值检查

用户输入：
> 检查 orders.csv 和 customers.csv 中，订单号、客户名称、金额这三个栏位是否有空值

系统操作：
1. 读取两个 CSV 文件
2. 检查指定栏位的空值情况
3. 生成包含具体行号和空值类型的报告

### 示例 2：模板一致性验证

用户输入：
> 验证 data.xlsx 是否符合标准模板（必填栏位：ID、名称、数量；金额栏位必须为数字）

系统操作：
1. 读取 data.xlsx 和模板配置
2. 检查必填栏位是否存在
3. 验证数据类型
4. 输出差异报告

### 示例 3：跨文件逻辑检查

用户输入：
> 检查订单表的金额是否等于明细表的金额汇总（允许0.01误差）

系统操作：
1. 读取 orders.csv 和 order_items.csv
2. 按订单号分组汇总明细金额
3. 与订单金额对比
4. 报告不匹配项

## 限制与注意事项

1. **文件大小限制**: 单个文件建议不超过 50MB
2. **支持格式**: Excel (.xlsx, .xls)、CSV (.csv)、JSON (.json)
3. **编码支持**: UTF-8、GBK（自动检测）
4. **性能考虑**: 大文件使用分块读取

## 错误处理

- 文件不存在: 提示用户检查路径
- 格式不支持: 列出支持的文件格式
- 解析失败: 提供具体解析错误信息
- 内存不足: 建议分批处理
