# Design Process — 从零开始 / 持续进阶

原书第 1 章和第 9 章。**这一章管的是"怎么开始"和"怎么变强"，不是具体数值。**

## 从零开始（Starting from Scratch）

### 1. 从功能开始，不是从布局

"Start with a feature, not a layout." 别一上来就想侧边栏、顶栏、导航项。**先想清楚这个功能
给用户什么价值**，再设计它长什么样。

从一个空白画布加上导航壳开始，是新手最常见的坑——你在设计一个壳，没在设计功能。

### 2. 细节留到后面

"Detail comes later." **先做灰度线稿。**不选颜色、不选字体、不加阴影。

这一步的价值在于：被迫靠**间距、对比度、布局**做所有重活。这正是层级是否真的成立的检验——
如果去掉了颜色和字体，界面还是清楚，说明层级对了；一去掉就散架，说明你一直在用颜色
救场。

### 3. 别设计太多

"Don't design too much." 你不需要在这个阶段想清楚每一个边界情况。设计太多会导致瘫痪。

### 4. 走短循环

不要设计三个月再开工。**设计 → 建 → 设计 → 建**，短周期反复。每轮都能看到真实效果，比在
纸上推演准得多。

### 5. 做个悲观主义者

别在设计里承诺你还建不出来的东西。如果某个功能实际很难实现，就先在设计里避开，或明确标为
"以后再说"。设计图上出现的东西，工程上做不动，整个节奏就崩了。

## 6. 选择一种个性（Choose a personality）

这一步被严重低估，但它决定所有后续决策。**动手定 token 之前先回答：这个产品给人的感觉
是什么？**

| 维度 | 一端 | 另一端 |
|---|---|---|
| 严肃 ↔ 亲和 | 金融 / 医疗 | 社交 / 娱乐 |
| 锐利 ↔ 柔和 | 小圆角、方 | 大圆角、圆 |
| 克制 ↔ 张扬 | 单色 + 一个强调色 | 彩色、大胆排版 |
| 紧凑 ↔ 舒展 | 数据工具 | 内容站点 |

个性会传导到具体选择：

- **字体**：衬线显得优雅 / 传统，无衬线显得中性 / 现代。UI 正文一律无衬线
- **圆角**：小圆角或 0 = 严肃正式；大圆角 = 活泼亲和。**这是最直接传达个性的一个控件**
- **颜色**：冷静的颜色（蓝、深灰）传达可信；暖色、亮色传达活力
- **文案语气**：也是个性的一部分，和视觉要对得上
- **留白密度**：舒展 = 高级 / 克制；紧凑 = 信息密度 / 专业工具

个性定下来之后，后面所有 token 都从这个方向推，**整个界面会自然一致**——因为它们出自
同一个判断，而不是各自拍脑袋。

### 7. 限制你的选择（Limit your choices）

不要每次都重新想：这个颜色用哪个、字号用多少、按钮多大。

**把选择变成有限集合，用排除法决策**：

- 灰色 8–10 档（已定）
- 主色 5–10 档（已定）
- 字号 8–12 档（已定）
- 间距 10–15 档（已定）
- 字重 2–3 档（已定）
- 圆角 1 档（已定）
- 阴影 5 档（已定）

决策从"无限选择 + 审美判断"变成"有限选择 + 规则判断"。**速度提升来自这里，不来自审美。**
Tailwind 就是这一章的完整实现。

## 持续进阶（Leveling Up）

这一章只有一节，但值得记住：**有意识地拆解别人为什么这样设计。**

- 看到做得好的界面，问"如果是我，我会怎么处理这个角？"然后去找答案
- **动手复刻**你喜欢的产品界面——复刻过程暴露出的问题比看一百遍都有用
- 关注设计领域的作品，建立自己的 reference 库

设计能力不是天赋，是**逐个案例积累出来的模式识别**。这和 skill 的存在是一回事——
把已经想明白的规则固化下来，就不必每次重新推导。

## 检查清单

开工前：

- [ ] 这个界面的主角是什么？（一句话）
- [ ] 个性定了吗？正式还是活泼、锐利还是柔和？
- [ ] 有没有既有品牌 token 要继承？
- [ ] 各系统（间距 / 字号 / 颜色 / 阴影）定好了吗？

交付前：

- [ ] 去掉颜色，层级还成立吗？
- [ ] 去掉字号差异，只靠字重和颜色，层级还成立吗？
- [ ] 所有间距值都在阶梯上吗？
- [ ] 所有字号都在阶梯上吗？
- [ ] 对比度实测了吗（不是目测）？
- [ ] 有没有只靠颜色传达的信息？
- [ ] 空状态 / 加载 / 错误 / 超长文本都处理了吗？
- [ ] 深色模式下阴影失效的部分有替代方案吗？
