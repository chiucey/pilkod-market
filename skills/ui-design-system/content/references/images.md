# Working with Images — 图片的运用

原书第 7 章。

## 1. 用好照片

"Use good photos." 烂照片能毁掉整个界面。不要为了"统一风格"把图调成灰——**风格一致靠布局和
配色，不靠把照片全降饱和**。图库（Unsplash、Grammys、Pexels）里挑高质量的，或雇个摄影师。

## 2. 图上放文字要有稳定的对比度

"Text needs consistent contrast." 图片内容不可控，文字压在上面时对比度是随机的。五种办法
（按推荐度排序）：

1. **压一层半透明遮罩** —— 最常用。深色遮罩 + 白字
2. **降低图片对比度和亮度** —— `filter: brightness(.7)`，会损失图片本身的冲击
3. **给图片上色** —— 叠一层主色，`mix-blend-mode: multiply`。这一条最有用：把图片统一
   到品牌调性，同时天然制造文字对比度
4. **文字加投影** —— `text-shadow` 大模糊半径、无偏移。只在前三种都不行时用，容易显脏
5. **半透明底色块** —— 文字放进一个带背景的盒子里。最稳但视觉上最"重"

**不要靠文字颜色和背景色碰运气。** hero 区的背景图必须做处理，哪怕是纯色块上的一张小图。

## 3. 每样东西都有它的预期尺寸

"Everything has an intended size."

- **不要放大小图标。**16px 设计的图标拉到 48px 会显得笨重（线条粗、留白比例失真）。要放大
  就换一套为大尺寸设计的图标，或者给它加个容器形状（圆形底、圆角底）
- **不要缩小截图。**把 16px 的字缩到 4px 根本看不清。截图要么按实际显示尺寸截、要么裁切
  局部、要么用简化效果图（去掉细节）
- 用户上传的图片尺寸不一，要**定死容器比例**并用 `object-fit: cover`

## 4. 当心用户上传的内容

"Beware of user-uploaded content."

- 用户上传的图尺寸、比例、色彩完全不可控，**不能用它作为布局依据**
- 头像等圆形容器：给容器加浅色底，避免透明 PNG 在深色背景上变成一块白
- 头像溢出裁剪时加细边框，避免图片直接切在容器边缘上显脏

## 5. 图标

- 用**为该尺寸设计的图标集**，不要缩放
- 图标尺寸和字号的配比：正文 16px 配 16px 或 20px 图标（1:1 或 1.25:1）
- 图标默认继承文字颜色；需要弱化时调浅而不是缩小
- 描边图标和实心图标不要混用

## 6. 图片尺寸速查

| 用途 | 尺寸建议 |
|---|---|
| 行内小图标 | 16 / 20px |
| 按钮图标 | 16px |
| 卡片缩略图 | 宽高比 16:9 或 4:3 |
| 用户头像 | 32 / 40 / 64px（圆形） |
| hero 背景 | `min-height: 60vh`，配遮罩 |
| 详情大图 | 容器宽度 100%，`object-fit: cover` |
