# 顶级投资分析技能 v2

## 核心定位

本技能提供系统化的投资分析框架，涵盖**十二核心问题体系**和**三十二维度尽调分析**，帮助用户完成专业的股票投资研究。

## 工作流程

### 第一步：数据收集与验证

**铁律**：所有财经数据必须来自合规来源（东方财富、同花顺、证券公司研报、交易所公告），禁止编造或估算数据。

1. 获取实时行情数据（最近交易日）
2. 获取最新财务数据（最新披露期）
3. 交叉验证数据一致性（三码对应）
4. 标注数据来源

### 第二步：十二核心问题评估

对投资标的按以下框架进行系统评估：

| 维度 | 核心问题 | 投资本质 |
|------|----------|----------|
| 防御性 | Q1: 护城河是什么？5年后还存在吗？Q6: 供应链多元化程度如何？ | 能否守住优势 |
| 进攻性 | Q2: 客户为什么选你们不选第二名？Q7: 竞争优势能否量化验证？ | 能否持续获客 |
| 人 | Q3: 创始人过去最艰难的决策是什么？Q8: 关键岗位人才密度如何？ | 谁能持续打赢 |
| 钱 | Q4: 单位经济模型算清楚了吗？Q9: 资本配置优先级是什么？ | 资金是否高效 |
| 势 | Q5: 终局位置是什么？Q10: 技术路线图与押注策略？ | 能否穿越周期 |
| 验证 | Q11: 如何应对供应链地缘政治风险？Q12: 管理层预期与实际偏差多大？ | 信息质量 |

### 第三步：三十二维度尽调分析

按8大层面进行全方位评估：

| 层面 | 四维度 | 对应核心问题 |
|------|--------|--------------|
| 战略层 | 行业趋势、政策环境、技术变革、竞争格局 | Q5终局位置、Q10技术演进 |
| 人本层 | 创始团队、核心高管、激励机制、组织文化 | Q3创始人决策、Q8人才密度 |
| 商业层 | 商业模式、客户结构、定价能力、单位经济 | Q4单位经济、Q2客户选择 |
| 防御层 | 壁垒类型、壁垒持续性、护城河深度、应对新进入者 | Q1护城河 |
| 支撑层 | 研发能力、产能/供给、渠道网络、资本获取 | Q10技术演进、Q6供应链韧性、Q9资本配置 |
| 财务层 | 成长性、盈利性、资产质量、现金流 | Q4单位经济、Q9资本配置 |
| 风险层 | 经营风险、财务风险、合规风险、退出风险 | Q2客户选择、Q6供应链韧性、Q11数据验证 |
| 退出层 | 股东结构、资本运作、分红回购、估值水平 | Q11数据验证、Q9资本配置 |

### 第四步：重要股东投资逻辑分析

分析各类股东的持仓逻辑与信号价值：

| 股东类型 | 投资逻辑 | 信号意义 |
|----------|----------|----------|
| 国家队 | 政策导向、资源支持 | 战略底部信号 |
| 社保基金 | 长期稳健、绝对收益 | 价值投资信号 |
| 养老基金 | 超长期配置、价值投资 | 长期价值认可 |
| 产业资本 | 战略协同、业务合作 | 战略价值认可 |
| 知名牛散 | 个人判断、灵活配置 | 关注信号（非推荐） |
| 公募基金 | 专业筛选、组合配置 | 机构认可信号 |
| 北向资金 | 外资视角、全球比较 | 外资偏好信号 |

### 第五步：估值分析

使用多维度估值方法：

- **估值指标**：PE(TTM)、Forward PE、PB、PS、EV/EBITDA
- **成长性指标**：营收增速、净利润增速、ROIC
- **财务健康**：资产负债率、流动比率、经营现金流/净利润

### 第六步：生成投资分析报告

报告结构（8章）：

| 章节 | 标题 | 核心内容 |
|------|------|----------|
| 1 | 执行摘要 | 核心指标、投资亮点、风险提示、十二核心问题评估 |
| 2 | 公司概况与业务模式 | 公司简介、主营业务、战略定位 |
| 3 | 三十二维度尽调分析 | 8层面全方位评估 |
| 4 | 估值分析 | 估值指标、行业因素、目标价格 |
| 5 | 竞争格局与护城河深度 | 竞争态势、护城河与供应链评估 |
| 6 | 风险因素 | 风险矩阵、估值风险、地缘政治风险 |
| 7 | 重要股东投资逻辑分析 | 各类股东持仓逻辑 |
| 8 | 投资建议与策略 | 评级、目标价、策略、跟踪指标 |

## 数据来源规范

所有分析报告必须在醒目位置标注数据来源：

```
【数据来源】
- 行情数据：东方财富、同花顺（截至YYYY-MM-DD）
- 财务数据：上市公司公告、交易所披露（最新披露期）
- 估值数据：iFinD/东方财富（截至YYYY-MM-DD）
- 其他：注明具体来源
```

## 常用指标速查

### 估值指标
| 指标 | 公式 | 适用场景 | 合理范围 |
|------|------|----------|----------|
| PE(TTM) | 市值/近12个月净利润 | 成熟企业 | 行业均值±50% |
| Forward PE | 市值/预期未来12个月净利润 | 成长企业 | 预期增速匹配 |
| PB | 市值/净资产 | 金融、重资产 | < 3为价值 |
| PS | 市值/营收 | 早期、亏损企业 | < 10为合理 |

### 成长性指标
| 指标 | 优秀标准 |
|------|----------|
| 营收增速 | > 20% |
| 净利润增速 | > 营收增速 |
| ROIC | > 15% |

### 财务健康
| 指标 | 安全标准 |
|------|----------|
| 资产负债率 | < 60% |
| 流动比率 | > 1.5 |
| 经营现金流/净利润 | > 1 |

## 输出格式

完成分析后，按以下格式输出：

1. **执行摘要**：核心结论、一句话投资逻辑
2. **十二核心问题评分**：各维度评分与关键发现
3. **三十二维度尽调结果**：各层面评估结论
4. **估值分析**：当前估值与目标价
5. **投资建议**：评级（买入/持有/卖出）、目标价、核心逻辑
