# 附录A：数据来源约定与使用规范（铁律）

本技能所有财经数据必须遵循以下原则，违反者视为分析报告无效。

## A.1 核心原则

|原则|具体要求|违规后果|
|-|-|-|
|**来源合规**|只能使用东方财富、同花顺、各大证券公司研报、交易所公告等正规渠道数据|数据不可用|
|**数据时效**|行情数据必须为最近交易日，财务数据使用最新披露期|分析失真|
|**禁止编造**|严禁自行编造、估算、推算关键财务/行情数据|严重违规|
|**三码对应**|股票名称、股票代码、行情数据必须相互验证、一一对应|分析错误|

## A.2 合规数据来源清单

|数据类型|推荐来源|优先级|
|-|-|:-:|
|实时行情|东方财富、同花顺|★★★|
|财务数据|上市公司公告、交易所披露|★★★|
|研报数据|中信证券、国泰君安、华泰证券等头部券商研报|★★|
|估值指标|东方财富、同花顺、iFinD|★★|
|股东数据|上市公司季报/年报、东方财富|★★|
|行业数据|国家统计局、行业协会、头部券商研报|★★|

## A.3 数据交叉验证要求

在进行投资分析前，必须完成以下数据一致性校验：

```
□ 股票名称与股票代码匹配（例：贵州茅台 ≠ 600519 或 000858）
□ 行情数据与数据源时间戳一致
□ 市值计算与股价×股本逻辑一致
□ 估值指标（PE/PB/PS）与市值/对应财务数据一致
□ 业绩预告与后续正式报告数据一致
```

## A.4 数据核实标准流程

1. **获取数据**：从合规来源获取原始数据
2. **交叉验证**：至少使用两个独立来源交叉验证
3. **逻辑校验**：验证数据之间的逻辑一致性（如市值=股价×总股本）
4. **时间确认**：确认数据为最新披露/最新交易日
5. **异常排除**：对明显偏离行业均值的异常数据进行复核

## A.5 禁止行为清单

```
🚫 禁止：根据股价倒推市值后声称是"数据来源"
🚫 禁止：使用过时行情数据（如节假日前的收盘价）
🚫 禁止：混淆不同市场的股票代码（如A股/港股/美股混淆）
🚫 禁止：使用估算/推算数据替代实际披露数据
🚫 禁止：将不同公司的数据张冠李戴
```

## A.6 数据报告格式规范

所有分析报告必须在醒目位置标注数据来源：

```
【数据来源】
- 行情数据：东方财富、同花顺（截至YYYY-MM-DD）
- 财务数据：上市公司公告、交易所披露（最新披露期）
- 估值数据：iFinD/东方财富（截至YYYY-MM-DD）
- 其他：注明具体来源
```

# 第一部分：五大核心问题框架

## 1.1 问题一：护城河是什么

**标准追问：**

> "你们的护城河是什么？5年后还存在吗？"

**护城河类型判断：**

|护城河类型|特征|典型企业|评估重点|
|-|-|-|-|
|网络效应|用户越多价值越大|微信、淘宝|网络密度、转换成本|
|品牌心智|品牌=品类代名词|茅台、可口可乐|品牌溢价、忠诚度|
|技术专利|独家技术/配方|高通、茅台|专利数量、保护期|
|规模经济|成本随规模下降|富士康、拼多多|成本优势、扩张边界|
|牌照垄断|资质门槛高|金融、烟草|政策持续性、牌照价值|

**追问形式：**

* "如果明天腾讯/字节跳动进入这个赛道，你们怎么办？"
* "你们的技术壁垒能被竞争对手快速复制吗？"
* "客户选择你们是因为价格、服务还是品牌？"

## 1.2 问题二：客户为什么选你们

**标准追问：**

> "客户为什么选你们，不选第二名？转换成本有多高？"

**客户粘性评估：**

|粘性类型|转换成本|典型案例|评估重点|
|-|-|-|-|
|极高|极高（不可替代）|ERP、银行核心系统|锁定程度、业务占比|
|高|较高（替换成本大）|Office、CAD软件|迁移难度、数据沉淀|
|中|中等（需要适应期）|电商平台、SaaS工具|替代方案、切换成本|
|低|较低（容易切换）|餐饮、外卖平台|产品差异、服务质量|

**追问形式：**

* "过去12个月，你们流失的核心客户去了哪里？为什么？"
* "如果竞争对手降价20%，客户会流失多少？"
* "你们的产品在客户成本结构中占多少比例？"

## 1.3 问题三：创始人决策

**标准追问：**

> "创始人，你过去最艰难的决策是什么？当时怎么选的？"

**决策质量评估维度：**

|决策类型|考察重点|评估标准|
|-|-|-|
|战略抉择|方向判断、押注勇气|反共识但正确|
|组织决策|人员取舍、利益平衡|长远眼光 vs 短期痛苦|
|资本决策|融资节奏、投资方向|资金效率最大化|
|合规抉择|拒绝灰色收入、主动披露|价值观底线|

**追问形式：**

* "如果重来一次，你会做不同选择吗？"
* "你愿意为此付出什么代价？"
* "你们踩过最大的坑是什么？如何爬出来的？"

## 1.4 问题四：单位经济模型

**标准追问：**

> "单位经济模型（Unit Economics）算清楚了吗？规模化后是改善还是恶化？"

**核心指标体系：**

|指标|公式|优秀标准|评估|
|-|-|:-:|-|
|客户终身价值（LTV）|ARPU × 留存月数 × 毛利率|LTV/CAC > 3|优秀/良好/承压|
|客户获取成本（CAC）|营销费用 / 新增客户数|回收期 < 12个月|优秀/良好/承压|
|边际贡献率|(收入-可变成本) / 收入|> 40%|优秀/良好/承压|
|单客经济|收入/客户数 - 成本/客户数|> 0 且增长|优秀/良好/承压|

**规模化后的预期变化：**

* ✓ 改善：边际成本递减、运营效率提升、网络效应增强
* → 稳定：规模经济抵消管理复杂度
* ✗ 恶化：规模不经济、管理失控、边际获客成本上升

## 1.5 问题五：终局位置判断

**标准追问：**

> "如果这个行业只能活3家公司，除了你们，另外两家是谁？为什么？"

**终局类型判断：**

|终局形态|特征|典型赛道|投资逻辑|
|-|-|-|-|
|赢家通吃|一家独大占据70%+市场|社交、搜索、操作系统|押注龙头|
|双寡头|两家合计占据60%+市场|电商、网约车、外卖|均衡配置|
|三分天下|三家合计占据50%+市场|手机、电动车|分散布局|
|诸侯割据|多家并存、各有领地|餐饮、零售|精选个股|
|分散市场|高度分散、长尾生存|餐饮、服务业|平台整合逻辑|

**战略定位评估：**

* 🏆 领先者：技术/品牌/规模领先，有望成为龙头
* 🥈挑战者：差距缩小，具备颠覆可能
* 🥉跟随者：差异化定位，细分市场冠军
* ⏳观望者：格局未定，需持续跟踪

## 1.6 补充维度一：资本配置能力

**标准追问：**

> "你们的资本配置优先级是什么？过去三年维持性支出与扩张性支出的比例是多少？"

**核心考察点：**

|考察维度|关键问题|验证方法|
|-|-|-|
|配置优先级|维持/防御/成长/回报如何排序|资本支出结构分析|
|配置纪律|是否频繁改变投资方向|历史投资回顾|
|股东回报|分红/回购/再投资如何平衡|分红率与回购历史|
|机会成本|放弃的配置选项是否更优|行业比较分析|

**追问形式：**

* "如果出现富余现金，你们优先考虑分红、回购还是再投资？"
* "过去五年的分红率是否稳定？回购价格是否合理？"
* "你们在资本配置上犯过什么错误？如何纠正？"

**评估框架：**

|资本配置类型|定义|评估标准|
|-|-|-|
|维持性资本支出|保持现有竞争力的必要投入|占比合理、不过度节俭|
|防御性资本支出|抵御风险的战略投入|充分覆盖关键风险|
|成长性资本支出|扩张产能/研发/渠道|ROI > 资本成本|
|股东回报|分红/回购|分红率匹配发展阶段|

## 1.7 补充维度二：人才密度与组织能力

**标准追问：**

|激励机制|股权激励覆盖面与力度|激励与业绩绑定|
|组织弹性|能否支撑下一个数量级增长|组织架构扁平化程度|

**追问形式：**

* "过去两年核心技术人员和管理层的流失率是多少？"
* "你们如何应对关键岗位的人才争夺战？"
* "如果创始人离开，公司能否正常运行？"
* "你们的管理层级有几层？决策链条是否过长？"

**评估框架：**

|组织能力维度|优秀标准|预警信号|
|-|-|-|
|人才密度|核心岗位零流失率|关键人才频繁离职|
|梯队深度|关键岗位有合格继任者|青黄不接|
|激励机制|覆盖面广、力度足够|激励不足导致人心浮动|
|组织弹性|架构扁平、决策高效|层级过多、效率低下|

# 第三部分：重要股东投资逻辑分析

## 三、股东分析框架（必选章节）

### 3.1 股东类型分类

|股东类型|投资逻辑|评估重点|持股比例参考|
|-|-|-|:-:|
|国家队|政策导向、稳定市场|战略意图、资源支持|1%-10%|
|社保基金|长期稳健、绝对收益|风险偏好、投资周期|0.5%-3%|
|养老基金|超长期配置、价值投资|估值安全边际|0.3%-2%|
|产业资本|战略协同、业务合作|产业整合意图|1%-20%|
|知名牛散|个人判断、灵活配置|投资风格、持仓周期|0.1%-2%|
|公募基金|专业筛选、组合配置|持仓集中度、换手率|5%-30%|
|北向资金|外资视角、全球比较|汇率风险、估值体系|1%-15%|

### 3.2 重点股东分析模板

#### 国家队（大基金/国有资本）

```
【投资方背景】
- 背景介绍（规模、管理架构、投资偏好）
- 代表产品/基金情况

【投资逻辑分析】
| 维度 | 分析内容 |
|-----|---------|
| 战略定位 | 行业龙头/政策支持/国企改革 |
| 持股结构 | 持仓稳定性、增持减持动向 |
| 投资风格 | 长期持有/波段操作/价值发现 |
| 政策信号 | 国家队入场=政策底？ |
| 资源支持 | 订单支持/背书效应 |

【评估结论】
国家队持仓变化是重要参考信号
```

#### 社保基金

```
【持仓情况】
- 持仓比例、组合配置
- 历史持仓变化轨迹

【投资逻辑】
- 稳健投资风格：追求绝对收益
- 长线配置逻辑：看好赛道长期发展
- 风险偏好特征：低估值、高分红、稳定现金流

【评估结论】
社保持仓=价值投资信号
```

#### 养老基金

```
【持仓特点】
- 超长期投资视角
- 注重分红与股息率
- 持仓稳定性极高

【投资偏好】
- 行业龙头
- 现金流稳定
- 估值合理

【评估结论】
养老基金=长期价值认可
```

#### 产业资本（哈勃投资等）

```
【投资方背景】
- 母公司/集团介绍
- 投资平台定位
- 过往投资案例

【协同逻辑分析】
| 维度 | 分析 |
|-----|-----|
| 业务协同 | 产业链整合/技术合作 |
| 战略意图 | 生态布局/卡位竞争 |
| 技术背书 | 研发支持/人员交流 |
| 潜在订单 | 优先采购/长期合作 |

【评估结论】
产业资本入局=战略价值认可
```

#### 知名牛散（葛卫东等）

```
【牛散背景】
- 投资经历、代表战绩
- 擅长领域、投资风格

【持仓分析】
- 持仓比例、历史变化
- 持仓周期特征

【投资逻辑】
- 行业判断依据
- 逆向投资/趋势投资

【评估结论】
牛散持仓=关注信号（非推荐）
```
