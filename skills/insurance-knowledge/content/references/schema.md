## 核心模块

### 1. WeChatScraper（公众号采集器）

**职责**：从微信公众号获取文章列表

**实现方式**：
- 首选：RSSHub 公开 RSS 服务
- 备选：微信公众号搜索 API
- 降级：手动输入文章链接

**限制**：
- 每公众号最多 5 篇文章
- 请求间隔 ≥ 30 秒

### 2. VideoAccountScraper（视频号采集器）

**职责**：从视频号获取视频信息

**实现方式**：
- 视频号主页解析
- 视频描述文本提取
- 字幕信息获取（如果可用）

**限制**：
- 每视频号最多 3 个视频
- 请求间隔 ≥ 60 秒

### 3. ContentFilter（内容过滤器）

**职责**：根据关键词过滤内容

**过滤规则**：
- 包含规则（满足任一关键词即保留）
- 排除规则（满足任一关键词则排除）
- 长度规则（标题过短则排除）

### 4. InsightsExtractor（观点提炼器）

**职责**：使用 LLM 从文章内容中提炼核心观点

**提炼字段**：
- `product_name`：产品名称
- `coverage`：保障责任
- `rate_comparison`：费率对比
- `pros`：优点
- `cons`：缺点
- `sales_talk`：销售话术

### 5. FeishuPusher（飞书推送器）

**职责**：将采集结果推送至飞书

**推送模式**：
- `card`：卡片形式展示所有文章
- `summary`：摘要统计 + 列表
- `text`：纯文本

## 定时任务配置

### Cron 表达式示例

```
# 每日早上 9 点
0 9 * * *

# 每周一早上 9 点
0 9 * * 1

# 每工作日早上 9 点
0 9 * * 1-5
```

### 定时任务脚本

```bash
#!/bin/bash
# cron_task.sh

CONFIG_PATH="/path/to/config.yaml"
WEBHOOK_URL="https://open.feishu.cn/open-apis/bot/v2/hook/xxx"
OUTPUT_DIR="/path/to/output"

# 执行采集
python scripts/collect_content.py \
  --config "$CONFIG_PATH" \
  --output "$OUTPUT_DIR/insurance_$(date +%Y%m%d).md" \
  --articles-json "$OUTPUT_DIR/articles_$(date +%Y%m%d).json"

# 推送到飞书
python scripts/feishu_pusher.py \
  --webhook "$WEBHOOK_URL" \
  --summary \
  --articles-json "$OUTPUT_DIR/articles_$(date +%Y%m%d).json"
```

## 错误处理

| 错误类型 | 处理策略 |
|---------|---------|
| 网络超时 | 重试 3 次，间隔 10 秒 |
| RSSHub 不可用 | 切换备用实例 |
| 账号不存在 | 记录并跳过，继续处理其他账号 |
| 被反爬拦截 | 停止采集，等待 30 分钟 |
| 飞书推送失败 | 重试 2 次，记录失败日志 |

## 安全性考虑

1. **API Key 存储**：敏感信息存储在环境变量或加密配置
2. **请求频率**：严格控制避免触发反爬
3. **数据隔离**：不与其他系统共享采集数据
4. **审计日志**：记录所有采集操作
