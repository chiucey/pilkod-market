# 保险知识采集与分析技能

## 功能概述

本技能帮助用户从微信公众号和视频号采集保险相关内容，提炼核心观点，并支持定时推送至飞书。

## 使用场景

1. **内容采集**：抓取指定公众号/视频号的最新保险相关文章和视频
2. **知识提炼**：从采集内容中提取产品信息、保障责任、费率对比等关键知识
3. **定时任务**：设置每日/每周自动采集并推送至飞书
4. **关键词过滤**：只保留特定险种相关内容（重疾险、增额终身寿、年金险等）

## 工作流程

### 第一步：配置数据源

用户提供以下信息之一或组合：

**微信公众号配置：**
```
公众号名称或ID列表（逗号分隔）
例如：深蓝保, 奶爸保, 保险八卦姐
```

**视频号配置：**
```
视频号名称或主页链接列表
例如：保险观察, https://channels.weixin.qq.com/profile/xxx
```

**关键词过滤配置（可选）：**
```
关键词列表（逗号分隔，默认包含以下险种）
- 重疾险
- 增额终身寿
- 年金险
- 医疗险
- 寿险
- 意外险
```

### 第二步：执行内容抓取

系统自动执行以下操作：

1. **公众号文章抓取**
   - 使用 RSSHub 公开接口获取公众号最新文章
   - 限制每公众号最多5篇文章
   - 提取字段：标题、发布时间、作者账号、原文链接、阅读量

2. **视频号内容提取**
   - 解析视频号主页获取视频列表
   - 提取视频字幕/文案信息
   - 记录标题、发布时间、账号名

3. **智能内容过滤**
   - 根据关键词过滤不相关内容
   - 跳过付费/私密内容

### 第三步：AI 提炼核心观点

对每篇采集内容执行：

1. **标题解析**：理解文章/视频主题
2. **核心观点提炼**：
   - 产品名称识别
   - 保障责任总结
   - 费率/收益对比数据
   - 优缺点分析
   - 常见销售话术提炼
3. **结构化输出**：生成标准化格式

### 第四步：格式化输出

**公众号内容格式：**
```markdown
### 📰 公众号内容

#### [账号名称]
1. **文章标题**
   - 📅 发布时间：YYYY-MM-DD
   - 🔗 原文链接：[链接]
   - 📊 阅读量：xxx
   - **核心观点：**
     - 产品名称：xxx
     - 保障责任：xxx
     - 费率对比：xxx vs xxx
     - 优点：xxx
     - 缺点：xxx
     - 销售话术：xxx
```

**视频号内容格式：**
```markdown
### 🎬 视频号内容

#### [账号名称]
1. **视频标题**
   - 📅 发布时间：YYYY-MM-DD
   - 📝 字幕/文案摘要：xxx
   - **核心观点：**
     - 产品名称：xxx
     - 保障责任：xxx
     - 费率对比：xxx vs xxx
     - 优点：xxx
     - 缺点：xxx
```

### 第五步：导出与推送

**导出选项：**
- Markdown 格式（默认）
- 纯文本格式
- 保存至本地文件

**飞书推送配置：**
- Webhook URL 配置
- 定时执行（每日/每周）
- 推送时间设置

## 合规要求

1. **仅限个人学习**：本技能仅用于个人学习和业务参考
2. **不用于商业用途**：禁止将采集内容用于商业盈利
3. **请求频率限制**：
   - 每次采集间隔 ≥ 30秒
   - 每日采集次数限制 ≤ 10次
   - 避免高峰时段抓取
4. **数据存储原则**：
   - 不存储原文内容
   - 仅保存提炼后的观点和链接
   - 链接仅作为知识索引
5. **平台合规**：
   - 仅抓取公开可见内容
   - 不登录、不获取隐私信息
   - 遵守各平台 robots.txt

## 配置文件说明

配置文件路径：`references/config.yaml`

```yaml
# 公众号配置
wechat_public_accounts:
  - name: "深蓝保"
  - name: "奶爸保"
  # 可添加更多...

# 视频号配置
video_accounts:
  - name: "保险观察"
  # 可添加更多...

# 关键词过滤
keywords_filter:
  - "重疾险"
  - "增额终身寿"
  - "年金险"
  - "医疗险"
  - "寿险"
  - "意外险"
  - "保险攻略"
  - "保险测评"

# 飞书推送配置
feishu_webhook:
  enabled: false
  webhook_url: "https://open.feishu.cn/open-apis/bot/v2/hook/xxx"
  schedule: "daily"  # daily / weekly
  push_time: "09:00"

# 采集限制
limits:
  articles_per_account: 5
  daily_requests: 10
  request_interval_seconds: 30
```

## 技术实现

### 公众号抓取方案
- **首选**：RSSHub 公开服务（无需登录）
- **备选**：第三方聚合平台 API
- **限制处理**：对于无法访问的公众号，提供手动链接输入选项

### 视频号处理方案
- **字幕提取**：使用视频平台公开字幕或标题信息
- **文案分析**：分析视频描述文本
- **频率控制**：单次最多处理3个视频号

### AI 提炼引擎
- 使用 LLM 进行内容理解和观点提炼
- 结构化输出统一格式
- 敏感信息过滤

## 故障排除

| 问题 | 解决方案 |
|------|----------|
| 公众号文章抓取失败 | 检查公众号名称是否正确，尝试使用短名称 |
| 视频号无法访问 | 确认视频号主页为公开链接 |
| 飞书推送失败 | 检查 Webhook URL 是否有效 |
| 内容过滤过于严格 | 调整关键词列表，减少过滤词 |
| 触发反爬限制 | 等待30分钟后重试，降低采集频率 |
