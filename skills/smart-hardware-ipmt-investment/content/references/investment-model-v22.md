## 版本说明

V2.2核心改进：
1. **老品ROI系数计算**：修正"营销ROI系数"与"营销弹性系数"公式不一致问题
2. **大客户投资模型**：基于历史数据建立"目标ROI反推法"，替代5%比例法
3. **新品多维决策**：简化为"ROI门槛+战略一票通过"模式，提升可落地性

---

## 核心框架

```
战略输入层：年度业绩目标 + 业务形态分布 + 投资组合策略
    ↓
预算规划层：
  ├─ 老品：老品增长预算 = 老品增长目标 / 老品ROI系数
  ├─ 大客户：预算 = 目标毛利 / 目标ROI × 战略系数
  └─ 新品：预算 = 新增毛利目标 / 新品ROI系数
    ↓
决策执行层：
  ├─ 新品：ROI门槛 ≥ 1.5/3.0/5.0 + 战略一票通过
  ├─ 大客户：ROI ≥ 目标ROI + 净利率校验
  └─ 老品：ROI系数年度滚动更新
    ↓
验证复盘层：季度ROI回顾 + 年度预算偏差分析 + 模型参数滚动优化
```

## 第一部分：老品增长预算模型

### 1. 核心概念区分

**营销ROI系数**：
- 公式：Δ营收 / Δ营销投入
- 单位：倍（dimensionless）
- 含义：每投入1元，带来X元营收
- 智能硬件行业范围：2.0-8.0

**营销弹性系数**：
- 公式：(Δ营收/基准营收) / (Δ营销/基准营销)
- 单位：%/%（dimensionless）
- 含义：营销投入增长1%，营收增长X%
- 智能硬件行业范围：0.1-2.0

**换算关系**：
```
ROI系数 ≈ 弹性系数 × (基准营收/基准营销投入)
```

### 2. ROI系数三种计算方法

#### 方法一：历史数据反推法（最推荐）
```
老品ROI系数 = Σ(各老品营收增量) / Σ(各老品营销投入)
```

示例（骑行台）：
- 2024年营收：325,540,000
- 2025年营收：459,448,966
- 营收增长：133,908,966
- 营销投入（5%-8%）：16,277,000 ~ 26,043,200
- ROI系数 ≈ 133,908,966 / 20,000,000 ≈ 6.7

#### 方法二：营销弹性系数法
```
老品ROI系数 = 老品营销弹性系数 × (基准营收/基准营销投入)
```

| 产品类型 | 营销弹性系数 | ROI系数推导 |
|----------|------------|------------|
| 成熟核心产品 | 0.1-0.3 | 2.0-4.0 |
| 成长产品 | 0.3-0.8 | 3.0-6.0 |
| 新上市产品 | 0.8-2.0 | 4.0-8.0 |

#### 方法三：行业基准对标法

| 行业类型 | ROI系数参考 | 弹性系数参考 |
|----------|------------|------------|
| 消费电子 | 2.0-4.0 | 0.2-0.5 |
| 智能硬件 | 3.0-6.0 | 0.3-0.8 |
| 运动科技 | 4.0-8.0 | 0.4-1.0 |
| 医疗设备 | 1.5-3.0 | 0.1-0.4 |

### 3. 老品营销预算计算流程

```
Step 1：确定老品增长目标
  老品增长目标 = 年度总业绩目标 - 新品预期贡献 - 大客户预期贡献

Step 2：确定老品ROI系数（选上述三种方法之一）

Step 3：计算所需营销投入
  所需老品营销预算 = 老品增长目标 / 老品ROI系数

Step 4：按增长因素分配
  渠道拓展 35% / 品牌深化 25% / 产品迭代 20% / 营销推动 20%

Step 5：ROI系数敏感性分析
  ROI=3.0 → 🔴保守 / ROI=5.0 → 🟡合理 / ROI=7.0 → 🟢优秀
```

### 4. ROI系数动态更新

```
年度老品ROI系数 = α × 历史系数 + (1-α) × 当年测算值
建议 α = 0.75
偏差 > 20% 需分析原因
```

## 第二部分：大客户投资决策模型

### 1. 从5%比例法到目标ROI反推法

V2.2核心改进：预算与ROI目标挂钩，而非简单比例。

### 2. 大客户历史ROI基准

| 大客户 | 综合ROI | 净利率 | 代表产品 |
|--------|--------|--------|---------|
| Wahoo | 155.75倍 | 24.36% | Verona（ROI=104）、Kickr Core（ROI=1822） |
| 迪卡侬 | 20.95倍 | 20.23% | D100系列（ROI=43-183） |

### 3. 目标ROI反推法

```
核心公式：
大客户年度预算 = 预期毛利贡献 / 目标ROI
预期毛利贡献 = 预期收入 × 历史毛利率
实际预算 = min(ROI反推预算, 上限控制线)
```

### 4. 大客户差异化参数

| 维度 | Wahoo | 迪卡侬 |
|------|-------|--------|
| 收入规模 | 约4亿/年 | 约1.57亿/年 |
| 毛利水平 | 22%-25% | 25%-30% |
| 目标ROI | ≥5.0 | ≥3.5 |
| 预算上限 | 收入的5% | 毛利的20% |
| 项目类型 | 定制开发为主 | 标准品OEM+定制 |
| 战略价值 | 技术标杆、全球渠道 | 规模化产能利用 |

### 5. PDT维度ROI参考

| PDT | 项目数 | 综合ROI | 平均净利率 | 建议目标ROI |
|-----|--------|--------|-----------|------------|
| 骑行台 | 8 | 275.29 | 18.64% | ≥10.0 |
| 功率计 | 1 | 27.11 | 21.31% | ≥8.0 |
| 传感器 | 3 | 31.01 | 16.05% | ≥5.0 |
| 码表 | 2 | 9.77 | 14.76% | ≥4.0 |
| 车灯 | 1 | 5.58 | 7.07% | ≥3.0 |

### 6. 大客户年度预算确定流程

```
Step 1（Q3末）：数据准备
  → 提取历史项目数据，计算综合ROI和净利率
  → 输出《大客户历史ROI与净利率基准表》

Step 2（Q4）：年度目标沟通
  → 与大客户对齐年度计划（老品+新增）
  → 收集新项目需求 → 《客户年度项目清单》

Step 3（Q4）：预算粗算
  → 计算预算上限（上年净利 × 40%）
  → 分配：老品维系30% + 新增项目70%

Step 4（Q4）：项目级ROI校验
  → 每个项目计算ROI vs PDT历史ROI
  → 净利率 vs 大客户历史净利率
  → ROI < 历史ROI×80% → 重评
  → 净利率 < 历史×60% → 特批

Step 5（Q4末）：整体校验与审批
  → 汇总 → 对比上限 → 超标则砍低优先级
  → 输出《大客户年度预算分配方案》

Step 6（年度执行中）：季度回顾与调整
  → 更新实际数据 → 重算ROI
  → 持续低于预期 → 启动复盘
```

### 7. 大客户ROI计算标准

```
ROI = 毛利贡献 / 客户投入
毛利贡献 = 该客户收入 × 毛利率
客户投入 = 研发投入 + 销售投入 + 客情维护 + 其他分摊
```

## 第三部分：新品投资决策模型

### 1. 纯ROI模型的六维缺失

| 维度 | 问题 | 启示 |
|------|------|------|
| 市场天花板 | ROI高但市场小，不值得大投 | ROI高≠值得大投入 |
| 竞争格局 | 战略必争之地ROI低也要投 | 防御性投入 |
| 技术平台价值 | 平台型投资ROI被低估 | 复用价值 |
| 时间窗口 | 不投的代价可能更大 | 机会成本 |
| 投入充分性 | ROI高可能是投入不足 | 检查充分性 |
| 现金流贡献 | 应看年化ROI | 时间维度 |

### 2. 简化模型：ROI门槛 + 战略一票通过

**规则1：ROI门槛（必须通过）**

| 业务形态 | ROI门槛 | 低于门槛处理 |
|---------|---------|------------|
| 核心业务 | ≥5.0 | CEO或IPMT特批 |
| 成长业务 | ≥3.0 | 部门负责人审批 |
| 孵化业务 | ≥1.5 | PDT自行决策 |

ROI计算：`ROI = (预估收入 × 毛利率) / 研发投入`
- TOC产品毛利率参考：50%
- TOB产品毛利率参考：40%

**规则2：战略一票通过（满足任一，门槛降低1档）**
- 战略必争之地（IPMT集体决策）
- 时间窗口紧迫（错过不再）
- 平台型投资（技术复用>50%）

降低后门槛：核心≥3.0 / 成长≥2.0 / 孵化≥1.0

**规则3：一票否决**
- 技术方案未成熟
- 目标市场不明确
- 团队能力不足
- 超预算承载
