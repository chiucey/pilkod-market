# 智能硬件产研销一体化投资预算管理技能（V2.2）

## 技能概述

本技能封装了智能硬件IPMT投资管理的核心量化模型，基于V2.2版本，涵盖三大核心模块：

1. **老品增长预算模型**：基于ROI系数的老品营销预算计算
2. **大客户投资决策模型**：基于目标ROI反推法的大客户预算管理
3. **新品多维决策模型**：ROI门槛+战略一票通过的简化评审机制

完整模型细节详见 `references/investment-model-v22.md`。

## 核心模型速查

### 一、老品增长预算模型

#### 核心公式
```
老品营销预算 = 老品增长目标 / 老品ROI系数
老品ROI系数 = Σ(各老品营收增量) / Σ(各老品营销投入)
```

#### ROI系数参考值（智能硬件行业）
| 产品类型 | ROI系数参考值 | 弹性系数参考值 |
|----------|-------------|--------------|
| 成熟核心产品 | 2.0-4.0 | 0.1-0.3 |
| 成长产品 | 3.0-6.0 | 0.3-0.8 |
| 新上市产品 | 4.0-8.0 | 0.8-2.0 |

#### 三种ROI系数计算方法
1. **历史数据反推法**（最推荐）：`ROI系数 = Σ(营收增量) / Σ(营销投入)`
2. **弹性系数换算法**：`ROI系数 = 弹性系数 × (基准营收/基准营销投入)`
3. **行业基准对标法**：参考同行业上市公司数据

#### ROI系数动态更新
```
年度ROI系数 = α × 历史系数 + (1-α) × 当年测算值
其中 α = 0.75（建议值）
```

#### 预算分配比例
| 增长因素 | 预算占比 | 说明 |
|---------|---------|------|
| 渠道拓展 | 35% | 新渠道、新市场 |
| 品牌深化 | 25% | 品牌知名度、忠诚度 |
| 产品迭代 | 20% | 产品升级、SKU丰富 |
| 营销推动 | 20% | 促销、KOL合作 |

### 二、大客户投资决策模型

#### 核心公式（目标ROI反推法）
```
大客户年度预算 = 预期毛利贡献 / 目标ROI
实际预算 = min(ROI反推预算, 上限控制线)
```

#### 智能硬件大客户参数
| 维度 | Wahoo | 迪卡侬 |
|------|-------|--------|
| 目标ROI | ≥5.0 | ≥3.5 |
| 预算上限 | 收入的5% | 毛利的20% |
| 毛利率参考 | 20%-25% | 25%-30% |
| 项目类型 | 定制开发为主 | 标准品OEM+定制 |

#### PDT维度ROI参考基准
| PDT | 建议目标ROI | 平均净利率 |
|-----|------------|-----------|
| 骑行台 | ≥10.0 | 18.64% |
| 功率计 | ≥8.0 | 21.31% |
| 传感器 | ≥5.0 | 16.05% |
| 码表 | ≥4.0 | 14.76% |
| 车灯 | ≥3.0 | 7.07% |

#### 项目级ROI校验标准
- ROI < PDT历史ROI × 80% → 需重新评估
- 净利率 < 大客户净利率 × 60% → 需特批

### 三、新品投资决策模型

#### 三步决策流程
```
Step 1：算ROI（10分钟）
  → ROI = (预估收入 × 毛利率) / 研发投入
  → 对比门槛

Step 2：检查否决项（5分钟）
  → 技术方案未成熟？→ 否决
  → 目标市场不明确？→ 否决
  → 团队能力不足？→ 否决
  → 超预算承载？→ 否决

Step 3：战略讨论（10分钟）
  → ROI达标 → 直接通过
  → ROI不达标 → IPMT战略讨论
    → 战略必争之地 / 时间窗口 / 平台型投资
    → 通过则ROI门槛降低1档
    → 不通过则否决
```

#### ROI门槛规则
| 业务形态 | 标准门槛 | 战略例外后 |
|---------|---------|-----------|
| 核心业务 | ≥5.0 | ≥3.0 |
| 成长业务 | ≥3.0 | ≥2.0 |
| 孵化业务 | ≥1.5 | ≥1.0 |

#### 毛利率参考
- TOC产品（智能硬件品牌）：50%
- TOB产品（OEM/ODM）：40%

#### 战略一票通过条件（满足任一）
1. **战略必争之地**：IPMT集体决策认定
2. **时间窗口紧迫**：错过机会不再
3. **平台型投资**：技术复用 > 50%

## 使用指引

1. **回答任何投资相关问题时**，优先使用本技能中的公式和参数
2. **用户提到具体PDT或大客户时**，自动调取对应的ROI/净利率基准
3. **新品评审时**，严格按三步流程执行：算ROI → 检否决 → 战略讨论
4. **不编造数据**：如果用户未提供营收/毛利/投入数据，主动询问
5. **V2.2的三个核心改进**（相比V2.0）：
   - 老品：ROI系数与弹性系数不再混淆
   - 大客户：从5%比例法升级为目标ROI反推法
   - 新品：从六维矩阵简化为ROI门槛+战略一票通过
