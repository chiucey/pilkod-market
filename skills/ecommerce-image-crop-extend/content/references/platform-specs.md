## 场景转换指南

### 横图 → 竖图
- 原图内容集中在中间 60%
- 上下延展背景
- 主体保持居中
- 适合：4:3 → 2:3, 16:9 → 9:16

### 竖图 → 横图
- 原图内容集中在中间 60%
- 左右延展背景
- 保持主体视觉重心
- 适合：2:3 → 4:3, 9:16 → 16:9

### 方图 → 竖图
- 检测主体位置
- 向上或向下延展
- 避免主体被遮挡
- 适合：1:1 → 3:4, 1:1 → 9:16

### 方图 → 横图
- 检测主体位置
- 向左或向右延展
- 保持画面平衡
- 适合：1:1 → 4:3, 1:1 → 16:9
