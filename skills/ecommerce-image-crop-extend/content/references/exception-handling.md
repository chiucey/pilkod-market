# 异常处理详细指南

## 异常分类体系

### A 类：原图质量异常

#### A1: 分辨率过低
**检测标准**：
- 长边像素 < 800px
- 短边像素 < 400px
- 宽高比极端 (> 1:5 或 < 5:1)

**影响评估**：
- 扩图后清晰度下降
- 可能出现像素化

**处理方案**：
```
建议方案：
1. 使用超分辨率技术提升基础分辨率
2. 接受较低输出分辨率（≤原图尺寸）
3. 使用 2x/3x 放大但标注"可能模糊"
```

**提示模板**：
> ⚠️ **原图分辨率分析**
> - 原图尺寸：{width} x {height}
> - 评估结果：分辨率较低，扩图后可能出现模糊
>
> 💡 **建议选项**：
> 1. 保持原尺寸输出（不扩图）
> 2. 接受 2x 放大（可能轻微模糊）
> 3. 使用超分辨率增强（处理时间较长）

---

#### A2: 压缩损伤
**检测标准**：
- JPEG 伪影明显
- 色块/色带异常
- 边缘振铃效应

**处理方案**：
```
建议方案：
1. 先进行去压缩损伤处理
2. 标注输出质量可能受影响
3. 建议用户提供更高质量原图
```

---

### B 类：构图异常

#### B1: 主体贴边
**检测标准**：
- 主体距任何边缘 < 5% 图宽
- 主体跨越画面边界

**影响评估**：
- 扩图时难以保持自然
- 裁切时可能丢失主体

**处理方案**：
```
建议方案：
1. 轻度贴边 (< 10%)：可接受扩图，注意延伸方向
2. 中度贴边 (10-20%)：扩图风险较高，建议裁切偏移
3. 重度贴边 (> 20%)：需用户确认处理方案
```

**提示模板**：
> ⚠️ **主体位置分析**
> - 主体位置：{left/right/top/bottom} 边缘 {distance}%
> - 评估结果：主体靠近 {方向} 边缘
>
> 💡 **处理选项**：
> 1. 向{direction}扩图（可能产生不自然背景）
> 2. 向{opposite_direction}扩图（保持主体居中）
> 3. 裁切时保留{side}侧{percentage}%边距

---

#### B2: 主体偏离中心
**检测标准**：
- 主体中心偏离画面中心 > 30%
- 主体占据画面 < 20% 或 > 90%

**处理方案**：
```
建议方案：
1. 裁切时以主体为中心
2. 扩图时向主体较少方向延展
3. 保留原构图（如用户要求）
```

---

### C 类：内容异常

#### C1: 文案区域过大
**检测标准**：
- 文案/文字覆盖画面 > 40%
- 文字距边缘 < 5%
- 多语言文字混合

**影响评估**：
- 安全裁切空间不足
- 扩图可能影响文案可读性

**处理方案**：
```
建议方案：
1. 包含文案区域在裁切/扩图范围内
2. 优先保护重要文字（如价格、促销语）
3. 次要文字可适当裁切（需用户授权）
```

**提示模板**：
> ⚠️ **文案区域分析**
> - 文案占比：{percentage}%
> - 重要文案：{list}
> - 评估结果：文案区域较大，安全裁切空间有限
>
> 💡 **处理选项**：
> 1. 保留全部文案（建议尺寸受限）
> 2. 裁切次要文案（需授权）
> 3. 文案区域单独处理

---

#### C2: 复杂场景
**检测标准**：
- 多个主体分散
- 场景深度复杂
- 前景背景交错

**处理方案**：
```
建议方案：
1. 识别所有重要主体
2. 选择最优裁切框覆盖最多主体
3. 扩图时优先延展背景区域
```

---

#### C3: 纯色/渐变背景
**检测标准**：
- 背景色块单一（> 90% 相似）
- 渐变平滑过渡
- 无明显纹理

**处理方案**：
```
建议方案：
1. 纯色背景：直接颜色延伸
2. 渐变背景：延续渐变方向和色彩
3. 效果：自然、无缝
```

---

### D 类：扩图风险

#### D1: 扩图比例过大
**检测标准**：
- 扩图面积 > 原图 50%
- 任一边扩图 > 原尺寸 80%

**影响评估**：
- 扩图区域可能失真
- AI 生成内容可能穿帮

**处理方案**：
```
建议方案：
1. 分步扩图（先 50%，再补足）
2. 降低扩图目标（如 4:3 → 21:9 改为 16:9）
3. 接受风险继续（标注可能失真）
4. 建议用户提供更长比例的原图
```

**提示模板**：
> ⚠️ **扩图比例评估**
> - 目标尺寸：{target}
> - 扩图比例：{ratio}%
> - 评估结果：扩图幅度较大，可能出现失真
>
> 💡 **建议选项**：
> 1. 降低扩图目标（建议 {alternative_ratio}）
> 2. 分步处理（先生成中等比例，再补足）
> 3. 继续执行（接受可能的失真风险）

---

#### D2: 扩图方向冲突
**检测标准**：
- 主体偏向一侧
- 用户指定方向与主体位置冲突

**处理方案**：
```
建议方案：
1. 优先保持主体完整
2. 向主体较少方向扩图
3. 提示用户最终处理方案
```

---

## 异常处理决策流程

```
开始
  ↓
原图质量检测
  ↓
分辨率足够？ ──否──→ A1处理 → 提示用户 → 等待确认
  ↓ 是
主体位置检测
  ↓
主体完整？ ──否──→ B1处理 → 提示用户 → 等待确认
  ↓ 是
文案区域检测
  ↓
文案占比合理？ ──否──→ C1处理 → 提示用户 → 等待确认
  ↓ 是
扩图需求评估
  ↓
需要扩图？ ──否──→ 直接裁切
  ↓ 是
扩图比例评估
  ↓
比例安全？ ──否──→ D1处理 → 提示用户 → 等待确认
  ↓ 是
执行扩图
  ↓
执行裁切
  ↓
完成
```

## 用户确认模板

### 需要用户确认的情况

1. **异常检测完成**
2. **提供多个处理选项**
3. **说明各选项的权衡**
4. **等待用户选择**

### 确认回复识别

**确认格式**：
- 直接回复选项编号（"1"、"选第一个"）
- 明确指令（"继续"、"执行"、"好的"）
- 明确拒绝（"算了"、"不要"、"取消"）

**默认处理**：
- 30秒内无回复 → 暂停执行
- 用户继续对话 → 延续上下文
- 用户超时重新发起 → 重新分析

## 异常日志

每次异常处理应记录：
- 异常类型和级别
- 检测到的具体数值
- 呈现给用户的选项
- 用户的最终选择
- 执行结果评估
