# 咨询顾问PPT设计系统

本文档详细说明咨询顾问风格PPT的设计规范，参考正略咨询、麦肯锡等顶级咨询公司的视觉标准。

## 配色系统

### 主色板

| 颜色名称 | Hex值 | RGB | 用途 |
|---------|-------|-----|------|
| 深海蓝 | `003366` | 0, 51, 102 | 主标题、强调元素 |
| 宝石蓝 | `004B8D` | 0, 75, 141 | 副标题、章节编号 |
| 商务蓝 | `0066CC` | 0, 102, 204 | 图表、链接 |
| 天空蓝 | `E6F0FF` | 230, 240, 255 | 卡片背景、高亮 |
| 极浅蓝 | `F5F9FF` | 245, 249, 255 | 交替行背景 |

### 中性色板

| 颜色名称 | Hex值 | 用途 |
|---------|-------|------|
| 深灰 | `333333` | 主要正文 |
| 中灰 | `666666` | 次要正文、注释 |
| 浅灰 | `999999` | 辅助文字 |
| 边框灰 | `CCCCCC` | 表格边框、分隔线 |
| 背景灰 | `F5F5F5` | 页面背景（可选） |

### 图表配色

按优先级使用：
1. `003366` - 深海蓝（第一数据系列）
2. `0066CC` - 商务蓝（第二数据系列）
3. `4A90D9` - 天蓝（第三数据系列）
4. `7AB3E8` - 浅蓝（第四数据系列）
5. `66CC99` - 绿色（增长/正向）
6. `FF6B6B` - 红色（下降/警示）

## 字体系统

### 字体家族

| 类型 | 中文 | 英文 | 数字 |
|------|------|------|------|
| 标题 | 微软雅黑 | Arial Bold | Arial |
| 正文 | 微软雅黑 | Arial | Arial |
| 表格 | 微软雅黑 | Arial | Arial |

### 字号规范

| 元素 | 字号 | 行高 | 字重 |
|------|------|------|------|
| 封面主标题 | 40-44pt | 1.2 | Bold |
| 封面副标题 | 20-24pt | 1.3 | Regular |
| 页面大标题 | 28-32pt | 1.2 | Bold |
| 页面小标题 | 20-24pt | 1.3 | Bold |
| 正文内容 | 14-16pt | 1.5 | Regular |
| 表格内容 | 11-12pt | 1.3 | Regular |
| 注释来源 | 10pt | 1.2 | Regular |

### 特殊文字

- **重点标注**：使用加粗 + 主题色
- **关键词**：使用主题色或加粗
- **数据强调**：使用大号数字 + 主题色

## 布局系统

### 页面结构

```
┌──────────────────────────────────────────────────┐
│ 0.08" 顶部装饰条 (主题色)                          │
├────┬─────────────────────────────────────────────┤
│    │                                             │
│ 0.08" │ ← 内容区域开始                          │
│    │                                             │
│ 侧边 │   页面标题 (28-32pt, 0.4" 高度)           │
│ 装饰 │   ─────────────                           │
│ 条   │   (标题下分隔线, 1.5" 宽度)                │
│    │                                             │
│    │   主内容区域                                │
│    │   (1.2" - 4.8" 高度)                        │
│    │                                             │
│    │                                             │
│    │                                             │
│    │                        ┌───┐               │
│    │                        │ 3 │ ← 页码        │
│    │                        └───┘               │
└────┴─────────────────────────────────────────────┘
     0.5"          9"           0.5"
```

### 边距规范

| 位置 | 边距 | 说明 |
|------|------|------|
| 上边距 | 0.4" | 页面标题 |
| 左边距 | 0.5" | 正文开始 |
| 右边距 | 0.5" | 正文结束 |
| 下边距 | 0.5" | 页码/来源 |
| 内容宽度 | 9" | 可用内容宽度 |

### 间距规范

| 元素 | 间距 |
|------|------|
| 标题与内容 | 0.3" |
| 段落之间 | 0.25" |
| 列表项之间 | 0.2" |
| 表格行之间 | 0" (紧邻) |
| 卡片之间 | 0.3" |

## 装饰元素

### 装饰条

```javascript
// 顶部装饰条
{
  type: "RECTANGLE",
  x: 0, y: 0, w: 10, h: 0.08,
  fill: { color: "003366" }
}

// 左侧装饰条
{
  type: "RECTANGLE",
  x: 0, y: 0, w: 0.08, h: 5.625,
  fill: { color: "004B8D" }
}
```

### 标题下分隔线

```javascript
{
  type: "RECTANGLE",
  x: 0.5, y: 1.0, w: 1.5, h: 0.04,
  fill: { color: "003366" }
}
```

### 章节编号圆圈

```javascript
{
  type: "OVAL",
  x: x, y: y, w: 0.5, h: 0.5,
  fill: { color: "003366" }
}
// 白色数字居中
```

## 响应式考虑

### 多列布局

| 列数 | 列宽 | 列间距 |
|------|------|--------|
| 2列 | 4.3" | 0.4" |
| 3列 | 2.8" | 0.3" |
| 4列 | 2.0" | 0.3" |

### 卡片布局

```javascript
// 2x2 卡片网格
const cardWidth = 4.3;
const cardHeight = 1.5;
const gap = 0.4;

// 计算位置
const col = index % 2;
const row = Math.floor(index / 2);
const x = 0.5 + col * (cardWidth + gap);
const y = 1.3 + row * (cardHeight + gap);
```
