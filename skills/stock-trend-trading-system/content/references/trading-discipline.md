```text
┌─────────────────────────────────────────────────────┐
│              交易前检查清单                           │
├─────────────────────────────────────────────────────┤
│                                                     │

│     └─ 趋势验证：基于多周期数据确认                   │
│                                                     │
│  □ 2. 入场信号是否满足条件？                         │
│     └─ 信号验证：≥2个指标共振                        │
│                                                     │

│     └─ 计算验证：精准计算止损价格                     │
│                                                     │
│  □ 4. 仓位是否合规？                                 │
│     └─ 核算验证：账户资金 × 仓位比例                │
│                                                     │
│  □ 5. 盈亏比是否 > 2:1？                             │
│     └─ 计算验证：精准计算盈亏数据                     │
│                                                     │
│  □ 6. 是否在能力圈范围内？                           │
│     └─ 理解验证：熟悉标的业务                       │
│                                                     │
│  □ 7. 数据来源是否可靠？                             │
│     └─ 交叉验证：≥2个数据源                         │
│                                                     │
│  □ 8. 数据时效性是否确认？                            │
│     └─ 日期验证：当日或最近交易日                    │
│                                                     │
└─────────────────────────────────────────────────────┘
```

### 2.2 数据准确性检查

```text
检查项一：价格数据
├─ 当前价格是否为最新交易日？
├─ 涨跌幅计算 = (当前价 - 昨收) / 昨收
└─ 验证示例：昨收29.08，今收28.32
             涨跌幅 = (28.32-29.08)/29.08 = -2.61%

检查项二：均线数据
├─ 均线数值是否合理？
├─ 股价与均线关系判断趋势
└─ 验证示例：50日均线29.16，当前价28.32
             股价 < 均线 → 短期趋势偏弱

检查项三：成交量数据
├─ 成交量是否在合理范围？
├─ 量价配合是否健康？
└─ 单位是否一致（手/股）？

检查项四：指标数据
├─ RSI/ MACD等计算是否正确？
├─ 背离信号是否经过验证？
└─ 数据更新时间是否标注？
```

## 四、止损执行纪律

### 4.1 止损触发规则

```text
必须立即止损的情况：
├─ 买入后下跌 ≥ 5%
├─ 跌破均线支撑（20日/60日）
├─ 触发时间止损（5日不涨）
├─ 出现明显破位信号
└─ 触发移动止损条件

禁止心存侥幸的情况：
├─ "只是回调，还会涨回来"
├─ "再等等看，说不定反弹"
├─ "已经亏了，卖出太亏了"
├─ "基本面没问题"
└─ "和大盘比跌得不多"
```

### 4.2 止损执行检查

```text
止损前确认：
├─ 是否达到止损条件？
├─ 止损价格是否计算精准？
├─ 止损后仓位是否合规？
└─ 是否记录止损原因？

止损后行动：
├─ 是否分析止损原因？
├─ 是否更新选股池？
├─ 是否等待下次机会？
└─ 是否控制情绪继续操作？
```

### 5.2 常见错误警示

```text
错误一：不止损 → 亏损扩大
├─ 教训：小亏不止 → 大亏
├─ 原则：截断亏损，让利润奔跑

错误二：过早止盈 → 利润减少
├─ 教训：怕回调 → 错过大涨
├─ 原则：趋势不破，持仓不动

错误三：逆势抄底 → 接飞刀
├─ 教训：以为到底 → 还在半山腰
├─ 原则：顺势而为，不抄底

错误四：重仓赌一把 → 风险失控
├─ 教训：赌对一次 → 赌错一次亏光
├─ 原则：仓位管理，生存第一

错误五：频繁换股 → 手续费损耗
├─ 教训：操作越多 → 错得越多
├─ 原则：耐心等待，精准出击
```

## 六、心理控制

### 6.1 情绪管理规则

```text
情绪信号识别：
├─ 恐惧信号：恐慌卖出/不敢买入
├─ 贪婪信号：重仓追涨/不止盈
├─ 侥幸信号：不止损/逆势加仓
└─ 从众信号：盲目跟随他人

情绪控制方法：
├─ 制定计划，严格执行
├─ 亏损后暂停操作
├─ 盈利后不要大意
├─ 每日复盘，保持冷静
└─ 仓位控制，降低风险
```

### 6.2 操作心态检查

```text
操作前自问：
├─ 是否冲动作业？
├─ 是否符合系统信号？
├─ 仓位是否合理？
├─ 止损是否明确？
└─ 盈亏比是否合适？

操作后自检：
├─ 是否按计划执行？
├─ 是否有情绪干扰？
├─ 止损是否及时？
├─ 止盈是否合理？
└─ 是否需要改进？
```
