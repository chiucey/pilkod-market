# 技术指标详解

## MA均线系统

### 均线参数设置

| 周期 | 用途 | 信号说明 |
|------|------|----------|
| MA5 | 短期趋势 | 灵敏度高，用于捕捉快速波动 |
| MA20 | 中期趋势 | 反映中期走向，常用于止损参考 |
| MA60 | 长期趋势 | 反映长期走向，过滤短期噪音 |
| MA120 | 半年线 | 用于长线趋势判断 |
| MA250 | 年线 | 牛熊分界线 |

### 均线排列判断

```
多头排列（看涨）：
MA5 > MA20 > MA60 > MA120 > MA250
所有均线向上发散，价格在均线上方

空头排列（看跌）：
MA5 < MA20 < MA60 < MA120 < MA250
所有均线向下发散，价格在均线下方

均线纠缠（震荡）：
各周期均线交织在一起，无明显方向
```

### 均线金叉死叉

```text
金叉（买入信号）：
├─ 短期均线上穿长期均线
├─ 例：MA5上穿MA20
└─ 需配合成交量放大确认

死叉（卖出信号）：
├─ 短期均线下穿长期均线
└─ 需配合成交量放大确认
```

## MACD指标

### 参数设置

- 快速EMA：12
- 慢速EMA：26
- 信号线：9

### 计算公式

```
DIF = EMA(close, 12) - EMA(close, 26)
DEA = EMA(DIF, 9)
MACD = (DIF - DEA) * 2
```

### 信号判断

| DIF与DEA关系 | MACD柱状图 | 市场状态 |
|--------------|------------|----------|
| DIF > 0, DEA > 0 | 红柱（正） | 多头市场 |
| DIF < 0, DEA < 0 | 绿柱（负） | 空头市场 |
| DIF上穿DEA | 红柱放大 | 金叉买入 |
| DIF下穿DEA | 绿柱放大 | 死叉卖出 |
| DIF与价格背离 | 红柱缩短 | 顶背离预警 |
| DIF与价格背离 | 绿柱缩短 | 底背离机会 |

### 零轴意义

```
零轴上方（正值区）：
├─ 多头市场
├─ DIF > 0 表示短期均线在长期均线之上
└─ 金叉更可靠

零轴下方（负值区）：
├─ 空头市场
├─ DIF < 0 表示短期均线在长期均线之下
└─ 反弹多为减仓机会
```

## RSI指标

### 参数设置

- 周期：14（默认）
- 超买线：70
- 超卖线：30

### 信号判断

```text
RSI > 70：超买区域
├─ 上涨动力可能减弱
├─ 警惕回调风险
└─ 短线考虑减仓

RSI < 30：超卖区域
├─ 下跌动力可能减弱
├─ 反弹机会出现
└─ 可观察企稳信号

RSI = 50：多空平衡点
├─ RSI > 50：多头占优
└─ RSI < 50：空头占优
```

### 背离信号

```text
顶背离（看跌信号）：
├─ 价格创新高
├─ RSI未创新高
└─ 预警：上涨动能减弱

底背离（看涨信号）：
├─ 价格创新低
├─ RSI未创新低
└─ 机会：下跌动能减弱
```

## KDJ指标

### 参数设置

- K：默认9
- D：默认3
- J：默认3

### 信号判断

```text
KDJ金叉（买入）：
├─ K线从下向上穿越D线
├─ J线 < 100
└─ 配合超卖区域更可靠

KDJ死叉（卖出）：
├─ K线从上向下穿越D线
├─ J线 > 0
└─ 配合超买区域更可靠

KDJ超买（警惕）：
└─ J线 > 100

KDJ超卖（机会）：
└─ J线 < 0
```

## 布林带（Bollinger Bands）

### 参数设置

- 周期：20
- 标准差倍数：2

### 轨道含义

```text
上轨（压力位）：
├─ MA20 + 2倍标准差
└─ 触及上轨注意回调风险

中轨（趋势线）：
├─ MA20
└─ 上涨趋势中为支撑，下跌趋势中为压力

下轨（支撑位）：
├─ MA20 - 2倍标准差
└─ 触及下轨注意反弹机会
```

### 布林带收口与开口

```text
收口（盘整信号）：
├─ 上轨下轨距离缩小
├─ 行情即将选择方向
└─ 等待突破确认

开口（趋势信号）：
├─ 上轨下轨距离扩大
├─ 趋势加速运行
└─ 沿趋势方向操作
```

## 成交量分析

### 量价关系

```text
放量上涨（健康）：
├─ 价格上涨 + 成交量放大
└─ 趋势确认信号

缩量上涨（警惕）：
├─ 价格上涨 + 成交量萎缩
└─ 可能是反弹尾声

放量下跌（正常）：
├─ 价格下跌 + 成交量放大
└─ 可能是加速赶底

缩量下跌（观望）：
├─ 价格下跌 + 成交量萎缩
└─ 观望等待信号
```

### 量能突破

```
突破放量：
├─ 突破重要价位时成交量放大
├─ 确认突破有效性
└─ 趋势信号加强

突破缩量：
├─ 突破重要价位时成交量萎缩
└─ 警惕假突破
```

## 综合指标应用

### 指标共振

```text
多指标共振买入：
├─ MA多头排列 ✓
├─ MACD零轴上方金叉 ✓
├─ RSI在40-60区间向上 ✓
├─ 成交量放大 ✓
└─ 信号强度：★★★★★

单指标信号：
├─ 仅单一指标出现信号
├─ 信号较弱
└─ 降低仓位操作
```

### 指标背离处理

```text
顶背离应对：
1. 减仓30%-50%
2. 上移止损至成本价
3. 密切观察后续走势
4. 等待确认信号

底背离应对：
1. 不盲目抄底
2. 等待企稳确认
3. 观察量能变化
4. 右侧交易为主
```
