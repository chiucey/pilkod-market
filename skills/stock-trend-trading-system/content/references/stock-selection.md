# 选股标准与分类管理

## 一、趋势股筛选标准

### 1.1 必选条件（全部满足）

```text
┌─────────────────────────────────────────────────────┐
│                  趋势股筛选条件                       │
├─────────────────────────────────────────────────────┤
│  ✓ 均线多头排列（MA5 > MA20 > MA60）                 │
│    └─ 数据验证：需交叉确认均线计算准确性              │
│                                                     │
│  ✓ 近期涨幅超过大盘同期涨幅                         │
│    └─ 数据验证：涨幅计算需精准（当前价-起始价）/起始价│
│                                                     │
│  ✓ 成交量持续放大（量价齐升）                       │
│    └─ 数据验证：核实成交量数据时效性                 │
│                                                     │
│  ✓ 突破重要技术压力位                               │
│    └─ 数据验证：基于最新价格数据确认                 │
│                                                     │
│  ✓ 有明确的主题/概念/业绩驱动                       │
│    └─ 数据验证：数据来源需可靠                       │
│                                                     │
│  ✓ 行业内排名靠前（板块效应）                       │
│    └─ 数据验证：排名数据需实时更新                   │
└─────────────────────────────────────────────────────┘
```

### 1.2 加分条件（满足越多越好）

| 条件 | 说明 | 权重 |
|------|------|------|
| 板块龙头 | 行业涨幅排名靠前 | +20% |
| 机构持仓 | 有明显机构买入迹象 | +15% |
| 业绩增长 | 季报/年报业绩向好 | +15% |
| 政策利好 | 受益于近期政策 | +15% |
| 资金流入 | 主力资金持续净流入 | +20% |
| 技术突破 | 放量突破重要压力 | +15% |

## 二、标的分类管理

### 2.1 四类标的定义

```text
┌─────────────────────────────────────────────────────┐
│                   标的分类矩阵                         │
├─────────────────────────────────────────────────────┤
│                                                     │
│  【强势股】                                          │
│  定义：均线多头排列，今日涨幅 > 3%                   │
│  操作：优先买入，回调买入                            │
│  仓位：可重仓                                        │
│  止损：买入价 - 5%                                  │
│                                                     │
│  【稳健股】                                          │
│  定义：震荡上行，趋势完好                           │
│  操作：逢低买入，持有为主                           │
│  仓位：中等仓位                                      │
│  止损：20日均线                                      │
│                                                     │
│  【弱势股】                                          │
│  定义：均线空头排列                                 │
│  操作：观望或做空                                   │
│  仓位：0%                                           │
│  止损：N/A                                          │
│                                                     │
│  【突破股】                                          │
│  定义：刚突破重要压力位                             │
│  操作：追涨买入，严格止损                           │
│  仓位：轻仓试探                                      │
│  止损：突破平台最低点 - 3%                         │
│                                                     │
└─────────────────────────────────────────────────────┘
```

### 2.2 标的转换规则

```text
强势股 → 稳健股：
├─ 触发条件：连续3日涨幅收窄
├─ 操作：不再加仓，持有观察
└─ 止损：上移至成本价

强势股 → 弱势股：
├─ 触发条件：跌破20日均线
├─ 操作：清仓
└─ 止损：立即执行

突破股 → 强势股：
├─ 触发条件：回踩确认后放量上涨
├─ 操作：加仓
└─ 止损：上移至突破位

稳健股 → 弱势股：
├─ 触发条件：跌破60日均线
├─ 操作：清仓
└─ 止损：立即执行
```

## 三、选股流程

### 3.1 海选流程

```text
Step 1：初步筛选
├─ 条件1：MA5 > MA20 > MA60（均线多头）
├─ 条件2：近10日涨幅 > 5%
├─ 条件3：成交量 > 5日均量1.5倍
└─ 输出：候选股票池

Step 2：精细筛选
├─ 检查1：趋势是否健康（无顶背离）
├─ 检查2：板块是否强势
├─ 检查3：消息面是否有驱动
└─ 输出：重点关注列表

Step 3：精选操作对象
├─ 分析1：是否突破重要压力
├─ 分析2：量价配合是否理想
├─ 分析3：止损空间是否合理
└─ 输出：买入候选名单
```

## 四、行业板块筛选

### 4.1 强势板块特征

```text
强势板块判断标准：
├─ 板块指数涨幅 > 大盘涨幅
├─ 板块内涨停股数量 ≥ 3只
├─ 板块成交量明显放大
├─ 有明确的主题或消息催化
└─ 龙头股走势强劲
```

### 4.2 板块内选股优先级

```text
第一梯队（首选）：
├─ 板块龙头
├─ 涨幅 > 5%
└─ 放量涨停

第二梯队（次选）：
├─ 板块涨幅排名2-5名
├─ 趋势健康
└─ 量价配合良好

第三梯队（观察）：
├─ 板块内补涨股
├─ 风险较高
└─ 轻仓操作
```

## 五、风险股票排除

### 5.1 禁止买入信号

```text
🚫 均线空头排列不抄底
   └─ MA5 < MA20 < MA60

🚫 高位放量大阴线不接盘
   └─ 涨幅 > 5% + 成交量 > 均量2倍 + 大阴线

🚫 顶背离不追涨
   └─ 价格创新高 + 指标未新高

🚫 暴雷股票不参与
   └─ 业绩亏损/诉讼/监管风险

🚫 冷门股不冒险
   └─ 成交额 < 5000万/日
```

### 5.2 谨慎操作信号

```text
⚠️ 高位横盘：警惕变盘风险
⚠️ 量价背离：上涨动能可能衰竭
⚠️ 均线粘合：即将选择方向
⚠️ 密集套牢区：需要放量突破
⚠️ 消息真空期：缺乏催化剂
```
