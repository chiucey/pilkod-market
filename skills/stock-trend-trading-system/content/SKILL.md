# 股票趋势交易操作系统

## 核心原则

| 原则 | 说明 |
|------|------|
| 顺势而为 | 永远顺着趋势方向交易，上涨趋势做多，下跌趋势做空/观望 |
| 截断亏损 | 每笔交易先想止损，亏损不超过总资金2% |
| 让利润奔跑 | 趋势不破，持仓不动，移动止损保护利润 |
| 纪律大于预测 | 系统信号优于主观判断，严格执行交易计划 |
| 数据精准 | 所有判断基于验证后的精准数据，禁止模糊表述 |

## 一、趋势识别

### 1.1 趋势三要素

| 趋势类型 | 波峰特征 | 波谷特征 | K线特征 |
|----------|----------|----------|----------|
| 上升趋势 | 逐步抬高 | 逐步抬高 | 高点创新高，低点上移 |
| 下降趋势 | 逐步降低 | 逐步降低 | 低点创新低，高点下移 |
| 横盘震荡 | 基本持平 | 基本持平 | 高点低点交替，无方向 |

### 1.2 多周期共振

```text
┌─────────────────────────────────────────────────────┐
│              趋势共振判断与信号强度                   │
├──────────┬──────────┬──────────┬────────────────────┤
│   日线   │   周线   │   月线   │      操作信号       │
├──────────┼──────────┼──────────┼────────────────────┤
│   上涨   │   上涨   │   上涨   │ ★★★ 强烈做多      │
│   上涨   │   上涨   │   下跌   │ ★★  观望/轻仓     │
│   上涨   │   下跌   │   上涨   │ ★   谨慎操作       │
│   下跌   │   上涨   │   上涨   │ ★   反弹机会       │
│   下跌   │   下跌   │   下跌   │ ★★★ 强烈做空/清仓  │
│   震荡   │   震荡   │   震荡   │ ○   不操作         │
└──────────┴──────────┴──────────┴────────────────────┘
```

### 1.3 技术指标速查

| 指标 | 参数 | 看涨信号 | 看跌信号 |
|------|------|----------|----------|
| MA均线 | 5/20/60日 | 多头排列(5>20>60) | 空头排列(5<20<60) |
| MACD | 12/26/9 | 零轴上方金叉+红柱 | 零轴下方死叉+绿柱 |
| RSI | 14日 | 突破50且<70 | 跌破50且>30 |
| KDJ | 默认 | 金叉 | 死叉 |
| 成交量 | - | 放量上涨 | 缩量上涨/放量下跌 |
| 布林带 | 20日/2倍 | 触及下轨反弹 | 触及上轨回调 |

## 二、入场信号系统

### 2.1 买入信号等级

| 等级 | 触发条件 | 仓位建议 | 数据验证 |
|------|----------|----------|----------|
| ★★★★★ 强烈买入 | 多周期共振 + 放量突破 + 趋势确认 | 40% | ≥2个数据源验证 |
| ★★★★☆ 积极买入 | 日线向上 + 回踩均线支撑 | 30% | 均线数据实时验证 |
| ★★★☆☆ 谨慎买入 | 单周期信号，量能不足 | 20% | 成交量数据核实 |
| ★★☆☆☆ 观望 | 技术背离或横盘 | 0% | 多源数据交叉验证 |

### 2.2 三种经典入场形态

#### 形态一：均线回踩买入

```
条件：上升趋势中，价格回踩20日均线获得支撑
入场：收盘价站稳20日均线上方
止损：跌破20日均线3%
目标：前高或移动止损跟踪
```

#### 形态二：平台突破买入

```
条件：横盘整理后放量突破前期高点
入场：突破后回踩确认时买入
止损：跌破平台最高价5%
目标：突破幅度1:1或移动止损
```

#### 形态三：MACD零轴金叉

```
条件：MACD在零轴上方形成金叉，成交量放大
入场：金叉形成次日开盘价买入
止损：金叉前低点下方3%
目标：MACD背离或移动止损
```

## 三、仓位管理

### 3.1 金字塔仓位法

```text
┌─────────────────────────────────────────────┐
│              金字塔仓位管理                   │
├─────────────────────────────────────────────┤
│  首仓：20%  (趋势确认后首次建仓)              │
│  二仓：15%  (回踩确认后加仓)                  │
│  三仓：10%  (突破确认后最后一次加仓)          │
│  预留：5%   (应对突发情况)                    │
│  ─────────────────────────────────────      │
│  总仓位上限：50%                             │
└─────────────────────────────────────────────┘
```

### 3.2 市场状态与仓位

| 市场状态 | 仓位比例 | 操作策略 |
|----------|----------|----------|
| 强势上涨 | 40%-50% | 重仓持有 |
| 震荡上行 | 30%-40% | 轻仓试探 |
| 横盘整理 | 10%-20% | 轻仓观望 |
| 趋势下跌 | 0%-10% | 清仓/空仓 |

## 四、止损止盈

### 4.1 三层止损机制

```text
┌─────────────────────────────────────────────┐
│               三层止损机制                    │
├─────────────────────────────────────────────┤
│                                             │
│  第一层：价格止损                             │
│  ├─ 单笔亏损 ≤ 总资金2%                       │
│  ├─ 买入后下跌5%-8%必须止损                   │
│  └─ 跌破均线/趋势线必须止损                   │
│                                             │
│  第二层：时间止损                             │
│  ├─ 买入后5个交易日不涨 → 弱势股              │
│  └─ 考虑换股或止损                           │
│                                             │
│  第三层：移动止损                             │
│  ├─ 盈利10% → 止损移至成本价                  │
│  ├─ 盈利20% → 止损移至盈利10%处               │
│  └─ 保护已有利润                             │
└─────────────────────────────────────────────┘
```

### 4.2 止盈策略

| 盈利幅度 | 止盈操作 | 止损设置 |
|----------|----------|----------|
| 10%-15% | 减仓30% | 移动止损至成本价 |
| 15%-25% | 减仓50% | 止损上移至盈利10% |
| 25%+ | 持有为主 | 移动止损跟踪趋势 |

### 4.3 风险红线

```
🚫 绝不抄底：下降趋势中不接飞刀
🚫 绝不重仓：单只股票仓位 ≤ 20%
🚫 绝不扛单：严格遵守止损纪律
🚫 绝不频繁：等待明确信号
🚫 绝不满仓：保留 ≥30% 资金
```

## 五、出场信号

### 5.1 趋势反转预警

```
⚠️ 价格创新高但MACD/RSI未创新高（顶背离）
⚠️ 成交量萎缩但价格继续上涨（量价背离）
⚠️ 连续3日无法突破前高（动能减弱）
⚠️ 跌破上升趋势线（趋势破坏）
⚠️ 均线开始走平或收口（趋势减弱）
⚠️ 出现大阴线破位（警惕信号）
```

### 5.2 出场操作流程

```text
下跌趋势确认 → 减仓30% → 确认破位再减30% → 关键位破位清仓
```

```text
│  ├─ 必须标注：数据来源                              │
```

### 6.2 数据源优先级

| 优先级 | 数据源 | 用途 | 可靠性 |
|--------|--------|------|--------|
| 1 | stocks_price API | K线数据 | ⭐⭐⭐⭐⭐ |
| 2 | stocks_info API | 基本面数据 | ⭐⭐⭐⭐⭐ |

### 6.3 禁止行为

```
🚫 禁止：直接使用搜索结果中的股价片段

🚫 禁止：单数据源完成关键数据引用
```
