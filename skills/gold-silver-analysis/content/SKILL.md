# 黄金与白银走势分析

## 核心分析框架

剑锋无尘的分析方法：**数据驱动 + 主力行为分析 + 期权市场情绪**。

### 三大分析维度

1. **CFTC 持仓数据（最核心）**
   - 对冲基金多头/空头持仓变化
   - 主力空头占比是否超过 50%
   - 白银期货端多头变化（期权数据量太少，主要看期货）

2. **期权市场情绪**
   - 押注价格跌破关键位置的仓位分布
   - 关键支撑位：期权市场几乎无人押注跌破的位置 = 硬底
   - 波动率曲面：隐含波动率异常区域 = 主力埋伏地

3. **技术面 + 宏观面共振**
   - 战争/地缘政治 → 流动性恐慌 → 黄金波动
   - 美联储加息/降息预期 → 实际利率 → 黄金定价
   - 央行购金行为 → 实物支撑

## 关键价位识别

### 剑锋无尘典型分析案例（2025-2026年数据，仅供框架学习）

| 场景 | 价位逻辑 |
|------|----------|
| 底部区间 | 4000-4500，4000 是硬底（期权市场无人押注跌破） |
| 洗盘识别 | 从高位5595跌到4097，幅度大但无量 = 主力洗盘非出货 |
| 加仓区间 | 回到4300-4400区间 = 非常好的加仓机会 |
| 反弹震荡 | 4600美元附近 = 大量承接盘，进入震荡 |
| 目标位 | 机构建仓完成后的目标窗口：5500+ |
| 白银关键位 | 70美元 = 重要心理关口 |

### 判断顶底的信号

**底部信号：**
- 跌幅大但成交量未放大 → 主力洗盘，非出货
- 关键支撑位期权几乎无空头押注 → 硬底
- 对冲基金多头被洗出（黄金暴跌时多头减少）同时白银多头反而增加 → 资金轮动，白银先见底

**顶部信号：**
- 主力空头占比超50%压住价格 + 战争流动性恐慌 → 短期顶部
- 所有人都在喊多 → 小心阶段性顶部

---

## 白银分析特殊性

- **主战场在期货端，不在期权端**（期权数据量太少，信号失真）
- 白银波动比黄金更大，用于领先判断黄金走势
- 关注白银/黄金比价（GP ratio）：金银比极端值往往预示反转

---

## 分析流程

1. 搜索最新 CFTC 持仓数据（每周发布）
2. 查看期权市场持仓分布（特别是关键价位的押注）
3. 结合宏观事件（美联储政策、地缘政治）
4. 判断当前属于哪种场景：洗盘 / 趋势 / 震荡 / 见顶/底
5. 给出支撑位、压力位、关键操作区间
