# 黄金白银分析：关键指标速查

## 一、核心数据来源

### 1. CFTC 持仓数据（COT 报告）
- **发布频率：** 每周二
- **直达链接：** https://www.cftc.gov/dea/newcot/f.txt
- **重点品种：** GC（COMEX黄金）、SI（COMEX白银）
- **最关键字段：** Managed Money（对冲基金）多头/空头持仓变化
- **净多头变化方向** = 判断主力动向的核心信号

### 2. 期权市场数据
- CME Group官网 + https://www.barchart.com/
- 重点看：执行价OI分布、波动率曲面、Risk Reversal指标
- **黄金4000美元硬底判断：** 期权市场几乎无人押注跌破此处

### 3. 宏观联动指标
- **实际利率（10年期TIPS收益率）：** 黄金的反面
- **美联储利率预期：** FOMC会议 + 点阵图
- **美国CPI：** 每月12-13日发布
- **非农就业：** 每月第一个周五发布

### 4. 黄金ETF持仓（SPDR Gold Trust — GLD）
- 持仓量增加 = 机构看多；减少 = 机构减仓
- 数据：https://www.spdrgoldshares.com/

### 5. 全球央行购金
- 世界黄金协会（WGC）：https://www.gold.org/
- WGC《全球黄金需求趋势报告》（季度）
- 央行购金是只买不卖的结构性支撑

### 6. 金银比（Gold/Silver Ratio）
- 公式：黄金价格 ÷ 白银价格，历史均值60-70
- 金银比 > 80：白银严重低估，可能即将补涨
- 金银比 < 50：白银相对高估，可能回调
- 数据：https://www.macrotrends.net/13375/historical-gold-silver-ratio-100-year-chart

## 四、分析检查清单（每次分析黄金必查）

1. [ ] CFTC：对冲基金净多头变化方向？
2. [ ] CFTC：白银期货多头是否减少？（白银是领先指标）
3. [ ] 期权市场：关键支撑位是否无人押注（找硬底）？
4. [ ] 宏观：美联储利率预期 + 实际利率方向？
5. [ ] 地缘：是否有流动性危机类事件（危机初期黄金可能下跌）？
6. [ ] 资金流：黄金ETF持仓增减？
7. [ ] 央行：各国央行购金动态？
8. [ ] 市场情绪：大多数人是看多还是看空（反向信号）？
