# Contract Intelligence Processor

## 核心能力

智能处理商业合同，自动完成：关键信息提取、中英互译、敏感信息脱敏、风险点识别。

## 适用场景

| 场景 | 说明 |
|------|------|
| **合同审阅** | 快速提取合同关键条款，无需逐字阅读全文 |
| **跨语言处理** | 中英文合同互译，保持格式和术语准确 |
| **敏感信息保护** | 自动识别并脱敏客户数据、商业机密 |
| **合同对比** | 多版本合同差异分析 |
| **风险识别** | 自动标记高风险条款 |

## 信息提取模板

### 关键条款提取

| 条款类型 | 提取内容 |
|---------|---------|
| **付款条款** | 付款方式、付款周期、付款条件、违约金 |
| **交付条款** | 交付时间、交付地点、验收标准 |
| **保密条款** | 保密范围、保密期限、违约责任 |
| **终止条款** | 终止条件、提前通知期、违约金 |
| **责任条款** | 责任范围、赔偿上限、免责情形 |
| **争议条款** | 争议解决方式、适用法律、仲裁条款 |

## 翻译策略

### 中译英原则

| 类型 | 处理方式 |
|------|---------|
| **法律术语** | 使用标准法律英文（如：不可抗力→Force Majeure） |
| **公司名称** | 保持原文，可附英文译名 |
| **金额** | 中文金额后附阿拉伯数字 |
| **日期** | 统一为YYYY-MM-DD格式 |

### 英译中原则

| 类型 | 处理方式 |
|------|---------|
| **法律术语** | 使用中国法律体系对应术语 |
| **金额** | 阿拉伯数字后附中文大写 |
| **条款编号** | 保持原编号或重新编号 |

### 翻译输出格式

```
【原文】
[原始句子]

【译文】
[翻译后句子]

【术语对照】
- 术语1 → Term1
- 术语2 → Term2
```

## 敏感信息脱敏

### 脱敏规则

| 信息类型 | 脱敏方式 | 示例 |
|---------|---------|------|
| **姓名** | 姓氏保留+星号 | 张三 → 张* |
| **身份证号** | 只保留前6后4 | 110101199001011234 → 110101********1234 |
| **手机号** | 只保留前3后4 | 13812345678 → 138****5678 |
| **银行卡号** | 只保留前4后4 | 6222021234567890123 → 6222**********0123 |
| **公司名称** | 改为"客户公司A/B" | 阿里巴巴 → 客户公司A |
| **地址** | 模糊化处理 | XX市XX区XX路XX号 → XX市XX区XX路 |
| **邮箱** | @前保留前2后1 | user@example.com → us****@e****.com |
| **金额** | 相对值或区间 | 具体金额 → 约占合同总额X% |

### 脱敏输出格式

```
【原始信息】
[包含敏感信息的原文]

【脱敏后信息】
[处理后的安全版本]

【脱敏标记】
⚠️ 已脱敏字段：姓名、手机号、公司名称
```

## 执行流程

### 1. 接收输入

- 用户上传合同文件（PDF、图片、Word）或粘贴文本
- 确认处理需求：仅提取 / 仅翻译 / 仅脱敏 / 全部

### 2. 预处理

- 识别语言（中/英/混合）
- 识别合同类型（采购/销售/服务/租赁/劳动等）
- 定位关键章节

### 3. 执行处理

根据用户选择的处理方式执行：
- **信息提取**：按模板提取关键字段
- **翻译**：保持法律术语准确性
- **脱敏**：按规则处理敏感信息

### 4. 输出结果

提供结构化输出：
- 关键信息摘要表
- 完整翻译（如需要）
- 脱敏版本（如需要）
- 风险提示（如需要）

## 示例场景

### 场景1：英文合同关键信息提取

**输入**：上传一份英文采购合同PDF

**输出**：

```
【合同基本信息】
合同名称：原材料采购合同
合同编号：PO-2024-0892
签约日期：2024-03-15
合同期限：2024-04-01 至 2025-03-31

【签约方】
甲方（供应商）：Global Materials Inc.
乙方（采购方）：[客户公司]

【合同金额】
总金额：USD 1,250,000.00（壹佰贰拾伍万美元整）
付款方式：T/T 30%预付，70%见提单复印件

【关键条款】
✓ 交付期限：2024-05-01前
✓ 质量标准：符合ASTM A36
✓ 争议解决：ICC仲裁，伦敦
✓ 适用法律：联合国国际货物销售公约(CISG)

【⚠️ 风险提示】
1. 仲裁条款使用ICC而非中国贸仲，可能增加维权成本
2. 建议增加质量保证期条款
```

### 场景2：合同中英翻译 + 脱敏

**输入**：
> "甲方为ABC科技有限公司，乙方为XYZ Corporation。双方约定，乙方应在2024年6月1日前向甲方交付总价为人民币500万元的货物。"

**输出**：

```
【翻译】
Party A (the "Buyer"): ABC Technology Co., Ltd.
Party B (the "Seller"): XYZ Corporation

The Parties agree that Party B shall deliver goods with a total value of CNY 5,000,000 to Party A on or before June 1, 2024.

【脱敏处理】
Party A (the "Buyer"): 客户公司A
Party B (the "Seller"): 客户公司B

The Parties agree that Party B shall deliver goods with a total value of approximately 5 million yuan (representing ~15% of total contract value) to Party A on or before June 1, 2024.

【脱敏标记】
⚠️ 已脱敏字段：公司名称（改为客户公司A/B）、金额（改为相对值）
```

## 注意事项

1. **准确性优先**：法律文本翻译必须准确，不确定时标注"建议法务确认"
2. **保持格式**：保持原文的条款编号、层级结构
3. **风险提示**：不遗漏任何异常条款
4. **双重验证**：重要信息建议用户人工复核
5. **隐私保护**：所有处理在脱敏环境下进行，不保留原始敏感数据

## 局限性说明

⚠️ 本技能存在以下局限，请知悉：

- 对于扫描件或模糊图片，识别准确率可能下降
- 极度专业化的法律术语可能需要人工确认
- 表格类信息的提取可能需要额外处理
- 建议对高价值合同（金额>100万）进行人工复核
