# 用户示例文档 - 【暖星谷】后台管理

## 文档说明
本文档是用户实际工作中的游戏策划文档，用于理解用户的写作习惯、术语使用、文档组织方式和表达风格。在润色过程中应参考本文档的风格特征，保持与用户习惯的一致性。

## 文档特征分析

### 1. 文档结构特点
- **版本记录**：文档开头包含明确的版本记录表格
  - 格式：版本号 | 修改内容 | 修改人 | 修改日期
- **明确范围界定**：在文档开头说明本文档包含和排除的内容范围
- **层级清晰**：使用数字编号（1.、1.1、1.1.1）进行章节划分

### 2. 写作风格特点
- **功能描述方式**：先总述"功能描述"，再详细展开"交互逻辑"或"功能逻辑"
- **列表化表达**：大量使用项目符号（◦、▪、•）组织内容
- **表格使用**：频繁使用表格展示状态定义、映射关系、规则等
- **图标引用**：使用表情符号或图标增强视觉识别（如 /、🎨等）

### 3. 术语和表达习惯
- **角色称谓**：使用"硬件"、"星之子"、"玩偶"等特定称谓
- **状态表达**：清晰定义状态类型、状态值、图标样式
- **交互描述**：使用"点击后"、"触发时"、"当...时"等交互触发词
- **流程说明**：对复杂逻辑使用编号步骤（i、ii、iii、iv、v）

### 4. 细节描述方式
- **颜色规则**：明确定义不同状态或类型的颜色映射（如电量 >= 65%: 绿色）
- **优先级定义**：明确列出规则的优先级顺序
- **异常处理**：单独列出异常情况的处理逻辑
- **示例说明**：通过具体示例说明抽象规则

### 5. 开发导向特征
- **数据定义**：明确数据格式、长度限制、口吻要求
- **技术细节**：包含计时器逻辑、触发条件、结束判断等技术细节
- **流程图引用**：在适当位置引用流程图辅助说明
- **截图说明**：使用界面截图说明UI布局和交互

## 典型内容示例

### 功能描述模板示例
```
1. 功能描述:展示和管理用户绑定的硬件设备列表
◦ 交互逻辑:
  ▪ 默认显示当前选定的硬件昵称
  ▪ 点击昵称区域弹出角色下拉列表
  ▪ 列表末尾行为｢添加星之子｣
```

### 状态定义表格示例
```
状态类型 | 状态值 | 图标样式
在线状态 | 在线 | /
离线状态 | 离线 | /
电量显示 | 0~100% | 电量图标(颜色+百分比)
```

### 规则定义示例
```
动画优先级:离线 > 充电中 > 聊天中 > 在线
```

### 异常处理示例
```
◦ 异常处理:
  ▪ 若7日内无任何聊天对话,则跳过该次报告,不进行生成
  ▪ 跳过后的下一周期重新累计7日
```

### 示例说明示例
```
示例:
  ▪ 4.1~4.7:有聊天,生成报告
  ▪ 4.8~4.14:无聊天,跳过生成,无报告
  ▪ 4.15~4.21:有聊天,生成报告
```

## 总结
本文档展示了以下关键特征：
1. **结构严谨**：清晰的章节划分和内容组织
2. **列表化**：大量使用列表和表格提升可读性
3. **细节充分**：对功能、状态、规则有详细的定义
4. **开发友好**：提供明确的技术实现细节和异常处理
5. **示例丰富**：通过具体示例辅助理解抽象规则
