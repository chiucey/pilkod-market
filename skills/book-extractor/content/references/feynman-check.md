# 费曼检验设计指南

## 概览
费曼检验通过情境模拟题验证用户对知识的理解深度，确保"会用"而非只是"知道"。

## 核心原则

### 1. 实践导向
- 题目必须是实际应用场景
- 避免纯理论问答
- 要求用户给出具体解决方案

### 2. 深度验证
- 检验概念理解（是什么）
- 检验应用能力（怎么用）
- 检验迁移能力（在哪用）

### 3. 情境设计
- 设计真实的工作/生活场景
- 包含具体约束条件
- 有明确的评价标准

## 题目类型

### 类型 A：应用题
**特点**：给定场景，要求应用所学概念解决问题

**示例**：
```
情境：你是一名产品经理，负责的新项目上线 3 个月，
用户增长缓慢。你想起《复利效应》中提到的"微小优势
持续积累"原理。

问题：请设计一个基于复利效应的用户增长策略，
包括：
1. 识别可以积累的"微小优势"
2. 制定 6 个月的执行计划
3. 设定关键里程碑和检查点
```

### 类型 B：迁移题
**特点**：要求将概念应用到不同领域

**示例**：
```
情境：你学习了《深度工作》中的"注意力残留"概念，
这个概念原本用于提升个人工作效率。

问题：如果你是团队负责人，如何将"注意力残留"
原理应用到团队管理中？请设计一个减少团队
注意力分散的管理方案。
```

### 类型 C：分析题
**特点**：分析给定案例，识别其中的概念应用

**示例**：
```
情境：某公司通过优化客服响应时间从 24 小时缩短到
2 小时，客户满意度从 70% 提升到 95%，复购率提升 30%。

问题：
1. 这个案例体现了什么核心概念？
2. 分析为什么"响应时间"这个微小改进能产生如此
   大的影响？
3. 如果你要复制这个成功，关键成功因素是什么？
```

## 评分标准

### 优秀（90-100分）
- 准确理解核心概念
- 能够灵活应用到新场景
- 方案具有可操作性
- 考虑了边界条件和限制

### 良好（70-89分）
- 基本理解核心概念
- 能够应用到类似场景
- 方案基本可行
- 部分考虑边界条件

### 待提升（70分以下）
- 概念理解有偏差
- 应用场景不匹配
- 方案缺乏可操作性
- 未考虑边界条件

## 设计检查清单

- [ ] 题目基于真实场景
- [ ] 要求给出具体方案而非泛泛而谈
- [ ] 包含明确的评价标准
- [ ] 难度适中，有挑战性但可完成
- [ ] 能够区分理解深度
