## 适用范围与不变框架

本文件适用于香港交易所上市的普通股、H股、红筹股、其他境外注册公司、ETF和REIT。权证、牛熊证、界内证、SPAC证券、债券及其他结构化产品具有不同杠杆、做市、到期和估值规则；用户未明确要求并提供必要数据时，不套用普通股计划。

港股与美股保持相同的核心交付：

1. 分离当前报价、最近完整K线、盘口和基本面时点。
2. 生成K线+MA、VOL+MAVOL、MACD核心图。
3. 使用趋势、资金与量价、基本面、估值、催化与预期五维评分。
4. 给出最多两个互斥方案、加权成本、统一失效位、第一合理目标、净盈亏比、时间止损、仓位和最大损失。
5. 分开管理交易仓与长期投资仓；数据或门槛失败时明确写“等待”。

差异只进入市场身份、数据源、交易制度、计算输入和风险项，不修改技术指标公式或五维权重。

## 标的身份与任务卡

### 代码与证券身份

- 在报告中保留HKEX原生五位零填充代码，例如 `00700`；同时记录数据商别名，例如 `0700.HK`，但不得把别名当作另一证券。
- 同时核对公司全名、股份类别、主板/GEM、上市地、注册地、主要经营地和证券类型。
- 识别H股、红筹、同股不同权标记、第二上市/双重主要上市、ETF、REIT和多柜台证券；这些标签必须来自当前交易所或发行人资料。
- 多柜台证券必须指定实际交易柜台、柜台代码和交易币种。不同柜台的价格、成交量和盘口分开分析，不拼接K线，不把一个柜台的深度用于另一个柜台执行。
- A/H两地上市公司可比较A/H估值或溢价，但先统一每股权利、股数口径、币种和汇率；A股价格不是H股技术支撑或盘口证据。

### 港股任务卡增量字段

在通用任务卡“标的”或独立市场规则表中记录：

| 字段 | 要求 | 缺失影响 |
|---|---|---|
| 市场与原生代码 | HKEX、五位代码、数据商别名 | 无法唯一匹配时先确认 |
| 证券/公司类别 | 普通股、H股、ETF、REIT等；主板/GEM | 影响来源、估值和风险 |
| 交易柜台与币种 | 柜台代码、HKD/CNY/USD或其他实际币种 | 不得计算精确盈亏或下单价 |
| 报告币种 | 财务报表使用币种 | 估值必须另做汇率换算 |
| 每手股数 | 当前有效board lot及生效日 | 不给精确整手股数 |
| 碎股状态 | 无、已有碎股、计划碎股处置 | 必须单列执行和流动性风险 |
| 账户币种与汇率 | 账户币种、交易币种、汇率方向/时间/来源 | 不给账户风险金额 |
| 交易路径 | 香港本地账户、南向港股通或其他 | 影响可交易标的、日历、费用和币种 |
| 卖空路径 | 是否允许、券源、费用、当前指定证券资格 | 未核验不得给精确做空计划 |

用户只要一般研究时，不因缺少账户币种或每手股数而中断；但不得输出伪精确整手数量或跨币种最大损失。

## 来源优先级

### 第一层：官方与法定来源

- HKEX证券资料、交易日历、交易时段、价位表、每手股数、公司行动、VCM及指定卖空证券清单。
- HKEXnews：业绩公告、年报/中报、盈利预警、须予公布交易、关连交易、配股/供股、回购、停复牌和股权披露。
- 公司Investor Relations：演示材料、电话会、经营数据和资本配置公告；与HKEX法定披露冲突时先核对期间和版本。
- 香港证监会、金管局及其他实际主管机关：监管、牌照、银行资本和市场规则。
- PRC发行人的中国证监会、交易所或公司法定披露只作相应事实来源；须与港股股份口径对齐。

### 第二层：行情与标准化数据

- 当前报价优先使用带时间戳、柜台代码、币种和延迟状态的HKEX授权行情、券商或专业数据商。
- OHLCV必须标明代码别名、柜台币种、复权方式和成交量单位。
- 一致预期、历史估值和同业数据可来自专业数据商，但要记录统计日期、分析师数、预测期间、报告币种和每股口径。

### 第三层：二手来源

权威财经媒体用于解释市场反应与背景。盈利预警、配股、监管、停牌、每手股数变更和业绩数字必须尽量回到HKEXnews、发行人或监管原文。

搜索摘要、无时间截图和论坛信息不能支撑精确数字或执行结论。

## 四类独立快照

港股完整分析保存：

| 快照 | 必填内容 |
|---|---|
| 当前报价 | 原生代码/柜台、价格、币种、时间、Asia/Hong_Kong、交易阶段、延迟与来源 |
| 最近完整K线 | 交易日、OHLCV、成交量单位、复权口径、柜台与来源 |
| 盘口 | 时间、连续盘/竞价、Level 1/2、`exchange_book`/聚合/未知、单位、每手股数、延迟与来源 |
| 市场规则 | 每手股数、适用价位、交易日/半日市、交易阶段、成本、结算/交易路径、公司行动和规则有效日 |

报价、K线、盘口和规则快照可以有不同时间，但不得拼成同一个“当前指标”。规则有变更公告时，以实际生效日决定使用旧规则或新规则。

## 交易时段与市场状态

- 使用 `Asia/Hong_Kong`；香港不使用美式夏令时。报告可同时换算用户时区。
- 每次从HKEX当前交易日历核验正常交易日、半日市、公众假期和特殊安排。不要仅凭星期判断“今天开市”。
- 2024年后恶劣天气交易安排已经变化；不得根据旧经验自动写“台风停市”，应核验当日HKEX状态。
- 正常全日的基线阶段包括开市前竞价、上午连续交易、延续早市、下午连续交易及收市竞价；半日市不同。具体时刻和证券适用范围每次以HKEX当前页面为准。

脚本使用以下规范状态：

| 港股阶段 | `market_state` | 连续盘口可用于当前执行 |
|---|---|---|
| 开市前竞价 | `pre_opening` | 否；普通买一卖一算法不适用 |
| 上午连续交易 | `morning` | 是，其他门槛仍须通过 |
| 延续早市 | `extended_morning` | 仅适用于实际可交易证券并核验 |
| 午间非交易/休市 | `midday_break` | 否 |
| 下午连续交易 | `afternoon` | 是，其他门槛仍须通过 |
| 收市竞价 | `closing_auction` | 否；需要竞价专用IEP/IEV口径 |
| 收市/停牌 | `closed` / `halted` | 否 |

开市前及收市竞价若只有参考价、参考平衡价格或不平衡量，必须按竞价字段解释，不得塞入连续盘Level 1计算，也不得称作“当前买一卖一确认”。

## OHLCV、公司行动与技术图

- 日线分析仍至少获取252个完整交易日；默认图显示最近120个完整日线。
- 价格与成交量必须来自同一柜台、同一交易币种。双柜台之间即使代表同一权益，也不得合并成交量或用另一柜台补缺。
- 先核验拆细、合股、红股、供股、配售、特别股息、除权除息、代码/简称和每手股数变更。明显跳变先查公司行动，不直接解释为突破或崩跌。
- OHLC四列使用同一复权口径。若提供商只调整收盘价，不能绘制复权K线或计算ATR/缺口。
- 成交量单位必须规范为股数。来源若使用手、千股或其他单位，保存原单位和换算因子；MAVOL、OBV、相对量统一使用股数。
- 图表必须传入实际币种，例如 `--currency HKD`，并显式选择 `--color-convention us`或`cn`；标题同时显示原生代码与数据商代码有助于复核。
- 基准按业务和上市类型选择恒生指数、恒生国企指数、恒生科技指数、行业指数或可交易ETF；先说明选择原因，不机械固定一个指数。

## 买卖盘与HKEX订单簿

- 港股不使用美式NBBO术语。HKEX OMD-C可提供Level 1、最多十档Level 2或更完整订单信息；实际层级取决于数据许可。
- HKEX中央订单簿快照标为 `quote_scope=exchange_book`。第三方聚合但范围明确可标 `aggregated`；只见单一券商界面且范围不明标 `unknown`，不能自称全市场。
- `size_unit=shares`时直接计算；`size_unit=round_lots`时必须传入该证券当前 `round_lot_size`，不得默认100股。
- 显示挂单、经纪队列和主动成交仍可能受撤单、隐藏流动性、内部化、场外交易与延迟影响，不推断“庄家/主力身份”。
- 竞价阶段不运行普通连续盘微价格、价差与盘口不平衡结论；若无竞价专用可靠数据，写“竞价盘口未取得”。
- 先检查证券是否属于当前VCM范围及是否处于冷静期。VCM是动态波动控制/冷静期，不是所有港股统一的全日涨跌停。
- 做空前核验当前指定卖空证券清单、价格规则、券源、借券费和账户资格；任一项未知时不给可执行做空计划。

## 每手股数、价位、成本与跨币种仓位

### 每手股数与碎股

- 港股没有统一每手股数。每次从当前证券资料或生效公告取得board lot；变更前后按交易日使用正确值。
- 新建整手计划的股数必须为board lot的整数倍。用户已有碎股时，持仓盈亏按实际股数计算，但卖出路径、报价和成交风险单列。
- `position_size.py --lot-step`传入当前board lot。若风险预算连一手都不足，脚本以 `status=wait_below_minimum_lot`、`quantity=0` 输出“0手/等待”，不要突破风险上限凑一手。

### 有效价位

- 订单价格必须符合分析日有效的HKEX价位表。价位表会调整，且适用证券类型和价格区间可能不同；不得在Skill中永久硬编码。
- 2026年8月3日已发生第二阶段最小价差调整，因此旧表或旧券商截图不可直接复用。每次记录价位表版本/有效日与来源。
- 技术支撑可保留计算值，但实际触发价、限价、止损价和目标执行价须按对应价格档位舍入，并说明舍入方向。

### 交易成本

- 净盈亏比至少纳入实际适用的双向印花税或豁免、交易费、监管征费、结算费、券商佣金/最低佣金和预期滑点；费用会变化，必须刷新官方费率与用户券商费率。
- ETF、做市交易、多柜台和不同交易路径可能有豁免或不同收费，不把普通股票费率机械套用。
- 账户币种与交易币种不同时，加入换汇点差/费用，并保存汇率方向、时间和来源。市场价格风险与汇率风险分别披露。

### 结算与交易路径

- 截至2026-08-18，普通联交所交易以CCASS的T+2结算作为基线；每次仍应刷新当前规则，不能沿用美股T+1假设。券商可用购买力、提款时间、预先交收要求和失败交收处理可能不同。
- 南向港股通另核验当日可交易证券、两地共同交易/结算日、额度、币种转换、碎股和公司行动安排；香港本地账户的可交易状态或日历不能直接替代港股通路径。
- 结算周期不改变技术失效位，但会影响现金调度、重复使用资金、卖空交付和组合流动性风险，必要时单列。

### 跨币种仓位

`position_size.py`使用 `--fx-quote-per-account`，定义为“1单位账户币种可兑换的交易币种数量”。例如账户USD、股票HKD时，输入HKD/USD而不是其倒数。脚本输出账户币种与交易币种两套预算、占用和止损损失。

## 基本面、估值与公司类别

- 港股主板公司不应被默认具有美股式10-Q季度披露。优先使用最新年报、半年报、业绩公告和自愿经营更新；写明报告期结束日、发布日期和距今时间。
- 会计口径可能为HKFRS、IFRS、CASBE或获准的其他标准；财年也可能不是自然年。跨期和同业比较先统一标准、期间、币种与持续经营范围。
- 业绩公告不等于完整审计年报；中期数字可能未经审计。审计意见、持续经营重大不确定性、核数师变更和延迟刊发属于重要风险。
- H股/内地业务额外分析政策与牌照、国资或控股股东、关连交易、VIE/合约安排、资本管制、分红汇出、制裁和地缘风险；只依据公开证据，不按标签自动给负面评分。
- 基本面使用报告币种，市场估值使用交易柜台币种。DCF、每股价值和市值换算使用同一时点汇率；汇率敏感性单列。
- 对H股与A股、双重上市或第二上市公司，确认总股本、各类别股数、库存股/回购注销和每股权利。不能只用港股已发行股数乘总公司利润计算EPS。
- ETF和REIT分别使用基金/REIT适用指标；不要把普通公司FCF或P/E模板机械套用。

## 交易计划与等待门槛

港股继续使用回踩与突破两套互斥方案，但在通用八项门槛外增加市场规则门槛：

1. 原生代码、交易柜台和币种已唯一确认。
2. 当前board lot及生效日已取得；精确新建数量是整手倍数，或碎股路径已解释。
3. 每个拟执行价格符合当日有效价位表。
4. 当日交易日历、当前阶段及半日市/特殊安排已核验。
5. 实际交易路径和当前结算周期已核验；南向港股通没有沿用香港本地账户的资格、日历或费用假设。
6. 双向成本已进入净盈亏比；账户币种不同时汇率和换汇成本已进入仓位风险。
7. 供股、配股、合股、业绩、停复牌等已知公司行动和事件已纳入。
8. 盘口术语与范围使用HKEX口径；竞价、休市或延迟盘口不作当前连续盘触发。
9. 做空计划已核验指定证券资格、券源和成本。

任一必需项失败：技术分析和条件价位可以保留，但精确执行状态为 `revise_plan_or_wait`，当前主动作写“等待/补齐市场规则”。

## 完成检查

- 是否显示HKEX原生五位代码、数据商代码和实际柜台，而非只写模糊简称？
- 报价、K线、盘口是否来自同一柜台和交易币种？
- 是否标注Asia/Hong_Kong、当前连续/竞价/休市阶段和半日市？
- 是否取得当前每手股数、生效日和有效价位，而非默认100股或旧价位表？
- 是否核验实际交易路径与当前结算规则，而非把香港本地账户、美股或港股通假设互相套用？
- 成交量是否已从手/千股正确换算为股数？
- 是否检查供股、合股、红股、特别股息、配售、停复牌和每手股数变更？
- 盘口是否使用 `exchange_book` 等HKEX适用口径，且没有写成NBBO？
- 竞价数据是否与连续盘盘口分开？VCM是否没有被误写成全日涨跌停？
- 精确股数是否为整手倍数；已有碎股是否单列执行风险？
- 双向交易成本和必要的换汇成本是否进入净盈亏比与最大损失？
- 财务期间、审计状态、会计标准、报告币种和汇率是否明确？
- 任何市场规则缺口是否使精确计划降级为“等待”？
