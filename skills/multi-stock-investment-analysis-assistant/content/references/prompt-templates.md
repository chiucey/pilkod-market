# 美股与港股简短标准提问模板

用最少输入启动完整分析，避免用户反复罗列报价、图表、盘口、基本面和策略字段。复制模板后替换方括号内容；不知道的内容写“未知”，不要使用空白或星号占位。

## 一、一句话完整输出协议

用户写出 **“其余按默认完整输出”**，等同于要求 Skill 自动完成以下工作，无需在问题中逐项重复：

1. 回显紧凑任务卡，标明已知、默认、未知、需刷新和阻塞项。
2. 刷新当前报价、市场状态、最近完整K线、同口径OHLCV、Level 1；可靠Level 2/逐笔可得时再使用。
3. 刷新最新财报/业绩、公告、估值、催化剂、行业和大盘背景；港股同时刷新柜台、币种、每手、价位、时段、交易路径、结算、费用和必要汇率。
4. 分列报价、完整K线、盘口、基本面/事件和市场规则的时间、时区、状态、范围与来源。
5. 生成K线+MA、VOL+MAVOL、MACD技术图，并按需加入RSI、KDJ、布林带或OBV。
6. 输出五维评分、唯一当前动作、最多两套互斥方案、分批、加权成本、统一失效位、T1/T2、时间止损、仓位、最大可见损失和第一目标净盈亏比。
7. 区分交易仓与长期核心仓，生成基线编号、复核条件和下次更新引用块。
8. 盘口、数据、市场规则或计划校验不满足执行门槛时，明确写“未取得”或“等待”，不得补造数据。

这句话只授权使用 Skill 的公开默认流程，不授权猜测成本、股数、账户权益、交易路径或用户风险偏好。

## 二、通用主模板

~~~text
@Multi-Stock Investment Analysis Assistant 【完整分析/持仓诊断/多股对比/更新】【标的】；周期【中短期/长期/自定义】；持仓【空仓/数量+每股均价或总成本+币种+交易仓或核心仓/未知】；风险【账户币种+单笔占账户风险+最大仓位占账户比例/未知】；港股路径【本地港股/港股通/其他/不适用】；特别要求【无/写明具体要求】。其余按默认完整输出。
~~~

只填写与本次任务有关的字段即可：

- 新建空仓分析：至少写标的、周期和“空仓”。
- 持仓诊断：至少写股数、成本口径与币种、交易仓/核心仓。
- 精确股数计划：再写账户权益、账户币种、单笔风险和最大仓位。
- 港股精确计划：再写交易路径；每手、价位、费用和汇率由 Skill 刷新。
- 多股比较：写全部标的、比较目的、逐只持仓和组合仓位上限。
- 更新分析：写基线编号或附旧报告/引用块，以及本次成交或“无变化”。

## 三、可直接复制的短模板

### 1. 美股空仓完整分析

~~~text

~~~

### 2. 港股空仓完整分析

~~~text
@Multi-Stock Investment Analysis Assistant 完整分析【00700.HK】；周期【中短期】；持仓【空仓】；账户【100,000 HKD】；风险【单笔占账户1%，最大仓位20%】；交易路径【本地港股】；其余按默认完整输出。
~~~

~~~text
@Multi-Stock Investment Analysis Assistant 持仓诊断【SPCX】；持有【9股】；成本【总成本1,767.92 USD】；仓位【交易仓，占账户13.79%，目标0股或9股】；其余按默认完整输出。
~~~

### 4. 港股持仓诊断

~~~text
@Multi-Stock Investment Analysis Assistant 持仓诊断【00700.HK】；持有【200股】；成本【每股420 HKD】；仓位【交易仓，占账户20%】；交易路径【港股通】；其余按默认完整输出。
~~~

### 5. 多股比较与择优

~~~text
@Multi-Stock Investment Analysis Assistant 比较【AAPL、NVDA、00700.HK】；目标【中短期择优】；账户【USD】；持仓【均空仓】；组合最大仓位【占账户30%】；其余按默认完整输出。
~~~

### 6. 日常更新

~~~text
@Multi-Stock Investment Analysis Assistant 更新【基线编号】；旧报告【同一会话可访问/已附引用块或旧报告】；本次变化【无成交，持仓和风险不变/写明成交或风险变化】；其余按默认完整输出。
~~~

### 7. 快速判断

~~~text
@Multi-Stock Investment Analysis Assistant 快速判断【AAPL】；持仓【空仓/未知】；其余按默认快速输出。
~~~

“默认快速输出”只包含当前结论、三项核心依据、关键价位、主要风险和需要补充的数据；不自动生成精确仓位或完整报告。

## 四、缺失字段与默认处理

- 未写周期：默认中短期，并在任务卡回显。
- 未写持仓：标为“持仓未知”，分别给空仓与持仓者的条件动作；不得默认空仓。
- 未写账户或风险：继续研究，但只给百分比框架或每10,000账户币种单位示例，不给个性化精确股数。
- 成本未说明“每股均价”或“总成本”：持仓盈亏与精确动作属于阻塞项，只追问这一必要问题。
- 标的存在同名、同代码、ADR或多柜台歧义：先确认证券身份。
- 未写是否跨财报/业绩：不得默认愿意跨重大事件持有。
- 未取得Level 1/Level 2：继续日线、基本面和估值分析，但盘中执行写“盘口未取得/等待”。
- 港股未写交易路径：继续研究，精确整手、成本和执行方案写“等待”。
- “当前”“完整数据”和市场规则均由本次重新刷新，不沿用旧报价、旧盘口、旧市场状态或旧校验结果。

除上述真正阻塞项外，不要求用户再次确认已经给出的信息；使用明确默认值继续分析。

## 五、连续更新规则

同一会话可以直接引用基线编号。新会话中，应附旧报告或粘贴上次回答的“下次更新引用块”，避免只凭编号猜测旧持仓与旧计划。

更新请求只需要写三项：

1. 基线编号或旧报告上下文。
2. 本次成交、账户或风险变化；没有变化就写“无成交，持仓和风险不变”。
3. “其余按默认完整输出”。

Skill 必须重新刷新所有时效数据，并在结果中列出“沿用输入、用户变化、事实变化、计划变化和旧计划有效/失效部分”。

## 六、最小检查清单

发出问题前只检查以下内容：

- 代码是否能唯一识别标的；港股建议使用五位代码或`.HK`格式。
- 持仓数量是否写明“股/手”。
- 成本是否写明“每股均价/总成本”和币种。
- 仓位是否写明交易仓或长期核心仓。
- 风险百分比是否写明相对账户权益或持仓。
- 更新任务是否附基线、引用块或旧报告，并写明本次变化。

其他数据和输出要求无需重复，统一使用“其余按默认完整输出”。
