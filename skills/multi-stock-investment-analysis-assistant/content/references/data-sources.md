# 美股与港股数据源及证据规则

## 目录

- 来源层级
- 最小数据包
- 时点与口径
- 冲突处理
- 引用与缺失数据

## 来源层级

根据当前环境中实际可用的工具动态选择来源，不把任何未安装插件写成前置依赖。

### 第一层：原始与官方来源

优先用于事实核验：

- SEC EDGAR：10-K、10-Q、8-K、20-F、6-K、DEF 14A、Form 4、13D/13G、13F 与 XBRL Company Facts。
- 公司 Investor Relations：业绩新闻稿、股东信、演示材料、电话会文字稿、指引与资本配置公告。
- 交易所、指数公司与基金发行人：上市状态、ETF 费用率、指数方法、持仓与杠杆属性。
- Federal Reserve、FRED、BLS、BEA、U.S. Treasury：利率、通胀、就业、GDP 与国债收益率。
- 港股使用HKEX证券资料、HKEXnews、交易日历、交易机制、价位表、公司行动、费用和证券清单；监管事实按问题使用香港证监会、金管局及其他实际主管机关。完整港股路由见 [hong-kong-market.md](hong-kong-market.md)。

SEC或HKEX法定披露与公司材料出现差异时，先检查会计标准、GAAP/Non-GAAP、期间、审计状态、单位、币种和是否重述；原始法定披露优先于摘要网站。

### 第二层：当前行情与标准化金融数据

使用当前运行环境提供的原生行情工具或专业金融数据工具获取：

- 当前价、前收、成交量、日内高低、52 周区间、市值。
- 带时间戳的最佳买一卖一、显示数量、Level 2多档订单簿与逐笔成交；美国仅在来源确认时称NBBO，香港使用HKEX交易所簿等适用范围；仅在权限、延迟、市场范围和数量单位明确时使用。
- 复权 OHLCV、公司行动、估值倍数、分析师一致预期。
- 行业与可比公司标准化口径。
- 大盘、行业 ETF、相对强弱、做空数据和期权隐含波动率（仅在来源可靠且时间口径一致时使用）。

若环境中存在 S&P Global、FactSet、LSEG、Bloomberg、Yahoo Finance 或同类工具，可使用其实际返回；不得假设某工具一定存在。保留提供商名称、时间戳和字段口径。

### 第三层：高质量二手来源

权威财经媒体、研究机构和数据聚合站仅用于：

- 补充市场反应与行业背景。
- 获取官方来源没有提供的共识数据。
- 交叉核对行情或事件时间。

不得用搜索结果摘要代替正文，不得用社交媒体帖子支撑财务事实。重大事件尽量回查 8-K、公司公告或监管文件。

## 最小数据包

| 任务 | 至少需要 |
|---|---|
| 当前行情快评 | 当前/最近收盘价格、行情时间、市场状态、近期事件 |
| 技术分析 | 同口径复权 OHLCV；短中线至少 252 个交易日；大盘与行业基准 |
| 盘口/买卖盘分析 | 至少带时间戳的一档买卖价与数量；多档结论还需Level 2；主动买卖量还需可靠逐笔方向 |
| 财报分析 | 最新申报、业绩材料、上年同期、上一季度、指引与可得共识 |
| 价值分析 | 5 年以上财务趋势、资本结构、股数、正常化现金流、估值基准 |
| 已有持仓计划 | 上述相应数据 + 用户成本、数量、期限；精确仓位还需账户与风险预算 |
| 多股对比 | 同一日期、同一会计和估值口径；无法统一的字段标 N/A |

技术数据不足 200 日时不得声称得到可靠 MA200。季度数据不足时不得计算多年度趋势。

## 时点与口径

### 行情时间

- 区分盘前、正常交易时段、盘后与最近收盘。
- 报告先建立独立的数据快照表：

| 快照 | 必填字段 | 用途 |
|---|---|---|
| 当前报价 | 价格、时间、时区、市场状态、延迟状态、来源 | 只描述用户此刻可见价格与执行环境 |
| 盘口快照 | 买卖价与显示数量、捕获时间、Level 1/2、市场适用范围、数量单位、延迟与来源 | 判断点差、显示深度、滑点和短线执行条件 |
| 最近完整日线 | 交易日、OHLCV、复权口径、来源 | 计算MA、MACD、RSI、ATR、成交量和收盘确认 |
| 基本面 | 财务期间、发布日期、GAAP/Non-GAAP、来源 | 评估经营与估值 |

- 写明交易所时区，并在用户所在时区有帮助时同时换算。
- 港股使用 `Asia/Hong_Kong` 并标明开市前竞价、上午、延续早市、午间非交易、下午或收市竞价；竞价参考价不得当作连续盘买一卖一。
- 盘中价格不得与前一交易日收盘的成交量、指标或估值混为同一时点。
- 盘前/盘后价格只能称“报价”或“临时价格”，不得称“突破确认”或“收盘站稳”。
- 活跃交易阶段的当前报价超过 60 分钟未更新时，不据此给“现在买/卖”的精确结论；先刷新或把结论降级为条件方案。
- 最近完整K线较分析日超过 4 个日历日时检查周末、假日和停牌；超过 7 个日历日仍无法解释时，数据门槛失败。
- 对延迟行情明确标注“延迟”及提供商时间。
- 正常交易时段的盘口快照年龄与已知延迟中的较大者超过60秒，或盘前/盘后超过300秒时，不用于当前执行触发；休市盘口只作历史快照。
- 单交易所Level 2不得描述为全市场深度；只有一档不得输出五档/十档结论；数量单位不明时不得默认“手”等于股数而不作说明。
- 来源为合成、演示、随机、默认或占位数据时，真实证券的盘口数据门槛直接失败。
- 建仓或离场的具体日期必须来自已核验的交易日历、财报或事件日历；不根据新闻传闻填写。

### 价格序列

- 技术指标使用经过拆股调整且 OHLC 四列口径一致的数据。
- 若只提供 Adjusted Close 而 OHLC 未同步调整，不能据此计算 ATR、缺口和 K 线形态。
- 明确 52 周高低、历史高点和收益率是复权还是未复权。

### 财务与估值

- 标明 TTM、NTM、财年或日历年。
- 区分 GAAP 与 Non-GAAP；不得把调整后 EPS 与 GAAP P/E 混用。
- 跨公司对比时统一币种、期间与单位。
- 对 ADR 核对每份 ADR 对应普通股数量；每股数据和目标价使用同一证券口径。
- 港股核对交易柜台币种、财务报告币种、当前每手股数和多柜台/多类别总股本；A股、H股或另一柜台的每股数据不得直接混用。
- 银行、保险、REIT、周期股与亏损成长股使用适合行业的估值指标，不能机械套用 P/E。

### 一致预期

- 标明共识来源、统计日期、覆盖分析师数和预测期间（若可得）。
- 公司指引不是分析师共识；两者分列。
- 目标价不是内在价值，也不是保证收益。

## 冲突处理

1. 先核对证券、期间、单位、币种、复权、GAAP/Non-GAAP 与发布日期。
2. 对法定历史财务，美股优先使用SEC，港股优先使用HKEXnews中的法定报告/公告；对公司最新指引优先使用公司公告或相应法定披露。
3. 对当前行情优先使用带时间戳的行情源；不同源相差明显时注明可能的盘前/盘后或延迟差异。
4. 对盘口优先使用带权限的券商/交易所或专业行情；先核对市场适用的NBBO、HKEX交易所簿、聚合或范围受限口径。不同来源深度不一致属于正常现象，不选择更支持既有观点的一侧。
5. 对共识数据保留提供商差异，不取更符合既有观点的数字。
6. 无法解释的重大差异应降级结论置信度，并在“数据限制”中列出。
7. 港股来源冲突时先核对原生代码、柜台币种、成交量单位、价位表生效日、每手股数生效日、复权和公司行动；不要选择更符合既有观点的数据商代码。

对“现在是否买卖”这类高时效问题，若两个可靠行情源在相近时间的价格差异超过约 0.5%，先检查延迟、盘前/盘后和币种。无法解释时不选择更符合观点的价格，改用区间并降低执行精度。官方财务数据与聚合站差异超过约 1% 时，回到申报文件核对单位、期间和GAAP口径。

## 引用与缺失数据

- 使用工具实际返回的 URL、文件、文档名、发布日期和数据时间。
- 事实后就近引用；同一表格可在列名或脚注清楚映射来源。
- 不编造插件名、数据集名、文档标题、访问日期或链接。
- 搜索摘要只用于定位来源；打开原文后再引用。
- 付费墙、权限、认证或超时属于访问故障，不等于“公司没有该数据”。
- 找不到关键数据时写 N/A，并说明它会影响哪个结论。覆盖率不足时停止给精确操作结论。
