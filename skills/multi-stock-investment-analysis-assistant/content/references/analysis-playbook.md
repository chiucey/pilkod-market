## 任务拆解

先把用户问题翻译成可验证的决策：

| 用户问题 | 需要回答的决策 |
|---|---|
| 现在能不能买 | 当前是否存在满足条件的入场；若没有，等待什么 |
| 什么时候卖 | 哪个条件代表目标达成、趋势破坏或投资逻辑证伪 |
| 还能不能拿 | 原始持有逻辑是否仍成立；风险是否超过预算 |
| 贵不贵 | 当前价格隐含了什么增长；相对合理价值是否有安全边际 |
| 财报好不好 | 实际值、预期、指引、质量和市场定价分别如何变化 |
| 哪只更好 | 在相同周期、口径和风险预算下谁的预期收益风险更优 |

不要在一个“买/卖”结论中混用短线和长线逻辑。若用户没有说明期限，默认同时给短、中、长三栏，但只对数据充分的周期给操作条件。

## 三框架决策逻辑

按顺序完成，不因某一项突出而跳过其余部分：

1. **游资/资金行为层**：判断大盘和行业环境、是否存在可验证催化、标的是不是相对强势核心、处于启动/加速/分歧/退潮哪个阶段，量价是否确认。把“买在分歧、卖在一致”翻译为可观察的价格、成交量和情绪条件，不凭故事判断资金意图。
2. **量化技术层**：用多周期趋势、指标、波动率、关键位和风险收益比定义建仓与离场。指标冲突时降低评分，不挑选最有利的一个。
3. **价值投资层**：判断生意质量、护城河、管理层、现金流和安全边际；确定长期“值得买什么、什么价格值得买、什么情况应该卖”。
4. **五维共振层**：合并证据并计算覆盖率和综合分；评分后仍需通过数据、结构、风险、收益、事件和流动性门槛。
5. **执行层**：给出当前动作、建仓点位与时间、分批步骤、目标、离场时间、持仓建议和最大损失。

## 标的核对

分析前确认：

1. ticker 与交易所是否唯一。
2. 是普通股、ADR、ETF、杠杆 ETF、SPAC、权证还是其他证券。
3. 当前报价币种与用户成本币种。
4. 是否发生拆股、并股、合并、分拆或代码变更。
5. ETF 是否存在每日杠杆重置；ADR 是否存在比例和存托费用。
6. 港股是否已核对HKEX原生五位代码、数据商代码、主板/GEM、股份类别、交易柜台与币种、报告币种、每手股数和交易路径；完整规则见 [hong-kong-market.md](hong-kong-market.md)。

若代码无法唯一匹配，先列出候选，不要猜测。

## 五维评分

每维只能依据已经取得并引用的数据评分。以下为通用锚点，不同行业需调整。

### 1. 趋势（25%）

| 分数 | 通用锚点 |
|---:|---|
| +2 | 周线与日线高低点抬升；收盘价高于 MA50 和 MA200；MA50 高于 MA200 |
| +1 | 中期结构偏上，但某一周期或均线尚未完全确认 |
| 0 | 区间震荡、均线缠绕或多周期冲突 |
| -1 | 中期结构偏弱，但长期趋势尚未完全破坏 |
| -2 | 周线与日线高低点下移；价格低于 MA50 和 MA200；均线空头排列 |

只有足够历史数据时才使用 MA200。单日上涨不能获得 +2。

### 2. 资金与量价（15%）

| 分数 | 通用锚点 |
|---:|---|
| +2 | 有效突破或回踩确认，成交量显著高于基准，OBV与动量同向；若盘口可得，可靠Level 2和主动成交也提供同向确认 |
| +1 | 动量和OBV改善或缩量回踩良好；可有Level 1/Level 2辅助确认，但仍缺少完整放量或结构证据 |
| 0 | 指标互相冲突、量能普通、OBV 横盘或处于中性区 |
| -1 | 动量走弱、反弹缩量、OBV下行、出现负背离，或可靠盘口与价格反弹明显背离 |
| -2 | 放量破位、高位放量滞涨，OBV与多项动量指标同步转弱；若盘口可得，可靠主动卖出和多档卖盘同时确认 |

“相对成交量”须说明基准窗口。RSI 超买本身不是卖出信号，超卖本身也不是买入信号。
盘口缺失不降低本维覆盖率，因为OHLCV仍可独立评分；但只有一档或延迟盘口不能让本维评分升级。可靠Level 2或逐笔成交只作增量证据，不能脱离价格结构、MAVOL、OBV和动量单独获得±2。显示挂单可以撤销，不得写成主力意图。

### 3. 基本面（25%）

| 分数 | 通用锚点 |
|---:|---|
| +2 | 收入或关键业务增长可持续；利润率、自由现金流和资本回报改善；资产负债表稳健 |
| +1 | 整体改善，但存在一项重要弱点或增长放缓 |
| 0 | 经营稳定但无明显改善，或正负变化抵消 |
| -1 | 增长、利润率或现金流恶化，但资产负债表仍可控 |
| -2 | 核心业务萎缩、现金流持续恶化、杠杆或治理出现重大风险 |

周期股须使用中周期盈利，银行和保险须改用资产质量、资本充足与承保/信贷指标。一次性收益不能当成经营改善。

### 4. 估值（20%）

| 分数 | 通用锚点 |
|---:|---|
| +2 | 多种合理方法均显示明显折价，且假设不过度依赖高增长 |
| +1 | 低于合理区间中位或同业，具备一定安全边际 |
| 0 | 位于合理价值区间，或不同方法结论明显冲突 |
| -1 | 高于合理区间，需要较乐观增长才能兑现 |
| -2 | 估值隐含假设显著高于可验证经营能力或历史周期 |

分析师目标价不能单独决定估值分数。亏损公司不使用无意义的 P/E。

### 5. 催化与预期（15%）

| 分数 | 通用锚点 |
|---:|---|
| +2 | 已核验的正向事件、上调指引或预期差形成顺风，且尚未明显反映在价格中 |
| +1 | 存在正向事件，但影响或定价程度不确定 |
| 0 | 无明确事件，或正负催化并存 |
| -1 | 财报、监管、融资或竞争事件形成可见逆风 |
| -2 | 重大负面事件已经证伪核心逻辑，或临近高风险事件且市场预期过度集中 |

不得把新闻数量当作情绪指标。若没有可靠的共识、做空或期权数据，不对“拥挤度”作精确判断。

### 综合计算

使用 SKILL.md 中的权重和公式。评级表必须同时显示：

- 每维评分与一句依据。
- 有效权重覆盖率。
- 综合分与信号区间。
- 至少一个反方证据。

覆盖率低于 70% 时，信号强度最多写“中等”；低于 50% 时不得输出精确交易点位。

完整分析时将五维评分写入 JSON 并运行：

~~~bash
python3 scripts/five_dimension_score.py \
  --input five-dimensions.json --output five-dimensions-result.json
~~~

输入使用以下键；rating 只能为 -2、-1、0、1、2 或 null：

~~~json
{
  "market": "US",
  "dimensions": {
    "trend": {"rating": 1, "evidence": "已引用证据", "counterevidence": "反方证据"},
    "capital_volume": {"rating": 1, "evidence": "已引用证据"},
    "fundamentals": {"rating": 2, "evidence": "已引用证据"},
    "valuation": {"rating": 0, "evidence": "已引用证据"},
    "catalyst_expectations": {"rating": 1, "evidence": "已引用证据"}
  },
  "gates": {
    "data": true,
    "structure": true,
    "risk": true,
    "reward": true,
    "event": true,
    "liquidity": true,
    "time": true,
    "consistency": true,
    "market_rules": true
  }
}
~~~

港股将 `market` 设为 `HK`；此时 `market_rules` 是必检门槛，缺失会使计划保持分析状态。美股也可显式填写该门槛，以证明交易日历、币种和市场约束已核验。

脚本只统一算分和门槛，不替代证据判断。每个非空评分仍须在报告中附来源和反方证据。

## 明确动作映射

必须给出一个主动作，但不得只凭综合分自动下结论：

| 五维结果与门槛 | 默认主动作 |
|---|---|
| 强正向、覆盖率 ≥70%、全部门槛通过 | 按风险预算分批建仓或对合格持仓加仓 |
| 偏正向、门槛通过 | 小仓试探、持有或等待更优买点 |
| 中性或技术/价值框架冲突 | 持有已有合格仓位；新资金等待 |
| 偏负向 | 不新建仓；已有仓位按失效位减仓 |
| 强负向或核心逻辑证伪 | 退出/回避；说明执行窗口与跳空风险 |
| 覆盖率 <50% 或任何关键门槛失败 | 等待，不报虚假精确点位 |

若中短线趋势偏多但长期估值过高，可以给“交易者轻仓、价值投资者等待”；若基本面优秀但技术破位，可以给“长期观察价值区间、中短线暂不参与”。

## 决策门槛

五维分数通过后仍须经过下列门槛：

1. **数据门槛**：价格与技术指标同一时点、同一复权口径。
2. **结构门槛**：有清楚的触发价与逻辑失效位。
3. **风险门槛**：止损距离与用户风险预算相容。
4. **收益门槛**：第一合理目标通常提供至少 2:1 的预期盈亏比；否则等待。
5. **事件门槛**：未来 5 个交易日内的财报或重大裁决可能造成跳空时，降仓、等待或明确将其定义为事件交易。
6. **流动性门槛**：低价股、小市值股或点差明显时，考虑滑点和无法按止损成交。取得盘口后检查价差、计划股数相对显示深度、模拟扫单滑点和数据范围；延迟、单场所或显示深度不足时，不把流动性门槛标为已通过而不加说明。
7. **时间门槛**：明确用收盘确认、下一交易日、2–3 个交易日站稳、财报后重估或具体事件日期定义建仓时间；同时设置与周期一致的结构化时间止损，至少包含期限、可观察触发、动作和适用账本。
8. **一致性门槛**：全部分批成交后的加权成本仍满足第一合理目标的盈亏比；加仓价不与第一止盈位冲突；目标比例和剩余仓位退出规则完整；交易仓与投资仓不混用止损。
9. **市场规则门槛**：使用标的市场当前有效的交易日历、时段、行情范围、数量步长、价位、费用、币种及交易/结算路径。港股缺原生柜台、每手股数、有效价位、交易路径、结算核验或跨币种换算时，只能给研究条件并写“等待”。

任何门槛不通过都可得出“暂不交易”，即使综合分偏正向。

## 已有持仓

按以下顺序分析：

1. 复述成本、数量、持仓市值和未实现盈亏；若用户只给“几手”，先确认每手对应股数。
2. 将“成本价”与“当前合理操作”分开。成本不是支撑位，不因回本愿望改变公司价值。
3. 列出三类条件：
   - 继续持有：趋势/逻辑保持的条件。
   - 加仓：只在风险预算允许且出现新的正向证据时执行。
   - 减仓/退出：价格失效位、事件证伪或组合集中度过高。
4. 计算跌至失效位的金额损失和账户占比。账户规模未知时仅给持仓本身的金额损失。
5. 避免机械摊平亏损。越跌越买必须重新验证基本面和估值。
6. 最终必须用一句明确建议收口，例如“当前持有、不加仓；日线收盘跌破 X 减仓 Y%，到达第一目标减仓 Z%”。数据不足时明确写“等待补齐数据”。

## 财报分析

不要只看 EPS 是否“超预期”。至少检查：

- 收入、EPS、毛利率/营业利润率相对预期。
- 增长的价格、销量、汇率、并购和会计贡献。
- 经营现金流、自由现金流、应收、库存与递延收入。
- 下一季度和全年指引是否上调、下调或撤回。
- 电话会中新增的约束条件、资本开支与需求信号。
- 公布后价格反应相对大盘和行业，区分“财报好”与“市场定价更高”。

## 多股对比与筛选

- 先固定比较日期、周期、行业与币种。
- 使用同一口径的增长、利润、现金流与估值字段。
- 对银行、REIT、软件、半导体等不同行业，分开比较行业专用指标。
- 表格后回答“谁适合哪类投资者”，不要只给总分排名。
- 筛选结果必须列出每条规则是否通过；样本和字段不足时说明漏选风险。

## 常见错误

- 用盘后价配上正常交易时段收盘指标。
- 用未复权高低价计算拆股后的支撑阻力。
- 混用季度同比、环比和全年增速。
- 把 Non-GAAP EPS 与 GAAP 净利润趋势混为一谈。
- 把回购授权额当作已回购金额。
- 把分析师目标价均值当作客观内在价值。
- 因为用户成本较高而调高目标价。
- 给出精确小数点后的“合理价”却不披露估值假设。
- 在财报前用普通止损假定一定能成交。
- 把港股代码别名或双柜台混成一条价格序列，默认一手100股，沿用旧价位表，或把HKEX盘口称作NBBO。
