## 研究顺序

使用企业所有者视角，但不要以名人观点替代证据，也不要虚构名言或背书。按顺序回答：

1. 公司如何赚钱，客户为何付费。
2. 市场增长来自哪里，公司的份额和议价能力如何变化。
3. 护城河来自品牌、网络效应、转换成本、规模、数据、成本或监管中的哪一种。
4. 管理层如何分配资本：研发、资本开支、并购、回购、分红和偿债。
5. 利润是否转化为现金，资产负债表能否穿越下行周期。
6. 当前价格隐含什么增长与回报。
7. 哪些证据会推翻投资逻辑。

无法解释生意模式或关键数据不足时，明确缩小结论范围，不强行给估值。

港股同时应用 [hong-kong-market.md](hong-kong-market.md)。不要默认存在美股式季度报告；写清年报/中报/自愿经营更新的报告期、发布日期、审计状态、HKFRS/IFRS/CASBE等会计标准、报告币种与交易柜台币种。

## 三位投资者的公开原则映射

| 框架 | 在分析中的落实 |
|---|---|
| 巴菲特 | 把股票视为企业所有权；分析能力圈、护城河、管理层资本配置、所有者收益、长期复利与安全边际 |
| 芒格 | 反过来想公司可能如何失败；使用多模型交叉检验；重视企业质量、机会成本、激励机制和避免永久性损失 |
| 段永平 | 先看生意模式和长期价值；区分价格波动与企业变化；重视做对的事情、管理层诚信、耐心等待好价格 |

每个框架都必须落到公司数据、估值假设或可观察卖出信号，不写成名人语录汇编。

## 财务质量

至少观察 5 年趋势；周期性公司尽量覆盖完整周期。

### 增长

- 收入、每股收入、营业利润和自由现金流的 CAGR。
- 有机增长与收购、汇率、价格、销量的贡献。
- 股数变化：总利润增长可能被稀释抵消。

### 盈利与资本回报

- 毛利率、营业利润率、净利率的水平与稳定性。
- ROIC 优先于单独 ROE；高杠杆可人为抬高 ROE。
- 对研发资本化争议、股权激励和一次性项目作敏感性说明。

### 现金流

- 经营现金流与净利润的长期匹配。
- 自由现金流 = 经营现金流 − 资本开支；区分维持性与增长性资本开支（若公司披露不足，说明估计限制）。
- 检查应收、库存、合同负债和资本化成本。

### 资产负债表

- 净债务、利息覆盖、到期结构、固定/浮动利率和表外义务。
- 商誉与无形资产占比、养老金、租赁和潜在诉讼。
- 对金融公司改用资本充足、资产质量、准备金和流动性指标。

### 资本配置

- 区分回购授权、实际回购与注销股数。
- 评价回购价格相对内在价值，而非把所有回购都视为利好。
- 检查并购后的 ROIC、减值和协同兑现。

## 公司类型与估值方法

先分类，再选方法：

| 公司类型 | 主要方法 | 辅助指标 | 避免 |
|---|---|---|---|
| 稳定盈利/现金牛 | DCF、FCF Yield、P/E | EV/EBITDA、股东回报 | 只看单年 EPS |
| 高增长盈利公司 | 情景 DCF、PEG、远期倍数 | 单位经济、增量利润率 | 外推极高增长过久 |
| 尚未盈利公司 | EV/Sales 情景、单位经济 | 毛利率、现金消耗、稀释 | 使用无意义 P/E |
| 周期股/商品股 | 中周期盈利、资产净值 | EV/EBITDA、成本曲线 | 用景气峰值 P/E |
| 银行/保险 | P/B、ROE、剩余收益 | 资本充足、资产质量 | 企业价值倍数套用 |
| REIT | P/AFFO、NAV | 同店 NOI、负债与利率 | GAAP EPS 单独判断 |

至少使用两种互相独立的方法交叉验证。历史估值只能说明市场过去如何定价，不自动等于合理价值。

## DCF 情景

简化 DCF 可运行：

~~~bash
python3 scripts/dcf_scenarios.py --input dcf-input.json --output dcf-output.json
~~~

输入示例：

~~~json
{
  "base_fcf": 1000000000,
  "shares": 500000000,
  "net_debt": 200000000,
  "current_price": 24,
  "projection_years": 5,
  "margin_of_safety_pct": [20, 30],
  "scenarios": [
    {"name": "保守", "growth_pct": 3, "discount_pct": 11, "terminal_growth_pct": 2},
    {"name": "中性", "growth_pct": 6, "discount_pct": 10, "terminal_growth_pct": 2.5},
    {"name": "乐观", "growth_pct": 9, "discount_pct": 9, "terminal_growth_pct": 3}
  ],
  "reverse_dcf": {"discount_pct": 10, "terminal_growth_pct": 2.5}
}
~~~

要求：

- base_fcf 使用正常化、可持续的年度自由现金流，不机械取异常高低年份。
- growth_pct 是显性预测期的恒定增长，仅为简化假设；业务变化明显时改用逐年模型。
- discount_pct 必须高于 terminal_growth_pct。
- net_debt = 有息债务及类似义务 − 现金与可用投资；净现金可填负数。
- shares 使用稀释后股数并考虑未来股权激励。
- 港股多类别、A/H股或双重上市公司使用全公司同权口径的稀释后总股数；不要只用港股流通股数分摊全公司自由现金流。报告币种与交易币种不同时，记录估值日汇率和方向。
- 输出是情景估值，不是精确真值。正文必须显示关键假设与敏感性。
- 提供 current_price 和 reverse_dcf 时，脚本计算“市场价格要求的恒定FCF增长率”。它是反推的隐含要求，不是预测，不得写成公司一定会实现的增速。

高增长公司的终值占企业价值过高时，降低置信度。若终值贡献超过约 75%，特别提示结果高度依赖长期假设。

若保守、中性和乐观估值相差超过 3 倍，或反向DCF要求十年左右维持超过约 25% 的恒定FCF增速，估值结论最多写“低置信度/高度依赖假设”。此时不得用单一DCF点值直接生成精确买入价；应扩大区间、提高安全边际，并用市场倍数、单位经济或分部价值交叉验证。

## 安全边际

安全边际随不确定性变化，不固定为某个比例：

- 稳定、可预测且资产负债表强：可参考 15%–25%。
- 中等不确定性：可参考 25%–35%。
- 周期、高杠杆、早期或治理风险高：可要求 35%–50% 甚至放弃。

“好价格区间”应来自保守价值区间乘以安全边际，而非简单按当前价打折。若不同估值方法差异过大，扩大区间并降低仓位，而不是取平均制造精确感。

## 买入、持有与卖出

### 买入

- 价格进入具备安全边际的区间。
- 长期逻辑未被短期利空破坏。
- 分批买入的总风险与组合集中度可控。
- 技术面可用于改善入场，但不替代基本面。
- 明确回答“当前买入 / 等待 / 小仓试探”并给出好价格区间、触发事件和分批步骤。

### 持有

建立一份可复核的投资论点：

- 3 个核心经营假设。
- 3–5 个季度/年度监控指标。
- 估值区间与预期年化回报来源。
- 下次复核事件或日期。

### 减仓或卖出

以下均可成为理由，但必须具体化：

1. 护城河、治理或资产负债表出现实质恶化。
2. 关键经营假设被连续数据证伪。
3. 价格远高于合理价值，未来回报显著低于可接受水平。
4. 组合集中度、流动性需求或风险预算发生变化。
5. 存在风险调整后明显更优的机会，并完成同口径比较。

税务、交易费用和持有期限会影响实际决策；数据不足时只讨论税前框架。

港股额外检查控股股东与国资背景、关连交易、配股/供股、VIE或合约安排、分红汇出、资本管制、审计意见和多柜台流动性；这些是证据核对项，不因公司标签自动加减分。

### 明确买卖信号

| 动作 | 必须出现的证据 |
|---|---|
| 买入 | 进入安全边际区间，长期逻辑成立，资产负债表可承受下行，预期回报满足要求 |
| 加仓 | 价格更有吸引力且基本面未恶化，或新数据提高内在价值；组合风险仍合规 |
| 持有 | 投资论点、资本回报和合理估值区间没有实质恶化 |
| 减仓 | 价格明显高于合理价值、组合过度集中、预期回报下降或风险上升 |
| 卖出 | 护城河/管理层/资产负债表/核心增长逻辑被证伪，或存在更优风险调整机会 |

长期卖出信号不等同于预测某一天的最高点。给出“证据出现后的下一可执行窗口”、季度复核节点或经核验的事件日期。

## 反方检验

结论前强制回答：

- 最可能导致收入增速低于假设的因素是什么？
- 毛利率或资本回报为何可能不可持续？
- 市场已经在价格中计入了哪些利好？
- 哪项会计或现金流口径最可能高估质量？
- 如果折现率上升 1–2 个百分点，价值区间如何变化？
- 哪个可观察数据出现后，应承认原判断错误？

最终报告至少列出一个与主结论相反、且有数据支持的观点。
