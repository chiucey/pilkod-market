## 强制输出规则

以下任务只要取得可靠的同口径 OHLCV，就必须生成并在答案中实际展示走势图：

- 个股行情趋势分析；
- 中短线技术分析；
- 完整建仓、持仓或离场策略；
- 用户明确要求K线、MACD、成交量或技术图表。

策略表、指标数值表和文字不能替代走势图。默认生成一张共享时间轴的多面板图，至少包含K线与MA、VOL与MAVOL、MACD。用户只问基本面且不需要择时时可不生成。

## 数据与时点

- 默认使用最近120个**完整日线交易日**作显示窗口；指标使用窗口之前的历史数据预热，不得只用屏幕内120行重新起算MA200或MACD。
- 图表不得混入盘前、盘中或盘后临时报价。当前报价在正文另列，图中最后一根K线明确标为“最近完整交易日”。
- 若输入含未完成日线，使用 `--last-bar-status incomplete` 自动排除最后一行；不得把临时K线当作收盘确认。
- OHLC四列必须采用同一拆股复权口径；成交量沿用提供商的公司行动口径。只取得Adjusted Close而没有同步复权OHLC时，不画K线、ATR或缺口。
- 图中写清标的、频率、日期区间、最近完整K线日期、复权口径及实际数据源。
- 图中必须显式传入交易币种。港股同时写原生代码/柜台；成交量先从手、千股等来源单位规范为股数，并在元数据保留换算因子。
- 必须显式选择颜色习惯：`--color-convention us`为绿涨红跌，`cn`为红涨绿跌。颜色只改变显示，不改变涨跌计算；港股按用户/券商习惯选择并在图中保留标注。
- 港股先核验供股、合股/拆细、红股、特别股息、柜台和每手股数变更；异常跳变未排除公司行动前，不生成可能误导的关键位结论。
- 先检查 `analyze_ohlcv.py` 返回的 `data_quality` 与 `warnings`。超过7个日历日且无法解释的陈旧日线不能支持“现在买卖”的图表结论。

## 标准面板

| 面板 | 默认内容 | 必须回答的问题 |
|---|---|---|
| 价格 | 日K线、MA5/10/20/50/200、20日关键位 | 高低点结构、均线排列、趋势所处阶段 |
| 量能 | VOL、MAVOL5/10/20 | 放量或缩量相对哪个基准，量价是否确认 |
| 动量 | MACD DIF、DEA、柱 | 零轴位置、交叉、柱体扩张/收敛、是否与价格背离 |
| 选配 | RSI14、KDJ(9,3,3)或OBV/OBV-MA20 | 过热/超卖、短周期拐点或资金累积是否提供增量证据 |

主图保持克制：默认只画MA，不同时叠加全部布林带和所有策略线。只有判断波动收缩、突破或带宽时才加布林带。最多标出五个最关键的支撑、压力或交易位，避免遮挡K线。

长期结论依赖多年结构时，另补周线或3–5年趋势图；不要把数年日K压缩到一张无法阅读的图中。多周期图分别写明频率，不能把周线指标当作日线指标。

## 指标口径

- MA5/10/20/50/200：收盘价简单移动平均。
- MAVOL5/10/20：成交量简单移动平均；成交量缺失或全为零时全部记为不可用。
- MACD：DIF = EMA12 − EMA26；DEA = DIF的EMA9；柱 = DIF − DEA。本Skill不使用部分平台的两倍柱口径，比较外部图表时先核对。
- RSI14：Wilder平滑。
- KDJ：9,3,3。
- 布林带：SMA20 ± 2倍总体标准差。
- OBV：按收盘涨跌累加当日成交量；同时比较OBV-MA20。

指标必须与 `analyze_ohlcv.py` 的结果一致，不手算另一套口径。单一金叉、死叉、超买或超卖不构成买卖结论，必须结合价格结构、量能和风险收益。

## 图表标注

- 20日实际前高/前低可作为支撑压力辅助线；正文必须解释它们是否经过多次验证。
- 建仓、加仓、止损和目标只能在 `validate_trade_plan.py` 返回 `plan_passes_internal_checks` 后标入图中。
- 生成策略标注时同时传入原计划与校验结果；绘图脚本核对完整日线日期，避免图表与计划使用不同快照。
- 图中只显示已通过方案的分批价格、加权成本、统一止损和目标。未通过方案保留在正文“等待/修订”说明中，不画成可执行信号。
- 图中价位与正文、策略表、仓位计算必须完全一致。任何一处更新后，重新生成图表和计划校验。

## 图后解读

每张图后用四至七条简短结论覆盖：

1. 价格处于上升、下降、区间或转换结构中的哪一阶段；
2. 收盘价与MA20/50/200的关系，以及均线斜率和排列；
3. 当前成交量相对MAVOL5/10/20，突破或回踩是否被量能确认；
4. MACD位于零轴上/下，DIF与DEA关系，柱体扩张还是收敛；
5. 选配指标是否提供增量证据或出现背离；
6. 最近支撑、压力与图表证伪点；
7. 这些证据如何改变当前动作。

不要只贴图不解释，也不要从一根K线或一个指标直接跳到“买入/卖出”。背离必须说明比较的两个价格高低点和对应指标高低点。

## 数据不足与降级

- 少于200行：MA200显示不可用，不得外推；仍可展示K线、量能和可计算指标。
- 少于35行：MACD信号线可能不足；保留MACD面板并明确显示“数据不足”，不能静默删掉。
- 新上市标的：在图题中注明可用交易日数量，长期趋势置信度降级。
- 无有效成交量：保留量能面板并写“成交量不可用”，MAVOL、OBV和相对量均不计算。
- OHLC复权口径不一致或最近K线过期：不生成可能误导的K线图；改用数据缺口表，当前动作降级为等待。
- 绘图环境故障：报告中明确说明图表未成功生成并重试；不得把策略表称作K线图。

## 执行命令

先计算指标：

~~~bash
python3 scripts/analyze_ohlcv.py --input prices.csv \
  --output indicators.json --enriched-output indicators.csv \
  --as-of 2026-08-18T16:00:00-04:00
~~~

生成标准图：

~~~bash
python3 scripts/render_technical_chart.py \
  --input prices.csv --output technical-chart.png --symbol AMD \
  --currency USD --color-convention us \
  --source-label "实际数据提供商" --basis "同口径拆股复权OHLCV" \
  --last-bar-status completed --bars 120 --oscillator rsi \
  --as-of 2026-08-18T16:00:00-04:00
~~~

短周期拐点改用 `--oscillator kdj`；量价背离改用 `--oscillator obv`；波动收缩判断加 `--bollinger`。

只有计划校验通过时添加策略点位：

~~~bash
python3 scripts/render_technical_chart.py \
  --input prices.csv --output technical-chart.png --symbol AMD \
  --currency USD --color-convention us \
  --source-label "实际数据提供商" --basis "同口径拆股复权OHLCV" \
  --last-bar-status completed --plan-input trade-plan.json \
  --plan-validation trade-plan-result.json
~~~

在支持本地图片的回答中实际嵌入生成文件；不要只给内部路径。若用户要求报告文件，把同一张图嵌入报告，不重新手工绘制另一套指标。

## 完成检查

- 是否真的出现K线、VOL/MAVOL与MACD，而非只有策略表？
- 图和正文是否使用同一最近完整交易日、同一复权口径与同一数据源？
- 当前临时报价是否与完整日线图分离？
- 图中的MA、MAVOL与MACD参数是否已标明且与脚本一致？
- 图中的买入、止损和目标是否来自通过校验的同一计划？
- 图后是否解释价格、量能、动量、关键位及其对动作的影响？
- 港股图是否使用正确柜台、币种、成交量股数口径和公司行动调整，而非混入另一柜台或旧每手单位？
