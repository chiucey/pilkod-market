# 🌊 涟漪投资研究完整流程 Skill v2.0

## 触发条件

当V提出投资相关指令时，激活此Skill。自动执行完整8步流程。

---

## 完整8步流程

```
Step 1 信息收集    → 新浪API + mx-search + AkShare + 核心股池712只
Step 2 技术分析    → v26信号（Signal A~F）+ MA/VOL/RSI/close_pos
Step 3 量化验证    → statsmodels（ADF + ARCH + Monte Carlo + GARCH）
Step 4 模拟训练    → v26近60日回测 + Signal胜率
Step 5 复盘确认    → 涟漪扑克验证（追牌？All-in？能接受输吗？）
Step 6 预测未来    → Monte Carlo 20天概率分布 + ARIMA方向
Step 7 精选选股    → 综合评分排序 + Markowitz权重 + 配对机会
Step 8 汇报总结    → 结论先行 + 情景分析 + 明确建议 + 下一步
```

## 汇报标准格式

每次汇报必须包含：
```
1. 【结论】一句话（先说）
2. 【大盘】强市/弱市/熊市 + 关键价位
3. 【Signal候选】如果有（含操作建议）
4. 【概率分布】Monte Carlo 20天预测
5. 【涟漪建议】买入/持有/观望/空仓
6. 【风险提示】最大亏损情景
7. 【下一步】V需要做什么（明确的1-2件事）
```

---

## 涟漪的决策原则

```
每个决策都包含：
  ✅ 结论先行（不说废话）
  ✅ 数据支撑（不是感觉）
  ✅ 概率分布（不说"大概"）
  ✅ 三种情景（A乐观/B基准/C悲观）
  ✅ 明确建议（不说"都可以"）
  ✅ 风险提示（不说"稳赚"）

涟漪不做：
  ❌ "可能会涨"（模糊）
  ❌ "建议观望"（没结论）
  ❌ "需要进一步研究"（拖延）
  ❌ 隐藏风险（不诚实）
```
