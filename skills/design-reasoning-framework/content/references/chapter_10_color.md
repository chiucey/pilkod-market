# 第十章：配色系统（核心）

## 10.1 配色的本质

> **配色不是选颜色，而是分配明度层次。**

### 核心公式

```
配色 = 黑白构成 + 彩色点缀
先做黑白，再加颜色
```

## 10.2 黑白构成（明度层次）

### 明度层次数量

| 层次数 | 效果 | 适用场景 |
|--------|------|---------|
| **2层** | 强对比、干净 | 图标、logo、简化角色 |
| **3层** | 基础层次、清晰 | 大部分角色设计 |
| **4层** | 丰富、立体 | 复杂角色、场景 |
| **5层+** | 过渡丰富、写实 | 写实风格 |

### 明度分配公式

```
【3层基础配比】
亮色（白/浅灰）: 40-60%
中间色（灰）: 20-40%
暗色（深灰/黑）: 20-40%

【常见组合】
6:3:1 = 主体亮，暗色点缀
5:4:1 = 平衡型
4:4:2 = 对比强烈
```

---

## 10.3 彩色加入规则

### 核心原则

> **彩色是点缀，不是主体。先确定黑白，再加彩色。**

### 彩色加入步骤

```
Step 1: 完成黑白构成（确定明度层次）
Step 2: 选择1个主色
Step 3: 确定彩色面积（通常<20%）
Step 4: 确定彩色位置（视觉焦点）
```

### 彩色面积比例

| 彩色面积 | 效果 | 适用场景 |
|---------|------|---------|
| **5%以下** | 点睛、弱点标识 | 眼睛、宝石、伤口 |
| **10-20%** | 辨识色、角色特征 | 头发、配件、武器 |
| **30%以上** | 主色调、强烈风格 | 特定阵营色、拟人角色 |

## 10.4 配色风格类型

### 三种基础配色风格

| 风格 | 特点 | 黑白构成 | 彩色使用 |
|------|------|---------|---------|
| **彩相** | 高饱和、活力 | 弱 | 多色、高饱和 |
| **灰褐** | 复古、沉稳 | 中 | 低饱和、土色系 |
| **黑白** | 干净、现代 | 强 | 极少、仅点缀 |

### 风格情感对照

```
【彩相风格】
├── 适用：萌系、卡通、欢快角色
├── 情感：活力、可爱、热闹
└── 参考：任天堂角色、喷射战士

【灰褐风格】
├── 适用：历史、军事、成熟角色
├── 情感：沉稳、复古、写实
└── 参考：战锤、刺客信条

【黑白风格】
├── 适用：暗黑、科幻、时尚角色
├── 情感：酷、神秘、高级感
└── 参考：战双、尼尔
```

## 10.5 太极式配色（阴阳平衡）

### 核心概念

> **黑中有白，白中有黑。对立统一。**

### 应用方法

```
【阴阳配色】
主体黑 → 点缀白（白色配件、高光）
主体白 → 点缀黑（黑色细节、阴影）

【交织配色】
上半身黑+下半身白
左侧黑+右侧白
外层黑+内层白
```

### 太极配色的张力

| 配比 | 效果 |
|------|------|
| 5:5 | 最大张力、双面性 |
| 7:3 | 主次分明、有倾向 |
| 9:1 | 极端中的反转、点睛 |

## 10.6 配色检验清单

- [ ] 黑白构成是否清晰？（去色后仍有层次）
- [ ] 明度层次是否合理？（3-4层）
- [ ] 彩色面积是否克制？（通常<20%）
- [ ] 彩色位置是否有意义？（焦点/弱点/特征）
- [ ] 配色是否强化轮廓？（剪影更清晰）
- [ ] 整体风格是否统一？（彩相/灰褐/黑白）
