## E. 轮廓公式速查

```
【基础形状】
△ = 攻击性、危险
○ = 友好、可爱
□ = 稳定、力量

【组合】
△+○ = 锐利但柔和
□+△ = 稳重但有攻击性
○+□ = 可爱但有力量

【轮廓方向】
上窄下宽 = 稳定、力量型
上宽下窄 = 不稳定、灵活型
中间宽 = 圆润、可爱型
```

## H. 配色速查表

```
【配色公式】
配色 = 黑白构成 + 彩色点缀
先做黑白，再加颜色

【明度层次】
2层 = 强对比、干净
3层 = 基础、清晰
4层 = 丰富、立体

【彩色面积】
<5% = 点睛
10-20% = 辨识色
>30% = 主色调

【黑白分布】
上白下黑 = 轻盈
上黑下白 = 稳重
中白上下黑 = 中心突出
条纹交替 = 节奏感

【配色风格】
彩相 = 活力、可爱
灰褐 = 沉稳、复古
黑白 = 酷、高级感

【太极配色】
黑中有白，白中有黑
主体黑→点缀白
主体白→点缀黑
```

## I. 立体构成速查表

```
【体块七要素】
1. 有体块（基础形态）
2. 有体块变化（形态渐变）
3. 有方向朝向（XYZ轴向）
4. 有体积对比（大小关系）
5. 有疏密变化（聚散节奏）
6. 有穿插关系（体块交叉）
7. 有层次叠加（前后遮挡）

【三种基础体块】
□ 方体 = 稳定、工业、理性
○ 球体 = 柔和、有机、亲和
△ 锥体 = 攻击性、指向性、动态

【方向对比】
0°（水平）= 稳定、静态
45°（斜向）= 动态、过渡
90°（垂直）= 直立、力量

【体积分布】
顶重 = 压迫 | 底重 = 稳定 | 中重 = 可爱

【穿插类型】
贯穿 = A完全穿过B
嵌入 = A部分嵌入B
缠绕 = A绕着B
包裹 = A包住B

【体块层级】
1级 = 整体轮廓体块
2级 = 区域体块（头/胸/腰/腿）
3级 = 局部体块（手臂/肩膀）
4级 = 细节体块（手指/装饰）

【先3D后2D】
概念 → 体块草图 → 三视图 → 2D细化 → 上色
```

## J. 配色分区速查表

```
【2节点分区】
亮（上）+ 暗（下）= 最简模式

【7节点分区】
头发 → 面部 → 上装 → 腰部 → 下装 → 脚部 → 配件

【纵向分区】
头部（亮）→ 躯干（中）→ 下肢（暗）

【层次分区】
外层（暗）→ 中层（中）→ 内层（亮）

【分区原则】
同功能 → 同色系
不同层次 → 不同明度
不同材质 → 不同饱和度
```
