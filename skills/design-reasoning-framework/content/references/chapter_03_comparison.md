# 第三章：图形对比系统

## 3.1 对比的本质

> **设计的张力来自对比，没有对比就没有记忆点。**

## 3.2 对比铁律

| 铁律 | 说明 |
|------|------|
| **五五开 = 没有对比** | 权重相同的对比等于没有设计 |
| **必须有主对比** | 一个角色只能有一个核心记忆点 |
| **曲直是立场** | 曲=生物/感性/流动，直=人工/理性/控制 |

## 3.3 对比分级（硬规则）

| 级别 | 数量 | 作用 | 权重 |
|------|------|------|------|
| **主对比** | 1个 | 决定角色记忆点 | 60% |
| **次对比** | 1-2个 | 强化主对比 | 30% |
| **细节对比** | 若干 | 增加层次感 | 10% |
| **其余对比** | - | 必须弱化或删除 | 0% |

## 3.4 曲直立场规则

> 曲直五五开 = 图形无立场 = 没张力

| 偏向 | 传达信息 | 示例 |
|------|---------|------|
| **偏曲** | 生物性、失控、蔓延 | 根须、触手、肉质 |
| **偏直** | 人工性、控制、规则 | 金属框架、几何形状 |

**设计必须：明确偏向一侧，另一侧作为对比存在**

| 对比类型 | 对比轴 | 视觉表现 |
|---------|-------|---------|
| **尺度对比** | 大 vs 小 | 体型差异、局部放大 |
| **比例对比** | 满 vs 疏 | 密集区 vs 留白区 |
| **明度对比** | 黑 vs 白 | 亮部 vs 暗部 |
| **长度对比** | 长 vs 短 | 延伸 vs 收缩 |
| **方向对比** | 上 vs 下、横 vs 竖 | 动势方向 |
| **形状对比** | 直 vs 曲 | 直线 vs 曲线 |
| **厚度对比** | 厚 vs 薄 | 体量感差异 |
| **点线面对比** | 点 vs 线 vs 面 | 图形元素类型 |
| **软硬对比** | 软 vs 硬 | 布料 vs 金属 |
| **虚实对比** | 虚 vs 实 | 透明 vs 实体 |
| **疏密对比** | 密 vs 疏 | 聚集 vs 分散 |
| **有机对比** | 有机 vs 几何 | 自然形 vs 人工形 |

| 对比轴 | 极A | 极B | 情感传达 |
|--------|-----|-----|---------|

| **曲/直** | 曲线 | 直线 | 感性/理性 |

| **冷/暖** | 冷色 | 暖色 | 冷静/危险 |
| **光/哑** | 光泽 | 哑光 | 人工/自然 |

## 3.8 轮廓公式（基础几何组合）

### 基础形状情感

| 形状 | 情感倾向 | 适用角色 |
|------|---------|---------|
| **△ 三角形** | 攻击性、锐利、危险 | 反派、战士、尖锐角色 |
| **○ 圆形** | 友好、可爱、柔软 | 萌系、亲和角色 |
| **□ 方形** | 稳定、可靠、力量 | 坦克、守护者 |
| **△ + ○** | 锐利中带柔和 | 有攻击性但不全恶 |
| **□ + △** | 稳重但有攻击性 | 重装战士 |
| **○ + □** | 可爱但有力量 | 萌系力量型 |

### 轮廓剪影公式

```
【上窄下宽】= 稳定、力量型（如大猩猩）
【上宽下窄】= 不稳定、灵活型（如倒三角英雄）
【中间宽】= 圆润、可爱型（如企鹅）
【均匀】= 普通、中性
```

### 轮廓变化规律

```
疏 → 密：元素从少到多，节奏感
聚 → 散：从集中到分散，动态感
大 → 小：从主体到细节，层次感
正 → 负：从正形到负形，空间感
```

## 3.9 剪影测试法

> **好设计 = 3秒内能从剪影识别角色。**

### 测试方法

1. 把设计转为纯黑剪影
2. 检查是否能识别：
   - 角色类型（人/兽/机械）
   - 职业/身份
   - 情绪/姿态
3. 检查轮廓是否有记忆点

### 轮廓记忆点类型

| 类型 | 说明 | 示例 |
|------|------|------|
| **突出物** | 从主体延伸出的元素 | 角、翅膀、尾巴、武器 |
| **缺失物** | 主体缺少的元素 | 断臂、无头、空洞 |
| **异常比例** | 不符合常规的比例 | 超长手臂、巨大头部 |
| **不对称** | 左右不一致 | 一侧有翅膀 |
