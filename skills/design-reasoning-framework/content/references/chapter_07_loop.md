# 第七章：加法/减法循环

## 7.1 加法阶段（探索）

> 没有"最终版本"，只有"每一轮都更聚焦"

| 目标 | 方法 |
|------|------|
| **找出主对比轴** | 多方案、多替换、多尝试 |
| **不是堆元素** | 是探索哪个对比最有张力 |

## 7.2 减法阶段（收敛）

| 类型 | 说明 | 示例 |
|------|------|------|
| **整理** | 把杂乱元素摆出秩序，强化图形感 | 统一方向、对齐边缘 |
| **合并（高级）** | 一个元素承担多重信息 | 装饰=功能=语义 |

## 7.3 合并的判断标准

> 这是高级角色与普通角色的分水岭

| 普通设计 | 高级设计 |
|---------|---------|
| 装饰是装饰，功能是功能 | 装饰=功能=语义 |
| 元素各自独立 | 元素互相服务 |
| 加法思维 | 减法+合并思维 |

### 合并检验

- [ ] 是否利用了载体的原有零件/功能？
- [ ] 视觉元素是否同时承载"功能"和"隐喻"？
- [ ] 删掉这个元素后，是否同时失去多重信息？

## 7.4 循环规则

```
加法 → 减法 → 加法 → 减法 → ...
每一轮都更聚焦，直到无法再减
```
