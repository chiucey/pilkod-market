# 第一章：推理的本质

## 1.1 人类思维的两种模式

| 模式 | 说明 | 特点 |
|------|------|------|
| **收敛思维** | 从多到一，聚焦答案 | 确定性高，但可能遗漏可能性 |
| **发散思维** | 从一到多，拓展可能 | 创造性高，但可能失控 |

**设计推理 = 发散 → 收敛 → 发散 → 收敛 的循环**

```
起点 → [发散] → 多条路径 → [收敛] → 选定方向 → [发散] → 细节变体 → [收敛] → 最终设计
```

---

## 1.2 推理的三层结构

| 层级 | 名称 | 问题 | 产出 |
|------|------|------|------|
| **第一层** | 功能层 | 这个东西**做什么**？ | 动词列表 |
| **第二层** | 语义层 | 这个东西**意味着什么**？ | 隐喻/情感/联想 |
| **第三层** | 图形层 | 这个东西**长什么样**？ | 形状/轮廓/视觉 |

> **核心原则**：先推功能和语义，最后才确定图形。

---

## 1.3 四大属性维度

每个载体都可以从以下4个维度拆解出分支：

| 属性维度 | 核心问题 | 产出分支类型 |
|---------|---------|-------------|
| **功能属性** | 它能做什么？有什么行为？ | 动作→机制→图形 |
| **形态属性** | 它长什么样？什么结构？ | 部件→造型→图形 |
| **材质属性** | 它是什么材质/质感？ | 材质→触感→图形 |
| **文化属性** | 它象征什么？有什么隐喻？ | 意象→情感→图形 |

---

## 1.4 联想的三条路径

每个属性分支都可以通过以下方式延伸：

| 路径 | 方法 | 示例 |
|------|------|------|
| **相似联想** | 什么东西也有这个特征？ | 蒸汽→云→棉花→水母触须 |
| **功能联想** | 什么东西也能做这个？ | 开合→嘴巴→捕蝇草→夹子 |
| **情感联想** | 什么东西也给人这种感觉？ | 温饱→满足→猪猪→圆润 |

### 联想链书写规则

```
【正确】每一步都有逻辑连接词
蒸汽 → 飘散形态 → 水母触须 → 透明+流动

【错误】跳跃无连接
蒸汽 → 水母（缺少中间逻辑）
```

### 联想终点 = 图形落点

联想链的终点必须是**可视化的图形描述**：

| ❌ 无效终点 | ✅ 有效终点 |
| ----------- | ----------------- |
| 感觉很酷 | 透明+触须+发光 |
| 有攻击性 | 锯齿边缘+红色内壁 |
| 很可爱 | 圆形轮廓+大眼睛 |
