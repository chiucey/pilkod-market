# 第六章：构成重算系统

## 6.1 构成顺序（严格执行）

> 设计不是堆细节，而是"组织形态"

| 顺序 | 阶段 | 检验内容 |
|------|------|---------|
| 1 | **黑白构成** | 只看图形，不看颜色材质 |
| 2 | **点线面对比** | 疏密、方向、视觉引导 |
| 3 | **色彩构成** | 冷暖、纯灰、权重分配 |
| 4 | **平面构成** | 版式、节奏、呼吸感 |
| 5 | **立体构成** | 厚度、包裹、连接方式 |

## 6.2 构成铁律

| 铁律 | 说明 |
|------|------|
| **❌ 直接上颜色/材质** | 90%会失败 |
| **✅ 先过黑白构成** | 黑白不成立，彩色也不会成立 |

## 6.3 点线面对比

### 三元素特征

| 元素 | 特征 | 视觉效果 |
|------|------|---------|
| **点** | 聚集、强调 | 视觉焦点 |
| **线** | 引导、连接 | 视觉路径 |
| **面** | 填充、分割 | 区域划分 |

### 点线面应用

```
【点元素应用】
- 装饰点：纽扣、铆钉、纹理点
- 聚焦效果：眼睛、高光、弱点标识

【线元素应用】
- 轮廓线：剪影边缘
- 结构线：关节、接缝、纹路
- 动态线：速度线、飘带轨迹

【面元素应用】
- 区域划分：服装区块、体块分布
- 留白处理：呼吸感、节奏
```
