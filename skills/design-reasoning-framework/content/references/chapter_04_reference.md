# 第四章：参考反推法

## 4.1 从参考图反推设计逻辑

> **看到优秀设计时，反推它的推导链。**

### 反推步骤

```
1. 识别载体：这个设计的原型是什么？
2. 拆解元素：它由哪些视觉元素组成？
3. 追溯功能：每个元素对应载体的什么功能？
4. 提取对比：它的主对比轴是什么？
5. 总结公式：提炼可复用的设计公式
```

### 反推示例

```
【参考图】宝石之国角色

1. 载体识别：宝石 + 人体
2. 元素拆解：透明身体、宝石纹理、脆弱感
3. 功能追溯：
   - 透明 ← 宝石的光学特性
   - 脆弱 ← 宝石易碎
   - 美丽 ← 宝石的装饰价值
4. 主对比：美丽 vs 脆弱、永恒 vs 易碎
5. 设计公式：【珍贵材质】+【人形】+【材质特性决定性格】
```

## 4.2 参考分类标签系统

### 按材质分类

| 材质类型 | 关键词 | 情感倾向 |
|---------|-------|---------|
| **陶瓷** | 素体、白瓷、裂纹 | 脆弱、纯净、易碎 |
| **金属** | 机械、盔甲、锈蚀 | 坚硬、冷酷、工业 |
| **布料** | 飘逸、缠绕、褶皱 | 柔软、流动、包裹 |
| **生物** | 骨骼、肌肉、皮肤 | 有机、生命、恐怖 |
| **植物** | 藤蔓、花朵、枯萎 | 生长、侵蚀、凋零 |
| **液体** | 流淌、滴落、融化 | 不稳定、变化、侵蚀 |
| **宝石** | 透明、折射、多面 | 珍贵、脆弱、永恒 |

### 按情绪分类

| 情绪 | 关键词 | 视觉特征 |
|------|-------|---------|
| **神圣** | 光环、白色、对称 | 向上、发光、秩序 |
| **堕落** | 黑暗、不对称、侵蚀 | 向下、阴影、混乱 |
| **悲伤** | 下垂、灰色、残缺 | 低头、褪色、破损 |
| **愤怒** | 尖锐、红色、扩张 | 外扩、高饱和、锐角 |
| **恐惧** | 扭曲、黑色、不明 | 异常比例、遮挡、模糊 |
| **可爱** | 圆润、明亮、小巧 | 大眼、短肢、柔和色 |

## 4.3 参考图锚点（树状图的视觉节点）

### 每个图形落点必须标注参考图

```
蒸汽 → 飘散 → 水母触须
                   │
              [参考图：水母]
              ├── 直接关键词：水母、jellyfish、海月水母
              ├── 跨界关键词：机械水母、蒸汽朋克水母
              └── 提取要素：透明材质、触须流动、发光边缘
```

### 参考图类型

| 类型 | 说明 | 搜索平台 |
|------|------|---------|
| **直接参考** | 联想物本体 | Google Images |
| **跨界参考** | 其他领域的类似形态 | Pinterest、ArtStation |
| **艺术参考** | 已有的优秀设计作品 | ArtStation、Behance |
