# 第十一章：立体构成系统（核心）

## 11.1 立体构成的本质

> **设计不是画平面，而是构建三维空间中的体块关系。**

### 核心概念

```
立体构成 = 体块组合 + 方向变化 + 体积对比
2D是结果，3D是逻辑
```

### 设计常见问题（来自立体构成缺失）

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| **无体积感** | 只考虑轮廓，没考虑体块 | 先画体块盒子 |
| **元件拼凑感** | 只有体块，无体块变化 | 增加方向对比 |
| **无立体透视** | 缺乏朝向面变化 | 明确XYZ轴向 |

---

## 11.2 体块基础

### 三种基础体块

| 体块 | 形态 | 情感倾向 |
|------|------|---------|
| **方体（□）** | 立方体、长方体 | 稳定、工业、理性 |
| **球体（○）** | 球、椭球 | 柔和、有机、亲和 |
| **锥体（△）** | 圆锥、棱锥 | 攻击性、指向性、动态 |

### 体块的七大要素

```
1. 有体块（基础形态）
2. 有体块变化（形态渐变）
3. 有方向朝向（XYZ轴向）
4. 有体积对比（大小关系）
5. 有疏密变化（聚散节奏）
6. 有穿插关系（体块交叉）
7. 有层次叠加（前后遮挡）
```

---

## 11.3 方向对比（核心）

> **方向对比是立体构成的灵魂，没有方向变化就没有立体感。**

### 三轴方向

```
X轴：左右方向（横向）
Y轴：上下方向（纵向）
Z轴：前后方向（进深）
```

### 方向对比类型

| 对比类型 | 说明 | 视觉效果 |
|---------|------|---------|
| **横vs竖** | X轴vs Y轴 | 基础方向张力 |
| **平vs斜** | 水平vs倾斜 | 动态vs稳定 |
| **0°vs 45°vs 90°** | 角度渐变 | 节奏感、层次 |
| **朝向变化** | 面的朝向不同 | 三维空间感 |

### 角度变化示意

```
【角度对比】
0°（水平）  → 稳定、静态
45°（斜向） → 动态、过渡
90°（垂直） → 直立、力量

【组合示例】
0° + 45° = 稳定中带动感
45° + 90° = 从动态到直立
0° + 45° + 90° = 完整方向节奏
```

## 11.4 体积对比

> **体积对比创造视觉焦点和节奏感。**

### 体积对比类型

| 对比类型 | 说明 | 效果 |
|---------|------|------|
| **大vs小** | 主体块vs细节块 | 主次分明 |
| **厚vs薄** | 体积厚重vs轻薄 | 质感对比 |
| **满vs空** | 实心vs镂空 | 虚实对比 |

### 体积分布模式

| 分布模式 | 特点 | 适用 |
|---------|------|------|
| **顶重型** | 上大下小 | 不稳定、压迫感 |
| **底重型** | 上小下大 | 稳定、扎实 |
| **中重型** | 中间体积最大 | 圆润、可爱 |
| **均匀型** | 体积均匀分布 | 普通、中性 |
| **两极型** | 上下都大中间小 | 张力、对立 |

---

## 11.5 穿插关系

> **穿插让体块不再孤立，形成有机整体。**

### 穿插类型

| 类型 | 说明 | 示例 |
|------|------|------|
| **贯穿** | A体块完全穿过B体块 | 剑穿过盾牌 |
| **嵌入** | A体块部分嵌入B体块 | 宝石嵌入盔甲 |
| **缠绕** | A体块绕着B体块 | 藤蔓缠绕手臂 |
| **包裹** | A体块包住B体块 | 铠甲包裹身体 |

---

## 11.6 体块剪影测试

> **好的立体构成 = 从任何角度看剪影都有辨识度。**

### 测试方法

```
Step 1: 将设计转为正视剪影 → 检查轮廓
Step 2: 将设计转为侧视剪影 → 检查进深
Step 3: 将设计转为顶视剪影 → 检查空间占用
Step 4: 旋转检查 → 任意角度是否可识别
```

## 11.7 立体构成检验清单

- [ ] 有明确的体块划分？（不是平面涂色）
- [ ] 有体积对比？（大中小层次）
- [ ] 有方向对比？（0°/45°/90°变化）
- [ ] 有朝向面变化？（不同面朝向）
- [ ] 有穿插关系？（体块互相连接）
- [ ] 多角度剪影可识别？（不只正面好看）
- [ ] 体块层级清晰？（1-4级分明）
