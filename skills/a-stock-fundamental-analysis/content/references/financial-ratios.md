# 财务指标计算公式

## 一、盈利能力指标

### 1.1 毛利率 (Gross Margin)
```
毛利率 = (营业收入 - 营业成本) / 营业收入 × 100%
```

### 1.2 净利率 (Net Profit Margin)
```
净利率 = 净利润 / 营业收入 × 100%
```

### 1.3 营业利润率
```
营业利润率 = 营业利润 / 营业收入 × 100%
```

### 1.4 ROE（净资产收益率）
```
ROE = 净利润 / 净资产平均余额 × 100%
     = 净利润 / ((期初净资产 + 期末净资产)/2) × 100%

杜邦分析:
ROE = 净利率 × 资产周转率 × 权益乘数
    = (净利润/收入) × (收入/资产) × (资产/净资产)
```

### 1.5 ROA（资产收益率）
```
ROA = 净利润 / 总资产平均余额 × 100%
```

### 1.6 投入资本回报率 (ROIC)
```
ROIC = 税后净营业利润 / 投入资本 × 100%
     = EBIT × (1-税率) / (净资产 + 有息负债 - 现金)
```

## 二、成长性指标

### 2.1 营收增长率
```
营收同比增长率 = (本期营业收入 - 上年同期营业收入) / 上年同期营业收入 × 100%
```

### 2.2 净利润增长率
```
净利润同比增长率 = (本期净利润 - 上年同期净利润) / 上年同期净利润 × 100%
```

### 2.3 复合增长率 (CAGR)
```
CAGR = (终值/初值)^(1/n) - 1
其中 n = 年数
```

### 2.4 季度环比增长率
```
季度环比增长率 = (本季度值 - 上季度值) / 上季度值 × 100%
```

## 三、估值指标

### 3.1 市盈率 (PE)
```
PE = 每股市价 / 每股收益 (EPS)
每股收益(EPS) = 净利润 / 总股本
```

### 3.2 市净率 (PB)
```
PB = 每股市价 / 每股净资产
每股净资产 = 净资产 / 总股本
```

### 3.3 市销率 (PS)
```
PS = 总市值 / 总营业收入
每股销率 = 每股市价 / 每股营业收入
```

### 3.4 EV/EBITDA
```
EV = 市值 + 负债 - 现金
EBITDA = 净利润 + 利息 + 所得税 + 折旧 + 摊销
```

---

## 四、财务质量指标

### 4.1 现金流匹配度
```
现金流/净利润比 = 经营现金流净额 / 净利润
```
- 比值 > 1: 现金流充裕，盈利质量高
- 比值 0.8-1: 基本匹配
- 比值 < 0.6: 盈利质量存疑

### 4.2 收现比
```
收现比 = 销售商品提供劳务收到的现金 / 营业收入
```
- 理想值 ≈ 1.1（考虑增值税）

### 4.3 净现比
```
净现比 = 经营活动现金流净额 / 净利润
```

---

## 五、偿债能力指标

### 5.1 资产负债率
```
资产负债率 = 负债总额 / 资产总额 × 100%
```

### 5.2 流动比率
```
流动比率 = 流动资产 / 流动负债
```
- 理想值 > 1.5
- 制造业通常 1.2-2.0

### 5.3 速动比率
```
速动比率 = (流动资产 - 存货) / 流动负债
```
- 理想值 > 1

### 5.4 现金比率
```
现金比率 = 现金及现金等价物 / 流动负债
```

---

## 六、运营效率指标

### 6.1 存货周转天数
```
存货周转率 = 营业成本 / 平均存货
存货周转天数 = 365 / 存货周转率
```

### 6.2 应收账款周转天数
```
应收账款周转率 = 营业收入 / 平均应收账款
应收账款周转天数 = 365 / 应收账款周转率
```

### 6.3 总资产周转率
```
总资产周转率 = 营业收入 / 平均总资产
```

### 6.4 固定资产周转率
```
固定资产周转率 = 营业收入 / 平均固定资产
```

---

## 七、风险指标

### 7.1 商誉占净资产比例
```
商誉占比 = 商誉 / 净资产 × 100%
```
- 警戒线: > 30%

### 7.2 应收账款占营收比例
```
应收占比 = 应收账款 / 营业收入 × 100%
```

### 7.3 有息负债率
```
有息负债率 = 有息负债 / 总资产 × 100%
有息负债 = 短期借款 + 长期借款 + 应付债券
```

### 7.4 利息保障倍数
```
利息保障倍数 = EBIT / 利息支出
```

---

## 八、股东回报指标

### 8.1 分红率
```
分红率 = 股利分配 / 净利润 × 100%
```

### 8.2 股息率
```
股息率 = 年度每股股利 / 当前股价 × 100%
```

### 8.3 自由现金流
```
自由现金流 = 经营现金流 - 资本支出
```

---

## 九、综合评分计算模板

```
总分 = 盈利能力得分 × 25% + 成长性得分 × 20% + 估值得分 × 20% + 财务质量得分 × 20% + 风险控制得分 × 15%

各维度得分计算:
- 盈利能力: ROE(40%) + 净利率(30%) + 毛利率(30%)
- 成长性: 营收增速(50%) + 利润增速(50%)
- 估值: PE/PB/PS综合
- 财务质量: 现金流(40%) + 负债(30%) + 周转(30%)
- 风险控制: 商誉(33%) + 应收(33%) + 存货(34%)
```

## 十、财务报表关键科目说明

### 资产负债表重点科目
| 科目 | 关注点 |
|------|--------|
| 货币资金 | 是否被冻结、受限资金 |
| 应收账款 | 账龄分布、坏账计提 |
| 存货 | 跌价准备、周转情况 |
| 固定资产 | 在建工程转固时点 |
| 商誉 | 减值测试、减值风险 |
| 短期借款 | 银行授信、续贷能力 |
| 应付账款 | 供应商话语权 |

### 利润表重点科目
| 科目 | 关注点 |
|------|--------|
| 营收 | 真实性、季节性波动 |
| 毛利率 | 趋势变化、行业对比 |
| 销售费用 | 占比是否合理 |
| 管理费用 | 研发费用资本化 |
| 投资收益 | 占比、可持续性 |
| 资产减值 | 调节利润风险 |

### 现金流量表重点科目
| 科目 | 关注点 |
|------|--------|
| 销售商品收现 | 验证营收真实性 |
| 购买商品付现 | 与存货变动匹配 |
| 支付职工薪酬 | 人数与薪酬合理性 |
| 购建固定资产 | 产能扩张节奏 |
| 借款收到的现金 | 融资依赖度 |
