# 估值方法详解

## 一、市盈率（P/E）

### 计算公式
```
静态PE = 当前股价 / 上年度每股收益
滚动PE(TTM) = 当前股价 / 最近四个季度每股收益之和
动态PE = 当前股价 / 预计本年度每股收益
```

### 适用范围
- 成熟的盈利企业
- 周期性较弱的公司
- 行业可比性较强

### 评判标准
| PE区间 | 估值状态 | 备注 |
|--------|----------|------|
| < 10 | 较低估 | 需关注是否经营异常 |
| 10-20 | 合理偏低 | 价值投资区间 |
| 20-30 | 合理偏高 | 成长性溢价 |
| 30-50 | 较高估 | 高增长预期 |
| > 50 | 高估风险 | 需业绩支撑 |

### 注意事项
- 亏损企业PE不适用
- 周期性行业需用周期调整PE
- 金融股PE通常较低

---

## 二、市净率（P/B）

### 计算公式
```
PB = 当前股价 / 每股净资产
```

### 适用范围
- 金融类公司（银行、保险、券商）
- 资产重的企业（钢铁、房地产）
- 清算价值明确的公司

### 评判标准
| PB区间 | 估值状态 |
|--------|----------|
| < 1 | 破净，存在价值重估机会 |
| 1-2 | 合理区间 |
| 2-5 | 成长性溢价 |
| > 5 | 品牌/技术溢价 |

---

## 三、市销率（P/S）

### 计算公式
```
PS = 当前股价 / 每股营业收入
或
PS = 总市值 / 总营业收入
```

### 适用范围
- 成长型公司（尤其互联网、科技）
- 尚未盈利的成长期企业
- 营收稳定但利润波动大的公司

### 评判标准
| PS区间 | 适用情况 |
|--------|----------|
| < 1 | 价值区间 |
| 1-5 | 合理区间 |
| 5-10 | 成长溢价 |
| > 10 | 高增长预期 |

---

## 四、PEG估值法

### 计算公式
```
PEG = PE / 年化利润增长率 × 100
```

### 评判标准
| PEG值 | 估值状态 |
|--------|----------|
| < 0.5 | 极度低估 |
| 0.5-1 | 相对低估 |
| 1-1.5 | 合理 |
| 1.5-2 | 相对高估 |
| > 2 | 风险较高 |

### 注意事项
- 适用于成长股评估
- 增长率取3-5年复合增长率
- 需排除一次性收益影响

---

## 五、DCF估值法（现金流折现）

### 基本原理
```
企业价值 = Σ [ CFt / (1+r)^t ] + Terminal Value/(1+r)^n
```

### 参数说明
- CFt: 第t年的自由现金流
- r: 折现率（通常取WACC）
- n: 预测期
- Terminal Value: 永续价值

### 简化版本（两阶段）
```
内在价值 = 高增长期现金流现值 + 永续价值现值
```

---

## 六、EV/EBITDA估值

### 计算公式
```
EV/EBITDA = 企业价值 / 息税折旧摊销前利润

其中:
EBITDA = 净利润 + 利息 + 税 + 折旧 + 摊销
EV = 市值 + 负债 - 现金
```

### 适用范围
- 资本密集型企业
- 周期性行业
- 并购估值参考

### 评判标准
| EV/EBITDA | 估值状态 |
|-----------|----------|
| < 5 | 较低估 |
| 5-10 | 合理 |
| 10-15 | 较高估 |
| > 15 | 高估 |

---

## 七、估值方法选择指南

| 行业类型 | 首选估值方法 | 辅助方法 |
|----------|-------------|----------|
| 银行 | PB | PE、EV |
| 保险 | PEV | PB |
| 券商 | PB | PE |
| 地产 | NAV | PB、PE |
| 消费 | PE | PEG |
| 科技 | PS | PE、PEG |
| 医药 | PE | PS |
| 周期 | PB | EV/EBITDA |
