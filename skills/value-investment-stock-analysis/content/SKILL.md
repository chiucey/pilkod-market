# 价值投资股票分析技能

## 核心工作流程

### 第一步：股票筛选

使用以下**准入门槛**筛选符合条件的价值投资标的：

| 指标 | 筛选标准 | 数据来源 |
|------|----------|----------|
| 市盈率 (PE) | ≤ 行业均值 | 东方财富/AkShare |
| 净资产收益率 (ROE) | > 15% | 财务报告 |
| 资产负债率 | < 60% | 财务报告 |
| 均线趋势 | 50日均线 > 150日均线 | 行情数据 |
| 总市值 | > 200亿 | 市场数据 |

**执行顺序**：市值初筛 → 技术面筛选 → 财务筛选 → 估值筛选

### 第二步：精细化内在价值估算

采用**三层动态估值模型**，将筛选指标融入质量因子计算：

```
内在价值 = EPS × 行业合理PE × 质量综合因子 × 成长调整因子 × 行业趋势因子
```

#### 质量综合因子（基于筛选指标）

| 指标 | 表现 | 因子调整 |
|------|------|----------|
| **ROE** | > 25% | +15% |
| | 20%-25% | +10% |
| | 15%-20% | +5% |
| | < 15% | -10% (不通过) |
| **资产负债率** | < 40% | +8% |
| | 40%-50% | +5% |
| | 50%-60% | 0% |
| **市盈率相对** | PE < 行业均值×0.7 | +10% |
| | PE < 行业均值 | +5% |
| | PE = 行业均值 | 0% |
| | PE > 行业均值 | -5% |
| **均线形态** | 50日 > 150日 >10% | +8% |
| | 50日 > 150日 5-10% | +5% |
| | 50日 > 150日 <5% | +2% |
| **市值规模** | > 1000亿 | +5% |
| | 500-1000亿 | +3% |
| | 200-500亿 | 0% |

#### 成长调整因子（基于利润增长率）

| 利润增长率 (YoY) | 因子 |
|------------------|------|
| G > 40% | 1.4 |
| 30% < G ≤ 40% | 1.3 |
| 20% < G ≤ 30% | 1.2 |
| 10% < G ≤ 20% | 1.1 |
| 5% < G ≤ 10% | 1.0 |
| 0% < G ≤ 5% | 0.95 |
| -10% < G ≤ 0% | 0.85 |
| G ≤ -10% | 0.7 |

#### 行业趋势研判因子

| 行业趋势研判 | 因子 |
|-------------|------|
| 上升周期/政策强支持 | 1.15 |
| 稳定增长期 | 1.05 |
| 行业平均/中性 | 1.0 |
| 成熟/饱和期 | 0.95 |
| 下行周期/政策压制 | 0.85 |

### 第三步：买卖建议

基于内在价值计算安全边际：

```
低估买入线 = 内在价值 × (1 - 安全边际系数)
建议卖出线 = 内在价值 × (1 + 乐观系数)
```

| 内在价值折溢价 | 操作建议 |
|---------------|----------|
| 现价 < 低估买入线 | ★★★★★ 强烈买入 |
| 现价 < 内在价值×0.9 | ★★★★ 买入 |
| 现价 < 内在价值 | ★★★ 持有/逢低买入 |
| 现价 ≈ 内在价值±10% | ★★ 持有观望 |
| 现价 > 内在价值×1.1 | ★ 谨慎/持有 |
| 现价 > 建议卖出线 | ☆ 卖出/减仓 |

## 数据源配置

优先使用以下开源数据源（按优先级排序）：

1. **AkShare** - A股数据全面，免费开源
2. **东方财富API** - 免费接口，无需密钥
3. **Tushare** - 财务数据完整（需注册获取token）

## 注意事项

1. **数据时效性**：财务报表季度更新，分析时标注数据截止日期
2. **行业分类**：使用申万行业或证监会行业分类
3. **异常处理**：单季度数据异常时使用TTM（滚动12个月）数据
4. **免责声明**：分析结果仅供参考，不构成投资建议
