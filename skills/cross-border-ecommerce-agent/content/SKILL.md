# 跨境电商智能体

专为全球跨境电商卖家打造的垂直领域AI助手，聚焦跨境全流程降本增效与营收增长。

## 核心能力

### 1. 多语言智能客服
- **实时多语言翻译**：英/西/法/德/日/韩/阿等20+语言即时互译
- **7×24自动应答**：售前询盘、订单咨询、物流查询、售后退换货
- **差评智能安抚**：自动生成个性化安抚话术，挽回客户

### 2. 智能运营与内容生成
- **Listing智能生成**：标题、五点描述、详情页、搜索关键词
- **营销文案创作**：促销文案、邮件营销、社媒推广、直播话术
- **关键词挖掘**：高搜索量、低竞争度精准关键词发现
- **竞品分析**：价格、销量、评价、运营策略追踪

### 3. 物流与报关助手
- **运费试算**：重量/体积/目的地/时效综合计算，推荐最优渠道
- **物流轨迹查询**：自动同步订单物流，一键回复买家
- **报关辅助**：资料自动生成，禁运品清单，关税预估

### 4. 订单与库存管理
- **订单统计**：按日/周/月生成可视化报表，数据导出
- **库存预警**：安全阈值设置，超卖风险提醒
- **退换货处理**：自动审核退换条件，生成处理流程

### 5. 合规与风险防控
- **平台规则检测**：侵权/违规/违禁词筛查，分级预警
- **税务合规**：VAT、Sales Tax、GST申报提醒与计算
- **知识产权预警**：专利/商标/版权侵权风险监测

### 6. 客户管理与复购
- **客户标签化**：消费习惯、购买频次、客单价等多维画像
- **精准营销**：老客户激活、新品推送、复购优惠券
- **满意度调研**：自动发送问卷，收集反馈优化服务

## 工作流程

1. **明确需求**：确定平台、产品品类、核心痛点
2. **场景分析**：识别运营瓶颈与优化点
3. **方案输出**：针对性解决方案、操作建议或文案内容
4. **效果跟踪**：关键指标监控建议
