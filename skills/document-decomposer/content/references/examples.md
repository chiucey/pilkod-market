# 文档解构示例集

本文档提供各类文档类型的分析示例，展示不同场景下的解构方法。

## 示例 1：法律合同分析

### 输入文档（节选）

```
第四章 保密条款

第十七条 保密义务
1. 双方应对在合作过程中知悉的对方商业秘密负有保密义务。
2. 商业秘密包括但不限于：技术信息、经营信息、财务信息、客户信息等。
3. 本保密义务自合同签订之日起生效，至合同终止后两年内仍然有效。

第十八条 保密例外
下列情形不视为违反保密义务：
1. 法律法规强制要求披露；
2. 已公开的信息（非因违约导致）；
3. 独立研发获取的相同或类似信息。
```

### 输出示例（详细摘要）

```markdown
## 📋 第四章：保密条款

### 核心规则
本章节规定了双方在合作期间及之后对商业秘密的保护责任。

---

### 第十七条 保密义务（必须遵守）

**保密对象**：四大类商业秘密
| 类别 | 具体内容 |
|------|----------|
| 技术信息 | 生产工艺、配方、技术诀窍等 |
| 经营信息 | 战略规划、营销方案、定价策略 |
| 财务信息 | 成本结构、利润数据、投融资计划 |
| 客户信息 | 客户名单、需求特征、交易记录 |

**保护期限**：很长
- 合作期间：全程保密
- 合作结束后：继续保密2年

---

### 第十八条 保密例外（合法不保密的情况）

⚠️ **这三种情况可以不用保密：**

| 情况 | 通俗解释 |
|------|----------|
| 法律要求 | 政府/法院强制要求必须说 |
| 已经公开 | 信息上了新闻或官网（但不包括被你泄露的） |
| 自己研发 | 你自己研究出来的，不是偷来的 |

**实战提示**：如果对方引用本条，主张"信息已公开"，需要提供公开渠道的证据。

---

### 💡 谈判建议

1. **建议延长保密期**：两年可能不够，建议谈3-5年
2. **建议扩大定义**：当前定义较宽泛，可考虑具体列举
3. **建议增加竞业限制**：防止对方用你的秘密去服务竞争对手
```

## 示例 2：技术文档分析

### 输入文档（节选）

```
## API调用指南

### 认证方式
本API使用OAuth 2.0协议进行身份认证，支持四种授权模式：
- 授权码模式（Authorization Code）
- 隐式授权模式（Implicit Grant）
- 客户端凭证模式（Client Credentials）
- 资源所有者凭证模式（Resource Owner Password Credentials）

### 调用频率限制
| 等级 | 每分钟 | 每天 |
|------|--------|------|
| 免费版 | 60次 | 1000次 |
| 专业版 | 600次 | 50000次 |
| 企业版 | 6000次 | 不限 |

### 错误代码
- 400：请求参数错误
- 401：未授权/Token失效
- 403：权限不足
- 429：请求过于频繁
- 500：服务器内部错误
```

### 输出示例（通俗改写）

```markdown
## 🔐 如何调用这个API

### 第一步：证明"你是你"（认证）

就像进公司需要刷门禁卡，调用API也需要"身份卡"。

我们支持两种最常用的方式：

| 方式 | 适用场景 | 难度 |
|------|----------|------|
| 授权码模式 | 用户要登录的系统（最安全） | ⭐⭐⭐ |
| 客户端凭证 | 服务器调用服务器 | ⭐⭐ |

**通俗理解**：
- 授权码模式 = 你刷门禁卡，保安看到是你才开门
- 客户端凭证 = 两个服务器之间自动交换密码，不需要人操作

---

### 第二步：别打太快（速率限制）

系统会限制你的调用频率，就像高速公路限速：

| 套餐 | 相当于... | 每天相当于... |
|------|----------|---------------|
| 免费版 | 1秒1次 | 不到2小时就用完 |
| 专业版 | 10秒1次 | 可以用一整天 |
| 企业版 | 随便用 | 土豪专属 |

**⚠️ 防止被限流的技巧**：
- 批量操作，一次处理多条
- 本地缓存，不重复请求
- 错峰调用，避开高峰时段

---

### 第三步：看懂报错（错误处理）

当出错时，系统会返回一个数字：

| 代码 | 什么意思 | 怎么办 |
|------|----------|--------|
| 400 | 你的请求格式不对 | 检查参数是否完整、格式是否正确 |
| 401 | 你的"门禁卡"失效了 | 重新获取Token |
| 403 | 你没有权限 | 联系管理员开通权限 |
| 429 | 你打太快了 | 等1分钟再试 |
| 500 | 对方服务器出问题了 | 等一会再试，或联系技术支持 |

**代码示例**：
```javascript
// 推荐的错误处理方式
try {
  const result = await api.call();
} catch (error) {
  if (error.code === 401) {
    // 重新登录获取新Token
    await refreshToken();
  } else if (error.code === 429) {
    // 等1分钟再试
    await sleep(60000);
  }
}
```
```

## 示例 4：商业报告分析

### 输入文档（节选）

```
公司2024年第三季度财报摘要

营收情况：
- 总营收：128.5亿元，同比增长23%
- 线上业务：78.3亿元，占比61%，同比增长35%
- 线下业务：50.2亿元，占比39%，同比增长8%

利润情况：
- 毛利率：42.3%，同比提升2.1个百分点
- 净利润：15.8亿元，同比增长41%

业务亮点：
1. 付费会员突破5000万，同比增长40%
2. 核心产品DAU达2.1亿，用户粘性指数提升15%
3. 国际化业务收入占比首次超过20%
```

### 输出示例（结构化摘要）

```markdown
## 📊 Q3财报速览：营收利润双增长

### 一句话结论
✅ 业绩超预期，保持高速增长态势

---

### 📈 核心数据

| 指标 | 数值 | 表现 |
|------|------|------|
| 总营收 | 128.5亿 | ⬆️ 增长23% |
| 净利润 | 15.8亿 | ⬆️ 增长41% |
| 付费会员 | 5000万 | ⬆️ 增长40% |

---

### 🔍 关键发现

**1. 线上业务是增长主引擎**
- 线上占比61%，贡献了大部分增量
- 线上增长35%，远超线下8%
- **意味着**：公司数字化转型成功

**2. 盈利能力显著提升**
- 毛利率42.3%，比去年高2.1个百分点
- 净利润增速（41%）远超营收增速（23%）
- **意味着**：规模效应显现，赚钱效率提高

**3. 国际化开局良好**
- 海外收入占比首次超20%
- **意味着**：不再依赖单一市场

---

### ⚠️ 需要关注的风险

1. **线下增长放缓**：仅8%，需要加大投入
2. **竞争加剧**：同行业绩普遍增长，价格战可能升温
3. **宏观经济**：消费降级可能影响付费意愿

---

### 📌 投资评级（模拟）

| 维度 | 评分 | 说明 |
|------|------|------|
| 成长性 | ⭐⭐⭐⭐⭐ | 各项指标高速增长 |
| 盈利能力 | ⭐⭐⭐⭐ | 毛利率持续提升 |
| 确定性 | ⭐⭐⭐⭐ | 核心业务稳健，国际化提供增量 |
| 风险性 | ⭐⭐⭐ | 需要关注竞争和宏观环境 |

**综合建议**：维持看好，建议逢低配置
```
