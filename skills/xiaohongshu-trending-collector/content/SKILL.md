# 小红书爆款内容采集与分析

## Overview

根据用户提供的选题关键词，自动爬取小红书网页内容，筛选高互动量的爆款笔记，计算各项数据指标，并生成专业的数据分析表格与洞察报告。整个流程涵盖需求确认、数据爬取、数据清洗与计算、行业分类、报告生成和数据导出。

## 完整工作流程

### 步骤1：获取用户选题需求

1. 询问用户想要采集的**选题关键词**（如：穿搭、美妆、职场、副业等）
2. 确认用户的**筛选标准**（默认：点赞+收藏 ≥ 500）
3. 确认需要采集的**笔记数量**（建议：20-50条）

### 步骤2：爬取小红书内容

使用 `interact_with_website` 工具访问小红书搜索页面进行数据采集。

**2.1 搜索结果页采集**
1. 访问 `https://www.xiaohongshu.com/search_result?keyword={用户关键词}&source=web_search_result_notes`
2. 等待页面加载完成（2-3秒）
3. 滚动页面加载更多内容（滚动间隔1-2秒，随机滚动距离）
4. 收集所有笔记卡片的基础信息
5. 提取笔记链接列表

**2.2 笔记详情页采集**
1. 依次访问每个笔记链接
2. 等待详情页加载（2秒）
3. 提取完整数据（见下方"采集字段"）
4. 返回或访问下一个链接
5. 每次请求间隔 2-3 秒

**采集字段：**
- 笔记标题
- 发布时间
- 点赞数
- 收藏数
- 评论数
- 作者昵称
- 作者粉丝数
- **作品链接**（笔记详情页URL，格式：`https://www.xiaohongshu.com/explore/笔记ID`）
- **对标账号链接**（作者主页URL，格式：`https://www.xiaohongshu.com/user/profile/用户ID`）

### 步骤3：数据清洗

- 去除重复笔记
- 处理异常数据（如点赞数为0、数据缺失等）
- 统一数据格式（如将"1.2w"转换为12000）
- 对异常数据进行标注说明

### 步骤4：数据筛选与指标计算

**筛选条件：**
- 点赞数 + 收藏数 ≥ 500（可根据用户需求调整）

**对每条笔记计算以下指标：**

```
收藏比 = (收藏数 / 点赞数) × 100%
评论比 = (评论数 / 点赞数) × 100%
互动总量 = 点赞数 + 收藏数 + 评论数
平均数据 = 互动总量 / 3
```

**对每个账号计算：**
- 该账号所有笔记的平均互动量
- 入池差 = 当前笔记互动量 - 账号平均互动量

**格式要求：**
- 所有百分比保留1位小数
- 大数字使用简化显示（如1.2w、3.5k）

### 步骤5：行业分类

根据笔记标题和内容关键词进行行业分类：

| 行业 | 关键词示例 |
|------|-----------|
| 美妆护肤 | 化妆、护肤、口红、粉底、眼影、美容 |
| 穿搭时尚 | 穿搭、outfit、ootd、搭配、服装、时尚 |
| 美食探店 | 美食、探店、餐厅、食谱、做饭、烹饪 |
| 旅行攻略 | 旅行、攻略、景点、酒店、出行、旅游 |
| 职场成长 | 职场、工作、简历、面试、副业、技能 |
| 生活方式 | 家居、收纳、好物、日常、vlog、生活技巧 |
| 母婴育儿 | 宝宝、育儿、母婴、辅食、带娃、亲子 |
| 健身运动 | 健身、减肥、瑜伽、运动、keep |
| 数码科技 | 数码、手机、电脑、测评、开箱、电子产品 |
| 其他 | 无法归类的内容 |

### 步骤6：生成数据洞察

分析数据并生成以下洞察：
- **爆款规律**：高互动笔记的共同特征
- **最佳发布时间**：根据发布时间分析最佳发布时段
- **标题特征**：高点赞笔记的标题模式
- **对标账号推荐**：粉丝量适中但数据优秀的账号

### 步骤7：生成爆款选题表格并导出

生成包含以下字段的 Markdown 表格：

| 字段 | 说明 |
|------|------|
| 选题行业（方向） | 根据内容分析的行业分类 |
| 标题 | 笔记完整标题 |
| 作品链接 | 笔记详情页链接（https://www.xiaohongshu.com/explore/笔记ID） |
| 发布时间 | 笔记发布日期 |
| 点赞 | 点赞数量 |
| 收藏 | 收藏数量 |
| 评论 | 评论数量 |
| 收藏比 | 收藏/点赞百分比 |
| 评论比 | 评论/点赞百分比 |
| 对标账号名称 | 作者昵称 |
| 账号链接 | 对标账号的小红书主页链接（https://www.xiaohongshu.com/user/profile/用户ID） |
| 账号粉丝 | 作者粉丝数 |
| 平均数据 | 互动平均值 |
| 入池差 | 与账号均值的差异 |

**导出方式（根据用户需求）：**
1. **Markdown 表格**：直接在对话中展示
2. **CSV 文件**：保存到 `/workspace/output/` 目录
3. **Excel 文件**：如用户需要，生成 .xlsx 格式

## 小红书爬取策略指南

### 页面元素定位

#### 搜索结果列表
- 笔记卡片容器：`.note-item` 或 `[data-note-id]`
- 笔记标题：`.title` 或 `.note-title`
- 点赞数：`.like-count` 或包含心形图标的元素
- 作者信息：`.author` 或 `.user-info`

#### 笔记详情页
- 标题：`#detail-title` 或 `.title`
- 点赞数：`.like-count`
- 收藏数：`.collect-count`
- 评论数：`.comment-count`
- 发布时间：`.date` 或 `.publish-time`
- 作者昵称：`.author-name`
- 粉丝数：`.fans-count`

### 数据提取模板

```json
{
  "title": "笔记标题",
  "publish_time": "2026-01-20",
  "likes": 23000,
  "collects": 18000,
  "comments": 892,
  "author_name": "作者昵称",
  "author_fans": 500000,
  "note_url": "https://www.xiaohongshu.com/explore/xxx"
}
```

### 数据格式转换

小红书数字显示格式转换：
- `1.2w` → `12000`
- `3.5k` → `3500`
- `892` → `892`
- `1.2万` → `12000`

### 反爬虫注意事项

1. **请求频率控制**
   - 页面间隔：2-3秒
   - 滚动间隔：1-2秒
   - 单次采集不超过50条

2. **模拟用户行为**
   - 随机滚动距离
   - 随机点击间隔
   - 正常的鼠标移动

3. **异常处理**
   - 验证码出现：暂停并通知用户
   - 页面加载失败：重试3次
   - 数据缺失：标记并跳过

### 最佳采集时间

- 工作日：上午10-12点、下午2-4点
- 周末：下午时段
- 避开高峰时段以减少反爬风险

## 交互原则

1. **主动引导**：如用户未提供完整信息，主动询问选题关键词
2. **进度反馈**：爬取过程中实时告知用户进度
3. **数据可视化**：尽可能以表格形式呈现数据
4. **建议输出**：根据数据给出选题建议和对标账号推荐

## 常见问题处理

- **页面加载失败**：重试3次或更换搜索关键词
- **数据量不足**：扩大搜索范围或降低筛选标准
- **账号粉丝数获取困难**：标注为"待补充"并继续采集其他数据
- **验证码出现**：暂停并通知用户
- **数据缺失**：标记并跳过
