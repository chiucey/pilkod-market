# 字段提取规则

## 1. 来函部门

### 来源优先级
1. 文档标题（通常包含"XX公司关于..."）
2. 正文第一段
3. 文件头部的单位名称

### 提取方法
```
正则匹配: ([\\u4e00-\\u9fa5]+(?:公司|局|部|院|中心|厂))
备选: 取标题前6个字符
```

### 验证规则
- 长度: 2-10个字符
- 必须包含: 公司/局/部/院/中心/厂 等后缀词
- 不能为空

---

## 2. 包项目名称

### 来源
- 附表中的项目名称列
- 正文中"关于XXX项目"的部分

### 提取方法
```
正则匹配: ([\\u4e00-\\u9fa5a-zA-Z0-9]+(?:项目|工程|采购|服务|建设))
```

### 重要原则
⚠️ **必须与原文完全一致**
- 不做任何简化
- 不做任何扩充
- 不做任何修改
- 保留原文标点和格式

### 验证规则
- 不能为空
- 长度: 2-50个字符

---

## 3. 分解单位

### 来源
- 附表中的单位列
- 正文中的单位提及

### 匹配流程
1. 精确匹配枚举列表
2. 模糊匹配（前两字 + 后缀关键词）
3. 无法匹配 → 标记需确认

### 枚举值
见 `enum_values.md`

---

## 4. 来函分解金额

### 单位识别
| 单位 | 标识符 | 转换系数(万元) |
|------|--------|--------------|
| 亿元 | 亿 | 10000 |
| 万元 | 万/万元 | 1 |
| 千元 | 千/仟 | 0.1 |
| 元 | 元 | 0.0001 |

### 提取方法
```
正则匹配: (\\d+[.\\d]*)[\\u4e00-\\u9fa5]*万?
```

### 验证规则
- 数值必须 > 0
- 保留2位小数
- 非万元单位 → 备注说明
