# 来函文档提取器

## 功能概述

从指定文件夹中提取多种格式文档的来函信息，生成符合固定模板的Excel汇总统计表。

## 支持文档格式

| 格式 | 扩展名 | 说明 |
|------|--------|------|
| PDF | .pdf | 主力格式，支持含HTML表格的复杂布局 |
| Excel | .xlsx, .xls | 直接读取单元格数据 |
| Word | .docx | 读取段落和表格 |

## 支持部门格式

来函部门自动识别以下格式：
- XX部（如：科技部、财务部、人力部）
- XX办（如：特高压办、办公室）
- XX中心（如：营销中心、后勤中心）
- XX会（如：工会）
- XX联（如：统战联）
- XX指挥部

## 输出模板

### 来函明细统计表（Sheet: 来函明细）

| 字段 | 说明 |
|------|------|
| 来函部门 | 从文档标题提取，自动识别格式 |
| 包项目名称 | 从文档附表提取，与原文件完全一致 |
| 分解单位 | 模糊匹配到28个枚举值之一 |
| 来函分解金额(万元) | 从附表提取，单位万元 |
| 数据来源 | 原始文件名 |
| 备注 | 备用字段 |

### 来函汇总统计表（Sheet: 来函汇总）

| 字段 | 说明 |
|------|------|
| 来函部门 | 汇总后的部门 |
| 来函单位 | 分解单位 |
| 项目数量 | 该部门的项目数量 |
| 总金额(万元) | 该部门汇总金额 |

### 模糊匹配清单（Sheet: 模糊匹配清单）

记录所有原始单位名称到枚举值的模糊匹配结果，供人工确认。

|------|----------|----------|
| 1 | 国网XX供电公司 | 100 |
```

```

## 执行命令

## 注意事项

1. **严格保真**：提取的项目名称必须与原文完全一致
2. **模糊匹配**：分解单位自动匹配到枚举值，存疑数据在清单中标注
3. **多表格合并**：同一项目的分散表格会自动合并
4. **去重处理**：自动去除完全重复的记录
