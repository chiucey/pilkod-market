# Pipeline 检查点配置

## 检查点层级

### FULL (完整检查)
- 所有验证阶段执行
- 最多轮次的评审
- 最严格的质量标准
- 适用: 重要发表、学位论文、基金申请

### SLIM (精简检查)
- 关键验证保留
- 评审轮次减少
- 适用: 快速草稿、会议投稿、初步研究

### MANDATORY (强制检查)
- 仅强制项验证
- 无评审循环
- 适用: 时间受限场景、探索性研究

---

## 10 阶段流程检查点

### 阶段 1: RESEARCH (深度研究)

**检查点类型**: MANDATORY

**检查项**:
- [ ] 研究问题明确 (FINER 框架)
- [ ] 检索策略记录
- [ ] 至少 10 篇核心文献
- [ ] 来源可信度评估

**输出**: 研究问题文档 + 文献列表

---

### 阶段 2: WRITE (论文写作)

**检查点类型**: MANDATORY

**检查项**:
- [ ] 大纲批准
- [ ] 所有章节草稿完成
- [ ] 引用格式一致
- [ ] 图表质量检查

**输出**: 完整论文草稿

---

### 阶段 2.5: INTEGRITY (诚信验证)

**检查点类型**: FULL

**Phase A: 引用验证**
- [ ] 每条引用可在线检索
- [ ] DOI/URL 有效性
- [ ] 掠夺性期刊检测
- [ ] 幽灵引用识别

**Phase B: 数据验证**
- [ ] 统计数据可重复
- [ ] 方法描述完整
- [ ] 样本量合理性

**Phase C: 声明验证**
- [ ] 主要声明有据可查
- [ ] 夸大陈述识别
- [ ] 因果关系陈述适当

**Phase D: 逻辑验证**
- [ ] 论点结构检查
- [ ] 逻辑谬误识别
- [ ] 矛盾点检测

**Phase E: 合规检查**
- [ ] 伦理审批确认
- [ ] 利益冲突披露
- [ ] AI 使用披露

**输出**: 诚信验证报告

---

### 阶段 3: REVIEW (同行评审) - 第1轮

**检查点类型**: FULL

**评审维度**:
1. 期刊匹配度
2. 创新性与意义
3. 方法论质量
4. 文献覆盖
5. 理论与实践价值
6. 逻辑严谨性

**智能体参与**:
- 主编
- 方法论评审
- 领域评审
- 视角评审
- 魔鬼代言人

**输出**: 评审报告 + 0-100 评分

---

### Socratic 修改教练

**检查点类型**: MANDATORY

**教练内容**:
- 解析审稿意见
- 制定修改策略
- 逐点回复指导

**输出**: Revision Roadmap

---

### 阶段 4: REVISE (修改) - 第1轮

**检查点类型**: SLIM

**检查项**:
- [ ] 审稿意见逐条回应
- [ ] 修改内容标注
- [ ] 未修改项合理说明

**输出**: 修改后稿件

---

### 阶段 3': RE-REVIEW (复审)

**检查点类型**: SLIM

**评审重点**:
- 修改充分性
- 新引入问题
- 是否达到接受标准

**输出**: 复审报告 + 修改建议

---

### 阶段 4': RE-REVISE (再次修改)

**检查点类型**: MANDATORY

**输出**: 最终修改稿

---

### 阶段 4.5: FINAL INTEGRITY (最终验证)

**检查点类型**: FULL

**检查项**:
- [ ] 无退化现象
- [ ] 所有问题已解决
- [ ] 最终完整性确认

**输出**: 最终诚信报告

---

### 阶段 5: FINALIZE (定稿)

**检查点类型**: MANDATORY

**输出格式**:
- Markdown (源文件)
- DOCX (Word 格式)
- LaTeX (可选)
- PDF (编译输出)

**检查项**:
- [ ] 格式合规
- [ ] 图表编号
- [ ] 参考文献完整
- [ ] 页眉页脚
- [ ] 声明页

---

### 阶段 6: PROCESS SUMMARY (流程总结)

**检查点类型**: SLIM

**6 维度协作质量评分**:
1. 研究问题清晰度 (1-100)
2. 文献覆盖完整性 (1-100)
3. 方法论严谨性 (1-100)
4. 写作质量 (1-100)
5. 修改响应度 (1-100)
6. 整体协作效率 (1-100)

**输出**: 流程总结报告 + 质量评分

---

## 协作质量评估标准

### 研究问题清晰度
| 分数 | 标准 |
|------|------|
| 90-100 | FINER 全要素满足，研究边界清晰 |
| 70-89 | 大部分要素满足，偶有模糊 |
| 50-69 | 研究问题存在但不够聚焦 |
| <50 | 研究问题不明确或过于宽泛 |

### 文献覆盖完整性
| 分数 | 标准 |
|------|------|
| 90-100 | 核心文献全覆盖，gap 识别准确 |
| 70-89 | 主要文献覆盖，个别遗漏 |
| 50-69 | 文献覆盖不完整 |
| <50 | 文献调研明显不足 |

### 方法论严谨性
| 分数 | 标准 |
|------|------|
| 90-100 | 设计严谨，无明显偏倚 |
| 70-89 | 设计合理，有轻微局限 |
| 50-69 | 方法存在明显问题 |
| <50 | 方法论缺陷严重 |

### 写作质量
| 分数 | 标准 |
|------|------|
| 90-100 | 表达清晰，逻辑严密，格式规范 |
| 70-89 | 表达流畅，偶有不清 |
| 50-69 | 写作存在问题需大量修改 |
| <50 | 写作质量差，需重写 |

### 修改响应度
| 分数 | 标准 |
|------|------|
| 90-100 | 审稿意见全部响应，修改充分 |
| 70-89 | 大部分意见响应，部分未完成 |
| 50-69 | 响应不完整 |
| <50 | 未实质性响应审稿意见 |

### 整体协作效率
| 分数 | 标准 |
|------|------|
| 90-100 | 流程顺畅，迭代高效 |
| 70-89 | 流程基本顺畅 |
| 50-69 | 流程存在较多问题 |
| <50 | 流程混乱，效率低下 |

---

## 决策阈值

### 基于评分的决策
| 总分范围 | 决策 | 建议 |
|---------|------|------|
| ≥80 平均 | 接受 | 可直接投稿 |
| 65-79 平均 | 小修 | 修改后可接受 |
| 50-64 平均 | 大修 | 需实质性修改 |
| <50 平均 | 拒稿 | 建议重写 |

### 关键检查项否决
以下任一情况触发 MANDATORY 流程重启:
- 诚信验证发现 >5 个严重问题
- 方法论存在根本性缺陷
- 剽窃/造假指控
