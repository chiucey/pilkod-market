# 学术引用格式规范

## 支持的引用格式

本技能支持以下引用格式的生成和转换：
- APA 7.0 (默认)
- IEEE
- Chicago (Notes & Author-Date)
- MLA
- Vancouver

---

## APA 7.0 (美国心理学会 第7版)

### 基本格式

#### 期刊文章
```
Author, A. A., & Author, B. B. (Year). Title of article. Title of Periodical, volume number(issue number), page-page. https://doi.org/xxxxx
```

**示例**:
```
Smith, J. A., & Johnson, M. B. (2023). The impact of AI on academic research. Journal of Educational Technology, 45(2), 123-145. https://doi.org/10.1000/jed.2023.001
```

#### 书籍
```
Author, A. A. (Year). Title of work: Capital letter also for subtitle. Publisher.
```

**示例**:
```
Brown, K. M. (2022). Academic writing for graduate students (3rd ed.). University Press.
```

#### 书籍章节
```
Author, A. A. (Year). Title of chapter. In E. E. Editor (Ed.), Title of book (pp. xx-xx). Publisher.
```

**示例**:
```
Davis, L. R. (2021). Research methodology. In M. K. Wilson (Ed.), Handbook of academic research (pp. 45-78). Academic Press.
```

#### 网络资源
```
Author, A. A. (Year, Month Day). Title of page. Site Name. URL
```

**示例**:
```
World Health Organization. (2023, March 15). Global health statistics 2023. https://www.who.int/data/gho
```

---

### 文中引用格式

#### 直接引用
- **少于40词**: 融入句子
  ```
  According to Smith (2023), "the methodology is innovative" (p. 45).
  ```

- **40词或以上**: 单独段落，缩进
  ```
  Smith (2023) argued:

  > The methodology presented in this study represents a paradigm shift in how researchers approach data collection and analysis. The implications extend beyond the immediate field of study to impact broader research practices. (p. 45)
  ```

#### 二次引用
```
Johnson (2022) as cited in Smith (2023) argued that...
```

#### 作者信息
- 1-2位作者: 全部列出
  ```
  (Smith & Johnson, 2023)
  ```
- 3位及以上作者: 列出第一位后加 et al.
  ```
  (Smith et al., 2023)
  ```

## IEEE 格式

### 引用编号
- 按文中出现顺序编号
- 使用方括号 `[1]`
- 可在句末或引用后

### 基本格式

#### 期刊文章
```
[1] A. A. Author, "Title of article," Title of Periodical, vol. X, no. X, pp. X-X, Month Year.
```

#### 书籍
```
[1] A. A. Author, Title of Book. City, Country: Publisher, Year.
```

#### 会议论文
```
[1] A. A. Author, "Title of paper," in Proc. Conference Name, Year, pp. X-X.
```

## Chicago 格式

### Author-Date 格式

#### 期刊文章
```
Author. Year. "Article Title." Journal Title volume (issue): pages. DOI.
```

#### 书籍
```
Author. Year. Title of Book. City: Publisher.
```

### Notes 格式

#### 期刊文章 (首次引用)
```
Author, "Article Title," Journal Title volume, no. issue (Year): pages.
```

#### 书籍
```
Author, Title of Book (City: Publisher, Year), pages.
```

---

## MLA 格式

### 基本格式

#### 期刊文章
```
Author. "Article Title." Journal Title, vol. X, no. X, Year, pp. X-X.
```

#### 书籍
```
Author. Title of Book. Publisher, Year.
```

### 文中引用
- 引用页码
  ```
  (Smith 45)
  ```
- 作者名已在句中出现
  ```
  Smith argues that... (45)
  ```

---

## Vancouver 格式

### 期刊文章
```
Author(s). Article title. Journal name. Year;volume(issue):pages.
```

**示例**:
```
Smith JA, Johnson MB. The impact of AI on academic research. J Educ Technol. 2023;45(2):123-145.
```

### 作者数量
- 1-6位: 全部列出
- 7位及以上: 前6位后加 et al.

## 引用转换规则

### 期刊名称
| 格式 | 处理 |
|------|------|
| APA | 斜体 |
| IEEE | 缩写 |
| Chicago | 斜体 |
| MLA | 斜体 |
| Vancouver | 缩写 |

### 作者格式
| 格式 | 示例 |
|------|------|
| APA | Smith, J. A. |
| IEEE | J. A. Smith |
| Chicago | Smith, James A. |
| MLA | Smith, James A. |
| Vancouver | Smith JA |

### 年份位置
| 格式 | 位置 |
|------|------|
| APA | 作者后 |
| IEEE | 标题后 |
| Chicago | 作者后 |
| MLA | 标题后 |
| Vancouver | 题名后 |

## 常见错误检查

1. **作者名格式不一致** - 检查同一作者的不同引用格式
2. **DOI 缺失** - 优先使用 DOI 而非 URL
3. **页码缺失** - 直接引用必须包含页码
4. **期刊名称错误** - 确认拼写和缩写
5. **年份错误** - 验证出版年份的准确性
6. **掠夺性期刊** - 检测可疑期刊名称
7. **幽灵引用** - 验证引用可在线检索
