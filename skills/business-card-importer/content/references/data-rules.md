## 1. Company Name（英文公司名）处理

### 规则
- **首字母大写，其余字母小写**
- 多个公司名用 "/" 隔开（前后各一个空格）

### 处理逻辑
```python
# 示例输入
"ABC CORP / XYZ INC" → "Abc Corp / Xyz Inc"
"MICROSOFT" → "Microsoft"
"apple" → "Apple"
```

### 代码实现
```python
def normalize_company_name(company_name: str) -> str:
    companies = company_name.split("/")
    normalized = [c.strip().capitalize() for c in companies]
    return " / ".join(normalized)
```

## 3. 手机号码处理

### 规则
| 规则 | 说明 |
|------|------|
| 仅录入中国内地手机 | 11位数字，以1开头 |
| 排除国际区号 | "+86"、"86-"、"+86 "等不录入 |
| 多号码分配 | 填入后续手机列（手机1→手机2→手机3） |
| 每格一个 | 手机和邮箱一个格子只能填入一个 |

### 处理流程
```
原始输入 → 清理空白 → 移除国际区号 → 提取纯数字 → 验证11位 → 录入
```

### 处理示例

| 原始输入 | 处理结果 | 说明 |
|----------|----------|------|
| "13812345678" | "13812345678" | ✓ 直接录入 |
| "+86 13812345678" | "13812345678" | ✓ 移除+86 |
| "+86-139-8765-4321" | "13987654321" | ✓ 移除符号和+86 |
| "86-13812345678" | "13812345678" | ✓ 移除86- |
| "+1 13812345678" | （不录入） | ✗ 非中国号码 |
| "400-800-8888" | （不录入） | ✗ 固话号码 |

### 代码实现
```python
def extract_china_mobile(phone: str) -> Optional[str]:
    # 移除国际区号前缀
    phone_clean = re.sub(r'^\+86[\s\-]?', '', phone)
    phone_clean = re.sub(r'^86[\s\-]?', '', phone_clean)

    # 提取纯数字
    digits_only = re.sub(r'\D', '', phone_clean)

    # 验证：中国手机号（11位，以1开头）
    if len(digits_only) == 11 and digits_only.startswith('1'):
        return digits_only
    return None
```
