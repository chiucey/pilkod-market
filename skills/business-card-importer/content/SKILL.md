# 名片扫描导入技能

---

## ⚠️ 铁律（每次执行前必读）

### 写入 Excel 的正确方式
- **必须用 openpyxl 库**写入或修改 Excel 文件，禁止手动拼接 XML 字符串
- 如果坚持用 XML 写入：必须对所有特殊字符转义 `&`→`&amp;` ` <`→`&lt;` `>`→`&gt;` `"`→`&quot;`
- 写入后必须用 openpyxl 读取验证数据是否正确

### 工作节奏（最高优先级）
- **一张一张来**：识别 → 汇报 → 等待确认 → 写入 → 确认后再下一张
- **不擅自修改已确认的内容**：用户确认后的数据不得再改，必须改时先征求同意
- 操作前先确认源文件正确，再动手

### 禁止行为
- 不得跳过确认流程直接录入
- 不得在未验证的情况下覆盖源文件
- 不得用字符串拼接方式写入 Excel（即使看起来能work）
- **不得未经过用户同意擅自修改已确认录入的内容**
- **不得跳过当前名片，直接录入下一张**

## 功能概述

将扫描或拍照的名片图片自动识别并按照规定格式导入到Excel模板中，支持批量处理。

## 名片录入模板（25列标准格式）

每张名片录入一行，列结构如下：

| 列 | 表头 | 说明 |
|----|------|------|
| A | 名片文件名称 | 图片文件名，如"1-1.jpg & 1-2.jpg"，多面合并用&连接 |
| B | Company Name | 英文公司名（名片原文，无则留空） |
| C | 公司名 | 中文公司名（名片原文，繁转简；多名称用/分隔） |
| D | 产品品类 | 严格从三大行业产品品类选项中选填，不可填行业总称 |
| E | 联系人 | 中文优先：中文名+英文名合并，如"梁楚楚Chloe Liang" |
| F | 联系人职位 | 中文优先，如名片有中文职位填中文 |
| G | 联系人手机1 | 11位内地号码，+86/86-前缀去掉后录入；852/886前缀留空 |
| H | 联系人手机2 | 同上 |

## 工作流程

### 步骤 0: 接收并清点任务（批量任务必须先完成此步）

**名片文件命名规则**

名片图片必须使用 `X-Y` 格式命名：

- **X** = 名片编号（同一张名片的所有面共用同一个编号）
- **Y** = 该名片含有的画面编号（1=正面/联系面，2=背面/品牌面，以此类推）
- X 和 Y 均为正整数

**示例：**
- `1-1.jpg` + `1-2.jpg` → 名片编号1，正面=1-1，背面=1-2，合并为**1张名片**
- `2-1.jpg` + `2-2.jpg` → 名片编号2，合并为**1张名片**
- `3-1.jpg` → 名片编号3，仅有正面，**1张名片**

**统计规则：**
- 有多少个**不同的 X**值 = 就有多少张独立名片
- 同一 X 下的多张 Y 图片（1-1、1-2、1-3…）→ 合并录入同一行
- 文件格式支持：JPG、JPEG、PNG、WebP

**批量任务开始前，必须完成以下清点工作：**

**A. 确认名片数量**
- 从文件名中提取 X-Y 命名的 X 值，统计不重复 X 数量
- 向用户确认：`检测到 N 张名片，是否开始录入？`

**B. 确认预期写入行数**
- 已有 Excel 行数（不含表头） + N 张名片 = 预期总行数
- 记录此数字，作为后续验证基准

**C. 建立卡片追踪表（贯穿全程）**

| 文件名 | 识别状态 | 写入行号 | 验证状态 |
|--------|----------|----------|----------|
| 1-1.jpg | ✅ | 15 | ✅ |
| 1-2.jpg | ✅（背面，合并） | 15 | ✅ |
| 2-1.jpg | ⏳ | — | — |

**D. 数据与写入脚本分离**
- 原始识别结果存入 JSON 文件（如 `d.json`），处理过程中不动原始数据
- 写入 Excel 使用独立的 JS 脚本，只负责把 JSON 数据写入 Excel
- 脚本错误只影响本次写入，不破坏原始数据

### 步骤 2: 识别名片信息

使用图像识别从名片中提取以下字段：

- 联系人姓名
- 职位

- 公司网址

### 步骤 3: 数据格式规范化

#### 3.1 Company Name（英文公司名）
- **直接按名片原文填写，不翻译、不补全**
- **首字母大写，其余字母小写**（除非名片原文全部大写/全部小写/特殊大小写格式）
- 多个公司名用 "/" 隔开
- 若名片上无英文名，此格**留空**，不得自行翻译补全

#### 3.2 公司名（中文）
- **直接按名片原文填写，不翻译、不补全**
- **公司名一律使用简体中文**，不得填写繁体中文；若名片为繁体中文，需转换为简体后填入
- 多个公司名用 "/" 隔开
- 若名片上无中文名，此格**留空**，不得自行翻译补全

#### 3.3 联系人姓名与职位
- **直接按名片原文填写，不翻译、不补全**
- **联系人：中文优先，中文名+英文名合并填入一格**，如"梁楚楚Chloe Liang"
- **职位：中文优先，如名片有中文职位则填中文**
- 示例：`梁楚楚Chloe Liang`
- 示例：`个性化礼品，印刷包装职业经理人`

#### 3.4 手机号码处理
- **仅录入中国内地手机**：11位纯数字
- **+86 前缀**：内地手机号码前缀，**录入**，去掉+86前缀后填入
- **86- 前缀**：内地手机号码前缀，**录入**，去掉86-后填入
- **852 前缀**：香港电话区号，不是内地手机号码前缀，**不得录入**
- **886 前缀**：台湾电话区号，不是内地手机号码前缀，**不得录入**
- **多个号码**：填入后续手机列（手机1→手机2→手机3）
- 每个格子只能填入一个手机号码

#### 3.5 邮箱地址
- **全部转为小写字母**
- 多个邮箱：填入后续邮箱列（邮箱1→邮箱2→邮箱3→邮箱4）
- 每个格子只能填入一个邮箱地址

#### 3.6 公司电话、公司传真、公司网址
- 若名片上**有提供**则直接填入对应单元格
- 若名片上**未提供**，对应单元格**留空**，不填任何内容

#### 3.7 地址处理
- **地址原文为英文时，翻译为中文简体填写**
- **省份和城市一律使用中文简体填写**
- **中文繁体地址需转换为中文简体后方可填入**
- 直辖市/特别行政区：省份和城市填写同一中文名称
  - 上海 → 省份：上海，城市：上海
  - 北京 → 省份：北京，城市：北京
  - 天津 → 省份：天津，城市：天津
  - 重庆 → 省份：重庆，城市：重庆
  - 香港 → 省份：香港，城市：香港
  - 澳门 → 省份：澳门，城市：澳门
  - 台湾 → 省份：台湾，城市：台北/高雄等
- **每个格子只填入一个地址**
- **多个地址**：填入后续地址列（地址1→地址2→地址3）

#### 3.8 产品品类自动推断（重要）

**产品品类列不可留空**，必须根据名片上的"主营"或"经营范围"信息对照三大行业产品品类选项进行推断，从对应行业中选择最贴切的选项填入。

**同一公司有多个产品线时，符合多个行业划分的产品品类应同时录入，用 "/" 分隔。**

### 步骤 4: 逐张写入Excel并验证

每处理完一张名片，立即执行写入和验证，不等全部处理完再批量检查。

**A. 写入前：确认目标行**
- 读取当前 Excel 行数（不含表头）
- 确定这张名片应写在第几行（已有行数 + 1）

**B. 写入后：立即核对**
- 读取 Excel 总行数，与步骤0记录的预期总行数比对
- 行数符合预期 → 这张卡写入成功，继续下一张
- 行数不符 → 立即报警，告知用户哪张卡写入失败，**不继续处理下一张**，等待用户指示

**C. 写入后：对照自检表逐一核验**
- 发现不符合项 → 告知用户，不擅自覆盖数据

**D. 更新卡片追踪表**

| 文件名 | 识别状态 | 写入行号 | 自检结果 | 验证状态 |
|--------|----------|----------|----------|----------|
| 1-1.jpg | ✅ | 15 | ✅ 通过 | ✅ |
| 1-2.jpg | ✅ 背面（合并） | 15 | ✅ 通过 | ✅ |
| 2-1.jpg | ✅ | 16 | ✅ 通过 | ✅ |
| 3-1.jpg | ✅ | 17 | ⚠️ 产品品类待确认 | ⏳ |

发现 ⏳ → **停止下一张处理**，先问用户确认该异常项。

**E. 禁止行为（批量处理中）**
- ❌ 先处理完全部卡片，再一次性写入
- ❌ 批量写入后不核对行数
- ❌ 跳过自检直接覆盖数据
- ❌ 用数组索引推算行号，不实际读取 Excel 行数

所有名片处理完毕后，向上级报告：

1. **成功录入 N 张名片**，分别是哪些公司

3. **总行数**：与预期是否一致
4. **文件路径**：提供下载链接

## 标准工作流程

### 流程说明

1. **用户发送名片** — 一次只发一张名片图片（正面+反面直接发，不用注明正反面，系统会自动判断并合并信息）
2. **识别录入** — 系统调用 skill 将名片内容识别后，按照规范填入 Excel
3. **持续追加** — 每收到一张新名片，自动追加到**同一张 Excel** 的新一行中
4. **另起新表** — 当用户明确说"另起一个表格"或"另起一个 Excel"时，才创建新的 Excel 文件

### 追加规则

- 已有名片存在：找到文件的最后一行，在其下方插入新数据
- 已有表头：复用原表头，不重复创建
- 文件命名：如用户未指定，默认命名为 `名片录入_YYYYMMDD.xlsx`；如用户指定了名字则用用户命名
- 另起新表后：按新的 Excel 文件重新开始计数

### 触发"另起一张表"的关键词

用户说以下任意一句时，立即创建新 Excel：
- "另起一个表格"
- "另起一个 Excel"
- "新建一张表"
- "重新开始"
- "开一个新表格"
