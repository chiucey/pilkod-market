# 电商产品作图技能

## 工作流程

### 第一步：解析需求文档

读取用户上传的作图需求文件（Excel/PDF/图片），提取：
- 产品名称、产品卖点
- 目标平台（淘宝/天猫/京东/抖音/亚马逊/乐天等）
- 文案内容（中日语分开）
- 参考风格链接
- 每张图的编号、标题、文案

### 第二步：产品图片分析

分析用户上传的产品图片，识别：
- 产品外观、颜色、材质
- 适合的拍摄角度（正面/侧面/底部/场景）
- 产品定位（高端/平价/家用/商用）

### 第三步：市场调研 + 竞品分析

根据产品类别，搜索：
- 平台同类热销商品主图风格
- 价格带、销量、视觉特征
- 颜色趋势、排版风格流行趋势

输出结构化调研报告：
```
## [平台] 市场调研
- 价格带：xxx
- 主销价格：xxx
- 常见主图风格：xxx
- 爆款共同特征：xxx
- 颜色趋势：xxx
- 排版规律：xxx
```

### 第四步：主图设计

根据调研结果设计主图：
- 构图：产品居中/左大右小/右大左小
- 背景：纯色/渐变/场景/生活化
- 卖点数量：1-3个核心卖点优先
- 字体：平台规范字体
- 尺寸：平台要求的像素尺寸

输出：可直接使用的主图文件

### 第五步：详情页多图设计

按需求文档顺序生成每张图：
- 图1：主图（产品+核心文案）
- 图2：产品概念/卖点介绍
- 图3：对比/优势亮点
- 图4：使用场景/生活方式
- 图5：功能点合集
- 图6：菜谱/附加价值
- 图7：容量/适用人数
- 图8：预约功能
- 图9：操作说明
- 图10：清洁功能
- 图11：安全设计细节

每张图输出：设计说明 + 生成的图片文件

## 作图输出规范

### 平台尺寸标准

| 平台 | 主图尺寸 | 详情页宽度 |
|------|---------|-----------|
| 淘宝/天猫 | 800×800px | 750px |
| 京东 | 800×800px | 790px |
| 抖音 | 720×720px | 主体 |
| 亚马逊 | 1500×1500px | 1000px |
| 乐天 | 500×500px以上 | 750px |

### 文案高度规范

- 标题区：不超过图片高度30%
- 留白区：不少于图片高度15%
- 核心卖点：1-3个，超出用省略号

### 多图连续性

- 详情页图片保持统一的背景色/风格
- 使用相同的水印或logo位置
- 字体大小系列化

## 交付清单

生成完成后，提供：
1. 市场调研报告（Markdown格式）
2. 主图文件（PNG/JPG）
3. 详情页图片系列（按编号）
4. 整体文件包（ZIP格式）
