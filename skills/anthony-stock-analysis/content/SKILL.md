# Anthony股票分析（Anthony-Stock-Analysis）

批量分析1-50份研报，输出结构化评估报告与持仓操作建议。

## 输入

用户一次性发送N份研报（PDF、图片或文本），指定持仓信息：
```
股票名称+代码、持股数量、成本价、当前价（如有）
```

## 输出文件结构

每次分析生成3个文件（写入 `/workspace/analysis/[股票代码]_[日期]/`）：
- `00_评分排名.md` — 十篇研报评分排名表
- `01_各篇评估.md` — 每篇研报的完整评估
- `02_最终建议.md` — 针对用户持仓的综合建议

---

## 第一步：创建输出目录

```bash
mkdir -p /workspace/analysis/[股票代码]_[日期]
```
例如：`mkdir -p /workspace/analysis/601111_2026-05-03`

## 第二步：读取所有研报

对于每份研报，按以下顺序处理：

### PDF文件
```bash
# 优先用 pdftotext（保留表格结构）
pdftotext -layout "[文件路径]" /tmp/tmp_text.txt 2>/dev/null

# 如果 pdftotext 失败（无文字流），用以下顺序 fallback：
# 1. images_understand + prompt="请提取报告中所有关键财务数据、数字、目标价、评级和投资建议"
# 2. read tool（limit 200行，逐段读取）
```

### 图片/PDF图片格式
```python
images_understand + prompt="请提取图片中所有文字内容，特别是：财务数据、数字、评级、目标价、分析逻辑"
```

### 文本/markdown 文件
直接用 read tool 读取完整内容。

## 第四步：识别系统性错误（关键！）

**同一数据的多个版本出现在不同报告中，必须标记！**

检查模式：
- "Q1净利润有X份报告引用17.14亿，Y份引用9.83亿——X>Y，17.14亿是传播的AI错误"
- "有3份报告混用了港股技术数据（港元报价）与A股实际走势"
- "有5份报告使用了相同的错误数字，推断为AI数据污染"

**处理规则：**
- 以分析师署名+ institution背书 的报告为准
- 多个AI报告引用相同错误数字 → 标记为AI传播错误，不采用
- 技术面数据必须与A股实际走势（人民币报价）核对

## 核心原则

1. **数据冲突时**：以分析师署名+ institution 背书的报告为准；无署名AI报告的一致数字可能是传播错误
2. **技术面必须核实**：港股数据（HKD报价）≠ A股数据（CNY报价），混用是致命错误
3. **操作建议必须具体**："持有/加仓/止损" + 具体价格，不能模糊
4. **作者身份造假**：Cliff Asness从未授权任何中国AI平台使用其框架——发现即扣分
5. **写文件**：所有分析结果必须写入 `/workspace/analysis/[代码]_[日期]/` 下的文件，不只是口头输出
