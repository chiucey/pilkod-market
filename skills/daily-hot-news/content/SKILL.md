# 每日热点新闻技能

## 工作流程

1. **使用 `batch_web_search`** 搜索今日热点新闻（搜索当天日期）
2. **多维度搜索**（一次搜索最多10条）：
   - 国内热点（新浪/微博/百度热搜）
   - 国际要闻
   - 财经/股市相关热点
   - 科技/互联网热点
3. **筛选与去重**，合并同类内容
4. **结构化输出**，按类别整理

## 搜索策略

### 第一批（并行）
```
query: 今日热搜 热点新闻 {today} site:weibo.com OR site:baidu.com OR site:sina.com.cn
query: 今日国内热点新闻 {today}
query: 今日财经热点 {today}
query: 今日科技互联网热点 {today}
```

### 第二批（如需补充）
```
query: 今日国际要闻 {today}
query: 今日A股市场热点 {today}
```

### 日期变量
- today = 实际日期，格式"2026年4月24日"
- 也可用"昨天"、"前天"配合搜索

## 输出格式

输出格式如下，每条新闻包含：标题 + 来源 + 摘要（1-2句）

```
## 📰 今日热点新闻 — {today}

### 🔥 国内热点
1. [标题]（来源）
   摘要...

### 💰 财经热点
1. [标题]（来源）
   ...

### 🌍 国际要闻
1. [标题]（来源）
   ...

### 💻 科技前沿
1. [标题]（来源）
   ...

---
📡 数据来源：微博热搜 / 百度热榜 / 新浪财经 / 今日头条
```

## 注意事项

- 优先选择**当天日期**的新闻，标注新闻时间
- 财经新闻侧重：A股、基金、ETF、宏观政策
- 科技新闻侧重：AI、半导体、新能源、消费电子
- 如搜索结果均为前一天内容，标注"数据更新至昨日"
- 总字数控制在 800-1500 字以内，简洁有力
- 标注每条新闻来源（新浪/微博/证券时报/澎湃等）
