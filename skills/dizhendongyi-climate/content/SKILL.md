# 地动仪气候模型技能（v1.0.0）
## Dizhendongyi-Climate: Orbital-Scale Climate Prediction Skill

---

## 核心功能

基于"地动仪"模型（v2.0）理论框架，提供**轨道尺度长期气候预测**和**近期（数十年至百年）气候推演**的能力。激活条件：用户提到气候预测、气候变化模型、轨道周期、米兰科维奇理论、冰期预测、长期气候推演、FEBE方程、古气候建模等关键词。

本技能整合三大核心模块：
- **长期气候预测**：基于岁差-倾角-偏心率三要素耦合机制 + FEBE方程，预测未来10³–10⁵年尺度气候演变
- **近期气候推演**：叠加温室气体强迫（RCP/SSP情景），将模型预测延伸至2100年前后
- **极端事件预警**：基于三阶前兆指标体系，构建气候突变事件预警框架

## 工作流程

### 流程一：长期气候预测（轨道尺度，10³–10⁵年）

```
1. 确定预测时间范围
   → 用户输入目标年份（如"未来1万年"）
   
2. 获取轨道参数
   → 运行 orbital_forcing.py 计算目标时间的岁差/倾角/偏心率
   → 输出：F_ψ(t), F_ε(t), F_δ(t), F_orb(t)
   
3. 求解FEBE方程
   → 运行 febe_solver.py，输入轨道强迫时间序列
   → 选择记忆指数 h（默认：h大气=0.4, h深海=0.7, h冰盖=0.85）
   → 输出：温度异常 ΔT(t), 各组件贡献分解
   
4. 叠加反馈机制
   → 反馈项 G_ice-albedo, G_CO2, G_AMOC, G_veg
   → 总放大效应：基础辐射强迫 × λ_sys（约2–4倍）
   
5. 输出预测结果
   → 给出具体数值（温度异常、CO₂估算、冰期/间冰期阶段判断）
   → 明确标注前提条件（自然强迫为主or含人为强迫）
```

### 流程二：近期气候推演（至2100年）

```
1. 确定排放情景
   → 用户选择：RCP2.6 / RCP4.5 / RCP6.0 / RCP8.5 或 SSP1-2.6 / SSP2-4.5 / SSP5-8.5
   
2. 构建混合强迫输入
   → 轨道强迫（自然）：orbital_forcing.py
   → 温室气体强迫（人为）：读取 references/ scenarios/ 中的CO₂浓度路径
   
3. 求解混合FEBE
   → F_total = F_orb(t) + ΔQ_CO2(t)
   → 近期（<2100年）：轨道强迫主导？→ 标注说明
   
4. 输出近期推演结果
   → 关键时间节点（2030/2050/2100）的温度异常估算
   → 与CMIP6/IPCC AR6结果的对比说明
```

### 流程三：极端事件预警

```
1. 识别触发因素
   → 检查用户提供的监测指标（AMOC强度、土壤湿度、SST梯度等）
   → 对照 references/extreme_events.md 中的前兆指标体系
   
2. 匹配历史案例
   → 检索 references/extreme_events.md 中的类比事件库
   → 评估当前状态与历史案例的相似度
   
3. 输出预警评估
   → 触发等级：正常 / 关注 / 警戒 / 紧急
   → 给出参考响应时长（基于历史案例的滞后时间）
```

## 重要边界条件

- **适用时间尺度**：10³–10⁵年（轨道尺度），近期（至2100年）须叠加人为强迫
- **适用前提**：自然轨道强迫主导；人类活动强迫不主导（工业革命前或未来排放极低情景）
- **不适用情形**：年代际ENSO/NAM等短周期现象；全新世内部精细结构（代用指标分辨率不足时）
- **结果标注**：所有预测结果必须标注"自然轨道情景"前提及人为强迫叠加说明

> **边界条件说明**：本预测基于自然轨道强迫情景（假设人类活动保持工业革命前水平）。现实中大气CO₂浓度已达~420 ppm（2024年），对应辐射强迫约2.1–2.5 W·m⁻²，是当前自然轨道强迫（<0.5 W·m⁻²）的4–6倍，在未来数十年至数百年尺度上，人为温室效应主导气候趋势。轨道预测仅具有理论参考价值，不代表实际气候演变方向。
