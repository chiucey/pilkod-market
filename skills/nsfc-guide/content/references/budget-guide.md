# 国基金经费预算编制指南

## 一、预算编制原则

### 基本原则
1. **目标相关性**：经费用于实现项目目标
2. **政策相符性**：符合国家财政政策和管理规定
3. **经济合理性**：厉行节约，避免铺张浪费
4. **真实性**：实事求是，客观真实

### 预算科目设置（NSFC）

| 科目 | 说明 | 青年基金 | 面上项目 |
|------|------|---------|---------|
| **直接费用** | | | |
| - 设备费 | 购置/试制设备 | ≤10万 | 不限 |
| - 业务费 | 测试/材料/差旅等 | 主导 | 主导 |
| - 劳务费 | 研究生/临时工费用 | 有上限 | 有上限 |
| **间接费用** | 单位管理费+绩效 | 500万×20% | 500万×20% |

### 预算科目设置（NSSFC）

| 科目 | 说明 |
|------|------|
| 资料费 | 图书、文献、档案等 |
| 调研差旅费 | 调研、会议费用 |
| 数据采集费 | 问卷、访谈费用 |
| 会议费 | 研讨会、论证会 |
| 专家咨询费 | 支付给专家的咨询费 |
| 劳务费 | 助研金、学生补贴 |
| 印刷费 | 打印、复印、装订 |
| 其他支出 | 其他合理支出 |

## 二、各科目预算要点

### 1. 设备费

**范围**：
- 购置单台套≥5万元的设备
- 改装现有设备
- 租赁外单位设备

**注意事项**：
- ⭐ 基础研究应以使用现有设备为主
- ⭐ 鼓励共享、试制、租借
- ⭐ 5万以下设备列入"其他支出"
- ❌ 办公设备（电脑、打印机）一般不资助

**计算依据**：
```
设备费 = 设备单价 × 数量
例：高端显微镜 30万 × 1 = 30万
```

### 2. 业务费

**范围**：
- 测试化验加工费
- 材料费
- 燃料动力费
- 差旅费
- 会议费
- 国际合作与交流费
- 出版/文献/信息传播费
- 知识产权事务费
- 其他

**青年基金业务费占比**：通常60-80%

**各科目说明**：

#### 测试化验加工费
- 需说明测试内容、次数、单价的测算依据
- 市场价格参考
- 高校、科研院所检测平台优先

#### 材料费
- 实验耗材
- 试剂购买
- 样本采集运输
- 计算依据：单耗×数量×单价

#### 差旅费
- 国内调研
- 学术会议
- 野外考察
- 标准参照国家规定

#### 会议费
- 小型研讨会
- 专家咨询会
- 标注会议规模、人数、天数
- 标准参照国家规定

#### 国际合作交流费
- 出国参加学术会议
- 外国专家来访
- 双边合作交流
- 需有出访计划或合作基础

### 3. 劳务费

**NSFC规定**：
- 面上项目：≤15%直接费用
- 青年基金：≤30%直接费用

**NSSFC规定**：
- 劳务费据实编制
- 说明参与人员数量和补贴标准

**支出对象**：
- 研究生助研费
- 博士后人员费用
- 临时聘用人员费用

**注意事项**：
- ❌ 项目组成员不能领取
- ❌ 不能用于发工资
- ❌ 需据实测算人数和标准

### 4. 专家咨询费

**标准**（参照国家规定）：
- 院士、正高级职称：≤2400元/人/天
- 其他高级职称：≤1500元/人/天
- 其他人员：≤900元/人/天

**适用范围**：
- 论文评审
- 成果鉴定
- 项目咨询
- 论证指导

**注意事项**：
- ❌ 项目组成员不能领取
- ❌ 项目组织管理部门人员不能领取
- ⭐ 需说明咨询内容和人次

## 三、间接费用

### NSFC间接费用（2021年后新规定）

| 直接费用 | 间接费用比例 |
|---------|-------------|
| 500万及以下部分 | 20% |
| 超过500万元至1000万元部分 | 15% |
| 超过1000万元部分 | 13% |

**计算示例**：
```
直接费用300万：
间接费用 = 300万 × 20% = 60万

直接费用800万：
间接费用 = 500万×20% + 300万×15% = 100+45 = 145万
```

### NSSFC间接费用

- 间接费用比例：20%
- 含单位管理费和绩效支出

## 四、预算说明书撰写

### 撰写要点

1. **逐项说明**：每个科目都要说明测算依据
2. **合理归集**：避免不同科目交叉重复
3. **实事求是**：与研究内容紧密相关
4. **重点突出**：大额支出需详细说明

### 撰写模板

```markdown
### 设备费（XX万元）

1. XX设备（型号），用于XX实验/研究，市场价格参考XX万元
2. XX仪器（型号），用于XX检测，预计XX万元
3. ...

### 测试化验加工费（XX万元）

1. XX检测：XX样本×XX次×XX元/次 = XX万元
2. XX分析：XX样品×XX元/样品 = XX万元
...

### 材料费（XX万元）

1. XX试剂：XX盒×XX元/盒 = XX万元
2. XX耗材：XX批次×XX元/批 = XX万元
...

### 差旅费（XX万元）

1. 国内调研：XX次×XX人×XX元/人次 = XX万元
2. 学术会议：XX次×XX人×XX元/人次 = XX万元
...

### 专家咨询费（XX万元）

1. XX专家咨询：XX人次×XX元/人次 = XX万元
...
```

## 五、常见问题与解答

### Q1：可以直接费用中列支设备吗？
A：可以，但需符合"直接用于该项目"的设备。单台套≥5万元计入设备费，<5万元计入其他支出。

### Q2：研究生可以领取劳务费吗？
A：可以。项目经费中可以列支研究生助研费，但不能给项目组成员。

### Q3：会议费标准是多少？
A：参照国家会议费标准：
- 一类会议：≤660元/人/天
- 二类会议：≤550元/人/天
- 三类会议：≤450元/人/天

### Q4：预算可以调整吗？
A：可以。在项目执行中，设备费和专家咨询费一般不调增，其他科目可按规定程序调整。

### Q5：项目结余经费如何使用？
A：NSFC项目结余经费可在2年内由依托单位统筹用于科研活动，直接用于科学研究。

## 六、预算审核常见不合格原因

- ❌ 预算超标准（如劳务费超比例）
- ❌ 测算依据不充分
- ❌ 与研究内容不相关
- ❌ 科目之间明显失衡
- ❌ 缺少预算说明书
- ❌ 预算说明书过于简单
