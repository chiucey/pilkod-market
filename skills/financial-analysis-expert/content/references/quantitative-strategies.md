### 1.2 趋势跟踪策略

#### 双重均线策略

**策略逻辑**：
- 短期均线上穿长期均线：买入信号
- 短期均线下穿长期均线：卖出信号

**参数优化**：
| 参数组合 | 特点 | 适用市场 |
|---------|------|---------|
| MA(5,20) | 敏感度高，信号多 | 短线、波动市场 |
| MA(10,60) | 平衡型 | 波段操作 |
| MA(20,200) | 滞后性大，信号少 | 长线趋势 |

#### ATR通道突破策略

**策略逻辑**：
```
上轨 = MA + K × ATR
下轨 = MA - K × ATR

突破上轨 → 买入
跌破下轨 → 卖出
```

**参数设置**：
- MA周期：20-50
- ATR周期：20
- K值：2-3

### 1.3 均值回归策略

#### 布林带回归策略

**策略逻辑**：
- 价格触及下轨：买入（预期回归）
- 价格触及上轨：卖出（预期回归）
- 止损设置：价格继续突破2×ATR

**优化方向**：
- 结合RSI过滤假信号
- RSI < 30 时下轨买入
- RSI > 70 时上轨卖出

#### RSI均值回归策略

**策略逻辑**：
- RSI < 30：超卖区域，买入信号
- RSI > 70：超买区域，卖出信号
- RSI回归至50：确认信号

### 1.4 多因子量化模型

#### 因子分类体系

| 因子类别 | 因子名称 | 因子说明 |
|---------|---------|---------|
| 价值因子 | PE、PB、PS、PCF | 估值水平 |
| 成长因子 | 营收增速、利润增速 | 增长潜力 |
| 质量因子 | ROE、ROA、毛利率 | 盈利质量 |
| 动量因子 | 20日收益、60日收益 | 价格趋势 |

| 情绪因子 | 换手率、波动率 | 市场情绪 |

#### 多因子选股模型

**模型框架**：
```python
# 简化多因子模型
Score = Σ(Wi × Factor_i_normalized)

# 因子权重配置示例

    'value': 0.20,      # 价值因子
```

### 2.2 基金评价指标体系

#### 收益指标

| 指标 | 计算公式 | 说明 |
|-----|---------|------|
| 单位净值 | 基金净资产/份额 | 基金价格 |
| 累计净值 | 单位净值+历史分红 | 考虑分红的收益 |
| 净值增长率 | (期末净值-期初净值)/期初净值 | 持有期收益 |
| 年化收益率 | 持有收益/年数 | 标准化收益 |

#### 风险指标

| 指标 | 计算公式 | 说明 |
|-----|---------|------|
| 标准差 | σ(每日收益) | 收益波动程度 |
| 最大回撤 | max(高点-低点)/高点 | 历史最大亏损 |
| 下行偏差 | σ(负收益) | 下行波动 |
| VaR | 置信区间最大损失 | 风险价值 |

#### 风险调整收益

| 指标 | 公式 | 评价标准 |
|-----|------|---------|
| 夏普比率 | (Rp-Rf)/σp | >1优秀，>2杰出 |
| 卡玛比率 | 收益率/最大回撤 | >1优秀，>2杰出 |
| 索提诺比率 | (Rp-Rf)/下行偏差 | >1优秀 |
| 信息比率 | 超额收益/跟踪误差 | >0.5优秀 |

### 3.2 仓位管理方法

#### 固定比例法

```python
# 固定比例法
position_size = portfolio_value * risk_per_trade
# 每笔交易承担账户的1-2%风险
```

#### ATR动态调整法

```python
# ATR仓位管理
atr = calculate_atr(close, high, low, period=14)
position_size = risk_amount / (atr * multiplier)
# multiplier通常为1.5-2.0
```

#### 凯利公式

```python
# 凯利公式
# f = (bp - q) / b
# 其中：
# f = 最佳下注比例
# b = 赔率（盈亏比）
# p = 胜率
# q = 败率 = 1-p

# 实际应用考虑半凯利（f/2）降低波动
```

### 3.3 止损策略体系

#### 止损类型

| 类型 | 触发条件 | 适用场景 |
|-----|---------|---------|
| 固定止损 | 价格亏损X% | 短线交易 |
| 跟踪止损 | 最高点回落X% | 趋势交易 |
| 时间止损 | 持仓超过N天 | 所有策略 |
| 指标止损 | 技术指标触发 | 量化策略 |
| 资金止损 | 账户亏损达X% | 风控底线 |

#### 止损参数建议

| 策略类型 | 止损幅度 | 跟踪幅度 |
|---------|---------|---------|
| 短线（日内） | 0.5-1% | 0.3-0.5% |
| 波段（1-5日） | 2-3% | 1.5-2% |
| 中线（周级） | 5-7% | 3-5% |
| 长线（月级） | 10-15% | 8-10% |

### 3.4 投资组合优化

#### 组合构建原则

1. **相关性控制**：
   - 资产相关系数 < 0.7
   - 策略相关系数 < 0.5

2. **分散化配置**：
   - 单一资产 < 20%
   - 单一行业 < 30%
   - 单一策略 < 40%

3. **流动性管理**：
   - 日交易量 < 1%流通盘
   - 持仓变现时间 < 5日

#### 优化算法

| 算法 | 目标 | 约束 |
|-----|------|------|
| 均值方差 | 最大化夏普 | 权重和=1 |
| 最小方差 | 最小化波动 | 预期收益≥基准 |
| 最大多元化 | 最大化分散化 | 权重和=1 |
| 风险平价 | 风险贡献相等 | 权重和=1 |
