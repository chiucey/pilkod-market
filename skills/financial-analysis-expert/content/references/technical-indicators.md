# 技术指标详解参考文档

## 一、趋势类指标深度解析

### 1.1 移动平均线系统（MA/EMA）

#### 简单移动平均线（SMA）

**计算公式**：
```
SMA(n) = (P1 + P2 + ... + Pn) / n
```

其中Pn为第n日的收盘价，n为计算周期。

**参数设置建议**：
| 周期类型 | 参数 | 应用场景 |
|---------|------|---------|
| 短期 | 5、10 | 短线交易、敏感度高 |
| 中期 | 20、30 | 波段操作 |
| 长期 | 60、120、250 | 趋势判断、长线投资 |

#### 指数移动平均线（EMA）

**计算公式**：
```
EMA(n) = α × Ptoday + (1-α) × EMAyesterday
其中α = 2 / (n + 1)
```

**与SMA对比**：
| 特性 | SMA | EMA |
|-----|-----|-----|
| 灵敏度 | 较低 | 较高 |
| 滞后性 | 较大 | 较小 |
| 计算权重 | 等权重 | 近权重更大 |
| 适用场景 | 长周期 | 短中期 |

### 1.2 MACD指标详解

#### 标准参数

| 参数 | 默认值 | 说明 |
|-----|-------|------|
| 快速EMA周期 | 12 | 短期均线 |
| 慢速EMA周期 | 26 | 长期均线 |
| 信号线周期 | 9 | DIF的EMA平滑 |

#### MACD三要素

1. **DIF线（差离值）**：
   - DIF = EMA(12) - EMA(26)
   - 代表短期与长期均线的差值
   - DIF > 0 表示短期均线在长期均线上方

2. **DEA线（信号线）**：
   - DEA = EMA(DIF, 9)
   - 对DIF进行平滑处理
   - 作为买卖信号参考线

3. **MACD柱（BAR）**：
   - BAR = 2 × (DIF - DEA)
   - 柱状图直观展示多空力量对比
   - 红柱：多头市场；绿柱：空头市场

#### MACD交易信号

| 信号类型 | 买入信号 | 卖出信号 |
|---------|---------|---------|
| 金叉/死叉 | DIF上穿DEA | DIF下穿DEA |
| 零轴交叉 | DIF上穿零轴 | DIF下穿零轴 |
| 背离 | 价格新低但DIF未新低 | 价格新高但DIF未新高 |
| 柱状收缩 | 红柱缩短（潜在转势） | 绿柱缩短（潜在反弹） |

### 1.3 DMA指标（差值平均线）

**计算公式**：
```
DMA = A1 - REF(A1, M)
A1 = 短期均线
M = 差值周期
```

**应用要点**：
- DMA上穿零轴：中线买入信号
- DMA下穿零轴：中线卖出信号
- 与DMA均线交叉可作为辅助信号

### 1.4 TRIX指标（三重指数平滑）

**计算过程**：
```
EMA1 = EMA(close, N)
EMA2 = EMA(EMA1, N)
EMA3 = EMA(EMA2, N)
TRIX = (EMA3 - REF(EMA3, 1)) / REF(EMA3, 1) × 100
```

**应用原则**：
- TRIX > 0：多头市场
- TRIX < 0：空头市场
- TRIX与股价背离：重要转势信号

## 二、摆动类指标深度解析

### 2.1 KDJ随机指标

#### 计算公式

1. **RSV（未成熟随机值）**：
   ```
   RSV(n) = (Cn - Ln) / (Hn - Ln) × 100
   ```
   其中：
   - Cn：第n日收盘价
   - Ln：n日内最低价
   - Hn：n日内最高价

2. **K值**：
   ```
   K = 2/3 × Kprev + 1/3 × RSV
   ```

3. **D值**：
   ```
   D = 2/3 × Dprev + 1/3 × K
   ```

4. **J值**：
   ```
   J = 3 × K - 2 × D
   ```

#### 参数设置

| 参数 | 默认值 | 建议范围 | 说明 |
|-----|-------|---------|------|
| n | 9 | 5-14 | 计算周期 |
| M1 | 3 | 3-5 | K平滑天数 |
| M2 | 3 | 3-5 | D平滑天数 |

#### KDJ交易法则

| 市场状态 | KDJ特征 | 交易建议 |
|---------|---------|---------|
| 超买区 | K、D、J > 80 | 谨慎追高，考虑减仓 |
| 超卖区 | K、D、J < 20 | 关注反弹机会 |
| 金叉 | K上穿D | 买入信号（在超卖区更强） |
| 死叉 | K下穿D | 卖出信号（在超买区更强） |
| 顶背离 | 价格新高但KDJ未新高 | 预警卖出 |
| 底背离 | 价格新低但KDJ未新低 | 关注买入 |

### 2.2 RSI相对强弱指标

#### 计算公式

```
RS = n日内上涨幅度均值 / n日内下跌幅度均值
RSI = 100 - 100 / (1 + RS)
```

简化计算：
```
RSI = 100 × n日内上涨幅度之和 / (n日内上涨幅度之和 + |n日内下跌幅度之和|)
```

#### 参数设置与市场对应

| RSI周期 | 特点 | 适用场景 |
|--------|------|---------|
| 6日RSI | 极度敏感，波动大 | 短线交易 |
| 12日RSI | 平衡型 | 波段操作 |
| 24日RSI | 稳定，信号滞后 | 中长线投资 |

#### RSI应用法则

| 区间 | RSI值 | 市场含义 |
|-----|-------|---------|
| 极强 | >80 | 超买区，回调概率大 |
| 强势 | 60-80 | 多头市场，谨慎追涨 |
| 中性 | 40-60 | 震荡整理 |
| 弱势 | 20-40 | 空头市场，谨慎杀跌 |
| 极弱 | <20 | 超卖区，反弹概率大 |

### 2.3 WR威廉指标

#### 计算公式

```
WR(n) = (Hn - Cn) / (Hn - Ln) × 100
```

- Cn：当日收盘价
- Hn：n日内最高价
- Ln：n日内最低价

#### 应用要点

| 区间 | WR值 | 市场含义 |
|-----|------|---------|
| 超买 | WR < 20 | 价格接近n日高点，可能回落 |
| 超卖 | WR > 80 | 价格接近n日低点，可能反弹 |
| 中性 | 20-80 | 震荡整理 |

### 2.4 CCI商品通道指数

#### 计算公式

```
TP = (High + Low + Close) / 3
MA = SMA(TP, n)
MD = Σ|TP - MA| / n
CCI = (TP - MA) / MD / 0.015
```

#### 应用标准

| CCI区间 | 市场含义 | 交易建议 |
|--------|---------|---------|
| >+100 | 强势上涨 | 持有或买入 |
| < -100 | 弱势下跌 | 观望或做空 |
| ±100之间 | 震荡整理 | 区间操作 |

## 三、量能类指标深度解析

### 3.1 VOL成交量指标

#### 量价配合分析

| 价格走势 | 成交量 | 市场含义 |
|---------|-------|---------|
| 上涨 | 放量 | 多头强势，上涨可持续 |
| 上涨 | 缩量 | 上涨乏力，可能回调 |
| 下跌 | 放量 | 恐慌抛售，可能见底 |
| 下跌 | 缩量 | 下跌动能减弱 |
| 盘整 | 缩量 | 蓄势待发 |
| 盘整 | 放量 | 方向选择临近 |

### 3.2 OBV能量潮

#### 计算公式

```
If Close > Close_prev: OBV = OBV_prev + Volume
If Close < Close_prev: OBV = OBV_prev - Volume
If Close = Close_prev: OBV = OBV_prev
```

#### 应用法则

1. **趋势确认**：OBV与价格同向运行，确认趋势
2. **背离预警**：价格创新高但OBV未创新高，预示见顶
3. **突破验证**：价格突破重要位置时，OBV应同步配合

### 3.3 VR成交量比率

#### 计算公式

```
VR = (n日内上涨日成交量之和 × 100) / (n日内下跌日成交量之和)
```

#### 经验参数

| VR区间 | 市场含义 |
|-------|---------|
| <40 | 极度超卖，可能反弹 |
| 40-80 | 弱势市场 |
| 80-150 | 正常波动范围 |
| 150-250 | 活跃市场 |
| >250 | 过度活跃，警惕反转 |

## 四、波动类指标深度解析

### 4.1 布林带（Bollinger Bands）

#### 计算公式

```
中轨 = MA(close, N)
上轨 = 中轨 + K × STD(close, N)
下轨 = 中轨 - K × STD(close, N)
```

其中N=20，K=2为标准参数。

#### 布林带形态分析

| 形态 | 特征 | 交易含义 |
|-----|------|---------|
| 开口放大 | 带宽扩大 | 趋势启动或加速 |
| 收口缩小 | 带宽收窄 | 蓄势整理，突破在即 |
| 走平收缩 | 极度收窄 | 重大突破前兆 |
| 轨道上轨 | 价格触及上轨 | 超买预警 |
| 轨道下轨 | 价格触及下轨 | 超卖反弹机会 |

#### 布林带交易策略

1. **突破策略**：价格突破上轨买入，跌破下轨卖出
2. **回归策略**：触及极端轨道后回归中轨的概率大
3. **收口突破**：极度收口后方向选择，跟随突破方向

### 4.2 ATR平均真实波幅

#### True Range计算

```
TR = max(H - L, |H - PC|, |L - PC|)
```

其中PC为前一日收盘价。

#### ATR应用

| 应用场景 | 具体方法 |
|---------|---------|
| 止损设置 | 1.5-2×ATR作为止损距离 |
| 仓位计算 | 账户风险/（ATR×每手价值） |
| 波动率比较 | ATR与历史均值比较 |
| 突破确认 | 价格变动超过1×ATR |

### 4.3 肯特纳通道（Keltner Channel）

#### 计算公式

```
中轨 = EMA(close, N)
上轨 = 中轨 + K × ATR(N)
下轨 = 中轨 - K × ATR(N)
```

其中N=20，K=2为标准参数。

#### 应用要点

- 价格突破通道：趋势可能延续
- 价格回抽通道：交易机会
- 结合其他指标：提升信号可靠性

## 五、多指标综合分析框架

### 5.1 指标共振分析

| 共振类型 | 指标组合 | 信号强度 |
|---------|---------|---------|
| 趋势共振 | MA、MACD、ADX同向 | 最强信号 |
| 时机共振 | KDJ、RSI、WR同向 | 短线信号 |
| 量价共振 | OBV、VOL、Price同向 | 确认信号 |

### 5.2 指标背离分析体系

#### 背离类型

| 类型 | 价格走势 | 指标走势 | 信号强度 |
|-----|---------|---------|---------|
| 顶背离 | 创新高 | 未创新高 | 预警信号 |
| 底背离 | 创新低 | 未创新低 | 反弹信号 |
| 双重背离 | 两次新高/低 | 两次未跟随 | 强信号 |
| 三重背离 | 三次新高/低 | 未跟随 | 极强信号 |

#### 背离确认要素

1. 价格必须走出明确的高点或低点
2. 指标必须在相应位置形成明显的高峰或低谷
3. 背离需要至少两个高点/低点的对比
4. 背离发生时，指标应在超买超卖区域

### 5.3 多周期联动分析

```
周线：判断主要趋势方向
↓ 确认
日线：寻找入场时机
↓ 确认
60分钟：精细化入场点
```

**周期共振原则**：
- 多周期同向：趋势明确，坚定持仓
- 多周期矛盾：观望等待，减少操作
- 大周期优先：小周期服从大周期方向
