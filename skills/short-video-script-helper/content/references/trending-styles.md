## 一、视觉风格速查（按旧"视频类型"）

| 类型 | 卖点呈现 | 演员/出镜 | 适合产品 | 时长 |
|---|---|---|---|---|
| 口播 | 直给 | 主播本人 | 美妆/个护/食品 | 15-30s |
| 带货 | 直给+演示 | 主播+产品 | 日用品/工具 | 15-30s |
| 知识 | 间接(藏在知识里) | 老师/达人 | 工具/书/课程 | 30-60s |
| vlog | 生活场景 | 创作者本人 | 任何能融入生活的 | 15-60s |
| 剧情 | 戏剧化呈现 | 演员 | 有故事性的产品 | 15-60s |
| 剧情带货 | 戏剧化+直接转化 | 演员+产品 | 强功能/强卖点 | 15-30s |

> ⚠️ **v4 升级**：上述 6 种已**并轨到 5 种脚本结构**（演示/选择/体验/剧情/答疑），不再独立使用。
> 选"什么脚本结构"代替选"什么视频类型"。详见 `references/script-skeletons.md`。

## 二、时长节拍统一表（全文档唯一权威）

### 15s 视频（默认）
```
钩:      0-3s   (3 秒)
展 1:    3-8s   (5 秒)
展 2:    8-13s  (5 秒)
收:      13-15s (2 秒)
```

### 30s 视频
```
钩:      0-3s   (3 秒)
展 1:    3-10s  (7 秒)
展 2:    10-18s (8 秒)
展 3:    18-26s (8 秒)
收:      26-30s (4 秒)
```

### 60s 视频
```
钩:      0-3s   (3 秒)
展 1:    3-15s  (12 秒)
展 2:    15-30s (15 秒)
展 3:    30-45s (15 秒)
展 4:    45-55s (10 秒)
收:      55-60s (5 秒)
```

### 字密度（与 SKILL.md 统一）
- 15s ≈ 50-80 字
- 30s ≈ 120-180 字
- 60s ≈ 250-350 字

## 三、按视觉类型的 15s 脚本节拍模板

### 类型 1:口播（Direct-to-camera Talking）

**判定信号**: 多个明确卖点,主播有人设
```
钩(0-3s): 痛点直给 / 利益直给 / 情绪共鸣
展 1(3-8s): 卖点 1(快速) + 卖点 2(快速)
展 2(8-13s): 卖点 3(快速) + 情绪升华
收(13-15s): CTA
```

### 类型 2:带货（Demonstration Selling）

**判定信号**: 需要演示,"用前 vs 用后"对比
```
钩(0-3s): 痛点/反差/悬念
展 1(3-8s): 使用前状态(夸张痛苦)
展 2(8-13s): 使用产品(镜头特写) + 使用后状态(夸张满意)
收(13-15s): CTA + 产品特写
```

### 类型 3:知识（Knowledge）

**判定信号**: 产品背后有原理,目标人群有学习需求
```
钩(0-3s): 悬念/提问("为什么 XX 是 YY?")
展 1(3-8s): 知识点 1(快速) + 知识点 2(快速)
展 2(8-13s): 反转/高潮
收(13-15s): "所以答案是 XX 产品" + CTA
```

### 类型 4:vlog（Lifestyle Vlog）

**判定信号**: 创作者有人设,产品融入生活
```
钩(0-3s): 情绪共鸣("家人们/打工人/独居的")
展 1(3-8s): 一日生活片段 + 产品出现
展 2(8-13s): 产品使用 + 生活改善
收(13-15s): CTA(可以软)
```

### 类型 5:剧情（Story/Drama）

**判定信号**: 有戏剧冲突,需要演员
```
钩(0-3s): 冲突开场("我被 XX 了/我遇到了 XX")
展 1(3-8s): 起:背景介绍(快速)
展 2(8-13s): 承:冲突展开(中速) + 转:反转
收(13-15s): 结局 + (可选)CTA
```

### 类型 6:剧情带货（Story + Selling）

**判定信号**: 产品本身有"故事性"
```
钩(0-3s): 故事开场 + 产品出现(必须有产品)
展 1(3-8s): 起:产品 + 故事开头
展 2(8-13s): 承:笑点/冲突 + 转:反转 + 产品特写
收(13-15s): CTA + 产品再次出现
```

## 四、同产品不同视觉类型的钩子对比（智能保温杯）

| 视觉类型 | 钩子 | 收 |
|---|---|---|
| 口播 | "这保温杯,真的能 12 小时恒温" | "链接在下方" |
| 带货 | "我泡了 12 小时的咖啡还是热的" | "点购物车" |
| 知识 | "为什么有些保温杯 12 小时还热?" | "所以答案是 XX 保温杯" |
| vlog | "打工人的早八续命神器" | "购物车里" |
| 剧情 | "前男友留下的保温杯,现在还在显示最后一次泡枸杞的温度" | "我现在用 XX,链接在下方" |
| 剧情带货 | "前男友留下的保温杯,现在还在显示最后一次泡枸杞的温度" | "XX 保温杯,链接在下方" |

**经验**：剧情带货的钩子最强（情绪+反差+悬念），但选型要看商品+人群，不能默认。

## 五、如何选视觉类型？

**v4 升级后决策流程**：
1. **优先选脚本结构**（演示/选择/体验/剧情/答疑）→ 详见 `script-skeletons.md`
2. **再选视觉类型**（口播/带货/知识/vlog/剧情/剧情带货）→ 决定"谁出镜 + 怎么拍"
3. **风格**（严肃/幽默/治愈/悬疑）→ 决定"用什么情绪拍"

**默认推荐**：演示型 + 带货视觉 + 治愈风格（最安全组合）
