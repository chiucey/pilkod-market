# 4 平台适配速查（Platform Adaptation）

> **v4 新增**：覆盖 **抖音 / 快手 / 视频号 / 小红书** 4 个平台。
> 脚本写完后,发布前必查本表调字幕 / 风格 / 话题 / 风险点。
> 合规红线见 `references/compliance.md`。

## 一、4 平台对比速查

| 维度 | 抖音 | 快手 | 视频号 | 小红书 |
|---|---|---|---|---|
| **甜点时长** | 15-30s | 15-60s | 30-60s | 15-30s |
| **钩子节奏** | 极快（0.3s 必须抓人） | 中等（老铁文化） | 中慢（知识/实用） | 封面党 + 标题党 |
| **字幕策略** | 0.5s 出大字 | 方言+普语双字幕 | 字幕勿压 logo | 封面图必须有标题 |
| **审核重点** | 功效/医疗/低俗/极限词 | 老铁/真实 | 涉政零容忍/养生 | 软广必须标识 |
| **话题风格** | 强情绪/梗 | 接地气/真实 | 知识/实用 | 种草/审美/标签党 |
| **BGM 风格** | 卡点 / 流行 | 接地气 / 抖音热歌 | 沉稳 / 文艺 | 治愈 / 氛围感 |
| **CTA 风格** | 购物车+加橱窗 | 主页/小店 | 关注/私域引流谨慎 | 评论区/收藏夹 |
| **封面要求** | 动态文字 + 强情绪 | 真实感 | 字幕不压 logo | 颜值即正义+标题 |
| **禁忌** | 站外引流立即限流 | 民族/宗教严禁 | 涉政/涉黄零容忍 | 不标 #广告 下架 |

## 二、抖音（强情绪 + 短平快）

### 特点
- 算法对**前 3 秒留存**最敏感（前 0.3 秒决定停留）
- 复看率 / 收藏率 / 评论质量 > 点赞数
- 创意上限高，"你绝对想不到"已经免疫

### 适配策略
- **节奏**：极快，0-3s 必须有强刺激
- **字幕**：0.5s 内出核心信息大字，配色用撞色
- **BGM**：抖音热歌 + 卡点
- **风格**：幽默 / 治愈 / 剧情 优先
- **话题**：#打工人日常 #办公好物 #美食 等强情绪
- **CTA**：购物车 + 加橱窗 + 关注
- **禁忌**：站外引流（"加微信"）立即限流

### 实用模板
- 剧情带货 15s：钩(3s) + 展(10s) + 收(2s)
- 口播带货 15s：钩(3s) + 卖点 1-3 个(10s) + CTA(2s)

---

## 三、快手（接地气 + 老铁信任）

### 特点
- 老铁文化，方言 / 真实感 / 信任关系
- 比抖音对"功效承诺"略松，但对"虚假宣传"严
- 直播带货生态成熟

### 适配策略
- **节奏**：中等，不用追求抖音那种极限
- **字幕**：方言 + 普通话双字幕（提高完播）
- **BGM**：接地气版本，参考快手热榜
- **风格**：剧情 / 幽默 / 真实生活
- **话题**:#老铁 #真实生活 #东北话 等地域标签
- **CTA**：主页 + 小店 + 私信（站内）
- **禁忌**：未成年人 / 民族 / 宗教 / 政治

### 实用模板
- 真实生活 vlog 15-30s
- 接地气剧情带货 30s

---

## 四、视频号（微信生态 + 严政治 + 中年人群）

### 特点
- 微信生态中，**微信好友可见**，社交属性强
- **涉政 / 涉黄 / 涉暴** 零容忍
- 用户年龄偏大（30-60 岁为主）
- 知识 / 实用 / 真实生活最受欢迎
- 私域引流最敏感（"加微信"会被判定为站外引流）

### 适配策略
- **节奏**：中慢，知识/实用内容可放长
- **字幕**：严禁压住右上角分享按钮或品牌 logo
- **BGM**：文艺 / 沉稳 / 不浮夸
- **风格**：知识 / 实用 / 真实生活 / 治愈
- **话题**：#生活智慧 #实用技巧 #家庭 等中年人群标签
- **CTA**：关注视频号（不轻易加微信）
- **禁忌**：
  - 涉政 / 涉领导人 / 国旗国徽 → 零容忍
  - "加微信领 XX" → 站外引流限流
  - 虚假养生 / 医疗 → 严打

### 实用模板
- 知识科普 30-60s
- 实用生活技巧 30s
- 真实生活 vlog 60s

---

## 五、小红书（种草 + 颜值 + 软广必标识）

### 特点
- **软广必须标识**：#广告 / #赞助 / 品牌合作 / 利益相关
- 封面党：标题+颜值双重吸引
- 标签党：缺标签 = 没流量
- 用户主动搜索占比高（关键词优化重要）
- 美妆 / 穿搭 / 家居 / 母婴最强

### 适配策略
- **节奏**：15-30s 最佳
- **封面**：必须有"标题 + 颜值产品"双重吸引
- **字幕**：不要遮挡产品细节
- **BGM**：治愈 / 氛围感
- **风格**：种草 / 审美 / 体验 / 治愈
- **话题**：#好物分享 #种草 #XX测评 等标签党
- **CTA**：评论区互动 / 收藏夹 / 店铺
- **软广**：
  - 标题前加 `#广告` 或 `#赞助`
  - 正文写"本笔记含商业推广"
  - 否则被举报 → 下架 + 扣信用分

### 实用模板
- 体验型 15-30s（美妆/香水/穿搭）
- 选择型 30s（多 SKU 对比）
- 演示型 15-30s（食品/家居）

## 六、跨平台复用策略

一条脚本可以**多平台发布**，但要按平台调：

| 调节点 | 抖音 | 快手 | 视频号 | 小红书 |
|---|---|---|---|---|
| 时长 | 15-30s | 15-60s | 30-60s | 15-30s |
| 字幕 | 0.5s 大字 | 双字幕 | 勿压 logo | 封面党 |
| 风格 | 强情绪 | 接地气 | 知识/实用 | 治愈/审美 |
| 话题 | 强情绪 | 地域/真实 | 中年实用 | 标签党 |
| CTA | 购物车 | 主页/小店 | 关注 | 评论区/收藏 |
| 合规 | 极限词 | 民族/宗教 | 涉政/私域 | 软广标识 |

**复用流程**:
1. 选定目标平台（默认抖音）
2. 写完脚本 → 按目标平台调 5 个调节点
3. 多平台发布 → 改封面 + 改话题 + 改 CTA
4. 不要把抖音的"快剪+强情绪"硬塞到视频号
5. 不要把抖音的"购物车 CTA"硬塞到小红书

## 七、平台选择判断

按目标人群 / 商品 / 调性 选平台：

| 情况 | 推荐平台 |
|---|---|
| 25-40 都市男女 / 强情绪 / 短平快 | 抖音 |
| 25-50 接地气 / 老铁信任 / 下沉市场 | 快手 |
| 30-60 中年 / 知识实用 / 真实生活 | 视频号 |
| 18-40 女性 / 种草 / 颜值 / 体验 | 小红书 |
| 通用（多平台分发） | 抖音 + 小红书（流量大 + 软广合规） |

**默认平台：抖音**（用户基础最大、算法对完播友好、商业化成熟）
