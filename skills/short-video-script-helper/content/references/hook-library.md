# 钩子库 v2.0(去重 + 扩列 + 错位维度 + 适用品类)

> **v4.0 升级**：去重 + 加 2 列(推荐错位 / 适用品类) + 类型 5 补真句式。
> 每行 = `#` + `句式` + `占位符示例` + `推荐错位` + `适用品类`。
> 错位手法统一定为 6 种(场景/服饰/动作/反常识/数字/身份诡计)。

---

## 使用规则

1. 句中的「…」是**待替换占位符**，填入你的主题/产品/人群即可成句
   - 例：「我愿称为…天花板」→「我愿称为这条裙子的显瘦天花板」
2. 前 3 秒决定完播率。钩子只负责把人留住，**正文必须兑现承诺**，否则适得其反
3. 一个钩子对应一种类型，套用时要清楚它在打哪个心理按钮
4. **用「推荐错位」列找错位方向** + 用「适用品类」列匹配商品
5. 套用后按 [SKILL.md 统一 Self-check](11 项) 验证

## 钩子组合实战模板

**模板 A:剧情带货万能组合(最常用)**
```
视觉暴力(响指/砰) + 反差(前男友/同事/老板对比) + 痛点共鸣
```

**模板 B:口播带货万能组合**
```
痛点直给(具体数字) + 情绪共鸣("家人们") + 强 CTA 收尾
```

**模板 C:知识类万能组合**
```
悬念提问("为什么 XX 是 YY?") + 视觉暴力(震惊脸) + 钩子承诺("藏着一个 XX")
```

**模板 D:vlog/生活类万能组合**
```
情绪共鸣("家人们…") + 反差(对比) + 自嘲("是我太天真了")
```

## 自检清单(写钩子时必跑)

> **本表为辅助清单，发布前必须按 [SKILL.md 统一 Self-check](11 项) 跑一遍。**

- [ ] 钩子能否在 3 秒内念完?(否则就不是钩子，变成开场白)
- [ ] 是否避开了自我介绍和铺垫?
- [ ] 是否有"具体细节"(数字/人名/场景)而非抽象描述?
- [ ] 是否能让人下意识"想知道接下来"?
- [ ] 这个钩子打的是哪个心理按钮?(损失厌恶?好奇?共鸣?)
- [ ] 正文是否能兑现这个钩子的承诺?(不能兑现就别用)
- [ ] **错位维度 ≥ 1 项**(场景/服饰/动作/反常识/数字/身份诡计,见各行「推荐错位」列)
- [ ] **适用品类匹配**(避免把知识类钩子套到食品)
