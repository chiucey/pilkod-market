## 怎么选 V1 还是 V2

| 判定信号 | 用 V1 | 用 V2 |
|---|---|---|
| 产品形态 | 实物 / 食用 / 用品 | 虚拟 IP / 拟人化物件 |
| 主目的 | 单条带货 / 一次性转化 | 长期养号 + 商单预留 |
| 制作方式 | 真人拍 / 剪映后期 | AI 图生视频(可灵 / 即梦 / MiniMax-H3) |
| 风格 | 情感 / 故事 / 共鸣 | 魔性 / 搞笑 / 快剪 |
| 钩子偏好 | 双关 / 悬念 / 共鸣 | 拟人化 / 反差 / XX 占位 |
| 时长复用 | 一次性 15s 脚本 | 15s 模板(可复用 N 次) |
| 商单预留 | 不需要 | 13-15s 留 2 秒槽位 |

## V1 核心方法(情感/共鸣型产品)

### 适用产品
- 童年记忆、怀旧、亲情、友情类
- "为什么 / 怎么"类悬念
- 任何带"情感属性"的产品

### 4 个可复用模式

1. **"双关钩子"公式**
   - 模板: "你以为 A,其实 B"(表面词 + 真实意)
   - 例: "我怀疑这桂花酸梅汤里加了童年的味道"("童年"是物理+情感双关)
   - 适用: 任何带"情感属性"的产品(童年 / 家 / 亲人 / 第一次)
   - 优势: 钩子新颖、自带深度、不撞款

2. **"道具暗示" 胜过 "真人童年戏"**
   - 15s 内不做真实童年闪回,改用老式搪瓷杯 + 老电扇 + 慢动作
   - 原因: 成本最低,15s 装不下复杂剧情
   - 兜底: 实在不行,删掉闪回段,只保留"恍惚回神"的微表情

3. **一镜到底配音稿 ≈ 55 字**
   - 15s 标准甜蜜点
   - 比"50-80 字"更紧,适合边演边说
   - 结构: 钩(15-20字) + 展(20-25字) + 收(10-15字)

4. **"产品 + 情绪" 双层话题**
   - 产品类(垂直): #桂花酸梅汤 #夏日消暑
   - 情绪类(泛人群): #童年记忆 #打工人日常
   - 组合后算法池最广

## V2 核心方法(虚拟 IP / 拟人化 / AI 视频生成专用)

### 适用产品
- 虚拟 IP 养号(虚拟猫咪 / 数字人)
- 拟人化物件(娃娃 / 手办 / 食物)
- AI 视频生成产物(可灵 / 即梦 / MiniMax-H3)
- 长期可复用的"角色"

### 5 个可复用模式

1. **"商单位预留"结构**
   - 13-15s 留 2 秒"槽位",接广告时只改这一段
   - 模板: 钩 3s + 展 10s + **商单位 2s**
   - 优势: 一个脚本可多次复用,商单来了无缝切换

2. **"5 段快剪"舞蹈公式**
   - 抖肩 → 华尔兹 → 比心 → 太空步 → 萨满摇
   - 每段 2 秒,卡点切换
   - 替换规则: 用当下热门 BGM 卡点替换 5 个舞种

3. **"AI 提示词模板化"**
   - DeepSeek 分镜师 prompt 模板
   - 每段输出: [舞种] | 动作描述 | 背景描述 | 卡点位置 | 字幕
   - 喂给可灵 / 即梦时直接复制动作描述

4. **"母句占位符" 「XX」**
   - 钩子里留 "XX" 占位
   - 例: "我家猫跳 XX 一周瘦了 3 斤"("XX"可填任何舞种)
   - 优势: 长期可复用,不用每次重写钩子

5. **"养号 + 商单" 双轨**
   - 无商单时: "评论区告诉我下期跳什么,关注蹲"
   - 有商单时: 直接接品牌口播
   - 同一脚本,广告来了 5 分钟切换

## 关键警示(用户真实反馈)

> "我们这几天发布了几个视频,效果一般,我突然想到一件事,我觉得我们可以升级了"
> —— mvs_e4f5691 用户原话

**真实情况**: 脚本方案做得扎实,**但 AI 视频生成执行环节出问题** —— 具体见 fino 洗发水 1.6s 失败案例(2026-10-01 上传)。

下次写脚本时,如果是 AI 视频生成,必须:
- 每个分镜时长不超过 AI 工具的最小生成时长(通常 5-10s)
- 演员动作要"大幅度 + 慢动作 + 易识别",避免"嘘"等小手势
- AI 视频生成常无声 → 必须用字幕扛信息密度
- 多个 AI 分镜 → 用剧情短句+字幕分割,不要追求一个长镜
- **AI 视频生成能力 + 商品一致性检查 + 动作验收** 详见 `references/ai-video-capability.md`
- **失败案例与诊断模式** 详见 `references/diagnosis-archive.md` 案例 #001 Fino

## 复用判定流程(Round 2 时跑)

```
Step 1: 看产品
  ├─ 实物 / 食用 / 用品 → 进入 V1
  └─ 虚拟 IP / 拟人化 → 进入 V2

Step 2: 看主目的
  ├─ 单条带货 → V1
  └─ 长期养号 + 商单 → V2

Step 3: 看制作方式
  ├─ 真人拍 → V1 优先(V1 设计的就是真人路径)
  └─ AI 视频生成 → V2 优先,但要按"关键警示"约束

Step 4: 对应 4 / 5 个模式
  V1: 钩子双关 + 道具暗示 + 55字配音 + 双层话题
  V2: 商单位 + 5段快剪 + AI 提示词 + XX 占位 + 双轨 CTA

Step 5: 自评
  - 8-10 分: 可投放
  - 6-7 分: 优化扣分点
  - <6 分: 重做
```
