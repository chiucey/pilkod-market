# 5 种脚本结构骨架（Script Skeletons）

> 解决"默认幽默剧情带货"的偏见。
> 不同商品需要不同结构来"卖货"，剧情只是其中之一。
> **幽默搞笑是风格选项，不是默认结构。**

---

## 一、5 种骨架总览

| 骨架 | 核心逻辑 | 适用商品 | 不适合 |
|---|---|---|---|
| **演示型** | 展示使用过程 + 可见结果 | 食品冲泡、家居工具、清洁用品、美妆操作 | 纯品牌类（无具体功能） |
| **选择型** | 谁适合 + 关键差异 + 规格 | 3C、家电、多 SKU 商品、高客单 | 单一规格的标品 |
| **体验型** | 真实场景 + 细节感受 | 美妆、香水、服饰、贴身用品 | 实用性强的工具 |
| **剧情型** | 冲突 + 产品参与解决 + 展示依据 | 通用、玄学、礼物、低决策成本 | 需要详细规格说明的商品 |
| **答疑型** | 用户顾虑 + 直接回答 + 演示 | 工具、3C、健康、功效型商品 | 单纯颜值 / 情绪类 |

**默认推荐**：按商品类型智能匹配，**不默认剧情**。如用户明确说"做剧情"，才走剧情型。

---

## 二、骨架详解

### 骨架 1：演示型
**适用场景**：用户需要看到"怎么用、用起来什么样"
**典型产品**：桂花酸梅汤（怎么冲）、懒人抹布（怎么擦）、冲泡咖啡、清洁喷雾

**结构**：
```
钩(0-3s)：具体问题 / 反常识陈述
卖点证据 1(3-8s)：使用过程演示 + 细节特写
卖点证据 2(8-13s)：可见结果对比 + 数字/规格
适用条件(13-15s)：谁适合 / 怎么选 + CTA
```

**桂花酸梅汤示例**：
- 钩：「桂花酸梅汤别再乱买了！这3点选错等于白花钱」（痛点直给）
- 演示 1(3-6s)：把粉末倒入杯中 + 注水 + 搅拌（特写手部 + 杯中颜色变化）
- 演示 2(6-10s)：喝一口 + 表情变化 + 大字幕「酸甜不涩，0 添加剂」
- 规格(10-13s)：展示包装规格 +「20g×30 袋，独立小包」
- 收(13-15s)：「送便携杯，点击购物车」

**注意**：演示型不能跳过"使用过程"，否则就成了剧情型。

---

### 骨架 2：选择型
**适用场景**：用户有选择困难，需要帮 ta 决策
**典型产品**：3C（手机/耳机）、家电、多 SKU 美妆、高客单

**结构**：
```
钩(0-3s)：谁适合 + 反常识陈述
关键差异(3-8s)：横向对比 2-3 个关键参数
规格选择(8-13s)：按人群/场景推荐
下单提醒(13-15s)：避坑提醒 + CTA
```

**耳机示例**：
- 钩：「买耳机别只看音质！这3点选错直接吃灰」（痛点直给 + 反常识）
- 差异(3-6s)：左「普通耳机 - 漏音严重」/ 右「这款 - 定向传声」+ 大字幕
- 差异(6-9s)：佩戴对比 +「连续戴 4 小时不痛」
- 规格(9-13s)：3 个 SKU 对比（标准/Pro/Max）+ 按人群推荐
- 收(13-15s)：「选错退不了,链接在评论区」

**注意**：选择型必须有"具体规格对比"，空喊"好"不行。

---

### 骨架 3：体验型
**适用场景**：用户买的是感受/体验，不是功能
**典型产品**：香水、护肤、贴身衣物、奢侈品

**结构**：
```
钩(0-3s)：场景代入 + 细节暗示
使用感受(3-8s)：真实场景 + 感官细节
细节证据(8-13s)：成分/材质/工艺特写
适合谁(13-15s)：明确适合/不适合 + CTA
```

**香水示例**：
- 钩：「周末喷了这款香水，陌生人问了我3遍」（场景代入 + 反差）
- 感受(3-6s)：咖啡馆场景 + 喷香水 + 路人回头
- 感受(6-9s)：特写香水瓶 + 香气弥漫
- 细节(9-12s)：成分特写「前调柑橘/中调玫瑰/后调麝香」+ 工艺镜头
- 适合(12-15s)：「适合通勤/约会/晚宴,不适合运动/重场合」+ CTA

**注意**：体验型不能"只说感受不说成分"，必须有可验证的细节。

---

### 骨架 4：剧情型
**适用场景**：用户决策成本低，需要被吸引/情绪打动
**典型产品**：玄学挂件、零食、礼物、低单价小物件

**结构**：
```
钩(0-3s)：冲突场景 + 戏剧张力
产品参与解决(3-8s)：产品出现 + 解决冲突
展示依据(8-13s)：为什么有效 + 可视化细节
收尾(13-15s)：情绪升华 + CTA
```

**蓝莓挂件示例**：
- 钩：「通勤路上又遇到讨厌的人？」（场景冲突 + 痛点）
- 产品(3-6s)：掏出蓝莓挂件 +「自从我挂了它」(产品第一次出现)
- 依据(6-10s)：谐音梗动画 + 治愈细节(捏挂件 / 软fufu)
- 升华(10-13s)：春日街景 + 心情变好
- 收(13-15s)：「拦霉运,链接在购物车」

**注意**：剧情型必须有"为什么有效"的展示依据,不能纯搞笑完事。

---

### 骨架 5：答疑型
**适用场景**：用户有具体顾虑，需要打消
**典型产品**：工具、3C、健康用品、功效型产品

**结构**：
```
钩(0-3s)：用户顾虑直说
直接回答(3-8s)：数据/原理/对比
演示支撑(8-13s)：实际演示/资料证据
行动引导(13-15s)：适用场景 + CTA
```

**榨汁机示例**：
- 钩：「买榨汁机最怕什么？洗不干净！」（用户顾虑直说）
- 回答(3-6s)：特写刀头 +「可拆可水冲,10 秒洗干净」
- 演示(6-9s)：拆洗演示 + 装机演示
- 资料(9-12s)：对比清洗时间（普通榨汁机 3 分钟 vs 这款 10 秒）
- 引导(12-15s)：「适合懒人/宝妈/租房党」+ CTA

**注意**：答疑型必须先列出"用户顾虑"再回答,不能自问自答。

## 四、骨架 × 钩子类型 = 30 种组合

| 骨架 \\ 钩子类型 | 痛点直给 | 反差猎奇 | 情绪共鸣 | 悬念提问 | 视觉暴力 |
|---|---|---|---|---|---|
| 演示型 | "别再乱买" | "我才知道原来 X 这么用" | "厨房懒人终于有救了" | "为什么 X 步骤是反的" | [产品爆破镜头] |
| 选择型 | "买 X 别只看 Y" | "3 个 SKU 怎么选" | "我之前选错了 X" | "为什么贵的反而不好" | [3 个产品对比] |
| 体验型 | "周末喷了 X 香水" | "穿了 X 才发现" | "那一刻我才知道" | "为什么 X 这么上头" | [特写镜头] |
| 剧情型 | "自从我用了 X" | "X 居然能解决这个" | "那天我才发现 X" | "为什么 X 能让 XX 变好" | [戏剧冲突] |
| 答疑型 | "买 X 最怕什么" | "X 居然能 YY" | "X 治好了我的 ZZ" | "为什么 X 不 YY" | [顾虑特写] |

## 五、骨架 × 风格（幽默是风格选项）

骨架是结构，风格是情绪。两者可任意组合：

| 骨架 | 风格 = 严肃 | 风格 = 幽默 | 风格 = 治愈 | 风格 = 悬疑 |
|---|---|---|---|---|
| 演示型 | 标准产品视频 | 反转演示（演示失败再成功） | 慢动作特写 + 治愈 BGM | 显微镜下揭示真相 |
| 选择型 | 客观对比 | 反差对比（自己打脸） | 真实生活场景对比 | 信息层层递进 |
| 体验型 | 真实记录 | 自我吐槽 | 第一人称叙述 | 留白式叙述 |
| 剧情型 | 戏剧冲突 | 夸张表演 + 自嘲 | 温柔日常 | 反转揭秘 |
| 答疑型 | 直接回答 | 自问自答 + 抖机灵 | 真实案例分享 | 顾虑可视化 |

**默认风格**：根据用户产品/品牌调性匹配，**不默认幽默**。如用户说"要幽默"再走幽默。

## 六、骨架自检清单

每条脚本输出前过一遍：
- [ ] 骨架选型有没有按商品类型匹配？(不默认剧情)
- [ ] 骨架内"卖点证据"是否可证？(演示过程 / 规格表 / 材质细节)
- [ ] 骨架内"为什么买"是否清晰？(解决了什么问题 / 适合谁)
- [ ] 钩子风格是否与骨架匹配？(严肃骨架不要"哈哈哈哈哈"开场)
- [ ] 收尾 CTA 是否对应该骨架的最终目标？

7 项过 5 项以上才输出。
