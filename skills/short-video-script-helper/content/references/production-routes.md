# 3 种制作路线（Production Routes）

> 不同商品、不同预算、不同人手 = 不同制作路线。
> 不默认"剧情 + AI 生成"路线。

---

## 路线 1：真人口播 + 商品实拍

**核心**：真人出镜讲解，插入操作和细节镜头。

**适合**：
- 知识类 / 种草类 / 测评类
- 商品需要"人讲解"才能讲清楚
- 决策成本较高的商品

**优点**：
- 可信度高（真人背书）
- 制作相对简单（手机+自然光即可）
- 复用性强（同一演员拍多个产品）

**缺点**：
- 演员表达力决定上限
- 需要真人配合时间
- 镜头单一容易看腻

**配置清单**：
- 演员 1 人（主理人 / 模特）
- 手机或相机 1 台
- 稳定器（可选）
- 反光板 / 自然光
- 商品 + 包装 + 赠品
- 收音设备（小蜜蜂 / 领夹麦）

**拍摄脚本模板**：
```
[钩 0-3s] 演员直视镜头 + 钩子文案
[展 3-8s] 演员演示使用 + 插入特写
[展 8-13s] 演员讲解卖点 + 真实操作
[收 13-15s] 演员引导行动 + 指向购物车
```

---

## 路线 2：不露脸的手部演示

**核心**：不露脸，只拍手部操作 + 商品 + 桌面场景。

**适合**：
- 食品冲泡 / 收纳整理 / 清洁用品
- 工具 / 美妆操作 / 小型电子产品
- 演员门槛低（不需露脸）
- 拍摄环境：桌面 / 厨房台 / 卫生间

**优点**：
- 演员 0 门槛（任何人都能拍）
- 拍摄快（一遍过即可）
- 视觉信息密度高（不分散注意力）
- 制作成本极低

**缺点**：
- 缺乏"人物背书"
- 视觉冲击较弱
- 难以建立账号 IP

**配置清单**：
- 手机 + 三脚架（俯拍 / 侧拍）
- 商品 + 道具
- 桌面（建议纯色 / 木质）
- 自然光 / 顶灯

**拍摄脚本模板**：
```
[钩 0-3s] 桌面全景 + 商品居中 + 字幕
[展 3-8s] 手部操作特写 + 步骤字幕
[展 8-13s] 操作过程 / 效果对比特写
[收 13-15s] 商品特写 + 引导手势（指向购物车位置）
```

**适合账号**：种草号 / 测评号 / 厨房号 / 收纳号 / 工具号

---

## 路线 3：剧情 / AI 画面 + 真实商品展示

**核心**：用剧情或 AI 生成画面吸引注意，关键商品信息和效果由真实素材承接。

**适合**：
- 玄学 / 礼物 / 低决策成本
- 想要视觉冲击 / 创意差异化
- 演员难找 / 时间紧张

**优点**：
- 视觉上限高
- 创意空间大
- 不依赖固定演员

**缺点**：
- 制作成本高（AI 工具 / 设计师）
- 商品性能可信度低（必须真实镜头兜底）
- 周期长（AI 生成要多次抽卡）

**配置清单**：
- AI 视频工具（可灵 / 即梦 / Vidu / Sora 等）
- 商品 + 实拍素材
- 演员（可选，部分镜头需要真人）
- 设计师 / 剪辑师

**拍摄脚本模板**：
```
[钩 0-3s] AI 生成画面（剧情 / 视觉冲击）
[展 3-8s] AI + 真实素材混剪
[展 8-13s] 真实商品展示（关键证据）
[收 13-15s] 真实特写 + 引导购物车
```

**关键规则**：
- 商品性能证据（吸水 / 容量 / 适合场景）**优先用真实拍摄**
- AI 画面只承担情绪 / 故事 / 视觉创意
- 每个 AI 分镜必须配 1 个真实镜头兜底

---

## 路线选择判断表

| 你的情况 | 推荐路线 |
|---|---|
| 演员表达好 + 商品需要讲解 | 路线 1（口播+实拍） |
| 演员难找 + 商品适合演示 | 路线 2（手部演示） |
| 想要差异化 + 预算够 + 周期不紧 | 路线 3（剧情+实拍） |
| 食品/工具/收纳类 | 路线 2（首选） |
| 美妆/香水/服饰 | 路线 1 或 3 |
| 玄学/礼物/萌宠 | 路线 3（首选） |
| 3C/家电/功效型 | 路线 1（首选） |
| 抖音剧情号 | 路线 3（首选） |

---

## 路线切换原则

同一条脚本可以混用多种路线，例如：
- 钩(0-3s)：路线 3（AI 画面吸睛）
- 展(3-13s)：路线 1（演员讲解）
- 收(13-15s)：路线 2（商品特写）

**核心原则**：商品性能证据永远走真实路线，创意部分可走 AI 路线。
