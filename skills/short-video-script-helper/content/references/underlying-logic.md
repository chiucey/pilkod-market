# 短视频底层逻辑(为什么火?怎么火?)

> 这份文档解释短视频能让人上瘾的根本原因,以及平台算法是怎么分发的。
> 写脚本前理解这套机制,会比"凭感觉凑段子"稳得多。

## 一、人为什么爱看短视频(生理本能)

### 1. 多巴胺奖赏机制(开盲盒)
- 刷短视频像"开盲盒",永远不知道下一个视频是什么
- "未知的奖励"刺激多巴胺分泌,产生期待和快感
- **类比**:游戏抽卡、朋友圈刷新、期待外卖送达

**写脚本启示**:
- 钩子必须制造"未知的奖励"——观众不知道下一句是什么,但想看
- 反转/悬念天然契合这套机制(每几秒一个小反转 ≈ 多次"小盲盒")

### 2. 低认知负荷 + 齐加尼克效应
- 视频只有十几秒,看完毫无压力
- 大脑极易获得"完成一件事"的即时满足感
- 看完一个想接下一个,陷入"再看一个"的死循环

**写脚本启示**:
- 不要塞太满——15s 视频 50-80 字是上限,信息过载会让大脑拒绝"完成"
- 钩-展-收每一段都要有"完成感",让观众潜意识觉得"这一段值了"

### 3. 预期错位(爆款的认知根)

**短视频爆火的根本认知机制是"预期错位"**——观众带着预期 A 进来,实际看到 B,这种"被打断"的感觉才会让人停下来。**没有对抗预期就没有爆款逻辑。**

**5 种典型预期错位**(也对应 5 种钩子类型的认知根):

| 错位 | 心理 | 钩子类型 | 典型例 |
|---|---|---|---|
| **认知错位** | "你以为是这样,其实不是" | 反差/猎奇 | "月薪 3000 vs 30000 差距" |
| **情境错位** | "你以为不会发生,但发生了" | 逆袭/反转 | "万万没想到……" |
| **情感错位** | "你以为只是你这样,其实是共性" | 情绪共鸣 | "你是不是也这样" |
| **信息错位** | "你以为知道,其实不知道" | 悬念/提问 | "为什么飞机窗户是圆角" |
| **感官错位** | "你以为平静,突然被打断" | 视觉/听觉暴力 | "[砰]停!" |

**写脚本启示**:
- 每个钩子必须**至少制造一种预期错位**——没有错位就没有爆款
- 错位越"出乎意料但合理",爆发力越强(可预见 → 反转 → 不惊讶)
- 错位的强度 = (预期强度)→(现实反差强度);反差越大,完播率越高
- 正文展开要"兑现这个错位"——观众期待答案,你给答案(或更炸的反转)

**自检**(每个钩子问自己):
- "观众的预期是什么?"
- "我打碎了哪个预期?"

## 二、爆款公式:钩-展-收 三段式

爆款视频几乎都遵循这个结构:

```
🪝 钩(0-3 秒)        → 解决"我为什么要看"
📺 展(中间节奏)      → 解决"我为什么不划走"
🎯 收(最后 2-3 秒)   → 解决"我要不要点赞/关注/购买"
```

### 钩(0-3 秒)
- **任务**:强行抓住观众眼球
- **方法**:强烈冲突 / 悬念 / 痛点 / 利益
- **错误示范**:自我介绍、铺垫天气、客套开场
- **正确示范**:"月薪 3000 和 30000 的人,差距到底在哪里?"

### 展(中间节奏)
- **任务**:保持注意力
- **方法**:紧凑节奏,每隔几秒给一个信息点/笑点/视觉刺激
- **节奏公式**(以 15s 视频为例):
  - 0-3s:钩子
  - 3-8s:第一个刺激(信息/反转/笑点)
  - 8-13s:第二个刺激 + 产品露出
  - 13-15s:收

### 收(最后 2-3 秒)
- **任务**:完成流量转化
- **方法**:金句升华 / 直接引导互动(点赞/评论/关注/购买)
- **CTA 类型**:
  - 软引导:"如果你也觉得有用,点赞告诉我"
  - 硬引导:"点击购物车,数量有限"
  - 关注引导:"关注我,下期教你更多"
  - 转发引导:"转发给那个需要的朋友"

## 三、平台算法分发逻辑(流量怎么来)

平台是一个数据筛选机器。视频发布后:

```
发布视频 → 初始流量池(几百次播放) → 数据检测 → 扩大 / 停止
```

### 核心指标(算法在意的)

| 指标 | 含义 | 反映 |
|---|---|---|
| 完播率 | 用户看完了吗 | 内容是否留住人 |
| 点赞率 | 用户喜欢吗 | 内容质量 |
| 评论率 | 用户想说话吗 | 参与度/共鸣度 |
| 转发率 | 用户觉得有用吗 | 价值感 |
| 关注转化率 | 用户想看更多吗 | 内容长期价值 |

### 算法视角下的"好脚本"

- **完播率优先**:钩子要快,信息密度要合适(不能太满,也不能太空)
- **评论率撬动**:争议性话题、反转、提问都能拉评论率("你觉得 XX 是不是这样?")
- **转发率撬动**:实用价值、身份认同、情感共鸣能拉转发("转发给那个 XX 的朋友")
- **关注转化率撬动**:系列感、悬念("下期教你……")、人设鲜明

**写脚本启示**:
- 一个钩子不能只满足"留人",还要满足"撬动某项指标"
- 想要评论率?结尾留个问题("你们觉得 XX 怎么样?评论区告诉我")
- 想要转发率?结尾带身份认同("转给那个每天加班的朋友")

## 四、为什么是 15s?

- 15s 是抖音/快手算法推荐的"甜点位":能跑完一次完整完播,又短到能反复重看
- 30s 用于"需要展示过程/多个反转"的产品(美妆教程、剧情带货)
- 60s 用于"知识密度高/产品需要多角度展示"的场景,完播率门槛会显著提高

**判断规则**:
- 卖点单一 + 适合反转/钩子 → 15s
- 卖点 2-3 个 + 需要展示使用过程 → 30s
- 知识/教程 + 多步骤 → 60s
