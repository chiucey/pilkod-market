## 六、使用技巧

### 如何将AI代码转换为draw.io图形

**方法1：Mermaid直接导入**
1. 在draw.io中：文件 → 打开 → 粘贴Mermaid代码
2. 自动生成图形

**方法2：XML粘贴**
1. 让AI生成完整的draw.io XML
2. 在draw.io中：编辑 → 粘贴
3. 图形自动出现

### 常见问题解决

| 问题 | 解决方案 |
|------|---------|
| 中文显示乱码 | 确保使用UTF-8编码 |
| 布局不美观 | 手动调整节点位置 |
| 箭头方向错误 | 检查连接线的source和target |
| 样式不统一 | 使用批处理脚本统一样式 |
