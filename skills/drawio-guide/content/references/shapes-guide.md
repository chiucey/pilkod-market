# draw.io 形状库完整指南

## 一、基础形状

### 1.1 常用形状（General）

| 形状 | 名称 | 用途 |
|-----|------|-----|
| 矩形 | Rectangle | 最通用的形状，用于表示流程、步骤、文档 |
| 圆角矩形 | Rounded Rectangle | 表示开始/结束，或友好的操作步骤 |
| 菱形 | Diamond | 表示判断、决策节点 |
| 椭圆形 | Ellipse | 表示开始、结束，或备注信息 |
| 三角形 | Triangle | 表示流程方向 |
| 六边形 | Hexagon | 表示准备阶段 |
| 平行四边形 | Parallelogram | 表示输入/输出操作 |
| 文档形状 | Document | 表示文档、报告 |
| 圆柱形 | Cylinder | 表示数据库、存储 |
| 漏斗形 | Funnel | 表示过滤、筛选过程 |

### 1.2 流程图形状（Flowchart）

| 形状 | 名称 | 用途 |
|-----|------|-----|
| 流程 | Process | 标准处理步骤 |
| 判断 | Decision | 条件判断（是/否） |
| 数据 | Data | 输入/输出操作 |
| 文档 | Document | 文件、报告 |
| 多文档 | Multidocument | 批量文档 |
| 终止 | Terminator | 流程起点/终点 |
| 准备 | Preparation | 初始化、准备 |
| 手动输入 | Manual Input | 人工操作 |
| 手动操作 | Manual Operation | 半自动步骤 |
| 连接器 | Connector | 流程连接 |
| Or | Or | 并行分支合并 |

### 1.3 组织结构图形状（Org Chart）

| 形状 | 名称 | 用途 |
|-----|------|-----|
| 主管 | Executive | 最高管理层 |
| 副主管 |助理 | Deputy / Assistant |
| 经理 | Manager | 中层管理 |
| 员工 | Employee | 普通员工 |
| 顾问 | Consultant | 外部顾问 |

## 二、箭头与连接线

### 2.1 箭头样式

| 类型 | 说明 |
|-----|------|
| 普通箭头 | 最常用的流程指示 |
| 开口箭头 | 表示流程方向 |
| 菱形端点 | 表示数据流向 |
| 圆形端点 | 表示连接点 |
| 无箭头 | 表示关联关系 |

### 2.2 连接线类型

| 类型 | 说明 |
|-----|------|
| 直角线 | 标准流程线 |
| 曲线 | 柔和的过渡 |
| 虚线 | 表示可选流程或间接关系 |
| 点线 | 表示建议或参考 |

## 三、图标库

draw.io 内置多种图标，可通过以下方式添加：

1. 左侧面板 → "形状" → 搜索图标
2. 或通过 URL 插入外部图标

### 常用图标

| 图标 | 名称 | 用途 |
|-----|------|-----|
| 👤 | 用户/人 | 表示人员角色 |
| 📁 | 文件夹 | 表示归档、存储 |
| 📄 | 文档 | 表示文件 |
| 📧 | 邮件 | 表示邮件通知 |
| ✅ | 勾选 | 表示已完成 |
| ❌ | 叉号 | 表示否决/拒绝 |
| ⏰ | 时钟 | 表示时间节点 |
| 📍 | 位置 | 表示地点 |

## 四、样式设置

### 4.1 快速样式

- **填充颜色**：为形状添加背景色
- **字体颜色**：设置文字颜色
- **线条颜色**：设置边框颜色
- **线条粗细**：0.5pt - 5pt

### 4.2 渐变效果

draw.io 支持线性渐变和径向渐变，适合制作展示型图示。

### 4.3 阴影效果

可添加预设阴影或自定义阴影参数（偏移量、模糊度、颜色）。

## 五、快捷技巧

### 5.1 快速复制样式

1. 选中已设置样式的形状
2. 按 `Ctrl + Shift + C` 复制样式
3. 选中其他形状，按 `Ctrl + Shift + V` 粘贴样式

### 5.2 快速对齐

1. 选中多个形状
2. 右键 → "排列" → 选择对齐方式
   - 左对齐
   - 居中对齐
   - 右对齐
   - 顶部对齐
   - 底部对齐
   - 水平分布
   - 垂直分布

### 5.3 快速调整大小

| 操作 | 方法 |
|-----|------|
| 等比缩放 | 按住 Shift 拖动角落 |
| 中心缩放 | 按住 Alt 拖动角落 |
| 精确尺寸 | 选中后输入具体数值 |

### 5.4 锁定与解锁

- **锁定**：防止误操作，可右键 → "锁定"
- **解锁**：选中后右键 → "解锁"
