# 团队协作最佳实践

本指南帮助团队在draw.io中高效协作，确保流程图的标准化和一致性。

---

## 一、团队标准化配置

### 1.1 统一样式配置

团队应统一以下配置，确保所有成员输出的图形风格一致：

| 元素 | 标准配置 | 颜色代码 |
|------|---------|---------|
| 主要流程 | 矩形，蓝色 | #4472C4 |
| 判断节点 | 菱形，橙色 | #ED7D31 |
| 开始/结束 | 椭圆，绿色/红色 | #70AD47 / #C00000 |
| 连接线 | 深蓝箭头 | #2F5597 |
| 背景色 | 白色或浅灰 | #FFFFFF / #F5F5F5 |
| 字体 | 微软雅黑 | - |

### 1.2 导出共享模板

**导出团队样式：**
1. 绘制一个标准形状
2. 设置好样式
3. 右键 → 格式 → 复制样式代码
4. 保存到团队共享文档

**批量导入：**
1. 打开draw.io
2. 格式 → 编辑样式
3. 粘贴团队样式代码

## 二、文件管理规范

### 2.1 命名规范

```
[类型]-[项目]-[版本]-[日期].drawio

示例：
流程-公文处理-v1.0-20260414.drawio
架构-组织结构-v2.1-20260415.drawio
汇报-季度总结-2026Q1.drawio
```

### 2.2 目录结构

```
drawio-projects/
├── 01-流程图/
│   ├── 公文处理/
│   ├── 绩效考核/
│   └── 会议管理/
├── 02-架构图/
│   ├── 组织结构/
│   └── 系统架构/
├── 03-汇报材料/
│   └── 季度汇报/
└── 04-归档/
```

### 2.3 版本控制

| 操作 | 建议 |
|------|------|
| 大改版本 | v1.0 → v2.0 |
| 小改版本 | v1.0 → v1.1 |
| 紧急修复 | v1.0 → v1.0.1 |
| 归档版本 | 添加日期后缀 |

## 三、协作工作流

### 3.1 集中管理流程

```
1. 负责人创建主文件
2. 团队成员Fork副本
3. 完成后提交审核
4. 负责人合并更新
5. 发布最终版本
```

### 3.2 分支管理模式

| 角色 | 权限 | 职责 |
|------|------|------|
| 管理员 | 全部权限 | 创建、审核、合并、发布 |
| 编辑 | 编辑权限 | 绘制、修改 |
| 审阅者 | 只读权限 | 查看、批注 |

### 3.3 审核流程

```
提交审核 → 初审(格式) → 复审(内容) → 批准发布
    ↓           ↓            ↓           ↓
  返回修改    返回修改      返回修改     版本归档
```

## 四、共享与同步

### 4.1 云端存储

**推荐存储位置：**
- 企业微信/钉钉文档
- 腾讯文档
- OneDrive / Google Drive
- 自建NextCloud

**注意事项：**
- 设置合理的同步频率
- 开启版本历史功能
- 定期备份本地副本

### 4.2 离线协作

```
1. 负责人分享.drawio文件
2. 团队成员下载到本地
3. 各自编辑完成后提交
4. 负责人手动合并更新
```

### 4.3 批量导出分享

**导出为PDF报告：**
1. 多个图形合并为一个PDF
2. 添加目录和页码
3. 发送给团队成员

## 五、反馈与批注

### 5.1 使用批注功能

1. 选中要评论的图形
2. 右键 → 添加评论
3. 输入反馈内容
4. @提及团队成员

### 5.2 问题标记

| 标记类型 | 颜色 | 含义 |
|---------|------|------|
| 待确认 | 黄色 | 需要进一步确认 |
| 需修改 | 橙色 | 需要修改 |
| 已完成 | 绿色 | 审核通过 |
| 紧急 | 红色 | 需要优先处理 |

### 5.3 审核清单

```
□ 流程逻辑正确
□ 节点命名清晰
□ 样式符合规范
□ 无交叉连线
□ 导出格式正确
□ 团队成员确认
```

## 六、安全与权限

### 6.1 访问控制

| 人员类型 | 访问权限 |
|---------|---------|

- 离职工前及时收回权限

## 七、效率提升技巧

### 7.1 快捷操作

| 操作 | 快捷键 |
|------|--------|
| 快速复制样式 | Ctrl+Shift+C / Ctrl+Shift+V |
| 成组操作 | Ctrl+G |
| 批量选择 | Ctrl+点击 |
| 快速查找 | Ctrl+F |

### 7.2 模板复用

1. 创建标准模板文件
2. 每次使用时"另存为"新文件
3. 避免直接修改原模板

### 7.3 自动化脚本

使用配套的Python脚本批量处理：

```bash
# 批量应用样式
python scripts/batch_style.py 行政蓝 *.drawio

# 批量导出图片
python scripts/batch_export.py --format png --dpi 300
```
