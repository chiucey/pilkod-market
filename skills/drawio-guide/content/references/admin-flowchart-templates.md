## 四、标准规范

### 4.1 流程图绘制标准

| 项目 | 标准要求 |
|-----|---------|
| 方向 | 从上到下，从左到右 |
| 箭头 | 表示流程方向，统一使用 |
| 形状 | 同类图形使用统一样式 |
| 颜色 | 同一图示使用不超过3种颜色 |
| 文字 | 简洁清晰，避免换行 |
| 比例 | 形状大小协调，避免过密或过疏 |

### 4.2 论文插图规范

| 项目 | 要求 |
|-----|------|
| 分辨率 | ≥ 300 DPI |
| 格式 | PNG（位图）或 SVG（矢量） |
| 色彩 | 黑白或灰度为主 |
| 字号 | 图内文字 ≥ 10pt |
| 边框 | 添加简洁边框 |
| 标题 | 图下方居中标注 |

### 4.3 汇报PPT图示规范

| 项目 | 要求 |
|-----|------|
| 风格 | 简洁专业，符合公司VI |
| 配色 | 与PPT整体风格统一 |
| 元素 | 突出核心信息，去除冗余 |
| 动画 | 适度使用，避免喧宾夺主 |

## 十五、文件导出与Office集成

### 15.1 导出到Word

**推荐格式选择：**
| 格式 | 适用场景 | 设置要点 |
|------|---------|---------|
| PNG | 论文插图 | 分辨率 300dpi，透明/白色背景 |
| SVG | 可编辑文档 | 矢量格式，放大不失真 |
| PDF | 正式文件 | 适合打印和存档 |

**插入Word步骤：**
1. draw.io：文件 → 另存为 → 选择 PNG/SVG
2. Word：插入 → 图片 → 选择文件
3. 设置环绕方式：四周型/嵌入型

### 15.2 导出到PowerPoint

**PPT最佳格式：**
| 格式 | 优点 | 适用场景 |
|------|------|---------|
| PNG | 清晰度高 | 静态图示 |
| SVG | 可编辑颜色 | 需要统一风格 |
| EMF | 矢量无锯齿 | 打印质量要求高 |

**插入PPT步骤：**
1. draw.io：文件 → 导出为 PNG（推荐 2x 缩放）
2. PPT：插入 → 图片 → 选择文件
3. 取消锁定纵横比，调整大小

### 15.3 导出到Excel（数据可视化）

**方法一：复制粘贴**
1. draw.io 中选中图形
2. Ctrl+C 复制
3. Excel 中 Ctrl+V 粘贴

**方法二：导出为图片**
1. 导出为 PNG
2. Excel 中插入 → 图片

## 十六、常见问题FAQ

### Q1: 图形边缘有白色边框怎么去除？
**A:** 格式 → 页面设置 → 取消勾选"打印背景色/阴影"

### Q2: 导出PNG模糊怎么办？
**A:** 导出时选择2x或3x缩放，或导出为SVG矢量格式

### Q3: 中文字体显示异常？
**A:** 格式 → 文本 → 选择"微软雅黑"或"宋体"，避免使用特殊字体

### Q4: 怎么让连接线自动吸附到图形？
**A:** 视图 → 辅助线 → 启用"连接线吸附"，拖动时图形会高亮显示连接点

### Q5: 流程图太复杂怎么简化？
**A:**
- 使用泳道（Swimlanes）分区
- 拆分为主流程和子流程
- 使用"跳转到"符号减少连线交叉

### Q6: 怎么批量修改多个图形的样式？
**A:** Ctrl+点击选中多个图形 → 右侧格式面板统一设置

### Q7: 文件意外关闭怎么恢复？
**A:** 自动保存位置：`%APPDATA%\draw.io\autosave\`，或使用Ctrl+Alt+T访问历史版本

### Q8: 怎么制作可交互的流程图？
**A:** 使用draw.io的"页面"功能创建多页，每页代表一个流程状态

### 23.1 分层设计

```
Level 0: 目录页（所有流程一览）
    ↓
Level 1: 主流程图（概览）
    ↓
Level 2: 子流程图（详细展开）
    ↓
Level 3: 节点说明（每个步骤的详细文档）
```

**draw.io 实现方式：**
1. 使用"页面"功能创建多层级
2. 使用"跳转"符号连接不同页面
3. 使用目录形状创建导航页

### 23.2 大图打印技巧

**分页打印：**
1. 文件 → 打印 → 页面设置
2. 选择"适合页面"或"分页"
3. 预览确认分页位置
4. 建议添加页码和标题

**海报打印（多页拼贴）：**
1. 导出为 SVG
2. 使用Illustrator/Inkscape处理
3. 设置打印重叠区域便于拼接

### 23.3 性能优化

**优化大型流程图：**
| 问题 | 解决方案 |
|------|---------|
| 卡顿 | 关闭实时预览，批量操作后刷新 |
| 文件大 | 减少嵌入图片，使用链接 |
| 加载慢 | 简化分组，拆分文件 |
| 渲染慢 | 降低缩放级别 |

## 二十五、实战案例库

### 案例1：高校行政服务中心流程图

**场景：** 学生事务中心"一站式"服务流程

**涉及部门：** 学生处、教务处、财务处、后勤集团

**模板结构：**
```
[泳道1: 学生] → [泳道2: 服务中心] → [泳道3: 业务部门] → [泳道4: 办结]
```

**绘制要点：**
- 使用泳道分区明确责任
- 判断节点用菱形
- 结果节点用椭圆
- 标注预计时长

### 案例2：政府OA系统流程图

**场景：** 公文审批全流程（含会签）

**模板结构：**
```
拟稿 → 部门审核 → 办公室初审 → [并行] 会签部门 → 综合审核 → 领导签发
```

**绘制要点：**
- 并行处理用双向箭头
- 会签节点用虚线框
- 分支合并用汇聚箭头

### 案例3：毕业论文研究框架

**场景：** "大学生就业意向影响因素研究"框架图

**模板结构：**
```
理论基础 → 假设H1/H2/H3 → 自变量(X1/X2/X3) → 因变量(Y)
```

**绘制要点：**
- 假设用菱形
- 变量用矩形
- 结论用椭圆
- 箭头表示影响关系

### 案例4：企业年度考核流程

**场景：** 员工年度绩效考核全过程

**模板结构：**
```
发布通知 → 个人述职 → 民主测评 → 部门初评 → 考核小组复审 → 结果公示 → 存档
```

**绘制要点：**
- 时间轴布局
- 并行环节用虚线连接
- 结果分级用不同颜色标注
