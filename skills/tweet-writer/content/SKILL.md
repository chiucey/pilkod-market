## 写作框架

### 1. 微博/ Twitter 框架

```
[悬念开头] - 引发好奇
[核心内容] - 简洁有力
[亮点/金句] - 让人印象深刻
[互动引导] - 鼓励评论
[话题标签] - 增加曝光
```

**示例模板：**

```
🔥 [悬念句式，引发好奇]
[1-2句话核心观点]
✨ [金句/亮点]
你怎么看？👇
#话题1 #话题2
```

### 2. 小红书框架

```
[封面标题] - 吸睛、关键词前置
[开头hook] - 痛点/场景切入
[正文内容] - 分点罗列、条理清晰
[个人经历] - 真实感、增强信任
[实用建议] - 干货价值
[结尾引导] - 收藏/评论/关注
```

**示例模板：**

```
【封面标题：数字+关键词】
❗️[痛点问题]的姐妹看过来！

今天分享[主题]，亲测有效！

① [第一要点]
② [第二要点]
③ [第三要点]

⚠️[注意事项/小贴士]

💬 评论区告诉我，你还想看什么？

❤️ 觉得有用记得收藏哦～
```

### 3. 微信公众号框架

```
[标题] - 引发好奇、包含关键词
[引言] - 场景/数据/故事引入
[正文] - 分章节、有小标题
[案例/故事] - 增强说服力
[总结] - 要点回顾
[行动号召] - 关注/转发/留言
```

### 4. 知乎框架

```
[问题回应] - 直接切入核心
[背景说明] - 建立专业性
[分析论述] - 逻辑清晰、有据可依
[案例支撑] - 数据/文献/实例
[解决方案] - 可操作性强
[延伸思考] - 展现深度
```

## 内容优化技巧

### 开头写法（Hook）

```
1. 数字开头："90%的人都不知道..."
2. 提问开头："你有没有发现..."
3. 对比开头："同样是...为什么别人..."
4. 场景开头："你有没有遇到过..."
5. 颠覆开头："其实你一直理解错了..."
```

### 互动引导语

```
• "你同意吗？评论区聊聊"
• "你们遇到过类似情况吗？"
• "还想看什么？告诉我"
• "觉得有用就点个赞吧"
• "收藏起来慢慢看"
• "转发给需要的朋友"
```

### 爆款标题公式

```
1. 数字+利益：【3个技巧让你...】
2. 痛点+方案：【还在...？试试这个】
3. 悬念+好奇：【原来...是这样】
4. 对比+冲突：【别人...你却...】
5. 身份+共鸣：【[人群]必看：[主题]】
```

## 创作流程

### Step 1: 收集信息

- 确定目标平台
- 明确内容主题
- 了解目标受众
- 收集相关素材

### Step 2: 选择框架

根据平台特点选择合适的写作框架。

### Step 3: 内容撰写

按照框架填充内容，注意：
- 语言风格适配平台
- 长度控制在合理范围
- 添加合适的标签/话题

### Step 4: 优化调整

- 检查是否有错别字
- 确保核心信息清晰
- 优化开头吸引度
- 添加互动引导

### Step 5: 适配输出

如需多平台发布，针对每个平台特点调整输出。

## 注意事项

1. **平台规则**：遵守各平台社区规范，避免敏感词
2. **内容真实**：不夸大、不虚假宣传
3. **版权意识**：引用他人内容需注明来源
4. **频率控制**：保持稳定的发布频率
5. **数据复盘**：根据互动数据持续优化内容
