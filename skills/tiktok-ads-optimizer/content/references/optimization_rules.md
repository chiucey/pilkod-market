# TikTok广告优化规则库

## 一、预算优化规则

### 规则1：智能扩量
```
触发条件：
  - ROAS >= 目标ROAS × 1.3
  - 消耗率 >= 85%
  - 持续时间 >= 3天
  - 转化数 >= 50

执行操作：
  - 提高日预算 20%~50%
  - 记录扩量日志
  - 发送扩量通知

回滚条件：
  - 若扩量后ROAS下降超过15%
  - 恢复原预算
```

### 规则2：缩量控制
```
触发条件：
  - CPA >= 目标CPA × 1.5
  - 连续2天无转化
  - 花费 >= ¥500

执行操作：
  - 降低出价 10%~20%
  - 或暂停广告组
  - 标记待优化

观察期：3天
```

### 规则3：预算再分配
```
执行周期：每日
执行逻辑：
  1. 按ROAS排序所有广告组
  2. TOP 20%广告组额外获得30%预算
  3. BOTTOM 20%广告组减少50%预算
  4. 中间60%保持不变
```

## 二、出价优化规则

### 规则4：竞争时段出价
```
黄金时段（19:00-23:00）：
  - 提高出价 15%~30%
  - 优先消耗预算

低峰时段（00:00-06:00）：
  - 降低出价 20%~40%
  - 节省成本

工作时段（06:00-19:00）：
  - 保持正常出价
```

### 规则5：成本达标加价
```
触发条件：
  - CPA <= 目标CPA × 0.9
  - 转化数 >= 30/天
  - 数据稳定 >= 5天

执行操作：
  - 提高出价 10%
  - 争取更多优质流量
  - 提升转化量
```

### 规则6：超成本降价
```
触发条件：
  - CPA > 目标CPA × 1.2
  - 转化成本持续上升

执行操作：
  - 第一步：降低出价15%
  - 第二步（若无效）：再降15%
  - 第三步（若无效）：暂停审查素材
```

## 三、受众优化规则

### 规则7：相似受众扩展
```
触发条件：
  - 现有受众消耗 >= ¥5000
  - 转化数 >= 100
  - CPA <= 目标 × 1.2

执行操作：
  - 扩展相似受众 1%~3%
  - 创建新广告组测试
  - 保持原受众组继续投放
```

### 规则8：排除已转化用户
```
执行逻辑：
  - 抓取近30天转化用户ID
  - 创建排除受众包
  - 应用到所有新广告组
  - 避免重复投放浪费

更新频率：每日
```

### 规则9：兴趣标签调优
```
分析维度：
  - 各兴趣标签的CTR/CVR
  - 受众重叠度分析
  - 转化成本对比

优化操作：
  - 保留高表现兴趣标签
  - 剔除低效兴趣标签
  - 尝试细分兴趣组合
```

## 四、素材优化规则

### 规则10：素材A/B测试
```
测试配置：
  - 同时创建2~4个素材变体
  - 相同定向和出价
  - 测试周期：5~7天
  - 最小样本：1000曝光/素材

胜出标准：
  - CTR高于均值20%+
  - 转化数 >= 20
  - CPA <= 目标

决策：
  - 胜出素材：扩量投放
  - 落败素材：暂停替换
```

### 规则11：低效素材淘汰
```
触发条件（满足任一）：
  - CTR < 行业均值50%，持续3天
  - CVR < 行业均值40%，持续3天
  - 花费 >= ¥300 无转化

执行操作：
  - 暂停低效素材
  - 记录淘汰原因
  - 生成新素材建议
```

### 规则12：爆款素材复制
```
触发条件：
  - 单素材ROAS >= 目标ROAS × 2
  - 转化数 >= 50
  - 生命周期 >= 7天

执行操作：
  - 复制爆款结构
  - 更换背景/音乐/字幕
  - 保持核心创意元素
  - 测试新变体
```

## 五、时段优化规则

### 规则13：智能时段分配
```
分析方法：
  - 分析过去14天分小时数据
  - 计算每个时段的CPA/ROAS
  - 标记高效时段和低效时段

执行操作：
  - 高效时段：提高出价+增预算
  - 低效时段：降低出价或暂停
  - 零效果时段：完全暂停
```

### 规则14：排期优化
```
工作日 vs 周末对比：
  - 若周末ROAS高20%+ → 增加周末预算
  - 若工作日表现稳定 → 保持常规投放

节假日策略：
  - 提前3~5天调整预算
  - 准备节假日专属素材
  - 提高出价应对竞争
```

## 六、设备与平台规则

### 规则15：设备优化
```
分析维度：
  - iOS vs Android转化对比
  - 高端机 vs 低端机效果
  - 不同系统版本表现

优化操作：
  - 优化高效果设备定向
  - 排除低转化设备
  - 调整分平台出价
```

### 规则16：版位优化
```
TikTok版位：
  - For You Page (FYP) - 首选
  - In-Feed Ads - 标准信息流
  - TopView - 开屏广告
  - Brand Takeover - 品牌接管

优化策略：
  - 新账户优先信息流
  - 品牌曝光优先TopView
  - 成本优先FYP
```

## 七、自动化规则模板

### 模板A：保守型
```yaml
rules:
  - name: 保守扩量
    trigger: roas >= 1.5 AND conversions >= 30
    action: budget +10%
    max_daily_change: 10%

  - name: 保守缩量
    trigger: cpa >= target_cpa * 1.3
    action: bid -10%
    min_bid_floor: 0.5
```

### 模板B：激进型
```yaml
rules:
  - name: 激进扩量
    trigger: roas >= 1.2 AND conversions >= 20
    action: budget +30%
    max_daily_change: 30%

  - name: 激进缩量
    trigger: cpa >= target_cpa * 1.2
    action: bid -20%
    pause_if: cpa >= target_cpa * 2
```

### 模板C：平衡型
```yaml
rules:
  - name: 平衡扩量
    trigger: roas >= 1.3 AND conversions >= 25
    action: budget +20%
    max_daily_change: 20%

  - name: 平衡缩量
    trigger: cpa >= target_cpa * 1.25
    action: bid -15%
    min_bid_floor: 0.3
```

## 八、规则优先级

```
高优先级（立即执行）：
  1. 预算耗尽暂停
  2. 异常流量检测
  3. 账户余额预警

中优先级（每日执行）：
  1. CPA超目标调整
  2. 素材效果评估
  3. 时段效果优化

低优先级（每周执行）：
  1. 受众结构优化
  2. 版位效果分析
  3. 整体策略复盘
```

## 九、最佳实践

1. **最小样本量原则**
   - 出价调整：至少50次转化
   - 素材判断：至少1000曝光
   - 受众评估：至少100次转化

2. **渐进式调整**
   - 单次出价调整不超过20%
   - 单次预算调整不超过50%
   - 观察期至少3天

3. **数据稳定性确认**
   - 连续3天趋势一致再决策
   - 排除偶发性波动
   - 参考周同比数据

4. **日志记录**
   - 记录所有调整操作
   - 记录调整前后指标
   - 定期复盘优化效果
