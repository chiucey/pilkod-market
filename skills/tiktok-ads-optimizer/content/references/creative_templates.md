# TikTok广告素材模板库

## 一、视频素材规格

### 基础要求
| 参数 | 推荐值 | 范围 |
|------|--------|------|
| 时长 | 15-21秒 | 5-60秒 |
| 分辨率 | 1080×1920 | 720×1280+ |
| 宽高比 | 9:16 | 1:1 / 9:16 |
| 文件格式 | MP4 | MP4 / MOV |
| 文件大小 | ≤500MB | - |
| 帧率 | 30fps | 25-60fps |
| 码率 | ≥8Mbps | 推荐15Mbps |

### 封面要求
- 尺寸：1080×1920
- 格式：JPG / PNG
- 大小：≤2MB
- 要求：第一帧避免黑屏/白屏

## 二、爆款素材结构

### 结构1：3秒开场钩子 + 产品展示 + CTA
```
0-3秒：震撼开场（痛点/痒点）
  - "还在为XXX烦恼？"
  - "99%的人都不知道的XXX"
  - 惊人数据/对比

4-12秒：产品展示
  - 展示核心功能/卖点
  - 使用场景演示
  - 用户见证

13-15秒：行动号召
  - "点击立即购买"
  - "限时优惠，扫码领取"
  - 紧迫感营造
```

### 结构2：问题-解决方案
```
0-2秒：提出问题
  - 展示用户痛点场景
  - 引起共鸣

3-8秒：解决方案
  - 介绍产品/服务
  - 展示如何解决问题

9-12秒：效果展示
  - Before/After对比
  - 用户反馈

13-15秒：引导转化
  - 明确CTA
  - 价值主张强调
```

### 结构3：UGC风格种草
```
特点：真实、有代入感、低广告感
格式：
  - 第一人称视角
  - 真实场景拍摄
  - 自然对话形式
  - 避免过度精致

脚本示例：
  "姐妹们！这个真的绝了！
   用了大概X天，效果超明显...
   链接在评论区，抓紧冲！"
```

### 结构4：剧情类内容
```
时长：15-60秒
要素：
  - 有冲突/悬念的开场
  - 逐步展开的剧情
  - 自然植入产品
  - 出人意料的结尾

适用场景：
  - 品牌推广
  - APP推广
  - 高客单价产品
```

## 六、素材测试策略

### 测试矩阵
| 测试维度 | 变量 | 建议数量 |
|----------|------|----------|
| 视频类型 | 实拍/动画/混剪 | 2-3个 |
| 开场形式 | 痛点/数据/场景 | 2-3个 |
| 时长 | 15s/30s/60s | 2-3个 |
| 音乐风格 | 动感/舒缓/流行 | 2-3个 |
| CTA位置 | 开头/中间/结尾 | 2-3个 |

### 素材生命周期
```
引入期（Day 1-3）：
  - 观察基础数据
  - 给予充足曝光
  - 不急于判断

成长期（Day 4-7）：
  - 收集转化数据
  - 开始效果对比
  - 初步筛选

爆发期（Day 8-14）：
  - 确定主力素材
  - 准备备用素材
  - 制定迭代计划

衰退期（Day 15+）：
  - 监控数据下滑
  - 及时替换素材
  - 分析衰退原因
```

### 素材更新节奏
- 高消耗账户：每3-5天更新素材
- 中等消耗账户：每7-10天更新素材
- 低消耗账户：每10-15天更新素材

## 八、素材合规要求

### TikTok广告政策红线
1. **禁止内容**
   - 虚假宣传/夸大功效
   - 误导性价格信息
   - 未经授权的第三方品牌
   - 敏感话题/争议内容

2. **受限内容**
   - 金融产品需风险提示
   - 医疗健康类需资质
   - 酒类需年龄限制
   - 减肥类需效果声明合规

3. **创意要求**
   - 避免过度闪烁/强光
   - 避免密集文字遮挡
   - 音频需有版权
   - 避免竞品对比贬低
