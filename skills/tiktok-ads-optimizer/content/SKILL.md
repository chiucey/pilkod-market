# TikTok Ads Optimizer - 智能广告投放与优化助手

## 技能概述

本技能提供TikTok广告全生命周期管理，包括：
- **智能投放**：广告系列创建、A/B测试、受众定向
- **数据分析**：实时监控、效果分析、竞品对比
- **自动优化**：智能出价、预算调整、素材迭代
- **报表生成**：日报、周报、月报自动生成

---

## 核心功能模块

### 1. 广告投放管理

#### 1.1 创建广告系列
- 根据营销目标选择推广目的（应用安装/线索收集/商品推广/品牌曝光）
- 设置广告组：定向、预算、排期、投放位置
- 创建广告创意：视频制作规格、标题文案、CTA设置

#### 1.2 广告系列结构
```
├── 广告账户 (Account)
│   ├── 广告系列 (Campaign) - 营销目标层级
│   │   ├── 广告组 (Ad Group) - 定向/预算层级
│   │   │   └── 广告 (Ad) - 创意素材层级
```

### 2. 数据分析模块

#### 2.1 核心指标
| 指标 | 说明 | 优化目标 |
|------|------|----------|
| CTR | 点击率 | 越高越好 |
| CVR | 转化率 | 越高越好 |
| CPM | 千次展示成本 | 越低越好 |
| CPC | 单次点击成本 | 越低越好 |
| CPA | 单次转化成本 | 越低越好 |
| ACoS | 广告支出回报率 | 因品类而异 |
| ROAS | 广告投资回报率 | 越高越好 |

#### 2.2 数据分析方法
1. **趋势分析**：按时间维度追踪指标变化
2. **维度分析**：按广告组/素材/受众细分
3. **归因分析**：转化路径与触点归因
4. **异常检测**：识别数据波动与异常点

### 3. 智能优化引擎

#### 3.1 优化策略库

**预算优化**
- 表现好的广告组自动增加预算（+20%~50%）
- 表现差的广告组降低预算或暂停
- 遵循最小样本量原则（建议100+转化）

**出价优化**
- CPC过高 → 优化素材/降低出价
- CPA达标 → 适当提价抢量
- 凌晨vs黄金时段动态调整

**素材优化**
- 识别高表现素材特征
- 淘汰低CTR/CVR素材
- A/B测试迭代优化

**受众优化**
- 相似受众扩展
- 排除已转化用户
- 兴趣标签调优

#### 3.2 自动优化规则
```yaml
规则1: 成本控制
  条件: CPA > 目标CPA × 1.2
  操作: 降低出价15%或暂停

规则2: 爆量机会
  条件: ROAS > 目标ROAS × 1.5 且 预算消耗<80%
  操作: 提高预算30%

规则3: 素材更新
  条件: 某素材连续3天CTR < 行业均值50%
  操作: 标记待替换 + 建议新素材方向
```

### 4. 报表生成模块

#### 4.1 日报内容
- 当日核心指标汇总
- 与昨日/上周同期对比
- TOP3表现最好/最差的广告
- 异常数据预警
- 今日优化建议

#### 4.2 周报内容
- 周度趋势图表
- 广告系列维度分析
- 素材效果排行榜
- 竞品数据对比（可选）
- 下周优化计划

#### 4.3 月报内容
- 月度GMV/ROI汇总
- 投入产出分析
- 爆款素材案例
- 策略复盘与总结
- 下月预算规划

## 执行工作流

### 工作流1：创建新广告系列
1. 确认营销目标与预算
2. 设定受众定向
3. 准备/制作视频素材
4. 撰写广告文案
5. 配置出价策略
6. 提交审核

### 工作流2：数据分析诊断
1. 获取账户数据
2. 计算核心指标
3. 识别问题点与机会点
4. 生成诊断报告
5. 输出优化建议

### 工作流3：自动优化执行
1. 设置优化规则阈值
2. 定时执行数据检查
3. 符合条件则自动执行
4. 记录操作日志
5. 发送执行通知

### 工作流4：生成定期报告
1. 确定报告周期
2. 拉取周期数据
3. 计算汇总指标
4. 生成可视化图表
5. 输出结构化报告

## 使用限制与注意事项

1. **合规性**：确保广告内容符合TikTok平台政策
2. **预算控制**：建议单日预算不低于¥100以获取足够数据
3. **学习期**：新广告系列通常有3-7天学习期
4. **数据延迟**：TikTok数据通常有2-4小时延迟
5. **最小样本**：优化决策需足够样本量支撑
