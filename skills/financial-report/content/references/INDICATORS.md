## 盈利能力指标

### 1.1 毛利率 (Gross Margin)

**定义：** 营业收入减去直接成本后的利润占营业收入的比例

**计算公式：**
```
毛利率 = (营业收入 - 营业成本) / 营业收入 × 100%
       = 毛利润 / 营业收入 × 100%
```

**参考标准：**

| 行业 | 优秀 | 良好 | 一般 |
|------|------|------|------|
| 酒类 | >70% | 50-70% | <50% |
| 软件 | >60% | 40-60% | <40% |
| 医药 | >50% | 30-50% | <30% |
| 制造业 | >30% | 15-30% | <15% |
| 零售 | >25% | 10-25% | <10% |
| 房地产 | >35% | 20-35% | <20% |

**分析要点：**
- 与行业平均水平对比
- 逐年趋势变化
- 原材料价格影响
- 定价能力评估

---

### 1.2 净利率 (Net Profit Margin)

**定义：** 净利润占营业收入的比例，反映最终盈利能力

**计算公式：**
```
净利率 = 净利润 / 营业收入 × 100%
```

**参考标准：**

| 行业 | 优秀 | 良好 | 一般 |
|------|------|------|------|
| 金融 | >30% | 20-30% | <20% |
| 科技 | >20% | 10-20% | <10% |
| 消费 | >15% | 8-15% | <8% |
| 工业 | >10% | 5-10% | <5% |
| 建筑 | >8% | 3-8% | <3% |

**分析要点：**
- 三费占比（销售、管理、财务费用）
- 税费率变化
- 非经常性损益影响
- 与毛利率差距反映期间费用率

---

### 1.3 净资产收益率 (ROE)

**定义：** 净利润与平均股东权益的比值，反映股东投入资本的回报率

**计算公式：**
```
ROE = 净利润 / 平均股东权益 × 100%

杜邦分解：
ROE = 净利率 × 资产周转率 × 权益乘数
    = (净利润/营收) × (营收/总资产) × (总资产/股东权益)
```

**参考标准：**

| 评级 | ROE范围 | 说明 |
|------|---------|------|
| 优秀 | >20% | 极强的盈利能力 |
| 良好 | 15-20% | 较强的盈利能力 |
| 一般 | 10-15% | 行业平均水平的盈利能力 |
| 较差 | 5-10% | 盈利较弱 |
| 差 | <5% | 盈利困难 |

**分析要点：**
- 拆解杜邦分析，找出问题根源
- 净利率驱动：定价能力、成本控制
- 周转率驱动：运营效率、资产利用
- 杠杆驱动：负债水平、风险程度

---

### 1.4 资产回报率 (ROA)

**定义：** 净利润与平均总资产的比值，反映资产利用效率

**计算公式：**
```
ROA = 净利润 / 平均总资产 × 100%
```

**参考标准：**

| 行业 | 优秀 | 良好 | 一般 |
|------|------|------|------|
| 金融 | >2% | 1-2% | <1% |
| 消费 | >10% | 5-10% | <5% |
| 工业 | >8% | 4-8% | <4% |
| 科技 | >12% | 6-12% | <6% |

---

### 1.5 投入资本回报率 (ROIC)

**定义：** 税后净营业利润与投入资本的比率

**计算公式：**
```
ROIC = NOPAT / 投入资本 × 100%

其中：
NOPAT = 息税前利润(EBIT) × (1 - 税率)
投入资本 = 股东权益 + 有息负债 - 现金
```

**分析要点：**
- ROIC > WACC：创造价值
- ROIC < WACC：毁灭价值

## 成长性指标

### 2.1 营收增长率

**定义：** 营业收入同比或环比增长的比例

**计算公式：**
```
营收同比增长率 = (本期营收 - 上年同期营收) / 上年同期营收 × 100%
营收环比增长率 = (本期营收 - 上期营收) / 上期营收 × 100%
```

**参考标准：**

| 成长阶段 | 营收增速 |
|----------|----------|
| 高速成长期 | >30% |
| 稳定成长期 | 15-30% |
| 成熟期 | 5-15% |
| 衰退期 | <5%或负增长 |

---

### 2.2 净利润增长率

**定义：** 净利润同比或环比增长的比例

**分析要点：**
- 与营收增速对比（规模效应）
- 关注非经常性损益影响
- 增速的可持续性

---

### 2.3 复合增长率 (CAGR)

**定义：** 多年平均增长率

**计算公式：**
```
CAGR = (期末值/期初值)^(1/n) - 1

其中 n = 年数
```

**应用场景：**
- 3年营收CAGR
- 5年净利润CAGR
- 长期趋势评估

---

## 偿债能力指标

### 3.1 流动比率 (Current Ratio)

**定义：** 流动资产与流动负债的比值

**计算公式：**
```
流动比率 = 流动资产 / 流动负债
```

**参考标准：**

| 范围 | 评价 |
|------|------|
| >2 | 优秀，偿债能力强 |
| 1.5-2 | 良好 |
| 1-1.5 | 一般，需要关注 |
| <1 | 较差，短期偿债风险 |

---

### 3.2 速动比率 (Quick Ratio)

**定义：** 剔除存货后的快速变现资产与流动负债的比值

**计算公式：**
```
速动比率 = (流动资产 - 存货) / 流动负债
```

**参考标准：**

| 范围 | 评价 |
|------|------|
| >1 | 优秀 |
| 0.8-1 | 良好 |
| <0.8 | 较差 |

---

### 3.3 资产负债率

**定义：** 总负债占总资产的比例

**计算公式：**
```
资产负债率 = 总负债 / 总资产 × 100%
```

**参考标准：**

| 行业 | 合理范围 |
|------|----------|
| 金融 | 85-92% |
| 房地产 | 60-80% |
| 制造业 | 40-60% |
| 科技 | 30-50% |
| 消费 | 30-45% |

**分析要点：**
- 与行业平均水平对比
- 负债结构（长期/短期）
- 负债成本

---

### 3.4 利息保障倍数

**定义：** 息税前利润与利息费用的比值

**计算公式：**
```
利息保障倍数 = EBIT / 利息费用
```

**参考标准：**

| 范围 | 评价 |
|------|------|
| >5 | 优秀 |
| 3-5 | 良好 |
| 1-3 | 一般 |
| <1 | 较差 |

## 运营效率指标

### 4.1 存货周转率

**定义：** 一定时期内存货周转的次数

**计算公式：**
```
存货周转率 = 营业成本 / 平均存货
存货周转天数 = 365 / 存货周转率
```

**参考标准：**

| 行业 | 优秀(天数) | 良好(天数) | 一般(天数) |
|------|-----------|-----------|-----------|
| 食品 | <30 | 30-60 | >60 |
| 服装 | <60 | 60-90 | >90 |
| 电子 | <45 | 45-75 | >75 |
| 汽车 | <60 | 60-90 | >90 |

---

### 4.2 应收账款周转率

**定义：** 一定时期内应收账款周转的次数

**计算公式：**
```
应收账款周转率 = 营业收入 / 平均应收账款
应收账款周转天数 = 365 / 应收账款周转率
```

**分析要点：**
- 收账周期长短
- 坏账风险评估
- 与行业对比

---

### 4.3 总资产周转率

**定义：** 营业收入与平均总资产的比值

**计算公式：**
```
总资产周转率 = 营业收入 / 平均总资产
```

**参考标准：**

| 行业 | 典型值 |
|------|--------|
| 零售 | 2-3 |
| 制造 | 1-2 |
| 房地产 | 0.2-0.5 |
| 金融 | 0.05-0.1 |

---

### 4.4 固定资产周转率

**定义：** 营业收入与固定资产净值的比值

**计算公式：**
```
固定资产周转率 = 营业收入 / 平均固定资产净值
```

## 估值指标

### 5.1 市盈率 (PE)

**定义：** 股价与每股收益的比值

**计算公式：**
```
市盈率 = 股价 / 每股收益(PE)
      = 总市值 / 净利润
```

**类型：**

| 类型 | 计算方法 | 适用场景 |
|------|----------|----------|
| 静态PE | 当前股价 / 上年度EPS | 参考价值 |
| 动态PE | 当前股价 / 预期年度EPS | 成长股 |
| 滚动PE | 当前股价 / 近12个月EPS | 当前估值 |

**参考标准：**

| 估值状态 | PE分位 | 说明 |
|----------|--------|------|
| 极度低估 | <20% | 历史底部区域 |
| 偏低估 | 20-40% | 低于历史平均 |
| 合理 | 40-60% | 接近历史平均 |
| 偏高估 | 60-80% | 高于历史平均 |
| 极度高估 | >80% | 历史顶部区域 |

**适用限制：**
- 不适用于亏损企业
- 周期行业需谨慎
- 高成长股PE普遍较高

---

### 5.2 市净率 (PB)

**定义：** 股价与每股净资产的比值

**计算公式：**
```
市净率 = 股价 / 每股净资产
      = 总市值 / 净资产
```

**参考标准：**

| 行业 | 合理PB |
|------|--------|
| 银行 | 0.5-1.5 |
| 保险 | 1-2 |
| 券商 | 1-3 |
| 地产 | 0.5-2 |
| 消费 | 3-8 |
| 科技 | 5-15 |

**适用场景：**
- 金融行业首选
- 周期行业参考
- 亏损企业可用

---

### 5.3 市销率 (PS)

**定义：** 股价与每股销售额的比值

**计算公式：**
```
市销率 = 股价 / 每股销售额
      = 总市值 / 营业收入
```

**适用场景：**
- 成长型或亏损企业
- 营收稳定的企业
- 电商、SaaS等新经济

---

### 5.4 PEG

**定义：** 市盈率与净利润增速的比值

**计算公式：**
```
PEG = PE / 净利润增长率(%)
```

**参考标准：**

| PEG值 | 估值状态 |
|-------|----------|
| <0.5 | 极度低估 |
| 0.5-1 | 偏低估或合理 |
| 1-1.5 | 略高估 |
| >1.5 | 明显高估 |

**分析要点：**
- 假设增速持续性
- 行业特性差异
- 仅适用于成长股

---

### 5.5 EV/EBITDA

**定义：** 企业价值与息税折旧摊销前利润的比值

**计算公式：**
```
EV/EBITDA = 企业价值 / EBITDA

其中：
EBITDA = 息税前利润 + 折旧 + 摊销
EV = 市值 + 负债 - 现金
```

**适用场景：**
- 资本密集型企业
- 跨行业对比
- 并购估值参考

## 股息指标

### 6.1 股息率

**定义：** 年度股息与股价的比值

**计算公式：**
```
股息率 = 年度每股股息 / 股价 × 100%
```

**参考标准：**

| 股息率 | 类型 |
|--------|------|
| >5% | 高股息 |
| 3-5% | 中高股息 |
| 1-3% | 正常股息 |
| <1% | 低股息或不分红 |

**分析要点：**
- 分红的可持续性
- 股息支付率
- 与无风险利率对比

---

### 6.2 股息支付率

**定义：** 股息占净利润的比例

**计算公式：**
```
股息支付率 = 每股股息 / 每股收益 × 100%
```

**参考标准：**

| 支付率 | 说明 |
|--------|------|
| >80% | 高分红 |
| 30-80% | 正常分红 |
| <30% | 低分红或留存发展 |

---

### 6.3 自由现金流收益率

**定义：** 自由现金流与市值的比值

**计算公式：**
```
FCF收益率 = 自由现金流 / 市值 × 100%

其中：
FCF = 经营活动现金流 - 资本支出
```

**分析要点：**
- 分红能力的真实来源
- 资本支出效率
- 现金流质量

## 技术指标

### 7.1 移动平均线 (MA)

**定义：** 一定周期内价格的平均值

**常用周期：**

| 周期 | 名称 | 用途 |
|------|------|------|
| MA5 | 周线 | 短期趋势 |
| MA10 | 双周线 | 短期趋势 |
| MA20 | 月线 | 中期趋势 |
| MA60 | 季线 | 中期趋势 |
| MA120 | 半年线 | 中长期趋势 |
| MA250 | 年线 | 长期趋势 |

**应用：**
- 均线多头排列：MA5>MA10>MA20>MA60>MA120
- 均线空头排列：MA5<MA10<MA20<MA60<MA120

---

### 7.2 MACD

**定义：** 异同移动平均线

**组成：**
- DIF线：快线EMA
- DEA线：慢线EMA
- MACD柱：DIF与DEA的差值

**默认参数：** 12, 26, 9

**信号：**
- 金叉：DIF上穿DEA
- 死叉：DIF下穿DEA
- 零轴：多空分界线

---

### 7.3 RSI

**定义：** 相对强弱指标

**周期：** 通常14日

**范围：** 0-100

**信号：**
- >80：超买
- <20：超卖
- 50：中轴

---

### 7.4 KDJ

**定义：** 随机指标

**组成：**
- K值：快速随机指标
- D值：慢速随机指标
- J值：3K-2D

**信号：**
- K>D：金叉
- K<D：死叉
- J>100：超买
- J<0：超卖

---

### 7.5 布林带 (Bollinger Bands)

**定义：** 由中轨和上下轨组成的通道

**参数：** 通常20日，2倍标准差

**组成：**
- 中轨：20日MA
- 上轨：中轨+2SD
- 下轨：中轨-2SD

**应用：**
- 突破上轨：强势
- 跌破下轨：弱势
- 收口：趋势减弱
- 开口：趋势增强

---

### 7.6 成交量指标

**量价关系：**

| 形态 | 价格 | 成交量 | 含义 |
|------|------|--------|------|
| 价升量增 | 上涨 | 放大 | 强势上涨 |
| 价升量缩 | 上涨 | 萎缩 | 顶背离 |
| 价跌量增 | 下跌 | 放大 | 恐慌抛售 |
| 价跌量缩 | 下跌 | 萎缩 | 底部区域 |

## 注意事项

1. **单一指标局限**：综合多项指标评估
2. **行业差异**：不同行业指标标准不同
3. **时间维度**：关注历史趋势和行业周期
4. **数据质量**：核实数据来源和可靠性
5. **调整项**：关注非经常性损益、会计政策变更
