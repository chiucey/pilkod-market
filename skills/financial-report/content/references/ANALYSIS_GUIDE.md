## 分析框架概述

本技能采用 **四维度分析框架**，从基本面、技术面、消息面和宏观政策四个层面对上市公司进行全面评估。

```
                    ┌─────────────────┐
                    │   综合评估报告    │
                    └────────┬────────┘
                             │
         ┌───────────────────┼───────────────────┐
         │                   │                   │
    ┌────▼────┐        ┌────▼────┐        ┌────▼────┐
    │ 基本面  │        │ 技术面  │        │ 消息面  │
    └────┬────┘        └────┬────┘        └────┬────┘
         │                   │                   │
         └───────────────────┼───────────────────┘
                             │
                    ┌────────▼────────┐
                    │   宏观政策环境   │
                    └─────────────────┘
```

## 基本面分析

### 1.1 盈利能力评估

**核心指标：**

| 指标 | 计算方法 | 优秀 | 良好 | 一般 |
|------|----------|------|------|------|
| 毛利率 | (营收-成本)/营收 × 100% | >40% | 20-40% | <20% |
| 净利率 | 净利润/营收 × 100% | >20% | 10-20% | <10% |
| ROE | 净利润/净资产 × 100% | >20% | 10-20% | <10% |
| ROA | 净利润/总资产 × 100% | >10% | 5-10% | <5% |

**分析要点：**
- 与行业平均水平对比
- 趋势变化分析（逐年对比）
- 波动性评估（稳定性）

### 1.2 成长性评估

**核心指标：**

| 指标 | 说明 | 评估标准 |
|------|------|----------|
| 营收增速 | 营收同比增长 | >20%为优秀 |
| 净利润增速 | 净利润同比增长 | >20%为优秀 |
| 复合增长率(CAGR) | 3-5年平均增长率 | 衡量长期成长性 |
| 市场份额变化 | 市场占有率趋势 | 持续增长为优 |

**成长阶段判断：**

```
初创期 → 成长期 → 成熟期 → 衰退期
   │        │        │        │
   └────────┴────────┴────────┴──→ 营收规模
```

- **初创期**：营收低，增速高，不确定性大
- **成长期**：营收快速增长，市场扩张
- **成熟期**：营收稳定，增速放缓
- **衰退期**：营收下降，竞争加剧

### 1.3 财务健康评估

**偿债能力：**

| 指标 | 计算方法 | 安全值 | 警告值 | 危险值 |
|------|----------|--------|--------|--------|
| 流动比率 | 流动资产/流动负债 | >2 | 1.5-2 | <1.5 |
| 速动比率 | (流动资产-存货)/流动负债 | >1 | 0.8-1 | <0.8 |
| 资产负债率 | 负债/资产 × 100% | <50% | 50-70% | >70% |

**现金流评估：**

| 现金流类型 | 理想状态 |
|------------|----------|
| 经营活动现金流 | 持续为正，且大于净利润 |
| 投资活动现金流 | 合理负值（扩张期），接近零（成熟期） |
| 筹资活动现金流 | 负值（分红回购），正值（融资扩张） |

### 1.4 估值分析

**相对估值法：**

| 方法 | 适用场景 | 优点 | 缺点 |
|------|----------|------|------|
| PE估值 | 盈利稳定的成熟企业 | 简单直观 | 不适合亏损企业 |
| PB估值 | 金融、周期行业 | 稳定可靠 | 不反映盈利能力 |
| PS估值 | 成长型、亏损企业 | 适合初创期 | 忽略成本控制 |
| PEG估值 | 成长股 | 兼顾成长性 | 假设线性增长 |

**绝对估值法（DCF）：**

```
企业价值 = Σ [CFt / (1+r)^t] + TV / (1+r)^n

其中：
- CFt: 第t年的自由现金流
- r: 折现率
- TV: 终值
- n: 预测期
```

**历史分位分析：**

| 分位区间 | 估值状态 | 投资建议 |
|----------|----------|----------|
| <20% | 严重低估 | 重点关注 |
| 20-40% | 偏低估 | 值得关注 |
| 40-60% | 合理 | 观望 |
| 60-80% | 偏高估 | 谨慎 |
| >80% | 严重高估 | 回避 |

## 技术面分析

### 2.1 趋势分析

**均线系统：**

| 均线 | 周期 | 作用 |
|------|------|------|
| MA5 | 1周 | 短期趋势 |
| MA10 | 2周 | 短期趋势 |
| MA20 | 1月 | 中期趋势 |
| MA60 | 3月 | 中期趋势 |
| MA120 | 6月 | 中长期趋势 |
| MA250 | 1年 | 长期趋势 |

**趋势判断：**

- **上升趋势**：价格站稳均线，均线多头排列（MA5>MA10>MA20>MA60>MA120>MA250）
- **下降趋势**：价格跌破均线，均线空头排列
- **震荡趋势**：均线缠绕，价格在区间波动

### 2.2 MACD分析

**指标构成：**

| 指标 | 计算方法 | 说明 |
|------|----------|------|
| DIF | EMA(close,12) - EMA(close,26) | 快线 |
| DEA | EMA(DIF,9) | 慢线/信号线 |
| MACD柱 | (DIF - DEA) × 2 | 动能柱 |

**交易信号：**

| 信号类型 | 判断条件 | 意义 |
|----------|----------|------|
| 金叉 | DIF上穿DEA | 看涨信号 |
| 死叉 | DIF下穿DEA | 看跌信号 |
| 顶背离 | 价格创新高，MACD未创新高 | 警示见顶 |
| 底背离 | 价格创新低，MACD未创新低 | 警示见底 |
| 零轴上方 | DIF>0 | 多头市场 |
| 零轴下方 | DIF<0 | 空头市场 |

### 2.3 RSI分析

**周期设置：**

| RSI周期 | 特点 | 适用场景 |
|---------|------|----------|
| 6日 | 灵敏度高，波动大 | 短线交易 |
| 12日 | 平衡型 | 中线交易 |
| 24日 | 稳定性高 | 长线交易 |

**信号标准：**

| RSI区间 | 市场状态 | 建议 |
|---------|----------|------|
| >80 | 严重超买 | 考虑卖出 |
| 70-80 | 超买区域 | 谨慎追高 |
| 30-70 | 正常区间 | 观望 |
| 20-30 | 超卖区域 | 关注机会 |
| <20 | 严重超卖 | 考虑买入 |

### 2.4 KDJ分析

**随机指标：**

| 指标 | 说明 |
|------|------|
| K值 | 快速随机指标 |
| D值 | 慢速随机指标 |
| J值 | 3×K - 2×D，敏感性最高 |

**交易信号：**

| 信号类型 | 判断条件 |
|----------|----------|
| K>D | 多头 |
| K<D | 空头 |
| J>100 | 超买，警惕回调 |
| J<0 | 超卖，警惕反弹 |

### 2.5 布林带分析

**参数设置：**

- 中轨：20日简单移动平均线
- 上轨：中轨 + 2×标准差
- 下轨：中轨 - 2×标准差

**通道含义：**

| 价格位置 | 含义 |
|----------|------|
| 上轨上方 | 极度强势，可能回调 |
| 上轨附近 | 强势区域 |
| 中轨附近 | 平衡区域 |
| 下轨附近 | 弱势区域 |
| 下轨下方 | 极度弱势，可能反弹 |

### 2.6 综合评分

**技术面评分表：**

| 指标 | 看涨 | 中性 | 看跌 |
|------|------|------|------|
| 均线系统 | 多头排列 | 缠绕 | 空头排列 |
| MACD | 金叉在零轴上 | 零轴附近 | 死叉在零轴下 |
| RSI | 40-70区间 | 超买超卖 | RSI<30或>80 |
| KDJ | K>D,J<100 | 钝化 | K<D,J<0或>100 |
| 布林带 | 中轨上方 | 中轨附近 | 中轨下方 |
| 成交量 | 放量上涨 | 缩量 | 放量下跌 |

## 消息面分析

### 3.1 公司新闻分类

| 类别 | 利好程度 | 示例 |
|------|----------|------|
| 业绩超预期 | ★★★★★ | 净利润增长50% |
| 重大合同 | ★★★★☆ | 签订百亿订单 |
| 产品突破 | ★★★★☆ | 新产品发布 |
| 政策支持 | ★★★☆☆ | 获得政府补贴 |
| 管理层变动 | ★★☆☆☆ | CEO离职/任命 |
| 并购重组 | ★★★★☆ | 行业整合 |
| 股权激励 | ★★★☆☆ | 员工持股计划 |

### 3.2 行业动态跟踪

**关注要点：**

1. **政策变化**：行业监管、扶持政策
2. **竞争格局**：主要对手动态、市场份额变化
3. **技术革新**：新进入者、技术替代
4. **供需变化**：原材料价格、下游需求
5. **国际贸易**：汇率、关税、进出口

### 3.3 机构观点收集

**研报评级分布：**

| 评级 | 含义 | 预期收益 |
|------|------|----------|
| 强烈推荐 | 显著优于行业 | >30% |
| 推荐 | 优于行业 | 15-30% |
| 中性 | 与行业持平 | -10%~15% |
| 回避 | 弱于行业 | <-10% |

**目标价分析：**

- 收集近3个月内的券商目标价
- 计算平均值和区间
- 关注调整频率和方向

| 中 | 消费、制造 | 受政策影响 |

## 综合评估方法

### 5.1 多因子评分模型

```
综合得分 = Σ (因子权重 × 因子得分)

因子权重：
- 基本面：40%
  - 盈利能力：15%
  - 成长性：10%
  - 财务健康：8%
  - 估值水平：7%

- 技术面：25%
  - 趋势：10%
  - 动量：8%
  - 成交量：7%

- 消息面：20%
  - 业绩：8%
  - 事件：6%
  - 机构观点：6%

- 宏观：15%
  - 经济周期：8%
  - 政策环境：7%
```

### 5.2 投资评级定义

| 评级 | 综合得分 | 投资建议 |
|------|----------|----------|
| 强烈推荐 | ≥80 | 积极买入 |
| 推荐 | 65-80 | 适量买入 |
| 中性 | 50-65 | 持有观望 |
| 回避 | 35-50 | 减仓 |
| 卖出 | <35 | 清仓 |

### 5.3 风险评估矩阵

| | 低影响 | 中影响 | 高影响 |
|---|---|---|---|
| **高概率** | 中风险 | 高风险 | 极高风险 |
| **中概率** | 低风险 | 中风险 | 高风险 |
| **低概率** | 低风险 | 低风险 | 中风险 |

### 5.4 报告输出标准

每份研究报告必须包含以下核心内容：

1. **摘要**（200字以内）
   - 核心结论
   - 目标价
   - 主要风险

2. **基本面分析**
   - 盈利能力
   - 成长性
   - 财务健康
   - 估值水平

3. **技术分析**
   - 趋势判断
   - 关键支撑/压力位
   - 交易信号

4. **消息面**
   - 重大事项
   - 机构观点
   - 行业动态

5. **投资建议**
   - 目标价及理由
   - 上升空间
   - 止损位
   - 核心逻辑

6. **风险提示**
   - 主要风险因素
   - 风险等级评估
