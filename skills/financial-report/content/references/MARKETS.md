## A股市场

### 1.1 市场概述

| 项目 | 说明 |
|------|------|
| 全称 | 中国A股市场 |
| 交易所 | 上海证券交易所(SSE)、深圳证券交易所(SZSE) |
| 成立时间 | 上交所1990年、深交所1990年 |
| 主要指数 | 上证指数、深证成指、创业板指、科创50 |
| 股票代码 | 上交所6开头，深交所0/3开头 |

### 1.2 板块分类

| 板块 | 交易所 | 代码特征 | 上市条件 | 投资者门槛 |
|------|--------|----------|----------|------------|
| 主板 | 上交所/深交所 | 600/000/001 | 连续盈利 | 无 |
| 创业板 | 深交所 | 300 | 两年经验 | 10万+ |
| 科创板 | 上交所 | 688 | 50万+ | 50万+ |
| 北交所 | 北交所 | 8开头 | 50万+ | 50万+ |

### 1.3 交易时间

**普通交易日：**
| 时段 | 时间 | 说明 |
|------|------|------|
| 集合竞价 | 9:15-9:25 | 可挂单、可撤单 |
| 连续竞价 | 9:30-11:30 | 实际成交 |
| 午间休市 | 11:30-13:00 | - |
| 连续竞价 | 13:00-15:00 | 实际成交 |
| 收盘集合竞价 | 14:57-15:00 | 仅可挂单 |

**港股通交易时间（A股投资者投资港股）：**
| 时段 | 时间 |
|------|------|
| 早市 | 9:30-12:00 |
| 午市 | 13:00-16:00 |

### 1.4 涨跌幅限制

| 板块 | 涨跌幅 | 特殊情况 |
|------|--------|----------|
| 主板 | ±10% | ST股票 ±5% |
| 创业板 | ±20% | 上市首日不限 |
| 科创板 | ±20% | 上市首日不限 |
| 北交所 | ±30% | 上市首日不限 |
| 新股上市 | 首日44%上限 | - |

### 1.5 交易单位

| 项目 | 规则 |
|------|------|
| 最小交易单位 | 100股（1手） |
| 申报数量 | 100股的整数倍 |
| 零股处理 | 可一次性卖出 |
| 单笔上限 | 100万股 |

### 1.6 交易费用

| 费用类型 | 收取方式 | 典型费率 |
|----------|----------|----------|
| 印花税 | 卖出时收取 | 0.1%（国家） |
| 过户费 | 双向收取 | 0.002%（中登） |
| 佣金 | 双向收取 | 0.03%左右（券商） |
| 规费 | 双向收取 | 约0.0087% |

## 港股市场

### 2.1 市场概述

| 项目 | 说明 |
|------|------|
| 全称 | 香港联合交易所(HKEX) |
| 成立时间 | 1891年 |
| 主要指数 | 恒生指数、国企指数、恒生科技指数 |
| 股票代码 | 4-5位数字 |
| 货币 | 港币(HKD) |

### 2.2 交易时间

**普通交易日：**
| 时段 | 时间 | 说明 |
|------|------|------|
| 早市 | 9:30-12:00 | 连续竞价 |
| 午市 | 13:00-16:00 | 连续竞价 |

**港股通：**
| 时段 | 时间 | 说明 |
|------|------|------|
| 早市 | 9:30-12:00 | A股开盘后半小时 |
| 午市 | 13:00-16:00 | 收盘后半小时 |

### 2.3 涨跌幅

| 项目 | 规则 |
|------|------|
| 涨跌幅限制 | **无涨跌幅限制** |
| 波动调节机制 | 仅对部分股票在特定情况下触发 |
| 极端波动 | 可能短暂停牌 |

### 2.4 交易单位

| 项目 | 规则 |
|------|------|
| 最小交易单位 | 每手股数由上市公司决定 |
| 常见每手 | 100股、200股、500股、1000股 |
| 申报数量 | 任意数量 |

### 2.5 交易费用

| 费用类型 | 收取方式 | 费率 |
|----------|----------|------|
| 印花税 | 双向收取 | 0.1%（最低1港币） |
| 交易征费 | 双向收取 | 0.0027% |
| 交易费 | 双向收取 | 0.005% |
| 结算费 | 双向收取 | 0.002%（最低2港币） |
| 券商佣金 | 双向收取 | 0.1-0.3% |

### 2.6 港股通

| 项目 | 说明 |
|------|------|
| 沪港通(南向) | 沪市投资者买港股 |
| 深港通(南向) | 深市投资者买港股 |
| 准入门槛 | 50万人民币资产 |
| 可投资标的 |恒生综合大盘/中盘/小盘成分股(A+H股优先) |

### 2.7 重要特点

1. **做空机制**：支持融券做空
2. **涡轮、牛熊证**：衍生品丰富
3. **仙股**：低价股众多，风险较高
4. **老千股**：需警惕小市值、低流动性股票
5. **涡轮**：高杠杆衍生品，风险极大

## 美股市场

### 3.1 市场概述

| 项目 | 说明 |
|------|------|
| 主要交易所 | 纽约证券交易所(NYSE)、纳斯达克(NASDAQ) |
| 成立时间 | NYSE 1792年，NASDAQ 1971年 |
| 主要指数 | 道琼斯、纳斯达克综合、标普500 |
| 股票代码 | 1-5个字母 |
| 货币 | 美元(USD) |

### 3.2 主要交易所

#### NYSE（纽约证券交易所）

| 项目 | 说明 |
|------|------|
| 性质 | 场内交易所 |
| 上市标准 | 较严格 |
| 代表企业 | 伯克希尔哈撒韦、IBM、沃尔玛 |
| 交易大厅 | 纽交所大楼 |

#### NASDAQ（纳斯达克证券交易所）

| 项目 | 说明 |
|------|------|
| 性质 | 电子交易所 |
| 上市标准 | 相对灵活 |
| 代表企业 | 苹果、微软、谷歌、亚马逊 |
| 特点 | 科技股为主 |

### 3.3 交易时间

**美国东部时间：**

| 时段 | 时间 | 说明 |
|------|------|------|
| 盘前 | 4:00-9:30 | 可交易，但流动性差 |
| 正常交易 | 9:30-16:00 | 主要交易时段 |
| 盘后 | 16:00-20:00 | 可交易，流动性差 |

**北京时间（夏令时）：**

| 时段 | 时间 |
|------|------|
| 盘前 | 21:30-次日4:00 |
| 正常交易 | 22:30-次日5:00 |
| 盘后 | 5:00-9:00 |

**北京时间（冬令时）：**

| 时段 | 时间 |
|------|------|
| 盘前 | 22:30-次日5:00 |
| 正常交易 | 23:30-次日6:00 |
| 盘后 | 6:00-10:00 |

### 3.4 涨跌幅

| 项目 | 规则 |
|------|------|
| 涨跌幅限制 | **无涨跌幅限制** |
| 熔断机制 | 标普500跌幅达7%/13%/20%时暂停交易 |
| 个股熔断 | 部分股票有盘前熔断机制 |

### 3.5 交易单位

| 项目 | 规则 |
|------|------|
| 最小交易单位 | 1股 |
| 申报数量 | 任意数量 |
| 碎股交易 | 某些券商支持 |

### 3.6 交易费用

**典型券商费用：**

| 券商类型 | 费用 |
|----------|------|
| 传统券商 | $5-10/笔 |
| 折扣券商 | $0-5/笔 |
| 零佣金券商 | $0/笔 |
| 佣金 | 多数已取消 |

**注意：** 虽然佣金取消，但可能有：
- 平台费
- 期权交易费
- 保证金利率
- 美元转换费

### 3.7 重要特点

1. **做空机制**：允许做空（需保证金账户）
2. **期权市场**：丰富的衍生品交易
3. **ADR**：美国存托凭证，投资海外公司
4. **401K/IRA**：养老投资账户
5. **分层上市**：纽交所和纳斯达克都有不同上市层级

## 交易规则对比

### 三大市场对比表

| 对比项 | A股 | 港股 | 美股 |
|--------|-----|------|------|
| **交易时间** | 4小时/天 | 5.5小时/天 | 6.5小时/天(+盘前盘后) |
| **涨跌幅** | ±10/20% | 无限制 | 无限制 |
| **熔断机制** | 有 | 无 | 有(大盘) |
| **T+0** | 不支持 | 支持 | 支持 |
| **T+1** | T+1交割 | T+2交割 | T+2交割 |
| **最小交易单位** | 100股 | 不固定 | 1股 |
| **做空** | 有限(ETF/融券) | 支持 | 支持 |
| **印花税** | 0.1% | 0.1% | 无 |
| **结算货币** | 人民币 | 港币 | 美元 |

### 交易机制差异

#### T+0 vs T+1

| 市场 | 规则 | 说明 |
|------|------|------|
| A股 | T+1 | 当日买入，次日才能卖出 |
| 港股 | T+0 | 当日可多次买卖 |
| 美股 | T+0 | 当日可多次买卖(日内交易) |

#### 做空机制

| 市场 | 做空方式 | 难度 |
|------|----------|------|
| A股 | 融券卖出 | 较难 |
| 港股 | 借券卖出 | 较易 |
| 美股 | 直接卖出 | 最容易 |

## 财务报告规则

### A股报告规则

#### 报告期

| 报告期 | 截止日期 | 披露时间 |
|--------|----------|----------|
| 一季报 | 3月31日 | 4月底前 |
| 中报 | 6月30日 | 8月底前 |
| 三季报 | 9月30日 | 10月底前 |
| 年报 | 12月31日 | 次年4月底前 |

#### 业绩预告/快报

| 情况 | 要求 |
|------|------|
| 年度业绩变动>50% | 必须预告 |
| 中期业绩变动>50% | 必须预告 |
| 预计亏损 | 必须预告 |
| 扭亏为盈 | 必须预告 |

#### 特别处理

| 标识 | 条件 |
|------|------|
| ST | 连续两年亏损 |
| *ST | 连续三年亏损（退市风险） |
| PT | 暂停上市 |
| S | 尚未完成股改 |

### 港股报告规则

#### 报告期

| 报告期 | 截止日期 | 披露时间 |
|--------|----------|----------|
| 中报 | 6月30日 | 9月底前 |
| 年报 | 12月31日 | 次年4月底前 |

#### 特点

1. **半年度披露**：不要求季报
2. **自愿披露**：部分公司自愿发布季报
3. **ADR规则**：在美上市港股需遵守SEC规则

### 美股报告规则

#### 报告期

| 报告期 | 截止日期 | 披露时间 |
|--------|----------|----------|
| 季报(Q1) | 3月31日 | 5月15日前 |
| 季报(Q2) | 6月30日 | 8月15日前 |
| 季报(Q3) | 9月30日 | 11月15日前 |
| 年报 | 12月31日 | 次年2月底前 |

#### SEC披露要求

| 表格 | 内容 | 频率 |
|------|------|------|
| 10-K | 年报 | 每年 |
| 10-Q | 季报 | 每季度 |
| 8-K | 重大事件 | 随时 |
| DEF 14A | 委托声明 | 年会前 |

#### 外国公司披露

| 表格 | 说明 |
|------|------|
| 20-F | 外国公司年报 |
| 6-K | 外国公司季报/重大事项 |

## 注意事项

### 汇率风险

| 市场 | 货币 | 汇率风险 |
|------|------|----------|
| A股 | 人民币 | 无 |
| 港股 | 港币 | 港币与美元联系汇率，相对稳定 |
| 美股 | 美元 | 需考虑人民币-美元汇率 |

### 流动性风险

| 市场 | 流动性 | 注意事项 |
|------|--------|----------|
| A股主板 | 高 | 流动性好 |
| A股创业板/科创板 | 中高 | 流动性略差 |
| 港股 | 差异大 | 小市值股流动性差 |
| 美股 | 高 | 整体流动性好 |

### 信息披露差异

1. **A股**：信息披露较规范，监管严格
2. **港股**：半年度披露，季报自愿
3. **美股**：严格SEC披露要求，信息透明

### 投资者保护

| 市场 | 保护机制 |
|------|----------|
| A股 | 涨跌停限制、熔断机制 |
| 港股 | 无涨跌幅，投资者自负 |
| 美股 | 无涨跌幅，SIPC保险 |

## 相关术语表

| 术语 | 市场 | 含义 |
|------|------|------|
| 涨停/跌停 | A股 | 价格达到当日最大涨幅/跌幅 |
| 熔断 | A股/美股 | 暂停交易机制 |
| 做空 | 港股/美股 | 借股卖出，等下跌买回 |
| T+0 | 港股/美股 | 当日可买卖 |
| T+1 | A股 | 今日买明日卖 |
| 涡轮 | 港股 | 认股权证，高杠杆 |
| ADR | 美股 | 美国存托凭证 |
| SPAC | 美股 | 特殊目的收购公司 |
