### 1.5 电能过滤器 vs 电火保 功能区分

| 功能 | 电能过滤器 | 电火保 |
|-----|----------|-------|
| **漏电保护** | ✅ 标准版含"漏电不伤人、不停电" | ⚠️ 仅加强版/至尊版有 |
| **短路不起火** | ✅ 有（微秒级断弧） | ✅ 有（微秒级断弧） |
| **短路时断电** | ✅ 会断电（符合国标） | ✅ 会断电（符合国标） |
| **APP智控** | ✅ 标准版含 | ⚠️ 仅加强版/至尊版有 |
| **价格区间** | 1万~150万元 | 2980元~32000元 |
| **保护范围** | 整个配电系统 | 单个分支回路 |
| **功率范围** | 2kW~100万W | 63A~160A |

> ⚠️ **重要说明**：短路保护后断电是**国家规定的技术要求**，小快智造所有产品均符合此要求。核心优势是"短路时不产生电弧/不起火"，而非"不停电"。

> ⚠️ **重要纠正**：电火保短路后也会断电，核心优势是"短路时不产生电弧/不起火"，而非"不停电"。

### 1.8 配电匹配原则（出方案选型必备）

这是给业务人员出方案时**选型配型**的核心原则——必须根据客户配电箱的具体技术参数，对比小快产品线参数，选配**参数 ≥ 客户参数**的产品型号。

#### 核心原则

```
选型逻辑：
客户配电箱参数 → 对比小快产品线参数 → 选参数 ≥ 客户的型号

错误做法：随便选一个产品型号
正确做法：严格匹配参数，确保小快产品参数 ≥ 客户配电参数
```

| 参数 | 含义 | 匹配原则 |

| **额定电流** | 20A/32A/63A/80A/100A/125A/160A/250A等 | 产品电流 ≥ 配电箱额定电流 |

## 二、配电设计核心流程

### Step 1: 读取图纸信息

### Step 2: 计算选型

```python
# 电流计算公式（三相/单相）
三相电流 I = P / (√3 × U × cosφ × η)
单相电流 I = P / (U × cosφ)

In ≥ 计算电流 Ijs

# 整定电流参考
```

## 三、负荷计算（升级模块）

### 3.1 负荷计算方法选择

| 方法 | 适用场景 | 精度 |
|-----|---------|------|
| **需要系数法** | 民用建筑、住宅、办公、商业 | 中等，适合初设/施工图 |
| **二项式法** | 用电设备数量少、容量大的工业 | 较高 |
| **单位指标法** | 方案估算、初步匡算 | 粗略 |

### 3.2 需要系数法（最常用）

```
计算步骤：
1. Pjs = Kx × Pe    （有功计算功率）
2. Qjs = Pjs × tanφ （无功计算功率）
3. Sjs = √(Pjs² + Qjs²)  （视在功率）

其中：
  Kx = 需要系数（查表取得）
  Pe = 用电设备总容量（kW）
  tanφ = 对应功率因数的正切值
```

**常见需要系数表（民用建筑）：**

| 负荷类型 | 需要系数 Kx | cosφ | tanφ |
|---------|------------|------|------|
| 照明（一般） | 0.8~0.9 | 0.9 | 0.484 |
| 照明（景观/特殊） | 0.6~0.7 | 0.8 | 0.75 |
| 空调主机 | 0.8~0.85 | 0.8 | 0.75 |
| 风机/水泵 | 0.7~0.8 | 0.8 | 0.75 |
| 电梯 | 0.5~0.6 | 0.6 | 1.33 |
| 厨房设备（商业） | 0.5~0.7 | 0.8 | 0.75 |
| 办公设备 | 0.7~0.8 | 0.8 | 0.75 |
| 充电桩 | 0.6~0.8 | 0.95 | 0.329 |
| 消防动力（不参与同时系数） | 1.0 | 0.8 | 0.75 |

### 3.3 单位指标法（快速估算）

```
住宅（每户）：4~8 kW（按面积分档）
  - 90㎡以下：4 kW
  - 90~144㎡：6 kW
  - 144㎡以上：8~10 kW

商业（每㎡）：80~120 W
酒店（每间客房）：1.5~2 kW
办公（每㎡）：60~100 W
学校（每间教室）：2~3 kW
医院（每床位）：1~2 kW
```

### 3.4 同时系数

| 应用层级 | 同时系数 Ksp |
|---------|-------------|
| 总配电箱 | 0.8~0.9 |
| 变压器低压侧 | 0.85~0.95 |
| 消防负荷（不参与） | 不参与同时系数 |

### 3.5 变压器容量选择

```
变压器容量 S ≥ Sjs / Kb

其中：Kb = 变压器负荷率（通常取 0.7~0.85）

常见变压器容量序列：315kVA / 400kVA / 500kVA / 630kVA / 800kVA / 1000kVA / 1250kVA / 1600kVA

经验公式（快速估算）：
  S ≈ (Pe × Kx) / 0.8    （单位：kVA）
```

### 3.6 分级计算实例

```
示例：某商业综合体，总空调功率 500kW，风机水泵 200kW，照明 150kW，动力 100kW

计算：
  Pjs = 500×0.85 + 200×0.75 + 150×0.85 + 100×0.7
      = 425 + 150 + 127.5 + 70 = 772.5 kW

  Qjs = 425×0.75 + 150×0.75 + 127.5×0.484 + 70×0.75
      = 318.75 + 112.5 + 61.7 + 52.5 = 545.45 kvar

  Sjs = √(772.5² + 545.45²) = √(596,756 + 297,516) = √894,272 ≈ 946 kVA

  → 推荐选 1000kVA 或 2×630kVA 变压器
```

## 五、上下级保护配合（升级模块）

### 5.1 保护配合原则

| 原则 | 说明 |
|-----|------|
| **选择性** | 故障时，只断开最小范围的回路（越靠近故障点的开关先跳） |
| **灵敏性** | 开关能在规定时间内切断最小短路电流 |
| **可靠性** | 开关额定短路分断能力 ≥ 预期短路电流 |
| **协调性** | 上下级开关时间-电流曲线不重叠 |

### 5.2 短路电流计算

```
# 三相短路电流（初步估算）
Ik = In / (Zd% × Uk%)

其中：
  In = 变压器额定电流
  Zd% = 变压器阻抗电压百分比（常见 4%~6%）
  Uk% = 短路点到变压器阻抗百分比比值

# 简化估算（常用）
380V系统末端短路电流：

  低压配电站（变压器后第一个配电箱）：
    Ik ≈ (100 ~ 150) × In（对于1000kVA变压器，In≈1443A，Ik≈150kA）

  线路末端（配电箱到设备）：
    Ik ≈ 230 / L × S / r

    其中：L=线路长度(m), S=截面积(mm²), r=铜的电阻率(0.0184Ω·mm²/m)
```

**常见变压器低压侧短路电流参考：**

| 变压器容量 | 阻抗电压 | 低压额定电流 | 三相短路电流 Ik |
|-----------|---------|------------|----------------|
| 400kVA | 4% | 577A | ~14kA |
| 630kVA | 4% | 909A | ~23kA |
| 800kVA | 4.5% | 1155A | ~26kA |
| 1000kVA | 4.5% | 1443A | ~32kA |
| 1250kVA | 5% | 1804A | ~36kA |
| 1600kVA | 5% | 2309A | ~46kA |

### 5.3 断路器整定电流配合表

| 层级 | 开关类型 | 整定电流 | 整定原则 |
|-----|---------|---------|---------|
| **变压器总开关** | 框架断路器（智能塑壳） | 1.0~1.25 × In | 长延时1倍整定，短延时躲过电动机启动 |
| **配电箱主开关** | 塑壳/智慧微断4P | 0.8~1.0 × 母线允许电流 | 上下级配合整定 |
| **分路开关** | 智慧微断/小型断路器 | ≤线路允许电流 | 与主开关配合，留2级以上选择性 |
| **设备开关** | 隔离开关/负荷开关 | 1.0~1.25 × 设备额定电流 | 就地隔离用 |

### 5.4 选择性配合实例

```
示例：配电系统三级保护配合

[变压器 1000kVA]
       ↓ 母线
[总开关 智慧微断4P 160A]    ← 整定：长延时160A，短延时800A（5倍）
       ↓ 配电箱分支配电
[分开关 智慧微断2P 63A]     ← 整定：长延时63A，瞬时315A（5倍）
       ↓ 照明回路
[末开关 小微断 C16A]        ← 整定：长延时16A，瞬时80A（5倍）

配合验证：
  - 末端短路时：16A先跳（<0.1s）
  - 分路短路时：63A跳，16A不跳（选择性）
  - 配电箱短路时：160A跳，63A不跳（选择性）

配合口诀：上级整定电流 = 1.2~1.5 × 下级整定电流
         上级延时 = 下级延时 + 0.1~0.2s（时间级差）
```

### 5.5 漏电保护整定

| 应用场景 | 漏电动作电流 IΔn | 动作时间 |
|---------|----------------|---------|
| 插座回路（潮湿场所） | 10mA~30mA | ≤0.04s |
| 一般插座回路 | 30mA | ≤0.1s |
| 配电箱总漏电保护 | 100mA~300mA | ≤0.2s |
| 母线/干线漏电保护 | 300mA~500mA | ≤0.3s |
| 接地故障报警 | 300mA~500mA | 报警不跳闸 |

> ⚠️ **小快智造智慧微断（XK-ZNC系列）自带漏电保护功能**：2P带漏保型标配30mA漏电保护，可替代传统漏电断路器使用。

### 5.6 灵敏度校验

```
目的：确保开关能切断最小接地故障电流

校验公式：
  Ijs ≥ K · IΔn

其中：
  Ijs = 漏电保护动作电流（mA）
  IΔn = 被保护回路最小接地故障电流（mA）
  K = 可靠系数，C型微断取4.5，D型取2

示例：
  C16A微断，最小短路电流应 ≥ 16×4.5 = 72A
  如末端最小短路电流仅50A，则该开关对此故障不灵敏，需加大线径或改用额定电流更小的开关
```

#### 11.1.1 电力系统的组成与接线


#### 11.1.2 潮流计算（电力系统稳态分析）

```
目的：求解电力系统在给定负荷和发电条件下的各节点电压、相角和功率分布。

常用方法：

1. 手算方法（简单网络）
   - 已知首端电压 → 求各支路电流 → 求各节点电压
   - 近似计算：忽略电压降横分量

2. 迭代方法（复杂网络）
   - 牛拉法（Newton-Raphson）
   - P-Q分解法（简化牛拉法，收敛更快）

潮流计算基本方程（牛拉法）：
[ΔP/ΔQ] = [J] × [Δθ/ΔV]
其中 J 为雅可比矩阵

手算示例（两节点系统）：

已知：电源端电压 U1=1.0pu，负荷功率 PL=0.8pu，QL=0.3pu
线路阻抗 Z=0.02+j0.04pu

求解末端电压 U2 和功率分布：

Step 1: 计算末端等效阻抗
ΔU = (P×R + Q×X)/U = (0.8×0.02 + 0.3×0.04)/1.0 = 0.028pu
δU = (P×X - Q×R)/U = (0.8×0.04 - 0.3×0.02)/1.0 = 0.026pu

Step 2: 末端电压
U2 ≈ U1 - ΔU = 1.0 - 0.028 = 0.972pu

Step 3: 支路功率
S12 = U1²/Z* - U1×U2/Z* = ...
```

#### 11.1.3 短路电流计算（电力系统暂态分析）

```
目的：计算电力系统发生短路时的电流，用于选择断路器、整定继电保护。

三相短路电流计算：

Ik = Un / (√3 × Zk)

其中：
  Ik = 三相短路电流（kA）
  Un = 短路点额定电压（kV）
  Zk = 短路回路总阻抗（Ω）

有名值法（实用计算）：

变压器短路电流：
  Ik = In / Uk%
  其中：In = 变压器额定电流，Uk% = 阻抗电压百分比

示例：1000kVA变压器，Uk%=4.5%，低压侧额定电压0.4kV
  In = 1000 / (√3 × 0.4) = 1443 A
  Ik = 1443 / 0.045 = 32,067 A ≈ 32 kA

短路容量：
  Sk = √3 × Un × Ik  （单位：MVA）

常用基准值：
  取基准容量 Sd = 100 MVA
  取基准电压 Ud = 各电压等级平均电压（Uav = 1.05 × Uc）

标幺值换算：
  Zpu = Z × Sd / Uav²

冲击电流（最大瞬时值）：
  ich = 2.55 × Ik（三相短路）
  （考虑直流分量衰减）
```

#### 11.1.4 电力系统稳定

| 稳定类型 | 定义 | 失稳原因 | 防范措施 |
|---------|------|---------|---------|
| **静态稳定** | 正常运行小扰动后恢复能力 | 功角 δ > 90° | 提高系统电压、串联电容补偿 |
| **暂态稳定** | 大扰动（短路）后恢复能力 | 功角 δ 失去同步 | 快速切除故障、制动电阻 |
| **动态稳定** | 长过程（自动调节）后稳定性 | 调压器/调速器相互作用 | PSS（电力系统稳定器） |

```
功角特性方程：
P = (E×U / X) × sinδ

稳定判据：
- 静态稳定：dP/dδ > 0，即 δ < 90°
- 暂态稳定：面积定则，减速面积 ≥ 加速面积

小快智造业务关联：
在电力系统不稳定的区域（如工业区电网末端），
电能质量问题（电压暂降、谐波）更为突出，
小快智造的电压调节/滤波功能可改善末端电能质量。
```

```
  1. 限流保护（快速关断）
  2. 负载识别（检测电流波形特征）
  3. 电压调节（保持输出稳定）
```

### 11.3 电机学深化

#### 11.3.1 变压器

```
基本原理：电磁感应（互感原理）

额定参数：
- 额定容量 Sn（kVA）
- 额定电压 Un1/Un2（kV）
- 额定电流 In1/In2（A）
- 额定频率 f = 50Hz
- 阻抗电压 Uk%

等效电路参数测定（短路试验）：
 Pk = 短路损耗（铜损）
 Uk% = 阻抗电压百分比（4%~6%）
 Rk = Pk / In²
 Xk = √(Uk² - Rk²)

效率特性：
  η = P2 / P1 = P2 / (P2 + P0 + Pk×β²)
  其中：β = 负载系数，P0 = 空载损耗

变压器并列运行条件（三个条件缺一不可）：
1. 额定电压比相等（变比相同）
2. 短路阻抗标幺值相等（阻抗匹配）
3. 连接组别相同（相位一致）

小快智造应用：
- 380V配电变压器→ 电能过滤器安装位置在变压器出线端
- 多台变压器并列运行时，注意短路阻抗分配负荷
```

#### 11.3.2 异步电动机

```
基本原理：定子旋转磁场 → 转子感应电流 → 转子受力转动

转差率：s = (n0 - n) / n0
  - 额定转差率：sn = 0.01~0.05（1%~5%）
  - 额定转速 n = (1-s)×n0

机械特性：
  额定转矩：Mn = 9550 × Pn(kW) / nn(rpm)
  最大转矩（临界转矩）：Mmax = λ × Mn
  其中 λ = 最大转矩倍数（2.0~2.2）

启动性能：
  - 直接启动：启动电流 Is = (5~7) × In
  - 星-三角启动：Is = (1.8~2.2) × In
  - 软启动器：限制启动电流
  - 变频启动：频率斜坡上升

小快智造应用：
  - 电火保可以安装在电动机回路上（防止电弧故障）
  - 智慧微断适合电动机回路（带负载识别）
  - 变频器+电火保注意：变频器输出侧不能加漏电保护！
```

#### 11.3.3 同步电动机

```
特点：转子转速 = 同步转速（n = 60f/p）

功率因数调节（核心价值）：
- 超前cosφ运行：发出无功功率，改善电网功率因数
- 励磁调节可以改变无功输出

启动方式：
1. 辅助电机启动
2. 变频启动（现代方式）
3. 异步启动（加阻尼绕组）

小快智造应用：
  同步电动机多的工厂（如大型空压机、水泵），
  需要关注功率因数补偿柜的配置。
```

### 11.4 继电保护深化

#### 11.4.1 继电保护基础

```
继电保护四性（由重要到基本）：
1. 可靠性：保护该动时必须动（不拒动）
2. 选择性：最小范围切除故障（不误动）
3. 灵敏性：对故障的敏感程度（灵敏度系数 Kl）
4. 速动性：快速切除故障

灵敏系数计算：
  Kl = 保护范围末端最小短路电流 / 保护动作电流
  要求：Kl ≥ 1.2~1.5（过电流保护）

保护动作时限配合（阶梯原则）：
  t2 > t1 + Δt
  其中 Δt = 0.3~0.5s（时间级差）

断路器固有动作时间：0.06~0.12s
```

#### 11.4.2 电流保护

```
三段式电流保护：

第一段（电流速断）：
- 动作电流：Iop1 = Krel × Ik.max
- 保护范围：线路全长约50%~60%
- 无时限（0s）
- 不保护线路末端

第二段（限时电流速断）：
- 动作电流：Iop2 = Krel × Iop.2
- 保护范围：线路全长 + 下一线路15%~20%
- 时限：0.5s（与下一线路第一段配合）

第三段（定时限过电流保护）：
- 动作电流：Iop3 = Krel×Kss×In.max / Kr
- 保护范围：本线路 + 下一线路全长
- 时限：与下一线路第三段配合（0.5s级差）

其中：
  Krel = 可靠系数（1.1~1.3）
  Kss = 返回系数（0.85~0.95）
  Kr = 继电器返回系数
```

#### 11.4.3 距离保护

```
原理：U/I = Z（阻抗），测量阻抗值判断故障位置

动作特性（阻抗圆）：
- 圆1（第一段）：保护线路全长约80%，0s
- 圆2（第二段）：保护全长+下一线路一部分，0.5s
- 圆3（第三段）：后备保护，1.0s

阻抗整定：
- Zop1 = Krel × ZL（一段）
- Zop2 = Krel × (ZL + Krel2 × ZL.next)（二段）

特点：
- 不受系统运行方式影响（比电流保护更稳定）
- 适用于长距离输电线路
```

#### 11.4.4 变压器保护

| 保护类型 | 整定值 | 动作时间 | 备注 |
|---------|-------|---------|------|
| **瓦斯保护** | 轻瓦斯报警，重瓦斯跳闸 | 0s | 油浸式变压器专属 |
| **纵差动保护** | 变压器额定电流的1.5~2倍 | 0s | 变压器内部故障主保护 |
| **电流速断** | 变压器额定电流3~5倍 | 0s | 作为差动后备 |
| **过电流保护** | 按躲过最大负荷电流整定 | 0.5~1.0s | 作为后备保护 |
| **过负荷保护** | 1.2~1.3 × 额定电流 | 9~10s | 信号/减载 |

#### 11.4.5 微机保护（数字继电保护）

```
现代继电保护的主流形式

核心组成：
- 模拟量采集（CT/PT）
- A/D转换
- 数字信号处理器（DSP）
- 保护算法
- 人机接口

常用算法：
1. 比值法/相位法（故障方向判断）
2. 傅里叶算法（提取基波分量）
3. 小波变换（暂态信号分析）

通信规约：
- IEC 61850（变电站通信）
- IEC 60870-5-103/104（继电保护通信）
- Modbus RTU/TCP

小快智造产品保护定位：
- 小快智造产品属于"主动保护"（预防性）
- 继电保护属于"事后隔离"（故障后切除）
- 两者互补，小快不能替代继电保护！
```

### 11.5 新能源技术

#### 11.5.1 光伏发电系统

```
系统组成：

组件 → 直流汇流箱 → 逆变器（直流→交流） → 交流配电柜 → 电网/负载

光伏组件关键参数：
- 开路电压 Voc
- 短路电流 Isc
- 最大功率点电压/电流 Vmp / Imp
- 转换效率：17%~23%（主流PERC）

组串设计：
- 串联电压：每串组件数 × Voc < 逆变器最大输入电压
- 并联电流：满足逆变器功率要求

逆变器选型：
- 组串式逆变器（常见）：功率 3~250kW
- 集中式逆变器（大型地面电站）：功率 500kW~3MW

电能质量问题：
- 谐波：逆变器PWM调制产生谐波
- 电压波动：光照变化导致功率突变
- 直流分量：部分逆变器会向电网注入直流分量

→ 小快智造的电能过滤器可以安装在光伏并网点，
   改善谐波和功率因数问题
```

#### 11.5.2 储能系统

```
储能类型：

| 类型 | 能量密度 | 功率密度 | 循环寿命 | 响应速度 | 典型应用 |
|-----|---------|---------|---------|---------|---------|
| 锂电池 | 高 | 高 | 3000~6000次 | ms级 | 调频、新能源配套 |
| 铅酸电池 | 中 | 中 | 500~1000次 | s级 | 备用电源 |
| 液流电池 | 高 | 低 | 10000+次 | s级 | 大规模储能 |
| 飞轮储能 | 低 | 极高 | 100万+次 | ms级 | 短时调频 |
| 超级电容 | 极低 | 极高 | 50万+次 | ms级 | 短时功率支撑 |

BMS（电池管理系统）功能：
- 监测单体电压、温度
- SOC（荷电状态）计算
- 均衡管理
- 保护（过压/欠压/过温）

PCS（储能变流器）：
- 整流（充电）/ 逆变（放电）
- 有功/无功调节
- 并离网切换
```

#### 11.5.3 电动汽车充电桩

```
充电桩类型：

交流充电桩（慢充）：
- 功率：3.5kW / 7kW / 11kW / 21kW
- 输入：单相220V 或 三相380V
- 输出：交流（车载OBC整流）

直流充电桩（快充）：
- 功率：30kW / 60kW / 120kW / 180kW / 360kW
- 输入：三相380V
- 输出：直流（桩内整流）

谐波问题（重要）：
- 充电桩是典型非线性负载
- 直流充电桩谐波含量高（THDi可达30%以上）
- 需要有源滤波器或电能质量治理设备

→ 小快智造电能过滤器可以安装在充电桩配电前端，
   解决谐波和功率因数问题

充电桩配电设计：
- 单台120kW快充额定电流：约182A
- 需要专用变压器或单独配电回路
- 需要考虑同时系数（通常取0.6~0.8）
```

### 11.6 高电压技术基础

#### 11.6.1 绝缘配合

```
目的：在绝缘强度和经济性之间取得平衡

绝缘水平：
- 基本冲击绝缘水平（BIL）：设备能承受的雷电冲击电压峰值
- 额定短时工频耐受电压

雷电冲击电压：1.2/50μs（标准雷电波）
操作冲击电压：250/2500μs（标准操作波）

避雷器选型：
- 额定电压 Ur ≥ 系统最高运行相电压
- 持续运行电压 Uc ≥ 系统最高相电压
- 残压（8/20μs）：限制雷电/操作过电压

典型值（10kV系统）：
  避雷器额定电压：17kV
  持续运行电压：13.6kV（相电压×1.4）
  雷电残压（5kA）：≤ 45kV
```

#### 11.6.2 内部过电压

| 类型 | 产生原因 | 幅值 | 防护措施 |
|-----|---------|------|---------|
| **工频过电压** | 甩负荷、单相接地 | 1.3~1.4倍 | 并联电抗器 |
| **谐振过电压** | 铁磁谐振、参数谐振 | 2~3倍 | 阻尼电阻 |
| **操作过电压** | 开关操作 | 3~4倍 | 金属氧化物避雷器 |

#### 11.6.3 电气设备绝缘试验

```
出厂试验（例行试验）：
- 绝缘电阻测量（兆欧表）
- 交流耐压试验
- 介质损耗角正切（tanδ）测量

交接试验：
- 直流耐压试验（电缆）
- 局部放电测量
- 绝缘油试验（变压器油）

预防性试验周期：
- 电力变压器：3年
- 高压断路器：3年
- 金属氧化物避雷器：3年（运行电压下的泄漏电流）

tanδ判断标准（变压器）：
- 35kV以下：≤ 1.5%
- 35~220kV：≤ 0.8%
- 220kV以上：≤ 0.5%
```
