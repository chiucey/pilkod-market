# 专利布局策略参考

## 专利布局策略体系

### 一、核心-外围专利布局

#### 经典组合模式

```
核心专利（1项）
├── 保护核心技术原理
├── 申请发明专利
├── 寻求最大保护范围
└── 优先申请+全球布局

外围专利（N项）
├── 改进型发明（2-3项）
├── 实用新型（3-5项）
├── 外观设计（1-2项）
└── 补充保护核心技术的应用场景
```

#### 示例：智能电动汽车企业

| 专利类型 | 数量 | 保护内容 | 申请类型 |
|----------|------|----------|----------|
| 核心电池管理算法 | 1项 | BMS控制策略 | 发明 |
| 充电管理优化 | 2项 | 快充算法、充电保护 | 发明 |
| 热管理系统 | 2项 | 冷却结构、温度控制 | 发明+实用新型 |
| 电池包结构 | 3项 | 模组布置、固定方式 | 实用新型 |
| 充电接口设计 | 1项 | 连接器外观 | 外观设计 |

### 二、地理布局策略

#### 市场导向布局

| 市场重要性 | 地区 | 申请建议 |
|------------|------|----------|
| 核心市场 | 中国、美国 | 发明+实用新型，双报 |
| 重要市场 | 欧洲、日本、韩国 | 发明专利，优先申请 |
| 制造基地 | 越南、泰国、印度 | 实用新型或直接申请 |
| 潜在市场 | 巴西、俄罗斯 | 根据预算选择性申请 |

#### 专利审查高速公路(PPH)

建议申请顺序：
1. 先在中国申请（如需优先权）
2. 12个月内通过PCT进入目标国
3. 利用PPH加速审查

### 三、技术生命周期布局

#### 导入期（技术初创）
- 聚焦基础原理专利
- 保护范围适度放宽
- 优先申请发明专利
- 布局重点：核心市场

#### 成长期（技术发展）
- 围绕核心专利布局外围
- 快速迭代改进专利
- 实用新型保护快速成果
- 扩大地域布局

#### 成熟期（技术稳定）
- 完善专利网络
- 申请防御性专利
- 关注竞品专利空白点
- 考虑专利许可策略

#### 衰退期/转型期
- 维持核心专利
- 放弃价值低的专利
- 布局新技术路线
- 考虑专利交易

### 四、专利申请类型组合

#### 方案A：重发明模式
```
1项核心发明 + 3项改进发明 + 5项实用新型 + 2项外观
```
适用：核心技术领先、保护意识强、预算充足

#### 方案B：平衡模式
```
2项核心发明 + 2项实用新型 + 1项外观
```
适用：中等研发投入、常规专利布局

#### 方案C：快速保护模式
```
1项核心发明 + 5项实用新型
```
适用：快速迭代产品、需要快速获权

### 五、分层保护策略

#### 第一层：核心保护层
- 最基础、最核心的发明点
- 申请发明专利
- 保护范围最大化
- 全球化布局

#### 第二层：应用保护层
- 基于核心技术的具体应用
- 发明+实用新型结合
- 覆盖主要产品形态
- 核心市场布局

#### 第三层：防御保护层
- 改进型创新点
- 主要申请实用新型
- 防止竞争对手规避
- 重点市场布局

#### 第四层：外观保护层
- 产品外观设计
- 申请外观设计专利
- 提升品牌价值
- 选择性布局

---

### 六、专利布局Checklist

#### 核心专利
- [ ] 技术方案具有开创性
- [ ] 保护范围足够宽
- [ ] 审查周期可接受（2-3年）
- [ ] 已考虑全球化布局
- [ ] 制定了防御性外围专利

#### 外围专利
- [ ] 覆盖主要改进方向
- [ ] 覆盖主要应用场景
- [ ] 考虑了替代方案
- [ ] 实用新型提供快速保护
- [ ] 外观设计补充保护

#### 申请策略
- [ ] 发明/实用新型组合申请
- [ ] 制定了地域布局计划
- [ ] 考虑了PCT途径
- [ ] 预算分配合理
- [ ] 有专人跟踪审查进度

- 主动均衡算法（发明专利）
- 全球主要市场申请

### 第二层：重要专利（3-5项）
- 仿生流道设计
- 热管理控制系统
- 充电优化算法
- 发明+实用新型双报

### 第三层：外围专利（5-8项）
- 具体结构改进
- 参数优化方案
- 主要申请实用新型

### 第四层：防御专利（3-5项）
- 替代方案
- 规避设计
- 补充保护
