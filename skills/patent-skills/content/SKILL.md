# 专利挖掘与布局分析系统

## 系统概述

本技能面向企业 IPR、研发人员、专利代理师，通过 AI 技术自动从技术文档、研发数据中识别、提取、评估可专利创新点，生成标准化专利挖掘报告，辅助用户完成技术成果到专利资产的转化。

**核心价值**：将研发人员的技术描述转化为标准化的专利技术点，显著提升专利布局效率。

**能力边界**：本技能输出的初步评估结果不可直接作为专利申请、侵权判断的最终依据，最终决策需由专业知识产权人员审核确认。

---

## 一、处理流程（7步标准工作流）

### Step 1: 输入预处理

**任务**：解析并标准化用户输入

**执行要点**：
1. **文档解析**
   - 解析 Word (.docx)、PDF、TXT、Markdown 格式文档
   - 提取纯文本内容，保留技术逻辑结构
   - 长文档（最大500页）分段处理，每段独立分析后合并

2. **数据清洗**
   - 去除格式噪音（页眉页脚、目录、水印）
   - 识别并标记技术术语（自动标注领域词汇）

3. **技术术语标准化**
   - 建立领域术语映射表
   - 识别技术简称与全称对应关系
   - 统一技术描述用词

**输出**：`预处理后技术文本` + `术语标注结果`

---

### Step 2: 技术调研与问题识别

**任务**：理解技术背景，识别技术痛点

**执行要点**：
1. **技术背景提取**
   - 识别技术领域分类
   - 提取技术发展现状描述
   - 梳理技术路线演进

2. **技术问题识别**
   - 识别现有技术的缺陷与不足
   - 提取用户明示的技术痛点
   - 挖掘隐含的技术问题（通过"但是"、"然而"、"难以"、"无法"等转折词）

3. **技术目标确认**
   - 明确技术改进目标
   - 确认预期达到的技术效果

**输出**：`技术背景摘要` + `问题清单`

---

### Step 3: 技术分解与创新点挖掘

**任务**：系统化拆解技术方案，提取可专利点

**执行要点**：

#### 3.1 正向挖掘（从技术方案出发）

1. **技术系统分层拆解**
   - Level 1 总成级：完整技术系统
   - Level 2 部件级：核心功能模块
   - Level 3 零件级：具体结构组件
   - Level 4 关键结构/参数级：细节特征与参数范围

2. **问题-手段-效果三元组提取**
   ```
   [问题] 技术缺陷/需求 → [手段] 技术实现方案 → [效果] 技术改进效果
   ```
   - 每个三元组对应一个潜在专利点

3. **横向挖掘（替代方案推导）**
   - 分析等效替换方案
   - 推导功能等价技术路线
   - 识别不同实现路径

4. **纵向挖掘（细节深化）**
   - 参数范围优化分析
   - 工艺窗口探索
   - 材料替代可能性

#### 3.2 反向挖掘（从现有技术出发）

1. **现有专利匹配**
   - 分析目标领域专利分布
   - 识别竞品专利保护范围
   - 发现技术空白点

2. **交叉领域创新识别**
   - 识别不同技术分支的交叉点
   - 发现跨界应用可能性
   - 推导融合创新机会

**输出**：`技术分解树` + `初步创新点清单`

---

### Step 4: 专利检索与分析

**任务**：检索现有技术，评估新颖性基础

**执行要点**：

1. **检索策略制定**
   - 确定检索关键词（技术术语 + 同义词 + 上位概念）
   - 选择检索字段（标题/摘要/权利要求/全文）
   - 设定地域范围（用户指定或默认中美欧日韩）
   - 设定时间范围（通常10年内）

2. **专利数据库检索**
   - 检索相同/相近技术领域的已有专利
   - 检索相关竞品的所有专利
   - 记录高度相关文献

3. **技术空白分析**
   - 识别无人布局的技术方向
   - 区分核心专利与外围专利
   - 评估侵权风险等级

**输出**：`相关专利清单` + `技术空白分析`

---

### Step 5: 创新点评估与筛选

**任务**：三维评估创新点，确定优先级

**执行要点**：

#### 5.1 技术维度评估
| 评估项 | 评估内容 | 评分标准 |
|--------|----------|----------|
| 技术可行性 | 方案是否可实现 | 1-5分 |
| 创新高度 | 与现有技术相比的创新程度 | 1-5分 |
| 技术瓶颈突破 | 是否解决行业关键技术难题 | 1-5分 |

#### 5.2 市场维度评估
| 评估项 | 评估内容 | 评分标准 |
|--------|----------|----------|
| 市场规模 | 对应技术的市场容量 | 1-5分 |
| 产品覆盖度 | 可应用的产品种类 | 1-5分 |
| 商业价值潜力 | 预期的商业回报 | 1-5分 |

#### 5.3 法律维度评估
| 评估项 | 评估内容 | 评分标准 |
|--------|----------|----------|
| 新颖性 | 是否存在在先公开技术 | 高/中/低/无 |
| 创造性 | 技术方案是否非显而易见 | 高/中/低 |
| 可专利类型 | 适配的申请类型 | 发明/实用新型/外观 |

**综合评分**：加权计算（技术40% + 市场30% + 法律30%）

**输出**：`评估后创新点清单` + `优先级排序`

---

### Step 6: 专利布局策略制定

**任务**：生成专业布局建议

**执行要点**：

1. **核心专利识别**
   - 识别技术方案的核心创新点
   - 确定需要最强保护的技术点
   - 建议优先申请发明专利

2. **外围专利规划**
   - 识别可布局的改进型创新点
   - 建议申请实用新型保护
   - 规划外观设计保护（如适用）

3. **专利组合方案**
   ```
   典型组合：1项核心发明 + N项外围实用新型/外观
   ```

4. **地域布局策略**
   | 市场重要性 | 建议申请地域 |
   |------------|-------------|
   | 核心市场 | 中国、美国、欧洲 |
   | 制造基地 | 东南亚（如越南、泰国） |
   | 潜在市场 | 印度、巴西 |

**输出**：`专利布局建议书`

---

### Step 7: 结果输出

**任务**：生成标准化报告与可导出文件

**执行要点**：

1. **结构化创新点清单**
   - 方案名称
   - 待解决的技术问题
   - 核心技术手段
   - 实现的技术效果
   - 替代方案
   - 建议申请类型
   - 初步可专利性评估结果

2. **完整专利挖掘报告**
   - 项目技术背景概述
   - 创新点清单（表格形式）
   - 专利布局整体建议
   - 后续工作指引

3. **技术交底书草稿**（可选扩展）
   - 基于挖掘结果自动生成初稿
   - 包含技术领域、背景、发明内容、附图说明等模块

4. **可视化展示**
   - 技术分解树图
   - 创新点价值分布图
   - 专利布局策略图

**输出格式**：
- 完整报告：Word (.docx)、PDF
- 数据导出：Excel (.xlsx)
- 可视化：PNG/SVG 图表

## 二、扩展功能模块

### TRIZ 辅助创新拓展

**功能**：基于40个发明原理，辅助推导创新方案

**适用场景**：当技术问题明确但创新方向不清晰时

**操作方式**：
1. 输入技术问题描述
2. 系统推荐适用的TRIZ原理
3. 推导潜在创新方案
4. 评估并纳入创新点清单

### 技术交底书草稿生成

**功能**：基于挖掘结果生成技术交底书初稿

**文档结构**：
- 技术领域
- 背景技术
- 发明内容
- 附图说明
- 具体实施方式

### 工艺数据联动挖掘（高级）

**功能**：对接制造业数据，将工艺Know-how专利化

**适用数据**：
- DCS 系统数据
- MES 生产数据
- 质量检测数据
- 设备运维日志

## 四、技术能力限制说明

**本技能可做到**：
- 自动解析技术文档并提取关键信息
- 基于语义分析识别潜在创新点
- 提供初步的可专利性评估
- 生成标准化的专利挖掘报告
- 推荐专利布局策略

**本技能限制**：
- 无法替代专业专利检索系统的深度检索
- 初步评估结果需专业人员审核
- 无法判断侵权风险（需法律分析）
- 输出质量依赖输入文档的完整度

**重要声明**：所有专利申请决策必须由具备资质的专利代理师或知识产权律师审核确认。

## 五、使用示例

### 示例场景1：新能源汽车电池热管理技术

**用户输入**：
```
技术文档：动力电池热管理系统设计文档
技术领域：新能源汽车
挖掘重点：热管理算法、结构设计
```

**处理流程**：
1. 解析电池热管理技术文档
2. 识别技术问题：散热不均匀、温控响应慢
3. 技术分解：总成(热管理系统) → 部件(冷却模块) → 零件(冷却板、流道) → 参数(流速、温度阈值)
4. 提取创新点：主动式热均衡算法、仿生流道设计、相变材料集成
5. 专利检索：检索热管理相关专利
6. 评估：三维度评估后排序
7. 布局：1项核心算法发明 + 2项结构实用新型
8. 输出：完整挖掘报告 + 创新点清单

### 示例场景2：医疗器械软件算法

**用户输入**：
```
技术文档：AI辅助诊断算法说明
技术领域：医疗器械+AI
挖掘重点：算法改进、数据处理
```

## 六、质量控制

### 自检清单

处理每个任务时，确保：

- [ ] 文档解析完整，无遗漏关键章节
- [ ] 技术术语识别准确，标注无歧义
- [ ] 问题-手段-效果三元组逻辑清晰
- [ ] 创新点评估依据充分
- [ ] 布局建议符合行业惯例
- [ ] 报告格式规范，内容完整

### 错误处理

| 异常情况 | 处理方式 |
|---------|---------|
| 文档格式无法解析 | 提示用户转换为可读格式 |
| 技术领域无法识别 | 请用户明确指定领域 |
| 创新点过少 | 引导用户提供更多技术细节 |
| 检索结果为空 | 扩大检索范围或调整关键词 |
