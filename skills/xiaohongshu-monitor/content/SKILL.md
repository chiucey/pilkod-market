# 小红书搜寻监控总结技能

## 技能概述

本技能用于小红书平台的内容搜索、监控和数据分析总结，帮助用户追踪热门话题、分析爆款笔记、监控竞品内容。

## 核心能力

1. **内容搜索**：搜索帖子、笔记、博主信息
2. **话题监控**：追踪特定关键词/话题的热门内容
3. **数据分析**：分析互动数据、提取热门关键词
4. **报告生成**：生成可视化监控报告

## 执行流程

### 步骤 1：需求理解

解析用户需求：
- 搜索主题/关键词
- 监控范围（时间、类型）
- 输出格式要求

### 步骤 2：执行搜索

调用小红书搜索工具获取内容数据：
- 帖子基本信息（标题、作者、时间）
- 互动数据（点赞、收藏、评论）
- 话题标签

### 步骤 3：数据分析

对搜索结果进行深度分析：
- 热门内容排序
- 关键词提取与词频统计
- 博主/账号分析
- 趋势洞察

### 步骤 4：报告生成

生成结构化报告：
- 执行摘要
- 数据概览
- 热门内容分析
- 关键发现
- 建议与洞察

## 输出格式

### 标准报告结构

```
📊 小红书监控报告
────────────────
⏰ 监控时间：[时间范围]
🔍 搜索主题：[关键词]
📈 数据量：X条笔记

【热门内容 TOP 10】
1. [标题] - ❤️X 👍X 💬X
...

【关键词云】
[标签1] (X次) | [标签2] (X次) | ...

【博主榜单】
1. @用户名 - X篇笔记

【数据洞察】
- 平均互动量：X
- 最活跃时间段：X
- 热门内容类型：X
```

## 注意事项

- 搜索结果受平台限制，可能无法获取全部数据
- 数据分析基于公开可获取信息
- 定期监控建议设置定时任务
