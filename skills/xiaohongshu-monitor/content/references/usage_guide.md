# 小红书监控技能参考文档

## 触发场景示例

### 1. 搜索内容
```
用户：搜索小红书关于"露营装备推荐"的内容
技能：执行搜索，返回相关笔记列表和数据分析
```

### 2. 话题监控
```
用户：监控小红书"618好物推荐"话题的热门笔记
技能：搜索话题内容，分析爆款笔记特征
```

### 3. 竞品分析
```
用户：分析竞品账号"XX美妆"的小红书内容
技能：搜索博主笔记，分析内容策略和数据表现
```

### 4. 趋势洞察
```
用户：分析最近一周小红书"减肥"相关热门内容
技能：按时间范围搜索，分析趋势变化
```

## 输出格式变体

### 1. 简洁摘要（快速响应）
适合即时对话场景，输出精简的关键信息。

### 2. 详细报告（完整分析）
适合需要深入分析的正式场景。

### 3. 数据表格（结构化输出）
适合需要后续处理的数据导出场景。

## 常见问题

### Q: 搜索结果不完整？
A: 小红书平台对搜索结果有限制，建议分多次搜索或使用更精确的关键词。

### Q: 如何设置定时监控？
A: 使用 `create_cron_job` 工具设置定期执行，频率建议每天或每周一次。

### Q: 支持哪些类型的分析？
A: 话题热度分析、博主影响力分析、内容类型分析、互动数据对比等。
