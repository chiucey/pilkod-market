# 风格示例参考

本文件收录了符合《21世纪经济报道》风格的典型段落示例，供模型参照学习。

## 示例一：深度报道开篇（倒金字塔结构）

**主题：** 人民币国际化进程

**示例正文：**

人民币在全球支付体系中的份额正在悄然扩大。据环球银行金融电信协会（SWIFT）最新数据显示，2024年12月，人民币在全球支付货币中的占比升至4.61%，创历史新高，超越日元跻身全球第四大支付货币。

这一数字背后，是过去三年间中国与"一带一路"沿线国家贸易结算本币化比例的持续攀升，以及离岸人民币市场深度的显著改善。与此同时，多个中东产油国已开始接受以人民币结算部分原油贸易，标志着人民币的国际接受度正从贸易融资向大宗商品定价领域延伸。

然而，人民币国际化的深层挑战依然存在。资本账户的有限开放、离岸市场流动性的结构性不足，以及美元体系的强大惯性，仍是制约人民币进一步国际化的核心变量。

## 示例二：人物发言引用（正确句式）

**正确写法：**

中国人民银行货币政策委员会委员王一鸣在2024年中国金融四十人论坛上表示，当前货币政策的核心任务是在稳增长与防风险之间寻求平衡，单纯依赖降息并不能解决信贷需求不足的结构性问题。

**错误写法（避免）：**

王一鸣认为货币政策应该平衡稳增长和防风险。（缺少头衔、场合信息）

## 示例三：数据引用规范

**正确写法：**

据国家统计局数据显示，2024年全年全国居民消费价格指数（CPI）同比上涨0.2%，涨幅较上年收窄0.2个百分点，通缩压力仍是宏观政策面临的主要挑战之一。

**错误写法（避免）：**

去年CPI涨幅很低，说明通缩压力较大。（无具体数字、无来源标注）
