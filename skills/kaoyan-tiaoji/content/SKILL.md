# 考研调剂情报检索

将模糊的考研调剂需求转化为来源可追溯的院校清单。

## 快速开始

- 锁定用户报考年份、目标专业、意向地区、院校层次偏好、科目约束和输出格式后再进行搜索。
- 用户未指定的字段从上下文推断最窄的合理默认值，并明确说明每项假设。
- 详细字段定义、搜索模式和输出模板请参阅 `references/source-patterns.md`。

## 工作流程

### 1. 锁定需求

确认或推断以下字段：

- **报考年份**（必填）；所有交付物使用绝对日期，如 `2026-04-03`
- **专业代码和专业名称**（如已知）
- **研究方向、研究领域或培养方向**（如相关）
- **意向省份、城市或地理排除区**
- **院校层次偏好**：985/211、双一流、普通一本、地区优先、院校层次不限
- **初试科目约束**：英语一+数学一、英语二+数学二、408、396、自命题专业课，或仅接受相同初试科目
- **期望输出形式**：Markdown 表格、分级清单或关注列表

### 2. 优先搜索官方来源

按以下优先级搜索：

1. 院校研究生院网站
2. 接收学院或系所网站
3. 中国研究生招生信息网（yz.chsi.com.cn）、省级教育考试院、或院校招生门户
4. 教育部或省级教育部门直接发布的公告或目录

仅使用商业聚合网站发现候选院校，不引用其作为最终事实依据。

详细搜索模式请参阅 `references/source-patterns.md`。

### 3. 谨慎判断科目兼容性

根据用户实际约束，将科目兼容性作为筛选条件。为每所院校分配唯一标签：

| 标签 | 含义 |
|------|------|
| `明确匹配` | 官方来源直接确认相同或可接受的科目组合 |
| `间接匹配` | 仅旧版官方目录、间接证据或宽泛措辞支持兼容性 |
| `明确不匹配` | 官方来源显示冲突的科目设置或调剂限制 |
| `待确认` | 院校接受调剂，但当前官方来源信息不足无法判断 |

常见科目检查项：
- 201 英语一 + 301 数学一
- 204 英语二 + 302 数学二
- 396 经济类联考
- 408 计算机学科专业基础
- 自命题专业课代码是否一致或相近
- 是否要求原报考专业相同/相近

若当年目录仅以图片形式呈现、无法访问或过于模糊，不得过度声明确定性，优先使用 `间接匹配` 或 `待确认`。

### 4. 仅提取有依据的数据

尽可能为每所院校收集以下字段：

| 字段 | 说明 |
|------|------|
| 学校 | 院校名称 |
| 学院 | 接收学院 |
| 地区 | 省份或城市 |
| 专业 | 代码+名称，或研究方向 |
| 科目要求 | 用户请求的科目筛选条件 |
| 科目匹配 | 明确匹配/间接匹配/明确不匹配/待确认 |
| 当年计划 | 当年计划招生人数 |
| 一志愿录取 | 当年一志愿已录取人数 |
| 调剂名额 | 当年调剂名额或可计算的缺口 |
| 历年分数 | 历年最低分及来源类型标注 |
| 状态 | 当前可申报/重点关注 |
| 来源 | 官方链接 |

数据规则：
- 官方页面无该字段时，写 `未说明`
- 仅当两个输入均为官方且可比时，才计算 `缺口 = 计划招生 - 已录取一志愿`
- 若页面仅写"接受调剂"无具体名额，调剂名额字段保持 `未说明`
- 若仅为复试名单或分数公示，标注为 `复试名单分数参考` 而非 `拟录取最低分`
- 若专业名称相似但代码不同，明确标注不一致，不合并记录

### 5. 按可操作性分级

至少分为两个Bucket：

- **当前可申报**：有当年官方调剂公告或明确调剂名额，且无已知科目冲突
- **重点关注**：符合用户地区或层次偏好，有历年调剂证据或当年较强信号，但尚未发布足够当年详情

必要时可附加执行优先级标签：高优先/中优先/低优先。

### 6. 输出 Markdown 交付物

产出简洁的 Markdown 文件，包含：

- 标题：包含报考年份+专业代码或研究方向
- 更新日期和当日检查内容
- 方法说明：明确最终表格仅保留官方来源可直接支持的事实
- 当前确认选项的表格
- 每所院校的简短说明：覆盖兼容性、名额、分数参考和注意事项
- 关注列表：适合但仍需当年确认的潜在院校
- 每所院校的来源链接或专门的来源列

默认结构模板见 `references/source-patterns.md`。

## 输出标准

- 优先使用官方链接而非复制的文字
- 包含精确日期如 `2026-04-03`
- 区分 `明确匹配` 与 `间接匹配`
- 不在表格中放入无依据的猜测
- 在时效性搜索时说明当日检查内容
- 将仅图片、仅PDF或不可访问的官方页面标注为证据局限
- 研究生招生研究优先正确性而非完整性
