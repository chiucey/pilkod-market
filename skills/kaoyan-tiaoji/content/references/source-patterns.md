# 考研调剂检索：搜索模式与输出模板

## 推荐搜索语句

将占位符 `{year}`、`{major_code}`、`{major_name}`、`{school}`、`{province}`、`{city}`、`{subject}` 替换为用户实际约束。

### 院校域名搜索（优先）

```
site:edu.cn {year} 调剂 {major_code}
site:edu.cn {year} 调剂 {major_name}
site:edu.cn {year} {school} 调剂 公告
site:edu.cn {year} {school} 研究生院 调剂
site:edu.cn {year} {school} {major_code} 调剂
site:edu.cn {year} {major_name} 英语一 数学一 调剂
site:edu.cn {year} {major_name} 英语二 数学二 调剂
site:edu.cn {year} {major_name} 408 调剂
site:edu.cn {year} {major_name} 396 调剂
site:edu.cn {year} {province} {major_name} 调剂
```

### 招生信息网搜索

```
site:yz.chsi.com.cn {year} 调剂 {major_name}
```

### 历年数据搜索

```
site:edu.cn {year_minus_1} {school} {major_name} 调剂
site:edu.cn {year_minus_1} {school} 复试名单 {major_name}
site:edu.cn {year_minus_1} {school} 拟录取名单 {major_name}
```

发现候选院校后，优先搜索其研究生院域名，其次是学院或系所域名。

## 官方页面类型

查找以下类型的官方页面：

| 页面类型 | 优先级 | 说明 |
|---------|--------|------|
| 当年调剂公告/通知/工作办法 | P0 | 核心依据 |
| 学院或系所调剂通知 | P0 | 专业级详情 |
| 当年招生专业目录及初试科目表 | P1 | 科目兼容性判断 |
| 复试名单/复试成绩公示 | P1 | 分数参考 |
| 拟录取名单/拟录取公示 | P1 | 最终录取数据 |
| 历年调剂公告（含缺额/名额/接收/余额等措辞） | P2 | 历史参考 |
| 调剂规则（原报考专业相同/相近、初试科目要求） | P1 | 兼容性判断 |

## 字段清单

| 字段 | 说明 | 必填 |
|------|------|------|
| school | 院校名称 | 是 |
| college | 接收学院 | 是 |
| region | 省份或城市 | 是 |
| major | 专业代码+名称，或研究方向 | 是 |
| subject_requirement | 用户请求的科目筛选条件 | 是 |
| subject_match | 明确匹配/间接匹配/明确不匹配/待确认 | 是 |
| current_plan | 当年计划招生人数 | 推荐 |
| first_choice | 当年一志愿已录取人数 | 推荐 |
| vacancy | 当年调剂名额或可计算的缺口 | 推荐 |
| prev_min_score | 历年最低分（含来源类型标注） | 推荐 |
| status | 当前可申报/重点关注 | 是 |
| sources | 官方来源链接 | 是 |

## 科目匹配标签定义

| 标签 | 定义 |
|------|------|
| `明确匹配` | 当前官方来源直接确认相同科目要求或明确可接受的规则 |
| `间接匹配` | 仅旧版官方目录、间接证据或宽泛措辞支持兼容性匹配 |
| `明确不匹配` | 官方来源显示冲突的科目设置或明确的调剂限制 |
| `待确认` | 院校接受调剂学生，但当前官方证据不足以判断兼容性 |

## 分数标注规则

| 场景 | 标签 |
|------|------|
| 官方页面为拟录取名单或最终录取名单 | 拟录取最低分 |
| 来源为复试名单或分数公示通知 | 复试名单分数参考 |
| 官方来源未披露该字段 | 未说明 |

## 调剂状态标签定义

| 标签 | 定义 |
|------|------|
| `当前可申报` | 有当年官方调剂公告或明确调剂名额，且无已知科目冲突 |
| `重点关注` | 符合用户地区或层次偏好，有历年调剂证据或当年较强信号，但尚未发布足够当年详情 |

## 搜索策略建议

1. **年度优先**：优先搜索当年官方公告，当年信息最准确
2. **层层深入**：从院校研究生院 → 学院/系所 → 招生信息网递进
3. **历年验证**：若当年信息不足，查询历年调剂公告作为参考
4. **多源交叉**：关键数据点建议在多个官方来源中交叉验证
5. **时效敏感**：考研调剂窗口期短，优先最新发布的信息
