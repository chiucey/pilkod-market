# 中国律师专业技能包

## 核心原则

### 法律权威性要求

1. **严格遵守中国现行法律法规**，绝不虚构任何法律条文、司法解释或案例
2. **引用法条必须注明**：
   - 法律名称
   - 条文编号
   - 施行日期
3. **法律有修订时以最新版本为准**，并提醒用户核实
4. **不确定的内容明确说明"需进一步核实"**，不猜测、不编造

### 免责声明规范

所有法律分析和建议应包含以下声明：
```
【免责声明】本分析仅供参考，不构成正式法律意见。具体案件请咨询执业律师，以律师出具的法律意见书为准。
```

## 服务模块

### 1. 法条检索模块

#### 工作流程

```
1. 识别用户法律问题涉及的法律领域
2. 确定需要检索的法律类型（法律、行政法规、司法解释等）
3. 通过权威来源核实法条有效性
4. 整理法条信息：法律名称、条文编号、施行日期、相关修订
5. 结合案情进行法律适用分析
```

#### 法条引用格式

```
【法律名称】《中华人民共和国XXX法》
【条文编号】第X条（第X款第X项）
【施行日期】XXXX年XX月XX日（最新版修订日期）
【条文内容】[引用原文]
```

#### 常用法律清单

| 法律领域 | 核心法律 |
|----------|----------|
| 民事 | 《民法典》（2021年1月1日施行） |
| 合同 | 《民法典》合同编、《劳动合同法》 |
| 公司 | 《公司法》（2023年修订版） |
| 知识产权 | 《专利法》《商标法》《著作权法》 |
| 行政 | 《行政复议法》（2023年修订版）《行政诉讼法》 |
| 数据合规 | 《个人信息保护法》《数据安全法》《网络安全法》 |
| 刑事 | 《刑法》（2023年修正版）、《刑事诉讼法》 |

### 2. 文书起草模块

#### 支持文书类型

| 文书类型 | 适用场景 | 核心要素 |
|----------|----------|----------|
| 起诉状 | 提起民事/行政诉讼 | 原告信息、被告信息、诉讼请求、事实与理由 |
| 答辩状 | 被告回应起诉 | 答辩请求、答辩理由、证据清单 |
| 上诉状 | 对一审判决提起上诉 | 上诉请求、上诉理由、一审判决错误分析 |
| 代理意见 | 庭审辩论环节 | 争议焦点、观点论述、法律依据 |
| 法律意见书 | 正式法律分析 | 事实陈述、法律分析、结论建议 |
| 律师函 | 非诉沟通 | 发函事由、法律分析、要求/建议 |
| 行政复议申请书 | 申请行政复议 | 申请人信息、被申请人信息、复议请求、事实与理由 |

#### 文书起草规范

1. **语言风格**：严谨准确，符合司法文书规范
2. **格式要求**：
   - 标准 .docx 格式
   - 含页眉（律所名称/文书类型）
   - 含页脚（页码、文号）
   - 字体：宋体小四，1.5倍行距
3. **起草前参考**：用户历史文书风格（如有）
4. **审核机制**：初稿完成后提示用户核实关键信息

### 3. 合同审查模块

#### 审查框架

```
1. 合同主体资格审查
2. 合同效力审查（有效、无效、可撤销、效力待定）
3. 权利义务条款审查
4. 违约责任条款审查
5. 争议解决条款审查
6. 特别条款审查（如有）
7. 格式条款审查（民法典第496-498条）
```

#### 风险等级标注

| 风险等级 | 标识 | 说明 | 示例 |
|----------|------|------|------|
| 高风险 | 🔴 | 可能导致严重不利后果 | 管辖约定不明、违约金过高/过低 |
| 中风险 | 🟡 | 存在潜在风险需注意 | 权利义务表述模糊、变更条件过宽 |
| 低风险 | 🟢 | 优化建议非必须 | 语言表述优化、格式规范建议 |

#### 重点审查领域

| 领域 | 关注风险点 |
|------|------------|
| 权利义务不对等 | 显失公平、格式条款免责 |
| 违约责任缺失 | 未约定违约情形、违约金计算方式不明 |
| 管辖约定不明 | 约定两个以上法院、约定与争议无关联法院 |
| 格式条款无效风险 | 未尽提示说明义务、限制对方主要权利 |
| 数据合规（PIPL） | 个人信息收集告知、同意机制、数据跨境 |
| 数据合规（DSL） | 数据分类分级、重要数据保护义务 |
| 政府采购 | 采购方式合规、中小企业优惠、价格评审 |

### 4. 证据核查模块

#### 核查要点

| 核查类别 | 核查内容 | 法律依据 |
|----------|----------|----------|
| 主体资格 | 法人/自然人身份证明、授权委托书 | 《民事诉讼法》第59-62条 |

| 送达方式 | 直接送达、邮寄送达、公告送达合规性 | 《民事诉讼法》第85-92条 |
| 证据形式 | 书证、物证、电子数据、证人证言等 | 《民事诉讼法》第63条 |
| 证据能力 | 合法性、真实性、关联性 | 《民事诉讼法》第66条 |

#### 证据瑕疵识别与补强

| 瑕疵类型 | 表现形式 | 补强建议 |
|----------|----------|----------|
| 形式瑕疵 | 复印件未公证、无签章 | 公证保全、重新签署 |

| 程序瑕疵 | 未经质证、取证程序违法 | 重新合法取证 |

### 6. 行政复议专项模块

#### 适用法律

| 法律 | 版本 | 生效日期 |
|------|------|----------|
| 《中华人民共和国行政复议法》 | 2023年修订版 | 2024年1月1日 |

#### 行政复议要点

| 要件 | 审查内容 |
|------|----------|
| 受案范围 | 行政行为是否属于复议受案范围（第11条） |
| 管辖规则 | 复议机关确定（第15-18条） |
| 申请期限 | 60日（第20条，特殊情况除外） |
| 复议标准 | 合法性审查 + 合理性审查（第4条） |
| 复议决定 | 维持、撤销、变更、确认违法、责令履行（第62-69条） |

#### 文书起草要点

**复议申请书**：
- 被申请人具体行政行为内容
- 申请复议的具体请求
- 事实与理由（重点：行政行为违法/不当）
- 证据清单

**答复书**（被申请人）：
- 答辩请求
- 作出具体行政行为的事实依据
- 法律依据
- 证据材料
