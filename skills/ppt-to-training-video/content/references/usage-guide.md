# PPT转培训视频 - 使用指南

## 快速开始

1. **准备PPT文件**
   - 确保是 `.pptx` 格式
   - 每页内容不宜过多
   - 建议添加演讲者备注

2. **上传并执行**
   - 将PPT文件路径提供给技能
   - 指定输出选项（语音风格、分辨率等）

3. **等待生成**
   - 系统自动处理各步骤
   - 完成后下载视频

## 配置选项

### 语音配置

| 参数 | 默认值 | 说明 |
|------|--------|------|
| voice | female-qn-qingse | 女声（温柔专业） |
| speed | 1.0 | 语速范围 0.5-2.0 |
| emotion | happy | 情绪：happy/sad/neutral |

### 视频配置

| 参数 | 默认值 | 说明 |
|------|--------|------|
| resolution | 768P | 分辨率：768P/1080P |
| duration | auto | 每页时长根据内容自动计算 |
| format | mp4 | 输出格式 |

## 工作流程详解

### 1. 内容提取
系统使用 PptxGenJS 提取：
- 幻灯片标题和正文
- 演讲者备注
- 布局信息

### 2. 旁白生成
AI 根据内容生成讲解脚本：
```
输入：产品介绍 - 新功能
输出：接下来为大家介绍我们的新产品功能...
```

### 3. 语音合成
使用 MiniMax TTS API：
- 中文女声：female-qn-qingse
- 中文男声：male-qn-qingse
- 支持多种情绪表达

### 4. 视频生成
- 将每页PPT转换为图片
- 使用 AI 视频生成添加动态效果
- 根据语音时长调整视频长度

### 5. 视频合并
使用 FFmpeg 拼接所有片段：
```bash
ffmpeg -f concat -safe 0 -i filelist.txt -c copy output.mp4
```

## 常见问题

**Q: 支持哪些PPT格式？**
A: 目前仅支持 `.pptx` 格式，旧版 `.ppt` 请先转换。

**Q: 视频生成需要多长时间？**
A: 取决于幻灯片数量，通常每页需要 30-60 秒。

**Q: 如何调整语速？**
A: 在请求中指定 `speed` 参数，范围 0.5-2.0。

**Q: 可以自定义语音吗？**
A: 可以，先使用 `get_voice_list` 查看可用声音。
