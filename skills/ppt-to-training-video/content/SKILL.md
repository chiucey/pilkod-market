# PPT一键生成培训视频

将PowerPoint演示文稿自动转换为带有配音旁白的培训视频。

## 输入要求

- **PPT文件**：支持 `.pptx` 格式
- **可选配置**：
  - 语音风格（男声/女声）
  - 语速（0.5-2.0）
  - 视频分辨率（768P/1080P）
  - 每页停留时间

## 工作流程

### 步骤1：提取PPT内容

使用 `pptx-generator` 技能的提取功能获取所有幻灯片文本和备注：

```
invoke skill: pptx-generator
action: extract_text
file: <用户上传的PPT文件路径>
```

提取每张幻灯片的：
- 标题文本
- 正文内容
- 备注信息（用于生成旁白）

### 步骤2：生成旁白脚本

为每张幻灯片生成讲解旁白：

```
对于每张幻灯片：
- 标题 → 强调开场白
- 正文 → 扩展为讲解语句
- 备注 → 直接使用或优化
```

旁白生成规则：
- 每页停留时间：3-8秒（根据文字量调整）
- 添加过渡语："接下来"、"接下来我们看"
- 专业培训语气

### 步骤3：文本转语音

使用 `batch_text_to_audio` 生成每页的语音旁白：

```
voice: 根据用户选择的语音风格
emotion: "happy"（专业培训风格）
speed: 用户指定的语速（默认1.0）
```

### 步骤4：生成视频片段

使用 `batch_image_to_video` 为每张幻灯片生成视频：

```
reference_type: "first_frame"
duration: 根据语音时长动态调整
resolution: 用户选择（默认768P）
```

### 步骤5：合并视频

使用FFmpeg合并所有片段：

```bash
ffmpeg -f concat -safe 0 -i filelist.txt -c copy output.mp4
```

## 输出

- **视频文件**：`.mp4` 格式
- **分辨率**：768P（默认）或 1080P
- **时长**：根据内容自动计算
- **音频**：内置专业配音

## 错误处理

- **PPT读取失败**：提示用户检查文件格式
- **语音生成失败**：使用备用语音或跳过该页
- **视频生成失败**：生成静态图片版本
- **文件过大**：提示用户压缩或分批处理
