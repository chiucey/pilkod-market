# Content Analysis Framework

## Analysis Dimensions

### 1. Content Type Classification

| Type | Keywords | Characteristics |
|------|----------|-----------------|
| 种草 | 推荐、分享、爱用、回购 | 情感驱动，重体验 |
| 干货 | 知识、技巧、攻略、指南 | 信息驱动，重实用 |
| 测评 | 对比、测评、体验、真实 | 客观分析，重可信 |
| 教程 | 步骤、怎么、如何、教 | 流程驱动，重清晰 |
| 避坑 | 注意、避坑、千万别、警告 | 警示驱动，重提醒 |
| 故事 | 经历、故事、分享、心情 | 叙事驱动，重共鸣 |

### 2. Hook Analysis

**爆款标题要素**：
- 数字量化 ("5个技巧", "90%的人不知道")
- 情绪词 ("绝了", "太好用了", "哭死")
- 悬念 ("竟然", "原来", "终于")
- 身份标签 ("学生党", "打工人", "新手")

**标题公式**：
```
[情绪词] + [数字] + [核心卖点] + [目标人群]
```

### 3. Target Audience

| Audience | Characteristics | Style Preference |
|----------|-----------------|------------------|
| 学生党 | 预算有限、追求性价比 | cute, fresh |
| 打工人 | 时间紧张、效率优先 | notion, minimal |
| 精致妈妈 | 品质要求高、有消费力 | warm, fresh |
| 时尚达人 | 潮流敏感、注重颜值 | pop, bold |
| 知识青年 | 追求深度、理性消费 | notion, minimal |

### 4. Engagement Potential

| Element | High Potential | Low Potential |
|---------|----------------|---------------|
| 收藏价值 | 实用清单、干货知识 | 纯情绪宣泄 |
| 分享价值 | 有趣冷知识、观点鲜明 | 主观感受 |
| 评论价值 | 有争议话题、提问互动 | 封闭结论 |

### 5. Visual Opportunity

| Content Signal | Visual Direction |
|----------------|-----------------|
| 产品展示 | clean product shot |
| 流程操作 | step-by-step flow |
| 前后对比 | comparison layout |
| 情绪表达 | atmospheric/cute |
| 知识科普 | information dense |
| 观点输出 | bold typography |

## Strategy Selection Matrix

| Content Signals | Strategy | Style | Layout |
|-----------------|----------|-------|--------|
| 变美/穿搭/少女 | A | cute | balanced/sparse |
| 健康/自然/有机 | B | fresh | balanced/flow |
| 生活/故事/情感 | A | warm | balanced |
| 避坑/警告/重要 | B | bold | list/comparison |
| 专业/商务/简洁 | B | minimal | sparse/balanced |
| 经典/复古/传统 | A | retro | balanced |
| 趣味/好玩/震撼 | C | pop | sparse/list |
| 知识/概念/效率 | B | notion | dense/list |
| 教程/学习/课堂 | B | chalkboard | balanced/flow |
| 笔记/考试/手写 | B | study-notes | dense/list |
| 影评/海报/观点 | C | screen-print | sparse/comparison |

## Image Count Decision

| Content Depth | Recommended Images | Breakdown |
|---------------|-------------------|-----------|
| 浅尝辄止 | 2-3张 | 封面 + 1内容 + 结尾 |
| 标准深度 | 4-5张 | 封面 + 2-3内容 + 结尾 |
| 深度内容 | 6-8张 | 封面 + 4-6内容 + 结尾 |
| 超级干货 | 9-10张 | 封面 + 7-8内容 + 结尾 |

## Output Format

```markdown
## 内容分析

**主题**: [主题名称]
**类型**: [内容类型]
**核心卖点**: [1-3个要点]
**目标受众**: [受众描述]
**钩子潜力**: [高/中/低 + 原因]

## 推荐方案

**策略**: [A/B/C]
**风格**: [风格名]
**布局**: [布局名]
**预设**: [预设名]
**图片数量**: [N]张

## 内容拆分

P1: [封面] - [布局] - [核心钩子]
P2: [内容] - [布局] - [要点1]
...
PN: [结尾] - [布局] - [CTA]
```
