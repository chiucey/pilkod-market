# Outline Template

## YAML Frontmatter

```yaml
---
strategy: a  # a, b, or c
name: Strategy Name
style: style-name
style_reason: "Why this style fits the content"
elements:
  background: solid-pastel
  decorations: [clouds, stars-sparkles]
  emphasis: star-burst
  typography: highlight
layout: balanced  # primary layout
image_count: 5
---
```

## Page Structure

### Cover Page (P1)

```markdown
## P1 Cover
**Type**: cover
**Hook**: "标题文案，带emoji"
**Visual**: 主视觉描述
**Layout**: sparse
**Key Elements**:
- 主图/产品图
- 标题文字
- 氛围装饰
```

### Content Pages (P2 - PN-1)

```markdown
## P2 [Page Topic]
**Type**: content
**Message**: 要传达的核心信息
**Visual**: 视觉描述
**Layout**: balanced/dense/list/etc
**Key Points**:
- 要点1
- 要点2
- 要点3
```

### Ending Page (PN)

```markdown
## PN Ending
**Type**: ending
**CTA**: 行动号召文案
**Visual**: 结尾视觉
**Layout**: sparse
**Key Elements**:
- 总结金句
- 互动引导
- 品牌/账号提示
```

## Strategy-Specific Templates

### Strategy A: Story-Driven

```yaml
---
strategy: a
name: Story-Driven
style: warm
style_reason: "Warm tones enhance emotional storytelling"
elements:
  background: gradient-warm
  decorations: [soft-glow, cozy-elements]
  emphasis: quote-bubble
  typography: handwritten
layout: balanced
image_count: 5
---

## Outline Structure

P1: Hook → Personal pain point introduction
P2: Problem → Before state, relatable struggle
P3: Discovery → Finding the solution
P4: Experience → Using the product/service
P5: Transformation → After results + CTA
```

### Strategy B: Information-Dense

```yaml
---
strategy: b
name: Information-Dense
style: notion
style_reason: "Line art style excels at presenting structured information"
elements:
  background: white
  decorations: [line-icons, connectors]
  emphasis: highlight-box
  typography: clean
layout: dense
image_count: 6
---

## Outline Structure

P1: Cover → Core conclusion teaser
P2: Overview → Main framework/big picture
P3-P5: Deep Dive → 3-4 key points in detail
P6: Summary → Key takeaways + Recommendation
```

### Strategy C: Visual-First

```yaml
---
strategy: c
name: Visual-First
style: bold
style_reason: "High contrast creates instant visual impact"
elements:
  background: dark-solid
  decorations: [explosion, bold-lines]
  emphasis: big-number
  typography: outline-text
layout: sparse
image_count: 4
---

## Outline Structure

P1: Hero → Single powerful statement/image
P2: Impact → Visual evidence of value
P3: Atmosphere → Lifestyle/mood shot
P4: CTA → Clean call-to-action
```

## Layout-Specific Page Templates

### Sparse (封面/结尾)

```
[大量留白]
[主视觉居中]
[简短标题]
[角落装饰]
```

### Balanced (内容)

```
[顶部标题]
[左图] [右图]
[底部总结/装饰]
```

### Dense (干货)

```
[标题栏]
[P1][P2][P3][P4]
[P5][P6][P7][P8]
```

### List (排行)

```
[标题]
[1. 条目内容...]
[2. 条目内容...]
[3. 条目内容...]
[4. 条目内容...]
```

### Flow (流程)

```
[Step 1] → [Step 2]
    ↓         ↓
[Step 3] → [Step 4]
```

### Comparison (对比)

```
[左侧] | [右侧]
[内容] | [内容]
   VS
```

### Mindmap (导图)

```
      [支线1]
         |
[支线4]--[中心]--[支线2]
         |
      [支线3]
```

### Quadrant (四象限)

```
[象限1] | [象限2]
--------|--------
[象限3] | [象限4]
```
