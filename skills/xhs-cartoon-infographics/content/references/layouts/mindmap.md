# Layout: Mindmap (中心思维导图)

中心放射式，适合概念展开、知识脉络。

## Characteristics

| Aspect | Description |
|--------|-------------|
| Information Density | 高 |
| Visual Space | 放射分布 |
| Element Size | 中心大、支线小 |
| Text Amount | 精简关键词 |

## Structure

```
           [分支1]
              │
    [分支4]──[中心]──[分支2]
              │
           [分支3]
              │
         [子分支]
```

## Best For

- 概念解释
- 知识脉络
- 主题发散
- 思维整理
