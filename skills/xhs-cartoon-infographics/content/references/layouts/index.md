# Layout Index

## 8 Layout Modes

| Layout | Density | Best For | Key Features |
|--------|---------|----------|--------------|
| sparse | 极低 | 封面、金句 | 70-80%留白，单一焦点 |
| balanced | 中等 | 内容详情 | 3-4均匀分区 |
| dense | 高 | 知识卡片 | 5-8密集卡片 |
| list | 中高 | 排行清单 | 纵向编号条目 |
| comparison | 中等 | 对比分析 | 左右/上下镜像 |
| flow | 中等 | 教程流程 | 时间线/步骤链 |
| mindmap | 高 | 思维导图 | 中心放射结构 |
| quadrant | 中高 | 分类矩阵 | 2x2四象限 |

## Layout Selection Guide

**封面/开场** → sparse
**内容详情** → balanced
**干货知识** → dense
**Top N排行** → list
**优缺点对比** → comparison
**步骤教程** → flow
**概念发散** → mindmap
**分类整理** → quadrant
