# Layout: Flow (流程时间线)

步骤流程、时间线、发展历程。

## Characteristics

| Aspect | Description |
|--------|-------------|
| Information Density | 中等 |
| Visual Space | 线性分布 |
| Element Size | 步骤卡片 |
| Text Amount | 每步简短 |

## Structure

```
┌─────────────────────────┐
│         标题            │
├─────────────────────────┤
│                         │
│  [Step 1] ──→ [Step 2]  │
│      │           │     │
│      ↓           ↓     │
│  [Step 3] ──→ [Step 4]  │
│      │                 │
│      ↓                 │
│     ...                 │
│                         │
└─────────────────────────┘
```

## Best For

- 教程步骤
- 操作流程
- 时间线
- 发展历程

## Style Compatibility

| Style | Recommended | Notes |
|-------|-------------|-------|
| cute | ✓ | 可爱箭头 |
| fresh | ✓✓ | 自然流程 |
| warm | ✓ | 温馨步骤 |
| bold | ✓ | 动态箭头 |
| minimal | ✓ | 简洁连接 |
| retro | ✓ | 复古步骤 |
| pop | ✓✓ | 活力动效 |
| notion | ✓✓ | 线稿流程 |
| chalkboard | ✓✓ | 粉笔步骤 |
| study-notes | ✓ | 笔记流程 |
| screen-print | ✗ | 不适合 |
