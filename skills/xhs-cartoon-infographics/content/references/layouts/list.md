# Layout: List (清单枚举)

排行榜、清单、步骤列表格式。

## Characteristics

| Aspect | Description |
|--------|-------------|
| Information Density | 中高 (4-7项) |
| Visual Space | 纵向排列 |
| Element Size | 均匀条状 |
| Text Amount | 简短条目 |

## Structure

```
┌─────────────────────────┐
│         标题            │
├─────────────────────────┤
│  1️⃣  第一条内容...       │
├─────────────────────────┤
│  2️⃣  第二条内容...       │
├─────────────────────────┤
│  3️⃣  第三条内容...       │
├─────────────────────────┤
│  4️⃣  第四条内容...       │
├─────────────────────────┤
│        ...更多...        │
└─────────────────────────┘
```

## Best For

- Top N 排行
- 必备清单
- 操作步骤
- 注意事项
