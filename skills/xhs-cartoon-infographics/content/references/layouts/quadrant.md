# Layout: Quadrant (四象限)

四个分区，适合分类、矩阵分析。

## Characteristics

| Aspect | Description |
|--------|-------------|
| Information Density | 中高 |
| Visual Space | 2x2网格 |
| Element Size | 均匀分区 |
| Text Amount | 每区简短 |

## Structure

```
┌───────────┬───────────┐
│           │           │
│   第一象限  │  第二象限   │
│   (重要)   │  (紧急)    │
│           │           │
├───────────┼───────────┤
│           │           │
│   第三象限  │  第四象限   │
│   (一般)   │  (待定)    │
│           │           │
└───────────┴───────────┘
```

## Best For

- SWOT分析
- 分类整理
- 矩阵决策
- 四宫格内容
