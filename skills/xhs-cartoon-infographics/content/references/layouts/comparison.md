# Layout: Comparison (对比布局)

左右/上下对比，适合正反对比、产品对比。

## Characteristics

| Aspect | Description |
|--------|-------------|
| Information Density | 中等 |
| Visual Space | 对称分布 |
| Element Size | 镜像结构 |
| Text Amount | 对应说明 |

## Structure

```
┌───────────┬───────────┐
│           │           │
│  左侧内容  │  右侧内容  │
│  Left     │  Right    │
│           │           │
│  [优点]   │  [缺点]    │
│           │           │
│    VS     │           │
│           │           │
└───────────┴───────────┘
```

## Best For

- Before/After
- 产品对比
- 优缺点分析
- 方案对比

| Style | Recommended | Notes |
|-------|-------------|-------|
| cute | ✓ | 可爱对比框 |
| fresh | ✓ | 清新对比 |

| bold | ✓✓ | 强烈VS效果 |
| minimal | ✓ | 简洁分栏 |
| retro | ✓ | 复古对比 |
| pop | ✓✓ | 活力对比 |
| notion | ✓✓ | 线稿对比 |
