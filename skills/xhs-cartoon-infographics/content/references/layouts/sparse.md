# Layout: Sparse (稀疏留白)

最小信息、最大视觉冲击。适合封面和强观点内容。

## Characteristics

| Aspect | Description |
|--------|-------------|
| Information Density | 极低 (1-2个要点) |
| Visual Space | 70-80% 留白 |
| Element Size | 大尺寸主视觉 |
| Text Amount | 少量关键词 |

## Structure

```
┌─────────────────────────┐
│                         │
│      [主视觉/图片]       │
│                         │
│      简短标题文字        │
│                         │
│    [装饰元素/品牌]       │
│                         │
└─────────────────────────┘
```

## Best For

- 封面图 (Hook)
- 强观点输出
- 情绪氛围营造
- 金句/总结

## Style Compatibility

| Style | Recommended | Notes |
|-------|-------------|-------|
| cute | ✓✓ | 配合大量装饰 |
| fresh | ✓✓ | 简洁自然 |
| warm | ✓✓ | 温馨氛围 |
| bold | ✓✓ | 强对比冲击 |
| minimal | ✓✓ | 极简美学 |
| retro | ✓✓ | 复古留白 |
| pop | ✓✓ | 活力释放 |
| notion | ✓✓ | 极简线稿 |
| chalkboard | ✓ | 需适当装饰 |
| study-notes | ✗ | 不适合 |
| screen-print | ✓✓ | 海报张力 |

