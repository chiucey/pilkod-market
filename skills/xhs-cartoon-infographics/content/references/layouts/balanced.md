# Layout: Balanced (平衡布局)

标准内容布局，3-4个要点均匀分布。

## Characteristics

| Aspect | Description |
|--------|-------------|
| Information Density | 中等 (3-4个要点) |
| Visual Space | 50-60% 留白 |
| Element Size | 均匀分布 |
| Text Amount | 适量说明文字 |

## Structure

```
┌─────────────────────────┐
│         标题            │
├──────────┬──────────────┤
│          │              │
│  [图1]   │   [图2]      │
│          │              │
├──────────┴──────────────┤
│         [图3/总结]      │
└─────────────────────────┘
```

## Best For

- 内容详情页
- 体验分享
- 产品介绍
- 教程讲解
