# Style: Minimal (极简高级)

简洁、优雅、高级的设计风格。

## Visual Elements

| Element | Description |
|---------|-------------|
| Colors | 纯白(#FFFFFF)、浅灰(#F5F5F5)、炭灰(#333333)、金色(#D4AF37) |
| Lines | 极细线条，1-2px |
| Shapes | 基础几何、无装饰 |
| Decorations | 极少点缀、呼吸空间 |

## Typography

- 高级无衬线字体
- 大小写混合
- 大量留白

## Decoration Patterns

- 极简线条装饰
- 微妙渐变
- 精确间距
- 单一强调色

## Best Layouts

- sparse (封面)
- balanced (内容)
- dense (信息卡)
- mindmap (思维导图)
