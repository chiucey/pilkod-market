# Style: Retro (复古怀旧)

复古、经典、怀旧感的设计。

## Visual Elements

| Element | Description |
|---------|-------------|
| Colors | 焦糖色(#D2691E)、墨绿(#2F4F4F)、奶油(#FFFDD0)、砖红(#CB4154) |
| Lines | 复古线条，3-4px |
| Shapes | 老式图案、波浪边框 |
| Decorations | 旧报纸纹理、老式花纹 |

## Typography

- 复古衬线字体
- 打字机效果
- 怀旧标签

## Decoration Patterns

- 旧纸张纹理
- 复古边框花纹
- 褪色效果
- 老式标签贴

## Best Layouts

- sparse (封面)
- balanced (内容)
- list (排行)
- comparison (对比)
