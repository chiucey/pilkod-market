# Style: Notion (手绘知性)

极简手绘线条、知识感强的设计。

## Visual Elements

| Element | Description |
|---------|-------------|
| Colors | 纯白背景、黑色线条(#333333)、灰色(#999999)、单色强调(#4A90E2) |
| Lines | 手绘细线，1-2px |
| Shapes | 简约图标、手绘箭头 |
| Decorations | 简洁标注、线条装饰 |

## Typography

- 简洁无衬线
- 统一字号层级
- 手写风格注释

## Decoration Patterns

- 细线边框
- 手绘图标
- 虚线连接
- 简洁标注框

## Best Layouts

- dense (知识卡)
- list (清单)
- comparison (对比)
- mindmap (思维导图)
- quadrant (四象限)
- flow (流程)
