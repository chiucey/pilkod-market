# Style: Fresh (清新自然)

干净、清爽、自然感的设计风格。

## Visual Elements

| Element | Description |
|---------|-------------|
| Colors | 薄荷绿(#98FB98)、天蓝(#87CEEB)、白色(#FFFFFF)、浅黄(#FFFACD) |
| Lines | 流畅自然，粗细2-3px |
| Shapes | 叶片、波浪、石头、自然曲线 |
| Decorations | 绿叶、植物、阳光、水滴 |

## Typography

- 简洁无衬线
- 浅灰/深绿色文字
- 轻量装饰线条

## Decoration Patterns

- 角落绿植装饰
- 透明气泡效果
- 自然纹理背景
- 阳光光晕

## Best Layouts

- sparse (封面)
- balanced (内容)
- flow (流程)
- comparison (对比)
