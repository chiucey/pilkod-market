# Style Index

## 11 Visual Styles

| Style | Key Features | Best For |
|-------|--------------|----------|
| cute | 粉色系、圆润、可爱装饰 | 少女种草、甜美分享 |
| fresh | 绿蓝配色、自然元素 | 健康产品、清新生活 |
| warm | 暖橙棕色、温馨氛围 | 生活故事、情感分享 |
| bold | 高对比、粗线条、爆炸效果 | 避坑指南、强烈观点 |
| minimal | 极简留白、细线、优雅 | 专业总结、金句封面 |
| retro | 焦糖墨绿、复古纹理 | 怀旧分享、经典盘点 |
| pop | 明亮彩虹、动态元素 | 趣味内容、潮流分享 |
| notion | 黑白线稿、知性手绘 | 干货知识、清单教程 |
| chalkboard | 黑板粉笔、教育风格 | 学习笔记、课堂讲解 |
| study-notes | 真实手写、蓝红标注 | 考试重点、学习攻略 |
| screen-print | 丝网印刷、有限色彩 | 影评书评、海报封面 |
