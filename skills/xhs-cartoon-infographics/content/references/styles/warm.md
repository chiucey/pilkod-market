# Style: Warm (温馨友好)

温馨、亲切、有人情味的设计。

## Visual Elements

| Element | Description |
|---------|-------------|
| Colors | 暖橙(#FFA500)、杏色(#FFDAB9)、奶油白(#FFF8DC)、棕色(#D2691E) |
| Lines | 柔和手绘感，粗细3-4px |
| Shapes | 圆角矩形、面包房元素、咖啡杯 |
| Decorations | 针织纹理、毛线、烘焙、阳光 |

## Typography

- 圆润温暖字体
- 暖色系文字
- 柔和阴影

## Decoration Patterns

- 针织/毛线纹理
- 咖啡杯/茶杯装饰
- 阳光洒落效果
- 棉柔云朵

## Best Layouts

- sparse (封面)
- balanced (内容)
- comparison (对比)
- flow (故事)
