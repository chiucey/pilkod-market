# Style: Cute (甜美可爱)

少女风、可爱、温馨的小红书经典风格。

## Visual Elements

| Element | Description |
|---------|-------------|
| Colors | 粉色系(#FFB6C1, #FFC0CB, #FF69B4)、浅紫(#E6E6FA)、薄荷绿(#98FB98) |
| Lines | 圆润柔和的线条，粗细2-4px |
| Shapes | 圆形、心形、星形、泡泡 |
| Decorations | 云朵、星星、蝴蝶结、爱心、浆果 |

## Typography

- 花体/圆润字体
- 手写风格数字
- 粉色/金色强调文字

## Decoration Patterns

- 角落装饰小花/蝴蝶结
- 文字气泡框
- 散落星星/爱心
- 渐变光晕效果

## Best Layouts

- sparse (封面)
- balanced (内容)
- list (清单)
- quadrant (分类)
