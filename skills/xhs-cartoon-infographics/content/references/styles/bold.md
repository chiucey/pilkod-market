# Style: Bold (强视觉冲击)

高对比度、醒目的视觉风格。

## Visual Elements

| Element | Description |
|---------|-------------|
| Colors | 纯黑(#000000)、亮红(#FF0000)、电光蓝(#00BFFF)、荧光绿(#39FF14) |
| Lines | 粗黑线条，4-6px |
| Shapes | 几何图形、箭头、惊叹号 |
| Decorations | 放射线、爆炸效果、强调符号 |

## Typography

- 黑体/无衬线粗体
- 高对比色文字
- 描边文字效果

## Decoration Patterns

- 爆炸/光芒效果
- 粗体边框
- 警示/惊叹元素
- 动态斜线

## Best Layouts

- sparse (封面)
- list (清单)
- comparison (对比)
- quadrant (四象限)
