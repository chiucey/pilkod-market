# Style: Study Notes (手写笔记)

真实感手写笔记风格，蓝笔+红标注+黄色高亮。

## Visual Elements

| Element | Description |
|---------|-------------|
| Colors | 白色纸张、蓝色笔迹(#0000FF)、红色标注(#FF0000)、黄色高亮(#FFFF00) |
| Lines | 真实手写字迹 |
| Shapes | 手绘下划线、圈注 |
| Decorations | 便利贴、图钉、胶带 |

## Typography

- 真实手写字迹
- 蓝色正文
- 红色强调/批注
- 黄色高亮底色

## Decoration Patterns

- 纸张边缘
- 胶带/图钉装饰
- 折角效果
- 铅笔线条

## Best Layouts

- dense (学习笔记)
- list (清单)
- mindmap (思维导图)
- balanced (内容)
