# Style: Pop (活力潮流)

充满活力、年轻、潮流的设计。

## Visual Elements

| Element | Description |
|---------|-------------|
| Colors | 明黄(#FFFF00)、橙红(#FF4500)、电紫(#8A2BE2)、青绿(#00CED1) |
| Lines | 流畅动感，3-5px |
| Shapes | 卡通人物、表情包、动态元素 |
| Decorations | 闪电、音浪、emoji元素 |

## Typography

- 圆润几何字体
- 彩虹渐变文字
- 动态效果

## Decoration Patterns

- 速度线效果
- 卡通表情
- 撞色搭配
- 几何拼贴

## Best Layouts

- sparse (封面)
- balanced (内容)
- list (清单)
- comparison (对比)
