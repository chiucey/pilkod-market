# Style: Screen Print (丝网印刷)

粗犷海报风、有限色彩、强烈对比。

## Visual Elements

| Element | Description |
|---------|-------------|
| Colors | 有限配色方案(2-4色)、纯色平涂、粗颗粒纹理 |
| Lines | 粗黑轮廓，边缘硬朗 |
| Shapes | 简化几何、象征性图形 |
| Decorations | 半调网点、叠印效果 |

## Typography

- 粗体无衬线
- 描边文字
- 有限字体

## Decoration Patterns

- 半调渐变
- 错位叠印
- 粗颗粒纹理
- 硬边阴影

## Best Layouts

- sparse (海报封面)
- balanced (内容)
- comparison (对比)
- quadrant (四象限)
