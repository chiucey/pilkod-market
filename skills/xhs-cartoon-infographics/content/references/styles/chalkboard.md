# Style: Chalkboard (黑板粉笔)

彩色粉笔在黑板上的教育风格。

## Visual Elements

| Element | Description |
|---------|-------------|
| Colors | 黑板绿/黑(#2F4F2F, #1a1a1a)、白粉笔(#FFFFFF)、彩色粉笔(黄/粉/蓝) |
| Lines | 粉笔质感，边缘不规则 |
| Shapes | 手绘图形、粉笔纹理 |
| Decorations | 粉笔星号、下划线、方框 |

## Typography

- 手写粉笔字
- 不均匀边缘
- 活泼排版

## Decoration Patterns

- 粉笔涂抹效果
- 手绘边框
- 星星/箭头强调
- 粉笔灰纹理

## Best Layouts

- balanced (内容)
- dense (知识卡)
- flow (教程流程)
- mindmap (思维导图)
