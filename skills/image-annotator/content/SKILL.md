# 图片注释 — 工程图纸附图标注技能

## 功能概述

将工程示意图中的附图标记（数字编号），与对应的部件名称自动匹配，并将名称标注到图片对应位置，输出带标注的结果图。

**不改变原始图纸图案，只叠加文字标注层。**

---

## 两种输入情况

### 情况 1：图片 + PDF 文件
用户同时提供工程图片和 PDF 专利文档，从 PDF 中读取附图标记说明。

### 情况 2：图片 + 文字内容
用户提供工程图片和技术文字（权利要求书/说明书），从文字中匹配附图标记。

---

## 工作流程

### 情况 1（图片 + PDF）

**Step 1｜分析图片，提取附图标记**
使用 `images_understand` 分析图片：

```
提示词模板：
这是一张工程示意图。请详细列出图中所有数字附图标记（如100、40、10等），
每个标记的位置（左/右/上/下/中间区域），以及标记指向的部位。
```

**Step 2｜从 PDF 提取附图标记说明**
使用 `images_understand` 读取 PDF 内容：

```
提示词模板：
请提取这份专利文档中所有"附图标记说明"的内容，
列出所有"数字-部件名称"的对应关系。
```

**Step 3｜生成对应表并标注**
将图片标记与 PDF 内容交叉匹配，生成对应表，叠加到图片。

---

### 情况 2（图片 + 文字）

**Step 1｜分析图片，提取附图标记**
同情况 1 Step 1。

**Step 2｜从文字内容生成对应表**
使用正则表达式从用户提供的文字中自动提取：

```
匹配模式：
- "部件名称[编号]" → 部件名称:编号
- "编号：部件名称" → 编号:部件名称
- "部件名称（编号）" → 部件名称:编号
```

示例（从离心管权利要求书提取）：
```
离心管[100] → 100:离心管
管盖[40]   → 40:管盖
上管体[10] → 10:上管体
过滤膜[30] → 30:过滤膜
凸出部[11] → 11:凸出部
下管体[20] → 20:下管体
```

**Step 3｜合成标注图**
将"部件名称+编号"标注到图片对应位置。

---

## 标注样式规范

| 属性 | 规范值 |
|---|---|
| **标注位置** | 数字标记的**右上方**（默认），空间不足时自动调整 |
| **文字内容** | `编号+部件名称`（如"10上管体"） |
| **字体颜色** | `#1E3A8A`（深蓝色） |
| **背景** | 无背景框，无边框，纯文字叠加 |
| **字体** | 使用系统中文字体（如有），或 AI 生成方式 |

---

## 技术要点

### 图片分析注意事项
- 工程图纸数字为空心轮廓或实心，需明确告知 AI 检测**所有数字标记**
- 记录每条引导线末端坐标（引导线末梢 = 标注文字位置）
- 图片中**只有用户提供的附图标记**，不得添加任何原图中不存在的标记

### 标注位置精确定位
- **首选**：数字标记右侧，上方对齐
- **备选**：数字标记左侧 / 上方（当右侧空间不足时）
- **不覆盖原则**：标注文字不得遮挡原图中的任何结构线条

### 文字提取注意事项
- 优先匹配方括号格式 `[编号]`
- 其次匹配括号格式 `（编号）`
- 同一编号出现多次时，取第一次出现的内容
- 编号对应部件在图片中不存在时，**跳过该编号，不标注**

---

## 输出

- 标注结果图保存至：`/workspace/output/annotated_[原始文件名].jpg`
- 如有部分编号无法在图片中找到对应标记，需在结果中说明**哪些编号未能标注**
- 使用 `upload_to_cdn` 将结果上传并分享链接给用户

## 依赖工具

- `images_understand`（MCP 内置）— 图片 OCR 与标记检测
- `image_synthesize`（MCP 内置）— AI 生成式标注（字体缺失时的备选方案）
- `upload_to_cdn`（MCP 内置）— 上传结果图

---

## 脚本文件

- `scripts/annotate.py` — 主脚本：协调整个标注流程
- `scripts/detect_markers.py` — 使用 `images_understand` 检测图片标记
- `scripts/extract_from_text.py` — 从文字内容提取附图标记对应关系
- `scripts/extract_from_pdf.py` — 从 PDF 提取附图标记说明
- `scripts/overlay_labels.py` — 将标注文字叠加到图片
