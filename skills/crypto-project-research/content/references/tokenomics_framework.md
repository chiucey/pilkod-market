# Tokenomics Analysis Framework

## Supply Analysis

### Total Supply Metrics
- **Max Supply**: Hard cap, inflationary, or uncapped
- **Circulating Supply**: Current tradable amount
- **Locked/Timed Supply**: Vesting schedules, team allocation

### Emission Schedule
```
Token Release Timeline:
- TGE (Token Generation Event): Initial supply
- Cliff: No vesting before cliff period
- Vesting: Linear or step-wise release
- Fully Diluted: All tokens in circulation
```

### Inflation Model
- **Deflationary**: Burn mechanisms, buyback
- **Inflationary**: Staking rewards, emission schedule
- **Neutral**: Balanced supply dynamics

## Utility Analysis

### Value Capture Mechanisms
1. **Transaction Fees**: Native currency for gas/fees
2. **Staking Rewards**: Yield for network security
3. **Governance**: Voting rights
4. **Discounts**: Protocol fee discounts
5. **Access**: Gated functionality

### Demand Drivers
- Protocol revenue generation
- Network effect growth
- Adoption metrics
- Utility expansion

## Distribution Analysis

### Allocation Model
```json
{
  "public_sale": 0.10,
  "team": 0.15,
  "investors": 0.20,
  "treasury": 0.15,
  "community_rewards": 0.25,
  "ecosystem_fund": 0.15
}
```

### Concentration Risks
- Top 10 holder percentage
- Team/Investor unlock timeline
- Whale activity patterns

## Valuation Metrics

### Traditional Crypto
- MCap/TVL Ratio
- MCap/Revenue Ratio
- Network Value to Transactions (NVT)

### DeFi-Specific
- P/F (Price/Fees)
- P/U (Price/Users)
- TVL Market Share

## Red Flags
- Unlimited supply inflation
- Team/investor dump potential
- No clear utility
- Unrealistic token burns
- Misaligned incentives
