# 文件分类标签技能 (file-classify-tag)

## 技能目标

读取用户指定的云盘文档（Word/PDF/Excel/TXT/PPT），分析文件名和文件内容，自动判断该文件在国资资料库中的分类（A~F 类及二级分类），并生成多维度标签（单位、年份、版本、内容关键词）。

## 输入

- 一个或多个文件路径（支持 UNC 网络路径如 `\\192.168.1.100\共享\待归档\xxx.docx` 或映射盘符 `Z:\xxx.docx`）
- 或一个文件夹路径（递归读取其中所有支持格式的文件）

## 输出格式

每个文件输出以下 JSON 结构：

```json
{
  "file_path": "文件完整路径",
  "filename": "文件名",
  "category1": "C",
  "category2": "C01",
  "category1_name": "战略规划与改革重组库",
  "category2_name": "五年规划",
  "company": "机场集团",
  "year": "2026",
  "version": "正式稿",
  "subject": "十五五发展规划纲要",
  "tags": ["#战略改革", "#五年规划", "#机场集团", "#2026", "#正式稿", "#枢纽建设"],
  "source": "api",  // api 或 fallback
  "warning": ""    // 如"仅文件名分类"
}
```

## 分类体系

详细分类体系见 `references/classification-tree.md`。

**一级分类：**
- **A 类** - 企业基础信息库（组织架构、基础画像）
- **B 类** - 财务与经营动态库（财务决算、经营分析、预算投资、考核分配）
- **C 类** - 战略规划与改革重组库（五年规划、专项改革、重组压减、科技创新）
- **D 类** - 项目与投资监管库（固定资产/股权项目、基金业务）
- **E 类** - 内控合规与监督库（法治合规、社会责任与ESG）
- **F 类** - 国资监管政策法规库（国务院国资委规章、省国资委规范性文件、废止失效库）

## 执行流程

### 步骤 1：接收路径

接收用户指定的文件路径或文件夹路径，支持 Windows 路径格式（注意 UNC 路径使用原始字符串）。

### 步骤 2：文件遍历

遍历所有支持格式的文件：
- `.docx` - Word 文档
- `.pdf` - PDF 文档
- `.xlsx` / `.xls` - Excel 电子表格
- `.txt` - 纯文本（尝试 UTF-8 和 GBK 编码）
- `.pptx` - PowerPoint 演示文稿

### 步骤 3：内容提取

对每个文件提取文本内容（前 2000 字）：

| 格式 | 库/方法 |
|------|---------|
| `.docx` | python-docx |
| `.pdf` | pdfplumber |
| `.xlsx` | openpyxl |
| `.xls` | xlrd |
| `.txt` | 内置 open()，UTF-8/GBK |
| `.pptx` | python-pptx |

**降级处理**：若内容提取失败（如扫描件 PDF），仅依赖文件名分析，标记 `warning: "仅文件名分类"`。

### 步骤 4：API 分析

构造 Prompt，调用 MiniMax API 进行分类分析：

**Prompt 模板：**
```
你是一个国资系统文档分类专家。请根据以下文件内容和文件名，判断该文件应归档到哪个分类，并提取相关元数据。

【分类体系】
（从 references/classification-tree.md 加载完整分类体系）

【文件信息】
文件名：{filename}
文件内容摘要（前 2000 字）：
{content}

【输出要求】
请严格返回以下 JSON 格式，不要添加任何额外说明或代码块标记：
{
"category1": "C",
"category2": "C01",
"category1_name": "战略规划与改革重组库",
"category2_name": "五年规划",
"company": "机场集团",
"year": "2026",
"version": "正式稿",
"subject": "十五五发展规划纲要",
"keywords": ["枢纽建设", "航班正常率", "绿色机场"]
}

【字段说明】
- category1: A/B/C/D/E/F 一级分类代码
- category2: 二级分类代码（如 C01）
- category1_name: 一级分类全称
- category2_name: 二级分类全称
- company: 单位简称，若无法识别则留空字符串
- year: 四位年份，若无法确定则用当前年份
- version: 初稿/征求意见稿/正式稿/报批稿，若无法判断则留空字符串
- subject: 文件核心主题，15 字以内
- keywords: 1-5 个核心关键词，不加 # 号
```

### 步骤 5：标签生成

根据返回结果生成标签列表：

1. **分类标签**：`#` + 一级分类简称（如 `#战略改革`）
2. **二级分类标签**：`#` + 二级分类名称（如 `#五年规划`）
3. **单位标签**：识别到的单位简称（如 `#机场集团`）
4. **年份标签**：`#` + 年份（如 `#2026`）
5. **版本标签**：识别到的版本（如 `#正式稿`）
6. **内容关键词标签**：`#` + 每个关键词

### 步骤 6：降级处理

若 API 调用失败（网络问题、配额不足、返回无效 JSON），使用本地规则降级：

| 关键词 | 分类 |
|--------|------|
| 组织架构、企业简介、信用评级、所属企业名录 | A 类 |
| 财务快报、决算审计、经营分析、预算报告、考核分配、股权激励 | B 类 |
| 五年规划、十四五、十五五、改革方案、重组整合、数字化转型 | C 类 |
| 可研报告、后评价报告、基金项目、投资计划 | D 类 |
| 合规管理、法律纠纷、ESG、社会责任、帮扶报告 | E 类 |
| 国资委规章、管理办法、通知、意见、废止失效 | F 类 |

降级模式下：`company`、`version`、`keywords` 均留空，`subject` 取文件名（去除扩展名和数字编号）。

## 标签生成规则速查

| 标签类型 | 来源 | 示例 |
|----------|------|------|
| 一级分类 | 自动生成 | `#战略改革` |
| 二级分类 | 自动生成 | `#五年规划` |
| 单位 | 文件名/内容识别 | `#机场集团` |
| 年份 | 文件名/内容提取 | `#2026` |
| 版本 | 文件名/内容识别 | `#正式稿` |
| 内容关键词 | 内容提取 3-5 个 | `#枢纽建设` |

## 注意事项

1. **网络路径处理**：Windows 路径反斜杠需转义或使用原始字符串 `r"..."`
2. **编码处理**：`txt` 文件优先 UTF-8，失败则尝试 GBK
3. **扫描件处理**：无法提取内容时，仅用文件名分析并标注
4. **输出结构**：生成标准化 JSON，便于后续技能（如重命名归档）使用
