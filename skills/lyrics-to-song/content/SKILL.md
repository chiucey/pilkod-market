# 歌词转歌曲技能

## 技能简介

将用户提供的歌词转化为完整的歌曲制作方案，包括旋律建议、和弦进行、节奏型编排和编曲风格指导。

**使用场景**：用户有现成歌词，需要专业级歌曲制作建议

## 工作流程

### 第一步：歌词分析

1. **读取用户歌词**
   - 识别歌词段落结构（主歌、副歌、桥段）
   - 统计字数和行数
   - 分析情绪走向

2. **情感识别**
   - 提取歌词核心情绪（悲伤、欢快、深情、激昂等）
   - 识别主题关键词
   - 判断歌词意境

### 第二步：风格匹配

根据歌词内容和用户指定的风格（默认自动匹配），推荐最佳风格：

| 风格 | 适用场景 | 节奏特点 | 推荐BPM |
|------|---------|---------|--------|
| 流行 Pop | 抒情、爱情、日常 | 稳定、律动 | 90-120 |
| 说唱 Rap | 叙事、态度、urban | 切分节奏、808鼓点 | 70-140 |
| 民谣 Folk | 诗意、怀旧、叙事 | 原声、简洁 | 60-100 |
| 摇滚 Rock | 激情、叛逆、力量 | 强劲鼓点、失真吉他 | 110-160 |

### 第三步：歌曲结构设计

自动规划歌曲结构：

```
标准结构示例：
├── 前奏 (4-8小节)
├── 主歌1 (8小节)
├── 副歌1 (8小节)
├── 主歌2 (8小节)
├── 副歌2 (8小节)
├── 桥段 Bridge (4-8小节)
├── 副歌3 (8小节)
└── 尾奏 (4-8小节)
```

根据歌词内容推荐最适合的结构变体。

### 第四步：核心音乐元素生成

#### 4.1 调式与音高建议

```
根据歌词情绪和字数推荐：
- 大调/小调选择
- 起始音和终止音
- 音域范围
- 关键段落音高走势
```

#### 4.2 和弦进行建议

为每个段落推荐和弦：
- 流行：I-V-vi-IV, I-vi-IV-V, vi-IV-I-V
- 说唱：I-vi-II-V, 805和弦, 极简和弦
- 民谣：I-IV-V, I-V-vi-IV, 开放式和弦进行
- 摇滚：I-bVII-IV, I-V-IV-V, 动力和弦

#### 4.3 节奏型编排

- 推荐BPM范围
- 鼓点节奏型
- 副歌与主歌节奏差异
- 桥段节奏变化点

### 第五步：编曲风格指导

根据风格和情绪提供：
- 推荐乐器配置
- 前奏/尾奏设计思路
- 段落间的编曲过渡
- 动态编排建议（渐强/渐弱）

## 使用示例

### 示例 1：中文歌词转流行歌曲

**用户输入**：
```
我想要一首关于思念的流行歌曲
歌词：
月光洒在窗台上
思念像潮水一样
远方的你还好吗
等待是最长情的告白
```

**技能输出**：
- 风格：流行抒情
- 调式：C大调
- BPM：85
- 和弦：Am-F-C-G 经典进行
- 结构：标准ABABCB

### 示例 2：说唱节奏适配

**用户输入**：
```
一段需要配上说唱的歌词
```

**技能输出**：
- 风格：Trap Rap / Old School（根据歌词内容选择）
- BPM：90-120
- 和弦：极简重复和弦
- 节奏：切分音型、重拍前置

## 注意事项

1. **字数适配**：如果歌词字数与建议结构不匹配，提供调整方案
2. **韵律优化**：建议押韵位置和换气点
3. **动态平衡**：确保各段落有明显的情绪起伏
4. **专业术语**：使用标准音乐术语，便于制作人理解

## 错误处理

- 如果歌词格式异常，自动尝试解析
- 如果字数过少，提示需要补充
- 如果字数过多，建议分段处理
- 如果风格冲突，给出替代建议
