# 和弦进行大全

## 流行音乐常用和弦进行

### C大调/ A小调和弦

| 级数 | 大调和弦 | 小调和弦 | 功能 |
|------|---------|---------|------|
| I | C | Am | 主和弦 |
| ii | Dm | Bdim | 上主和弦 |
| iii | Em | C | 副主和弦 |
| IV | F | Dm | 下属和弦 |
| V | G | Em | 属和弦 |
| vi | Am | F | 副属和弦 |
| vii° | Bdim | G | 导和弦 |

### 经典和弦进行

#### 1. I-V-vi-IV（流行金曲进行）
```
C - G - Am - F
G - D - Em - C
```
**适用**：流行、抒情、告白歌曲
**代表作品**：Let It Be, No Woman No Cry, With or Without You

#### 2. I-vi-IV-V（do-wop进行）
```
C - Am - F - G
```
**适用**：复古流行、怀旧歌曲
**代表作品**：Stand By Me, Unchained Melody

#### 3. I-IV-V-I（布鲁斯/摇滚进行）
```
C - F - G - C
```
**适用**：摇滚、民谣、布鲁斯
**代表作品**：乐享早期摇滚

#### 4. vi-IV-I-V（阴郁深情进行）
```
Am - F - C - G
```
**适用**：深情、忧郁、反思类歌曲
**代表作品**：Someone Like You, Zombie

808风格：

Trap和弦：

### 经典说唱和弦
- 805和弦：Em - Am - D - G
- 808bass：只用根音+五度音
- 空灵和弦：小调和弦+延音

**适用**：Trap, Lo-fi, Boom Bap

## 摇滚和弦进行

### 硬摇滚进行
```
动力和弦（Power Chord）：
| C5 | F5 | G5 | C5 |
| A5 | D5 | E5 | A5 |
```

### 经典摇滚进行
```
I-bVII-IV（大调色彩）
| C | Bb | F | C |

I-V-IV-V（强劲节奏）
| C | G | F | C |

i-bVII-bVI-IV（自然小调）
| Am | G | F | C |
```

### 现代摇滚
```
I-iii-IV-V（带小调色彩）
| C | Em | F | G |

I-IV-vi-V（混合进行）
| C | F | Am | G |
```

## 和弦转位与节奏型

### 开放和弦（适合民谣）
```
C：x32010
Am：x02210
F：133211
G：320003
```

### 节奏型建议

| 风格 | 节奏型 | 特点 |
|------|--------|------|
| 流行抒情 | 下上下上 下上下上 | 稳定、均匀 |
| 说唱 | 下 下下下 下下下下 | 重拍前置、切分 |
| 民谣 | 下上下 下上下 | 原声吉他感 |
| 摇滚 | 下下下 下下下下 | 强劲、有力 |

## 色彩和弦

### 七和弦
```
maj7：大七和弦，温暖、爵士
| Cmaj7 | Em7 | Fmaj7 | G7 |

m7：小七和弦，柔和、深情
| Am7 | Dm7 | Em7 | G7 |

7：属七和弦，张力、期待
| G7 | Cmaj7 | Dm7 | G7 |
```

### 添加音和弦
```
add9：添加九度，流行感
| Cadd9 | Dm7 | Emadd9 | G |

sus4：挂留四度，悬疑感
| Csus4 | Fsus4 | Gsus4 | C |
