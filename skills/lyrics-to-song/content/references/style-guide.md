# 风格编曲指南

## 流行 Pop

### 风格特点
- 旋律朗朗上口
- 编曲精致、现代
- 和弦进行经典
- 制作精良、层次丰富

### 典型编曲

#### 乐器配置
```
必备：
- 人声（主导）
- 鼓（电子鼓/真鼓）
- 低音（Bass/合成器Bass）
- 和弦乐器（钢琴/吉他）

可选：
- 合成器Pad
- 弦乐
- 背景和声
- 电子音效
```

#### 节奏特点
```
BPM：85-120
鼓点：
- 四拍子稳定节奏
- 适量的Hi-Hat
- 副歌加重Kick和Snare

Bass：
- 根音+律动线条
- 切分节奏增加律动感
```

#### 编曲动态
```
Verse：编曲简洁，突出人声
Pre-Chorus：逐步加入元素
Chorus：全编制爆发
Break：留白或简化
```

### 制作建议
- 人声处理：EQ、压缩、混响、自动化
- 和声：三层和声增加厚度
- Drop：副歌后适当简化

## 说唱 Rap

### 风格分支

#### Old School
- BPM：80-100
- 特点：4/4拍、808早期风格
- 乐器：采样、DJ turntable

#### Boom Bap
- BPM：85-100
- 特点：重鼓点、采样
- 乐器：硬鼓、贝斯线、老式采样

#### Trap
- BPM：130-160
- 特点：808鼓机、Hi-Hat滚奏
- 乐器：合成器、Auto-Tune

#### Lo-Fi
- BPM：70-90
- 特点：低保真、温暖
- 乐器：复古采样、柔和Pad

### 典型编曲

#### 乐器配置
```
必备：
- 人声（干声或Auto-Tune）
- 鼓（808/硬鼓）
- Bass（808Bass或合成Bass）

核心：
- 主和弦（极简）
- 采样（氛围）

装饰：
- Hi-Hat节奏
- 音效采样
- 副歌加和声
```

#### 节奏特点
```
BPM：70-160（根据风格）
鼓点：
- 重拍前置
- 切分节奏型
- Hi-Hat变化（Open/Close）

韵脚对齐：
- 重音对齐强拍
- 连音创造流动感
```

### 制作建议
- 人声：压缩处理、Auto-Tune
- 和弦：简化，避免干扰人声
- 层次：Hook前加入元素

## 民谣 Folk

### 风格特点
- 原声乐器为主
- 编曲简洁
- 情感真挚
- 叙事性强

### 典型编曲

#### 乐器配置
```
必备：
- 人声（核心）
- 原声吉他
- （可选）木贝斯

常见组合：
- 吉他 + 人声
- 吉他 + 贝斯 + 打击乐
- 小编制乐队（吉他、贝斯、鼓）
- 加弦乐四重奏（现代民谣）
```

#### 节奏特点
```
BPM：60-100
吉他节奏型：
- 指弹：分解和弦
- 拨弦：下上下上
- 乡村：跳跃节奏

鼓点（如有）：
- 轻柔、辅助
- Brushes（刷子）代替鼓棒
```

### 编曲动态
```
Verse：极简吉他
Chorus：加入元素
Bridge：可能加入弦乐或打击乐
Solo：吉他独奏或器乐间奏
```

### 制作建议
- 人声：自然、清晰
- 吉他：录音质量很重要
- 留白：不过度制作
- 情感：真实胜于完美

## 摇滚 Rock

### 风格分支

#### Classic Rock
- BPM：100-130
- 特点：吉他主导、失真
- 乐器：电吉他、贝斯、鼓

#### Punk Rock
- BPM：150-180
- 特点：快速、强劲、三和弦
- 乐器：简化配置

#### Alternative/Indie
- BPM：90-130
- 特点：创新、实验
- 乐器：多样化

### 典型编曲

#### 乐器配置
```
必备：
- 人声
- 电吉他1（节奏）
- 电吉他2（主旋律/独奏）
- 贝斯
- 鼓

常见：
- 键盘/钢琴
- 合成器
- 弦乐（现代摇滚）
```

#### 节奏特点
```
BPM：110-160
鼓点：
- 强劲Kick
- 有力的Snare
- 有节奏的Hi-Hat
- 军鼓滚奏（高潮）

Bass：
- 根音为主
- 切分增加律动
```

#### 编曲动态
```
Verse：基础节奏
Pre-Chorus：逐渐加压
Chorus：全释放
Bridge：变化最大
Solo：器乐solo段落
```

### 制作建议
- 吉他：双轨增加厚度
- 失真：主歌轻/副歌重
- 力度：自动化处理
- 混音：吉他主导

## 段落过渡指南

### Verse → Chorus 过渡
```
技术：
1. 和弦进行导向
2. 鼓点加花
3. 贝斯线条上升
4. 加入Hi-Hat滚奏
5. 人声音高提升
```

### Chorus → Bridge 过渡
```
技术：
1. 全停（Full Stop）
2. 渐弱
3. 调式转换
4. 节奏型变化
5. 乐器增减
```

### 桥段后回副歌
```
技术：
1. 重复动机回归
2. 直接连接
3. 短间奏过渡
4. 升高半音（Key Change）
```

## 动态编排原则

| 段落 | 动态级别 | 元素数量 | 密度 |
|------|----------|----------|------|
| Intro | 0-30% | 渐增 | 稀疏 |
| Verse | 30-50% | 基础 | 中等 |
| Pre-Chorus | 50-70% | 增加 | 渐密 |
| Chorus | 80-100% | 全部 | 密集 |
| Bridge | 可变 | 变化 | 对比 |

### 动态对比原则
1. **Verse平静，Chorus爆发**
2. **副歌后适当休息**
3. **桥段提供对比**
4. **尾奏逐渐消退**
