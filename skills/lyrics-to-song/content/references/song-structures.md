# 歌曲结构模板

## 基础结构术语

| 术语 | 英文 | 缩写 | 说明 |
|------|------|------|------|
| 前奏 | Intro | INT | 歌曲开始，引导进入 |
| 主歌 | Verse | V | 叙事、铺垫 |
| 副歌 | Chorus | CH | 高潮、记忆点 |
| 预副歌 | Pre-Chorus | PC | 过渡、蓄力 |
| 桥段 | Bridge | B | 转折、变奏 |
| 尾奏 | Outro | OUT | 结束、回味 |
| 间奏 | Interlude | IL | 段落间过渡 |

## 标准结构模板

### 1. 最简结构 (Verse-Chorus)
```
Intro → Verse → Chorus → Verse → Chorus → Outro
```
**适用**：简单民谣、极简说唱
**时长**：2-3分钟

### 2. 流行标准结构 (ABABCB)
```
Intro → Verse1 → Chorus1 → Verse2 → Chorus2 → Bridge → Chorus3 → Outro
```
**适用**：流行歌曲主流结构
**时长**：3-4分钟

### 3. 经典摇滚结构
```
Intro → Verse1 → Pre-Chorus → Chorus1 → Verse2 → Pre-Chorus → Chorus2 → Solo → Bridge → Chorus3 → Outro
```
**适用**：摇滚、硬核
**时长**：4-6分钟

### 4. 说唱结构
```
Intro → Verse1 → Hook → Verse2 → Hook → Verse3 → Hook → Outro
```
**适用**：Trap, Old School Rap
**注意**：Hook（副歌/副歌）通常重复4-8小节

## 各段落规格

### 前奏 (Intro)
```
长度：4-8小节（16-32拍）
类型：
- 纯器乐前奏
- 主旋律前奏
- 节奏型前奏
- 歌词前奏（罕见）

功能：
- 建立调性
- 设定情绪
- 引入主题动机
```

### 主歌 (Verse)
```
长度：8-16小节
节拍：通常与副歌相同或略慢
歌词：叙事性内容
旋律：相对平稳、铺垫

变体：
- 主歌A（第一主歌）
- 主歌B（情绪升级版）
```

### 预副歌 (Pre-Chorus)
```
长度：4-8小节
功能：从主歌过渡到副歌
特点：
- 情绪逐渐上升
- 旋律走向高音区
- 和弦进行导向V或I

注意：并非所有歌曲都需要预副歌
```

### 副歌 (Chorus/Hook)
```
长度：8小节（4+4结构）或16小节
特点：
- 记忆点最强
- 情绪最高点
- 旋律朗朗上口
- 歌词重复核心主题

变体：
- 完全重复
- 微调重复（增加层次）
- 变调副歌（升高半音）
```

### 桥段 (Bridge)
```
长度：4-8小节
位置：通常在最后一次副歌前
功能：
- 提供对比
- 情绪转折
- 避免重复疲劳

特点：
- 旋律新素材
- 和弦变化（常用iv、vi、II、V）
- 节奏变化
- 视角转换（歌词）

注意：并非所有歌曲都需要桥段
```

### 尾奏 (Outro)
```
长度：4-16小节
类型：
- 渐弱结束（Fade Out）
- 完整结束（Full Ending）
- 主题回归
- 意外终止

功能：
- 情绪缓冲
- 留下回味
- 与前奏呼应
```

## 结构变体模板

### 1. 抒情歌曲结构
```
Intro(4) → Verse1(8) → Chorus1(8) → Verse2(8) → Chorus2(8) → Bridge(8) → Chorus3(8) → Outro(4)
总长度：约48小节，3-4分钟
```

### 2. 说唱歌曲结构
```
Intro(2) → Hook(4) → Verse1(16) → Hook(4) → Verse2(16) → Hook(4) → Bridge(4) → Hook(4) → Outro(2)
总长度：约52小节，2.5-3.5分钟
```

### 3. 摇滚歌曲结构
```
Intro(8) → Verse1(8) → Pre-Chorus(4) → Chorus1(8) → Verse2(8) → Pre-Chorus(4) → Chorus2(8) → Solo(8) → Bridge(8) → Chorus3(8) → Outro(8)
总长度：约72小节，4-5分钟
```

### 4. 民谣歌曲结构
```
Intro(4) → Verse1(8) → Chorus1(8) → Verse2(8) → Chorus2(8) → Bridge(4) → Chorus3(8) → Outro(4)
总长度：约44小节，3-4分钟
```

## 结构选择指南

| 歌词长度 | 推荐结构 | 调整方案 |
|----------|----------|----------|
| 少于50字 | 短结构 | 简化段落 |
| 50-100字 | 标准结构 | 正常分配 |
| 100-150字 | 扩展结构 | 增加重复 |
| 150-200字 | 双副歌 | 主副歌+副副歌 |
| 超过200字 | 分段处理 | 拆分为多首 |

| 情绪类型 | 推荐结构 |
|----------|----------|
| 平静叙事 | Verse-Chorus循环 |
| 情绪爆发 | 增加Pre-Chorus和Bridge |
| 叙事性强 | 增加Verse数量 |
| 记忆点强 | 简化结构，突出Hook |
