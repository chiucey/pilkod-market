## 四、策略建议

### 系数预测策略
1. **跟势原则**：v0630连续性最强(73%)，可优先跟势
2. **保守预测**：v0830多为0.9，早高峰避免追涨
3. **灵活调整**：v0900-v0930波动大，需结合当日情况

### 差价交易策略
1. **杀跌为主**：买小差价均值始终为正，胜率更高
2. **避免追涨**：买大差价均值始终为负，亏损概率大
3. **重点时段**：v0900-v0930差价波动最大，需谨慎

### 综合决策框架
```
IF 系数为1.1:
    → 预期买大亏损，建议观望或买小
IF 系数为0.9:
    → 买小盈利概率高，可适当参与
IF 前一时段与当前时段系数连续:
    → 提高预测置信度，跟势操作
```
