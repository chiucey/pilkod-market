# 「知彼」— 竞品动态监控系统

## 简介

输入竞品账号，AI 自动追踪它的内容更新、爆款规律、粉丝互动，生成结构化日报/周报。让你比竞品早一步知道市场动向。

## 核心能力

- **账号监控**：同时监控多个竞品账号（小红书、微信公众号、微博、知乎、抖音等）
- **内容追踪**：自动记录每个内容的发布时间、形式、主题、爆款程度
- **爆款分析**：识别什么类型内容效果最好，分析爆款规律
- **粉丝互动**：追踪评论热词、粉丝画像变化
- **定时报告**：每日/每周自动生成竞品动态简报
- **竞品对比**：将自己账号与竞品进行多维度对比

## 监控维度

| 维度 | 说明 |
|------|------|
| 更新频率 | 发帖数量、时间分布 |
| 内容类型 | 图文/视频/纯文字/直播 |
| 爆款率 | 爆款内容占比（点赞>1000） |
| 互动率 | 点赞/收藏/评论/转发比 |
| 话题方向 | 主题分类、关键词云 |
| 粉丝趋势 | 涨粉/掉粉动态 |

## 使用方法

### 基础用法

```
帮我监控以下竞品账号的小红书动态：
- @竞品A
- @竞品B
生成今天的竞品动态简报。
```

### 进阶用法

```
我想了解最近30天，竞品A和竞品B在小红书上的内容策略差异。
重点分析：
1. 什么话题最火
2. 爆款内容的共同特征
3. 我们可以借鉴什么
```

### 完整工作流

```
第一步：输入竞品账号列表（支持多平台）
第二步：选择监控时间范围（今天/本周/本月/自定义）
第三步：AI 自动抓取数据（内容、互动、发布时间）
第四步：分析爆款规律和内容策略
第五步：生成结构化报告（含数据图表）
第六步：输出可操作建议
```

## 输出报告模板

### 日报
- 今日竞品更新汇总
- 新爆款内容列表
- 值得关注的动作

### 周报
- 竞品内容发布统计
- 爆款规律分析
- 话题趋势对比
- 竞品粉丝变化
- 下周内容建议

## 注意事项

- 抓取频率受平台反爬限制，建议设置合理间隔
- 部分平台数据（如粉丝画像）可能无法获取
- 报告仅供参考，决策需结合自身情况
- 建议监控竞品数量不超过10个以保证分析质量
