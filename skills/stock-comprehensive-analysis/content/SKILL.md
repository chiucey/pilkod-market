# 综合股票分析系统

对目标股票进行技术分析与价值投资相结合的综合研判。

## 分析框架概览

本技能整合六大分析流派：

| 分类 | 分析方法 | 核心问题 |
|------|----------|----------|
| 技术分析 | 道氏理论 | 趋势是什么方向？ |
| 技术分析 | 艾略特波浪 | 当前处于哪一浪？ |
| 技术分析 | CAN SLIM | 成长性如何？ |
| 价值投资 | 格雷厄姆估值 | 安全边际够吗？ |
| 价值投资 | 巴菲特护城河 | 竞争优势强吗？ |
| 价值投资 | 马克斯周期 | 周期位置在哪？ |

## 执行流程

### 第一步：数据采集与交叉验证

**必须使用实时数据查询工具获取以下数据：**

1. **价格与行情数据**
   - 使用 `stocks_price` 获取历史价格时间序列（至少1年）
   - 使用 `stocks_info` 获取基本信息
   - 使用 `stocks_news` 获取近期新闻

2. **财务数据采集**
   - 使用 `stocks_financial_data` 获取财务报告
   - 使用 `stocks_statistics` 获取关键统计指标
   - 使用 `stocks_insights` 获取分析师观点

3. **数据验证规则**
   - **必须**：通过至少两个不同平台/数据源交叉验证
   - **必须**：标注每个数据的来源和查询日期
   - **标注**：无法验证的数据需明确标注"[待验证]"而非直接采纳
   - **禁止**：绝不编造或使用训练数据中的旧数据

### 第二步：技术分析

#### 2.1 道氏理论趋势分析

```
分析要素：
- 主要趋势：牛市/熊市/盘整（基于高低点序列）
- 次要趋势：回调/反弹阶段判断
- 成交量确认：价量配合分析
- 关键价位：
  * 支撑位：标注具体价格
  * 阻力位：标注具体价格
```

#### 2.2 艾略特波浪分析

```
分析要素：
- 波浪计数：从最近重要低点开始的浪序
- 各浪特征：起止点、幅度（用具体价格）
- 目标预测：推动浪目标位 / 调整浪支撑位
- 置信度：评估波浪计数的确定性
```

## 数据纪律要求

1. **实时性**：所有数据必须来自实时查询工具，禁止使用训练数据
2. **可验证性**：关键数据需通过至少两个来源交叉验证
3. **透明度**：无法获取的数据标注"[待查询]"或"[待验证]"，不编造
4. **溯源性**：所有价格/指标必须标注查询日期（精确到交易日）
5. **假设声明**：估值模型必须公开所有假设参数

## 输出格式

分析完成后，输出结构化报告，包含：
1. 执行摘要（核心结论一目了然）
2. 技术分析详情（附数据表格）
3. 价值投资分析（附估值模型）
4. 综合研判（明确买卖建议）
5. 数据来源与验证状态附录
