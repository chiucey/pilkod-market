# 价值投资参考手册

## 一、格雷厄姆安全边际估值（Benjamin Graham）

### 格雷厄姆数（Graham Number）
```
Graham Number = √(22.5 × EPS × BPS)

解释：
- EPS：稀释每股收益（TTM或预期EPS）
- BPS：每股净资产（Book Value Per Share）
- 22.5：格雷厄姆设定的系数（基于PE≤15且PB≤1.5）

决策阈值：
- 当前股价 < Graham Number × 0.7 → 深度价值，买入
- 当前股价 < Graham Number → 有安全边际，买入
- 当前股价 = Graham Number → 合理估值，持有
- 当前股价 > Graham Number × 1.3 → 溢价偏高，谨慎
```

### DCF三阶段模型

```
第一阶段（明确预测期）：5-10年
第二阶段（过渡期）：5年，增长率线性衰减
第三阶段（永续期）：永续增长

内在价值 = Σ(DCFFt/(1+WACC)^t) + TV/(1+WACC)^n

TV = FCFn × (1+g永) / (WACC - g永)
```

#### DCF参数设置

| 场景 | WACC | 第一阶段增长率 | 永续增长率 | 适用情况 |
|------|------|----------------|------------|----------|
| 保守 | WACC+2% | 行业增速×0.7 | 2-3% | 高不确定性 |
| 中性 | WACC | 行业增速 | 3-4% | 一般情况 |
| 乐观 | WACC-2% | 行业增速×1.3 | 4-5% | 高确定性 |

#### 安全边际计算
```
安全边际 = (内在价值 - 当前股价) / 内在价值 × 100%

格雷厄姆标准：
- 安全边际 > 40% → 强烈买入
- 安全边际 > 20% → 买入
- 安全边际 0-20% → 持有
- 安全边际 < 0 → 卖出/回避
```

## 二、巴菲特护城河分析（Warren Buffett's Moat）

### 五种护城河类型

#### 1. 无形资产（Intangible Assets）
- **品牌**：消费者愿意为品牌溢价付费
- **专利**：技术壁垒，研发投入
- **许可证**：监管门槛，牌照稀缺
- **评估方法**：
  - 品牌溢价 = 产品价格 - 同类无品牌产品价格
  - 毛利率与行业平均对比
  - 能否持续获得定价权

#### 2. 转换成本（Switching Costs）
- **定义**：客户从A产品转向B产品的一次性成本
- **类型**：
  - 金钱成本（重新购买、培训）
  - 时间成本（学习新系统）
  - 精神成本（不确定性、风险）
- **评估信号**：
  - 客户留存率>90%
  - 客户平均使用年限>5年
  - 竞争对手难以复制的专属数据/习惯

#### 3. 网络效应（Network Effects）
- **定义**：每增加一个用户，产品价值递增
- **类型**：
  - 直接网络效应：社交网络
  - 间接网络效应：平台双边市场
  - 数据网络效应：数据越多，AI越准
- **评估方法**：
  - 观察用户增长与变现能力的相关性
  - 市场集中度
  - 赢家通吃的趋势

#### 4. 成本优势（Cost Advantages）
- **来源**：
  - 规模经济（固定成本摊薄）
  - 流程优化（专有技术/工艺）
  - 地理位置（运输成本、资源获取）
  - 特殊资源（矿权、土地、许可证）
- **评估指标**：
  - 毛利率 vs 行业平均
  - 成本结构分析
  - 可持续性判断

#### 5. 有效规模（Efficient Scale）
- **定义**：市场只能容纳1-2家有效竞争者
- **特征**：
  - 进入壁垒高
  - 退出成本高
  - 在位者持续盈利
- **典型案例**：公共事业、地区垄断

### 护城河评级标准

| 评级 | 定义 | 预期持续性 | 投资策略 |
|------|------|------------|----------|
| **宽护城河** | 竞争优势持久，可抵御多次竞争冲击 | 10年+ | 长期持有，享受复利 |
| **窄护城河** | 竞争优势存在但可能被侵蚀 | 5-10年 | 估值合理时持有 |
| **无护城河** | 充分竞争，难以持续获得超额收益 | <5年 | 只能做波段/择时 |

### 护城河评估清单

```
□ 品牌认知度调研：能说出3个竞争对手吗？
□ 定价权测试：近5年毛利率趋势？
□ 客户留存率：>90%表示强转换成本
□ 资本回报率：ROIC持续>15%？
□ 竞争者数量：是否在增加？
□ 技术变革威胁：是否面临颠覆风险？
□ 监管变化：政策是否支持在位者？
```

## 三、霍华德·马克斯周期思维（Howard Marks - The Cycle）

### 周期理论基础

马克斯认为：
- **周期是常态**：经济、市场、行业都有周期
- **周期不可预测**：能判断方向但不能精确时间
- **均值回归**：涨多必跌，跌多必涨
- **钟摆效应**：过度乐观 → 过度悲观循环

### 周期位置判断

#### 1. 宏观经济周期

| 阶段 | 特征 | 投资信号 |
|------|------|----------|
| **复苏早期** | GDP回升、失业率下降、通胀低 | 股票>债券，积极配置 |
| **复苏中期** | GDP强劲、消费旺盛 | 顺周期行业，超配 |
| **过热期** | 通胀上升、产能紧张 | 减少股票，增配商品 |
| **衰退期** | GDP负增长、失业率上升 | 防御性资产，现金为王 |

#### 2. 信贷周期

| 阶段 | 信贷环境 | 市场信号 |
|------|----------|----------|
| **宽松** | 低利率、高杠杆、易获贷 | 风险偏好上升，资产价格上涨 |
| **收紧** | 高利率、去杠杆、违约上升 | 风险偏好下降，资产价格下跌 |

**关键指标**：
- 信用利差（Corporate Bond Spread）
- 高收益债违约率
- 银行贷款标准变化

#### 3. 市场情绪周期

```
极度悲观 → 谨慎乐观 → 过度乐观 → 泡沫 → 崩盘 → 恐慌 → 绝望 → 谨慎乐观...
```

**评估工具**：
- PE/PB与历史分位数对比
- 分析师一致预期
- 恐慌/贪婪指数
- 基金仓位数据

### 估值分位数分析

```
计算方法：
历史分位数 = (当前估值 - 历史最低) / (历史最高 - 历史最低) × 100%

判断标准：
- <20%分位数：估值偏低
- 20-80%分位数：估值合理
- >80%分位数：估值偏高
- >95%分位数：极度高估

注意：
- 必须使用同周期数据对比
- 不同行业估值方法不同
- 考虑盈利预期变化
```

### 马克斯风险评估框架

```
第一层：Loss of Opportunity（错失机会）
第二层：Return/Risk Ratio（风险收益比）
第三层：Downside Protection（下行保护）

评估问题：
□ 当前位置向上向下概率各多少？
□ 最大回撤能承受多少？
□ 等待下一个机会的时间成本？
□ 错误的代价 vs 正确的机会成本？
```

## 五、数据验证与来源规范

### 交叉验证要求

| 数据类型 | 必须验证来源 | 验证方法 |
|----------|--------------|----------|
| 价格数据 | 至少2个行情终端 | 对比差异<0.1% |
| 财务数据 | 年报+季报+数据库 | 三方一致 |
| 估值数据 | 至少2家机构 | 取中位数 |
| 新闻事件 | 至少2个媒体 | 核实细节 |

### 数据标注格式

```
价格：¥XX.XX（数据来源：新浪财经，查询时间：2026-04-02）
EPS：X.XX元（数据来源：Wind，查询时间：2026-04-02）
[待验证]：标注无法确认的数据
[趋势示意]：标注非精确数据
```
