## 五阶段仓位管理

| 阶段 | 判断标准 | 仓位上限 | 可做信号 |
|------|---------|---------|---------|
| **冰点期** | 跌停>30家 或 涨停<15家 | 0% | 空仓等待 |
| **启动期** | MA5>MA10 + 反弹 | 1-3成 | M1、M4 |
| **发酵期** | 强趋势 + 成交放量 | 8成 | M1 / M3 / M4 / M5 |
| **高潮期** | 情绪高涨 | 3-5成 | M5（减少追高）|
| **退潮期** | 龙头滞涨 | 0-1成 | 全部停止 |

## 持仓管理（三层风控）

```
第一层：仓位防线
  冰点期 → 0%仓位（不建仓）
  退潮期 → ≤10%仓位（M4恐慌除外）

第二层：止损防线
  机械止损：-5%（无条件）
  移动止盈：触发后反向回落→立即止盈
  时间止损：持有到期日（按信号决定）仍亏损→止损

第三层：系统防线
  周亏损>5% → 减仓50%
  月亏损>10% → 停牌检查
```

## 移动止盈规则（让利润奔跑的核心）

```
持仓中：
  → 最高价回落超过止盈阈值时，触发移动止盈
  → 触发后：价格回落X% → 立即止盈

M1首板：最高价回落8% → 止盈（持有2天）
M3整理：最高价回落15% → 止盈（持有7天）← 精华！
M4恐慌：最高价回落8% → 止盈（持有3天）
M5金叉：最高价回落10% → 止盈（持有5天）
```

## 扑克验证（必须触发的情况）

```
以下情况必须用扑克三问验证：
  → 想要追涨时
  → 想要补仓时
  → 想要全仓时
  → 连续亏损后想报复时
  → 某个标的已经跌了15%还在持有时

扑克三问：
  ❓ 涟漪会追牌吗？
     → 会追 → 不投资；会弃 → 止损

  ❓ 涟漪会All-in吗？
     → 不会All-in → 不全仓

  ❓ 涟漪能接受这手输吗？
     → 不能接受 → 仓位过大；能接受 → 仓位合适
```

## 禁止事项（铁律）

```
❌ 情绪<20分 → 空仓
❌ 跌停>30家 → 空仓
❌ 未通过扑克验证 → 不执行
❌ 单一标的>25%仓位
❌ 单一板块>40%仓位
❌ 总仓位>80%
❌ 持有>15天（强制检视）
❌ 真实下单 → 必须V授权
```
