# 学术论文深度解读技能

## 核心能力

采用工程优先工作流程，对学术论文进行系统性深度分析，覆盖八大关键维度：

1. **文章总览分析** - 背景、主题、目的和结论
2. **关键概念提取** - 论文核心术语和定义
3. **研究设计解析** - 整体研究或设计流程
4. **理论建构过程解析** - 理论形成路径
5. **研究方法分析** - 方法及具体操作
6. **数据分析方法解释** - 方法及其目的
7. **图表解析** - 图表含义解读
8. **论文局限性解析** - 写作及结果的局限性

## 工作流程

### 步骤1：内容提取

**对于网页论文：**
- 使用 `extract_content_from_websites` 工具提取完整内容
- 收集标题、作者、摘要、正文等所有部分

**对于文档文件（如DOCX/PDF）：**
- 使用相应工具读取文件内容
- 处理文本编码和格式问题

### 步骤2：八大维度分析

按照以下框架进行系统性分析：

#### 2.1 文章总览分析

分析论文的：
- **研究背景**：时代背景、研究领域的现状
- **研究主题**：核心研究问题
- **研究目的**：作者希望通过研究解决什么问题
- **主要结论**：论文的核心发现和贡献

#### 2.2 关键概念提取

列出并定义：
- **核心概念**：论文最重要的理论或技术概念
- **辅助概念**：支撑核心概念的相关术语
- 每个概念需说明其定义和在论文中的作用

#### 2.3 研究设计解析

解析论文的：
- **整体研究框架**：从理论到实证的路径
- **研究方法选择依据**：为何选择该方法
- **案例选择逻辑**：案例研究的选取标准
- **研究创新点**（如有）

#### 2.4 理论建构过程解析

分析论文：
- **理论起点**：基于何种理论或假设
- **理论发展路径**：从起点到核心概念的演进
- **理论深化**：如何逐步完善理论框架
- **理论贡献**：对学科领域的贡献

#### 2.5 研究方法分析

分析：
- **方法论定位**：定量/定性/混合研究
- **具体研究方法**：实验/调查/案例等
- **方法运用**：如何具体实施
- **方法论优劣势**：该方法的长处和局限

#### 2.6 数据分析方法解释

详细说明：
- **数据收集方法**：数据来源、样本选择
- **数据处理技术**：清洗、预处理方式
- **分析模型**：使用的统计或计算模型
- **评价指标**：如何验证结果有效性

#### 2.7 图表解析

- 识别论文中的所有图表
- 解析每张图表展示的信息
- 说明图表与分析结论的关系
- 如论文无图表，分析其对可读性的影响

#### 2.8 论文局限性解析

批判性分析：
- **理论层面局限**：假设验证、概念边界问题
- **方法论局限**：样本、测量、因果推断问题
- **论证逻辑局限**：逻辑谬误、论证跳跃
- **内容覆盖局限**：遗漏的重要议题
- **外部效度局限**：结论适用性限制

### 步骤3：深度认知框架分析（可选）

可使用以下框架深化分析：

#### SCQA 脉络图

- **Situation（情境）**：背景和环境
- **Complication（冲突）**：核心矛盾
- **Question（问题）**：关键研究问题
- **Answer（答案）**：作者解决方案

#### 5W2H 全维度分析

- What/Why/Who/When/Where/How/How Much

#### 六顶思考帽分析

从白/红/黑/黄/绿/蓝六个视角审视论文

### 步骤4：总体评价与建议

给出：
- **论文贡献**：主要学术价值
- **论文不足**：需要改进之处
- **改进建议**：具体可操作的建议

## 输出格式

最终输出应包含：

1. **结构化报告**：八大维度的完整分析
2. **认知框架分析**（如有）：SCQA、5W2H、六顶思考帽等
3. **核心洞察提炼**：带置信度评级的主张
4. **可行动建议**：分优先级的实践路径

## 注意事项

- **适用范围**：主要针对学术论文
- **输入处理**：支持网页URL和文档文件
- **分析深度**：根据论文实际内容调整，避免过度解读
- **批判思维**：在肯定贡献的同时，保持客观批判视角

## 示例

**输入：**
```
请解读这篇论文：https://example.com/paper.pdf
```

**处理流程：**
1. 提取论文全文内容
2. 按八大维度进行系统分析
3. 使用认知框架深化理解
4. 生成完整解读报告
