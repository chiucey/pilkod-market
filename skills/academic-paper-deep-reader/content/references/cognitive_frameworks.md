# 深度认知框架指南

本文档为学术论文深度解读技能提供补充性的认知框架参考。

## 1. SCQA 分析模型

### 结构

- **Situation（情境）**：识别文章背景和环境
- **Complication（冲突）**：发现核心矛盾和张力点
- **Question（问题）**：提炼关键研究问题
- **Answer（答案）**：总结作者论点和解决方案

### 输出格式

```
## SCQA 脉络图

**Situation（情境）**：
[描述研究背景和时代环境]

**Complication（冲突）**：
[识别核心矛盾是什么]

**Question（问题）**：
[提炼关键研究问题]

**Answer（答案）**：
[总结作者的核心论点]
```

### 应用示例

对于一篇关于AI在股市预测中应用的论文：

- **Situation**：AI技术飞速发展，金融领域面临数字化转型
- **Complication**：传统预测方法难以处理股市的非线性特征
- **Question**：如何利用AI技术提升股市预测的准确性？
- **Answer**：通过深度学习融合多源数据，构建自适应预测模型

## 2. 5W2H 全维度分析

### 结构

| 维度 | 内容 |
|------|------|
| **What** | 核心概念和定义 |
| **Why** | 原因和动机分析 |
| **Who** | 相关主体识别 |
| **When** | 时间维度 |
| **Where** | 空间维度 |
| **How** | 方法路径 |
| **How Much** | 量化数据 |

### 应用场景

用于全面理解论文的研究范围、内容、方法论和预期成果。

## 3. 六顶思考帽分析

### 视角说明

| 帽子 | 视角 | 分析内容 |
|------|------|---------|
| 白帽 | 事实与信息 | 数据、证据、客观信息 |
| 红帽 | 情感与直觉 | 感受、情绪反应 |
| 黑帽 | 批判与风险 | 逻辑漏洞、潜在问题 |
| 黄帽 | 乐观与价值 | 优势、机遇、收益 |
| 绿帽 | 创意与可能 | 创新点、替代方案 |
| 蓝帽 | 管控与总结 | 整体框架、行动建议 |

### 输出格式

```
## 六顶思考帽分析

**白帽（事实与信息）**：
[列出论文的客观事实和数据]

**红帽（情感与直觉）**：
[描述文章的情感基调和读者的直观感受]

**黑帽（批判与风险）**：
[识别论文的逻辑漏洞和潜在问题]

**黄帽（乐观与价值）**：
[总结论文的价值和优势]

**绿帽（创意与可能）**：
[提出创新点和替代方案]

**蓝帽（管控与总结）**：
[提供整体评价和建议]
```

## 4. 批判性分析指南

### 常见逻辑谬误检查

- **滑坡谬误**：假设一种趋势会导致极端后果
- **虚假二分法**：忽略中间立场
- **循环论证**：论点是自身的证明
- **诉诸权威**：仅因权威观点而接受论点
- **幸存者偏差**：只关注成功案例

### 证据质量评估

1. **数据来源可靠性**：数据是否权威、完整
2. **样本代表性**：样本是否足够且有代表性
3. **因果vs相关**：是否混淆了因果关系和相关关系
4. **统计显著性**：结果是否具有统计意义
5. **可重复性**：研究是否可被独立重复验证

### 认知偏差识别

- **确认偏差**：倾向于寻找支持已有观点的信息
- **锚定偏差**：过度依赖最初获得的信息
- **过度自信偏差**：高估自己的判断准确性
- **可得性启发**：根据易获取的信息做判断

## 5. 假设层级分析

### 分析层次

```
表层假设：具体的操作假设
    ↓
中层假设：理论推导假设
    ↓
深层假设：根本性的世界观/范式假设
```

### 识别方法

1. 找出论文中"不言自明"的前提
2. 追问"为什么这样假设"
3. 探索是否存在替代假设
4. 评估假设的合理性

## 6. 核心洞察提炼

### 置信度评级

| 置信度 | 说明 |
|--------|------|
| **高** | 有充分证据支持，跨研究验证 |
| **中** | 有一定证据，但可能存在例外 |
| **低** | 推测性结论，需要更多验证 |

### 输出格式

```
## 核心洞察提炼

### 高置信度主张
| 置信度 | 主张 |
|--------|------|
| 高 | [具体主张1] |
| 高 | [具体主张2] |

### 中置信度主张
| 置信度 | 主张 |
|--------|------|
| 中 | [具体主张1] |

### 低置信度主张
| 置信度 | 主张 |
|--------|------|
| 低 | [具体主张1] |
```

## 7. 可行动建议优先级

### 优先级划分

| 优先级 | 时间范围 | 说明 |
|--------|----------|------|
| **高** | 立即行动 | 核心改进项 |
| **中** | 1-3个月 | 重要但非紧急 |
| **低** | 长期规划 | 战略性方向 |

### 输出格式

```
## 可行动建议（优先级排序）

### 高优先级（立即行动）
1. [具体建议]
2. [具体建议]

### 中优先级（1-3个月）
3. [具体建议]

### 低优先级（长期规划）
4. [具体建议]
```

## 8. 批判性评分标准

### 评分维度

| 维度 | 满分 | 评分标准 |
|------|------|----------|
| 论证强度 | 10 | 逻辑严密性、证据充分性 |
| 逻辑严密性 | 10 | 论证结构、因果推断 |
| 证据质量 | 10 | 数据、样本、统计方法 |
| 创新程度 | 10 | 理论创新、方法创新 |
| 实用性 | 10 | 应用价值、可操作性 |
| **总分** | 50 | 平均分 = 总分/5 |

### 评分说明

- **8-10分**：优秀，该维度达到顶尖水平
- **6-7分**：良好，该维度表现良好
- **4-5分**：一般，该维度存在明显不足
- **1-3分**：较差，该维度有重大缺陷

---

## 使用指南

1. 根据论文特点选择合适的认知框架
2. 深度分析时建议综合使用多个框架
3. 保持批判性思维，不盲目接受作者观点
4. 在输出中明确标注分析来源和依据
5. 区分事实陈述和主观判断
