## Core Styles Deep Dive

### 1. Boom Bap

**Origin**: East Coast (mainly New York), early to mid-1990s

**Signature Features**:
- Heavy kicks (Heavy Kick)
- Snappy snares (Snappy Snare)
- Lo-fi samples (Lo-fi Samples)
- Strong basslines
- Swing/Shuffle groove

**Recommended Prompts**:
```
Boom Bap, Hard-hitting Drums, Heavy Kick, Snappy Snare, Lo-fi Sample, Underground, East Coast, Raw Energy
```

**Classic Producer References**:
- DJ Premier
- Pete Rock
- RZA
- Large Professor
- Lord Finesse

---

### 2. Jazz Rap

**Origin**: East Coast, early 1990s

**Signature Features**:
- Jazz samples (Jazz Piano, Saxophone, Upright Bass)
- Complex harmonic progressions
- Relaxed rhythms
- Intellectual lyric content
- Vintage record texture

**Recommended Prompts**:
```
Jazz Rap, Jazz Piano Sample, Upright Bass, Laid-back Groove, Soulful Atmosphere, Conscious Lyrics, Vintage Production
```

**Classic Producer References**:
- A Tribe Called Quest
- Guru (Gang Starr)
- Pete Rock & CL Smooth
- De La Soul
- Digable Planets

---

### 3. Lo-fi Hip-Hop

**Origin**: Global, 2010s to present

**Signature Features**:
- Low-fidelity sound quality
- Vinyl crackle
- Warm analog texture
- Relaxing, meditative atmosphere
- Usually instrumental or ambient vocals

**Recommended Prompts**:
```
Lo-fi Hip Hop, Vinyl Crackle, Warm Texture, Relaxing Groove, Nostalgic Samples, Chill Beats, Study Music, Bedroom Production
```

**Modern Representatives**:
- J Dilla (Lo-fi pioneer)
- Nujabes
- Madlib
- Mndsgn

---

### 4. East Coast Golden Era

**Period**: Golden Era 1988-1996

**Signature Features**:
- Sample-intensive production
- Swinging drum patterns
- Soul/Jazz samples
- Narrative lyrics
- Vintage hip-hop aesthetics

**Recommended Prompts**:
```
90s East Coast Hip Hop, Golden Era, Sample-based Production, Soul Sample, Jazz Influence, Classic Boom Bap, Raw Sound, Underground
```

**Golden Era Representatives**:
- Nas (Illmatic)
- Big L
- Mobb Deep
- Wu-Tang Clan
- Gang Starr

---

### 5. Underground Hip-Hop

**Core Spirit**: Independent, anti-mainstream, authentic

**Signature Features**:
- Lo-fi production
- Unconventional sampling
- Dark/gloomy atmosphere
- Authentic lyric themes
- DIY aesthetics

**Recommended Prompts**:
```
Underground Hip Hop, Dark Atmosphere, Lo-fi Production, Raw Texture, Vintage Sampler, Gritty Drums, Authentic Sound, Street Poetic
```

## Instrument Role Guide

### Drums

| Element | Old-School Requirement | Recommended Prompts |
|---------|----------------------|---------------------|
| Kick | Powerful, heavy, impactful | Heavy Kick, Punchy 808 Alternative |
| Snare | Crisp, slight reverb, classic texture | Snappy Snare, Tight Clap Sound |
| Hi-Hat | **NEVER** trap-style 16th notes | Open Hi-hat, 2-Step Pattern, Swing Hi-hat |
| Bass Alternative | Analog synth or sampled | Analog Synth Bass, Acoustic Kick |

### Samples

| Type | Usage | Recommended Prompts |
|------|-------|---------------------|
| Piano | Main melody/chord progressions | Jazz Piano Loop, Soulful Keys |
| Bass | Low-end support | Upright Bass, Deep Bass Line |
| Vocals | Chopping/harmonies | Vocal Chops, Soulful Ad-libs |
| Vinyl | Texture/atmosphere | Vinyl Crackle, Dusty Texture |
| Drums | Vintage patterns | Breaks Sample, Amen Break |

### Effects

| Effect | Usage | Recommended Prompts |
|--------|-------|---------------------|
| Hiss | Vinyl simulation | Vinyl Noise, Static, Tape Hiss |
| Saturation | Warmth | Tape Saturation, Analog Warmth |
| Reverb | Space | Room Reverb, Vinyl Chamber |
| Filter | Vintage processing | Low-pass Filter, Filtered Sample |

### Texture Level Guide

| Level | Description | Prompt Combination |
|-------|-------------|-------------------|
| **Level 1 (Warm)** | Slight analog feel, suitable for most Boom Bap | `Light Tape Saturation, Subtle Vinyl` |

## Negative Prompt Guide

### Must Exclude

| Exclusion | Reason | Negative Prompt |
|-----------|--------|-----------------|
| Auto-tune | Conflicts with Old-School aesthetics | `Auto-tune, Pitch Correction` |
| Trap drums | Modern trap features | `Trap Hi-hats, 808 Bass, 808 Drums` |
| Over-clean | Loses vintage texture | `Over-polished, Clean Production` |
| Synthesizers | Non-sample aesthetics | `Synthesized, EDM, Electronic Drums` |
| Modern mixing | Anachronistic | `Modern Mix, Digital Perfection, Compressed` |

### Style-Based Exclusions

| Target Style | Additional Exclusions |
|-------------|----------------------|
| Pure Boom Bap | `Jazz Elements, Funk, Lo-fi (excessive)` |
| Pure Jazz Rap | `Hardcore Drums, Aggressive Energy` |
| Lo-fi | `Clean, Modern, Digital, Pristine` |

## Style Blending Guide

### Blendable Combinations

```
Boom Bap + Lo-fi = Dusty Boom Bap (Modern Old-School)
Jazz Rap + Lo-fi = Chill Jazz Rap (Relaxed Atmosphere)
East Coast + Jazz = Classic East Coast Golden Era
Underground + Jazz = Spiritual Jazz Rap
```

### Blend Examples

**Dusty Boom Bap**:
```
Boom Bap + Heavy Lo-fi Texture
→ Dark Boom Bap, Lo-fi Gritty, Vinyl Noise, Underground
```

**Chill Jazz Rap**:
```
Jazz Rap + Relaxed Lo-fi
→ Jazz Rap, Lo-fi Texture, Relaxed Groove, Nostalgic Piano
```
