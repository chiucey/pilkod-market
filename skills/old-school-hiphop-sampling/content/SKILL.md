# Old-School Hip-Hop Sampling & Stylized Generation

This skill focuses on guiding you to use MiniMax Music models to transform modern pop song fragments into Underground Hip-Hop Beats with authentic 90s Golden Era texture.

## Core Capabilities

- **Stylized Prompt Construction**: Precisely invoke specialized vocabulary for sub-genres like Boom Bap, Jazz Rap, and Lo-fi
- **Sampling Fusion Guidance**: Use dry vocals or melody fragments as seed audio for harmonic and rhythmic matching
- **Audio Perception Control**: Fine-tune parameters for Old-School specific "roughness" and "analog warmth"

## Prompt Template Structure

```
[Style Definition] + [Instrumentation] + [Rhythm Features] + [Atmosphere/Texture] + [Negative Prompt]
```

## Recommended Prompt Combinations

### Style Prompt (Style Definition)

```
90s East Coast Hip Hop, Boom Bap, Underground, Hard-hitting Drums, Heavy Kick, Snappy Snare
```

### Instrumentation (Instrument Description)

```
Sampled Jazz Piano Loop, Scratched Vinyl, Deep Upright Bass, Soulful Vocal Chops
```

### Texture & Vibe (Texture and Atmosphere)

```
Lo-fi texture, Vinyl Crackle, Tape Saturation, Dusty, Gritty, Swing Rhythm, Nostalgic, Dark
```

### Negative Prompt (Exclusions)

```
Auto-tune, Trap Hi-hats, Over-polished, EDM, Synthesized, Clean Production
```

## Expert Operation Tips

### 1. Groove Control

The soul of Old-School lies in Swing. Be sure to emphasize in your prompts:
- `Swing Rhythm`
- `Groovy`
- `Laid-back`
- `Loose feel`

Avoid AI generating overly mechanical, perfectly quantized rhythms.

### 2. Sample Processing

If you upload vocal chops, include:
- `Chopped and Screwed`
- `Vocal Sample as Instrument`
- `Vocal Chop Loop`

Guide AI to treat vocals as an instrument rather than a lead vocal.

### 3. Noise Layering

To simulate vinyl record playback, prompts must include:
- `Vinyl Noise`
- `Static`
- `Tape Hiss`
- `Crackle`

This instantly adds "vintage feel" and "underground vibe."

## Expected Output

Audio generated with this skill will have the following characteristics:

| Element | Characteristics |
|---------|----------------|
| **Drums** | Powerful yet loose, snare with noticeable reverb and punch |
| **Low-end** | Thick but clear, simulating analog synth or acoustic bass texture |
| **Overall Feel** | Warm, slightly rough, like a classic beat playing from an old record |
