# 社交媒体运营导流话术指南

## 概述

本技能提供小红书和抖音平台的评论导流话术，帮助用户在遵守平台规则的前提下有效引导用户私信联系或加入群聊。所有话术均已规避平台违禁词汇，可安全使用。

| 电话 | 稍后联系、方便时沟通 |

### 评论违禁词汇
| 违禁词 | 替代表达 |
|--------|----------|
| 踢踢我 | 踢踢、私 |
| 私 | 看主页、戳我 |
| 私发你 | 看群置顶 |

### 谐音替代方案
- 微信 → 伟新、威、薇、微微、小绿号、地球号、卫星号
- 私信 → 丝喔、斯沃、丝下、沃斯你、思
- 群 → 圈子、裙（emoji表情）
- 置顶 → 至鼎、看置顶评论

## 二、抖音评论话术

### 1. 置顶评论引导
```
需要清单的朋友们直接丝喔～
需要清单的朋友们评论区打个"需要"
```

### 2. 回复评论引导私信
- 用表情包回复，引导客户主动私聊
- 给主动私信的人直接回复导流话术
- 回复评论+进主页私信导流话术

### 3. 小号钩子话术
```
博主讲的太实用了，想深入请教一下，能留个联系方式吗？
兄弟们，博主建了个交流群，可以点主页进群一起交流下
```

### 4. 主页导流方式
- 创建公开群在主页展示，设置群公告，群内发导流话术
- 主页简介挂微信号（使用谐音）
- 背景图p上微信号
- 主页置顶导流的图文作品

## 三、小红书评论话术

### 1. 群聊导流（大小号配合）
群名可设为：`微信号/需要清单方案的看这里`

#### 操作步骤：
1. 准备小号发布引流图文，将小号拉入群聊
2. 用小号将引流笔记分享到群内并在群内置顶
3. 将进群欢迎语设置成引导话术，引导看群置顶笔记
4. 群内发布图片进行引流
5. 把群聊关联笔记，他人可通过笔记直接进群

#### 评论区引导：
- 置顶群链接
- 如审核不通过不可置顶，评论：`需要清单的家人们看这里`
- 在置顶的评论下面回复群链接

### 2. 主页打卡导流
通过他人的主页打卡模板设置自己的打卡内容

### 3. 蓝V助理号导流
- 开一个蓝V号留账号白名单作为助理号
- 其他号评论区艾特小助理，引到小助理号上进行回复

## 五、注意事项

1. **避免敏感词汇**：微信、电话、米钱等词必须用谐音替代
2. **表情辅助**：适当使用emoji可以降低被检测风险
3. **自然互动**：避免刷屏式引导，保持正常社交互动
4. **多账号配合**：大号引导+小号互动效果更好
5. **及时更新**：平台规则变化时需相应调整话术
