# 一夜持股法（2026优化版）
## 超短线交易系统

---

## 一、策略定位与适用市场

**核心理念：** 尾盘14:30-14:50买入，次日9:15-10:15卖出，隔夜持股，利用T+1规则博取隔夜情绪溢价，靠胜率+复利实现稳定盈利。

**适用市场：**
| 市场环境 | 适用性 | 仓位建议 |
|----------|--------|----------|
| 上证创阶段性新高 + 成交>2万亿 + 热点明确 | 最佳 | 60%~80% |
| 震荡市，涨跌互现 | 可操作 | 40%~50% |
| 大盘单边下跌，热点散乱 | 不操作 | 0%（空仓） |
| 批量跌停，情绪恐慌 | 禁止 | 0% |

**禁止场景：**
- 大盘连续下跌超过3天
- 全市场跌停家数 > 50只
- 无明确热点主线
- 持仓股突发利空公告

---

## 二、每日执行流程

T日 14:00  → 市场环境评分 → 确定仓位
T日 14:30  → 筛选备选标的
T日 14:50  → 买入（最多5只）
T+1日 9:15 → 竞价观察
T+1日 9:30-10:15 → 分批卖出
T+1日 10:15前 → 全部清仓
T+1日收盘 → 复盘记录

---

## 三、市场环境评分（每日必做）

**14:00执行，评分决定当日仓位：**

| 评分维度 | 加分（+1分） | 减分（-1分） |
|----------|-------------|-------------|
| 指数 | 创阶段性新高/站上均线 | 跌破均线/创新低 |
| 量能 | 较前日放量/持续>2万亿 | 缩量/量能萎缩 |
| 情绪 | 上涨家数>下跌家数1/3 | 跌多涨少/涨停>50只 |
| 热点 | 有明确主线≥3只涨停 | 无主线/热点散乱 |
| 外部 | 无重大利空/外盘稳定 | 有利空/外盘大跌 |

**仓位对照：**
| 综合评分 | 仓位建议 | 单只仓位 |
|----------|----------|----------|
| 8-10分 | 70%~80% | 10%~15% |
| 5-7分 | 40%~50% | 8%~10% |
| 3-4分 | 20%~30% | 5%~8% |
| 0-2分 | 0%（空仓） | 不操作 |

## 四、选股标准（8+3条件）

**筛选时间：** T日 14:30开始

### 基础条件（全部满足）

| # | 条件 | 标准 | 筛选理由 |
|---|------|------|----------|
| 1 | 涨幅区间 | 3% ≤ 涨幅 ≤ 8% | 低于3%动力不足，超过8%高位接盘 |
| 2 | 量比 | > 1.5 | 资金关注度高，活跃度强 |
| 3 | 换手率 | > 3% | 市场参与度强 |
| 4 | 流通市值 | < 100亿 | 小盘股弹性更大 |
| 5 | 成交量形态 | 上涨时放量，健康量能 | 资金持续流入 |
| 6 | 分时走势 | 全天运行在均线上方，强于大盘 | 主力控盘，独立性强势 |
| 7 | 尾盘形态 | 14:30后创日内新高，回踩不破均线 | 资金尾盘持续流入，次日延续 |
| 8 | 涨幅确认 | 14:30前涨幅已≥3% | 走势已确认，避免尾盘急拉陷阱 |

### 附加条件（优先满足）

| # | 条件 | 标准 | 筛选理由 |
|---|------|------|----------|
| 9 | 板块归属 | 属于当日热点板块（前3龙头） | 资金聚焦，溢价更高 |
| 10 | 消息催化 | 当日有实质性利好公告 | 隔夜情绪有支撑 |
| 11 | 涨停基因 | 20天内有涨停记录 | 股性活跃，主力认可 |

### 排除条件（一票否决）

- 尾盘5分钟内直线拉升（主力做收盘价）
- 涨停打开又封回（抛压重）
- 大盘跳水时逆势拉升（补跌风险）
- 涨幅超过8%（高位接盘）
- 属于当日跌幅前10板块
- 有减持/限售股解禁等利空

**筛选原则：** 全部满足基础条件 + 尽可能满足附加条件 + 无排除项 = 目标标的

## 五、买入规则

### 买入时间
执行窗口：14:30-14:50
原因：14:30前走势已确认稳定，避免尾盘急拉陷阱

### 买入操作

| 规则 | 具体要求 |
|------|----------|
| 下单方式 | 市价委托（确保快速成交） |
| 单只仓位 | 按评分结果确定（8%~15%） |
| 总仓位上限 | 按评分结果确定（最高80%） |
| 分仓数量 | 最多5只，每只等权配置 |
| 不可满仓 | 始终保留≥20%子弹 |

### 仓位计算公式
单只买入金额 = 总资金 × 仓位比例 / 标的数量

---

## 六、卖出规则

### 次日卖出决策树

竞价观察（9:15-9:25）：
- 高开 ≥ +3%：持有，9:30后冲高时分批出
- 高开 < +3%：9:30后直接出，10:00前完成
- 平开：观察5分钟，10:00前出
- 低开 ≥ -3%：集合竞价直接出
- 低开 < -3%：开盘即出止损

### 动态止盈标准

| 市场环境 | 止盈区间 | 操作 |
|----------|----------|------|
| 强势市场（评分≥7） | 3%~8% | 冲高后分批出 |
| 震荡市场（评分5-7） | 2%~5% | 冲高即出 |
| 弱势市场（评分<5） | 1%~3% | 开盘即出 |

### 止损标准

| 亏损幅度 | 动作 |
|----------|------|
| -1.5% | 减半仓（保留观察） |
| -2.5% | 全出（不止损） |
| 任何情况超-3% | 立即清仓 |

### 时间红线
绝对红线：10:15前完成全部卖出

---

## 七、风控熔断机制

触发以下任一条件，立即停止当日操作：

| 熔断条件 | 触发动作 |
|----------|----------|
| 单日亏损 > 2% | 当日停止操作 |
| 单周亏损 > 5% | 本周停止操作 |
| 大盘连续下跌 > 3天 | 空仓等待 |
| 持仓股突发利空 | 开盘无条件清仓 |
| 市场跌停家数 > 80只 | 立即降仓至20%以下 |
| 外部重大利空 | 空仓等待事件平息 |

## 八、复盘流程

T+1日收盘后必做：

1. 盈亏统计：每只股票实际盈亏金额和比例
2. 执行情况：是否严格遵守买卖时间、仓位、止盈止损
3. 选股复盘：选股条件是否全部满足，选错原因
4. 错误记录：执行偏差、情绪化操作、违规操作
5. 熔断检查：是否触发熔断条件
6. 策略调整：根据本周表现调整下周策略

---

## 九、策略核心纪律

1. 每天只操作一次 - 尾盘买入，早盘卖出
2. 不符合条件不开仓 - 没有符合条件的股票就空仓
3. 时间红线不可破 - 14:30前不买，10:15后不持
4. 仓位按评分来 - 不凭感觉重仓或空仓
5. 止损不止损 - 触发止损线必须执行，不扛单
6. 分仓控风险 - 单只不超过15%，总仓位不超过80%
7. 熔断即停 - 触发熔断条件立即停止，不侥幸
8. 复盘必做 - 每天收盘记录，不总结就无法进步

- [ ] 评估外部环境

- [ ] 打开涨幅榜，筛选涨幅3%-8%
- [ ] 逐项核对8项基础条件
- [ ] 确认板块属于热点主线
- [ ] 确认无排除项
- [ ] 确认有涨停基因或消息催化
- [ ] 确认分时走势强于大盘

- [ ] 市价委托下单
- [ ] 记录买入时间和价格

### T+1日 9:15 - 竞价观察
- [ ] 观察持仓股竞价情况
- [ ] 对照卖出决策树

### T+1日 9:30-10:15 - 卖出
- [ ] 执行分批卖出
- [ ] 记录实际成交价格

### T+1日收盘 - 复盘
- [ ] 统计盈亏
- [ ] 对比执行情况
- [ ] 记录问题和改进

**策略本质：**
不追求卖在最高点，不幻想一夜暴富，只赚早盘冲高的确定性差价，靠大概率的小盈利+严格纪律+长期复利，实现账户稳定增长。

选股方法可以学会，执行纪律才是能否盈利的关键。

- mx-search：搜索热点板块、涨停股、消息面
- mx-data：获取股票行情数据

- mx-moni：执行模拟交易
