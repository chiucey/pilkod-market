## 第一章 总则

### 1.1 清单目的

为确保中国区域政策研究的完整性和系统性，本清单规定了各类政策研究必须检索的政策类型。任何基于本skill完成的研究报告，必须覆盖清单中的必检政策类型。

### 1.2 清单结构

本清单按政策体系分类，共包含七大类必检政策：

| 类别编号 | 类别名称 | 检索优先级 |
|----------|----------|------------|
| 第一类 | 规划类政策 | ★★★★★ 必检 |
| 第二类 | 法规类政策 | ★★★★★ 必检 |
| 第三类 | 综合性政策 | ★★★★★ 必检 |
| 第四类 | 专项政策 | ★★★★☆ 视主题检索 |
| 第五类 | 实施方案类 | ★★★☆☆ 视主题检索 |
| 第六类 | 重要会议文件 | ★★★☆☆ 参考性检索 |
| 第七类 | 标准与规范 | ★★☆☆☆ 视需要检索 |

### 1.3 检索覆盖原则

#### 1.3.1 层级覆盖原则

根据研究地区的层级，必须同步检索对应层级的上级政策：

| 研究地区层级 | 必须检索的政策层级 |
|--------------|-------------------|
| 区县级 | 区县 + 市级 + 省级 + 国家级 |
| 市级 | 市级 + 省级 + 国家级 |
| 省级 | 省级 + 国家级 |
| 省级区域 | 涉及的所有省份 + 国家级 |
| 国家级 | 仅国家级 |

#### 1.3.2 时间覆盖原则

| 用户选择的时间范围 | 必须覆盖的时间段 |
|-------------------|------------------|
| 3年 | 近3年政策 + 重要历史政策（背景参考） |
| 5年 | 近5年政策 + 上一个五年规划周期 |
| 10年 | 近10年政策 + 两个五年规划周期 |
