# 中国区域政策研究报告撰写规范

**版本**: v1.0
**制定单位**: 政策研究标准化小组
**生效日期**: 2026年1月

---

## 第一章 总则

### 1.1 规范目的

为确保中国区域政策研究报告的专业性、准确性和可读性，特制定本撰写规范。所有基于本skill生成的政策研究报告，必须严格遵循本规范的要求。

### 1.2 适用范围

本规范适用于以下类型报告的撰写：

- 区域政策研究分析报告
- 产业发展政策研究报告
- 城市规划与土地利用政策研究
- 区域协调发展研究报告
- 政策对标分析报告
- 政策趋势预测报告

### 1.3 基本原则

本规范确立以下四项基本原则，所有报告撰写必须以此为准则：

| 原则编号 | 原则名称 | 核心要求 |
|----------|----------|----------|
| 原则一 | 来源可追溯 | 只写有来源的内容 |
| 原则二 | 引用规范化 | 统一行内引注格式 |
| 原则三 | 事实与分析分离 | 明确区分两类内容 |
| 原则四 | 政策关联标注 | 规范化引用格式 |

## 第二章 来源管理规范

### 2.1 来源可追溯原则

**核心要求**：所有陈述性内容必须附带明确的政策来源依据。

#### 2.1.1 可用来源类型

| 来源类型 | 权威等级 | 使用建议 |
|----------|----------|----------|
| 中央政府文件 | ★★★★★ | 首选来源 |
| 国务院及各部委文件 | ★★★★★ | 首选来源 |
| 省级人大立法 | ★★★★☆ | 重要依据 |
| 省级政府文件 | ★★★★☆ | 重要依据 |
| 市级政府文件 | ★★★☆☆ | 补充参考 |
| 区县级政府文件 | ★★☆☆☆ | 视情况使用 |
| 新闻媒体报道 | ★☆☆☆☆ | 仅作背景参考 |

#### 2.1.2 禁用情况

以下情况严禁写入报告：

- 未经核实的网络信息
- 社交媒体流传的未经证实的政策内容
- 已过期失效的政策
- 与现行政策明显冲突的旧政策（作为历史对比除外）

### 2.2 行内引注格式

#### 2.2.1 基础引注格式

所有行内引用必须采用以下标准格式：

```
[政策全称]（[发布机构]，[发布时间]，[文件编号]）
```

**示例**：

```
国务院关于加快建设全国统一大市场的意见（国务院，2022年4月，国发〔2022〕7号）
```

#### 2.2.2 不同引用场景格式

| 场景 | 格式 | 示例 |
|------|------|------|
| 首次引用 | 完整格式 | 国务院关于印发《十四五数字经济发展规划》的通知（国务院，2022年1月，国发〔2022〕3号） |
| 后续引用 | 简化格式 | 《十四五数字经济发展规划》 |
| 多次引用同一文件 | 首次完整+后续简化 | 首次：[全称]（机构，年份）<br>后续：同上文件 |
| 引用条款 | 带条款引用 | 《中华人民共和国乡村振兴促进法》第三十二条 |

#### 2.2.3 引用校验要求

撰写引用时必须完成以下校验：

- [ ] 政策全称准确无误
- [ ] 发布机构名称规范
- [ ] 发布时间（含年月）正确
- [ ] 文件编号完整准确
- [ ] 来源链接有效

## 第三章 内容撰写规范

### 3.1 事实与分析分离

#### 3.1.1 事实性内容界定

以下内容属于事实性内容，必须基于政策原文：

- 政策明确的条文规定
- 政策规定的具体指标数字
- 政策确定的时间节点
- 政策赋予的具体权利义务
- 政策的程序性规定

**标注方式**：直接撰写，无需特殊标注，但需确保来源准确。

#### 3.1.2 分析性内容界定

以下内容属于分析性内容，需要明确标注：

- 对政策意图的解读
- 政策效果的分析预测
- 政策趋势的研判
- 不同政策的比较分析
- 政策优劣势评价

**标注方式**：在分析内容前增加「分析认为：」或「研究表明：」等引导语。

#### 3.1.3 预测性内容界定

以下内容属于预测性内容，需要特别标注：

- 对未来政策走向的预判
- 对政策效果的预先评估
- 对政策调整的推测

**标注方式**：

```
基于现有政策的分析，未来可能[预测内容]
或
根据政策发展趋势，预计[预测内容]
```

### 3.2 政策关联引用格式

#### 3.2.1 政策层级关联

| 关系类型 | 格式 | 示例 |
|----------|------|------|
| 上位政策依据 | [下位政策]依据[上位政策]制定 | 《北京市十四五规划》依据《北京市城市总体规划（2016年-2035年）》制定 |
| 下位政策落实 | [上位政策]由[下位政策]落实 | 《国家数字经济发展战略》由《北京市数字经济促进条例》落实 |
| 同级政策协同 | [政策A]与[政策B]协同推进 | 《长三角一体化发展规划》与《粤港澳大湾区发展规划》形成区域协同 |

#### 3.2.2 政策时间关联

| 关系类型 | 格式 | 示例 |
|----------|------|------|
| 政策延续 | [新政策]延续[旧政策] | 《新能源汽车产业发展规划（2021-2035年）》延续《节能与新能源汽车产业发展规划（2012-2020年）》 |
| 政策修订 | [新政策]修订[旧政策] | 《中华人民共和国个人信息保护法》修订并替代《全国人民代表大会常务委员会关于加强网络信息保护的决定》 |
| 政策废止 | [新政策]废止[旧政策] | 《市场准入负面清单（2022年版）》废止《市场准入负面清单（2020年版）》 |

## 第四章 报告结构规范

### 4.1 标准报告结构

#### 4.1.1 封面信息

报告封面应包含以下信息：

```
[地区] [主题] 政策研究报告

研究周期：[起始年]年[起始月] - [结束年]年[结束月]
报告生成日期：[YYYY年MM月DD日]
研究层级：[国家级/省级/市级/多层级]
```

#### 4.1.2 目录结构

```
第一章 执行摘要
第二章 研究背景与方法
  2.1 研究背景
  2.2 研究范围界定
  2.3 研究方法
  2.4 数据来源说明
第三章 政策宏观环境分析
  3.1 国家层面政策梳理
  3.2 政策体系架构
  3.3 政策演变历程
第四章 区域政策深度分析
  4.1 [省份/城市]政策概述
  4.2 重点政策详细解读
  4.3 政策实施机制分析
  4.4 政策创新亮点
第五章 政策比较分析
  5.1 区域横向比较
  5.2 政策层级纵向比较
  5.3 差异因素分析
第六章 政策发展趋势预测
  6.1 时间维度趋势
  6.2 内容维度趋势
  6.3 体制机制创新趋势
第七章 结论与建议
  7.1 主要研究结论
  7.2 政策建议
  7.3 研究局限与展望
参考文献
附录
```

### 4.2 各章节撰写要点

#### 4.2.1 执行摘要

**字数要求**：300-500字

**必须包含**：

- 研究目的与背景（一句话）
- 研究范围（地区+主题+时间）
- 主要政策发现（3-5条核心结论）
- 关键趋势判断
- 主要建议（1-3条）

**禁止包含**：

- 详细的政策罗列
- 具体的数字表格
- 复杂的分析过程

#### 4.2.2 研究背景与方法

**必须说明**：

- 为什么选择该地区和主题进行研究
- 研究的时间范围及选择依据
- 采用的研究方法
- 数据来源及可靠性说明
- 研究边界与局限性预判

#### 4.2.3 政策宏观环境分析

**撰写要点**：

- 系统梳理国家层面相关政策
- 明确政策体系的层级关系
- 梳理政策演变的历史脉络
- 分析宏观政策对区域的影响

**常见错误**：

- 简单罗列政策，缺乏分析
- 忽略政策之间的关联
- 遗漏重要政策类型

#### 4.2.4 区域政策深度分析

**撰写要点**：

- 按政策类型或时间维度分类阐述
- 解读核心政策的主要内容和创新点
- 分析政策的实施路径和保障措施
- 评估政策的执行效果

#### 4.2.5 政策比较分析

**比较维度**：

| 比较维度 | 比较内容 |
|----------|----------|
| 区域横向比较 | 不同地区同类政策的差异 |
| 层级纵向比较 | 不同层级政策的衔接与差异 |
| 时间纵向比较 | 同一政策的演变发展 |
| 类型横向比较 | 不同类型政策的协调性 |

#### 4.2.6 趋势预测

**撰写规范**：

- 必须基于已有政策的明确导向
- 分析认为部分需明确标注
- 避免过度推测
- 区分短期趋势和长期趋势

#### 4.2.7 结论与建议

**结论撰写要求**：

- 结论必须有政策来源支撑
- 结论必须与前文分析呼应
- 结论应具有前瞻性和指导性

**建议撰写要求**：

- 建议必须针对具体问题
- 建议必须具有可操作性
- 建议应区分短期和中长期

## 第五章 质量控制规范

### 5.1 降AI味自查清单

在提交最终报告前，必须逐项完成以下检查：

#### 5.1.1 表述质量检查

- [ ] 是否存在过多的绝对化表述（如"全面实现"、"彻底解决"、"完美"）
- [ ] 是否使用了human写作常见的过渡语（如"值得注意的是"、"众所周知"）
- [ ] 是否存在过于工整的排比句式
- [ ] 是否存在不自然的程度副词堆砌

#### 5.1.2 内容深度检查

- [ ] 是否停留在政策表面描述
- [ ] 是否有深度的政策解读和分析
- [ ] 是否缺少对政策实际效果的讨论
- [ ] 是否有批判性思考和问题意识

#### 5.1.3 逻辑连贯性检查

- [ ] 章节之间的逻辑关系是否清晰
- [ ] 结论是否与前文分析一致
- [ ] 建议是否针对报告发现的问题

### 5.2 质量自检清单

#### 5.2.1 来源准确性

- [ ] 所有引用政策均已核实来源
- [ ] 政策元数据（名称、机构、时间、编号）完全准确
- [ ] 引用链接均为有效链接

#### 5.2.2 内容完整性

- [ ] 报告结构完整，无缺项
- [ ] 必检政策类型均已覆盖
- [ ] 重要政策均有解读

#### 5.2.3 格式规范性

- [ ] 术语使用准确规范
- [ ] 引用格式统一
- [ ] 标点符号使用正确
- [ ] 标题层级清晰

#### 5.2.4 事实一致性

- [ ] 无事实性错误
- [ ] 无自相矛盾的内容
- [ ] 数字引用前后一致

## 第六章 附录规范

### 6.1 参考文献格式

#### 6.1.1 政策文件引用格式

```
[序号]. [政策全称]（[发布机构]，[发布时间]，[文件编号]）
[来源链接]
```

**示例**：

```
1. 国务院关于加快建设全国统一大市场的意见（国务院，2022年4月10日，国发〔2022〕7号）
https://www.gov.cn/zhengce/content/202204/content_5684595.htm
```

#### 6.1.2 排序规则

- 按政策层级从高到低排序
- 同层级按发布时间从新到旧排序
- 同一政策按引用顺序排列

### 6.2 附录内容建议

以下内容建议纳入附录：

- 完整政策清单（Excel格式）
- 重要政策全文
- 政策对比表格
- 数据来源详细说明
- 研究方法补充说明
