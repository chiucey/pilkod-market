# 中国区域政策研究与分析系统

## 系统概述

本技能为用户提供中国大陆特定区域特定主题的政策检索与分析服务。通过分级网络检索、政策来源校审和相关度筛选，系统自动生成政策清单索引、政策全文汇编和政策趋势报告。

**触发方式**：输入地名+政策主题（如"北京市 人工智能产业"），选择时间范围和研究目的。

## 工作流程

### 第一阶段：需求确认

1. **解析用户输入**
   - 识别目标地区（省/市/区/县）
   - 识别政策研究主题
   - 确认时间范围（3年/5年/10年）
   - 确认研究目的（综合研究/产业发展/空间规划/制度建设等）

2. **生成任务书**
   - 自动生成标准化任务书
   - 明确检索范围和层级
   - 预估政策数量和类型

3. **目录创建**（Claude Code环境）
   ```
   /02_policy_database/01_full_policy/
   /02_policy_database/02_relevant_policy/
   /06_research_report/01_policy_trend_report/
   ```

### 第二阶段：分级网络检索

**检索策略**：根据用户输入的地名，自动执行本层级及上层级政策检索。

| 用户输入 | 自动检索层级 |
|----------|--------------|
| 北京市 | 北京市 + 国家级 |
| 上海市浦东新区 | 浦东新区 + 上海市 + 国家级 |
| 广东省 | 广东省 + 国家级 |
| 苏州市 | 苏州市 + 江苏省 + 国家级 |

**检索内容**：
- 综合性政策文件
- 专项发展规划
- 实施方案与细则
- 法规与条例
- 领导讲话与解读
- **社保公积金专项政策**（社会保险、住房公积金相关）

**社保公积金专项检索主题**：

| 检索主题 | 包含内容 |
|---------|---------|
| 社会保险 | 养老保险、医疗保险、失业保险、工伤保险、生育保险 |
| 住房公积金 | 缴存、提取、贷款、异地转移接续 |
| 社保公积金基数 | 缴费基数调整、比例规定 |
| 社保公积金待遇 | 养老金、医保报销、公积金提取使用 |
| 社保基金监管 | 基金收支管理、投资运营、风险防控 |
| 弹性用工社保 | 新业态从业人员、灵活就业人员社保 |
| 跨区域社保 | 医保跨省结算、社保关系转移、养老金转移 |

**信息来源优先级**：
1. 政府官方网站（国家发改委、地方政府官网）
2. 法律法规数据库（国家法律法规数据库）
3. 政府信息公开平台
4. 权威政策研究机构

### 第三阶段：政策相关度裁剪

**相关性评估标准**：

| 等级 | 定义 | 处理方式 |
|------|------|----------|
| A级（核心政策） | 直接针对主题的核心政策 | 全文收录，详细分析 |
| B级（关联政策） | 与主题密切相关 | 全文收录 |
| C级（参考政策） | 间接相关或背景性文件 | 摘要收录 |
| D级（低相关） | 相关度较低 | 仅列索引 |

**相关度判断因素**：
- 政策标题关键词匹配度
- 政策内容与主题的关联程度
- 政策发布时间的新鲜度
- 政策发布层级的权威性

### 第四阶段：政策来源校审

**校审内容**：
- 政策名称准确性
- 发布机构信息
- 发布时间核实
- 文件编号验证
- 来源链接有效性
- 备用来源补充

**校审流程**：
1. 逐条核对元数据信息
2. 通过多个渠道交叉验证
3. 自动修正明显错误
4. 对存疑信息进行人工标注

## 报告撰写规范（必须遵守）

### 四项基本原则

**1. 只写有来源的内容**
- 所有陈述必须有明确政策来源
- 禁止凭空推断或假设
- 数据引用需标注来源

**2. 行内引注格式**
```
政策名称（[发布机构]，[发布时间]）
例如：国务院关于加快建设全国统一大市场的意见（国务院，2022年4月）
```

**3. 区分事实与分析**
- 事实性内容：客观描述政策内容
- 分析性内容：明确标注"分析认为"
- 预测性内容：明确标注"基于现有政策，未来可能"

**4. 政策关联引用格式**
```
引用关系：[政策A] → [政策B]（依据/发展/补充）
```

## 常见问题处理

### Q1: 检索结果过多如何处理？
A: 按相关性分级，优先保证A级和B级政策的完整性，C级和D级政策选择性收录。

### Q2: 部分政策找不到原文怎么办？
A: 如无法获取全文，必须录入核心条款摘录，并在备注中说明来源情况。

### Q3: 不同层级政策冲突如何处理？
A: 在报告中客观呈现政策差异，分析冲突原因，并标注相关度。

### Q4: 用户输入地区不明确怎么办？
A: 主动询问确认具体地区范围，必要时提供多个选项供用户选择。

### Q5: 政策时效性如何判断？
A: 结合政策规定的有效期、修订频率和当前实施状态综合判断。

## 注意事项

1. **数据准确性**：所有政策信息必须经过核实，严禁使用未经确认的信息
2. **时效性意识**：政策具有时效性，需关注最新政策动态和修订情况
3. **用户需求导向**：研究重点应围绕用户实际需求，而非泛泛而谈
4. **批判性思维**：既要梳理政策，也要分析政策的实际效果和局限性
5. **持续更新**：如用户需要，可定期更新政策库和研究结论
