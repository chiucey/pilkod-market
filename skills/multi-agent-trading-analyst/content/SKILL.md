# 多智能体交易分析框架

专业级股票分析系统，协调六个专业子智能体进行全方位投资研究。

## 核心子智能体

| 智能体 | 专业领域 | 触发关键词 |
|--------|----------|-------------|
| 📊 基本面分析师 | 财务报表、估值模型、盈利能力、成长性 | 财务数据、估值、利润、收入、ROE、EPS |
| 🎭 情绪分析师 | 市场情绪、资金流向、投资者信心 | 情绪、资金流向、北向资金、融资融券 |
| 📰 新闻分析师 | 重大事件、政策影响、行业动态 | 新闻、公告、政策、事件、财报发布 |
| 📈 技术分析师 | 图表形态、技术指标、趋势分析 | K线、均线、MACD、RSI、支撑阻力 |
| 🐂🐻 看涨/看跌研究员 | 多空观点、风险收益比、投资逻辑 | 多空、观点、建议、评级、目标价 |
| ⚠️ 风险管理师 | 仓位管理、止损设置、风险敞口 | 风险、止损、仓位、敞口、回撤 |

## 分析工作流程

### 1. 需求解析

解析用户输入，识别所需分析类型：

- **全面分析**：请求综合报告时 → 启动全部6个子智能体
- **专项分析**：仅需某类分析时 → 启动对应子智能体
- **组合分析**：投资组合评估 → 风险管理师主导，其他辅助

### 2. 子智能体委托

使用 `Task` 工具并行或按序委托子智能体：

```
分析类型 → 并行/串行委托 → 结果聚合
```

**并行委托场景**：全面分析、快速概览
**串行委托场景**：风险评估优先、逐步深入

### 3. 结果聚合与输出

综合各子智能体输出，生成结构化分析报告：

- 执行摘要（核心结论）
- 详细分析（各维度）
- 投资建议（明确观点）
- 风险提示（下行保护）

## 质量标准

- 数据时效性：优先使用最新可用数据
- 观点平衡性：必须呈现多空双方观点
- 风险提示：任何投资建议必须包含风险提示
- 量化依据：关键结论需有数据支撑

## 触发条件

此技能在以下场景自动激活：

1. 用户询问特定公司/股票的研究分析
2. 用户请求投资组合评估或风险分析
3. 用户要求技术分析或基本面分析
4. 用户需要市场情绪评估或新闻解读
5. 用户请求综合投资报告或交易建议
6. 用户询问特定行业的投资机会或风险

## 注意事项

- 明确标注信息来源和时效性
- 区分事实陈述与观点推测
- 强调历史业绩不代表未来表现
- 建议仅供参考，不构成投资建议
