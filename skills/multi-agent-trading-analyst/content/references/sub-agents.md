# 多智能体交易分析框架 - 子智能体参考文档

## 子智能体详细规格

### 1. 基本面分析师 (Fundamental Analyst)

**核心职责**：
- 财务指标分析（营收、利润、毛利率、净利率）
- 估值模型构建（DCF、PE、PB、PS）
- 盈利能力评估（ROE、ROA、ROIC）
- 成长性分析（营收增速、利润增速）
- 资产负债表健康度评估

**数据来源**：
- 财务报告（季报、年报）
- 分析师预期
- 行业对比数据

**输出格式**：
```
## 基本面分析

### 核心财务指标
| 指标 | 最新 | 同比 | 行业均值 |
|------|------|------|----------|
| 营收增速 | XX% | +Xpp | XX% |
| 净利润增速 | XX% | +Xpp | XX% |
| 毛利率 | XX% | +Xpp | XX% |
| 净利率 | XX% | +Xpp | XX% |
| ROE | XX% | +Xpp | XX% |

### 估值分析
- 当前PE: XX倍 (历史分位: XX%)
- 当前PB: XX倍 (历史分位: XX%)
- 目标价: XX元 (基于XX模型)

### 盈利预测
- 2024E EPS: XX元 (+XX%)
- 2025E EPS: XX元 (+XX%)

### 投资亮点
1. ...
2. ...

### 潜在风险
1. ...
2. ...
```

### 2. 情绪分析师 (Sentiment Analyst)

**核心职责**：
- 市场情绪量化评估
- 资金流向追踪（北向资金、主力资金）
- 融资融券余额分析
- 筹码分布分析
- 情绪周期判断

**情绪指标体系**：
| 指标 | 说明 | 阈值 |
|------|------|------|
| 市场情绪指数 | 综合情绪打分 | 0-100 |
| 资金净流入率 | 主力资金占比 | >5%强势 |
| 融资融券比 | 杠杆资金偏好 | >1.5偏多 |
| 换手率分位 | 活跃度评估 | >80%高活跃 |

**输出格式**：
```
## 市场情绪分析

### 整体情绪评估
- 情绪指数: XX/100 (区间: 乐观/中性/悲观)
- 情绪趋势: [近5日走势描述]

### 资金流向
- 北向资金(近5日): XX亿元 [净买入/净卖出]
- 主力净流入: XX亿元
- 融资余额: XX亿元 (+XX亿)

### 筹码分布
- 持仓成本区间: XX-XX元
- 筹码集中度: [集中/分散]

### 情绪信号
- ✓ 信号1: ...
- ✗ 信号2: ...

### 情绪研判
[综合情绪判断及依据]
```

### 3. 新闻分析师 (News Analyst)

**核心职责**：
- 重大新闻事件识别
- 政策影响评估
- 行业动态追踪
- 突发事件分析
- 新闻情绪量化

**事件分类**：
| 类型 | 影响周期 | 举例 |
|------|----------|------|
| 黑天鹅 | 长期 | 疫情、危机 |
| 重大政策 | 中期 | 行业监管 |
| 公司事件 | 短期 | 业绩发布 |
| 市场传闻 | 短期 | 消息面 |

**输出格式**：
```
## 新闻与事件分析

### 近期重大新闻
| 时间 | 事件 | 影响程度 | 性质 |
|------|------|----------|------|
| YYYY-MM-DD | 事件描述 | 高/中/低 | 正面/中性/负面 |

### 政策环境
- 行业政策: [相关政策及影响]
- 宏观环境: [经济背景分析]

### 事件影响评估
#### 事件1: [标题]
- 影响时间: 短期/中期/长期
- 影响程度: [量化评估]
- 股价反应: [历史案例参考]

### 新闻情绪
- 近期新闻情感: [正面/负面/中性] (占比XX%)
- 市场预期调整: [方向及幅度]

### 投资提示
[基于新闻事件的投资建议]
```

### 4. 技术分析师 (Technical Analyst)

**核心职责**：
- 趋势分析（短期、中期、长期）
- 形态识别（头肩顶、三角形等）
- 技术指标分析（MA、MACD、RSI、KDJ）
- 支撑阻力位确定
- 量价关系分析

**技术指标体系**：
| 指标 | 参数 | 信号说明 |
|------|------|----------|
| MA | 5/10/20/60日 | 金叉/死叉 |
| MACD | 12/26/9 | DIF/DEA交叉 |
| RSI | 14日 | 超买/超卖 |
| KDJ | 9/3/3 | 金叉/死叉 |
| BOLL | 20/2σ | 轨道突破 |

**输出格式**：
```
## 技术面分析

### 趋势判断
- 短期趋势: [上升/下降/震荡] (均线: MA5>MA10? / MA10>MA20?)
- 中期趋势: [上升/下降/震荡]
- 长期趋势: [上升/下降/震荡]

### 关键位置
- 强支撑位: XX元 [理由]
- 弱支撑位: XX元
- 强压力位: XX元
- 弱压力位: XX元

### 技术信号
| 指标 | 当前值 | 信号 |
|------|--------|------|
| MA5 | XX元 | [多头/空头排列] |
| MACD | XX | [金叉/死叉] |
| RSI(14) | XX | [超买/中性/超卖] |
| KDJ | XX | [金叉/死叉] |

### 形态分析
- 当前形态: [形态名称]
- 形态目标: XX元
- 形态可靠性: [高/中/低]

### 量价分析
- 近期量能: [放量/缩量/平量]
- 量价配合: [健康/背离]

### 技术研判
[综合技术面判断及交易建议]
```

### 5. 看涨/看跌研究员 (Bullish/Bearish Researcher)

**核心职责**：
- 多空观点系统梳理
- 风险收益比评估
- 催化剂识别
- 投资逻辑构建
- 目标价位设定

**评级体系**：
| 评级 | 建议 | 持有期 |
|------|------|--------|
| 强烈推荐 | 积极买入 | 短线+中线 |
| 推荐 | 适量买入 | 中线 |
| 中性 | 持有观望 | 观望 |
| 谨慎 | 减持 | 短线 |
| 回避 | 卖出 | 立即离场 |

**输出格式**：
```
## 多空观点分析

### 综合评级
**评级**: [强烈推荐/推荐/中性/谨慎/回避]
**目标价**: XX元 (当前价XX元, 上涨空间XX%)
**建议仓位**: XX%
**持有建议**: [时间框架]

### 支持做多的理由 (Bull Case)
1. **[逻辑1]**: [详细阐述]
   - 催化剂: [可能的触发因素]
   - 潜在空间: [量化预期]

2. **[逻辑2]**: [详细阐述]
   - 催化剂: [可能的触发因素]
   - 潜在空间: [量化预期]

### 支持做空的理由 (Bear Case)
1. **[逻辑1]**: [详细阐述]
   - 风险点: [可能的下跌因素]
   - 潜在跌幅: [量化预期]

2. **[逻辑2]**: [详细阐述]
   - 风险点: [可能的下跌因素]
   - 潜在跌幅: [量化预期]

### 风险收益比
- 上涨空间: XX% (当前价→目标价)
- 下跌风险: XX% (当前价→止损价)

[明确的投资观点及理由]

### 6. 风险管理师 (Risk Manager)

**核心职责**：
- 整体风险评估
- 仓位管理建议
- 止损策略制定
- 风险敞口计算
- 回撤控制方案

**风险评估维度**：
| 维度 | 评估内容 | 权重 |
|------|----------|------|
| 市场风险 | 系统性风险暴露 | 30% |
| 个股风险 | 非系统性风险 | 25% |
| 流动性风险 | 交易活跃度 | 15% |
| 杠杆风险 | 融资/杠杆使用 | 15% |
| 时间风险 | 持仓周期风险 | 15% |

**输出格式**：
```
## 风险评估与管理

### 综合风险评级

## 子智能体协调机制

### 并行分析模式
适用于：全面分析、快速概览
```
用户请求 → Task(基本面) ‖ Task(情绪) ‖ Task(新闻) ‖ Task(技术) ‖ Task(多空) ‖ Task(风险)
                    ↓            ↓            ↓            ↓            ↓            ↓
                 结果A        结果B        结果C        结果D        结果E        结果F
                                        ↓综合聚合↓
                                    最终报告
```

### 串行分析模式
适用于：风险优先、逐步深入
```
用户请求 → [风险评估] → [基本面验证] → [技术确认] → 最终建议
```

### 按需分析模式
适用于：单一维度请求
```
用户: "帮我分析XXX的技术面" → Task(技术分析师) → 技术分析报告
```

## 数据获取优先级

1. **实时数据**：当前股价、成交量、资金流向
2. **近期数据**：近1月/3月/6月行情
3. **基本面数据**：最新财报、业绩预告
4. **新闻数据**：近期重大公告、新闻
5. **历史数据**：长期历史行情用于技术分析
