## 四种经典爆款方向

根据产品类型和目标人群，从下面4个方向里挑3个组合。三个方向之间必须在"方向类型 / 钩子打法 / 人物场景"上至少有两个维度不同。

### 方向 A：UGC 真人口播种草（Talking-Head / 闺蜜安利）

- **适合**：美妆个护、家居小物、服饰配饰、3C小配件、食品零食——所有"真人对着镜头讲两句就够了"的产品。
- **人物设定**：目标市场普通用户本人（20-35岁为主），居家/办公室/街头自然场景，手持手机自拍感，穿着日常，不化妆或淡妆，语气像跟朋友吐槽/安利。**不是模特，不是主播**。
- **产品角色**：人物手里举着/在用产品，产品是"我最近发现的宝贝"，不是广告道具。
- **解决什么问题**：解决"没人告诉我这个东西好用"的信任缺口，靠真人情绪和真实感带货。
- **钩子打法**：多使用"反差开场+感叹句"——先抛一个反常识结论或个人吐槽，再亮产品。
- **节奏**：0-3s 钩子吐槽 → 3-8s 痛点共鸣+产品亮相 → 8-12s 现场演示+卖点 → 12-15s CTA。
- **拍摄标准**：竖屏手持，轻微晃动，近景胸上构图，自然光，不要打光棚感；画面有生活痕迹（床上、桌上、咖啡杯）。

### 方向 B：痛点解决剧情（Before / After Problem-Solution）

- **适合**：清洁用品、收纳整理、厨具工具、宠物用品、个护功效类、办公效率工具——所有"有明确痛点场景"的产品。
- **人物设定**：一个"被问题困扰的人"（可以和目标用户同年龄段/同身份，例如宝妈、上班族、学生），前半段表情崩溃/烦躁，后半段表情解放/惊喜。
- **产品角色**：产品是"救星"，在剧情最低谷时登场，一出场问题立刻解决。
- **解决什么问题**：把痛点可视化，让用户在3秒内认出"这就是我"。
- **钩子打法**：先演痛点（画面混乱/人物崩溃），不说话或说一句抱怨，再切产品。
- **节奏**：0-3s 痛点画面+一句吐槽 → 3-8s 尝试失败/更糟 → 8-12s 产品登场+解决 → 12-15s 轻松状态+CTA。
- **拍摄标准**：前后对比强烈——前段光线偏冷/乱，后段光线暖/整洁；多用固定机位中景，关键转折用特写；剪辑节奏前慢后快。

### 方向 C：ASMR / 沉浸式产品演示（No-Talking Demo）

- **适合**：美妆、香水、食品、玩具、厨具、文具、DIY手工——所有"产品本身有声音、有质感、有满足感"的产品。
- **人物设定**：基本不露脸，只出现一双手或局部（手部特写、嘴唇、指尖）。穿着干净简洁。
- **产品角色**：产品是绝对主角，占画面 70% 以上，微距/特写镜头为主。
- **解决什么问题**：靠视觉满足感和 ASMR 声音让用户"手痒想买"，不需要口播解释。
- **钩子打法**：第一帧就是最有冲击力的动作（倒水、掰开、拉丝、挤压、开关、开箱），配合一个让人"嗯？"的音效。
- **节奏**：0-3s 最爽的那个动作先放 → 3-8s 拆解/使用过程多角度 → 8-12s 成品效果/对比 → 12-15s 产品定格+CTA字幕。
- **拍摄标准**：微距+特写，顶光+侧逆光突出质感；慢动作或正常速；环境安静，保留产品原声（撕、捏、倒、咔哒）；BGM 极轻或不用。

### 方向 D：反差 / 搞笑剧情植入（Comedy / Twist）

- **适合**：情绪消费、礼品、新奇小玩意、宠物用品、家居奇葩好物、社交货币型产品。
- **人物设定**：两个角色（"正常人"vs"戏精"，或"被误解的人"vs"懂行的人"），有明确表演感，表情夸张。
- **产品角色**：产品是反转道具——前面看起来没用/奇怪，结尾揭示其实超好用/超懂行。
- **解决什么问题**：靠娱乐性完播率，让用户笑着看完最后记住产品。
- **钩子打法**：反常行为开场（一个人在做奇怪的事，另一个人疑惑），观众好奇"他在干嘛"。
- **节奏**：0-3s 反常行为+疑惑表情 → 3-8s 误会加深/闹笑话 → 8-12s 反转：亮出产品真相 → 12-15s 真相大白+CTA。
- **拍摄标准**：多机位快切，中景+特写交替，表情夸张；喜剧节奏靠剪辑卡点；光线明快，饱和度略高。

## 前3秒钩子库

从下面挑钩子类型时，必须写成"画面 + 第一句话"的完整组合，不能只写钩子名字。**避免**："今天给大家推荐""家人们谁懂啊"这种已经被用烂的开场。

| 钩子类型 | 画面动作 | 第一句话模板（用目标市场语言） |
|---|---|---|
| 反常识结论 | 人物举着产品，挑眉 | "I stopped buying [common thing] after I found this." |
| 个人吐槽 | 人物对着镜头叹气/无奈 | "Why did nobody tell me [pain point] sooner?" |
| 直接演示 | 第一帧就是最爽动作（倒水/掰开） | （无台词，靠动作+音效） |
| 恐吓/损失厌恶 | 展示问题的糟糕后果 | "You're doing [habit] wrong — here's what happens." |
| 身份代入 | 人物正在经历痛点场景 | "If you're a [target user], you need to see this." |
| 数字承诺 | 产品特写+字幕花字 | "3 reasons this [product] is selling out — #2 shocked me." |
| 反差对比 | 左右分屏 before/after | "Same [thing], one costs $50 and one costs $8." |
| 悬念提问 | 人物举着产品神秘笑 | "Guess how much this [product] actually costs." |
| 社会证明暗示 | 镜头扫过一堆同款/评论区 | "Everyone on my FYP is buying this — so I tried it." |
| 直接挑衅 | 人物对镜头摇头 | "Don't buy [category] until you watch this." |

写作时把 `[xxx]` 替换成产品真实信息，**不要留方括号**。

## 四段式情节框架（15秒）

每个大纲方向都按这四段写，30秒版本每段时长翻倍。

| 段落 | 时长 | 任务 | 必须出现 |
|---|---|---|---|
| 钩子 | 0-3s | 留住用户 | 1个画面冲击 + 1句话钩子 |
| 共鸣/痛点 | 3-8s | 让用户认出自己 | 痛点场景或个人故事，产品在3s末或4s处亮相 |
| 卖点证明 | 8-12s | 让用户相信 | 现场演示核心买点 + 1-2个辅助卖点佐证 |
| CTA | 12-15s | 推动行动 | 产品定格 + 一句行动号召（"link in bio / tap to shop / 限定"） |

## 大纲输出卡片模板

阶段1给用户的输出格式。三个方向各一张卡片，字段不要合并、不要省略。

```markdown
## 方向 A：<方向名称，如"闺蜜安利型 UGC 口播">

- **人物设定**：<年龄/身份/穿着/语气，一句话>
- **故事场景**：<具体地点/时间/氛围，一句话>
- **产品角色 & 解决的问题**：<产品在剧情里是什么角色，解决哪个痛点，一句话>
- **前3秒钩子**：
  - 画面：<具体动作/构图>
  - 台词："<目标市场语言的第一句话>"
- **核心买点**：<1句话>
- **辅助卖点**：
  1. <卖点+怎么证明>
  2. <卖点+怎么证明>
  3. <卖点+怎么证明>
- **故事情节框架**：
  - 0-3s：<内容>
  - 3-8s：<内容>
  - 8-12s：<内容>
  - 12-15s：<内容+CTA>
- **拍摄标准**：<景别/运镜/光线/风格关键词，一句话>
```

三张卡片输出完后，补一段"选择建议"：

```markdown
---
**选择建议**：根据<产品类型>和<目标市场>，我个人推荐方向<X>，因为<1-2句理由>。你也可以组合，比如"A的钩子+B的剧情"。请告诉我用哪个方向，或要怎么改。
```

## 方向选择速查

| 产品类型 | 首选 | 备选 |
|---|---|---|
| 美妆个护、香水 | C ASMR | A UGC |
| 家居小物、收纳、清洁 | B 痛点剧情 | A UGC |
| 3C小配件、数码周边 | A UGC | C ASMR |
| 食品、零食 | C ASMR | D 反差 |
| 新奇小玩意、礼品 | D 反差 | C ASMR |
| 宠物用品 | B 痛点 | D 反差 |
| 服饰配饰 | A UGC | C ASMR |
| 厨具、厨房工具 | B 痛点 | C ASMR |

三个方向必须都来自这四个模板，不要自己发明第五种；但可以在模板内做本地化改造（例如方向B改成"欧洲厨房场景"）。
