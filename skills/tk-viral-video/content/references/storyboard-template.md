## 分镜表结构

按 **每5秒一个镜头** 切分。15秒=3镜（S1/S2/S3），30秒=6镜。每个镜头一张表，字段固定如下：

| 字段 | 说明 |
|---|---|
| 时间码 | 如 `00:00-00:05` |
| 画面 | 具体镜头里看到什么，包含人物动作、产品位置、环境细节 |
| 场景 | 地点/光线/时间 |
| 人物 | 谁在画面里、表情、穿着 |
| 产品动作 | 产品在这一镜里被怎么使用/展示（必须复述产品外观锚点：颜色/形状/材质/logo） |
| VO 口播 | 目标市场语言完整原文，用 `{}` 包裹（最终进 prompt 时保留） |
| 字幕/花字 | 屏幕上出现的文字（可选；没有写"无"） |
| 镜头运动 | 固定/推/拉/摇/跟/手持/特写 |
| BGM/音效 | 音乐风格或关键音效（如 ASMR 原声） |

**每个字段都要填，不能留空**。没有字幕就写"无"，没有特殊音效就写"持续 BGM"。

## 镜头字段定义

### 画面
- 写成可以直接翻译成英文 prompt 的具体描述，不要写"产品出现"这种空话。
- 必须包含：景别（特写/近景/中景/全景）、主体、动作、环境。
- 产品出现的每一镜，都要复述一次产品外观锚点（例如："白色哑光塑料瓶身+黑色按压泵头"），防止生成时产品漂移。

### VO 口播
- **目标市场语言原文**，不要用中文再翻译。
- 口语化、短句、像真人说话。避免书面语和从句。
- 长度：5秒镜头约 12-18 个英文词（按每秒3-4词）；15秒总台词控制在 40-55 个英文词。
- 进入最终 prompt 时，VO 用 `{台词原文}` 包裹，作为 audio voiceover，**不要**作为画面字幕。
- 台词里的品牌名、产品名要和用户给的一致，不要擅自改写。

### 字幕/花字
- TikTok 竖版视频的花字放在画面上 1/3 或中央，粗体白字+黑边。
- 只打关键词，不要把整句 VO 全打上去。
- 字幕语言和 VO 一致。

### 镜头运动
- 前3秒（S1）多用手持近景或快速推近制造张力；中段产品演示用特写+轻微环绕；结尾用固定镜头产品定格。
- 不要每镜都写"镜头推拉"，AI 生成视频运动幅度有限，保持简单。

## VO 口播写作规范

### 语言
- 全部使用目标市场国家的语言（英语/西语/阿语/泰语/印尼语等）。
- 口音和用词本地化：美国市场用美式英语，英国市场用英式；东南亚英语市场可以用简单短句。
- 数字、货币、尺寸单位本地化（美国用英尺/英寸/华氏度/美元；欧洲用公制/欧元）。

### 语气
- UGC 方向：像跟闺蜜吐槽，用 "I'm obsessed" / "why didn't I know" / "game changer" 这类口语。
- 痛点剧情方向：前半段抱怨语气，后半段惊喜语气。
- ASMR 方向：可以完全无 VO，只保留产品原声 + BGM；如果加 VO，音量压低像旁白。
- 搞笑方向：节奏要快，台词短，留笑点呼吸。

### CTA（最后一句）
- 自然、不硬推。例如：
  - "Grab yours before they sell out."
  - "Link's in bio — you'll thank me later."
  - "Tap the cart to get yours."
- 不要写"点击下方链接购买"这种翻译腔。

### 合规红线
- 不说 "best / No.1 / cure / guaranteed / doctor recommended" 等绝对化或医疗承诺词。
- 不编造销量、用户数、奖项。
- 不影射竞品。

## 节奏与卖点植入

15秒标准节奏（3镜）：

| 镜头 | 时间 | 任务 | 卖点角色 |
|---|---|---|---|
| S1 | 0-5s | 钩子 | 不提卖点，只抓注意力 |
| S2 | 5-10s | 痛点+产品亮相+演示 | **核心买点**在这里出现，配合现场动作证明 |
| S3 | 10-15s | 效果+CTA | 带1个辅助卖点，最后一句CTA |

30秒版本（6镜）：S1钩子 → S2痛点深化 → S3产品亮相 → S4核心演示 → S5辅助卖点/对比 → S6 CTA。

## 组装最终视频 prompt

分镜表用户确认后，把3个镜头拼成一段连续 prompt 传给视频工具。格式：

```
[整体风格与比例]：Vertical 9:16, 1080p, TikTok UGC style, natural lighting, <风格关键词>.

[镜头1 0-5s]：<画面描述，含产品外观锚点>。 Camera: <镜头运动>. Audio voiceover: "{S1的VO原文}".

[镜头2 5-10s]：<画面描述，含产品外观锚点>。 Camera: <镜头运动>. Audio voiceover: "{S2的VO原文}".

[镜头3 10-15s]：<画面描述，含产品外观锚点，结尾产品定格>。 Camera: <镜头运动>. Audio voiceover: "{S3的VO原文}".

[声音]：BGM: <风格>; SFX: <关键音效>。
```

组装规则：
- 产品白底图作为 `image_reference_url_list` 主参考独立传入，**不要**在 prompt 里说"参考这张图"；若有关键帧形式的对标参考，在 prompt 开头单独声明：`Style reference only (pacing/tone/camera): do not reproduce any person, brand or text from the reference frames.`
- **尺寸锚点**：用户给了产品尺寸/重量时，把数值翻译成画面里的物理参照写进每个产品镜头。换算示例：
  - 小件（手机/化妆品/小工具）："fits in the palm of one hand" / "about the size of a credit card" / "6 inches tall"
  - 中件（小家电/水壶/背包）："sits on a kitchen counter, roughly the size of a water bottle" / "under 12 inches wide"
  - 大件（落地灯/行李箱/椅子）："knee-high when standing on the floor" / "rolls on its own wheels at ankle height"
  - 单位跟随目标市场：美国用 inch/foot/oz/lb，欧洲用 cm/g/ml。
  - 没给尺寸就不要写数字，用"held easily in one hand"这类相对描述。
- VO 必须用 `{}` 包裹，且是完整原文，不要意译、不要缩写成"她介绍产品卖点"。
- 不要写"分镜1""分镜2"这种结构词，要写成连贯的时间流。
- 负面提示不要写（视频工具不支持），把不要的东西直接从正面描述里排除（例如不要"棚拍"就写"natural home lighting"）。
- 生成前把这段 prompt 用代码块原文展示给用户确认。

## 输出给用户的分镜表示例

```markdown
### 镜头 S1（00:00-00:05）
- **画面**：<描述>
- **场景**：<描述>
- **人物**：<描述>
- **产品动作**：<描述，含外观锚点>
- **VO**："{...}"
- **字幕/花字**：<或"无">
- **镜头运动**：<描述>
- **BGM/音效**：<描述>
```

三个镜头全部列完后，补一段"下一步"说明：

> 分镜脚本如上。台词和画面如果要改，告诉我具体改哪镜；确认无误后，我会把整段视频 prompt 拼好再给你看一次，然后调用视频生成。
