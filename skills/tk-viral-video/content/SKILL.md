# 跨境 TK 爆款短视频

## 定位

本技能是**跨境 TikTok / TikTok Shop 带货短视频**的端到端创作工作流，把用户的"产品白底图 + 大白话创意"转化为可投放的 mp4 视频。它是一个编排层：创意方法论和分镜规范在本技能内，最终视频生成调用底层 `image_to_video` / `text_to_video` 工具，产品白底图作为 `product_ref` 保证产品一致性。

固定四阶段，**每阶段必须用户确认后才进入下一阶段**：

```
输入收集 → 阶段1: 输出≥3个拍摄大纲方向 → 用户选/改 → 阶段2: 分镜脚本 → 用户确认 → 阶段3: 生成视频mp4 → 交付
```

## 输入收集门控（开工前必查）

开始创作前，必须收齐以下输入。缺哪项问哪项，不要让用户逐项填表，先根据已有信息补全合理默认值，只追问真正影响方向的缺失项。

| # | 输入 | 必填 | 默认/说明 |
|---|---|---|---|
| ① | 产品白底图 | 必填 | **至少2张**。作为 product_ref 贯穿全流程，保证产品外观一致。若用户只给1张，明确告知"至少2张才能稳住产品角度和细节一致性"并请补充。 |
| ② | 产品名称 + 卖点 | 必填 | 产品名（目标市场语言可接受的写法）、核心买点（1个）、辅助卖点（2-3个）。 |
| ③ | 目标用户 / 目标市场国家 / 视频语言 | 必填 | 三者绑定。例如：美国18-35岁女性 / 英语；东南亚25-40岁宝妈 / 英语或当地语言。语言决定 VO 口播和字幕语言。 |
| ④ | 视频时长 / 比例 / 清晰度 | 可选 | 默认 **15秒 / 9:16竖版 / 1080P**。时长受生视频模型限制（5-30秒整数秒），超出要回退并说明。 |
| ⑤ | 创意描述 | 可选 | 用户用普通大白话说的情节、画面、人物、卖点植入要求。没有则由 AI 按方法论自由发挥。 |
| ⑥ | 产品尺寸 / 物理参数 | 可选 | 长宽高/直径/重量/容量等。用于在 prompt 里锚定产品在画面中的真实比例、与手/桌面/参照物的物理关系，避免 AI 把小件产品画成巨物或把大件画成手办。单位跟随目标市场（美国用英寸/磅，欧洲用厘米/克）。没有就按外观合理推断，但不要编数字。 |
| ⑦ | 对标参考视频 | 可选 | 用户给的 TikTok/其他平台爆款视频链接或文件。**只参考其节奏、钩子结构、镜头语言、剪辑卡点、BGM风格，不复制其人物、台词、品牌、画面内容**。处理方式见下。 |

**对标参考视频的处理**（输入⑦给了才走这步）：
1. 先用 `doubao-video-extract` 或 `byted-mediakit-video` 把对标视频拆成关键帧+时间轴，分析：前3秒钩子是什么、每几秒切一次镜、产品怎么亮相、CTA 怎么收尾、BGM 是什么风格。
2. 把拆解结论作为"风格/节奏参考"写进阶段1的三个大纲方向里（例如："对标视频钩子是0.5秒快切+一句反问，本方向沿用这个节奏但换成我们的产品"）。
3. 抽取 2-3 张对标视频的关键帧（不含原品牌 logo/可识别台词画面）作为 `style_ref`，与产品白底图一起传给视频工具，只用于借镜头语言和色调，不作为产品或人物参考。
4. **红线**：不照搬对标视频的台词、演员形象、品牌名、特定音乐版权片段；用户明确说"就要一模一样"时，要提醒这会有侵权和同质化风险，并改写为"同结构不同内容"。

收集完输入后，**先输出一份"输入确认摘要"**（产品图数量+尺寸、产品名/卖点、目标人群/市场/语言、时长/比例、创意要点、对标视频拆解结论），让用户确认无误，再进入阶段1。

## 阶段1：输出至少3个拍摄大纲方向

根据产品和创意，**必须输出至少3个差异化方向**，从 `references/outline-methodology.md` 中选取最匹配的方向模板填充。三个方向必须在以下维度上明显不同（不能只是换个场景）：

- **方向类型**不同（例如：A=UGC真人口播种草，B=痛点解决剧情，C=ASMR沉浸式产品演示）
- **钩子打法**不同（反差/好奇/利益/恐吓/演示…）
- **人物设定**不同或场景完全不同

每个方向必须包含以下字段（缺一不可）：

1. **方向名称**（一句话，如"闺蜜安利型 UGC 口播"）
2. **人物设定**（年龄、身份、语气、穿着感）
3. **故事场景**（具体在哪、什么时间、什么氛围）
4. **产品角色 & 解决什么问题**（产品在剧情里是什么身份，解决用户哪个痛点）
5. **开场前3秒硬核钩子**（具体到画面+第一句话，不能写"吸引注意"这种空话）
6. **核心买点**（用户为什么买，1句话）
7. **辅助卖点**（2-3个，怎么佐证核心买点）
8. **故事情节框架**（按 0-3s / 3-8s / 8-12s / 12-15s 分四段写）
9. **拍摄标准框架**（景别、运镜节奏、光线、风格关键词）

输出格式用结构化卡片，每个方向一张卡片，末尾给一个"选择建议"（AI 根据产品和市场倾向推荐哪个，但最终用户选）。

**输出后必须停下来等用户**：让用户选择方向，或提出修改意见。用户说"就用方向B""第一个不错但钩子改成XX"都算确认；不要自作主张进入阶段2。

## 阶段2：根据选定方向生成分镜脚本

用户选定（或修改后）方向后，读取 `references/storyboard-template.md`，输出**专业分镜脚本**。要求：

- 按 **每5秒一个镜头** 切分（15秒=3镜；30秒=6镜），每镜字段完整：时间码、画面、场景、人物、产品动作、VO口播原文、字幕/花字、镜头运动、BGM/音效。
- **VO口播必须是目标市场语言的完整原文**（不是中文再标注翻译），口语化、可直接朗读，长度匹配镜头时长（约每秒3-4个词）。
- 前3秒的钩子台词和画面必须与阶段1大纲一致。
- 卖点植入要自然：核心买点出现在中段，CTA 出现在最后3秒。
- 分镜表输出后，**停下来等用户确认或修改台词/画面**。用户确认后才进阶段3。

## 阶段3：生成视频并交付

分镜脚本确认后，按以下顺序执行：

1. **路由视频生成模型（优先1080P）**：
   - **优先 `seedance_2.5`**（用户有会员高级套餐时）：走 `seedance-25` skill 的规则（原文透传 prompt、固定 model_version=seedance_2.5），出片分辨率更高、接近1080P。
   - **退到 `seedance_2.0_fast`**（免费/默认）：会出 720×1280，**不是1080P**——确认摘要里必须明确告知用户"fast模型实际输出720p，要1080p需升级到seedance 2.5"，让用户选。
   - 用户明确要求2.5才切，不主动升级。
2. **组装生成参数**：
   - 时长 = 用户确认值（默认15s，5-30整数秒）
   - 比例 = 用户确认值（默认9:16；生视频工具仅支持 16:9/4:3/1:1/3:4/9:16/21:9）
   - 参考图 = 用户上传的产品白底图（≥2张）作为 `image_reference_url_list` 主参考；若有对标视频，把抽取的 2-3 张关键帧也一并传入，**在 prompt 中明确区分**：白底图是"product reference, must match product exactly"，对标关键帧只是"cinematic tone / pacing reference, do not copy content"。
   - prompt = 按分镜脚本逐镜组装成一段连贯的画面+动作+VO描述（VO 用 `{台词}` 包裹作为 audio voiceover，不要写成画面字幕）；**每个出现产品的镜头都要带上尺寸锚点**（如"the product is about 6 inches tall, held in one hand"），让 AI 不把比例画错。
   - 清晰度要求在 prompt 中体现（"1080p, high quality"），但 fast 模型实际仍出 720p，不要在交付时谎称1080P。
3. **生成前最后确认**：把"模型 / 实际输出分辨率 / 时长 / 比例 / 参考图 / 完整 prompt（代码块原文）/ 每镜VO"汇总成确认摘要，等用户说"生成/确认/开始"后再调用视频工具。
4. **调用工具**：使用 `image_to_video`（有产品图参考时）或 `text_to_video`（用户明确不要产品参考时）。一次最多生成2个版本。
5. **生成后必做两项检查**（详见 `references/post-processing.md`）：
   - **水印检查**：抽帧看右下角，几乎所有AI视频生成工具都会在角落打水印。发现水印→按 post-processing.md 的放大裁剪法处理。
   - **花字乱码检查**：抽帧看每段屏幕花字。越南语/泰语/法语/西语等带声调符号的文字，AI 生成时极易渲染成乱码错字。发现乱码→按 post-processing.md 的"局部模糊+drawtext重写"法修正。
   - 产品一致性、VO清晰度、时长比例也一并检查；有明显问题先重试一次或说明。
6. **交付**：后处理完成后的最终 mp4 必须通过 `present_files` 工具交付给用户，附一句"成片+用了哪个方向/多少秒+实际分辨率"的说明。不要只丢一个裸链接。

## 硬规则

- **用户确认门**：输入摘要、大纲选择、分镜脚本、最终生成参数，这四道关每道都必须停下等用户明确确认（"确认/可以/开始/OK/yes/用方向B"等）。用户沉默、模糊回应、或只改一个词都不算全确认，要更新摘要再问。
- **产品一致性**：产品白底图从阶段1起就是最高优先级参考。分镜里产品的颜色、形状、logo、包装、关键特征必须与白底图一致，prompt 中每个出现产品的镜头都要复述产品外观锚点。
- **产品物理比例**：用户给了尺寸/重量/容量时，prompt 里必须把尺寸翻译成画面中的物理参照（"掌心大小""和手机差不多高""一瓶矿泉水重"），让 AI 不把小件画成巨物、大件画成模型。没给尺寸不要编数字，用外观相对关系描述。
- **对标视频只借节奏不抄内容**：对标视频的钩子结构、切镜节奏、运镜、色调可以学；台词、演员脸、品牌 logo、专属 BGM 片段不复制。关键帧作为 style_ref 传入时必须在 prompt 里声明"tone reference only, do not reproduce"。
- **前3秒钩子**：任何方向都不能省。钩子必须是"画面冲击+第一句话"组合，不能用"今天给大家推荐一款好物"这种开场。
- **语言跟随市场**：VO 口播、字幕花字、CTA 全部用目标市场国家的语言；人物设定、场景审美、文化梗也要贴合该市场（例如不拿宗教敏感元素开玩笑、节日/货币/尺寸单位本地化）。
- **不编造数据**：卖点可以是产品功能描述，但不得编造"销量第一""99%用户好评""医生推荐"等无来源的权威/数据背书。
- **一次最多2个视频**：超出先澄清。
- **不主动生成分镜图/关键帧图**：用户没要图片时，阶段2只输出文字分镜表，直接进视频生成；用户明确要"分镜图/关键帧图"才先出图。
- **合规红线**：不做医疗功效承诺、不做绝对化用语（best/No.1/guaranteed cure）、不模仿在役真人明星/政客形象、不出现平台禁用词。

## 参考文件路由

| 阶段 | 读取文件 | 什么时候读 |
|---|---|---|
| 阶段1 出大纲 | `references/outline-methodology.md` | 每次生成3个方向前必读，按里面的方向模板和钩子库填充 |
| 阶段2 写分镜 | `references/storyboard-template.md` | 用户选定大纲后必读，按表结构和VO规范写 |
| 阶段3 后处理 | `references/post-processing.md` | 视频生成后必查水印和花字乱码时读，按里面的 ffmpeg 命令模板处理 |

三个 reference 不要在开工前一次性塞进上下文；阶段1结束、用户选定方向后再读 storyboard；视频生成完发现水印/花字问题时再读 post-processing。

## 不承接 / 转派

- 用户要做**长篇短剧、连续剧情、5分钟以上故事片** → 转派 `doubao-creative-drama`。
- 用户要做**纯品牌形象片/企业宣传片/无转化目标的TVC** → 转派 `doubao-creative-video` 的 corporate 分支。
- 用户只要**写脚本不要生成视频** → 本技能阶段1+阶段2即可停，不强行生成。
- 用户给的产品图不是白底图、背景杂乱 → 先建议用 `white-bg-retouch` 技能处理成白底图再开始，或明确告知"非白底图产品一致性会变差"。
