# MaxClaw 技能发现元技能

## 概述

此元技能为大型Agent团队提供自动化的技能发现、匹配、推荐与管理能力，支持动态能力扩展需求。

## 核心能力

### 1. 技能发现引擎
- **缺失技能识别**：分析任务需求，自动识别团队现有技能库中的能力缺口
- **相似技能检索**：基于语义匹配找到功能相似或互补的技能
- **技能图谱构建**：建立技能间的依赖关系和协作网络

### 2. 智能匹配系统
- **需求-技能映射**：将用户任务需求精准映射到可用技能
- **多维度评分**：基于能力匹配度、性能指标、权限要求进行综合评分
- **优先级排序**：根据匹配质量和使用场景推荐最优技能序列

### 3. 技能推荐引擎
- **单一技能推荐**：针对简单任务推荐最佳单一技能
- **组合技能推荐**：针对复杂任务推荐多个协同工作的技能组合
- **替代技能建议**：当首选技能不可用时提供替代方案

### 4. 技能管理助手
- **挂载/卸载指导**：协助用户完成技能的挂载和卸载操作
- **技能状态监控**：跟踪技能的使用状态和性能表现
- **团队技能库同步**：支持多Agent团队的技能库一致性管理

## 触发场景

| 场景 | 触发短语示例 |
|------|-------------|
| 缺失技能识别 | "我需要完成X任务，现有技能有哪些不足？" |
| 技能搜索 | "帮我找一个能处理Y的专业技能" |
| 技能推荐 | "针对这个复杂任务，哪个技能组合最合适？" |
| 技能管理 | "如何挂载这个技能？""哪些技能可以卸载？" |
| 能力规划 | "团队需要扩展哪些能力？" |

## 执行工作流

### 阶段1：任务分析
1. 解析用户任务需求，提取关键能力要求
2. 识别任务类型（简单/复杂/多Agent协作）
3. 确定所需的技能维度（功能域、性能要求、权限级别）

### 阶段2：技能库扫描
1. 扫描已安装技能列表
2. 分析每个技能的元数据（描述、能力标签、版本）
3. 构建当前技能能力矩阵

### 阶段3：匹配与推荐
1. 计算需求与技能的匹配度分数
2. 应用多维度筛选条件
3. 生成排序后的推荐列表
4. 对复杂任务生成技能组合方案

### 阶段4：报告生成
1. 输出缺失技能清单及优先级
2. 提供推荐技能及理由说明
3. 给出挂载/卸载操作指引
4. 包含能力扩展规划建议

## 决策规则

### 匹配阈值
- **高匹配**: 匹配度 ≥ 80% → 优先推荐
- **中匹配**: 匹配度 50-79% → 候选考虑
- **低匹配**: 匹配度 < 50% → 建议扩展

### 技能组合原则
- 优先选择无冲突的技能组合
- 避免功能重复的技能同时使用
- 考虑技能间的依赖关系和执行顺序

### 权限处理
- 需要敏感权限的技能需明确标注
- 建议用户在使用前确认权限需求
