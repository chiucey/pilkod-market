# 观测文档模板

## 概述

# 观测方案：微服务快速部署功能

监控微服务快速部署功能的使用情况和系统健康度，为后续迭代优化提供数据支持。

## 业务指标

### 核心指标

| 指标ID | 指标名称 | 计算公式 | 目标值 | 采集频率 |
|:-------|:---------|:---------|:-------|:---------|
| OBS-001 | 部署成功率 | 成功部署数 / 总部署数 | > 95% | 实时 |
| OBS-002 | 平均部署时间 | sum(部署时间) / 部署次数 | < 10min | 实时 |
| OBS-003 | 部署频率 | 每日部署次数 | - | 每日 |

### 衍生指标

| 指标ID | 指标名称 | 计算公式 | 用途 |
|:-------|:---------|:---------|:-----|
| OBS-004 | 回滚率 | 回滚次数 / 总部署次数 | 稳定性指标 |
| OBS-005 | 部署超时率 | 超时次数 / 总部署次数 | 性能指标 |

## 技术指标

### 性能指标

| 指标 | 说明 | 告警阈值 |
|:-----|:-----|:---------|
| Chart 生成时间 | 生成 Helm Chart 耗时 | > 1s |
| API 响应时间 P99 | API 请求响应时间 | > 2s |
| 部署执行时间 | 部署到完成的总时间 | > 15min |

## AI Agent 执行指导

### 从观测数据触发迭代

```
监控数据 ──→ 分析指标趋势
              │
              ↓
          对比目标值
              │
              ↓
          判断是否触发迭代条件
              │
              ↓
          生成迭代建议 ──→ 创建新的场景/需求
```

### 观测配置生成

```yaml
# Prometheus 告警规则示例
# 基于观测文档自动生成

groups:
  - name: deploy-service-alerts
    rules:
      - alert: DeploySuccessRateLow
        expr: |
          sum(rate(deploy_success_total[10m])) 
          / 
          sum(rate(deploy_total[10m])) < 0.8
        for: 5m
        labels:
          severity: critical
        annotations:
          summary: "部署成功率严重下降"
```
