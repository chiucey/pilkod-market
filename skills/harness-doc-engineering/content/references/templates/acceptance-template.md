## AI Agent 执行指导

### 自验收流程

```
验收文档 ──→ 解析验收标准
              │
              ↓
测试结果 ──→ 匹配测试结果
              │
              ↓
          生成验收报告
              │
              ↓
          识别遗留问题
              │
              ↓
          输出验收结论
```

### 验收检查清单

- [ ] 所有验收标准有对应测试
- [ ] 测试通过率达标（> 95%）
- [ ] 无高危遗留问题
