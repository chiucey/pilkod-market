## 示例

```markdown
# 用例：一键部署微服务

**用例ID**: UC-001
**来源场景**: SC-001
**创建日期**: 2024-03-30
**负责人**: 张三
**状态**: Approved
**优先级**: High

## 简要描述

开发工程师通过简单配置快速部署微服务到 Kubernetes 集群。

## 参与者

### 主要参与者

- 开发工程师

### 次要参与者

- CI/CD 系统（自动触发部署）

## 前置条件

- 开发工程师已登录平台
- 目标集群已配置
- 微服务镜像已构建并推送

## 后置条件

### 成功后置条件

- 微服务运行在目标集群
- 部署记录已保存
- 相关人员收到通知

### 失败后置条件

- 微服务保持原有状态
- 失败原因已记录
- 开发工程师收到错误通知

## 触发条件

- 开发工程师手动发起部署
- CI 流水线自动触发部署

## 主流程

| 步骤 | 参与者 | 系统响应 |
|:-----|:-------|:---------|
| 1 | 选择要部署的微服务 | - |
| 2 | - | 显示微服务配置选项 |
| 3 | 选择目标环境（dev/staging/prod） | - |
| 4 | - | 验证环境配置和权限 |
| 5 | 配置部署参数（副本数、资源限制等） | - |
| 6 | - | 生成 Helm Chart |
| 7 | 点击 **Deploy** | - |
| 8 | - | 执行部署命令 |
| 9 | - | 监控部署进度 |
| 10 | - | 返回部署结果 |

## 异常流程

### 异常流程 1: 镜像不存在

**触发条件**: 指定的镜像版本在仓库中不存在

| 步骤 | 参与者 | 系统响应 |
|:-----|:-------|:---------|
| 6a.1 | - | 检测到镜像不存在 |
| 6a.2 | - | 显示错误信息：镜像版本未找到 |
| 6a.3 | - | 提供可用的镜像版本列表 |

### 异常流程 2: 权限不足

**触发条件**: 用户没有目标环境的部署权限

| 步骤 | 参与者 | 系统响应 |
|:-----|:-------|:---------|
| 4a.1 | - | 检测到权限不足 |
| 4a.2 | - | 显示错误信息：无权限部署到此环境 |
| 4a.3 | - | 提供申请权限的链接 |

### 异常流程 3: 部署超时

**触发条件**: 部署在指定时间内未完成

| 步骤 | 参与者 | 系统响应 |
|:-----|:-------|:---------|
| 9a.1 | - | 检测到部署超时 |
| 9a.2 | - | 记录超时事件 |
| 9a.3 | - | 提供诊断信息和回滚选项 |

## 业务规则

| 规则ID | 规则描述 |
|:-------|:---------|
| BR-001 | 生产环境部署需要审批 |
| BR-002 | 同一服务同一环境只能有一个活跃部署 |
| BR-003 | 部署超时时间为 15 分钟 |

## 衍生需求

| 需求ID | 需求名称 | 类型 | 优先级 |
|:-------|:---------|:-----|:-------|
| REQ-001 | 微服务选择界面 | Functional | High |
| REQ-002 | 环境配置管理 | Functional | High |
| REQ-003 | Helm Chart 生成 | Functional | High |
| REQ-004 | 部署进度监控 | Functional | High |
| REQ-005 | 部署权限控制 | Non-functional | High |

## UI 原型

[链接到原型设计]

## 非功能性需求

- **性能**: 部署操作响应时间 < 2 秒
- **安全**: 生产环境部署需要 MFA 验证
- **可用性**: 支持 Chrome、Firefox、Safari 最新两个版本

## 备注

此用例是微服务部署流程的核心用例。
```

## AI Agent 执行指导

### 从用例提取需求

1. 分析主流程中的每个步骤
2. 识别需要的系统功能
3. 分析异常流程中的处理逻辑
4. 提取非功能性需求
5. 为每个需求分配唯一 ID

### 生成测试用例

1. 主流程 → 正向测试用例
2. 异常流程 → 逆向测试用例
3. 边界条件 → 边界测试用例
