# CCI技术指标详解

## 什么是CCI指标

CCI（Commodity Channel Index，商品通道指数）是由唐纳德·兰伯特（Donald Lambert）于1980年发明的一种技术分析指标。最初用于商品市场，现广泛应用于股票、外汇等金融产品的分析。

## CCI计算公式

```
CCI = (TP - SMA(TP, N)) / (0.015 × MAD)
```

其中：
- **TP（典型价格）** = (最高价 + 最低价 + 收盘价) / 3
- **SMA(TP, N)** = TP的N日简单移动平均值
- **MAD** = TP与SMA的绝对偏差的平均值
- **N** = 周期（默认14）
- **0.015** = 调整常数，确保大部分CCI值在-100至+100之间

## CCI默认值设置

| 参数 | 默认值 |
|-----|-------|
| 周期(N) | 14日 |
| 数据类型 | 日线 |
| 调整常数 | 0.015 |

## 信号判断标准（日线级别）

| 信号类型 | CCI数值 | 操作建议 |
|---------|--------|---------|
| 超卖严重 | CCI < -200 | **强烈买入信号** |
| 注意超卖 | -200 < CCI < -150 | 关注买入机会 |
| 震荡区间 | -150 ≤ CCI ≤ 150 | 无明确指示 |
| 注意超买 | 150 < CCI < 200 | 关注卖出机会 |
| 超买严重 | CCI > +200 | **强烈卖出信号** |

## 应用场景

### 1. 顺趋势交易
- 当CCI从负值区域向上穿越+100时，可能预示上涨趋势，可考虑买入
- 当CCI从正值区域向下穿越-100时，可能预示下跌趋势，可考虑卖出

### 2. 反趋势交易
- CCI < -200：极度超卖，可能存在反弹机会
- CCI > +200：极度超买，可能存在回调风险

### 3. 日线级别监控
- 本技能专注于日线级别的CCI监控
- 每个交易日下午14:30推送一次更新
- 适合中长期交易者参考

## 注意事项

1. CCI指标不适用于横盘震荡行情
2. 极端CCI值可能持续较长时间
3. 建议结合其他指标综合判断
4. 投资有风险，决策需谨慎
