# CCI股票监控助手

## 功能概述

此技能帮助用户监控A股股票的CCI技术指标，提供买入/卖出/超买超卖等信号提示。

## 核心功能

### 1. 个股收藏管理

**添加收藏：**
```
添加股票 [股票代码] [成本价] [持有数量]
例：添加股票 600519 1800.00 100
```

**查看收藏：**
```
查看收藏
列出我的股票
```

**删除收藏：**
```
删除股票 [股票代码]
```

### 2. 交易记录

**记录买入：**
```
记录买入 [股票代码] [价格] [数量] [日期]
例：记录买入 600519 1750.00 100 2024-01-15
```

**记录卖出：**
```
记录卖出 [股票代码] [价格] [数量] [日期]
例：记录卖出 600519 1800.00 50 2024-01-20
```

**查看交易记录：**
```
查看交易记录 [股票代码]
```

### 3. CCI指标监控

**手动查询单只股票：**
```
查询CCI [股票代码]
例：查询CCI 600519
```

**查询所有收藏股票：**
```
查询所有CCI
```

### 4. CCI信号规则（日线级别）

| CCI数值范围 | 信号提示 |
|------------|---------|
| CCI < -200 | "买入" |
| CCI > +200 | "卖出" |
| -200 < CCI < -150 | "注意超卖" |
| 150 < CCI < 200 | "注意超买" |
| 其他情况 | "震荡无指示" |

### 5. 定时推送设置

**设置每日14:30推送：**
```
设置CCI定时推送
开启每日提醒
```

**取消定时推送：**
```
取消CCI定时推送
关闭每日提醒
```

## 数据来源

- 使用东方财富API获取实时行情数据
- 计算日线级别的CCI指标
- 数据存储于用户个人空间

## 技术说明

**CCI计算参数：**
- 默认周期：14日
- 数据类型：日线
- 数据源：东方财富

**定时推送说明：**
- 推送时间：每个交易日下午14:30（北京时间）
- 推送渠道：微信
- 仅监控收藏列表中的股票
