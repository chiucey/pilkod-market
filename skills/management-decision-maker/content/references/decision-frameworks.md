# 管理决策参考框架

## 一、经典决策模型

### 1. 理性决策模型（Rational Decision Model）

**步骤**：
1. 识别问题
2. 确定标准
3. 分配权重
4. 研发方案
5. 评估方案
6. 选择最优

**适用场景**：有明确目标、信息充分、时间充裕的决策

### 2. 有限理性模型（bounded rationality）

**核心观点**：
- 人无法获得全部信息
- 处理信息的能力有限
- 决策者"满意"即可，而非最优

**实践建议**：
- 设置决策截止时间
- 明确"可接受"的最低标准
- 区分"理想方案"和"可行方案"

### 3. 渐进决策模型（Muddling Through）

**核心观点**：
- 决策是逐步调整的过程
- 注重边际变化而非根本变革
- 小步快跑，不断试错

**适用场景**：复杂组织环境、利益相关方众多、变革阻力大

### 4. 垃圾桶模型（Garbage Can Model）

**核心观点**：
- 决策是偶然事件
- 问题、解决方案、参与者在特定时机碰撞
- 机遇和时机很重要

## 二、风险评估框架

### 风险矩阵

| | 低影响 | 中影响 | 高影响 |
|---|---|---|---|
| **高可能性** | 监控 | 缓解计划 | 立即处理 |
| **中可能性** | 接受 | 缓解计划 | 规避/转移 |
| **低可能性** | 接受 | 接受 | 缓解计划 |

### 风险应对策略

1. **规避**：改变计划消除风险
2. **转移**：保险、外包、分担
3. **缓解**：降低可能性或影响
4. **接受**：准备应急方案

## 三、常用分析工具

### 1. SWOT分析

| | 帮助 | 阻碍 |
|---|---|---|
| **内部** | Strengths优势 | Weaknesses劣势 |
| **外部** | Opportunities机会 | Threats威胁 |

### 2. 波士顿矩阵

| 类型 | 策略 |
|------|------|
| 明星业务 | 投资扩张 |
| 现金牛业务 | 维持稳定 |
| 问题业务 | 选择性投资 |
| 瘦狗业务 | 收割或放弃 |

### 3. 波特决策

- **成本领先**：价格竞争
- **差异化**：独特价值
- **聚焦**：细分市场

## 四、团队决策方法

### 1. 共识决策法
- 优点：参与度高、执行力强
- 缺点：耗时、可能被少数人主导

### 2. 多数投票法
- 优点：快速、简单
- 缺点：少数派可能不满

### 3. 权威决策法
- 适用：紧急情况、专业领域
- 注意：明确决策者责任

### 4. DESS决策法
- **D**ecide：决策者拍板
- **E**xpertise：专家决策
- **S**tatistics：数据决策
- **S**elf：当事人决策

## 五、常见决策陷阱

### 1. 确认偏误（Confirmation Bias）
- 只看支持自己观点的信息
- 对反对意见视而不见

### 2. 锚定效应（Anchoring）
- 过度依赖第一个信息
- 难以根据新信息调整

### 3. 群体思维（Groupthink）
- 追求一致而压制异议
- 表面和谐实则危险

### 4. 沉没成本谬误（Sunk Cost Fallacy）
- 因已投入而继续错误决策
- 难以"割肉"止损

### 5. 过度自信（Overconfidence）
- 高估自己判断准确性
- 低估风险和不确定性

### 6. 后见之明（Hindsight Bias）
- 事后认为结果必然
- 忽视决策时的不确定性

## 六、快速决策指南

### 紧急决策（24小时内）

```
1. 明确：最坏结果是什么？
2. 检查：这个决定可逆吗？
3. 行动：先止血，再优化
4. 复盘：事后完善流程
```

### 一般决策（1周内）

```
1. 收集：关键信息（2-3天）
2. 讨论：核心团队（1天）
3. 决定：明确责任（1天）
4. 执行：行动计划（持续）
```

### 重大决策（1月以上）

```
1. 调研：充分信息收集
2. 分析：多方案评估
3. 论证：可行性分析
4. 审批：按权限逐级上报
5. 试点：必要时先小范围验证
6. 推广：全面实施
7. 复盘：效果评估
```
