# Video Prompt Analyzer - Agent 版本

视频镜头分析 & AI 视频生成提示词反推工具

## 功能特点

- **视频加载** - 支持加载视频文件，自动提取关键帧
- **图片加载** - 支持直接加载多张图片进行分析
- **专业分析** - 6维度深度分析（主体/场景/镜头/光影/风格/氛围）
- **结构化输出** - 自动生成可直接用于 AI 视频生成的提示词
- **结果导出** - 支持 TXT、MD、JSON 格式导出

## 分析维度

| 维度 | 说明 | 优先级 |
|------|------|--------|
| 主体 | 人物/物体特征、动作、服装 | ★★★★★ |
| 场景 | 场景类型、时段天气、空间深度 | ★★★★☆ |
| 镜头 | 拍摄角度、景别、运镜、构图 | ★★★★★ |
| 光影 | 光源类型、方向、光比、色温 | ★★★★☆ |
| 风格 | 视觉风格、色彩体系、质感 | ★★★☆☆ |
| 氛围 | 情感基调、叙事暗示、节奏 | ★★★☆☆ |

### 批量分析输出

批量分析会额外输出：
- **镜头运动分析**：运镜方式、速度、轨迹
- **视觉风格统一分析**：跨帧的风格一致性
- **逐帧关键差异**：每帧的变化点

## 使用方式

### 在 Agent 中直接使用

1. 用户上传视频或图片
2. 使用 `videos_understand` 或 `images_understand` 工具分析
3. 根据提示词模板生成结构化输出
4. 返回完整的分析结果和提示词

### 使用命令行工具

```bash
# 提取视频帧并获取分析提示词
python analyzer.py --video your_video.mp4 --frames 8

# 仅打印分析提示词模板
python analyzer.py --print-prompt

# 批量分析模式
python analyzer.py --video your_video.mp4 --mode batch
```

## 技术实现

- 视频处理：使用 OpenCV 提取视频帧
- AI 分析：使用 MiniMax VL 内置模型
- 提示词工程：6维度专业分析框架
