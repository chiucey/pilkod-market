# Daily Best Skills Collector

每天自动收集、整理和报告最好用的 skills。

## 触发条件

当用户要求：
- 收集每日最佳 skills
- 生成技能库报告
- 整理和分类 skills
- 设置定时收集任务

## 工作流程

### 1. 收集来源

从以下来源收集高质量 skills：
- Skills 社区热门列表
- 用户评分最高的 skills
- 最近活跃/更新的 skills
- 特定领域的推荐 skills

### 2. 评估标准

评估每个 skill 的质量维度：
- **功能性**: 是否解决实际问题
- **完整性**: 文档和示例是否齐全
- **易用性**: 配置和使用是否简便
- **活跃度**: 维护和更新频率
- **评分**: 用户评价和反馈

### 3. 数据整理

按以下结构整理收集的数据：
```
- 技能名称
- 描述摘要
- 分类标签
- 核心功能
- 使用场景
- 评分/热度
- 来源链接
```

### 4. 输出格式

生成每日报告，包含：
- 今日新增最佳技能 (Top 10)
- 热门分类排行榜
- 编辑推荐精选
- 可复用的脚本/模板

## 使用示例

### 手动执行
当用户说 "收集今天的最佳 skills" 时，执行完整的收集流程。

### 定时任务
当用户要求设置定时任务时，使用 `create_cron_job` 工具创建每日定时执行。

### 按分类收集
用户可以指定分类（如 "代码审查"、"PPT生成"），只收集该领域的最佳技能。

## 注意事项

- 优先收集活跃维护的 skills
- 避免重复收集同一技能
- 保留历史记录便于趋势分析
- 定期清理过时的技能信息
