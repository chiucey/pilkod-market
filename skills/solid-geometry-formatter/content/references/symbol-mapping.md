|---------|-------|
| α | `\alpha` |
| β | `\beta` |
| γ | `\gamma` |
| δ | `\delta` |
| θ | `\theta` |
| π | `\pi` |
| ρ | `\rho` |
| σ | `\sigma` |
| φ | `\phi` |
| ω | `\omega` |
| Α | `A` |
| Β | `B` |

## 下标/上标

| 原写法 | 正确写法 |
|--------|----------|
| `A₁` | `A_1` |
| `B²` | `B^2` |
| `x₁₂` | `x_{12}` |
| `A'` | `A'` (保留) |

## 转换示例

```
输入: α∩β=a
输出: \alpha \cap \beta = a

输入: A∈直线l
输出: A \in 直线 $l$

输入: 平面α∥平面β
输出: 平面 $\alpha \parallel$ 平面 $\beta$

输入: 直线l在平面α内
输出: 直线 $l$ 在平面 $\alpha$ 内
```
