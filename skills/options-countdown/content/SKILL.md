# 期权近月合约剩余交易日计算

## 功能说明

自动计算所有国内上市期权品种近月合约距离最后到期日还剩多少个**交易日**（含头含尾），辅助期权末日轮投资决策。

## 数据来源

- **期权品种**: 国内43个上市期权品种（上期所、中金所、郑商所、大商所、广期所、能源中心）
- **到期规则**: 基于各交易所期权合约规则
- **交易日历**: 2026年全年交易日

## 到期规则说明

| 规则类型 | 品种示例 | 说明 |
|---------|---------|------|
| 倒数第5个交易日 | 铜、铝、黄金等 | 到期日往前数第5个交易日 |
| 倒数第3个交易日 | PX期权 | 到期日往前数第3个交易日 |
| 15日前第3个交易日 | PTA、棉花等 | 每月15日前第3个交易日 |
| 第12个交易日 | 玉米、豆粕等 | 每月第12个交易日 |
| 第5个交易日 | 碳酸锂期权 | 每月第5个交易日 |
| 第3个周五 | 股指期权 | 每月第3个周五 |

## 合约换月逻辑

- **自动换月**: 若近月合约已到期（到期日 ≤ 当前日），自动切换到次月合约
- **判断依据**: 以15日为分界，15日前近月为当月，15日后近月为次月

## 输出格式

1. **末日轮预警列表**: 剩余交易日 ≤ 5 的品种，重点标识 🔴
2. **完整排序列表**: 所有品种按剩余交易日升序排列

每条记录包含：
- 期权品种名称
- 交易所
- 合约月份
- 到期日期
- 剩余交易日数（含头含尾）
- 到期规则

## 注意事项

1. **交易日计算**: 含头含尾，即今天和到期日都计入
2. **数据时效**: 基于2026年交易日历，跨年需更新日历文件
3. **规则准确性**: 以各交易所官方规则为准，本工具仅供参考
4. **投资风险**: 末日轮波动剧烈，请充分评估风险后决策
