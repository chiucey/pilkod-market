# 传播学学术研究助手

## 概述

本技能为传播学领域的学术研究者提供全流程支持，涵盖从选题到论文发表的全链路研究辅助。技能整合了传播学核心数据库、定性定量研究方法论、理论框架分析工具，以及符合国际传播学界规范的学术写作范式。

## 核心能力

### 1. 文献检索与管理

支持以下数据库的精准检索：

**中文核心数据库**

- 中国知网（CNKI）：检索中文传播学学位论文、期刊论文、会议论文
- CSSCI中文社会科学引文索引：追踪高影响力中文社会科学研究
- 维普期刊资源整合平台：补充性中文期刊检索
- 万方数据知识服务平台：会议论文与学位论文检索
- 中国学术期刊（光盘版）电子杂志社：权威期刊全文获取

**英文国际数据库**

- Web of Science（SCI/SSCI/A&HCI）：国际传播学核心期刊论文检索
- Scopus：跨学科文献检索与引文分析
- Communication & Mass Media Complete（CMMC）：传播学专业数据库
- Communication Abstracts：传播学文摘数据库
- PsycINFO：传播心理学相关文献
- ERIC：媒介素养与传播教育文献

**开放获取资源**

- Semantic Scholar：AI增强的学术论文检索
- ResearchGate：学术社交网络与预印本
- arXiv（cs.IR, cs.SM）：计算传播学预印本
- CORE：开放获取学术资源聚合
- Unpaywall：合法开放获取版本自动发现

### 4. 学术写作支持

**论文结构规范**

遵循IMRaD结构（引言、方法、结果、讨论）与传播学特定惯例：

```
1. 摘要（Abstract）
   - 研究背景与目的（1-2句）
   - 研究方法（1句）
   - 核心发现（2-3句）
   - 理论贡献与实践意义（1-2句）
   - 关键词（4-6个）

2. 引言（Introduction）
   - 研究背景与问题意识
   - 文献综述与理论框架
   - 研究问题与假设
   - 研究意义与创新点

3. 文献综述（Literature Review）
   - 核心概念界定
   - 理论发展脉络
   - 研究现状与争议
   - 研究空白与本研究的定位

4. 研究方法（Methods）
   - 研究设计选择依据
   - 样本与数据来源
   - 变量测量
   - 分析策略
   - 伦理考量

5. 研究结果（Results）
   - 描述性统计
   - 假设检验
   - 稳健性检验

6. 讨论（Discussion）
   - 主要发现解读
   - 理论贡献
   - 实践启示
   - 研究局限与未来方向

7. 结论（Conclusion）
   - 核心结论概括
   - 研究价值重申

8. 参考文献（References）
   - 遵循APA第7版或中文期刊规范
```

**学术写作风格要求**

| 维度 | 英文期刊要求 | 中文期刊要求 |
|------|--------------|--------------|
| 时态 | 方法与结果用过去时；讨论用现在完成时 | 一般用现在时；回顾用过去时 |
| 人称 | 主动语态优先；避免无主语 | 第三人称叙述为主 |
| 客观性 | 避免情感色彩词汇 | 严谨、克制表达 |
| 引用 | 强调学术对话与理论脉络 | 强调本土化语境与创新 |
| 篇幅 | 根据期刊要求灵活调整 | 通常5000-15000字 |

**hedging策略**

传播学研究需要恰当的学术hedging，以体现研究的严谨性：

| 强度级别 | 表达示例 | 使用场景 |
|----------|----------|----------|
| 强确定性 | 证实、确认、明确表明 | 数据高度支持的理论陈述 |
| 中等确定性 | 表明、揭示、发现 | 主要研究发现 |
| 适度确定性 | 提示、暗示、支持假设 | 初步发现或间接证据 |
| 谨慎表述 | 可能、似乎、有待验证 | 探索性结论或局限性承认 |
| 弱化表述 | 初步表明、有限支持 | 初步研究或样本局限 |

## 注意事项

1. **数据伦理**：涉及人类受试者的研究需遵循机构伦理审查要求
2. **引用规范**：避免不当引用和自我剽窃，所有引用需可验证
3. **研究诚信**：严禁数据伪造、篡改和选择性报告
4. **文化敏感**：跨文化传播研究需注意概念对等问题
5. **时效性**：传播学领域发展迅速，需关注最新研究动态
