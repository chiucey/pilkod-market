# 完整提示词正文(10 个子模块 · 独立可复制版)

> **本文件是什么**
> `WUION1011海信动作` skill 从 `references/output-template.md` 抽出的"完整提示词正文"骨架。
> 与原模板相比:**每个子模块的 ` ```markdown ... ``` ` 代码块围栏已去掉,只保留内部占位符骨架**。
> 任何编辑器(Markdown 渲染器 / VSCode / 纯文本 / Notion / 飞书 / 微信 / 邮件)打开都能直接读、直接选中复制,不会出现"代码块副本 → 还得手动解包"的尴尬。

> **怎么用**
> 1. 整段复制下面的"## 子模块 1"到"## 子模块 10"全部内容;
> 2. 把所有 `<占位符>` 替换为本次视频的实测值(时长 / 站位 / 口播 / 动作 / 电视内容 / 强约束);
> 3. 整段贴入 **Sora / MiniMax-H3 / Veo / 可灵** 等任意 AI 视频生成工具的提示词输入框;
> 4. 工具会读到加粗、列表、缩进这些 Markdown 标记并照常解析——若工具不识别 Markdown,转纯文本也语义完整。

> **占位符约定**
> - `<...>`:必须由实际值替换(例:`<duration>` → `8.31`)
> - `N`:分镜数 / 口播段数(必须相等)
> - 时间戳单位统一为秒,精度 0.01s
> - 站位 6 项字段名(横向位置 / 纵向景别 / 身体朝向 / 与图 2 关键家具相对位置 / 是否被遮挡 / 是否变化)为强约束,不可改名/不可并项

> **格式自包含原则**
> 本文件**不依赖**前文的素材表 / 分镜表 / 元素表 / 检查清单——所有模型需要的变量都在 10 个子模块内部自洽。

## 子模块 9:精准强约束清单(强约束 12-15,默认必含)

**精准强约束清单(覆盖 0.00s–<duration>s 全部时段,任何分镜/任何时间点均不得违反)**:

- **强约束 12 — 站位精准复刻(模特在场景中的站位严格参考视频,提供精准站位描述)**:
  - **子规则 12.1 横向位置**:图 1 在画面中的横向位置必须与参考视频 0.00s 起点完全一致(画面 X% / 左 1/3 / 居中 / 右 1/3 / 居中略偏左 / 居中略偏右 / 正中)
  - **子规则 12.2 纵向景别**:中景 / 中近景 / 前景 / 远景 / 全景,必须与参考视频对应时间点完全一致
  - **子规则 12.3 身体朝向**:正对 / 侧对(左/右)/ 斜对 / 背对镜头,必须与参考视频一致
  - **子规则 12.4 与图 2 关键家具的相对位置**:电视 / 沙发 / 茶几 / 吊柜等的左/右/正前方关系 + 距离,必须与参考视频一致
  - **子规则 12.5 是否被遮挡**:完全可见 / 被家具部分遮挡(遮挡部位)/ 完全不可见,必须与参考视频一致
  - **子规则 12.6 是否变化**:稳定不动 / 切换点;每个站位切换点要显式标出切换秒 + 6 项新站位齐全
  - **失败判定**:若 AI 视频工具输出中,图 1 在任一时间点的横向位置 / 纵向景别 / 身体朝向 / 与图 2 关键家具的相对关系 / 是否被遮挡与参考视频不一致,视为任务失败

- **强约束 13 — 机位镜头对齐图 2(机位和镜头必须跟场景参考图完成对齐)**:
  - **子规则 13.1 相机位置**:机位 X/Y/Z 三轴位置与图 2 百分百一致
  - **子规则 13.2 镜头焦段**:焦段与图 2 等效
  - **子规则 13.3 视角高度**:视角高度(平视/俯视/仰视)与图 2 一致
  - **子规则 13.4 拍摄方向**:拍摄方向(正面/侧面/斜侧)与图 2 一致
  - **子规则 13.5 镜头俯仰角**:俯仰角与图 2 一致
  - **失败判定**:若 AI 视频工具输出中,相机位置 / 视角高度 / 拍摄方向 / 俯仰角任一与图 2 出现偏差,视为任务失败

- **强约束 14 — 场景 100% 入框(场景参考图完全百分百入视频画面框内)**:
  - **子规则 14.1 画幅一致**:视频输出画幅宽高比与图 2 完全一致(横向对横向、竖向对竖向)
  - **子规则 14.2 边界完整**:图 2 的上 / 下 / 左 / 右四个边界全部出现在视频画面内,不得被裁切
  - **子规则 14.3 家具装饰完整**:图 2 中所有家具 / 装饰 / 区域 / 角落均完整呈现于视频画面内
  - **子规则 14.4 优先级最高**:该约束优先于机位;即使机位与图 2 对齐,若图 2 边缘被裁切仍视为违反
  - **失败判定**:若 AI 视频工具输出中,图 2 任意家具/装饰/区域/边界被视频画面框裁切(顶部/底部/左侧/右侧),视为任务失败

- **强约束 15 — 电视画面满屏(电视机播放画面必须满屏)**:
  - **子规则 15.1 满屏呈现**:电视内播放的画面 100% 满屏呈现于电视屏幕区域,像素级铺满
  - **子规则 15.2 无黑边 / 无信箱模式**:电视屏幕内画面不得有任何黑边、上下黑条、信箱模式
  - **子规则 15.3 无 UI 控件**:不得有电视台 UI / 菜单 / 进度条 / 角标
  - **子规则 15.4 无画中画(PiP)**:不得有画中画 / 缩略图 / 多窗口
  - **子规则 15.5 比例严格一致**:电视屏幕内画面比例与电视屏幕物理比例严格一致,不得被裁切 / 不得有留白
  - **失败判定**:若 AI 视频工具输出中,电视屏幕内画面出现任何黑边 / 信箱模式 / UI 控件 / 留白 / 画中画,视为任务失败
