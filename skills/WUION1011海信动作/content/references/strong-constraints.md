# 强约束清单(15 条)

> 本文件是 WUION1011海信动作 skill 的硬性规则。**违反任一条 = 任务失败**。生成最终 .md 时,15 条必须全部满足。其中前 11 条为基础强约束,后 4 条(12-15)为本次新增的精准强约束。

## 1. 时长实测

- 必须用 `ffprobe -v error -show_format -show_streams` 读取参考视频的实际 duration
- 全篇输出时长 = 该实测值(精确到 0.01s)
- **禁止沿用任何示例 / MD 模板 / 历史值**(如 5.50s、6.00s、8.00s、10.00s 等固定值)

## 2. 音频抽离(内部用)

- 用 `ffmpeg -i <video> -vn -acodec pcm_s16le -ar 44100 -ac 2 <wav>` 分离出 wav
- wav 文件必须出现在"素材与范围"表格的"参考音频"行(以 `@参考音频.wav` 占位)
- **本次需求:不交付音频文件,但内部仍需抽离做 ASR**

## 3. 口播 verbatim 转录

- 用语音识别工具(listen_audio / audios_understand)做完整中文转录
- verbatim:不改字、不删字、不补字、不合并语义连贯的短句
- 句级时间戳,精确到 0.01s
- **禁止沿用任何示例口播文本**(如"先唠画质 / 颜色好只是基本功 / 心动的话 / 赶紧冲"等)

## 4. 分镜数 = 口播段数

- 分镜数 = 真实口播段数(参考视频有几段口播就拆几镜)
- 不固定为 N 镜(如不固定为 5 镜或 7 镜)

## 5. 时间精度与步长

- 全程 0.01s 精度(口播时间戳、电视画面时间线、切换点秒数)
- 每 0.20s 一个时间点标注模特动作
- 时间点列表的最后一档 ≤ duration

## 6. 图1 / 图2 代称

- 全程使用"图1"指代模特、"图2"指代场景
- **禁止描述**模特具体的脸型 / 发型 / 服装 / 配饰
- **禁止描述**场景具体画面(如"雪山湖泊"、"游轮港口"等)
- 任何具体细节都必须用 @Image1 / @Image2 + 描述性代称

## 7. 无任何文字元素

- 全程无任何文字、字幕、标题、水印、Logo、赛事标志、角标、贴纸、对话框
- 视频原带的旁白条、产品卖点贴纸、赞助商角标、闪白闪屏、花瓣/纸屑叠加、参数对话框、电视表面反光与人物倒影、装饰性道具等,任务交付时一律不出现

## 8. 电视外观干净

- 电视外观全程无反光、无倒影、无任何文字与 Logo
- 电视内播放画面 100% 满屏(无黑边 / 无信箱模式 / 无 UI / 无留白)
- 若用户提"全屏"约束,电视画面必须扩展、铺满到整个输出视频画面

## 9. 固定机位

- 全程固定机位,机位与图2 百分百一致
- 无推拉 / 无环绕 / 无旋转 / 无倾斜 / 无变焦
- 唯一例外:分镜之间的硬切(画面裁切变化),需显式注明"非运镜"

## 10. 字数上限

- 输出中文字符数 ≤ 6800
- 超出时按"二 → 三 → 四"顺序精简,保留所有时间点 / 口播文本 / 19 条检查项

## 11. 站位实测复刻(关键反例)

- 站位必须从参考视频逐帧观察后复刻
- 禁止硬编码任何站位文字(如"电视正前方、居中略偏右"等固定字符串)
- 不同视频站位可能完全不同,每次跑流程都要重新观察
- 写进"画面内容"和"人物动作时间线"的 0.00s 起点行
- 后续时间点只写动作变化,不再重复站位(除非站位有变)
- 每个站位切换点要显式标出切换秒数 + 新站位

## 12. 站位精准复刻(视频逐帧实测) — 新强约束

> **模特在场景中的站位严格参考视频,必须提供精准的站位描述。**

站位描述必须满足以下 6 项精准字段(全部基于参考视频逐帧实测,**禁止硬编码**):

1. **横向位置**:精确到"画面左 1/3 / 居中 / 画面右 1/3 / 居中略偏左 / 居中略偏右 / 正中",或更细的"画面 X% 位置"
2. **纵向景别**:"前景 / 中景 / 中近景 / 远景 / 全景"
3. **身体朝向**:"正对镜头 / 侧对镜头(左/右) / 斜对镜头 / 背对镜头"
4. **与图 2 关键家具的相对位置**:电视 / 沙发 / 茶几 / 吊柜等,精确到"家具左/右/正前方,距离 ~X 米"
5. **是否被遮挡**:被家具部分遮挡 / 完全可见 / 完全不可见
6. **是否站位变化**:稳定不动 / 切换点 + 新站位

**输出位置**:站位描述必须出现在"画面内容"段首句,且在"人物动作时间线"0.00s 起点行同步标注;每个站位切换点要写明"切换秒 + 新站位(6 项齐全)"。

## 13. 机位镜头与图 2 完全对齐 — 新强约束

> **机位和镜头必须跟场景参考图完成对齐。**

- 相机位置(机位 X/Y/Z 三轴)、镜头焦段、视角高度、拍摄方向、镜头俯仰角**必须与图 2 完全一致,百分百对齐**
- 任何分镜、任何时间点都不得偏离图 2 的整体相机机位
- 视频输出画面的相机视角必须复刻图 2 的视角;若图 2 是平视,视频也必须平视;若图 2 是俯视/仰视,视频也必须同向同角度
- 该约束与强约束 9(固定机位)叠加:既固定、又与图 2 对齐
- **输出位置**:在"运镜"段首句显式声明"机位与图 2 完全一致,百分百对齐,固定机位无任何镜头运动"
- **失败判定**:若 AI 视频工具输出中相机位置、视角、拍摄方向任一与图 2 出现偏差,视为任务失败

## 14. 场景参考图 100% 入视频画面框 — 新强约束

> **场景参考图完全百分百入视频画面框内。**

- 图 2 场景必须 100% 完整入视频画面框内,任何家具 / 装饰 / 区域 / 边界**不得被视频画面框裁切**
- 视频输出画面的宽高比必须与图 2 完全一致(横向对横向、竖向对竖向),保证图 2 整体构图完整呈现
- 图 2 的四个边界(上 / 下 / 左 / 右)必须全部出现在视频画面内,不得被裁剪、不得有溢出
- 该约束优先于机位:即使机位与图 2 对齐,若图 2 边缘被裁切,仍视为违反
- **输出位置**:在"画面内容"段、"环境细节"段都要显式声明"图 2 100% 入框,无任何裁切"
- **失败判定**:若 AI 视频工具输出画面中,图 2 任意家具/装饰/区域被视频画面框裁切(顶部/底部/左侧/右侧),视为任务失败

## 15. 电视机播放画面必须满屏 — 新强约束

> **电视机播放画面必须满屏。**

- 电视内播放的画面必须 100% 满屏呈现于电视屏幕区域,**无黑边 / 无信箱模式 / 无上下黑条 / 无 UI 控件 / 无留白**
- 电视屏幕内画面要铺满到电视屏幕的 100% 显示区域(像素级铺满,不留任何边框/信箱/画面比例留白)
- 电视屏幕内的画面比例(16:9 / 21:9 / 其他)与电视屏幕物理比例严格一致,不得被裁切、不得有黑边、不得有信箱
- 该约束优先于电视外观:即使电视外观干净(强约束 8),若电视内画面不满屏,仍视为违反
- **输出位置**:在"电视画面内容时间线"段、"环境细节"段都要显式声明"电视内播放画面 100% 满屏,无黑边、无信箱模式、无 UI 控件、无留白"
- **失败判定**:若 AI 视频工具输出中,电视屏幕内画面出现任何黑边、信箱模式、UI 控件、留白、画中画(PiP)等,视为任务失败

## 用户附加约束的扩展模式

当用户在基础 15 条之上加新约束(类似之前的"电视满屏 + 全屏")时,**必须四同步**:

1. **素材与范围表**:新增一行约束
2. **完整提示词正文**:新增一个子块(强约束标题 + 子规则 + 覆盖范围 + 失败判定)
3. **元素变更表**:新增一行(E12+)
4. **检查清单**:新增 ≥ 2 条具体检查项

禁止只改一处而不刷新其他三处。
