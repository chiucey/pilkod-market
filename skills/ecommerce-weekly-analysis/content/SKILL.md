# 电商周数据分析智能体

## 触发场景

- 用户要求分析电商平台（淘宝、京东、拼多多、抖音等）运营数据
- 需要生成周期性数据分析报告
- 需要总结运营经验和给出优化方案
- 进行销售数据复盘和趋势分析
- 需要制定下周运营策略

## 输入要求

用户提供以下数据（任选）：

| 数据类型 | 说明 | 必需 |
|---------|------|------|
| 销售数据 | 订单量、GMV、客单价等 | 推荐 |
| 流量数据 | 访客数、浏览量、转化率等 | 推荐 |
| 商品数据 | 爆款、滞销品、库存等 | 可选 |
| 活动数据 | 推广费用、活动效果等 | 可选 |
| 竞品数据 | 市场份额、价格变化等 | 可选 |

## 分析维度

### 1. 核心指标分析
- **销售维度**：GMV、订单量、客单价、同比/环比增长率
- **流量维度**：访客数(UV)、浏览量(PV)、转化率(CVR)、跳出率
- **用户维度**：新客/老客占比、复购率、用户生命周期价值

### 2. 时间维度对比
- 本周 vs 上周
- 本周 vs 去年同期
- 工作日 vs 周末分布

### 3. 商品维度分析
- 爆款商品TOP10
- 滞销商品识别
- 新品表现评估
- 品类结构分析

### 4. 渠道维度分析
- 各流量渠道贡献（搜索/推荐/活动/付费）
- 付费推广ROI
- 私域 vs 公域占比

## 分析流程

### Step 1: 数据理解
- 确认数据来源和格式
- 识别数据完整性和异常值
- 标记关键时间节点（活动/节日）

### Step 2: 指标计算
- 计算同比/环比增长率
- 计算各维度占比
- 识别异常波动点

### Step 3: 洞察提炼
- 从数据中提取关键发现
- 关联因果关系
- 对标行业基准（如有）

### Step 4: 方案生成
- 基于问题给出针对性建议
- 方案需具备可执行性
- 明确资源需求和预期效果

### Step 5: 报告输出
- 按模板结构化输出
- 突出关键发现和行动项
- 附加数据支撑

## 质量标准

### 数据分析准确性
- 数值计算误差 < 1%
- 百分比换算正确
- 图表数据与文字一致

### 建议有效性
- 每个建议有明确问题对应
- 方案具备可落地性
- 预估效果需有数据支撑

### 报告完整性
- 结构完整，无遗漏板块
- 语言简洁专业
- 重点突出，逻辑清晰

## 示例场景

### 场景1：常规周报
用户输入：本周销售数据表格
输出：标准周报，包含数据概览、问题发现、经验总结、方案建议

### 场景2：问题诊断
用户输入：某指标异常下降的数据
输出：原因分析 + 针对性改善方案

### 场景3：活动复盘
用户输入：某次大促的完整数据
输出：活动效果评估 + 经验沉淀 + 下次改进建议

## 注意事项

1. **数据安全**：不存储用户上传的敏感数据，分析后即删除
2. **时效性**：周报需标注具体分析周期
3. **可比性**：同比/环比数据需确保口径一致
4. **客观性**：问题分析保持中立，避免归因偏差
