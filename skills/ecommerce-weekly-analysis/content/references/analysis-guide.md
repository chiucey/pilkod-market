# 电商周数据分析技能 - 参考文档

## 核心指标定义

### 销售指标
| 指标 | 定义 | 计算公式 |
|------|------|----------|
| GMV | 商品成交总额 | 订单金额之和（含退款） |
| 净GMV | 实际成交额 | GMV - 退款金额 |
| 客单价 | 平均每单金额 | GMV / 订单数 |
| 件单价 | 平均每件金额 | GMV / 销售件数 |

### 流量指标
| 指标 | 定义 | 计算公式 |
|------|------|----------|
| UV | 独立访客数 | 去重后的访客数 |
| PV | 页面浏览量 | 页面被访问次数 |
| 转化率 | 访客到订单 | 订单数 / UV * 100% |
| 跳出率 | 单页访问占比 | 单页访问 / 总访问 |

### 用户指标
| 指标 | 定义 | 计算公式 |
|------|------|----------|
| 新客占比 | 新用户订单比例 | 新客订单数 / 总订单数 |
| 复购率 | 重复购买比例 | 复购用户数 / 总购买用户 |
| RFM | 用户价值模型 | 最近、消费频率、消费金额 |

## 分析框架

### 1. 5W2H分析法
- What：发生了什么问题/机会
- Why：为什么会出现这个情况
- When：什么时候开始的，持续多久
- Where：在哪个渠道/品类发生
- Who：影响哪些用户群体
- How：如何发生的（因果链）
- How much：影响范围多大

### 2. 同比环比分析
```
同比增长率 = (本期 - 去年同期) / 去年同期 * 100%
环比增长率 = (本期 - 上期) / 上期 * 100%
```

### 3. 杜邦分析
将核心指标拆解为可操作因子：
- GMV = UV × 转化率 × 客单价
- GMV = 流量结构 × 各渠道转化 × 各渠道客单

## 常见问题诊断

### 转化率下降
1. 检查流量质量（是否垃圾流量）
2. 检查商品页面停留时间和跳失率
3. 检查价格竞争力
4. 检查客服响应速度
5. 检查支付流程是否顺畅

### GMV下降但流量上涨
1. 排查是否高客单商品缺货
2. 检查是否有大量退款
3. 分析品类结构变化
4. 检查是否存在刷单/异常订单

### 客单价下降
1. 检查活动是否拉低整体价格
2. 检查是否高价值商品缺货
3. 分析是否有竞争对手价格战
4. 检查凑单引导是否有效

## 优化方案库

### 流量提升方案
| 方案 | 适用场景 | 预期效果 |
|------|---------|----------|
| 搜索优化 | 免费流量不足 | +15-30%搜索流量 |
| 付费推广 | 急需流量 | 即时效果，需ROI监控 |
| 内容营销 | 提升品牌认知 | 长效，积累型 |
| 活动引流 | 节点爆发 | 短期集中爆量 |

### 转化提升方案
| 方案 | 适用场景 | 预期效果 |
|------|---------|----------|
| 详情页优化 | 跳失率高 | CVR +5-15% |
| 客服跟进 | 咨询少成单少 | CVR +10-20% |
| 限时优惠 | 决策周期长 | CVR +20-40% |
| 信任背书 | 信任度低 | CVR +5-10% |

### 客单价提升方案
| 方案 | 适用场景 | 预期效果 |
|------|---------|----------|
| 满减/凑单 | 引导高客单 | 客单 +15-30% |
| 套餐组合 | 提升连带率 | 客单 +20-40% |
| 会员价 | 锁定高价值用户 | 客单 +10-20% |

## 注意事项

### 数据口径一致性
1. GMV是否含退款需确认
2. UV统计周期需一致
3. 转化率分母需明确（UV还是PV）
4. 节假日数据需特别标注

### 分析客观性
1. 避免幸存者偏差
2. 区分相关性和因果性
3. 考虑外部因素（平台政策、竞品动作）
4. 样本量不足时慎下结论
