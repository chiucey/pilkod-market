# 音视频剪辑助手

## 技能简介

帮助用户对音频和视频文件进行常见剪辑处理，包括裁剪片段、拼接多个文件、提取音频、转码、压缩、加字幕、加水印、调整分辨率与导出指定格式等。

适合短视频处理、素材整理、课程剪辑、播客后期、内容二次创作前处理等场景。

## 适用场景

- 截取视频中的指定片段
- 合并多个音频或视频文件
- 从视频中提取音频
- 给视频加字幕、水印，片头片尾
- 调整视频尺寸、码率、格式
- 压缩视频体积便于上传
- 给音频做基础裁剪、拼接、转格式

## Agent 执行目标

当用户上传一个或多个音视频文件，并描述处理需求后，自动完成以下任务：
1. 识别输入文件类型与数量
2. 判断是音频任务、视频任务，或混合任务
3. 按用户要求执行剪辑、拼接、提取、转码或叠加处理
4. 导出用户需要的结果文件
5. 若处理失败，明确说明原因和修复建议

## 输入

用户可提供：
- 一个或多个音频文件
- 一个或多个视频文件
- 剪辑要求，例如：
  - "截取 00:10 到 00:25"
  - "把这三个视频拼接起来"
  - "提取音频为 mp3"
  - "压缩到更小体积"
  - "加一个右上角水印"
  - "加字幕"
  - "转成 1080p mp4"

## 输出

输出应尽量包含：
- 处理后的目标文件
- 处理说明（执行了哪些操作）
- 若用户要求多个输出，分别命名清楚
- 若出现质量损失、分辨率变化、重新编码等情况，要清晰说明
- 若处理失败，给出具体原因与解决方式

## 支持的常见能力

### 视频处理
- 截取片段
- 拼接多个视频
- 转码格式（mp4 / mov / mkv / avi 等）
- 压缩体积
- 改分辨率
- 改帧率
- 提取封面帧
- 添加字幕
- 添加水印
- 去除音轨 / 替换音轨
- 视频旋转/裁边

### 音频处理
- 裁剪片段
- 拼接多个音频
- 转码格式（mp3 / wav / m4a / flac 等）
- 调整音量
- 提取视频音频
- 转单声道/双声道
- 统一采样率

## 执行规则

1. 先检查文件是否可读取，确认格式、时长、大小
2. 优先保留原始文件，不覆盖源文件
3. 如果用户未指定输出格式：
   - 视频默认输出 mp4（H.264 + AAC）
   - 音频默认输出 mp3
4. 如果任务只涉及无损剪切且条件允许，可优先尝试流复制
5. 所有导出文件命名应清晰
6. 如果用户要求互相冲突，应优先保证可执行并说明取舍
7. 涉及字幕、水印、尺寸变化时，通常需要重新编码，应明确提示

## 推荐工具与依赖

### 核心系统工具

#### ffmpeg
这是最核心的音视频处理工具，几乎所有常见剪辑功能都依赖它。

#### ffprobe
用于读取媒体信息，通常与 ffmpeg 一起安装。

### Python 依赖

```bash
pip install ffmpeg-python moviepy pydub imageio imageio-ffmpeg numpy pillow
```

## 系统工具安装方式

- **Windows**：`winget install ffmpeg`
- **macOS**：`brew install ffmpeg`
- **Ubuntu/Debian**：`sudo apt update && sudo apt install -y ffmpeg`

## Agent 可参考的处理流程

### 1. 识别媒体信息

先读取：文件格式、时长、分辨率、帧率、是否含音轨、音频采样率/声道数

可优先通过 `ffprobe` 获取信息。

### 2. 判断任务类型

根据用户需求选择处理路径：截取、拼接、提取音频、转格式、压缩、加字幕、加水印、替换音轨、调尺寸

### 3. 执行处理

#### A. 截取视频片段
```bash
ffmpeg -i input.mp4 -ss 00:00:10 -to 00:00:25 -c:v libx264 -c:a aac output.mp4
```

#### B. 提取音频
```bash
ffmpeg -i input.mp4 -vn -acodec mp3 extracted_audio.mp3
```

#### C. 压缩视频
```bash
ffmpeg -i input.mp4 -c:v libx264 -crf 28 -preset medium -c:a aac compressed.mp4
```

#### D. 添加字幕
```bash
ffmpeg -i input.mp4 -vf subtitles=subtitles.srt -c:a copy subtitled.mp4
```

#### E. 添加图片水印
```bash
ffmpeg -i input.mp4 -i logo.png -filter_complex "overlay=W-w-20:20" watermarked.mp4
```

#### F. 音频裁剪
```python
from pydub import AudioSegment
audio = AudioSegment.from_file("input.mp3")
clip = audio[10_000:25_000]
clip.export("trimmed_audio.mp3", format="mp3")
```

## 输出策略

### 视频默认输出
- 格式：mp4
- 视频编码：H.264
- 音频编码：AAC

### 音频默认输出
- 格式：mp3

## 错误处理

### 1. 文件格式不支持
当前文件格式暂不支持，请上传常见音频或视频格式，例如 mp3、wav、m4a、mp4、mov、mkv。

### 2. 时间范围非法
你提供的裁剪时间超出了媒体时长，或开始时间晚于结束时间，请检查后重试。

### 3. 文件损坏
文件可能已损坏或编码异常，当前无法正常读取，请更换源文件后重试。

### 4. 编码器缺失
当前环境缺少所需编码器，无法按指定格式导出。请检查 ffmpeg 是否完整安装。

### 5. 依赖未安装
提示安装命令，不要只报错不提供解决方案。

## 输出风格要求

- 明确说明做了什么处理
- 不把技术术语堆给用户，除非用户需要
- 出现限制时清楚说明原因
- 文件名尽量直观
- 如果用户只想要结果，不额外输出过多解释
- 如果用户要求"给出命令"，可同时返回对应 ffmpeg 命令
