# 视频人脸卡通替换器

## 功能概述

将视频中指定的人物头像替换为卡通形象，保护人物隐私。

## 工作流程

### 步骤 1：视频上传与首帧提取

1. 接收用户上传的视频文件（MP4、AVI、MOV 等常见格式）
2. 使用 OpenCV 提取视频首帧作为标注底图
3. 将首帧图片返回给用户进行标注

### 步骤 2：用户标注人脸区域

1. 提供交互式标注界面
2. 用户通过鼠标拖拽绘制矩形框
3. 支持标注多个人脸区域
4. 每个矩形框格式：`[x1, y1, x2, y2]`（左上角和右下角坐标）
5. 用户选择卡通形象类型

### 步骤 3：卡通形象生成

提供以下卡通形象选项：
- 🐱 猫 (cat)
- 🐯 老虎 (tiger)
- 🦁 狮子 (lion)
- 🐻 熊 (bear)
- 🐰 兔子 (rabbit)
- 🐼 熊猫 (panda)
- 🦊 狐狸 (fox)
- 🐶 狗 (dog)

### 步骤 4：视频处理与替换

核心处理流程：

```
输入视频 → 分帧处理 → 人脸检测 → 区域匹配 → 卡通替换 → 帧合成 → 输出视频
```

技术实现：
1. **人脸检测**：使用 MTCNN 或 RetinaFace 检测人脸关键点
2. **区域匹配**：将用户标注的矩形区域与检测到的人脸进行匹配
3. **卡通生成**：使用 Stable Diffusion 或预训练卡通模型生成目标卡通形象
4. **图像融合**：使用泊松融合、Alpha融合等技术将卡通头像无缝融入原视频
5. **帧处理**：逐帧处理视频，保持原始帧率和分辨率

### 步骤 5：输出视频

1. 合成处理后的所有帧
2. 保持原始音频轨道
3. 输出最终视频文件

## 技术栈

- **视频处理**：OpenCV, FFmpeg
- **人脸检测**：MTCNN, RetinaFace, MediaPipe Face Detection
- **图像生成**：Stable Diffusion (SDXL), CartoonGAN, Toonify
- **图像融合**：OpenCV, PIL, blend_modes

## 错误处理

- 视频格式不支持：提示用户转换格式后重试
- 未检测到人脸：提示用户在首帧重新标注
- 标注区域无效：要求至少标注一个人脸区域
- 处理失败：保留原始视频，提供错误日志

## 输出规范

- 格式：MP4 (H.264编码)
- 分辨率：与原视频一致
- 帧率：与原视频一致
- 音频：保留原始音频轨道
