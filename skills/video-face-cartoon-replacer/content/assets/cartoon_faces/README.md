# 卡通人脸素材目录

此目录存放卡通人脸模板图片。

## 模板要求

- 格式：PNG（支持透明通道）
- 尺寸：建议 512x512 像素
- 背景：透明或白色背景
- 风格：卡通化人脸，适合融入视频

## 生成卡通素材

您可以使用以下方式获取卡通人脸素材：

1. **AI生成**：使用 Stable Diffusion、Midjourney 等工具生成
2. **卡通头像网站**：如 Avatarify、Toonify
3. **手绘**：使用绘图软件创建

## 使用说明

在视频处理时，系统会根据用户选择自动加载对应的卡通模板，并将其缩放到人脸区域大小后进行融合。
