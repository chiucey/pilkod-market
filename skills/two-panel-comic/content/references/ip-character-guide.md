## IP角色生成器

### 核心思路

IP角色不是固定的，而是通过多个维度组合生成：

```
IP角色 = 基础物种 + 毛色/肤色 + 配饰/服饰 + 表情风格
```

通过组合，可以生成**上万种**独特的IP角色，有效避免不同用户同质化问题。

## IP角色演绎规则

### 情绪状态对照表

| 短句逻辑 | 上栏IP状态 | 下栏IP状态 |
|---------|-----------|-----------|
| **困境→释然** | 焦虑/困惑/低头/握拳 | 轻松/释然/抬头微笑/张开双臂 |
| **铺垫→升华** | 平静/期待/望向远方 | 满足/愉悦/闭眼享受 |
| **问题→答案** | 疑惑/挠头/思考 | 恍然大悟/微笑/比心 |
| **对比→统一** | 紧张/不安/皱眉 | 放松/自在/舒展 |
| **递进→深化** | 认真/专注/记录 | 点头/微笑/比赞 |
| **因果→结果** | 努力/坚持/行动 | 收获/满足/开心 |

### 姿态设计细则

#### 上栏姿态（铺垫/困境/问题）

| 姿态类型 | 具体描述 | 情绪传达 |
|---------|---------|---------|
| 思考型 | 低头、手托下巴、皱眉 | 困惑、思考 |
| 焦虑型 | 双手握拳、低头、身体紧绷 | 焦虑、不安 |
| 期待型 | 望向远方、手放在胸前 | 期待、希望 |
| 努力型 | 挥汗、咬牙、握拳 | 努力、坚持 |
| 疑惑型 | 挠头、歪头、眨眼 | 疑惑、不解 |

#### 下栏姿态（释然/升华/答案）

| 姿态类型 | 具体描述 | 情绪传达 |
|---------|---------|---------|
| 释然型 | 抬头微笑、张开双臂、身体舒展 | 释然、轻松 |
| 满足型 | 闭眼微笑、双手放在胸口 | 满足、幸福 |
| 开悟型 | 睁大眼睛、微笑、比心 | 恍然大悟、开心 |
| 收获型 | 举起双手、欢呼、跳跃 | 收获、庆祝 |
| 自在型 | 躺下、伸懒腰、放松 | 自在、舒适 |

### 表情设计细则

#### 上栏表情

- 眉毛：微皱或平直
- 眼睛：略眯或睁大（疑惑）
- 嘴巴：抿嘴或微微下垂
- 整体：略带忧虑或专注

#### 下栏表情

- 眉毛：舒展或微扬
- 眼睛：明亮或微眯（愉悦）
- 嘴巴：微笑或大笑
- 整体：开心、满足、释然
