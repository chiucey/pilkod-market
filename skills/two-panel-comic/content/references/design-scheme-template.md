# 两格图文设计方案模板

## ⛔⛔⛔ 设计方案文件输出规范（违反即失败）⛔⛔⛔

```
┌─────────────────────────────────────────────────────────────────────────────
│  ⛔ 必须生成设计方案文件，禁止只生成图片而不保存设计方案文档                     
├─────────────────────────────────────────────────────────────────────────────
│                                                                              
│  ✅ 文件命名规范：                                                            
│     文件名：两格图文设计方案_【IP角色】_【主题】.md                            
│     示例：两格图文设计方案_米白小狗_允许一切发生.md                            
│                                                                              
│  ✅ 生成时机：                                                                
│     系列图文生成完成后，立即生成本文档                                         
│                                                                              
│  ✅ 文档内容必须包含的模块：                                                   
│     1. IP角色设计：角色名称、物种、毛色、配饰、表情风格、核心特征、形象照URL    
│     2. 图文设计规范：图片比例、分栏方案、布局参数、文字样式、画风特征、质量要求  
│     3. 复用方式：说明如何使用此设计方案生成新系列图文                           
│                                                                              
│  ⛔ 禁止：只生成图片而不保存设计方案文档                                        
│  ⛔ 禁止：设计方案文档缺少任何必需模块                                          
│  ⛔ 禁止：形象照URL留空或填入无效URL                                            
│                                                                              
└─────────────────────────────────────────────────────────────────────────────
```

## 设计方案完整格式模板

```markdown
# 两格图文设计方案：【IP角色】_【主题】

## 一、IP角色设计
- **角色名称**：【名称，如：米白小狗】
- **基础物种**：【物种，如：小狗/小猫/小兔等】
- **毛色/肤色**：【颜色，如：米白色短毛】
- **配饰**：【配饰列表，如：无/红色领结/眼镜等】
- **表情风格**：【风格类型，如：治愈软萌/活泼可爱/憨厚温和】
- **核心特征**：【最突出的视觉特征，如：圆滚滚的身材、大大的眼睛、总是微笑的表情】
- **形象照URL**：【生成好的IP角色形象照图片URL，必须填入真实URL】

### 形象照
![IP角色形象照](【生成好的形象照URL】)

## 二、图文设计规范
- **图片比例**：竖版3:4比例（1536×2048像素）
- **分栏方案**：【如：卡片式分隔-圆角矩形卡片/线条分隔/无边框融合】
- **布局参数**：【如：卡片形状、尺寸、间距、位置、样式、文字位置】
- **文字样式**：【如：字号中等、颜色深棕色、字体圆润可爱】
- **画风特征**：【如：粗描边、柔和色彩、简洁线条】
- **质量要求**：
  - IP外观全程一致
  - 文字样式全程统一
  - 文字不遮挡IP角色

## 三、复用方式
使用此设计方案生成新系列图文时，请提供：
1. 此设计方案文档
2. 新的系列短句

**可选**：同时提供IP角色文档（`【IP角色名称】_IP角色设定.md`），以获取更完整的角色特征描述和生图提示词。

示例：
"使用此设计方案，为以下短句生成系列图文：
【短句1】
【短句2】
..."
```

## 各模块填写说明

### 一、IP角色设计

| 字段 | 说明 | 填写示例 |
|------|------|---------|
| 角色名称 | IP角色的名称 | 米白小狗、灰蓝眼镜猫、治愈小熊 |
| 基础物种 | 角色的基础动物种类 | 小狗、小猫、小兔、小熊、仓鼠 |
| 毛色/肤色 | 角色的主要颜色 | 米白色短毛、灰蓝色短毛、奶茶色毛发 |
| 配饰 | 角色的标志性配饰 | 无、红色领结、圆框眼镜、小皇冠 |
| 表情风格 | 角色的表情气质 | 治愈软萌、活泼可爱、憨厚温和、呆萌无辜 |
| 核心特征 | 最突出的视觉识别点 | 圆滚滚的身材、大大的眼睛、总是微笑的表情 |
| 形象照URL | IP角色标准形象照的图片URL | 必须填入真实的图片URL，不可留空 |

### 二、图文设计规范

| 字段 | 说明 | 填写示例 |
|------|------|---------|
| 图片比例 | 图片的尺寸比例 | 竖版3:4比例（1536×2048像素）|
| 分栏方案 | 上下栏的分隔方式 | 卡片式分隔-圆角矩形卡片、线条分隔、无边框融合 |
| 布局参数 | 具体的布局细节 | 圆角矩形卡片，两卡片间保留一点留白，文字居中 |
| 文字样式 | 文字的字体、颜色、大小 | 字号中等、颜色深棕色、字体圆润可爱 |
| 画风特征 | 整体的绘画风格 | 粗描边、柔和色彩、简洁线条、扁平化卡通风格 |
| 质量要求 | 系列统一性的硬性要求 | IP外观全程一致、文字样式全程统一、文字不遮挡IP角色 |

### 三、复用方式

说明用户如何使用此设计方案快速生成同风格的新系列图文：
1. 提供此设计方案文档
2. 提供新的系列短句
3. 可选：同时提供IP角色文档获取更完整的角色描述

## 完整示例

```markdown
# 两格图文设计方案：米白小狗_允许一切发生

## 一、IP角色设计
- **角色名称**：米白小狗
- **基础物种**：小狗
- **毛色/肤色**：米白色短毛，柔软蓬松
- **配饰**：无
- **表情风格**：治愈软萌，温暖治愈
- **核心特征**：圆滚滚的身材、大大的黑眼睛、总是微笑的表情、耷拉着的小耳朵
- **形象照URL**：https://code.coze.cn/api/sandbox/.../ip-character.jpg

### 形象照
![IP角色形象照](https://code.coze.cn/api/sandbox/.../ip-character.jpg)

## 二、图文设计规范
- **图片比例**：竖版3:4比例（1536×2048像素）
- **分栏方案**：卡片式分隔-圆角矩形卡片
- **布局参数**：上下两个圆角矩形卡片，卡片几乎占满画面宽度，两卡片间保留一点留白，文字居中显示在卡片内
- **文字样式**：字号中等、颜色深棕色、字体圆润可爱
- **画风特征**：粗黑描边是核心特征、柔和色彩、简洁线条、扁平化卡通风格
- **质量要求**：
  - IP外观全程一致（米白色短毛、圆滚滚身材、大眼睛、微笑表情）
  - 文字样式全程统一（深棕色圆润字体）
  - 文字不遮挡IP角色

## 三、复用方式
使用此设计方案生成新系列图文时，请提供：
1. 此设计方案文档
2. 新的系列短句

**可选**：同时提供IP角色文档（`米白小狗_IP角色设定.md`），以获取更完整的角色特征描述和生图提示词。

示例：
"使用此设计方案，为以下短句生成系列图文：
不必急着成为大人
成长需要时间
慢慢来，比较快
"
```

## ⚠️ 注意事项

1. **形象照URL必须真实有效**：这是设计方案的核心资产，用于后续生成同风格图文
2. **图文设计规范必须详细**：避免模糊描述，确保AI能准确理解和执行
3. **质量要求必须明确**：这是保证系列图文统一性的关键
