## 两格图文设计原则

### 核心定位

两格图文是一种上下分栏的视觉叙事形式，通过上半句+下半句的结构，配合IP角色的情绪演绎，传达治愈、励志、共鸣的情感内核。

### 设计原则

1. **上下呼应**：上栏与下栏形成情绪递进，从铺垫到升华
2. **IP统一**：整个系列使用同一IP角色，仅通过姿态、神情表达变化
3. **风格一致**：所有图文的设计风格、色彩、字体、背景完全统一
4. **文字清晰**：上半句、下半句文字清晰可读，位置明确
5. **情绪表达**：IP角色通过肢体语言和神情准确传达短句含义

### 布局结构

```
┌─────────────────────────────────────
│  上栏（约50%）                       
│  ┌─────────────────────────────────┐
│  │  上半句文字（居中/偏上）          │
│  │                                 │
│  │  IP角色演绎（姿态/神情表达铺垫）   │
│  │                                 │
│  │  背景：偏冷/暗色调或统一色调      │
│  └─────────────────────────────────┘
├─────────────────────────────────────┤ ← 分隔线
│  下栏（约50%）                       
│  ┌─────────────────────────────────┐
│  │  下半句文字（居中/偏下）          │
│  │                                 │
│  │  IP角色演绎（姿态/神情表达升华）   │
│  │                                 │
│  │  背景：偏暖/亮色调或统一色调      │
│  └─────────────────────────────────┘
└─────────────────────────────────────
```

## 两格图文提示词模板

### 简化版模板（两格图文参考图快速通道专用）

**⚠️ 适用场景**：用户上传了两格图文参考图，明确要求参考该图的角色和设计风格生成系列图文。

**核心设计理念**：
- 生图模型能自动从参考图中提取视觉特征（角色外观、画风、布局）
- 过多的文字描述可能"干扰"视觉特征的传递
- 简化版提示词让生图模型自己理解参考图，减少信息失真

```
【生图配置】模式：图生图；参考图片：【用户上传的图片URL】；参考强度：高；

【分层参考规则】
┌─────────────────────────────────────────────────────────────────
│ ⛔ 必须保持一致（禁止修改）                                        
├─────────────────────────────────────────────────────────────────
│ - 角色外观：物种、毛色、体型、配饰与参考图完全一致                  
│ - 画风细节：描边、线条风格、色彩体系与参考图完全一致                
│ - 布局类型：上下分栏结构、分隔方式与参考图一致                     
│ - 文字样式：字体风格、字号、字色与参考图一致                       
├─────────────────────────────────────────────────────────────────
│ ⛔ 必须创新（禁止照搬）                                            
├─────────────────────────────────────────────────────────────────
│ - 上下分栏的文字内容：必须使用下方指定的上半句和下半句               
│ - 角色姿态：必须根据短句语义重新设计，禁止照搬参考图姿态            
│ - 角色动作：必须根据短句语义重新设计，禁止照搬参考图动作            
│ - 角色神情：必须根据短句语义重新设计，禁止照搬参考图神情            
│ - 分栏微场景：必须根据短句内容重新设计，禁止照搬参考图场景          
└─────────────────────────────────────────────────────────────────

上半句："❌【上半句内容】"
下半句："❌【下半句内容】"

【创新要求】（必须使用具体的姿态动作描述，禁止使用抽象情绪词）
- 上栏角色：❌【整体姿态+具体动作+面部神情+眼神方向，如：坐在窗边，双手托腮，眉头微皱，望向窗外下雨的天空】
- 下栏角色：❌【整体姿态+具体动作+面部神情+眼神方向，如：站起来，张开双臂，嘴角上扬，眼神充满希望】
- 上栏微场景：❌【具体场景+微场景元素，如：下雨的窗边，窗外有雨滴、玻璃水痕、远处路灯微光】
- 下栏微场景：❌【具体场景+微场景元素，如：阳光明媚的户外，有阳光光斑、远处山丘、淡淡云朵】
```

**⚠️ 简化版提示词的核心理念**：

| 做法 | 说明 |
|-----|------|
| **少描述角色外观** | 生图模型能从参考图中自动识别，无需文字赘述 |
| **明确"必须一致"vs"必须创新"** | 用表格形式清晰划分边界，避免模糊地带 |
| **禁止照搬 > 建议创新** | 用"禁止"而非"建议"，强制AI创新 |
| **仅保留必要信息** | 上半句、下半句、创新要求 |

**完整示例**：

```

【分层参考规则】
┌─────────────────────────────────────────────────────────────────
│ ⛔ 必须保持一致（禁止修改）

│ - 角色外观：物种、毛色、体型、配饰与参考图完全一致                  
│ - 画风细节：描边、线条风格、色彩体系与参考图完全一致                
│ - 布局类型：上下分栏结构、分隔方式与参考图一致                     
│ - 文字样式：字体风格、字号、字色与参考图一致                       
├─────────────────────────────────────────────────────────────────
│ ⛔ 必须创新（禁止照搬）                                            
├─────────────────────────────────────────────────────────────────
│ - 上下分栏的文字内容：必须使用下方指定的上半句和下半句               
│ - 角色姿态：必须根据短句语义重新设计，禁止照搬参考图姿态

上半句："不必强迫自己立刻改变"

【创新要求】
- 上栏角色：坐在窗边（姿态），双手托腮（动作），眉头微皱（神情），望向窗外下雨的天空（眼神方向）

- 上栏微场景：下雨的窗边，窗外有雨滴、玻璃水痕、远处路灯微光
- 下栏微场景：阳光明媚的户外，有阳光光斑、远处山丘、淡淡云朵
```

### 标准模板（角色参考图/纯风格参考图专用）

```
【生图配置】模式：图生图；参考图片：❌【用户上传的参考图URL】；

【分层参考规则】
- 必须参考：角色外观 ❌【物种/毛色/体型/配饰】与参考图完全一致
- 必须参考：画风细节 ❌【描边特征/线条风格/表情风格】与参考图完全一致
- 必须参考：布局类型 ❌【如：无边框融合/线条分隔/卡片式分隔】
- 参考但不强制：上下分栏的整体结构、文字装饰风格 ❌【呈现形式/装饰元素/排版样式/特效风格】
- 禁止姿态：❌【上栏禁止：XX姿态+XX动作；下栏禁止：XX姿态+XX动作】
- 禁止照搬：角色整体姿态、动作神情、背景场景、排版关系（必须根据短句创新）
- 系列统一：字体样式（字体/字号/字色）、角色外观、设计风格、画风细节全程一致；

基础配置层：两格图文，整体风格：【风格】，画风细节：❌【描边特征+线条风格+表情风格】，色彩体系：【配色】，字体风格：【字体】，背景：【背景质感】，图片比例：【图片比例描述，如"竖版3:4比例，宽度1536像素，高度2048像素"】，IP角色：❌【知名IP名称（若有）】+ ❌【画风类型】，❌【物种】，❌【毛色】，❌【毛发长度】，❌【体型描述】，❌【面部特征】，❌【眼镜样式】，❌【腮红】，❌【配饰】，❌【性格气质】；

核心信息锚点：✅ 必须保留的硬信息：1. 上半句文字："【上半句】"；2. 下半句文字："【下半句】"；文字样式要求：上半句和下半句文字使用相同的【字体风格】，字体粗细为【粗细】，文字颜色为【颜色名称】，字号适中且文字体积小于IP角色体积，文字不抢夺视觉焦点；文字装饰参考：文字呈现形式为❌【如：对话气泡/直接展示】，装饰元素包含❌【如：气泡边框+阴影/无装饰】，排版样式为❌【如：居中对称】，特效风格为❌【如：手写感】；

创意适配层：✨ IP角色演绎设计（禁止使用禁止姿态，必须根据短句语义创新，必须使用具体的姿态动作描述，禁止使用抽象情绪词）：- 上栏IP状态：❌【整体姿态+具体动作+面部神情+眼神方向，如：坐在窗边，双手托腮，眉头微皱，望向窗外下雨的天空】；- 下栏IP状态：❌【整体姿态+具体动作+面部神情+眼神方向，需与上半句形成情绪递进，如：推开门跑出去，张开双臂，嘴角上扬，眼神充满希望】；✨ 上下分栏布局：【布局描述，与参考图布局类型一致】；✨ 背景场景设计（禁止照搬参考图，必须根据短句意境创新，必须包含微场景元素）：上栏背景❌【具体场景描述+微场景元素，如：下雨的窗边，窗外有雨滴、玻璃水痕、远处路灯微光】，下栏背景❌【具体场景描述+微场景元素，如：阳光明媚的户外，有阳光光斑、远处山丘、淡淡云朵】；✨ 视觉符号（必须根据短句主题设计差异化元素，禁止所有图文使用相同符号）：- 辅助元素：❌【贴合短句主题的装饰元素，如：犹豫主题→雨滴、时钟、问号；成长主题→阳光、嫩芽、脚印】；

质量兜底规则：
1. 角色外观必须参考：IP角色外观与参考图完全一致（画风、物种、毛色、毛发长度、体型、面部特征、眼镜样式、腮红、配饰全部相同）
2. 画风细节必须参考：描边特征、线条风格、表情风格与参考图完全一致
3. 布局类型必须参考：使用与参考图相同的布局方案（无边框融合/线条分隔/卡片式分隔等）
4. 系列统一必须遵守：字体样式全程完全统一（字体、颜色、字号相同）
5. 创新约束必须遵守：角色整体姿态必须根据短句语义重新设计（禁止使用禁止姿态中的姿态动作）、动作神情必须创新、背景场景必须根据短句内容重新设计（禁止照搬参考图）、排版关系必须创新（角色与场景/文字的位置关系禁止照搬参考图）
6. 基础质量：文字不要遮挡IP角色，上下栏情绪递进自然，文字清晰可读
```

**⚠️ 若识别为知名IP角色，IP角色描述必须包含IP名称**：

```

```

## 四大模块详解

### 模块零：生图配置（最高优先级）

```
┌─────────────────────────────────────────────────────────────────────────────
│  ⛔ 强制规则（违反即失败）                                                     
├─────────────────────────────────────────────────────────────────────────────
│  1. 系列图文生成必须使用【图生图模式】，禁止使用文生图模式                       
│  2. 每条提示词开头必须包含【生图配置】模块                                     
│  3. 必须明确声明"模式：图生图"                                                
│  4. 参考强度必须声明为"高"                                                    
│  5. 两格图文参考图必须包含【分层参考规则】模块                                  
└─────────────────────────────────────────────────────────────────────────────
```

**必填内容**：

| 配置项 | 说明 | 示例 |
|-------|------|------|
| 模式 | 明确声明使用图生图模式 | 模式：图生图 |
| 参考图片 | 用户上传的图片URL | 参考图片：https://code.coze.cn/api/sandbox/.../file.jpg |
| 参考强度 | 一致性要求 | 参考强度：高（保持角色外观完全一致，仅调整姿态表情） |

**⚠️ 参考图片URL格式要求**：

```
┌─────────────────────────────────────────────────────────────────────────────
│  ⛔ 参考图片URL格式规范                                                        
├─────────────────────────────────────────────────────────────────────────────
│  ✅ 正确格式：用户上传的图片URL（支持短链接和原始URL）                                                
│     https://code.coze.cn/api/sandbox/coze_coding/file/proxy?.../file.jpg   
│                                                                              
│  ⚠️ 生图模型支持短链接和原始URL，直接使用用户上传的URL即可                      
└─────────────────────────────────────────────────────────────────────────────
```

## 分栏设计方案

分栏设计是两格图文的核心布局方式，详见 [two-panel-layout-guide.md](two-panel-layout-guide.md)。

### 方案概览

| 方案 | 设计特点 | 提示词描述示例 |
|-----|---------|---------------|
| **线条分隔** | 用线分隔上下栏 | 中间用横线装饰分隔 |
| **色块分隔** | 上下栏不同底色 | 上栏淡粉色纯色底，下栏淡蓝色纯色底 |
| **渐变过渡** | 颜色渐变融合 | 从上栏淡粉色渐变过渡到下栏淡蓝色 |
| **场景切换** | 上下不同场景 | 上栏夜晚星空，下栏白天阳光 |
| **IP跨越** | IP跨越上下栏 | IP角色身体横跨分界线 |
| **无边框融合** | 无明显分隔 | 统一背景，无分隔线或色块差异 |
| **卡片式分隔** | 上下各为独立卡片 | 上栏为圆角矩形卡片，下栏为圆角矩形卡片 |
