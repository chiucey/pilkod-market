## 分栏设计方案概览

上下分栏有**7种设计方案**，每种方案有不同的视觉效果和适用场景：

| 方案 | 设计特点 | 视觉效果 | 适用风格 |
|-----|---------|---------|---------|
| **线条分隔** | 用线分隔上下栏 | 简洁明确 | 简约、专业 |
| **色块分隔** | 上下栏不同底色 | 色彩鲜明 | 活泼、对比 |
| **渐变过渡** | 颜色渐变融合 | 柔和连贯 | 治愈、文艺 |
| **场景切换** | 上下不同场景 | 叙事性强 | 故事感、成长 |
| **IP跨越** | IP跨越上下栏 | 动态生动 | 创意、趣味 |
| **无边框融合** | 无明显分隔 | 极简自然 | 高级、简约 |
| **卡片式分隔** | 上下各为独立卡片 | 结构清晰 | 经典、百搭 |

## 方案一：线条分隔

### 设计特点

用一条线（或装饰性线条）分隔上下栏，边界清晰明确。

### 线条类型

| 线条类型 | 视觉效果 | 适用风格 | 示例描述 |
|---------|---------|---------|---------|
| **实线** | 简洁利落，边界清晰 | 简约风格、励志主题 | 一条细实线横贯画面 |
| **虚线** | 轻盈透气，若隐若现 | 文艺风格、清新主题 | 点状虚线分隔 |
| **波浪线** | 柔和活泼，有流动感 | 治愈风格、温柔主题 | 波浪形曲线分隔 |
| **点划线** | 精致有序，有设计感 | 精致风格、知性主题 | 点与短划交替 |
| **装饰线** | 创意分隔，增加趣味 | 可爱风格、活泼主题 | 带星星/心形装饰的线 |
| **手绘线** | 随性自然，有温度 | 手账风格、温暖主题 | 不规则手绘线条 |
| **双线** | 层次丰富，有厚度 | 复古风格、经典主题 | 两条平行细线 |
| **粗线** | 边界分明，有力量感 | 励志风格、硬朗主题 | 较粗的实线分隔 |

### 提示词描述示例

```
上下分栏布局：上栏和下栏各占画面一半，中间用波浪线装饰分隔（柔和曲线，颜色与背景协调）
```

```
上下分栏布局：上栏和下栏各占画面一半，中间用实线分隔（细直线，深棕色，简洁利落）
```

## 方案二：色块分隔

### 设计特点

上下栏使用不同的底色，通过色彩差异自然区分，无需线条分隔。

### 色块搭配方案

| 搭配方案 | 上栏底色 | 下栏底色 | 情绪表达 | 适用主题 |
|---------|---------|---------|---------|---------|
| 治愈渐变 | 淡粉色 | 淡蓝色 | 从焦虑到释然 | 治愈类、释然类 |
| 温暖渐变 | 淡橙色 | 奶油黄 | 从期待到满足 | 温暖类、快乐类 |
| 清新渐变 | 薄荷绿 | 天蓝色 | 从成长到希望 | 成长类、希望类 |
| 文艺渐变 | 灰蓝色 | 米白色 | 从思考到沉淀 | 文艺类、思考类 |
| 活力渐变 | 亮黄色 | 橙色 | 从能量到行动 | 活力类、励志类 |
| 梦幻渐变 | 薰衣草紫 | 淡粉色 | 从迷茫到觉醒 | 梦幻类、治愈类 |

### 提示词描述示例

上下分栏布局：上栏和下栏各占画面一半，无分隔线，通过底色区分。上栏背景淡粉色纯色底，下栏背景淡蓝色纯色底，色彩交界处干净利落

## 方案三：渐变过渡

### 设计特点

上下栏颜色通过渐变自然融合，无明确边界，视觉连贯柔和。

### 渐变方式

| 渐变类型 | 视觉效果 | 适用风格 |
|---------|---------|---------|
| **上下渐变** | 从上到下颜色自然过渡 | 治愈、连贯 |
| **对角渐变** | 斜向颜色变化，有动感 | 活力、创意 |
| **中心渐变** | 中间向四周扩散 | 梦幻、聚焦 |
| **多色渐变** | 多个颜色平滑过渡 | 丰富、层次 |

### 提示词描述示例

```
上下分栏布局：上栏和下栏各占画面一半，无分隔线，背景为整体渐变。从上栏淡粉色渐变过渡到下栏淡蓝色，过渡自然柔和，无明确分界线
```

```
上下分栏布局：上栏和下栏各占画面一半，背景为整体渐变。从上栏灰蓝色渐变过渡到下栏奶油白，中间过渡区域柔和模糊
```

## 方案四：场景切换

### 设计特点

上下栏是不同的场景/环境，通过场景本身区分上下，叙事性强。

### 场景搭配方案

| 场景搭配 | 上栏场景 | 下栏场景 | 叙事含义 | 适用主题 |
|---------|---------|---------|---------|---------|
| 室内到户外 | 房间内 | 户外自然 | 从封闭到开放 | 成长类、突破类 |
| 黑夜到白天 | 夜晚星空 | 白天阳光 | 从迷茫到希望 | 励志类、希望类 |
| 城市到自然 | 城市建筑 | 森林田野 | 从喧嚣到宁静 | 治愈类、释然类 |
| 雨天到晴天 | 下雨天 | 晴朗天空 | 从低谷到转机 | 成长类、正能量 |
| 单色到彩色 | 黑白/单色 | 彩色 | 从平淡到精彩 | 蜕变类、成长类 |
| 独处到相伴 | 一个人 | 有伙伴/宠物 | 从孤独到陪伴 | 温暖类、陪伴类 |

### 提示词描述示例

```
上下分栏布局：上栏和下栏各占画面一半，通过场景切换区分。上栏场景为夜晚星空背景（IP角色抬头仰望），下栏场景为白天阳光明媚（IP角色迎着阳光），场景自然过渡
```

```
上下分栏布局：上栏和下栏各占画面一半，通过场景切换区分。上栏为单色（黑白或低饱和度）场景，下栏为彩色丰富场景，象征从平淡到精彩的变化
```

## 方案五：IP跨越

### 设计特点

IP角色不被上下栏分割，而是跨越上下两部分，增强动态感和生动性。

### 跨越方式

| 跨越类型 | 设计效果 | 适用场景 |
|---------|---------|---------|
| **身体跨越** | IP身体横跨上下栏，头在上栏，腿在下栏 | 动态、活泼 |
| **动作跨越** | IP从一个栏"跳"到另一个栏 | 运动、成长 |
| **视线跨越** | IP在上栏看向/指向下栏 | 连贯、叙事 |
| **道具跨越** | IP持有的道具（如气球）跨越上下栏 | 趣味、创意 |

### 提示词描述示例

```
上下分栏布局：上栏和下栏各占画面一半，IP角色跨越上下栏。IP角色身体横跨分界线，头部在上栏（表情略带焦虑），下半身在下栏（姿态轻松），增强上下栏的连贯性
```

```
上下分栏布局：上栏和下栏各占画面一半，IP角色动作跨越。IP角色从上栏"跳下"到下栏，动作连贯，上下栏背景色自然过渡
```

## 方案六：无边框融合

### 设计特点

无任何分隔线或色块差异，上下栏通过内容（文字位置、IP姿态）自然区分，极简高级。

### 设计要点

| 要点 | 说明 |
|-----|------|
| 统一背景 | 整个画面使用统一背景，无上下差异 |
| 文字定位 | 上半句文字偏上方，下半句文字偏下方 |
| IP定位 | 上栏IP和下栏IP通过姿态区分情绪 |
| 留白呼吸 | 上下栏之间保持适当留白，自然分隔 |

### 提示词描述示例

```
上下分栏布局：上栏和下栏各占画面一半，无边框融合设计。整个画面使用统一水彩渐变背景，无分隔线或色块差异，上半句文字位于画面上方区域，下半句文字位于画面下方区域，中间通过IP角色姿态和留白自然区分上下
```

```
上下分栏布局：上栏和下栏各占画面一半，无边框融合设计。统一奶油白背景，无任何分隔元素，上半句文字偏上，下半句文字偏下，中间为IP角色和留白区域，整体简洁高级
```

## 方案七：卡片式分隔

### 设计特点

上下栏各为独立的卡片，每张卡片有独立的边框/背景，卡片之间可分开或有间距，视觉结构清晰。

**⛔ 卡片式分栏禁止添加分隔线**：

```
┌─────────────────────────────────────────────────────────────────
│  ⚠️ 重要规则（违反即失败）                                        
├─────────────────────────────────────────────────────────────────
│  卡片本身已经起到视觉分隔作用，无需额外添加分隔线！                 
│                                                                   
│  ❌ 禁止描述：                                                    
│  "上栏和下栏各占画面一半，中间用波浪线装饰分隔"                    
│  （这是"线条分隔"方案的描述，不是"卡片式分隔"方案！）               
│                                                                   
│  ✅ 正确描述：                                                    
│  "两个卡片之间保留一点点留白"                                     
│  （卡片式分隔通过卡片本身和间距来区分上下栏，不使用分隔线）         
└─────────────────────────────────────────────────────────────────
```

**⚠️ 卡片式分栏核心规范（必须遵守）**：

```
┌─────────────────────────────────────────────────────────────────
│  卡片式分栏提示词必须包含以下6个要素，确保系列图文统一性            
├─────────────────────────────────────────────────────────────────
│  1. 卡片形状：圆角矩形/直角矩形/波浪边/云朵形/撕纸边/便签纸等      
│  2. 卡片尺寸：高度约为画面的一半减去间距，宽度几乎占满整个画面      
│  3. 卡片间距：两个卡片之间有细小间距（约5-10像素）露出背景          
│  4. 卡片位置：上下卡片居中对齐，左右边距相等                       
│  5. 卡片样式：根据卡片类型选择合适的装饰效果                       
│  6. 文字位置：上半句文字在上卡片内居中，下半句文字在下卡片内居中    
└─────────────────────────────────────────────────────────────────
```

### 卡片样式类型

| 卡片类型 | 视觉效果 | 适用风格 | 示例描述 |
|---------|---------|---------|---------|
| **圆角矩形卡片** | 柔和友好，经典百搭 | 通用、治愈 | 上下各一个圆角矩形卡片 |
| **直角矩形卡片** | 简洁利落，有力量感 | 专业、励志 | 上下各一个直角矩形卡片 |
| **波浪边卡片** | 活泼可爱，有童趣 | 可爱、活泼 | 卡片边缘为波浪形状 |
| **云朵形卡片** | 梦幻柔软，有治愈感 | 治愈、温柔 | 卡片形状像云朵 |
| **撕纸边卡片** | 手账风格，有温度 | 手账、文艺 | 边缘像撕纸的不规则形状 |
| **便签纸卡片** | 生活感，有烟火气 | 生活、日常 | 像便签纸的样子，带虚线边 |
| **拍立得卡片** | 复古怀旧，有故事感 | 复古、文艺 | 像拍立得照片的样子 |
| **胶带粘贴卡片** | 手账感，有创意 | 手账、创意 | 卡片四角有胶带装饰 |
| **邮票边卡片** | 独特个性，有设计感 | 文艺、个性 | 边缘有邮票齿孔效果 |
| **气泡对话框卡片** | 趣味对话，有互动感 | 可爱、趣味 | 像对话气泡的形状 |

### 卡片装饰样式

| 装饰类型 | 视觉效果 | 示例描述 |
|---------|---------|---------|
| **阴影效果** | 卡片有立体感，悬浮效果 | 卡片带柔和阴影，有立体悬浮感 |
| **描边效果** | 卡片轮廓清晰，边界明确 | 卡片有深色描边，轮廓清晰 |
| **纹理效果** | 卡片有质感，增加细节 | 卡片内有细格纹理/点状纹理 |
| **装饰角** | 卡片四角有装饰元素 | 卡片四角有小星星/花朵装饰 |
| **边框装饰** | 卡片边框有花纹/图案 | 边框有简单的花纹装饰 |
| **渐变填充** | 卡片内部颜色渐变 | 卡片背景从浅到深渐变 |

### 卡片排列方式

| 排列方式 | 视觉效果 | 示例描述 |
|---------|---------|---------|
| **上下紧贴** | 卡片紧密相连 | 上下卡片紧密相连，无间距 |
| **上下分离** | 卡片有留白 | 上下卡片之间有细小间距，中间露出背景 |
| **错位排列** | 动感活泼 | 上下卡片左右错开一点位置 |
| **大小差异** | 强调下半句 | 上卡片略小，下卡片略大 |

### ⚠️ 禁止使用百分比数字

生图模型可能将"45%"、"90%"等数字误解为需要绘制的文字！

✅ **正确描述方式**：
- "高度约为画面的一半"（代替"高度占画面45%"）
- "卡片宽度几乎占满整个画面，左右各留极窄边距"（代替"宽度占画面90%"）

## 方案选择建议

### 根据主题情绪选择

| 主题情绪 | 推荐方案 | 推荐理由 |
|---------|---------|---------|
| 治愈/释然 | 渐变过渡、云朵形卡片 | 柔和连贯，符合治愈氛围 |
| 励志/成长 | 场景切换、IP跨越 | 叙事性强，展现变化过程 |
| 文艺/思考 | 无边框融合、撕纸边卡片 | 极简高级，有质感 |
| 活泼/可爱 | 波浪边卡片、波浪线分隔 | 活泼有趣，增添童趣 |
| 生活/日常 | 便签纸卡片、圆角矩形卡片 | 生活感强，接地气 |
| 专业/励志 | 实线分隔、直角矩形卡片 | 简洁利落，有力量感 |

### 根据设计风格选择

| 设计风格 | 推荐方案 | 推荐理由 |
|---------|---------|---------|
| 治愈插画风 | 渐变过渡、云朵形卡片 | 柔和梦幻，符合治愈调性 |
| 简笔卡通风 | 波浪线分隔、波浪边卡片 | 活泼可爱，有童趣 |
| 日系盐系风 | 无边框融合、圆角矩形卡片 | 简约清新，高级感 |
| 手账风格 | 撕纸边卡片、胶带粘贴卡片 | 手账质感，有温度 |
| 复古风格 | 拍立得卡片、双线分隔 | 复古怀旧，有故事感 |

### 根据短句内容选择

| 短句类型 | 推荐方案 | 推荐理由 |
|---------|---------|---------|
| 困境→释然 | 渐变过渡、场景切换（黑→彩） | 视觉化展现转变 |
| 问题→答案 | 气泡对话框卡片 | 对话形式，问答清晰 |
| 铺垫→升华 | 卡片式（上小下大） | 强调升华的结论 |
| 对比→统一 | 色块分隔（对比色） | 对比鲜明，视觉冲击 |

## 方案组合使用

某些情况下，可以组合多种方案，创造更丰富的视觉效果：

| 组合方案 | 效果描述 |
|---------|---------|
| 卡片式 + 渐变背景 | 卡片漂浮在渐变背景上，层次丰富 |
| 场景切换 + IP跨越 | IP从上栏场景穿越到下栏场景 |
| 卡片式 + 阴影效果 | 卡片立体悬浮，增加空间感 |
| 线条分隔 + 装饰线 | 分隔线上有星星/心形装饰 |
