# Elsevier Journal Paper Format Guidelines

## Basic Requirements

### Page Setup
- Page size: A4
- Margins: 2.5 cm top/bottom, 2.5 cm left/right
- Single spacing (some journals require double)
- Font: Times New Roman or Arial, 10 pt

### Title
- Listed separately on the title page
- Concise, typically no more than 20 words
- Include keyword information

### Abstract
- 150-300 words
- No indentation, standalone paragraph
- Include research background, objective, methods, results, conclusions
- Structured or unstructured abstract accepted

### Graphical Abstract
- Recommended to provide
- Size: no more than 8 cm width × 20 cm height
- Clearly present core findings

## Text Structure

### Highlights
- 3-5 bullet points
- Each no more than 85 characters
- Summarize core innovations

### Keywords
- 5-7 terms
- Alphabetically ordered
- Not repeated from abstract

### Nomenclature
- Define abbreviations on first use
- SI units
- Chemical nomenclature following IUPAC

### Table Format
- Use journal template
- Three-line table
- 8pt font allowed within tables

### Figure Legends
- Standalone paragraph
- Explanatory text, not descriptive
- 8-9pt font

## Materials Science Formatting Key Points

### Chemical Formulas and Mathematical Expressions
- Chemical formulas: Fe2O3 (subscript format)
- Mathematical variables: italic
- Units: roman font

### Instrument Description
- Equipment model (manufacturer, city, country)
- Indicate standard methods used

### Crystal Structure Description
- Crystal system, space group
- Unit cell parameters
- Atomic coordinates

### XRD Data Description
- 2θ angles (degree symbol)
- hkl indices (italic)
- PDF card number

## Tense and Voice Usage

### Recommended Voice
- Methods section: passive voice preferred
- Results section: active/passive acceptable
- Conclusions section: active voice more direct

### Tense Selection
| Content | Recommended Tense |
|---------|-------------------|
| Known facts | Present |
| This work | Past |
| Figure/table description | Present |
| Future work | Will |

## Common Sentences

### Introduction
- "In recent years, ... has emerged as a promising candidate for..."
- "Although considerable efforts have been devoted to..., the fundamental mechanism remains unclear."
- "Motivated by ..., we herein report..."

### Experimental
- "The precursor was prepared by dissolving ... in ... under magnetic stirring."
- "The mixture was transferred to a Teflon-lined autoclave and maintained at ... °C for ... h."
- "The obtained product was washed with ... and dried at ... °C overnight."

### Results
- "The crystalline phase was identified by XRD, as shown in Fig. 1."
- "The morphology and microstructure were examined by SEM and TEM (Fig. 2)."
- "Notably, the as-prepared ... exhibited excellent ... performance."

### Discussion
- "These results can be explained by the formation of..."
- "Based on the above analysis, it is believed that..."
- "The superior performance can be attributed to the synergistic effect of..."

## Reference Format

### Journal Articles
```
[1] Author1, Author2, Author3. Title of article. Journal Name Year, Volume, Pages. DOI
```

### Books
```
[2] Author. Book Title; Publisher: City, Year.
```

### Conference Papers
```
[3] Author. in Title of Conference, Location, Year; Pages.
```

## Common Errors to Avoid

1. Abstract too long or contains citations
2. Keywords repeated in abstract
3. Insufficient figure resolution
4. Inconsistent reference format
5. Abbreviations not defined on first use
