# 股票查询 Skill

基于 AkShare 接口，适配 OpenClaw 框架的 A 股/港股实时行情查询技能。

## 核心功能

- **实时行情查询**：支持 A 股和港股的实时价格、涨跌幅、成交量、成交额
- **智能识别**：支持股票代码（6位数字）和中文名称两种查询方式
- **新闻资讯**：提供 A 股个股的最新新闻（东方财富数据源）
- **缓存优化**：内置 30 秒 TTL 缓存，减少重复 API 调用
- **重试机制**：网络异常时自动重试（最多3次），提高稳定性

## 触发条件

| 关键词 | 说明 |
|--------|------|
| 行情 | 股票行情查询 |
| 股价 | 当前价格查询 |
| 涨跌 | 涨跌幅信息 |
| 新闻 | 个股新闻查询 |
| 港股/hk | 港股市场查询 |

## 数据来源

- **A股数据**：`akshare` → `stock_zh_a_spot_em()`
- **港股数据**：`akshare` → `stock_hk_spot()`
- **新闻数据**：`akshare` → `stock_news_em()`

## 技术特性

| 特性 | 说明 |
|------|------|
| 缓存机制 | 30秒TTL，防止频繁请求 |
| 重试策略 | 最大3次重试，1秒间隔 |
| 错误处理 | 优雅降级，返回友好错误信息 |

```
用户: 港股 00700

      现价：xxx
      涨跌：xxx
      涨跌幅：xxx%

      成交额：xxx 元

用户: 新闻 贵州茅台
助手: 【时间】新闻标题1 (来源)
      【时间】新闻标题2 (来源)
      ...
```
