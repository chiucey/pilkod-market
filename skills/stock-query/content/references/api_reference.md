# 股票查询技能 - API 参考文档

## 模块概述

本模块提供 A 股和港股市场的实时行情查询及个股新闻资讯服务。

## 安装依赖

```bash
pip install akshare>=1.10.0 pandas>=1.5.0
```

## 核心函数

### `run(query: str) -> str`

技能主入口函数，处理自然语言查询。

**参数:**
- `query` (str): 自然语言查询字符串

**返回:**
- `str`: 格式化的查询结果

**支持的查询类型:**

| 查询类型 | 示例 | 说明 |
|---------|------|------|
| A股行情 | `股票行情 000001` | 查询平安银行实时行情 |
| A股名称查询 | `股价 贵州茅台` | 通过名称查询 |
| 港股行情 | `港股 00700` | 查询腾讯控股 |
| A股新闻 | `新闻 平安银行` | 获取个股新闻 |

---

### `get_a_spot_data() -> pd.DataFrame`

获取 A 股全量实时行情数据（带缓存）。

**返回:**
- `pd.DataFrame`: A股实时行情数据

**字段说明:**
| 字段 | 类型 | 说明 |
|------|------|------|
| 代码 | str | 股票代码（6位数字） |
| 名称 | str | 股票名称 |
| 最新价 | float | 当前价格 |
| 涨跌额 | float | 价格变化 |
| 涨跌幅 | float | 涨跌幅百分比 |
| 成交量 | int | 成交量（手） |
| 成交额 | float | 成交额（元） |

---

### `get_hk_spot_data() -> pd.DataFrame`

获取港股全量实时行情数据（带缓存）。

**返回:**
- `pd.DataFrame`: 港股实时行情数据

**字段说明:**
| 字段 | 类型 | 说明 |
|------|------|------|
| 代码 | str | 股票代码 |
| 名称 | str | 股票名称 |
| 现价 | float | 当前价格 |
| 涨跌 | float | 价格变化 |
| 涨跌幅 | float | 涨跌幅百分比 |
| 成交量 | int | 成交量（股） |
| 成交额 | float | 成交额（元） |

---

### `get_a_news(symbol: str) -> str`

获取 A 股个股新闻。

**参数:**
- `symbol` (str): A股股票代码（6位数字）

**返回:**
- `str`: 格式化新闻列表，每条包含时间、标题和来源

**示例输出:**
```
【2024-01-15 10:30】某公司发布年度业绩预告 (东方财富)
【2024-01-14 15:20】行业政策利好刺激板块上涨 (证券时报)
...
```

## 内部函数

### `cached(ttl: int)`

缓存装饰器，实现带 TTL 的函数结果缓存。

**参数:**
- `ttl` (int): 缓存有效期（秒），默认 30 秒

**用法:**
```python
@cached(ttl=60)
def get_data():
    # 首次调用会执行函数并缓存结果
    # 60秒内的后续调用直接返回缓存
    return fetch_data()
```

---

### `with_retry(func, retries: int, delay: int)`

重试装饰器/函数，处理网络异常。

**参数:**
- `func` (callable): 要执行的函数
- `retries` (int): 最大重试次数，默认 3
- `delay` (int): 重试间隔（秒），默认 1

**返回值:**
- 函数执行结果

## 数据源

| 市场 | 数据接口 | 说明 |
|------|---------|------|
| A股行情 | `akshare.stock_zh_a_spot_em()` | 东方财富 A 股实时行情 |
| 港股行情 | `akshare.stock_hk_spot()` | 东方财富港股实时行情 |
| A股新闻 | `akshare.stock_news_em(symbol)` | 东方财富个股新闻 |

## 错误处理

| 错误情况 | 返回信息 |
|---------|---------|
| 股票未找到 | `未找到 A股 代码或名称 'xxx'` |
| 无新闻数据 | `未找到相关新闻` |
| 网络异常 | `新闻查询失败：xxx` |
| 港股新闻 | `港股新闻暂未支持...` |

## 缓存机制

- **TTL**: 30 秒
- **缓存键**: `(函数名, 参数元组, 关键字参数元组)`
- **适用函数**: `get_a_spot_data()`, `get_hk_spot_data()`

## 重试策略

- **最大重试次数**: 3
- **重试间隔**: 1 秒
- **适用场景**: 网络请求异常

## 使用示例

```python
from stock_query import run

# 查询A股行情
result = run("股票行情 000001")
print(result)

# 查询港股
result = run("港股 00700")
print(result)

# 查询新闻
result = run("新闻 贵州茅台")
print(result)
```

## 注意事项

1. 港股新闻功能暂未支持
2. 名称查询会自动转换为代码
3. 缓存可减少 API 调用频率
4. 网络异常时会自动重试
