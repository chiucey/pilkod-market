#### 3.2 加速寿命测试(ALT)设计

```python
# 阿伦尼乌斯-功率疲劳复合模型
class AcceleratedLifeModel:
    """
    光刻机关键部件寿命预测模型

    温度加速因子：AF_T = exp(Ea/k × (1/T_use - 1/T_acc))
    功率循环加速因子：AF_P = (ΔP_acc/ΔP_use)^n
    综合加速因子：AF_total = AF_T × AF_P

    参数：
    - Ea: 激活能 (eV)
    - k: 波尔兹曼常数 (8.617×10⁻⁵ eV/K)
    - T_use/T_acc: 使用/加速温度 (K)
    - n: 功率指数 (通常取2-3)
    """

    def __init__(self, ea=0.7, n=2.5):
        self.ea = ea  # 激活能
        self.n = n    # 功率指数

    def temperature_af(self, t_use, t_acc):
        k = 8.617e-5  # eV/K
        return exp(self.ea/k * (1/t_use - 1/t_acc))

    def power_af(self, p_use, p_acc):
        return (p_acc/p_use) ** self.n

    def total_af(self, t_use, t_acc, p_use, p_acc):
        return self.temperature_af(t_use, t_acc) * self.power_af(p_use, p_acc)

    def predict_life(self, acc_life, t_use, t_acc, p_use, p_acc):
        af = self.total_af(t_use, t_acc, p_use, p_acc)
        return acc_life * af
```
