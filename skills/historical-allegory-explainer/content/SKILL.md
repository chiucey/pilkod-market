# 历史典故讲解图片生成器

将历史典故转化为通俗易懂的讲解图片，让人一眼看懂故事含义。

## 工作流程

### 1. 理解典故

接收用户输入的历史典故名称或描述：

- 常见成语典故（如：刻舟求剑、亡羊补牢、掩耳盗铃）
- 历史人物故事（如：卧薪尝胆、霸王别姬）
- 古代寓言（如：庄周梦蝶、塞翁失马）
- 文学作品典故（如：黛玉葬花、大闹天宫）

### 2. 提取核心要素

分析典故并提取以下关键信息：

- **故事背景**：时代、人物、地点
- **核心情节**：故事的起承转合
- **主要人物**：角色及其性格特征
- **转折点**：故事的关键节点
- **寓意启示**：故事要传达的道理
- **现代启示**：对当下的借鉴意义

### 3. 生成讲解图片

使用图像生成工具创建**4格漫画式讲解图**：

**图片1 - 故事开场**
- 呈现故事发生的背景和环境
- 人物首次登场
- 铺垫故事起因

**图片2 - 矛盾发展**
- 展示故事的核心冲突
- 人物做出关键选择或行动
- 推动情节发展

**图片3 - 高潮转折**
- 故事的关键转折点
- 矛盾达到顶点
- 人物面临考验

**图片4 - 结局与启示**
- 展示故事的结局
- 揭示寓意和道理
- 配上简洁的启示文字

### 4. 输出格式

每张图片应包含：

- 场景插图（简洁清晰的风格）
- 场景标题（简短概括）
- 2-3句关键描述（口语化，易理解）
- 底部添加故事寓意总结

## 图片生成要求

### 视觉风格

- **风格**：中国古典与现代简约结合的插画风格
- **色调**：温暖古朴，符合历史氛围
- **人物**：简笔画风格，表情夸张但传神
- **背景**：简化的中国传统元素（山水、建筑、器物）

### 尺寸与格式

- 比例：3:4 竖版，适合手机阅读
- 分辨率：1080P
- 每张图片底部留白用于添加文字说明

### 文字排版

- 使用简洁易读的中文字体
- 场景标题用粗体
- 描述文字用正常字重
- 底部启示用醒目的对比色

## 示例典故讲解

### 输入
用户输入："刻舟求剑"

### 输出流程

1. **典故分析**：
   - 出处：《吕氏春秋·察今》
   - 背景：战国时期
   - 人物：楚国人
   - 情节：渡江时剑掉水中，在船舷刻记号
   - 寓意：做事不知变通，不知随势而变

2. **图片生成**：
   - 图1：江边渡船，乘客携带宝剑，准备过江
   - 图2：宝剑不慎滑落江中，乘客在船舷刻下记号
   - 图3：船靠岸后，乘客按记号下水捞剑，一无所获
   - 图4：恍然大悟的表情，配上"刻舟求剑"的寓意

3. **最终交付**：
   - 4张讲解图片
   - 每张带有场景描述
   - 底部总结：做事要随机应变，不能固守老经验

## 注意事项

1. **准确性**：确保典故内容的历史准确性
2. **通俗性**：用现代人易懂的语言解释
3. **趣味性**：通过夸张的视觉元素增加趣味
4. **教育性**：突出故事的教育意义和现代启示
5. **视觉一致性**：保持4张图片风格统一
