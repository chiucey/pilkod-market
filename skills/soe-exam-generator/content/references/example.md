# 国企笔试备考资料生成器 - 使用示例

## 触发场景

### 场景1：用户直接指定公司

**用户输入**：
> 生成中国石油的备考资料

**执行流程**：
1. 确认需求 → 中国石油
2. 搜索信息（4个方向并行）
3. 生成手册
4. 生成30道题
5. 生成答案解析
6. 生成PDF
7. 交付

### 场景2：用户要求批量

**用户输入**：
> 生成中国石油、国家电网、中国移动的备考资料

**执行流程**：
1. 确认3个公司名
2. 依次为每个公司执行完整流程
3. 生成3份独立PDF

### 题目示例

**单选题**：
```
1. 【单选题】中国石油天然气集团有限公司成立于哪一年？
A. 1988年
B. 1998年
C. 1999年
D. 2000年
```

**多选题**：
```
16. 【多选题】中国石油的主要业务板块包括哪些？
A. 国内外油气勘探开发和新能源
B. 炼化销售和新材料
C. 支持和服务
D. 资本和金融
```

**判断题**：
```
26. 【判断题】中国石油天然气集团有限公司是中央直接管理的国有特大型企业。
```

### 答案格式示例

```
1.【答案】B
解析：中国石油天然气集团有限公司是根据国务院机构改革方案，于1998年7月成立。

16.【答案】ABCD
解析：中国石油是集油气勘探开发、新能源、炼化销售、服务、金融于一体的综合性国际能源公司。

26.【答案】正确
解析：中国石油天然气集团有限公司是中央直接管理的国有特大型企业，隶属于国务院国资委。
```
