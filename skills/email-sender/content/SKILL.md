# 邮件发送专家

## 核心能力

- 发送单封或批量邮件
- 撰写专业邮件内容
- 支持 SMTP 配置
- 支持多种邮件服务（SendGrid、Mailgun、自定义 SMTP）
- HTML 邮件与纯文本邮件
- 附件支持
- 邮件模板管理

## 使用场景

1. **发送通知邮件**：系统通知、订单确认、密码重置等
2. **发送营销邮件**：推广内容、新闻通讯、活动邀请
3. **发送事务邮件**：发票、收据、确认信息
4. **批量邮件发送**：用户分组、精准营销

## 工作流程

### 1. 邮件配置

确保已配置以下环境变量：
- SMTP_HOST / SMTP_PORT
- SMTP_USER / SMTP_PASSWORD
- 发送者邮箱地址

### 2. 邮件构建

定义邮件的核心要素：
- **收件人**：单个或多个邮箱地址
- **主题**：清晰简洁的邮件主题
- **正文**：HTML 或纯文本内容
- **附件**：可选的文件附件

### 3. 发送执行

使用 send_email 函数发送邮件，支持：
- 同步发送（立即发送）
- 批量发送（分批处理大量邮件）

## 邮件撰写规范

### 主题行
- 简洁明了，控制在 50 字符以内
- 避免垃圾邮件关键词
- 体现邮件核心价值

### 正文结构
1. 礼貌称谓
2. 邮件目的说明
3. 详细内容/行动号召
4. 结束语与签名

### 最佳实践
- 移动端适配
- 避免过多图片导致加载缓慢
- 清晰的 CTA 按钮
- 退订链接（营销邮件必需）

## 邮件类型模板

### 通知邮件
```
主题：[系统通知] {通知标题}
正文：尊敬的 {用户名}，
{通知内容}
如有疑问请联系客服。
```

### 营销邮件
```
主题：{促销标题} - {限时优惠}
正文：亲爱的 {用户名}，
{促销内容}
{CTA 按钮}
```

### 事务邮件
```
主题：{事务类型} #{订单号}
正文：您好 {用户名}，
{事务详情}
{相关链接}
```

## 错误处理

- **SMTP 连接失败**：检查网络和配置
- **收件人无效**：验证邮箱格式
- **附件过大**：压缩或使用云存储链接
- **发送频率限制**：实施退避策略

## 技术实现

使用 Python smtplib 或第三方邮件服务 API：
- smtplib：标准库，无需额外依赖
- SendGrid API：大规模发送推荐
- Mailgun API：灵活性高

执行邮件发送任务后，返回：
- 发送状态（成功/失败）
- 成功发送数量
- 失败原因（如有）
