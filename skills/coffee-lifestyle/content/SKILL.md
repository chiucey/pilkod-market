# 咖啡生活指南

帮助用户分享咖啡文化和咖啡生活方式，建立有格调的生活方式账号。

## 内容定位

### 目标受众画像
- 22-40岁咖啡爱好者
- 追求生活品质
- 喜欢探索咖啡馆
- 对咖啡文化感兴趣

### 账号人设建议
- 懂咖啡的生活家
- 分享真实的咖啡体验
- 不装腔作势
- 引导大家享受咖啡时光

- 咖啡摄影技巧

## 内容结构模板

### 手冲教程类正文结构
1. **器具准备**：需要哪些工具
2. **参数说明**：粉量、水温、比例
3. **冲泡步骤**：详细的冲泡过程
4. **注意事项**：新手容易犯的错
5. **风味描述**：做好后的口感
6. **延伸推荐**：进阶学习建议

### 探店分享类正文结构
1. **店铺信息**：店名、地址、价格
2. **环境介绍**：装修风格、氛围
3. **咖啡推荐**：点了什么，味道如何
4. **拍照建议**：哪个位置/角度好拍
5. **适合场景**：一个人/约会/工作
6. **综合评价**：是否值得去

## 拍摄技巧

### 场景选择
- 咖啡馆环境
- 咖啡特写
- 手冲过程
- 咖啡+甜点

### 拍摄要点
- 光线柔和（窗边最佳）
- 背景简洁
- 咖啡杯要干净
- 可以拍蒸汽/拉花细节

### 封面设计
- 咖啡特写+店名
- 咖啡馆环境图
- 咖啡制作过程
- 咖啡+甜点组合
