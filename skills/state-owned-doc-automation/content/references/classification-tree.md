## 文件命名规范

格式：`YYYYMMDD_单位简称_主题_版本.扩展名`

| 字段 | 说明 | 示例 |
|------|------|------|
| YYYYMMDD | 文件日期（8位数字） | 20260417 |
| 单位简称 | 发文单位简称 | 川省属国企 |
| 主题 | 文档主题 | 基金投资情况表 |
| 版本 | 文件版本状态 | 正式稿、报批稿、征求意见稿、初稿 |
| 扩展名 | 原始文件扩展名 | .xlsx、.docx、.pdf |

## 支持的文件格式

- Word: `.docx`
- PDF: `.pdf`
- Excel: `.xlsx`, `.xls`
- 文本: `.txt`
- PPT: `.pptx`, `.ppt`（部分功能）
