# 股票多空辩论分析技能

## 概述

本技能通过创建两个AI分析师子agent，分别扮演**多方（看涨）**和**空方（看跌）**的角色，对指定股票进行5轮激烈、不留情面的辩论，最终综合双方观点形成统一的投资价值、买卖时机及操作建议。

## 工作流程

### 步骤1：确认辩论标的

用户需提供股票信息：
- A股：股票代码（如600519）或名称（如贵州茅台）
- 港股：股票代码（如0700）或名称（如腾讯控股）
- 美股： ticker符号（如AAPL）或名称（如Apple）

解析并确认股票后，进入辩论环节。

### 步骤2：启动数据分析

在辩论开始前，使用工具收集股票相关数据：

**必须收集的数据：**
1. **基本信息**：公司名称、行业、市值、股价
2. **财务数据**：营收、净利润、毛利率、ROE、资产负债率
3. **估值指标**：PE、PB、PS、PEG
4. **近期新闻**：重大公告、行业动态
5. **技术面**：近期走势、关键支撑阻力位

使用工具：
- A股：`mcp__matrix__stocks_info`, `mcp__matrix__stocks_financial_data`, `mcp__matrix__stocks_price`
- 港股：`mcp__matrix__stocks_info`, `mcp__matrix__stocks_financial_data`, `mcp__matrix__stocks_price`
- 美股：同上工具

### 步骤3：创建辩论双方

使用Task工具并行创建两个子agent：

**多方分析师（Bull Analyst）：**
- 角色：资深看涨分析师
- 目标：构建最有力的买入论点
- 规则：使用数据支撑论点，挑战看跌观点，承认合理风险但强调可控性

**空方分析师（Bear Analyst）：**
- 角色：资深看跌分析师
- 目标：识别最大风险和警示信号
- 规则：使用数据构建看跌论点，挑战看涨观点，提供历史案例

### 步骤4：执行5轮辩论

每轮辩论结构：

**第1轮：开场陈述**
- 多方：3个最强买入理由
- 空方：3个最大风险警示

**第2轮：攻守交锋**
- 多方反驳空方的第1个担忧
- 空方反驳多方的第1个买入理由

**第3轮：深度挖掘**
- 多方：提供被低估的催化剂
- 空方：识别被忽视的风险因素

**第4轮：估值对决**
- 多方：目标价及上涨逻辑
- 空方：下行空间及风险回报

**第5轮：最终陈词**
- 多方：核心推介总结
- 空方：关键警告总结

### 步骤5：综合裁决

基于5轮辩论结果，输出：

1. **投资价值评估**（1-10分）
2. **统一的投资建议**
   - 买入/持有/卖出
   - 目标价位
   - 止损位
   - 时间预期
3. **操作建议**
   - 仓位建议
   - 入场时机
   - 分批策略

## 子Agent提示词模板

### 多方分析师系统提示

```
你是[股票名称]的资深看涨分析师。你的任务是基于基本面、技术面、新闻等全面信息，构建最有力的买入投资论点。

核心原则：
1. 使用数据支撑每一个论点
2. 承认有效的风险，但强调其可控性
3. 挑战过于悲观的观点
4. 提供量化的上涨目标
5. 保持专业但不保守的看涨立场

你的分析应涵盖：
- 核心竞争力和护城河
- 增长催化剂
- 估值吸引力
- 管理层能力
- 行业景气度
```

### 空方分析师系统提示

```
你是[股票名称]的资深看跌分析师。你的任务是基于所有可用信息，识别最大的投资风险和警示信号。

核心原则：
1. 使用数据支撑每一个担忧
2. 挑战过于乐观的假设
3. 提供历史失败案例对比
4. 量化潜在下行空间
5. 保持专业但不悲观的谨慎立场

你的分析应涵盖：
- 基本面隐患
- 估值泡沫风险
- 竞争威胁
- 宏观风险敞口
- 管理层问题
```

## 辩论规则

1. **数据为王**：所有论点必须有数据支撑
2. **不留情面**：双方应积极反驳对方观点
3. **有理有据**：避免情绪化言论
4. **见好就收**：当对方论点有效时，应承认并回应
5. **最终聚焦**：第5轮应聚焦于关键分歧和统一建议

## 适用场景

- 投资决策前的多方验证
- 对特定股票有分歧时的深度分析
- 学习投资分析方法
- 形成投资决策前的最后审视

## 局限性

- 辩论质量受限于所收集的数据
- AI分析仍有局限性
- 市场环境可能快速变化
- 建议结合其他信息源使用
