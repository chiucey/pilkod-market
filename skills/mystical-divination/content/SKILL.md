# 玄学占卜工具箱

## 核心功能

### 1. 塔罗牌占卜（主要功能）
- **每日一抽** — 晨间能量指引，随机抽取一张牌
- **牌阵解读** — 单牌、三牌阵（过去/现在/未来）、凯尔特十字
- **决策辅助** — 针对具体问题给出行动指引
- **78张完整牌义** — 22张大阿卡纳 + 56张小阿卡纳

### 2. 易经六十四卦
- **起卦** — 数字卦法，随机生成卦象
- **卦辞解读** — 卦象、彖曰、大象、决策指引
- **趋避建议** — 趋吉避凶的具体行动建议

### 3. 数字能量学
- **生命灵数** — 出生日期计算 + 性格解读（1-9, 11, 22, 33）
- **关系匹配** — 两人生命灵数契合度分析

### 4. 星盘/星座
- **十二星座** — 性格、优势挑战、事业、爱情解读
- **行星含义** — 太阳/月亮/上升等十大行星核心含义

## 使用流程

### 每日一抽（塔罗）
```
用户：每日一抽 / 今天抽张牌 / 日运
1. 随机选择一张塔罗牌（1-78）
2. 读取 references/tarot_major.json 或 tarot_minor.json 获取牌义
3. 如有大阿卡纳牌面图片(assets/tarot_major_XX.jpg)，优先发送图片
4. 结合当下语境给出日能量指引
```

### 决策辅助（塔罗·三牌阵）
```
用户：帮我看看要不要跳槽 / 二选一
1. 确认具体问题背景
2. 三牌阵布局：过去 / 现在核心 / 未来走向
3. 随机抽取3张不同牌
4. 结合问题解读，给出具体行动建议
```

### 易经占卜
```
用户：帮我占一卦 / 易经问事
1. 让用户心中默念问题
2. 生成6个随机数（每个1-8），对应6爻
3. 从 references/iching.json 查找卦辞和解读
4. 给出卦象分析与行动建议
```

### 生命灵数
```
用户：帮我算生命灵数
1. 询问出生日期（YYYY年MM月DD日）
2. 将年月日数字全部相加到个位数（如1990-05-12 → 1+9+9+0+0+5+1+2=27 → 2+7=9 → 生命灵数为9）
3. 从 references/numerology.json 查对应解读
4. 结合用户问题给出分析
```
