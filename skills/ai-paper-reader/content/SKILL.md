# AI论文阅读技能

本技能提供完整的AI领域论文学习体验：获取原文PDF、翻译（英文→中文）、深度阅读、博客式总结输出。

## 工作流程

### 1. 论文获取

**输入**：用户提供的论文URL（arXiv、PDF链接等）

**执行步骤**：
1. 解析URL类型，确定最佳下载方式
2. 优先使用原始链接下载PDF（保持最高质量）
3. 保存原始PDF到 `downloads/{论文ID}/original.pdf`

**支持来源**：
- arXiv链接 → 使用arXiv API或直接下载
- PDF直链 → 直接下载
- DOI → 尝试定位官方PDF
- 其他学术源 → 通用下载方式

### 2. PDF翻译（仅英文论文）

**判断标准**：
- 论文语言检测（摘要/正文首段）
- 英文占比>70%视为英文论文

**执行步骤**：
1. 提取PDF文本内容
2. 调用翻译服务（保持原有格式和结构）
3. 生成翻译版PDF：`downloads/{论文ID}/translated.pdf`

**翻译原则**：
- 保留原文档结构（标题层级、段落、公式位置）
- 术语保持一致性（首次出现提供中英对照）
- 专业术语保留英文+中文注释

### 3. 论文深度阅读

**阅读维度**：
1. **基本信息**：标题、作者、机构、发表时间、顶会/期刊
2. **研究背景**：问题定义、领域现状、研究动机
3. **核心贡献**：主要创新点、关键技术突破
4. **方法论**：算法框架、技术方案、实验设计
5. **实验结果**：数据集合、性能指标、对比分析
6. **深度洞察**：局限性、启发思考、未来方向

**图片处理策略**：
- 图表提取：保存论文中所有重要图表为独立图片
- 图片保存：`downloads/{论文ID}/figures/`
- 关键图片说明：为每张图添加详细图注，辅助理解
- 不可忽略：架构图、流程图、实验对比图、主要结果图表

### 4. 输出文档

**输出格式**：Markdown文档（便于阅读和分享）

**文档结构**：
```markdown
# {论文标题}

> **论文信息**：{作者} | {机构} | {发表时间} | {发表 venue}
> **论文链接**：{原始链接}
> **阅读日期**：{YYYY-MM-DD}

## 一句话总结
{用1-2句话概括论文核心贡献}

## 论文速览
- **研究领域**：{领域}
- **核心问题**：{要解决的问题}
- **主要方法**：{采用的技术方案}
- **关键成果**：{在什么数据集上达到什么效果}

## 详细阅读

### 1. 研究背景与动机
{背景介绍}

### 2. 核心贡献
{创新点分析}

### 3. 技术方案
{方法详解}

### 4. 实验与分析
{实验结果解读}

### 5. 深度思考
{局限性分析、启发、改进方向}

## 重要图表
{按原文顺序展示关键图表，每张图配详细说明}

## 相关知识
{扩展阅读、背景知识补充}

## 参考资料
{原文链接、相关工作链接}
```

**文件命名**：`{论文标题}_{YYYYMMDD}.md`
**输出路径**：`outputs/{论文ID}/{文档文件名}`

## 输出文件结构

```
outputs/
└── {论文ID}/
    ├── summary.md                    # 博客式总结文档
    ├── figures/                      # 提取的图片资源
    │   ├── figure_1.png
    │   ├── figure_2.png
    │   └── ...
    └── notes.md                      # 原始阅读笔记（可选）
```

## 执行约束

1. **PDF质量**：必须获取完整、准确的原始PDF，不可使用截图版或低质量版本
2. **图片完整性**：论文中所有图表必须完整提取，不可遗漏关键图片
3. **翻译准确性**：专业术语保持准确性，可读性优先
4. **格式规范性**：输出文档遵循上述结构，便于后续查阅

## 错误处理

- **下载失败**：尝试备用下载方式，记录错误并告知用户
- **翻译失败**：跳过翻译步骤，标注"翻译失败"
- **图片提取失败**：使用替代方式或标注"图片获取失败"
- **部分失败**：完成能完成的部分，汇总报告
