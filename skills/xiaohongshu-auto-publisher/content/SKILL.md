# 小红书自动发布技能

## 技能概述

此技能用于自动采集指定主题的相关信息，生成高质量的小红书图文内容，并自动发布到小红书网页版。

## 工作流程

### 阶段 1：信息采集

1. **接收用户主题**：明确用户想发布的内容主题
2. **网络搜索**：使用 `batch_web_search` 工具搜索相关内容素材
3. **内容整理**：整理搜索结果，提炼关键信息

### 阶段 2：内容生成

1. **文案撰写**：生成符合小红书风格的标题和正文
2. **配图生成**：使用 `image_synthesize` 工具生成高质量配图
3. **标签建议**：提供适合的 hashtags

### 阶段 3：自动发布

1. **打开小红书**：使用 `interact_with_website` 打开小红书网页版
2. **等待登录**：确保用户已登录状态
3. **自动填充**：将标题、正文、图片填入发布表单
4. **发布确认**：点击发布按钮完成发布

## 安全与合规说明

- 不存储用户账号密码
- 依赖用户已登录状态进行操作
- 遵守平台服务条款
- 仅用于用户主动授权的场景

## 快速使用

当用户要求发布小红书时，按顺序执行：
1. 确认发布主题
2. 采集相关信息
3. 生成图文内容
4. 打开小红书网页版
5. 自动填写并发布
