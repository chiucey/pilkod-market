# 文件传输技能

快速完成文件的上传、下载、移动和复制操作。

## 支持的操作

### 1. 文件上传
将本地或用户输入文件传输到workspace：
- 接收用户提供的文件路径或内容
- 读取并保存到指定目录

### 2. 文件下载
将workspace内文件传输到用户可访问位置：
- 生成可下载的文件链接
- 提供文件路径供用户获取

### 3. 文件移动/复制
在workspace内移动或复制文件：
- 源路径和目标路径
- 支持重命名

### 4. 文件夹操作
- 创建文件夹
- 列出目录内容
- 删除文件或空文件夹

## 执行流程

1. **识别操作类型**
   - 上传：用户提供外部文件或内容
   - 下载：用户提供目标文件名，从workspace获取
   - 移动/复制：提供源和目标路径

2. **验证路径**
   - 检查源文件是否存在
   - 确认目标路径有效
   - 避免覆盖重要文件

3. **执行传输**
   - 使用bash命令或文件操作工具
   - 保持文件完整性

4. **确认完成**
   - 返回操作结果
   - 提供文件访问方式

## 常用命令

| 操作 | 命令 |
|------|------|
| 复制文件 | `cp source dest` |
| 移动文件 | `mv source dest` |
| 创建目录 | `mkdir -p path` |
| 查看目录 | `ls -la path` |
| 删除文件 | `rm file` |

## 注意事项

- workspace路径: `/workspace`
- 临时文件目录: `tmp/`
- 用户输入文件目录: `user_input_files/` (只读)
- 保持路径简洁，避免特殊字符
