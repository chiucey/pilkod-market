# Coffee News Digest（咖啡新闻日报）

## Overview

全自动咖啡行业新闻采集工具，每天获取最新咖啡资讯并整理到飞书文档。

**工作流程：**
1. 使用 `batch_web_search` 搜索今日咖啡行业新闻（中英文来源）
2. 整理标题、摘要、来源链接
3. 使用 `feishu_doc` 创建或追加到飞书文档

---

## 执行步骤

### Step 1 — 搜索今日咖啡新闻

使用 `batch_web_search` 并行搜索多个来源：

```json
{
  "queries": [
    {"query": "咖啡行业新闻 2026", "num_results": 8, "data_range": "d"},
    {"query": "coffee industry news 2026", "num_results": 8, "data_range": "d"},
    {"query": "咖啡市场 最新动态", "num_results": 5, "data_range": "d"},
    {"query": "coffee brand new product 2026", "num_results": 5, "data_range": "d"}
  ]
}
```

合并去重后，筛选有价值的条目（行业趋势、品牌动态、市场数据、政策、赛事等）。

### Step 2 — 写入飞书文档

**文档命名规则：** `咖啡新闻日报 — YYYY-MM-DD`

**首次创建文档（按月归档）：**
- 使用 `feishu_doc(action=create, title=咖啡新闻日报 — YYYY年MM月)` 创建月度文档
- 在文档中插入当日新闻表格

**每日追加内容：**
- 在月度文档中新增日期区块，包含：
  - **日期标题**（h2 格式）
  - **新闻列表**（每条含序号、标题、摘要、来源链接）
  - 当日若无重大新闻，写入"今日无重大更新"

**文档格式规范：**
```
## 📅 YYYY-MM-DD

| # | 标题 | 摘要 | 来源 |
|---|------|------|------|
| 1 | xxx | xxx | [链接](url) |

---
```

### Step 3 — Cron 定时任务配置

将以下 Cron 表达式告知用户，由用户在 OpenClaw 中配置每日定时触发：

```
0 8 * * *   # 每天北京时间 08:00 执行
```

用户可通过 OpenClaw 管理界面配置定时任务，指向本 skill。

---

## 飞书文档链接获取

如用户提供已有的飞书文档链接，直接追加内容；如无，则创建新月度文档。

---

## 注意事项

- 搜索语言优先级：**中文 > 英文**，中文覆盖不足时用英文补充
- 每条新闻保留原始来源链接，便于溯源
- 文档按**月份**组织，每月一个文档，避免单文档过长
- 如当日搜索结果为空，记录"今日咖啡行业无重大新闻更新"
