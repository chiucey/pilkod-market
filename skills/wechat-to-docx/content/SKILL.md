# 微信公众号转Word文档

将微信公众号文章（mp.weixin.qq.com）转换为格式化的Word文档，包含文章中的所有图片。

## 功能

- **多格式自动兼容**：自动识别并正确解析微信旧版编辑器、新版编辑器、96编辑器等不同格式的 HTML
- 解析微信公众号文章元数据（标题、作者、发布时间、公众号名称）
- 提取文章正文内容
- 自动下载文章中的所有图片
- 生成格式化的Word文档（.docx），图片已嵌入
- 保存文章元数据为JSON文件

## HTML 格式兼容性

本技能自动识别并支持以下微信文章 HTML 格式：

| 格式类型 | HTML 特征 | 说明 |
|---------|----------|------|
| 旧版微信编辑器 | `<span leaf="">` 属性包裹内容 | 早期微信公众号文章 |
| 新版微信编辑器 | `<p><span style="">...</span></p>`，无 `leaf` 属性 | 2019年后新格式 |
| 96编辑器等第三方 | 深度嵌套的 `<section>` + `<p>` 结构，含 `data-tpl-id` 等属性 | 常见于学校/政务公众号 |

解析器会自动检测 HTML 结构，选择最优解析路径，无需用户手动指定。

## 使用方法

### 方式一：使用主脚本（推荐）

```bash
# 进入技能目录
cd C:\Users\ET\.workbuddy\skills\wechat-to-docx

# 执行转换（依赖已预装，无需 npm install）
node scripts/main.js <文章URL> [输出目录] [文件名]
```

示例：
```bash
node scripts/main.js "https://mp.weixin.qq.com/s/xxx" "C:\Users\ET\Documents\微信文章"
```

### 方式二：在代码中调用

```javascript
const { convertWechatToDocx } = require('./scripts/main');

convertWechatToDocx(
  'https://mp.weixin.qq.com/s/xxx',
  './output',
  '自定义文件名'
).then(result => {
  console.log('文档已生成:', result.docxPath);
});
```

## 输出结构

转换完成后，会创建一个文件夹，包含：

```
输出目录/文章标题/
├── 文章标题.docx      # Word文档（含图片）
├── metadata.json      # 文章元数据
└── images/            # 图片文件夹
    ├── img_01.jpg
    ├── img_02.png
    └── ...
```

## 排版说明

生成的 Word 文档有以下排版优化：

- **多格式智能解析**：自动识别微信旧版/新版/96编辑器等不同 HTML 结构
- **智能段落合并**：相邻同属性（同字号、同对齐、同粗细）的文字碎片自动合并为一个段落，减少碎片化
- **标题层级保护**：字号差异 ≥4px 的相邻节点不会被合并，不同级标题（封面/正文）保持独立
- **图片段落分离**：含图片的 HTML 块（`<span leaf="">` 或 `<p><span>`）中图片与文字各自独立成段，顺序正确
- **元信息保护**：撰稿/编辑/一审/二审/三审/终审 等作者信息强制独立分段，不与正文合并
- **正文图片穿插**：图片按原文 DOM 顺序插入，与相邻文字段落保持合理间距
- **装饰内容过滤**：自动过滤 SVG 装饰图、空白分隔符等无意义内容

## 注意事项

1. 需要网络连接才能解析文章和下载图片
2. 部分文章可能因权限或已删除而无法访问
3. 图片下载可能因网络问题失败，失败的图片会跳过但文档仍会生成
4. 生成的Word文档使用微软雅黑字体，适合中文阅读
5. 部分使用 SVG 动画或特殊 CSS 效果的图片可能无法完全还原原版视觉效果

## 故障排除

### 文章解析失败
- 检查文章链接是否有效
- 确认文章未被删除或设置权限
- 部分文章需要微信客户端才能访问

### 图片下载失败
- 检查网络连接
- 部分图片可能需要微信登录才能访问
- 失败的图片不会影响文档生成
