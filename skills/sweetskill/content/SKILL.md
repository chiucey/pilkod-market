## 故障诊断方法论

### 第一步：信息收集
```
- 故障现象描述
- 设备基本信息（型号、投运时间）
- 运行参数记录
- 历史维护记录
- 最近是否有操作或改造
```

### 第二步：初步分析
```
- 缩小故障范围
- 识别可能原因
- 确定检测重点
- 制定排查计划
```

### 第三步：现场检测
```
- 非带电检测（如适用）
- 带电测试数据采集
- 对比历史数据
- 兄弟设备对比
```

### 第四步：原因确定
```
- 综合分析各项数据
- 识别根本原因
- 评估问题严重程度
```

### 第五步：处理建议
```
- 紧急处理措施
- 永久解决方案
- 预防措施建议
- 后续跟踪事项
```

## 典型案例参考

### 案例1：变压器油温持续偏高
**症状**：油浸式变压器油温比正常高出15°C，环境温度正常
**可能原因**：
- 负载超过额定值
- 散热器堵塞或风扇故障
- 油位过低
- 绕组局部短路
- 温度测量元件故障

**排查步骤**：
1. 检查负载电流是否超标
2. 检查散热器运行状态
3. 检测绕组直流电阻
4. 油色谱分析
5. 检查温控器准确性

### 案例2：电机运行振动大
**症状**：电机振动值超标，伴有异常噪音
**可能原因**：
- 轴承损坏或磨损
- 不对中（电机与负载）
- 转子不平衡
- 共振问题
- 地脚螺栓松动

**排查步骤**：
1. 振动频谱分析
2. 轴承温度检测
3. 检查对中情况
4. 检查转子平衡
5. 紧固检查

### 案例3：断路器频繁跳闸
**症状**：低压断路器无故跳闸，查找不到明显故障
**可能原因**：
- 整定电流设置过小
- 线路存在漏电
- 谐波电流过大
- 断路器本身故障
- 接线松动导致发热

**排查步骤**：
1. 复核保护整定值
2. 漏电电流测试
3. 电能质量分析
4. 检查接线端子
5. 断路器功能测试

## 安全注意事项

### 电气作业安全
- 严格执行停电、验电、挂接地线程序
- 使用合适的个人防护装备
- 保持安全操作距离
- 两人作业，一人监护
- 带电作业需经批准

### 设备安全
- 测试前确认设备状态
- 使用合格检测仪器
- 避免造成二次故障
- 记录所有测试数据
- 恢复前全面检查
