# History Report Workflow

激活后，执行完整的历史研究报告流水线。

## 工作流步骤

1. 确认研究主题和时间范围（目标朝代）
2. 年代红线验证：每条目标注 `[OK]` 或 `[排除+原因]`
3. 写**历史背景章节**（5维度，800-1500字）
4. 写**建筑条目**（8项，每条240字：结构+工艺+功能+沿革）
5. 写**文物条目**（10件，每条200字：材质+尺寸+意义）
6. 图片搜集：每例配3-5张，`images_understand` 验证后使用
7. 部署图文HTML报告，输出链接
8. 打包图片ZIP，输出下载链接

## 年代红线规则

每条必须标注：
```
前200年 ✅ 合规：[OK]
1056年  ❌ 合规：[排除：辽代，超出汉代范围]
```

## 数据源优先级

1. 博物馆官网（国家博物馆、故宫数字库等）
2. 学术专著、考古报告
3. 百度百科 / Wikipedia（有具体年份的词条）
4. 知乎认证账号

## 输出格式

- 文字报告：`/workspace/{topic}_report.md`
- 图文HTML：`/workspace/report_{topic}/index.html`
- 图片包：ZIP文件供下载
