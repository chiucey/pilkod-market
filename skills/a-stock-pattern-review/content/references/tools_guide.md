# A股复盘工具使用指南

## 一、情绪监控工具

### 1. 通达信880005（昨日涨停股表现）

**查看位置**：通达信软件 → 功能 → 昨日涨停股表现

**指标解读**：
- 数值>0：昨日涨停股整体有溢价，市场追板资金赚钱
- 数值<0：昨日涨停股整体亏钱，市场情绪低迷
- 数值<-5%：冰点区，进攻窗口可能开启

**实战应用**：
```
冰点信号：
✓ 880005连续3日下跌
✓ 数值<-3%
✓ 涨停家数<30家
→ 关注情绪拐点，次日可能出现回暖
```

### 2. 连板率计算

**公式**：连板率 = 连续涨停股数 / 涨停股总数 × 100%

**参考标准**：
| 连板率 | 市场状态 | 操作策略 |
|-------|---------|---------|
| >30% | 高潮期 | 锁定最强，不轻易换股 |
| 15%-30% | 回暖期 | 积极试错，寻找活口 |
| <15% | 冰点期 | 等待，不追高 |
| <5% | 冰点深化 | 空仓休息 |

### 3. 炸板率计算

**公式**：炸板率 = 炸板股数 / (涨停股数 + 炸板股数) × 100%

**实战参考**：
- 炸板率>30%：情绪不稳，追板风险大
- 炸板率<20%：情绪稳定，可以积极操作
- 炸板率>50%：退潮信号，禁止追板

### 4. 昨日涨停今日红盘率

**计算方式**：昨日涨停今日上涨的股票数 / 昨日涨停股总数

**参考标准**：
- 红盘率>60%：追板有溢价，积极操作
- 红盘率<40%：追板亏钱，控制仓位
- 红盘率<30%：市场情绪差，减少操作

## 二、资金流向工具

### 1. 东方财富资金流向

**入口**：东方财富网 → 数据中心 → 资金流向

**关键指标**：
- 行业板块资金净流入排名
- 概念板块资金净流入排名
- 个股资金净流入/净流出

### 2. 同花顺主力资金

**入口**：同花顺 → 资金流向

**筛选技巧**：
- 按"主力净流入"排序
- 筛选"今日主力净流入>5000万"
- 结合板块题材判断持续性

### 3. 北向资金监控

**入口**：东方财富 → 沪深港通

**解读方法**：
- 北向资金净流入>50亿：外资积极买入
- 北向资金净流出>30亿：外资减仓
- 连续净流入：中期看多信号
- 连续净流出：中期看空信号

## 三、龙虎榜解读

### 1. 龙虎榜获取渠道

- 东方财富网 → 数据中心 → 龙虎榜
- 同花顺 → 龙虎榜
- 交易所官网（上交所/深交所）

### 2. 龙虎榜关键信息

```
【龙虎榜要素】
股票名称：[XXX]
上榜原因：[日涨幅偏离值达7%等]
成交金额：[X亿]
买入席位：
  - 知名游资：[营业部名称] [买入金额]
  - 机构席位：[金额]
卖出席位：
  - 游资：[金额]
  - 机构：[金额]
```

### 3. 席位识别与跟庄

**顶级游资席位**：
| 席位 | 风格 | 特点 |
|-----|------|-----|
| 欢乐海岸 | 锁仓龙头 | 不砸盘，持续加仓 |
| 溧阳路 | 题材接力 | 频繁换手 |
| 成都系 | 一日游 | 次日砸盘 |
| 佛山系 | 引导二波 | 偶尔锁仓 |
| 赵老哥 | 龙头接力 | 经典涨停板 |

**跟庄策略**：
```
✓ 欢乐海岸买 → 锁仓持有，等二波
✓ 成都系买 → 次日高开走人
✓ 多席位协同买 → 可能有行情
✗ 机构卖 + 游资买 → 谨慎
```

## 四、主线识别工具

### 1. 板块涨停家数统计

**筛选条件**：
- 同一板块涨停家数≥3家 → 可能是主线
- 同一板块涨停家数≥5家 → 基本确认主线
- 同一板块涨停家数≥10家 → 主线高潮期

### 2. 板块K线结构分析

**强势板块特征**：
- 板块指数突破20日均线
- 成交量逐日递增
- 出现明显龙头股

### 3. 主线行情生命周期

```
启动期（1-2天）
  → 龙头股首板
  → 板块效应不明显
  → 识别难度大

发酵期（3-5天）
  → 跟风股批量涨停
  → 板块效应明显
  → 确认主线

高潮期（5-10天）
  → 龙头连板加速
  → 补涨股轮动
  → 开始高位分歧

退潮期
  → 龙头跌停
  → 跟风股补跌
  → 主线结束
```

## 五、容量唯一性识别

### 1. 容量标的特征

**大盘股指标**：
- 流通市值>50亿
- 日成交额>10亿
- 机构持仓明显

**唯一性判断**：
- 同题材中盘子最大
- 同市值中题材最正
- 板块调整时抗跌

### 2. 活口识别技巧

**退潮期活口特征**：
- 唯一没有跌停的高位股
- 分时图逆势拉升
- 成交回报显示大资金买入

### 3. 流动性切换信号

**切换信号**：
- 老主线龙头高位跌停
- 新方向首板出现
- 资金快速切换到新板块

**切换时机**：
- 情绪冰点次日
- 老主线亏钱效应扩散时
- 新方向出现明确的容量标的时
