# A股历史行情复盘案例

## 案例一：情绪冰点反转（2024年典型）

### 背景
连续3日情绪低迷，涨停家数从80家降至20家，880005连续收阴。

### 盘面特征
```
指数表现：缩量震荡，振幅<1%
情绪指标：
  - 涨停家数：18家（冰点）
  - 连板率：8%（极低）
  - 炸板率：45%（高危）
  - 880005：-3.2%
主线：混沌期，无明显主线
```

### 分析过程
1. 识别冰点：连续3日情绪低迷
2. 观察先行信号：券商板块异动
3. 判断主线：科技股有资金提前布局
4. 锁定标的：科技容量中军XX股票

### 次日表现
```
开盘：情绪延续恐慌，快速杀跌
转折：10:30科技股逆势拉升
确认：10:45出现容量唯一性标的涨停
介入：打板XX股票
结果：次日涨停，后市连板
```

### 总结
```
✓ 冰点次日情绪反转是最佳进攻时机
✓ 关注券商/大金融的先行异动
✓ 容量唯一性标的是首选
✓ 情绪拐点需要板块共振确认
```

## 案例二：主线退潮期操作

### 背景
AI主线连续炒作2周后，龙头股高位滞涨，跟风股开始亏钱。

### 盘面特征
```
龙头表现：XX股票高位跌停
跟风股：批量跌停或大跌
情绪指标：
  - 涨停家数：25家
  - 连板率：5%
  - 炸板率：52%（危险）
  - 昨日涨停红盘率：28%
主线：AI退潮，无新主线
```

### 分析过程
1. 判断退潮：龙头跌停确认退潮开始
2. 处理持仓：开盘无条件卖出跟风股
3. 空仓等待：不抄底，不博弈反抽
4. 观察新方向：等待情绪企稳

### 操作结果
```
✗ 早盘抄底跟风股 → 当日浮亏8%
✗ 博弈龙头反抽 → 次日继续跌停
✓ 空仓等待3天后 → 情绪冰点新主线出现
✓ 介入新主线龙头 → 次日涨停
```

### 总结
```
✗ 退潮期禁止抄底
✗ 退潮期禁止博弈反抽
✗ 退潮期禁止追老主线跟风股
✓ 空仓是最好的风控
✓ 等待是散户最大的优势
```

## 案例三：容量唯一性实战

### 背景
市场出现新题材"固态电池"，多只个股涨停，需要识别容量标的。

### 盘面分析
```
题材：固态电池
涨停个股：
  - XX科技（流通市值8亿）
  - YY新能源（流通市值60亿）
  - ZZ材料（流通市值15亿）

资金容量分析：
  8亿标的：最多承载2亿资金
  15亿标的：最多承载4亿资金
  60亿标的：可以承载20亿+资金
```

### 识别过程
1. 题材催化：政策+业绩预期双轮驱动
2. 容量需求：大资金必须找到出口
3. 唯一性判断：YY新能源是唯一能承载大资金的标的
4. 确认逻辑：盘子最大、题材最正、机构持仓

### 操作预案
```
【容量唯一性买入】
标的：YY新能源
买入时机：
  1. 开盘情绪恐慌时低吸
  2. 板上确认后打板

仓位：30%
止损：-5%

【锁仓条件】
✓ 板块持续发酵
✓ 成交回报显示大资金买入
✓ 股价不破5日均线
```

### 结果
```
首日：震荡后涨停
次日：高开加速，连板
第三日：高位震荡，大资金出货
操作：锁仓到第三日尾盘离场
收益：+35%
```

### 总结
```
✓ 题材够大时，容量唯一性标的必须重视
✓ 大资金必须找到出口，有容量才能持续
✓ 识别容量标的需要判断题材持续性
✓ 锁仓需要成交回报确认大资金在场
```

## 案例四：新主线确认流程

### 背景
市场混沌期，新题材出现，需要判断是否成为主线。

### 盘面信息
```
新题材：新型城镇化
涨停个股：
  - XX建设（首板）
  - YY规划（首板）
  - ZZ园林（首板）

昨日表现：
  - XX建设（首板）
  - 无跟风股
```

### 分析框架

#### 第一步：题材新鲜度
```
✓ 新题材：过去1个月内没有炒作
✓ 政策催化：住建部发文支持
✗ 纯概念：无实质内容
```

#### 第二步：板块结构
```
完整结构：
✓ 身位龙头：XX建设（3板）
✓ 弹性核心：YY规划（小盘）
✓ 容量中军：ZZ园林（大盘）

不完整结构：
✗ 只有跟风，没有龙头
✗ 只有龙头，没有跟风
```

#### 第三步：持续性判断
```
✓ 催化持续：多部委联合出台政策
✓ 资金认可：成交额逐日放大
✓ 龙头表态：高位不跌，继续连板

✗ 催化一次性：只有单日消息
✗ 资金不认可：成交额萎缩
✗ 龙头高位滞涨
```

### 结论输出
```
【主线确认】
题材：新型城镇化
判定：有效主线（待观察）

结构评分：
  - 身位龙头：XX建设（3板）✓
  - 弹性核心：YY规划 ✓
  - 容量中军：ZZ园林 ✓

持续性预期：
  - 催化力度：强
  - 资金认可度：中高
  - 持续时间：预计5-7天

操作建议：
  1. 重点关注YY规划（弹性核心）
  2. 回踩5日线可低吸
  3. 破5日线止损
```

## 案例五：情绪周期与仓位管理

### 完整情绪周期演示

```
【第一阶段：冰点期】（Day 1-3）
情绪特征：
  - 涨停家数：15-25家
  - 连板率：<10%
  - 880005：<-2%

操作策略：
  - 仓位：0-10%
  - 方向：空仓/轻仓试错新题材
  - 禁止：追高、打板

【第二阶段：回暖期】（Day 4-6）
情绪特征：
  - 涨停家数：30-50家
  - 连板率：15-25%
  - 880005：0-3%

操作策略：
  - 仓位：20-40%
  - 方向：积极试错，聚焦主线
  - 技巧：首板试错，连板确认后加仓

【第三阶段：高潮期】（Day 7-12）
情绪特征：
  - 涨停家数：60-100家
  - 连板率：>30%
  - 880005：>3%

操作策略：
  - 仓位：50-80%
  - 方向：锁定最强，锁仓持有
  - 技巧：龙头不轻易卖，跟风快进快出

【第四阶段：退潮期】（Day 13-15）
情绪特征：
  - 涨停家数：30-50家
  - 连板率：10-15%
  - 880005：<-2%
  - 炸板率：>40%

操作策略：
  - 仓位：0-20%
  - 方向：处理持仓，不做新买入
  - 技巧：宁错过不做错
```
