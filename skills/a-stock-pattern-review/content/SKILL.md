# A股短线交易复盘框架

基于「情绪周期 + 资金流向 + 容量唯一性」三维体系的标准化复盘流程。

---

## 一、今日盘面发生了什么

**目标**：用3-5句话说清楚今天市场整体表现。

### 核心要素清单
- **指数表现**：上证/深证/创业板今日涨跌幅，成交量变化
- **涨跌停家数**：涨停数量、跌停数量、连板数量
- **北向资金**：净流入/净流出方向
- **日内关键节点**：早盘/午盘/尾盘的转折点或异动时刻
- **主线概括**：今日最强板块是什么，驱动逻辑是什么

### 输出格式
```
【今日盘面概览】
指数：[涨跌幅] [量能变化]
情绪：[涨停X家 / 跌停X家 / 连板X家]
主线：[最强板块] [驱动逻辑]
关键节点：[X时X分发生了XX事件]
```

## 二、市场温度与情绪周期解读

**目标**：识别当前市场所处阶段，判断增量/存量/退潮。

### 核心工具
- **通达信880005（昨日涨停股表现）**：今日整体表现
- **连板率**：连板股占比
- **炸板率**：炸板股占比
- **昨日涨停今日红盘率**：判断昨日追板资金是否有溢价

### 情绪钟摆位置判断

| 钟摆位置 | 特征 | 信号 |
|---------|------|------|
| **冰点区** | 涨停稀少、情绪低迷、连板率低 | 进攻窗口开启 |
| **回暖区** | 连板出现、昨日涨停有溢价 | 积极试错 |
| **高潮区** | 批量涨停、连板率高、龙头一字 | 锁定最强 |
| **退潮区** | 炸板率高、龙头跌停、亏钱效应扩散 | 收缩防守 |

### 阶段判断标准
```
增量市场：量能持续放大，涨停家数逐日递增
存量市场：量能平稳，板块快速轮动
退潮市场：涨停家数递减，跌停家数增加，炸板率高企
```

### 输出格式
```
【情绪周期定位】
当前阶段：[增量/存量/退潮]
钟摆位置：[冰点/回暖/高潮/退潮]
关键指标：
  - 880005昨日涨停表现：[XX%]
  - 连板率：[XX%]
  - 炸板率：[XX%]
  - 红盘率：[XX%]
结论：[进攻窗口/积极试错/锁定最强/收缩防守]
```

## 三、资金流向与主线博弈

**目标**：找出「水往哪里流」，判断持续性，识别核心标的。

### 分析维度

#### 1. 资金从哪个方向流向哪里
- 主力资金净流入板块排名
- 板块内个股资金流向结构
- 资金切换路径（昨日板块→今日板块）

#### 2. 方向的持续性预期
- 催化逻辑是否清晰（政策/业绩/题材）
- 板块容量是否足够（能否承载大资金）
- 龙头股表现是否强势（封单/连板）

#### 3. 核心标的识别

| 标的类型 | 定义 | 特征 |
|---------|------|------|
| **身位高标** | 当前连板最高或启动最早的标的 | 代表板块空间 |
| **弹性核心** | 小盘子、情绪驱动的涨停股 | 代表赚钱效应 |
| **容量中军** | 大盘子、机构/大游资参与的核心资产 | 代表资金容量 |

### 主线判断标准
```
有效主线特征：
✓ 有明确题材催化
✓ 涨停家数≥3家
✓ 有身位龙头（3板+）
✓ 板块内结构完整（龙头→跟风→补涨）
✓ 持续性≥2天

无效轮动特征：
✗ 一日游行情
✗ 无身位龙头
✗ 板块内个股独立炒作
✗ 纯消息刺激无实质逻辑
```

### 输出格式
```
【资金流向与主线分析】
资金方向：[从XX板块流入XX板块]
持续性预期：[强/中/弱] [理由：...]
核心标的：
  身位高标：[股票名称] [X板] [代表逻辑]
  弹性核心：[股票名称] [X亿流通] [特征描述]
  容量中军：[股票名称] [X亿流通] [机构参与情况]
主线判定：[有效主线/无效轮动/混沌期]
```

## 四、明日剧本与操作预案

**目标**：基于复盘结论，制定明日交易计划。

### 核心模式说明
> **本人模式是做情绪拐点上的「容量唯一性」活口，或者流动性切换的新方向**

这句话的实战含义：
- **容量唯一性**：在同一题材/板块中，只有它能承载大资金
- **活口**：主线分歧时，唯一活下来的标的
- **流动性切换**：资金从老方向切换到新方向时的承接点

### 预案制定流程

#### 情形A：进攻预案（冰点回暖时）
```
触发条件：情绪从冰点回暖，出现首个3板+
目标标的：容量唯一性活口
买入时机：
  - 开盘情绪恐慌时的低吸机会
  - 板上确认后的打板介入
仓位策略：核心标的轻仓试错，确认后加仓
```

#### 情形B：锁仓预案（高潮延续时）
```
触发条件：主线明确，龙头强势
目标标的：持仓最强标的
操作：锁仓持有，不轻易下车
风控：设置回撤止盈线（浮盈回撤20%出）
```

#### 情形C：收缩预案（退潮期）
```
触发条件：连板率下降，炸板率高企
目标标的：空仓或极轻仓
操作：不做新买入，处理持仓
风控：宁错过不做错
```

### 明日推演模板
```
【明日剧本推演】

情境1：开盘XX%
→ 预期走势：[...]
→ 操作预案：[...]

情境2：开盘XX%
→ 预期走势：[...]
→ 操作预案：[...]

核心观察点：
1. [关键指标1]
2. [关键指标2]
3. [关键指标3]

情绪拐点信号：
✓ 出现条件：[...]
✓ 出现条件：[...]
```

### 输出格式
```
【明日操作预案】
当前模式：[容量唯一性/活口确认/流动性切换]
介入条件：
  1. [条件1]
  2. [条件2]
  3. [条件3]
目标标的：
  主攻：[名称] [逻辑]
  备选：[名称] [逻辑]
风险控制：
  止损线：[XX%]
  仓位上限：[XX%]
  禁止事项：[...]
```

## 五、快速复盘检查清单

每次复盘完成后，对照检查：

- [ ] 今日主线是否清晰？（能一句话说清楚吗？）
- [ ] 情绪周期位置是否判断准确？
- [ ] 容量唯一性标的是否识别正确？
- [ ] 明日操作计划是否有明确触发条件？
- [ ] 风险控制措施是否到位？
