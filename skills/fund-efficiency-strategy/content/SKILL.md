# 资金效率动量策略 - 纯日线数据版 v2.0

## 策略概述

基于**"单位成交额引起的流通市值变化率"**核心创意，结合MFI、OBV、成交量分布和背离检测构建的多因子复合策略。**无需Level-2数据**，仅需日线OHLCV数据即可运行。

核心逻辑：相同资金流入对不同市值的股票会产生不同的价格推动力，小市值股票对资金流动更敏感。

## 核心因子体系

| 因子 | 权重 | 说明 |
|------|------|------|
| 资金效率排名 | 30% | 每元成交额的市值增长效率 |
| MFI健康度 | 20% | 14日资金流量指标，动态阈值 |
| 成交量分布 | 15% | 主力行为识别、吸筹信号 |
| OBV验证 | 15% | 量价趋势一致性+健康度 |
| 背离信号 | 10% | 价格vs资金指标背离检测 |
| 突破验证 | 10% | 关键价位突破信号质量 |

## v2.0 核心优化

### 1. 动态MFI阈值
- 基于60日滚动分位数计算（p20/p80）
- 更适应不同市场环境（牛市/熊市）
- 避免固定阈值在极端行情下的失效

### 2. 关键价位突破验证
```
有效突破：高成交量 + 高资金效率跟随
假突破风险：低成交量 + 高变化率
```

### 3. OBV成交量真实性验证
- `obv_health`：OBV与成交量的相关性（0-1）
- >0.8：高相关，成交量真实可靠
- <0.5：低相关，可能存在操纵

### 4. 虚假成交量检测
- 检测条件：成交量放大但OBV不跟随
- 可能存在对倒交易或虚假放量

### 5. 股票代码三码验证
- 验证股票代码与数据的一致性
- 防止数据张冠李戴

## 核心指标说明

### 资金效率排名（fund_efficiency_rank）
- 含义：单位成交额推动的市值变化率在同类中的排名分位
- >70%：优秀 — 资金利用高效，主力积极
- 50%~70%：良好 — 正常资金效率
- 30%~50%：一般 — 资金效率偏弱
- <30%：较差 — 资金推动效果弱

### MFI资金流量指标
- 含义：量能加权RSI，反映资金流入流出的强度
- >动态p80：超买区 — 警惕回调风险
- 40~60：正常区 — 多空平衡
- <动态p20：超卖区 — 可能见底

### 突破验证（breakout_validity）
- 含义：关键价位突破时的信号质量评估
- >0.8：有效突破
- 0.5~0.8：待确认
- <0.5：假突破风险

### OBV健康度（obv_health）
- 含义：OBV与成交量的相关性，反映成交量真实性
- >0.8：健康
- 0.5~0.8：可疑
- <0.5：异常（可能存在操纵）

## 交易信号

### 买入条件（需同时满足）
- 综合得分 > 0.6
- 资金效率排名前30%
- MFI在40-70区间且上升
- OBV在MA20上方
- 无顶背离
- 5日线 > 10日线（多头排列）
- 日成交额 > 5000万
- 虚假成交量信号 = 0
- OBV健康度 >= 0.5

### 卖出条件（任一满足）
- 综合得分 < 0.4
- MFI > 80 或快速下降
- 出现顶背离
- 均线死叉
- 从最高点回撤 > 8%
- 虚假成交量信号 = 1

## 数据要求

## 风险控制

1. 小盘股易被操纵，需严格止损（5%）
2. 跟踪止损（8%）
3. 日线数据滞后，建议结合周线趋势
4. 单一策略无法保证收益，建议作为多因子模型的一部分
