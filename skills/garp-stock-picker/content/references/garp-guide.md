# GARP策略参考手册

## 一、核心概念详解

### 1.1 PE（市盈率）的正确打开方式

**静态PE vs 滚动PE vs 动态PE**

| 类型 | 计算方式 | 优缺点 |
|------|----------|--------|
| 静态PE | 基于上一年度年报净利润 | 滞后，不推荐 |
| PE-TTM | 基于过去12个月净利润 | 相对客观，兼顾时效 |
| Forward PE | 基于机构预测未来净利润 | 反映预期，但有主观性 |

**行业PE参考区间（仅供参考）**

| 行业 | 低估区间 | 合理区间 | 高估区间 |
|------|----------|----------|----------|
| 银行 | < 6倍 | 6-10倍 | > 10倍 |
| 消费 | < 20倍 | 20-35倍 | > 35倍 |
| 医药 | < 25倍 | 25-45倍 | > 45倍 |
| 科技 | < 30倍 | 30-60倍 | > 60倍 |
| 新能源 | < 25倍 | 25-50倍 | > 50倍 |

**注**：跨行业比较PE无意义，必须在行业内横向比较。

---

### 1.2 PEG的深度解读

**计算公式**：PEG = PE ÷ 年净利润增速(%)

**为什么是未来3年CAGR？**
- 单年增速容易被短期因素扭曲（一次性收益、政策红利）
- 3年窗口平滑波动，更能反映企业真实成长能力
- 彼得·林奇习惯用3-5年视野评估成长股

**PEG的局限性**
1. 不适用于盈利波动大的公司（亏损/微利企业PEG失效）
2. 忽略了商业模式质量差异
3. 未考虑行业生命周期阶段

**优化方案**：可结合ROE（净资产收益率）综合判断
- PEG < 1 且 ROE > 15% = 黄金标的
- PEG < 1 但 ROE < 10% = 需谨慎，可能是低质量增长

## 二、行业增速数据来源

### 2.1 权威数据渠道

| 数据类型 | 推荐来源 |
|----------|----------|
| 宏观行业数据 | 国家统计局、行业协会白皮书 |
| 中观行业数据 | Wind、Bloomberg、Choice |
| 研报数据 | 各券商研究所报告（Wind研报、慧博） |
| 上市公司招股书 | 募资用途中的市场容量测算 |
| 海关/进出口数据 | 海关总署、UN Comtrade |

### 2.2 行业增速估算方法

**方法1：自上而下**
```
行业规模 × 增速 = Σ(各公司营收增速 × 市场份额)
```

**方法2：自下而上**
```
选取龙头公司样本 → 计算平均增速 → 剔除异常值 → 得到行业基准
```

## 三、财务造假识别清单

### 3.1 红旗预警信号

**收入异常类**
- [ ] 应收账款增速远大于营收增速（提前确认收入）
- [ ] 预收款项异常减少（收入真实性存疑）
- [ ] 关联交易占比过高（大股东输送利润）
- [ ] 客户集中度极高（单一客户依赖风险）

**现金流异常类**
- [ ] 净利润持续为正，但经营现金流持续为负
- [ ] 经营现金流/净利润 < 0.5（收钱能力弱）
- [ ] 存货暴增但周转率持续下降
- [ ] 固定资产异常增长（虚增资产）

**毛利率异常类**
- [ ] 毛利率远高于同行（可能虚构收入）
- [ ] 毛利率与行业趋势背离
- [ ] 上下游占款能力突然变化

### 3.2 历史造假案例特征（供识别参考）

| 案例特征 | 典型公司（举例） |
|----------|------------------|
| 虚构海外客户 | 康美药业、康得新 |
| 提前确认收入 | 尔康制药、金亚科技 |
| 虚增固定资产 | 皖江物流、雅百特 |
| 关联交易转移 | 乐视、暴风 |

## 四、周期股行业分类与特殊框架

### 4.1 强周期行业列表

| 行业类别 | 代表公司 | 周期驱动因素 |
|----------|----------|--------------|
| 大宗商品 | 石油、铜、铝、煤炭、钢铁 | 商品价格 |
| 养猪 | 牧原、温氏、正邦 | 猪周期 |
| 航运 | 中远海控、招商轮船 | 运价指数（BDI） |
| 证券/券商 | 中信、海通 | 牛市/成交量 |
| 房地产 | 万科、保利 | 政策+利率 |
| 化工 | 万华化学、卫星化学 | 油价+供需 |
| 工程机械 | 三一重工、徐工 | 基建投资 |

### 4.2 周期股投资特殊框架

**PB-ROE框架**
- 适用场景：周期底部、盈利不稳定时
- 核心逻辑：ROE低位时用PB估值，ROE高位时切换PE

**猪周期特殊法则**
| 阶段 | PE特征 | 信号 |
|------|--------|------|
| 周期顶部 | PE极低（甚至<5） | 产能过剩，拐点将至 |
| 周期底部 | PE极高/亏损 | 产能去化完成，布局良机 |

**关键指标**
- 猪：能繁母猪存栏量 → 判断产能去化进度
- 航运：BDI指数 → 全球贸易活跃度
- 证券：日均成交量、两融余额 → 市场情绪

## 五、GARP策略实战案例

### 5.1 理想标的画像

```
公司：某医疗器械龙头（示例）
- 市值：800亿
- 扣非净利润：25亿
- PE-TTM：32倍

成长性：
- 3年CAGR预期：35%
- PEG = 32/35 = 0.91

行业验证：
- 公司增速：35%
- 行业增速：20%
- 结论：Alpha型（抢占市场份额）

现金流：
- 经营现金流：22亿
- 经营现金流/净利润 = 0.88 > 0.8 ✓

综合结论：买入
核心理由：PEG接近1，增速显著跑赢行业，现金流健康，符合GARP黄金标的特征
```

### 5.2 典型避坑案例

**案例1：低PE陷阱（周期股误用GARP）**
```
某煤炭股：
- PE = 5倍（看似极低）
- 行业周期：顶部
- 正确判断：排除（周期见顶信号）
```

**案例2：纸面财富（现金流陷阱）**
```
某环保股：
- 净利润增速：40%
- 经营现金流：-5亿（持续为负）
- 结论：排除（应收账款堆积，增速是白条）
```

**案例3：行业背离（造假预警）**
```
某消费电子公司：
- 公司增速：50%
- 行业增速：-15%（整体萎缩）
- 结论：排除（极度不合常理）
```

## 六、快速决策检查清单

### 使用前确认
- [ ] 确认非周期股（或用户明确需要周期股框架）
- [ ] 获取股票市值与扣非净利润

### 第一层：估值计算
- [ ] 计算PE（TTM或Forward）
- [ ] 记录行业参考区间对比

### 第二层：PEG匹配
- [ ] 获取3年CAGR预期增速
- [ ] 计算PEG = PE / 增速
- [ ] 判断区间（<0.8/0.8-1.2/1.2-1.5/>1.5）

### 第三层：行业验证
- [ ] 获取公司增速
- [ ] 获取行业增速
- [ ] 判断类型（Beta/Alpha/异常）

### 补丁检查
- [ ] 现金流健康度：经营现金流/净利润 ≥ 0.8
- [ ] 财务造假红灯：逐一排查

### 最终结论
- [ ] 给出【买入/观望/排除】结论
- [ ] 附带核心理由与风险提示
