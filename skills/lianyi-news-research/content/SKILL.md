## 二、涟漪AI新闻评分体系

每条新闻输出以下字段：

```json
{
  "title": "新闻标题",
  "source": "来源",
  "time": "时间",
  "summary": "摘要（50字内）",
  "lianyi_score": 0-100,
  "signal": "long | short | neutral",
  "related_markets": ["A股", "加密", "商品"],
  "related_coins": ["BTC", "ETH"],
  "risk_level": "高 | 中 | 低",
  "lianyi_verdict": "涟漪判断"
}
```

### 涟漪AI评分规则（0-100分）

| 信号类型 | 评分范围 | 说明 |
|---------|---------|------|
| 做多信号（long） | 60-100 | 利好、主力买入、积极政策 |
| 中性信号（neutral） | 40-59 | 信息中性、待观察 |
| 做空信号（short） | 0-39 | 利空、风险事件、泡沫警告 |

### 做多信号特征（评分+10到+20）
- 机构大额买入/增持仓
- 政策利好（降息/刺激/扶持）
- 业绩超预期
- ETF净流入
- 技术突破关键阻力

### 做空信号特征（评分-10到-20）
- 机构大额卖出/减持
- 政策利空（加息/收紧/监管）
- 业绩不及预期
- ETF净流出
- 技术破位/均线死叉

### 涟漪综合判断词（verdict）
- "强烈做多"（评分>80）
- "建议关注"（评分60-80）
- "中性观望"（评分40-59）
- "谨慎回避"（评分20-39）
- "强烈做空"（评分<20）

## 四、涟漪市场情绪指数

### 情绪判断标准

| 涟漪情绪指数 | 说明 | 操作建议 |
|-------------|------|---------|
| 🥊 极度贪婪（80-100） | 全民讨论市场，基金爆量发行 | 减仓，保留现金 |
| 🔴 贪婪（60-79） | 赚钱效应强，热点明确 | 持仓，不追高 |
| 🟡 中性（40-59） | 震荡分化，无明显主线 | 轻仓，高抛低吸 |
| 🟢 恐慌（20-39） | 跌停>30家，主力出逃 | 空仓，等恐慌买点 |
| ⚫ 极度恐慌（0-19） | 流动性危机，VIX>40 | 清仓，持有现金 |

### 情绪数据来源（涟漪四维）
1. **涨停板数量** → 赚钱效应
2. **北向/主力资金流向** → 机构方向
3. **VIX指数** → 恐慌程度
4. **涨跌家数比** → 市场广度
