# Article Writer - AI智能写作助手

专业的AI驱动智能写作系统，专注公众号和自媒体文章创作。

## 核心特性

### 多模式写作系统

根据文章类型和时间预算选择合适模式：

| 模式 | AI角色 | AI生成 | 时间投入 | 适用场景 |
|-----|-------|-------|---------|---------|
| 教练模式 | 教练（提问引导） | 0% | 3-4小时 | 产品评测、个人体验 |
| 快速模式 | 助手（生成初稿） | 100% | 1-2小时 | 论文解读、技术总结 |
| 混合模式 | 协作者（写框架） | 40% | 2-3小时 | 教程、案例分析 |
| 框架约束模式 | 助手（填充内容） | 60-80% | 2-3小时 | 立项报告、开题报告、标书 |

### 斜杠命令系统

在AI助手中直接使用斜杠命令：

```
阶段1: 准备
/specify      → 定义创作需求
/topic        → 选题讨论

阶段2: 收集
/research     → 信息搜索与调研
/collect      → 素材收集
/extract      → 提取真实经历

阶段3: 写作
/write        → 多模式写作
/outline      → 框架约束模式

阶段4: 检查
/authentic    → 5维真实性检查
/review       → 三遍审校

阶段5: 发布
/images       → 配图建议
/check        → 发布前检查
/publish      → 发布指南
```

### 工作区系统

| 工作区 | 特点 | 适用场景 |
|--------|------|----------|
| wechat | AI味<30%，段落<150字 | 公众号文章 |
| video | AI味<20%，高度口语化 | 视频脚本 |
| general | 灵活配置，SEO优化 | 博客/知乎/Medium |

## 适用场景

- 公众号文章创作
- 视频脚本/短视频脚本
- 自媒体内容生产
- 技术文档撰写
- 项目立项报告
- 开题报告/标书撰写

```bash
npm install -g article-writer-cn
content init my-article --workspace wechat
```
