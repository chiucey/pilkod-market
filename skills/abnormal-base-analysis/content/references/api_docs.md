# 东方财富 A 股数据 API 参考

## 1. A 股行情列表接口

获取沪深京 A 股实时行情数据，支持按涨跌幅排序。

**URL**: `https://push2.eastmoney.com/api/qt/clist/get`

**常用参数**:

| 参数 | 说明 | 示例值 |
|------|------|--------|
| pn | 页码 | 1 |
| pz | 每页数量 | 500 |
| po | 排序方向，0降序/1升序 | 0 |
| np | 分页方式 | 1 |
| fltt | 过滤类型 | 2 |
| invt | 投资类型 | 2 |
| fid | 排序字段 | f3 (涨跌幅) |
| fs | 市场筛选 | m:0+t:6,m:0+t:80,m:1+t:2,m:1+t:23 |
| fields | 返回字段 | f2,f3,f12,f14,f15,f16,f17 |

**fs 参数说明**:
- `m:0+t:6` - 上海 A 股
- `m:0+t:80` - 北京 A 股
- `m:1+t:2` - 深圳 A 股（主板）
- `m:1+t:23` - 深圳创业板

**fields 常用字段**:

| 字段 | 含义 |
|------|------|
| f2 | 最新价 |
| f3 | 涨跌幅(%) |
| f12 | 股票代码 |
| f14 | 股票名称 |
| f15 | 最高价 |
| f16 | 最低价 |
| f17 | 开盘价 |
| f5 | 成交量(手) |
| f6 | 成交额 |
| f8 | 换手率 |
| f20 | 总市值 |

**返回格式**:
```json
{
  "data": {
    "total": 5634,
    "diff": [
      {
        "f2": 85.32,
        "f3": 10.01,
        "f12": "301366",
        "f14": "一博科技",
        "f20": 8500000000
      }
    ]
  }
}
```

## 2. 个股 K 线数据接口

获取单只股票的日线/周线/月线 K 线数据。

**URL**: `https://push2his.eastmoney.com/api/qt/stock/kline/get`

**常用参数**:

| 参数 | 说明 | 示例值 |
|------|------|--------|
| secid | 股票标识，格式: market.code | 0.301366 |
| klt | K线周期: 101=日线, 102=周线, 103=月线 | 101 |
| fqt | 复权方式: 0=不复权, 1=前复权, 2=后复权 | 1 |
| beg | 开始日期 (YYYYMMDD) | 20260101 |
| end | 结束日期 (YYYYMMDD) | 20260604 |
| lmt | 返回条数上限 | 120 |
| fields1 | 始终返回的字段 | f1,f2,f3,f4,f5,f6 |
| fields2 | 按需返回的字段 | f51,f52,f53,f54,f55,f56,f57,f58,f59,f60,f61 |

**secid 构建规则**:
- 上海主板 (60xxxx): `1.60xxxx`
- 上海科创板 (688xxx): `1.688xxx`
- 深圳主板 (00xxxx): `0.00xxxx`
- 深圳创业板 (30xxxx): `0.30xxxx`
- 北京 (8xxxxx): `0.8xxxxx`

**K 线返回格式**: 每条 K 线为逗号分隔字符串:
```
日期,开盘,收盘,最高,最低,成交量,成交额,振幅,涨跌幅,涨跌额,换手率
```

**fields2 字段对应关系**:
| 字段 | 含义 |
|------|------|
| f51 | 日期 |
| f52 | 开盘价 |
| f53 | 收盘价 |
| f54 | 最高价 |
| f55 | 最低价 |
| f56 | 成交量(手) |
| f57 | 成交额(元) |
| f58 | 振幅(%) |
| f59 | 涨跌幅(%) |
| f60 | 涨跌额 |
| f61 | 换手率(%) |

## 3. 注意事项

- 所有接口返回 JSON 格式
- 需要设置 `Referer: https://quote.eastmoney.com/` 请求头
- 建议请求间隔 200-500ms，避免被限流
- 成交量单位为"手"（1手=100股）
- 非官方接口，可能随时变动
