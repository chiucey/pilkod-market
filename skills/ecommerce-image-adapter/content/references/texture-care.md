# 面料/材质质感处理参考

生成图片时，在提示词末尾附加对应材质的质感描述，确保面料细节和质感被保留。

---

## 棉麻 / 亚麻（Linen / Cotton）

```
soft natural linen texture visible, breathable fabric weave pattern clearly shown, matte finish, natural fiber details preserved
```

## 羊毛（Wool）

```
fine wool fiber texture visible, soft matte surface, natural sheep wool nuance preserved, no synthetic sheen
```

## 皮革（Leather）

```
genuine leather grain texture visible, natural leather sheen, soft natural light showing leather pore details, no plastic look
```

## 丝绒 / 天鹅绒（Velvet）

```
soft velvet pile texture visible, delicate light reflection on fabric surface, rich color depth, plush tactile quality preserved
```

## 羽绒 / 填充类（Down / Polyester Fill）

```
soft plump filling texture visible, natural down cluster details, fluffy volume preserved, no flat compressed look
```

## 针织 / 毛线（Knit）

```
visible knit stitch pattern, soft yarn texture, cozy hand-crafted quality preserved, no stiff synthetic look
```

## 合成纤维 / 科技面料（Synthetic）

```
smooth synthetic fabric texture, subtle technical weave pattern, clean modern material quality preserved
```

---

## 通用原则

1. **光线决定质感**：硬光 → 光滑/皮革；柔光 → 棉麻/羊毛/羽绒
2. **避免过度锐化**：会让面料看起来塑料感
3. **色温偏暖**（3000-4000K）：北欧自然光风格，原片色彩更柔和
4. **景深适中**：产品清晰，背景轻微虚化，保留北欧极简氛围
