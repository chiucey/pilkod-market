# Format Cloner - 格式克隆器

保持格式不变，智能替换内容。

## 核心能力

- **占位符模式**：`{{变量名}}` 标记 → 字典/JSON 数据替换
- **结构化映射**：JSON/CSV → 按字段映射到模板位置
- **差异对比**：自动识别两个文件的差异并应用

## 支持格式

| 类型 | 扩展名 | 处理能力 |
|------|--------|----------|
| 文档 | .docx, .doc | 完整保留段落、样式、表格、页眉页脚 |
| 表格 | .xlsx, .xls, .csv | 保留公式、格式、图表、样式 |
| 演示 | .pptx, .ppt | 保留布局、动画、母版、配色 |
| 其他 | .txt, .md, .html, .json, .pdf | 保留结构、标签、样式 |

## 工作流程

### Step 1: 分析输入

**必须提供：**
- `template_file`: 格式模板文件（已调好格式的文件）

**内容来源（任选其一）：**
- `content_file`: 包含新内容的文件
- `data_dict`: 直接提供的键值对数据
- `json_data`: JSON 格式的结构化数据
- `csv_data`: CSV 格式的表格数据

### Step 2: 检测替换模式

```
┌─────────────────────────────────────────────────┐
│                  替换模式选择                      │
├─────────────────────────────────────────────────┤
│                                                  │
│  模式A: 占位符模式                                 │
│  ├─ 模板包含 {{变量名}} 或 {变量名}                  │
│  ├─ 数据为字典或JSON                               │
│  └─ 精确替换指定占位符                              │
│                                                  │
│  模式B: 结构化映射模式                             │
│  ├─ 数据为JSON数组或CSV                           │
│  ├─ 按字段名或位置映射                             │
│  └─ 支持批量生成多条记录                           │
│                                                  │
│  模式C: 差异对比模式                              │
│  ├─ 模板A（旧内容）vs 模板B（新内容）               │
│  ├─ 自动识别差异                                   │
│  └─ 将差异应用到格式模板                           │
│                                                  │
└─────────────────────────────────────────────────┘
```

### Step 3: 执行替换

根据文件类型选择处理引擎：

| 文件类型 | 处理方法 | 关键操作 |
|----------|----------|----------|
| .docx | python-docx | 遍历所有段落、表格、页眉页脚 |
| .xlsx | openpyxl | 遍历所有单元格、公式、样式 |
| .pptx | python-pptx | 遍历所有幻灯片、形状、占位符 |
| .txt/.md | Python 字符串处理 | 正则匹配替换 |
| .json | json 模块 | 递归键值替换 |
| .csv | csv 模块 | 按行列映射 |
| .pdf | PyPDF2/pdfplumber | 文本层替换（需格式重建） |
| .html | BeautifulSoup | DOM 操作替换 |

### Step 4: 输出结果

- 生成新文件，保持原始格式不变
- 文件名自动添加后缀：`原文件名_processed.docx`
- 或按用户指定输出路径

## 使用示例

### 示例 1: 占位符替换（合同生成）

**模板文件 (contract_template.docx) 内容：**
```
合同编号：{{contract_no}}
甲方：{{party_a}}
乙方：{{party_b}}
签订日期：{{sign_date}}
金额：{{amount}} 元
```

**输入数据：**
```json
{
  "contract_no": "HT-2024-001",
  "party_a": "北京科技有限公司",
  "party_b": "上海贸易公司",
  "sign_date": "2024年3月15日",
  "amount": "500,000"
}
```

**输出：** 生成完整填写的合同文档

---

### 示例 2: 结构化数据批量生成（证书）

**模板文件 (certificate_template.docx)：**
```
{{name}} 同学
在 {{course}} 课程中表现优秀
特发此证
{{issue_date}}
```

**CSV 数据 (students.csv)：**
```csv
name,course,issue_date
张三,Python编程,2024-03-01
李四,数据分析,2024-03-01
王五,机器学习,2024-03-01
```

**输出：** 批量生成3张不同的证书

---

### 示例 3: 差异对比替换

**场景：** 模板A有旧数据，模板B有新数据，需要将新数据填入格式模板

- `format_template.docx`（纯格式，无具体内容）
- `old_data.docx`（旧版填写好的文档）
- `new_data.docx`（新版填写好的文档）

**结果：** 将 `new_data.docx` 中的内容按结构替换到格式模板

## 决策规则

### 占位符匹配优先级

1. **精确匹配**：`{{变量名}}` 完全一致
2. **不区分大小写**：如果精确匹配失败，忽略大小写再匹配
3. **花括号变体**：`{变量名}` 或 `${变量名}` 也视为有效占位符

### 多值数据处理

当数据为数组/多行时：
- 如果只有一个模板 → 批量生成多个文件
- 如果用户指定批量模式 → 生成ZIP压缩包

### 格式保护规则

1. **绝对不修改：**
   - 字体名称、大小、颜色
   - 段落间距、对齐方式
   - 表格边框、单元格合并
   - 页边距、页面方向
   - 页眉页脚内容（除非显式指定）

2. **只修改：**
   - 文本内容
   - 数值数据
   - 图片（如果提供新图片）

## 错误处理

| 错误类型 | 处理方式 |
|----------|----------|
| 模板文件不存在 | 提示用户上传格式模板 |
| 占位符在模板中不存在 | 警告并跳过，保留原占位符 |
| 数据缺少必要字段 | 提示缺失的字段列表 |
| 不支持的文件类型 | 提示支持的文件类型 |

## 输出格式

完成时返回：
- 输出文件路径
- 替换数量统计
- 警告信息（如果有）
