# 怎么坐地铁

当用户询问如何坐地铁时，按下列流程给出清晰、可执行的中文指引。先确认城市与起终点，再按步骤说明。

## 开始前先确认

向用户确认（缺一项就追问）：

1. **城市**（如北京、上海、深圳、重庆）
2. **起点**（站名或附近地标）
3. **终点**（站名或附近地标）
4. **是否高峰出行**（影响车厢与换乘建议）

若用户只问「怎么坐地铁」而无具体路线，先讲通用流程，再问城市与起终点给出具体方案。

## 通用乘车流程

按顺序指导用户：

### 1. 查路线

- 推荐：高德地图、百度地图、Apple 地图，或当地地铁官方 App
- 记下：**几号线 → 方向（开往哪一站）→ 几站 → 是否换乘 → 出口编号**
- 优先直达；必须换乘时，选换乘次数少、步行短的方案

### 2. 购票 / 进站方式（按优先级推荐）

| 方式 | 说明 |
|------|------|
| 手机支付 | 微信/支付宝「乘车码」，或当地地铁 App 二维码；过闸机扫码 |
| 交通卡 / 公交卡 | 刷卡进站、出站；部分城市支持手机 NFC |
| 单程票 | 自动售票机选终点站、投币/扫码购票；进站刷票，出站投票 |

提醒：进站前保证手机有电；首次用乘车码需先开通并授权定位/支付。

### 3. 进站

1. 看站外地图或指示牌，走到正确入口
2. 安检（包过机、人过门；液体等按当地规定）
3. 刷码 / 刷卡 / 刷票进闸；闸机指示灯变绿再通过
4. 跟「线路色 + 方向」指示牌走到站台（注意上下行）

### 4. 候车与上车

- 站在黄线内；看屏幕确认列车方向与到站时间
- 先下后上；车门两侧排队，不堵门口
- 上车后往车厢中部走；抓稳扶手或拉环
- 留意下一站报站（广播 + 车内屏幕）

### 5. 换乘（如有）

1. 到站后沿「换乘 X 号线」指示走，不要出闸
2. 确认新线路的**方向**后再上站台
3. 换乘通道可能较长，预留步行时间

### 6. 出站

1. 到站后沿「出口 Exit」指示走
2. 刷码 / 刷卡出闸；单程票投入回收口
3. 看出口编号与周边地标图，选最近出口
4. 出站后用地图导航到最终目的地

## 回答用户时的输出格式

给出具体路线时，使用下面模板：

```markdown
## 路线概要
- 城市：
- 从：A 站 → 到：B 站
- 方案：X 号线（开往 Y 方向）→ 换乘 Z 号线 → 到达
- 约 N 站 / 预计 M 分钟（不含步行）

## 逐步怎么走
1. 进站与购票：…
2. 上车：在 A 站上 X 号线，开往 Y，坐到 C 站
3. 换乘：在 C 站换乘 Z 号线，开往 W，坐到 B 站
4. 出站：建议走 Exit N，因为…

## 注意
- …
```

信息不确定时（站名、出口、是否可无障碍通行等），明确写出「请以站内指示牌 / 官方 App 为准」，不要编造站名或出口。

## 常见问题速答

- **坐过站**：下一站下车，走对面站台坐回程，或按站内「反方向」指示
- **乘车码没反应**：检查网络、是否开通、余额/免密支付；可改用单程票
- **高峰**：避开车厢两端门口堆积；无障碍需求选电梯/升降平台标志
- **行李**：大件走宽闸机；遵守当地限带规定
- **遗失物品**：尽快联系站内工作人员或地铁失物招领

## 安全与礼仪（简要带一句即可）

不扒门、不挡门；电瓶车/自行车一般禁止进站；先下后上；车厢内小声通话。

## 不要做的事

- 不要捏造不存在的线路、站名或出口编号
- 不要把公交、城际铁路当成地铁而不加区分
- 城市未定时，不要默认某一城市的线路图
