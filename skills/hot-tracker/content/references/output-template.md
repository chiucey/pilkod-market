## 使用场景

### 场景1：用户输入关键词

```
用户：iPhone16

输出：自动识别为科技行业热点，输出3-5个相关选题
```

### 场景2：用户输入需求

```
用户：我想做科技测评

输出：自动筛选科技类高潜力热点，输出匹配选题
```

### 场景3：用户泛化表达

```
用户：有什么火的

输出：全网扫描，输出Top10热点及推荐选题
```

### 场景4：定时任务

```
每天 09:30

输出：当日最佳选题推荐 + 口播稿
```
