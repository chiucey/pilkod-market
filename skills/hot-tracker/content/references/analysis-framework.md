## 跨平台热度计算框架

### H_global 计算公式

```
对每个平台分别做 Z 标准化：
H_p = w1·Z(赞/在看/投票类) + w2·Z(收藏/转发/分享) + w3·Z(评论) + w4·Z(阅读/播放/曝光)
     all × FreshDecay(τ=48h) × Relevance(行业/关键词)

H_global = Σ_p α_p · H_p
```

### 权重说明

| 权重 | 符号 | 值 | 说明 |
|------|------|-----|------|
| 赞/在看/投票类 | w1 | 0.32 | 点赞、在看等正面互动 |
| 收藏/转发/分享 | w2 | 0.28 | 价值认同和传播行为 |
| 评论 | w3 | 0.22 | 深度参与和讨论 |
| 阅读/播放/曝光 | w4 | 0.18 | 触达规模 |

### 新鲜度衰减

```
FreshDecay(hours) = exp(-hours / τ)

其中：
- hours：内容发布后的时间（小时）
- τ：衰减时间常数，默认为 48 小时
```

**衰减曲线示例**：

| 发布时间 | 衰减因子 | 说明 |
|----------|----------|------|
| 0h | 1.00 | 刚发布，无衰减 |
| 12h | 0.78 | 新鲜，轻度衰减 |
| 24h | 0.61 | 适中衰减 |
| 48h | 0.37 | 明显衰减 |
| 72h | 0.22 | 显著衰减 |

### 平台自适应权重（α_p）

根据各平台数据量和质量动态调整：

```
α_p = (样本量_p × 质量因子_p) / Σ(样本量 × 质量因子)
```

**质量因子参考**：

| 平台 | 质量因子 | 原因 |
|------|----------|------|
| 公众号 | 1.0 | 阅读数据可靠，互动数据完整 |
| 小红书 | 0.9 | 数据相对完整，无播放量 |
| 抖音 | 0.85 | 播放量可见，但评论质量参差 |

### Z 标准化处理

```
Z(x) = (x - μ) / σ

其中：
- x：原始数值
- μ：均值
- σ：标准差
```

**特殊情况处理**：

1. **全零值**：所有 Z 分数为 0
2. **全相同值**：所有 Z 分数为 0
3. **异常值**：保留，但考虑截断处理

## 低粉爆文识别框架

### 识别条件（满足任一即可）

#### 条件 A：账号规模小但表现突出

```
账号规模分位 ≤ 30% 且 单篇表现分位 ≥ 90%
```

**计算步骤**：

1. 计算账号粉丝数的分位排名
2. 计算单篇热度的分位排名
3. 判定是否满足条件

**适用场景**：
- 新账号突然爆火
- 小众领域精品内容
- 突发热点快速跟进

#### 条件 B：互动倍率异常高

```
单篇阅读/互动 LIFT ≥ 5 × 账号近90天中位数
```

**LIFT 计算公式**：

```
LIFT = 单篇热度 / 账号历史热度中位数
```

**适用场景**：
- 内容质量明显提升
- 热点事件精准捕捉
- 标题/封面优化显著

#### 条件 C：增量斜率进入前列

```
近24h增量斜率进入平台前10%分位
```

**增量斜率计算**：

```
增量斜率 = (当前热度 - 24h前热度) / 24h
```

**适用场景**：
- 热点快速发酵期
- 病毒式传播早期
- 平台算法推荐加持

### 低粉爆文分级

| 等级 | LIFT范围 | 定义 |
|------|----------|------|
| S级 | ≥ 10x | 极度异常，深度分析 |
| A级 | 7-10x | 高度异常，重点关注 |
| B级 | 5-7x | 明显异常，可借鉴 |
| C级 | 3-5x | 轻度异常，观察 |

## 爆款候选判定框架

### 判定条件

```
H_global ≥ 0.85 且 N ≥ 0.60 且 C ≥ 0.55
```

### 三维判定体系

#### 1. 综合热度（H_global）

| 分值范围 | 等级 | 说明 |
|----------|------|------|
| 0.90-1.00 | S级 | 超级爆款候选 |
| 0.85-0.89 | A级 | 强爆款候选 |
| 0.75-0.84 | B级 | 潜力爆款 |
| 0.65-0.74 | C级 | 一般热度 |
| < 0.65 | D级 | 低热度 |

#### 2. 新鲜度（N）

```
N = 1 - 近7日同构事件/话题复现率
```

| 分值范围 | 等级 | 说明 |
|----------|------|------|
| 0.80-1.00 | 新鲜 | 全新话题，独特性强 |
| 0.60-0.79 | 较新 | 有新意，有参考 |
| 0.40-0.59 | 一般 | 常见话题，需差异化 |
| < 0.40 | 陈旧 | 过度重复，谨慎 |

#### 3. 评论多样性（C）

```
C = 评论主题熵（含立场均衡）
```

| 分值范围 | 等级 | 说明 |
|----------|------|------|
| 0.70-1.00 | 多元 | 多角度讨论，争议性强 |
| 0.55-0.69 | 较多元 | 有多角度，争议适中 |
| 0.40-0.54 | 一般 | 单一视角为主 |
| < 0.40 | 单一 | 观点高度一致 |

### 爆款潜力评分

```
爆款潜力 = H_global × 0.5 + N × 0.25 + C × 0.25
```

**优先级排序**：按爆款潜力分数降序排列

## 评论洞察分析框架

### 评论主题分类

#### 主要类别

| 类别 | 说明 | 关键词示例 |
|------|------|------------|
| 需求 | 用户表达的需求和期望 | 想要、需要、希望、期待 |
| 痛点 | 用户遇到的问题和困扰 | 烦恼、困惑、不知道、难 |
| 价格 | 关于价格的讨论 | 贵、便宜、性价比、值得 |
| 渠道 | 关于购买渠道的信息 | 哪里买、天猫、京东、官方 |
| 真假 | 对内容真实性的质疑 | 假的、托、广告、水军 |
| 争议 | 不同观点的冲突 | 不同意、反对、质疑、反驳 |
| 二创 | 衍生内容和创意 | 搬运、模仿、类似、参考 |
| 情感 | 情感表达 | 喜欢、讨厌、激动、愤怒 |

#### 提取方法

**关键词匹配**：
- 基于规则的关键词识别
- 同义词扩展
- 负面情感词识别

**聚类分析**：
- 将评论按主题分组
- 识别高频主题
- 提取代表性观点

**神评识别**：
- 点赞数前5的高赞评论
- 独特观点或创意表达
- 精辟总结或反直觉观点

### 评论多样性计算

```
C = -Σ (p_i × log2(p_i))

其中：
- p_i：第 i 个主题的评论占比
- log2：以2为底的对数
```

**多样性等级**：

| C值 | 多样性 | 说明 |
|-----|--------|------|
| > 2.5 | 高度多元 | 多主题，观点丰富 |
| 1.5-2.5 | 中等多元 | 3-4个主题，有讨论 |
| 0.5-1.5 | 较单一 | 1-2个主题，观点集中 |
| < 0.5 | 单一 | 单一主题，观点一致 |

## 机会标签体系

### 标签分类

#### 内容类型

| 标签 | 适用场景 | 优先级 |
|------|----------|--------|
| 清单×价格带 | 不同价位的产品对比 | 高 |
| 清单×预算段 | 特定预算范围内的推荐 | 高 |
| 清单×功能点 | 功能维度的整理汇总 | 中 |
| 对比×替代款 | 平价替代、竞品对比 | 高 |
| 攻略×路线 | 流程、步骤指导 | 中 |
| 测评×功效 | 效果验证、体验分享 | 高 |
| 避坑×误区 | 常见错误、注意事项 | 高 |
| 事实核查 | 辟谣、验证真伪 | 中 |
| 本地福利 | 城市、区域化信息 | 低 |
| KOL联动 | 达人合作、跨界 | 低 |

#### 行业适配

**美妆护肤**：
- 测评×功效、避坑×误区、清单×价格带

**数码科技**：
- 对比×替代款、清单×功能点、事实核查

**美食餐饮**：
- 攻略×路线、测评×功效、清单×价格带

**家居生活**：
- 清单×预算段、避坑×误区、攻略×路线

**服饰穿搭**：
- 对比×替代款、清单×风格、KOL联动

### 标签组合策略

#### 组合规则

```
主标签 × 次标签 + 辅助标签

示例：
- 清单×价格带（主） + 数码行业 + 小红书平台
- 测评×功效（主） + 美妆行业 + 短视频平台
```

#### 优先级排序

1. **高优先级**：清单×、对比×、测评×、避坑×
2. **中优先级**：攻略×、事实核查、KOL联动
3. **低优先级**：本地福利、平台特定标签

### 标签使用建议

#### 内容创作

- **清单类**：适合信息量大、易于消化的内容
- **对比类**：适合有明确竞品或替代方案的内容
- **测评类**：适合需要验证和背书的内容
- **攻略类**：适合流程性强、需要指导的内容

#### 平台适配

- **公众号**：清单×、对比×、事实核查（深度内容）
- **小红书**：测评×、避坑×、清单×价格带（种草导向）
- **抖音**：清单×、攻略×、KOL联动（短平快）

## 分析流程总结

### 完整分析流程

```
1. 数据加载
   ├─ 加载各平台榜单数据
   ├─ 验证数据完整性
   └─ 数据清洗和标准化

2. 热度计算
   ├─ 计算各平台热度 H_p
   ├─ 应用新鲜度衰减
   ├─ 计算综合热度 H_global
   └─ 跨平台事件聚合

3. 特征识别
   ├─ 识别低粉爆文
   ├─ 计算新鲜度 N
   ├─ 计算评论多样性 C
   └─ 判定爆款候选

4. 深度分析
   ├─ 评论主题提取
   ├─ 神评识别
   ├─ 机会标签匹配
   └─ 选题推荐

5. 输出生成
   ├─ 生成 JSON 格式输出
   ├─ 生成人读版日报
   └─ 生成口播稿
```

### 质量控制

- **数据验证**：确保输入数据完整、准确
- **算法校准**：定期调整权重参数
- **结果验证**：人工抽检分析结果
- **持续优化**：根据反馈改进算法
