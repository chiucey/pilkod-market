# 大宗商品每日媒体简报系统

## 功能概述

这是一个专注于大宗商品行业的自动化媒体信息采集与报告生成系统。

### 核心功能

1. **多数据源爬虫**
   - 财经媒体：华尔街见闻、财联社、金十数据
   - 行业门户：上海有色网(SMM)、我的钢铁网、隆众资讯
   - 交易所公告：上海期货交易所、大连商品交易所、郑州商品交易所、上海国际能源交易中心
   - 宏观数据：国家统计局、人民银行、美联储、新华财经

2. **智能分类系统**
   - **宏观要闻**：GDP、CPI、利率、货币政策等
   - **期货行业**：期货价格、交割、库存、基差等
   - **产业动态**：供需、产量、产能、进出口等

3. **品种关联**
   - 有色金属：铜、铝、锌、镍、锡、铅
   - 黑色金属：螺纹钢、铁矿石、焦煤、热卷
   - 贵金属：黄金、白银
   - 能源化工：原油、天然气、燃料油、橡胶、塑料、甲醇
   - 农产品：大豆、玉米、棉花、白糖、棕榈油

4. **输出格式**
   - Word文档（可直接分发的专业简报）
   - HTML文件（邮件正文备份）
   - 邮件自动发送（可选）

## 使用方法

### 首次配置

1. 编辑 `config.json`：
   - 填写邮箱SMTP信息
   - 设置重点关注品种
   - 配置代理（如需要）

2. 安装依赖：
```bash
pip install requests beautifulsoup4 lxml python-docx
```

### 运行简报

```bash
python daily_briefing.py
```

### 输出文件

```
output/
├── 2026-04-02_大宗商品简报5000期.docx
├── 2026-04-02_大宗商品简报5000期.html
└── logs/
    └── 2026-04-02.log
```

## 配置说明

### config.json 参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `scraping.min_delay` | 请求最小间隔(秒) | 3 |
| `scraping.max_delay` | 请求最大间隔(秒) | 8 |
| `scraping.max_retries` | 失败重试次数 | 2 |
| `focus_commodities` | 重点品种列表 | 铜、铝、原油等 |

### 邮箱配置

- QQ邮箱：`smtp_server = "smtp.qq.com"`
- 163邮箱：`smtp_server = "smtp.163.com"`

## 技术特点

1. **防封机制**：随机User-Agent、请求延时、重试机制
2. **去重算法**：基于字符串相似度的新闻去重
3. **智能排序**：重点品种新闻优先显示
4. **容错设计**：单个数据源失败不影响整体采集
