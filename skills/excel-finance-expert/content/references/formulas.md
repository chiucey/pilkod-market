# Excel 财务函数速查表

## 时间价值函数

### PV (Present Value) - 现值
```
=PV(rate, nper, pmt, [fv], [type])
```
- rate: 利率（期间）
- nper: 总期数
- pmt: 每期付款金额
- fv: 未来值（可选，默认0）
- type: 期初/期末付款（0=期末，1=期初）

**示例**: 5年后需要100万，利率4%，现在需要存入多少？
```
=PV(4%, 5, 0, 1000000)  → -855,597
```

### FV (Future Value) - 终值
```
=FV(rate, nper, pmt, [pv], [type])
```
**示例**: 每月存5000，年利率5%，存20年后有多少？
```
=FV(5%/12, 20*12, -5000)  → 2,079,158
```

### NPV (Net Present Value) - 净现值
```
=NPV(rate, value1, [value2], ...)
```
**示例**: 项目初始投资50万，后续5年分别带来10万、15万、20万、25万、30万收益，利率8%
```
=NPV(8%, 100000, 150000, 200000, 250000, 300000) - 500000
```

### IRR (Internal Rate of Return) - 内部收益率
```
=IRR(values, [guess])
```
**示例**: 计算投资50万，收益10万、20万、25万、15万的IRR
```
=IRR({-500000, 100000, 200000, 250000, 150000})  → 约16.8%
```

### PMT (Payment) - 等额本息还款
```
=PMT(rate, nper, pv, [fv], [type])
```
**示例**: 贷款100万，年利率5.5%，20年还清，月供？
```
=PMT(5.5%/12, 20*12, 1000000)  → -6,855
```

## 折旧函数

### SLN (Straight-Line) - 直线法
```
=SLN(cost, salvage, life)
```
**示例**: 设备原值100万，残值10万，使用5年，每年折旧？
```
=SLN(1000000, 100000, 5)  → 180,000
```

### DDB (Double Declining Balance) - 双倍余额递减法
```
=DDB(cost, salvage, life, period, [factor])
```
**示例**: 同上，第一年折旧？
```
=DDB(1000000, 100000, 5, 1, 2)  → 400,000
```

## 常用财务指标计算

### 投资回收期 (Payback Period)
```
=COUNTIF(累计现金流列, "<=0") + ABS(最后一个负值累计) / 下一个正值
```

### 资产负债率
```
=负债总额 / 资产总额
```

### 流动比率
```
=流动资产 / 流动负债
```

### 速动比率
```
=(流动资产 - 存货) / 流动负债
```

### 毛利率
```
=(营业收入 - 营业成本) / 营业收入
```

### 净利率
```
=净利润 / 营业收入
```

## DCF 估值模型结构

### Sheet结构建议
1. **Assumptions**: 关键假设输入
2. **Income Statement**: 利润表预测
3. **Balance Sheet**: 资产负债表预测
4. **Cash Flow**: 自由现金流计算
5. **Valuation**: 估值计算与结果

### 自由现金流计算
```
FCF = 净利润
    + 折旧摊销
    - 资本支出
    +/- 营运资本变动
```

### 终值计算 (Gordon Growth Model)
```
TV = FCF_n × (1 + g) / (WACC - g)
```

### 企业价值
```
EV = Σ(FCF_t / (1 + WACC)^t) + TV / (1 + WACC)^n
```
