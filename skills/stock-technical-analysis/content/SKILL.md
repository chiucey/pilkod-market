# 股票技术分析技能

对指定股票进行全面技术分析研判，整合道氏理论、艾略特波浪理论、欧奈尔CAN SLIM系统和技术指标分析。

## 分析流程

### 阶段一：道氏理论趋势分析

使用查尔斯·道的经典理论判断股票当前趋势状态：

1. **主要趋势判断**
   - 分析价格是否持续创出更高高点（HH）和更高低点（HL）→ 牛市
   - 或持续创出更低低点和更低高点（LL和LH）→ 熊市
   - 或价格在区间内波动 → 盘整

2. **次要趋势识别**
   - 判断是否处于回调（反弹）阶段
   - 回调幅度通常为前一波段的33%-66%

3. **成交量确认**
   - 牛市：上涨时放量，下跌时缩量
   - 熊市：下跌时放量，反弹时缩量

4. **关键价位标注**
   - 最近3-6个月的支撑位和阻力位
   - 使用整数关口和前期高低点

### 阶段二：艾略特波浪分析

分析近三年低点以来的波浪结构：

1. **波浪计数**
   - 识别推动浪（1、2、3、4、5）和调整浪（A、B、C）
   - 标记各浪的起止点和具体价格

2. **波浪比率分析**
   - 推动浪：3浪通常是1浪的161.8%
   - 4浪回调通常不跌破1浪的100%
   - 5浪高度通常等于1浪或为1浪的61.8%

3. **目标位预测**
   - 如果在推动浪：计算各浪目标位
   - 如果在调整浪：预测A浪终点和B浪反弹高度

4. **置信度评估**
   - 高置信度：波浪结构清晰、比率符合标准
   - 中置信度：基本符合但有小偏差
   - 低置信度：结构复杂或存在多种计数

### 阶段三：欧奈尔CAN SLIM七维度分析

使用威廉·欧奈尔的CAN SLIM系统进行评分（每项1-10分）：

1. **C - 当前季度盈利**
   - 查询最近季度EPS同比增长率
   - 理想值：≥25%

2. **A - 年度盈利增长**
   - 分析过去3-5年年度EPS复合增长率
   - 理想值：≥25%

3. **N - 新产品/新管理层/创新高**
   - 是否有新产品、新管理层、创新高突破
   - 股价是否在稳固期后向上突破

4. **S - 供需关系**
   - 流通股数量变化
   - 机构持仓动向
   - 大单买卖信号

5. **L - 领导股还是落后股**
   - 相对强度(RS)评级（1-99）
   - 在同行业中的排名

6. **I - 机构持仓**
   - 顶级基金持仓变化
   - 最近一个季度增减仓情况

7. **M - 市场方向**
   - 大盘当前趋势
   - 是否适合买入时机

**综合评级计算**：各维度平均分，≥7分为优质，5-7分为中等，<5分为较弱。

### 阶段四：技术指标汇总

查询并汇总以下指标最新值：

| 指标 | 参数 | 含义 |
|------|------|------|
| RSI(14) | 14日 | 超买>70，超卖<30 |
| MACD | 12,26,9 | 金叉/死叉、柱状图 |
| 布林带 | 20,2 | 突破上轨/下轨信号 |
| 均线 | 50/200日 | 金叉/死叉、多头/空头排列 |
| ATR | 14日 | 波动率衡量 |

### 阶段五：综合研判

1. **学派一致性判断**
   - 三个学派的结论是否相互印证
   - 如有分歧，分析原因

2. **分周期方向判断**

| 时间周期 | 方向 | 依据 |
|----------|------|------|
| 短期(1-4周) | 看涨/看跌/中性 | |
| 中期(1-3月) | 看涨/看跌/中性 | |
| 长期(6-12月) | 看涨/看跌/中性 | |

3. **关键价位建议**
   - **支撑位**：值得关注的买入区域
   - **阻力位**：可能的卖出或止盈区域
   - **止损位**：风险控制关键点

4. **适合交易者类型**
   - 激进型：追求高收益、接受高风险
   - 稳健型：等待确认信号、控制仓位
   - 保守型：长线持有、注重基本面

## 执行要点

1. **数据获取顺序**
   - 先获取股票基本信息（代码、名称、当前价格）
   - 再获取历史价格数据用于技术分析
   - 最后获取财务数据进行CAN SLIM分析

2. **置信度处理**
   - 对于不确定的分析，明确标注置信度
   - 提供多种可能的计数方案
   - 建议用户结合自身风险承受能力判断

3. **风险提示**
   - 技术分析仅供参考，不构成投资建议
   - 请结合基本面分析和市场环境综合判断
   - 建议设置止损位控制风险
