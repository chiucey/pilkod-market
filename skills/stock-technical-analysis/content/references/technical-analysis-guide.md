# 技术分析参考指南

本文档提供股票技术分析的详细参考信息，包括各理论的核心概念、计算公式和分析方法。

## 一、道氏理论核心原则

### 1.1 三大假设
1. 指数反映一切已知信息
2. 市场趋势分为三种：主要趋势、次要趋势、短期趋势
3. 趋势确认需要成交量配合

### 1.2 主要趋势判断标准

| 趋势类型 | 牛市特征 | 熊市特征 |
|----------|----------|----------|
| 高点 | 不断创新高(HH) | 不断创新低(LH) |
| 低点 | 不断抬高(HL) | 不断降低(LL) |
| 成交量 | 上涨放量、调整缩量 | 下跌放量、反弹缩量 |

### 1.3 次要趋势（回调/反弹）
- **回调幅度**：通常为前一波段的33%-66%
- **回调时间**：通常持续3周至3个月
- **判断标准**：不跌破前一个主要趋势的起点

### 1.4 关键支撑阻力位计算
1. **整数关口**：价格以0、5、00结尾的位置
2. **前期高点/低点**：过去3-6个月的重要转折点
3. **均线支撑**：50日、200日均线
4. **布林带中轨**：20日均线

## 二、艾略特波浪理论

### 2.1 波浪基础结构

**推动浪（5浪结构）**
```
浪1：起始驱动浪
浪2：回调，不跌破浪1起点，通常回调61.8%
浪3：最强势，通常是浪1的161.8%
浪4：复杂调整，不与浪1重叠，回调38.2%-50%
浪5：最后一波，可细分为5小浪
```

**调整浪（3浪结构）**
```
A浪：下跌第一波
B浪：反弹，通常回撤A浪的38.2%-78.6%
C浪：最终下跌，通常与A浪等长或1.618倍
```

### 2.2 波浪比率表

| 关系 | 常用比率 |
|------|----------|
| 浪2回调浪1 | 38.2%, 50%, 61.8%, 78.6% |
| 浪3与浪1 | 100%, 138.2%, 161.8%, 200%, 261.8% |
| 浪4回调浪3 | 23.6%, 38.2%, 50%, 61.8% |
| 浪5与浪1 | 61.8%, 100%, 138.2% |
| 调整A与C | 100%, 161.8%, 261.8% |
| B浪回调A浪 | 38.2%, 50%, 61.8%, 78.6%, 100% |

### 2.3 波浪计数置信度

| 置信度 | 特征 |
|--------|------|
| 高 | 比率精准、结构清晰、无替代方案 |
| 中 | 基本符合、有轻微偏差、存在1-2个替代计数 |
| 低 | 结构复杂、多个替代计数、比率不明确 |

## 四、技术指标详解

### 4.1 RSI (相对强弱指标)

**计算公式**
```
RSI = 100 - (100 / (1 + RS))
RS = 平均涨幅 / 平均跌幅
```

**参数与信号**
| 参数 | 超买 | 超卖 | 背离信号 |
|------|------|------|----------|
| 14日 | >70 | <30 | 价格创新高但RSI下降=看跌背离 |
| 6日 | >80 | <20 | 价格创新低但RSI上升=看涨背离 |

### 4.2 MACD (移动平均收敛发散)

**计算公式**
```
DIF = 12日EMA - 26日EMA
DEA = DIF的9日EMA
MACD柱 = (DIF - DEA) × 2
```

**信号解读**
| 信号类型 | DIF | DEA | MACD柱 |
|----------|-----|-----|--------|
| 金叉 | 上穿 | - | 由负转正 |
| 死叉 | 下穿 | - | 由正转负 |
| 零轴之上 | DIF>0 | - | 多头市场 |
| 零轴之下 | DIF<0 | - | 空头市场 |

### 4.3 布林带

**计算公式**
```
中轨 = 20日均线
上轨 = 中轨 + 2倍标准差
下轨 = 中轨 - 2倍标准差
```

**交易信号**
| 价格位置 | 信号含义 |
|----------|----------|
| 触及上轨 | 可能超买，考虑卖出 |
| 触及下轨 | 可能超卖，考虑买入 |
| 突破上轨 | 强势信号，确认上涨 |
| 跌破下轨 | 弱势信号，确认下跌 |
| 收窄开口 | 酝酿突破 |

### 4.4 均线系统

**常用均线周期**
- 短期：5日、10日（短线操作）
- 中期：20日、50日（波段操作）
- 长期：100日、200日（趋势判断）

**均线排列**
| 排列类型 | 多头排列 | 空头排列 |
|----------|----------|----------|
| 条件 | 短期>中期>长期 | 短期<中期<长期 |
| 含义 | 上升趋势 | 下降趋势 |

**金叉死叉**
- 金叉：短期均线上穿长期均线 → 买入信号
- 死叉：短期均线下穿长期均线 → 卖出信号

### 4.5 ATR (平均真实波幅)

**计算公式**
```
TR = max(今日高点-今日低点, |今日高点-昨日收盘|, |今日低点-昨日收盘|)
ATR = TR的14日简单平均
```

**应用**
- 止损设置：入场价 ± 2×ATR
- 目标位：入场价 ± 3×ATR
- 波动率比较：ATR越大，波动越剧烈
