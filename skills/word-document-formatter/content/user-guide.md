### 方式二：Python 脚本（适合批量处理）

#### 第1步：确认已安装依赖

```bash
pip install python-docx
```

> 💡 提示：你的电脑已经安装好了！

#### 第2步：准备要格式化的文档

把你的 Word 文档放在 `word-document-formatter` 文件夹中，例如：
- `我的请示.docx`
- `报价函.docx`
- `报价单.docx`

#### 第3步：运行格式化命令

**基本用法（自动识别类型）：**
```bash
python scripts/format_doc.py 输入文件.docx 输出文件.docx
```

**指定文档类型：**
```bash
# 请示/报告类
python scripts/format_doc.py 我的请示.docx 格式化后.docx petition

# 报价函/询价函
python scripts/format_doc.py 报价函.docx 格式化后.docx quotation

# 报价单/清单
python scripts/format_doc.py 报价单.docx 格式化后.docx price_list
```

## 📋 支持的文档类型

### 1️⃣ 请示/报告类 (petition)

**适用文档**：
- 请示
- 报告
- 申请
- 审批文件

**识别关键词**：请示、批示、妥否、请批示、特此报告

**格式化效果**：
```
                    标题（二号加粗居中）

收件单位：（三号顶格）

    正文内容...（小四首行缩进2字符）
    
    更多正文...

妥否，请批示。（单独段落）

附件：xxx（顶格）

                                    日期（右对齐）
                        （经办人信息）（右对齐小字）
```

---

### 2️⃣ 报价函/询价函 (quotation)

**适用文档**：
- 报价函
- 询价函
- 招标文件
- 采购需求

**识别关键词**：报价函、询价、比价、控制价、供应商

**格式化效果**：
```
                标题（二号加粗居中）

一、项目需求（三号加粗）

    具体内容...（小四首行缩进）

二、技术要求

    具体内容...

控制价：36,800.00元（加粗突出）

联系人：张三
联系电话：13800138000

                        单位名称（右对齐加粗）
                            日期（右对齐）
```

    1. 条款一...

供货商名称：_____________

## 💡 实际使用示例

### 示例1：格式化你的三个文档

假设你把这三个文档放在当前文件夹：

```bash
# 文档1：请示
python scripts/format_doc.py "信息技术中心关于采购生产网杀毒软件续期授权的请示(1).docx" "格式化后-请示.docx" petition

# 文档2：报价函
python scripts/format_doc.py "沈阳机场停车场系统服务器升级项目报价函.docx" "格式化后-报价函.docx" quotation

# 文档3：报价清单
python scripts/format_doc.py "附件：1、报价清单格式范本.docx" "格式化后-清单.docx" price_list
```

### 示例2：批量处理整个文件夹

**Windows PowerShell：**
```powershell
Get-ChildItem *.docx | ForEach-Object {
    python scripts/format_doc.py $_.Name "formatted_$($_.Name)"
}
```

**CMD 命令提示符：**
```cmd
for %f in (*.docx) do python scripts/format_doc.py "%f" "formatted_%f"
```

## ⚙️ 自定义配置

如果需要调整格式标准，编辑 `scripts/format_doc.py` 文件：

### 修改字号

找到 `_apply_style` 方法中的 `size_map`：

```python
size_map = {
    'heading1': 22,    # 一级标题字号，可改为 24、20 等
    'heading2': 16,    # 二级标题字号
    'normal': 12,      # 正文字号
    'table_content': 10.5,  # 表格字号
}
```

### 修改字体

找到 `__init__` 方法：

```python
def __init__(self):
    self.chinese_font = 'Microsoft YaHei'  # 改为 'SimSun'（宋体）等
    self.english_font = 'Arial'
```

### 修改缩进

找到 `_apply_style` 方法中的缩进设置：

```python
if indent:
    pf.first_line_indent = Pt(24)  # 改为 Pt(28)、Pt(20) 等
```

## ❓ 常见问题

### Q1: 如何知道文档应该用哪种类型？

**A**: 可以不指定类型，让程序自动识别：
```bash
python scripts/format_doc.py 输入.docx 输出.docx
```

或者根据关键词判断：
- 有"请示"、"批示" → petition
- 有"报价函"、"控制价" → quotation
- 有"报价单"、"序号" → price_list

### Q2: 格式化后内容会变吗？

**A**: 不会！只调整格式（字体、字号、对齐、间距等），**内容完全不变**。

### Q3: 表格能自动重建吗？

**A**: 基础版本会简化处理表格。复杂表格建议：
1. 使用 AI 辅助方式（我帮你重建）
2. 或手动调整格式化后的表格

### Q4: 可以撤销格式化吗？

**A**: 建议格式化前备份原文件。如果没备份，重新从原始文件格式化即可。

### Q5: 支持 Mac/Linux 吗？

**A**: 支持！Python 脚本跨平台，命令相同。
