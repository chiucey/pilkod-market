# Word 公文智能格式化

## 快速开始

当用户提供 Word 文档需要格式化时：

1. **读取文档内容**，分析文档结构和类型
2. **识别文档类型**：请示/报告、报价函、清单表格、通知等
3. **提取关键元素**：标题、正文、条款、表格、签名等
4. **应用统一格式**：按照公文标准格式化所有元素
5. **输出格式化文档**，保持内容不变仅调整格式

## 文档类型识别

### 请示/报告类
**特征关键词**：请示、报告、批示、妥否、请批示、特此报告
**格式要点**：
- 标题居中加粗（二号字）
- 收件单位顶格或空两格（三号字）
- 正文首行缩进2字符（小四号字）
- 结尾语单独成段
- 日期右对齐
- 附件说明顶格

### 报价函/询价函类
**特征关键词**：报价函、询价、比价、供应商、控制价、报价要求
**格式要点**：
- 标题居中加粗
- 章节标题加粗（一、二、三、或1. 2. 3.）
- 条款清晰分段
- 关键信息（金额、联系方式）突出显示
- 落款单位右对齐加粗
- 日期右对齐

### 清单/表格类
**特征关键词**：报价单、清单、序号、合计、备注
**格式要点**：
- 标题居中加粗
- **重建规范表格**（最重要）
- 表头加粗居中，浅灰背景
- 数据行左对齐或居中
- 数字右对齐或居中
- 合计行加粗
- 备注条款编号清晰
- 签名区域预留位置

### 通知/公告类
**特征关键词**：通知、公告、通告、决定
**格式要点**：
- 标题居中加粗
- 正文规范段落
- 条款编号规范

## 统一格式标准

### 字体规范
- **中文字体**：微软雅黑（Microsoft YaHei）
- **英文字体**：Arial
- **数字字体**：Arial 或 Times New Roman

### 字号规范

| 元素 | 字号 | 加粗 | 说明 |
|------|------|------|------|
| 一级标题 | 二号(22pt) | 是 | 文档主标题 |
| 二级标题 | 三号(16pt) | 是 | 章节标题 |
| 三级标题 | 四号(14pt) | 是 | 小节标题 |
| 正文 | 小四(12pt) | 否 | 普通段落 |
| 表格内容 | 五号(10.5pt) | 否 | 表格内文字 |
| 备注说明 | 小四(12pt) | 否 | 附注信息 |

### 段落格式

**正文段落**：
- 首行缩进：2字符（约24pt）
- 行距：1.5倍
- 对齐：两端对齐
- 段前段后：0pt

**标题段落**：
- 一级标题：居中，段前18pt，段后12pt
- 二级标题：左对齐，段前12pt，段后6pt，首行缩进2字符
- 三级标题：左对齐，段前6pt，段后6pt，首行缩进2字符

**特殊段落**：
- 日期：右对齐，段前12pt
- 签名单位：右对齐加粗
- 附件说明：左对齐顶格
- 联系信息：右对齐或单独段落

### 表格格式

**表头**：
- 字体：微软雅黑，小四(12pt)，加粗
- 对齐：居中
- 背景：浅灰色（#D9E2F3）
- 边框：实线0.5pt

**表格内容**：
- 字体：微软雅黑，五号(10.5pt)
- 对齐：文字左对齐，数字居中或右对齐
- 行高：适中，留有空隙

**列宽建议**：
- 序号列：0.8英寸
- 名称列：1.5-2.0英寸
- 规格列：2.0-2.5英寸
- 数量/单位列：0.6-0.8英寸
- 金额列：1.2-1.5英寸

## 内容识别规则

### 标题识别

**一级标题**（文档主标题）：
- 通常是文档第一行
- 包含"关于"、"请示"、"报告"、"函"、"单"等关键词
- 长度一般不超过40字符
- 独立成行，前后可能有空行

**二级标题**（章节标题）：
- 以"一、二、三、"或"1. 2. 3."开头
- 或以"项目名称："、"质量要求："等冒号结尾的短文本
- 长度较短，通常不超过20字符

**三级标题**（小节标题）：
- 以"（一）"、"（1）"或"1.1"等开头
- 更细粒度的内容分组

### 正文识别
- 长度超过30字符的段落
- 包含完整句子，以句号、问号、感叹号结尾
- 不包含明显的序号模式

### 条款识别
- 以"一、"、"1."、"（一）"、"①"等开头
- 多条连续的同级别项目
- 每条独立成段

### 金额识别
- 包含数字和"元"、"万元"等单位
- 格式如：48,850.00元、36800.00元
- 应该加粗显示

### 日期识别
- 格式：2025年11月24日 或 2025年xx月xx日
- 通常在文档末尾
- 应该右对齐

### 签名识别
- 包含单位名称，如"沈阳桃仙国际机场股份有限公司"
- 通常在日期上方
- 应该右对齐加粗


### 步骤1: 读取文档

使用 python-docx 读取：

```python
from docx import Document
doc = Document('input.docx')
paragraphs = [p.text.strip() for p in doc.paragraphs if p.text.strip()]
```

### 步骤2: 识别文档类型

```python
def identify_doc_type(paragraphs):
    """识别文档类型"""
    text_all = ' '.join(paragraphs)
    
    if any(kw in text_all for kw in ['请示', '批示', '妥否']):
        return 'petition'
    elif any(kw in text_all for kw in ['报价函', '询价', '比价', '控制价']):
        return 'quotation'
    elif any(kw in text_all for kw in ['报价单', '清单', '序号', '合计']):
        return 'price_list'
    elif any(kw in text_all for kw in ['通知', '公告', '通告']):
        return 'notice'
    else:
        return 'general'
```

### 步骤3: 提取关键元素

根据文档类型提取：
- 标题
- 收件单位/前言
- 正文段落
- 条款列表
- 表格数据（如果有）
- 签名和日期

### 步骤4: 应用格式

使用格式化脚本或手动应用：

```bash
# 安装依赖
pip install python-docx

# 运行格式化脚本
python scripts/format_doc.py input.docx output.docx [doc_type]
```

### 步骤5: 验证输出

检查：
- ✓ 标题是否正确加粗居中
- ✓ 正文是否首行缩进
- ✓ 表格是否规范
- ✓ 日期和签名位置正确
- ✓ 关键信息突出显示

## 常见场景示例

### 场景1：请示文档

**输入**：混乱格式的请示
**处理**：
- 标题 → 二号加粗居中
- "规划采购部：" → 三号顶格
- 正文 → 小四首行缩进2字符
- "妥否，请批示。" → 单独段落
- "附件：..." → 顶格
- 日期 → 右对齐
- 经办人 → 右对齐小字

### 场景2：报价函

**输入**：格式不规范的报价函
**处理**：
- 标题 → 二号加粗居中
- "一、项目需求" → 三号加粗
- 各条款 → 小四首行缩进
- 控制价 → 加粗突出
- 联系方式 → 清晰分段
- 落款 → 右对齐加粗

### 场景3：报价清单

**输入**：表格丢失的清单文本
**处理**：
- 标题 → 二号加粗居中
- **重建表格**（最重要）
  - 识别表头和数据行
  - 创建规范表格
  - 设置列宽和对齐
  - 表头加粗浅灰背景
- 备注条款 → 编号清晰
- 签名区 → 预留位置

## 注意事项

⚠️ **重要提示**：

1. **备份原文件**：格式化前务必备份
2. **表格重建**：复杂表格可能需要手动调整
3. **特殊元素**：图片、公式、图表需单独处理
4. **字体可用性**：确保系统安装了微软雅黑
5. **人工检查**：自动化后务必人工审核关键内容
6. **保留内容**：只改格式，不改内容
