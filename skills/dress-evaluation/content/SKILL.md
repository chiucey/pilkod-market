# 穿搭评价与建议系统

## 功能概述

增强版穿搭评价系统，支持多维度综合评估：

| 评价维度 | 说明 |
|---------|------|
| 基础版型配色 | 评估合身度、颜色搭配、整体协调性 |
| 体型适配 | 苹果型、梨形、沙漏型、H型、倒三角型、标准型 |
| 肤色匹配 | 冷色调/暖色调肤色与服装颜色的和谐度 |
| 年龄风格 | 各年龄段适合的风格定位 |
| 上下装比例 | 腰线位置、高矮比例优化 |
| 配饰搭配 | 数量、风格、点睛效果 |
| 季节适宜 | 材质、颜色与季节的匹配 |
| 场景匹配 | 职场、约会、日常、运动、聚会等 |

## 使用方法

### 输入参数

```python
minimax_dress_evaluation_enhanced(
    gender: str,           # "male" 或 "female"
    age_range: str,         # "18-25", "26-35", "36-45", "46+"
    scene: str,            # "日常", "职场", "约会", "运动", "聚会"
    img_features: dict = {  # 图像特征字典
        "current_dress": str,      # 当前穿着描述
        "body_type": str,         # 体型类型
        "skin_undertone": str,    # 肤色基调: "冷", "暖", "自然"
        "complexion": str,        # 肤色明暗: "偏白", "正常", "偏黑"
        "accessories": list,      # 配饰列表
        "season": str,            # 季节: "春夏", "秋冬", "春秋"
        "top_length": str,        # 上装长度
        "bottom_length": str,     # 下装长度
        "waistline": str          # 腰线位置
    }
)
```

## 评分标准

| 分数段 | 等级 | 描述 |
|-------|------|------|
| ≥9.0 | 卓越 | 完美驾驭，时尚感与质感兼具 |
| 8.0-8.9 | 优秀 | 穿搭协调且有品味，细节处理得当 |
| 7.0-7.9 | 良好 | 基础合格，细节可进一步优化 |
| 6.0-6.9 | 中等偏上 | 整体尚可，有小幅提升空间 |
| 5.0-5.9 | 中等 | 整体普通，有明显提升空间 |
| <5.0 | 偏低 | 存在明显问题需改进 |

## 体型适配规则

| 体型 | 推荐 | 避免 |
|-----|------|------|
| 苹果型 | A字裙、高腰设计 | 紧身短款上衣 |
| 梨形 | A字裙、阔腿裤、深色下装 | 紧身浅色下装 |
| 沙漏型 | 收腰设计、X型剪裁 | 过于宽松的H型 |
| H型 | 腰带、高腰、层穿 | 直筒无腰线设计 |
| 倒三角型 | A字裙、下身外扩设计 | 垫肩、泡泡袖 |

## 肤色匹配规则

| 肤色基调 | 推荐颜色 | 避免颜色 |
|---------|---------|---------|
| 冷色调 | 蓝、紫、粉、藏青、银 | 橙、黄、驼色 |
| 暖色调 | 黄、橙、驼色、珊瑚、大地色 | 紫、粉蓝、薄荷绿 |
| 自然色调 | 白、黑、灰、藏青、酒红 | - |

## 场景适配规则

| 场景 | 核心要求 |
|-----|---------|
| 职场 | 正式感、整洁、专业，避免拖鞋、运动装 |
| 约会 | 精致感、适度女人味，避免过于随意 |
| 运动 | 舒适透气、功能性，避免正装皮鞋 |
| 聚会 | 设计感、亮点，避免过于朴素 |
| 日常 | 舒适实用，最宽容，隆重复古需注意 |

## 示例对话

### 用户输入
"帮我看看这套搭配怎么样：白色衬衫、藏青色西裤、黑色皮鞋，约会穿合适吗？"

### 处理流程
1. 提取性别、年龄、场景信息
2. 调用评价函数进行多维度分析
3. 返回评分、优缺点、改进建议

### 输出示例
```
评分: 7.8 - 良好，基础合格，细节可进一步优化

优势:
- 版型合身，整体干净利落
- 配色简洁有序，视觉效果清爽

问题:
- 职场风格偏浓，可能过于正式

建议:
- 约会场景建议选择更柔和的配色
- 可将深色西裤替换为卡其裤或深蓝牛仔
- 增加简约项链或耳饰提升精致度
```

## 注意事项

1. **信息完整度**: 提供的特征信息越完整，评价越准确
2. **主观性**: 时尚评价具有一定主观性，建议仅供参考
3. **文化差异**: 默认基于东亚审美习惯，其他地区需适当调整
4. **季节因素**: 评价会考虑当季流行趋势
