# 穿搭配色完全指南

## 一、肤色与色彩匹配

### 1.1 判断肤色基调

**冷色调肤色特征：**
- 手腕内侧静脉呈蓝紫色
- 银饰比金饰更衬肤色
- 日晒后皮肤变红而非变黑
- 适合的口红颜色：莓果色、玫瑰色

**暖色调肤色特征：**
- 手腕内侧静脉呈绿色
- 金饰比银饰更衬肤色
- 日晒后皮肤变黑
- 适合的口红颜色：珊瑚色、砖红色

### 1.2 肤色-色彩对照表

| 肤色 | 推荐色系 | 避免色系 | 提亮色 |
|-----|---------|---------|--------|
| 冷白皮 | 蓝、紫、粉、薄荷绿 | - | 黑色、藏青 |
| 冷黄皮 | 雾霾蓝、灰紫、玫瑰粉 | 荧光色 | 米白、浅灰 |
| 暖白皮 | 大地色、珊瑚、奶黄 | - | 黑色、深蓝 |
| 暖黄皮 | 驼色、砖红、焦糖 | 荧光粉 | 白色、浅蓝 |
| 中性皮 | 大多数颜色都适合 | 无明显禁忌 | 任意 |
| 深肤色 | 白色、金属色、亮色 | 与肤色接近的颜色 | 白色、亮黄 |

## 二、四季色彩理论

### 2.1 春之色彩（暖亮型）

**特征**：黄底调的暖色，带有明亮、活泼的质感

**推荐色系：**
- 正黄、橙黄、珊瑚
- 暖粉、桃红、杏色
- 浅绿、薄荷绿
- 米白、象牙白

**搭配建议**：
- 暖白+正红 = 活力感
- 浅绿+鹅黄 = 清新感
- 珊瑚+米白 = 温柔感

### 2.2 夏之色彩（冷柔型）

**特征**：蓝底调的冷色，带有柔和、淡雅的质感

**推荐色系：**
- 薰衣草紫、玫瑰粉
- 天蓝、湖蓝、薄荷蓝
- 雾霾蓝、灰紫
- 浅灰、浅米

**搭配建议**：
- 薰衣草+浅灰 = 优雅感
- 玫瑰粉+白色 = 少女感
- 天蓝+浅黄 = 清爽感

### 2.3 秋之色彩（暖柔型）

**特征**：黄底调的暖色，带有成熟、浓郁的质感

**推荐色系：**
- 驼色、焦糖、南瓜橙
- 砖红、酒红、陶土色
- 橄榄绿、深绿
- 姜黄、芥末黄

**搭配建议**：
- 驼色+酒红 = 高级感
- 焦糖+深绿 = 复古感
- 砖红+米白 = 温暖感

### 2.4 冬之色彩（冷深型）

**特征**：蓝底调的冷色，带有强烈、干净的质感

**推荐色系：**
- 正红、正蓝、正绿
- 宝蓝、玫红、翠绿
- 黑色、纯白
- 紫罗兰、深紫

**搭配建议**：
- 正红+黑色 = 气场感
- 宝蓝+白色 = 干练感
- 纯白+黑色 = 经典感

## 三、场合穿搭色彩

### 3.1 职场色彩

**正式商务：**
- 男士：深蓝、深灰、藏青、白色
- 女士：黑色、藏青、灰色、米白

**创意行业：**
- 可适当增加亮色点缀
- 莫兰迪色系安全又时尚

**禁忌色：**
- 过于艳丽的荧光色
- 大面积的花纹图案

### 3.2 约会色彩

**男生存活色：**
- 浅蓝、白色、浅灰
- 驼色、深绿
- 海军蓝（不沉闷）

**女生小心机：**
- 酒红（显白又有气质）
- 浅粉（温柔感）
- 黑色（神秘感）

### 3.3 聚会色彩

**晚宴/正式：**
- 黑色、藏青、酒红
- 金色、银色配饰点缀

**轻松聚会：**
- 可以尝试亮色或跳色
- 同色系搭配显高级

## 四、经典配色公式

### 4.1 安全牌搭配

```
黑白配 = 永不过时
米白+驼色 = 温柔知性
灰+蓝 = 冷静专业
白+蓝 = 清爽干净
```

### 4.2 进阶配色

```
同色系深浅 = 高级感（例：深蓝+浅蓝+藏青）
邻近色搭配 = 和谐统一（例：蓝+绿、紫+蓝）
互补色对比 = 时尚亮眼（例：橙+蓝、紫+黄）
```

### 4.3 进阶技巧

```
主色(60%) + 辅色(30%) + 点缀色(10%)
= 完美比例

中性色（黑白灰米） = 万能搭配色
```

## 五、体型-色彩修饰

### 5.1 显瘦配色

| 目标 | 推荐 | 避免 |
|-----|------|------|
| 上身显瘦 | 深色上衣 | 膨胀感浅色 |
| 下身显瘦 | 深色裤/裙 | 浅色紧身裤 |
| 整体显瘦 | 全身深色系 | 上下都浅色 |
| 显高 | 同色系搭配 | 颜色断层 |

### 5.2 显白技巧

| 肤色 | 显白色 | 显暗沉 |
|-----|--------|--------|
| 黄皮 | 白色、浅蓝、浅粉 | 土黄、荧光色 |
| 黑皮 | 白色、亮黄、正红 | 与肤色接近的暗色 |
| 白皮 | 几乎都适合 | - |

## 七、快速查询表

### 7.1 我不知道穿什么？

```
职场不知道 → 白色+藏青
约会不知道 → 黑色/酒红
日常不知道 → 黑白灰基础款
```

### 7.2 这个颜色怎么搭？

```
蓝色不知道配什么 → 白/灰/驼
粉色不知道配什么 → 白/灰/黑
绿色不知道配什么 → 白/米/棕
橙色不知道配什么 → 白/蓝/灰
紫色不知道配什么 → 白/灰/粉
```

### 7.3 肤色判断口诀

```
冷皮：静脉蓝紫、银饰衬肤
暖皮：静脉绿黄、金饰衬肤
分不清：大概率是暖皮
```
