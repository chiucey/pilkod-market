# 需求文档模板

本文档定义了标准需求文档的格式和内容要求。

## 文档结构

### 1. 修订记录

| **序号** | **修订内容/原因** | **修订时间** | **修订人** |
| --- | --- | --- | --- |
| 1 | 初版创建 | YYYY-MM-DD | @作者 |

### 2. 参考链接

| **参考内容** | **参考链接** |
| --- | --- |
| 原型 | [URL] |
| 相关需求 | [URL] |

### 3. 功能背景

描述功能的业务价值和存在的必要性。

### 4. 流程说明

描述用户操作的典型流程，必要时用流程图或步骤说明。

### 5. 业务规则

以表格形式详细定义每个功能操作的规则。

#### 业务规则类型

| 规则类型 | 描述 | 示例 |
| --- | --- | --- |
| 列表呈现 | 数据展示方式 | 按创建时间倒序显示 |
| 列表查询 | 查询条件 | 支持按名称模糊搜索 |
| 新增规则 | 创建数据时的校验 | 校验字段唯一性 |
| 修改规则 | 更新数据时的限制 | 某些字段不可修改 |
| 状态规则 | 状态变更条件 | 仅停用状态可删除 |
| 校验规则 | 数据校验逻辑 | 关联数据检查 |

#### 通用校验规则模板

```markdown
*   唯一性校验：[字段名]唯一（逻辑删除数据不参与校验），重复时提示"xxx已存在"
*   关联校验：停用前检查关联数据数量，不为0时提示"已被X个xxx引用"
*   状态依赖：[操作]仅在[状态]时可执行
*   二次确认：危险操作需用户二次确认
```

### 6. 信息项说明

定义界面上所有字段的属性。

| **信息项** | **必填** | **类型** | **长度/精度** | **业务规则** |
| --- | --- | --- | --- | --- |
| 字段名 | 是/否 | 文本/数值/枚举 | 字符数 | 校验规则 |

#### 字段类型规范

| 类型 | 说明 | 示例 |
| --- | --- | --- |
| 文本 | 普通文本输入 | 名称、描述 |
| 数值 | 数字类型 | 数量、金额 |
| 枚举 | 固定选项 | 状态（下拉选择） |
| 日期时间 | 时间选择 | 创建时间 |
| 自动生成 | 系统自动填充 | 编号、ID |

#### 自动生成字段

| 信息项 | 说明 |
| --- | --- |
| 创建人 | 自动记录当前操作人 |
| 创建时间 | 精确到秒 |
| 修改人 | 自动更新 |
| 修改时间 | 任何操作均更新 |
| 状态 | 默认值：启用 |

```markdown
# XX管理

# 修订记录

| --- | --- | --- | --- |

# 参考链接

| **参考内容** | **参考链接** |
| --- | --- |
| 原型 | [URL] |

# 功能背景

用于管理系统的XX功能。

# 流程说明

用户进入页面 → 查看列表 → 执行操作 → 系统响应

# 业务规则

| **功能操作** | **业务规则** |
| --- | --- |
| 列表呈现 | 按创建时间倒序显示 |
| 列表查询 | 支持按名称模糊搜索、状态下拉筛选 |
| 新增 | 校验字段唯一性，逻辑删除数据不参与校验 |
| 修改 | 仅特定状态下可修改特定字段 |
| 停用 | 校验是否被关联数据引用 |
| 删除 | 仅停用状态可删除，二次确认 |

# 信息项说明

| **信息项** | **必填** | **类型** | **长度/精度** | **业务规则** |
| --- | --- | --- | --- | --- |
| 名称 | 是 | 文本 | 20字符以内 | 校验唯一性 |
| 描述 | 否 | 文本 | 100字符以内 | - |
| 状态 | - | 枚举 | - | 启用/停用 |
| 引用数 | - | 数值 | - | 自动统计 |
| 创建人 | - | 自动 | - | 自动生成 |
| 创建时间 | - | 日期时间 | - | 自动生成 |
| 修改人 | - | 自动 | - | 自动生成 |
| 修改时间 | - | 日期时间 | - | 自动生成 |
```
