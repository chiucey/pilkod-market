# Renji - 人际关系题型专精技能

## Overview

本技能专注于公务员结构化面试中的**人际关系题型**,提供完整的调取热点、出题、答题、排版、输出word文档全流程。
当收到触发词：人际、人际关系，执行全流程。
### ⚠️ 人际关系题型核心特点

| 特征 | 人际关系题型 | 说明 |
|:---|:---|:---|
| **性质** | 工作场景中的人际冲突或协调问题 | 需要处理与领导、同事等的关系 |
| **处理对象** | 领导、同事 | 区分主次,优先处理工作关系 |
| **核心原则** | 主动性、原则性、适应性 | 既要坚持原则,又要灵活处理 |
| **典型场景** | 工作分歧、误解、投诉、求助 | 沟通协调、化解矛盾 |

### ⚠️ 人际关系题型典型场景

- 与领导意见不一致
- 同事之间工作配合问题
- 与其他部门之间的矛盾
- 新人适应期困惑
- 项目中的沟通问题
- 工作任务分配争议
- 轮岗/岗位调整适应

### 适用范围

- 基于热点出人际关系题型练习题
- 回答人际关系题型面试题
- 人际关系题型专项训练

## 人际关系题型答题框架

**三步法结构**:分析矛盾主体A的原因及解决对策 → 分析矛盾主体B的原因及解决对策 → 总结

### ⚠️ 主体命名规则

**【核心规则】"分析矛盾主体A"和"分析矛盾主体B"必须根据题目中的矛盾双方灵活命名,禁止固定使用"主体A/主体B"。**

**命名方式**:
- 如果矛盾方是"我"和"同事小王" → **分析自身** / **分析小王**
- 如果矛盾方是"我"和"领导" → **分析自身** / **分析领导**
- 如果矛盾方是"我"和"群众" → **分析自身** / **分析群众**
- 如果矛盾方是"我"和"亲友" → **分析自身** / **分析亲友**

**常见命名示例**:
| 题目情境 | 板块一命名 | 板块二命名 |
|:---|:---|:---|
| 同事拒绝配合 | 分析自身 | 分析同事 |
| 领导批评不满 | 分析自身 | 分析领导 |
| 群众投诉不满 | 分析自身 | 分析群众 |
| 亲友托人说情 | 分析自身 | 分析亲友 |
| 多人矛盾 | 分析自身 | 分析对方 |

### 框架详解

1. **板块一·[灵活命名]的原因及解决对策**:从第一矛盾方的角度分析问题原因并提出解决对策。原因可假设且多个。
2. **板块二·[灵活命名]的原因及解决对策**:从第二矛盾方的角度分析问题原因并提出解决对策。原因可假设且多个。
3. **板块三·总结**:总结经验,避免类似问题再次发生(**总结标题加粗**,**弹药库内容加下划线**)

## 出题规范

### 题目要求
- 字数:80-150字
- 结尾:用"你怎么办?"或"你如何处理?"
- 特点:设置人际矛盾情境,涉及多方利益关系

### 题目结构
```
题目:[人际矛盾描述]你怎么办?
```

### 文档结构
- 标题:【人际关系题型】+ 主题
- 题目:题目描述(80-150字)
- 关键词:逗号分隔,不用【】
- 核心事件:高度概括题目中的核心人际矛盾(1句话)
- 联想要点:根据题目情境设置主体维度
- 答题正文

### 核心事件格式
**格式**:一句话概括题目中的核心人际矛盾
**示例**:
> 核心事件:新同事小王工作能力突出但骄傲自负,与同事关系紧张

### 联想要点格式

**【核心规则】联想要点分3行,前两行根据题目情境灵活编写,第3行总结固定不变。**

**3行结构**:
1. **分析[灵活命名A]**:分析第一矛盾方的原因+提出解决对策(灵活);
2. **分析[灵活命名B]**:分析第二矛盾方的原因+提出解决对策(灵活)
3. **总结**:(固定弹药库)

**第3行·总结(固定·禁止修改)**:
```
背诵内容
```

**格式**:每行`标题词(加粗):内容(普通)`

**示例**(以同事拒绝配合为例):
```

分析自身:工作繁忙:理解关心、合理安排;态度消极:沟通疏导、激发热情
分析同事:同事不满:解释说明、安抚情绪;担心效果:营造氛围、增强荣誉
总结:今后我将以此为戒...(固定弹药库)

```

**格式要点**:
1. 分三行:**分析[灵活命名A]、分析[灵活命名B]、总结**
2. **标题词(分析自身:、分析[对方]:、总结:)必须加粗**
3. 标题词后的内容**普通字体,不加粗**
4. 前两行**根据题目意思灵活更改主体名称**
5. 第三行**固定**:`总结:今后我将以此为戒...`
6. 每行先写主体维度,主体后用冒号
7. 同一主体的多个要点用顿号或逗号分隔
8. 不同主体之间用分号分隔

## 人际关系核心原则

### 三大原则

| 原则 | 说明 | 应用场景 |
|:---|:---|:---|
| **主动性** | 积极主动沟通,不消极等待 | 遇到问题主动解决,主动汇报 |
| **原则性** | 坚持工作底线,不违背原则 | 违法违纪要坚持原则,但方式要灵活 |
| **适应性** | 适应工作环境,融入团队 | 新人适应、岗位调整等情况 |

### 四种关系处理要点

| 关系 | 核心要点 | 注意事项 |
|:---|:---|:---|
| **与领导** | 尊重服从、请示汇报 | 不越权、不擅自决定 |
| **与同事** | 团结协作、换位思考 | 不推诿、不斤斤计较 |

2. ☐ 无【、无】(关键词除外)
3. ☐ 粗体只用于弹药库句式中的原因要点,解释内容用普通黑色
4. ☐ 无"最主要原因是...造成的"病句
5. ☐ 无"我想,我想"重复使用
6. ☐ 无板块标注【板块一】等
7. ☐ 无禁用词
8. ☐ 联想要点格式:分析[灵活命名A]的原因和解决措施;分析[灵活命名B]的原因和解决措施;总结(固定弹药库)
9. ☐ 单点扩展:原因要点(粗体)→ 句号 → 解决措施(普通),不分行。
10. ☐ **开场白:普通字体加下划线**
11. ☐ **弹药库句式(过渡句):下划线** | **总结标题:加粗** | **总结内容:下划线**
12. ☐ 输出word到：D:\2026\2026新增\2026新模拟题\
