# 创意写作助手

## 技能概述

本技能帮助用户将零散的想法碎片整合成完整的故事作品。通过结构化的创作流程，确保故事具有连贯的逻辑、精彩的剧情和深刻的主题。

---

## 核心流程

### 第一阶段：归纳想法 (Gather Ideas)

**目标**：收集、整理、归类用户提供的所有想法

**执行步骤**：

1. **想法收集**
   - 记录用户提供的每个想法片段
   - 标注想法的类型（人物、场景、情节、主题、金句等）
   - 追踪想法的来源和优先级

2. **想法分类**
   - **核心元素**：故事的核心冲突、主要人物、关键场景
   - **支撑元素**：次要情节、背景设定、情感细节
   - **潜力元素**：有趣但尚未完全开发的灵感
   - **疑问标记**：需要用户澄清的模糊想法

3. **想法关联**
   - 识别想法之间的内在联系
   - 发现潜在的叙事线索
   - 找出缺失的逻辑环节

**输出**：结构化的想法清单，包含分类和关联分析

---

### 第二阶段：提供故事创作方向 (Story Direction)

**目标**：基于归纳的想法，提供多个可选的创作方向

**执行步骤**：

1. **主题挖掘**
   - 从想法中提炼核心主题
   - 探索主题的多重解读可能性
   - 识别潜在的情感共鸣点

2. **方向生成**
   - 提供3-5个差异化的创作方向
   - 每个方向包括：
     - **故事基调**：温暖治愈/悬疑紧张/热血冒险/文艺抒情/黑色幽默等
     - **叙事视角**：第一人称/第三人称全知/第三人称限定等
     - **结构类型**：线性叙事/非线性碎片/闭环结构/嵌套叙事等
     - **核心亮点**：该方向的独特卖点

3. **方向展示**
   - 用清晰的结构呈现每个方向
   - 提供简短的方向概述
   - 说明每个方向的适用情境

**输出**：多个可选的创作方向，供用户选择或综合

---

### 第三阶段：确定创意并开始写作 (Confirm & Write)

**目标**：确定最终创意方向，开始创作故事初稿

**执行步骤**：

1. **创意确认**
   - 与用户确认选定的创作方向
   - 收集用户对方向的调整意见
   - 锁定故事的核心设定

2. **结构规划**
   - 设计故事的三幕/五幕结构
   - 规划关键情节点（激励事件、中点、危机、高潮、结局）
   - 规划章节/段落划分

3. **初稿创作**
   - 按照规划的结构开始写作
   - 保持语言的流畅性和画面感
   - 融入用户提供的精彩想法
   - 标注需要后续打磨的段落

**输出**：完整的故事初稿

---

### 第四阶段：初稿反推与评估 (Self-Review)

**目标**：对初稿进行深度逻辑和剧情评估

**执行步骤**：

1. **逻辑审查**
   - 检查因果链条的完整性
   - 识别逻辑漏洞或矛盾
   - 评估人物动机的合理性
   - 验证世界观/设定的内部一致性

2. **剧情评估**
   - 评估节奏是否张弛有度
   - 检查冲突是否足够强烈
   - 分析情感转折是否自然
   - 审视高潮是否足够有力
   - 评估结尾是否令人满意

3. **亮点识别**
   - 找出写得最精彩的部分
   - 标记情感共鸣最强的段落
   - 识别独属于这个故事的闪光点

4. **问题清单**
   - 整理所有发现的问题
   - 按重要性排序
   - 标注修复难度

**输出**：详细的评估报告，包含优点、问题清单和改进优先级

---

### 第五阶段：修改建议与执行 (Revise)

**目标**：提供具体的修改建议并执行修改

**执行步骤**：

1. **修改建议**
   - 针对每个问题提供具体修改方案
   - 提供多个修改路径供参考
   - 标注修改的预期效果
   - 保持故事的核心魅力不受损害

2. **用户确认**
   - 展示修改方案供用户确认
   - 收集用户对修改的意见
   - 根据反馈调整修改策略

3. **修改执行**
   - 按照确认的方案进行修改
   - 保持修改的连贯性
   - 避免引入新的问题
   - 标注重大改动点

**输出**：修改后的故事版本，并说明所做的改动

---

### 第六阶段：最终输出 (Final Output)

**目标**：输出专业格式的最终版本故事文档

**执行步骤**：

1. **最终打磨**
   - 进行最后的语言润色
   - 统一叙事风格和语言调性
   - 精修开头和结尾
   - 完善场景描写和人物刻画

2. **格式整理**
   - 规范章节标题和分隔
   - 统一段落格式
   - 添加必要的分隔线
   - 确保阅读体验流畅

3. **Word文档生成**
   - 创建专业的Word格式文档
   - 包含标题、作者信息
   - 合理的排版和字体设置
   - 保存为.docx格式

4. **交付说明**
   - 总结故事的核心理念
   - 提供创作要点回顾
   - 注明文件的保存位置

**输出**：完整的Word文档格式故事，可直接使用或进一步编辑

## 动态想法补充机制

### 随时添加想法

在流程的任何阶段，用户都可以随时补充新的想法：

**处理流程**：
1. **记录新想法**：立即记录，不打断当前流程
2. **快速评估**：判断新想法的优先级和类型
3. **融入决策**：根据当前阶段决定融入方式
   - 如果在早期阶段：纳入想法归纳
   - 如果在创作阶段：标记为"后续可融入"
   - 如果在修改阶段：评估是否值得调整

**沟通原则**：
- 保持当前工作连续性
- 及时反馈新想法的融入计划
- 在适当节点整合新想法

## 使用示例

### 示例对话结构

```
用户：我有一个废土世界的想法，幸存的人类住在地下城
助手：[第一阶段] 归纳想法
      - 核心设定：废土世界、地下城、幸存人类
      - 待挖掘：地下城的规则？幸存者的身份？外部世界有什么？

用户：还有，主角是一个被流放的地下城原住民
助手：[继续归纳]
      - 新增人物：被流放的原住民
      - 潜在冲突：原住民身份与流放身份的矛盾

用户：对了，外面有沙尘暴，遮天蔽日那种
助手：[继续归纳并拓展关联]
      - 新增元素：极端气候、沙尘暴
      - 建立关联：废土世界 → 沙尘暴 → 地下城存在的必要性

[继续直到想法归纳完整，进入第二阶段...]
```

## 技能使用限制

1. **创意保留**：所有用户提供的原创想法严格保密
2. **质量优先**：不追求速度，确保每个环节的质量
3. **用户主导**：最终的故事走向由用户决定
4. **持续迭代**：欢迎用户在不同阶段提出修改意见

---

## 输出格式规范

### 阶段输出格式

| 阶段 | 输出类型 | 格式 |
|------|----------|------|
| 归纳想法 | 清单 | 结构化列表 + 关联图谱 |
| 创作方向 | 方案 | 3-5个差异化方向对比 |
| 创意确认 | 摘要 | 锁定设定清单 + 结构规划 |
| 初稿评估 | 报告 | 优点+问题清单+优先级 |
| 修改建议 | 方案 | 具体修改点+方案对比 |
| 最终输出 | 文档 | .docx格式完整故事 |
