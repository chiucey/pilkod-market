# 知识原子化器

将输入文本拆解为最小独立知识点的技能。

## 拆解规则

1. **语义完整性**：每个知识点必须语义完整，可以单独理解
2. **单一信息**：每个知识点只表达一个核心信息（定义/定理/结论/公式/说明）
3. **禁止逻辑混杂**：不允许多个逻辑混在一个点中
4. **强制拆分**：如果一句话包含多个逻辑，必须拆分
5. **保留原意**：保留原始含义，不要扩写或解释

## 公式处理规则

1. 所有数学公式必须单独提取到 `formula` 字段
2. 如果该知识点包含公式，则放入对应字段
3. 一个知识点可以有多个公式

## 编号规则

1. 使用层级编号：X.Y（例如 1.1, 1.2, 2.1）
2. 按输入顺序递增
3. 编号必须唯一

## 执行流程

### 步骤1：接收输入文本
接收用户提供的教材、PPT或文本内容。

### 步骤2：识别句子边界
将文本按句子拆分成独立单元。

### 步骤3：识别公式
扫描每个句子，提取所有数学公式到formula数组。

### 步骤4：逻辑拆分
检查每个句子是否包含多个逻辑：
- 转折关系（但是、然而、不过）
- 因果关系（因此、所以、因为）
- 并列关系（同时、并且、此外）
- 条件关系（如果...则...）
- 发现多个逻辑时，必须拆分

### 步骤5：知识点编号
按顺序为每个知识点分配层级编号（X.Y格式）。

### 步骤6：输出JSON
仅输出JSON格式结果，不要添加任何解释。

## 输出格式

```json
{
  "points": [
    {
      "point_id": "1.1",
      "text": "知识点文本内容",
      "formula": ["公式1", "公式2"]
    },
    {
      "point_id": "1.2",
      "text": "知识点文本内容",
      "formula": []
    }
  ]
}
```

## 约束

- 只输出JSON，不要解释
- 不要遗漏任何重要信息
- 不要合并知识点
- 公式使用LaTeX格式（如有）

## 示例

**输入**：
勾股定理是指直角三角形的两条直角边的平方和等于斜边的平方。其数学表达式为 a² + b² = c²。这个定理在几何学中有广泛应用。

**输出**：
```json
{
  "points": [
    {
      "point_id": "1.1",
      "text": "勾股定理是指直角三角形的两条直角边的平方和等于斜边的平方。",
      "formula": ["a^2 + b^2 = c^2"]
    },
    {
      "point_id": "1.2",
      "text": "勾股定理在几何学中有广泛应用。",
      "formula": []
    }
  ]
}
```
