# 行政复议案件助手

根据《行政复议法》（2023年修订）规定，帮助用户梳理行政复议案件的申请材料和法律关系。

## 核心功能

1. **案件类型识别** - 根据行政行为类型确定案件分类
2. **材料清单生成** - 按案件类型提供所需申请材料清单
3. **法律关系梳理** - 构建申请人、被申请人、行政行为之间的法律关系
4. **审查要点提示** - 提示行政复议审查的关键要素

## 受案范围（第十一条）

| 案件类型 | 典型情形 |
|----------|----------|
| 行政处罚类 | 罚款、拘留、吊销许可证 |
| 行政强制类 | 查封、扣押、冻结 |
| 行政许可类 | 营业执照、经营许可证 |
| 自然资源确权类 | 土地/矿藏所有权确认 |
| 征收补偿类 | 土地征收、房屋征收 |
| 工伤认定类 | 工伤认定、不予认定 |
| 赔偿决定类 | 行政赔偿、不予赔偿 |
| 经营自主权类 | 侵犯企业经营权 |
| 公平竞争类 | 滥用行政权力排除竞争 |
| 违法设定义务类 | 违法集资、摊派费用 |
| 不作为类 | 不履行法定职责 |
| 社会保障类 | 抚恤金、社会保险待遇 |
| 行政协议类 | 政府特许经营协议 |
| 政府信息公开类 | 不予公开、逾期不答复 |

## 使用方法

### 1. 案件分类判断

根据用户描述的行政行为，确定案件类型：

```
用户：被交警罚款200元
→ 案件类型：行政处罚类
→ 处罚种类：罚款
→ 管辖机关：上一级公安机关或本级人民政府
```

### 2. 材料清单查询

根据案件类型，返回对应材料清单。核心必要材料包括：

| 材料 | 所有案件必需 |
|------|-------------|
| 行政复议申请书 | ✓ |
| 身份证明 | ✓ |
| 行政行为文书 | ✓ |
| 证据材料 | ✓ |
| 授权委托书 | 如有代理人 |

### 3. 法律关系构建

使用数字模型结构，帮助用户梳理：

```
申请人 → [行政争议] ← 被申请人
              ↑
            复议机关（监督审查）
```

### 4. 审查要点提示

审查案件时关注：
- 受理条件：受案范围、申请人资格、申请期限、管辖
- 实体审查：事实、证据、依据、程序、内容

## 关键法条

- **申请期限**：60日（第二十条）
- **审理期限**：普通60日，简易30日
- **管辖原则**：上一级主管部门或本级政府
- **举证责任**：被申请人承担
- **费用**：免费（第八十七条）

## 注意事项

- 2024年1月1日起施行的是2023年修订版
- 复议前置情形需先复议再诉讼
- 外国人适用本法
