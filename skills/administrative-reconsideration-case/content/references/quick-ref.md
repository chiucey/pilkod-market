# 行政复议案件分类材料速查

## 十四类案件材料清单

| 案件类型 | 核心材料 |
|----------|----------|
| **行政处罚类** | 处罚决定书、听证材料、陈述申辩材料、违法证据 |
| **行政强制类** | 强制措施决定书、查封扣押清单、执行凭证 |
| **行政许可类** | 许可申请材料、不予许可决定书、符合条件证据 |
| **自然资源确权类** | 确权决定书、权属证据、权利来源证明 |
| **征收补偿类** | 征收决定、补偿方案、权属证明、评估报告 |
| **工伤认定类** | 认定决定书、劳动关系证明、事故证明、诊疗材料 |
| **赔偿决定类** | 赔偿决定书、损失证明、赔偿计算依据 |
| **经营自主权类** | 侵权行为证据、经营损失证明、干预行为证明 |
| **公平竞争类** | 竞争受影响证据、滥用职权证据、市场影响证明 |
| **违法设定义务类** | 违法收费/集资证据、收费依据、缴费凭证 |
| **不作为类** | 履职申请记录、不予答复证据、法定职责依据 |
| **社会保障类** | 不予给付决定书、资格证明、待遇计算依据 |
| **行政协议类** | 协议文本、履约证据、违约证据、损失证明 |
| **政府信息公开类** | 申请记录、答复书、信息描述 |

## 通用材料（所有案件）

- 行政复议申请书（2份）
- 身份证明（身份证/营业执照）
- 行政行为文书原件或复印件
- 授权委托书（如有代理人）

## 管辖速查

| 被申请人类型 | 管辖机关 |
|--------------|----------|
| 市政府工作部门 | 市人民政府 |
| 区政府工作部门 | 区人民政府 |
| 下一级政府 | 本级政府 |
| 公安派出所 | 公安分局或区政府 |
| 省垂管部门 | 省级主管部门 |

## 期限速记

- 申请期限：60日
- 受理审查：5日
- 被申请人答复：10日
- 普通审理：60日（可+30日）
- 简易审理：30日
