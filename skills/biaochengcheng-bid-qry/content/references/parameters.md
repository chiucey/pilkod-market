# 工程招投标标讯查询 - 参数参考

## MCP 工具信息

**工具名称**: `mcp_bid_query`

## 参数详解

### keyWord (必填)
- **类型**: 数组 `string[]`
- **说明**: 搜索关键词
- **示例**: `["通讯工程"]`, `["光伏", "太阳能"]`

### searchScope (可选)
- **类型**: 数组 `string[]`
- **默认值**: `["1", "2"]`
- **选项**:
  - `"1"` - 标题搜索
  - `"2"` - 内容搜索
  - `"4"` - 招标人搜索
- **示例**: `["1", "2"]` (搜索标题+内容), `["1", "2", "4"]` (搜索标题+内容+招标人)

### searchMode (可选)
- **类型**: 字符串
- **选项**:
  - `"1"` - 精确匹配
  - `"2"` - 分词匹配（模糊搜索）
- **示例**: `"2"` (推荐用于大多数场景)

### startTime (可选)
- **类型**: 字符串
- **格式**: `yyyy-mm-dd hh:mm:ss`
- **说明**: 查询开始时间，不传默认近3个月
- **示例**: `"2026-01-01 00:00:00"`

### endTime (可选)
- **类型**: 字符串
- **格式**: `yyyy-mm-dd hh:mm:ss`
- **说明**: 查询结束时间，不传默认当前时间
- **示例**: `"2026-04-29 23:59:59"`

### minAmount / maxAmount (可选)
- **类型**: 数字
- **说明**: 金额筛选范围，单位：元
- **示例**: `minAmount: 500000`, `maxAmount: 5000000`

### selectAddr (可选)
- **类型**: 数组 `string[]`
- **说明**: 省份筛选，使用全称
- **省份全称列表**:
  - 北京市、天津市、上海市、重庆市
  - 河北省、山西省、辽宁省、吉林省、黑龙江省
  - 江苏省、浙江省、安徽省、福建省、江西省、山东省
  - 河南省、湖北省、湖南省、广东省、海南省四川省、贵州省、云南省、陕西省、甘肃省、青海省、台湾省
  - 内蒙古自治区、广西壮族自治区、西藏自治区、宁夏回族自治区、新疆维吾尔自治区
  - 香港特别行政区、澳门特别行政区
- **简称转换**:
  - "湘" → "湖南省"
  - "京" → "北京市"
  - "沪" → "上海市"
  - "粤" → "广东省"
  - 等等...

### city (可选)
- **类型**: 数组 `string[]`
- **说明**: 城市筛选，使用全称
- **示例**: `["长沙市", "岳阳市"]`

### pageSize (可选)
- **类型**: 数字
- **默认值**: `10`
- **最大值**: `50`
- **说明**: 每页返回条数

### pageNum (可选)
- **类型**: 数字
- **默认值**: `1`
- **说明**: 页码，从1开始

## 查询示例

### 示例1: 查找湖南省光伏项目招标
```json
{
  "keyWord": ["光伏"],
  "selectAddr": ["湖南省"],
  "startTime": "2026-01-01 00:00:00",
  "endTime": "2026-04-29 23:59:59",
  "minAmount": 100000,
  "maxAmount": 50000000
}
```

### 示例2: 查找数据中心建设招标公告
```json
{
  "keyWord": ["数据中心", "建设"],
  "searchScope": ["1", "2"],
  "searchMode": "2",
  "pageSize": 20,
  "pageNum": 1
}
```

### 示例3: 查找某招标人的历史招标
```json
{
  "keyWord": ["中国移动"],
  "searchScope": ["1", "2", "4"],
  "startTime": "2025-01-01 00:00:00",
  "pageSize": 50
}
```

## 返回字段说明

每条招标记录包含:

| 字段 | 说明 |
|------|------|
| title | 项目名称 |
| tenderUnit | 招标单位 |
| amount | 金额（元） |
| publishTime | 发布时间 |
| area | 地区 |
| url | 详情链接 |
