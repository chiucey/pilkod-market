# 你只需要给这三样（其余交给 skill）

> ⚠️ **本文件是唯一正文**（V3.7 起）。
> 根目录的 [`CONTRACT.md`](../CONTRACT.md) 只是**指针版**，指向这里。
> 背景：这两份原本"逐字节相同"，后来各自演变 —— 根目录版反而更长、
> 且多出一段 `record fix` 用法，**主次颠倒**（自称"指针"却比正文全）。
> 现在统一为：正文只此一份，改这里就行。

对使用者（不想管 YAML/命令的人）——每面完一场，只回填 3 样就够：
skill 会接手"建卡归纳 + 出求职总报 + 备战/复盘"。

## 什么时候回填（重要）
- **有实际结果就随时填**（过没过 / 最终拿没拿 / 为什么没推进）—— 不用等任何截止日，越早越准。
- `d+7` 只是**兜底**：系统会在"你还没回填实际结果的第 7 天"提醒你一次，防止你忘。
  它**不是**让你等到第 7 天。
- 若结果本身要两周后才出，把卡的 `confirm_by` 顺延即可；别让它长期停在 unknown 误导统计。

## 三把"钥匙"
| 你给什么 | 对应字段 | 示例 |
|---|---|---|
| ① 这轮过没过 | `result.outcome` | pass / fail |
| ② 没推进/没 offer 的原因 | `result.why_ended` | 横向对比 / 审批不通过 / 简历背调 / 卡薪资 / base / 外包无转正 |
| ③ 最终有没有拿到 | `result.offer` | got(拿到) / no(没拿到) / ongoing(还在走) |

> 只要 ① = 通过 且 ③ = no，它就属于"业务过了却非能力被卡"，
> 会被归到【总报·业务全过却 offer=no】提醒你 —— 这是很多人真正的坑，
> 别把它当普通"挂了"。

## 怎么填（一条命令补齐）

```bash
python tools/main.py record fix I007 --offer no
python tools/main.py record fix 某张卡 --why-ended "横向对比"

# 看哪些卡还缺
python tools/main.py remind
```

> `remind` 会按 `outcome` 判断该要哪一项（过了要 `offer`，挂了要 `why_ended`），
> 并**直接打印可复制的命令**。

## 填空模板（说你记得的措辞就行）
```
① 这轮：过/没过
② 如果没推进，为什么：____（横向/审批/薪资/背调/base/其他）
③ 最终拿到offer了吗：拿了 / 没拿 / 还在走
```

## 你可以顺便多给（更准，不强求）
- 那些面试官具体问了什么 + 你现场怎么答的（越多越能自动建卡与出可复用答案）
- 公司/岗位名没给就补一句；给过就跳过。

## 首次
如果一场都还没有，会先给你一张"空卡"示范；你按上面回填一场，就进入正轨。
数据 <15 场时报告看趋势即可，别迷信小样本百分比。
