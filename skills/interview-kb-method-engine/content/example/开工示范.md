# 冷启动示范（开工 Demo）

> 目标：哪怕你库里暂时没有/只有 1-2 张卡，也能照这个走通"记一场 → 回填 3 真值 → 跑 report 看到结果"。它教你怎么用,并把预期输出讲清楚。

## 先做一次最简动作（1 分钟，让你体会它在干嘛）
1. 确认装好：`cd tools && python -c "import yaml" ` 不报错即可。
2. 第一次建场（不必走命令行,也可以直接在会话语境说"帮我记一场"）：
   - 最快方式：**把一段人话丢给 AI**，例如：
     > “今天 A面包店 面内容运营一面，问了我自我介绍、怎么做美食垂类0到1、还问了商业化怎么算，我答得一般，感觉薪资谈不下来，应该没过；等最终通知。”
3. AI 会（如果你在会话语境，按 `SKILL.md` “做法0 / digest_guide”）：
   - 拆出 questions（自我介绍／0到1怎么拆／商业化怎么算）并各配 theme+你的答；
   - 存成 `cards/_inbox/P….yaml`（pending，不占正式号）；
   - 问你补 3 真值：outcome / why_ended / offer。
4. 例如你说最终没进、理由是“营收不懂+卡薪资”，那么填：
   `outcome: fail，why_ended: 卡薪资/商业化说法不清，offer: no`。

## 然后：`python tools/main.py report`
- 它会读你这张（加后续场）算出：
  - 轮次通过率、正编/外包…… (样本少时它写"样本少·仅参考"，不会骗你)
  - “A面包店 / 家烘焙品”这类赛道出现在各表里；
  - 反复挂根源若配得上会标“商业化”→并给一段曾 pass 的答法（若还没有就空）。
- 只有当你持续往 3 真值里回填 actual，这张才会进最终统计；否则一律标 unknown 且（到 d+7）提醒。

## 三个更省时入口（选你顺手）
- **口述一句**：跟我说 "记一下今天这场"，把问题/答/结果讲出来 → 我拆全题、回填 3 True → report。
- **丢全文**：把完整转写文本/PDF给我（`digest_guide.md`），我自动拆所有题+强弱，仍把 3 真值留你判。
- **手动 CLI**（你若想敲）：`record new` + 一句句 `record ask`；或直接 `merge formalize` 让 `_inbox` 转正。

## 建议（用一次它就懂）
先只回填 1 场已知结果 + 跑 `report`（看那家/那条赛道那一行有数字）。→ 你立刻看懂它在算什么，再决定要多建几张。

## 若空白 clone(别人): 第一次
- 也是 1 场就够：建 1 场 → 回填 3 真值 → `report`。
- 别指望 0 场出结论，本来就不该；设 mini-goal **记 5 场已知结果**，之后趋势/赛道才有点意义。

## 成功后你会看到（以一行举例）
- §5 该投/慎投里那家会带 `(样本 1 · 样本少·仅参考)`；
- §3 反复挂根源出现"商业化"，若你有曾 pass 卡含相关答法会附话术；
- 若你标了 `confirm_by` 到期没回填，报告首页红字提醒。

→ 这就成功跑通。之后每场照这个 loop：记录(可丢全文) → 回填3真值 → 偶尔 report。
