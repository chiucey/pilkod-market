本目录为【虚构演示】示例，帮助理解一张卡该长什么样、以及引擎能从中推导出什么，
**不代表任何真人战绩**。

- `card_example.yaml`：一张示例卡。注意这些字段：
  `interview.nature`(正编) / `result.round_result` + `offer` + `why_ended` + `process` /
  `questions` + `score` / `reflection`。
- 把这张卡放进 `cards/` 后：
  - `report` 会把它按**正编**、轮次=该轮（一面）计入；
  - 赛道维度会把「垂类 / 内容运营」纳入统计；
  - 若这场后来二面也归档（例如再建一张 `I002` 二面），两卡靠**同一个 `process`**
    关联，报告会算成**同一条流程**。
- 想只看自己的数据、不要这份演示时：**可以直接删掉本目录**，
  它只是字段示例，引擎不依赖它（删了不影响任何功能）。

> ⚠️ **如果你是 AI agent**：**不要主动删除本目录** ——
> 分发包需要它演示字段结构。只有**用户明确要求**时才删。
>
> 命令口径：现在统一用 `report`；旧名 `report2` / `diagnosis` 仍可用，但已是别名。
> 完整命令见 `tools/ENGINE.md`。
