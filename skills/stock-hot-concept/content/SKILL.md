# 股票市场热点概念捕捉与龙头板块分析

## 技能概述

本技能用于实时捕捉A股市场热点概念，识别概念龙头板块，分析概念轮动规律，并为用户提供概念投资机会参考。

## 核心功能

### 1. 热点概念识别
- **实时数据采集**：通过东方财富、同花顺等权威金融数据源获取当日概念涨跌数据
- **热度评分算法**：综合考虑涨幅、成交量、资金流入、涨停家数等多维度指标
- **概念分类**：区分主线热点、轮动热点、一日游热点等类型

### 2. 龙头板块分析
- **龙头股识别**：根据市值、流通盘、涨停时间、封单金额等指标筛选龙头
- **梯队划分**：区分龙头股、跟风股、补涨股
- **联动分析**：分析同概念个股联动强度

### 3. 概念轮动追踪
- **轮动节奏**：记录热点概念的启动、高潮、退潮周期
- **资金流向**：追踪主力资金在不同概念间的流动
- **预期管理**：提示概念可能的延续或切换

## 分析维度

### 数据采集维度
| 指标 | 说明 | 数据来源 |
|------|------|----------|
| 概念涨幅 | 当日概念整体涨跌幅 | 东方财富/同花顺 |
| 成交额 | 概念板块总成交金额 | 交易所数据 |
| 主力净流入 | 大单资金净流入 | 资金流数据 |
| 涨停家数 | 概念内涨停股票数量 | 实时行情 |
| 龙头股表现 | 龙头个股涨跌情况 | 个股数据 |

### 龙头股筛选标准
1. **连板情况**：是否有连续涨停
2. **市值适中**：50-500亿为佳（便于接力）
3. **流通性**：日成交额需达到一定门槛
4. **题材纯正**：主业与概念高度契合
5. **筹码结构**：股东人数变化、机构持仓

## 注意事项

1. **时效性**：热点概念分析具有高度时效性，报告中需标注数据时间
2. **风险提示**：所有分析仅供参考，不构成投资建议
3. **数据验证**：涉及投资决策时，需交叉验证多个数据源
4. **仓位管理**：热点概念波动较大，需注意仓位控制

## 数据更新频率

- **实时数据**：交易时间内每5分钟更新涨跌排名
- **日终数据**：收盘后30分钟内生成完整日报
- **周度总结**：每周最后一个交易日生成周度轮动总结
