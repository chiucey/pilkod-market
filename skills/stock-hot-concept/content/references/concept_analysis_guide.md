# 股票热点概念分析参考指南

## 概念热度评分算法

### 多维度评分体系

| 维度 | 权重 | 说明 |
|------|------|------|
| 涨幅得分 | 25% | 概念整体涨跌幅得分 |
| 成交额得分 | 20% | 成交金额活跃度 |
| 资金流入得分 | 20% | 主力资金净流入 |
| 涨停家数得分 | 20% | 涨停个股数量 |
| 龙头强度得分 | 15% | 龙头股表现 |

### 计算公式

```
热度得分 = 涨幅标准化分 × 0.25
         + 成交额标准化分 × 0.20
         + 资金流入标准化分 × 0.20
         + 涨停家数标准化分 × 0.20
         + 龙头强度分 × 0.15
```

## 龙头股识别标准

### 一、龙头股特征

1. **先于板块启动**：在概念爆发时率先涨停
2. **封板质量高**：封单金额大、撤单少
3. **连板能力强**：可连续多日涨停
4. **市值适中**：便于市场合力
5. **题材纯正**：主业与概念高度契合

### 二、龙头股分类

| 类型 | 特征 | 风险等级 |
|------|------|----------|
| 绝对龙头 | 全市场最高连板数 | 中 |
| 板块龙头 | 同概念内最高连板 | 中低 |
| 情绪龙头 | 带动整个市场情绪 | 高 |
| 补涨龙头 | 板块高潮时启动 | 高 |

## 概念轮动规律

### 轮动周期

```
启动期(1-2天) → 发酵期(2-3天) → 高潮期(1-2天) → 退潮期(1-3天)
```

### 轮动信号

1. **资金信号**：大单资金开始流出
2. **情绪信号**：市场情绪开始扩散
3. **时间信号**：概念持续时间接近极限
4. **替代信号**：新概念开始出现

## 风险控制要点

1. **仓位控制**：热点概念单次操作不超过总仓位20%
2. **止损纪律**：跌破5日线或亏损8%坚决止损
3. **分散投资**：单个概念持仓不超过3只
4. **时间控制**：不做尾盘拉升个股
5. **消息验证**：重大消息需多源验证
