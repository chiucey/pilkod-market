# 变更签证索赔标准流程

---

## 一、变更（Change）处理流程

### Step 1：变更识别与评估
- 图纸会审/施工过程中发现与合同图纸不符
- 设计院或业主主动发出变更指令（设计变更通知单）
- 评估：是否涉及费用/工期影响

### Step 2：变更申报（成本岗位）
```
时限：收到变更指令后 7~14 天内完成测算
输出：《变更费用估算表》
内容：变更内容 → 工程量计算 → 综合单价确定 → 合价汇总
```

### Step 3：报价与审批
- 报送监理/业主审核
- 注意不平衡报价策略（哪些单价可调高/调低）
- 留存：变更指令原件、测算底稿、现场照片

### Step 4：变更执行与跟踪
- 同步更新台账（变更台账 Excel）
- 跟进审批进度，避免久拖不批

### Step 5：变更结算
- 竣工结算时汇总所有变更
- 核对变更指令编号与实际施工是否一致

## 二、签证（VO / Site Instruction）处理流程

### 签证分类
| 类型 | 触发来源 | 典型场景 |
|------|---------|---------|
| 零星用工 | 监理/业主指令 | 额外抽水、清理 |
| 隐蔽验收 | 图纸与实际不符 | 验槽、验筋 |
| 材料二次转运 | 业主原因 | 甲供材延迟 |
| 抢工费用 | 业主赶工指令 | 春节/雨季赶工 |

### 签证时效要求
- **行业惯例**：发生当日起 **7天内** 完成签认
- 逾期签认：法律风险大增，须在合同中约定合理期限
- 建议：项目部建立"签证双周清"机制

### 签证单要素（缺一不可）
1. 签证编号（项目自编号）
2. 签证日期（精确到日）
3. 签证原因（具体描述）
4. 工程量计算式（列式，不要只写结果）
5. 费用计算（注明单价/合价依据）
6. 附件：现场照片/收方单/会议纪要
7. 签字栏：施工单位/监理/业主三方签章

## 三、索赔（Claim）标准流程

### 索赔成立三要素
```
① 事件非己方责任
② 造成实际工期延误或费用增加（有证据）
③ 合同约定的时限内提出（一般 28 天内）
```

### 索赔程序
```
[事件发生] 
    ↓ 7天内发出索赔意向通知（CLAIN NOTICE）
    ↓ 按合同约定时间提交正式索赔报告
    ↓ 同期记录（费用/工期证据收集）
    ↓ 过程跟进谈判
    ↓ 达成一致 → 签署补充协议
    ↓ 未达成一致 → 争议评审/DAB/仲裁
```

### 索赔证据清单

| 证据类型 | 具体内容 |
|---------|---------|
| 合同文件 | 招标文件、投标文件、合同及附件 |
| 往来函件 | 会议纪要、指令函、回复函 |
| 工期证据 | 进度计划、实际进度记录、停工记录 |
| 费用证据 | 财务凭证、工资表、材料发票、机械台班 |
| 现场记录 | 照片/视频（注明时间地点）、施工日志 |
| 天气预报 | 恶劣天气记录（工期索赔用）|

### 工期索赔计算方法
| 方法 | 适用场景 |
|------|---------|
| 关键线路法（CPM）| 有完整网络计划 |
| 比例分析法 | 单项工程变更/暂停 |
| 直接计算法 | 停工天数 × 平均日产值 |

### 费用索赔项目（清单）
```
① 人工费（停工/窝工费用）
② 材料费（材料积压/涨价）
③ 机械费（机械闲置/进退场）
④ 管理费（现场管理费/总部管理费）
⑤ 利润
⑥ 利息（资金占用成本）
⑦ 规费和税金
```

## 四、变更签证索赔台账管理

### 核心字段
```
编号 | 日期 | 类型 | 变更内容摘要 | 报送金额 | 审定金额 | 审减额 
| 已结算金额 | 是否闭环 | 备注
```

### 关键指标（每月更新）
- **变更报送金额** vs **审定金额**（反映报价准确度）
- **变更审定周期**（平均天数，反映流程效率）
- **审减率**（正常范围 5%~15%，超15%需专项分析）

---

> **红线提醒**：变更签证费用必须在合同约定的时效内申报，逾期往往被视为放弃权益。证据原件（纸质签字版）是结算审核最重要的凭证。
