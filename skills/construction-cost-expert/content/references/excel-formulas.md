# 成本分析常用 Excel 公式

---

## 一、数据匹配与关联

### VLOOKUP（垂直查询）
```excel
=VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup])
```
**场景**：根据清单编号匹配清单单价/工程量
```excel
=VLOOKUP(A2, 清单台账!$A:$F, 3, 0)  ' 返回第3列（合同单价）
```

### XLOOKUP（新一代查询，Office 365）
```excel
=XLOOKUP(A2, 清单台账!A:A, 清单台账!C:C, "未找到")
```
**优势**：支持逆向查找，无需指定列序号

### INDEX + MATCH（万能组合）
```excel
=INDEX(B:B, MATCH(A2, C:C, 0))
```
**场景**：当VLOOKUP列顺序不固定时使用，可从右往左查

### 多条件匹配
```excel
=SUMIFS(产值台账!$C:$C, 产值台账!$A:$A, A2, 产值台账!$B:$B, "2024-01")
```
**场景**：按项目和月份匹配产值

## 二、条件汇总

### SUMIF（单条件求和）
```excel
=SUMIF(成本台账!$B:$B, "钢筋", 成本台账!$D:$D)
```
**场景**：汇总所有"钢筋"类成本

### SUMIFS（多条件求和）
```excel
=SUMIFS(实际成本!$G:$G, 实际成本!$A:$A, A2, 实际成本!$C:$C, ">=2024-1-1", 实际成本!$C:$C, "<=2024-1-31")
```
**场景**：汇总某项目某期间的实际成本

### COUNTIFS（计数）
```excel
=COUNTIFS(变更台账!$D:$D, "待审定", 变更台账!$B:$B, A2)
```
**场景**：统计某项目待审定变更数量

### AVERAGEIFS
```excel
=AVERAGEIFS(清单!$E:$E, 清单!$B:$B, "主体结构")
```
**场景**：计算某分部分项的平均报价

## 三、数据整理与清洗

### 去重+统计（数据透视表替代）
```excel
=SUMPRODUCT(1/COUNTIF(清单!$A$2:$A$100, 清单!$A$2:$A$100))
```
**场景**：统计清单中不重复项的数量

### TRIM（去除多余空格）
```excel
=TRIM(A2)
```
**场景**：清理从系统导出的多余空格

### TEXTJOIN（多条件文本合并）
```excel
=TEXTJOIN(", ", TRUE, IF(变更!$B$2:$B$50=A2, 变更!$C$2:$C$50, ""))
```
**场景**：将某项目所有变更编号汇总到一个单元格

### 提取数字（正则替代）
```excel
=VALUE(MID(A2, FIND(":", A2)+1, FIND("元", A2)-FIND(":", A2)-1))
```
**场景**：从"钢筋：5000元/吨"中提取数字5000

## 四、成本分析核心公式

### 目标成本 vs 实际成本对比
```excel
='成本对比'!D2-'成本对比'!C2   ' 超支金额
=('成本对比'!D2-'成本对比'!C2)/'成本对比'!C2  ' 超支率%
```

### 综合单价计算
```excel
=(人工费+材料费+机械费)*(1+管理费率)*(1+利润率)+规费+税金
```

### 不平衡报价判断
```excel
=IF(投标单价/市场单价 > 1.1, "偏高", IF(投标单价/市场单价 < 0.9, "偏低", "正常"))
```

### 变更审减率
```excel
=(1 - 审定金额/报送金额)  ' 格式化为百分比
```

### 动态成本预警（红黄绿）
```excel
=IF(实际成本/目标成本 > 1.1, "🔴超支", IF(实际成本/目标成本 > 1.0, "🟡预警", "🟢正常"))
```

### 月度累计成本（滚动汇总）
```excel
=SUMIF($B:$B, "<="&DATE(2024,1,31), C:C)  ' 截止2024.1.31的累计
```

## 五、数据透视表字段配置

### 成本汇总透视表布局
```
行字段：成本科目（钢筋/混凝土/模板/人工/机械...）
列字段：期间（月度）
值字段：求和项-金额
筛选字段：项目名称/施工单位
```

### 变更台账透视表布局
```
行字段：变更类型（设计变更/现场签证）
列字段：状态（待报送/待审定/已结算）
值字段：计数项-变更数量 / 求和项-审定金额
```

## 六、数据验证与清洗

### 下拉菜单（数据验证）
```excel
=数据验证 → 序列 → 来源：=项目列表!$A$2:$A$10
```

### 重复值高亮
```excel
=COUNTIF($A:$A, A2) > 1   ' 条件格式公式
```

### 必填字段非空检查
```excel
=IF(A2="", "⚠️必填", "")
```
