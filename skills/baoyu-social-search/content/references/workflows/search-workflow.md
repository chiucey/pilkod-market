# 搜索工作流程

## 标准搜索流程

```
1. 需求理解
   ↓
2. 关键词提取 + 搜索变体
   ↓
3. 分平台执行搜索
   ↓
4. 结果清洗 + 去重
   ↓
5. 内容分析（热度/质量/规律）
   ↓
6. 报告生成
```

## 关键词扩展

同一个主题的多种表达：
- 主词：大模型应用
- 变体：大模型落地、AI应用场景、大模型实际应用、LLM应用

## 内容分析方法

1. **热度分析**：哪些内容点赞高？为什么？
2. **角度分析**：内容切入点有哪些？
3. **差距分析**：现有内容缺少什么？
4. **机会分析**：你能做什么差异化？

## 搜索质量检查

- [ ] 结果与主题相关性 > 80%
- [ ] 时间在要求范围内
- [ ] 覆盖主流观点
- [ ] 包含数据支撑的内容
- [ ] 有不同立场的观点
