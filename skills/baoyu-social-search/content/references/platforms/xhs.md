# 小红书平台特点

## 内容风格

- **真实体验分享**：第一视角，亲和力强
- **图片为主**：封面图决定点击率
- **标签驱动**：#话题标签 是发现入口
- **种草属性**：强互动，收藏价值高

## 高赞内容规律

1. **标题党 + 实用干货**：冲突感标题 + 实用内容
2. **真实个人经历**：第一人称，有细节
3. **前后对比**：改变前/后 形式冲击感强
4. **清单列表**：3个技巧 / 5个方法 / 10个建议

## 互动指标解读

- 点赞 < 收藏：内容有保存价值，干货型
- 收藏 > 点赞 3倍：强种草内容
- 评论多：话题性强，引发讨论

## 热门话题特征

- 生活方式（美妆、穿搭、旅行、美食）
- 职场干货（简历、面试、职场生存）
- 科技数码（新品体验、App推荐）
- 情感心理（自我提升、人际关系）
