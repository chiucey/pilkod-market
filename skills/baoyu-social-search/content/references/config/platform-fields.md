# 平台数据字段说明

## 小红书（XHS）

| 字段 | 说明 | 重要性指标 |
|------|------|-----------|
| title | 笔记标题 | 高 |
| author | 作者昵称 | 中 |
| likes | 点赞数 | ⭐核心 |
| collects | 收藏数 | ⭐核心 |
| comments | 评论数 | ⭐核心 |
| tags | 话题标签 | ⭐核心 |
| content | 正文摘要（前200字） | 高 |
| images | 封面图片 | 中 |
| publish_date | 发布时间 | 中 |

## 知乎

| 字段 | 说明 | 重要性指标 |
|------|------|-----------|
| question_title | 问题标题 | 高 |
| question_desc | 问题补充说明 | 中 |
| answer_snippet | 回答摘要 | ⭐核心 |
| answer_likes | 回答点赞数 | ⭐核心 |
| author | 回答者 | 中 |
| author_title | 回答者简介 | 低 |
| publish_date | 发布时间 | 中 |
| answer_count | 回答数 | 中 |
| followers | 问题关注者 | 中 |
