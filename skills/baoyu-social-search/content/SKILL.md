# 社交媒体内容搜索技能

同时支持**小红书**和**知乎**两大平台的内容搜索与分析。

## 使用方式

直接描述需求：

**主题搜索**：小红书搜索"AI创业"相关内容
**双平台调研**：帮我调研"大模型应用"在小红书和知乎上的讨论情况
**竞品分析**：搜索竞品"XX品牌"在小红书的口碑和内容
**话题趋势**：最近"远程办公"在知乎上有哪些热门讨论

## 核心参数

| 参数 | 说明 |
|------|------|
| `--platform` | xhs（小red书）/ zhihu（知乎）/ both（两者） |
| `--sort` | hot（热门）/ latest（最新）/ top（精华） |
| `--limit` | 结果数量，默认 10 条 |
| `--days` | 最近几天内，默认 30 天 |

## 平台特点

| 平台 | 内容风格 | 适合搜索 |
|------|---------|---------|
| 小红书 | 种草、分享、真实体验、生活方式 | 产品体验、品牌口碑、旅行美食、日常技巧 |
| 知乎 | 深度分析、专业讨论、观点见解 | 行业分析、知识科普、技术解读、热点事件 |

## 输出结构

搜索结果保存在 `social-search/{keyword}/` 目录：

```
social-search/{keyword}/
├── search-report.md        # 完整分析报告
├── xhs-results.md          # 小red书结果
├── zhihu-results.md        # 知乎结果
└── media/                   # 内容图片
    └── ...
```

## 小红书搜索策略

- 使用关键词 + 平台限制搜索
- 提取：标题、作者、点赞/收藏数、标签、正文摘要
- 识别：高赞内容规律、热门话题标签、内容形式
- 排序：按点赞数 / 收藏数 / 评论数综合排序

## 知乎搜索策略

- 问题 + 回答一起呈现
- 提取：问题标题、回答摘要、点赞数、发布时间
- 识别：核心观点、主要立场、数据引用、优质回答特征
- 排序：按回答点赞数 / 关注者数量综合排序
