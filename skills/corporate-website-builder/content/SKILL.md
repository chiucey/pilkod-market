# 企业官网搭建技能

## 触发条件

当用户请求以下任务时触发本技能：
- 创建网站 / 制作网页 / 开发Web应用
- 落地页 / 个人主页 / 企业官网 / 电商网站
- 网站重构 / 网站改版 / 网页优化

## 工作流程

### 阶段1：需求确认与设计规范

1. **理解用户需求**
   - 确定网站类型（企业官网、个人站、电商等）
   - 确认目标受众和品牌定位
   - 收集功能需求（联系表单、作品集、电商等）

2. **创建设计规范文档 (SPEC.md)**
   - 定义视觉风格和设计语言
   - 制定色彩系统、字体规范、间距系统
   - 规划页面结构和组件库
   - 定义动效哲学和交互逻辑

### 阶段2：页面结构规划

完整的企业官网应包含以下模块：

```
导航栏 (Navigation)
├── Logo + 主导航链接
├── CTA按钮
└── 移动端汉堡菜单

Hero区域 (Hero Section)
├── 主标题 + 副标题
├── CTA按钮组
├── 动态背景效果
└── 滚动指示器

数据统计 (Stats Section)
├── 核心数据展示
└── 数字滚动动画

服务展示 (Services)
├── 服务卡片网格
└── 悬停交互效果

关于我们 (About)
├── 图文分栏布局
└── 资质认证展示

团队成员 (Team)
├── 成员卡片轮播
└── 3D翻转效果

客户评价 (Testimonials)
├── 评价卡片网格
└── 真实客户案例

联系表单 (Contact)
├── 联系信息
├── 表单验证
└── 提交反馈

页脚 (Footer)
├── 品牌信息
├── 快速链接
├── 社交媒体
└── 版权信息
```

### 阶段3：技术实现

1. **HTML结构**
   - 使用语义化HTML5标签
   - 确保可访问性 (ARIA标签)
   - 响应式meta标签配置

2. **CSS样式**
   - CSS变量管理主题色
   - Flexbox/Grid布局
   - 媒体查询响应式断点
   - CSS动画和过渡效果
   - 自定义滚动条样式

3. **JavaScript交互**
   - 导航滚动效果
   - 数字滚动动画
   - 表单验证与提交
   - 粒子/背景动效
   - 平滑滚动

### 阶段4：响应式设计

响应式断点规范：
- Desktop: 1200px+
- Tablet: 768px - 1199px
- Mobile: < 768px

### 阶段5：部署上线

1. 使用 `deploy` 工具部署
2. 提供部署URL和截图
3. 交付完整项目文件

## 核心组件清单

| 组件 | 功能描述 |
|------|----------|
| Navigation | 固定顶部，滚动透明化 |
| Hero | 全屏视差背景，粒子效果 |
| Stats Counter | 数字滚动动画 |
| Service Card | 悬停发光边框 |
| Team Card | 3D翻转效果 |
| Contact Form | 实时验证 + Toast提示 |
| Back to Top | 滚动显示/隐藏 |

## 质量标准

- 所有交互元素可点击
- 表单完整验证
- 加载状态处理
- 错误提示友好
- 移动端功能完整
- 动画流畅无卡顿
- 部署后可正常访问
