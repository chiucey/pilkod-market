# 证据整理技能 (Evidence Organization Skill)

## 1. 技能概述

本技能专注于法律证据的整理、分析与管理，帮助法律工作者高效处理案件材料。

### 核心能力
- 自动识别和分类各类证据材料
- 生成结构化证据清单
- 分析证据的"真实性、合法性、关联性"
- 整理证据之间的关联关系
- 输出专业的证据目录文档

## 2. 证据类型识别

### 支持的证据类型

| 类型 | 说明 | 示例文件 |
|------|------|----------|
| 书证 | 书面材料 | 合同、发票、借据、通知 |
| 物证 | 实物证据 | 照片、实物样品 |
| 证人证言 | 证人陈述 | 证人笔录、录音 |
| 当事人陈述 | 当事人口述 | 笔录、声明 |
| 鉴定意见 | 专业鉴定 | 检测报告、审计报告 |
| 视听资料 | 音视频 | 录音、录像、邮件 |
| 电子数据 | 数字化信息 | 微信记录、网页截图 |
| 勘验笔录 | 现场记录 | 现场照片、勘验报告 |

### 输出格式

```markdown

- 证据总数：[X]份

### 证据分类汇总

#### 一、书证类（X份）

|------|----------|----------|------|------|
| 1 | 文件名称 | 证明内容 | P1-P3 | 关键证据 |

#### 二、物证类（X份）
...

### 证据目录
1. [证据名称] - [页码范围] - [证明目的]
```

## 4. 证据分析方法

### 证据三性分析框架

#### 4.1 真实性审查
- 证据是否原件
- 内容是否被篡改
- 来源是否可靠
- 形成时间是否合理

#### 4.2 合法性审查
- 取得方式是否合法
- 证据形式是否符合规定
- 调查程序是否合规
- 是否经过公证/鉴定

#### 4.3 关联性审查
- 与案件事实的关联程度
- 是否能证明待证事实
- 与其他证据的印证关系

### 证据链分析

```
主证据 → 辅助证据 → 补强证据
   ↓
事实认定 ← 法律适用
```


## 7. 使用示例

### 示例场景
**输入**: 用户上传了一份合同纠纷案件的文件夹，包含10份PDF文件和5张图片

**处理流程**:
1. 识别所有文件类型
2. 分类为"书证-合同类"、"书证-票据类"、"物证-照片类"
3. 提取关键信息（日期、金额、签名等）
4. 生成证据清单表格
5. 输出完整的证据目录文档

**输出示例**:
```
## 证据清单

### 案件概要
- 案件类型：合同纠纷
- 证据总数：15份
- 书证：10份
- 物证：5份

### 证据明细

#### 书证类证据

| 序号 | 证据名称 | 文件名 | 证明目的 |
|------|----------|--------|----------|
| 1 | 《购销合同》 | contract_001.pdf | 证明双方存在买卖合同关系 |
| 2 | 《送货单》 | delivery_002.pdf | 证明货物已交付 |
| 3 | 《发票》 | invoice_003.pdf | 证明付款金额 |

#### 物证类证据

| 序号 | 证据名称 | 文件名 | 证明目的 |
|------|----------|--------|----------|
| 1 | 现场照片 | photo_001.jpg | 证明货物存放情况 |

### 证据三性分析

| 证据 | 真实性 | 合法性 | 关联性 | 备注 |
|------|--------|--------|--------|------|
| 《购销合同》 | ✓ | ✓ | ✓ | 原件，有双方签字 |
| 《送货单》 | △ | ✓ | ✓ | 需配合其他证据印证 |

### 证据链梳理
1. 合同约定 → 2. 送货签收 → 3. 发票开具 → 4. 欠款形成
```

## 8. 注意事项

### 数据安全
- 所有文件处理均在本地完成
- 不上传至外部服务器
- 处理完成后自动清理缓存

### 证据保管
- 建议保留原始文件备份
- 电子证据建议公证保全
- 重要证据建议制作多份

### 使用建议
- 首次使用建议从少量文件开始
- 根据案件类型调整证据分类
- 定期更新证据清单

## 9. 错误处理
