# 助眠催眠音乐播放器

一款精心设计的助眠音乐播放器，帮助用户放松身心、快速入睡。

## 核心功能

### 1. 权威音乐曲目库
基于中国音乐治疗协会、中央音乐学院、中华医学音像出版社等权威机构推荐的助眠曲目，精选以下10首经典助眠音乐：

1. **《春江花月夜》** - 中国传统名曲，舒缓悠扬
2. **《梅花三弄》** - 古琴名曲，清心宁神
3. **《高山流水》** - 古琴经典，意境深远
4. **《良宵》** - 二胡名曲，温柔细腻
5. **《阳关三叠》** - 古琴名曲，宁静致远
6. **《摇篮曲》** - 经典催眠曲目，温柔抚慰
7. **《秋日私语》** - 理查德·克莱德曼钢琴曲，浪漫舒缓
8. **《梦的婚礼》** - 钢琴名曲，梦幻温馨
9. **《卡农》** - 帕赫贝尔经典，循环之美
10. **《月光》** - 德彪西钢琴曲，如月轻柔

### 2. 交互流程

**步骤一：选择曲目**
- 用户可浏览10首推荐曲目
- 每首曲目显示名称、简介和来源
- 支持在线试听功能

**步骤二：设置时长**
- 提供预设时长选项：15分钟、30分钟、45分钟、60分钟、90分钟
- 支持自定义时长输入
- 显示预计入睡时间提示

**步骤三：全屏播放**
- 点击开始后进入全屏播放模式
- 显示动态可视化效果
- 播放进度条和剩余时间显示
- 支持暂停/继续控制
- 播放结束后自动淡出

### 3. 设计特点

**视觉设计**
- 深蓝色渐变背景，营造宁静氛围
- 星空/月亮元素装饰
- 呼吸灯效果动画
- 柔和的光晕效果

**音频特性**
- 低频舒缓旋律
- 自然的音乐节奏
- 渐进式音量设计

## 技术实现

### 前端架构
- 纯HTML5 + CSS3 + JavaScript
- 无需外部依赖
- 响应式设计，支持移动端
- 全屏API实现沉浸体验

### 音乐资源
- 使用公开可用的音乐API（如网易云音乐外链）
- 备用方案：内置静音背景音效
- Web Audio API 可视化支持

### 浏览器兼容
- Chrome 80+
- Firefox 75+
- Safari 13+
- Edge 80+

## 使用场景

- 失眠困扰需要助眠
- 压力过大需要放松
- 睡前冥想和放松
- 焦虑情绪舒缓
- 深度睡眠引导

## 注意事项

1. 建议使用耳机获得最佳体验
2. 音量适中，避免过大
3. 保持网络连接以加载音乐
4. 全屏模式可获得沉浸式体验
