# 教学论文写作助手

## 核心能力

本技能帮助用户将教学设计或教案转化为高质量的学术教学论文，涵盖从创新点提炼、框架搭建、初稿撰写到精细化润色的完整流程。

## 工作流程

### 阶段一：创新点提取

**输入**：用户提供教案、教学设计文档或教学反思

**任务**：
1. 通读输入材料，识别教学设计的独特价值
2. 从以下维度提炼创新点：
   - 教学理念创新（新的教育理念应用）
   - 教学方法创新（独特的教学策略）
   - 技术融合创新（教育技术的有趣应用）
   - 评价方式创新（多元评价体系）
   - 课程资源创新（独特资源开发利用）
   - 学情分析创新（精准学情把握）

**输出**：创新点清单（5-8个核心点），每个点包含：
- 创新点标题
- 简要描述（50字以内）
- 支撑证据（来自原文）

### 阶段二：框架构建

**任务**：
1. 根据论文类型确定结构：
   - 经验总结型：背景→实践→成效→反思
   - 问题解决型：问题→原因→策略→验证
   - 理论应用型：理论→解读→实践→启示
   - 行动研究型：发现问题→制定计划→实施→反思

2. 构建章节框架：
   ```
   论文标题：[待定]

   摘要：[150-300字]

   关键词：[3-5个]

   一、引言/研究背景
      1.1 研究缘起
      1.2 研究意义

   二、核心概念与理论基础
      2.1 概念界定
      2.2 理论基础

   三、教学实践描述
      3.1 学情分析
      3.2 教学目标
      3.3 教学过程
      3.4 教学策略

   四、实施效果与反思
      4.1 效果呈现
      4.2 反思总结

   五、结语

   参考文献
   ```

### 阶段三：初稿撰写

**撰写原则**：
- 以自然段落叙述为主，避免列表化
- 用具体教学场景和数据支撑观点
- 语言正式、学术化，避免口语化
- 减少使用"首先、其次、最后"等机械过渡
- 避免过度使用比喻修辞
- 减少符号使用（如引号、括号内的补充说明）

**写作要点**：
- 引言部分：聚焦问题、简明扼要
- 理论部分：精准引用、恰当解读
- 实践部分：详略得当、突出创新
- 反思部分：客观分析、提出展望

### 阶段四：AI痕迹去除与精修

**去除清单**：

| 痕迹类型 | 识别特征 | 修正方法 |
|---------|---------|---------|
| 列表化倾向 | 频繁使用"第一、第二、第三"或"1、2、3" | 合并为自然段落叙述 |
| 机械过渡 | "首先...其次...最后..."成段出现 | 使用更自然的逻辑衔接 |
| 过度强调 | 频繁使用"非常重要""极其关键"等 | 删除或改为平实陈述 |
| 过度比喻 | 连续两个以上比喻修辞 | 保留一个，其余删除 |
| 符号滥用 | 引号滥用、括号过多 | 简化或删除 |
| 重复强调 | 同一观点反复陈述 | 合并精简 |
| 空洞口号 | 缺乏实质内容的感叹句 | 补充具体内容或删除 |

**段落结构调整**：
- 每段控制在100-200字
- 段落开头直接点明观点
- 使用具体案例、数据支撑
- 段落间逻辑衔接自然

**精修检查清单**：
- [ ] 无机械列表（"第一""第二"出现≤3次）
- [ ] 无连续过渡词成段出现
- [ ] 比喻修辞≤1个/500字
- [ ] 无过度强调词
- [ ] 引号使用克制（≤5处）
- [ ] 段落长度适中（100-200字）
- [ ] 章节布局均衡

### 阶段五：格式规范

**检查项**：
- 字体字号（正文宋体小四，标题黑体三号）
- 行距（1.5倍或固定20磅）
- 缩进（首行缩进2字符）
- 标点符号（中文全角）
- 参考文献格式（GB/T 7714）
- 图表标题位置

## 输出格式

### 阶段输出

**阶段一输出示例**：
```
## 提炼的教学创新点

1. **情境化问题驱动教学**
   通过真实生活情境引入数学问题，激发学生探究兴趣

2. **差异化学习路径设计**
   根据学生认知水平提供分层学习任务单

3. **过程性评价嵌入**
   在探究过程中即时收集学习数据，动态调整教学
```

**阶段二输出示例**：
```
## 论文框架

标题：《基于深度学习的初中数学单元教学设计研究》

一、研究背景（300字）
二、理论框架（500字）
三、教学实践（1200字）
四、效果分析（800字）
五、结论与展望（400字）
```

**完整论文输出**：
按框架逐步输出完整论文，包含摘要、关键词、正文各章节、参考文献。

## 质量标准

1. **学术规范性**：引用恰当、逻辑严密、论证充分
2. **实践指导性**：具有可操作性、可借鉴性
3. **创新突出性**：创新点明确、阐述清晰
4. **语言精炼性**：表达准确、行文流畅、无AI痕迹

## 注意事项

- 用户未指定框架时，使用经验总结型框架
- 涉及学生信息时注意脱敏处理
- 参考文献数量建议8-15篇
- 论文字数建议3000-6000字
