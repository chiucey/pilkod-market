# 跨境电商选品参考指南

## 概述

本参考文档提供跨境电商选品的核心概念、方法和最佳实践。

## 核心选品指标

### 1. 市场容量指标
- **月搜索量**：关键词月均搜索次数，反映市场需求
- **月销量**：产品月销售数量
- **市场总销售额**：类目整体销售额

### 2. 竞争程度指标
- **卖家数量**：在售卖家数量
- **评论数分布**：竞品评论数量
- **价格区间**：市场价格分布
- **BSR排名**：Best Seller Rank

### 3. 盈利指标
- **利润率**：售价减去成本后的利润占比
- **投资回报率(ROI)**：广告投放回报
- **头程费用**：国际运费
- **平台佣金**：各平台佣金比例

## 主流平台特性

### Amazon
- **佣金**：8-15%
- **FBA优势**：物流体验好
- **适合品类**：3C、家居、玩具

### eBay
- **佣金**：10-12%
- **特点**：拍卖模式多样
- **适合品类**：二手、收藏品

### TikTok Shop
- **佣金**：2-8%
- **特点**：内容电商、达人营销
- **适合品类**：时尚、美妆、生活用品

### Temu
- **佣金**：较低
- **特点**：低价策略
- **适合品类**：家居、配件

### Shopify + 独立站
- **特点**：品牌建设
- **成本**：较高
- **适合品类**：有一定品牌溢价的产品

## 选品方法论

### 方法1：关键词选品
1. 确定目标市场
2. 收集目标品类关键词
3. 分析搜索量和竞争度
4. 筛选蓝海关键词
5. 验证产品可行性

### 方法2：竞品分析选品
1. 找到类目头部产品
2. 分析差异化机会
3. 评估进入壁垒
4. 制定差异化策略

### 方法3：趋势选品
1. 关注社交媒体热点
2. 追踪季节性需求
3. 分析政策影响
4. 预测未来趋势

### 方法4：用户痛点选品
1. 收集用户评论
2. 识别产品痛点
3. 寻找改进机会
4. 开发解决痛点的产品
