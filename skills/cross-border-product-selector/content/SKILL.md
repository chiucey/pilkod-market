# 跨境电商选品技能

## 核心能力

本技能帮助用户进行跨境电商选品决策，提供：
- **选品热点分析**：追踪当前市场热门品类和趋势
- **爆品发现**：识别和分析近期销量爆发的产品
- **市场趋势**：分析目标市场的消费趋势变化
- **竞争分析**：评估品类竞争程度和市场机会
- **选品建议**：基于数据分析提供选品推荐

## 工作流程

### 1. 需求理解
- 确认目标平台（Amazon、eBay、TikTok Shop、Temu等）
- 确认目标市场（北美、欧洲、东南亚等）
- 确认品类偏好或具体需求

### 2. 数据获取与分析
使用以下数据源进行分析：
- 热门搜索词趋势
- 类目销量排行榜
- 竞品价格和评论分析
- 社交媒体热度
- 季节性消费数据

### 3. 选品热点更新
支持动态更新选品热点数据：
- 自动抓取最新市场数据
- 用户可自定义添加/修改热点品类
- 保存历史热点数据用于趋势分析

### 4. 爆品分析
分析爆品特征：
- 产品差异化特点
- 价格区间分布
- 评论数量和评分
- 上架时间和销量增长曲线
- 利润率估算

## 输出格式

### 选品热点报告
```
## 选品热点分析报告

### 当前热门品类
| 品类 | 热度指数 | 趋势 | 建议 |
|------|---------|------|------|

### 爆品特征分析
...

### 市场机会评估
...
```

### 爆品分析卡片
```
## 爆品：{产品名称}

- **平台**：{销售平台}
- **价格区间**：{价格}
- **月销量估算**：{销量}
- **评论数**：{评论数}
- **评分**：{评分}
- **差异化特点**：{特点分析}
```

## 数据存储

选品热点和爆品数据存储在技能目录的 `data/` 文件夹中：
- `hot_topics.json`：选品热点数据
- `best_sellers.json`：爆品数据
- `market_trends.json`：市场趋势数据

## 更新机制

1. **自动更新**：每次执行选品分析时自动刷新热点数据
2. **手动更新**：用户可通过对话要求"更新选品热点"
3. **自定义数据**：用户可添加自己的热点观察数据
