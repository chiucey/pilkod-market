# 教学模板库

本模板库提供标准化的教学响应模板，可根据不同概念类型快速定制。

## 通用教学模板

### 模板一：概念引入式

```
## 理解你的问题
[用自己的话复述问题，融入文学/历史/文化元素]

## 启发之旅
### 起点：具体案例
[从生活/技术场景引入一个具体例子]

### 发现：引导问题
[3-5个递进式问题，引导思考]

### 提炼：原理阐述
[用清晰的语言定义概念，配合图示]

### 验证：代码佐证
[展示开源项目中的实际应用代码]

## 知识延伸
[概念的起源、历史演变、相邻概念]

## 能力检验
[3道递进式题目：基础→进阶→挑战]
```

### 模板二：问题追溯式

```
## 追根溯源
[从"为什么"开始，理解概念产生的背景]

### 根因分析
[逐步拆解，揭示本质]

### 方案设计
[展示解决方案的演进]

## 工程实践

## 评估题目模板

### 题目类型

#### 1. 概念辨析题

```
**题目**: [陈述概念或展示代码]
**问题**: 请判断以下说法是否正确，并解释原因。

a) [说法1]
b) [说法2]
c) [说法3]

**评分标准**:
- 正确判断：每项 2 分
- 合理解释：每项 3 分
```

#### 2. 代码追踪题

```
**题目**: 预测以下代码的输出

```[语言]
[代码]
```

**问题**:
1. 运行后会输出什么？（5分）
2. 如果把 X 改为 Y，结果会变吗？为什么？（5分）
3. 这个代码利用了什么概念？（5分）

**评分标准**:
- 准确预测：5分
- 原因解释：5分
- 概念识别：5分
```

#### 3. 设计实现题

```
**题目**: 请设计并实现...

**要求**:
- 满足以下条件：[条件列表]
- 考虑性能/内存/可维护性

**评分标准**:
| 标准 | 分值 | 说明 |
|------|------|------|
| 功能正确 | 40% | 满足所有需求 |
| 代码质量 | 30% | 清晰、可读、可测 |
| 性能优化 | 20% | 时间/空间效率 |
| 文档说明 | 10% | 注释和 README |

**参考答案**: [提供参考实现]
```

#### 4. 错误修复题

```
**题目**: 以下代码存在 [问题描述]，请修复。

```[语言]
[有bug的代码]
```

**问题**:
1. 识别问题所在（3分）
2. 解释问题原因（4分）
3. 提供修复方案（5分）
4. 修改后的完整代码（8分）

**评分标准**:
- 问题识别：3分
- 原因分析：4分
- 方案设计：5分
- 代码实现：8分
```

## 模板使用指南

### 选择模板的决策树

```
问题类型
├── 定义/概念 → "概念引入式"或"定义型"
├── 比较/区别 → "对比型"
├── 原理/过程 → "过程型"
├── 错误/陷阱 → "反模式型"
└── 综合应用 → 根据主次选择 + 组合
```

### 模板定制原则

1. **保持灵活性**: 模板是起点，不是终点
2. **因材施教**: 根据学习者水平调整深度
3. **融入个人风格**: 在模板基础上添加独特见解
4. **持续迭代**: 根据反馈优化模板

### 时间分配建议

| 环节 | 建议时长 | 重要性 |
|------|----------|--------|
| 概念引入 | 5-10% | 引发兴趣 |
| 现象观察 | 15-20% | 建立直觉 |
| 原理提炼 | 30-35% | 核心内容 |
| 代码佐证 | 20-25% | 实践连接 |
| 能力检验 | 15-20% | 验证学习 |
