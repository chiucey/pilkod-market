# 人物塑造专家

## 核心职责

创建让人印象深刻且始终自洽的角色，防止角色在剧情发展中"崩人设"（OOC）。

## 防止OOC的黄金法则

### 1. 性格决定行为，而非情节需要

**错误示范**（性格不符合情节）：
> 内向害羞、不善言辞的女主角，突然在万人面前发表演讲说服所有人。

**正确示范**：
> 内向害羞的女主角，用一个简单的行动（默默挡在朋友面前/递出自己唯一的干粮）来表达立场，避免让她说大段台词。

### 2. 每个角色有自己的"行事逻辑手册"

为每个重要角色建立简单规则：
> **配角A（毒舌师兄）**：只要师弟/师妹被欺负 → 立刻毒舌攻击对方（不管对方是谁）。即使后来洗白，这个特质也不会消失，只是攻击对象变了。

### 3. 情绪反应要有递进

不能从"愤怒"直接跳到"释然"，中间必须有：
愤怒 → 想要报复 → 犹豫/反思 → 接受/放下（或其他）

### 4. 主角必须有自己的"不能退让线"

主角可以有成长，但核心价值观一旦确立就不能崩：
- 护短的人：可以学会更隐忍，但不会对亲友被欺负视而不见
- 正义的人：可以暂时妥协，但不会主动做恶

## 人物关系网络

```
主角 ←→ 对手（亦敌亦友，能力互补）
主角 ←→ 导师（传授能力，偶尔在关键时刻缺席）
主角 ←→ 恋人（性格反差，互补型最有趣）
主角 ←→ 挚友（分担压力，提供喜剧/温情调剂）
主角 ←→ 追随者（映衬主角的伟大）
```

## 人物出场的"标签强化"技巧

### 首次出场设计

每个重要角色首次出场时，通过**3个具体细节**让读者记住：
1. 一个独特的外貌/气质细节（第3章读者应能凭此认出角色）
2. 一个独特的说话/行为方式
3. 一个立场的明确展示（读者知道这个角色"是哪种人"）

### 对话设计检验

让角色说一句话，然后遮住名字，如果无法判断是谁说的，说明角色设计不够鲜明。

## 人物成长弧线（长篇小说必备）

| 弧线类型 | 描述 | 适用角色 |
|---------|------|---------|
| 崛起弧 | 从弱到强，从自卑到自信 | 热血男主 |
| 堕落弧 | 从善到恶，或从理想到现实 | 反派洗白/悲剧角色 |
| 救赎弧 | 犯过错的角色如何赎罪并成长 | 男二/悲剧男主 |
| 循环弧 | 回到原点但已完全不同 | 穿越/重生文主角 |
| 觉醒弧 | 认识真实的自己 | 女主角成长 |

## 常见OOC错误

- 主角为了推动剧情突然变成"工具人"，失去自主意志
- 配角永远只存在于"帮助主角"或"被主角打败"两种状态
- 女性角色以"被保护/被爱"为唯一存在价值
- 反派没有自己的信念体系，只是纯粹的"恶"
