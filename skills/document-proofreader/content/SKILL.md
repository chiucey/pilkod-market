# 文档校对技能

## 核心能力

本技能对中文文档进行全面校对，检查以下内容：

| 校对类型 | 说明 | 适用标准 |
|---------|------|---------|
| 拼写错误 | 错别字、漏字、多字 | 《标点符号用法》GB/T 15834 |
| 语法错误 | 句子成分残缺、搭配不当、语序混乱 | 语言规范 |
| 标点符号 | 标点使用错误、中英文标点混用 | GB/T 15834-2011 |
| 格式一致性 | 标题层级、列表格式、数字格式 | GB/T 9704/GB/T 15835 |
| 用词准确性 | 近义词误用、词义重复、搭配不当 | 《新华社禁用词》 |
| 语句通顺 | 冗余表述、不通顺句子、表达歧义 | 语言规范 |
| 敏感词/不当表达 | 政治敏感词、低俗词汇、不当比喻 | 《新华社禁用词》 |
| 公文格式 | 公文各要素编排、版式要求 | GB/T 9704-2012 |

## 校对模式

### 普通文档校对
适用于一般文章、报告、邮件等文档的校对。

### 公文校对（高级）
适用于党政机关、企事业单位公文的校对，需遵循以下标准：
- **《党政机关公文格式》GB/T 9704-2012**
- **《标点符号用法》GB/T 15834-2011**
- **《出版物上数字用法》GB/T 15835-2011**
- **《新华社新闻信息报道中的禁用词和慎用词》**

## 输入方式

### 方式一：直接粘贴文本
用户直接发送文本内容，技能立即进行校对。

### 方式二：上传文件
用户上传文档文件，支持格式：
- `.txt` 纯文本
- `.md` Markdown
- `.docx` Word文档
- `.pdf` PDF文档

## 工作流程

### Step 1: 接收文档
1. 识别用户输入方式（文本粘贴/文件上传）
2. 如果是文件，提取文本内容
3. 记录原始文档
4. 判断是否为公文（根据内容特征或用户说明）

### Step 2: 文本预处理
1. 按段落分割文本
2. 识别标题层级
3. 识别列表结构
4. 提取纯文本内容

### Step 3: 逐项校对
按以下顺序检查：

1. **拼写检查**
   - 常见错别字对照
   - 拼音相似字词
   - 漏字/多字检测

2. **语法分析**
   - 句子成分完整性
   - 主谓宾搭配
   - 语序合理性

3. **标点检查**
   - 句号/逗号/分号使用
   - 引号/括号配对
   - 中英文标点区分
   - 公文特定标点要求

4. **格式检查**
   - 标题层级一致性
   - 列表格式统一
   - 数字/字母使用规范
   - 公文格式规范（如适用）

5. **用词检查**
   - 近义词辨析
   - 词义重复
   - 固定搭配
   - 新华社禁用词过滤

6. **语句优化**
   - 冗余表述
   - 语句不通顺
   - 歧义消除

7. **敏感词过滤**
   - 政治敏感词库
   - 低俗用语
   - 不当表达
   - 新华社禁用词

### Step 4: 生成报告
1. 汇总所有问题
2. 按位置排序
3. 生成修改建议
4. 输出修正文档

### Step 5: 公文排版（如适用）
按照GB/T 9704-2012对修正后的公文进行标准排版。

## 公文格式要求（GB/T 9704-2012）

### 字体字号要求

| 公文要素 | 字体 | 字号 |
|---------|------|------|
| 公文标题 | 黑体（方正） | 2号 |
| 正文 | 仿宋体 | 3号 |
| 一级层次标题 | 黑体 | 3号 |
| 二级层次标题 | 楷体 | 3号 |
| 三级层次标题 | 仿宋体 | 3号 |
| 四级层次标题 | 仿宋体（加圆圈） | 3号 |

### 层次序数规范

公文正文中的结构层次序数依次使用：
1. **第一层**：`一、`
2. **第二层**：`（一）`
3. **第三层**：`1.`
4. **第四层**：`（1）`

> ⚠️ 注意：层次序数不能越级使用，如不能直接用"1."跳过"（一）"

### 段落格式

- **正文首行**：左空2字
- **回行**：顶格
- **段间距**：段前0，段后0
- **行间距**：一般每页排22行（特定情况28行或24行）

### 标题排版

- 标题应居中排列
- 回行时做到词意完整、排列对称
- 标题排列可使用梯形或菱形

### 数字用法（GB/T 15835-2011）

#### 应使用阿拉伯数字的情形
- 计量的数字：100km、50kg
- 编号的数字：国办发〔2024〕3号
- 统计数据：增长12.5%
- 日期时间：2024年1月1日

#### 应使用汉字数字的情形
- 定型词组：一律、三思而行
- 概数：七八十年代、五十多岁
- 节日：七一、八一
- 成语：五湖四海

#### 公文中数字特殊要求
- 发文字号年份用六角括号〔 〕：国发〔2024〕3号
- 成文日期用阿拉伯数字：2024年1月1日

### 标点符号要求（GB/T 15834-2011）

- 句号用"。"表示
- 逗号用"，"表示
- 顿号用"、"表示
- 引号用""表示
- 括号用（）表示
- 书名号用《》表示
- 连接号用"-"或"—"表示

> ⚠️ 公文禁止使用"XX"等省略号形式，应使用标准中文标点

## 校对标准

### 错别字判断标准
- 与标准用法不符
- 引起理解歧义
- 常见易错字词

### 语法错误判断标准
- 句子成分残缺（缺主语、缺谓语等）
- 搭配不当（主谓不搭、动宾不搭）
- 语序混乱（定语位置错误、状语位置错误）

### 标点错误判断标准
- 该用句号用了逗号
- 引用标点使用错误
- 列举时分号使用不当
- 中英文标点混用

### 格式问题判断标准
- 同一文档中相同层级标题格式不一致
- 列表符号混用（• 和 1. 混用）
- 数字格式不统一（全角半角混用）
- 公文层次序数越级使用

### 敏感词处理
- 标记但不自动修改
- 提示用户人工确认
- 严重问题给予明确警示

## 注意事项

1. **保持原意**：修改时不改变文档原意
2. **最小修改**：能少改就少改，避免过度修改
3. **上下文敏感**：结合上下文判断，避免机械修改
4. **标注位置**：明确指出错误位置，便于用户定位
5. **尊重风格**：在符合规范的前提下尊重作者原有风格
6. **标准遵循**：公文校对时严格遵循GB/T 9704-2012等标准
