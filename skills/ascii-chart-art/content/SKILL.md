# ASCII 艺术图表生成器

## 概述

这是一个强大的 ASCII 艺术图表生成工具，支持多种图表类型、可自定义样式和 ANSI 颜色输出。本技能可以生成适合在终端、文档或网页中显示的 ASCII 图形化数据可视化。

## 功能特性

### 支持的图表类型

1. **条形图 (Bar Chart)** - 垂直或水平条形图
2. **折线图 (Line Chart)** - 带数据点和连线的趋势图
3. **面积图 (Area Chart)** - 填充式折线图
4. **直方图 (Histogram)** - 频率分布图
5. **饼图 (Pie Chart)** - 文本版饼图展示
6. **散点图 (Scatter Plot)** - 数据点分布图
7. **堆叠图 (Stacked Chart)** - 多数据系列堆叠展示
8. **箱线图 (Box Plot)** - 统计分布图

### 可自定义样式

#### 图表样式主题

- **minimal** - 极简风格，使用基本字符
- **classic** - 经典风格，使用标准 ASCII 字符
- **modern** - 现代风格，使用多样化字符
- ** bordered** - 带边框的精致风格
- **double** - 双线边框风格
- **rounded** - 圆角风格
- **dense** - 紧凑风格，适合大数据量

#### 图表组件

- **标题** - 图表主标题（支持多行）
- **副标题** - 图表副标题或说明
- **轴标签** - X 轴和 Y 轴标签
- **数据标签** - 显示具体数值
- **图例** - 多数据系列标识
- **网格线** - 可配置水平和垂直网格
- **刻度标记** - Y 轴数值刻度

#### 尺寸配置

- **宽度** - 图表宽度（字符数）
- **高度** - 图表高度（行数）
- **边距** - 图表内边距

### ANSI 颜色支持

#### 可用颜色

| 颜色名称 | 前景色代码 | 背景色代码 | 示例用途 |
|---------|-----------|-----------|---------|
| black | 30 | 40 | 背景/边框 |
| red | 31 | 41 | 错误/负值 |
| green | 32 | 42 | 成功/正增长 |
| yellow | 33 | 43 | 警告/中性 |
| blue | 34 | 44 | 信息/主要数据 |
| magenta | 35 | 45 | 特殊/强调 |
| cyan | 36 | 46 | 链接/次要数据 |
| white | 37 | 47 | 高亮/文本 |

#### 样式修饰

- **bold** - 加粗 (1)
- **dim** - 暗淡 (2)
- **italic** - 斜体 (3)
- **underline** - 下划线 (4)
- **inverse** - 反转 (7)
- **hidden** - 隐藏 (8)

## 输入数据格式

### 单一数据系列

```json
{
  "data": [10, 25, 30, 45, 50, 35, 20],
  "labels": ["一月", "二月", "三月", "四月", "五月", "六月", "七月"],
  "title": "月度销售数据"
}
```

### 多数据系列

```json
{
  "datasets": [
    {
      "name": "产品A",
      "data": [10, 25, 30, 45, 50],
      "color": "cyan"
    },
    {
      "name": "产品B",
      "data": [15, 20, 35, 40, 55],
      "color": "yellow"
    }
  ],
  "labels": ["Q1", "Q2", "Q3", "Q4", "Q5"],
  "title": "产品对比分析"
}
```

## 输出格式选项

### 纯文本模式

输出不带 ANSI 颜色的纯 ASCII 字符，适合复制粘贴到不支持颜色的环境。

### 终端颜色模式

输出带 ANSI 颜色代码的文本，适合在终端中直接显示。

### HTML 模式

输出嵌入 ANSI 颜色代码的 HTML 代码，适合在网页中展示。

### Markdown 模式

输出适合在 Markdown 文档中显示的格式。

## 技术实现

### 字符集映射

| 图表元素 | 使用的字符 |
|---------|-----------|
| 条形填充 | █ ▓ ▒ ░ |
| 边框 | ┌ ┐ └ ┘ ─ │ ├ ┤ ┬ ┴ ┼ |
| 数据点 | ● ○ ◉ ◎ |
| 箭头 | ↑ ↓ ← → ↗ ↘ |
| 线条 | ═ ║ ╔ ╗ ╚ ╝ |

### 颜色代码生成

自动生成符合 ANSI 标准的颜色转义序列，兼容大多数终端和现代编程语言的打印函数。

## 应用场景

1. **终端应用** - 为 CLI 工具添加数据可视化
2. **文档生成** - 在 Markdown 中嵌入图表
3. **日志分析** - 可视化日志数据趋势
4. **演示文稿** - 创建复古风格的图表展示
5. **数据探索** - 快速查看数据分布情况
6. **教学演示** - 展示基本图表概念
7. **测试报告** - 在测试输出中展示指标

## 使用限制

- 最大数据点数：100
- 最大数据系列数：10
- 最大图表宽度：200 字符
- 最大图表高度：50 行
- 颜色模式需要终端支持 ANSI 标准

## 错误处理

- 无效数据类型：返回错误信息和修正建议
- 数据为空：返回提示信息和示例数据
- 数值越界：自动归一化处理并提示
- 标签过长：自动截断并添加省略号
