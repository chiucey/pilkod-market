# 图生视频技能 (Image-to-Video)

将一张静态图片（人物、风景、插画等）通过 AI 模型生成逼真的动态视频。核心是让画面中的人物/场景产生自然运动（转头、眨眼、发丝飘动、镜头推拉等）。

## 触发场景

- "用这张图做视频 / 让人物动起来"
- "图生视频 / 图片动画 / 照片变视频"
- "让我的照片会动 / 人物动态视频"
- 需要给音乐MV配一段人物动态画面

## 输入需求

- **必选**：一张图片（人物肖像 / 场景 / 插画），本地文件路径或URL
- **可选**：
  - `seconds`：时长（默认5秒）
  - `resolution`：分辨率（`720P` 或 `1080P`，默认720P）
  - `prompt`：动作/镜头/风格描述
  - `last_image`：尾帧图（做帧间插值，生成更完整的长镜头）

## 输入图片获取（重要）

> ⚠️ AI 无法访问用户本机电脑文件系统（如 `C:\Users\...`）。图片必须通过对话界面的**附件/上传通道**发送，落到沙盒 `/root/uploads/` 后才能被读取。纯预览图不落盘，无法读取像素。

**排查步骤：**
```bash
# 确认图片是否真的上传到沙盒
ls -la /root/uploads/
# 确认目标图片存在
ls -la /path/to/image.png
```

## 核心工作流

### 1. 定位输入图片
确认图片路径存在（本地路径或已上传的 `/root/uploads/` 文件）。

### 2. 调用图生视频
使用图生视频能力，传入图片路径 + 动作描述：

- `image`：输入图片路径
- `prompt`：详细描述动作、镜头、风格（见下）
- `seconds`：时长（5/6/10，更长消耗更多额度）
- `resolution`：`720P` 或 `1080P`
- `output_dir`：输出目录

### 3. 编写高质量 prompt（关键）
高质量 prompt = 人物动作 + 微表情 + 镜头运动 + 氛围/风格 + 保真要求：

```
人物动作：缓慢转头、发丝随微风飘动、抬手撩发、转身
微表情：轻启双眼、嘴角浮现含蓄微笑、目光投向镜头、垂眸
镜头运动：慢速推近(medium→close-up)、轻微环绕/手持晃动
氛围：蓝色黄昏背景、体积光、浅景深、胶片颗粒、电影感
保真：保持与源图一致的容貌/服饰/配色 (Preserve facial identity)
```

### 4. 生成并校验
```bash
# 校验视频参数
ffprobe -v error -show_entries format=duration,size \
  -show_entries stream=width,height,r_frame_rate,codec_name \
  -of default=noprint_wrappers=1 output.mp4
# 提取关键帧确认效果
ffmpeg -y -ss 2 -i output.mp4 -frames:v 1 first_frame.png
```

### 5. 交付
将最终 MP4 呈现给用户，并说明参数与后续可调整项。

## 质量要点

- [ ] 人物容貌与源图一致（保真）
- [ ] 动作自然流畅，无僵硬/扭曲
- [ ] 镜头运动与动作匹配
- [ ] 分辨率/时长符合需求
- [ ] 色彩、氛围与源图风格统一
- [ ] 输出为 MP4(H.264)

## 常见问题与解决

| 问题 | 解决 |
|---|---|
| 图片无法读取 | 确认通过附件上传到 `/root/uploads/`，不是纯预览图 |
| 人物容貌不一致 | prompt 里加"Preserve facial identity / 保持与源图一致" |
| 动作太僵硬 | 明确具体动作动词(转头/眨眼/发丝飘动)，别用模糊词 |
| 视频太短/太长 | 调整 `seconds`（更长消耗更多额度） |
| 分辨率不符 | 用 `1080P`(1920×1080) 或 `720P` |

## 注意事项

- 图生视频调用外部 AI 模型，消耗独立额度（约50-100/段）
- 需在调用前向用户说明额度消耗
- 默认5秒、720P；用户有明确需求再调整
