# 顶级投资机构评估框架参考

## 一、红杉资本（Sequoia Capital）评估框架

### 沈南鹏投资三原则

1. **巨大的市场空间**
   - 投资"海洋里的大鱼"，而非"池塘里的大鱼"
   - 关注行业整体规模、上升空间、爆炸力
   - 二级市场打通产业链视角

2. **出色的创业团队**
   - 优先选择"创业者精神"，其次看"能力"
   - 面对面交流考察对方素质
   - 看重团队是否具备正能量

3. **清晰的商业模式**
   - 商业模式直观透明
   - 具有较好的盈利性
   - 净利润年增长率通常在20-25%以上

### 红杉"赛道论"

> "投资于一家有着巨大市场需求的公司，要好过投资于需要创造市场需求的公司。" —— Don Valentine

**核心策略**：
- 下注于赛道，而非赛手
- 同一赛道可竞品双投（如蚂蚁金服+京东数科）
- 沿产业链地图系统布局

### 张磊投资方法论

1. 信息点的收集（100+关键数据点）
2. 行业深度研究

4. 管理层评估

**聚焦领域**：
- 消费
- 互联网/TMT
- 医药健康
- 企业服务

**投资特点**：
- 全阶段投资（VC到PE到二级市场）
- 长期结构性价值投资
- 赋能式投资

## 三、Y Combinator 评估标准

### Sam Altman 四个核心问题

1. **产品力**
   > "这家公司能开发出很多人真正喜欢的东西吗？"
   - 用户是否真的热爱产品
   - 用户是否主动向朋友推荐（NPS）

2. **护城河**
   > "这家公司容易被复制吗？"
   - 网络效应
   - 专有技术
   - 复杂的协调成本
   - 市场壁垒

3. **创始人潜力**
   > "这些创始人会发展成为'天生的好手'吗？"
   - 坚定的意志力
   - 创造性思维
   - 独特的洞察力
   - 执行力

4. **使命感**
   > "公司是否有正确的使命？"
   - 解决真实问题
   - 长期愿景
   - 超越赚钱的驱动力

### YC四要素

1. **Idea（想法）**：清晰、能够传播、不能太复杂
2. **Team（团队）**：2-3人最佳，合伙人至关重要
3. **Product（产品）**：用户热爱 > 大众喜欢
4. **Execution（执行力）**：速度、专注、强度

## 四、分阶段评估重点

### 种子轮/天使轮评估重点

**核心关注**：
- 创始人背景、过往经历
- 赛道选择的前瞻性
- 创意的独特性和可执行性
- 团队完整性（初期可容忍缺失）

**权重分配**：
| 维度 | 权重 |
|------|------|
| 团队 | 35% |
| 赛道 | 25% |
| 产品/技术 | 20% |
| 商业模式 | 10% |
| 估值 | 10% |

### A轮评估重点

**核心关注**：
- 产品市场契合度（PMF）
- 初步商业化数据
- 单位经济模型
- 增长趋势

**权重分配**：
| 维度 | 权重 |
|------|------|
| 团队 | 25% |
| 赛道 | 20% |
| 商业模式 | 20% |
| 产品/技术 | 20% |
| 财务 | 5% |
| 估值 | 10% |

### B轮及以后评估重点

**核心关注**：
- 增长质量（效率 vs 规模）
- 竞争壁垒建立情况
- 团队扩展和管理能力
- 财务健康度
- 清晰的退出路径

## 五、行业特定评估指标

### AI/人工智能行业

#### 核心技术指标

| 指标 | 说明 | 评估标准 |
|------|------|---------|
| **模型性能** | 准确率、召回率、F1、AUC | Benchmark排名 |
| **推理效率** | 延迟、吞吐量 | 毫秒级响应 |
| **算力成本** | 训练成本/推理成本 | 行业对标 |
| **模型迭代速度** | 版本更新频率 | 快速迭代为佳 |

#### 商业化指标

| 指标 | 说明 | 评估标准 |
|------|------|---------|
| **ARR** | 年度经常性收入 | >100%增长为佳 |
| **付费转化率** | 免费到付费比例 | 行业对标 |
| **Gross Margin** | 毛利率 | >60%为佳 |
| **客户集中度** | 最大客户占比 | <30%为佳 |

#### 壁垒评估

| 壁垒类型 | 说明 | 评估要点 |
|---------|------|---------|
| **数据壁垒** | 专有数据集 | 规模、质量、独占性 |
| **算法壁垒** | 核心算法 | 专利、论文、技术独特性 |
| **工程壁垒** | 系统稳定性 | 大规模部署能力 |
| **人才壁垒** | 核心团队 | 顶级背景、稳定性 |

#### AI行业特殊风险

- 大模型能力快速迭代（能力可能被快速追赶）
- 算力获取成本不确定性
- 监管政策变化（数据合规、AI伦理）
- 人才流失（挖角激烈）
- 应用层"套壳"风险

### 硬科技/半导体行业

#### 技术评估

| 指标 | 说明 | 评估标准 |
|------|------|---------|
| **TRL等级** | 技术成熟度1-9 | 5+可商业化 |
| **良率** | 产品合格率 | >90%量产标准 |
| **专利数量** | 核心专利 | 发明专利>5项 |
| **研发投入** | 营收占比 | >15%为佳 |

#### 供应链评估

| 指标 | 说明 | 评估要点 |
|------|------|---------|
| **国产化率** | 自主可控程度 | 越高越好 |
| **产能利用率** | 产能使用情况 | >70%为佳 |
| **客户验证** | 头部客户 | 是否进入龙头供应链 |
| **认证周期** | 客户认证时间 | 短为佳 |

#### 硬科技特殊风险

- 技术路线不确定性
- 产能建设周期长（资本支出大）
- 政策依赖度高
- 国际供应链变化（出口管制）
- 人才稀缺

### SaaS/企业服务行业

#### 核心指标体系

| 指标 | 公式 | 健康标准 |
|------|------|---------|
| **NRR** | (期末ARR-流失ARR)/期初ARR | >100% |
| **CAC回收期** | CAC/MRR增量 | <12个月 |
| **LTV/CAC** | 生命周期价值/获客成本 | >3 |
| **Magic Number** | ARR增量/销售营销支出 | >1 |
| **Gross Margin** | (收入-成本)/收入 | >70% |
| **ARR增长率** | 年度增长 | >80% |

#### 产品指标

| 指标 | 说明 | 评估标准 |
|------|------|---------|
| **PMF调查** | 用户满意度 | >40%表示很满意 |
| **NPS** | 净推荐值 | >50为佳 |
| **流失率** | 月/年流失 | <5%/月 |
| **功能使用率** | 核心功能使用 | 高频使用为佳 |
