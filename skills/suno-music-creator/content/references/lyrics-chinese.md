# 中文歌词创作参数化规则 v3.5

> ⚠️ 防污染：本文档只有规则和参数，无任何示例歌词正文
> 用途：给定任意歌曲 → 提取作词人参数 → 按规则生成原创歌词

---

## 核心工作流

```
Step 1：分析歌曲 → 提取作词人参数
Step 2：热评情感 → 提取 NA 五元组
Step 3：基于作词人参数 + NA 五元组 → 生成原创歌词
Step 4：经过可唱性检查
Step 5：输出三件套（Style + Lyrics + Exclude）
```

> 数据已完整覆盖十三辙所有韵部

### 韵部可唱性分级

| 等级 | 韵部 | 韵母 | 开口度 | 可唱性 | 适合段落 |
|------|------|------|--------|--------|---------|
| ⭐⭐⭐⭐⭐ | **发花** | a, ua, ia | 开口 | 最高 | 全部 |
| ⭐⭐⭐⭐⭐ | **江阳** | ang, iang, uang | 开口 | 最高 | 全部 |
| ⭐⭐⭐⭐ | **遥迢** | ao, iao | 开口 | 良好 | 全部 |
| ⭐⭐⭐⭐ | **言前** | an, ian, uan, üan | 开口 | 良好 | 全部 |
| ⭐⭐⭐⭐ | **怀来** | ai, uai | 开口 | 良好 | 全部 |
| ⭐⭐⭐ | **梭波** | e, o, uo | 半开口 | 可用 | Verse/Chorus |
| ⭐⭐⭐ | **灰堆** | ei, ui (uei) | 细口 | 可用 | Verse/Chorus |

### 韵辙速查表

```
开口度最高（优先用）：
  a韵（发花）：家/花/他/她/吗/啊/啦/妈/卡
  ang韵（江阳）：光/方/香/长/想/伤/放/张/江/阳

开口度良好（常用）：
  an韵（言前）：难/看/慢/散/山/安/兰/残
  ao韵（遥迢）：高/好/草/道/跑/倒/老/脑/毛
  ai韵（怀来）：开/爱/在/来/白/海/莱/怀

鼻音韵（共鸣好）：
  eng韵（中东）：等/疼/朋/情/声/名/心/风/空/中
  ong韵（中东）：同/中/龙/容/浓/重/种/用/红

半开口可用：
  ou韵（梭波）：走/口/留/否/柔/透/够/头/楼

高风险（仅 Bridge/Outro）：
  i韵（一七）：迷/期/离/飞/诗/思/时/起
  u韵（姑苏）：路/图/无/苦/书/出/如/都
  uo韵（梭波）：说/国/活/过/落/火/我
```

### 韵辙选取规则

```
规则1：Chorus 开口音韵优先（发花/江阳/言前/怀来/遥迢）
规则2：Verse 可用鼻音韵（eng/ong）增加深度
规则3：Bridge / Outro 可用高风险韵辙（i/u）
规则4：同一首歌押同一韵部，不换辙
规则5：偶数句押韵（2/4/6/8句），奇数句自由
```

## 二、作词人手法参数（动态提取）

> 核心：拿到一首歌 → 实时分析作词人手法 → 提取为可复刻参数

### 手法分析工作流

```
Step 1a：搜索歌曲 → 作词人信息
Step 1b：搜索网易云热评 → 情感逻辑
Step 1c：分析该作词人的惯用手法（从歌词文本提取）
Step 2：按四个维度提取参数
Step 3：用提取的参数指导原创歌词生成
```

### 四个维度参数

```
维度1：意象选择规则（该作词人偏好什么意象？）
  IT_preference: [visual/temporal/spatial/tactile/auditory]
  → 从原歌词统计各意象类型频率
  → 保留高频意象类型

维度2：句法结构特征（该作词人爱用什么句式？）
  SYNTAX_pattern:
    short_pause:  "主语+谓语"短句占比（林夕常见）
    long_breath:  从句/复句长度（方文山常见）
    spoken:       口语化程度（李宗盛常见）
  → 从原歌词统计句式比例
  → 生成时保持相近比例

维度3：韵律模式（该作词人爱用什么韵？）
  RHYME_pattern:
    rhyme_scheme: ABAB / AABB / 自由
    rhyme_zone:  韵部偏好（eng/an/ang/i...）
  → 从原歌词提取韵脚
  → 生成时复用同一韵部

维度4：情绪表达方式（该作词人如何处理情绪？）
  EMOTION_pattern:
    show_not_tell: true/false
    leave_blank:   true/false
    subtext:       "情绪在言外"的程度
  → 判断该作词人的情绪表达风格
  → 生成时保持一致
```

### 常见作词人手法参数（预设参考）

> ⚠️ 以下是参数定义，不是模板。实际使用时从目标歌曲实时提取。

```
林夕手法参数：
  IT:        [temporal, spatial, tactile]（时间/空间/触觉意象多）
  SYNTAX:   short_pause占比高（2-5字短句多）
  RHYME:     eng韵/ang韵为主，偶换an韵
  EMOTION:   show_not_tell强，不直说情绪
  PATTERN:   "用意象说情绪，不直说"

方文山手法参数：
  IT:        [visual]（MTV式视觉意象多）
  SYNTAX:    medium_sentence（6-9字，场景蒙太奇）
  RHYME:     an/ang韵为主
  EMOTION:   通过画面讲故事
  PATTERN:   "MTV式场景蒙太奇"

李宗盛手法参数：
  IT:        [temporal, auditory]（时间/听觉意象）
  SYNTAX:    spoken占比高（口语化，一句说清一事）
  RHYME:     ou/eng韵为主
  EMOTION:   直接说，但说得真实动人
  PATTERN:   "白话入歌，一句拆三句"
```

## 三、歌词逻辑三要素

> 基于作词人手法参数（SYNTAX_pattern）动态定义，不是固定公式

### 三要素参数定义

```
三要素 = {
  subject:    主语，
  action:     行为（谓语+宾语），
  result:     结果（行为带来的改变）
}

→ 三要素的存在形式由 SYNTAX_pattern 决定：
```

**林夕式三要素（短句型）：**
```
结构："主语" + "行为"（两句分开，不写结果）
效果：留白，让听众自己补结果

示例：
  "我站在门口"    → 主语+行为，有地点无动作结果
  "等你的灯亮"    → 主语+行为，暗示结果在灯亮那一刻
```

**方文山式三要素（场景型）：**
```
结构："主语+行为+场景细节"（一句内完成）
效果：画面感强，结果融在场景里

示例：
  "我看见雨落在青石板"  → 主语+行为+空间细节，结果不明说
```

**李宗盛式三要素（直白型）：**
```
结构："因为X，所以我Y"（一句说清因果）
效果：真实感强，结果直接给出

示例：
  "爱了三年，最后还是分了"  → 主语+行为+结果全有
```

### 三要素质检规则

```
□ 每句至少含主语+行为两项
□ 同一段落内主语一致（不突然换视角）
□ 行为和结果在逻辑上因果相关
□ 作词人手法参数决定三要素的存在形式（短句/场景/直白）
```

## 四、BPM-字数公式

```
推荐字数/行 = BPM / 10 × 情绪因子

情绪因子：
  Q3（内敛/calm）= 0.9
  Q2（积累/building）= 1.0
  Q1（爆发/explosive）= 0.8
```

| BPM Range | 情绪 | 每行字数范围 |
|-----------|------|------------|
| 40-60 adagio | 冥想/悲伤 | 3-5 字 |
| 60-80 slow | 伤感 ballad | 5-7 字 |
| 80-100 andante | 叙事抒情 | 7-9 字 |
| 100-120 moderate | 流行轻快 | 9-11 字 |
| 120-140 allegro | 舞曲/K-pop | 10-14 字 |

## 五、中文歌词结构参数

```
结构能量曲线（0-10量表）：
  0→1→2→3→4→5→6→7→8→7→5→3→1→0
  I  V  P  C  V  P  C  B  F  O

段落参数：
  intro:   lyric_lines=0-1,  energy=0-1,  density=极稀
  verse:   lyric_lines=4,    energy=2-3,  density=稀疏
  pre:     lyric_lines=2,    energy=4-5,  density=积累
  chorus:  lyric_lines=4,    energy=7-8,  density=饱满
  bridge:  lyric_lines=4,    energy=2-3,  density=极稀
  final:   lyric_lines=3,    energy=6-7,  density=收束
  outro:   lyric_lines=0-1,  energy=0-1,  density=消散
```

## 六、可唱性规则

```
多音字强制替换：还/着/了/地/得/长/行
开口音优先：Chorus 每行至少一个开口音韵母
闭口音控制：单行内 i/ü 韵 ≤ 3次
三声字：Chorus 行 ≤ 2个三声字/行
音节差：同段落相邻行音节差 ≤ 2
```

---

## 七、网易云热评转化规则

```
Step 1：提取 NA 五元组
Step 2：丢弃（不复制）：
  ❌ 具体数字、具体地名、具体人名、悲伤过度细节
Step 3：保留（用于重建）：
  ✅ 行为模式、情感逻辑、时间代价、空间等待
Step 4：基于保留内容 + 作词人参数 + 韵辙选取规则
  → 生成原创歌词
```
