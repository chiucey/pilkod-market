# 创作者风格复刻技术 v3.7

> 用途：给定一首歌曲 → 提取作词人DNA六维参数 → 生成"像TA写的，但不是抄TA的"全新歌词
> **⚠️ 防污染声明**：本文件只含DNA提取规则和参数，无任何原歌词正文

---

## 核心理念：抓灵魂，不搬运；用法润色，不复制

通过「DNA 六维提取 + 四步技术」，实现对原作者风格的精准复刻。
通过「作词人手法 + 热评情感」，实现从根源防污染。

---

## 一、DNA 六维提取模型

| 维度 | 提取什么 | 如何提取 |
|------|---------|---------|
| 主题母题 | 反复书写的核心命题 | 从代表作品中统计（≥3次出现）|
| 情感基调 | 情绪的主色调 | 含蓄忧伤？直白遗憾？压抑后释放？ |
| 意象系统 | 高频符号及其关联网络 | 统计具体物品/场景词频 |
| 句式节奏 | 语句的呼吸与韵律特征 | 短句型/长短交错/口语长句 |
| 修辞特征 | 标志性的表达方式 | 电影蒙太奇/身体隐喻/白描 |
| 哲学内核 | 最深层的价值观 | 一句话概括该作者的底色 |

## 二、四步风格复刻技术

### Step 1: DNA 提取

```
DNA 提取清单：
□ 反复出现的主题（≥3次）
□ 高频意象（具体物品/场景）
□ 标志性句式结构（至少5种）
□ 核心哲学/价值观（一句话）
□ 押韵习惯（常用韵辙）
□ 情绪走向（悲伤→释然？压抑→爆发？）
```

### Step 2: 热评情感 → NA五元组（v3.7核心）

```
❌ 错误：从原曲歌词提取意象
❌ 错误：从热评复制完整句子

✅ 正确流程：
  网易云热评 → 提取"行为模式/情感逻辑/时间代价/空间等待"
  → 生成 NA 五元组
  → 用 NA 五元组 + 作词人手法 → 生成全新意象
```

### Step 3: DNA 解构（非原文引用）

```
❌ 错误（引用原歌词）：
直接展示原歌词句子

✅ 正确（DNA 解构式）：
【DNA片段 - 意象系统解构】
核心命题：用"物"承载"人"的情感
句式结构：[色彩词+名词] + [动词+自然现象] / [转折] + [人称+动词]
意象网络：色彩词(瓷器色彩)→自然现象(气候)→等待者(人)
哲学内核：最美的东西需要时间
韵辙：ang韵为主

→ 生成时：用新的色彩词+自然现象组合，不复用原文
```

### Step 4: 约束解码生成

```
原创约束（给 Agent 的说明）：
- 100%原创，不得出现原歌词中的完整短语
- 使用「DNA意象网络」的新组合，而非旧词排列
- 保持该作者的句式节奏，但换新内容
- 韵脚落在同韵辙（新字）
- 【禁止】搜索原曲歌词进入创作过程
```

## 三、作词人手法的正确用法（v3.7核心）

> **核心原则：用于润色生成，不用于复制原文**

### 用手法创作 vs 复制原文

```
❌ 错误（复制原文）：
  看到"离别"主题 → 直接套用林夕写过的"风很远/雨很冷" → 污染

✅ 正确（用手法创作）：
  离别主题 + 林夕手法
  → 用意象说情绪，不直说
  → 用一个新场景承载离别情绪
  → 新意象不是林夕写过的，是全新的
```

### 三种手法对比

| 手法 | 结构 | 意象 | 韵脚 | 特点 |
|------|------|------|------|------|
| 林夕式 | 主语+行为（两句分开）| temporal/tactile | eng/ang | 用意象说情绪，不直说 |
| 方文山式 | 主语+行为+场景（一句）| visual | an/ang | MTV场景蒙太奇，画面感强 |
| 李宗盛式 | 因为X所以Y（一句）| temporal/auditory | ou/eng | 直白，一句一事 |

### 作词人手法速查（v3.7更新）

```
林夕式参数：
  IT:        [temporal, spatial, tactile]
  SYNTAX:   short_pause占比高（2-5字短句）
  RHYME:     eng韵/ang韵为主
  EMOTION:   show_not_tell强，意象承载情绪

方文山式参数：
  IT:        [visual]
  SYNTAX:   medium_sentence（6-9字，MTV场景蒙太奇）
  RHYME:     an/ang韵为主
  EMOTION:   通过画面讲故事，意象密集

李宗盛式参数：
  IT:        [temporal, auditory]
  SYNTAX:   spoken高（口语化，一句一事）
  RHYME:     ou/eng韵为主
  EMOTION:   直白，但真实动人
```

## 四、Suno 提示词中的风格复刻表达

### 分维度控制

```
[Style]         → Suno 风格描述（genre + tempo + mood）
[Composition]   → 作曲风格（旋律语言）
[Lyrics Theme] → 作词风格（意象/主题系统）
[Vocal]        → 人声音色（性别+音色+技术）
```

### Style Prompt 构造规则

```
规则1：Genre 放第一位
规则2：不写艺术家/歌手名称（禁止）
规则3：用人声音色参数替代艺术家名

❌ 错误（艺术家名）：
"某歌手风格人声音色"
"某艺术家风格"

✅ 正确（音色参数）：
"ethereal breathy female vocal"
"warm emotional male vocal, intimate"
```

### 音色参数替代艺术家名

| 艺术家风格 | 替换为音色参数 |
|-----------|--------------|
| 空灵/咽音系 | `ethereal breathy female vocal` |
| 温暖抒情系 | `warm emotional male vocal, smooth` |
| 沧桑呐喊系 | `raspy male vocal, rough, emotional` |
| 气声亲密系 | `breathy intimate female vocal, close-miked` |
| 力量爆发系 | `powerful full voice, belting` |

## 五、防污染规则（v3.7更新）

### 5.0 核心禁令

```
【禁令】原曲歌词永远不进入创作过程

原曲歌词进入创作过程的方式（全部禁止）：
❌ 搜索原曲歌词 → 提取意象 → 写入正文
❌ 搜索原曲歌词 → 复制片段 → 换几个字
❌ 把歌名当情感逻辑 → 写入正文
❌ 搜索方文山/林夕手法词 → 直接写入正文
❌ 用户概念 = 原曲歌词 → 直接使用

正确路径：
用户要求复刻 → 搜热评情感 → NA五元组 → 生成新意象 → 写入正文
```

### 5.1 污染判定标准

```
以下情况视为污染：
□ 原曲歌词完整短语超过3字相同（更严格）
□ 热评原文完整句子
□ 原曲核心意象直接使用（特定意象词）
□ 句式结构1:1模仿
□ 搜索了原曲歌词（不论是否直接使用）

以下情况不算污染：
□ 共用常见意象（风/雨/海/路）—— 常见词人人用
□ 共用情感逻辑（离别/追梦/遗憾）—— 情感共通
□ 共用押韵韵脚（ang/eng/ai）—— 韵辙共用
□ 歌名出现在标题（风格锚定，合理）
□ 风格标签词（cantonese/mandarin pop等）
```

### 5.2 污染案例（错误示范）

| 歌曲 | 错误 | 正确 |
|------|------|------|
| 海阔天空 | 搜原曲歌词→写"原谅我这一生" | 搜热评情感→"异地恋人的等待"→新意象 |
| 水手 | 搜原曲歌词→写"码头/烈酒/舵盘" | 搜热评情感→"打工人的疲惫"→新意象 |
| 千千阙歌 | 搜歌词→写"来日纵有千千阙歌" | 搜热评→"离别时想说的话"→新意象 |
| 七里香 | 搜方文山歌词→写"候车室/诗集" | 搜热评→"少年暗恋的纯真"→新意象 |
| Dear D | 用户概念=原曲歌词→写"亲爱滴" | 用户概念→新歌词内容→原创"亲爱的" |

### 5.3 污染排查流程

```
Step 1：歌词写完后，逐行对比原曲歌词
Step 2：超过5字相同 → 标记为污染
Step 3：用NA五元组 + 作词人手法重新生成该行
Step 4：验证新行不再与原曲重复
```
