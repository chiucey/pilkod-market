# 音节计数与节奏指南

> **来源**：Suno Architect AI Blog + Suno 官方 Music Glossary + Reddit SunoAI
> **核心**：Suno 将一行歌词映射为一个 vocal phrase，音节数决定节奏感和唱腔

---

## 一、核心规则：Suno 的行→乐句映射

> **Suno Architect**：Suno maps a single short sentence or line to one vocal phrase

```
1 行歌词 = 1 个 vocal phrase（声乐乐句）
→ 行内音节数直接决定该句的唱腔密度
→ 音节数稳定 = 节奏稳定
→ 音节数突变 = 节奏混乱
```

---

## 二、±2 规则（Syllable Count Math）

> **来源**：Suno Architect "The +/- 2 Rule"

**规则**：同段落内相邻行音节数差不超过 2

| 段落 | 基准音节数 | ±2 范围 | 说明 |
|------|-----------|---------|------|
| Verse | 8-9 音节 | 6-11 | 叙事，自然呼吸 |
| Pre-Chorus | 7-8 音节 | 5-10 | 过渡，积累 |
| Chorus | 9-10 音节 | 7-12 | 高潮，可稍长 |
| Bridge | 6-7 音节 | 4-9 | 留白，极短 |
| Outro | 3-5 音节 | - | 极短，渐弱 |

| BPM | 中文基准 | 英文基准 | 每行音节范围 |
|-----|---------|---------|-------------|
| 52-60 (慢) | 5-6 字 | 4-6 | 长音，慢速 |

## 四、段落音节分布（层次感核心）

### 层次感原理

层次感 = 不同段落的音节密度不同，形成听觉上的起伏。

| 段落 | 音节密度 | 密度感 | 作用 |
|------|---------|--------|------|
| Intro | 无歌词 | 纯器乐 | 建立声场 |
| Verse | 低密度 | 稀疏，叙事 | 铺垫 |
| Pre-Chorus | 中低密度 | 积累，张力 | 引导爆发 |
| Chorus | 高密度 | 饱满，高潮 | 情感释放 |
| Verse2 | 同Verse | 恢复叙事 | 推进情节 |
| Bridge | 极低密度 | 最稀疏 | 最大留白 |
| Final Chorus | 最高密度 | 最饱满 | 终极爆发 |
| Outro | 极低密度 | 消散 | 收束 |

### 正确的密度曲线

```
密度：  0 → 低 → 中低 → 高 → 低 → 中低 → 高 → 极高 → 低
段落：  Intro → V1 → Pre → C1 → V2 → Pre → C2 → Bridge → Final → Outro
能量：  3 → 4-5 → 6 → 8 → 5 → 6 → 8 → 7 → 8 → 3
```

### 错误的密度曲线（千篇一律的原因）

```
❌ 问题：所有段落音节密度相同
密度：  中 → 中 → 中 → 中 → 中 → 中 → 中 → 中 → 中
→ 没有层次感，听感平淡

✅ 正确：Verse稀疏 → Chorus饱满 → Bridge极稀疏
密度：  低 → 高 → 低 → 高 → 极低 → 最高 → 低
→ 有呼吸感，有起伏
```

## 五、行内音节数稳定性（避免节奏崩溃）

> **Suno Architect**："If your verse establishes a pattern of roughly 10 syllables per line, keep every subsequent line between 8 and 12"

**规则**：
1. 第一段 Verse 确定基准音节数
2. 之后每行在基准 ±2 范围内
3. 超过 ±3 会开始出现节奏不稳
4. 超过 ±5 会明显听到节奏错乱

### 正确案例（Verse，基准=8）

```
8  音节：门口的灯亮了一夜     ✓
8  音节：你等我的样子看不见     ✓
7  音节：每次打电话           ✓
8  音节：你总说家里很好        ✓
```

### 错误案例

```
8  音节：门口的灯亮了一夜       ✓
10 音节：你在家的那盏灯还亮着吗     ← +2  OK
6  音节：别挂念            ← -2  OK
15 音节：我其实每天都想回去看你但是没有时间 ← -3  开始不稳
```

## 六、中文特殊处理

### 中文音节计算规则

```
1个汉字 = 1个音节
多音字 = 按语义所在发音计算（不是多音字的所有读法）

例如：
- "还(hái)" 不读"huán" → 1音节
- "长(cháng)" 不读"zhǎng" → 1音节
```

### 中文押韵音节密度

中文押韵字通常落在行尾最后一个字：

```
韵脚字音节：也计算在行音节数内
例如："长" = 1音节，"光" = 1音节
→ "比冬天还长" = 6音节
```

## 七、节奏自检清单

```
□ 同段落相邻行音节数差 ≤ 2
□ Verse 基准不超过 Chorus 基准（避免 V 比 C 还密）
□ Bridge 密度全曲最低（留白感）
□ Final Chorus 密度全曲最高（终极爆发）
□ 中文多音字已处理，不影响音节计算
□ Hook 句音节数与 Verse 不同（形成记忆点）
```
