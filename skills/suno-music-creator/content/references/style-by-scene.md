# Style Prompt 参数库：按场景分类

> ⚠️ **防污染声明**：本文件只含参数槽位组合，**无任何可直接复制的 Style Prompt 或歌词正文**
> 生成时：选取对应场景的参数槽位 → 按 GMIVE+T 公式自主组合 → 不复制本文件的任何字符串

---

## 使用方法

```
1. 找到目标场景
2. 选取 genre / mood / tempo 参数
3. 从 data/instrument-timbre.yaml 选 2-4 种含音色描述的乐器
4. 从 data/vocal-tags.yaml 选完整 vocal 配置（4字段）
5. 按公式组合，不复制本文件内容
```
