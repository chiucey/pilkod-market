## 七、Tempo（速度）标注方式

> Suno推荐在Style Prompt里直接写 BPM 数字，如 `85 BPM`，不需要用文字描述速度

| 描述 | 文字标注（可与BPM数字混用）|
|------|------------------------|
| 极慢 | `adagio` (66-76 BPM) |
| 慢 | `slow` / `lento` |
| 中速 | `moderate` / `moderato` |
| 快 | `fast` / `allegro` |
| 极快 | `presto` / `upbeat` |
| 加速 | `accelerando` |
| 渐慢 | `ritardando` |

## 九、综合 Style Prompt 示例（来自Suno社区验证）

### 社区验证有效的完整Style Prompt

**Lo-fi学习音乐：**
```
Lo-fi hip hop, soft piano chords, vinyl crackle, rain sounds, 75 BPM, no vocals, study music
```

**城市流行（City Pop）：**
```
City pop, 118 BPM, bittersweet, groove, Japanese 80s, synth, warm bass, nostalgic, romantic
```

**中文古风：**
```
Chinese ancient style, Chinese musical instruments, guzheng, erhu, bamboo flute, female vocal, ethereal, slow, melancholic
```

**港风抒情：**
```
Cantonese ballad, 80 BPM, melancholic, piano, strings, nostalgic, Hong Kong 90s, emotional male vocal
```

**华语民谣：**
```
Mandarin folk ballad, 72 BPM, guitar, husky male vocal, storytelling, intimate, bittersweet
```
