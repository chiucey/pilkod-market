# 中文歌词创作参数化规则 v3.7

> ⚠️ 防污染：本文件只有参数和规则，无任何示例正文
> 用途：给定任意概念，提取参数 → 按规则组合 → 生成原创歌词

---

## 快速工作流（热评驱动）

```
Step 1：搜索歌曲 + 网易云热评
Step 2：热评情感 → NA五元组（丢弃具体数字/地名/人名）
Step 3：NA五元组 + 作词人手法 → 生成新意象（不用原曲意象）
Step 4：基于新意象同步生成 Style Prompt + Lyrics
Step 5：经过可唱性检查 + 一致性检查
Step 6：输出三件套（Style + Lyrics + Exclude）
```

## 一、歌词参数体系

### 1.1 叙事弧线参数（NA）

每首歌必须有完整的行为链：

```
NA = {
  agent:      主角（谁？）
  action:     核心行为（做了什么？）
  obstacle:   障碍（什么阻挡了行为？）
  attempt:    尝试（怎么克服障碍的？）
  outcome:    结果（最终怎样？）
}
```

**NA 五元组来源（v3.7核心）：**

```
❌ 错误来源：直接复制原曲歌词
❌ 错误来源：直接复制网易云热评原文

✅ 正确来源：
  网易云热评 → 提取"行为模式/情感逻辑/时间代价/空间等待"
  ↓
  用提取的逻辑 → 生成全新意象
  ↓
  新意象写进歌词（不是热评原文）
```

**丢弃规则：**
```
❌ 丢弃：具体数字、具体地名/店名/人名
❌ 丢弃：热评原文完整句子
✅ 保留：行为模式、情感逻辑、时间代价、空间等待
```

---

### 1.2 意象类型参数（IT）

意象按感官类型分布：

```
IT_types = [
  visual,    # 视觉：颜色，光线，形状
  auditory,  # 听觉：声音，沉默，回声
  temporal,  # 时间：季节，时刻，等待时长
  spatial,   # 空间：位置，移动方向
  tactile,   # 触觉：温度，质感
  olfactory  # 嗅觉（慎用）
]
```

**分配规则**：同一段落内意象类型不超过2种。

---

### 1.3 韵律参数（RP）

```
RP = {
  scheme:     ABAB | AABA | AABB | 自由,
  anchor:     第2、4句必须押韵,
  skip_line:  第3句可出韵,
  rhyme_set:  取值来自13辙之一
}
```

---

### 1.4 字数参数（WC）

```
WC = f(BPM, section_type) → 每行字数范围

规律：BPM / 10 = 基准字数
情绪因子：Q3(calm)=0.9 | Q2(building)=1.0 | Q1(explosive)=0.8
```

## 二、作词人手法（用于润色，不是复制）

### 2.1 三种手法对比

| 手法 | 结构 | 特点 | 来源 |
|------|------|------|------|
| 林夕式 | 短句型，留白 | 用意象说情绪，不直说 | vocal-tags.yaml |
| 方文山式 | 场景型，MTV蒙太奇 | 画面感强，一句一景 | vocal-tags.yaml |
| 李宗盛式 | 直白型，一句一事 | 真实动人，结果直接给 | vocal-tags.yaml |

### 2.2 作词人手法的正确用法

```
✅ 正确：用手法生成新意象
  "离别时话太多说不完"
  → 林夕式：酒杯碰在一起的声音，胜过了千言万语
  → 方文山式：风翻动页角，留白写在最后一行
  → 李宗盛式：因为话太多说不完，所以我们举杯

❌ 错误：直接复制原曲歌词+换几个字
  原："徐徐回望，曾属于彼此的晚上"
  抄："慢慢回望，曾属于你我的时光"  ← 污染
```

## 三、防污染规则（v3.7核心）

### 3.1 污染判定

```
以下情况视为污染：
□ 原曲歌词的完整短语（超过5个字相同）
□ 热评原文的完整句子
□ 原曲核心意象（阙歌/斜阳/红豆/星光）直接使用
□ 句式结构1:1模仿

以下情况不算污染：
□ 共用常见意象（风/雨/海/路）—— 常见词人人用
□ 共用情感逻辑（离别/追梦/遗憾）—— 情感共通
□ 共用押韵韵脚（ang/eng/ai）—— 韵辙共用
```

### 3.2 防污染工作流

```
Step 1：从热评提取情感逻辑（不是原文）
Step 2：用情感逻辑生成NA五元组
Step 3：用NA五元组 + 作词人手法 → 生成全新意象
Step 4：全新意象写进歌词
Step 5：排查是否与原曲歌词重复（超过5字相同=污染）
```

## 四、热评驱动创作示例

### 场景：创作《千千阙歌》风格

**Step 1：热评提取**
```
热评原文："离别时想说的话太多，最后只能唱成歌，希望对方以后唱起这首歌时记得今晚"

丢弃：具体词语
保留：离别→话说不完→用歌声封存→希望对方记住
```

**Step 2：NA五元组**
```
agent:    临别的人
action:   把说不完的话唱成歌
obstacle: 离别在即，夜太短
attempt:  用歌声封存温度，希望对方记住
outcome:  你以后唱起这首歌时，要记得今晚
```

**Step 3：新作词（林振强手法 + NA五元组）**
```
酒杯碰在一起的声音
胜过了千言万语
窗外有人在唱着我们的歌
我笑着举杯 泪在杯里融化
```
