# 多周期均线渐进收敛 + 高成长低估值选股器

## 核心筛选逻辑

### 第一阶段：技术面 — 均线渐进收敛

| 指标 | 条件 |
|------|------|
| MA粘合度 | MA5/10/20/30/60与MA60的最大偏离 ≤ 2.0%（可调） |
| 渐进收敛 | 连续5日内振幅逐日收窄，≥3天在收窄 |
| 均线包裹 | 收盘价位于均线集群内部 |
| 趋势保护 | MA60走平或缓升，剔除下降通道 |
| 流动性 | 近30日日均成交额 ≥ 5000万元 |

### 第二阶段：基本面 — 硬性过滤

| 指标 | 阈值 |
|------|------|
| 总市值 | ≤ 200亿元 |
| 营收增速 | 同比 ≥ 20% |
| 利润增速 | 同比 ≥ 20% |
| PEG | < 1.0 |
| ST过滤 | 剔除ST/*ST/退市整理 |

### 第三阶段：风控过滤

- 剔除上市未满1年的次新股
- 剔除停牌股
- 剔除流动性极低标的

## 使用方式

用户发出选股指令后，执行：

```bash
python3 /workspace/skills/ma-growth-low-peg-screener/scripts/screen.py
```

输出：`/workspace/ma_growth_peg_YYYYMMDD.xlsx`

## 参数调整

直接修改 `screen.py` 顶部的配置块：

```python
MAX_MARKET_CAP = 200      # 最大市值（亿元）
MIN_REV_GROWTH = 20       # 最小营收增速（%）
MIN_PROFIT_GROWTH = 20    # 最小利润增速（%）
MAX_PEG = 1.0              # 最大PEG
MIN_DAILY_TURNOVER = 5000 # 最低日均成交（万元）
MAX_MA_SPREAD = 2.0       # MA最大偏离（%）
CONVERGENCE_WINDOW = 5    # 收敛窗口天数
```

## 输出字段说明

| 列名 | 说明 |
|------|------|
| 代码 | 股票代码 |
| 收盘价 | 最新收盘价（元） |
| MA离散系数 | MA群组标准差/价格（%），越小越粘合 |
| 最大MA偏离 | 各均线与MA60的最大相对偏离（%） |
| 收敛评分 | 历史离散系数-当前离散系数，越大收敛越明显 |
| 5日收敛天数 | 近5日振幅逐日收窄的天数 |
| 总市值 | 总市值（亿元） |
| PE | 市盈率（倍） |
| PEG | PE/利润增速，越小越被低估 |
| 营收增速 | 营业收入同比增速（%） |
| 利润增速 | 归母净利润同比增速（%） |
| ROE | 净资产收益率（%） |
| 毛利率 | 销售毛利率（%） |
