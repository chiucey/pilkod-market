# 大纲模板和案例

## 新书大纲模板

### 基础信息

```markdown
【书名】：待定（起名公式：核心卖点+期待感）

【类型】：都市/玄幻/穿越/重生等

【核心卖点】：一句话说清本书最大的亮点

【目标读者】：年龄、性别、喜好

【预计字数】：百万字以上
```

### 世界观设定

```markdown
【时代背景】：
- 时间：现代/古代/未来/异世界
- 地点：具体地域
- 社会形态：封建/资本/异能社会

【金手指设定】：
- 类型：系统/重生/血脉/空间
- 具体规则：详细说明如何运作
- 成长上限：最高能达到什么程度

【等级体系】（如有）：
- 等级名称
- 每个等级的特征
- 升级条件

【势力分布】：
- 主要势力（3-5个）
- 各势力特点
- 主角与各势力的关系
```

### 主线剧情大纲

```markdown
【开篇阶段】（1-30章）

核心事件：
1. 主角处境（第1-3章）
2. 金手指觉醒（第4-6章）
3. 第一次小高潮（第7-10章）
4. 冲突升级（第11-20章）
5. 第一阶段boss（第21-30章）

本阶段目标：
- 建立主角讨喜形象
- 明确主线冲突
- 展示金手指能力
- 建立核心人物关系

【发展阶段】（31-100章）

核心事件：
1. 势力崛起（第31-50章）
2. 中期boss出现（第51-70章）
3. 感情线发展（第71-85章）
4. 势力大战（第86-100章）

本阶段目标：
- 扩大势力范围
- 感情线推进
- 设置重大伏笔
- 引入重要配角

【高潮阶段】（101-200章）

核心事件：
1. 真相揭示（第101-130章）
2. 最终boss准备（第131-160章）
3. 终极对决（第161-180章）
4. 完美收尾（第181-200章）

本阶段目标：
- 回收所有伏笔
- 完成感情线
- 达成主线结局
- 留有后续悬念（可选）
```

## 章节大纲模板

### 单章大纲格式

```markdown
【第X章】章节标题

【核心情节点】：本章要解决什么问题

【主要事件】：
1. 开场（场景、人物状态）
2. 发展（遇到什么、做了什么）
3. 高潮（冲突/转折/突破）
4. 结尾（钩子设置）

【爽点/期待】：
- 本章给读者什么满足感
- 下章有什么期待

【字数】：预计X字

【伏笔】：埋下了什么伏笔

【人物出场】：本章出场的人物
```

### 具体案例：都市神医文大纲

```markdown
【类型】：都市神医
【核心卖点】：被退婚废物赘婿，偶得医武传承，逆袭都市
【预计字数】：200万字

【金手指】：上古医武传承（可升级）
【等级体系】：医师等级（入门/初阶/中阶/高阶/大师/宗师）

【主线】：主角从废物赘婿成长为绝世神医，揭露身世之谜

=========================================

【开篇阶段】（1-30章）

第1-3章：废物开局
- 主角身份：三年废物赘婿，被全家人嫌弃
- 当前困境：妻子要离婚，丈母娘逼他净身出户
- 初步冲突：被小舅子羞辱，被要求签字离婚

第4-6章：传承觉醒
- 偶遇机缘：救治老者，获得医武传承
- 金手指展示：一眼看穿病情，针灸立竿见影
- 能力初显：治好医院束手无策的病人

第7-10章：第一次打脸
- 老同学聚会，被嘲讽
- 关键时刻出手，震惊全场
- 前妻态度开始转变

第11-20章：立足与发展
- 开诊所，展露医术
- 第一桶金
- 收服小弟
- 与医院合作

第21-30章：第一阶段boss
- 反派出场：某个权贵子弟
- 冲突升级：被陷害入狱
- 绝地反击：揭露对方阴谋
- 完成虐渣，丈母娘态度大变

=========================================

【发展阶段】（31-100章）

第31-50章：声名鹊起
- 名声传开，达官贵人来求医
- 遇到女主（豪门千金）
- 与女主的感情线开始

第51-70章：中期boss
- 女主机遇暴露（原来出身不凡）
- 强大敌人出现（医道世家/古武家族）
- 主角陷入危机

第71-85章：感情线高潮
- 主角与女主的感情突破
- 共同面对敌人
- 生死与共

第86-100章：势力大战
- 主角建立自己的势力
- 与敌对势力全面对抗
- 主角身份开始揭示

=========================================

【高潮阶段】（101-200章）

第101-130章：身世之谜
- 主角身世揭露
- 原来出身顶级家族
- 家族内部斗争

第131-160章：终极boss
- 终极敌人出现
- 全球性危机
- 主角成为救世主

第161-180章：最终对决
- 主角vs终极boss
- 各种伏笔回收
- 世界观完整揭示

第181-200章：完美结局
- 解决所有敌人
- 感情线收尾（大婚）
- 主角成为医道宗师
- 开启新地图（可选）
```

## 大纲检查清单

### 开篇阶段检查

- [ ] 前3章有强开篇钩子
- [ ] 主角身份和处境明确
- [ ] 金手指设定清晰
- [ ] 主线冲突明确
- [ ] 有1-2个吸引人的爽点
- [ ] 章节结尾有悬念

### 发展阶段检查

- [ ] 有明显的升级感
- [ ] 感情线有进展
- [ ] 人物有成长
- [ ] 反派有压迫感
- [ ] 伏笔有埋设
- [ ] 节奏有起伏

### 高潮阶段检查

- [ ] 所有伏笔有回收
- [ ] 所有感情线有交代
- [ ] 主线冲突有解决
- [ ] 结局合理且满足
- [ ] 无重大漏洞
- [ ] 留有适当余韵
