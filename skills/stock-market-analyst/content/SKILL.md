# 股市分析技能

## 技能概述

本技能提供从新手入门到高手进阶的完整股市分析框架，涵盖公司研究、行业分析、技术分析、财务解读及高级投资策略。

---

## 模块一：新手入门 - 从"查资料"到"下判断"

### 1.1 了解一家公司

**触发词**: "了解[公司名]"、"分析[公司]基本面"、"梳理[公司]情况"

**执行流程**:

1. **核心业务识别**
   - 使用网络搜索获取公司主营业务描述
   - 识别收入占比最高的业务板块
   - 分析业务模式（B2B/B2C/平台型）

2. **收入来源分析**
   - 搜索最新财报中的收入构成
   - 识别前5大客户/产品线
   - 分析地域收入分布

3. **客户场景与产业链位置**
   - 确定公司处于产业链的上中下游
   - 分析上下游关系和议价能力
   - 识别主要竞争对手和差异化优势

4. **近年战略变化**
   - 搜索公司重大战略调整公告
   - 分析并购、新业务拓展、转型动态
   - 评估战略执行效果

**输出格式**:

```
## [公司名] 基础情况报告

### 核心业务
- 主营业务描述
- 业务模式

### 收入来源
| 业务板块 | 收入占比 | 同比变化 |
|---------|---------|---------|
|         |         |         |

### 产业链位置
- 上游/中游/下游定位
- 上下游关系分析

### 近年战略变化
- [年份]: [重大事件]
- [年份]: [重大事件]
```

> ⚠️ 注意：只做事实整理，不提供投资建议

### 1.2 分析一个行业

**触发词**: "分析[行业名]行业"、"行业研究"、"[行业]周期阶段"

**执行流程**:

1. **行业周期阶段判断**
   - 搜索行业生命周期阶段（导入期/成长期/成熟期/衰退期）
   - 分析当前处于经济周期的哪个阶段
   - 识别行业特有周期属性

2. **供需分析**
   - 搜索行业产能和需求数据
   - 分析供需平衡状态（供不应求/平衡/产能过剩）
   - 识别供需拐点信号

3. **竞争格局**
   - 分析市场集中度（CR3/CR5/CR10）
   - 识别主要竞争者和市场份额变化
   - 分析进入壁垒和替代品威胁

4. **关键变量**
   - 政策影响因素
   - 技术变革影响
   - 宏观经济敏感度

**输出格式**:

```
## [行业名] 行业分析报告

### 周期阶段
- 生命周期阶段: [阶段]
- 经济周期位置: [位置]
- 行业周期属性: [描述]

### 供需状况
- 供给侧: [分析]
- 需求侧: [分析]
- 平衡状态: [判断]

### 竞争格局
- 市场集中度: [CR数据]
- 主要参与者: [列表]
- 进入壁垒: [分析]

### 关键变量
| 变量类型 | 具体内容 | 影响程度 |
|---------|---------|---------|
| 政策    |         | 高/中/低 |
| 技术    |         | 高/中/低 |
| 宏观    |         | 高/中/低 |

### 结构性因素 vs 短期波动
- 结构性因素: [分析]
- 短期波动来源: [分析]
```

### 1.3 判断技术走势

**触发词**: "分析[股票代码]走势"、"技术分析"、"MACD/RSI判断"、"超买超卖"

**执行流程**:

1. **股价数据获取**
   - 使用股票数据API获取近X个月的OHLCV数据
   - 计算每日收益率序列

2. **技术指标计算**
   - **MACD**: 计算12日EMA、26日EMA、DIF线、DEA线
   - **RSI**: 计算14日RSI值
   - **移动平均线**: MA5/MA10/MA20/MA60

3. **趋势判断**
   - MACD金叉/死叉信号
   - RSI超买(>70)/超卖(<30)判断
   - 价格与均线的偏离程度

4. **投资建议**（仅技术面角度）
   - 当前趋势判断（上升/下降/震荡）
   - 关键支撑位和压力位
   - 风险收益比评估

**输出格式**:

```
## [股票代码] 技术分析报告

### 价格走势概览
- 当前价格: [价格]
- 近X月涨跌幅: [涨跌幅]
- 当前趋势: [上升/下降/震荡]

### MACD指标
- DIF值: [值]
- DEA值: [值]
- MACD柱: [值]
- 信号: [金叉/死叉/中性]

### RSI指标
- 当前RSI(14): [值]
- 状态: [超买/超卖/中性]

### 关键价位
- 支撑位: [价格]
- 压力位: [价格]

### 技术面建议
- 趋势判断: [描述]
- 入场时机: [建议]
- 止损位: [价格]
- 风险收益比: [比例]
```

> ⚠️ 注意：仅基于技术分析，不构成投资建议

### 1.4 深入财报细节

**触发词**: "分析[公司]财报"、"毛利率变化"、"估值影响"

**执行流程**:

1. **财报数据获取**
   - 获取最新季报/年报关键数据
   - 识别毛利率、净利率、ROE等核心指标

2. **毛利率变化原因分析**
   - 原材料成本变化
   - 产品定价调整
   - 规模效应
   - 产品结构变化

3. **估值影响评估**
   - 当前PE/PB/PS估值水平
   - 与行业平均对比
   - 历史估值分位

**输出格式**:

```
## [公司名] 财报分析

### 最新财报概况
- 报告期: [时间]
- 营收: [金额] (同比[变化])
- 净利润: [金额] (同比[变化])

### 毛利率分析
- 当前毛利率: [百分比]
- 同比变化: [变化]
- 变化原因:
  - [原因1]
  - [原因2]

### 估值分析
| 指标 | 当前值 | 行业中值 | 历史分位 |
|------|-------|---------|---------|
| PE   |       |         |          |
| PB   |       |         |          |
| PS   |       |         |          |

### 估值影响评估
- [分析内容]
```

> ⚠️ 注意：只做数据分析，不构成投资建议

## 模块二：高手进阶 - 模拟投资分析框架

### 2.1 "宏观-行业-个股"逻辑

**触发词**: "宏观行业个股分析"、"宏观环境下表现超群的行业"、"历史案例分析"

**执行流程**:

1. **当前宏观背景分析**
   - 搜索通胀水平（CPI/PPI）
   - 利率环境（基准利率/LM曲线）
   - 经济增长预期（GDP增速）
   - 政策导向

2. **历史规律研究**
   - 搜索类似宏观环境下的行业表现历史数据
   - 识别表现超群的行业特征
   - 分析时间框架和持续性

3. **行业筛选**
   - 基于宏观环境筛选受益行业
   - 分析行业与宏观变量的敏感性
   - 给出3个历史相似案例

**输出格式**:

```
## 宏观-行业-个股逻辑分析

### 当前宏观背景
| 指标 | 当前值 | 趋势 |
|------|-------|------|

| GDP  |       |      |

### 历史规律
在[宏观环境描述]下，历来表现超群的行业:
1. [行业1]: [原因分析]
2. [行业2]: [原因分析]
3. [行业3]: [原因分析]

### 历史案例
| 时期 | 宏观环境 | 表现行业 | 持续时间 | 涨幅 |
|------|---------|---------|---------|------|
|      |         |         |         |      |

### 预期时间框架
- 短期(1-3月): [预期]
- 中期(3-12月): [预期]
- 长期(1年+): [预期]

### 风险提示
- [风险因素]
```

### 2.2 "情绪-基本面"套利

**触发词**: "情绪基本面分歧"、"被错杀的股票"、"市场情绪过度悲观"

**执行流程**:

1. **情绪信号识别**
   - 搜索近期大幅下跌但无基本面恶化的股票
   - 分析负面情绪来源（行业景气度下降/市场情绪传染/短期事件）
   - 识别被错杀的机会

2. **基本面验证**
   - 验证公司核心竞争力是否受损
   - 分析业绩增长逻辑是否破坏
   - 评估估值是否进入合理区间

3. **技术面入场点**
   - 寻找支撑位
   - 判断缩量见底信号
   - 设置止损位

**输出格式**:

```
## 情绪-基本面套利机会

### 机会1: [股票代码] - [公司名]
- **负面情绪原因**: [描述]
- **基本面为何与之矛盾**: [分析]
- **技术面入场点**: [价格/信号]
- **风险收益比**: [比例]

### 机会2: [股票代码] - [公司名]
...

(共6个机会)

### 筛选标准
- 情绪指标: 股价近期跌幅>[X]%但基本面无显著恶化
- 估值水平: PE/PB低于行业中位数
- 技术信号: 缩量/支撑位/底部形态

### 风险提示
- 市场系统性风险可能持续压制
- 基本面可能存在未被发现的隐患
```

> ⚠️ 注意：不构成投资建议，仅供参考

### 2.3 挖掘内部交易信号

**触发词**: "内部交易"、"内部人士买入"、"追踪内部人"、"重大内部买入"

**执行流程**:

1. **内部交易数据搜索**
   - 搜索过去30天内重大内部人士买入(>$10万)的股票
   - 识别买入人员职位和金额
   - 分析买入时机和背景

2. **信号解读**
   - 高管买入 vs 董事买入的信号强度差异
   - 买入规模与日常薪资的对比
   - 与公司近期公告的关联性

3. **背景分析**
   - 搜索公司近期是否有利好未公布
   - 分析高管是否知道更多信息
   - 评估内幕交易合规性

**输出格式**:

```
## 内部交易信号追踪

### 信号1: [股票代码] - [公司名]
| 项目 | 内容 |
|------|------|
| 内部人士 | [职位] |
| 买入金额 | [$XX万] |
| 买入日期 | [日期] |
| 买入方式 | [二级市场/大宗交易] |

**"内部人士知道什么"分析**:
- [分析内容]

---

(共6个信号)

### 信号强度评级
- ⭐⭐⭐⭐⭐: 高管/董事大额买入，且无明显薪资来源
- ⭐⭐⭐⭐: 大额买入，职位较高
- ⭐⭐⭐: 买入金额显著，但需进一步验证

### 使用注意事项
- 内部交易信号仅供参考，不构成买入建议
- 部分买入可能与个人资金需求有关
- 需结合基本面和技术面综合判断
```
