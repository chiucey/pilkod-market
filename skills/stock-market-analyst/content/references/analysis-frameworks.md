## 附录A：技术指标计算方法

### A.1 MACD指标详解

MACD（Moving Average Convergence Divergence）是由Gerald Appel创建的趋向指标，由快线DIF、慢线DEA和柱状图组成。

**计算公式**：

```
EMA(12) = 12日指数移动平均
EMA(26) = 26日指数移动平均
DIF = EMA(12) - EMA(26)
DEA = DIF的9日指数移动平均
MACD柱 = (DIF - DEA) × 2
```

**信号解读**：

| 信号类型 | DIF与DEA关系 | 交易建议 |
|---------|-------------|---------|
| 金叉 | DIF上穿DEA | 看多信号 |
| 死叉 | DIF下穿DEA | 看空信号 |
| 零轴上方 | DIF>0 | 多头趋势 |
| 零轴下方 | DIF<0 | 空头趋势 |
| 顶背离 | 价格创新高但DIF未创新高 | 潜在见顶信号 |
| 底背离 | 价格创新低但DIF未创新低 | 潜在见底信号 |

### A.2 RSI指标详解

RSI（Relative Strength Index）是由J. Welles Wilder Jr.发明的动量指标，用于衡量价格变动的速度和幅度。

**计算公式**：

```
RS = 平均涨幅 / 平均跌幅
RSI = 100 - (100 / (1 + RS))
```

**标准参数**：14日RSI是最常用设置

**信号解读**：

| RSI区间 | 状态 | 市场含义 |
|--------|------|---------|
| RSI>80 | 严重超买 | 可能面临回调 |
| RSI>70 | 超买区域 | 多头力量可能衰竭 |
| RSI=50 | 中性 | 无明显趋势 |
| RSI<30 | 超卖区域 | 空头力量可能衰竭 |
| RSI<20 | 严重超卖 | 可能迎来反弹 |

### A.3 综合技术分析检查清单

进行技术分析时，建议按以下清单逐项检查：

**趋势确认**：
- [ ] 价格是否位于MA均线系统上方（多头排列）？
- [ ] 是否有明确的高点抬高和低点抬高？
- [ ] 成交量是否配合趋势？

**动量确认**：
- [ ] MACD是否发出入场信号？
- [ ] RSI是否进入超买/超卖区域？
- [ ] 是否存在背离信号？

**支撑阻力**：
- [ ] 关键支撑位在哪里？
- [ ] 关键阻力位在哪里？
- [ ] 价格是否形成突破或破位？

## 附录C：高级分析框架

### C.1 宏观-行业-个股三因素模型

**理论框架**：

投资回报 = 宏观Beta × 行业Alpha × 个股Alpha

**宏观因素权重分析**：

| 宏观环境 | 受益行业 | 历史案例 | 预期持续时间 |
|---------|---------|---------|-------------|
| 高通胀 | 原材料、黄金、能源 | 1970s滞涨期 | 3-5年 |
| 低利率 | 成长股、房地产 | 2010-2020年 | 5-10年 |
| 经济复苏 | 周期股、消费 | 2009-2010年 | 1-2年 |
| 经济衰退 | 公用事业、必选消费 | 2008年 | 0.5-1年 |

**行业轮动规律**：

```
经济周期 → 行业轮动：
├── 复苏初期：金融、基建
├── 复苏中期：可选消费、地产
├── 繁荣期：周期成长、科技
├── 滞涨期：黄金、能源、农业
└── 衰退期：公用事业、医药
```

### C.2 内部交易信号解读指南

**信号强度分级标准**：

| 等级 | 条件 | 预期胜率提升 |
|------|------|------------|
| 5星 | 高管（CEO/CFO/董秘）单人买入>100万美元 | +15-20% |
| 4星 | 董事单人买入>50万美元 | +10-15% |
| 3星 | 多位高管合计买入>100万美元 | +8-12% |
| 2星 | 高管买入10-50万美元 | +3-8% |
| 1星 | 员工持股计划买入 | 参考价值有限 |

**需排除的干扰信号**：

1. **薪资行权**：高管行使期权通常不构成信心信号
2. **定期定额**：部分公司有定期购买计划，需区分
3. **遗产继承**：家族传承不属于投资决策
4. **对冲操作**：部分买入可能是为平抑已持有的卖出

**信号验证流程**：

```
Step 1: 识别内部人买入
    ↓
Step 2: 核实买入规模（>10万美元为显著）
    ↓
Step 3: 判断职位权重（CEO/CFO信号最强）
    ↓
Step 4: 排除干扰因素（期权行权等）
    ↓
Step 5: 搜索近期未披露的重大信息
    ↓
Step 6: 评估买入时机合理性
    ↓
Step 7: 结合基本面综合判断
```

### C.3 情绪-基本面套利框架

**负面情绪来源分类**：

| 类型 | 特征 | 持续时间 | 恢复概率 |
|------|------|---------|---------|
| 系统性恐慌 | 全行业/全市场下跌 | 中期（3-12月） | 高 |
| 行业景气下行 | 政策打压/需求放缓 | 中长期（1-3年）| 中 |
| 个股黑天鹅 | 丑闻/事故/业绩暴雷 | 短期（1-6月）| 因情况而异 |
| 市场情绪传染 | 龙头股下跌带动 | 短期（1-3月）| 高 |

**套利机会筛选标准**：

```
必要条件：
├── 股价近期跌幅>20%
├── 无重大基本面恶化
├── 估值处于历史低位（<30%分位）
└── 机构持仓未显著下降

加分条件：
├── 大股东/高管增持
├── 业绩指引未下调
├── 行业政策边际改善
└── 技术面出现底部信号
```

**入场时机判断**：

1. **左侧入场**：估值极低+基本面无恶化+情绪极度悲观
2. **右侧入场**：缩量整理+放量突破+站稳支撑位
3. **分批入场**：首次1/3，突破确认后加仓1/3，回调不破再加仓1/3
