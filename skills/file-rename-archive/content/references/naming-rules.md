# 命名规范、清洗规则与目录结构

本文档为 `file-rename-archive` 技能的详细参考，SKILL.md 中仅保留工作流摘要。

---

## 一、文件命名格式

```
YYYYMMDD_单位简称_文件主题_版本标记.扩展名
```

### 1.1 各字段说明

| 字段 | 来源 | 空值处理 | 说明 |
|------|------|----------|------|
| `YYYYMMDD` | `year` + 文件修改时间 | 完全使用文件修改日期 | 优先使用 Skill 1 提供的 year（4位），月日从文件修改时间提取 |
| `单位简称` | `company` | 省略内容，保留分隔符 | 为空时形如 `20260417__投资计划执行报告_正式稿.docx`（双下划线） |
| `文件主题` | `subject`（清洗后） | 不可为空 | 清洗规则见 1.2 节 |
| `版本标记` | `version` | 省略该段及其前置下划线 | 如 `正式稿`、`征求意见稿` |
| 扩展名 | 原文件名 | 保持原样 | 统一小写，如 `.docx`、`.pdf` |

### 1.2 日期生成逻辑（Python 伪代码）

```python
import os, datetime

def get_date_str(year: str, file_path: str) -> str:
    mtime = datetime.datetime.fromtimestamp(os.path.getmtime(file_path))
    if year and len(year) == 4 and year.isdigit():
        return f"{year}{mtime.month:02d}{mtime.day:02d}"
    else:
        return mtime.strftime("%Y%m%d")
```

### 1.3 版本标记枚举

允许值（来自 Skill 1 输出，原样使用）：

- `初稿`
- `征求意见稿`
- `报批稿`
- `正式稿`
- 其他自定义值（原样保留，不做修改）

## 二、subject 清洗规则

### 2.1 去除数字编号前缀

以下模式在 `subject` 开头时**全部删除**（不区分全半角）：

| 模式示例 | 正则 |
|----------|------|
| `7.`、`12.` | `^\d+[\.．]` |
| `1、`、`三、` | `^[\d\u4e00-\u9fa5]+[、]` |
| `附件1：`、`附件一:` | `^附件[\d一二三四五六七八九十]+[：:]` |
| `（一）`、`(1)` | `^[（(][\d一二三四五六七八九十]+[）)]` |

### 2.2 去除特殊字符

删除以下字符（若出现在任意位置）：

- 引号：`"`  `"`  `'`  `'`  `"`  `'`
- 书名号：`《`  `》`  `〈`  `〉`
- 括号（成对，含内容时谨慎处理）：`（）`  `()`  `【】`  `[]`
- 顿号、分号单独出现时：`、`  `；`
- 省略号：`……`  `...`
- 其他：`!`  `！`  `?`  `？`  `#`  `@`  `&`  `*`  `%`

> **注意**：括号若含关键信息（如年份"（2026）"），可保留括号内容并去掉括号符号本身。

### 2.3 长度截断

清洗完成后，`subject` 最长保留 **15 个字符**（按中文字符计算，不含标点）。  
若超出，在第 15 字处截断（不截断词语中间，优先在词语边界截断）。

### 2.4 清洗示例

| 原始 subject | 清洗后 |
|-------------|--------|
| `7.省机场集团"十五五"高质量发展规划纲要` | `省机场集团十五五高质量发展规划纲` |
| `附件1：2025年度投资计划执行情况报告（正式）` | `2025年度投资计划执行情况报告正式` |
| `（三）重组整合与企业压减工作方案（征求意见稿）` | `重组整合与企业压减工作方案` |
| `1、科技创新三年行动计划` | `科技创新三年行动计划` |

### 2.5 清洗函数（Python 参考实现）

```python
import re

def clean_subject(subject: str, max_len: int = 15) -> str:
    # Step 1：去除编号前缀
    subject = re.sub(r'^附件[\d一二三四五六七八九十]+[：:]\s*', '', subject)
    subject = re.sub(r'^[（(][\d一二三四五六七八九十]+[）)]\s*', '', subject)
    subject = re.sub(r'^[\d\u4e00-\u9fa5]+[、]\s*', '', subject)
    subject = re.sub(r'^\d+[\.．]\s*', '', subject)

    # Step 2：去除特殊符号
    subject = re.sub(r'[""\'\'\"\'《》〈〉【】\[\]（）()\u2026\.]{1,3}', '', subject)
    subject = re.sub(r'[！!？?#@&*%；;、]', '', subject)

    # Step 3：截断至 max_len 字符
    if len(subject) > max_len:
        subject = subject[:max_len]

    return subject.strip()
```

## 五、重名冲突处理

若 `目标路径/新文件名.ext` 已存在：

```
新文件名_1.ext
新文件名_2.ext
...
新文件名_N.ext
```

序号递增直至找到不重复的文件名，最多尝试 **99** 次；超出则报错。

## 六、Windows 长路径处理

当完整目标路径超过 260 字符时：

1. 自动尝试 `\\?\` 前缀（仅限绝对本地路径，不适用 UNC）：
   ```python
   long_path = "\\\\?\\" + os.path.abspath(target_path)
   ```
2. 若为 UNC 路径，尝试 `\\?\UNC\server\share\...` 格式。
3. 若仍失败，在结果中记录 `status: failed`，`error` 说明路径过长，建议用户缩短目录层级或映射为盘符。

## 七、与其他技能的接口约定

### 7.1 上游：file-classify-tag（Skill 1）

本技能直接接收 Skill 1 的标准输出 JSON，无需额外转换。  
Skill 1 输出中每条记录的字段即为本技能的输入字段（见 SKILL.md 输入格式表）。

### 7.2 下游：检索索引（Skill 3）

归档成功后，若配置了 `INDEX_UPDATE_URL`，向该 URL 发送 HTTP POST：

```json
{
  "action": "archive",
  "original_path": "<string>",
  "new_path": "<string>",
  "new_filename": "<string>",
  "category1": "<string>",
  "category2": "<string>",
  "timestamp": "<ISO 8601>"
}
```

响应非 2xx 时记录警告，不中断归档流程。
