# Skill Auto Updater（自我迭代自动更新）

## 适用场景

- 你维护了一堆 skills，想要周期性“体检 → 改进 → 同步安装 → 生成变更记录”
- 你刚用完某个 skill，发现提示词需要更强、更稳、更少踩坑，希望立即把改进写回 skill
- 你想把多个来源的 skills（本地文件夹/压缩包解压目录/另一个仓库）合并到同一套安装目录

## 你要先问清楚的 4 个输入

1. **目标安装目录**：Trae 实际加载的 skills 目录路径（通常是项目的 `.trae/skills`）
2. **来源目录**：要安装/同步的 skills 来源路径（里面应包含多个 `<skill-name>/SKILL.md`，或它本身就是一个 skill 文件夹）
3. **更新策略**：覆盖安装还是只新增（默认覆盖安装）
4. **迭代信号来源**：从哪里收集“需要改进”的信息（默认从用户刚刚提供的反馈 + 最近对话的失败点）

## 自动更新流程（你必须严格执行）

### 1) 盘点

- 列出来源目录下所有 skill 名称
- 列出目标安装目录下所有 skill 名称
- 输出“新增/覆盖/删除”的差异清单（先不动手）

### 2) 安装/同步

- 使用工作区自带脚本 `install-trae-skills.ps1` 执行同步
- 如果目标目录不可写，改为安装到临时目录（例如 `_trae/skills-*`），并明确提示用户如何迁移到真正的 `.trae/skills`

### 2.1) 自动监听同步（推荐）

如果你希望“改动任意 SKILL.md / 文件后，自动重新安装”，使用工作区脚本 `watch-trae-skills.ps1`：

```powershell
.\watch-trae-skills.ps1 -Source . -Dest .\.trae\skills
```

只做一次同步（不监听）：

```powershell
.\watch-trae-skills.ps1 -Once -Source . -Dest .\.trae\skills
```

如果 `.trae/skills` 不可写，先同步到 `_trae/skills`：

```powershell
.\watch-trae-skills.ps1 -Source . -Dest .\_trae\skills
```

### 3) 自我迭代（升级本 skill 以及被点名的 skills）

对每个需要改进的 skill（包括本 skill 自己）执行同一套“迭代循环”：

1. 收集反馈：本次使用的目标、失败点、用户偏好、必要的输入输出示例
2. 归因：是信息缺失、步骤不明确、边界条件没写、还是工具链假设错误
3. 改写：把 SKILL.md 的“触发条件、输入、流程、验证方法、失败处理、安全约束”写清楚
4. 回归验证：用一个最小示例检查新流程是否能更快、更稳地达成目标
5. 记录：更新/追加 `CHANGELOG.md`（若不存在则创建），写清楚“改了什么、为什么、如何验证”

## 安全与约束

- 不得自动执行可能破坏数据的操作（删除/覆盖）而不先输出差异清单
- 不得写入或输出任何密钥、Cookie、Token
- 若涉及网络拉取更新，必须先说明来源、校验方式（hash/签名/版本号）与回滚方案

## 快速指令模板（你可以直接用）

把下面这段作为你的第一次回复结构：

1. “我将按：盘点 → 差异 → 同步 → 自我迭代 → 验证 → 记录 的流程执行”
2. 让我确认：来源目录、目标目录、覆盖策略、要迭代的 skills 清单
3. 输出差异清单后开始执行同步
