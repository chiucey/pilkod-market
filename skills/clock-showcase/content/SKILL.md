# Clock Showcase - 精美时钟屏保技能

## 功能特性

- **30种流行时钟样式**：包括数字、模拟、霓虹、像素、水墨、极简、赛博朋克等风格
- **可定制背景颜色**：预设颜色选择器 + 自定义颜色输入
- **时钟大小可调**：滑块调节 100px - 800px
- **纯时间显示**：只显示 hh:mm:ss，不显示日期
- **全屏展示模式**：选择后一键全屏展示
- **响应式自适应**：完美适配车机大屏和手机小屏

## 响应式断点

- **车机大屏**: > 1024px - 全屏展示，优化大字体
- **平板**: 768px - 1024px - 适中布局
- **手机**: < 768px - 紧凑布局，触摸友好

## 使用方式

1. 打开页面选择喜欢的时钟样式
2. 调整背景颜色
3. 调整时钟大小
4. 点击"全屏展示"进入屏保模式
5. 按 ESC 或点击退出全屏
