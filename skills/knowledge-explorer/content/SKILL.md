# 知识探索规划师

帮助您构建任何主题的完整知识框架，从浅层了解到深度洞察。

## 核心工作流程

### 第一步：界定探索边界

**明确研究主题**
- 核心主题是什么？
- 是单一地点、人物、时期，还是跨多个领域？

**界定空间范围**
- 地理边界（城市、地区、国家）
- 时间边界（朝代、世纪、年代）
- 主题边界（历史、艺术、建筑、文化）

**示例**
用户说："我想了解云冈石窟"
→ 扩展为：大同地理 → 北魏历史 → 石窟开凿背景 → 石窟艺术特点 → 佛教文化影响

### 第二步：构建知识维度矩阵

针对每个主题，从以下维度进行探索：

| 维度类别 | 具体问题 | 示例（云冈石窟） |
|----------|----------|------------------|
| 历史维度 | 起源、发展、转折、消亡或传承 | 北魏为何在此开凿石窟？ |
| 地理维度 | 位置、环境、气候、资源的影响 | 大同的地理位置有何特殊性？ |
| 文化维度 | 信仰、习俗、艺术风格、思想流派 | 佛教如何影响石窟造像？ |
| 人物维度 | 决策者、创作者、守护者、参观者 | 是谁主持建造？工匠来自哪里？ |
| 物质维度 | 建筑、文物、工艺、材料、技术 | 采用何种雕刻技法？ |
| 影响维度 | 对后世、政治、经济、社会、文化的影响 | 对后续石窟有何影响？ |

### 第三步：信息收集策略

**历史类主题**
- 时间线梳理：起源 → 发展 → 繁荣 → 衰落/转型
- 关键事件：政治变革、战争、创新、灾难
- 重要人物：决策者、执行者、见证者

**地点类主题**
- 自然地理：地形、气候、生态
- 人文地理：居民、交通、经济
- 历史沿革：归属变迁、重要事件

**艺术/文化类主题**
- 形式分析：外观、结构、风格特征
- 技法工艺：材料、工具、创作过程
- 审美特征：造型语言、象征意义、美学价值
- 传承脉络：影响来源、对后世影响

### 第四步：框架构建方法

**金字塔结构**
```
顶层：核心认知（3-5个关键洞见）
中层：支撑维度（每个维度的核心发现）
底层：详细信息（具体事实、数据、细节）
```

**时间线结构**（适合历史主题）
```
起源期 → 发展期 → 鼎盛期 → 转折/衰落期 → 当代意义
```

**空间结构**（适合地点/建筑主题）
```
宏观（区域/整体）→ 中观（组成部分）→ 微观（细节/局部）
```

### 第五步：深化与关联

**建立横向联系**
- 不同维度之间的关联
- 与其他相似主题的对比
- 跨领域的启发

**形成独特洞见**
- 为什么这个主题重要？
- 它揭示了什么普遍规律？
- 对您个人有何意义？

## 输出格式

为每个探索主题生成结构化报告：

```
## [主题名称] 知识框架

### 核心认知（必知的3-5个要点）

### 维度一：[维度名称]
- 关键发现
- 重要细节
- 信息来源

### 维度二：[维度名称]
...

### 时间线/空间分布/关系图

### 待深入探索的问题

### 实践建议（如果适用）
```
