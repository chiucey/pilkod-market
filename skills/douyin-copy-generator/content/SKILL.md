# 抖音文案与热点Hashtag生成器

## 技能概述

本技能专注于为抖音创作者提供高质量的文案和hashtag解决方案，帮助提升视频的完播率、点赞量和粉丝转化。

## 核心能力

### 1. 文案生成
支持多种文案风格：
- **情感共鸣型**：触动用户情感，引发共鸣和评论
- **悬念引导型**：制造悬念，诱导用户看完视频
- **干货分享型**：提供实用价值，吸引精准受众
- **热点蹭流型**：结合当下热门话题获取流量
- **对比反差型**：通过对比吸引注意力
- **数字量化型**：用具体数字增强说服力

### 2. Hashtag策略
- 热门话题：当前抖音热门挑战/话题
- 垂直领域标签：精准触达目标用户
- 长尾标签：覆盖细分搜索流量
- 品牌标签：建立个人IP认知

## 输入参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| topic | string | 是 | 视频主题或核心内容 |
| style | string | 否 | 文案风格偏好 |
| target | string | 否 | 目标受众描述 |
| keyword | array | 否 | 关键词列表 |


## 热点追踪

生成文案时可结合以下热点策略：
1. **节日营销**：春节、情人节、双11等节点
2. **季节话题**：换季穿搭、防晒指南、冬季护肤等
3. **社会热点**：结合当下热议话题蹭流量
4. **平台活动**：抖音官方挑战赛、话题活动

## 质量标准

1. **标题党识别**：避免过度标题党导致用户体验差
2. **敏感词过滤**：自动规避平台敏感词
3. **合规性检查**：确保内容符合抖音社区规范
4. **emoji使用**：适量使用emoji增加活力，避免滥用

## 常见问题

**Q: 如何选择合适的hashtag数量？**
A: 建议使用5-8个标签，包含1-2个热门话题、2-3个垂直标签、1-2个长尾标签。

**Q: 标题长度多少合适？**
A: 建议控制在10-30字，确保在信息流中完整显示。

**Q: 如何判断热点是否适合蹭？**
A: 优先选择与自身内容相关度高、正能量、有讨论空间的热点。
