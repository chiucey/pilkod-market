# AI 视觉提示词

把"我想要一张/一段 X"翻译成结构化提示词，产出**中文 + English Prompt** 双份，并标注用了哪条技法。

## 路由：先判断产线

| 用户需求 | 产线 | 读哪份参考 |
|---|---|---|
| 人物、生活、纪实照片；抱怨"AI 味重/太假/塑料感" | **A 静态图·去 AI 味** | `references/de-ai-flavor.md` |
| 已有图，要它动起来 | **B 图生视频** | 本文件 §B + `de-ai-flavor.md` 氛围层 |
| 要有影视感的多镜头视频 | **C 分镜三步** | `references/storyboard.md` |
| PPT 封面、主视觉、"大片感"配图 | **D 恢弘感封面** | `references/epic-cover.md` |

判断不了就问一句：出图还是要视频、要人物还是要风景。**不要替用户假设。**

需求同时跨产线时（例如"一组去 AI 味的人物图，还要做成 PPT 封面"），先跑 A/D 拿静态图提示词，再跑 B/C 拿视频提示词，不要合并成一条。

---

## 生成闸门（硬规则，优先级高于所有产线）

**写提示词 ≠ 生成图片/视频。提示词可以随时给，生成必须先过闸。**

用户只是要提示词时，闸门不适用；一旦要**实际调用工具生成**，下面三道闸必须依次过完。

### 闸 1｜信息不足 → 提问，禁止直接生成

需求不完整时**停下来提问，不要脑补后开跑**。

判断标准——缺以下任意一项即视为"不充分"：

| 场景 | 最小充分集（缺一即问） |
|---|---|
| 静态图 | 主体 · 场景 · 风格取向 · 用途 · 张数 |
| 图生视频 | 起始图或画面内容 · 要发生什么变化 |
| 分镜视频 | 主题 · 分镜数 · 单镜时长 · 是否有参考图 · 是否要音轨 |
| PPT/封面 | 画面主体 · 标题文字 · 留白方向 |

**一次问完，别挤牙膏。** 把缺的项列成清单让用户一次补齐。

- ❌ 别因为"没说几张"就默认 1 张然后直接跑
- ❌ 别因为"没说风格"就脑补一个自选风格开干
- ❌ 别因为"感觉懂了"就跳过——**你的理解不等于用户的意图**
- ✅ 缺信息 → 列清单 → 等回答 → 再往下走

### 闸 2｜提示词先过目，同意后才生成

提交前**必须**把完整提示词（中英双份）原样贴给用户，附手法标注，然后**停下等明确同意**。

- 用户要改就改，改完**重新过一遍闸 2**，别用改前的版本生成
- "你看着办" ≠ 同意生成，要拿到明确的"可以""生成吧""就这样"
- 用户只说了"生成"但没看过提示词 → 回闸 2
- 一次给多版时，标明哪版是主推、哪版是备选，等用户点名

### 闸 3｜确认模型、参数、张数

闸 2 通过后、实际提交前，确认三项：

| 项 | 要问清什么 |
|---|---|
| **模型** | 用哪个 / 哪个变体（如 H3 与 H3 Max 的取舍）。**若目标工具不暴露模型选择**（例如 matrix 生图只有统一接口、没有 model 字段），直接说明"该工具不暴露模型，只能走默认路由"，**不要问一个用户答不了的问题** |
| **参数** | 画幅比例 · 分辨率档位 · 风格强度相关开关。转换规则见「工具方言」。**主动提示分辨率对去 AI 味的影响**，见 §A 铁律 |
| **张数** | 一次出几张。生图有随机性，张数直接等于抽卡成本，按用途给建议量 |

### 三闸合并成一次确认

**闸 2 和闸 3 放在同一条消息里，不要来回两轮。** 一条消息同时给出：

1. 完整提示词（中英双份）+ 手法标注
2. 建议的模型 / 画幅 / 分辨率 / 张数，附一句理由
3. 一句明确的"确认就生成，或告诉我要改哪里"

用户一次点头即可开跑。

### 完整顺序

```
需求 → 闸1 问清 → 写提示词 → 闸2+3 合并确认 → 生成 → 交付
```

任何一步被打断（用户改了需求、补了新信息、要求重写），**回到对应的闸重来**，不要从中间接着跑。

## A 静态图·去 AI 味

**三招，必须在交付时注明用了哪几招。**

1. **不完美化** — 从不完美清单挑 3–5 项塞进提示词。核心是"聚焦结果的真实性"：让画面像真实世界里随手拍下的一张照片。
2. **详细化** — 按维度表补细节（场景/细节/动作/情绪/服装/光线）。核心是"聚焦过程的精准控制"。
3. **随机词** — 提示词结尾追加：`以下一些可供参考的随机词汇：<从 161 词库按类型挑选>`。核心是"聚焦探索和创造性"。

### 句式模板（从 43 个实测案例反推）

```
[主体+年龄/身份]的[真实场景]，[动作/情绪细节]，[服装细节]，[光影]，
[不完美项 × 3–5]，整体氛围[质感词]。
```

```
a candid [genre] photo of [subject] , [action] , [clothing] ,
[lighting] , [imperfections] , raw and imperfect documentary style.
```

### 铁律

- 英文结尾固定带 `raw`、`un-retouched`、`imperfect documentary style`、`candid photography style` 中的 2–3 个，这是去 AI 味最省力的锚点。
- **不靠堆 quality tag 去 AI 味。** `8K / best quality / masterpiece` 恰恰是 AI 味的来源之一；去 AI 味靠具体名词（毛孔、法令纹、掉漆），不靠分辨率词。
- 人物类优先"日常环境背景"（`everyday environment background`），不要 studio 棚拍、渐变纯色背景。
- **随机词只能从 161 词库里挑，禁止自造。** 自造的词（`unstyled`、`soft-focus`、`damp` 之类）会让招 3 退化成普通写作，失去词库的随机性价值。词库覆盖不到想要的表达时，老实说明，不要凑词。
- **不完美项优先挑"物理瑕疵"，别挑"成像缺陷"。** 实测：皱纹/油光/起皱/毛球/老年斑几乎必中；噪点/颗粒/模糊/欠曝在高分辨率下基本失效。详见 `de-ai-flavor.md`。
- **高分辨率会反噬去 AI 味。** 分辨率越高，模型越倾向输出"干净"的图，物理瑕疵也会被抹平。追求真实感时降一档分辨率，比多写三行提示词有用。
- **画面里有中文就一定会翻车**（招牌、菜单、路牌、书脊、报纸）。要么构图避开文字区域，要么明确写"招牌为空白或无可辨识文字"，后期自己贴。
- 生图有随机性：同一提示词多次生成结果不同。交付时提醒用户这一点，别让用户以为是提示词写错了。

## B 图生视频

### 两种模式

**无提示词**：一键图生视频。适合只需要轻微环境动态（云飘、浪涌）的场景，先给这个低成本选项。

**有提示词**：只写**变化**，不重复图里已有的内容。

```
保持[主体]的位置和形态不变，让[环境/光线]发生变化：[具体动作]。
```

**以主体为中心的运镜公式**（适合静态封面图）：

```
以[XX]为中心，旋转运镜。
以[XX]为中心，旋转运镜。保持[XX]在画面中的位置不变。
```

### 动作词库（照抄或改写）

海浪翻涌，冲浪者在其中穿行。/ 灯塔的光扫射。/ 海浪拍打船头。/ 鲸鱼在海面翻腾。
让天空中的云层飘动起来，有一种时间流逝的感觉。/ 衣角和发丝随风飘动。/ 镜头缓缓环绕人物一圈，细腻展示人物蹲地寻找的动作。

### 去 AI 味词库在视频里的用法

`de-ai-flavor.md` 的词库**同样适用于视频**，但只用**动态与氛围层**：

- ✅ 可用：雾气、光束、发丝飘动、碎屑、水花、涟漪、逆光呼吸感、镜头轻微手持感
- ❌ 不可用：雀斑、法令纹、衣服起皱、镜头畸变——这些是**静态外观**，写成动作模型会执行成诡异变形

铁律：视频提示词里出现静态缺陷词，模型大概率理解为"让脸变形"。

## C 分镜三步（影视感）

固定三步，不要跳步，参考 `references/storyboard.md`：

1. **定审美基调** — 一段中英双语的定调提示词，含镜头语言、焦段、光、画幅、`--style raw`
2. **造多景别分身** — 用图生图造分镜图，通常 3 个景别（远景 / 中景 / 近景特写），每个景别配一句中文描述
3. **让分镜动起来** — 每镜配视频提示词 = **运镜 + 节奏 + 氛围**

交付时用分镜表呈现，一镜一行。

## D 恢弘感封面

四维度自由组合，参考 `references/epic-cover.md`：

**留白充足 + 主体宏大 + 光影对比 + 真实摄影感**

修图三步：**去干扰 → 扩留白 → 压暗背景突出主体**。

## 输出契约

每次交付必须包含：

1. **中文提示词** — 可直接复制
2. **English Prompt** — 可直接复制
3. **手法标注** — 用了哪几招 / 哪几个维度，一句话说清为什么这么写
4. **负面提示词**（Negative Prompt）— 人物 / 写实类必给，直接复制，见 `de-ai-flavor.md`
5. **视频类额外给分镜表** — 景别 / 中文描述 / 运镜 / 视频提示词

用户没说要不要英文时，一律给中英双份。英文版不是逐字翻译，按英文摄影提示词的语序重写。

**关于负面提示词**：正向提示词写得再好，模型默认倾向仍是"棚拍、磨皮、HDR、完美对称"。负面提示词是把这些默认值**显式关掉**的唯一手段，属于必交付项，不是可选项。

**但负面词表必须按目标风格裁剪后再给，不能整份照抄。** `bokeh`、`shallow depth of field`、`teal and orange`、`golden hour glow`、`centered composition` 会跟影视感/恢弘感产线正面打架。裁剪规则见 `de-ai-flavor.md`。

**如果目标工具没有 negative_prompt 字段**：把关键约束折进正向提示词末尾，用中文写"避免磨皮、美颜、HDR、过度锐化、完美对称、3D 渲染感"。不要因为工具没这个字段就省略约束。

## 工具方言

本技能的提示词默认是 **Midjourney 方言**。其他工具语法不同，直接粘贴会掉信息。常见转换：

| MJ 写法 | 结构化字段工具 | 说明 |
|---|---|---|
| `--ar 16:9` | `aspect_ratio: "16:9"` | 常见比例普遍支持，优先用字段而非文字 |
| `--ar 3:2` | ⚠️ 多数工具**没有 3:2** | 退到 `4:3`（随手拍首选）或 `16:9` |
| `--style raw` | ❌ 无对应字段 | 降级成提示词正文里的 `raw` / `photographic` 描述词 |
| `8K` | `resolution: "2K"` | 走字段，别写在正文里 |
| 负面提示词块 | ❌ 多数工具无此字段 | 折进正向提示词末尾，见上 |
| `--no xxx` | ❌ 无对应 | 同上，改写成"避免 xxx" |

**投喂前先确认目标工具的 schema**，别假设语法通用。

**降分辨率是去 AI 味的手段，不是妥协。** 见 §A 铁律。

## 交付前自检

**闸门（要实际生成时，逐条过）**

- [ ] 信息充分吗？缺项已列清单问用户，没有脑补？
- [ ] 完整提示词（中英双份）已贴给用户过目，拿到明确同意？
- [ ] 模型 / 画幅 / 分辨率 / 张数 已确认，或已说明该工具不支持选模型？
- [ ] 提示词被改过之后，重新过了一遍确认？

**内容**

- [ ] 中英双份都在？
- [ ] 不完美项够 3–5 个，且都是具体名词不是抽象形容？
- [ ] **不完美项以物理瑕疵为主，不是成像缺陷？**
- [ ] **画面里要避开中文文字区域？**
- [ ] 英文版带 `raw` / `candid` / `imperfect` 锚点？
- [ ] **随机词全部来自 161 词库，没有自造的？**
- [ ] 附了负面提示词（或已折进正向提示词）？
- [ ] **已按目标工具的 schema 做过方言转换？**
- [ ] 视频提示词里没混入静态缺陷词？
- [ ] 视频提示词只写变化、不复述原图内容？
- [ ] 提醒了"生图有随机性"？
