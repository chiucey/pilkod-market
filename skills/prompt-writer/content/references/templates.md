### 代码审查
```
请审查以下[编程语言]代码：

```[语言]
[代码内容]
```

审查要点：
- 代码逻辑正确性
- 潜在bug和安全问题
- 性能优化建议
- 代码风格一致性
- 可读性和维护性

输出格式：问题列表 + 改进建议
```

- 数据流和执行流程
- 重要的设计模式或算法
```
