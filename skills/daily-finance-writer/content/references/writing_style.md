# 财经公众号写作风格指南

## 一、语言风格

### 1.1 核心原则
- **通俗易懂**：用简单直白的语言解释复杂财经概念
- **专业感**：保持财经自媒体的专业权威性
- **亲近感**：像朋友聊天一样与读者交流

### 1.2 表达技巧

#### 善用比喻
```
❌ 原文：A股三大指数集体下跌，跌幅超过2%
✅ 优化：A股今天"摔了一跤"，三大指数集体跳水，跌幅均超2%

❌ 原文：央妈放水5000亿
✅ 优化：央行"开闸放水"，一口气释放5000亿流动性
```

#### 适度网络化
```
可以使用：
- "内卷"、"躺平"、"破防"（描述市场情绪）
- "神仙打架"、"神仙打架凡人遭殃"（描述大企业竞争）
- "硬核"、"yyds"、"绝绝子"（正面评价）
- 避免过度娱乐化，保持财经严肃性
```

#### 数据可视化表达
```
❌ 原文：茅台股价从高点2600元下跌至1600元
✅ 优化：茅台股价"膝盖斩"，从2600元高点一路跌至1600元，
        市值蒸发超过一个"小米"的体量

❌ 原文：互联网行业裁员比例达到20%
✅ 优化：互联网行业"凛冬已至"，裁员潮汹涌，部分企业
        裁员比例高达两成——每10个人就有2个可能卷铺盖
```

## 二、标题撰写技巧

### 2.1 爆款标题公式

| 类型 | 公式 | 示例 |
|------|------|------|
| 数字悬念型 | 数字+悬念词 | 《跌了50%！这类资产终于见底了？》 |
| 对比冲突型 | 两个极端对比 | 《月薪3000和月薪30000的人，差距在哪？》 |
| 热点借势型 | 热点事件+解读 | 《巴菲特抄底日本，释放什么信号？》 |
| 疑问引导型 | 抛出问题 | 《楼市还能救起来吗？》 |
| 情绪共鸣型 | 戳痛点/爽点 | 《终于等到了！这类资产要起飞了》 |

### 2.2 标题避坑指南
- 避免过度标题党（内容要配得上标题）
- 不用模糊表述（少用"可能"、"也许"）
- 控制字数在15-25字之间
- 避免纯负面标题（如"完蛋了"、"暴跌"）

## 三、文章结构模板

### 3.1 深度解读型文章结构

```
【开篇 Hook】（100-150字）
- 用一个惊人的事实/数据/事件切入
- 制造悬念或引发共鸣

【事件背景】（300-400字）
- 交代事件来龙去脉
- 引入关键人物和公司
- 提供必要的背景知识

【核心分析】（600-800字）
- 多角度解读（政策、行业、企业、投资者角度）
- 引入专家观点或机构研报
- 数据支撑+逻辑推理

【趋势预判】（200-300字）
- 未来走势判断
- 对不同主体的影响
- 机会与风险提示

【结尾互动】（50-100字）
- 总结核心观点
- 引导读者评论互动
- 预告后续话题
```

### 3.2 热点汇总型文章结构

```
【今日概览】（150-200字）
- 用2-3句话概括今日市场整体情况
- 给出关键词/主题词

【热点一：XXX】（350-400字）
- 事件简述
- 核心要点分析
- 简短点评

【热点二：XXX】（350-400字）
（同上结构）

【热点三：XXX】（350-400字）
（同上结构）

【综合点评】（200-250字）
- 总结今日市场主线
- 展望明日重点关注

【互动话题】（50-100字）
- 抛出一个讨论问题
```

## 四、内容红线

### 4.1 绝对禁止
- ❌ 预测具体点位或股价
- ❌ 推荐具体股票或投资标的
- ❌ 传播未经证实的内幕消息
- ❌ 使用"涨停"、"必涨"、"稳赚"等绝对化用语
- ❌ 涉及政治敏感话题
- ❌ 损害特定企业/个人声誉

### 4.2 建议使用
- ✅ "值得关注"、"可以关注"
- ✅ "可能"、"或许"、"大概率"
- ✅ "从历史数据看"、"根据XX机构研究"
- ✅ "风险提示：投资有风险，入市需谨慎"

## 五、数据引用规范

### 5.1 可信来源优先级
1. 官方数据（国家统计局、央行、证监会等）
2. 权威机构（高盛、摩根士丹利、中金等研报）
3. 上市公司公告
4. 主流财经媒体（第一财经、财新、21世纪经济报道等）

### 5.2 数据呈现方式
```
原文：1-2月全国固定资产投资同比增长5.5%
优化：据国家统计局最新数据，1-2月全国固定资产投资
     同比增长5.5%，增速比去年同期加快0.4个百分点

原文：腾讯Q4营收1440亿
优化：腾讯最新财报显示，Q4营收达到1440亿元，
     同比增长19%，超出市场预期
```
