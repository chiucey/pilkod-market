# 每日财经热点追踪与深度文章创作技能

## 核心工作流程

### 步骤1：热点信息采集

使用 `batch_web_search` 工具搜索当日财经热点：

```
搜索维度：
1. A股市场今日行情与重大事件
2. 宏观经济政策最新动态
3. 头部企业重大新闻（腾讯、阿里、华为、比亚迪等）
4. 行业热点事件
5. 海外市场重要资讯

搜索关键词示例（当日日期）：
- "2026年4月4日 A股 行情"
- "2026年4月4日 财经政策"
- "2026年4月4日 企业动态"
```

### 步骤2：信息深度分析

对采集的信息进行筛选和深度分析：

1. **事件识别**：提取最具新闻价值的3-5个热点
2. **价值判断**：评估每个热点的传播潜力和读者兴趣
3. **角度选取**：确定文章切入角度和立意
4. **深度挖掘**：查找相关背景数据、历史对比、专家观点

### 步骤3：文章结构设计

根据内容选择合适的文章结构：

**结构模式A：单一深度解读型**
- 开头：热点事件引入（150字）
- 背景：事件来龙去脉（400字）
- 分析：多角度解读（800字）
- 结论：趋势预判或投资启示（200字）

**结构模式B：多事件汇总评析型**
- 开头：今日市场概览（200字）
- 主体：3-4个热点分述（每个300-400字）
- 结尾：综合点评与机会展望（200字）

### 步骤4：文章创作

按照选定结构创作文章，注意：

1. **标题撰写**：使用数字、悬念、对比等技巧，控制在20字以内
2. **语言风格**：
   - 通俗易懂，避免过于专业的术语
   - 适度使用网络化表达
   - 保持财经自媒体的专业感
3. **数据引用**：确保数据来源可靠，标注出处
4. **观点鲜明**：有明确立场，避免模棱两可

### 步骤5：质量检查

- 检查文章逻辑连贯性
- 核实关键数据准确性
- 确保有独特观点和深度分析
- 检查格式和错别字

## 输出格式

```
## 文章标题

### 摘要/导语
（50-100字的文章摘要）

### 正文
（完整文章内容）

### 配图建议
（标注需要配图的位置和图片类型）

### 标签建议
（3-5个文章标签）
```

## 质量标准

1. **时效性**：文章需紧扣当日热点
2. **深度**：有独特视角和深度分析，不做简单新闻复述
3. **可读性**：语言流畅，结构清晰，适合移动端阅读
4. **价值性**：提供有用的信息增量或投资/商业洞察
5. **合规性**：遵守财经自媒体内容规范

## 创作数量

每日创作1-2篇文章，优先选择当日最有价值的1-2个热点进行深度创作。
