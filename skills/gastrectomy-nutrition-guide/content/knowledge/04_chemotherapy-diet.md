# 化疗期间饮食调整

> 化疗是胃癌术后辅助治疗的重要组成部分，但化疗药物在杀伤癌细胞的同时也会影响正常细胞，带来一系列消化道反应。合理的饮食调整可以帮助患者更好地耐受化疗，保证营养摄入。

---

## 化疗常见消化道反应

### 常见症状

| 症状 | 发生时间 | 持续时间 |
|------|---------|---------|
| **恶心呕吐** | 化疗后数小时至数天 | 通常3-5天 |
| **食欲下降** | 化疗期间持续 | 因人而异 |
| **口腔溃疡** | 化疗后5-10天 | 1-2周 |
| **味觉改变** | 化疗期间 | 多数可恢复 |
| **腹泻** | 化疗后数天 | 数天至1周 |
| **便秘** | 化疗期间 | 因人而异 |
| **乏力** | 化疗后明显 | 1-2周 |

### 味觉改变的表现
- 金属味、苦味增加
- 某些食物味道变淡或消失
- 对某些食物突然反感

---

## 化疗期间饮食原则

### 总体原则

1. **想吃就吃**：不要强迫自己定时定量
2. **少量多餐**：胃部不适时小口进食
3. **选择能吃的**：化疗期间没有绝对禁忌
4. **保证蛋白质**：这是最重要的营养需求
5. **多喝水**：帮助药物代谢

### 恶心呕吐时的饮食

#### 推荐措施

| 措施 | 说明 |
|------|------|
| **少量多餐** | 每餐吃得少，吃的次数多 |
| **清淡饮食** | 避免油腻、辛辣、甜腻 |
| **温热食物** | 温热比热烫更易耐受 |
| **干性食物** | 米饭、馒头、饼干等 |
| **酸味食物** | 柠檬水、山楂（部分人有效） |
| **薄荷/姜** | 姜茶可能有帮助 |

#### 推荐食物

| 食物类型 | 示例 |
|---------|------|
| **主食** | 白粥、白米饭、馒头、苏打饼干 |
| **蛋白质** | 鸡蛋羹、蒸鱼、鸡胸肉（如果能吃） |
| **蔬果** | 苹果酱、梨、香蕉（熟软） |
| **饮品** | 淡盐水、姜茶、柠檬水、米汤 |

#### 应避免
- ❌ 油炸食物
- ❌ 强烈气味的食物
- ❌ 过甜、过油腻
- ❌ 进食时大量喝水

### 口腔溃疡时的饮食

#### 口腔护理

| 措施 | 说明 |
|------|------|
| **温和清洁** | 软毛牙刷，进食后漱口 |
| **盐水漱口** | 温盐水漱口，每日数次 |
| **避免刺激** | 不使用含酒精漱口水 |

#### 软烂流质饮食

| 食物类型 | 推荐 | 避免 |
|---------|------|------|
| **流质** | 米糊、藕粉、牛奶（温热） | 酸性果汁 |
| **软食** | 蛋羹、豆腐脑、土豆泥 | 硬的、脆的 |
| **蛋白质** | 鸡蛋羹、鱼肉茸、豆浆 | 坚果、炸物 |
| **蔬果** | 煮软的绿叶菜泥、苹果泥 | 生的蔬果 |

#### 推荐食谱
- **蛋花米糊**：稀米糊+蛋花，少盐
- **牛奶蒸蛋**：鸡蛋打散+牛奶（不过敏），蒸熟
- **蔬菜泥**：煮软的青菜+少许盐，捣成泥

### 味觉改变时的饮食

#### 应对策略

| 问题 | 应对方法 |
|------|---------|
| **金属味** | 使用塑料餐具，避免金属接触 |
| **苦味重** | 增加甜味（自然甜味）、改变调味 |
| **没味道** | 稍微增加调味、尝试不同口味 |
| **反感某种食物** | 暂时避免，换其他同类食物 |

#### 饮食调整
- 使用调味料增加风味（葱、姜、蒜需根据耐受）
- 尝试酸甜口味（山楂、醋需根据耐受）
- 食物温度适中
- 保持口腔清洁

## 化疗期间的营养支持

### 蛋白质需求

化疗期间蛋白质需求增加：
- **目标**：每天每公斤体重1.2-1.5克
- **示例**：60kg患者，每天需要72-90克蛋白质

| 高蛋白食物 | 每100g蛋白质含量 |
|-----------|----------------|
| 鸡蛋 | 13g |
| 鸡胸肉 | 31g |
| 鱼肉 | 18-25g |
| 豆腐 | 8g |
| 牛奶 | 3g |

### 口服营养补充剂（ONS）

当普通饮食无法满足需求时：

| 类型 | 使用场景 | 说明 |
|------|---------|------|
| **整蛋白型** | 食欲差、摄入不足 | 如安素、佳膳 |
| **短肽型** | 消化吸收差 | 更易吸收 |
| **高蛋白型** | 蛋白质需求高 | 适合化疗期间 |

#### 使用建议
- 两餐之间服用
- 可以加入粥、汤中
- 从少量开始，逐渐增量
- 冷热皆可服用

## 化疗周期饮食安排

### 化疗当天

| 时间 | 建议 |
|------|------|
| **早餐** | 清淡、易消化，如白粥+蛋 |
| **化疗前2小时** | 少量进食，避免空腹 |
| **化疗期间** | 多喝水，可配合营养补充剂 |
| **化疗后** | 根据反应调整，少量多次 |

### 化疗后5-7天（反应期）

- 以流质、半流质为主
- 少量多餐
- 优先保证水分和蛋白质
- 必要时使用肠内营养制剂

### 化疗后14-21天（恢复期）

- 逐步恢复正常饮食
- 加强营养，为下次化疗做准备
- 多摄入高蛋白食物
- 补充复合维生素

## 特殊情况处理

### 严重恶心呕吐

| 情况 | 建议 |
|------|------|
| **无法进食超过1天** | 联系医生，可能需要静脉营养 |
| **呕吐带血** | 立即就医 |
| **严重脱水** | 口服补液盐或就医 |

### 严重腹泻

| 情况 | 建议 |
|------|------|
| **每天>4次稀便** | 服用止泻药，补液盐 |
| **腹泻伴腹痛发热** | 立即就医 |
| **持续>3天** | 联系医生调整方案 |

### 便秘

| 建议 | 说明 |
|------|------|
| 增加膳食纤维 | 煮软的蔬菜、全谷物 |
| 多喝水 | 每天1500-2000ml |
| 适度活动 | 根据体力情况 |
| 必要时使用缓泻剂 | 遵医嘱 |

## 化疗期间饮食记录

### 建议记录内容

| 项目 | 内容 |
|------|------|
| **日期** | 哪天、第几次化疗后 |
| **进食情况** | 吃了什么、吃了多少 |
| **症状** | 恶心程度、呕吐次数等 |
| **体重** | 每周测一次 |
| **其他** | 特别的问题或发现 |

### 就医时告知医生

- 化疗期间体重变化
- 饮食摄入情况
- 严重的消化道症状
- 使用的营养补充剂

---

## 特别提醒

> ⚠️ **化疗期间营养支持非常重要，但请在医生/营养师指导下进行。**
>
> ⚠️ **如果连续3天无法进食或体重明显下降，请及时联系医生。**
>
> 💡 **化疗期间，目标是保证基本营养需求，不必过分追求"健康饮食"，能吃进去的就是好的。**
