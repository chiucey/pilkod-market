# 术后分阶段饮食指南

> 本指南依据 ESPEN（欧洲临床营养与代谢学会）及国内胃癌诊疗指南编制，适合全胃切除术后患者参考。

---

## 阶段一：流质饮食（术后1-2周）

### 适应人群
- 刚出院或术后2周内的患者
- 消化道吻合口尚未完全愈合

### 饮食原则
1. **少量多餐**：每日6-8餐，每餐50-100ml
2. **温度适宜**：温热为宜，避免过烫或过冷
3. **循序渐进**：从少量开始，根据耐受情况逐渐增加
4. **细细过滤**：所有食物需过滤，无渣无颗粒

### 推荐食物

| 食物类别 | 推荐 | 备注 |
|---------|------|------|
| **主食类** | 米汤、藕粉、面汤 | 稀薄、温和、易消化 |
| **蛋白类** | 蒸蛋羹（去蛋白块）、蛋花汤 | 优质蛋白来源 |
| **蔬果类** | 鲜榨果汁（苹果/梨/胡萝卜） | 过滤去渣 |
| **营养补充** | 肠内营养制剂（ONS） | 可咨询医生后添加 |

### 每日饮食示例

**早餐（7-8点）**
- 温开水或淡米汤 50ml

**加餐（9-10点）**
- 过滤果汁 50ml

**午餐（12点）**
- 稀藕粉 100ml

**加餐（14-15点）**
- 蛋花汤 50ml

**晚餐（18点）**
- 面汤（不加任何配料）100ml

**加餐（20点）**
- 肠内营养制剂或温开水

### 注意事项
- ❌ 禁止：牛奶、豆浆、碳酸饮料、油腻汤类
- ❌ 禁止：任何带渣食物、粗纤维蔬菜
- ⚠️ 如出现腹胀、恶心，减慢进食速度或减少单次量

## 阶段二：半流质饮食（术后2-4周）

### 适应人群
- 术后2-4周，伤口愈合良好
- 流质饮食耐受良好，无明显腹胀

### 饮食原则
1. **少量多餐**：每日5-6餐，每餐150-200ml
2. **软烂为主**：食物需软烂，便于消化
3. **干湿分离**：固体食物和液体分开进食
4. **细嚼慢咽**：每口食物咀嚼20-30次

### 推荐食物

| 食物类别 | 推荐 | 备注 |
|---------|------|------|
| **主食类** | 稀粥、烂面条、蒸馒头 | 煮烂煮软 |
| **蛋白类** | 嫩豆腐、蛋羹、鱼肉茸、鸡肉茸 | 细软易消化 |
| **蔬果类** | 土豆泥、胡萝卜泥、南瓜泥 | 煮熟压烂 |
| **调味** | 少量盐、酱油 | 清淡少油 |

### 每日饮食示例

**早餐（7-8点）**
- 稀白粥 150ml + 蒸蛋羹 1个

**加餐（10点）**
- 苹果泥 50g

**午餐（12点）**
- 烂面条（加少量青菜碎）100g + 鱼肉茸 30g

**加餐（15点）**
- 酸奶（低糖）100ml

**晚餐（18点）**
- 稀粥 150ml + 土豆泥 50g + 鸡胸肉茸 30g

**加餐（20点）**
- 肠内营养制剂 100ml

### 注意事项
- ❌ 禁止：油炸食物、坚果、硬米饭、生冷食物
- ❌ 禁止：粗纤维蔬菜（芹菜、韭菜）
- ⚠️ 出现倾倒综合征症状（见02文档）时，调整进食方式

## 阶段三：软食/细软食物（术后1-3个月）

### 适应人群
- 术后1-3个月
- 消化功能逐渐恢复，无严重并发症

### 饮食原则
1. **定时定量**：每日3餐+2次加餐
2. **细软易嚼**：所有食物切成小块或绞碎
3. **均衡营养**：注重蛋白质摄入
4. **避免刺激**：少辛辣、少油腻、少产气

### 推荐食物

| 食物类别 | 推荐 | 限量/避免 |
|---------|------|----------|
| **主食** | 软米饭、馒头、花卷、发面饼 | 避免硬米饭 |
| **肉类** | 蒸/炖的瘦肉、鱼肉、虾肉 | 避免油炸、煎炸 |
| **蛋类** | 蒸蛋、煮蛋、蛋花汤 | 避免油煎蛋 |
| **奶类** | 牛奶、酸奶、低脂奶 | 酸奶更易耐受 |
| **蔬菜** | 冬瓜、丝瓜、西葫芦、土豆、胡萝卜 | 煮软切小块 |
| **水果** | 苹果、梨、香蕉（熟软） | 避免酸性太强 |
| **油脂** | 植物油限量（每日<20g） | 避免动物油过多 |

### 每日饮食示例

**早餐（7-8点）**
- 软米饭半碗 + 蒸蛋1个 + 炒青菜（少油）少许

**加餐（10点）**
- 酸奶 150ml + 苏打饼干 2片

**午餐（12点）**
- 软米饭 1碗 + 清蒸鱼 50g + 土豆胡萝卜（炖烂）各50g

**加餐（15点）**
- 香蕉泥 半根

**晚餐（18点）**
- 馒头1个 + 炖鸡胸肉（切小块）50g + 冬瓜汤 1碗

**加餐（20点）**
- 温牛奶 200ml

### 注意事项
- ❌ 避免：糯米食品、年糕、汤圆（不易消化）
- ❌ 避免：辛辣刺激性食物
- ❌ 避免：碳酸饮料、咖啡、浓茶
- ⚠️ 细嚼慢咽，每餐20-30分钟

## 阶段四：逐步过渡到普通饮食（术后3个月以上）

### 适应人群
- 术后3个月以上
- 饮食耐受良好，体重稳定

### 饮食原则
1. **接近正常三餐**：每日3-4餐
2. **食物多样化**：逐步恢复各类食物
3. **补充关键营养素**：终身注意维生素B12、钙、铁的补充
4. **终身饮食习惯**：少量多餐、细嚼慢咽

### 食物选择

| 食物类别 | 推荐 | 注意事项 |
|---------|------|----------|
| **主食** | 各类主食均可 | 仍以软烂为主 |
| **蛋白** | 鱼、肉、蛋、豆制品 | 细嚼 |
| **蔬菜** | 逐步增加种类 | 初期仍需煮软 |
| **水果** | 逐步恢复正常 | 注意酸性水果耐受 |
| **调味** | 可恢复正常调味 | 仍需清淡 |

### 长期饮食建议

1. **蛋白质优先**：每餐保证优质蛋白
2. **补充维生素**：B12、钙、铁需特别关注
3. **定时体检**：监测营养状况
4. **记录饮食**：如有不适，记录食物日记

## 常见问题快速参考

| 问题 | 解决方案 |
|------|---------|
| 吃不下太多 | 浓汤类、营养密度高的食物 |
| 经常腹泻 | 减少乳制品、避免生冷 |
| 体重持续下降 | 增加高蛋白食物、咨询营养师 |
| 饭后腹胀 | 减慢速度、少吃产气食物 |
