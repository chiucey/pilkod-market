# 危险信号与就医指引

> ⚠️ **重要提示**：以下内容涉及可能危及生命的情况。当患者描述以下症状时，请立即建议就医，并提供相应指引。**

---

## 必须立即就医的紧急情况

### 消化道出血

| 症状 | 描述 |
|------|------|
| **呕血** | 呕吐物呈红色或咖啡渣样 |
| **黑便** | 大便呈黑色、柏油样 |
| **血便** | 大便带血，呈鲜红或暗红 |

**可能原因**：吻合口溃疡、应激性溃疡、食管胃底静脉曲张破裂

**紧急程度**：🔴 立即就医（拨打120或前往急诊）

### 消化道穿孔

| 症状 | 描述 |
|------|------|
| **剧烈腹痛** | 突然发作的剧烈腹痛，呈持续性 |
| **板状腹** | 腹部硬如木板，不敢触碰 |
| **发热** | 体温>38.5℃ |
| **全身症状** | 面色苍白、出冷汗、心慌 |

**可能原因**：吻合口漏、手术部位穿孔

**紧急程度**：🔴 立即就医（拨打120）

### 严重梗阻

| 症状 | 描述 |
|------|------|
| **剧烈腹胀** | 腹部明显膨隆，无法忍受 |
| **呕吐** | 反复呕吐，呕吐物含或不含胆汁 |
| **停止排气排便** | 长时间（>24小时）无排气排便 |
| **腹痛** | 进行性加重的腹痛 |

**可能原因**：粘连性肠梗阻、吻合口狭窄

**紧急程度**：🔴 立即就医

### 其他紧急情况

| 情况 | 症状 |
|------|------|
| **严重脱水** | 频繁呕吐/腹泻导致口干、尿少、意识模糊 |
| **低血糖危象** | 意识丧失、大汗淋漓、颤抖 |
| **过敏反应** | 皮疹、呼吸困难、喉头水肿 |

## 应尽快就医的情况（24小时内）

### 感染迹象

| 症状 | 需警惕 |
|------|-------|
| **发热** | 体温>38℃持续24小时以上 |
| **伤口红肿** | 手术伤口发红、肿胀、渗液 |
| **咳嗽咳痰** | 伴有发热、胸痛 |
| **尿路症状** | 尿频、尿急、尿痛伴发热 |

### 营养相关严重问题

| 症状 | 需警惕 |
|------|-------|
| **严重厌食** | 连续3天几乎无法进食 |
| **体重急剧下降** | 一周内体重下降>5% |
| **严重腹泻** | 每天>6次稀便，持续>3天 |
| **严重便秘** | >7天无排便，伴有腹胀腹痛 |

### 化疗相关问题

| 症状 | 需警惕 |
|------|-------|
| **严重恶心呕吐** | 口服止吐药无法控制 |
| **口腔溃疡** | 影响进食，>3处溃疡 |
| **严重骨髓抑制** | 发热伴白细胞降低 |
| **肝肾功能异常** | 疲乏、食欲不振伴检查异常 |

## 需要门诊就诊的情况（一周内）

### 消化道症状

| 症状 | 说明 |
|------|------|
| **反复倾倒综合征** | 每周发作>3次，影响生活 |
| **持续腹胀** | 不缓解的腹胀感 |
| **反酸烧心** | 胸骨后烧灼感，影响睡眠 |
| **吞咽困难** | 进食固体食物时有阻挡感 |

### 营养相关问题

| 症状 | 说明 |
|------|------|
| **体重持续下降** | 每月体重下降>2kg |
| **贫血症状** | 乏力、头晕、面色苍白 |
| **骨质疏松症状** | 腰背痛、身高变矮、易骨折 |

### 其他症状

| 症状 | 说明 |
|------|------|
| **疲劳不缓解** | 休息后仍感疲劳 |
| **睡眠障碍** | 严重失眠或睡眠质量差 |
| **情绪问题** | 持续焦虑、抑郁 |

## 就医准备指南

### 急诊准备

当需要紧急就医时：

1. **携带物品**
   - 就诊卡、医保卡
   - 既往病历资料
   - 目前服用药物清单
   - 紧急联系人电话

2. **描述症状要点**
   - 什么时候开始？
   - 主要不适是什么？
   - 有没有吃什么特殊东西？
   - 之前有没有类似情况？

3. **注意事项**
   - 不要自行服用止痛药（可能掩盖症状）
   - 不要自行服用止泻药（如果是感染可能加重）
   - 保留呕吐物和粪便样本供医生查看

### 门诊准备

1. **提前记录**
   - 症状出现的时间和变化
   - 近期的饮食情况
   - 体重变化
   - 服用药物情况

2. **准备问题**
   - 想问医生的问题列出来
   - 带上相关检查报告

3. **复诊要点**
   - 记清楚下次复诊时间
   - 需要做的检查提前预约

## 常见症状自查表

### 轻微 → 观察

| 症状 | 建议 |
|------|------|
| 偶尔腹胀 | 调整进食速度，少吃产气食物 |
| 轻微反胃 | 少量多餐，避免躺下即睡 |
| 偶尔腹泻（1-2次/天） | 清淡饮食，观察 |
| 食欲稍差 | 变换食物种类，少量多餐 |

### 中度 → 咨询

| 症状 | 建议 |
|------|------|
| 持续腹胀>3天 | 联系医生或门诊就诊 |
| 倾倒综合征每周2-3次 | 调整饮食，预约营养科 |
| 体重1周内下降1-2kg | 加强营养，门诊复查 |
| 口腔溃疡影响进食 | 门诊处理，对症处理 |

### 重度 → 立即就医

| 症状 | 行动 |
|------|------|
| 呕血/黑便/血便 | 🔴 立即急诊 |
| 剧烈腹痛伴发热 | 🔴 立即急诊 |
| 严重脱水 | 🔴 立即急诊 |
| 意识模糊 | 🔴 立即急诊/拨打120 |

## 心理支持资源

### 什么时候需要心理支持

- 持续的焦虑或恐惧
- 无法入睡或早醒
- 对饮食产生恐惧
- 社交活动明显减少
- 有消极想法

### 可以寻求的帮助

| 资源 | 说明 |
|------|------|
| 主治医生 | 可推荐心理科会诊 |
| 医院心理咨询 | 肿瘤心理门诊 |
| 病友互助组织 | 情感支持、经验分享 |
| 家属支持 | 家属也需要关注自己的情绪 |

---

## 重要提醒

> ⚠️ **本指南不能替代专业医疗建议。如果您不确定症状的严重程度，请致电您的医疗团队或就医咨询。**
>
> ⚠️ **当症状突然加重或出现新的严重症状时，请不要等待，立即就医。**
>
> 💡 **与您的医疗团队保持良好的沟通非常重要，他们最了解您的具体情况，能给出最适合的建议。**
