# 每日食谱参考

> 本文档提供不同恢复阶段的食谱参考，帮助患者和家属规划每日饮食。食谱仅供参考，请根据个人耐受情况和医生建议调整。

---

## 食谱使用说明

### 食谱分阶段

| 阶段 | 适用时间 | 餐次 |
|------|---------|------|
| 流质食谱 | 术后1-2周 | 6-8餐 |
| 半流质食谱 | 术后2-4周 | 5-6餐 |
| 软食食谱 | 术后1-3个月 | 3餐+2加餐 |
| 普通食谱 | 术后3个月以上 | 3餐+2加餐 |

### 营养小贴士
- 🥚 每餐尽量包含蛋白质食物
- 🥬 蔬菜水果要煮软或做成泥
- 💧 少油少盐，清淡为主
- 🍚 主食粗细搭配

## 流质食谱（术后1-2周）

### 每日饮食安排

| 时间 | 食物 | 量 |
|------|------|---|
| 7:00 | 温开水/淡米汤 | 50-100ml |
| 9:00 | 过滤苹果汁 | 50-100ml |
| 11:00 | 稀藕粉（无糖） | 50-100ml |
| 13:00 | 温开水/米汤 | 50-100ml |
| 15:00 | 蛋花汤（去蛋花） | 50-100ml |
| 17:00 | 面汤（清汤） | 50-100ml |
| 19:00 | 过滤梨汁 | 50-100ml |
| 21:00 | 肠内营养制剂或温水 | 50-100ml |

### 详细做法

#### 淡米汤
1. 大米50g，洗净
2. 加水1000ml，大火煮沸
3. 转小火煮30分钟
4. 取米汤部分，过滤
5. 温热服用

#### 过滤苹果汁
1. 苹果1个，洗净去皮去核
2. 切成小块
3. 加少量水煮软
4. 用料理机打碎
5. 用细筛或纱布过滤
6. 温热服用

#### 稀藕粉
1. 藕粉1-2平勺（约10g）
2. 用少量凉开水调开
3. 冲入沸水，边冲边搅拌
4. 稀薄透明即可
5. 温热服用

#### 蛋花汤
1. 鸡蛋1个，打散
2. 锅中加水烧开
3. 蛋液慢慢淋入，形成蛋花
4. 再煮1-2分钟
5. 过滤掉大块蛋花
6. 只取汤汁，温热服用

## 半流质食谱（术后2-4周）

### 每日饮食安排

| 时间 | 食物 | 量 |
|------|------|---|
| 7:30 | 白粥 + 蒸蛋羹 | 100ml + 1个蛋 |
| 10:00 | 苹果泥或酸奶 | 50-100g |
| 12:00 | 烂面条 + 鱼肉茸 + 青菜泥 | 100g + 30g + 30g |
| 15:00 | 牛奶或豆花 | 100-150ml |
| 18:00 | 稀粥 + 土豆泥 + 鸡胸肉茸 | 150ml + 50g + 30g |
| 20:00 | 肠内营养制剂或酸奶 | 100-150ml |

### 详细做法

#### 蒸蛋羹
1. 鸡蛋1个，打散
2. 加入温开水（约蛋液体积的1.5倍）
3. 少盐，搅拌均匀
4. 撇去浮沫
5. 蒸8-10分钟至凝固
6. 可加几滴香油

#### 烂面条
1. 细面条50g
2. 锅中水烧开
3. 下面条煮软（约10分钟）
4. 加少量切碎的青菜叶
5. 可加少量酱油调味
6. 面条用筷子夹断成小段

#### 土豆泥
1. 土豆1个（约150g），去皮
2. 切成小块
3. 蒸熟或煮熟
4. 趁热压成泥
5. 可加少量牛奶和黄油调软

#### 鱼肉茸
1. 刺少的鱼（如鲈鱼、鳜鱼）50g
2. 蒸熟
3. 小心去骨去皮
4. 用勺子压成茸
5. 可加少量鸡汤调味

## 软食食谱（术后1-3个月）

### 每日饮食安排

| 时间 | 食物 | 量 |
|------|------|---|
| 7:30 | 软米饭 + 蒸蛋 + 清炒青菜 | 半碗 + 1个 + 50g |
| 10:00 | 酸奶 + 饼干 | 150ml + 2片 |
| 12:00 | 软米饭 + 清蒸鱼 + 炖蔬菜 | 1碗 + 60g + 100g |
| 15:00 | 水果泥（苹果/香蕉） | 100g |
| 18:00 | 馒头 + 红烧肉（少油）+ 汤 | 1个 + 40g + 1碗 |
| 20:00 | 牛奶 | 200ml |

### 推荐菜谱

#### 清蒸鱼
1. 鲈鱼或鳜鱼1段（约100g）
2. 鱼身划几刀
3. 姜丝、葱段铺在鱼上
4. 蒸10-15分钟
5. 出锅后淋少许酱油
6. 挑出姜丝葱段

#### 炖蔬菜
1. 胡萝卜、土豆、南瓜各30g
2. 切成小丁（1cm大小）
3. 加少量水炖软
4. 可加少许盐

#### 红烧肉（少油版）
1. 瘦肉（如里脊）50g
2. 切成1cm小块
3. 少油煸炒
4. 加少量酱油、糖、水
5. 小火炖至软烂
6. 注意去油

## 普通食谱（术后3个月以上）

### 每日饮食安排

| 时间 | 食物 | 量 |
|------|------|---|
| 7:30 | 软米饭 + 煎蛋 + 凉拌菜 | 1碗 + 1个 + 50g |
| 10:00 | 豆浆 + 全麦面包 | 200ml + 1片 |
| 12:00 | 软米饭 + 炒肉片 + 炒青菜 + 汤 | 1碗 + 60g + 100g + 1碗 |
| 15:00 | 水果（苹果/梨/香蕉） | 100-150g |
| 18:00 | 面食 + 炖肉 + 炒蔬菜 | 1碗 + 60g + 100g |
| 20:00 | 酸奶或牛奶 | 200ml |

### 推荐菜谱

#### 番茄炒蛋
1. 番茄1个，切块
2. 鸡蛋1个打散
3. 少油炒蛋，盛出
4. 少油炒番茄至软
5. 加入鸡蛋翻炒
6. 加少许盐调味

#### 肉末豆腐
1. 嫩豆腐100g，切小块
2. 瘦肉末30g
3. 少油煸炒肉末
4. 加入豆腐轻炒
5. 加少量水、酱油煮入味
6. 水淀粉勾薄芡

#### 清炒时蔬
1. 时令蔬菜100g
2. 洗净切段
3. 大火快炒
4. 加少许盐
5. 保持蔬菜脆嫩

## 营养补充建议

### 每日营养目标

| 营养素 | 推荐量 | 说明 |
|--------|-------|------|
| 能量 | 25-30kcal/kg/天 | 保持体重 |
| 蛋白质 | 1.2-1.5g/kg/天 | 防止肌肉流失 |
| 钙 | 1000-1200mg/天 | 预防骨质疏松 |
| 铁 | 15-20mg/天 | 预防贫血 |
| 维生素D | 800-1000IU/天 | 促进钙吸收 |

### 常见营养问题

| 问题 | 解决方案 |
|------|---------|
| 吃不下太多 | 选择营养密度高的食物 |
| 体重下降 | 增加优质蛋白，必要时ONS |
| 贫血 | 多吃红肉、动物血，补充铁剂 |
| 骨质疏松 | 补钙+维生素D，多晒太阳 |

## 食谱调整原则

1. **循序渐进**：根据个人耐受情况逐步调整
2. **因人而异**：每个人对食物的耐受不同
3. **记录反应**：记录吃了什么、有什么反应
4. **与医生沟通**：有任何疑问及时咨询
