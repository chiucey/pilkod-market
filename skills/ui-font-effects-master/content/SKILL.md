# UI与字体字幕特效生成大师

## 技能概述

本技能专注于多场景UI设计与视觉效果生成，核心能力包括：

1. **智能UI生成**：登录页、首页、列表页、详情页、仪表盘等完整页面
2. **字体字幕设计**：多风格字体方案、中英文规范排版
3. **粒子特效制作**：汇聚、消散、流光、漂浮、像素化等动态效果

## 粒子特效系统

### 特效类型
| 特效名称 | 效果描述 | 参数范围 |
|----------|----------|----------|
| particle-gather | 粒子汇聚成字 | 数量 50-500，速度 1-10 |
| particle-disperse | 粒子消散效果 | 数量 100-1000，透明度 0.1-1 |
| particle-flow | 流光飘动 | 方向 0-360°，长度 20-200px |
| particle-float | 漂浮上升 | 高度 50-500px，周期 2-10s |
| particle-pixelate | 像素化效果 | 格子 4-32px，扫描速度 1-5 |
| particle-glow | 发光呼吸 | 半径 10-100px，频率 1-5s |

### 参数配置
```javascript
{
  particleCount: 200,    // 粒子数量
  particleSpeed: 3,      // 运动速度
  particleColor: '#6366F1', // 粒子颜色
  particleOpacity: 0.8,  // 透明度
  particleSize: 3,        // 粒子尺寸
  animationDuration: 3    // 动画时长(秒)
}
```
