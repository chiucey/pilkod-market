# 赛车比赛综合分析技能

## 技能定位

本技能提供专业的赛车比赛分析服务，涵盖多种国际顶级赛事，包括但不限于：

- **F1（一级方程式）**：分站赛策略、车队战术、车手表现分析
- **GT3耐力赛**：长距离赛事战术、换人策略、车辆管理
- **NLS（纽博格林耐力赛）**：纽博格林北环赛道专项分析
- **DTM（德国房车大师赛）**：房车赛战术与竞争格局
- **MotoGP（摩托车大奖赛）**：两轮赛事动力学分析
- **世界摩托车锦标赛**：Moto2/Moto3梯队分析
- **WRC（世界拉力锦标赛）**：拉力赛段策略、成绩解析

## 核心能力

### 1. 比赛策略分析

**分析维度**：
- 进站时机决策（pit stop timing）
- 轮胎策略选择（硬胎/中性胎/软胎）
- 燃油管理策略
- 赛道位置争夺战术
- 套圈与被套圈处理
- 安全车/红旗应对

**分析方法**：
- 对比同赛道历史数据
- 分析车队策略组决策逻辑
- 评估天气因素影响
- 解读DRS使用时机

### 2. 赛程安排解读

**信息维度**：
- 排位赛/正赛时间表
- 赛道特点分析（弯道数量、直道长度、海拔变化）
- 天气预判对赛程的影响
- 各分站积分规则差异

### 3. 赛后名次分析

**分析内容**：
- 最终排名与起点位置对比（净收益/损失）
- 关键超车瞬间解析
- 事故与判罚影响评估
- 车队/车手积分榜变化

### 4. 视频内容分析

当用户提供B站等平台视频链接时：
1. 提取视频核心内容要点
2. 识别视频中的关键比赛事件
3. 归纳视频分析的风格与视角
4. 补充相关背景信息

## 工作流程

### Step 1: 信息获取

- 解析用户提供的视频链接（如B站BV号）
- 根据赛事类型搜索最新比赛信息
- 确定分析重点（策略/表现/排名/赛程）

### Step 2: 数据处理

对于不同赛事类型：

**F1/DTM分析**：
- 进站圈数与时间差
- 轮胎策略组合
- 车载无线电信息解读
- 车速对比（相对差距）

**耐力赛（GT3/NLS）分析**：
- 车组换人时机
- 夜间赛段特殊考量
- 车辆可靠性管理
- 积分计算规则

**摩托车赛事分析**：
- 刹车点选择
- 倾角控制
- 弯道线路选择
- 车手对抗风格

### Step 3: 输出呈现

**结构化分析报告**：
```
## 比赛概览
- 赛事/分站
- 天气条件
- 总圈数/赛程

## 关键事件时间线
| 圈数 | 事件 | 影响分析 |

## 策略分析
### 进站策略对比
### 轮胎使用
### 关键时刻决策

## 最终排名
| 名次 | 车手/车队 | 完赛时间 | 关键亮点 |

## 总结与展望
```
