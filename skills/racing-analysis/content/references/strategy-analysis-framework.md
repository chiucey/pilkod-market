# 赛车策略分析框架

## 一级方程式策略分析框架

### 1. 进站时机决策模型

#### 理论最优进站圈
```
最佳窗口 = 轮胎性能衰减拐点前1-2圈
关键指标：
- 轮胎损耗指数（ Tire Degradation Index, TDI）
- 赛道温度影响系数
- 对手进站窗口分析
```

#### 进站时机类型

| 类型 | 适用场景 | 风险等级 | 案例 |
|------|----------|----------|------|
| 早停（Undercut） | 追上对手时 | 中 | 用新胎追上旧胎对手 |
| 晚停（Overcut） | 赛道位置有利 | 中 | 利用交通掩护延长 stint |
| 双重停站 | 长距离/高损耗赛道 | 低 | 标准策略 |
| 单停策略 | 特定条件 | 高 | 赌安全车或天气 |

#### Undercut分析要素
- 圈速差：新胎 vs 旧胎（通常1-2秒/圈）
- 交通风险：出站后遇到慢车概率
- 位置收益：能否超越前车

#### Overcut分析要素
- 赛道位置：能否利用前车交通
- 出站时机：是否在对手进站窗口内
- 旧胎剩余性能：是否足够坚持

### 2. 轮胎策略矩阵

#### 轮胎类型选择（以倍耐力2024为例）

| 配方 | 名称 | 抓地力 | 耐久性 | 适用条件 |
|------|------|--------|--------|----------|
| C1 | 硬胎 | 低 | 最高 | 高磨损赛道（银石） |
| C2 | 中性胎 | 中 | 中高 | 大多数赛道 |
| C3 | 软胎 | 高 | 中 | 低磨损/排位赛 |
| C4 | 超软胎 | 最高 | 低 | 街道赛/排位赛 |
| C5 | 极软胎 | 极高 | 最低 | 特定高速赛道 |

#### 策略组合示例

**双停标准策略**：
```
起步胎 → 换胎时机 → 第二套胎 → 换胎时机 → 完赛胎
软胎(10-15圈) → 中性胎(20-30圈) → 硬胎(收官)
```

**单停激进策略**（需特定条件）：
```
中性胎起步 → 全程约45-50圈 → 完赛
适用：赛道温度低/磨损慢/无安全车
```

### 3. 比赛关键时刻识别

#### 决定性事件分类

**结构性事件**：
- 安全车出勒（全场黄旗）
- 红旗（比赛暂停）
- 赛道变化（新增DRS区）
- 天气骤变

**竞争性事件**：
- 关键超车（领先集团）
- 进站失误（换胎延误）
- 判罚（5秒/10秒加时）
- 车辆故障（机械故障）

#### 时间损失计算
```
总时间损失 = 进站基础时间（约2秒）
           + 换胎时间（通常2-3秒）
           + 出站距离损失（5-15秒）
           + 交通延误（变量）
```

### 4. 车队无线电解码

#### 常见指令类型

| 指令类型 | 英文原文 | 含义 |
|----------|----------|------|
| 推进指令 | "Push now" / "You can push" | 全速冲刺 |
| 保守指令 | "Manage tires" / "Lift and coast" | 省胎省油 |
| 追击指令 | "We need to close the gap" | 缩小差距 |
| 防守指令 | "Maintain gap to car behind" | 保持位置 |
| 进站指令 | "Box box" / "In lap" | 立即进站 |

#### 车队策略暗语
- "Save the engine" → 降低转速保护引擎
- "Battery mode" → 节省ERS能量
- "Fuel target" → 燃油节省模式
- "Tire management" → 延长轮胎寿命

### 耐力赛策略框架

#### 1. Stint管理原则

**Stint长度计算**：
```
最优Stint = (油箱容量 / 每圈油耗) - 安全余量
典型值：约14-18圈（根据赛道不同）
```

**换人规则考量**：
- 最低连续驾驶时间限制
- 换人窗口期（通常10-20分钟）
- 夜间驾驶资格认证

#### 2. 夜间赛段特殊分析

**夜间特有风险**：
- 能见度降低（依赖照明系统）
- 温度变化影响轮胎性能
- 车手疲劳累积
- 视野判断差异

**夜间策略要素**：
- 车手轮换频率增加
- 灯光系统检查
- 交通警示加强

#### 3. 车辆可靠性管理

**关键监控指标**：
- 刹车温度（碳刹损耗）
- 轮胎压力（热衰减）
- 油温/水温（过热警告）
- 混合动力状态（ERS可用性）

### 摩托车赛事分析框架

#### 1. 刹车点与倾角控制

**关键数据点**：
- 最高速点（Top Speed）
- 刹车点位置（Brake Marker）
- 入弯倾角（Lean Angle）
- 出弯加速点（Acceleration Point）

#### 2. 线路选择策略

**进攻型线路**：
- 晚刹车
- 弯中换线
- 晚开油门

**防守型线路**：
- 早刹车
- 保守入弯
- 早开油门保持稳定

#### 3. 胎耗与比赛节奏

**MotoGP轮胎策略**：
```
前胎：偏向倾角抓地
后胎：偏向加速牵引
软硬选择依据：
- 赛道温度
- 比赛长度（MotoGP约45分钟）
- 车手风格
```

### 拉力赛事分析框架

#### 1. 赛段时间分析

**关键指标**：
```
Delta Time = 本赛段时间 - 参考时间
负值 = 领先
正值 = 落后
```

**赛段类型适配**：
- 柏油赛段：注重刹车和加速
- 砂石赛段：注重滑移控制
- 冰雪赛段：注重抓地判断

#### 2. 轮胎选择矩阵

| 赛段类型 | 轮胎类型 | 胎压设置 |
|----------|----------|----------|
| 干柏油 | 光头胎/半热熔 | 高胎压（2.2-2.4 bar） |
| 湿柏油 | 雨胎 | 低胎压（1.8-2.0 bar） |
| 砂石 | 越野胎 | 低胎压（1.6-1.8 bar） |
| 冰雪 | 钉胎 | 专用规格 |

#### 3. 路书（Pacenotes）效率

**时间节省计算**：
- 熟悉路书：减少犹豫时间
- 节奏稳定性：减少失误修复
- 预判能力：提前调整姿态

### 数据可视化要素

**推荐图表类型**：

1. **进站时机图**：横向柱状图展示各车手进站圈
2. **圈速对比图**：分阶段折线图对比不同stint表现
3. **赛道位置变化图**：随圈数变化的排名波动
4. **策略矩阵热力图**：轮胎类型×进站时机组合

**图表配色建议**：
- 领先集团：红色系
- 中游集团：蓝色系
- 落后集团：灰色系
- 安全车时段：黄色底色
- 红旗时段：红色底色
