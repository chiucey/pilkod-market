# df_salary_retail — 代发C端零售指标分析

## 定位
专门分析**拿到代发权的个人客户**在行内的资产提升、产品持有、活跃程度，回答"发了薪的人在我行留了多少钱、买了什么、还活跃吗"。

## 核心分析维度

### 维度1：代发客户AUM与存款分析

| 指标 | 含义 | 分析价值 |
|---|---|---|
| 代发客户储蓄存款余额 | 发薪户在交行的储蓄总量 | 核心负债指标 |
| 代发客户AUM净增 | 发薪户的整体资产管理规模净增 | 综合价值 |
| 人均AUM | AUM / 代发客户数 | 客群质量 |
| 存款留存率（发薪日T+N）| 发薪日T+N天后资金仍在本行的比例 | 留存能力 |
| 活期占比 | 活期存款 / 总存款 | 资金稳定性 |

**分析方法：**
- 和系统均值比（高于均值=好）
- 和系统前一名比（差距有多大）
- 趋势：近3个月/6个月走势

### 维度2：代发客户产品渗透分析

| 产品 | 核心指标 |
|---|---|
| 财富产品（理财/基金/保险） | 持有人数 / 占比 / 系统排名 |
| 贷款产品 | 持有人数 / 占比 / 系统排名 |
| 个养账户 | 开户人数 / 渗透率 |
| 信用卡 | 持有卡数 / 渗透率 |
| 三方支付绑卡 | 支付宝/微信绑卡率 |
| 三方存管 | 签约人数 |

**分析方法：**
- 系统排名法：各指标逐一与系统均值对比
- 差距放大法：低于均值最多的产品→优先改进

### 维度3：代发客户活跃度MAU分析

| 活跃分层 | 定义 | 改善目标 |
|---|---|---|
| 高活户 | 当月登录APP | 维护重点 |
| 低活跃户 | 有登录但非常态 | 激活 |
| 睡眠户 | 超过90天未登录 | 流失前兆 |
| 未注册户 | 注册后从未登录 | 获客未转化 |

**分代发类型统计：**
- 代发工资（最大基数）
- 代发奖金（季节性，春节后流失率高）
- 代发补贴/报销
- 代发社保/养老金
- 代发公积金

### 维度4：代发客户出金结构分析（核心创新维度）

| 出金类型 | 占比高=预警信号 |
|---|---|
| 消费出金占比 | 高=资金流入消费，资金沉淀好 |
| 还款出金占比 | 中性 |
| 三方机构投资出金 | 高=流向他行财富平台 |
| **他行同名转账占比** | **极高预警=即将流失** |

> 经验规律：他行同名转账>25% = 该客户即将流失

### 维度5：代发客户分层经营分析

| 客户层 | 划分标准 | 分析重点 |
|---|---|---|
| 私银客户 | AUM≥600万 | 高净值深耕 |
| 沃德客户 | AUM≥50万 | 价值提升 |
| 中端客户 | AUM≥10万 | 潜力挖掘 |
| 基础客户 | 普通代发户 | 基础服务 |

**分析方法：**
- 各层客户数 × 占比 × 系统排名
- 增量贡献度：各层新增客户中，有多少来自代发转化

## 新增：代发客户活跃度MAU四层分析模型

基于月均登录行为，将代发客户分为四层，是判断"睡眠户"的核心：

| 层级 | 定义 | 运营价值 |
|---|---|---|
| **高活跃** | 当月有登录/交易行为 | 核心经营户，重点维护 |
| **低活跃** | 有注册但当月无登录 | 激活对象，发送权益触发 |
| **睡眠户** | 长期（≥3个月）无登录 | 即将流失，需专项唤醒 |
| **未注册** | 注册后从未登录 | 开卡后未激活，重点跟进 |

**MAU渗透率计算：**
```
MAU渗透率 = 当月登录的代发客户数 / 代发总客户数
```

> ⚠️ **关注点**：低活跃+睡眠户占比>40%，意味着代发只是"空户"，没有真正经营

## 新增：代发资金T+N留存分析

资金留存的本质是"发薪日之后钱还在不在本行"：

| 指标 | 定义 | 健康标准 |
|---|---|---|
| **T+0留存率** | 发薪当日末的本行资金占比 | 反映绑定强度 |
| **T+3留存率** | 发薪后3天本行资金占比 | 反映短期留存 |
| **T+7留存率** | 发薪后7天本行资金占比 | 反映中期留存 |
| **T+30留存率** | 发薪后30天本行资金占比 | 反映长期留存 |

**分析重点：**
- T+7 vs T+30差距大=资金在流出
- 行业差异：传统制造/建筑→过年过节大量流出；医公教→相对稳定
- 同业对比：招行代发留存率普遍高于本行

在原有6品基础上，完整产品图谱：

| 产品大类 | 具体产品 | 渗透率优先级 |
|---|---|---|

| **综合类** | 企微添加、沃德/私银卡、卡片等级 | 客户关系标志 |
