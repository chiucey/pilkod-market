# 视频字幕生成器

自动为含有语音的视频文件生成并添加同步字幕。

## 支持的视频格式

- MP4, AVI, MOV, MPEG, MKV, FLV, WMV, WebM

## 工作流程

### 步骤 1：接收视频文件

接收用户上传的视频文件路径和字幕样式参数。

### 步骤 2：提取音频

使用 FFmpeg 将视频中的音频提取为 WAV 格式（16kHz，单声道）以适配语音识别模型。

### 步骤 3：语音识别

使用 Whisper 模型对音频进行语音识别，生成带有时间戳的文本片段。

### 步骤 4：生成字幕文件

将识别结果转换为 SRT 格式的字幕文件，包含序号、开始时间、结束时间和文本内容。

### 步骤 5：烧录字幕（可选）

使用 FFmpeg 将字幕文件烧录到视频中，生成带字幕的新视频文件。

## 字幕样式选项

| 参数 | 说明 | 默认值 |
|------|------|--------|
| font_size | 字体大小 | 48 |
| font_color | 字体颜色（白色） | #FFFFFF |
| bg_color | 背景颜色（半透明黑色） | #000000CC |
| position | 字幕位置（底部居中） | bottom |
| margin | 距底部边距 | 50 |

## 输出产物

1. **字幕文件** - `.srt` 格式，可在播放器中使用
2. **带字幕视频**（可选）- 烧录字幕后的新视频文件

## 技术栈

- **Python 3.8+**
- **Whisper** - OpenAI 语音识别模型
- **FFmpeg** - 音视频处理
- **moviepy** - Python 视频处理库
