# 打工牛马的 Workagnet-Qiaomai

本技能集成各类办公软件的实战技巧，涵盖 Word 文档、Excel 数据处理、PPT 演示制作、PDF 操作、邮件管理、协作工具等场景。旨在帮助打工人快速解决日常办公难题，提升工作效率。

- 快速排版与样式应用

- 目录生成与更新
- 页眉页脚与页码设置
- 多级编号与项目符号
- 表格与图文混排
- 文档保护与批注协作

### 2. Excel 数据处理

- 数据清洗与格式化
- 函数公式应用（VLOOKUP、SUMIF、条件统计）
- 数据透视表高级用法
- 图表制作与美化
- 条件格式与数据验证
- 批量操作与快捷键
- 多表关联与汇总

### 3. PPT 演示制作

- 快速排版与主题应用
- 母版与版式设计
- 图片与图表处理
- 动画与切换效果
- 演示者视图使用
- 批量修改与格式刷
- 导出与转换技巧

### 4. PDF 操作技巧

- PDF 转换（Word/Excel/图片）
- PDF 合并与拆分
- PDF 压缩与优化
- PDF 编辑与签名
- 批量处理技巧

### 5. 邮件与日程管理

### 6. 协作工具使用
