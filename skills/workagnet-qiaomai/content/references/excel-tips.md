# Excel 高效操作秘籍

## 一、数据处理基础

### 1.1 选择技巧

**快速选择：**

- `Ctrl+Shift+方向键`：快速选中连续区域
- `Ctrl+Space`：选中整列
- `Shift+Space`：选中整行
- `Ctrl+A`：选中整个数据区域
- `Ctrl+Shift+End`：选中到数据区域右下角

**选择性选择：**

- 按住 `Ctrl` 点击：选择不连续单元格
- 按住 `Shift` 点击：选中连续区域
- 按住 `Alt+Enter`：在单元格内换行

### 1.2 填充与序列

**快速填充：**

- `Ctrl+D`：向下填充（复制上方内容）
- `Ctrl+R`：向右填充
- `Ctrl+E`：智能填充（识别规律自动填充）

**序列填充：**

1. 输入起始值
2. 拖动填充柄
3. 选择「填充序列」或「等差序列」「等比序列」

**自定义序列：**

1. 「文件」→「选项」→「高级」
2. 点击「编辑自定义列表」
3. 添加常用序列（部门、职位等）

## 二、公式与函数

### 2.1 常用函数速查

**统计类：**

- `SUM`：求和
- `AVERAGE`：平均值
- `COUNT`：计数（数字）
- `COUNTA`：计数（非空）
- `MAX/MIN`：最大/最小值

**条件类：**

- `SUMIF`：条件求和
- `COUNTIF`：条件计数
- `AVERAGEIF`：条件平均
- `SUMIFS`：多条件求和
- `COUNTIFS`：多条件计数

**查找类：**

- `VLOOKUP`：垂直查找
- `HLOOKUP`：水平查找
- `INDEX+MATCH`：灵活查找
- `XLOOKUP`：新一代查找函数

### 2.2 VLOOKUP 详解

**基础语法：**

```
=VLOOKUP(查找值, 查找区域, 返回列号, 匹配类型)
```

**使用示例：**

```
=VLOOKUP(A2, 员工表!A:C, 3, 0)
查找A2的值，在员工表A到C列中，返回第3列，精确匹配
```

**常见错误：**

- #N/A：查找值不存在
- #REF：列号超出范围
- #VALUE：参数类型错误

### 2.3 INDEX+MATCH 组合

**优势：**

- 可以从右向左查找
- 列位置变化不影响公式
- 更加灵活强大

**语法：**

```
=INDEX(返回区域, MATCH(查找值, 查找区域, 匹配类型))
```

**示例：**

```
=INDEX(B:B, MATCH(A2, C:C, 0))
根据A2在C列查找，返回B列对应值
```

### 2.4 SUMIF 与 COUNTIF

**SUMIF 语法：**

```
=SUMIF(条件区域, 条件, 求和区域)
```

**示例：**

```
=SUMIF(A:A, "北京", B:B)
统计A列为"北京"的B列总和
```

**COUNTIF 语法：**

```
=COUNTIF(区域, 条件)
```

**示例：**

```
=COUNTIF(A:A, ">=60")
统计A列大于等于60的数量
```

## 三、数据透视表

### 3.1 创建数据透视表

**步骤：**

1. 选中数据区域任意单元格
2. 「插入」→「数据透视表」
3. 选择放置位置（新工作表/现有工作表）
4. 拖动字段到相应区域

**区域说明：**

- 筛选：全局筛选
- 列：列标题字段
- 行：行标题字段
- 值：汇总计算字段

### 3.2 分组与计算

**日期分组：**

1. 右键日期列
2. 选择「分组」
3. 选择「月」「季度」「年」等

**自定义分组：**

1. 按住 `Ctrl` 选择要分组的项目
2. 右键「创建组」
3. 命名分组

**值汇总方式：**

- 求和、计数、平均值
- 最大值、最小值
- 计数（不重复）

### 3.3 切片器与日程表

**切片器使用方法：**

1. 点击数据透视表
2. 「分析」→「插入切片器」
3. 选择要筛选的字段
4. 切片器会自动关联当前透视表

**切片器设置：**

- 多列显示：`切片器设置」→「列」
- 清除筛选：点击右上角清除图标
- 断开连接：右键「数据透视表连接」

## 四、条件格式

### 4.1 常用规则

**突出显示规则：**

1. 选中区域
2. 「开始」→「条件格式」→「突出显示单元格规则」
3. 选择条件（大于、小于、等于、介于）
4. 设置格式

**最前最后规则：**

- 前 10 项/后 10 项
- 高于/低于平均值
- 唯一值/重复值

### 4.2 公式自定义规则

**使用场景：**

- 跨列条件判断
- 复杂逻辑条件
- 动态格式设置

**语法：**

```
=条件公式（第一个单元格）
```

**示例：**

```
=$A1>"已完成"  （A列大于某值时整行高亮）
=AND($B1>=60, $C1>=60)  （两门都及格）
=MOD(ROW(), 2)=1  （奇数行变色）
```

### 4.3 数据条与色阶

**数据条：**

- 直观显示数值大小
- 可设置渐变填充或实心填充
- 支持正负值显示

**色阶：**

- 三色色阶：根据数值分布着色
- 两色色阶：高低调对比

**图标集：**

- 方向箭头：上升/下降趋势
- 形状：图形化标识
- 等级：分级显示

## 八、常见问题解决

### 8.1 公式显示为文本

**原因：** 单元格格式被设置为文本。

**解决方法：**

1. 将格式改为「常规」
2. 双击单元格，按 `Enter` 重新计算
3. 或使用「数据」→「分列」功能

### 8.2 VLOOKUP 返回错误值

**排查步骤：**

1. 检查查找值是否存在
2. 检查列号是否正确
3. 检查数据是否有前导空格
4. 确认匹配类型（精确/近似）

### 8.3 透视表不刷新

**原因：** 源数据变化后未更新。

**解决方法：**

1. 右键透视表选择「刷新」
2. 右键选择「刷新全部」
3. 设置打开文件时自动刷新

### 8.4 日期显示为数字

**原因：** 单元格格式为常规或数值。

**解决方法：**

1. 选中单元格
2. 设置格式为日期类型
3. 选择合适的日期显示格式
