# PDF 处理大全

## 一、PDF 基础操作

### 1.1 PDF 查看与浏览

**常用 PDF 阅读器：**

- Adobe Acrobat Reader（官方免费版）
- Adobe Acrobat Pro（专业版）
- 福昕 PDF 阅读器
- 万兴 PDF 专家
- 浏览器内置 PDF 预览

**基本浏览操作：**

- 滚动浏览：鼠标滚轮
- 单页/连续滚动切换：视图菜单
- 缩放：Ctrl+鼠标滚轮 或 工具栏缩放按钮
- 全屏阅读：F11

### 1.2 PDF 搜索与导航

**搜索功能：**

- `Ctrl+F`：在当前 PDF 中搜索
- `Ctrl+Shift+F`：高级搜索
- 搜索结果高亮显示
- 支持正则表达式搜索

**书签与缩略图：**

- 左侧栏切换到书签或缩略图面板
- 点击书签直接跳转
- 缩略图预览页面内容

## 二、PDF 转换技巧

### 2.1 PDF 转 Word

**在线转换工具：**

- SmallPDF
- iLovePDF
- CloudConvert
- PDF2DOC

**桌面软件：**

- Adobe Acrobat Pro
- 福昕 PDF
- 万兴 PDF 专家
- ABBYY FineReader

**转换技巧：**

1. 选择「布局保持」模式
2. 避免扫描件直接转换（需 OCR）
3. 转换后检查表格和图片位置
4. 删除多余的空行和格式残留

### 2.2 PDF 转 Excel

**适用场景：**

- 表格型 PDF
- 数据报告
- 财务报表

**转换建议：**

1. 使用专业转换工具
2. 选择「表格识别」模式
3. 转换后检查数据对齐
4. 手动调整合并单元格

### 2.3 PDF 转图片

**方法一：截图工具**

- 系统截图（Win+Shift+S）
- Snipaste
- FastStone Capture

**方法二：软件导出**

- Adobe Acrobat：文件→导出
- 在线工具批量转换

**方法三：命令行工具**

- pdftoppm（Linux/Mac）
- ImageMagick

### 2.4 图片转 PDF

**Windows 系统：**

1. 选中多张图片
2. 右键选择「打印」
3. 选择「Microsoft Print to PDF」
4. 调整顺序和布局

**Mac 系统：**

1. 选中图片
2. 右键「快速操作」→「创建 PDF」

**在线工具：**

- SmallPDF
- iLovePDF
- PDF Converter

## 三、PDF 编辑技巧

### 3.1 文本编辑

**编辑模式：**

1. 工具栏选择「编辑 PDF」
2. 点击文本即可修改
3. 添加新文本框

**注意事项：**

- 扫描件需要 OCR 识别后才能编辑
- 复杂排版可能出现错位
- 字体可能需要嵌入

### 3.2 添加批注与标记

**批注工具：**

- 高亮文本：选中文字后添加
- 下划线/删除线：标记文本修改
- 便签：添加便签注释
- 打字机：固定位置添加文字

**绘图工具：**

- 矩形、椭圆、线条
- 箭头指向
- 手绘自由标注

### 3.3 表单处理

**填写表单：**

- 点击表单字段直接填写
- Tab 键切换字段
- 保存填写后的 PDF

**创建表单：**

1. 准备表单内容
2. 使用表单工具添加字段
3. 设置字段属性（必填、格式验证）
4. 分发表单收集信息

## 四、PDF 合并与拆分

### 4.1 合并多个 PDF

**Adobe Acrobat：**

1. 工具→合并文件
2. 添加要合并的文件
3. 调整文件顺序
4. 点击「合并」
5. 保存

**在线工具：**

- SmallPDF 合并
- iLovePDF 合并
- PDF Merge

### 4.2 拆分 PDF

**按页面拆分：**

1. 工具→组织页面
2. 选择要拆分的页面
3. 右键「提取」或拖出
4. 保存为新文件

**按范围拆分：**

1. 使用拆分工具
2. 设置拆分条件（每 N 页、页面范围）
3. 批量生成文件

### 4.3 提取页面

**Acrobat 操作：**

1. 缩略图视图选中页面
2. 右键「提取页面」
3. 选择「提取后删除原页面」或「保留」
4. 保存为新文件

## 五、PDF 压缩与优化

### 5.1 压缩方法

**Acrobat 压缩：**

1. 文件→另存为其他→优化扫描 PDF
2. 选择压缩质量
3. 预览文件大小变化

**在线压缩：**

- SmallPDF 压缩
- iLovePDF 压缩
- PDF Compressor

**压缩质量选项：**

| 质量级别 | 适用场景 |
|----------|----------|
| 高 | 需要高质量打印 |
| 中 | 一般办公文档 |
| 低 | 仅屏幕查看、存档 |

### 5.2 优化大文件

**图片优化：**

- 降低图片分辨率
- 压缩图片质量
- 删除重复/隐藏元素

**字体处理：**

- 嵌入子集字体
- 移除未使用的字体
- 转换为轮廓

## 六、PDF 安全与权限

### 6.1 密码保护

**设置密码：**

1. 工具→保护→加密
2. 选择加密方式
3. 设置打开密码
4. 设置权限密码（限制编辑）

**密码类型：**

- 打开密码：必须输入才能查看
- 权限密码：查看无密码，编辑需要密码

### 6.2 权限设置

**限制操作：**

- 打印权限（高质量/低质量/禁止）
- 编辑权限（允许修改/只读/禁止）
- 复制内容（允许/禁止）
- 页面提取（允许/禁止）

### 6.3 数字签名

**添加签名：**

1. 工具→签名→准备表单
2. 选择签名位置
3. 绘制或导入签名图片
4. 应用签名

**签名类型：**

- 手写签名：扫描导入
- 打字签名：输入姓名选择字体
- 数字签名：需要证书

## 七、OCR 文字识别

### 7.1 OCR 使用场景

**适用情况：**

- 扫描的纸质文档
- 图片型 PDF
- 无法选中的文本

**识别精度：**

- 印刷体识别率：95%+
- 手写体识别率：70-85%
- 复杂排版识别困难

### 7.2 OCR 工具推荐

**专业软件：**

- ABBYY FineReader（识别率最高）
- Adobe Acrobat Pro
- 讯飞 OCR
- 百度 OCR API

**在线服务：**

- SmallPDF OCR
- iLovePDF OCR
- Google Docs（免费）

### 7.3 OCR 优化技巧

**提升识别率：**

1. 提高原图分辨率（300dpi 以上）
2. 确保图片清晰无污渍
3. 使用纯黑文字白底
4. 调整对比度和锐化

**后处理：**

- 校对识别错误
- 修正表格结构
- 调整段落格式

## 十、常见问题解决

### 10.1 PDF 打不开

**可能原因：**

- 文件损坏
- PDF 版本不兼容
- 阅读器版本过低

**解决方法：**

1. 尝试其他 PDF 阅读器
2. 重新下载或获取原文件
3. 使用在线工具修复
4. 更新 PDF 阅读器

### 10.2 无法编辑 PDF

**原因分析：**

- PDF 受保护加密
- PDF 为扫描图片
- 不是文本型 PDF

**解决方案：**

1. 移除安全限制（需密码）
2. 使用 OCR 识别
3. 转换为可编辑格式

### 10.3 中文显示乱码

**原因：**

- 缺少字体嵌入
- 字体不支持中文

**解决建议：**

1. 安装中文字体包
2. 使用高版本阅读器
3. 转换为图片格式

### 10.4 PDF 打印空白页

**排查步骤：**

1. 检查是否有内容被隐藏
2. 检查页面尺寸设置
3. 尝试「适合纸张」打印
4. 更新打印机驱动
