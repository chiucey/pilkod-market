## 🎯 何时使用本技能

1. 用户要求分析卷渣/夹渣缺陷原因

## 📋 核心知识框架

### 1. 卷渣定义与四种机理

**卷渣（Slag Entrapment）：** 结晶器内液态保护渣被钢液流动或气泡裹挟，从钢 - 渣界面卷入钢液内部的物理过程。

**夹渣（Slag Inclusion）：** 卷渣的结果——被卷入的保护渣凝固后残留在铸坯表面或皮下。

| 机理 | 名称 | 驱动因素 | 优先级 |
|------|------|---------|--------|
| M1 | 弯月面翻腾型 | 拉速↑ → 流股冲击↑ → 弯月面翻腾 | ⭐⭐⭐⭐⭐ |
| M2 | 气泡驱动型 | 吹氩↑ → 气泡穿透界面 | ⭐⭐⭐⭐⭐ |
| M3 | 液面波动型 | 拉速/塞棒波动 → 液面波动 | ⭐⭐⭐⭐⭐ |
| M4 | 漩涡卷渣型 | 偏流 → 漩涡形成 | ⭐⭐⭐ |

### 2. 八大分析维度

| 维度 | 名称 | 变量数 | 核心作用 |
|------|------|--------|---------|
| A | 结晶器内工艺 | 20 | 直接驱动四种卷渣机理的执行端 |
| B | 吹氩工艺 | 12 | 机理二的直接驱动 + 塞棒控制 |
| C | 中间包工艺 | 8 | 影响钢液供给稳定性和纯净度 |
| D | 钢水纯净度 | 28 | 夹杂物叠加 + 促进卷渣 |
| E | 保护渣特性 | 3 | 决定卷渣难度（基础条件） |
| F | 板坯清理 | 6 | 切断缺陷传递的防御层 |
| G | 热轧工艺 | 5 | 改变缺陷形态（不产生卷渣） |
| H | 冷轧工艺 | 5 | 放大和暴露缺陷（不产生卷渣） |

**总计：** 约 90 个分析变量，25 个可验证假设

### 3. 完整因果链

```
【D. 钢水纯净度】→ 夹杂物 → 水口结瘤 → 偏流
       ↓
【C. 中间包工艺】→ 钢液供给稳定性 → 液面波动
       ↓
【A. 结晶器内工艺】→ 四种卷渣机理
       ↓
【B. 吹氩工艺】→ 气泡驱动 + 塞棒控制
       ↓
【E. 保护渣特性】→ 卷渣难度
       ↓
卷渣 → 夹渣 → 【F. 板坯清理】→ 【G. 热轧】→ 【H. 冷轧】→ 封锁判定
```

## 🔄 分析流程

### 步骤 1：数据准备与检查

**输入要求：**

- Excel 格式连铸工艺数据（.xlsx）
- 必须包含的列：出钢记号、热轧封锁、冷轧封锁、年月日等基础列
- 可选包含：八大维度的工艺参数列

**检查清单：**

```
□ 数据文件是否存在
□ 数据行数是否足够（建议>1000 行）
□ 关键列是否存在（缺陷判定列、工艺参数列）
□ 数据质量检查（缺失值、异常值）
```

### 步骤 2：加载分析配置

读取 `analysis-config.json` 配置文件，获取：

- 目标列映射（target_columns）
- 八大维度变量定义（dimensions）
- 25 个可验证假设（hypotheses）
- 四种卷渣机理定义（slag_entrapment_mechanisms）

### 步骤 3：执行数据分析

**3.1 描述性统计**

- 缺陷率统计（热轧封锁率、冷轧封锁率）
- 按钢种、月份、板坯位置等维度分组统计

**3.2 假设检验**

对 25 个假设逐一进行统计检验：

- 有缺陷 vs 无缺陷样本的均值对比
- T 检验/ANOVA 检验显著性
- 效应量计算（Cohen's d）

**3.3 相关性分析**

- 计算各工艺参数与缺陷率的相关系数
- 识别强相关参数（|r| > 0.3）

**3.4 随机森林特征重要性**

- 训练随机森林模型预测缺陷
- 提取特征重要性排序
- 识别关键影响因子

**3.5 趋势分析**

- 按月统计缺陷率趋势
- 按关键参数分组绘制趋势图

### 步骤 4：机理解释与验证

**核心原则（铁律）：**

> 统计显著 ≠ 因果关系  
> 每条"原因"必须能回答"通过哪个卷渣机理"或"通过哪个维度起作用"  
> 无法用机理链条解释的结果不构成卷渣/夹渣原因

**验证流程：**

1. 数据分析识别出显著参数
2. 映射到八大维度
3. 关联到四种卷渣机理
4. 用连铸理论解释因果链
5. 如无法解释 → 舍弃该参数，不认定为原因

### 步骤 5：生成报告

**报告结构：**

```markdown
# 连铸卷渣/夹渣缺陷分析报告

## 1. 执行摘要
- 核心发现（3-5 条）
- 关键建议（2-3 条）

## 2. 数据概况
- 数据量、时间范围、钢种分布
- 缺陷率统计

## 3. 缺陷定义与判定
- 热轧封锁定义
- 冷轧封锁定义
- 封锁率计算方法

## 4. 机理框架
- 四种卷渣机理说明
- 八大维度介绍

## 5. 数据分析结果
- 描述性统计
- 假设检验结果（25 个假设）
- 相关性分析
- 随机森林特征重要性
- 趋势分析

## 6. 机理解释与成因分析
- 显著参数的机理解释
- 因果链梳理
- 关键成因排序

## 7. 改进建议
- 工艺优化建议
- 监控重点建议
- 后续研究方向

## 8. 附录
- 变量定义表
- 统计检验详情
```

## ⚙️ 配置说明

### analysis-config.json 结构

```json
{
  "template_name": "卷渣/夹渣缺陷分析",
  "version": "V6",
  "target_columns": {
    "grade": "出钢记号",
    "hot_defect": "热轧封锁",
    "cold_defect": "冷轧封锁",
    ...
  },
  "dimensions": {
    "A": {
      "name": "结晶器内工艺",
      "variables": [
        {"name": "液面波动最大减最小", "col_index": 50, "priority": 5}
      ]
    },
    ...
  },
  "hypotheses": [
    {"id": "H1", "text": "液面波动是卷渣的直接驱动因素", "dimension": "A"}
  ],
  "slag_entrapment_mechanisms": [...]
}
```

### 添加新变量

在对应维度的 `variables` 数组中添加：

```json
{
  "name": "新变量名",
  "col_index": 数字,
  "priority": 1-5,
  "mechanism": "影响机理说明"
}
```

### 添加新假设

在 `hypotheses` 数组中添加：

```json
{
  "id": "H26",
  "text": "新假设描述",
  "dimension": "维度字母",
  "expected": "预期数据表现"
}
```

## ⚠️ 注意事项

### 数据分析铁律

1. **统计显著 ≠ 因果关系**
2. **效应量大 ≠ 实际成因**
3. **Random Forest 权重高 ≠ 机理上成立**
4. **每一条"原因"都必须能回答"连铸机理是什么"**

### 禁止行为

- ❌ 把统计相关的工艺参数直接认定为"原因"
- ❌ 用模糊的"影响凝固行为"来解释一切参数
- ❌ 将下游工序参数（热轧卷尺寸、合同规格）认定为连铸缺陷原因
- ❌ 将标识类、追溯类参数（处理号、批号、重量）认定为工艺原因
- ❌ 给出没有连铸文献支撑的机理说明

### 连铸分析核心机理链条

分析必须以以下机理链条为核心判断依据：

1. 结晶器内钢液流动行为（SEN 流场、吹氩、EMS）
2. 初生坯壳凝固行为（传热、过热度、拉速、锥度）
3. 保护渣行为（消耗量、熔化、渣膜形成、卷入）
4. 结晶器液面稳定性（拉速波动、塞棒控制）
5. 钢水纯净度（夹杂物来源、上浮条件）
6. 二次冷却行为（喷水均匀性、矫直温度）
