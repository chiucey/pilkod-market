# 全链路软件开发 (Full-Stack Software Development)

## 概述

这是一个完整的多智能体软件项目组技能包，包含6个专业智能体，覆盖软件开发的全生命周期：需求分析 → 系统设计 → 编码测试 → 交付运维。

## 执行流程

### 阶段1：项目启动

1. **项目经理**接收史诗级需求
2. **产品分析师**提取需求，生成用户故事与验收标准
3. **架构师**完成技术选型与模块划分

### 阶段2：开发执行

1. **项目经理**拆解任务，分配至**开发智能体组**
2. 各开发智能体专注独立模块，完成代码与单元测试
3. **测试工程师**生成集成测试，执行并定位缺陷
4. **开发智能体**根据反馈进行自修复

### 阶段3：交付运维

1. **DevOps**生成CI/CD配置，部署系统
2. **测试工程师**生成质量报告，执行质量门禁
3. **DevOps**配置监控告警，建立自愈机制
4. **项目经理**沉淀项目知识库

## 协作机制

### 信息共享

- **共享任务板**：任务状态、进度实时同步
- **接口契约**：架构师维护，各智能体遵守
- **向量知识库**：决策日志、故障记录、项目经验

### 智能体协调

| 场景 | 协调方式 |
|------|----------|
| 任务分配 | 项目经理 → 开发智能体组 |
| 技术决策 | 架构师 → 开发智能体组 |
| Bug修复 | 测试工程师 → 开发智能体组 |
| 部署上线 | 项目经理 → DevOps |
| 进度阻塞 | 项目经理协调相关智能体 |

### 自愈与升级

- **开发自愈**：代码bug → 开发智能体自修复（3次）→ 升级架构师
- **测试重试**：环境问题 → 测试工程师重试（2-3次）
- **故障恢复**：Pod异常 → DevOps自愈 → 人工干预（如需）

## 质量门禁

| 阶段 | 门禁标准 |
|------|----------|
| 需求完成 | 功能性/非功能性需求清单 + INVEST用户故事 |
| 设计完成 | 技术栈 + 模块划分 + OpenAPI定义 |
| 开发完成 | 核心代码覆盖率≥90% + 单元测试通过 |
| 测试完成 | 核心用例通过率100% + 无高优先级未修复缺陷 |
| 部署完成 | CI/CD就绪 + 监控告警配置完成 |

## 使用示例

### 启动新项目

```
用户：开发一个带用户认证的待办事项应用
```

**执行流程**：
1. 项目经理拆解任务
2. 产品分析师提取需求
3. 架构师设计架构
4. 开发智能体组并行开发各模块
5. 测试工程师执行集成测试
6. DevOps部署上线

### 修复生产故障

```
用户：登录接口响应超时
```

**执行流程**：
1. DevOps检测告警，分析故障
2. 触发自愈或回滚
3. 测试工程师验证修复
4. 项目经理记录故障知识库
