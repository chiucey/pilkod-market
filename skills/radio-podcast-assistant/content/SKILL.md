# 电台播客助手

一个强大的技能，可以将任何文字或文档内容转换为专业的播客音频。支持单人独白和双人对话两种模式，并可通过内容调整控制音频时长。

## 核心功能

- **内容分析**：智能解析输入的文字内容，提取关键信息和主题
- **脚本生成**：将内容重组为自然的播客对话形式
- **双模式支持**：
  - 单人模式：适合个人分享、故事讲述、知识讲解
  - 双人模式：适合访谈、讨论、问答等互动场景
- **时长控制**：通过内容密度和对话节奏调整音频总时长
- **多声音选择**：支持多种音色选项，营造不同氛围

## 工作流程

### 1. 内容输入

支持多种输入形式：
- 直接粘贴文字内容
- 上传文档（支持 .txt, .md 格式）
- 提供文章/报告的核心要点

### 2. 内容分析与重组

智能处理流程：
- 识别内容主题和结构
- 提取关键信息和亮点
- 重组为流畅的播客脚本
- 添加过渡语和连接词
- 设计开场白和结束语

### 3. 模式选择

**单人模式**：
- 适合：个人分享、独白讲解、故事叙述
- 特点：连贯性强，节奏稳定
- 推荐场景：个人博客、教程讲解、新闻播报

**双人模式**：
- 适合：访谈、讨论、问答
- 特点：互动感强，趣味性高
- 推荐场景：访谈节目、圆桌讨论、对话讲解

### 4. 时长控制

通过以下方式控制总时长：

| 目标时长 | 内容策略 |
|---------|---------|
| 1-2分钟 | 精华摘要，核心要点 |
| 3-5分钟 | 完整概述，主要内容 |
| 5-10分钟 | 详细讲解，适当扩展 |
| 10+分钟 | 深度分析，全面展开 |

### 5. 声音配置

双人模式示例：
- **声音A（主持人/主播）**：正式、专业、适合提问和引导
- **声音B（嘉宾/搭档）**：亲切、自然、适合回答和分享

单人模式示例：
- 单一声音贯穿全程
- 可根据内容调整语速和情感

## 使用示例

### 示例1：文章转播客

**用户输入**：
```
请将以下文章转换为3分钟的播客：
[粘贴文章内容...]
```

**生成结果**：
```
【播客脚本 - 单人模式 约3分钟】

[开场]
大家好，欢迎收听今天的播客。今天我们要聊的话题是...

[正文]
首先，让我们来看看第一点...

然后是第二点，非常重要...

最后，我想分享一个观点...

[结尾]
以上就是今天的内容，感谢大家的聆听...
```

### 示例2：文档转双人对话

**用户输入**：
```
将这份报告转换为5分钟的双人访谈播客
角色：主持人（男声）+ 专家（女声）
```

**生成结果**：
```
【播客脚本 - 双人模式 约5分钟】

[主持人A]：各位听众朋友好，欢迎来到...
[专家B]：大家好，很高兴能和大家分享...
[主持人A]：今天我们要聊的话题是...
[专家B]：是的，这个问题确实很重要...
...
```

## 技术说明

### 音频生成

使用文本转语音（TTS）技术，将生成的脚本转换为自然流畅的音频。

**参数配置**：
- 语速：可调节（0.5x - 2.0x）
- 音量：标准音量
- 情感：中性（可根据内容调整）

### 文件输出

生成的音频文件：
- 格式：MP3
- 采样率：标准音质
- 命名：`podcast_[主题]_[时长].mp3`

## 注意事项

1. **内容质量**：输入的文字内容越清晰、结构化，生成的播客质量越高
2. **时长估算**：实际时长可能因语速、停顿等因素有±10%的误差
3. **声音选择**：建议根据内容主题选择合适的音色组合
4. **内容审核**：生成前请确认内容适合公开播客使用

## 快速开始

1. 提供你想要转换的文字内容或上传文档
2. 选择播客模式（单人/双人）
3. 指定目标时长
4. （可选）指定声音偏好
5. 等待生成完成，下载音频文件
