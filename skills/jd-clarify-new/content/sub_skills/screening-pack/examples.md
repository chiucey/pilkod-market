# Examples (Mode D)

## 示例：Java后端岗位筛选包

【ITO招聘需求检查表读取摘要】
- 来源版本：A模式 v1.1
- 已读取关键项：工作地点、工作时间、加班情况、薪资待遇、签约主体、面试流程、反馈周期

【平台筛选信息（按模板）】
第一部分：岗位职责盘点
- 岗位内容：
  1. 负责交易链路核心接口开发与性能优化。
  2. 参与服务治理与线上稳定性建设，保障版本交付。
- 要求及薪资福利：
  1. Java开发经验必须3年以上，具备MySQL与Redis实战。
  2. 薪资12-15K，双休，入职缴纳五险一金。

第二部分：门槛条件因子关键词清单（用于平台匹配）
- 年龄：不限
- 性别：不限
- 学历：必须本科及以上
- 第一学历：优先本科
- 工作地点：优先成都高新区
- 历任公司：优先金融科技或支付公司
- 排除公司：不限
- 专业：优先计算机相关专业
- 技能经验：必须Java、MySQL、Redis实战
- 职类：优先后端开发
- 行业：必须交易链路或支付行业经验
- 期望城市：优先成都
- 工作年限：必须3年以上
- 毕业年限：不限
- 工作稳定性：优先近三年单段工作满1年以上

第三部分：补充关键信息
- 上班时间：9:30-18:30，周末双休。
- 面试地址：成都市高新区天府三街XX号。
- 工作地址：成都市高新区天府三街XX号（园区和楼栋待补齐）。
- 是否提供食宿：不提供住宿，餐补按公司政策执行。
- 是否提供培训：入职有业务与系统培训。
- 试用期与社保：试用期3个月，社保公积金从入职当月缴纳。
- 其他说明：偶发晚间上线支持，次日可调休。
- 平台AI筛简历用岗位筛选要求：
  - 硬性通过条件（Must Have）：
    - Java开发3年以上，有独立模块交付经历。
    - 有MySQL与Redis实战经验，能说明性能优化动作。
    - 能接受偶发上线支持节奏。
  - 加分排序条件（Good to Have）：
    - 有交易链路或支付相关项目经验。
    - 有服务治理或稳定性建设经验。
  - 红线淘汰条件（Red Flags）：
    - 无法说明个人贡献边界。
    - 简历与问答中的离职原因前后不一致。
- 平台AI文字初面用求职者关心信息：
  - 薪资与结构：12-15K，固定薪资结构清晰。
  - 作息与加班节奏：双休，常规不加班，高峰期有补贴或调休。
  - 工作地点与通勤：工作地点在XX区，通勤时长建议不超过60分钟。
  - 福利与保障：入职缴纳五险一金，年度调薪机制明确。
  - 团队协作与成长路径：参与核心交易链路，和产品测试协同推进迭代。
  - 用工关系与签约主体：由招聘服务团队招募，录用后与指定主体签约。

【自动化打招呼话术】
- 第一段（先予）：您好，我们这边是Java后端岗位，薪资12-15K，双休，福利和社保都齐全。
- 第二段（后取）：如果你看重稳定节奏和交易链路项目经验，我可以发你团队和项目细节，方便了解下吗？

【AI初面内容】
1、岗位与待遇信息告知
- 这边岗位主要负责交易链路后端开发，薪资12-15K，双休，入职即缴五险一金。

2、关键条件匹配题（问题+期望答案）
- 问题：您这边Java开发大概做了几年？ 期望答案：3年及以上。
- 问题：最近一个项目里您独立负责的模块是什么？ 期望答案：可清晰说明模块职责与结果。

3、补充信息收集题（仅问题）
- 如果流程顺利，您最快什么时候能到岗？
- 您看机会更关注薪资、作息，还是技术成长路径？
