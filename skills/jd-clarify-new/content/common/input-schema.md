# Input Schema

## 岗位输入

- 岗位名称、职级、汇报线、团队规模
- 工作地点、班次/出差、薪酬区间
- 业务目标（入职3-6个月关键结果）
- 经验与能力要求（行业、年限、技能、工具）
- 约束条件（到岗时间、稳定性、地理限制）

## 公司信息输入

- 公司阶段（初创/成长期/成熟期）
- 行业赛道、主营业务、组织规模
- 团队结构、管理风格、激励机制

## 用工关系输入

- 签约主体、用工主体、社保主体
- 管理汇报关系
- 外包/派遣/项目制信息

## 缺失处理

- 信息不足时继续输出，但逐项标记 `待确认`。
- 必须补充“最小可沟通口径”，保证招聘团队对外一致。
