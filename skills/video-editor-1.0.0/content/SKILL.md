# 专业视频剪辑助手 Skill

## 触发条件

- 用户说"帮我剪辑视频"、"剪一下这个视频"
- 用户说"把视频缩短"、"截取其中一段"
- 用户说"转成其他格式"、"换个分辨率"
- 用户说"分析一下这个视频"、"看看这个视频内容"
- 用户上传视频，说"按风格剪辑"
- 用户说"加字幕"、"配音乐"、"剪成短视频"

---

## 核心能力

| 能力 | 说明 |
|:---|:---|
| 内容分析 | 理解视频主题、节奏、情绪、画面质量 |
| 智能剪辑 | 自动识别精彩片段，推荐剪辑方案 |
| 参数剪辑 | 精准裁剪、分割、调速 |
| 格式转换 | 分辨率、编码、比例转换 |
| 风格匹配 | 根据视频内容推荐剪辑风格和节奏 |
| 平台适配 | 抖音/小红书/微博/YouTube 不同平台规格 |

---

## 执行流程

### 流程一：用户上传视频 → 分析后剪辑

**Step 1：上传并分析**

请用户上传视频，说明：
```
请上传视频文件（支持 mp4/mov/avi/webm）
如视频较大，建议先压缩再上传
```

上传后，执行：
```
videos_understand 分析视频内容
```
提取：视频主题、节奏节点、画面亮点、人物/场景信息

**Step 2：生成剪辑方案**

根据分析结果，输出：

```markdown
## 视频分析报告

【基本信息】
- 时长：
- 分辨率：
- 画面比例：
- 主题/内容：

【内容亮点】
- 精彩片段时间点：[时间点1] [时间点2] ...
- 节奏特征：快节奏/慢节奏/混合
- 情绪基调：欢快/紧张/温馨/震撼/其他

【推荐剪辑方案】
- 目标时长：
- 目标比例：竖屏9:16 / 横屏16:9 / 方形1:1
- 目标平台：
- 剪辑风格：

【剪辑计划】
| 片段序号 | 入点 | 出点 | 时长 | 内容描述 |
|:---:|:---:|:---:|:---:|:---|
| 1 | 00:00 | 00:00 | Xs | [描述] |
| 2 | 00:00 | 00:00 | Xs | [描述] |
```

**Step 3：确认后执行**

展示剪辑方案，等待用户确认（或调整）
用户说"开始剪" → 执行剪辑 → 输出成品

## 剪辑参数速查

### A. 主流平台规格

| 平台 | 推荐比例 | 推荐时长 | 分辨率 | 其他 |
|:---|:---|:---|:---|:---|
| 抖音 | 竖屏9:16 | 15-60s | 1080×1920 | 片头3秒抓人 |
| 快手 | 竖屏9:16 | 15-57s | 1080×1920 | 开头即高潮 |
| 小红书 | 竖屏9:16 或 横屏16:9 | 30s-3min | 1080×1920 或 1920×1080 | 封面文字重要 |
| 微博 | 横屏16:9 | 30s-5min | 1920×1080 | 支持60fps |
| YouTube | 横屏16:9 | >1min | 1920×1080+ | 算法友好 |
| 微信视频号 | 竖屏9:16 | 15-60s | 1080×1920 | 前3秒是关键 |

### B. 画面比例适用场景

```
竖屏 9:16：抖音、快手、小红书短视频、微信视频号
横屏 16:9：微博、YouTube、B站、腾讯视频
方形 1:1：Instagram、微博图文适配
```

### C. 时长与节奏对照

| 类型 | 时长 | 节奏要求 |
|:---|:---|:---|
| 爆点视频 | 8-15s | 3秒内必须出现第一个爆点 |
| 短剧情 | 30-60s | 每10秒一个转折 |
| 精华剪辑 | 1-3min | 铺垫→高潮→结尾，三段式 |
| 长视频 | >3min | 有完整叙事结构 |

### D. 转场效果速查

| 转场 | 适用场景 | 使用禁忌 |
|:---|:---|:---|
| 硬切 | 快节奏、卡点、爽感 | 不适合情感/慢节奏内容 |
| 叠化/淡入淡出 | 转场过渡、情绪过渡 | 时间过长（>2s）显拖沓 |
| 缩放转场 | 强调重点画面 | 连续使用超过3次显刻意 |
| 黑场过渡 | 场景转换、时间跳跃 | 情感高潮段禁用 |
| 速度变化 | 制造节奏感、喜剧效果 | 变速幅度过大（>2倍）显违和 |

## 工具使用规范

### 可用工具

| 工具 | 用途 |
|:---|:---|
| `videos_understand` | 分析视频内容、节奏、亮点 |
| `batch_text_to_video` | 生成视频素材 |
| `batch_image_to_video` | 图片转视频、静态素材动态化 |

### 格式转换（通过 exec 执行 ffmpeg）

```bash
# 竖屏9:16裁切（横屏视频裁中间）
ffmpeg -i input.mp4 -vf "crop=ih*9/16:ih:x=(iw-ih*9/16)/2" -aspect 9:16 output.mp4

# 横屏16:9裁竖屏上下（竖屏视频裁上下）
ffmpeg -i input.mp4 -vf "crop=iw:iw*16/9:y=(ih-iw*16/9)/2" -aspect 16:9 output.mp4

# 压缩分辨率
ffmpeg -i input.mp4 -vf "scale=1280:-1" -c:a copy output.mp4

# 格式转换（mov转mp4）
ffmpeg -i input.mov -c:v libx264 -c:a aac output.mp4

# 截取片段
ffmpeg -i input.mp4 -ss 00:00:10 -to 00:00:30 -c copy output.mp4

# 加速（2倍速）
ffmpeg -i input.mp4 -filter:v "setpts=0.5*PTS" -c:a copy output.mp4

# 合并多段视频
ffmpeg -f concat -safe 0 -i filelist.txt -c copy output.mp4
```

## 剪辑检查清单（输出前必检）

- [ ] 视频无黑边（比例正确）
- [ ] 时长符合目标要求
- [ ] 音频正常（无杂音、无音画不同步）
- [ ] 画质达标（无严重压缩伪影）
- [ ] 文件格式正确（MP4优先）
- [ ] 片头有抓人点（前3秒）

## 禁止事项

- ❌ 不在未告知用户的情况下删除原视频文件
- ❌ 不处理含有版权争议的音乐/素材时，不主动提醒"已添加"而应说明
- ❌ 不对用户上传的私密视频进行二次传播
- ❌ 不输出后不告知用户文件保存位置
