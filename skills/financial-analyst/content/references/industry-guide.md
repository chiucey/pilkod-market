# 行业财务分析指南

本指南提供不同行业的财务分析侧重点和估值方法参考。

---

## 1. 消费品行业

### 核心指标优先级

| 优先级 | 指标 | 关注点 |
|--------|------|--------|
| ★★★ | 毛利率 | 品牌溢价能力 |
| ★★★ | 营收增速 | 市场扩张能力 |
| ★★☆ | 存货周转 | 产品滞销风险 |
| ★★☆ | 经营现金流 | 盈利质量 |
| ★★☆ | ROE | 股东回报 |

### 估值方法

- **PE估值**：首选，适合稳定成长的消费品龙头
- **PS估值**：新消费品牌、电商
- **PEG**：成长型消费品公司

### 风险信号

- 毛利率持续下降（竞争加剧或定价权丧失）
- 存货大幅增长（产品滞销）
- 销售费用率异常攀升

---

## 2. 制造业

### 核心指标优先级

| 优先级 | 指标 | 关注点 |
|--------|------|--------|
| ★★★ | 固定资产周转率 | 产能利用率 |
| ★★★ | 毛利率 | 成本控制能力 |
| ★★★ | ROIC | 资本使用效率 |
| ★★☆ | 资产负债率 | 财务杠杆 |
| ★★☆ | 存货周转 | 库存管理 |

### 估值方法

- **PB估值**：重资产制造业主流
- **EV/EBITDA**：资本密集型制造
- **PE估值**：轻资产制造

### 风险信号

- 固定资产大幅增加但营收未增长（产能过剩）
- 毛利率下降（原材料成本上升或价格战）
- 应收账款周转天数增加

---

## 3. 金融行业

### 核心指标优先级

| 优先级 | 指标 | 关注点 |
|--------|------|--------|
| ★★★ | 不良贷款率(NPL) | 资产质量 |
| ★★★ | 拨备覆盖率 | 风险抵补 |
| ★★★ | 资本充足率 | 安全边际 |
| ★★☆ | 净息差(NIM) | 盈利能力 |
| ★★☆ | 成本收入比 | 运营效率 |

### 估值方法

- **PB估值**：银行首选，净资产是核心
- **PE估值**：证券公司
- **EV/内含价值**：保险公司

### 风险信号

- 不良贷款率持续上升
- 拨备覆盖率低于150%
- 核心一级资本充足率逼近监管红线

---

## 4. 互联网行业

### 核心指标优先级

| 优先级 | 指标 | 关注点 |
|--------|------|--------|
| ★★★ | GMV/平台成交额 | 平台规模 |
| ★★★ | MAU/DAU | 用户活跃度 |
| ★★★ | ARPU | 变现能力 |
| ★★☆ | 获客成本(CAC) | 增长效率 |
| ★★☆ | 留存率/NDR | 用户黏性 |

### 估值方法

- **PS估值**：成长期互联网首选
- **EV/GMV**：平台型公司
- **EV/EBITDA**：成熟互联网

### 风险信号

- MAU增长放缓
- ARPU下降
- 获客成本大幅上升
- 经营现金流恶化

## 5. 房地产行业

### 核心指标优先级

| 优先级 | 指标 | 关注点 |
|--------|------|--------|
| ★★★ | 资产负债率 | 财务杠杆 |
| ★★★ | 现金短债比 | 流动性风险 |
| ★★★ | 土地储备质量 | 未来发展 |
| ★★☆ | 毛利率 | 利润空间 |
| ★★☆ | 去化周期 | 销售能力 |

### 估值方法

- **NAV估值**：土地储备价值法
- **PE估值**：稳健开发商
- **PB估值**：资产价值参考

### 风险信号

- 三道红线触及
- 现金短债比<1
- 土地储备大幅贬值风险
- 应收账款异常

---

## 6. 医药行业

### 核心指标优先级

| 优先级 | 指标 | 关注点 |
|--------|------|--------|
| ★★★ | 研发投入占比 | 创新实力 |
| ★★★ | 管线价值 | 未来潜力 |
| ★★★ | 毛利率 | 定价能力 |
| ★★☆ | 净利率 | 盈利能力 |
| ★★☆ | 现金流 | 研发支撑 |

### 估值方法

- **DCF估值**：管线价值折现（biotech）
- **PE估值**：成熟药企
- **PS估值**：创新药公司

### 风险信号

- 研发投入资本化比例过高
- 单一产品依赖度
- 带量采购影响
- 应收账款回收问题

## 7. SaaS/企业服务

### 核心指标优先级

| 优先级 | 指标 | 关注点 |
|--------|------|--------|
| ★★★ | 毛利率 | 产品竞争力 |
| ★★★ | ARR/MRR | 经常性收入 |
| ★★★ | NDR(净收入留存率) | 客户黏性 |
| ★★☆ | LTV/CAC | 增长效率 |
| ★★☆ | 获客成本回收期 | 运营效率 |

### 估值方法

- **PS估值**：SaaS行业主流
- **EV/ARR**：标准化估值
- **EV/EBITDA**：成熟SaaS

### 关键比率

- **健康指标**：NDR>100%，CAC<1年回收
- **优质指标**：毛利率>70%，LTV/CAC>3

### 风险信号

- NDR<100%（客户流失）
- 获客成本上升
- 研发费用率过高

---

## 8. 周期性行业（钢铁、煤炭、化工）

### 核心指标优先级

| 优先级 | 指标 | 关注点 |
|--------|------|--------|
| ★★★ | 周期位置判断 | 宏观择时 |
| ★★★ | 毛利率波动 | 景气度 |
| ★★★ | 资产负债率 | 底部抗压 |
| ★★☆ | 现金流 | 周期底部生存 |
| ★★☆ | 成本优势 | 竞争壁垒 |

### 估值方法

- **PB估值**：重资产周期股
- **EV/EBITDA**：剔除折旧影响
- **市净率/历史分位**：判断周期位置

### 风险信号

- 行业产能利用率低于70%
- 商品价格持续下跌
- 应收账款激增
