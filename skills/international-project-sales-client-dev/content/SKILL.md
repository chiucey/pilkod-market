# 国际项目型销售新客户开发技能

本技能面向国际项目型销售人员，提供从线索挖掘到破冰接触的完整客户开发工作流程。

## 三大核心功能

### A. 线索挖掘（Lead Intelligence）

**输入**：客户公司名称

**工作流程**：

1. **信息搜集**
   - 通过网络搜索收集客户公司基本信息
   - 搜索客户年报、新闻稿、行业媒体报道
   - 搜集光伏项目相关公开信息（在建、已建、规划项目）
   - 通过 LinkedIn 等渠道搜集组织架构和人员信息

2. **深度研究报告生成**
   - 按照以下框架撰写 Word 格式报告（约1500-2000字）
   - 严格区分"已确认信息"与"推测信息"

**报告框架**：

```
1. 客户基本信息
   - 公司全称、总部所在地、成立时间、上市情况
   - 主营业务及光伏产业链定位

2. 财务状况概览
   - 近3年关键财务数据
   - 光伏业务占比及趋势
   - 财务健康度评估

3. 光伏项目情况（核心重点）
   - 已建成项目（规模、地点、技术参数）
   - 在建项目（进度、供应商）
   - 未来开发计划/Pipeline
   - 项目分布与市场重心
   - 项目模式分析

4. 组织架构与关键联系人（核心重点）
   - LinkedIn 注册员工分布
   - 关键部门详情
   - 关键人物列表（表格形式）
   - 决策链分析

5. 供应商关系
   - 主要供应商及合作历史
   - 供应商切换趋势与机会

6. 法律风险与历史记录
   - 诉讼历史、产品质量争议、贸易合规

7. 综合评估与机会点
   - 战略重点与痛点
   - 我司切入点评估
   - 风险提示
```

**输出**：Word 版本深度分析报告

---

### B. 报告及线索评估（Lead Scoring & Assessment）

**输入**：A 阶段生成的深度分析报告

**工作流程**：

1. **客户画像提炼**
   - 战略定位与业务模式
   - 关键决策链条
   - 核心需求与痛点

2. **潜力评分体系**

| 评估维度 | 权重 | 评分标准 |
|---------|------|---------|
| 项目规模与频率 | 25% | 大型项目多/高 = 高分 |
| 财务健康度 | 20% | 稳健 = 高分 |
| 供应商可切入性 | 20% | 存在切换空间 = 高分 |
| 决策链清晰度 | 15% | 关键人可触达 = 高分 |
| 市场增长趋势 | 10% | 扩张中 = 高分 |
| 合规与信用记录 | 10% | 无重大风险 = 高分 |

3. **分类标签**

| 标签 | 标准 |
|-----|------|
| **高潜** | 综合评分 >= 75分 |
| **培育** | 综合评分 50-74分 |
| **非重点** | 综合评分 < 50分 |

4. **跟进建议**
   - 针对不同标签给出差异化跟进策略
   - 明确优先接触的关键人

**输出**：
- 客户画像摘要
- 潜力评分表
- 分类标签与跟进建议

---

### C. 破冰策略（Ice-breaking Strategy）

**输入**：B 阶段评估结果 + 搜集到的联系方式

**工作流程**：

1. **文化背景适配**
   - 判断客户所属国家/地区文化圈
   - 适配相应的沟通礼仪和禁忌

2. **角色定位与话术定制**
   - 高管层：战略价值导向
   - 项目负责人：技术细节导向
   - 采购负责人：商务条款导向

3. **话术版本生成**

**文化适配规则**：

| 地区 | 沟通风格 | 关键注意事项 |
|------|---------|-------------|
| 中国 | 直接专业 | 避免过度谦卑 |
| 日本 | 正式敬语 | 注重礼节和关系铺垫 |
| 韩国 | 尊重层级 | 先联系中间人再触达决策者 |
| 中东 | 关系导向 | 先建立信任再谈业务 |
| 欧美 | 效率优先 | 直接切入价值主张 |

4. **触达渠道选择**
   - LinkedIn 消息（首选）
   - 邮件（备选）
   - 电话（谨慎使用）

**输出**：
- 多个版本的首次接触话术
- 渠道选择建议
- 价值主张要点清单

## 执行优先级

当用户触发本技能时：
1. 首先确认客户公司名称和开发阶段
2. 按 A → B → C 顺序执行，或根据需要单独执行某一模块
3. 在执行过程中如需补充信息，及时告知用户
