# 结构工程师知识收集技能

通过问答引导方式，快速收集结构工程领域的概念、经验和设计知识，分类存储到结构化知识库中。

## 知识分类体系

本技能支持以下四类知识的录入：

### 1. 闭环措施（Troubleshooting）
用于记录问题分析与解决方案

### 2. 设计参考（Design Reference）
用于记录规范参数和适用条件

### 3. 对比决策（Decision Comparison）
用于记录多方案比选结论

### 4. 其他知识（General Knowledge）
用于记录通用概念和经验

---

## 工作流程

### 第一步：确认知识类型

通过询问确定用户要录入的知识类型：

```
请告诉我您要录入的知识属于哪种类型？
1. 闭环措施 - 问题分析与解决方案
2. 设计参考 - 参数和适用条件
3. 对比决策 - 方案比选结论
4. 其他知识 - 概念和经验
```

### 第二步：根据类型引导问答

#### 类型1：闭环措施（Troubleshooting）

按顺序询问以下信息，填入模板：

| 字段 | 询问问题 |
|------|----------|
| 标题 | 这个问题/故障的名称是什么？ |
| 问题现象 | 具体的表现是什么？有哪些可见的异常？ |
| 根因 | 根本原因是什么？通过什么分析确定的？ |
| 解决方案 | 如何解决这个问题？ |
| 操作步骤 | 请详细描述操作步骤 |
| 图纸/参考 | 需要附上哪些图纸或参考文件？ |

**生成模板：**
```markdown
## 闭环措施：[标题]

### 问题现象
[描述]

### 根因分析
[原因分析]

### 解决方案
#### 操作步骤
1. [步骤1]
2. [步骤2]
...

#### 关联图纸
- [图纸名称/路径]
```

#### 类型2：设计参考（Design Reference）

按顺序询问以下信息：

| 字段 | 询问问题 |
|------|----------|
| 参数名称 | 这个设计参数的名称是什么？ |
| 参数值 | 标准值或推荐值是多少？ |
| 适用上限 | 最大允许值是多少？ |
| 适用下限 | 最小允许值是多少？ |
| 适用场景 | 在什么情况下使用这个参数？ |
| 注意事项 | 有什么特别需要注意的点？ |

**生成模板：**
```markdown
## 设计参考：[参数名称]

### 基本参数
- **参数值**: [值]
- **上限**: [最大值]
- **下限**: [最小值]

### 适用条件
[适用场景描述]

### 注意事项
[注意事项]
```

#### 类型3：对比决策（Decision Comparison）

按顺序询问：

| 字段 | 询问问题 |
|------|----------|
| 决策主题 | 这个对比是为了解决什么问题？ |
| 对比维度 | 从哪些方面进行对比？（成本/性能/工艺/工期等） |
| 方案A名称 | 方案A的名称是什么？ |
| 方案A各项值 | 方案A在各维度的具体值/描述？ |
| 方案B名称 | 方案B的名称是什么？ |
| 方案B各项值 | 方案B在各维度的具体值/描述？ |
| 最终结论 | 综合比较后的结论是什么？推荐哪个方案？ |

**生成模板：**
```markdown
## 对比决策：[主题]

### 对比维度
| 维度 | 方案A | 方案B |
|------|-------|-------|
| [维度1] | [值] | [值] |
| [维度2] | [值] | [值] |

### 最终结论
[结论描述]

### 推荐方案
[推荐方案]
```

#### 类型4：其他知识（General Knowledge）

按顺序询问：

| 字段 | 询问问题 |
|------|----------|
| 知识标题 | 这个知识点的名称/标题是什么？ |
| 知识内容 | 请详细描述这个知识点 |
| 关联标签 | 需要添加哪些标签方便检索？（如：抗震、梁、节点等） |
| 参考来源 | 有哪些参考来源？（规范/书籍/论文/经验等） |

**生成模板：**
```markdown
## 其他知识：[标题]

### 内容
[详细描述]

### 标签
[#标签1] [#标签2] [#标签3]

### 参考来源
- [来源1]
- [来源2]
```

### 第三步：确认与保存

将生成的格式化内容展示给用户确认：

```
请确认以下录入内容是否正确：
[生成的内容]

1. 确认保存
2. 修改某处
3. 取消录入
```

### 第四步：写入知识库

用户确认后，将知识写入分类知识库文件。

4. 解决方案和操作步骤

**AI**: [生成格式化内容并确认]

**AI**: 请提供：
1. 参数名称

## 注意事项

1. **快速录入**：优先采用简洁问答，字段可灵活填空
2. **模板填充**：生成的内容必须包含模板的所有必填字段
3. **知识溯源**：鼓励添加参考来源，便于后续验证
4. **标签管理**：合理使用标签，便于知识检索和关联
