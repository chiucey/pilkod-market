### 1.4 特色分析

**多指标共振分析**
- 三金共振: MA金叉 + 均量线金叉 + MACD金叉
- 信号强度: 3指标共振 > 2指标共振 > 单指标

**成交量异常检测**
- 量增价跌: 可能主力出货
- 量缩价涨: 可能主力控盘
- 量增价涨: 健康上涨
- 量缩价跌: 可能见底

## 2. 基本面分析

### 2.1 估值因子

| 因子 | 计算公式 | 评判标准 |
|------|---------|---------|
| PE | 股价/每股收益 | 低于行业均值低估 |
| PB | 股价/每股净资产 | 低于1可能有价值陷阱 |
| PS | 股价/每股营收 | 成长股参考意义大 |
| 股息率 | 股息/股价 | >3%为高股息 |

### 2.2 盈利因子

| 因子 | 说明 |
|------|------|
| ROE | 净资产收益率，>15%为优质 |
| ROA | 总资产收益率 |
| 毛利率 | 护城河体现 |
| 净利率 | 盈利能力 |

### 2.3 成长因子

| 因子 | 说明 |
|------|------|
| 营收增速 | >10%为成长性良好 |
| 利润增速 | 稳定性重要 |
| 订单增速 | 先行指标 |

### 6.2 A股传导机制

```
地缘事件 → 油价波动 → 能源成本 → 通胀预期
     ↓
避险情绪 → 资金流向 → A股资金面
     ↓
情绪影响 → 市场波动 → 操作难度
```
