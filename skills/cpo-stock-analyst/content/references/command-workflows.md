# 指令执行详细流程

## 1. 分析报告指令（v3.5强制流程）

### ⚠️ 核心原则

**重要**: 每次生成分析报告前，**必须先获取实时数据**！使用实时数据源替代历史收盘数据。

### 执行流程（6步强制流程+v3.5 CPO重点）

```
实时行情获取 → 市场整体数据 → 历史数据采集 → 资金流向 → CPO主线分析 → 报告生成
```

### 详细步骤

#### 第1步: 获取实时行情数据（盘中必须）

**使用AKShare `stock_individual_spot_xq()` 接口:**

```python
import akshare as ak

# 获取上证指数实时数据
df = ak.stock_individual_spot_xq(symbol="SH000001")

# 获取深证成指实时数据
df = ak.stock_individual_spot_xq(symbol="SZ399001")

# 获取创业板实时数据
df = ak.stock_individual_spot_xq(symbol="SZ399006")

# 获取科创50实时数据
df = ak.stock_individual_spot_xq(symbol="SH000688")
```

**返回数据**: 实时点位、涨跌幅、成交量等

#### 第2步: 获取市场整体数据

**使用AKShare `stock_zh_a_spot_em()` 接口:**

```python
# 获取全市场实时快照
df = ak.stock_zh_a_spot_em()
# 返回：涨跌家数、成交额、涨跌停数量、市值等
```

#### 第3步: 获取历史数据（用于技术分析）

**使用AKShare `stock_zh_index_daily()` 接口:**

```python
# 获取指数日线数据
df = ak.stock_zh_index_daily(symbol="sh000001", start_date="20260101", end_date="20260408")
# 返回：近60日日线数据，用于计算均线、MACD、KDJ等技术指标
```

#### 第4步: 获取资金流向数据

**东方财富北向资金接口:**

```python
# 北向资金实时
# http://push2.eastmoney.com/api/qt/kamt.rtmin/get

# 融资融券数据
# http://push2.eastmoney.com/api/qt/kamt.rtmin/get
```

#### 第5步: CPO主线分析(v3.5重点)

**获取CPO产业链数据:**

```python
# CPO情绪因子分析
# 光模块情绪因子: cpo_module_sentiment
# CPO设备情绪因子: cpo_device_sentiment
# 光芯片情绪因子: optical_chip_sentiment

# 龙头新高追踪
# 龙头创新高数量: leader_new_high_count
# 新高加速度: new_high_acceleration
# 板块龙头强度: sector_leader_strength

# 缩量市场分析(v3.5)
# 成交量萎缩比例: volume_shrink_ratio
# 干粉比例: dry_powder_ratio
# 情绪降温指数: market_sentiment_cooling
```

#### 第6步: 报告生成

1. 按v3.5报告模板生成完整报告
2. 填充实时数据
3. 重点输出CPO主线分析
4. 输出缩量市场应对策略

## 3. 数据更新指令

### 执行流程

```
扫描数据源 → 获取数据 → 数据检核 → 虚拟数据处理 → 更新日志
```

### 详细步骤

#### 第1步: 扫描数据源

1. 检查主数据源状态
   - 东方财富API
   - 新浪财经API
   - 腾讯财经API
2. 检查备用数据源
3. 评估数据质量

#### 第2步: 获取数据

1. 获取实时行情
   - 指数数据
   - ETF数据
   - 资金流向
2. 获取历史数据
   - 日线数据
   - 分钟数据
3. 获取基本面数据
   - 财务数据
   - 公告数据

#### 第3步: 数据检核

1. 完整性检查
   - 交易日数据不应缺失
2. 一致性检查
   - 同日期不同源偏差 < 1%
3. 逻辑性检查
   - 最高价 >= 收盘价 >= 最低价
4. 异常标记
   - 异常数据标记并记录

#### 第4步: 虚拟数据处理

1. 节假日数据处理
   - 标记为虚拟数据
   - 设置置信度 < 0.8
2. 接口故障数据
   - 尝试备用数据源
   - 无法获取则虚拟
3. 历史缺失数据
   - 补充或标记


## 5. 报告优化指令

### 执行流程

```
获取最新数据 → 扩充分析维度 → 深度解读 → 输出优化报告
```

### 扩充的分析维度

1. **行业对比分析**
   - 领涨板块 vs 落后板块
   - 行业轮动分析

2. **跨市场联动**
   - 美股对A股影响
   - 港股联动分析
   - 期指对现货影响

3. **资金流向深度**
   - 北向资金来源
   - 融资融券变化
   - 主力资金动向

4. **政策解读**
   - 最新政策影响
   - 政策预期分析

5. **热点追踪**
   - 最强主题
   - 投资逻辑验证

6. **风险预警**
   - 最新风险因素
   - 应对建议
