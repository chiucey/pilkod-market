# 风险管理详细策略

## 1. 三道防线体系

### 第一道防线: 仓位控制

**仓位规则**

| 规则 | 数值 | 说明 |
|------|------|------|
| 最大单只仓位 | 30% | 分散风险 |
| 最大总仓位 | 95% | 保留现金 |
| 最小仓位 | 5% | 避免无效交易 |

**动态仓位调整**

| 市场状态 | 置信度 | 仓位比例 |
|---------|--------|---------|
| 高确定性信号 | 高 | 60-80% |
| 中确定性信号 | 中 | 40-60% |
| 低确定性信号 | 低 | 20-40% |

### 第二道防线: 策略分散

**配置原则**

1. **行业分散**
   - 单行业仓位 <= 30%
   - 覆盖2-4个不同行业

2. **风格分散**
   - 成长 + 价值
   - 进攻 + 防御

3. **因子分散**
   - 多Alpha因子组合
   - 低相关性

**分散配置示例**

```
总仓位: 80%
├── 成长股配置(40%)
│   ├── AI算力: 20%
│   └── 新能源: 20%
└── 防御股配置(40%)
    ├── 高股息: 25%
    └── 消费: 15%
```

### 第三道防线: 止损纪律

**止损规则**

| 类型 | 触发条件 | 执行动作 |
|------|---------|---------|
| 硬性止损 | 亏损7% | 无条件清仓 |
| 移动止损 | 回撤3% | 止损上移 |
| 时间止损 | 持有超限 | 审视持仓 |

## 2. 仓位管理策略

### 三分动态仓位法

**仓位分配**

| 仓位类型 | 比例 | 用途 | 持有周期 |
|---------|------|------|---------|
| 底仓 | 50% | 长期配置 | 3-6个月 |
| 趋势仓 | 20% | 中期机会 | 1-3个月 |
| 现金储备 | 10% | 应急/机会 | - |

**调整信号**

| 信号类型 | 调整动作 |
|---------|---------|
| 趋势确认 | 增加趋势仓 |
| 趋势破位 | 减至底仓 |
| 极端机会 | 动用现金储备 |

### 分批建仓策略

**入场分批**

| 买点 | 仓位 | 条件 |
|------|------|------|
| 第一买点 | 33% | 支撑位 + 买入信号 |
| 第二买点 | 33% | 趋势确认 + 回调点 |
| 第三买点 | 34% | 追涨 + 趋势强劲 |

## 3. 止损止盈体系

### 止损策略

**硬性止损**

```python
HARD_STOP_LOSS = {
    "threshold": 0.07,  # 7%亏损
    "action": "exit_all",
    "no_exception": True
}
```

**移动止损**

```python
TRAILING_STOP = {
    "activation": "profit_only",
    "pullback_distance": 0.03,  # 3%回撤
    "lock_profit": True
}
```

**移动止损执行示例**

```
买入价: 10.00元
最高价: 11.00元 (+10%)
止损位: 10.67元 (11.00 - 3%)
```

### 止盈策略

**双止盈规则**

```python
DUAL_TAKE_PROFIT = {
    "first_target": {
        "threshold": 0.03,  # 3%
        "action": "sell_half"
    },
    "second_target": {
        "threshold": 0.08,  # 8%
        "action": "sell_30%"
    }
}
```

**止盈执行示例**

```
买入价: 10.00元
第一止盈: 10.30元 → 卖出50%
第二止盈: 10.80元 → 卖出30%
保留仓位: 20% → 博取更大趋势
```

### 止盈止损对比

| 策略 | 优点 | 缺点 |
|------|------|------|
| 固定止损 | 简单执行 | 可能被洗出 |
| 移动止损 | 锁定利润 | 可能踏空 |
| 时间止损 | 控制无效持仓 | 可能错过机会 |

## 4. VaR风险指标体系

### VaR计算

```python
VAR_CONFIG = {
    "confidence_levels": [0.95, 0.99],
    "method": "historical_simulation",
    "lookback_period": "252d",
    "update_frequency": "daily"
}
```

### VaR指标说明

| 指标 | 置信度 | 含义 |
|------|--------|------|
| 日VaR(95%) | 95% | 95%概率日损失不超过此值 |
| 日VaR(99%) | 99% | 99%概率日损失不超过此值 |
| CVaR(95%) | 95% | 极端损失情况下的平均值 |

### VaR应用规则

```python
VAR_RULES = {
    "var_breach_action": "reduce_position",
    "var_breach_threshold": 0.02,  # VaR超过2%需减仓
    "max_var_95": 0.02,
    "max_var_99": 0.04
}
```

## 5. 回撤管理

### 最大回撤控制

```python
DRAWDOWN_CONTROL = {
    "max_drawdown_tolerance": 0.15,  # 15%
    "warning_level": 0.10,  # 10%预警
    "action_at_warning": "reduce_20pct",
    "action_at_max": "reduce_50pct"
}
```

### 回撤应对策略

| 回撤水平 | 应对措施 |
|---------|---------|
| < 5% | 正常持有 |
| 5-10% | 预警，减仓20% |
| 10-15% | 减仓50%，审视持仓 |
| > 15% | 强制清仓至30% |

## 6. 黑天鹅应对

### 尾部风险对冲

```python
TAIL_RISK_HEDGE = {
    "enabled": True,
    "hedge_ratio": 0.05,  # 5%仓位对冲
    "instruments": ["put_options", "vix ETF"],
    "activation": {
        "vix_above": 25,
        "drawdown_above": 0.05
    }
}
```

### 应急预案

**流动性枯竭应对**

1. 优先卖出高流动性品种
2. 避免在流动性极差时卖出
3. 考虑大额卖出分批执行

**市场暂停交易**

1. 启用期权对冲
2. 准备期货对冲
3. 关注盘后公告
