## 一、分析方法选择指南

### 按分析目的分类

| 分析目的 | 方法 | 适用场景 |
|----------|------|----------|
| 描述发生了什么 | 描述性统计、趋势图、同比环比 | 月报、周报、仪表板 |
| 解释为什么发生 | 相关性分析、回归分析、分层分析 | 问题诊断、归因分析 |
| 预测未来会怎样 | 时间序列、机器学习模型 | 销售预测、流失预测 |
| 决定该怎么做 | A/B测试、决策树、优化模型 | 策略选择、资源分配 |

### 统计检验选择

| 场景 | 推荐检验 | Python方法 |
|------|----------|-----------|
| 比较两组均值 | t检验（独立样本） | `scipy.stats.ttest_ind` |
| 比较多组均值 | 单因素ANOVA | `scipy.stats.f_oneway` |
| 比较转化率 | z检验（比例） | `statsmodels.stats.proportion.proportions_ztest` |
| 检验分布差异 | Kolmogorov-Smirnov | `scipy.stats.ks_2samp` |
| 分析变量相关性 | Pearson/Spearman相关系数 | `scipy.stats.pearsonr` / `spearmanr` |
| 时间序列趋势 | Mann-Kendall趋势检验 | `pymannkendall` |
| 非正态小样本 | Mann-Whitney U 检验 | `scipy.stats.mannwhitneyu` |

## 二、A/B 测试规范

### 样本量计算公式

$$n = \frac{(z_{\alpha/2} + z_\beta)^2 \cdot 2\sigma^2}{\delta^2}$$

其中：
- `z_α/2 = 1.96`（双侧，α=0.05）
- `z_β = 0.84`（统计功效80%）或 `1.28`（90%）
- `δ`：最小可检测效应（MDE）
- `σ`：总体标准差

**Python 快速计算**：
```python
from scipy import stats
import numpy as np

def sample_size_for_means(baseline_mean, mde_pct, std, alpha=0.05, power=0.8):
    """计算两组均值比较所需样本量（每组）"""
    mde = baseline_mean * mde_pct
    effect_size = mde / std
    analysis = TTestIndPower()
    n = analysis.solve_power(effect_size=effect_size, alpha=alpha, power=power)
    return int(np.ceil(n))

def sample_size_for_proportions(p_baseline, mde_pct, alpha=0.05, power=0.8):
    """计算转化率A/B测试所需样本量（每组）"""
    p_treatment = p_baseline * (1 + mde_pct)
    analysis = NormalIndPower()
    effect_size = proportion_effectsize(p_baseline, p_treatment)
    n = analysis.solve_power(effect_size=effect_size, alpha=alpha, power=power)
    return int(np.ceil(n))
```

### A/B 测试结果解读框架

1. **检查随机性**：SRM（样本比率不匹配）检验，确认分流无偏
2. **主要指标**：p值 + 置信区间 + 效应量（不只看p值！）
3. **辅助指标**：确认无意外负面影响
4. **实践显著性**：效应量是否大于业务阈值？
5. **多重比较校正**：测试多个指标时使用 Bonferroni 或 BH 校正

## 三、RFM 分析框架

### 评分标准（以5分制为例）

| 维度 | 含义 | 评分规则 |
|------|------|----------|
| R (Recency) | 最近一次购买距今天数 | 越近 = 分数越高（5=最近）|
| F (Frequency) | 购买频率 | 越多 = 分数越高 |
| M (Monetary) | 累计消费金额 | 越高 = 分数越高 |

### 客户细分矩阵

| 细分类型 | RFM 特征 | 建议策略 |
|----------|----------|----------|
| 冠军客户 | R高/F高/M高 | 奖励忠诚，邀请推荐，提前享新品 |
| 忠诚客户 | F高/M高 | 会员计划，交叉/向上销售 |
| 潜力客户 | R高/F低 | 引导复购，推荐相关品类 |
| 新客户 | R高/F低/M低 | 入门优惠，产品教育，建立习惯 |
| 高风险客户 | R低/曾经高 | 挽回活动，专属优惠，问卷调研 |
| 流失客户 | R极低/F低 | 低成本邮件/短信，最后一搏优惠 |

## 五、报告写作规范

### 执行摘要写作原则（BLUF 原则）

**Bottom Line Up Front**：先说结论，再说证据。

**好的执行摘要结构**：
```
1. 核心发现（1句话）
2. 量化业务影响
3. 主要证据（2-3点）
4. 推荐行动
5. 所需决策/资源
```

**禁止**：
- 开头铺垫分析背景（先说结果！）
- 大量数字堆砌无解释
- 技术术语不加说明
- 含糊的建议（"进一步研究"、"持续关注"）

### 可视化选择指南

| 数据关系 | 推荐图表类型 |
|----------|-------------|
| 趋势变化 | 折线图（Line Chart）|
| 占比构成 | 饼图/环形图（<6类），堆积柱状图（≥6类）|
| 分布形态 | 直方图、箱线图 |
| 两变量相关 | 散点图（Scatter Plot）|
| 多类别对比 | 条形图（水平）或柱状图（垂直）|
| 地理分布 | 热力地图（Choropleth）|
| 部分与整体 | 瀑布图（Waterfall）|
| 多维度雷达 | 雷达图（≤8维）|

### 置信度标注规范

所有结论应标注置信度等级：

- 🟢 **高置信度**：基于统计显著结果（p < 0.05），样本量充足
- 🟡 **中置信度**：趋势明显但样本量偏小，或结果接近显著性边界
- 🔴 **低置信度**：初步观察，需更多数据验证，或数据质量存疑

## 六、常见分析陷阱

| 陷阱 | 说明 | 应对方法 |
|------|------|----------|
| 幸存者偏差 | 只分析留存用户，忽略已流失用户 | 确保分析包含全量用户 |
| 辛普森悖论 | 整体趋势与分组趋势相反 | 对关键变量分层后再汇总 |
| p值滥用 | 大样本下细微差异也显著 | 同时报告效应量（Cohen's d / η²）|
| 相关 ≠ 因果 | 两指标同时变动不代表因果关系 | 设计RCT或使用准实验方法 |
| 多重比较 | 同时测100个指标必然有5个"显著" | Bonferroni校正或预先明确主要指标 |
| 时间窗口偏差 | 选取特殊时间段导致结论失真 | 对比多个时间窗口，标注季节性 |
