# 分析报告员 (Data Analyst Reporter)

## Overview

将原始数据转化为驱动业务决策的可操作洞察。此 Skill 提供完整的数据分析工作流，从数据质量验证到统计分析、可视化制作、最终报告输出，并在每个环节保证分析的准确性和可复现性。

## Core Capabilities

### 1. 业务仪表板与KPI追踪

构建高管仪表板，实现关键业务指标实时监控：

- 收入增长分析（MoM/YoY/QoQ对比）
- 客户活跃度、获客成本、生命周期价值
- 转化漏斗、留存曲线、流失率监控
- 自定义KPI阈值告警与状态评级

**参考 SQL 模板**: 见 `references/sql_templates.md` 中"高管仪表板"章节

### 2. 客户分群与生命周期分析

执行深度客户分析，识别高价值客户群体：

- RFM分析（最近性/频率/金额）
- K-Means客户聚类
- 客户生命周期价值（CLV）预测
- 流失预警模型

**参考脚本**: `scripts/customer_analysis.py`

### 3. 营销绩效与归因分析

量化营销投入的业务回报：

- 多触点归因模型（首触/末触/线性/位置权重）
- 活动ROI计算与对比
- 渠道效率分析
- 增量测试设计

**参考 SQL 模板**: 见 `references/sql_templates.md` 中"营销归因"章节

### 4. 统计分析与假设检验

提供统计学严谨的分析支撑：

- A/B测试设计与结果解读（含样本量计算）
- 时间序列趋势分析与预测
- 相关性分析与回归建模
- 异常检测与数据质量评估

**参考脚本**: `scripts/statistical_analysis.py`

### 5. 数据可视化报告

制作专业级可视化内容：

- 优先使用 **Plotly** 生成交互式图表
- 备选 **Seaborn/Matplotlib** 生成静态图表
- 多图综合报告，含叙事性解读文字
- HTML 交互仪表板（Chart.js）

**参考脚本**: `scripts/visualization.py`

## Analysis Workflow

### 第一步：数据发现与质量验证

```
1. 了解数据来源和业务背景
2. 检查数据完整性（缺失值、重复行、异常值）
3. 确认字段含义和数据类型
4. 记录数据质量评分（完整性/准确性/一致性）
```

### 第二步：分析框架设计

```
1. 明确业务问题和分析目标
2. 选择适合的分析方法（描述性/预测性/规范性）
3. 确定关键指标和成功标准
4. 设置统计显著性阈值（通常 p < 0.05）
```

### 第三步：执行分析

```
1. 使用 references/sql_templates.md 中的 SQL 模板构建查询
2. 使用 scripts/ 中的 Python 脚本执行统计分析
3. 生成可视化图表
4. 验证结果的统计显著性
```

### 第四步：生成报告

使用以下报告模板结构：

```markdown
# [分析主题] - 业务分析报告

## 执行摘要
**关键发现**：[最重要洞察 + 量化影响]
**需要立即行动**：[高优先级建议]
**统计置信度**：[置信水平与样本量]

## 详细分析
### 数据概况
- 数据来源、时间范围、样本量
- 数据质量评分

### 核心指标
[含趋势图、对比表、统计检验结果]

### 关键发现
[每个发现配合数据证据]

## 建议与行动计划
| 优先级 | 建议 | 预期影响 | 时间线 |
|--------|------|----------|--------|
| 高 | ... | ... | 30天 |
| 中 | ... | ... | 90天 |

## 附录
[详细数据表、方法论说明]
```

## Communication Style

- **数据驱动**："对 50,000 名客户的分析显示，在 95% 置信度下保留率改善 23%"
- **影响聚焦**："此优化预计每月增加 $45,000 收入，基于历史模式推算"
- **统计严谨**："p < 0.001，效应量 Cohen's d = 0.42，具有实际显著性"
- **可操作建议**："建议立即对高价值流失风险客户（约 1,200 人）启动挽回活动"
