# 租房合同诈骗风险识别技能

## 一、技能概述

本技能专门用于帮助个人租户识别和防范租房合同中的各类诈骗风险。用户可通过上传合同文件（PDF、图片）或粘贴合同文本，获取详细的诈骗风险分析和专业审核报告。

### 触发场景

- 上传/提交租房合同进行审核
- 签署租房合同前进行风险评估
- 遇到异常优惠的房源需要核实
- 房东要求绑定银行卡或授权贷款
- 合同条款模糊或存在歧义需要分析
- 对租房流程有疑虑需要专业建议

### 技能能力

- **合同内容提取**：支持PDF、图片、文本等多种格式
- **智能风险识别**：基于关键词和条款模式识别诈骗风险
- **详细报告生成**：逐条分析、风险分级、修改建议
- **专业法律参考**：引用相关法律法规进行合规性评估

## 三、风险识别核心维度

### 3.1 金融诈骗风险（最高优先级）

**租房合同变贷款合同**

| 危险信号 | 风险等级 | 说明 |
|---------|---------|------|
| 合同中出现"授信"、"额度"、"分期" | 极高 | 警惕贷款条款伪装 |
| 要求绑定银行卡并预授权 | 极高 | 可能是自动扣款授权 |
| 提及"信用支付"、"消费分期" | 极高 | 租金可能变贷款 |
| 合同名称含"贷"字 | 极高 | 正规租房合同不应有贷 |
| 要求下载特定APP注册 | 高 | 可能为贷款平台 |
| 强调"免押金"、"租金优惠" | 高 | 可能有对价陷阱 |
| 签署页显示"贷款确认"按钮 | 极高 | 必须停止签约 |

**正常租房合同特征**

- 仅涉及租金金额和支付周期
- 仅需提供银行卡号用于转账
- 签署文件标题为"租房合同"
- 签约平台为正规中介或房东直租

### 3.2 主体资格风险

| 风险点 | 风险等级 | 识别方法 |
|-------|---------|---------|
| 出租方非房东本人 | 高 | 核实授权委托书 |
| 房东身份信息缺失 | 高 | 要求补充证件 |
| 房屋权属不明确 | 高 | 要求房产证核实 |
| 中介无经营资质 | 中 | 核实营业执照 |
| 代理人超越授权 | 中 | 核对授权范围 |

### 3.3 费用条款风险

**租金相关**

| 风险点 | 风险等级 | 正常标准 |
|-------|---------|---------|
| 租金明显低于市场价30%+ | 极高 | 参考同区域均价 |
| 租金支付至第三方账户 | 高 | 应支付至房东本人账户 |
| 租金递增条款不合理 | 高 | 涨幅不超过10%/年 |
| 要求预付多个月租金 | 中 | 一般不超过3个月 |

**押金相关**

| 风险点 | 风险等级 | 正常标准 |
|-------|---------|---------|
| 押金超过月租金100% | 高 | 一般为1-2个月租金 |
| 押金退还条件模糊 | 中 | 应明确无损坏全额退还 |
| 押金退还时限不明确 | 中 | 一般不超过15个工作日 |
| 扣除押金情形未明确 | 中 | 应列举具体情形 |

**隐藏费用**

| 风险点 | 风险等级 |
|-------|---------|
| 物业费、取暖费未明确 | 中 |
| 中介费标准不透明 | 中 |
| 违约金金额过高 | 中 |
| 存在服务费、管理费等 | 中 |

### 3.4 合同条款风险

**租赁期限**

- 起止日期不明确 → 中风险
- 续租条件不明确 → 中风险
- 提前解约条款不公平 → 高风险

**房屋维修**

- 维修责任划分不清 → 中风险
- 损坏认定标准模糊 → 中风险
- 维修响应时限缺失 → 中风险

**违约责任**

- 双方违约责任不对等 → 高风险
- 违约金明显过高 → 中风险
- 不可抗力条款缺失 → 中风险

## 八、应急处理预案

### 如已签署可疑合同

**立即行动**

1. 停止一切后续操作
2. 不要继续支付任何款项
3. 联系银行冻结相关账户
4. 保留所有签署和沟通证据

**紧急联系**

- 报警：110
- 消费者投诉：12315
- 法律援助：12348
- 银监会投诉：12378
- 工商投诉：12315

### 如发现已陷入贷款诈骗

**止损步骤**

1. 立即联系放贷机构核实情况
2. 向中国人民银行征信中心查询征信
3. 申请征信异议处理
4. 必要时向公安机关报案

### 相关法律法规

- 《中华人民共和国民法典》合同编
- 《中华人民共和国消费者权益保护法》
- 《住房租赁条例》
- 《房地产经纪管理办法》

### 关键法条提示

1. **押金条款**：不得超过2个月租金
2. **违约金**：不得超过实际损失的30%
3. **合同解除**：提前通知即可，无需违约金
4. **维修责任**：正常使用导致的损坏由房东承担

## 十一、分析示例

### 示例：典型贷款诈骗合同分析

**上传合同内容摘要**

```
XX租房平台服务协议

甲方（出租方）：XX公寓管理有限公司
乙方（承租方）：[用户]

第一条 租赁标的
房屋位于[地址]，建筑面积约60㎡...

第二条 费用及支付
1. 房屋租金为人民币2800元/月
2. 乙方同意授权甲方从其银行账户（尾号XXXX）
   每月自动扣款用于支付租金...
3. 乙方理解并同意，本协议项下的租金支付服务
   由XX金融提供，乙方绑定银行卡即视为同意
   《XX金融用户授信协议》...

[后续条款省略]
```

**风险识别结果**

```
检测到极高风险：
- 合同名称实际为"服务协议"而非"租房合同"
- 要求绑定银行卡并自动扣款
- 提及"授信协议"和金融合作
- 存在将租金转变为贷款的重大风险
```

**审核结论**

```
综合风险等级：极高风险

建议决策：【立即停止签约】

如已签署，请立即：
1. 冻结关联银行卡
2. 联系XX金融核实授信情况
3. 检查个人征信记录
4. 必要时报警处理
```
