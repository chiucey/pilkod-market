# Stock Monitor - A股智能股票侦察兵

基于五维信号评分引擎的A股智能选股系统，融合资金流向、机构持仓、技术动能等多维度数据，输出可执行的选股信号。

## 核心功能

### 1. 五维评分引擎

| 维度 | 权重 | 数据来源 | 信号逻辑 |
|------|------|----------|----------|
| 北向资金 | 25% | 沪深港通持股数据 | 持股比例越高+近期增持=强信号 |
| 主力资金流 | 25% | 个股资金流向 | 大单净流入+主力净流入双强 |
| 融资余额 | 15% | 融资融券数据 | 逆向指标：余额激增=见顶预警 |
| 技术动能 | 20% | 价格+换手率 | 适度涨幅+高换手=活跃信号 |
| 券商评级 | 15% | 券商金股推荐 | 高评级+大目标价空间=强买入 |

### 2. 信号类型

- **🟢 资金流入** - 主力+北向双强，强势信号
- **🔵 北向加码** - 北向持股明显增加，机构资金介入
- **🟡 启动信号** - 多维度正向，处于启动初期
- **🟠 高位警示** - 融资余额激增+主力流出，短期回调风险
- **🔴 下降趋势** - 技术空头+资金持续流出

### 3. 评分等级

| 评分范围 | 信号等级 | 操作建议 |
|----------|----------|----------|
| 80-100 | 🟢 强势信号 | 重点关注，可考虑买入 |
| 65-79 | 🔵 偏强信号 | 持续观察，择机布局 |
| 50-64 | 🟡 中性信号 | 谨慎观望，等待确认 |
| 35-49 | 🟠 偏弱信号 | 回避为主 |
| 0-34 | 🔴 弱势信号 | 建议卖出/规避 |

## 使用指南

### 快速开始

1. **运行侦察脚本**：
   ```bash
   cd /workspace/stock-monitor
   python run_tencent_fast.py
   ```

2. **更新股票池**（定期执行）：
   ```bash
   python build_pool.py
   ```

3. **调整评分参数**：编辑 `config.py` 中的权重配置

### 配置文件说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `MIN_SCORE` | 65 | 进入Scout结果的最低评分阈值 |
| `MIN_HK_HOLD_PCT` | 1 | 最低北向持股百分比 |
| `WEIGHT_*` | 见上表 | 各维度评分权重 |

### 数据源

- **股票列表**：东方财富全市场股票列表（含证监会行业分类）
- **行情数据**：腾讯财经免费API
- **资金流向**：东方财富资金流数据
- **北向持股**：沪深港通持股数据
- **券商评级**：Tushare券商推荐数据

## 适用场景

- **日常选股**：获取每日股票侦察报告
- **趋势分析**：识别资金流向和机构动向
- **风险预警**：发现高位警示和下降趋势股票
- **组合参考**：结合券商评级和技术信号做投资决策
- **定期复盘**：分析持仓股票的最新评分变化

## 注意事项

1. 本工具仅供辅助决策，不构成投资建议
2. 评分结果基于历史数据，存在滞后性
3. 建议结合基本面分析和市场环境综合判断
4. 股票池和评分参数需定期更新维护
