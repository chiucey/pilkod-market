# 评分系统详细说明

## 五维评分算法

### 1. 北向资金评分（权重 25%）

北向资金是A股市场最重要的机构资金风向标。

**评分逻辑：**
- 持股比例 >= 10%：极强信号（+20分额外加分）
- 持股比例 > 5%：强信号（每超1%加4分）
- 持股比例 < 最低阈值：0分

**计算公式：**
```
基础分 = min(60, pct × 4)
加分项 = min(20, (pct - 5) × 4)  [当 pct > 5%]
极强加分 = 20  [当 pct > 10%]
最终分 = min(100, 基础分 + 加分项 + 极强加分)
```

### 2. 主力资金流评分（权重 25%）

追踪机构级大单资金动向。

**评分逻辑：**
- 大单净流入 > 1亿：+15分
- 大单净流入 > 5000万：+10分
- 主力净流入配合：每2000万+1分
- 大单净流出 > 1亿：-20分

### 3. 融资余额评分（权重 15%）

**逆向指标**，融资余额激增通常是见顶信号。

| 融资余额变动 | 评分调整 |
|-------------|---------|
| > +30% | -25分 |
| > +20% | -15分 |
| > +10% | -8分 |
| < -30% | +15分（见底可能）|
| < -20% | +10分 |

### 4. 技术动能评分（权重 20%）

**最佳区间**：涨幅2%-6% + 换手率3%-10%

| 涨跌幅区间 | 评分调整 |
|-----------|---------|
| -5% ~ +2% | +10分（温和上涨）|
| +2% ~ +6% | +15分（稳健上涨）|
| +6% ~ +9% | +8分（强势）|
| > +9% | -10分（接近涨停）|

| 换手率区间 | 评分调整 |
|-----------|---------|
| > 10% | +10分 |
| > 5% | +7分 |
| > 2% | +3分 |
| < 0.5% | -5分 |

### 5. 券商评级评分（权重 15%）

| 评级 | 评分调整 |
|------|---------|
| >= 4.5 | +25分 |
| >= 4.0 | +18分 |
| >= 3.5 | +10分 |
| >= 3.0 | +5分 |

**目标价空间：**
- 空间 >= 50%：+15分
- 空间 >= 30%：+10分
- 空间 >= 15%：+5分
- 空间 < -20%：-15分

## 信号类型判断规则

### 资金流入信号
条件：看涨计数 >= 4 且看跌计数 <= 1
- 北向持股 > 5%
- 主力净流入 > 5000万
- 融资余额未激增

### 北向加码信号
条件：看涨计数 >= 3 且 北向持股 > 3%
- 北向持股明显增加
- 资金面稳定

### 启动信号
条件：看涨计数 >= 3 且 券商评级 >= 4.0
- 多维度正向
- 券商强烈推荐

### 高位警示信号
条件：看跌计数 >= 4 或 融资余额变动 > 30%
- 融资余额激增
- 主力净流出
- 北向资金减少

### 下降趋势信号
条件：看涨计数 <= 1 且 看跌计数 >= 3
- 技术空头排列
- 资金持续流出

## 评分阈值说明

| 阈值 | 含义 |
|------|------|
| 65分 | 进入Scout结果的最低门槛 |
| 80分 | 强势信号，可重点关注 |
| 50分 | 中性分界线 |
