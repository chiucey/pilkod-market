# 识人九段 - 参考手册与实用指南

## 信息收集引导话术

### 第一类：开放性问题（用于初步了解）

```
"能和我聊聊您最近在忙的事情吗？"
"在您的工作/生活中，有没有让您特别有成就感的事情？"
"如果让您回忆一段重要的经历，您会想到什么？"
"您平时下班后会做些什么？"
```

### 第二类：追问性问题（用于深入底层储备）

**关于最佳战绩**
```
"您提到过[成就事件]，能详细说说当时的情况吗？"
"在那个过程中，您扮演了什么角色？"
"您认为那件事成功最关键的因素是什么？"
"当时遇到的最大的挑战是什么？"
```

**关于克服困难**
```
"在那段时间，有没有让您觉得特别困难、甚至想放弃的时刻？"
"当时您是怎么处理的？"
"回过头来看，那段经历给您带来了什么？"
```

**关于遗憾和不足**
```
"如果有机会重来，您会在哪些方面做得不一样？"
"目前有什么事情让您觉得还有提升空间？"
"您觉得自己在哪些方面还需要学习？"
```

### 第三类：情境性问题（用于评估知行能力）

```
"假设您现在要[描述一个具体任务]，您会怎么做？"
"如果您发现原来的方法行不通，会怎么办？"
"当您的想法和其他人不一样时，您通常怎么处理？"
"面对一个完全陌生的领域，您会怎么开始？"
```

## 分析维度详解

### 人设三角函数评估标准

| 维度 | 真实信号 | 伪装信号 |
|------|---------|---------|
| 经济实力 | 消费习惯稳定、选品有逻辑、不刻意炫耀 | 超出收入水平的消费、频繁换新、刻意展示logo |
| 身份角色 | 单一专注的身份、投入与产出匹配 | 多重身份、名实不符、身份间跳跃 |
| 言谈举止 | 紧跟话题、逻辑顺畅、情绪鲜活 | 话题跳跃、自相矛盾、情绪僵硬/过度表演 |

### 兴奋点识别清单

**高兴奋信号**
- 🔥 眼睛亮了、瞳孔放大
- 🔥 语速加快、音量提高
- 🔥 身体前倾、手舞足蹈
- 🔥 反复提及、主动延展话题
- 🔥 主动占用更多交流时间

**低兴奋/回避信号**
- 😶 眼神飘移、回避话题
- 😶 语速变慢、音量降低
- 😶 身体后倾、手臂收紧
- 😶 简短回答、话题转移
- 😶 频繁看时间或环境

### 知行高效评估框架

**目标清晰度**
- 🔴 不清晰：不知道自己要什么，频繁变换方向
- 🟡 模糊：有方向但无具体目标，容易被干扰
- 🟢 清晰：大小知统一，知道自己在做什么、为什么做

**方法得当度**
- 🔴 不当：不懂规则蛮干，或只守规则不敢突破
- 🟡 一般：能遵守规则，但创新不足
- 🟢 得当：充分了解规则，必要时能创新突破

**知行合一度**
- 🔴 低：知道但做不到，借口多、行动少
- 🟡 中：能部分执行，但易受干扰
- 🟢 高：言行一致，排除干扰达成目标

### 升维思考评估方法

**回溯推理测试**
- 请对方分析一个已发生事件的原因
- 观察其是否能从事物的多角度分析
- 能否看到表面原因背后的深层逻辑

**战略前瞻测试**
- 请对方描述对未来发展的预判
- 观察其是否有系统性的分析框架
- 能否考虑长期影响和趋势

**俯瞰全局测试**
- 请对方分析一个复杂问题的多个维度
- 观察其是否能平衡多方利益
- 能否从更高视角看问题

### 容人有度评估维度

**容人范围**
- 独狼型：只能容下自己，难以与人合作
- 小圈型：只容三五知己，排他性强
- 团队型：能容团队成员，协作顺畅
- 领袖型：能容大量不同类型的人

**容人策略**
- 权威型：用权力和制度管理
- 心智型：用智慧和逻辑说服
- 愿景型：用目标和理想凝聚
- 情感型：用情感和信任维系
- 笼络型：用利益交换控制

### 情绪稳定性评估

**六界情绪定位**

| 情绪类型 | 触发条件 | 稳定表现 | 不稳定表现 |
|---------|---------|---------|-----------|
| 惊讶 | 意外+关心 | 适度好奇、理性分析 | 大惊小怪、过度反应 |
| 厌恶 | 不认同、不接受 | 合理回避、保持距离 | 不当厌恶、过度排斥 |
| 愤怒 | 解决方案窘迫 | 控制情绪、寻求出路 | 易怒失控、迁怒他人 |
| 恐惧 | 自信上限 | 理性评估、量力而行 | 过度担忧、逃避现实 |
| 悲伤 | 无力改变 | 接受现实、寻求支持 | 沉溺悲伤、无法自拔 |
| 愉悦 | 收益感/优越感 | 适度享受、分享快乐 | 得意忘形、炫耀优越 |

### 心态开放度评估

**高开放度特征**
- ✅ 能听劝：愿意听取不同意见
- ✅ 能认错：承认自己的不足和错误
- ✅ 方案多样：解决问题的方法丰富
- ✅ 主动学习：持续学习新知识新技能
- ✅ 对未知好奇：愿意尝试新事物

**低开放度特征**
- ❌ 偏执不听劝：固执己见
- ❌ 不认错：即使错了也不承认
- ❌ 方法简单：解决问题简单粗暴
- ❌ 抵触新知：对新信息不感兴趣
- ❌ 负面情绪多：容易被顺从安抚

### 使命愿景评估

**真使命特征**
- 🎯 有明确的专注领域
- 🎯 有底层储备支撑
- 🎯 能接受长期投入
- 🎯 遇到困难不放弃
- 🎯 不轻易被利益诱惑

**伪愿景特征**
- 🚫 空泛流行词汇
- 🚫 没有储备支撑
- 🚫 追求短期利益
- 🚫 遇到困难就换方向
- 🚫 容易被外界影响

## 常见场景分析要点

### 场景一：商业合作候选人评估

```
重点关注：
1. 底层储备与当前项目的匹配度
2. 知行效率（能否落地执行）
3. 容人格局（能否带团队）
4. 使命愿景（是否长期主义）

关键问题：
- "您之前做过类似的项目吗？"
- "当时遇到的最大挑战是什么？"
- "您理想中的事业是什么样的？"
```

### 场景二：团队成员潜力评估

```
重点关注：
1. 学习能力（心态开放度）
2. 抗压能力（情绪稳定性）
3. 执行力（知行合一度）
4. 发展意愿（使命愿景）

关键问题：
- "您希望三年后成为什么样的人？"
- "最近有什么让您感到压力的事？"
- "您是怎么学习的？"
```

### 场景三：人际交往深度评估

```
重点关注：
1. 言行一致性（人设真实度）
2. 情绪稳定性（可预测性）
3. 容人范围（相处舒适度）
4. 价值观匹配（长期相处基础）

关键问题：
- "您一般周末会做什么？"
- "和朋友有分歧时您怎么处理？"
- "您最看重朋友什么特质？"
```

## 使用注意事项

### ⚠️ 避免的误区

1. **以偏概全**：单一观察不能定论，需多维度验证
2. **过度解读**：行为信号仅供参考，不是绝对
3. **静态判断**：人是变化的，分析结果需动态更新
4. **主观偏见**：避免先入为主，保持客观中立

### ✅ 正确的心态

1. **理解导向**：洞察是为了更好地理解，而非评判
2. **合作视角**：寻找适合的相处模式，而非改变对方
3. **持续更新**：随着了解的深入，不断修正分析
4. **伦理边界**：用于帮助和保护，不用于操控和伤害
