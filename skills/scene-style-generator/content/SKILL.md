# 场景风格生成器

## 核心能力

对用户上传的场景图片进行深度风格分析，提取建筑风格、材质、光影、色调、氛围、构图视角等全部视觉要素，输出可直接用于 nano banana 的高质量场景提示词。同时支持根据需求在同一风格体系下扩展：生成不同场景类型（如将室内客厅扩展为同风格宴会厅）或提供该场景的其他视角描述。

## 触发方式

用户上传场景图片 + 说明需求，触发本 Skill。

常见需求表达：
- "分析一下这个场景的风格"
- "描述一下这个图的构图和视角"
- "给我一个这个室内风格一致的 XXX 场景提示词"
- "这个新古典主义场景的其他视角"
- "把这个风格用到 XXX 场景"
- "把这个风格复刻到 XXX"

## 执行流程

### 第 1 步：图像深度分析

对上传的场景图片系统性提取以下五大维度要素：

---

#### A. 建筑与空间风格
- 建筑风格（新古典主义/Art Deco/法式/现代极简/工业风/伊斯兰/中式/有机主义等）
- 空间类型（室内/室外/半室内外/庭院/车内外等）
- 层高与空间尺度感
- 地面、墙面、天花的材质与处理方式
- 门窗形态与比例（纵向长方/方形/拱形等，窗框颜色与材质）
- 装饰元素（线条/雕花/壁灯/画框/家具/百叶窗等）

#### B. 光影与氛围
- 光源类型（自然光/人工光/混合光/烛光等）
- 光线方向（顺光/侧光/逆光/顶光/散射光/侧逆光等）
- 光质（硬光/柔光/斑驳光/金色时刻光/午后硬光等）
- 色调（冷/暖/中性，明度高低）
- 氛围关键词（庄重/温馨/浪漫/冷峻/怀旧/奢华/宁静/电影感等）

#### C. 色彩体系
- 主色调与占比
- 辅助色与点缀色
- 色彩情感倾向

#### D. 材质语言
- 地面材质（木地板/大理石/瓷砖/水泥/砂砾/碎石等）
- 墙面材质（艺术涂料/石材/墙纸/护墙板/Stucco抹灰等）
- 家具材质与风格
- 织物材质（窗帘/地毯/沙发面料等）

#### E. 陈设与装饰
- 家具类型与排列方式
- 装饰品（画框/雕塑/烛台/绿植等）
- 餐具与桌布风格（如为餐桌场景）
- 特殊道具（如为车内外场景，记录车辆内饰风格）

---

#### F. 画面内容分析（新增核心维度）
- **主体定义**：画面核心主体是什么（人物局部/整体/建筑/静物/风景等）
- **主体位置与占比**：主体在画面中的位置（居中/三分点/边缘等）与面积比例
- **环境元素**：画面中包含哪些环境物件（建筑/植物/道具/车辆等）
- **主体与环境关系**：主体如何与环境互动（融入/对比/遮挡/被包围等）
- **画面平衡感**：重量分布（视觉密度 vs 面积占比的补偿关系）

---

#### G. 视角与构图分析（新增核心维度）
- **机位高度**：俯视/平视/仰视，与被摄体的空间距离感
- **景别**：远景/全景/中景/近景/特写，或裁切部位（如"中近景，聚焦下半身与裙摆"）
- **焦段推断**：根据透视关系推断镜头焦段（约XXmm）
- **构图框架**：框架构图/对角线构图/三分法/中心对称/框架挤压等
- **引导线**：建筑线条/物体边缘/阴影线/生长方向等视觉引导线
- **纵深结构**：前景（前）/中景（实）/背景（后）的虚实层次分布
- **负空间处理**：空白/深色块面/渐变消色如何承载视觉呼吸
- **视觉焦点**：第一落点位置与视线引导路径（如"手部→手臂→裙摆→环境"）
- **核心冲突与张力**：画面中哪些对立元素形成视觉张力（如"硬直线vs柔曲线"/"工业vs女性"/"密实vs轻盈"等）

---

### 第 2 步：风格定位

根据分析结果，给出：

**风格标签**（5–7个核心标签，覆盖风格+光影+色调+构图关键词）
> 例：新古典主义 / 法式优雅 / 温暖奶油色调 / 胶片质感 / 电影感光影 / 框架挤压构图 / 黄金时刻

**风格描述段**（1段话精炼概括）
> 用一段话描述该场景的整体视觉印象，包括构图方式、风格基调、光影氛围、材质语言、色彩倾向。

---

### 第 3 步：nano banana 提示词输出

#### 3A：原场景复刻提示词

将第1步分析得到的全部视觉要素整合为高质量场景描述，格式：

```
[场景类型]的[风格定位]室内/室外空间。[建筑与空间描述]，[材质与表面处理]，[光影描述]，[色彩体系]，[氛围关键词]，[风格定位]。[构图补充]。[细节补充].[质量要求]
```

#### 3B：按需求扩展的场景提示词（如有）

根据用户需求，在同一风格体系下生成扩展场景提示词：

**扩展类型 A：同风格不同场景**
> 将原场景风格（如新古典主义法式奶油色调）应用于用户指定的场景类型（如宴会厅/教堂/花园/书房等）

**扩展类型 B：原场景的其他视角**
> 给出同一室内空间的不同角度描述（如从正面入口看、从楼梯间看、俯视全景等），保持所有风格参数一致，仅改变观察角度和取景范围

---

### 第 4 步：复刻要点总结

给出专业摄影师/导演视角的可执行复刻建议：

| 要素 | 复刻建议 |
|------|---------|
| 镜头参数 | 焦距/光圈建议 |
| 光线布置 | 主光方向/柔光附件 |
| 构图方法 | 核心构图框架与引导线 |
| 色彩后期 | 色调偏移方向 |
| 材质注意 | 关键材质替代表达 |
| 氛围控制 | 前期/后期核心把控点 |

## 质量标准

- 分析须全面细致，覆盖建筑/光影/色彩/材质/陈设/画面内容/构图视角七大维度
- 风格标签精准（5–7个），描述段精炼有画面感
- **构图分析须包含：机位、景别、构图框架、引导线、纵深层次、负空间处理、视觉焦点路径、核心张力点**
- nano banana 提示词结构完整、语句自然、可直接使用
- 扩展场景须严格保持原风格体系，不得偏离原图的材质语言和色彩体系
- 复刻要点具体可执行，不说废话
- 使用中文表达（风格标签可用中英文混合）
