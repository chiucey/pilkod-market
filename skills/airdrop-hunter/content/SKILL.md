# 空投挖掘助手

## 技能概述

本技能每日挖掘潜在空投项目，基于项目类型、融资背景、代币经济、社区热度等多维度筛选逻辑，为用户推荐最具潜力的加密货币空投项目，并提供具体可执行的任务步骤。

## 执行流程

### 第一步：信息收集

1. 搜索最新融资新闻（The Block、CoinDesk、Odaily星球日报、深潮）
2. 扫描任务平台新任务（Galxe、Layer3、QuestN）
3. 查看官方社交媒体公告和更新
4. 关注空投追踪社区动态（@airdrops_io、@theairdropfactor）

### 第二步：项目筛选

**优先级评估标准：**

| 优先级 | 项目类型 | 代表项目 |
|--------|----------|----------|
| 高 | Layer2网络 | Optimism、Arbitrum、Base、zkSync、Starknet、Linea |
| 高 | 跨链桥 | LayerZero、Stargate、Across、Synapse |
| 高 | DeFi协议 | DEX、借贷协议、质押协议 |
| 中 | 测试网项目 | Initia、Berachain、Morph |
| 中 | 模块化区块链 | Celestia、Fuel、Monad |

**融资背景要求：**
- 第一梯队：a16z、Paradigm、Sequoia、Polychain
- 第二梯队：Binance Labs、Coinbase Ventures、Dragonfly
- 第三梯队：Multicoin、Hack VC、OKX Ventures

### 第四步：任务类型分类

**零撸（成本：$0）**
- 测试网交互（swap、mint、跨链测试）
- 社交媒体关注、转发、评论
- Galxe、Layer3基础任务完成
- Discord社区验证和角色获取

**低成本（成本：$5-30）**
- 跨链桥小额转账
- 主网小额Swap交互
- 小额质押参与
- 购买或铸造NFT

**常规（成本：$30-100）**
- 较大资金量交互
- 多链布局（3条链以上）
- 流动性提供（LP）
- 长期质押锁仓

## 风险提示

- 使用专用钱包参与空投，不要使用主钱包授权不明确项目
- 控制成本，零撸优先，避免重仓早期项目
- 谨防钓鱼链接，核实所有官方渠道的真实性
- DYOR原则：自己做研究，不要盲目相信推荐
