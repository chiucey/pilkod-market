# 项目筛选条件完整清单

## 一、项目类型优先级

### 1.1 高优先级类型（必选其一）

**Layer2 网络**
- Optimism、Arbitrum、Base、zkSync、Starknet、Linea、Scroll、Mantle、Metis、Polygon zkEVM
- 特点：成熟生态、高TVL、潜在巨额空投

**跨链桥**
- LayerZero、Stargate、Across、Circle、Synapse、Celer、Hop Protocol
- 特点：跨链交互必需、用户黏性高

**DeFi 协议**
- DEX（AMM）、借贷协议、质押协议、收益聚合器、保险协议
- 特点：持续交互价值、质押奖励机制

### 1.2 中优先级类型

**测试网项目**
- 即将上线主网的早期项目
- 代表：Initia、Berachain、Morph、Particle Network

**模块化区块链**
- Celestia、Fuel、Monad、Sega
- 特点：技术创新、高融资、生态潜力

**BTCFi**
- 比特币生态DeFi协议
- 代表：Lombard（Polychain领投）、Babylon

**AI区块链**
- AI与区块链结合项目
- 代表：0G Labs（融资1.05亿美元）、Sahara AI（融资4300万美元）

## 三、代币经济判断

### 3.1 发币状态评估

| 状态 | 埋伏价值 | 说明 |
|------|----------|------|
| 尚未发币 | ⭐⭐⭐ 最佳时机 | 项目尚未发行代币，提前布局获取早期资格 |
| 已发币但持续交互有价值 | ⭐⭐ 中等价值 | 空投2.0或质押奖励机制 |
| 明确代币计划 | ⭐⭐⭐ 最佳时机 | 官方暗示发币或有明确规划 |

### 3.2 代币激励评估标准

- 有明确的代币激励机制
- 质押/流动性挖矿奖励
- 治理代币分配计划
- 空投历史表现（参考项目）
