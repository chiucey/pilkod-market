# Bitable录入模板

## 字段说明

| 字段名称 | 字段说明 | 必填 | 选项/示例 |
|----------|----------|:----:|-----------|
| 项目名称 | 项目官方名称 | ✅ | zkSync |
| 任务描述 | 具体操作步骤 | ✅ | 1. 连接钱包 2. 进行Swap... |
| 任务类型 | 任务成本类型 | ✅ | 零撸/低成本/常规 |
| 平台类型 | 项目所属类型 | ✅ | Layer2/跨链桥/DeFi等 |
| 成本预估 | 预计花费金额 | ✅ | $0-10 |
| 优先级 | 项目优先级 | ✅ | 🔥高/⭐中/⚠️观察 |
| 融资情况 | VC和融资金额 | ❌ | a16z领投2300万美元 |
| 代币情况 | 发币状态 | ❌ | 未发币/已发币/即将发币 |
| 操作链接 | 官方或任务链接 | ❌ | https://... |
| 备注 | 其他补充信息 | ❌ | 测试网即将上线 |

## 使用说明

1. 每发现一个推荐项目，按模板录入Bitable
2. 定期更新项目状态和动态
3. 记录任务完成状态和进度
4. 回顾和调整埋伏策略
