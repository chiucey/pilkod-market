# Music Style Finder

## 概述

Music Style Finder 是一款智能音乐风格推荐工具，能够根据用户输入的模糊文字描述（如情绪、场景、活动等），快速匹配并返回最合适的音乐风格建议。

## 核心功能

### 1. 智能语义匹配
- 支持模糊描述解析
- 多维度关键词识别
- 上下文理解能力

### 2. 音乐风格数据库
涵盖以下主要风格分类：

**按情绪分类：**
- 放松/平静 (Relaxing/Calm)
- 欢快/愉悦 (Happy/Upbeat)
- 忧郁/沉思 (Melancholic/Reflective)
- 激情/能量 (Passionate/Energetic)
- 浪漫/温馨 (Romantic/Cozy)

**按场景分类：**
- 专注工作 (Focus/Work)
- 运动健身 (Exercise/Fitness)
- 睡眠/冥想 (Sleep/Meditation)
- 通勤/旅行 (Commute/Travel)
- 社交聚会 (Social/Party)

**按流派分类：**
- 古典 (Classical)
- 爵士 (Jazz)
- 电子 (Electronic)
- 流行 (Pop)
- 摇滚 (Rock)
- 民谣 (Folk)
- 氛围 (Ambient)
- 世界音乐 (World Music)

## 使用方式

1. 用户在文本框中输入模糊的音乐描述
2. 系统分析关键词和语义
3. 返回最匹配的音乐风格建议
4. 显示风格特点和建议的歌单类型

## 技术实现

- 纯前端 JavaScript 实现
- 关键词权重匹配算法
- 响应式设计
- 即时反馈机制
