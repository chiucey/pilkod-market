| 必填校验 | 不通过默认提示"{字段名称}{字段编码}不能为空"，例"{员工编号}{empCode}不能为空" |
| 长度校验 | 不通过默认提示"{字段名称}{字段编码}{【字段值】}超出最大长度限制{最大长度}"，例"{员工编号}{empCode}{2018110006}超出最大长度限制{60}" |
| 格式校验 | 不通过默认提示"{字段名称}{字段编码}{【字段值】}格式错误"，例"{报账金额}{applyAmount}{3333.33333}格式错误" |
| 存在性校验 | 不通过默认提示"{字段名称}{字段编码}{【字段值】}在系统中不存在"，例"{员工编号}{empCode}{2018110006}在系统中不存在"；快速编码类存在性校验应校验在父编码下存在，尽量不要写死具体值 |
| 有效性校验 | 不通过默认提示"{字段名称}{字段编码}{【字段值】}已失效"，例"{员工编号}{empCode}{【2018110006】}已失效" |
| 存在且有效校验 | 不通过默认提示"{字段名称}{字段编码}{【字段值】}不存在或无效"，例"{员工编号}{empCode}{【2018110006】}不存在或无效" |
| 批次内唯一性校验 | 指一次请求接收的数据范围内，不通过默认提示"与第{N}行数据重复"，例"与第{5}行数据重复" |
| 系统内唯一性校验 | 指一次请求接收的数据+系统中已存在的数据范围内，不通过默认提示"第{N}行数据在系统已存在"，例"第{5}行数据在系统已存在" |
| 开始结束时间校验 | 需控制开始时间小于等于结束时间，不通过默认提示"{开始字段名称}{开始字段编码}{字段值}与{结束字段名称}{结束字段编码}{字段值}范围错误" |
| 金额/数字范围校验 | 不通过默认提示"{字段名称}{字段编码}{字段值}不在指定范围内{范围值}"，{范围值}由具体需求指定 |
| 其他校验 | 需求文档说明规则但未写明字段报错提示语的地方，不通过默认提示"{字段名称}{字段编码}{字段值}不合规" |
| 字段校验顺序 | 先做必填校验，必填校验通过，再根据需求文档标识顺序进行校验 |
| 多字段校验提示 | 一条数据多个字段校验不通过，提示语用英文分号分隔，并在最前面增加"第{N}行数据" |

**注意事项**：具体需要做哪些校验，以需求文档为准，校验提示语文档无特殊说明则以公约为准

## 公约应用规则

1. **自动匹配**：根据需求分析内容自动识别需求类型，匹配对应公约
2. **多类型组合**：一个需求可能同时匹配多个公约类型，需组合应用
3. **公约优先级**：当公约规则与具体需求冲突时，以具体需求为准
4. **覆盖完整性**：确保公约中定义的必测点都被覆盖
5. **特殊说明优先**：需求文档中有特殊说明的，以需求文档为准
