# 歌海灵感创作引擎

一个基于广西少数民族音乐特征的旋律创作技能，帮助用户快速生成具有地域特色的原创音乐片段。

## 执行流程

### 第1步：确认风格标签

请用户选择以下广西风格标签之一：

- **壮族三声部**：多声部和声结构，常见于田阳等地
- **侗族大歌**：无伴奏合唱，复调性高
- **京族独弦琴味**：单旋律线条，音色独特
- **彩调节奏**：欢快跳跃，舞曲风格

### 第2步：确认情绪关键词与用途

**情绪关键词**（选一）：
- 欢快
- 悠扬
- 叙事
- 庄重

**用途**（选一）：
- 配乐
- 儿歌
- 舞蹈

### 第3步：生成旋律

生成8-16小节的旋律，遵循以下原则：

| 风格 | 音阶特点 | 节奏特征 |
|------|----------|----------|
| 壮族三声部 | 五声羽调式为主 | 均衡平稳 |
| 侗族大歌 | 五声徵调式为主 | 模仿自然声响 |
| 京族独弦琴 | 五声宫调式为主 | 悠长抒情 |
| 彩调节奏 | 五声商调式为主 | 跳跃灵动 |

### 第4步：呈现格式

使用数字简谱呈现，标注小节线。在需要添加衬词的位置用括号标注。

**格式示例**：
```
1 2 3 | 5 3 2 | (衬词) 1 2 3 | 5 - ||
```

### 第5步：节奏型标注

在简谱下方单独标注节奏型，例如：
- 四拍子：X — — —
- 三拍子：X · X
- 切分：X · · X

### 第6步：衬词建议

标注建议添加的广西特色衬词及位置：

| 衬词 | 风格 | 常见位置 |
|------|------|----------|
| 啰 | 壮族 | 句尾 |
| 咧 | 壮族 | 句中 |
| 哈嘹 | 侗族 | 句首/句尾 |
| 呃 | 京族 | 句尾 |

### 第7步：进阶灵感

提供1个修改建议，让旋律更"广西"，例如：

- 将第二小节的re改为大三度音程
- 在句尾添加向上四度的跳进
- 引入相邻乐句的卡农模仿

## 试唱提示

> 可以先念一遍歌词的声调，再套上音符，感受"依字行腔"的广西味道。

