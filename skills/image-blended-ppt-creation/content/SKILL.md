# 图片融合PPT制作技能（智能增强版）

## 核心能力

1. **用户图片融合**：将用户提供的图片和文字说明自然整合
2. **智能图片补充**：当用户仅提供文字内容时，自动从网络搜索下载合适的配图
3. **视觉美化增强**：插入装饰性真实图片提升PPT美观度，与内容高度相关
4. **主题适配配色**：根据内容主题自动选择最合适的色彩风格
5. **逻辑结构化**：将内容组织成逻辑清晰的演示结构

## 工作流程

### 步骤 1：内容接收与主题分析

接收用户输入，分析以下内容：

**内容分析：**
- 核心主题识别
- 内容类型判断（教学/商务/个人/技术等）
- 情感基调评估（正式/轻松/专业/活泼）
- 目标受众识别

**主题匹配配色：**
根据主题自动选择配色方案：

| 内容主题 | 推荐配色 | 风格描述 |
|---------|---------|---------|
| 音乐/艺术 | 优雅古典：深紫+金色+米白 | 优雅、艺术感 |
| 科技/数码 | 深邃科技：深蓝+青绿+银白 | 专业、未来感 |
| 教育/学习 | 清新学术：蓝绿+橙黄+浅灰 | 活力、专注 |
| 商业/职场 | 专业商务：深蓝+灰+金 | 稳重、可信 |
| 美食/生活 | 温暖生活：暖橙+棕+奶白 | 温馨、自然 |
| 健康/运动 | 活力健康：绿色+橙色+白 | 活力、健康 |
| 旅行/自然 | 清新自然：蓝绿+大地色 | 清新、放松 |
| 儿童/亲子 | 可爱童趣：粉彩+明黄+白 | 活泼、可爱 |

### 步骤 2：智能图片获取

**关键词提取：**
1. 分析文字内容，提取核心主题词
2. 识别每个章节/段落的关键概念
3. 生成适合搜索的图片描述

**图片类型规划：**

| 图片用途 | 位置 | 说明 |
|---------|------|------|
| 封面背景图 | 封面页 | 大尺寸背景图，提升视觉冲击力 |
| 内容配图 | 内容页 | 与文字内容高度相关的说明图 |
| 侧边装饰图 | 页面侧边 | 适中的装饰图片（占页面15-25%） |
| 角落点缀图 | 页面角落 | 小型装饰图片，增强美观性 |
| 分隔装饰 | 章节过渡 | 装饰性图片区分不同章节 |

**网络图片搜索：**
- 使用 `images_search_and_download` 工具进行图片搜索
- 为每个内容模块搜索 1-3 张相关图片
- 优先选择高质量、免版权或合理使用的图片

**图片质量标准：**
- 最小尺寸：800x600 像素
- 推荐比例：16:9 或 4:3
- 文件格式：JPG 或 PNG
- 优先选择：高清、无水印、内容相关

### 步骤 3：内容结构化

根据用户提供的材料，执行以下分析：

1. **主题识别**：确定演示文稿的核心主题
2. **逻辑分组**：将内容按逻辑关系分章节
3. **层级设计**：确定标题、子标题、正文的层级
4. **配图规划**：为每个章节规划合适的配图数量和位置
5. **装饰规划**：规划装饰图片的插入位置

### 步骤 4：PPT生成（视觉增强版）

使用 PptxGenJS 库生成PPT，执行以下操作：

1. **创建基础结构**：
   - 封面页（主题 + 真实图片背景 + 文字叠加）
   - 目录页（章节概览 + 侧边装饰）
   - 内容页（真实配图 + 文字 + 角落点缀）
   - 结束页（总结 + 视觉收尾）

2. **图片融入策略**：
   - **大图背景**：使用真实图片作为背景，叠加半透明遮罩 + 文字层，适合封面/章节页
   - **左图右文**：配图在左（35-45%），说明在右，适合叙事型内容
   - **右图左文**：配图在右，说明在左，适合对比型内容
   - **上图下文**：配图在上（50-60%），标题/说明在下，适合展示型内容
   - **侧边装饰**：图片在页面侧边（占15-25%），主体内容区域保持清晰
   - **多图网格**：多张图片并排展示（2x2/3x3），适合对比或画廊式展示
   - **卡片式布局**：将内容放在带图片的卡片上

3. **装饰图片插入规则（不破坏逻辑）：**
   - **侧边装饰图**：放在页面右侧或左侧边栏（15-25%宽度），不遮挡主要内容
   - **角落点缀图**：放在页面四角适当位置，作为视觉平衡
   - **背景虚化图**：作为页面背景，使用高斯模糊或透明度处理
   - **大小控制**：
     - 侧边装饰图：占页面15-25%
     - 角落点缀图：占页面5-10%
     - 背景图：全屏或60%以上
   - **透明度处理**：装饰图片使用 70-85% 透明度，避免喧宾夺主

4. **文字排版**：
   - 标题：使用大字号（28-36pt）、加粗、主题色
   - 说明文字：使用易读字号（16-20pt），保持 1.3-1.5 倍行距
   - 要点列表：使用项目符号，保持对齐，添加适当间距
   - **核心原则**：文字内容始终保持完整性和可读性

5. **视觉增强元素**：
   - 真实主题相关图片作为装饰
   - 圆形/圆角矩形色块
   - 细线分隔符
   - 透明度叠加层
   - 音符符号等主题元素（作为辅助装饰）

### 步骤 5：输出交付

生成完成的 PPTX 文件，提供下载链接。

## 注意事项

1. **版权合规**：优先使用免版权图片源（如 Unsplash、Pexels），并记录图片来源
2. **内容相关性**：确保下载的图片与文字内容高度相关
3. **质量把控**：检查图片清晰度，避免使用模糊或低质量图片
4. **数量控制**：
   - 内容页：1-2张配图（侧边或角落），不超3张
   - 封面页：1张背景大图 + 1-2张角落点缀
   - 装饰图控制在页面5-25%
5. **视觉平衡**：图文比例保持 3:7 或 4:6，确保文字内容清晰可读
6. **核心原则**：**不破坏逻辑性和表达** - 图片只是辅助美化，不能影响主要信息的传达
7. **用户确认**：如用户有特殊图片需求或配色偏好，先确认后再生成
