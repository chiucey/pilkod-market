## 一、核心定位

### 1.1 什么是"课程口播"？

课程口播是**"口播视频"与"课程交付"的双轨合一**：

| 维度 | 纯口播视频 | 纯课程 | 课程口播（本指南） |
|------|-----------|--------|------------------|
| **时长** | 1-5分钟 | 45-90分钟 | 15-20分钟 |
| **结构** | 钩子→故事→升华 | 系统知识体系 | 课程骨架+口播节奏 |
| **受众** | 陌生人（公域） | 付费学员（私域） | 两者兼顾 |
| **目的** | 吸引粉丝 | 知识交付 | 锻炼讲课+吸引粉丝 |
| **互动** | 评论区 | 现场问答 | 想象互动（镜头前） |

### 1.2 为什么选15-20分钟？

**视频号算法逻辑**：
- 2026年视频号官方扶持"专家型"深度内容
- "时长即诚意"——4分钟以上内容获得流量加权
- 15-20分钟是"完播率"与"深度"的最佳平衡点

**讲课训练逻辑**：
- 15分钟 = 1个核心知识点讲透
- 可锻炼：开场→展开→案例→工具→收尾的完整能力
- 可复用：多条15分钟内容 = 1节完整大课

## 二、内容结构（五步法）

每条15-20分钟课程口播，必须包含五个部分：

```
【开场】钩子与问题引入（2-3分钟）
    ↓
【第一部分】核心概念讲解（4-5分钟）
    ↓
【第二部分】真实案例分享（4-5分钟）
    ↓
【第三部分】工具方法论交付（3-4分钟）
    ↓
【第四部分】升华与总结（2-3分钟）
    ↓
【结尾】固定署名（10秒）
```

### 2.1 【开场】钩子与问题引入（2-3分钟）

**核心任务**：3秒抓注意力，30秒建立信任，2分钟引发共鸣

**结构模板**：

```
1. 痛点提问（你有没有遇到过...）
2. 个人经历（我也曾经...）
3. 问题放大（试了很多次...）
4. 转折引入（后来我发现...）
5. 价值预告（今天我要给你...）
```

**示例**（NLP六层主题）：

> 你有没有遇到过这种情况——
> 
> 用AI写文案，技术上没问题，语法通顺，逻辑清晰。
> 
> 但读起来，就是不像你。
> 
> （停顿2秒）
> 
> 我去年开始用AI辅助创作，一开始也是这样...

**训练要点**：
- 眼神直视镜头，像与老朋友对话
- 语调从日常逐渐转为专注
- 关键问题后停顿2-3秒

---

### 2.2 【第一部分】核心概念讲解（4-5分钟）

**核心任务**：把复杂概念讲清楚，让听众听懂

**结构模板**：

```
1. 概念定义（这是什么）
2. 分层拆解（逐层讲解）
3. 核心洞察（关键发现）
4. 对比误区（常见错误）
5. 类比说明（用例子解释）
```

**示例**（NLP六层）：

> NLP六逻辑层次，是神经语言程序学的核心工具。
> 
> 它描述了人类思维和表达的六个层次...
> 
> （手势配合，从上到下）
> 
> 最顶层是精神层——我为何而做。
> 第二层是身份层——我是谁。
> 第三层是信念层——我相信什么...

**训练要点**：
- 用手势配合层次结构
- 每层讲解后短暂停顿
- 关键洞察加重语调

---

### 2.3 【第二部分】真实案例分享（4-5分钟）

**核心任务**：用真实故事让概念落地，建立信任

**结构模板**（STAR法则）：

```
1. Situation（背景）
2. Task（任务/问题）
3. Action（行动/尝试）
4. Result（结果/转变）
```

**示例**：

> 去年，我开始用AI辅助创作。
> 
> （回忆状，语调放缓）
> 
> 一开始，我跟大多数人一样，上来就说：
> "你要用口语化风格""你要有温度"...
> 
> （摇头，苦笑）
> 
> 结果AI写出来的东西，总是缺了点什么...

**训练要点**：
- 语调有起伏（困惑→发现→喜悦）
- 加入感官细节（"试了很多次""总觉得"）
- 情绪真实，不夸张

---

### 2.4 【第三部分】工具方法论交付（3-4分钟）

**核心任务**：给听众可带走的方法，推动行动

**结构模板**：

```
1. 工具介绍（这是什么）
2. 逐层讲解（怎么用）
3. 个人示例（我怎么做）
4. 关键提醒（注意什么）
5. 行动号召（去做什么）
```

**示例**：

> 现在，我把NLP六逻辑层次变成一个你可以直接用的工具。
> 
> 这是一个"AI人格建模模板"...
> 
> （展示模板）
> 
> 第一层，精神层。你的内容最终要影响谁？...

**训练要点**：
- 工具可视化（金字塔、表格）
- 每层配个人示例
- 关键提醒加重语调

---

### 2.5 【第四部分】升华与总结（2-3分钟）

**核心任务**：提炼金句，强化记忆，提升格局

**结构模板**：

```
1. 结构化回顾（总结要点）
2. 金句提炼（一句话记忆）
3. 格局提升（更大视角）
4. 行动推动（下一步）
```

**示例**：

> 好，我们来总结一下。
> 
> 第一，AI写作的问题不在技术，在顶层输入。
> 第二，NLP六逻辑层次是最佳框架。
> 第三，从顶层到底层，层层落地...
> 
> （语调加重）
> 
> 记住这句话：别教AI语气，教它你的灵魂。

**训练要点**：
- 金句部分加重+停顿
- 语调从具体上升到抽象
- 给听众"带走"的感觉

---

### 2.6 【结尾】固定署名（10秒）

**标准结尾**：

> 我是史海建，这是我的真实日记。真实记录每一天，让我们一起成为更好的自己。

**变体可选**：
- A版（流畅）："我是史海建，这是我的真实日记，真实记录每一天，一起成为更好的自己。"
- B版（有力）："我是史海建，真实记录，真实成长，我们下期见。"
- C版（简洁）："我是史海建，这是我的真实日记，下期见。"
- D版（原味）："我是史海建，这是我的真实日记，真实记录每一天，让我们一起成为更好的自己。"

## 三、语言风格规范

### 3.1 必须使用

| 元素 | 示例 | 作用 |
|------|------|------|
| **共同体称呼** | "咱们""伙伴们" | 建立亲近感 |
| **口语缓冲词** | "说实话""你发现了吗" | 降低说教感 |
| **设问自答** | "为什么？因为..." | 引导思考 |
| **一句话洞察** | "请大家记住..." | 强化记忆点 |
| **数据量化** | "16年军旅+5年私募+8年保险" | 建立专业感 |
| **真实痕迹** | "我去年...""试了很多次" | 建立信任 |

### 3.2 禁止使用

| 类型 | 错误示例 | 问题 |
|------|---------|------|
| **说教句式** | "你应该...""你必须..." | 居高临下 |
| **负面恐吓** | "如果不...就会..." | 制造焦虑 |
| **杜撰案例** | "有个朋友..."（无真实来源） | 失去信任 |
| **标题党** | "震惊！99%的人不知道..." | 降低格调 |
| **过度承诺** | "保证你月入十万" | 不真实 |

### 3.3 节奏控制

**短句原则**：
- 单句不超过20字
- 一段不超过3句话
- 关键点后必须停顿

**停顿位置**：
- 钩子后：停2-3秒
- 问题后：停3秒（给思考时间）
- 金句后：停3秒（让记忆沉淀）
- 转折前：停2秒（制造悬念）

## 四、创作流程

### 4.1 信息梳理（老A执行）

**输入**：老板提供的素材/主题/方向
**输出**：
- 核心要点提炼
- 扩写与串联
- 联想与补充
- 案例真实性确认

### 4.2 结构组织（老A执行）

**按五步法搭建骨架**：
1. 开场钩子
2. 概念讲解
3. 案例分享
4. 工具交付
5. 升华总结

**每个部分标注**：
- 预计时长
- 语调要求
- 停顿位置
- 手势建议

### 4.3 文案撰写（老A执行）

**逐段撰写，确保**：
- 口语化（读起来顺口）
- 有节奏（长短句交替）
- 有温度（真实、不装）
- 有洞察（金句、观点）

### 4.4 视频化素材（老A执行）

**每条文案配套**：
- 标题3选1（推荐1个）
- 发布描述
- 封面建议
- 标签建议

### 4.5 自检清单（老A执行）

| 检查项 | 标准 |
|--------|------|
| 符合视频号算法 | 真善美，无贪嗔痴 |
| "我"视角 | 分享者而非教育者 |
| 有真实故事 | 本人/团队/朋友/公开报道 |
| 有"根" | 理论/数据/经典/官方文件 |
| 正向表达 | 解决问题，赋能他人 |
| 时长合规 | 15-20分钟 |
| 有金句 | 易传播，易记忆 |
| 结尾署名 | 固定结尾已包含 |

## 七、使用说明

### 7.1 给史海建（老板）

**拍摄前**：
1. 通读完整文案2-3遍
2. 标记自己的停顿节奏
3. 准备简单道具（如六层金字塔图）

**拍摄时**：
1. 固定机位，中景（胸部以上）
2. 眼神直视镜头
3. 按标注的停顿位置自然停顿
4. 不用一字不差，保持口语感

**发布后**：
1. 关注完播率（15分钟内容的目标：>20%）
2. 关注评论区互动
3. 收集反馈，优化下一条

### 7.2 给其他AI（如果本指南被分享）

**核心原则**：
1. 严格遵循五步法结构
2. 必须使用史海建的语言风格
3. 必须包含真实案例（不可杜撰）
4. 必须输出完整格式（含视频化素材）

**禁止事项**：
1. 改变身份定位（三界史者、16+5+8）
2. 改变语言风格（说教、负面、标题党）
3. 杜撰案例（无真实来源的故事）
4. 省略视频化素材（标题、描述、封面）
