# 口播脚本模板（史海建风格）

根据不同时长和场景提供三版模板。

---

## 极简版（30-60秒短视频）

**适用场景**：抖音/快手/视频号 短视频、朋友圈视频

**结构公式**：
```
[金句/反问开场] → [1个核心观点] → [1个故事/案例] → [金句结尾 + 互动引导]
```

**模板**：
```
[开头：一句话抓住注意力——反问/金句/争议观点]

[中间：用一个故事或案例说明核心观点]
（故事来源：个人经历/客户故事/社会热点/行业案例）

[结尾：升华 + 金句 + 互动引导]
"在评论区告诉我，[与主题相关的问题]"
```

**字数参考**：200-500字
**语速参考**：每分钟200-250字

---

## 标准版（3-5分钟口播视频）

**适用场景**：视频号中长视频、小红书视频、直播开场

**结构公式**：
```
[情感开场] → [核心问题/痛点] → [个人经历佐证] → [方法论/观点展开] → [金句总结] → [行动号召]
```

**模板**：
```
[0-30秒] 情感开场
用一个能引发共鸣的问题、场景或故事开场。
例："你有多久没有体会过____的感觉了？"
例："很多人认为____，其实不对。"

[30秒-2分钟] 核心问题与个人经历
提出要讨论的核心问题，用自身真实经历佐证。
例：军旅故事、金融亏损经历、团队成长案例
原则：真诚不包装，用数据说话。

[2-4分钟] 方法论展开
用道法术器或NLP框架展开分析。
每1-2分钟切一个要点。
适当引用经典（名人名言、古诗词、武侠典故）。

[4-5分钟] 金句总结与行动号召
用1-2个核心金句总结升华。
引导互动："点赞/转发/评论区留言"
如需转化，自然过渡到行动引导。
```

**字数参考**：800-1500字
**语速参考**：每分钟200-220字

---

## 深度版（10-20分钟演讲/直播）

**适用场景**：线下演讲、事业说明会、直播主题分享、培训课程

**结构公式**：
```
[诗意/典故开场] → [三问切入] → [个人三界故事] → [底层方法论] → [实战体系] → [愿景升华]
```

**模板**：
```
[开场 1-2分钟]
用诗词或典故营造氛围。
例："阳气回升冷意收，青龙二月二抬头。"
例："总有人间一两风，填我十万八千梦。"
向听众致敬/感谢。

[核心三问 2-3分钟]
用三个问题引发思考：
1. 我的成长，配得上我的年龄吗？
2. 我的积累，撑得起三年后的野心吗？
3. 如果继续这样，我能看到五年后想要的生活吗？

[个人故事 5-8分钟]
完整讲述三界经历（军旅→金融→保险）。
每个阶段：经历→感悟→转折。
用真实数据增强说服力。
强调"白板也能成功"。

[方法论展开 8-15分钟]
核心框架讲解（道法术器/NLP理解层次）。
结合具体案例说明。
展示团队培训体系和成果数据。
用武侠典故或寓言故事辅助理解。

[结尾 2-3分钟]
金句升华 + 感谢 + 愿景。
例："心有大愿，乘风登舟，舍舟登岸，抵岸即是神通。"
如需转化，设计明确的下一步行动。
```

**字数参考**：3000-6000字
**语速参考**：每分钟180-200字（演讲语速偏慢）

---

## 风格检验清单

创作完成后，对照以下清单检验：

- [ ] 开场是否在3秒内抓住注意力？
- [ ] 是否有真实个人经历佐证？（军旅/金融/保险）
- [ ] 是否包含了至少一个方法论框架？（道法术器/NLP/能量层级）
- [ ] 是否有至少一句原创金句/记忆点？
- [ ] 口语化程度如何？读起来自然吗？
- [ ] 是否有数据支撑关键论点？
- [ ] 结尾是否有升华和行动号召？
- [ ] 整体语调是否：亲切但有权威感？
- [ ] 情感节奏：先共情→再分析→后激励？
- [ ] 是否避免了生硬的广告感？（产品植入要自然）
