# 文章/朋友圈/公众号模板（史海建风格）

---

## 朋友圈文案模板

### 风格要点
- 控制在3-5行，不超过200字
- 搭配一张高质量图片
- 要么有金句，要么有故事，要么有数据
- 语气像朋友聊天，不像广告

### 模板一：金句型
```
[原创金句]

[简短感悟/背景，1-2句话]

[如有行动引导：欢迎评论区交流/私信我]
```

### 模板二：故事型
```
[一句话概括今天发生的事]

[简短叙述经过和感受]

[提炼一个感悟/启发]
```

### 模板三：数据型
```
[核心数据/成绩]

[一句话解读数据背后的意义]

[团队/个人成长感悟]
```

### 模板四：价值观型
```
[对某个现象/话题的看法]

[用方法论框架简要分析]

[一句话升华]
```

## 公众号文章模板

### 标题公式
1. **反差型**："从[低谷]到[高峰]，[数字]年我悟出的[数字]个道理"
2. **疑问型**："[常见认知]，真的对吗？"
3. **故事型**："一个[身份]，如何[成就]"
4. **数字型**："[数字]句话/个方法，帮你[目标]"
5. **金句型**：直接用核心金句作标题

### 文章结构
```
[标题] 吸睛但不标题党

[开头 100-200字]
用一个故事/现象/问题开场
制造"我必须继续读下去"的冲动

[第一部分：故事/现象]
详细展开开头的案例
用细节和画面感增强代入感
适当加入个人经历佐证

[第二部分：分析/方法论]
用道法术器或NLP框架分析
每段一个核心观点
用小标题分段
穿插数据、引用、案例

[第三部分：行动指南]
给读者可执行的具体建议
分步骤列出
用 numbered list

[结尾 100-200字]
金句升华
回归初心/使命
引导互动（在看/转发/留言）
```

### 写作规范
- 段落不超过4行（移动端阅读友好）
- 重点句子加粗
- 每篇文章至少1个原创金句
- 引用要标注来源
- 数据要标注来源
- 语气保持"亲切导师"感，不要居高临下

## 课程大纲模板

### 适用场景
- 培训课程设计
- 讲课PPT大纲
- 直播课程结构

### 结构模板
```
[课程名称]
[课程时长：X小时/X天]
[目标人群：XXX]
[课程目标：学完能XXX]

模块一：[名称]丨[讲师]
  课程1：[具体课程名]
  课程2：[具体课程名]
  ...

模块二：[名称]丨[讲师]
  ...

模块三：[名称]丨[讲师]
  ...
```

### 课程设计原则
1. 遵循道法术器框架（先认知，再方法，后工具）
2. 每个模块都有明确的"学完能做什么"
3. 理论与实践结合（每个知识点配实操练习）
4. 用NLP理解层次组织内容（从环境层→精神层递进）
5. 课程结尾要有能量提升环节（霍金斯能量层级应用）
