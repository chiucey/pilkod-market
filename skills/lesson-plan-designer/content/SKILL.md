# 教案设计器 (Lesson Plan Designer)

## 技能概述

本技能依据《义务教育英语课程标准》（2022年版2025年修订）的要求，帮助教师将教材素材设计为符合课程标准规范的英语教案。课程标准是纲领性文件，规定课程性质、课程理念、课程目标、课程内容、学业质量和课程实施等核心要素；教案设计必须以课程标准为准绳，确保教学目标与核心素养培养目标一致。

## 一、核心素养框架

### 1.1 语言能力

语言能力是核心素养的基础要素，指运用语言和非语言知识以及各种策略，参与特定情境下相关主题的语言活动时表现出来的语言理解和表达能力。

**学段表现特征：**

| 学段 | 语言能力表现 |
|------|-------------|
| 一级(3-4年级) | 能感知单词、短语及简单句的重音和升降调；能理解基本的日常问候、感谢和请求用语；能借助图片读懂语言简单的小故事 |
| 二级(5-6年级) | 能领悟基本语调表达的意义；能理解常见词语的意思和基本句式；能读懂语言简单、主题相关的简短语篇 |
| 三级(7-9年级) | 能识别不同语调与节奏所表达的意义；能理解句子结构特征；能提取并归纳关键信息，理解隐含意义 |

### 1.2 文化意识

文化意识指对中外文化的理解和对优秀文化的鉴赏，是学生在新时代表现出的跨文化认知、态度和行为选择。

**学段表现特征：**

| 学段 | 文化意识表现 |
|------|-------------|
| 一级(3-4年级) | 有主动了解中外文化的愿望；能用简单的单词、短语描述与中外文化有关的图片 |
| 二级(5-6年级) | 对学习、探索中外文化有兴趣；能用简短的句子描述所学的与中外文化有关的具体事物 |
| 三级(7-9年级) | 能初步理解人类命运共同体概念；能用所学语言描述文化现象与文化差异，表达自己的价值取向 |

### 1.3 思维品质

思维品质指人的思维个性特征，反映学生在理解、分析、比较、推断、批判、评价、创造等方面的层次和水平。

**学段表现特征：**

| 学段 | 思维品质表现 |
|------|-------------|
| 一级(3-4年级) | 能通过对图片、具体现象和事物的观察获取信息；能从不同角度观察周围的人与事 |
| 二级(5-6年级) | 能对获取的语篇信息进行简单的分类和对比；从不同角度辩证地看待事物，学会换位思考 |
| 三级(7-9年级) | 能辨识语篇中的衔接手段；能多角度、辩证地看待事物和分析问题 |

### 1.4 学习能力

学习能力指积极运用和主动调适英语学习策略、拓展英语学习渠道、努力提升英语学习效率的意识和能力。

**学段表现特征：**

| 学段 | 学习能力表现 |
|------|-------------|
| 一级(3-4年级) | 对英语学习感兴趣；乐于参与课堂活动，遇到困难能大胆求助 |
| 二级(5-6年级) | 能制订并完成简单的英语学习计划；能借助多种渠道或资源学习英语 |
| 三级(7-9年级) | 能制订明确的英语学习目标和计划；能根据学习目标和进展合理调整学习计划和策略 |

## 二、课程内容要素

### 2.1 主题范畴

课程内容围绕三大主题范畴展开：

- **人与自我**：生活与学习、做人与做事
- **人与社会**：社会服务与人际沟通、文学艺术与体育、历史社会与文化、科学与技术
- **人与自然**：自然生态、环境保护、灾害防范、宇宙探索

### 2.2 语篇类型要求

| 级别 | 语篇类型 |
|------|---------|
| 一级 | 歌谣、歌曲、韵文；日常简短对话；配图故事；人物介绍、物品介绍；书信、活动通知、贺卡等 |
| 二级 | 日常简单对话、独白；记叙文（配图故事、人物故事、寓言、童话等）；说明文；应用文 |
| 三级 | 日常对话、独白；记叙文（故事、简版小说、人物传记）；说明文；应用文；新闻报道 |

### 2.3 语言知识要求

#### 语音知识

- 一级：识别26个字母；感知简单拼读规则；感知单词重音和句子升降调
- 二级：借助拼读规则拼读单词；使用正确语音语调朗读；感知意群、语调与节奏
- 三级：了解语音在语境中的表意功能；根据重音、语调表达不同意义；根据读音规则和音标拼读单词

#### 词汇知识

- 一级：借助图片、实物理解词汇；根据音、形、义学习词汇
- 二级：在语境中理解和积累词汇；运用词汇描述事物
- 三级：了解构词法知识；在特定语境中运用词汇表达意义

#### 语法知识

- 一级：感知简单句的表意功能；理解一般现在时和现在进行时
- 二级：理解基本句型结构；理解一般过去时和一般将来时
- 三级：建立"形式—意义—使用"语法观；了解句子结构特征

### 2.4 语言技能要求

**理解性技能（听、读、看）**

| 学段 | 理解性技能要求 |
|------|--------------|
| 一级 | 理解课堂简单指令；根据图片和标题推测语篇主题；在听、读、看的过程中提取信息 |
| 二级 | 理解日常学习和生活中的简单指令；借助图片理解语篇；根据上下文线索猜测词义 |
| 三级 | 识别口语语篇的主题、大意和要点；理解书面语篇的整体意义；运用阅读策略获取信息 |

**表达性技能（说、写）**

| 学段 | 表达性技能要求 |
|------|--------------|
| 一级 | 运用所学语言进行简单交流；口头描述图片或事物；正确书写字母、单词和句子 |
| 二级 | 完整、连贯地朗读所学语篇；围绕主题与他人交流；写出几个意思基本连贯的句子 |
| 三级 | 在口头表达中使用较为准确的词语和句式；写出简单文段传达信息；围绕主题表达观点 |

## 四、教学活动设计原则

### 4.1 英语学习活动观

教学设计与实施要以主题为引领，以语篇为依托，通过学习理解、应用实践和迁移创新等活动，引导学生整合性地学习语言知识和文化知识。

**活动层次说明：**

1. **学习理解类活动**
   - 感知与注意：创设情境，激活已有知识
   - 获取与梳理：获取信息，建立关联
   - 概括与整合：形成新的知识结构

2. **应用实践类活动**
   - 描述与阐释：内化语言和文化知识
   - 分析与判断：加深对文化意涵的理解
   - 内化与运用：促进知识向能力转化

3. **迁移创新类活动**
   - 推理与论证：评价作者或主人公的观点和行为
   - 批判与评价：加深对主题意义的理解
   - 想象与创造：创造性解决新情境中的问题

### 4.2 "教—学—评"一体化

**评价功能：**

- 以评促学：监控学习过程，提供反馈
- 以评促教：诊断教学效果，改进教学

**评价原则：**

1. 评价目标与课程目标保持一致
2. 充分发挥学生的主体作用
3. 采用多种评价方式和手段
4. 充分关注学生的持续发展
5. 充分关注学生的个体差异

**评价方式：**

| 评价类型 | 具体方式 | 适用场景 |
|---------|---------|---------|
| 课堂评价 | 观察、提问、追问 | 实时了解学习过程 |
| 作业评价 | 书面/口头任务 | 检测知识理解程度 |
| 单元评价 | 综合表现评价 | 检测素养达成情况 |
| 表现性评价 | 展示、汇报、表演 | 检测语言运用能力 |

## 五、作业设计建议

### 5.1 作业类型

| 类型 | 一级(3-4年级) | 二级(5-6年级) | 三级(7-9年级) |
|------|--------------|--------------|--------------|
| 基础性作业 | 抄写单词、跟读录音 | 抄写句型、完成练习 | 语法练习、阅读理解 |
| 实践性作业 | 唱歌曲、背韵文 | 制作海报、对话表演 | 主题演讲、项目任务 |
| 拓展性作业 | 画图配词 | 阅读绘本 | 课外阅读、写作 |
| 探究性作业 | 观察记录 | 调查访问 | 主题探究 |

### 5.2 作业评价要点

- 语言知识的准确性
- 语言表达的流畅性
- 任务完成的完整性
- 创意与个性化表现

## 六、教学资源准备

### 6.1 必备资源

- 多模态语篇材料（图片、视频、音频）
- 语言知识支架（词汇卡、句型图）
- 思维工具（思维导图、信息图表）
- 评价工具（评价量表、学习单）

### 6.2 资源选择原则

- 符合学生认知水平和语言水平
- 具有正确的价值导向
- 有利于促进知识建构和思维发展
- 贴近学生生活实际

## 八、使用说明

### 输入信息

当您需要设计教案时，请提供以下信息：

1. **课程基本信息**
   - 年级：3-4年级/5-6年级/7-9年级
   - 学段级别：一级/二级/三级

2. **教材素材**
   - 语篇内容（对话、故事、短文等）
   - 主题范畴（人与自我/人与社会/人与自然）
   - 涉及的语言知识（词汇、句型、语法）

3. **学情分析**
   - 学生语言水平
   - 已有的知识和经验
   - 学习需求和兴趣

### 输出内容

技能将根据您提供的信息，输出符合课程标准要求的完整教案，包括：

1. 单元整体设计（包括单元内容分析、单元教学目标、单元内容框架）
2. 课时教学设计（包括语篇研读、教学目标、教学过程、效果评价）
3. 配套资源建议（板书设计、作业设计、教学评语等）

### 输出格式

教案将按照以下结构呈现：

```
【单元整体设计】
一、单元内容分析
二、单元教学目标
三、单元主题内容框架图
四、课时划分

【课时教学设计】（每课时）
（一）课时基本信息
（二）语篇研读
（三）教学目标
（四）教学过程
（五）效果评价
（六）板书设计
```
