# 公众号文章数据源兜底策略

微信公众号反爬严重，搜索引擎索引也有限。按以下优先级尝试数据源：

## 主用：搜索引擎 + 学术资源

| 优先级 | 数据源 | 检索语法 | 适用 |
|--------|--------|----------|------|
| 1 | Bing 站内搜索 | `site:mp.weixin.qq.com "公众号名" 2026` | 通用 |
| 2 | Sogou 微信搜索 | `https://weixin.sogou.com/weixin?query=公众号名` | 通用 |
| 3 | 学术期刊数据库 | `中国法学 2026 第N期 目录 site:chinalaw.org.cn` | 顶刊 |
| 4 | 期刊官网目录 | `iolaw.cssn.cn` / `chinalaw.org.cn` / `law.tsinghua.edu.cn` | 各刊官网 |
| 5 | CNKI 知网 | `公众号名 + 学者名 + 主题` | 学术全文 |

## 备用：跨源同主题检索

如果某公众号当日没有推送，**不要死磕**该公众号，转去其他公众号或期刊：
- 同一个学者可能同时给多个公众号投稿
- 中国法学会、社科院法学所的官网会同步发布

## 兜底：直接抓学者主页或机构新闻

如出现 `腾讯新闻 so.html5.qq.com` 转载，可以用 `web_fetch` 拿到全文摘要。

## 不建议使用

- ❌ 第三方爬虫服务（newrank.cn / 西瓜数据等）— 需付费或有版权风险
- ❌ 微信公众号 API 个人号调用 — 触发风控封号
- ❌ Selenium 自动化登录公众号 — 违反 WeChat ToS
