# 王煜全初创企业发掘 · Skill

## 核心方法论

王煜全投资分析框架的四步：

1. **宏观——产业阶段判断**：产业处于导入期、成长期、成熟期还是衰退期？
2. **中观——产业链分析**：利润在哪个环节集中？谁有定价权？
3. **微观——四维评估**：技术壁垒、市场定位、政策顺风、出海能力
4. **验证陷阱**：否决"锤子找钉子"（技术好但市场不买单）和"伪需求"

**核心原则**：技术×市场×执行，三件事同时发生才能赢。单一维度强没有用。

## 输出标准

- 每期只分析 **1-2家** 具体公司
- 给出明确判断：**能投 / 不能投 / 不确定**
- 说明理由：行业逻辑 + 公司逻辑 + 风险点
- 时长：10分钟音频，分两段合成

## 内容结构（10分钟）

### 第一段（5分钟）：框架 + 行业判断
1. 开头：直接点名公司名（30秒）
2. 行业阶段：这个行业为什么能出100倍公司（2分钟）
3. 产业链定位：这家公司站在哪个环节（2分钟）

### 第二段（5分钟）：公司拆解 + 风险
1. 四维评估：技术/市场/政策/出海（3分钟）
2. 风险提示：什么情况下逻辑不成立（1分钟）
3. 结论：明确说"能投/不能投/再观察"（1分钟）

## 执行流程

### 1. 搜索最新内容
用 batch_web_search 搜索：
- 王煜全最近推荐的行业/公司
- 王煜全对特定赛道的最新判断
- 相关初创公司融资动态

### 2. 筛选标的
按以下标准筛选，优先选择同时满足多条的公司：
- 处于成长期行业（不是成熟期）
- 有明确的技术壁垒（不是纯模式创新）
- 有真实的付费客户（不是PPT阶段）
- 中国背景或中国团队/市场相关

### 3. 深度分析
用 extract_content_from_websites 抓取：
- 公司官网、融资公告
- 王煜全相关点评
- 行业对比数据

### 4. 写出分析脚本
按上方结构写，不背话术，给出自己的判断。

### 5. 合成音频
分两段合成（每段约500字），使用 voice_id: male-qn-qingse，speed: 1
