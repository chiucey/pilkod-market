## 📄 Word文档模板

### 商业报告模板
```
主题：[报告主题]
目标读者：[目标受众]
核心信息：
1. [关键发现1]
2. [关键发现2]
3. [关键发现3]

请按照以下结构撰写报告：
- 执行摘要
- 背景与目的
- 主要发现
- 分析与讨论
- 结论与建议
- 附录（如需要）

格式要求：
- 字体：[指定字体]
- 长度：[字数要求]
- 风格：[正式/简洁/专业]
```

## 📊 PPT演示模板

### 产品发布PPT
```
主题：[产品名称]
目标：介绍产品特点，激发购买兴趣
时长：[X]分钟
听众：[听众画像]

幻灯片结构：
1. 封面（产品名+品牌+发布日期）
2. 问题/痛点（用户面临的问题）
3. 解决方案（产品如何解决）
4. 产品特点（3-5个核心卖点）
5. 工作原理/技术亮点
6. 应用场景/案例展示
7. 用户评价/社会证明
8. 价格与购买方式
9. 联系方式/Q&A
10. 致谢

视觉风格：[简约科技/温暖亲和/高端专业]
```

### 工作汇报PPT
```
汇报人：[姓名]
汇报主题：[主题]
汇报周期：[时间范围]

汇报结构：
1. 封面（标题+姓名+部门+日期）
2. 目录/议程
3. 工作概览（关键指标一览）
4. 重点成果展示（2-3个亮点）
5. 问题与挑战
6. 下一步计划
7. 需要的支持/资源
8. Q&A

数据要求：需包含具体数字和对比
```

## 📈 Excel数据处理模板

### 数据分析报告
```

数据范围：[时间/范围]

分析维度：
1. 数据概览（记录数、字段数、时间范围）
2. 数据质量检查
   - 缺失值
   - 异常值
   - 重复项
3. 描述性统计
4. 趋势分析
5. 相关性分析
6. 关键发现
7. 建议与结论

输出要求：
- 数据表格
- 可视化图表
- 分析结论
```
