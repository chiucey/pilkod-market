## 使用指南

### 音频处理

1. **转码**：选择音频文件 → 选择目标格式（MP3/WAV/AAC/FLAC等）→ 选择编码参数 → 开始转换
2. **抽取**：选择视频文件 → 自动提取音频 → 保存
3. **降噪**：上传带噪音的音频 → 一键降噪 → 试听满意后保存
4. **剪辑**：拖动时间轴选择片段 → 精准裁剪 → 导出
5. **淡入淡出**：设置时长（2-5秒）→ 自动添加效果
6. **音量标准化**：上传音频 → 自动分析音量 → 一键标准化
7. **变速**：拖动速度滑块（0.5x-2.0x）→ 保持音调不变
8. **查看信息**：上传文件 → 显示采样率、时长、码率等参数

### 视频处理

1. **转码**：选择视频 → 选择格式+编码 → 开始转换
2. **截图**：拖动进度条定位 → 点击截图 → 保存单帧/连续帧
3. **降噪**：上传视频 → 选择降噪强度 → 导出优化后视频
4. **抽帧**：输入时间点或间隔 → 批量提取帧
5. **转GIF**：选择视频片段 → 设置尺寸和帧率 → 生成动图
6. **去水印**：框选水印区域 → AI自动消除 → 不影响画质
7. **拼接**：拖入多个视频 → 选择拼接模式 → 一键合并
8. **分割**：拖动时间轴 → 设置入出点 → 精准裁剪
9. **反序**：选择视频 → 一键倒放 → 保存
10. **画中画**：主视频+小窗口叠加 → 调整位置和大小
11. **图片合成视频**：导入多张图片 → 设置时长和转场 → 生成视频
12. **分屏**：选择布局模板（2/4/9宫格等）→ 拖入视频 → 导出
13. **转场**：选择转场效果（淡入淡出/滑动/缩放等）→ 设置时长
14. **亮度/对比度**：拖动滑块调整 → 实时预览
15. **调色**：预设风格/手动调节 → 打造专属色调
16. **比例裁剪**：选择平台比例（9:16/16:9/1:1/4:3）→ 自动适配
17. **压缩**：选择模式（保持画质/减小体积）→ 快速压缩
18. **变速**：拖动速度（0.25x-4x）→ 不损画质
19. **音量调节**：拖动音量滑块 → 静音或增强
20. **裁剪**：框选保留区域 → 去除多余画面
21. **旋转/翻转**：选择角度（90°/180°/水平/垂直）→ 保存

### 图片处理

1. **格式转换**：上传图片 → 选择目标格式（JPG/PNG/WebP等）→ 转换
2. **去水印**：框选水印区域 → AI自动消除
3. **比例裁剪**：选择平台尺寸 → 自动裁剪
4. **拼接**：选择拼接方式（横/纵/网格）→ 拖入图片 → 生成

### 合成与批量

1. **音视频合成**：导入视频+音频 → 对齐时间轴 → 合并导出
2. **批量转码**：拖入多个文件 → 选择目标格式 → 批量转换
3. **批量裁剪**：选择统一比例 → 拖入多个文件 → 一键处理
4. **批量压缩**：设置压缩参数 → 拖入多个文件 → 批量压缩

### 实用工具

1. **抖音/B站下载**：粘贴视频链接 → 自动解析 → 无水印下载
2. **TTS语音合成**：输入文本 → 选择语言/音色 → 生成语音
