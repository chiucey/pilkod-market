# 客户开发搜索模板

## 谷歌搜索模板

### 制造商搜索
```
"[产品]" manufacturer
"[产品]" manufacturer in [国家/城市]
"[产品]" factory
"[产品]" manufacturing company
```

### 批发商/分销商搜索
```
"[产品]" wholesaler
"[产品]" distributor
"[产品]" supplier
"[产品]" bulk supplier
"[产品]" wholesale supplier
```

### 进口商/出口商搜索
```
"[产品]" importer
"[产品]" exporter
"[产品]" trading company
"[产品]" export-import
```

### 零售商搜索
```
"[产品]" retailer
"[产品]" store
"[产品]" shop
"[产品]" dealer
```

## 谷歌地图搜索

### 商家定位
```
[产品] + [城市/地区] + maps
"[产品] near me"
"[产品] supplier" + [城市]
```

### 商业区搜索
```
[产品] + business park
[产品] + industrial zone
[产品] + wholesale market
```

## 高级搜索组合

### 多关键词组合
```
"[产品]" AND "[地区]" AND (manufacturer OR supplier)
"[产品]" + "made in" + [国家]
"[产品]" industry leader in [地区]
```

### 排除词使用
```
"[产品]" supplier -ebay -amazon -alibaba
"[产品]" wholesale -retail -reseller
```

### 文件类型搜索
```
filetype:pdf "[产品]" catalog
filetype:xls "[产品]" price list
"[产品]" company profile filetype:pdf
```

## 地区特定搜索

### 常用国家/地区关键词
```
China: "[产品]" manufacturer +site:cn
Vietnam: "[产品]" manufacturer Vietnam
India: "[产品]" supplier India +site:in
USA: "[产品]" manufacturer USA +site:com
Europe: "[产品]" supplier Europe +site:eu
```
