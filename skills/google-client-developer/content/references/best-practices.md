# 客户开发最佳实践

## 搜索策略优化

### 1. 关键词优化
- **核心词**：产品名称、主要特征
- **修饰词**：manufacturer, supplier, wholesaler, distributor
- **地区词**：国家、城市、地区缩写
- **组合方式**：核心词 + 修饰词 + 地区词

### 2. 多渠道交叉验证
- 一个客户在多个平台出现 = 高可信度
- 单一渠道发现 = 需要进一步验证
- 关注平台认证和活跃度

### 3. 搜索频率管理
- 避免短时间内大量请求
- 使用不同关键词变体
- 分散搜索时间

## 数据收集规范

### 必收信息
- [x] 公司/品牌名称
- [x] 官方网站URL
- [x] 联系电话（如有）
- [x] 邮箱地址（如有）
- [x] 社交媒体账号
- [x] 公司地址

### 选收信息
- [ ] 公司规模（员工数）
- [ ] 年营业额
- [ ] 成立时间
- [ ] 主营产品
- [ ] 客户评价/评分
- [ ] 认证信息

### 数据完整度评分
```
完整（80-100%）：官网+电话+邮箱+社交媒体
较完整（60-79%）：官网+至少2种联系方式
一般（40-59%）：官网+1种联系方式
不完整（<40%）：仅有公司名或社交媒体
```

## 客户筛选标准

### 优先级划分
| 优先级 | 特征 | 说明 |
|--------|------|------|
| P1 | 有官网+完整联系方式 | 直接跟进 |
| P2 | 有官网+部分联系方式 | 需补充信息 |
| P3 | 仅社交媒体存在 | 需进一步调查 |
| P4 | 信息模糊或过期 | 暂缓或放弃 |

### 排除标准
- 竞争对手公司
- 非商业性质机构
- 信息明显过时（网站已关闭）
- 仅有个人信息无商业价值

## 跟进建议

### 首次接触
1. 通过官网联系表单
2. 通过LinkedIn发送连接请求
3. 通过info@邮箱发送自我介绍

### 邮件模板要素
- 明确说明如何找到对方
- 简述己方产品/服务
- 说明合作价值
- 提供下一步行动建议
- 附上联系方式

### 跟进时机
- 首次联系后7天
- 未回复则14天后第二次跟进
- 最多3次跟进尝试

## 法律与道德规范

### 合规要求
- 仅收集公开商业信息
- 遵守GDPR等数据保护法规
- 不使用自动化爬虫抓取数据
- 尊重平台使用条款

### 禁止行为
- 不得伪造身份联系客户
- 不得发送垃圾邮件
- 不得泄露客户数据给第三方
- 不得使用非法获取的数据

### 建议做法
- 在邮件中说明信息来源
- 提供退订选项
- 保持专业和礼貌
- 尊重对方时间和意愿
