# 谷歌客户自动开发工具

## 功能概述

通过多渠道自动搜索和开发潜在B2B客户，整合谷歌搜索、谷歌地图、社交媒体等多平台数据。

## 工作流程

### 1. 收集客户开发需求

**必填参数：**
- 目标行业/产品关键词
- 目标地区/市场

**可选参数：**
- 公司规模（小型/中型/大型）
- 客户类型（制造商/分销商/零售商）
- 特定要求

### 2. 多渠道搜索策略

#### A. 谷歌关键词搜索
- 使用关键词组合：`[产品] + [行业] + [distributor/manufacturer/supplier/wholesale]`
- 使用过滤器定位特定地区
- 收集公司名称、网站、联系方式

#### B. 谷歌地图搜索
- 搜索：`[产品] + [地区]`
- 提取商家信息：名称、地址、电话、网站、评分
- 识别本地供应商和分销商

#### C. 社交媒体客户开发

**TikTok：**
- 搜索品牌账号和商业账号
- 分析企业认证账号
- 收集主页链接和联系方式

**Facebook：**
- 搜索公司主页和商业群组
- 查找商业页面联系方式
- 分析评论中的商业账号

**LinkedIn：**
- 搜索公司主页
- 查找决策者和管理层
- 收集公司规模、行业、位置信息

**Instagram：**
- 搜索品牌账号
- 分析商业账号简介
- 收集联系方式

### 3. 数据整理与输出

**收集的客户信息：**
- 公司名称
- 官方网站
- 联系电话/邮箱
- 社交媒体账号
- 地址位置
- 产品/服务描述
- 数据来源渠道

**输出格式：**
- 结构化客户列表（JSON格式）
- 可导出CSV/Excel格式
- 按渠道分类整理

## 使用示例

**示例1：开发美国市场的LED灯具客户**
```
关键词：LED lights
地区：United States
渠道：Google + Google Maps + Facebook
```

**示例2：开发东南亚家具制造商**
```
关键词：furniture manufacturer
地区：Vietnam, Thailand, Indonesia
渠道：LinkedIn + Google + Instagram
```

## 执行命令

### 关键词搜索
使用 `batch_web_search` 执行多个搜索查询：
- 产品关键词搜索
- 制造商搜索
- 批发商搜索
- 分销商搜索

### 地图搜索
使用 `batch_web_search` 搜索：
- 地区 + 产品 + "Google Maps"
- 从搜索结果提取商家信息

### 社交媒体搜索
使用 `batch_web_search` 搜索：
- `[品牌] site:tiktok.com`
- `[公司] site:facebook.com`
- `[公司] site:linkedin.com`
- `[品牌] site:instagram.com`

## 输出规范

1. **JSON格式客户数据**
2. **分类整理**：按渠道/地区/行业分类
3. **去重处理**：合并同一公司的多渠道信息
4. **数据完整度评分**：评估信息完整程度

## 注意事项

- 遵守各平台使用条款
- 仅收集公开商业信息
- 尊重数据保护法规（如GDPR）
- 建议人工核实联系方式有效性
