# 错题分析技能

对试卷中的错题进行全面分析，帮助学生理解和掌握知识薄弱点。

## 核心功能

### 1. 错题知识点分类分析

**分析维度：**

- **知识点识别**：从每道错题中提取核心知识点
- **错误类型分类**：
  - 概念理解错误
  - 审题不清
  - 计算失误
  - 知识遗忘
  - 综合应用能力不足
- **知识模块归类**：将错误归入对应的知识模块
- **错误频率统计**：统计各知识模块的错误频次

**输出格式：**
```
知识点分类统计表
| 知识模块 | 错误次数 | 错误率 | 优先级 |
|---------|---------|-------|-------|
| 代数运算 | 3 | 30% | 高 |
| 几何证明 | 2 | 20% | 中 |
| ... | ... | ... | ... |
```

### 2. 错题详细讲解

**讲解内容：**

- **原题重现**：完整呈现题目内容
- **正确答案**：给出正确解法
- **错误分析**：分析学生可能犯的错误原因
- **知识点解析**：详细解释涉及的知识点
- **解题思路**：提供系统的解题方法
- **类似题目**：列举同类型练习题

### 3. 针对性练习整理

**练习分类原则：**

- **同知识点练习**：针对每个薄弱知识点提供3-5道练习
- **难度梯度**：从基础到提高，循序渐进
- **变式训练**：提供题目变式，锻炼举一反三能力
- **综合练习**：设计跨知识点的综合题目

## 执行流程

### 步骤 1：接收试卷内容

接收用户提供的试卷内容，可以是：
- 试卷图片（使用图片理解工具分析）
- 试卷文字内容
- 题目与答案对照

### 步骤 2：识别错题

识别并列出所有错题，提取：
- 题目内容
- 学生答案
- 正确答案
- 题目分值

### 步骤 3：知识点分类

对每道错题进行：
1. 标记涉及的知识模块
2. 分析错误类型
3. 评估掌握程度

### 步骤 4：生成讲解

为每道错题生成详细讲解，包含：
- 错误原因分析
- 正确解法演示
- 相关知识点梳理

### 步骤 5：整理练习

根据分类结果：
1. 按知识模块分组练习题
2. 提供难度建议
3. 标注练习重点

## 示例

**输入示例：**
用户上传数学试卷图片或输入题目内容

**输出示例：**
```
## 错题分析报告

### 知识点分类统计
| 知识模块 | 错误次数 | 占比 | 优先级 |
|---------|---------|-----|-------|
| 一元二次方程 | 4 | 40% | ★★★ |
| 因式分解 | 2 | 20% | ★★ |
| 函数图像 | 3 | 30% | ★★★ |
| 几何证明 | 1 | 10% | ★ |

### 错题讲解示例

**题目：** 解方程 x² - 5x + 6 = 0

**学生答案：** x = 2

**正确答案：** x₁ = 2, x₂ = 3

**错误分析：** 只求出一个根，遗漏了另一个解

**正确解法：** (x-2)(x-3) = 0，x = 2 或 x = 3

...
```

## 注意事项

1. **仔细审题**：确保理解每道题目的完整含义
2. **多种解法**：尽量提供不同角度的解题思路
3. **循序渐进**：练习题按难度排序
4. **举一反三**：提供变式题目帮助深化理解
