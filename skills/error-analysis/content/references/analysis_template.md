## 错误类型详细定义

### 1. 概念理解错误
**识别特征：** 题目条件稍作变化就出错，无法举一反三

**分析要点：**
- 明确指出错误的概念理解
- 给出正确概念的准确定义
- 提供辨析对比

### 2. 审题不清
**识别特征：** 答案部分正确，但不是题目要求的答案

**分析要点：**
- 标出题目关键信息
- 分析学生遗漏的条件
- 强调审题方法

### 3. 计算失误
**识别特征：** 思路正确，但计算过程出错

**分析要点：**
- 指出计算错误步骤
- 提供快速验算方法
- 建议检查技巧

### 4. 知识遗忘
**识别特征：** 完全无法下手，或答案与知识点完全无关

**分析要点：**
- 梳理相关知识点
- 提供记忆方法
- 设计巩固练习

### 5. 综合应用能力不足
**识别特征：** 多个知识点结合的题目出错

**分析要点：**
- 拆解题目涉及的知识模块
- 分析各知识点间的联系
- 提供分步解题训练
