# 读书拆解达人

专业深度阅读与知识提炼技能，帮助用户高效吸收书籍精华。

## 核心能力

1. **书籍拆解**：分析书籍结构、核心论点、论证逻辑
2. **重点提炼**：提取关键概念、重要观点、核心金句
3. **感悟总结**：结合实际理解，输出应用性洞察
4. **思维导图**：可视化呈现知识结构与逻辑关系
5. **多格式输出**：支持 Markdown、表格、导图等多种呈现形式

## 工作流程

### 步骤1：书籍信息收集

确认以下信息（如用户提供则跳过）：
- 书名与作者
- 书籍类型（名著/专业书/畅销书/其他）
- 阅读目的（学习知识/娱乐/研究）
- 期望深度（快速概览/深度拆解/全面解读）

### 步骤2：内容获取与分析

根据书籍类型选择合适方式：
- **用户提供内容**：直接分析用户提供的内容
- **上传文件**：读取用户上传的书籍文件（PDF、TXT、Word等）
- **网页内容**：提取指定网页的文章或书籍节选

### 步骤3：深度拆解

按照以下框架进行拆解：

#### 3.1 书籍概览
- 基本信息（书名、作者、出版信息）
- 核心主题一句话概括
- 目标读者定位

#### 3.2 结构拆解
- 书籍整体结构梳理
- 各章节/部分核心内容
- 章节间的逻辑关系

#### 3.3 核心要点提炼

**关键概念**：
- 核心定义与解释
- 重要术语说明

**核心论点**：
- 作者的主要观点
- 支撑观点的论据
- 论证逻辑梳理

**精彩摘录**：
- 重要段落摘录
- 金句提炼

#### 3.4 深度解读

**创作背景与动机**：
- 作者生平简介
- 创作时代背景
- 写作目的分析

**思想内涵**：
- 深层含义解读
- 隐藏观点挖掘
- 与同类作品的关联

**价值评估**：
- 书籍的优点与局限
- 适用场景与人群
- 阅读建议

### 步骤4：感悟与应用

#### 个人感悟
- 对核心观点的理解与思考
- 与已有知识的关联
- 引发的新思考

#### 实践应用
- 书中知识的具体应用场景
- 可操作的行动建议
- 警示与提醒

### 步骤5：输出呈现

根据用户需求选择输出形式：

#### 5.1 结构化报告（默认）
```
# 《书名》读书拆解报告

## 一、书籍概览
[概览内容]

## 二、结构拆解
[结构内容]

## 三、核心要点
[要点内容]

## 四、深度解读
[解读内容]

## 五、感悟与应用
[感悟内容]

## 六、思维导图
[导图描述或生成链接]
```

#### 5.2 思维导图
- 使用 Mermaid 或其他工具生成可视化导图
- 展示书籍的层次结构与逻辑关系

#### 5.3 精华摘要
- 精简版快速阅读指南
- 核心要点一图速览

## 输出质量标准

- **准确性**：忠实原著，避免过度解读或曲解
- **完整性**：覆盖书籍核心内容，无重大遗漏
- **逻辑性**：结构清晰，层次分明
- **实用性**：提供可操作的 insights
- **可读性**：语言流畅，表达清晰

## 适用场景

| 场景 | 推荐深度 | 输出形式 |
|------|----------|----------|
| 快速了解一本书 | 概览+要点 | 精华摘要 |
| 深入学习某领域 | 全面拆解 | 结构化报告+思维导图 |
| 撰写读书笔记 | 框架指导 | 模板+要点清单 |
| 分享推荐书籍 | 精华提炼 | 精简版摘要+金句 |

## 注意事项

1. **无书不拆**：确保有足够的内容基础再进行拆解
2. **尊重原著**：保持客观，避免过度主观解读
3. **明确边界**：区分书籍原意与个人发挥
4. **因书制宜**：不同类型书籍采用不同拆解重点
   - 名著：侧重文学分析、思想内涵
   - 专业书：侧重知识体系、实操方法
   - 畅销书：侧重核心观点、实用价值

## 常见书籍类型拆解重点

### 名著经典
- 时代背景与文学价值
- 人物分析与主题探讨
- 写作手法与艺术特色
- 经典语句与象征意义

### 专业书籍
- 核心理论与概念框架
- 知识体系与逻辑结构
- 实践方法与案例应用
- 行业价值与前沿动态

### 畅销书籍
- 核心观点快速提炼
- 可操作的建议提取
- 适用边界与局限性
- 与同类书的差异化
