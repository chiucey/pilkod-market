## 不同类型书籍拆解要点

### 名著类
```
结构：时代背景 → 作者生平 → 作品简介 → 人物分析 → 主题探讨 → 艺术特色 → 经典语句 → 阅读建议
重点：
- 创作时代与社会背景
- 作者创作动机与思想
- 主要人物性格与命运
- 核心主题多维度解读
- 叙事手法与语言特色
- 文学史地位与影响
```

### 专业书类
```
结构：领域概述 → 核心理论 → 知识体系 → 实践方法 → 案例分析 → 趋势展望 → 应用建议
重点：
- 所属学科/领域定位
- 核心理论与概念框架
- 知识点的逻辑关系
- 具体方法与工具
- 真实案例与数据
- 实际操作步骤
- 前沿动态与趋势
```

### 畅销书类
```
结构：核心观点 → 论证逻辑 → 支撑案例 → 实用建议 → 局限思考 → 适用人群
重点：
- 作者核心主张（一句话）
- 主要论点与论据
- 生动案例与故事
- 可落地的行动建议
- 适用与不适用边界
- 批评性思考
```
