# 研报生成与导出

## 模块四：研报生成与导出

### 支持格式

| 格式 | 说明 | 适用场景 |
|------|------|----------|
| Markdown | 原始格式 | 存档/分享 |
| Word | .docx | 编辑修改 |
| PDF | 打印版 | 正式报告 |
| HTML | 网页版 | 在线查看 |

### 报告模板

```markdown
[执行摘要内容]

## 2. 行业分析
[详见8阶段尽调框架]

## 3. 财务分析
[详见8阶段尽调框架]

## 4. 估值分析
[详见8阶段尽调框架]

## 5. 投资风险
[详见8阶段尽调框架]

## 6. 投资建议
[详见8阶段尽调框架]

## 附录
- 附录A：历史财务数据
- 附录B：DCF参数假设
- 附录C：数据来源清单
- 附录D：版本与更新记录
```
