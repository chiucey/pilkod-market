# 框架与理念

## 核心理念

融合价值投资、质量投资、成长投资、逆向投资、宏观投资等多理念体系，为投资者提供专业、客观、深度的股票分析。

**分析原则**：
- 股票价值是客观的，用数据说话
- 多视角交叉验证，不迷信单一指标
- 长期趋势比短期波动更重要

---

## 8阶段专业尽调框架

本技能采用机构级8阶段尽调框架，对股票进行全面深度的分析：

| 阶段 | 研究重点 | 核心输出 |
|------|----------|----------|
| **1. 公司事实底座** | 公司基本情况 | 产品/营收结构/客户/价值链/战略定位 |
| **2. 行业周期分析** | 行业环境 | 周期位置/供需关系/竞争格局/政策影响 |
| **3. 业务拆解** | 利润来源 | 业务分部/利润引擎/定价权/经济模型 |
| **4. 财务质量** | 财务健康度 | 现金流/利润率/风险信号/同行对比 |
| **5. 公司治理** | 管理层质量 | 股权结构/管理层/资本配置/ROIC |
| **6. 市场分歧** | 多空观点 | 多方论点/空方论点/核心争议/验证节点 |
| **7. 估值与护城河** | 投资价值 | 护城河评级(0-5)/估值/风险 |
| **8. 综合报告** | 最终结论 | 信号评级/投资论点/监测清单 |

**质量标准**：
- 所有关键结论必须标注数据来源
- 争议性观点需标注多空双方论据
- 引用可信度评级（A=权威/B=可靠/C=一般/D=需验证）

## 输入参数

| 参数 | 必需 | 默认值 | 说明 |
|------|------|--------|------|
| symbol | 是 | - | 股票代码（600519.SH、0700.HK、BABA.O） |
| analysis_type | 否 | full | 分析深度（full/valuation_only/fundamental/technical） |
| investor_style | 否 | balanced | 投资风格（value/growth/turnaround/dividend/balanced） |
| holding_period | 否 | medium | 持有周期（short<6m/medium 6-18m/long>1y） |
| risk_tolerance | 否 | moderate | 风险偏好（conservative/moderate/aggressive） |

---

## 投资风格说明

| 风格 | 估值方法 | 关键指标 | 适用场景 |
|------|----------|----------|----------|
| **价值投资(value)** | P/B, EV/EBITDA, DCF(保守) | P/B, 标准化盈利, FCF收益率 | 低估值、高安全边际机会 |
| **成长投资(growth)** | PEG, DCF(激进), 用户模型 | 营收增长, 护城河, TAM渗透率 | 高成长潜力公司 |
| **困境反转(turnaround)** | 清算价值, 期权价值 | 债务率, 现金跑道, 催化剂时间线 | 业绩承压但有反转可能 |
| **红利投资(dividend)** | DDM, FCF收益率 | 股息率, 分派率, FCF覆盖率 | 追求稳定现金收益 |
| **均衡配置(balanced)** | 综合评估 | 所有维度均衡 | 标准分析场景 |

---

## 持有周期说明

| 周期 | 说明 | 分析重点 |
|------|------|----------|
| 短期(short<6m) | 6个月以内 | 技术面、短期催化剂、事件驱动 |
| 中期(medium 6-18m) | 6个月到1年半 | 基本面拐点、业绩预期 |
| 长期(long>1y) | 1年以上 | 竞争优势、长期成长性、管理层质量 |
