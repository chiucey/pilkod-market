# 评分体系（可量化版本）

## 数据来源标注要求

> **重要**: 所有评分数据必须标注来源和时间，格式：`数值@来源:时间`

### 必需标注的数据

| 数据类型 | 标注格式 | 示例 |
|----------|----------|------|
| 价格数据 | `价格@来源:时间` | `36.92@Baostock:2026-04-20 15:00` |
| 估值指标 | `指标@来源:日期` | `152.81x@东方财富:2026-04-20` |
| 财务数据 | `数值@来源:报告期` | `2.90亿@公司公告:2025-12-31` |
| 情绪数据 | `分值@来源:时间` | `65@雪球:2026-04-20` |

### 可信度评级

| 评级 | 来源 | 适用数据 |
|------|------|----------|
| A级 | 交易所、监管机构、公司公告 | 年报、季报、交易所行情 |
| B级 | Baostock、东方财富、同花顺 | 金融数据平台 |
| C级 | 雪球、东财股吧 | 情绪数据、估算数据 |
| D级 | DCF计算、内部假设 | 估值模型、需要验证 |

## 8维度统一评分体系

> **设计原则**: 投行分析模块(分析师预期、盈利预测等)作为第8维度，整合形成完整的8维度评分体系

### 维度权重总览

| 维度 | 权重 | 核心指标 | 评分范围 |
|------|------|----------|----------|
| 1. 估值分析 | 20% | PE/PB/PEG/股息率/安全边际 | 0-100 |
| 2. 基本面分析 | 18% | ROE/ROIC/营收净利增速/现金流 | 0-100 |
| 3. 技术面分析 | 15% | 均线/RSI/MACD/量能/趋势 | 0-100 |
| 4. 情绪分析 | 12% | 散户情绪/机构持仓/分析师评级/外资 | 0-100 |
| 5. 宏观分析 | 8% | 经济周期/货币政策/汇率 | 0-100 |
| 6. 行业分析 | 8% | 行业地位/竞争格局/政策 | 0-100 |
| 7. 风险评估 | 9% | 波动性/流动性/经营/财务/行业 | 0-100 |
| **8. 投行预期** | 10% | 分析师评级/目标价/盈利预测/股息 | 0-100 |

### 综合评分计算

```
综合评分 = 估值×20% + 基本面×18% + 技术×15% + 情绪×12% + 宏观×8% + 行业×8% + 风险×9% + 投行×10%
```

## 各维度量化评分公式

### 1. 估值评分（0-100）

```
估值得分 = PE分位×25% + PB分位×20% + PEG分×15% + 股息率分×15% + 安全边际分×25%

其中:
- PE分位 = 100 - (当前PE在5年历史分位)
- PB分位 = 100 - (当前PB在5年历史分位)
- PEG分 = min(100, (1/PEG)×50) if PEG>0 else 100
- 股息率分 = min(100, 股息率/行业均值股息率×50)
- 安全边际分 = max(0, min(100, (内在价值-当前价)/内在价值×200))
```

### 2. 基本面评分（0-100）

```
基本面得分 = ROE分×25% + ROIC分×20% + 营收增速分×20% + 净利增速分×20% + 现金流分×15%

其中:
- ROE分 = min(100, ROE/行业龙头ROE×100)
- ROIC分 = min(100, ROIC/行业龙头ROIC×100)
- 营收增速分 = min(100, 营收增速×3.33)  (30%增速=100分)
- 净利增速分 = min(100, 净利增速×3.33)
- 现金流分 = 100 if CFO/净利>1 else CFO/净利×100
```

### 3. 技术面评分（0-100）

```
技术得分 = 均线多头分×20% + RSI分×20% + MACD分×15% + 量能分×10% + 52周高分×15% + 趋势一致分×10% + 支撑阻力分×10%

其中:
- 均线多头分 = 100 if MA5>MA10>MA20 else 60 if MA5>MA20 else 30
- RSI分 = 100 if RSI<30 else 80 if RSI<40 else 60 if RSI<60 else 40 if RSI<70 else 20
- MACD分 = 100 if DIF>DEA and DIF>0 else 50 if DIF>0 else 20
- 量能分 = 100 if 放量>1.2 else 80 if 放量>1 else 60
- 52周高分 = max(0, 100 - (当前价/52周高点-1)×200)
- 趋势一致分 = 100 if 短期中期长期趋势一致 else 60
- 支撑阻力分 = 基于支撑位数量和强度 (0-100)
```

### 4. 情绪评分（0-100）

```
情绪得分 = 散户情绪分×25% + 机构持仓分×25% + 分析师评级分×30% + 外资分×20%

其中:
- 散户情绪分 = 雪球/东财情绪指数 (0-100)
- 机构持仓分 = 机构持股比例得分 (0-100)
- 分析师评级分 = 买入比例×100 + 增持比例×80 + 持有比例×50 + 减持比例×20 + 卖出比例×0
- 外资分 = 北向资金持股变化得分 (0-100)
```

### 5. 宏观评分（0-100）

```
宏观得分 = 经济周期分×30% + 货币政策分×25% + 行业政策分×25% + 汇率分×20%

其中:
- 经济周期分 = 复苏100/扩张80/放缓50/衰退20
- 货币政策分 = 宽松100/中性60/紧缩20
- 行业政策分 = 利好100/中性50/利空0
- 汇率分 = 稳定80/波动50/大幅波动20
```

### 6. 行业评分（0-100）

```
行业得分 = 行业地位分×30% + 竞争格局分×25% + 行业增速分×25% + 政策影响分×20%

其中:
- 行业地位分 = (1-排名/总数)×100
- 竞争格局分 = 垄断100/寡头80/分散50
- 行业增速分 = min(100, 行业增速×10)
- 政策影响分 = 利好100/中性50/利空0
```

### 7. 风险评分（0-100）

```
风险得分 = 100 - (波动风险分×25% + 流动性风险分×20% + 经营风险分×20% + 财务风险分×20% + 行业风险分×15%)

其中:
- 波动风险分 = Beta>1.5?100 : Beta>1.2?70 : Beta>1?40 : 20
- 流动性风险分 = 日均成交额<5000万?100 : <1亿?70 : <5亿?40 : 10
- 经营风险分 = 高?100 : 中?50 : 低?20
- 财务风险分 = 资产负债率>80%?100 : >70%?70 : >60%?40 : 20
- 行业风险分 = 高?100 : 中?50 : 低?20
```

### 8. 投行预期评分（0-100）★新增维度

```
投行得分 = 分析师评级分×25% + 目标价共识分×25% + 盈利预测分×20% + 业务结构分×15% + 股息分×15%

其中:
- 分析师评级分 = 买入比例×100 + 增持比例×80 + 持有比例×50 + 减持比例×20 + 卖出比例×0
- 目标价共识分 = max(0, min(100, (共识目标价/当前价-1)×200))  (上涨空间>50%=100分)
- 盈利预测分 = max(0, min(100, 100 - 预测误差率×5))
- 业务结构分 = 业务多元化程度得分 (0-100)
  - 单一业务: 30分
  - 2-3个业务: 60分
  - 3个以上且稳定: 100分
- 股息分 = min(100, 分红率×2) if 分红稳定增长 else 分红率×1.5
```
