# 数据来源与时效性

## 数据来源规范

| 数据类型 | 主要来源 | 延迟 | 可靠性 | 说明 |
|----------|----------|------|--------|------|
| 实时价格 | Baostock / akshare / 港交所 | <3秒 | 高 | 多源验证 |
| 技术指标 | Baostock / akshare / 同花顺 | 分钟级 | 高 | 基于实时价格计算 |
| 基本面数据 | **Baostock** / 公司公告 / Wind | 日更 | 高 | 财报发布后更新 |
| 估值指标 | Baostock / 东方财富 / Bloomberg | 日更 | 高 | 基于最新财报 |
| 分析师评级 | 券商研报 / 雪球 | 日更 | 高 | 综合主流券商观点 |
| 国内论坛情绪 | 雪球 / 东方财富 / 同花顺 | 实时 | 中 | 需注意噪声过滤 |
| 宏观数据 | Wind / 国家统计局 / 美联储 | 月度/季度 | 高 | 参考使用 |

---

## 数据实时性要求

**执行摘要数据（必须标注）**：
- 当前价格：标注采集时间（精确到分钟）
- 涨跌幅：当日涨跌幅
- 52周高低点：标注数据日期
- 综合评分：标注评分日期

**数据新鲜度标识**：
```
数据采集时间: YYYY-MM-DD HH:MM:SS
财务数据更新: YYYY-MM-DD（最近财报发布日期）
市场情绪数据: YYYY-MM-DD HH:MM（最近采集时间）
```

## 数据源分层架构

### 第一层：主数据源（优先使用）

| 市场 | 主数据源 | 优先级 | 备注 |
|------|----------|--------|------|
| **A股** | **Baostock** (免费,无需注册) | 1 | 数据全面稳定 |
| A股 | 东方财富、同花顺、腾讯财经 | 2 | 实时行情 |
| 港股 | AASTOCKS、港交所、东方财富、腾讯财经 | 1 | - |

> ⚠️ **重要提示**: 港股数据请优先使用akshare或其他国内可访问源

### 第二层：备用数据源（主源不可用时）

| 市场 | 备用源 | 触发条件 |
|------|--------|----------|
| A股 | akshare、新浪财经、网易财经、腾讯财经 | Baostock不可用 |
| 港股 | akshare、AASTOCKS、腾讯自选股、东方财富 | 主源不可用 |

### 第三层：权威验证源（用于交叉验证）

| 数据类型 | 验证源 | 用途 |
|----------|--------|------|
| 财务数据 | 公司公告、SEC EDGAR | 交叉验证财报数据 |
| 实时价格 | 交易所直连、经纪商API | 验证价格准确性 |
| 宏观数据 | 国家统计局、美联储 | 宏观分析验证 |

## 数据时效性分类管理

### 实时数据（交易时段）

| 数据类型 | 更新频率 | 有效期限 | 说明 |
|----------|----------|----------|------|
| 当前价格 | 实时 | <30秒 | 交易时段内 |
| 涨跌幅 | 实时 | <30秒 | 当日涨跌幅 |
| 成交量 | 实时 | <1分钟 | 当日累计 |
| 盘口数据 | 实时 | <1分钟 | Level2数据 |

### 准实时数据

| 数据类型 | 更新频率 | 有效期限 | 说明 |
|----------|----------|----------|------|
| 日K线 | 收盘后15分钟 | 当日有效 | 技术指标计算 |
| 分钟K线 | 1/5/15分钟 | 收盘后更新 | 短期技术分析 |
| RSI/MACD | 收盘后计算 | 当日有效 | 技术指标 |

### 日更数据

| 数据类型 | 更新频率 | 有效期限 | 说明 |
|----------|----------|----------|------|
| 融资融券 | 每日收盘后 | 次日开盘前 | 杠杆情绪指标 |
| 北向资金 | 每日收盘后 | 次日开盘前 | 外资动向 |
| 行业数据 | 每日 | 实时参考 | 行业涨跌排名 |

## 服务降级策略

当主数据源不可用时,按以下优先级切换:

```
1. Baostock (A股主选)
   ↓ 不可用
2. akshare
   ↓ 不可用
3. 新浪财经/网易财经
   ↓ 不可用
4. 返回"数据获取失败"并提示用户
```
