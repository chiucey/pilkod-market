# 多票对比与筛选

## 模块三：多票对比与筛选

### 功能描述

支持多只股票同时分析对比，支持自定义筛选条件。

### 对比分析模板

```markdown
# 白酒龙头对比研报

## 综合评分对比
| 股票 | 评级 | 目标价 | 空间 | 综合评分 |
|------|------|--------|------|----------|
| 泸州老窖 | 🟢🟢买入 | ¥280 | +12.5% | 82 |
| 五粮液 | 🟡🟡🟡持有 | ¥200 | +8.7% | 81 |
| 贵州茅台 | 🟢🟢买入 | ¥2,150 | +15.8% | 80 |

## 估值对比
| 指标 | 贵州茅台 | 五粮液 | 泸州老窖 |
|------|----------|--------|----------|
| PE(TTM) | 32x | 25x | 28x |
| vs 5年均值 | +5% | -15% | -3% |
| 股息率 | 2.1% | 2.8% | 2.5% |
| ROE | 31% | 22% | 28% |

## 基本面对比
| 指标 | 贵州茅台 | 五粮液 | 泸州老窖 |
|------|----------|--------|----------|
| 营收增速 | +15% | +12% | +18% |
| 净利润增速 | +18% | +14% | +22% |
| 毛利率 | 91% | 75% | 78% |

## 综合建议
**首选**：泸州老窖（成长性最好，估值适中）
**次选**：贵州茅台（品牌护城河最强）
**谨慎**：五粮液（估值最低但基本面相对弱）
```

## 筛选条件

### 预设筛选条件

| 筛选类型 | 条件 | 说明 |
|----------|------|------|
| **价值筛选** | P/E < 20 | 市盈率低于20 |
| | P/B < 3 | 市净率低于3 |
| | 股息率 > 3% | 股息率高于3% |
| **成长筛选** | 营收增速 > 15% | 营收同比增长超15% |
| | 净利润增速 > 15% | 净利润同比增长超15% |
| **质量筛选** | ROE > 15% | 净资产收益率高于15% |
| | 经营现金流/净利润 > 1 | 盈利质量好 |
| **技术筛选** | MA5 > MA20 | 短期多头 |
| | RSI < 70 | 非超买 |
| **综合筛选** | 综合评分 > 75 | 全部维度达标 |

### 自定义筛选示例

```
筛选条件:
- 行业: 家电制造
- 市值: > 500亿
- 日均成交额: > 5亿
- 综合评分: > 65
- 股息率: > 2%
- ROE: > 12%
```
