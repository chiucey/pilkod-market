# 持续监测与预警

## 模块一：回测能力

### 功能描述

对历史分析记录进行回测验证，量化AI分析的准确率，持续优化分析质量。

### 回测信号格式

```json
{
  "backtest_signal": {
    "report_id": "xxx",
    "report_date": "2026-04-12",
    "stock_code": "000333.SZ",
    "signal": "BUY",
    "signal_strength": 4,
    "target_price": 82.0,
    "stop_loss": 58.0,
    "score": 72,
    "dimensions": {
      "valuation": 65,
      "fundamental": 85,
      "technical": 52
    }
  }
}
```

### 回测参数配置

```python
BACKTEST_CONFIG = {
    "signal_thresholds": {
        "STRONG_BUY": 85,
        "BUY": 75,
        "HOLD": 60,
        "SELL": 45,
        "STRONG_SELL": 0,
    },
    "position_limits": {
        "max_single": 0.20,
        "max_sector": 0.40,
        "min_daily_volume": 1e8,
        "max_positions": 20,
    },
    "risk_rules": {
        "stop_loss": 0.08,
        "take_profit": 0.25,
        "trailing_stop": 0.05,
        "rebalance_period": 20,
    },
    "cost": {
        "stamp_tax": 0.001,
        "commission": 0.0003,
    }
}
```

### 止损条件

| 条件 | 阈值 | 说明 |
|------|------|------|
| 价格止损 | -15%至-20% | 跌破成本价15-20% |
| 基本面止损 | 核心指标恶化 | ROE连续2季度下降>20% |
| 逻辑止损 | 投资假设破坏 | 当初买入的逻辑不再成立 |

### 止盈条件

| 条件 | 阈值 | 说明 |
|------|------|------|
| 估值目标 | 达到乐观目标价 | DCF乐观情景目标价 |
| 技术目标 | 重要阻力位 | 前期高点、历史高位 |
| 风险回报比 | R/R < 1:1.5 | 上行空间不足风险2倍 |

## 模块二：持续监测与预警

### 监测类型

#### 价格监测

```
触发条件:
- 涨跌幅 > ±5%: 提醒
- 涨跌幅 > ±10%: 警告
- 盘中异动 > ±3% 且成交量放大 > 2倍: 重点关注
```

#### 基本面监测

```
触发条件:
- 季报/年报发布后: 自动更新评分
- 重大业务变化: 公告后24小时内
- 分析师评级大幅调整: 评级或目标价变化>20%
```

#### 情绪监测

```
触发条件:
- 雪球讨论热度 > 过去30日均值3倍: 关注
- 东财股吧看多比例 > 80% 或 < 20%: 预警
- RSI > 80 或 RSI < 20: 技术面预警
```

### 监测配置示例

```yaml
monitoring:
  stock: 美的集团(000333.SZ)
  entry_price: 70.49
  entry_date: 2026-04-12
  target_price: 82.0
  stop_loss: 58.0

  alerts:
    price:
      - trigger: "涨跌 > 5%"
        action: "通知"
      - trigger: "涨跌 > 10%"
        action: "警告+建议评估"

    fundamental:
      - trigger: "季报发布"
        action: "重新评分"
      - trigger: "评级大幅调整"
        action: "通知+重新评估"

    technical:
      - trigger: "RSI > 80"
        action: "考虑止盈"
      - trigger: "RSI < 20"
        action: "考虑加仓"
```

### 监测报告格式

```
## 📢 监测告警：美的集团 (000333.SZ)

**触发时间**: 2026-04-12 15:30
**触发类型**: 价格预警

### 告警详情
| 项目 | 值 | 阈值 | 状态 |
|------|-----|------|------|
| 当前价格 | ¥75.20 | - | - |
| 日涨跌幅 | +6.7% | >5% | ⚠️ 触发 |
| 成交量变化 | +180% | >100% | ⚠️ 放量 |
| RSI | 72.5 | >70超买 | ⚠️ 注意 |

### 建议操作
- 考虑分批止盈
- 评估当前基本面是否有变化
```
