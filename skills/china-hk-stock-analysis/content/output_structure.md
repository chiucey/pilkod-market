本文档定义股票分析报告的标准输出格式，所有模块需严格按此结构输出。

---

## 报告基础信息

| 字段 | 说明 | 必填 |
|------|------|------|
| report_id | 报告唯一标识(UUID) | 是 |
| report_date | 报告生成时间 | 是 |
| data_source | 主数据源 | 是 |
| data_freshness | 数据新鲜度 | 是 |
| stock_code | 股票代码 | 是 |
| stock_name | 股票名称 | 是 |
| market | 市场(A股/港股) | 是 |

## 数据来源规范

### 可信度评级

| 评级 | 来源 | 适用数据 |
|------|------|----------|
| A | 交易所、监管机构、公司公告 | 年报、季报、交易所行情 |
| B | Baostock、东方财富、同花顺 | 金融数据平台 |
| C | 雪球、东财股吧 | 情绪数据、估算 |
| D | DCF计算、内部假设 | 估值模型 |

### 数据质量评分

```
数据质量评分 = 完整性×30% + 一致性×30% + 时效性×20% + 可信度×20%
```

## 三、8维度评分体系（统一评分框架）

> **设计原则**: 将投行分析模块整合为第8维度，形成完整的8维度评分体系

### 3.1 权重设计依据

**初始权重设定方法**: 基于 `风险平价 + 因子重要性` 原则

| 维度 | 初始权重 | 设定依据 |
|------|----------|----------|
| 估值分析 | 20% | 价值投资核心,格雷厄姆/巴菲特体系核心因子 |
| 基本面分析 | 18% | 质量投资核心,ROE/ROIC是长期回报关键 |
| 技术面分析 | 15% | 择时辅助,但不宜权重过高(避免短期噪声) |
| 情绪分析 | 12% | 逆向投资参考,权重适中 |
| 宏观分析 | 8% | 自上而下辅助,行业龙头受宏观影响较小 |
| 行业分析 | 8% | 竞争格局/政策影响,对个股重要 |
| 风险评估 | 9% | 风险控制是长期投资关键 |
| 投行预期 | 10% | 整合分析师智慧,提供前瞻参考 |

**权重优化说明**:
- 初始权重基于经典投资理论设定
- 可通过回测验证IC(信息系数)来优化权重
- 不同市场/行业可能需要不同的权重调整
- 建议每季度复盘权重有效性

---

### 3.2 综合评分计算公式

```
综合评分 = 估值×20% + 基本面×18% + 技术×15% + 情绪×12% + 宏观×8% + 行业×8% + 风险×9% + 投行×10%
```

### 3.3 各维度评分详解

#### 3.3.1 估值分析 (Valuation) - 权重20%

**量化公式**:
```
估值得分 = PE分位×25% + PB分位×20% + PEG分×15% + 股息率分×15% + 安全边际分×25%

其中:
- PE分位分 = 100 - PE历史5年分位
- PB分位分 = 100 - PB历史5年分位
- PEG分 = min(100, (1/PEG)×50) if PEG>0 else 100
- 股息率分 = min(100, 当前股息率/行业均值×50)
- 安全边际分 = max(0, min(100, (内在价值-当前价)/内在价值×200))
```

**评分表格**:

| 评分项 | 数值 | 行业 | 趋势 | 评级 | 得分 |
|--------|------|------|------|------|------|
| PE历史分位 | {PE}x | {均值}x | - | {评级} | {分} |
| PB历史分位 | {PB}x | {均值}x | - | {评级} | {分} |
| PEG | {数值} | <1佳 | - | {评级} | {分} |
| 股息率 | {数值}% | {均值}% | - | {评级} | {分} |
| 安全边际 | {数值}% | >30%佳 | - | {评级} | {分} |
| **维度总分** | - | - | - | - | **{分}/100** |

#### 3.3.2 基本面分析 (Fundamental) - 权重18%

**量化公式**:
```
基本面得分 = ROE分×25% + ROIC分×20% + 营收增速分×20% + 净利增速分×20% + 现金流分×15%

其中:
- ROE分 = min(100, ROE/行业龙头ROE×100)
- ROIC分 = min(100, ROIC/行业龙头ROIC×100)
- 营收增速分 = min(100, 营收增速×3.33)
- 净利增速分 = min(100, 净利增速×3.33)
- 现金流分 = 100 if CFO/净利>1 else CFO/净利×100
```
