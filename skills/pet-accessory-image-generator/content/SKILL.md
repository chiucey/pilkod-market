# 宠物配饰图片批量生成器

根据描述信息批量生成写实风格、高清画质的宠物配饰图片。

## 核心能力

| 能力 | 说明 |
|------|------|
| 批量生成 | 支持从描述文件/表格中批量提取信息并生成多张图片 |
| 写实风格 | 生成逼真的产品效果图 |
| 高清画质 | 输出高质量图片 (1K/2K/4K) |
| 固定比例 | 支持 1:1 等多种比例 |
| 宠物佩戴 | 可生成宠物佩戴配饰的场景图 |
| 重新生成 | 支持根据反馈修改后重新生成指定图片 |

## 工作流程

### 阶段 1：理解需求

**读取描述文件**
- 分析用户提供的描述文件（表格、图片等）
- 提取每个配饰的关键信息：名称、设计灵感、材质、形状、颜色、风格
- 识别图片数量和生成顺序

**识别关键元素**
```
每条描述需包含：
├── 产品名称
├── 设计灵感（城市/文化元素）
├── 材质特征
├── 视觉特征
├── 宠物佩戴场景（可选）
└── 风格要求（写实/卡通等）
```

### 阶段 2：生成策略

**单张生成**：单条描述 → 直接生成
**批量生成**：多条描述 → 并行处理 → 统一输出

**图片类型决策**：
| 描述类型 | 生成策略 |
|----------|----------|
| 仅有配饰描述 | 生成产品白底图 |
| 包含"宠物佩戴" | 生成宠物佩戴效果图 |
| 有参考图片 | 基于参考图片风格生成 |

### 阶段 3：执行生成

**使用 `image_synthesize` 工具**

批量请求格式：
```json
{
  "requests": [
    {
      "prompt": "详细的产品描述",
      "output_file": "输出路径",
      "aspect_ratio": "1:1",
      "resolution": "2K"
    }
  ]
}
```

**生成参数规范**：
| 参数 | 值 | 说明 |
|------|-----|------|
| `aspect_ratio` | `1:1` | 固定比例 |
| `resolution` | `2K` | 高清画质 |
| `style` | `photorealistic` | 写实风格 |

### 阶段 4：输出管理

**保存位置**：`/workspace/imgs/`

**命名规范**：
```
{序号}_{产品名称}.png
示例：01_swan_headband.png, 02_pirate_bandana.png
```

**交付格式**：
- 输出图片路径列表
- 每张图片附带简短描述
- 使用 `<deliver_assets>` 组件呈现

### 常见问题处理

| 问题 | 解决方案 |
|------|----------|
| 描述不完整 | 询问用户补充关键信息（材质、颜色、风格） |
| 图片效果不佳 | 调整描述措辞，强调关键特征 |
| 批量生成失败 | 逐个重试，定位问题描述 |
| 用户不满意 | 提取具体反馈点，重新生成 |

## 输出标准

**图片质量检查**：
- [ ] 分辨率达标
- [ ] 比例正确 (1:1)
- [ ] 主体清晰可见
- [ ] 宠物佩戴自然（如适用）

**交付物**：
- 图片文件列表
- 每张图片的URL或路径
- 简短的效果描述
