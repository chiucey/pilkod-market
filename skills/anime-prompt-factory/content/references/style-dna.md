# 风格 DNA 词库

> 12个动漫工作室/游戏IP的关键词配方。可叠加使用，但建议单次最多2个工作室风格。

---

## 日本动画工作室

### 1. 京都动画 (Kyoto Animation / 京阿尼)

**视觉DNA**：柔光质感 + 细腻情感表达 + 日常系光影 + 略微过曝的高光

**关键词配方**：
```
Kyoto Animation style, soft shading, warm natural lighting,
gentle light rays through windows, soft highlights on hair,
emotional scene, everyday life atmosphere, slight overexposure,
smooth color gradients, watercolor-like background,
expressive eyes, clean lineart
```

**适合场景**：日常治愈、校园恋爱、轻百合、青春成长

---

### 2. 新海诚 (Makoto Shinkai)

**视觉DNA**：写实级风景 + 空灵氛围 + 天空/云/光晕 + 油画感色彩

**关键词配方**：
```
Makoto Shinkai style, cinematic sky, clouds, golden hour lighting,
dramatic sunset, sun rays, ethereal atmosphere, photorealistic background,
oil painting texture, vivid colors, dust particles in light,
romantic mood, detailed city lights, reflections on water
```

**适合场景**：爱情电影感、风景空镜头、离别/重逢情绪

---

### 3. 扳机社 (TRIGGER)

**视觉DNA**：高饱和度 + 锐利线条 + 战斗动感 + 赛博朋克元素

**关键词配方**：
```
TRIGGER style, vibrant saturated colors, sharp lineart,
dynamic action pose, mecha elements, cyberpunk aesthetic,
neon highlights, bold composition, intense motion lines,
anime screenshot, Kill la Kill, Darling in the Franxx style
```

**适合场景**：战斗高燃、机甲/科幻、热血番、偶像

---

### 4. 骨头社 (BONES)

**视觉DNA**：电影级构图 + 写实光影 + 复杂机械 + 成熟角色设计

**关键词配方**：
```
BONES style, cinematic composition, realistic lighting,
Fullmetal Alchemist style, My Hero Academia character design,
mechanical details, full metal armor, dynamic perspective,
mature character design, detailed background art
```

**适合场景**：热血战斗、SF机械、成熟向作品

---

### 5. PA Works

**视觉DNA**：风景写实 + 自然光 + 写真级背景 + 细腻空气感

## 通用风格叠加指南

### 允许叠加组合（推荐）

| 组合 | 效果 |
|------|------|
| 京阿尼 + 新海诚 | 日常电影感，最安全的组合 |
| BA + 原神 | 学院+武侠混搭 |
| WIT + 白狐社 | 史诗+梦幻 |
| 骨头社 + 疯房 | 成熟向战斗 |

### 禁止叠加组合

- 暗调（明日方舟/疯房）+ 萌系（赛马娘/BA）→ 风格打架
- 超过3个工作室 → 必然漂移

### 按场景推荐风格

| 场景 | 推荐工作室 | 备选 |
|------|-----------|------|
| 头像 | 京阿尼/BA/白狐 | 原神/赛马娘 |
| 战斗CG | 扳机社/骨头社/WIT | 明日方舟 |
| 日常治愈 | 京阿尼/PA Works | 新海诚 |
| 电影感海报 | 新海诚/WIT | 骨头社 |
| 角色卡 | 原神/明日方舟 | BA/疯房 |
