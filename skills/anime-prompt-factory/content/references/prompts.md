# 28套核心Prompt模板

> 所有模板均为 Meta-Prompt 结构：用户填入变量 → AI生成精修Prompt → 喂给图像模型

## 一、真人动漫化（5套）

### P01 · 一键日漫化

**适用场景**：上传照片，保留五官转换为日漫风格

**Prompt模板**：
```
你是一位精通日系动漫角色设计与图像 prompt 工程的视觉总监。我将给你一张人物照片的描述，请按以下结构帮我生成一段可直接用于 [IMAGE_MODEL] 的 prompt，把这个人转换为 [ANIME_STYLE] 风格，同时保留其面部识别特征。

转换的核心约束：
1. 必须保留：[FACE_FEATURES_TO_PRESERVE]
2. 性格调性：[CHARACTER_MOOD]
3. 服装：[OUTFIT_STYLE]
4. 背景氛围：[BACKGROUND_VIBE]
5. 光照：[LIGHTING_STYLE]
6. 构图：[FRAMING]

请输出三段 prompt：
A. 主 prompt（含 quality 词、风格词、特征保留词、场景词）
B. negative prompt（去除常见的脸型崩坏、风格漂移问题）
C. 参数建议（aspect ratio、stylize、weight 等）

最后再给我一句中文话术，帮我向不懂 prompt 的朋友解释这张图为什么是这个调子。
```

**变量定义**：
| 变量 | 说明 | 示例 |
|------|------|------|
| IMAGE_MODEL | 目标模型 | Midjourney v6 / NovelAI v3 / Niji 6 |
| ANIME_STYLE | 目标风格 | 京阿尼日常系/新海诚电影感/蔚蓝档案/原神璃月 |
| FACE_FEATURES_TO_PRESERVE | 五官特征 | 单眼皮、高鼻梁、左眼下有痣 |
| CHARACTER_MOOD | 性格调性 | 元气活泼/清冷高傲/温柔治愈/暗黑反派 |
| OUTFIT_STYLE | 服装风格 | JK制服/古风襦裙/校园便服/战斗装 |
| BACKGROUND_VIBE | 背景氛围 | 樱花校园放学/海边夕阳/都市夜景霓虹 |
| LIGHTING_STYLE | 光照 | 黄金时刻逆光/室内暖光/月光冷调 |
| FRAMING | 构图 | 胸像中景/半身正面/全身斜45度 |

## 通用负面Prompt模板

```
generic anime face, identity drift, blurry features, deformed eyes,
watermark, low quality, bad anatomy, extra limbs, poorly drawn face,
asymmetrical eyes, mutated hands, text, logo, signature
```

**按需追加**：
- 总是被画成猫耳：`cat ears, animal ears, no animal features`
- 服装总是不对：`wrong costume, inaccurate clothing, missing details`
- 背景太乱：`cluttered background, busy background, distracting elements`
