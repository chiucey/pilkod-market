# 萝卜看票 - 量化信号扫描器

多维度共振选股系统，数据源为腾讯财经API。

## 核心模块

| 模块 | 功能 | 权重 |
|------|------|------|
| ① 均线+MACD | 多头粘合、庄股、出击、突破信号 | 30分 |
| ② 价格通道 | LLV/HHV趋势判断、动力线 | 15分 |
| ③ 超买超卖 | RSI三周期(9/14/34) | 10分 |
| ④ 动量振荡 | GUP1-GUP4多重平滑 | 10分 |
| ⑤ 量价关系 | 资金流、量比、背离检测 | 15分 |
| ⑥ 形态识别 | 金牛暴起、妖股检测 | 10分 |
| ⑦ 多时间框架 | MA5/13/34/75/200共振 | 10分 |
| ⑧ 信号过滤 | 去重+共振确认 | - |

## 信号类型

### 买入信号
- **出击** 🟢：目标确认后MACD金叉
- **突破** 🔵：粘合+MA65向上+收盘突破TPX
- **金牛暴起** 🐂：连续阳线+涨幅>3%+放量1.5x+突破20日高点

### 风险信号
- **妖股** 👻：近10日波动率>8%+多次涨跌幅>5%
- **顶背离**：价涨量缩，可能见顶
- **RSI>80**：超买风险

## 共振评分

| 评分 | 含义 | 操作建议 |
|------|------|----------|
| ≥80 | 强烈共振 | 果断买入 |
| ≥60 | 较强共振 | 积极关注 |
| ≥40 | 中等共振 | 轻仓试探 |
| <40 | 弱/无共振 | 继续观望 |

## 使用方法

```bash
# 入口脚本
bash skills/luobo-kan-piao/run.sh <股票代码>           # 简洁分析
bash skills/luobo-kan-piao/run.sh --verbose <代码>     # 详细分析
bash skills/luobo-kan-piao/run.sh --score <代码>       # 仅共振评分
bash skills/luobo-kan-piao/run.sh --json <代码>        # JSON输出

# 示例
bash skills/luobo-kan-piao/run.sh 601231
bash skills/luobo-kan-piao/run.sh --verbose 300657
bash skills/luobo-kan-piao/run.sh 601231 600519 000858  # 批量
```
