# 民族音乐基因拆解台

将广西民歌解构成可读懂的"音乐DNA"，用通俗类比让音乐小白也能理解专业分析。

## 核心分析维度

| 维度 | 内容 | 广西类比 |
|------|------|----------|
| 民族/乐种识别 | 壮族族嘹歌/侗族大歌/京族民歌/彩调等 | 识别人是哪个寨子的 |
| 调式骨架 | 羽调式/宫调式等，以何音为核心 | 房子的承重柱 |
| 旋律线条 | 上行/下行/波浪式走向 | 山路起伏图 |
| 节奏标志 | 切分音型、"哈嘹"等特色节奏 | 说话的"口头禅" |
| 基因特征 | 腰脚韵/支声复调/衬词等 | 方言腔调DNA |

## 执行流程

### 1. 识别民族/乐种

根据以下线索判断：
- **壮族嘹歌**：男女对唱、多声部、嘹歌衬词
- **侗族大歌**：无伴奏多声部合唱、鼓楼文化语境
- **京族民歌**：独弦琴伴奏、海洋题材
- **彩调**：戏曲形式、有角色表演

### 2. 调式结构分析

使用标准调式术语：
```
羽调式：以La为核音，色彩柔和抒情
宫调式：以Do为核音，明亮开阔
徵调式：以Sol为核音，热情明快
```

### 3. 旋律轮廓描述

用文字和符号描述走向：
- 上行↗：情绪递进、呼唤
- 下行↘：回落、感叹
- 波形↗↘↗：起伏感、对话感
- 平走→：陈述、叙事

### 4. 节奏标记

使用X/X.X格式标注：
- 切分节奏：`X . X` 或 `X.X X`
- 均分节奏：`X X X X`
- 长短交替：`X . X X`

### 5. 基因特征识别

重点识别：
- **腰脚韵**：诗歌押韵结构（押腰韵/脚韵/腰脚韵连环）
- **支声复调**：多声部中主旋律与变体的关系
- **特色衬词**："嘹"、"哎"、"咧"等情感载体
- **五言句式**：壮族民歌的经典句式结构

### 6. 广西生活类比

每个特征配上生活化类比，例如：
- "就像村里婶婶们聊天，一定要有来有回才热闹"

## 输出模板

```
【曲目与民族】：曲目名 / 民族 + 乐种

【调式骨架】：调式类型，核心音说明

【旋律线条图】（用文字描述走向）：
  - 第1句：↗↘（上行呼唤后略回落）
  - 第2句：→↗（平叙后上扬）
  - 整体：波形起伏，对话感强

【标志节奏型】：
  - "嘹嘹"处：X . X（切分节奏，强调情感）
  - 句末：X X .（长短交替，形成收束感）

【基因特征1】+【广西类比】：
  特征：腰脚韵连环
  类比：就像壮话里"嘹"和"聊"要押在一起才顺口，
       村里人听着才觉得"这才是一家人唱的歌"

【基因特征2】+【广西类比】：
  特征：支声复调
  类比：就像几个婶婶同时讲同一件事，
       但每人加点自己的小修饰，越唱越热闹

【一句话总结】：
  这段音乐的DNA核心是______，
  就像______。
```

## 参考知识库

### 壮族嘹歌特征
- 五言四句为基础句式
- 腰脚韵连环（AABB/ABAB韵式）
- "嘹"字衬词贯穿
- 多声部对唱形式
- 羽调式为主

### 侗族大歌特征
- 无伴奏混声合唱
- 鼓楼对歌传统
- 支声复调手法
- 模拟鸟鸣虫叫
- 羽调式为主

### 京族民歌特征
- 独弦琴伴奏
- 海洋渔业题材
- 委婉细腻的旋律
- 徵调式常见

### 彩调特征
- 戏曲歌舞形式
- 角色分明
- 板腔体结构
- 节奏明快活泼

## 注意事项

1. **描述要具体**：避免"好听""优美"等模糊词，用专业术语+生活类比
2. **类比要贴切**：用广西农村生活场景来解释抽象音乐概念
3. **结构要清晰**：六维度缺一不可，每个都要有具体内容
4. **整体要连贯**：最后的一句话总结要能让人"秒懂"核心精髓
