# 热门板块追踪器

识别当前全球热门板块炒作题材，实时分析板块热度并提供对应基金推荐。

## 数据来源

使用 `batch_web_search` 工具搜索以下信息：
- A股热门板块排行
- 概念炒作题材
- 资金流向数据
- 场内外基金信息

## 执行流程

### 步骤1：搜索热门板块数据

使用 `batch_web_search` 搜索最新板块热点：

```
queries: [
  {"num_results": 10, "query": "A股今日热门板块排行 资金流向 2024"},
  {"num_results": 10, "query": "热门概念板块 龙头股 涨停板 今日"},
  {"num_results": 10, "query": "主力资金流入板块排行 概念题材炒作"}
]
```

### 步骤2：搜索基金数据

对热门板块搜索对应的ETF和场外基金：

```
queries: [
  {"num_results": 5, "query": "[板块名] ETF 场内基金 代码"},
  {"num_results": 5, "query": "[板块名] 场外基金 主动基金 推荐"}
]
```

### 步骤3：提取并整理数据

使用 `extract_content_from_websites` 从权威财经网站提取：
- 板块名称
- 涨幅/热度指数
- 资金净流入
- 相关基金代码和名称

### 步骤4：生成排行报告

输出格式化的板块热度排行，包含：
1. 板块排名（1-10）
2. 板块名称
3. 热度指数/涨幅
4. 资金净流入
5. 场内基金（ETF代码）
6. 场外基金推荐

```markdown
# 全球热门板块日报

**更新时间**: [时间戳]

|------|----------|----------|--------|----------------|----------|----------|
| 1    | XXX板块  | ★★★★★   | +X.X%  | XX             | 512XXXX  | 00XXXXX  |
...（共10条）

## 投资风险提示
⚠️ 以上内容仅供参考，不构成投资建议。热点板块波动较大，请谨慎决策。
```

## 注意事项

- 优先选择权威财经网站数据源
- 基金数据需核实最新净值和规模
- 提醒用户关注流动性风险
- 区分场内ETF和场外主动基金的风险特征
