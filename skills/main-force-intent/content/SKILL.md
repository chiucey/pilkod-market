# 主力意图识别（Delta P 模型）

## 一、技能概述

本技能基于市场冲击力模型（Delta P），通过分析Level-2逐笔成交数据，识别A股市场主力资金的意图行为，输出意图标签、置信度评分和风险提示。

**适用范围**：A股（主板/创业板/科创板）
**时间窗口**：短期（1-5日）、中期（5-20日）

## 二、核心算法

### 2.1 市场冲击力公式

```
ΔP = γ × ρ × √(Q/V)
```

| 参数 | 含义 |
|------|------|
| ΔP | 价格冲击强度 |
| γ | 动态阈值系数（市值+波动率+流动性调整） |
| ρ | 方向系数（买入=1，卖出=-1） |
| Q | 成交量 |
| V | 流通盘 |

### 2.2 Gamma 系数动态计算

基础值 γ = 0.75，根据三维度调整：

| 市值区间 | 调整系数 |
|----------|----------|
| <50亿（小盘） | ×1.15 |
| 50-200亿（中盘） | ×1.0 |
| >200亿（大盘） | ×0.85 |

| 波动率 | 调整系数 |
|--------|----------|
| 高波动期 | ×(1 + (波动率-0.25)×0.5)，上限1.3 |
| 低波动期 | 下限0.7 |

| 板块流动性 | 调整系数 |
|------------|----------|
| 低流动性 | ×1.1 |
| 高流动性 | ×0.9 |

### 2.3 场景化阈值设定策略

根据分析目标动态选择基础阈值 γ：

| 分析场景 | 建议阈值 | 适用情况 | 典型特征 |
|----------|----------|----------|----------|
| 建仓/洗盘识别 | γ ≈ 0.5 | 观察主力吸筹或清洗浮筹阶段 | 大单间歇性流入，价格震荡或缓跌 |
| 常规大单分析 | γ ≈ 0.7-0.8 | 一般性主力资金行为识别（A股默认值） | 中等规模资金持续进出 |
| 超大单/机构行为 | γ ≈ 0.9 | 识别机构级别大额交易 | 单笔金额巨大，对价格产生明显冲击 |

**阈值选择原则**：
- 市值越大、流动性越好，阈值可适当上调
- 波动率越高，阈值需相应提高以过滤噪音
- 多阈值对比分析：同一标的分别用0.5和0.8计算，对比资金流向差异

### 2.4 资金影响阈值速算

基于公式 `影响资金 ≈ γ × √市值`，快速估算不同市值标的的主力资金影响门槛：

| 市值规模 | 理论影响资金（γ=0.75） | 实际观察阈值 | 说明 |
|----------|------------------------|--------------|------|
| 30亿（小盘） | 4.1亿 | 3-5亿 | 小盘股易被操纵，需结合换手率验证 |
| 50亿 | 5.3亿 | 4-7亿 | 中小盘活跃股典型阈值 |
| 100亿 | 7.5亿 | 6-10亿 | 中盘股主力运作常见规模 |
| 200亿 | 10.6亿 | 8-12亿 | 大盘股需更大资金才能影响 |
| 500亿 | 16.8亿 | 12-20亿 | 机构重仓股，门槛较高 |

**速算口诀**：100亿市值约需10亿资金可产生影响（√100=10），其他规模按比例推算。

### 2.5 资金流向分级

| 单量级别 | 金额标准 | 行为含义 |
|----------|----------|----------|
| 大单 | >100万元 | 机构/主力级别交易，决定价格方向 |
| 中单 | 10万-100万元 | 中户/游资交易，反映市场情绪 |
| 小单 | <10万元 | 散户交易，常作为反向指标 |

## 三、意图识别规则

### 3.1 建仓（吸筹）

**核心条件**（需同时满足）：
- 大单净流入 > 5000万
- Q/V ∈ [0.3, 0.8]
- 价格振幅 < 5%
- γ系数低于历史均值

**行为特征描述**：
- **大单特征**：持续大单买入、小单零星卖出，呈现"大单主导、小单跟随"格局
- **资金节奏**：大单净流入呈现"间歇性脉冲"特征，非持续涌入，避免引起市场注意
- **价格表现**：价格窄幅震荡或缓慢爬升，不出现明显拉升

**辅助验证**：龙虎榜机构买入、融资余额增加、北向资金流入

**阈值建议**：使用 γ ≈ 0.5 更易捕捉建仓期的大单异动

### 3.2 洗盘

**核心条件**：
- 价格急跌 > 3%
- 小单净流出 > 大单净流出
- 大单间歇性承接（非持续）
- 成交量放大但ΔP被压制

**行为特征描述**：
- **大单特征**："大单承接托底、小单恐慌出逃"，大单在关键价位护盘
- **资金节奏**：价格下跌时大单净流出收窄或转正，显示主力未离场
- **价格表现**：急跌后快速企稳，或呈现"主力买单与价格下跌并存"的背离现象

**辅助验证**：筹码集中度变化、股东户数减少、大宗交易溢价

**阈值建议**：使用 γ ≈ 0.5 观察洗盘期的大单承接力度；对比0.5和0.8阈值下的资金流向差异，若0.5阈值显示大单流入而0.8阈值显示中性，则洗盘信号更明确

### 3.3 拉升

**核心条件**：
- 大单突破买入
- Q/V > 0.8
- 量价齐升（量增价涨）
- γ跳升（流动性消耗）

**辅助验证**：板块共振、消息面配合、技术位突破

### 3.4 出货

**核心条件**：
- 大单伪装买入（托单）
- 小单持续净流出
- 量价背离（价平量缩或价涨量缩）
- 换手率异常但价格滞涨

**辅助验证**：龙虎榜机构卖出、融资余额减少、大宗交易折价

### 3.5 对倒

**核心条件**：
- 买卖大单金额接近（差额 < 10%）
- 换手率骤升但价格无方向
- 多账户交易时间聚集
- 无基本面/消息面驱动

**辅助验证**：龙虎榜无机构、股东户数异常、历史对倒记录

## 四、置信度评分体系

| 置信度区间 | 含义 | 操作建议 |
|------------|------|----------|
| 90-100 | 极高确定性 | 可作为核心决策依据，设止损 |
| 70-89 | 高确定性 | 重要参考，结合基本面 |
| 50-69 | 中等确定性 | 观察参考，等待信号强化 |
| 30-49 | 低确定性 | 建议忽略或反向验证 |
| 0-29 | 极低确定性 | 信号无效，不采取行动 |

## 五、风险控制机制

### 5.1 模型自动降级

| 触发场景 | 条件 | 置信度惩罚 |
|----------|------|------------|
| 涨跌停 | 价格触及涨跌停 | -50 |
| 业绩公告 | EPS超预期>30% | -30 |
| 板块危机 | 板块跌幅>5% | -25 |
| 成交异常 | 换手率>20日均值的3倍 | -20 |
| 小盘操纵 | 市值<30亿且换手>15% | -35 |

### 5.2 失效场景

- 涨跌停时Q/V与ΔP关系断裂
- 业绩公告导致基本面冲击主导
- 系统性风险淹没个股α
- 小盘股高换手易被操纵

## 七、使用流程

1. **数据获取**：收集Level-2逐笔成交、分时成交、流通盘、历史波动率、板块指数
2. **Delta P计算**：计算冲击强度和资金流向分解
3. **模式识别**：匹配意图特征模式
4. **置信度评估**：综合信号一致性评分
5. **风险检查**：触发降级机制时调整置信度
6. **输出结果**：生成结构化分析报告

### 8.1 洗盘案例：双液压

**案例背景**：
- 标的：双液压（液压设备板块）
- 阶段：下跌调整过程中
- 分析日期：2024年X月X日

**信号识别**：
- **价格表现**：股价下跌过程中
- **资金流向（γ=0.5）**：大单持续买入承接，小单恐慌卖出
- **核心特征**：符合"大单承接托底、小单恐慌出逃"的洗盘特征

**分析结论**：
- 主力未离场，下跌为良性调整
- 后续关注主力承接力度是否持续

### 8.6 案例分析方法论

**标准分析流程**：

1. **初筛（γ=0.8）**
   - 识别明显的大单异动
   - 过滤掉噪音交易

2. **细查（γ=0.5）**
   - 观察隐性主力行为
   - 捕捉建仓/洗盘期的微妙信号

3. **对比验证**
   - 对比0.5和0.8阈值下的资金流向
   - 若0.5显示流入而0.8显示中性→隐性吸筹信号
   - 若两者均显示流入→明显主力介入

4. **结合价格**
   - 价格下跌+0.5阈值大单流入→洗盘/建仓
   - 价格上涨+双阈值均流入→拉升确认

## 九、重要声明

⚠️ **风险提示**：
- 本模型仅识别"异常交易行为"，不保证意图判断准确
- 主力可能反向利用模型逻辑进行伪装
- 所有信号需配合基本面分析使用
- 历史回测胜率约58-65%，存在显著回撤风险
- 禁止单独作为投资依据
