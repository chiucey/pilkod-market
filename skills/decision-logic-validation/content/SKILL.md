# 产品决策逻辑校验与风险前置识别技能

## 技能定义

在产品决策执行前，系统性校验决策逻辑的完整性和合理性，识别潜在的逻辑漏洞和风险点，提前制定应对方案，确保决策质量。

## 核心SOP

### 步骤1：决策前提验证

| 检查项 | 验证方法 | 绿灯标准 |
|--------|---------|---------|
| 数据真实性 | 交叉验证、多源对比 | 有2+个数据源支撑 |
| 假设合理性 | 反例思考、专家评审 | 假设有明确依据 |
| 边界条件 | 极端情况测试 | 已定义清晰边界 |
| 时效性 | 发布时间对照 | 数据在有效期内 |

### 步骤2：逻辑链条检验

```
决策结论 → 支撑论点 → 论据基础
    ↓            ↓            ↓
[最终决策] → [为什么这样做] → [数据/事实支撑]
```

**检验问题**：
- 论点之间是否相互独立？
- 是否存在循环论证？
- 是否有未考虑的反驳观点？
- 因果关系是否成立？
