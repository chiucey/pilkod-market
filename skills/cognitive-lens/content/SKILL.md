# CognitiveLens - 深度认知框架工具

## 核心能力

### 1. SCQA 模型分析
- **Situation（情境）**：识别文章背景和环境
- **Complication（冲突）**：发现核心矛盾和张力点
- **Question（问题）**：提炼关键研究问题
- **Answer（答案）**：总结作者论点和解决方案

### 2. 5W2H 全维度分析
- **What**：核心概念和定义
- **Why**：原因和动机分析
- **Who**：相关主体识别
- **When**：时间维度
- **Where**：空间维度
- **How**：方法路径
- **How Much**：量化数据

### 3. 第一性原理分析
- 追溯根本假设层级
- 识别核心前提
- 思维重构建议

### 4. 六顶思考帽分析
| 帽子 | 视角 | 分析内容 |
|------|------|---------|
| 白帽 | 事实与信息 | 数据、证据、客观信息 |
| 红帽 | 情感与直觉 | 感受、情绪反应 |
| 黑帽 | 批判与风险 | 逻辑漏洞、潜在问题 |
| 黄帽 | 乐观与价值 | 优势、机遇、收益 |
| 绿帽 | 创意与可能 | 创新点、替代方案 |
| 蓝帽 | 管控与总结 | 整体框架、行动建议 |

### 5. 批判性分析
- 识别逻辑谬误（滑坡谬误、虚假二分法、循环论证等）
- 评估证据质量和论证充分性
- 发现认知偏差和预设前提
- 生成论证强度评分

### 6. 洞见提炼与实践转化
- 提取核心洞察（置信度评级）
- 生成可操作建议（优先级排序）
- 构建知识图谱

## 输出格式

分析完成后输出结构化报告，包含：

1. **SCQA 脉络图**：完整的问题-答案链条
2. **5W2H 矩阵**：七维度关键信息表
3. **假设层级图**：从表层到根本的假设树
4. **六维视角分析**：多角度审视结论
5. **批判性评分**：论证质量、逻辑漏洞、证据强度
6. **核心洞察**：带置信度的主张列表
7. **可行动建议**：分优先级的实践路径
8. **知识图谱**：概念关系可视化

## 最佳使用场景

- 学术论文深度解读和逻辑分析
- 复杂商业报告的战略洞察提取
- 行业白皮书的多维分析
- 技术文档的系统梳理
- 长篇演讲或访谈内容的核心观点提炼
- 需要超越简单信息提取的深度思考任务

## 使用方式

用户提供需要分析的内容文本，选择所需的思维框架组合，系统将：
1. 解析内容结构和关键要素
2. 按选择的框架逐个执行分析
3. 整合各框架结果生成综合报告
4. 输出结构化洞察和可操作建议
