# 每日打卡记录系统

## 记录文件结构

每日记录存储于 `memory/fitness-logs/YYYY-MM-DD.md`，格式如下：

```markdown
# 每日健身打卡 — YYYY-MM-DD（周X）

## 晨间数据
- 起床时间：
- 体重：kg（与昨日相比：+/- kg）
- 体脂率：%（如有测量）
- 主观疲劳感（1-10）：（1=神清气爽，10=极度疲惫）
- 睡眠质量（1-10）：

## 饮食记录
- 早餐： kcal | P: g | C: g | F: g
- 午餐： kcal | P: g | C: g | F: g
- 晚餐： kcal | P: g | C: g | F: g
- 加餐/零食： kcal
- **今日总摄入：约 kcal**（目标： kcal，偏差：+/- kcal）
- 饮水量：ml
- 补剂服用：（如蛋白粉、鱼油、维生素等）

## 训练记录
- 今日训练：✅ 完成 / ❌ 未完成 / ⏸️ 部分完成
- 训练类型：（力量-推类 / 力量-拉类 / 力量-下肢 / 力量-全身 / 有氧 / HIIT / 休息）
- 训练时长：分钟
- 训练感受（1-10）：
- 完成度：（全部完成 / 部分动作跳过）
- 备注：（新尝试、关节不适、突破重量等）

## 女性生理周期（如适用）
- 今日处于：D1-D5月经期 / D6-D14卵泡期 / D15-D28黄体期
- 今日身体状态：（正常 / 轻微不适 / 明显不适）
- 经期不适症状：（痛经/腹胀/情绪波动/无）

## 晚间总结
- 今日整体表现（1-10）：
- 主要收获/感想：
- 明日改进重点：
- 是否服用药物/保健品：
```

## 每周总结计算公式

每周日自动汇总，输出：

```
📊 第X周总结（MM/DD - MM/DD）

【体重变化】
起始体重：kg → 今日体重：kg
本周净变化：+/- kg（较上周：+/- kg）

【训练完成率】
本周计划训练：X次 | 实际完成：X次（X%）
累计训练时长：X分钟

【饮食遵从度】
平均每日摄入：约 X kcal（目标：X kcal）
偏差：+/- X%

【身体状态趋势】
疲劳感均值：X/10
最佳状态日：周X（记录亮点）
需关注日：周X（记录问题）

【下周调整建议】
- 训练：
- 饮食：
- 恢复：
```

## 重要指标趋势追踪

每30天汇总一次，存储于 `memory/fitness-logs/monthly-summary.md`：

```
# X月身体数据月报

记录周期：YYYY-MM-01 至 YYYY-MM-31

【体重走势】
月最高：Xkg | 月最低：Xkg | 月末：Xkg
月净变化：+/- Xkg

【训练总量】
总训练次数：X次
总训练时长：约X小时
最常训练类型：推类（X次）/ 拉类（X次）/ 下肢（X次）

【饮食月均】
月均每日摄入：约 X kcal

【里程碑事件】
- 第一次完成XX重量
- 连续训练X天（最佳记录）
- 达成目标体重：XX kg
```
