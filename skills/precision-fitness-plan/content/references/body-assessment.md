# 身体数据评估与计算公式

## 基础数据计算

### 去脂体重（LBM）
```
去脂体重 = 体重(kg) × (1 - 体脂率 / 100)
```

### 体脂重量
```
体脂重量 = 体重(kg) × 体脂率 / 100
```

### 瘦体重（Lean Body Mass）
瘦体重 ≈ 骨骼肌重量 + 内脏器官 + 其他非脂组织，通常≈去脂体重。
```
瘦体重 ≈ 去脂体重（误差约0.5-1kg）
```

### BMI
```
BMI = 体重(kg) / 身高(m)²
```
参考范围：18.5-23.9正常，24-27.9超重，≥28肥胖

---

## 基础代谢率（BMR）

**Mifflin-St Jeor 公式（最推荐）：**

男性：
```
BMR = 10 × 体重(kg) + 6.25 × 身高(cm) - 5 × 年龄 + 5
```

女性：
```
BMR = 10 × 体重(kg) + 6.25 × 身高(cm) - 5 × 年龄 - 161
```

**Katch-McArdle 公式（适用于已知体脂率者，更精准）：**
```
BMR = 370 + 21.6 × 瘦体重(kg)
```

---

## 每日总消耗（TDEE）

```
TDEE = BMR × 活动系数
```

| 活动水平 | 描述 | 系数 |
|---------|------|------|
| 久坐 | 几乎不运动 | 1.2 |
| 轻度活跃 | 每周1-3次轻度运动 | 1.375 |
| 中度活跃 | 每周3-5次中等强度运动 | 1.55 |
| 高度活跃 | 每周6-7次较高强度运动 | 1.725 |
| 极端活跃 | 运动员/体力劳动 | 1.9 |

---

## 热量目标计算

### 减脂热量目标
```
目标热量 = TDEE - 每日热量缺口
```

缺口幅度选择：
- 激进（快速减脂）：缺口 600-750 kcal/天 → 每周减约0.5-0.75kg（主要来自脂肪）
- 标准（平衡型）：缺口 300-500 kcal/天 → 每周减约0.3-0.5kg
- 保守（长期型）：缺口 150-250 kcal/天 → 每周减约0.1-0.25kg

**安全下限：**
- 女性：不低于 1400 kcal/天
- 男性：不低于 1800 kcal/天
- 低于下限会显著降低基础代谢，得不偿失

### 增肌热量目标
```
目标热量 = TDEE + 每日热量盈余 250-500 kcal
```
注：新人为减脂增肌并行，可在TDEE±100kcal范围内（"身体重组"）

---

## 目标评估

### 减脂可行速度估算
```
每周可减体脂量 ≈ 每日热量缺口(kcal) / 7700(kcal/kg)
```
注：1kg脂肪 ≈ 7700kcal，实际减脂时体重下降包含肌肉和水分，目标为保肌减脂。

### 增肌可行速度估算
```
自然训练者每月可增肌肉量：
- 新手福利期：0.5-1kg/月
- 中级训练者：0.25-0.5kg/月
- 高级训练者：0.1-0.25kg/月
```

### 骨骼肌目标差距分析
```
当前骨骼肌 - 目标骨骼肌 = 需增加量
结合训练年限，评估达成周期现实性
```
