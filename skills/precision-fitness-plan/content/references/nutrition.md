# 精准营养素分配指南

## 宏量营养素计算

### 蛋白质

**蛋白质需求（g/kg 体重/天）：**

| 目标 | 蛋白质需求 | 说明 |
|------|----------|------|
| 久坐维持 | 1.0-1.2 | 普通健康维持 |
| 减脂保肌 | 2.0-2.4 | 高蛋白保护肌肉 |
| 增肌（自然） | 1.8-2.2 | 支持肌肉蛋白合成 |
| 减脂增肌并行 | 2.2-2.6 | 最大肌肉保护 |
| 极限减脂（备赛） | 2.4-3.0 | 极低热量时维持肌肉 |
| 老人/肌肉少 | 2.0-2.5 | 预防肌肉减少 |

**蛋白质热量换算：** 1g蛋白质 = 4 kcal

**建议蛋白质来源（优质蛋白优先）：**
- 动物：鸡胸肉、牛肉、鱼虾、鸡蛋、奶制品
- 植物：豆腐、纳豆、毛豆、藜麦、鹰嘴豆

---

### 碳水化合物

**碳水需求（g/kg 体重/天）：**

| 场景 | 碳水需求 | 适用人群 |
|------|---------|---------|
| 低碳（减脂期） | 2.0-3.0 | 黄体期、胰岛素抵抗者 |
| 中碳（标准） | 3.0-4.5 | 大多数人日常 |
| 高碳（增肌/训练日） | 4.0-6.0 | 力量训练后、高活动量 |
| 极低炭（生酮） | < 0.5 | 特殊需求（医疗监测下） |

**碳水热量换算：** 1g碳水 = 4 kcal

**碳水周期化策略（针对女性）：**
- 训练日：碳水调高（4-6g/kg）→ 提升训练表现
- 休息日：碳水下调（2-3g/kg）→ 配合减脂

---

### 脂肪

**脂肪需求：** 0.8-1.2 g/kg 体重/天
- 最低不应低于 0.5 g/kg（影响激素合成）
- 饱和脂肪不超过总热量 10%
- Ω-3 脂肪酸（深海鱼、亚麻籽油）每日摄入

**脂肪热量换算：** 1g脂肪 = 9 kcal

**每日总热量校验：**
```
蛋白质热量 + 碳水热量 + 脂肪热量 ≈ 目标总热量
±50kcal误差可接受
```

## 分餐建议

### 训练日（力量训练当天）
```
训练前 1.5-2h：中等碳水 + 中等蛋白（100-150g碳水 + 20-30g蛋白）
训练后即刻：快碳 + 蛋白质（精制碳水+乳清蛋白，比例 3:1）
正餐：均衡三大营养素
睡前：慢蛋白 + 少量脂肪（防肌肉分解，如鸡胸肉+坚果）
```

### 非训练日
```
早餐：碳水可略高（启动代谢），搭配蛋白质
午/晚餐：均衡，碳水略低
睡前：高蛋白 + 适量脂肪
```

## 特殊人群营养调整

### 高血压用户
- 控盐 < 6g/天
- 增加钾摄入（香蕉、菠菜、土豆）
- 避免酒精

### 糖尿病/胰岛素抵抗用户
- 碳水集中在白天活动时段
- 优先复合碳水（燕麦、糙米、薯类）
- 避免精制糖和高GI食物

### 高尿酸用户
- 控制嘌呤摄入（动物内脏、海鲜浓汤）
- 蛋白质以蛋奶为主
- 每日饮水 ≥ 2L
