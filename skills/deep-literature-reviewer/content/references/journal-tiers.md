## 期刊影响因子参考（IF）

> 注：影响因子随年份变化，此处为参考值

| Tier | IF 范围 | 说明 |
|------|---------|------|
| Tier 1 | IF > 40 | 顶刊，综合科学/Nature/Science/Cell系 |
| Tier 2 | IF 10-40 | 领域顶刊 |
| Tier 3 | IF 5-10 | 专业期刊 |
| Tier 4 | IF 2-5 | 严谨综合性期刊 |

## 自定义期刊列表

研究者可根据具体领域自定义期刊优先级：

```
【我的领域期刊优先级】
Tier 1（必读）：
- [领域顶刊1]
- [领域顶刊2]

Tier 2（重要）：
- [专业期刊1]
- [专业期刊2]

排除列表：
- [存在争议/问题的期刊]
```
