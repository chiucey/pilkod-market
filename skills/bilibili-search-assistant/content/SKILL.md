# B站（哔哩哔哩）搜索小助手

## 功能概述

接收用户输入的B站搜索关键词，自动访问B站网页版搜索结果页面，提取前30条视频数据，生成包含以下信息的Excel表格：

- 视频标题
- 视频链接
- 作者名称
- 发布时间
- 播放量
- 点赞/投币/收藏数
- 评论数
- 弹幕数

## 工作流程

### 步骤1：接收搜索关键词

用户在前端界面输入B站搜索关键词。

### 步骤2：搜索并提取数据

1. 构造B站搜索URL：`https://search.bilibili.com/all?keyword={关键词}`
2. 使用网页抓取工具提取搜索结果列表
3. 对于每个视频结果，提取：
   - 视频标题
   - 视频BV号/链接
   - 作者信息（UP主名称）
   - 发布时间
   - 互动数据（播放、点赞、投币、收藏、评论、弹幕）

### 步骤3：数据整理与排序

按以下维度进行统计分析：

| 统计维度 | 说明 |
|---------|------|
| 相关度排名 | 按B站默认排序 |
| 播放量排序 | 从高到低排列 |
| 收藏量排序 | 从高到低排列 |
| 评论数排序 | 从高到低排列 |
| 点赞量排序 | 从高到低排列 |

### 步骤4：生成Excel表格

创建包含多个Sheet的Excel文件：

1. **综合统计表**：包含所有视频的完整数据
2. **播放量排行**：按播放量降序排列
3. **收藏量排行**：按收藏量降序排列
4. **评论数排行**：按评论数降序排列
5. **点赞量排行**：按点赞量降序排列

### 步骤5：交付结果

- 提供Excel文件下载链接
- 汇总关键统计信息
- 提供使用说明

## 数据字段规范

| 字段名 | 数据类型 | 说明 |
|-------|---------|------|
| 排名 | INT | 搜索结果序号 |
| 视频标题 | TEXT | 视频标题全文 |
| 视频链接 | URL | B站视频完整URL |
| UP主名称 | TEXT | 创作者昵称 |
| UP主主页 | URL | 创作者主页链接 |
| 发布时间 | DATETIME | 视频发布时间 |
| 播放量 | NUMBER | 格式化数字（如10.2万） |
| 点赞数 | NUMBER | 格式化数字 |
| 投币数 | NUMBER | 格式化数字 |
| 收藏数 | NUMBER | 格式化数字 |
| 评论数 | NUMBER | 格式化数字 |
| 弹幕数 | NUMBER | 格式化数字 |

## 错误处理

- 如果B站页面无法访问，提示用户手动复制搜索结果
- 如果数据提取失败，记录失败原因并继续处理其他结果
- 如果数据量不足30条，按实际数量生成表格

## 输出示例

用户输入关键词"Python教程"后，生成Excel包含：

- Sheet1: 综合统计 - 所有30条视频完整数据
- Sheet2: 播放排行 - 按播放量排序
- Sheet3: 收藏排行 - 按收藏量排序
- Sheet4: 评论排行 - 按评论数排序
- Sheet5: 点赞排行 - 按点赞量排序

每个Sheet包含可点击的视频链接，方便用户直接跳转观看。
