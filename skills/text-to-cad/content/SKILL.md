## 国际/国家制图强制规则（每次生成必须遵守）

### 规则 R1 — 图幅（ISO 5457 / GB/T 14689）
- 每张图必须声明图幅（A0/A1/A2/A3/A4）
- 必须生成 `border`（图框）实体，外框细实线，内框粗实线
- 图幅选取建议：小零件选 A4/A3，中等零件 A3/A2，大型装配图 A1/A0
- 标准图框尺寸严格执行 ISO 5457 / GB/T 14689 规定
- A0-A3 优先横放；A4 优先竖放；装订边固定在图纸左侧（25mm）

### 规则 R2 — 标题栏（GB/T 10609.1 / ISO 7200 / ★ v13.0 企业级强化）

**双标准模式选择：**

| 使用场景 | 标题栏标准 | 字段语言 | 直径前缀 | 投影默认 |
|---------|---------|---------|---------|---------|
| **国内生产/默认** | GB/T 10609.1 ★ | 中文 | Φ | 第一角投影 |
| 外贸/ISO/国际场景 | ISO 7200 | 英文 | Ø | 第一角投影（可切换第三角） |

- 每张图必须生成 `title_block` 实体
- 必须填写：图样名称、图号、比例、材料、单位名称
- 装配图须在标题栏旁生成 `bom`（明细表，GB/T 10609.2 或 ISO 7573 格式）
- 标题栏必须标注投影方式和投影符号

### 规则 R4 — 中心线（ISO 128-24 / GB/T 4457.4）
- 圆形或回转零件必须画中心线（center_mark 或 CENTER 图层上的线）
- 中心线须超出轮廓外约 3-5mm
- 中心线使用细点画线（CENTER 线型）
- 对称零件须画对称中心线

### 规则 R5 — 尺寸标注（ISO 129-1 / GB/T 4458.4）
- 主要外形尺寸必须全部标注，不得遗漏任何重要尺寸
- 直径：国内图纸用 Φ（`dim_diameter`），ISO/外贸用 Ø
- 半径用 `dim_radius`（R 前缀）
- 尺寸线与轮廓线间距 ≥10mm（首道），两道并行尺寸线间距 ≥7mm
- 小尺寸靠近，大尺寸在外（避免交叉）
- **基准链闭环标注（强制）**：所有尺寸必须以基准面/基准轴为起点形成闭环
- 禁止无序乱标、禁止孤立尺寸、禁止缺少基准参考

### 规则 R6 — 剖面填充（ISO 128-50 / GB/T 4457.5）
- 金属剖视：`pattern: "ANSI31"`, `scale: 1.0`（45°等间距细实线，间距约3mm）
- 同一零件所有剖面：方向、间距一致
- 相邻零件剖面线方向相反或间距不同
- 实心件（轴、销、键、螺栓）纵向剖切不画剖面线

### 规则 R7 — 技术要求（★ v13.0 企业级强化）

**双语模式：**
- 国内图纸（GB）：技术要求用**中文**，置于图纸左下角 mtext
- 国际图纸（ISO/外贸）：Technical Requirements 用**英文**

| 焊接件 | 焊接材料及标准/焊接方法/焊缝等级/探伤要求 |

### 规则 R8 — 比例（ISO 5455 / GB/T 14690）
- 图纸选择合理比例：1:1, 1:2, 1:5, 2:1, 1:10 等
- 标题栏 scale 字段必须填写实际比例
- 局部放大图须单独标注其局部比例

### 规则 R9 — 粗糙度与公差（ISO 1302/21920 / GB/T 131 / ISO 1101）
- 表面粗糙度用 `surface_roughness` 图元（ISO 1302 / GB/T 131 符号体系）
- 形位公差用 `tolerance_frame` 图元（ISO 1101 / GB/T 1182）
- 基准符号用 `datum_mark` 图元
- Ra 系列值（μm）：0.4, 0.8, 1.6, 3.2, 6.3, 12.5
- 公差选配按 ISO 286 / GB/T 1800 配合制（H7/g6, H7/h6, H7/p6 等）
- 未注公差：国内按 GB/T 1804-m，国际按 ISO 2768-mK

**粗糙度与加工工艺对应参考：**
| 加工方式 | Ra(μm) | 典型应用 |
|---------|--------|---------|
| 精密磨削 | 0.4~0.8 | 轴承座孔、精密配合面 |
| 精车/精铣 | 1.6 | 一般配合面、密封面 |
| 半精加工 | 3.2 | 非配合装配面 |
| 粗加工 | 6.3~12.5 | 非工作面、安装基准面 |

- 所有尺寸标注必须以基准面/基准轴为参考
- 基准体系：主基准(A)、副基准(B)、第三基准(C)
- 尺寸链必须形成闭环（从基准出发，回到基准或到最终加工面）

  - 过渡配合：H7/k6, H7/js6
  - 过盈配合：H7/p6, H7/s6
- 形位公差按 ISO 1101 / GB/T 1182 / ASME Y14.5 选配
- 未注公差：国内 GB/T 1804-m，国际 ISO 2768-mK

### 规则 R20 — 视图选择三原则（★ v12.0 课本级新增）

**主视图选择三原则（优先级从高到低）：**

| 优先级 | 原则 | 核心要求 | 适用零件 |
|--------|------|---------|---------|
| 1（首要） | **形状特征原则** | 选择最能反映零件各部分形状及各功能部分相对位置的方向作为投射方向 | 所有零件 |
| 2 | **加工位置原则** | 主视图与零件主要加工工序的装夹位置一致 | 轴/套/轮/盘等回转体（轴线水平放置） |
| 3 | **工作位置原则** | 主视图与零件在机器中的工作位置一致 | 叉架/箱体/支架等复杂零件（底面朝下） |

**其他视图选择规则：**
- 选择顺序：主视图 → 优先基本视图 → 基本视图上取剖视/断面 → 辅助视图补充
- 数量原则：在保证充分表达的前提下，视图数目为最少
- 独立原则：每个视图都有明确表达重点，具有独立存在意义
- 避免重复：各视图相互配合、相互补充而不重复
- **虚线使用原则**：在不致引起误解时，应避免使用虚线表示不可见结构；仅当虚线能减少视图数量时才画

详细参考：`references/mechanical_drawing_textbook_rules.md` 第一章

### 规则 R21 — 剖视图分类与画法（★ v12.0 课本级新增，GB/T 4458.6 / GB/T 17452）

**按剖切范围分类：**

| 类型 | 定义 | 适用条件 | 标注要求 |
|------|------|---------|---------|
| **全剖视图** | 完全剖开物体 | 外形简单、内形复杂的不对称机件 | 对称面剖切可省略 |
| **半剖视图** | 以对称中心线为界，一半剖视一半视图 | 物体具有对称平面，内外形都需表达 | 分界线为**细点画线**，不可用粗实线 |
| **局部剖视图** | 局部剖开物体，波浪线分界 | 内外都需表达/不对称/实心杆上的孔槽 | 位置明显时可省略 |

**半剖视图关键规则：**
- 分界线必须是细点画线（对称中心线），**不可**画成粗实线
- 已表达清楚的内部结构，另一半视图中**不再画虚线**
- 对称中心线处有轮廓线时，**不宜**使用半剖 → 改用局部剖

**局部剖视图关键规则：**
- 剖与不剖用波浪线分界，波浪线不得与其他图线重合
- 波浪线不得超出物体实体（孔/槽处必须断开）
- 回转体允许用轴线作为分界线
- 一个视图中局部剖数量不宜过多

**按剖切方法分类：**

| 方法 | 说明 | 适用场景 | 标注 |
|------|------|---------|------|
| 单一剖 | 平行于基本投影面的平面 | 最常用 | 对称面可省略 |
| 斜剖 | 不平行任何基本投影面 | 倾斜内形 | 必须标注 |
| 阶梯剖 | 几个平行的剖切面 | 不同层次的内部结构 | 转折处标注，不出现不完整要素 |
| 旋转剖 | 几个相交的剖切面 | 有回转轴的机件（均布孔等） | 必须标注，后续结构按原位投影 |
| 复合剖 | 组合方法 | 结构复杂 | 必须标注 |

**剖面填充课本级规则：**
- 金属剖面线与水平线成 45°，间距 2-4mm
- 同一零件所有剖面方向和间距一致
- 相邻零件剖面方向相反或间距不同
- **实心件纵向剖切不画剖面线**（轴/销/键/螺栓/螺母/球）

详细参考：`references/mechanical_drawing_textbook_rules.md` 第二章

### 规则 R22 — 断面图画法（★ v12.0 课本级新增，GB/T 4458.6）

断面图仅画出剖切面与物体接触部分的截面图形，用于表达截面形状。

| 类型 | 轮廓线 | 配置 | 标注 |
|------|--------|------|------|
| **移出断面** | 粗实线 | 剖切线延长线上或其他位置 | 对称且在延长线上可省略 |
| **重合断面** | 细实线 | 视图内部 | 不对称可省略 |

**移出断面特殊规则：**
- 通过回转面孔/凹坑轴线时 → 按剖视图绘制
- 通过非圆孔导致分离的两个断面时 → 按剖视图绘制
- 两个相交剖切平面 → 中间断开

**典型应用：** 轴类零件的键槽深度、轮辐/肋板的截面形状

### 规则 R23 — 简化画法（★ v12.0 课本级新增，GB/T 16675.1）

**简化三原则：**
1. 前提原则：保证不引起误解和多义性
2. 效果原则：便于识读和绘制
3. 兼容原则：兼顾手工和计算机制图

**常见简化画法清单：**

| 编号 | 简化内容 | 画法规则 |
|------|---------|---------|
| S1 | 相同结构要素 | 仅画一个或几个，其余用中心线标明位置并注数量 |
| S2 | 交线简化 | 较小交线（过渡线/相贯线）可用圆弧或直线代替 |
| S3 | 小圆角/小倒角 | 可省略不画，但须在技术要求中注明 |
| S4 | 对称零件 | 可仅画一半或四分之一，两端画对称符号 |
| S5 | 滚花 | 用粗实线附近示意标注（如"网纹m0.4"） |
| S6 | 平面符号 | 两相交细实线表示平面 |
| S7 | 长零件折断 | 沿长度方向形状一致时可断开缩短，标注实际长度 |
| S8 | 法兰均布孔 | 可按简化方法绘制 |
| S9 | 移出断面 | 对称且在剖切线延长线上可省略标注 |
| S10 | 局部放大图 | 可按比例或简化绘制 |

**简化注法：** 退刀槽（3×1）、倒角（C2）、均布（EQS）、沉孔/埋头孔格式

详细参考：`references/mechanical_drawing_textbook_rules.md` 第三章

### 规则 R24 — 标准件/常用件画法（★ v12.0 课本级新增，GB/T 4459.1~5）

**螺纹画法（GB/T 4459.1）：**
- 牙顶圆（大径）= **粗实线**；牙底圆（小径）= **细实线**（约为大径的 0.85 倍）
- 端视图中牙底细实线圆只画约 **3/4 圈**，倒角投影圆省略
- 螺纹终止线 = **粗实线**
- 内外螺纹连接：结合部分按外螺纹画法
- 外螺纹剖视：剖面线画到粗实线（大径）处
- 内螺纹剖视：剖面线画到粗实线（小径）处

**齿轮画法（GB/T 4459.2）：**
- 齿顶圆 = 粗实线；分度圆 = 细点画线；齿根圆 = 细实线（可省略）
- 剖视中轮齿部分按**不剖**处理（不画剖面线）
- 齿轮啮合：啮合区分度线相切，一个齿轮齿顶用粗实线，另一个用虚线

**弹簧画法（GB/T 4459.4）：**
- 各圈轮廓画成直线，可画成右旋
- 4 圈以上中间可省略并适当缩短
- 被弹簧挡住的结构不画出

**花键画法（GB/T 4459.3）：**
- 外花键：大径粗实线、小径细实线
- 内花键：大径细实线、小径粗实线
- 标注：N×d×D×B

**中心孔（GB/T 4459.5）：**
- 符号为 60° 三角形，细实线引出标注

详细参考：`references/mechanical_drawing_textbook_rules.md` 第四章

### 规则 R25 — 尺寸标注课本级规则（★ v12.0 课本级新增，GB/T 4458.4）

**基本原则：**
1. **功能尺寸直接标注**: 配合尺寸、装配尺寸必须直接标注，不可间接推算
2. **避免封闭尺寸链**: 相关尺寸不形成封闭链，留一个最不重要的段不标
3. **相关尺寸集中标注**: 同一结构要素的尺寸集中标注在同一视图
4. **标注在特征最清晰的视图**: 选择最能反映该特征的视图
5. **内形与外形尺寸分开标注**: 避免尺寸线交叉
6. **小尺寸靠近，大尺寸在外**: 尺寸线间距 ≥ 7mm

**常见标注格式速查：**

| 标注类型 | 格式 | 示例 |
|---------|------|------|
| 45°倒角 | C+数字 | C2 |
| 非45°倒角 | 宽度×角度 | 1.5×30° |
| 退刀槽 | 槽宽×槽深 | 3×1 |
| 砂轮越程槽 | 槽宽×槽深 | 2×0.5 |
| 键槽深度 | 从外圆到槽底 | 标注 d-t 或直接标注 |
| 均布要素 | 数量×规格 EQS | 6×M10 EQS |
| 沉孔 | Φ孔径沉孔Φ大径深h | 4×Φ10沉孔Φ16深3 |
| 埋头孔 | Φ孔径埋头孔角度Φ大径 | 4×Φ8埋头孔90°Φ14 |

详细参考：`references/mechanical_drawing_textbook_rules.md` 第五章

### 规则 R26 — 图号编码体系（★ v13.0 企业级新增，JB/T 5054.4）

**编码基本原则：** 唯一性、简洁性、系统性、扩展性、可溯性

**隶属编号法（推荐，体现产品装配关系）：**

```
格式：企业代号-产品代号-部件级-零件序号-文件类型

示例：ABC-1000-01-02-00  (01号部件下02号二级部件)
```

**分类编号法（适用于通用件/标准件多的企业）：**

| 分类特征码 | 含义 | 尾注 | 含义 |
|-----------|------|------|------|
| 0 | 零件/标准件/外购件 | 00 | 总图/装配图 |
| 1 | 组件/部件 | 01~99 | 零件图 |

| 5 | 检验文件 | -S | 展开图 |

**图号在标题栏中的填写：**
- 图号栏填写完整图号
- 图样标记栏填写阶段标记（S=试制 / A=小批试产 / B=量产）

### 规则 R27 — 工程变更管理（★ v13.0 企业级新增）

**变更分级：**

| 级别 | 类型 | 审批要求 | 适用场景 |
|------|------|---------|---------|
| EC1 | 重大变更 | 总工程师/技术总监 | 影响功能/安全/互换性 |
| EC2 | 一般变更 | 部门主管/技术经理 | 尺寸/公差/材料/工艺修改 |
| EC3 | 微小变更 | 主管工程师 | 错别字/标注优化 |

**版本号规则：**
- 初始版本：Rev A；首次修订：Rev B
- 大改递增字母（A→B→C），小改数字递增（A.0→A.1→A.2）
- 版本号在标题栏"版本"栏填写

**更改记录栏（标题栏上方）：**

| 标记 | 处数 | 分区 | 更改文件号 | 签名 | 日期 |
|------|------|------|-----------|------|------|

- 每次图纸变更必须填写更改记录栏
- 更改文件号关联 ECN 编号

**变更流程：** 变更申请 → 技术评审 → 影响分析(BOM/工艺/工装/库存) → 审批 → 图纸修改 → 更新受控清单 → 通知相关部门 → 回收旧版 → 发放新版 → 归档

详细参考：`references/enterprise_drawing_standards.md` 第二章

### 规则 R28 — 签审流程（★ v13.0 企业级新增，ISO 9001 / IATF 16949）

**六岗签审制度：**

| 岗位 | 职责 | 一般零件图 | 关键零件图 | 装配图/总装图 |
|------|------|-----------|-----------|-------------|
| 编制(Design) | 设计出图 | 设计工程师 | 高级工程师 | 主管/技术经理 |
| 校对(Check) | 核对尺寸/标准 | 同级工程师 | 主管工程师 | 高级工程师 |
| 审核(Review) | 评估合理性 | 主管工程师 | 技术经理 | 技术经理 |
| 工艺(Process) | 评估可加工性 | - | 工艺工程师 | 工艺工程师 |
| 标准化(Std) | 检查标准符合性 | - | 标准工程师 | 标准工程师 |
| 批准(Approve) | 最终确认 | 部门主管 | 技术总监 | 技术总监/总经理 |

**签审栏标准格式（标题栏右下区域）：**
```
编制 Design  │ 签名 │ 日期 │  校对 Check  │ 签名 │ 日期
审核 Review  │ 签名 │ 日期 │  工艺 Process │ 签名 │ 日期
标准化 Std    │ 签名 │ 日期 │  批准 Approve│ 签名 │ 日期
```

**签审要点：**
- 校对：尺寸链、公差配合、标准件规格、投影关系、视图完整性
- 审核：结构合理性、工艺可行性、成本影响、部件接口
- 工艺：可加工性、加工顺序、工装需求
- 标准化：国标/行业标准、企业标准、统一规范
- 批准：最终确认，承担技术责任

详细参考：`references/enterprise_drawing_standards.md` 第三章

### 规则 R29 — 检验标准体系（★ v13.0 企业级新增）

**常用检验标准引用清单：**

| 标准号 | 适用场景 |
|--------|---------|
| GB/T 1804 | 未注公差尺寸 |
| GB/T 1184 | 未注形位公差 |
| GB/T 2828.1 | 计数抽样检验 |
| GB/T 11345 | 焊缝超声波检测 |
| GB/T 9286 | 涂层附着力（划格试验） |
| GB/T 10125 | 盐雾试验 |
| GB/T 14211 | 机械密封试验 |

**CTQ/CPK 标注规则：**
- 关键特性尺寸（Critical-to-Quality）用 **CTQ** 或 **★** 符号标识
- 量产要求：CPK ≥ 1.33
- 技术要求中须列出 CTQ 检验方法和抽检比例

**零件图检验要求模板：**
```
检验要求:
1. ★CTQ尺寸用三坐标测量仪检测, CPK≥1.33
2. 未注尺寸公差按 GB/T 1804-m 验收
3. 未注形位公差按 GB/T 1184-K 验收
4. 表面粗糙度用粗糙度仪检测
5. 硬度检测: 洛氏硬度计, 每批次抽检5件
6. 外观检验: 无裂纹、气孔、砂眼、碰伤等缺陷
7. 来料检验按 GB/T 2828.1, AQL=1.0
```

**装配图检验要求模板：**
```
检验要求:
1. 装配后主轴径向圆跳动≤0.015mm (百分表检测)
2. 气密性试验: 0.6MPa, 保压5min, 无泄漏
3. 运转试验: 空载2h, 噪音≤75dB, 温升≤35℃
4. 关键配合面接触率: 涂色检查, ≥70%
```

详细参考：`references/enterprise_drawing_standards.md` 第四章

### 规则 R30 — 材料规范与环保合规（★ v13.0 企业级新增）

**材料标注标准格式：**
```
材料: 牌号 + 标准号 + 供货状态
示例: 45钢, GB/T 699-2015, 调质态
示例: 304不锈钢, GB/T 20878-2007, 固溶态
示例: 6061-T6铝合金, GB/T 3190-2020
示例: HT250灰铸铁, GB/T 9439-2010
```

**禁止模糊标注：** 不允许仅写"钢材"、"铝材"，必须写明具体牌号和标准号。

**环保合规要求：**

| 法规 | 标注要求 |
|------|---------|
| RoHS 2.0 | 技术要求中注明"符合 RoHS 2.0 指令要求" |
| REACH | 供应商需提供 SVHC 声明 |
| GB/T 26572 | 电子电气产品限用物质 |

**环保标注模板：**
```
环保要求:
1. 本产品及所有零部件须符合 RoHS 2.0 指令要求
2. 材料中有害物质含量须符合 GB/T 26572-2011
3. 禁止使用含六价铬的表面处理工艺
```

**材料替代规则：**
- 替代须提交材料代用申请单
- 须经技术评审确认不影响性能
- 替代材料性能须同等或优于原件
- 更新图纸材料栏和 BOM 表

### Step A3 — 确定基准体系与视图布局

**基准体系建立（强制）：**

根据零件功能与加工工艺，确定三基准体系：
1. **主基准 A**：通常为最大装配面/底面/主要定位面
2. **副基准 B**：通常为关键侧面/导向面
3. **第三基准 C**：通常为辅助定位面/端面

**视图选择矩阵（精准还原各零件类型，融入课本三原则 ★v12.0 强化）：**

| 零件类型 | 主视图选择原则 | 推荐视图组合 | 剖面要求 | 特殊标注 |
|---------|-------------|---------|---------|---------|
| 阶梯轴 | ★ 加工位置（轴线水平）+ 形状特征 | 主视图(水平) + 移出断面图 + 局部放大图(退刀槽) | 断面图标注键槽/退刀槽 | 中心孔、砂轮越程槽 |
| 法兰盘 | ★ 加工位置（轴线水平）+ 形状特征 | 主视图(圆形端面) + 全剖侧视图 | A-A 全剖 | PCD、螺栓孔均布 |
| 齿轮 | ★ 加工位置（轴线水平）+ 形状特征 | 主视图(外形) + 全剖左视图 | A-A 全剖 | 节圆、分度圆(细点画线) |
| 箱体 | ★ 工作位置（底面朝下）+ 形状特征 | 主视图 + 俯视图 + 左视图 + 辅助剖 | 全剖/阶梯剖 | 安装孔、轴承孔 |
| 支架 | ★ 工作位置 + 形状特征 | 主视图 + 俯视图 + 左视图 | 局部剖 | 安装孔、加强筋 |
| 叉架 | ★ 工作位置 + 形状特征 | 主视图 + 俯视图 + 左视图 | 局部剖/斜剖 | 销孔、配合面 |
| 钣金件 | ★ 形状特征 | 成形主视图 + 展开图 | 折弯线标注 | K因子、板厚 |
| 装配体 | ★ 工作位置 | 主视图(剖) + 俯视图/左视图 + BOM | 全剖/阶梯剖 | 序号、配合尺寸 |
| 弹簧 | ★ 形状特征（轴线竖直或水平） | 主视图(全剖) | 按GB/T 4459.4不剖 | 自由高、节距、旋向 |

**Agent 坐标计算算法（默认第一角投影）：**

```
给定图幅（如 A3 = 420×297）和图框内框尺寸：
  有装订边 A3: 内框 = (25, 5) → (395, 292)  即 iw=370, ih=287

步骤 1: 确定主视图占据区域（含标注空间）
  main_w = 零件最大宽度 × scale + 2×dim_margin
  main_h = 零件最大高度 × scale + 2×dim_margin
  (dim_margin ≈ 30mm, 为尺寸标注留空间)

步骤 2: 根据 projection 确定视图位置

  ▸ 第一角投影 (projection="first") ★默认:
    主视图居中偏左:
      front_x = inner_left + (iw - main_w - left_w - view_gap) / 2
      front_y = inner_top - 15 - main_h
    俯视图在主视图正下方:
      top_x = front_x  (与主视图左对齐 — 长对正)
      top_y = front_y - view_gap - top_h
    左视图在主视图正右方:
      left_x = front_x + main_w + view_gap
      left_y = front_y  (与主视图底部对齐 — 高平齐)

  ▸ 第三角投影 (projection="third"):
    俯视图在主视图正上方:
      front_x = inner_left + left_w + view_gap + (iw - left_w - view_gap - main_w) / 2
      front_y = inner_bottom + 56 + 15 + main_h
      top_y = front_y + view_gap + top_h
      top_x = front_x
    左视图在主视图正左方:
      left_x = front_x - view_gap - left_w
      left_y = front_y

步骤 3: 剖面图位置（放在右下区域或视图旁边）

步骤 4: 技术要求（左下角，距内框左边 20mm，距内框底部 10-20mm）

步骤 5: 验证所有视图不超出内框范围（如超出则调整比例或图幅）
```

### Step A5.7 — Spec 自动校验（生成前必做 ★v11.0 新增）

在生成 DXF 之前，先对 spec JSON 进行自动校验：

```bash

```

校验内容：
- 顶层字段完整性（standard/projection/unit_system/gps_standard）
- 默认值一致性（standard="GB", projection="first" 时无矛盾字段）
- 图框/标题栏/投影符号/基准体系是否存在
- 图元类型是否在支持列表中

- 尺寸标注无孤立（每个 dim 引用有效 datum）
- 技术要求是否存在
- BOM 与装配图一致性

如校验报错，必须修复后再生成 DXF。

### Step A6 — 质量自检（生成后必做 ★）

对照以下清单检查生成的 spec JSON：

**A. Spec 校验（v11.0 新增，优先执行）**
- [ ] Spec 已通过 spec_validation.py 自动校验（Step A5.7）
- [ ] 顶层默认值一致：standard="GB", projection="first"（除非用户另有指定）

**B. 完整性检查**
- [ ] 有 `border` 图框（标准图幅，内外框分明）
- [ ] 有 `title_block` 标题栏（GB/T 10609.1 或 ISO 7200 格式）
- [ ] 有 `projection_symbol` 投影符号（与 projection 字段一致）
- [ ] 有 `datum_system` 基准体系定义（至少主基准 A）
- [ ] 有 `datum_mark` 基准符号（与 datum_system 对应）

## 🧊 Route E — 钣金展开 / 爆炸图 / 装配图

### 钣金展开图

当用户描述包含"钣金"、"展开"、"折弯"、"板厚"等关键词时：

**生成内容：**
1. 折弯成形图（主视图 + 俯视图）：标注板厚、折弯角度、折弯半径
2. 展开图（单独视图区域）：标注展开后轮廓尺寸
3. 折弯线标记：双点画线（PHANTOM）
4. 技术要求：注明折弯方向、K因子、折弯顺序

**折弯补偿计算：**
```
展开长度 = 直线段总长 + 折弯补偿
折弯补偿 BA = π × (R + K × T) × θ / 180
其中: R=折弯内半径, K=K因子(通常0.3-0.5), T=板厚, θ=折弯角度
```

### 零件爆炸图

当用户说"爆炸图"、"分解图"、"拆解图"时：

1. 沿主要装配轴向偏移各零件（偏移量递增，如 0, 30, 60, 90...）
2. 每个零件用引线标注序号
3. 放置 BOM 表格（GB/T 10609.2）
4. 用 PHANTOM 线型绘制装配轴线

### 装配图

**生成内容：**
1. 主视图（剖视图显示内部装配关系）
2. 俯视图或左视图（外形视图）
3. 剖面填充（相邻零件方向不同）
4. 零件序号标注（引线 + Ø8 圆圈序号，从左下逆时针排列）
5. GB/T 10609.2 或 ISO 7573 BOM 明细表
6. 关键配合尺寸标注（如 Φ50H7/g6）
7. 干涉检查说明

**干涉检查说明格式：**
```
装配干涉检查说明:
1. 零件1(壳体)孔 Φ50H7 + 零件2(轴)Φ50g6 → 间隙配合 (H7/g6)
   最大间隙: +0.050mm, 最小间隙: +0.009mm → 无干涉 ✓
2. 零件3(轴承)外径 Φ62J6 + 零件1(壳体)孔 Φ62H7 → 过渡配合
   最大过盈: -0.012mm → 合理（轴承压配）✓
3. 所有紧固件孔位已验证 PCD 公差 → 无干涉 ✓
```

## 全局约定

- 所有角度：**度（°）**，从正 X 轴逆时针
- 默认尺寸单位：**mm（毫米）**，英制图纸使用 **inch（英寸）**
- 图纸放置：图形居中于图框内框可用区域
- **★ 默认投影方式：第一角投影法**（ISO 128-1 / GB/T 17451 中国/欧洲标准）
- 默认标准体系：**GB** 国家标准（国内生产）/ **ISO** 国际标准（外贸/出口）
- GPS 公差原则：**ISO 8015** 独立原则
- 通用公差等级：国内默认 **GB/T 1804-m**，国际默认 **ISO 2768-mK**
- 尺寸标注方式：**基准链闭环标注**（ISO 8015 / ISO 5458）
- 直径前缀：国内图纸用 **Φ**（GB），国际图纸用 **Ø**（ISO）
- 技术要求：国内图纸用**中文**，国际/外贸图纸用**英文**
- **永久生效**：技能安装后永久可用，用户只需口述零件结构即可获得全套标准图纸
- **黑色背景预览**：每次生成 DXF 后自动生成黑色背景 PNG 预览图
- **永不降级**：后续修改/重绘必须保持同一套国际/国家高标准
- **铁律永久有效**：8 条禁止条款在任何情况下不可跳过或降级
