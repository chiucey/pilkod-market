## 第一章 视图选择原则（课本核心）

### 1.1 主视图选择三原则（★ 最重要）

主视图是一组视图的核心，其选择是否合理直接关系到看图、画图是否方便，以及整个表达方案的优劣。

| 原则 | 核心要求 | 适用零件 | 目的 |
|------|---------|---------|------|
| **形状特征原则** | 选择最能反映零件各部分形状及组成零件各功能部分相对位置的方向作为投射方向 | 所有零件（首要原则） | 便于设计和读图 |
| **加工位置原则** | 主视图与零件在主要加工工序中的装夹位置一致 | 轴、套、轮、盘等回转体 | 便于加工时看图和测量尺寸 |
| **工作位置原则** | 主视图与零件安装在机器（或部件）中的工作位置一致 | 叉架、箱体、支架等复杂零件 | 便于想象零件工作状况和按图装配 |

**三原则优先级**: 形状特征原则 ≥ 加工位置原则 ≥ 工作位置原则
- 形状特征原则是**首要原则**，任何零件都必须首先考虑
- 加工位置原则和工作位置原则根据零件类型二选一（或综合考虑）

### 1.2 各类零件主视图选择指南

| 零件类型 | 主视图选择要点 | 典型安放方式 |
|---------|-------------|------------|
| **轴类**（阶梯轴/花键轴/曲轴） | 按加工位置：轴线水平放置，反映各段直径、键槽、退刀槽、中心孔 | 水平放置（车削位置） |
| **盘类**（法兰盘/齿轮/皮带轮） | 按加工位置：轴线水平放置，反映内孔、外圆、键槽、均布孔 | 水平放置（车削位置） |
| **叉架类**（拨叉/连杆/摇臂） | 按工作位置原则或形状特征原则 | 自然工作位置 |
| **箱体类**（减速机箱/泵壳/阀体） | 按工作位置原则：反映主要安装面、轴承孔、连接法兰 | 工作位置（底面朝下） |
| **支架类**（悬臂支架/角支架） | 按工作位置原则：反映安装面、支撑面、加强筋 | 工作位置 |
| **钣金件** | 按形状特征原则：反映折弯方向和展开关系 | 主折弯面平行投影面 |

### 1.3 其他视图选择规则

1. **选择顺序**: 主视图确定 → 优先基本视图 → 在基本视图上取剖视/断面 → 辅助视图补充
2. **表达层次**:
   - 首要：基本视图/剖视图 — 表达主视图中尚未表达清楚的主要结构
   - 次要：局部视图/斜视图 — 表达次要结构、细小部位或局部形状
3. **数量原则**: 在保证充分表达零件结构形状的前提下，视图数目为最少
4. **独立原则**: 每个视图都应有明确的表达重点，具有独立存在的意义
5. **配置原则**: 局部视图/斜视图尽可能按投影关系直接配置在相关视图附近
6. **避免重复**: 各视图要相互配合、相互补充而不重复

### 1.4 典型零件视图选择方案

| 零件类型 | 推荐视图组合 | 选择依据 |
|---------|------------|---------|
| 光轴 | 主视图（水平） + 断面图（键槽处） | 形状简单，轴向尺寸为主 |
| 阶梯轴 | 主视图（水平） + 移出断面图 + 局部放大图（退刀槽/砂轮越程槽） | 多段直径变化，需断面图辅助 |
| 法兰盘 | 主视图（圆形端面视图） + 全剖侧视图 | 需表达均布孔、内孔台阶 |
| 齿轮 | 主视图（外形/圆形） + 全剖左视图 | 需表达轮齿参数、键槽、轮毂 |
| 箱体 | 主视图 + 俯视图 + 左视图 + 局部剖 | 内部结构复杂，需多视图+剖视 |
| 支架 | 主视图 + 俯视图 + 局部剖 | 安装孔、加强筋需表达 |
| 叉架 | 主视图 + 俯视图 + 局部剖 | 销孔、配合面需表达 |
| 钣金件 | 成形主视图 + 展开图 | 需同时表达成形和展开状态 |

## 第二章 剖视图分类与画法（GB/T 4458.6 / GB/T 17452）

### 2.1 剖视图基本概念

假想用剖切面剖开物体，将处在观察者和剖切面之间的部分移去，而将其余部分向投影面投射所得的图形。

**核心规则**:
- 剖切是**假想**的，并非真的切去零件的某部分
- 其他视图仍按完整零件绘制
- 剖面区域内需绘制剖面线

### 2.2 剖视图按剖切范围分类

| 类型 | 定义 | 适用条件 | 标注要求 |
|------|------|---------|---------|
| **全剖视图** | 用剖切面**完全**剖开物体 | 外形简单、内形复杂的不对称机件 | 一般需标注（×—×）；对称面剖切且按投影关系配置时可省略 |
| **半剖视图** | 以对称中心线为界，一半画剖视，一半画视图 | 物体具有对称平面，且内外形都需要表达 | 对称面剖切可省略标注；标注同全剖 |
| **局部剖视图** | 用剖切面**局部**剖开物体 | 内外结构都需表达；不对称机件；实心杆上的孔槽 | 单一剖切面位置明显时可省略标注 |

**半剖视图画法要点**:
- 半个剖视图与半个视图的分界线为**细点画线**（对称中心线），不得画成粗实线
- 在半个剖视图中已表达清楚的内部结构，在另一半视图中**不再画虚线**
- 当对称物体在对称中心线处有轮廓线时，**不宜**使用半剖视图，改用局部剖视图

**局部剖视图画法要点**:
- 剖与不剖部分用**波浪线**（或双折线）分界
- 波浪线不应和图样上其他图线重合
- 波浪线不应超出物体的实体（孔、槽处必须断开）
- 当被剖结构为回转体时，允许将该结构的**轴线**作为分界线
- 一个视图中局部剖的数量不宜过多，避免图形破碎

### 2.3 剖切方法分类

| 剖切方法 | 说明 | 适用场景 | 标注 |
|---------|------|---------|------|
| **单一剖切面** | 平行于基本投影面的平面 | 最常用 | 对称面剖切可省略 |
| **斜剖** | 不平行于任何基本投影面的剖切面 | 表达倾斜部分的内形 | 必须标注，可旋转配置并标注旋转符号 |
| **阶梯剖** | 几个平行的剖切面 | 内部结构在不同层次但轴线平行的机件 | 各转折处必须标注，图形内不应出现不完整要素 |
| **旋转剖** | 几个相交的剖切面（交线垂直于某投影面） | 具有回转轴的机件（如法兰盘上均布孔） | 必须标注，剖切平面后的结构按原来位置投影 |
| **复合剖** | 以上方法的组合 | 结构复杂的机件 | 必须标注 |

**阶梯剖画法要点**:
- 各剖切平面的转折处必须为**直角**
- 不应出现不完整的要素（如半个孔）
- 剖切平面的转折处不应与轮廓线重合
- 当两个要素在图形上具有公共对称中心线时，可各画一半

**旋转剖画法要点**:
- 先假想按剖切位置剖开机件
- 然后将被剖切到的倾斜结构**旋转**到与选定的投影面平行
- 再进行投射
- 剖切平面**之后**的其他结构一般仍按原来位置投影

### 2.4 断面图（GB/T 4458.6）

断面图仅画出剖切面与物体接触部分的图形（即"截面"），用于表达零件某处的截面形状。

| 类型 | 定义 | 画法要点 |
|------|------|---------|
| **移出断面** | 画在视图之外的断面图 | 轮廓线用**粗实线**；配置在剖切线延长线上；对称断面可省略标注 |
| **重合断面** | 画在视图之内的断面图 | 轮廓线用**细实线**；视图轮廓线不中断；不对称时可省略标注 |

**移出断面特殊规则**:
- 剖切平面通过回转面形成的**孔或凹坑**的轴线时 → 按**剖视图**绘制
- 剖切平面通过**非圆孔**导致完全分离的两个断面时 → 按**剖视图**绘制
- 由两个相交剖切平面剖切得到的移出断面 → 中间一般应**断开**

### 2.5 剖面填充规则（GB/T 4457.5）

- 金属材料的剖面线：与水平线成 **45°** 的等距平行细实线，间距约 **2-4mm**
- 同一零件所有剖面的剖面线**方向和间距必须一致**
- 相邻零件的剖面线**方向相反**或**间距不同**
- 剖面线间距可按图形大小调整，但同一零件中应一致
- **实心件**（轴、销、键、螺栓、螺母、垫圈、球等）在纵向剖切时**不画剖面线**
- 当剖切平面通过实心件的轴线时，按**不剖**处理（只画外形）

## 第三章 简化画法（GB/T 16675.1）

### 3.1 简化原则（总则）

1. **前提原则**: 简化必须保证不致引起误解和不会产生理解的多义性
2. **效果原则**: 便于识读和绘制，注重简化的综合效果
3. **兼容原则**: 兼顾手工制图、计算机制图的需求

### 3.2 绘图基本要求

| 序号 | 要求 | 说明 |
|------|------|------|
| 1 | 应避免不必要的视图和剖视图 | 能用一个视图表达的不用两个 |
| 2 | 在不致引起误解时，应避免使用虚线 | 虚线过多影响清晰度 |
| 3 | 尽可能使用有关标准中规定的符号 | 用符号代替图形 |
| 4 | 尽可能减少相同结构要素的重复绘制 | 标注"×个"代替逐个绘制 |
| 5 | 对于已清晰表达的结构，可对其进行简化 | 如省略倒角圆角小结构 |

### 3.3 常见简化画法清单

| 编号 | 简化内容 | 画法规则 |
|------|---------|---------|
| S1 | **相同结构要素简化** | 若干相同结构（孔/槽/齿），仅画一个或几个，其余用中心线标明位置并注数量（如"4×Φ10均布"） |
| S2 | **交线简化** | 较小的交线（如过渡线/相贯线）可用圆弧或直线代替 |
| S3 | **小圆角/小倒角简化** | 在不致引起误解时，零件上的小圆角、锐边小倒角允许省略不画，但必须注明尺寸或技术要求 |
| S4 | **对称零件简化** | 对称零件可仅画一半或四分之一，在对称中心线两端画对称符号（两条平行细实线） |
| S5 | **滚花简化** | 滚花结构只需在轮廓附近用粗实线示意标注"网纹m0.4"或"直纹m0.3" |
| S6 | **平面符号** | 当平面不能充分表达时，可用平面符号（两相交细实线）表示 |
| S7 | **长零件折断** | 较长零件（轴/杆/型材）沿长度方向形状一致或按规律变化时，可断开缩短绘制，但标注实际长度 |
| S8 | **法兰盘均布孔** | 圆柱形法兰盘上均布孔可按简化方法绘制 |
| S9 | **移出断面简化** | 配置在剖切线延长线上的对称移出断面可省略标注 |
| S10 | **局部放大图简化** | 局部放大图可按比例或简化绘制，需标注比例和被放大部位 |

### 3.4 简化注法

| 编号 | 简化注法 | 说明 |
|------|---------|------|
| A1 | **退刀槽/砂轮越程槽** | 可统一标注"槽宽×槽深"或"槽宽×直径" |
| A2 | **倒角** | 45°倒角用"C+数字"表示（如C2），非45°倒角标注角度和宽度 |
| A3 | **省略尺寸线箭头** | 在不引起误解时，可省略尺寸线一端的箭头 |
| A4 | **一组同心圆/尺寸** | 可共用一条尺寸线，用箭头指向各要素 |
| A5 | **均布要素** | 均匀分布的孔/槽用"EQS"（equally spaced）或"均布"标注 |

## 第四章 标准件/常用件画法（GB/T 4459）

### 4.1 螺纹画法（GB/T 4459.1）

**基本规则**:
- 螺纹牙顶圆（大径）的投影用**粗实线**表示
- 螺纹牙底圆（小径）的投影用**细实线**表示（小径通常画成大径的 **0.85 倍**）
- 在垂直于螺纹轴线的视图中，表示牙底的细实线圆只画约 **3/4 圈**，空出的 1/4 圈位置不限
- 螺纹倒角的投影圆**省略不画**（3/4 圈的细实线处）
- 有效螺纹的终止线（螺纹收尾线）用**粗实线**表示

**外螺纹画法**:
```
主视图（平行轴线方向）：
  ── 大径（粗实线，上下两条）
  ── 小径（细实线，上下两条，在大径内侧，约 0.85 倍）
  ── 螺纹终止线（粗实线，垂直于轴线）
  ── 倒角处细实线也应画出

端视图（垂直轴线方向）：
  ── 大径（粗实线圆，完整圆）
  ── 小径（细实线圆，只画 3/4 圈）
  ── 倒角投影圆（省略不画）
```

**内螺纹画法**（通常画成剖视图）:
```
剖视图（平行轴线方向）：
  ── 小径（粗实线，上下两条）
  ── 大径（细实线，上下两条，在小径外侧）
  ── 螺纹终止线（粗实线，垂直于轴线）
  ── 剖面线画到粗实线（小径）处

端视图（垂直轴线方向）：
  ── 小径（粗实线圆，完整圆）
  ── 大径（细实线圆，只画 3/4 圈）
  ── 倒角投影圆（省略不画）
```

**内外螺纹连接画法**:
- 结合部分按**外螺纹**画法（大径粗实线、小径细实线）
- 未结合部分各自按原画法

**螺纹标注格式**:
```
普通螺纹：M 公称直径 × 螺距 - 公差带代号 - 旋合长度代号
           M20×1.5-6H （粗牙省略螺距：M20-6g）
梯形螺纹：Tr 公称直径 × 导程(P螺距) - 公差带代号
           Tr40×14(P7)LH-7e （LH表示左旋）
管螺纹：  G/Rp/Rc 1/2 （55°非密封/密封管螺纹，尺寸代号为英寸）
```

### 4.2 齿轮画法（GB/T 4459.2）

**圆柱齿轮画法规则**:
```
齿顶圆（da）→ 粗实线
分度圆（d）  → 细点画线（CENTER）
齿根圆（df）→ 细实线（可省略不画）

主视图（轴线水平）：
  齿顶圆投影 → 粗实线
  齿根圆投影 → 细实线（可省略）
  分度圆投影 → 细点画线

剖视图（沿轴线剖切）：
  轮齿部分按不剖处理（不画剖面线）
  齿顶线和齿根线均用粗实线
  分度线用细点画线

端视图（垂直轴线）：
  齿顶圆 → 粗实线圆
  分度圆 → 细点画线圆
  齿根圆 → 细实线圆（可省略）
```

**齿轮啮合画法**:
```
主视图（非剖视）：
  啮合区的齿顶圆均省略不画
  啮合区的分度圆相切（一条粗实线）

主视图（剖视）：
  一个齿轮的齿顶用粗实线
  另一个齿轮的齿顶用虚线（或省略）
  啮合区分度线用点画线

端视图：
  啮合区的齿顶圆可省略
  分度圆相切
```

### 4.3 弹簧画法（GB/T 4459.4）

**螺旋压缩弹簧画法**:
- 各圈的轮廓画成**直线**（而非螺旋线）
- 可画成右旋，左旋需注明"左"字
- 如要求两端并紧且磨平，不论实际支承圈数多少，均按标准形式绘制
- 有效圈数在 4 圈以上的，中间部分可省略，允许适当缩短图形长度
- 被弹簧挡住的结构一般不画出

**螺旋弹簧简化**:
```
视图（不剖）： 画成直线轮廓
剖视图：      只画弹簧丝截面（小圆或涂黑），中间部分可省略
示意图：      用单线表示弹簧的行程范围
```

### 4.4 花键画法（GB/T 4459.3）

**矩形花键**:
```
外花键（花键轴）：
  大径 → 粗实线
  小径 → 细实线
  工作长度终止线和尾部长度末端均用粗实线

内花键（花键孔，剖视）：
  大径 → 细实线
  小径 → 粗实线

花键连接（剖视）：
  连接部分按外花键画法
```

**花键标注格式**: N×d×D×B（齿数×小径×大径×齿宽）

### 4.5 中心孔表示法（GB/T 4459.5）

- 中心孔符号为 60° 三角形，尖端向内
- 在轴端用细实线引出标注
- 标注格式：中心孔类型 + 规格尺寸
- 不需保留的中心孔可省略标注

## 第五章 尺寸标注课本级规则（GB/T 4458.4 / ISO 129-1）

### 5.1 尺寸标注基本原则

| 原则 | 说明 |
|------|------|
| **正确性** | 尺寸数值必须正确，标注方法符合国标 |
| **完整性** | 所需尺寸齐全，不遗漏、不重复 |
| **清晰性** | 配置合理、排列整齐、便于读图 |
| **合理性** | 符合设计要求和工艺要求 |

### 5.2 尺寸标注课本级要点

1. **功能尺寸直接标注**: 零件的重要功能尺寸（配合尺寸、装配尺寸）必须直接标注，不可通过间接计算获得
2. **避免封闭尺寸链**: 一组相关尺寸不要形成封闭链（即不要把所有段都标全），留一个最不重要的段不标（开环），由其他尺寸间接保证
3. **相关尺寸集中标注**: 同一结构要素的尺寸应尽可能集中标注在同一视图上
4. **标注在特征最清晰的视图上**: 尺寸应标注在最能反映该特征形状的视图上
5. **内形尺寸与外形尺寸分开标注**: 避免尺寸线和尺寸界线交叉
6. **小尺寸靠近，大尺寸在外**: 尺寸线间距 ≥ 7mm，首道尺寸线与轮廓间距 ≥ 10mm

### 5.3 常见标注格式

| 标注类型 | 格式 | 示例 |
|---------|------|------|
| 倒角（45°） | C+数字 | C2（2×45°倒角） |
| 倒角（非45°） | 宽度×角度 | 1.5×30° |
| 退刀槽 | 槽宽×槽深 或 槽宽×直径 | 3×1 或 3×Φ10 |
| 砂轮越程槽 | 槽宽×槽深 | 2×0.5 |
| 键槽深度 | 槽深（从外圆到槽底） | 标注 d-t 或直接标注深度值 |
| 均布要素 | 数量×规格 + EQS/均布 | 6×M10 EQS |
| 沉孔/锪平 | 沉孔直径×深度 | 4×Φ10沉孔Φ16深3 |
| 埋头孔 | 埋头孔角度×大径 | 4×Φ8埋头孔90°Φ14 |

## 第六章 典型零件表达方案详解

### 6.1 轴类零件

**结构特点**: 主要由同轴圆柱面组成，可有键槽、退刀槽、中心孔、砂轮越程槽、螺纹等
**主视图选择**: 按加工位置原则，轴线水平放置
**视图配置**:
- 主视图：水平放置，表达各段直径、长度、键槽、螺纹
- 断面图：移出断面图表达键槽深度（配置在剖切线延长线上）
- 局部放大图：退刀槽/砂轮越程槽/螺纹牙型的细节放大
- 中心线：必须在主视图上画出轴线（CENTER 图层）

**尺寸标注要点**:
- 径向尺寸以轴线为基准
- 轴向尺寸以重要端面（装配基准面）为主要基准
- 键槽尺寸集中标注在断面图附近
- 退刀槽/砂轮越程槽用局部放大图标注

### 6.2 盘类零件

**结构特点**: 主要由同轴圆柱面和端面组成，常有均布孔、键槽、轮辐等
**主视图选择**: 按加工位置原则（非圆视图作主视图）或形状特征原则（圆形端面视图作主视图）
**视图配置**:
- 方案A: 主视图（圆形端面视图，表达均布孔分布） + 全剖侧视图（表达内孔台阶和键槽）
- 方案B: 主视图（全剖非圆视图，表达内孔结构） + 端面视图（表达均布孔分布）

### 6.3 箱体类零件

**结构特点**: 内外结构复杂，常有轴承孔、安装法兰、加强筋、观察孔等
**主视图选择**: 按工作位置原则（底面朝下）
**视图配置**: 主视图 + 俯视图 + 左视图 + 局部剖/断面图
- 至少需要 3 个基本视图
- 内部结构用全剖或阶梯剖表达
- 局部结构用局部剖或局部放大图补充

### 6.4 叉架类零件

**结构特点**: 形状不规则，由工作部分、支撑部分和连接部分组成
**主视图选择**: 按工作位置原则或形状特征原则
**视图配置**: 主视图 + 俯视图/左视图 + 局部剖
- 支撑孔用局部剖表达
- 连接部分用断面图表达截面形状
- 倾斜部分用斜视图或斜剖表达

## 第七章 视图表达方法的优先级（课本总结）

### 7.1 表达方法选择优先级

```
1. 基本视图（主/俯/左/右/仰/后）       ← 首选
2. 全剖视图                             ← 内形为主的不对称件
3. 半剖视图                             ← 对称件且内外形都需表达
4. 局部剖视图                           ← 最灵活，适用面最广
5. 移出断面图                           ← 表达截面形状（轴类键槽/肋板）
6. 局部放大图                           ← 细小结构放大表达
7. 斜视图                               ← 倾斜结构表达
8. 重合断面图                           ← 简单截面形状
```

### 7.2 虚线使用原则

- **尽量避免虚线**: 在不致引起误解时，不画虚线表示不可见结构
- **虚线的合理使用**:
  - 仅当虚线能**减少视图数量**时才画（即不画虚线就需要增加一个视图）
  - 虚线不能形成封闭线框（除非必要）
  - 虚线与实线、点画线不得重合
- **课本原则**: 能用实线（通过剖视/断面）表达的不用虚线
