## 1. 图幅与图框（ISO 5457）

### 1.1 标准图幅尺寸（单位：mm）

| 代号 | 宽×高       | 图框外框   | 留装订边内框                  | 不留装订边内框              |
|------|-------------|-----------|--------------------------------------|----------------------------|
| A0   | 1189×841   | 0,0→1189,841 | 左25,下10,右10,上10 → 内1154×821  | 四边各10 → 内1169×821      |
| A1   | 841×594    | 0,0→841,594  | 左25,下10,右10,上10 → 内806×574  | 四边各10 → 内821×574       |
| A2   | 594×420    | 0,0→594,420  | 左25,下10,右10,上10 → 内559×400  | 四边各10 → 内574×400       |
| A3   | 420×297    | 0,0→420,297  | 左25,下5,右5,上5  → 内390×287   | 四边各5  → 内410×287       |

```

```

## 2. 标题栏（ISO 7200）

### 2.1 ISO 7200 标准标题栏布局

ISO 7200 标题栏与 GB/T 10609.1 结构类似，但字段名称为英文：

```
总宽：180mm，总高：56mm
分区：
  ┌─────────────────────────────────────────────┐
  │ 更改区(80×32)       │  签字区(100×32)         │
  ├─────────────────────────────────────────────┤
  │ Part no. │ Designation │ Material │ Phase │ Mass │ Remark │
  │   20     │     60      │    30    │  20   │  15  │  35    │（宽mm）
  ├─────────────────────────────────────────────┤
  │  Drawing No.(100×14)          │ Scale(40×14) │   │
  ├─────────────────────────────────────────────┤
  │  Organization(100×14)         │ Sheet(40×14) │   │
  └─────────────────────────────────────────────┘
行高：8mm（各行）
```

### 2.2 ISO 标题栏标准字段

| 字段 | ISO 7200 英文 | GB/T 10609.1 中文 | 文字高度(mm) |
|------|--------------|-------------------|-------------|
| 图样名称 | Designation | 图样名称 | 5 |
| 图号 | Drawing No. | 图号 | 5 |
| 比例 | Scale | 比例 | 3.5 |
| 材料 | Material | 材料 | 3.5 |
| 单位 | Organization | 单位名称 | 3.5 |
| 设计 | Designed by | 设计 | 2.5 |
| 审核 | Checked by | 审核 | 2.5 |
| 图幅 | Size | 图幅 | 3.5 |
| 投影 | Projection | 投影 | 3.5 |
| 共X张第X张 | Sheet X of Y | 共X张第X张 | 2.5 |

### 2.3 投影方式标注

ISO 标题栏必须标注投影方式：
- 第一角投影：标注 "1st Angle" 或绘制第一角投影符号
- 第三角投影：标注 "3rd Angle" 或绘制第三角投影符号

## 5. 尺寸标注规范（ISO 129-1）

### 5.1 核心规则

1. **尺寸线**：平行于被测要素，两端画箭头（实心箭头，长约3.5mm，宽约1.5mm）
2. **尺寸界线**：垂直于尺寸线，超出尺寸线约2mm，与轮廓线留约2mm间距
3. **尺寸数字**：
   - 位于尺寸线**上方中间**（水平）或**左侧**（垂直）
   - 水平标注：数字朝上
   - 垂直标注：数字朝左
   - 不得被任何图线穿过
4. **角度数字**：水平书写，位于尺寸线外侧
5. **直径标注**：数字前加"Ø"（ISO），如"Ø50"
6. **半径标注**：数字前加"R"，如"R25"
7. **尺寸排列**：小尺寸靠近轮廓，大尺寸在外侧
8. **总尺寸**：应标注

### 5.2 ISO vs GB 尺寸前缀对照

| 含义 | ISO 129-1 | GB/T 4458.4 |
|------|-----------|-------------|
| 直径 | Ø | Φ |
| 半径 | R | R |
| 球径 | SØ | SΦ |
| 球半径 | SR | SR |
| 板厚 | t | t |
| 正方形 | □ | □ |
| 弧长 | ⌒ | ⌒ |
| 参考尺寸 | () | () |

> **重要**：ISO 标准使用 Ø 表示直径，GB 标准使用 Φ。Agent 需根据 `standard` 字段选择正确前缀。

### 5.3 尺寸标注最小间距

- 两道平行尺寸线之间：≥7mm
- 尺寸线距最近轮廓线：≥10mm（首道）

## 6. 公差与配合标注（ISO 286 / ISO 1101）

### 6.1 ISO 配合制标注

ISO 286 配合制与 GB/T 1800 完全一致：

```
Ø50H7/h6 — 基孔制间隙配合
Ø60H7/p6 — 基孔制过盈配合
Ø45H7/k6 — 基孔制过渡配合
Ø30JS7/h6 — 基轴制过渡配合
```

### 6.2 形位公差框格（ISO 1101）

ISO 1101 与 ASME Y14.5 形位公差符号基本一致，与 GB/T 1182 规定相同：

```
┌───┬───────┬───┐
│ ⊥ │ 0.05  │ A │
└───┴───────┴───┘
第1格：特征符号（高5mm）
第2格：公差值（如 0.05，可加 Ø/Ⓔ 等修饰符）
第3格（可选）：基准代号（如 A）
框格高度：8mm，宽度：各列自适应
```

### 6.3 ISO 1101 / ASME Y14.5 特征符号对照

| 特征 | ISO 1101 符号 | ASME Y14.5 符号 | 说明 |
|------|-------------|----------------|------|
| 直线度 | ─ | ─ | 相同 |
| 平面度 | □ | □ | 相同 |
| 圆度 | ○ | ○ | 相同 |
| 圆柱度 | ⌭ | ⌭ | 相同 |
| 平行度 | ∥ | ∥ | 相同 |
| 垂直度 | ⊥ | ⊥ | 相同 |
| 倾斜度 | ∠ | ∠ | 相同 |
| 位置度 | ↗ | ⊕ | ASME 用靶心符号 |
| 同轴度 | ⊙ | ⊙ | ISO 用同心圆 |
| 对称度 | ≡ | ≡ | 相同 |
| 圆跳动 | ∿ | ∿ | 相同 |
| 全跳动 | ∭ | ∭ | 相同 |

### 6.4 ISO 1101 基准符号

ISO 1101 基准符号与 GB/T 1182 格式相同：
- 粗实线方框 + 大写字母 + 细实线连线 + 实心三角形
- ASME Y14.5 基准符号略有不同（方框内字母，下方连线至特征）

## 7. 表面粗糙度（ISO 1302 / ISO 21920）

### 7.1 ISO 1302 粗糙度符号

```
基本符号（去除材料）：
        √
       / \
      /   \
（两条线夹角60°，高约4mm）

完整符号结构：
   a
  √
 / b
c  d
   e

a = Ra 值 (如 Ra1.6, Ra3.2, Ra6.3) 或 Ra + Rz
b = 加工方法 (如 "turned", "ground")
c = 取样长度
d = 加工纹理方向
e = 加工余量
```

### 7.2 ISO vs GB 粗糙度标注对照

| 项目 | ISO 1302 | GB/T 131 |
|------|----------|----------|
| 评价参数 | Ra, Rz | Ra, Rz |
| 符号体系 | 相同（GB 等同采用 ISO 1302） | 相同 |
| 常用 Ra 值 | 0.8, 1.6, 3.2, 6.3, 12.5 μm | 相同 |
| 标注格式 | Ra 1.6 或 1.6 Ra | Ra1.6 |

### 7.3 ISO 21920（2021 新标准）

ISO 21920 取代了 ISO 1302 的部分内容，但基本符号体系不变。主要变化：
- 更详细的滤波规则
- 新增参数（如 Rk, Rpk, Rvk）
- 与 GPS（产品几何技术规范）标准体系整合

## 9. 螺纹表示法（ISO 6410）

### 9.1 ISO 螺纹画法

**外螺纹（external thread）**：
- 大径（牙顶）：粗实线
- 小径（牙根）：细实线，约 0.85 × 大径
- 终止线：粗实线（垂直轴线）
- 剖面中：牙根线用细实线圆弧（右边3/4圆弧，留缺口）

**内螺纹（internal thread）**：
- 大径（牙根）：细实线虚线
- 小径（牙顶）：粗实线
- 终止线：粗实线

### 9.2 ISO 螺纹标注格式（ISO 6410 / ISO 261/262）

| 螺纹类型 | ISO 标注 | GB 标注 | 说明 |
|---------|---------|--------|------|
| 普通粗牙螺纹 | M20 | M20 | 相同 |
| 普通细牙螺纹 | M20×1.5 | M20×1.5 | 相同 |
| 管螺纹 | G1/2 | G1/2 | 相同 |
| 梯形螺纹 | Tr32×6 | Tr32×6 | 相同 |
| 公差等级（内） | M20×1.5-6H | M20×1.5-6H | 相同 |
| 公差等级（外） | M20×1.5-6g | M20×1.5-6g | 相同 |

## 10. 第一/第三角投影（ISO 128-1）

### 10.1 投影方式概述

| 投影方式 | ISO 标准 | 视图关系 | 主要使用地区 |
|---------|---------|---------|------------|
| 第一角投影 | ISO 128-1（默认） | 物体在投影面与观察者之间 | 中国、欧洲、俄罗斯 |
| 第三角投影 | ISO 128-1 / ASME Y14.3 | 投影面在物体与观察者之间 | 美国、日本、加拿大、英国 |

### 10.2 第一角投影布局

```
          ┌──────────────────────────────┐
          │  俯视图(从上方看)             │
          │  (在主视图上方)               │  ← 这是错误的！
          └──────────────────────────────┘  第一角中俯视图在下方！

正确的第一角投影布局：

┌──────────┐  ┌──────────┐
│  主视图   │  │  左视图   │
│ (Front)  │  │(从左看)   │  ← 左视图在主视图右方
└──────────┘  └──────────┘
     ↕
┌──────────┐
│  俯视图   │
│(从上方看) │  ← 俯视图在主视图下方
└──────────┘
```

### 10.3 第三角投影布局

```
          ┌──────────┐
          │  俯视图   │  ← 俯视图在主视图上方
          │(从上方看) │
          └──────────┘
               ↕
┌──────────┐  ┌──────────┐
│  左视图   │  │  主视图   │  ← 左视图在主视图左方
│(从左看)   │  │ (Front)  │
└──────────┘  └──────────┘
```

### 10.4 投影符号

**第一角投影符号**（截锥体）：
```
     ┌─────────────────────┐
     │     ┌───┐           │
     │     │ ○ │  ← 俯视图│
     │     └───┘           │
     │                     │
     │  ┌───┐    ┌───┐    │
     │  │(○)│    │ ○ │    │
     │  └───┘    └───┘    │
     │  左视图   右视图    │
     └─────────────────────┘
```

**第三角投影符号**（截锥体）：
```
     ┌─────────────────────┐
     │  ┌───┐    ┌───┐    │
     │  │ ○ │    │(○)│    │
     │  └───┘    └───┘    │
     │  左视图   右视图    │
     │                     │
     │     ┌───┐           │
     │     │ ○ │  ← 俯视图│
     │     └───┘           │
     └─────────────────────┘
```

> 简化绘制：用同心圆表示俯视图，全圆表示左/右视图。

## 14. LLM Agent 生成 ISO 图纸的核心原则

生成任何 ISO 标准图纸时，Agent **必须**检查以下规则：

1. **图幅优先**：先确定图幅（A0-A4），再在对应图框内布图
2. **投影方式**：必须在 spec 中声明 `projection` 字段，在标题栏中标注投影方式
3. **图层分配**：每种线型必须使用对应图层
4. **线宽规范**：轮廓线 0.5mm，尺寸线 0.25mm
5. **中心线必画**：圆形和对称零件必须画中心线
6. **尺寸完整**：每个重要尺寸都应标注
7. **标题栏必填**：必须生成标题栏，包含图号、名称、比例、材料、投影方式
8. **直径前缀**：ISO 用 Ø，GB 用 Φ
9. **剖面填充**：金属剖视用 ANSI31
10. **投影符号**：必须绘制投影方式符号
11. **技术要求**：国际场景使用英文
12. **单位**：所有尺寸默认 mm

## 15. 国际场景适配清单（v10.0 更新）

当用户指定"ISO"、"ASME"、"外贸"、"海外"等关键词时：

**★ ISO 国际场景（非 ASME）：**
- [ ] 标题栏使用 ISO 7200 格式（英文字段）
- [ ] **投影方式为第一角**（ISO 128-1 默认，除非用户明确指定第三角）
- [ ] 绘制**第一角投影符号**
- [ ] 直径前缀使用 Ø（非 Φ）
- [ ] 技术要求使用英文
- [ ] 通用公差引用 ISO 2768-mK
- [ ] 粗糙度标注符合 ISO 1302
- [ ] 形位公差符合 ISO 1101
- [ ] 螺纹标注符合 ISO 6410
- [ ] 标准引用使用 ISO 标准号（非 GB/T）

**ASME 美标场景（外贸至美国/日本）：**
- [ ] 标题栏使用英文字段
- [ ] **投影方式为第三角**（ASME Y14.3 默认）
- [ ] 绘制**第三角投影符号**
- [ ] 直径前缀使用 Ø
- [ ] 技术要求使用英文
- [ ] 形位公差符合 ASME Y14.5
