## 3. 三视图布局算法

### 3.1 输入参数

```
inner_left, inner_bottom = 内框左下角坐标
inner_right, inner_top = 内框右上角坐标
iw = inner_right - inner_left  # 内框宽
ih = inner_top - inner_bottom    # 内框高

part_w = 零件宽度（主视图水平方向）
part_h = 零件高度（主视图垂直方向）
part_d = 零件深度（俯视图垂直方向）

scale = 绘图比例
margin = 30  # 尺寸标注预留空间（每侧）
view_gap = 20  # 视图间距

# 各视图实际占用尺寸
main_w = part_w × scale + 2 × margin
main_h = part_h × scale + 2 × margin
top_w = part_w × scale + 2 × margin  # 俯视图宽度 = 主视图宽度
top_h = part_d × scale + 2 × margin  # 俯视图高度 = 零件深度
left_w = part_d × scale + 2 × margin  # 左视图宽度 = 零件深度
left_h = part_h × scale + 2 × margin  # 左视图高度 = 主视图高度
```

### 3.2 坐标计算步骤

```
步骤 1: 主视图位置
  front_x = inner_left + (iw - main_w - left_w - view_gap) / 2
  front_y = inner_top - 15 - main_h  (顶部留白15mm)

  # 验证: front_x ≥ inner_left + 5
  # 如果放不下，减小 scale 或选用更大图幅

步骤 2: 俯视图位置（主视图正下方）
  top_x = front_x  (与主视图左对齐 — "长对正")
  top_y = front_y - view_gap - top_h

步骤 3: 左视图位置（主视图正右方）
  left_x = front_x + main_w + view_gap
  left_y = front_y  (与主视图底部对齐 — "高平齐")

步骤 4: 验证
  # 所有视图不得超出内框
  assert top_x + top_w ≤ inner_right - 5
  assert left_x + left_w ≤ inner_right - 5
  assert top_y ≥ inner_bottom + 80  (技术要求区域)
  assert left_y ≥ inner_bottom + 5

步骤 5: 技术要求位置
  tech_x = inner_left + 15
  tech_y = inner_bottom + 10
  tech_w = 120
```

### 3.3 "长对正、高平齐、宽相等" 投影关系

```
长对正: 主视图和俯视图的 X 方向尺寸一致 → top_x = front_x
高平齐: 主视图和左视图的 Y 方向尺寸一致 → left_y = front_y
宽相等: 俯视图的深度 = 左视图的宽度 → top_h = left_w（不含标注预留）
```

## 4. 常见零件布局模板

### 4.1 阶梯轴类零件（A3 横幅）

```
主视图: 水平放置，轴线水平
断面图: 放在主视图下方或右侧
局部放大图: 放在右上角空白区域

布局:
  ┌─────────────────────────────┐
  │         主视图（水平轴）       │
  │  ←──────── 200mm ────────→ │
  └─────────────────────────────┘
       ↕ gap=20
  ┌──────────┐  ┌──────────────┐
  │ 断面图A-A │  │ 局部放大图 I │
  └──────────┘  └──────────────┘

技术要求区域: 左下角
标题栏: 右下角
```

### 4.2 法兰盘类零件（A3 横幅）

```
主视图: 圆形盘面（正面），居中偏左
左视图: 全剖视图，在主视图右方

布局:
  ┌──────────┐  ┌──────────┐
  │  主视图   │  │  A-A 剖  │
  │  (圆形)   │  │  (矩形)  │
  └──────────┘  └──────────┘

技术要求: 左下角
标题栏: 右下角
```

### 4.3 箱体类零件（A2 或 A1）

```
主视图: 正面外形
俯视图: 顶面外形（主视图下方）
左视图: 侧面全剖（主视图右方）
辅助剖: 如需要，放左视图下方

布局:
  ┌──────────┐  ┌──────────┐
  │  主视图   │  │  左视图   │
  │          │  │  (B-B剖)  │
  └──────────┘  └──────────┘
       ↕ gap=20
  ┌──────────┐  ┌──────────┐
  │  俯视图   │  │ 辅助剖视  │
  │          │  │  (C-C剖)  │
  └──────────┘  └──────────┘
```

## 5. 比例自动选择算法

```
计算零件最大外廓尺寸:
  max_dim = max(零件总宽, 零件总高, 零件总深)

可用绘图区域（三视图并排）:
  可用宽度 ≈ iw × 0.7  (留30%给标注和间距)
  可用高度 ≈ (ih - 56) × 0.6  (减标题栏，留40%)

估算所需图幅:
  if max_dim ≤ 100:  A4, scale = 1:1 或 2:1
  if max_dim ≤ 200:  A3, scale = 1:1
  if max_dim ≤ 400:  A3, scale = 1:2  或 A2, scale = 1:1
  if max_dim ≤ 600:  A2, scale = 1:2  或 A1, scale = 1:1
  if max_dim ≤ 1000: A1, scale = 1:2  或 A0, scale = 1:1
  if max_dim > 1000: A0, scale = 1:5  或 1:10
```

## 6. 坐标计算示例

### 示例：法兰盘 A3 图纸

已知:
- 零件外径 Φ100, 内径 Φ40
- 6×M10 螺栓孔 PCD Φ75
- 图幅 A3 有装订边: 内框 (25, 5) → (395, 292)
- scale = 1:1

计算:
```
inner_left = 25, inner_bottom = 5
inner_right = 395, inner_top = 292
iw = 370, ih = 287

# 主视图（圆形，直径100 + 标注预留30×2 = 160mm）
main_w = 160
main_h = 160

# 左视图（剖视图，矩形 100宽×20厚 + 标注预留）
left_w = 60 + 60 = 120  # (深度20 + 标注预留)
left_h = 160

# 主视图位置（居中偏左）
front_x = 25 + (370 - 160 - 120 - 20) / 2 = 25 + 35 = 60
front_y = 292 - 15 - 160 = 117

# 主视图中心 = (60+80, 117+80) = (140, 197)

# 左视图位置
left_x = 60 + 160 + 20 = 240
left_y = 117

# 技术要求位置
tech_x = 30
tech_y = 10

# 验证
# 左视图右边界: 240 + 120 = 360 < 395 ✓
# 主视图下边界: 117 > 5 + 80(技术要求) = 85 ✓
#   (实际 117 > 85 ✓, 但很紧凑 — 可能需要 scale=2:1 或更大图幅)
```

## 7. 第三角投影布局算法（v8.0 新增）

### 7.1 第三角投影视图关系

```
第三角投影法（美国/日本/加拿大标准）：
  俯视图（Top View）      在主视图正上方
  左视图（Left View）      在主视图正左方
  右视图（Right View）     在主视图正右方（可选）
  仰视图（Bottom View）    在主视图正下方（可选）
```

### 7.2 坐标计算步骤

```
步骤 1: 主视图位置（第三角投影）
  front_x = inner_left + left_w + view_gap + (iw - left_w - view_gap - main_w) / 2
  front_y = inner_bottom + 56 + 15 + main_h  (标题栏上方56mm + 留白15mm)

  # 注意：第三角投影中，左视图在主视图左方，需要先为左视图预留空间
  # front_x 的计算要考虑 left_w + view_gap 的左视图空间

步骤 2: 俯视图位置（主视图正上方）
  top_x = front_x  (与主视图左对齐 — "长对正")
  top_y = front_y + view_gap + top_h  (在主视图上方)

步骤 3: 左视图位置（主视图正左方）
  left_x = front_x - view_gap - left_w  (在主视图左方)
  left_y = front_y  (与主视图底部对齐 — "高平齐")

步骤 4: 验证
  assert left_x >= inner_left + 5
  assert top_y + top_h <= inner_top - 5
  assert front_x + main_w <= inner_right - 5
  assert front_y >= inner_bottom + 56 + 5  (标题栏区域)

步骤 5: 技术要求位置
  tech_x = inner_left + 15
  tech_y = inner_bottom + 10
```

### 7.3 第三角投影示例（法兰盘 A3 图纸）

```
已知:
- 零件外径 Ø100, 内径 Ø40
- 图幅 A3 有装订边: 内框 (25, 5) → (395, 292)
- scale = 1:1, projection = "third"

计算:
  inner_left = 25, inner_bottom = 5
  inner_right = 395, inner_top = 292
  iw = 370, ih = 287

  # 主视图（圆形，直径100 + 标注预留30×2 = 160mm）
  main_w = 160, main_h = 160
  # 左视图（剖视图）
  left_w = 120, left_h = 160

  # 第三角投影：左视图在主视图左方
  front_x = 25 + 120 + 20 + (370 - 120 - 20 - 160) / 2 = 25 + 140 + 35 = 200
  front_y = 5 + 56 + 15 + 160 = 236  (标题栏上方)

  # 俯视图在主视图上方
  top_x = 200
  top_y = 236 + 20 + 160 = 416 → 超出内框！(292)

  # 需要调整：使用更小比例或更大图幅
  # 方案1: scale = 1:2 → main_h = 80, top_h = 80
  # front_y = 5 + 56 + 15 + 80 = 156
  # top_y = 156 + 20 + 80 = 256 < 292 ✓

  # 方案2: 使用 A2 图幅
  # A2 内框: (25, 10) → (584, 410), iw=559, ih=400
  # 更充裕的布局空间
```

## 8. 投影方式选择策略（v10.0 ★ 第一角投影为默认）

```
根据用户指定或场景自动选择投影方式：

★ 默认规则（无指定时）→ 第一角投影（ISO 128-1 / GB/T 17451）

1. 用户明确指定 "第一角"/"first angle"/"ISO"/"GB"/"国内"/"欧洲" → 第一角投影
2. 用户明确指定 "第三角"/"third angle"/"ASME"/"美标" → 第三角投影
3. 用户指定 standard="GB" → 第一角投影（中国国家标准）
4. 用户指定 standard="ISO" 且未指定投影 → 第一角投影（ISO 默认）
5. 用户指定 standard="ASME" → 第三角投影（美国标准）
6. 用户未指定标准 → 第一角投影（GB/ISO 默认，中国/欧洲通用）

场景关键词自动切换：
- "外贸"/"出口"/"美国客户"/"美标" → 第三角投影
- "日本客户"/"JIS" → 第三角投影（JIS B 0001）
- "欧洲客户"/"国内"/"国标"/"GB" → 第一角投影
- "英制"/"inch"/"ANSI" → 第三角投影（ANSI/ASME 默认，可指定第一角）
- 未指定任何场景 → 第一角投影（最保守默认）

严禁：
- 不得无依据地自动切换到第三角投影
- 不得忘记在标题栏中标注投影方式
- 不得遗漏投影符号
```

## 9. 第一角投影布局算法（v10.0 ★ 主要算法）

### 9.1 第一角投影视图关系

```
第一角投影法（中国/欧洲 ISO/GB 标准）：
  主视图（Front View）     居中偏左
  俯视图（Top View）       在主视图正下方
  左视图（Left View）      在主视图正右方
  右视图（Right View）     在主视图正左方（可选）
  仰视图（Bottom View）    在主视图正上方（可选）

投影关系：
  长对正: 主视图和俯视图的 X 方向尺寸一致 → top_x = front_x
  高平齐: 主视图和左视图的 Y 方向尺寸一致 → left_y = front_y
  宽相等: 俯视图的深度 = 左视图的宽度 → top_h ≈ left_w（不含标注预留）
```

### 9.2 坐标计算步骤（第一角投影，默认）

```
步骤 1: 主视图位置（第一角投影）
  front_x = inner_left + (iw - main_w - left_w - view_gap) / 2
  front_y = inner_top - 15 - main_h  (顶部留白15mm)

  # 验证: front_x ≥ inner_left + 5

步骤 2: 俯视图位置（主视图正下方 ★ 第一角投影）
  top_x = front_x  (与主视图左对齐 — "长对正")
  top_y = front_y - view_gap - top_h

步骤 3: 左视图位置（主视图正右方 ★ 第一角投影）
  left_x = front_x + main_w + view_gap
  left_y = front_y  (与主视图底部对齐 — "高平齐")

步骤 4: 验证
  assert top_x + top_w ≤ inner_right - 5
  assert left_x + left_w ≤ inner_right - 5
  assert top_y ≥ inner_bottom + 80  (技术要求区域预留)
  assert left_y ≥ inner_bottom + 5

步骤 5: 技术要求位置
  tech_x = inner_left + 15
  tech_y = inner_bottom + 10
  tech_w = 120
```
