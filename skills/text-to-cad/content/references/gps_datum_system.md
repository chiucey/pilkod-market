## 1. ISO 8015 几何产品规范（GPS）基础原则

### 1.1 GPS 基本原则

ISO 8015 定义了技术图样中尺寸和公差标注的基础原则：

1. **独立原则 (Envelop Principle)**：尺寸公差和形位公差相互独立，除非有特别规定
2. **缺省规则**：默认采用独立原则
3. **相关要求**：当需要时，可用 (E) 包容要求、(M) 最大实体要求、(L) 最小实体要求
4. **基准体系**：所有几何公差和尺寸公差应尽可能从统一的基准体系出发

### 1.2 基准体系三平面系统

根据 ISO 5458 / ASME Y14.5，基准体系由三个相互垂直的基准平面组成：

```
        ┌─────────────────────┐
        │      第三基准 C       │
        │    (辅助定位面)       │
        └─────────────────────┘
              ↑
              │
    ┌─────────┼─────────┐
    │         │         │
    │  主基准A ←→ 副基准B  │
    │ (底面)   (侧面)  │
    └─────────────────────┘
```

| 基准级别 | 代号 | 功能 | 典型选择 |
|---------|------|------|---------|
| 主基准 A | △-A | 主要定位基准 | 最大装配面、底面、主要加工面 |
| 副基准 B | △-B | 次要定位基准 | 关键侧面、导向面、对齐面 |
| 第三基准 C | △-C | 辅助定位基准 | 端面、止推面、防转面 |

## 2. 基准链闭环标注（ISO 5458 / ASME Y14.5）

### 2.1 基准链标注原则

**核心规则：所有尺寸必须从基准出发，形成封闭的尺寸链。**

```
基准A ──→ 尺寸1 ──→ 特征1
  │                         │
  └──→ 尺寸2 ──→ 特征2 ────┘ (回到基准A)
```

### 2.2 尺寸链分类

| 尺寸链类型 | 特点 | 适用场景 |
|-----------|------|---------|
| 增环链 | 各环方向一致，公差累加 | 简单线性尺寸 |
| 共面链 | 从同一基准出发的并行尺寸 | 多孔组、多台阶 |
| 闭环链 | 从基准出发回到基准 | 精密配合件 |
| 角度链 | 角度尺寸组成的链 | 锥面、斜面 |

### 2.3 尺寸链公差累加计算

```
闭环公差 = 各组成环公差之和（完全互换法）
T_closed = T1 + T2 + T3 + ... + Tn

例：A → B(50±0.05) → C(30±0.03) → A
    闭环公差 = ±0.05 + ±0.03 = ±0.08

建议：将公差分配到最不重要的环上
```

### 2.4 基准链标注示例

**阶梯轴基准链标注：**
```
基准A(右端面) ──→ 40h11 ──→ 台阶面1 ──→ 60h10 ──→ 台阶面2 ──→ 30h9 ──→ 基准A
              ←──────────────── 总长 130 ───────────────────→
```

**法兰盘孔组基准链：**
```
基准C(中心轴线) ──→ PCD Ø75 ±0.1 ──→ 6×M10(均布)
基准A(底面) ──→ 25 ±0.05 ──→ 孔深
```

## 4. ISO 2768 通用公差等级

### 4.1 等级分类

| 等级 | 说明 | 线性公差范围 | 适用场景 |
|------|------|-------------|---------|
| f | 精密 (fine) | ±0.05~±0.8 | 精密机械、仪表 |
| m | 中等 (medium) | ±0.1~±2.0 | 一般机械加工 ★最常用 |
| c | 粗糙 (coarse) | ±0.2~±4.0 | 粗加工、冲压 |
| v | 很粗糙 (very coarse) | ±0.5~±8.0 | 粗加工、焊接件 |

### 4.2 ISO 2768-mK 标注含义

- **m**: 线性尺寸和倒角用中等精度等级
- **K**: 包含形位公差（直线度、平面度、垂直度、对称度）

## 5. ASME Y14.5 尺寸公差标准（v9.0 新增）

### 5.1 ASME Y14.5 与 ISO 1101 对应关系

| ASME Y14.5 | ISO 1101 | 名称 |
|-----------|----------|------|
| Straightness | Straightness | 直线度 |
| Flatness | Flatness | 平面度 |
| Circularity | Circularity | 圆度 |
| Cylindricity | Cylindricity | 圆柱度 |
| Perpendicularity | Perpendicularity | 垂直度 |
| Angularity | Angularity | 倾斜度 |
| Parallelism | Parallelism | 平行度 |
| Position | Position | 位置度 |
| Concentricity | Concentricity | 同轴度 |
| Symmetry | Symmetry | 对称度 |
| Circular Runout | Circular Runout | 圆跳动 |
| Total Runout | Total Runout | 全跳动 |
| Profile of a Line | Profile of any line | 线轮廓度 |
| Profile of a Surface | Profile of any surface | 面轮廓度 |

### 5.2 ASME Y14.5 基准修饰符

| 修饰符 | 含义 | 适用场景 |
|-------|------|---------|
| (M) MMC | 最大实体状态 | 保证可装配性 |
| (L) LMC | 最小实体状态 | 保证最小壁厚 |
| (RFS) | 不考虑实体状态 | ASME 默认 |
| (P) 延伸公差带 | 螺栓孔等贯穿特征 |

### 5.3 ASME Y14.5 尺寸标注惯例

- 默认使用第三角投影
- 尺寸单位：inch 或 mm（图纸上必须注明）
- 直径符号使用 Ø（与 ISO 相同）
- 角度单位：度（°）
- 基准符号：实心三角形（ISO 1101 为空心三角形）
- 基准顺序从左到右：A-B-C

## 7. 干涉检查标准（v9.0 新增）

### 7.1 装配干涉检查流程

```
1. 识别所有配合面及其公差带
2. 计算 MMC/LMC 条件下的极限配合状态
3. 检查是否存在过盈干涉（间隙 < 0）
4. 检查运动部件的空间余量
5. 检查螺栓/销钉的安装空间
6. 输出干涉检查报告
```

### 7.2 干涉判定标准

| 配合类型 | 判定条件 | 处理 |
|---------|---------|------|
| 间隙配合 | Max clearance > 0, Min clearance ≥ 0 | ✓ 正常 |
| 间隙配合 | Min clearance < 0 | ✗ 干涉！需调整公差 |
| 过渡配合 | Max clearance > 0, Max interference > 0 | △ 需验证 |
| 过盈配合 | Max interference > 0 | ✓ 压入装配 |
| 过盈配合 | Max interference > 材料屈服强度 | ✗ 变形风险！|

## 10. ISO 7573 BOM 物料清单格式

### 10.1 ISO 7573 标准 BOM 字段

| 字段名 | 英文 | 说明 |
|-------|------|------|
| 序号 | Item | 零件顺序号 |
| 代号 | Part No. | 图号/零件编号 |
| 名称 | Description | 零件名称/规格 |
| 数量 | Qty | 装配数量 |
| 材料 | Material | 材料牌号 |
| 质量 | Mass (kg) | 单件质量 |
| 备注 | Notes | 备注/表面处理等 |
| 层级 | Level | 子组件层级（可选）|

### 10.2 BOM 排列规则

1. 按装配顺序从下往上排列（序号 1 在最下面）
2. 标题行在底部
3. 外边框使用粗实线
4. 内部分割线使用细实线
5. 复杂装配可分多列排列
