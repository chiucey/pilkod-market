# 上市企业级工程图纸管理规范

> 本文档定义符合 ISO 9001 / IATF 16949 质量管理体系要求的机械工程图纸企业级规范。
> 适用于上市制造企业的正式生产图纸，确保图纸在全生命周期（设计→审核→批准→量产→变更→归档）中受控。

---

## 第一章 图号编码体系（JB/T 5054.4 / 企业标准）

### 1.1 编码基本原则

| 原则 | 要求 |
|------|------|
| 唯一性 | 每个图样代号必须全局唯一，不可重复 |
| 简洁性 | 代码简短明了，便于记忆和检索 |
| 系统性 | 具有分类规律，体现隶属关系 |
| 扩展性 | 编码结构预留发展空间，不因产品扩展而失效 |
| 可溯性 | 从编号可直接追溯到产品/部件/零件的归属关系 |

### 1.2 隶属编号法（推荐用于机械制造企业）

**格式：** `企业代号-产品代号-部件级-零件序号-文件类型`

```
┌──────────┬──────────┬──────────┬──────────┬──────────┐
│ 企业代号   │ 产品代号   │ 部件/层级 │ 零件序号   │ 文件类型   │
│ (2-4位)  │ (2-6位)  │ (2-4位)  │ (2-3位)  │ (2位)    │
└──────────┴──────────┴──────────┴──────────┴──────────┘
```

**示例：**
- 总装图：`ABC-1000-00-00`（产品1000的总装配图）
- 一级部件图：`ABC-1000-01-00`（01号一级部件装配图）
- 二级部件图：`ABC-1000-01-02-00`（01号部件下的02号二级部件）
- 零件图：`ABC-1000-01-05`（01号部件下的05号零件）
- 零件图（带类型）：`ABC-1000-01-05-P`（05号零件，P=零件图）

### 1.3 分类编号法

**格式：** `分类特征代号-顺序号-设计文件尾注`

| 分类特征码 | 含义 |
|-----------|------|
| 0 | 零件（通用件/标准件/外购件） |
| 1 | 组件/部件 |
| 2 | 产品总成 |
| 3 | 图纸文件（装配图/零件图） |
| 4 | 工艺文件（工艺卡/作业指导书） |
| 5 | 检验文件（检验规范/检测报告） |

### 1.4 文件类型尾注码

| 尾注 | 含义 |
|------|------|
| 00 | 总图/装配图 |
| 01~99 | 零件图（顺序编号） |
| -M | 明细表/BOM |
| -T | 技术要求文件 |
| -W | 焊接图 |
| -S | 展开图 |

### 1.5 图号在标题栏中的填写

- 图号栏填写完整图号
- 图样名称栏填写零件/部件/产品名称
- 图样标记栏填写阶段标记（S=试制、A=小批、B=量产）

## 第二章 工程变更管理（ECN/ECO）

### 2.1 变更分级

| 级别 | 类型 | 审批要求 | 适用场景 |
|------|------|---------|---------|
| **EC1** | 重大变更 | 总工程师/技术总监审批 | 影响产品功能/安全/互换性的变更 |
| **EC2** | 一般变更 | 部门主管/技术经理审批 | 尺寸/公差/材料/工艺参数修改 |
| **EC3** | 微小变更 | 主管工程师审批 | 错别字修正、标注优化、非功能调整 |

### 2.2 变更流程

```
变更申请 → 技术评审 → 影响分析（BOM/工艺/工装/库存） → 审批
→ 图纸修改（修订版本号） → 更新受控文件清单 → 通知相关部门
→ 回收旧版图纸 → 发放新版图纸 → 验证确认 → 归档
```

### 2.3 版本号规则

- 初始版本：Rev A
- 首次修订：Rev B（小改）或 Rev A.1（微改）
- 大改版本号递增字母（A→B→C...），小改数字递增（A.0→A.1→A.2）
- 版本号在标题栏"版本"或"阶段标记"栏填写

### 2.4 更改记录栏

标题栏上方设置更改记录区，每行记录一次变更：

| 标记 | 处数 | 分区 | 更改文件号 | 签名 | 日期 |
|------|------|------|-----------|------|------|
| B | 3 | - | ECN-2026-045 | 张工 | 2026-05-19 |
| C | 1 | D3 | ECN-2026-078 | 李工 | 2026-06-15 |

## 第三章 签审流程（ISO 9001 / IATF 16949）

### 3.1 图纸签审权限

| 文件类型 | 编制（设计） | 校对 | 审核 | 标准化 | 批准 |
|---------|-----------|------|------|-------|------|
| 一般零件图 | 设计工程师 | 同级工程师 | 主管工程师 | - | 部门主管 |
| 关键零件图 | 高级工程师 | 主管工程师 | 技术经理 | 标准工程师 | 技术总监 |
| 装配图 | 主管工程师 | 高级工程师 | 技术经理 | 标准工程师 | 技术总监 |
| 总装图/系统图 | 技术经理 | 总工程师 | 技术总监 | 标准工程师 | 总经理 |

### 3.2 签审栏标准格式（标题栏右下区域）

```
┌─────────┬──────┬──────┐
│  编 制   │ 签名 │ 日期 │
├─────────┼──────┼──────┤
│  校 对   │ 签名 │ 日期 │
├─────────┼──────┼──────┤
│  审 核   │ 签名 │ 日期 │
├─────────┼──────┼──────┤
│  工 艺   │ 签名 │ 日期 │
├─────────┼──────┼──────┤
│  标准化  │ 签名 │ 日期 │
├─────────┼──────┼──────┤
│  批 准   │ 签名 │ 日期 │
└─────────┴──────┴──────┘
```

### 3.3 签审要点

- **校对**：核对尺寸链、公差配合、标准件规格、投影关系、视图完整性
- **审核**：评估结构合理性、工艺可行性、成本影响、与其他部件接口
- **工艺**：评估可加工性、加工顺序、工装需求
- **标准化**：检查是否符合国家/行业标准、企业标准、统一规范
- **批准**：最终确认，承担技术责任

## 第四章 检验标准引用体系

### 4.1 常用检验标准清单

| 标准号 | 标准名称 | 适用场景 |
|--------|---------|---------|
| GB/T 1804 | 一般公差 未注公差的线性和角度尺寸的公差 | 未注公差尺寸 |
| GB/T 1184 | 形状和位置公差 未注公差值 | 未注形位公差 |
| GB/T 2828.1 | 计数抽样检验程序 | 来料/成品抽检 |
| GB/T 11345 | 焊缝无损检测 超声波检测 | 焊缝质量 |
| GB/T 14211 | 机械密封 试验方法 | 密封件检验 |
| GB/T 9286 | 色漆和清漆 漆膜的划格试验 | 涂层附着力 |
| GB/T 10125 | 人造气氛腐蚀试验 盐雾试验 | 耐腐蚀性 |
| ISO 16232 | 道路车辆 清洁度 | 零件清洁度 |
| IATF 16949 | 汽车行业质量管理体系 | 汽车零部件供应商 |

### 4.2 零件图检验要求模板

```
检验要求:
1. 关键尺寸(CPK尺寸)用三坐标测量仪检测, CPK≥1.33
2. 未注尺寸公差按 GB/T 1804-m 验收
3. 未注形位公差按 GB/T 1184-K 验收
4. 表面粗糙度用粗糙度仪检测, Ra值不得大于图纸标注值
5. 硬度检测: 洛氏硬度计, 每批次抽检5件
6. 外观检验: 无裂纹、气孔、砂眼、碰伤等缺陷
7. 来料检验按 GB/T 2828.1, AQL=1.0
```

### 4.3 装配图检验要求模板

```
检验要求:
1. 装配后主轴径向圆跳动≤0.015mm (百分表检测)
2. 装配后同轴度≤0.05mm
3. 气密性试验: 压力0.6MPa, 保压5min, 无泄漏
4. 运转试验: 空载运行2h, 噪音≤75dB, 温升≤35℃
5. 关键配合面接触率: 涂色检查, 接触面积≥70%
```

### 4.4 CPK 尺寸标注

关键特性尺寸（Critical-to-Quality，CTQ）在图纸上标注：
- 用 **CTQ** 或 **★** 符号标识
- 技术要求中列出 CTQ 检验要求
- 量产时 CPK≥1.33，过程能力不足时需整改

## 第五章 材料规范与引用

### 5.1 材料标注标准格式

```
材料: 牌号 + 标准号 + 供货状态
示例: 45钢, GB/T 699-2015, 正火态
示例: 304不锈钢, GB/T 20878-2007, 固溶态
示例: 6061-T6铝合金, GB/T 3190-2020
示例: HT250灰铸铁, GB/T 9439-2010
示例: POM-C聚甲醛, ISO 9988-1
```

### 5.2 常用材料对照表

| 材料类别 | 常用牌号 | 标准号 | 典型应用 |
|---------|---------|--------|---------|
| 碳素结构钢 | Q235A/B, 45, 40Cr | GB/T 700, GB/T 699 | 通用结构件、轴、齿轮 |
| 合金钢 | 20CrMnTi, 42CrMo, 65Mn | GB/T 3077 | 齿轮、弹簧、高强度件 |
| 不锈钢 | 304, 316L, 420 | GB/T 20878 | 食品/化工/医疗 |
| 铸铁 | HT200, HT250, QT450-10 | GB/T 9439, GB/T 1348 | 箱体、阀体、支架 |
| 铝合金 | 6061-T6, 7075-T6 | GB/T 3190 | 航空/轻量化结构件 |
| 铜合金 | H62, QSn6.5-0.1 | GB/T 5231 | 导电件、耐磨件 |

### 5.3 材料替代规则

- 材料替代须提交 **材料代用申请单**
- 须经技术评审确认不影响产品性能
- 替代材料必须同等或优于原材料的力学性能
- 更新图纸材料栏和 BOM 表

## 第六章 环保与合规要求

### 6.1 环保法规合规

| 法规 | 适用范围 | 标注要求 |
|------|---------|---------|
| **RoHS** | 限制有害物质（铅/汞/镉/六价铬/PBB/PBDE） | 技术要求中注明"符合 RoHS 2.0" |
| **REACH** | 化学品注册评估授权 | 供应商需提供 SVHC 声明 |
| **ELV** | 汽车报废指令 | 出口欧洲汽车零件必须 |
| **WEEE** | 废弃电子电气设备 | 电子类/含电控部件 |

### 6.2 环保标注模板

**国内图纸：**
```
环保要求:
1. 本产品及所有零部件须符合 RoHS 2.0 指令要求
2. 材料中有害物质含量须符合 GB/T 26572-2011
3. 外协/外购件供应商须提供 RoHS 合格声明
4. 禁止使用含六价铬的表面处理工艺
```

**国际图纸：**
```
Environmental Compliance:
1. All materials shall comply with EU RoHS 2.0 Directive (2011/65/EU)
2. Supplier shall provide RoHS compliance declaration
3. No hexavalent chromium (Cr6+) surface treatment allowed
4. SVHC substances per REACH Article 33 must be declared
```

## 第八章 企业级技术要求增强模板

### 8.1 零件图技术要求（完整企业级）

```
技术要求
1. 材料: 45钢, GB/T 699-2015, 调质态, 硬度220-250HB
2. 未注尺寸公差按 GB/T 1804-m
3. 未注形位公差按 GB/T 1184-K
4. 未注表面粗糙度 Ra3.2μm
5. ★CTQ尺寸(带★标记): CPK≥1.33, 每100件抽检5件
6. 键槽对称度≤0.03mm(基准A)
7. 所有锐边倒钝C1.0, 去除毛刺飞边
8. 表面发黑处理, GB/T 15519
9. 零件不得有裂纹、气孔、砂眼等缺陷
10. 清洁度要求: 表面无油污、铁屑、杂质
11. 环保: 符合 RoHS 2.0 要求
12. 标记/刻字: 图号刻字于非配合面, 深0.3mm
13. 检验标准: 按本图标注尺寸及 GB/T 1804-m、GB/T 1184-K 验收
14. 包装: 单件 PE 袋包装, 防锈油涂抹, 纸箱内衬泡沫
```

### 8.2 装配图技术要求（完整企业级）

```
技术要求
1. 装配前所有零件须清洗干净, 无油污、铁屑, 清洁度达标
2. 关键配合尺寸: 轴孔配合 H7/g6, 轴承配合 H7/k6
3. 滚动轴承装配采用热装法, 加热温度≤120℃
4. 螺栓紧固: 从中间向两侧对称进行, 扭矩45-50N·m
5. 油封装配后无渗漏, 符合 GB/T 14211
6. 气密性试验: 0.6MPa, 保压5min, 无泄漏
7. 运转试验: 空载2h, 噪音≤75dB, 温升≤35℃
8. 装配后径向跳动≤0.015mm, 同轴度≤0.05mm
9. 涂装: 表面喷涂防锈漆, 颜色 RAL7035, 干膜厚≥60μm
10. 环保: 所有外购件须提供 RoHS 合格声明
```

### 8.3 按零件类型的技术要求速查

| 零件类型 | 必含技术要求 |
|---------|------------|
| 轴类 | 材料/热处理硬度/未注公差/配合面粗糙度/中心孔/去毛刺 |
| 齿轮 | 材料/热处理/齿面硬度/精度等级(GB 10095)/去毛刺 |
| 箱体 | 材料/时效处理/未注公差/密封面粗糙度/防水试验 |
| 法兰 | 材料/密封面粗糙度/螺栓孔均布精度/无损检测 |
| 钣金 | 材料厚度及标准/折弯半径/折弯角度公差/表面处理 |
| 弹簧 | 材料/有效圈数/工作载荷/自由高度/表面处理 |
| 焊接件 | 焊接材料/焊接方法/焊缝等级/探伤要求/焊后处理 |
