## 1. 图幅与图框（GB/T 14689）

### 1.1 标准图幅尺寸（单位：mm）

| 代号 | 宽×高       | 图框外框   | 留装订边（25mm）内框                  | 不留装订边内框              |
|------|-------------|-----------|--------------------------------------|----------------------------|
| A0   | 1189×841   | 0,0→1189,841 | 左25,下10,右10,上10 → 内1154×821  | 四边各10 → 内1169×821      |
| A1   | 841×594    | 0,0→841,594  | 左25,下10,右10,上10 → 内806×574  | 四边各10 → 内821×574       |
| A2   | 594×420    | 0,0→594,420  | 左25,下10,右10,上10 → 内559×400  | 四边各10 → 内574×400       |
| A3   | 420×297    | 0,0→420,297  | 左25,下5,右5,上5  → 内390×287   | 四边各5  → 内410×287       |
| A4   | 297×210    | 0,0→297,210  | 左25,下5,右5,上5  → 内267×200   | 四边各5  → 内287×200       |

**要点**：
- 图框用**粗实线（lineweight=50/0.5mm）** 绘制
- 图幅外框用**细实线（lineweight=0/0.18mm）** 绘制
- A0～A3 优先横放；A4 优先竖放
- 装订边固定在图纸**左侧**

### 1.2 标准图框生成规则（SKILL 必须遵守）

```
外框：rectangle(0, 0, W, H)，细实线
内框（有装订边）：rectangle(25, 5, W-30, H-10)，粗实线
内框（无装订边）：rectangle(10, 10, W-20, H-20)，粗实线
```

## 5. 尺寸标注规范（GB/T 4458.4）

### 5.1 核心规则

1. **尺寸线**：平行于被测要素，两端画箭头（实心箭头，长约3.5mm，宽约1.5mm）
2. **尺寸界线**：垂直于尺寸线，超出尺寸线约2mm，与轮廓线留约2mm间距
3. **尺寸数字**：
   - 位于尺寸线**上方中间**（水平）或**左侧**（垂直）
   - 水平标注：数字朝上
   - 垂直标注：数字朝左
   - 不得被任何图线穿过；若穿过，图线在数字处断开
4. **角度数字**：水平书写，位于尺寸线外侧
5. **直径标注**：数字前加"Φ"，如"Φ50"
6. **半径标注**：数字前加"R"，如"R25"
7. **尺寸排列**：小尺寸靠近轮廓，大尺寸在外侧（避免尺寸线交叉）
8. **总尺寸**：应标注，便于检验

### 5.2 尺寸标注最小间距

- 两道平行尺寸线之间：≥7mm
- 尺寸线距最近轮廓线：≥10mm（首道）

### 5.3 常用特殊符号（文字前缀）

| 含义     | 符号  | 示例       |
|----------|-------|-----------|
| 直径     | Φ     | Φ50       |
| 半径     | R     | R25       |
| 球径     | SΦ    | SΦ30      |
| 球半径   | SR    | SR15      |
| 板厚     | t     | t=5       |
| 正方形   | □     | □50       |
| 弧长     | ⌒     | ⌒50       |
| 参考尺寸 | ()    | (100)     |

## 7. 表面粗糙度符号（GB/T 1031、GB/T 131）

### 7.1 符号构成

```
基本符号（去除材料）：
        √
       / \
      /   \
（两条线夹角60°，高约4mm）

完整符号结构：
   a
  √
 / b
c  d
   e

a = Ra 值 (如 Ra1.6, Ra3.2, Ra6.3)
b = 加工方法 (如 "车", "磨")
c = 取样长度
d = 加工纹理方向
e = 加工余量
```

### 7.2 常用 Ra 值系列（μm）

`0.012, 0.025, 0.05, 0.1, 0.2, 0.4, 0.8, 1.6, 3.2, 6.3, 12.5, 25, 50, 100`

### 7.3 DXF 中表面粗糙度的绘制方法

由于 DXF 无内置粗糙度符号，用以下几何近似：
1. **基本符号**：两条线，以接触点为顶，夹角 60°，高 4mm
2. **水平延伸线**：从右侧斜线顶部延伸（约 3mm）
3. **Ra 文本**：在符号上方，字高 2.5mm，注明如 "Ra1.6"

```python
# 示例：在点(cx, cy)处绘制朝下粗糙度符号
h = 4  # 符号高度
w = h * math.tan(math.radians(60)) / 2  # 底部半宽
# 左斜线
line((cx - w, cy + h), (cx, cy))
# 右斜线
line((cx, cy), (cx + w, cy + h))
# 水平延伸
line((cx + w, cy + h), (cx + w + 3, cy + h))
# Ra 文字
text(f"Ra{ra_value}", (cx + w + 1, cy + h + 1.5), height=2.5)
```

## 8. 剖面线（剖视图）规范（GB/T 4457.5）

### 8.1 剖面符号

| 材料         | 剖面符号         | Hatch pattern |
|-------------|-----------------|--------------|
| 金属（通用） | 45°等间距细实线  | ANSI31       |
| 非金属（塑料等）| 双向45°格栅    | ANSI37       |
| 混凝土       | 砾石颗粒         | AR-CONC      |
| 木材（纵剖） | 平行纹理         | WOOD         |
| 液面         | 水平线           | LINE         |
| 玻璃         | 三行细线组       | GLASS        |
| 橡胶         | 黑色填充         | SOLID        |

### 8.2 剖面线规则

1. 间距：同一零件同一剖面，间距一致（推荐 2～4mm）
2. 角度：一般 45°，避免与主轮廓线平行/垂直
3. 同一零件多处剖面：方向、间距相同
4. 相邻零件剖面线：方向相反或间距不同

## 9. 机械制图特殊图元规范

### 9.1 螺纹表示法（GB/T 4459.1）

**外螺纹（shaft thread）**：
- 大径（牙顶）：粗实线
- 小径（牙根）：细实线，约 0.85 × 大径
- 终止线：粗实线（垂直轴线）
- 剖面中：牙根线用细实线圆弧（右边3/4圆弧，留缺口）

**内螺纹（hole thread）**：
- 大径（牙根）：细实线虚线
- 小径（牙顶）：粗实线
- 终止线：粗实线

**标注格式**：
- 普通螺纹：`M20×2.5-6H`（内）/ `M20×2.5-6g`（外）
- 管螺纹：`G1/2`
- 梯形螺纹：`Tr32×6`

### 9.2 键槽规范（GB/T 1095）

平键槽：宽度公差 `JS9`，深度公差 `P9`（轴槽）/ `N9`（孔槽）

标准平键尺寸（轴径→键宽×键高）：
```
Φ6-8   → 2×2    Φ8-10  → 3×3    Φ10-12 → 4×4
Φ12-17 → 5×5    Φ17-22 → 6×6    Φ22-30 → 8×7
Φ30-38 → 10×8   Φ38-44 → 12×8   Φ44-50 → 14×9
Φ50-58 → 16×10  Φ58-65 → 18×11  Φ65-75 → 20×12
```

### 9.3 中心孔标注（GB/T 4459.5）

A 型中心孔（60° 锥孔无护锥）：`A2/4.25`（导入孔径/锥口径）
B 型中心孔（60° 锥孔有护锥）：`B2/4.25`
R 型中心孔（弧形）：`R2.5`

### 9.4 倒角规范

- 一般倒角：`C1`（表示 1mm × 45°），需在图中标出
- 倒角线用细实线绘制
- 图样中书写：`1×45°` 或使用符号 `C1`

## 16. LLM Agent 生成图纸的核心原则（v10.0 ★）

生成任何 CAD 图纸时，Agent **必须**检查以下规则：

1. **图幅优先**：先确定图幅（A0-A4），再在对应图框内布图
2. **图层分配**：每种线型必须使用对应图层（不得全用 layer 0）
3. **线宽规范**：轮廓线 0.5mm，尺寸线 0.25mm，文字行 0.25mm
4. **中心线必画**：圆形和对称零件必须画中心线（CENTER 图层）
5. **尺寸完整**：图形中每个重要尺寸都应标注；不能让读者猜
6. **标题栏必填**：必须生成标题栏，包含图号、名称、比例、材料、单位、日期
7. **剖面填充正确**：金属剖视用 ANSI31（45°细线），间距约 3mm
8. **字体一致**：全图使用同一字族（height=3.5 为正文，height=5 为标题）
9. **★ 视图投影默认第一角投影**（GB/T 17451 / ISO 128-1 中国/欧洲标准）
   - 第一角投影：主视图居中，**俯视图在主视图正下方**，**左视图在主视图正右方**
   - 第三角投影（仅外贸/ASME 时使用）：俯视图在上方，左视图在左方
10. **比例标注**：图框外或标题栏内必须标明绘图比例
11. **技术要求**：国内图纸在左下角用**中文** mtext 写技术要求；外贸图纸用英文
12. **单位默认 mm**：所有尺寸默认单位毫米
13. **★ 铁律执行**：不得自主创意绘图、不得随意改尺寸、不得非标绘制
14. **★ 基准链闭环**：所有尺寸以基准体系为参考形成闭环，无孤立尺寸
15. **★ 双标准模式**：
    - 国内生产/默认：GB/T 10609.1 标题栏（中文字段）+ Φ 直径前缀
    - 外贸/ISO/国际：ISO 7200 标题栏（英文字段）+ Ø 直径前缀

## 18. 钣金展开图规范（v7.0 新增）

### 18.1 钣金折弯标注

- 折弯线用**双点画线（PHANTOM）**绘制
- 折弯方向用箭头标注（leader 指向）
- 折弯角度必须标注（dim_angular）
- 板厚必须标注
- 折弯半径必须标注

### 18.2 展开图标注要求

- 展开后所有直线尺寸必须标注
- 折弯区域用**波浪线（break_line）**标示
- 折弯补偿长度必须计算并标注
- 展开图比例应与成形图一致

### 18.3 折弯补偿计算公式

```
展开长度 L = Σ直线段 + Σ折弯补偿

折弯补偿 BA = π × (R + K × T) × θ / 180

其中:
  R = 折弯内半径（mm）
  K = K因子（材料中性层位置系数）
  T = 板厚（mm）
  θ = 折弯角度（°）

常用 K 因子参考:
  低碳钢:   K = 0.35 - 0.42
  不锈钢:   K = 0.40 - 0.45
  铝合金:   K = 0.33 - 0.40
  黄铜:     K = 0.35 - 0.40
  紫铜:     K = 0.35 - 0.40
```

### 18.4 钣金件技术要求（模板）

```
技术要求
1. 板厚: t=X mm, 材料: XX
2. 折弯半径: R=X mm, K因子: X.XX
3. 未注公差按 GB/T 1804-m
4. 表面处理: XX（如喷涂、镀锌、阳极氧化等）
5. 折弯处不得有裂纹
6. 去除毛刺，锐边倒钝
```

### 19.1 装配图视图选择

### 19.2 装配图画法规则

|------|------|
| 相邻零件区分 | 剖面线方向相反或间距不同 |

## 21. 一键重绘规范（v7.0 新增）

### 21.1 重绘操作类型

| 类型 | 说明 | 影响范围 |
|------|------|---------|
| 尺寸变更 | 修改某个/某些尺寸值 | 受影响视图的坐标重算 |
| 结构变更 | 增/删/改特征（孔、槽等） | 受影响视图重绘 |
| 工艺变更 | 修改材料、热处理、表面处理等 | 仅技术要求文字更新 |
| 比例变更 | 修改绘图比例 | 所有坐标重算 |
| 投影变更 | 修改投影方式（第一/第三角） | 所有视图坐标重算、投影符号更新 |
| 标准变更 | 修改标准体系（ISO↔GB） | 标题栏、尺寸前缀、技术要求文字更新 |

### 21.2 重绘流程

1. 提取变更项 → 在 spec JSON 中定位对应实体
2. 修改实体参数 → 重算受影响视图坐标
3. 验证所有视图不超出内框 → 如超出则自动调整比例或图幅
4. 重新生成 DXF
5. 输出变更摘要对比

## 23. ISO/GB 双标准对照速查（v10.0 强化）

### 23.1 核心差异对照

| 项目 | GB/T 国标（国内默认） | ISO 国际标准（外贸/国际） | 差异说明 |
|------|---------------------|------------------------|---------|
| 直径前缀 | **Φ**（φ） | **Ø**（斜杠O） | GB 用希腊大写 Phi，ISO 用带斜杠 O |
| 标题栏格式 | GB/T 10609.1（中文字段） | ISO 7200（英文字段） | 结构类似，字段名不同 |
| 投影默认 | **★ 第一角投影** | **★ 第一角投影** | 两者均默认第一角（美国 ASME 用第三角） |
| 技术要求 | 中文 | 英文 | 国际场景使用英文 |
| 粗糙度标注 | Ra1.6 | Ra 1.6 | GB 无空格，ISO 有空格 |
| 通用公差 | GB/T 1804-m | ISO 2768-mK | 标准号不同，等级基本一致 |
| BOM 明细表 | GB/T 10609.2（中文字段） | ISO 7573（英文字段） | 格式略有差异 |

### 23.2 投影方式统一说明（v10.0 ★ 重要）

| 投影方式 | GB/T 17451 | ISO 128-1 | ASME Y14.3 | 视图布局 |
|---------|-----------|----------|-----------|---------|
| **第一角** ★**双标准默认** | ✅ 默认 | ✅ 默认 | ❌ | 俯视图在下，左视图在右 |
| 第三角 | 可选 | 可选 | ✅ 默认 | 俯视图在上，左视图在左 |

> **重要说明**：ISO 128-1 和 GB/T 17451 均以第一角投影为默认。ASME Y14.3（美国标准）以第三角为默认。
> Agent 默认使用第一角投影，仅在用户明确指定 ASME/美标/外贸/第三角时切换。

### 23.3 标准体系选择策略（v10.0 精确规则）

```
★ 默认行为（无任何指定时）：
  → standard = "GB"
  → projection = "first"（第一角投影）
  → 直径前缀 = Φ
  → 标题栏 GB/T 10609.1（中文字段）
  → 技术要求中文
  → 通用公差 GB/T 1804-m

如果用户指定 "ISO" / "国际" / "外贸" / "海外" / "出口":
  → standard = "ISO"
  → projection = "first"（ISO 默认，除非另外指定）
  → 直径前缀 = Ø
  → 标题栏 ISO 7200（英文字段）
  → 技术要求英文
  → 通用公差 ISO 2768-mK

如果用户指定 "ASME" / "美标" / "美国" / "第三角" / "third angle":
  → standard = "ASME"
  → projection = "third"（第三角投影）
  → 直径前缀 = Ø
  → 标题栏 ISO 7200 或 ANSI Y14.35 格式（英文）
  → 技术要求英文
  → 通用公差 ASME Y14.5 / ISO 2768-mK

如果用户指定 "日本" / "JIS":
  → standard = "JIS"
  → projection = "third"（JIS 使用第三角投影）
  → 直径前缀 = Ø
  → 参照 ISO 7200 标题栏格式
```
