# Alpha-Eleven 投资框架

## 框架概述

本框架融合48本投资经典，涵盖51个量化指标，严格按11层顺序执行，确保决策可复制、可复盘。

## 核心执行流程

### 第0层 · 战略推演
**判断该不该投资中国权益**

- **输出**：战略配置系数（0-100%）
- **关键指标**：GRI v2.0、CSI v5.0、供应链安全指数、技术权力指数、地缘冲突指数
- **决策规则**：供应链安全指数>70 → 优先国内替代赛道；CSI>50 → 加仓

### 第1层 · 宏观定位
**确定超配/低配及风格**

- **输出**：宏观体制（扩张/收缩/滞胀/衰退）× 风格偏好
- **关键指标**：ERP、AI渗透率、气候政策风险评分、FRA-OIS利差、日元平仓规模
- **决策树**：扩张→成长；收缩→价值；滞胀→黄金/资源；衰退→债券/现金

### 第2层 · 行业扫描
**选出值得研究的行业**

- **输出**：行业优先级（🟢/🟡/🔴）+ 气候风险等级（A/B/C/D）
- **关键指标**：气候风险评分、另类数据综合信号、产能利用率差值、进口替代率、渗透率增速、产能扩张速度

### 第3层 · 量价买入信号
**判断买卖时机**

- **输出**：买入概率（0-100%）+ 置信度 + 行为偏差检测
- **关键指标**：ADTM、NSV、行为偏差因子、恐惧贪婪指数、卖方评级拥挤度、机构持仓分位、量价背离度

### 第4层 · 标的研选
**选出具体投资标的**

- **输出**：候选股票池（≤10只）+ AI期望收益 + 管理层本分评分
- **关键指标**：王子落难指数、86体系综合分、管理层本分评分、AI量化综合分、分析师覆盖密度
- **86体系维度**：行业空间/竞争格局/商业模式/管理层/财务质量/成长性/估值/催化剂

### 第5层 · 财务估值
**核心：值多少钱**

- **输出**：内在价值区间（含气候调整前/后双数值）+ 安全边际 + AI目标价
- **必须执行气候调整DCF**：气候调整内在价值 = DCF基准值 - 碳成本现值（碳价按全国碳市场最新成交价约80元/吨）
- **关键指标**：安全边际、PEG、气候调整DCF、AI预测EPS偏离度、ESG评分、碳成本现值、碳价敏感度、自由现金流收益率
- **估值方法选择规范**：
  - 稳定ROE>15%消费/医药：PEG + PE历史分位
  - 成长股（增速>20%）：PEG（<1低估，>1.5高估）+ PSR
  - 强周期股（银行/保险）：PB + PE均值回归
  - 贵金属/黄金股：金价联动模型 + 资源NAV
  - 光伏/储能/电力设备：PE vs 行业均值
  - 衰退期/困境反转：清算价值/pb + 催化剂概率
  - 港股（流动性折价）：PE折价20-30%

### 第6层 · 催化分析
**识别涨跌催化剂**

- **输出**：上涨催化×概率加权×时间窗口 + 下跌风险×概率加权
- **关键指标**：预期差、另类数据综合信号、情景概率加权（预期回报<15%则放弃建仓）

### 第7层 · 仓位决策
**决定买多少**

- **输出**：分批建仓方案 + 贝叶斯调整后仓位 + 止损价
- **动态凯利公式**：f* = (bp - q)/b，其中b=赔率=(目标价-现价)/(现价-止损价)，p=贝叶斯更新后胜率
- **仓位上限**：单票≤20%，单一行业≤40%，现金≥10%

### 第8层 · 行为校验
**防止人性弱点**

- **输出**：决策通过✅/否决❌ + 贝叶斯置信度 + 本分合规性
- **必须执行段永平本分检查清单**（11项）：
  1. 这是不是"对的事"？
  2. 如果所有人都不做，我还会做吗？
  3. 这是买公司还是买股价？
  4. 我能承受这只股票跌50%吗？（如果不能，说明不了解）
  5. 我是在用"本分"还是"贪心"做决策？
  6. 我是否在赌"一了这个机会就没了"？
  7. 我的决策是基于概率还是情绪？
  8. 我是否高估了上涨概率？
  9. 我是否混淆了"可能"和"大概率"？
  10. 我的置信度是否有数据支撑？
  11. 我的仓位是否与我的置信度匹配？
- **关键指标**：本分清单合规率（<60%重新审视）、概率校准度、系统1冲动次数

### 第9层 · 交易执行

- **规则**：分两批建仓（各50%），必须挂止损价，卖出条件触发立即执行
- **关键指标**：成交量分位（>200%=异常放量）、盘口深度（<20%=流动性紧张）

### 第10层 · 持仓管理

- **卖出触发条件**（任一即重新评估）：
  1. 宏观体制切换
  2. 核心业务连续2季低于预期
  3. 股价透支超目标价1.5倍标准差
  4. 气候风险黑天鹅事件
  5. 持仓逻辑被破坏
- **继续持有条件**：基本面未变、估值未极端、概率优势未消失、宏观体制未切换

### 第11层 · 反馈闭环
**让系统自己变聪明**

- 每季度追踪因子准确率：
  - 准确率>65% → 权重+5%
  - 40%-65% → 维持
  - <40% → 权重-5%，标记"存疑"
  - <30% → 从模型移除
- 每笔决策记录：决策依据、实际结果、偏差原因、是否违反本分、是否存在认知偏误
- 每年迭代版本升级

## 重要约束

- **高碳行业**（钢铁/煤炭/水泥）必须计算气候调整DCF，若调整后差距>15%需在报告中明确说明
- **预期回报<15%时不得建仓**
- **每次决策前必须执行第8层本分清单**
- **每季度必须更新贝叶斯胜率和因子准确率**
