# 微信公众号文案格式指南

## 一、Word文档输出格式

### 文档命名规范
```
[产品名称]-[文案类型]-[日期].docx
```
示例：`Airfun益生菌-卖点提炼-20240115.docx`

### 文档结构模板

```
===============================================================================
                              文案标题
===============================================================================

【适用产品】：[产品名称]
【文案类型】：[卖点提炼/蓝帽认证/深度解析/功效说明/Q&A合集]
【生成日期】：[YYYY-MM-DD]
【使用说明】：可直接复制正文内容到微信公众号后台，配图需上传至公众号素材库

===============================================================================
                                 正文内容
===============================================================================


[正文内容]


===============================================================================
                                配图说明
===============================================================================

【图1】：产品主图/场景图
- 建议尺寸：1920×1080像素（16:9比例）
- 用途：[描述图片用途]

【图2】：卖点可视化/功效图示
- 建议尺寸：1920×1080像素（16:9比例）
- 用途：[描述图片用途]

【图3】：[可选]对比图/人群图示
- 建议尺寸：1920×1080像素（16:9比例）
- 用途：[描述图片用途]


===============================================================================
                              公众号排版建议
===============================================================================

【封面图】：建议尺寸 900×383 像素（2.35:1）
【正文配图】：建议尺寸 900×506 像素（16:9）或正方形 900×900 像素
【图片格式】：JPG/PNG，建议文件大小不超过 2MB

===============================================================================
```

## 二、正文排版规范

### 标题规范
- 主标题：16-24字，加粗居中
- 二级标题：使用"##"或"【】"标注
- 三级标题：使用"###"或"一、二、三"

### 字号建议
- 正文：15-16号字
- 标题：18-22号字
- 注释/说明：12-14号字

### 行间距
- 正文：1.75-2.0倍行距
- 段落间：空一行

### 重点标注
- 关键词加粗
- 数据用【】或【】标注
- 行动号召用【】框起

## 三、配图生成要求

### 图片比例
- **微信公众号封面图**：2.35:1（900×383像素）
- **正文横版配图**：16:9（1920×1080像素）
- **正文方形配图**：1:1（900×900像素）

### 图片风格要求

#### 产品主图
```
风格：清新专业、简洁大方
元素：产品实物、品牌LOGO、产品名称
色调：与品牌形象一致（健康、自然、科技感）
背景：纯色或渐变背景，避免杂乱
```

#### 卖点可视化图
```
风格：信息图式、清晰易读
元素：图标、数字、关键词、简单图示
布局：左右分栏或上下分区
配色：不超过3种主色
```

#### 场景图
```
风格：生活化、有代入感
场景：根据产品定位选择（办公、居家、户外等）
人物：目标人群形象
色调：温馨舒适
```

### 图片文件命名
```
[产品名缩写]-[图片类型]-[序号].[格式]
```
示例：
- `AFYSSJ-主图-01.jpg`
- `AFYSSJ-卖点-02.png`

## 四、不同文案类型的图片配置

| 文案类型 | 图1 | 图2 | 图3 |
|----------|-----|-----|-----|
| 卖点提炼 | 产品主图 | 卖点汇总图 | 场景图（可选） |
| 蓝帽认证 | 蓝帽+产品组合 | 认证说明图 | 功效图（可选） |
| 深度解析 | 使用场景图 | 成分/技术图解 | 对比图（可选） |
| 功效说明 | 产品+功效图 | 适用人群图 | 服用方法图（可选） |
| Q&A合集 | 产品图 | FAQ图示 | 温馨提示图（可选） |
| 对比型 | 产品对比图 | 差异说明图 | 选择建议图 |

## 六、内容合规提醒

### 禁止使用的表述
- ❌ "最好"、"第一"、"顶级"等绝对化用语
- ❌ "治疗"、"治愈"、"疗效"等医疗用语
- ❌ 与药品、医疗器械混淆的表述
- ❌ 虚假或无法证实的数据

### 保健食品广告特别提醒
- 蓝帽产品可提及"增强免疫力"、"抗氧化"等功能
- 不得提及对疾病的治疗作用
- 需标注"保健食品不是药物，不能代替药物治疗疾病"
- 需标注不适宜人群
