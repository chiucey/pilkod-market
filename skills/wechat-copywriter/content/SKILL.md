## 技能使用方式

### 触发指令示例

| 用户指令 | 识别意图 | 输出内容 |
|----------|----------|----------|
| "Airfun益生菌的卖点" | 卖点提炼 | 核心卖点列表+配图 |
| "云启元辅酶Q10蓝帽认证说明" | 蓝帽解读 | 认证资质+专业说明 |
| "详细介绍云启元鱼油" | 深度解析 | NFABE结构化长文 |
| "Airfun氨糖的功效有哪些" | 功效说明 | 功效+适用人群 |
| "Airfun磷虾油怎么吃" | 使用指南 | 服用方法+注意事项 |
| "云启元益生菌FAQ" | Q&A合集 | 常见问题解答 |
| "磷虾油和鱼油哪个好" | 对比型 | 选购对比指南 |

### 完整工作流程

```
1. 用户输入 → 识别产品 + 识别指令类型
2. 读取资料 → 从 references/product-catalog.md 提取产品信息
3. 内容编排 → 按照 templates.md 的对应模板生成文案
4. 格式校验 → 按照 format-guide.md 检查格式规范
5. 配图生成 → 使用 image_synthesize 生成16:9配图
6. Word输出 → 生成 .docx 文件供用户下载
```

## 文案类型详解

### 1. 卖点提炼型
**适用场景**：产品推广初期，强调差异化卖点
**输出结构**：
- 吸引标题（16-24字）
- 3-5个核心卖点（每个卖点2-3句话）
- 行动号召

### 2. 蓝帽认证型
**适用场景**：蓝帽保健食品（破壁灵芝孢子粉、辅酶Q10）
**输出结构**：
- 蓝帽认证专业解读
- 产品认证资质详情
- 选择蓝帽产品的理由

### 3. 深度解析型（NFABE）
**适用场景**：需要详细介绍产品
**输出结构**：
- 痛点引入（N）
- 专业分析
- 产品特征（F）
- 核心优势（A）
- 使用利益（B）
- 权威证据（E）

### 4. 功效说明型
**适用场景**：功效宣传
**输出结构**：
- 主要功效列表
- 适合人群
- 服用方法
- 注意事项

### 5. Q&A合集型
**适用场景**：解答常见疑问
**输出结构**：
- 5-10个高频问题及解答
- 温馨提示

### 6. 对比型
**适用场景**：帮助消费者做选择
**输出结构**：
- 产品A vs 产品B对比表格
- 差异分析
- 选择建议

## 输出规范

### Word文档结构
```
【文档标题】
产品名称 | 文案类型

【正文内容】
（按照公众号排版格式）

【配图说明】
图1：[描述] - 16:9
图2：[描述] - 16:9

【使用说明】
可直接复制正文到公众号后台
```

### 配图要求
- **比例**：16:9（1920×1080像素）
- **风格**：清新专业，符合健康产品调性
- **数量**：每篇文案2-3张配图

### 内容合规
- 严格基于产品资料编写
- 保健食品广告需符合规范
- 蓝帽产品标注认证信息
- 禁用绝对化用语和医疗用语

## 注意事项

1. **内容来源**：文案内容严格来源于产品资料，不得自行编造
2. **功效宣传**：确保符合保健食品广告法规
3. **配图比例**：统一为16:9（1920×1080）
4. **蓝帽产品**：必须体现认证编号和保健功能
5. **输出格式**：Word文档可直接复制，保留基本格式
