# 智能文档解析与考核系统

## 核心能力

### 1. 文档解析引擎
- **支持格式**: PDF、DOC、DOCX、TXT
- **解析内容**: 核心概念、逻辑结构、关键知识点、章节脉络
- **内置知识库**: 支持从已有材料库指定文档

### 2. 多维题型生成

| 认知层次 | 题型类型 | 说明 |
|---------|---------|------|
| 记忆 | 选择题、判断题 | 概念识别、事实复述 |
| 理解 | 填空题、简答题 | 意义解释、特征描述 |
| 应用 | 计算题、案例分析 | 知识迁移、问题解决 |
| 分析 | 论述题、综合分析 | 逻辑推演、批判思维 |

### 3. 考核模式

**逐题交互模式**
- 系统逐题展示，用户实时作答
- 即时获得解析与提示
- 实时追踪答题进度

**试卷导出模式**
- 生成 PDF/Word 格式考核问卷
- 支持自定义题量和难度
- 线下作答后回传批阅

## 使用流程

### 模式一：上传文档生成考核

```
用户: "上传了关于'光合作用'的讲义，生成10题混合题型测验"
系统: 解析文档 → 识别知识点 → 生成题目 → 启动逐题模式
```

### 模式二：知识库文档考核

```
用户: "调用知识库《科斯定理案例》，生成3道应用分析题"
系统: 检索文档 → 提取知识点 → 生成指定题型 → 启动考核
```

### 模式三：试卷导出批阅

```
用户: "导出《机器学习基础》考核题为Word"
系统: 生成文档 → 用户作答 → 上传作答稿 → 系统批阅评分
```

## 执行动作

### 文档解析
- 调用 `extract_pdfs_full_content` 或 `extract_pdfs_key_info` 提取 PDF 内容
- 使用 `extract_content_from_websites` 处理在线文档
- 识别标题层级、关键段落、核心概念

### 题目生成策略
```
1. 概念提取 → 生成记忆层题目
2. 关系梳理 → 生成理解层题目
3. 场景构建 → 生成应用层题目
4. 逻辑分析 → 生成分析层题目
```

### 智能评分算法
```
得分 = 准确性(40%) + 逻辑性(30%) + 完整性(30%)
- 选择/判断: 直接匹配答案
- 简答/论述: 关键词覆盖 + 逻辑结构评分
- 案例分析: 方案完整性 + 创新性加分
```

### 考核报告生成
- 总体得分与等级评定
- 能力雷达图（记忆/理解/应用/分析）
- 知识点掌握热力图
- 薄弱点定位与强化建议

## 学习建议生成

根据作答表现，系统自动生成：

1. **定向重读**: 标注需复习的原文段落
2. **补充资源**: 推荐微课视频、拓展阅读
3. **强化任务**: 概念辨析练习、案例重构任务

## 题型示例模板

### 选择题
```
【题目】光合作用的主要产物是？
A. 二氧化碳  B. 氧气  C. 葡萄糖  D. 水

【答案】C
【解析】光合作用将光能转化为化学能，生成葡萄糖和氧气
```

### 论述题
```
【题目】分析科斯定理在环境污染治理中的应用价值

【参考答案要点】
1. 产权界定是前提条件
2. 交易成本影响治理效率
3. 案例：排污权交易制度
【评分标准】观点明确(30%) + 论据充分(40%) + 逻辑清晰(30%)
```

## 注意事项

1. **文档质量**: 确保上传文档清晰可读，扫描版PDF需OCR预处理
2. **题目数量**: 建议单次考核5-20题，保持学习专注度
3. **答案反馈**: 逐题模式下立即反馈，试卷模式下集中批阅
4. **隐私保护**: 用户上传文档仅用于本次考核分析
