# 标准合同条款清单

本文档列出各类合同的标准条款清单，用于合规审查时的必含条款检查。

## 一、通用必含条款

所有类型合同均应包含以下条款：

| 条款类型 | 条款内容要求 | 说明 |
|---------|------------|------|
| 当事人条款 | 明确双方全称、地址、联系方式 | 确认合同主体资格 |
| 标的条款 | 明确合同标的的名称、规格、数量 | 合同的核心内容 |
| 价格条款 | 明确金额、币种、支付方式、支付时间 | 涉及金钱的核心条款 |
| 履行条款 | 明确履行期限、方式、地点 | 执行依据 |
| 违约条款 | 明确违约情形、责任承担方式 | 约束双方履行 |
| 争议条款 | 明确争议解决方式（诉讼/仲裁） | 纠纷处理方式 |
| 生效条款 | 明确合同生效条件、时间 | 合同效力依据 |
| 签署条款 | 双方签字/盖章、签署日期 | 形式要件 |

## 二、合同类型专项条款

### 采购合同

| 条款类型 | 条款内容要求 |
|---------|------------|
| 质量标准 | 明确质量要求、检验标准、验收方式 |
| 交付条款 | 交付时间、地点、运输方式、风险转移 |
| 质保条款 | 质保期限、质保范围、质保责任 |
| 售后服务 | 维修响应时间、备件供应承诺 |
| 包装条款 | 包装要求、标识要求 |

### 服务合同

| 条款类型 | 条款内容要求 |
|---------|------------|
| 服务内容 | 明确服务范围、具体工作内容 |
| 服务标准 | 明确服务质量要求、验收标准 |
| 人员要求 | 明确服务人员资质要求 |
| 保密条款 | 涉及客户商业秘密的保密义务 |
| 知识产权 | 服务成果的知识产权归属 |

### 劳动合同

| 条款类型 | 条款内容要求 |
|---------|------------|
| 试用期条款 | 试用期期限、试用期考核标准 |
| 工作内容 | 岗位名称、工作职责、工作地点 |
| 工作时间 | 工时制度、休息休假安排 |
| 薪酬条款 | 工资构成、支付时间、加班费计算 |
| 社会保险 | 社保缴纳险种、比例 |
| 竞业限制 | 限制期限、范围、补偿标准（可选） |
| 培训条款 | 服务期约定、培训费用承担（可选） |

### 租赁合同

| 条款类型 | 条款内容要求 |
|---------|------------|
| 租赁物条款 | 租赁物地址、面积、用途 |
| 租赁期限 | 起止日期、续租条件 |
| 租金条款 | 租金金额、支付周期、递增条款 |
| 押金条款 | 押金金额、退还条件 |
| 维修责任 | 出租人/承租人各自承担的维修范围 |
| 转让条款 | 转租条件、优先购买权 |

### 建设工程合同

| 条款类型 | 条款内容要求 |
|---------|------------|
| 工程范围 | 明确施工范围、工程量 |
| 工期条款 | 开工日期、竣工日期、工期延误责任 |
| 工程款 | 付款节点、付款比例、结算方式 |
| 工程变更 | 变更程序、变更价款调整 |
| 竣工验收 | 验收程序、验收标准 |
| 保修条款 | 保修范围、保修期限 |

## 三、行业特定条款

### 金融行业

- 反洗钱条款
- 合规声明条款
- 监管配合条款
- 信息披露条款

### 医疗健康

- 隐私保护条款（HIPAA/GDPR合规）
- 医疗器械相关资质条款
- 不良反应报告条款

### 信息技术

- 数据安全条款
- 系统可用性条款（SLA）
- 漏洞修补责任条款
- 源代码权属条款（视情况）

### 跨国贸易

- 进出口合规条款
- 关税条款
- 原产地条款
- 外汇管制条款

## 四、条款表述规范

### 推荐表述

- 使用明确的时间节点（具体日期而非模糊时间）
- 使用确定的金额（具体数字而非"合理费用"）
- 使用具体的责任范围（明确数额或比例）
- 使用可验证的标准（客观可测量的指标）

### 避免表述

- "合理"、"适当"等模糊词汇
- "双方协商"（应在协商机制中明确）
- "必要时"、"相关情况下"等不确定表述
- 歧义性表述（如"交付"与"验收"的混淆）
