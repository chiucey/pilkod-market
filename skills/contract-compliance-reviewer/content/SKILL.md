# 合同合规审查技能

## 触发条件

当用户提供合同文本并要求以下操作时激活：
- 合同合规性审查
- 法律风险识别
- 合同条款分析
- 合规审核
- 风险点评估

## 审查流程

### 1. 合同基本信息识别

解析并提取合同关键信息：
- 合同类型（采购合同、服务合同、劳动合同、租赁合同等）
- 合同双方当事人信息
- 合同标的和范围
- 合同期限和生效条件
- 金额和支付条款

### 2. 标准条款合规检查

按照合同类型对应的标准条款清单逐一检查：

**必含条款检查**：
- 当事人信息条款
- 标的和数量条款
- 价格和支付条款
- 履行期限和方式条款
- 违约责任条款
- 争议解决条款
- 合同生效要件

**格式规范检查**：
- 条款编号连续性
- 前后条款编号一致性
- 术语使用统一性

### 3. 风险识别

识别以下类型风险：

**高风险项**：
- 责任免除过宽的条款
- 违约金额明显不公平的条款
- 争议解决偏向单方的条款
- 违反法律法规的强制性规定

**中风险项**：
- 模糊不清的条款表述
- 可能产生歧义的定义
- 缺乏具体执行细节的条款
- 通知和送达条款不完善

**低风险项**：
- 表述不够精炼的条款
- 格式不够规范的表述
- 建议优化但不构成风险的条款

### 4. 缺失条款检查

根据合同类型检查必要条款是否完整：
- 保密条款（如涉及商业机密）
- 知识产权归属条款（如涉及智力成果）
- 不可抗力条款
- 合同变更和解除条款
- 附件效力条款

## 注意事项

1. **仅提供参考意见**：本技能仅提供合规性参考，不构成法律意见
2. **区分合同类型**：不同类型合同有不同的合规要求
3. **考虑行业特性**：金融、医疗、劳动等特殊行业有额外合规要求
4. **版本一致性**：确保附件与主合同条款一致
5. **语言准确性**：注意中英文合同表述差异
