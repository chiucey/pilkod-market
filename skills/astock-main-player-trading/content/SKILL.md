# A股主力博弈分析系统

## 技能概述

本技能专注于A股市场主力行为识别与量价博弈研究，通过四大核心检测模块和五步诊断法，帮助投资者识别主力做局陷阱、把握行情拐点。

## 四大核心检测模块

### 1. 诱空陷阱识别（Bear Trap）

**量化标准**：
- 连续3至5个交易日出现缩量阴跌走势
- 量能较前期高点缩减30%以上
- 价格跌破关键技术位但未见恐慌性放量

**分析要点**：主力锁仓洗盘，通过消磨散户持股意志收集筹码。

### 2. 亮剑信号（放量倍率）

**量化标准**：当日成交额与过去3至5日均值相比，放量倍率超过2倍以上。

**分析要点**：主力完成吸筹或洗盘后的破局进攻验证，高位放量需警惕出货信号。

### 3. 攻击波效率（分时博弈）

**重点监控时段**：14:00之后的抢筹攻击波。

**量化标准**：攻击波斜率大于45度，且收盘价站稳在日内均价线上方。

### 4. 成本偏离度分析

**判定逻辑**：
- 收盘价远高于均价：主力不计成本扫货，惯性冲高概率大
- 收盘价低于均价：主力存在诱多出货嫌疑

## 五步诊断法

1. **盘面快照** - 持仓状态、仓位评级、量能诊断
2. **五日复盘** - 逐日走势记录、做局类型判定
3. **主力诊断** - 技术形态、资金面、情绪周期
4. **触发分析** - 条件式交易计划（加仓/减仓条件）
5. **今日结论** - 主力意图总结、方向性建议

## A股特有约束

### T+1交易机制
- 禁止一次性加满所有仓位
- 所有操作必须分批执行
- 每次加仓必须等待前一次确认

### 数据获取要求
- **优先使用 akshare 库**获取A股实时和历史数据
- 如未安装 akshare，先执行 `pip install akshare`
- 非交易日获取最近交易日数据
- 报告开头标注数据基准日

## 输出格式

所有分析结论以条件触发形式呈现：
- 明确标注触发条件
- 标注分析方向
- 不提供具体买卖价格建议
- 标注数据延迟情况
