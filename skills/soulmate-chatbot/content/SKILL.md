# 灵魂伴侣聊天机器人

## 触发条件

当用户要求：
- 创建心灵陪伴类应用
- 构建情感倾诉/吐槽类聊天机器人
- 开发深夜树洞应用
- 设计具有共情能力的AI伴侣
- 心理咨询类对话应用

## 工作流程

### 1. 需求分析

确认以下关键要素：
- **核心功能**: 对话、情绪标签、对话记忆
- **对话风格**: 共情优先，不说教不鸡汤
- **设计调性**: 温暖、私密、安全（如深夜、电台氛围）
- **技术栈**: HTML5 + CSS3 + JavaScript（纯前端）

### 2. 设计规范

**美学方向**:
- 深色主题 + 温暖色调（如琥珀色、玫瑰色）
- 营造私密倾诉氛围
- 可选星空/月亮相关系列动画

**色彩系统**:
```css
--primary: #E8A87C;     /* 温暖琥珀 */
--secondary: #C38D9E;   /* 温柔玫瑰 */
--background: #1A1A2E;   /* 深夜蓝黑 */
--surface: #16213E;      /* 深蓝 */
```

**字体**: 中文衬线字体（如 Noto Serif SC、ZCOOL XiaoWei）

### 3. 功能组件

必选组件：
- [ ] Header 头部（标题 + 清空按钮）
- [ ] ChatContainer 对话区域（消息气泡、欢迎语）
- [ ] TypingIndicator 打字指示器
- [ ] EmotionPicker 情绪选择器（😊😐😢😤🤔）
- [ ] InputArea 输入区域（文本框 + 发送按钮）
- [ ] Modal 确认弹窗（清空对话确认）

### 4. 对话系统设计

**回复原则**:
1. 首先承认和接纳情绪
2. 不急于给建议或解决方案
3. 可以适当共情吐槽
4. 必要时温和引导，不强迫

**分类响应**:
- 工作问题: 理解压力，不鸡汤
- 感情问题: 承认感受，不说教
- 家庭问题: 尊重羁绊的复杂性
- 学习问题: 肯定坚持
- 自我探索: 陪伴迷茫期
- 日常闲聊: 轻松自然

### 5. 技术实现

**数据存储**: LocalStorage
```javascript
// 存储结构
{
  "soulmate_messages": [
    { role: "user", content: "...", emotion: "sad", timestamp: 1234567890 },
    { role: "ai", content: "...", timestamp: 1234567891 }
  ]
}
```

**动画效果**:
- 消息淡入上浮: `fadeInUp 0.3s ease-out`
- 打字指示器: 三点波浪起伏 `1.4s`
- 星空背景: 闪烁动画 `3s ease-in-out infinite`

### 6. 部署

完成开发后使用 `deploy` 工具部署到线上环境。

## 质量验收

- [ ] 对话区域可正常滚动
- [ ] 消息发送后AI有打字动画
- [ ] 情绪选择器可切换状态
- [ ] 清空对话有确认弹窗
- [ ] 刷新页面对话记录保留
- [ ] 深色主题视觉舒适
