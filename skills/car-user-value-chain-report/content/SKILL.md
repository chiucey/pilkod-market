# 汽车用户价值链分析报告生成器

生成专业的汽车用户价值链分析报告，整合懂车帝、汽车之家、小红书、抖音等多平台用户评价数据。

## 输出产物

- **HTML 可视化报告**：包含完整的用户价值链分析
- **数据维度**：购车原因、竞品对比、感知层分析、用户画像、用户价值链时间线
- **数据来源标注**：每个数据点标注来源平台

## 分析维度

### 1. 感知层分析 (Perception Layer)
- **日常驾驶**：续航、充电、动力、操控、能耗
- **静态感受**：外观、内饰、空间、舒适性
- **特殊场景**：高速、山路、冬季、载物
- **智能驾驶**：辅助驾驶、自动泊车、语音交互

### 2. 用户画像分析
- 年龄分布
- 收入水平
- 家庭结构
- 用车场景
- 兴趣爱好

### 3. 购车决策因素
- 核心购车原因
- 对比车型
- 决策周期
- 价格敏感度

### 4. 用户价值链时间线
- 购车前信息获取
- 试驾体验
- 购买转化
- 用车满意度
- 推荐意愿

## 工作流程

### 步骤 1：需求收集

使用 GenUI 表单收集以下信息：

```
车型名称（支持多选或自定义）
目标市场细分（如：15万以下两厢车）
分析平台（懂车帝/汽车之家/小红书/抖音，可多选）
报告用途（竞品分析/产品定位/用户研究）
```

### 步骤 2：数据采集

1. **网络搜索**：按平台搜索目标车型的用户评价
2. **关键词策略**：
   - `"{车型}" + "用户评价" + "懂车帝"`
   - `"{车型}" + "提车作业" + "汽车之家"`
   - `"{车型}" + "真实用车" + "小红书"`
   - `"{车型}" + "测评" + "抖音"`

### 步骤 3：内容提取

使用 `extract_content_from_websites` 提取平台页面内容

### 步骤 4：报告生成

生成包含以下模块的 HTML 报告：
- 执行摘要
- 车型基本信息表（价格、尺寸、续航、装备）
- 市场竞争格局卡片
- 用户画像分析（Tab 切换：全市场 + 单车）
- 感知层满意度分析（Tab 切换：驾驶/静态/特殊/智驾）
- 用户价值链时间线
- 数据来源说明

## 报告模板结构

```html
<!-- 核心模块 -->
1. 顶部导航 + 执行摘要
2. 车型基本信息对比表
```
