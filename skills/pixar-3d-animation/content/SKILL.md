# 皮克斯3D动画风格技能

> **Author**: 起始终下
> **Copyright**: © 2025 起始终下. All Rights Reserved.

---

## 技能定位

本技能将用户的图像需求转化为皮克斯3D动画美学风格的Prompt，专门适配千问系列图像生成模型。

**核心价值**：用圆润可爱的3D角色和鲜艳丰富的色彩，讲述普世的家庭、冒险与成长故事。

---

## 适用场景

### 主要适用场景

| 场景类型 | 具体示例 | 输出特点 |
|---------|---------|---------|
| **可爱角色** | 圆润3D角色、家庭成员 | 大眼睛、夸张表情 |
| **冒险世界** | 奇幻场景、异域风情 | 细节丰富、色彩斑斓 |
| **家庭场景** | 温馨时刻、日常互动 | 温暖治愈、有笑有泪 |
| **欢乐节日** | 派对、庆典、团聚 | 热闹喜庆、色彩鲜艳 |
| **梦想追求** | 追梦、成长、冒险 | 励志温暖、感人 |

### 不适用场景

| 不适用场景 | 原因说明 |
|-----------|---------|
| **写实摄影** | 纯写实风格与3D动画不兼容 |
| **暗黑恐怖** | 皮克斯风格温馨欢乐，非恐怖 |
| **成人压抑** | 家庭向/全年龄向，非沉重成人向 |
| **过于尖锐** | 圆润边缘是核心特征 |
| **低饱和暗调** | 皮克斯风格鲜艳明亮 |

## 输入要求

### 必填信息

| 信息类型 | 说明 | 示例 |
|---------|------|------|
| **主体** | 主要角色或场景 | "可爱的小女孩"、"一家人在客厅" |
| **场景类型** | 环境背景 | "墨西哥小镇"、"动物城市" |
| **情感基调** | 整体氛围 | "温馨"、"冒险"、"欢乐" |

### 选填信息

| 信息类型 | 说明 | 缺失时处理 |
|---------|------|-----------|
| **角色细节** | 物种/外貌/服饰 | 使用通用人类儿童 |
| **世界观** | 奇幻/现实 | 使用温馨家庭场景 |
| **文化元素** | 特定文化 | 使用通用西方家庭 |
| **动作/表情** | 具体描写 | 使用开心表情 |

### 模糊需求处理

当用户只说"皮克斯风格"而无具体描述时，**必须先确认**：

```
了解您需要皮克斯3D动画美学的图像。为了更精准生成，请告诉我：

1. 【主体】画面主要内容是什么？
   - 角色（人类儿童/动物/幻想生物）？
   - 家庭（一家三口/祖孙/朋友）？

2. 【场景环境】在哪里发生？
   - 家庭场景（客厅/厨房/后院）？
   - 奇幻世界（异域/太空/水下）？
   - 节日庆典（派对/节日/团聚）？

3. 【情感基调】希望传达什么感受？
   - 温馨治愈 / 欢乐冒险 / 梦想追求 / 家庭团聚 / 成长故事？

4. 【重要元素】有什么必须保留的？（可选）
   - 特定角色/道具/文化元素？

如需快速开始，我可以按默认方案生成：
【可爱小女孩站在彩虹色的奇幻小镇中央，阳光明媚，欢乐冒险氛围】
```

## 千问模型Prompt框架

### 框架A：长文叙述式（Qwen-Image-2.0/3.0推荐）

```
【整体定调】
- 画幅：[横幅/竖幅/方形]
- 风格：皮克斯3D动画风格，圆润角色设计
- 色调：[鲜艳饱和/暖色主调/文化特征色]

【角色描述】
- 主要角色：[物种/性别/年龄/外貌描述]
- 服饰：[特色服装描述]
- 表情：[夸张表情，如大笑/惊喜/感动]
- 皮肤：[光滑/次表面散射质感]

【场景设定】
- 地点：[具体场景，如"彩虹小镇广场"或"温馨客厅"]
- 时间：[阳光明媚/温馨傍晚/节日氛围]
- 环境细节：[富有想象力的建筑/鲜艳植被/文化元素]

【视觉特征】
- 光线：[三点布光/暖色调/轮廓光]
- 色彩：[鲜艳饱和/色彩丰富]
- 质感：[光滑3D渲染/圆润边缘/柔软毛发]

【动画特征】
- 表情：夸张但可爱，情感表达清晰
- 质感：圆角边缘，柔和过渡，无锐利边缘

【情感基调】
- 氛围：欢乐、温暖、家庭感、冒险精神

【约束条件】

## 应用示例

### 示例1：墨西哥小镇

**用户需求**："皮克斯风格的小女孩站在墨西哥小镇广场上"

**生成Prompt（框架A）**：

```
【整体定调】
- 画幅：横幅，2.39:1电影比例
- 风格：皮克斯3D动画风格，圆润角色设计
- 色调：墨西哥色彩为主，鲜艳饱和

【角色描述】
- 主要角色：一位8岁左右的墨西哥小女孩，
  橙红色卷发扎成两个小辫子，大眼睛，
  圆脸，皮肤呈健康的小麦色
- 服饰：穿着色彩鲜艳的红色连衣裙，
  裙子上有黄色和绿色的花朵图案
- 表情：开心大笑，张开双臂，非常兴奋

【场景设定】
- 地点：墨西哥小镇广场，阳光明媚
- 时间：午后，温暖的阳光
- 环境细节：广场上挂满彩色纸灯笼和万寿菊，
  远处可见典型的墨西哥彩色房屋，
  地面铺着红砖，周围有绿色仙人掌

【视觉特征】
- 光线：温暖阳光从上方照射，
  三点布光使角色立体
- 色彩：墨西哥典型色彩，
  橙黄红绿蓝紫都非常鲜艳饱和
- 质感：光滑3D渲染，圆润边缘，
  次表面散射皮肤质感

【动画特征】

## 皮克斯创作哲学

### 故事主题

```
家庭：家庭之爱, 亲情羁绊
成长：成长, 学习, 改变
梦想：追求梦想, 克服困难
身份：认识自我, 归属感
情感：欢乐, 泪水, 治愈
```

### 角色设计原则

```
可爱但有深度：外表可爱，内心丰富
成长弧线：角色必须有成长
情感真实：即使夸张也真实可信
普世共鸣：超越年龄文化的情感
```

### 视觉设计原则

```
色彩叙事：色彩传递情感
圆润安全：边缘圆润，温暖安全
细节丰富：满满当当，生动有趣
想象力：无边界的创意世界
```
