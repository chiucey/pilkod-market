## 目标受众画像

### 主要用户群体

#### 1. 刚需购房群体
- 特征：首套房装修，预算有限，经验不足
- 痛点：怕踩坑、想省钱、不懂行
- 偏好内容：预算清单、避坑指南、流程科普
- 互动方式：收藏为主，爱问问题

#### 2. 改善型装修群体
- 特征：有装修经验，追求品质，愿意投入
- 痛点：想要更好的效果、不确定如何选择
- 偏好内容：设计灵感、高端产品测评、品牌对比
- 互动方式：评论交流、分享经验

#### 3. 旧房改造群体
- 特征：住久翻新、局部改造、预算中等
- 痛点：施工难度大、担心影响生活
- 偏好内容：改造案例、施工经验、收纳方案
- 互动方式：评论区请教、寻求建议

#### 4. 租房改造群体
- 特征：年轻租客、预算低、喜欢折腾
- 痛点：房东限制、预算有限
- 偏好内容：平价好物、租房神器、装饰技巧
- 互动方式：收藏分享、互相种草

## 违禁词与敏感话题

### 装修类内容禁区

```
绝对化用语：
- 「最好」「第一」「顶级」等绝对化表述
- 「保证」「100%」等承诺性用语

违禁推广：
- 医疗相关功效宣称（如空气净化治甲醛等）
- 夸大宣传产品效果
- 虚假比价信息

敏感话题：
- 涉及政治敏感内容
- 宗教相关
- 邻里纠纷等敏感社会话题
```

### 合规表述建议

```markdown
❌ 错误：「这款漆是最好的选择」
✅ 正确：「我用下来觉得这款漆很不错」

❌ 错误：「保证10年不会坏」
✅ 正确：「正常使用情况下，大部分用户反馈使用效果不错」

❌ 错误：「除甲醛率99%」
✅ 正确：「配合通风使用，效果会更好」
```
