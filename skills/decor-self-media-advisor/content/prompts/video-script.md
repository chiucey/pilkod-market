## 不同类型视频脚本

### 1. 干货教程类
```
结构：痛点→解决方案→步骤详解→总结
时长：1-3分钟
重点：信息密度高，干货满满
```

### 2. 测评对比类
```
结构：引入→产品A介绍→产品B介绍→对比→推荐
时长：2-5分钟
重点：客观真实，专业可信
```

### 3. 案例分享类
```
结构：背景介绍→装修过程→效果展示→经验总结
时长：2-4分钟
重点：真实案例，代入感强
```

### 4. 避坑指南类
```
结构：常见问题→错误做法→正确做法→建议
时长：1-3分钟
重点：经验教训，避免踩雷
```

## 爆款视频要素

### 开头3秒法则
- **强视觉冲击**：惊人效果对比、问题展示
- **利益承诺**：「学会这招省下xxx」
- **悬念设置**：「大多数人不知道的xxx」
- **身份认同**：「装修过的人一定要看」

### 内容节奏把控
```
每30秒设置一个「钩子」：
- 信息钩子：新知识/新观点
- 情绪钩子：共鸣/感动/震惊
- 行动钩子：「看到最后有惊喜」
```

### 结尾互动设计
- 提问式：「你们家是这样的吗？」
- 引导式：「评论区告诉我」
- 利他式：「点赞过xxx我教你们xxx」
- 悬念式：「下期讲xxx，记得关注」

## 脚本优化技巧

### 专业度与通俗度平衡
- 使用专业术语时加通俗解释
- 用生活类比说明复杂概念
- 避免过度专业导致观看门槛高

### 数据与案例结合
- 具体数字：「省下3万」比「省很多」更有效
- 真实案例：「我家」「粉丝家」的装修故事
- 对比展示：Before/After效果明显

### 字幕与配音配合
- 关键信息用字幕高亮
- 专业词汇配字幕辅助理解
- 语速节奏配合画面切换

## 违禁词与注意事项

### 绝对化用语
- ❌ 「第一」「顶级」「最好」
- ✅ 「我用下来觉得」「很多人反馈」

### 虚假承诺
- ❌ 「用了保证xxx」
- ✅ 「根据我的经验」「大部分情况下」

### 竞品对比注意
- 不直接说竞品名字
- 用「某品牌」「其他产品」替代
- 重点说自己的使用体验
