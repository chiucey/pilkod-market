# 三省六部制历史背景与详细资料

## 历史沿革

### 起源与发展

1. **萌芽期（东汉-魏晋）**：尚书台制度
   - 东汉光武帝设置尚书台，作为皇帝的秘书机构
   - 尚书台逐渐取代三公的权力

2. **确立期（南北朝）**
   - 西魏、北周开始出现三省雏形
   - 中书、门下两省逐渐独立

3. **确立期（隋朝）**
   - 隋文帝正式确立三省制度
   - 三省长官均为宰相

4. **完善期（唐朝）**
   - 唐太宗进一步完善三省制度
   - 三省分工明确，相互制衡
   - 门下省封驳权达到顶峰

5. **演变期（宋代）**
   - 宋代实行"二府三司"制
   - 三省逐渐向一省制过渡

6. **衰落期（元明清）**
   - 元朝废除三省制
   - 明朝设六部直辖皇帝
   - 清朝沿用六部设置

## 六部长官品级

每部设尚书一人（正三品），侍郎一人或二人（正四品上）。

## 封驳制度详解

### 封驳的具体程序

1. **草诏**：中书省起草诏书
2. **过省**：诏书送门下省
3. **审议**：给事中审核诏书
4. **签署**：若同意，侍郎签字
5. **驳回**：若有异议，退回修改
6. **封还**：坚持己见则封还诏书

### 著名的封驳案例

- **唐太宗时期**：魏征等谏官多次封驳诏书
- **唐玄宗时期**：门下省驳回多项不当时政
- 封驳制度有效制约了皇权滥用

## 三司会审制度

### 组成

| 机构 | 职能 |
|------|------|
| 刑部 | 司法审判 |
| 大理寺 | 案件复核 |
| 御史台 | 监察弹劾 |

### 适用范围

- 重大刑事案件
- 涉及官员的案件
- 死刑案件

## 科举制度与礼部

礼部管辖的科举考试流程：

```
乡试（州县）→ 省试（各道/州）→ 礼部试（全国）→ 殿试（皇帝亲试）
```

### 考试科目

- **明经科**：背诵经典
- **进士科**：诗赋文章（最受重视）
- 明法科、算学科等专科

## 兵部与军事

### 府兵制（初期）

- 府兵平时务农，战时出征
- 军府分布全国
- 十二卫统领

### 募兵制（后期）

- 职业军人
- 节度使制度
- 边镇军权集中

## 延伸阅读

- 三省六部制体现了"分权制衡"的政治智慧
- 对比西方三权分立制度
- 日本大化改新借鉴了三省六部制
- 朝鲜高丽王朝也采用了类似制度
