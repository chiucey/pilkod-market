# 北京高中地理核心知识点汇总

## 必修一：自然地理

### 1. 地球运动及其地理意义
- 地球自转：产生昼夜交替、地方时差
- 地球公转：产生四季更替、正午太阳高度变化、昼夜长短变化
- 北京位于北纬39°56'，太阳高度角计算
- 二十四节气与农业生产

### 2. 大气环流与气候
- 北京属温带季风气候
- 夏季高温多雨（东南季风）
- 冬季寒冷干燥（西北季风）
- 年降水量600-800mm
- 主要气象灾害：暴雨、洪涝、干旱、沙尘暴

### 3. 水循环与水资源
- 北京水资源短缺的原因
- 南水北调工程
- 地下水超采问题
- 水资源保护措施

### 4. 地形地貌
- 北京地形：平原与山地交界
- 西北部为山地（太行山、燕山）
- 东南部为平原
- 主要河流：永定河、潮白河

### 5. 自然灾害与防治
- 地质灾害：地震、滑坡、泥石流
- 气象灾害：暴雨、冰雹
- 防灾减灾措施

## 必修二：人文地理

### 1. 人口与城市
- 北京人口特点：总量大、增长快、人才集中
- 城市化进程
- 城市功能分区
- 京津冀城市群

### 2. 产业活动与区位
- 第一产业：都市型现代农业
- 第二产业：高端制造业
- 第三产业：金融、文化、科技
- 产业集聚与分散
- 国家级产业园区：中关村科技园区、北京经济技术开发区

### 3. 交通运输
- 北京交通枢纽地位
- 公路：高速公路网络
- 铁路：高铁网络
- 航空：首都国际机场、大兴国际机场
- 城市轨道交通

### 4. 人地关系与可持续发展
- 人口、资源、环境与发展协调
- 绿色发展理念
- 生态文明建设
