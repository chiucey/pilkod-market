# 北京高中地理课本文章生成器

## 触发条件

当用户请求以下内容时激活此技能：
- "写一篇关于北京地理的作文"
- "根据地理课本内容生成文章"
- "将XX地理知识点写成文章"
- "北京高中地理相关的文章"
- "用地理知识分析XX"

## 工作流程

### 1. 理解用户需求

- 确认用户需要生成的文章主题
- 确认文章类型（作文、科普、论述等）
- 确认字数要求或详细程度
- 确认是否需要特定地理知识点

### 2. 知识库检索

根据用户需求，检索以下北京高中地理核心知识点：

**必修一（自然地理）**
- 地球运动及其地理意义
- 大气环流与气候
- 水循环与水资源
- 地形地貌成因
- 自然灾害与防治

**必修二（人文地理）**
- 人口与城市分布
- 产业活动与区位选择
- 交通运输布局
- 人地关系与可持续发展

**选择性必修一（区域地理）**
- 北京市的自然环境特征
- 北京城市职能与发展
- 京津冀协同发展
- 北京的生态环境问题

**选修内容**
- 环境保护与生态修复
- 资源开发利用
- 地理信息技术应用

### 3. 文章结构设计

根据文章类型选择合适结构：

**说明文结构**
```
1. 引言（引入主题）
2. 概念定义与背景
3. 主要内容展开
   - 地理原理阐述
   - 北京实例分析
   - 数据支撑
4. 总结与意义
```

**议论文结构**
```
1. 论点提出
2. 论据展开（地理事实）
3. 论证分析
4. 结论
```

**记叙文/散文结构**
```
1. 情景引入
2. 地理知识融入
3. 感悟升华
```

### 4. 内容生成

生成文章时确保：
- 知识准确性（符合地理学原理）
- 语言规范性（符合高中作文要求）
- 内容充实（融入具体地理事实）
- 逻辑清晰（层次分明）

### 5. 输出格式

```
**文章标题**：[根据内容拟定]

**正文**：[生成的文章内容]

**知识点覆盖**：[列出文中涉及的地理知识点]
```

## 质量标准

- 地理概念准确无误
- 符合北京高中地理课程标准
- 文章结构完整、逻辑连贯
- 语言流畅、符合文体要求
