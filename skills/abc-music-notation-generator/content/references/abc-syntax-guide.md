# ABC记谱法完整语法参考

## 基本结构

ABC谱子由头部信息区（header）和音符区（body）组成。

```
X:1              % 曲目编号
T:曲目标题       % Title
C:作曲家        % Composer
M:4/4            % 节拍
K:C              % 调号
% 这里开始音符区
CDEF|GABC|
```

## 头部字段详解

| 字段 | 含义 | 示例 |
|------|------|------|
| X | 曲目编号 | X:1 |
| T | 曲目标题 | T:小星星 |
| C | 作曲家 | C:莫扎特 |
| M | 节拍 | M:4/4, M:6/8 |
| L | 默认音符长度 | L:1/8 |
| K | 调号 | K:C, K:G, K:Dm |
| Q | 速度 | Q:120 |
| B | 书名/来源 | B:民间音乐集 |
| R | 节奏类型 | R:reel, R:jig, R:waltz |

## 音高与音符

### 八度音高
- `c d e f g a b` - 小写音名表示低音区（八度4）
- `C D E F G A B` - 大写音名表示高音区（八度5）
- `c'` `d'` 等表示更高八度
- `C,` `D,` 等表示更低八度

### 音符长度
- 数字后缀表示相对长度
- `/` 表示缩短一半
- `//` 表示缩短到1/4

| 符号 | 含义 |
|------|------|
| C | 全音符 |
| C2 | 二分音符 |
| C4 | 四分音符 |
| C/ | 八分音符 |
| C/2 | 八分音符（另一种写法） |
| C3 | 三连音 |

## 休止符

- `z` - 休止符，z后可跟数字表示长度
- `Z` - 全小节休止符
- `z/2` - 八分休止符
- `z3` - 三连音休止符

## 装饰音与特殊符号

| 符号 | 含义 |
|------|------|
| ~ | 滚奏/装饰音 |
| T | 颤音起始 |
| u | 上波音 |
| v | 下波音 |
| H | 保持音 |
| L | 倚音 |

## 连音与延音

使用方括号表示连音组：
```
"C"DEFG|
```

## 重复与跳转

| 符号 | 含义 |
|------|------|
| | | 单小节线 |
| || | 双小节线 |
| [| | 开始重复 |
| |] | 结束重复 |
| 1 | 第一次演奏 |
| 2 | 第二次演奏 |
| [1 | 第一次演奏开始 |
| [2 | 第二次演奏开始 |

## 和弦与多声部

使用方括号表示和弦：
```
[C2E2G2]|[DF2A2]|  % 和弦
```

## 完整示例

```
X:1
T:小星星
C:莫扎特
M:4/4
L:1/4
K:C
C C G G | A A G2 |
F F E E | D D C2 |
G G F F | E E D2 |
G G F F | E E D2 |
C C G G | A A G2 |
F F E E | D D C2 ||
```

## 生成原则

1. 头部信息至少包含：X、T、M、K
2. 音符行长度适中，便于阅读
3. 使用空格或 | 分隔小节
4. 适当使用装饰音增强表现力
5. 重复段落使用重复记号而非复制
