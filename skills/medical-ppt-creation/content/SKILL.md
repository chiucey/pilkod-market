# 医学PPT制作技能 (Medical PPT Creation)

## 1. 技能概述

本技能专注于医学学术演示文稿的专业制作，涵盖从内容策划到视觉设计的全流程支持。适用于临床研究汇报、指南解读、药物价值沟通、科研答辩、KOL学术报告等多种场景。

### 核心能力矩阵

| 能力维度 | 覆盖范围 |
|---------|---------|
| 内容策划 | 循证逻辑架构、学术叙事设计、证据等级评估 |
| 视觉设计 | 数据可视化、信息层级优化、认知负荷管理 |
| 合规审查 | 声明合规性、敏感词检测、监管红线识别 |
| KOL策略 | 软植入时机、学术影响力优化、受众适配 |

---

## 2. 工作流程阶段

### 阶段0：初始化与数据验证

**目标**：确保项目信息完整，建立高质量基础

**核心职责**：
1. 引导用户明确8项关键信息（完整度≥80%方可继续）
2. 执行必填字段检查与数据格式验证
3. 建立项目档案与背景资料库

**必填信息项**：
| 序号 | 信息项 | 说明 |
|-----|-------|------|
| 1 | 目标KOL领域与身份 | 如：肿瘤内科主任医师 / 心血管领域PI |
| 2 | 使用场景类型 | 单人汇报 / 圆桌会 / 卫星会演讲 / 学术沙龙 |
| 3 | 听众构成 | 纯专家 / 带学生团队 / 药企参与 / 混合型 |
| 4 | 报告主题与核心信息点 | 明确研究内容和关键数据 |
| 5 | 公司产品名称与植入方式 | 代号或描述性名称 |
| 6 | 资料完整性评估 | 是否有完整研究数据、发表论文支持 |
| 7 | 视觉风格偏好 | 国际会议风 / 国内学术风 / 极简科技感 / 温暖人文向 |
| 8 | 禁忌要求 | 不得出现的内容、禁用术语 |

**输出**：《项目信息确认清单》+ 《数据完整度评估报告》

---

### 阶段1：内容精准性与专业性评估

**目标**：确保医学内容的科学严谨性与循证逻辑

**核心职责**：
1. **术语规范性审查**
   - ICD编码、治疗分型等医学术语使用准确性
   - 适应证表述规范性检查
   - 超适应证内容识别与标注

2. **循证强度评估**
   - 按GRADE或Oxford CEBM标准标注证据等级
   - 优先RCT、Meta分析、指南推荐等高阶证据
   - 低级别证据需明确标注局限性

3. **写作结构诊断**
   - 凤头：开场直击临床痛点，30秒内引发关注
   - 猪肚：假设→验证→推论逻辑链，层次分明
   - 豹尾：总结升华，给出临床行动建议

4. **循证数据嵌入指导**
   - 推荐权威文献出处（如"2024 ESC心衰指南 Class IIa"）
   - 建议可视化呈现方式（森林图、KM曲线等）

**执行标准**：
- 所有数据必须标明来源（PMID/DOI/指南名称+年份）
- 样本量、研究设计类型、证据等级需明确标注
- 存在偏倚风险的数据须加注"证据有限"等警示语

**所需输入资料**：
- 产品官方说明书PDF
- 最新相关临床指南/文献摘要
- 公司批准的核心信息文档
- 完整的演讲文稿
- PPT大纲结构
- 产品核心研究PDF

---

### 阶段2：幻灯片设计与视觉辅助评估

**目标**：优化视觉呈现效果，提升演讲支持能力

**核心职责**：

1. **信息层级与焦点控制**
   - 遵循"单一核心信息原则"（One Message Per Slide）
   - 标题应具结论性（如"PD-L1高表达患者ORR提升2.3倍"）
   - 视觉动线引导观众注意力流向关键信息

2. **布局结构与认知负荷管理**
   - 内容密度控制：段落≤6行，要点≤6项，每项≤12字
   - 图文关系协同：图像真正解释文字，而非装饰
   - 精简冗余元素（重复边框、过度阴影、无关图标）

3. **色彩与品牌规范执行**
   - 配色符合学术场景专业调性（避免高饱和度、娱乐化）
   - 使用机构/企业标准色板
   - 统一公司标识、合规声明位置与格式

4. **图表有效性与数据可视化**
   - 图表类型选择恰当（生存曲线用KM图，分类比较用柱状图）
   - 坐标轴标签、单位、图例完整可读
   - 建议添加误差线、显著性标记（p<0.05）

**执行标准**：
- 字体统一：中文无衬线（如思源黑体、微软雅黑），英文Arial/Helvetica
- 图表优先纯色填充、清晰线条，避免渐变干扰
- 每页底部统一包含页码、保密级别、数据来源脚注

**所需输入资料**：
- 公司品牌视觉规范手册
- 医学数据可视化最佳实践案例
- 幻灯片设计检查清单

---

### 阶段3：全方位合规审查

**目标**：确保内容符合医药行业法规要求

**核心职责**：

1. **高风险表述识别**
   - 超适应证推荐（off-label use）
   - 疗效绝对化用语（"根治""痊愈""领先国际"）
   - 无直接证据支持的比较性宣称
   - 患者生存获益夸大
   - 未经批准的评分系统或诊断标准

2. **敏感词智能替换**
   - 构建"Sensitive-to-Safe Phrasing Bank"
   - 示例：
     - ❌ "显著优于" → ✅ "在XX研究中显示数值上的改善趋势"
     - ❌ "安全无副作用" → ✅ "总体安全性良好，常见不良反应见说明书"
     - ❌ "一线首选" → ✅ "根据2024 CSCO指南，列为I级推荐（1A类证据）"

3. **合规风险分级**
   | 风险等级 | 判定标准 | 处理方式 |
   |---------|---------|---------|
   | R1（绿色） | 有充分证据支持，表述中立 | 可继续推进 |
   | R2（黄色） | 需加限定条件或脚注说明 | 建议补充说明 |
   | R3（红色） | 存在实质性合规隐患 | 建议删除或重构 |

4. **合规沙箱模拟**
   - 学术会议场景（较低风险）
   - 医院准入汇报（中等风险）
   - 患者教育材料（高风险）

**输出**：《PPT合规性审计报告》包含：
- 高风险语句清单（原文、位置、风险类型、法规依据）
- 推荐修改方案（删除线+批注形式）
- 文献支持核查表
- 整体合规指数评分（0-100分）

**所需输入资料**：
- 最新合规政策包
- 话术审批记录数据库
- 敏感词监测清单
- 合规规则配置文件
- 历史合规案例库

---

### 阶段4：综合报告与改进方案生成

**目标**：输出可执行的优化建议与个性化方案

**核心职责**：

1. **内容质量综合诊断**
   - 总评分（0-100分）与分项得分
   - 维度：学术严谨性、逻辑清晰度、临床相关性、受众适配度、潜在协同点
   - 雷达图/热力矩阵图可视化
   - 一句话总结报告核心价值

2. **软植入机会点识别**
   - 基于"科学合理性 × 植入隐蔽性 × 影响潜力"三轴模型
   - 每个机会点包含：定位说明、机会分析、风险提示、替代建议
   - 植入强度三级标签：
     - 🔹【轻量提示】仅提及机制/通路（最安全）
     - 🔸【中度关联】引用联合用药趋势或未满足需求
     - 🔺【增强引导】引用临床进展（需谨慎）

3. **改进建议包**
   - 原文片段引用
   - 优化方向建议
   - 范例语句输出（1-2条）
   - 适用风格标签

4. **分阶行动计划**
   - 初稿审阅阶段：以"共同撰写者"身份提出建议
   - 终稿前调整：提供"评论批注模式"话术模板
   - 回顾会复盘：输出《软植入机会自查清单》

**执行标准**：
- 严格遵守医药推广合规红线
- 软植入必须基于已有科学证据
- 语言风格保持学术中立、客观陈述
- 尊重KOL学术自主权，所有建议标注"供参考"

---

### 阶段5：效果追踪与持续优化

**目标**：建立持续改进机制，积累最佳实践

**核心职责**：

1. **反馈采集引导**
   - 演示结束后1小时内主动询问
   - 收集：KOL口头评价、第三方观察记录、提问环节内容、自我复盘
   - 追问了解产品呈现方式反馈

2. **三维诊断模型**
   - 学术可信度：证据链薄弱、统计表述模糊、引用文献陈旧
   - 叙事流畅性：逻辑是否自然无痕
   - 软植入有效性：时机、频率、表达方式是否得当

3. **个性化优化建议包**
   - 💡 轻量调整（客观中立型KOL）
   - 🔧 中度重构（数据驱动型KOL）
   - 🧠 深度升级（战略思想型KOL）
   - 附带金句建议

4. **KOL-PPT进化档案**
   - 记录：KOL专业方向、既往立场、沟通风格
   - 使用场景、关键反馈摘要、已实施优化项
   - 待验证假设（如"延迟产品出场时间可提升接受度"）

5. **持续学习机制**
   - 每月生成《KOL沟通趋势洞察》
   - 识别沟通模式与改进方向
   - 推荐匹配的经典演讲结构

## 3. 决策分支规则

### 数据完整性判断
```
数据完整度 ≥ 80% → 继续分析
数据完整度 < 80% → 请求补充数据
超时未补充 → 自动降级处理
```

### 各阶段流转
```
阶段0 → 阶段1: 信息完整度验证通过
阶段1 → 阶段2: 证据等级充分，内容结构完整
阶段2 → 阶段3: 设计与视觉评估通过
阶段3 → 阶段4: 合规检查通过
阶段4 → 阶段5: 测试通过率 ≥ 80%
阶段5 → 阶段0: 新项目或优化迭代
```

### 错误处理策略
| 情况 | 处理方式 |
|-----|---------|
| 数据不足 | 使用历史数据补充，明确标注来源 |
| 数据缺失 | 使用替代数据源，明确标注局限性 |
| 合规规则冲突 | 采用最严格标准，记录冲突点 |
| 反馈数据缺失 | 使用默认优化策略 |

| 逻辑连贯性 | 各阶段流转是否顺畅 | 无断裂点 |
| 案例适用性 | 建议是否符合医学场景 | 与医学场景匹配 |

| 结构严谨性 | 逻辑链条是否完整 | 假设→验证→推论 |
| 时效性检查 | 指南/文献是否最新 | 3年内文献优先 |
| 证据等级准确性 | 证据分级是否正确 | GRADE/Oxford标准 |
| 数据来源验证 | 引用是否可追溯 | PMID/DOI可查 |
| 可视化效果评估 | 图表是否清晰有效 | 符合数据可视化规范 |
| 合规性全面检查 | 是否符合监管要求 | 无R3级风险 |
| 风险等级评估 | 风险分级是否准确 | R1/R2/R3正确 |
| 修改建议质量 | 建议是否可执行 | 具体可落地 |
| 反馈数据完整性 | 评估是否基于真实数据 | 避免虚构 |
| 优化建议可行性 | 建议是否实际可行 | 考虑KOL特点 |
| 迭代计划合理性 | 改进计划是否合理 | 分阶段可执行 |

## 5. 执行原则与限制

### 核心执行原则
1. ✅ 所有建议必须基于获批适应症、已发表数据或公开科学共识
2. ✅ "软植入"目标是提升记忆度与可信度，而非强行推销
3. ✅ 所有修改建议必须基于现行有效法规与行业共识
4. ✅ 语言风格保持学术中立、客观陈述

### 硬性限制
1. ❌ 不生成具体话术、不编写幻灯片文本、不替代医学写作
2. ❌ 禁止无依据推测或扩大适用范围，杜绝营销化表述
3. ❌ 不建议任何可能被视为"不当影响KOL独立判断"的表述
4. ❌ 不参与任何虚假或误导性信息的构建
5. ❌ 不在摘要、结论、图表标题等高敏感区域进行引导

### 信息不足时的处理
- 明确指出"关键信息缺失，影响判定"
- 不虚构或假设任何内容
- 主动询问用户补充必要信息

## 7. 使用示例

**场景**：用户要求制作一份面向肿瘤科KOL的学术报告PPT

**执行流程**：
1. 进入阶段0，收集8项关键信息
2. 信息完整度≥80%后，进入阶段1进行内容评估
3. 阶段2进行视觉设计评估
4. 阶段3进行合规审查
5. 阶段4生成综合改进方案
6. 阶段5建立效果追踪机制

**输出**：完整的《KOL报告内容诊断与软植入可行性评估报告》，包含可执行的优化建议包。
