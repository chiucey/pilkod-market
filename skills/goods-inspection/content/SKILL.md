# 验货比对分析 Goods Inspection & Comparison

将原文件（PDF设计稿、制令单、规格书等）与实物照片进行详细比对，生成专业的验货报告。

## 核心功能

1. **原文件解析** - 读取PDF、Word等设计稿和规格文件
2. **实物照片分析** - AI识别实物照片中的产品特征
3. **多维度比对** - 尺寸、材质、文字、图案、做工等
4. **生成验货报告** - 输出结构化的验货结论

---

## 验货比对流程

### Step 1: 收集信息

确认以下文件路径：
- **原文件目录**: 包含设计稿、图纸、制令单等
- **实物照片**: 待验货产品的实拍照片

### Step 2: 分析原文件

使用 `extract_pdfs_full_content` 或 `extract_pdfs_key_info` 提取PDF内容：

```
提取内容：
1. 产品编号/名称
2. 尺寸规格
3. 材质要求
4. 文字内容（中英文）
5. 图案描述
6. 特殊工艺要求
```

### Step 3: 分析实物照片

使用 `images_understand` 进行照片分析：

```
照片分析维度：
1. 尺寸比例是否正确
2. 材质/表面工艺是否符合（哑光/亮光等）
3. 文字内容拼写是否正确
4. 图案是否清晰完整
5. 整体做工质量（气泡、褶皱、切割等）
```

### Step 4: 生成验货报告

输出结构化报告，包含：

```
报告结构：
1. 原文件清单
2. 实物照片信息
3. 产品规格要求
4. 比对结果（分项打分）
   - 尺寸规格 ✅/❌
   - 材质工艺 ✅/❌
   - 文字内容 ✅/❌
   - 图案印刷 ✅/❌
   - 整体做工 ✅/❌
5. 验货结论（合格/不合格/待定）
6. 问题清单与修正建议
```

## 比对检查项清单

### 必检项目

| 检查项 | 检查内容 | 判定标准 |
|--------|----------|----------|
| **尺寸规格** | 长宽尺寸、比例 | 与设计稿误差≤±3mm |
| **材质工艺** | 材料类型、表面处理 | 符合规格书要求 |
| **文字内容** | 文字拼写、翻译准确性 | 无错别字、内容一致 |
| **图案印刷** | 清晰度、色彩还原、完整性 | 与设计稿一致 |
| **切割做工** | 边缘整齐度、有无毛刺 | 切割平整、无崩边 |

### 常见问题类型

| 问题类型 | 描述 | 严重程度 |
|----------|------|----------|
| 尺寸偏差 | 尺寸超出公差范围 | 🔴 高 |
| 材质不符 | 使用了错误的材料 | 🔴 高 |
| 拼写错误 | 文字内容有错别字 | 🔴 高 |
| 图案模糊 | 印刷不清晰 | 🟡 中 |
| 气泡/褶皱 | 表面有质量问题 | 🟡 中 |
| 切割不良 | 边缘不整齐 | 🟡 中 |
