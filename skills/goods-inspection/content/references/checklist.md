# 验货检查清单参考

## 一、印刷品验货清单

### 1.1 常规检查
- [ ] 尺寸是否符合规格（量具测量）
- [ ] 材质是否正确（手感、光泽、厚度）
- [ ] 颜色是否与设计稿一致
- [ ] 文字是否清晰可读
- [ ] 图案是否完整无缺失

### 1.2 印刷质量
- [ ] 无明显色差
- [ ] 无套印不准
- [ ] 无墨皮/墨点
- [ ] 无蹭脏
- [ ] 渐变过渡自然

### 1.3 后加工
- [ ] 覆膜均匀（哑膜/亮膜）
- [ ] 压痕/折痕整齐
- [ ] 切割边平整
- [ ] 无毛刺/崩边

---

## 二、五金/塑料制品验货清单

### 2.1 外观检查
- [ ] 表面无划痕/碰伤
- [ ] 无气泡/缩痕
- [ ] 无飞边/毛刺
- [ ] 颜色/光泽均匀

### 2.2 尺寸检查
- [ ] 主要尺寸在公差内
- [ ] 螺纹完整
- [ ] 配合尺寸正确

### 2.3 功能检查
- [ ] 活动件灵活
- [ ] 密封性良好（如适用）
- [ ] 标识清晰

---

## 三、包装验货清单

### 3.1 包装材料
- [ ] 材质规格正确
- [ ] 尺寸合适
- [ ] 无破损

### 3.2 印刷内容
- [ ] 标签内容完整
- [ ] 条码可扫描
- [ ] 生产日期/批号正确

### 3.3 装配
- [ ] 封口平整
- [ ] 内衬到位
- [ ] 数量正确

## 六、常见缺陷分类

### 严重缺陷（Critical）
- 安全问题
- 功能完全失效
- 法规不符合

### 主要缺陷（Major）
- 影响使用功能
- 外观严重瑕疵
- 标识错误

### 次要缺陷（Minor）
- 轻微外观问题
- 不影响使用的小瑕疵
