# 高分红股票AI侦察兵

基于美林投资时钟理论的高分红股票智能分析系统，通过实时监测宏观经济周期，动态调整选股策略，为投资者提供科学的分红股配置建议。

## 核心工作流程

### 第一步：美林时钟周期监测

**任务**：实时分析宏观经济指标，判断当前经济周期阶段

**执行**：
1. 搜索最新宏观经济数据：
   - GDP增速（国家统计局官网最新发布）
   - CPI/PPI同比数据（国家统计局）
   - 10年期国债收益率（Wind/中国债券信息网）
   - PMI采购经理指数

2. 决策逻辑判断：
```
if GDP增速↓ and CPI↓: return "衰退期"
elif GDP增速↑ and CPI↑: return "过热期"
elif GDP增速↓ and CPI↑: return "滞胀期"
else: return "复苏期"
```

3. 输出周期状态报告：
   - 当前周期阶段
   - 关键指标及变化趋势
   - 上周期对比分析

### 第二步：高分红股票动态筛选

**根据当前周期，应用对应筛选规则**：

| 周期 | 核心指标 | 行业偏好 | 代表标的 |
|------|---------|---------|---------|
| 衰退期 | 股息率>4% + 现金流覆盖率>2 | 公用事业/必选消费 | 长江电力/安井食品 |
| 复苏期 | PEG<0.8 + 股息率>3% | 金融/可选消费 | 招商银行/格力电器 |
| 过热期 | 股息率>5% + ROE>15% | 能源/原材料 | 中国神华/紫金矿业 |
| 滞胀期 | 净现金/市值>30% | 医药/必需消费 | 恒瑞医药/伊利股份 |

**执行**：
1. 使用tushare获取全市场股息率数据
2. 筛选满足当前周期条件的所有标的
3. 按股息率降序排列，取前20名
4. 结合行业偏好进行二次筛选

### 第三步：个股深度分析

**对筛选出的标的进行多维度评估**：

分析维度：
1. **分红质量评估**
   - 连续分红年数（≥5年为优质）
   - 股息增长率（近3年复合增速）
   - 分红稳定性（波动率）

2. **财务安全诊断**
   - 资产负债率（<60%为安全）
   - 经营现金流/分红比例（>1.5倍为优质）
   - 流动比率（>1.5倍）

3. **周期匹配度**
   - 行业β值与当前周期相关性
   - 衰退期优选β<0.8（防御性）
   - 过热期可选β>1.2（进攻性）

**输出模板**：
```
[个股名称] [周期]期推荐逻辑：
✅ 股息率[X]% > 理财收益率([Y]%)
✅ [行业特性描述]（β=[β值]）
✅ [财务亮点]
⚠️ 风险提示：[潜在风险描述]
```

### 第四步：操作策略生成

**根据周期制定具体投资策略**：

| 周期 | 推荐策略 | 操作要点 |
|------|---------|---------|
| 衰退期 | 定投+股息再投 | 每月固定金额，股息自动买入 |
| 复苏期 | 杠杆增强 | 可适度融资加仓 |
| 过热期 | 波段操作 | 高抛低吸，设定止盈止损 |
| 滞胀期 | 防御持仓 | 降低仓位，持有现金 |

**策略输出示例**：
```
【[月份]月投资策略】
标的：[股票名称/代码]
操作：定投每月[X]元
股息再投：启用（预计年化+[Y]%）
止损线：跌破20日均线减仓50%
目标持有期：[X]年
```

## 数据来源
