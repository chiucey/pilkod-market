# 高分红股票筛选标准参考

## 核心指标体系

### 一、分红质量指标

| 指标 | 计算方式 | 优质标准 | 说明 |
|------|---------|---------|------|
| 连续分红年数 | 统计连续分红次数 | ≥5年 | 体现分红稳定性 |
| 股息率 | 分红/股价×100% | >3.5% | 与无风险收益对比 |
| 股息增长率 | (本期股息-上期)/上期 | >5% | 体现成长性 |
| 分红比例 | 分红/净利润 | 30-60% | 适中为优 |

### 二、财务安全指标

| 指标 | 计算方式 | 优质标准 | 说明 |
|------|---------|---------|------|
| 资产负债率 | 负债/资产×100% | <60% | 财务杠杆水平 |
| 现金流覆盖率 | 经营现金流/分红 | >1.5倍 | 分红可持续性 |
| 流动比率 | 流动资产/流动负债 | >1.5倍 | 短期偿债能力 |
| 净利润现金含量 | 经营现金流/净利润 | >80% | 盈利质量 |

### 三、估值与盈利指标

| 指标 | 计算方式 | 优质标准 | 说明 |
|------|---------|---------|------|
| PE | 股价/每股收益 | <15倍 | 估值合理性 |
| PEG | PE/利润增速 | <1 | 成长性价比 |
| ROE | 净利润/净资产×100% | >12% | 股东回报 |
| 净现金/市值 | 净现金/总市值×100% | >20% | 资产安全性 |

### 四、行业β值参考

β值反映个股与大盘的相关性，用于周期匹配：

| 行业 | 平均β值 | 周期偏好 |
|------|--------|---------|
| 公用事业 | 0.4-0.7 | 衰退/滞胀 |
| 必选消费 | 0.5-0.8 | 全周期 |
| 医药 | 0.6-0.9 | 滞胀 |
| 金融 | 0.8-1.2 | 复苏 |
| 可选消费 | 0.9-1.3 | 复苏/过热 |
| 能源 | 1.0-1.5 | 过热 |

## 行业特殊标准

### 公用事业（水电/电力）

- 稳定现金流是核心
- 重点关注：装机容量、电价政策
- 优质标的：长江电力、国投电力

### 必选消费（食品/饮料）

- 需求刚性是优势
- 重点关注：市占率、原材料成本
- 优质标的：伊利股份、安井食品

### 银行

- 分红稳定但需精选
- 重点关注：不良贷款率、拨备覆盖率
- 优质标的：招商银行、工商银行

### 房地产（REITs类）

- 高分红特色鲜明
- 重点关注：出租率、租金回报率
- 优质标的：万科A、保利发展

## 负面清单（剔除标准）

1. 连续2年不分红
2. 分红率>80%（可能不可持续）
3. 经营现金流为负
4. 资产负债率>80%
5. 净利润连续2年下滑
6. 存在财务造假风险

## 使用示例

### 衰退期筛选配置

```
基础条件：
- 股息率 > 4%
- 现金流覆盖率 > 2
- 资产负债率 < 60%
- 行业β < 0.8

加分项：
- 连续分红年数 ≥ 10年
- 股息率 > 5%
- 净现金/市值 > 30%
```

### 过热期筛选配置

```
基础条件：
- 股息率 > 5%
- ROE > 15%
- 净利润增速 > 10%
- 行业β > 1.0

加分项：
- 资源禀赋（能源/矿业）
- 定价能力（品牌溢价）
- 产能扩张潜力
```
