# 战略分析师实战模板库

## 模板1：三场景快速路由卡

```
接到问题后，先回答这3个问题：

Q1: 分析对象是什么阶段？
  → 0→1新项目/初创 .......... 进入场景A
  → 成长期/上市企业 .......... 进入场景B
  → 大型组织内部变革 ......... 进入场景C
  → 跨场景（如上市公司孵化新业务）.. 主场景B，辅以A工具

Q2: 核心问题是什么类型？
  → 值不值得做 / 怎么做 ........ 假设导向 + 五看三定
  → 如何持续增长 ............... 三地平线 + 价值树
  → 组织/流程哪里卡住了 ........ 7S + BLM执行层诊断

Q3: 输出给谁？
  → CEO/投资人 .................. 电梯演讲 + 金字塔结论先行
  → 管理团队 ..................... 完整分析 + 实施路线图
  → 内部工作坊 .................. 议题树 + 综合三部曲卡
```

## 模板7：电梯演讲打磨四步

```
第一步：先写200字（信息全，不删任何关键信息）
第二步：砍到80字（删修饰词，保骨架）
第三步：砍到60字（每字必须有功能）
第四步：大声朗读3遍，检验：
  ① 30秒内说完
  ② 包含：背景/冲突/方案/价值（缺一不可）
  ③ 价值部分必须含具体数字
  ④ 听完会问"具体怎么做？"而不是"你在说什么？"
```

## 模板8：输出质量8维自检

```
输出前逐项确认，任一不通过即重写：

[ ] 1. MECE：同层论点0重叠、0遗漏
[ ] 2. 假设：每个假设有验证状态标签[✅/❌/🟡/⚪]
[ ] 3. 金字塔：首句即结论，同层MECE
[ ] 4. So What：0条裸数据，每条数据有含义和影响
[ ] 5. 电梯：30秒说清且含量化价值
[ ] 6. 可执行：Who/When/KPI/资源/退出条件5项齐全
[ ] 7. 取舍：显式列出"不做项"清单
[ ] 8. 韧性：至少1套下行情景预案
```

## 模板9：AI项目专项核查清单

```
在常规分析基础上，AI/数据类项目额外核查：

护城河维度：
[ ] 是否识别出专有垂直数据资产（而非依赖通用模型）？
[ ] 数据飞轮逻辑是否清晰（更多用户→更多数据→更好模型）？
[ ] 临界点估算是否合理（多少用户/数据才能启动飞轮）？

成本维度：
[ ] 算力/推理成本是否单独建模（不能并入一般IT成本）？
[ ] 合规成本是否单列（EU AI Act/PIPL，通常占预算10-25%）？
[ ] 供应商锁定风险是否评估（单一闭源API的备案方案）？

竞争维度：
[ ] 是否分析了主要对手的AI能力积累速度？
[ ] 竞争窗口是否合理（AI领域先发优势衰减极快）？
[ ] 是否评估了"大模型直接进入你的赛道"的颠覆风险？

合规维度：
[ ] EU AI Act风险等级是否明确（不可接受/高风险/通用GPAI）？
[ ] 数据出境路径是否合规（中国/欧盟/美国三地本地化要求）？
[ ] 训练数据合规是否在立项期评估（而非推迟到执行阶段）？
```
