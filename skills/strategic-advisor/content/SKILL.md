```
场景识别（0.1）→ 信息澄清（0.2）→ 假设前置（0.3）→ 结论先行（0.4）→ 分析主体
```

### 0.1 场景识别（决定分析路由与工具组合）

**三类场景，分析重心截然不同：**

| 场景 | 核心问题 | 主导框架 | 辅助工具 |
|---|---|---|---|
| 🚀 **A. 初创/新项目** | 这个机会值不值得做？能不能赢？ | BLM机会差距 + 五看三定 + 单位经济 | 假设导向、MECE逻辑树、情景规划 |
| 📈 **B. 上市企业战略** | 如何持续创造股东价值？下一步增长从哪来？ | 麦肯锡三地平线 + 价值树 + GE矩阵 | BLM业务设计、情景规划、7S诊断 |
| 🏭 **C. 大企业流程/组织** | 哪里卡住了？如何变革？效率从哪里来？ | 麦肯锡7S + BLM执行层（关键任务/组织/人才/文化） | MECE诊断树、假设导向、双元性模型 |

**场景识别规则：**
- 用户明确说出场景 → 直接进入对应路由
- 用户描述模糊 → 先问两个问题（见0.2），再判断场景
- 同一问题跨多个场景 → 明确主场景，次场景工具作补充

### 0.2 意图澄清（描述不足150字或场景不明时触发）

**必问两个问题（不超过两问，不得一次抛出清单）：**

**问题①：实体类型**
- 初创/新项目（产品或业务处于0→1阶段）
- 成长期企业（已有收入，处于规模化阶段）
- 上市/成熟企业（营收稳定，寻求第二增长曲线）
- 大型组织内部变革（职能/流程/组织架构优化）

**问题②：分析深度**
- ⚡ **快速诊断**（500-1000字）：核心判断 + 3条洞见 + 建议行动
- 📋 **标准分析**（3000-5000字）：场景对应的完整框架
- 🔬 **深度可研**（5000-8000字）：全链路分析，含财务模型、情景预案、执行路线图

### 0.3 假设前置（正式分析前，先形成1-3个可证伪初始假设）

在收集数据前形成假设——这是麦肯锡效率的核心：

```
初始假设：[一句话，必须可证伪]
关键验证点：① ... ② ... ③ ...
验证状态：✅已验证 / ❌已证伪 / 🟡部分验证 / ⚪待验证
若证伪：[修正方向]
```

**合理性过滤**：无法基于行业基准做粗略判断的假设，可能是脱离现实的脑补，需标注`[⚠️高度不确定假设，优先验证]`。

```
┌────────────────────────────────────────────────┐
│                 【核心判断】                      │
│  🟢 推进  /  🟡 小步验证  /  🟠 暂缓  /  🔴 放弃  │
│                                                │
│  一句话结论：[20字以内，含动作+方向]              │
│  信心评级：★★★☆☆（X/5）                         │
│                                                │
│  核心逻辑（3条，事实+洞见+影响）：               │
│  1. [最强支撑] → [战略含义]                      │
│  2. [最大风险] → [触发信号]                      │
│  3. [关键假设] → [验证方法 + 时间]               │
└────────────────────────────────────────────────┘
→ 详细分析见下文
```

**判断标准：**

| 判断 | 条件 | 行动 |
|---|---|---|
| 🟢 推进 | 逻辑自洽 + 壁垒可识别 + 团队/资源匹配 + 单位经济健康 | 立项并配置完整资源 |
| 🟡 小步验证 | 机会真实，但Top3假设有≥1个未验证 | MVP/灰度试点，先验证再扩大 |
| 🟠 暂缓 | 项目有价值，但外部窗口未开 / 资源缺口明确可预期 | 设定重启触发条件，保持关注 |
| 🔴 放弃 | 市场天花板极低 / 无战略控制点 / 核心假设已证伪 / 单位经济崩塌 / 重大合规障碍 | 明确止损，释放资源 |

## 场景A：初创 / 新项目分析

> **核心工具**：BLM机会差距 + 华为五看三定 + 麦肯锡假设导向 + 单位经济验证

### A1. 差距分析 — 锚定起点

**机会差距（新项目重点）**

- 战略野心 vs 零起点落差：决策层期望的3年回报 vs 当前现状
- 赛道天花板（TAM）vs 当前能力可触达份额（SOM）
- **核心判断**：是"能力不足"（需投资建能力）还是"方向偏差"（需调整战略）？

### A2. 五看市场洞察

| 维度 | 核心问题 | AI时代特别关注 |
|---|---|---|
| **看趋势** | 长期演进规律是什么？ | AI重塑路径与时间表、监管窗口（EU AI Act / PIPL） |
| **看市场** | TAM/SAM/SOM三层结构？ | 数字平台是否改变市场边界？ |
| **看客户** | 客户为什么买？TCO是多少？ | AI是否改变了客户的决策路径和价格敏感性？ |
| **看竞争** | 我们如何活下来？ | 对手的AI能力积累速度、数据壁垒深度 |
| **看机会** | 爆发点在哪里？ | 技术拐点（成本下降10x）、监管放开、被AI颠覆的传统环节 |

**PESTEL强制六维**（L维度为高优先级，重大缺口构成放弃条件）：

| 维度 | 关键发现（≤3条） | 战略含义 |
|---|---|---|
| P 政治/政策 | | |
| E 经济环境 | | |
| S 社会文化 | | |
| T 技术趋势 | | |
| E 环境/ESG | | |
| L 法律法规 | | |

> AI/数据类项目必须在L维度审视：EU AI Act风险等级（不可接受/高风险/通用GPAI）、PIPL/数据安全法约束、跨境数据出境路径。合规成本通常占项目预算10-25%，必须在财务模型中单列。

## 场景B：上市企业战略咨询

> **核心工具**：麦肯锡三地平线 + 价值树 + GE矩阵 + BLM业务设计 + 情景规划

### B1. 问题定义（SMART）

用一句话陈述战略核心问题：

```
[公司X]在[时间窗口]内，如何[具体目标]，在[约束条件]下，
使[关键指标]从[基线值]达到[目标值]？
```

边界声明：什么在分析范围内，什么不在。

### B2. MECE问题拆解

**选择拆解维度（按问题类型选择，禁止全部套用）：**

- **业务增长问题** → 三地平线 + 价值树分解
- **竞争战略问题** → 市场吸引力 × 竞争地位（GE矩阵）
- **价值创造问题** → ROIC价值树逐层拆解至可操作驱动因素
- **转型变革问题** → 7S组织诊断 + BLM执行层

**MECE自检三问：**
- 这些分类有重叠吗？（互斥性）
- 加总之后够完整吗？（穷尽性）
- 这种分类有商业含义吗？（避免无效切分）

### B3. 增长三地平线分析

> **模型说明**：三地平线由麦肯锡开发，定义的是业务**生命周期阶段**，时间跨度因行业而异（快消品H1/H2/H3约1/2/5年；航空航天可能是5/10/20年）。

| 地平线 | 定位 | 资源配比建议 | 财务特征 | 当前状态 |
|---|---|---|---|---|
| H1（守住核心） | 当前核心业务 | 70% | 现金流主力，利润主贡献 | |
| H2（培育新兴） | 新兴业务成长 | 20% | 高增长但未盈利，需持续投入 | |
| H3（探索远期） | 远期选项投资 | 10% | 多数失败，少数颠覆 | |

**资源平衡警示：**
- H1 > 85% → 增长枯竭风险
- H3 > 20% → 现金流断裂风险

**AI时代特别提示**：H3中的AI原生业务可能以指数级速度进入H2，传统三地平线时间估算需压缩30-50%。

### B4. 价值树分析

将股东价值逐层拆解至可操作的驱动因素：

```
ROIC（投资资本回报率）
├─ 营业利润率
│    ├─ 收入
│    │    ├─ 价格（品牌溢价 / 产品组合 / 定价模型）
│    │    └─ 销量（市场份额 × 市场规模）
│    └─ 成本
│         ├─ COGS（含算力成本/AI推理成本）
│         └─ 期间费用
└─ 资本周转率
     ├─ 营运资本周转
     └─ 固定资本周转
```

**价值检验**：分析建议影响哪些叶节点？影响幅度是ROIC提升+X个bps？

### B5. 业务组合诊断（GE-麦肯锡九宫格）

对各业务单元评分（每项1-5分）：

**市场吸引力**：市场规模、增速、利润率、竞争强度、监管风险、技术变革影响

**竞争地位**：市场份额、品牌、成本结构、渠道、技术能力、数据资产（AI时代新增）

| 业务单元 | 市场吸引力 | 竞争地位 | 决策 |
|---|---|---|---|
| | | | 投资/选择/收割/剥离 |

### B6. 战略建议 + 金字塔输出

**SCQA叙事包装**（源自芭芭拉·明托《金字塔原理》，被麦肯锡广泛采用）：
- **S（情境）**：公司/行业当前稳定状态
- **C（冲突）**：出现了什么变化/挑战
- **Q（问题）**：决策者面临的核心抉择

**金字塔结构输出：**

```
【实施路线图】

  举措2：...
  举措3：...

```

### B7. 情景规划（韧性测试）

|---|---|---|---|---|---|

| 上行 | 20% | KPI超+30% | 加速扩张 | | — |
| 下行 | 15% | KPI低于-30% | 现金保护+收缩 | | 触发Plan B |
| 黑天鹅 | 5% | 极端事件（地缘/监管） | 危机预案 | 不可预测 | 董事会决策 |

**地缘政治压力测试**（涉及跨境业务必填）：

- 关键供应链中断时的备选路径（ASEAN/印度/墨西哥）

## 场景C：大企业业务流程梳理与组织变革

> **核心工具**：麦肯锡7S + BLM执行层 + MECE诊断树 + 双元性组织模型

### C1. 问题定义与边界

```
[组织X]在[时间窗口]内，如何解决[具体症状]，
使[关键指标]从[基线值]改善至[目标值]？

在范围内：[明确列出]
不在范围内：[明确排除]
成功标准：[可量化的交付物]
```

### C2. 7S组织诊断

> **模型来源**：麦肯锡开发，适用于组织变革、并购整合、战略落地评估。局限性：静态特征强，不告诉决策者"先动哪个S"，需叠加优先级判断。中小企业可仅做"战略-结构-技能"三项核心诊断。

| S要素 | 类型 | 当前状态 | 理想状态 | 匹配度（🔴/🟡/🟢） |
|---|---|---|---|---|
| Strategy（战略） | 硬 | | | |
| Structure（结构） | 硬 | | | |
| Systems（系统/流程） | 硬 | | | |
| Shared Values（共同价值观） | 软 | | | |
| Style（领导风格） | 软 | | | |
| Staff（人才构成） | 软 | | | |
| Skills（核心能力） | 软 | | | |

**7S失配诊断**：21个两两交叉点中，标注所有🔴（严重失配）和🟡（部分失配）项，按优先级排序修复。

**AI时代新增诊断维度**：
- AI流利度（组织整体AI工具使用能力）
- 数据治理成熟度（数据质量/权属/流通机制）
- 自动化覆盖率（核心流程中可自动化/已自动化的比例）

### C3. 流程诊断 — MECE拆解问题树

**诊断树（Issue Tree）构建规则：**
1. 顶层：一句话陈述核心症状（如"研发效率低"）
2. 第二层：MECE拆解成因（供给侧/需求侧，或人/流程/工具/数据）
3. 第三层：每个成因的具体表现和量化程度
4. 底层：可操作的干预点

**AI/数字化诊断特别问题：**
- 哪些流程仍依赖人工决策但实际上可以被算法替代？
- 数据孤岛在哪里？打通后能释放多少效率？
- 现有系统中有多少"影子流程"（绕过正式系统的非正式工作方式）？

### C4. BLM执行层诊断

**关键任务（Key Tasks）**

检验战略解码质量：
- 所有关键任务是否有明确责任人（具体的人，不是部门）？
- 是否有可量化的截止日期和产出物？
- 关键任务之间是否存在逻辑断层（战略→举措→任务的连接是否完整）？

**正式组织（Formal Organization）**

- 组织架构是否支撑战略意图？
- 决策链长度是否合理（超过4层通常是效率杀手）？
- 关键流程是否标准化且数字化？

**人才（Talent）**

- 关键岗位胜任力缺口在哪里？
- AI时代新增：核心岗位的AI辅助能力评估

**氛围与文化（Culture）**

- 当前文化对变革的支持程度
- 创新容错机制是否存在（失败被惩罚 vs 快速学习被奖励）

### C5. 双元性组织诊断

**探索（Exploration）vs 开发（Exploitation）的平衡：**

| 创新类型 | 特征 | 建议组织形态 |
|---|---|---|
| 渐进式改进 | 优化现有产品/流程 | 嵌入现有部门 |
| 延伸式创新 | 进入相邻市场/客群 | 独立小组，共享部分资源 |
| 颠覆式创新 | 全新市场/商业模式 | **独立子公司**（强烈推荐完全隔离） |

> **根本问题**：这个新业务/新流程，是被现有组织"改进"还是"排异"？

### C6. 综合洞见输出（事实+洞见+影响三部曲）

每条核心发现必须写成：

```
═══════════════════════════════════════
洞见卡 #N
═══════════════════════════════════════
【事实】（含数字+时间+来源，禁止裸数据）
...

【洞见】（这意味着什么？为什么？）
...

【商业影响】（如果不行动，损失多大？多快？）
...

【建议动作】
Who：[单一责任人]
When：[截止日期]
KPI：[量化目标，含基线和目标值]
资源：[人/钱/技术需求]
退出条件：[什么情况下调整]
═══════════════════════════════════════
```

**强制规则**：裸数据+无洞见+无影响 = 无效输出，整段必须重写。

### C7. 变革路线图

```
快赢阶段（0-3个月）：建立信心，展示变革价值
  举措：[任务] | 责任人：[Who] | 产出：[可见成果]
  成功信号：[什么现象说明快赢实现]
```

## 通用工具层（三场景共用）

### T1. 电梯演讲（30秒压缩测试）

任何分析的最终检验——能否30秒内说清核心？

| 时段 | 内容 | 字数 |
|---|---|---|
| 0-5秒 | 背景：一句话锁定当前状态 | 15-20字 |
| 5-10秒 | 冲突：核心挑战/抉择 | 15-20字 |
| 10-20秒 | 方案：核心建议（金字塔塔尖） | 30-40字 |
| 20-30秒 | 价值：**必须量化**（ROI/时间/业务指标） | 15-25字 |

**训练法**：先写200字 → 砍到80字 → 砍到60字 → 大声朗读检验。

### T2. 四维可行性测试

任何重大建议在进入实施前，必须通过四维测试：

| 维度 | 评估问题 | 🔴 | 🟡 | 🟢 |
|---|---|---|---|---|
| 政治可行性 | 有无关键支持者？是否触动既得利益？ | 核心高管反对 | 需跨部门协调 | CEO直接背书 |
| 资源可行性 | 人/钱/技术缺口多大？ | 缺口>50% | 缺口20-50% | 缺口<20% |
| 时间可行性 | 能否在战略窗口期内完成？ | 错过窗口 | 紧贴窗口 | 留有缓冲 |
| 法规可行性 | 是否触发监管/合规风险？ | 明确违规 | 灰色地带 | 合规明确 |

**规则**：任一🔴 → 列为"前置依赖"，未解决前不进入实施计划。

### T3. 空·雨·伞 快速洞见框架

适用于快速诊断和日常沟通场景（日本麦肯锡常用，非全球通用）：

```
☁️ 空（事实/观察）：[客观现象，不加判断]
🌧️ 雨（分析/洞见）：[这意味着什么？逻辑推断]
☂️ 伞（行动/建议）：[因此我们应该做什么？]
```

### T4. 80/20 聚焦法则

识别产生80%结果的20%关键驱动因素：
1. 列出所有要素
2. 按贡献度排序
3. 找到帕累托拐点
4. 聚焦拐点前的关键少数，明确放弃其余

## 常见陷阱

**经典战略陷阱：**
- ❌ 市场够大就能做（忽略竞争强度和进入壁垒）
- ❌ 技术领先就能赢（忽略商业化能力和市场教育成本）
- ❌ 只有生意，没有壁垒（为行业探路，为对手作嫁衣）
- ❌ 战略意图与成本结构脱节（想做高端，但成本只支撑低端）
- ❌ 任务没有责任人和时间表（无效战略解码）
- ❌ 组织文化冲突被低估（传统企业孵化创新的首要死因）
- ❌ 把BLM/麦肯锡框架当成填空模板（没有真正的战略对话，沦为PPT堆砌）

**AI时代新增陷阱：**
- ❌ 假设AI能力可快速商业化（忽略用户接受度和部署成本）
- ❌ 用通用模型+公开数据建立护城河（垂直专有数据才是AI护城河）
- ❌ 忽视算力/推理成本对利润的持续侵蚀（财务模型必须单列技术成本）
- ❌ 过度依赖单一闭源AI供应商（API涨价/断供/政策变化风险）
- ❌ 低估竞争窗口收窄速度（大模型能力迭代极快，先发优势衰减迅速）
- ❌ 将数据合规风险下沉到执行阶段（立项期就要评估合规成本，占预算10-25%）

**地缘政治陷阱：**
- ❌ 假设当前贸易关系会持续（忽视关税突变与出口管制风险）
- ❌ 单一供应链节点依赖（缺乏ASEAN/印度等备选路径）
- ❌ 财务模型未做地缘压力测试（关税跳变20%时的现金流模拟缺失）
