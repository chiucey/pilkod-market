# 情绪关键词完整指南

本指南系统整理了短剧创作中各类情绪氛围的描述词汇，帮助创作者精准传达情感状态，用于剧本写作和Seedance 2.0提示词生成。

---

## 一、基础情绪词汇

### 1.1 喜悦与幸福

#### 温暖幸福

| 中文 | 英文 | 适用场景 |
|-----|------|---------|
| 温馨 | warm, cozy, comforting | 家庭场景、亲密时刻 |
| 甜蜜 | sweet, sugary, adorable | 恋爱初期、撒糖时刻 |
| 幸福 | happy, joyful, blissful | 圆满结局、梦想成真 |
| 满足 | content, satisfied, fulfilled | 和解、成功、释然 |
| 安心 | peaceful, at ease, secure | 依靠、归属、放下 |
| 放松 | relaxed, carefree, tranquil | 度假、逃离、独处 |
| 愉悦 | cheerful, pleasant, delightful | 日常互动、朋友相处 |

**Seedance提示词示例**：
```
Warm golden hour lighting bathes the scene in a comforting glow, the couple's soft laughter echoing in the air.

Atmosphere of pure bliss as the reunited family embraces, tears of joy glistening on their cheeks.

Delightful scene of children playing in a sunlit meadow, their innocent joy contagious and heartwarming.
```

## 四、情绪组合公式

### 4.1 虐心场景组合

**核心公式**：悲伤情绪 + 美好回忆反差 + 环境渲染

**示例**：
```
[悲伤] heartbreak + [回忆] memory of happier times + [环境] empty room

= 心碎场景：前任物品散落房间，回忆涌上心头

Sadness and loss permeating a room filled with remnants of a failed relationship, each object triggering a painful memory.
```

---

### 4.2 甜蜜场景组合

**核心公式**：幸福情绪 + 亲密互动 + 温馨环境

**示例**：
```
[幸福] joy + [亲密] physical closeness + [环境] warm setting

= 甜蜜场景：夕阳下的海边漫步

Joyful intimacy as the loving couple walks hand in hand along the beach at sunset, golden light painting everything in warmth.
```

---

### 4.3 紧张场景组合

**核心公式**：危机感 + 时间压力 + 危险暗示

**示例**：
```
[危机] danger + [时间] countdown + [危险] threat

= 紧张场景：炸弹倒计时中的抉择

Desperate tension as the protagonist races against the bomb's countdown, every second precious, threat closing in.
```

---

### 4.4 复仇场景组合

**核心公式**：决心 + 力量感 + 戏剧对比

**示例**：
```
[决心] determination + [力量] power + [对比] before/after

= 复仇场景：浴火重生的逆袭

Powerful scene of transformation from victim to victor, the fallen woman rising from ashes with cold fire in her eyes.
```

## 六、实用情绪表达模板

### 6.1 场景情绪快速描述模板

**模板**：
```
[情绪] + [程度副词] + [表达方式] + [细节描写]

示例：
深沉的悲伤如潮水般涌来，她独自坐在空荡荡的房间里，手中紧握着那封再也无法送达的信。
```

**Seedance版本**：
```
Overwhelming sadness washing over the solitary figure, she sits in the empty room clutching an unsendable letter.
```

---

### 6.2 多层次情绪交织模板

**模板**：
```
[主情绪] while [次情绪], creating [整体氛围]

示例：
表面平静如水的他内心却翻涌着愤怒与不甘，整个对峙场景弥漫着一触即发的张力。
```

**Seedance版本**：
```
Surface calm masking seething fury, the confrontation building to explosive tension, every muscle tensed for action.
```

---

### 6.3 情绪转变模板

**模板**：
```
From [起始情绪] to [转折] to [最终情绪]

示例：
从最初的惊愕到逐渐清醒的愤怒，再到冰冷刺骨的仇恨，女主角的眼神完成了完美的蜕变。
```

**Seedance版本**：
```
Expression morphing from shock to dawning fury to cold determination, her eyes transforming completely in a single moment.
```
