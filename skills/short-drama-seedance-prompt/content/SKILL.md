# 短剧剧本创作与Seedance 2.0提示词生成

## 核心能力

本技能帮助用户快速创作短剧剧本，并直接输出符合Seedance 2.0视频生成模型的提示词，实现从剧本到AI视频的一站式创作流程。

## 工作流程

### 步骤1：理解需求

收集以下信息：

- **题材类型**：霸总甜宠、豪门恩怨、穿越重生、民国谍战、古装言情、都市情感等
- **核心冲突**：误会型、复仇型、甜宠型、虐恋型、身份反转型等
- **目标受众**：年轻女性为主（18-35岁），注重情绪共鸣
- **时长要求**：单集1-5分钟，总集数3-100集
- **风格偏好**：唯美浪漫、紧张刺激、幽默诙谐、虐心催泪等

### 步骤2：剧本结构设计

#### 短剧标准结构（3分钟/集）

```
[开场Hook 0-10秒]
吸引眼球的冲突或悬念开场

[建置 10-50秒]
交代人物关系和基本背景

[对抗 50-150秒]
核心冲突升级，情感拉扯

[转折 150-170秒]
意外事件或反转

[钩子 170-180秒]
留下悬念，引诱继续观看
```

#### 多集结构规划

- **前3集**：建立世界观、主要人物、快速建立追剧动力
- **中间集**：持续输出冲突，维持情感张力
- **高潮集**：核心矛盾爆发，情感高潮
- **结局集**：圆满或开放式结局，符合平台调性

### 步骤3：场景与镜头设计

#### 场景库分类

| 场景类型 | 视觉特征 | 适用情绪 |
|---------|---------|---------|
| 豪华总裁办公室 | 大理石、落地窗、水晶灯 | 霸气、震撼 |
| 温馨小公寓 | 暖光、简约、文艺 | 甜蜜、安心 |
| 雨中追逐 | 慢动作、雨滴特写 | 虐心、浪漫 |
| 舞会/宴会 | 华丽服装、灯光 | 戏剧性、冲突 |
| 海边/夕阳 | 逆光、剪影 | 唯美、告白 |

#### 镜头语言

- **全景**：建立场景，交代空间关系
- **中景**：对话场景，情感交流
- **特写**：情绪表达，眼神戏
- **推镜头**：强调重要信息，增强情绪
- **拉镜头**：交代环境，拓展情绪
- **手持跟拍**：增强临场感、紧张感

### 步骤4：Seedance 2.0提示词生成

#### 提示词结构模板

```
[主体] + [场景环境] + [镜头运动] + [画面风格] + [情绪氛围] + [光影色彩] + [画质要求]
```

#### 各要素详解

**主体描述**

- 人物外貌特征（发色、服装、表情）
- 人物动作和姿态
- 人物数量和位置关系
- 示例：「一位身穿黑色西装的年轻男子，深邃的眼眸带着忧伤，手中紧握一封泛黄的信」

**场景环境**

- 室内/室外
- 具体场景类型
- 时间（清晨、正午、黄昏、夜晚）
- 天气状况
- 示例：「在一间复古风格的欧式书房内，窗外是绵绵细雨，壁炉里火焰摇曳」

**镜头运动**

- 固定镜头：static shot, locked frame
- 推进镜头：slow push-in, tracking forward
- 拉远镜头：pull back, zooming out
- 环绕镜头：orbiting, circling around
- 跟拍镜头：following shot, handheld
- 示例：「镜头缓慢推进至人物面部特写，捕捉眼角滑落的泪水」

**画面风格**

- 电影感：cinematic, film grain
- 唯美风格：ethereal, dreamy
- 高级感：luxurious, elegant
- 复古风：vintage, retro
- 现代感：modern, minimalist
- 示例：「电影感画面，略带胶片颗粒感，高级灰调色彩」

**情绪氛围**

- 悲伤孤独：melancholic, solitary
- 浪漫甜蜜：romantic, warm
- 紧张悬疑：tense, suspenseful
- 戏剧冲突：dramatic, intense
- 示例：「弥漫着淡淡的忧伤和未说出口的爱意」

**光影色彩**

- 光线类型：自然光、暖光、冷光、戏剧光
- 色彩倾向：暖色调、冷色调、黑白
- 阴影比例：明亮、高对比、柔和
- 示例：「温暖的琥珀色光线从侧面打来，在人物脸上形成柔和的光影」

**画质要求**

- 分辨率：4K, Ultra HD
- 帧率：24fps, 30fps, 60fps
- 画面比例：9:16（竖屏）, 16:9（横屏）
- 示例：「4K超清画质，30fps，竖屏9:16，适合短视频平台」

## 常见问题处理

### Q1：如何制造强冲突开场？

**技巧**：

- 用"一句话冲突"开场：「她没想到，昨晚在酒吧共度一夜的男人，竟是她未婚夫的父亲」
- 视觉冲击优先：豪车、豪宅、美颜冲击
- 留足悬念：不要在开场透露太多

### Q2：如何保持每集的追剧动力？

**技巧**：

- 每集结尾必须有钩子（悬念/冲突/反转）
- 设置"周经剧情"：每3-5集一个小高潮
- 情感拉扯：爱→误会→恨→心疼→原谅→更爱

### Q3：提示词太长/效果不好怎么办？

**技巧**：

- 精简到核心元素：主体+场景+情绪
- 优先确保主体描述准确
- 测试不同风格关键词组合
- 避免过多限定词导致矛盾
