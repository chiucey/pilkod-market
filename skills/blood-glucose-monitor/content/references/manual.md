## 功能介绍

血糖监测技能帮助您便捷地记录、查询和管理血糖数据，支持：

- **快速记录**：一句话完成血糖记录
- **历史查询**：按日期、类型查看历史记录
- **统计报告**：生成血糖趋势分析报告
- **异常提醒**：自动识别并提醒异常值

## 快速开始


## 指令详解

### 1. 记录血糖

**基本语法**：
```
记录血糖 [数值] [类型] [备注]
```

| 参数 | 必填 | 说明 | 示例 |
|------|------|------|------|
| 数值 | 是 | 血糖值（mmol/L） | 5.6、7.8、8.5 |
| 类型 | 否 | 餐前/餐后 | 餐前、餐后、空腹 |
| 备注 | 否 | 补充信息 | 空腹、睡眠差 |

**完整示例**：

```
记录血糖 5.6 餐前 早起空腹，睡眠良好
血糖 7.2 餐后 午餐吃了米饭和蔬菜
测量血糖 8.5 餐后 晚餐后2小时，吃了较多主食
```

**简化用法**：
- `记录血糖 5.6` → 自动识别为餐前
- `血糖 7.8` → 使用当前时间

### 2. 查看记录

**基本语法**：
```
查看血糖记录 [条件]
```

**常用查询**：

| 指令 | 说明 |
|------|------|
| `查看血糖记录` | 查看最近 10 条记录 |
| `查看所有血糖记录` | 查看全部历史记录 |
| `查看最近一周的血糖记录` | 查看 7 天内记录 |
| `查看餐前血糖记录` | 仅查看餐前记录 |
| `查看餐后血糖记录` | 仅查看餐后记录 |
| `查看 [日期] 的血糖记录` | 查看指定日期记录 |

**排序参数**：
- `asc` - 按日期升序（从旧到新）
- `desc` - 按日期降序（从新到旧，默认）

**示例**：
```
查看血糖记录 asc
查看最近一周的血糖记录 餐前
查看2024年1月的血糖记录
```

## 血糖参考值

### 正常范围

| 测量类型 | 正常范围 | 说明 |
|----------|----------|------|
| 餐前（空腹） | 3.9 - 6.1 mmol/L | 未进食至少 8 小时 |
| 餐后 2 小时 | < 7.8 mmol/L | 从第一口饭开始计时 |

### 异常范围

#### 偏高

| 测量类型 | 偏高范围 | 说明 |
|----------|----------|------|
| 餐前（空腹） | 6.1 - 7.0 mmol/L | 空腹血糖受损 |
| 餐后 2 小时 | 7.8 - 11.1 mmol/L | 糖耐量异常 |

#### 过高

| 测量类型 | 过高范围 | 说明 |
|----------|----------|------|
| 餐前（空腹） | > 7.0 mmol/L | 糖尿病诊断标准之一 |
| 餐后 2 小时 | > 11.1 mmol/L | 糖尿病诊断标准之一 |

#### 偏低

| 测量类型 | 偏低范围 | 说明 |
|----------|----------|------|
| 任何时候 | < 3.9 mmol/L | 低血糖，可能有危险 |

## 常见问题

### Q1: 如何选择测量时间？

**建议测量时间**：
- **早起空腹**：经过一夜未进食，最能反映基础血糖水平
- **餐后 2 小时**：反映进食后的血糖控制能力

### Q2: 记录有误怎么办？

目前版本不支持修改记录，如有需要请重新记录一条正确数据。

### Q3: 数据保存在哪里？

数据保存在本地 JSON 文件中，不会上传到服务器。

### Q4: 血糖单位是什么？

使用国际标准单位 **mmol/L**。如果您习惯使用 mg/dL，需要进行换算：
- mg/dL ÷ 18 = mmol/L
- 例如：100 mg/dL ≈ 5.6 mmol/L

## 健康提示

### 为什么要记录血糖？

1. **了解自身情况**：掌握血糖变化规律
2. **发现问题**：及时发现异常波动
3. **评估效果**：判断饮食、运动、药物的效果
4. **就医参考**：为医生提供完整数据

### 记录建议

1. **规律测量**：建议每天测量 2-4 次
2. **记录完整**：备注饮食、用药、运动情况
3. **坚持记录**：长期坚持才能发现规律
4. **结合症状**：如有不适，记录具体症状

### 血糖控制小贴士

| 方面 | 建议 |
|------|------|
| 饮食 | 少食多餐，避免高糖高脂食物 |
| 运动 | 餐后适度运动，如散步 30 分钟 |
| 作息 | 保持规律作息，避免熬夜 |
| 监测 | 遵医嘱定期监测，不随意停药 |
