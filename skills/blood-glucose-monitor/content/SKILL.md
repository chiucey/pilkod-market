# 血糖监测与管理技能

## 技能概述

这是一款专业的血糖监测与管理技能，帮助用户便捷地记录血糖数据、查看历史记录，并生成健康趋势分析报告。

## 核心功能

### 1. 血糖记录

当用户请求记录血糖时，收集以下信息：
- **测量日期**：自动获取当前日期
- **测量时间**：自动获取当前时间
- **血糖值**：用户输入的血糖数值（单位：mmol/L）
- **测量类型**：餐前（Fasting）或餐后（Postprandial）
- **备注**：可选，包括饮食情况、身体症状等

### 2. 查看记录

支持多种查询方式：
- **按日期范围**：查看指定时间段内的记录
- **按类型**：仅查看餐前或餐后记录
- **全部记录**：查看所有历史记录
- **排序方式**：按日期升序或降序排列

### 3. 统计报告

生成血糖统计信息：
- 平均值、最高值、最低值
- 测量次数统计
- 异常值提醒
- 趋势分析

## 数据存储

数据以 JSON 格式存储在 `data/glucose_records.json` 文件中。

### 数据结构

```json
{
  "records": [
    {
      "id": "uuid-string",
      "date": "2024-01-15",
      "time": "08:30",
      "value": 5.6,
      "type": "fasting",
      "note": "空腹，无不适",
      "created_at": "2024-01-15T08:30:00"
    }
  ]
}
```

## 使用指令

### 记录血糖

**触发方式**：
- "记录血糖 [数值]"
- "测量血糖 [数值] [餐前/餐后]"
- "血糖 [数值] [备注]"

**完整示例**：
```
记录血糖 5.6 餐前 昨晚睡眠较好，今早空腹测量
血糖 7.8 餐后 午餐吃了米饭和蔬菜，2小时后测量
```

### 查看记录

**触发方式**：
- "查看血糖记录"
- "查看最近一周的血糖记录"
- "查看餐前血糖记录"
- "查看[日期]的血糖记录"

**排序参数**：
- `asc`：按日期升序（ oldest first）
- `desc`：按日期降序（ newest first，默认）

### 获取报告

**触发方式**：
- "生成血糖报告"
- "查看血糖统计"
- "本周血糖情况"

## 血糖参考范围

| 状态 | 餐前 (mmol/L) | 餐后 2h (mmol/L) |
|------|---------------|------------------|
| 正常 | 3.9 - 6.1 | < 7.8 |
| 偏高 | 6.1 - 7.0 | 7.8 - 11.1 |
| 过高 | > 7.0 | > 11.1 |

## 错误处理

| 情况 | 处理方式 |
|------|---------|
| 血糖值无效 | 提示用户输入有效数值（0.1-50.0 mmol/L） |
| 日期格式错误 | 自动使用当前日期 |
| 数据文件不存在 | 自动创建新文件 |
| 查询无结果 | 显示"无记录"提示 |

## 健康提示

1. **规律测量**：建议每天测量 2-4 次（餐前+餐后）
2. **记录完整**：备注有助于分析血糖波动原因
3. **关注趋势**：单次异常不必惊慌，趋势分析更有意义
4. **遵医嘱**：如有异常，请咨询医生

## 技术说明

- 数据存储：`data/glucose_records.json`
- 支持时间范围：所有历史数据
- 血糖单位：mmol/L（国际标准单位）
