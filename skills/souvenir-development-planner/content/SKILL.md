# 纪念品开发规划师 (Souvenir Development Planner)

## 触发短语

用户可能使用的中文触发短语：
- 纪念品开发计划
- 纪念品规划
- 纪念品设计方向
- 纪念品开发思路
- 未来纪念品建议

英文触发短语：
- souvenir development plan
- souvenir planning
- souvenir design direction
- corporate souvenir roadmap

## 激活条件

当用户提供以下信息时激活：
- 公司现有纪念品清单或描述
- 任何限制条件（预算、人群、品牌调性等）
- 规划时间范围（1-2年）

## 工作流程

### 第一步：收集与分析

1. **盘点现有纪念品**
   - 列出用户提供的现有纪念品类型、材质、功能
   - 识别品牌元素与标志性特征
   - 分析现有产品的优势与不足

2. **明确限制条件**
   - 提取用户提供的预算范围
   - 识别目标受众特征
   - 确认品牌调性与风格要求
   - 了解任何功能或合规限制

3. **趋势研究**
   - 搜索当前流行的纪念品设计趋势
   - 关注可持续环保材料趋势
   - 关注数字化与传统结合趋势
   - 关注个性化定制趋势

### 第二步：核心输出（按优先级排序）

#### 1. 设计方向和形式建议（最重要）

```
## 设计方向建议

### 核心设计理念
- 提炼3-5个设计关键词
- 确定视觉风格方向（现代简约/传统经典/趣味活泼等）
- 定义色彩体系建议

### 形式创新建议
- 列出3-5种创新形式
- 每种形式包含：
  - 名称
  - 概念描述
  - 与现有产品的差异化
  - 预期受众反应

### 材质建议
- 推荐2-3种主材
- 推荐1-2种辅材
- 考虑环保可持续材料
```

#### 2. 品类组合建议

```
## 品类组合规划

### 核心品类（占比40-50%）
- 品类名称
- 开发优先级
- 预计成本范围
- 预期用途

### 辅助品类（占比30-40%）
- 同上格式

### 探索品类（占比10-20%）
- 创新尝试型产品
- 小批量试水
```

#### 3. 预算分级建议

```
## 预算分级方案

### 入门级（单件成本 XX元以内）
- 适合人群：大众/新客户
- 推荐品类
- 年产量建议

### 标准级（单件成本 XX-XX元）
- 适合人群：核心客户/合作伙伴
- 推荐品类

### 高端级（单件成本 XX元以上）
- 适合人群：VIP/重要场合
- 推荐品类
```

#### 4. 趋势融合方案

```
## 趋势融入建议

### 流行趋势应用
| 趋势 | 融入方式 | 产品示例 | 实施难度 |

### 差异化策略
- 如何在趋势中保持品牌独特性
- 避免同质化的建议
```

#### 5. 时间线规划（最次要）

```
## 开发时间线

### 第一年（Q1-Q4）
- Q1：市场调研与概念设计
- Q2：样品开发与测试
- Q3：首批产品上市
- Q4：反馈收集与优化

### 第二年（持续迭代）
- 基于市场反馈调整
- 新品类研发
- 爆款产品扩展
```

### 第三步：输出整理

最终输出应包含：
1. **执行摘要**（1段话概括整体规划）
2. **设计方向建议**（详细展开）
3. **品类组合规划**（带具体产品建议）
4. **预算分级方案**（含成本估算）
5. **趋势融合方案**（可落地执行）
6. **时间线规划**（分季度里程碑）

## 输出格式要求

- 使用Markdown格式输出
- 适当使用表格、列表增强可读性
- 每个建议都应包含"为什么这样建议"的解释
- 提供具体可操作的行动项
- 标注需要用户进一步确认的信息

## 限制条件处理

- 如果用户未提供预算，询问或给出合理假设后说明
- 如果信息不足，标注为"[需要补充]"并给出具体问题
- 始终考虑品牌的长期一致性
