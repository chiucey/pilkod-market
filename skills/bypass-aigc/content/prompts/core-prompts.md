## 🔥 核心降 AIGC Prompt（推荐）

```
请帮我对以下学术文本进行深度润色，降低其 AI 生成特征，使其读起来更像人类学者撰写：

【原文】
[粘贴你需要修改的文本]

【润色要求】
1. 语言风格改造：
   - 将过于规整的句子打散，增加自然停顿
   - 替换 AI 惯用的套路化表达（如"显而易见"、"值得注意的是"）
   - 引入符合人类写作习惯的微小变化（语气、节奏）

2. 词汇与句式多样化：
   - 同义替换过度重复的词汇
   - 将重复句式改为多样句式
   - 替换标准化的连接词

3. 增加人类写作特征：
   - 加入合理的省略和隐含逻辑
   - 添加适度的口语化学术表达
   - 引入轻微的"不完美"

4. 保持学术严谨性：
   - 不改变原文的学术含义和技术内容
   - 不降低论证的逻辑严密性
   - 不删除专业术语

5. 降低 AIGC 检测特征：
   - 减少过度使用的高频学术词汇
   - 避免过于完美的语法结构
   - 引入符合人类认知过程的自然表达顺序

【输出】直接输出润色后的文本，不附加说明。
如改动可能影响原意，用 [原文：xxx → 润色：yyy] 标注。
```

## Prompt 2：学术论文降 AIGC 率（强力版）

```
我有一篇由 AI 辅助撰写的学术论文，需要进行深度降 AIGC 率处理。

【论文类型】：[期刊论文/学位论文/会议论文]
【学科领域】：[计算机/经济学/心理学等]
【目标期刊/会议】：（如有）

【降 AIGC 核心原则】
1. 打乱过于规律的句子节奏
2. 替换 AI 特征性表达：
   - "显而易见" → 符合领域习惯的表达
   - "值得注意的是" → "不过"或删除
   - "综上所述" → "可见"或删除
   - "首先、其次、最后" → "第一步"或不明显的过渡
3. 增加同义词多样性
4. 引入自然的认知跳跃
5. 保留学术术语和数据

请逐段处理，标记主要 AI 特征，给出修改版本。
```

## Prompt 3：极致降 AIGC（高风险检测场景）

```
以下文本来自 AI 生成，需要极致降 AIGC 率处理，通过主流 AIGC 检测工具检测。

【原文】
[粘贴文本]

【极端降 AIGC 策略】
1. 句式：拆散复合句，打乱主动/被动规律
2. 词汇：替换 AI 高频词（significant/substantial/comprehensive）
3. 逻辑：删除完美过渡，引入天然缺口
4. 格式：允许标点轻微不规整

【注意】技术术语、实验数据、引用必须保留原样。

输出：纯润色后文本，不附加说明。
```

## Prompt 4：学术润色（不改内容）

```
请对以下学术文本进行专业润色，只提升语言质量，不改变任何技术含义：

【原文】
[粘贴文本]

【润色标准】
- 拼写、语法、标点零错误
- 句意清晰，无歧义
- 逻辑连贯，过渡自然
- 用词精准，符合学术规范
- 适当简练，删除冗余

【不做】不改技术内容 / 不改数据 / 不改原创观点
```

## Prompt 5：逐章节处理

```
以下是一篇 [X] 字学术论文的 [章节名]，需要降 AIGC 率处理。

【原文】
[粘贴内容]

【本章降 AIGC 策略】
- 文献综述类：保留引用格式，打乱综述句式，增加评价性语句
- 研究方法类：保留技术细节，润色操作描述
- 实验结果类：保留数据描述，丰富结果分析
- 讨论与结论类：增加前瞻性表述，自然收尾

请说明策略，然后输出处理后的文本。
```
