# 专业术语对照表

## 软件操作术语

### VosViewer
| 英文术语 | 中文术语 | 含义 |
|---------|---------|------|
| Occurrences | 出现频次 | 关键词在文献中出现次数 |
| Links | 连线数 | 与其他节点的连接数量 |
| Total link strength | 总连线强度 | 连接的综合权重 |
| Cluster | 聚类 | 高度相关的节点群 |
| Network visualization | 网络可视化 | 聚类关系的图形展示 |
| Overlay visualization | 叠加可视化 | 添加时间等属性的可视化 |
| Density | 密度 | 聚类内部连接紧密度 |
| Modularity | 模块度 | 聚类分离程度指标 |
| Silhouette | 轮廓值 | 聚类质量指标 |

### CiteSpace
| 英文术语 | 中文术语 | 含义 |
|---------|---------|------|
| Degree centrality | 度中心性 | 节点连接数量的标准化指标 |
| Betweenness centrality | 介数中心性 | 节点桥梁作用指标 |
| Citation burst | 引文突现 | 被引频次突然增加的文献 |
| Keyword burst | 关键词突现 | 关键词出现频次突然增加 |
| Timeline view | 时间线视图 | 展示聚类随时间演化 |
| Timezone view | 时区视图 | 按时间分区的网络视图 |
| Top N per slice | 每切片Top N | 每个时间切片选取的节点数 |
| g-index | g指数 | 修正的引文量指标 |

## 描述性短语

### 图表描述
- "如图X所示" → "As shown in Figure X"
- "节点大小反映..." → "The node size indicates..."
- "不同颜色代表..." → "Different colors represent..."
- "连线粗细表示..." → "The line thickness represents..."

### 趋势描述
- "呈上升趋势" → "shows an upward trend"
- "持续增长" → "continuous growth"
- "波动变化" → "fluctuating changes"
- "趋于稳定" → "tends to be stable"

### 强度描述
- "显著" → "significant/substantial"
- "明显" → "notable/marked"
- "轻微" → "slight/mild"
- "密切" → "close/intensive"
