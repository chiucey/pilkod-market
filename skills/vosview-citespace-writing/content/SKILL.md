# 基于VosViewer与CiteSpace的论文写作技能

本技能帮助用户将VosViewer和CiteSpace软件生成的可视化图表转化为高质量学术论文内容。

## 核心工作流程

### 1. 图表识别与分析

**输入**：用户提供软件截图或描述

**任务**：
- 识别图表类型（聚类图谱、合作网络、高被引论文、突现词等）
- 提取关键数据：节点数量、连线密度、聚类模块值、中心性指标

**常用图表类型**：
| 图表类型 | VosViewer | CiteSpace |
|---------|-----------|-----------|
| 聚类分析 | Network Visualization → All keywords | Log-likelihood ratio/Verbosity |
| 合作网络 | Overlay Visualization → Authors/Institutions | Author/Institution Collaboration |
| 时区视图 | Network Visualization → Timeline view | Timezone |
| 突现词检测 | - | Burst detection |

### 2. 数据解读标准

#### 2.1 聚类图谱解读规范

```
聚类质量指标判定：
- Modularity Q > 0.3 → 聚类结构显著
- Mean Silhouette > 0.5 → 聚类效果良好
- Modularity Q > 0.7 → 聚类非常显著

解读顺序：
1. 整体结构：聚类数量、主要聚类分布
2. 内部特征：高频标签词、高密度节点
3. 跨类关系：聚类间连线、桥接节点
4. 演化趋势：时区图中的时间分布
```

#### 2.2 网络图谱解读规范

```
合作网络分析维度：
- 节点大小 = 发文量/引用量
- 连线粗细 = 合作关系强度
- 节点颜色 = 时间分期/聚类归属
- 位置中心性 = 学术影响力

核心作者判定：
- 度中心性 Top 10
- 介数中心性 > 0.1
- 被引频次 > 50
```

#### 2.3 突现词检测解读

```
突现词判定标准：
- Burst strength > 3.0 → 显著突现
- 突现持续时间 > 2年 → 持续关注
- 突现领域 = 研究热点/新兴方向

时序特征：
- 早期突现 = 奠基性概念
- 中期突现 = 主流研究方向
- 近期突现 = 前沿热点
```

### 3. 学术论文写作模板

#### 3.1 聚类分析章节模板

```markdown
## X.X 研究主题聚类分析

本研究运用VOSviewer软件对检索文献的关键词进行共现分析，采用NLW算法进行聚类[参数说明]。经分析，共形成N个聚类模块，Q值为X，Silhouette值为X，整体聚类结构[显著/一般/不显著]。

[表格：主要聚类及其核心关键词]

### X.X.X 聚类#主要特征分析

聚类#涵盖关键词"XX"（出现频次N次）、"XX"等，反映了该领域[研究方向描述]。该聚类内部共形成X条连线，平均密度为X，表明[内部合作/关联强度描述]。

从时间维度看，该聚类文献主要发表于20XX-20XX年，表明[时间趋势说明]。
```

#### 3.2 合作网络章节模板

```markdown
## X.X 作者/机构合作网络分析

### X.X.X 合作网络整体特征

基于CiteSpace合作网络分析，本研究揭示了[作者/机构]合作格局。如图X所示，合作网络包含N个节点（[作者/机构]）和X条连线，网络密度为X。

整体来看，该领域呈现[合作特征描述：
- 核心作者群集中/分散
- 机构间合作/独立倾向
- 地域分布特征]
```

#### 3.3 高被引论文分析模板

```markdown
## X.X 高被引论文分析

通过引文分析，本研究筛选出被引频次≥X次的文献X篇（占总样本的X%），这些论文构成该领域的知识基础。

[表格：高被引论文列表]

### X.X.X 高被引论文特征

上述高被引论文呈现以下特征：
1. 研究主题：集中在[主题1]、[主题2]等方向
2. 发表时间：多为20XX-20XX年发表的[类型]论文
3. 来源期刊：以[期刊1]、[期刊2]等为核心阵地
4. 作者特征：[原创者/引领者]以[国家/机构]学者为主
```

#### 3.4 突现词/研究热点章节模板

```markdown
## X.X 研究热点与前沿趋势

### X.X.X 突现词检测结果

借助CiteSpace的突现词检测功能，本研究识别出X个突现词，总突现强度为X-X。如表X所示，[简述主要发现]。

[表格：突现词及其强度]

### X.X.X 研究趋势演化分析

根据突现词的时序分布，该领域研究趋势呈现三个阶段：
- **奠基期（20XX-20XX）**：[早期主题]成为研究起点
- **发展期（20XX-20XX）**：[中期主题]引发持续关注
- **前沿期（20XX-至今）**：[近期主题]代表新兴方向
```

### 4. 图表描述规范

#### 4.1 位置分布图描述

```
标准格式：
"如图X所示，采用VOSviewer软件的聚类视图（Clustered Views），N篇文献关键词共形成N个聚类，各聚类以不同颜色标注。"

量化描述：
- 聚类数量
- 主要聚类标签
- 节点总数、连线总数
- 网络密度
```

#### 4.2 时间线图描述

```
标准格式：
"图X为关键词时间线图谱（Timeline View），横轴表示时间演变，纵轴展示各聚类。"

演化描述：
- 聚类最早出现时间
- 聚类活跃期
- 聚类消亡/融合节点
```

#### 4.3 合作网络图描述

```
标准格式：
"图X展示了[作者/机构]合作网络关系，节点大小反映[发文量/合作频次]，连线粗细表示[合作强度/频次]。"
```

### 5. 质量自检清单

| 检查项 | 标准 |
|-------|------|
| 术语准确性 | VosViewer/CiteSpace 专业术语使用正确 |
| 参数报告 | 包含阈值设置、聚类算法选择 |
| 数据一致性 | 图表数据与正文描述一致 |
| 统计指标 | 报告Q值、Silhouette值、中心性等 |
| 时效性 | 引用文献时间分布合理 |
| 图表标注 | 所有图表均有编号和英文图注 |

### 6. 常见问题处理

**Q：用户提供的图表不清晰怎么办？**
A：请用户提供：①图表名称 ②主要聚类标签 ③关键数值（节点数、连线数、Q值等）

**Q：如何处理多软件对比分析？**
A：建议分软件陈述结果后，在"讨论"章节进行对比整合

**Q：数据描述过于笼统？**
A：要求用户提取具体数值，使用"约"、"左右"等模糊词需避免

## 触发边界

**适用场景**：
- 用户上传VosViewer/CiteSpace图表截图
- 用户描述图表特征并要求撰写论文内容
- 用户需要将图表转化为学术写作素材
- 用户询问如何解读聚类图谱/合作网络/突现词

**不适用场景**：
- 用户要求生成图表本身（使用对应软件）
- 用户仅需图表描述而无需论文正文
- 非学术写作场景（如商业报告）
