# 红头文件解析器

## 功能概述

解析红头文件（党政机关公文/人事任免通知），提取其中的员工调度信息（任命、离职、调任等）。

## 工作流程

### 步骤1：验证文件格式

根据 GB/T 9704-2012《党政机关公文格式》国家标准，检查文件是否具备红头文件基本特征：

| 要素 | 必需 | 说明 |
|------|------|------|
| 发文机关标志 | 是 | 红色，通常为"XXX人民政府文件"或"XXX公司文件" |
| 发文字号 | 是 | 格式：发文机关代字〔年份〕序号，如"×发〔2024〕1号" |
| 红色分隔线 | 是 | 版头与主体之间的红色横线 |
| 标题 | 是 | 通常为"关于XXX的人事任免通知"等 |
| 成文日期 | 是 | 文件落款日期 |

### 步骤2：格式匹配判断

- **匹配**：文件包含上述所有必需要素，继续解析
- **不匹配**：列出缺失的要素，等待用户确认是否继续

### 步骤3：内容解析

识别并提取以下类型的员工调度信息：

| 调度类型 | 识别关键词 |
|----------|-----------|
| 任命 | 任命、聘任、委任、任职 |
| 离职 | 离职、免职、辞职、解聘 |
| 调任 | 调任、调动、轮岗、挂职 |
| 晋升 | 晋升、提拔、升职 |
| 退休 | 退休、退职 |

### 步骤4：数据提取

从文件正文中提取每条调度记录的字段：

| 字段 | 说明 | 示例 |
|------|------|------|
| 时间 | 调度生效日期 | 2026年5月26日 |
| 人员 | 员工姓名 | 张三 |
| 原公司 | 原所属单位 | 首创公司 |
| 原职位 | 原任职务 | 部门经理 |
| 新公司 | 新所属单位 | 新公司（离职时为"-"） |
| 新职位 | 新任职务 | 总监（离职时为"-"） |
| 调度类型 | 操作类型 | 任命/离职/调任 |

### 步骤5：缺失数据处理

如果解析出的记录缺少必要字段：

1. 列出缺失的字段名称
2. 提示用户输入缺失数据
3. 记录用户输入并更新记录

### 步骤6：结果输出

以 Markdown 表格格式输出最终结果：

```markdown
## 员工调度信息汇总

| 时间 | 人员 | 原公司 | 原职位 | 新公司 | 新职位 | 调度类型 |
|------|------|--------|--------|--------|--------|----------|
| 2026/05/26 | 张三 | 首创公司 | 部门经理 | - | - | 离职 |
| 2026/05/27 | 李四 | A公司 | 专员 | B公司 | 主管 | 调任 |
```

## 输入要求

- 支持格式：PDF、Word文档（.doc/.docx）、图片（.jpg/.png）
- 文件应包含清晰可读的红头文件内容
- 优先使用原始文件，避免截图或照片

## 输出格式

1. **验证结果**：文件格式是否符合红头文件标准
2. **识别状态**：检测到的调度记录数量
3. **数据表格**：提取的员工调度信息
4. **缺失字段**：需要用户补充的信息（如有）

## 注意事项

- 发文字号是红头文件的核心标识，优先核验
- 日期格式统一转换为 YYYY/MM/DD
- 联合行文可能涉及多方人员，需全部提取
- 附件中如有人员名单，也应纳入解析范围
