# 红头文件格式标准参考

## 国家标准概述

本文档依据 **GB/T 9704-2012《党政机关公文格式》** 国家标准编写。该标准于2012年6月29日发布，2012年7月1日正式实施。

## 公文格式三大部分

红头文件格式分为**版头、主体、版记**三大部分：

```
┌─────────────────────────────┐
│          版 头              │  ← 红色分隔线以上
├─────────────────────────────┤
│          主 体              │  ← 红色分隔线以下、版记以上
├─────────────────────────────┤
│          版 记              │  ← 分隔线以下
└─────────────────────────────┘
```

---

## 一、版头部分（必须为红色）

### 1. 份号

- **定义**：同一文稿印制若干份时每份的顺序编号
- **位置**：版心左上角顶格第1行
- **格式**：6位阿拉伯数字
- **字体**：3号黑体
- **适用**：涉密公文必须标注

### 2. 密级和保密期限

- **位置**：版心左上角第2行（如有份号则第3行）
- **格式**：`密级` 或 `密级★期限`
- **字体**：3号黑体
- **密级等级**：
  - 秘密
  - 机密
  - 绝密

### 3. 紧急程度

- **位置**：版心右上角第1行
- **格式**：`急件` 或 `特急`
- **字体**：3号黑体
- **优先级顺序**：
  - 特急
  - 急件
  - 平急

### 4. 发文机关标志（红头）

- **定义**：发文机关名称，即"红头"
- **位置**：首页上边缘至版心上边缘 25mm
- **字体**：红色小标宋体
- **字号**：不大于上级机关发文机关标志
- **组合方式**：
  - `XXX人民政府文件`（主要用于上行文、重大事项）
  - `XXX人民政府`（主要用于函件、一般事务）
  - 联合行文时，将主办机关排列在前

### 5. 发文字号

- **定义**：公文的身份标识
- **格式**：`发文机关代字〔年份〕序号`
- **示例**：`×发〔2024〕1号`、`×府发〔2024〕001号`
- **字体**：3号仿宋体
- **位置**：发文机关标志下空2行，居中排布
- **注意**：
  - 年份用六角括号「〔〕」括起
  - 序号不加「第」字，不加「号」字
  - 联合行文只标主办机关发文字号

### 6. 签发人

- **适用**：仅上行文（请示、报告）需标注
- **格式**：`签发人：XXX`
- **字体**：
  - "签发人"三字：3号仿宋体
  - 签发人姓名：3号楷体
- **位置**：
  - 发文字号居左空1字
  - 签发人姓名居右空1字
  - 两者在同一行

### 7. 红色分隔线

- **定义**：区分版头与主体的红色横线
- **位置**：发文字号下方
- **特征**：贯穿版心宽度的红色实线

---

## 二、主体部分

### 1. 标题

- **位置**：红色分隔线下空2行
- **字体**：2号小标宋体（居中）
- **结构**：`发文机关 + 关于 + 事由 + 文种`
- **示例**：`关于张三同志职务任免的通知`

### 2. 主送机关

- **位置**：标题下空1行，左侧顶格
- **字体**：3号仿宋体
- **格式**：`主送机关：XXX`
- **注意**：
  - 如有多个主送，用顿号分隔
  - 公告、通告等周知性公文可省略

### 3. 正文

- **字体**：3号仿宋体
- **结构层次**：
  - 第一层：黑体
  - 第二层：楷体
  - 第三层：仿宋
- **每面排版**：22行，每行28字
- **特殊符号**：数字、外文等可使用对应字体

### 4. 附件说明

- **位置**：正文下空1行
- **格式**：`附件：1. ××××`
- **字体**：3号仿宋体
- **附件标题**：3号黑体

### 5. 发文机关署名

- **位置**：正文末行下空2行
- **字体**：3号仿宋体
- **格式**：应与正文保持一致

### 6. 成文日期

- **格式**：阿拉伯数字，如 `2026年5月26日`
- **位置**：发文机关署名右下方
- **字体**：3号仿宋体

### 7. 印章

- **类型**：
  - 印章（骑年盖月）
  - 签发人签名章
- **位置**：成文日期之上

### 8. 附注

- **位置**：版记之前
- **字体**：3号仿宋体
- **用途**：对公文内容进行解释说明

---

## 三、版记部分

### 1. 分隔线

- **特征**：与版心等宽的黑色实线

### 2. 抄送机关

- **位置**：分隔线上方
- **格式**：`抄送：XXX`
- **字体**：4号仿宋体

### 3. 印发机关和印发日期

- **格式**：
  ```
  ××××
   2026年5月26日印
  ```
- **位置**：版记最下方
- **字体**：4号仿宋体

## 五、人事任免类文件特征

人事任免类红头文件通常包含以下内容模式：

### 常见文种

- `关于XXX同志职务任免的通知`
- `关于XXX等同志任免职的通知`
- `关于XXX同志任职的决定`
- `关于XXX同志辞职的通知`

### 常见句式

```
经研究决定：
1. 任命张三同志为XX部门经理，免去其XX职务
2. 李四同志任XX公司副总经理（试用期一年）
3. 王五同志不再担任XX职务，另有任用
```

### 数据提取对照表

| 原始描述 | 提取字段 |
|----------|----------|
| "自2026年5月26日起" | 时间：2026/05/26 |
| "张三同志" | 人员：张三 |
| "XX公司" | 原公司/新公司 |
| "XX部门经理" | 原职位/新职位 |
| "任命/免职/调任" | 调度类型 |

## 六、验证检查清单

解析文件时，请确认以下要素：

- [ ] 发文机关标志（红头）存在
- [ ] 发文字号格式正确
- [ ] 红色分隔线可见
- [ ] 标题包含"任免"或"任职"等关键词
- [ ] 正文中包含人员姓名
- [ ] 有明确的生效日期
- [ ] 有发文机关盖章/署名
