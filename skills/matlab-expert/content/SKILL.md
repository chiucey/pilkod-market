# MATLAB专家技能

## 技能概述

此技能帮助用户编写、调试和优化MATLAB代码，涵盖科学计算和工程应用的各个方面。

## 核心能力

### 1. 数值计算
- 基础数学运算和矩阵操作
- 线性代数（矩阵分解、特征值、奇异值分解）
- 数值分析（插值、数值积分、微分方程求解）
- 优化算法

### 2. 数据可视化
- 2D/3D绘图
- 图形定制（坐标轴、标签、图例、颜色）
- 子图布局
- 动画制作
- 导出高质量图像

### 3. 信号处理
- 傅里叶变换（FFT/IFFT）
- 滤波器设计（FIR/IIR）
- 频谱分析
- 小波变换
- 信号滤波与去噪

### 4. 图像处理
- 图像读取、显示和保存
- 几何变换
- 灰度变换和直方图
- 滤波和卷积
- 边缘检测和分割
- 形态学操作

### 5. 机器学习
- 监督学习（分类、回归）
- 无监督学习（聚类、降维）
- 神经网络和深度学习
- 模型训练和评估
- 特征工程

### 6. 控制系统
- 系统建模
- 时域/频域分析
- PID控制器设计
- 根轨迹分析
- Bode图绘制

## 使用指南

### 代码生成工作流

1. **理解需求**：明确用户的具体任务和技术要求
2. **选择方法**：确定最合适的MATLAB函数和方法
3. **编写代码**：生成清晰、可读的MATLAB代码
4. **添加注释**：解释关键步骤和参数含义
5. **提供示例**：给出完整可运行的代码示例

### 代码风格规范

```matlab
% 遵循以下命名规范：
% - 变量名：小写下划线分隔 (e.g., data_matrix)
% - 函数名：小写下划线分隔 (e.g., my_function)
% - 常量：全大写下划线分隔 (e.g., MAX_ITERATIONS)
% - 类名：首字母大写 (e.g., DataProcessor)

% 代码结构：
% 1. 清除工作空间
clear; close all; clc;

% 2. 初始化参数
% 3. 数据加载/生成
% 4. 核心算法实现
% 5. 结果可视化
% 6. 保存结果
```

### 常见问题处理

| 场景 | 解决方案 |
|------|----------|
| 内存不足 | 使用稀疏矩阵、分批处理、clear释放变量 |
| 运行缓慢 | 向量化操作、预分配数组、使用内置函数 |
| 图形显示异常 | 使用 `figure; hold on;` 正确管理图形 |
| 数据类型问题 | 使用 `class()`, `cast()`, `typecast()` 转换 |
| 文件路径问题 | 使用 `fullfile()`, `fileparts()` 处理路径 |
