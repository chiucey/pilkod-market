# 技术指标详解

## 1. 布林线 (Bollinger Bands)

### 指标原理

布林线由John Bollinger发明，是一种趋势跟踪指标，通过计算股价的标准差来确定股价的波动范围。

### 计算公式

```
中轨 (MID) = N日简单移动平均线 (SMA)
上轨 (UPPER) = 中轨 + 2 × 标准差
下轨 (LOWER) = 中轨 - 2 × 标准差

默认参数：N = 20日
```

### 交易信号

| 价格位置 | 信号含义 | 操作建议 |
|---------|---------|---------|
| 突破上轨 | 超买区域 | 考虑卖出 |
| 触及下轨 | 超卖区域 | 考虑买入 |
| 中轨上方 | 多头趋势 | 持有或买入 |
| 中轨下方 | 空头趋势 | 持有或卖出 |

### 注意事项

- 布林带收缩表示市场平静，可能即将突破
- 布林带扩张表示波动加大
- 单靠布林线容易被假突破欺骗，需结合其他指标

## 2. CCI顺势指标 (Commodity Channel Index)

### 指标原理

CCI由Donald Lambert发明，用于测量股价是否进入周期性极端区域。

### 计算公式

```
典型价格 (TP) = (最高价 + 最低价 + 收盘价) / 3

CCI = (TP - SMA(TP)) / (0.015 × 平均绝对偏差)

其中：平均绝对偏差 = Σ|TP - SMA(TP)| / N

默认参数：N = 14日
```

### 交易信号

| CCI范围 | 信号含义 | 操作建议 |
|---------|---------|---------|
| > +100 | 超买区 | 考虑卖出 |
| < -100 | 超卖区 | 考虑买入 |
| 从下向上穿越-100 | 从超卖回升 | 买入信号 |
| 从上向下穿越+100 | 从超买回落 | 卖出信号 |

### 注意事项

- CCI没有上限和下限，数值可能超过+200或低于-200
- 单边行情中CCI会持续在超买或超卖区
- 适合结合趋势指标使用

## 3. MACD指标 (Moving Average Convergence Divergence)

### 指标原理

MACD由Gerald Appel创造，是最常用的趋势跟踪指标之一，通过短期和长期指数移动平均线的差值来判断趋势。

### 计算公式

```
快速EMA = 12日指数移动平均
慢速EMA = 26日指数移动平均

DIF (差离值) = 快速EMA - 慢速EMA
DEA (信号线) = DIF的9日EMA
MACD柱 = (DIF - DEA) × 2

默认参数：12, 26, 9
```

### 交易信号

| DIF与DEA关系 | 信号含义 | 操作建议 |
|-------------|---------|---------|
| DIF上穿DEA | 金叉 | 买入信号 |
| DIF下穿DEA | 死叉 | 卖出信号 |
| DIF > DEA | 多头排列 | 持有 |
| DIF < DEA | 空头排列 | 观望或卖出 |
| MACD柱放大 | 趋势加速 | 顺势操作 |
| MACD柱收缩 | 趋势减缓 | 注意反转 |

### 注意事项

- MACD是趋势指标，在震荡市中可能产生假信号
- 金叉/死叉需要配合量能确认
- DIF和DEA的交叉点比柱状图更重要

## 4. EXPMA指标 (Exponential Moving Average)

### 指标原理

EXPMA是指数加权移动平均线，对近期数据给予更大权重，比SMA更能反映价格变化。

### 计算公式

```
EXPMA = α × 当前收盘价 + (1-α) × 昨日EXPMA

其中：α = 2 / (N + 1)

默认参数：EMA12 (短期), EMA50 (长期)
```

### 交易信号

| 短期线与长期线关系 | 信号含义 | 操作建议 |
|------------------|---------|---------|
| 短期线上穿长期线 | 金叉 | 买入信号 |
| 短期线下穿长期线 | 死叉 | 卖出信号 |
| 短期线 > 长期线 | 多头排列 | 持有 |
| 短期线 < 长期线 | 空头排列 | 观望 |
| 价格 > EXPMA12 | 短期强势 | 可持有 |
| 价格 < EXPMA12 | 短期弱势 | 注意风险 |

### 注意事项

- EXPMA比SMA更敏感，响应更快
- 短期EXPMA适合做止损参考
- 长期EXPMA适合判断大趋势

## 5. 多指标综合策略

### 信号评分系统

为每个指标分配评分：

| 指标 | 看多信号 | 看空信号 | 评分范围 |
|-----|---------|---------|---------|
| 布林线 | 跌破下轨 | 突破上轨 | ±1-3 |
| CCI | 从超卖回升 | 从超买回落 | ±2-3 |
| MACD | 金叉/多头 | 死叉/空头 | ±2-5 |
| EXPMA | 金叉/多头 | 死叉/空头 | ±2-5 |

### 综合评级

| 总评分 | 评级 | 操作 |
|-------|-----|------|
| ≥ 8 | 强烈买入 | 积极建仓 |
| 4-7 | 买入 | 适量买入 |
| -3 to 3 | 观望 | 谨慎操作 |
| -4 to -7 | 卖出 | 适量减仓 |
| ≤ -8 | 强烈卖出 | 清仓 |

### 风险控制

- 止损位：买入信号下浮3%-5%
- 止盈位：买入信号上浮6%-10%
- 仓位控制：强烈信号仓位30%-50%，普通信号仓位10%-20%
