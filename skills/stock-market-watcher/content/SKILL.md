# 股票智能看盘技能

## 触发条件

当用户请求以下场景时激活此技能：
- 启动股票盯盘/看盘服务
- 分析指定股票的技术指标
- 获取买入/卖出建议
- 设置股票价格提醒
- 查询股票实时行情

## 核心功能

### 1. 数据获取

```python
# 获取股票实时数据
- 调用 stocks_price 获取指定股票的实时价格
- 支持A股、港股、美股
- 数据包括：开盘价、收盘价、最高价、最低价、成交量
```

### 2. 技术指标计算

```python
# 布林线 (Bollinger Bands)
- 中轨：N日简单移动平均线 (SMA)
- 上轨：中轨 + 2倍标准差
- 下轨：中轨 - 2倍标准差
- 默认周期：20日

# CCI顺势指标 (Commodity Channel Index)
- 计算典型价格：(最高价 + 最低价 + 收盘价) / 3
- CCI = (典型价格 - SMA) / (0.015 * 平均绝对偏差)
- 超买阈值：+100
- 超卖阈值：-100

# MACD指标
- DIF线：12日EMA - 26日EMA
- DEA线：DIF的9日EMA
- MACD柱：DIF - DEA
- 默认参数：12, 26, 9

# EXPMA指数加权移动平均
- EXPMA = α × 当前收盘价 + (1-α) × 昨日EXPMA
- α = 2 / (N + 1)
- 默认周期：12日和50日
```

### 3. 交易策略制定

```python
# 多指标综合策略
信号 = 布林线信号 + CCI信号 + MACD信号 + EXPMA信号

# 买入信号条件
- 布林线：价格触及下轨或突破中轨
- CCI：<-100超卖区回升
- MACD：DIF上穿DEA（金叉）
- EXPMA：短期线上穿长期线或多头排列

# 卖出信号条件
- 布林线：价格触及上轨或跌破中轨
- CCI：>+100超买区回落
- MACD：DIF下穿DEA（死叉）
- EXPMA：短期线下穿长期线或空头排列

# 信号强度评级
- 强烈买入：3-4个指标同时发出买入信号
- 温和买入：2个指标发出买入信号
- 观望：1个指标信号或指标矛盾
- 温和卖出：2个指标发出卖出信号
- 强烈卖出：3-4个指标同时发出卖出信号
```

### 4. 定时更新机制

```python
# 工作流程
1. 用户选择要监控的股票列表
2. 设置盯盘时间（默认9:15-15:00）
3. 每5分钟执行一次：
   - 获取最新价格数据
   - 计算技术指标
   - 生成策略建议
   - 推送交易信号
4. 收盘后生成当日总结报告
```

### 5. 推送报告格式

```markdown
📊 【{股票名称} {股票代码} 看盘报告】
⏰ 更新时间：{时间}

💰 实时行情：
- 当前价：{价格}
- 涨跌幅：{涨幅}%
- 成交量：{成交量}

📈 技术指标：
- 布林线：上轨{上轨值} 中轨{中轨值} 下轨{下轨值} | 位置：{上轨/中轨/下轨附近}
- CCI：{CCI值} | 信号：{超买/超卖/正常}
- MACD：DIF={DIF值} DEA={DEA值} | 信号：{金叉/死叉}
- EXPMA：EMA12={EMA12值} EMA50={EMA50值} | 多头/空头排列

🎯 策略建议：
- 信号评级：{强烈买入/买入/观望/卖出/强烈卖出}
- 建议操作：{买入/卖出/持有}
- 止损位：{价格}
- 止盈位：{价格}
- 风险等级：{高/中/低}

⚠️ 风险提示：以上建议仅供参考，不构成投资依据
```

## 执行流程

### 启动盯盘
1. 确认用户要盯盘的股票列表（股票代码或名称）
2. 设置提醒参数（是否需要推送、推送频率）
3. 启动定时任务，每5分钟获取数据并分析
4. 实时推送交易信号

### 立即分析
1. 获取指定股票的最新行情数据
2. 计算布林线、CCI、MACD、EXPMA指标
3. 综合分析生成交易建议
4. 输出详细分析报告

### 收盘总结
1. 汇总当日所有交易信号
2. 生成个股和整体持仓分析
3. 提供次日操作建议

## 注意事项

1. **数据限制**：历史数据至少需要50个交易日才能准确计算所有指标
2. **时区处理**：A股交易时间为9:30-11:30、13:00-15:00（9:15-9:25为集合竞价）
3. **风险提示**：必须明确告知用户此为辅助工具，不构成投资建议
4. **异常处理**：数据获取失败时提供友好的错误提示
