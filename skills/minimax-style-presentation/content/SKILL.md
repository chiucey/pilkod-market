# MiniMax风格演示文稿生成器

## 技能概述

本技能帮助用户创建具有MiniMax官网风格的演示文稿，包括PPT和HTML网页演示两种格式。

## 核心能力

### 1. 设计风格
- **简约科技风**：遵循MiniMax官网的极简设计语言
- **色彩体系**：深色主题为主，搭配品牌蓝/紫色调
- **排版规范**：大量留白，内容层次分明
- **视觉元素**：几何图形、渐变色块、科技感图标

### 2. 支持的输出格式
- **HTML演示文稿**：可部署的网页版幻灯片
- **PPTX文件**：PowerPoint可编辑格式

### 3. 内容结构
- 封面页（标题+副标题+装饰元素）
- 目录页
- 内容页（支持多种布局）
- 分隔页（章节过渡）
- 总结页

## 工作流程

### 第一步：收集需求
- 演示主题和标题
- 主要内容要点（3-5个核心信息）
- 目标受众
- 详细程度偏好

### 第二步：生成设计
- 根据MiniMax风格生成幻灯片
- 自动应用品牌色彩和排版
- 添加适当的装饰元素

### 第三步：输出交付
- 生成HTML演示文稿并部署
- 或生成PPTX文件供下载

## 使用示例

**用户输入**：
```
帮我做一个关于AI技术趋势的演示文稿
```

**技能响应**：
1. 确认主题：AI技术趋势
2. 收集核心内容要点
3. 生成10-15页的MiniMax风格演示
4. 提供网页版链接或PPTX下载

## 技术实现

### HTML演示文稿
- 使用Tailwind CSS构建
- 支持响应式布局
- 可添加动画效果
- 部署后提供公开链接

### PPTX生成
- 使用PptxGenJS库
- 支持自定义主题色
- 可编辑的矢量图形

## 设计规范

### 色彩规范
```
主色调：#0066FF（MiniMax蓝）
辅助色：#1A1A2E（深色背景）
点缀色：#7C3AED（科技紫）
文字色：#FFFFFF（白色）/ #94A3B8（灰色）
```

### 排版规范
- 标题：2.5rem - 3rem，粗体
- 副标题：1.5rem - 2rem，常规
- 正文：1rem - 1.25rem，常规
- 行高：1.5 - 1.75倍

### 布局原则
- 内容区域占比60-70%
- 左右/上下留白20-30%
- 元素对齐：左对齐或居中
- 图文比例可根据内容调整

## 注意事项

1. **内容为王**：先确保内容逻辑清晰，再追求视觉效果
2. **简洁表达**：每页聚焦一个核心观点
3. **视觉一致**：全篇保持统一的视觉风格
4. **可读性**：确保文字清晰，对比度足够
