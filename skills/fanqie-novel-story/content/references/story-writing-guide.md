
# 番茄小说短故事创作参考指南

## 一、故事类型深度指南

### 1.1 都市打工人系列

**核心元素**
- 通勤：地铁挤成沙丁鱼、公交堵在路上、打车软件永远没车
- 租房：奇葩室友、黑心房东、隔断间里的隔音噩梦
- 外卖：骑手与时间的赛跑、差评与理解的拉锯战
- 加班：深夜的办公楼、凌晨的朋友圈、体检报告上的箭头
- 薪资：交完房租的绝望、存款为负的焦虑、年终奖的期待与落空

**人物原型**
- 北漂十年的程序员，存款还没他老家的房价涨得快
- 沪漂五年的销售，见过凌晨四点的上海，却没有见过自己账户的六位数
- 深漂三年的设计师，改了108版方案，最后客户选了第一版

**故事核心理念**
不是卖惨，而是真实。每一个打工人都能在故事里看到自己的影子，但又不至于太惨，而是带着一点黑色幽默的自嘲。

### 1.2 小镇青年系列

**核心元素**
- 回不去的家乡：回去被催婚，不回去被说翅膀硬了
- 城市的夹缝：融入不了城市，回不去家乡
- 同学会的尴尬：有人年入百万，有人还在考编
- 父母的期待：你是全村的希望，但你只是个月光族
- 相亲市场：条件匹配比情投意合更重要

**独特视角**
- 十八线小县城的奶茶店老板，看尽人间百态
- 返乡创业的失败者，被嘲笑但还在坚持
- 通过读书改变命运的幸运儿，却发现自己只是换了个地方卷

### 1.3 家庭伦理系列

**核心冲突**
- 婆媳关系：不是敌人，但绝对不是什么朋友
- 亲子矛盾：父母的爱是真实的，伤害也是真实的
- 兄弟姐妹：小时候抢遥控器，长大了抢遗产
- 夫妻相处：同居前的浪漫vs同居后的鸡毛

**写作技巧**
不要写那种狗血的出轨、小三剧情，要写那种"明明都没错，但就是过不下去"的无奈感。

### 1.4 情感纠葛系列

**暗恋指南**
- 暗恋是一个人的兵荒马乱
- 每天翻朋友圈八百遍，只为找到他点赞的痕迹
- 制造偶遇比中彩票还紧张

**分手指南**
- 分手不是突然的，是积攒够了失望
- 删掉联系方式后，又偷偷从共同好友那里打听消息
- 删掉的照片可以恢复，删掉的记忆怎么恢复

**复合指南**
- 分手后复合的概率统计上没有意义，对个体来说只有0和100
- 复合后最可怕的不是重蹈覆辙，而是小心翼翼

### 1.5 悬疑反转系列

**生活类悬疑**
- 邻居家的神秘访客
- 同事的奇怪行为背后的真相
- 消失的快递、被换的咖啡、突然变味的友情

**反转技巧**
- 第一层：看起来是A
- 第二层：其实是B
- 第三层：但B也有苦衷
- 第四层：最后才是真相

反转不是为了让读者觉得被愚弄，而是为了让读者在知道真相后说一句"原来如此"。

## 二、人物塑造深度指南

### 2.1 主角设计原则

**有缺陷才有魅力**
- 太完美的主角让人反感
- 适当的"缺点"让人物更真实
- 缺陷可以是：拖延症、路痴、选择困难症、嘴硬心软、过度乐观

**口头禅和小动作**
- 口头禅：让人物开口就知道是谁
  - "我太难了"
  - "就离谱"
  - "行吧行吧"
  - "你说的都对"

- 小动作：
  - 紧张时抠指甲
  - 思考时推眼镜
  - 尴尬时摸鼻子
  - 生气时握紧拳头

**成长弧线**
- 好的故事，主角要有变化
- 这个变化不是变好或变坏，而是变得更像"人"
- 可能从逃避到面对，从自私到理解，从懦弱到勇敢

### 2.2 配角设计原则

**功能性配角**
- 推动剧情型：他的出现必然带来转折
- 制造冲突型：他和主角必然产生矛盾
- 提供信息型：通过他的嘴说出需要交代的背景
- 情感支撑型：让主角有地方倾诉和依靠

**避免脸谱化**
- 反派也有自己的逻辑
- 好人也会做坏事
- 配角要有自己的故事线，哪怕只是一笔带过

### 2.3 人物关系图谱

```
        【主角】
       /   |   \
    【哥们】 【恋人】 【对手】
      |       |       |
   【前任】 【家人】 【贵人】
```

每一层关系都要有不同的互动模式和冲突点。

## 三、语言风格深度指南

### 3.1 对话真人化

**问题诊断**
问自己一个问题：这句话，我爸妈会这样说吗？我室友会这样说吗？我同事会这样说吗？

如果答案是"不会"，那就改。

**常见AI腔调及修正**

| AI腔调 | 真人腔调 |
|--------|----------|
| "我们重新开始吧" | "要不再试试？" |
| "我感到非常高兴" | "我可太开心了" |
| "这个问题很棘手" | "这事有点难办啊" |
| "我深深地爱着你" | "我也不知道为什么，就是想对你好" |
| "事情就是这样" | "反正就是这么个情况" |
| "他的眼神充满悲伤" | "他眼眶红了一圈" |

### 3.2 描写克制法

**三不原则**
- 不直接描写心理
- 不直接描写情感
- 不直接描写性格

**替代方案**
- 用动作代替心理
- 用场景代替情感
- 用事件代替性格

**示例对比**

❌ 过度：
```
她感到非常孤独，那种被全世界抛弃的感觉涌上心头。
```

✓ 克制：
```
她打开手机，滑了半天也不知道该找谁聊天。
手机屏幕暗下去，映出她自己的脸。
```

### 3.3 场景构建技巧

**五感写作法**
- 视觉：这个场景你看到什么？
- 听觉：有什么声音？
- 嗅觉：有什么味道？
- 触觉：温度、触感如何？
- 味觉：嘴巴里是什么味道？（紧张时发苦？开心时发甜？）

但不是每个场景都要用五感，选择最有力的2-3个即可。

**场景切片法**
不需要完整描述一个场景，只需要几个关键切片，让读者自己脑补。

```
✓ 凌晨三点的办公室：
日光灯嗡嗡响着，咖啡凉了也没顾上喝，键盘敲得啪啪响。

✓ 高考查分的瞬间：
手抖得输错三次密码，心跳得像要从嗓子眼蹦出来。

✓ 分手后的第一天：
冰箱里还有她买的牛奶，扔了，又捡回来。
```

### 3.4 幽默感培养

**自嘲式幽默**
把自己/主角写得惨一点、蠢一点，读者笑了，就记住了。

```
我大概是唯一一个被外卖小哥同情的外卖员。
他看我的眼神充满了悲悯，仿佛在说："这孩子混得还不如我。"
```

**反差式幽默**
在正经场合加入不正经的反应。

```
经理说要给大家一个惊喜。
我紧张地握紧拳头，以为要升职加薪。
结果他说："给大家介绍一下，这是我们新来的保洁阿姨。"
```

**吐槽式幽默**
对生活中不合理的现象进行调侃。

```
专家说年轻人不要躺平，要努力奋斗。
我想问专家：奋斗完了能买得起房吗？
如果奋斗完了还是买不起，那我躺着你管得着吗？
```

**意外式幽默**
剧情走向出乎意料。

```
我鼓起勇气表白，结果她手机没电了。
我等她充电，她充到80%的时候接了个电话。
挂了电话她说："不好意思，我男朋友找我。"
我："......"
她："你刚才说什么？"
我："没什么，我说你手机充电挺快的。"
```

## 四、结构布局深度指南

### 4.1 开头写法

**禁忌开头**
- 环境描写开头（除非你能写得非常抓人）
- 自我介绍式开头（"我叫XXX，是一个XXX"）
- 背景交代式开头（"这是一个关于..."）

**推荐开头方式**

**1. 场景切入式**
```
地铁三号线早高峰，我被挤得双脚离地。
不是夸张，是真的离地。
前一秒我还踩在地上，下一秒我就飞起来了。
```

**2. 冲突爆发式**
```
"分手吧。"
她说这话的时候，正在往嘴里塞第18个饺子。
```

**3. 反常识式**
```
我叫王建国，今年32岁，还没谈过恋爱。
不是没人追，是追我的都是我妈安排的。
```

**4. 对话切入式**
```
"你知道你错哪儿了吗？"
"我错在不该认识你？"
"不对。"
"我错在不该喜欢你？"
"也不对。"
"那你说啊，我到底错哪儿了？"
"你错在——你为什么要还我那五块钱？"
```

### 4.2 中段写法

**困境-行动-挫折-转折 循环**

不要让主角一帆风顺，也不要一直倒霉。波浪式前进，螺旋式上升。

```
困境1 → 行动1 → 挫折1 → 转折1
困境2 → 行动2 → 挫折2 → 转折2
困境3 → 行动3 → 挫折3 → 转折3
高潮 ←←←←←←←←←←←←←←←←
```

**每3000字一个小高潮**
长篇故事需要不断给读者"爽点"或"痛点"，否则读者会流失。

### 4.3 结尾写法

**禁忌结尾**
- 强行圆满（强行大团圆让人尴尬）
- 强行升华（"这个故事告诉我们..."）
- 强行反转（为了反转而反转）
- 戛然而止（故事没讲完就结束了）

**推荐结尾方式**

**1. 温情收尾**
```
后来我和老张还是经常去那家馄饨店。
他还是嫌弃我吃相难看，我还是偷偷多放辣椒。
只是现在我会记得给他也拿一碟醋。
有些话不用说，有些事不用问。
你懂我懂就够了。
```

**2. 留白收尾**
```
她问："你当年到底喜不喜欢我？"
他笑了笑，没说话，转身走了。
其实那天的风很大，她根本没听清他最后说了什么。
但她看到了他的嘴型。
那两个字是——"喜欢。"
```

**3. 反转收尾**
```
我以为这辈子最爱的人是他。
直到他去世，我整理遗物的时候才发现——
他这辈子最爱的人，从来都不是我。
是他初恋的名字。
刻在他心里最深的地方。
而我，不过是一个长得像她的替身。
```

**4. 开放式收尾**
```
故事讲完了。
但老李到底有没有找到他儿子？
老张说的那个"办法"到底是什么？
我妈最后有没有嫁过去？
这些，我也不知道。
生活不是故事，故事总要有结局。
生活没有。
```

## 五、去AI化深度指南

### 5.1 AI写作的典型特征

**词汇层面**
- 过度使用成语（四字词语）
- 喜欢用"然而"、"但是"、"因此"等连接词
- 形容词堆砌
- 书面语过多

**句式层面**
- 句子过于工整
- 段落过于均匀
- 缺少口语化表达
- 感叹号过多或过少

**结构层面**
- 过于追求逻辑严密
- 铺垫过长
- 缺乏"废话"
- 叙事节奏过于均匀

### 5.2 去AI化实操技巧

**技巧1：加入"废话"**
真人写作会有很多看似无用的话，AI不会。

```
✓ 真人味：
那天我记得特别清楚，是个周三。
为什么是周三呢？
因为周三外卖有满减，我每周三都会点那个麻辣烫。
虽然那个麻辣烫有点咸，但架不住便宜。

✓ AI味：
那天是个周三，我点了一份麻辣烫。
```

**技巧2：打乱节奏**
真人写作不会每个段落都完美衔接。

```
✓ 真人味：
说完这话我就后悔了。
不是，我为什么要说这个？
好好的气氛都被我搞砸了。
你说我嘴怎么就那么欠呢？
她也愣了一下，然后笑了。

✓ AI味：
说完这话我就后悔了。
她愣了一下，然后笑了。
```

**技巧3：加入真实细节**
真人写作会有很多生活化的细节，AI往往忽略。

```
✓ 真人味：
他脱了鞋，袜子前面有个洞。
大拇指若隐若现的。
我想笑，又不好意思笑。
他发现我在看，尴尬地把脚缩了缩。

✓ AI味：
他脱了鞋，有些尴尬。
```

**技巧4：允许不完美**
真人写作会有错别字（如果想模拟）、病句、重复，但AI不会。

```
✓ 真人味：
我也不知道为什么，就是感觉
算了不说了
反正就是那么个意思
你们懂的

✓ AI味：
我也不知道为什么，就是感觉到了一种莫名的情绪。
```

### 5.3 自检清单

完成故事后，逐项检查：

**对话检查**
- [ ] 读出声来，看看像不像真人说话
- [ ] 去掉所有引号，对话还成立吗？
- [ ] 有没有"复读机"式的对话？

**描写检查**
- [ ] 有没有具体的场景、物品？
- [ ] 有没有五感细节？
- [ ] 描写是否克制？

**人物检查**
- [ ] 主角有没有口头禅或小动作？
- [ ] 配角有没有自己的性格？
- [ ] 人物关系是否复杂？

**节奏检查**
- [ ] 开头是否抓人？
- [ ] 中段有没有起伏？
- [ ] 结尾是否有力？

**风格检查**
- [ ] 有没有AI腔需要修改？
- [ ] 有没有可以加入幽默感的地方？
- [ ] 有没有可以制造意外/反转的地方？

## 六、字数控制指南

### 6.1 字数分配

以2万字故事为例：

| 部分 | 字数 | 占比 |
|------|------|------|
| 开头（钩子+背景） | 2000字 | 10% |
| 发展（困境+行动） | 6000字 | 30% |
| 高潮（转折+冲突） | 8000字 | 40% |
| 结局（收尾+留白） | 4000字 | 20% |

### 6.2 字数调整技巧

**如果字数不够：**
- 增加一个配角
- 增加一个支线情节
- 增加回忆/插叙
- 增加场景描写
- 增加对话

**如果字数太多：**
- 删除冗余描写
- 合并配角
- 删除支线情节
- 加快叙事节奏
- 减少对话

## 七、创作心态指南

### 7.1 核心理念

写故事不是为了展示文采，而是为了讲好一个故事。

### 7.2 写作心态

**不要追求完美**
初稿都是垃圾，但垃圾里可能有金子。
先写出来，再慢慢改。

**不要害怕俗套**
俗套之所以是俗套，是因为好用。
俗套+细节=新鲜。

**不要自我感动**
你觉得感人的，读者可能觉得尴尬。
你觉得搞笑的，读者可能觉得冷。
写完放一放，再回头看。

**不要忽略生活**
最好的故事都是从生活中来的。
那些让你笑过、哭过、气过、无奈过的事，都是素材。

### 7.3 读者心态

**读者要的是什么？**
- 代入感：这事我也经历过
- 期待感：后面会发生什么
- 满足感：原来如此/太爽了/哭死我了
- 获得感：学到了什么/感悟了什么

**读者讨厌什么？**
- 拖沓（废话太多）
- 强行（转折太突兀）
- 尴尬（强行煽情）
- 无聊（没有冲突）
- 被教育（道理讲太多）

## 八、热门题材推荐

### 8.1 情感类（永不过时）
- 分手后的前任突然联系你
- 暗恋多年的对象突然脱单
- 相亲遇到奇葩
- 复合后又分手
- 友情变质

### 8.2 职场类（戳心窝子）
- 同事甩锅
- 领导画饼
- 加班到崩溃
- 面试被PUA
- 裸辞后的焦虑

### 8.3 家庭类（情感炸弹）
- 父母偏心
- 原生家庭的伤
- 和解或不和解
- 遗产风波
- 催婚大战

### 8.4 社会类（引发共鸣）
- 租房踩坑
- 外卖小哥的故事
- 地铁上的陌生人
- 便利店的深夜
- 小区的八卦

### 8.5 悬疑类（反转惊喜）
- 消失的他/她
- 邻居的秘密
- 同事的另一面
- 朋友的朋友
- 假象的真相
