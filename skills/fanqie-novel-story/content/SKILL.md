# 番茄小说短故事创作技能

## 核心定位

生成符合番茄小说平台风格的短篇故事，字数控制在1万至3万字之间，追求"接地气、贴生活、有烟火气"的文风，杜绝AI味，确保每个故事都像是从真实生活中提炼出来的。

## 质量标准

### 硬性指标
- **字数**：10,000-30,000字（标点符号不计入）
- **结构完整**：有清晰的开端、发展、高潮、结局
- **可读性强**：段落适中，每段不超过150字

### 软性指标（去AI化核心）
- **口语化对话**：角色说话要像真人，避免书面语
- **生活化细节**：要有具体的场景、物品、动作描写
- **有缺陷的完美**：允许叙事上的小瑕疵和风格的"毛边"
- **幽默感**：不是刻意搞笑，而是从生活细节中自然流露
- **情绪真实**：喜怒哀乐都要有层次，不是脸谱化的表达

## 故事类型库

### 都市生活类
- 打工人日常（通勤、加班、租房、外卖）
- 小镇青年的进击与迷茫
- 家庭关系的鸡毛蒜皮
- 相亲恋爱那些事儿
- 职场博弈与生存法则

### 情感故事类
- 友情、爱情、亲情的微妙关系
- 分手、复合、暗恋、明恋
- 中年危机与婚姻经营
- 原生家庭的羁绊与和解

### 悬疑反转类
- 日常生活中的意外事件
- 身份秘密与身份反转
- 邻里关系背后的故事

### 治愈暖心类
- 人与动物的特殊羁绊
- 陌生人之间的善意
- 平凡人的闪光时刻

## 写作风格指南

### 对话写作规范
```
❌ AI味： "让我们重新开始吧。"
✓ 真人味： "要不...咱俩再试试？"

❌ AI味： "我很抱歉。"
✓ 真人味： "那啥...对不起啊，我错了还不行吗..."

❌ AI味： "你永远都不会懂的。"
✓ 真人味： "算了，跟你说了你也不明白。"
```

### 描写克制原则
```
❌ 过度描写：她的眼眸中闪烁着晶莹的泪光，在昏暗的灯光下显得格外动人
✓ 克制描写：她眼眶红了，别过脸去

❌ 心理描写：他的内心翻涌着复杂的情绪，纠结着是否应该坦诚
✓ 动作暗示：他把烟点上，又掐灭，反反复复

❌ 环境描写：天空湛蓝如洗，白云悠悠飘过，鸟儿在枝头欢快歌唱
✓ 场景切片：外面日头正毒，蝉叫得人心烦
```

### 幽默感来源
1. **自嘲**：主角的尴尬、窘迫、倒霉
2. **反差**：正经场合的不正经反应
3. **吐槽**：对生活、社会、职场的不满式幽默
4. **意外**：剧情走向的出人意料但合情合理
5. **梗**：融入当下流行的网络用语和热梗

### 段落节奏把控
- 长段落（3-5句）：用于铺垫、情绪积累
- 短段落（1-2句）：用于转折、高潮、制造张力
- 超短段落（1句）：用于强调、留白

## 叙事结构模板

### 开头三板斧（500字内）
1. 制造钩子：一个悬念、一个冲突、一个尴尬场景
2. 交代背景：用行动而非说明
3. 建立人设：让读者迅速记住主角

### 中段四步走
1. **困境呈现**：主角面临什么问题
2. **尝试解决**：主角做了什么努力
3. **遭遇挫折**：事情变得更糟
4. **意外转折**：出现意想不到的变数

### 结尾三模式
1. **开放式**：留悬念，让读者意犹未尽
2. **温情式**：给一个温暖的收尾
3. **反转式**：结尾出乎意料但逻辑自洽

## 去AI化自检清单

生成故事后，逐项检查：

- [ ] 对话是否像真人说话？（朗读出来检查）
- [ ] 是否有具体的生活细节？（地名、食物、物品）
- [ ] 主角是否有鲜明的口头禅或小动作？
- [ ] 故事是否有一个"不太完美"的真实感？
- [ ] 是否有从生活中观察到的有趣细节？
- [ ] 幽默是否自然而非刻意？
- [ ] 情绪表达是否有层次和变化？
- [ ] 是否有让人共情的点？

## 生成流程

### 第一步：确定故事内核
- 核心冲突是什么？
- 主角想要什么？
- 最大的悬念/看点是什么？

### 第二步：构建人物关系
- 主角性格特点（缺陷即魅力）
- 配角功能（推动剧情/制造冲突/提供对比）
- 人物关系图谱

### 第三步：设计情节走向
- 列出3-5个关键情节点
- 设计至少1个反转
- 预埋伏笔并回收

### 第四步：确定风格调性
- 是悲是喜还是悲喜交加
- 幽默比重的分配
- 情感烈度的把控

### 第五步：动笔写作
- 先写草稿，不追求完美
- 写完后通读，用真人思维替换AI腔
- 控制字数在目标范围内

## 输出格式

故事以纯文本形式输出，结构如下：

```
【故事标题】

【开篇引导语 - 一句话抓住眼球】

【正文】

【引导语 - 让读者产生互动欲望】
```

## 注意事项

1. **不要堆砌形容词**：用名词和动词构建画面
2. **不要过度解释**：让读者自己体会
3. **不要完美人设**：有缺点的主角更可爱
4. **不要狗血过头**：贴近生活才能引发共鸣
5. **不要忘记节奏**：有张有弛才能吸引人读下去
