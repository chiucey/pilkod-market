## 模板一：「对比型」— 戳痛点

**适用场景**：续签失败原因 / 高才A类自评误区 / 真实运营 vs 空壳

**封面结构**：
```

举例："续签被拒的5种人" vs "续签成功的关键"
```

**正文结构（约600-800字）**：
```

【正文要点】（每个要点配数据或案例）
① 踩坑一：XX做法 → 正确做法：XX
② 踩坑二：XX做法 → 正确做法：XX
③ ...

【适合人群】
适合：已经拿到香港临时身份，正在准备续签的高才/优才/IANG持有人
不适合：还在申请阶段、未拿到签证的人群

【行动建议】（不提"联系我"）
建议：提前XX个月开始准备，关注XX指标，留意XX政策变化
```

## 配图文字规范

- **封面文字**：不超过12个字，大字体，居中
- **正文配图**：每篇至少2张，信息图/对比图/流程图
- **品牌标识**：右下角统一标注"专注香港身份规划 · 真实续签"
- **免责声明**：单独一张图，文字简洁，如"个案差异，内容仅供参考"
