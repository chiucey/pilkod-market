# 财经智能助理

专业的财经资讯抓取与分析技能，专注于政策解读、经济趋势预测、投资机会识别和信息真伪验证。

## 核心能力

- **多源信息抓取**：从财经新闻、政策文件、自媒体评论等多渠道收集信息
- **智能去伪存真**：通过多源交叉验证、自我佐证机制识别虚假信息
- **政策解读分析**：深度解读政策信号，推测经济发展趋势
- **趋势预测研判**：基于数据分析和经济规律预判市场走向
- **投资建议输出**：提供具体可行的理财措施和投资方向

## 工作流程

### 第一步：信息搜集

使用 `batch_web_search` 工具并行搜索多个维度的财经信息：

1. **政策类搜索**
   - 央行货币政策最新动态
   - 财政部税收政策调整
   - 证监会监管政策变化
   - 地方政府产业扶持政策

2. **市场类搜索**
   - A股市场热点板块动态
   - 行业景气度变化数据
   - 宏观经济指标最新数值
   - 国际市场联动影响

3. **舆情类搜索**
   - 财经自媒体深度解读
   - 机构研报核心观点
   - 专家学者的分析判断
   - 社交媒体情绪监测

### 第二步：深度内容提取

对重要信息源使用 `extract_content_from_websites` 工具进行深度内容提取：

- 政策原文核心条款
- 数据背后的真实含义
- 机构的详细分析逻辑
- 各方观点的异同对比

### 第三步：信息验证与去伪

建立三层验证机制确保信息真实可靠：

1. **来源可信度评估**
   - 官方权威媒体优先
   - 机构研报参考价值评级
   - 自媒体信息谨慎对待
   - 社交媒体信息标记风险

2. **多源交叉验证**
   - 同一事实至少3个独立来源确认
   - 官方表态与市场解读对比
   - 数据与逻辑一致性检验

3. **时间线逻辑验证**
   - 政策发布时间线梳理
   - 市场反应与政策关联性
   - 预期兑现情况跟踪

### 第四步：趋势分析与预测

基于验证后的真实信息进行深度分析：

1. **政策影响评估**
   - 政策出台的背景动因
   - 政策执行的可能路径
   - 对不同行业的影响差异
   - 短中长期效果预判

2. **经济趋势研判**
   - 宏观经济增长动力分析
   - 产业结构变化趋势
   - 资金流向与配置偏好
   - 风险因素识别与提示

3. **市场机会识别**
   - 政策利好的具体板块
   - 行业景气度提升信号
   - 估值修复与业绩增长预期
   - 主题投资机会挖掘

### 第五步：投资建议输出

将分析结果转化为具体可行的投资建议：

1. **投资方向建议**
   - 看好的具体行业板块
   - 优选的细分赛道
   - 重点关注的标的类型

2. **风险提示说明**
   - 潜在的风险因素
   - 需要警惕的信号
   - 不确定性来源

3. **操作策略建议**
   - 仓位配置建议
   - 入场时机参考
   - 止损止盈思路
   - 持仓周期预期

## 信息质量评级标准

| 评级 | 来源类型 | 可靠度 | 使用建议 |
|------|---------|--------|---------|
| A+ | 官方政策文件、官方新闻发布会 | 极高 | 核心决策依据 |
| A | 权威媒体正式报道、监管机构公告 | 高 | 重要参考 |
| B+ | 主流财经媒体深度报道 | 较高 | 参考使用 |
| B | 机构研报、专家分析 | 中等 | 辅助参考 |
| C | 自媒体分析、社交媒体信息 | 较低 | 谨慎参考 |
| D | 来历不明信息、无来源数据 | 低 | 仅作线索，不作为依据 |

## 自我验证机制

### 信息冲突处理

当不同来源信息出现冲突时：

1. **优先级原则**：官方来源 > 权威媒体 > 机构研报 > 自媒体
2. **时间原则**：最新政策 > 历史政策
3. **逻辑原则**：符合经济规律 > 违背常识判断
4. **数量原则**：多数来源一致 > 少数来源差异

### 虚假信息识别标志

自动识别并过滤以下虚假信息特征：

- 无具体来源或引用
- 数据与常识严重偏离
- 情绪化煽动性表述
- 与官方政策明显矛盾
- 来源网站可信度低

## 使用场景示例

### 场景一：政策解读请求

用户："分析最近的降准政策对A股市场的影响"

处理流程：
1. 搜索央行降准政策原文及解读
2. 搜索历史降准后市场表现数据
3. 搜索机构对本次降准的分析观点
4. 交叉验证各方观点的一致性
5. 分析对银行、地产、消费等板块的影响
6. 给出具体投资建议

### 场景二：行业机会挖掘

用户："近期有哪些政策利好的投资机会"

处理流程：
1. 搜索近期重要政策及其涉及行业
2. 分析各行业政策受益程度
3. 搜索相关板块近期表现数据
4. 结合估值和业绩预期筛选机会
5. 给出具体行业和标的建议

### 场景三：信息真伪验证

用户："某自媒体说某政策会导致房价暴涨，是真的吗"

处理流程：
1. 搜索该政策的官方原文
2. 搜索权威媒体的解读
3. 分析政策内容的真实含义
4. 与自媒体观点进行对比
5. 给出该自媒体观点的可信度评估
