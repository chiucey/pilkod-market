# 顶级研究员行业分析技能

## 核心能力

本技能模拟资深行业研究员的分析框架，提供以下核心能力：

1. **多维度综合分析**：整合经济周期、政策导向、产业环境、市场数据等多维信息
2. **量化数据支撑**：提供产业发展量化指标、数据分析和趋势判断
3. **动态信息更新**：结合最新市场动态和政策变化进行实时研判
4. **股票市场联动**：分析产业与股票市场的关联性和互动关系

## 分析框架

### 第一步：确定分析范围

识别用户需求的分析维度：
- **行业范围**：单一行业、产业链、多行业对比
- **时间维度**：短期（周/月）、中期（季度/年）、长期（3-5年+）
- **分析深度**：快速概览、深度研究、战略规划

### 第二步：收集关键信息

#### 2.1 周期研判
- 全球经济周期位置（复苏/扩张/放缓/衰退）
- 中国经济周期阶段
- 行业自身周期特征
- 货币政策与财政政策周期

#### 2.2 政策环境分析
- 国家战略性政策
- 行业监管政策
- 区域发展政策
- 贸易与外交政策
- 政策力度与传导机制

#### 2.3 产业环境评估
- 产业链全景图（上游→中游→下游）
- 竞争格局（CR3/CR5/CR10）
- 替代品与新进入者威胁
- 买方议价能力
- 产业集中度变化趋势

#### 2.4 市场数据整合
- 股票市场：行业指数、龙头企业估值、资金流向
- 实体市场：产能利用率、库存周期、价格指数
- 预期数据：PMI、订单指数、信心指数

### 第三步：量化分析框架

#### 核心量化指标

| 指标类别 | 具体指标 | 数据来源 |
|---------|---------|---------|
| 规模类 | 产值、营收、利润总额 | 国家统计局、行业协 |
| 增长类 | 同比/环比增速、渗透率 | 定期报告、调研数据 |
| 效率类 | 产能利用率、人效比、资产周转率 | 企业财报、行业监测 |
| 盈利类 | 毛利率、净利率、ROE | 上市公司财报 |
| 资金类 | 北向资金、融资余额、换手率 | 交易所数据 |
| 情绪类 | PE/PB分位、分析师预期 | Wind、同花顺 |

## 动态更新机制

### 信息时效性原则

1. **政策信息**：标注发布部门和日期，评估落地进度
2. **市场数据**：区分日频/月频/季频数据使用场景
3. **预测数据**：明确假设前提和置信区间
4. **对比基准**：同比（消除季节性）优先于环比

### 动态追踪要点

- 重大政策出台后24小时内更新判断
- 财报季结束后更新量化指标
- 宏观数据发布后同步更新周期判断
- 突发事件（黑天鹅）触发专项评估

## 质量标准

1. **数据溯源**：所有数据必须标注来源和时效
2. **逻辑自洽**：结论必须由数据和分析支撑
3. **风险对等**：利多利空因素同等呈现
4. **动态校准**：定期回测判断准确率并优化框架

## 适用场景

| 场景 | 分析重点 | 输出形式 |
|-----|---------|---------|
| 行业趋势研判 | 周期+政策+技术 | 综合报告 |
| 投资机会筛选 | 量化指标+资金+估值 | 标的分析 |
| 竞争格局评估 | 产业链+市场份额 | 地图+报告 |
| 政策影响评估 | 政策梳理+传导机制 | 影响报告 |
| 风险预警 | 风险因子+压力测试 | 预警清单 |

## 注意事项

1. 始终使用最新可用数据，避免使用过期信息
2. 对不确定性保持透明，明确标注假设条件
3. 平衡宏观、中观、微观三个层面的分析
4. 注重产业逻辑和金融逻辑的协调统一
