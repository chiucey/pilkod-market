# 相似日查找工具

## 概述

本技能以**统计表.xlsx**为数据库，用于在历史数据中查找与预测日特征相似的日期，利用相似日的负荷曲线进行预测。

## 数据源说明

### 数据库文件

| 文件 | 内容 | Sheet结构 |
|-----|------|----------|
| 统计表.xlsx | 历史负荷统计数据 | 按年份/日期命名 |

### Sheet命名规则

| Sheet名称 | 对应数据 | 数据范围 |
|-----------|----------|----------|
| 26 | 2026年数据 | 4月下旬-5月 |
| 25 | 2025年数据 | 5月 |
| Sheet1~Sheet31 | 其他分类数据 | 视情况 |

### 数据维度

| 分时类型 | 时段数 | 时间粒度 |
|---------|-------|---------|
| 96点 | 96 | 每15分钟一个点 |
| 48点 | 48 | 每30分钟一个点 |
| 24点 | 24 | 每小时一个点 |

### 数据列结构

| 列位置 | 字段名 | 说明 |
|-------|-------|------|
| 第1列 | 分时 | 96/48/24 |
| 第2列 | 日期 | 如4.27周一、5.01 |
| 第3列 | 品种 | 周预测数据/日前负荷/实际负荷数据/日前价格 |
| 第4列 | 天气 | 太阳/阴天/多云太阳/下雨阴天/阴雨等 |
| 第5列 | 每进一日 | 标识 |
| 第6列 | 负荷 | 日总负荷量 |
| 第7列~ | 时段数据 | 各时段电力负荷值 |

## 核心功能

### 1. 相似日查找流程

#### 步骤一：确定预测日特征

获取预测日的关键信息：
- **工作日类型**：周一至周五/周六/周日/节假日
- **天气条件**：晴天/阴天/多云/雨天
- **气温水平**：最高温、最低温
- **日期信息**：预测日期

#### 步骤二：筛选候选日期

从统计表数据库中筛选候选日期：

1. **筛选范围**：优先近期数据（30天内）
2. **筛选条件**：同工作日类型
3. **排除条件**：极端天气日期

#### 步骤三：计算相似度

**匹配维度与权重**：

| 匹配维度 | 权重 | 优先级 |
|---------|------|-------|
| 工作日类型 | 40% | 高 |
| 天气条件 | 30% | 高 |
| 气温水平 | 20% | 中 |
| 日期相近 | 10% | 中 |

**相似度计算**：

```python
综合评分 = 工作日类型得分 × 0.4 + 天气得分 × 0.3 + 气温得分 × 0.2 + 季节得分 × 0.1
```

#### 步骤四：输出相似日

按综合评分排序，输出评分最高的3-5个相似日及其曲线数据。

### 2. 匹配规则详解

#### 2.1 工作日类型匹配

| 预测日类型 | 优先匹配 | 备选 |
|-----------|---------|------|
| 周一至周五 | 近期工作日 | 同周一/周二... |
| 周六 | 近期周六 | 周五 |
| 周日 | 近期周日 | 周六 |
| 节假日 | 去年同期节假日 | 节假日相近日 |

#### 2.2 天气条件匹配

| 预测日天气 | 相似日选择 | 电量区间（MWh） |
|-----------|-----------|-----------------|
| 晴天 | 晴天 | 50,000-70,000 |
| 阴天 | 阴天 | 6,000-12,000 |
| 多云 | 多云/阴天 | 12,000-35,000 |
| 雨天 | 雨天 | 视情况 |

#### 2.3 气温水平匹配

| 温度条件 | 负荷特征 |
|---------|---------|
| 最高温≥30℃第2天 | 负荷+30,000 MWh |
| 最高温≥30℃第3天 | 负荷再+50,000 MWh |
| 降温第1天 | 不降负荷 |
| 连续降温2天 | 恢复原水平 |

### 3. 相似度评分标准

#### 3.1 工作日类型得分

| 匹配情况 | 得分 |
|---------|------|
| 完全相同 | 1.0 |
| 同类（如都是工作日） | 0.8 |
| 相邻（如周一配周五） | 0.5 |

#### 3.2 天气条件得分

| 匹配情况 | 得分 |
|---------|------|
| 完全相同 | 1.0 |
| 相近（如晴天配多云） | 0.7 |
| 差异大 | 0.3 |

#### 3.3 气温得分

| 温度差异 | 得分 |
|---------|------|
| 差异0-2℃ | 1.0 |
| 差异2-5℃ | 0.7 |
| 差异5-10℃ | 0.4 |
| 差异>10℃ | 0.1 |

### 4. 查询示例

#### 示例一：查找5月11日（周一，晴天）的相似日

**输入**：
- 预测日期：5月11日
- 工作日类型：周一
- 天气：晴天

**查询过程**：
1. 在"26"Sheet筛选周一数据
2. 筛选天气为"太阳"的日期
3. 匹配近期数据（如4.27周一太阳）
4. 计算综合评分

**输出**：4.27周一的负荷曲线作为预测基准

#### 示例二：查找节假日前的相似日

**输入**：
- 预测日期：6月2日（端午节后第一个工作日）
- 工作日类型：周一（节假日后）
- 天气：多云

**查询过程**：
1. 在"25"Sheet查找去年端午节数据
2. 筛选节假日后恢复期的数据
3. 匹配天气和温度相近的日期

**输出**：去年端午后相似日曲线供参考

### 5. 数据验证标准

| 验证项目 | 合格标准 |
|---------|---------|
| 日总电量偏差 | ±10%以内 |
| 峰谷时段位置 | 一致 |
| 曲线形态 | 平滑无突变 |

### 6. 注意事项

1. **数据时效性**：近期数据（7-15天）优先于远期数据
2. **极端日期剔除**：暴雨、台风等天气日期不参与匹配
3. **季节性调整**：选取去年同期样本时需考虑年际负荷增长（约5%）
4. **曲线形态检查**：选取后目视检查曲线是否合理

## 术语说明

- **相似日**：与预测日在工作日类型、天气、气温等维度相近的历史日期
- **匹配法**：利用相似日历史曲线进行预测的方法
- **96点数据**：每15分钟一个数据点，全天96个点
- **48点数据**：每30分钟一个数据点，全天48个点
