# 自动剪口播技能

## 触发条件

当用户需要以下操作时触发本技能：
- 自动剪辑口播/自拍类视频
- 使用开拍网页版进行预处理
- 自动识别字幕
- 自动添加AI画中画
- 自动生成标题和配乐
- 视频后期检查和修改

## 工作流程

### 步骤1：打开开拍网页版

访问开拍工作台：https://www.kaipai.com/workspace

使用 `interact_with_website` 工具打开网页并登录（如需要）。

### 步骤2：上传原始视频

1. 在开拍工作台中找到"上传视频"或"导入素材"功能
2. 选择用户提供的原始口播视频文件
3. 等待视频上传完成

### 步骤3：选择AI智能剪辑功能

在开拍平台中选择以下AI功能进行预处理：

1. **自动识别字幕** - 开启字幕识别
2. **AI画中画** - 开启智能画中画效果
3. **自动生成标题** - 开启标题生成
4. **智能配乐** - 选择合适的背景音乐

### 步骤4：等待AI处理

系统将自动处理视频，等待处理完成（可能需要几分钟时间）。

### 步骤5：人工检查与修改（关键步骤）

**这是成品输出前的最后检查环节，必须认真执行：**

1. **逐帧检查字幕**
   - 播放处理后的视频
   - 仔细核对每一句字幕
   - 如发现错别字，在编辑界面直接修改为正确文字

2. **检查画中画效果**
   - 确认画中画位置、大小合适
   - 检查画中画与主画面切换时机是否自然

3. **检查标题**
   - 确认标题是否准确反映视频内容
   - 如有不准确处，修改为正确标题

4. **检查配乐**
   - 确认背景音乐与视频节奏匹配
   - 检查音量是否合适

### 步骤6：导出成品

确认所有检查项无误后：

1. 点击"导出"或"生成成品"
2. 选择合适的分辨率和格式
3. 等待视频导出完成
4. 下载最终成品视频

## 注意事项

- 如果开拍需要登录，引导用户先完成登录
- 如果处理失败，尝试重新上传或联系开拍客服
- 检查错别字是最后成品质量的关键步骤，不可跳过
- 导出时建议选择1080P或更高分辨率

## 成功标准

- 视频成功上传并处理完成
- 字幕、画中画、标题、配乐均已添加
- 已完成人工检查，错别字已修正
- 最终成品视频已成功导出
