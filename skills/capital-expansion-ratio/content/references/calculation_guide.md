## 完整计算公式

### 数据来源映射

| 项目 | 数据来源 | 说明 |
|------|----------|------|
| (1) 处置固定资产等收回的现金净额 | 现金流量表（投资活动） | 直接取值 |
| (2) 购建固定资产等支付的现金 | 现金流量表（投资活动） | 直接取值（资本支出） |
| (3) 长期经营资产净投资额 | 计算得出 | = (2) - (1) |
| (4) 固定资产折旧、油气资产折耗、生产性生物资产折旧 | 现金流量表（附注/间接法调整项） | 直接取值 |
| (5) 无形资产摊销 | 现金流量表（附注/间接法调整项） | 直接取值 |
| (6) 长期待摊费用摊销 | 现金流量表（附注/间接法调整项） | 直接取值 |
| (7) 处置固定资产、无形资产和其他长期资产的损失 | 现金流量表（附注/间接法调整项） | 直接取值，无则填0 |
| (8) 固定资产报废损失 | 现金流量表（附注/间接法调整项） | 直接取值，无则填0 |
| (9) 长期经营资产扩张性资本支出 | 计算得出 | = (3) - (4) - (5) - (6) - (7) - (8) |
| (10) 期初长期经营资产净额 | 资产负债表（上年年末） | 见下方说明 |
| (11) 长期经营资产扩张性支出比例 | 计算得出 | = (9) ÷ (10) × 100% |

---

### 第 (10) 项：期初长期经营资产净额

**组成项目（取当年年初，即上年年末的资产负债表数据）：**

```
期初长期经营资产净额 =
    固定资产（净值）
  + 无形资产
  + 长期待摊费用
  + 商誉（若有）
  + 投资性房地产（若有）
  + 生产性生物资产（若有）
  + 油气资产（若有）
```

**注意：**
- 投资性房地产若采用公允价值模式计量，则不计入（因其不计提折旧）。
- 实操中常用简化口径：仅取固定资产净值 + 无形资产 + 长期待摊费用。

## 指标含义

- **正值高比例**：公司正在积极扩张长期经营资产，意味着大规模资本支出超过资产损耗，产能持续扩大。
- **接近零**：资本支出约等于资产折旧摊销，公司处于维持现状阶段，无明显扩张。
- **负值**：扩张性支出为负，说明公司资本支出不足以覆盖资产损耗，长期资产在净缩减（可能在收缩或出售资产）。

## AKShare 接口参考

### 东方财富接口（推荐，优先使用）

```python
import akshare as ak

# 现金流量表（年度）
cf = ak.stock_cash_flow_sheet_by_yearly_em(symbol="600309")

# 资产负债表（年度）
bs = ak.stock_balance_sheet_by_yearly_em(symbol="600309")
```

### 新浪接口（备用）

```python
# 沪市：sh前缀；深市：sz前缀
cf = ak.stock_financial_report_sina(stock="sh600309", symbol="现金流量表")
bs = ak.stock_financial_report_sina(stock="sh600309", symbol="资产负债表")
```

## 常见字段名变体

现金流量表中，不同数据源对同一字段的命名可能存在差异：

| 标准字段 | 常见变体 |
|----------|----------|
| 购建固定资产等支付的现金 | 资本支出、购置固定资产、购建固定资产支出 |
| 处置固定资产等收回的现金净额 | 处置资产收回、出售固定资产 |
| 固定资产折旧 | 折旧与摊销、固定资产折旧费用 |
