# 长期经营资产扩张性支出比例分析技能

## 目标

从对话框获取上市公司代码或简称，通过 AKShare 获取近5年（或上市以来）现金流量表及资产负债表，计算并展示**长期经营资产扩张性支出比例**，结果以结构化表格呈现。

---

## 工作流程

### 第一步：获取公司信息

直接向用户询问：

> 请输入上市公司的股票代码（如 600309）或公司简称（如 万华化学）：

- 若用户输入简称，需通过 AKShare `stock_info_a_code_name` 接口将其匹配为 A 股代码（6 位数字）。
- 确认所查公司的股票代码和全称后，进入第二步。

### 第二步：获取财务数据

使用 AKShare 接口获取以下两类数据（年度报告，取最近5个完整年度，不足5年则取上市以来所有年度）：

**（A）现金流量表** —— 使用 `stock_financial_report_sina` 接口，`indicator="现金流量表"`：

需要的字段（关键字段名可能因接口版本略有差异，优先精确匹配，次之模糊匹配）：

| 变量 | 中文字段名（模糊匹配关键词） |
|------|------------------------------|
| `cash_from_disposal` | 处置固定资产、无形资产和其他长期资产收回的现金净额 |
| `cash_for_acquisition` | 购建固定资产、无形资产和其他长期资产支付的现金 |
| `depreciation_fa` | 固定资产折旧、油气资产折耗、生产性生物资产折旧 |
| `amort_intangible` | 无形资产摊销 |
| `amort_lt_prepaid` | 长期待摊费用摊销 |
| `loss_disposal` | 处置固定资产、无形资产和其他长期资产的损失 |
| `loss_scrap` | 固定资产报废损失 |

**（B）资产负债表** —— 使用 `stock_financial_report_sina` 接口，`indicator="资产负债表"`：

| 变量 | 中文字段名（模糊匹配关键词） |
|------|------------------------------|
| `fa_net` | 固定资产净额 / 固定资产 |
| `intangible_net` | 无形资产 |
| `lt_prepaid` | 长期待摊费用 |
| `goodwill` | 商誉（若有） |
| `invest_property` | 投资性房地产 |
| `productive_bio` | 生产性生物资产（若有） |
| `oil_gas` | 油气资产（若有） |

> **注意：** 若 AKShare 接口格式变化，优先检查 `stock_balance_sheet_by_yearly_em`、`stock_cash_flow_sheet_by_yearly_em`（东方财富接口），字段名称需重新匹配。

**执行脚本：** 调用 `scripts/fetch_and_calc.py` 完成数据获取与计算。

---

### 第三步：计算长期经营资产扩张性支出比例

按以下11项逐年计算（金额单位：万元）：

```
(1) 处置固定资产等收回的现金净额          = cash_from_disposal
(2) 购建固定资产等支付的现金              = cash_for_acquisition
(3) 长期经营资产净投资额 (=(2)-(1))       = (2) - (1)
(4) 固定资产折旧、油气资产折耗、生产性生物资产折旧  = depreciation_fa
(5) 无形资产摊销                         = amort_intangible
(6) 长期待摊费用摊销                     = amort_lt_prepaid
(7) 处置固定资产等的损失                  = loss_disposal
(8) 固定资产报废损失                     = loss_scrap
(9) 长期经营资产扩张性资本支出 (=(3)-(4)-(5)-(6)-(7)-(8))
(10) 期初长期经营资产净额                 = 上年末(fa_net + intangible_net + lt_prepaid + goodwill + invest_property + productive_bio + oil_gas)
(11) 长期经营资产扩张性支出比例 (=(9)/(10)×100%)
```

> **期初说明：** 第 (10) 行取**当年年初**（即上一年年末）的资产负债表数据，为各长期经营资产净值之和。

---

### 第四步：展示结果

以 Markdown 表格形式输出，格式参考如下：

```

金额单位：万元

| 项目                                          | 20XX-12-31 | 20XX-12-31 | 20XX-12-31 | 20XX-12-31 | 20XX-12-31 |
|-----------------------------------------------|------------|------------|------------|------------|------------|
| (1) 处置固定资产等收回的现金净额               |            |            |            |            |            |
| (2) 购建固定资产等支付的现金                   |            |            |            |            |            |
| (3) 长期经营资产净投资额 (=(2)-(1))            |            |            |            |            |            |
| (4) 固定资产折旧、油气资产折耗、生产性生物资产折旧 |         |            |            |            |            |
| (5) 无形资产摊销                              |            |            |            |            |            |
| (6) 长期待摊费用摊销                          |            |            |            |            |            |
| (7) 处置固定资产、无形资产和其他长期资产的损失  |            |            |            |            |            |

| (9) 长期经营资产扩张性资本支出 (=(3)-(4)-...-(8)) |         |            |            |            |            |
```

**展示要求：**
- 年份列从最新年份排列到最旧年份（从左至右）。
- 数字以千分位逗号分隔，保留两位小数。
- 第 (11) 行比例保留两位小数，附带 `%` 符号。
- 缺失数据显示 `—`（横杠）。
- 表格下方附注：数据来源 AKShare，接口获取日期。

## 错误处理

| 情形 | 处理方式 |
|------|----------|
| 公司代码/简称无法匹配 | 提示用户确认并重新输入 |
| 年报数据不完整（某字段缺失） | 将该字段标为 `—`，继续计算可计算项 |
| 接口调用失败 | 报错提示，建议稍后重试或换用备用接口 |
| 上市不足1年（无年报） | 提示"暂无足够年报数据，无法计算" |
| 处置收到的现金净额为负（资产损失） | 按0处理，并在表格下方备注 |

---

## 关键约束

- 仅处理 **A 股上市公司**，代码为 6 位数字。
- 财务数据单位统一换算为**万元**后再展示。
- 所有计算必须基于**合并报表**数据（非母公司单体）。
- 若同时有多个年度数据，取最近5个自然年度（以会计年度截止日12月31日为准）。
