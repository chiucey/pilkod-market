# 新功能开发流程

适合：新增页面、新增API、新增模块

```
需求理解 → 任务分解
  ↓
技术方案设计
  ↓
TDD循环（每个子任务）
  ↓
功能联调
  ↓
自审 + 清理
  ↓
提交 + 文档更新
```

## TDD 循环详细步骤

### 1. 写一个失败测试
- 测试文件名：`{模块名}.test.ts`
- 测试内容：描述期望行为
- 运行测试：确认失败（red）

### 2. 写最少量代码通过测试
- 只写让测试通过的最少代码
- 不多不少（YAGNI 原则）
- 运行测试：确认通过（green）

### 3. 重构
- 改善代码结构，不改变行为
- 运行测试：确认通过（refactor）

## 什么时候停？

- 所有子任务完成
- 测试全部通过
- 自审5项全部通过
