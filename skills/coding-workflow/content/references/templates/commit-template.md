# Commit 信息模板

## 格式

```
[类型] 简述：做了什么 + 为什么

详细说明（可选）
```

## 类型标签

| 标签 | 用途 |
|------|------|
| `[feat]` | 新功能 |
| `[fix]` | 修复bug |
| `[refactor]` | 重构（不改变行为） |
| `[test]` | 新增/修改测试 |
| `[docs]` | 文档更新 |
| `[chore]` | 构建/工具/依赖 |
| `[perf]` | 性能优化 |
| `[style]` | 代码格式（不影响行为） |

## 示例

```
[feat] 添加资金账户历史记录功能
支持按日期记录余额变动，饼图展示分布

[fix] 修复删除账户后趋势图不更新问题
原因：未调用 renderAll()
```

## Commit 节奏

- 每完成一个**子任务**就提交
- 不要攒很多改动一次性提交
- 信息具体：让人看到 commit 就知道发生了什么
