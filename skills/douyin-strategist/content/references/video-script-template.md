# 短视频脚本模板参考

## 黄金3秒钩子库

### 冲突型钩子
- "千万别买 XXX，除非你先看完这条视频"
- "花 300 块买的教训，看完立省 3000"
- "99% 的人都不知道的 XXX，今天全部告诉你"

### 价值型钩子
- "花了 XX 元，解决了困扰我 3 年的难题"
- "这个方法让我每月多赚 XX 元"
- "3 分钟学会价值 XX 元的技能"

### 悬念型钩子
- "我发现了一个 XX 行业不愿让你知道的秘密"
- "为什么商家从不说 XXX？看完你就懂了"
- "直播带货背后的套路，今天全曝光"

### 共鸣型钩子
- "有没有人跟我一样，每次 XXX 的时候都崩溃？"
- "作为 XX 年从业者，我想说句公道话"
- "同样买 XXX，为什么别人买的就是比你好用？"

## 视频结构公式

### 种草类 (30-45秒)
```
0-3s:  黄金钩子（抛出痛点或悬念）
4-10s: 痛点放大（让用户感同身受）
11-20s: 解决方案（产品介绍+效果展示）
21-30s: 价值总结 + 互动引导
```

### 教学类 (45-60秒)
```
0-3s:  价值承诺（学完能获得什么）
4-15s: 核心知识点1
16-25s: 核心知识点2
26-35s: 核心知识点3
36-45s: 实操演示 + 成果展示
46-55s: 总结回顾 + 关注引导
```

### 剧情反转类 (15-30秒)
```
0-5s:  铺垫场景（制造熟悉感）
6-15s: 冲突升级（制造紧张感）
16-25s: 反转揭晓（出乎意料的结果）
```

## 拍摄要求
- 比例：9:16 垂直构图
- 出镜：真人出镜完播率比纯产品空镜高 30%+
- 字幕：必须添加，支持静音观看
- BGM：使用本周热门背景音乐
- 画质：1080P+，光线充足
