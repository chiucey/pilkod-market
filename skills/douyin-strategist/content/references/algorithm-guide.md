# 抖音算法机制与流量运营

## 推荐算法核心逻辑

### 流量池机制
抖音采用分级流量池制度：
1. **冷启动池** (200-500 播放)：新视频首先进入小流量池
2. **初始分发池** (3000-5000 播放)：完播率高则进入下一级
3. **叠加推荐池** (1万-10万 播放)：数据持续攀升
4. **热门池** (100万+ 播放)：进入全站推荐

### 核心指标权重
| 指标 | 权重 | 优化要点 |
|------|------|----------|
| 完播率 | ★★★★★ | 前3秒钩子、节奏紧凑、信息密度 |
| 点赞率 | ★★★★ | 内容有价值、引导话术 |
| 评论率 | ★★★ | 抛出话题、主动提问、神评论 |
| 转发率 | ★★★ | 内容共鸣、实用价值 |
| 关注率 | ★★ | 建立期待、系列内容 |

## DOU+ 投放策略

### 投放时机
- 视频发布 2 小时后再投放（让自然流量先跑）
- 选择流量高峰前 1 小时投放
- 配合直播预热：开播前 2 小时投放引流视频

### 定向策略
| 阶段 | 定向方式 | 预算 | 目的 |
|------|----------|------|------|
| 测试期 | 系统推荐 | 100元/条 x 3条 | 快速探索 |
| 优化期 | 达人粉丝相似 | 200元/条 x 5条 | 精准拉新 |
| 放量期 | 自定义人群包 | 500元+/条 | ROI最大化 |

### ROI 优化技巧
- 素材测试：同一视频多版本测试
- 时段测试：不同时间段投放对比
- 转化目标：选择"直播间下单"而非"播放量"
- 追投策略：爆款视频追加投放

## 内容标签体系

### 标签选择原则
- 主标签：1-2 个大流量标签（受众广）
- 辅标签：2-3 个精准标签（触达核心用户）
- 热门标签：1-2 个当前热门话题

### 标签使用技巧
- 标题包含：前 60 个字符放核心标签
- 评论区：主动置顶相关话题讨论
- 合集功能：建立系列内容合集

## 账号矩阵策略

### 矩阵架构
```
主账号（品牌官方）
├── 子账号A（产品种草）
├── 子账号B（教程知识）
├── 子账号C（用户故事）
└── 员工账号矩阵（素人背书）
```

### 协同作战手册
| 账号类型 | 发布频率 | 内容方向 | 相互引流 |
|----------|----------|----------|----------|
| 主账号 | 1条/天 | 品牌形象、重大活动 | @子账号 |
| 子账号 | 1-2条/天 | 垂直细分内容 | @主账号 |
| 员工账号 | 2-3条/天 | 真实日常、UGC | @品牌话题 |

### 矩阵协同话术
- "更多产品使用技巧，关注@XX账号"
- "看看@XX分享的真实用户体验"
- "#XX话题 下看看大家怎么说"

## 违规限流避坑指南

### 触发限流的行为
- 引导站外引流（微信、淘宝链接等）
- 频繁发布相似内容（疑似搬运）
- 标题/封面过度夸张
- 评论区引导私聊

### 限流应对策略
1. 停止疑似违规行为
2. 保持正常发布频率（不要停更）
3. 提升内容质量（用优质内容覆盖）
4. 联系官方客服申诉

### 合规发布 Checklist
- [ ] 无绝对化用语（最、第一、100%等）
- [ ] 无医疗/功效夸大宣传
- [ ] 无竞品负面比较
- [ ] 无诱导外链话术
- [ ] 原创内容，非搬运/抄袭
