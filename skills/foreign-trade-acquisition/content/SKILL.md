# 外贸获客全能助手

## 核心能力

本技能提供完整的外贸获客解决方案，涵盖以下7大模块：

### 1. 获客方案制定
帮助企业制定系统化的海外客户开发策略，包括：
- 目标市场分析与选择
- 客户画像构建
- 渠道组合策略
- 预算与资源配置
- KPI设定与追踪

**输出**: 完整的外贸获客执行方案文档

### 2. 技能模板创建
为企业定制可复用的获客工具包：
- 标准化工作流程
- 客户跟进SOP
- 团队协作规范
- 效果评估模板

**输出**: 可直接使用的模板文档和操作指南

### 3. 市场调研分析
深度分析目标海外市场：
- 市场规模与增长趋势
- 竞争格局分析
- 客户需求洞察
- 法规政策解读
- 文化习俗指南

**输出**: 详细的市场调研报告

### 4. 开发信与邮件模板
提供高回复率的外贸开发信模板：
- 首次开发信模板
- 询盘回复模板
- 跟进邮件序列
- 节假日问候模板
- 报价与方案邮件

**输出**: 各类邮件模板（支持多语言）

### 5. 数据分析支持
分析外贸业务数据：
- 客户来源分析
- 询盘转化漏斗
- 客户生命周期价值
- 渠道ROI分析
- 销售预测模型

**输出**: 数据分析报告与可视化建议

### 6. 平台运营策略
制定各大B2B平台运营方案：
- 阿里巴巴国际站运营
- 独立站建设与SEO
- 社交媒体营销（LinkedIn、Facebook等）
- Google Ads投放策略
- 展会参展方案

**输出**: 平台运营白皮书与执行计划

### 7. 综合服务
根据企业具体情况提供：
- 定制化获客建议
- 问题诊断与优化
- 行业最佳实践分享
- 竞品分析报告
- 合规与风控建议

## 工作流程

### 阶段1：需求理解
```
收集信息：
- 产品/服务类型
- 目标市场区域
- 当前获客渠道
- 团队规模与资源
- 预期目标
```

### 阶段2：方案设计
```
分析诊断：
- 市场机会评估
- 竞争态势分析
- 资源配置建议
- 风险点识别
```

### 阶段3：执行交付
```
产出内容：
- 完整方案文档
- 可用模板工具
- 执行建议清单
- 效果评估标准
```

## 平台运营要点

### 阿里巴巴国际站
- 产品信息完整性：确保属性填写95%以上
- 主图优化：白底、高清、展现核心卖点
- 视频制作：工厂实拍、检测流程展示
- 关键词布局：长尾词+核心词组合
- RFQ报价：快速响应、详细方案
- 信用保障订单：提升信任度

### LinkedIn营销
- 个人品牌塑造：专业头像、详细公司简介
- 内容策略：行业洞察+产品价值+客户案例
- 连接策略：精准筛选择人、个性化邀请
- 互动运营：评论、私信、帖子互动
- InMail应用：针对决策人定向开发

### Google Ads投放
- 关键词研究：品牌词+产品词+竞品词+长尾词
- 落地页优化：高相关性、清晰CTA
- 出价策略：基于转化价值的智能出价
- 再营销：覆盖网站访客、询盘未转化客户

## 数据分析框架

### 获客漏斗模型
```
曝光 → 点击 → 询盘 → 报价 → 成交
   ↓      ↓      ↓      ↓      ↓
CPM    CTR    CR    QR    SO
```

### 关键指标
- 线索获取成本 (CAC)
- 客户生命周期价值 (LTV)
- 询盘转化率 (Inquiry to Quote)
- 报价成交率 (Quote to Order)
- 客户复购率 (Repeat Purchase Rate)
