# 外贸数据分析模板

## 第一部分：数据收集与整理

### 1.1 核心数据指标

#### 获客漏斗指标
```
┌─────────────────────────────────────────────────────────────┐
│                     外贸获客漏斗模型                          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  曝光量    ──→  点击量    ──→  询盘量    ──→  报价量    ──→  成交量    │
│  (Impr)        (Click)       (Inquiry)     (Quote)       (Order)     │
│     │              │              │              │             │
│     ↓              ↓              ↓              ↓             ↓             │
│  10000        500         50          30           5           │
│               ↓           ↓            ↓           ↓             │
│            CTR:5%      CR:10%      QR:60%      SO:16.7%          │
│                                                             │
└─────────────────────────────────────────────────────────────┘

各阶段转化率计算：
├── 点击率(CTR) = 点击量 / 曝光量 × 100%
├── 询盘转化率(CR) = 询盘量 / 点击量 × 100%
├── 报价率(QR) = 报价量 / 询盘量 × 100%
├── 成交率(SO) = 成交量 / 报价量 × 100%
└── 总体转化率 = 成交量 / 曝光量 × 100%
```

#### 关键绩效指标(KPI)
| 指标 | 定义 | 计算公式 | 目标值 |
|-----|------|---------|-------|
| CAC | 客户获取成本 | 总营销成本 / 新客户数 | ${{cac_target}} |
| LTV | 客户生命周期价值 | 平均订单额 × 年均订单数 × 客户生命周期 | ${{ltv_target}} |
| LTV/CAC | 价值比率 | LTV / CAC | >3 |
| ROI | 投资回报率 | (收入-成本) / 成本 × 100% | >{{roi_target}}% |
| 询盘响应时间 | 从收到询盘到首次回复的时间 | 平均响应时间 | <2小时 |
| 报价周期 | 从询盘到报价的时间 | 平均报价时间 | <24小时 |
