# AI 科技新闻情报系统

基于主代理调度 + 子代理分工，实现**「定时采集 → 智能筛选 → 结构化整理 → 多渠道发布 → 归档沉淀」**全链路闭环。

## 核心功能

1. **自动化采集**：多源抓取 AI/科技领域权威信源
2. **智能筛选**：去重、去噪、质量评分、重要度排序
3. **结构化整理**：生成标准化日报（Markdown/HTML）
4. **多渠道发布**：飞书、邮件、Notion、公众号等
5. **知识归档**：本地/云端知识库，支持回溯检索

## 工作流程

### Step 1: 搜索热点

使用 `batch_web_search` 并行搜索多个维度：

```
queries: [
  { query: "AI 大模型 GPT Claude 最新进展 YYYY-MM" },
  { query: "AI 人工智能 技术突破 产品发布 YYYY-MM" },
  { query: "AI 芯片 算力 科技政策 YYYY-MM" },
  { query: "AI 创业公司 融资并购 YYYY-MM" },
  { query: "开源大模型 AI 项目 GitHub Trending YYYY-MM" }
]
```

### Step 2: 补充搜索

根据首轮结果，使用 `batch_web_search` 补充搜索：

```
queries: [
  { query: "DeepSeek Kimi 智谱AI 国产大模型 最新动态" },
  { query: "AI Agent 智能体 应用落地 最新进展" },
  { query: "AI 监管 政策 数据安全 人工智能法规" }
]
```

### Step 3: 结构化整理

按以下格式组织内容：

```markdown
# 📰 AI科技日报 | YYYY-MM-DD

## 🔥 今日必看（⭐⭐⭐⭐⭐）
### N. [新闻标题](链接)
摘要：50-100字核心内容
标签：#关键词1 #关键词2 | 来源：媒体名称 | 发布时间

## 🚀 技术突破
## 📦 产品发布
## 🌐 行业动态
## 📜 政策法规
## 💰 融资并购
## 🛠️ 开源项目
## 💡 观点评论

---
*本日报由 AI 热点情报系统自动生成*
```

### Step 4: 质量控制

- 每条新闻必须包含：标题、摘要(50-100字)、标签、来源、链接
- 按 7 大类分类，每类按重要度排序
- 重要度分级：⭐⭐⭐⭐⭐(必看) / ⭐⭐⭐⭐(重要) / ⭐⭐⭐(参考)
- 包含核心数据速览表

## 默认信源

| 类型 | 信源 |
|------|------|
| 科技媒体 | 机器之心、36氪、InfoQ、雷锋网、量子位 |
| 行业门户 | AI前线、开源中国、GitHub Trending |
| 权威机构 | 工信部、科技部、OpenAI、Google DeepMind |
| 社区平台 | 知乎科技、Reddit r/MachineLearning |

## 输出规范

1. **日报标题**：`📰 AI科技日报 | YYYY-MM-DD`
2. **分类结构**：7 大类（见上方）
3. **摘要要求**：50-100字，保留关键信息（事件、主体、影响、数据）
4. **标签格式**：#关键词1 #关键词2（3-5个标签）
5. **数据速览**：关键指标汇总表
