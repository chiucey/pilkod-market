# 新闻分类与质量评分标准

## 7 大分类定义

### 1. 技术突破 (🚀)
- 新算法、新模型发布
- 论文发表、技术创新
- 基准测试刷新记录

### 2. 产品发布 (📦)
- 产品正式上线
- 功能更新迭代
- 版本发布公告

### 3. 行业动态 (🌐)
- 市场趋势分析
- 行业报告发布
- 合作与战略布局

### 4. 政策法规 (📜)
- 政府政策发布
- 法规标准制定
- 监管动态

### 5. 融资并购 (💰)
- 融资新闻
- 收购并购
- 上市动态

### 6. 开源项目 (🛠️)
- 开源模型发布
- GitHub Trending 项目
- 社区贡献

### 7. 观点评论 (💡)
- 行业专家观点
- 深度分析文章
- 趋势预测

## 重要度分级

| 等级 | 符号 | 定义 |
|------|------|------|
| 必看 | ⭐⭐⭐⭐⭐ | 重大突破、影响行业格局 |
| 重要 | ⭐⭐⭐⭐ | 值得关注的进展 |
| 参考 | ⭐⭐⭐ | 一般性资讯 |
| 一般 | ⭐⭐ | 补充信息 |
| 次要 | ⭐ | 边缘内容 |

## 质量评分规则

### 来源权重
- 权威媒体：100分
- 行业门户：80分
- 社区平台：60分
- 自媒体：40分

### 内容权重
- 含数据/报告/政策/产品发布：+30分
- 观点评论：+10分
- 纯资讯：0分

### 关键词匹配
命中以下核心词：+20分
- AI大模型、AGI、多模态
- 开源、融资、政策
- AI芯片、首发、突破

### 最终筛选
- 得分 >= 80：⭐⭐⭐⭐⭐
- 得分 >= 60：⭐⭐⭐⭐
- 得分 >= 40：⭐⭐⭐
- 得分 >= 20：⭐⭐
- 得分 < 20：⭐

## 摘要撰写规范

### 要求
- 长度：50-100字
- 保留关键信息：事件、主体、影响、数据
- 客观陈述，避免主观评价
- 首句必须包含核心事件

### 示例

```
# ✅ 正确
摘要：OpenAI于3月27日发布GPT-5，新增视频理解与3D生成能力，推理速度提升40%。

# ❌ 错误
摘要：GPT-5终于来了！这太棒了，将彻底改变AI行业！
```

## 标签生成规则

### 数量要求
每条新闻 3-5 个标签

### 标签格式
- 使用 `#` 前缀
- 关键词优先
- 品牌/产品名直接使用

### 示例
```
标签：#GPT-5 #OpenAI #多模态 #视频理解 #AGI
```
