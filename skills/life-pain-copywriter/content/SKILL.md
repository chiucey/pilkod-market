# 生活痛点文案写作框架

针对生活痛点的通俗易懂解释型文案，核心目标：让读者从"不知道"到"原来如此"再到"马上去做"。

## 七步文案框架

### 第一步：破常识 — 反常识冲击开场

**目标**：打破读者自我满足感，制造认知落差，让读者停下来

**技巧**：
- 第一句直接否定常见认知
- 使用强烈对比："你以为...？愚蠢！"
- 用夸张比喻把无害变危险

**示例结构**：
> "你以为在保护家人？实际上你在家里铺了一层微型化工厂。"

**记忆口诀**：破常识，第一棒，打破幻想醒醒脑

---

### 第二步：报家门 — 建立恐惧权威

**目标**：让恐惧有重量，从焦虑变成行动动力

**技巧**：
- 堆砌专业术语（材料名、化学名、品牌名）
- 报出具体名称而非笼统说"有毒"
- 模糊的恐惧是焦虑，具体的恐惧才是行动力

**示例结构**：
> "PVC、下水道管材、邻苯二甲酸酯、双酚A..."

**记忆口诀**：报家门，名要全，专业术语压死人

---

### 第三步：打比方 — 科学机制生活化

**目标**：让读者获得"原来如此"的顿悟感

**技巧**：
- 用生活常见场景解释科学原理
- 微观过程用可感知的动作可视化
- 公式：科学概念 = 生活中的熟悉场景

**比喻库**：
- 逃逸问题 → "海绵里的水，迟早会挤出来"
- 热效应 → "热汤加油脂=化学萃取实验"
- 材质变化 → "发黏=高分子迁移，材料在吐"
- 累积效应 → "每天喝一口毒，年底就是一瓶"

**记忆口诀**：打比方，生活化，难懂科学变家家

---

### 第四步：三秒验 — 快速验证方法

**目标**：从恐惧走向行动，给读者验证工具

**技巧**：
- 给出3个以内可操作的检测动作
- 任何人都能立刻执行
- 看、摸、闻三感检查法

**示例结构**：
> "现在拿起你家的XXX，三秒检测：一看颜色是否发黄，二摸表面是否发黏，三闻有没有异味。"

**记忆口诀**：三秒验，马上测，行动才是硬道理

---

### 第五步：唯一解 — 给出正确答案

**目标**：不制造选择困难，只给最优解

**技巧**：
- 有且只有一个正确答案
- 解释"为什么是这个"而非只说"这个好"
- 结论落到分子/结构层面才有说服力

**示例结构**：
> "认准TPU。不是因为广告，是因为它的分子结构里自带软段，根本不需要添加增塑剂。"

**记忆口诀**：唯一解，别啰嗦，分子层面最有力

---

### 第六步：狠收尾 — 情绪顶点锁定

**目标**：用反问或金句把情绪推到顶点

**技巧**：
- 用商业逻辑/价值对比做框架转换
- 用不可逆性锁死行动冲动
- 一句话让读者觉得"不行动就亏大了"

**示例结构**：
> "为了保护家具，牺牲全家人的内分泌系统——这是人类历史上最亏本的买卖。"

**记忆口诀**：狠收尾，一句话，不行动就亏到姥姥家

---

### 第七步：一口诀 — 全文总结口诀化

**目标**：让读者记住核心信息，便于传播

**技巧**：
- 用1-2句话总结全文
- 押韵或对仗增加记忆点
- 可以是行动号召或警示语

**示例结构**：
> "记住这个口诀：一看二摸三闻味，TPU才是真命柜！"
> "生活隐患处处藏，认清真相不慌张！"

**记忆口诀**：一口诀，好传播，读者记住才能帮

---

## 框架速记

```
破常识 → 报家门 → 打比方 → 三秒验 → 唯一解 → 狠收尾 → 一口诀
  1棒      2全     3化     4测     5对     6狠     7记
```

**核心口诀**：
> "破报打三唯狠记，生活真相一篇通"

## 写作检查清单

- [ ] 开场钩子够不够震撼？能否3秒内抓住注意力？
- [ ] 专业术语够不够具体？能否让恐惧有重量？
- [ ] 比喻是否生活化？读者能否在生活中找到对应？
- [ ] 验证方法是否3秒内可执行？
- [ ] 解决方案是否唯一且有科学支撑？
- [ ] 收尾金句是否让人想转发？
- [ ] 是否有朗朗上口的口诀让读者记住？

## 适用场景

| 场景 | 示例话题 |
|------|----------|
| 健康警示 | 甲醛危害、塑化剂风险、辐射防护 |
| 产品揭秘 | 材质选择、成分分析、选购指南 |
| 生活误区 | 清洁误区、存储误区、使用误区 |
| 食品安全 | 添加剂真相、烹饪陷阱、食材选择 |
| 环境健康 | 室内污染、绿色生活、环保选择 |

## 写作原则

1. **科学严谨**：比喻是手段，真相是核心，不能为了通俗而失去准确性
2. **行动导向**：读完文案，读者必须知道"我该做什么"
3. **情感共鸣**：用读者的恐惧、困惑、不便是切入点
4. **一句记住**：无论文案多长，必须有一个核心信息能被记住和传播
