## 二、AI辅助选题实战

### 2.1 热点选题裂变法

**方法论**：利用AI对热点进行多角度解读，快速生成10+差异化选题

**操作流程**：

```
Step 1: 确定核心热点
         ↓
Step 2: 输入AI指令批量生成选题角度
         ↓
Step 3: 按RIDSA标准筛选
         ↓
Step 4: 选定最优选题进行深度策划
```

**AI提示词模板**：

```
请围绕"[热点事件]"这个话题，从以下10个不同角度生成选题建议：

1. 专业科普角度：（领域知识）
2. 情感共鸣角度：（情绪价值）
3. 娱乐八卦角度：（轻松有趣）
4. 实用干货角度：（方法论输出）
5. 观点输出角度：（犀利观点）
6. 故事叙述角度：（案例故事）
7. 数据分析角度：（数据支撑）
8. 跨界联想角度：（其他领域）
9. 反常识角度：（颠覆认知）
10. 未来预判角度：（趋势预测）

每个选题请包含：
- 标题（吸引眼球）
- 切入角度（一句话说明）
- 目标受众
- 预计传播潜力（高/中/低）
```

### 2.2 竞品爆款拆解法

**方法论**：AI分析竞品爆款内容，提炼可复用的选题逻辑

**AI分析提示词**：

```
请分析以下[平台]爆款内容的选题逻辑：

爆款内容：[粘贴内容链接或摘要]

请从以下维度分析：
1. 【选题特征】选题属于什么类型？蹭热点/痛点/痒点？
2. 【受众定位】目标受众是谁？满足了什么需求？
3. 【差异化】与同类内容相比有什么独特之处？
4. 【传播性】为什么能引发传播？社交货币是什么？
5. 【可复制性】这个选题逻辑能否复制？如何复制？
6. 【改进空间】如果我来做，会有什么不同的切入角度？
```

### 2.3 系列内容矩阵法

**方法论**：从单一选题出发，AI辅助延展成系列内容矩阵

**AI提示词模板**：

```
我有一个核心选题"[主选题]"，请帮我设计一个系列内容矩阵：

1. 【旗舰内容】围绕主选题的深度内容（3000字+或10分钟+视频）
2. 【分支选题】从主选题拆分的3-5个子话题
3. 【日常选题】适合日常更新的轻量级相关选题
4. 【互动选题】能引发用户讨论的社交话题
5. 【系列钩子】能串联系列内容的线索

每个选题请说明：
- 内容形式（图文/短视频/长视频/直播）
- 预计时长/篇幅
- 与主选题的关联度
- 预计发布优先级
```

### 2.4 受众模拟法

**方法论**：AI模拟目标用户视角，发现被忽视的选题角度

**AI提示词模板**：

```
你是一个[目标用户画像]，请从你的角度思考以下话题：

话题：[待选题领域]

请回答：
1. 作为[用户]，你最想知道但目前找不到满意答案的问题是什么？
2. 现有内容中，你最讨厌的3种内容类型是什么？为什么？
3. 什么样的内容会让你"眼前一亮"并主动分享？
4. 你最信任什么样的内容创作者？为什么？
5. 如果让你来创作这个话题，你会怎么做？

基于以上分析，请提出3个"受众真正关心但没人做"的选题方向。
```

### 4.2 AI视频Prompt技巧

**场景描述要素**：
```
[主体动作/状态] + [场景环境] + [镜头运动] + [氛围光线] + [时长控制]
```

**优质Prompt示例**：

```
正面案例：
"A young woman walking through a rainy Tokyo street at night,
neon lights reflecting on wet pavement, cinematic drone shot,
following her movement, moody atmosphere, film grain"

反面案例：
"Girl walking in city"
```

```
请为以下视频脚本设计分镜：
```

## 六、AI内容合规与伦理

### 6.1 AI内容红线

**绝对禁止**：
- 伪造新闻事件、公众人物
- 生成虚假数据、学术造假
- 侵犯知识产权的复制
- 暴力、血腥、色情内容
- 政治敏感内容创作

**高风险需审核**：
- 涉及真实人物的图像
- 医疗健康效果展示
- 金融投资建议
- 品牌logo/产品外观
- 公众人物观点引用

### 6.2 AI内容标注建议

| 平台 | 标注要求 | 建议方式 |
|-----|---------|---------|
| 抖音 | 建议标注 | "内容含AI辅助创作" |
| 小红书 | 建议标注 | "#AI创作" |
| 微博 | 建议标注 | "[AI绘图]" |
| B站 | 必须标注 | 视频简介标注 |
| 微信公众号 | 建议标注 | 文末注明 |

### 6.3 AI内容质量检查清单

**发布前必查**：
- [ ] 事实核查：关键数据、信息是否准确？
- [ ] 版权检查：使用的AI素材是否合规？
- [ ] 风格检查：是否符合账号统一调性？
- [ ] 平台适配：是否符合平台规格要求？
- [ ] 敏感词检测：是否有违规内容？
- [ ] 人工润色：是否经过专业编辑优化？
