# 国内主流平台媒体投放规则参考

## 一、平台内容规范总览

### 1.1 内容红线（所有平台通用）

**绝对禁止**：
- 违反法律法规内容（分裂国家、煽动暴力、赌博等）
- 政治敏感话题（领导人负面信息、重大历史事件争议）
- 虚假信息（谣言、伪造新闻）
- 色情低俗内容
- 暴力血腥内容
- 侵犯他人权益（隐私权、肖像权、知识产权）

**高风险内容**：
- 医疗健康领域：需资质，内容需有据可查
- 金融投资领域：禁止荐股、承诺收益
- 食品保健品：功效宣传需合规
- 教育培训：不得含有虚假承诺
- 房地产：广告法特殊限制

### 1.2 广告标识要求

| 平台 | 广告标识要求 |
|-----|------------|
| 微信公众号 | 需标注"广告"字样 |
| 抖音 | 商业内容需添加"广告"标签 |
| 小红书 | 需标注"合作"或"广告" |
| B站 | 需在视频/专栏中添加广告标识 |
| 微博 | 需标注"推广"或"广告" |
| 知乎 | 需标注"利益相关"或"商业合作" |

## 二、微信公众号

### 2.1 内容规范

**推荐内容特征**：
- 原创度高，1500-3000字为宜
- 信息密度高，干货充足
- 排版精美，图文并茂
- 有明确的价值主张

**限流/封禁原因**：
- 频繁推送同一类型内容
- 标题党、夸大宣传
- 诱导关注/分享行为
- 频繁发广告
- 抄袭/洗稿

### 2.2 传播机制

**影响因素**：
- 好友在看（强关系）
- 订阅号列表（主动触达）
- 精选内容推荐（算法）
- 搜一搜流量（搜索）
-看一看推荐（算法）

**提升建议**：
- 设置"点赞"+"在看"双引导
- 引导用户加星标
- 善用专辑/话题标签
- 保持更新频率

### 2.3 变现路径

| 方式 | 要求 | 特点 |
|-----|------|-----|
| 流量主 | 500粉丝即可 | 被动收入，单价较低 |
| 软文广告 | 1万+粉丝 | 主动报价，单篇计价 |
| 知识付费 | 需IP影响力 | 高客单价 |
| 电商带货 | 需选品能力 | 佣金制 |
| IP授权 | 需强IP | 高门槛 |

## 三、抖音

### 3.1 内容规范

**算法核心指标**：
| 指标 | 权重 | 优化方向 |
|-----|------|---------|
| 完播率 | 最高 | 前3秒钩子，节奏紧凑 |
| 互动率 | 高 | 评论区运营 |
| 关注转化 | 中 | 价值承诺、系列内容 |
| 转发率 | 中 | 社交货币设计 |
| 收藏率 | 中高 | 实用价值输出 |

**限流原因自查**：
- 搬运/抄袭内容
- 频繁删除/发布
- 内容质量低（画面模糊、无主题）
- 含有敏感词
- 过度营销（联系方式、诱导购买）
- 违反社区规范

### 3.2 内容形式规范

**竖版短视频标准**：
- 分辨率：1080×1920（9:16）
- 时长：15秒-3分钟（新手建议15-60秒）
- 文件格式：MP4
- 大小：≤4GB

**字幕要求**：
- 必须有字幕（聋人友好）
- 字体清晰，不遮挡主体
- 敏感词需遮挡处理

### 3.3 话题标签策略

| 类型 | 作用 | 示例 |
|-----|------|-----|
| 泛流量标签 | 获取大流量曝光 | #抖音# #热门 |
| 垂直领域标签 | 精准人群触达 | #职场# #美妆# |
| 热点标签 | 借势流量 | #春节# #世界杯# |
| 地域标签 | 本地流量 | #北京# #成都# |
| 账号专属标签 | 强化IP | #XX的日常# |

### 3.4 抖音变现路径

| 方式 | 粉丝要求 | 特点 |
|-----|---------|-----|
| 带货橱窗 | 1000+ | 门槛低，需选品 |
| 抖音小店 | 无明确要求 | 自闭环经营 |
| 星图广告 | 10万+ | 品牌合作 |
| 直播打赏 | 无明确要求 | 需直播能力 |
| 知识付费 | 需IP影响力 | 高毛利 |

## 四、小红书

### 4.1 内容规范

**平台调性**：
- 真实感：反对过度精致/假大空
- 利他性：提供实用价值
- 颜值：图片精美，有审美
- 生活方式：与美好生活关联

**内容敏感领域**：
| 领域 | 特殊要求 |
|-----|---------|
| 医疗健康 | 需资质，不可直接推荐药品 |
| 金融理财 | 禁止荐股，可做知识科普 |
| 护肤品 | 需真人使用体验，不可夸大功效 |
| 食品 | 不可宣称保健功效 |
| 教育培训 | 不可承诺效果 |

### 4.2 传播机制

**推荐因素**：
- 收藏率（高权重）
- 点赞/评论
- 笔记质量分
- 账号权重
- 关键词匹配

**SEO优化**：
- 标题含关键词
- 正文关键词密度
- 话题标签精准
- 地点标注（本地内容）

### 4.3 封面/图片规范

| 类型 | 尺寸要求 | 设计要点 |
|-----|---------|---------|
| 单图 | 3:4（竖版） | 信息清晰，有视觉冲击 |
| 多图拼图 | 1:1或3:4 | 风格统一，信息丰富 |
| 视频封面 | 3:4 | 静态关键帧 |

### 4.4 小红书变现路径

| 方式 | 粉丝要求 | 特点 |
|-----|---------|-----|
| 品牌合作 | 5000+ | 主流变现方式 |
| 小清单带货 | 无明确要求 | 佣金制 |
| 薯店 | 无明确要求 | 自闭环 |
| 直播 | 无明确要求 | 需供应链 |

## 八、内容合规自检清单

### 8.1 敏感词检测

**常见敏感词类别**：
- 政治相关：领导人姓名、敏感事件
- 宗教相关：邪教组织、特定宗教敏感内容
- 社会事件：重大事故、群体事件
- 违法犯罪：赌博、毒品、诈骗
- 虚假宣传：绝对化用语、伪科学

**自检工具**：
- 平台自带检测
- 第三方敏感词检测工具
- 人工审核

### 8.2 广告法合规

**禁用词汇**：
- 绝对化：最佳、第一、顶级
- 虚假：无副作用、无效退款
- 违禁功效：抗癌、治疗疾病
- 权威误导：诺贝尔奖、专利等

**建议表述**：
- "深受喜爱"替代"销量第一"
- "约90%用户反馈"替代"100%有效"
- "可能有助于"替代"可以治疗"

### 8.3 知识产权合规

**内容原创要求**：
- 引用需注明来源
- 图片需有版权或授权
- 音乐/音效需商用授权
- 视频素材需合规

**洗稿判定**：
- 核心观点相同
- 表达方式高度相似
- 结构逻辑复制
