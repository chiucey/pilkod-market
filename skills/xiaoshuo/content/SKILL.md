# 专业网络小说创作技能

本技能整合白金作家、大神作家、番茄殿堂作家的写作方法论，涵盖从世界观搭建到正文创作的全流程。

## 第一章：创作启动流程

### 1.1 项目初始化

当用户提出创作小说需求时，**必须按以下顺序执行**：

1. **确认基本信息**：题材、平台、受众、核心梗
2. **创建项目文件夹**：按照规范目录结构创建所有文件夹
3. **完成设定文档**：世界观、人物、金手指等必须先于正文创作
4. **设计章纲**：每章内容、钩子、爽点必须提前规划

### 1.2 文件夹结构规范

每个小说项目必须建立以下目录结构：

```
[项目名称]/
├── 01_大纲/
│   ├── 总纲.md
│   └── 02_卷纲/

│       │   └── 章纲.md
│       └── 第二卷：xxx/
│           ├── 卷纲.md
│           └── 章纲.md
│
├── 02_世界观/
│   ├── 01_世界观总览/
│   │   └── 世界观总览.md
│   ├── 02_地理设定/
│   │   ├── 世界地图.md
│   │   └── [各地域详情].md
│   ├── 03_力量体系/

│   │   └── 修炼功法.md
```

### 1.3 命名规则

- **章命名格式**：`【第X章：章节名称】.md`
- **每10章一个文件夹**：01-10章、11-20章，以此类推
- **人物命名格式**：`[姓名].md`，按正派/反派分类
- **卷命名格式**：`第X卷：卷名/`

## 第二章：钩子系统设计

白金作家将钩子分为五个层级，每个层级有独特功能和写法。

### 2.1 五级钩子体系

| 钩子层级 | 功能定位 | 核心要素 | 放置位置 |
|---------|---------|---------|---------|
| **引流钩** | 书名和封面的第一吸引力 | 核心梗、创新点、情绪关键词 | 书名、封面 |
| **卖点钩** | 简介文案的情绪激发 | 背景设定+当前处境+冲突阻碍 | 简介、简介文案 |
| **开场钩** | 黄金三章的生死线 | 意外事件+情绪预期+核心梗直击 | 开篇前500字 |
| **主线钩** | 贯穿全文的牵引力 | 可拉扯空间+多层嵌套+答案期待 | 全文主线 |
| **章节钩** | 每章结尾的追更动力 | 话说完但不说透+情绪高点 | 每章结尾 |

### 2.2 钩子写法详解

#### 引流钩（书名）

**核心公式**：`核心梗 + 创新点 + 类型关键词`

- 参考案例：《全职高手》《斗破苍穹》《庆余年》
- 要点：书名要让人一眼看出核心卖点

#### 卖点钩（简介）

**万能公式**：`背景设定 + 当前处境 + 主线目标 + 冲突阻碍 + 卖点钩子 + 反转结局`

- 读者对反常理的、刺激的、吸引眼球的、巨大价值的、特别的人和事产生猎奇心理
- 如能符合逻辑、与读者有关或引起同情，兴趣值翻倍

#### 开场钩（黄金三章）

**核心要求**：

- 前300字：锁定主角身份
- 前500字：出现核心冲突
- 前1000字：展示金手指或特殊设定

**开场钩必须符合两个条件**：
1. 能吸引读者的意外事件
2. 结果要符合读者的情绪预期

#### 主线钩

**核心要求**：
- 紧扣核心梗，有可拉扯的空间
- 像套娃一样，收回一个还有下一个
- 没有拉扯空间的钩子，主线很难写长

#### 章节钩

**核心原则**：
- 把话说完但不要说透
- 在情绪高点断章
- 预告奖励、给读者甜头、吸引读者

**禁忌**：在不恰当的地方断章，话说一半不叫留钩子，只会送走读者

## 第三章：世界观搭建

### 3.1 世界观八系统

每个小说世界必须包含以下八个核心系统：

#### 系统一：世界观总览

```markdown
## 世界背景
- 时代特征：
- 社会结构：
- 核心规则：
- 特殊设定：
```

#### 系统二：地理设定

必须包含：
- 世界地图与各区域关系
- 每个地域的独特规则（灵气浓度、资源分布等）
- 地图递进逻辑（低维→高维的升级感）

#### 系统三：力量体系

必须定义：
- 力量等级划分（必须有清晰的等级名称和分界线）
- 力量上限与天花板
- 突破条件与代价
- 力量体系的独特性（区别于其他小说）

#### 系统四：职业体系

可选但不限于：
- 炼药师（稀缺性决定价值）
- 阵法师
- 锻造师
- 驯兽师
- 其他特殊职业

每个职业必须定义：等级划分、技能特点、稀缺程度。

#### 系统五：势力体系

必须包含：
- 势力关系图（正派/反派/中立的三方或多方博弈）
- 每个势力的核心利益和立场
- 势力之间的冲突历史

#### 系统六：资源体系

必须定义：
- 货币系统
- 天材地宝的稀缺等级
- 资源的获取难度和代价
- 资源与力量的绑定关系

#### 系统七：历史时间线

必须包含：
- 世界形成至今的重大事件
- 重要历史节点与传说
- 历史与当前剧情的关联

#### 系统八：金手指（如需要）

必须详细定义：
- 金手指的来源（系统、老爷爷、穿越福利等）
- 金手指的能力边界（必须有限制，否则爽感消失）
- 金手指的成长性
- 金手指与主线的绑定关系

### 3.2 世界观一致性原则

**铁律**：设定一旦确定就不能随意改变

- 宗门等级制度确定后不能乱
- 力量上限确定后不能随意突破
- 人物能力确定后不能随意增减
- 如需改变，必须通过剧情合理化

## 第四章：人物体系设计

### 4.1 人物档案核心字段

每个重要人物必须创建独立文档，包含以下字段：

```markdown
# 人物档案：[姓名]

## 基础信息
- 性别：
- 年龄：
- 阵营：正派/反派/中立
- 身份/职位：

## 外在呈现
- 外貌特征：
- 语言风格：（口语化，符合人设）
- 行为习惯：
- 标志性动作/口头禅：

## 内在逻辑
- 性格类型：
- 核心性格：
- 性格成因/背景故事：
- 心理创伤（如果有）：
- 核心欲望：
- 最大恐惧：

## 能力设定
- 战斗能力等级：
- 特殊能力/技能：
- 金手指/外挂（如果有）：
- 能力上限：

## 关系网络
- 家人：
- 朋友/盟友：
- 爱人/暧昧对象：
- 敌人/仇人：
- 与主角的关系：

## 人物弧光
- 初始状态：
- 触发事件：
- 转变过程：
- 最终状态：

## 写作注意事项
- 人设一致性提醒：
- 避免的行为/言辞：
```

### 4.2 人物立体化原则

**核心目标**：让Agent知道这个人怎么写

- 不要写"他很冷酷"，要写"他在什么情况下会冷酷，面对谁时会软化"
- 不要写"她很聪明"，要写"她用什么方式展现聪明，思维模式是什么"
- 每个人物必须有独特的行为逻辑，不能千人一面

### 4.3 人设一致性原则

**铁律**：避免"前一秒是个霸主，后一秒变成王八"的情况

- 性格一旦确定，所有行为必须符合性格
- 语言风格必须统一（不同人物有不同说话方式）
- 能力边界必须清晰（不能今天还会飞，明天就忘了）
- 所有修改必须记录在人物档案的"写作注意事项"中

## 第五章：钩子回填管理

### 5.1 伏笔类型分类

| 伏笔类型 | 读者感知 | 回填时机 | 写法要点 |
|---------|---------|---------|---------|
| **明线伏笔** | 读者能察觉 | 中期回填 | 埋得浅，容易发现 |
| **暗线伏笔** | 回头才能发现 | 全文结尾 | 埋得深，表面无关 |
| **情感伏笔** | 情绪释放前预埋 | 即时/中期 | 提前铺垫情绪 |

### 5.2 回填时机把控

| 回填类型 | 埋设到回填的章节距离 | 使用场景 |
|---------|---------------------|---------|
| **即时回填** | 3-5章内 | 章节内的小伏笔 |
| **中期回填** | 30-50章 | 重要情节伏笔 |
| **长期回填** | 全文核心谜题 | 主线相关的大伏笔 |

### 5.3 钩子管理系统

每次埋设伏笔时必须：

1. 在总纲或卷纲中记录伏笔位置和预期回填位置
2. 标记伏笔类型（明线/暗线/情感）
3. 在正文对应位置做标记（如`<!-- 伏笔：xxx，回填点：第X章 -->`）
4. 回填时检查是否与新情节冲突

### 5.4 回填与新钩子的衔接

- 回填一个旧钩子时，同时埋下2-3个新钩子
- 保持"钩子储备量"始终充足
- 重要情节的回填要设计情绪释放点（爽点/泪点）

## 第六章：AI去味与毒点规避

### 6.1 语言层面的AI味识别与规避

| AI味特征 | 具体表现 | 规避方法 |
|---------|---------|---------|
| 形容词堆砌 | 大量"璀璨的"、"绚丽的"、"精致的" | 用具体细节替代，用动词和名词构建画面 |
| 成语滥用 | 频繁出现四字成语，尤其是书面化 | 口语化表达，必要时才用成语 |
| 过度修辞 | 比喻夸张、拟人过度 | 简洁直接，符合人物语言习惯 |
| 句式工整 | 刻意对仗、排比 | 句式长短交错，符合口语节奏 |
| 情感词直接描述 | "他感到悲伤"、"她非常高兴" | 通过动作、表情、环境来展示情绪 |

### 6.2 结构层面的出戏问题

#### 上下文一致性

**必须规避**：
- 人设崩塌：前一章冷酷，后一章婆婆妈妈
- 世界观矛盾：设定前后不一致
- 细节矛盾：人物外貌、配角名字、势力关系前后不符
- 时间线混乱：逻辑错误

**解决方法**：
- 建立人物追踪表
- 建立设定对照表
- 写完章节后检查一致性

#### 叙事节奏问题

**必须规避**：
- 开篇延迟：前500字还不进入主题
- 聊天水字数：大段大段对话，缺乏场景描写
- 事件推进慢：没有冲突、没有目标
- 无效场景：对剧情毫无推进

**核心原则**：
- 每个场景开始时，用2-3句话快速建立时间、地点、氛围
- 对话要推动剧情或展示人物，不是为了凑字数
- 对话过长时要插入动作、心理、场景描写来打断
- 每章要有情绪起伏，找到情绪高点作为章节结尾

### 6.3 毒点清单

**人物毒点**：
- 圣母、舔狗、智商下线
- 主角被动、不反击、过度忍让

**情节毒点**：
- 过度压抑（压抑到读者弃书）
- 女主/重要角色被欺负（读者接受不了）
- 主角一直被打脸没有反转

**文笔毒点**：
- 过度描写（环境、心理、动作过度堆砌）
- 无意义堆砌（凑字数）
- 大量使用书面语、成语

**节奏毒点**：
- 灌水（重复内容）
- 平淡（无冲突）
- 卡在冲突点（该爆发不爆发）

## 第七章：大纲与章纲管理

### 7.1 大纲层级设计

```
总纲
├── 主线：故事的核心脉络
├── 核心冲突：贯穿全文的主要矛盾
├── 结局走向：最终要达到的目标
│
卷纲（每卷）
├── 本卷核心事件
├── 本卷情绪目标（热血/感动/紧张等）
├── 本卷出场人物
├── 本卷钩子埋设点
│
章纲（每章）
├── 本章核心情节
├── 本章情绪目标
├── 本章钩子（开场钩/章节钩）
└── 本章爽点设计
```

### 7.2 章纲锁定原则

**铁律**：已写了的章纲不能改变

- 一旦开始写该章，章纲即锁定
- 如需修正，只能通过后续章节补充，不能修改已写内容
- 总纲和卷纲可以调整，但必须标注变更原因和影响范围
- 调整时必须检查是否影响已发布的章节

### 7.3 章纲模板

```markdown
# 第X章：章节名称

## 核心情节
[本章要发生什么事]

## 情绪目标
[本章要调动什么情绪：爽/燃/感动/紧张]

## 钩子设计
- 开场钩：[本章开头的钩子]
- 章节钩：[本章结尾的钩子]

## 爽点设计
[本章的爽点是什么，如何铺垫和爆发]

## 伏笔记录
- 本章埋设的伏笔：[记录]
- 需要回填的伏笔：[记录]

## 人物出场
- 主要人物：
- 次要人物：

## 写作注意事项
- 本章重点：
- 需要规避：
```

## 第八章：写作执行规范

### 8.1 开篇黄金三章法则

1. **300字内**：锁定主角身份
2. **500字内**：出现核心冲突
3. **1000字内**：展示金手指或特殊设定

**开篇公式**：`主角 + 困境 + 金手指 + 冲突预告`

### 8.2 正文节奏把控

- 每章至少一个小高潮（冲突/反转/爽点之一）
- 每3-5章一个大高潮（重要战斗/重要揭示/重要收获）
- 章与章之间要有钩子衔接，不能断档
- 情绪要有起伏，不能从开头平到结尾

### 8.3 对话写作规范

- 对话要符合人物性格和身份（农民不说文人话）
- 对话要推动剧情，不是闲聊
- 对话中插入动作、表情、场景描写
- 控制对话长度，避免大段聊天水字数

### 8.4 场景转换规范

- 每个场景要有明确目的（推进剧情/展示人物/埋设伏笔）
- 场景转换要有过渡，不能生硬跳转
- 重要场景要有氛围描写（通过感官：视觉、听觉、嗅觉等）

### 8.5 章节结尾规范

- 在情绪高点断章
- 给读者期待感（预告下文/留下悬念）
- 不要在不恰当的地方断章（话说一半）
- 把话说完但不要说透

## 第九章：类型化写作模板（参考）

### 9.1 玄幻/修仙类

**核心元素**：
- 力量体系：等级划分清晰
- 升级快感：每一级都有明确收益
- 宗门恩怨：势力冲突
- 天材地宝：稀缺资源争夺
- 飞升轮回：终极目标

**常见模板**：
- 凡人流：资质低下但有奇遇
- 洪荒流：神话人物和法宝
- 穿越流：现代知识或系统金手指

### 9.2 都市类

**核心元素**：
- 重生逆袭：利用前世记忆
- 继承系统：遗产、能力、地位
- 豪门恩怨：家族博弈
- 商战崛起：从零到巅峰

**常见模板**：
- 重生文：预知未来，改变命运
- 继承文：遗产、系统、身份
- 创业文：商业帝国崛起

### 9.3 历史类

**核心元素**：
- 乱世争雄：群雄并起
- 权谋博弈：智斗、朝堂
- 文化穿越：现代知识古代应用

**常见模板**：
- 穿越历史：利用现代知识
- 架空历史：全新世界观
- 抗战/军事：家国情怀

### 9.4 仙侠类

**核心元素**：
- 修真体系：修炼飞升
- 门派恩怨：正邪之争
- 剑道/丹道：专业技能
- 凡人流：资质与奇遇

### 9.5 言情类

**核心元素**：
- 甜宠：甜蜜互动，撒糖不断
- 虐恋：误会、分离、重逢
- 双向奔赴：共同成长

### 9.6 悬疑类

**核心元素**：
- 案件推进：核心谜题
- 层层剥茧：逐步揭示
- 最终反转：意想不到的真相

## 第十章：创作检查清单

### 每次创作前检查

- [ ] 世界观设定是否完整？
- [ ] 人物档案是否齐全？
- [ ] 力量体系/职业体系是否清晰？
- [ ] 钩子是否设计到位？
- [ ] 金手指限制是否明确？

### 每次章节完成后检查

- [ ] 是否有人设崩塌？
- [ ] 是否有设定矛盾？
- [ ] 是否有AI味（形容词堆砌/成语滥用）？
- [ ] 是否在情绪高点断章？
- [ ] 是否留下钩子？
- [ ] 是否有聊天水字数？
- [ ] 是否符合当前章纲？

### 每次章节发布前检查

- [ ] 一致性检查：人设、设定、细节是否前后一致
- [ ] 节奏检查：是否有冲突、是否有推进
- [ ] 毒点检查：是否规避了所有毒点
- [ ] 钩子检查：是否埋设了伏笔、是否留下了钩子
