# AI去味写作指南

本文档详细说明如何规避AI生成的文字特征，让小说更加自然、人性化。

## 一、AI味识别特征

### 1.1 语言层面的AI味

**问题一：形容词堆砌**

AI生成的文字往往有过多的形容词，尤其是空洞的、仪式化的形容词：

```markdown
# AI味示例（错误）
他缓缓地睁开眼睛，璀璨的星光在眼眸中闪烁，精致的面容在月光下显得格外耀眼。

# 自然写法（正确）
他睁开眼，星光映在眼里。
```

**问题二：成语滥用**

过度使用四字成语会让文字显得书面化、不自然：

```markdown
# AI味示例（错误）
他义愤填膺地说道："这简直是岂有此理！"
两人剑拔弩张，场面一度陷入僵持。

# 自然写法（正确）
他气坏了："这算什么破规矩！"
两人互瞪着，谁也不让谁。
```

**问题三：过度修辞**

AI喜欢用夸张的比喻和拟人：

```markdown
# AI味示例（错误）
狂风如同一头怒吼的野兽，狠狠地扑向大地。
太阳像一个金色的圆盘，慷慨地洒下温暖的光芒。

# 自然写法（正确）
风呼呼地刮。
阳光晒得人睁不开眼。
```

**问题四：句式工整**

AI倾向于使用对仗工整的句式：

```markdown
# AI味示例（错误）
他眉头紧锁，心中充满了忧虑；她眼含泪光，脸上写满了悲伤。

# 自然写法（正确）
他皱着眉，没说话。
她眼眶红了。
```

**问题五：情感词直接描述**

AI喜欢直接告诉读者角色的情绪：

```markdown
# AI味示例（错误）
他感到非常悲伤，眼泪忍不住流了下来。
她心中大喜，兴奋地跳了起来。

# 自然写法（正确）
他低下头，眼泪掉在地上。
她一下子蹦起来，差点撞到头。
```

### 1.2 结构层面的AI味

**问题六：上下文不一致**

这是AI最常见的问题，表现为：
- 人物性格突然改变
- 世界观设定前后矛盾
- 细节错误（前一章说了A，后一章变成B）

**问题七：突然出现"第X章"字眼**

AI有时候会在文中突然提到"第X章"或"前面第X章说过"：

```markdown
# AI味示例（错误）
"正如第3章所说的那样，我必须这样做。"

# 自然写法（正确）
"我必须这样做。"
```

**问题八：长时间不进入主题**

AI喜欢在开头铺垫大量背景、环境描写：

```markdown
# AI味示例（错误）
在一个遥远的星球上，存在着一片广袤无垠的大陆。大陆上有着各种各样的种族，他们在这片土地上生存了数万年。这是一个修仙的世界，灵气浓郁，万物皆可修炼……

# 自然写法（正确）
他叫陈默，是个杂役。
今天是他进山采药的日子。
```

**问题九：大面积聊天互动水字数**

AI喜欢写大段大段的人物对话，缺乏场景描写和心理刻画：

```markdown
# AI味示例（错误）
"你好。"
"你好。"
"你是谁？"
"我是张三。"
"你来做什么？"
"我来挑战你。"
"好。"
"那就来吧。"
"好。"

# 自然写法（正确）
"你谁啊？"陈默皱了皱眉。
"挑战你的。"对方抽出剑。
陈默没说话，只是点了点头，抬手就是一拳。
```

### 1.3 内容层面的AI味

**问题十：情节套路化**

AI生成的情节往往遵循固定的套路：
- 遇到危机 → 金手指爆发 → 完美解决
- 被嘲讽 → 打脸 → 对方惊讶
- 获得宝物 → 升级 → 展示实力

**问题十一：缺乏真实感**

AI描写的人物行为缺乏真实的人性：
- 永远正确（不会犯错）
- 永远冷静（不会有情绪失控）
- 永远完美（不会有缺点）

## 二、AI去味实战技巧

### 2.1 语言层面的调整

**技巧一：少用形容词，多用动词和名词**

```markdown
# 原句（AI味）
他迈着沉重的步伐，缓缓地走向那座古老的、庄严的、散发着神秘气息的城堡。

# 修改后（自然）
他走向城堡。
```

**技巧二：口语化表达**

网络小说本身就是通俗文学，口语化没有问题：
- "璀璨的星光" → "星星很亮"
- "缓缓地" → "慢慢"
- "不由自主地" → "忍不住"

**技巧三：句式长短交错**

不要每句话都同样长度，要有长有短：

```markdown
# 修改前（平板）
他走进房间。房间很暗。他看到一个人。那人转过头。那人是他父亲。

# 修改后（节奏感）
他推开门。
房间里很暗。
一个人影靠在墙边。
那人转过头。
是父亲。
```

**技巧四：用动作和表情展示情绪**

不要直接说"他很悲伤"，要通过行为来展示：

```markdown
# 修改前（直接描述）
他感到非常悲伤，眼眶湿润了。

# 修改后（通过动作展示）
他把脸别过去，用手背蹭了蹭眼睛。
```

### 2.2 结构层面的调整

**技巧五：快速进入主题**

网文的黄金法则：前300字锁定主角，前500字出现冲突。

```markdown
# 修改前（铺垫过长）
天元大陆是一个修仙的世界。在这个世界里，灵气浓郁，万物皆可修炼。有人的地方就有江湖，有江湖的地方就有纷争……

# 修改后（快速切入）
陈默摸了摸怀里的玉佩。
这是爹留给他的唯一遗物。
今天，他要去参加宗门大选。
```

**技巧六：控制对话长度**

对话不能太长，更不能全是对话。要在对话中插入动作、表情、场景：

```markdown
# 修改前（全是对话）
"你好。"
"你好。"
"你是谁？"
"我是张三。"

# 修改后（插入描写）
"你谁啊？"陈默皱着眉。
对方没回答，只是上下打量他。
"陈默？"
"是我。"他握紧了拳头，"你又是谁？"
```

**技巧七：场景要有目的性**

每个场景必须有明确的目的：
- 推进剧情
- 展示人物
- 埋设伏笔

不能为了"凑字数"而写场景。

### 2.3 内容层面的调整

**技巧八：给人物增加缺点**

完美的主角不真实。要给主角一些缺点：
- 性格缺陷（冲动、骄傲、固执）
- 能力缺陷（某方面很弱）
- 经历缺陷（有过失败、后悔的事）

**技巧九：让情节有意外**

不要总是按照固定套路走：
- 可以让主角遭遇意外的失败
- 可以让反派有一些值得同情的地方
- 可以让配角有自己的故事

**技巧十：增加真实的生活细节**

加入一些真实的、接地气的细节：
- 饿肚子、冷热、疲惫等身体感受
- 犹豫、后悔、自责等心理活动
- 日常生活的琐碎（吃饭、睡觉等）

## 三、毒点清单与规避

### 3.1 人物毒点

| 毒点类型 | 表现 | 规避方法 |
|---------|------|---------|
| 圣母 | 原谅所有伤害过自己的人 | 给主角一个底线，触及底线必反击 |
| 舔狗 | 无条件讨好 | 主角有自己的尊严和骄傲 |
| 智商下线 | 经常犯低级错误 | 主角要聪明，至少要学习能力快 |
| 被动挨打 | 一直被打压不反抗 | 给主角反击的能力和机会 |

### 3.2 情节毒点

| 毒点类型 | 表现 | 规避方法 |
|---------|------|---------|
| 过度压抑 | 一直被打压没有反转 | 适时给主角成功的机会 |
| 女主被欺负 | 女性角色被羞辱 | 主角要保护重要的人 |
| 打脸无极限 | 一直被打脸 | 有输有赢，主角要赢得漂亮 |
| 无意义重复 | 同样的情节反复出现 | 每一次战斗/冲突要有新意 |

### 3.3 文笔毒点

| 毒点类型 | 表现 | 规避方法 |
|---------|------|---------|
| 过度描写 | 环境、心理、动作过度堆砌 | 简洁直接，删掉不必要的词 |
| 无意义堆砌 | 凑字数 | 每个场景都要有目的 |
| 书面语过多 | 成语、古风词过多 | 口语化，简洁明了 |

### 3.4 节奏毒点

| 毒点类型 | 表现 | 规避方法 |
|---------|------|---------|
| 灌水 | 重复内容 | 写之前想清楚这段话要表达什么 |
| 平淡 | 无冲突 | 每章至少要有一点冲突 |
| 卡在冲突点 | 该爆发不爆发 | 该爽的时候要爽，不要憋着 |

## 四、检查清单

### 每次创作时检查

- [ ] 形容词是否过多？（形容词改动词/名词）
- [ ] 成语是否过多？（口语化表达）
- [ ] 句式是否平板？（长短交错）
- [ ] 情绪是否直接描述？（用动作展示）
- [ ] 开篇是否拖沓？（快速进入主题）
- [ ] 对话是否过长？（插入动作/场景）
- [ ] 场景是否有目的？（推进/展示/埋伏笔）

### 每次章节完成后检查

- [ ] 有没有人设崩塌？
- [ ] 有没有设定矛盾？
- [ ] 有没有出现"第X章"字眼？
- [ ] 有没有聊天水字数？
- [ ] 有没有情绪直接描述？
- [ ] 有没有形容词堆砌？

### AI味自检问题

1. 读一遍，朗读出来，是否自然流畅？
2. 是否有过多的"的"、"地"、"得"？
3. 是否有过多的四字成语？
4. 是否句式过于工整？
5. 是否有大段对话没有动作和场景？

如果以上有任何一个问题，需要修改。

## 五、快速修改技巧

### 5.1 形容词过多

**检查词**：的、地、得
**替换方法**：删掉能删的，剩下的改成动词或名词

### 5.2 成语过多

**检查词**：四字成语
**替换方法**：用口语化表达替代

### 5.3 句式工整

**检查模式**：每句话长度相近
**替换方法**：长短交错，加一些短句

### 5.4 情绪直接描述

**检查词**：感到、觉得、认为
**替换方法**：用动作、表情、环境来展示

### 5.5 铺垫过长

**检查**：前500字是否有冲突
**替换方法**：把冲突前置，把铺垫减少

## 六、实战案例

### 案例一：开篇修改

**修改前（AI味）**：
> 在一个神秘而古老的世界里，存在着一片广袤无垠的大陆。大陆上有着各种各样的种族和势力，他们在这片土地上繁衍生息了无数年。这是一个修仙的世界，灵气浓郁，万物皆可修炼……

**修改后（自然）**：
> 陈默摸了摸怀里的玉佩。
> 这是爹留给他的唯一遗物。
> 今天，是他改变命运的日子。

### 案例二：对话修改

**修改前（AI味）**：
> "你好，我叫张三。"
> "你好，张三，我叫李四。"
> "李四，你来这里做什么？"
> "我来这里参加宗门大选。"

**修改后（自然）**：
> "你谁啊？"陈默拦住对方。
> 那人上下打量他，嘴角一挑："张三。"
> "张三？没听过。"陈默皱眉，"来干嘛的？"
> "跟你一样，宗门大选。"

### 案例三：情绪描写修改

**修改前（AI味）**：
> 他感到非常愤怒，拳头紧握，指节发白。他的心中燃烧着复仇的火焰。

**修改后（自然）**：
> 他攥紧拳头，指关节咔咔响。
> 复仇？
> 他冷笑一声。
> 那条命，他要亲手拿回来。

### 案例四：场景描写修改

**修改前（AI味）**：
> 阳光透过茂密的树叶洒下斑驳的光点，在微风的吹拂下轻轻摇曳。小溪潺潺流过，发出悦耳动听的声音。远处有鸟儿的鸣叫，一切显得那么宁静而美好。

**修改后（自然）**：
> 阳光从树叶缝里漏下来。
> 溪水哗哗地流。
> 远处传来鸟叫。
> 陈默没心思欣赏，他得赶路。

## 七、总结

**AI去味的核心原则**：

1. **简洁**：能删的字都删掉
2. **具体**：用具体的东西代替抽象的形容
3. **动作**：用动作和表情代替直接的情绪描述
4. **口语**：口语化表达，不要过于书面
5. **目的**：每个场景、每句话都要有目的

**一句话总结**：
> 写得自然，像人说话，像人做事，像人活着。
