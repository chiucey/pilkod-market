# 人物设计指南

本文档详细说明如何设计立体化的人物，让Agent知道"这个人怎么写"。

## 一、人物设计的重要性

### 1.1 人物是故事的灵魂

好的故事需要好的人物来支撑：
- 读者通过人物代入故事
- 冲突通过人物产生
- 情感通过人物传递
- 主题通过人物表达

### 1.2 网文人物的特殊性

网文人物需要：
- 有鲜明的特点（让读者记住）
- 有明确的动机（驱动剧情）
- 有合理的成长（让读者有期待）
- 有足够的冲突（让读者有看点）

### 1.3 避免人设崩塌

**核心问题**：如何避免"前一秒是个霸主，后一秒变成王八"的情况？

**解决方案**：
1. 建立完整的人物档案
2. 严格遵守性格逻辑
3. 在关键时刻检查一致性

## 三、人物类型与写法

### 3.1 主角类型

| 主角类型 | 特点 | 写法要点 | 适合题材 |
|---------|------|---------|---------|
| 废柴逆袭型 | 开局弱势，逐步变强 | 先抑后扬，爽感递进 | 玄幻、修仙 |
| 天才型 | 开局强大，持续领先 | 不断升级，应对更强挑战 | 都市、系统 |
| 普通人型 | 平平无奇，特定优势 | 依靠智慧和机遇 | 穿越、历史 |
| 多面型 | 身份复杂，多重身份 | 身份揭露的爽感 | 悬疑、仙侠 |

### 3.2 配角类型

| 配角类型 | 功能 | 写法要点 |
|---------|------|---------|
| 导师型 | 帮助主角成长 | 有实力但有限制 |
| 兄弟型 | 提供陪伴和支持 | 忠诚但有自己的故事 |
| 敌人型 | 制造冲突和挑战 | 强大且有理由 |
| 爱慕型 | 情感线的推动 | 情感描写要适度 |
| 工具型 | 提供信息或资源 | 简洁，不需要太多笔墨 |

### 3.3 反派设计

**好的反派特点**：
1. 有合理的动机（不是为了坏而坏）
2. 有强大的实力（能让主角感到压力）
3. 有独特的立场（与主角的价值冲突）
4. 有自己的故事（不只是一个工具人）

**反派类型**：

| 反派类型 | 动机 | 写法要点 |
|---------|------|---------|
| 纯粹恶人 | 享受破坏 | 极端行为，需要主角来制止 |
| 野心家 | 追求权力/地位 | 为达目的不择手段 |
| 复仇者 | 报仇雪恨 | 与主角有恩怨 |
| 理想主义者 | 坚持自己认为正确的道路 | 与主角的立场冲突 |
| 被利用的棋子 | 被他人操控 | 悲剧色彩，可同情 |

## 四、人物关系设计

### 4.1 关系类型

| 关系类型 | 特点 | 写法要点 |
|---------|------|---------|
| 亲情 | 血缘纽带 | 自然但要有冲突 |
| 友情 | 志同道合 | 共同经历是关键 |
| 爱情 | 情感吸引 | 循序渐进，水到渠成 |
| 仇恨 | 利益或情感冲突 | 冲突要有根有据 |

### 4.2 关系变化

**关系变化类型**：

1. **正向变化**：敌人→朋友、陌生人→爱人
2. **负向变化**：朋友→敌人、爱人→陌生人
3. **复杂变化**：先敌后友、先友后敌又变友

**变化逻辑**：
- 变化必须有合理的原因
- 变化必须有足够的铺垫
- 变化要给读者情感冲击

## 五、人物立体化技巧

### 5.1 细节决定人物

通过细节让人物活起来：
- 独特的口头禅
- 习惯性动作
- 特殊爱好
- 特定习惯

### 5.2 对话展示性格

对话是展示人物的重要方式：
- 不同人物说话方式不同
- 语言要符合身份和性格
- 对话要推动剧情，不是闲聊

### 5.3 行为逻辑一致

**核心原则**：性格决定行为

- 外向的人不会突然沉默
- 骄傲的人不会轻易低头
- 冷静的人不会冲动行事

如需改变，必须有足够的理由和铺垫。

### 5.4 多面性展示

真实的人物有多面性：
- 强硬的外表下可能有脆弱
- 冷酷的人可能有温情一面
- 软弱的人可能有坚持的原则

通过多面性让人物更立体。

## 六、人物与其他要素的配合

### 6.1 人物与钩子

- 每个重要人物都可以是钩子（身份之谜、关系之谜）
- 人物出场可以设置悬念
- 人物关系变化可以推动剧情

### 6.2 人物与爽点

- 主角战胜敌人是爽点
- 主角获得盟友是爽点
- 主角赢得爱情是爽点
- 主角证明自己是爽点

### 6.3 人物与世界观

- 人物是世界的组成部分
- 人物的能力要符合世界观
- 人物的关系要符合势力体系

## 七、人物写作检查清单

### 每次人物出场时检查

- [ ] 语言是否符合性格？
- [ ] 行为是否符合性格？
- [ ] 能力是否符合设定？
- [ ] 与其他人物的关系是否正确？

### 每次章节完成后检查

- [ ] 有没有人设崩塌？
- [ ] 有没有设定矛盾？
- [ ] 有没有行为不一致？

### 每次人物关系变化时检查

- [ ] 变化是否有合理的原因？
- [ ] 变化是否有足够的铺垫？
- [ ] 读者是否会认可这个变化？

## 八、常见问题

### Q1：人物太多记不住怎么办？
A：每个重要人物都要有档案。主要人物控制在10个以内，其他可以简化。

### Q2：如何让配角不沦为工具人？
A：给配角自己的故事线和动机，不要只是"为了帮助主角而存在"。

### Q3：反派如何写才不脸谱化？
A：给反派合理的动机和立场，让读者能理解（即使不认同）。

### Q4：爱情线如何写才不尴尬？
A：循序渐进，有足够的相处和情感铺垫，不要强行撒糖。

### Q5：主角的性格如何保持一致？
A：建立人物档案，写之前先看人物设定，写之后检查一致性。
