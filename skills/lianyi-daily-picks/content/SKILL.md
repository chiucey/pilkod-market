# 涟漪每日精选标的 Skill v3.0

## 核心定位

涟漪每日的"投资决策清单"。从5大市场中筛选最优买入标的，输出：25个精选标的（每板块5个）。

---

## 一、涟漪精选五步标准格式（永久规范）

### 每个板块必须5个标的，类型分配固定：

| 类型 | 数量 | 定义 |
|------|------|------|
| **类型A：退学炒股核心** | 每个板块必有1个 | 历史低位 + 近期短期大额买入 |
| **类型B：启动+叙事** | 每个板块必有1个 | 已有启动迹象 + 洗盘充分 + 前瞻叙事 + 未来半年市场契合 |
| **类型C：趋势/配置/事件** | 可选3个 | 均线多头/政策驱动/事件催化/板块轮动 |

### 五大板块（每个板块5个标的）：

| 板块 | 数量 | 涵盖范围 | 计价货币 |
|------|------|---------|---------|
| 🇺🇸 美股 | 5个 | 纳指/标普500/个股 | $（≈¥XXX）|
| 🇨🇳 A股 | 5个 | 沪深主板/科创/创业板 | ¥ |
| ₿ 币圈 | 5个 | BTC/ETH/SOL/其他主流币 | $（≈¥XXX）|
| 🛢 期货 | 5个 | 原油/天然气/铜/农产品 | ¥ |
| 🥇 贵金属 | 5个 | 黄金/白银/矿业股ETF | ¥ |

### 类型A标准（退学炒股核心·必须同时满足）：
```
✅ 价格处于近1年低位（相对ATH折让>40%）
✅ 近30日内有主力/机构大额买入记录
✅ 恐慌性杀跌日（单日-8%+）OR 底部横盘>5天
退学买点：等底部形态确认再入，不抄在最低点
```

### 类型B标准（启动+叙事·必须同时满足）：
```
✅ 已有资金布局迹象（成交量放大>30%）
✅ 从高点回落洗盘充分（回落>10%且<30%）
✅ 有清晰的1-3个月催化剂
✅ 前瞻叙事与未来6个月市场需求高度契合
退学买点：回调5-8%再入，不追高
```

---

## 二、涟漪五步选股流程

### Step 1：四维市场评估（定仓位上限）
| 四维信号 | 仓位上限 |
|---------|---------|
| 4/4强 | 75-80% |
| 3/4中 | 50-60% |
| 2/4弱 | 30-40% |
| 1/4极弱 | 10-20% |
| 0/4空 | 0% |

### Step 2：板块主线确认
有明确主线 → 做多龙头；无主线 → 休息

### Step 3：每板块5个标的筛选（类型A+B优先）

### Step 4：涟漪七问评分

| 总分 | 仓位 |
|------|------|
| 18-20分（9-10分制）| 20-25% |
| 14-17分（7-8分制）| 10-15% |
| 10-13分（5-6分制）| ≤5% |
| <10分 | 0% |

### Step 5：三步止盈（强制执行）
- 浮盈70% → 卖1/3
- 达到目标 → 再卖1/3
- 剩1/3持有到趋势逆转
