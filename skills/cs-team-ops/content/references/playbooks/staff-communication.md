# Playbook：人员沟通话术

## 适用
绩效结果沟通、批评纠偏、拒绝诉求（加班/调岗/涨薪/晋升名额）、T 转部门处理、评优落选沟通、新人融入、表扬认可、离职挽留与交接。

## 必填输入
- 沟通目的（要对方做什么 / 接受什么）
- 对方近期表现的具体数据（**没有数据就不要开这场谈话**）
- 你在这件事上的权限边界（哪些能定、哪些不能）
- 沟通后需要什么留痕

---

## 一、通用话术骨架

任何人员沟通都按这个顺序，不要跳步：

1. **给事实** — 具体行为与数据，不带评价。("本周三批标注 30 条，漏标 3 条；上周五的配置变更没有走发布记录")
2. **讲影响** — 这个事实造成了什么后果。("漏标的部分直接进了在线文本机器人，昨天下午有 2 个相关投诉")
3. **给标准** — 明确要求是什么、合格线在哪。("我们的线是单批合格率 98%")
4. **讲下一步** — 具体动作、期限、需要什么支持。("这周内把容易漏的三类过一遍，我给你一份上周的漏标清单；下周一我复核")
5. **确认理解** — "我说的这些你复述一下你的理解，确认我们是一回事。"（这是最容易省掉、也最有效的一步）
6. **落书面** — 谈完当天发确认件（沟通要点 + 约定动作 + 期限），抄送需要的人。

**禁止出现的表述**："你态度有问题""你不够细心""你不够配合""你刺头"——人格评价会让对方转入防御、停止暴露真实问题，且一旦进入书面材料就无法回收。

## 二、沟通姿态按人调整

同一件事，对不同的人换姿态。细节见 `../management-levers.md`。

| 人 | 姿态 | 特别注意 |
|---|---|---|
| W | 平等、共议、先给减负清单再谈要求 | 别只说"你再扛扛"；支援期要谈具体交接 |
| Z | 坦诚预期、讲清名额规则与时间点 | 不要口头画饼"以后转派遣" |
| S | 只谈具体行为与错例，私下沟通、给改正窗口 | 公开场合只讲标准不点名；给"达标"的明确确认 |
| T | 一对一、平等、给选择权、用数据不评价人 | 不承诺名额、不拿年龄说事、不道德绑架 |
| Q | 明确成长路径与时间点，兑现小承诺 | 现金之外给成长速度 |
| K | 先回应工作量本身，再谈质量 | 别用"这点工作量算什么"回应 |

## 三、高频场景剧本

### 场景 1：绩效结果沟通（分数低于预期）

1. 提前告知：不在结果当天第一次说。"我们找个时间过一下这个月的绩效，我周三下午有空"——给对方准备时间，也降低情绪对抗。
2. 开场不绕弯，但也不开门见山给结论：先说"我把这个月的数跟你过一遍，你看看数据对不对"。
3. 逐维度过，**先过表现好的部分**，再进入问题维度。
4. 进入问题维度时：给事实 → 给影响 → 给标准 → 给下一步和期限 → 要支持。
5. 收尾：确认理解 + 明确下期怎么算才达标（把目标变成可查的数字）。
6. 当天发确认件。

避免：把表格丢过去让人自己看；用"这次只是 0.9 不算低"来安抚（把差距说小会让人以为不用改）；留"下次注意"这种无动作的结尾。

### 场景 2：批评纠偏 / 改进期第一面（S 细致度、T 协作）

结构：事实 → 影响 → 标准 → 改进项与期限 → 支持 → 书面确认。
要点：
- **用错例不用形容词**。给 3 条具体错例 + 1 条正确示例，比说十遍"要细心"有用。
- **单次只谈一到两个问题**。一次倒五个问题，对方一个都记不住。
- **明确支持是什么**。"我给你一份已确认的标注模板""这周让 Z 带你过一遍高频错例"——只罚不扶，对方只会更消极。
- **给确认正面的部分**。"你这批返工率是 0，比上月好。问题在准确率，这个我们一起解决。"（对能力低的人，具体确认比泛泛表扬更能建立信心）
- 涉外包的改进期谈话，按 `onsite-norms.md` L4 同步外包公司。

避免：拿他和同事横向比较；公开场合说；用"大家都觉得你……"。

### 场景 3：拒绝诉求（加班 / 调岗 / 涨薪 / 晋升名额）

**核心原则：用"规则 + 可预期"替代"给承诺"。**

四步：
1. **先接住情绪和动机**——"我知道这批量确实大""你想换个方向我理解"。
2. **讲清客观限制**——不给多少给为什么。"团队奖金是全员 670 的包干，我这边能动的只有绩效系数，区间是 0.8 到 1.2"；"转派遣编制一年 1 个，按综合评估，评定时间点是 X 月，规则我发你"。
3. **给替代方案**——这是拒绝能不能被接受的关键。"量的问题我们这样处理：我把外呼的统计口径做成台账给你，你能自己看到，如果确实超了，我们按加班流程走"；"你想转的方向如果是 XX，我们下次名额评审时你是有资格的，具体条件我发你"。
4. **给时间锚点**——"这个我们下次评定时间点再看，到时候我提前跟你对一次"。

避免：含糊拖延（"再看看""以后有机会"）；把责任推给别的部门（"这是外包公司定的"）；为了安抚而承诺自己无权决定的事——**兑现不了是这个岗位最容易失信的地方**。

### 场景 4：T 提出转部门（最高风险场景）

背景：T 强势、自我、专业中高、协作弱、曾多次提出转部门、年龄较大、职级最高（1 等）但月度奖金与全员相同。

处理逻辑：**不否定动机，用规则接住诉求，用专业价值留住。**

1. **不否定动机**。"你有更好的发展我理解，也支持你想清楚自己的方向。"（对抗只会加速他离开）
2. **摆事实，不评价人**。用交付与协作的具体记录，不说"你刺头"："X 项目因为提示词变更没同步，直接影响了 Y；这个是事实，我想跟你一起把它解决掉。"
3. **给出与他个人强项挂钩的通道**。"你的专业是这个团队里最强的，大模型提示词目前也只有你能调。年度转派遣/职级晋升是 1 个名额，规则我发你，你达到什么条件就有竞争资格。"
   - **把话说透，别留幻想**：他已是外包 1 等，职级晋升这条路对他基本封了，唯一出口是转派遣。当面讲清楚"你的路径是转派遣，不是升等"——他自己心里清楚，含糊说反而显得你在敷衍。
   - 同时要说清另一件他不一定愿意面对的事：**月度奖金是全员 670，职级不带来钱差**。他对这个体系的失望，可能有一部分来自"我职位最高但拿得和最低的一样"。这话不点破，他会把转部门当成唯一出路。
4. **给时间锚点 + 书面确认**。"下次名额评审是 X 月，我们 X 月中旬对一次。"

雷区（这几条会直接加速流失或引发冲突）：
- 承诺名额、暗示"我给你留着"。
- 拿年龄说事、说"你这个年纪不好找"。
- 道德绑架："你走了我们怎么办。"
- 拿他和其他成员横向比较贬低。
- 当众或在其他成员面前谈。

### 场景 5：评优 / 晋升名额落选沟通

1. **先讲规则和得分**——"这次是按 X 规则排的，你的总分是 A，第一名是 B 分。这个规则公示过在群里。"
2. **讲差距在哪一项**——具体到维度："差在改善这一项，你提交了 1 个提案但没有落地验证；Z 提了 3 个落地了 2 个。"
3. **讲下期要达到什么**——"下个月你只要把改善这一项做到有提案落地验证，总分就能过线。"
4. **讲你会给的支撑**——"我可以做的是：给你的模块配一个可量化的目标口径，提案评审固定每周一次。"
5. **不承诺结果，只承诺过程标准。**

雷区：临时改规则；说"下次一定是你"；用"你还年轻"这类理由（把落选归因于对方无法改变的因素，最伤公平感）。

### 场景 6：表扬与认可

- **具体到行为和数字**："你这批 200 条返工 0 条，模块里第一次。"（泛泛表扬会被专业型员工识别为客套）
- **私下为主，公开为辅**。公开表扬用在团队会、复盘会，且要具体；群里的公开表扬要谨慎，S/T 都可能把公开表扬读成管理手段。
- **表扬后立刻接一个具体目标**——利用正向反馈把行为固化："下个月同样的口径做外呼那部分。"
- **对 T 的表扬要公开且基于专业**（"提示词这次改完，意图识别从 X 到 Y"）。他不吃团队式夸奖，吃可验证的专业认可。公开的专业认可同时是对其他人的示范。
- **不要跨人比较式表扬**（"你比 T 快多了"）。跨人比较会让表扬对象也被牵连。

### 场景 7：离职挽留与交接

- 先问原因，听完再判断是否可挽留。**不问原因就给条件的挽留基本无效。**
- 薪酬条件在无权限时，改为说清名额规则和下一次评定时间点。
- 无论留不留，立刻进入交接：交接清单（模块清单、关键配置位置、未结事项、文档缺口）、交接对象、交接验收标准、最后工作日。**交接标准不写清，走了之后会变成持续救火。**
- 对 T 这类掌握高杠杆单点知识的人，交接要在他在职时就推进文档沉淀，不要等提离职。

## 四、输出格式建议
- 场景判断 + 建议姿态（含针对谁）
- 可照读的话术（口语版，不是书面语；一段一段给，标出哪句是关键的）
- 预期反应与应对分支（2–3 个：接受 / 抵触 / 谈条件）
- 收尾留痕动作（确认件写什么）
- 本次沟通的雷区提醒（挑最容易犯的 1–2 条）

## 常见坑
- 谈完不留痕：口头沟通无法追溯，后续争议无据可依。
- 一次谈太多问题：超过 2 个问题，双方都记不住。
- 只讲要求不讲支持：改进类谈话的成功率取决于对方是否相信改了有用。
- 拒绝时不接情绪、直接进政策：对方会认为你在敷衍。
- 拿稀有名额当安抚工具：一次两次有效，第三次整个团队的规则一起失信。
