# 林肯报告生成技能

## 功能描述

自动生成林肯相关的分析报告，支持自定义报告维度、数据维度、输出格式。

## 使用方法

1. 在 Zeelin Claw 聊天框输入触发指令（如 `生成林肯报告`）
2. 按照提示填写报告参数
3. 等待技能自动生成完整报告

## 配置说明

- 入口文件：`lincoln_report.py`
- 配置文件：`skill.yaml`
- 依赖：Python 3.8+，相关依赖包已在 skill.yaml 中声明
