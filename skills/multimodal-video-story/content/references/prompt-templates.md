# 分镜Prompt模板库

## 镜头类型 → Prompt模式映射

### 1. 远景/全景 (Establishing Shot)
```
[时间/天气] + [地点环境] + [氛围描述] + [电影感参数]
```
**示例**：
```
A sweeping aerial view of a cyberpunk city at night in heavy rain,
neon signs reflected on wet streets, moody atmosphere, cinematic
drone shot, anamorphic lens, 2.39:1 aspect ratio, film grain
```

### 2. 中景 (Medium Shot)
```
[主体位置] + [动作描述] + [环境互动] + [光影设定]
```
**示例**：
```
A hooded figure running through a narrow alley, rain streaming down,
neon light casting dramatic shadows, shallow depth of field,
35mm lens, bokeh background, cinematic lighting
```

### 3. 特写 (Close-up / Extreme Close-up)
```
[面部/物体细节] + [情感表达] + [微表情/材质] + [焦点设定]
```
**示例**：
```
Extreme close-up of a masked face, raindrops hitting the visor,
breath visible in cold air, sharp focus on eyes, shallow DOF,
85mm portrait lens, dramatic rim lighting
```

### 4. POV镜头 (Point of View)
```
First-person perspective of [主体视角] + [所见内容] + [主观感受]
```
**示例**：
```
First-person POV running through the rain, neon lights blurring
past, breath heavy, hands gripping ledge, motion blur,
wide-angle 24mm, subjective camera shake
```

### 5. 慢动作 (Slow Motion)
```
[瞬间动作] + in slow motion + [粒子细节] + [情感强化]
```
**示例**：
```
A leap through the air in slow motion, rain droplets suspended
around the figure, cape billowing, dramatic lighting, 120fps
cinematic slow-mo, ethereal atmosphere
```

## 运镜Prompt关键词

| 运镜类型 | 英文关键词 | 适用场景 |
|---------|-----------|---------|
| 推镜头 | `push in`, `zoom in`, `dolly forward` | 聚焦紧张感、揭示细节 |
| 拉镜头 | `pull back`, `zoom out`, `dolly out` | 揭示环境、情绪释放 |
| 摇镜头 | `pan left/right`, `sweep` | 扫视场景、交代关系 |
| 跟镜头 | `tracking shot`, `follow` | 跟随移动、沉浸感 |
| 升降镜头 | `crane up/down`, `jib shot` | 气势镜头、场景揭示 |
| 环绕镜头 | `orbit`, `revolve`, `360° sweep` | 强调主体、展示全貌 |
| 手持感 | `handheld`, `cinematic shake` | 紧张、真实感 |
| 稳定器 | `gimbal smooth`, ` stabilized` | 平滑跟随、专业感 |

## 光影氛围Prompt库

```
blue and magenta neon lights, volumetric fog, rain particles
catching light, wet surfaces reflecting glow, cyberpunk aesthetic,
Blade Runner atmosphere
```

### 写实自然
```
natural daylight, soft shadows, golden hour warmth, overcast
diffused light, realistic skin tones, documentary feel
```

anamorphic lens flares, cinematic color grading, Teal & Orange palette
```

### 动漫风格

bokeh background, anime cinematography, Studio Ghibli influence
```

soft edges, classical composition, Renaissance lighting

## 画面比例参数

| 比例 | 用途 | Prompt关键词 |

| 16:9 | 电影/电视 | `16:9 aspect ratio, widescreen, cinematic` |

| 9:16 | 竖屏/短视频 | `9:16 vertical format, portrait orientation` |
