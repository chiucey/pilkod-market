# 场景坐标系模板

每个场景使用前，先建立坐标系，全集通用，不乱改。

---

## 皇宫大殿坐标系（登基大典）

```
    ┌─────────────────────────────────────────┐
    │  TOP      ← 王座（MASON固定位置）        │
    │            SELENE出发点/终点             │
    ├─────────────────────────────────────────┤
    │  MIDDLE   ← 红毯（SELENE行经路线）      │
    ├─────────────────────────────────────────┤
    │  BOTTOM   ← 近端（LIY固定站立位置）     │
    │            群众区域                      │
    └─────────────────────────────────────────┘

    LEFT SIDE  ← 群众/围观贵族
    RIGHT SIDE ← 侍卫/仆从
```

**空间约定：**
- SELENE从TOP→BOTTOM = 从王座端→群众端（走红毯）
- LILY固定在BOTTOM（红毯近端/群众前方）
- MASON固定在王座（TOP）

## 角色固定位置卡

```
【MASON】
神殿：BOTTOM CENTER（MASON躺卧）
大殿：TOP center（王座）
悬崖：TOP of frame（悬崖顶）

【SELENE】
大殿：TOP right of MASON（MASON右侧，始终伴随）
悬崖：TOP of frame（MASON身旁）

【LILY】
神殿：CENTER FRONT（祭坛前）
大殿：BOTTOM center（红毯近端）
悬崖：BOTTOM of frame（悬崖边缘）
```

---

## 场景坐标系建立步骤

Step 1：读剧本，确定场景类型（神殿/大殿/悬崖/水下/其他）
Step 2：画坐标系，标出TOP/BOTTOM/LEFT/RIGHT
Step 3：为每个角色分配固定位置
Step 4：检查每个镜头的角色位置是否在坐标系的固定位置内
Step 5：接不上的位置变化 → 加承接句说明
