# 情绪链条设计指南

每个角色的情绪必须平滑演变，不能跳跃。

---

## LILY 情绪演变链（全剧）

```
期待（anticipation）
  ↓
震惊（shock）— 初次面对打击，呆住
  ↓
恐慌（panic）— 意识到严重性，开始崩溃
  ↓
绝望（despair）— 完全无力，情绪谷底
  ↓
崩溃（collapse）— 彻底失控，爆发或麻木
  ↓
仇恨（hatred）— 坠崖瞬间转化（Shot 15）
```

**跳跃示例（错误）：**
```
震惊 → 崩溃  ❌（跳过了恐慌和绝望）
```

**正确示例：**
```
震惊（镜头6）→ 恐慌（镜头7）→ 绝望（镜头8）→ 崩溃（镜头9）  ✅
```

---

## MASON 情绪演变链（全剧）

```
冷峻权威（cold authority）— 全程基调
  ↓
冷眼旁观（cold indifference）— 看着LILY被打
  ↓
残忍（cruelty）— 宣判死刑
  ↓
冷酷无情（cold dismissiveness）— 推入深渊
```

---

## SELENE 情绪演变链（全剧）

```
得意（triumphant）— 登基大典
  ↓
轻蔑（contempt）— 经过LILY身边
  ↓
恶毒满足（venomous satisfaction）— LILY被宣判
  ↓
残忍（cruel）— 目睹推入深渊
```

## 情绪词语速查

| 情绪 | 英文 | 适用场景 |
|------|------|---------|
| 震惊 | shock, stunned | 初次打击，不敢相信 |
| 恐慌 | panic, terror | 意识到严重性 |
| 绝望 | despair, hopelessness | 完全无力 |
| 崩溃 | collapse, break down | 彻底失控 |
| 仇恨 | hatred, vengeance | 转化情绪 |
| 冷峻 | cold authority | MASON基调 |
| 轻蔑 | contempt, disdain | SELENE基调 |
| 温柔 | tender, intimate | 情感戏 |
| 恐怖 | horror | 水下/悬崖场景 |
| 悲伤 | sadness, grief | 情感低谷 |

## 情绪连贯检查

每个镜头输出时检查：

```
情绪连贯性检查：
上个镜头情绪：_______
这个镜头情绪：_______
演变是否平滑：_______
是否有跳跃：_______
```

如果情绪跳跃，在提示词中加情绪过渡描写。
