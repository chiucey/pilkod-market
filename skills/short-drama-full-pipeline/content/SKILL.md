# 短剧完整制作流程编排器

## 核心能力

作为主流程编排技能，协调故事大纲生成、人物设计、分镜头、镜头提示词、剧本审核、场景氛围等子技能，完成从创意概念到可执行短剧制作的完整流程。

## 输入参数

| 参数 | 说明 | 必填 | 默认值 |
|-----|------|------|-------|
| 题材类型 | 霸总/甜宠/虐恋/复仇等 | 是 | - |
| 剧集数量 | 总集数 | 是 | 10集 |
| 单集时长 | 分钟/集 | 是 | 2分钟 |
| 目标平台 | 抖音/快手等 | 否 | 抖音 |
| 特殊要求 | 用户额外需求 | 否 | 无 |
