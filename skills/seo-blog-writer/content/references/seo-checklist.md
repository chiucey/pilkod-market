# On-Page SEO Checklist (Detailed)

## Title Tag
- 50–60 characters ideal (Google truncates at ~60)
- Primary keyword as close to the front as possible
- Avoid clickbait — be descriptive and accurate
- Include a power word when natural: "Complete", "Ultimate", "Guide", "How to", "Best"
- Don't stuff keywords — one primary keyword per title

## Meta Description
- 150–160 characters
- Include the primary keyword naturally
- Write a value proposition: what will the reader gain?
- Include a soft CTA: "Learn how", "Discover", "Find out"
- Each page must have a unique meta description

## URL Slug
- Lowercase, hyphens (not underscores)
- Include primary keyword
- Keep it short: 3–5 words max
- Remove stop words (the, a, and, of, for...)
- Example: /b2b-content-marketing-strategy

## Heading Structure
- One H1 per page (same as title tag or close variant)
- H2s = major sections (8–12 for long-form)
- H3s = subsections under each H2
- Include primary keyword in 2–3 H2s naturally
- H2s should be descriptive and scannable (readers often only read headings)

## Content Body
- Primary keyword density: ~0.5–1.5% (don't force it)
- Primary keyword in first 100 words
- Secondary keywords: use each 1–3 times throughout
- LSI keywords: woven in naturally
- Paragraph length: 2–4 sentences max
- Use active voice predominantly
- Use transition words for readability (However, Therefore, As a result, In addition)

## Images (if applicable)
- Descriptive file names (not image001.jpg)
- Alt text includes keyword where natural
- Compress images for page speed
- Use WebP format when possible

## Internal Linking
- 2–4 internal links per article
- Use descriptive anchor text (not "click here")
- Link to relevant, high-value pages
- Avoid linking to the same page twice

## External Linking
- 2–3 outbound links to authoritative sources
- Link to primary sources (studies, official sites, data providers)
- Opens in new tab (target="_blank")
- Adds credibility and context for readers

## Content Freshness
- Include the year in titles for time-sensitive topics (e.g., "...in 2025")
- Note publication and last-updated dates
- Plan to refresh statistics and data annually

## Page Experience Signals
- Keep intro concise — answer the core question early
- Use a TL;DR or Key Takeaways box for long articles
- Table of Contents for articles with 6+ sections
- Short sentences for mobile readability
