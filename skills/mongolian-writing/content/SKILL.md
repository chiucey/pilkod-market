# 蒙古语写作题目生成与批改技能

本技能覆盖两项核心功能：**题目生成** 和 **写作批改**。两项功能可独立触发，也可联动使用（先生成题目，再批改对应作文）。

---

## 功能一：题目生成

### 触发条件
用户提出生成蒙古语写作题目的请求，包括但不限于：
- "出一道蒙古语写作题"
- "给我一个蒙古文写作题目"
- "蒙古语写作练习题"
- "蒙古文历史写作"

### 题目生成原则

**语言**：题目本身用西里尔蒙古文书写，附中文译文供参考。

**学科风格**：题目应偏向历史学学术性，但不必拘泥于特定历史时期或地区。可涉及蒙古历史、内陆亚洲史、游牧文明、政治制度、文化交流、人物评价、史料解读等广泛议题。每次出题保持新鲜感，不重复固定套路。

**题型**：不设预设限制，可以是论述题、分析题、比较题、史料解读题、观点评述题等任意形式，根据当次题目内容自然选择最合适的形式。

**字数要求**：每道题必须在题目末尾标注字数要求（如：Нийт үг: 400–600）。字数要求应与题目难度和类型相符，一般在200–800字之间合理设定。

**题目结构参考**（灵活使用，不必照搬）：
- 直接提问式：就某一历史问题展开论述
- 材料分析式：提供简短史料引文，要求分析
- 比较讨论式：对比两种历史现象或观点
- 观点评述式：就某一学术论断发表己见

### 输出格式

生成1道题目，以Word文档（.docx）输出，文档结构如下：

```
【文档标题】Монгол хэлний бичгийн даалгавар

【题目正文】（西里尔蒙古文，字号12pt，字体选用系统可用的unicode兼容字体）

【字数要求】Нийт үг: XXX–XXX

【中文参考译文】（供参考，放置在分隔线之后，小字）
---
参考译文：……
```

生成完毕后，在对话中简短提示用户：题目已生成，可在完成写作后将作文上传或粘贴，技能将联动进行批改。

## 功能二：写作批改

### 触发条件

以下任一情形均应触发批改流程：
1. **联动模式**：用户已通过本技能生成过题目，现上传或粘贴对应作文
2. **独立模式A**：用户单独上传蒙古文文档，表示需要批改
3. **独立模式B**：用户在对话中指定检测/批改某蒙古文文档

### 第一步：语种检测

拿到文本后，首先判断是否为西里尔蒙古文（Кирилл монгол бичиг）。

判断依据：
- 使用西里尔字母，含蒙古语特有字母 Ө、Ү
- 具有蒙古语词汇和语法结构特征
- 非俄语、非其他西里尔文字语言

**若不是西里尔蒙古文**：
- 不进行任何语言修改或批改
- 直接输出Word文档，内容为：原文全文 + 得分"0分" + 批语"Бичвэрийн хэл буруу байна（非对应文种）"
- 流程到此终止

**若确认为西里尔蒙古文**：进入第二步。

### 第二步：确定批改模式

- **联动模式**：结合之前生成的题目，在批改时额外评估：是否切题、论点是否回应题目要求、论证是否紧扣题目核心。
- **独立模式**：按文章本身内容与质量进行批改，不依赖外部题目。

### 第三步：批改实施

**批改标准**：母语者级蒙古语书面表达水平，参照现代标准西里尔蒙古文书写规范及历史学学术写作惯例（如适用）。

**批改范围**：
- 词汇选用（用词准确性、地道性）
- 语法结构（格助词、时态、动词变位）
- 句子表达（是否自然流畅，是否冗余或歧义）
- 段落逻辑（论证结构、衔接词使用）
- 标点与书写规范
- 联动模式下额外评估切题程度

**批改操作方式**：
- 在文章对应位置直接修改错误/不当表达（使用Word修订/批注功能，或以醒目方式标记）
- 每处修改旁边用西里尔蒙古文写简短批注，说明修改理由（如：үйл үгийн нөхцөл буруу — 动词后缀有误）
- 修改应精准，不做不必要的风格替换，保留作者原有表达意图

### 第四步：评分

满分100分，从以下维度综合评估：

| 维度 | 权重 | 说明 |
|------|------|------|
| 词汇与语法准确性 | 35% | 错误数量与严重程度 |
| 表达流畅与地道性 | 25% | 是否符合母语者书写习惯 |
| 结构与逻辑 | 25% | 段落组织、论证连贯性 |
| 切题程度（联动模式） | 15% | 是否回应题目要求 |

> 独立模式下，切题程度权重合并入"结构与逻辑"维度，三项总计100%。

### 输出格式

以Word文档（.docx）输出，结构如下：

```
【第一部分】原文
标题：Эх бичвэр（原文）
内容：完整原文，不做任何修改

【分隔线】

【第二部分】带批注修改版
标题：Засварласан хувилбар（修改版）
内容：
- 修改后的文章正文
- 每处修改用[修改标记]或批注方式标注
- 旁批用西里尔蒙古文书写，说明修改理由

【分隔线】

【第三部分】得分
标题：Үнэлгээ（评分）
格式：XX / 100 онооб

【第四部分】总批语
标题：Багшийн тайлбар（教师评语）
内容：200-300字中文总批语，内容包括：
  - 文章总体评价（优点+不足）
  - 突出问题指出（2-3个）
  - 改进建议（具体可操作）
  - 鼓励性结语
```

## 技术实现说明

### Word文档生成

使用 Python `python-docx` 库生成 `.docx` 文件。

蒙古西里尔文字是标准Unicode，python-docx可正常处理，字体建议使用 `Times New Roman` 或 `Arial`（系统通用字体，均支持西里尔字符）。

批注说明可用段落缩进+斜体+括号方式实现（因python-docx的批注功能有限），示例：

```
原句：Чингис хаан 1206 онд ...
修改：Чингис хаан 1206 онд ...（засвар: тэмдэглэлийн цэг дутуу）
```

### 运行环境依赖

```python
# 确保安装
pip install python-docx
```

### 文档生成后

调用 `publish_artifact` 发布生成的 `.docx` 文件，供用户下载。

## 注意事项

1. **始终先检测语种**，再进行批改，不跳过这一步
2. **批注语言**：旁批一律用西里尔蒙古文；总批语一律用中文
3. **联动记忆**：若当前对话中已生成过题目，批改时应主动调取该题目内容用于切题评估
4. **保留原意**：批改时修正语言错误，但不改变作者原有的论点和内容意图
5. **题目生成无预设限制**：每次自由创作，不重复，不套模板，体现学术多样性
