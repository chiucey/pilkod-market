#### 2.1 通过账户余额反推平均缴费指数（固定步骤）

当用户不清楚自己的缴费系数时，使用此方法反推：

```
┌─────────────────────────────────────────────────────────────┐
│ 已知条件                                                    │
│ - 账户余额：A元                                             │
│ - 缴费总月数：N月                                           │
│ - 缴费起止年份：YYYY1 ~ YYYY2                               │
│ - 参保类型：职工社保 / 灵活就业 / 混合                       │
├─────────────────────────────────────────────────────────────┤
│ 反推公式                                                    │
│                                                             │
│ 第一步：计算实际缴费年数（考虑利息）                           │
│ 年数 = N ÷ 12                                              │
│ 利息系数 ≈ 1 + 4% × (年数 ÷ 2)  （平均存了约一半时间）        │
│                                                             │
│ 第二步：反推年均缴费本金                                     │
│ 年均缴费本金 = 账户余额 ÷ 利息系数                          │
│                                                             │
│ 第三步：反推年均缴费基数                                     │
│ 职工社保：年均缴费基数 = 年均缴费本金 ÷ 8%                  │
│ 灵活就业：年均缴费基数 = 年均缴费本金 ÷ 8%                  │
│                                                             │
│ 第四步：反推平均缴费指数                                     │
│ 平均缴费指数 = 平均缴费基数 ÷ 平均社平工资（历年）            │
└─────────────────────────────────────────────────────────────┘
```

**简化计算公式**：
```
平均缴费指数 ≈ 账户余额 ÷ (缴费月数 × 月均社平工资 × 8% × 利息系数)

其中：
- 月均社平工资 = 历年社平工资平均值（查询城市配置）
- 利息系数 ≈ 1.12 ~ 1.20（根据缴费年限调整）
```

**示例**：
```
用户信息：
- 账户余额：139,000元
- 缴费月数：147个月（约12.25年）
- 杭州，2018年开始缴费
- 混合参保：143个月职工 + 4个月灵活就业

计算：
1. 月均社平工资（2018-2024）：(7000+7300+7500+7800+8000+8200+8400)÷7 ≈ 7,743元
2. 利息系数：1 + 4% × 6 = 1.24
3. 平均缴费指数 = 139000 ÷ (147 × 7743 × 8% × 1.24)
              = 139000 ÷ 11,267
              ≈ 1.23

结论：平均缴费指数约1.2（即按社平工资的120%缴纳）
```

## 投入产出比计算（核心结论模块）

**这是用户最关心的核心问题：怎么交社保划算？**

### 一、投入计算

| 参保类型 | 个人缴费比例 | 计算公式 |
|---------|------------|---------|
| 职工社保 | 8% | 缴费基数 × 8% × 月数 |
| 灵活就业 | 20% | 缴费基数 × 20% × 月数 |

**总投入计算**（考虑资金时间价值）：
```
总投入 = Σ(历年缴费金额 ÷ (1 + 通胀率)^缴费年份)

简化公式（按复利计算）：
总投入 = 月均缴费 × 缴费月数 × (1 + 通胀率)^(平均存年数)
```

### 二、产出计算

```
退休后月养老金 = 基础养老金 + 个人账户养老金

总产出 = Σ(月养老金 × 12 × (1 + 养老金年涨幅)^(退休后年数)) × 折现系数

其中：
- 养老金年涨幅：默认3%（历史惯例）
- 折现系数 = 1 / (1 + 通胀率)^n
- 预期领取年限：约20~25年（根据退休年龄和预期寿命）
```

### 三、核心指标

| 指标 | 计算公式 | 说明 | 评判标准 |
|------|---------|------|---------|
| **回本年限** | 总投入 ÷ (月养老金 × 12) | 领回本金需要几年 | <10年优秀，<15年良好 |
| **投入产出比** | 总产出 ÷ 总投入 | 每投入1元能领回多少 | >1.5优秀，>1.2良好 |
| **年化收益率** | IRR（内部收益率） | 相当于年化多少收益 | >5%优秀，>3%良好 |
| **实际收益率** | (总领取 - 总投入) ÷ 总投入 | 扣除通胀后的收益 | >0则不亏 |

### 五、边际效益分析（关键：多交是否划算？）

**1. 多交1年（延长缴费年限）**

| 指标 | 影响 | 量化值 |
|------|------|-------|
| 基础养老金 | 每多1年增加1%基础养老金 | 约+50~100元/月 |
| 个人账户 | 多12个月缴费积累 | 约+5,000~8,000元 |
| 领取时间 | 少领1年（如果其他条件不变） | -12个月 |
| **净收益** | 基础养老金增加超过个人账户损失 | **划算** |

**2. 多交1个档次（提高缴费指数）**

| 指数变化 | 投入增加 | 养老金增加 | 边际收益率 |
|---------|---------|-----------|-----------|
| 0.6 → 1.0 | +66% | +约40% | 约5%~8% |
| 1.0 → 1.5 | +50% | +约25% | 约3%~5% |
| 1.5 → 2.0 | +33% | +约17% | 约2%~4% |

**结论**：缴费指数越低，边际收益越高；低档缴纳"性价比"更高。

**3. 晚退休1年（延迟退休）**

| 指标 | 影响 | 量化值 |
|------|------|-------|
| 社平工资 | 晚退休1年，社平↑5% | 基础养老金↑约5% |
| 计发月数 | 60岁→61岁 | 个人账户↓约5% |
| 账户积累 | 多缴1年，多存1年利息 | +约1年缴费 + 利息 |
| **净收益** | 社平增长收益 > 计发月数损失 | **划算** |

### 六、什么情况下划算？（结论汇总）

```
┌─────────────────────────────────────────────────────────────┐
│ ✅ 划算的情况                                                 │
├─────────────────────────────────────────────────────────────┤
│ 1. 缴费年限长（>20年）：基础养老金累积效应显著                  │
│ 2. 缴费指数低（0.6~1.0）：边际收益率高                         │
│ 3. 退休晚：社平工资增长覆盖计发月数损失                        │
│ 4. 预期寿命长：领的时间越长越划算                              │
│ 5. 职工社保（有单位补贴）：实际投入少，收益高                   │
├─────────────────────────────────────────────────────────────┤
│ ❌ 不划算的情况                                                │
├─────────────────────────────────────────────────────────────┤
│ 1. 缴费指数过高（>2.0）：边际收益率低                          │
│ 2. 提前退休：社平工资未充分增长                               │
│ 3. 预期寿命短：领的时间不够回本                               │
│ 4. 灵活就业高基数：20%全自付，性价比低                         │
└─────────────────────────────────────────────────────────────┘
```

### 七、灵活就业 vs 职工社保对比

| 对比项 | 职工社保 | 灵活就业 |
|--------|---------|---------|
| 个人缴费 | 8% | 20% |
| 单位缴费 | 16%+（不计入投入）| 无 |
| 进入账户比例 | 8% | 8% |
| **同样基数下账户积累** | 相同 | 相同 |
| **实际性价比** | 高（有单位补贴）| 低（全自付）|
| **建议** | 尽量通过单位参保 | 过渡方案，不宜长期 |

**灵活就业"回本"分析**：
- 灵活就业20% = 单位16% + 个人8%
- 若按职工社保算：单位部分相当于"补贴"
- 因此：灵活就业需额外支付16%的"单位部分"
- 结论：同样缴费基数，灵活就业实际投入是职工的2.5倍

## 养老金计算公式

### 基础养老金

```
基础养老金 = 社平工资 × (1 + 平均缴费指数) ÷ 2 × 缴费年限 × 1%
```

### 个人账户养老金

```
个人账户养老金 = 个人账户储存额 ÷ 计发月数
```

### 月养老金总额

```
月养老金 = 基础养老金 + 个人账户养老金
```

### 投入产出比

```
回本年限 = 总投入 ÷ (月养老金 × 12)
投入产出比 = 总领取 ÷ 总投入
```

## 缴费系数测算（核心验证模块）

**重要性**：平均缴费指数直接影响基础养老金的计算结果，必须经过精确测算和核验。

### 一、缴费系数标准

| 缴费档次 | 缴费系数 | 说明 |
|---------|---------|------|
| 60% | 0.6 | 最低缴费档次 |
| 100% | 1.0 | 社平工资缴费 |
| 150% | 1.5 | 中高档次 |
| 200% | 2.0 | 高档次 |
| 300% | 3.0 | 最高档次 |

### 二、月缴费指数计算

```
月缴费指数 = 缴费基数 ÷ 当年社平工资
```

**示例**：
- 2024年社平工资：8,400元
- 缴费基数：5,040元（60%档次）
- 月缴费指数：5040 ÷ 8400 = 0.6

### 三、平均缴费指数计算

```
平均缴费指数 = Σ(各月缴费指数 × 缴费月数) ÷ 总缴费月数
```

**完整公式**：
```
平均缴费指数 = (第1月指数 × 月数1 + 第2月指数 × 月数2 + ... + 第n月指数 × 月数n) ÷ 总月数
```

**示例**：
```
用户缴费记录：
- 2020年：月缴费指数 0.6（12个月）
- 2021年：月缴费指数 1.0（12个月）
- 2022年：月缴费指数 1.0（12个月）
- 2023年：月缴费指数 0.6（12个月）

平均缴费指数 = (0.6×12 + 1.0×12 + 1.0×12 + 0.6×12) ÷ 48
             = (7.2 + 12 + 12 + 7.2) ÷ 48
             = 38.4 ÷ 48
             = 0.8
```

### 四、从账户余额倒推缴费基数验证

当用户提供账户余额时，必须验证是否与缴费记录一致：

```
步骤1：计算历年个人缴费总额

个人缴费部分 = 缴费基数 × 8%（职工社保）或 20%（灵活就业）

示例（职工社保，月缴费基数8400元）：
- 月缴费：8400 × 8% = 672元
- 年缴费：672 × 12 = 8,064元
- 20年总额：8,064 × 20 = 161,280元
```

```
步骤2：考虑利息增长（年化约4%复利）

账户余额 = Σ(历年缴费 × (1 + 年化利率)^剩余年数)

示例：2024年账户余额核验
- 2020年缴费8640元，存了4年 → 8640 × 1.1699 ≈ 10,105元
- 2021年缴费9216元，存了3年 → 9216 × 1.1249 ≈ 10,367元
- 2022年缴费9600元，存了2年 → 9600 × 1.082 ≈ 10,387元
- 2023年缴费10080元，存了1年 → 10080 × 1.04 ≈ 10,483元
- 2024年缴费10560元，存了0年 → 10,560元
- 预计账户余额：约51,902元
```

### 五、账户余额合理性验证

**验证公式**：
```
理论账户余额 ≈ Σ(历年个人缴费本金 × 累计利息系数)

允许误差范围：±10%（考虑工资增长、利率波动）
```

**不一致处理**：
| 情况 | 可能原因 | 处理方式 |
|------|---------|---------|
| 余额偏低 | 漏缴、低基数、断缴 | 核实缴费记录，调整平均指数 |
| 余额偏高 | 补缴、利息累积、单位补贴 | 确认是否有额外资金来源 |
| 严重不符 | 记录错误或转移合并 | 建议用户查询社保系统确认 |

### 六、不同参保类型的缴费系数差异

| 参保类型 | 缴费比例 | 进入个人账户比例 | 缴费系数确定方式 |
|---------|---------|-----------------|-----------------|
| 职工社保 | 个人8% | 8%全额进入 | 单位申报基数决定 |
| 灵活就业 | 20% | 8%进入账户 | 个人选择缴费档次 |
| 城乡居民 | 100-2000元/年 | 约8%进入账户 | 固定金额，非系数 |

**灵活就业人员特别注意**：
```
灵活就业20%缴费中：
- 8%进入个人账户（= 缴费基数 × 8%）
- 12%进入统筹账户

因此，相同缴费基数下，灵活就业和职工社保的个人账户积累相同
```

### 七、平均缴费指数的精确计算流程

```
┌─────────────────────────────────────────────────────────────┐
│ 步骤1：收集各阶段缴费信息                                      │
│ ├── 起始年月、结束年月                                         │
│ ├── 各阶段缴费基数或缴费系数                                   │
│ └── 各阶段缴费月数                                            │
├─────────────────────────────────────────────────────────────┤
│ 步骤2：计算各阶段月缴费指数                                    │
│ ├── 查询历年社平工资（from references/city_policy_rules.json）  │
│ └── 月缴费指数 = 缴费基数 ÷ 当年社平工资                        │
├─────────────────────────────────────────────────────────────┤
│ 步骤3：加权计算平均缴费指数                                     │
│ └── 平均指数 = Σ(各阶段指数 × 月数) ÷ 总月数                    │
├─────────────────────────────────────────────────────────────┤
│ 步骤4：验证结果                                               │
│ ├── 检查指数范围（0.6 ~ 3.0）                                  │

└─────────────────────────────────────────────────────────────┘
```

### 八、实操案例：杭州女性1988年生账户验证

**用户信息**：
- 杭州，女，1988年5月出生
- 143个月职工社保 + 4个月灵活就业（按0.6交）
- 总共147个月（12年3个月）
- 2018年3月开始缴纳
- 账户余额13.9万

**测算过程**：

#### 第一步：计算加权平均缴费指数

```
根据用户缴费记录分析：
- 143个月职工社保：假设平均缴费系数1.0
- 4个月灵活就业：0.6

平均缴费指数 = (1.0×143 + 0.6×4) ÷ 147
             = (143 + 2.4) ÷ 147
             = 145.4 ÷ 147
             = 0.989 ≈ 1.0
```

#### 第二步：验证账户余额

```
2018年3月 ~ 2024年，约6年缴费记录

假设历年社平工资（简化计算）：
- 2018年：约7,000元/月
- 2019年：约7,300元/月
- 2020年：约7,500元/月
- 2021年：约7,800元/月
- 2022年：约8,000元/月
- 2023年：约8,200元/月
- 2024年：约8,400元/月

按平均缴费系数1.0计算（职工社保个人8%进入账户）：
- 2018年：7000×8%×12 = 6,720元
- 2019年：7300×8%×12 = 7,008元
- 2020年：7500×8%×12 = 7,200元
- 2021年：7800×8%×12 = 7,488元
- 2022年：8000×8%×12 = 7,680元
- 2023年：8200×8%×12 = 7,872元
- 2024年（按实际月份）：8400×8%×12×(12/12) = 8,064元

本金合计：约52,032元

利息累计（按4%年化复利）：
- 假设各年缴费平均存了3年
- 累计利息约：52,032 × 0.126 ≈ 6,556元

理论账户余额：52,032 + 6,556 ≈ 58,588元

用户余额13.9万 = 存在较大差异
→ 需要用户确认：是否有单位补贴、历年基数调整、补缴情况？
```

#### 第三步：修正平均缴费指数

```
如果确认用户余额正确，则倒推平均缴费指数：

假设余额13.9万，本金约9万（考虑灵活就业20%中有8%进入账户）
→ 平均缴费指数应该更高

重新估算：
- 143个月职工社保，平均指数1.1（单位按较高基数申报）
- 4个月灵活就业，指数0.6

验证：(1.1×143 + 0.6×4) ÷ 147 = 1.09

结论：用户职工社保阶段缴费基数较高，平均缴费指数约1.1
```
