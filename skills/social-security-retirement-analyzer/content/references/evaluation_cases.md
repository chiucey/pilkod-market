# 社保退休分析技能评估用例

本文档提供用于测试和评估技能表现的典型场景。每个用例包含输入、预期输出和评分标准。

## 评估用例集

### 用例1：普通男性职工退休规划

**输入**：
> "我1975年出生，北京参保，现在已经缴费20年了，账户有8万块，帮我算算退休金"

**预期输出要素**：

| 检查项 | 预期值 | 评分标准 |
|--------|--------|---------|
| 社平工资 | 12,000元/月 | ✅ 正确使用北京参数 |
| 退休年龄 | 62岁6个月 | ✅ 延迟30个月计算正确 |
| 计发月数 | 125个月 | ✅ 62岁对应 |
| 基础养老金 | 2,400元 | ✅ 12000×(1+1)/2×20×1% |
| 个人账户养老金 | 640元 | ✅ 80000÷125 |
| 月养老金 | 3,040元 | ✅ 两项相加 |

**完整报告要素**：
- [ ] 基本信息汇总（出生年份、参保地、缴费年限、账户余额）
- [ ] 退休年龄测算（含延迟计算）
- [ ] 养老金计算过程
- [ ] 至少2个方案对比
- [ ] 推荐方案及理由

**评分标准**：
- 核心参数错误：-5分/项
- 计算错误：-3分/项
- 缺少必要输出：-2分/项
- 满分：100分
- 及格：80分

### 用例2：杭州女性灵活就业退休规划

**输入**：
> "我1982年出生，女性，杭州灵活就业，2024年参保，缴费5年了，账户2.5万，怎么规划比较好？"

**预期输出要素**：

| 检查项 | 预期值 | 评分标准 |
|--------|--------|---------|
| 退休年龄 | 54岁9个月 | ✅ 延迟57个月 |
| 判断依据 | 2024年参保→有浙江记录→50岁退休 | ✅ 杭州特殊规则判断正确 |
| 计发月数 | 175个月（54岁） | ✅ |
| 社平工资 | 8,400元/月 | ✅ 使用杭州参数 |
| 医保年限 | 20年 | ✅ 杭州标准 |

**方案对比要素**：
- [ ] 方案一：缴满15年最低年限
- [ ] 方案二：缴到54岁9个月
- [ ] 方案三：灵活选择（可选）
- [ ] 各方案投入、月养老金、回本年限对比
- [ ] 明确推荐方案

**评分标准**：
- 杭州特殊规则判断错误：-20分
- 退休年龄计算错误：-10分
- 方案对比不完整：-5分/项
- 满分：100分
- 及格：80分

### 用例3：武汉女性多地缴费

**输入**：
> "我是武汉户口，女性，1980年出生，之前在武汉交了5年、杭州8年、北京7年，现在账户有9.5万，能拿多少退休金？在哪退休？"

**预期输出要素**：

| 检查项 | 预期值 | 评分标准 |
|--------|--------|---------|
| 退休地 | 武汉 | ✅ 所有地区都不满10年，转回户籍地 |
| 退休年龄 | 53岁 | ✅ 延迟36个月 |
| 计发月数 | 175个月 | ✅ |
| 社平工资 | 7,500元/月 | ✅ 使用武汉参数 |
| 平均缴费指数 | ~1.1 | ✅ 多地缴费通常较高 |

**养老金计算**：
```
基础养老金 = 7500 × (1+1.1) ÷ 2 × 20 × 1% = 1,575元
个人账户养老金 = 95000 ÷ 175 = 543元
月养老金 = 2,118元
```

**评分标准**：
- 退休地判断错误：-15分
- 多地合并计算错误：-10分
- 养老金计算错误：-5分/项
- 满分：100分
- 及格：80分

### 用例4：灵活就业vs职工社保对比

**输入**：
> "我想在杭州参保，女性1985年，交20年，灵活就业和职工社保哪个划算？"

**预期输出要素**：

| 对比维度 | 灵活就业 | 职工社保 | 说明 |
|---------|---------|---------|------|
| 月缴费 | 1,680元 | 672元 | 灵活就业全额自付 |
| 20年总投入 | 40.3万 | 16.1万 | 差额24万 |
| 养老金 | 基本相同 | 基本相同 | 取决于账户积累 |

**关键结论**：
- [ ] 职工社保更划算（投入少）
- [ ] 但职工社保需要单位配合
- [ ] 灵活就业是有效备选

**评分标准**：
- 投入计算错误：-5分
- 养老金对比缺失：-5分
- 缺少结论建议：-5分
- 满分：100分
- 及格：80分

### 用例5：多方案投入产出比分析

**输入**：
> "男性，1980年出生，上海参保，现在30岁，计划缴25年，账户预计积累30万，怎么规划最划算？"

**预期输出要素**：

| 方案 | 退休年龄 | 投入 | 月养老金 | 回本年限 | 投入产出比 |
|------|----------|------|---------|----------|-----------|
| 缴满最低年限(15年) | 63岁 | 较少 | 较低 | 短 | 较高 |
| 缴到法定退休(25年) | 63岁 | 中等 | 中等 | 中等 | 中等 |
| 缴30年 | 63岁 | 最多 | 最高 | 较长 | 较低 |

**分析要求**：
- [ ] 计算各方案投入金额
- [ ] 计算各方案月养老金
- [ ] 计算回本年限
- [ ] 分析投入产出比
- [ ] 结合用户情况给出建议

**评分标准**：
- 方案不完整：-10分/方案
- 计算错误：-5分/项
- 缺少建议：-10分
- 满分：100分
- 及格：80分

### 用例6：边界情况 - 断缴处理

|--------|---------|---------|
| 缴费年限计算 | 2015-2020(5年) + 2022至今(约3年) = 8年 | ✅ 正确处理断缴 |
| 中断影响 | 中断期间不计算年限，但可累计 | ✅ 规则说明正确 |
| 未来规划 | 需要继续缴纳至满15年 | ✅ 给出建议 |

**评分标准**：
- 年限计算错误：-10分
- 断缴规则说明错误：-5分
- 缺少规划建议：-5分
- 满分：100分
- 及格：80分
