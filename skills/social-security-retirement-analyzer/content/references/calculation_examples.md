## 示例1：普通男性职工退休规划

### 基本信息

| 项目 | 数值 |
|------|------|
| 参保地 | 北京 |
| 性别 | 男 |
| 出生年份 | 1975年 |
| 已缴费年限 | 20年（240个月） |
| 账户余额 | 80,000元 |
| 平均缴费指数 | 1.0（按社平工资缴费） |

### 计算过程

#### 第一步：确定政策参数

```
查找北京配置：
- 社平工资：12,000元/月
- 医保年限：25年
- 男性退休年龄：63岁（延迟后）
```

#### 第二步：计算延迟退休年龄

```
公式：(出生年份 - 1965) × 12 ÷ 4
= (1975 - 1965) × 12 ÷ 4
= 10 × 12 ÷ 4
= 30个月
= 2年6个月

退休年龄 = 60 + 2年6个月 = 62岁6个月
退休年份 = 1975 + 62 = 2037年
```

#### 第三步：确定计发月数

```
62岁 → 计发月数 = 125
```

#### 第四步：计算基础养老金

```
基础养老金 = 社平工资 × (1 + 平均缴费指数) ÷ 2 × 缴费年限 × 1%
= 12000 × (1 + 1.0) ÷ 2 × 20 × 1%
= 12000 × 2 ÷ 2 × 20 × 1%
= 12000 × 20 × 1%
= 2,400元/月
```

#### 第五步：计算个人账户养老金

```
个人账户养老金 = 账户余额 ÷ 计发月数
= 80000 ÷ 125
= 640元/月
```

#### 第六步：汇总月养老金

```
月养老金 = 基础养老金 + 个人账户养老金
= 2400 + 640
= 3,040元/月
```

### 方案对比

| 方案 | 描述 | 退休年份 | 投入(万) | 月养老金 | 回本年限 |
|------|------|----------|---------|---------|----------|
| 方案一 | 缴满最低年限(15年)停缴 | 2030年 | 0 | 2,200 | - |
| 方案二 | 继续缴到法定退休年龄 | 2037年 | 8 | 3,040 | 2.6年 |
| 方案三 | 再多缴5年提升养老金 | 2042年 | 18 | 3,800 | 4.7年 |

## 示例2：杭州女性灵活就业退休规划

### 基本信息

| 项目 | 数值 |
|------|------|
| 参保地 | 杭州 |
| 性别 | 女 |
| 出生年份 | 1982年 |
| 参保类型 | 灵活就业 |
| 参保时间 | 2024年（2025年前已有浙江参保记录） |
| 已缴费年限 | 5年（60个月） |
| 账户余额 | 25,000元 |
| 平均缴费指数 | 1.0 |

### 特殊规则判断

```
判断流程：
1. 2025年1月1日前是否有浙江参保记录？
   - 2024年已参保 → 有记录 → 50岁退休（延迟后）

2. 计算延迟后退休年龄：
   公式：(出生年份 - 1974) × 12 ÷ 2
   = (1982 - 1974) × 12 ÷ 2
   = 8 × 12 ÷ 2
   = 96 ÷ 2
   = 48个月
   = 4年

   退休年龄 = 50 + 4年 = 54岁9个月
```

### 计算过程

#### 确定政策参数

```
杭州配置：
- 社平工资：8,400元/月
- 医保年限：20年
- 退休年龄：54岁9个月
- 计发月数：175（54岁）
```

#### 方案设计

**方案一：缴满最低年限15年**

```
仍需缴费：15 - 5 = 10年（120个月）
退休时间：1982 + 15 = 2037年（但2037年已满54岁9个月，提前退休）

预测账户余额：
- 现有：25,000元
- 未来10年投入：8400 × 20% × 120 = 201,600元（灵活就业全额）
- 利息（按4%年化）：约40,000元
- 预计账户总额：约266,600元

基础养老金 = 8400 × (1+1) ÷ 2 × 15 × 1% = 1,260元
个人账户养老金 = 266600 ÷ 175 = 1,523元
月养老金 = 2,783元

投入（个人部分）= 8400 × 20% × 120 = 201,600元
回本年限 = 201600 ÷ (2783 × 12) = 6年
```

**方案二：缴到法定退休年龄（54岁9个月）**

```
缴费至：1982 + 54 = 2036年
总缴费年限：约29年
仍需缴费：29 - 5 = 24年（288个月）

预测账户余额：
- 现有：25,000元
- 未来24年投入：8400 × 20% × 288 = 483,840元
- 利息（按4%年化）：约250,000元
- 预计账户总额：约758,840元

基础养老金 = 8400 × (1+1) ÷ 2 × 29 × 1% = 2,436元
个人账户养老金 = 758840 ÷ 175 = 4,336元
月养老金 = 6,772元

投入 = 483,840元
回本年限 = 483840 ÷ (6772 × 12) = 6年
```

**方案三：按灵活就业缴纳25年**

```
缴费至：1982 + 25 = 2007年
总缴费年限：25年
仍需缴费：25 - 5 = 20年（240个月）

投入 = 8400 × 20% × 240 = 403,200元
预测账户：约620,000元

基础养老金 = 8400 × (1+1) ÷ 2 × 25 × 1% = 2,100元
个人账户养老金 = 620000 ÷ 175 = 3,543元
月养老金 = 5,643元

回本年限 = 403200 ÷ (5643 × 12) = 6年
```

### 方案对比表

| 方案 | 退休年份 | 总投入 | 月养老金 | 回本年限 | 评价 |
|------|----------|--------|---------|----------|------|
| 方案一 | 2037年 | 20万 | 2,783元 | 6年 | 投入最少，但养老金较低 |
| 方案二 | 2036年 | 48万 | 6,772元 | 6年 | 养老金最高，投入较大 |
| 方案三 | 2007年 | 40万 | 5,643元 | 6年 | 平衡之选 |

## 示例3：多地缴费合并计算

### 基本信息

| 项目 | 数值 |
|------|------|
| 户籍地 | 武汉 |
| 参保地经历 | 武汉5年 → 杭州8年 → 北京7年 |
| 总缴费年限 | 20年 |
| 总账户余额 | 95,000元 |
| 性别 | 女 |
| 出生年份 | 1980年 |

### 退休地判断

```
多地缴费规则：
- 武汉：5年（不满10年）
- 杭州：8年（不满10年）
- 北京：7年（不满10年）
- 所有地区都不满10年

结论：转回户籍地（武汉）退休
```

### 退休年龄计算

```
原50岁女性，1980年出生：
延迟月数 = (1980 - 1974) × 12 ÷ 2 = 6 × 6 = 36个月 = 3年
退休年龄 = 50 + 3 = 53岁
计发月数 = 175（53岁，按54岁计算）
```

### 养老金计算

```
按武汉参数：
- 社平工资：7,500元/月
- 平均缴费指数：约1.1（多地缴费通常较高）

基础养老金 = 7500 × (1+1.1) ÷ 2 × 20 × 1%
= 7500 × 2.1 ÷ 2 × 20 × 1%
= 7,875 × 20 × 1%
= 1,575元

个人账户养老金 = 95000 ÷ 175 = 543元

月养老金 = 1,575 + 543 = 2,118元
```

## 示例4：灵活就业vs职工社保对比

### 基本信息

| 项目 | 灵活就业 | 职工社保 |
|------|---------|---------|
| 缴费基数 | 8,400元 | 8,400元 |
| 月缴费额 | 1,680元 | 672元 |
| 年缴费额 | 20,160元 | 8,064元 |
| 退休地 | 杭州 | 杭州 |
| 性别 | 女 | 女 |
| 缴费年限 | 20年 | 20年 |

### 投入对比

```
20年总投入：
- 灵活就业：20160 × 20 = 403,200元
- 职工社保：8064 × 20 = 161,280元

差额：241,920元
```

### 养老金对比（假设相同账户积累）

```
账户积累（假设相同）：
- 灵活就业：60万
- 职工社保：60万

灵活就业月养老金：
- 基础：8400 × (1+1) ÷ 2 × 20 × 1% = 1,680元
- 个人：600000 ÷ 175 = 3,429元
- 合计：5,109元

职工社保月养老金：
- 基础：8400 × (1+1) ÷ 2 × 20 × 1% = 1,680元
- 个人：600000 ÷ 175 = 3,429元
- 合计：5,109元

养老金相同！但投入差24万！
```

### 结论

| 指标 | 灵活就业 | 职工社保 | 胜者 |
|------|---------|---------|------|
| 月缴费 | 1,680元 | 672元 | 职工社保 |
| 20年总投入 | 40万 | 16万 | 职工社保 |
| 月养老金 | 5,109元 | 5,109元 | 平局 |
| 回本年限 | 6.5年 | 2.6年 | 职工社保 |

**结论**：职工社保更划算，但如果无法获得职工社保，灵活就业仍是有效选择。

## 示例5：延迟退休养老金增加测算

### 基本信息

| 项目 | 数值 |
|------|------|
| 性别 | 男 |
| 出生年份 | 1970年 |
| 账户余额 | 15万 |
| 缴费年限 | 30年 |
| 平均缴费指数 | 1.2 |

### 不同退休年龄对比

#### 60岁退休（原退休年龄）

```
退休年龄：60岁
计发月数：139
社平工资（假设）：10,000元

基础养老金 = 10000 × (1+1.2) ÷ 2 × 30 × 1% = 3,300元
个人账户养老金 = 150000 ÷ 139 = 1,079元
月养老金 = 4,379元
```

#### 63岁退休（延迟后）

```
退休年龄：63岁
计发月数：117
社平工资（假设涨至）：12,000元

延迟3年增加投入：
- 账户增加：约5万（含利息）
- 账户总额：约20万

基础养老金 = 12000 × (1+1.2) ÷ 2 × 33 × 1% = 4,356元
个人账户养老金 = 200000 ÷ 117 = 1,709元
月养老金 = 6,065元
```

### 对比结果

| 指标 | 60岁退休 | 63岁退休 | 差异 |
|------|----------|----------|------|
| 月养老金 | 4,379元 | 6,065元 | +1,686元 (+38%) |
| 总领取(20年) | 105万 | 145万 | +40万 |
| 延迟投入 | - | 约10万 | - |

**结论**：延迟退休不仅增加了缴费年限，还因计发月数减少、社平工资增长，显著提升养老金水平。

## 示例6：病退提前退休计算

### 基本信息

| 项目 | 数值 |
|------|------|
| 性别 | 男 |
| 出生年份 | 1968年 |
| 特殊情况 | 因病完全丧失劳动能力 |
| 账户余额 | 80,000元 |
| 缴费年限 | 28年 |

### 退休年龄

```
病退条件：男55岁
退休年龄：55岁
计发月数：170
```

### 养老金计算

```
社平工资：10,000元
平均缴费指数：1.0

基础养老金 = 10000 × (1+1) ÷ 2 × 28 × 1% = 2,800元
个人账户养老金 = 80000 ÷ 170 = 470元
月养老金 = 3,270元
```

### 与正常退休对比

| 指标 | 病退(55岁) | 正常退休(63岁) |
|------|------------|---------------|
| 月养老金 | 3,270元 | 5,500元 |
| 差额 | - | +2,230元 |

**注意**：病退养老金较低，但可提前8年领取，需权衡。
