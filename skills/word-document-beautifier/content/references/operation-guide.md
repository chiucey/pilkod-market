# Word/WPS格式应用操作指南

## 第一部分：文档预处理

### 1.1 清除原有格式
```
选中全文（Ctrl+A）
→ 开始 → 清除格式（Word）/ 格式刷清除（WPS）
```

### 1.2 修复字体混乱
```
选中全文
→ 开始 → 字体设置
→ 选择统一的中文字体（如宋体/微软雅黑）
→ 选择统一英文字体（如Times New Roman）
```

### 1.3 修复段落间距
```
选中全文
→ 开始 → 行和段落间距
→ 选择"1.5"或固定值"28磅"
```

## 第二部分：样式库创建

### 2.1 创建标题样式（Word）
```
1. 开始 → 样式 → 新建样式
2. 样式名称：正文（根据层级命名）
3. 格式设置：
   - 字体：选择字体、字号
   - 段落：行距、段前段后间距
   - 快捷键：设置便捷快捷键
4. 格式 → 后续段落样式：选择下一级标题或正文
```

### 2.2 创建标题样式（WPS）
```
1. 菜单栏 → 格式 → 样式与格式
2. 点击"样式和格式"窗格中的"新建样式"
3. 按要求设置字体、段落格式
```

### 2.3 推荐的快捷键分配
| 样式 | 推荐快捷键 |
|------|-----------|
| 标题1 | Ctrl+Alt+1 |
| 标题2 | Ctrl+Alt+2 |
| 标题3 | Ctrl+Alt+3 |
| 正文 | Ctrl+Shift+N |

## 第三部分：全文档格式应用

### 3.1 设置页边距
```
布局 → 页边距 → 自定义边距
→ 设置上下左右边距数值
→ 应用于：整篇文档
```

### 3.2 设置页眉页脚
```
1. 插入 → 页眉 → 选择样式或编辑
2. 输入页眉内容（可包含文档标题、日期）
3. 插入 → 页脚 → 选择样式或编辑
4. 设置页码格式
```

### 3.3 标题格式刷应用
```
方法一（单个）：
选中已设置好格式的标题
→ 开始 → 格式刷
→ 点击要应用格式的标题

方法二（批量）：
选中已设置好格式的标题
→ 双击格式刷
→ 依次点击要应用格式的多个标题
→ 按Esc结束
```

### 3.4 表格格式美化
```
1. 选中表格
2. 表格工具 → 设计 → 表格样式
2. 或右键 → 表格属性
   → 边框和底纹：设置边框样式、颜色
   → 底纹：设置填充颜色
```

### 3.5 图片排版
```
1. 选中图片
2. 格式 → 自动换行
   - 嵌入式：图片与文字同行
   - 四周型：文字环绕
   - 紧密型：紧密环绕
   - 浮于文字上方/下方：用于水印
3. 格式 → 对齐 → 选择对齐方式
```

## 第四部分：最终校验

### 4.1 内容完整性校验
- 全文通读，确认无文字遗漏
- 检查表格数据是否完整
- 核对图片是否全部显示

### 4.2 格式一致性校验
- 检查标题层级是否统一
- 核对正文字体字号是否一致
- 验证段落间距是否统一

### 4.3 兼容性校验
- 另存为.doc格式确保低版本兼容
- 在不同查看器中打开测试
- 打印预览检查分页效果

### 4.4 合规性校验
- 党政公文：对照GB/T 9704-2012检查
- 法律合同：核对法律文书格式规范
- 学术论文：对照学校/期刊格式要求

## 第五部分：常见问题处理

### 5.1 格式刷失效
```
原因：复制了包含隐藏字符的内容
解决：选择性粘贴 → 仅保留文本
```

### 5.2 页眉页脚不一致
```
首页不同：布局 → 页眉页脚 → 首页不同
奇偶页不同：布局 → 页眉页脚 → 奇偶页不同
```

### 5.3 目录无法更新
```
引用 → 更新目录
或 右键目录 → 更新域
```
