# 简笔画生成技能

本技能帮助小学生快速完成简笔画作业，提供3副不同风格的简笔画供选择。

## 工作流程

### 1. 解析用户需求

当用户说"画一只小猫的简笔画"、"我要画小动物的简笔画"、"帮我画个苹果"等类似需求时，触发本技能。

**提取要素**：
- 主题对象（如：小猫、苹果、小汽车等）
- 如果用户未指定具体对象，询问用户想要画什么

### 2. 生成3副简笔画

使用 `image_synthesize` 工具，生成3副风格各异的简笔画：

**Prompt 模板**：
```
A simple line drawing for elementary school children, black and white sketch style, [主题], clean lines, easy to draw, educational worksheet, white background
```

**参数设置**：
- 每副图片使用略有不同的 prompt 变体（如添加：minimal style / cartoon style / outline only）
- 输出文件：`simple-drawing-1.png`、`simple-drawing-2.png`、`simple-drawing-3.png`

### 3. 展示与下载

1. 使用 `images_understand` 工具验证生成的图片是否符合简笔画要求
2. 向用户展示3副简笔画，标注1/2/3
3. 提示用户选择喜欢的版本，或全部下载

## 适用主题参考

| 类别 | 常见主题 |
|------|----------|
| 动物 | 小猫、小狗、小兔子、小鸟、小鱼、小乌龟、小蝴蝶 |
| 水果 | 苹果、梨、香蕉、葡萄、西瓜、草莓 |
| 植物 | 小花、小树、小草、向日葵、仙人掌 |
| 交通工具 | 小汽车、公交车、自行车、飞机、船、火车 |
| 日常用品 | 杯子、闹钟、书本、书包、帽子、鞋子 |
| 食物 | 汉堡、蛋糕、冰淇淋、披萨、热狗 |

## 注意事项

1. **风格统一**：简笔画应该线条简洁、轮廓清晰、易于模仿
2. **适龄设计**：适合6-12岁小学生绘制
3. **纯线条为主**：不使用复杂阴影和色彩
4. **留白充足**：方便打印和涂色
