# 视频口播文案智能配图工具

根据文案内容、情感脉络，智能生成多备选配图方案并下载打包。

## 核心工作流

### 第一步：深度理解文案（必须）

**分析维度**：
1. **情感结构**：识别文案的情感转折点（震惊→悲痛→愤怒→希望→升华）
2. **时间线**：标注每个情感节点在整体时长中的位置
3. **关键元素**：提取地名、建筑名、人名、技术术语、法律条款等识别度高的元素
4. **画面需求**：根据文案描述，推断画面应该呈现什么场景

**输出模板**：
```
| 时间 | 情感基调 | 关键元素 | 配图需求 |
|------|----------|----------|----------|
| 0:00 | 震惊 | 德黑兰、3月28日凌晨 | 夜空火光、爆炸 |
| ... | ... | ... | ... |
```

### 第二步：多备选搜索策略

**每个情感节点搜索 2-3 张备选图片**，满足不同剪辑需求。

**搜索优先级**：
1. **无水印来源**（必须）：
   - Unsplash（高质量风景/建筑）
   - Pexels（人物/事件）
   - StockCake（中性题材）
   - Vecteezy（矢量插画/图标）

2. **避开来源**（禁止）：
   - Dreamstime / Shutterstock / Alamy / Getty Images（带水印）
   - 新闻机构原图（NYT/BBC/CNN等通常带水印）

3. **搜索关键词技巧**：
   - 加入 `unsplash pexels stockcake` 限定来源
   - 加入 `no watermark free commercial` 排除水印
   - 情感类图片用抽象意象（火焰、书本、蜡烛）效果更好

**备选命名规范**：
```
01A_开篇_城市夜空大火_Unsplash.jpg
01B_开篇_建筑夜间燃烧_Pexels.jpg
01C_开篇_夜空火焰效果_StockCake.jpg
```

### 第三步：确认用户偏好

**必须询问的偏好**：
1. **图片格式**：横版 16:9 / 竖版 9:16 / 两者都要
2. **人物风格**：真实人物 / 剪影抽象 / 混合使用
3. **建筑识别**：真实校门校徽 / 通用建筑 / 需加水印

**用户选择后**，提供最终配图方案。

### 第四步：下载与打包

1. 使用 Python 脚本批量下载
2. 按情感节点命名（时间+情感+主题）
3. 打包成 ZIP 文件

**下载脚本要点**：
- 设置 User-Agent 模拟浏览器
- 30秒超时
- 失败自动跳过，不中断整体
- 完成后统计成功/失败数量

### 第五步：交付清单

**必须包含**：
- ZIP 压缩包
- 文件目录列表
- 每个情感节点对应的备选图片说明
- 缺失图片及原因（如有）

## 常见文案类型与配图策略

### 时事评论类（如本案例）
- **情感跨度**：震惊 → 分析 → 愤怒 → 悲痛 → 反思 → 希望 → 祈愿
- **画面风格**：新闻摄影 + 情感隐喻混合
- **关键元素**：地名/建筑名/日期/数字/法律条款

### 情感故事类
- **情感跨度**：引入 → 冲突 → 高潮 → 转折 → 结局
- **画面风格**：人物特写 + 环境氛围
- **关键元素**：人物关系/情感关键词/象征物

### 知识科普类
- **情感跨度**：引入 → 解析 → 深化 → 总结
- **画面风格**：示意图 + 数据可视化 + 场景图
- **关键元素**：专业术语/流程图/对比数据

### 产品/服务推广类
- **情感跨度**：痛点 → 方案 → 展示 → 行动
- **画面风格**：产品图 + 使用场景 + 效果图
- **关键元素**：产品名/功能点/用户评价

## 命名规范模板

```

示例：
01A_开篇_德黑兰夜空火光_Unsplash.jpg
02B_背景_伊朗科技大学_Pexels.jpg
03C_深化_导弹攻击_StockCake.jpg
```

**序号规则**：按文案时间顺序 01, 02, 03...

**情感标签**：
- 开篇/背景/深化/愤怒/悲痛/反思/希望/祈愿
- 或自定义：震惊/平静/紧张/高潮/尾声
