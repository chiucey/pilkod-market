# 图片命名规范详细说明

## 核心命名模板

```
{序号}{情感标签}_{画面主题}_{来源}.{格式}
```

### 各部分说明

#### 1. 序号（2位数字）
- 按文案时间顺序编排
- 01, 02, 03... 依次递增
- 保持两位数（01-09）

#### 2. 情感标签
**标准情感标签**：
| 标签 | 适用场景 |
|------|----------|
| 开篇 | 吸引注意力的震撼画面 |
| 背景 | 交代环境/背景信息 |
| 引入 | 话题引入 |
| 深化 | 深入分析 |
| 分析 | 理性陈述 |
| 愤怒 | 情绪高涨/控诉 |
| 悲痛 | 哀悼/损失 |
| 反思 | 理性思考 |
| 希望 | 正面转折 |
| 升华 | 总结升华 |
| 祈愿 | 情感收尾 |
| 结尾 | 最终画面 |

#### 3. 画面主题
**命名规则**：
- 使用具体、有识别度的关键词
- 包含关键元素（地名、建筑名、技术名）
- 避免太抽象的词

**正确示例**：
- `德黑兰夜空火光`
- `伊朗科技大学校门`
- `导弹发射瞬间`
- `女科学家实验室`

**错误示例**：
- `图片1`
- `场景`
- `示意图`

#### 4. 来源
**标准来源标识**：
| 标识 | 来源 |
|------|------|
| Unsplash | Unsplash |
| Pexels | Pexels |
| StockCake | StockCake |
| Vecteezy | Vecteezy |
| WikiMedia | WikiMedia |

#### 5. 备选标识
**备选命名规则**：
- A/B/C 表示同一节点的多个备选
- A 通常是最佳选择
- B/C 是替代方案

**示例**：
```
01A_开篇_德黑兰夜空火光_Unsplash.jpg    ← 最佳选择
01B_开篇_城市爆炸火焰_Pexels.jpg        ← 备选1
01C_开篇_浓烟笼罩城市_StockCake.jpg     ← 备选2
```

## 情感节点时间估算

| 文案时长 | 每节点建议时长 | 节点数量 |
|----------|----------------|----------|
| 1分钟 | 10-15秒 | 4-6个 |
| 2分钟 | 15-20秒 | 6-8个 |
| 3分钟 | 20-25秒 | 7-9个 |
| 4分钟 | 25-30秒 | 8-10个 |
| 5分钟+ | 30秒以上 | 根据内容 |

## 文件夹结构建议

```
口播文案配图/
├── 01_开篇/
│   ├── 01A_德黑兰夜空火光_Unsplash.jpg
│   ├── 01B_城市爆炸_Pexels.jpg
│   └── 01C_浓烟_StockCake.jpg
├── 02_背景/
│   ├── 02A_大学校门_Pexels.jpg
│   └── 02B_校园建筑_Unsplash.jpg
├── ...
└── 08_结尾/
    └── 08A_和平校园_Unsplash.jpg
```

或者扁平结构（按当前最佳实践）：
```
配图_无水印/
├── 01A_开篇_德黑兰夜空火光_Unsplash.jpg
├── 01B_开篇_城市爆炸火焰_Pexels.jpg
├── 02A_背景_大学校园建筑_Pexels.jpg
└── ...
```
