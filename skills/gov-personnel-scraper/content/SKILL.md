# 政府人事任免信息爬取与管理系统

## 功能概述

本系统实现对中国政府网（gov.cn）人事任免信息的自动化爬取、增量更新、数据管理和排序查询功能。

## 核心功能

### 1. 自动爬取（定时任务）
- 每天8:00自动登录 gov.cn
- 搜索"任免"关键词
- 抓取最近24小时的人事任免信息
- 字段提取：姓名、职务、上任/免去、时间、文号

### 2. 增量更新机制
- 基于文号（唯一标识）判断是否重复
- 基于时间戳判断是否遗漏
- 状态文件记录最后爬取时间
- 增量追加，不覆盖历史数据

### 3. 上传机制
- 支持手动CSV上传
- 支持不定时追加上传
- 自动去重和合并
- 冲突检测与提示

### 4. 职务排序系统
- 按职务层级自动排序
- 支持按职级大小排序
- 给出排序理由说明

## 使用方式

### 定时任务模式
```bash
python src/main.py --mode schedule
```

### 单次爬取
```bash
python src/main.py --mode scrape
```

### 上传CSV
```bash
python src/main.py --mode upload --file path/to/appointments.csv
```

### 排序查询
```bash
python src/main.py --mode rank --names "张三,李四,王五" --file data/appointments.csv
```

## 职务职级排序规则

### 国家级排序
1. 中共中央总书记
2. 国家主席
3. 全国人大常委会委员长
4. 国务院总理
5. 全国政协主席
6. 中央纪委书记

### 省部级排序
1. 省委书记/自治区党委书记
2. 省长/自治区主席
3. 省人大常委会主任
4. 省政协主席
5. 副省长
6. 副省级干部

### 市厅级排序
1. 市委书记
2. 市长
3. 市人大常委会主任
4. 市政协主席
5. 副市长
6. 正厅级干部

### 县处级排序
1. 县委书记
2. 县长
3. 县人大常委会主任
4. 县政协主席
5. 副县长
6. 正处级干部

### 同级排序规则
- 同级职务按党内职务优先
- 同一职务按任职时间倒序
- 特殊情况按文号顺序

## 增量更新逻辑

```
1. 读取当前CSV数据
2. 读取state.json获取最后爬取时间
3. 爬取gov.cn最新数据
4. 过滤出24小时内的新数据
5. 按文号去重：
   - 新数据中文号存在 → 跳过
   - 新数据中文号不存在 → 追加
6. 更新state.json
7. 生成上传日志
```
