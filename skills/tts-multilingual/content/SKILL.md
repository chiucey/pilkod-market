# 文字转语音多语言技能

## 触发条件

当用户请求以下操作时激活此技能：
- 将文字转换为语音/音频
- 朗读文本内容
- 使用特定国家语言生成语音
- 制作多语言配音
- 生成 TTS 音频文件
- 语音合成

## 执行流程

### 步骤 1：解析用户需求
确认以下信息：
- **文本内容**：需要转换为语音的文字
- **目标语言**：用户指定的语言或自动检测
- **语音属性**：语速、音量、音调（可选）
- **输出格式**：MP3 格式

### 步骤 2：选择语音
根据语言选择合适的语音ID，支持以下语音参数：
- `voice`：选择特定语音
- `speed`：语速（0.5-2.0，默认1.0）
- `volume`：音量（0.0-10.0，默认1.0）
- `pitch`：音调（-12到12，默认0）
- `emotion`：情感（happy, sad, angry, fearful, disgusted, surprised, neutral）

### 步骤 3：生成音频
使用 `gen_audios` 或 `batch_text_to_audio` 工具生成语音：
- 单段文本使用 `gen_audios`
- 多段文本使用 `batch_text_to_audio`

### 步骤 4：返回结果
- 提供生成的音频文件路径
- 说明音频格式和属性

## 使用示例

### 示例 1：简单中文化语音
**用户输入**："将以下文字转为语音：今天天气真好"

**执行操作**：
```
使用 gen_audios 生成中文语音
```

### 示例 2：多语言语音生成
**用户输入**："用英语、法语和日语分别朗读：Hello World"

**执行操作**：
```
使用 batch_text_to_audio 批量生成三种语言的语音
```

### 示例 3：带情感参数的语音
**用户输入**："用欢快的语气朗读：恭喜发财"

**执行操作**：
```
使用 gen_audios，emotion="happy"
```

## 错误处理

| 错误类型 | 处理方式 |
|----------|----------|
| 不支持的语言 | 返回支持的完整语言列表 |
| 文本过长 | 提示分段处理或使用 batch_text_to_audio |
| 生成失败 | 报告错误并建议重试 |

## 限制说明

- 单次生成文本建议不超过 500 字符
- 支持的输出格式为 MP3
- 音频时长受文本长度限制
- 部分语言可能需要更长处理时间

## 相关工具

- `get_voice_list`：获取所有可用语音列表
- `gen_audios`：生成单个音频文件
- `batch_text_to_audio`：批量生成多个音频文件
