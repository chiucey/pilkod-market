# 案例分析框架参考

## 一、案例筛选标准

### 选取标准
1. 典型性：反映普遍法律问题
2. 权威性：来源于权威裁判
3. 时效性：反映最新司法观点
4. 争议性：存在法律适用争议

### 案例类型
- 指导性案例
- 公报案例
- 典型案例
- 重大影响力案件

## 二、案例分析维度

### 事实分析维度
- 当事人关系
- 行为过程
- 损害后果
- 因果关系

### 法律分析维度
- 法律关系定性
- 权利义务内容
- 法律责任认定

### 裁判分析维度
- 裁判依据
- 裁判逻辑
- 裁判结果

## 三、裁判规则提炼方法

### 规则来源识别
1. 从个案裁判中提炼规则
2. 从系列案例中归纳规则
3. 从司法解释中确认规则

### 规则结构化呈现

```
规则：[简明扼要陈述裁判规则]

构成要件：
1. ...
2. ...
3. ...

适用情形：
- 典型情形
- 除外情形

法律依据：
- 相关法条
- 参考案例

实践要点：
1. ...
2. ...
```

## 四、典型案例分析方法

### 民事案例分析要素
- 民事法律关系分析
- 合同效力判断
- 违约责任认定
- 损害赔偿计算

### 刑事案例分析要素
- 犯罪构成要件
- 罪与非罪界限
- 此罪与彼罪区分
- 刑事责任认定

### 行政案例分析要素
- 行政行为合法性
- 程序合规性
- 事实认定依据
- 法律适用正确性
