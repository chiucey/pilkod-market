# 法律专业文章写作参考标准

## 一、法律引用规范

### 法律法规引用格式

```
《中华人民共和国XX法》第X条第X款
如：《中华人民共和国民法典》第一百四十三条
```

### 案例引用格式

```
[案号] 审理法院 裁判日期
如：[2021]最高法民终1234号 最高人民法院 2021年10月15日
```

### 司法解释引用

```
《最高人民法院关于适用〈中华人民共和国民法典〉合同编通则若干问题的解释》第X条
```

## 二、法律术语规范

### 常用专业术语对照

| 规范用语 | 避免使用 |
|---------|---------|
| 民事法律行为 | 民事行为 |
| 合同 | 合约、协议（正式法律文本） |
| 标的 | 合同标的物 |
| 连带责任 | 连带负责 |
| 举证责任 | 证明责任 |

### 常用法律表述

- "根据《...法》第X条规定..."
- "《...法》第X条规定了..."
- "本案争议焦点为..."
- "本院认为..."

## 三、法律论证方法

### 法律解释方法

1. 文义解释 - 按条文字面含义解释
2. 体系解释 - 联系法律整体进行解释
3. 目的解释 - 依据立法目的进行解释
4. 历史解释 - 结合立法历程解释
5. 比较解释 - 参考域外立法例解释

### 法律推理形式

```
大前提：法律规定
小前提：案件事实
结论：法律后果
```

## 四、文章结构模板

### 新法影响分析模板

```markdown
# [法律名称]对[主体]的合规影响分析

## 一、立法背景与目的
## 二、主要修订内容
## 三、对[主体]的具体影响
   3.1 义务变化
   3.2 风险点分析
   3.3 合规建议
## 四、过渡期安排
## 五、结语
```

### 案例评析模板

```markdown
# [案号]案例评析

## 一、案情概述
## 二、争议焦点
## 三、法院裁判
   3.1 事实认定
   3.2 法律适用
## 四、裁判要旨
## 五、实务启示
```
