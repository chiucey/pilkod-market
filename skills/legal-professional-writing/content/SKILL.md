# 法律专业文章写作技能

## 核心能力

本技能帮助用户撰写高质量的法律专业文章，涵盖以下核心领域：

1. **新法合规影响分析** - 分析新法律法规对特定法律主体的冲击与影响
2. **案例剖析** - 深度解析过往法律案例的事实认定、法律适用和裁判逻辑
3. **裁判规则梳理** - 归纳总结特定法律领域的裁判规则和司法实践

## 工作流程

### 1. 需求理解

在开始写作前，明确以下要素：

- **法律领域**：民法、刑法、行政法、商法、劳动法等
- **文章类型**：学术论文、实务分析、案例评析、法规解读
- **目标受众**：法律专业人士、企业法务、司法实务工作者
- **深度要求**：基础概述、深度分析还是前沿探讨

### 2. 内容结构框架

法律专业文章应遵循以下标准结构：

```
1. 引言/背景
   - 法律问题的提出
   - 研究的必要性和意义
   - 本文结构概述

2. 法律规定与解读
   - 相关法律条文梳理
   - 条文含义的规范解读
   - 与旧法/其他规定的比较

3. 合规影响分析（新法分析类）
   - 适用主体分析
   - 义务变化梳理
   - 合规风险评估
   - 实操影响评估

4. 案例剖析（案例分析类）
   - 案件基本情况
   - 争议焦点
   - 法律适用分析
   - 裁判要旨提炼

5. 裁判规则梳理
   - 规则归纳
   - 适用条件
   - 实践要点
   - 典型案例支撑

6. 结论与建议
   - 主要观点总结
   - 实操建议
   - 风险提示
```

### 3. 写作规范

**语言风格**：
- 使用严谨的法律专业术语
- 表达准确、逻辑严密
- 避免口语化和模糊表述

**论证要求**：
- 论点明确，论据充分
- 法律依据引用准确（法条、案例）
- 分析深入，避免浮于表面

**引用规范**：
- 法律法规：注明名称、条款号
- 案例引用：注明案号、审理法院、裁判日期
- 学术观点：注明作者、来源

## 内容创作指南

### 新法合规影响分析要点

1. **立法背景梳理**
   - 立法目的与政策考量
   - 立法历程与主要修订
   - 与国际惯例的比较

2. **主体影响评估**
   - 明确适用主体范围
   - 分析新增义务
   - 评估合规成本

3. **实操影响分析**
   - 业务流程影响
   - 制度调整需求
   - 时间节点要求

### 案例剖析框架

1. **案件概述**
   - 当事人信息
   - 案件经过
   - 裁判结果

2. **法律分析**
   - 事实认定要点
   - 法律适用逻辑
   - 裁判理由阐述

3. **价值评析**
   - 典型意义
   - 实践指导价值
   - 启示与反思

### 裁判规则梳理方法

1. **样本收集**
   - 检索相关案例
   - 筛选典型案例
   - 建立案例库

2. **规则提炼**
   - 识别共同要素
   - 归纳适用条件
   - 明确裁判尺度

3. **规则呈现**
   - 正面规则
   - 除外情形
   - 实践指引

## 输出格式

根据文章类型选择适当的输出格式：

| 文章类型 | 适用场景 | 结构特点 |
|---------|---------|---------|
| 学术论文 | 研究探讨 | 理论深度、文献综述 |
| 实务分析 | 指导实践 | 操作性强、要点清晰 |
| 案例评析 | 案例研究 | 事实与法律分析并重 |
| 法规解读 | 理解适用 | 条文解读与案例结合 |

## 质量标准

1. **准确性**：法律条文引用准确无误
2. **专业性**：运用专业法律术语和分析框架
3. **逻辑性**：论证过程严密、层次分明
4. **实用性**：结论和建议具有实操价值
5. **时效性**：反映最新的法律动态和司法实践

## 触发示例

- "撰写一篇关于《个人信息保护法》对企业合规影响分析的文章"
- "分析这个劳动争议案例的裁判规则"
- "梳理建设工程合同纠纷的裁判规则"
- "撰写公司法修订的专题文章"
- "深度剖析这起股权转让纠纷案例"
