# 市政道路效果图生成

根据用户提供的道路参数和地块信息，生成专业市政道路效果图。

## 工作流程

### 步骤 1：收集用户参数

向用户收集以下三类信息：

**1. 道路横断面参数**
| 参数项 | 选项参考 |
|--------|----------|
| 道路等级 | 城市支路、城市干路、快速路等 |
| 车道数量 | 双向二车道、双向四车道、双向六车道等 |
| 车道宽度 | 3.0m / 3.25m / 3.5m / 3.75m |
| 机非分隔形式 | 机非护栏分隔、绿化分隔、标线分隔、无分隔 |
| 中央分隔形式 | 单黄虚线、双黄线、护栏分隔、绿化带 |
| 人行道宽度 | 1.5m / 2.0m / 2.5m / 3.0m / 无 |

**2. 道路两侧地块情况**
| 参数项 | 选项参考 |
|--------|----------|
| 用地性质 | 学校、厂房、住宅小区、商业建筑、公共建筑、公园等 |
| 绿化配置 | 行道树（樟树/银杏/梧桐/桂花等）、绿化带、花箱隔离 |
| 围墙形式 | 铁艺围墙、实体砖墙、绿篱围挡、无围墙 |
| 退让距离 | 无退让 / 2m / 5m / 10m 等 |

**3. 其他定制需求**
| 参数项 | 选项参考 |
|--------|----------|
| 天气/时段 | 晴天、阴天、黄昏、夜景 |
| 视角偏好 | 一点透视、两点透视、鸟瞰视角 |
| 特殊元素 | 公交站台、交通信号灯、城市家具等 |

### 步骤 2：生成效果图

根据收集的参数，使用 `image_synthesize` 工具生成效果图。

**提示词构建要点：**

1. **道路结构**：
   - 机动车道统一采用深灰色平整沥青路面
   - 非机动车道与机动车道材质保持一致
   - 机非分隔采用专用钢管式隔离护栏（非波形护栏）

2. **交通标线**：
   - 中央分隔：单黄虚线，全幅纵向贯通
   - 车道分界：白色虚线
   - 车行道边界：白色实线

3. **人行道**：
   - 宽度按参数设置
   - 采用浅灰色透水砖铺装

4. **围墙形式**：
   - 优先使用铁艺栏杆式围墙（黑色或深灰色）
   - 造型通透简洁，不同于实体砖墙

5. **行道树**：
   - 间距适中，不遮挡地块构筑物
   - 树冠不超过建筑二层
   - 保证视线通透

6. **建筑可见性**：
   - 学校/厂房建筑主体完整展示
   - 不被行道树和围墙过度遮挡

7. **构图原则**：
   - 中心一点透视，强调纵深感
   - 建筑高度约占画面1/4-1/3
   - 层次分明：天空→建筑→围墙→行道树→道路

### 步骤 3：输出交付

使用 `<deliver_assets>` 标签输出效果图，并附上参数对照表。

## 示例参数

| 用户提供的参数 | 实现情况 |
|---------------|----------|
| 城市支路，双向四车道 | 双向四车道，每车道3.5m |
| 机非护栏分隔 | 专用钢管式隔离护栏 |
| 人行道2.5m | 两侧各2.5m浅灰色透水砖 |
| 铁艺围墙 | 黑色铁艺栏杆式围墙 |
| 晴天一点透视 | 晴朗浅蓝色天空，中心透视 |

## 技术规范要点

1. **铺装材质**：机动车道与非机动车道统一深灰色沥青
2. **护栏类型**：机非分隔用钢管式框架护栏，非波形护栏
3. **围墙形式**：铁艺栏杆式围墙，通透简洁
4. **行道树配置**：高度适中，不遮挡建筑，保证视线通透
