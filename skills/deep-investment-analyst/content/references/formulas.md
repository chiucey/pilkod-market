# 深度投研分析专家 - 参考文档

## A. 核心财务公式速查

### A1. ROE 分解（杜邦分析）
```
ROE = 销售净利率 × 资产周转率 × 权益乘数
    = (净利润 ÷ 营业收入) × (营业收入 ÷ 总资产) × (总资产 ÷ 股东权益)
```

### A2. CFOR 分解法
```
CFOR = 现金利润率 × 经营资产周转率
     = (经营活动现金流净额 ÷ 营业收入) × (营业收入 ÷ 经营资产)
```

### A3. FCF 转化率
```
FCFF = 经营活动现金流净额 - 资本支出
FCF转化率 = FCFF ÷ 净利润
>1.0: 盈利质量极高 | ≈1.0: 盈利质量良好 | <0.5(连续2年): 风险高
```

### A4. ROIC 与 WACC
```
NOPAT = 息税前利润 × (1 - 所得税率)
投入资本 = 股东权益 + 有息负债 - 现金等价物
ROIC = NOPAT ÷ 投入资本

WACC = Ke × 股权占比 + Kd × (1 - 税率) × 债务占比
Ke(CAPM) = Rf + β × ERP

价值判断:
- ROIC > WACC → 创造价值
- ROIC < WACC → 毁灭价值
```

### A5. 市赚率 (PR)
```
【重要】ROE必须代入百分比数值（如15%代入15，而非0.15）
PR = N × PE(TTM) / ROE(TTM)

N系数规则:
- 股利支付率 ≥ 50% → N=1.0
- 30%-50% → N=1.5
- 10%-30% → N=1.8
- <10% → N=2.0

双5策略买入条件: PR ≤ 0.5(理想0.4) 且 股息率 ≥ 5%
```

## B. 技术指标计算

### B1. 移动平均线 (MA)
```
MA(n) = (P1 + P2 + ... + Pn) / n
```

### B2. 平均真实波幅 (ATR)
```
TR = max(H-L, |H-PC|, |L-PC|)
ATR(n) = sum(TR) / n
```

### B3. 相对强弱指数 (RSI)
```
RS = avg(上涨) / avg(下跌)
RSI = 100 - 100 / (1 + RS)
```

### B4. 平均趋向指数 (ADX)
```
+DMI = (High - PrevHigh) vs (PrevLow - Low)
-DMI = (PrevLow - Low) vs (High - PrevHigh)
ADX = 100 × avg(|+DMI - (-DMI)|) / (+DMI + (-DMI))
```

### B5. 乖离率 (BIAS)
```
BIAS(n) = (当前收盘价 - MA(n)) / MA(n) × 100%
```

### B6. 布林带
```
中轨 = MA(20)
上轨 = 中轨 + 2 × std(20)
下轨 = 中轨 - 2 × std(20)
```

## C. 短线交易策略筛选优先级

| 优先级 | 策略 | 筛选条件 | 排斥条件 |
|--------|------|----------|----------|
| 1 | 事件驱动 | 近15日重大事件且评分≥7 | 无近期重大事件 |
| 2 | 趋势跟踪 | ADX(14)>25 且均线多头/空头排列 | ADX<20 |
| 3 | 均值回归 | ADX<30 且 ADX未持续上升, BIAS(20)<-6%或RSI<30 | ADX>30且持续上升 |
| 4 | 网格交易 | ADX<25 且 ATR/收盘价在1.5%-5% | ATR/收盘价<1.5%或>5% |

**兜底规则**: 四种策略均未命中 → "当前市况无高度适配策略，建议观望或降低仓位至底仓级别"

## G. 年化处理规则

### 默认方法（线性年化）
```
年化数值 = (报告期累积数值 / 报告期月份数) × 12
```

### 季节性调整年化（优先级更高）
```
适用于季节性显著行业（白酒、零售、空调、农业、旅游等）
年化数值 = 报告期累积数值 / 上年同期各季度占全年比例之和
```

**强制要求**: 所有流量指标必须注明数据口径（如"含2025年三季报（年化）"及年化方法）
