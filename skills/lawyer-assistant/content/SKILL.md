# 律师助理技能

## 技能概述

本技能专注于提供专业的法律文书服务，帮助用户高效完成各类法律文档的起草、审查和修改工作。

## 核心功能

### 1. 合同起草

支持各类商务合同的起草服务：

- **常用商务合同**：买卖合同、服务合同、租赁合同、委托合同
- **劳动合同**：劳动合同、劳务协议、保密协议
- **投资融资类**：股权投资协议、借款合同、对赌协议
- **知识产权类**：专利许可合同、商标许可协议、软件著作权转让合同

**工作流程**：

1. 明确合同类型和交易背景
2. 确定合同双方主体信息
3. 梳理核心权利义务条款
4. 识别潜在法律风险点
5. 生成完整合同文本

### 2. 合同审查

对现有合同进行专业审查：

- 审查合同主体资格和资质
- 检查条款的合法性和有效性
- 识别不公平条款和风险条款
- 提出修改建议和优化方案
- 提供风险评估报告

**输出格式**：

- 风险等级评定（高/中/低）
- 问题条款清单
- 具体修改建议
- 审查结论和法律意见

### 3. 代理词撰写

为诉讼案件撰写专业代理意见：

- 原告代理词/被告代理词
- 上诉状和申诉状
- 再审申请书
- 各类程序的代理意见

**撰写要点**：

- 事实陈述：梳理案件事实和证据
- 法律适用：援引相关法律条文
- 论证逻辑：构建完整的论证体系
- 诉讼请求：明确具体的诉讼主张

### 4. 答辩状草拟

为被告或被上诉人撰写答辩意见：

- 一审答辩状
- 二审答辩状
- 管辖权异议申请书
- 反诉状

### 5. 法律意见书

根据需求出具专业法律意见：

- 合规性审查意见
- 投资并购法律意见
- 合同效力认定意见
- 法律风险评估报告
- 尽职调查报告

## 使用指南

### 如何获取最佳结果

提供以下信息可显著提升文书质量：

| 信息类型 | 说明 | 重要性 |
|---------|------|--------|
| 案件/交易背景 | 完整的业务场景描述 | ★★★★★ |
| 当事人信息 | 各方的名称、资质、关系 | ★★★★★ |
| 核心诉求 | 想要达成什么目的 | ★★★★★ |
| 相关证据 | 现有证据材料清单 | ★★★★ |
| 法律依据 | 适用的法律条文 | ★★★ |
| 参考案例 | 类似判例或经验 | ★★★ |

### 示例提示语

- "帮我起草一份房屋租赁合同，租期两年"
- "审查这份合作协议，找出潜在风险"
- "写一份建设工程合同纠纷的代理词"
- "为这起买卖合同纠纷撰写答辩状"
- "出具一份关于股权收购的法律意见书"

## 文书格式规范

所有生成的法律文书遵循以下规范：

- 使用规范的法律文书格式
- 准确援引现行有效法律条文
- 语言表达严谨、规范、专业
- 结构清晰、层次分明
- 重要条款配有必要说明

## 免责声明

本技能生成的法律文书仅供参考学习使用，不构成正式法律意见。如需正式法律文书或有重大法律事务需求，请咨询持证律师或法律专业人士。
