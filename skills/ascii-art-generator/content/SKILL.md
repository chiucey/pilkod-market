# ASCII 艺术图表生成器

## 核心能力

生成高质量的 ASCII 艺术图表，支持多种图表类型和完全可定制的样式。

## 支持的图表类型

| 类型 | 说明 | 触发关键词 |
|------|------|------------|
| 条形图 (Bar Chart) | 水平或垂直条形图 | bar, 条形图, 柱状图 |
| 折线图 (Line Chart) | 数据趋势线图 | line, 折线图, 趋势 |
| 饼图 (Pie Chart) | ASCII 圆形饼图 | pie, 饼图, 比例 |
| 面积图 (Area Chart) | 填充区域图表 | area, 面积图 |
| 堆叠图 (Stacked Chart) | 多数据堆叠展示 | stacked, 堆叠 |

## 样式选项

### 字符集选择
```javascript
// 基础字符
CHARS = {
  solid: ['█', '▓', '▒', '░', '#', '@', '%', '*', '+', '-', '.'],
  light: ['▔', '▁', '▂', '▃', '▄', '▅', '▆', '▇', '█'],
  rounded: ['◢', '◣', '◤', '◥', '●', '○', '◎']
}
```

### 颜色支持 (ANSI 颜色代码)
```javascript
COLORS = {
  reset: '\x1b[0m',
  red: '\x1b[31m',
  green: '\x1b[32m',
  yellow: '\x1b[33m',
  blue: '\x1b[34m',
  magenta: '\x1b[35m',
  cyan: '\x1b[36m',
  white: '\x1b[37m',
  bold: '\x1b[1m'
}
```

### 尺寸参数
- `width`: 图表宽度 (默认: 50)
- `height`: 图表高度 (默认: 20)
- `barWidth`: 单个条形宽度 (默认: 2)

## 输出格式

生成的 ASCII 图表应该：
1. 有清晰的标题
2. 显示轴标签和刻度
3. 显示数据值或百分比
4. 使用一致的间距
5. 在支持的环境中使用 ANSI 颜色

## 响应格式

提供生成的 ASCII 图表时，使用代码块包裹：
````markdown
```ascii
[ASCII 图表内容]
```
````

## 错误处理

- 数据为空：提示用户提供数据
- 数据格式错误：说明正确的数据格式
- 数据值无效（负数）：使用绝对值或提示用户
