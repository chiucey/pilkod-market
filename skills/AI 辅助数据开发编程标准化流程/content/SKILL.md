# Skill：AI 辅助数据开发编程标准化流程

## 1. 需求结构化（必须第一步）
- 业务目的
- 输入表/数据源
- 输出字段清单
- 过滤条件
- 计算口径
- 异常场景（NULL、空值、特殊字符）
- 性能要求

## 2. 逻辑拆解
- 涉及表与别名
- 关联键与关联类型
- 分层计算逻辑
- 业务口径规则
- 性能风险点（全表扫描、大表JOIN、无索引）

## 3. 代码生成
- 完整可运行 SQL
- 关键注释
- 空值/异常处理
- 测试用例

## 4. 校验与优化
- 业务口径正确性校验
- 执行计划分析
- 索引建议
- 性能优化方案

## 5. 交付归档
- 最终代码
- 逻辑说明
- 维护注意事项
- 可复用片段
