# Skill 安全评估器

## 评估概述

本技能提供对 Agent Skill 的全方位安全评估，覆盖代码安全、数据安全、网络安全、权限安全、依赖安全和内容安全六大维度。

## 评估维度

### 1. 代码安全评估

**检查项**：
- 敏感信息泄露检测（API 密钥、密码、Token）
- 注入攻击风险（命令注入、代码注入、Prompt 注入）
- 硬编码凭证识别
- 日志中的敏感信息暴露
- 代码注释中的敏感内容

**安全等级定义**：
- **严重**：发现明文密钥/凭证
- **高危**：硬编码密码或 Token
- **中危**：可能泄露敏感信息的日志输出
- **低危**：注释中包含的配置信息

### 2. 数据安全评估

**检查项**：
- 文件系统访问范围
- 敏感文件读取风险（~/.ssh、/etc/passwd、.env）
- 数据存储安全性
- 临时文件处理
- 数据清理机制

**安全等级定义**：
- **严重**：访问系统关键目录
- **高危**：广泛的目录读写权限
- **中危**：临时文件未清理
- **低危**：仅访问工作目录

### 3. 网络安全评估

**检查项**：
- 外部 API 调用安全性
- 数据传输加密
- 第三方服务依赖
- 网络请求验证
- 重定向和跳转安全

**安全等级定义**：
- **严重**：向未知第三方发送敏感数据
- **高危**：HTTP 而非 HTTPS 的敏感传输
- **中危**：缺少请求验证
- **低危**：仅访问白名单域名

### 4. 权限安全评估

**检查项**：
- 工具权限范围是否最小化
- 高危操作权限审查
- 系统命令执行权限
- 文件操作权限
- 数据库操作权限

**安全等级定义**：
- **严重**：需要执行系统命令的高危权限
- **高危**：宽泛的文件读写权限
- **中危**：网络访问权限
- **低危**：只读权限或最小必要权限

### 5. 依赖安全评估

**检查项**：
- 第三方库安全性
- 依赖版本漏洞
- 可疑的包引用
- 更新维护状态
- 许可证合规性

**安全等级定义**：
- **严重**：已知漏洞的依赖
- **高危**：停止维护的依赖
- **中危**：非活跃维护的依赖
- **低危**：活跃维护的安全依赖

### 6. 内容安全评估

**检查项**：
- Prompt 注入风险
- 恶意代码检测
- 用户输入验证
- 输出内容过滤
- 隐私数据处理

**安全等级定义**：
- **严重**：可执行任意代码的能力
- **高危**：缺少输入验证
- **中危**：可能的隐私泄露
- **低危**：有适当的输入输出验证

## 评估流程

### 阶段 1：信息收集

1. **读取 Skill 文件结构**
   - 检查 SKILL.md 内容
   - 检查 scripts/ 目录中的脚本
   - 检查 references/ 和 assets/ 内容
   - 读取 _meta.json 元数据

2. **静态代码分析**
   - 识别所有工具调用
   - 识别所有文件操作
   - 识别所有网络请求
   - 识别敏感信息模式

### 阶段 2：逐维评估

对每个评估维度执行专项检查：

```
评估维度：{维度名称}
├── 检查项 1：{检查内容}
│   └── 风险等级：{等级} | 状态：{通过/警告/危险} | 详情：{说明}
├── 检查项 2：{检查内容}
│   └── 风险等级：{等级} | 状态：{通过/警告/危险} | 详情：{说明}
└── 维度评分：{X}/100
```

### 阶段 3：综合分析

1. **风险聚合**
   - 统计各等级风险数量
   - 计算加权风险分数
   - 识别高危风险链

2. **攻击向量分析**
   - 识别可能的攻击路径
   - 评估攻击可行性
   - 评估潜在影响

### 阶段 4：评估报告生成

### 代码安全

- 限制文件系统访问范围
- 使用安全临时文件处理
- 实施数据清理机制

### 网络安全
- 验证所有外部请求
- 使用 HTTPS 进行敏感传输
- 实施请求限流

### 权限安全
- 遵循最小权限原则
- 限制工具调用范围
- 实施权限审计

## 安全评分计算

### 维度权重

| 维度 | 权重 | 说明 |
|------|------|------|
| 代码安全 | 25% | 最重要，影响最广 |
| 权限安全 | 20% | 直接影响系统安全 |
| 数据安全 | 20% | 数据泄露风险 |
| 网络安全 | 15% | 外部交互安全 |
| 内容安全 | 10% | 用户交互安全 |
| 依赖安全 | 10% | 间接风险 |

### 计算公式

```
综合得分 = Σ(维度得分 × 权重) - 严重风险惩罚

严重风险惩罚 = 严重风险数 × 15 + 高危风险数 × 5
```

## 评估执行指南

### 输入要求
- Skill 文件路径或 SKILL.md 内容
- 可选的特定评估维度

### 输出要求
- 结构化安全评估报告
- 具体问题列表和位置
- 可操作的修复建议
- 综合安全评分和等级

### 评估原则
1. **全面性**：覆盖所有安全维度
2. **准确性**：精确定位问题和位置
3. **可操作性**：提供可行的修复建议
4. **客观性**：基于明确的评估标准
