# 安全风险评估矩阵

## CVSS 风格评分

### 可利用性 (Exploitability)
| 等级 | 分值 | 说明 |
|------|------|------|
| 极高 | 3.9 | 无需认证即可利用，广泛曝光 |
| 高 | 3.0 | 需要特定条件或配置 |
| 中 | 2.0 | 需要用户交互或特殊条件 |
| 低 | 1.0 | 需要高度特殊的条件 |
| 极低 | 0.1 | 理论上可利用但极难实现 |

### 影响范围 (Impact)
| 等级 | 分值 | 说明 |
|------|------|------|
| 严重 | 3.0 | 完全控制受影响系统 |
| 高 | 2.0 | 主要功能受损，数据泄露 |
| 中 | 1.5 | 部分功能受损 |
| 低 | 0.5 | 轻微功能影响 |
| 无 | 0.0 | 无实际影响 |

### 综合风险计算
```
风险值 = (可利用性 + 影响范围) / 2
```

## 风险等级阈值

| 综合风险值 | 等级 | 颜色编码 | 响应时间 |
|------------|------|----------|----------|
| 2.5 - 3.0 | 严重 | 🔴 | 立即 |
| 2.0 - 2.4 | 高危 | 🟠 | 24 小时内 |
| 1.5 - 1.9 | 中危 | 🟡 | 1 周内 |
| 0.5 - 1.4 | 低危 | 🟢 | 下一版本 |
| 0.0 - 0.4 | 极低 | ⚪ | 视情况 |

## 攻击复杂度评估

### 低复杂度
- 无需特殊条件
- 默认配置即可攻击
- 广泛可用的攻击工具

### 中复杂度
- 需要特定环境配置
- 需要受害者特定操作
- 定制攻击工具

### 高复杂度
- 需要高度特殊的条件
- 几乎不可能自动化
- 需要内部信息

## 风险传播分析

### 风险链
```
初始风险 → 传播路径 → 级联影响
```

### 传播模式
1. **直接利用**: 风险直接可利用
2. **权限提升**: 低权限 → 高权限
3. **横向移动**: 单系统 → 多系统
4. **数据泄露**: 敏感数据外流
5. **持久化**: 建立持久访问

## 修复优先级定义

### P0 - 立即修复
- 严重风险（风险值 ≥ 2.5）
- 正在被利用的漏洞
- 核心凭证泄露

### P1 - 24 小时内
- 高危风险（风险值 2.0-2.4）
- 可导致数据泄露的问题
- 可提权的问题

### P2 - 1 周内
- 中危风险（风险值 1.5-1.9）
- 潜在安全问题
- 安全边界模糊

### P3 - 下一版本
- 低危风险（风险值 0.5-1.4）
- 改进建议
- 最佳实践不符

### P4 - 视情况
- 极低风险（风险值 < 0.5）
- 信息披露
- 理论风险
