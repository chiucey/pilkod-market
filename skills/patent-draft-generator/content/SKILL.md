# 专利申请文件生成器

本技能根据技术交底书自动生成符合中国专利法要求的专利申请文件，特别注重权利要求书采用上位描述以扩大专利保护范围。

## 工作流程

### 1. 输入解析

解析技术交底书，提取以下关键信息：

- **技术领域**：发明所属的技术领域
- **背景技术**：现有技术及其存在的问题
- **发明内容**：本发明的技术方案、要解决的技术问题、技术效果
- **附图说明**：需要绘制的说明书附图和摘要附图
- **具体实施方式**：最佳实施例

### 2. 文件生成顺序

按照以下顺序生成专利文件：

1. **说明书摘要**（~300字）
2. **权利要求书**（核心文件，采用上位描述）
3. **说明书**（完整五个部分）
4. **说明书附图说明**
5. **摘要附图说明**

### 3. 权利要求书撰写规范（上位描述策略）

#### 3.1 独立权利要求撰写原则

```
特征1 + 功能性描述 + 数值范围上位化 + 结构简化
```

**策略一：组件上位化**
- ❌ 低位：所述螺栓为六角螺栓
- ✅ 上位：所述紧固件

**策略二：材料上位化**
- ❌ 低位：硅胶密封圈
- ✅ 上位：弹性密封件

**策略三：连接关系上位化**
- ❌ 低位：通过螺纹连接
- ✅ 上位：可拆卸连接

**策略四：形状上位化**
- ❌ 低位：圆形散热片
- ✅ 上位：翅片状散热结构

**策略五：功能描述替代结构描述**
- ❌ 低位：包括加热电阻丝
- ✅ 上位：包括加热元件

**策略六：数值范围上位化**
- ❌ 低位：温度为65-75°C
- ✅ 上位：温度为预设值/适宜温度

#### 3.2 权利要求编号示例

```
权利要求1（独立权利要求）：
一种[技术领域]装置，其特征在于，包括：
[主体结构上位描述]、与所述[结构]连接的[功能组件上位描述]、以及[连接关系上位描述]。

权利要求2（从属权利要求）：
根据权利要求1所述的装置，其特征在于，所述[进一步下位限定]。

权利要求3（从属权利要求）：
根据权利要求2所述的装置，其特征在于，所述[更进一步下位限定]。
```

#### 3.3 常见上位概念词库

| 低位描述 | 上位概念 |
|---------|---------|
| 电机、步进电机、直流电机 | 驱动装置 |
| 螺丝、螺栓、螺钉 | 紧固件 |
| 齿轮、皮带轮 | 传动件 |
| 弹簧、橡皮筋 | 弹性件 |
| 胶水、螺丝、卡扣 | 连接件 |
| 按钮、旋钮、触摸屏 | 操作界面 |
| 温度传感器、压力传感器 | 检测元件 |
| 电路板、单片机、PLC | 控制单元 |

### 4. 说明书撰写规范

#### 4.1 五个部分结构

1. **技术领域**：简明指出发明所属或直接应用的技术领域
2. **背景技术**：说明现状和不足，引出发明动机
3. **发明内容**：技术方案、技术效果、附图说明
4. **附图说明**：对各附图的简要说明
5. **具体实施方式**：详细描述最佳实施例

#### 4.2 撰写要点

- 技术术语使用本领域通用术语
- 支持权利要求书的所有技术特征
- 具体实施方式应能实现发明目的
- 避免使用商业性宣传用语

### 5. 摘要撰写规范

- 字数控制在300字以内
- 包含技术领域、技术问题、技术方案、技术效果
- 不得使用商业性宣传用语
- 摘要附图应清楚反映发明主要技术特征

### 6. 附图说明规范

- 说明书附图说明：对每幅附图进行编号和简要描述
- 摘要附图说明：选取最能反映技术方案核心的附图

## 输出模板

生成的专利文件按以下顺序组织：

```
===== 说明书摘要 =====

[摘要正文，约300字]

===== 权利要求书 =====

1. [独立权利要求]
2. [从属权利要求]
...
n. [从属权利要求]

===== 说明书 =====

【技术领域】

【背景技术】

【发明内容】

【附图说明】

【具体实施方式】

===== 说明书附图说明 =====

图1：[描述]
图2：[描述]
...

===== 摘要附图说明 =====

[简要说明选定的摘要附图]
```

## 质量检查清单

生成完成后，自检以下要点：

- [ ] 权利要求书包含独立权利要求和从属权利要求
- [ ] 独立权利要求采用了上位描述策略
- [ ] 说明书的五个部分完整无缺
- [ ] 摘要字数不超过300字
- [ ] 附图说明编号连续规范
- [ ] 技术术语前后一致
- [ ] 无商业性宣传用语
