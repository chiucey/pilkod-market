## 文案口语化标准

### 书面语 → 口语 转换规则

```markdown
## 文案口语化清单

【必须转换】

❌ 书面语 → ✅ 自然口语

"因此" → "所以"
"然而" → "但是/不过"
"综上所述" → "总的来说"
"本产品" → "这个产品/咱们这个"
"具有" → "有"
"采用" → "用/用的是"
"非常" → "特别/贼/超（语气词强化）"
"即可" → "就能"
"请勿" → "别"
"然而" → "结果呢"

【数字处理】
- 年份：2024年 → "二零二四年" 或 "去年/今年"
- 百分比：73% → "七成多"
- 金额：¥299 → "两百九十九块"

【标点转换】
- 省略号 → 拖长音："这个嘛……"
- 问号 → 上扬加重："什么？"
- 感叹号 → 配合语气词："太厉害了！"
```

## 断句节奏设计

### 自然断句规则

```
【黄金断句原则】

1. 单句长度 ≤ 20字（中文）
   - 配音每口气大约支持15-20字
   - 超过则断气，不自然

2. 标点断句 ≠ 配音断句
   - 逗号：短停顿（0.3s）
   - 句号：完整停顿（0.5-0.8s）
   - 省略号：拖音（0.5-1.2s）

3. 主动词前置
   - 把结果放在前面，过程后置
   - 例："我跟你说，这个东西真的超好用"
```

### 节奏类型对照

| 风格 | 语速 | 句长 | 停顿频率 | 适用场景 |
|:---|:---|:---|:---|:---|
| 快节奏带货 | 中快 180-200字/分 | 短句为主 | 频繁短停 | 抖音带货、口播 |
| 慢节奏治愈 | 慢 120-150字/分 | 中等句 | 较长停顿 | 情感、ASMR、睡前 |
| 激情解说 | 快 200-240字/分 | 短句+感叹 | 短促有力 | 游戏解说、体育 |
| 专业课程 | 中等 150-180字/分 | 稍长 | 关键处停顿 | 在线课堂、培训 |
| 新闻资讯 | 标准 180-200字/分 | 标准句 | 稳定节奏 | 新闻播报 |

## 情绪标注系统

### 基础情绪标签

```
# 语气标注符号（插入文案中）

[语速]
- 加速：语速微微加快，直到某个词突然顿住
- 减速：说到重点时放慢，强调感出来
- 正常：基准语速

[停顿]
- 短停：|（0.3秒）
- 中停：||（0.6秒）
- 长停：|||（1秒+）

[语调]
- 上扬：↗（问号、反问、悬念处）
- 下沉：↘（陈述、感叹、确定处）
- 平调：→（平稳叙述）

[重音]
- 加重：══（在重音词前后标记）

[情绪叠加]
- #happy   开心、愉悦
- #sad     悲伤、惋惜
- #angry   愤怒、不满
- #excited 激动、兴奋
- #calm    平静、理性
- #anxious 焦虑、紧迫
- #funny   幽默、调侃
```

### 标注示例

```markdown
## 标注示例

原文：
"这个产品采用了最新的技术，能够在最短的时间内帮你解决问题，而且价格非常实惠。"

✅ 优化+标注版：

"这个产品||用了最新技术||↗（好奇感）
||能在最短时间内|帮你解决麻烦||↘（确定感）
而且价格还特别实惠||══超划算══#excited"

---

原文：
"如果你今天不努力，明天就会被淘汰。"
✅ 优化+标注版：

"如果你今天不努力↘|||明天就会被淘汰||#anxious"
（语速稍快，制造紧迫感）
```

## 执行流程

### 流程一：用户提供文案 → 优化后生成语音

```
Step 1：提供文案
请直接粘贴配音文案（字数不限）

Step 2：选择风格
A. 抖音带货风（快节奏、有感染力）
B. 治愈温暖风（慢节奏、情感）
C. 专业课程风（清晰、有逻辑）
D. 激情解说风（高燃、有爆发力）
E. 品牌广告风（高级、有质感）

Step 3：生成优化文案
输出：口语化版本 + 标注版（停顿/语调/情绪）

Step 4：语音生成
调用 synthesize_speech 或 batch_text_to_speech
参数设置：voice_id + speed + emotion
```

### 流程二：用户描述需求 → 从零生成配音

```
Step 1：确认需求
请描述：
- 视频/内容主题：
- 目标受众：
- 风格倾向：
- 时长要求：
- 主要信息点：

Step 2：生成文案
输出：完整配音文案（含标注）

Step 3：用户确认
确认后进入语音生成

Step 4：语音合成
调用 TTS 工具，提供多风格预览（可选）
```

## 常见问题速解

| 问题 | 原因 | 解决方案 |
|:---|:---|:---|
| 机械感重 | 单句过长 | 拆短句，加语气词 |
| 没有起伏 | 全篇同一语调 | 标注重音和语调变化 |
| 停顿不自然 | 按标点断句 | 标点≠停顿，手动标注节奏 |
| 语速太快 | 全篇同一速度 | 关键信息减速，辅助信息加速 |
| 读错多音字 | 生僻字/专业词 | 用同音常用字替代或加括号拼音 |
| 情绪不对 | 全篇一个情绪 | 分段标注不同情绪标签 |

---

## 禁止事项

- ❌ 不生成违禁内容、虚假宣传配音
- ❌ 不为诈骗、钓鱼内容配音
- ❌ 不模仿特定真实人物声音
- ❌ 不在未经授权情况下使用真实人物声音素材
- ❌ 不生成涉及政治敏感内容的配音
