# 人体工程学与面积指标规范

## 一、人体工程学尺寸规范

### 通道宽度标准

| 通道类型 | 宽度范围 | 适用场景 |
|----------|----------|----------|
| 主通道 | 2700-3600mm | 2-4人并行，适合主要人流走廊 |
| 次通道 | 1800-2700mm | 2-3人并行，适合功能区内部通道 |
| 服务通道 | 750mm | 单人通行，适合后勤补给 |
| 餐桌间距 | ≥750mm | 服务通道最小宽度 |
| 餐厅走道净宽 | ≥1100mm | 人体工程学最小舒适宽度 |

### 服务台高度规范

| 类型 | 高度 | 用途 |
|------|------|------|
| 总服务台（外部） | 1050-1100mm | 客人侧操作面 |
| 总服务台（内部） | 850-900mm | 员工侧操作面 |
| 礼宾服务台 | 1050-1100mm | 行李服务 |
| 吧台（站姿） | 1100-1200mm | 站立服务 |
| 吧台（坐姿） | 750-800mm | 吧凳配套 |

### 就坐空间规范

| 类型 | 深度/宽度 | 说明 |
|------|----------|------|
| 沙发深度 | 800-900mm | 人体舒适就坐深度 |
| 扶手椅宽度 | 550-700mm | 单人座位宽度 |
| 餐椅高度 | 450-480mm | 标准餐椅高度 |
| 沙发座面高度 | 400-450mm | 人体工程学舒适高度 |

## 三、空间布局原则

### 人体活动区域

- **站立区域**：每人约0.3-0.5㎡
- **就坐区域**：每人约1.2-1.5㎡（不含通道）
- **行走区域**：通道宽度不小于900mm

### 功能区最小面积

| 功能区 | 最小面积 | 适用规模 |
|--------|---------|----------|
| 小包间（4-6人） | 20-30㎡ | 圆桌φ1200-1370mm |
| 中包间（6-8人） | 35-45㎡ | 圆桌φ1500mm |
| 大包间（10-12人） | 50-70㎡ | 圆桌φ1800-2000mm |
| 无障碍卫生间 | 4.5㎡ | 含轮椅回转空间 |

## 四、疏散与安全

### 疏散宽度指标

- 疏散楼梯最小宽度：1200mm
- 疏散走道最小宽度：1100mm
- 疏散出口最小宽度：900mm
- 客房疏散路径宽度：≥1000mm

### 安全间距

- 餐桌与墙面最小间距：600mm
- 餐桌与服务通道最小间距：450mm
- 固定障碍物与通道边缘：≥300mm
