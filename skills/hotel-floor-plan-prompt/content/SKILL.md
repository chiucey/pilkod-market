# 酒店平面布置图AI出图提示词生成技能

## 技能概述

本技能用于分析酒店建筑空白平面图，基于酒店设计SOP规范和设计标准，生成符合建筑结构约束的AI绘图提示词，输出五星级酒店平面布置方案。

## 输入要求

### 必需输入
- **建筑平面图**：空白平面图（JPG/PNG/PDF格式），需包含轴线标注、结构柱位置、承重墙标识
- **建筑基本信息**：
  - 建筑尺寸（横向×纵向）
  - 轴线系统
  - 入口方向
  - 电梯和楼梯位置

### 可选输入
- 建筑形态描述（U型/C型/矩形等）
- 具体功能区域需求
- 设计风格偏好

## 工作流程

### 步骤1：建筑条件分析

1. **识别建筑基本信息**：
   - 横向总长度（轴线范围，如1-9轴）
   - 纵向总跨度（轴线范围，如A-H轴）
   - 建筑形态（不规则U型、C型或规则矩形）

2. **识别结构约束**：
   - 承重墙位置（禁止改动区域）
   - 结构柱位置（黑色实心方块标注）
   - 管道井位置（不可移动）
   - 电梯井位置（固定）
   - 楼梯位置

3. **识别入户方向**：
   - 主入口位置（如9-E轴、9-D轴区域）
   - 入口方向（由东向西等）
   - 门廊深度、门斗尺寸

### 步骤2：空间配置规划

根据五星级酒店标准配置，必须包含以下功能空间：

| 功能区域 | 具体要求 |
|----------|----------|
| 大堂接待区 | 门厅、总服务台（L形9-12米）、礼宾服务区（30-50个行李寄存位）、等候休息区 |
| 餐饮区域 | 全日餐厅（120-180餐位）、开放式厨房 |
| 厨房后勤区 | 主厨房、备餐间、收货区、储藏间、员工更衣淋浴区、垃圾处理区 |
| 会议宴会区 | 多功能厅（400-600㎡可灵活分隔）、宴会前厅、储藏间 |
| 中餐包间区 | 6-10个不同规格包间（大包10-12人、中包6-8人、小包4-6人） |
| 公共卫生间 | 男卫、女卫、无障碍卫生间 |

### 步骤3：设计规范应用

#### 人体工程学尺寸规范
- 主通道宽度：2700-3600mm（2-4人并行）
- 次通道宽度：1800-2700mm（2-3人并行）
- 服务通道宽度：750mm
- 总服务台高度：1050-1100mm（外部）、850-900mm（内部）

#### 餐饮空间尺寸规范
- 最小四人圆桌直径：1220mm
- 最佳六人圆桌直径：1830mm
- 扶手椅宽度：550-700mm
- 沙发深度：800-900mm

#### 家具尺度规范
- 单人沙发（组合式）：W1955mm×D839mm
- 三人沙发高度：863mm
- 扶手椅：W774mm×D685mm×H635mm
- 休息茶几：W1549mm×D863mm×H711mm

#### 面积指标规范
- 酒吧每席：1.1-1.7㎡
- 咖啡厅每座：1.1-1.7㎡
- 总服务台（200间客房）：18.5㎡
- 总服务台（400间客房）：30.0㎡
- 礼宾服务区：10-15㎡
- 电梯厅前室：最小15㎡

### 步骤4：动线设计

#### 三类动线必须分离
1. **客人动线**：主入口→门厅→服务台→电梯厅/餐厅/会议室
2. **服务动线**：与客人动线完全分离
3. **后勤补给动线**：从货梯进入，不经过公共区域

#### 行李动线
- 沿边缘区域
- 不穿越座位区

### 步骤5：材质与色彩规范

#### 材质规范
- 地面：米白色大理石
- 服务台：水磨石或大理石
- 沙发：高端布艺配皮革点缀
- 吧台细节：核桃木和黄铜金属
- 天花：白色石膏板配间接照明灯槽

#### 色彩规范
- 主色调：暖白色和柔灰色（NCS S 1000-S 1500）
- 点缀色：深棕色和暖金色（NCS S 6030-S 5030）

#### 设计风格
- 现代奢华融合地方特色文化
- 非对称布局
- 温暖典雅氛围
- 动静分区合理
- 流线清晰高效

## 输出格式

### 标准格式出图提示词

#### 中文版结构

```
设计一个五星级高端酒店一层平面布置图。

建筑约束条件：
- 整体规模：横向约XX米（轴线1至9），纵向约XX米（轴线A至H）
- 建筑形态：XXX型布局
- 承重墙位置：禁止任何改动
- 结构柱位置：保持不动
- 管道井位置：禁止移动
- 电梯位置：固定
- 楼梯位置：固定

必须配置的功能空间：
[大堂接待区、餐饮区域、厨房后勤区、会议宴会区、中餐包间区、公共卫生间详细描述]

动线设计要求：
[客人动线、服务动线、行李动线、后勤补给动线]

材质规范：[具体材质描述]

色彩规范：[主色调和点缀色]

设计风格：[设计理念和风格描述]
```

#### 英文版结构

对应中文版内容，提供完整英文翻译。

### 平面布置图输出标准

#### 图纸内容要求
- 轴线与尺寸标注：完整的轴线编号系统
- 功能区域标识：大堂、餐厅、厨房、会议室、包间、公卫等
- 家具布置图：完整标注所有家具位置、尺寸和数量
- 人流与物流标注：客人动线、服务动线、后勤动线
- 材质标注说明：各区域地面材质变化
- 索引与图例：家具符号、材质符号、尺寸标注说明

#### 输出格式要求
- 绘图比例：1:100
- 线型规范：承重墙（加粗实线）、新建墙体（中粗实线）、家具轮廓（细实线）
- 色彩规范：2-3色设计打印模式
- 标注字体：中英文双语标注，黑体或宋体

## 约束条件

### 绝对禁止
1. 改动原始建筑结构
2. 移动承重墙位置
3. 移动管道井位置
4. 修改建筑外轮廓

### 空间优先级
1. 必须空间：大堂、餐厅、厨房、会议室、包间、公卫
2. 可选空间：根据建筑形态灵活配置
