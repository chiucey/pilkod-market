# 医学PPT工作流详细说明

## 阶段0：初始化与数据验证

### 必填信息清单

| 序号 | 信息项 | 说明 | 验证标准 |
|------|--------|------|----------|
| 1 | KOL领域与身份 | 肿瘤内科主任医师/心血管PI/神经科青年学者等 | 非空 |
| 2 | 使用场景类型 | 单人汇报/小型圆桌会/卫星会演讲/学术沙龙 | 需明确 |
| 3 | 听众构成 | 纯专家/带学生团队/药企参与/混合型 | 需明确 |
| 4 | 报告主题与核心信息点 | 例：新型XX抑制剂在难治性患者中的探索性研究结果 | 非空 |
| 5 | 产品名称与植入方式 | 代号XXX药物/某机制代表性分子 | 可选（若涉及产品） |
| 6 | 资料完整性 | 完整研究数据/已发表论文支持/初步数据 | 需评估 |
| 7 | 视觉风格偏好 | 国际会议风/国内学术风/极简科技感/温暖人文向 | 需明确 |
| 8 | 禁忌要求 | 不得竞品对比/避免直接疗效宣称/禁用特定术语 | 可选 |

### 数据完整度计算

```
完整度 = (已填写项数 / 8) × 100%
```

- **≥80%**：继续分析
- **<80%**：输出补充请求

## 阶段1：内容精准性与专业性评估

### 1.1 内容精准性审查

**检查项**：
- [ ] 术语使用是否规范（ICD编码、治疗分型）
- [ ] 适应证表述是否准确
- [ ] 是否存在超适应证引用
- [ ] 是否存在夸大结论

### 1.2 循证强度评估

**GRADE证据等级**：
- 高（A）：RCT、Meta分析
- 中（B）：系统综述、队列研究
- 低（C）：病例对照研究、病例系列
- 极低（D）：专家意见、个案报告

**Oxford CEBM证据等级**：
- Level 1：系统性综述、随机对照试验
- Level 2：队列研究、病例对照研究
- Level 3：病例系列、横断面研究
- Level 4：专家意见、基础研究

### 1.3 写作结构诊断

**"凤头—猪肚—豹尾"黄金结构**：

| 部分 | 任务 | 检查点 |
|------|------|--------|
| 凤头 | 开场直击临床痛点 | 能否在30秒内引发听众关注 |
| 猪肚 | 主体遵循逻辑链 | 机制→疗效→安全性→卫生经济学 |
| 豹尾 | 总结升华 | 给出清晰的临床行动建议 |

### 1.4 循证数据嵌入

**要求**：
- 标明来源：PMID/DOI/指南名称+年份
- 标明样本量、研究设计类型
- 标明证据等级

## 阶段2：视觉设计与布局优化

### 2.1 信息层级控制

**单一核心信息原则**（One Message Per Slide）

标题应具结论性：
- ❌ "概述"、"相关数据"
- ✅ "PD-L1高表达患者ORR提升2.3倍"

### 2.2 布局密度标准

| 项目 | 建议值 |
|------|--------|
| 段落 | ≤6行 |
| 要点 | ≤6项 |
| 每项字数 | ≤12字 |

### 2.3 字体规范

| 用途 | 中文 | 英文 |
|------|------|------|
| 标题 | 微软雅黑/思源黑体 | Arial/Helvetica |
| 正文 | 微软雅黑/思源黑体 | Arial/Helvetica |

### 2.4 图表选择指南

| 数据类型 | 推荐图表 |
|----------|----------|
| 生存分析 | Kaplan-Meier曲线 |
| 分类比较 | 柱状图 |
| 趋势分析 | 折线图 |
| 相关性 | 散点图 |
| 构成比 | 饼图（≤6类） |
| 效应量 | 森林图 |

## 阶段3：合规审查

### 3.1 风险等级定义

| 等级 | 标识 | 判定标准 | 处理方式 |
|------|------|----------|----------|
| R1 | 绿色 | 充分证据支持，表述中立 | 可继续推进 |
| R2 | 黄色 | 需加限定条件或脚注 | 建议补充说明 |
| R3 | 红色 | 存在实质性合规隐患 | 建议删除或重构 |

### 3.2 高风险表述识别

**警告级**：
- "治愈"、"痊愈"
- "领先"、"首选"
- 未经批准宣称

**提示级**：
- 数据来源不明
- p值未标注
- 图表无误差线

### 3.3 合规替代表述库

| ❌ 禁用表述 | ✅ 合规替代表述 |
|------------|-----------------|
| "显著优于" | "在XX研究中显示数值上的改善趋势" |
| "安全无副作用" | "总体安全性良好，常见不良反应见说明书" |
| "一线首选" | "根据2024 CSCO指南，列为I级推荐（1A类证据）" |
| "根治" | "实现持续缓解" |
| "延长生命X年" | "中位OS延长X个月（需注明人群与CI）" |

## 阶段4：软植入策略

### 4.1 三轴评估模型

```
机会点评分 = 科学合理性 × 植入隐蔽性 × 影响潜力
```

### 4.2 植入强度标识

| 标识 | 强度 | 说明 |
|------|------|------|
| 🔹 | 【轻量提示】 | 仅提及机制/通路（最安全） |
| 🔸 | 【中度关联】 | 引用联合用药趋势或未满足需求 |
| 🔺 | 【增强引导】 | 引用产品所在类别临床进展（需谨慎） |

### 4.3 植入机会自查清单

1. 当前内容是否涉及产品适应症领域？
2. 是否存在明确的未满足临床需求描述？
3. 是否有机会提及相关生物标志物或病理机制？
4. 引用文献中是否有我可借鉴的研究类型？
5. KOL是否有过往发表过与我方机制相关的研究？

## 阶段5：效果追踪

### 5.1 反馈采集维度

- KOL口头评价摘要
- 第三方观察记录
- 提问环节内容整理
- 自我复盘

### 5.2 三维诊断模型

1. **学术可信度**：证据链、统计表述、文献时效性
2. **叙事流畅性**：逻辑链自然度
3. **软植入有效性**：时机、频率、表达方式

### 5.3 KOL-PPT进化档案

| 字段 | 说明 |
|------|------|
| KOL专业方向 | 目标KOL的专业领域 |
| 既往立场 | 支持/中立/怀疑 |
| 沟通风格 | 直接/委婉 |
| 使用场景 | 拜访类型 |
| 关键反馈 | 产品态度变化 |
| 已实施优化项 | 本次改进内容 |
| 待验证假设 | 下次验证方向 |
