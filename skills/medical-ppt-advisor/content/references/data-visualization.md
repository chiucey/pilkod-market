# 医学数据可视化最佳实践

## 一、图表选择原则

### 1.1 按数据类型选择

| 数据类型 | 推荐图表 | 说明 |
|----------|----------|------|
| 生存数据 | Kaplan-Meier曲线 | 展示时间-事件数据 |
| 分类计数 | 柱状图/条形图 | 对比不同类别 |
| 连续变量 | 箱线图/散点图 | 展示分布和相关性 |
| 趋势变化 | 折线图 | 展示随时间变化 |
| 构成比 | 饼图/堆叠图 | 展示组成部分（≤6类） |
| 效应量 | 森林图 | 展示多研究汇总 |
| 相关性 | 热力图 | 展示矩阵关系 |

### 1.2 避免的图表类型

- ❌ 3D图表（扭曲数据比例）
- ❌ 饼图超过6类
- ❌ 双Y轴图表（易误导）
- ❌ 截断坐标轴的图表

## 二、生存分析图表规范

### 2.1 Kaplan-Meier曲线标准

**必须包含**：
- [ ] X轴：时间（单位明确）
- [ ] Y轴：生存率（0-100%或0-1）
- [ ] 删失标记（垂直短线）
- [ ] 风险人数表（at-risk table）
- [ ] 图例
- [ ] Log-rank检验p值
- [ ] HR及95%CI（若适用）
- [ ] 生存中位数及95%CI

**推荐格式**：
```
图例: HR=0.65 (95%CI: 0.48-0.88), p=0.005
```

### 2.2 亚组分析森林图

**标准结构**：
```
            HR (95% CI)     p值
总体         0.65 (0.48-0.88)  0.005
───────────────────────────────
亚组1
  类别A     0.55 (0.30-0.90)  0.020
  类别B     0.72 (0.45-1.10)  0.120
───────────────────────────────
亚组2
  ...
```

## 三、临床试验数据图表

### 3.1 瀑布图（Waterfall Plot）

**适用场景**：肿瘤大小变化（最佳总体缓解）

**要求**：
- Y轴：靶病灶相对于基线的最佳变化百分比
- 零线：基线
- 颜色区分：缓解（蓝色）/进展（红色）/稳定（灰色）
- 标注每位患者的最佳缓解

### 3.2 游泳图（Swimmer Plot）

**适用场景**：展示多个受试者的治疗/事件时间线

**要求**：
- 每个受试者一行
- 标注关键事件（应答/进展/停药）
- 颜色区分应答程度
- 随访时间对齐

### 3.3 蜘蛛图（Spider Plot）

**适用场景**：个体患者靶病灶随时间变化趋势

**要求**：
- 每个患者一条线
- 标注疾病进展时间点
- 基线为零的水平参考线

## 四、安全性数据可视化

### 4.1 不良事件发生率图

**推荐格式**：柱状图对比

**要求**：
- 按系统分类（SOC）排列
- 按严重程度分组（任意级别 vs ≥3级）
- 误差线表示95%CI
- 标注样本量

### 4.2 治疗相关不良事件热力图

**适用场景**：多中心/多剂量组安全性对比

**结构**：
- 行：不良事件类型
- 列：研究组别
- 颜色/数值：发生率

## 五、统计图形标注规范

### 5.1 显著性标记

| 标记 | 含义 | 使用场景 |
|------|------|----------|
| ns | p ≥ 0.05 | 无统计学差异 |
| * | p < 0.05 | 显著 |
| ** | p < 0.01 | 高度显著 |
| *** | p < 0.001 | 极显著 |
| **** | p < 0.0001 | 高度极显著 |

### 5.2 置信区间标注

**推荐格式**：
- 数值：±1.5 (95% CI: 0.8-2.2)
- 图形：误差棒从CI下界到上界

### 5.3 数据来源脚注

**标准格式**：
```
来源：[研究者姓氏]，等. [文章标题]. [期刊名]. [年份];[卷号]:[页码]. DOI: xxxxxxxxxx
或：[指南名称]. [发布机构]. [年份].
```

## 六、颜色使用规范

### 6.1 学术图表推荐配色

**单色渐变（用于有序数据）**：
```
#08519C → #3182BD → #6BAED6 → #BDD7E7 → #EFF3FF
```

**分类数据（区分度最高）**：
```
#1F77B4 蓝色   #FF7F0E 橙色
#2CA02C 绿色   #D62728 红色
#9467BD 紫色   #8C564B 棕色
```

**对比色（用于二元比较）**：
```
治疗组：#0072B2（蓝色）
对照组：#E69F00（橙黄色）
```

### 6.2 无障碍设计

- 确保红绿区分度足够（色盲友好）
- 考虑使用图案区分
- 添加文字标签

## 七、图表质量检查清单

### 7.1 基础检查
- [ ] 坐标轴有清晰标签
- [ ] 单位标注正确
- [ ] 图例完整且清晰
- [ ] 标题具描述性

### 7.2 数据准确性
- [ ] 数据与原文一致
- [ ] 误差线/置信区间计算正确
- [ ] 比例/百分比计算正确

### 7.3 视觉可读性
- [ ] 字体大小足够（≥8pt）
- [ ] 线条粗细合适（0.5-2pt）
- [ ] 无过度装饰
- [ ] 留白适当

### 7.4 合规性
- [ ] 标注p值/HR及CI
- [ ] 标注数据来源
- [ ] 添加利益声明（如适用）
