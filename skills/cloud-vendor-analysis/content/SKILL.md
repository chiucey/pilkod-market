# 云厂商产品竞品分析

## 输入收集

收到分析请求后，通过表单或对话收集：

1. **产品/方案类型**：用户需求的产品类别（ECS/数据库/存储/网络等）
2. **具体业务场景**：用户要解决的技术问题或业务需求
3. **对比厂商范围**：
   - 全部四家（默认）：阿里云、华为云、腾讯云、火山引擎
   - 指定厂商组合
4. **特殊约束**：预算限制、合规要求、技术限制等

## 调研执行

### 信息源优先级

1. **官方文档**（必选）：
   - 阿里云：https://www.aliyun.com/documentation
   - 华为云：https://support.huaweicloud.com/
   - 腾讯云：https://cloud.tencent.com/document/product
   - 火山引擎：https://www.volcengine.com/docs/

2. **高可信度论坛**：
   - 知乎云原生/云计算话题
   - CSDN云计算板块
   - InfoQ技术社区
   - v2ex云服务讨论区

### 调研维度

| 维度 | 说明 |
|------|------|
| 核心规格 | CPU/内存/存储/网络等基础参数 |
| 功能特性 | 独特功能、增值服务、配套工具 |
| 价格体系 | 定价模式、折扣政策、长期合约 |
| 可用区分布 | 机房覆盖、延迟表现 |
| 生态集成 | 与其他产品的联动能力 |
| 运维管理 | 控制台体验、监控告警、API完备性 |
| 安全合规 | 认证情况、安全能力、审计日志 |

## 分析输出

### 1. 产品对比矩阵

以表格形式呈现关键指标对比，标注各厂商优劣。

### 2. 竞争力分析

- **自身优势**：功能领先点、成本优势、生态优势
- **竞品威胁**：竞品的差异化卖点、定价策略
- **市场定位**：各厂商在目标细分市场的表现

### 3. 防守方案

根据分析结果输出针对性建议：

| 场景 | 防守策略 |
|------|----------|
| 价格竞争 | 成本优化方案、长期合约优惠、量级折扣 |
| 功能差距 | 差异化功能开发路线图、替代方案 |
| 生态缺失 | 快速集成计划、合作伙伴策略 |
| 合规要求 | 认证获取计划、定制化方案 |

### 4. 推荐配置

给出针对用户场景的最优产品推荐和配置建议。

## 质量标准

- 信息源必须包含至少3个厂商的官方文档
- 对比维度至少覆盖核心规格、功能、价格、可用区
- 防守方案必须有具体可执行性，不能是泛泛而谈
- 如信息不足，明确标注"待确认"项
