# 文本清洗规则

严格删除：

- 广告
- sponsor内容
- 无意义寒暄
- 客套话
- 冗长铺垫
- 重复表达
- 无价值免责声明
- 与主题弱相关的跑题内容
- 播客式闲聊

保留：

- 核心观点
- 关键机制
- 实验内容
- 研究引用
- 关键案例
- 核心比喻
- 关键原话
- 关键定义
- 关键行为建议
- 与减肥/行为改变相关的隐性内容

不要输出逐字稿。

而是输出：

“经过结构化重构后的高密度知识文本”。
