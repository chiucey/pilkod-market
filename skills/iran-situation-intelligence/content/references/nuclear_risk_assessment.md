## IAEA核查机制

### 保障监督措施
1. **常规核查**
   - 设施访问
   - 物料平衡
   - 监控记录

2. **非常规核查**
   - 疑似地点访问
   - 环境采样
   - 信息验证

### 关键报告节点
- **季度报告**：常规活动更新
- **特别报告**：异常发现时
- **紧急报告**：重大违规时

### 典型警告信号
```
□ IAEA无法进入某设施
□ 核材料盘存差异
□ 申报信息不一致
□ 铀痕迹异常
□ 清洗活动痕迹
```

## 情景分析

### 情景A：外交回归JCPOA（概率：中）
- 美国重返协议
- 制裁部分解除
- 浓缩活动回退
- 油价稳定或下降

### 情景B：渐进式突破（概率：中-高）
- 逐步提高浓缩丰度
- 极限施压策略
- 国际制裁加码
- 油价温和上涨

### 情景C：核危机（概率：低）
- 达到武器级浓缩
- 国际孤立加剧
- 军事打击风险
- 油价大幅上涨

### 情景D：内部政变（概率：低）
- 强硬派被取代
- 政策突变
- 高度不确定性
- 市场剧震

## 快速评估检查清单

当收到核相关信号时：

1. **技术真实性？**
   - [ ] 是否来自IAEA/官方
   - [ ] 独立验证可能

2. **浓缩丰度？**
   - [ ] <5% / 5-20% / >20%

3. **可逆性？**
   - [ ] 是否为政策选择
   - [ ] 国际压力效果

4. **时间线？**
   - [ ] 多久达到关键节点

5. **市场影响？**
   - [ ] 油价/金价/股市反应

6. **升级路径？**
   - [ ] 各方下一步可能
