## 企业信号识别指南

### 高优先级信号
1. **减产/停运公告**
   - 官方减产声明
   - 不可抗力通知
   - 设施关闭公告

2. **运输中断**
   - 霍尔木兹通行限制
   - 保险费调整
   - 租船合同取消

3. **炼厂负荷变化**
   - 开工率大幅调整
   - 采购来源转移
   - 库存异常变化

4. **采购模式异常**
   - 突然转向非伊朗供应商
   - 库存异常积累
   - 长期合同变更

### 信号可信度分级
```
企业声明（官网） → 中等可信，需媒体交叉验证
社交媒体（非官方） → 低可信，需多源确认
行业传闻 → 极低可信，仅作预警参考
```

## 信息冲突处理原则

当多个信息源出现冲突时：
1. **政府声明 vs 媒体**：政府声明优先
2. **多国政府声明冲突**：美国优先，盟友次之
3. **企业信号 vs 政府**：政府优先（制裁合规）
4. **行业数据 vs 企业**：行业机构数据优先
5. **无法判定时**：标注"存疑"，不作为结论
