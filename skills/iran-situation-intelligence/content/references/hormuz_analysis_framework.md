## 地理与战略重要性

### 基本数据
| 指标 | 数值 |
|------|------|
| 宽度 | 21-60海里（最窄处） |
| 长度 | 约195公里 |
| 平均水深 | 70米 |

| 占全球海运石油 | ~30% |

### 主要参与者
- **伊朗**：控制北岸，拥有霍尔木兹甘省军事基地
- **阿曼**：控制南岸，与美国有军事合作
- **美国**：第五舰队驻扎，海湾合作
- **沙特/UAE**：主要石油出口国

## 情景分析

### 情景A：有限骚扰（概率：中）
- 伊朗干扰而非封锁
- 美军威慑但不升级
- 油价短期波动10-15%
- 持续时间：数日至数周

### 情景B：局部封锁（概率：低-中）
- 伊朗封锁部分航道
- 美国牵头国际响应
- 油价波动20-30%
- 持续时间：数周至数月

### 情景C：全面封锁（概率：极低）
- 战争爆发导致封锁
- 全球能源危机
- 油价波动>40%
- 持续时间：取决于冲突结束

### 情景D：外交缓和（概率：中-高）
- 美伊间接谈判
- 制裁暂时放松
- 地区局势降温
- 油价回落或稳定
