# 美股分析技能

提供全面的美国股票市场分析能力，包括实时价格、财务数据、新闻资讯和统计分析。

## 支持的功能

### 1. 股票价格查询
- 获取历史股价数据（支持日/周/月级别）
- 查询实时价格和涨跌幅
- 支持时间范围自定义

### 2. 股票基本信息
- 公司概况和基本信息
- 实时行情数据
- 关键统计数据

### 3. 财务数据分析
- 财务报表指标
- 盈利能力分析
- 估值指标

### 4. 股票新闻
- 最新公司新闻
- 行业动态
- 市场分析报告

### 5. 股票洞察分析
- 市场情绪分析
- 趋势判断
- 风险评估

## 使用方式

### 查询股票价格
```
输入: 股票代码（如AAPL）、开始日期、结束日期、间隔（1d/1w/1m）
示例: 查询苹果公司(AAPL)近一年的股价数据
```

### 获取股票新闻
```
输入: 股票代码、新闻数量
示例: 获取英伟达(NVDA)最新10条新闻
```

### 分析财务数据
```
输入: 股票代码
示例: 分析特斯拉(TSLA)的财务指标
```

## 输出格式

分析结果以结构化方式呈现：
- **数据表格**: 股价、财务指标等以清晰表格展示
- **趋势图表**: 支持生成可视化图表
- **文字分析**: 提供专业的市场分析和见解
- **关键指标**: 突出显示重要财务和交易数据

## 注意事项

1. 股票代码必须使用正确的美股代码（如 AAPL，而非 Apple）
2. 日期格式为 YYYY-MM-DD
3. 市场数据可能存在延迟
4. 历史数据查询可能受限于数据源
