# 章末钩子模式

修真网文"留存率"命门是**章末钩子**。读者每章读完决定要不要翻下一章，全看这 200-500 字。

## 三重钩子原则

每章末段必须包含至少 2 重钩子（建议 3 重全用）：

- **短期钩子**（立刻）：本章冲突未完，读者想知道结果
- **中期钩子**（5-20 章后）：新威胁/新谜题浮现，读者想看主角怎么应对
- **长期钩子**（50 章+）：身世/远古/大因果一角，读者想看终局

## 短期钩子（6 种）

1. **追杀中断**：主角刚杀了一个反派，发现反派身上有个信物 → 立刻有更强的敌人追来
2. **比斗中断**：与天骄对决打到一半，关键时刻天降异象（秘境开启/天劫/外人插手）
3. **宝物觉醒**：主角捡到的法宝突然发出异动，疑似召唤
4. **陌生人出现**：刚松口气时，一个神秘人物降临（敌友不明）
5. **消息骤变**：刚得到的好消息立刻被坏消息覆盖（盟友背叛/亲人出事）
6. **身体异变**：主角突然发现体内有异样（封印松动/第二元婴/魔气反噬）

## 中期钩子（5 种）

1. **新势力登场**：本章出现一个之前未提的势力，且对主角释放出敌意/招揽
2. **身世碎片**：主角发现一个疑似自己身世的线索（遗物/族谱/胎记）
3. **敌人报复预告**：被打脸的敌人回去报告师门，更强的对手被派出
4. **异象全宗**：宗门/王朝/整片大陆出现大异象，暗示大事将至
5. **神秘人指点**：一个高人（老怪/系统/前世记忆）突然给主角一个看似简单的任务，实则暗藏大因果

## 长期钩子（4 种）

1. **远古真相一角**：主角发现一个远古遗迹/古族/古法宝，暗示曾经有大劫
2. **预言/血脉觉醒**：某个被封印的预言/血脉之谜开始浮现
3. **域外/上界压力**：上层世界的目光开始投向主角（如飞升通道异常/上界使者下界）
4. **最终 Boss 暗线**：终极 Boss 首次以"看似无害"的方式出现（如同一门派的师兄/救过主角的恩人其实是幕后黑手）

## 钩子组合示例

### 示例 1：突破境界章

主角闭关突破 → 短期：刚突破就被守在洞府外的师兄堵门（追杀中断）→ 中期：师兄提到了一个主角从未听过的"地渊会"（新势力）→ 长期：突破瞬间，主角瞥见自己识海深处有一道远古封印松动（身世线）

### 示例 2：拍卖会章

主角低价拍得宝物 → 短期：刚付完灵石就被人跟踪（追杀中断）→ 中期：跟踪者原来是某个大势力的人，他们也在找同一件东西（势力对抗）→ 长期：宝物的上一任主人是一万年前的传奇人物，且在历史记载中"飞升失败"，但拍卖行卖的是飞升成功后才会留下的东西（远古真相矛盾）

### 示例 3：宗门大比章

主角战胜天骄 → 短期：刚下擂台就被长老叫去"问话"（被盯上）→ 中期：长老提到了一个即将开启的"上古战场"（新副本）→ 长期：长老的真实身份与主角师祖是同一时代的人（师门线暗藏大因果）

## 钩子禁忌

以下写法会直接断钩子，**不要用**：

- "主角继续修炼，明天还有比赛" —— 没有任何钩子，下一章读者不会来
- "主角成功突破了，开心地笑了" —— 情绪单薄，读者没有追更理由
- "一切归于平静" —— 修真长篇不允许平静章，平静章 = 弃书点
- "主角预感大事将至" —— 太抽象，要具体到"什么事"
