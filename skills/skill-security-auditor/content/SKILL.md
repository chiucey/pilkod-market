# Skill 安全审计器

## 功能概述

自动扫描和检查其他 Skill 文件中的安全风险、漏洞和不合规内容。输出详细的安全报告和风险等级评估。

## 工作流程

### 1. 接收目标Skill路径

接收用户提供的待审计Skill路径，格式：`/workspace/temp-skills/[skill-name]/`

### 2. 执行多维度安全扫描

#### 2.1 文件结构检查
- 验证SKILL.md存在性
- 验证_meta.json格式
- 检查敏感文件泄露（如.env、credentials）
- 扫描隐藏文件（如.ssh、*.pem、*.key）

#### 2.2 Frontmatter格式检查
- 验证必填字段（name、description）
- 检查name格式（连字符、无中文）
- 验证description包含触发短语

#### 2.3 代码安全扫描
- 检测硬编码凭证/密钥
- 检测可疑的system命令执行
- 检测文件系统逃逸风险（如../../等路径遍历）
- 检测敏感文件访问
- 检测网络请求风险
- 检测恶意脚本模式

#### 2.4 内容安全检查
- 检测敏感信息泄露
- 检测钓鱼/欺诈内容模式
- 检测不当言论模式

### 3. 生成安全报告

```
## 安全审计报告

**审计目标**: [Skill名称]
**审计时间**: [时间戳]
**风险等级**: [严重/高危/中危/低危/安全]
```

## 安全风险模式库

### 高危模式（必须拦截）
```
- 密码/密钥硬编码: password\s*=\s*["'][^"']+["']
- API密钥泄露: api[_-]?key\s*=\s*["'][^"']+["']
- 私钥文件: -----BEGIN.*PRIVATE KEY-----
- 路径遍历: \.\./.*|\.\.\\\\.*
- 危险命令: rm\s+-rf|dd\s+|mkfs|format
```

### 中危模式（需要审查）
```
- 外部网络请求到可疑域名
- 文件系统写操作到系统目录
- 长时间超时设置（可能被用于挖矿）
- Base64编码的可疑脚本
```

### 低危模式（建议优化）
```
- 缺少风险提示
- 缺少输入验证
- 过于宽泛的文件权限
```

## 错误处理

- Skill路径不存在：返回错误提示
- 权限不足：返回部分结果并说明限制
- 扫描超时：返回已扫描结果

## 注意事项

1. 仅扫描，不执行任何修改
2. 对敏感内容进行脱敏处理
3. 尊重用户隐私和机密信息
