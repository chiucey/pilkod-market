# 小红书医生账号调研技能

本技能用于在小红书平台调研全国优秀三甲医院医生的账号内容，分析爆款内容规律，为医生用户提供可参考的账号定位和内容策略。

## 调研框架

每次调研必须包含以下四个板块：

### 一、小红书平台医疗健康科普内容概览

- 平台用户规模 + 医生入驻情况
- 目标受众画像（年龄/城市/性别）
- 医疗内容监管政策动态（最新）
- 内容分发机制特点（小红书算法逻辑）

### 二、各科室内容类型与特点

每个科室分别说明：

- **科室名称**
- **内容类型**：科普图文/短视频/病例故事/实操演示/攻略指南等
- **内容特点**：该科室在小红书上的内容风格、表达方式、受众需求
- **爆款共性**：该科室最容易出爆款的内容方向
- **适合的定位类型**

### 三、案例分析

每个案例必须包含：

- **账号名**（必填）
- **科室**（必填）
- **医院**（必填，含城市，如"北京协和医院"）
- **定位类型**：科普型 / 经验型 / 工具型 / 剧情型 / 科室团队型
- **内容形式**：图文 / 短视频 / 直播
- **粉丝量级**：素人(<1万) / 成长期(1-10万) / 成熟期(10-50万) / 头部(>50万)
- **爆款内容代表**：标题 + 互动数据（如有）
- **可借鉴点**：1-2条

### 四、高互动爆款内容分析

- 爆款共同特征
- 标题规律
- 内容模式
- 互动率分析

## 内容禁入范围

**绝对禁止纳入以下科室/内容类型：**

- 医美 / 整形外科 / 皮肤科（护肤方向）
- 妇产科（含备孕/孕期/产后/妇科/产科）
- 儿科（含儿童保健/儿科全科）
- 中医科 / 针灸推拿科
- 营养科（仅当内容与减肥/医美挂钩时剔除；与消化内科/胃肠疾病相关的营养管理内容可保留）

**允许调研的科室范围：**

| 类别 | 科室 |
|------|------|
| 内科 | 心内科 / 消化内科 / 呼吸内科 / 肾内科 / 血液科 / 肿瘤科 / 感染科 |
| 外科 | 普外科 / 骨科 / 泌尿外科 / 神经外科 / 心外科 / 胸外科 |
| 其他 | 急诊科 / 重症医学科 / 神经内科 / 眼科 / 耳鼻喉科 / 口腔科 / 麻醉科 / 影像科 / 超声科 / 检验科 / 康复科 / 全科医学科 |
| 特殊 | 营养科（仅限与消化内科/胃肠疾病相关的营养管理方向） |

**账号类型**：个人医生账号（主要）+ 科室/医院官方团队账号（同等纳入）

**地理范围**：优先北上广深，全国任何城市优秀三甲医院均可

## 调研操作步骤

### 第一步：搜索账号数据

使用 `batch_web_search` 搜索以下关键词（必须含2025）：

```
小红书 三甲医院 心内科 医生账号 粉丝 2025
小红书 三甲医院 骨科 急诊科 神经内科 医生账号 2025
小红书 三甲医院 消化内科 肿瘤科 医生博主 2025
小红书 三甲医院 口腔科 眼科 耳鼻喉科 医生账号 2025
小红书 三甲医院 普外科 泌尿外科 医生 内容 2025
小红书 三甲医院 科室 官方账号 科普 2025
小红书 医生 爆款内容 互动数据 2025 最新
小红书 优秀医生账号 全国三甲医院 2025
```

### 第二步：搜索平台与政策

```
小红书医疗内容治理 2025 最新政策
国家卫健委 网红医生 政策 2025
小红书医生认证 资质要求 最新
```

### 第三步：整理案例数据

按案例分析字段要求整理，每个案例必须包含：

- 账号名 + 科室 + 医院（含城市）
- 定位类型 + 内容形式 + 粉丝量级
- 爆款内容 + 可借鉴点

同一科室至少纳入2-3个案例。

### 第四步：输出调研报告

按四大板块完整输出，第二板块必须按科室逐一展开。

## 数据年份要求

- **优先**：2025年数据
- **可接受**：2024年数据
- **禁止**：2022年及以前的旧数据作为主要引用来源

## 注意事项

- 案例必须来自小红书平台，优先选择优秀三甲医院医生
- 科室团队账号与个人账号同等对待
- 爆款内容需说明互动数据（点赞/收藏/评论）
- 如搜索结果不理想，扩大关键词或搜索其他变体
- 涉及具体医生账号信息，以公开可查数据为准
- 搜索关键词必须包含年份"2025"，如无结果再降级至"2024"
