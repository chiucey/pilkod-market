# 产品介绍配音技能

## 声音配置

### 英文产品介绍
- **推荐声音**: `English_SereneWoman`
- **声音描述**: 宁静、平和、优雅
- **参数设置**:
  - speed: 0.9 (稍慢，展现从容气质)
  - pitch: 0
  - emotion: neutral

### 中文产品介绍
- **推荐声音**: `Chinese (Mandarin)_Sweet_Lady`
- **声音描述**: 温柔、平和、专业
- **参数设置**:
  - speed: 0.9
  - pitch: 0
  - emotion: neutral

## 适用场景

1. **电商产品介绍** - 展现产品的高端品质
2. **品牌宣传片** - 传递品牌调性与价值
3. **产品发布会** - 正式场合的专业旁白
4. **App/软件介绍** - 科技产品的温和引导

## 文案风格指南

### 高端感文案特征
- 使用简洁有力的短句
- 避免过度夸张的修饰词
- 注重节奏感和留白
- 强调品质、工艺、设计理念

### 推荐句式
- "精选 [材质]，只为 [价值主张]"
- "每一处细节，都经过 [匠心考量]"
- "为您呈现，[核心卖点]"

## 输出要求

- 音频格式: MP3
- 采样率: 32000 或 44100
- 比特率: 128000 或更高

## 执行流程

1. 分析产品信息和目标受众
2. 确定语言（中文/英文）
3. 选择对应声音配置
4. 生成配音并保存
