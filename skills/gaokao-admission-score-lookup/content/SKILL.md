# 高考录取分数线查询技能

本技能帮助用户快速查询高校历年高考录取分数线数据，确保数据来源官方可靠，为高考志愿填报提供准确参考。

## 核心功能

1. **高校信息识别**：准确识别用户输入的高校名称
2. **官方网站定位**：快速找到高校招生官方网站
3. **历年数据查询**：获取2021年至2025年的录取分数线数据
4. **官方数据验证**：与全国高考成绩查询官方网站进行交叉验证
5. **专业分类整理**：按省份、专业、年份等多维度整理数据

## 工作流程

### 步骤一：识别高校名称

收到用户查询请求后，首先明确识别目标高校：

- 提取高校全称或简称
- 对于易混淆的高校名，进行二次确认
- 记录用户查询的具体专业（如果有）

### 步骤二：定位官方网站

通过以下渠道定位高校官方招生网站：

- 使用搜索引擎搜索"[高校名称]本科招生网"
- 优先选择以.edu.cn结尾的官方网站
- 确认网站ICP备案信息与高校名称一致
- 查找招生信息栏目中的历年录取数据板块

### 步骤三：提取历年数据

在高校官方网站上查找并提取：

- 各省份本科一批/二批录取分数线
- 各专业录取最高分、最低分、平均分
- 文科/理科分类数据
- 特殊类型招生（自主招生、高校专项等）数据

### 步骤四：官方数据验证

为确保数据准确性，进行交叉验证：

- 访问省级教育考试院官方网站核实数据
- 对比阳光高考平台（教育部指定平台）数据
- 检查数据与官方公布的分省计划是否匹配
- 标注数据来源，供用户核实

### 步骤五：结果呈现

向用户清晰呈现查询结果：

- 整理为结构化表格形式
- 标注数据来源和查询时间
- 提醒用户以官方最终公布为准
- 提供官方联系方式供用户确认

## 数据验证标准

为确保数据准确性，必须遵循以下验证标准：

| 验证项目 | 要求 | 不通过处理 |
|---------|------|-----------|
| 来源可靠性 | 必须是高校官网或官方指定平台 | 标注"待核实"并说明来源 |
| 时间准确性 | 明确标注数据对应年份 | 不可使用模糊年份 |
| 分数完整性 | 包含最高分、最低分、省控线 | 缺失项单独标注 |
| 省份一致性 | 注明录取省份和科类 | 不可混用不同省份数据 |
| 格式规范性 | 分数单位统一为"分" | 不一致的进行换算说明 |

## 注意事项

### 数据准确性保障

1. **双重验证原则**：所有数据必须经过高校官网和省级考试院双重核实
2. **时效性标注**：明确标注数据发布时间，避免使用过期数据
3. **不确定性处理**：对于存疑数据，必须明确标注并建议用户联系高校确认
4. **版本记录**：记录每次数据查询的版本，便于追溯核实

### 用户提醒义务

1. **免责声明**：明确告知用户数据仅供参考，不作为志愿填报唯一依据
2. **官方渠道推荐**：建议用户通过高校官方招生热线和现场咨询确认
3. **风险提示**：提醒用户关注招生政策变化、年份差异等风险因素
4. **时效性提醒**：告知用户录取分数线每年可能有较大变化

### 特殊情况的处理

1. **新设专业**：若查询专业为新设专业，无历年数据时明确说明
2. **合并招生**：多专业合并招生时，拆分为具体专业分别说明
3. **大类招生**：说明大类包含的具体专业及分流情况
4. **中外合作**：标注学费标准、合作院校等特殊说明

## 质量检查清单

完成查询后，必须检查以下项目：

- [ ] 高校名称识别准确无误
- [ ] 官方网站已验证，链接可访问
- [ ] 数据年份明确，无模糊表述
- [ ] 最高分、最低分、省控线数据完整
- [ ] 已在至少一个官方渠道完成验证
- [ ] 数据来源已明确标注
- [ ] 免责声明已包含
- [ ] 用户提醒已完整传达
- [ ] 结果呈现格式规范清晰

## 禁止行为

1. **禁止臆测数据**：不可编造或推算未核实的数据
2. **禁止模糊表述**：不可使用"大概"、"左右"等模糊词汇描述分数
3. **禁止唯一性承诺**：不可承诺数据为唯一标准或保证录取
4. **禁止商业引导**：不可引导用户选择特定机构或服务
5. **禁止跨省通用**：不可将某省数据作为其他省份参考
