# 小红书自动发布笔记

## 工作原理

使用 OpenClaw Browser Relay 控制用户的 Chrome 标签页，自动化操作小红书创作者中心。

## 前置条件（用户需要做的）

### 第一步：安装 OpenClaw Browser Relay 插件
插件已安装（如未安装从 Chrome Web Store 搜索 "OpenClaw Browser Relay"）

### 第二步：配置插件连接信息
1. 打开 Chrome，点击工具栏右上角的 **OpenClaw Browser Relay 图标**
2. 点击 **Options（选项）**
3. 填写以下信息：
   - **Port**：`18792`
   - **Gateway Token**：空白（不需要填）
4. 点击保存

### 第三步：打开创作者中心并连接
1. 在 Chrome 打开 `https://creator.xiaohongshu.com` 并**登录你的账号**
2. 登录后，点击 Browser Relay 插件图标
3. 图标显示 **ON** 即表示连接成功

> 如果插件显示 `!` 或连接失败，请告诉我，我们来排查。

## 使用方式

用户说"发布笔记"、"自动发小红书"、"帮我发这篇"时激活。

### 需要的信息
- **标题**：笔记标题
- **正文**：笔记正文内容
- **话题**：（可选）要添加的话题，如 `#游牧文化`
- **图片**：已在内容工厂选好，Skill 自动获取

### 发布流程
1. 打开创作者中心发布页
2. 填入标题和正文
3. 上传封面图和内图
4. 添加话题
5. 点击发布

### 错误处理
- 未检测到连接：提示用户点击 Browser Relay 插件连接
- 发布失败：截图当前状态，告知用户具体错误
- 超时：重新尝试或转人工

## 典型用户指令
- "帮我发布这篇笔记"
- "自动发小红书"
- "把内容发到小红书"
