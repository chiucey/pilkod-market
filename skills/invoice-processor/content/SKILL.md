# 发票处理智能体 (Invoice Processing Agent)

## 功能概述

本技能自动处理发票报销文件，支持以下功能：
- 多格式支持：PDF、OFD、XML（携程订单）、图片（JPG/PNG）
- 智能去重：按发票号码去重，相同发票保留PDF格式
- 智能重命名：按`类型_日期_内容_金额`格式命名
- 出差行程关联：自动识别南京出发的往返行程
- 缺失票据标记：自动检测缺失的返程票、住宿发票
- 美观报表：生成带格式的Excel，包含总表、分类表、出差专项表

## 工作流程

### 阶段1：文件扫描与分类
1. 扫描指定文件夹，识别所有支持的文件类型
2. 按文件格式分类：PDF、OFD、XML、图片

### 阶段2：智能去重
1. 提取每个文件的发票号码
2. 相同发票号码保留一个，优先保留PDF格式
3. 删除重复文件

### 阶段3：内容解析
1. 根据文件类型调用对应解析器
2. 提取关键信息：发票号码、日期、金额、类型、描述
3. 复杂内容调用大模型增强提取

### 阶段4：出差行程识别
1. 筛选交通票据（机票、高铁）
2. 按日期排序，识别往返行程
3. 关联住宿、保险等票据
4. 计算每次出差总金额
5. 标记缺失票据

### 阶段5：文件重命名
1. 生成规范化文件名：`{类型}_{日期}_{描述}_{金额}.pdf`
2. 处理文件名中的特殊字符
3. 避免文件名冲突

### 阶段6：生成报表
1. **报销明细总表**：所有发票按类别和日期排序
2. **分类工作簿**：交通-航空、交通-铁路、住宿、餐饮、保险、其他
3. **出差专项报表**：每次出差单独统计，包含往返交通、住宿、保险明细

## 发票类型分类

| 类型代码 | 类型名称 | 包含内容 |
|---------|---------|---------|
| flight | 交通-航空 | 机票、行程单 |
| train | 交通-铁路 | 高铁票 |
| hotel | 住宿 | 酒店住宿发票 |
| meal | 餐饮 | 餐饮发票 |
| insurance | 保险 | 航空意外险等 |
| other | 其他 | 其他发票 |

## 输出文件结构

```
{目标文件夹}/
├── 报销明细_{timestamp}.xlsx     # 主报表
│   ├── 报销明细总表              # 所有发票汇总
│   ├── 交通-航空                 # 机票类发票
│   ├── 交通-铁路                 # 高铁票
│   ├── 住宿                      # 酒店住宿
│   ├── 餐饮                      # 餐饮发票
│   ├── 保险                      # 保险发票
│   ├── 其他                      # 其他发票
│   └── 出差专项报表              # 按出差行程统计
└── {重命名的发票文件}            # 按规范重命名
```

## 关键配置

- **基准城市**：默认南京，用于识别出差往返
- **出差定义**：从基准城市出发并返回为一次完整出差
- **去重规则**：相同发票号码仅保留一个，优先PDF格式

## 使用方式

```
处理发票文件夹：
"帮我整理桌面上的发票报销文件夹"
"处理 C:\Users\xxx\Desktop\发票 文件夹中的发票"
"处理发票，从南京出差报销"

指定参数：
folder_path: 发票文件夹路径
base_city: 出差基准城市（默认南京）
```
