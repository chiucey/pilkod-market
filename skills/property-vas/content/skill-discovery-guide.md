# 技能发现与优化指南

## 📖 技能如何被用户发现

### 1. description 字段 - 搜索索引核心

**description** 是技能被搜索和路由的**唯一入口**。

当用户在系统中搜索或提问时，系统会：
1. 解析用户输入的关键词
2. 在所有技能的 description 中进行语义匹配
3. 选择最相关的技能进行响应

### 2. 触发短语设计原则

一个优秀的 description 应包含：

#### ✅ **必须包含**
| 要素 | 说明 | 示例 |
|------|------|------|
| **功能描述** | 技能做什么 | "物业公司多种经营全流程实战技能" |
| **使用场景** | 何时使用 | "适用于物业多种经营负责人" |
| **关键词** | 触发词 | "物业增值服务、社区电商、物业选品" |

#### ✅ **推荐格式**
```
{核心功能}。{适用对象}。{触发关键词列表}。
```

#### ❌ **避免**
- 过于笼统的描述
- 缺少具体关键词
- 与技能功能无关的内容

### 3. description 长度建议

- **最短**：30 个字符（包含核心关键词）
- **推荐**：80-200 个字符
- **最佳**：包含 5-10 个触发关键词

## 🔍 关键词优化策略

### 核心关键词类型

| 类型 | 例子 | 作用 |
|------|------|------|
| **场景词** | "物业"、"电商"、"销售" | 定位领域 |
| **动作词** | "选品"、"洽谈"、"运营" | 定位功能 |
| **问题词** | "如何开展"、"怎么做" | 匹配提问 |
| **同义词** | "多种经营"="增值服务" | 扩大覆盖 |

## 🚀 发布到社区的流程

当您完成技能验证和打包后，可以通过以下方式发布：

### 步骤 1：使用 GenUI Skill Card

在技能创建完成时，系统会输出：
```xml
<genui-skill-card name="property-vas" desc="物业公司多种经营..." skill-id="383051105620552"></genui-skill-card>
```

### 步骤 2：用户操作

- **添加到我的技能库**：保存到个人收藏
- **发布到社区**：与社区用户共享

### 步骤 3：社区发现

发布后，其他用户可以通过：
- 搜索"物业"、"增值服务"等关键词发现
- 浏览社区技能列表
- 接收技能推荐
