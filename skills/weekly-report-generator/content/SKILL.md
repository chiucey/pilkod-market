# 周报生成器

## 技能概述

此技能帮助用户快速生成结构化、专业的工作周报，自动提炼工作要点与数据。

## 使用场景

- 定期工作总结汇报
- 项目进度汇报
- 团队协作周报汇总
- 个人工作记录与复盘

## 工作流程

### 1. 接收输入

收集用户的周报原始内容，支持多种格式：
- 自由文本描述
- 结构化工作列表
- 关键事件/里程碑

### 2. 内容分析

智能提取以下信息：
- **已完成事项**：具体交付成果
- **进行中事项**：当前进展状态
- **关键数据**：可量化的指标（完成数量、增长率、百分比等）
- **亮点成果**：值得强调的突出表现
- **挑战与解决方案**：遇到的问题及应对措施
- **下周计划**：后续工作安排

### 3. 周报生成

按以下结构组织输出：

```
# [姓名] 工作周报
## 📅 周期：[日期区间]

### ✅ 本周完成
- [要点1] - [数据支撑]
- [要点2] - [数据支撑]

### 📊 数据亮点
| 指标 | 数值 | 环比变化 |
|------|------|----------|
| ...  | ...  | ...      |

### 🔄 进行中
- [事项] - 进度：[百分比/状态]

### 🎯 亮点与成果
- ...

### ⚠️ 挑战与对策
- 挑战：[描述]
- 对策：[解决方案]

### 📅 下周计划
- [计划1]
- [计划2]
```

## 输出规范

1. **数据优先**：优先提取和展示可量化数据
2. **要点精炼**：每条要点不超过2行，突出核心价值
3. **结构清晰**：使用Markdown格式，便于复制和二次编辑
4. **语言专业**：使用商务汇报语言，避免口语化

## 示例输入

```
本周完成了APP用户增长模块的开发，新用户注册转化率从12%提升到18%，
修复了支付流程的3个bug，参与了产品需求评审会议，
和老王一起做了技术方案设计，下周准备开始做分享功能。
```

### 📊 数据亮点
