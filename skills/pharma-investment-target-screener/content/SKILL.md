# 医药投行投资标的筛选技能

## 核心能力

本技能帮助医药投行专业人员筛选、评估和分析医药研发投资标的，提供从初筛到深度分析的全流程支持。

## 工作流程

### 1. 需求理解与目标锁定

当用户发起医药投资标的查询时，首先明确：

- **投资阶段偏好**：早期（临床前/Phase I）、中期（Phase II/III）、后期（已上市/商业化）
- **治疗领域兴趣**：肿瘤、免疫、神经、心血管、代谢、罕见病等
- **地域偏好**：中国、美国、欧洲 biotech
- **估值区间**：具体数值或范围
- **投资类型**：股权投资、并购、License-in/out

### 2. 信息收集与数据获取

使用以下工具组合获取信息：

```
stocks_info + stocks_financial_data + batch_web_search + mcp__matrix__extract_content_from_websites
```

#### 核心数据维度

| 维度 | 数据来源 | 关键指标 |
|------|----------|----------|
| 财务状况 | akshare/stocks_financial_data | 营收、现金流、研发投入、资产负债率 |
| 管线进度 | 药监局/ClinicalTrials/公司公告 | 临床阶段、预计里程碑、适应症 |
| 竞争格局 | 行业数据库/研报 | 市场渗透率、竞品对比、差异化优势 |
| 团队背景 | 公司官网/LinkedIn/新闻 | 创始人背景、高管团队、技术平台 |
| 估值分析 | 同行对标/DCF | P/S、P/E、EV/Revenue 区间 |

### 3. 筛选框架

#### 定量筛选标准

```
必选条件（硬性）：
├── 营业收入 > X 万元（按阶段设定阈值）
├── 研发投入占比 > 10%
├── 现金流覆盖 > 12个月
└── 核心管线处于临床II期及以上

加分条件（软性）：
├── 拥有自主知识产权的技术平台
├── 国际化布局（中美双报/全球权益）
├── 知名投资机构背书
└── 清晰的商业化路径
```

#### 定性评估维度

1. **技术创新性**：靶点创新度、平台延展性、技术壁垒
2. **临床价值**：未满足临床需求、差异化定位
3. **商业化潜力**：市场规模、定价策略、准入能力
4. **团队执行力**：临床推进速度、商务拓展能力

### 5. 后续跟进

- 定期监控标的动态（新闻、临床进展、融资事件）
- 竞品动态追踪
- 行业政策变化影响分析

## 工具使用规范

| 任务类型 | 推荐工具组合 |
|----------|--------------|
| A股公司数据 | akshare + stocks_info + stocks_financial_data |

| 行业研报 | extract_pdfs_key_info / extract_pdfs_full_content |
| 新闻舆情 | stocks_news + batch_web_search |

## 输出格式选择

根据用户需求选择输出形式：

- **结构化报告**：Markdown格式，适合详细分析
- **数据表格**：CSV/Excel格式，便于进一步处理
- **对比分析**：多标的横向对比矩阵
- **可视化图表**：管线进度图、竞争格局图

## 注意事项

1. **数据时效性**：医药行业信息更新快，标注数据来源日期
2. **估值不确定性**：早期biotech估值主观性强，提供多种估值方法
3. **风险提示**：充分披露政策、技术、监管风险
4. **合规要求**：遵守投行保密协议，不泄露非公开信息

## 常见场景处理

### 场景1：寻找特定靶点的投资标的

```
处理流程：
1. 确定靶点（如KRAS G12C、TROP2等）
2. 搜索该靶点在研药物
3. 筛选已披露的biotech公司
4. 评估管线进度和公司质量
5. 生成标的清单和初步评估
```

### 场景2：特定治疗领域的系统性筛选

```
处理流程：
1. 确定治疗领域（如ADC药物）
2. 梳理该领域主要靶点和技术路线
3. 搜索领域内主要玩家
4. 按估值、进度、团队等维度排序
5. 生成行业地图和标的矩阵
```

### 场景3：特定公司深度尽调

```
处理流程：
1. 公司背景调查（团队、历史、融资）
2. 管线深度分析（数据验证、竞品对比）
3. 财务建模（DCF、可比公司法）
4. 风险评估
5. 投资建议输出
```
