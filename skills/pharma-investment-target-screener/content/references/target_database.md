## 不同投资阶段的筛选标准

### 天使/种子轮

```
必要条件：
├── 创始人/核心团队有成功退出或大型药企经验
├── 技术平台具有差异化优势
├── 核心靶点新颖或Fast-follow策略明确
└── 首付款需求 < 500万人民币

加分项：
├── 知名天使投资人背书
├── 专利布局完善
└── 与高校/研究所合作
```

### A轮

```
必要条件：
├── 完成PCC（临床前候选化合物）阶段
├── 核心管线 IND enabling
├── 团队规模 10-30人
└── 估值范围 5000万-3亿人民币

加分项：
├── 首席医学官（CMO）有临床开发经验
├── 已建立外部合作网络
└── 有意向性数据支持概念验证
```

### B轮及以后

```
必要条件：
├── 至少一条管线进入临床I期
├── 临床数据具有竞争力（me-better或差异化）
├── 现金流可支撑12-18个月
└── 估值范围 10亿-50亿人民币

加分项：
├── 国际多中心临床计划
├── 与大药企的战略合作意向
└── 商业化团队开始搭建
```

### 后期（IPO前/Pre-IPO）

```
必要条件：
├── 核心产品进入临床III期或NDA阶段
├── 收入>1亿人民币 或 明确商业化时间表
├── 有盈利能力或明确盈利路径
└── 二级市场可比公司估值参考

加分项：
├── 核心产品纳入医保目录
├── 海外权益授权（License-out）
└── 完善的销售网络
```

## 估值方法参考

### 1. 可比公司法（Trading Comparables）

```
估值倍数参考：

| 公司类型 | EV/Revenue | EV/EBITDA | P/S |
|----------|-------------|-----------|-----|
| 商业化Biotech | 3-8x | 15-30x | 5-12x |
| 临床III期 Biotech | 2-5x | N/A | 3-8x |
| 临床II期 Biotech | 1-3x | N/A | 2-5x |
| 临床I期 Biotech | 0.5-1.5x | N/A | 1-3x |
| 临床前 Biotech | 0.2-0.5x | N/A | 0.5-1.5x |
```

### 2. DCF现金流折现法

```
关键假设：
├── 成功概率（基于临床阶段）
├── 上市时间
├── 峰值市场份额
├── 定价策略
└── 折现率（通常15-25%）

成功概率参考：
| 阶段 | 成功率 |
|------|--------|
| 临床前 → I期 | 10-15% |
| I期 → II期 | 25-35% |
| II期 → III期 | 40-55% |
| III期 → NDA | 60-75% |
| NDA → 批准 | 85-95% |
```

### 3. 风险调整后NPV

```
公式：rNPV = NPV × Probability of Success

计算步骤：
1. 预测各管线未来现金流
2. 按临床阶段确定成功概率
3. 应用竞争强度调整因子
4. 计算加权平均NPV
5. 加上净现金（非管线资产）
```
