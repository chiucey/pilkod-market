# 香港赛马 Place 投注预测系统 (courseplace)

## 核心功能

### 1. Place 投注原理

**Place 投注规则**：选择马匹在比赛中获得前三位（冠、亚、季军）。若选择的马匹进入前三名，投注获胜。

**返奖机制**：
- 香港赛马返奖率约 82%
- Place 赔率 = 总彩池 × 0.82 × (1/前三名赔率加权)
- 每场比赛前三名瓜分 Place 彩池

### 2. 物理学预测模型

本技能采用多维物理学模型进行赛马预测：

#### 2.1 Elo Rating System（经典模型）
```python
# Elo 评分系统原理
# 每匹马有一个评分 R
# 比赛后评分更新：R' = R + K × (S - E)
# S = 实际结果 (1=冠军, 0.5=亚军, 0.25=季军, 0=之外)
# E = 期望胜率 = 1 / (1 + 10^((Ra-Rb)/400))
# K = 评分调整系数 (通常 20-32)
```

#### 2.2 Bradley-Terry Model（成对比较）
```python
# Bradley-Terry 概率模型
# P(A beats B) = πA / (πA + πB)
# πA, πB 为马匹 A, B 的强度参数
# 通过最大似然估计（MLE）求解参数
# 强度参数 = exp(β × 综合评分)
```

#### 2.3 TrueSkill Model（贝叶斯模型）
```python
# TrueSkill 多维评分
# 每匹马有 (μ, σ) 评分对
# μ = 技能水平（均值）
# σ = 不确定性（标准差）
# 更新：考虑所有马匹的排名信息
# 输出：胜率 + 置信区间
```

#### 2.4 物理学特征权重
| 特征类型 | 权重公式 | 物理意义 |
|---------|---------|---------|
| 时序衰减 | exp(-t/τ) | 时间衰减因子 |
| 场地适应 | 1 + α×cos(θ-θ₀) | 赛道方向余弦相似度 |
| 负磅影响 | exp(-w/λ) | 负磅指数衰减 |
| 档位优势 | β₀ + β₁×(draw-7)² | 档位距离平方损失 |

## 预测工作流

### Step 1: 数据采集
从 HKJC 公开数据源采集：
- 马匹历史表现数据
- 骑师/练马师胜率统计
- 赛道特定历史数据
- 当前赔率数据

### Step 2: 特征工程
计算以下特征：
- 最近 3/5/10 场加权胜率
- 指数衰减平均排名
- 赛道/途程适应度
- 负磅影响因子
- 档位历史表现

### Step 3: 模型训练
训练多个排序模型：
- Elo 评分系统
- Bradley-Terry 成对模型
- TrueSkill 贝叶斯模型

### Step 4: Place 预测

## 注意事项

1. **数据时效性**：使用最近 2-3 个马季数据训练
2. **模型局限**：赛马存在固有不确定性，预测仅供参考
3. **投注风险**：请理性投注，设置止损线
4. **税费说明**：香港 Place 返奖率 82%，计算期望值时已扣除
