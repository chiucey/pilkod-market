# 金蝶领导致辞稿撰写 Skill

为金蝶各分公司市场部提供标准化致辞稿生成服务。输出符合金蝶品牌调性、约1000字（5分钟）、可直接使用的 Word 文档。

---

## 使用前必读

**第一步（信息采集）**：触发后立即用 `ask_user_input` 工具收集必要信息，缺任何一项不得开始写稿。

**第二步（判断身份分支）**：根据致辞人身份，走不同写作规则。

**第三步（品牌素材）**：读取 `references/brand-assets.md` 获取可引用的数据、话术、产品线说明。

**第四步（生成+自检）**：按四段式结构写稿，输出前完成自检清单，输出 Word 文件。

---

## 第一阶段：信息采集

### 1.1 必须收集的材料（缺一不可）

用 `ask_user_input` 工具**一次性**提出以下问题：

```
问题1  标题："活动策划案"  类型：说明
  提示："请粘贴或上传完整活动策划案（含活动名称、类型、规模、目标受众）"

问题2  标题："致辞人身份"  类型：single_select
  选项：
    A. 金蝶内部代表（集团/分公司高管，以金蝶名义发言）
    B. 外部代表——政府/主管部门领导
    C. 外部代表——行业协会/研究机构代表
    D. 外部代表——合作伙伴/客户代表

问题3  标题："致辞人信息"  类型：说明
  提示："致辞人姓名 + 完整职务（如：张三，金蝶集团华南区总经理）"

问题4  标题："开场点名嘉宾"  类型：说明
  提示："需在开头点名问候的重要嘉宾，请按您希望出现的顺序列出（姓名+职务），没有则填'无'"
```

### 1.2 根据身份追加问题

**若为金蝶内部代表（选A）**，追加：

```
追加问题A1  标题："希望引用的近期成果"  类型：说明
  提示："请提供近6个月内希望在致辞中引用的金蝶对外公开成果或新闻，1-3条即可（直接粘贴内容摘要）"

追加问题A2  标题："是否有产品发布"  类型：single_select
  选项：有产品发布（请上传上市材料） / 无产品发布
```

**若为外部代表（选B/C/D）**，追加：

```
追加问题B1  标题："致辞人所在机构"  类型：说明
  提示："致辞人代表的机构全称，及其与本次活动/金蝶的关系"
```

> **默认时长**：5分钟 / 约1000字。如用户有特殊要求，以用户为准。

## 第二阶段：写作规则

### 2.1 金蝶内部代表（选A）

**口吻**：主人翁姿态，自信有力，结论先行，数据跟进。语言风格参照主席报告：多用判断句，少用形容词堆叠。

**结构与内容要求**：

| 段落 | 结构标注 | 内容要求 |
|---|---|---|
| 欢迎感谢 | 【欢迎感谢】 | 点名问候重要嘉宾（按用户提供顺序）；说明活动名称；代表金蝶欢迎致谢 |
| 高举大旗 | 【高举大旗】 | 结合当下政策热点（AI+、新质生产力等）阐述活动背景；点明本次活动定位与意义 |
| 成果展示 | 【成果展示】 | ① 优先使用撰写者提供的近期成果；② 若有产品发布，主推上市材料内容；③ 补充引用 brand-assets.md 中的数据，按活动受众选择匹配的产品线和客户案例 |
| 总结祝愿 | 【总结祝愿】 | 从行业回归活动本身；用金蝶使命/愿景升华；祝大会成功 |

**成果展示优先级**：
1. 撰写者提供的近期新闻成果（最优先）
2. 产品上市材料（若有产品发布）
3. `brand-assets.md` 中的标准数据和话术（兜底补充）

### 2.2 外部代表——政府/主管部门（选B）

**口吻**：官方、庄重、有站位，代表政府视角看行业与活动。

**结构与内容要求**：

| 段落 | 结构标注 | 内容要求 |
|---|---|---|
| 欢迎感谢 | 【欢迎感谢】 | 代表所在机构祝贺活动召开；欢迎各方嘉宾；可结合活动举办地特色 |
| 政策背景 | 【高举大旗】 | **重点**：引用国家或地方工信/科技部门政策；阐述行业发展形势；点明政府对本次活动及金蝶的支持 |
| 地方/行业展望 | 【成果展示】 | 结合本地/本行业数字化发展目标；介绍本地营商环境或产业布局；**点到金蝶即可**，不做大篇幅介绍 |
| 总结祝愿 | 【总结祝愿】 | 祝大会圆满成功；表达期待与金蝶/行业共同发展的意愿 |

### 2.3 外部代表——行业协会/研究机构（选C）

**口吻**：专业、客观、有行业权威感，以第三方视角背书金蝶。

**结构与内容要求**：

| 段落 | 结构标注 | 内容要求 |
|---|---|---|
| 欢迎感谢 | 【欢迎感谢】 | 代表机构对活动召开表示祝贺；感谢主办方邀请 |
| 行业趋势 | 【高举大旗】 | **重点**：用行业数据和趋势铺垫（AI产业规模、增速、政策方向等）；阐述企业数字化的必要性 |
| 金蝶定位 | 【成果展示】 | 以第三方视角说明金蝶在行业中的位置（可引用 IDC、Gartner 等报告数据）；表达对本次活动的期待；**语气是"我们看到金蝶……"而非"我们金蝶……"** |
| 总结祝愿 | 【总结祝愿】 | 祝大会成功；期待产学研各方深度交流 |

### 2.4 外部代表——合作伙伴/客户（选D）

**口吻**：真诚、有温度，以合作者/受益者身份表达感谢与期待。

**结构与内容要求**：

| 段落 | 结构标注 | 内容要求 |
|---|---|---|
| 欢迎感谢 | 【欢迎感谢】 | 代表机构感谢金蝶邀请；祝贺活动召开 |
| 合作背景 | 【高举大旗】 | 结合行业数字化趋势；讲述与金蝶合作的背景与动因 |
| 合作成果 | 【成果展示】 | **重点**：讲述双方合作的具体成果（需撰写者提供）；以"共同成就了什么"为主线，而非单独夸金蝶 |
| 总结祝愿 | 【总结祝愿】 | 期待进一步合作；祝大会成功 |

## 第三阶段：品牌素材调用规则

> **必读**：`references/brand-assets.md`，在写稿前加载。

**按活动受众选择产品线**：
- 面向央国企/大型企业 → 引用**金蝶AI苍穹、星瀚**
- 面向中大型企业 → 引用**金蝶AI星辰**
- 面向小微企业 → 引用**金蝶AI星空**
- 面向全客群/综合活动 → 整体数据为主，产品线选1-2个重点

**按活动行业选择客户案例**（详见 brand-assets.md §4）：
- 钢铁冶金 → 沙钢、河钢、德龙钢铁
- 制造/高科技 → 海信、三一重工、华为
- 央国企 → 招商局集团、中国通用技术、山东重工
- 能源 → 通威股份、深圳能源、广东能源
- 金融 → 中国建设银行、浦发银行
- 综合场合 → 优先用整体表述："超70家世界500强""超一半中国500强"

**网站动态补充**（Skill运行时按需执行）：
- 抓取 `kingdee.com` 补充最新产品介绍和官方使命表述
- 抓取 `investor.kingdee.com` 补充最新财务数据（输出时标注"⚠️ 请撰写者确认数据时效性"）
- 撰写者提供的近期成果**优先于**网站抓取内容

## 第四阶段：输出前自检清单

写完后逐条核查，**全部通过**才能输出：

- [ ] 所有点名嘉宾已出现在开头，顺序与用户提供一致
- [ ] 正文含具体数据或具体事件，无连续3句以上空洞表述
- [ ] 活动全称完整引用至少一次
- [ ] 字数在900-1100字之间（默认1000字）
- [ ] 无公文腔词汇：我司、贵司、兹、特此、予以、就……一事、上述、综上所述、为此、鉴于此
- [ ] 无文言体词汇：深感荣幸之至、不胜感激、谨此、敬颂、藉此
- [ ] 无AI生成腔：在这个充满挑战与机遇的时代、各位嘉宾的到来让我们倍感荣幸、相信在大家的共同努力下
- [ ] 外部代表稿：金蝶相关内容不超过全文30%，无"我们金蝶"式主语

## 第五阶段：Word 输出规范

### 文档结构

```
【标题行】  在"[活动全名]"上的致辞
            [致辞人姓名]  [致辞人职务]
【空一行】
【称呼语】  尊敬的[重要嘉宾姓名职务]，各位[来宾/嘉宾/朋友们]：
【空一行】
【正文】    各段落首行缩进2字符
            段落旁保留结构标注：【欢迎感谢】【高举大旗】【成果展示】【总结祝愿】
【结尾】    谢谢大家！
```

### 字体规范

| 层级 | 字体 | 字号 | 格式 |
|---|---|---|---|
| 标题行 | 方正小标宋简体 | 22pt | 居中 |
| 称呼语 | 仿宋_GB2312 | 12pt | 顶格 |
| 正文段落 | 仿宋_GB2312 | 12pt | 首行缩进2字，1.5倍行距 |
| 结构标注【…】 | 仿宋_GB2312 | 10pt | 灰色，置于段前 |
| 结尾祝词 | 仿宋_GB2312 | 12pt | 同正文 |

### 文件输出

使用 docx-js 生成 .docx，输出至 `/mnt/user-data/outputs/`，文件名格式：
```
[活动简称]_[致辞人姓名]致辞_[YYYYMMDD].docx
```

## 常见情况处理

| 情况 | 处理方式 |
|---|---|
| 用户直接粘贴了完整策划案 | 从策划案提取活动名称、规模、受众，跳过该问题，其余正常问 |
| 用户说"直接写"/"快速版" | 跳过确认环节，信息采集后直接输出，末尾注明"如需调整请告知" |
| 活动有多位致辞人 | 每位单独走一次完整流程，分别生成文件 |
| 字数要求不同 | 以用户为准：3分钟≈600字，8分钟≈1500字 |
| 走进客户的客场活动 | 开头大量赞美客户，以"共同成就"为主线，客户是主角；参照范文G（走进沙钢） |
| 峰会附属闭门环节 | 可承接主会场内容，使用"今早/今天发布了……"式衔接语；参照范文E（章勇闭门研讨会） |
| 用户对草稿提出修改 | 定位到对应段落修改，其余段落保持不动，重新生成 Word 文件 |
