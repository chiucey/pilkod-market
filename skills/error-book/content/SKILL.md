# 错题本技能

## 核心功能

本技能提供个人错题本管理功能，包括：错题本创建与管理、错题录入、错题练习。

---

## 一、入口：选择错题本

### 1.1 菜单展示

当触发本技能时，向用户展示以下菜单：

```
【错题本选择】
请选择您的错题本：

已创建的错题本：
1. [错题本名称1] - [学科] - [层级]
2. [错题本名称2] - [学科] - [层级]
...

创建新错题本
```

### 1.2 用户选择处理

- **选择已有错题本**：进入该错题本的功能选择（第2节）
- **选择"创建新错题本"**：进入创建流程（第1.3节）

---

## 二、创建新错题本

### 2.1 信息收集

按顺序收集以下信息：

1. **错题本名称**：用户自定义名称（必填）
2. **学科**：如数学、英语、物理等（必填）
3. **层级**：如初一、高二、高考等（必填）
4. **特殊备注**：可选，用于描述错题本的特殊用途或范围

### 2.2 创建确认

收集完毕后，向用户确认信息：

```
【确认创建】
错题本名称：[名称]
学科：[学科]
层级：[层级]
备注：[备注或"无"]
确认创建？ (Y/N)
```

- 用户确认后，创建成功，进入该错题本功能选择
- 用户取消，返回菜单

---

## 三、错题本功能选择

用户选择一个错题本后，展示该错题本的功能菜单：

```
【[错题本名称]】
请选择操作：

1. 录入错题
2. 错题练习
3. 返回上级菜单
```

---

## 四、录入错题

### 4.1 无错题本情况

如果用户未选择错题本而直接要求录入错题：
1. 自动创建一个默认错题本
2. 进入信息收集流程（学科、层级、备注）

### 4.2 录入流程

**步骤1：录入题目**

引导用户输入题目信息：

```
【录入错题】
请以对话形式输入错题信息（题目、选项等）
输入完成后说"录入完毕"

格式示例：
题目：以下哪个是...
A. 选项1
B. 选项2
C. 选项3
D. 选项4
```

**步骤2：AI审查**

录入完成后，AI进行审查：

1. **检查是否录错错题本**
   - 检查当前题目的学科/知识点是否与已有错题本匹配
   - 如果发现可能属于其他错题本，询问用户确认

2. **检查选项重复**
   - 检查多个选项编号（A/B/C/D）是否对应完全相同的内容
   - 如发现重复，要求用户调整后重新录入

**步骤3：生成答案与解析**

通过对话引导用户确认或补充：

```
【生成答案】
请确认或补充以下信息：

正确答案：[A/B/C/D]
解题思路：[简要说明解题方法]
相关知识点：[涉及的知识点]
```

**步骤4：保存**

将错题保存到后台数据库，包含：
- 题目内容
- 选项（A/B/C/D及其内容）
- 正确答案
- 解析
- 录入时间
- 所属错题本ID

## 五、错题练习

### 5.1 练习类型选择

```
【错题练习】
请选择练习模式：

1. 原题练习 - 使用已保存的错题，打乱选项顺序
2. 出题练习 - 基于错题知识点，出新题练习
3. 返回
```

### 5.2 原题练习

**步骤1：从数据库获取错题**

获取当前错题本中的所有已保存错题。

**步骤2：打乱选项**

对每道题目的选项进行随机打乱，但记录正确的打乱后位置。

**步骤3：输出练习**

```
【原题练习 - 第X题】

[题目内容]

A. [选项内容]
B. [选项内容]
C. [选项内容]
D. [选项内容]
```

### 5.3 出题练习

**步骤1：分析知识点**

从错题本中提取知识点，确定出题范围。

**步骤2：按照教育学理论组织试题结构**

遵循以下原则：
- 考察目标明确
- 难度递进
- 干扰项合理
- 情境设置恰当

**步骤3：检查题目质量**

在输出前进行两项检查：

1. **题干检查**：确保题干内容未在选项中出现
2. **选项检查**：确保多个选项编号对应内容不完全相同

**检查流程**：
```
【题目检查】
- 检查题干是否在选项中泄露答案
- 检查选项是否有重复内容
```

- **检查通过**：输出题目
- **检查未通过**：自动调整题目后重新检查，直到通过

**步骤4：输出新题**

输出格式与原题练习相同。

## 八、错误处理

1. **空选项**：如果用户输入的选项为空，提示用户补充
2. **重复选项**：检测到重复时，要求用户重新输入选项
3. **无错题本直接录入**：自动创建默认错题本并引导补充信息
4. **练习无题**：如果错题本为空，提示用户先录入错题
