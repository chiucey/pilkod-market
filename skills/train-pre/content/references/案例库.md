# 五类常见表层问题·追问校准案例库

> 用途：为智能体的追问逻辑做**校准**，避免把所有问题都归结为"管理机制问题"。
> 每类问题填 2–3 个内部真实案例。标【待业务方补充】的字段由业务发起人在第一阶段提供。
> 使用原则：真实原因可能来自**资源、技术、专业能力、流程、权责**或多种因素，**以事实和学员确认为准**，案例仅用于示范"如何问、往哪些方向比较"，不作为预设结论。

## 单个案例的填写结构

- **表层说法**：学员最初怎么说（一句话）。
- **需要先澄清的事实**：把话题从"评价"拉回"具体事件"要问清的 3–5 个事实点（时间、对象、动作、结果、约束）。
- **可能的多种原因（供比较，不预设）**：分别从 资源 / 技术 / 专业能力 / 流程 / 权责 等角度各列一种可能。
- **典型追问示例**：2–3 句一次一问的追问（体现"一次一问、≤3 层"）。
- **校准要点**：这个案例最容易被误归到哪一类原因，如何避免。

## 一、跨部门协同困难

### 案例 1
- **表层说法**：【待业务方补充，如"每次跨部门推事情都特别慢"】
- **需要先澄清的事实**：具体是哪件事？涉及哪两个（去标识化的）部门？卡在哪一步？期望多久、实际多久？【待补充】
- **可能的多种原因（供比较）**：
  - 资源：对方部门同期任务饱和 / 【待补充】
  - 流程：缺少跨部门发起与对接的既定路径 / 【待补充】
  - 权责：谁拍板不清、责任边界模糊 / 【待补充】
  - 专业能力：双方对同一目标的理解口径不一致 / 【待补充】
- **典型追问示例**：
  1. "这件事最近一次卡住，是卡在'找不到对接人'，还是'找到了但推不动'？"
  2. "如果推不动，是对方没动力，还是没权限、没资源？"
- **校准要点**：不要一听"协同难"就归因为"机制/激励"，先分清是**对接路径**问题还是**权责/资源**问题。

## 二、激励机制不足

### 案例 1
- **表层说法**：【待补充，如"干多干少一个样，大家没积极性"】
- **需要先澄清的事实**：具体哪个岗位/哪件事上感到没激励？现有的认可方式是什么？学员期望的是什么？【待补充】
- **可能的多种原因（供比较）**：
  - 权责：贡献与评价口径不匹配 / 【待补充】
  - 流程：反馈与认可不及时 / 【待补充】
  - 专业能力：目标设定不清导致"努力无处发力" / 【待补充】
  - 资源：可支配的激励手段有限 / 【待补充】
- **典型追问示例**：
  1. "你说的'没积极性'，是钱的问题，还是'干得好也没人看见'的问题？"
  2. "如果是后者，最近有没有一件事你做得不错但没被反馈到？"
- **校准要点**：区分**物质激励**、**认可反馈**、**目标清晰度**三种截然不同的症结，别笼统归为"激励不足"。

## 三、流程或审批过长

### 案例 1
- **表层说法**：【待补充，如"一个审批走完要两周"】
- **需要先澄清的事实**：哪类事项？经过几个环节？哪个环节最慢？是常态还是个例？【待补充】
- **可能的多种原因（供比较）**：
  - 流程：环节冗余 / 串行本可并行 / 【待补充】
  - 权责：审批权限层级过高或分散 / 【待补充】
  - 资源：审批人同期负荷高 / 【待补充】
  - 技术：线下流转、缺少线上化 / 【待补充】
- **典型追问示例**：
  1. "两周里，真正'在处理'的时间多，还是'在等下一个人'的时间多？"
  2. "最慢的那一环，是没人批，还是不敢批、批不了？"
- **校准要点**：区分**环节设计**问题与**审批权限**问题；"慢"常常是"等"而非"办"。

## 四、人手或资源不足

### 案例 1
- **表层说法**：【待补充，如"活太多人太少，根本忙不过来"】
- **需要先澄清的事实**：哪段时间、哪类任务集中？是长期缺编还是阶段性高峰？现有人手的时间花在哪？【待补充】
- **可能的多种原因（供比较）**：
  - 资源：确属编制/预算不足 / 【待补充】
  - 流程：大量时间耗在返工、等待、重复沟通 / 【待补充】
  - 专业能力：技能错配导致效率低 / 【待补充】
  - 技术：可自动化的工作仍靠人力 / 【待补充】
- **典型追问示例**：
  1. "如果给你多一个人，他会主要去做哪件事？"
  2. "现在团队的时间，有多少是花在'本可以不做'的事情上？"
- **校准要点**：不要一听"人不够"就停在"缺编"，先看是**总量不足**还是**结构/效率**问题。

## 五、执行不到位

### 案例 1
- **表层说法**：【待补充，如"布置下去了，就是落不了地"】
- **需要先澄清的事实**：哪件事没落地？卡在"没开始/没做完/做偏了"哪一种？相关人是否清楚目标？【待补充】
- **可能的多种原因（供比较）**：
  - 专业能力：不会做 / 不知道怎么做 / 【待补充】
  - 流程：任务拆解与跟进机制缺失 / 【待补充】
  - 权责：责任不清、多头指挥 / 【待补充】
  - 资源：缺条件、缺工具 / 【待补充】
- **典型追问示例**：
  1. "落不了地，是他们'不愿做'，还是'不会做'、'做不了'？"
  2. "上一次没落地的那件事，问题最先出现在哪一步？"
- **校准要点**：区分**意愿**、**能力**、**条件**三种原因，避免默认归为"态度/执行力"问题。

## 通用校准红线
- 每类问题都不得走固定套路直接给结论；先澄清事实，再**并列比较**多种可能原因。
- 航空运输专业问题若无法上升为管理共性议题，按专业培训需求保留，不强行归纳为"管理机制"。
- 任何原因判断都需**经学员确认**才写入报告；未确认的一律不写成结论。
