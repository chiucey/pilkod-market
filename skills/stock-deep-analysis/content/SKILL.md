# 股票深度分析技能

## 分析框架概述

本技能采用"基因-成长-现状-竞争-战略-风险"六维深度分析体系，遵循严格的信息溯源原则：

**核心原则**：
- **🚨 年报为本（强制）**：所有分析结论必须基于公司年报，**年报是分析的基石，绝不可跳过**
- **🚨 用户提供（强制）**：年报必须由用户提供，**不提供年报则不进行任何分析**
- **🚨 搜索为辅（辅助）**：网页搜索仅用于补充公开资料，**绝对不能替代年报**
- **🚨 证据链闭环**：每个结论必须有年报数据支撑，搜索信息需在报告中标注为"辅佐参考"

> **⚠️ 强制前置条件：用户未提供年报 = 分析终止**
>
> 用户必须提供年报PDF文件或年报关键数据才能开始分析。如果用户不提供年报，应明确告知无法继续分析，并结束任务。绝不能以搜索数据替代年报内容进行分析。

- ✅ 行业政策背景（国常会、部委文件）
- ✅ 行业整体市场规模和增速
- ✅ 竞争对手的公开信息
- ✅ 宏观经济数据（GDP、CPI等）

## 分析维度体系

### 第一维度：公司源头全局定位

**分析目标**：从企业诞生之初理解其原始基因

**分析要点**：
1. **创始人背景**
   - 自然人创业/国企/央企/地方政府/外资背景
   - 创始人行业积淀与资源禀赋

2. **成立时间与地点**
   - 是否处于行业萌芽期或政策红利期
   - 地理位置与产业集群关系

3. **初始主营业务**
   - 技术驱动型/资源依赖型/渠道驱动型
   - 起家业务的核心竞争力来源

4. **上下游关系雏形**
   - 上游供应商分散度（集中/分散）
   - 下游客户性质（B端/C端/政府）

5. **行业初始地位**
   - 领先者/跟随者/边缘参与者

**输出格式**：
```
## 公司源头画像
- 创始背景：[类型]
- 成立时期：[时间] / [地点]
- 起家业务：[描述]
- 上下游特征：[描述]
- 初始行业地位：[定位]
- 原始基因判断：[领先者/跟随者/边缘参与者]
```

### 第二维度：商业模式深度拆解

**分析目标**：理解公司盈利本质与壁垒

**商业画布九要素分析**：
1. 客户细分 - 谁是核心客户
2. 价值主张 - 解决什么痛点
3. 渠道通路 - 如何触达客户
4. 客户关系 - 如何维护客户
5. 收入来源 - 收入结构与模式
6. 核心资源 - 关键资产与能力
7. 关键业务 - 核心业务活动
8. 重要伙伴 - 战略合作伙伴
9. 成本结构 - 成本控制特征

**盈利模式识别**：
| 模式类型 | 特征 | 判断标准 |
|---------|------|---------|
| 按件收费 | 制造业、商品销售 | 销量驱动 |
| 订阅制 | SaaS、会员服务 | 复购稳定 |
| 项目制 | 工程、服务外包 | 周期波动 |
| 佣金抽成 | 平台、金融中介 | 流量依赖 |

**成本结构判断**：
- 固定成本占比高 → 重资产、规模效应强
- 变动成本主导 → 灵活但毛利率受限
- 人力密集型 → 扩张边际成本高

**核心壁垒评估**：
- 专利技术壁垒
- 牌照资质壁垒
- 网络效应壁垒
- 先发优势壁垒
- 品牌认知壁垒

**输出格式**：
```
## 商业模式画像
- 盈利模式：[类型]
- 成本结构：[特征描述]
- 核心壁垒：[优先级排序]
- 生意属性判断：[辛苦钱/轻松钱]
- 可复制性：[高/中/低]
```

### 第三维度：公司完整传记式历史分析

**分析目标**：以时间轴方式梳理企业发展历程

#### 3.1 历年业务变迁
- 主营业务演进路径：多元化扩张/垂直深化/战略收缩
- 新增业务动因：市场需求/政策引导/并购驱动
- 剥离业务原因：亏损退出/战略聚焦/资产腾挪

#### 3.2 控制权与管理层变迁
- 实际控制人变更次数及背景：家族传承/股权争夺/国资接手
- 高管团队稳定性：董事长/总经理任职年限
- "壳资源"嫌疑排查：频繁更换主业、无实质经营

#### 3.3 投融资与资本运作历史
- 历次融资情况：IPO、增发、配股、债券金额与用途
- 并购行为分析：横向整合/纵向延伸/跨界并购/商誉积累
- 资产出售记录：是否存在"卖资产保利润"现象

#### 3.4 历史基因总结
综合判断公司类型：
- **经营型**：专注主业、稳步发展
- **资本运作型**：擅长并购重组、讲故事
- **周期型**：业绩随行业波动明显
- **壳资源型**：主业空心化、控制权易手频繁

**输出格式**：
```
## 企业历史传记
### 业务演进时间轴
[按年份梳理]

### 资本运作轨迹
[融资/并购/出售记录]

### 控制权变更史
[实控人变化记录]

### 基因类型判定
[经营型/资本运作型/周期型/壳资源型]
```

### 第四维度：当下公司全景商业模式

**分析目标**：回归当前真实运营状态

#### 4.1 业务板块全景
- 当前主要业务数量与名称
- 各业务营收占比排序
- 业务分类定位：
  - 成长型业务（高速增长中）
  - 培育型业务（尚未盈利）
  - 拖累型业务（持续亏损）

#### 4.2 各业务深度拆解
对每个业务单元分析：
- **生产流程**：自主研发/代工生产/轻资产运营
- **盈利机制**：产品销售/服务收费/授权许可
- **定价能力**：是否有提价权/受制于客户压价
- **成本构成**：原材料占比/人工占比/折旧摊销影响
- **生命周期阶段**：导入期/成长期/成熟期/衰退期
- **成长驱动力**：技术突破/市场份额提升/政策补贴
- **当前主要痛点**：产能瓶颈/回款慢/人才短缺

#### 4.3 客户与需求深度分析
- 客户类型分布：B端大客户/C端零售/政府采购
- 需求特性判断：
  - 刚性需求 vs 可选消费
  - 高频复购 vs 一次性购买
  - 替代性强 vs 黏性高
- 客户集中度：前五大客户销售占比
- 大客户依赖风险：单一客户占比是否超30%

#### 4.4 整体生意属性总结
一句话定义当前生意本质

**输出格式**：
```

### 各业务深度分析
[按业务逐一分析]

### 客户画像
- 客户类型：[分布]
- 需求特征：[描述]
- 集中度：[占比]
- 大客户风险：[有无]
```

### 第五维度：纵向全产业链分析

**分析目标**：揭示公司在产业链中的位置与话语权

**产业链结构分析**：
```
上游 → 中游（本公司）→ 下游 → 终端市场
```

**关键判断维度**：
| 判断维度 | 分析要点 | 风险提示 |
|---------|---------|---------|
| 成本传导能力 | 原材料涨价能否转嫁给下游 | 不能转嫁则利润被压缩 |
| 需求传导敏感性 | 终端需求变化对公司影响滞后多久 | 滞后短则敏感度高 |
| 产业链景气周期 | 当前处于上行/下行/平稳 | 顺周期放大波动 |
| 议价能力 | 上游垄断程度/下游强势程度 | 夹心层利润最薄 |

**产业链地位判断**：
- **"吃肉"**：主导者，具有定价权
- **"喝汤"**：参与者，随行业波动
- **"挨打"**：夹心层，议价能力弱

**输出格式**：
```

下游：[描述]

### 议价能力评估
成本传导：[能/否/部分]
需求敏感度：[高/中/低]
景气周期：[上/下/平稳]

### 产业链地位判定
[吃肉/喝汤/挨打]
```

### 第六维度：横向竞争格局分析

**分析目标**：通过同业对比明确市场地位

**竞争格局评估框架**：
```
行业整体竞争程度 → 集中度指标 → 公司排名 → 壁垒高低
```

**分析维度**：

1. **行业整体竞争程度**
   - 充分竞争（进入门槛低）
   - 寡头垄断（CR5 > 50%）
   - 垄断竞争（品牌差异化显著）

2. **集中度指标**
   - CR5（前五名市占率）
   - CR10

3. **公司自身排名与定位**
   - 第一梯队（龙头地位）
   - 第二梯队（追赶者）
   - 第三梯队（边缘玩家）

4. **市场份额趋势**
   - 提升中/停滞/下滑

5. **与龙头差距分析**
   - 技术差距
   - 规模差距
   - 渠道差距
   - 品牌差距

6. **进入壁垒评估**
   - 技术壁垒（芯片设计、医药审批）
   - 资质壁垒（特殊行业许可）
   - 规模壁垒（重资产、规模经济）
   - 网络效应（平台、社交）

**竞争对手对比分析**：
当用户要求分析个股时，必须进行横向对比：
- 主要竞争对手识别
- 核心指标对比表：

| 毛利率 | - | - | - |
| 净利率 | - | - | - |
| 市占率 | - | - | - |
| PE/PB | - | - | - |

**板块走势与资金关注**：
- 所属板块整体趋势判断
- 板块是否放量、是否有资金持续流入
- 个股与板块走势关系（强于/弱于板块）

### 第七维度：公司战略体系分析

**分析目标**：评估公司战略规划与执行能力

**战略分析框架（PESTEL + 内部资源）**：

## 第九维度：量化估值评估

**分析目标**：给出客观的估值水平判断

### 9.1 估值方法选择矩阵

| 行业特征 | 推荐估值方法 | 辅助方法 |
|---------|-------------|---------|
| 成熟稳定（消费、银行） | PE、PB | DCF、股息率 |
| 成长型（科技、医药） | PEG、PS | DCF（高权重） |
| 强周期（钢铁、煤炭） | PB、EV/EBITDA | 股息率 |
| 资产驱动（地产、保险） | NAV、PB | PE（谨慎） |
| 初创/亏损（新能源、AI） | PS、用户数 | DCF（高折现率） |

### 9.2 核心估值指标阈值

#### PE估值判断标准
| PE区间 | 判断 | 说明 |
|-------|------|------|
| PE < 0 | 亏损 | 需结合其他指标判断 |
| 0 < PE < 10 | 极低 | 价值低估/周期低谷/市场偏见 |
| 10 < PE < 20 | 合理偏低 | 优质公司合理区间 |
| 20 < PE < 35 | 合理偏高 | 成长性公司正常区间 |
| 35 < PE < 50 | 偏高 | 需要高增长验证 |
| PE > 50 | 泡沫区 | 需要极强的成长故事支撑 |

#### PB估值判断标准
| PB区间 | 判断 | 说明 |
|-------|------|------|
| PB < 1 | 破净 | 资产重/市场偏见/价值陷阱 |
| 1 < PB < 2 | 合理偏低 | 传统行业正常区间 |
| 2 < PB < 5 | 合理偏高 | 品牌溢价/轻资产 |
| 5 < PB < 10 | 偏高 | 强品牌/高ROE |
| PB > 10 | 极高 | 需极强的护城河支撑 |

#### ROE与PB联动分析
| ROE | 合理PB区间 | 逻辑 |
|-----|-----------|------|
| ROE < 5% | PB < 1 | 资产效率低 |
| 5% < ROE < 10% | 1 < PB < 2 | 一般效率 |
| 10% < ROE < 15% | 2 < PB < 4 | 良好效率 |
| 15% < ROE < 25% | 4 < PB < 8 | 优秀效率 |
| ROE > 25% | PB > 8 | 顶级效率 |

## 投资方向筛选框架

### 三大投资方向

| 方向 | 特征 | 筛选标准 |
|-----|------|---------|
| 高景气度行业 | 业绩好、增速快 | 行业增速 > GDP增速2倍、龙头公司连续2年营收增速 > 30% |
| 传统行业转型 | 估值重塑机会 | 传统业务稳定、转型业务占营收 > 20%且高增长 |
| 困境反转 | 超跌修复 | 股价跌幅 > 50%、基本面无致命缺陷、拐点信号出现 |

### 筛选步骤
1. 确定投资方向类型
2. 在该方向内筛选标的
3. 与竞争对手横向对比
4. 验证板块走势与资金动向
5. 综合评估后给出投资建议
