# 视频脚本与剪辑方案

## 理解需求的步骤

1. **提取关键信息**：
   - 视频类型：宣传/教程/日常/vlog/影评/电商
   - 时长要求：15s / 60s / 3min / 自定义
   - 风格：正式/活泼/电影感/搞笑
   - 目标受众：年轻人/商务/儿童/大众

2. **生成剪辑脚本**（结构化输出）：

```
# 视频脚本：《[主题]》
类型：[类型] | 时长：[时长] | 风格：[风格]

## 整体结构
- [00:00-00:05] 片头：...
- [00:05-00:XX] 第1段：...
- [00:XX-00:XX] 第2段：...
- [00:XX-END] 片尾：...

## 配音文案
[完整配音/旁白文案，可供 TTS 使用]

## BGM 建议
风格：[活泼/舒缓/激昂]
参考：[轻音乐/电子/古典]

## 字幕样式
类型：普通字幕 / 动感字幕 / 特效字幕
```

## 视频类型剪辑策略

| 类型 | 重点 | 时长建议 |
|---|---|---|
| 宣传片 | 片头吸睛、产品亮点、结尾CTA | 30s~2min |
| 教程 | 步骤清晰、重点高亮、字幕完整 | 3~10min |
| vlog | 节奏轻快、BGM 配合、真情实感 | 1~5min |
| 影评 | 先声夺人、情节梳理、观点输出 | 3~10min |
| 电商 | 产品特写、功能演示、促销信息 | 15s~60s |
| 混剪 | 节奏卡点、镜头张力、转场自然 | 30s~3min |

## 脚本输出规范

- 时长精确到秒（视频帧级控制）
- 每段标注运镜/景别建议（远/中/近/特写）
- 配音文案须可直接用于 TTS（避免生僻字）
