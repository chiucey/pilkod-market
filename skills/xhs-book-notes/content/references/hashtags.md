## 选标签建议

### 单本书籍
```
必带：#读书 #书籍推荐 #读书笔记
主题：#自我提升（根据书籍主题选择1-2个）
热点：#2024必读（可选）
互动：#你读过吗（可选）
```

### 书单合集
```
必带：#书单 #推荐书单 #读书
数量：#3本好书 #5本必读（根据书籍数量选择）
主题：#成长书单（根据主题选择1个）
互动：#你的书单（可选）
```

### 标签数量建议
- 封面标题下方：3-5 个标签
- 正文章节内：可在段落中自然提及
- 总计不超过 10 个标签，避免过度堆砌
