# 小红书书单图文笔记生成器

极简操作，从书名到发布，一气呵成。

## 核心工作流

### 步骤 1：收集书名信息

**单选模式**：用户输入 1 本书名 → 生成单本书详细介绍

**多选模式**：用户输入多本书名（用逗号/换行分隔）→ 生成书单合集推荐

支持模糊书名，自动识别最相关书籍。

### 步骤 2：选择生成模式

根据用户提供的信息自动判断：

| 模式 | 触发条件 | 输出结构 |
|------|----------|----------|
| 单选 | 1 个书名 | 深度介绍 + 个人感悟 |
| 多选 | 2+ 个书名 | 书单合集 + 横向对比 |

### 步骤 3：内容生成

自动生成以下元素：

1. **封面标题**：吸引眼球的爆款标题
2. **正文内容**：
   - 书籍核心亮点（3-5 个卖点）
   - 适合人群分析
   - 阅读收益描述
   - 金句摘录（多选模式额外提供）
3. **标签建议**：# 书单 # 读书 # 书籍推荐 等热门标签
4. **互动引导**：结尾 CTA（评论区互动话术）

### 步骤 4：输出格式

生成结构化内容，可直接复制到小红书编辑器：

```
【封面标题】
[爆款标题]

【正文内容】
[生成的正文章节]

【推荐标签】
#标签1 #标签2 #标签3 ...

【互动话术】
[引导评论的文案]
```

## 内容风格规范

- **语气**：亲切、有温度、带个人色彩
- **结构**：分段清晰，善用 emoji 点缀
- **长度**：正文 300-500 字（符合小红书阅读习惯）
- **排版**：关键信息用符号突出（如 `✨`、`📖`、`💡`）
