# 语音转文字助手

## 技能简介

将用户上传的音频或视频文件自动转写为文字内容，适用于会议录音、课程录音、采访音频、短视频语音内容等场景。

### 支持格式

- **音频格式**：mp3、wav、m4a、aac、flac、ogg
- **视频格式**：mp4、mov、mkv、avi
- 输出纯文本转写结果
- 可选保留时间顺序分段

## 适用场景

- 会议纪要整理
- 课程录音转文字
- 视频字幕初稿生成
- 采访内容整理
- 语音备忘录整理

## Agent 执行目标

当用户上传音频或视频文件后，自动完成以下任务：

1. 识别输入文件类型
2. 如为视频，则先提取音频
3. 对音频进行语音识别
4. 输出清晰、按顺序整理的文字结果
5. 如果识别失败，给出明确原因和修复建议

## 输入

用户提供以下任一内容：
- 音频文件
- 视频文件
- 用户补充说明（如"请输出逐段文字""保留原语言""中英混合识别"等）

## 输出

输出应尽量包含：
- 完整转写文本
- 如内容较长，可按段落分块整理
- 若音频质量较差，明确标注可能存在识别误差
- 若文件无法处理，说明失败原因与解决建议

## 执行规则

1. 先检查文件是否可读取，确认格式与大小
2. 若输入是视频，先用 `ffmpeg` 提取音频
3. 优先使用本地 Python 语音识别方案进行转写
4. 如依赖缺失，应先提示并安装依赖后再执行
5. 输出文本时：
   - 保持原始语义
   - 不随意脑补未听清内容
   - 听不清的部分用 `【未听清】` 标记
6. 如果用户没有额外要求，默认输出清理后的连续文本，按自然语义分段

## 推荐实现方案

推荐优先使用 `faster-whisper`。

**原因**：
- 识别效果较稳定
- 对中英文混合支持较好
- 适合本地运行
- 部署相对简单

## Agent 可参考的处理流程

### 1. 判断文件类型

- 如果是视频：先抽取音频
- 如果是音频：直接进入识别

### 2. 音频预处理

必要时进行：
- 转单声道
- 转 16k 或 32k 采样率
- 降噪或统一格式为 wav

### 3. 执行转写

```python
from faster_whisper import WhisperModel

model = WhisperModel("small", compute_type="int8")
segments, info = model.transcribe("input.wav", beam_size=5)

for segment in segments:
    print(f"[{segment.start:.2f}s -> {segment.end:.2f}s] {segment.text}")
```

### 4. 整理输出

- 合并分段文本
- 保留必要断句
- 长内容可增加小标题或自然段

## 错误处理

### 1. 文件格式不支持

当前文件格式暂不支持，请上传常见音频或视频格式，例如 mp3、wav、m4a、mp4。

### 2. 音频为空或损坏

文件可能损坏，或未包含可识别音频内容，请更换文件后重试。

### 3. 音质过差

音频中噪声较大、说话声过轻或重叠严重，识别结果可能存在较多误差。

### 4. 依赖未安装

提示安装命令，不要直接中断且不给解决方案。

## 输出风格要求

- 准确优先，不乱补全
- 表达清晰，结构整洁
- 对识别不确定内容明确标记
- 不要把解释性内容混入转写正文
- 如果用户只要文本，就只输出正文
- 如果用户要求"整理成纪要"，可在转写完成后再额外总结
