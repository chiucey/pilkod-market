# 黄金ETF与纳指ETF每日盯盘助手

## 核心功能

本技能结合实时新闻、市场数据和专业分析框架，为您的黄金ETF和纳指ETF持仓提供交易决策支持。

## 分析维度

### 1. 黄金ETF分析框架

**价格驱动因素：**

- **美元实际利率**：美元实际利率与金价呈负相关，降息周期利好黄金
- **全球央行购金**：央行购金行为是金价的重要支撑，尤其是去美元化背景
- **地缘政治风险**：地区冲突、战争威胁提升避险需求
- **通胀水平**：高通胀环境下黄金对冲价值凸显
- **避险情绪**：市场波动加剧时资金流向黄金

**技术信号识别：**

- 金价突破关键阻力位（如5000美元/盎司心理关口）
- 黄金ETF净值创历史新高
- 黄金相关板块（如黄金股ETF）表现领先

### 2. 纳指ETF分析框架

**价格驱动因素：**

- **美联储政策**：加息利空科技股，降息利好成长股
- **科技股业绩**：苹果、微软、谷歌等权重股财报影响指数走势
- **宏观经济**：GDP、就业数据、CPI影响市场预期
- **估值水平**：纳指100估值处于历史高位时的调整风险
- **市场情绪**：VIX波动率、美股期货走势

**技术信号识别：**

- 纳指期货大幅下跌（如纳指100期货跌超1%）
- 科技股板块轮动信号
- 英伟达、苹果等权重股走势

### 步骤1：收集实时新闻

```json
  ]

```

### 步骤2：分析新闻影响

**黄金ETF新闻分析：**

1. 提取与黄金相关的宏观经济新闻（美元、利率、通胀）
2. 识别地缘政治事件（中东冲突、俄乌局势等）
3. 追踪央行购金动态和机构预测
4. 评估避险情绪变化

**纳指ETF新闻分析：**

1. 关注美联储官员讲话和货币政策信号
2. 分析大型科技股业绩发布
3. 评估宏观经济数据对科技股的影响
4. 监测美股期货盘前走势

### 步骤3：生成交易信号

**信号等级：**

- **强烈买入**：多个积极因素共振，技术面突破关键点位
- **谨慎买入**：基本面改善但估值偏高
- **持有观望**：无明显方向，等待更多信号
- **谨慎卖出**：估值过高或出现利空因素
- **强烈卖出**：趋势逆转信号明确
