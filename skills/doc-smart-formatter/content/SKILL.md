# Word文档智能排版技能

## 功能概述

本技能提供Word文档智能排版功能，能够：
- 自动识别文档中的标题层级（一级、二级、三级标题等）
- 智能分析文本样式和格式
- 应用标准中文排版规范（首行缩进、段落间距等）
- 统一字体和字号设置
- 生成专业排版的Word文档

## 排版规范

### 默认排版设置

| 项目 | 设置值 |
|------|--------|
| 正文字体 | 宋体/SimSun |
| 正文字号 | 小四 (12pt) |
| 标题字体 | 黑体/SimHei |
| 一级标题 | 三号 (16pt)，居中，加粗 |
| 二级标题 | 小三 (15pt)，左对齐，加粗 |
| 三级标题 | 四号 (14pt)，左对齐，加粗 |
| 英文/数字字体 | Times New Roman |
| 行距 | 固定值 24磅 |
| 段前间距 | 0行 |
| 段后间距 | 0行 |
| 首行缩进 | 2字符 |

### 标题识别规则

系统通过以下规则智能识别标题级别：
1. **段落格式分析**：检测段落是否单独成行且长度适中
2. **关键词匹配**：
   - 一级标题：第X章、第X部分、第一/二/三/四...
   - 二级标题：X.X格式、第一节、第一条...
   - 三级标题：X.X.X格式、小节...
3. **字体加粗**：包含加粗样式的段落优先识别为标题
4. **行首字符分析**：数字序号、大写字母开头等

## 使用方法

### 上传文档
支持以下格式：
- `.docx` - Microsoft Word 2007及以上版本
- `.doc` - 早期Word格式（自动转换）
- `.txt` - 纯文本文件

### 处理流程
1. 用户上传原始文档
2. 系统自动分析文档结构
3. 应用智能识别算法检测标题级别
4. 按照排版规范格式化文档
5. 生成排版后的文档供下载

### 输出格式
- 格式：`.docx`
- 编码：UTF-8
- 兼容：Microsoft Word 2007+

## 技术实现

使用Python语言开发，核心依赖：
- `python-docx`：Word文档读写
- `python-docx-template`：模板处理
- `pypandoc`：文档格式转换

## 应用场景

- 学术论文排版
- 办公文档规范化
- 电子书格式整理
- 政府公文排版
- 教材章节格式化
