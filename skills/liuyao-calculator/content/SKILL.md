# 六爻卦象测算

遵循《增删卜易》野鹤老人古法的六爻测算技能。

## 核心功能

### 1. 卦象装卦
根据用户输入的六个爻象（从初爻到上爻），自动计算：
- 本卦名称（64卦之一）
- 上下卦组合
- 变卦（动爻变化后的卦象）
- 互卦（二三四五爻组成的交互之卦）

### 2. 纳甲装卦（浑天甲子）
为每个爻装配：
- 天干地支（纳甲）
- 六亲（官鬼、子孙、妻财、兄弟、父母）
- 六神（青龙、朱雀、勾陈、螣蛇、白虎、玄武）

### 3. 世应定位
根据八宫规则确定世爻和应爻的位置

### 4. 吉凶判断
依据《增删卜易》原文断语进行判断：

| 事项类型 | 用神 | 判断规则 |
|---------|------|---------|
| 求名/考试 | 官鬼 | 官鬼持世即许成名，子孙持世自首无成 |
| 求财 | 妻财 | 财爻持世必得，兄弟持世难求 |
| 疾病 | 官鬼 | 官鬼持世难愈，子孙持世易安 |
| 忧虑 | 子孙 | 子孙持世无忧，官鬼持世忧疑难解 |
| 婚姻 | 妻财/官鬼 | 男占妻财持世得佳偶，女占官鬼持世得良缘 |
| 出行 | 父母 | 父母持世出行吉，官鬼持世不宜行 |
| 流年 | 世爻 | 财爻子孙持世亨通，官鬼持世见灾非 |

## 输入要求

### 爻象输入
用户需要提供六个爻，从上爻到初爻：
- 老阳（○）：动爻，阳变阴
- 少阳（—）：静爻，阳不变
- 老阴（×）：动爻，阴变阳
- 少阴（--）：静爻，阴不变

### 干支输入
需要输入四柱：
- 年柱：年干 + 年支
- 月柱：月干 + 月支
- 日柱：日干 + 日支
- 时柱：时干 + 时支

天干：甲、乙、丙、丁、戊、己、庚、辛、壬、癸
地支：子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥

### 问题描述
用户需要说明占卜的具体事项

## 输出内容

1. **六爻排盘**：完整的六爻盘显示
2. **本卦信息**：卦名、上下卦、周易卦辞
3. **变卦信息**：动爻变化后的卦象
4. **互卦信息**：二三四五爻组成的互卦
5. **吉凶判断**：依据《增删卜易》的直接断语
6. **趋避建议**：具体的趋吉避凶建议
7. **应期判断**：事情应验的时间预测

## 执行流程

### 步骤 1：收集信息
1. 询问用户的问题类型
2. 获取六个爻象（从上爻到初爻）
3. 获取四柱干支信息

### 步骤 2：执行测算
调用核心算法计算：
- 卦象名称、世应位置
- 纳甲装卦
- 动变分析
- 用神判断

### 步骤 3：输出结果
1. 展示六爻排盘
2. 给出《增删卜易》原文断语
3. 提供吉凶判断
4. 给出具体建议

## 注意事项

1. 爻象输入顺序：必须从上爻到初爻（从上到下）
2. 动爻判断：老阳和老阴为动爻，会产生变卦
3. 世应标记：世爻代表自己，应爻代表对方或环境
4. 用神选择：根据问题类型选择对应的六亲作为用神

## 快速示例

**问：** 帮我算一卦，我想知道这次考试能不能通过

**答：**
- 用户需要提供六个爻象
- 需要提供四柱干支（可用万年历查询）
- 测算后给出判断结果
