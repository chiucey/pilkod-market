# 提示词自动提升技能 - 使用指南

## 技能概述

「提示词自动提升器」是一个持续学习型的AI辅助工具。它通过分析用户满意的成果，自动反推和优化提示词，形成一个不断改进的反馈循环。

## 核心价值

1. **知识沉淀**：将每次成功的交互经验转化为可复用的提示词模板
2. **效率提升**：相同类型的任务，后续使用优化后的提示词可获得更快、更好的结果
3. **隐性知识显性化**：将用户未明说的期望显式编码到提示词中

## 工作流程详解

### 触发阶段

技能会在以下情况自动触发：

```
用户确认成果满意 → 系统分析成果特征 → 反推优化提示词
```

**触发信号识别**：
- 用户的正面反馈："很好"、"完美"、"正是我想要的"
- 成果达到预期目标
- 用户明确要求："帮我优化这个提示词"

### 分析阶段

系统会从以下维度分析用户满意的成果：

| 分析维度 | 内容 | 示例 |
|---------|------|------|
| 结构特征 | 输出的组织方式 | 是否分点、是否有目录 |
| 风格特征 | 表达方式和语气 | 正式/口语、专业/通俗 |
| 深度特征 | 内容详细程度 | 简要概述 vs 深度分析 |
| 格式特征 | 呈现方式 | 纯文本/表格/代码块 |
| 边界特征 | 明确的限制条件 | 字数限制、禁止内容等 |

### 反推阶段

基于分析结果，系统会反推能够产生此成果的提示词：

**反推要素**：
1. 角色定位：AI应该扮演什么角色
2. 任务描述：需要完成什么任务
3. 背景信息：需要什么上下文
4. 输出要求：具体格式和规范
5. 约束条件：必须遵守的限制
6. 示例参考：期望的输出样例

**反推示例**：

用户原始提示词：
> "帮我写一封辞职信"

用户满意的成果特征：
- 专业正式的语气
- 结构清晰（开头、主体、结尾）
- 表达感恩之情
- 简洁但完整

反推后的优化提示词：
```
你是一位资深HR专家。请帮我撰写一封辞职信，要求：
1. 语气专业、得体，表达对公司的感谢
2. 结构清晰，包含：开头（表明意图）、主体（简要说明原因）、结尾（送上祝福）
3. 长度控制在200-300字
4. 不要过于情绪化，保持职业态度
```

### 对比阶段

系统会将反推提示词与原提示词进行对比：

```
┌─────────────────────────────────────────────────────┐
│                    对比分析报告                      │
├─────────────────────────────────────────────────────┤
│ 原提示词：帮我写一封辞职信                           │
│                                                     │
│ 优化差异：                                           │
│ ✗ 缺少角色定义 → ✓ 增加"资深HR专家"角色              │
│ ✗ 语气模糊 → ✓ 明确"专业正式、表达感恩"              │
│ ✗ 结构无要求 → ✓ 增加三段式结构要求                  │
│ ✗ 无长度限制 → ✓ 增加字数范围                       │
│ ✗ 无风格约束 → ✓ 增加"不情绪化"约束                 │
└─────────────────────────────────────────────────────┘
```

### 优化阶段

融合反推提示词中的优质要素，生成增强版：

**优化原则**：
- 保留原提示词的核心意图
- 增量改进，每次优化聚焦关键差异
- 表述清晰明确，避免歧义

### 存储与应用阶段

**存储位置**：`/memories/prompt-enhancements/`

**文件命名**：`pmt_{md5哈希前12位}.json`

**存储内容**：
```json
{
  "id": "pmt_a1b2c3d4e5f6",
  "original_prompt": "帮我写一封辞职信",
  "enhanced_prompt": "你是一位资深HR专家...",
  "improvement_notes": "增加角色定义、明确语气要求、增加结构约束",
  "created_at": "2024-01-15T10:30:00",
  "success_count": 0,
  "last_used": null
}
```

**自动应用**：
- 系统维护提示词索引
- 当检测到相似输入时，自动调用优化版本
- 在响应开始时说明："检测到相似提示词，已应用优化版本"

## 使用场景

### 场景1：文档撰写优化

**用户**：帮我写一份产品介绍

**优化过程**：
- 系统识别用户满意的文档特点
- 反推包含：目标受众、关键卖点、结构要求、风格指南
- 后续相同类型任务自动套用

### 场景2：代码生成优化

**用户**：写一个Python函数计算斐波那契数列

**优化过程**：
- 分析用户满意的代码特征
- 反推包含：输入输出类型、错误处理、注释要求、命名规范
- 后续代码生成任务应用相同标准

### 场景3：报告生成优化

**用户**：分析一下Q3的销售数据

**优化过程**：
- 识别用户期望的报告结构
- 反推包含：分析维度、图表要求、结论格式、建议框架
- 后续数据分析任务自动套用

## 最佳实践

### 给用户的建议

1. **给予明确反馈**：明确告诉AI哪些地方做得好
2. **渐进优化**：不要期望一次性完美，持续微调
3. **记录优化**：可以查看 `/memories/prompt-enhancements/` 了解已优化的提示词

### 维护提示词库

定期检查优化后的提示词：
- 评估实际效果
- 根据新经验继续调整
- 删除不再适用的旧模板

## 技术细节

### 相似度匹配算法

采用多级匹配策略：

1. **精确匹配**：直接匹配MD5哈希
2. **模糊匹配**：基于关键字重叠率（阈值70%）
3. **语义匹配**：基于意图相似度（未来升级）

### 更新机制

- 同一提示词可多次优化
- 新优化会与历史版本合并
- 保留优化历史便于回溯

## 常见问题

**Q: 优化后的提示词不满意怎么办？**
A: 可以手动编辑存储的JSON文件，或通过新的交互继续优化。

**Q: 如何查看已优化的提示词？**
A: 查看 `/memories/prompt-enhancements/` 目录下的JSON文件。

**Q: 可以删除某个优化吗？**
A: 直接删除对应的JSON文件即可。

**Q: 不同项目需要不同的优化策略怎么办？**
A: 系统支持多组优化映射，可以按项目/类型分别管理。
