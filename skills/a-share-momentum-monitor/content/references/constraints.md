# 约束与边界情况说明

## 一、输出格式约束

### 1.1 数值格式
| 类型 | 格式要求 |
|------|----------|
| 比例和涨跌幅 | 保留两位小数，百分比显示（如 3.25%） |
| 天数 | 整数输出 |
| N/A | 与0严格区分 |
| 空值 | 明确输出"N/A"，不得留空 |

### 1.2 输出结构
- 报告必须包含4个主要章节
- 结论数量控制在3-6条
- 口径说明不得省略

## 二、数据处理约束

### 2.1 真实数据原则
- 所有统计必须基于真实数据
- 不得编造、不得补值
- 缺失数据必须明确说明

### 2.2 计算边界
| 情况 | 处理方式 |
|------|----------|
| 某指数无上涨日 | 上涨日成分股上涨家数占比 = N/A |
| 某指数无下跌日 | 下跌日成分股下跌家数占比 = N/A |
| 指数平盘 | 指标3同向占比 = N/A，备注说明 |
| 静态成分股替代 | 结果中明确标注 |

### 2.3 成分股有效样本
以下情况不纳入当日分母：
- 停牌股票
- 缺失行情数据
- 无法判断涨跌方向

平盘股票处理：
- 计入有效成分股总数
- 不计入上涨家数
- 不计入下跌家数

## 三、内容约束

### 3.1 禁止事项
- ❌ 禁止写投资建议
- ❌ 禁止写泛泛而谈的技术分析
- ❌ 禁止编造数据
- ❌ 禁止省略口径说明

### 3.2 结论撰写原则
结论应聚焦于：
- 客观事实描述
- 数据对比分析
- 明确的数据缺口说明

## 四、边界情况清单

### 4.1 交易日相关
| 情况 | 处理 |
|------|------|
| 今日非A股交易日 | 直接输出"今日非A股交易日，不执行计算。" |
| 今日为交易日但历史数据不足10日 | 统计窗口调整为可得的交易日数 |

### 4.2 数据缺失相关
| 情况 | 处理 |
|------|------|
| 某指数某日行情缺失 | 在备注中说明，不参与该日统计 |
| 成分股数据不可得 | 仅统计有效样本，说明缺失原因 |
| 历史成分股不可得 | 使用静态成分股，标注替代情况 |

### 4.3 计算异常相关
| 情况 | 处理 |
|------|------|
| 有效样本为0 | 输出0，备注说明 |
| 所有样本平盘 | 同向占比 = N/A |
| 分母为0 | 输出N/A，避免除零错误 |

## 五、质量检查清单

执行报告生成前检查：

- [ ] 今日是否为A股交易日已确认
- [ ] 最近10个交易日列表已获取
- [ ] 所有8个指数数据已读取
- [ ] 直接读取项与计算项已区分
- [ ] 数值格式已统一（两位小数、百分比）
- [ ] N/A与0已区分
- [ ] 数据缺口已明确标注
- [ ] 口径说明已包含
- [ ] 结论数量在3-6条范围内
- [ ] 无投资建议或主观臆测
