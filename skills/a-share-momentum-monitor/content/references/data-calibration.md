# 数据口径说明

## 一、成分股口径

### 1.1 优先规则
- **优先使用**：对应交易日当日成分股口径（历史成分股回溯）
- **退化规则**：若数据源不支持历史成分股回溯，则退化为最近一个可得交易日的静态成分股口径
- **标注要求**：若使用静态成分股替代历史成分股，必须在结果中明确标注

### 1.2 有效样本口径

- **分母统计规则**：每日分母仅统计"当日有有效行情且能判定涨跌方向"的成分股
- **排除项**：停牌、缺失行情、无法判断涨跌方向的股票，不纳入当日分母
- **平盘处理**：平盘股票计入有效成分股总数，但不计入上涨家数和下跌家数

## 二、涨跌方向口径

### 2.1 优先规则
- 若API已直接提供涨跌方向，则直接使用
- 若API未提供涨跌方向，但提供涨跌幅，按以下规则派生

### 2.2 派生规则
| 涨跌幅 | 涨跌方向 |
|--------|----------|
| > 0 | 上涨 |
| < 0 | 下跌 |
| = 0 | 平盘 |

## 三、指数原始行情字段（直接读取）

以下字段若API已提供，必须直接取值，不重复计算：

| 字段类型 | 字段名称 |
|----------|----------|
| 交易日历 | 今日是否为A股交易日 |
| 交易日历 | 最近10个A股交易日列表 |
| 交易日历 | 今日日期 |
| 交易日历 | 上一交易日日期 |
| 指数行情 | 指数当日涨跌幅 |
| 指数行情 | 指数当日涨跌额 |
| 指数行情 | 指数当日收盘价 |
| 指数行情 | 指数当日涨跌方向 |
| 指数行情 | 指数最近10个交易日逐日涨跌幅 |
| 指数行情 | 指数最近10个交易日逐日涨跌方向 |
| 成分信息 | 各指数对应交易日的历史成分股列表 |
| 成分行情 | 成分股当日涨跌幅 |
| 成分行情 | 成分股当日涨跌方向 |
| 成分行情 | 成分股最近10个交易日逐日涨跌幅 |
| 成分行情 | 成分股停牌状态 |
| 成分行情 | 成分股是否有有效行情数据 |

## 四、数据缺口处理

### 4.1 允许的缺口情况
- 某指数某日无行情数据
- 历史成分股数据不可得
- 成分股停牌导致样本减少

### 4.2 处理原则
- 数据缺口必须明确说明
- 不得自行补值或插值
- 在备注列标注缺失原因
- 分母仅统计有效样本
