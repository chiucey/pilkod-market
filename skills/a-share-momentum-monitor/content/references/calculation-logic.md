# 计算逻辑说明

## 指标1：最近10个交易日指数方向统计

### 计算公式

对于每个指数，统计最近10个交易日中的：

```
上涨天数 = count(交易日涨跌方向 == "上涨")
下跌天数 = count(交易日涨跌方向 == "下跌")
平盘天数 = count(交易日涨跌方向 == "平盘")
```

### 数据来源
- 若API直接提供每个交易日的指数涨跌方向，基于该方向字段统计
- 这是聚合统计项，必须计算

### 输出格式
| 字段 | 说明 |
|------|------|
| 指数名称 | - |
| 上涨天数 | 整数 |
| 下跌天数 | 整数 |
| 平盘天数 | 整数 |
| 备注 | 特殊说明 |

## 指标2：成分股同向家数占比（汇总加权口径）

### 2.1 上涨日成分股上涨家数占比

**定义**：仅在最近10个交易日中该指数"上涨"的日期内统计

**计算步骤**：

1. 筛选出最近10个交易日中指数上涨的日期（上涨日集合）
2. 对每个上涨日，读取该日该指数成分股数据：
   - 上涨股票家数
   - 有效成分股总数
3. 汇总计算：

```
上涨日成分股上涨家数占比
= 所有上涨日的上涨股票家数之和 / 所有上涨日的有效成分股总数之和
```

### 2.2 下跌日成分股下跌家数占比

**定义**：仅在最近10个交易日中该指数"下跌"的日期内统计

**计算步骤**：

1. 筛选出最近10个交易日中指数下跌的日期（下跌日集合）
2. 对每个下跌日，读取该日该指数成分股数据：
   - 下跌股票家数
   - 有效成分股总数
3. 汇总计算：

```
下跌日成分股下跌家数占比
= 所有下跌日的下跌股票家数之和 / 所有下跌日的有效成分股总数之和
```

### 2.3 特殊处理

| 情况 | 输出 |
|------|------|
| 最近10个交易日内无上涨日 | 上涨日成分股上涨家数占比 = N/A |
| 最近10个交易日内无下跌日 | 下跌日成分股下跌家数占比 = N/A |

### 2.4 辅助输出字段

| 字段 | 说明 |
|------|------|
| 上涨日样本天数 | 上涨日集合的元素数量 |
| 下跌日样本天数 | 下跌日集合的元素数量 |
| 上涨日累计有效样本总量 | Σ(每个上涨日的有效成分股总数) |
| 下跌日累计有效样本总量 | Σ(每个下跌日的有效成分股总数) |

## 指标3：今日指数表现与成分股同向占比

### 3.1 今日指数涨跌幅
- **规则**：若API已提供当日指数涨跌幅，则直接读取，不计算
- **格式**：保留两位小数，百分比显示

### 3.2 今日指数方向
- **规则**：若API已提供当日指数方向，则直接读取，不计算

### 3.3 今日成分股同向数量占比

**计算逻辑**：

```
若 今日指数方向 == "上涨":
    同向占比 = 今日上涨成分股家数 / 今日有效成分股总数

若 今日指数方向 == "下跌":
    同向占比 = 今日下跌成分股家数 / 今日有效成分股总数

若 今日指数方向 == "平盘":
    同向占比 = N/A
    备注：指数平盘，不统计同向占比
```

### 3.4 辅助输出字段

| 字段 | 说明 |
|------|------|
| 今日有效成分股总数 | 分母 |
| 今日上涨家数 | 分子（上涨情况） |
| 今日下跌家数 | 分子（下跌情况） |
| 今日平盘家数 | 仅作统计展示 |

## 计算优先级原则

1. **API直接提供**的字段 > 派生计算
2. 涨跌幅和涨跌方向若API已提供，禁止用收盘价自行推算
3. 仅对聚合统计项进行计算
4. 原始行情字段以API返回为准，除非缺失
