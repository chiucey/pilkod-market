# A股市场动量监控技能

## 技能概述

本技能用于生成A股收盘后全市场指数动量分析日报，监控8个主要宽基指数的动量特征。

## 监控指数范围

1. 中证全指 (000985)
2. 中证A500 (000510)
3. 沪深300 (000300)
4. 中证500 (000905)
5. 中证1000 (000852)
6. 创业板指 (399006)
7. 科创综指 (000688)
8. 科创50 (000688)

## 核心工作流程

### 第一步：交易日检查

1. 判断今天是否为A股交易日
2. 若非交易日，直接输出："今日非A股交易日，不执行计算。"
3. 若是交易日，获取最近10个A股交易日列表

### 第二步：数据获取

从API直接读取以下字段（不重复计算）：

- 今日是否为A股交易日
- 最近10个交易日列表
- 上一交易日日期
- 各指数当日涨跌幅
- 各指数当日涨跌方向
- 各指数最近10个交易日逐日涨跌幅
- 各指数成分股当日涨跌幅
- 成分股停牌状态

详细数据口径见 [references/data-calibration.md](./references/data-calibration.md)

### 第三步：指标计算

**指标1：最近10个交易日指数方向统计**
- 统计每个指数的上涨天数、下跌天数、平盘天数

**指标2：成分股同向占比（汇总加权口径）**
- 上涨日成分股上涨家数占比
- 下跌日成分股下跌家数占比
- 输出样本天数和累计样本量

**指标3：今日指数与成分股同向占比**
- 今日涨跌幅直接读取
- 同向占比 = 同向成分股数 / 有效成分股总数

详细计算逻辑见 [references/calculation-logic.md](./references/calculation-logic.md)

### 第四步：报告生成

按以下结构输出Markdown报告：

```
## A股收盘后全市场指数动量分析日报
- 运行日期
- 统计窗口
- 口径说明

### 1. 最近10个交易日指数方向统计
[表格]

### 2. 成分股同向家数占比
[表格]

### 3. 今日指数表现与成分股同向占比
[表格]

### 4. 简要结论
[3-6条聚焦性结论]
```

## 关键约束

1. **严格区分直接读取项与计算项**：API已提供的字段不重复计算
2. **真实数据**：所有统计必须基于真实数据，不得编造
3. **比例格式**：统一保留两位小数，百分比显示
4. **N/A处理**：指数平盘时同向占比输出N/A
5. **无投资建议**：不写投资建议，不写泛泛而谈的技术分析
6. **数据缺口说明**：缺失数据必须明确说明，不得补值

详细约束与边界情况见 [references/constraints.md](./references/constraints.md)

## 输出质量标准

- 所有比例和涨跌幅：保留两位小数，百分比显示
- 天数：整数输出
- N/A与0严格区分
- 口径说明不得省略
- 结论聚焦客观事实，不主观臆测
