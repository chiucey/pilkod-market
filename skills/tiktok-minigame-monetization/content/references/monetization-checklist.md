# TikTok小游戏广告变现完整检查清单

## 阶段1：账号与资质准备

### 开发者账号注册
- [ ] 访问TikTok开发者门户 (https://developers.tiktok.com/)
- [ ] 选择账号类型：个人 / 公司
- [ ] 填写基本信息（邮箱、手机号、地区）
- [ ] 完成邮箱验证
- [ ] 完成手机号验证
- [ ] 设置双重认证

### 开发者资质认证
- [ ] 选择认证类型
- [ ] 个人开发者：准备身份证信息
- [ ] 公司开发者：准备营业执照
- [ ] 提交资质认证申请
- [ ] 等待审核通过（1-7个工作日）
- [ ] 获取开发者认证证书

### 收款账户配置
- [ ] 选择收款方式（PayPal / Wise / 银行转账）
- [ ] 注册/登录收款账户
- [ ] 完成收款账户验证
- [ ] 在TikTok后台绑定收款账户
- [ ] 设置付款阈值（默认$100）
- [ ] 确认货币类型（USD）

### 税务信息
- [ ] 美国开发者：填写W-9表格
- [ ] 非美国开发者：填写W-8BEN表格
- [ ] 确认纳税人身份
- [ ] 了解预扣税规则

## 关键指标目标

| 指标 | 目标值 | 说明 |
|-----|-------|------|
| 日活用户 (DAU) | 1000+ | 稳定变现基础 |
| 用户留存率 (D1) | 40%+ | 第一天留存 |
| 用户留存率 (D7) | 15%+ | 一周留存 |
| 广告展示率 | 30-50% | 用户看广告比例 |
| 激励视频观看率 | 60%+ | 展示后观看比例 |
| 千次展示收益 (eCPM) | $10+ | 广告收益效率 |
| 用户生命周期价值 (LTV) | $1+ | 用户价值 |
