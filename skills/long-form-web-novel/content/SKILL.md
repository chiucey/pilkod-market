# 长篇网络小说协作创作技能

## 创作理念

**"好小说是聊出来的，不是憋出来的。"**

采用**对话引导法**，通过精心设计的问题和选项，启发作者理清创作思路，最终形成逻辑严密、爽点密集、付费点明确的详细大纲。

## Step 1: 确定赛道

### 引导话术

> "写小说第一步，选对赛道就成功了一半。让我们先确定你的小说类型。"

### 主流类型选项

| 类型 | 核心爽点 | 受众画像 | 变现难度 |
|------|----------|----------|----------|
| **玄幻修仙** | 废柴逆袭、境界突破、丹药神器 | 18-35岁男性为主 | ★★★☆☆ |
| **都市异能** | 扮猪吃虎、继承遗产、美女倒追 | 20-40岁男性 | ★★★☆☆ |
| **悬疑推理** | 烧脑反转、真相揭露、连环伏笔 | 全年龄段 | ★★★★☆ |
| **都市总裁** | 霸道总裁、甜宠虐恋、身份反转 | 18-45岁女性 | ★★☆☆☆ |
| **科幻末世** | 异能觉醒、领地建设、末日生存 | 20-35岁男性 | ★★★☆☆ |
| **历史穿越** | 权谋争斗、后宫争宠、科技碾压 | 25-45岁男性 | ★★★★☆ |

### 市场分析要点

告诉用户当前各平台：
- **起点中文网**：玄幻/仙侠/都市长篇依然是头部
- **晋江文学城**：女频甜宠、虐恋是主流
- **番茄小说**：免费阅读，男频爽文、短篇吃香
- **七猫小说**：赘婿、神医、战神三大热门赛道

### 询问模板

```
请告诉我：
1. 你最想写什么类型？（或者最擅长什么类型）
2. 你有特别偏好的爽点吗？比如"打脸"、"逆袭"、"甜宠"？
3. 你的目标读者是谁？（男性为主？女性为主？）
```

## Step 2: 构建世界观

### 核心四问

> "世界观是小说的地基，决定了故事的广度和深度。我们来聊聊你的世界。"

### 2.1 世界基础设定

| 问题 | 含义 | 示例 |
|------|------|------|
| **现实/架空/异界？** | 故事发生的空间 | 现实都市 / 异界大陆 / 未来星际 |
| **低武/中武/高武？** | 战斗力天花板 | 普通人→武林高手 / 凡人→陆地神仙 / 凡人→诸神 |
| **单世界/多世界？** | 地图范围 | 一国之内 / 多国纷争 / 诸天万界 |
| **当前社会形态？** | 世界氛围 | 封建王朝 / 现代都市 / 赛博朋克 |

### 2.2 能力体系设计（修仙/玄幻必答）

```
【标准九阶模板】
境界1-9：淬体境 → 炼气境 → 筑基境 → 金丹境 → 元婴境 → 出窍境 → 分神境 → 合体境 → 大乘境 → 渡劫境

【可选特色元素】
□ 天赋系统（天生属性：金木水火土/雷暗光暗）
□ 功法体系（内功/外功/炼体/神魂）
□ 丹药/炼器/阵法（副职业加分）
□ 契约/驭兽/召唤（战力拓展）
```

### 2.3 势力格局设定

每个势力用**三个关键词**定义：

```
【示例：青云宗】
标签：名门正派 | 剑修为主 | 隐世高人
实力：超一流（顶层战力：大乘境×3）
特点：收徒极严，一脉单传
掌门：清虚真人（表面公正，实则护短）
敌对势力：魔道三宗
主角关系：宗门弟子→被逐→复仇
```

### 2.4 地图阶段化设计

```
【新手村阶段】主角起步地，限制低战力天花板
    ↓ 突破解锁
【郡城/城区阶段】小势力盘踞，资源开始丰富
    ↓ 声望积累
【王都/主城阶段】大势力博弈，风云变幻
    ↓ 终极BOSS出现
【禁地/秘境的阶段】终极大决战
```

### 询问模板

```
请描述你的世界：
1. 这是一个什么样的世界？（都市/古代/异界/未来...）
2. 在这个世界里，力量是如何体现的？（修炼/科技/异能...）
3. 有哪些主要势力？主角会跟他们产生什么关系？
```

## Step 3: 设计人物

### 主角打造公式

```
【让读者爱上的主角】
= 悲惨起点（合理性）
+ 超强潜力（代入感）
+ 鲜明性格（记忆点）
+ 独特金句（传播度）
+ 反差萌（立体感）
```

### 3.1 主角人设模板

```markdown
## 【主角档案】

### 基础信息
- 姓名：（最好有特色，让人过目不忘）
- 性别：
- 年龄：（初登场时）

### 外在形象
- 身高/外貌特征：
- 标志性装扮：
- 给人留下的第一印象：

### 性格标签（选2-3个）
□ 杀伐果断 □ 重情重义 □ 痞气十足 □ 冷酷无情
□ 表面憨厚 □ 腹黑深沉 □ 护短狂魔 □ 亦正亦邪

### 核心人设（300字内）
用一句话概括你的主角：
"他是______的人，曾经______，如今______。"

### 悲惨背景（选1-2个）
□ 被家族抛弃/灭门
□ 被未婚妻退婚/被嘲讽
□ 被挚友背叛
□ 父母双亡/失踪
□ 天生废物/无法修炼
□ 深陷牢狱/困境

### 金句模板（提前设计3-5句）
1. "______"——体现______性格
2. "______"——体现______性格

### 反差萌设定
他在什么情况下会展现不同的一面？
（如：杀伐果断却在女主面前脸红）
```

### 3.3 配角与反派模板

```markdown
## 【重要配角/反派档案】

### 反派设计原则
1. 智商在线，不能是傻子
2. 有合理动机（不是纯坏）

### 每个重要角色必答
- 姓名：

### 询问模板

```
请跟我聊聊你的主角：
1. 他的名字是什么？有没有你特别喜欢的名字风格？
2. 他是什么样的性格？（冷酷型/热血型/腹黑型/痞帅型...）
3. 他的起点是什么？（被嘲笑的天才/家族弃子/普通少年...）
4. 你希望读者看到他时是什么感觉？（爽/心疼/想保护/想成为他...）

## Step 4: 规划冲突

### 核心公式

```
【爆款网文】
= 强冲突（每3000字至少一个高潮）
× 快节奏（章章有爆点）
× 深共鸣（主角经历映射读者梦想）
× 付费钩（每章结尾悬念）
```

### 4.1 主线矛盾设计

```markdown
## 【主线矛盾链】

### 核心悬念（贯穿全书）
"______？（用一句话概括全书最大谜题）"

### 主线阶段规划
| 阶段 | 字数 | 核心冲突 | 爽点密度 |
|------|------|----------|----------|
| 序章 | 0-2万字 | 开局设定+首个打击 | 高密度 |
| 第一卷 | 2-30万字 | 生存危机/初入势力 | 每3-5章一爆 |
| 第二卷 | 30-60万字 | 势力崛起/情感纠葛 | 每2-3章一爆 |
| 第三卷 | 60-100万字 | 格局决战/身世揭露 | 每1-2章一爆 |
| 终卷 | 100万字+ | 终极大决战 | 持续高潮 |

### 单元矛盾设计（5-10万字/单元）
每个单元需要：
- 独立矛盾（这一卷主要解决什么问题？）
- 核心配角（谁来推动矛盾？）
- 情感转折（主角心态/感情线变化？）
- 付费钩（这一卷结尾设什么悬念？）
```

### 4.2 爽点设计清单

```markdown
## 【爽点矩阵】（按出现顺序排列）

| 爽点类型 | 出现章节 | 具体场景描述 |
|----------|----------|--------------|
| 首次打脸 | 第3-5章 | 被羞辱→当众反击→众人震惊 |
| 天赋觉醒 | 第8-10章 | 隐藏天赋爆发→震惊全场 |
| 红颜初遇 | 第12-15章 | 女主登场→产生纠葛 |
| 宝物入手 | 第20-25章 | 获得关键道具/功法 |
| 势力打脸 | 第30-35章 | 让敌对势力付出代价 |
| 身份揭露 | 第50-60章 | 隐藏身份曝光→震惊 |
| 小弟追随 | 第70-80章 | 收服第一个小弟 |
| 师姐倒追 | 第90-100章 | 情感升温→倒追 |
```

### 4.3 付费钩设计

```markdown
## 【付费钩分布图】

### 断章钩（每章必备）
- 技巧：在章节70%处制造情绪最高点
- 话术："就在他即将______的时候——"
- 频率：每章至少1次

### 章节钩分布
| 位置 | 类型 | 示例 |
|------|------|------|
| 第5章结尾 | 身份钩 | 主角身世之谜初现 |
| 第10章结尾 | 情感钩 | 女主角落泪离开 |
| 第15章结尾 | 危机钩 | 强敌来袭，主角陷入绝境 |
| 第20章结尾 | 逆袭钩 | 绝地反击，打脸全场 |

### 大高潮节点（付费章节）
| 节点 | 位置 | 内容 |
|------|------|------|
| 第一个大高潮 | 30万字左右 | 首次越级战胜 |
| 第二个大高潮 | 60万字左右 | 身世揭露/身份逆转 |
| 第三个大高潮 | 90万字左右 | 终局决战前奏 |
| 终极大结局 | 100万字+ | 完美收尾+第二季伏笔 |
```

### 4.4 三重悬念链

```markdown
## 【悬念设计】

### 单元悬念（1-3章）
每2-3章解开一个
示例：
- "林凡能否赢得这场比赛？"→第3章解开
- "神秘老人是谁？"→第5-7章解开

### 主线悬念（贯穿全书）
每20-30章推进一次
示例：
- "林凡的父亲到底是谁？"→持续到50章
- "幕后黑手是谁？"→持续到80章

### 终局悬念（伏笔埋设）
每50章深化一次
示例：
- "诸天万界的真相是什么？"→100章揭示
- "林凡的终极命运？"→大结局
```

## 工作流程

**当用户要求创作长篇网络小说时：**

1. **启动协作模式**：告知用户将按步骤引导讨论
2. **按Step 1-4逐步推进**：每一步提供选项和引导问题
3. **等待用户反馈**：根据用户回答进行下一轮深化
4. **确认所有设计后**：输出万字级详细大纲
5. **提供分部选择**：用户选择从哪一部分开始正文创作
6. **逐部交付正文**：按大纲逐卷创作高质量章节

**核心原则**：
- 不催促用户，给足思考时间
- 每一步都提供选项和模板
- 鼓励用户提出自己的想法和创意
- 在用户不明确时，提供推荐选项
- 最终目标是产出**可执行、高质量、催更潜力强**的长篇网文
