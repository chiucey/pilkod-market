# 客户画像（Customer Persona）

## 工具概述

客户画像（Customer Persona）是通过收集和分析客户数据，构建虚拟客户原型，帮助企业深入理解目标客户。是一种"共情设计"工具，帮助团队建立以客户为中心的思维模式。

## 画像构建要素

### 基础属性维度

| 维度 | 说明 | 示例 |
|------|------|------|
| 人口统计 | 基本信息 | 年龄、性别、教育、收入、职业 |
| 地理特征 | 地理位置 | 一线城市、沿海地区、华东区域 |
| 行为特征 | 消费行为 | 购买频率、渠道偏好、决策周期 |
| 心理特征 | 态度价值观 | 品牌认知、生活态度、风险偏好 |
| 技术特征 | 数字化程度 | APP使用、社交媒体活跃度 |

### 痛点与需求

**痛点类型**：
- 功能性痛点（产品/服务不能满足需求）
- 流程性痛点（使用过程不顺畅）
- 情感性痛点（缺乏情感连接）
- 社会性痛点（社会认同需求未满足）
- 经济性痛点（价格/成本问题）

**需求层级**：
```
马斯洛需求层次：
         ▲
        /│\      自我实现
       / │ \     尊重需求
      /  │  \    社会需求
     /   │   \   安全需求
    /    │    \  生理需求
   ──────────────
```

## 客户画像模板

### 基础信息卡

```
┌─────────────────────────────────────────────────────────────────┐
│                       客户画像：{画像名称}                         │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  ┌─────────────┐                                                │
│  │   [头像]    │   姓名：{姓名}                                   │
│  │             │   年龄：{年龄段}                                 │
│  │             │   职业：{职业}                                    │
│  └─────────────┘   城市：{城市}                                   │
│                     收入：{收入水平}                               │
│                     家庭：{家庭状况}                               │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 特征描述

**日常生活**：
- 典型的一天如何度过
- 主要的时间和精力分配
- 关注的媒体和信息来源

**价值观与动机**：
- 最看重什么（时间/金钱/品质/效率）
- 驱动行为的核心动机
- 对产品和服务的期待

**痛点与挑战**：
- 最大的困扰是什么
- 现有解决方案的不足
- 希望解决但未解决的问题

**购买行为**：
- 决策周期多长
- 如何获取产品信息
- 信任什么类型的品牌/渠道
- 价格敏感度如何

**媒体触点**：
- 常用社交媒体
- 关注的KOL类型
- 获取信息的习惯

## 分析输出模板

### 画像对比矩阵

| 画像维度 | 画像A：年轻白领 | 画像B：企业高管 | 画像C：家庭用户 |
|---------|---------------|---------------|---------------|
| 核心需求 | 效率、品质 | 专业、便捷 | 性价比、安全 |
| 决策因素 | 口碑、体验 | 品牌、效果 | 价格、口碑 |
| 触达渠道 | 社交媒体 | 行业论坛、邮件 | 电商、门店 |
| 价格敏感度 | 中等 | 低 | 高 |
| 生命周期价值 | 中等 | 高 | 中高 |

### 优先级画像排序

```
1. 核心画像（Primary Persona）
   画像A - 年轻白领
   占比：40%
   特征：25-35岁，追求品质生活，注重效率

2. 次要画像（Secondary Persona）
   画像B - 企业高管
   占比：25%
   特征：35-45岁，高净值，专业导向

3. 边缘画像（Edge Persona）
   画像C - 家庭用户
   占比：20%
   特征：30-50岁，理性消费，性价比导向
```

## 应用场景

1. **产品设计**：指导功能优先级
2. **营销策略**：精准触达目标客户
3. **用户增长**：识别高价值用户
4. **客户服务**：个性化服务设计
5. **战略规划**：明确目标市场定位
