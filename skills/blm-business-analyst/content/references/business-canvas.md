# 商业画布（Business Canvas）

## 工具概述

商业画布（Business Model Canvas）由亚历山大·奥斯特瓦尔德（Alexander Osterwalder）提出，是一种用于描述和设计商业模式的视觉化工具。通过9个构建模块，帮助企业系统化地理解和设计商业模式。

## 九大构建模块

### 1. 客户细分 (Customer Segments)
**核心问题**：我们为谁创造价值？谁是我们最重要的客户？

**细分类型**：
- 大众市场（标准化产品）
- 利基市场（细分垂直领域）
- 细分市场（细分需求）
- 多元化市场（多种需求）
- 多边平台（多边客户）

**客户画像要素**：
- 基本属性（年龄、性别、收入）
- 行为特征（购买习惯、媒体偏好）
- 心理特征（价值观、态度）
- 痛点与需求

### 2. 价值主张 (Value Propositions)
**核心问题**：我们为客户解决什么问题？满足什么需求？

**价值主张类型**：
- 新颖性（全新技术/体验）
- 性能提升（更好性能）
- 定制化（个性化解决方案）
- 品牌体验（品牌价值）
- 价格优势（低成本）
- 成本降低（降低客户成本）
- 风险降低（降低客户风险）
- 可达性（让更多人获得）

**价值主张构建公式**：
```
[对谁] + [解决什么问题/满足什么需求] + [如何做到] + [差异化承诺]
例：为中小企业提供低成本、高可用的云服务，让他们无需投入大量IT基础设施即可享受企业级云计算能力
```

### 3. 渠道通道 (Channels)
**核心问题**：我们如何触达客户？如何建立联系？

**渠道类型**：

| 渠道类型 | 特点 | 适用场景 |
|---------|------|---------|
| 直销渠道 | 企业直接销售 | 高价值产品 |
| 合作伙伴渠道 | 渠道商/代理商 | 扩大覆盖 |
| 线上渠道 | 电商/APP | 标准化产品 |
| 线下渠道 | 门店/体验店 | 重体验产品 |

**渠道阶段管理**：
```
认知 → 评估 → 购买 → 交付 → 售后
  │      │      │     │      │
  │      │      │     │      └── 客户支持
  │      │      │     └── 价值交付
  │      │      └── 交易
  │      └── 方案评估
  └── 品牌认知
```

### 4. 客户关系 (Customer Relationships)
**核心问题**：我们与客户建立什么类型的关系？

**关系类型**：
- 私人助理（客服一对一）
- 专属私人助理（VIP服务）
- 自助服务（自动化服务）
- 自动化服务（AI客服）
- 社区（用户社区运营）
- 共创（与客户共同创造）

### 5. 收入来源 (Revenue Streams)
**核心问题**：客户愿意支付什么？我们如何获得收入？

**收入模式**：

| 模式类型 | 说明 | 案例 |
|---------|------|------|
| 资产销售 | 销售产品所有权 | 传统零售 |
| 使用费 | 按使用量收费 | 水电燃气 |
| 订阅费 | 定期付费 | 会员制 |
| 授权费 | 知识产权授权 | 专利授权 |
| 经纪费 | 中介服务费 | 房产中介 |
| 广告费 | 广告展示收费 | 媒体平台 |
| 平台费 | 平台交易抽成 | 电商平台 |

**定价策略**：
- 成本加成定价
- 竞争导向定价
- 价值导向定价
- 动态定价

### 6. 核心资源 (Key Resources)
**核心问题**：我们需要什么核心资源？

**资源类型**：
- 实体资源（工厂、设备）
- 知识资源（专利、品牌）
- 人力资源（核心人才）
- 财务资源（资金、融资）

### 7. 关键业务 (Key Activities)
**核心问题**：我们需要做什么关键业务？

**业务类型**：
- 生产制造
- 解决方案设计
- 平台/网络运营

### 8. 关键合作 (Key Partnerships)
**核心问题**：谁是我们的关键合作伙伴？

**合作类型**：
- 战略联盟
- 竞合关系
- 供应商关系
- 平台合作伙伴

### 9. 成本结构 (Cost Structure)
**核心问题**：商业模式运营的成本是什么？

**成本类型**：
- 固定成本（租金、工资）
- 可变成本（原材料、按量付费）
- 规模经济效应
- 范围经济效应

**成本导向分类**：
- 成本驱动（效率优先）
- 价值驱动（价值优先）

## 应用场景

1. **新业务设计**：从0到1设计商业模式
2. **现有业务优化**：分析改进机会
3. **竞品分析**：对比竞争商业模式
4. **战略沟通**：统一战略语言
5. **创业验证**：快速验证商业模式假设
