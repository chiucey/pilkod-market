> **方法论文档**：[`docs/方法论_从感性比喻到可复用投资框架.md`](../../../docs/方法论_从感性比喻到可复用投资框架.md)  
> **回测验证文档**：[`docs/二阶导视角_5案例回测_2026Q1.md`](../../../docs/二阶导视角_5案例回测_2026Q1.md)
>
> **本文目的**：详细说明"业绩二阶导"作为香槟塔分析的**第二个轴**，与香槟塔（空间维度）共同构成"估值魔方"双轴的具体方法。主 SKILL.md §6.5 给"5 步快速校验清单"，本文给完整方法、原理、领先指标体系、限制条件、案例数据。

> ⚠️ 二阶导视角**必须与香槟塔双轴使用**，单独使用会产生**EMS 模式假阳性**（详见 §7）。

## 1. 核心命题

**股价对业绩二阶导（增速变化）的敏感度，远大于对一阶导（增速绝对值）的敏感度。**

| 阶 | 含义 | 例 |
|---|---|---|
| 业绩本身 | 营收 / 净利绝对值 | 200 亿 |
| 一阶导 | YoY 增速 | +192% |
| 二阶导 | 本季 YoY - 上季 YoY | +90pp = 加速 / -28pp = 减速 |

**为什么股价 ~ 二阶导**：
- 股价 = 未来现金流贴现（反映**预期**）
- 当前一阶导（增速）已被 price in 在当前价位
- 真正驱动股价新涨幅的是**预期偏离当前预期**——即二阶导

## 2. 计算约定

### 2.1 单季 YoY 视角（推荐）

```
二阶导（pp） = 本季 YoY 增速 - 上季 YoY 增速
```

| 区间 | 节奏判定 |
|---|---|
| **二阶导 ≥ +15pp** | 强加速 |
| 二阶导 ∈ [+5pp, +15pp) | 弱加速 |
| 二阶导 ∈ [-5pp, +5pp] | **稳态** |
| 二阶导 ∈ (-15pp, -5pp] | 弱减速 |
| **二阶导 ≤ -15pp** | 强减速 |

### 2.2 全年 YoY 视角（基数极低或波动剧烈时使用）

当公司处于"小公司爆发期"或"基数效应剧烈"时，单季 YoY 可能因低基数失真（典型：寒武纪 2025Q1 单季 +4230%）。此时改用全年 YoY 跨年度对比：

```
二阶导（pp） = 当年 YoY - 上年 YoY
```

### 2.3 必须做的标准化处理

| 场景 | 处理 |
|---|---|
| 季节性强 | 用 4 个季度移动平均，或仅做 YoY（不做 QoQ） |
| 重大并购 / 资产剥离 | 排除并购贡献后再算 YoY |
| 会计准则变更（如 consign 模式切换） | 需用同口径还原；若不可还原，本工具失效 |
| 一次性补贴 / 资产处置 | 看扣非业绩（扣非营业利润 YoY） |

## 3. 5 步快速校验流程（与 SKILL.md §6.5 一致，此处展开）

### Step 1：取近 6-8 个季度的 YoY 增速序列

数据来源（推荐优先级）：
1. 公司财报（年报 / 季报附注）
2. 东方财富 / 同花顺 / Wind 季度数据
3. 第三方财经汇总（验证用）

**至少需要 6 个季度**才能识别出有意义的二阶导节奏；< 6 季度则跳过此校验。

### Step 2：计算每季度二阶导

```
Q   | YoY  | 二阶导
Q1  | +X%  | -
Q2  | +Y%  | (Y-X) pp
Q3  | +Z%  | (Z-Y) pp
...
```

**强制可视化**：用一张二阶导走势的简表呈现，不要用文字描述代替数字。

### Step 3：定位最新一期落入哪个区间

| 区间 | 标记 |
|---|---|
| 二阶导首次 +15pp 以上跃迁 | 🟢 加速拐点 |
| 二阶导持续 ≥ +5pp | 🟢 加速中 |
| 二阶导 ∈ [-5, +5pp] 已 ≥ 2 季度 | 🟡 稳态 |
| 二阶导首次 -15pp 以下转负 | 🔴 减速拐点（**先于物理瓶颈**）|
| 一阶导 ≈ 0 持续 ≥ 4 季度 | ⚪ 二阶导未启动 |

### Step 4：双轴定位 9 宫格

将"二阶导节奏（时间轴）"与"瓶颈层判定（空间轴）"交叉，落入 9 宫格：

|   | **空间：强瓶颈（≥5/6）** | **空间：次级瓶颈（4/6）** | **空间：非瓶颈/概念股** |
|---|---|---|---|
| **加速** | 🟢 **赔率最佳象限** | 🟡 流量行情（弹性受压制）| 🟡 主题加速（短线）|
| **稳态** | 🟡 持有 | 🟡 稳健仓位 | ⚪ 平淡，无主升浪 |
| **减速（转负）** | 🔴 **见顶警报** | 🔴 双重承压 | 🔴 主题退潮 |
| **未启动** | ⚪ 未到时点 | ⚪ 早期布局 | ⚪ **纯预期博弈/主题股** |

### Step 5：根据象限给出节奏建议（不是投资建议）

| 象限 | 节奏含义 | 与香槟塔 T 阶段的对应 |
|---|---|---|
| 🟢 强瓶颈 + 加速 | T2 末 / T3 早期，**赔率最佳** | T2→T3 |
| 🟡 强瓶颈 + 稳态 | T3 中段，持有但不加仓 | T3 |
| 🔴 强瓶颈 + 减速 | T3 中后段→T4 早期，**减仓评估** | T3 顶 / T4 |
| 🟢/🟡 次级瓶颈 + 加速 | 跟涨但弹性弱，仓位轻 | 同 T2-T3 但赔率压制 |
| 🔴 次级瓶颈 + 减速 | 双重承压，避开 | T4 |
| ⚪ 未启动 + 任何象限 | 主题博弈，与本 skill 无关 | T0 |

## 4. 二阶导拐点的领先指标体系（核心交付物）

> 二阶导本身在财报披露时是**同步**或**滞后**信号；但二阶导**未来的拐点**有领先指标。

### 4.1 领先 6-12 个月

| 信号 | 来源 | 解读 |
|---|---|---|
| L1 大客户 capex guidance | 大客户业绩说明会 / 年报 | capex 调增 → 6-12 月后传导到中游业绩 |
| 行业渗透率拐点 | 第三方机构数据（如 5%→15% 区间） | 渗透率非线性加速期 = 业绩二阶导即将转正 |
| 替代品 / 政策催化 | 国家政策 / 大客户技术路线 | 政策落地 → 6-12 月后订单兑现 |
| 重大长协公告 | 公司公告 | 锁定未来 6-18 月收入节奏 |

### 4.2 领先 3-6 个月

| 信号 | 来源 | 解读 |
|---|---|---|
| 合同负债 / 预收账款变化 | 资产负债表 | 预付模式行业的核心领先指标 |
| 预付款项变化（**直销大客户行业必看**）| 资产负债表 | 公司向上游凶猛备料 → 3-6 月后产出 |
| 存货中"原材料 + 在产品" | 资产负债表附注 | 备产强度的直接量化 |
| 在建工程同比 | 资产负债表 | 自身产能投放，3-6 月后释放 |
| 管理层 guidance 措辞变化 | 业绩说明会 | "维持" → "上调" 的措辞跃迁 |
| 大客户订单环比 | 公告 + 调研 | 订单环比加速 = 二阶导转正前奏 |

### 4.3 同步指标（财报披露时即时可见）

| 信号 | 来源 |
|---|---|
| 当期营业收入 / 净利润 YoY | 利润表 |
| 毛利率同比扩张 | 利润表 |
| 经营现金流 / 净利润比 | 现金流量表 |

### 4.4 滞后指标（确认拐点已发生，**不可作为预测**）

| 信号 | 来源 | 时延 |
|---|---|---|
| 库存周转天数 | 资产负债表 + 利润表 | 滞后 1-2 季度 |
| 应收账款周转天数 | 资产负债表 + 利润表 | 滞后 1-2 季度 |
| 在建工程占固定资产比 ≥ 50% | 资产负债表 | 滞后 1-2 年 |

### 4.5 实战要诀

> **领先指标体系的核心使用规则**：
>
> 1. **不要单独使用领先 6-12 月信号**——L1 capex 调增不必然传导到中游（中间可能被 in-house / 自研 / 替代品截胡）
> 2. **3-6 月领先指标至少要 2 个共振**——单一指标可能是基数 / 季节扰动
> 3. **同步指标用来确认**，不用来预测
> 4. **滞后指标用来排除**——若滞后指标已恶化，说明二阶导已经转负 1-2 季度，**别再追**

## 5. 三大假设的实证（详见 [回测文档](../../../docs/二阶导视角_5案例回测_2026Q1.md)）

### 5.1 假设 1：二阶导转正 → 股价启动 ✅

| 案例 | 转正时点 | 转正幅度 | 股价反应 |
|---|---|---|---|
| 中际旭创 | 2025Q3（+37% → +57%）| +20.58pp | 主升浪起点 |
| 海光信息 | 2025Q3（+51% → +70%）| +18.84pp | 加速上行 |
| 绿的谐波 | 2025Q3（机器人主题加速）| ≈ +30pp | 高位震荡 |

### 5.2 假设 2：二阶导首次大幅扩张 → 主升浪 ✅

| 案例 | 强加速期 | 二阶导跃迁 | 股价 |
|---|---|---|---|
| 中际旭创 | 2025Q4-2026Q1 | +45pp → +90pp | 历史高位 |
| 寒武纪 | 2025 全年（vs 2024）| +388pp | 主升浪 |

### 5.3 假设 3：二阶导首次转负 → 股价见顶（**先于一阶导见顶**）✅✅

> 这是二阶导视角**最有价值的洞察**——它能**领先于香槟塔的物理瓶颈信号**。

| 案例 | 转负时点 | 一阶导仍 | 二阶导 | 物理瓶颈信号 |
|---|---|---|---|---|
| 寒武纪 | 2026Q1（vs 2025）| +159% 仍极高 | -294pp | 尚未亮 |
| 双环传动 | 2026Q1（vs 2025Q4）| +1.49% | -28pp | 主业失速 |

→ **寒武纪二阶导先于库存 / 在建工程信号**给出 T4 早期警报。

### 5.4 假设 4：二阶导稳态 → 股价横盘 ✅

工业富联 8 季度二阶导都在 ±10pp 区间，**没有任何瞬间跃迁** → 股价稳健但无主升浪。

### 5.5 假设 5：二阶导未启动 → 主题炒作 ✅

固态电池整体业绩二阶导 = 0（一阶导本身 = 0），股价完全由"未来预期变化"驱动 → **主题股标志**。

## 6. 与香槟塔 T 阶段的精确对应

| T 阶段 | 二阶导特征 | 验证案例 |
|---|---|---|
| **T0 触发期** | 二阶导 = 0（业绩未启动） | 固态电池整体 |
| **T1 资本承诺期** | 上游设备 / 材料公司**开始**显示二阶导转正 | （对应行业的 L5 标的）|
| **T2 订单确认期** | 候选公司**预付款项 / 备产**等领先指标先转正；二阶导即将转正 | 海光 2025Q1 之前 |
| **T2 末 / T3 早** | **二阶导首次大幅跃迁（+15pp 以上）** | 中际旭创 2025Q3、海光 2025Q3 |
| **T3 中段** | 二阶导持续 ≥ +5pp 但渐进收敛 | 中际旭创 2026Q1（仍加速但物理瓶颈预警）|
| **T3 后段 / T4 早** | **二阶导首次转负**（一阶导仍高） | 寒武纪 2026Q1 |
| **T4 见顶期** | 二阶导大幅转负 + 物理瓶颈滞后信号亮 | （预期到来的）|

**关键映射**：

> **二阶导视角能告诉你"T2 末 / T3 早"的精确时点**——这是香槟塔 T 阶段判定中最难、也最重要的边界。  
> **二阶导转负领先于香槟塔的"物理瓶颈"信号 1-2 季度**——这是 v1.2 升级后香槟塔的**早期预警机制**。

## 7. 局限与误用警示（**必读**）

### 7.1 二阶导单独使用会产生 **EMS 模式假阳性**

| 案例 | 单独看二阶导 | 单独看香槟塔 | 双轴交叉 |
|---|---|---|---|
| 工业富联 | 二阶导小幅加速 → 看似"加速"标的 | 次级瓶颈，结构性赔率压制 | 🟡 稳健仓位（不是高赔率主仓） |
| 寒武纪 2026Q1 | 二阶导转负 → 看似"减仓"信号 | 强瓶颈但客户集中度风险 | 🔴 见顶警报，**两轴都打 ⚠️** |

→ **必须双轴同时使用**。

### 7.2 二阶导失效场景

| 场景 | 失效原因 | 处理 |
|---|---|---|
| **基数效应剧烈** | 公司刚突破盈亏平衡或 IPO 后基数极低 | 用全年 YoY 替代单季 YoY；考虑用绝对额变化 |
| **重大并购 / 剥离** | 同口径不可比 | 用扣除并购影响后的"内生增长率" |
| **会计准则切换** | 如 consign 模式切换、会计政策变更 | 需还原同口径，若不可还原则本工具失效 |
| **强周期股** | 周期波动覆盖二阶导信号 | 改用 PB 分位 + 库存周期；本工具不适用 |
| **未上市 / 财报披露不全** | 数据不足 | 退出本工具 |

### 7.3 不要做的 5 件事

1. ❌ 仅看一个季度的二阶导就下判断（至少需要 6 季度趋势）
2. ❌ 把二阶导当成入场理由（它是**节奏校验**，不是入场依据；入场依据是香槟塔 + 双轴交叉）
3. ❌ 用二阶导做精确点位预测（它给出区间，不给点位）
4. ❌ 在 T0 阶段（二阶导未启动）用本工具找标的
5. ❌ 把二阶导作为"困境反转股"的唯一识别依据（需配合**反转持续性**判断，本 skill 默认不覆盖纯困境反转）

## 8. 困境反转视角的扩展（边界讨论）

香槟塔 skill 的核心边界是"技术驱动型"。但二阶导视角理论上对**所有业绩二阶导转正的场景**都有效，包括：

| 类型 | 典型 | 是否纳入本 skill |
|---|---|---|
| 技术驱动型香槟塔 | AI、电动车、光模块 | ✅ 本 skill 主战场 |
| **困境反转型** | 周期反转（钢铁、化工、锂电）、政策反转 | ⚠️ 二阶导视角适用，但**需补充**反转持续性判断 |
| 平台型 / 服务型 | SaaS、互联网平台 | ❌ 本 skill 不适用 |

**当前结论**：困境反转视角**不在 v1.2 范围内**。如果未来要扩展，需新增"反转持续性闸门"（如：行业出清深度、政策力度、库存底部确认）。

## 9. FAQ

**Q1：二阶导视角和动量投资（Momentum）有什么区别？**

A：动量投资关注**股价**的趋势，二阶导关注**业绩**的加速度。两者通常正相关但不等同——业绩二阶导转负往往**先于**股价见顶。本 skill 关注**业绩节奏**，不直接做股价动量交易。

**Q2：二阶导和"超预期/不及预期"有什么区别？**

A："超预期/不及预期"看的是"实际 vs 卖方一致预期"，本 skill 看的是"实际 vs 公司自身上一期"。两者互补：
- 二阶导加速 + 超预期 = 最强信号
- 二阶导加速 + 不及预期 = 警告（可能是预期已透支）
- 二阶导减速 + 超预期 = 短期反弹但中期承压
- 二阶导减速 + 不及预期 = 双重打击

**未来的第三轴（候选）**可能是"市场预期差"。

**Q3：二阶导视角对 PE / PB 估值有没有指导意义？**

A：直接相关——PE 应当跟随**未来 1-2 年的二阶导**，而非当期一阶导。  
- 二阶导加速期：高 PE 合理（市场愿意预付）
- 二阶导稳态期：PE 应回归历史均值
- 二阶导减速期：PE 应当压缩（即使一阶导仍高）  
但具体估值由 [`stock-valuation-fcff-dcf`](../stock-valuation-fcff-dcf/SKILL.md) 给出，本 skill 不做估值。

**Q4：单季和全年 YoY 用哪个？**

A：默认用单季 YoY。但出现以下情况之一，改用全年 YoY：
1. 单季营收波动 > 50%（季节性 / 验收节奏）
2. 上一年同期基数 < 当年单季营收的 10%（基数极低）
3. 行业惯例用累计 YoY（如部分基建 / 能源行业）

**Q5：二阶导能用净利润代替营收吗？**

A：可以，且推荐**两者都做**。规则：
- 营收二阶导：反映需求节奏
- 净利二阶导：反映需求 + 毛利率 + 费用节奏
- **两者背离**是重要信号：
  - 营收加速 + 净利更加速 = 量价齐升（最强）
  - 营收加速 + 净利平稳 = 价格 / 成本承压（警告）
  - 营收稳态 + 净利加速 = 提价 / 降本（结构性改善，但不可持续）
