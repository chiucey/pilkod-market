# 香槟塔分析法（技术驱动型产业链传导）

**核心命题**：技术突破 → 头部公司 capex 承诺 → 中游订单确认 → 上游产能验证 → 收入/利润兑现，香槟塔从顶部下溢的过程中，**赔率与概率呈反向变化**，最佳介入点在 **T1→T2 转换期**（capex 已落实但收入尚未兑现）。

**非投资建议。** 输出禁止"买入/卖出/目标价"。

## 1. 适用边界（先排除，再入场）

**适用**：
- 由**单一技术拐点**触发的、**有清晰 BOM 物理传导链**的产业。
- 头部资本开支提供方**至少 2 家**以上独立买家，且都是上市公司（这样财报可查）。

**不适用（直接用其他方法，不要硬套）**：

| 情形 | 原因 | 推荐替代 |
|---|---|---|
| 纯软件/服务/平台型主题 | 没有物理产能瓶颈，传导链短或缺失 | 用单位经济模型（LTV/CAC、渗透率） |
| 消费品牌升级 | 是需求拉动，不是 capex 推动 | 用品类渗透率 + 渠道分析 |
| 大宗商品周期 | 是供需周期，不是技术拐点 | 用库存周期 + PB 分位 |
| 政策/补贴驱动 | 持续性取决于政策意志，不是 capex 自循环 | 用政策时间表 + 中标占比 |
| 单一买家垄断的链条（仅 1 家 capex 提供方） | 无法分散订单风险，本质是单一客户绑定 | 直接做客户依赖度分析 |
| 头部 capex 提供方未上市（财报不可查） | 数据源约束失效 | 改用产业链调研、专家访谈 |

> ⚠️ **重要提醒**：80% 的"概念股主题"过不了适用性自检。**过不了就退出本 skill**，不要降低标准硬套。

## 2. 两种使用模式

### 模式 A：股票 → 塔位（反向定位）

> "请分析中际旭创目前在产业链什么位置、处于 T 几阶段、还能持有多久？"

输入：单一股票代码或公司名称。

输出：该公司所处的塔层、T 阶段、上下游卡脖子环节、入场/出场信号。

### 模式 B：行业/技术 → 标的（正向构建）

> "AI 推理/人形机器人/固态电池产业链中，哪些股票构成它的香槟塔？"

输入：技术主题 / 行业关键词。

输出：完整产业链塔型结构 + 每层代表标的 + 当前各层 T 阶段 + 优先介入名单。

**不论哪种模式，都必须先跑 §3 的"塔有效性自检"。**

## 3. 塔有效性自检（Gatekeeper · 必跑）

四道闸门 + **三档判定** + **子塔识别**（v1.1 升级）。**禁止"任一不过即放弃"**——按下表分档处理：

| 通过情况 | 档级 | 处理 |
|---|---|---|
| **4/4 全过** | **严过** | 直接进入完整塔型分析（典型案例：中际旭创 / AI 推理芯片国产替代） |
| **3/4 通过 + 1 项⚠️** | **勉强过（边界塔）** | 进入分析，但**强制**：① 在结论开头声明"塔成熟度=早期/边界塔"；② 推荐策略**强制偏向横向分散**（3-5 只候选）；③ 显式声明"1 年持有期可能不匹配，等待期可能 12-18 月"（典型案例：固态电池） |
| **≤ 2/4 通过** | **整体不过** | **不要直接放弃**——进入 §3.5 **子塔识别**流程；若无独立子塔则终止（典型案例：人形机器人——整体不过但 L4 零部件层独立成熟） |

> **方法论说明**：v1.0 是 0/1 二档判定，导致两种错误：(a) 4/4 通过但已是 T3 顶部时仍推荐介入（中际旭创对照）；(b) 3/4 时直接放弃，错过子塔机会（人形机器人对照）。v1.1 用三档 + 子塔识别修复。

### 闸门 1：资本开支证据（capex commitment）

**必查指标**：

- 头部 2-3 家 capex 提供方（必须是上市公司）的现金流量表"购建固定资产、无形资产和其他长期资产支付的现金"科目，**最近 2-3 个季度同比是否连续上调？**
- 这些公司的业绩说明会/年报中，**capex guidance 文字是否从"维持"变成"上调"**？
- 是否有结构性变化（比如 capex 占收入比从 8% 跳到 15%）？

**通过标准**：≥ 2 家头部公司连续 2-3 个季度 capex 同比 +30% 以上，且管理层文字明确指向**该技术主题**。

**失败案例**：2021 年的元宇宙 —— 仅 Meta 一家大幅 capex，且其他大厂均未跟进，2022Q4 Meta 自己也下修，闸门 1 失败。

### 闸门 2：订单可见性（order visibility）

**必查指标**（在产业链中游候选公司的财报）：

- **合同负债 / 预收账款**是否同比显著上升？
- 大客户名单是否扩展（不是单一客户）？
- 重大销售合同公告是否带有 take-or-pay / 长协 / 预付款条款？

**通过标准**：合同负债同比 +50% 或在手订单覆盖未来 12 个月以上收入。

### 闸门 3：物理瓶颈存在（physical bottleneck）

**必查问题**：

- 该技术落地是否需要**实体产能**（厂房、设备、特种材料）？
- 该实体产能的**扩产周期是否 ≥ 12 个月**？
- 是否存在**客户认证 / 资质准入**门槛？

**通过标准**：扩产周期 ≥ 12 个月 **或** 客户认证周期 ≥ 12 个月。

> 若是纯软件/算法/服务，**直接退出**——香槟塔模型不适用。

### 闸门 4：替代风险可控（substitution risk）

**必查问题**：

- 1-2 年内是否有可能的颠覆性替代技术路线？
- 头部 capex 提供方是否曾在同主题下切换过供应链（如转向自研、in-house）？
- 是否存在地缘政治 / 出口管制可能切断传导链？

**通过标准**：未来 12 个月内**无大概率**的技术路线切换或链条切断。

### 3.5 子塔识别机制（v1.1 新增 · 整体塔"勉强过"或"不过"时启动）

> **核心思想**：当整体行业塔不成立或勉强成立时，**产业链中可能存在独立成熟的子塔**——某个特定层因为"上游同时供给多家整机/L1 厂商"形成**整合性需求**，规避了单一买家订单稀薄问题。

**判定步骤**：

1. 列出产业链各层（L1-L5）的代表公司及其客户群
2. 检视是否存在**单一供应商横跨多家 L1 厂商**的供给关系
3. 若存在，把该层升级为**子塔的中心**：
   - 子塔的"L1 capex 提供方" = **该层所有买家集合**（可来自不同行业、不同地理）
   - 子塔的"瓶颈层" = **该层本身**
4. 对子塔运行**完整 4 道闸门自检**（标准与整体塔相同）
5. 子塔通过自检 → 进入分析；不通过 → 终止整个分析

**典型案例**（人形机器人）：
- 整体塔不通过：A 股可投的整机厂订单稀薄、整机厂多数未上市
- 但 L4 减速器层（双环传动 / 绿的谐波）**同时供给特斯拉 / Figure / 宇树 / 智元 / 优必选 / 华为 / 小米 / 荣耀**等多家整机厂，形成整合性需求
- 子塔自检：4/4 通过 → 进入完整分析

**适用与不适用情境**：

| 适用 | 不适用 |
|---|---|
| 上游元器件横跨多家整机厂（人形机器人减速器） | L1 单一买家垄断（无法构造整合性需求） |
| 设备 / 材料层供给多个细分应用（半导体设备国产化） | 整机层与零部件高度一体化（如 iPhone 苹果链已被整合） |
| 标准化 BOM 项（光学元件、特种钢材） | 高度定制化的非标产品 |

**警告**：子塔识别 **不允许** 用来"硬凑塔"。若候选层只供给 1-2 家 L1 厂商，**不构成子塔**，老老实实终止分析。

## 4. 价值链拓扑（Map the Tower）

通过自检后，按以下 5 层结构展开（**不是所有主题都有 5 层，至少应识别出资金源 + 瓶颈层 + 材料层 3 层**）：

```
L1 资本开支提供方 (Capex Source)
   ↓ 钱在这里出，决定了塔的总规模
L2 系统集成商 (System Integrator)
   ↓ 定义需求、整合、卖给 L1
L3 关键模组 (Key Module)
   ↓ 通常是瓶颈层之一，毛利率最厚
L4 核心元器件 (Core Component)
   ↓ 第二瓶颈层，技术壁垒在这里
L5 基础材料 / 设备 (Material / Equipment)
   ↓ 周期最长，但启动最早
```

**每一层必须填表**：

| 维度 | 问题 |
|---|---|
| 该层代表公司 | 列 2-5 家上市公司（含港美股） |
| 该层全球 / 国内 CR3 | （从行业研究 / 公司财报披露的市占率推测） |
| 该层议价权来源 | 专利 / 产能稀缺 / 客户认证 / 规模 / 网络效应 |
| 该层在 BOM 中价值占比 | （可从 L1 的 capex 拆解或第三方拆机数据获取） |
| 该层产能扩张周期 | 多少个月能新增 30% 产能 |
| 该层与下游一致性 | 卖给一家还是多家 L1？是否被 L1 自研替代？ |

> 💡 提示：**塔不一定是严格的层级线**，可能是**网格**：L4 可能同时供给 L2 和 L3；L1 也可能直接采购 L4（绕过 L3）。**画图时承认这种交叉**，不要为了塔型整齐而强行简化。

## 5. 瓶颈识别（香槟在哪里积水）

**核心命题**：利润不均匀分布在塔上，会在"瓶颈层"沉淀。瓶颈层就是最值得介入的层。

**6 个**（v1.1 新增第 ⑥ 信号）**全部从财报可观测**的瓶颈信号（每个候选标的逐项打勾）：

| 信号 | 财报对应位置 | 阈值 |
|---|---|---|
| ① 产能利用率高且扩产慢 | 固定资产周转率（营业收入 / 平均固定资产）连续 2 年 ≥ 2.5 且环比加速 + 在建工程占固定资产比 < 30% | 通过 |
| ② 寡头格局 | 公司市占率（年报披露）+ 行业 CR3 | CR3 ≥ 60% |
| ③ 客户切换成本高 | 前 5 大客户集中度 + 主营业务收入与大客户匹配关系 + 应付/预收账款条款 | 前 5 大客户 ≥ 50% 收入且**含长协** |
| ④ 毛利率逆势扩张 | 利润表毛利率 vs 同行 / 同期上下游对比 | 毛利率同比扩张 ≥ 3 个百分点（且非财务勾兑） |
| ⑤ 成本转嫁能力 | 原材料涨价 vs 公司毛利率走势 | 上游涨价时毛利率不降反升 |
| **⑥ 客户集中度合理**（v1.1 新增） | 前 1 大客户占主营收入比 / 前 5 大客户占比 | **前 1 大 ≤ 50%** **或**（前 1 大 > 50% 但客户为多年战略合作 + 客户本身位于多元化分散行业） |

**判定规则**（v1.1 升级）：

- **≥ 5 个信号通过** → **强瓶颈**（典型如中际旭创 800G 时期，5/5 + ⑥也通过）
- **4 个信号通过** → **次级瓶颈**，可作为弹性标的
- **≤ 3 个** → **非瓶颈**，传导收益但缺乏定价权，不优先介入

**⑥ 集中度风险特殊处理**（v1.1 新增 · 重要）：

> 若信号 ① ② ③ ④ ⑤ 都通过但仅 **⑥ 不通过**（前 1 大客户 > 50% 且非多年战略），不能简单判为"次级瓶颈"，必须显式标记：
> 
> **"高瓶颈 + 极端客户集中度风险"** —— 1 年持有期收益预期需打折，且必须把**该客户本身的财务健康/采购指引**纳入红队反证。
> 
> **典型案例**（寒武纪 2026Q1）：5/5 全过但前 1 大客户字节占 79%。如果字节减少采购、转向自研或自身业绩下滑，寒武纪 80% 收入会一夜消失。这种"高瓶颈但单点失败风险"在 1 年持有期不应作为主仓配置，仅适合小仓位高弹性押注。

## 5.5 概念股过滤（v1.1 新增 · 强制运行）

> ⚠️ Tier 1 / 多元化巨头常把"未来概念业务"作为故事讲，但实际营收占比微乎其微。**这是主题炒作的最常见陷阱**。每次正向构建（Mode B）的候选名单都必须运行此过滤。

**过滤条件**（任一满足 → 标记"概念股"，从优先名单**剔除**）：

| # | 过滤条件 | 财报判定 |
|---|---|---|
| ① | 目标主题业务收入 / 总营收 **< 1%** | 看分部报告或专项披露 |
| ② | 该业务连续 **2 个完整年度**披露但营收**未实质突破**（< 2x 增长且绝对额仍 < 5,000 万元） | 跨年度对比 |
| ③ | 公司年报明确披露"研发、试制、迭代、送样"等措辞但**无量产/订单指引** | 文字证据 |
| ④ | 公司将该业务作为"未来增长点"宣传 ≥ 2 年但**主业财务**已开始恶化（增收不增利 / 毛利率持续下滑） | 主业指标对比 |

**典型案例**（人形机器人 2025-2026）：

| 公司 | 业务情况 | 过滤结论 |
|---|---|---|
| 拓普集团（601689） | 2025 机器人执行器收入 **1,359 万元 = 总营收 0.05%**；2025 增收不增利（净利 -7.38%，6 年首次） | ❌ 满足 ① + ④，**剔除** |
| 三花智控（002050） | 年报明确"研发、试制、迭代、送样阶段"，无量产指引；机器人占总营收无独立披露 | ❌ 满足 ③，**剔除** |
| 绿的谐波（688017） | 机器人收入 1 亿（2025 占总营收 17.5%）→ 3 亿+（2026 指引） | ✅ 不满足任何过滤条件，**保留** |
| 双环传动（002472） | 特斯拉 50 万套/年专用产线已认证；环动科技子公司分拆上市 | ✅ **保留** |

> **使用警告**：此过滤运行**严格**。即便是行业龙头，只要满足任一条件就剔除——"龙头光环"不能替代"业务实质"。

## 6. T 阶段判定（Timing Trickle）

> ⚠️ **强制规则**：禁止"我感觉它在 T2"。**每一个 T 阶段判定必须 cite 具体财报科目 + 数字 + 同比变化**。

### 6.1 T 阶段定义与财报判定标准

| 阶段 | 定义 | **必备**财报证据（至少满足 2 项） | 介入逻辑 |
|---|---|---|---|
| **T0**<br>触发期 | 技术突破被发布、行业会议公布 | 无财报证据可查；仅有论文/产品发布/管理层文字 | 仅观察名单 |
| **T1**<br>资本承诺期 | 头部公司 capex 真实调增 | （a）L1 公司现金流量表"购建长期资产"科目同比 +30% 以上 ≥ 2 个季度<br>（b）L1 公司管理层 capex guidance 上调<br>（c）相关设备/材料厂商在手订单同比 +50% | 介入"卖铲人"（设备/材料） |
| **T2**<br>订单确认期 | 中游订单已落地 | **必先按 §6.1.5 判定销售模式，选择对应指标组**：<br>（a）合同负债 / 预收账款同比 +50%（**仅适用预付模式**）<br>（b）**预付款项**同比 +100% + **存货中原材料 + 在产品**同比 +30%（备产，**直销大客户模式必用**）<br>（c）公司公告**重大销售合同 / 长协**（普遍适用）<br>（d）在建工程同比快速上升（自身扩产，普遍适用）<br>（e）**在手订单**或**未履行履约义务**附注披露金额覆盖未来 12 个月以上收入（B2G / 项目制必用） | **最佳介入点**（瓶颈层核心标的） |
| **T3**<br>业绩兑现期 | 收入毛利已转化 | （a）营业收入连续 2 个季度同比 +30% 以上<br>（b）**毛利率同比扩张 ≥ 3 pp**<br>（c）**固定资产周转率**冲高<br>（d）应收账款周转天数缩短（说明客户付款积极） | 持有 / 谨慎加仓，已开始计算赔率 |
| **T4**<br>见顶期 | 供给追上需求 | （a）行业新进入者公告扩产<br>（b）**毛利率掉头**或环比下滑<br>（c）**存货 / 应收账款 / 在建工程**三者之一异常上升<br>（d）公司大规模 capex 投放（在建工程占比 > 50%） | **退出信号**——开始减仓 |

### 6.1.5 按销售模式分类的 T2 指标选择（**强制前置**）

> ⚠️ 不同销售模式下"订单确认"在财报里反映的科目完全不同。**未先判定销售模式直接套用合同负债指标，会在直销大客户行业造成系统性误判**（典型反例：2025-2026 中际旭创合同负债仅占单季营收 0.2%，远不达 +50% 阈值，但实际订单已远超产能）。

**判定流程**：先回答 3 个问题，落入对应模式：

| 问题 | 答案 | 模式 |
|---|---|---|
| 客户是否预付款？（看合同负债 / 预收账款占营收比） | ≥ 5% 显著占比 | **A. 预付模式** |
| 是否直销大客户（前 5 大客户 ≥ 50%）+ 长账期？ | 是 | **B. 直销大客户模式** |
| 是否项目制 / 政府订单 / 工程承包？ | 是 | **C. B2G/项目制模式** |

**各模式的 T2 必备指标组**（每组至少满足 2 项）：

| 模式 | T2 必备指标 | 典型行业 |
|---|---|---|
| **A. 预付模式** | ① 合同负债 / 预收账款同比 +50%<br>② 重大销售合同 / 长协公告<br>③ 存货中原材料 + 在产品同比 +30% | 消费品（茅台、伊利）、地产、部分高端制造 |
| **B. 直销大客户模式** | ① **预付款项**同比 +100%（向上游凶猛备料）<br>② **存货中原材料 + 在产品**同比 +30%<br>③ 重大销售合同 / 长协公告<br>④ 在建工程同比 +30%（自身扩产） | 光模块、半导体设备、新能源车 Tier 1、PCB、CCL、苹果链 |
| **C. B2G/项目制** | ① 在手订单 / 未履行履约义务附注金额覆盖未来 ≥ 12 个月收入<br>② 重大中标公告金额同比 +50%<br>③ 存货 + 合同资产同比 +30% | 军工、电网设备、卫星、轨交、电力工程 |

**反例提醒**（避免误判）：
- 直销大客户行业（如光模块）的合同负债**永远很小**，**不要**误判为"订单尚未落地、还在 T1"
- 项目制行业（如军工）的存货大幅上升可能是 **正常履约**，**不要**误判为"备产 = T2 信号"，必须配合在手订单佐证
- 强季节性行业的合同负债 / 预收账款波动剧烈，需用 **同比** 而非环比，且至少看 4 个季度移动平均

### 6.2 T 阶段判定输出格式（强制）

```markdown
| 公司 | 销售模式 | 当前 T 阶段 | 主要证据（必须含财报科目 + 数字 + 同比） |
|---|---|---|---|
| XX（预付模式样例） | A | T2 | 2025H1 合同负债 12.3 亿元（+58% YoY，2024 全年仅 7.8 亿）；存货中原材料 + 在产品同比 +41%；2025-08 公告与 A 客户签订 25 亿元长协 |
| YY（直销大客户样例） | B | T2 | 2025H1 预付款项 14.9 亿元（+1009% vs 年初）；存货中原材料 + 在产品同比 +35%；在建工程同比 +66%；2025-08 重大合同公告 |
```

## 6.5 业绩二阶导节奏校验（v1.2 新增 · 估值魔方第二轴）

> **核心命题**：股价对**二阶导**（增速变化）的敏感度，远大于对**一阶导**（增速绝对值）的敏感度。  
> 香槟塔（§3-§6）回答**空间维度**："你站在产业链什么结构位置（积水点 vs 流量管道）"。  
> 二阶导（本节）回答**时间维度**："你站在业绩生命周期的什么时点（启动 / 加速 / 稳态 / 减速 / 未启动）"。  
> **两轴交叉 = 估值魔方**——任何单一轴都会误判（详见 [reference §7](second-derivative-reference.md#7-局限与误用警示必读)）。
>
> ⚠️ **强制规则**：T 阶段（§6）判定后，**必须**运行本节的 5 步快速校验。详细方法、领先指标体系、案例数据见 [`second-derivative-reference.md`](second-derivative-reference.md)。

### 6.5.1 5 步快速校验清单

| 步 | 操作 | 输出 |
|---|---|---|
| 1 | 取候选公司近 **6-8 个季度**的 YoY 增速序列（营收 + 净利双跑）| 一张趋势表 |
| 2 | 计算每季度二阶导 = 本季 YoY - 上季 YoY（pp）| 二阶导走势 |
| 3 | 定位最新一期落入哪个区间：🟢 加速拐点（≥ +15pp）/ 🟢 加速中（≥ +5pp）/ 🟡 稳态（±5pp）/ 🔴 减速拐点（≤ -15pp）/ ⚪ 未启动（一阶导 ≈ 0 ≥ 4 季度）| 节奏标签 |
| 4 | 与瓶颈层判定（§5）交叉，落入下表 9 宫格 | 象限定位 |
| 5 | 输出节奏含义（与 T 阶段对应）+ 决策建议（不是投资建议）| 双轴结论 |

### 6.5.2 双轴 9 宫格（决策魔方）

|   | **空间：强瓶颈（≥5/6）** | **空间：次级瓶颈（4/6）** | **空间：非瓶颈/概念股** |
|---|---|---|---|
| **二阶导加速（≥ +15pp）** | 🟢 **赔率最佳象限** | 🟡 流量行情（弹性受压） | 🟡 主题加速（短线） |
| **二阶导稳态（±5pp）** | 🟡 持有 | 🟡 稳健仓位 | ⚪ 平淡，无主升浪 |
| **二阶导减速（≤ -15pp）** | 🔴 **见顶警报** | 🔴 双重承压 | 🔴 主题退潮 |
| **二阶导未启动（≈ 0）** | ⚪ 未到时点 | ⚪ 早期布局 | ⚪ **纯预期博弈/主题股** |

### 6.5.3 与 T 阶段的精确对应（关键映射）

| 二阶导节奏 | 对应 T 阶段 | 实战意义 |
|---|---|---|
| 二阶导首次大幅跃迁（≥ +15pp）| **T2 末 / T3 早** | **赔率最佳的精确时点**——香槟塔 T 阶段最难判的边界 |

### 6.5.5 限制与误用警示（精简版）

> 完整版见 [reference §7](second-derivative-reference.md#7-局限与误用警示必读)。

- ❌ **不要单轴使用**：单看二阶导会把工业富联（次级瓶颈但二阶导加速）误判为强标的；单看香槟塔会把寒武纪（强瓶颈但二阶导转负）误判为继续主升浪。
- ❌ **不要 < 6 季度数据时使用**——数据不够，本工具失效。
- ❌ **不要在以下场景使用**：基数效应剧烈期、重大并购 / 剥离、会计准则切换、强周期股（用 PB 分位替代）。
- ❌ **不要用净利二阶导**单独判断（一次性补贴 / 资产处置会污染信号），优先看营收二阶导 + 扣非净利二阶导。
- ⚠️ 困境反转 / 周期反转视角虽与二阶导逻辑同构，但**未纳入 v1.2**（需补充反转持续性判断），见 [reference §8](second-derivative-reference.md#8-困境反转视角的扩展边界讨论)。

## 7. 入场 / 出场决策矩阵（针对 1 年持有期 · 高赔率约束）

### 7.1 一般决策矩阵

| 当前 T 阶段 | 是否瓶颈层 | 决策（非投资建议） | 理由 |
|---|---|---|---|
| T0 | — | **不介入**，仅观察 | 概率太低，幸存者偏差风险高 |
| T1 | 瓶颈 | **可小仓位试探**（设备/材料层最优先） | 赔率高、概率中等；T1 多为上游 |
| T1 | 非瓶颈 | 不介入 | 没有定价权，捞不到香槟 |
| **T2** | **瓶颈** | **重点介入**（最佳点） | 概率（订单已锁）+ 赔率（市场未充分定价）兼有 |
| T2 | 非瓶颈 | 小仓位 + 严格止盈 | 跟涨但弹性弱 |
| T3 | 瓶颈 | 持有 / 谨慎加仓 | 概率最高但赔率压缩 |
| T3 | 非瓶颈 | 减仓 / 退出 | 已经吃到大部分涨幅，剩余赔率不够 |
| T4 | — | **逐步退出** | 见顶信号已现 |

### 7.2 1 年持有期专属约束

由于你的目标是平均持有 1 年兑现可观收益：

1. **优先在 T1 末 → T2 中介入**（介入到兑现的等待期 ≈ 6-12 个月，正好匹配持有周期）
2. **避开纯 T3 介入**（剩余收益空间通常不够 1 年的机会成本）
3. **T2 介入需同时满足**：瓶颈层 + 通过自检 + 财报证据齐全
4. **每持有 1 个季度复核 1 次 T 阶段**，T3 信号一出立刻评估是否减仓
5. **小资金高赔率的副作用**：分散到 3-5 只候选标的，不要单押一只（单押的胜率风险无法承担）

### 7.3 双轴交叉决策（v1.2 · 与 §6.5 9 宫格联动）

§7.1 决策矩阵基于"T 阶段 × 是否瓶颈层"。v1.2 引入**二阶导节奏**作为第二时间维度后，**最终决策应基于双轴 9 宫格象限**（§6.5.2），而非单一 T 阶段：

| 双轴象限 | 1 年持有 + 高赔率约束下的决策 |
|---|---|
| 🟢 **强瓶颈 + 二阶导加速** | **重点介入**——这是 T2 末 / T3 早的精确时点，赔率最佳（典型：海光信息 2025Q3） |
| 🟢 强瓶颈 + 二阶导稳态正区间 | 持有但不追高（典型：海光 2026Q1） |
| 🔴 **强瓶颈 + 二阶导转负** | **触发减仓评估**——领先于 §6 物理瓶颈信号；即使一阶导仍高也要警觉（典型：寒武纪 2026Q1） |
| 🟡 次级瓶颈 + 二阶导加速 | 跟涨但仓位偏轻——结构性赔率压制（典型：工业富联 EMS 模式） |
| 🟡 次级瓶颈 + 稳态 | 稳健仓位（不是高赔率主仓） |
| 🔴 次级瓶颈 + 减速 | 双重承压，避开 |
| ⚪ 二阶导未启动（任何空间） | 主题博弈，不属于本 skill 战场（典型：固态电池整体；纯主题股进入 ⚪ 极右下角） |

**冲突解决**：当 §7.1（T 阶段决策）与 §7.3（双轴决策）不一致时，**以双轴决策为准**。  
**典型冲突**：寒武纪 §7.1 判 T3 中段"持有 / 谨慎加仓"，§7.3 因二阶导转负判"减仓评估"——以后者为准。

## 8. 红队反证（Red Team · 强制）

**每次分析最后必须列出至少 3 条证伪证据**，强制反向思考。每条证据须可观测：

| 证伪类型 | 具体观测点 | 一旦出现的处理 |
|---|---|---|
| 头部 capex 削减 | L1 公司下季度 capex guidance 下调或 capex 同比由正转负 | 立即退出，整个塔失效 |
| 技术路线切换 | 出现替代方案的产品发布、L1 公司转向新方案 | 重新评估塔层结构 |
| 瓶颈消除 | 行业新增产能集中投放（多家在建工程同时大幅上升） | 退出瓶颈层标的 |
| 大客户自研 | L1 公司宣布 in-house 该层产品（如苹果自研芯片） | 立即退出该层 |
| 财务勾兑 | 合同负债涨但收入不涨；应收账款异常膨胀；存货积压 | 排除该标的 |
| 地缘 / 政策切断 | 出口管制 / 关税升级 / 制裁 | 立即评估传导链是否断裂 |

## 12. 立场说明

本 skill 与一般"题材分析"的关键区别：

1. **强 gatekeeper + 三档判定**：自检结果不是 0/1，而是严过/勉强过/不过三档；80% 的"AI 概念股 / 机器人概念股"会被过滤；"勉强过"档强制横向分散；"不过"档触发子塔识别。
2. **T 阶段必须用财报硬指标**：禁止情绪化判断"它在 T2"。
3. **销售模式分类（v1.0.1）**：T2 判定按行业销售模式（A 预付/B 直销大客户/C B2G 项目制）选指标，不默认套用合同负债。
4. **6 信号瓶颈识别（v1.1）**：含客户集中度信号；"高瓶颈但极端集中度风险"独立处理。
5. **概念股过滤（v1.1）**：Tier 1 / 多元化巨头的"概念业务"（占比 < 1% 或连续 2 年未突破）强制剔除。
6. **子塔识别（v1.1）**：整体塔不通过时检视产业链各层是否存在独立成熟子塔（多家 L1 共同需求）。
7. **双轴估值魔方（v1.2）**：香槟塔（空间维度：积水点 vs 流量管道）+ 业绩二阶导（时间维度：节奏拐点）双轴交叉决策；单轴使用会产生 EMS 模式假阳性 / T3 顶部假阴性等系统性误判。
8. **入场/出场绑定 1 年持有 + 高赔率约束**：不是泛泛"建议关注"，而是给出明确介入窗口与触发条件；二阶导首次转负**领先于物理瓶颈信号 1-2 季度**作为减仓评估触发点。
9. **红队反证强制化**：每次都要列出能打掉论点的证据；存在集中度风险时必含关键客户证伪；处于加速末期时必含二阶导反转的领先指标证伪。
10. **不做估值**：是否便宜由 `stock-valuation-fcff-dcf` 决定；本 skill 只判断"塔在不在、自己在哪一层、什么阶段、节奏在加速还是减速"。
