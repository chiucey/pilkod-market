# 陪伴型销售工作流 - 精准触发模板

> 本模板帮助您更精准地触发日常销售工作流技能，实现全程陪伴式的销售支持。

---

## 一、方法论说明

### 1.1 核心参考标准

本模板设计参考以下成熟方法论体系：

#### 销售漏斗管理 (参考：BANT理论 + 传统漏斗模型)

- **BANT框架**：Budget（预算）、Authority（决策权）、Need（需求）、Timeline（时间线）
- **七阶段漏斗模型**：潜在客户 → 初步接触 → 需求确认 → 方案制定 → 商务谈判 → 合同签订 → 成交
- **阶段转化率分析**：通过数据追踪识别瓶颈，优化销售效率

#### 客户背景分析 (参考：MEDDIC + SPIN框架)

- **MEDDIC**：Metrics、Economic Buyer、Decision Criteria、Decision Process、Identify Pain、Champion
- **SPIN**：Situation（现状）、Problem（痛点）、Implication（影响）、Need-Payoff（价值）
- **组织架构分析**：决策链识别（决策者、使用者、评估者、阻拦者）

#### 经验沉淀方法 (参考：PDCA + AAR复盘模型)

- **PDCA循环**：Plan（计划）→ Do（执行）→ Check（检查）→ Act（改进）
- **AAR复盘**：After Action Review — 发生了什么、为什么、下次如何改进
- **知识库三层架构**：基础信息层、实践经验层、动态更新层

## 三、节点参与指引

### 3.1 销售全生命周期节点清单

| 阶段 | 节点 | 我的参与方式 | 您需要提供的输入 |
|------|------|------------|----------------|
| **线索获取** | 新线索识别 | 分析线索价值，评估跟进优先级 | 线索来源、初步了解的信息 |
| **客户开发** | 初次接触 | 准备接触策略，提供沟通话术 | 客户背景、接触目的 |
| | 需求挖掘 | 设计访谈提纲，分析需求结构 | 客户业务情况、痛点 |

| | 方案呈现 | 准备呈现材料，预演Q&A | 客户关注点、决策人 |
| **商务谈判** | 价格谈判 | 分析价格策略，提供议价建议 | 客户预算、竞品报价 |
| | 条款协商 | 分析条款风险，提供建议 | 客户要求、底线 |

## 五、精准触发小贴士

### 5.1 让结果更精准的技巧

1. **明确阶段定位**：告诉我您当前处于哪个销售阶段，我可以提供更针对性的支持

2. **提供上下文**：背景信息越完整，我的分析和建议越精准

3. **明确输出格式**：如果您有特定的格式要求（如必须用表格、分点不超过5条），请提前说明

4. **指定关注重点**：告诉我您最想解决的问题，我可以优先分析

5. **及时反馈**：告诉我哪些分析有用、哪些不够精准，帮助我优化响应质量

### 5.2 推荐触发模式

```
【场景】+【客户/项目】+【具体需求】+【格式要求（可选）】
```

**示例：**

- ✅ "【周报】本周漏斗分析，重点关注3个高价值商机的跟进建议，用表格呈现"
- ✅ "【拜访准备】XYZ公司采购总监，下周一拜访，需要客户背景摘要和可能问题清单"
- ✅ "【经验归档】ABC项目失败案例，提炼3条可复用的教训，用于新人培训"

### 5.3 避免模糊提问

| ❌ 模糊提问 | ✅ 精准触发 |
|------------|------------|
| "帮我分析一下客户" | "分析ABC公司的决策链，重点是采购部门的关键人" |
| "看看漏斗情况" | "本周漏斗数据，各阶段转化率对比，用表格呈现" |
| "记录一下" | "记录今天拜访XYZ公司的情况，更新漏斗状态到'需求确认'" |
