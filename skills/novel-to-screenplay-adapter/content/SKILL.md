# 女生生活类小说剧本改编助手

将女生生活类小说内容转化为专业剧本格式的工具。

## 核心能力

- **小说分析**：提取场景、人物、对话、情感线索
- **格式转换**：将叙述性文字转为剧本格式（场景描写、对话、动作指示）
- **对话提取**：从小说叙述中提取自然对话
- **情感强化**：保留并强化情感张力和人物关系

## 工作流程

### 步骤 1：小说内容分析

分析输入的小说内容，提取：

- **人物清单**：主要角色及性格特征
- **场景划分**：按时间、地点划分场景
- **情节主线**：核心冲突和情感发展
- **关键对话**：重要对白和内心独白

### 步骤 2：场景设计

为每个场景构建：

```
场景编号：[INT./EXT.] 地点 - 时间
【场景描写】：环境氛围、人物状态
【主要动作】：关键行为和情节推进
【核心对话】：人物对白或内心独白
【情感基调】：温馨/虐心/甜蜜/紧张等
```

### 步骤 3：对话转化

将叙述性文字转化为戏剧对话：

- 保留角色说话风格
- 简化长句为自然口语
- 添加舞台指示和情感标注
- 保持潜台词和言外之意

### 步骤 4：人物弧线保持

- 记录人物性格关键词
- 确保对话符合人物设定
- 保持情感变化的合理性

## 剧本格式模板

```markdown
# [剧集/电影标题]

## 第[X]场

**场景类型**：INT.(室内) / EXT.(室外)
**地点**：[具体场所]
**时间**：日/夜/晨/昏

【画面描述】
[详细的视觉呈现描写]

【人物动作】
[CHARACTER NAME] 正在...
  - 肢体动作
  - 表情变化
  - 心理状态

【核心对话】
**人物A**：（情绪标签）"对话内容"
**人物B**：（情绪标签）"对话内容"

【转场指示】
→ 切至 / 淡入淡出 / 闪回
```

## 女生生活类小说改编要点

1. **细腻情感描写**：强化内心独白和微表情
2. **人物关系层次**：闺蜜情、暗恋、职场竞争等
3. **生活细节场景**：日常场景的艺术化呈现
4. **成长主题突出**：女主角的成长弧线
5. **情感高潮设计**：关键节点的情感爆发

## 输出规范

改编结果包含：

1. **人物小传**：主要角色详细设定
2. **场景清单**：全剧场景统计
3. **剧本正文**：按场次呈现的完整剧本
4. **改编说明**：关键改编决策说明
