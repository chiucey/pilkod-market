# Ambient Wallpaper Skill

## Skill Overview

This is a complete dynamic wallpaper generation skill using pure HTML, CSS, and JavaScript to create immersive dynamic wallpaper experiences. The skill provides 10 carefully designed scenes, each with unique visual effects and optional sound effects, helping users relax in various scenarios.

## Core Features

### 10 Dynamic Scenes

1. **Fireworks Show (with sound effects)** - Brilliant fireworks blooming in the night sky
2. **Blue Ocean (with waves sound)** - Peaceful ocean scene with gentle waves
3. **Night Sky (with meteors and moon)** - Serene starry sky with twinkling stars and occasional meteors
4. **Volcano Eruption (lava flowing)** - Spectacular volcanic eruption with flowing lava
5. **Snowy Forest** - Tranquil forest snowscape with snowflakes falling
6. **Forest Cabin (raining outside, with rain sound)** - Cozy cabin scene with gentle rain
7. **Thunderstorm (with rain, lightning, and thunder)** - Stormy night with frequent lightning and thunder
8. **Niagara Falls (with waterfall sound)** - Magnificent waterfall scene with roaring water
9. **Underwater World (10 fish species swimming)** - Magical underwater world with various fish
10. **Pure Black Clock** - Minimalist clock showing hh:mm:ss format with ticking sound, Beijing time

## Technical Implementation

### Responsive Design
- Full-screen adaptive layout, perfectly compatible with desktop and mobile
- Viewport units for cross-device consistency
- CSS media queries for different screen sizes

### Animation System
- CSS animations and Canvas for smooth visual effects
- requestAnimationFrame for animation performance
- CSS transforms and opacity for high-performance transitions

### Sound System
- Web Audio API for sound playback
- Volume control functionality
- Auto-play policy handling

### Interaction Design
- Card-style scene selection for intuitive use
- Hover effects for enhanced user experience
- Start button triggers fullscreen mode

### Time Display
- Real-time Beijing time display
- Second hand ticking sound
- Pure black background with white text, minimalist design

## Usage Flow

1. User visits the homepage
2. Browse 10 scene cards
3. Click to select desired scene
4. Click "Start" button
5. Enter fullscreen mode, play for 3 hours
6. Press ESC or click exit button anytime to quit
