# 新网银行客户投诉处理（XWB Complaint Negotiation）

## Inputs to collect

调用此 skill 前，模型必须先从用户那里收集以下信息。信息不全时不要硬上，先问。

**必填**：
- **场景类型**：从 4 类典型中选（见 `references/scenario-patterns.md`）
  - A. 利率合规争议（高利贷、超过法定利率）
  - B. 风控与贷后管理争议（贷前审核失察、贷后管理缺失）
  - C. 平台操作失误争议（客户误操作、功能 BUG）
  - D. 综合诉求类（停催 + 减免 + 赔偿的组合）
- **客户诉求清单**：从 5 类诉求中勾选（高息退费 / 停催 / 减免费用 / 赔偿 / 退息退费）
- **客户情绪状态**：激动型 / 理性型 / 弱势型 / 强硬型
- **关键事实**：涉及金额、期数、是否逾期、是否已投诉监管、合同利率

**选填**（影响话术细节）：
- 客户年龄段、性别（影响称呼和语气）
- 客户历史投诉记录（首次 / 多次）
- 是否已威胁诉诸媒体、12378、银保监
- 客服本人是否有 500 元小额赔付权限（默认有）

**红线信息**（必须主动识别）：
- 客户明确表达自伤、自杀倾向 → 立即转危机干预流程，不进话术
- 客户明确已起诉或已申请调解 → 标注"司法介入"标签，话术改为"协调法务"口吻
- 客户为媒体记者或"职业投诉人" → 走专项流程

## Procedure

按以下 6 步执行，每步的详细执行规范见对应 references。

### Step 1: 场景分类与诉求拆解

读完用户输入的投诉描述后，**先归类**到 A/B/C/D 四类之一（或组合），再**拆解诉求**：
- 核心诉求：客户嘴上说的最大诉求
- 附加诉求：客户列举但优先级低的诉求
- 隐藏诉求：客户没明说但实际想要的（如"我想出口气"、"我想拖延还款"、"我想证明自己没错"）

→ 详细场景特征见 `references/scenario-patterns.md`

### Step 2: 法规与合规校准

根据场景调取对应法规基线，给出"我方立场"和"客户可援引的法规"两侧的客观陈述。

**当前基线**（截至 2026-07）：
- 民间借贷利率上限：合同成立时一年期 LPR 的 4 倍（最高法 2020 新民间借贷司法解释）
- 消费金融公司 / 银行：司法实践中**主流适用** 4 倍 LPR 上限；地方法院有差异
- 催收合规：《互联网金融逾期债务催收自律公约（试行）》、不得暴力催收、外包催收不得骚扰第三人
- 个人信息保护：《个人信息保护法》——客户可援引"信息泄露"主张
- 格式条款：明显加重对方义务、免除自身责任的条款无效

→ 法规基线全文见 `references/regulation-baseline.md`
**使用前需核实**：司法解释、地方判例、自律公约可能更新，重大金额事项需法务复核

### Step 3: 解决方案梯度设计

按"理想 / 折中 / 兜底"三档设计，每档必须有明确触发条件。

**三档通用框架**（针对 XWB 客诉岗 500 元权限设计）：

| 档位 | 适用条件 | 典型内容 | 让步空间 |
|------|---------|---------|---------|
| 方案 A 理想 | 客户诉求完全合理 / 我方确有过错 | 全额满足核心诉求（如确认违规后全额退费）+ 500 元上限内小额赔付（话费/京东卡） | 大 |
| 方案 B 折中 | 客户诉求部分合理 / 责任难认定 | 满足部分诉求（如减免 1-2 期息费）+ 500 元上限内小额赔付 + 出具书面说明 | 中 |
| 方案 C 兜底 | 客户诉求不合理 / 我方无责 / 客户坚持过高诉求 | 守住合同底线 + 解释清楚 + 引导外部救济（12378、调解、诉讼） | 小 |

**关键原则**：
- 永远**先给 C 兜底**在脑子里，话术先抛 B；A 只在客户接受 B 后或客户提出强证据时再给
- 让步必须**有条件**（如"减免这 2 期是基于您按时还款的诚意，后续请保持良好记录"），不可无条件给
- 500 元权限要省着用，给过 1 次后第 2 次只能给"等值服务"（如延期、分期）不可重复给现金等价物

→ 谈判节奏与心理学见 `references/negotiation-frameworks.md`

### Step 4: 沟通策略制定

根据客户类型匹配主线策略：

| 客户类型 | 主线策略 | 关键动作 |
|---------|---------|---------|
| 激动型（哭闹/骂人/摔东西/威胁） | 共情先行，**绝对不和客户争对错** | 先听完、再复述诉求、给台阶、用"我理解您"句式 |
| 理性型（讲法条/引判例/说话有逻辑） | 方案先行，用专业度建立信任 | 引用具体法规条款、给出书面测算、留出核查时间 |
| 弱势型（焦虑/哭泣/反复道歉） | 保护性策略，**给安全感** | 慢速、柔声、确认"是否被理解"、主动给确定信息 |
| 强硬型（通牒式/"今天不解决就..."） | 攻守兼备，**不卑不亢** | 不被威胁带节奏、坚持按流程走、留谈判窗口 |

### Step 5: 输出结构化话术

按 `references/output-template.md` 的固定结构输出，包含 5 段：
1. **开场共情 + 身份确认**
2. **核实事实**（问什么、怎么问、为什么问）
3. **释法回应**（针对客户质疑点）
4. **方案梯度**（A/B/C 三档，每档配话术 + 让步条件）
5. **收尾与确认**（达成一致后如何确认、没达成如何留口）

每段话术必须满足：
- **温度** ≥ **专业**：先让人觉得被听见，再讲道理
- 用"我"开头表达理解（"我理解您..."），不用"我们银行"开头推卸（"我们银行没做错..."）
- 数字、金额、法规用**口语化**但**精确**的方式说，不要念合同

### Step 6: 红线检查与升级

输完话术后，自查：
- 是否有"威胁/嘲讽/推卸"性措辞 → 改
- 是否有"承诺超额赔付"超出 500 元权限 → 标注"需主管授权"
- 客户已投诉监管 / 媒体 → 在话术头部加"投诉升级"标签，提醒先核对投诉渠道
- 涉及合同条款解释 → 标注"以合同原文为准，避免单方释法"
- 客户提及起诉 / 已立案 → 改口为"协调法务对接"，不直接对法律实体问题表态

## Failure handling

| 失败情形 | 处理方式 |
|---------|---------|
| 客户描述含糊，无法归类到 A/B/C/D | 不要硬归类，先输出"待补充信息清单"（场景 / 诉求 / 情绪 / 关键事实） |
| 客户诉求明显超出 500 元权限 | 话术中明确标注"本方案需主管授权，主管审批通过后可执行" |
| 客户已投诉监管/媒体/12378 | 话术头部加"⚠️ 投诉升级"标签，建议先确认投诉编号、投诉内容，再设计话术 |
| 客户提及自杀、自伤、伤人 | 立即挂断本 skill 流程，转危机干预（同步主管、当事人紧急联系人、必要时报警） |
| 客户要的具体金额明显无依据 | 话术中标注"需法务/合规测算"——不要给出无依据的金额 |
| 法规可能更新，话术引用具体条款 | 标注"以现行有效法规为准；重大金额事项需法务复核" |
| 同一客户多次投诉、每次理由不同 | 调取历史投诉记录，话术中增加"我看到您之前也反馈过 X，我们之前给到的方案是 Y..." 衔接句 |
| 客户是"职业投诉人"（以投诉为业、要挟牟利） | 不适用本 skill 普通流程，转专项处置流程（用户需补充说明） |

## Examples

### Example 1：利率合规争议（A 类）

**Input**：
> 客户投诉新网银行好人贷利率超过国家法定利率，存在高利贷违规，要求高息退费+停催。客户借款 5 万元，分 24 期，年化利率 24%（IRR 算下来约 30%）。客户已 12378 投诉。

**Output 关键节选**（完整结构见 Output contract）：

场景分类：A（利率合规）
客户画像：理性型，30-40 岁，会用 IRR 算实际利率
诉求拆解：
- 核心：高息退费（要求退还超出 4 倍 LPR 部分）
- 附加：停催
- 隐藏：想用这个把逾期欠款重新谈下来

法律风险评估：**部分合理**。合同成立时 4 倍 LPR ≈ 13.8%-15.4%，客户主张 24% 超过上限的可能性大。需核实合同实际 IRR（合同利率 vs 综合 IRR 是两回事）。

方案梯度：
- 方案 A 理想：经法务/财务测算后，全额退还超出 4 倍 LPR 部分利息 + 500 元京东卡（需主管授权）
- 方案 B 折中：经测算后退还部分利息（具体金额待定）+ 500 元京东卡 + 停催 30 天
- 方案 C 兜底：当前合同利率符合监管要求（需出具书面依据），暂不满足退费诉求，建议通过调解/诉讼解决

话术要点：
- 开头："X 先生/女士，我看您这笔借款是 2023 年 X 月放的，金额 5 万，24 期。我能感受到您对利息这块很在意，咱们今天就是专门处理这件事。"
- 释法："民间借贷利率的司法保护上限是合同成立时一年期 LPR 的 4 倍，银行贷款利率虽不强制适用，但近年司法实践中很多法院参照适用。我现在需要先核实一下您这笔借款合同里的实际年化利率是多少。"

### Example 2：平台操作失误争议（C 类）

**Input**：
> 客户投诉使用新网银行车贷业务自助登记功能，本来要办理结清登记，**点成了解押登记**（功能位置相近，客户误操作），结果一直没人回复，要求银行承担这期间的利息。

**Output 关键节选**：

场景分类：C（平台操作失误）
客户画像：理性偏弱势，对流程不熟
诉求拆解：
- 核心：承担这期间的利息
- 附加：希望得到明确答复时间
- 隐藏：希望银行承认有 UX 设计问题

法律风险评估：**部分合理**。客户自身有操作责任，但若平台 UI 确实存在"结清"和"解押"功能入口混淆的设计缺陷，平台有改善责任。利息承担需逐日计算。

方案梯度：
- 方案 A 理想：经核实后，承担操作后到我行处理期间的实际利息损失（按合同日利率）+ 500 元京东卡
- 方案 B 折中：承担 50% 利息损失 + 500 元京东卡 + 提交产品部门优化功能（出书面说明）
- 方案 C 兜底：利息按合同正常计算，建议客户走"我行差错申诉"流程另行处理

话术要点：
- 共情："您说本来要办结清，结果点错成解押了，我心里特别理解您着急的心情——这一字之差，事情完全不一样。"
- 释法："您说的这个功能操作问题，我先把您这笔记录调出来确认下。一般来说，自助登记提交后我行会在 X 个工作日内处理，但您这笔我看到是 X 天前提交的，确实是超出了正常处理时长，我先帮您加急处理。"

## 重要免责声明

1. 本 skill 输出的所有话术与方案是**沟通辅助**，不构成法律意见或最终处理决定
2. 涉及具体金额减免、合同变更、利率认定等事项，**必须经 XWB 法务/合规复核**后方可执行
3. 法规基线标注"截至 2026-07"，使用前需核实最新司法解释、自律规范、监管政策
4. 严禁将本 skill 话术用于：暴力/侮辱/威胁催收、伪造证据、诱导客户撤诉等违规场景
5. 如客户表达自伤/伤人/自杀倾向，立即停用本 skill，转危机干预流程
