# 输出话术模板

> 本文件是 SKILL.md 5 步流程中"Step 5: 输出结构化话术"的标准模板。
> 调用 skill 后，**严格按本模板**输出 Markdown 格式的话术。

---

## 模板主体结构

```markdown
# 投诉处理沟通话术：[场景类型简述]

> ⚠️ **投诉升级标签**（如适用）
> [12378 已受理 / 媒体已介入 / 反复投诉 N 次 / 职业投诉人 / 其他]

> **客户核心信息**
> - 姓名：
> - 合同号：
> - 借款金额：
> - 合同利率（名义）：
> - 实际 IRR：
> - 客户情绪：[激动型 / 理性型 / 弱势型 / 强硬型]
> - 沟通难度：[低 / 中 / 高]

## 1. 场景分析

- **场景分类**：[A / B / C / D]
- **客户画像**：[1-2 句描述，包括年龄段、职业特征、债务情况]
- **诉求拆解**：
  - 核心诉求：[客户嘴上说的最大诉求]
  - 附加诉求：[客户列举但优先级低的诉求]
  - 隐藏诉求：[客户没明说但实际想要的]
- **法律风险评估**：[合理 / 部分合理 / 不合理]（带依据）
- **沟通难度**：[低 / 中 / 高]（带原因）

## 2. 沟通策略

- **主线策略**：[对应客户类型]
- **让步节奏建议**：[节奏 A/B/C/D/E 之一，见 negotiation-frameworks.md §2]
- **关键心理效应**：[互惠 / 锚定 / 承诺一致 / 权威 / 其他]
- **关键话术点**（3-5 个）：
  1. [开场切入点]
  2. [释法核心]
  3. [方案抛出顺序]
  4. [让步触发条件]
  5. [兜底/升级触发条件]

## 3. 结构化话术（电话版）

### 3.1 开场共情 + 身份确认（建议时长 2-3 分钟）

[ ] **身份确认话术**：
> "您好，请问是 [客户姓名] X 先生/女士吗？"
> "为了保护您的账户安全，我需要先核实一下您的身份。请提供您的身份证后四位和合同号。"

[ ] **共情开场**：
> "[X 先生/女士]，我看到您这笔 [业务类型] 是 [时间] 办的，[金额]，[期数]。"
> "[对客户具体诉求的核心重述]——我完全理解您 [情绪词] 的心情。"
> "今天这通电话，我专门来帮您处理这件事。"

[ ] **复述诉求确认**：
> "我跟您确认一下您今天要反馈的主要问题是：[1...2...3...]——我理解对吗？"
> （等客户确认）

### 3.2 核实事实（建议时长 4-6 分钟）

[ ] **关键问题清单**（按优先级）：
1. [问题 1] —— 问 [什么] / 为什么问 [原因]
2. [问题 2] —— 问 [什么] / 为什么问 [原因]
3. [问题 3] —— 问 [什么] / 为什么问 [原因]

[ ] **核实过渡话术**：
> "为了给您一个准确的答复，我需要先核实几件事——大概需要 3-5 分钟，您别着急。"
> （每个问题后）"我记下来了。"

[ ] **信息不足时的应对**：
> "这块信息我系统里没看到，我帮您查一下——可能需要一点时间，您稍等。"

### 3.3 释法回应（建议时长 2-4 分钟）

[ ] **针对客户每个质疑点的话术**：

**质疑点 1：[客户原话]**
> "您说的 [客户原话引述]——我帮您解释一下这块的情况：[通俗化、但精确的释法话术]"
> "具体到您这笔合同，实际情况是 [事实陈述，避免单方释法]"

**质疑点 2：[客户原话]**
> [同上结构]

[ ] **释法的注意事项**：
- 不用法条编号
- 不用"我们银行"开头推卸
- 不用"您误解了"否定客户
- 每个质疑点都要"先肯定合理性，再给事实"

### 3.4 方案梯度（建议时长 4-6 分钟）

[ ] **方案 B（折中）—— 首选抛出**：
> "我跟您说说我今天能为您争取到的方案——"
> "[方案 B 具体内容：减免几期息费 / 500 元京东卡 / 停催 X 天 / 其他]"
> "[让步条件：例如'需要您后续保持按时还款，并配合我们完成 X 流程']"
> "您看这个方案能不能接受？"

[ ] **方案 A（理想）—— 仅在 B 被拒后抛出**：
> "如果您刚才说的 [客户更强烈诉求] 确实有特殊原因，我再为您申请一个特别方案——"
> "[方案 A 具体内容]"
> "[让步条件：通常更严苛]"
> "但这个方案需要主管审批，可能需要 X 个工作日才能正式生效。您先口头确认意向？"

[ ] **方案 C（兜底）—— 仅在 A、B 被拒后抛出**：
> "我非常想帮您把这件事解决，但 [方案 C 受限原因]——"
> "我行目前能做的最大努力是 [方案 C 内容]——这是基于合同约定和我行处理流程的"
> "如果您对这个方案不认可，您完全有权利通过 [外部救济渠道] 进一步反映"
> "但我仍然建议您给我们 X 个工作日的时间，我们争取给您一个更好的答复"

[ ] **方案抛出的注意事项**：
- 永远先 B，后 A，最后 C
- 每个方案给"为什么这个方案适合您"的理由
- 每个方案给"您需要配合什么"的条件
- 不要给三个以上选项

### 3.5 收尾与确认（建议时长 2-3 分钟）

[ ] **达成共识的收尾**：
> "我跟您把今天达成的共识再过一遍——"
> "1. 我们将在 [X 日内] 为您 [具体行动 1]"
> "2. 我们将在 [X 日内] 为您 [具体行动 2]"
> "3. 您这边需要 [客户需要做的事]"
> "4. 如果过程中有任何问题，工单号是 [X]，您可以凭这个工单联系我们"
> "您看是这样吗？"（等客户确认）

[ ] **未达成共识的收尾**：
> "X 先生/女士，我今天能为您争取到的最大诚意是 [方案 C 内容]——如果您希望进一步推进，我建议："
> "1. 您可以 [外部救济渠道]，我们可以配合提供材料"
> "2. 我将在 [X 日内] 主动联系您，跟进事态进展"
> "3. 如果您有新的证据或诉求，随时联系我们——工单号是 [X]"
> "我理解这个结果可能不是您最满意的，但请您相信我行会认真对待。"

[ ] **通用结束语**：
> "感谢您今天花时间跟我沟通，我会把您的情况专门记录下来，给到对应的主管同事。"
> "打扰您了，祝您生活愉快。"

## 4. 注意事项

### 4.1 红线（绝对不能做/说）
- [ ] 不得承诺超出 500 元权限的具体金额
- [ ] 不得承认/否认"催收违规"、"信息泄露"等需核查事项
- [ ] 不得念法条编号
- [ ] 不得在电话中单方解释合同条款（"以合同原文为准"）
- [ ] 不得嘲讽、推卸、威胁、辱骂
- [ ] 不得暗示"不投诉就多给"
- [ ] 不得替客户起草对第三方的施压话术

### 4.2 升级（什么情况转主管/法务）
- [ ] 客户诉求超出 500 元权限
- [ ] 客户已投诉 12378 / 媒体 / 监管
- [ ] 客户提及起诉 / 已立案
- [ ] 客户提及自伤 / 伤人 / 自杀
- [ ] 客户有 3 次以上同质投诉
- [ ] 客户疑似职业投诉人
- [ ] 涉及合同条款的法律解释
- [ ] 涉及第三方（借款方、担保方）的责任划分

### 4.3 后续（通话后必须做的事）
- [ ] 工单完整记录（诉求、情绪、方案、达成度、未达成原因）
- [ ] 通话录音归档
- [ ] 涉及让步的方案 → 主管审批
- [ ] 涉及违规催收/泄露的 → 转合规部
- [ ] 涉及客户威胁的 → 转风控/法务
- [ ] 已承诺的回电 → 设置提醒，按时拨打
- [ ] 客户情绪严重 / 有危机倾向 → 同步主管，必要时联系紧急联系人

## 模板使用说明

### 必填项 vs 选填项
- 标 [ ] 的项目 = 必须输出
- 未标 [ ] 的项目 = 选填，根据场景调整

### 长度控制
- 完整 4 件套输出约 1500-2500 字
- 短场景（信息齐全）≈ 1500 字
- 复杂场景（综合诉求）≈ 2500 字

### 场景差异
- A 利率合规：方案梯度中"方案 A"通常是事实核查后的让步，需主管审批
- B 风控贷后：开场共情要更长（5 分钟以上），方案梯度要让客户感觉"被保护"
- C 平台操作：释法要"承认改进责任"，方案要"小额 + 出具书面反馈"
- D 综合诉求：方案抛出要慢，每个方案之间要给客户"思考时间"——用"您先想想"留白

### 客户类型适配
- **激动型**：开场共情加长到 3-5 分钟，方案部分更直接（节奏 C 一次性让步）
- **理性型**：释法部分更专业（可引用更精准的法规名称，但不念编号）
- **弱势型**：每段话术都加上"您别担心"、"您放心"，结尾给"具体能联系到我"的方式
- **强硬型**：方案抛出节奏快（A→B→C 间隔短），不让客户"耗"

## 一句话版快速调用（信息不全时）

如果用户给的信息严重不全，先用这个版本回复，再追问：

```markdown
## 待补充信息清单

调用本 skill 前，请补充以下信息：

1. **场景类型**：[A 利率合规 / B 风控贷后 / C 平台操作 / D 综合诉求]——可多选
2. **客户诉求清单**：[高息退费 / 停催 / 减免费用 / 赔偿 / 退息退费]——可多选
3. **客户情绪状态**：[激动型 / 理性型 / 弱势型 / 强硬型]
4. **关键事实**：
   - 借款金额、期数、合同利率
   - 实际 IRR（如果已知）
   - 是否逾期、逾期天数
   - 是否已投诉 12378 / 媒体 / 监管
5. **客户是否有特别情况**：[职业投诉人 / 媒体记者 / 自伤倾向 / 司法介入 / 多次投诉]

补充以上信息后，本 skill 可输出完整 4 件套沟通话术。
```

**严禁**：在信息不全时**直接编造客户事实、具体金额、合同号**——所有数据必须来自用户输入。
