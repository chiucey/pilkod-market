# 谈判框架与心理学基础

> 本文件是 XWB 客诉岗电话沟通的"心理与节奏"工具箱。话术的灵魂不在于"说什么"，
> 而在于"怎么说"和"什么时候说"。

## 1. 谈判的根本原则

### 原则 1：先处理情绪，再处理事情
- 客户情绪在 7-8 分时，给方案等于火上浇油
- 客户情绪在 3-4 分时，给方案才能被接受
- **情绪降温三件套**：复述诉求（让他知道被听见）、表达共情（让他知道被理解）、给确定信息（让他知道事情会推进）

### 原则 2：让步必须"有成本"
- 每次让步都要让客户"付出"一点（再次明确诉求合理性、承诺后续配合、撤销投诉等）
- 无条件让步 → 客户下次要求更高
- 经典句式："我可以为您减免这 2 期，但需要您后续保持按时还款，并配合我们完成 X 流程"

### 原则 3：永远有 BATNA（Best Alternative）
- BATNA = "如果这次谈不拢，你的最优替代方案是什么"
- 我方 BATNA：走法律程序、外包催收、报送征信
- 客户 BATNA：12378、聚投诉、媒体、起诉
- **谈判时心里清楚双方 BATNA**——但**不在话术中**直接说"您去投诉吧"

### 原则 4：锚定效应（Anchoring）
- **先抛出的数字/方案会影响后续走向**
- 方案 B 是"锚"——绝大多数客户最终在 B 附近达成
- 方案 A 是"诱饵"——只在 B 不被接受时才拿出来
- 方案 C 是"底线"——永远不说"没得谈了"，但要明确"这是我们最大的诚意"

### 原则 5：承诺一致性
- 客户一旦口头同意任何事，就要"趁热打铁"具体化
- 经典话术："您刚才也说了，希望这件事尽快解决，对吧？——那我们今天就把方案定下来"
- 不要让客户"先想想再说"——给时间 = 给犹豫空间 = 给反悔机会

## 2. 五大让让步节奏

### 节奏 A：先大后小（适用于客户坚持型）
```
客户开价 10,000 → 我方 1,000 → 客户 8,000 → 我方 2,000 → 客户 5,000 → 我方 3,000 → 达成
```
- **优点**：让客户感觉"我让步了"
- **风险**：开价过大可能让客户觉得"原来还有这么多空间"
- **适用**：客户强硬、不让步会威胁升级

### 节奏 B：先小后大（适用于客户理性型）
```
客户开价 10,000 → 我方 500 → 客户 8,000 → 我方 1,500 → 客户 5,000 → 我方 3,000 → 达成
```
- **优点**：每步让步幅度小、累计也能给到合理范围
- **风险**：客户可能中途失去耐心
- **适用**：客户理性、要的是"被尊重"而非"占便宜"

### 节奏 C：一次性让步（适用于客户弱势型）
```
客户开价 10,000 → 我方 500 → 客户 7,000 → 我方直接给 3,000 + 500 元京东卡 → 达成
```
- **优点**：避免来回拉锯，给客户安全感
- **风险**：显得我方立场不坚定
- **适用**：客户焦虑、弱势、怕复杂

### 节奏 D：不给让步，给替代（适用于客户不合理诉求）
```
客户要全免 → 我方："全免我做不了，但我可以给您两个选择：
  选项 1：减免 X 期 + 500 元京东卡
  选项 2：延期 3 个月 + 不上报征信"
```
- **优点**：给客户"选择感"，转移矛盾
- **风险**：选项设计要合理，不能让客户感觉被糊弄
- **适用**：客户诉求超出我方权限

### 节奏 E：沉默让步（适用于客户犹豫型）
```
客户开价 5,000 → 我方"嗯..."（沉默 5 秒）→ 客户"3,000 行不行？" → 我方 2,500 → 达成
```
- **优点**：沉默是强大的谈判武器
- **风险**：用不好会让客户感觉被冷落
- **适用**：客户已经动摇、只是想要"再多一点"

## 3. 关键心理学效应在电话中的应用

### 3.1 互惠原理（Reciprocity）
- **客户先让步，我们再让步**
- 话术："我先为您申请了一个 X 元的额度调整——但这个需要您配合我确认两件事..."
- 让客户感觉"我方先付出了"

### 3.2 承诺与一致（Commitment & Consistency）
- 让客户**先做小承诺**——"您愿意继续按时还款对吧？"
- 一旦客户口头同意，再谈"那基于这个前提，我们可以..."
- 客户为了保持"言行一致"，更容易接受方案

### 3.3 社会认同（Social Proof）
- 话术："我们之前也处理过类似的客户，最终给到的方案是..."
- **慎用**：不要让客户感觉被当成"案例"批量处理
- 适用：客户是首次投诉、不了解流程

### 3.4 权威（Authority）
- 话术："按监管要求，我行对这类问题有明确处理流程..."
- 话术："我们主管特别重视您这个案件，专门要求我..."
- **慎用**：权威用多了会显得官僚

### 3.5 稀缺（Scarcity）
- 话术："这个 500 元的补偿方案是基于您首次投诉申请的，如果您撤销投诉再回来，可能就没这个额度了"
- **慎用**：用过了会变成"威胁"，让客户感觉被利用
- **红线**：不得暗示"如果不投诉就给更好方案"——这是变相的"投诉奖励"

### 3.6 喜好（Liking）
- 叫出客户姓氏、用客户偏好的称呼
- 找到共同点（"我老家也是湖南的"）
- **慎用**：过度套近乎会让客户反感、感觉不专业

### 3.7 损失厌恶（Loss Aversion）
- 人对"损失"的痛感是"获得"的 2-2.5 倍
- 话术："如果今天不定下来，这 500 元的补偿方案可能就申请不到了"
- 话术："您继续逾期的话，每天会有 X 元的罚息，还会影响您的征信记录"
- **慎用**：用多了会让客户感觉被"恐吓"

## 4. 客户类型 × 策略矩阵

| 客户类型 | 主线策略 | 让步节奏 | 关键心理效应 | 红线 |
|---------|---------|---------|------------|------|
| 激动型 | 共情先行 | 节奏 C（一次性） | 互惠 + 损失厌恶（不） | 不得争对错、不得嘲笑 |
| 理性型 | 方案先行 | 节奏 B（先小后大） | 权威 + 社会认同 | 不得敷衍、不得绕弯 |
| 弱势型 | 保护性 | 节奏 C（一次性） | 承诺一致 + 喜好 | 不得催促、不得冷漠 |
| 强硬型 | 攻守兼备 | 节奏 A（先大后小） | 锚定 + BATNA | 不得示弱、不得威胁 |
| 犹豫型 | 引导决策 | 节奏 E（沉默） | 稀缺（慎用）| 不得催促、不得给压力 |
| 反复型（同一问题多次投诉） | 历史衔接 | 节奏 D（替代） | 承诺一致 | 不得说"我同事怎么搞的"、不得否认历史 |

## 5. 沟通节奏：3-5-7 节奏

电话沟通的黄金节奏：**3 分钟共情、5 分钟核实、7 分钟方案**。

### 前 3 分钟：共情 + 身份确认
- 让客户把情绪释放出来
- 复述客户诉求确认理解
- 确认客户身份（姓名、身份证后 4 位、合同号）

### 4-8 分钟（共 5 分钟）：核实事实
- **问问题、听答案、做记录**
- 关键问题清单（按场景）
- **不要在核实阶段给方案**——会被客户"咬住"成为新诉求

### 9-15 分钟（共 7 分钟）：方案 + 收尾
- 先抛方案 B 折中（这是锚点）
- 客户接受 → 收尾确认
- 客户不接受 → 抛方案 A 理想（加严条件）
- 客户还接受 → 抛方案 C 兜底（明确底线）
- 客户仍不接受 → 给出明确后续时间表，礼貌结束

### 注意
- 实际电话时长可长可短，但**比例**要保持
- 共情阶段超过 5 分钟 = 失控
- 方案阶段超过 10 分钟 = 拉锯战
- 出现"再想想"超过 2 次 = 客户要走

## 6. 关键话术技巧清单

### 6.1 复述诉求（让客户感觉被听见）
- "所以我理解您的诉求主要是三点：1...2...3...我理解对吗？"
- "我再说一遍我跟您确认下——您这笔借款是 X 元，发生时间是 X，主要问题是 X，对吗？"
- 复述完**必须**等客户确认，再进入下一步

### 6.2 表达共情（让客户感觉被理解）
- "我能感受到您特别着急/生气/委屈——换了我也会这样"
- "您这个情况确实让人心里不舒服"
- "您反映的这些情况我都记下来了，一件都没漏"
- **避免**："我理解您的心情"——太官方、太冷

### 6.3 释法（让客户感觉银行讲道理）
- "您说到的 X 这个问题，我帮您解释下——"
- "您关心的是 X，我给您说一下我们的情况——"
- "这块确实需要核查，我帮您调一下——"
- **避免**：长篇念法条编号、引用学术判例

### 6.4 给方案（让客户有选择）
- "我今天给您准备了 X 个方案，您看哪个更合适——"
- "方案 A 是...方案 B 是...您更倾向哪个？"
- **避免**：只给一个方案（客户没选择感）、给三个以上（客户选择困难）

### 6.5 收尾（让客户有确定感）
- "我帮您把今天说的内容复述一下——"
- "我们接下来要做的几件事是——"
- "X 个工作日内我会主动联系您"
- **避免**："您还有什么问题吗？"——开放问题容易跑题

## 7. 常见话术陷阱

| 陷阱 | 错误说法 | 正确说法 |
|------|---------|---------|
| 推卸责任 | "这是我们系统的 BUG，不赖我们" | "这个系统问题给您带来不便，我们深表歉意" |
| 否定客户 | "您说的不对" | "您说的有道理，但您可能没了解到的是——" |
| 画大饼 | "我帮您全额免了" | "我会尽力帮您申请最优方案，但具体金额需要主管审批" |
| 敷衍 | "我帮您反馈一下" | "我帮您登记成工单，X 日内给您明确回复" |
| 拖延 | "我先查一下"（没有后续） | "我现在就帮您查，需要 X 分钟，您稍等" |
| 站队催收 | "催收那边没做错" | "催收人员的具体行为我需要核查，您的反馈我们一定会认真对待" |
| 同情心爆棚 | "我也觉得银行做得不对" | "您的感受我完全理解，但具体责任认定需要核查" |
| 法条背书 | "根据《XXX法》第 X 条" | "按现行规定，这类情况一般是...具体我会帮您核实" |
| 直接挂断 | "这个我解决不了" | "这个事我马上转给主管，请您稍等" |
| 反复请示 | "我问一下主管"（无终止） | "我现在就帮您申请，主管 1 小时内会给您回电" |

## 8. 通话结束的两个关键动作

### 动作 1：复述确认
- 无论是否达成，都要把今天达成的共识/下一步说一遍
- "我再跟您确认一下今天的内容：1... 2... 3... 您看是这样吗？"
- 客户确认后**再**挂电话

### 动作 2：明确时间表
- "我会在 X 日内联系您/给您回电"
- "如果 X 日内您没收到回复，请直接联系我，工单号是 X"
- 给出客户的"退路"——避免客户感觉被冷落后再次投诉

### 不要在电话中做的事
- 答应退款/退费/免息的具体金额（除非在 500 元权限内）
- 答应客户删除征信记录
- 答应客户去骚扰/施压借款第三方
- 答应客户"给您特殊渠道 / 找领导直接批"
- 暗示"投诉到媒体就给您更多"

### 通话后必须做的事
- 工单完整记录（诉求、情绪、方案、达成度、未达成原因）
- 通话录音归档
- 涉及让步的方案 → 主管审批
- 涉及违规催收/泄露的 → 转合规部
- 涉及客户威胁的 → 转风控/法务
- 已承诺的回电 → 设置提醒，按时拨打
