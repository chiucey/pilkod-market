# 装配图风格转换技能

将工程装配图转换为多种视觉风格的专业技能。

## 工作流程

### 1. 分析原始图像

使用 `images_understand` 工具分析装配图内容：
- 识别图片类型（工程图、装配图、设备图等）
- 分析主要结构和物体特征
- 确认需要去除的标注元素

### 2. 生成三种风格图像

使用 `image_synthesize` 工具批量生成三种风格：

**风格1：铅笔素描风格**
- 提示词：转换图像为铅笔素描风格
- 添加纸张纹理效果和铅笔阴影痕迹
- 去除所有尺寸、标注、引导线
- 保留主要结构特征

**风格2：三维渲染剖面图**
- 提示词：转换为专业3D渲染剖面视图
- 白色背景
- 展示内部结构
- 金属灰色调，专业CAD渲染风格

**风格3：三维渲染效果图**
- 提示词：转换为专业3D渲染外部视图
- 白色背景
- 展示完整外观结构
- 柔和阴影，逼真材质

### 3. 输出交付

- 将生成的图像保存到工作目录
- 使用 `<deliver_assets>` 组件交付
- 列出所有输出文件的路径

## 图像生成参数建议

- 宽高比：`2:3`（适配纵向装配图）
- 输入文件：用户提供的原始装配图
- 输出格式：PNG

## 注意事项

- 确保所有标注元素被完全去除
- 保持设备主体结构的完整性和准确性
- 三维渲染风格应具有专业工程可视化品质
