# Image to Style Analyzer

将图片反向工程为详细的风格描述词。

## 核心模式：文件夹批量分析

当用户发送**文件夹**时，执行以下流程：

### Step 1: 收集图片

1. 遍历文件夹中的所有图片（支持 jpg/png/webp/jpeg）
2. 记录图片数量

### Step 2: 批量分析

1. 使用 `images_understand` 批量分析**每张图片**
2. 分析时明确要求：分析这张商业空间图片的渲染特征
3. 提取每张图片的：空间类型、材质特征、光线特点、色彩基调、构图方式、渲染风格

### Step 3: 汇总输出

**必须输出唯一结果：整套空间的风格汇总描述**

**重要**：所有内容必须是中文，所有描述必须根据图片分析结果生成具体的描述文字。

输出格式如下：

```
### 核心风格定义
根据图片分析得出的整体渲染风格描述，例如：商业展厅空间，基于原始建模结构进行真实感渲染，从建模草图感升级为真实自然的商业级空间渲染，整体呈现高端室内摄影质感，自然克制，没有明显的AI渲染痕迹。

### 空间与材质
根据图片分析得出的材质描述：
**墙面**：根据实际图片描述，如淡灰色乳胶漆墙面呈现细腻哑光质感，或白色微水泥墙面质感细腻自然
**地面**：根据实际图片描述，如浅木色实木地板自然温润，或灰色石材地面纹理真实
**顶面**：根据实际图片描述，如白色乳胶漆平顶简洁干净，或局部吊顶处理
**家具**：根据实际图片描述，如深色实木家具温润有质感，或金属与玻璃材质现代简洁

### 光照系统
根据图片分析得出的光照描述，例如：自然光从侧面窗户柔和进入，光线有明确的方向和衰减，辅以室内环境光补充，整体明暗层次清晰但不刺眼，呈现自然舒适的空间氛围，没有棚拍感的均匀打光。

### 阴影与细节
根据图片分析得出的阴影描述，例如：物体与地面之间有自然的接触阴影，阴影边缘柔和有层次，边角处略有环境遮蔽增强空间深度，整体画面干净通透，保留真实的空间光影变化。

### 镜头与构图
根据图片分析得出的构图描述，例如：相机高度约1.5米符合人眼视角，略微广角透视自然，垂直线保持稳定，构图留白合理，呈现设计感的商业空间视角。
```

### 关键要求

1. **不要列出每张图片的单独分析** - 只输出汇总结果
2. **所有描述使用中文** - 完全不能出现英文单词
3. **格式必须严格遵循**：`### 核心风格定义`、`### 空间与材质`、`### 光照系统`、`### 阴影与细节`、`### 镜头与构图`
4. **空间与材质部分必须包含**：墙面、地面、顶面、家具四个分类
5. **描述内容必须是根据图片分析得出的具体描述**，不是模板占位符，要描述图片中实际看到的样子
