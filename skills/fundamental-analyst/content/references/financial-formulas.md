# Financial Analysis Formulas Reference

## 1. Growth Metrics

### YoY Revenue Growth Rate
```
YoY Revenue Growth = (Current Revenue - Prior Revenue) / abs(Prior Revenue) × 100%
```

### YoY Net Profit Growth Rate
```
YoY Net Profit Growth = (Current Net Profit - Prior Net Profit) / abs(Prior Net Profit) × 100%
```

### YoY EPS Growth Rate
```
YoY EPS Growth = (Current EPS - Prior EPS) / abs(Prior EPS) × 100%
```

## 2. Profitability Metrics

### Gross Margin
```
Gross Margin = (Revenue - COGS) / Revenue × 100%
            = Gross Profit / Revenue × 100%
```

### Net Profit Margin
```
Net Profit Margin = Net Profit / Revenue × 100%
```

### ROE (Return on Equity)
```
ROE = Net Profit / Net Assets × 100%
    = Net Profit / (Total Assets - Total Liabilities) × 100%
```

### ROA (Return on Assets)
```
ROA = Net Profit / Total Assets × 100%
```

## 3. Financial Structure Metrics

### Debt-to-Asset Ratio
```
Debt-to-Asset Ratio = Total Liabilities / Total Assets × 100%
```

### Current Ratio
```
Current Ratio = Current Assets / Current Liabilities
```

### Quick Ratio
```
Quick Ratio = (Current Assets - Inventory) / Current Liabilities
```

## 4. Valuation Metrics

### PE (Price-to-Earnings)
```
PE = Stock Price / EPS
   = Market Cap / Net Profit
```

### PB (Price-to-Book)
```
PB = Stock Price / Book Value Per Share
   = Market Cap / Net Assets
```

### PS (Price-to-Sales)
```
PS = Market Cap / Total Revenue
```

## 5. CAN SLIM Scoring Standards

### C - Quarterly EPS
| Score | Criteria |
|-------|----------|
| 90-100 | Quarterly EPS growth >40% |
| 70-89 | Quarterly EPS growth 20%-40% |
| 50-69 | Quarterly EPS growth 10%-20% |
| 30-49 | Quarterly EPS growth 0%-10% |
| 0-29 | Quarterly EPS declined |

### A - Annual EPS Growth
| Score | Criteria |
|-------|----------|
| 90-100 | Annual EPS growth >35% |
| 70-89 | Annual EPS growth 25%-35% |
| 50-69 | Annual EPS growth 15%-25% |
| 30-49 | Annual EPS growth 5%-15% |
| 0-29 | Annual EPS growth <5% |

### L - Relative Strength
| Score | Criteria |
|-------|----------|
| 90-100 | Relative strength >90 |
| 70-89 | Relative strength 80-90 |
| 50-69 | Relative strength 70-80 |
| 30-49 | Relative strength 60-70 |
| 0-29 | Relative strength <60 |

### Composite Score
```
CAN SLIM Composite = C×0.25 + A×0.25 + N×0.10 + S×0.10 + L×0.15 + I×0.10 + M×0.05
```

## 6. Reasonable Valuation Estimation

### PEG Valuation
```
PEG = PE / Net Profit Growth Rate
PEG < 1: Undervalued
PEG = 1: Fair value
PEG > 1: Overvalued
```

### Historical Percentile Method
```
Current Valuation Percentile = (Current - Historical Low) / (Historical High - Historical Low) × 100%
```

### Industry Comparison Method
```
Valuation Premium/Discount = (Stock PE - Industry PE) / Industry PE × 100%
```
