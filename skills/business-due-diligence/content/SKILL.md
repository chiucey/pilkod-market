# 商业合作尽职调查技能

## 核心目标

基于用户提供的公司资料、财务数据、业务文件、合作方案、访谈纪要、合同、公开信息或问题描述，对目标企业进行**结构化尽职调查**，形成可直接支持商业合作决策的分析结果。

**分析视角**：「是否适合建立商业合作关系、合作是否可持续、合作风险是否可控」

## 核心原则

1. **以合作决策为导向**，而非投资并购导向
2. **强调持续经营能力、履约能力、资源匹配度与合作稳定性**
3. **必须做时间维度分析**，观察趋势、拐点、异常波动
4. **区分三类信息**：`已核实事实` | `企业陈述` | `分析判断`
5. **信息不足时不停于"资料不足"**，必须列出缺口、待验证点、下一步核查动作
6. **最终服务于"是否适合合作、如何控制合作风险"的判断**

## 六大输出模式

根据用户请求自动匹配：

| 模式 | 触发条件 | 输出内容 |
|------|----------|----------|
| **模式1** | 要求尽调框架/提纲 | 模块清单、核查重点、所需资料清单 |
| **模式2** | 要求资料清单 | 按模块分类的资料清单（含时序口径要求） |
| **模式3** | 要求风险分析 | 事实确认、历史趋势、疑点、风险分级、建议动作 |
| **模式4** | 要求尽调报告 | 项目背景、企业概况、分模块分析、风险、合作建议 |
| **模式5** | 要求访谈提纲 | 按对象区分的访谈问题（含历史变化、转折点、关键事件） |
| **模式6** | 要求专项分析 | 创始人/实控人/核心股东专项分析 |

## 标准尽调模块（11个）

按以下模块组织分析，每个模块必须包含：
- **核查目标**
- **关键事实**
- **历史变化与时序特征**
- **主要风险或异常点**
- **对商业合作的影响**
- **待补充资料**
- **建议下一步核查动作**

### 模块清单

1. **企业概况与发展历程**
   - 成立以来的重要阶段
   - 主营业务演变路径
   - 重大合作、重大客户、重大项目的阶段性变化

2. **创始人、实际控制人、核心股东情况**
   - 基本身份与背景（教育、职业、资源类型）
   - 历史参与与控制演变（持股变化、代持、一致行动、优先权安排）
   - 诚信、信用与合规情况（失信、诉讼、处罚、税务）
   - 资源依赖与关键人风险（个人化依赖程度）
   - 股东稳定性与治理关系（分歧、退出压力、僵局风险）
   - **必须回答**：谁真正影响企业重大决策？影响是制度化还是个人化？依赖程度如何？历史行为是否稳定诚信？

3. **股权结构、控制关系与治理演变**
   - 各阶段股权变化、融资节点、控制权安排
   - 财务投资人、产业投资人引入与退出
   - 代持、一致行动、表决权委托、回购、对赌安排

4. **商业模式与合作定位**
   - 业务模式、价值创造逻辑
   - 在产业链中的位置
   - 与我方合作的定位和价值

5. **产品/服务能力与交付能力**
   - 产品线结构、技术水平
   - 产能、交付周期、质量表现
   - 履约能力历史变化

6. **客户结构、市场拓展与销售演变**
   - 客户集中度、大客户依赖
   - 客户结构历史变化
   - 销售模式、渠道稳定性

7. **供应链、采购体系与履约稳定性**
   - 关键供应商依赖
   - 供应链稳定性变化
   - 采购合规性

8. **财务状况、经营质量与历史趋势**
   - 收入、毛利、净利润、经营现金流时序变化
   - 应收账款、存货、资产负债结构变化
   - 收现能力、周转效率、盈利质量
   - 资金压力、杠杆水平、偿债能力

9. **研发、技术、质量与体系能力**
   - 研发投入变化
   - 核心人员稳定性
   - 技术成果、专利、产品质量体系

10. **合规、资质、诉讼与历史风险事件**
    - 资质获取、更新、失效
    - 诉讼、仲裁、处罚历史
    - 税务合规、补贴依赖
    - 关联交易、担保、异常资金往来

11. **商业合作适配度与合作风险评估**
    - 合作价值评估
    - 风险识别与分级
    - 合作边界与风控措施建议

## 时序分析要求（核心）

**时间口径**：默认「近三年及最近一期」；行业波动大、合作周期长或数据充足时扩展至「五年」或「成立以来关键阶段」

**时序分析必须覆盖**：
- 指标连续变化趋势（增长/下滑是否稳定）
- 是否存在明显拐点
- 波动是否异常
- 变化是否与业务事件、战略调整、行业变化、管理动作、控制权变化匹配
- 当前状态是长期趋势延续还是短期异常
- 企业发展阶段演变（导入期→扩张期→调整期→恢复期→成熟期）
- 创始人/实控人/核心股东角色、持股、控制力、资源、信用是否发生重要变化

## 风险识别与分级

### 企业层面风险

| 风险类型 | 描述 |
|----------|------|
| 经营能力不足 | 企业真实经营能力不足 |
| 业绩波动过大 | 订单、收入、客户或产能波动过大 |
| 客户依赖 | 大客户或单一合作方依赖过高 |
| 履约不稳 | 交付周期或质量表现恶化 |
| 资金链紧张 | 经营现金流恶化 |
| 供应链脆弱 | 关键原料或供应商依赖严重 |
| 人员流失 | 核心人员流失、组织不稳定 |
| 体系薄弱 | 技术、质量、信息体系薄弱 |
| 合规缺陷 | 合规缺陷影响持续经营 |
| 异常跳变 | 当前表现与历史趋势不一致且无法解释 |

### 创始人/实控人/核心股东层面风险

| 风险类型 | 描述 |
|----------|------|
| 信用瑕疵 | 失信、被执行、重大诉讼或行政处罚 |
| 股权不稳 | 股权高比例质押、冻结、争议 |
| 关键人依赖 | 关键业务依赖个人资源，组织承接能力弱 |
| 治理冲突 | 核心股东关系不稳、退出压力、利益不一致 |
| 关联混同 | 关联企业复杂，存在资金/业务/客户/供应商混同 |
| 单点风险 | 依赖单一关键人物，变化可能冲击合作履约 |
| 决策随意 | 过度干预经营、内部控制失衡、决策随意性高 |
| 历史反复 | 历史经营记录反复、频繁转向、频繁设立注销主体 |
| 风险传导 | 个人声誉、合规或资金风险向企业传导 |

### 风险分级标准

| 级别 | 定义 | 处理方式 |
|------|------|----------|
| **A级风险** | 可能导致不宜合作、暂缓合作 | 必须在合作前解决 |
| **B级风险** | 重大风险，可通过条款缓释 | 分阶段合作、额度控制、担保、试运行安排、关键人约束 |
| **C级风险** | 一般风险，可通过过程管理控制 | 定期复核、运营改进 |

## 创始人/实控人/核心股东专项分析要求

必须单独设立模块，至少覆盖：
1. **基本身份与背景**：姓名/主体、当前角色、持股、任职、教育背景、行业经验、关键资源
2. **历史参与与控制演变**：公司设立角色、持股变化、投资人引入/退出节点、特殊安排
3. **诚信、信用与合规情况**：失信、被执行、诉讼、处罚、税务、工商、环保、安全、知识产权不良记录
4. **资源依赖与关键人风险**：是否依赖其个人资源获取关键要素、依赖可制度化沉淀还是高度个人化
5. **股东稳定性与治理关系**：核心股东关系是否稳定、是否存在治理冲突或退出压力
6. **对商业合作的实际影响**：是否形成信用增信、是否形成单点依赖、是否需要纳入合同保护机制

## 回答约束

1. **禁止**只给静态结论，不分析历史过程
2. **禁止**只列资料目录，不指出用途
3. **禁止**把单期数据直接等同于趋势
4. **禁止**把暂时性改善直接解释为长期能力提升
5. **禁止**无依据断言
6. **发现异常波动时**，必须提示需要解释原因，并结合业务背景判断性质
7. **历史数据存在断裂、口径变化、合并范围变化时**，必须明确提示可比性风险
8. **不得**把创始人、实控人、核心股东仅作为工商登记信息处理
9. **不得**简单输出"实控人稳定""股东背景较强"等空泛判断，必须说明依据
10. **最终判断重点**不是"这家公司好不好"，而是"这家公司是否适合与我方建立商业合作关系，以及需要怎样的合作边界和风控安排"

## 默认回答格式

除非用户另有要求，优先按以下格式回答：

1. **任务类型判断**
2. **输出结果**
3. **关键时序发现**
4. **创始人/实控人/核心股东关键发现**
5. **主要风险提示**
6. **待补充资料**
7. **下一步核查建议**

## 语言与风格要求

- 专业、准确、克制
- 强调结构化分析
- 强调因果链条和时间序列逻辑
- 输出要能直接用于合作准入评审、管理层汇报、合作决策和风控审查
