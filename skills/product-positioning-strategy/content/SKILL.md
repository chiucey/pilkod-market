# 产品定位与差异化竞争策略制定技能

## 技能定义

通过系统性的市场分析和战略规划，明确产品的独特定位，构建差异化竞争优势，制定清晰的价值主张，实现目标用户的精准卡位。

## 核心SOP

### 步骤1：市场分析

**五力模型分析**：

| 力量 | 分析要点 | 影响程度 |
|------|---------|---------|
| 现有竞争 | 竞争者数量、集中度 | [高/中/低] |
| 新进入者 | 壁垒高低、威胁程度 | [高/中/低] |
| 替代品 | 替代品威胁程度 | [高/中/低] |
| 供应商 | 供应商议价能力 | [高/中/低] |
| 买方 | 买方议价能力 | [高/中/低] |

### 步骤2：竞争格局绘制

**竞争地图**：

```
                    高市场增长率
                        ↑
                        |
        领导者          |          挑战者
    ←───────────────────┼───────────────────→
                        |           领导者
    利基市场            |            跟随者
                        |
                        ↓
                    低市场增长率
```

### 步骤3：差异化维度选择

| 差异化维度 | 高频场景 | 案例 |
|-----------|---------|------|
| 产品功能 | 功能创新 | Notion |
| 用户体验 | 交互设计 | Apple |
| 价格策略 | 成本领先 | 小米 |
| 渠道覆盖 | 渠道创新 | 美团 |
| 服务体系 | 服务溢价 | 海底捞 |
| 品牌形象 | 品牌调性 | 戴森 |

### 步骤4：定位陈述撰写

**模板**：

```
For [目标用户]
who [需求/痛点]
the [产品名称] is a [产品品类]
that [核心价值主张]
unlike [主要竞品]
our product [差异化优势]
```

### 步骤5：价值主张设计

**价值金字塔**：

```
           ┌─────────────┐
           │   情感价值   │
           │ (品牌/身份)  │
           ├─────────────┤
           │   社交价值   │
           │ (关系/认可)  │
           ├─────────────┤
           │   功能价值   │
           │ (解决问题)  │
           ├─────────────┤
           │   核心价值   │
           │ (基本利益)  │
           └─────────────┘
```
