# 生物医学实验设计参考

> 适用于代谢组学、蛋白质组学、空间成像、传统生物化学、细胞生物学、小动物实验等方向

---

## 一、传统生物化学实验

### 酶活性测定

#### 实验设计要点
```
□ 底物浓度：需达到饱和（> Km 值）
□ 酶浓度：在线性范围内
□ pH 和温度：需标准化
□ 反应时间：需在线性范围内终止
□ 抑制剂控制：设置阳性/阴性对照
```

#### 方法对比
| 方法 | 优点 | 缺点 | 适用场景 |
|------|------|------|---------|
| 比色法 | 简单、快速 | 灵敏度有限 | 初筛、定性 |
| 荧光法 | 高灵敏度 | 可能存在自发荧光 | 微量样本 |
|放射性法 | 最高灵敏度 | 安全性问题 | 研究用 |
| HPLC/UPLC | 高特异性 | 耗时 | 精确定量 |

### ELISA (酶联免疫吸附测定)

#### 实验设计要点
```
□ 抗体选择：
  - 单克隆 vs 多克隆：单克隆特异性高，多克隆敏感性高
  - 交叉反应评估
  - 保存条件验证

□ 标准曲线：
  - 浓度点：6-8 个点（双复孔）
  - 范围：覆盖预期样本浓度
  - 拟合方法：四参数逻辑回归

□ 样本处理：
  - 稀释倍数：预实验确定
  - 批间变异：同一批次检测
  - 复孔一致性：CV < 15%
```

#### 方法验证参数
```
□ 准确度：回收率 80-120%
□ 精密度：批内 CV < 10%，批间 CV < 15%
□ 线性：r² > 0.99
□ 检测范围：LOD 到 ULOQ
□ 基质效应：评估血清/血浆/组织裂解液
```

### Western Blot (免疫印迹)

#### 实验设计要点
```
□ 样本制备：
  - 蛋白定量：BCA 或 Bradford（一致方法）
  - 变性条件：SDS + 热变性
  - 还原剂：DTT 或 β-ME

□ 电泳：
  - 凝胶浓度：根据分子量选择
  - 上样量：20-50 µg/泳道（内参校正）
  - 分子量标记：预染 marker

□ 转膜：
  - PVDF 膜：需甲醇活化
  - 转膜条件：湿转 or 半干转
  - 转膜效率：可用预染 marker 监测

□ 抗体孵育：
  - 一抗稀释比：预实验优化
  - 孵育时间：4°C 过夜 or 室温 1-2h
  - 洗涤：TBST 3×10min

□ 检测：
  - ECL：曝光时间优化
  - 或荧光二抗：多靶点同时检测
```

#### 定量分析要点
```
□ 内参选择：
  - 看家基因：GAPDH, β-actin, β-tubulin
  - 核蛋白：Histone H3
  - 总蛋白染色： Ponceau S / Stain-Free

□ 归一化方法：
  - 目的蛋白 / 内参
  - 或 total protein normalization

□ 线性范围验证：
  - 上样量梯度确认线性
  - 曝光时间线性
```

## 二、分子生物学实验

### PCR / qPCR

#### 实验设计要点
```
□ 引物设计：
  - 长度：18-25 nt
  - Tm：55-65°C，两端引物差异 < 2°C
  - 产物长度：80-200 bp（qPCR）
  - 避免二聚体和发夹结构

□ 标准品：
  - 质粒标准品：绝对定量金标准
  - 克隆片段：需测序确认
  - 标准曲线：5-6 个稀释点

□ 内参基因：
  - 表达稳定：GAPDH, ACTB, 18S rRNA
  - 需验证稳定性（GeNorm, NormFinder）
  - 样本类型特异

□ 质量控制：
  - No Template Control (NTC)
  - No Reverse Transcriptase Control (NRT)
  - 熔解曲线：单峰确认特异性
```

#### 相对定量计算
```
ΔΔCt 方法：
1. ΔCt = Ct(目的基因) - Ct(内参)
2. ΔΔCt = ΔCt(实验组) - ΔCt(对照组)
3. Fold Change = 2^(-ΔΔCt)

注意：
- 需要验证扩增效率 (90-110%)
- 复孔 CV < 5%
```

### 克隆与基因编辑

#### 实验设计要点
```
□ 载体选择：
  - 启动子：组织特异性表达需求
  - 筛选标记：抗生素抗性
  - 表达标签：N/C-terminal

□ 转化/转染：
  - 阳性克隆筛选
  - 单克隆分离
  - 测序验证

□ sgRNA / shRNA 设计：
  - 脱靶效应评估
  - 敲除效率验证
  - 功能验证
```

## 三、细胞生物学实验

### 细胞培养

#### 实验设计要点
```
□ 细胞系认证：
  - STR 分型鉴定
  - 支原体检测
  - 污染物筛查

□ 培养条件：
  - 培养基：血清浓度、品牌批次记录
  - 温度、CO₂：37°C, 5% CO₂
  - 传代次数：记录，避免过度传代

□ 实验处理：
  - 细胞密度：铺板均匀度
  - 处理时间/剂量：梯度预实验
  - 溶剂对照（DMSO 等）< 0.1%

□ 批次效应控制：
  - 同一批次细胞做同一实验
  - 同一批次培养基/试剂
```

#### 细胞计数与活力
```
□ 计数方法：
  - 血球计数板
  - 自动细胞计数仪（Trypan Blue）
  - Countess 等设备

□ 活力评估：
  - 台盼蓝拒染法
  - Calcein-AM/PI 双染
  - MTT/MTS/XTT 法

□ 铺板标准化：
  - 细胞数/孔面积
  - 汇合度控制
```

### 流式细胞术

#### 实验设计要点
```
□ 抗体选择与滴定：
  - 预实验滴定最佳浓度
  - 同型对照设置
  - 荧光补偿对照

□ 样本制备：
  - 单细胞悬液制备
  - 胞内染色需固定/透化
  - Fc 受体阻断

□ 设门策略：
  - FSC/SSC 圈门
  - 单细胞门（FSC-A vs FSC-H）
  - 阴性/阳性分界

□ 补偿与对照：
  - 单染对照（补偿）
  - FMO (Fluorescence Minus One) 对照
  - 阳性对照
```

#### 数据分析要点
```
□ 统计量：
  - MFI (Mean Fluorescence Intensity)
  - % 阳性细胞
  - 几何均值 vs 算术均值

□ 展示方式：
  - 直方图：单参数
  - 散点图：双参数
  - 等高线图：高密度数据
```

### 免疫荧光 / 免疫组化

#### 实验设计要点
```
□ 抗体验证：
  - IHC/IF 专用抗体
  - 文献引用确认
  - 组织特异性验证

□ 样本固定：
  - 福尔马林：组织蛋白交联
  - 甲醇/丙酮：保留抗原性
  - 条件优化

□ 抗原修复：
  - 热诱导表位修复 (HIER)
  - 酶消化：proteinase K, pepsin

□ 染色对照：
  - 阳性对照：已知表达组织
  - 阴性对照：同型对照/省略一抗
```

## 四、小动物实验（啮齿类）

### 实验设计原则

#### 动物模型选择
```
□ 基因背景：
  - 纯系 vs 杂交：纯系变异小
  - 近交系 vs 远交系
  - 转基因/基因敲除模型

□ 年龄/体重：
  - 发育阶段匹配研究目的
  - 同批次动物年龄一致
  - 体重作为协变量考虑

□ 性别因素：
  - 单性别研究需说明理由
  - 雌雄各半需足够样本量
  - 考虑激素周期影响
```

#### 分组设计
```
□ 随机化原则：
  - 简单随机化
  - 分层随机化（体重分层）
  - 区组随机化

□ 组别设置（典型设计）：
  - 正常对照组 (Control)
  - 模型组 (Model)
  - 阳性对照组 (Positive)
  - 实验组 (Treatment, 可多剂量)

□ 每组样本量：
  - 预实验：3-5 只/组
  - 正式实验：8-15 只/组（根据效应量）
  - 考虑损耗率：额外 10-20%
```

### 伦理与规范

#### 3R 原则
```
Reduction (减少)：
  - 统计方法减少动物用量
  - 同一动物多次采样
  - 合理实验设计

Replacement (替代)：
  - 体外实验优先
  - 计算机模拟
  - 低等生物模型

Refinement (优化)：
  - 最小化痛苦
  - 麻醉和镇痛
  - 环境丰富化
```

#### 伦理审批
```
□ IACUC / 动物伦理委员会审批
□ 实验方案详细记录
□ 人员培训证书
□ 疼痛评估与安乐死标准
```

### 给药与干预设计

#### 给药方案
```
□ 途径选择：
| 途径 | 优点 | 缺点 | 适用 |
|------|------|------|------|
| 口服灌胃 | 无创 | 吸收不稳定 | 药物研发 |
| 腹腔注射 | 吸收好 | 有刺激风险 | 常规给药 |
| 静脉注射 | 生物利用度100% | 技术要求高 | 精确给药 |
| 皮下注射 | 吸收慢 | 操作简单 | 缓释制剂 |
| 吸入 | 呼吸道疾病 | 设备要求 | 呼吸系统 |

□ 溶媒选择：
  - 生理盐水
  - DMSO (终浓度 < 1%)
  - 羧甲基纤维素 (CMC)
  - 对照组给等体积溶媒

□ 剂量设置：
  - 人体等效剂量换算
  - 预实验确定剂量范围
  - 临床前安全剂量
```

#### 样本采集

```
□ 终末采样 vs 动态采样：
  - 终末：实验终点处死取材
  - 动态：同一动物多点采样
  - 优势：减少动物用量

□ 常见采样时间点：
  - 0h (给药前基线)
  - 0.5h, 1h, 2h, 4h, 8h, 24h
  - 采血量限制：小鼠 < 10% 总血量/次

□ 样本处理：
  - 立即分离血清/血浆
  - 组织速冻 (液氮) 或固定
  - 分装储存 (-80°C)
```

□ 运动功能：

  - 固定时间段检测
  - 昼夜节律影响
  - 检测顺序平衡

□ 设备校准：
  - 仪器一致性
  - 视频追踪系统验证

## 五、生物标志物发现与验证

### 发现 → 验证 → 临床转化

```
阶段 1：发现（n = 30-100/组）
  → 高通量筛选，发现候选标志物
  → 不追求精确量化

阶段 2：验证（n = 100-300/组）
  → 靶向方法验证
  → 评估诊断性能（AUC）

阶段 3：临床验证（n = 300+/组）
  → 多中心，前瞻性
  → 完整的方法验证
```

### 样本匹配
```
□ 年龄、性别匹配
□ BMI、合并症匹配
□ 采样时间标准化
□ 前处理一致性
```

## 六、质量控制标准

### 队列研究 QC
```
□ 盲态 QC 样本插入（10-15%）
□ 批次效应评估与校正
□ 离群值定义与处理
□ 缺失数据记录
```

### 技术验证 QC
```
□ 线性范围：r² > 0.99
□ 批内精密度：CV < 15%
□ 批间精密度：CV < 20%
□ 检出限（LOD）：S/N > 3
□ 定量限（LOQ）：CV < 20%
□ 基质效应：< 15%
□ 回收率：80-120%
```

### 动物实验 QC
```
□ 体重监测：每周 2-3 次
□ 临床评分：标准化量表
□ 生存率记录
□ 组织病理学评估
```

## 九、实验设计共性分析框架

### 几乎所有生物医学实验的共性要素

```
1. 阳性对照
   - 为什么必要：验证实验体系正常工作
   - 共性证据：ELISA、WB、PCR、流式都需要
   - 本实验：选择什么阳性对照？

2. 阴性对照
   - 为什么必要：排除假阳性
   - 共性证据：所有检测方法都需要
   - 本实验：设置什么阴性对照？

3. 重复测量
   - 为什么必要：评估变异、确保可重复
   - 共性证据：技术重复 + 生物学重复
   - 本实验：重复次数是否足够？

4. 校准与标准化
   - 为什么必要：确保测量准确性
   - 共性证据：定量实验都需要
   - 本实验：如何校准？
```

### 差异性决策示例

| 决策点 | 选项 A | 选项 B | 差异原因 |
|--------|--------|--------|---------|
| 样本量 | n=6 | n=12 | 预期效应大小 vs 资源 |
| 检测方法 | ELISA | Western Blot | 定量 vs 定性/半定量 |
| 动物模型 | 野生型 | 转基因 | 机制研究 vs 疾病模型 |
| 采样时间 | 终点采样 | 动态采样 | 3R 原则 vs 数据完整性 |
