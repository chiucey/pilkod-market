# 化学实验设计参考

> 适用于有机化学、分析化学、物理化学、催化化学等方向

---

## 有机合成实验设计

### 反应变量控制

#### 核心变量清单
```
□ 底物结构：电子效应、位阻效应
□ 试剂选择：亲核性/亲电性、活性
□ 溶剂：极性、质子性/非质子性、沸点
□ 温度：反应速率、热力学控制
□ 催化剂/配体：选择性、活性
□ 浓度：反应级数、副反应
□ 反应时间：转化率、选择性
□ 气氛：空气敏感、水氧敏感
```

#### 变量控制检查表
```
基础对照实验：
□ 空白实验（无催化剂/无试剂）
□ 已知条件重复（文献方法）
□ 温度梯度实验
□ 溶剂对照实验

变量筛选策略：
□ 单变量法：每次改变一个变量
□ 正交实验法：多因素同时优化
□ DoE (Design of Experiments)：系统筛选
```

### 反应条件优化

#### 温度优化
```
| 温度范围 | 适用场景 | 风险 |
|---------|---------|------|
| -78°C | 低温反应、锂试剂 | 设备要求高 |
| 0°C - 室温 | 大多数有机反应 | 温和、安全 |
| 50-80°C | 加热促进反应 | 副反应增加 |
| 回流 | 高沸点溶剂 | 溶剂选择受限 |

温度选择原则：
- 室温可进行的反应不加热的原则
- 升温需有明确理由（速率、平衡）
- 热敏性底物避免高温
```

#### 溶剂选择
```
| 溶剂类型 | 极性 | 适用反应 | 注意事项 |
|---------|------|---------|---------|
| 正己烷 | 低 | 疏水性反应 | 非极性溶解 |
| 甲苯 | 低 | Pd 催化、加热 | 回流温度高 |
| THF | 中 | 锂试剂、格氏 | 需无水 |
| DCM | 中 | 有机金属、温和条件 | 易挥发 |
| DMF | 高 | 偶联、SNAr | 沸点高，难除 |
| MeOH | 高 | 氢化、酯化 | 质子性 |
| DMSO | 高 | 极性反应 | 难以去除 |
| 水 | 高 | 绿色化学 | 水敏感反应不适用 |

共沸干燥参考：
| 共沸物 | 沸点 | 水含量 |
|-------|------|-------|
| 甲苯-水 | 85°C | 20% |
| THF-水 | 64°C | 5% |
```

#### 催化剂/配体优化
```
配体电子效应：
□ 富电子配体：促进还原消除
□ 缺电子配体：增强氧化加成
□ 膦配体：位阻可调

常见配体类型：
| 类型 | 特性 | 适用反应 |
|------|------|---------|
| PPh3 | 常用、稳定 | Pd(0) 基础 |
| XPhos | 大位阻 | 杂环偶联 |
| BINAP | 手性 | 不对称催化 |
| DPPP | 柔性 | 多步串联 |

金属负载量：
- 常规：1-5 mol%
- 惰性底物：5-10 mol%
- 活性底物：0.1-1 mol%
```

### 合成路线设计

#### 逆合成分析
```
策略层次：
1. 识别目标分子骨架
2. 选择关键键断裂点
3. 评估可得的起始原料
4. 设计保护基策略
5. 验证立体化学控制

常见转化逆向：
| 目标官能团 | 逆合成 | 试剂 |
|-----------|-------|------|
| 醇 | C=O + 还原剂 | NaBH4, LiAlH4 |
| 胺 | 还原胺化/硝基 | NH3, H2/Pd |
| 羧酸 | 氧化/水解 | KMnO4, 酯水解 |
| 烯烃 | Wittig/Elimination | 膦叶立德 |
```

#### 路线对比维度
```
□ 总步骤数 vs 整体收率
□ 步骤经济性（step economy）
□ 原子经济性（atom economy）
□ 试剂可获得性
□ 操作复杂性
□ 安全性
□ 成本
□ 可放大性

方案A vs 方案B 示例：
| 指标 | 路线 A | 路线 B |
|------|--------|--------|
| 步骤数 | 5 步 | 3 步 |
| 整体收率 | 35% | 22% |
| 原料成本 | 高 | 中 |
| 放大难度 | 中 | 低 |
```

## 分析化学实验设计

### 仪器分析方法设计

#### UV-Vis 分光光度法
```
方法开发参数：
□ 波长选择：最大吸收 λmax 或等吸收点
□ 浓度范围：线性范围 (Beer-Lambert)
□ 溶剂选择：透明度、极性匹配
□ pH 影响：离子化状态

验证参数：
| 参数 | 典型要求 | 方法 |
|------|---------|------|
| 线性 | r² > 0.999 | 标准曲线 ≥ 5 点 |
| 范围 | 80-120% | 线性范围上下限 |
| 检出限 | S/N ≥ 3 | ICH 指南 |
| 定量限 | S/N ≥ 10 | ICH 指南 |
| 精密度 | RSD < 2% | 重复测量 |
| 准确度 | 95-105% | 加标回收 |

```

#### HPLC/GC 方法开发
```
固定相选择：
| 分离类型 | 色谱柱 | 适用分析物 |
|---------|-------|-----------|
| 反相 | C18, C8 | 大多数有机物 |
| 正相 | 硅胶, CN | 非极性 |
| HILIC | Amide, NH2 | 极性化合物 |
| 离子交换 | SA/SC | 离子型化合物 |
| 分子排阻 | GPC | 高分子、聚合物 |

梯度优化：
```
初始有机相比例：根据分析物极性
梯度斜率：陡梯度（快速筛选）vs 缓梯度（高分离度）
最终有机相比例：确保所有组分洗脱
平衡时间：2-5 柱体积
```

流动相选择：
```
反相 HPLC：
- 水相：纯水或缓冲液
- 有机相：ACN, MeOH
- 添加剂：TFA, FA, 缓冲盐

缓冲液选择原则：
□ 分析物 pKa ± 2 范围内
□ 与检测波长兼容
□ 不与固定相/管路反应
```

#### 质谱 (MS) 接口
```
ESI vs APCI vs APCI：
| 接口 | 离子化方式 | 适用样品 | 极性 |
|------|-----------|---------|------|
| ESI | 电喷雾 | 极性、热不稳 | 正/负 |
| APCI | 大气压化学 | 非极性 | 正/负 |
| APPI | 光致电离 | 非极性、弱极性 | 正/负 |

碎片离子选择：
□ 选择性离子监测 (SIM)：高灵敏度
□ 产物离子扫描：高特异性
□ 中性丢失扫描：结构筛选
□ MRM/PRM：定量金标准
```

### 方法验证设计

#### 完整验证清单
```
专属性 (Specificity)：
□ 峰纯度检查
□ 空白干扰
□ 降解产物分离

线性 (Linearity)：
□ r² > 0.999
□ 截距接近零
□ 残差分布随机

范围 (Range)：
□ 80-120% 目标浓度
□ 各浓度均满足准确度/精密度

准确度 (Accuracy)：
□ 回收率 98-102%
□ 与参比方法对比

精密度 (Precision)：
□ 重复性 (Repeatability)：RSD < 2%
□ 中间精密度：不同日/仪/人
□ 重现性 (Reproducibility)：实验室间

耐用性 (Robustness)：
□ 流动相 pH ± 0.2
□ 波长 ± 2 nm
□ 流速 ± 10%
□ 柱温 ± 2°C
```

## 物理化学实验设计

### 热力学测量

#### 热量测定 (DSC/TGA)
```
DSC 实验设计：
□ 升温速率：5-20°C/min（慢速更准确）
□ 气氛：N2 (惰性) vs Air (氧化)
□ 样品量：1-10 mg（与热效应匹配）
□ 参比物：空坩埚或 Al2O3

热分析参数：
| 参数 | 定义 | 意义 |
|------|------|------|
| Tg | 玻璃化转变 | 聚合物性质 |
| Tm | 熔点 | 纯度/结晶度 |
| Td | 分解温度 | 稳定性 |
| ΔH | 焓变 | 反应/相变能量 |
```

#### 动力学测量
```
Arrhenius 方程：
k = A·exp(-Ea/RT)

实验设计要点：
□ 温度范围：覆盖 Ea 计算所需
□ 等温 vs 非等温：等温更准确
□ 数据点数：至少 5 个温度点
□ 重复测定：每个温度 3 次

转化率 vs 时间：
□ 采样间隔：自动 vs 手动
□ 转化率测定：产物分析或物理性质
□ 温度控制：±0.1°C
```

### 催化化学实验

#### 催化剂表征
```
必备表征技术：
| 技术 | 提供信息 | 关键参数 |
|------|---------|---------|
| BET | 比表面积 | m²/g |
| XRD | 晶相结构 | 晶粒大小 |
| TEM/SEM | 形貌 | 粒径分布 |
| XPS | 表面组成 | 元素化学态 |
| H2-TPR | 还原性 | 还原温度 |
| NH3-TPD | 酸性 | 酸量/强度 |

比表面积测定：
□ 吸附气体：N2 at 77K
□ 预处理：真空脱气 200-300°C
□ 相对压力范围：0.05-0.30
□ 计算方法：BET 方程
```

#### 催化性能测试
```
反应条件设计：
□ 温度：考虑转化率 < 20% 以排除传质
□ 空速：WHSV 或 GHSV
□ 压力：常压 vs 加压
□ 进料比：反应物/产物比例

活性评价要点：
□ 转化率 (Conversion)：X%
□ 选择性 (Selectivity)：S%
□ 收率 (Yield)：Y% = X% × S%
□ TOF：每个活性位点的转化数

动力学测试条件：
□ 排除内外扩散
□ 排除热点
□ 确保反应在动力学控制区
□ 测定 TOF 需已知活性位点数
```

## 合成共性元素分析

### 必需操作（共性）
```
几乎所有有机合成反应的共性操作：

1. 无水无氧操作
   - 为什么必要：水分/氧气与活性中间体反应
   - 共性证据：格氏、锂试剂、Wittig 等都需要
   - 本实验：是否涉及活性中间体？

2. 溶剂干燥
   - 为什么必要：水影响反应或后处理
   - 共性证据：含活泼氢反应都需要
   - 本实验：原料/试剂对水敏感吗？

3. 淬灭操作
   - 为什么必要：终止反应、释放产物
   - 共性证据：有机金属反应必需
   - 本实验：如何安全淬灭？

4. 萃取洗涤
   - 为什么必要：分离产物、去除杂质
   - 共性证据：几乎所有后处理都需要
   - 本实验：选择什么萃取体系？
```

### 差异性设计点
```
常见差异化决策：

| 决策点 | 选项 A | 选项 B | 差异原因 |
|--------|--------|--------|---------|
| 温度 | 0°C | 回流 | 反应活性/选择性权衡 |
| 溶剂 | THF | Et2O | 溶解度/安全性差异 |
| 后处理 | 萃取 | 重结晶 | 纯度 vs 收率 |
| 催化剂 | Pd(OAc)2 | Pd(PPh3)4 | 活性/选择性差异 |
| 干燥 | Na2SO4 | 减压蒸发 | 稳定性/效率 |

差异分析框架：
□ 选项 A 优先于 B 当：...
□ 选项 B 优先于 A 当：...
□ 本研究目标更适合：...
```

## 质量控制与安全

### 反应监控设计
```
TLC 监控：
□ 点样：反应液、起始物、产物标准
□ 展开剂：Rf 值 0.2-0.8 最佳
□ 检测方法：UV、显色剂、碘缸
□ 取样时间点：起始、反应 30%、预期完成

HPLC/GC 监控：
□ 内标法 vs 外标法
□ 取样稀释：终止反应
□ 对照品准备

终点判断：
□ 原料转化率 > 95%
□ 副产物可控
□ 达到预期选择性
```

### 安全检查表
```
反应风险评估：
□ 放热反应：能否热失控？
□ 高压反应：设备承压？
□ 毒性物质：通风柜操作？
□ 爆炸性中间体：规模限制？
□ 气体产生：尾气处理？

个人防护：
□ 手套：丁腈 vs 乳胶 vs 无粉
□ 护目镜：必须
□ 实验服：棉质 vs 一次性
□ 通风：通风橱 vs 全面通风
```
