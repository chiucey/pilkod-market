# 通用实验设计原则

> 适用于所有科学、工程、技术领域

---

## 完整实验方案模板

每个最终实验方案应包含以下要素：

### 1. 实验目的
```
假设：[具体、可证伪的陈述]
验证方向：□ 确认 / □ 反驳
核心问题：[1-2句话描述]
预期结果意义：
  - 支持假设 → 意味着...
  - 不支持假设 → 意味着...
```

### 2. 变量定义
```
自变量：[被操纵的因素/条件]
因变量：[被测量的指标/输出]
控制变量：[保持恒定的因素]
协变量：[可能影响结果的干扰因素]
```

### 3. 实验类型
```
□ 探索性（Discovery）
□ 验证性（Confirmation）
□ 优化性（Optimization）

□ 对照实验
□ 因子实验
□ 时间序列实验
□ 空间/分布实验

设计理由：[为什么这个设计能回答所述假设]
```

### 4. 样本/重复与对照
```
独立重复：N = [X]，理由：[...]
测量重复：N = [X]，理由：[...]
阳性对照：[是什么，为什么必要]
阴性对照：[是什么，为什么必要]
空白/基准：[基线对照]
```

### 5. 测量与分析参数
```
测量系统：[仪器/工具/方法]
关键参数：[分辨率/精度/采样率等]
校准方案：[如何确保测量准确性]
```

### 6. 质量控制策略
```
QC 样本类型：[根据领域选择]
QC 验收标准：[定义接受阈值]
数据验证：[异常值检测/一致性检查]
```

### 7. 功效分析与样本量
```
预期效应量：[effect size]
估计变异：[从预实验或文献]
期望检验力：[0.80 或 0.90]
计算所得 N/组：[结果]
```

### 8. 预注册/文档计划
```
预注册平台：[OSF / 内部系统 / 无]
注册内容：
  - 假设
  - 主要指标
  - 分析计划
```

### 9. 局限性声明
```
本实验不能回答的问题：
[...]

做出的假设：
[...]
```

## 变量控制检查表

### 必须控制的变量
```
□ 识别所有可能的混杂变量
□ 确定哪些变量需要严格控制
□ 确定哪些变量可以随机化
□ 识别哪些变量需要作为协变量分析
```

### 控制方法
```
□ 物理控制：保持恒定
□ 统计控制：通过随机化平衡
□ 测量控制：记录并在分析中调整
□ 消除：移除该变量（如可能）
```

## 重复与抽样设计

### 重复类型
| 类型 | 目的 | 最小要求 |
|------|------|---------|
| 独立重复 | 代表性/泛化性 | 3-5 |
| 测量重复 | 精确性 | 2-3 |
| 批次重复 | 批次效应控制 | 每批次包含对照 |

### 样本量考量
```
□ 独立样本 > 技术/测量重复
□ 样本量应基于功效分析，而非便利性
□ 考虑 10-20% 的损耗/失败率
□ 预实验可帮助估计变异
```

## 随机化原则

### 何时随机化
```
□ 实验单元分配到处理组
□ 测量顺序
□ 样本处理顺序
□ 批次/区块内的顺序
```

### 随机化方法
```
□ 简单随机化：硬币/随机数表
□ 区组随机化：平衡已知混杂因素
□ 分层随机化：多因素平衡
□ 分级随机化：多中心/多批次
```

## 数据质量检查

### 采集阶段
```
□ 测量仪器校准记录
□ 环境条件监控
□ 操作人员培训确认
□ 原始数据备份
```

### 处理阶段
```
□ 数据完整性检查
□ 异常值识别（预设标准）
□ 缺失值处理策略（提前定义）
□ 批次效应评估
```

## 偏差识别与控制

### 常见偏差类型
```
| 偏差类型 | 描述 | 控制方法 |
|---------|------|---------|
| 选择偏差 | 样本非随机选取 | 随机抽样/分配 |
| 测量偏差 | 系统性测量误差 | 校准/盲法 |
| 确认偏差 | 选择性解读数据 | 预设分析计划 |
| 发表偏差 | 阴性结果未报告 | 预注册 |
```
