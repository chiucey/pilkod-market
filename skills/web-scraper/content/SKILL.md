# Web Scraper Skill

## 功能概述

网页爬虫技能可以高效地从网页中提取所需信息，支持多种提取模式和格式输出。

## 核心能力

### 1. 单页爬取
- 根据URL和提取提示词从单个网页提取信息
- 支持动态渲染页面（JavaScript渲染内容）
- 自动处理编码和格式问题

### 2. 批量爬取
- 最多支持10个URL并行提取
- 适用于列表页、专题页等场景
- 每个任务可自定义提取需求

### 3. 提取模式
- **自动模式 (auto)**: 自动检测页面类型，智能选择提取方式
- **直接提取 (curl_only)**: 快速HTTP请求，适用于静态页面
- **浏览器渲染 (browser_only)**: 使用浏览器渲染，适用于SPA/CSR页面

## 使用场景

| 场景 | 推荐模式 | 说明 |
|------|---------|------|
| 新闻文章 | curl_only | 静态内容，快速提取 |
| 电商详情 | browser_only | JavaScript渲染，需要等待 |
| 论坛帖子 | auto | 自动适配 |
| 搜索结果 | browser_only | 动态加载内容 |
| 文档页面 | curl_only | 静态文档，最快 |

## 使用示例

### 示例1: 提取新闻文章
```
URL: https://news.example.com/article/123
提示: 提取文章标题、作者、发布时间、正文内容
模式: curl_only
```

### 示例2: 批量爬取产品信息
```
URLs: [商品页1, 商品页2, 商品页3]
提示: 提取商品名称、价格、规格、库存状态
模式: browser_only
```

### 示例3: 提取结构化数据
```
URL: https://example.com/data
提示: 提取表格中的所有数据行，包括列名
模式: auto
```

## 输出格式

提取结果以JSON格式返回，包含：
- `success`: 是否成功
- `content`: 提取的文本内容
- `url`: 来源URL
- `extracted_data`: 结构化数据（如适用）

## 注意事项

1. **robots.txt**: 请尊重网站的爬虫协议
2. **频率限制**: 批量爬取时注意请求频率
3. **登录验证**: 需要登录的页面无法直接爬取
4. **反爬机制**: 部分网站有反爬措施，请谨慎使用
5. **数据合规**: 确保爬取数据的使用符合法律法规

## 技术实现

使用浏览器自动化技术，支持：
- Cookie和Session处理
- 请求头自定义
- 超时设置
- 重试机制
