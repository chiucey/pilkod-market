# Web Scraper 使用指南

## 快速开始

### 基本使用流程

1. **提供目标URL**: 告诉Agent要爬取的网页地址
2. **描述提取需求**: 说明需要从页面中提取哪些信息
3. **等待处理**: Agent将使用网页爬虫技能提取数据
4. **获取结果**: 收到结构化的提取结果

### 提取模式选择

| 模式 | 适用场景 | 速度 |
|------|---------|------|
| auto | 大多数情况 | 中等 |
| curl_only | 静态HTML页面 | 最快 |
| browser_only | JavaScript渲染页面 | 较慢 |

## 常见使用示例

### 示例1: 提取文章内容
```
用户: 请爬取 https://news.example.com/tech/123 这篇文章，提取标题、作者、发布日期和正文内容。

Agent将使用curl_only模式快速提取静态文章内容。
```

### 示例2: 批量爬取商品信息
```
用户: 我需要从以下3个页面提取产品名称、价格和库存状态：
- https://shop.example.com/product/1
- https://shop.example.com/product/2
- https://shop.example.com/product/3

Agent将使用browser_only模式并行爬取所有页面。
```

### 示例3: 提取表格数据
```
用户: 爬取 https://finance.example.com/stocks 页面的股票数据表格，包括股票代码、名称、当前价格、涨跌幅。

Agent将提取表格中的结构化数据并整理成JSON格式返回。
```

### 示例4: 提取图片资源
```
用户: 提取 https://gallery.example.com/photos 页面中的所有图片URL列表。

Agent将分析页面结构，提取所有图片链接。
```

## 输出格式

```json
{
  "success": true,
  "url": "https://example.com/page",
  "extracted_data": {
    "title": "页面标题",
    "content": "提取的内容...",
    "images": ["url1", "url2"],
    "links": ["url1", "url2"]
  },
  "metadata": {
    "extracted_at": "2024-01-01T00:00:00Z",

  }

```

### 失败响应示例
```json

  "success": false,
  "url": "https://example.com/page",
  "error": "Failed to fetch page: 403 Forbidden",
  "suggestion": "该网站可能限制了爬取，请尝试手动访问或使用其他数据源"

```

## 数据保存

Agent可以将爬取结果保存为以下格式：

| 格式 | 文件扩展名 | 说明 |
|------|-----------|------|
| JSON | .json | 结构化数据，便于程序处理 |
| CSV | .csv | 表格数据，便于Excel打开 |
| TXT | .txt | 纯文本，简单通用 |

### 保存示例
```
用户: 将刚才爬取的文章保存为JSON文件到 data/article.json

Agent将调用scraper.js脚本将数据保存为JSON文件。
```

## 最佳实践

### 1. 选择合适的提取模式
- 静态页面使用 `curl_only` 以获得最快速度
- 需要等待JavaScript渲染的页面使用 `browser_only`
- 不确定时使用 `auto` 让系统自动选择

### 2. 提供清晰的提取需求
- ✓ "提取页面中所有新闻标题和发布日期"
- ✗ "随便看看这个页面有什么"

### 3. 注意请求频率
- 单页爬取: 无限制
- 批量爬取(>5页): 建议间隔2-3秒
- 大量爬取(>20页): 建议分批进行

### 4. 处理反爬机制
如果遇到反爬提示：
- 降低请求频率
- 更换User-Agent
- 等待一段时间后重试
- 使用其他数据源

## 限制与注意事项

### 技术限制
1. **登录页面**: 无法爬取需要登录的内容
2. **验证码**: 无法自动绕过验证码
3. **反爬措施**: 部分网站会阻止爬虫访问
4. **动态加载**: 部分内容可能无法完全提取

### 合规要求
1. **robots.txt**: 请遵守目标网站的爬虫协议
2. **使用限制**: 爬取的数据仅供个人学习使用
3. **版权内容**: 尊重原创，不要大量复制发布
4. **隐私数据**: 不要爬取个人隐私信息

## 故障排除

### 常见问题

**Q: 为什么爬取失败？**
A: 可能原因：
- 网站服务器暂时不可用
- 网站有反爬措施
- 网络连接问题
- URL无效或页面已删除

**Q: 为什么只能爬取部分内容？**
A: 可能原因：
- 部分内容由JavaScript动态加载
- 内容需要滚动才能加载
- 页面有分页限制

**Q: 如何爬取需要登录的页面？**
A: 目前不支持登录后的页面爬取，建议：
- 寻找公开可访问的替代页面
- 使用RSS订阅获取内容
- 联系网站管理员获取数据访问权限
