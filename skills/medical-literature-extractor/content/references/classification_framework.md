# 生物制剂安全性管理信息提取框架

## 完整分类体系

### 一、治疗前的风险评估

#### 1.1 启动生物制剂的核心指征
- 疾病严重程度评估标准
- 传统治疗失败/不耐受的判断
- 获益大于风险的评估依据
- 特定生物制剂的适应症要求

#### 1.2 安全性的基线评估要点
- 感染筛查（结核、乙肝、HIV等）
- 恶性肿瘤筛查
- 心功能评估
- 妊娠/哺乳状态评估
- 既往用药史采集
- 疫苗接种状态评估

### 二、治疗方案的制定

#### 2.1 药物选择的安全性考量
- 不同生物制剂的安全性特征对比
- 特定人群的药物选择（如老年患者、肝肾功能不全患者）
- 药物相互作用评估
- 过敏史/输液反应风险评估

#### 2.2 基于风险评估的治疗策略调整
- 低风险患者的方案选择
- 中高风险患者的加强监测策略
- 预防性用药方案
- 剂量调整原则

#### 2.3 生物制剂伴随的预防用药
- 抗结核预防治疗方案
- 抗病毒预防用药
- 糖皮质激素桥接方案
- 免疫调节剂联合方案

#### 2.4 疫苗接种的临床管理
- 接种时机（治疗前/治疗期间）
- 推荐接种的疫苗类型
- 禁忌接种的疫苗
- 接种后的注意事项

---

### 三、治疗期间的监测与管理

#### 3.1 安全性监测要点
- 感染监测指标
- 实验室检查频率
- 影像学监测计划
- 特殊不良反应监测
- 治疗疗效与安全性平衡评估

#### 3.2 不良事件的处理原则
- 轻度不良事件的处理
- 中重度不良事件的管理
- 输液反应的处理流程
- 感染事件的应对策略
- 何时考虑停药/换药

---

### 四、多学科管理模式

#### 4.1 生物制剂安全性管理的多学科团队组成
- 风湿免疫科/相关专科医师
- 临床药师
- 感染科医师
- 护理团队
- 患者及家属教育

#### 4.2 多学科管理模式的实施路径
- 评估与筛选流程
- 治疗决策流程
- 随访与监测流程
- 不良事件处理流程
- 会诊与转诊机制
- 患者教育与随访管理

## 提取指南

### 信息提取原则

1. **原文优先**：尽量保留原文表述，标注页码
2. **结构化**：按上述分类框架归类信息
3. **相关性**：只提取与框架主题直接相关的内容
4. **完整性**：即使某篇文献仅涉及部分框架，也应提取可用的信息

### 置信度评估

| 置信度 | 含义 |
|--------|------|
| 高 | 文献直接讨论该主题，有明确结论 |
| 中 | 文献涉及该主题，但表述较为间接 |
| 低 | 文献仅在部分段落或表格中提及 |

### 输出标注格式

```
[页码:pX] 原文片段 | 置信度:H
```
