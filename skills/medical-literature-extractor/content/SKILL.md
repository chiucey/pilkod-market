# 医学文献信息提取器

## 核心能力

1. **PDF批量解析**：支持批量读取本地PDF文献，提取全文内容
2. **结构化信息提取**：按用户定义的分类框架提取相关内容
3. **表格自动填充**：将提取信息写入Excel表格，支持自定义列结构

## 工作流程

### 第一步：接收用户输入

**必需信息：**
- PDF文献所在文件夹路径
- 已有表格模板文件路径（.xlsx）
- 信息提取框架（分类主题）

**可选信息：**
- 是否需要提取原文引用片段
- 是否需要标注置信度

### 第二步：解析PDF文献

```
对于文件夹中的每个PDF文件：
1. 提取文献名称（文件名或内部标题）
2. 提取全文文本内容
3. 按页码索引，便于后续定位
```

### 第三步：按主题框架提取信息

```
对于用户定义的每个分类主题（如"启动生物制剂的核心指征"）：
1. 在文献内容中搜索相关段落
2. 提取匹配的内容片段
3. 记录来源页码和位置
4. 评估内容与主题的相关性
```

### 第四步：填充表格

```
对于表格中的每一行（文献）：
1. 在对应列中填入提取的信息
2. 如有原文引用，附上引用片段
3. 标记信息来源和置信度
```

## 输出格式

**Excel表格结构：**
- 第一列：文献名称
- 后续列：按用户框架定义的主题列
- 单元格内容：提取的相关段落/要点
- 附加列（可选）：页码、原文引用、置信度

## 质量保障

1. **双重验证**：对每个提取结果进行回溯确认
2. **透明度**：保留原文引用，便于人工复核
3. **相关性评分**：对提取内容进行相关性排序
4. **缺失标注**：未能提取的信息标注为"未提及"

## 限制说明

- 仅支持本地PDF文件读取
- 扫描版PDF（无文字层）需先进行OCR处理
- 表格模板需为.xlsx格式
- 建议单次处理文献数量不超过100篇

## 快速使用示例

```
用户：请从 D:/文献 folder 中提取关于"生物制剂安全性"的信息，填充到 template.xlsx 表格中。

执行流程：
1. 读取 template.xlsx 获取列结构（分类框架）
2. 扫描 D:/文献 folder 下所有PDF
3. 对每篇文献按框架提取相关信息
4. 输出填充后的表格
```
