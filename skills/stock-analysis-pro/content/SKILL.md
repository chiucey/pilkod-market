# stock-analysis-pro：专业级多维度股票分析技能

## 核心定位

融合技术面分析深度与基本面分析广度的专业级股票分析技能，为投资者提供**四大维度**的全面分析服务，输出结构化、可执行的专业报告。

**⚠️ 仅作为投资参考，不构成任何交易建议。**

## 技能特色

| 特色 | 说明 |
|------|------|
| 🎯 **四维覆盖** | 基本面 + 技术面 + 估值 + 风险 |
| 📊 **20+指标** | MA/MACD/RSI/KDJ/BOLL/DMI等 |
| 💹 **估值模型** | PE/PB/PEG/DCF/DDM |
| 🔒 **安全合规** | 数据隔离、禁止交易、仅公开数据 |
| 🧪 **测试完备** | 单元测试覆盖核心功能 |
| 📝 **文档完善** | 4份专业参考手册 |

## 分析框架

### 1. 预处理流程

1. **初始化分析体系**
   - 加载A股/港股/美股财务指标库
   - 配置20+技术指标计算规则
   - 设置估值模型参数
   - 初始化风险评估维度

2. **数据加载**（使用yfinance）
   - 行情数据：OHLCV + 调整后收盘价
   - 财务报表：资产负债表、利润表、现金流量表
   - 公司信息：行业分类、市值、PE、PB等

3. **指令解析**
   - 识别分析标的（股票代码或名称）
   - 确定分析维度（可选：全部/基本面/技术面/估值/风险）
   - 识别对比标的（如有）
   - 确定时间周期

### 2. 基本面分析模块

**财务指标提取：**
- 盈利能力：毛利率、净利率、ROE、ROA、ROIC
- 成长能力：营收增速、净利润增速、EPS增速
- 偿债能力：资产负债率、流动比率、速动比率
- 运营效率：存货周转率、应收账款周转率
- 现金流质量：经营现金流/净利润比率

**同比/环比分析：**
- 单季度vs去年同期
- 单季度vs上季度
- 年度趋势分析（3-5年）

### 3. 技术面分析模块

**趋势指标：**
- MA（5/10/20/60/120/250日均线）
- EMA（指数移动平均）
- MACD（12,26,9）
- DMA、DMI趋势指标

**动量指标：**
- RSI（6/12/24周期）
- KDJ随机指标
- WR威廉指标
- CCI顺势指标
- ROC变动率

**成交量指标：**
- OBV能量潮
- VR容量比率

**波动性指标：**
- BOLL布林带
- ATR平均真实波幅

**支撑压力分析：**
- 黄金分割线（0.382/0.5/0.618/0.786）
- 均线支撑/压力位
- 前期高低点

**技术信号：**
- 买入信号（强烈/中性）
- 持有信号
- 卖出信号（中性/强烈）

### 4. 估值分析模块

**相对估值法：**
- PE（市盈率）
- PB（市净率）
- PEG（市盈率相对盈利增长比率）
- PS（市销率）
- EV/EBITDA

**绝对估值法：**
- DCF（现金流折现模型）
- DDM（股息折现模型）

**估值区间判定：**
- 显著低估 → 轻度低估 → 合理估值 → 轻度高估 → 显著高估

### 5. 风险评估模块

**系统性风险：**
- Beta系数
- 历史波动率（年化）
- VaR（在险价值）

**回撤分析：**
- 最大回撤
- 平均回撤幅度

**流动性风险：**
- 日均成交量
- 成交量变化趋势

**风险等级：R1(低) - R2 - R3 - R4 - R5(高)**

### 6. 对比分析模块

- 多标的财务指标对比
- 估值指标对比
- 技术面强弱对比
- 风险指标对比
- 综合评分
