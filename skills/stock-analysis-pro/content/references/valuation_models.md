# 估值模型参考手册

## 相对估值法

### PE (市盈率)

```
PE = 当前股价 / EPS
```

**行业参考范围**：
| 行业 | PE范围 |
|------|--------|
| 银行 | 4-8倍 |
| 房地产 | 5-12倍 |
| 消费 | 20-40倍 |
| 科技 | 30-60倍 |
| 医药 | 25-50倍 |

### PB (市净率)

```
PB = 当前股价 / 每股净资产
```

适用：金融业、周期性行业、资产型企业

### PEG (市盈率相对盈利增长)

```
PEG = PE / 年化净利润增速 × 100
```

- PEG < 1 → 相对低估
- PEG = 1 → 合理估值
- PEG > 1 → 相对高估

## 绝对估值法

### DCF (现金流折现)

```
企业价值 = Σ [FCFt / (1 + WACC)^t] + TV/(1+WACC)^n
```

**参数**：
- FCF：自由现金流
- WACC：加权平均资本成本
- TV：永续价值
- n：预测期（通常5-10年）

**敏感性**：
| 永续增长率 | 估值影响 |
|-----------|---------|
| 2% | 保守 |
| 3% | 合理 |
| 4% | 乐观 |

### DDM (股息折现)

适用于高股息、稳定分红的企业。

```
内在价值 = D1 / (r - g)
```
