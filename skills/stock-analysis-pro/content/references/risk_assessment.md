# 风险评估参考手册

## 系统性风险

### Beta系数

```
β = Cov(Ri, Rm) / Var(Rm)
```

- β > 1.5：进攻型（高波动）
- β = 1：与市场同步
- β < 0.8：防御型（低波动）

### 历史波动率

```
年化波动率 = 日收益率标准差 × √252
```

| 波动率 | 风险等级 |
|--------|---------|
| < 15% | 低 |
| 15-30% | 中 |
| > 30% | 高 |

## 回撤分析

### 最大回撤

```
最大回撤 = (谷值 - 峰值) / 峰值 × 100%
```

| 最大回撤 | 风险等级 |
|---------|---------|
| < 10% | 低 |
| 10-25% | 中 |
| > 25% | 高 |

## 风险等级

| 等级 | 分数 | 说明 |
|------|------|------|
| R1 | 0-20 | 低风险 |
| R2 | 21-40 | 中低风险 |
| R3 | 41-60 | 中等风险 |
| R4 | 61-80 | 中高风险 |
| R5 | 81-100 | 高风险 |

## 风险预警信号

1. **财务风险**：应收账款异常增长、经营现金流为负
2. **经营风险**：大客户流失、核心人员离职
3. **市场风险**：行业政策变化、竞争加剧
