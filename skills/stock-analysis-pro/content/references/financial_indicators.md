# 财务指标参考手册

## 盈利能力指标

### 毛利率

```
毛利率 = (营业收入 - 营业成本) / 营业收入 × 100%
```

| 水平 | 范围 |
|------|------|
| 优秀 | > 40% |
| 良好 | 20-40% |
| 一般 | < 20% |

### ROE (净资产收益率)

```
ROE = 净利润 / 股东权益 × 100%
```

| 水平 | 范围 |
|------|------|
| 优秀 | > 15% |
| 良好 | 10-15% |
| 一般 | < 10% |

## 成长能力指标

- 营收增速：营收同比增长
- 净利润增速：净利润同比增长
- EPS增速：每股收益同比增长

## 偿债能力指标

### 资产负债率

```
资产负债率 = 总负债 / 总资产 × 100%
```

| 水平 | 范围 |
|------|------|
| 保守 | < 40% |
| 稳健 | 40-60% |
| 激进 | > 60% |

### 流动比率

```
流动比率 = 流动资产 / 流动负债
```

- 优秀：> 2
- 良好：1.5-2
- 一般：< 1.5

## 现金流质量

```
经营现金流/净利润比率 = 经营活动现金流净额 / 净利润
```

- 优秀：> 1
- 良好：0.8-1
- 风险信号：< 0.5
