# 技术指标参考手册

## 趋势指标

### 移动平均线 (MA)

| 周期 | 用途 |
|------|------|
| MA5 | 短期趋势，快速响应 |
| MA10 | 短期趋势 |
| MA20 | 中期趋势 |
| MA60 | 中长期趋势 |
| MA120 | 长期趋势 |
| MA250 | 年线 |

**均线排列**：
- 多头排列：MA5 > MA20 > MA60 → 强势上涨
- 空头排列：MA5 < MA20 < MA60 → 弱势下跌

### MACD

```
DIF = EMA12 - EMA26
DEA = DIF的EMA9
MACD柱 = (DIF - DEA) × 2
```

**信号**：
- DIF > 0 且 DIF > DEA → 金叉（买入）
- DIF < 0 且 DIF < DEA → 死叉（卖出）
- 顶背离：价格创新高，MACD未创新高 → 下跌预警
- 底背离：价格创新低，MACD未创新低 → 上涨预警

## 动量指标

### RSI

```
RS = N日上涨幅度均值 / N日下跌幅度均值
RSI = 100 - 100/(1+RS)
```

**信号区间**：
- RSI > 80：超买（警惕回调）
- RSI < 20：超卖（关注反弹）
- RSI = 50：多空平衡

### KDJ

**信号**：
- K、D < 20 → 超卖区域
- K、D > 80 → 超买区域
- K从下向上穿越D → 金叉买入
- K从上向下穿越D → 死叉卖出

## 波动性指标

### BOLL布林带

```
中轨 = MA20
上轨 = 中轨 + 2 × 标准差
下轨 = 中轨 - 2 × 标准差
```

**应用**：
- 股价触及上轨 → 警惕回调
- 股价触及下轨 → 关注反弹
- 布林带收口 → 突破在即
- 布林带开口 → 趋势加速

### ATR平均真实波幅

衡量价格波动剧烈程度，用于设置止损。

## 成交量指标

### OBV能量潮

```
上涨日：OBV = 前日OBV + 今日成交量
下跌日：OBV = 前日OBV - 今日成交量
```

OBV创新高 → 资金流入确认
