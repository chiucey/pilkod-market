# PPT 创作助手

## Overview

本技能用于根据用户需求生成 PowerPoint（.pptx）演示文稿。支持以下场景：

1. **按主题生成**：用户提供一个主题/话题，自动规划内容大纲并生成完整 PPT。
2. **按模板生成**：用户提供已有的 .pptx 模板文件，基于该模板的版式和风格填充内容。
3. **按用户文件生成**：用户提供文档（如 .txt、.md、.pdf、.docx 等），将文件内容提炼并转化为 PPT。

## Workflow

### 1. 确认需求

1. 确认用户的输入方式：
   - 仅提供 **主题关键词/描述**
   - 提供 **PPT 模板文件**（.pptx）
   - 提供 **内容文件**（.txt / .md / .docx / .pdf 等）
   - 以上组合（如：模板 + 主题，模板 + 内容文件）
2. 确认目标受众、用途、期望页数等（如用户未说明，使用合理默认值）。
3. 确认语言（默认与用户对话语言一致）。

### 2. 内容规划

1. 根据用户输入，生成 PPT 大纲，包含：
   - 封面页（标题 + 副标题）
   - 目录页（可选）
   - 各章节内容页（标题 + 要点）
   - 总结/结尾页
2. 将大纲展示给用户确认，或在用户要求直接生成时跳过确认。

### 3. 生成 PPT 文件

1. 使用 `python-pptx` 库编写 Python 脚本生成 .pptx 文件。
2. 如果用户提供了模板文件：
   - 使用 `Presentation(template_path)` 加载模板。
   - 获取模板中已有的幻灯片版式（`slide_layouts`），优先使用模板版式。
   - 保持模板的配色方案、字体和母版设计。
3. 如果没有模板：
   - 使用 `Presentation()` 创建空白演示文稿。
   - 设置合理的默认幻灯片尺寸（16:9 宽屏，宽 13333400 EMU × 高 7500938 EMU）。
   - 使用简洁专业的配色。
4. 逐页添加内容。
5. 保存为 .pptx 文件。

### 4. 交付与迭代

1. 告知用户文件输出路径。
2. 如用户有修改意见，按需调整并重新生成。

## 生成脚本规范

### 依赖

```python
from pptx import Presentation
from pptx.util import Inches, Pt, Emu
from pptx.dml.color import RGBColor
from pptx.enum.text import PP_ALIGN, MSO_ANCHOR
from pptx.enum.shapes import MSO_SHAPE
```

若环境中未安装 `python-pptx`，先执行：

```bash
pip install python-pptx
```

### 常用版式索引（默认模板）

| 索引 | 版式名称              | 用途           |
|------|-----------------------|----------------|
| 0    | Title Slide           | 封面页         |
| 1    | Title and Content     | 内容页         |
| 2    | Section Header        | 章节分隔页     |
| 5    | Blank                 | 空白页（自由排版）|
| 6    | Title Only            | 仅标题页       |

> 注意：使用用户模板时，版式索引可能不同，应先遍历 `prs.slide_layouts` 检查可用版式。

### 幻灯片尺寸

- **16:9 宽屏（推荐）**：`prs.slide_width = Emu(13333400)`，`prs.slide_height = Emu(7500938)`
- **4:3 标准**：`prs.slide_width = Emu(9144000)`，`prs.slide_height = Emu(6858000)`

### 文本格式建议

| 元素       | 字号      | 对齐     | 加粗  |
|------------|-----------|----------|-------|
| 封面标题   | 36-44 pt  | 居中     | 是    |
| 封面副标题 | 18-24 pt  | 居中     | 否    |
| 页面标题   | 28-32 pt  | 左对齐   | 是    |
| 正文内容   | 16-20 pt  | 左对齐   | 否    |
| 要点符号   | 16-18 pt  | 左对齐   | 否    |
| 脚注/页码  | 10-12 pt  | 右对齐   | 否    |

### 默认配色方案

| 用途         | 颜色代码    |
|--------------|-------------|
| 主色（标题） | `#2B579A`   |
| 强调色       | `#217346`   |
| 正文文字     | `#333333`   |
| 浅色背景     | `#F5F5F5`   |
| 白色背景     | `#FFFFFF`   |

## 使用模板时的注意事项

1. **先检查版式**：遍历 `prs.slide_layouts`，通过 `layout.name` 识别各版式的用途。
2. **保留占位符**：使用模板版式中已有的占位符（`placeholders`）填充文本，而非自行添加文本框。
3. **不要修改母版**：避免修改 `slide_masters`，以保持模板原有风格。
4. **字体兼容**：如果模板使用了特殊字体，生成时也尽量使用相同字体名称。

## 处理用户文件的要点

1. **文本文件 (.txt / .md)**：直接读取，按段落/标题分割为幻灯片内容。
2. **Word 文件 (.docx)**：使用 `python-docx` 读取，按标题层级划分章节。
3. **PDF 文件 (.pdf)**：使用 `PyPDF2` 或 `pdfplumber` 提取文本。
4. 提炼要点，每页幻灯片控制在 **3-6 个要点**，避免文字过多。
5. 保持原始内容的逻辑结构和层次。

## 常见错误与注意事项

- **不要**在一页幻灯片上放置过多文字（每页建议不超过 6 个要点，每个要点不超过 2 行）。
- **不要**忘记设置幻灯片尺寸 — 默认可能是 4:3，需根据需要切换为 16:9。
- **不要**硬编码版式索引 — 使用模板时，应通过名称或遍历来选择版式。
- **不要**忽略文本溢出 — 长文本应做截断或分页处理。
- **务必**确保文件保存路径正确，并使用 `.pptx` 扩展名。
- **务必**在生成脚本中处理异常（如模板文件不存在、依赖未安装等）。

## 输出文件约定

- 默认文件名格式：`output.pptx` 或 `{主题名}.pptx`
- 输出到当前工作目录，除非用户指定了其他路径。
- 文件格式：仅支持 `.pptx`（Office Open XML）。
