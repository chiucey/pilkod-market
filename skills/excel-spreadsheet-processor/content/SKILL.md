# Excel表格处理专家技能

## 技能概述

本技能提供专业的Excel电子表格处理能力，包括创建新文件、读取分析数据、编辑修改现有文件、公式计算以及数据可视化。

## 核心能力

### 文件创建与编辑

- 创建新的Excel工作簿（.xlsx、.xlsm格式）
- 读取和分析现有Excel文件数据
- 在保留公式的前提下修改现有文件
- 支持CSV和TSV格式文件的处理

### 公式与计算

- 使用Excel公式替代硬编码值，确保表格动态可更新
- 支持各类数学、统计、财务函数
- 公式错误检测与修复（#REF!、#DIV/0!、#VALUE!、#N/A、#NAME?等）
- 使用recalc.py脚本重新计算所有公式

### 数据分析

- 使用pandas进行数据处理和分析
- 数据统计和描述性分析
- 生成数据可视化图表

### 格式设置

- 单元格格式设置（字体、颜色、背景）
- 数字格式（货币、百分比、日期等）
- 对齐方式和边框设置
- 列宽和行高调整

## 财务模型规范

### 颜色编码标准

- **蓝色文字（RGB: 0,0,255）**：硬编码输入值和场景参数
- **黑色文字（RGB: 0,0,0）**：所有公式和计算
- **绿色文字（RGB: 0,128,0）**：同一工作簿内其他工作表的引用链接
- **红色文字（RGB: 255,0,0）**：外部文件链接
- **黄色背景（RGB: 255,255,0）**：需要关注的关键假设或需要更新的单元格

### 数字格式规范

- **年份**：格式化为文本字符串（如"2024"而非"2,024"）
- **货币**：使用$#,##0格式，在表头中注明单位（如"收入($mm)"）
- **零值**：使用数字格式将所有零显示为"-"，包括百分比（如"$#,##0;($#,##0);-"）
- **百分比**：默认使用0.0%格式（一位小数）
- **倍数**：估值倍数（EV/EBITDA、P/E）格式化为0.0x
- **负数**：使用括号表示（如(123)而非-123）

### 公式构建规则

#### 假设值放置

- 将所有假设（增长率、利润率、倍数等）放在单独的假设单元格中
- 公式中使用单元格引用替代硬编码值
- 示例：使用=B5*(1+$B$6)而非=B5*1.05

#### 公式错误预防

- 验证所有单元格引用正确性
- 检查范围内的偏差错误
- 确保所有预测期间公式一致
- 使用边界值（零值、负数）测试
- 验证无意外循环引用

## 工具使用指南

### 库选择

- **pandas**：适用于数据分析、批量操作和简单数据导出
- **openpyxl**：适用于复杂格式、公式和Excel特定功能

### 工作流程

1. **选择工具**：数据分析用pandas，公式格式用openpyxl
2. **创建或加载**：创建新工作簿或加载现有文件
3. **修改**：添加或编辑数据、公式和格式
4. **保存**：写入文件
5. **重新计算公式（使用公式时必需）**：使用recalc.py脚本
6. **验证并修复错误**：检查并修复公式错误

### 重新计算公式

使用提供的recalc.py脚本重新计算公式：

```bash
python recalc.py <excel文件> [超时秒数]
```

脚本功能：
- 首次运行时自动配置LibreOffice
- 重新计算所有工作表中的公式
- 扫描所有单元格的Excel错误（#REF!、#DIV/0!等）
- 返回包含错误位置和数量的详细JSON结果
- 支持Linux和macOS系统

## 代码风格指南

### Python代码要求

- 编写简洁、最小化的Python代码
- 避免冗余的变量名和不必要的操作
- 避免不必要的print语句

### Excel文件要求

- 为复杂公式或重要假设添加单元格注释
- 为硬编码值记录数据来源
- 为关键计算和模型部分添加说明

## 常见错误处理

### 公式错误类型

- **#REF!**：无效的单元格引用
- **#DIV/0!**：除以零
- **#VALUE!**：公式中数据类型错误
- **#NAME?**：无法识别的公式名称

### 验证清单

- [ ] 测试2-3个样本引用，确保获取正确值
- [ ] 确认Excel列映射正确（如第64列=BL）
- [ ] 注意Excel行从1开始（DataFrame第5行=Excel第6行）
- [ ] 检查空值处理（使用pd.notna()）
- [ ] 检查除数是否为零
- [ ] 验证所有单元格引用指向目标单元格
