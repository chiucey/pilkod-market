# 教育PPT模板指南

## 一、模板分类体系

### A. 概念讲解型模板

**适用场景**：新概念引入、定义阐述、原理说明

**结构设计**：
```
┌─────────────────────────────────────┐
│  【章节导入】                        │
│  问题情境 → 引发思考                  │
├─────────────────────────────────────┤
│  【概念定义】                        │
│  核心定义 → 关键词标注                │
├─────────────────────────────────────┤
│  【可视化呈现】                      │
│  图示/动画 → 直观理解                 │
├─────────────────────────────────────┤
│  【应用示例】                        │
│  例题 → 分析 → 解答                  │
├─────────────────────────────────────┤
│  【思维留白】                        │
│  🔲 这个概念还能应用在哪些场景？        │
└─────────────────────────────────────┘
```

**留白标注规范**：
- 概念引入页：留出"学生联想"空间
- 定义讲解页：关键定义区域不填满
- 应用示例页：解题步骤可逐步展示

### B. 公式推导型模板

**适用场景**：数学推导、物理公式、化学方程式

**核心设计原则**：
1. 分步展示，不一次性呈现完整推导
2. 每个关键变换点设置"思考框"
3. 推导完成后留出"板书确认"区域

**推导页面结构**：
```
┌──────────────────────────────────────────┐
│  推导目标：从A推导到B                      │
├──────────────────────────────────────────┤
│                                          │
│  已知条件区域                             │
│  ┌────────────────────────────────┐      │
│  │  条件1：__________             │      │
│  │  条件2：__________             │      │
│  └────────────────────────────────┘      │
│                                          │
│  【思维引导区】                           │
│  🔲 第一步应该做什么？                     │
│     提示：观察已知条件中的_____            │
│                                          │
│  【推导过程区】（逐步展示）                │
│     Step 1: _____ → _____                │
│     Step 2: _____ → _____                │
│     🔲 Step 3: _____ → _____ ？          │
│                                          │
│  ══════════════════════════════════      │
│  【板书留白】此处记录关键步骤               │
│                                          │
└──────────────────────────────────────────┘
```

## 四、视觉设计规范

### 4.1 配色方案

| 类型 | 主色 | 辅助色 | 强调色 | 适用学科 |
|------|------|--------|--------|----------|
| 数学 | #2C5F8A | #E8F4FD | #FF6B6B | 数学 |
| 物理 | #3A7D44 | #E8F5E9 | #FFB74D | 物理 |
| 化学 | #7B1FA2 | #F3E5F5 | #4CAF50 | 化学 |
| 生物 | #00897B | #E0F2F1 | #FF7043 | 生物 |

### 4.2 留白符号系统

| 符号 | 含义 | 使用场景 |
|------|------|----------|
| 🔲 | 思考/讨论留白 | 需要学生独立思考处 |
| 💡 | 关键点/提示 | 需要重点讲解处 |
| ⏸️ | 暂停/互动 | 适合课堂互动处 |
| ⚠️ | 易错警示 | 常见错误提醒 |
| ══ | 板书区域 | 预留书写空间 |

### 4.3 排版黄金法则

1. **7±2法则**：每页关键信息不超过7个要点
2. **三等分原则**：重要内容放在视觉黄金分割点
3. **渐进披露**：复杂内容分步展示，每步聚焦一个点
4. **对比呈现**：新旧知识用视觉对比突出差异

## 五、制作检查清单

### 制作前
- [ ] 明确教学目标
- [ ] 确定目标受众（高中/大学/过渡年级）
- [ ] 梳理知识逻辑链
- [ ] 设计思维引导节点

### 制作中
- [ ] 每页有且只有一个核心
- [ ] 关键推导设置分步留白
- [ ] 预留足够板书空间
- [ ] 标注互动/讨论节点

### 制作后
- [ ] 通读检查逻辑连贯性
- [ ] 验证大中衔接平滑度
- [ ] 确认留白位置合理
- [ ] 预览讲授节奏
