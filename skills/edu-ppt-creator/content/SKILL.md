# 教育PPT制作专家

## 核心能力

### 1. 模板智能选择
根据课件内容特征自动匹配最佳模板：

| 内容类型 | 推荐模板 | 核心特征 |
|---------|---------|---------|
| 概念讲解 | 渐进式结构 | 问题引入→定义→图示→应用 |
| 公式推导 | 思维引导型 | 分步展示→推导留白→结论 |
| 问题探讨 | 对话式结构 | 提问→思考→讨论→总结 |
| 章节复习 | 框架图型 | 知识网络→重点标注→练习 |

### 2. 大中衔接设计

**高中→大学过渡维度：**
- 直观→抽象：从具象图形到符号化表达
- 记忆→理解：从公式背诵到原理推导
- 套用→创新：从题型解法到问题建模
- 单一→系统：从孤立知识点到学科体系

**衔接坡度设计原则：**
```
高中水平 → 铺垫过渡 → 大学内容
   ↓          ↓          ↓
  熟悉概念 → 新旧联系 → 深度提升
```

### 3. 数学思维引导框架

**问题驱动三步法：**
1. **问题锚定**：用具体问题引入抽象概念
2. **思维脚手架**：分步引导，保留学生思考空间
3. **自主发现**：关键步骤留白，引导学生自己完成

**公式推导留白策略：**
- 关键变形步骤设置"思考框"
- 易错点标注"为什么这样？"
- 多种解法对比展示

### 4. PPT留白设计

**视觉留白原则：**
- 每页核心信息≤3个要点
- 关键推导前设置"空白框"供板书
- 动画分步展示，保留讲解节奏

**思维引导标记：**
- 🔲 待思考：给学生独立思考时间
- 💡 关键点：需要重点讲解
- ⏸️ 暂停：此处适合课堂互动

## 制作流程

### 步骤1：内容分析
```
输入：课程主题 + 目标受众 + 教学目标
↓
识别：知识类型（概念/原理/方法/应用）
↓
确定：内容深度（高中/过渡/大学）
```

### 步骤2：模板匹配
```
知识类型 + 受众特征 → 推荐模板
↓
模板定制：调整章节结构、示例难度
↓
留白设计：标注板书位置、互动节点
```

### 步骤3：视觉设计
```
配色方案：
- 理科类：蓝绿色系（冷静、专业）
- 过渡内容：暖色调（温和、引导）

排版原则：
- 公式居中放大
- 文字简洁有力
- 图文比例协调
```

### 步骤4：输出交付
```
生成：完整PPT结构 + 讲稿提示
标注：留白位置、互动建议、时间分配
```

## 模板示例结构

### 公式推导型模板
```markdown
【页面标题】核心公式名称

【左侧】公式展示区
   完整公式或分步推导

【右侧】思维引导区
   🔲 第一步变形为什么这样做？
   💡 关键：注意符号变化
   🔲 下一步如何继续？

【底部】留白框
   ═══════════════════════
   [此处板书补充]
```

### 问题探讨型模板
```markdown
【页面标题】核心问题

【问题区】
   🎯 问题描述（清晰呈现）

【思考区】
   🔲 你的初步想法是？
   💡 提示：联系已有知识...

【讨论区】（预留空间）


```

## 质量标准

1. **教育性**：知识传递清晰，逻辑递进合理
2. **引导性**：思维留白恰当，引导自然流畅
3. **简洁性**：每页信息精炼，重点突出
4. **衔接性**：大中过渡平滑，坡度适中
5. **实用性**：适合实际讲授，可操作性强
