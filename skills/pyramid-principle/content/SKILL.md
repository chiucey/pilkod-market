# Pyramid Principle

This skill provides a structured approach to thinking and communication based on Barbara Minto's Pyramid Principle. It helps organize ideas logically, making them easier for audiences to comprehend and remember.

## Core Concepts

The Pyramid Principle is built on the premise that the mind automatically sorts information into distinctive pyramidal groupings to comprehend it. By presenting information in a top-down structure, you align with the reader's natural cognitive processing, saving them mental energy.

### The Top-Down Structure

Always begin with the main idea or conclusion. This is the "Bottom Line Up Front" (BLUF) approach. The main idea should invoke a question or curiosity in the reader's mind.

Beneath the main idea, present key supporting arguments or findings. Each of these key ideas must summarize the detailed evidence below it.

### The Bottom-Up Thinking Process

While communication flows top-down, the thinking process to build the pyramid must occur bottom-up. This involves three rules:

1. Ideas in each grouping must always be the same kind of idea.
2. Ideas at any level must always be summaries of the ideas grouped below them.
3. Ideas in each grouping must always be logically ordered.

### Logical Ordering

When grouping supporting ideas, they must follow a logical sequence. The five options for ordering ideas are:

- **Chronologically**: Present ideas in the order they occurred.
- **Structurally**: Present ideas in their natural groups (e.g., geographic regions, company divisions).
- **Comparatively**: Order by importance (most important to least important).
- **Deductive**: Each point builds upon the previous one to form an argument.
- **Inductive**: Independent points that all support the same conclusion.

Deductive and inductive logic are the primary reasoning types in business communication. Inductive logic is generally safer, as disproving one supporting point does not invalidate the entire argument, unlike deductive logic.

## The SCQA Framework

The SCQA framework is essential for setting the context and defining the problem before presenting the main idea. It ensures the writer and reader are aligned before diving into the arguments.

- **Situation**: Establish the context with facts the audience already agrees with.
- **Complication**: Introduce the problem or dilemma that triggers the question.
- **Question**: State the core question that needs to be answered.
- **Answer**: Provide the main idea or solution (the top of the pyramid).

Depending on the desired tone, the order of these elements can be adjusted:

- **Direct**: Solution, Situation, Complication
- **Indirect**: Situation, Complication, Solution

## Usage Guidelines

When tasked with writing a document, presentation, or email using the Pyramid Principle, follow these steps:

1. **Define the SCQA**: Clarify the situation, complication, and question to formulate the main answer.
2. **Build the Pyramid Bottom-Up**: Gather all facts and data. Group similar items and summarize them into key ideas.
3. **Structure Top-Down**: Place the main answer at the top, followed by the key ideas, and then the supporting data.
4. **Review Logic**: Ensure each grouping follows one of the logical ordering methods (chronological, structural, comparative, deductive, or inductive) and adheres to the MECE principle (Mutually Exclusive, Collectively Exhaustive).
