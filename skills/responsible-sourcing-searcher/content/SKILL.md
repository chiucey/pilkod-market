# 负责任采购搜索技能

## 概述

本技能用于搜索全球主要的负责任采购和供应链尽责管理相关信息来源，包括：

- **OECD** (经济合作与发展组织) - 负责任商业行为和供应链尽责管理指南
- **LBMA** (伦敦金银市场协会) - 贵金属负责任采购标准
- **LME** (伦敦金属交易所) - 可持续发展和负责任采购要求
- **中国五矿商会** - 中国矿产品负责任采购指南
- **CAHRA** (受冲突影响和高风险地区) - 相关定义、评估和风险管理信息

## 使用方法

用户可以使用以下方式触发本技能：

- "搜索负责任采购相关信息"
- "查找OECD供应链尽责管理指南"
- "搜索LBMA负责任采购标准"
- "查询中国五矿商会负责任采购"
- "搜索CAHRA受冲突影响和高风险地区"
- "查找LME负责任采购要求"

## 搜索策略

本技能采用以下搜索策略：

1. **针对性网站搜索** - 直接访问相关组织的官方网站和资源库
2. **全网综合搜索** - 在整个网络上搜索相关关键词
3. **专业数据库检索** - 搜索专业报告、指南和白皮书
4. **最新资讯追踪** - 搜索最新的行业新闻和政策更新
