# 投资策略大师课

## 概述

本技能源自一位拥有20年投资经验的专业投资人的实战总结，涵盖从投资认知建立到具体交易操作、资产配置、风控体系的完整投资方法论。核心思想是：**在风险可控的前提下，通过时间放大复利效应，实现财富的稳步增值**。

---

## 第一部分：投资认知体系

### 1.1 资产与负债的本质定义

**资产**：能产生收益的产品。例如全款购房出租产生租金收益，这是资产。

**负债**：不能产生正现金流的产品。例如贷款购房，租金无法覆盖月供，这是负债而非资产。

**关键洞察**：投资的本质是识别真正能产生收益的资产，并完成"买入-持有-收益"的完整闭环。

### 1.2 投资的首要原则：保值优于增值

> 不在推土机面前捡钢镚，不在山洪面前捡矿石。

投资的首要前提是**保值**，其次才是增值。必须确保风险在自身能力承受范围内，避免赌徒心态，这是"富一世"的正确途径。

### 1.3 周期的力量

投资不是一成不变的，而是有周期的。任何行业都有其时代和周期，如同潮水涨跌，会随时间推移而发生变动和调整。

**核心思维**：
- 所有推演和预演都是阶段性的，在某个时间点内适用，超过这个时间点就不再合适
- 同一只股票，入手的节点和价格不同，收益和效果会决然不同
- 不能刻舟求剑，一切事物都是动态变化发展的

### 1.4 实践优于宏大叙事

- 想而不干是空想，干而不想是蛮干
- 经历是最好的老师，只有自身的经历感悟才真正属于自己
- "好言难劝该死鬼"，"人是叫不醒的，只能痛醒"
- 宏大叙事是奶头乐，是投资最大的毒药，应远离沉迷宏大叙事的群体

### 1.5 多维度认知

看一件事不能只看一面，魔方不止一面，它是多维的。你能看到哪一面，取决于你站在哪个位置。

**核心公式**：
```
钱（货币）= 价值的体现（表现形式）
价值 = 认知的反馈
```

### 1.6 顺应大势

- 2021年之前，人民币处于资产扩表期，所以人民币资产一飞冲天
- 人民币资产转向缩表期后，板块轮动让美元资产再度强势
- 2018年之前，国内的房产投资和VC能成，是因为大势在房产和风险投资上
- 2018年后，美元资产价格不断走高，如今人工智能崛起，科技股引领浪潮

**投资要学会看大势、用大势、顺应大势，不要逆大势。**

### 1.7 中长线投资原则

- 选对产品后，坚持中长线为主的投资，才能吃到收益的主要涨幅
- 短线只适合做波段套利，更像投机行为
- 学习他人投资成功案例时，不要看别人怎么说，要看他怎么做。只有动作才不会骗人

### 1.8 反人性思维

投资是反人性的。最常见的原则：**买在无人问津处，卖在人声鼎沸时。** 但知易行难，因为人性的恐惧和贪婪。

### 1.9 用对人 + 勘透本质

- 人的精力和专长有限，要用有能力的人帮你赚钱
- 世上最简单也最难的投资，就是投资"人"
- 学会看人也学会看事，尽可能让自己少受信息茧房的困扰，具备透过现象看本质的能力

### 1.10 耐心 + 知错就改

- 时间是个好东西，会验证过往中所有的对与否
- 把一切交给时间和市场验证，根据过程中出现的情况做校正和调整
- 只要大趋势和基本面没有发生变化，就少操作

## 第二部分：交易操作系统

### 2.1 赚确定性强的钱

**确定性强**的例子：
- 城镇化快速推进时利好楼市
- 人工智能利好英伟达
- 美元降息和川普上台利好大饼（比特币）

**操作原则**：
- 只在确定性强的波段里加杠杆，放大收益
- 震荡时及时去杠杆，兼做波段套利
- 做好风险管控，波动太大则及时止盈，不要追高

### 2.2 选股策略：要么第一，要么唯一

股票大部分很普通，少数是精粹。选股策略：**"要么第一，要么唯一，最好二者兼得"**

**"第一"的含义**：规模，说明是行业龙头，市场占有率高

**"唯一"的含义**：技术/创新，说明有核心竞争力，不容易被复制和替代

- 钻石和木炭的成分是一样的，最后的价格是不一样的（稀缺性）
- "第一"是规模，能把这种稀缺性最大程度利益化、货币化

**核心标准**：被市场验证过的、有规模有护城河的、持续成长能力的龙头股。

### 2.3 买入策略：分批建仓，逐步加仓

**核心理念**：先小幅建仓，观察后觉得可以，再择机加仓。遇到基本面没发生恶化但大跌的，果断加仓，越跌越买。

**行军打仗比喻**：
- 先派斥候去刺探情报（观察市场）
- 再派先锋开路（小幅建仓）
- 大军随后跟上（资金主力进入交易）

**关键原则**：只有在市场走势确认我的观点后，才进入交易，然后迅速进入。如果我的判断和市场走势相冲突，那就是我错了，迅速调整，该止损就及时止损。**因为市场永远不会错。**

### 2.4 抄底四原则

1. **价格档差要拉开**：才能有效拉低成本。不要几块钱就设置加仓，没有意义。
2. **不要轻易梭哈**：要逢跌分批买入，不怕踏空，就怕踩坑。
3. **不要过早满仓**：永远留一些仓位，方便市场出机会时可以加仓。一般建议7-7.5成仓位，极限不超过8.5成。
4. **不要在单一方向上仓位太重**：尽量多元化，不单一持有某个股和房产。

### 2.5 定投策略

**定投是大多数普通人相对有效的方法**，因为没法精准把握市场走势和机会，容易高位站岗和错失良机。

**定投三要点**：
1. **估值太高的，尽量不投或少投**。例如当下的纳指和标普500，不知道什么时候会暴跌，只能选择逢大/暴跌买一点。
2. **估值很低或较低的，可以多投**。主要看增速、营收+利润等基本面，和PE会不会有太大偏离度。
3. **将定投和价格档差相结合**：跌到多少就买点，再跌到多少再买点，要有自己心里的预期值。

### 2.6 控成本、撑空间

观察走势和波段，只要股票走势正确、市场走势正确，就不要急于获利了结。

**操作示例**：
- 大饼和英伟达在主升浪中，尽量不出
- 即便要出，也不一次性卖出，而是只出20%（拆成多个5%）

**核心优势**：
- 可以压低成本，把空间撑大
- 有利于自己拿得住、拿得久
- 让自己始终处于"进可攻退可守"的境地
- 不容易被情绪所左右，出机会时敢出手捞，下跌时不慌张

### 2.7 止盈与止损

**达到预期的交易结束后**：看震荡区和博弈区在哪个位置，反复震荡的区间如果后续没有确定性利好，一般会选择结束。

**止损重要，止盈更重要**：很多人在浮盈面前会失控，想赚更多，不懂适可而止，最终浮盈变浮亏。**凡事不能太贪心。**

**铁律**：
- 理性＞赌性的人，大多数可以"富一世"
- 赌性＞理性的人，大多数"富一时"

### 2.8 耐心原则

- 市场不缺机会，缺的是耐心，还有一双能看懂机会的慧眼
- 咱是去做猎人的，要做好准备（弹药），耐住性子，不是去做猎物的
- 真正让你优于常人的，不是频繁出手争取小机会，而是耐心、慎重地对待重大机会

### 2.9 信息源的重要性

从不用里面的信息来做外面的投资，这样往往会因为信息茧房而造成亏损。

## 第三部分：财务分析方法

### 3.1 财报六要素分析法

**核心原则**：财报中绝大多数信息都是"噪音"，要学会屏蔽，化繁为简，直指本质。

真正决定一家公司长期价值和内在风险的六项关键要素：

#### 3.1.1 负债分析

**关注点**：总负债水平、负债结构（短期/长期）、有息负债多少

**关键洞察**：
- 高负债（尤其是有息负债）是公司的"定时炸弹"
- 在经济下行或利率上涨时，高额利息会侵蚀利润，甚至导致资金链断裂
- 好公司通常低负债甚至无负债，或负债属于"良性"
- **低杠杆意味着更大的生存弹性**

**案例**：苹果发行债券用于回购股票，因为利率低于它的股本回报率。

#### 3.1.2 净现金分析

**公式**：净现金 = 现金及等价物 + 短期投资 - 有息负债

**重要性**：
- 一家净现金为正的公司，意味着它在没有任何收入的情况下也能存活很久
- 净现金为正的公司可以安然度过经济危机，抗风险能力强
- 大量净现金意味着公司有能力进行并购、回购股票、提高分红

**典型优等生**：英伟达、苹果、微软都坐拥巨额净现金。

**警示信号**：前些年房企账面有钱却背负高利息债务，这种本质是财务魔术。

#### 3.1.3 现金流分析

**核心概念**：经营活动现金流 = 主营业务中实际收到和付出的现金净额

**为什么重要**：
- 利润可以通过会计手段（如赊销、折旧）调节，但现金流很难造假
- 一家公司可以账面利润很高，但如果现金流持续为负，说明它赚的是"假钱"
- 持续经营活动现金流入是企业能够存活和发展的根本

**警示**：大A里许多企业账面利润丰厚，却依赖应收账款"注水"，实则现金枯竭。

#### 3.1.4 开销合理性分析

**关注点**：营业费用（销售、管理、研发费用）占毛利润或收入的比例是否合理、稳定

**关键洞察**：
- 高昂销售费用可能意味着产品缺乏竞争力，需要靠营销驱动
- 持续高额研发投入可能构成技术护城河（如苹果、英伟达）
- 胡乱花钱、费用率不断攀升的公司，说明管理层不珍惜股东的钱

**警示**：有些公司会把本应计入当期费用的开支资本化，虚增当期利润。

#### 3.1.5 真实利润分析

**核心概念**：扣除非经常性损益后，来自主营业务的、可持续的利润

**关键洞察**：
- 剔除一次性收益或损失，才能看清公司主业到底赚不赚钱
- 真实利润是企业的"素颜照"，就像评价人不应看精修图而应看素颜照
- 前些年大A经常能看到一些公司靠卖房实现利润，这种不可持续

**验证方法**：真实利润要和现金流结合看，如果利润和现金流长期背离就需要深究原因。

#### 3.1.6 扣除商誉的净资产

**核心概念**：商誉是并购时产生的溢价，是账面上最"虚"的资产

**关键公式**：实际净资产 = 净资产（股东权益）- 商誉

**重要性**：
- 商誉本身不能单独变现，一旦被收购公司业绩不达标，商誉就可能大幅减值
- 计算ROE时使用"扣除商誉的净资产"，更能反映公司利用实际投入资本创造回报的水平

**警示**：大A里许多公司收购时夸大协同效应，最终计提减值拖累利润。

### 3.2 三表综合分析法

| 报表 | 核心问题 | 关键指标 | 警示信号 |
|------|---------|---------|---------|
| 利润表 | 公司是否赚钱 | 营收增长、净利润 | 连续亏损三年还看不到希望 |
| 资产负债表 | 公司是否健康 | 现金 vs 负债 | 现金低于刚性债务 |
| 现金流量表 | 钱是真是假 | 经营现金流 | 持续为负，靠借钱度日 |

### 3.3 行业前景分析法

**行业前景三要素**：
1. **市场空间**：天花板越高越有成长空间
2. **政策利好和风向**：踩中风口容易起飞
3. **竞争优势**：是第一还是唯一

**案例对比**：
- 英伟达：主营业务踏上人工智能赛道，股价飙升10倍+
- 万科：主营业务房地产处于夕阳产业，"三好生"一样陷入资金困境

## 第四部分：估值与选股方法

### 4.1 市盈率（PE）分析

**基础理解**：如果公司每年的利润不变，投资者投资的钱多少年能回本。

**计算示例**：公司市值1000亿，每年赚50亿，PE = 20。

**核心原则**：
- PE越低，理论上回本时间越快，股票越便宜
- PE越高，某种程度上代表市场对它的未来更看好

**PE类型**：
- **静态PE**：用过去一整年的净利润计算
- **滚动市盈率（TTM）**：用最近四个季度的净利润计算
- **动态PE**：用预测的未来净利润计算

**使用建议**：
- 传统行业一般看TTM，数据相对稳定
- 科技等高增长行业一般看动态PE，但风险是预测可能会出错
- 不同行业的PE没有可比性

### 4.2 夏普比率

**公式**：夏普比率 = （投资回报 - 无风险利率）÷ 波动率

**应用**：
- 大于1算优等生，大于2就是万里挑一的学神
- 两个基金对比：年化25%、波动20%（夏普1.25）vs 年化15%、波动7.5%（夏普2）
- 后者每承担1份风险能赚2元，通常优于前者每承担1份风险只赚1.25元

### 4.3 选股策略总结

**核心标准**：兼具"第一和唯一"

**筛选条件**：
- 财报数据连续几年稳定向好
- 行业地位高或有核心竞争力
- 管理层人品靠谱
- 市盈率在合理区间

**不碰原则**：
- 不碰不懂的行业和企业，不管它涨得如何凶猛
- 不买估值离谱的公司
- 不在市场情绪极端时做重大决策

## 第五部分：仓位与资金管理

### 5.1 仓位管理核心原则

**最佳仓位**：保持7-7.5成仓位，极限不超过8.5成

**资金分配**：3成做T，7成底仓

**核心理念**：永远不满仓，给自己留机会

### 5.2 金字塔加仓法

**适用场景**：优质个股下跌过程中逐步买入

**操作示例**（假设从120元开始下跌）：
- 120元：观望
- 110元：买入30股
- 100元：买入30股
- 90元：买入40股
- 80元：买入60股
- 70元：买入90股
- 60元：买入180股

**关键原则**：
- 随着下跌增加买入量，有效摊低成本
- 每跌10%左右，按1-1.5-2倍数比例买入
- 资金体量大可小步快跑，5%跌幅加仓一次

### 5.3 倒金字塔卖出法

**核心理念**：先收回本金和将一部分利润落袋为安

**操作示例**：
- 120元：卖出20%
- 130元：卖出30%
- 140元：卖出40%
- 更高位：持有剩余仓位博取更高收益

### 5.4 做T操作

**正T操作**：先买后卖
- 满仓时在成本线上T掉一部分
- 保本同时腾出资金和仓位

**反T操作**：先卖后买
- 预计下跌时先卖出
- 等跌不动时再买回
- 赚取差价

**关键原则**：做T要留够底仓，不容易导致卖飞

### 5.5 QDII基金选择

**聪明定投**：随下跌逐步增加购买金额

**选择标准**：
1. 根据情况选方向（纳指100追科技、标普500求稳健）
2. 看夏普比率（大于1优等生，大于2学神）
3. 看成立时间和基金经理操盘年限
4. 看管理费（越低持有成本越低）

## 第六部分：资产配置体系

### 6.1 三类资产配置

#### 防守型资产（稳健但收益低）

**特点**：稳，收益可忽略，但能睡得安稳

**类型**：
- 货币基金（朝朝宝、余额宝、零钱通）
- 大额存单（50万以内有保险兜底）
- R1级银行理财
- 国债

**适用人群**：不需要资产增值，只想守好本金略有小盈余的群体

#### 稳健型资产（平衡型）

**类型**：
- 优质纯债基金（年化3-4%）
- 核心城市住宅（讲究入场时间）
- 可转债打新/大券商收益凭证
- 分红险
- 宽基指数ETF（沪深300、中证500、标普500、纳指100等）

**适用人群**：普通人慢慢变富的首选，长期持有大概率正收益

#### 进取型资产（高收益高风险）

**类型**：
- 混合型/股票型基金
- 优质个股（白马股、龙头股）
- 可转债投资/公募REITs
- 黄金及相关ETF

**适用人群**：能承受较大波动，有一定投资经验

#### 激进型资产（高风险）

**类型**：
- 期货、期权
- 加密货币/合约
- 外汇交易
- 垃圾股、妖股

**建议比例**：想涉及激进型，最好控制在2%左右不超过5%

### 6.2 推荐的资产配置比例

```
防守型 > 稳健型 > 进取型 > 激进型（≤5%）
```

### 6.3 个人配置参考（示例）

- 美股：47%（重仓科技龙头股 + 宽基指数ETF + 生物医药 + 消费）
- 美债/美元债基/美元货基/港险：20%+
- 不动产：20%+
- 其他（加密货币等）：少量（娱乐性质）

## 第七部分：风险控制体系

### 7.1 风险控制核心原则

1. **投资的首要前提是保值，其次才是增值**
2. **在风险可控（自身能力承受范围内）的前提下做投资**
3. **不要赌徒心态**
4. **稳定盈利是最快的捷径，稳定是复利的前提**

### 7.2 最大回撤控制

**关键认知**：
- "收益率50%但最大回撤35%"的人，在风险控制水平上不如"收益率25%但最大回撤10%"的人
- 从小资金到大资金，靠的是稳定盈利，而不是暴利

**复利公式**：
```
控制回撤10%，年收益20% = 10年后资产翻6倍
控制回撤30%，年收益50% = 10年后资产仅翻3倍
```

### 7.3 安全边际

**核心概念**：
- 选优质个股
- 做好仓位、资金、成本的管理
- 控制好回撤
- 心态平和
- 不贪多也不恐惧
- 活得久，不断穿越牛熊

### 7.4 避免常见陷阱

1. **不要梭哈**：股市不是赌场，不要一把梭哈
2. **不要追高**：追高容易被挂东南枝
3. **不要满仓**：永远留有子弹
4. **不要上高杠杆**：上杠杆要非常谨慎
5. **不要碰自己不懂的东西**：不碰不懂的行业和企业

## 第八部分：技术分析工具

### 8.1 MACD指标

**参数设置**：系统默认（12，26，9），个人习惯（6，13，5）更灵敏

**适用场景**：
- 蓝筹股、大盘股、成熟行业龙头股
- 股价稳定、业绩稳定、影响市场的股票

**不适用**：高波动性股票、小盘股、新股或次新股

**核心信号**：
- DIF线和DEA线都是负数，DIF下穿DEA = 卖出信号
- DIF线和DEA线都是正数，DIF上穿DEA = 买入信号
- DEA线和股价背离 = 可能变盘
- MACD柱由红变绿 = 卖出信号；由绿变红 = 买入信号

### 8.2 斐波那契回撤

**核心数值**：23.6%、38.2%、50%、61.8%、78.6%

**应用**：
- 上涨趋势中，从波段最低点到最高点绘制，寻找回调支撑位
- 下跌趋势中，从波段最高点到最低点绘制，寻找反弹阻力位

**组合使用**：
- 斐波那契61.8% + MA200均线 = 强支撑区域
- 斐波那契38.2% + MACD金叉 = 可能反弹信号
- 斐波那契78.6% + RSI超卖 = 低吸机会

### 8.3 VIX恐慌指数

**用途**：用于判断市场情绪和风险偏好

**工具**：VIX、SVXY（做空VIX）、UVXY（2倍做多VIX）、TVIX（2倍做多VIX）

## 第十部分：投资心理与修养

### 10.1 圈层选择

- 多靠近"条件好、高能量"的群体
- 少接触自以为是的群体
- "条件好、高能量"群体的特征：稳定情绪、清晰逻辑、解决问题能力、对世界的善意
- 过得好的人因物质富足不太会主动批评你；容易攻击你的人要么一穷二白、要么嫉妒你

### 10.2 心态修炼

> 投资是和自己的价值观相印证的过程。

**核心要点**：
- 心可以选择柔和、慷慨、同情，也可以选择冷酷或狰狞
- 当一个人还有选择时，最好停一下，让选择权悬停片刻，认识自我
- 追求长期稳健前行，建立"长期可持续的循环体系"
- 过程中需要保持专注、耐心、定力、心静，是一场很好的修行

### 10.3 自我认知

**关键问题**：
1. 我是谁？
2. 我有什么？
3. 我要什么？
4. 我怎么做？

**常见错误**：
- 人到中年有了家庭后，首先要求稳，做好守富，防止返贫
- 先考虑怎么把钱留住，而不是再赚多少钱
- 大多数人最大的问题是"不认识自己"，心里没点数，容易飘

### 10.4 避免致命心态

1. **不要飘**：一飘就容易出事，大多数人栽在了"飘"字上
2. **不要急**：财不入急门，有赚且小幅跑赢通胀和存款利率就知足
3. **不要贪**：贪是投资的天敌，不追高
4. **不要惧**：恐惧是亏损的根源，敢于止盈也敢于抄底
