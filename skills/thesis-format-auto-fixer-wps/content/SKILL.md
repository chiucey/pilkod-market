# 毕业论文格式全自动修复工具（WPS版）

## 概述

用户只需上传 **2 个文档**，Skill 完全自动完成所有格式修复工作：
1. **论文原文**（docx/doc）
2. **格式规范文档**（Word / PDF / Markdown）

输出：`[原文件名]_格式修复完成版.docx` + `格式修改报告.txt`

---

## 执行工作流

### Step 1：接收与识别文档

1. 识别用户上传的两个文件：
   - 论文原文：扩展名为 `.docx` / `.doc`
   - 格式规范：扩展名为 `.docx` / `.doc` / `.pdf` / `.md` / `.txt`
2. 若文件数量或类型不符，友好提示用户重新上传，**无需用户提供其他任何参数**。
3. 确认识别后，告知用户"正在全自动处理，请稍候"。

---

### Step 2：全自动解析格式规范文档

使用适当工具读取规范文档全文（PDF 用 `extract_pdfs_full_content`，Word/MD 用 `Read` 或 `bash` 读取），**完整提取**以下所有格式要求，绝不遗漏：

| 类别 | 提取项目 |
|------|----------|
| 页面设置 | 纸张大小、页边距（上/下/左/右）、装订线位置与宽度、纸张方向 |
| 字体规范 | 正文、各级标题（一/二/三/四级）、摘要、关键词、目录、参考文献、图注/表注的字体名称、字号、加粗、斜体、颜色、下划线 |
| 段落规范 | 各部分首行缩进/悬挂缩进、行间距（固定值/倍数）、段前/段后间距、对齐方式 |
| 页眉页脚 | 页眉内容（分节/奇偶页差异）、页脚页码格式（位置、样式、起始页码、分节规则；封面无页码、摘要罗马数字、正文阿拉伯数字） |
| 标题层级 | 编号规则（如 1. / 1.1 / 1.1.1 或第一章）、各级缩进 |
| 图表规范 | 编号规则（如图1-1、表2-3）、标题位置（图注在下/表注在上）、字体字号 |
| 参考文献 | 格式标准（如 GB/T 7714）、排列方式、缩进、行距、标点符号全半角规则 |
| 目录 | 包含标题层级、格式样式、页码对齐、是否自动更新 |
| 其他特殊要求 | 规范中提及的所有个性化要求，全部提取，一条不漏 |

将解析结果结构化存储为 Python 字典 `spec`，供后续步骤使用。

---

### Step 3：全自动处理论文文档（WPS 兼容）

调用 `scripts/fix_thesis_format.py` 完成以下操作，**全程使用 python-docx 处理，确保 WPS Office 完美兼容**：

#### 3.1 全局页面设置
```
- 纸张大小（A4/B5 等）
- 页边距（上下左右及装订线）
- 纸张方向
```

#### 3.2 论文结构自动识别
自动识别并标记以下结构（使用关键词匹配 + 段落样式推断）：
- 封面、独创性声明、中文摘要、英文摘要（Abstract）
- 目录、正文各章节、图、表、参考文献、附录

#### 3.3 逐部分格式修复

**标题格式**
- 识别各级标题（正则匹配编号规则 + 样式推断）
- 应用对应 WPS 内置标题样式（Heading 1/2/3…）并按规范覆盖字体、字号、间距、加粗
- 修正编号连续性

**正文格式**
- 应用规范字体、字号、首行缩进、行距、段前段后间距、对齐方式

**页眉页脚与分节**
- 插入分节符（连续/下一页）实现：封面无页码、摘要罗马数字页码、正文阿拉伯数字页码
- 按规范配置各节页眉（内容/奇偶页/章节动态）

**图表编号与标题**
- 全文扫描图表，按规范规则（如图1-1、表2-1）重新连续编号
- 修正图注/表注字体字号，确保图注在图下方、表注在表上方

**参考文献格式**
- 按规范（如 GB/T 7714）统一作者名格式、标点符号（全角/半角）、行距、缩进
- 自动处理文献列表的悬挂缩进

**目录**
- 自动生成/更新符合规范的目录，插入到指定位置
- 更新目录域，确保页码完全正确

#### 3.4 内容保护原则
- **严格只修改格式，绝不修改正文内容**
- 完整保留：复杂公式、图片、表格、特殊符号、批注

#### 3.5 逐段格式检查
全文逐段扫描，核对所有格式参数是否 100% 符合 `spec`，记录每处修改。

---

### Step 4：生成输出文件

#### 输出文件 1：修复完成版论文
- 文件名：`[原论文文件名]_格式修复完成版.docx`
- 格式：标准 OOXML，WPS Office 直接打开所有格式正常显示

#### 输出文件 2：格式修改报告
- 文件名：`格式修改报告.txt`
- 内容结构：
  ```
  ============================================================
  毕业论文格式修改报告
  ============================================================
  规范来源：[规范文档文件名]
  处理时间：[时间戳]
  论文原文：[原文件名]

  一、检测到的格式问题总计：X 处

  二、修复明细
  【页面设置】共修改 X 项
    - 纸张大小：A4
    - 上边距：25mm → 30mm
    ...
  【标题格式】共修复 X 处
    - 第1章标题：字体宋体→黑体，字号小三→三号 ...
    ...
  【图表编号】共修复 X 处
    - 图编号重新排序：图1 → 图1-1 ...
  【参考文献】共修复 X 处
    ...
  【目录】已自动更新目录及页码

  三、需手动检查的项目（如有）
    - [具体描述无法自动修复的特殊问题]
  ============================================================
  ```

---

### Step 5：返回结果

将两个文件一并返回用户，并简要说明修复摘要。整个过程用户**零操作**。

## 硬性约束

1. **完全自动化**：用户只上传 2 个文件，无需输入任何额外参数。
2. **精准执行**：100% 按规范文档执行，不自行猜测或修改规范要求。
3. **WPS 兼容**：生成的 docx 必须在 WPS Office 中完美显示。
4. **内容安全**：只改格式，不改内容；所有文档处理在本地沙箱完成，不外传用户数据。
5. **细节完整**：标点全半角、空格、换行、编号连续性全部处理到位。
