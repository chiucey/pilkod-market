# A股量化筛选标准详细说明

## 一、资金流向维度详解

### 1.1 主力资金判定标准

**定义**：单笔成交金额超过100万元的买卖行为被视为主力资金动向

**计算公式**：
```
主力资金净流入 = 超大单净流入 + 大单净流入
超大单净流入 = 超大单买入额 - 超大单卖出额
大单净流入 = 大单买入额 - 大单卖出额
```

### 1.2 北向资金分析

**数据来源**：港交所披露的沪深港通持股数据

**关键指标**：
- 持股数量变化
- 持股比例变化
- 持仓市值变化

### 1.3 融资融券观察

**融资买入** = 做多情绪指标
**融券卖出** = 做空情绪指标
**融资融券余额差值** = 市场多空情绪分歧

## 二、量价技术维度详解

### 2.1 均线系统

**金叉信号**：短期均线上穿长期均线
```
5日均线 > 20日均线 → 买入信号
10日均线 > 30日均线 → 买入信号
```

**死叉信号**：短期均线下穿长期均线
```
5日均线 < 20日均线 → 卖出信号
10日均线 < 30日均线 → 卖出信号
```

### 2.2 MACD指标

**参数设置**：
- 快线EMA：12日
- 慢线EMA：26日
- 信号线：9日

**交易信号**：
```
MACD柱由负转正 + DIFF上穿DEA → 买入
MACD柱由正转负 + DIFF下穿DEA → 卖出
```

### 2.3 BOLL布林带

**参数设置**：
- 中轨：20日均线
- 上轨：中轨 + 2倍标准差
- 下轨：中轨 - 2倍标准差

**交易信号**：
```
股价突破中轨 + 成交量放大 → 买入
股价跌破中轨 + 成交量萎缩 → 卖出
```

### 2.4 KDJ随机指标

**参数设置**：
- N：9日
- K：3日
- D：3日

**超买超卖区域**：
```
K、D、J值 < 20 → 超卖区域 → 买入机会
K、D、J值 > 80 → 超买区域 → 卖出风险
```

## 三、趋势强度维度详解

### 3.1 相对强弱指标（RSI）

**参数设置**：6日、12日、24日

**信号判断**：
```
RSI < 30 → 超卖 → 买入机会
RSI > 70 → 超买 → 卖出风险
RSI在40-70区间 → 强势整理
```

### 3.2 动量指标

**计算公式**：
```
动量 = 今日收盘价 - N日前收盘价
动量率 = (今日收盘价 - N日前收盘价) / N日前收盘价 × 100%
```

### 3.3 相对大盘超额收益

**计算公式**：
```
超额收益 = 个股收益率 - 沪深300收益率
区间超额收益 = Σ(个股日收益率 - 沪深300日收益率)
```

## 四、基本面维度详解

### 4.1 市值筛选

**分类标准**：
```
超大盘股：> 1000亿
大盘股：300-1000亿
中盘股：100-300亿
小盘股：50-100亿
微盘股：< 50亿
```

**筛选建议**：主板50-500亿，兼顾流动性和弹性

### 4.2 估值指标

**市盈率（PE）**：
```
PE = 每股市价 / 每股收益
历史分位数 < 30% → 低估
历史分位数 > 70% → 高估
```

**市净率（PB）**：
```
PB = 每股市价 / 每股净资产
PB < 1 → 破净
行业平均PB作为参考基准
```

### 4.3 成长性指标

**净利润增长率**：
```
增长率 = (本期净利润 - 上期净利润) / 上期净利润 × 100%
连续2年正增长为佳
```

**营业收入增长率**：
```
增长率 = (本期营业收入 - 上期营业收入) / 上期营业收入 × 100%
> 10%为优质成长标准
```

## 五、筹码集中度详解

### 5.1 股东户数变化

**数据来源**：季报、半年报、年报披露

**分析逻辑**：
```
股东户数减少 → 筹码趋向集中 → 主力吸筹可能性
股东户数增加 → 筹码趋向分散 → 主力派发可能性
```

### 5.2 户均持股数

**计算公式**：
```
户均持股数 = 总股本 / 股东户数
户均持股数增加 → 筹码集中
户均持股数减少 → 筹码分散
```

### 5.3 机构持仓变化

**重点关注**：
- 公募基金持仓变化
- 私募基金持仓变化
- 社保基金持仓变化
- QFII持仓变化

## 六、综合评分模型

### 6.1 权重分配

```
资金流向：30%
量价技术：25%
趋势强度：20%
基本面：15%
筹码集中度：10%
```

### 6.2 评分标准

**每项指标评分（0-100分）**：
- 满分：完美满足条件
- 80分：较好满足条件
- 60分：基本满足条件
- 40分：部分满足条件
- 20分：勉强满足条件
- 0分：不满足条件

**综合得分计算**：
```
总分 = 资金流向得分 × 0.30
     + 量价技术得分 × 0.25
     + 趋势强度得分 × 0.20
     + 基本面得分 × 0.15
     + 筹码集中度得分 × 0.10
```

### 6.3 筛选门槛

```
综合得分 ≥ 70分 → 重点关注
综合得分 60-70分 → 观察标的
综合得分 < 60分 → 暂不推荐
```

## 七、风控模型

### 7.1 止损策略

**固定止损**：
```
止损价位 = 买入价 × 0.92（8%止损）
```

**移动止损**：
```
止损价位 = 最高价 × 0.95
```

### 7.2 仓位管理

**单只股票仓位上限**：10%
**持仓数量上限**：20只
**行业集中度上限**：30%

### 7.3 风险预警

```
持仓股票下跌10% → 一级预警
持仓股票下跌15% → 二级预警
持仓股票下跌20% → 必须止损
```

## 八、实战案例

### 案例：比亚迪（002594）

**入选理由**：
1. 主力资金连续5日净流入
2. 成交量较20日均量放大2.3倍
3. 5日均线上穿20日均线
4. 股价突破BOLL中轨
5. 新能源汽车龙头，基本面稳健
6. 股东户数连续2期减少

**风险提示**：
- 原材料价格波动
- 竞争格局恶化
- 政策变化风险

**综合评分**：78分 → 重点推荐
