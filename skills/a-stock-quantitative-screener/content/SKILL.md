# A股量化交易股票筛选系统

## 工作流程

本技能采用**三角色辩论式分析**流程，确保筛选结果的客观性和可靠性：

```
角色1（筛选） → 角色2（反驳） → 角色3（综判） → 最终推荐
```

## 阶段一：A股量化特点分析

分析当前A股市场的量化交易特征：

1. **成交活跃度高** - 日均成交额约1-2万亿，量化交易占20-30%
2. **散户占比高** - 散户交易占比大，定价效率相对低，超额机会多
3. **政策影响显著** - 监管政策对量化策略影响大
4. **波动性大** - 散户追涨杀跌放大波动，趋势跟踪策略有效
5. **小盘股溢价** - 小微盘股流动性溢价明显
6. **板块轮动快** - 热点切换频繁，行业轮动策略适用
7. **技术指标有效** - 量价数据被广泛使用
8. **北向资金影响** - 外资定价权逐渐增强

## 阶段二：五维筛选标准

### 1. 资金流向维度（权重30%）

- 主力资金连续净流入 ≥ 3日
- 超大单净流入占比 > 5%
- 北向资金持股比例上升
- 融资融券余额变化

### 2. 量价技术维度（权重25%）

- 成交量较20日均量放大 ≥ 1.5倍
- 5日均线上穿20日均线（金叉）
- 股价站上BOLL中轨
- MACD零轴上方金叉

### 3. 趋势强度维度（权重20%）

- 区间涨幅 5%-25%（避免追高和弱势股）
- 相对大盘（沪深300）超额收益 > 3%
- 股价创20日新高
- 多周期均线多头排列

### 4. 基本面维度（权重15%）

- 市值：主板50-500亿（兼顾流动性和弹性）
- PE：0-50倍（估值合理）
- 近两年净利润正增长
- 近一年无重大违规

### 5. 筹码集中度（权重10%）

- 股东户数连续减少
- 户均持股数增加
- 筹码趋向集中

## 阶段三：三角色分析

### 角色1：量化研究员（筛选）

1. 分析A股量化特点并记录补充筛选标准
2. 结合当日最新市场行情
3. 应用筛选标准识别量化资金介入信号
4. 输出符合条件的前10只股票（主板为主）
5. 附具体代码、名称、入选理由、风险提示

### 角色2：量化研究员（反驳）

验证角色1筛选结果的合理性，查找逻辑漏洞：

1. **技术指标有效性** - 质疑滞后性、参数敏感性、市场适应性
2. **资金流向可靠性** - 质疑数据划分标准、对倒交易混淆、短期噪音
3. **基本面矛盾** - 质疑流动性陷阱、估值与动量矛盾
4. **样本偏差** - 质疑幸存者偏差、时间窗口依赖
5. **执行问题** - 质疑滑点、延迟、风控缺失

### 角色3：量化研究员（综判）

综合评估双方观点，输出最终结论：

1. 评估辩论双方的论据强度
2. 调整优化筛选标准
3. 更新最终股票池
4. 提供优先级排序
5. 给出具体投资建议

## 阶段四：风险控制

### 风控要求

- 单只股票仓位 ≤ 10%
- 设置8%止损线
- 持仓不超过20只
- 避免高位追涨

### 风险提示

- 量化策略存在失效风险
- 技术指标具有滞后性
- 资金流向数据可能存在误差
- 市场环境变化影响策略有效性
- 投资有风险，决策需谨慎
