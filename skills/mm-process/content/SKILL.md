## A. Scope and Operating Contract

本技能用于执行市场管理（Market Management）七阶段评估流程，从公司视角穷举细分市场，到PDT锁定细分市场组合。

**核心输出**：PDT细分市场组合声明（品类 + 核心场景 + 核心人群）

**执行时机**：年度规划Q4（10-12月）

**触发场景**：
- 用户询问品类规划、细分市场识别
- 用户要求进行市场吸引力评估
- 用户需要PDT细分市场组合声明

---

## B. MM V5.0 七阶段评估框架

### B1. 整体架构速览

```
Phase 1：细分市场识别 ★公司级
    ↓
Phase 2：细分市场吸引力评估 ★公司级（品类×场景后评估）
    ↓
Phase 3：BU战略匹配度评估 ★BU级
    ↓
Phase 4：细分市场综合优先级 ★公司+BU联合
    ↓
Phase 5：BU能力匹配度确认 ★BU级（双重确认）
    ↓
Phase 6：PDT细分市场组合确定 ★PDT级
    ↓
Phase 7：品类策略制定 ★PDT级
```

## C. Phase 1：细分市场识别（公司级）

### C1. 细分市场定义

**细分市场 = 品类 × 场景 × 用户群**

| 维度 | 选项 | 说明 |
|------|------|------|
| 品类 | 公路、Gravel、MTB、室内训练等 | 按骑行场景分类 |
| 场景 | 严肃训练、竞技比赛、运动休闲、长途骑游、室内训练等 | 按使用目的分类 |
| 用户群 | 新手(<2年)、进阶(2-5年)、老手(>5年) | 按骑行经验分类 |

### C2. 品类优先级

| 优先级 | 品类 | 战略定位 |
|-------|------|---------|
| A类 | Gravel砾石车系 | 第一优先 |
| A类 | 室内训练 | 第一优先 |
| A类 | 公路车系 | 核心防守 |
| B类 | E-Bike电助力系 | 战略孵化 |
| C类 | 山地车系 | 选择性发展 |
| D类 | 城市车系 | 边缘观望 |

### C3. 场景优先级

| 优先级 | 场景 | 核心需求 |
|-------|------|---------|
| 核心 | 严肃训练 | 精确数据、训练计划、数据分析 |
| 核心 | 竞技比赛 | 最轻重量、最高精度、最快响应 |
| 核心 | 室内训练 | 骑行台兼容、功率精度、虚拟软件生态 |
| 重要 | 运动休闲 | 记录分享、基础数据、社交互动 |
| 重要 | 长途骑游 | 超长续航、离线导航、耐用性 |

## D. Phase 2：细分市场吸引力评估（公司级）

### D1. 核心修正

**V5.0关键修正**：市场吸引力评估必须在**品类×场景**交叉之后，评估的是**具体细分市场**的吸引力，而非抽象品类的吸引力。

| 错误做法 | 正确做法 |
|---------|---------|
| 评估"公路车市场" | 评估"公路-严肃训练市场" |
| 评估"Gravel市场" | 评估"Gravel-长途骑游市场" |

### D2. 五维评估模型

| 维度 | 权重 | 评估对象 |
|------|------|---------|
| 1.市场规模 | 25% | 该细分市场的实际容量 |
| 2.市场增速 | 20% | 该细分市场的CAGR |
| 3.竞争强度 | 20% | 该细分市场内的玩家数量和集中度 |
| 4.盈利潜力 | 20% | 该细分市场的典型毛利率和价格带 |
| 5.政策/趋势 | 15% | 影响该细分市场的外部因素 |

### D3. 综合评分标准

```
综合得分 = Σ(各维度得分×权重)

评分标准：
- ≥4.0分 = 极高吸引力（优先投入）
- 3.5-3.9分 = 高吸引力（重点投入）
- 3.0-3.4分 = 中等吸引力（选择性投入）
- <3.0分 = 低吸引力（谨慎投入或观望）
```

## E. Phase 3：BU战略匹配度评估（BU级）

### E1. 核心修正

**Phase 3是BU级活动，不是公司级活动。**

- 每个BU有不同战略重点
- 同一细分市场，不同BU可能有不同的战略匹配度
- 各BU评估"我们（BU）要不要做这个细分市场"

### E2. 三维评估模型

| 维度 | 权重 | 评估问题 |
|------|------|---------|
| 1.品类经验匹配 | 40% | 该BU在该品类有多少积累？品牌/技术/渠道能否迁移？ |
| 2.场景需求匹配 | 35% | 该BU能否满足该场景的核心用户需求？ |
| 3.竞争定位匹配 | 25% | 该BU能否在该细分市场找到差异化定位？ |

### E3. PDT归属关系（示例模板）

| BU | PDT | 核心产品线 |
|----|-----|-----------|
| 室内BU | PDT1-2B | XX产品B系列 |
| | PDT1-2C | XX产品C系列 |
| 室外BU | PDT2 | XX产品系列 |
| | PDT3 | XX产品系列 |
| | PDT4 | XX产品系列 |
| 智能驱动BU | PDT5 | XX产品系统 |
| | PDT6 | XX产品线 |
| 电助力BU | PDT7 | XX系统、XX配件 |

### E4. 匹配度等级

| 得分 | 等级 | 建议 |
|------|------|------|
| ≥4.0分 | 高匹配 | 强烈建议承接 |
| 3.5-3.9分 | 中高匹配 | 建议承接 |
| 3.0-3.4分 | 中等匹配 | 可选承接 |
| <3.0分 | 低匹配 | 不建议承接 |

## F. Phase 4：细分市场综合优先级

### F1. 综合得分计算

```
综合得分 = 公司吸引力得分×50% + BU战略匹配度×50%
```

### F2. 优先级矩阵模板

| 细分市场 | 吸引力得分 | BU匹配度 | 综合得分 | 优先级 |
|---------|-----------|---------|---------|--------|
| Gravel-长途骑游 | 4.0 | 4.5 | 4.25 | P1 |
| Gravel-严肃训练 | 3.8 | 4.0 | 3.90 | P1 |
| 公路-严肃训练 | 4.1 | 4.2 | 4.15 | P1 |

## G. Phase 5：BU能力匹配度确认（BU级）

### G1. 核心修正

**Phase 5是"双重确认"，不是"选择谁来承担"。**

- Phase 5确认已选择的细分市场，BU是否有能力承接
- 能力不足 → 该BU放弃该细分市场（不会转给其他BU）
- 每个PDT是专属资源，不会跨BU调配

### G2. 四维评估模型

| 维度 | 权重 | 评估问题 |
|------|------|---------|
| 1.技术适配性 | 30% | 现有技术平台能否快速适配该细分市场需求？ |
| 2.产品复用性 | 25% | 能否复用现有产品线，减少研发投入？ |
| 3.PDT能力匹配 | 25% | PDT团队是否有该品类的研发经验？ |
| 4.供应链协同 | 20% | 现有供应链能否支撑该产品？ |

### G3. 确认决策

| 综合得分 | 决策 | 行动 |
|---------|------|------|
| ≥3.5分 | 承接 | 能力充分，全力投入 |
| 3.0-3.4分 | 谨慎承接 | 能力中等，有限投入 |
| <3.0分 | 不承接 | 该BU放弃该细分市场 |

## L. 常见问题

### L1. Phase 3和Phase 5有何区别？

- **Phase 3（战略匹配度）**：外部视角，评估"要不要做"
- **Phase 5（能力匹配度）**：内部视角，评估"能不能做"

### L2. PDT能力不足时怎么办？

PDT是专属资源，不会跨BU调配。能力不足时，该BU放弃该细分市场，其他BU应自己建立相应能力。

### L3. 为什么市场吸引力要在品类×场景后评估？

因为同一品类在不同场景下，市场特征差异巨大。例如"Gravel-严肃训练"和"Gravel-长途骑游"在市场规模、增速、竞争格局上完全不同。
