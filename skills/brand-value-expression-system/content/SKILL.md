# 搭建品牌价值表达体系（品牌表现符咒双线模型）

## 模型内核（先读这段再干活）

本 skill **双向可用**：
- **正向推演**：从价值原点出发，为一/家品牌从零搭建价值表达系统（本文「标准作业流程」7步）
- **反向验证**：基于某品牌已有的传播物/表达物（slogan、KV、包装、广告、落地页、话术、产品页等），逆向反推其品牌价值系统并做总结与检验 → 直接跳读 `references/09-reverse-audit.md`

先判断用户意图属于哪一向：给品牌做设计/策划 → 正向；给现成物料/品牌做拆解、复盘、体检、审计、竞品分析 → 反向。两个方向共用同一套模型语言（符咒场证行、四柱、三场、检验体系）。

品牌 ≠ Logo美学 + 广告修辞 + 情绪叙事。真正决定企业被优先选择、支撑溢价、形成复购的，是顾客在关键决策时刻**更快看见价值、更容易听懂价值、更清楚地比较价值**，以及企业持续兑现的组织能力。

五字总纲：
- **符**（视觉领导力）→ 让品牌**被看见**
- **咒**（语言领导力）→ 让品牌**被理解**
- **场**（场景钩/三场触点）→ 让品牌**被想起**
- **证**（信任状）→ 让品牌**被相信**
- **行**（经营兑现）→ 让品牌**被证明**

本模型是加加林Brand-OS四层中的第三层（表现层）：第一层品牌价值引力层回答「为什么值得被选择」，第二层六化翻译层回答「抽象价值如何被感知」，第三层**符咒双线**回答「价值如何被一眼认出、一句听懂」，第四层经营层回答「如何被持续兑现、沉淀与放大」。

完整结构 = **一核、双线、四柱、三场、五验**（原文另有"双飞轮"提法但未展开，勿杜撰）。

**红线**：没有价值原点的符只是装饰，没有事实证明的咒只是口号，没有触点兑现的品牌表现只是一次性广告。

## 标准作业流程（正向推演，7步）

按序执行，每步产出可签字的交付物。用户只做局部（如只要语言钉）时，仍先核对第1步价值原点是否成立，再进入对应模块。反向（审计已有品牌）见 `references/09-reverse-audit.md`。

### 第1步 · 锁一核（价值原点）

一核三要素，**缺一则创意脱离需求、语言沦为套话**：
1. 顾客真实冲突（不是人口学标签，是顾客原话里的怕与想）
2. 独特价值主张（对冲突的尖锐回应）
3. 企业真实证明（拿得出的事实证据）

一核表达公式：
> 对于（目标顾客）而言，当他们处于（关键场景）并遇到（核心冲突）时，品牌通过（可验证能力）提供（独特价值结果），因而成为更值得优先选择的（品类/解决方案）。

一核确定后先落品牌平台4P总开关（见 references/06）：先有4P与证据，后有口号与视觉。

### 第2步 · 建双线（符+咒）

- **符 = 视觉识别 + 价值联想 + 情绪气质 + 触点一致性**。7项资产逐项任务、9层资产链、5项检验 → 读 `references/02-fu-visual-system.md`
- **咒 = 语言理解 + 价值压缩 + 场景触发 + 行动指令**。14类资产、9项硬要求、6项检验 → 读 `references/03-zhou-language-system.md`

任务不是「装饰得更漂亮」「写句好听的广告语」，而是让顾客、销售、导购、客服、渠道、员工和AI**使用同一套资产**。

### 第3步 · 立四柱（超级记忆四柱）

符咒要成为记忆与交易系统，靠四根支柱，每柱有作业卡必填项 → 读 `references/04-four-pillars-workcards.md`：
1. **语言钉**：核心价值词+顾客冲突+关键场景=候选语言钉，至少产出10条候选
2. **视觉锤**：看到→认出→联想到价值→想起语言钉→进入触点感到一致
3. **场景钩**：时间/地点/情绪/关系/任务五要素
4. **信任状**：荣誉/人物/机构/口碑/安全五类，每条主张必须有对应证明

### 第4步 · 查互锁

对照5种错误状态逐条排雷（视觉高级语言模糊→认知不转化；语言直接视觉像竞品→记忆不积累；视觉说高端价格促销→信任下降；语言讲专业服务随意→品牌反噬；内容每天换调性→资产稀释）→ 读 `references/06-interlock-4p-ironrules.md`。正确状态是**互相唤醒**：听到语言钉即出现视觉锤，看到视觉锤即想起核心价值词。

### 第5步 · 落三场

- 心智场（认不认得、懂不懂）：品牌名/品类名/核心价值词/语言钉/视觉锤/场景钩 → 无提示提及率、品类关联率、语言复述率、视觉识别率、竞品混淆率
- 交易场（信不信、买不买）：USP标签/产品事实/对比图/价格说明/案例/认证/服务承诺 → 咨询成交率、试用加购率、客单与价格接受度、折扣依赖度、退款率
- 经营场（做不做得到）：产品标准/价格纪律/渠道规范/话术/触点抽检/资产台账/AI规范 → 触点一致性、价格合规率、承诺兑现率、内容复用率、复购与LTV

三者关联逻辑：只有心智没交易证据→停在「知道」；只有交易没经营兑现→停在「一次购买」；只有经营没心智交易表达→价值藏在内部。
→ 细读 `references/05-three-fields-five-tests.md`

### 第6步 · 过五验

品牌表现不能由喜好决定 → 读 `references/05-three-fields-five-tests.md`：
识别验（3秒盲测）、理解验（5秒理解10秒复述）、信任验（证据点击/异议分析）、转化验（咨询试用成交）、复利验（复购NPS转介绍LTV）。
判断纪律：视觉好看≠被识别；语言好听≠被理解；内容爆火≠被信任；成交增长≠品牌形成；只有复购、推荐、溢价与长期一致性才说明资产开始积累。

### 第7步 · 排期与治理

- **12周作业路线**：W1定战略锚→W2顾客冲突→W3竞品表达→W4信任证据→W5品牌平台4P→W6语言钉→W7视觉锤→W8符咒互锁→W9资产三层→W10三场触点→W11定90天火车头→W12签字上线复盘 → 读 `references/07-execution-roadmap.md`
- **90天火车头**：每季度只选一个最大断点（8类方向选1），30/60/90节奏（样板建立→小范围验证→复盘固化）
- **一页纸决策书**：8模块收口（战略锚/品牌平台4P/符咒双线/记忆四柱/三场触点/不做清单/90天火车头/各部门签字）
- **资产三层**：核心价值层（长期原点）→识别符号层（认出理解记住）→体验触点层（接触点验证承诺）

## 交付物清单（按此验收）

任何完整项目应交付：一核表达公式一段话、品牌平台4P一页纸、语言钉终稿（含10条候选+使用周期+应用触点+禁止表达）、视觉锤作业卡、场景钩地图（五要素）、信任状证据墙（每条主张对应一张）、符咒互锁评价矩阵、三场触点作战图、90天火车头项目书、一页纸决策书。

## 输出纪律

- 始终从价值原点出发；顾客说不出原话时，用「顾客最怕什么/最想得到什么」访谈补齐，不得代编
- 语言钉必须给≥10条候选再收敛，不许直接给1条
- 每条品牌主张必须挂对应信任状，挂不上的主张删掉
- 对已有品牌：先做互锁5错误状态诊断+五验现状打分，再开药方
- 参考完整案例推演（区域家装公司）见 `references/08-case-demo.md`，输出时举一反三但标注借鉴来源
