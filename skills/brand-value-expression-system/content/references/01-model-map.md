# 模型总图

## 模型定位

加加林Brand-OS四层结构，本模型是第三层：

| 层 | 名称 | 回答的问题 |
| --- | --- | --- |
| 第一层 | 品牌价值引力层 | 品牌为什么值得被选择 |
| 第二层 | 六化翻译层 | 抽象价值如何被顾客感知 |
| 第三层 | **表现层（符咒双线模型）** | 价值如何被一眼认出、一句听懂 |
| 第四层 | 经营层 | 品牌如何被持续兑现、沉淀与放大 |

引力场决定品牌为什么有力量；六化决定感知路径；符咒双线决定力量如何显形、传递并放大。

## 五字总纲

| 字 | 系统作用 | 顾客动作 |
| --- | --- | --- |
| 符 | 视觉领导力 | 一眼认出（被看见） |
| 咒 | 语言领导力 | 一句听懂（被理解） |
| 场 | 场景钩/三场触点 | 需要时想起（被想起） |
| 证 | 信任状 | 购买时相信（被相信） |
| 行 | 经营兑现 | 使用后验证（被证明） |

最终以产品、渠道和服务把承诺做到。

## 完整结构

一核、双线、四柱、三场、五验（原文提及"双飞轮"但全文未展开，引用时不要展开解释）。

- **一核**：价值原点 = 顾客真实冲突 × 独特价值主张 × 企业真实证明，三者缺一，创意脱离需求、语言沦为套话、视觉与口号变成虚假承诺
- **一核表达公式**：对于（目标顾客）而言，当他们处于（关键场景）并遇到（核心冲突）时，品牌通过（可验证能力）提供（独特价值结果），因而成为更值得优先选择的（品类/解决方案）
- **双线**：符（视觉领导力）+ 咒（语言领导力）
- **四柱**：语言钉、视觉锤、场景钩、信任状
- **三场**：心智场、交易场、经营场
- **五验**：识别验、理解验、信任验、转化验、复利验

## 模型本质

不是视觉与文案的工具箱，而是**可签字、可执行、可验证、可治理的表达执行引擎**。它解决的不是「Logo好不好看、广告语顺不顺口」，而是企业已有的真实价值如何被翻译成顾客看得见、听得懂、记得住、愿意相信并最终愿意选择的品牌表现系统。

品牌表现不是品牌部的视觉项目，而是战略、产品、销售、渠道、运营、服务与数据共同向客户交付的承诺。

## 三条红线

1. 没有价值原点的符，只是装饰
2. 没有事实证明的咒，只是口号
3. 没有触点兑现的品牌表现，只是一次性广告
