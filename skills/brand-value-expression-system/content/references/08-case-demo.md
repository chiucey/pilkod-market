# 案例演示：区域家装公司的符咒推演（教学型虚构案例）

## 行业原有共性问题

原主张「品质家装，美好生活」是所有装修公司都能提出的口号，实际落地存在明显缺陷：

1. 客户无法感知「品质」的具体落点
2. 工地、客服、销售、广告的品牌表达没有形成统一口径

## 顾客真实核心冲突

> 我想把家装好，但害怕报价不透明、工期拖延、出问题没人负责。

## 核心定位（品牌平台4P）

| 维度 | 内容 |
| --- | --- |
| Purpose（目标） | 让普通家庭不必在装修过程中被反复消耗 |
| Promise（承诺） | 报价讲清、进度看见、问题有人负责 |
| Proof（佐证支撑） | 透明报价、节点验收、固定项目经理、每周进度、售后时效 |
| Personality（品牌人格） | 像一位直接、可靠、懂行但不推诿的项目管家 |

## 落地执行体系

| 维度 | 内容 |
| --- | --- |
| 咒 · 语言钉 | 装修不靠催，节点自己报 |
| 符 · 视觉锤 | 装修进度护照：节点时间轴、责任人卡、统一节点视觉 |
| 场 · 场景钩 | 三大焦虑场景：装修前担心被坑、施工中担心拖延、发现问题担心没人负责 |
| 证 · 信任状 | 透明报价单、节点验收二维码、责任卡、工地记录、售后时效 |
| 行 · 体验 | 进度每周主动更新，客户随时可查 |

## 核心理念总结

> 「省心」不是一句文案，也不是一个管家图标。它必须变成能看见的报价、能追踪的进度、能找到的责任人、能兑现的售后。

---

# 使用方法（输出时举一反三）

照此推演顺序为任何品牌做符咒推导：共性问题 → 顾客真实冲突 → 4P定位 → 符/咒/场/证/行五行落地。示范输出的形态（表格式逐层推导）可直接复用；案例内容本身是教学型虚构，不要照抄结论到真实品牌上。
