# 三场与五验

## 三场（符咒双线必须同时进入）

### 心智场 · 客户认不认得、懂不懂

- **核心资产**：品牌名 + 品类名 + 核心价值词 + 语言钉 + 视觉锤 + 场景钩（+ 最小记忆元素）
- **核心指标**：无提示提及率 · 品类关联率 · 语言复述率 · 场景联想率 · 视觉识别率 · 竞品混淆率

### 交易场 · 客户信不信、买不买

- **核心资产**：USP标签 + 产品事实 + 对比图 + 价格说明 + 案例 + 认证 + 服务承诺（+ 销售话术与试用体验）
- **核心指标**：咨询成交转化率 · 试用加购率 · 客单价与价格接受度 · 折扣依赖度 · 价格异议率 · 退款投诉率

### 经营场 · 企业做不做得到

- **核心机制**：产品服务标准、价格纪律、渠道物料规范、销售客服话术、触点抽检、内容审核、资产台账、AI生成规范与月度一致性会
- **核心指标**：触点一致性评分 · 价格合规率 · 话术合格率 · 服务兑现率 · 内容复用率 · 主张变更次数 · 复购、LTV与贡献毛利

### 三者关联逻辑

1. 只有心智没有交易证据 → 顾客停留在「知道」
2. 只有交易没有经营兑现 → 顾客停留在「一次购买」
3. 只有经营没有心智与交易表达 → 价值永远藏在内部

## 五验机制（品牌表现不能由喜好决定）

| 序号 | 验证类型 | 核心考察方向 | 测试方法 |
| --- | --- | --- | --- |
| 1 | 识别验 | 顾客一眼能否认出 | 3秒视觉盲测、货架测试、竞品混淆测试 |
| 2 | 理解验 | 顾客一听能否听懂 | 5秒理解、10秒复述、访谈、销售录音抽检 |
| 3 | 信任验 | 顾客是否相信 | 证据点击、案例查看、评价分析、价格异议分析 |
| 4 | 转化验 | 顾客是否愿意行动 | 咨询、试用、加购、成交、客单、渠道转化 |
| 5 | 复利验 | 顾客是否愿意留下与推荐 | 复购、续费、NPS、转介绍、UGC、LTV |

### 判断纪律

- 视觉好看，不等于被识别
- 语言好听，不等于被理解
- 内容爆火，不等于被信任
- 成交增长，不等于品牌形成
- **只有复购、推荐、溢价和长期一致性，才说明品牌资产开始积累**
