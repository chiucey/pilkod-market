# 咒 · 语言领导力系统

## 定义

> 咒 = 语言理解 + 价值压缩 + 场景触发 + 行动指令

核心任务不是创作好听的广告语，而是**让顾客、销售、导购、客服、渠道、员工和AI都使用同一种品牌语言**。语言领导力让企业从品牌部到一线说同一种话。

## 资产链（14类资产）

品牌名、品类名、核心价值词、定位句、战略口号、超级话语、USP标签、产品命名、价格解释、销售话术、服务语言、内容标题、社群语言、AI语言规范。

## 九项资产的硬要求

| 资产 | 硬要求 |
| --- | --- |
| 品牌名 | 易读、易记、可搜索、可扩展 |
| 品类名 | 清楚、能重定义竞争、不自嗨 |
| 核心价值词 | 一个主词，长期守住 |
| 定位句 | 有对象、场景、冲突和价值 |
| 战略口号 | 短、尖、可重复、可兑现 |
| USP标签 | 有产品事实、可比较、可证明 |
| 产品命名 | 结构清楚、降低选择成本 |
| 销售/服务语言 | 从功能参数转向客户结果 |
| 内容语言 | 同一语调、不同场景、长期复用 |

## 六项检验标准

1. **明确性**：顾客一听知道你在说什么吗
2. **尖锐性**：是否直指顾客冲突或核心价值
3. **可复述性**：顾客、销售、导购能说出来吗
4. **可重复性**：能用三年，而不是每年换一句
5. **可兑现性**：产品、服务和渠道真能做到吗
6. **可传播性**：是否适合内容、社交、搜索与AI检索
