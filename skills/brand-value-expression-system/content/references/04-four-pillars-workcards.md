# 超级记忆四柱 · 作业卡

符咒双线要成为记忆与交易系统，需要四根支柱。每柱给出公式/标准/作业卡必填项，作业时逐项填写，缺项不算完成。

## ① 语言钉

**公式**：核心价值词 + 顾客冲突 + 关键场景 = 候选语言钉

**核心认知**：语言钉不是文案好不好，而是把顾客最害怕的事，翻成一句容易理解的承诺。

**六个评判标准**：

| 标准 | 释义 |
| --- | --- |
| 尖 | 直指客户最在意的问题 |
| 短 | 降低理解和记忆成本 |
| 真 | 有产品与服务证明 |
| 稳 | 不因一次营销活动（Campaign）轻易更换 |
| 能说 | 销售、导购、客服都敢使用 |
| 能传 | 顾客愿意复述、愿意转述 |

**作业卡必填项（11项）**：
1. 核心价值词
2. 目标顾客
3. 关键场景
4. 顾客原话
5. 顾客冲突
6. 企业证明
7. 候选语言钉（**至少10条**）
8. 最终语言钉
9. 使用周期
10. 应用触点
11. 禁止使用的相似表达

## ② 视觉锤

**定义**：把语言钉和核心价值，转化成顾客一眼能认出的画面、符号、色彩、动作或结构。

**传递逻辑（四层递进）**：
看到 → 能认出 → 能联想到价值 → 能想起语言钉 → 进入触点能感到体验一致

**作业卡必填项（12项）**：
- 核心价值、语言钉、目标顾客
- 关键场景、顾客希望感到什么、认知母体
- 主符号、主色彩、主画面
- 产品事实如何进入、包装/空间如何使用、内容/销售如何使用
- 竞品混淆风险、三秒识别测试

## ③ 场景钩

**任务**：品牌必须绑在「顾客需要时」。

**五要素**：

| 维度 | 说明 |
| --- | --- |
| 时间 | 顾客什么时候最需要 |
| 地点 | 顾客在哪儿作出选择 |
| 情绪 | 焦虑、疲惫、犹豫、开心还是期待 |
| 关系 | 为自己、家人、朋友还是客户 |
| 任务 | 顾客到底要完成什么 |

**作业要求**：明确目标场景、顾客最怕什么、最想得到什么、替代方案、品牌为何更适合，以及语言钉、视觉锤与信任状如何在该场景出现。

## ④ 信任状

**解决的问题**：「你说得不错，但我凭什么信你？」

**五类信任状**：

| 类型 | 包含内容 |
| --- | --- |
| 荣誉信任状 | 奖项、认证、专利、行业标准 |
| 人物信任状 | 创始人、专家、客户、意见领袖 |
| 机构信任状 | 检测机构、权威单位、合作伙伴 |
| 口碑信任状 | 真实评价、案例、复购、销量、转介绍 |
| 安全信任状 | 服务承诺、质检、售后、保险、合规与责任 |

**核心原则：每一条核心价值，都必须有一张对应的信任状。**

不同核心价值的信任状支撑要求：

| 核心价值 | 必备支撑内容 |
| --- | --- |
| 「专业」 | 方法、资质、项目案例、流程、结果 |
| 「透明」 | 价格、合同、流程、节点与责任公开 |
| 「健康」 | 成分、来源、检测、适用边界 |
| 「省心」 | 时效、责任人、SOP、售后与响应机制 |
| 「高品质」 | 原料、工艺、标准、质检、体验对比 |
| 「高性价比」 | 价格组成、使用周期、替代成本、结果价值 |
