# 符 · 视觉领导力系统

## 定义

> 符 = 视觉识别 + 价值联想 + 情绪气质 + 触点一致性

核心任务不是把企业装饰得更漂亮，而是**把核心价值压缩成顾客能够迅速识别、长期记忆、跨场景调用的视觉资产**。

视觉领导力不是一套VI，而是所有视觉接触点向顾客传递同一价值的系统。

## 资产链（9层，自上而下流转）

1. 核心价值
2. 战略符号
3. 战略色彩
4. 战略纹样与视觉语法
5. 战略IP/角色
6. 核心KV与视觉锤
7. 产品/包装/空间/终端
8. 官网/电商/内容/销售资料
9. 视觉规范与AI调用模板

## 七项核心视觉资产（每一项都有明确任务）

| 资产 | 解决什么 | 硬要求 |
| --- | --- | --- |
| 战略符号 | 如何一眼识别品牌 | 有价值关联、独特、可延展 |
| 战略色彩 | 如何迅速传递气质与情绪 | 在品类中不混淆、跨触点稳定 |
| 战略纹样 | 如何形成有归属感的视觉语法 | 必须服务价值，而非无关装饰 |
| 战略IP | 如何把价值人格化、故事化 | 必须有具体任务，而非仅是吉祥物 |
| 战略KV | 如何把价值戏剧化、画面化 | 必须有场景、有冲突、有产品证明 |
| 产品/包装/空间 | 如何让顾客在交易现场感受品牌 | 视觉与产品体验必须一致 |
| VI与数字模板 | 如何让组织和AI持续一致使用 | 可规范、可调用、可审核、可迭代 |

完整覆盖面还包括：Logo与核心图形、产品轮廓、包装结构、空间与终端、主视觉KV、摄影/字体/排版与动态语法、数字界面与AI调用模板。

## 五项检验标准

| 标准 | 判定规则 |
| --- | --- |
| 识别性 | 顾客在1—3秒内能否认出 |
| 独占性 | 是否容易与竞品混淆 |
| 关联性 | 顾客能否联想到核心价值 |
| 延展性 | 能否进入产品、包装、空间、内容、销售与数字界面 |
| 资产性 | 能否注册、沉淀、长期复用和防御 |

注意：颜色与视觉资产不是为了好看，而是为了区分进度、风险、验收和责任。
