4. 多周期技术底共振：日线RSI(14)<30、周线RSI(14)<40，指数偏离20日均线>15%，成交额低于20日均量50%以上。

### 辅助验证信号（至少满足2项，提升抄底胜率）

4. 多空博弈反转信号：沽空余额连续3日下降，沽空成交占比从高位回落超5个百分点，ETF溢价率持续扩张。

### 绝对禁止信号（出现任一，立即禁止抄底/新增建仓）

### 7.2 逻辑破位止损（出现任一，立即执行减仓/清仓）

1. 核心驱动因子全面反转：美联储进入加息周期、国内科技政策超预期收紧、美债收益率持续>4.5%；
2. 资金面持续恶化：南向资金30日累计净流出超500亿港元，外资持续大额抛售；

4. 多空博弈空头主导：沽空占比持续>25%，Put/Call>2，VHSI>35，且无企稳信号；
5. 汇率冲击：人民币兑港币波动导致人民币计价收益回撤超15%，且无企稳信号。

### 7.3 极端风险应急机制

1. **流动性断层应急**：单日跌幅>8%或3日累计跌幅>15%且成交额放大100%，T+0立即暂停所有加仓操作，T+1完成全维度风险评估，T+3若指数再跌超5%且南向资金持续净流出，执行清仓；企稳10个交易日且驱动因子修复后，方可重启建仓；
2. **黑天鹅事件应急**：地缘政治冲突、突发监管政策、美联储超预期加息等重大事件，5个交易日内暂停所有加仓操作；5-20个交易日指数累计跌幅>15%，减仓50%；跌幅>25%，执行清仓；20个交易日后视局势修复情况调整策略；
3. **数据质量风险应急**：核心指标出现多源数据偏差>10%、数据源中断、指数成分股重大调仓未完成校准，立即暂停所有建仓/加仓操作，仅可执行止盈止损，数据恢复且校验通过后方可恢复正常策略执行。
