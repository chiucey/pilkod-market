```markdown
## 四维属性定义

| 属性 | 中文名 | 初始值 | 上限 | 核心影响 |
|------|--------|--------|------|---------|
| VIG | 体魄 | 10 | 20 | 体力消耗/承受伤害 |
| MND | 心智 | 10 | 20 | 精神抵抗/古籍能力 |
| INS | 洞察 | 10 | 20 | 线索发现/识破谎言 |
| REL | 人脉 | 10 | 20 | NPC态度/情报获取 |

## 派生数值
- 体力值 = 体魄 × 10（用于探索、战斗消耗）
- 精神值 = 心智 × 10（用于使用古籍能力）
- 秘术等级 = 1-9（决定可解锁的古籍能力数量）
```

```markdown
|--------|-----------|-----------|------|
|  |  |  |  |

## 判定规则
- 好感度 > 85：完全信任
- 60-85：随机数单数同意，双数拒绝
- 35-59：直接拒绝
- < 35：警惕/敌意

## 好感度变化基准
| 行为 | 加成 | 减益 |
|------|------|------|
| 帮助NPC | +5~+15 | - |
| 提供情报 | +3~+10 | - |
| 关键时刻救助 | +10~+20 | - |
| 伤害NPC或其在意之人 | - | -20~-50 |
| 欺骗/背叛 | - | -15~-30 |
```
