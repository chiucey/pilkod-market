# Meimodu 世界书 JSON 格式详解

## 完整字段列表

```json
{
  "entries": {
    "001": {
      "comment": "世界设定/核心规则——每个参数独立一个 comment",
      "disable": false,
      "constant": true,
      "position": 1,
      "role": 0,
      "depth": "world",
      "order": "001",
      "probability": 100,
      "key": ["关键字", "触发词"],
      "keysecondary": [],
      "content": "这里是沉浸式的世界观描述内容。\n\n使用「」标注NPC对白。\n使用**加粗**强调重要概念。\n换行使用 \\n。",
      "uid": "001"
    }
  }
}
```

## 字段逐条说明

### comment
- **用途**：在世界书管理界面显示的中文名称
- **命名规范**：动作/参数类型 + 内容概览
- **示例**：`"核心设定/四层世界"`、`"NPC/周清源"`、`"场景/送仙桥古玩市场"`

### disable
- **用途**：是否激活该条目
- **可选值**：`false`（激活）/ `true`（禁用）

### constant
- **用途**：是否为常量条目（常驻内存）
- **建议**：核心设定设为 `true`，临时事件可设 `false`

### position
- **用途**：同一 `depth` 下的优先级，数字越小越优先
- **参考值**：
  - 1-10：核心规则/基础设定
  - 11-30：重要NPC/主要场景
  - 31-50：次要NPC/支线场景
  - 51+：物品/ Lore /背景信息

### role
- **用途**：条目角色类型（通常保持 0）

### depth（最重要字段）
- **用途**：决定AI调用该条目的优先级层级
- **可选值**：

| depth 值 | 含义 | 使用场景 |
|---------|------|---------|
| `world` | 世界层 | 核心设定、世界规则、基础架构 |
| `scenario` | 场景层 | 地点描写、情境设定、氛围营造 |
| `NPC` | NPC层 | 角色介绍、关系网络、背景故事 |
| `character` | 角色层 | 详细角色设定（含敏感信息） |
| `item` | 物品层 | 道具、文献、神器 |
| `lore` | 知识层 | 背景历史、宗教、知识信息 |

### order
- **用途**：同 `depth` 内的排序序号
- **建议**：三位数编号（001, 002...）便于插入新条目

### probability
- **用途**：AI 调用概率权重
- **参考值**：100（标准）、150（重要）、50（次要）
- **注意**：数值越高被调用频率越高，但非绝对

### key（核心）
- **用途**：触发该条目的关键词数组
- **设计原则**：
  - 精准 > 宽泛（"送仙桥" > "古玩市场" > "成都"）
  - 避免与高频通用词重复（"但是"、"突然"）
  - 每个条目不超过 5 个 key
  - 有层级关系时用具体词优先

**❌ 错误示例：**
```json
"key": ["人", "世界", "非常", "然后"]
```

**✅ 正确示例：**
```json
"key": ["送仙桥", "古玩市场", "天府基金会", "邪教"]
```

### keysecondary
- **用途**：次要触发词，不影响优先级
- **用途**：提供上下文关联，但不让 AI 主动检索

### content（最重要）
- **用途**：AI 进行角色扮演/世界观扩展时的参考内容
- **写作规范**：
  1. **100%沉浸式叙事**，无游戏系统语言
  2. **感官锚定**：每个场景至少2个感官维度
  3. **情绪先行**：先写氛围，再写细节
  4. **信息分层**：浅层可感知，深层需条件解锁
  5. **NPC对白规范**：`「………」` 或 `**「………」**`
  6. **长度参考**：场景 300-800字，NPC 200-500字，设定 100-300字

## depth 层级说明与条目数量规划

| depth | 建议条目数 | 内容占比 |
|-------|----------|---------|
| world | 5-15条 | 核心规则和基础设定 |
| scenario | 10-30条 | 所有场景和地点 |
| NPC | 10-30条 | 可交互角色 |
| character | 10-20条 | 详细角色信息（含敏感内容） |
| item | 5-15条 | 道具、文献、神器 |
| lore | 5-20条 | 历史、知识、背景故事 |

## JSON 输出自检表

- [ ] 所有 `comment` 字段不重复
- [ ] `uid` 与 `order` 保持一致（均为三位数字）
- [ ] `key` 无通用词（如"的"、"然后"）
- [ ] `content` 中无"玩家"、"角色"、"属性"、"判定"等系统语言
- [ ] JSON 语法正确（引号、逗号、花括号）
- [ ] 文件保存为 `.json` 编码 UTF-8
