# 叙事风格指南——暗域古卷式沉浸描写

## 一、场景描写四步法

```
第一步：情绪定调（1-2句）→ 用氛围词确定整体基调
第二步：视觉侵入（2-3句）→ 最突出的视觉细节，锚定画面感
第三步：感官叠加（1-2句）→ 加入听觉/嗅觉/触觉/触觉之一
第四步：悬念注入（可选，1句）→ 留下一个未解细节，引导玩家注意
```

## 二、感官词汇库

### 视觉
正面：幽光、烛火、斑驳、尘埃浮动、暗红
中性：阴影、空旷、剥落、裂隙
负面：漆黑、腐烂、血迹、扭曲、干涸

### 听觉
正面：低语、呢喃（邪性正面）、低沉的嗡鸣
中性：回声、脚步、空旷的回响、风声
负面：尖叫、破碎、撕裂、寂静（极致的安静）

### 嗅觉
正面：焚香（适度）、古籍、陈年纸墨
中性：潮湿、灰尘、泥土、铁锈
负面：血腥、腐败、枯萎、腐烂

### 触觉
正面：光滑（仅限器物）、温暖（仅限生命体）
中性：冰冷、粗粝、湿冷、黏腻
负面：僵硬、震颤、灼烧、刺痛、麻痹

## 三、NPC对白规范

格式：「……」
示例：
NPC说完这句话，眼神在身后的书架上停留了一秒。
**周清源**轻声说道：「……不要回头。」

| NPC类型 | 对白特征 | 示例 |
|--------|---------|------|
| 学者/教授 | 谨慎、停顿、引用 | 「根据《山海经》的记载……」 |
| 邪教信徒 | 狂热、引用教义 | 「这是归墟的召唤。」 |
| 普通人 | 直接、口语化 | 「哎，你别吓我！」 |
| 超自然存在 | 扭曲、非线性 | 「你能听到——你已经听到了——不是吗？」 |

## 四、邪教描写规范

教义结构（必须包含）：
1. 起源论：组织从哪里来
2. 核心信仰：相信什么
3. 仪式行为：做什么/怎么做
4. 入会机制：如何吸收新成员
5. 分层结构：谁统治/谁服从

## 五、冰山原则

可见信息（10%）：NPC说出口的、场景表面呈现的
暗示信息（30%）：道具细节、语气停顿、NPC回避的话题
隐藏信息（60%）：通过线索解锁，需要玩家主动调查

## 六、场景描写模板

### 深渊/超自然区域
光线___（颜色/强度）。
空气___（温度/重量/味道）。
你听到___（声音/节奏/异常）。
你的身体感觉到___（触觉/平衡/不适）。
你的理智在提醒你：这不是___（正常的边界）。
