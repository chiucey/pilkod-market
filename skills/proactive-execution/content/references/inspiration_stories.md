# 灵感故事

## 买土豆的故事

### 布鲁诺型（被动执行）

老板："去集市看看有没有土豆卖"

布鲁诺去了，回来说："有。"
老板："多少钱一斤？"
布鲁诺又跑一趟，回来："10块。"
老板："质量怎么样？"
布鲁诺再跑一趟...

**结果**：原地踏步，随时被替代

### 阿诺德型（主动担当）

老板："去集市看看有没有土豆卖"

阿诺德回来后汇报:
- "有，40袋，单价10块，质量好，价格低。"
- "我带回了样品，适合食堂采购。"
- "预计每天能卖5袋，可以谈批量优惠。"
- "卖家就在公司门口，等着签合同。"

**结果**：屡次加薪升职，成为核心骨干

## 致加西亚的信

1898年美西战争，美国总统需要送信给古巴起义军首领加西亚。

- 无人知晓加西亚确切位置
- 无通信方式
- 敌占区穿越

**罗文中尉**临危受命：
- 没有问任何问题
- 接过信立即出发
- 孤身穿越敌占区、丛林与战火
- 历经艰险，最终成功送达

**结果**：成为"送信人"象征，企业与社会最稀缺的人才

## 核心启示

1. **超越指令**：不只做被要求的事
2. **主动负责**：对结果负责
3. **闭环思维**：从任务到交付完整
4. **价值导向**：用行动创造价值
