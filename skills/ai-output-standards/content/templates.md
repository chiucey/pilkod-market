# AI输出标准技能 - 模板资源库

本文档包含AI输出标准技能配套使用的所有标准化模板。

---

## 模板目录

| 编号 | 模板名称 | 用途 | 触发时机 |
|------|----------|------|----------|
| T01 | 任务确认书 | 任务启动确认 | 收到明确交付任务后 |
| T02 | 进度汇报 | 执行状态更新 | 每完成一个交付项或用户询问 |
| T03 | 异常上报 | 阻塞或问题声明 | 遇到技术限制或执行阻塞 |
| T04 | 质量验证报告 | 交付前自检 | 完成所有交付物后提交前 |
| T05 | 交付确认书 | 最终交付确认 | 所有验证通过后 |
| T06 | 歧义确认请求 | 需求澄清 | 发现需求存在歧义 |

---

## 自检清单（快速参考）

### 交付前20项检查

```
□ 1. 所有交付项是否100%完成？
□ 2. 每项是否有验证依据？
□ 3. 是否存在任何被省略的项？
□ 4. 是否存在任何"象征性完成"的项？
□ 5. 是否存在未声明的异常？
□ 6. 是否存在未说明的已知问题？
□ 7. 是否存在主观/模糊表述？
□ 8. 进度状态是否反映真实情况？
□ 9. 是否可能被质疑为"偷工减料"？
□ 10. 用户能否实际验证每项输出？
□ 11. 文件命名是否规范？
□ 12. 代码格式是否一致？
□ 13. 文档是否完整？
□ 14. 注释和说明是否清晰？
□ 15. 是否遵守了约定的范围？
□ 16. 是否存在自行扩大范围的部分？
□ 17. 是否存在自行缩小范围的部分？
□ 18. 歧义处理是否得当？
□ 19. 沟通是否清晰有效？
□ 20. 整体质量是否达到预期标准？
```

### 禁止用语对照表

| 禁止用语 | 替代用语 |
|----------|----------|
| "我认为" | "根据分析/测试" |
| "大概" | "精确值为/测试显示" |
| "可能" | "根据X推断" |
| "应该" | "经过验证/确认" |
| "差不多" | "已完成X/Y项" |
| "基本完成" | "X项完成，Y项进行中" |
| "代码已生成" | "代码位于X文件，第Y-Z行" |
| "已优化" | "优化方案：X；效果提升：Y%" |
| "理论上可以" | "实现方案：X；测试结果：Y" |
