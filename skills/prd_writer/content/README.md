# PRD Writer 技能

> PRD需求文档编写助手，帮助产品经理快速生成结构化的产品需求文档

## 📦 安装方式

将 `prd_writer` 文件夹复制到 CoPaw 的 skills 目录：

```
C:\Users\{你的用户名}\.copaw\workspaces\{agent_id}\skills\
```

或在工作目录下创建：

```
{你的工作目录}\skills\prd_writer\
```

## 🚀 使用方法

### 在CoPaw中使用

当用户提到以下关键词时，本技能将被触发：

| 触发词 | 示例 |
|--------|------|
| 写PRD | "帮我写一个PRD" |
| 生成PRD | "生成产品需求文档" |
| 产品需求文档 | "需要一份产品需求文档" |
| 需求文档 | "帮我写需求文档" |
| PRD模板 | "给我一个PRD模板" |

### 交互流程

1. **用户提出需求** → 技能被激活
2. **确认信息完整性** → 如信息不完整，主动询问：
   - 产品/模块名称
   - 核心功能
   - 目标用户
   - 数据来源
   - 外部依赖
3. **生成PRD** → 基于模板生成Markdown文档
4. **输出结果** → 保存到工作目录

## 📁 目录结构

```
prd_writer/
├── SKILL.md          # 技能说明文件（必须）
├── README.md          # 本说明文件
└── scripts/
    └── generate_prd.py  # PRD生成脚本（可选）
```

## 📝 使用示例

### 示例1：快速生成PRD

**用户输入：**
```
帮我生成一个「工位信息管理」的PRD，包含查询、筛选、绑定管理功能
```

**技能响应：**
```
✅ 正在为您生成「工位信息管理」PRD...

请确认以下信息：
1. 数据来源是哪个系统？
2. 是否需要权限控制？
3. 是否需要导出功能？

[用户回答后]
✅ PRD文档已生成：E:\copawws\工位信息管理PRD.md
```

### 示例2：使用Python脚本

```bash
# 基于模板生成空白PRD
python scripts/generate_prd.py --name "用户管理" --output "E:/copawws"

# 输出
# ✅ PRD文档已生成: E:/copawws/用户管理PRD.md
```

## 🎯 核心功能

| 功能 | 说明 |
|------|------|
| 结构化模板 | 包含核心章节（0-4）+ 可选章节（5-9） |
| Mermaid图表 | 支持流程图、架构图、时序图等 |
| 工程导向 | 偏工程方案，可直接给研发使用 |
| 主动补全 | 对不清晰需求，主动假设并说明 |
