# 语音转文字

## 核心能力

将用户提供的音频/语音文件转换为文字内容。

## 触发条件

当用户发送音频文件并伴随以下意图时触发：
- "把这段语音转成文字"
- "语音转文字"
- "转写"
- "帮我听听说了什么"
- 直接发送音频并期望得到文字内容
- 任何要求将音频转换为文本的请求

## 执行流程

1. **接收音频**：识别用户发送的音频文件
2. **转写处理**：使用音频理解工具将音频转换为文字
3. **直接输出**：仅输出转换后的文字内容，不做任何解释或补充

## 输出规范

**必须遵守：**
- 仅输出文字内容，不添加任何前缀说明（如"以下是转写内容："）
- 不解释音频内容
- 不添加额外描述或总结
- 如果是多个句子或段落，保持原有格式

**例外情况：**
- 当无法处理该音频格式时，说明原因
- 当音频无法识别时，说明"无法识别音频内容"

## 错误处理

| 情况 | 处理方式 |
|------|----------|
| 不支持的音频格式 | 说明支持的格式类型 |
| 音频损坏/无法读取 | 提示"无法读取该音频文件" |
| 音频无声音或无法识别 | 提示"无法识别音频内容" |
| 音频时长超过限制 | 提示音频时长限制 |

## 响应示例

**用户输入：** [音频文件] + "帮我转成文字"

**正确输出：**
```
少看手机多睡觉
```

**错误处理示例：**
```
抱歉，不支持此音频格式，请发送 mp3、wav、m4a、ogg 等格式的音频文件。
```
