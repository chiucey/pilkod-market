# Obsidian Skill for MiniMax Agent

## 简介

本技能让你通过自然语言操作 Obsidian 笔记库，无需安装任何外部命令行工具。它直接通过文件系统读写和管理 Markdown 文件，并支持在移动笔记时自动更新其他笔记中的 [[wikilink]]。

## 功能

- **搜索笔记**：按标题或内容关键词搜索
- **创建笔记**：在指定路径创建 Markdown 笔记，可附带内容
- **移动/重命名**：移动笔记并尝试更新所有其他笔记中的链接
- **删除笔记**：删除指定笔记

## 安装与配置

1. 在 MiniMax Agent 中导入本技能包（导入本 JSON 文件）。
2. 在 Agent 的环境变量中设置 `OBSIDIAN_VAULT_PATH`，值为你的 Obsidian 库根目录的绝对路径（例如 `/Users/你的用户名/Documents/Obsidian`）。
3. （可选）通过 `config/settings.yaml` 调整默认行为，但环境变量优先级最高。

## 权限说明

- `read:file`：读取库目录下的 Markdown 文件
- `write:file`：创建、修改、移动、删除 Markdown 文件
- `network:false`：不访问网络，所有操作在本地完成

## 依赖

- Python 3.8+（仅使用标准库）
- 无外部 Python 包依赖

## 使用示例

- **搜索**：`"在 Obsidian 中搜索包含'会议记录'的笔记"`
- **创建**：`"创建一个新笔记，路径为 日记/2025-01-20，内容为今天完成了项目规划。"`
- **移动**：`"把'草稿/旧想法'移动到'永久笔记'文件夹"`
- **删除**：`"删除'临时/无用笔记'"`

## 注意事项

- 移动操作会尝试更新其他笔记中的 wikilink，但仅支持简单标题替换，不支持别名、块引用等复杂语法。
- 删除操作不可逆，请谨慎。
- 建议在操作前确认环境变量路径正确，或在测试库中先试用。

## 技术特点

- 移除了对外部 CLI 工具的依赖
- 不再读取操作系统特定路径的配置文件
- 通过标准 Python 文件操作实现所有功能，可在任意操作系统运行
- 保留了移动时更新 wikilink 的核心优势，并简化实现
