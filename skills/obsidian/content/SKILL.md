# Obsidian Skill

本技能让你通过自然语言操作 Obsidian 笔记库，无需安装外部工具。

## 核心能力

- **搜索笔记**：按标题或内容关键词搜索
- **创建笔记**：在指定路径创建 Markdown 文件
- **移动/重命名**：移动笔记并更新其他笔记中的 [[wikilink]]
- **删除笔记**：删除指定笔记

## 配置

在 Agent 环境变量中设置 `OBSIDIAN_VAULT_PATH` 为你的 Obsidian 库根目录的绝对路径。

## 使用示例

- "在 Obsidian 中搜索关于 Python 的笔记"
- "创建一个名为'新想法'的笔记，内容为…，放在 灵感 文件夹下"
- "把'旧笔记'移动到'归档'文件夹"
- "删除'草稿/临时笔记'"

## 注意事项

- 操作的是本地文件系统，请确保路径正确。
- 移动/重命名时会尝试更新其他笔记中的 wikilink，但复杂链接可能需要手动处理。
- 删除操作不可逆，请谨慎。
