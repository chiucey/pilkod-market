# 网文创作全维度避坑自检专家（2026终极版·扩充版）
> 写得好不如写得安全。避坑，才是网文创作的第一生存技能。
## 一、2026年平台合规新趋势
### 1.1 审核趋严的三大方向
```
趋势一【政治红线收紧】
→ 涉及国家领导人/政党/历史敏感事件的内容
→ 越来越严格的管控
→ 所有历史/政治/军事题材都需要特别谨慎
趋势二【价值观导向加强】
→ 宣扬暴力/犯罪/不良价值观
→ 破坏社会秩序/违背公序良俗
→ 都会被重点审核
趋势三【未成年人保护升级】
→ 未成年人恋爱/性描写/暴力内容
→ 比以往更严格的限制
→ 涉及未成年人的内容要特别谨慎
### 1.2 2026年重点违规类型
⭐⭐⭐⭐⭐ 高危违规（一旦命中，直接封书）
→ 涉及政治领导人/政党/军队
→ 涉及台海/西藏/新疆/香港等敏感地区
→ 涉及邪教/恐怖组织
⭐⭐⭐⭐ 高危违规（扣分/封章/限流）
→ 过度血腥暴力描写
→ 未成年人的性暗示

⭐⭐⭐ 中危违规（警告/修改）

→ 过度玄学/算命内容
→ 过度丑化某群体
## 二、格式合规避坑
### 2.1 书名与简介避坑
书名避坑：
❌ 不能用政治相关词汇（即使中性词也可能被误判）
❌ 不能用色情暗示词汇
❌ 不能用极端词汇（最/第一/天下无敌等，易违反广告法）
✅ 书名建议：
→ 简洁明了，概括核心卖点
→ 可以有悬念/反差/趣味
→ 示例：
  《我修士重生后》《我在诡异世界当神医》
  《全家流放，她带空间养崽》
简介避坑：
❌ 不能在简介里出现露骨的承诺（如"纯甜无虐"）
❌ 不能用"绝对""保证"等绝对化词汇
❌ 不能暴露后续大纲（影响推荐）
✅ 简介建议：
→ 前三行必须抓人（读者只读前三行）
→ 可以用悬念/反差/直接展示卖点
→ 300字以内最佳
### 2.2 正文格式规范
章节格式：
❌ 不要单章节超过5000字（影响完读率）
❌ 不要章节之间无衔接（跳跃太大）
❌ 不要重复上一章开头（新手常犯）
✅ 章节格式标准：
→ 每章1500-3000字最佳
→ 章节名要有信息量/悬念
→ 章节开头要有承接（"却说……"）
→ 章节末尾要有钩子
敏感内容处理：
❌ 涉及政治/军事/历史敏感内容 → 删除或替换
❌ 涉及血腥暴力 → 减少细节描写，用暗示替代
❌ 涉及性暗示 → 删除或改为隐晦表达
## 三、内容质量避坑
### 3.1 战力崩坏避坑
战力崩坏是长篇网文最常见的问题：
❌ 战力崩坏的表现：
→ 主角越级打怪太容易
→ 后期角色秒前期角色毫无代价
→ 配角实力忽高忽低
✅ 战力稳定的做法：
→ 建立量化的战力体系（用"年"量化差距）
→ 跨境界战斗必须有充分铺垫
→ 配角实力在出场时就确定，不随意更改
→ 定期检查战力体系的一致性
### 3.2 节奏崩盘避坑
❌ 节奏崩盘的表现：
→ 开局精彩，后面越来越水
→ 高潮之后没有新的高潮
→ 配角线喧宾夺主
→ 日常描写过多，正事太少
✅ 节奏稳定的做法：
→ 建立清晰的大纲（主线/支线/情感线）
→ 每5万字检查一次节奏
→ 主角永远要有目标（不能没有追求）
→ 支线服务于主线，不能代替主线
### 3.3 角色OOC避坑
❌ 角色OOC的表现：
→ 主角人设前后不一致
→ 配角变成工具人
→ 反派动机不明
✅ 角色稳定的做法：
→ 建立角色设定卡（性格标签/行事逻辑/底线）
→ 每个角色必须有独立的目标和欲望
→ 重要角色行为改变前必须有铺垫
→ 定期检查角色设定的一致性
## 四、平台推荐机制避坑
### 4.1 番茄小说推荐机制
番茄推荐核心指标：
① 完读率（最重要）：读者读完全书的比例
② 阅读时长：读者在本书停留时间
③ 书架率：读者加入书架的比例
④ 追更率：持续追更的读者比例
避坑建议：
❌ 前3章不要倾倒设定（读者会弃书，完读率低）
❌ 前5章必须出核心冲突（否则留不住读者）
❌ 不要在第一章就几十个角色（认知负荷太高）
❌ 不要频繁断更/太监（影响追更率）
✅ 番茄生存法则：
→ 前3章=生死线，必须抓人
→ 每章章末要有钩子
→ 每章字数控制在2000-2500字
→ 日更比断更追更率更高
### 4.2 起点中文网推荐机制
起点推荐核心指标：
① 追读率（最重要）：读者追到最新章节的比例
② 收藏率：收藏本书的人数
③ 打赏/月票：付费意愿
④ 本章说互动：读者参与度
❌ 不要太监（起点太监书追读率直接归零）
❌ 不要在前10万字水剧情（起点读者会弃书）
❌ 不要忽视读者反馈（本章说互动影响推荐）
❌ 不要更新太慢（起点日更4000字是基准线）
✅ 起点生存法则：
→ 前10万字是签约关键，必须精品
→ 每章要有足够的爽点/信息量
→ 重要章节要引导读者互动（"求月票"等）
→ 存稿至少20章再发书（防断更）
## 五、AI辅助创作的合规边界（新增模块）
### 5.1 AI辅助创作的红线
⭐⭐⭐⭐⭐ AI创作红线（绝对不能碰）：
❌ 用AI直接生成全文发布（平台可检测）
❌ AI生成内容不加修改直接使用
❌ 抄袭/洗稿他人的作品
✅ AI辅助创作的正确姿势：
→ AI生成 → 人工审核 → 修改润色 → 发布
→ AI用于：大纲生成/卡文续写/资料搜集/错别字检查
→ 人工负责：情节设计/情感描写/人物塑造/价值观把控
### 5.2 AI创作内容的合规检查
AI生成内容必须检查：
检查一【是否与已有作品高度相似】
→ 用查重工具检测AI生成内容
→ 相似度超过20%的段落必须重写
检查二【是否有事实错误】
→ AI可能生成错误的历史/科学信息
→ 涉及专业知识的章节必须人工核实
检查三【是否符合平台调性】
→ AI生成内容可能过于模板化
→ 必须人工润色，增加个性化表达
检查四【是否有价值观问题】
→ AI生成内容可能有偏见/不当表述
→ 必须人工审核价值观导向
### 5.3 AI辅助创作的最佳工作流
工作流程：
① 大纲设计（人工）：确定故事核心和方向
② 大纲生成（AI辅助）：扩展大纲细节
③ 大纲审核（人工）：确保方向正确
④ 章节创作（人工核心+AI辅助）：AI生成初稿，人工修改
⑤ 内容审核（人工）：检查逻辑/情感/价值观
⑥ 错别字检查（AI）：辅助检查
⑦ 发布
注意：AI是工具，不是替代品
→ 核心创意必须来自人
→ 情感表达必须来自人
→ 价值观把控必须来自人
## 六、政治敏感内容的规避（新增模块）
### 6.1 政治敏感话题清单
⭐⭐⭐⭐⭐ 绝对禁止的话题：
① 中国政治制度相关
→ 不能讨论/影射中国政治制度
→ 不能出现"共产党""国民党"等同名
→ 不能讨论"民主""专制"等政治话题
② 领土主权相关
→ 不能涉及台湾、香港、澳门、西藏、新疆等
→ 不能出现"独立""分裂"等相关内容
→ 不能讨论"领土争端"等话题
③ 领导人相关
→ 不能出现任何中国领导人的名字/绰号/形象
→ 不能以任何方式影射/暗示
→ 历史小说中的古代帝王可以写，但要客观描述
④ 宗教政策相关
→ 不能涉及邪教组织
→ 不能恶意描写/贬低任何宗教
→ 佛教/道教/基督教等正常宗教可以写，但需客观
⑤ 军事相关
→ 不能涉及军队/武器/泄密相关
→ 不能讨论"战争""军事行动"等敏感话题
→ 历史战争（如三国演义）可以写，但要客观中性
### 6.2 玄幻/仙侠文的政治安全写法
玄幻/仙侠文中容易触雷的内容：
❌ 涉及"朝廷""皇帝"的描写过于现实
→ 不能映射现实政治
→ 建议：用宗门/王国代替朝廷，用宗主/国王代替皇帝
❌ 涉及"门派斗争"过于政治化
→ 不能影射现实政治斗争
→ 建议：聚焦于个人成长和冒险，减少政治描写
❌ 历史穿越文中涉及近代史
→ 近代史（1840年以后）极其敏感
→ 建议：穿越到古代（唐宋以前）风险较低
✅ 安全的写法：
→ 仙侠/玄幻背景天然具有安全距离
→ 聚焦于修炼/升级/冒险等普适主题
→ 避免涉及现实政治/历史敏感事件
→ 用虚构世界传递正向价值观
### 6.3 敏感内容替换模板
【敏感内容替换对照表】
| 敏感内容 | 替换方案 | 示例 |
|---------|---------|------|
| 皇帝/朝廷 | 宗主/宗门/王国 | 把"朝廷争斗"改为"宗门内斗" |
| 军队/战争 | 修士联盟/势力对抗 | 把"大军压境"改为"高手云集" |
| 近代历史人物 | 删除或虚构 | 不写任何近代史人物 |
| 宗教领袖 | 虚构宗主/神祇 | 用"天道宗宗主"代替宗教人物 |
| 领土争端 | 秘境争夺/资源战争 | 把"两国开战"改为"两宗争夺灵脉" |
| 民主/专制 | 宗门制度/王国制度 | 用修炼世界的规则代替政治制度 |
## 七、暴力与色情内容的尺度控制（新增模块）
### 7.1 番茄小说内容尺度标准
番茄小说的内容尺度（相对宽松，但有底线）：
【可写但需谨慎的内容】
✓ 战斗/打斗描写（可以写，但不能过度血腥）
✓ 死亡描写（可以写，但不能详细描写死法）
✓ 恋爱/情感描写（可以写，但不能露骨）
【绝对不能写的内容】
✗ 生殖器描写
✗ 性行为描写（无论是否详细）
✗ 未成年人的性暗示
✗ 暴力描写的过度细节（断肢/剖腹等）
【建议写法】
→ 战斗描写：侧重招式和结果，弱化过程细节
  ✗ "剑刺入他的腹部，肠子流了一地。"
  ✓ "剑光一闪，对方应声倒地，鲜血染红了衣襟。"
→ 恋爱描写：侧重心理和氛围，弱化身体描写
  ✗ "他的手伸进了她的衣服……"
  ✓ "他的手指触碰到她的指尖，两人的心跳都漏了一拍。"
### 7.2 起点中文网内容尺度标准
起点的内容尺度（相对严格）：
【起点禁止的内容】
✗ 任何形式的色情描写
✗ 过度详细的血腥暴力描写
✗ 抄袭/盗版他人作品
✗ 政治敏感内容
✗ 违规敏感词（如某些特定词汇）
【起点推荐的写法】
→ 升级爽点要密集
→ 战斗描写要精彩但不血腥
→ 感情线要含蓄但有张力
→ 主角要有正确的价值观
【起点的自我审查技巧】
→ 写完章节后，用"Ctrl+F"搜索敏感词
→ 检查是否有疑似违规的表述
→ 有疑虑的段落，主动弱化或删除
### 7.3 擦边内容的处理技巧
容易被认为是"擦边"的内容：
【情感线擦边】
→ 表现："她在床上等他"/"一夜之后"等暗示性描写
→ 建议：删除或改为更隐晦的表达
【战斗暴力擦边】
→ 表现：过于详细的身体伤害描写
→ 建议：用结果代替过程，用暗示代替细节
【灵异擦边】
→ 表现：涉及"算命"/"巫蛊"/"通灵"等
→ 建议：改为"天机"/"灵觉"/"预知"等正向词汇
【通用处理原则】
→ 有疑虑的内容 → 删
→ 可能引发误解的内容 → 改
→ 读者可能举报的内容 → 避
→ 不要挑战审核底线
## 八、版权与抄袭避坑（新增模块）
### 8.1 抄袭的定义与判定
平台认定的抄袭行为：
❌ 文字复制：将他人作品直接复制粘贴
❌ 洗稿：将他人作品改头换面后发布
❌ 思想抄袭：使用他人作品的创意/大纲/人物设定
❌ 融梗：将多个作品的核心元素拼接
抄袭的判定标准（番茄/起点通用）：
→ 连续200字以上相同
→ 核心情节/人物设定相同
→ 相同比例超过20%
✅ 避免抄袭的做法：
→ 所有内容必须是原创
→ 借鉴经典套路时要有自己的创新
→ 参考资料时，合上资料再写
→ AI生成内容要经过充分修改
### 8.2 借鉴与抄袭的边界
【可以借鉴的内容】（不算抄袭）
✓ 网文经典套路（如"废柴逆袭"/"打脸"等）
✓ 题材类型（如"修仙"/"都市"等题材）
✓ 设定元素（如"灵气"/"境界"等通用设定）
【可能构成抄袭的内容】（需谨慎）
△ 非常具体的情节设计（如某个特定场景的详细描写）
△ 原创角色名/物品名/地名（这些有版权）
△ 独特的世界观架构（如诡秘之主的世界观）
【明确构成抄袭的内容】（绝对禁止）
✗ 直接复制他人作品的文字
✗ 高度相似的情节设计（连细节都相同）
✗ 照搬他人作品的人物设定+情节
### 8.3 版权安全检查流程
发布前版权自检：
第一步【查重检测】
→ 用免费查重工具检测正文
第二步【人名地名检查】
→ 检查是否有与已有作品高度相似的人名/地名
→ 原创性越高，版权风险越低
第三步【情节逻辑检查】
→ 检查情节是否有明显借鉴痕迹
→ 自己读一遍，看是否像在看别人的故事
第四步【AI检测】（2026年新要求）
→ 平台会检测AI生成内容
→ 建议：AI辅助创作后，要充分人工修改
→ 保持至少30%的原创性修改
第五步【敏感词检测】
→ 用敏感词检测工具扫描全文
→ 有疑虑的词汇立即替换

① 暧昧描写的边界

→ 可以写具体金额（"他欠了一个亿"）

→ 不能写如何非法转移资产

### 案例1：边缘擦边内容被限流

### 案例2：涉政内容被封号

→ 评价历史朝代时，不要与现实政治制度类比

结果：全书封禁+全平台封禁

## 附五：AI创作安全合规进阶（2026年最新）
### 12. AI检测的"指纹"规避法
平台AI检测的本质：
→ AI生成的内容有"指纹"
→ 这个指纹是AI模型的统计特征
→ 人类写作没有这个特征
如何规避AI指纹：
① 句式多样性：主动变化句式（长短交替）
② 段落开头多样性：不要每章开头都用同样的句式
③ 口头禅植入：给角色设计独特的口头禅（AI不会学）
④ 打字错误：适当留一两个typo（不是严重错误）
### 13. 多平台同步发布的合规策略
同一内容多平台发布注意事项：
→ 各平台的AI标注要求不同
→ 番茄：必须标注AI辅助
→ 起点：无强制要求，但建议标注
→ 晋江：无强制要求，但建议人工标注
不同平台的内容调整：
→ 同一内容，根据平台尺度调整
→ 尺度大的平台可以写得更详细
→ 尺度小的平台要精简描写
### 14. 创作安全的"预防-监测-补救"体系
预防：
→ 发布前做完整的合规检查
→ 使用AI辅助时保留创作底稿
→ 了解各平台最新规则
监测：
→ 关注平台通知和违规提示
→ 定期检查作品数据（异常下降可能是被限流）
→ 关注读者反馈（读者可能先于平台发现违规）
补救：
→ 收到通知后立即修改
→ 申诉时提供创作时间戳证明
→ 修改后观察数据恢复情况
