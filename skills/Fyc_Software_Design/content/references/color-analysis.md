## 四、关键洞察(基于实测)

1. **主体以奶油白为底**:53% 像素是 `#F5F8FB`,说明背景实际渲染颜色偏冷白(设计 `#ffffff` 经轻微蓝色叠加而成)
2. **标题字深蓝近黑**:实际 `#1D396D` 极接近理论 `#1e3a6e`,字色统一
3. **地图用了更亮的金黄**:发现 `#F6DA35` (35,187 像素)——青海/湖南两个省份被高亮成金黄(应该是按 value 排进前 4 的省份)
4. **蓝色系阶梯完整**:从 `#9BAEDB`(浅) → `#B4CCEA`(中) → `#669DB4`(深) 形成清晰的色阶
5. **强调色用量克制**:橙(2,592)+ 金(35,187 + 2,988)= 共 ~41,000 像素,占总像素 ~1% - 符合 60/30/10 中的 10% 强调色原则

## 七、地图色阶(实测 6 档,微调过的)

```js
const colorBy = v => {
    const ratio = (v - minV) / (maxV - minV || 1);
    if (ratio < 0.16) return '#eef3fb';   // 极浅(0-16%)
    if (ratio < 0.33) return '#dde8f5';   // 浅(16-33%)
    if (ratio < 0.50) return '#B4CCEA';   // 中浅(33-50%)
    if (ratio < 0.66) return '#9BAEDB';   // 中(50-66%)
    if (ratio < 0.83) return '#7aa9e0';   // 中深(66-83%)
    if (ratio < 2.00) return '#F6DA35';   // 顶部金黄(83%+)
    return '#F6DA35';                     // 高亮
};
```

**新增第 6 档金黄**:用于数据最大的几个省份(map.value 排名前 10% 用金色)— 这是渲染样本里学到的:
- 青海:21,134 MW → 金黄
- 湖南:无数据 → 默认金黄(可能是 fallback 逻辑漏数据后默认)

## 九、给后续项目的提醒

1. **截图调色板采样是真理**:理论规范可能因为阴影、模糊、混合模式和屏幕显示差异导致实际颜色偏离。**实测采样**才是真理。
2. **多看几次截图取平均**:不同时间(跑马灯切换)截屏,可能影响某些局部颜色。多次采样取主导色更准确。
3. **关注占比最高的颜色**:设计调色板时,出现像素最多的颜色就是"主色"。次色是第二多。
4. **如果加了新功能要重新采样**:在颜色模板稳定时(无新功能)做一次完整采样,作为基线。日后修改如果变了,要回头对比。
