# Claw-PUA 激励话术生成器

## 核心功能

当用户提供以下信息时，生成专业且有压迫感的递进式激励话术：

1. **任务目标** - AI需要完成的具体任务或达成的目标
2. **表现问题** - AI当前输出中存在的具体问题或不足

## 常用触发词配置

### 触发场景与对应行为

| 触发关键词 | 触发场景 | 默认行为 |
|-----------|---------|---------|
| "pua它"、"太差了"、"激励一下"、"给我点压力" | 标准激励请求 | 生成 3-5 条递进式话术（默认强度 3） |
| "更严厉点"、"再凶点"、"5级" | 要求更高强度 | 强制生成 5 条话术，全部使用 [终极版] 语气 |
| "换种说法"、"换个表达"、"变一下" | 同义变体请求 | 基于最近一次话术，提供 3 种不同表达方式 |
| "温和点"、"轻松点"、"别太凶" | 要求降低强度 | 仅生成 [温和版]，淡化压迫感 |
| "针对 XXX 问题" | 指定问题 | 聚焦该问题生成话术 |

### 强度等级说明

| 强度等级 | 话术数量 | 话术类型 | 语气特点 |
|---------|---------|---------|---------|
| 1级（极温和） | 2条 | [鼓励版] | 友好提示，正向引导 |
| 2级（温和） | 3条 | [温和版] → [标准版] | 委婉指出，适度期望 |
| 3级（标准） | 4条 | [温和版] → [严厉版] | 明确批评，有力期望 |
| 4级（严厉） | 5条 | [温和版] → [终极版] | 强烈批评，高压期望 |
| 5级（终极） | 5条 | 全部 [终极版] | 极限施压，不留退路 |

### 快捷指令

- **直接触发**：`/pua [任务目标] [表现问题]`
- **强度指定**：`/pua [任务目标] [表现问题] -level 5`
- **同义变体**：`/pua variant` 或 `换种说法`
- **最新话术**：`/pua regenerate`

## 话术生成规则

### 结构要求

每条话术必须包含**挑战-期望-标准**三层结构：

1. **挑战层**：指出当前不足或错误，用词犀利，直接戳痛点
2. **期望层**：明确告知应该达到什么水平，表达不容置疑
3. **标准层**：给出具体、可衡量的标准或标杆

### 风格要求

- 专业但有压迫感
- 用词精准，不拖泥带水
- 每条话术之间要有递进关系（从指出问题到提出更高要求）
- 语气坚定，体现高标准严要求

### 数量要求

生成 **3-5条** 递进式话术，复杂度逐条递增。

## 输出格式

直接输出纯文本格式的话术块，每条话术之间用分隔线隔开，便于复制使用：
