# A股股票回购价值分析工具 v2.0.0

## 核心目标

通过调用Tushare数据库，筛选近7天内发布回购执行公告的上市公司，汇总本次回购方案下的全部执行数据，计算溢价率，**仅输出溢价率>1（即回购均价>当日股价）的标的**，为投资决策提供依据。

## 数据来源与接口

| 数据 | Tushare接口 | 说明 |
|------|------------|------|
| 回购执行公告 | `repurchase` | ann_date=起始日期，end_date=截止日期 |
| 股票名称 | `stock_basic` | 批量获取公司简称 |
| 当日股价 | `daily` | 取最近交易日收盘价 |
| 交易日判断 | `trade_cal` | 确定股价基准日 |

---

## 筛选与匹配规则

**步骤1：拉取近7日公告**
- 以查询当日为基准，回溯7个自然日，调用 `repurchase` 接口

**步骤2：过滤执行状态**
- 仅保留 `proc ∈ {实施, 完成}` 且 `vol > 0` 的记录
- 排除：预案、提议、股东大会通过、停止（vol=0无执行）

**步骤3：按公司聚合并汇总**
- 同一上市公司同一回购方案下的所有执行记录 → 汇总计算
- 不混淆历史回购方案，严格以最近一次公告对应的方案为准
- 汇总字段：累计回购股数、累计回购金额

**步骤4：获取当日股价**
- 优先取查询当日收盘价；若当日未交易，取最近交易日收盘价
- 股价获取日期标注在备注列

---

## 指标计算规则

| 指标 | 计算公式 | 单位 |
|------|---------|------|
| 本次回购累计股数 | Σ各期执行股数 | 股 |
| 本次回购累计金额 | Σ各期执行金额 | 元 |
| 回购均价 | 累计回购金额 ÷ 累计回购股数 | 元/股 |
| 当日股价 | 最近交易日收盘价 | 元/股 |
| 溢价率 | 回购均价 ÷ 当日股价 | 纯比例（>1表示溢价）|

**筛选条件（硬性）**：溢价率 **> 1**（即回购均价高于当日股价，存在回购溢价） → 纳入结果

## 输出字段（Excel表格）

| 字段 | 说明 |
|------|------|
| 股票代码 | A股标准代码（沪/深/北交所） |
| 股票名称 | 全称或简称 |
| 本次回购累计金额 | 单位：元，汇总本次方案所有执行记录之和 |
| 本次回购累计股数 | 单位：股，汇总本次方案所有执行记录之和 |
| 回购均价 | 单位：元/股，=累计金额÷累计股数，保留4位小数 |
| 当日股价 | 单位：元/股，取最近交易日收盘价 |
| 溢价率 | =回购均价÷当日股价，保留4位小数；>1表示溢价 |
| 方案价格区间 | 回购方案上限价~下限价（high_limit~low_limit） |
| 备注 | 股价日期（若非当日）；数据缺失说明 |

---

## 数据校验

- 计算完成后校验：累计金额 ≈ 回购均价 × 累计股数（允许浮点误差±1%）
- 股票代码与名称一一校验，确保匹配
- vol=0 或 amount=0 的记录不纳入计算
- 若某公司执行记录缺失关键字段，在备注中标注"数据缺失"
