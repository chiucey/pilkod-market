# 视频理解工具 (Video Understanding Tool)

## 功能概述

智能分析视频内容，提取核心知识点、可复用技巧、爆款元素和结构模式。

## 输入方式

### 方式1：视频URL链接
支持平台：
- 抖音 (douyin.com)
- B站 (bilibili.com)
- 快手 (kuaishou.com)
- 小红书 (xiaohongshu.com/xhs.cn)
- YouTube (youtube.com)
- 微博视频 (weibo.com)
- 微信公众号视频
- 其他主流视频平台

### 方式2：本地视频文件
支持格式：mp4, avi, mov, mkv, webm, flv

## 执行流程

### Step 1: 视频获取
1. **URL链接**：使用 `videos_understand` 工具分析视频内容
2. **本地文件**：直接使用 `videos_understand` 工具分析

### Step 2: 内容分析
调用 `videos_understand` 工具，传入视频URL或本地文件路径，并指定分析提示词：

**提示词模板**：
```
请对这段视频进行深度内容分析，包括：

1. **内容概述**：用3-5句话概括视频核心内容
2. **目标受众**：分析视频的目标观众群体
3. **核心知识点**：提取3-5个关键知识点或信息点
4. **可复用技巧**：拆解视频中可复用的操作技巧或方法
5. **结构分析**：分析视频的叙事结构（开场、内容展开、结尾）
6. **爆款元素**（如适用）：分析视频吸引人的元素（标题、封面、内容节奏、情绪点）
7. **关键金句**：摘录2-3句视频中的核心观点或精彩表达
8. **学习建议**：给观众的学习或行动建议

请用结构化的Markdown格式输出分析结果。
```

### Step 3: 结果呈现
以结构化Markdown格式输出分析报告。

## 工具调用示例

### URL分析
```json
{
  "video_info": [
    {
      "url": "https://www.bilibili.com/video/BVxxx",
      "prompt": "请进行深度内容分析，提取核心知识点、可复用技巧和爆款元素"
    }
  ]
}
```

### 本地文件分析
```json
{
  "video_info": [
    {
      "file": "/path/to/video.mp4",
      "prompt": "请进行深度内容分析，提取核心知识点、可复用技巧和爆款元素"
    }
  ]
}
```

## 注意事项

1. **URL兼容性**：优先使用直接视频URL，避免需要登录的内容
2. **文件大小**：本地文件建议不超过500MB以确保分析效率
3. **分析深度**：根据视频长度调整分析详细程度
4. **多语言**：支持中文、英文等主流语言的视频分析
5. **隐私保护**：用户上传的本地文件仅用于当次分析，不保存

## 适用场景

- 学习资料整理：将视频教程转化为结构化笔记
- 内容创作参考：分析爆款视频学习其成功要素
- 竞品分析：分析同类视频找出差异化机会
- 知识沉淀：将视频内容转化为可检索的文本资料
- 技巧提炼：快速提取视频中的实操技巧
