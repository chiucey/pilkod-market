# 风险管理手册

## 一、风险管理体系

### 核心理念
> "保住本金是第一要务" —— 沃伦·巴菲特
>
> "投资的第一原则是：不要亏损。第二原则是：永远记住第一原则。" —— 沃伦·巴菲特

### 风险管理的重要性
- **数学角度**：亏损50%需要100%收益才能回本
- **概率角度**：控制亏损才能在长期中存活
- **心理角度**：大幅亏损会影响判断，导致更多错误

## 二、仓位管理

### 基本仓位原则
| 市场环境 | 建议仓位 | 操作策略 |
|----------|----------|----------|
| 大涨行情 | 80-100% | 满仓进攻 |
| 震荡行情 | 50-70% | 半仓轮动 |
| 大跌行情 | 20-40% | 轻仓防御 |

### 动态仓位调整
```
if 市场连续上涨：
    逐步减仓至70%
elif 市场高位震荡：
    保持50-60%
elif 市场出现明显下跌信号：
    减仓至30%以下
```

### 单股仓位控制
- **最大单股仓位**：总资金30%
- **最小建仓单位**：1手（100股）
- **加仓原则**：盈利加仓，不轻易补仓亏损股

## 三、止损体系

### 止损类型

#### 1. 硬止损（必须执行）
| 条件 | 操作 | 原因 |
|------|------|------|
| 单日亏损-5% | 次日开盘清仓 | 防止进一步亏损 |
| 连续3日未盈利 | 评估换股 | 市场不配合 |
| 持仓股票跌停 | 次日开盘减半 | 流动性风险 |

#### 2. 软止损（建议执行）
| 条件 | 操作 | 原因 |
|------|------|------|
| 跌破重要均线 | 减仓50% | 趋势可能反转 |
| 大盘连续走弱 | 降低仓位 | 系统性风险 |
| 持仓股票破位 | 减仓观望 | 技术性走弱 |

#### 3. 涨幅止盈
| 盈利幅度 | 操作建议 |
|----------|----------|
| +10% | 可考虑减半仓 |
| +15% | 建议减仓30% |
| +20% | 建议减仓50% |
| +30%以上 | 逐步清仓 |

### 止损执行流程
```
止损触发 → 冷静5分钟 → 执行止损 → 记录复盘 → 分析原因
```

## 四、交易纪律

### 十大交易纪律
1. **绝不逆势加仓摊平成本**：亏损时加仓是重大错误
2. **不设置不合理价格**：大幅低买高卖无法成交
3. **不追涨停板**：涨停板买入风险极大
4. **不重仓单一股票**：最大30%仓位限制
5. **不频繁交易**：每日换手率过高会增加成本
6. **不参与ST股票**：退市风险高
7. **不参与次新股炒作**：波动过大
8. **不盲目抄底**：接飞刀风险极高
9. **不追热点末班车**：热点退潮后立即下跌
10. **不忽视止损**：止损是保护生命的盾牌

### 禁止行为清单
- ❌ 全仓单一股票
- ❌ 追高买入涨停板
- ❌ 亏损后加仓摊平
- ❌ 无止损持仓过夜
- ❌ 买入ST/*ST股票
- ❌ 追热点炒作末班车

## 五、心理风险控制

### 常见心理偏差

#### 1. 损失厌恶
- **表现**：亏损时不愿意止损，盈利时急于卖出
- **危害**：小亏变大亏，小赚变大亏
- **对策**：严格执行止损纪律

#### 2. 过度自信
- **表现**：重仓押注，频繁交易
- **危害**：一次失败可能造成重大损失
- **对策**：分散投资，控制仓位

#### 3. 从众心理
- **表现**：盲目跟随"专家"建议或跟风操作
- **危害**：买在高点，卖在低点
- **对策**：独立思考，谨慎决策

#### 4. 后悔厌恶
- **表现**：卖出的股票继续上涨，后悔不已
- **危害**：追高买入被套
- **对策**：制定计划并执行，不后悔

### 心理调节方法
1. **每日复盘**：记录情绪和决策过程
2. **设置规则**：用规则限制情绪干扰
3. **暂时离场**：情绪激动时暂停交易
4. **目标明确**：设定合理收益目标

## 六、极端情况应对

### 大盘暴跌应对
1. **保持冷静**：不要恐慌性抛售
2. **检查持仓**：评估持仓股票质地
3. **分批减仓**：如需减仓，分批进行
4. **保留现金**：为后续机会准备子弹

### 持仓股票跌停应对
1. **评估原因**：是系统风险还是个股问题
2. **次日决策**：观察开盘情况再决定
3. **流动性风险**：跌停时无法卖出是正常的
4. **设置预警**：提前设置止损价

### 连续亏损应对
1. **暂停交易**：连续3次止损后必须暂停
2. **复盘总结**：找出亏损原因
3. **降低仓位**：恢复后先小仓位试探
4. **调整策略**：改变不有效的策略

## 七、收益目标与风控平衡

### 目标设定
| 时间段 | 激进目标 | 合理目标 | 保底目标 |
|--------|----------|----------|----------|
| 单日 | +3% | +1-2% | 不亏损 |
| 单周 | +15% | +5-8% | +2% |
| 全程 | +50% | +35% | +20% |

### 风控底线
- **最大单日回撤**：-5%
- **最大单周回撤**：-10%
- **最大全程回撤**：-15%

### 风险收益比
| 预期收益 | 最大亏损 | 风险收益比 | 评价 |
|----------|----------|------------|------|
| +20% | -10% | 2:1 | 优秀 |
| +15% | -7.5% | 2:1 | 良好 |
| +10% | -5% | 2:1 | 可接受 |

## 八、每日风险检查清单

### 交易前检查
- [ ] 今日大盘走势预判
- [ ] 持仓股票是否有重大消息
- [ ] 是否有足够可用资金
- [ ] 止损位是否设置合理

### 交易后检查
- [ ] 是否执行了止损
- [ ] 交易成本是否在预期内
- [ ] 持仓比例是否合理
- [ ] 明日操作计划是否清晰

### 每周风控总结
- [ ] 本周收益率
- [ ] 最大单次回撤
- [ ] 交易胜率
- [ ] 需要调整的策略
