# 交易规则详细说明

## 一、交易品种

### 可交易品种
- **沪深A股**：上海交易所、深圳交易所全部A股
- **京市A股**：北京交易所股票
- **场内基金**：在二级市场交易的基金（不含特殊基金）
- **板块覆盖**：主板、创业板、科创板

### 不可交易品种
- **新股**：N和C开头的新股不允许交易
- **特殊基金**：具体以系统规则为准
- **场外基金**：需通过基金销售渠道购买

## 二、交易时间详解

### 完整交易时段

| 时间段 | 状态 | 说明 |
|--------|------|------|
| 9:15-9:20 | 集合竞价 | 可挂单、可撤单、不撮合成交 |
| 9:20-9:25 | 集合竞价 | 可挂单、**不可撤单**、9:25统一撮合 |
| 9:25-9:30 | 冷静期 | 可挂单、可撤单、不撮合成交 |
| 9:30-11:30 | 连续竞价 | 可挂单、可撤单、实时撮合 |
| 11:30-13:00 | 午间休市 | 不接受委托 |
| 13:00-14:57 | 连续竞价 | 可挂单、可撤单、实时撮合 |
| 14:57-15:00 | 尾盘集合竞价 | 可挂单、**不可撤单**、15:00收盘撮合 |
| 15:00-18:00 | 清算时间 | 不接受委托 |

### 重要提醒
- **9:20-9:25**：此时间段挂单后无法撤单，请谨慎操作
- **14:57-15:00**：尾盘竞价时间段，同样无法撤单
- **清算时间**：当天15:00后至18:00为清算时间，无法下单

## 三、T+0与T+1规则

### T+1规则（A股）
- **定义**：当天买入的股票，当天不能卖出
- **适用范围**：沪深京A股（主板、创业板、科创板）
- **举例**：周一买入的股票，最早只能在周二卖出

### T+0规则（部分基金）
- **定义**：当天买入的基金，当天可以卖出
- **适用范围**：部分场内基金
- **优势**：可以做日内高抛低吸，降低持仓成本

### 实用技巧
1. **卖出时点选择**：考虑T+1限制，建议在尾盘决策当日操作
2. **资金规划**：保留足够资金应对T+1规则
3. **基金T+0机会**：可利用T+0基金做现金管理

## 四、手续费计算

### 费用构成
| 费用类型 | 费率 | 收取方式 |
|----------|------|----------|
| 经手费 | 0.00487% | 买卖双边 |
| 证管费 | 0.002% | 买卖双边 |
| 过户费 | 0.001% | 买卖双边（沪市） |
| 佣金 | 约0.025% | 买卖双边，最低5元 |
| 印花税 | 0.05% | 仅卖出时收取 |

### 计算公式
```
买入费用 = 成交金额 × 0.025%
卖出费用 = 成交金额 × (0.025% + 0.05%) = 成交金额 × 0.075%
总费用 = 买入费用 + 卖出费用
```

### 实例计算
假设：买入100万市值的股票，次日以105万卖出

**买入时**：
- 成交金额：100万
- 经手费+证管费+过户费：约0.00687%（合计约68.7元）
- 佣金：250元（按0.025%，最低5元）
- 买入总费用：约319元

**卖出时**：
- 成交金额：105万
- 经手费+证管费+过户费：约72元
- 佣金：262.5元
- 印花税：525元（0.05%）
- 卖出总费用：约859.5元

**总费用**：约1178.5元

**盈利部分**：5万 - 1.1785万 = 3.8215万

## 五、清仓与成本计算

### 清仓后重新买入
- **规则**：清仓某标的后，当天重新买入，持仓成本和持仓盈亏会延续并合并计算
- **举例**：
  - 上午以10元买入1000股，成本=10000元
  - 下午以11元卖出1000股，清仓
  - 当天又以10.5元买回500股
  - 最终成本 = 10000 + 5250 = 15250元，持股1500股

### 持仓盈亏计算
```
持仓盈亏 = (现价 - 成本价) × 持股数量
盈亏比例 = 持仓盈亏 ÷ 持仓成本 × 100%
```

## 六、涨跌停规则

### 涨跌停幅度
| 板块 | 涨跌停幅度 |
|------|------------|
| 主板 | ±10% |
| 创业板 | ±20% |
| 科创板 | ±20% |
| ST股票 | ±5% |

### 涨停板买入规则
- **涨停价**：当日最高可申报价格（卖一价=涨停价）
- **无法成交**：涨停板股票买入申报不会成交，因为没有卖单
- **排队等待**：需等涨停板打开（有人卖出）才可能成交
- **风险提示**：追涨停板风险极大，可能连续涨停后开板大跌

### 跌停板卖出规则
- **跌停价**：当日最低可申报价格（买一价=跌停价）
- **无法成交**：跌停板股票卖出申报不会成交，因为没有买单
- **止损技巧**：设置止损单时注意，避免挂跌停价

## 七、成交规则详解

### 买入成交规则
1. **委托价 ≥ 卖一价**：按卖一价全部成交
2. **委托价 < 卖一价**：挂单等待成交（部分成交或未成交）
3. **成交量为0**：不会撮合成交

### 卖出成交规则
1. **委托价 ≤ 买一价**：按买一价全部成交
2. **委托价 > 买一价**：挂单等待成交（部分成交或未成交）
3. **成交量为0**：不会撮合成交

### 成交时间差风险
- 模拟交易参考实盘买卖一档行情
- 有一定概率无法按照当天最高价或最低价成交
- 建议留出价格缓冲空间

## 八、收益率计算

### 基础公式
```
当日收益率 = 当日收益额 ÷ 当日期初资产 × 100%
周收益率 = 本周收益额 ÷ 本周期初资产 × 100%
总收益率 = 总收益额 ÷ 期初总资产（100万）× 100%
```

### 计算示例
假设初始资金100万：
- 第一天盈利2万 → 当日收益率=2%，累计=2%
- 第二天盈利1.5万 → 当日收益率=1.5%，累计=3.5%
- 第三天亏损1万 → 当日收益率=-1%，累计=2.5%

### 比赛目标
- **期初资产**：100万
- **目标收益率**：≥35%
- **目标终值**：≥135万

## 九、退市与异常处理

### 退市处理
- 发生退市的标的会从持仓中移除
- 主办方不补偿资金
- **建议**：避免持有连续亏损、存在退市风险的股票

### 异常交易处理
- 系统发生故障时，主办方有权暂停操作
- 异常交易数据可能重置回开盘前状态
- 故意利用漏洞者将被取消参赛资格

## 十、权益处理

### 股票权益
| 业务类型 | 处理规则 |
|----------|----------|
| 分红 | 自动发放到账户 |
| 送股 | 自动增加持股数量 |
| 转股 | 自动增加持股数量 |
| 配股 | 默认自动进行，资金不足则失败 |

### 基金权益
- 分红：自动发放
- 份额转结：自动处理
- 拆分折算：按公告执行

### 除权除息说明
- 股权登记日当晚进行权益上账
- 到除权日开盘前可能出现资产虚增
- 虚增资产不计入收益率计算
