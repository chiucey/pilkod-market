# 风格转化参考指南

## 风格关键词与设计转化

### 高级感
**转化要点**：
- 留白控制 → 大面积留白，呼吸感强
- 材质克制 → 哑光、磨砂、金属质感
- 色彩纯度 → 降低饱和度，避免艳俗
- 版式秩序 → 对齐严谨，间距精确
- 字体气质 → 简洁几何，无装饰线
- 光影节奏 → 柔和过渡，无硬阴影

**视觉特征**：安静、精致、有品位、不张扬

### 国际化
**转化要点**：
- 简洁构图 → 去繁从简，信息集中
- 品牌级调性 → 专业、稳重、可信赖
- 视觉重心清晰 → 焦点明确，不杂乱
- 图文关系克制 → 图片为主，文字精简
- 信息层级理性 → 逻辑清晰，不过度装饰

**视觉特征**：全球通用、无文化壁垒、专业可信

### 品牌感
**转化要点**：
- 识别性强色彩 → 建立品牌专属色
- 统一视觉符号 → Logo和辅助图形贯穿
- 稳定版式逻辑 → 形成品牌专属版式语言
- 传播适配性 → 多尺寸多场景一致

**视觉特征**：一看就知道是什么品牌

### 大片感
**转化要点**：
- 强视觉中心 → 主体突出，冲击力强
- 电影感光影 → 戏剧性用光，氛围浓郁
- 空间纵深 → 前景中景远景层次分明
- 镜头语言 → 俯仰角度、运动感
- 情绪张力 → 紧张感、戏剧感、故事性

**视觉特征**：震撼、有张力、像电影截图

### 艺术感
**转化要点**：
- 画面节奏 → 留白与密集对比
- 材质语言 → 肌理、质感、触感
- 叙事氛围 → 有故事、有情绪
- 形式控制 → 构图讲究、比例特殊
- 审美独特性 → 不随大流、有辨识度

**视觉特征**：有品味、有深度、不商业

### 高端感
**转化要点**：
- 克制 → 少即是多
- 高级材质 → 金属、皮革、玻璃、丝绸
- 精密构图 → 黄金比例、精确对称
- 少而准 → 元素少但每个都精挑细选
- 统一细节 → 细节完成度极高

**视觉特征**：奢华、有品质、稀缺感

## 设计风格库

### 极简高级
- 元素极少、留白充足
- 色彩单一或双色
- 几何图形为主
- 无多余装饰

### 国际品牌感
- 简洁大气
- 高端材质暗示
- 版式稳定
- 全球通用

### 瑞士平面
- 网格系统严谨
- 字体排版精确
- 功能主义
- 信息优先

### 包豪斯
- 几何形态
- 功能主义
- 基础色系
- 结构理性

### 苹果系科技感
- 极简留白
- 渐变微妙
- 字体干净
- 光影柔和

### 未来科技感
- 线条光效
- 深色背景
- 霓虹点缀
- 几何解构

### 东方极简
- 水墨意境
- 留白禅意
- 线条流动
- 色彩克制

### 新中式
- 传统元素当代化
- 色彩典雅
- 纹样现代演绎
- 文化内涵

### 国潮高端化
- 传统元素精致化
- 配色高级
- 工艺感强
- 不俗不土

### 时尚轻奢
- 黑白灰为主
- 金属点缀
- 材质奢华
- 排版考究

### 艺术馆展陈感
- 白墙空间
- 作品突出
- 光影精准
- 距离舒适

### 博物馆叙事感
- 历史厚重
- 场景还原
- 灯光聚焦
- 信息层次

### 绘本感
- 手绘温度
- 色彩柔和
- 故事性强
- 适合儿童或情感类

### 电影海报感
- 人物突出
- 光影戏剧
- 色调统一
- 氛围浓郁

### 手绘概念稿风
- 线稿为主
- 快速感
- 便于修改
- 提案沟通

### 高级商业插画风
- 矢量精细
- 色彩高级
- 商业适配
- 辨识度强

## 禁忌风格

### 廉价感
- 高饱和度撞色
- 粗糙渐变
- 俗套光效
- 堆砌装饰

### 模板感
- 套用固定版式
- 缺乏创意
- 千篇一律

### 电商图感
- 过度PS
- 廉价光效
- 信息过载
- 促销感太强

### 粗糙AI感
- 手指畸形
- 边缘模糊
- 光影矛盾
- 细节缺失
