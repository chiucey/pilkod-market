# 中文校对机制

## 核心原则

**只要最终输出涉及简体中文画面内容，必须先把文案整理成可直接上图的最终版本。**

## 必须执行的检查流程

### 1. 逐字检查
- 每个汉字书写正确
- 无错别字
- 无形近字错误（如"己/已"、"末/未"）
- 无数字与汉字混用错误

### 2. 逐词检查
- 词语搭配合理
- 无病态搭配
- 专业术语准确
- 避免生造词

### 3. 逐句检查
- 语法结构完整
- 主谓宾齐全
- 无成分残缺
- 无成分赘余

### 4. 语义检查
- 语句通顺流畅
- 无歧义表达
- 逻辑关系清晰
- 符合表达习惯

### 5. 断句检查
- 标点使用正确
- 断句位置合理
- 长句适当分割
- 节奏感良好

### 6. 标点检查
- 句号、逗号、顿号使用规范
- 引号、括号配套
- 省略号、破折号规范
- 无中英文标点混用

### 7. 视觉排版检查
- 横竖排版合适
- 行距字距适当
- 留白比例协调
- 整体视觉平衡

## 必须确保的结果

| 检查项 | 要求 |
|-------|------|
| 错别字 | 零容忍 |
| 病句 | 零容忍 |
| 奇怪换行 | 零容忍 |
| 歧义表达 | 零容忍 |
| 低级表达 | 零容忍 |
| 口号式空洞 | 零容忍 |

**同时要求**：
- ✅ 既准确又上镜
- ✅ 既可读又高级
- ✅ 适合画面构图
- ✅ 适配字体排版

## 层级化处理原则

当标题、副标题、卖点、说明文字同时出现时，必须主动做层级化处理。

### 层级定义

```
第一层级：主标题
- 字数：4-12字
- 作用：吸引注意、传达核心
- 位置：画面焦点区域
- 字号：最大
- 颜色：可与背景形成对比

第二层级：副标题
- 字数：6-20字
- 作用：补充说明、引导阅读
- 位置：主标题附近
- 字号：中等
- 颜色：可与主标题区分

第三层级：卖点/特点
- 字数：4-8字/条
- 作用：强调优势、促进记忆
- 位置：信息区
- 字号：较小
- 颜色：弱化处理

第四层级：说明文字
- 字数：不限
- 作用：详细说明、补充信息
- 位置：边缘或底部
- 字号：最小
- 颜色：最弱化
```

### 排版优先级
1. 主标题：最醒目、占据视觉焦点
2. 副标题：辅助主标题、引导阅读
3. 卖点：点缀、节奏感
4. 说明：弱化、可选择性阅读

## 常见错误类型

### 字形错误
- "己"写成了"已"
- "土"写成了"士"
- "候"写成了"侯"

### 词义错误
- "的地得"混用
- "截止/截至"混淆
- "制定/制订"混淆

### 语法错误
- 主谓搭配不当
- 动宾搭配不当
- 修饰语位置错误

### 标点错误
- 逗号句号混用
- 顿号用于句子之间
- 引号不配套

### 风格错误
- 口语化严重
- 语气不统一
- 层级混乱

## 校对示例

### 错误示例
```
标题：引领未来•创新科技
副标题：开创美好生活
卖点：高品质/高性能/高效率
说明：我们的产品采用了最先进的技术...
```

### 正确校对
```
标题：引领未来
副标题：创新科技，开创美好生活
卖点：
  · 高品质保障
  · 性能卓越
  · 效率领先
说明：（可选，视画面需要）
```

### 关键改进点
1. 标题精简，去除装饰符号
2. 副标题合并，信息连贯
3. 卖点用项目符号，节奏清晰
4. 说明文字根据需要决定取舍

## 视觉呈现检查

### 上图前必须确认
- 字号在指定距离可读
- 颜色与背景有足够对比度
- 位置不遮挡核心视觉元素
- 排版方向与画面风格一致

### 常见问题
- 文字太小看不清
- 颜色太浅没效果
- 压在复杂图案上
- 与画面元素冲突

## 执行检查清单

```

□ 逐句检查语法
□ 标点全部核实
□ 语义无歧义
□ 断句合适
□ 层级关系正确
□ 视觉排版协调
□ 上图位置合理
□ 最终效果满意
```
