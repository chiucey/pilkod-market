## ⚠️ 关键数据处理规则（经验沉淀，必须遵守）

### 规则1：物业管理开支必须从 Databack/财务附注取数

**这是最常被错误处理的数据之一。**

来源：`年报/招股书 → 财务报表附注 → 其他开支明细 → 物业管理开支`

2025年正确值：
- 物业管理开支：**143,840千元**（年报附注数据）
- 占营收比：143,840 ÷ 5,345,091 = **2.7%**

2024年正确值：
- 物业管理开支：**132,316千元**
- 占营收比：132,316 ÷ 5,209,874 = **2.5%**

⚠️ 不要使用"还原值"（110,985/141,151），那是此前错误计算的值。

### 规则2：其他开支（管理类）必须扣减物业管理开支

物业管理开支已被重分类进"租金及相关"，所以"其他开支（管理类）"需要扣减物业管理开支：

- 2025年：原值 254,825 − 143,840 = **110,985千元**
- 2024年：原值 273,467 − 132,316 = **141,151千元**
- 标签改为：**其他开支（管理类）（已扣减物业管理开支）**

### 规则3：合计行计算规则

成本结构表的"合计"行必须用以下9项相加（不含子项）：

```
合计 = 原材料及消耗品 + 员工成本 + 租金及相关（综合）
      + 水电煤开支 + 其他资产折旧及摊销 + 广告及促销开支
      + 外卖服务开支 + 其他开支（管理类）（已扣减）+ 财务成本
```

**不等于**各子项之和；子项（使用权资产折旧/其他租金/物业管理开支）不计入合计，它们已包含在"租金及相关（综合）"中。

**正确示例（2025年）：**
- 原材料：1,582,209
- 员工：1,373,429
- 租金及相关：**508,807**（= 268,007+96,960+143,840）
- 水电煤：174,575
- 其他资产折旧：189,431
- 广告：77,443
- 外卖：359,329
- 其他开支（已扣减）：110,985
- 财务成本：43,053
- **合计：4,419,261千元 / 82.7%**
- **变动：-93,003千元 / -3.9ppt**

### 规则4：删除"而非86亿"

IPO市值相关内容不得出现"而非86亿"、"而非此前错误计算的86亿"等表述。正确表述：
> "IPO市值 = 8.50港元 × 11.7652亿股 = **100亿港元**"

### 规则5：单店年员工成本列的处理

**分城市层级效率对比表**不得包含"单店年员工成本"列（因为二线城市未披露，强行列出会导致数据不完整）。

必须删除的列：
- ❌ 单店年员工成本（千元）
- ❌ 日均员工成本

如需描述员工成本差异，使用：
- "一线城市日均员工成本约4,550元/天，三线城市约3,757元/天"
- 不得在表格中混入未披露的城市数据

### 规则6：HTML表格"整体平均"行格式

`分城市单店效率对比`表中，"整体平均"行**不得有多余单元格**：
- 表头6列 → 数据行也必须6列
- 不得出现"整体平均"行有7个 `<td>` 导致列错位
