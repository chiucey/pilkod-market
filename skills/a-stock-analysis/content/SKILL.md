# A股股票和大盘分析技能

## 核心能力

本技能提供全面的A股市场分析服务，涵盖大盘走势、个股研究、财报解读、新闻收集等维度。

## 分析维度

### 1. 大盘分析
- **指数走势**：上证指数、深证成指、创业板指、科创50、北证50
- **成交量能**：两市成交额、量能变化、量价配合
- **市场情绪**：涨跌停数量、炸板率、昨日涨停表现
- **资金动向**：北向资金、南向资金、主力净流入
- **板块轮动**：热点板块切换、主力资金流向
- **技术形态**：均线系统、K线组合、趋势通道

### 2. 个股分析
- **基本面**：公司概况、行业地位、核心竞争力
- **财务指标**：营收、净利润、毛利率、净利率、ROE
- **估值分析**：市盈率(PE)、市净率(PB)、PEG、EV/EBITDA
- **技术分析**：K线形态、均线系统、MACD、KDJ、布林带
- **资金流向**：主力资金、散户资金、大单净流入
- **股东结构**：机构持仓、股东人数变化、解禁压力

### 3. 财报分析
- **业绩解读**：营收增长、利润增速、毛利率变化
- **资产负债表**：资产结构、负债水平、偿债能力
- **现金流量**：经营现金流、投资现金流、筹资现金流
- **盈利质量**：扣非净利润、经营性现金流/净利润
- **业绩预告**：业绩快报、业绩修正、业绩变脸
- **同比环比**：季度对比、年度对比、行业对比

### 4. 新闻与公告
- **重要新闻**：政策利好、行业动态、公司公告
- **公告解读**：重大合同、股权变动、高管增持/减持
- **研报摘要**：机构研报要点、投资评级、目标价
- **舆情监控**：市场传闻、澄清公告、监管问询

## 工作流程

### 数据收集
1. 调用股票数据API获取实时行情
2. 获取历史K线数据
3. 抓取最新财经新闻
4. 收集公司公告和财报

### 分析执行
1. **大盘研判**：判断市场趋势、热点方向、操作环境
2. **技术分析**：识别关键支撑压力、买卖信号
3. **基本面筛选**：财务指标横向纵向对比
4. **消息面结合**：结合政策、行业、公司动态综合判断

### 输出呈现
1. 技术面：K线图、指标数值、形态判断
2. 基本面：财务摘要、估值区间、业绩预测
3. 消息面：新闻摘要、公告要点、风险提示
4. 综合结论：操作建议、风险收益比、注意事项

## 常用分析指标

### 技术指标
| 指标 | 说明 | 用途 |
|------|------|------|
| MA5/MA10/MA20 | 短期/中期/长期均线 | 判断趋势方向 |
| MACD | 指数平滑异同移动平均线 | 判断动能转折 |
| KDJ | 随机指标 | 判断超买超卖 |
| RSI | 相对强弱指标 | 判断多空力量 |
| BOLL | 布林带 | 判断波动区间 |
| VOL | 成交量 | 判断资金活跃度 |

### 基本面指标
| 指标 | 说明 | 参考标准 |
|------|------|----------|
| PE | 市盈率 | 行业平均对比 |
| PB | 市净率 | 低于1可能有价值陷阱 |
| ROE | 净资产收益率 | 持续>15%为优质 |
| 毛利率 | 盈利能力 | 行业领先为佳 |
| 营收增速 | 成长性 | 持续增长优于波动 |
| 现金流 | 盈利质量 | 经营现金流>净利润 |

## 风险提示规范

所有分析必须包含以下风险提示：
- 本分析仅供参考，不构成投资建议
- 市场有风险，投资需谨慎
- 历史业绩不代表未来表现
- 需结合个人风险承受能力决策

## 数据来源优先级

1. **官方渠道**：交易所公告、公司公告、监管文件
2. **财经平台**：东方财富、同花顺、雪球
3. **资讯媒体**：财联社、上证报、证券时报
4. **研究机构**：券商研报、评级报告
