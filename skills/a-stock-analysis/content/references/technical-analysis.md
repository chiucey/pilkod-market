# 技术分析参考手册

## 趋势判断

### 均线系统
- **多头排列**：MA5>MA10>MA20>MA60，行情处于上升趋势
- **空头排列**：MA5<MA10<MA20<MA60，行情处于下降趋势
- **均线缠绕**：短期均线反复交叉，行情处于震荡整理

### MACD指标
- **金叉**：DIF线上穿DEA线，看涨信号
- **死叉**：DIF线下穿DEA线，看跌信号
- **顶背离**：价格创新高但MACD未创新高，警惕回调
- **底背离**：价格创新低但MACD未创新低，警惕反弹

### KDJ指标
- **超买区**：K、D、J值>80，高位震荡可能回落
- **超卖区**：K、D、J值<20，低位震荡可能反弹
- **金叉**：K线上穿D线，买入信号
- **死叉**：K线下穿D线，卖出信号

## 形态识别

### 底部形态
- **W底**：双重底，预示反转上涨
- **头肩底**：三重底，反转信号较强
- **圆弧底**：缓慢筑底，成功率较高

### 顶部形态
- **M顶**：双重顶，预示反转下跌
- **头肩顶**：三重顶，反转信号较强
- **圆弧顶**：缓慢筑顶，成功率较高

### 持续形态
- **旗形**：短暂整理后延续原趋势
- **三角形**：收敛后选择方向
- **矩形**：震荡整理后突破

## 量价关系

### 放量信号
- **放量上涨**：量增价涨，资金积极介入，看多
- **放量下跌**：量增价跌，抛压较重，看空
- **底部放量**：低位突然放量，可能有资金进场

### 缩量信号
- **缩量上涨**：量缩价涨，上涨动力不足
- **缩量下跌**：量缩价跌，抛压减轻，可能见底

### 量价背离
- **顶背离**：价涨量缩，上涨乏力
- **底背离**：价跌量缩，下跌动力减弱
