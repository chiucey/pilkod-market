# 基本面分析参考手册

## 财务指标体系

### 盈利能力
| 指标 | 计算公式 | 优质标准 |
|------|----------|----------|
| 毛利率 | (营收-成本)/营收 | >30%为优质 |
| 净利率 | 净利润/营收 | >15%为优质 |
| ROE | 净利润/净资产 | 持续>15% |
| ROA | 净利润/总资产 | >5% |

### 成长能力
| 指标 | 说明 | 优质标准 |
|------|------|----------|
| 营收增速 | (本期-上期)/上期 | 持续>10% |
| 净利润增速 | (本期-上期)/上期 | 持续>15% |
| 季度环比 | 季度间增长 | 稳定增长 |

### 偿债能力
| 指标 | 计算公式 | 优质标准 |
|------|----------|----------|
| 资产负债率 | 总负债/总资产 | <60% |
| 流动比率 | 流动资产/流动负债 | >1.5 |
| 速动比率 | (流动资产-存货)/流动负债 | >1 |

### 运营能力
| 指标 | 说明 | 优质标准 |
|------|------|----------|
| 存货周转率 | 销货成本/平均存货 | 行业对比 |
| 应收账款周转率 | 营收/平均应收账款 | 越高越好 |
| 总资产周转率 | 营收/平均总资产 | 行业对比 |

## 估值方法

### 相对估值
- **PE估值**：适合稳定增长企业
- **PB估值**：适合金融、周期企业
- **PS估值**：适合营收稳定企业

### DCF估值
- 现金流折现法
- 适用于稳定现金流的成熟企业

## 财报阅读重点

### 利润表
1. 营收增长是否稳定
2. 毛利率变化趋势
3. 三费占比是否合理
4. 扣非净利润与净利润差异

### 资产负债表
1. 资产结构是否健康
2. 负债水平是否可控
3. 商誉是否过高
4. 应收账款变化

### 现金流量表
1. 经营现金流是否为正
2. 经营现金流与净利润匹配度
3. 投资现金流是否合理
4. 筹资现金流变化

## 风险识别

### 财务风险
- 应收账款异常增长
- 存货大幅增加
- 商誉减值风险
- 关联交易频繁

### 经营风险
- 客户集中度高
- 供应商依赖强
- 产品单一
- 技术替代风险

### 退市风险信号
- 连续亏损
- 营收低于1亿元
- 审计非标意见
- 信息披露违规
