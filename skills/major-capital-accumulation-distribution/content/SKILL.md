# 主力吸筹与出货判断技能

## 核心分析框架

### 一、量价关系分析

#### 吸筹特征（主力建仓期）
1. **温和放量上涨**：成交量逐步放大，价格稳步上升
2. **缩量回调**：上涨后缩量回调，不破关键支撑
3. **区间震荡吸筹**：价格在一定区间内反复震荡，量能间歇性放大
4. **低位堆量**：在相对低位区域成交量持续放大

#### 出货特征（主力派发期）
1. **放量滞涨**：成交量放大但价格上涨乏力或滞涨
2. **高位震荡出货**：在高位区间反复冲高回落
3. **放量破位**：向下突破重要支撑位时伴随放量
4. **天量天价**：出现历史天量伴随价格新高

### 二、资金流向指标

#### 吸筹信号
- **主动买入净流入**：大单买入显著大于大单卖出
- **持续净流入**：连续多日资金呈现净流入状态
- **底背离**：股价下跌但资金反而流入

#### 出货信号
- **主动卖出净流出**：大单卖出显著大于大单买入
- **持续净流出**：连续多日资金呈现净流出状态
- **顶背离**：股价上涨但资金反而流出

### 三、技术形态判断

#### 吸筹形态
1. **潜伏底**：长时间横盘后突然放量突破
2. **W底**：双重底形态，第二次底部不破前低
3. **旗形整理**：小幅回调后继续上涨
4. **缩量挖坑**：故意打压后快速拉升

#### 出货形态
1. **M头**：双重顶形态，第二次冲高后回落
2. **头肩顶**：标准顶部反转形态
3. **喇叭形**：震荡幅度越来越大
4. **岛形反转**：跳空缺口后反向运行

### 四、均线系统验证

#### 吸筹确认
- 股价站稳中长期均线（如60日线、120日线）
- 均线呈多头排列（短期 > 中期 > 长期）
- 股价回调至均线附近获得支撑

#### 出货确认
- 股价跌破重要均线（如60日线）
- 均线呈空头排列（短期 < 中期 < 长期）
- 均线对股价形成压制

### 五、分时图分析

#### 吸筹特征
- **早盘快速下探后拉起**：利用恐慌盘吸筹
- **尾盘拉升**：避免过多关注，悄悄吸筹
- **压盘吸货**：在卖档挂大单压价，趁低位吸筹
- **对倒拉升吸筹**：对倒打压制造恐慌后吸筹

#### 出货特征
- **早盘冲高后回落**：利用追涨热情出货
- **盘中反复震荡**：边拉边出
- **尾盘砸盘**：不计成本出货
- **涨停板出货**：在涨停价大量抛售

## 分析决策流程

### Step 1: 收集数据
```
- 近20-60个交易日K线数据
- 成交量变化（量能分布）
- 资金流向数据（大单净流入）
- 均线系统状态
- 分时成交明细
```

### Step 2: 形态识别
```
1. 识别当前价格所处阶段（低位/中位/高位）
2. 判断量价配合关系
3. 对照吸筹/出货特征库
```

### Step 3: 多信号共振
```
- 量价信号 × 资金信号 × 形态信号 × 均线信号
- 多信号一致 → 判断可靠
- 信号矛盾 → 需要谨慎，等待更多确认
```

### Step 4: 结论输出
```
【主力行为判断】
- 吸筹概率：XX%
- 出货概率：XX%
- 当前阶段：建仓期/拉升期/派发期/回落期
- 关键支撑/压力位
- 操作建议
```

## 实战判断口诀

1. **低位放量要关注**：可能是吸筹开始
2. **天量见天价**：高位天量警惕出货
3. **缩量上涨是吸筹**：惜售说明主力控盘
4. **放量滞涨是出货**：主力在对倒派发
5. **价跌量增是吸筹**：对倒打压收集筹码
6. **价涨量缩是出货**：拉高吸引接盘后减仓

## 注意事项

1. **结合大盘环境**：大盘弱势时吸筹更可靠
2. **识别对倒行为**：成交量异常放大需警惕
3. **多周期验证**：日线、周线共振更可靠
4. **关注板块联动**：独立个股更容易判断
5. **仓位管理**：不确定时控制仓位
