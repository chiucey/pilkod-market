# 照片上色处理指南

## 上色原则

### 真实性优先
- 基于历史时期推断合理色彩
- 参考同期照片色彩风格
- 避免过度饱和或失真

### 场景适配
| 场景类型 | 色彩建议 |
|---------|---------|
| 人像 | 自然肤色、服饰色彩符合年代 |
| 室内 | 暖色调为主、环境光线自然 |
| 室外 | 参考天气和时段、光照合理 |
| 建筑 | 中性色调、尊重原有材质 |

## 人像上色要点

### 肤色处理
- 识别不同年龄段肤色特征
- 考虑光线对肤色的影响
- 避免统一肤色导致的塑料感

### 服饰色彩
- 推断服饰原有色彩
- 考虑褪色程度
- 细节纹理保留

### 背景处理
- 前景主体优先
- 背景色彩简化处理
- 景深氛围营造

## 质量检查清单

- [ ] 人物肤色自然准确
- [ ] 服饰色彩符合年代特征
- [ ] 光影关系合理
- [ ] 背景与主体色彩协调
- [ ] 无色彩溢出或噪点
- [ ] 细节纹理清晰保留
