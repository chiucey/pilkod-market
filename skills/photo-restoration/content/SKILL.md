# 照片修复与增强技能

## 技能概述

本技能提供专业的照片修复和增强服务，利用 AI 技术智能处理各种照片质量问题。

## 核心功能

### 1. 老照片修复
- 修复划痕、折痕、污渍
- 填补缺失的画面区域
- 恢复损坏的照片细节

### 2. 照片上色
- 智能识别照片场景和人物
- 自然还原真实色彩
- 支持人像、风景、建筑等各类照片

### 3. 画质增强
- 去除噪点和颗粒感
- 提升清晰度和锐度
- 无损放大图片分辨率

### 4. 色彩校正
- 修复褪色照片
- 调整曝光和对比度
- 平衡色彩平衡

## 使用流程

### 第一步：分析照片问题
仔细观察用户提供的照片，识别以下问题：
- 物理损坏类型（划痕、撕裂、污渍）
- 画质问题（模糊、噪点、低分辨率）
- 色彩问题（褪色、偏色）

### 第二步：选择修复策略
根据问题类型选择合适的处理方式：
| 问题类型 | 优先处理方式 |
|---------|-------------|
| 划痕/损坏 | 智能填补 + 细节重建 |
| 黑白照片 | AI 上色 + 场景适配 |
| 模糊/噪点 | 画质增强 + 去噪处理 |
| 褪色/泛黄 | 色彩校正 + 对比度调整 |

### 第三步：执行修复
使用图像生成工具进行修复，确保：
- 保持原始照片的主要结构和特征
- 修复区域与周围画面自然融合
- 不添加原图不存在的内容

### 第四步：质量检查
检查修复结果：
- 损坏区域是否已修复
- 新生成的内容是否自然
- 整体画质是否有提升
- 色彩是否协调

**用户输入：**

> [附件：old_photo_001.jpg]

**处理流程：**
1. 分析照片：识别横向划痕、局部褪色问题
2. 使用图像编辑工具修复划痕区域
3. 补充缺失的细节信息
4. 进行整体色彩校正

**输出：**
提供修复后的照片，并说明修复内容和处理方式。

## 注意事项

### 不适合处理的情况
- 严重损毁导致关键信息完全缺失的照片
- 分辨率极低（低于 100x100 像素）且严重模糊的照片
- 扫描或拍摄条件极差的照片

### 修复局限性
- 无法 100% 还原原始场景
- 严重损坏区域可能存在合理但非原始的内容
- 上色结果基于 AI 推断，不代表历史真实色彩

### 用户沟通
- 修复前说明预期效果和局限性
- 复杂任务提供修复前后对比
- 根据用户反馈进行微调

3. **局限性提示**：提醒可能的不足之处
