# 书籍深度榨取系统

## 核心定位

智能化的书籍价值挖掘工具，通过**"四层榨取法"**将抽象理论转化为可执行、可迁移的实战能力。

## 核心特性

### 四层榨取法

| 层次 | 名称 | 产出内容 |
|------|------|---------|
| 第一层 | 骨架提取 | 精准定义核心概念，建立知识骨架 |
| 第二层 | 肉质挖掘 | 配套2-3个具体案例，深度解析应用逻辑 |
| 第三层 | 精华萃取 | 跨行业迁移矩阵 + 可执行SOP |
| 第四层 | 残渣利用 | 批判性视角，明确理论边界 |

### 双模式支持

| 模式 | 知识点数量 | 适用场景 | 耗时 |
|------|-----------|---------|------|
| 快速模式 | 5个核心 | 快速了解一本书 | 10-15分钟 |
| 深度模式 | 10-20个 | 系统学习、知识库建设 | 30-45分钟 |

### 费曼检验

通过情境模拟题验证理解深度，确保**"会用"**而非**"知道"**。

## 处理流程

### 第一步：接收书籍内容

支持以下输入方式：
- 上传PDF/EPUB/文本文件
- 粘贴书籍全文或核心章节
- 提供书名和榨取范围

### 第二步：自动分析

智能体执行四层榨取：

```
输入书籍 → 骨架提取 → 肉质挖掘 → 精华萃取 → 残渣利用 → 费曼检验
```

### 第三步：输出报告

报告包含：

| 模块 | 内容 |
|------|------|
| 元信息 | 书名、作者、榨取模式 |
| 内容地图 | 核心概念分布与关联网络 |
| 知识点深度解析 | 概念定义 + 案例 + 迁移矩阵 + SOP |
| 费曼检验 | 情境模拟题 + 参考答案 |
| 批判性总结 | 理论边界 + 追问方向 |

### 第四步：多格式导出

| 格式 | 说明 |
|------|------|
| Markdown | 默认格式，直接阅读 |
| PDF | 正式文档，便于打印分享 |
| Word | 可编辑文档，便于编辑 |

## 适用书籍类型

### 强烈推荐
- 方法论类书籍
- 思维模型类书籍
- 技能提升类书籍
- 商业管理类书籍
- 心理学类书籍
- 沟通技巧类书籍

### 部分适合
- 传记类（提取决策模型）
- 历史类（提取规律与教训）

### 不适合
- 工具书、字典
- 纯数据型文献
- 小说（除非分析叙事技巧）

## SOP设计标准

### 五要素结构

```markdown
【步骤1：[动作]】
□ 前置条件确认
□ 具体执行项
□ 完成确认

【步骤2：[动作]】
□ ...

【升级条件】
□ 何时上报
□ 升级路径
```

### 核心SOP模板

```markdown
## [场景名称] 标准操作程序

### 1. 识别
- 确认异常现象
- 记录时间/位置/影响范围
- 初步判断等级

### 2. 隔离
- 切断扩散路径
- 启动备用方案
- 通知相关方

### 3. 修复
- 制定修复方案
- 实施修复
- 测试验证

### 4. 恢复
- 切换正常模式
- 监控运行状态
- 确认服务恢复

### 5. 复盘
- 编写报告
- 根因分析
- 制定预防措施
- 更新文档
```

## 质量标准

### 骨架提取标准
- 每个核心概念有精确定义
- 概念之间有逻辑关联
- 便于形成知识网络

### 案例解析标准
- 原书案例有完整背景-过程-结果
- 每个知识点配2-3个案例
- 案例有深度启示提炼

### 迁移矩阵标准
- 每个矩阵至少3个行业
- 映射关系清晰可执行
- 提供具体应用场景

### 费曼检验标准
- 情境题具有现实代表性
- 答案有操作性
- 能区分"知道"和"会用"
