# 企业洞察分析 - 详细参考资料

本文档为企业洞察技能的详细参考资料，补充 SKILL.md 中的方法论。

## 一、行业及地位分析

### 1.1 行业分类标准

| 行业大类 | 细分行业 | 数据来源 |
|----------|----------|----------|
| 制造业 | 装备制造、电子制造、食品加工 | 工信部、行业协会 |
| 信息技术 | 软件开发、互联网服务、电子商务 | 工信部、艾瑞咨询 |
| 金融业 | 银行、证券、保险 | 银保监会、证监会 |
| 服务业 | 餐饮、教育、医疗、物流 | 商务部、统计局 |

### 1.2 行业地位评估指标

- 市场份额（按营收/销量排名）
- 技术壁垒与专利数量
- 品牌认知度
- 行业排名与荣誉
- 核心竞争力（技术/渠道/品牌）

### 1.3 搜索关键词

```
"[企业名称] 行业排名"
"[企业名称] 市场占有率"
"[企业名称] 核心竞争力"
"[行业名称] 龙头企业"
```

## 二、社保人数变化分析

### 2.1 数据获取渠道

| 渠道 | 可获取信息 | 局限性 |
|------|------------|--------|
| 工商年报 | 社保人数（近3年） | 部分企业未公示 |
| 企查查/天眼查 | 工商年报摘要 | 数据滞后1年 |
| 招聘平台 | 在招职位数 | 无法反映总人数 |
| 官网 | 员工数量 | 未强制披露 |

### 2.2 趋势解读

- 连续增长：业务扩张期
- 连续下降：收缩或自动化
- 波动较大：业务不稳定
- 稳定：成熟期企业

## 三、经营盈利情况分析

### 3.1 上市公司

- 年报（巨潮资讯网、上交所、深交所）
- 招股说明书
- 半年报、季报

### 3.2 非上市公司

- 工商年报（实缴资本、资产总额）
- 新闻报道
- 行业估算

### 3.3 关键指标

```
营收同比增长率 = (本期营收 - 上期营收) / 上期营收 × 100%
净利润率 = 净利润 / 营收 × 100%
毛利率 = (营收 - 成本) / 营收 × 100%
```

## 四、主要产品/服务分析

### 4.1 产品线梳理方法

1. 官网产品页面
2. 电商平台店铺
3. 产品手册/宣传资料
4. 年报中的业务构成

### 4.2 产品分类框架

| 维度 | 分类 |
|------|------|
| 形态 | 实体产品 / 软件服务 / 解决方案 |
| 客群 | B2B / B2C / B2G |
| 价格 | 高端 / 中端 / 低端 |
| 生命周期 | 导入期 / 成长期 / 成熟期 / 衰退期 |

## 五、目标消费市场分析

### 5.1 市场分析要素

- 市场规模（TAM/SAM/SOM）
- 增长趋势
- 竞争格局
- 政策环境
- 客户画像

### 5.2 客户类型

- 终端消费者（C端）
- 企业客户（B端）
- 政府客户（G端）

## 六、主要客户分析

### 6.1 数据来源

- 上市公司年报（大客户披露）
- 招股说明书
- 行业新闻
- 官网客户案例

### 6.2 客户结构评估

```
客户集中度 = 前5大客户营收占比
客户流失率 = 年度流失客户数 / 总客户数
复购率 = 复购客户数 / 总客户数
```

## 七、主要供应商分析

### 7.1 供应链分析维度

- 供应商数量与规模
- 供应商集中度
- 原材料依赖度
- 替代供应商可能性

### 7.2 采购策略评估

- 集中采购 vs 分散采购
- 长期协议 vs 短期招标
- 本地采购 vs 全球采购

## 八、招聘岗位变化分析

### 8.1 数据采集平台

| 平台 | 特点 |
|------|------|
| BOSS直聘 | 职位量大、更新快 |
| 智联招聘 | 传统企业多 |
| 猎聘 | 中高端职位 |
| 前程无忧 | 综合类 |

### 8.2 岗位分类

```
技术类：研发、测试、运维、数据
销售类：销售、客服、市场
职能类：HR、财务、行政、法务
管理类：总监、经理、主管
```

### 8.3 趋势分析

- 增长岗位：业务扩张方向
- 减少岗位：自动化替代
- 新兴岗位：战略转型信号

## 九、管理难点分析

### 9.1 常见管理挑战

| 类别 | 具体问题 |
|------|----------|
| 战略 | 方向不清晰、决策效率低 |
| 组织 | 部门墙、协同差 |
| 人才 | 招聘难、流失高、培训弱 |
| 运营 | 流程繁琐、效率低下 |
| 财务 | 成本控制、现金流 |

### 9.2 分析方法

1. 脉脉、知乎的员工评价
2. 离职员工访谈
3. 行业对标
4. 公开的劳动仲裁记录

## 十、企业信息化现状评估

### 10.1 信息化成熟度模型

| 等级 | 特征 |
|------|------|
| L1 初始级 | 手工操作为主，IT系统碎片化 |
| L2 流程级 | 核心流程电子化，但系统孤岛 |
| L3 整合级 | 系统集成，数据共享 |
| L4 优化级 | 数据驱动，智能化决策 |
| L5 引领级 | 创新驱动，数字化转型 |

### 10.2 常见IT系统

```
企业资源：ERP (SAP/用友/金蝶)
客户关系：CRM (Salesforce/纷享销客)
办公协同：OA (泛微/钉钉/企业微信)
财务管理：财务系统
供应链：SCM系统
数据分析：BI系统
```

## 十一、信息化需求分析

### 11.1 需求识别方法

1. **现状差距分析**：对标行业标杆
2. **业务痛点访谈**：收集各部门需求
3. **数据驱动发现**：从业务数据中发现机会
4. **技术趋势匹配**：AI、大数据、云计算应用

### 11.2 常见信息化需求

| 痛点 | 解决方案 |
|------|----------|
| 数据孤岛 | 建立数据中台 |
| 决策效率低 | BI分析平台 |
| 客户管理混乱 | CRM系统升级 |
| 协同效率低 | 统一办公平台 |
| 供应链不透明 | SCM系统 |

### 11.3 优先级评估

```
紧迫度：业务影响程度
可行性：技术难度、成本
价值：ROI预期

高紧迫 × 高价值 = 优先实施
```
