# Minecraft Pixel Art Image Generator

## Skill Description

This is a specialized skill for generating Minecraft pixel art style images. By calling the image synthesis tool with carefully crafted prompts, it creates images with blocky feel and pixelated MC style.

## Core Features

### 1. Basic Pixel Style
- 8-bit pixel art effect
- Blocky visual style
- Minecraft-specific pixel granularity

### 2. Theme Types
- **Characters**: Steve, Alex, Creeper, Enderman, Zombie, Skeleton, etc.
- **Buildings**: Blocky structures, redstone machines, wooden cabins, castles
- **Landscapes**: Mountains, forests, villages, sunrise/sunset scenes
- **Items**: Diamonds, golden armor, enchanted books, TNT, etc.
- **Biomes**: Forests, deserts, plains, snow biomes, mushroom islands

### 3. Scene Combinations
Supports multi-element combinations such as:
- "Village panorama at sunrise"
- "Player mining diamonds in a cave"
- "End castle and Ender Dragon"
- "Nether fortress ruins"

## Common Troubleshooting

### Q: Generated images not pixelated enough?
A: Add these keywords: `more pixelated`, `lower resolution look`, `chunky blocks`, `big pixels`

### Q: How to avoid generating realistic style images?
A: Explicitly specify: `NOT photorealistic`, `NOT 3D render`, `game style only`, `pixel-perfect`

### Q: Want specific biome style?
A: Add biome keywords: `oak forest`, `birch forest`, `desert temple`, `ice spikes`, `jungle temple`
