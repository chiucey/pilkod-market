# 国际中文教师奖学金申请材料评审

## 任务目标

本技能用于评审国际中文教师奖学金申请材料，包括：
- 验证申请者是否符合基本条件
- 检查材料是否完整合规
- 评估HSK/HSKK成绩是否达标
- 指出材料不足并给出改进建议
- 生成结构化评审报告（采用正式、专业的审核用语风格）

## 语言风格指南

评审报告应采用正式、客观、有温度的审核用语：

### 开场介绍模式
- "[姓名]是来自[国籍]的[优秀/杰出]学生，..."
- "作为[姓名]同学的推荐人，..."
- "[姓名]是[院校/机构][专业/身份]的[年级/身份]，..."

### 语言能力评价
- "语言能力已符合HSK与HSKK要求"
- "其汉语水平已满足[级别]标准"
- "以[优异/良好]成绩通过HSK/HSKK考试"

### 学习目标与规划
- "有着明确的学习目标，致力于..."
- "制定了系统详实的学习计划"
- "展现了扎实的语言基础和对中国文化的深刻理解"
- "未来希望促进跨文化交流"

### 综合素质评价
- "热爱汉语学习/中文学习"
- "积极参加汉语比赛/活动"
- "展现了较强的语言学习能力和跨文化交流潜力"
- "对中文有浓厚兴趣"
- "渴望到中国沉浸式学习汉语，深入了解中国文化"

### 审核结论
- "提供材料齐全，符合我校国际中文教师奖学金[类别]项目的招生要求"
- "建议授予奖学金到我校就读"
- "推荐来校学习，授予奖学金"

### 后续通知
- "我校将于近期给申请者邮箱发送海外学生在线提名邮件，请根据要求尽快填写提交为盼"

## 奖学金类别与申请条件

### 类别一：汉语国际教育专业硕士

| 项目 | 要求 |
|------|------|
| 资助期限 | 2年（2026年9月入学） |
| 学历要求 | 大学本科学历 |
| HSK成绩 | 六级 180分 |
| HSKK成绩 | 高级 60分 |
| 年龄限制 | 16-35周岁（教师可放宽至45周岁） |
| 加分项 | 提供毕业后拟任教机构工作协议或相关证明 |

### 类别二：汉语言本科生（国际中文教育方向）

| 项目 | 要求 |
|------|------|
| 资助期限 | 4年（2026年9月入学） |
| 学历要求 | 高中学历 |
| HSK成绩 | 五级 200分 |
| HSKK成绩 | 中级 60分 |
| 年龄限制 | 一般不超过25周岁 |
| 申请时间 | 2026年5月15日前 |

### 类别三：一学年研修生（汉语研修）

| 项目 | 要求 |
|------|------|
| 资助期限 | 11个月（2025年9月入学） |
| HSK成绩 | 三级 210分 |
| HSKK成绩 | 提供者优先 |
| 重要提示 | 原则上不录取3年内享受过同类奖学金的申请者 |

### 类别四：一学期研修生（汉语言文学）

| 项目 | 要求 |
|------|------|
| 资助期限 | 5个月（2026年9月或2027年3月入学） |
| HSK成绩 | 三级 180分 |
| HSKK成绩 | 必须提供 |
| 重要提示 | 原则上不录取3年内享受过同类奖学金的申请者 |

## 基本申请条件（所有类别适用）

1. 非中国籍人士
2. 对华友好，无违法犯罪记录
3. 身心健康，品学兼优
4. 有志于从事中文教育、教学及相关工作
5. 年龄16-35周岁（在职中文教师放宽至45周岁）

## 必需申请材料清单

### 所有类别必需

| 材料 | 要求 |
|------|------|
| 护照照片页扫描件 | 有效期覆盖学习期间 |
| HSK成绩报告 | 有效期两年内 |
| HSKK成绩报告 | 有效期两年内 |
| 推荐信 | 客观评价申请者，注明是否孔子学院学员 |
| 个人陈述（申请陈述） | 要求中文撰写 |

### 可选加分材料

| 材料 | 说明 |
|------|------|
| 汉语桥证书 | 证书编码格式如 CBCFSSS20240087，同等条件下优先录取 |

### 学历生（硕士/本科）额外需要

| 材料 | 要求 |
|------|------|
| 最高学历证明 | 毕业证明或在校学习证明，非中英文需公证 |
| 在校学习成绩单 | - |
| 导师推荐信（仅硕士） | 两名副教授以上职称 |

### 特殊情况

| 情况 | 额外材料 |
|------|----------|
| 未满18周岁 | 在华法定监护人署名的委托证明文件 |
| 在职中文教师 | 就职机构出具的在职证明和推荐信 |

## 评审流程

### 第一步：收集申请信息

确认申请者姓名、国籍、申请类别、语言成绩、学历背景等基本信息。

### 第二步：基本条件筛查

1. 核对国籍（必须非中国籍）
2. 核对年龄是否符合类别要求
3. 核对学历是否符合类别要求

### 第三步：材料完整性检查

逐项核对申请材料是否齐全，参照上方材料清单。

### 第四步：成绩达标评估

| 类别 | HSK最低要求 | HSKK最低要求 |
|------|------------|--------------|
| 硕士 | 六级180分 | 高级60分 |
| 本科 | 五级200分 | 中级60分 |
| 一学年研修 | 三级210分 | 提供者优先 |
| 一学期研修 | 三级180分 | 必须提供 |

### 第五步：个人陈述语言检查

检查申请陈述（个人陈述）撰写语言：
- **要求**：原则上应以中文撰写
- **标注**：如为英文撰写，在审核报告中标注"个人陈述为英文"，但不体现在对外评语中

### 第六步：个人陈述真实性评估

对个人陈述（申请陈述）进行真实性审查，重点判断是否存在AI生成痕迹：

**AI生成痕迹判断指标**：
| 指标 | AI生成典型特征 | 真实撰写典型特征 |
|------|---------------|-----------------|
| 情感表达 | 情感空洞、套话连篇、缺乏个人色彩 | 有具体情感经历、独特个人视角 |
| 细节描述 | 泛泛而谈、缺乏具体事例 | 包含具体时间/地点/人物/事件 |
| 语言风格 | 过于工整、修辞堆砌、结构模板化 | 有自然瑕疵、口语化表达、个性化句式 |
| 内容深度 | 表面化、通用化、可套用于任何人 | 与个人背景高度关联、不可复制 |
| 逻辑连贯 | 完美但机械的逻辑递进 | 有跳跃、有回味、有个人思维痕迹 |
| 中文水平 | 中文水平与HSK成绩明显不匹配 | 中文水平与成绩基本一致 |

**真实性评估结论**：
- **真实**：内容有个人特色，无AI痕迹
- **可疑**：部分段落疑似AI生成，建议抽查面试核实
- **高度可疑**：明显为AI生成，建议要求重新撰写或面试核实

**重要**：真实性评估结论仅在内部审核报告中标注，不体现在对外评语中。

### 第七步：生成评审报告

按照下方模板输出结构化评审报告，语言风格参照上方指南。

## 评审报告模板

```

[评价学习目标/经历，如：有着明确的学习目标，致力于为跨文化交流贡献力量。/展现了较强的语言学习能力和跨文化交流潜力。]

|------|------|------|

| HSK成绩 | 达标/未达标 | [级别]：[分数]分 |

| 汉语桥证书 | 已提供/缺失 | 证书编码：[编码] |

**评估结论**：[真实/可疑/高度可疑]

**判断依据**：

## 审核结论

[建议授予奖学金到我校就读。/材料尚需补充，请尽快完善。]

[后续通知：我校将于近期给申请者邮箱发送海外学生在线提名邮件，请根据要求尽快填写提交为盼。]
```

## 定时清理任务

### 功能说明

每年5月1日至5月25日为集中申请审核期。为控制磁盘空间与信息安全，已审核的申请表PDF需在每天17:00自动清理删除。

### 清理脚本

脚本调用示例：
```bash
# 试运行（查看将要删除的文件，不实际删除）
python scripts/cleanup_reviews.py --dir ./assets --dry-run

# 正式清理（基于已审核列表）
python scripts/cleanup_reviews.py --dir ./assets --reviewed-list reviewed_files.txt

# 清理超过7天的PDF（与已审核列表取并集）
python scripts/cleanup_reviews.py --dir ./assets --older-than 7
```

### 维护已审核列表

在审核工作目录中创建 `reviewed_files.txt`，每行记录一个已审核的PDF文件名：
```
CISCCHNE26022776_20260516140111351.pdf
CISCCHNE26023619_20260516140111680.pdf
```

### 系统级定时配置（crontab）

在操作系统层面配置cron任务，实现每年5月1日至5月25日每天17:00自动执行：

```bash
# 编辑crontab
crontab -e

# 添加以下行（请替换为实际绝对路径）
0 17 1-25 5 * cd /path/to/skill && python3 scripts/cleanup_reviews.py --dir ./assets --reviewed-list reviewed_files.txt >> cleanup.log 2>&1
```

cron表达式说明：`0 17 1-25 5 *`
- `0 17` — 每天17:00
- `1-25` — 日期1号至25号
- `5` — 5月
- `*` — 星期任意

### 注意事项

1. `--dry-run` 必须在正式运行前执行，确认删除范围正确
2. `reviewed_files.txt` 需在日常审核过程中同步维护
3. 脚本输出JSON格式清理报告，可重定向到日志文件备查
4. 清理操作不可逆，建议定期备份重要材料

## 飞书通知推送

### 功能说明

审核完成后，可将审核结果以消息卡片形式推送到飞书群聊，便于在飞书中集中查看和管理审核进度。

### 前置准备

1. 在目标飞书群中创建自定义机器人：群设置 → 群机器人 → 添加机器人 → 自定义
2. 复制Webhook地址（格式：`https://open.feishu.cn/open-apis/bot/v2/hook/xxxxx`）
3. 配置Skill凭证（已自动触发配置弹窗）

### 脚本调用示例

```bash
# 推送审核结果到飞书
python scripts/feishu_notify.py \
  --student-name "吴庆泽" \
  --category "一学期研修生" \
  --status "通过" \
  --hsk "四级261分" \

# 研修生项目（自动附加提名信提醒）

  --student-name "徐楷怡" \
  --category "一学期研修生" \
  --status "通过" \
```

## 注意事项

1. 所有评审基于国际中文教师奖学金政策
2. 评审意见仅供参考，最终录取由语合中心专家组决定
3. 成绩要求为最低标准，实际竞争可能更激烈
4. 推荐信必须客观评价申请者
5. 非中英文材料需提供公证文件
6. 语言风格应正式、客观、有温度，体现对申请者的鼓励与期待
7. 定时清理任务需在操作系统层面配置cron，Skill本身不运行后台服务
8. 个人陈述原则上要求中文撰写；如为英文撰写，仅在内部审核报告中标注，对外评语中不予体现
9. 个人陈述真实性评估为内部审查环节，评估结论（真实/可疑/高度可疑）仅在审核报告中体现，不写入对外评语
10. 判断AI生成痕迹时需综合多个指标，避免单一指标误判；中文水平与HSK成绩不匹配是重要参考
11. 对"可疑"和"高度可疑"的陈述，建议通过面试进一步核实，不轻易直接否决申请
