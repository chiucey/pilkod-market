# 中文字体排版指南

## 字体选择原则

### 可读性优先
- **屏幕显示**：选择屏幕优化字体
- **打印输出**：选择印刷专用字体
- **移动端**：考虑小字号清晰度
- **长文阅读**：使用衬线体增强可读性

### 风格匹配
- **正式场合**：黑体、宋体
- **创意设计**：艺术字体、手写体
- **科技感**：等宽字体、几何字体
- **传统感**：书法字体、楷体

## 常用中文字体

### 系统字体（跨平台）
1. **苹方** (PingFang SC)
   - 平台：macOS、iOS
   - 特点：屏幕优化，清晰易读
   - 适用：正文、界面文字

2. **微软雅黑** (Microsoft YaHei)
   - 平台：Windows
   - 特点：屏幕显示优秀
   - 适用：网页、应用程序

3. **思源黑体** (Source Han Sans)
   - 平台：全平台
   - 特点：开源免费，字重齐全
   - 适用：多语言混排

4. **阿里巴巴普惠体** (Alibaba PuHuiTi)
   - 平台：全平台
   - 特点：免费商用，字型现代
   - 适用：商业设计、电商

### 创意字体
1. **站酷高端黑**
   - 特点：现代感强，笔画简洁
   - 适用：标题、海报

2. **庞门正道标题体**
   - 特点：力量感强，视觉冲击
   - 适用：大标题、活动宣传

3. **汉仪旗黑**
   - 特点：几何感强，时尚现代
   - 适用：品牌设计、UI界面

4. **造字工房字体**
   - 特点：风格多样，设计感强
   - 注意：部分需商业授权

## 字号设置规范

### 移动端字号
- **超大标题**：36-48px（仅限主标题）
- **主标题**：28-36px
- **副标题**：24-28px
- **正文**：16-20px
- **说明文字**：14-16px
- **辅助信息**：12-14px

### 桌面端字号
- **超大标题**：48-72px
- **主标题**：36-48px
- **副标题**：24-36px
- **正文**：18-24px
- **说明文字**：16-18px
- **辅助信息**：14-16px

### 响应式字号调整
```css
/* 基础字号 */
:root {
  --font-size-base: 16px;
}

/* 移动端 */
@media (max-width: 768px) {
  :root {
    --font-size-base: 14px;
  }
}

/* 桌面端 */
@media (min-width: 1200px) {
  :root {
    --font-size-base: 18px;
  }
}
```

## 行高与间距

### 行高设置
- **标题**：1.2-1.5倍（紧凑）
- **正文**：1.5-1.8倍（舒适阅读）
- **长文**：1.8-2.0倍（增强可读性）
- **英文**：比中文增加0.1-0.2倍

### 字间距
- **正常**：0（默认）
- **宽松**：0.1-0.2em（标题）
- **紧凑**：-0.05em（特殊效果）
- **艺术效果**：可调整至±0.3em

### 段落间距
- **标题与正文**：1.5-2倍行高
- **段落之间**：1-1.5倍行高
- **列表项**：0.5-1倍行高

## 对齐方式

### 水平对齐
- **左对齐**：最常用，符合阅读习惯
- **居中对齐**：标题、短文本
- **右对齐**：数字、时间、引用
- **两端对齐**：印刷品、正式文档

### 垂直对齐
- **顶部对齐**：东亚文字标准
- **居中对齐**：图标+文字组合
- **基线对齐**：多语言混排

## 色彩与对比度

### 文字颜色
- **主文字**：#262626（深灰）
- **次要文字**：#595959（中灰）
- **辅助文字**：#8C8C8C（浅灰）
- **链接文字**：#1890FF（品牌色）
- **警示文字**：#FF4D4F（红色）

### 背景对比度
- **正常文本**：对比度≥4.5:1
- **大号文本**：对比度≥3:1
- **图标文字**：对比度≥3:1
- **禁用状态**：对比度≥2:1

### 色彩组合示例
1. **白底黑字**：#FFFFFF + #262626
2. **黑底白字**：#000000 + #FFFFFF
3. **深色背景浅色字**：#1890FF + #FFFFFF
4. **浅色背景深色字**：#F5F5F5 + #262626

## 特殊字符处理

### 标点符号
- **全角标点**：中文使用全角
- **半角标点**：英文、数字使用半角
- **避头尾**：标点不出现在行首
- **悬挂标点**：引号、括号可悬挂

### 数字与单位
- **阿拉伯数字**：使用半角
- **中文数字**：正式场合使用
- **单位符号**：与数字间加空格
- **货币符号**：人民币符号¥在前

### 英文混排
- **字体选择**：使用中文字体的英文字母
- **大小写**：遵循英文规则
- **间距**：中英文间加空格
- **连字符**：正确使用连字符-

## 排版禁忌

### 避免问题
1. **字体过多**：一个设计不超过3种字体
2. **字号混乱**：建立清晰的层级关系
3. **颜色杂乱**：主色调不超过3种
4. **对齐混乱**：保持一致性
5. **行距不当**：避免过密或过疏

### 移动端注意事项
1. **最小字号**：不小于12px
2. **触摸目标**：文字周围留足够空间
3. **横竖屏**：考虑不同方向显示
4. **加载状态**：字体加载失败时的fallback

## 测试与验证

### 可读性测试
1. **距离测试**：在正常阅读距离查看
2. **时间测试**：快速浏览是否易读
3. **设备测试**：在不同设备上查看
4. **环境测试**：在不同光线条件下查看

### 无障碍测试
1. **屏幕阅读器**：确保语义正确
2. **放大功能**：支持200%放大
3. **色彩模式**：在灰度模式下可读
4. **对比度工具**：使用工具验证对比度

## 最佳实践总结

1. **建立层级**：清晰的视觉层次
2. **保持简洁**：少即是多
3. **考虑场景**：根据使用场景选择字体
4. **测试验证**：多设备多环境测试
5. **持续学习**：关注设计趋势变化
