# 订阅号图片生成技能使用示例

## 技能概述

本技能提供专业级的订阅号图片生成能力，支持基于文字内容、图片素材生成多种类型的社交媒体图片。

## 快速开始

### 场景1：生成微信公众号封面

**用户请求示例**：
```
帮我生成一个微信公众号封面，标题是"2026年人工智能发展趋势分析"，风格要商务专业
```

**技能处理流程**：
1. 识别需求：微信公众号封面、商务专业风格
2. 确定尺寸：900×383px（头条封面）
3. 设计规划：
   - 使用深蓝色背景体现科技感
   - 白色大字体标题
   - 添加简约的AI相关装饰元素
4. 图片生成：
   - 使用 `aily-image-generate` 生成背景
   - 使用 `text_overlay.py` 添加文字
   - 调整色彩和对比度
5. 输出：生成符合微信平台要求的封面图片

### 场景2：生成营销海报

**用户请求示例**：
```
为我们的新产品"智能咖啡机"制作一张营销海报，突出"一键冲泡，专业口感"的卖点
```

**技能处理流程**：
1. 识别需求：产品营销海报、突出卖点
2. 确定尺寸：1080×1920px（竖版海报）
3. 内容分析：
   - 主标题：智能咖啡机
   - 副标题：一键冲泡，专业口感
   - 产品特点：智能控制、多种口味、快速加热
4. 设计规划：
   - 使用咖啡相关的视觉元素
   - 突出产品图片
   - 清晰展示卖点
5. 图片生成与优化
6. 输出：高质量的营销海报

## 完整使用示例

### 示例1：公众号文章封面生成

**用户输入**：
```
请帮我生成一个公众号封面
标题：数字化转型赋能传统制造业
副标题：2026年制造业升级路径分析
风格：商务专业
平台：微信公众号头条
```

**技能调用**：
```python

1. 确定平台要求：900×383px，JPG格式，不超过5MB
2. 选择设计风格：商务专业（蓝色系、简洁排版）
3. 生成背景图像：使用AI生成与"数字化转型"相关的抽象背景
4. 添加文字：主标题48px，副标题24px，使用思源黑体
5. 添加品牌元素：在右下角添加公众号二维码位置
6. 质量检查：确保文字清晰、对比度足够
7. 输出图片：保存为 /home/workspace/artifacts/wechat_cover.jpg
```

## 技能参数说明

### 输入参数
- **文字内容**：标题、正文、标签等
- **图片素材**：现有图片或AI生成要求
- **风格偏好**：简约、商务、创意等
- **平台要求**：微信、小红书、微博等
- **尺寸规格**：自定义或使用平台标准
- **品牌元素**：Logo、品牌色、字体等

### 输出参数
- **图片文件**：JPG/PNG格式
- **多尺寸版本**：根据需要生成多个尺寸
- **设计说明**：包含设计理念和注意事项
- **使用建议**：平台发布建议和优化提示

## 高级功能


## 错误处理

### 常见问题及解决方案

1. **文字过多无法清晰显示**
   - 解决方案：自动换行、调整字号、简化文字

2. **图片质量不足**
   - 解决方案：使用更高分辨率生成、AI增强、重新生成

3. **色彩不符合品牌要求**
   - 解决方案：应用品牌色板、调整色彩平衡

4. **尺寸不符合平台要求**
   - 解决方案：自动裁剪、调整比例、重新生成

### 用户提示
当遇到以下情况时，技能会提示用户：
- 文字内容过长建议精简
- 图片素材质量不足建议更换
- 品牌规范缺失建议提供
- 平台要求不明确需要确认

## 最佳实践建议

### 设计建议
1. **保持简洁**：避免信息过载
2. **突出重点**：核心信息一目了然
3. **考虑移动端**：确保小屏幕可读性
4. **测试验证**：在不同设备上预览

### 技术建议
1. **文件优化**：平衡质量和文件大小
2. **格式选择**：根据用途选择JPG或PNG
3. **色彩管理**：使用sRGB色彩空间
4. **元数据**：添加必要的EXIF信息

### 发布建议
1. **发布时间**：选择用户活跃时段
2. **平台特性**：利用各平台特色功能
3. **互动元素**：添加二维码、话题标签等
4. **数据分析**：跟踪图片效果进行优化
