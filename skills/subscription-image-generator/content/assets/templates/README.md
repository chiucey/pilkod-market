# 订阅号图片设计模板

本目录包含各种订阅号图片的设计模板，可用于快速生成符合平台要求的图片。

## 模板分类

### 1. 微信公众号模板
- `wechat_cover_01.psd` - 头条封面模板（简约风格）
- `wechat_cover_02.psd` - 头条封面模板（商务风格）
- `wechat_secondary_01.psd` - 次条封面模板
- `wechat_article_01.psd` - 文章内图模板

### 2. 小红书模板
- `xiaohongshu_cover_01.psd` - 笔记封面模板（时尚风格）
- `xiaohongshu_cover_02.psd` - 笔记封面模板（美食风格）
- `xiaohongshu_content_01.psd` - 内容图片模板

### 3. 微博模板
- `weibo_post_01.psd` - 微博配图模板
- `weibo_story_01.psd` - 微博故事模板
- `weibo_header_01.psd` - 微博头图模板

### 4. 通用模板
- `square_01.psd` - 正方形图片模板
- `portrait_01.psd` - 竖版图片模板
- `landscape_01.psd` - 横版图片模板
- `story_01.psd` - 故事模式模板

## 模板使用说明

### PSD模板使用
1. 使用Adobe Photoshop打开模板文件
2. 修改文字图层内容
3. 替换图片图层内容
4. 调整颜色和效果
5. 导出为JPG或PNG格式

### 模板自定义
1. **修改尺寸**：根据需求调整画布大小
2. **更换字体**：使用系统安装的中文字体
3. **调整配色**：修改颜色调整图层
4. **添加元素**：根据需要添加装饰元素

## 设计原则

### 一致性原则
- 同一系列的图片使用相同设计语言
- 保持品牌色彩和字体的一致性
- 确保视觉风格统一

### 可读性原则
- 文字与背景有足够对比度
- 重要信息突出显示
- 避免过度装饰影响阅读

### 适应性原则
- 考虑不同设备显示效果
- 确保在不同平台上显示良好
- 支持响应式设计

## 快速开始

### 步骤1：选择模板
根据目标平台和内容类型选择合适的模板。

### 步骤2：准备素材
- 准备高清图片素材
- 准备好文字内容
- 准备品牌Logo（如有）

### 步骤3：编辑模板
使用设计软件编辑模板内容。

### 步骤4：导出优化
- 选择合适的分辨率
- 优化文件大小
- 添加alt文本（如需）

## 注意事项

### 版权问题
- 确保使用的图片有合法授权
- 避免使用有版权的字体
- 注明图片来源（如需）

### 技术要求
- 导出时注意色彩模式（RGB）
- 确保图片尺寸符合平台要求
- 优化文件大小提高加载速度

### 更新维护
- 定期更新模板以适应平台变化
- 根据用户反馈优化模板设计
- 跟踪设计趋势进行更新
