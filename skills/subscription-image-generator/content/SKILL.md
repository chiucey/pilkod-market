# 订阅号图片生成器

## 概述

本技能提供专业级的订阅号图片生成能力，支持基于文字内容、图片素材或两者组合生成多种类型的社交媒体图片。技能集成了AI图像生成、排版设计、品牌一致性保持等核心功能，适用于公众号运营、社交媒体营销、活动宣传等场景。

## 核心能力

### 1. 多类型图片生成
- **公众号文章封面**：适用于公众号文章标题封面，尺寸1080×1350px
- **营销海报**：产品推广、活动宣传海报，尺寸1080×1920px
- **活动宣传图**：线上线下活动宣传图片，尺寸1200×628px
- **信息图/长图**：信息可视化长图，尺寸1080×无限长（分段生成）

### 2. 输入格式支持
- **纯文字输入**：根据文字内容自动设计图片布局和视觉元素
- **图片输入**：基于现有图片进行风格转换、添加文字或修饰
- **文字+图片组合**：结合文字内容和图片素材生成融合设计
- **飞书文档/Markdown**：从文档中提取关键信息生成图片

### 3. 设计风格选项
- **简约现代**：简洁明快的设计，适合科技、商务类内容
- **商务专业**：正式专业的风格，适合企业、行业报告
- **活泼创意**：色彩鲜明、创意十足，适合娱乐、时尚内容
- **节日/季节主题**：结合节日或季节元素的设计
- **品牌定制**：基于品牌VI系统的定制设计（需提供品牌规范）

## 使用流程

### 步骤1：确定需求
分析用户请求，明确以下关键信息：
- 图片类型（封面、海报、宣传图等）
- 内容主题和核心信息
- 目标受众和平台要求
- 设计风格偏好
- 尺寸规格要求

### 步骤2：内容分析与提取
- 从文字输入中提取标题、副标题、关键信息点
- 分析图片素材的视觉特征和可用元素
- 确定信息层次和视觉焦点

### 步骤3：设计规划
- 选择适合的布局模板
- 确定配色方案和字体搭配
- 规划视觉元素的位置关系
- 考虑品牌一致性要求

### 步骤4：图片生成与优化
使用 `aily-image-generate` 技能进行图片生成：
- 生成背景图像或视觉元素
- 添加文字排版和装饰元素
- 调整色彩、对比度和细节
- 确保输出质量符合平台要求

### 步骤5：输出与交付
- 生成最终图片文件（PNG/JPG格式）
- 提供多尺寸版本（如需）
- 保存到 `/home/workspace/artifacts/` 目录
- 在回复中展示生成的图片和设计说明

## 技术实现指南

### 图像生成策略
1. **文生图模式**：使用 Stable Diffusion/Seedream 模型生成背景或主题图像
2. **图生图模式**：基于现有图片进行风格迁移或内容增强
3. **组合设计**：多个元素叠加，确保视觉协调

### 文字处理要点
- 中文标题处理：选择合适的字体和字号
- 英文标题处理：确保字母间距和行高合适
- 段落文本：合理分段，控制每行字数
- 强调处理：使用粗细、颜色、装饰线等方式突出关键信息

### 色彩管理
- 主色调选择：基于内容主题和情感色彩
- 辅助色搭配：使用色轮理论确保和谐
- 对比度检查：确保文字可读性
- 品牌色应用：如有品牌规范，优先使用品牌色

## 常见场景处理

### 场景1：公众号文章封面
**输入**：文章标题 + 简短摘要  
**处理**：
1. 生成与标题主题相关的背景图像
2. 以清晰易读的方式展示标题
3. 添加公众号Logo或品牌标识
4. 使用标准尺寸1080×1350px

### 场景2：营销海报
**输入**：产品信息 + 促销文案 + 图片素材  
**处理**：
1. 突出产品卖点和促销信息
2. 添加价格标签或优惠券样式
3. 包含二维码或联系方式
4. 使用适合打印和分享的尺寸

### 场景3：活动宣传图
**输入**：活动详情 + 时间地点 + 参与方式  
**处理**：
1. 清晰展示活动基本信息
2. 添加日期和时间元素
3. 设计吸引眼球的视觉效果
4. 包含报名或了解更多链接

## 故障排除

### 常见问题
1. **文字不清晰**：增加对比度或调整字体大小
2. **图片模糊**：确保使用足够分辨率或重新生成
3. **色彩偏差**：检查色彩模式和色域设置
4. **文件过大**：优化压缩设置或调整尺寸

### 解决方案
- 重新生成时调整参数设置
- 使用不同的模型或风格
- 手动调整不满意部分
- 提供多个版本供选择
