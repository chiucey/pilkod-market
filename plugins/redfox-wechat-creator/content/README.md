# 公众号爆款内容创作师

基于公众号每日 10w+ 爆文数据的全流程创作套件：爆文榜单、账号诊断、封面设计、违禁词检测、文案改写、标题生成与评分、整文创作，覆盖公众号运营从选题到发布的全链路。

## 包含技能

| 技能 | 说明 |
|------|------|
| wechat-10w-hot | 全网每日收录 1000+ 公众号 10w+ 文章，支持分类查询与热门榜单 |
| wechat-account-analyzer | 公众号账号四维度量化诊断（内容力、增长力、粉丝活跃度、变现潜力） |
| wechat-cover | 爆款封面AI设计：基于同赛道爆文封面数据生成封面方案 |
| wechat-prohibited-word | 违禁词与敏感表述检测，标注风险并提供合规替换建议 |
| wechat-rewrite | 将任意素材改写成地道公众号爆款风格文案 |
| wechat-title | 公众号爆款标题生成与多维度评分，优化标题点击率 |
| wechat-write | 基于热门数据规律创作整篇公众号爆款文案 |

## 使用示例
- "查询最近 7 天的公众号 10w+ 爆文榜"
- "给我诊断一下这个公众号账号的运营状况"
- "为这篇文章生成 5 个公众号爆款标题并打分"
## 专家工作流建议

1. **选题规划**：使用 wechat-10w-hot 查看热门榜单，发现选题方向
2. **内容创作**：使用 wechat-write 或 wechat-rewrite 产出初稿
3. **标题打磨**：使用 wechat-title 生成备选标题并评分
4. **封面设计**：使用 wechat-cover 产出封面方案
5. **合规检查**：发布前使用 wechat-prohibited-word 检测违禁词

## 数据来源

技能数据基于全网每日持续收录的公众号 10w+ 爆款文章，由红狐数据提供。
