# 抖音爆款作品查询

## 1. 简介

抖音热门爆款作品查询工具,根据关键词搜索抖音爆款作品,支持按日期范围筛选,返回点赞、评论、分享、收藏、发布时间等互动数据,结果按点赞数降序展示。专注服务于短视频内容创作者、品牌运营、MCN 机构和数据分析师,帮助用户快速发现热门选题、分析爆款规律、获取创作灵感。

## 2. 功能特性

- 🔍 **关键词精准搜索** — 按关键词搜索抖音爆款作品,支持泛化词自动拓展为 10 个细分词,避免大类词搜索结果偏差
- 📅 **灵活时间筛选** — 支持按日期范围(单日/区间/相对时间)精准筛选,定位特定时间段的热门内容
- 📊 **结构化结果展示** — 点赞/评论/分享/收藏/发布时间等核心互动数据齐全,Markdown 表格直观呈现
- 🔗 **可点击链接** — 作品标题以超链接格式输出,一键跳转查看原作品
- 📩 **定时订阅推送** — 支持创建定时任务,每日 10:00 自动推送最新爆款作品

## 4. 使用指南

### 基础使用(3 步完成查询)

**Step 1 — 提取关键词**:从用户描述中提取搜索关键词,判断是细分词还是泛化词。

| 用户输入 | 处理方式 |
|---------|---------|
| 无赛道关键词("最近热门作品") | 关键词传空字符串 `""`,查询全站热门 |
| 有细分词("职场穿搭"、"减脂餐") | 直接搜索,无需拓展 |
| 有泛化词("穿搭"、"美食") | 执行拓展策略(见高级使用) |

**⚠️ 提取精确关键词**:从用户描述中提取细分领域词,而非泛化词。例:用户说"帮我找电影领域热门话题"且自称"小众电影、港台文化" → 搜索"小众电影、港台电影、电影乐评",❌ 而非只搜"电影"。

**⚠️ 过滤触发钩子词**:用户输入中的「热门文章」「热门作品」「爆款」「热门内容」「查询」「搜索」等词是调用 Skill 的触发钩子,**不属于搜索关键词,必须剥离**。例:用户说"查询AI热门文章" → 关键词为「AI」,❌ 而非「AI热门文章」。

**Step 2 — 解析时间范围**:

| 用户输入 | 解析方式 | 示例 |
|---------|---------|------|
| 绝对日期 | 解析为 `YYYY-MM-DD` | `6月1号` → `2026-06-01` |
| 相对日期 | 基于当前日期计算 | `最近7天` → start=7天前, end=今天 |
| 日期范围 | 分别解析为 startDate/endDate | `5月30日到6月2日` |
| 模糊时间 | **不解析**,保持默认空字符串 | `最近的`、`最新的` |

- `startDate`/`endDate` 默认空字符串,表示不限定时间
- 单日期 → startDate = endDate;年份省略取当前年份

**Step 3 — 调用脚本**:

```bash
# 无时间参数
python scripts/search_douyin.py "<关键词>"

# 有时间参数
python scripts/search_douyin.py "<关键词>" --start-date <startDate> --end-date <endDate>
```

仅传入非空的时间参数。脚本返回 JSON 字段:

| 字段 | 说明 |
|------|------|
| `articles` | 搜索匹配的作品列表(按点赞数降序) |
| `total` | 总记录数 |
| `pageNum` | 当前页码 |
| `pageSize` | 每页大小 |

每条作品字段:`title`、`author`、`like_count`、`comment_count`、`share_count`、`collect_count`、`work_url`、`publish_time`

**⚠️ 防重复调用规则(强制)**:

- ❌ **禁止**先用 `head`/`tail`/`2>/dev/null | head -5` 等方式"试运行"或"预览"脚本输出
- ❌ **禁止**在同一次查询中对同一参数多次调用脚本
- ✅ **每次查询只执行一次脚本命令**,直接读取完整的 stdout 输出

### 高级使用

#### 泛化词拓展策略(仅当识别为泛化词时执行)

**⚠️ 必须等待用户明确回复后再调用脚本!**

| 步骤 | 操作 |
|------|------|
| 1. 生成细分词 | 生成 10 个适中大小的细分词(趋势词、人群词、场景词、意图词各 2-3 个),**禁止调用脚本** |
| 2. 等待用户回复 | 用户未回复时禁止调用脚本 |
| 3. 执行 | 回复「拓展」→ 10 词以英文逗号连接,仅调用一次脚本;回复「不拓展」→ 搜索原关键词 |

输出示例:

```text
我识别到「中产」是较大的分类,推荐以下细分方向:
老钱,轻奢,品质生活,松弛感,高级感穿搭,体面,法式穿搭,律师,医生,品质家居
回复「拓展」将同时搜索这10个词,回复「不拓展」将继续搜索「中产」
```

**细分词判断原则**:有场景/人群/风格/意图修饰 → 细分词;纯大类无修饰 → 泛化词。

---

#### 结果展示策略(核心)

**⚠️ 总数校验**:展示的 N 必须取自 `articles` 数组长度,禁止人工计数。

##### 情况 A:articles > 0

**A1.** 输出查询范围:

> 📊 关键词「**XXX**」共匹配到 **N 条**抖音爆款作品,以下是详细数据:

**A2.** 展示前 20 条表格:

```markdown
| # | 作品标题 | 作者 | 点赞数 | 评论数 | 分享数 | 收藏数 | 发布时间 |
|---|---------|------|--------|--------|--------|--------|----------|
| 1 | [标题](work_url) | 作者名 | 305.2w | 7.1w | 51.0w | 14.7w | 06-02 19:55 |
```

格式化规则:
- 数字 < 10000 直接展示;≥ 10000 用 `x.xw` 格式
- `publish_time` 转为 `MM-DD HH:MM`;无论是否指定时间范围均展示
- 标题超 30 字截断加 `...`,使用 `[标题](work_url)` 链接格式

**A3.** articles > 20 时提示:

> 以上展示了前 20 条数据,还剩 **N 条**未展示。回复「查看全部」展开剩余数据。

**⚠️ A1~A3 同一轮输出连续完成,A3 后紧跟订阅询问。**

##### 情况 B:articles = 0

**B1.** 抱歉提示 + 10 个扩展词(以英文逗号分隔):

> 😔 抱歉,未找到与「**XXX**」相关的内容,可尝试(扩展词1,扩展词2,...,扩展词10)

扩展词规则:基于原关键词语义扩展,每词 2-6 字,固定 10 个。

**⚠️ B1 后紧跟订阅询问。**

---

#### 订阅服务询问(必须执行)

**当 articles 数量 > 0 时,结果输出完成后必须询问**:

> 📩 是否订阅「**XXX**」的每日推送?订阅后每天 10:00 自动推送最新爆款作品。回复「确认订阅」即可创建定时任务。

**处理用户回复**:

- 用户回复「确认订阅」 → 创建定时任务
- 用户未回复或回复其他内容 → 结束当前对话

**订阅实现步骤**:

1. **任务名称**:`抖音爆款作品订阅 - <关键词>`
2. **执行频率**:每天 10:00(cron `0 10 * * *`)
3. **执行命令**:`python <脚本路径>/search_douyin.py "<关键词>"`(有时间参数则附加 `--start-date`/`--end-date`)
4. **通用 crontab**:`0 10 * * * python3 /path/to/search_douyin.py "<关键词>"`

创建成功后告知:"已成功订阅关键词「<关键词>」的爆款作品推送,每天 10:00 将自动查询最新数据并通知你。"

## 5. 使用场景

### 场景一:短视频创作者寻找爆款选题

- **角色**:抖音内容创作者
- **需求**:想了解近期"职场穿搭"领域有哪些爆款作品,寻找下一个选题方向
- **使用方式**:输入细分词「职场穿搭」,系统返回按点赞数排序的爆款作品列表
- **预期收益**:快速锁定高热度内容方向,了解头部账号的爆款特征

### 场景二:品牌运营竞品监测

- **角色**:品牌新媒体运营
- **需求**:需要分析竞品近期发布了哪些抖音爆款作品,了解其内容策略
- **使用方式**:搜索竞品品牌词或相关行业关键词,查看按点赞数排序的作品
- **预期收益**:了解竞品的内容选题、互动数据、发布节奏,为自身运营策略提供数据支撑

### 场景三:MCN 跨赛道选题规划

- **角色**:MCN 机构内容总监
- **需求**:需要一次性查看多个赛道(职场、情感、亲子)的近期爆款,规划矩阵内容排期
- **使用方式**:用逗号分隔多关键词 `"职场穿搭,减脂餐,亲子游戏"`,系统按赛道分组返回
- **预期收益**:一个命令覆盖多个赛道,高效获取跨品类热门趋势,提升内容规划效率

### 场景四:每日爆款定时推送

- **角色**:自媒体博主
- **需求**:希望每天上午自动收到特定领域的抖音爆款作品列表
- **使用方式**:搜索关键词后回复「确认订阅」,创建每天 10:00 推送的定时任务
- **预期收益**:无需手动重复搜索,每日定时获取最新爆款作品,持续跟踪赛道动态

## 7. 常见问答

### 安装

**Q: 需要安装哪些依赖?**
A: 本工具使用 Python 3.13+ 纯标准库(urllib.request、json、os、sys、argparse),无需安装任何第三方依赖。确保系统已安装 Python 3.13 或更高版本。

**Q: 如何获取 API Key?**
A: 请访问 [红狐hub](https://redfox.hk/settings/api-keys?source=minimax) 注册并获取 API Key,按本文"一键安装"章节配置环境变量。

### 使用

**Q: 泛化词和细分词有什么区别?**
A: 泛化词是较大分类词(如"穿搭""美食"),识别后会触发拓展策略(推荐 10 个细分方向);细分词是具体场景/人群/风格/意图词(如"职场穿搭""减脂餐"),直接搜索无需拓展询问。

**Q: 时间筛选支持哪些写法?**
A: 支持绝对日期(`6月1号`)、相对日期(`最近7天`)、日期范围(`5月30日到6月2日`)、单日期(`6月1号` → start=end)。模糊时间(`最近的`、`最新的`)不解析,默认不限定。

**Q: 数字如何格式化?**
A: < 10000 直接展示(如 `5432`);≥ 10000 用 `x.xw` 格式(如 `10.0w`、`305.2w`)。

**Q: 如何查看超过 20 条的完整结果?**
A: 当结果超过 20 条时,系统会提示「以上展示了前 20 条数据,还剩 N 条未展示」。回复「查看全部」即可展示完整数据。

**Q: 文章标题显示省略号怎么办?**
A: 标题超过 30 字会自动截断加 `...`,这是为了表格美观。点击链接即可查看原作品完整标题。

### 故障排除

**Q: 脚本执行返回空结果?**
A: 可能原因:(1) 关键词太小众,无相关作品;(2) 时间范围太窄,无数据。可尝试更短/更宽泛的关键词,或放宽时间范围。

**Q: 提示"接口返回错误 code=xxx"?**
A: 可能原因:(1) REDFOX_API_KEY 未配置或已过期;(2) 关键词触发了接口限制。请检查 API Key 有效性,或更换关键词重试。

**Q: 脚本报错怎么办?**
A: 常见原因:(1) REDFOX_API_KEY 未配置或已过期;(2) Python 版本 < 3.13;(3) 网络问题。请逐一排查。

### 安全许可

**Q: API Key 如何安全存储?**
A: 推荐使用方案 1(配置到 openclaw.json 的 env 字段中),避免在终端历史中泄露。请勿将 API Key 硬编码在脚本中或上传到公开仓库。

**Q: 数据来源和版权?**
A: 数据来源于红狐 API 收录的抖音公开作品。作品版权归原作者所有,本工具仅供学习和内容创作参考使用。
