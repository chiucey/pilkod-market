# Skills for MiniMax-H3

这是将 MiniMax H3 仓库中的 Skill 集合封装为市场插件的版本，面向视频提示词编写与短片创作工作流。

插件由国内 Pilkod 插件市场统一下发。安装插件后，市场会直接提供下列 Skill，无需在包内执行额外的命令式安装步骤。

## 包含的 Skill

- `h3-prompt-writing`：为 T2VA、I2VA、FL2VA、L2VA 和 Ref2VA 编写结构化 H3 提示词。
- `minimalist-product-ad-generator`：制作极简产品广告短片。
- `3d-animation-short-generator`：从故事创意到成片规划 3D 动画短片。
- `papercraft-stop-motion-explainer`：制作纸艺定格科普视频创作包。
- `brand-promo-video-generator`：规划品牌与产品宣传短片。
- `music-video-subtitle-generator`：设计节拍同步的音乐 MV 与动态歌词文字。
- `co-op-game-intro-generator`：制作双人合作游戏菜单与开场动画。
- `paper-collage-explainer-generator`：用纸拼贴视觉制作讲解动画。
- `handdrawn-live-video-generator`：制作手绘动画与实拍空间融合短片。

其中大多数视频创作 Skill 依赖 MiniMax Hub 的画布、媒体生成与音视频工具；`h3-prompt-writing` 可在能够读取本地 Skill 文件的 Agent 中独立使用。各 Skill 的正文和参考资料位于对应目录中。

## 图标

- 默认/浅色图标：以明亮紫色与靛蓝色为主，使用液态毛玻璃、柔和折射和流体高光。

默认图标由用户提供的 MiniMax H3 视觉稿扩展为 1:1 画幅，移除底部副标题，仅保留并居中 `MiniMax H3` 主标识。
