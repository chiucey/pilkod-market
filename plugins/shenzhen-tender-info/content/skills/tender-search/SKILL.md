# 深圳投标进度查询与评标资料下载

## 数据源

只覆盖深圳本地平台：深圳公共资源交易网 `https://www.szggzy.com`。渠道分建设工程与政府采购两类。

## 可用工具

- `project_progress` —— 传工程名称关键词，拿到该项目所有阶段公告、当前阶段、是否已截标/已进入评标、可下载报告入口。
- `get_notice` —— 按 contentId 取单条公告正文与全部附件直链（已分类）。
- `download_docs` —— 把附件下载到本地目录，可只下某一类。
- `list_notices` —— 按渠道浏览公告。
- `list_channels` —— 渠道、阶段表、附件分类。

## 标准流程

1. **先查进度**：用 `project_progress`，`title` 用工程名的核心词（去掉「工程」「项目」等通用后缀更容易命中），`scope` 默认 `jsgc`（建设工程），政府采购用 `zfcg`。
2. **看阶段**：返回的 `currentStage` 取该项目到达过的最深阶段。阶段顺序：意向阶段 → 投标中 → 已截标 → 已开标 → 评标中 → 评标完成 → 已定标 → 已中标。`bidClosed` 表示已截标，`enteredEvaluation` 表示已进入评标。
3. **取附件**：从 `availableDocs` 里挑需要的 `contentId`，用 `get_notice` 看清楚附件清单和用途分类，再 `download_docs`。
4. **落盘**：下载目录用绝对路径，Windows 下建议 `E:\投标资料\<工程名>`。

## 阶段与对应文件

| 阶段 | 公告类型 | 可拿到的文件 |
| --- | --- | --- |
| 已截标 | 截标信息 | 截标时间、投标家数 |
| 已开标 | 开标情况公示 | 开标情况记录表（含各投标人报价） |
| 评标中 | 资审及业绩公示、评标委员会公示 | 资格审查结果、评委名单 |
| 评标完成 | 评标报告公示 | 评标报告、各投标人资信标文件 |
| 已定标 | 定标结果公示 | 定标结果、投票表 |
| 已中标 | 中标结果公示 | 中标结果公告（中标单位、项目经理、中标价、资格证书编号）、中标结果公告 PDF |

## 评标报告的文件命名（实测）

评标报告公示里的评标报告按评审分组命名，**三个名字都会出现，具体哪个要看项目**：

- `技术组评标报告.pdf` —— 技术标评审组
- `商务组评标报告.pdf` —— 商务标评审组
- `综合组评标报告.pdf` —— 单一评审组（全过程造价咨询、货物服务类项目常见）

另有可能出现 `商务组否决投标汇总表.pdf`（含被否决投标的原因汇总）。

**因此不要预设文件名**：一定用 `get_notice` 看该公告实际的附件清单，按实际名称下载。下载时用 `docClass: ["pingbiao"]` 会一并取到上述评标报告类文件。

## 两条数据通道的下载能力不同（重要）

| | 建设工程 | 政府采购 |
| --- | --- | --- |
| 附件来源 | 主站详情页正文 | `zfcg.szggzy.com:8081` 静态页 |
| 附件能否自动下载 | **可以**，直链免登录 | **不可以**，附件受图形验证码保护 |
| 典型附件 | 开标情况记录表、技术/商务/综合组评标报告、中标结果公告 | 开标记录表、评分结果表、资格性审查表、中标结果公告 |

政府采购的附件下载在浏览器里要先在验证码弹窗输入图形验证码。`download_docs` 对这类公告会返回 `manualRequired` 列表与 `staticUrl`，**照实告知用户需要人工下载**，不要谎称已下载，也不要伪造文件。

## 重要口径

- **各投标人的资信标文件会逐个列出附件名**，数量可能很多（实测单公告可达 15~20 份，部分单份超过 90 MB）。下载时优先只取评标报告与中标结果公告，除非用户明确要全部；一次全量拉取可能超过 1 GB。
- 政府采购公告要传 `noticeId` 与 `releaseTime`（来自 `project_progress` 的 `availableDocs`），工具据此定位静态页并解析附件清单。
- 同名工程可能有多个标段和历史同名项目，按 `projectCode` 区分，别把不同标段混成一个。`project_progress` 返回的 `projects` 已按阶段深度排序，最深的排在最前。
- 所有结论带 `fetchedAt`，报告里写明查询时点；超过 1 天应重新查。

## 输出格式

1. 进度一句话：当前阶段 + 是否已截标/进入评标。
2. 时间线表：阶段 | 公告类型 | 发布时间 | 内容链接。
3. 中标信息（若已中标）：中标单位、项目经理及资格等级、资格证书编号、中标价、工期。
4. 已下载文件清单：文件名 | 用途分类 | 大小 | 本地路径。
5. 未获取项及原因（如平台未公开、需人工验证码下载等）。

不写「应该已经」「大概是」；每个数字都要能对应到具体公告字段或文件。

## 可视化组合（可选）

本技能始终是完整的文本能力，不依赖任何可视化。当用户明确想看图（时间轴、报价对比、资料齐备度），在拿到 `project_progress` / `get_notice` / `download_docs` 的结构化结果后，调用运行时限定名 `shenzhen-tender-info:tender-search-visualizer` 渲染；它只变换已有结果，不重复取数、不臆造指标。没有得到授权或数据不足时，保持纯文本输出。
