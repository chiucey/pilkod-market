# 小红书爆款内容创作师

基于真实更新的爆款笔记打法，把灵感变成可发布的小红书笔记：爆款生成、封面设计、违禁词检测、文案标题优化评分，发布前全链路打磨，以及数据不佳的历史笔记诊断。

## 包含技能

| 技能 | 说明 |
|------|------|
| xiaohongshu-write | 一站式笔记生成：基于爆款数据提炼流量密码，生成读感自然、合规可发布的笔记正文 |
| xiaohongshu-rewrite | 文案改写：把任何素材（产品卖点、口播稿、长文）改写成地道小红书风格 |
| xiaohongshu-title-score | 标题生成与评分：产出爆款标题，并对已有标题多维加权评分给出优化方向 |
| xiaohongshu-cover | 封面设计：分析同赛道爆款封面视觉元素，生成贴合内容的封面方案 |
| xiaohongshu-prohibited-word | 违禁词检测：扫描文案中的违禁词与敏感表述，标注风险并提供合规替换建议 |

## 使用示例
- "帮我写一篇关于减脂餐的小红书爆款笔记"
- "评估这个标题的爆款潜力：早八通勤穿搭天花板"
- "检测一下这篇笔记有没有违禁词"
## 专家工作流建议

1. **生成/改写**：使用 xiaohongshu-write 或 xiaohongshu-rewrite 产出笔记初稿
2. **标题打磨**：使用 xiaohongshu-title-score 生成备选标题并评分选优
3. **封面设计**：使用 xiaohongshu-cover 产出封面方案
4. **合规检查**：发布前使用 xiaohongshu-prohibited-word 过一遍违禁词

## 数据来源

技能数据基于全网每日持续收录的小红书爆款笔记（2000+ 条/日），由红狐数据提供。
