# 代码生成视频

代码动画适合精确文字、图表、示意图与片头；写实镜头使用用户指定且已配置的 H3 等视频工具。两者可混合剪辑。不要把代码动画转交给图片或视频生成模型。

1. 使用本插件的工具读取当前工程，target_project 后读取尺寸、帧率、素材、时间线和已有草稿。工程不明确时先让用户选择，不能改其他工程。
2. 先加载 load_skill 的 create-motion-graphics 指南，读取当前工具 schema。create_motion_graphic_from_code 接收完整 React/JSX 内联代码；保留可编辑文字与颜色属性。代码仅通过动画素材工具保存，不修改应用源码、数据库或沙箱限制。工具不可用时请用户打开对应工程，不猜测接口。
3. 配音通过当前 MiniMax Code Agent 查找用户已配置、授权的语音能力。先生成并测量实际音频时长，再安排动画与字幕。只发现工具不等于验证成功；缺少能力时说明，不擅自切换收费服务，不在聊天索要密钥。复用已生成文件和任务 ID，不能因导入失败重复收费生成。
4. 新建或继续 manual 编辑草稿。创建动画素材后再放入时间线；导入成功必须重新读取确认。添加配音、字幕及已有音乐；没有配音时明确交付无配音版本，不伪造已生成音频。
5. 通过 view_timeline_frames 检查开头、中间、结尾，每次一帧，检查文字遮挡、黑帧、节奏和安全边距。review_edit_session 交付预览，只有 applied 才算应用成功。
6. 用户确认后走编辑器导出。实际检查导出文件的时长、分辨率、解码与音画，附文件和限制；代码创建成功、预览成功、导出成功必须分别报告。

例：制作 8 秒深色背景、珊瑚红强调色的 MiniMax Video 片头，使用可编辑代码动画，不调用 H3，先给手动预览。
