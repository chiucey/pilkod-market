# 分段续接

只在单镜头超过接口上限，或严格单次生成失败且用户确认唯一一次重试时使用。

## 固定规则

- 段长 4–6 秒，重叠 0.5–1 秒；接口最短时长更长时扩大窗口。
- 每段必须输入对应的白模切片作为待编辑视频，并使用同一组外观参考。
- 下一段额外携带上一段末尾 0.5–1 秒生成视频，保持运动速度和视觉连续性。
- 工具明确支持 Ref2VA + FL2VA 混合时，才把上一段末帧作为硬边界锁；否则只按
  视频软续接，不能声称已经硬锁。
- 接缝选在遮挡、低纹理、低运动或快速摇镜处；避开动作发力点、速度反转、
  人脸近景和高视差环绕。
- 重叠区只用于选择连续接缝，不添加溶解、硬切或新镜头掩盖失败。

每一段独立执行 preflight、合同、prompt 和 QA。拼接完成后，再以整条原始白模为
source 运行 `prepare-qa`，最终仍按一个连续镜头验收；任何可感知接缝都判结构失败。
