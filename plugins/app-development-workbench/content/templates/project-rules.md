# 项目规则模板

这是待填写的模板，不自动覆盖 AGENTS.md。由当前项目负责人/用户指定适用范围；复制到项目后填入真实路径和约束，再让宿主从该规则入口读取。

## 目标与范围
- 当前产品目标、目标平台、包含/不包含的业务：待填写。
- 代码、原型、服务端、测试和交付目录：待填写。
- 最低系统版本、构建 scheme、运行入口：从工程发现后填写。

## 需求与证据
需求歧义先利用现有材料消除；仍影响方向时提出 1–3 个具体问题。关键答案未到不推进依赖工作。用户表述机制时核对真实版本、配置和调用链，区分事实、推断与待验证项；有误明确更正并给依据。

## 视觉与组件
锁定背景/配色/导航及唯一实现位置：待填写。先盘点后修改 Token/基础组件，再迁移页面。品牌样式集中管理，同一职责复用一个基础组件，语义变体扩展；一处修改所有调用方同步是验收标准。覆盖交互状态与辅助功能。

## 状态、数据与服务
状态归属、API 契约、身份与资源 owner、数据模式、配置变量名：待填写。不得写真实凭据。重复逻辑集中复用，失败/取消/竞态/清理与持久化有明确语义。

## 运行与交付
启动前识别端口和进程，复用正确服务，只处理明确属于任务的残留。浏览器优先用户现有桌面浏览器。默认交付正常运行 App/模拟器与可执行 E2E 步骤；真机、真实外部服务和发布分别记录证据。

## Git 与发布
主/测试分支与目标环境由现有仓库规范或用户明确指示确定，提交前同步。保留用户改动，按授权提交推送和 MR；MR 英文标题、中文完整说明。自动检查不代替用户体验验收；不得自动扩展为生产发布。
