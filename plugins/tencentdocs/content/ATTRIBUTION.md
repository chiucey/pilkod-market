# 腾讯文档 Skill 来源

本插件的 Skill 内容基于 SkillHub 官方企业 Skill `tencent-docs` 1.0.41 打包，来源：

- SkillHub 详情：https://api.skillhub.cn/api/v1/skills/tencent-docs
- 下载接口：https://api.skillhub.cn/api/v1/download?slug=tencent-docs&version=1.0.41
- 发布方：腾讯文档团队

为适配 MiniMax Plugin V1，包内已将原有本地安装、Token 写入和旧的服务直连调用改为 `tencentdocs` Connector；本地打包和编码辅助逻辑保留。
