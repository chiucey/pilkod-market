# 钉钉

桌面插件，通过官方 `dws` 使用钉钉，包含与 CLI 1.0.64 同包发布的 16 个产品技能。覆盖消息、文档、云盘、知识库、日程、待办、会议纪要、通讯录等，具体能力受组织权限限制。

首次使用按 [准备说明](skills/dingtalk-shared/references/minimax-code-setup.md) 检查 CLI 和登录；已有安装优先复用。缺少时运行 `scripts/install-dws.py`，只安装校验过的官方二进制与许可证，不运行会改动其他 Agent 技能目录的上游安装器。

需要用户完成钉钉授权，组织可能需要管理员开启 CLI。插件安装不会自动登录、发消息、提交申请或改变默认组织。此次只支持桌面，云端不依赖用户本机 CLI 和登录状态。

上游来源和本地改动见 [PROVENANCE.md](PROVENANCE.md)。Python 3.9+ 用于可选安装脚本及部分上游辅助脚本；核心调用使用官方原生 CLI。
