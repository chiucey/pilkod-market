# Connector 与插件版本管理

## 版本归属

腾讯会议服务端可能在业务响应中附带版本提示。Connector 配置中的 `X-Skill-Version` 与插件包版本是两项独立信息：前者由 Connector 管理方维护，后者由客户端的插件市场管理。

本插件不运行原 CLI 的安装流程，不捆绑 `get_skill_update_preference` / `set_skill_update_preference`，也不读取或修改本地更新状态文件。

## 收到版本提示时

1. 先检查业务请求是否成功。仅有可选更新提示时，继续交付当前业务结果。
2. 记录响应实际给出的当前版本、最新版本及提示；缺失的版本号不能推断。
3. 同一会话、同一版本最多提醒一次。用户已表示暂不更新或不再提醒时，在该会话中遵循其选择，不声称已写入跨会话的更新偏好。
4. 用户要求更新插件时，引导使用客户端的插件管理/市场更新入口；本技能不能自行修改已安装包或下载执行远端安装脚本。
5. 若提示涉及 Connector 的版本头或服务端兼容性，由 Connector 管理方检查 provider 配置。不要自行改请求头以绕过检查。

## 工具可用性

只有当前 Connector 实际发现了 `check_skill_version`，且其 Schema 明确支持查询版本时，才可把它作为只读查询使用。没有该工具时，直接说明当前 Connector 未提供版本查询能力，不调用旧 CLI 或虚构工具。

即使返回了安装地址，也不能据此运行安装命令。更新后的 Skill 规则何时生效，以客户端插件管理结果为准；必要时重新开始会话。
